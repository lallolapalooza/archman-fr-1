sous-routine dlahqr (logical wantt, logical wantz, integer n, integer ilo, integer ihi, double precision, dimension( ldh, * ) h, integer ldh, double precision, dimension( * ) wr, double precision, dimension( * ) wi, integer iloz, integer ihiz, double precision, dimension( ldz, * ) z, integer ldz, integer info)

DLAHQR calcule les valeurs propres et la décomposition de Schur d'une matrice de Hessenberg supérieure, en utilisant l'algorithme QR à double/simple décalage.

Objectif :

!>
!>    DLAHQR est une sous-routine auxiliaire appelée par DHSEQR pour mettre à jour
!>    les valeurs propres et la décomposition de Schur déjà calculées par DHSEQR,
!>    en traitant la sous-matrice de Hessenberg dans les lignes et colonnes ILO à
!>    IHI.
!>

Paramètres

WANTT 
!>          WANTT est LOGICAL
!>          = .TRUE. : la forme de Schur complète T est requise ;
!>          = .FALSE. : seules les valeurs propres sont requises.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          = .TRUE. : la matrice des vecteurs de Schur Z est requise ;
!>          = .FALSE. : les vecteurs de Schur ne sont pas requis.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice H. N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>          On suppose que H est déjà quasi-triangulaire supérieure dans les
!>          lignes et colonnes IHI+1:N, et que H(ILO,ILO-1) = 0 (sauf si
!>          ILO = 1). DLAHQR travaille principalement avec la sous-matrice de
!>          Hessenberg dans les lignes et colonnes ILO à IHI, mais applique
!>          des transformations à tout H si WANTT est .TRUE..
!>          1 <= ILO <= max(1,IHI); IHI <= N.
!>

H

!>          H est un tableau DOUBLE PRECISION, dimension (LDH,N)
!>          À l'entrée, la matrice de Hessenberg supérieure H.
!>          À la sortie, si INFO est zéro et si WANTT est .TRUE., H est quasi-triangulaire
!>          supérieure dans les lignes et colonnes ILO:IHI, avec les blocs diagonaux
!>          de 2 par 2 en forme standard. Si INFO est zéro et WANTT est .FALSE.,
!>          le contenu de H n'est pas spécifié à la sortie. L'état de sortie de H
!>          si INFO est non nul est donné ci-dessous sous la description de INFO.
!>

LDH

!>          LDH est INTEGER
!>          La dimension principale du tableau H. LDH >= max(1,N).
!>

WR

!>          WR est un tableau DOUBLE PRECISION, dimension (N)
!>

WI

!>          WI est un tableau DOUBLE PRECISION, dimension (N)
!>          Les parties réelles et imaginaires, respectivement, des valeurs propres
!>          calculées ILO à IHI sont stockées dans les éléments correspondants de WR et WI.
!>          Si deux valeurs propres sont calculées comme une paire conjuguée complexe,
!>          elles sont stockées dans des éléments consécutifs de WR et WI, par exemple
!>          le i-ème et le (i+1)-ème, avec WI(i) > 0 et WI(i+1) < 0. Si WANTT est .TRUE.,
!>          les valeurs propres sont stockées dans le même ordre que sur la diagonale
!>          de la forme de Schur retournée dans H, avec WR(i) = H(i,i), et, si
!>          H(i:i+1,i:i+1) est un bloc diagonal de 2 par 2,
!>          WI(i) = sqrt(H(i+1,i)*H(i,i+1)) et WI(i+1) = -WI(i).
!>

ILOZ

!>          ILOZ est INTEGER
!>

IHIZ

!>          IHIZ est INTEGER
!>          Spécifiez les lignes de Z auxquelles les transformations doivent être
!>          appliquées si WANTZ est .TRUE..
!>          1 <= ILOZ <= ILO; IHI <= IHIZ <= N.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension (LDZ,N)
!>          Si WANTZ est .TRUE., à l'entrée Z doit contenir la matrice Z actuelle des
!>          transformations accumulées par DHSEQR, et à la sortie Z a été mise à jour ;
!>          les transformations ne sont appliquées qu'à la sous-matrice Z(ILOZ:IHIZ,ILO:IHI).
!>          Si WANTZ est .FALSE., Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>           = 0 : sortie réussie
!>           > 0 : Si INFO = i, DLAHQR n'a pas réussi à calculer toutes les
!>                  valeurs propres ILO à IHI en un total de 30 itérations
!>                  par valeur propre ; les éléments i+1:ihi de WR et WI
!>                  contiennent les valeurs propres qui ont été
!>                  calculées avec succès.
!>
!>                  Si INFO > 0 et WANTT est .FALSE., alors à la sortie,
!>                  les valeurs propres non convergentes restantes sont les
!>                  valeurs propres de la matrice de Hessenberg supérieure des
!>                  lignes et colonnes ILO à INFO de la valeur finale, de sortie, de H.
!>
!>                  Si INFO > 0 et WANTT est .TRUE., alors à la sortie
!>          (*)       (valeur initiale de H)*U  = U*(valeur finale de H)
!>                  où U est une matrice orthogonale. La valeur finale de H est
!>                  de Hessenberg supérieure et triangulaire dans les lignes et
!>                  colonnes INFO+1 à IHI.
!>
!>                  Si INFO > 0 et WANTZ est .TRUE., alors à la sortie
!>                      (valeur finale de Z)  = (valeur initiale de Z)*U
!>                  où U est la matrice orthogonale dans (*)
!>                  (quel que soit la valeur de WANTT.)
!>

dlahqr(3)

NAME
dlahqr — subroutine for finding the eigenvalues and eigenvectors of a general matrix

SYNOPSIS
subroutine dlahqr(job,compz,n,ilo,ihi,h,ldh,wr,wi,z,ldz,work,lwork,info)

DESCRIPTION
dlahqr computes the eigenvalues and right eigenvectors of a real upper Hessenberg matrix H. Eigenvectors of a general matrix A can be found by separately computing eigenvectors of H and then transforming back to the eigenvectors of A.

ARGUMENTS
job (input) CHARACTER*1
Specifies whether to compute the eigenvectors:

  • 'E': Compute the eigenvalues only.
  • 'V': Compute the eigenvalues and the eigenvectors.
compz (input) CHARACTER*1
Specifies whether to compute the matrix Z of eigenvectors, and the mode in which Z is computed.
  • 'N': Eigenvectors are not computed.
  • 'I': Eigenvectors are computed and initialized to the identity matrix, then overwritten by the eigenvectors.
  • 'V': Eigenvectors are computed in the current matrix Z.
n (input) INTEGER
The order of the matrix H. 0 <= n <= n.
ilo (input) INTEGER
ihi (input) INTEGER
Specify the range of the submatrix H(ilo, ihi) of H. h (input) DOUBLE PRECISION array, dimension (ldh, n)
On entry, the upper Hessenberg matrix H.
On exit, the array H is overwritten by information about the Schur factorization. ldh (input) INTEGER
The leading dimension of the array H. ldh >= max(1, n).
wr (output) DOUBLE PRECISION array, dimension (n)
wi (output) DOUBLE PRECISION array, dimension (n)
The computed eigenvalues. Eigenvalues are stored in the order they occur as the diagonal elements of the Schur form. The imaginary parts of complex eigenvalues are stored in wi. If wi(i) is zero, then wr(i) is the real eigenvalue. If wi(i) is non-zero, then the complex eigenvalue is wr(i) + sqrt(-1)*wi(i). z (input/output) DOUBLE PRECISION array, dimension (ldz, n)
On entry, if compz = 'V', z must contain the transformation matrix T that reduces H to the Schur form R. If compz = 'I', z is initialized to the identity matrix.
On exit, if job = 'V', z contains the matrix Z of right eigenvectors of H.
ldz (input) INTEGER
The leading dimension of the array z. ldz >= max(1, n).
work (output) DOUBLE PRECISION array, dimension (lwork)
lwork (input) INTEGER
The dimension of the array work. lwork >= max(1, n).
For optimal performance, lwork is n*nb, where nb is the block size used in the algorithms. If lwork = -1, then the dimension is calculated and stored in work(1).
info (output) INTEGER
= 0: successful exit
< 0: if info = -i, the i-th argument had an illegal value.
> 0: if info = i, the QR algorithm failed to converge. i eigenvectors were computed.

EXAMPLES
This is a subroutine, so it is not meant to be run alone. The following is a conceptual example of how it might be used in a larger program: 

            PROGRAM example
            IMPLICIT NONE
            INTEGER, PARAMETER :: n_max = 100
            INTEGER :: n, ldh, ldz, lwork, info
            DOUBLE PRECISION :: h(n_max, n_max), z(n_max, n_max), work(n_max)
            DOUBLE PRECISION :: wr(n_max), wi(n_max)

            ! ... initialize n, h, ldh, ldz ...

            lwork = n_max * 10 ! Example block size
            CALL dlahqr('V', 'I', n, 1, n, h, ldh, wr, wi, z, ldz, work, lwork, info)

            IF (info == 0) THEN
                PRINT *, "Eigenvalues:", wr, wi
                PRINT *, "Eigenvectors:", z
            ELSE
                PRINT *, "dlahqr failed with info=", info
            END IF
            END PROGRAM example

NOTE
This routine is deprecated and may be removed in a future release. Consider using dgeev or dhgeev instead.

DIAGNOSTICS
The QR algorithm implemented in this subroutine may fail to converge for some matrices. In such cases, the subroutine returns a positive value for info, indicating the number of eigenvectors that were successfully computed.
