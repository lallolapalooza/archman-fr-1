Documentation de la fonction/sous-programme

sous-programme dlaic1 (integer job, integer j, double precision, dimension( j ) x, double precision sest, double precision, dimension( j ) w, double precision gamma, double precision sestpr, double precision s, double precision c)

DLAIC1 applique une étape d'estimation de condition incrémentale dans sa version la plus simple :

Soit x, twonorm(x) = 1, un vecteur singulier approximatif d'une matrice triangulaire inférieure j par j, L, tel que twonorm(L*x) = sest. Alors DLAIC1 calcule sestpr, s, c tels que le vecteur [ s*x ] xhat = [ c ] soit un vecteur singulier approximatif de [ L 0 ] Lhat = [ w**T gamma ] au sens où twonorm(Lhat*xhat) = sestpr. Notez que [s c]**T et sestpr**2 est une paire propre du système diag(sest*sest, 0) + [alpha gamma] * [ alpha ] [ gamma ] où alpha = x**T*w.

Paramètres

JOB 
!>          JOB est INTEGER
!>          = 1 : une estimation de la plus grande valeur singulière est calculée.
!>          = 2 : une estimation de la plus petite valeur singulière est calculée.
!>

J

!>          J est INTEGER
!>          Longueur de X et W
!>

X

!>          X est un tableau de DOUBLE PRECISION, dimension (J)
!>          Le vecteur j, x.
!>

SEST

!>          SEST est DOUBLE PRECISION
!>          Valeur singulière estimée de la matrice j par j, L
!>

W

!>          W est un tableau de DOUBLE PRECISION, dimension (J)
!>          Le vecteur j, w.
!>

GAMMA

!>          GAMMA est DOUBLE PRECISION
!>          L'élément diagonal gamma.
!>

SESTPR

!>          SESTPR est DOUBLE PRECISION
!>          Valeur singulière estimée de la matrice (j+1) par (j+1), Lhat.
!>

S

!>          S est DOUBLE PRECISION
!>          Sinus nécessaire pour former xhat.
!>

C

!>          C est DOUBLE PRECISION
!>          Cosinus nécessaire pour former xhat.
!>
