Documentation de la fonction/sous-routine

sous-routine dlattb (entier imat, caractère uplo, caractère trans, caractère diag, entier, dimension( 4 ) iseed, entier n, entier kd, double précision, dimension( ldab, * ) ab, entier ldab, double précision, dimension( * ) b, double précision, dimension( * ) work, entier info)

DLATTB

Objectif :

!>
!> DLATTB génère une matrice triangulaire de test en stockage 2D.
!> IMAT et UPLO définissent de manière unique les propriétés de la matrice de test,
!> qui est retournée dans le tableau A.
!>

Paramètres

IMAT 
!>          IMAT est ENTIER
!>          Une clé entière décrivant quelle matrice générer pour ce
!>          chemin.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          Spécifie si la matrice A sera triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CARACTERE*1
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Conjuguée transposée (= transposée)
!>

DIAG

!>          DIAG est CARACTERE*1
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

ISEED

!>          ISEED est un tableau d'ENTIERS, dimension (4)
!>          Le vecteur de germe pour le générateur de nombres aléatoires (utilisé dans
!>          DLATMS).  Modifié à la sortie.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice à générer.
!>

KD

!>          KD est ENTIER
!>          Le nombre de super-diagonales ou de sous-diagonales de la matrice
!>          triangulaire bande A.  KD >= 0.
!>

AB

!>          AB est un tableau de DOUBLE PRÉCISION, dimension (LDAB,N)
!>          La matrice triangulaire bande supérieure ou inférieure A, stockée dans les
!>          KD+1 premières lignes de AB.  Soit j une colonne de A, 1<=j<=n.
!>          Si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j.
!>          Si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

B

!>          B est un tableau de DOUBLE PRÉCISION, dimension (N)
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, dimension (2*N)
!>

INFO

!>          INFO est ENTIER
!>          = 0:  Sortie réussie
!>          < 0: si INFO = -k, le k-ième argument avait une valeur illégale
!>
