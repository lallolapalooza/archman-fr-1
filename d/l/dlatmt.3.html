T

But

!>
!>    DLATMT génère des matrices aléatoires avec des valeurs singulières
!>    spécifiées (ou symétriques/hermitiennes avec des valeurs propres
!>    spécifiées) pour tester les programmes LAPACK.
!>
!>    DLATMT fonctionne en appliquant la séquence suivante
!>    d'opérations :
!>
!>      Définir la diagonale à D, où D peut être en entrée ou
!>         calculé selon MODE, COND, DMAX et SYM
!>         comme décrit ci-dessous.
!>
!>      Générer une matrice avec la structure de bande appropriée, par
!>         l'une des deux méthodes :
!>
!>      Méthode A :
!>          Générer une matrice dense M x N en multipliant D à gauche
!>              et à droite par des matrices unitaires aléatoires, puis :
!>
!>          Réduire la largeur de bande selon KL et KU, en utilisant
!>          les transformations de Householder.
!>
!>      Méthode B :
!>          Convertir la matrice de largeur de bande 0 (c.-à-d. diagonale) en une
!>              matrice de largeur de bande 1 en utilisant les rotations de Givens,
!>              les éléments hors bande en arrière, un peu comme dans QR ; puis
!>              convertir la largeur de bande 1 en largeur de bande 2, etc.
!>              Notez que pour des largeurs de bande raisonnablement petites (par rapport à
!>              M et N), cela nécessite moins de stockage, car une matrice dense
!>              n'est pas générée. De plus, pour les matrices symétriques, seul
!>              un triangle est généré.
!>
!>      La méthode A est choisie si la largeur de bande est une grande fraction de
!>          l'ordre de la matrice, et LDA est au moins M (de sorte qu'une matrice dense
!>          puisse être stockée.) La méthode B est choisie si la largeur de bande
!>          est petite (< 1/2 N pour symétrique, < .3 N+M pour
!>          non symétrique), ou LDA est inférieur à M et non inférieur à la
!>          largeur de bande.
!>
!>      Empaqueter la matrice si souhaité. Les options spécifiées par PACK sont :
!>         aucun empaquetage
!>         mettre à zéro la moitié supérieure (si symétrique)
!>         mettre à zéro la moitié inférieure (si symétrique)
!>         stocker la moitié supérieure par colonnes (si symétrique ou
!>               triangulaire supérieur)
!>         stocker la moitié inférieure par colonnes (si symétrique ou
!>               triangulaire inférieur)
!>         stocker le triangle inférieur au format bande (si symétrique
!>               ou triangulaire inférieur)
!>         stocker le triangle supérieur au format bande (si symétrique
!>               ou triangulaire supérieur)
!>         stocker la matrice entière au format bande
!>      Si la méthode B est choisie et que le format bande est spécifié, alors la
!>         matrice sera générée au format bande, de sorte qu'aucun réempaquetage
!>         ne sera nécessaire.
!
>

!>          DIST est CHARACTER*1
!>           À l'entrée, DIST spécifie le type de distribution à utiliser
!>           pour générer les valeurs propres/singulières aléatoires.
!>           'U' => UNIFORM( 0, 1 )  ( 'U' pour uniforme )
!>           'S' => UNIFORM( -1, 1 ) ( 'S' pour symétrique )
!>           'N' => NORMAL( 0, 1 )   ( 'N' pour normale )
!>           Non modifié.
!
>

ISEE

D 
!>          ISEED est un tableau INTEGER, dimension ( 4 )
!>           À l'entrée, ISEED spécifie la graine du générateur de
!>           nombres aléatoires. Elles doivent être comprises entre 0 et 4095
!>           inclus, et ISEED(4) doit être impair. Le générateur de nombres
!>           aléatoires utilise une suite congruentielle linéaire limitée à de
!>           petits entiers, et devrait donc produire des nombres aléatoires
!>           indépendants de la machine. Les valeurs de ISEED sont modifiées à
!>           la sortie, et peuvent être utilisées dans le prochain appel à DLATMT
!>           pour continuer la même suite de nombres aléatoires.
!>           Modifié à la sortie.
!
>

SY

M 
!>          SYM est CHARACTER*1
!>           Si SYM='S' ou 'H', la matrice générée est symétrique, avec
!>             des valeurs propres spécifiées par D, COND, MODE et DMAX ; elles
!>             peuvent être positives, négatives ou nulles.
!>           Si SYM='P', la matrice générée est symétrique, avec
!>             des valeurs propres (= valeurs singulières) spécifiées par D, COND,
!>             MODE et DMAX ; elles ne seront pas négatives.
!>           Si SYM='N', la matrice générée est non symétrique, avec
!>             des valeurs singulières spécifiées par D, COND, MODE et DMAX ;
!>             elles ne seront pas négatives.
!>           Non modifié.
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension ( MIN( M , N ) )
!>           Ce tableau est utilisé pour spécifier les valeurs singulières ou
!>           propres de A (voir SYM, ci-dessus.) Si MODE=0, alors D est
!>           supposé contenir les valeurs singulières/propres, sinon
!>           elles seront calculées selon MODE, COND et DMAX,
!>           et placées dans D.
!>           Modifié si MODE est non nul.
!
>

MOD

E 
!>          MODE est INTEGER
!>           À l'entrée, cela décrit comment les valeurs singulières/propres doivent
!>           être spécifiées :
!>           MODE = 0 signifie utiliser D en entrée
!>
!>           MODE = 1 définit D(1)=1 et D(2:RANK)=1.0/COND
!>           MODE = 2 définit D(1:RANK-1)=1 et D(RANK)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(RANK-1))
!>
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    soient uniformément distribués.
!>           MODE = 6 définit D à des nombres aléatoires de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est positif, D a des entrées allant de
!>              1 à 1/COND, si négatif, de 1/COND à 1.
!>           Si SYM='S' ou 'H', et que MODE n'est ni 0, ni 6, ni -6, alors
!>              les éléments de D seront aussi multipliés par un signe
!>              aléatoire (c.-à-d. +1 ou -1.)
!>           Non modifié.
!
>

CON

D 
!>          COND est DOUBLE PRECISION
!>           À l'entrée, cela est utilisé comme décrit sous MODE ci-dessus.
!>           S'il est utilisé, il doit être >= 1. Non modifié.
!
>

DMA

X 
!>          DMAX est DOUBLE PRECISION
!>           Si MODE n'est ni -6, ni 0, ni 6, le contenu de D, tel que
!>           calculé selon MODE et COND, sera mis à l'échelle par
!>           DMAX / max(abs(D(i))) ; ainsi, la valeur propre ou
!>           singulière absolue maximale (c'est-à-dire la norme) sera abs(DMAX).
!>           Notez que DMAX n'a pas besoin d'être positif : si DMAX est négatif
!>           (ou nul), D sera mis à l'échelle par un nombre négatif (ou nul).
!>           Non modifié.
!
>

RAN

K 
!>          RANK est INTEGER
!>           Le rang de la matrice à générer uniquement pour les modes 1,2,3.
!>           D( RANK+1:N ) = 0.
!>           Non modifié.
!
>

SUBROUTINE DLATMT( M, N, DIST, D S , SYM, MODE, COND, DMAX, PACK, A, LDA, WORK, INFO )


      INTEGER :: M, N, INFO


      REAL*8 :: D S , COND, DMAX


      CHARACTER(LEN=*) :: DIST, SYM, PACK


      INTEGER :: KL, KU


      REAL*8, DIMENSION( * ) :: A, WORK


      INTEGER :: LDA

Function/Subroutine Documentation

Purpose

  DLATMT generates a general rectangular matrix A which is
  functionally related to the arguments below.

  A = S * P * ( D * R * D' ) * P'

Arguments

M
M is INTEGER
Number of rows of the matrix A.
N
N is INTEGER
Number of columns of the matrix A.
DIST
DIST is CHARACTER*1
Specifies the distribution of the singular values of the matrix. 
'U' =   uniformly distributed in (0,1]
'S' =   scaled singular values in (0,1]
'D' =   diagonal matrix with values in (0,1]
'D I A G O N A L' =   diagonal matrix with values in (0,1]
'R' =   randomly distributed in (0,1]
'L' =   log-uniformly distributed in (0,1]
'E' =   equal singular values
Not modified.
DS
DS is REAL*8
Specifies the value of the largest singular value. Not modified.
SYM
SYM is CHARACTER*1
Specifies the structure of the matrix. 
'N' =   NO TRANSPOSE                  (general rectangular)
'T' =   TRANSPOSE                     (general rectangular)
'S' =   SYMMETRIC                     (upper triangle stored)
'H' =   HERMITIAN                     (upper triangle stored)
'P' =   POSITIVE DEFINITE             (upper triangle stored)
'P O S I T I V E   D E F I N I T E' =   POSITIVE DEFINITE (upper triangle stored)
Not modified.
MODE
MODE is INTEGER
Determines the properties of the matrix. 
-1 =   cond*I
 0 =   no condition number scaling
 1 =   cond = |A|
 2 =   cond = ||A||
 3 =   cond = ||A||_1
 4 =   cond = ||A||_inf
 5 =   cond = max(min(M,N))
 6 =   cond = 1
Not modified.
COND
COND is REAL*8
Specifies the condition number of the matrix. Not modified.
DMAX
DMAX is REAL*8
Specifies the maximum absolute value of the entries in the matrix. Not modified.
PACK
PACK is CHARACTER*1
Specifies packing of matrix as follows: 
'N' => no packing
'U' => zero out all subdiagonal entries (if symmetric)
'L' => zero out all superdiagonal entries (if symmetric)
'C' => store the upper triangle columnwise
      (only if the matrix is symmetric or upper triangular)
'R' => store the lower triangle columnwise
      (only if the matrix is symmetric or lower triangular)
'B' => store the lower triangle in band storage scheme
      (only if matrix symmetric or lower triangular)
'Q' => store the upper triangle in band storage scheme
      (only if matrix symmetric or upper triangular)
'Z' => store the entire matrix in band storage scheme
      (pivoting can be provided for by using this
      option to store A in the trailing rows of
      the allocated storage)
Using these options, the various LAPACK packed and banded storage schemes can be obtained: 
GB               - use 'Z'
PB, SB or TB     - use 'B' or 'Q'
PP, SP or TP     - use 'C' or 'R'
If two calls to DLATMT differ only in the PACK parameter, they will generate mathematically equivalent matrices. Not modified.
A
A is DOUBLE PRECISION array, dimension ( LDA, N )
On exit A is the desired test matrix. A is first generated in full (unpacked) form, and then packed, if so specified by PACK. Thus, the first M elements of the first N columns will always be modified. If PACK specifies a packed or banded storage scheme, all LDA elements of the first N columns will be modified; the elements of the array which do not correspond to elements of the generated matrix are set to zero. Modified.
LDA
LDA is INTEGER
LDA specifies the first dimension of A as declared in the calling program. If PACK='N', 'U', 'L', 'C', or 'R', then LDA must be at least M. If PACK='B' or 'Q', then LDA must be at least MIN( KL, M-1) (which is equal to MIN(KU,N-1)). If PACK='Z', LDA must be large enough to hold the packed array: MIN( KU, N-1) + MIN( KL, M-1) + 1. Not modified.
WORK
WORK is DOUBLE PRECISION array, dimension ( 3*MAX( N , M ) )
Workspace. Modified.
INFO
INFO is INTEGER
Error code. On exit, INFO will be set to one of the following values: 
0 => normal return
-1 => M negative or unequal to N and SYM='S', 'H', or 'P'
-2 => N negative
-3 => DIST illegal string
-5 => SYM illegal string
-7 => MODE not in range -6 to 6
-8 => COND less than 1.0, and MODE neither -6, 0 nor 6
-10 => KL negative
-11 => KU negative, or SYM='S' or 'H' and KU not equal to KL
-12 => PACK illegal string, or PACK='U' or 'L', and SYM='N';
      or PACK='C' or 'Q' and SYM='N' and KL is not zero;
      or PACK='R' or 'B' and SYM='N' and KU is not zero;
      or PACK='U', 'L', 'C', 'R', 'B', or 'Q', and M is not
      N.
-14 => LDA is less than M, or PACK='Z' and LDA is less than
      MIN(KU,N-1) + MIN(KL,M-1) + 1.
1  => Error return from DLATM7
2  => Cannot scale to DMAX (max. sing. value is 0)
3  => Error return from DLAGGE or DLAGSY
