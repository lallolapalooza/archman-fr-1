DLASQ3 vérifie la déflation, calcule un décalage et appelle dqds. Utilisé par sbdsqr.

Documentation de la fonction/sous-routine

sous-routine dlasq3 (integer i0, integer n0, double precision, dimension( * ) z, integer pp, double precision dmin, double precision sigma, double precision desig, double precision qmax, integer nfail, integer iter, integer ndiv, logical ieee, integer ttype, double precision dmin1, double precision dmin2, double precision dn, double precision dn1, double precision dn2, double precision g, double precision tau)

DLASQ3 vérifie la déflation, calcule un décalage (TAU) et appelle dqds. En cas d'échec, il modifie les décalages et réessaie jusqu'à ce que la sortie soit positive.

Objectif:

!>
!> DLASQ3 vérifie la déflation, calcule un décalage (TAU) et appelle dqds.
!> En cas d'échec, il modifie les décalages et réessaie jusqu'à ce que la sortie
!> soit positive.
!>

Paramètres

I0 
!>          I0 est un entier
!>         Premier indice.
!>

N0

!>          N0 est un entier
!>         Dernier indice.
!>

Z

!>          Z est un tableau de DOUBLE PRECISION, de dimension ( 4*N0 )
!>         Z contient le tableau qd.
!>

PP

!>          PP est un entier
!>         PP=0 pour ping, PP=1 pour pong.
!>         PP=2 indique que le retournement a été appliqué au tableau Z
!>         et que les tests initiaux de déflation ne doivent pas
!>         être effectués.
!>

DMIN

!>          DMIN est un DOUBLE PRECISION
!>         Valeur minimale de d.
!>

SIGMA

!>          SIGMA est un DOUBLE PRECISION
!>         Somme des décalages utilisés dans le segment courant.
!>

DESIG

!>          DESIG est un DOUBLE PRECISION
!>         Partie d'ordre inférieur de SIGMA
!>

QMAX

!>          QMAX est un DOUBLE PRECISION
!>         Valeur maximale de q.
!>

NFAIL

!>          NFAIL est un entier
!>         Incrémente NFAIL de 1 à chaque fois que le décalage était trop grand.
!>

ITER

!>          ITER est un entier
!>         Incrémente ITER de 1 à chaque itération.
!>

NDIV

!>          NDIV est un entier
!>         Incrémente NDIV de 1 pour chaque division.
!>

IEEE

!>          IEEE est un LOGICAL
!>         Indicateur pour l'arithmétique IEEE ou non IEEE (passé à DLASQ5).
!>

TTYPE

!>          TTYPE est un entier
!>         Type de décalage.
!>

DMIN1

!>          DMIN1 est un DOUBLE PRECISION
!>

DMIN2

!>          DMIN2 est un DOUBLE PRECISION
!>

DN

!>          DN est un DOUBLE PRECISION
!>

DN1

!>          DN1 est un DOUBLE PRECISION
!>

DN2

!>          DN2 est un DOUBLE PRECISION
!>

G

!>          G est un DOUBLE PRECISION
!>

TAU

!>          TAU est un DOUBLE PRECISION
!>
!>         Ceux-ci sont passés en arguments afin de conserver leurs valeurs
!>         entre les appels à DLASQ3.
!>
