sous-programme dlarrf (entier n, nombre réel double, dimension( * ) d, nombre réel double, dimension( * ) l, nombre réel double, dimension( * ) ld, entier clstrt, entier clend, nombre réel double, dimension( * ) w, nombre réel double, dimension( * ) wgap, nombre réel double, dimension( * ) werr, nombre réel double spdiam, nombre réel double clgapl, nombre réel double clgapr, nombre réel double pivmin, nombre réel double sigma, nombre réel double, dimension( * ) dplus, nombre réel double, dimension( * ) lplus, nombre réel double, dimension( * ) work, entier info)

DLARRF trouve une nouvelle représentation relativement robuste telle qu'au moins une des valeurs propres soit relativement isolée.

Objectif :

!>
!> Étant donné la représentation initiale L D L^T et son cluster de valeurs propres
!> proches (en mesure relative), W( CLSTRT ), W( CLSTRT+1 ), ...
!> W( CLEND ), DLARRF trouve une nouvelle représentation relativement robuste
!> L D L^T - SIGMA I = L(+) D(+) L(+)^T telle qu'au moins une des
!> valeurs propres de L(+) D(+) L(+)^T soit relativement isolée.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice (sous-bloc, si la matrice est divisée).
!>

D

!>          D est tableau de NOMBRE REEL DOUBLE, dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D.
!>

L

!>          L est tableau de NOMBRE REEL DOUBLE, dimension (N-1)
!>          Les (N-1) éléments sous-diagonaux de la matrice bidiagonale unitaire
!>          L.
!>

LD

!>          LD est tableau de NOMBRE REEL DOUBLE, dimension (N-1)
!>          Les (N-1) éléments L(i)*D(i).
!>

CLSTRT

!>          CLSTRT est ENTIER
!>          L'indice de la première valeur propre dans le cluster.
!>

CLEND

!>          CLEND est ENTIER
!>          L'indice de la dernière valeur propre dans le cluster.
!>

W

!>          W est tableau de NOMBRE REEL DOUBLE, dimension
!>          dimension est >=  (CLEND-CLSTRT+1)
!>          Les APPROXIMATIONS des valeurs propres de L D L^T dans l'ordre croissant.
!>          W( CLSTRT ) à W( CLEND ) forment le cluster de valeurs propres relativement
!>          proches.
!>

WGAP

!>          WGAP est tableau de NOMBRE REEL DOUBLE, dimension
!>          dimension est >=  (CLEND-CLSTRT+1)
!>          La séparation par rapport à la valeur propre voisine droite dans W.
!>

WERR

!>          WERR est tableau de NOMBRE REEL DOUBLE, dimension
!>          dimension est  >=  (CLEND-CLSTRT+1)
!>          WERR contient la demi-largeur de l'intervalle d'incertitude
!>          de l'APPROXIMATION de valeur propre correspondante dans W
!>

SPDIAM

!>          SPDIAM est NOMBRE REEL DOUBLE
!>          estimation du diamètre spectral obtenu à partir des
!>          intervalles de Gerschgorin
!>

CLGAPL

!>          CLGAPL est NOMBRE REEL DOUBLE
!>

CLGAPR

!>          CLGAPR est NOMBRE REEL DOUBLE
!>          écart absolu à chaque extrémité du cluster.
!>          Défini par la routine appelante pour éviter les décalages trop proches
!>          des valeurs propres en dehors du cluster.
!>

PIVMIN

!>          PIVMIN est NOMBRE REEL DOUBLE
!>          Le pivot minimum autorisé dans la séquence de Sturm.
!>

SIGMA

!>          SIGMA est NOMBRE REEL DOUBLE
!>          Le décalage utilisé pour former L(+) D(+) L(+)^T.
!>

DPLUS

!>          DPLUS est tableau de NOMBRE REEL DOUBLE, dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D(+).
!>

LPLUS

!>          LPLUS est tableau de NOMBRE REEL DOUBLE, dimension (N-1)
!>          Les (N-1) premiers éléments de LPLUS contiennent les éléments sous-diagonaux
!>          de la matrice bidiagonale unitaire L(+).
!>

WORK

!>          WORK est tableau de NOMBRE REEL DOUBLE, dimension (2*N)
!>          Espace de travail.
!>

INFO

!>          INFO est ENTIER
!>          Indique si le traitement a réussi (=0) ou échoué (=1)
!>
