DLASD7 fusionne les deux ensembles de valeurs singulières en un seul ensemble trié. Il essaie ensuite de réduire la taille du problème (déflation). Utilisé par

sbdsdc.

But

: 
!>
!> DLASD7 fusionne les deux ensembles de valeurs singulières en un seul
!> ensemble trié. Il essaie ensuite de réduire la taille du problème.
!> Il existe deux façons dont la déflation peut survenir : lorsque deux
!> valeurs singulières ou plus sont proches les unes des autres, ou s'il
!> existe une entrée minuscule dans le vecteur Z. Pour chaque occurrence
!> de ce type, l'ordre du problème d'équation séculaire associé est
!> réduit d'une unité.
!>
!> DLASD7 est appelé depuis DLASD6.
!
>

Paramètre

s
ICOMPQ 
!>          ICOMPQ est INTEGER
!>          Spécifie si les vecteurs singuliers doivent être calculés
!>          sous forme compacte, comme suit :
!>          = 0 : Calculer uniquement les valeurs singulières.
!>          = 1 : Calculer les vecteurs singuliers de la matrice
!>               bidiagonale supérieure sous forme compacte.
!
>

N

L 
!>          NL est INTEGER
!>         La dimension des lignes du bloc supérieur. NL >= 1.
!
>

N

R 
!>          NR est INTEGER
!>         La dimension des lignes du bloc inférieur. NR >= 1.
!
>

SQR

E 
!>          SQRE est INTEGER
!>         = 0 : le bloc inférieur est une matrice carrée NR par NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR par (NR+1).
!>
!>         La matrice bidiagonale a
!>         N = NL + NR + 1 lignes et
!>         M = N + SQRE >= N colonnes.
!
>

K 
!>          K est INTEGER
!>         Contient la dimension de la matrice non déflatée, c'est-à-dire
!>         l'ordre de l'équation séculaire associée. 1 <= K <=N.
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension ( N )
!>         À l'entrée, D contient les valeurs singulières des deux sous-matrices
!>         à combiner. À la sortie, D contient les (N-K) valeurs singulières
!>         mises à jour restantes (celles qui ont été déflatées), triées
!>         par ordre croissant.
!
>

Z 
!>          Z est un tableau DOUBLE PRECISION, dimension ( M )
!>         À la sortie, Z contient le vecteur de mise à jour dans l'équation
!>         séculaire.
!
>

Z

W 
!>          ZW est un tableau DOUBLE PRECISION, dimension ( M )
!>         Espace de travail pour Z.
!
>

V

F 
!>          VF est un tableau DOUBLE PRECISION, dimension ( M )
!>         À l'entrée, VF(1:NL+1) contient les premiers composants de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VF(NL+2:M)
!>         contient les premiers composants de tous les vecteurs singuliers
!>         droits du bloc inférieur. À la sortie, VF contient les premiers
!>         composants de tous les vecteurs singuliers droits de la matrice
!>         bidiagonale.
!
>

VF

W 
!>          VFW est un tableau DOUBLE PRECISION, dimension ( M )
!>         Espace de travail pour VF.
!
>

V

L 
!>          VL est un tableau DOUBLE PRECISION, dimension ( M )
!>         À l'entrée, VL(1:NL+1) contient les derniers composants de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VL(NL+2:M)
!>         contient les derniers composants de tous les vecteurs singuliers
!>         droits du bloc inférieur. À la sortie, VL contient les derniers
!>         composants de tous les vecteurs singuliers droits de la matrice
!>         bidiagonale.
!
>

VL

W 
!>          VLW est un tableau DOUBLE PRECISION, dimension ( M )
!>         Espace de travail pour VL.
!
>

ALPH

A 
!>          ALPHA est DOUBLE PRECISION
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!
>

BET

A 
!>          BETA est DOUBLE PRECISION
!>         Contient l'élément hors-diagonal associé à la ligne
!>         ajoutée.
!
>

DSIGM

A 
!>          DSIGMA est un tableau DOUBLE PRECISION, dimension ( N )
!>         Contient une copie des éléments diagonaux (K-1 valeurs
!>         singulières et un zéro) dans l'équation séculaire.
!
>

ID

X 
!>          IDX est un tableau INTEGER, dimension ( N )
!>         Cela contiendra la permutation utilisée pour trier le contenu
!>         de D dans l'ordre croissant.
!
>

IDX

P 
!>          IDXP est un tableau INTEGER, dimension ( N )
!>         Cela contiendra la permutation utilisée pour placer les valeurs
!>         déflatées de D à la fin du tableau. En sortie, IDXP(2:K)
!>         pointe vers les valeurs de D non déflatées et IDXP(K+1:N)
!>         pointe vers les valeurs singulières déflatées.
!
>

IDX

Q 
!>          IDXQ est un tableau INTEGER, dimension ( N )
!>         Cela contient la permutation qui trie séparément les deux
!>         sous-problèmes dans D dans l'ordre croissant. Notez que les
!>         entrées dans la première moitié de cette permutation doivent
!>         d'abord être déplacées d'une position vers l'arrière ; et les
!>         entrées dans la seconde moitié doivent d'abord avoir NL+1
!>         ajouté à leurs valeurs.
!
>

PER

M 
!>          PERM est un tableau INTEGER, dimension ( N )
!>         Les permutations (issues de la déflation et du tri) à appliquer
!>         à chaque bloc singulier. Non référencé si ICOMPQ = 0.
!
>

GIVPT

R 
!>          GIVPTR est INTEGER
!>         Le nombre de rotations de Givens qui ont eu lieu dans ce
!>         sous-problème. Non référencé si ICOMPQ = 0.
!
>

GIVCO

L 
!>          GIVCOL est un tableau INTEGER, dimension ( LDGCOL, 2 )
!>         Chaque paire de nombres indique une paire de colonnes à
!>         inclure dans une rotation de Givens. Non référencé si ICOMPQ = 0.
!
>

LDGCO

L 
!>          LDGCOL est INTEGER
!>         La dimension principale de GIVCOL, doit être au moins N.
!
>

GIVNU

M 
!>          GIVNUM est un tableau DOUBLE PRECISION, dimension ( LDGNUM, 2 )
!>         Chaque nombre indique la valeur C ou S à utiliser dans la
!>         rotation de Givens correspondante. Non référencé si ICOMPQ = 0.
!
>

LDGNU

M 
!>          LDGNUM est de type INTEGER
!>         La dimension principale de GIVNUM, doit être au moins N.
!
>

C 
!>          C est de type DOUBLE PRECISION
!>         C contient des données non significatives si SQRE = 0 et la
!>         valeur C d'une rotation de Givens liée à l'espace nul droit
!>         si SQRE = 1.
!
>

S 
!>          S est de type DOUBLE PRECISION
!>         S contient des données non significatives si SQRE = 0 et la
!>         valeur S d'une rotation de Givens liée à l'espace nul droit
!>         si SQRE = 1.
!
>

INF

O 
!>          INFO est de type INTEGER
!>         = 0 :  sortie réussie.
!>         < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!
>
