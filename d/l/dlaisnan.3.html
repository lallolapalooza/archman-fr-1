fonction logique dlaisnan (double précision, intent(in) din1, double précision, intent(in) din2)

DLAISNAN teste l'entrée pour NaN en comparant deux arguments pour l'inégalité.

Objectif :

!>
!> Cette routine n'est pas pour une utilisation générale. Elle existe uniquement pour éviter
!> une sur-optimisation dans DISNAN.
!>
!> DLAISNAN vérifie les NaNs en comparant ses deux arguments pour
!> l'inégalité. NaN est la seule valeur en virgule flottante pour laquelle NaN != NaN
!> renvoie .TRUE. Pour vérifier les NaNs, passez la même variable comme les deux
!> arguments.
!>
!> Un compilateur doit supposer que les deux arguments ne sont pas
!> la même variable, et le test ne sera pas optimisé.
!> L'optimisation interprocédurale ou sur l'ensemble du programme peut supprimer ce
!> test. Les fonctions ISNAN seront remplacées par l'intrinsèque Fortran 03 correcte
!> une fois que l'intrinsèque sera largement disponible.
!>

Paramètres

DIN1 
!>          DIN1 est DOUBLE PRECISION
!>

DIN2

!>          DIN2 est DOUBLE PRECISION
!>          Deux nombres à comparer pour l'inégalité.
!>
