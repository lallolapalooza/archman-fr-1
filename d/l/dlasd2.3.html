DLASD2 fusionne les deux ensembles de valeurs singulières en un seul ensemble trié. Utilisé par sbdsdc.

Objectif :

!>
!> DLASD2 fusionne les deux ensembles de valeurs singulières en un seul
!> ensemble trié. Puis il tente de déflater la taille du problème.
!> Il existe deux façons dont la déflation peut se produire : lorsque deux ou plusieurs
!> valeurs singulières sont proches les unes des autres ou s'il y a une entrée minuscule dans
!> le vecteur Z. Pour chaque occurrence, l'ordre du problème d'équation séculaire
!> associé est réduit de un.
!>
!> DLASD2 est appelé à partir de DLASD1.
!>

Paramètres

NL 
!>          NL est un ENTIER
!>         La dimension de ligne du bloc supérieur. NL >= 1.
!>

NR

!>          NR est un ENTIER
!>         La dimension de ligne du bloc inférieur. NR >= 1.
!>

SQRE

!>          SQRE est un ENTIER
!>         = 0 : le bloc inférieur est une matrice carrée NR-par-NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR-par-(NR+1).
!>
!>         La matrice bidiagonale a N = NL + NR + 1 lignes et
!>         M = N + SQRE >= N colonnes.
!>

K

!>          K est un ENTIER
!>         Contient la dimension de la matrice non déflatée,
!>         C'est l'ordre de l'équation séculaire associée. 1 <= K <=N.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension(N)
!>         À l'entrée, D contient les valeurs singulières des deux sous-matrices
!>         à combiner. À la sortie, D contient les (N-K) dernières valeurs singulières
!>         mises à jour (celles qui ont été déflatées) triées par ordre croissant.
!>

Z

!>          Z est un tableau de DOUBLE PRÉCISION, dimension(N)
!>         À la sortie, Z contient le vecteur ligne de mise à jour dans l'équation
!>         séculaire.
!>

ALPHA

!>          ALPHA est de DOUBLE PRÉCISION
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!>

BETA

!>          BETA est de DOUBLE PRÉCISION
!>         Contient l'élément hors diagonale associé à la ligne ajoutée.
!>

U

!>          U est un tableau de DOUBLE PRÉCISION, dimension(LDU,N)
!>         À l'entrée, U contient les vecteurs singuliers gauches de deux
!>         sous-matrices dans les deux blocs carrés aux coins (1,1),
!>         (NL, NL), et (NL+2, NL+2), (N,N).
!>         À la sortie, U contient les (N-K) derniers vecteurs singuliers gauches
!>         mis à jour (ceux qui ont été déflatés) dans ses N-K dernières colonnes.
!>

LDU

!>          LDU est un ENTIER
!>         La dimension principale du tableau U. LDU >= N.
!>

VT

!>          VT est un tableau de DOUBLE PRÉCISION, dimension(LDVT,M)
!>         À l'entrée, VT**T contient les vecteurs singuliers droits de deux
!>         sous-matrices dans les deux blocs carrés aux coins (1,1),
!>         (NL+1, NL+1), et (NL+2, NL+2), (M,M).
!>         À la sortie, VT**T contient les (N-K) derniers vecteurs singuliers droits
!>         mis à jour (ceux qui ont été déflatés) dans ses N-K dernières colonnes.
!>         En cas de SQRE =1, la dernière ligne de VT couvre l'espace nul droit.
!>

LDVT

!>          LDVT est un ENTIER
!>         La dimension principale du tableau VT. LDVT >= M.
!>

DSIGMA

!>          DSIGMA est un tableau de DOUBLE PRÉCISION, dimension (N)
!>         Contient une copie des éléments diagonaux (K-1 valeurs singulières
!>         et un zéro) dans l'équation séculaire.
!>

U2

!>          U2 est un tableau de DOUBLE PRÉCISION, dimension(LDU2,N)
!>         Contient une copie des K-1 premiers vecteurs singuliers gauches qui
!>         seront utilisés par DLASD3 dans une multiplication de matrices (DGEMM) pour résoudre
!>         pour les nouveaux vecteurs singuliers gauches. U2 est organisé en quatre
!>         blocs. Le premier bloc contient une colonne avec 1 à NL+1 et
!>         zéro partout ailleurs ; le deuxième bloc contient des entrées non nulles
!>         seulement à partir de NL ; le troisième contient des entrées non nulles
!>         seulement en dessous de NL+1 ; et le quatrième est dense.
!>

LDU2

!>          LDU2 est un ENTIER
!>         La dimension principale du tableau U2. LDU2 >= N.
!>

VT2

!>          VT2 est un tableau de DOUBLE PRÉCISION, dimension(LDVT2,N)
!>         VT2**T contient une copie des K premiers vecteurs singuliers droits
!>         qui seront utilisés par DLASD3 dans une multiplication de matrices (DGEMM) pour
!>         résoudre pour les nouveaux vecteurs singuliers droits. VT2 est organisé en
!>         trois blocs. Le premier bloc contient une ligne qui correspond
!>         à l'élément diagonal spécial 0 dans SIGMA ; le deuxième bloc
!>         contient des non-zéros seulement jusqu'à NL +1 ; le troisième bloc
!>         contient des non-zéros seulement après NL +2.
!>

LDVT2

!>          LDVT2 est un ENTIER
!>         La dimension principale du tableau VT2. LDVT2 >= M.
!>

IDXP

!>          IDXP est un tableau d'ENTIERS, dimension(N)
!>         Ceci contiendra la permutation utilisée pour placer les valeurs déflatées
!>         de D à la fin du tableau. En sortie, IDXP(2:K)
!>         pointe vers les valeurs D non déflatées et IDXP(K+1:N)
!>         pointe vers les valeurs singulières déflatées.
!>

IDX

!>          IDX est un tableau d'ENTIERS, dimension(N)
!>         Ceci contiendra la permutation utilisée pour trier le contenu de
!>         D par ordre croissant.
!>

IDXC

!>          IDXC est un tableau d'ENTIERS, dimension(N)
!>         Ceci contiendra la permutation utilisée pour organiser les colonnes
!>         de la matrice U déflatée en trois groupes : le premier groupe
!>         contient des entrées non nulles seulement à partir de NL, le deuxième
!>         contient des entrées non nulles seulement en dessous de NL+2, et le troisième
!>         est dense.
!>

IDXQ

!>          IDXQ est un tableau d'ENTIERS, dimension(N)
!>         Ceci contient la permutation qui trie séparément les deux
!>         sous-problèmes dans D par ordre croissant. Notez que les entrées dans
!>         la première moitié de cette permutation doivent d'abord être déplacées
!>         d'une position vers l'arrière ; et les entrées dans la seconde moitié
!>         doivent d'abord avoir NL+1 ajouté à leurs valeurs.
!>

COLTYP

!>          COLTYP est un tableau d'ENTIERS, dimensio

COLTYP

!>         COLTYP is INTEGER array, dimension(N)
!>        Contains the column type of the rows of U and columns of VT
!>        that are part of the smaller subproblems.
!>        COLTYP(I)=0 if the column I is not participating in the
!>                deflation.
!>        COLTYP(I)=1 if the column I is participating in the
!>                first deflation (small singular value).
!>        COLTYP(I)=2 if the column I is participating in the
!>                second deflation (large singular value).
!>

INFO

!>          INFO is INTEGER
!>         = 0 :  successful exit.
!>         < 0 :  if INFO = -i, then the i-th argument had an
!>                illegal value.
!>
