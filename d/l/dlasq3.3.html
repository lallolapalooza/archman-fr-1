sous-programme dlasq3 (entier i0, entier n0, double précision, dimension( * ) z, entier pp, double précision dmin, double précision sigma, double précision desig, double précision qmax, entier nfail, entier iter, entier ndiv, logique ieee, entier ttype, double précision dmin1, double précision dmin2, double précision dn, double précision dn1, double précision dn2, double précision g, double précision tau)

DLASQ3 vérifie la déflation, calcule un décalage (TAU) et appelle dqds. Utilisé par sbdsqr.

Objectif :

!>
!> DLASQ3 vérifie la déflation, calcule un décalage (TAU) et appelle dqds.
!> En cas d'échec, il change les décalages et réessaie jusqu'à ce que la sortie
!> soit positive.
!>

Paramètres

I0 
!>          I0 est ENTIER
!>         Premier indice.
!>

N0

!>          N0 est ENTIER
!>         Dernier indice.
!>

Z

!>          Z est un tableau de DOUBLE PRÉCISION, dimension ( 4*N0 )
!>         Z contient le tableau qd.
!>

PP

!>          PP est ENTIER
!>         PP=0 pour ping, PP=1 pour pong.
!>         PP=2 indique que le renversement a été appliqué au tableau Z
!>         et que les tests initiaux de déflation ne doivent pas
!>         être effectués.
!>

DMIN

!>          DMIN est DOUBLE PRÉCISION
!>         Valeur minimale de d.
!>

SIGMA

!>          SIGMA est DOUBLE PRÉCISION
!>         Somme des décalages utilisés dans le segment courant.
!>

DESIG

!>          DESIG est DOUBLE PRÉCISION
!>         Partie d'ordre inférieur de SIGMA
!>

QMAX

!>          QMAX est DOUBLE PRÉCISION
!>         Valeur maximale de q.
!>

NFAIL

!>          NFAIL est ENTIER
!>         Incrémente NFAIL de 1 à chaque fois que le décalage était trop grand.
!>

ITER

!>          ITER est ENTIER
!>         Incrémente ITER de 1 pour chaque itération.
!>

NDIV

!>          NDIV est ENTIER
!>         Incrémente NDIV de 1 pour chaque division.
!>

IEEE

!>          IEEE est LOGIQUE
!>         Indicateur pour l'arithmétique IEEE ou non IEEE (passé à DLASQ5).
!>

TTYPE

!>          TTYPE est ENTIER
!>         Type de décalage.
!>

DMIN1

!>          DMIN1 est DOUBLE PRÉCISION
!>

DMIN2

!>          DMIN2 est DOUBLE PRÉCISION
!>

DN

!>          DN est DOUBLE PRÉCISION
!>

DN1

!>          DN1 est DOUBLE PRÉCISION
!>

DN2

!>          DN2 est DOUBLE PRÉCISION
!>

G

!>          G est DOUBLE PRÉCISION
!>

TAU

!>          TAU est DOUBLE PRÉCISION
!>
!>         Ceux-ci sont passés en arguments afin de sauvegarder leurs valeurs
!>         entre les appels à DLASQ3.
!>
