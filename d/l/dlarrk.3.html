sous-programme dlarrk (n, iw, gl, gu, d, e2, pivmin, reltol, w, werr, info)
DLARRK calcule une valeur propre d'une matrice tridiagonale symétrique avec la précision appropriée.

Documentation de la fonction/sous-programme

sous-programme dlarrk (integer n, integer iw, double precision gl, double precision gu, double precision, dimension( * ) d, double precision, dimension( * ) e2, double precision pivmin, double precision reltol, double precision w, double precision werr, integer info)

DLARRK calcule une valeur propre d'une matrice tridiagonale symétrique avec la précision appropriée.

Objectif :

!>
!> DLARRK calcule une valeur propre d'une matrice tridiagonale
!> symétrique avec la précision appropriée. Ceci est un code auxiliaire à appeler
!> depuis DSTEMR.
!>
!> Pour éviter le dépassement, la matrice doit être mise à l'échelle de sorte que son
!> plus grand élément ne dépasse pas overflow**(1/2) * underflow**(1/4) en valeur absolue, et pour une
!> plus grande précision, il ne doit pas être beaucoup plus petit que cela.
!>
!> Voir W. Kahan , Report CS41, Computer Science Dept., Stanford
!> University, July 21, 1966.
!>

Paramètres

N 
!>          N est un INTEGER
!>          L'ordre de la matrice tridiagonale T.  N >= 0.
!>

IW

!>          IW est un INTEGER
!>          L'indice de la valeur propre à retourner.
!>

GL

!>          GL est un DOUBLE PRECISION
!>

GU

!>          GU est un DOUBLE PRECISION
!>          Une borne supérieure et une borne inférieure sur la valeur propre.
!>

D

!>          D est un tableau de DOUBLE PRECISION, de dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale T.
!>

E2

!>          E2 est un tableau de DOUBLE PRECISION, de dimension (N-1)
!>          Les (n-1) éléments hors diagonaux au carré de la matrice tridiagonale T.
!>

PIVMIN

!>          PIVMIN est un DOUBLE PRECISION
!>          Le pivot minimum autorisé dans la séquence de Sturm pour T.
!>

RELTOL

!>          RELTOL est un DOUBLE PRECISION
!>          La largeur relative minimale d'un intervalle. Quand un intervalle
!>          est plus étroit que RELTOL multiplié par le plus grand (en
!>          valeur absolue) des points de terminaison, alors il est considéré comme
!>          suffisamment petit, c'est-à-dire convergé.  Note : ceci devrait
!>          toujours être au moins radix*machine epsilon.
!>

W

!>          W est un DOUBLE PRECISION
!>

WERR

!>          WERR est un DOUBLE PRECISION
!>          La borne d'erreur sur l'approximation de valeur propre correspondante
!>          dans W.
!>

INFO

!>          INFO est un INTEGER
!>          = 0 :       La valeur propre a convergé
!>          = -1 :      La valeur propre N'a PAS convergé
!>

Paramètres internes :

!>  FUDGE   DOUBLE PRECISION, par défaut = 2
!>          Un facteur pour élargir les intervalles de Gershgorin.
!>
