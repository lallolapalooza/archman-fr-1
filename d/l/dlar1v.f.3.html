sous-routine dlar1v (entier n, entier b1, entier bn, double precision lambda, double precision, dimension( * ) d, double precision, dimension( * ) l, double precision, dimension( * ) ld, double precision, dimension( * ) lld, double precision pivmin, double precision gaptol, double precision, dimension( * ) z, logique wantnc, entier negcnt, double precision ztz, double precision mingma, entier r, entier, dimension( * ) isuppz, double precision nrminv, double precision resid, double precision rqcorr, double precision, dimension( * ) work)

DLAR1V calcule la colonne r (mise à l'échelle) de l'inverse de la sous-matrice des lignes b1 à bn de la matrice tridiagonale LDLT - λI.

Objectif :

!>
!> DLAR1V calcule la colonne r (mise à l'échelle) de l'inverse de
!> la sous-matrice des lignes B1 à BN de la matrice tridiagonale
!> L D L**T - sigma I. Lorsque sigma est proche d'une valeur propre,
!> le vecteur calculé est un vecteur propre précis. Habituellement, r correspond
!> à l'indice où le vecteur propre est le plus grand en magnitude.
!> Les étapes suivantes accomplissent ce calcul :
!> (a) Transformation qd stationnaire,  L D L**T - sigma I = L(+) D(+) L(+)**T,
!> (b) Transformation qd progressive, L D L**T - sigma I = U(-) D(-) U(-)**T,
!> (c) Calcul des éléments diagonaux de l'inverse de
!>     L D L**T - sigma I en combinant les transformations ci-dessus, et en choisissant
!>     r comme l'indice où la diagonale de l'inverse est (un des)
!>     plus grands en magnitude.
!> (d) Calcul de la colonne r (mise à l'échelle) de l'inverse en utilisant la
!>     factorisation tordue obtenue en combinant la partie supérieure de la
!>     transformation stationnaire et la partie inférieure de la transformation progressive.
!>

Paramètres

N 
!>          N est ENTIER
!>           L'ordre de la matrice L D L**T.
!>

B1

!>          B1 est ENTIER
!>           Premier indice de la sous-matrice de L D L**T.
!>

BN

!>          BN est ENTIER
!>           Dernier indice de la sous-matrice de L D L**T.
!>

LAMBDA

!>          LAMBDA est DOUBLE PRECISION
!>           Le décalage. Afin de calculer un vecteur propre précis,
!>           LAMBDA doit être une bonne approximation d'une valeur propre
!>           de L D L**T.
!>

L

!>          L est tableau DOUBLE PRECISION, dimension (N-1)
!>           Les (n-1) éléments sous-diagonaux de la matrice bidiagonale unitaire
!>           L, dans les éléments 1 à N-1.
!>

D

!>          D est tableau DOUBLE PRECISION, dimension (N)
!>           Les n éléments diagonaux de la matrice diagonale D.
!>

LD

!>          LD est tableau DOUBLE PRECISION, dimension (N-1)
!>           Les n-1 éléments L(i)*D(i).
!>

LLD

!>          LLD est tableau DOUBLE PRECISION, dimension (N-1)
!>           Les n-1 éléments L(i)*L(i)*D(i).
!>

PIVMIN

!>          PIVMIN est DOUBLE PRECISION
!>           Le pivot minimum dans la suite de Sturm.
!>

GAPTOL

!>          GAPTOL est DOUBLE PRECISION
!>           Tolérance indiquant quand les éléments du vecteur propre sont négligeables
!>           par rapport à leur contribution au résidu.
!>

Z

!>          Z est tableau DOUBLE PRECISION, dimension (N)
!>           À l'entrée, toutes les entrées de Z doivent être mises à 0.
!>           À la sortie, Z contient la colonne r (mise à l'échelle) de l'inverse.
!>           La mise à l'échelle est telle que Z(R) vaut 1.
!>

WANTNC

!>          WANTNC est LOGIQUE
!>           Spécifie si NEGCNT doit être calculé.
!>

NEGCNT

!>          NEGCNT est ENTIER
!>           Si WANTNC est .VRAI. alors NEGCNT = le nombre de pivots < pivmin
!>           dans la factorisation matricielle L D L**T, et NEGCNT = -1 sinon.
!>

ZTZ

!>          ZTZ est DOUBLE PRECISION
!>           Le carré de la norme 2 de Z.
!>

MINGMA

!>          MINGMA est DOUBLE PRECISION
!>           L'inverse du plus grand élément diagonal (en magnitude) de
!>           l'inverse de L D L**T - sigma I.
!>

R

!>          R est ENTIER
!>           L'indice de torsion pour la factorisation tordue utilisée pour
!>           calculer Z.
!>           À l'entrée, 0 <= R <= N. Si R est entré comme 0, R est défini comme
!>           l'indice où (L D L**T - sigma I)^{-1} est le plus grand en magnitude.
!>           Si 1 <= R <= N, R n'est pas modifié.
!>           À la sortie, R contient l'indice de torsion utilisé pour calculer Z.
!>           Idéalement, R désigne la position de l'élément maximum dans le
!>           vecteur propre.
!>

ISUPPZ

!>          ISUPPZ est tableau ENTIER, dimension (2)
!>           Le support du vecteur Z, c'est-à-dire que le vecteur Z est
!>           non nul seulement dans les éléments ISUPPZ(1) à ISUPPZ( 2 ).
!>

NRMINV

!>          NRMINV est DOUBLE PRECISION
!>           NRMINV = 1/SQRT( ZTZ )
!>

RESID

!>          RESID est DOUBLE PRECISION
!>           Le résidu du vecteur FP.
!>           RESID = ABS( MINGMA )/SQRT( ZTZ )
!>

RQCORR

!>          RQCORR est DOUBLE PRECISION
!>           La correction du Quotient de Rayleigh à LAMBDA.
!>           RQCORR = MINGMA*TMP
!>

WORK

!>          WORK est tableau DOUBLE PRECISION, dimension (4*N)
!>
