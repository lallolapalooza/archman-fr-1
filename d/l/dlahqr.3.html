    NAME

    dlahqr - compute the eigenvalues and eigenvectors of aasitriangular matrix

    SYNOPSIS

    SUBROUTINE DLАНQR(WANTZ, N, ILO, IHI, L, W, Z, LDZ, WORK, INFO)

  LOGICAL WANTZ
  INTEGER N, ILO, IHI, LDZ, INFO
  DOUBLE PRECISION L( … ), W( … ), Z( LDZ, … ), WORK( … )

    DESCRIPTION

    dlahqr is a subroutine that computes the eigenvalues and, optionally, the right eigenvectors of a real upper Hessenberg matrix. The eigenvalues are computed in the upper triangular matrix L, and the right eigenvectors are returned in the matrix Z.

    The matrix L is of the form

    L = ( T Y ) ( 0 B )

    where T is an upper triangular matrix containing the eigenvalues of the original matrix, and B is an upper triangular matrix containing the remaining eigenvalues. Y and 0 are matrices of appropriate dimensions.

    The right eigenvectors are computed such that L*Z = Z*D, where D is a diagonal matrix containing the eigenvalues.

    PARAMETERS

    • WANTZ (input) LOGICAL

      If WANTZ is true, then the right eigenvectors of L are computed.

    • N (input) INTEGER

      The order of the matrix L. 1 <= N.

    • ILO (input) INTEGER

      The starting row and column index of the submatrix of L to be reduced. 1 <= ILO <= IHI <= N.

    • IHI (input) INTEGER

      The ending row and column index of the submatrix of L to be reduced. ILO <= IHI <= N.

    • L (input/output) DOUBLE PRECISION array, dimension ( ... )

      On entry, L contains the upper Hessenberg matrix. On exit, L is replaced by the upper triangular matrix L.

    • W (output) DOUBLE PRECISION array, dimension (N)

      The eigenvalues of L. If WANTZ is true, the eigenvalues are sorted in ascending order.

    • Z (output) DOUBLE PRECISION array, dimension (LDZ, N)

      If WANTZ is true, Z contains the corresponding right eigenvectors. The normalized eigenvector corresponding to the k-th eigenvalue is stored in the k-th column of Z.

    • LDZ (input) INTEGER

      The leading dimension of the array Z. LDZ >= max(1, N).

    • WORK (workspace) DOUBLE PRECISION array, dimension (N)

      A workspace array used by the subroutine.

    • INFO (output) INTEGER

      INFO = 0: successful exit.

      INFO < 0: if INFO = -i, the i-th argument had an illegal value.

      INFO > 0: if INFO = i, the QR algorithm failed to compute all the eigenvalues. The upper triangular matrix L contains the eigenvalues in its diagonal. The remaining eigenvalues may be found in the submatrix L(IHI+1:N, IHI+1:N).

    DIAGNOSTICS

    The same as for dgeev.
