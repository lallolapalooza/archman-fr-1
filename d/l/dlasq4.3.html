Documentation de la fonction/sous-programme

sous-programme dlasq4 (entier i0, entier n0, double précision, dimension( * ) z, entier pp, entier n0in, double précision dmin, double précision dmin1, double précision dmin2, double précision dn, double précision dn1, double précision dn2, double précision tau, entier ttype, double précision g)

DLASQ4 calcule une approximation TAU de la plus petite valeur propre en utilisant les valeurs de d de la transformation précédente. Utilisé par sbdsqr.

Objectif :

!>
!> DLASQ4 calcule une approximation TAU de la plus petite valeur propre
!> en utilisant les valeurs de d de la transformation précédente.
!>

Paramètres

I0 
!>          I0 est un ENTIER
!>        Premier indice.
!>

N0

!>          N0 est un ENTIER
!>        Dernier indice.
!>

Z

!>          Z est un tableau de DOUBLE PRÉCISION, dimension ( 4*N0 )
!>        Z contient le tableau qd.
!>

PP

!>          PP est un ENTIER
!>        PP=0 pour ping, PP=1 pour pong.
!>

N0IN

!>          N0IN est un ENTIER
!>        La valeur de N0 au début de EIGTEST.
!>

DMIN

!>          DMIN est un DOUBLE PRÉCISION
!>        Valeur minimale de d.
!>

DMIN1

!>          DMIN1 est un DOUBLE PRÉCISION
!>        Valeur minimale de d, excluant D( N0 ).
!>

DMIN2

!>          DMIN2 est un DOUBLE PRÉCISION
!>        Valeur minimale de d, excluant D( N0 ) et D( N0-1 ).
!>

DN

!>          DN est un DOUBLE PRÉCISION
!>        d(N)
!>

DN1

!>          DN1 est un DOUBLE PRÉCISION
!>        d(N-1)
!>

DN2

!>          DN2 est un DOUBLE PRÉCISION
!>        d(N-2)
!>

TAU

!>          TAU est un DOUBLE PRÉCISION
!>        Ceci est le décalage.
!>

TTYPE

!>          TTYPE est un ENTIER
!>        Type de décalage.
!>

G

!>          G est un DOUBLE PRÉCISION
!>        G est passé en argument afin de sauvegarder sa valeur entre
!>        les appels à DLASQ4.
!>
