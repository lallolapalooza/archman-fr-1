sous-routine dlasd3 (nl, nr, sqre, k, d, q, ldq, dsigma, u, ldu, u2, ldu2, vt, ldvt, vt2, ldvt2, idxc, ctot, z, info)
DLASD3 trouve toutes les racines carrées des racines de l'équation séculaire, telles que définies par les valeurs dans D et Z, puis met à jour les vecteurs singuliers par multiplication matricielle. Utilisé par sbdsdc.

DLASD3 trouve toutes les racines carrées des racines de l'équation séculaire, telles que définies par les valeurs dans D et Z, puis met à jour les vecteurs singuliers par multiplication matricielle. Utilisé par

sbdsdc.

But

: 
!>
!> DLASD3 trouve toutes les racines carrées des racines de l'équation
!> séculaire, telles que définies par les valeurs dans D et Z.  Elle effectue
!> les appels appropriés à DLASD4 puis met à jour les vecteurs
!> singuliers par multiplication matricielle.
!>
!> DLASD3 est appelée depuis DLASD1.
!
>

Paramètre

s
NL 
!>          NL est INTEGER
!>         La dimension des lignes du bloc supérieur.  NL >= 1.
!
>

N

R 
!>          NR est INTEGER
!>         La dimension des lignes du bloc inférieur.  NR >= 1.
!
>

SQR

E 
!>          SQRE est INTEGER
!>         = 0 : le bloc inférieur est une matrice carrée NR par NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR par (NR+1).
!>
!>         La matrice bidiagonale a N = NL + NR + 1 lignes et
!>         M = N + SQRE >= N colonnes.
!
>

K 
!>          K est INTEGER
!>         L'ordre de l'équation séculaire, 1 =< K = < N.
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension(K)
!>         À la sortie, les racines carrées des racines de l'équation séculaire,
!>         dans l'ordre croissant.
!
>

Q 
!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ,K)
!
>

LD

Q 
!>          LDQ est INTEGER
!>         La dimension principale du tableau Q.  LDQ >= K.
!
>

DSIGM

A 
!>          DSIGMA est un tableau DOUBLE PRECISION, dimension(K)
!>         Les K premiers éléments de ce tableau contiennent les anciennes
!>         racines du problème de mise à jour déflaté.  Ce sont les pôles
!>         de l'équation séculaire.
!
>

U 
!>          U est un tableau DOUBLE PRECISION, dimension (LDU, N)
!>         Les N - K dernières colonnes de cette matrice contiennent les
!>         vecteurs singuliers gauches déflatés.
!
>

LD

U 
!>          LDU est INTEGER
!>         La dimension principale du tableau U.  LDU >= N.
!
>

U

2 
!>          U2 est un tableau DOUBLE PRECISION, dimension (LDU2, N)
!>         Les K premières colonnes de cette matrice contiennent les vecteurs
!>         singuliers gauches non déflatés du problème scindé.
!
>

LDU

2 
!>          LDU2 est INTEGER
!>         La dimension principale du tableau U2.  LDU2 >= N.
!
>

V

T 
!>          VT est un tableau DOUBLE PRECISION, dimension (LDVT, M)
!>         Les M - K dernières colonnes de VT**T contiennent les vecteurs
!>         singuliers droits déflatés.
!
>

LDV

T 
!>          LDVT est INTEGER
!>         La dimension principale du tableau VT.  LDVT >= N.
!
>

VT

2 
!>          VT2 est un tableau DOUBLE PRECISION, dimension (LDVT2, N)
!>         Les K premières colonnes de VT2**T contiennent les vecteurs
!>         singuliers droits non déflatés du problème scindé.
!
>

LDVT

2 
!>          LDVT2 est INTEGER
!>         La dimension principale du tableau VT2.  LDVT2 >= N.
!
>

IDX

C 
!>          IDXC est un tableau INTEGER, dimension ( N )
!>         La permutation utilisée pour disposer les colonnes de U (et les lignes
!>         de VT) en trois groupes : le premier groupe ne contient que des
!>         éléments non nuls à et au-dessus de (ou avant) NL +1 ; le deuxième
!>         ne contient que des éléments non nuls à et en dessous de (ou après)
!>         NL+2 ; et le troisième est dense. La première colonne de U et la
!>         ligne de VT sont cependant traitées séparément.
!>
!>         Les lignes des vecteurs singuliers trouvés par DLASD4
!>         doivent être permutées de la même manière avant que les
!>         multiplications matricielles puissent avoir lieu.
!
>

CTO

T 
!>          CTOT est un tableau INTEGER, dimension ( 4 )
!>         Un décompte du nombre total des différents types de colonnes
!>         dans U (ou de lignes dans VT), comme décrit dans IDXC. Le quatrième
!>         type de colonne est toute colonne qui a été déflatée.
!
>

Z 
!>          Z est un tableau DOUBLE PRECISION, dimension(K)
!>         Les K premiers éléments de ce tableau contiennent les composantes
!>         du vecteur ligne de mise à jour ajusté par déflation.
!
>

INF

O 
!>          INFO est INTEGER
!>         = 0 :  sortie réussie.
!>         < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>         > 0 :  si INFO = 1, une valeur singulière n'a pas convergé
!
>
