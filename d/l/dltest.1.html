NOM

dltest - Un programme simple de test de symboles de bibliothèque

SYNTAXE

dltest [ bibliothèque symbole ]

DESCRIPTION

dltest est un programme simple qui détermine si un symbole apparaît dans une bibliothèque (objet partagé).

Le nom de la bibliothèque doit être précédé d'un chemin système complet.

Si aucun paramètre n'est fourni, dltest affiche un bref message d'aide.

EXEMPLES

Pour déterminer si le symbole printf est trouvé dans libc-2.18.so, exécutez :

$ dltest /usr/lib/libc-2.18.so printf
