sous-programme dla_porfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, logical colequ, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, double precision, dimension( * ) res, double precision, dimension(*) ayb, double precision, dimension( * ) dy, double precision, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

DLA_PORFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires pour les matrices symétriques ou hermitiennes définies positives en effectuant un raffinement itératif de précision supplémentaire et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.

Objectif :

!>
!> DLA_PORFSX_EXTENDED améliore la solution calculée d'un système d'équations
!> linéaires en effectuant un raffinement itératif de précision supplémentaire
!> et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.
!> Ce sous-programme est appelé par DPORFSX pour effectuer le raffinement itératif.
!> En plus de la borne d'erreur normwise, le code fournit une borne d'erreur
!> composante par composante maximale si possible. Voir les commentaires pour
!> ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des bornes d'erreur. Notez que ce
!> sous-programme est seulement responsable de la définition des seconds champs de
!> ERR_BNDS_NORM et ERR_BNDS_COMP.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser dans le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un CARACTÈRE et P
!>          = 'S':  Simple
!>          = 'D':  Double
!>          = 'I':  Indigène
!>          = 'X' ou 'E':  Extra
!>

UPLO

!>          UPLO est CHARACTER*1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N×N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau DOUBLE PRECISION, de dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T, tel que calculé par DPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .VRAI. alors l'équilibration des colonnes a été effectuée sur A avant d'appeler
!>     ce sous-programme. Ceci est nécessaire pour calculer correctement la solution et les
!>     bornes d'erreur.
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FAUX., C
!>     n'est pas accédé. Si C est entré, chaque élément de C doit être une puissance
!>     de la base (radix) pour garantir une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances de la base ne provoque pas d'erreurs d'arrondi, sauf
!>     si le résultat sousflue ou déborde. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui pourraient ne pas être
!>     fiables.
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (LDB,NRHS)
!>     La matrice des côtés droits B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

Y

!>          Y est un tableau DOUBLE PRECISION, de dimension (LDY,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par DPOTRS.
!>     À la sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension principale du tableau Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>     À la sortie, BERR_OUT(j) contient l'erreur relative par composante arrière
!>     pour le j-ième côté droit de la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par DLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur retourner (voir ERR_BNDS_NORM
!>     et ERR_BNDS_COMP).
!>     Si N_NORMS >= 1, retourne des bornes d'erreur normwise.
!>     Si N_NORMS >= 2, retourne des bornes d'erreur par composante.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque côté droit, ce tableau contient des informations sur
!>     diverses bornes d'erreur et numéros de condition correspondant à
!>     l'erreur relative normwise, qui est définie comme suit :
!>
!>     Erreur relative normwise dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     côté droit.
!>
!>     Le second indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              numéro de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque
certainement dans un facteur 10 de l'erreur réelle !> tant que l'entrée suivante est supérieure au seuil !> sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait !> être considérée comme fiable que si le booléen précédent est vrai. !> !> err = 3 Nombre de condition réciproque : Estimation du nombre !> de condition réciproque au sens de la norme. Comparé au seuil !> sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation !> d'erreur est . Ces nombres de condition réciproques !> sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une !> matrice Z correctement mise à l'échelle. !> Soit Z = S*A, où S met chaque ligne à l'échelle par une puissance !> de la base afin que toutes les sommes absolues de lignes de Z soient !> approximativement égales à 1. !> !> Cette sous-routine est uniquement responsable du réglage du deuxième champ !> ci-dessus. !> Voir Lapack Working Note 165 pour plus de détails et de précautions !> supplémentaires. !>

ERR_BNDS_COM

P 
!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le ième vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (sur lequel
!>     l'erreur relative composante par composante dépend), et le type d'information
!>     d'erreur tel que décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations retournées pour chaque second membre. Si
!>     la précision composante par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au ième
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur directe estimée,
!>              certainement dans un facteur 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être considérée comme fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Estimation du nombre
!>              de condition réciproque composante par composante. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces nombres de condition réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z correctement mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met chaque ligne de
!>              A*diag(x) à l'échelle par une puissance de la base afin que toutes les sommes
!>              absolues de lignes de Z soient approximativement égales à 1.
!>
!>     Cette sous-routine est uniquement responsable du réglage du deuxième champ
!>     ci-dessus.
!>     Voir Lapack Working Note 165 pour plus de détails et de précautions
!>     supplémentaires.
!
>

RE

S 
!>          RES est un tableau DOUBLE PRECISION, de dimension (N)
!>     Espace de travail pour stocker le résidu intermédiaire.
!
>

AY

B 
!>          AYB est un tableau DOUBLE PRECISION, de dimension (N)
!>     Espace de travail. Cela peut être le même espace de travail passé pour Y_TAIL.
!
>

D

Y 
!>          DY est un tableau DOUBLE PRECISION, de dimension (N)
!>     Espace de travail pour stocker la solution intermédiaire.
!
>

Y_TAI

L 
!>          Y_TAIL est un tableau DOUBLE PRECISION, de dimension (N)
!>     Espace de travail pour stocker les bits de poids faible de la solution intermédiaire.
!
>

RCON

D 
!>          RCOND est DOUBLE PRECISION
!>     Nombre de condition réciproque mis à l'échelle. C'est une estimation du
!>     nombre de condition réciproque de Skeel de la matrice A après
!>     équilibrage (si effectué). Si cela est inférieur à la précision
!>     machine (en particulier, si c'est zéro), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut encore être petite même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!
>

ITHRES

H 
!>          ITHRESH est INTEGER
!>     Le nombre maximal de calculs de résidu autorisés pour
!>     l'affinage. La valeur par défaut est 10. Pour 'aggressive' mettre à 100 pour
!>     permettre la convergence en utilisant des factorisations approchées ou
!>     des factorisations autres que LU. Si la factorisation utilise une
!>     technique autre que l'élimination de Gauss, les garanties dans
!>     ERR_BNDS_NORM et ERR_BNDS_COMP peuvent ne plus être fiables.
!
>

RTHRES

H 
!>          RTHRESH est DOUBLE PRECISION
!>     Détermine quand arrêter l'affinage si l'estimation d'erreur cesse
!>     de diminuer. L'affinage s'arrêtera quand la solution suivante ne
!>     satisfait plus norm(dx_{i+1}) < RTHRESH * norm(dx_i) où norm(Z) est
!>     la norme infinie de Z. RTHRESH satisfait 0 < RTHRESH <= 1. La
!>     valeur par défaut est 0.5. Pour 'aggressive' mettre à 0.9 pour permettre
!>     la convergence sur des matrices extrêmement mal conditionnées. Voir LAWN 165
!>     pour plus de détails.
!
>

DZ_U

B 
!>          DZ_UB est DOUBLE PRECISION
!>     Détermine quand commencer à considérer la convergence composante par composante.
!>     La convergence composante par composante n'est considérée qu'après que chaque composante
!>     de la solution Y est stable, ce que nous définissons comme le changement
!>     relatif dans chaque composante étant inférieur à DZ_UB. La valeur par défaut
!>     est 0.25, exigeant que le premier bit soit stable. Voir LAWN 165 pour
!>     plus de détails.
!
>

IGNORE_CWIS

E 
!>          IGNORE_CWISE est LOGICAL
!>     Si .TRUE. alors ignorer la convergence composante par composante. La valeur par défaut
!>     est .FALSE..
!
>

INF

O 
!>          INFO est INTEGER
!>       = 0:  Sortie réussie.
!>       < 0:  si INFO = -i, le ième argument de DPOTRS avait une valeur
!>             illégale
!>
