subroutine dlatps (character uplo, character trans, character diag, character normin, integer n, double precision, dimension( * ) ap, double precision, dimension( * ) x, double precision scale, double precision, dimension( * ) cnorm, integer

info)

DLATPS résout un système d'équations triangulaire avec la matrice stockée sous forme

compacte.

But

: 
!>
!> DLATPS résout l'un des systèmes triangulaires
!>
!>    A *x = s*b  ou  A**T*x = s*b
!>
!> avec une mise à l'échelle pour empêcher le débordement, où A est une
!> matrice triangulaire supérieure ou inférieure stockée sous forme
!> compacte. Ici, A**T désigne la transposée de A, x et b sont des
!> vecteurs à n éléments, et s est un facteur d'échelle, généralement
!> inférieur ou égal à 1, choisi de sorte que les composantes de x
!> soient inférieures au seuil de débordement. Si le problème non mis à
!> l'échelle ne causera pas de débordement, la routine BLAS de niveau 2
!> DTPSV est appelée. Si la matrice A est singulière (A(j,j) = 0 pour
!> un certain j), alors s est mis à 0 et une solution non triviale à
!> A*x = 0 est retournée.
!
>

Paramètre

s
UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U' :  Triangulaire supérieure
!>          = 'L' :  Triangulaire inférieure
!
>

TRAN

S 
!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N' :  Résoudre A * x = s*b  (Pas de transposition)
!>          = 'T' :  Résoudre A**T* x = s*b  (Transposition)
!>          = 'C' :  Résoudre A**T* x = s*b  (Transposée conjuguée = Transposition)
!
>

DIA

G 
!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N' :  Triangulaire non unitaire
!>          = 'U' :  Triangulaire unitaire
!
>

NORMI

N 
!>          NORMIN est CHARACTER*1
!>          Spécifie si CNORM a été défini ou non.
!>          = 'Y' :  CNORM contient les normes de colonne à l'entrée
!>          = 'N' :  CNORM n'est pas défini à l'entrée. À la sortie, les normes seront
!>                  calculées et stockées dans CNORM.
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!
>

A

P 
!>          AP est un tableau DOUBLE PRECISION, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compactée par colonne dans
!>          un tableau linéaire. La j-ième colonne de A est stockée dans le tableau
!>          AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!
>

X 
!>          X est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, le membre de droite b du système triangulaire.
!>          À la sortie, X est écrasé par le vecteur solution x.
!
>

SCAL

E 
!>          SCALE est DOUBLE PRECISION
!>          Le facteur d'échelle s pour le système triangulaire
!>             A * x = s*b  ou  A**T* x = s*b.
!>          Si SCALE = 0, la matrice A est singulière ou mal mise à l'échelle, et
!>          le vecteur x est une solution exacte ou approchée à A*x = 0.
!
>

CNOR

M 
!>          CNORM est un tableau DOUBLE PRECISION, dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM est un argument d'entrée et CNORM(j)
!>          contient la norme de la partie hors diagonale de la j-ième colonne
!>          de A. Si TRANS = 'N', CNORM(j) doit être supérieur ou égal
!>          à la norme d'infini, et si TRANS = 'T' ou 'C', CNORM(j)
!>          doit être supérieur ou égal à la norme 1.
!>
!>          Si NORMIN = 'N', CNORM est un argument de sortie et CNORM(j)
!>          retourne la norme 1 de la partie hors diagonale de la j-ième colonne
!>          de A.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -k, le k-ième argument avait une valeur illégale
!
>

Détails supplémentaires

: 
!>
!>  Une borne approximative sur x est calculée ; si celle-ci est inférieure au débordement, DTPSV
!>  est appelé, sinon, un code spécifique est utilisé qui vérifie les débordements
!>  ou les divisions par zéro possibles à chaque opération.
!>
!>  Un schéma par colonne est utilisé pour résoudre A*x = b. L'algorithme de base
!>  si A est triangulaire inférieure est
!>
!>       x[1:n] := b[1:n]
!>       pour j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!>  Définir des bornes sur les composantes de x après j itérations de la boucle :
!>     M(j) = borne sur x[1:j]
!>     G(j) = borne sur x[j+1:n]
!>  Initialement, posons M(0) = 0 et G(0) = max{x(i), i=1,...,n}.
!>
!>  Alors pour l'itération j+1 nous avons
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!>  où CNORM(j+1) est supérieur ou égal à la norme d'infini de
!>  la colonne j+1 de A, sans compter la diagonale. Donc
!>
!>     G(j) <= G(0) produit ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!>  et
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) produit ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!>  Puisque |x(j)| <= M(j), nous utilisons la routine BLAS de niveau 2 DTPSV si le
!>  réciproque du plus grand M(j), j=1,..,n, est plus grand que
!>  max(underflow, 1/overflow).
!>
!>  La borne sur x(j) est également utilisée pour déterminer quand une étape dans la
!>  méthode par colonne peut être effectuée sans crainte de débordement. Si
!>  la borne calculée est supérieure à une grande constante, x est mis à l'échelle pour
!>  empêcher le débordement, mais si la borne déborde, x est mis à 0, x(j) à
!>  1, et scale à 0, et une solution non triviale à A*x = 0 est trouvée.
!>
!>  De même, un schéma par ligne est utilisé pour résoudre A**T*x = b. L'algorithme
!>  de base pour A triangulaire supérieure est
!>
!>       pour j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>       fin
!>
!>  Nous calculons simultanément deux bornes
!>       G(j) = borne sur ( b(i) - A[1:i-1,i]**T * x[1:i-1] ), 1<=i<=j
!>       M(j) = borne sur x(i), 1<=i<=j
!>
!>  Les valeurs initiales sont G(0) = 0, M(0) = max{b(i), i=1,..,n}, et nous
!>  ajoutons la contrainte G(j) >= G(j-1) et M(j) >= M(j-1) pour j >= 1.
!>  Alors la borne sur x(j) est
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * produit ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!>  et nous pouvons appeler DTPSV en toute sécurité si 1/M(n) et 1/G(n) sont tous deux supérieurs
!>  à max(underflow, 1/overflow).
!
>
