sous-programme dlasq5 (i0, n0, z, pp, tau, sigma, dmin, dmin1, dmin2, dn, dnm1, dnm2, ieee, eps)
DLASQ5 calcule une transformation dqds sous forme ping-pong. Utilisé par sbdsqr et sstegr.

Documentation de la fonction/sous-programme

sous-programme dlasq5 (integer i0, integer n0, double precision, dimension( * ) z, integer pp, double precision tau, double precision sigma, double precision dmin, double precision dmin1, double precision dmin2, double precision dn, double precision dnm1, double precision dnm2, logical ieee, double precision eps)

DLASQ5 calcule une transformation dqds sous forme ping-pong. Une version pour machines IEEE et une autre pour machines non IEEE.

Objectif :

!>
!> DLASQ5 calcule une transformation dqds sous forme ping-pong,
!> une version pour les machines IEEE et une autre pour les machines non IEEE.
!>

Paramètres

I0 
!>          I0 est un ENTIER
!>        Premier indice.
!>

N0

!>          N0 est un ENTIER
!>        Dernier indice.
!>

Z

!>          Z est un tableau de DOUBLE PRÉCISION, dimension ( 4*N )
!>        Z contient le tableau qd. EMIN est stocké dans Z(4*N0) pour éviter
!>        un argument supplémentaire.
!>

PP

!>          PP est un ENTIER
!>        PP=0 pour ping, PP=1 pour pong.
!>

TAU

!>          TAU est un DOUBLE PRÉCISION
!>        C'est le décalage.
!>

SIGMA

!>          SIGMA est un DOUBLE PRÉCISION
!>        C'est le décalage accumulé jusqu'à cette étape.
!>

DMIN

!>          DMIN est un DOUBLE PRÉCISION
!>        Valeur minimale de d.
!>

DMIN1

!>          DMIN1 est un DOUBLE PRÉCISION
!>        Valeur minimale de d, excluant D( N0 ).
!>

DMIN2

!>          DMIN2 est un DOUBLE PRÉCISION
!>        Valeur minimale de d, excluant D( N0 ) et D( N0-1 ).
!>

DN

!>          DN est un DOUBLE PRÉCISION
!>        d(N0), la dernière valeur de d.
!>

DNM1

!>          DNM1 est un DOUBLE PRÉCISION
!>        d(N0-1).
!>

DNM2

!>          DNM2 est un DOUBLE PRÉCISION
!>        d(N0-2).
!>

IEEE

!>          IEEE est un LOGIQUE
!>        Indicateur pour l'arithmétique IEEE ou non IEEE.
!>

EPS

!>          EPS est un DOUBLE PRÉCISION
!>        C'est la valeur d'epsilon utilisée.
!>
