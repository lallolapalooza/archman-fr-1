subroutine dlaed8 (integer icompq, integer k, integer n, integer qsiz, double precision, dimension( * ) d, double precision, dimension( ldq, * ) q, integer ldq, integer, dimension( * ) indxq, double precision rho, integer cutpnt, double precision, dimension( * ) z, double precision, dimension( * ) dlambda, double precision, dimension( ldq2, * ) q2, integer ldq2, double precision, dimension( * ) w, integer, dimension( * ) perm, integer givptr, integer, dimension( 2, * ) givcol, double precision, dimension( 2, * ) givnum, integer, dimension( * ) indxp, integer, dimension( * ) indx, integer

DLAED8 utilisé par DSTEDC. Fusionne les valeurs propres et met en déflation l'équation séculière. Utilisé lorsque la matrice d'origine est

dense.

But

: 
!>
!> DLAED8 fusionne les deux ensembles de valeurs propres en un ensemble unique
!> trié. Il essaie ensuite de réduire la taille du problème par déflation.
!> Il existe deux façons dont la déflation peut survenir : lorsque deux valeurs
!> propres ou plus sont proches l'une de l'autre, ou s'il existe un élément
!> minuscule dans le vecteur Z. Pour chaque occurrence de ce type, l'ordre du
!> problème d'équation séculière associé est réduit d'une unité.
!
>

Paramètre

s
ICOMPQ 
!>          ICOMPQ est INTEGER
!>          = 0 :  Calculer uniquement les valeurs propres.
!>          = 1 :  Calculer aussi les vecteurs propres de la matrice symétrique
!>                dense d'origine. À l'entrée, Q contient la matrice orthogonale
!>                utilisée pour réduire la matrice d'origine à une forme
!>                tridiagonale.
!
>

K 
!>          K est INTEGER
!>         Le nombre de valeurs propres non déflatées, et l'ordre de
!>         l'équation séculière associée.
!
>

N 
!>          N est INTEGER
!>         La dimension de la matrice symétrique tridiagonale. N >= 0.
!
>

QSI

Z 
!>          QSIZ est INTEGER
!>         La dimension de la matrice orthogonale utilisée pour réduire
!>         la matrice complète à une forme tridiagonale. QSIZ >= N si ICOMPQ = 1.
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>         À l'entrée, les valeurs propres des deux sous-matrices à
!>         combiner. À la sortie, les (N-K) valeurs propres mises à jour
!>         (celles qui ont été déflatées) triées par ordre croissant.
!
>

Q 
!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ,N)
!>         Si ICOMPQ = 0, Q n'est pas référencé. Sinon,
!>         à l'entrée, Q contient les vecteurs propres du système partiellement
!>         résolu qui a été précédemment mis à jour lors de multiplications
!>         matricielles avec d'autres systèmes propres partiellement résolus.
!>         À la sortie, Q contient les (N-K) vecteurs propres mis à jour
!>         (ceux qui ont été déflatés) dans ses N-K dernières colonnes.
!
>

LD

Q 
!>          LDQ est INTEGER
!>         La dimension principale du tableau Q. LDQ >= max(1,N).
!
>

INDX

Q 
!>          INDXQ est un tableau INTEGER, dimension (N)
!>         La permutation qui trie séparément les deux sous-problèmes
!>         en D par ordre croissant. Notez que les éléments de la seconde
!>         moitié de cette permutation doivent d'abord avoir CUTPNT ajouté
!>         à leurs valeurs afin d'être précis.
!
>

RH

O 
!>          RHO est DOUBLE PRECISION
!>         À l'entrée, l'élément hors-diagonale associé à la coupe de rang 1
!>         qui a initialement divisé les deux sous-matrices qui sont maintenant
!>         recombinais.
!>         À la sortie, RHO a été modifié à la valeur requise par
!>         DLAED3.
!
>

CUTPN

T 
!>          CUTPNT est INTEGER
!>         La position de la dernière valeur propre dans la
!>         sous-matrice principale. min(1,N) <= CUTPNT <= N.
!
>

Z 
!>          Z est un tableau DOUBLE PRECISION, dimension (N)
!>         À l'entrée, Z contient le vecteur de mise à jour (la dernière ligne
!>         de la première matrice de sous-vecteurs propres et la première ligne
!>         de la seconde matrice de sous-vecteurs propres).
!>         À la sortie, le contenu de Z est détruit par le processus de mise à jour.
!
>

DLAMBD

A 
!>          DLAMBDA est un tableau DOUBLE PRECISION, dimension (N)
!>         Une copie des K premières valeurs propres qui seront utilisées par
!>         DLAED3 pour former l'équation séculière.
!
>

Q

2 
!>          Q2 est un tableau DOUBLE PRECISION, dimension (LDQ2,N)
!>         Si ICOMPQ = 0, Q2 n'est pas référencé. Sinon,
!>         une copie des K premiers vecteurs propres qui seront utilisés par
!>         DLAED7 dans une multiplication matricielle (DGEMM) pour mettre à jour
!>         les nouveaux vecteurs propres.
!
>

LDQ

2 
!>          LDQ2 est INTEGER
!>         La dimension principale du tableau Q2. LDQ2 >= max(1,N).
!
>

W 
!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>         Les K premières valeurs du vecteur z finalement modifié par la
!>         déflation et qui seront passées à DLAED3.
!
>

PER

M 
!>          PERM est un tableau INTEGER, dimension (N)
!>         Les permutations (issues de la déflation et du tri) à appliquer
!>         à chaque bloc propre.
!
>

GIVPT

R 
!>          GIVPTR est INTEGER
!>         Le nombre de rotations de Givens qui ont eu lieu dans ce
!>         sous-problème.
!
>

GIVCO

L 
!>          GIVCOL est un tableau INTEGER, dimension (2, N)
!>         Chaque paire de nombres indique une paire de colonnes à utiliser
!>         dans une rotation de Givens.
!
>

GIVNU

M 
!>          GIVNUM est un tableau DOUBLE PRECISION, dimension (2, N)
!>         Chaque nombre indique la valeur S à utiliser dans la
!>         rotation de Givens correspondante.
!
>

INDX

P 
!>          INDXP est un tableau INTEGER, dimension (N)
!>         La permutation utilisée pour placer les valeurs déflatées de D à la fin
!>         du tableau. INDXP(1:K) pointe vers les valeurs de D non déflatées
!>         et INDXP(K+1:N) pointe vers les valeurs propres déflatées.
!
>

IND

X 
!>          INDX est un tableau INTEGER, dimension (N)
!>         La permutation utilisée pour trier le contenu de D par ordre
!>         croissant.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!
>
