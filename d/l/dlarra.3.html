sous-routine dlarra (n, d, e, e2, spltol, tnrm, nsplit, isplit, info)

DLARRA calcule les points de division avec le seuil spécifié.

Documentation de la fonction/sous-routine

sous-routine dlarra (integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) e2, double precision spltol, double precision tnrm, integer nsplit, integer, dimension( * ) isplit, integer info)

DLARRA calcule les points de division avec le seuil spécifié.

Objectif :

!>
!> Calculer les points de division avec le seuil SPLTOL.
!> DLARRA met à zéro tous les éléments hors diagonale.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice. N > 0.
!>

D

!>          D est un tableau de DOUBLE PRECISION, dimension (N)
!>          En entrée, les N éléments diagonaux de la matrice tridiagonale
!>          T.
!>

E

!>          E est un tableau de DOUBLE PRECISION, dimension (N)
!>          En entrée, les (N-1) premières entrées contiennent les éléments
!>          sous-diagonaux de la matrice tridiagonale T ; E(N) n'a pas besoin
!>          d'être défini.
!>          En sortie, les entrées E( ISPLIT( I ) ), 1 <= I <= NSPLIT,
!>          sont mises à zéro, les autres entrées de E ne sont pas modifiées.
!>

E2

!>          E2 est un tableau de DOUBLE PRECISION, dimension (N)
!>          En entrée, les (N-1) premières entrées contiennent les Carrés des
!>          éléments sous-diagonaux de la matrice tridiagonale T ;
!>          E2(N) n'a pas besoin d'être défini.
!>          En sortie, les entrées E2( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, ont été mises à zéro
!>

SPLTOL

!>          SPLTOL est un DOUBLE PRECISION
!>          Le seuil pour la division. Deux critères peuvent être utilisés :
!>          SPLTOL<0 : critère basé sur la valeur absolue hors diagonale
!>          SPLTOL>0 : critère qui préserve la précision relative
!>

TNRM

!>          TNRM est un DOUBLE PRECISION
!>          La norme de la matrice.
!>

NSPLIT

!>          NSPLIT est un entier (INTEGER)
!>          Le nombre de blocs dans lesquels T est divisé. 1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT est un tableau d'entiers (INTEGER), dimension (N)
!>          Les points de division, où T se divise en blocs.
!>          Le premier bloc comprend les lignes/colonnes 1 à ISPLIT(1),
!>          le second les lignes/colonnes ISPLIT(1)+1 à ISPLIT(2),
!>          etc., et le NSPLIT-ième bloc comprend les lignes/colonnes
!>          ISPLIT(NSPLIT-1)+1 à ISPLIT(NSPLIT)=N.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>
