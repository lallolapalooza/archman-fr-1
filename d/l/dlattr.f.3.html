sous-programme dlattr (entier imat, caractère uplo, caractère trans, caractère diag, entier, dimension( 4 ) iseed, entier n, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( * ) b, double précision, dimension( * ) work, entier info)

DLATTR

Objectif :

!>
!> DLATTR génère une matrice triangulaire de test.
!> IMAT et UPLO spécifient de manière unique les propriétés de la matrice de test,
!> qui est retournée dans le tableau A.
!>

Paramètres

IMAT 
!>          IMAT est un ENTIER
!>          Une clé entière décrivant quelle matrice générer pour ce chemin.
!>

UPLO

!>          UPLO est un CARACTÈRE*1
!>          Spécifie si la matrice A sera triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est un CARACTÈRE*1
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Transposée conjuguée (= Transposée)
!>

DIAG

!>          DIAG est un CARACTÈRE*1
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

ISEED

!>          ISEED est un tableau d'ENTIERS, de dimension (4)
!>          Le vecteur de départ pour le générateur de nombres aléatoires (utilisé dans
!>          DLATMS). Modifié à la sortie.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice à générer.
!>

A

!>          A est un tableau de DOUBLE PRÉCISION, de dimension (LDA,N)
!>          La matrice triangulaire A. Si UPLO = 'U', la partie supérieure triangulaire
!>          de dimension n par n de la matrice A contient la matrice triangulaire
!>          supérieure, et la partie strictement inférieure triangulaire de A n'est pas
!>          référencée. Si UPLO = 'L', la partie inférieure triangulaire de dimension
!>          n par n de la matrice A contient la matrice triangulaire inférieure, et la
!>          partie supérieure strictement triangulaire de A n'est pas référencée. Si
!>          DIAG = 'U', les éléments diagonaux de A sont définis de telle sorte que
!>          A(k,k) = k pour 1 <= k <= n.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau de DOUBLE PRÉCISION, de dimension (N)
!>          Le vecteur du second membre, si IMAT > 10.
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, de dimension (3*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  sortie réussie
!>          < 0: si INFO = -k, le k-ième argument avait une valeur illégale
!>
