subroutine dlarf (side, m, n, v, incv, tau, c, ldc, work)
DLARF applique un réflecteur élémentaire à une matrice rectangulaire générale.

Documentation de la fonction/sous-programme

sous-programme dlarf (character side, integer m, integer n, double precision, dimension( * ) v, integer incv, double precision tau, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) work)

DLARF applique un réflecteur élémentaire H à une matrice rectangulaire générale.

Objectif :

!>
!> DLARF applique un réflecteur élémentaire réel H à une matrice réelle m par n
!> C, soit à gauche, soit à droite. H est représenté sous la forme
!>
!>       H = I - tau * v * v**T
!>
!> où tau est un scalaire réel et v est un vecteur réel.
!>
!> Si tau = 0, alors H est considérée comme la matrice identité.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': forme  H * C
!>          = 'R': forme  C * H
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

V

!>          V est un tableau de DOUBLE PRECISION, de dimension
!>                     (1 + (M-1)*abs(INCV)) si SIDE = 'L'
!>                  ou (1 + (N-1)*abs(INCV)) si SIDE = 'R'
!>          Le vecteur v dans la représentation de H. V n'est pas utilisé si
!>          TAU = 0.
!>

INCV

!>          INCV est INTEGER
!>          L'incrément entre les éléments de v. INCV <> 0.
!>

TAU

!>          TAU est DOUBLE PRECISION
!>          La valeur tau dans la représentation de H.
!>

C

!>          C est un tableau de DOUBLE PRECISION, de dimension (LDC,N)
!>          À l'entrée, la matrice m par n C.
!>          À la sortie, C est écrasée par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, de dimension
!>                         (N) si SIDE = 'L'
!>                      ou (M) si SIDE = 'R'
!>
