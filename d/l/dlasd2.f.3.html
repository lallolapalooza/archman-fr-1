sous-routine dlasd2 (integer nl, integer nr, integer sqre, integer k, double precision, dimension( * ) d, double precision, dimension( * ) z, double precision alpha, double precision beta, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, double precision, dimension( * ) dsigma, double precision, dimension( ldu2, * ) u2, integer ldu2, double precision, dimension( ldvt2, * ) vt2, integer ldvt2, integer, dimension( * ) idxp, integer, dimension( * ) idx, integer, dimension( * ) idxc, integer, dimension( * ) idxq, integer, dimension( * ) coltyp, integer

DLASD2 fusionne les deux ensembles de valeurs singulières en un seul ensemble trié. Utilisé par

sbdsdc.

But

: 
!>
!> DLASD2 fusionne les deux ensembles de valeurs singulières en un seul
!> ensemble trié.  Il essaie ensuite de réduire la taille du problème.
!> Il existe deux façons pour qu'une déflation se produise : lorsque deux
!> valeurs singulières ou plus sont proches l'une de l'autre, ou s'il existe
!> une entrée minuscule dans le vecteur Z.  Pour chaque occurrence de ce type,
!> l'ordre du problème d'équation séculaire associé est réduit d'un.
!>
!> DLASD2 est appelé depuis DLASD1.
!
>

Paramètre

s
NL 
!>          NL est INTEGER
!>         La dimension des lignes du bloc supérieur.  NL >= 1.
!
>

N

R 
!>          NR est INTEGER
!>         La dimension des lignes du bloc inférieur.  NR >= 1.
!
>

SQR

E 
!>          SQRE est INTEGER
!>         = 0 : le bloc inférieur est une matrice carrée NR par NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR par (NR+1).
!>
!>         La matrice bidiagonale a N = NL + NR + 1 lignes et
!>         M = N + SQRE >= N colonnes.
!
>

K 
!>          K est INTEGER
!>         Contient la dimension de la matrice non déflée,
!>         C'est l'ordre de l'équation séculaire associée. 1 <= K <=N.
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension(N)
!>         À l'entrée, D contient les valeurs singulières des deux sous-matrices
!>         à combiner.  À la sortie, D contient les (N-K) valeurs singulières
!>         mises à jour restantes (celles qui ont été déflées), triées dans
!>         l'ordre croissant.
!
>

Z 
!>          Z est un tableau DOUBLE PRECISION, dimension(N)
!>         À la sortie, Z contient le vecteur de mise à jour dans l'équation
!>         séculaire.
!
>

ALPH

A 
!>          ALPHA est DOUBLE PRECISION
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!
>

BET

A 
!>          BETA est DOUBLE PRECISION
!>         Contient l'élément hors-diagonal associé à la ligne
!>         ajoutée.
!
>

U 
!>          U est un tableau DOUBLE PRECISION, dimension(LDU,N)
!>         À l'entrée, U contient les vecteurs singuliers gauches de deux
!>         sous-matrices dans les deux blocs carrés dont les coins sont à (1,1),
!>         (NL, NL), et (NL+2, NL+2), (N,N).
!>         À la sortie, U contient les (N-K) vecteurs singuliers gauches
!>         mis à jour restants (ceux qui ont été déflés) dans ses dernières
!>         N-K colonnes.
!
>

LD

U 
!>          LDU est INTEGER
!>         La dimension principale du tableau U.  LDU >= N.
!
>

V

T 
!>          VT est un tableau DOUBLE PRECISION, dimension(LDVT,M)
!>         À l'entrée, VT**T contient les vecteurs singuliers droits de deux
!>         sous-matrices dans les deux blocs carrés dont les coins sont à (1,1),
!>         (NL+1, NL+1), et (NL+2, NL+2), (M,M).
!>         À la sortie, VT**T contient les (N-K) vecteurs singuliers droits
!>         mis à jour restants (ceux qui ont été déflés) dans ses dernières
!>         N-K colonnes.
!>         Dans le cas SQRE =1, la dernière ligne de VT couvre l'espace
!>         nul droit.
!
>

LDV

T 
!>          LDVT est INTEGER
!>         La dimension principale du tableau VT.  LDVT >= M.
!
>

DSIGM

A 
!>          DSIGMA est un tableau DOUBLE PRECISION, dimension (N)
!>         Contient une copie des éléments diagonaux (K-1 valeurs singulières
!>         et un zéro) dans l'équation séculaire.
!
>

U

2 
!>          U2 est un tableau DOUBLE PRECISION, dimension(LDU2,N)
!>         Contient une copie des K-1 premiers vecteurs singuliers gauches qui
!>         seront utilisés par DLASD3 dans une multiplication de matrices (DGEMM)
!>         pour résoudre les nouveaux vecteurs singuliers gauches. U2 est
!>         organisé en quatre blocs. Le premier bloc contient une colonne avec 1
!>         à NL+1 et zéro partout ailleurs ; le second bloc contient des entrées
!>         non nulles uniquement à et au-dessus de NL ; le troisième contient des
!>         entrées non nulles uniquement en dessous de NL+1 ; et le quatrième est
!>         dense.
!
>

LDU

2 
!>          LDU2 est INTEGER
!>         La dimension principale du tableau U2.  LDU2 >= N.
!
>

VT

2 
!>          VT2 est un tableau DOUBLE PRECISION, dimension(LDVT2,N)
!>         VT2**T contient une copie des K premiers vecteurs singuliers droits
!>         qui seront utilisés par DLASD3 dans une multiplication de matrices
!>         (DGEMM) pour résoudre les nouveaux vecteurs singuliers droits. VT2 est
!>         organisé en trois blocs. Le premier bloc contient une ligne qui
!>         correspond à l'élément diagonal spécial 0 dans SIGMA ; le second bloc
!>         contient des éléments non nuls uniquement à et avant NL +1 ; le
!>         troisième bloc contient des éléments non nuls uniquement à et après
!>         NL +2.
!
>

LDVT

2 
!>          LDVT2 est INTEGER
!>         La dimension principale du tableau VT2.  LDVT2 >= M.
!
>

IDX

P 
!>          IDXP est un tableau INTEGER, dimension(N)
!>         Cela contiendra la permutation utilisée pour placer les valeurs
!>         déflées de D à la fin du tableau. En sortie IDXP(2:K)
!>         pointe vers les valeurs de D non déflées et IDXP(K+1:N)
!>         pointe vers les valeurs singulières déflées.
!
>

ID

X 
!>          IDX est un tableau INTEGER, dimension(N)
!>         Cela contiendra la permutation utilisée pour trier le contenu de
!>         D dans l'ordre croissant.
!
>

IDX

C 
!>          IDXC est un tableau INTEGER, dimension(N)
!>         Cela contiendra la permutation utilisée pour organiser les colonnes
!>         de la matrice U déflée en trois groupes : le premier groupe
!>         contient des entrées non nulles uniquement à et au-dessus de NL, le
!>         second contient des entrées non nulles uniquement en dessous de NL+2,
!>         et le troisième est dense.
!
>

IDX

Q 
!>          IDXQ est un tableau INTEGER, dimension(N)
!>         Cela contient la permutation qui trie séparément les deux
!>         sous-problèmes dans D dans l'ordre croissant.  Notez que les entrées
!>         dans la première moitié de cette permutation doivent d'abord être
!>         déplacées d'une position vers l'arrière ; et les entrées dans la
!>         seconde moitié doivent d'abord avoir NL+1 ajouté à leurs valeurs.
!
>

COLTY

P 
!>          COLTYP est un tableau INTEGER, dimension(N)
!>         En tant qu'espace de travail, ceci contiendra une étiquette qui indiquera
!>         lequel des types suivants correspond à une colonne de la matrice U2 ou à une
!>         ligne de la matrice VT2 :
!>         1 : non nul uniquement dans la moitié supérieure
!>         2 : non nul uniquement dans la moitié inférieure
!>         3 : dense
!>         4 : défléchi
!>
!>         À la sortie, c'est un tableau de dimension 4, où COLTYP(I) est
!>         la dimension des colonnes de type I.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!
>
