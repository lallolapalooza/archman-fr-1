sous-routine dlarfb_gett (character ident, integer m, integer n, integer k, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldwork, * ) work, integer

ldwork)

DLARFB_GET

T

But

: 
!>
!> DLARFB_GETT applique un réflecteur de bloc Householder réel H à gauche
!> d'une matrice réelle (K+M)-par-N
!> composée de deux matrices de blocs : une matrice trapézoïdale supérieure
!> K-par-N A stockée dans le tableau A, et une matrice rectangulaire
!> M-par-(N-K) B, stockée dans le tableau B. Le réflecteur de bloc H est
!> stocké dans une représentation compacte WY, où les réflecteurs
!> élémentaires se trouvent dans les tableaux A, B et T. Voir la section
!> Détails supplémentaires.
!
>

Paramètre

s
IDENT 
!>          IDENT est CHARACTER*1
!>          Si IDENT = pas 'I', ou pas 'i', alors V1 est une matrice
!>             triangulaire inférieure unitaire stockée dans le bloc
!>             gauche K-par-K de la matrice d'entrée A,
!>          Si IDENT = 'I' ou 'i', alors V1 est une matrice identité et
!>             n'est pas stockée.
!>          Voir la section Détails supplémentaires.
!
>

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice B.
!>          M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B.
!>          N >= 0.
!
>

K 
!>          K est INTEGER
!>          Le nombre de lignes de la matrice A.
!>          K est également l'ordre de la matrice T, c'est-à-dire le
!>          nombre de réflecteurs élémentaires dont le produit définit le
!>          réflecteur de bloc. 0 <= K <= N.
!
>

T 
!>          T est un tableau DOUBLE PRECISION, dimension (LDT,K)
!>          La matrice triangulaire supérieure K-par-K T dans la
!>          représentation du réflecteur de bloc.
!
>

LD

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= K.
!
>

A

!>
!>          À l'entrée :
!>           a) Dans la partie trapézoïdale supérieure K-par-N A : la matrice d'entrée A.
!>           b) Dans les colonnes sous la diagonale : les colonnes de V1
!>              (les uns ne sont pas stockés sur la diagonale).
!>
!>          À la sortie :
!>            A est écrasée par le produit rectangulaire K-par-N H*A.
!>
!>          Voir la section Détails supplémentaires.
!
>

LD

!
>

!>
!>          À l'entrée :
!>            a) Dans le bloc droit M-par-(N-K) : la matrice d'entrée B.
!>            b) Dans le bloc gauche M-par-N : les colonnes de V2.
!>
!>          À la sortie :
!>            B est écrasée par le produit rectangulaire M-par-N H*B.

Détails supplémentaires

: 
!>
!>    (1) Description de l'opération algébrique.
!>
!>    La matrice A est une matrice K-par-N composée de deux matrices de
!>    blocs de colonnes, A1, qui est K-par-K, et A2, qui est K-par-(N-K) :
!>    A = ( A1, A2 ).
!>    La matrice B est une matrice M-par-N composée de deux matrices de
!>    blocs de colonnes, B1, qui est M-par-K, et B2, qui est M-par-(N-K) :
!>    B = ( B1, B2 ).
!>
!>    Effectuer l'opération :
!>
!>       ( A_out ) := H * ( A_in ) = ( I - V * T * V**T ) * ( A_in ) =
!>       ( B_out )        ( B_in )                          ( B_in )
!>                  = ( I - ( V1 ) * T * ( V1**T, V2**T ) ) * ( A_in )
!>                          ( V2 )                            ( B_in )
!>     À l'entrée :
!>
!>    a) ( A_in )  se compose de deux colonnes de blocs :
!>       ( B_in )
!>
!>       ( A_in ) = (( A1_in ) ( A2_in )) = (( A1_in ) ( A2_in ))
!>       ( B_in )   (( B1_in ) ( B2_in ))   ((     0 ) ( B2_in )),
!>
!>       où les blocs de colonnes sont :
!>
!>       (  A1_in )  est une matrice triangulaire supérieure K-par-K stockée
!>                   dans la partie triangulaire supérieure du tableau A(1:K,1:K).
!>       (  B1_in )  est une matrice rectangulaire ZÉRO M-par-K et non stockée.
!>
!>       ( A2_in )  est une matrice rectangulaire K-par-(N-K) stockée
!>                  dans le tableau A(1:K,K+1:N).
!>       ( B2_in )  est une matrice rectangulaire M-par-(N-K) stockée
!>                  dans le tableau B(1:M,K+1:N).
!>
!>    b) V = ( V1 )
!>           ( V2 )
!>
!>       où :
!>       1) si IDENT == 'I', V1 est une matrice identité K-par-K, non stockée ;
!>       2) si IDENT != 'I', V1 est une matrice triangulaire inférieure
!>          unitaire K-par-K, stockée dans la partie triangulaire inférieure
!>          du tableau A(1:K,1:K) (les uns ne sont pas stockés),
!>       et V2 est une matrice rectangulaire M-par-K stockée dans le tableau
!>       B(1:M,1:K),
!>                 (car à l'entrée B1_in est une matrice rectangulaire zéro
!>                  qui n'est pas stockée et l'espace est
!>                  utilisé pour stocker V2).
!>
!>    c) T est une matrice triangulaire supérieure K-par-K stockée
!>       dans le tableau T(1:K,1:K).
!>
!>    À la sortie :
!>
!>    a) ( A_out ) se compose de deux colonnes de blocs :
!>       ( B_out )
!>
!>       ( A_out ) = (( A1_out ) ( A2_out ))
!>       ( B_out )   (( B1_out ) ( B2_out )),
!>
!>       où les blocs de colonnes sont :
!>
!>       ( A1_out )  est une matrice carrée K-par-K, ou une matrice
!>                   triangulaire supérieure K-par-K, si V1 est une
!>                   matrice identité. AiOut est stockée dans
!>                   le tableau A(1:K,1:K).
!>       ( B1_out )  est une matrice rectangulaire M-par-K stockée
!>                   dans le tableau B(1:M,K:N).
!>
!>       ( A2_out )  est une matrice rectangulaire K-par-(N-K) stockée
!>                   dans le tableau A(1:K,K+1:N).
!>       ( B2_out )  est une matrice rectangulaire M-par-(N-K) stockée
!>                   dans le tableau B(1:M,K+1:N).
!>
!>
!>    L'opération ci-dessus peut être représentée comme la même opération
!>    sur chaque colonne de blocs :
!>
!>       ( A1_out ) := H * ( A1_in ) = ( I - V * T * V**T ) * ( A1_in )
!>       ( B1_out )        (     0 )                          (     0 )
!>
!>       ( A2_out ) := H * ( A2_in ) = ( I - V * T * V**T ) * ( A2_in )
!>       ( B2_out )        ( B2_in )                          ( B2_in )
!>
!>    Si IDENT != 'I' :
!>
!>       Le calcul pour la colonne de blocs 1 :
!>
!>       A1_out: = A1_in - V1*T*(V1**T)*A1_in
!>
!>       B1_out: = - V2*T*(V1**T)*A1_in
!>
!>       Le calcul pour la colonne de blocs 2, qui existe si N > K :
!>
!>       A2_out: = A2_in - V1*T*( (V1**T)*A2_in + (V2**T)*B2_in )
!>
!>       B2_out: = B2_in - V2*T*( (V1**T)*A2_in + (V2**T)*B2_in )
!>
!>    Si IDENT == 'I' :
!>
!>       L'opération pour la colonne de blocs 1 :
!>
!>       A1_out: = A1_in - V1*T**A1_in
!>
!>       B1_out: = - V2*T**A1_in

!>
!>       Le calcul pour le bloc de colonnes 2, qui existe si N > K :
!>
!>       A2_out: = A2_in - T*( A2_in + (V2**T)*B2_in )
!>
!>       B2_out: = B2_in - V2*T*( A2_in + (V2**T)*B2_in )
!>
!>    (2) Description du calcul algorithmique.
!>
!>    Dans la première étape, nous calculons le bloc de colonnes 2, c'est-à-dire A2 et B2.
!>    Ici, nous devons utiliser la matrice de travail rectangulaire W2 de dimensions K par (N-K)
!>    qui est de la même taille que la matrice A2.
!>    W2 est stockée dans le tableau WORK(1:K,1:(N-K)).
!>
!>    Dans la deuxième étape, nous calculons le bloc de colonnes 1, c'est-à-dire A1 et B1.
!>    Ici, nous devons utiliser la matrice de travail carrée W1 de dimensions K par K
!>    qui est de la même taille que la matrice A1.
!>    W1 est stockée dans le tableau WORK(1:K,1:K).
!>
!>    NOTE : Par conséquent, dans cette routine, nous avons besoin du tableau de travail WORK
!>    seulement de taille WORK(1:K,1:max(K,N-K)) afin qu'il puisse contenir à la fois W2 de
!>    la première étape et W1 de la deuxième étape.
!>
!>    Cas (A), lorsque V1 est triangulaire inférieure unitaire, c'est-à-dire IDENT != 'I',
!>    plus de calculs que dans le Cas (B).
!>
!>    if( IDENT != 'I' ) then
!>     if ( N > K ) then
!>       (Première étape - bloc de colonnes 2)
!>       col2_(1) W2: = A2
!>       col2_(2) W2: = (V1**T) * W2 = (unit_lower_tr_of_(A1)**T) * W2
!>       col2_(3) W2: = W2 + (V2**T) * B2 = W2 + (B1**T) * B2
!>       col2_(4) W2: = T * W2
!>       col2_(5) B2: = B2 - V2 * W2 = B2 - B1 * W2
!>       col2_(6) W2: = V1 * W2 = unit_lower_tr_of_(A1) * W2
!>       col2_(7) A2: = A2 - W2
!>     else
!>       (Deuxième étape - bloc de colonnes 1)
!>       col1_(1) W1: = A1
!>       col1_(2) W1: = (V1**T) * W1 = (unit_lower_tr_of_(A1)**T) * W1
!>       col1_(3) W1: = T * W1
!>       col1_(4) B1: = - V2 * W1 = - B1 * W1
!>       col1_(5) square W1: = V1 * W1 = unit_lower_tr_of_(A1) * W1
!>       col1_(6) square A1: = A1 - W1
!>     end if
!>    end if
!>
!>    Cas (B), lorsque V1 est une matrice identité, c'est-à-dire IDENT == 'I',
!>    moins de calculs que dans le Cas (A)
!>
!>    if( IDENT == 'I' ) then
!>     if ( N > K ) then
!>       (Première étape - bloc de colonnes 2)
!>       col2_(1) W2: = A2
!>       col2_(3) W2: = W2 + (V2**T) * B2 = W2 + (B1**T) * B2
!>       col2_(4) W2: = T * W2
!>       col2_(5) B2: = B2 - V2 * W2 = B2 - B1 * W2
!>       col2_(7) A2: = A2 - W2
!>     else
!>       (Deuxième étape - bloc de colonnes 1)
!>       col1_(1) W1: = A1
!>       col1_(3) W1: = T * W1
!>       col1_(4) B1: = - V2 * W1 = - B1 * W1
!>       col1_(6) upper-triangular_of_(A1): = A1 - W1
!>     end if
!>    end if
!>
!>    En combinant ces cas (A) et (B), voici l'algorithme résultant :
!>
!>    if ( N > K ) then
!>
!>      (Première étape - bloc de colonnes 2)
!>
!>      col2_(1)  W2: = A2
!>      if( IDENT != 'I' ) then
!>        col2_(2)  W2: = (V1**T) * W2
!>                      = (unit_lower_tr_of_(A1)**T) * W2
!>      end if
!>      col2_(3)  W2: = W2 + (V2**T) * B2 = W2 + (B1**T) * B2]
!>      col2_(4)  W2: = T * W2
!>      col2_(5)  B2: = B2 - V2 * W2 = B2 - B1 * W2
!>      if( IDENT != 'I' ) then
!>        col2_(6)    W2: = V1 * W2 = unit_lower_tr_of_(A1) * W2
!>      end if
!>      col2_(7) A2: = A2 - W2
!>
!>    else
!>
!>    (Deuxième étape - bloc de colonnes 1)
!>
!>      col1_(1) W1: = A1
!>      if( IDENT != 'I' ) then
!>        col1_(2) W1: = (V1**T) * W1
!>                    = (unit_lower_tr_of_(A1)**T) * W1
!>      end if
!>      col1_(3) W1: = T * W1
!>      col1_(4) B1: = - V2 * W1 = - B1 * W1
!>      if( IDENT != 'I' ) then
!>        col1_(5) square W1: = V1 * W1 = unit_lower_tr_of_(A1) * W1
!>        col1_(6_a) below_diag_of_(A1): =  - below_diag_of_(W1)
!>      end if
!>      col1_(6_b) up_tr_of_(A1): = up_tr_of_(A1) - up_tr_of_(W1)
!>
!>    end if
!>
!
>
