sous-routine dlamrg (n1, n2, a, dtrd1, dtrd2, index)

DLAMRG crée une liste de permutation pour fusionner les entrées de deux ensembles triés indépendamment en un seul ensemble trié par ordre croissant.

Documentation de fonction/sous-routine

sous-routine dlamrg (entier n1, entier n2, double précision, dimension( * ) a, entier dtrd1, entier dtrd2, entier, dimension( * ) index)

DLAMRG crée une liste de permutation qui fusionnera les éléments de A (qui est composé de deux ensembles triés indépendamment) en un seul ensemble trié par ordre croissant.

Objectif :

!>
!> DLAMRG créera une liste de permutation qui fusionnera les éléments
!> de A (qui est composé de deux ensembles triés indépendamment) en un
!> seul ensemble trié par ordre croissant.
!>

Paramètres

N1 
!>          N1 est un ENTIER
!>

N2

!>          N2 est un ENTIER
!>         Ces arguments contiennent les longueurs respectives des deux
!>         listes triées à fusionner.
!>

A

!>          A est un tableau DOUBLE PRÉCISION, de dimension (N1+N2)
!>         Les N1 premiers éléments de A contiennent une liste de nombres
!>         triés par ordre croissant ou décroissant. Il en va de même
!>         pour les N2 éléments finaux.
!>

DTRD1

!>          DTRD1 est un ENTIER
!>

DTRD2

!>          DTRD2 est un ENTIER
!>         Ce sont les pas à effectuer dans le tableau A.
!>         Les pas autorisés sont 1 et -1. Ils indiquent si un sous-ensemble
!>         de A est trié par ordre croissant (DTRDx = 1) ou décroissant
!>         (DTRDx = -1).
!>

INDEX

!>          INDEX est un tableau ENTIER, de dimension (N1+N2)
!>         À la sortie, ce tableau contiendra une permutation telle que
!>         si B( I ) = A( INDEX( I ) ) pour I=1,N1+N2, alors B sera
!>         trié par ordre croissant.
!>
