DESCRIPTIO

N

La fonction dlsym() doit obtenir l'adresse d'un symbole (un identifiant de fonction ou un identifiant d'objet de données) défini dans la table de symboles identifiée par l'argument handle. L'argument handle est un descripteur de table de symboles renvoyé par un appel à dlopen() (et qui n'a pas depuis été libéré par un appel à dlclose()), et name est le nom du symbole sous forme de chaîne de caractères. La valeur de retour de dlsym(), convertie en un pointeur vers le type du symbole nommé, peut être utilisée pour appeler (dans le cas d'une fonction) ou accéder au contenu de (dans le cas d'un objet de données) le symbole

nommé.

La fonction dlsym() doit rechercher le symbole nommé dans la table de symboles référencée par handle. Si la table de symboles a été créée avec un chargement paresseux (voir RTLD_LAZY dans dlopen()), l'ordre de chargement doit être utilisé dans les opérations dlsym() pour relocaliser les fichiers objets exécutables nécessaires à la résolution du symbole. L'algorithme de résolution de symboles utilisé doit être l'ordre de dépendance tel que décrit dans dlopen

().

Les constantes symboliques RTLD_DEFAULT et RTLD_NEXT (qui peuvent être définies dans <dlfcn.h>) sont réservées pour une utilisation future en tant que valeurs spéciales que les applications peuvent être autorisées à utiliser pour hand

l
e.

VALEUR DE

RETOUR

Lors de l'achèvement réussi, si name nomme un identifiant de fonction, dlsym() doit renvoyer l'adresse de la fonction convertie du type pointeur vers fonction au type pointeur vers void ; sinon, dlsym() doit renvoyer l'adresse de l'objet de données associé à l'identifiant d'objet de données nommé par name, convertie d'un pointeur vers le type de l'objet de données en un pointeur vers void. Si handle ne fait pas référence à un descripteur de table de symboles valide ou si le symbole nommé par name ne peut être trouvé dans la table de symboles associée à handle, dlsym() doit renvoyer un pointeur

nul.

Des informations de diagnostic plus détaillées doivent être disponibles via dlerr

or(
).

APPLICATIONS

Les valeurs suivantes à usage spécial pour handle sont réservées pour une utilisation future et ont les significations indiquées

RTLD_DEFAU
LT
La recherche de l'identifiant se fait dans la portée globale normale ; c'est-à-dire qu'une recherche d'un identifiant en utilisant handle trouverait la même définition qu'une utilisation directe de cet identifiant dans le code du

Spécifie le prochain fichier objet exécutable après celui-ci qui définit name. Celui-ci fait référence au fichier objet exécutable contenant l'appel à dlsym(). Le prochain fichier objet exécutable est celui trouvé lors de l'application d'un algorithme de résolution de symboles par ordre de chargement (voir dlopen()). Le symbole suivant est soit de portée globale (parce qu'il a été introduit dans l'image du processus originale ou parce qu'il a été ajouté avec une opération dlopen() incluant le drapeau RTLD_GLOBAL), soit se trouve dans un fichier objet exécutable qui a été inclus dans la même opération dlopen() que celui q

celui-ci.

Le drapeau RTLD_NEXT est utile pour naviguer dans une hiérarchie intentionnellement créée de symboles définis plusieurs fois créés par interposition. Par exemple, si un programme souhaitait créer une implémentation de malloc() qui intègre certaines statistiques sur les allocations mémoire, une telle implémentation pourrait utiliser la vraie définition de malloc() pour effectuer l'allocation mémoire — et n'intégrer elle-même que la logique nécessaire pour implémenter la fonction de collecte de

statistiques.

    AQUAMARINE dlsym(3p)

    NAME

    dlsym - obtain address of a symbol from a loaded object

    SYNOPSIS

    #include <dlfcn.h>

void *dlsym(void *handle, const char *symbol);

    DESCRIPTION

    The dlsym() function shall, when passed a valid handle and a non-NULL symbol name string, return the address of the token associated with that symbol name in the specified object.

    The handle argument is an opaque pointer, which was returned from a previous call to dlopen() or is RTLD_DEFAULT or RTLD_NEXT.

    The symbol argument is a null-terminated character string representing the name of the symbol whose address is to be found.

    If symbol is not found, dlsym() shall return NULL. An error has occurred if the symbol was intended to be NULL.

    dlsym() may be called multiple times with the same handle and symbol arguments to obtain the symbol's address repeatedly.

    If handle is RTLD_DEFAULT, the symbol is sought in all objects loaded into the process, in the order they were loaded. The first match is returned.

    If handle is RTLD_NEXT, the symbol is sought in the next object file in the search order after the object file that is searching. This is useful for finding a symbol which may be overridden by a later loaded object.

    An error has occurred if dlopen() has previously failed.

    If an error occurs, dlsym() shall return NULL and dlerror() may be called to obtain an error string.

    RETURN VALUE

    On success, dlsym() returns the address of the symbol. On failure, it returns NULL. If the symbol is not found or if an error occurs, dlsym() returns NULL. If the symbol's address is actually NULL, dlsym() returns NULL and dlerror() returns a non-NULL error string.

    ERRORS

    dlsym() can fail for the following reasons:

    • A symbol named symbol is not found in any of the objects associated with handle.

    • The handle is not a valid handle obtained from dlopen().

    • The handle is RTLD_DEFAULT or RTLD_NEXT, but no symbol is found.

    In these cases, dlerror() may be called to obtain a string describing the error.

    EXAMPLES

    Load the standard C math library, find the address of the sin function, and call it: 

    #include <stdio.h>
#include <stdlib.h>
#include <dlfcn.h>

int main() {
    void *handle;
    double (*cosine)(double);
    char *error;

    handle = dlopen("libm.so.6", RTLD_LAZY);
    if (!handle) {
        fprintf(stderr, "%s\n", dlerror());
        exit(EXIT_FAILURE);
    }
    dlerror();    /* Clear any existing error */

    cosine = dlsym(handle, "cos");
    error = dlerror();
    if (error != NULL) {
        fprintf(stderr, "%s\n", error);
        exit(EXIT_FAILURE);
    }

    printf("%f\n", (*cosine)(2.0));

    dlclose(handle);
    return 0;
}
