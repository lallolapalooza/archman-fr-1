DLASR applique une séquence de rotations planes à une matrice rectangulaire générale.

Documentation de la fonction/de la

sous-routine

sous-routine dlasr (character side, character pivot, character direct, integer m, integer n, double precision, dimension( * ) c, double precision, dimension( * ) s, double precision, dimension( lda, * ) a, integer

lda)

DLASR applique une séquence de rotations planes à une matrice rectangulaire

générale.

But

: 
!>
!> DLASR applique une séquence de rotations planes à une matrice réelle A,
!> soit à gauche, soit à droite.
!>
!> Lorsque SIDE = 'L', la transformation prend la forme
!>
!>    A := P*A
!>
!> et lorsque SIDE = 'R', la transformation prend la forme
!>
!>    A := A*P**T
!>
!> où P est une matrice orthogonale constituée d'une séquence de z rotations
!> planes, avec z = M lorsque SIDE = 'L' et z = N lorsque SIDE = 'R',
!> et P**T est la transposée de P.
!>
!> Lorsque DIRECT = 'F' (séquence directe), alors
!>
!>    P = P(z-1) * ... * P(2) * P(1)
!>
!> et lorsque DIRECT = 'B' (séquence inverse), alors
!>
!>    P = P(1) * P(2) * ... * P(z-1)
!>
!> où P(k) est une matrice de rotation plane définie par la rotation 2-par-2
!>
!>    R(k) = (  c(k)  s(k) )
!>         = ( -s(k)  c(k) ).
!>
!> Lorsque PIVOT = 'V' (pivot variable), la rotation est effectuée
!> pour le plan (k,k+1), c'est-à-dire que P(k) a la forme
!>
!>    P(k) = (  1                                            )
!>           (       ...                                     )
!>           (              1                                )
!>           (                   c(k)  s(k)                  )
!>           (                  -s(k)  c(k)                  )
!>           (                                1              )
!>           (                                     ...       )
!>           (                                            1  )
!>
!> où R(k) apparaît comme une modification de rang 2 de la matrice identité dans
!> les lignes et colonnes k et k+1.
!>
!> Lorsque PIVOT = 'T' (pivot supérieur), la rotation est effectuée pour le
!> plan (1,k+1), de sorte que P(k) a la forme
!>
!>    P(k) = (  c(k)                    s(k)                 )
!>           (         1                                     )
!>           (              ...                              )
!>           (                     1                         )
!>           ( -s(k)                    c(k)                 )
!>           (                                 1             )
!>           (                                      ...      )
!>           (                                             1 )
!>
!> où R(k) apparaît dans les lignes et colonnes 1 et k+1.
!>
!> De même, lorsque PIVOT = 'B' (pivot inférieur), la rotation est
!> effectuée pour le plan (k,z), donnant à P(k) la forme
!>
!>    P(k) = ( 1                                             )
!>           (      ...                                      )
!>           (             1                                 )
!>           (                  c(k)                    s(k) )
!>           (                         1                     )
!>           (                              ...              )
!>           (                                     1         )
!>           (                 -s(k)                    c(k) )
!>
!> où R(k) apparaît dans les lignes et colonnes k et z.  Les rotations sont
!> effectuées sans jamais former P(k) explicitement.
!
>

Paramètre

s
SIDE 
!>          SIDE est CHARACTER*1
!>          Spécifie si la matrice de rotation plane P est appliquée à
!>          A à gauche ou à droite.
!>          = 'L' :  Gauche, calcule A := P*A
!>          = 'R' :  Droite, calcule A:= A*P**T
!
>

PIVO

T 
!>          PIVOT est CHARACTER*1
!>          Spécifie le plan pour lequel P(k) est une matrice de
!>          rotation plane.
!>          = 'V' :  pivot variable, le plan (k,k+1)
!>          = 'T' :  pivot supérieur, le plan (1,k+1)
!>          = 'B' :  pivot inférieur, le plan (k,z)
!
>

DIREC

T 
!>          DIRECT est CHARACTER*1
!>          Spécifie si P est une séquence directe ou inverse de
!>          rotations planes.
!>          = 'F' :  directe, P = P(z-1)*...*P(2)*P(1)
!>          = 'B' :  inverse, P = P(1)*P(2)*...*P(z-1)
!
>

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  Si m <= 1, un retour
!>          immédiat est effectué.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  Si n <= 1, un
!>          retour immédiat est effectué.
!
>

C 
!>          C est un tableau DOUBLE PRECISION, de dimension
!>                  (M-1) si SIDE = 'L'
!>                  (N-1) si SIDE = 'R'
!>          Les cosinus c(k) des rotations planes.
!
>

S 
!>          S est un tableau DOUBLE PRECISION, de dimension
!>                  (M-1) si SIDE = 'L'
!>                  (N-1) si SIDE = 'R'
!>          Les sinus s(k) des rotations planes.  La partie de rotation
!>          plane 2-par-2 de la matrice P(k), R(k), a la forme
!>          R(k) = (  c(k)  s(k) )
!>                 ( -s(k)  c(k) ).
!
>

A 
!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>          La matrice A de taille M-par-N.  À la sortie, A est écrasée par P*A si
!>          SIDE = 'L' ou par A*P**T si SIDE = 'R'.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!
>
