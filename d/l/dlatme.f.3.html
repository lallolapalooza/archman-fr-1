But

: 
!>
!>    DLATME génère des matrices carrées non symétriques aléatoires avec
!>    des valeurs propres spécifiées pour tester les programmes LAPACK.
!>
!>    DLATME fonctionne en appliquant la séquence suivante
!>    d'opérations :
!>
!>    1. Définit la diagonale à D, où D peut être en entrée ou
!>         calculé selon MODE, COND, DMAX et RSIGN
!>         comme décrit ci-dessous.
!>
!>    2. Si des paires conjuguées complexes sont souhaitées (MODE=0 et EI(1)='R',
!>         ou MODE=5), certaines paires d'éléments adjacents de D sont
!>         interprétées comme les parties réelle et imaginaire d'une paire
!>         conjuguée complexe ; A devient ainsi bloc-diagonale, avec des blocs
!>         1x1 et 2x2.
!>
!>    3. Si UPPER='T', le triangle supérieur de A est défini à des valeurs
!>         aléatoires tirées de la distribution DIST.
!>
!>    4. Si SIM='T', A est multiplié à gauche par une matrice aléatoire
!>         X, dont les valeurs singulières sont spécifiées par DS, MODES et
!>         CONDS, et à droite par l'inverse de X.
!>
!>    5. Si KL < N-1, la largeur de bande inférieure est réduite à KL en utilisant
!>         des transformations de Householder.  Si KU < N-1, la largeur de bande
!>         supérieure est réduite à KU.
!>
!>    6. Si ANORM n'est pas négatif, la matrice est mise à l'échelle pour avoir
!>         une norme élément-maximum ANORM.
!>
!>    (Remarque : puisque la matrice ne peut pas être réduite au-delà de la forme
!>     de Hessenberg, aucune option de compactage n'est disponible.)
!
>

Paramètre

s
N 
!>          N est INTEGER
!>           Le nombre de colonnes (ou de lignes) de A. Non modifié.
!
>

DIS

T 
!>          DIST est CHARACTER*1
!>           À l'entrée, DIST spécifie le type de distribution à utiliser
!>           pour générer les valeurs propres/singulières aléatoires, et pour le
!>           triangle supérieur (voir UPPER).
!>           'U' => UNIFORM( 0, 1 )  ( 'U' pour uniforme )
!>           'S' => UNIFORM( -1, 1 ) ( 'S' pour symétrique )
!>           'N' => NORMAL( 0, 1 )   ( 'N' pour normale )
!>           Non modifié.
!
>

ISEE

D 
!>          ISEED est un tableau INTEGER, dimension ( 4 )
!>           À l'entrée, ISEED spécifie la graine du générateur de nombres
!>           aléatoires. Elle doit être comprise entre 0 et 4095 inclus,
!>           et ISEED(4) doit être impair. Le générateur de nombres aléatoires
!>           utilise une suite congruentielle linéaire limitée à de petits
!>           entiers, et devrait donc produire des nombres aléatoires
!>           indépendants de la machine. Les valeurs de ISEED sont modifiées à
!>           la sortie, et peuvent être utilisées dans le prochain appel à DLATME
!>           pour continuer la même suite de nombres aléatoires.
!>           Modifié à la sortie.
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension ( N )
!>           Ce tableau est utilisé pour spécifier les valeurs propres de A.  Si
!>           MODE=0, alors D est supposé contenir les valeurs propres (mais
!>           voir la description de EI), sinon elles seront
!>           calculées selon MODE, COND, DMAX et RSIGN et
!>           placées dans D.
!>           Modifié si MODE est non nul.
!
>

MOD

E 
!>          MODE est INTEGER
!>           À l'entrée, ceci décrit comment les valeurs propres doivent
!>           être spécifiées :
!>           MODE = 0 signifie utiliser D (avec EI) en entrée
!>           MODE = 1 définit D(1)=1 et D(2:N)=1.0/COND
!>           MODE = 2 définit D(1:N-1)=1 et D(N)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    soient uniformément distribués.  Chaque paire impaire-paire
!>                    d'éléments sera soit utilisée comme deux valeurs propres
!>                    réelles, soit comme les parties réelle et imaginaire
!>                    d'une paire conjuguée complexe de valeurs propres ;
!>                    le choix effectué est aléatoire, avec
!>                    une probabilité de 50-50, pour chaque paire.
!>           MODE = 6 définit D à des nombres aléatoires de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est compris entre 1 et 4, D a des entrées allant
!>              de 1 à 1/COND, si entre -1 et -4, D a des entrées
!>              allant de 1/COND à 1,
!>           Non modifié.
!
>

CON

D 
!>          COND est DOUBLE PRECISION
!>           À l'entrée, ceci est utilisé comme décrit sous MODE ci-dessus.
!>           S'il est utilisé, il doit être >= 1. Non modifié.
!
>

DMA

X 
!>          DMAX est DOUBLE PRECISION
!>           Si MODE n'est ni -6, 0 ni 6, le contenu de D, tel que
!>           calculé selon MODE et COND, sera mis à l'échelle par
!>           DMAX / max(abs(D(i))).  Notez que DMAX n'a pas besoin d'être
!>           positif : si DMAX est négatif (ou nul), D sera
!>           mis à l'échelle par un nombre négatif (ou nul).
!>           Non modifié.
!
>

E

I 
!>          EI est un tableau CHARACTER*1, dimension ( N )
!>           Si MODE vaut 0, et EI(1) n'est pas ' ' (caractère espace),
!>           ce tableau spécifie quels éléments de D (à l'entrée) sont
!>           des valeurs propres réelles et lesquels sont les parties
!>           réelle et imaginaire d'une paire conjuguée complexe de valeurs propres.  Les éléments
!>           de EI ne peuvent alors avoir que les valeurs 'R' et 'I'.  Si
!>           EI(j)='R' et EI(j+1)='I', alors la j-ième valeur propre est
!>           CMPLX( D(j) , D(j+1) ), et la (j+1)-ième est le conjugué complexe
!>           de celle-ci.  Si EI(j)=EI(j+1)='R', alors la j-ième
!>           valeur propre est D(j) (c.-à-d. réelle).  EI(1) ne peut pas être 'I',
!>           ni deux éléments adjacents de EI ne peuvent avoir tous les deux la valeur 'I'.
!>           Si MODE n'est pas 0, alors EI est ignoré.  Si MODE est 0 et
!>           EI(1)=' ', alors les valeurs propres seront toutes réelles.
!>           Non modifié.
!
>

RSIG

N 
!>          RSIGN est CHARACTER*1
!>           Si MODE n'est pas 0, 6 ou -6, et RSIGN='T', alors les
!>           éléments de D, tels que calculés selon MODE et COND, seront
!>           multipliés par un signe aléatoire (+1 ou -1).  Si RSIGN='F',
!>           ils ne le seront pas.  RSIGN ne peut avoir que les valeurs 'T' ou
!>           'F'.
!>           Non modifié.
!
>

UPPE

R 
!>          UPPER est CHARACTER*1
!>           Si UPPER='T', alors les éléments de A au-dessus de la diagonale
!>           (et au-dessus des blocs diagonaux 2x2, si A a des valeurs propres
!>           complexes) seront définis à des nombres aléatoires tirés de DIST.
!>           Si UPPER='F', ils ne le seront pas.  UPPER ne peut avoir que les
!>           valeurs 'T' ou 'F'.
!>           Non modifié.
!
>

SI

M

Documentation de la fonction/sous-routine


Objectif


DLATME construit une matrice de test A de dimension N x N.


Arguments


N INTEGER


La dimension de la matrice A. N doit être positif.


DIST CHARACTER*1


DIST = 'R': La matrice est aléatoire. La matrice est générée
    comme X * S * X', où X est une matrice unitaire aléatoire et S est une
    matrice diagonale de valeurs propres spécifiées par D, MODES et CONDS.


MODE INTEGER


MODE détermine la génération des valeurs propres.


IL INTEGER


IL est la première ligne de la sous-matrice.


IU INTEGER


IU est la dernière ligne de la sous-matrice.


KL INTEGER


KL est la largeur de bande inférieure de la matrice.


KU INTEGER


KU est la largeur de bande supérieure de la matrice.


ANORM DOUBLE PRECISION


Si ANORM n'est pas négatif, alors A sera mise à l'échelle par un
    nombre réel non négatif pour que la norme maximale d'élément de A soit
    ANORM.


MAXP DOUBLE PRECISION


MAXP est la valeur maximale des valeurs propres (ou valeurs
    singulières).


MINP DOUBLE PRECISION


MINP est la valeur minimale des valeurs propres (ou valeurs
    singulières).


NL INTEGER


NL est le nombre de valeurs propres (ou valeurs singulières) à
    générer.


NR INTEGER


NR est le nombre de valeurs propres (ou valeurs singulières)
    aléatoires à générer.


A DOUBLE PRECISION array, dimension ( LDA, N )


À la sortie, A est la matrice de test souhaitée.


LDA INTEGER


LDA spécifie la première dimension de A telle que déclarée dans le
    programme appelant. LDA doit être au moins N.


WORK DOUBLE PRECISION array, dimension ( 3*N )


Espace de travail.


INFO INTEGER


Code d'erreur. À la sortie, INFO sera défini à l'une des valeurs
    suivantes :


            0 => retour normal
           -1 => N négatif
           -2 => DIST chaîne illégale
           -3 => MODE pas dans la plage -6 à 6
           -4 => IL ou IU hors limites
           -5 => KL est inférieur à 1
           -6 => KU est inférieur à 1, ou KL et KU sont tous deux inférieurs
                 à N-1.
           -7 => ANORM est négatif
           -8 => MAXP n'est pas supérieur ou égal à MINP
           -9 => MINP est inférieur ou égal à zéro
          -10 => NL n'est pas positif
          -11 => NR n'est pas positif
          -12 => NL + NR est supérieur à N
          -13 => LDA est inférieur à N
          -14 => Erreur de retour de DLATM1 (calcul de D)
           1  => Erreur de retour de DLATM1 (calcul de D)
           2  => Ne peut pas mettre à l'échelle vers DMAX (la valeur propre maximale est 0)
           3  => Erreur de retour de DLATM1 (calcul de DS)
           4  => Erreur de retour de DLARGE
           5  => Valeur propre nulle de DLATM1.



Exemple d'utilisation


Cet exemple montre comment générer une matrice aléatoire de 5x5
    avec des valeurs propres distribuées uniformément entre 1 et 10.


      PROGRAM TEST_DLATME
      INTEGER N, LDA, INFO, MODE, IL, IU, KL, KU, NL, NR
      DOUBLE PRECISION A(10,10), WORK(30)
      DOUBLE PRECISION ANORM, MAXP, MINP

      N = 5
      LDA = 10
      MODE = 0
      IL = 1
      IU = N
      KL = 1
      KU = 1
      ANORM = 1.0D0
      MAXP = 10.0D0
      MINP = 1.0D0
      NL = 3
      NR = 2

      CALL DLATME(N, 'R', MODE, IL, IU, KL, KU, ANORM,
     &            MAXP, MINP, NL, NR, A, LDA, WORK, INFO)

      IF (INFO .NE. 0) THEN
         PRINT *, 'Erreur lors de la génération de la matrice, INFO = ', INFO
      ELSE
         PRINT *, 'Matrice générée avec succès :'
         DO I = 1, N
            PRINT *, (A(I,J), J = 1, N)
         ENDDO
      ENDIF

      END



Implémentation


Sous-routine BLAS/LAPACK


DLATME est une sous-routine de LAPACK qui génère une
    matrice de test.


Elle utilise des sous-routines auxiliaires telles que DLATM1
    et DLARGE pour générer les valeurs propres et la matrice elle-même.


Informations de mise en cache


La matrice A est générée en mémoire, et la taille de la matrice est
    N x N.


Détails


Si DIST = 'R', alors A est générée comme X * S * X',
    où U et V sont des matrices unitaires aléatoires et S est une matrice (diagonale)
    de valeurs singulières spécifiées par DS, MODES et
    CONDS. Si SIM='F', alors A ne sera pas transformée.


DS


DS est un tableau de DOUBLE PRECISION,
    dimension ( N ). Ce tableau est utilisé pour spécifier les valeurs singulières
    de X, de la même manière que D spécifie les valeurs propres de A. Si
    MODE=0, DS contient les valeurs singulières, qui
    ne peuvent pas être zéro. Modifié si MODE est non nul.


MODES


MODES est un entier.


CONDS


CONDS est un DOUBLE PRECISION. Identique à
    MODE et COND, mais pour spécifier la diagonale de
    S. MODES=-6 et +6 ne sont pas autorisés (car ils entraîneraient
    des valeurs propres aléatoirement mal conditionnées).


KL


KL est un entier. Ceci spécifie la largeur de bande
    inférieure de la matrice. KL=1 spécifie la forme de Hessenberg
    supérieure. Si KL est au moins N-1, alors A aura une largeur de
    bande inférieure complète. KL doit être au moins 1. Non modifié.


KU


KU est un entier. Ceci spécifie la largeur de bande
    supérieure de la matrice. KU=1 spécifie la forme de Hessenberg
    inférieure. Si KU est au moins N-1, alors A aura une largeur de
    bande supérieure complète ; si KU et KL sont tous
    deux au moins N-1, alors A sera dense. Un seul parmi KU et
    KL peut être inférieur à N-1. KU doit être au
    moins 1. Non modifié.


ANORM


ANORM est un DOUBLE PRECISION. Si
    ANORM n'est pas négatif, alors A sera mise à l'échelle par un
    nombre réel non négatif pour que la norme maximale d'élément de A soit
    ANORM. Non modifié.


A


A est un tableau de DOUBLE PRECISION,
    dimension ( LDA, N ). À la sortie, A est la matrice de test souhaitée.
    Modifié.


LDA


LDA est un entier. LDA spécifie la première
    dimension de A telle que déclarée dans le programme appelant. LDA
    doit être au moins N. Non modifié.


WORK


WORK est un tableau de DOUBLE PRECISION,
    dimension ( 3*N ). Espace de travail. Modifié.


INFO


INFO est un entier. Code d'erreur. À la sortie, INFO
    sera défini à l'une des valeurs suivantes :


            0 => retour normal
           -1 => N négatif
           -2 => DIST chaîne illégale
           -5 => MODE pas dans la plage -6 à 6
           -6 => COND inférieur à 1.0, et MODE ni -6, 0 ni 6
           -8 => EI(1) n'est pas ' ' ou 'R', EI(j) n'est pas 'R' ou 'I', ou
                 deux éléments adjacents de EI sont 'I'.
           -9 => RSIGN n'est pas 'T' ou 'F'
          -10 => UPPER n'est pas 'T' ou 'F'
          -11 => SIM n'est pas 'T' ou 'F'
          -12 => MODES=0 et DS a une valeur singulière nulle.
          -13 => MODES n'est pas dans la plage -5 à 5.
          -14 => MODES est non nul et CONDS est inférieur à 1.
          -15 => KL est inférieur à 1.
          -16 => KU est inférieur à 1, ou KL et KU sont tous deux inférieurs
                 à N-1.
          -19 => LDA est inférieur à N.
            1  => Erreur de retour de DLATM1 (calcul de D)
            2  => Impossible de mettre à l'échelle vers DMAX (la valeur propre maximale est 0)
            3  => Erreur de retour de DLATM1 (calcul de DS)
            4  => Erreur de retour de DLARGE
            5  => Valeur singulière nulle de DLATM1.
