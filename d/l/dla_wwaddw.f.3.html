Documentation Fonction/Sous programme

sous programme dla_wwaddw (integer n, double precision, dimension( * ) x, double precision, dimension( * ) y, double precision, dimension( * ) w)

DLA_WWADDW ajoute un vecteur à un vecteur double-précision.

Objectif :

!>
!>    DLA_WWADDW ajoute un vecteur W dans un vecteur double-précision (X, Y).
!>
!>    Cela fonctionne pour toute l'arithmétique flottante hexadécimale et binaire d'IBM
!>    existante, mais pas pour le décimal.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>            La longueur des vecteurs X, Y et W.
!>

X

!>          X est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>            La première partie du vecteur d'accumulation double-précision.
!>

Y

!>          Y est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>            La deuxième partie du vecteur d'accumulation double-précision.
!>

W

!>          W est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>            Le vecteur à ajouter.
!>
