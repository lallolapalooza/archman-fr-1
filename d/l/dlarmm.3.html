double precision function dlarmm (double precision anorm, double precision bnorm, double precision cnorm)

DLARMM

But :

!>
!> DLARMM retourne un facteur s dans (0, 1] tel que les mises à jour linéaires
!>
!>    (s * C) - A * (s * B)  et  (s * C) - (s * A) * B
!>
!> ne puissent pas déborder, où A, B et C sont des matrices de dimensions conformes.
!>
!> Ceci est une routine auxiliaire, il n'y a donc pas de vérification des arguments.
!>

Paramètres

ANORM 
!>          ANORM est de type DOUBLE PRECISION
!>          La norme infinie de A. ANORM >= 0.
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

BNORM

!>          BNORM est de type DOUBLE PRECISION
!>          La norme infinie de B. BNORM >= 0.
!>

CNORM

!>          CNORM est de type DOUBLE PRECISION
!>          La norme infinie de C. CNORM >= 0.
!>


Références : C. C. Kjelgaard Mikkelsen et L. Karlsson, Blocked Algorithms for Robust Solution of Triangular Linear Systems. Dans : International Conference on Parallel Processing and Applied Mathematics, pages 68--78. Springer, 2017.
