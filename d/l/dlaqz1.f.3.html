sous-programme dlaqz1 (double précision, dimension( lda, * ), intent(in) a, entier, intent(in) lda, double précision, dimension( ldb, * ), intent(in) b, entier, intent(in) ldb, double précision, intent(in) sr1, double précision, intent(in) sr2, double précision, intent(in) si, double précision, intent(in) beta1, double précision, intent(in) beta2, double précision, dimension( * ), intent(out) v)

DLAQZ1

But:

!>
!>      Étant donné un faisceau de matrices 3x3 (A,B), DLAQZ1 définit v comme un
!>      multiple scalaire de la première colonne du produit
!>
!> (*)  K = (A - (beta2*sr2 - i*si)*B)*B^(-1)*(beta1*A - (sr2 + i*si2)*B)*B^(-1).
!>
!>      On suppose que soit
!>
!>              1) sr1 = sr2
!>          ou
!>              2) si = 0.
!>
!>      Ceci est utile pour démarrer les gonflements à décalage implicite double
!>      dans l'algorithme QZ.
!>

Paramètres

A 
!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>              La matrice 3x3 A dans (*).
!>

LDA

!>          LDA est un ENTIER
!>              La dimension principale de A telle que déclarée dans
!>              la procédure appelante.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>              La matrice 3x3 B dans (*).
!>

LDB

!>          LDB est un ENTIER
!>              La dimension principale de B telle que déclarée dans
!>              la procédure appelante.
!>

SR1

!>          SR1 est DOUBLE PRECISION
!>

SR2

!>          SR2 est DOUBLE PRECISION
!>

SI

!>          SI est DOUBLE PRECISION
!>

BETA1

!>          BETA1 est DOUBLE PRECISION
!>

BETA2

!>          BETA2 est DOUBLE PRECISION
!>

V

!>          V est un tableau DOUBLE PRECISION, dimension (N)
!>              Un multiple scalaire de la première colonne de la
!>              matrice K dans (*).
!>
