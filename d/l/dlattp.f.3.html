Documentation de la fonction/sous-routine

sous-routine dlattp (integer imat, character uplo, character trans, character diag, integer, dimension( 4 ) iseed, integer n, double precision, dimension( * ) a, double precision, dimension( * ) b, double precision, dimension( * ) work, integer info)

DLATTP

But:

!>
!> DLATTP génère une matrice triangulaire de test en stockage compacté.
!> IMAT et UPLO spécifient de manière unique les propriétés de la matrice de test,
!> qui est retournée dans le tableau AP.
!>

Paramètres

IMAT 
!>          IMAT est un entier
!>          Une clé entière décrivant quelle matrice générer pour ce
!>          chemin.
!>

UPLO

!>          UPLO est un CARACTERE*1
!>          Spécifie si la matrice A sera triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est un CARACTERE*1
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Transposée conjuguée (= Transposée)
!>

DIAG

!>          DIAG est un CARACTERE*1
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

ISEED

!>          ISEED est un tableau d'entiers, de dimension (4)
!>          Le vecteur de départ pour le générateur de nombres aléatoires (utilisé dans
!>          DLATMS). Modifié à la sortie.
!>

N

!>          N est un entier
!>          L'ordre de la matrice à générer.
!>

A

!>          A est un tableau de DOUBLE PRECISION, de dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compactée par colonne dans
!>          un tableau linéaire. La j-ème colonne de A est stockée dans le tableau
!>          AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

B

!>          B est un tableau de DOUBLE PRECISION, de dimension (N)
!>          Le vecteur du second membre, si IMAT > 10.
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, de dimension (3*N)
!>

INFO

!>          INFO est un entier
!>          = 0:  sortie réussie
!>          < 0: si INFO = -k, le k-ème argument avait une valeur illégale
!>
