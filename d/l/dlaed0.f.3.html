sous-routine dlaed0 (integer icompq, integer qsiz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( ldqs, * ) qstore, integer ldqs, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DLAED0 utilisé par DSTEDC. Calcule toutes les valeurs propres et les vecteurs propres correspondants d'une matrice symétrique tridiagonale non réduite à l'aide de la méthode diviser pour régner.

Objectif :

!>
!> DLAED0 calcule toutes les valeurs propres et les vecteurs propres correspondants d'une
!> matrice tridiagonale symétrique à l'aide de la méthode diviser pour régner.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est INTEGER
!>          = 0 : Calcule uniquement les valeurs propres.
!>          = 1 : Calcule également les vecteurs propres de la matrice symétrique dense
!>                d'origine. À l'entrée, Q contient la matrice orthogonale utilisée
!>                pour réduire la matrice d'origine à la forme tridiagonale.
!>          = 2 : Calcule les valeurs propres et les vecteurs propres de la matrice
!>                tridiagonale.
!>

QSIZ

!>          QSIZ est INTEGER
!>         La dimension de la matrice orthogonale utilisée pour réduire
!>         la matrice complète à la forme tridiagonale. QSIZ >= N si ICOMPQ = 1.
!>

N

!>          N est INTEGER
!>         La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>         À l'entrée, la diagonale principale de la matrice tridiagonale.
!>         À la sortie, ses valeurs propres.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (N-1)
!>         Les éléments hors diagonale de la matrice tridiagonale.
!>         À la sortie, E a été détruit.
!>

Q

!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ, N)
!>         À l'entrée, Q doit contenir une matrice orthogonale N x N.
!>         Si ICOMPQ = 0, Q n'est pas référencé.
!>         Si ICOMPQ = 1, À l'entrée, Q est un sous-ensemble des colonnes de la
!>                          matrice orthogonale utilisée pour réduire la
!>                          matrice complète à la forme tridiagonale correspondant
!>                          au sous-ensemble de la matrice complète qui est en
!>                          cours de décomposition.
!>         Si ICOMPQ = 2, À l'entrée, Q sera la matrice identité.
!>                          À la sortie, Q contient les vecteurs propres de la
!>                          matrice tridiagonale.
!>

LDQ

!>          LDQ est INTEGER
!>         La dimension principale du tableau Q. Si des vecteurs propres sont
!>         souhaités, alors LDQ >= max(1,N). Dans tous les cas, LDQ >= 1.
!>

QSTORE

!>          QSTORE est un tableau DOUBLE PRECISION, dimension (LDQS, N)
!>         Référencé uniquement lorsque ICOMPQ = 1. Utilisé pour stocker des parties
!>         de la matrice des vecteurs propres lorsque les multiplications de mise à jour
!>         ont lieu.
!>

LDQS

!>          LDQS est INTEGER
!>         La dimension principale du tableau QSTORE. Si ICOMPQ = 1,
!>         alors LDQS >= max(1,N). Dans tous les cas, LDQS >= 1.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION,
!>         Si ICOMPQ = 0 ou 1, la dimension de WORK doit être au moins
!>                     1 + 3*N + 2*N*lg N + 3*N**2
!>                     ( lg( N ) = plus petit entier k
!>                                 tel que 2^k >= N )
!>         Si ICOMPQ = 2, la dimension de WORK doit être au moins
!>                     4*N + N**2.
!>

IWORK

!>          IWORK est un tableau INTEGER,
!>         Si ICOMPQ = 0 ou 1, la dimension de IWORK doit être au moins
!>                        6 + 6*N + 5*N*lg N.
!>                        ( lg( N ) = plus petit entier k
!>                                    tel que 2^k >= N )
!>         Si ICOMPQ = 2, la dimension de IWORK doit être au moins
!>                        3 + 5*N.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : l'algorithme n'a pas réussi à calculer une valeur propre lors
!>                de la manipulation de la sous-matrice située dans les lignes et
!>                colonnes INFO/(N+1) à mod(INFO,N+1).
!>
