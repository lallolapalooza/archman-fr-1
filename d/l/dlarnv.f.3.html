subroutine dlarnv (integer idist, integer, dimension( 4 ) iseed, integer n, double precision, dimension( * ) x)

DLARNV renvoie un vecteur de nombres réels aléatoires issus d'une distribution uniforme ou normale.

Objectif :

!>
!> DLARNV renvoie un vecteur de n nombres réels aléatoires issus d'une distribution
!> uniforme ou normale.
!>

Paramètres

IDIST 
!>          IDIST est de type INTEGER
!>          Spécifie la distribution des nombres aléatoires :
!>          = 1 : uniforme (0,1)
!>          = 2 : uniforme (-1,1)
!>          = 3 : normale (0,1)
!>

ISEED

!>          ISEED est un tableau de type INTEGER, de dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires ; les éléments
!>          du tableau doivent être compris entre 0 et 4095, et ISEED(4) doit être
!>          impair.
!>          À la sortie, la graine est mise à jour.
!>

N

!>          N est de type INTEGER
!>          Le nombre de nombres aléatoires à générer.
!>

X

!>          X est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          Les nombres aléatoires générés.
!>

Auteur

Univ. du Tennessee

Univ. de Californie à Berkeley

Univ. du Colorado à Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  Cette routine appelle la routine auxiliaire DLARUV pour générer des nombres réels
!>  aléatoires issus d'une distribution uniforme (0,1), par lots allant jusqu'à
!>  128 en utilisant du code vectorisable. La méthode de Box-Muller est utilisée pour
!>  transformer des nombres d'une distribution uniforme à une distribution normale.
!>

Définition à la ligne 96 du fichier dlarnv.f.
