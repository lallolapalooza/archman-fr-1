sous-routine dlarrv (integer n, double precision vl, double precision vu, double precision, dimension( * ) d, double precision, dimension( * ) l, double precision pivmin, integer, dimension( * ) isplit, integer m, integer dol, integer dou, double precision minrgp, double precision rtol1, double precision rtol2, double precision, dimension( * ) w, double precision, dimension( * ) werr, double precision, dimension( * ) wgap, integer, dimension( * ) iblock, integer, dimension( * ) indexw, double precision, dimension( * ) gers, double precision, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DLARRV calcule les vecteurs propres de la matrice tridiagonale T = L D LT étant donné L, D et les valeurs propres de L D LT.

But :

!>
!> DLARRV calcule les vecteurs propres de la matrice tridiagonale
!> T = L D L**T étant donné L, D et des APPROXIMATIONS des valeurs propres de L D L**T.
!> Les valeurs propres en entrée doivent avoir été calculées par DLARRE.
!>

Paramètres

N 
!>          N est INTEGER
!>          L'ordre de la matrice.  N >= 0.
!>

VL

!>          VL est DOUBLE PRECISION
!>          Borne inférieure de l'intervalle contenant les valeurs
!>          propres désirées. VL < VU. Nécessaire pour calculer les écarts à l'extrémité gauche ou droite
!>          des valeurs propres extrêmes dans la plage RANGE désirée.
!>

VU

!>          VU est DOUBLE PRECISION
!>          Borne supérieure de l'intervalle contenant les valeurs
!>          propres désirées. VL < VU.
!>          Remarque : VU n'est actuellement pas utilisé par cette implémentation de DLARRV, VU est
!>          passé à DLARRV car il pourrait être utilisé pour calculer les écarts à l'extrémité droite
!>          des valeurs propres extrêmes. Cependant, avec une précision initiale insuffisante dans
!>          LAMBDA et VU, la formule peut conduire à une surestimation de l'écart droit
!>          et donc à une « convergence » RQI prématurée. Cela est actuellement
!>          empêché en forçant un petit écart droit. Il s'avère donc que VU
!>          n'est actuellement pas utilisé par cette implémentation de DLARRV.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les N éléments diagonaux de la matrice diagonale D.
!>          À la sortie, D peut être écrasé.
!>

L

!>          L est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les (N-1) éléments sous-diagonaux de la matrice
!>          bidiagonale unitaire L se trouvent dans les éléments 1 à N-1 de L
!>          (si la matrice n'est pas scindée). À la fin de chaque bloc
!>          est stocké le décalage correspondant donné par DLARRE.
!>          À la sortie, L est écrasé.
!>

PIVMIN

!>          PIVMIN est DOUBLE PRECISION
!>          Le pivot minimum autorisé dans la séquence de Sturm.
!>

ISPLIT

!>          ISPLIT est un tableau INTEGER, dimension (N)
!>          Les points de scission, auxquels T se divise en blocs.
!>          Le premier bloc se compose des lignes/colonnes 1 à
!>          ISPLIT( 1 ), le deuxième des lignes/colonnes ISPLIT( 1 )+1
!>          jusqu'à ISPLIT( 2 ), etc.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres en entrée.  0 <= M <= N.
!>

DOL

!>          DOL est INTEGER
!>

DOU

!>          DOU est INTEGER
!>          Si l'utilisateur souhaite calculer uniquement des vecteurs propres sélectionnés parmi toutes
!>          les valeurs propres fournies, il peut spécifier une plage d'index DOL:DOU.
!>          Sinon, le réglage DOL=1, DOU=M doit être appliqué.
!>          Notez que DOL et DOU font référence à l'ordre dans lequel les valeurs propres
!>          sont stockées dans W.
!>          Si l'utilisateur souhaite calculer uniquement des paires propres sélectionnées, alors
!>          les colonnes DOL-1 à DOU+1 de l'espace des vecteurs propres Z contiennent les
!>          vecteurs propres calculés. Toutes les autres colonnes de Z sont mises à zéro.
!>

MINRGP

!>          MINRGP est DOUBLE PRECISION
!>

RTOL1

!>          RTOL1 est DOUBLE PRECISION
!>

RTOL2

!>          RTOL2 est DOUBLE PRECISION
!>           Paramètres pour la bissection.
!>           Un intervalle [LEFT,RIGHT] a convergé si
!>           RIGHT-LEFT < MAX( RTOL1*GAP, RTOL2*MAX(|LEFT|,|RIGHT|) )
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          Les M premiers éléments de W contiennent les valeurs propres APPROXIMÉES pour
!>          lesquelles les vecteurs propres doivent être calculés. Les valeurs propres
!>          doivent être regroupées par bloc détaché et ordonnées de
!>          la plus petite à la plus grande à l'intérieur du bloc (le tableau de sortie
!>          W de DLARRE est attendu ici). De plus, elles sont par
!>          rapport au décalage de la représentation de racine correspondante
!>          pour leur bloc. À la sortie, W contient les valeurs propres de la
!>          matrice SANS décalage.
!>

WERR

!>          WERR est un tableau DOUBLE PRECISION, dimension (N)
!>          Les M premiers éléments contiennent la demi-largeur de l'intervalle
!>          d'incertitude de la valeur propre correspondante dans W
!>

WGAP

!>          WGAP est un tableau DOUBLE PRECISION, dimension (N)
!>          La séparation avec la valeur propre voisine de droite dans W.
!>

IBLOCK

!>          IBLOCK est un tableau INTEGER, dimension (N)
!>          Les index des blocs (sous-matrices) associés aux
!>          valeurs propres correspondantes dans W ; IBLOCK(i)=1 si la valeur propre
!>          W(i) appartient au premier bloc en partant du haut, =2 si W(i)
!>          appartient au deuxième bloc, etc.
!>

INDEXW

!>          INDEXW est un tableau INTEGER, dimension (N)
!>          Les index des valeurs propres à l'intérieur de chaque bloc (sous-matrice) ;
!>          par exemple, INDEXW(i)= 10 et IBLOCK(i)=2 impliquent que la
!>          i-ème valeur propre W(i) est la 10ème valeur propre dans le deuxième bloc.
!>

GERS

!>          GERS est un tableau DOUBLE PRECISION, dimension (2*N)
!>          Les N intervalles de Gerschgorin (le i-ème intervalle de Gerschgorin
!>          est (GERS(2*i-1), GERS(2*i)). Les intervalles de Gerschgorin doivent
!>          être calculés à partir de la matrice d'origine SANS décalage.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension (LDZ, max(1,M) )
!>          Si INFO = 0, les M premières colonnes de Z contiennent les
!>          vecteurs propres orthonormaux de la matrice T
!>          correspondant aux valeurs propres en entrée, avec la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Remarque : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z.
!>
< dlarrv.f(3)

NAME

dlarrv - a subroutine.

SYNOPSIS

SUBROUTINE DLARRV( N, D, E, VL, VU, IL, IU, RTOL,
                          tol, IWORK, WORK, INFO )


      INTEGER            N


      DOUBLE PRECISION   D( * ), E( * ), VL, VU, RTOL, tol


      INTEGER            IL, IU, IWORK( * ), INFO


      DOUBLE PRECISION   WORK( * )

Function/Subroutine Documentation

This subroutine computes the eigenvectors of a symmetric tridiagonal matrix T for a given spectral range (VL, VU]. The eigenvalues are computed by calls to DLARRB. The eigenvectors are computed by calls to DLARRF.

Arguments:

N
!>          N is INTEGER
!>          The order of the matrix T.  1 <= N <= NMAX.
!
D
!>          D is DOUBLE PRECISION array, dimension (N)
!>          The diagonal entries of the tridiagonal matrix T.
!
E
!>          E is DOUBLE PRECISION array, dimension (N)
!>          The off-diagonal entries of the tridiagonal matrix T.
!>          E(1) is implicitly zero.
!
VL
!>          VL is DOUBLE PRECISION
!>          The lower bound of the interval for the desired eigenvalues.
!
VU
!>          VU is DOUBLE PRECISION
!>          The upper bound of the interval for the desired eigenvalues.
!
IL
!>          IL is INTEGER
!>          The starting index of the eigenvectors with relative dimension
!>          1 to IU.
!
IU
!>          IU is INTEGER
!>          The ending index of the eigenvectors with relative dimension
!>          1 to IU.
!
RTOL
!>          RTOL is DOUBLE PRECISION
!>          Relative tolerance for determining the desired cluster of
!>          eigenvalues.
!
tol
!>          tol is DOUBLE PRECISION
!>          Absolute tolerance for determining the desired cluster of
!>          eigenvalues.
!
ISUPPZ
!>          ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
!>          The support of the eigenvectors in Z, i.e., the indices
!>          indicating the nonzero elements in Z. The I-th eigenvector
!>          is nonzero only in elements ISUPPZ( 2*I-1 ) through
!>          ISUPPZ( 2*I ).
!
WORK
!>          WORK is DOUBLE PRECISION array, dimension (12*N)
!
IWORK
!>          IWORK is INTEGER array, dimension (7*N)
!
INFO
!>          INFO is INTEGER
!>          = 0:  successful exit
!>
!>          > 0:  A problem occurred in DLARRV.
!>          < 0:  One of the called subroutines signaled an internal problem.
!>                Needs inspection of the corresponding parameter IINFO
!>                for further information.
!>
!>          =-1:  Problem in DLARRB when refining a child's eigenvalues.
!>          =-2:  Problem in DLARRF when computing the RRR of a child.
!>                When a child is inside a tight cluster, it can be difficult
!>                to find an RRR. A partial remedy from the user's point of
!>                view is to make the parameter MINRGP smaller and recompile.
!>                However, as the orthogonality of the computed vectors is
!>                proportional to 1/MINRGP, the user should be aware that
!>                he might be trading in precision when he decreases MINRGP.
!>          =-3:  Problem in DLARRB when refining a single eigenvalue
!>                after the Rayleigh correction was rejected.
!>          = 5:  The Rayleigh Quotient Iteration failed to converge to
!>                full accuracy in MAXITR steps.
!
