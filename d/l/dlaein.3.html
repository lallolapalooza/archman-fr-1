Documentation de la fonction/sous-programme

sous-programme dlaein (logical rightv, logical noinit, integer n, double precision, dimension( ldh, * ) h, integer ldh, double precision wr, double precision wi, double precision, dimension( * ) vr, double precision, dimension( * ) vi, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) work, double precision eps3, double precision smlnum, double precision bignum, integer info)

DLAEIN calcule un vecteur propre droit ou gauche spécifié d'une matrice de Hessenberg supérieure par itération inverse.

Objectif :

!>
!> DLAEIN utilise l'itération inverse pour trouver un vecteur propre droit
!> ou gauche correspondant à la valeur propre (WR,WI) d'une matrice de
!> Hessenberg supérieure réelle H.
!>

Paramètres

RIGHTV 
!>          RIGHTV est LOGICAL
!>          = .TRUE. : calculer le vecteur propre droit ;
!>          = .FALSE.: calculer le vecteur propre gauche.
!>

NOINIT

!>          NOINIT est LOGICAL
!>          = .TRUE. : aucun vecteur initial fourni dans (VR,VI).
!>          = .FALSE.: vecteur initial fourni dans (VR,VI).
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice H.  N >= 0.
!>

H

!>          H est un tableau DOUBLE PRECISION, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>

LDH

!>          LDH est INTEGER
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

WR

!>          WR est DOUBLE PRECISION
!>

WI

!>          WI est DOUBLE PRECISION
!>          Les parties réelle et imaginaire de la valeur propre de H dont
!>          le vecteur propre droit ou gauche correspondant doit être calculé.
!>

VR

!>          VR est un tableau DOUBLE PRECISION, dimension (N)
!>

VI

!>          VI est un tableau DOUBLE PRECISION, dimension (N)
!>          En entrée, si NOINIT = .FALSE. et WI = 0.0, VR doit contenir
!>          un vecteur de départ réel pour l'itération inverse utilisant la
!>          valeur propre réelle WR ; si NOINIT = .FALSE. et WI.ne.0.0, VR et VI
!>          doivent contenir les parties réelle et imaginaire d'un vecteur
!>          de départ complexe pour l'itération inverse utilisant la valeur
!>          propre complexe (WR,WI) ; sinon VR et VI n'ont pas besoin d'être
!>          définis.
!>          En sortie, si WI = 0.0 (valeur propre réelle), VR contient le
!>          vecteur propre réel calculé ; si WI.ne.0.0 (valeur propre complexe),
!>          VR et VI contiennent les parties réelle et imaginaire du
!>          vecteur propre complexe calculé. Le vecteur propre est normalisé
!>          de sorte que la composante de magnitude maximale ait une magnitude de 1 ;
!>          ici, la magnitude d'un nombre complexe (x,y) est considérée comme
!>          |x| + |y|.
!>          VI n'est pas référencé si WI = 0.0.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= N+1.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (N)
!>

EPS3

!>          EPS3 est DOUBLE PRECISION
!>          Une petite valeur dépendant de la machine qui est utilisée pour
!>          perturber les valeurs propres proches, et pour remplacer les
!>          pivots nuls.
!>

SMLNUM

!>          SMLNUM est DOUBLE PRECISION
!>          Une valeur dépendant de la machine proche du seuil de
!>          sous-dépassement.
!>

BIGNUM

!>          BIGNUM est DOUBLE PRECISION
!>          Une valeur dépendant de la machine proche du seuil de
!>          dépassement.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          = 1 : l'itération inverse n'a pas convergé ; VR est défini sur la
!>                dernière itération, et VI aussi si WI.ne.0.0.
!>
