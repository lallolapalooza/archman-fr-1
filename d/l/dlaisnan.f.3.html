fonction logique dlaisnan (double precision, intent(in) din1, double precision, intent(in) din2)

DLAISNAN vérifie les NaN en comparant deux arguments pour l'inégalité.

Objectif :

!>
!> Cette routine n'est pas pour un usage général. Elle existe uniquement pour éviter
!> une sur-optimisation dans DISNAN.
!>
!> DLAISNAN vérifie la présence de NaN en comparant ses deux arguments pour
!> l'inégalité. NaN est la seule valeur flottante pour laquelle NaN != NaN
!> renvoie .TRUE. Pour vérifier les NaN, passez la même variable comme les deux
!> arguments.
!>
!> Un compilateur doit supposer que les deux arguments ne sont pas la même variable,
!> et le test ne sera pas optimisé. L'optimisation interprocédurale ou sur
!> l'ensemble du programme peut supprimer ce test. Les fonctions ISNAN seront
!> remplacées par l'intrinsèque Fortran 03 correct une fois que l'intrinsèque
!> sera largement disponible.
!>

Paramètres

DIN1 
!>          DIN1 est DOUBLE PRECISION
!>

DIN2

!>          DIN2 est DOUBLE PRECISION
!>          Deux nombres à comparer pour l'inégalité.
!>
