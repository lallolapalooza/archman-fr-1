sous-routine dlatme (integer n, character dist, integer, dimension( 4 ) iseed, double precision, dimension( * ) d, integer mode, double precision cond, double precision dmax, character, dimension( * ) ei, character rsign, character upper, character sim, double precision, dimension( * ) ds, integer modes, double precision conds, integer kl, integer ku, double precision anorm, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work, integer

DLATM

E

But

: 
!>
!>    DLATME génère des matrices carrées non symétriques aléatoires avec
!>    des valeurs propres spécifiées pour tester les programmes LAPACK.
!>
!>    DLATME fonctionne en appliquant la séquence suivante
!>    d'opérations :
!>
!>    1. Définit la diagonale à D, où D peut être en entrée ou
!>         calculé selon MODE, COND, DMAX et RSIGN
!>         comme décrit ci-dessous.
!>
!>    2. Si des paires conjuguées complexes sont souhaitées (MODE=0 et EI(1)='R',
!>         ou MODE=5), certaines paires d'éléments adjacents de D sont
!>         interprétées comme les parties réelle et imaginaire d'une paire
!>         conjuguée complexe ; A devient ainsi bloc-diagonale, avec des blocs
!>         1x1 et 2x2.
!>
!>    3. Si UPPER='T', le triangle supérieur de A est défini à des valeurs
!>         aléatoires issues de la distribution DIST.
!>
!>    4. Si SIM='T', A est multipliée à gauche par une matrice aléatoire
!>         X, dont les valeurs singulières sont spécifiées par DS, MODES et
!>         CONDS, et à droite par l'inverse de X.
!>
!>    5. Si KL < N-1, la largeur de bande inférieure est réduite à KL en utilisant
!>         des transformations de Householder. Si KU < N-1, la largeur de bande
!>         supérieure est réduite à KU.
!>
!>    6. Si ANORM n'est pas négatif, la matrice est mise à l'échelle pour avoir
!>         une norme maximale des éléments ANORM.
!>
!>    (Remarque : puisque la matrice ne peut pas être réduite au-delà de la forme
!>     de Hessenberg, aucune option de compression n'est disponible.)
!
>

Paramètre

s
N 
!>          N est INTEGER
!>           Le nombre de colonnes (ou de lignes) de A. Non modifié.
!
>

DIS

T 
!>          DIST est CHARACTER*1
!>           À l'entrée, DIST spécifie le type de distribution à utiliser
!>           pour générer les valeurs propres/singulières aléatoires, et pour le
!>           triangle supérieur (voir UPPER).
!>           'U' => UNIFORM( 0, 1 )  ( 'U' pour uniforme )
!>           'S' => UNIFORM( -1, 1 ) ( 'S' pour symétrique )
!>           'N' => NORMAL( 0, 1 )   ( 'N' pour normale )
!>           Non modifié.
!
>

ISEE

D 
!>          ISEED est un tableau INTEGER, dimension ( 4 )
!>           À l'entrée, ISEED spécifie la graine du générateur de nombres
!>           aléatoires. Elle doit être comprise entre 0 et 4095 inclus,
!>           et ISEED(4) doit être impair. Le générateur de nombres aléatoires
!>           utilise une suite congruentielle linéaire limitée à de petits
!>           entiers, et devrait donc produire des nombres aléatoires
!>           indépendants de la machine. Les valeurs de ISEED sont modifiées à
!>           la sortie, et peuvent être utilisées dans le prochain appel à DLATME
!>           pour continuer la même suite de nombres aléatoires.
!>           Modifié à la sortie.
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension ( N )
!>           Ce tableau est utilisé pour spécifier les valeurs propres de A. Si
!>           MODE=0, alors D est supposé contenir les valeurs propres (mais
!>           voir la description de EI), sinon elles seront
!>           calculées selon MODE, COND, DMAX et RSIGN et
!>           placées dans D.
!>           Modifié si MODE est non nul.
!
>

MOD

E 
!>          MODE est INTEGER
!>           À l'entrée, cela décrit comment les valeurs propres doivent
!>           être spécifiées :
!>           MODE = 0 signifie utiliser D (avec EI) en entrée
!>           MODE = 1 définit D(1)=1 et D(2:N)=1.0/COND
!>           MODE = 2 définit D(1:N-1)=1 et D(N)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    soient uniformément distribués. Chaque paire impaire-paire
!>                    d'éléments sera soit utilisée comme deux valeurs propres
!>                    réelles, soit comme la partie réelle et imaginaire
!>                    d'une paire conjuguée complexe de valeurs propres ;
!>                    le choix de l'une ou l'autre est aléatoire, avec
!>                    une probabilité de 50-50, pour chaque paire.
!>           MODE = 6 définit D à des nombres aléatoires de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est compris entre 1 et 4, D a des entrées allant
!>              de 1 à 1/COND, si entre -1 et -4, D a des entrées
!>              allant de 1/COND à 1,
!>           Non modifié.
!
>

CON

D 
!>          COND est DOUBLE PRECISION
!>           À l'entrée, il est utilisé comme décrit sous MODE ci-dessus.
!>           S'il est utilisé, il doit être >= 1. Non modifié.
!
>

DMA

X 
!>          DMAX est DOUBLE PRECISION
!>           Si MODE n'est ni -6, 0 ni 6, le contenu de D, tel que
!>           calculé selon MODE et COND, sera mis à l'échelle par
!>           DMAX / max(abs(D(i))). Notez que DMAX n'a pas besoin d'être
!>           positif : si DMAX est négatif (ou zéro), D sera
!>           mis à l'échelle par un nombre négatif (ou zéro).
!>           Non modifié.
!
>

E

I 
!>          EI est un tableau CHARACTER*1, dimension ( N )
!>           Si MODE est 0, et EI(1) n'est pas ' ' (caractère espace),
!>           ce tableau spécifie quels éléments de D (en entrée) sont
!>           des valeurs propres réelles et lesquels sont les parties réelle et imaginaire
!>           d'une paire conjuguée complexe de valeurs propres. Les éléments
!>           de EI ne peuvent alors avoir que les valeurs 'R' et 'I'. Si
!>           EI(j)='R' et EI(j+1)='I', alors la j-ième valeur propre est
!>           CMPLX( D(j) , D(j+1) ), et la (j+1)-ième est le conjugué complexe
!>           de celle-ci. Si EI(j)=EI(j+1)='R', alors la j-ième
!>           valeur propre est D(j) (c.-à-d. réelle). EI(1) ne peut pas être 'I',
!>           ni deux éléments adjacents de EI ne peuvent avoir la valeur 'I'.
!>           Si MODE n'est pas 0, alors EI est ignoré. Si MODE est 0 et
!>           EI(1)=' ', alors les valeurs propres seront toutes réelles.
!>           Non modifié.
!
>

RSIG

N 
!>          RSIGN est CHARACTER*1
!>           Si MODE n'est pas 0, 6 ou -6, et RSIGN='T', alors les
!>           éléments de D, tels que calculés selon MODE et COND, seront
!>           multipliés par un signe aléatoire (+1 ou -1). Si RSIGN='F',
!>           ils ne le seront pas. RSIGN ne peut avoir que les valeurs 'T' ou
!>           'F'.
!>           Non modifié.
!
>

UPPE

R 
!>          UPPER est CHARACTER*1
!>           Si UPPER='T', alors les éléments de A au-dessus de la diagonale
!>           (et au-dessus des blocs diagonaux 2x2, si A a des valeurs propres
!>           complexes) seront définis à des nombres aléatoires issus de DIST.
!>           Si UPPER='F', ils ne le seront pas. UPPER ne peut avoir que les
!>           valeurs 'T' ou 'F'.
!>           Non modifié.
!
>

SI

M 
!>          SIM est CHARACTER*1
!>           Si SIM='T', alors A sera opéréeted on by a , i.e., multiplied on the left by a matrix X and
!>           on the right by X inverse.  X = U S V, where U and V are
!>           random unitary matrices and S is a (diagonal) matrix of
!>           singular values specified by DS, MODES, and CONDS.  If
!>           SIM='F', then A will not be transformed.
!>           Not modified.
!
>

D

S 
!>          DS is DOUBLE PRECISION array, dimension ( N )
!>           This array is used to specify the singular values of X,
!>           in the same way that D specifies the eigenvalues of A.
!>           If MODE=0, the DS contains the singular values, which
!>           may not be zero.
!>           Modified if MODE is nonzero.
!
>

MODE

S 
!>          MODES is INTEGER
!
>

COND

S 
!>          CONDS is DOUBLE PRECISION
!>           Same as MODE and COND, but for specifying the diagonal
!>           of S.  MODES=-6 and +6 are not allowed (since they would
!>           result in randomly ill-conditioned eigenvalues.)
!
>

K

L 
!>          KL is INTEGER
!>           This specifies the lower bandwidth of the  matrix.  KL=1
!>           specifies upper Hessenberg form.  If KL is at least N-1,
!>           then A will have full lower bandwidth.  KL must be at
!>           least 1.
!>           Not modified.
!
>

K

U 
!>          KU is INTEGER
!>           This specifies the upper bandwidth of the  matrix.  KU=1
!>           specifies lower Hessenberg form.  If KU is at least N-1,
!>           then A will have full upper bandwidth; if KU and KL
!>           are both at least N-1, then A will be dense.  Only one of
!>           KU and KL may be less than N-1.  KU must be at least 1.
!>           Not modified.
!
>

ANOR

M 
!>          ANORM is DOUBLE PRECISION
!>           If ANORM is not negative, then A will be scaled by a non-
!>           negative real number to make the maximum-element-norm of A
!>           to be ANORM.
!>           Not modified.
!
>

A 
!>          A is DOUBLE PRECISION array, dimension ( LDA, N )
!>           On exit A is the desired test matrix.
!>           Modified.
!
>

LD

A 
!>          LDA is INTEGER
!>           LDA specifies the first dimension of A as declared in the
!>           calling program.  LDA must be at least N.
!>           Not modified.
!
>

WOR

K 
!>          WORK is DOUBLE PRECISION array, dimension ( 3*N )
!>           Workspace.
!>           Modified.
!
>

INF

O 
!>          INFO is INTEGER
!>           Error code.  On exit, INFO will be set to one of the
!>           following values:
!>             0 => normal return
!>            -1 => N negative
!>            -2 => DIST illegal string
!>            -5 => MODE not in range -6 to 6
!>            -6 => COND less than 1.0, and MODE neither -6, 0 nor 6
!>            -8 => EI(1) is not ' ' or 'R', EI(j) is not 'R' or 'I', or
!>                  two adjacent elements of EI are 'I'.
!>            -9 => RSIGN is not 'T' or 'F'
!>           -10 => UPPER is not 'T' or 'F'
!>           -11 => SIM   is not 'T' or 'F'
!>           -12 => MODES=0 and DS has a zero singular value.
!>           -13 => MODES is not in the range -5 to 5.
!>           -14 => MODES is nonzero and CONDS is less than 1.
!>           -15 => KL is less than 1.
!>           -16 => KU is less than 1, or KL and KU are both less than
!>                  N-1.
!>           -19 => LDA is less than N.
!>            1  => Error return from DLATM1 (computing D)
!>            2  => Cannot scale to DMAX (max. eigenvalue is 0)
!>            3  => Error return from DLATM1 (computing DS)
!>            4  => Error return from DLARGE
!>            5  => Zero singular value from DLATM1.
!
>
