sous-programme dlasq2 (entier n, double précision, dimension( * ) z, entier info)

DLASQ2 calcule toutes les valeurs propres de la matrice tridiagonale symétrique définie positive associée au tableau qd Z, avec une grande précision relative. Utilisé par sbdsqr et sstegr.

Objectif :

!>
!> DLASQ2 calcule toutes les valeurs propres de la matrice tridiagonale symétrique
!> définie positive associée au tableau qd Z avec une grande précision relative,
!> en l'absence de dénormalisation, de sous-dépassement et de dépassement.
!>
!> Pour voir la relation entre Z et la matrice tridiagonale, soit L une
!> matrice triangulaire inférieure unitaire avec des sous-diagonales Z(2,4,6,,..)
!> et soit U une matrice bimodale avec des 1 au-dessus et une diagonale
!> Z(1,3,5,..). La matrice tridiagonale est L*U ou, si vous préférez, la
!> matrice tridiagonale symétrique à laquelle elle est similaire.
!>
!> Note : DLASQ2 définit une variable booléenne, IEEE, qui est vraie
!> sur les machines qui suivent la norme de virgule flottante ieee-754 dans leur
!> gestion des infinis et des NaN, et fausse sinon. Cette variable
!> est passée à DLASQ3.
!>

Paramètres

N 
!>          N est un ENTIER
!>        Le nombre de lignes et de colonnes de la matrice. N >= 0.
!>

Z

!>          Z est un tableau de DOUBLE PRÉCISION, de dimension ( 4*N )
!>        À l'entrée, Z contient le tableau qd. À la sortie, les entrées 1 à N contiennent
!>        les valeurs propres dans l'ordre décroissant, Z( 2*N+1 ) contient
!>        la trace, et Z( 2*N+2 ) contient la somme des valeurs propres. Si
!>        N > 2, alors Z( 2*N+3 ) contient le nombre d'itérations, Z( 2*N+4 )
!>        contient NDIVS/NIN^2, et Z( 2*N+5 ) contient le pourcentage
!>        des décalages qui ont échoué.
!>

INFO

!>          INFO est un ENTIER
!>        = 0 : sortie réussie
!>        < 0 : si le i-ème argument est un scalaire et avait une valeur illégale, alors INFO = -i, si le i-ème argument est un
!>             tableau et que l'entrée j avait une valeur illégale, alors
!>             INFO = -(i*100+j)
!>        > 0 : l'algorithme a échoué
!>              = 1, un scission a été marquée par une valeur positive dans E
!>              = 2, le bloc actuel de Z n'a pas été diagonalisé après 100*N
!>                   itérations (dans la boucle while interne). À la sortie, Z contient
!>                   un tableau qd avec les mêmes valeurs propres que le Z donné.
!>              = 3, le critère de terminaison de la boucle while externe n'a pas été satisfait
!>                   (le programme a créé plus de N blocs non réduits)
!>

Détails supplémentaires :

!>
!>  Variables locales : I0:N0 définit un segment non réduit actuel de Z.
!>  Les décalages sont accumulés dans SIGMA. Le compteur d'itérations est dans ITER.
!>  Le ping-pong est contrôlé par PP (alterne entre 0 et 1).
!>
