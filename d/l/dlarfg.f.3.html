Documentation de la fonction/sous-programme

sous-programme dlarfg (integer n, double precision alpha, double precision, dimension( * ) x, integer incx, double precision tau)

DLARFG génère un réflecteur élémentaire réel (matrice de Householder).

Objectif :

!>
!> DLARFG génère un réflecteur élémentaire réel H d'ordre n, tel que
!>
!>       H * ( alpha ) = ( beta ),   H**T * H = I.
!>           (   x   )   (   0  )
!>
!> où alpha et beta sont des scalaires, et x est un vecteur réel de (n-1) éléments.
!> H est représenté sous la forme
!>
!>       H = I - tau * ( 1 ) * ( 1 v**T ) ,
!>                     ( v )
!>
!> où tau est un scalaire réel et v est un vecteur réel de (n-1) éléments.
!>
!> Si tous les éléments de x sont nuls, alors tau = 0 et H est prise comme
!> la matrice unité.
!>
!> Sinon, 1 <= tau <= 2.
!>

Paramètres

N 
!>          N est INTEGER
!>          L'ordre du réflecteur élémentaire.
!>

ALPHA

!>          ALPHA est DOUBLE PRECISION
!>          À l'entrée, la valeur alpha.
!>          À la sortie, elle est écrasée par la valeur beta.
!>

X

!>          X est un tableau DOUBLE PRECISION, de dimension
!>                         (1+(N-2)*abs(INCX))
!>          À l'entrée, le vecteur x.
!>          À la sortie, il est écrasé par le vecteur v.
!>

INCX

!>          INCX est INTEGER
!>          Le pas entre les éléments de X. INCX > 0.
!>

TAU

!>          TAU est DOUBLE PRECISION
!>          La valeur tau.
!>
