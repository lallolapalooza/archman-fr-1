subroutine dlagts (job, n, a, b, c, d, in, y, tol, info)
DLAGTS résout le système d'équations (T-λI)x = y ou (T-λI)^Tx = y, où T est une matrice tridiagonale générale et λ un scalaire, en utilisant la factorisation LU calculée par slagtf.

Documentation de la fonction/sous-programme

sous-programme dlagts (entier job, entier n, double précision, dimension( * ) a, double précision, dimension( * ) b, double précision, dimension( * ) c, double précision, dimension( * ) d, entier, dimension( * ) in, double précision, dimension( * ) y, double précision tol, entier info)

DLAGTS résout le système d'équations (T-λI)x = y ou (T-λI)^Tx = y, où T est une matrice tridiagonale générale et λ un scalaire, en utilisant la factorisation LU calculée par slagtf.

Objectif :

!>
!> DLAGTS peut être utilisé pour résoudre l'un des systèmes d'équations
!>
!>    (T - lambda*I)*x = y   ou   (T - lambda*I)**T*x = y,
!>
!> où T est une matrice tridiagonale n x n, pour x, suite à la
!> factorisation de (T - lambda*I) en
!>
!>    (T - lambda*I) = P*L*U ,
!>
!> par la routine DLAGTF. Le choix de l'équation à résoudre est
!> contrôlé par l'argument JOB, et dans chaque cas, il y a une option
!> pour perturber les éléments diagonaux nuls ou très petits de U, cette option
!> étant destinée à être utilisée dans des applications telles que l'itération inverse.
!>

Paramètres

JOB 
!>          JOB est ENTIER
!>          Spécifie la tâche à effectuer par DLAGTS comme suit :
!>          =  1 : Les équations  (T - lambda*I)x = y  doivent être résolues,
!>                mais les éléments diagonaux de U ne doivent pas être perturbés.
!>          = -1 : Les équations  (T - lambda*I)x = y  doivent être résolues
!>                et, si un dépassement de capacité se produirait autrement, les éléments
!>                diagonaux de U doivent être perturbés. Voir l'argument TOL
!>                ci-dessous.
!>          =  2 : Les équations  (T - lambda*I)**Tx = y  doivent être résolues,
!>                mais les éléments diagonaux de U ne doivent pas être perturbés.
!>          = -2 : Les équations  (T - lambda*I)**Tx = y  doivent être résolues
!>                et, si un dépassement de capacité se produirait autrement, les éléments
!>                diagonaux de U doivent être perturbés. Voir l'argument TOL
!>                ci-dessous.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice T.
!>

A

!>          A est un tableau DOUBLE PRÉCISION, dimension (N)
!>          À l'entrée, A doit contenir les éléments diagonaux de U tels que
!>          retournés par DLAGTF.
!>

B

!>          B est un tableau DOUBLE PRÉCISION, dimension (N-1)
!>          À l'entrée, B doit contenir les premiers éléments supradiagonaux de
!>          U tels que retournés par DLAGTF.
!>

C

!>          C est un tableau DOUBLE PRÉCISION, dimension (N-1)
!>          À l'entrée, C doit contenir les éléments sous-diagonaux de L tels que
!>          retournés par DLAGTF.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (N-2)
!>          À l'entrée, D doit contenir les deuxièmes éléments supradiagonaux
!>          de U tels que retournés par DLAGTF.
!>

IN

!>          IN est un tableau ENTIER, dimension (N)
!>          À l'entrée, IN doit contenir les détails de la matrice P tels que retournés
!>          par DLAGTF.
!>

Y

!>          Y est un tableau DOUBLE PRÉCISION, dimension (N)
!>          À l'entrée, le vecteur du membre de droite y.
!>          À la sortie, Y est écrasé par le vecteur solution x.
!>

TOL

!>          TOL est DOUBLE PRÉCISION
!>          À l'entrée, avec  JOB < 0, TOL doit être la perturbation
!>          minimale à apporter aux éléments diagonaux très petits de U.
!>          TOL doit normalement être choisi d'environ eps*norm(U), où eps
!>          est la précision relative de la machine, mais si TOL est fourni comme
!>          non positif, alors il est réinitialisé à eps*max( abs( u(i,j) ) ).
!>          Si  JOB > 0  alors TOL n'est pas référencé.
!>
!>          À la sortie, TOL est modifié comme décrit ci-dessus, uniquement si TOL est
!>          non positif à l'entrée. Sinon, TOL reste inchangé.
!>

INFO

!>          INFO est ENTIER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  un dépassement de capacité se produirait lors du calcul de l'élément INFO
!>                du vecteur solution x. Cela ne peut se produire que
!>                lorsque JOB est fourni comme positif et signifie soit
!>                qu'un élément diagonal de U est très petit, soit
!>                que les éléments du vecteur membre de droite y sont très
!>                grands.
!>
