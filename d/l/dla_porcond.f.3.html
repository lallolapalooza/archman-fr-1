double precision function dla_porcond (character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer cmode, double precision, dimension( * ) c, integer info, double precision, dimension( * ) work, integer, dimension( * ) iwork)

DLA_PORCOND estime le nombre de condition de Skeel pour une matrice symétrique définie positive.

Objectif :

!>
!>    DLA_PORCOND Estime le nombre de condition de Skeel de  op(A) * op2(C)
!>    où op2 est déterminé par CMODE comme suit
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    Le nombre de condition de Skeel  cond(A) = norminf( |inv(A)||A| )
!>    est calculé en calculant des facteurs d'échelle R tels que
!>    diag(R)*A*op2(C) est équilibré en ligne et en calculant le nombre de condition
!>    standard de la norme infinie.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau DOUBLE PRECISION, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T, tel que calculé par DPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

CMODE

!>          CMODE est INTEGER
!>     Détermine op2(C) dans la formule op(A) * op2(C) comme suit :
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (N)
!>     Le vecteur C dans la formule op(A) * op2(C).
!>

INFO

!>          INFO est INTEGER
!>       = 0 :  Sortie réussie.
!>     i > 0 :  Le i-ème argument est invalide.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (3*N).
!>     Espace de travail.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N).
!>     Espace de travail.
!>
