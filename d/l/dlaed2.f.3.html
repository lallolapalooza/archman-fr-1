sous-programme dlaed2 (entier k, entier n, entier n1, double précision, dimension( * ) d, double précision, dimension( ldq, * ) q, entier ldq, entier, dimension( * ) indxq, double précision rho, double précision, dimension( * ) z, double précision, dimension( * ) dlambda, double précision, dimension( * ) w, double précision, dimension( * ) q2, entier, dimension( * ) indx, entier, dimension( * ) indxc, entier, dimension( * ) indxp, entier, dimension( * ) coltyp, entier info)

DLAED2 utilisé par DSTEDC. Fusionne les valeurs propres et déflate l'équation séculaire. Utilisé lorsque la matrice originale est tridiagonale.

Objectif:

!>
!> DLAED2 fusionne les deux ensembles de valeurs propres en un seul
!> ensemble trié. Ensuite, il essaie de déflater la taille du problème.
!> Il existe deux façons dont la déflation peut se produire : lorsque deux valeurs propres ou plus sont proches l'une de l'autre, ou s'il y a une entrée minuscule dans le
!> vecteur Z. Pour chaque occurrence de ce type, l'ordre du problème d'équation séculaire lié est réduit de un.
!>

Paramètres

K 
!>          K est ENTIER
!>         Le nombre de valeurs propres non déflatées, et l'ordre de l'équation séculaire associée. 0 <= K <=N.
!>

N

!>          N est ENTIER
!>         La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

N1

!>          N1 est ENTIER
!>         L'emplacement de la dernière valeur propre dans la sous-matrice principale.
!>         min(1,N) <= N1 <= N/2.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (N)
!>         À l'entrée, D contient les valeurs propres des deux sous-matrices à combiner.
!>         À la sortie, D contient les dernières (N-K) valeurs propres mises à jour
!>         (celles qui ont été déflatées) triées par ordre croissant.
!>

Q

!>          Q est un tableau DOUBLE PRÉCISION, dimension (LDQ, N)
!>         À l'entrée, Q contient les vecteurs propres de deux sous-matrices dans
!>         les deux blocs carrés avec coins en (1,1), (N1,N1)
!>         et (N1+1, N1+1), (N,N).
!>         À la sortie, Q contient les dernières (N-K) vecteurs propres mises à jour
!>         (celles qui ont été déflatées) dans ses N-K dernières colonnes.
!>

LDQ

!>          LDQ est ENTIER
!>         La dimension principale du tableau Q. LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ est un tableau ENTIER, dimension (N)
!>         La permutation qui trie séparément les deux sous-problèmes
!>         en D par ordre croissant. Notez que les éléments de la seconde
!>         moitié de cette permutation doivent d'abord avoir N1 ajouté à leurs
!>         valeurs. Détruit à la sortie.
!>

RHO

!>          RHO est DOUBLE PRÉCISION
!>         À l'entrée, l'élément hors diagonale associé à la coupe de rang 1
!>         qui a initialement divisé les deux sous-matrices qui sont maintenant
!>         en cours de combinaison.
!>         À la sortie, RHO a été modifié pour prendre la valeur requise par
!>         DLAED3.
!>

Z

!>          Z est un tableau DOUBLE PRÉCISION, dimension (N)
!>         À l'entrée, Z contient le vecteur de mise à jour (la dernière
!>         ligne de la première matrice de sous-vecteurs propres et la première ligne de
!>         la deuxième matrice de sous-vecteurs propres).
!>         À la sortie, le contenu de Z a été détruit par le processus de mise à jour.
!>

DLAMBDA

!>          DLAMBDA est un tableau DOUBLE PRÉCISION, dimension (N)
!>         Une copie des K premières valeurs propres qui seront utilisées par
!>         DLAED3 pour former l'équation séculaire.
!>

W

!>          W est un tableau DOUBLE PRÉCISION, dimension (N)
!>         Les K premières valeurs du vecteur z final modifié par déflation
!>         qui sera passé à DLAED3.
!>

Q2

!>          Q2 est un tableau DOUBLE PRÉCISION, dimension (N1**2+(N-N1)**2)
!>         Une copie des K premiers vecteurs propres qui seront utilisés par
!>         DLAED3 dans une multiplication de matrices (DGEMM) pour résoudre les nouveaux
!>         vecteurs propres.
!>

INDX

!>          INDX est un tableau ENTIER, dimension (N)
!>         La permutation utilisée pour trier le contenu de DLAMBDA par
!>         ordre croissant.
!>

INDXC

!>          INDXC est un tableau ENTIER, dimension (N)
!>         La permutation utilisée pour organiser les colonnes de la matrice Q déflatée
!>         en trois groupes : le premier groupe contient des éléments non nuls
!>         uniquement au-dessus de N1, le second contient des éléments non nuls
!>         uniquement en dessous de N1, et le troisième est dense.
!>

INDXP

!>          INDXP est un tableau ENTIER, dimension (N)
!>         La permutation utilisée pour placer les valeurs déflatées de D à la fin
!>         du tableau. INDXP(1:K) pointe vers les valeurs D non déflatées
!>         et INDXP(K+1:N) pointe vers les valeurs propres déflatées.
!>

COLTYP

!>          COLTYP est un tableau ENTIER, dimension (N)
!>         Pendant l'exécution, une étiquette qui indiquera quel type
!>         une colonne dans la matrice Q2 est :
!>         1 : non nulle dans la moitié supérieure seulement ;
!>         2 : dense ;
!>         3 : non nulle dans la moitié inférieure seulement ;
!>         4 : déflatée.
!>         À la sortie, COLTYP(i) est le nombre de colonnes de type i,
!>         pour i=1 à 4 seulement.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Documentation de la fonction/sous-routine

dlaed2 calcule les vecteurs propres pour la matrice de problème des petites valeurs propres diagonales qui se produisent lors du calcul des valeurs propres d'une matrice symétrique tridiagonale.

dlaed2 est appelé par dlaed1, dlaed3 et dlaed6.

Arguments :

  • KC : REAL(8) tableau de taille (NE). Contient les valeurs propres du sous-problème.
  • NE : INTEGER. Le nombre de valeurs propres à calculer.
  • KOUT : INTEGER. Le nombre de valeurs propres sélectionnées.
  • Z : REAL(8) tableau de taille (LDZ, *). Contient les vecteurs propres du sous-problème.
  • LDZ : INTEGER. Le premier indice de dimension de Z.
  • SUMM : REAL(8) tableau de taille (NE). Contient la somme des carrés des vecteurs propres du sous-problème.
  • RL : REAL(8) tableau de taille (NE). Contient les valeurs propres de la matrice de mise à jour.
  • GU : REAL(8) tableau de taille (NE). Contient les valeurs propres des matrices de mise à jour supérieures.
  • GD : REAL(8) tableau de taille (NE). Contient les valeurs propres des matrices de mise à jour inférieures.
  • R : REAL(8) tableau de taille (NE). Contient les valeurs propres de la matrice de mise à jour.
  • CI : REAL(8) tableau de taille (NE). Contient les valeurs propres de la matrice de mise à jour imaginaire.
  • CUT : REAL(8). La valeur de coupure pour la sélection des valeurs propres.
  • ZERR : REAL(8) tableau de taille (NE). Contient les erreurs sur les vecteurs propres.
  • INFO : INTEGER. Indicateur d'erreur. 0 si succès, < 0 si erreur.
