Documentation de la fonction/sous-routine

sous-routine dlavsp (character uplo, character trans, character diag, integer n, integer nrhs, double precision, dimension( * ) a, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, integer info)

DLAVSP

But:

!>
!> DLAVSP  effectue une des opérations matrice-vecteur
!>    x := A*x  ou  x := A'*x,
!> où x est un vecteur de N éléments et  A est l'un des facteurs
!> de la factorisation bloc U*D*U' ou L*D*L' calculée par DSPTRF.
!>
!> Si TRANS = 'N', multiplication par U  ou U * D  (ou L  ou L * D)
!> Si TRANS = 'T', multiplication par U' ou D * U' (ou L' ou D * L' )
!> Si TRANS = 'C', multiplication par U' ou D * U' (ou L' ou D * L' )
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si le facteur stocké dans A est triangulaire supérieur ou inférieur.
!>          = 'U':  Triangulaire supérieur
!>          = 'L':  Triangulaire inférieur
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération à effectuer :
!>          = 'N':  x := A*x
!>          = 'T':  x := A'*x
!>          = 'C':  x := A'*x
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si les blocs diagonaux sont des matrices unités ou non.
!>          Si les blocs diagonaux sont supposés être unités, alors A = U ou A = L,
!>          sinon A = U*D ou A = L*D.
!>          = 'U':  Les blocs diagonaux sont supposés être des matrices unités.
!>          = 'N':  Les blocs diagonaux sont supposés être des matrices non unités.
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de vecteurs
!>          x à multiplier par A.  NRHS >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (N*(N+1)/2)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L, stockés sous forme de matrice triangulaire compacte
!>          telle que calculée par DSPTRF.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Les indices de pivot de DSPTRF.
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (LDB,NRHS)
!>          À l'entrée, B contient NRHS vecteurs de longueur N.
!>          À la sortie, B est écrasé par le produit A * B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0: succès
!>          < 0: si INFO = -k, alors le k-ième argument avait une valeur illégale
!>
