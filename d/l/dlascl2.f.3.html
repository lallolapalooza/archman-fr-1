Documentation de la fonction/sous-routine

sous-routine dlascl2 (integer m, integer n, double precision, dimension( * ) d, double precision, dimension( ldx, * ) x, integer ldx)

DLASCL2 effectue une mise à l'échelle diagonale d'une matrice.

Objectif :

!>
!> DLASCL2 effectue une mise à l'échelle diagonale d'une matrice :
!>   x <-- D * x
!> où la matrice diagonale D est stockée sous forme de vecteur.
!>
!> À remplacer éventuellement par BLAS_dge_diag_scale dans la nouvelle norme BLAS.
!>

Paramètres

M 
!>          M est un entier
!>     Le nombre de lignes de D et X. M >= 0.
!>

N

!>          N est un entier
!>     Le nombre de colonnes de X. N >= 0.
!>

D

!>          D est un tableau de double précision, longueur M
!>     Matrice diagonale D, stockée sous forme de vecteur de longueur M.
!>

X

!>          X est un tableau de double précision, dimension (LDX,N)
!>     À l'entrée, la matrice X à mettre à l'échelle par D.
!>     À la sortie, la matrice mise à l'échelle.
!>

LDX

!>          LDX est un entier
!>     La dimension principale de la matrice X. LDX >= M.
!>
