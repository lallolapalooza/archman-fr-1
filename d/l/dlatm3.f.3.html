!>
!>    DLATM3 renvoie l'élément (ISUB,JSUB) d'une matrice aléatoire de
!>    dimension (M, N) décrite par les autres paramètres. (ISUB,JSUB)
!>    est la position finale de l'élément (I,J) après la permutation
!>    selon IPVTNG et IWORK. DLATM3 est appelée par la
!>    routine DLATMR afin de construire des matrices de test aléatoires. Aucune vérification
!>    d'erreur n'est effectuée sur les paramètres, car cette routine est appelée dans une
!>    boucle serrée par DLATMR qui a déjà vérifié les paramètres.
!>
!>    L'utilisation de DLATM3 diffère de celle de SLATM2 dans l'ordre dans lequel le
!>    générateur de nombres aléatoires est appelé pour remplir les éléments de la matrice aléatoire.
!>    Avec DLATM2, le générateur est appelé pour remplir la matrice pivotée
!>    colonne par colonne. Avec DLATM3, le générateur est appelé pour remplir la
!>    matrice colonne par colonne, après quoi elle est pivotée. Ainsi, DLATM3 peut
!>    être utilisée pour construire des matrices aléatoires qui ne diffèrent que par leur
!>    ordre de lignes et/ou de colonnes. DLATM2 est utilisée pour construire des matrices
!>    en bande tout en évitant d'appeler le générateur de nombres aléatoires pour les
!>    éléments hors de la bande (et donc en générant des nombres aléatoires
!>    dans des ordres différents pour des ordres de pivot différents).
!>
!>    La matrice dont l'élément (ISUB,JSUB) est renvoyé est construite comme
!>    suit (cette routine ne calcule qu'un seul élément) :
!>
!>      Si ISUB est en dehors de (1..M) ou JSUB est en dehors de (1..N), renvoyer zéro
!>         (ce qui est pratique pour générer des matrices au format bande).
!>
!>      Générer une matrice A avec des éléments aléatoires de distribution IDIST.
!>
!>      Définir la diagonale à D.
!>
!>      Échelonner la matrice, si désiré, depuis la gauche (par DL) et/ou
!>         depuis la droite (par DR ou DL) comme spécifié par IGRADE.
!>
!>      Permuter, si désiré, les lignes et/ou les colonnes comme spécifié par
!>         IPVTNG et IWORK.
!>
!>      Mettre la matrice en bande pour avoir une bande inférieure KL et une bande
!>         supérieure KU.
!>
!>      Mettre les éléments aléatoires à zéro comme spécifié par SPARSE.
!
>

Paramètre

s
M 
!>          M est INTEGER
!>           Nombre de lignes de la matrice. Non modifié.
!
>

N 
!>          N est INTEGER
!>           Nombre de colonnes de la matrice. Non modifié.
!
>

I 
!>          I est INTEGER
!>           Ligne de l'élément non pivoté à renvoyer. Non modifié.
!
>

J 
!>          J est INTEGER
!>           Colonne de l'élément non pivoté à renvoyer. Non modifié.
!
>

ISU

B 
!>          ISUB est INTEGER
!>           Ligne de l'élément pivoté à renvoyer. Modifié à la sortie.
!
>

JSU

B 
!>          JSUB est INTEGER
!>           Colonne de l'élément pivoté à renvoyer. Modifié à la sortie.
!
>

K

L 
!>          KL est INTEGER
!>           Bande inférieure. Non modifié.
!
>

K

U 
!>          KU est INTEGER
!>           Bande supérieure. Non modifié.
!
>

IDIS

T 
!>          IDIST est INTEGER
!>           À l'entrée, IDIST spécifie le type de distribution à
!>           utiliser pour générer une matrice aléatoire.
!>           1 => UNIFORM( 0, 1 )
!>           2 => UNIFORM( -1, 1 )
!>           3 => NORMAL( 0, 1 )
!>           Non modifié.
!
>

ISEE

D 
!>          ISEED est un tableau INTEGER de dimension ( 4 )
!>           Graine pour le générateur de nombres aléatoires.
!>           Modifié à la sortie.
!
>

D 
!>          D est un tableau DOUBLE PRECISION de dimension ( MIN( I , J ) )
!>           Éléments diagonaux de la matrice. Non modifié.
!
>

IGRAD

E 
!>          IGRADE est INTEGER
!>           Spécifie l'échelonnement de la matrice comme suit :
!>           0  => pas d'échelonnement
!>           1  => matrice prémultipliée par diag( DL )
!>           2  => matrice postmultipliée par diag( DR )
!>           3  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par diag( DR )
!>           4  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par inv( diag( DL ) )
!>           5  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par diag( DL )
!>           Non modifié.
!
>

D

L 
!>          DL est un tableau DOUBLE PRECISION ( I ou J, selon le cas )
!>           Facteurs d'échelle gauche pour l'échelonnement de la matrice. Non modifié.
!
>

D

R 
!>          DR est un tableau DOUBLE PRECISION ( I ou J, selon le cas )
!>           Facteurs d'échelle droit pour l'échelonnement de la matrice. Non modifié.
!
>

IPVTN

G 
!>          IPVTNG est INTEGER
!>           À l'entrée, spécifie les permutations de pivotement comme suit :
!>           0 => aucune.
!>           1 => pivotement sur les lignes.
!>           2 => pivotement sur les colonnes.
!>           3 => pivotement complet, c'est-à-dire sur les deux côtés.
!>           Non modifié.
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER ( I ou J, selon le cas )
!>           Ce tableau spécifie la permutation utilisée. La
!>           ligne (ou colonne) initialement en position K est en
!>           position IWORK( K ) après le pivotement.
!>           Cela diffère de IWORK pour DLATM2. Non modifié.
!
>

SPARS

E 
!>          SPARSE est un DOUBLE PRECISION entre 0. et 1.
!>           À l'entrée, spécifie la sparsité de la matrice
!>           si une matrice creuse doit être générée.
!>           SPARSE doit être compris entre 0 et 1.
!>           Un nombre aléatoire x uniforme ( 0, 1 ) est généré et
!>           comparé à SPARSE ; si x est plus grand, l'élément de la matrice
!>           est inchangé et si x est plus petit, l'élément est défini
!>           à zéro. Ainsi, en moyenne, une fraction SPARSE des
!>           éléments sera définie à zéro.
!>           Non modifié.
!
>
