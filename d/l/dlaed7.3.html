subroutine dlaed7 (integer icompq, integer n, integer qsiz, integer tlvls, integer curlvl, integer curpbm, double precision, dimension( * ) d, double precision, dimension( ldq, * ) q, integer ldq, integer, dimension( * ) indxq, double precision rho, integer cutpnt, double precision, dimension( * ) qstore, integer, dimension( * ) qptr, integer, dimension( * ) prmptr, integer, dimension( * ) perm, integer, dimension( * ) givptr, integer, dimension( 2, * ) givcol, double precision, dimension( 2, * ) givnum, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DLAED7 utilisé par DSTEDC. Calcule le système propre mis à jour d'une matrice diagonale après modification par une matrice symétrique de rang un. Utilisé lorsque la matrice originale est dense.

But :

!>
!> DLAED7 calcule le système propre mis à jour d'une matrice
!> diagonale après modification par une matrice symétrique de rang un. Cette
!> routine n'est utilisée que pour le problème aux valeurs propres qui nécessite
!> toutes les valeurs propres et, éventuellement, les vecteurs propres d'une
!> matrice symétrique dense qui a été réduite à une forme tridiagonale. DLAED1
!> gère le cas où l'on souhaite toutes les valeurs propres et les vecteurs
!> propres d'une matrice tridiagonale symétrique.
!>
!>   T = Q(in) ( D(in) + RHO * Z*Z**T ) Q**T(in) = Q(out) * D(out) * Q**T(out)
!>
!>    où Z = Q**Tu, u est un vecteur de longueur N avec des uns aux éléments
!>    CUTPNT et CUTPNT + 1 et des zéros ailleurs.
!>
!>    Les vecteurs propres de la matrice originale sont stockés dans Q, et les
!>    valeurs propres sont dans D. L'algorithme se compose de trois étapes :
!>
!>       La première étape consiste à déflater la taille du problème
!>       lorsqu'il y a des valeurs propres multiples ou s'il y a un zéro dans le
!>       vecteur Z. Pour chaque occurrence de ce type, la dimension du problème
!>       de l'équation séculière est réduite d'une unité. Cette étape est
!>       effectuée par la routine DLAED8.
!>
!>       La deuxième étape consiste à calculer les valeurs propres
!>       mises à jour. Cela se fait en trouvant les racines de l'équation
!>       séculière via la routine DLAED4 (appelée par DLAED9).
!>       Cette routine calcule également les vecteurs propres du problème
!>       courant.
!>
!>       La dernière étape consiste à calculer les vecteurs propres mis à
!>       jour directement en utilisant les valeurs propres mises à jour. Les
!>       vecteurs propres du problème courant sont multipliés avec les vecteurs
!>       propres du problème global.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est INTEGER
!>          = 0 :  Calculer uniquement les valeurs propres.
!>          = 1 :  Calculer également les vecteurs propres de la matrice
!>                symétrique dense originale. À l'entrée, Q contient la matrice
!>                orthogonale utilisée pour réduire la matrice originale à une
!>                forme tridiagonale.
!>

N

!>          N est INTEGER
!>         La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

QSIZ

!>          QSIZ est INTEGER
!>         La dimension de la matrice orthogonale utilisée pour réduire
!>         la matrice complète à une forme tridiagonale. QSIZ >= N si ICOMPQ = 1.
!>

TLVLS

!>          TLVLS est INTEGER
!>         Le nombre total de niveaux de fusion dans l'arbre global de
!>         division et conquête.
!>

CURLVL

!>          CURLVL est INTEGER
!>         Le niveau courant dans la routine de fusion globale,
!>         0 <= CURLVL <= TLVLS.
!>

CURPBM

!>          CURPBM est INTEGER
!>         Le problème courant au niveau courant dans la routine de
!>         fusion globale (en comptant de gauche à droite et de haut en bas).
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>         À l'entrée, les valeurs propres de la matrice perturbée de rang 1.
!>         À la sortie, les valeurs propres de la matrice réparée.
!>

Q

!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ, N)
!>         À l'entrée, les vecteurs propres de la matrice perturbée de rang 1.
!>         À la sortie, les vecteurs propres de la matrice tridiagonale réparée.
!>

LDQ

!>          LDQ est INTEGER
!>         La dimension principale du tableau Q. LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ est un tableau INTEGER, dimension (N)
!>         La permutation qui réintégrera le sous-problème juste
!>         résolu dans l'ordre trié, c'est-à-dire que D( INDXQ( I = 1, N ) )
!>         sera en ordre croissant.
!>

RHO

!>          RHO est DOUBLE PRECISION
!>         L'élément sous-diagonal utilisé pour créer la modification
!>         de rang 1.
!>

CUTPNT

!>          CUTPNT est INTEGER
!>         Contient l'emplacement de la dernière valeur propre dans la
!>         sous-matrice principale. min(1,N) <= CUTPNT <= N.
!>

QSTORE

!>          QSTORE est un tableau DOUBLE PRECISION, dimension (N**2+1)
!>         Stocke les vecteurs propres des sous-matrices rencontrées pendant la
!>         division et la conquête, empaquetés ensemble. QPTR pointe vers le
!>         début des sous-matrices.
!>

QPTR

!>          QPTR est un tableau INTEGER, dimension (N+2)
!>         Liste d'indices pointant vers le début des sous-matrices stockées
!>         dans QSTORE. Les sous-matrices sont numérotées en partant du coin
!>         inférieur gauche de l'arbre de division et conquête, de gauche à
!>         droite et de bas en haut.
!>

PRMPTR

!>          PRMPTR est un tableau INTEGER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où la permutation
!>         d'un niveau est stockée dans PERM. PRMPTR(i+1) - PRMPTR(i)
!>         indique la taille de la permutation et également la taille du
!>         problème complet, non déflaté.
!>

PERM

!>          PERM est un tableau INTEGER, dimension (N lg N)
!>         Contient les permutations (provenant de la déflation et du tri) à
!>         appliquer à chaque bloc propre.
!>

GIVPTR

!>          GIVPTR est un tableau INTEGER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où les rotations de
!>         Givens d'un niveau sont stockées dans GIVCOL. GIVPTR(i+1) - GIVPTR(i)
!>         indique le nombre de rotations de Givens.
!>

GIVCOL

!>          GIVCOL est un tableau INTEGER, dimension (2, N lg N)
!>         Chaque paire de nombres indique une paire de colonnes à utiliser
!>         dans une rotation de Givens.
!>

GIVNUM

!>          GIVNUM est un tableau DOUBLE PRECISION, dimension (2, N lg N)
!>         Chaque nombre indique la valeur S à utiliser dans la
!>         rotation de Givens correspondante.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (3*N+2*QSIZ*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (4*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur propre n'a pas convergé
!>
