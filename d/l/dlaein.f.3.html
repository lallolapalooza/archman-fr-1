sous-programme dlaein (logique rightv, logique noinit, entier n, double précision, dimension( ldh, * ) h, entier ldh, double précision wr, double précision wi, double précision, dimension( * ) vr, double précision, dimension( * ) vi, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( * ) work, double précision eps3, double précision smlnum, double précision bignum, entier info)

DLAEIN calcule un vecteur propre droit ou gauche spécifié d'une matrice de Hessenberg supérieure par itération inverse.

Objectif :

!>
!> DLAEIN utilise l'itération inverse pour trouver un vecteur propre droit ou gauche
!> correspondant à la valeur propre (WR,WI) d'une matrice de Hessenberg réelle H.
!>

Paramètres

RIGHTV 
!>          RIGHTV est LOGIQUE
!>          = .VRAI. : calculer le vecteur propre droit ;
!>          = .FAUX. : calculer le vecteur propre gauche.
!>

NOINIT

!>          NOINIT est LOGIQUE
!>          = .VRAI. : aucun vecteur initial fourni dans (VR,VI).
!>          = .FAUX. : vecteur initial fourni dans (VR,VI).
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice H. N >= 0.
!>

H

!>          H est un tableau DOUBLE PRECISION, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>

LDH

!>          LDH est ENTIER
!>          La dimension principale du tableau H. LDH >= max(1,N).
!>

WR

!>          WR est DOUBLE PRECISION
!>

WI

!>          WI est DOUBLE PRECISION
!>          Les parties réelle et imaginaire de la valeur propre de H dont
!>          le vecteur propre droit ou gauche correspondant doit être calculé.
!>

VR

!>          VR est un tableau DOUBLE PRECISION, dimension (N)
!>

VI

!>          VI est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, si NOINIT = .FAUX. et WI = 0.0, VR doit contenir
!>          un vecteur de départ réel pour l'itération inverse en utilisant la
!>          valeur propre réelle WR ; si NOINIT = .FAUX. et WI.ne.0.0, VR et VI
!>          doivent contenir les parties réelle et imaginaire d'un vecteur de
!>          départ complexe pour l'itération inverse en utilisant la valeur
!>          propre complexe (WR,WI) ; sinon VR et VI n'ont pas besoin d'être
!>          définis.
!>          À la sortie, si WI = 0.0 (valeur propre réelle), VR contient le
!>          vecteur propre réel calculé ; si WI.ne.0.0 (valeur propre complexe),
!>          VR et VI contiennent les parties réelle et imaginaire du vecteur
!>          propre complexe calculé. Le vecteur propre est normalisé de sorte que
!>          la composante de plus grande magnitude ait une magnitude de 1 ;
!>          ici, la magnitude d'un nombre complexe (x,y) est considérée comme
!>          |x| + |y|.
!>          VI n'est pas référencé si WI = 0.0.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= N+1.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (N)
!>

EPS3

!>          EPS3 est DOUBLE PRECISION
!>          Une petite valeur dépendant de la machine qui est utilisée pour
!>          perturber les valeurs propres proches et pour remplacer les pivots
!>          nuls.
!>

SMLNUM

!>          SMLNUM est DOUBLE PRECISION
!>          Une valeur dépendant de la machine proche du seuil de sous-dépassement.
!>

BIGNUM

!>          BIGNUM est DOUBLE PRECISION
!>          Une valeur dépendant de la machine proche du seuil de dépassement.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          = 1 : l'itération inverse n'a pas convergé ; VR est défini sur le
!>                dernier itéré, et il en va de même pour VI si WI.ne.0.0.
!>
