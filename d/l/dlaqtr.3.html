DLAQTR résout un système d'équations quasi-triangulaire réel, ou un système quasi-triangulaire complexe de forme spéciale, en arithmétique réelle.

Documentation de la fonction/sous-programme

sous-programme dlaqtr (logical ltran, logical lreal, integer n, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( * ) b, double precision w, double precision scale, double precision, dimension( * ) x, double precision, dimension( * ) work, integer info)

DLAQTR résout un système d'équations quasi-triangulaire réel, ou un système quasi-triangulaire complexe de forme spéciale, en arithmétique réelle.

Objectif :

!>
!> DLAQTR résout le système quasi-triangulaire réel
!>
!>              op(T)*p = scale*c,               si LREAL = .TRUE.
!>
!> ou les systèmes quasi-triangulaires complexes
!>
!>            op(T + iB)*(p+iq) = scale*(c+id),  si LREAL = .FALSE.
!>
!> en arithmétique réelle, où T est quasi-triangulaire supérieure.
!> Si LREAL = .FALSE., alors le premier bloc diagonal de T doit être
!> 1 par 1, B est la matrice de structure spéciale
!>
!>                B = [ b(1) b(2) ... b(n) ]
!>                    [       w            ]
!>                    [           w        ]
!>                    [              .     ]
!>                    [                 w  ]
!>
!> op(A) = A ou A**T, A**T dénote la transposée de
!> la matrice A.
!>
!> En entrée, X = [ c ].  En sortie, X = [ p ].
!>               [ d ]                  [ q ]
!>
!> Ce sous-programme est conçu pour l'estimation du nombre de conditionnement
!> dans la routine DTRSNA.
!>

Paramètres

LTRAN 
!>          LTRAN est LOGICAL
!>          En entrée, LTRAN spécifie l'option de transposée conjuguée :
!>             = .FALSE.,    op(T+i*B) = T+i*B,
!>             = .TRUE.,     op(T+i*B) = (T+i*B)**T.
!>

LREAL

!>          LREAL est LOGICAL
!>          En entrée, LREAL spécifie la structure de la matrice d'entrée :
!>             = .FALSE.,    l'entrée est complexe
!>             = .TRUE.,     l'entrée est réelle
!>

N

!>          N est INTEGER
!>          En entrée, N spécifie l'ordre de T+i*B. N >= 0.
!>

T

!>          T est un tableau DOUBLE PRECISION, dimension (LDT,N)
!>          En entrée, T contient une matrice en forme canonique de Schur.
!>          Si LREAL = .FALSE., alors le premier bloc diagonal de T est
!>          1 par 1.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale de la matrice T. LDT >= max(1,N).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (N)
!>          En entrée, B contient les éléments pour former la matrice
!>          B comme décrit ci-dessus.
!>          Si LREAL = .TRUE., B n'est pas référencé.
!>

W

!>          W est DOUBLE PRECISION
!>          En entrée, W est l'élément diagonal de la matrice B.
!>          Si LREAL = .TRUE., W n'est pas référencé.
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          En sortie, SCALE est le facteur d'échelle.
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (2*N)
!>          En entrée, X contient le membre de droite du système.
!>          En sortie, X est écrasé par la solution.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          En sortie, INFO est défini à
!>             0: sortie réussie.
!>               1: un bloc diagonal 1 par 1 a été perturbé par
!>                  un petit nombre SMIN pour maintenir la non-singularité.
!>               2: un bloc diagonal 2 par 2 a été perturbé par
!>                  un petit nombre dans DLALN2 pour maintenir la non-singularité.
!>          NOTE : Dans un souci de rapidité, ce sous-programme ne
!>                vérifie pas les entrées pour les erreurs.
!>
