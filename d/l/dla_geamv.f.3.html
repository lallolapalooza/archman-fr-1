subroutine dla_geamv (trans, m, n, alpha, a, lda, x, incx, beta, y, incy)
DLA_GEAMV calcule le produit matrice-vecteur à l'aide d'une matrice générale pour calculer les bornes d'erreur.

Documentation de la fonction/sous-routine

subroutine dla_geamv (integer trans, integer m, integer n, double precision alpha, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) x, integer incx, double precision beta, double precision, dimension( * ) y, integer incy)

DLA_GEAMV calcule le produit matrice-vecteur à l'aide d'une matrice générale pour calculer les bornes d'erreur.

Objectif:

!>
!> DLA_GEAMV  effectue l'une des opérations matrice-vecteur suivantes :
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>    ou   y := alpha*abs(A)**T*abs(x) + beta*abs(y),
!>
!> où alpha et beta sont des scalaires, x et y sont des vecteurs et A est une
!> matrice de taille m par n.
!>
!> Cette fonction est principalement utilisée pour calculer les bornes d'erreur.
!> Pour se protéger contre le sous-dépassement lors de l'évaluation, les composantes du
!> vecteur résultant sont perturbées à partir de zéro par (N+1)
!> fois le seuil de sous-dépassement. Pour éviter des erreurs inutilement importantes
!> pour les structures de blocs intégrées dans des matrices générales,
!> les composantes zéro ne sont pas perturbées. Une composante zéro
!> est considérée si toutes les multiplications impliquées
!> dans le calcul de cette composante ont au moins un multiplicande zéro.
!>

Paramètres

TRANS 
!>          TRANS est de type INTEGER
!>           À l'entrée, TRANS spécifie l'opération à effectuer comme suit :
!>
!>             BLAS_NO_TRANS      y := alpha*abs(A)*abs(x) + beta*abs(y)
!>             BLAS_TRANS         y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>             BLAS_CONJ_TRANS    y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>
!>           Non modifié à la sortie.
!>

M

!>          M est de type INTEGER
!>           À l'entrée, M spécifie le nombre de lignes de la matrice A.
!>           M doit être supérieur ou égal à zéro.
!>           Non modifié à la sortie.
!>

N

!>          N est de type INTEGER
!>           À l'entrée, N spécifie le nombre de colonnes de la matrice A.
!>           N doit être supérieur ou égal à zéro.
!>           Non modifié à la sortie.
!>

ALPHA

!>          ALPHA est de type DOUBLE PRECISION
!>           À l'entrée, ALPHA spécifie le scalaire alpha.
!>           Non modifié à la sortie.
!>

A

!>          A est un tableau de type DOUBLE PRECISION, de dimensions ( LDA, n )
!>           Avant l'appel, la partie principale de taille m par n du tableau A doit
!>           contenir la matrice des coefficients.
!>           Non modifié à la sortie.
!>

LDA

!>          LDA est de type INTEGER
!>           À l'entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant. LDA doit être supérieur ou égal à
!>           max( 1, m ).
!>           Non modifié à la sortie.
!>

X

!>          X est un tableau de type DOUBLE PRECISION, de dimensions
!>           ( 1 + ( n - 1 )*abs( INCX ) ) lorsque TRANS = 'N' ou 'n'
!>           et au moins
!>           ( 1 + ( m - 1 )*abs( INCX ) ) sinon.
!>           Avant l'appel, le tableau X incrémenté doit contenir
!>           le vecteur x.
!>           Non modifié à la sortie.
!>

INCX

!>          INCX est de type INTEGER
!>           À l'entrée, INCX spécifie l'incrément pour les éléments de
!>           X. INCX ne doit pas être zéro.
!>           Non modifié à la sortie.
!>

BETA

!>          BETA est de type DOUBLE PRECISION
!>           À l'entrée, BETA spécifie le scalaire beta. Lorsque BETA est
!>           fourni comme zéro, Y n'a pas besoin d'être défini à l'entrée.
!>           Non modifié à la sortie.
!>

Y

!>          Y est un tableau de type DOUBLE PRECISION,
!>           de dimensions au moins
!>           ( 1 + ( m - 1 )*abs( INCY ) ) lorsque TRANS = 'N' ou 'n'
!>           et au moins
!>           ( 1 + ( n - 1 )*abs( INCY ) ) sinon.
!>           Avant l'appel avec BETA non nul, le tableau Y incrémenté
!>           doit contenir le vecteur y. À la sortie, Y est écrasé par le
!>           vecteur y mis à jour.
!>           Si m ou n est zéro, alors Y n'est pas référencé et la fonction
!>           effectue un retour rapide.
!>

INCY

!>          INCY est de type INTEGER
!>           À l'entrée, INCY spécifie l'incrément pour les éléments de
!>           Y. INCY ne doit pas être zéro.
!>           Non modifié à la sortie.
!>
!>  Routine de niveau 2 de Blas.
!>
