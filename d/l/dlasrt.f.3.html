sous-programme dlasrt (caractère id, entier n, double précision, dimension( * ) d, entier info)

DLASRT trie des nombres par ordre croissant ou décroissant.

Objectif :

!>
!> Trie les nombres dans D par ordre croissant (si ID = 'I') ou
!> par ordre décroissant (si ID = 'D').
!>
!> Utilise le tri rapide, revenant au tri par insertion pour les tableaux de
!> taille <= 20. La dimension de STACK limite N à environ 2**32.
!>

Paramètres

ID 
!>          ID est de type CHARACTER*1
!>          = 'I': trie D par ordre croissant;
!>          = 'D': trie D par ordre décroissant.
!>

N

!>          N est de type INTEGER
!>          La longueur du tableau D.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          À l'entrée, le tableau à trier.
!>          À la sortie, D a été trié par ordre croissant
!>          (D(1) <= ... <= D(N) ) ou par ordre décroissant
!>          (D(1) >= ... >= D(N) ), selon ID.
!>

INFO

!>          INFO est de type INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
