subroutine dlasd6 (integer icompq, integer nl, integer nr, integer sqre, double precision, dimension( * ) d, double precision, dimension( * ) vf, double precision, dimension( * ) vl, double precision alpha, double precision beta, integer, dimension( * ) idxq, integer, dimension( * ) perm, integer givptr, integer, dimension( ldgcol, * ) givcol, integer ldgcol, double precision, dimension( ldgnum, * ) givnum, integer ldgnum, double precision, dimension( ldgnum, * ) poles, double precision, dimension( * ) difl, double precision, dimension( * ) difr, double precision, dimension( * ) z, integer k, double precision c, double precision s, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DLASD6 calcule la SVD d'une matrice bidiagonale supérieure mise à jour obtenue en fusionnant deux matrices plus petites par l'ajout d'une ligne. Utilisé par sbdsdc.

But :

!>
!> DLASD6 calcule la SVD d'une matrice bidiagonale supérieure B
!> obtenue en fusionnant deux matrices plus petites par l'ajout d'une ligne. Cette
!> routine n'est utilisée que pour le problème qui nécessite toutes les valeurs
!> singulières et, en option, les matrices de vecteurs singuliers sous forme factorisée.
!> B est une matrice N par M avec N = NL + NR + 1 et M = N + SQRE.
!> Une sous-routine connexe, DLASD1, traite le cas où toutes les valeurs
!> singulières et les vecteurs singuliers de la matrice bidiagonale sont souhaités.
!>
!> DLASD6 calcule la SVD comme suit :
!>
!>               ( D1(in)    0    0       0 )
!>   B = U(in) * (   Z1**T   a   Z2**T    b ) * VT(in)
!>               (   0       0   D2(in)   0 )
!>
!>     = U(out) * ( D(out) 0) * VT(out)
!>
!> où Z**T = (Z1**T a Z2**T b) = u**T VT**T, et u est un vecteur de dimension M
!> avec ALPHA et BETA aux entrées NL+1 et NL+2 et des zéros
!> ailleurs ; et l'entrée b est vide si SQRE = 0.
!>
!> Les valeurs singulières de B peuvent être calculées à l'aide de D1, D2, les premières
!> composantes de tous les vecteurs singuliers droits du bloc inférieur, et
!> les dernières composantes de tous les vecteurs singuliers droits du bloc
!> supérieur. Ces composantes sont stockées et mises à jour dans VF et VL,
!> respectivement, dans DLASD6. Par conséquent, U et VT ne sont pas explicitement
!> référencés.
!>
!> Les valeurs singulières sont stockées dans D. L'algorithme se compose de deux
!> étapes :
!>
!>       La première étape consiste à déflater la taille du problème
!>       lorsqu'il y a des valeurs singulières multiples ou s'il y a un zéro
!>       dans le vecteur Z. Pour chaque occurrence de ce type, la dimension du
!>       problème de l'équation séculaire est réduite d'une unité. Cette étape est
!>       effectuée par la routine DLASD7.
!>
!>       La deuxième étape consiste à calculer les valeurs
!>       singulières mises à jour. Cela se fait en trouvant les racines de
!>       l'équation séculaire via la routine DLASD4 (appelée par DLASD8).
!>       Cette routine met également à jour VF et VL et calcule les distances
!>       entre les valeurs singulières mises à jour et les anciennes valeurs
!>       singulières.
!>
!> DLASD6 est appelée depuis DLASDA.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est INTEGER
!>         Indique si les vecteurs singuliers doivent être calculés
!>         sous forme factorisée :
!>         = 0 : Calculer uniquement les valeurs singulières.
!>         = 1 : Calculer également les vecteurs singuliers sous forme factorisée.
!>

NL

!>          NL est INTEGER
!>         La dimension des lignes du bloc supérieur.  NL >= 1.
!>

NR

!>          NR est INTEGER
!>         La dimension des lignes du bloc inférieur.  NR >= 1.
!>

SQRE

!>          SQRE est INTEGER
!>         = 0 : le bloc inférieur est une matrice carrée NR par NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR par (NR+1).
!>
!>         La matrice bidiagonale a une dimension de lignes N = NL + NR + 1,
!>         et une dimension de colonnes M = N + SQRE.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension ( NL+NR+1 ).
!>         À l'entrée, D(1:NL,1:NL) contient les valeurs singulières du
!>         bloc supérieur, et D(NL+2:N) contient les valeurs singulières
!>         du bloc inférieur. À la sortie, D(1:N) contient les valeurs
!>         singulières de la matrice modifiée.
!>

VF

!>          VF est un tableau DOUBLE PRECISION, dimension ( M )
!>         À l'entrée, VF(1:NL+1) contient les premières composantes de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VF(NL+2:M)
!>         contient les premières composantes de tous les vecteurs singuliers droits
!>         du bloc inférieur. À la sortie, VF contient les premières composantes
!>         de tous les vecteurs singuliers droits de la matrice bidiagonale.
!>

VL

!>          VL est un tableau DOUBLE PRECISION, dimension ( M )
!>         À l'entrée, VL(1:NL+1) contient les dernières composantes de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VL(NL+2:M)
!>         contient les dernières composantes de tous les vecteurs singuliers droits
!>         du bloc inférieur. À la sortie, VL contient les dernières composantes
!>         de tous les vecteurs singuliers droits de la matrice bidiagonale.
!>

ALPHA

!>          ALPHA est DOUBLE PRECISION
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!>

BETA

!>          BETA est DOUBLE PRECISION
!>         Contient l'élément hors-diagonal associé à la ligne
!>         ajoutée.
!>

IDXQ

!>          IDXQ est un tableau INTEGER, dimension ( N )
!>         Cela contient la permutation qui réintégrera le
!>         sous-problème juste résolu dans l'ordre trié, c'est-à-dire
!>         que D( IDXQ( I = 1, N ) ) sera dans l'ordre croissant.
!>

PERM

!>          PERM est un tableau INTEGER, dimension ( N )
!>         Les permutations (issues de la déflation et du tri) à appliquer
!>         à chaque bloc. Non référencé si ICOMPQ = 0.
!>

GIVPTR

!>          GIVPTR est INTEGER
!>         Le nombre de rotations de Givens qui ont eu lieu dans ce
!>         sous-problème. Non référencé si ICOMPQ = 0.
!>

GIVCOL

!>          GIVCOL est un tableau INTEGER, dimension ( LDGCOL, 2 )
!>         Chaque paire de nombres indique une paire de colonnes sur lesquelles
!>         porte une rotation de Givens. Non référencé si ICOMPQ = 0.
!>

LDGCOL

!>          LDGCOL est INTEGER
!>         dimension principale de GIVCOL, doit être au moins N.
!>

GIVNUM

!>          GIVNUM est un tableau DOUBLE PRECISION, dimension ( LDGNUM, 2 )
!>         Chaque nombre indique la valeur C ou S à utiliser dans la
!>         rotation de Givens correspondante. Non référencé si ICOMPQ = 0.
!>

LDGNUM

!>          LDGNUM est INTEGER
!>         La dimension principale de GIVNUM et POLES, doit être au moins N.
!>
<p class="Pp">POLES

!>          POLES est un tableau DOUBLE PRECISION, dimension ( LDGNUM, 2 )
!>         À la sortie, POLES(1,*) est un tableau contenant les nouvelles
!>         valeurs singulières obtenues en résolvant l'équation
!>         séculière, et POLES(2,*) est un tableau contenant les pôles
!>         dans l'équation séculière. Non référencé si ICOMPQ = 0.
!>

DIFL

!>          DIFL est un tableau DOUBLE PRECISION, dimension ( N )
!>         À la sortie, DIFL(I) est la distance entre la I-ème valeur
!>         singulière mise à jour (non défléchie) et la I-ème valeur
!>         singulière (non défléchie) précédente.
!>

DIFR

!>          DIFR est un tableau DOUBLE PRECISION,
!>                   dimension ( LDDIFR, 2 ) si ICOMPQ = 1 et
!>                   dimension ( K ) si ICOMPQ = 0.
!>          À la sortie, DIFR(I,1) = D(I) - DSIGMA(I+1), DIFR(K,1) n'est
!>          pas défini et ne sera pas référencé.
!>
!>          Si ICOMPQ = 1, DIFR(1:K,2) est un tableau contenant les
!>          facteurs de normalisation pour la matrice des vecteurs
!>          singuliers droits.
!>
!>         Voir DLASD8 pour plus de détails sur DIFL et DIFR.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension ( M )
!>         Les premiers éléments de ce tableau contiennent les
!>         composantes du vecteur ligne de mise à jour ajusté par la
!>         déflation.
!>

K

!>          K est INTEGER
!>         Contient la dimension de la matrice non défléchie.
!>         C'est l'ordre de l'équation séculière associée. 1 <= K <=N.
!>

C

!>          C est DOUBLE PRECISION
!>         C contient des données inutiles si SQRE =0 et la valeur C
!>         d'une rotation de Givens liée à l'espace nul droit si
!>         SQRE = 1.
!>

S

!>          S est DOUBLE PRECISION
!>         S contient des données inutiles si SQRE =0 et la valeur S
!>         d'une rotation de Givens liée à l'espace nul droit si
!>         SQRE = 1.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension ( 4 * M )
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension ( 3 * N )
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur
!>          illégale.
!>          > 0:  si INFO = 1, une valeur singulière n'a pas convergé.
!>
