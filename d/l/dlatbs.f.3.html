sous-routine dlatbs (character uplo, character trans, character diag, character normin, integer n, integer kd, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) x, double precision scale, double precision, dimension( * ) cnorm, integer info)

DLATBS résout un des systèmes triangulaires bande.

Objectif :

!>
!> DLATBS résout un des systèmes triangulaires
!>
!>    A *x = s*b  ou  A**T*x = s*b
!>
!> avec mise à l'échelle pour éviter le débordement, où A est une matrice
!> bande triangulaire supérieure ou inférieure. Ici A**T dénote la transposée
!> de A, x et b sont des vecteurs de n éléments, et s est un facteur de
!> mise à l'échelle, généralement inférieur ou égal à 1, choisi de sorte que
!> les composantes de x soient inférieures au seuil de débordement. Si le
!> problème non mis à l'échelle ne cause pas de débordement, la routine
!> BLAS de niveau 2 DTBSV est appelée. Si la matrice A est singulière
!> (A(j,j) = 0 pour un certain j), alors s est mis à 0 et une solution
!> non triviale à A*x = 0 est retournée.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  Résoudre A * x = s*b  (Pas de transposée)
!>          = 'T':  Résoudre A**T* x = s*b  (Transposée)
!>          = 'C':  Résoudre A**T* x = s*b  (Transposée conjuguée = Transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N':  Non unitaire triangulaire
!>          = 'U':  Unitaire triangulaire
!>

NORMIN

!>          NORMIN est CHARACTER*1
!>          Spécifie si CNORM a été défini ou non.
!>          = 'Y':  CNORM contient les normes des colonnes à l'entrée
!>          = 'N':  CNORM n'est pas défini à l'entrée. En sortie, les normes
!>                  seront calculées et stockées dans CNORM.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de sous-diagonales ou super-diagonales dans la
!>          matrice triangulaire A.  KD >= 0.
!>

AB

!>          AB est un tableau de type DOUBLE PRECISION, de dimension (LDAB,N)
!>          La matrice bande triangulaire supérieure ou inférieure A, stockée dans
!>          les KD+1 premières lignes du tableau. La j-ème colonne de A est stockée
!>          dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

X

!>          X est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          À l'entrée, le côté droit b du système triangulaire.
!>          En sortie, X est écrasé par le vecteur solution x.
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          Le facteur de mise à l'échelle s pour le système triangulaire
!>             A * x = s*b  ou  A**T* x = s*b.
!>          Si SCALE = 0, la matrice A est singulière ou mal mise à l'échelle, et
!>          le vecteur x est une solution exacte ou approximative de A*x = 0.
!>

CNORM

!>          CNORM est un tableau de type DOUBLE PRECISION, de dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM est un argument d'entrée et CNORM(j)
!>          contient la norme de la partie hors diagonale de la j-ème colonne
!>          de A. Si TRANS = 'N', CNORM(j) doit être supérieur ou égal à la
!>          norme infinie, et si TRANS = 'T' ou 'C', CNORM(j)
!>          doit être supérieur ou égal à la norme 1.
!>
!>          Si NORMIN = 'N', CNORM est un argument de sortie et CNORM(j)
!>          retourne la norme 1 de la partie hors diagonale de la j-ème colonne
!>          de A.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -k, le k-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  Une estimation grossière de x est calculée ; si elle est inférieure au
!>  débordement, DTBSV est appelée, sinon, un code spécifique est utilisé
!>  qui vérifie le débordement potentiel ou la division par zéro à chaque
!>  opération.
!>
!>  Un schéma colonne par colonne est utilisé pour résoudre A*x = b. L'algorithme
!>  de base si A est triangulaire inférieure est
!>
!>       x[1:n] := b[1:n]
!>       pour j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!>  Définissons des bornes sur les composantes de x après j itérations de la boucle :
!>     M(j) = borne sur x[1:j]
!>     G(j) = borne sur x[j+1:n]
!>  Initialement, soit M(0) = 0 et G(0) = max{x(i), i=1,...,n}.
!>
!>  Alors pour l'itération j+1, nous avons
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!>  où CNORM(j+1) est supérieur ou égal à la norme infinie de
!>  la colonne j+1 de A, sans compter la diagonale. Donc
!>
!>     G(j) <= G(0) produit ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!>  et
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) produit ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!>  Comme |x(j)| <= M(j), nous utilisons la routine BLAS de niveau 2 DTBSV si le
!>  inverse du plus grand M(j), j=1,..,n, est supérieur à
!>  max(sous-débordement, 1/débordement).
!>
!>  La borne sur x(j) est également utilisée pour déterminer quand une étape de
!>  la méthode colonne par colonne peut être effectuée sans crainte de débordement. Si
!>  la borne calculée est supérieure à une grande constante, x est mis à l'échelle pour
!>  prévenir le débordement, mais si la borne déborde, x est mis à 0, x(j) à
!>  1, et scale à 0, et une solution non triviale à A*x = 0 est trouvée.
!>
!>  De même, un schéma ligne par ligne est utilisé pour résoudre A**T*x = b. L'algorithme
!>  de base pour A triangulaire supérieure est
!>
!>       pour j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>       fin
!>
!>  Nous calculons simultanément deux bornes
!>       G(j) = borne sur ( b(i) - A[1:i-1,i]**T * x[1:i-1] ), 1<=i<=j
!>       M(j) = borne sur x(i), 1<=i<=j
!>
!>  Les valeurs initiales sont G(0) = 0, M(0) = max{b(i), i=1,..,n}, et nous
!>  ajoutons la contrainte G(j) >= G(j-1) et M(j) >= M(j-1) pour j >= 1.
!>  Alors la borne sur x(j) est
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * produit ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!>  et nous pouvons appeler DTBSV en toute sécurité si 1/M(n) et 1/G(n) sont tous deux supérieurs
!>  à max(sous-débordement, 1/débordement).
!>

Documentation des fonctions/sous-routines

DLATBS résout un des systèmes d'équations linéaires suivant :
(A) * X = B
tr(A) * X = B
ou
inv(A) * X = B
où A est une matrice triangulaire m x n en blocs unitaires supérieure ou inférieure, et X et B sont des matrices m x n.
Des informations plus détaillées sur les paramètres de cette sous-routine sont disponibles dans la documentation de LAPACK.
