subroutine dla_syamv (uplo, n, alpha, a, lda, x, incx, beta, y, incy)
DLA_SYAMV calcule un produit matrice-vector utilisant une matrice symétrique indéfinie pour calculer les bornes d'erreur.

Documentation de la fonction/sous-programme

sous-programme dla_syamv (integer uplo, integer n, double precision alpha, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) x, integer incx, double precision beta, double precision, dimension( * ) y, integer incy)

DLA_SYAMV calcule un produit matrice-vector utilisant une matrice symétrique indéfinie pour calculer les bornes d'erreur.

Objectif :

!>
!> DLA_SYAMV  effectue l'opération matrice-vecteur
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>
!> où alpha et beta sont des scalaires, x et y sont des vecteurs et A est une
!> matrice symétrique de taille n par n.
!>
!> Cette fonction est principalement utilisée pour calculer les bornes d'erreur.
!> Pour éviter le débordement lors de l'évaluation, les composantes du
!> vecteur résultant sont perturbées par (N+1) fois le seuil de débordement.
!> Pour éviter des erreurs inutilement grandes pour les structures bloquées
!> intégrées dans des matrices générales, les composantes nulles ne sont pas
!> perturbées. Une entrée nulle est considérée si toutes les multiplications
!> impliquées dans le calcul de cette entrée ont au moins un multiplicande nul.
!>

Paramètres

UPLO 
!>          UPLO est de type INTEGER
!>           À l'entrée, UPLO spécifie si la partie triangulaire supérieure ou
!>           inférieure du tableau A doit être référencée comme suit :
!>
!>              UPLO = BLAS_UPPER   Seule la partie triangulaire supérieure de A
!>                                  doit être référencée.
!>
!>              UPLO = BLAS_LOWER   Seule la partie triangulaire inférieure de A
!>                                  doit être référencée.
!>
!>           Inchangé à la sortie.
!>

N

!>          N est de type INTEGER
!>           À l'entrée, N spécifie le nombre de colonnes de la matrice A.
!>           N doit être supérieur ou égal à zéro.
!>           Inchangé à la sortie.
!>

ALPHA

!>          ALPHA est de type DOUBLE PRECISION.
!>           À l'entrée, ALPHA spécifie le scalaire alpha.
!>           Inchangé à la sortie.
!>

A

!>          A est un tableau de type DOUBLE PRECISION, de dimension ( LDA, n ).
!>           Avant l'entrée, la partie principale de dimension m par n du
!>           tableau A doit contenir la matrice des coefficients.
!>           Inchangé à la sortie.
!>

LDA

!>          LDA est de type INTEGER
!>           À l'entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant (sub)routine. LDA doit être supérieur ou égal
!>           à max( 1, n ).
!>           Inchangé à la sortie.
!>

X

!>          X est un tableau de type DOUBLE PRECISION, de dimension
!>           ( 1 + ( n - 1 )*abs( INCX ) )
!>           Avant l'entrée, le tableau incrémenté X doit contenir le
!>           vecteur x.
!>           Inchangé à la sortie.
!>

INCX

!>          INCX est de type INTEGER
!>           À l'entrée, INCX spécifie l'incrément pour les éléments de
!>           X. INCX ne doit pas être nul.
!>           Inchangé à la sortie.
!>

BETA

!>          BETA est de type DOUBLE PRECISION.
!>           À l'entrée, BETA spécifie le scalaire beta. Lorsque BETA est
!>           fourni comme zéro, Y n'a pas besoin d'être défini à l'entrée.
!>           Inchangé à la sortie.
!>

Y

!>          Y est un tableau de type DOUBLE PRECISION, de dimension
!>           ( 1 + ( n - 1 )*abs( INCY ) )
!>           Avant l'entrée avec BETA différent de zéro, le tableau incrémenté Y
!>           doit contenir le vecteur y. À la sortie, Y est écrasé par le
!>           vecteur y mis à jour.
!>

INCY

!>          INCY est de type INTEGER
!>           À l'entrée, INCY spécifie l'incrément pour les éléments de
!>           Y. INCY ne doit pas être nul.
!>           Inchangé à la sortie.
!>
