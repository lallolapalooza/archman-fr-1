DLEYNA-RENDERER-SERVICE.CONF(5) Manuel des formats de fichiers DLEYNA-RENDERER-SERVICE.CONF(5)

NOM

dleyna-renderer-service.conf - Fichier de configuration pour dleyna-renderer-service

SYNTAXE

  • /etc/dleyna-renderer-service.conf
  • $XDG_CONFIG_HOME/dleyna-renderer-service.conf

DESCRIPTION

Le programme dleyna-renderer-service fournit le nom com.intel.dleyna-renderer sur le bus de messages de session. Il s'agit d'un service pour découvrir et manipuler les Digital Media Renderers (DMR) DLNA.

Les utilisateurs ou les administrateurs n'ont jamais besoin de démarrer ce démon car il sera automatiquement lancé par dbus-daemon chaque fois qu'un processus enverra un message D-Bus au nom com.intel.dleyna-renderer sur le bus de session.

Ce fichier peut être utilisé pour configurer le comportement du programme dleyna-renderer-service.

FORMAT DU FICHIER

Le format du fichier de configuration est le format dit de fichier clé (sorte de style ini). Il se compose de sections (ou groupes) de paires clé-valeur. Les lignes commençant par un '#' et les lignes vides sont considérées comme des commentaires. Les sections sont commencées par une ligne d'en-tête contenant la section entre crochets '[' et ']', et se terminent implicitement par le début de la section suivante ou la fin du fichier. Chaque paire clé-valeur doit être contenue dans une section.

SECTION GENERALE

nom-connecteur=dbus
Le nom de la méthode de communication inter-processus à utiliser. La seule valeur prise en charge est dbus.
ne-jamais-quitter=faux|vrai
Indique si le processus doit rester actif en permanence ou se terminer lorsque le dernier client se déconnecte. La valeur par défaut est faux.
port
Port source pour les messages du protocole Simple Service Discovery Protocol (SSDP). La valeur par défaut est 0, ce qui signifie qu'un port disponible aléatoire sera utilisé.
port-hote-push
Port pour le serveur de fichiers push. La valeur par défaut est 0, ce qui signifie qu'un port disponible aléatoire sera utilisé.

SECTION JOURNAL

type-journal=0|1|2
La méthode de journalisation à utiliser. Trois technologies sont prises en charge : 0 pour syslog, 1 pour GLib et 2 pour fichier. La valeur par défaut est 0.
niveau-journal=0|1|2|...|8
Liste des niveaux de journalisation séparés par des virgules. Les niveaux sont 1 pour critique, 2 pour erreur, 3 pour avertissement, 4 pour message, 5 pour information et 6 pour débogage. 0 exclut tous les niveaux, 7 est une combinaison de critique, erreur et information, et 8 inclut tous les niveaux.

La valeur par défaut est 7.

SECTION FILTRAGE RESEAU

filtre-reseau-actif=vrai|faux
Indique si le filtrage réseau doit être activé ou non. La valeur par défaut est faux.
liste-filtre-reseau
Liste des noms d'interfaces, des identifiants de jeu de services (SSID) et des adresses de protocole Internet (IP), séparés par des virgules. Si le filtrage réseau est demandé mais que la liste est vide, le filtrage reste désactivé.

La liste est vide par défaut.
