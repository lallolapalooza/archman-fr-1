sous-programme dlarrc (jobt, n, vl, vu, d, e, pivmin, eigcnt, lcnt, rcnt, info)
DLARRC calcule le nombre de valeurs propres de la matrice tridiagonale symétrique.

DOCUMENTATION DE LA FONCTION/SOUS-PROGRAMME

sous-programme dlarrc (caractère jobt, entier n, double précision vl, double précision vu, double précision, dimension( * ) d, double précision, dimension( * ) e, double précision pivmin, entier eigcnt, entier lcnt, entier rcnt, entier info)

DLARRC calcule le nombre de valeurs propres de la matrice tridiagonale symétrique.

Objectif :

!>
!> Trouver le nombre de valeurs propres de la matrice tridiagonale symétrique T
!> qui se trouvent dans l'intervalle (VL,VU] si JOBT = 'T', et de L D L^T
!> si JOBT = 'L'.
!>

Paramètres

JOBT 
!>          JOBT est CHARACTER*1
!>          = 'T' : Calculer le compte de Sturm pour la matrice T.
!>          = 'L' : Calculer le compte de Sturm pour la matrice L D L^T.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice. N > 0.
!>

VL

!>          VL est DOUBLE PRECISION
!>          La borne inférieure pour les valeurs propres.
!>

VU

!>          VU est DOUBLE PRECISION
!>          La borne supérieure pour les valeurs propres.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          JOBT = 'T' : Les N éléments diagonaux de la matrice tridiagonale T.
!>          JOBT = 'L' : Les N éléments diagonaux de la matrice diagonale D.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (N)
!>          JOBT = 'T' : Les N-1 éléments hors diagonale de la matrice T.
!>          JOBT = 'L' : Les N-1 éléments hors diagonale de la matrice L.
!>

PIVMIN

!>          PIVMIN est DOUBLE PRECISION
!>          Le pivot minimum dans la séquence de Sturm pour T.
!>

EIGCNT

!>          EIGCNT est INTEGER
!>          Le nombre de valeurs propres de la matrice tridiagonale symétrique T
!>          qui sont dans l'intervalle (VL,VU]
!>

LCNT

!>          LCNT est INTEGER
!>

RCNT

!>          RCNT est INTEGER
!>          Les comptes négatifs gauche et droit de l'intervalle.
!>

INFO

!>          INFO est INTEGER
!>
