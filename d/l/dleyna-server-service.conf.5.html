NOM

dleyna-server-service.conf - Fichier de configuration pour dleyna-server-service

:Section du manuel:5

SYNOPIS

  • /etc/dleyna-server-service.conf
  • $XDG_CONFIG_HOME/dleyna-server-service.conf

DESCRIPTION

Le programme dleyna-server-service fournit le nom com.intel.dleyna-server sur le bus de messages de session. C'est un service pour découvrir et manipuler les Digital Media Renderers (DMR) de DLNA.

Les utilisateurs ou les administrateurs n'auront jamais besoin de démarrer ce démon car il sera automatiquement démarré par dbus-daemon chaque fois qu'un processus envoie un message D-Bus au nom com.intel.dleyna-server sur le bus de session.

Ce fichier peut être utilisé pour configurer le comportement du programme dleyna-server-service.

FORMAT DU FICHIER

Le format du fichier de configuration est le format dit de fichier clé (en quelque sorte style ini). Il se compose de sections (ou groupes) de lignes clé-valeur. Les lignes commençant par '#' et les lignes vides sont considérées comme des commentaires. Les sections sont commencées par une ligne d'en-tête contenant la section entourée de '[' et ']', et se terminent implicitement par le début de la section suivante ou la fin du fichier. Chaque paire clé-valeur doit être contenue dans une section.

SECTION GÉNÉRALE

nom-connecteur=dbus
Le nom de la méthode de communication inter-processus à utiliser. La seule valeur supportée est dbus.
ne-jamais-quitter=faux|vrai
Indique si le processus doit rester actif indéfiniment ou se terminer lorsque le dernier client se déconnecte. La valeur par défaut est faux.
port
Port source pour les messages du protocole Simple Service Discovery Protocol (SSDP). La valeur par défaut est 0, ce qui signifie qu'un port aléatoire disponible sera utilisé.

SECTION LOG

type-log=0|1|2
La méthode de journalisation à utiliser. Trois technologies sont supportées : 0 pour syslog, 1 pour GLib, et 2 pour un fichier. La valeur par défaut est 0.
niveau-log=0|1|2|...|8
Liste séparée par des virgules des niveaux de journalisation. Les niveaux sont 1 pour critique, 2 pour erreur, 3 pour avertissement, 4 pour message, 5 pour information et 6 pour débogage. 0 exclut tous les niveaux, 7 est une combinaison de critique, erreur et information, et 8 inclut tous les niveaux.

La valeur par défaut est 7.

SECTION NETF

netf-activé=vrai|faux
Indique si le filtrage réseau doit être activé ou non. La valeur par défaut est faux.
liste-netf
Liste séparée par des virgules des noms d'interface, des identifiants de jeu de services (SSID), et des adresses de protocole Internet (IP). Si le filtrage réseau est demandé mais que la liste est vide, le filtrage reste désactivé.

La liste est vide par défaut.
