SYNOPSIS

Fonctions/Sous-programmes


sous-programme dlarfx (side, m, n, v, tau, c, ldc, work)
DLARFX applique un réflecteur élémentaire à une matrice rectangulaire générale, avec déroulement de boucle lorsque le réflecteur est d'ordre ≤ 10.

Documentation de la fonction/sous-programme

sous-programme dlarfx (caractère side, entier m, entier n, double précision, dimension( * ) v, double précision tau, double précision, dimension( ldc, * ) c, entier ldc, double précision, dimension( * ) work)

DLARFX applique un réflecteur élémentaire réel H à une matrice réelle m par n C, soit à gauche, soit à droite. H est représenté sous la forme H = I - tau * v * v**T où tau est un scalaire réel et v est un vecteur réel. Si tau = 0, alors H est considérée comme la matrice unité. Cette version utilise du code inline si H est d'ordre < 11.

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': forme  H * C
!>          = 'R': forme  C * H
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

V

!>          V est un tableau de DOUBLE PRECISION, de dimension (M) si SIDE = 'L'
!>                                     ou (N) si SIDE = 'R'
!>          Le vecteur v dans la représentation de H.
!>

TAU

!>          TAU est DOUBLE PRECISION
!>          La valeur tau dans la représentation de H.
!>

C

!>          C est un tableau de DOUBLE PRECISION, de dimension (LDC,N)
!>          À l'entrée, la matrice C de m par n.
!>          À la sortie, C est écrasé par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= (1,M).
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, de dimension
!>                      (N) si SIDE = 'L'
!>                      ou (M) si SIDE = 'R'
!>          WORK n'est pas référencé si H est d'ordre < 11.
!>
