sous-programme dlagv2 (double précision, dimension( lda, * ) a, entier lda, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( 2 ) alphar, double précision, dimension( 2 ) alphai, double précision, dimension( 2 ) beta, double précision csl, double précision snl, double précision csr, double précision snr)

DLAGV2 calcule la factorisation de Schur généralisée d'un crayon de matrice réelle 2x2 (A,B) où B est triangulaire supérieure.

Objectif :

!>
!> DLAGV2 calcule la factorisation de Schur généralisée d'un crayon de
!> matrice réelle 2x2 (A,B) où B est triangulaire supérieure. Cette
!> routine calcule les matrices orthogonales (de rotation) données par
!> CSL, SNL et CSR, SNR telles que
!>
!> 1) si le crayon (A,B) a deux valeurs propres réelles (incluant les
!>    types 0/0 ou 1/0), alors
!>
!>    [ a11 a12 ] := [  CSL  SNL ] [ a11 a12 ] [  CSR -SNR ]
!>    [  0  a22 ]    [ -SNL  CSL ] [ a21 a22 ] [  SNR  CSR ]
!>
!>    [ b11 b12 ] := [  CSL  SNL ] [ b11 b12 ] [  CSR -SNR ]
!>    [  0  b22 ]    [ -SNL  CSL ] [  0  b22 ] [  SNR  CSR ]
!>
!> 2) si le crayon (A,B) a une paire de valeurs propres complexes conjuguées,
!>    alors
!>
!>    [ a11 a12 ] := [  CSL  SNL ] [ a11 a12 ] [  CSR -SNR ]
!>    [ a21 a22 ]    [ -SNL  CSL ] [ a21 a22 ] [  SNR  CSR ]
!>
!>    [ b11  0  ] := [  CSL  SNL ] [ b11 b12 ] [  CSR -SNR ]
!>    [  0  b22 ]    [ -SNL  CSL ] [  0  b22 ] [  SNR  CSR ]
!>
!>    où b11 >= b22 > 0.
!>
!>

Paramètres

A 
!>          A est un tableau DOUBLE PRÉCISION, dimension (LDA, 2)
!>          En entrée, la matrice 2x2 A.
!>          En sortie, A est écrasée par la ``partie A'' de la forme
!>          de Schur généralisée.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= 2.
!>

B

!>          B est un tableau DOUBLE PRÉCISION, dimension (LDB, 2)
!>          En entrée, la matrice triangulaire supérieure 2x2 B.
!>          En sortie, B est écrasée par la ``partie B'' de la forme
!>          de Schur généralisée.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= 2.
!>

ALPHAR

!>          ALPHAR est un tableau DOUBLE PRÉCISION, dimension (2)
!>

ALPHAI

!>          ALPHAI est un tableau DOUBLE PRÉCISION, dimension (2)
!>

BETA

!>          BETA est un tableau DOUBLE PRÉCISION, dimension (2)
!>          (ALPHAR(k)+i*ALPHAI(k))/BETA(k) sont les valeurs propres du
!>          crayon (A,B), k=1,2, i = sqrt(-1). Notez que BETA(k) peut
!>          être zéro.
!>

CSL

!>          CSL est DOUBLE PRÉCISION
!>          Le cosinus de la matrice de rotation gauche.
!>

SNL

!>          SNL est DOUBLE PRÉCISION
!>          Le sinus de la matrice de rotation gauche.
!>

CSR

!>          CSR est DOUBLE PRÉCISION
!>          Le cosinus de la matrice de rotation droite.
!>

SNR

!>          SNR est DOUBLE PRÉCISION
!>          Le sinus de la matrice de rotation droite.
!>
