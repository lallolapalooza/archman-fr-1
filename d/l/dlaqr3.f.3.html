sous-routine dlaqr3 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, double precision, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, double precision, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, double precision, dimension( * ) sr, double precision, dimension( * ) si, double precision, dimension( ldv, * ) v, integer ldv, integer nh, double precision, dimension( ldt, * ) t, integer ldt, integer nv, double precision, dimension( ldwv, * ) wv, integer ldwv, double precision, dimension( * ) work, integer lwork)

DLAQR3 effectue la transformation de similarité orthogonale d'une matrice de Hessenberg pour détecter et déflater les valeurs propres complètement convergentes d'une sous-matrice principale traînante (déflation précoce agressive).

Objectif :

!>
!>    Déflation précoce agressive :
!>
!>    DLAQR3 prend en entrée une matrice de Hessenberg
!>    H et effectue une transformation de similarité orthogonale
!>    visant à détecter et déflater les valeurs propres complètement convergentes
!>    d'une sous-matrice principale traînante. En sortie, H a été
!>    écrasée par une nouvelle matrice de Hessenberg qui est une perturbation de
!>    une transformation de similarité orthogonale de H. On espère que
!>    la version finale de H comportera de nombreuses entrées sous-diagonales nulles.
!>

Paramètres

WANTT 
!>          WANTT est LOGICAL
!>          Si .TRUE., alors la matrice de Hessenberg H est entièrement mise à jour
!>          afin que le facteur de Schur quasi-triangulaire puisse être
!>          calculé (en coopération avec la sous-routine appelante).
!>          Si .FALSE., alors seule une partie suffisante de H est mise à jour pour préserver
!>          les valeurs propres.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          Si .TRUE., alors la matrice orthogonale Z est mise à jour afin que
!>          le facteur de Schur orthogonal puisse être calculé
!>          (en coopération avec la sous-routine appelante).
!>          Si .FALSE., alors Z n'est pas référencée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice H et (si WANTZ est .TRUE.) de
!>          la matrice orthogonale Z.
!>

KTOP

!>          KTOP est INTEGER
!>          On suppose soit que KTOP = 1, soit que H(KTOP,KTOP-1)=0.
!>          KBOT et KTOP déterminent ensemble un bloc isolé
!>          le long de la diagonale de la matrice de Hessenberg.
!>

KBOT

!>          KBOT est INTEGER
!>          On suppose sans vérification que soit
!>          KBOT = N, soit H(KBOT+1,KBOT)=0. KBOT et KTOP déterminent
!>          ensemble un bloc isolé le long de la diagonale de la
!>          matrice de Hessenberg.
!>

NW

!>          NW est INTEGER
!>          Taille de la fenêtre de déflation. 1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H est un tableau DOUBLE PRECISION, dimension (LDH,N)
!>          En entrée, la section N x N initiale de H stocke la
!>          matrice de Hessenberg subissant une déflation précoce agressive.
!>          En sortie, H a été transformée par une transformation de similarité
!>          orthogonale, perturbée, et ramenée à la forme de Hessenberg qui (on l'espère)
!>          possède quelques entrées sous-diagonales nulles.
!>

LDH

!>          LDH est INTEGER
!>          La dimension principale de H, telle que déclarée dans la sous-routine appelante.
!>          N <= LDH
!>

ILOZ

!>          ILOZ est INTEGER
!>

IHIZ

!>          IHIZ est INTEGER
!>          Spécifient les lignes de Z auxquelles les transformations doivent être
!>          appliquées si WANTZ est .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension (LDZ,N)
!>          Si WANTZ est .TRUE., alors en sortie, la transformation de similarité
!>          orthogonale mentionnée ci-dessus a été accumulée dans Z(ILOZ:IHIZ,ILOZ:IHIZ) par la droite.
!>          Si WANTZ est .FALSE., alors Z n'est pas référencée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale de Z, telle que déclarée dans la sous-routine appelante.
!>          1 <= LDZ.
!>

NS

!>          NS est INTEGER
!>          Le nombre de valeurs propres non convergentes (c'est-à-dire approximatives)
!>          renvoyées dans SR et SI qui peuvent être utilisées comme décalages par
!>          la sous-routine appelante.
!>

ND

!>          ND est INTEGER
!>          Le nombre de valeurs propres convergentes découvertes par cette
!>          sous-routine.
!>

SR

!>          SR est un tableau DOUBLE PRECISION, dimension (KBOT)
!>

SI

!>          SI est un tableau DOUBLE PRECISION, dimension (KBOT)
!>          En sortie, les parties réelles et imaginaires des valeurs propres approximatives
!>          qui peuvent être utilisées comme décalages sont stockées dans
!>          SR(KBOT-ND-NS+1) à SR(KBOT-ND) et
!>          SI(KBOT-ND-NS+1) à SI(KBOT-ND), respectivement.
!>          Les parties réelles et imaginaires des valeurs propres convergentes
!>          sont stockées dans SR(KBOT-ND+1) à SR(KBOT) et
!>          SI(KBOT-ND+1) à SI(KBOT), respectivement.
!>

V

!>          V est un tableau DOUBLE PRECISION, dimension (LDV,NW)
!>          Un tableau de travail NW x NW.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale de V, telle que déclarée dans la sous-routine appelante.
!>          NW <= LDV
!>

NH

!>          NH est INTEGER
!>          Le nombre de colonnes de T. NH >= NW.
!>

T

!>          T est un tableau DOUBLE PRECISION, dimension (LDT,NW)
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale de T, telle que déclarée dans la sous-routine appelante.
!>          NW <= LDT
!>

NV

!>          NV est INTEGER
!>          Le nombre de lignes du tableau de travail WV disponibles pour
!>          l'espace de travail. NV >= NW.
!>

WV

!>          WV est un tableau DOUBLE PRECISION, dimension (LDWV,NW)
!>

LDWV

!>          LDWV est INTEGER
!>          La dimension principale de W, telle que déclarée dans la sous-routine appelante.
!>          NW <= LDV
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK)
!>          En sortie, WORK(1) est défini à une estimation de la valeur optimale
!>          de LWORK pour les valeurs données de N, NW, KTOP et KBOT.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau de travail WORK. LWORK = 2*NW
!>          suffit, mais une efficacité accrue peut résulter de valeurs
!>          plus grandes de LWORK.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; DLAQR3
!>          estime seulement l'optimal
