sous-programme dlaqps (integer m, integer n, integer offset, integer nb, integer kb, double precision, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, double precision, dimension( * ) tau, double precision, dimension( * ) vn1, double precision, dimension( * ) vn2, double precision, dimension( * ) auxv, double precision, dimension( ldf, * ) f, integer ldf)

DLAQPS calcule une étape de factorisation QR avec pivotement de colonnes d'une matrice réelle m par n A à l'aide de BLAS niveau 3.

Objectif :

!>
!> DLAQPS calcule une étape de factorisation QR avec pivotement de
!> colonnes d'une matrice réelle M par N A à l'aide de Blas-3. Il tente de factoriser
!> NB colonnes de A à partir de la ligne OFFSET+1, et met à jour toute
!> la matrice avec xGEMM de Blas-3.
!>
!> Dans certains cas, en raison d'annulations catastrophiques, il ne peut pas
!> factoriser NB colonnes. Par conséquent, le nombre réel de colonnes factorisées
!> est retourné dans KB.
!>
!> Le bloc A(1:OFFSET,1:N) est pivoté en conséquence, mais pas factorisé.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice A. N >= 0
!>

OFFSET

!>          OFFSET est un entier
!>          Le nombre de lignes de A qui ont été factorisées dans des
!>          étapes précédentes.
!>

NB

!>          NB est un entier
!>          Le nombre de colonnes à factoriser.
!>

KB

!>          KB est un entier
!>          Le nombre de colonnes effectivement factorisées.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice M par N A.
!>          À la sortie, le bloc A(OFFSET+1:M,1:KB) est le facteur
!>          triangulaire obtenu et le bloc A(1:OFFSET,1:N) a été
!>          pivoté en conséquence, mais pas factorisé.
!>          Le reste de la matrice, bloc A(OFFSET+1:M,KB+1:N) a été
!>          mis à jour.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

JPVT

!>          JPVT est un tableau entier, dimension (N)
!>          JPVT(I) = K <==> La colonne K de la matrice complète A a été
!>          permuttée à la position I dans AP.
!>

TAU

!>          TAU est un tableau DOUBLE PRECISION, dimension (KB)
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

VN1

!>          VN1 est un tableau DOUBLE PRECISION, dimension (N)
!>          Le vecteur avec les normes partielles de colonnes.
!>

VN2

!>          VN2 est un tableau DOUBLE PRECISION, dimension (N)
!>          Le vecteur avec les normes exactes des colonnes.
!>

AUXV

!>          AUXV est un tableau DOUBLE PRECISION, dimension (NB)
!>          Vecteur auxiliaire.
!>

F

!>          F est un tableau DOUBLE PRECISION, dimension (LDF,NB)
!>          Matrice F**T = L*Y**T*A.
!>

LDF

!>          LDF est un entier
!>          La dimension principale du tableau F. LDF >= max(1,N).
!>
