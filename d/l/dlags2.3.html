Documentation de la fonction/sous-routine

sous-routine dlags2 (logique upper, double precision a1, double precision a2, double precision a3, double precision b1, double precision b2, double precision b3, double precision csu, double precision snu, double precision csv, double precision snv, double precision csq, double precision snq)

DLAGS2 calcule les matrices orthogonales 2x2 U, V et Q, et les applique aux matrices A et B de telle sorte que les lignes des A et B transformées soient parallèles.

Objectif :

!>
!> DLAGS2 calcule les matrices orthogonales 2x2 U, V et Q, telles que si ( UPPER ) alors
!>
!>           U**T *A*Q = U**T *( A1 A2 )*Q = ( x  0  )
!>                             ( 0  A3 )     ( x  x  )
!> et
!>           V**T*B*Q = V**T *( B1 B2 )*Q = ( x  0  )
!>                            ( 0  B3 )     ( x  x  )
!>
!> ou si ( .NON.UPPER ) alors
!>
!>           U**T *A*Q = U**T *( A1 0  )*Q = ( x  x  )
!>                             ( A2 A3 )     ( 0  x  )
!> et
!>           V**T*B*Q = V**T*( B1 0  )*Q = ( x  x  )
!>                           ( B2 B3 )     ( 0  x  )
!>
!> Les lignes de A et B transformées sont parallèles, où
!>
!>   U = (  CSU  SNU ), V = (  CSV SNV ), Q = (  CSQ   SNQ )
!>       ( -SNU  CSU )      ( -SNV CSV )      ( -SNQ   CSQ )
!>
!> Z**T désigne la transposée de Z.
!>
!>

Paramètres

UPPER 
!>          UPPER est LOGIQUE
!>          = .VRAI. : les matrices d'entrée A et B sont triangulaires supérieures.
!>          = .FAUX. : les matrices d'entrée A et B sont triangulaires inférieures.
!>

A1

!>          A1 est DOUBLE PRECISION
!>

A2

!>          A2 est DOUBLE PRECISION
!>

A3

!>          A3 est DOUBLE PRECISION
!>          À l'entrée, A1, A2 et A3 sont des éléments de la matrice 2x2
!>          triangulaire supérieure (inférieure) d'entrée A.
!>

B1

!>          B1 est DOUBLE PRECISION
!>

B2

!>          B2 est DOUBLE PRECISION
!>

B3

!>          B3 est DOUBLE PRECISION
!>          À l'entrée, B1, B2 et B3 sont des éléments de la matrice 2x2
!>          triangulaire supérieure (inférieure) d'entrée B.
!>

CSU

!>          CSU est DOUBLE PRECISION
!>

SNU

!>          SNU est DOUBLE PRECISION
!>          La matrice orthogonale désirée U.
!>

CSV

!>          CSV est DOUBLE PRECISION
!>

SNV

!>          SNV est DOUBLE PRECISION
!>          La matrice orthogonale désirée V.
!>

CSQ

!>          CSQ est DOUBLE PRECISION
!>

SNQ

!>          SNQ est DOUBLE PRECISION
!>          La matrice orthogonale désirée Q.
!>
