sous-programme dlarscl2 (integer m, integer n, double precision, dimension( * ) d, double precision, dimension( ldx, * ) x, integer ldx)

DLARSCL2 effectue une mise à l'échelle diagonale réciproque d'une matrice.

Objectif :

!>
!> DLARSCL2 effectue une mise à l'échelle diagonale réciproque d'une matrice :
!>   x <-- inv(D) * x
!> où la matrice diagonale D est stockée sous forme de vecteur.
!>
!> Sera éventuellement remplacée par BLAS_dge_diag_scale dans la nouvelle
!> norme BLAS.
!>

Paramètres

M 
!>          M est un INTEGER
!>     Le nombre de lignes de D et X. M >= 0.
!>

N

!>          N est un INTEGER
!>     Le nombre de colonnes de X. N >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, de dimension (M)
!>     Matrice diagonale D, stockée sous forme de vecteur de longueur M.
!>

X

!>          X est un tableau DOUBLE PRECISION, de dimension (LDX,N)
!>     À l'entrée, la matrice X à mettre à l'échelle par D.
!>     À la sortie, la matrice mise à l'échelle.
!>

LDX

!>          LDX est un INTEGER
!>     La dimension principale de la matrice X. LDX >= M.
!>
