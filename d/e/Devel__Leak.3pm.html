NOM

Devel::Leak - Utilitaire pour rechercher les objets perl qui ne sont pas récupérés.

SYNTAXE

use Devel::Leak;
... code de configuration
my $count = Devel::Leak::NoteSV($handle);
... code susceptible de fuir
Devel::Leak::CheckSV($handle);

DESCRIPTION

Devel::Leak possède deux fonctions : "NoteSV" et "CheckSV".

"NoteSV" parcourt la table interne de Perl des SV alloués (valeurs scalaires) - (qui contiennent en fait aussi des tableaux et des hachages) - et enregistre leurs adresses dans une table. Elle retourne un compte de ces "choses" et stocke un pointeur vers la table (obtenue depuis le tas à l'aide de malloc()) dans son argument.

"CheckSV" reçoit en argument un argument qui contient un pointeur vers une table créée par "NoteSV". Elle repasse sur les internes de Perl et appelle sv_dump() pour toutes les "choses" qui n'existaient pas lorsque "NoteSV" a été appelée. Elle retourne un compte du nombre de "choses" allouées à ce moment-là.

MISE EN GARDE

Notez que vous avez besoin d'un Perl compilé avec -DDEBUGGING pour que sv_dump() affiche quelque chose, mais les comptes sont valides dans n'importe quel Perl.

Si de nouvelles "choses" ont été créées, "CheckSV" peut (également) signaler des "choses" supplémentaires qui sont allouées par le code de sv_dump().

HISTORIQUE

Ce petit module utilitaire faisait partie de Tk jusqu'à ce que le renommage des variables dans perl5.005 rende clair que Tk n'avait pas à connaître autant des internes de Perl.
