DELETE(7) Documentation PostgreSQL 18.1 DELETE(7)

NOM

DELETE - supprimer des lignes d'une table

SYNOPSIS

[ WITH [ RECURSIVE ] with_query [, ...] ]
DELETE FROM [ ONLY ] table_name [ * ] [ [ AS ] alias ]
    [ USING from_item [, ...] ]
    [ WHERE condition | WHERE CURRENT OF cursor_name ]
    [ RETURNING [ WITH ( { OLD | NEW } AS output_alias [, ...] ) ]
                { * | output_expression [ [ AS ] output_name ] } [, ...] ]

DESCRIPTION

DELETE supprime les lignes qui satisfont la clause WHERE de la table spécifiée. Si la clause WHERE est absente, l'effet est de supprimer toutes les lignes de la table. Le résultat est une table valide, mais vide.


Astuce

TRUNCATE fournit un mécanisme plus rapide pour supprimer toutes les lignes d'une table.

Il existe deux façons de supprimer des lignes d'une table en utilisant des informations contenues dans d'autres tables de la base de données : à l'aide de sous-sélects, ou en spécifiant des tables supplémentaires dans la clause USING. La technique la plus appropriée dépend des circonstances spécifiques.

La clause RETURNING facultative fait que DELETE calcule et renvoie des valeurs basées sur chaque ligne réellement supprimée. Toute expression utilisant les colonnes de la table et/ou les colonnes d'autres tables mentionnées dans USING peut être calculée. La syntaxe de la liste RETURNING est identique à celle de la liste de sortie de SELECT.

Vous devez avoir le privilège DELETE sur la table pour en supprimer des lignes, ainsi que le privilège SELECT pour toute table de la clause USING ou dont les valeurs sont lues dans la condition.

PARAMÈTRES

with_query

La clause WITH vous permet de spécifier une ou plusieurs sous-requêtes qui peuvent être référencées par leur nom dans la requête DELETE . Voir la section 7.8 et SELECT(7) pour plus de détails.

table_name

Le nom (éventuellement qualifié par un schéma) de la table à partir de laquelle supprimer des lignes. Si ONLY est spécifié avant le nom de la table, seules les lignes correspondantes sont supprimées de la table nommée. Si ONLY n'est pas spécifié, les lignes correspondantes sont également supprimées de toutes les tables héritant de la table nommée. Facultativement, * peut être spécifié après le nom de la table pour indiquer explicitement que les tables descendantes sont incluses.

alias

Un nom de substitution pour la table cible. Lorsqu'un alias est fourni, il masque complètement le nom réel de la table. Par exemple, étant donné DELETE FROM foo AS f, le reste de l'instruction DELETE doit se référer à cette table sous le nom f et non foo.

from_item

Une expression de table permettant à des colonnes d'autres tables d' apparaître dans la condition WHERE. Elle utilise la même syntaxe que la clause FROM d'une instruction SELECT ; par exemple, un alias pour le nom de la table peut être spécifié. Ne répétez pas la table cible en tant que from_item sauf si vous souhaitez mettre en place une auto-jointure (auquel cas elle doit apparaître avec un alias dans le from_item).

condition

Une expression qui renvoie une valeur de type booléen. Seules les lignes pour lesquelles cette expression renvoie true seront supprimées.

cursor_name

Le nom du curseur à utiliser dans une condition WHERE CURRENT OF. La ligne à supprimer est celle la plus récemment extraite de ce curseur. Le curseur doit être une requête non groupante sur la table cible de DELETE. Notez que WHERE CURRENT OF ne peut pas être spécifié en même temps qu'une condition booléenne. Voir DECLARE(7) pour plus d'informations sur l'utilisation des curseurs avec WHERE CURRENT OF.

output_alias

Un nom de substitution facultatif pour les lignes OLD ou NEW dans la liste RETURNING.

Par défaut, les anciennes valeurs de la table cible peuvent être renvoyées en écrivant OLD.column_name ou OLD.*, et les nouvelles valeurs peuvent être renvoyées en écrivant NEW.column_name ou NEW.*. Lorsqu'un alias est fourni, ces noms sont masqués et les anciennes ou nouvelles lignes doivent être référencées à l'aide de l'alias. Par exemple RETURNING WITH (OLD AS o, NEW AS n) o.*, n.*.

output_expression

Une expression à calculer et à renvoyer par la commande DELETE après la suppression de chaque ligne. L'expression peut utiliser n'importe quels noms de colonnes de la table nommée par table_name ou des tables listées dans USING. Écrivez * pour renvoyer toutes les colonnes.

Un nom de colonne ou * peut être qualifié par OLD ou NEW, ou par l' output_alias correspondant pour OLD ou NEW, afin de faire renvoyer les anciennes ou nouvelles valeurs. Un nom de colonne non qualifié, ou *, ou un nom de colonne ou * qualifié par le nom ou l'alias de la table cible renverra les anciennes valeurs.

Pour un DELETEsimple, toutes les nouvelles valeurs seront NULL. Cependant, si une règle ON DELETE provoque l'exécution d'un INSERT ou UPDATE à la place, les nouvelles valeurs peuvent être non NULL.

output_name

Un nom à utiliser pour une colonne renvoyée.

SORTIES

En cas de réussite, une commande DELETE renvoie une étiquette de commande de la forme

DELETE count

Le count est le nombre de lignes supprimées. Notez que le nombre peut être inférieur au nombre de lignes qui correspondaient à la condition lorsque les suppressions ont été empêchées par un déclencheur BEFORE DELETE. Si count est 0, aucune ligne n'a été supprimée par la requête (ce n'est pas considéré comme une erreur).

Si la commande DELETE contient une clause RETURNING, le résultat sera similaire à celui d'une instruction SELECT contenant les colonnes et valeurs définies dans la liste RETURNING, calculées sur les lignes supprimées par la commande.

REMARQUES

PostgreSQL vous permet de référencer des colonnes d'autres tables dans la condition WHERE en spécifiant les autres tables dans la clause USING. Par exemple, pour supprimer tous les films produits par un producteur donné, on peut faire :

DELETE FROM films USING producers
  WHERE producer_id = producers.id AND producers.name = 'foo';

Ce qui se passe essentiellement ici est une jointure entre films et producers, avec toutes les lignes de films jointes avec succès marquées pour suppression. Cette syntaxe n'est pas standard. Une façon plus standard de le faire est :

DELETE FROM films
  WHERE producer_id IN (SELECT id FROM producers WHERE name = 'foo');

Dans certains cas, le style de jointure est plus facile à écrire ou plus rapide à exécuter que le style sous-sélect.

EXEMPLES

Supprimer tous les films sauf les comédies musicales :

DELETE FROM films WHERE kind <> 'Musical';

Vider la table films :

DELETE FROM films;

Supprimer les tâches terminées, en renvoyant les détails complets des lignes supprimées :

DELETE FROM tasks WHERE status = 'DONE' RETURNING *;

Supprimer la ligne de tasks sur laquelle le curseur c_tasks est actuellement positionné :

DELETE FROM tasks WHERE CURRENT OF c_tasks;

Bien qu'il n'y ait pas de clause LIMIT pour DELETE, il est possible d'obtenir un effet similaire en utilisant la même méthode décrite dans la documentation de UPDATE:

WITH delete_batch AS (
  SELECT l.ctid FROM user_logs AS l
    WHERE l.status = 'archived'
    ORDER BY l.creation_date
    FOR UPDATE
    LIMIT 10000
)
DELETE FROM user_logs AS dl
  USING delete_batch AS del
  WHERE dl.ctid = del.ctid;

COMPATIBILITÉ

Cette commande est conforme à la norme SQL, à l'exception des clauses USING et RETURNING qui sont des extensions PostgreSQL, tout comme la capacité d'utiliser WITH avec DELETE.
