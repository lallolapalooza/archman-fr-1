INTÉGRÉES
cp12
52
Une table de traduction pour transcoder les caractères CP-1252 en UTF-8, avec quelques exceptions. Ce n'est plus un cas d'utilisation courant et a été déplacé vers une table
séparée.
iso8859
_1
Une table de traduction pour transcoder les caractères sur un seul octet avec le bit de poids fort définim ISO-8859-1 vers UTF-8.
safe
Une table de remplacement pour les caractères difficiles à manipuler sous Unix et les systèmes d'exploitation similaires à Unix.
unicode
Une table de traduction pour convertir les caractères de contrôle multi-octets encodés en UTF-8 en caractères sûrs.

EXEMPLES

# filtre les caractères de contrôle UTF-8 vers ASCII (en utilisant des tables chaînées), nettoyage
sequence utf8 {
  utf_8 {
    filename "/usr/local/share/detox/custom.tbl";
  };
  utf_8 {
    builtin "unicode";
  };
  safe {
    builtin "safe";
  };
  wipeup {
    remove_trailing;
  };
  max_length {
    length 128;
  };
};
# décode CGI, transcode CP-1252 vers UTF-8, nettoyage
sequence "cgi-cp1252" {
  uncgi;
  iso8859_1 {
    builtin "cp1252";
  };
  safe {
    builtin "safe";
  };
};
