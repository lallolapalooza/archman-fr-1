Devel::PatchPerl::Plugin(3) Documentation Perl fournie par l'utilisateur Devel::PatchPerl::Plugin(3)

NOM

Devel::PatchPerl::Plugin - Explication des plugins Devel::PatchPerl

VERSION

version 2.14

DESCRIPTION

Ce document explique le système de plugins de Devel::PatchPerl.

Les plugins sont un mécanisme pour fournir des fonctionnalités supplémentaires à Devel::PatchPerl.

Les plugins sont recherchés dans le namespace Devel::PatchPerl::Plugin.

INITIALISATION

Le constructeur du plugin est "patchperl".

Un plugin est spécifié en utilisant la variable d'environnement "PERL5_PATCHPERL_PLUGIN". Il peut être spécifié en totalité (c'est-à-dire "Devel::PatchPerl::Plugin::Feegle") ou juste la partie courte (c'est-à-dire "Feegle").

$ export PERL5_PATCHPERL_PLUGIN=Devel::PatchPerl::Plugin::Feegle
$ export PERL5_PATCHPERL_PLUGIN=Feegle

Lorsque Devel::PatchPerl a identifié le patch de la source Perl et effectué son application, il tentera de charger le plugin identifié. Il appellera ensuite la méthode de classe "patchperl" pour le package du plugin, avec les paramètres suivants :

'version', la version de Perl de l'arborescence source ;
'source', le chemin absolu vers l'arborescence source de Perl ;
'patchexe', l'utilitaire 'patch' qui peut être utilisé ;

Les plugins sont appelés avec le répertoire de travail courant étant la racine de l'arborescence source de Perl, c'est-à-dire "source".

En résumé :

$ENV{PERL5_PATCHPERL_PLUGIN} = 'Devel::PatchPerl::Plugin::Feegle';
my $plugin = $ENV{PERL5_PATCHPERL_PLUGIN};
eval "require $plugin";
eval {
  $plugin->patchperl( version => $vers, source => $srcdir, patchexe => $patch );
};

Il incombe aux plugins de vérifier que leurs patches s'appliquent à la version de perl qui est patchée.

QUE PEUVENT FAIRE LES PLUGINS?

Tout ce que vous désirez pour une arborescence source Perl.

POURQUOI UTILISER UNE VARIABLE D'ENVIRONNEMENT POUR SPÉCIFIER LES PLUGINS?

Afin que l'indication d'un plugin à utiliser puisse être spécifiée indépendamment de quelque mécanisme que ce soit qui appelle Devel::PatchPerl pour faire son travail.

Pensez à perlbrew.
