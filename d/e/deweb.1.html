deweb(1) Manuel des commandes générales deweb(1)

NOM

deweb - supprime les commandes C & CWEB des sources CWEB

SYNTAXE

deweb [ fichier1 fichier2 ... ]

DESCRIPTION

deweb filtre toutes les commandes C & CWEB d'un code source CWEB. Il ne laisse que le code LaTeX. Ce code dépouillé peut alors être transmis à un vérificateur de syntaxe approprié pour LaTeX, tel que ChkTeX et lacheck, ou à des correcteurs orthographiques comme ispell.

L'outil chkweb, inclus dans la distribution ChkTeX, fait exactement cela ; écrire des scripts similaires devrait être trivial.

Lorsque deweb dépouille le code C de votre source CWEB, il tente de conserver les sauts de ligne. Cela signifie que les rapports d'erreur de <votre outil préféré> seront corrects en ce qui concerne les numéros de ligne. Dans la plupart des cas, la position de la colonne sera également correcte. Cela simplifie considérablement la recherche d'erreurs dans le code LaTeX (contrairement à la sortie de cweave, dont la sortie est vraiment difficile à comprendre).

deweb accepte une liste de noms de fichiers sur la ligne d'arguments et envoie sa sortie à stdout. Si aucun nom de fichier n'est donné, il lit depuis stdin, agissant comme un filtre. Aucune option n'est actuellement acceptée.

Les utilisateurs hardis peuvent essayer de rediriger la sortie de deweb directement dans LaTeX, théoriquement, cela devrait fonctionner. Cela faciliterait considérablement le débogage du code LaTeX, car lorsque LaTeX se plaint d'une syntaxe incorrecte, vous pourrez trouver la ligne erronée beaucoup plus facilement. Ne vous attendez pas cependant à ce que la sortie ressemble beaucoup à la version finale.

deweb devrait maintenant comprendre tous les opcodes CWEB corrects. S'il se plaint de ne pas comprendre un opcode correct, veuillez en informer l'auteur.

BOGUES

Ne compile même pas sous les versions de Perl antérieures à perl v5. Malheureusement, cela signifie que nous ne pouvons même pas dire à l'utilisateur pourquoi nous avons échoué ; Perl se plaindra simplement de ne pas pouvoir compiler les expressions régulières.

Le programme essaiera d'absorber tout le fichier d'entrée en une seule fois, au lieu de le traiter ligne par ligne.
