CRYPTDIR(1) Manuel des commandes générales CRYPTDIR(1)

NOM

cryptdir - crypte/décrypte tous les fichiers d'un répertoire

SYNTAXE

cryptdir [ rép ]
decryptdir [ rép ]

INTRODUCTION

cryptdir crypte tous les fichiers du répertoire courant (ou du répertoire donné si un argument est fourni). Lorsqu'il est appelé en tant que decryptdir (c'est-à-dire le même programme, mais avec un nom différent), tous les fichiers sont décryptés.

NOTES

Lors du cryptage, le mot de passe vous est demandé deux fois par mesure de précaution. Ce serait une catastrophe de crypter des fichiers avec un mot de passe différent de celui voulu.

En revanche, lors du décryptage, le mot de passe n'est demandé qu'une seule fois. Si ce n'est pas le bon mot de passe, aucun dégât n'est causé.

Les fichiers cryptés portent le suffixe .crypt. Cela empêche les fichiers d'être cryptés deux fois. Le suffixe est retiré lors du décryptage. Ainsi, vous pouvez facilement ajouter des fichiers à un répertoire crypté et exécuter cryptdir dessus sans vous soucier des fichiers déjà cryptés.
