Devel__StackTrace__Frame(3pm)

Paquet: perl-devel-stacktrace

Licences: PerlArtistic, GPL

Devel::StackTrace::Frame(3) Documentation Perl fournie par l'utilisateur Devel::StackTrace::Frame(3)

NOM

Devel::StackTrace::Frame - une seule trame dans une pile d'appels

VERSION

version 2.05

DESCRIPTION

Voir Devel::StackTrace pour les détails.

MÉTHODES

Voir la documentation de "caller" de Perl pour plus d'informations sur ce que ces méthodes retournent.

$frame->package

Le paquet qui a créé cette trame.

$frame->filename

Le nom de fichier qui a créé cette trame.

$frame->line

La ligne où la trame a été créée.

$frame->subroutine

La sous-routine qui a créé cette trame.

$frame->hasargs

Ceci sera vrai si un nouveau @_ a été créé pour cette trame.

$frame->wantarray

Ceci indique le contexte de l'appel pour cette trame. Ceci sera vrai si appelé dans un contexte tableau, faux dans un contexte scalaire, et "undef" dans un contexte vide.

$frame->evaltext

Retourne undef si la trame ne faisait pas partie d'un eval.

$frame->is_require

Retourne undef si la trame ne faisait pas partie d'un require.

$frame->args

Retourne les arguments passés à la trame. Notez que tous les arguments qui sont des références sont retournés en tant que références, pas des copies.

$frame->hints

Retourne la valeur de $^H pour cette trame.

$frame->bitmask

Retourne la valeur de $bitmask pour cette trame.

$frame->as_string

Retourne une chaîne contenant une description de la trame.

SUPPORT

SOURCE
