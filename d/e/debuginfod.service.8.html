NOM

debuginfod.service - serveur d'informations relatives aux debuginfo pour systemd

SYNTAXE

/usr/lib/systemd/system/debuginfod.service

DESCRIPTION

debuginfod.service intègre le démon debuginfod avec systemd, servant les artefacts liés aux debuginfo via HTTP. Les données sont stockées dans /var/cache/debuginfod/debuginfod.sqlite. Configurez /etc/sysconfig/debuginfod pour définir les variables d'environnement ci-dessous ainsi que celles listées dans debuginfod(8).

Variables d'environnement

$DEBUGINFOD_PORT - Modifie le port du démon de service debuginfod.
$DEBUGINFOD_VERBOSE - Modifie la verbosité du rapport dans le fichier journal du démon de service debuginfod.
$DEBUGINFOD_PATHS - Modifie les chemins à scanner pour le démon de service debuginfod.

FICHIERS

/usr/lib/systemd/system/debuginfod.service, /var/cache/debuginfod/debuginfod.sqlite /etc/sysconfig/debuginfod

VOIR AUSSI
