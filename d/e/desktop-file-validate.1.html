NOM

desktop-file-validate - Valider les fichiers de description de bureau

SYNTAXE

desktop-file-validate [--no-hints] [--no-warn-deprecated] [--warn-kde] FICHIER...

DESCRIPTION

Le programme desktop-file-validate est un outil permettant de valider les fichiers de description de bureau selon la spécification 1.5 des descriptions de bureau.

La spécification décrit un format de fichier pour fournir des informations telles que le nom, l'icône et la description d'une application. Un tel fichier peut ensuite être utilisé comme lanceur d'application et pour afficher l'application dans le menu des applications.

Pour plus d'informations sur la spécification des descriptions de bureau, consultez http://freedesktop.org/wiki/Specifications/desktop-entry-spec.

Les fichiers de description de bureau sont couramment appelés fichiers desktop.

OPTIONS

Les options suivantes sont prises en charge :

--no-hints
Ne pas afficher d'indices sur les éléments qui pourraient être améliorés dans le fichier de bureau.
--no-warn-deprecated
Ne pas avertir de l'utilisation d'éléments obsolètes définis dans les versions précédentes de la spécification.
--warn-kde
Avertir de l'utilisation d'extensions KDE de la spécification. Cela inclut l'utilisation du groupe KDE Desktop Entry, des clés ServiceTypes, DocPath, Keywords, InitialPreference, Dev, FSType, MountPoint, ReadOnly, UnmountIcon, ou des types Service, ServiceType et FSDevice.

BOGUES

Si vous trouvez des bogues dans le programme desktop-file-validate, veuillez les signaler sur https://bugs.freedesktop.org.
