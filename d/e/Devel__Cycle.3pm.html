DESCRIPTIO

N

C'est un simple outil de développement pour trouver les références circulaires dans les objets et d'autres types de références. En raison de la gestion de la mémoire basée sur le comptage de références de Perl, les références circulaires provoqueront des fuites de

mémoire.

EXPOR

T

Les sous-programmes find_cycle() et find_weakened_cycle() sont exportés par

défaut.
find_cycle($object_reference,[$callback]
)
La fonction find_cycle() parcourra la référence de l'objet et imprimera un rapport sur STDOUT identifiant tout cycle mémoire qu'elle trouve.

Si une référence de code de rappel optionnelle est fournie, alors ce rappel sera invoqué pour chaque cycle trouvé. Le rappel recevra une référence de tableau pointant vers une liste de listes au format

suivant : 
$arg = [ ['REFTYPE',$index,$reference,$reference_value],
         ['REFTYPE',$index,$reference,$reference_value],
         ['REFTYPE',$index,$reference,$reference_value],
          ...
]

Chaque élément de la référence de tableau décrit une arête dans le cycle mémoire. 'REFTYPE' décrit le type de la référence et est l'un de 'SCALAR', 'ARRAY' ou 'HASH'. $index est l'index affecté par la référence, et est undef pour un scalaire, un entier pour une référence de tableau, ou une clé de hachage pour un hachage. $reference est la référence mémoire, et $reference_value est sa valeur déréférencée. Par exemple, si l'arête est un ARRAY, alors la relation suivante

tient : 
$reference->[$index] eq
$reference_value

Le premier élément de la référence de tableau est le $object_reference que vous avez passé à find_cycle() et peut ne pas être directement impliqué dans le

cycle.

Si une référence est une référence faible produite à l'aide de la fonction weaken() de Scalar::Util, elle

ne contribuera
pas aux cycles.
find_weakened_cycle($object_reference,[$callback]
)
La fonction find_weakened_cycle() parcourra la référence de l'objet et imprimera un rapport sur STDOUT identifiant tout cycle mémoire qu'elle trouve, y compris tout cycle affaibli produit à l'aide de la fonction weaken() de Scalar::Util.

Si une référence de code de rappel optionnelle est fournie, alors ce rappel sera invoqué pour chaque cycle trouvé. Le rappel recevra une référence de tableau pointant vers une liste de listes au format

suivant : 
$arg = [ ['REFTYPE',$index,$reference,$reference_value,$is_weakened],
         ['REFTYPE',$index,$reference,$reference_value,$is_weakened],
         ['REFTYPE',$index,$reference,$reference_value,$is_weakened],
          ...
]

Chaque élément de la référence de tableau décrit une arête dans le cycle mémoire. 'REFTYPE' décrit le type de la référence et est l'un de 'SCALAR', 'ARRAY' ou 'HASH'. $index est l'index affecté par la référence, et est undef pour un scalaire, un entier pour une référence de tableau, ou une clé de hachage pour un hachage. $reference est la référence mémoire, et $reference_value est sa valeur déréférencée. $is_weakened est un booléen spécifiant si la référence est affaiblie ou non. Par exemple, si l'arête est un ARRAY, alors la relation suivante

tient : 
$reference->[$index] eq
$reference_value

Le premier élément de la référence de tableau est le $object_reference que vous avez passé à find_cycle() et peut ne

pas être d
irectement
impliqué dan
s le cycle.

Formats de rapport des

cycles

Le rappel par défaut imprime une trace de chaque cycle qu'il trouve. Vous pouvez contrôler le format de la trace en définissant la variable de paquet $Devel::Cycle::FORMATTING à l'une des valeurs "raw," "cooked," ou

"roasted".

Le format "raw" imprime les références mémoire anonymes en utilisant la nomenclature standard des adresses mémoire de Perl. Par exemple, un objet "Foo::Bar" pointant vers un hachage ordinaire apparaîtra dans la trace comme ceci

: 
Foo::Bar=HASH(0x8124394)->{'phyllis'} =>
HASH(0x81b4a90)

Le format "cooked" (par défaut), utilise des noms courts pour les adresses mémoire anonymes, commençant par "A" et augmentant avec l'opérateur magique ++. Cela donne un affichage beaucoup plus lisible

: 
$Foo::Bar=B->{'phyllis'} =>
\%A

Le format "roasted" est similaire au format "cooked", sauf que les références d'objets sont formatées légèrement différemment

: 
$Foo::Bar::B->{'phyllis'} =>
\%A

Si une référence est une référence affaiblie, alors elle aura un 'w->' préfixé, comme ceci

: 
w-> $Foo::Bar::B->{'phyllis'} =>
\%A

Pour votre commodité, $Devel::Cycle::FORMATTING peut être importé

: 
use Devel::Cycle qw(:DEFAULT $FORMATTING);
$FORMATTING =
'raw';

Alternativement, vous pouvez contrôler le formatage à la compilation en passant l'une des options -raw, -cooked, ou -roasted à "use" comme illustré ici

: 
use Dev
el::Cycl
e -raw;

Références de code

(closures)

Si le module PadWalker est installé, Devel::Cycle signalera aussi les cycles dans les closures de code. Si PadWalker n'est pas installé et que Devel::Cycle détecte une référence CODE dans l'une des structures de données, il émettra un avertissement (une fois par structure de données) indiquant qu'il ne peut pas inspecter le CODE à moins que PadWalker soit disponible. Vous pouvez désactiver cet avertissement en passant -quiet à Devel::Cycle à la compilation

: 
use De
vel::C
ycle -
quiet;
