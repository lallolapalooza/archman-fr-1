DEBUGEDIT(1) Commandes utilisateur DEBUGEDIT(1)

NOM

debugedit - outil de manipulation de chemins sources de débogage

SYNTAXE

debugedit [OPTION...] FICHIER

DESCRIPTION

-b, --base-dir=CHAÎNE
répertoire de base de compilation des objets
-d, --dest-dir=CHAÎNE
répertoire dans lequel réécrire base-dir
-l, --list-file=CHAÎNE
fichier dans lequel mettre la liste des noms de fichiers sources et d'en-tête
-i, --build-id
recale la note d'ID de compilation et affiche l'ID sur la sortie standard
-s, --build-id-seed=CHAÎNE
si l'ID de compilation est recalculé, utilise cette chaîne comme graine de hachage
-n, --no-recompute-build-id
ne recalcule pas la note d'ID de compilation, même si -i ou -s sont donnés
-p, --preserve-dates
Préserve les horodatages de modification/accès

Options d'aide :

-?, --help
Affiche cette aide
-u, --usage
Affiche un bref message d'utilisation
-V, --version
Affiche la version de debugedit
juillet 2025 debugedit 5.2
