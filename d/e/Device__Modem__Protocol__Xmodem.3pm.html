Xmodem::Block

Classe représentant un seul bloc Xmodem.

Synopsis

my $b = Xmodem::Block->new( 1, 'Mes Données...<jusqu'à 128 caractères>...' );
if( defined $b ) {
        # Ok, bloc instancié, vérifiez sa somme de contrôle
        if( $b->verify( 'checksum', <ma_somme_de_controle> ) ) {
                ...
        } else {
                ...
        }
} else {
        # Pas de bloc
}
# Calculer la somme de contrôle, crc16, 32, ...
$crc16 = $b->crc16();
$crc32 = $b->crc32();
$chksm = $b->checksum();

Xmodem::Buffer

Classe implémentant un tampon de réception Xmodem de blocs de données. Chaque bloc de données est représenté par un objet "Xmodem::Block".

Les blocs peuvent être pushés et popés du tampon. Vous pouvez récupérer le dernier bloc, ou la liste des blocs du tampon.

Synopsis

my $buf = Xmodem::Buffer->new();
my $b1  = Xmodem::Block->new(1, 'Données...');
$buf->push($b1);
my $b2  = Xmodem::Block->new(2, 'Plus de données...');
$buf->push($b2);
my $last_block = $buf->last();
print 'j'ai maintenant ', scalar($buf->blocks()), ' dans le tampon';

Xmodem::Receiver

Classe de contrôle pour initier et compléter un transfert de fichier "X-modem" en mode réception.

Synopsis

my $recv = Xmodem::Receiver->new(
        modem    => {Objet Device::Modem},
        filename => 'nom du fichier',
        XXX protocol => 'xmodem' | 'xmodem-crc', | 'xmodem-1k'
);
$recv->run();

Méthodes d'objet

abort_transfer()
Envoie un caractère annuler ("can"), qui signale à l'expéditeur que le transfert est interrompu. Ceci est émis si nous recevons un mauvais numéro de bloc, ce qui signifie généralement que la ligne était mauvaise.
modem()
Retourne l'objet Device::Modem sous-jacent.
receive_message()
Récupère le message du modem et, si un bloc est détecté, le décompose en parties appropriées.
run()
Démarre un nouveau transfert jusqu'à ce que la réception du fichier soit terminée. Le seul paramètre accepté est le nom de fichier local (optionnel) à écrire.
send_ack()
Envoie un caractère d'acquittement ("ack") pour signaler que nous avons reçu et stocké un bloc correct. Réinitialise le compteur de timeouts et retourne l'objet "Xmodem::Block" du bloc de données reçu.
send_timeout()
Envoie un caractère de timeout ("nak") pour signaler que nous avons reçu un mauvais en-tête de bloc (soit un mauvais caractère de départ, soit un mauvais numéro de bloc), ou une mauvaise somme de contrôle des données. Incrémente le compteur de timeouts et, après dix timeouts, interrompt le transfert.
