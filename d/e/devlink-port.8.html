EXEMPLES

devlink port show

Affiche l'état de tous les ports devlink du système.

devlink port show pci/0000:01:00.0/1

Affiche l'état du port devlink spécifié.

devlink port set pci/0000:01:00.0/1 type eth

Définit le type du port devlink spécifié sur Ethernet.

devlink port split pci/0000:01:00.0/1 count 4

Divise le port devlink spécifié en quatre ports.

devlink port unsplit pci/0000:01:00.0/1

Réunit le port devlink spécifié qui avait été précédemment divisé.

devlink port health show

Affiche le statut et la configuration de tous les reporters pris en charge et enregistrés sur tous les ports devlink.

devlink port health show pci/0000:01:00.0/1 reporter tx

Affiche le statut et la configuration du reporter tx enregistré sur le port devlink pci/0000:01:00.0/1.

devlink port add pci/0000:06:00.0 flavour pcisf pfnum 0 sfnum 88

Ajoute un port devlink de type PCI SF sur le PCI PF ayant le numéro 0 avec le numéro SF 88. Pour utiliser la fonction, une séquence d'exemple consiste à ajouter un port, configurer l'attribut de la fonction et activer la fonction. Une fois l'utilisation de la fonction terminée, désactiver la fonction et enfin supprimer le port. Lorsqu'il est souhaité de réutiliser le port sans le supprimer, il peut être reconfiguré et réactivé lorsque la fonction est dans un état inactif et que l'état opérationnel de la fonction est détaché.

devlink port del pci/0000:06:00.0/1

Supprime le port devlink créé précédemment. Il est recommandé de d'abord désactiver la fonction si celle-ci prend en charge la gestion de l'état.

devlink port function set pci/0000:01:00.0/1 hw_addr 00:00:00:11:22:33

Configure l'adresse matérielle de la fonction PCI représentée par le port devlink. Si le port prend en charge le changement de l'état de la fonction, l'adresse matérielle doit être configurée avant d'activer la fonction.

devlink port function set pci/0000:01:00.0/1 state active

Active la fonction. Cela initiera l'énumération de la fonction et le chargement du pilote.

devlink port function set pci/0000:01:00.0/1 state inactive

Désactive la fonction. Cela initiera la déconstruction de la fonction, ce qui entraînera le déchargement du pilote et la suppression de l'appareil.

devlink port function set pci/0000:01:00.0/1 roce enable

Cela activera la fonctionnalité RoCE de la fonction.

devlink port function set pci/0000:01:00.0/1 migratable enable

Cela activera la fonctionnalité de migration de la fonction.

devlink port function set pci/0000:01:00.0/1 ipsec_crypto enable

Cela activera la fonctionnalité de déchargement matériel (offload) du chiffrement IPsec de la fonction.

devlink port function set pci/0000:01:00.0/1 ipsec_packet enable

Cela activera la fonctionnalité de déchargement matériel (offload) des paquets IPsec de la fonction.

devlink port function set pci/0000:01:00.0/1 max_io_eqs 4

Cela définira le nombre maximal de files d'événements E/S de la fonction sur 4.

devlink port function set pci/0000:01:00.0/1 hw_addr 00:00:00:11:22:33 state active

Configure l'adresse matérielle et active également la fonction. Lorsqu'une fonction est activée avec d'autres configurations dans une seule commande, toutes les configurations sont d'abord appliquées avant de changer l'état en actif.

devlink dev param show

Affiche (dump) tous les paramètres de port à travers tous les appareils enregistrés dans devlink.

devlink dev param set pci/0000:01:00.0/1 name internal_error_reset value true cmode runtime

Définit le paramètre internal_error_reset du port devlink spécifié (#1) sur true.

devlink port add pci/0000:06:00.0 flavour pcisf pfnum 0 sfnum 88 controller 1

Ajoute un port devlink de type PCI SF sur le contrôleur 1 qui a un PCI PF de numéro 0 avec le numéro SF 88. Pour utiliser la fonction, une séquence d'exemple consiste à ajouter un port, configurer l'attribut de la fonction et activer la fonction. Une fois l'utilisation de la fonction terminée, désactiver la fonction et enfin supprimer le port. Lorsqu'il est souhaité de réutiliser le port sans le supprimer, il peut être reconfiguré et réactivé lorsque la fonction est dans un état inactif et que l'état opérationnel de la fonction est détaché.
