NOM

dehtmldiff - obtenir un diff utilisable à partir d'une page HTML

SYNTAXE

dehtmldiff [fichier...]

dehtmldiff {[--help] | [--version]}

DESCRIPTION

dehtmldiff crée des fichiers diff utilisables à partir de pages HTML. Ceci est utile dans le scénario où un patch a été posté sur une liste de diffusion visible via une page web.

Le diff corrigé est envoyé sur la sortie standard. Notez que vous devrez probablement utiliser l'option -l lors de l'application du patch, afin d'ignorer toute différence d'espacement qui pourrait exister.

OPTIONS

--help

Affiche un court message d'utilisation.

--version

Affiche le numéro de version de dehtmldiff.

LIMITATIONS

La façon dont cette commande fonctionne est assez primitive ; elle se résume à quelques remplacements de texte simples, suivis d'un passage unwrapdiff. Par conséquent, toutes les limitations qui s'appliquent à unwrapdiff s'appliquent également à dehtmldiff.
