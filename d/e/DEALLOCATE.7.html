NOM

DEALLOCATE - libérer un énoncé préparé

SYNOPSIS

DEALLOCATE [ PREPARE ] { nom | ALL }

DESCRIPTION

DEALLOCATE est utilisé pour libérer un énoncé SQL précédemment préparé. Si vous ne libérez pas explicitement un énoncé préparé, il est libéré lorsque la session se termine.

Pour plus d'informations sur les énoncés préparés, voir PREPARE(7).

PARAMÈTRES

PREPARE

Ce mot clé est ignoré.

nom

Le nom de l'énoncé préparé à libérer.

ALL

Libérer tous les énoncés préparés.

COMPATIBILITÉ

La norme SQL inclut une instruction DEALLOCATE, mais elle est réservée à l'utilisation dans le SQL embarqué.

VOIR AUSSI

EXECUTE(7), PREPARE(7)
