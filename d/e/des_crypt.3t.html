DES_CRYPT(3) Manuel des fonctions de bibliothèque DES_CRYPT(3)

NOM

des_crypt, ecb_crypt, cbc_crypt, des_setparity — chiffrement DES rapide

SYNTAXE

#include <rpc/des_crypt.h>

int
ecb_crypt(char *key, char *data, unsigned datalen, unsigned mode);

int
cbc_crypt(char *key, char *data, unsigned datalen, unsigned mode, char *ivec);

void
des_setparity(char *key);

DESCRIPTION

Les fonctions ecb_crypt() et cbc_crypt() implémentent le NBS DES (Data Encryption Standard). Ces routines sont plus rapides et plus générales que crypt(3). Elles sont également capables d'utiliser le matériel DES s'il est disponible. La fonction ecb_crypt() chiffre en mode ECB (Electronic Code Book), qui chiffre des blocs de données indépendamment. La fonction cbc_crypt() chiffre en mode CBC (Cipher Block Chaining), qui enchaîne des blocs successifs. Le mode CBC protège contre les insertions, suppressions et substitutions de blocs. De plus, les régularités du texte en clair n'apparaîtront pas dans le texte chiffré.

Voici comment utiliser ces routines. Le premier argument, key, est la clé de chiffrement de 8 octets avec parité. Pour définir la parité de la clé, qui pour DES est dans le bit de poids faible de chaque octet, utilisez des_setparity(). Le deuxième argument, data, contient les données à chiffrer ou déchiffrer. Le troisième argument, datalen, est la longueur en octets de data, qui doit être un multiple de 8. Le quatrième argument, mode, est formé en combinant par OU logique (OR) certaines options. Pour la direction du chiffrement, OU logique soit DES_ENCRYPT soit DES_DECRYPT. Pour le chiffrement logiciel ou matériel, OU logique soit DES_HW soit DES_SW. Si DES_HW est spécifié et qu'il n'y a pas de matériel, le chiffrement est effectué en logiciel et la routine retourne DESERR_NOHWDEVICE. Pour cbc_crypt(), l'argument ivec est le vecteur d'initialisation de 8 octets pour le chaînage. Il est mis à jour vers le vecteur d'initialisation suivant au retour.

ERREURS

[DESERR_NONE]
Aucune erreur.
[DESERR_NOHWDEVICE]
Le chiffrement a réussi, mais a été effectué en logiciel au lieu du matériel demandé.
[DESERR_HWERR]
Une erreur s'est produite dans le matériel ou le pilote.
[DESERR_BADPARAM]
Mauvais argument passé à la routine.

Étant donné un statut de résultat stat, la macro DES_FAILED(stat) est fausse uniquement pour les deux premiers statuts.

DISPONIBILITÉ

Les fonctions ecb_crypt(), cbc_crypt(), et des_setparity() font partie de libtirpc.

VOIR AUSSI

crypt(3)

RESTRICTIONS

Ces routines ne sont pas disponibles dans RPCSRC 4.0. Ces informations sont fournies pour décrire l'interface DES attendue par Secure RPC.
