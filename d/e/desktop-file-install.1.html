DESCRIPTIO

N

Le programme desktop-file-install est un outil pour installer et, éventuellement, éditer des fichiers desktop. Le programme desktop-file-edit est un outil pour éditer un fichier desktop. Ils sont principalement utiles pour les développeurs et les responsables de

paquets.

Diverses options sont disponibles pour éditer les fichiers desktop. Les options d'édition peuvent être spécifiées plus d'une fois et seront traitées dans le même ordre que les options passées au

programme.

desktop-file-install et desktop-file-edit tenteront toujours de valider le fichier desktop résultant. Un échec de validation peut entraîner l'abandon de l'installation des fichiers

desktop.

La liste des catégories et des environnements de bureau enregistrés est définie dans la spécification des menus : http://freedesktop.org/wiki/Specifications/menu-spe

c
.

OPTION

S

Les options suivantes sont prises en charge

:
--dir=D
IR
Installer les fichiers desktop dans le répertoire
DIR.
-m,
--mode=MODE
Définir les permissions des fichiers de destination sur MOD
E.
--vendor=VEN
DOR
Ajouter un préfixe de fournisseur aux fichiers desktop. Si un fichier possède déjà ce préfixe, rien ne se passe ; sinon, le fichier sera nommé VENDOR-FILE. Par exemple : si VENDOR est freedesktop.org et FILE est specification.desktop, le fichier résultant sera freedesktop.org-specifica
tion.desktop.
--delete-origi
nal
Supprimer les fichiers desktop sources, ne laissant que les fichiers cibles. Cela « renomme » effectivement les fichiers
desktop.
--rebuild-mime-info-ca
che
Reconstruire la base de données des applications de types MIME après l'installation des fichiers desktop. Voir update-desktop-database(1) pour
des informations
sur cette
base de données.

OPTIONS

D'ÉDITION

Les options d'édition suivantes sont prises en charge

:
--set-key=K
EY
Définir la clé KEY à la valeur passée à l'option --set-value suivante. Une option --set-value correspondante est
obligatoire.
--set-value=VA
LUE
Définir la clé spécifiée avec l'option --set-key précédente à VALUE. Une option --set-key correspondante est
obligatoire.
--set-name=N
AME
Définir le nom (clé Name) sur NAME. Si un nom était déjà défini, il sera remplacé. Les localisations de l'ancien nom seront
supprimées.
--copy-name-to-generic-n
ame
Copier la valeur de la clé Name vers la clé GenericName. Notez qu'un fichier desktop requiert une clé Name pour être valide, cette option aura donc toujours un
effet.
--set-generic-name=GENERIC-N
AME
Définir le nom générique (clé GenericName) sur GENERIC-NAME. Si un nom générique était déjà défini, il sera remplacé. Les localisations de l'ancien nom générique seront
supprimées.
--copy-generic-name-to-n
ame
Copier la valeur de la clé GenericName vers la clé Name, si la clé GenericName est
présente.
--set-comment=COMM
ENT
Définir le commentaire (clé Comment) sur COMMENT. Si un commentaire était déjà défini, il sera remplacé. Les localisations de l'ancien commentaire seront
supprimées.
--set-icon=I
CON
Définir l'icône (clé Icon) sur ICON. Si une icône était déjà définie, elle sera remplacée. Les localisations de l'ancienne icône seront
supprimées.
--add-category=CATEG
ORY
Ajouter CATEGORY à la liste des catégories (clé Categories). Si CATEGORY était déjà présent dans la liste, cette opération est sans effet. Une catégorie non enregistrée devrait être préfixée par X-
.
--remove-category=CATEG
ORY
Retirer CATEGORY de la liste des catégories (clé Categories). Si CATEGORY n'était pas présent dans la liste, cette opération est sans
effet.
--add-mime-type=MIME-T
YPE
Ajouter MIME-TYPE à la liste des types MIME (clé MimeType). Si MIME-TYPE était déjà présent dans la liste, cette opération est sans
effet.
--remove-mime-type=MIME-T
YPE
Retirer MIME-TYPE de la liste des types MIME (clé MimeType). Si MIME-TYPE n'était pas présent dans la liste, cette opération est sans
effet.
--add-only-show-in=ENVIRONM
ENT
Ajouter ENVIRONMENT à la liste des environnements de bureau où les fichiers desktop devraient être affichés (clé OnlyShowIn). Si ENVIRONMENT était déjà présent dans la liste, cette opération est sans effet. Un environnement de bureau non enregistré devrait être préfixé par X-. Notez qu'une clé OnlyShowIn vide dans un fichier desktop signifie que le fichier desktop sera affiché dans tous les
environnements.
--remove-only-show-in=ENVIRONM
ENT
Retirer ENVIRONMENT de la liste des environnements de bureau où les fichiers desktop devraient être affichés (clé OnlyShowIn). Si ENVIRONMENT n'était pas présent dans la liste, cette opération est sans
effet.
--add-not-show-in=ENVIRONM
ENT
Ajouter ENVIRONMENT à la liste des environnements de bureau où les fichiers desktop ne devraient pas être affichés (clé NotShowIn). Si ENVIRONMENT était déjà présent dans la liste, cette opération est sans effet. Un environnement de bureau non enregistré devrait être préfixé par X-. Notez qu'une clé NotShowIn vide dans un fichier desktop signifie que le fichier desktop sera affiché dans tous les
environnements.
--remove-not-show-in=ENVIRONM
ENT
Retirer ENVIRONMENT de la liste des environnements de bureau où les fichiers desktop ne devraient pas être affichés (clé NotShowIn). Si ENVIRONMENT n'était pas présent dans la liste, cette opération est sans
effet.
--remove-key=
KEY
Retirer la clé KEY des fichiers de
sktop, si
elle est
présente.

ENVIRONNEMEN

T

Certaines variables d'environnement modifient le comportement de desktop-file-in

stall :

DESKTOP_FILE_VENDO

R
Cette variable peut être utilisée comme alternative à l'option --vendor. Si l'option --vendor est utilisée, cette variabl
e d'environnement s
era ignorée.

DESKTOP_FILE_INSTALL_DI

R
Cette variable peut être utilisée comme alternative à l'option --dir. Si l'option --dir est utilisée, cette variable
d'environnement s
era ignorée.

RPM_BUILD_ROO

T
Cette variable est définie lors de la construction des paquets RPM. Si l'option --dir et la variable d'environnement DESKTOP_FILE_INSTALL_DIR ne sont pas utilisées, elle sera automatiquement ajoutée au début du répertoire d'installation par défaut pour installer correctement les fichiers de bureau lors de la construction des paquets.

Si vous trouvez des bogues dans le programme desktop-file-install, veuillez les signaler sur https://bugs.freedesktop.org.
