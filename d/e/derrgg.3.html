sous-routine derrgg (character*3 path, integer nunit)

DERRGG

But:

!>
!> DERRGG teste les sorties d'erreur pour DGGES, DGGESX, DGGEV,  DGGEVX,
!> DGGGLM, DGGHRD, DGGLSE, DGGQRF, DGGRQF, DGGSVD3,
!> DGGSVP3, DHGEQZ, DORCSD, DTGEVC, DTGEXC, DTGSEN, DTGSJA, DTGSNA,
!> DGGES3, DGGEV3, et DTGSYL.
!>

Paramètres

PATH 
!>          PATH est CHARACTER*3
!>          Le nom du chemin LAPACK pour les routines à tester.
!>

NUNIT

!>          NUNIT est INTEGER
!>          Le numéro de l'unité de sortie.
!>
