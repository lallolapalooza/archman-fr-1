DEJAGNU-HELP(1) Manuel des commandes générales (urm) DEJAGNU-HELP(1)

NOM

dejagnu help — affiche les pages de manuel des commandes auxiliaires de DejaGnu

SYNTAXE

dejagnu help [options...] ⟨commande⟩

DESCRIPTION

La commande dejagnu help affiche une documentation détaillée pour les commandes auxiliaires de DejaGnu.

OPTIONS

-v, --verbose
Émet une sortie supplémentaire décrivant le fonctionnement de dejagnu help lui-même.
-w, --path
Cette option est simplement transmise à man.
-W
Cette option est simplement transmise à man.

FICHIERS

La commande dejagnu help recherche les pages de manuel dans un répertoire doc/ à côté du répertoire commands/ où se trouve ce script. Si la page est trouvée là, un nom de fichier complet est donné à man. Sinon, seul le nom de la commande est donné et la recherche décrite dans man(1) est effectuée.

BOGUES
