NOM

Device::Modem::Log::File - Plugin de journalisation de fichiers texte pour la classe Device::Modem

SYNTAXE

use Device::Modem;
my $box = Device::Modem->new( log => 'file', ... );
my $box = Device::Modem->new( log => 'file,name=/tmp/mymodem.log', ... );
...

DESCRIPTION

Ceci est destiné à être un exemple de classe de journalisation à intégrer à "Device::Modem" pour fournir votre mécanisme de journalisation préféré. Vous devez simplement implémenter vos propres méthodes new(), write() et close().

Le fichier texte par défaut est "/tmp/modem.log". Sur les plateformes Windows, cela va dans "%TEMP%/modem.log" ou "%TMP%/modem.log", selon ce qui est défini. Par défaut, si le dossier du fichier journal n'existe pas, il est créé.

Cette classe est chargée automatiquement par la classe "Device::Modem" lorsqu'un objet est instancié, et c'est le mécanisme de journalisation par défaut pour la classe "Device::Modem".

Normalement, vous ne devriez pas avoir besoin d'utiliser cette classe directement, car il existe une multitude d'autres modules qui font mieux la journalisation que celle-ci.

Il devrait également être envisagé de remplacer "Device::Modem::Log::File" et ses acolytes par ces meilleures classes dans un avenir un peu lointain.

REQUIRES

Device::Modem
