Paquet: perl-device-gsm

Device::Gsm(3) Documentation Perl contribuée par les utilisateurs Device::Gsm(3)

NOM

Device::Gsm - Extension Perl pour interfacer les téléphones / modems GSM

SYNOPSIS

use Device::Gsm;
my $gsm = new Device::Gsm( port => '/dev/ttyS1', pin => 'xxxx' );
if( $gsm->connect() ) {
    print "connected!\n";
} else {
    print "sorry, no connection with gsm phone on serial port!\n";
}
# Register to GSM network (you must supply PIN number in above new() call)
# See 'assume_registered' in the new() method documentation
$gsm->register();
# Send quickly a short text message
$gsm->send_sms(
    recipient => '+3934910203040',
    content   => 'Hello world! from Device::Gsm'
);
# Get list of Device::Gsm::Sms message objects
# see `examples/read_messages.pl' for all the details
my @messages = $gsm->messages();

DESCRIPTION

La classe "Device::Gsm" implémente les fonctions GSM de base, l'enregistrement réseau et l'envoi de SMS. Cette classe prend également en charge le

mode "PDU" pour envoyer des messages "SMS" , et devrait être assez utilisable. Dans le passé, je l'ai développée et testée sous Linux RedHat 7.1 avec un port série 16550 et des téléphones GSM Siemens C35i/C45 connectés avec un câble série compatible Siemens. Après quelques années, je l'ai développée et testée avec Linux Slackware 10.2 et un dongle USB Bluetooth Cambridge Silicon Radio (CSR), en se connectant à un téléphone Nokia 6600.

Actuellement, je n'utilise plus ce logiciel. Il devrait probablement toujours fonctionner, mais il est peu probable que je puisse le tester à nouveau avec un vrai module GSM.

N'hésitez pas à me contacter si vous rencontrez des problèmes ou si vous êtes intéressé par l'amélioration de ce logiciel.

Si vous avez besoin d'un moyen de tester votre module ou téléphone GSM et que vous ne craignez pas de dépenser un SMS, utilisez le script "examples/send_to_cosimo.pl" pour me notifier que "Device::Gsm" fonctionne toujours et fonctionne bien avec votre appareil (merci !).

Au fil des ans, j'ai collecté des centaines de messages du monde entier :-)

POURQUOI ?

Pourquoi voudriez-vous utiliser ceci ?

Quand j'ai commencé à écrire ce logiciel, vers l'an 2000, j'avais besoin d'un moyen pratique d'envoyer automatiquement des dizaines de SMS via mon téléphone.

En accélérant jusqu'en 2016, j'utilise à peine les SMS, et vous pouvez trouver de nombreux services basés sur TCP/IP pour envoyer des SMS, peut-être même gratuitement.

La seule motivation restante serait d'apprendre comment fonctionnent les commandes AT pour les modules GSM. J'ai eu beaucoup de plaisir à apprendre cela, mais cela remonte à de nombreuses années, et YMMV, comme on dit.

MÉTHODES

Ce qui suit documente toutes les méthodes prises en charge avec de simples exemples d'utilisation.

new()

Héritée de Device::Modem. Voir la documentation de Device::Modem pour plus de détails.

Le seul argument obligatoire est le "port" que vous souhaitez utiliser pour vous connecter à l'appareil GSM :

my $gsm = Device::Gsm->new(
    port => '/dev/ttyS0',
);

Sur certains téléphones, vous pouvez rencontrer des problèmes lors de l'étape d'enregistrement sur le réseau GSM. Pour cette raison, vous pouvez passer une option spéciale "assume_registered" pour que Device::Gsm ignore l'étape d'enregistrement et suppose que l'appareil est déjà enregistré sur le réseau GSM. Exemple :

my $gsm = Device::Gsm->new(
    port => '/dev/ttyS0',
    assume_registered => 1,
);

Si vous souhaitez envoyer des informations de débogage vers votre propre fichier journal au lieu du paramètre par défaut, vous pouvez :

my $gsm = Device::Gsm->new(
    port => '/dev/ttyS1',
    log => 'file,/tmp/myfile.log',
    loglevel => 'debug',  # default is 'warning'
);

connect()

C'est l'appel principal qui se connecte à l'appareil approprié. Une fois la connexion établie, vous pouvez commencer à émettre des commandes. La liste des paramètres acceptés (à spécifier sous forme de clés et valeurs de hachage) est la même que celle de "Device::SerialPort" (ou "Win32::SerialPort" sur la plateforme Windows), car tous les paramètres sont transmis à la méthode "connect()" de ces classes.

La valeur par défaut du paramètre "baudrate" est 19200.

Exemple :

my $gsm = Device::Gsm->new( port=>'/dev/ttyS0', log=>'syslog' );
# ...
if( $gsm->connect(baudrate => 19200) ) {
    print "Connected!";
} else {
    print "Could not connect, sorry!";
}
# ...

datetime()

Utilisée pour obtenir ou définir la date et l'heure de votre téléphone/modem GSM.

Si elle est appelée sans paramètres, elle obtient la date et l'heure actuelles du téléphone/GSM au format "gsm", "AA/MM/JJ,HM:MN:SS". Par exemple "03/12/15,22:48:59" signifie le 15 décembre, à 22h48m59s. Exemple :

$datestr = $gsm->datetime();

Si elle est appelée avec des paramètres, elle définit la date et l'heure actuelles du téléphone/GSM à la valeur fournie. Exemple :

$newdate = $gsm->datetime( time() );

où time() est la fonction intégrée de Perl "time()" (voir "perldoc -f time" pour les détails). Une autre variante permet de passer un tableau "localtime" pour définir la date et l'heure correspondantes. Exemple :

$newdate = $gsm->datetime( localtime() );

(Notez le contexte de liste). Encore une fois, vous pouvez lire les détails de la fonction "localtime" avec "perldoc -f localtime".

Si votre appareil ne prend pas en charge cette commande, une valeur "undef" sera retournée dans les deux cas.

delete_sms()

Cette méthode supprime un message de votre carte SIM, étant donné le numéro d'index du message. Exemple :

$gsm->delete_sms(3);

Un deuxième paramètre facultatif spécifie le "storage". Il permet de supprimer des messages de la mémoire du téléphone GSM ou de la mémoire de la carte SIM. Exemple :

# Deletes first message from gsm phone memory
$gsm->delete_sms(1, 'ME');
# Deletes 3rd message from sim card
$gsm->delete_sms(3, 'SM');

Par défaut, il utilise le stockage actuellement défini, via la méthode "storage()" .

forward()

Définit le renvoi d'appel. Accepte trois arguments : raison, mode et numéro. La raison peut être la chaîne "unconditional", "busy", "no reply" et "unreachable". Le mode peut être la chaîne "disable", "enable", "query", "register", "erase".

Exemple :

# Set unconditional call forwarding to +47 123456789
$gsm->forward('unconditional','register','+47123456789');
# Erase unconditional call forwarding
$gsm->forward('unconditional','erase');

hangup()

Raccroche le téléphone, terminant les appels actifs, le cas échéant. Cette méthode n'a jamais été testée en conditions "réelles", mais elle doit être spécialisée pour les téléphones GSM, car elle repose sur la commande GSM "+HUP" . Exemple :

$gsm->hangup();

imei()

Retourne le numéro IMEI de l'appareil (International Mobile Station Equipment Identity).

Cet identifiant est numérique et est censé être unique parmi tous les appareils mobiles et téléphones GSM. Exemple :

my $imei = $gsm->imei();

manufacturer()

Retourne le fabricant de l'appareil, généralement seulement le premier mot (exemple : "Nokia", "Siemens", "Falcom", ...). Exemple :

my $man_name = $gsm->manufacturer();
if( $man_name eq 'Nokia' ) {
    print "We have a nokia phone...";
} else {
    print "We have a $man_name phone...";
}

messages()

Cette méthode est quelque peu instable et susceptible de changer, mais pour l'instant elle semble fonctionner. Elle est destinée àextraire tous les messages SMS texte stockés sur votre carte SIM ou votre téléphone gsm. En contexte liste, elle retourne une liste de messages (ou une valeur indéfinie s'il n'y a pas de message ou en cas d'erreur), chaque message étant un "Device::Gsm::Sms" objet.

Le seul paramètre spécifie le "storage" où vous voulez lire les messages, et peut prendre certaines des valeurs suivantes (mais vérifiez le manuel de votre téléphone/modémeur pour les valeurs spéciales des fabricants) :

"ME"
Signifie mémoire du téléphone gsm MEmoire
"MT"
Signifie mémoire du téléphone gsm MEmoire sur les téléphones Nokia ?
"SM"
Signifie Sim card Mémoire (valeur par défaut)

Exemple :

my $gsm = Device::Gsm->new();
$gsm->connect(port=>'/dev/ttyS0') or die "Can't connect!";
for( $gsm->messages('SM') )
{
    print $_->sender(), ': ', $_->content(), "\n";
}

mode()

Définit le mode de commande GSM de l'appareil. Accepte un paramètre pour définir le nouveau mode qui peut être la chaîne "text" ou "pdu". Exemple :

# Set text mode
$gsm->mode('text');

# Set pdu mode
$gsm->mode('pdu');

model()

Retourne le nom ou le numéro du modèle du téléphone/appareil. Exemple :

my $model = $gsm->model();

Par exemple, pour un Siemens C45, $model contient "C45"; pour un Nokia 6600, $model contient 6600.

network()

Retourne l'opérateur de réseau GSM actuellement enregistré ou préféré. Exemple :

my $net_name = $gsm->network();
# Returns 'Wind Telecom Spa'
my($net_name, $net_code) = $gsm->network();
# Returns ('Wind Telecom Spa', '222 88')

Cela varie évidemment selon le pays et l'opérateur réseau. Pour moi, c'est "Wind Telecomunicazioni SpA". Il n'est pas garanti que le téléphone mobile retourne le nom du réseau décodé. Il peut aussi retourner un code de réseau gsm, comme "222 88". Dans ce cas, une tentative de décodage du nom du réseau est faite.

Assurez-vous d'appeler la méthode network() lorsque vous êtes déjà enregistré sur le réseau gsm. Voir la méthode register() .

signal_quality()

Retourne la mesure de la qualité du signal exprimée en unités dBm, où une valeur proche de zéro est meilleure. Une valeur d'exemple est -91 dBm, et la valeur rapportée est -91. Les valeurs devraient être comprises entre -113 et -51 dBm, où -113 est la qualité de signal minimale et -51 est la qualité maximale théorique.

my $level = $gsm->signal_quality();

Si la qualité du signal ne peut pas être lue ou si votre appareil ne supporte pas cette commande, une valeur undefined sera retournée.

software_version()

Retourne la version du firmware de l'appareil, telle que stockée par le fabricant. Exemple :

my $rev = $gsm->software_revision();

Par exemple, pour mon Siemens C45, $rev contient 06.

storage()

Permet d'obtenir/définir le stockage sms actuel, c'est-à-dire où les messages sms sont sauvegardés, soit la carte SIM soit la mémoire du téléphone gsm. Les téléphones/modémeurs qui ne supportent pas cette fonctionnalité (implémentée par la commande AT "+CPMS" ne seront pas affectés par cette méthode.

my @msg;
my $storage = $gsm->storage();
print "Current storage is $storage\n";
# Read all messages on sim card
$gsm->storage('SM');
@msg = $gsm->messages();
# Read messages from gsm phone memory
$gsm->storage('ME');
push @msg, $gsm->messages();

test_command()

Cette méthode interroge l'appareil pour savoir si une commande AT GSM spécifique est supportée. Cela n'est utilisé qu'avec les commandes GSM (celles avec le préfixe "AT+" ). Par exemple, si je veux savoir si mon appareil supporte la commande "AT+GXXX" :

my $gsm = Device::Gsm->new( port => '/dev/myport' );
...
if( $gsm->test_command('GXXX') ) {
    # Ok, command is supported
} else {
    # Nope, no GXXX command
}

Notez que si vous omettez le caractère de départ "+" , il est automatiquement ajouté. Vous pouvez aussi tester des commandes comme "^SNBR" ou le genre, sans que le caractère "+" ne soit ajouté.

Cette méthode met en cache les résultats du test pour les utiliser dans les tests futurs (au moins jusqu'à ce que connect() ou disconnect() soit exécuté).

register()

"S'enregistrer" sur le réseau GSM est ce qui se passe quand vous allumez votre téléphone mobile ou votre équipement GSM et que l'appareil essaie d'atteindre le réseau de l'opérateur GSM. Si votre appareil requiert un code PIN , il est utilisé ici (mais souvenez-vous de fournir le paramètre "pin" dans le new() constructeur d'objet pour que cela fonctionne.

L'enregistrement peut prendre quelques secondes, ne vous inquiétez pas de l'attente. Après cela, vous êtes prêt à envoyer vos messages SMS ou à passer des appels vocaux. Normalement, vous n'avez pas besoin d'appeler register() explicitement car cela est fait automatiquement pour vous quand/c'est nécessaire.

Si la valeur de retour est vraie, l'enregistrement a réussi, sinon il y a quelque chose qui ne va pas ; probablement vous avez fourni le mauvais code PIN ou le réseau est injoignable.

send_sms()

Évidemment, cela envoie des messages SMS texte. Je devrais vous avertir que vous ne pouvez pas envoyer (pour l'instant) des messages MMS, sonneries, smart, ota d'aucune sorte avec cette méthode.

Envoyer rapidement un message SMS :

my $sent = $gsm->send_sms(
    content   => 'Hello, world!',   # SMS text
    recipient => '+99000123456',    # recipient phone number
);
if( $sent ) {
    print "OK!";
} else {
    print "Troubles...";
}

Les paramètres autorisés pour send_sms() sont :

"class"
Le paramètre class peut prendre deux valeurs : "normal" et "flash". Les messages Flash (ou classe zéro) sont particuliers car ils sont affichés immédiatement (sans confirmation de l'utilisateur) et jamais stockés en mémoire du téléphone, tandis que "normal" est la valeur par défaut.
"content"
C'est le texte que vous voulez envoyer, consistant en max 160 caractères si vous utilisez le mode PDU et 140 (?) si en mode text (plus sur cela plus tard).
"mode"
Peut prendre deux valeurs (insensible à la casse) : "pdu" et "text". "PDU" signifie Protocol Data Unit et c'est une sorte de binaire encodage des commandes, pour gagner du temps/de l'espace, tandis que "text" est le mode texte normal des commandes GSM.

Les téléphones mobiles et équipements GSM récents ont sûrement support pour le mode "PDU" . Les anciens modules OEM (comme Falcom Swing, par exemple) n'ont pas de mode PDU, mais seulement le mode texte. C'est juste une question d'essayer.

"recipient"
Numéro de téléphone du destinataire du message
"status_report"
Si présent avec une valeur vraie, cela active l'envoi de messages SMS (seulement pour le mode PDU, les SMS en mode texte ne seront pas influencés par ce paramètre) avec le rapport de statut, aussi connu comme rapport de livraison, qui est un court message qui rapporte le statut de votre message envoyé. Habituellement, cela n'est disponible que si votre compagnie de mobile supporte cette fonctionnalité, et probablement vous serez facturé un petit montant pour ce service.

Plus d'informations sur cela seraient les bienvenues.

service_center()

Si appelé sans paramètres, retourne le numéro de téléphone actuel du Centre de Service SMS. C'est le numéro que votre téléphone appelle automatiquement quand il reçoit et envoie des messages SMS texte, et votre opérateur réseau devrait vous dire quel est ce numéro.

Exemple :

my $gsm = Device::Gsm->new( port => 'COM1' );
$gsm->connect() or die "Can't connect";
$srv_cnt = $gsm->service_center();
print "My service center number is: $srv_cnt\n";

Si vous voulez définir ou changer ce numéro (si utilisé de manière inappropriée, cela peut désactiver l'envoi de messages SMS, alors soyez averti !), vous pouvez essayer quelque chose comme :

my $ok = $gsm->service_center('+99001234567');
print "Service center changed!\n" if $ok;

REQUIRES

  • Device::Modem, qui à son tour requiert
  • Device::SerialPort (ou Win32::SerialPort sur les machines Windows)

EXPORT

None

TROUBLESHOOTING

Si vous rencontrez des problèmes, veuillez vérifier à nouveau :

Permissions de l'appareil
Peut-être que vous n'avez pas les permissions nécessaires pour accéder à votre port série, irda ou bluetooth. Essayez d'exécuter votre script en tant que root, ou essayez, si cela ne vous dérange pas, "chmod a+rw /dev/ttyS1" (ou quoi que vous utilisez à la place de "/dev/ttyS1").
Vitesse de connexion
Essayez de changer le paramètre "baudrate" de 19200 (la valeur par défaut) à 9600 ou vice versa. C'est celui qui est responsable de 80% des problèmes, car il n'y a pas de détection automatique du baudrate.
Autoscan de l'appareil
Si tout le reste échoue, veuillez utiliser l'utilitaire autoscan dans le dossier "bin/" de la distribution "Device::Gsm" . Essayez de lancer cet utilitaire autoscan et examinez le fichier journal produit dans le répertoire courant.

Si vous perdez tout espoir, envoyez-moi ce fichier journal afin que je puisse éventuellement avoir un indice sur le problème / l'échec.

C'est aussi un outil de profilage, pour savoir quelles commandes sont supportées par votre appareil, alors veuillez m'envoyer les profils de vos appareils, afin que je puisse ajouter un meilleur support pour tous les appareils dans le futur !

Période de validité
Prise en charge de l'option « validity » (période de validité) lors de l'envoi de SMS. Indique combien de temps le Centre de service SMS doit conserver le SMS pour la livraison s'il n'est pas reçu.
