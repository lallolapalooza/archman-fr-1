des_crypt(3) Manuel des fonctions de bibliothèque des_crypt(3)

NOM

des_crypt, ecb_crypt, cbc_crypt, des_setparity, DES_FAILED - chiffrement DES rapide

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <rpc/des_crypt.h>
[[deprecated]] int ecb_crypt(unsigned int datalen;
                             char *key, char data[datalen],
                             unsigned int datalen, unsigned int mode);
[[deprecated]] int cbc_crypt(unsigned int datalen;
                             char *key, char data[datalen],
                             unsigned int datalen, unsigned int mode,
                             char *ivec);
[[deprecated]] void des_setparity(char *key);
[[deprecated]] int DES_FAILED(int status);

DESCRIPTION

ecb_crypt() et cbc_crypt() implémentent le NBS DES (Data Encryption Standard). Ces routines sont plus rapides et plus générales que crypt(3). Elles peuvent également utiliser le matériel DES s'il est disponible. ecb_crypt() chiffre en mode ECB (Electronic Code Book), qui chiffre des blocs de données indépendamment. cbc_crypt() chiffre en mode CBC (Cipher Block Chaining), qui enchaîne les blocs successifs. Le mode CBC protège contre les insertions, suppressions et substitutions de blocs. De plus, les régularités dans le texte clair n'apparaîtront pas dans le texte chiffré.

Voici comment utiliser ces routines. Le premier argument, key, est la clé de chiffrement de 8 octets avec parité. Pour définir la parité de la clé, qui pour DES est dans le bit de poids faible de chaque octet, utilisez des_setparity(). Le deuxième argument, data, contient les données à chiffrer ou déchiffrer. Le troisième argument, datalen, est la longueur en octets de data, qui doit être un multiple de 8. Le quatrième argument, mode, est formé en combinant plusieurs options par OU logique. Pour la direction du chiffrement, ajoutez par OU DES_ENCRYPT ou DES_DECRYPT. Pour le chiffrement logiciel par rapport au matériel, ajoutez par OU DES_HW ou DES_SW. Si DES_HW est spécifié, et qu'il n'y a pas de matériel, le chiffrement est effectué en logiciel et la routine retourne DESERR_NOHWDEVICE. Pour cbc_crypt(), l'argument ivec est le vecteur d'initialisation de 8 octets pour l'enchaînement. Il est mis à jour vers le prochain vecteur d'initialisation au retour.

VALEUR DE RETOUR

DESERR_NONE
Aucune erreur.
DESERR_NOHWDEVICE
Le chiffrement a réussi, mais a été effectué en logiciel au lieu du matériel demandé.
DESERR_HWERROR
Une erreur s'est produite dans le matériel ou le pilote.
DESERR_BADPARAM
Mauvais argument pour la routine.

Étant donné un statut de résultat stat, la macro DES_FAILED(stat) est fausse uniquement pour les deux premiers statuts.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
ecb_crypt (), cbc_crypt (), des_setparity () Sécurité thread MT-Safe

NORMES

Aucune.

HISTORIQUE

4.3BSD. glibc 2.1. Supprimé dans glibc 2.28.

Parce qu'elles utilisent le chiffrement par bloc DES, qui n'est plus considéré comme sûr, ces fonctions ont été supprimées. Les applications devraient passer à une bibliothèque cryptographique moderne, telle que libgcrypt.
