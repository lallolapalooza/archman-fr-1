Devel::Cover::DB(3) Documentation Perl fournie par l'utilisateur Devel::Cover::DB(3)

NOM

Devel::Cover::DB - Métriques de couverture de code pour Perl

VERSION

version 1.51

SYNOPIS

use Devel::Cover::DB;
my $db = Devel::Cover::DB->new(db => "ma_db_couverture");
$db->print_summary([$fichier1, $fichier2], ["instruction", "pod"]);

DESCRIPTION

Ce module fournit un accès à une base de données d'informations de couverture de code.

MÉTHODES

new

my $db = Devel::Cover::DB->new(db => "ma_db_couverture");

Construit la base de données à partir de la base de données spécifiée.

cover

my $cover = $db->cover;

Renvoie un objet Devel::Cover::DB::Cover. À partir de là, toutes les données de couverture peuvent être consultées.

my $cover = $db->cover;
for my $file ($cover->items) {
    print "$file\n";
    my $f = $cover->file($file);
    for my $criterion ($f->items) {
        print "  $criterion\n";
        my $c = $f->criterion($criterion);
        for my $location ($c->items) {
            my $l = $c->location($location);
            print "    $location @$l\n";
        }
    }
}

Les données pour différents critères seront dans des formats différents, donc cela nécessitera une gestion spéciale. Ce n'est pas encore documenté, donc le mieux pour l'instant est de regarder certains des rapports les plus simples et/ou le code source.

Les méthodes de l'exemple ci-dessus sont en fait des alias pour des méthodes de Devel::Cover::DB::Base (la classe de base pour toutes les classes Devel::Cover::DB::*):

  • Devel::Cover::DB::Base->values

    Alias pour Devel::Cover::DB::Cover->files, Devel::Cover::DB::File->criteria, Devel::Cover::DB::Criterion->locations, et Devel::Cover::DB::Location->data

  • Devel::Cover::DB::Base->get

    Alias pour Devel::Cover::DB::Cover->file, Devel::Cover::DB::File->criterion, Devel::Cover::DB::Criterion->location, et Devel::Cover::DB::Location->datum

Au lieu d'appeler $file->criterion("x") vous pouvez aussi appeler $file->x.

est_valide

my $valide = $db->is_valid;

Renvoie vrai si $db est valide (ou semble valide, la fonction est trop laxiste).
