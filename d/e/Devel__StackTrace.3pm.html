Cette méthode peut également être utilisée pour définir les trames de l'objet si vous lui transmettez une liste d'objets Devel::StackTrace::Frame.

C'est utile si vous souhaitez filtrer la liste des trames de manière plus complexe que ce qui peut être géré par la "$trace->filter_frames" méthode :

$stacktrace->frames( my_filter( $stacktrace->frames ) );

$trace->frame($index)

Étant donné un index, cette méthode retourne la trame correspondante, ou undef s'il n'y a pas de trame à cet index. L'index est exactement comme pour un tableau Perl. La première trame est 0 et les index négatifs sont autorisés.

$trace->frame_count

Retourne le nombre de trames dans l'objet trace.

$trace->as_string(\%p)

Appelle "$frame->as_string" sur chaque trame du haut vers le bas, produisant une sortie très similaire aux méthodes cluck/confess du module Carp.

Le paramètre optionnel "\%p" n'a qu'une seule option. Le "max_arg_length" paramètre tronque la représentation en chaîne de chaque argument de sous-routine si elle est plus longue que ce nombre de caractères.

Si toutes les trames d'une trace sont ignorées, alors cela retourne simplement le "message" passé au constructeur ou la chaîne "Trace begun".

$trace->message

Retourne le message passé au constructeur. Si celui-ci n'a pas été passé, alors cette méthode retourne "undef".
