NOM

defaults - lire ou modifier les valeurs par défaut de l'utilisateur GNUstep

SYNOPSIS

defaults [ action ]

DESCRIPTION

La commande 'defaults' permet de lire et modifier les valeurs par défaut d'un utilisateur.

Ce programme remplace les anciens programmes NeXTstep comme dread, dwrite et dremove.

Si vous avez accès à la base de données des valeurs par défaut d'un autre utilisateur, vous pouvez inclure '-u nomutilisateur' avant toute autre option pour utiliser la base de données de cet utilisateur plutôt que la vôtre.

defaults read [ domaine [ clé] ]

lit la valeur par défaut nommée du domaine spécifié. Si aucune 'clé' n'est fournie, lit toutes les valeurs par défaut du domaine. Si aucun 'domaine' n'est fourni, lit toutes les valeurs par défaut de tous les domaines. Un domaine est soit le nom d'une application, soit "NSGlobalDomain", pour les valeurs par défaut au niveau du système. (Les programmes en cours d'exécution peuvent accéder à deux autres domaines : "NSArgumentDomain", pour les arguments de la ligne de commande, "NSRegistrationDomain", un domaine de seconde chance où les "valeurs par défaut pour les valeurs par défaut" peuvent être enregistrées, et potentiellement des domaines pour des locales spécifiques.)

defaults readkey clé

lit la valeur par défaut nommée dans tous les domaines.

defaults write domaine clé valeur

écrit 'valeur' comme valeur par défaut 'clé' dans le domaine spécifié. 'valeur' doit être une property list entre apostrophes simples.

defaults write domaine dictionnaire

écrit 'dictionnaire' comme remplacement pour le domaine spécifié. 'dictionnaire' doit être une property list entre apostrophes simples.

defaults write

lit l'entrée standard pour les valeurs par défaut dans le format produit par 'defaults read' et les écrit dans la base de données.

defaults delete [ domaine [ clé] ]

supprime la ou les valeurs par défaut spécifiées du domaine. Si aucune 'clé' n'est fournie, supprime le domaine entier.

defaults delete

lit l'entrée standard pour une série de lignes contenant des paires de domaines et de clés pour les valeurs par défaut à supprimer.

defaults domains

liste les domaines dans la base de données (un par ligne)

defaults find mot

recherche dans les noms de domaines, les noms de valeurs par défaut et les chaînes de valeurs par défaut celles qui sont égales au mot spécifié et les liste sur la sortie standard.

defaults plist

affiche des informations sur les property lists

defaults help

liste les options de la commande defaults.

FICHIERS

~/GNUstep/Defaults/.GNUstepDefaults
contient les valeurs par défaut d'un utilisateur

BOGUES

Aucun connu.

DIAGNOSTICS

Espérons qu'ils sont explicites.

HISTORIQUE

La commande 'defaults' est apparue dans OpenStep et a combiné les capacités des commandes NeXTstep précédentes 'dread', 'dwrite' et 'dremove'.

La version GNUstep a été écrite en 1998.

Cette page de manuel est apparue pour la première fois dans gnustep-base 1.9.2 (mars 2004).
