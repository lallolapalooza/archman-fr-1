NOM

debugapp - Un wrapper pour openapp.

SYNTAXE

debugapp [--find] [--gdb=...] application [arguments...]

DESCRIPTION

debugapp est un outil qui vous aide à démarrer ou à trouver des applications par nom en mode débogage. Il agit comme un wrapper autour de openapp, et appelle openapp avec l'option --debug; nous recommandons d'utiliser openapp directement.

Par défaut, gdb est utilisé comme débogueur, mais cela peut être modifié avec l'option --gdb= ou via la variable d'environnement GDB.

Les arguments sont les arguments passés à l'application.

Voir la page de manuel openapp (1) pour une description complète.

VOIR AUSSI

openapp(1)

HISTORIQUE

Le travail sur debugapp a commencé en octobre 1997 par Ovidiu Predescu <ovidiu@net-community.com>. En octobre 2006, Nicola Pero <nicola.pero@meta-innovation.com> l'a fusionné avec openapp.
