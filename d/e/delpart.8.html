DELPART(8) Administration système DELPART(8)

NOM

delpart - demander au noyau d'oublier une partition

SYNTAXE

delpart périphérique partition

DESCRIPTION

delpart demande au noyau Linux d'oublier la partition spécifiée (un nombre) sur le périphérique spécifié. La commande est un simple wrapper autour de l'appel système « del partition ».

Cette commande ne manipule pas les partitions sur un périphérique bloc.

OPTIONS

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

VOIR AUSSI

addpart(8), fdisk(8), parted(8), partprobe(8), partx(8)

SIGNALEZ LES BOGUES

Pour les rapports de bogues, utilisez le suivi des problèmes https://github.com/util-linux/util-linux/issues.

DISPONIBILITÉ

La commande delpart fait partie du paquet util-linux qui peut être téléchargé depuis le Linux Kernel Archive https://www.kernel.org/pub/linux/utils/util-linux/.
