NOM

deb-postrm - script du mainteneur post-désinstallation du paquet

SYNTAXE

DEBIAN/postrm

DESCRIPTION

Un paquet peut effectuer plusieurs actions post-désinstallation via des scripts de maintenance, en incluant un fichier exécutable postrm dans son archive de contrôle (c'est-à-dire DEBIAN/postrm lors de la création du paquet).

Le script peut être appelé de différentes manières :

postrm remove
Après que le paquet a été désinstallé.
postrm purge
Après que le paquet a été purgé.
old-postrm upgrade nouvelle-version
Après que le paquet a été mis à niveau.
new-postrm failed-upgrade ancienne-version nouvelle-version
Si l'appel upgrade ci-dessus échoue.

La nouvelle-version est passée uniquement depuis dpkg 1.18.5.

postrm disappear paquet-remplaçant version-remplaçant
Après que tous les fichiers du paquet ont été remplacés.
new-postrm abort-install
Si preinst échoue pendant install.
new-postrm abort-install ancienne-version nouvelle-version
Si preinst échoue pendant install pour une mise à niveau d'un paquet supprimé.

La nouvelle-version est passée uniquement depuis dpkg 1.18.5.

new-postrm abort-upgrade ancienne-version nouvelle-version
Si preinst échoue pendant upgrade.

La nouvelle-version est passée uniquement depuis dpkg 1.18.5.
