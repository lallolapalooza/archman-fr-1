Device::Gsm::Pdu(3) Documentation Perl fournie par l'utilisateur Device::Gsm::Pdu(3)

NOM

Device::Gsm::Pdu - bibliothèque pour gérer les données encodées en PDU pour la messagerie GSM

AVERTISSEMENT

Ceci est un logiciel en version C<BETA>, nécessite encore des tests approfondis et
la prise en charge des commandes GSM personnalisées, alors utilisez-le à vos
propres risques, et sans C<AUCUNE> garantie ! Amusez-vous bien.

NOTICE

Ce module est destiné à être utilisé en interne par la classe C<Device::Gsm>,
donc vous ne voudrez probablement pas l'utiliser directement.

SYNOPSIS

use Device::Gsm::Pdu;
# DA est l'adresse de destination
$DA = Device::Gsm::Pdu::encode_address('+39347101010');
$number = Device::Gsm::Pdu::decode_address( $DA );
# Encoder du texte 7 bits pour envoyer des messages
$text = Device::Gsm::Pdu::encode_text7('bonjour');

DESCRIPTION

"Device::Gsm::Pdu" module inclut quelques fonctions de base pour traiter les SMS en mode PDU, telles que l'encodage des adresses GSM (numéros de téléphone) et, pour l'instant uniquement, le texte en 7 bits.

FONCTIONS

decode_address( pdu_encoded_address )

Prend une adresse encodée en PDU et la décode en un numéro de mobile lisible par l'homme. Si le type de numéro est international, le résultat sera précédé d'un signe `+'

Clairement, c'est une fonction prévue pour un usage interne.

Exemple

print Device::Gsm::Pdu::decode_address( '0B919343171010F0' );
# affiche `+39347101010';

encode_address( mobile_number )

Prend un numéro de mobile et l'encode en tant qu'adresse de destination (DA). S'il commence par un `+', comme dans `+39328101010', il est traité comme un numéro international.

Exemple

print Device::Gsm::Pdu::encode_address( '+39347101010' );
# affiche `0B919343171010F0'

encode_text7( text_string )

Encode une chaîne de caractères ASCII en format PDU 7 bits, incluant un octet d'en-tête qui indique la longueur en septets. C'est le seul mode 100% supporté pour encoder du texte.

Exemple

print Device::Gsm::Pdu::encode_text7( 'bonjourbonjour' );
# affiche `0AE832...'

pdu_to_latin1($pdu)

Convertit une PDU (sans l'octet de longueur initial) en une chaîne latin1.

Exemple

my $pdu = 'CAFA9C0E0ABBDF7474590E8296E56C103A3C5E97E5';
print Device::Gsm::Pdu::pdu_to_latin1($pdu);
# affiche `Juste un autre hacker Perl'

latin1_to_pdu($text)

Convertit une chaîne de texte en encodage latin1 (ISO-8859-1) en une chaîne PDU.

Exemple

my $text = "Juste un autre hacker Perl";
print Device::Gsm::Pdu::latin1_to_pdu($text);
# affiche `CAFA9C0E0ABBDF7474590E8296E56C103A3C5E97E5'
