Devel::Cover::Test(3) Documentation Perl Contribuée par l'Utilisateur Devel::Cover::Test(3)

NOM

Devel::Cover::Test - Module interne pour les tests

VERSION

version 1.51

MÉTHODES

new

my $test = Devel::Cover::Test->new($test, criteria => $string)

Constructeur.

"criteria" parameter (optionnel, par défaut "statement branch condition subroutine") est une liste de jetons séparés par des espaces. Les jetons supportés sont "statement", "branch", "condition", "subroutine" et "pod".

D'autres paramètres optionnels sont supportés. Voir la sous-routine "get_params".

shell_quote

my $quoted_item = shell_quote($item)

Retourne un élément correctement échappé pour gérer les espaces embarqués.

perl

my $perl = $self->perl

Retourne le chemin absolu vers l'interpréteur Perl avec les options -I appropriées (par rapport à blib).

test_command

my $command = $self->test_command

Retourne la commande de test, composée de :

chemin absolu vers l'interpréteur Perl
Devel::Cover option -M (si applicable)
fichier de test
paramètres du fichier de test (si applicable)

cover_command

my $command = $self->cover_command

Retourne la commande de test, composée de :

chemin absolu vers l'interpréteur Perl
chemin absolu vers le script cover
paramètres de cover

test_file

my $file = $self->test_file

Retourne le chemin absolu vers le fichier de test.

test_file_parameters

my $parameters = $self->test_file_parameters

Accesseur à la propriété test_file_parameters.

get_params

Remplit les clés "criteria", "select", "test_parameters", "db_name", "cover_db", "cover_parameters" et "skip" en utilisant le "test_file" s'il est disponible, sinon définit la valeur par défaut.

cover_gold

my ($base, $v) = $self->cover_gold;

Retourne le chemin absolu de la base du fichier doré et le numéro de version du suffixe.

$base provient du nom du test et $v sera $] à partir de la première version de Perl pour laquelle les résultats dorés doivent être identiques à ceux de la version actuelle $]

$v sera remplacé si les versions des bibliothèques installées le dictent ; par exemple, si Math::BigInt est à la version > 1.999806, alors la version de Perl sera remplacée comme s'il s'agissait de 5.26.

run_command

$self->run_command($command)

Exécute la commande, très probablement obtenue de la sous-routine "test_command".
