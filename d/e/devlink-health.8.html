DESCRIPTIO

N

devlink health show - Affiche l'état et la configuration de tous les reporters pris en

charge.

Affiche des informations sur les reporters enregistrés sur les périphériques et les ports

devlink.

DEV - spécifie le périphérique devlink.
DEV/PORT_INDEX - spécifie le port

devlink.

REPORTER - spécifie le nom du reporter enregistré s

ur le périphérique ou
le port devlink spécifié.

devlink health recover - Initie une opération de récupération sur un

reporter.

Cette action effectue une récupération et incrémente le compteur de récupérations en cas de

succès.

DEV - spécifie le périphérique devlink.
DEV/PORT_INDEX - spécifie le port

devlink.

REPORTER - spécifie le nom du reporter enregistré s

ur le périphérique ou
le port devlink spécifié.

devlink health diagnose - Récupère les données de diagnostic d'un

reporter.

DEV - spécifie le périphérique devlink.
DEV/PORT_INDEX - spécifie le port

devlink.

REPORTER - spécifie le nom du reporter enregistré s

ur le périphérique ou
le port devlink spécifié.

devlink health test - Déclenche un événement de test sur un

reporter.

DEV - spécifie le périphérique

devlink.

REPORTER - spécifie le nom du reporter en

registré sur le p
ériphérique devlink.

devlink health dump show - Affiche le dernier dump

enregistré.

devlink health enregistre un seul dump par reporter. Si un dump

n'est

pas déjà stocké par Devlink, cette commande en générera un

nouveau.

Le dump peut être généré soit automatiquement

lorsqu'un

reporter signale une erreur, soit manuellement à la demande de

l'utilisateur.

DEV - spécifie le périphérique devlink.
DEV/PORT_INDEX - spécifie le port

devlink.

REPORTER - spécifie le nom du reporter enregistré s

ur le périphérique ou
le port devlink spécifié.

devlink health dump clear - Supprime le dump

enregistré.

La suppression du dump enregistré permet la génération d'un nouveau dump lors

de

la prochaine commande "devlink health dump

show".

DEV - spécifie le périphérique devlink.
DEV/PORT_INDEX - spécifie le port

devlink.

REPORTER - spécifie le nom du reporter enregistré s

ur le périphérique ou
le port devlink spécifié.

devlink health set - Configure le reporter de

santé.

Veuillez noter que certains paramètres ne sont pas pris en charge sur un reporter qui ne prend pas en charge la récupération ou la méthode de

dump.

DEV - spécifie le périphérique devlink.
DEV/PORT_INDEX - spécifie le port

devlink.

REPORTER - spécifie le nom du reporter enregistré sur le périphérique ou le port devlink

spécifié.
grace_period MSE
C
Intervalle de temps entre les récupérations automatiques
consécutives.
auto_recover { true | false
}
Indique si devlink doit exécuter une récupération automatique en cas
d'erreur.
auto_dump { true | false
}
Indique si dev
link doit exéc
uter un dump
automatique en
cas d'erreur.

EXEMPLE

S

devlink health

show
Liste l'état et la configuration des reporters disponibles sur les périphériques et les
ports.

devlink health show pci/0000:00:09.0/1 reporter

tx
Liste l'état et la configuration du reporter tx enregistré sur le port pci/0000:00:09.
0/1

devlink health recover pci/0000:00:09.0 reporter

fw_fatal
Initie la récupération sur le reporter fw_fatal enregistré sur le périphérique pci/0000:00:09.
0.

devlink health recover pci/0000:00:09.0/1 reporter

tx
Initie la récupération sur le reporter tx enregistré sur le port pci/0000:00:09.
0/1.

devlink health diagnose pci/0000:00:09.0 reporter

fw
Liste les données de diagnostic sur le périphérique et le reporter
spécifiés.

devlink health dump show pci/0000:00:09.0/1 reporter

tx
Affiche le dernier dump enregistré sur le port et le reporter
spécifiés.

devlink health dump clear pci/0000:00:09.0/1 reporter

tx
Supprime le dump enregistré sur le port et le reporter
spécifiés.

devlink health set pci/0000:00:09.0 reporter fw_fatal grace_period

3500
Définit l'intervalle de temps entre les récupérations automatiques à un minimum de 3500 msec sur le périphérique et le reporter
spécifiés.

devlink health set pci/0000:00:09.0/1 reporter tx grace_period

3500
Définit l'intervalle de temps entre les récupérations automatiques à un minimum de 3500 msec sur le port et le reporter
spécifiés.

devlink health set pci/0000:00:09.0 reporter fw_fatal auto_recover

false
Désactive la récupération au
tomatique sur le périphérique
et le reporter spécifiés.
