NOM

desmume - émulateur Nintendo DS

SYNOPSIS

desmume [options] fichiers...

DESCRIPTION

Cette page de manuel documente brièvement le programme desmume

desmume est un émulateur Nintendo DS exécutant des démos homebrew et des jeux commerciaux.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

--charger-slot=NUM
Charge une sauvegarde de l'emplacement NUM
--opengl-2d
Active l'utilisation d'OpenGL pour le rendu de l'écran
--conversion-logicielle
Utilise la conversion logicielle des couleurs lors du rendu de l'écran avec OpenGL. Peut produire des fréquences d'images meilleures ou pires selon le matériel.
--moteur-3d=MOTEUR
Sélectionne l'émulation 3D disponible :
0 = 3D désactivée
1 = rasteriseur logiciel interne de desmume (par défaut)
2 = osmesa ou opengl gtkglext (si disponible, selon les options de compilation, voir desmume --help)
--desactiver-son
Désactive l'émulation sonore
--desactiver-limiteur
Désactive le limiteur de 60 ips
--arm9gdb=NUM_PORT
Active le stub GDB ARM9 sur le port donné
--arm7gdb=NUM_PORT
Active le stub GDB ARM7 sur le port donné
--type-sauvegarde=TYPE
Sélectionne le type de sauvegarde parmi les suivants :
0 = Détection automatique
1 = EEPROM 4 Kbit
2 = EEPROM 64 Kbit
3 = EEPROM 512 Kbit
4 = FRAM 256 Kbit
5 = FLASH 2 Mbit
6 = FLASH 4 Mbit
--fwlang=LANG
Définit la langue du firmware, LANG comme suit :
0 = Japonais
1 = Anglais
2 = Français
3 = Allemand
4 = Italien
5 = Espagnol
--cflash=CHEMIN_VERS_IMAGE_DISQUE
Active l'émulation de carte flash compacte GBAMP d'image disque
-h, --aide
Affiche un résumé des options.
-v, --version
Affiche la version du programme.

ENTRÉE

Le curseur de la souris agit comme un stylet, le clic de la souris remplace le toucher du stylet.

Le clavier peut être configuré et fonctionne par défaut comme suit :

F1-F10 charge une sauvegarde de l'emplacement 1-10
Maj+F1-F10 enregistre le jeu dans l'emplacement 1-10
Les flèches (sans pavé numérique) agissent comme une croix directionnelle
z = A
x = B
a = Y
s = X
q = L
w = R
Entrée = START
Maj gauche = SELECT
Retour arrière = LID

Desmume accepte les événements de joystick, qui peuvent être configurés par l'utilisateur.
