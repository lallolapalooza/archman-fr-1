Devel::PatchPerl(3) Documentation Perl fournie par l'utilisateur Devel::PatchPerl(3)

NOM

Devel::PatchPerl - Patch le code source de Perl à la manière de buildperl.pl de Devel::PPPort

VERSION

version 2.14

SYNOPSIS

use strict;
use warnings;
use Devel::PatchPerl;
Devel::PatchPerl->patch_source( '5.6.1', '/chemin/vers/source/perl/non/décompressé/perl-5.6.1' );

DESCRIPTION

Devel::PatchPerl est une modularisation du code de patching contenu dans le script "buildperl.pl" de Devel::PPPort.

Il ne construit pas de Perl, il fournit simplement une interface aux fonctionnalités de patching de source.

FONCTION

"patch_source"
Prend deux paramètres, une version de "perl" et le chemin vers la source Perl non décompressée pour cette version. Il s'arrête en cas d'erreur.

Si vous ne fournissez pas de version de "perl", il tentera de déterminer automatiquement la version de "perl" à partir du chemin spécifié.

Si vous ne fournissez pas le chemin vers la source Perl non décompressée, il supposera que c'est le répertoire courant.

"determine_version"
Prend un paramètre optionnel, le chemin vers la source Perl non décompressée. Il renvoie la version de Perl du code source à l'emplacement donné. Il renvoie undef en cas d'erreur.

Si vous ne fournissez pas le chemin vers la source Perl non décompressée, il supposera que c'est le répertoire courant.

SYSTÈME DE PLUGINS

Voir Devel::PatchPerl::Plugin pour les détails du système de plugins de Devel::PatchPerl.

PATCHLEVEL

Devel::PatchPerl mettra normalement à jour le fichier "patchlevel.h" dans l'arborescence source de Perl pour indiquer que des patches locaux ont été appliqués. Ce comportement est annulé s'il est détecté que le script opère dans un dépôt Git. Pour outrepasser cela et mettre à jour "patchlevel.h" dans un dépôt Git, définissez la variable d'environnement "PERL5_PATCHPERL_PATCHLEVEL" à une valeur vraie.

Alternativement, appelez "patchperl" avec l'option "--patchlevel".

AVERTISSEMENT

Devel::PatchPerl est destiné uniquement à faciliter la "construction" de Perl, pas la "vérification" de Perl. Cela signifie qu'il ne patchera pas les tests échoués dans la suite de tests de Perl.
