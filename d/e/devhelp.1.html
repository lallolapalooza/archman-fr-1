NOM

devhelp - Un navigateur de documentation d'API

SYNTAXE

devhelp [OPTIONS]

DESCRIPTION

Devhelp est un navigateur de documentation d'API pour GNOME.

OPTIONS

-s, --search=MOT_CLÉ
Recherche un mot-clé (fonction, symbole...).
-a, --search-assistant=MOT_CLÉ
Recherche et affiche tout résultat dans la fenêtre de l'assistant.

EXEMPLES

Pour exécuter ce programme de manière standard, tapez :

devhelp

Si vous souhaitez rechercher une fonction, tapez :

devhelp -s chaîne_de_recherche
