dehumanize_number(3bsd)

Paquet: libbsd

Licences: custom

humanize_number(3bsd) 3bsd humanize_number(3bsd)

NOM

dehumanize_number, humanize_number — formater un nombre dans une forme lisible par l'humain et inversement

BIBLIOTHÈQUE

bibliothèque « libbsd »

SYNOPSIS

#include <stdlib.h> (Voir libbsd(7) pour l'utilisation de l'inclusion.)
int
dehumanize_number(const char *str, int64_t *result);

int
humanize_number(char *buf, size_t len, int64_t number, const char *suffix, int scale, int flags);

DESCRIPTION

La humanize_number() formate la quantité signée sur 64 bits donnée dans number dans buffer. Un espace puis suffix sont ajoutés à la fin. buffer doit faire au moins len octets de long.

Si le nombre formaté (y compris suffix) serait trop long pour tenir dans buffer, divisez alors number par 1024 jusqu'à ce qu'il tienne. Dans ce cas, préfixez suffix avec le designateur SI approprié.

Les préfixes sont :

Préfixe Description Multiplicateur
k kilo 1024
M méga 1048576
G giga 1073741824
T téra 1099511627776
P péta 1125899906842624
E exa 1152921504606846976

len doit faire au moins 4 plus la longueur de suffix, afin de garantir qu'un résultat utile soit généré dans buffer. Pour utiliser un préfixe spécifique, spécifiez-le comme scale (Multiplicateur = 1024 ^ scale). Cela ne peut pas être combiné avec aucun des scale flags ci-dessous.

Les drapeaux suivants peuvent être passés dans scale:

HN_AUTOSCALE
Formater le tampon en utilisant le plus petit multiplicateur possible.
HN_GETSCALE
Retourner le numéro d'index du préfixe (le nombre de fois number doit être divisé pour tenir) au lieu de le formater dans le tampon.

Les drapeaux suivants peuvent être passés dans flags:

HN_DECIMAL
Si le résultat final est inférieur à 10, l'afficher avec un seul chiffre.
HN_NOSPACE
Ne pas mettre d'espace entre number et le préfixe.
HN_B
Utiliser 'B' (octets) comme préfixe si le résultat original n'a pas de préfixe.
HN_DIVISOR_1000
Diviser number par 1000 au lieu de 1024.

La dehumanize_number() analyse la chaîne représentant une valeur entière donnée dans str et stocke la valeur numérique dans l'entier pointé par result. La chaîne fournie peut contenir l'un des suffixes, qui sera interprété et utilisé pour mettre à l'échelle sa valeur numérique correspondante.

VALEURS RETOURNÉES

humanize_number() retourne le nombre de caractères stockés dans buffer (à l'exclusion du NUL terminant) en cas de succès, ou -1 en cas d'échec. Si HN_GETSCALE est spécifié, le numéro d'index du préfixe sera retourné à la place.

dehumanize_number() retourne 0 si la chaîne a été analysée correctement. Un -1 est retourné pour indiquer un échec et un code d'erreur est stocké dans errno.

ERREURS

dehumanize_number() échouera et aucun nombre ne sera stocké dans result si :

[EINVAL]
La chaîne dans str était vide ou portait un suffixe inconnu.
[ERANGE]
La chaîne dans str représentait un nombre qui ne tient pas dans result.
