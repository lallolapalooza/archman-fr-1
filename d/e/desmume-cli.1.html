NOM

desmume-cli - Émulateur Nintendo DS

SYNTAXE

desmume-cli [options] fichiers...

DESCRIPTION

Cette page de manuel documente brièvement le programme desmume-cli

desmume est un émulateur Nintendo DS exécutant des démos homebrew et des jeux commerciaux.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

--load-slot=NUM
Charge la sauvegarde de l'emplacement NUM
--disable-sound
Désactive l'émulation sonore
--disable-limiter
Désactive le limiteur de 60 images par seconde
--3d-engine=ENGINE
Sélectionne l'émulation 3D disponible :
0 = 3D désactivé
1 = Rasterizer logiciel interne de desmume (par défaut)
--opengl-2d
Active l'utilisation d'OpenGL pour le rendu de l'écran
--soft-convert
Utilise la conversion de couleurs logicielle pendant le rendu de l'écran OpenGL. Peut produire des taux de rafraîchissement meilleurs ou moins bons selon le matériel.
--arm9gdb=PORT_NUM
Active le stub GDB ARM9 sur le port donné
--arm7gdb=PORT_NUM
Active le stub GDB ARM7 sur le port donné
--save-type=TYPE
Sélectionne le type de sauvegarde parmi les suivants :
0 = Détection automatique
1 = EEPROM 4kbit
2 = EEPROM 64kbit
3 = EEPROM 512kbit
4 = FRAM 256kbit
5 = FLASH 2mbit
6 = FLASH 4mbit
--fwlang=LANG
Définit la langue dans le firmware, LANG comme suit :
0 = Japonais
1 = Anglais
2 = Français
3 = Allemand
4 = Italien
5 = Espagnol
--cflash=PATH_TO_DISK_IMAGE
Active l'émulation de carte compacte flash GBAMP d'image disque
--help
Affiche le résumé des options.
--version
Affiche la version du programme.

Certaines options peuvent être indisponibles, selon la configuration à la compilation, par exemple les stubs gdb et opengl.

ENTRÉE

Le curseur de la souris agit comme un stylet, le clic de souris remplace le toucher du stylet.

Le clavier est configuré comme suit :

F1-F10 charge la sauvegarde de l'emplacement 1-10
Maj+F1-F10 sauvegarde le jeu dans l'emplacement 1-10
Les flèches (hors pavé numérique) agissent comme une croix directionnelle
z = A
x = B
a = Y
s = X
q = L
w = R
Entrée = START
Maj gauche = SELECT
Retour arrière = LID
