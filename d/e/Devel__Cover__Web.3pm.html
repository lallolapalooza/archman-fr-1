Devel::Cover::Web(3) Documentation Perl fournie par l'utilisateur Devel::Cover::Web(3)

NOM

Devel::Cover::Web - Fichiers pour JavaScript ou CSS

VERSION

version 1.51

SYNOPSIS

use Devel::Cover::Web "write_file";
write_file $directory, $file;
write_file $directory, "all";
write_file $directory, "js";
write_file $directory, "css";

DESCRIPTION

Ce module permet d'écrire des fichiers JavaScript et CSS dans un répertoire spécifié.

SOUS PROGRAMMES

write_file($directory, $file)

Produit le fichier spécifié dans le répertoire spécifié.
