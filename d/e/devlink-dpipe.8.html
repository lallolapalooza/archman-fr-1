DEVLINK-DPIPE(8) Linux DEVLINK-DPIPE(8)

NOM

devlink-dpipe - visualisation du pipeline de données devlink

SYNTAXE


devlink [ OPTIONS ] dpipe { table | header } { COMMANDE | help }

OPTIONS := { -V[ersion] }

devlink dpipe table show DEV [ name NOM_TABLE ]

devlink dpipe table set DEV name NOM_TABLE

devlink dpipe table dump DEV name NOM_TABLE

devlink dpipe header show DEV

devlink dpipe help

DESCRIPTION

devlink dpipe table show - afficher les attributs de table dpipe devlink

name NOM_TABLE
Spécifie la table sur laquelle opérer.

devlink dpipe table set - définir les attributs de table dpipe devlink

name NOM_TABLE
Spécifie la table sur laquelle opérer.

devlink dpipe table dump - vider les entrées de table dpipe devlink

name NOM_TABLE
Spécifie la table sur laquelle opérer.

devlink dpipe header show - afficher les attributs d'en-tête dpipe devlink

name NOM_TABLE
Spécifie la table sur laquelle opérer.

EXEMPLES

devlink dpipe table show pci/0000:01:00.0

Affiche toutes les tables dpipe sur le périphérique devlink spécifié.

devlink dpipe table show pci/0000:01:00.0 name mlxsw_erif

Affiche la table dpipe mlxsw_erif sur le périphérique devlink spécifié.

devlink dpipe table set pci/0000:01:00.0 name mlxsw_erif counters_enabled true

Active les compteurs sur la table mlxsw_erif.

devlink dpipe table dump pci/0000:01:00.0 name mlxsw_erif

Vider le contenu de la table mlxsw_erif.

devlink dpipe header show pci/0000:01:00.0

Affiche toutes les en-têtes dpipe sur le périphérique devlink spécifié.
