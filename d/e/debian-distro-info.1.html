DEBIAN-DISTRO-INFO(1) Manuel des commandes générales DEBIAN-DISTRO-INFO(1)

NOM

debian-distro-info - fournit des informations sur les distributions Debian

SYNOPSIS

debian-distro-info [OPTIONS]

OPTIONS

--date=DATE
date pour le calcul de la version (par défaut : epoch de la variable d'environnement SOURCE_DATE_EPOCH si définie, sinon aujourd'hui)
-h, --help
affiche le message d'aide et quitte
--alias=DIST
affiche l'alias (oldstable, stable, testing, unstable) par rapport au nom de code de la distribution passé en argument. Seuls les noms de code de distribution composés de lettres minuscules ASCII sont acceptés, et si la distribution n'est pas qualifiée d'oldstable, stable, testing ou unstable, le même nom de code passé en argument est retourné.
-a, --all
liste toutes les versions connues
-y[MILESTONE], --days[=MILESTONE]
affiche le nombre de jours jusqu'à ce que la version spécifiée atteigne le jalon spécifié. MILESTONE peut être l'un des created, release, ou eol. Si aucun jalon n'est spécifié, suppose release. Pour les options qui retournent une liste, affiche la sortie normale suivie d'un espace blanc et du nombre de jours jusqu'au jalon spécifié. Si le jalon ne peut pas être calculé, la chaîne '(unknown)' est affichée. Sauf si l'une des options -c, -f ou -r est spécifiée, seul le nombre de jours sera affiché.
-d, --devel
dernière version de développement
-o, --old
dernière version ancienne (stable)
--series=SERIES
série pour laquelle calculer la version
-s, --stable
dernière version stable
--supported
liste de toutes les versions prises en charge, y compris les versions de développement
-t, --testing
dernière version de test
--unsupported
liste de toutes les versions stables non prises en charge
-c, --codename
affiche le nom de code (par défaut)
-r, --release
affiche le numéro de version
-f, --fullname
affiche le nom complet
