Device::Modem::Log::Syslog(3) Documentation Perl fournie par l'utilisateur Device::Modem::Log::Syslog(3)

NOM

Device::Modem::Log::Syslog - Plugin de journalisation Syslog pour la classe Device::Modem

SYNOPIS

use Device::Modem;
my $box = Device::Modem->( log => 'syslog', ... );
...

DESCRIPTION

Exemple de classe de journalisation pour Device::Modem qui enregistre toute l'activité du modem, les commandes, ... dans syslog

Elle est chargée automatiquement au démarrage de Device::Modem, uniquement si vous spécifiez la valeur "syslog" pour le paramètre "log".

Si vous n'avez pas le module additionnel Sys::Syslog installé, vous ne pourrez pas utiliser ce plugin de journalisation, et il est préférable de laisser la journalisation par défaut (vers un fichier texte).

EXIGENCES

"Sys::Syslog"
