NOM

Devel::CheckCompiler - Vérifie la disponibilité du compilateur

SYNTAXE

use Devel::CheckCompiler;
check_c99_or_exit();

DESCRIPTION

Devel::CheckCompiler est un vérificateur de disponibilité du compilateur.

FONCTIONS

check_c99()
Retourne vrai si le système actuel dispose d'un compilateur C99 fonctionnel, faux sinon.
check_c99_or_exit()
Vérifie si le système actuel dispose d'un compilateur C99 fonctionnel, sinon il se termine avec le code 0.
"check_compile($src: Str, %options)"
Compile $src en tant que code C. Retourne 1 s'il est disponible, 0 sinon.

Options possibles :

executable :Bool = false
Vérifie si la génération d'un exécutable est possible si ce paramètre est vrai.
extra_linker_flags : Str | ArrayRef[Str]
Tous les drapeaux supplémentaires que vous souhaitez passer à l'éditeur de liens. Cette option n'est utilisée que lorsque l'option "executable" est spécifiée.
