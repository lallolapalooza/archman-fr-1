NOM

Devel::PatchPerl::Hints - fichiers de remplacement pour les 'hints'

VERSION

version 2.14

SYNOPSIS

use Devel::PatchPerl::Hints;
if ( my $content = Devel::PatchPerl::Hints->hint_file() ) {
  chmod 0644, 'hints/netbsd.sh' or die "$!";
  open my $hints, '>', 'hints/netbsd.sh' or die "$!";
  print $hints $content;
  close $hints;
}
# Obtenir une liste des OS pour lesquels nous avons des hints
my @os = Devel::PatchPerl::Hints->hints();

DESCRIPTION

Parfois, il y a un problème avec les fichiers "hints" de Perl pour un port Perl particulier. Ce module fournit des fichiers "hints" corrigés encodés en utilisant "MIME::Base64".

FONCTION

La fonction est exportée, mais doit être implicitement importée dans le paquet demandeur.

use Devel::PatchPerl::Hints qw[hint_file];

Elle peut également être appelée comme une méthode de classe :

use Devel::PatchPerl::Hints;
my $content = Devel::PatchPerl::Hints->hint_file();
"hint_file"
Prend un argument optionnel qui est le nom de l'OS (tel que retourné par $^O). Par défaut, il utilisera $^O.

Dans un contexte scalaire, retournera le contenu décodé du fichier "hints" adapté à une écriture directe sur un descripteur de fichier, ou une liste vide si aucun fichier "hints" applicable n'existe pour l'OS donné ou dérivé.

Si appelée dans un contexte de liste, retournera une liste dont le premier élément sera le nom du fichier "hints" qui devra être modifié, et le second élément sera une chaîne avec le contenu décodé du fichier "hints" adapté à une écriture directe sur un descripteur de fichier. Sinon, une liste vide sera retournée.

"hints"
Ne prend aucun argument, retourne une liste des noms d'OS pour lesquels il existe des fichiers "hints".
