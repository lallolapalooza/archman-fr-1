NOM

devlink-lc - configuration de la carte de ligne devlink

SYNTAXE


devlink [ OPTIONS ] lc { COMMANDE | help }

OPTIONS := { -V[ersion] }

devlink lc set DEV lc INDEX_LC [ type { TYPE_LC | notype } ]

devlink lc show [ DEV [ lc INDEX_LC ] ]

devlink lc help

DESCRIPTION

devlink lc set - modifier les attributs de la carte de ligne

DEV
Spécifie le périphérique devlink à utiliser.


Format :
NOM_BUS/ADRESSE_BUS

lc INDEX_LC
Spécifie l'index de l'emplacement de la carte de ligne à définir.
type {
TYPE_LC | notype } Type de carte de ligne à provisionner. Chaque pilote fournit une liste de types de cartes de ligne supportés, qui est affichée dans la sortie de la commande devlink lc show.

devlink lc show - afficher les attributs de la carte de ligne

DEV
Spécifie le périphérique devlink à utiliser. Si cet argument et l'argument lc sont omis, toutes les cartes de ligne de tous les périphériques sont listées.
lc INDEX_LC
Spécifie l'index de l'emplacement de la carte de ligne à afficher.

EXEMPLES

devlink lc show

Affiche l'état de toutes les cartes de ligne sur le système.

devlink lc show pci/0000:01:00.0 lc 1

Affiche l'état de la carte de ligne avec l'index 1.

devlink lc set pci/0000:01:00.0 lc 1 type 16x100G

Définit le type de la carte de ligne spécifiée sur le type 16x100G.

devlink lc set pci/0000:01:00.0 lc 1 notype

Supprime le provisionnement sur une carte de ligne.
