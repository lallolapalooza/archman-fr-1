DETOX.TBL(5) Manuel des formats de fichiers DETOX.TBL(5)

NOM

detox.tbl — table de traduction pour detox(1)

VUE D'ENSEMBLE

detox permet de configurer le fonctionnement des filtres sécurisé, ISO-8859-1 et UTF-8 (Unicode). Grâce à des tables de traduction basées sur du texte, il est possible d'ajuster l'interprétation de ces jeux de caractères.

SYNTAXE

Le format des tables de traduction est simple. Il y a deux niveaux : un contenant les métadonnées et un contenant les traductions réelles.

défaut _
Le défaut spécifie la traduction par défaut pour un caractère. Un défaut vide ou inexistant indique que tout caractère inconnu doit passer au filtre suivant. De cette manière, il est possible d'enchaîner plusieurs tables de traduction en séquence.
début
Indique le début d'une liste de valeurs dans la table de traduction.
début lang
Indique le début d'une liste de valeurs spécifique à une langue dans la table de traduction.
fin
Indique la fin d'une liste de valeurs dans la table de traduction.
traduction de valeur
La valeur peut être spécifiée en décimal (1), hexadécimal (0x01) ou octal (01). Les mêmes règles que celles qui s'appliquent à sscanf s'appliquent ici.

La traduction peut être une chaîne ou une chaîne entre guillemets, avec des guillemets simples ou doubles.

EXEMPLES

L'exemple suivant montre une partie d'une table safe, avec seulement quelques remplacements de caractères spécifiés.

#
# Ceci est un exemple simple de table "safe". Elle ne traduit que 4 caractères.
#
# Le défaut est commenté, donc tout caractère qui n'est pas dans cette table sera
# ignoré.
#

# default   _

#
# Ceci est le bloc de remplacement principal. Chaque ligne spécifie un caractère et une
# chaîne pour le remplacer.
#

start
0x09	_tab_		# les commentaires fonctionnent aussi sur les lignes
0x24	_dollar_	# $$$
0x26	_and_		# ampersand
end

#
# Commence un bloc de traduction optionnel et spécifique à une langue. detox lira
# votre locale et chargera le bloc si le mot après start correspond à la partie langue
# de votre locale.
#
# Dans l'exemple ici, le caractère $ sera remplacé par "_money_" si
# l'utilisateur travaille en anglais. Si l'utilisateur utilise une autre langue, $
# sera remplacé par la valeur configurée dans le bloc précédent, "_dollar_".
#

start en
0x24	_money_		# argent argent
end

# EOF

Vous pourriez ensuite activer cette table dans votre ~/.detoxrc, en conjonction avec d'autres filtres.

# Exemple de detoxrc

sequence default {
	safe {
		filename "/home/MONNOMUTILISATEUR/.local/share/detox/safe.tbl";
	};
	safe;
	wipeup;
};

# EOF

Lorsque detox est exécuté, il exécutera d'abord le filtre personnalisé safe, puis le filtre safe par défaut, et enfin le filtre wipeup. Voir detoxrc(5) pour plus de détails sur les différents types de filtres.
