NOM

devtools - Outils de développement pour la distribution Arch Linux

DESCRIPTION

Devtools contient des outils pour la maintenance des paquets sous Arch Linux. Il est livré avec une interface de ligne de commande unifiée appelée pkgctl qui permet d'interagir facilement avec tous les différents outils que cette collection fournit.

La boîte à outils comprend des outils pour construire des paquets dans un chroot propre (mkarchroot, archbuild, ...), des outils liés à la création de paquets (sogrep, diffpkg, lddd) et des outils de gestion de dépôts tels que (pkgrepo).

PROGRAMMES

La liste ci-dessous donne un bref aperçu ; consultez la documentation correspondante pour les détails.

pkgctl(1) Interface en ligne de commande unifiée pour devtools

archbuild(1) Construit un paquet Arch Linux dans un chroot propre

arch-nspawn(1) Exécute une commande ou un système d'exploitation dans un conteneur léger basé sur un namespace

checkpkg(1) Compare le paquet de construction actuel avec la version du dépôt

diffpkg(1) Compare les fichiers de paquets en utilisant différents modes

export-pkgbuild-keys(1) Exporte les clés de signature de source valides d'un PKGBUILD

find-libdeps(1) Trouve les dépendances de nom de son pour un paquet

find-libprovides(1) Trouve les noms de son qui sont fournis par un paquet

lddd(1) Trouve les liens de librairie cassés sur votre système

mkarchroot(1) Crée un chroot Arch à un emplacement spécifié avec un ensemble de paquets spécifié

makechrootpkg(1) Construit un PKGBUILD dans un environnement chroot donné

makerepropkg(1) Reconstruit un paquet pour voir s'il est reproductible

offload-build(1) Construit un PKGBUILD sur un serveur distant en utilisant makechrootpkg

sogrep(1) Trouve les paquets qui dépendent d'une librairie partagée donnée
