NOM

derb - désassemble un paquet de ressources

SYNOPSIS

derb [ -h, -?, --help ] [ -V, --version ] [ -v, --verbose ] [ -e, --encoding encodage ] [ --bom ] [ -t, --truncate [ taille ] ] [ -s, --sourcedir source ] [ -d, --destdir destination ] [ -i, --icudatadir répertoire ] [ -c, --to-stdout ] paquet ...

DESCRIPTION

derb lit les fichiers de paquets de ressources compilés paquet passés en ligne de commande et les réécrit sous forme de texte. Les fichiers texte résultants ont une extension .txt tandis que les fichiers sources de paquets de ressources compilés ont généralement une extension .res .

Il est d'usage de nommer les paquets de ressources par leur nom de locale, c'est-à-dire d'utiliser un identifiant de locale pour le nom de fichier du paquet , par exemple ja_JP.res pour les données japonaises (Japon), ou root.res pour le paquet racine. C'est particulièrement important pour derb car le nom de locale n'est pas directement accessible depuis le paquet de ressources compilé, et il faut savoir quelle locale demander lors de l'ouverture du paquet. derb produira un fichier dont le nom de base est le nom de base du fichier de ressources compilé lui-même. Si l'option --to-stdout, -c est utilisée, le texte sera écrit sur la sortie standard.

OPTIONS

-h, -?, --help
Affiche une aide sur l'utilisation et se termine.
-V, --version
Affiche la version de derb et se termine.
-v, --verbose
Affiche des messages informatifs supplémentaires pendant l'exécution.
-A, --suppressAliases
Ne suit pas les alias lors de la production de la sortie.
-e, --encoding encodage
Définit l'encodage utilisé pour écrire les fichiers de sortie sur encodage. L'encodage par défaut est la page de codes invariante (sous-ensemble d'ASCII ou d'EBCDIC) du système (voir la section CARACTÈRES INVARIANTS). Le choix de l' encodage n'affecte pas les données, seulement leur représentation. Les caractères qui ne peuvent pas être représentés dans l' encodage seront représentés à l'aide de séquences d'échappement \uhhhh .
--bom
Écrit une marque d'ordre des octets (BOM) au début du fichier.
-l, --locale locale
Définit la locale du paquet de ressources, qui est utilisée à la fois dans le texte généré et comme nom de base du fichier de sortie.
-t, --truncate [ taille ]
Tronque les ressources individuelles (chaînes ou données binaires) à taille octets. La valeur par défaut si taille n'est pas spécifiée est 80 octets.
-s, --sourcedir source
Définit le répertoire source sur source. Le répertoire source par défaut est le répertoire courant. Si - est passé pour source, alors le paquet sera recherché dans son emplacement par défaut, spécifié par la variable d'environnement ICU_DATA (ou par défaut à l'emplacement défini lors de la compilation d'ICU si ICU_DATA n'est pas définie).
-d, --destdir destination
Définit le répertoire de destination sur destination. Le répertoire de destination par défaut est spécifié par la variable d'environnement ICU_DATA ou est l'emplacement défini lors de la compilation d'ICU si ICU_DATA n'est pas définie.
-i, --icudatadir répertoire
Recherche les fichiers de données ICU nécessaires dans répertoire. Par exemple, lors du traitement des surcharges de collation, le fichier ucadata.dat doit être localisé. Le répertoire de données ICU par défaut est spécifié par la variable d'environnement ICU_DATA.
-c, --to-stdout
Écrit le paquet désassemblé sur la sortie standard au lieu d'un fichier.

AVERTISSEMENTS

Lorsque l'option --bom est utilisée, le caractère U+FEFF est écrit dans l'encodage de destination encodage qu'il s'agisse ou non d'un format de transformation Unicode (UTF). Cette option ne devrait être utilisée qu'avec un encodage UTF, car les marques d'ordre des octets n'ont pas de sens pour les autres encodages.

CARACTÈRES INVARIANTS

L' ensemble de caractères invariants se compose de l'ensemble suivant de caractères, exprimé sous forme d'une expression rationnelle POSIX standard : [a-z]|[A-Z]|[0-9]|_| |+|-|*|/. C'est l'ensemble qui est garanti d'être disponible quelle que soit la page de codes.

ENVIRONNEMENT

ICU_DATA
Spécifie le répertoire contenant les données ICU. Par défaut : ${prefix}/share/icu/78.1/. Certains outils d'ICU dépendent de la présence de la barre oblique finale. Il est donc important de s'assurer qu'elle est présente si ICU_DATA est définie.
