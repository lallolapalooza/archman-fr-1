NOM

deluge-gtk - Interface Gtk pour un client BitTorrent

SYNTAXE

deluge-gtk [options] [fichier-torrent]

DESCRIPTION

Deluge utilise un modèle client/serveur, avec deluged comme processus démon et deluge-gtk utilisé pour lancer une interface utilisateur Gtk.

Par défaut, Deluge fonctionnera en mode Autonome où la fonctionnalité du démon sera cachée. Vous pouvez passer en mode Client léger dans la boîte de dialogue des Préférences.

OPTIONS

Options de configuration

-c chemin, --config=chemin
Définit l'emplacement du répertoire de configuration.

Options de journalisation

-l fichier, --logfile=fichier
Produit la sortie dans le fichier journal spécifié au lieu de la sortie standard.
-L niveau-journal, --loglevel=niveau-journal
Définit le niveau du journal (par défaut : error) : none, info, warning, error, debug
-q, --quiet
Définit le niveau du journal sur none, équivalent à -L none
--logrotate[=taille-max]
Active la rotation du fichier journal, avec une taille maximale optionnelle du fichier journal, par défaut : 2M (Le nombre de rotations du journal est de 5)
--profile[=fichier]
Profile avec cProfile. La sortie est envoyée à la sortie standard sauf si un nom de fichier est spécifié.

Options d'aide

-V, --version
Affiche le numéro de version du programme et quitte.
-h, --help
Affiche le message d'aide et quitte.
