NOM

decode-dimms - décode les informations trouvées dans les EEPROMs des modules mémoire

SYNOPSIS

decode-dimms [-c] [-f [-b]] [-x|-X fichier [fichiers..]]
decode-dimms -h

DESCRIPTION

L'outil decode-dimms a pour but de décoder les informations trouvées dans les EEPROMs des modules mémoire. Les données SPD sont lues soit depuis le système en cours d'exécution, soit depuis des fichiers de vidage. Dans le premier cas, l'outil nécessite qu'un module noyau soit chargé : eeprom, at24 ou ee1004 (pour la DDR4 SDRAM).

PARAMETRES

-f, --format
Affiche une belle sortie html
-b, --bodyonly
N'affiche pas l'en-tête html (utile pour le post-traitement de la sortie)
--side-by-side
Affiche tous les DIMMs côte à côte si possible
--merge-cells
Fusionne les cellules voisines avec des valeurs identiques (en sortie côte à côte uniquement, par défaut)
--no-merge-cells
Ne fusionne pas les cellules voisines avec des valeurs identiques (en sortie côte à côte uniquement)
-c, --checksum
Décode complètement même si la somme de contrôle échoue
-x
Lit les données depuis des fichiers hexdump
-X
Identique à -x sauf qu'il traite les données hexadécimales de plusieurs octets comme little endian
-h, --help
Affiche le résumé d'utilisation
