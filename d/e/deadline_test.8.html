NOM

deadline_test - Programme de test haute résolution

DESCRIPTION

Ce programme est utilisé pour tester le planificateur d'échéances (tâches SCHED_DEADLINE).

SYNTAXE

deadline_test [ -hb ] [ -c CPUSET ] [ -i INTV ] [ -p PERCENT ] [ -P PERCENT ] [ -r PRIO ] [ -s STEP ] [ -t NUM ]

OPTIONS

-b
Lier au dernier CPU. (raccourci pour -c <dernier_cpu>)
-c CPUSET
Liste de CPU séparés par des virgules ou des tirets sur lesquels exécuter les tâches d'échéance.
-h
Afficher ce menu d'aide.
-i INTV
L'échéance la plus courte pour les tâches.
-p PERCENT
Le pourcentage de bande passante à utiliser (1-90%).
-P PERCENT
Le pourcentage de temps d'exécution pour l'achèvement de l'exécution (par défaut 100%).
-r PRIO
Ajouter une tâche RT avec la priorité donnée pour stresser le système.
-s STEP
L'incrément de l'échéance pour chaque tâche en microsecondes (par défaut 500µs).
-t NUM
Le nombre de threads à exécuter en tant qu'échéance (par défaut 1).
