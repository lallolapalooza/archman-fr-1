DESCRIPTIO

N

Devel::CheckLib est un module perl qui v

érifie si une bibliothèque C partic
ulière et ses en-têtes sont disponibles.

SYNOPSI

S 
use Devel::CheckLib;
check_lib_or_exit( lib => 'jpeg', header => 'jpeglib.h' );
check_lib_or_exit( lib => [ 'iconv', 'jpeg' ] );

# ou demander le chemin vers la bibliothèque puis faire ceci :
check_lib_or_exit( lib => 'jpeg', libpath => $additional_path
)
;

PL

PRINCIPE DE

FONCTIONNEMENT

Vous passez des paramètres nommés à une fonction, en lui décrivant comment compiler et lier les

bibliothèques.

Cela fonctionne en essayant de compiler du code - dont la valeur par défaut est

: 
int main(int argc, char *argv[]) { return 0;
}

et en le liant aux bibliothèques spécifiées. Si quelque chose sort à la fin qui ressemble à un exécutable, il est exécuté, et si main() retourne 0, nous savons que cela a fonctionné. Ce petit programme est compilé une fois pour chaque bibliothèque que vous spécifiez, et (sans lier) une fois pour chaque fichier

d'en-tête.

Si vous voulez vérifier la présence de fonctions particulières dans une bibliothèque, ou même que ces fonctions retournent des résultats particuliers, alors vous pouvez passer votre propre corps de fonction pour main() comme ceci

: 
check_lib_or_exit(
    function => 'foo();if(libversion() > 5) return 0; else return 1;'
    incpath  => ...
    libpath  => ...
    lib      => ...
    header   => ...
)
;

Dans ce cas, la compilation échouera si foo() ou libversion() n'existent pas, et main() retournera la mauvaise valeur si la valeur de retour de libversion()

n'est pas celle qu
e vous voulez.
