NOM

Devel::Cover::Report::Html_Common - Code commun pour les rapporteurs HTML

VERSION

version 1.51

DESCRIPTION

Ce module fournit des fonctionnalités communes pour les rapporteurs HTML.

Fonctions

launch
Lance un navigateur pour visualiser le rapport. Les rapporteurs HTML ont juste besoin d'importer cette fonction pour activer l'option -launch pour ce type de rapport.
