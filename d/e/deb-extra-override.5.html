NOM

deb-extra-override - Fichier de substitution supplémentaire pour l'archive Debian

SYNTAXE

override

DESCRIPTION

Bien que la plupart des informations sur un paquet binaire/source se trouvent dans le fichier control/.dsc, toutes peuvent être remplacées lorsqu'il est exporté dans les fichiers Packages/Sources. Le fichier de substitution supplémentaire contient ces remplacements.

Le fichier de substitution supplémentaire a un format simple délimité par des espaces. Les commentaires sont autorisés (indiqués par un #).

paquet nom-champ valeur

paquet est le nom du paquet binaire/source.

nom-champ est le nom du champ qui est remplacé.

valeur est la valeur à mettre dans le champ. Elle peut contenir des espaces car la ligne est divisée en 3 colonnes au maximum lors de l'analyse.

Les fichiers de substitution supplémentaires utilisés pour créer les listes Packages officielles se trouvent dans le répertoire indices sur n'importe quel miroir Debian.

VOIR AUSSI

dpkg-scanpackages(1), dpkg-scansources(1), apt-ftparchive(1).
