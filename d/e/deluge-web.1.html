DELUGE-WEB(1) Manuel des commandes générales DELUGE-WEB(1)

NOM

deluge-web - une interface web pour client BitTorrent

SYNOPSIS

deluge-web [options]

DESCRIPTION

Deluge utilise un modèle client/serveur, où deluged est le processus démon et deluge-web est utilisé pour lancer une interface utilisateur basée sur le web via ajax.

Par défaut, deluge-web s'exécute en tant que démon en arrière-plan. Utilisez l'option -d pour exécuter le processus en premier plan.

Le mot de passe par défaut est deluge et sert la page web http://localhost:8112.

OPTIONS

Options de configuration

-c chemin, --config=chemin
Définit l'emplacement du répertoire de configuration.

Options Web

-i adresse_ip, --interface=adresse_ip
Adresse IP sur laquelle le serveur web doit écouter.
-p port, --port=port
Port sur lequel le serveur web doit écouter.
-b chemin, --base=chemin
Définit le chemin de base sur lequel l'interface web s'exécute (proxy).
--ssl
Force le serveur web à utiliser SSL.
--no-ssl
Force le serveur web à désactiver SSL.

Options de journalisation

-l fichier, --logfile=fichier
Écrit dans un fichier journal spécifié au lieu de la sortie standard.
-L niveau_journal, --loglevel=niveau_journal
Définit le niveau de journalisation (par défaut : error) : none, info, warning, error, debug.
-q, --quiet
Définit le niveau de journalisation sur none, identique à -L none.
--logrotate[=taille-max]
Active la rotation des fichiers journaux, avec une taille maximale optionnelle du fichier journal, par défaut : 2M (Le nombre de rotations est de 5).
--profile[=fichier]
Profile avec cProfile. Écrit dans la sortie standard sauf si un nom de fichier est spécifié.

Options de contrôle de processus :

-P fichier, --pidfile=fichier
Fichier PID pour stocker l'identifiant du processus.
-d, --do-not-daemonize
Ne pas faire de démonisation (fork) de ce processus.
-U, --user=utilisateur
Changer pour cet utilisateur au démarrage (nécessite root).
-g, --group=groupe
Changer pour ce groupe au démarrage (nécessite root).

Options d'aide

-V, --version
Affiche le numéro de version du programme et quitte.
-h, --help
Affiche le message d'aide et quitte.
