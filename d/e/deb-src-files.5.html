NOM

deb-src-files - format des fichiers de distribution Debian

SYNTAXE

debian/files

DESCRIPTION

Ce fichier contient la liste des artefacts qui doivent être distribués via le fichier de contrôle .changes.

Le fichier debian/files a un format simple délimité par des espaces.

nom_fichier section priorité [ mot-clé=valeur... ]

nom_fichier est le nom de l'artefact à distribuer.

section et priorité correspondent aux champs de contrôle respectifs disponibles dans le .deb. Les valeurs autorisées sont spécifiques à chaque archive de distribution.

mot-clé=valeur... correspond à une liste optionnelle d'attributs délimités par des espaces pour cette entrée. Le seul mot-clé actuellement supporté est automatic avec la valeur yes, pour marquer les fichiers générés automatiquement.

NOTES

Ce fichier n'est pas destiné à être modifié directement, veuillez utiliser dpkg-gencontrol ou dpkg-distaddfile pour y ajouter des entrées.

VOIR AUSSI

dpkg-genchanges(1), dpkg-distaddfile(1).
