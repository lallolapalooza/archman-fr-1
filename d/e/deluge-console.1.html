NOM

deluge-console - Interface console d'un client BitTorrent

SYNTAXE

deluge-console [options]

DESCRIPTION

Deluge utilise un modèle client/serveur, avec deluged étant le processus démon et deluge-console utilisé pour lancer une interface utilisateur console en curses.

Commandes de la console :

Vous pouvez passer des commandes de console directement depuis la ligne de commande et utiliser le séparateur point-virgule (;) pour exécuter plusieurs commandes. Il peut également être nécessaire d'entourer les commandes de guillemets, par exemple :


deluge-console 'add <torrent>; info <torrent_id>'

Les commandes de console suivantes sont disponibles :

add Ajouter des torrents
cache Afficher des informations sur le cache disque
config Afficher et définir les valeurs de configuration
connect Se connecter à un nouveau serveur deluge
debug Activer et désactiver le débogage
del Alias pour rm
exit Alias pour quit
gui Activer le mode interactif
halt Arrêter le serveur deluge
help Afficher l'aide sur les autres commandes
info Afficher des informations sur les torrents
manage Afficher et gérer les options par torrent
move Déplacer l'emplacement de stockage des torrents
pause Mettre en pause les torrents
plugin Gérer les plugins
quit Quitter le client
reannounce Alias pour update_tracker
recheck Force une vérification des données du torrent
resume Reprendre les torrents
rm Supprimer un torrent
status Affiche diverses informations d'état du démon
update_tracker Mettre à jour le tracker pour le(s) torrent(s)

OPTIONS

Options de configuration

-c chemin,--config=chemin
Définit l'emplacement du répertoire de configuration.

Options de la console

Ces options de connexion au démon seront utilisées pour les commandes, ou si la connexion automatique de l'interface console est activée.

-d ip_addr,--daemon=ip_addr
Adresse IP du démon Deluge à connecter (par défaut 127.0.0.1)
-p port,--port=port
Port du démon Deluge à connecter (par défaut 58846)
-U utilisateur,--username=utilisateur
Nom d'utilisateur du démon Deluge à utiliser lors de la connexion
-P mdp,--password=mdp
Mot de passe du démon Deluge à utiliser lors de la connexion

Options de journaux

-l fichier,--logfile=fichier
Envoyer la sortie vers un fichier journal spécifié au lieu de stdout
-L niveau_journal,--loglevel=niveau_journal
Définir le niveau du journal (par défaut est error) : none, info, warning, error, debug
-q,--quiet
Définit le niveau du journal sur none, équivalent à -L none
--logrotate[=taille-max]
Activer la rotation du fichier journal, avec une taille maximale optionnelle du fichier journal, par défaut : 2M (Nombre de rotations de fichiers journaux : 5)
--profile[=fichier]
Profiler avec cProfile. La sortie est envoyée à stdout sauf si un nom de fichier est spécifié

Options d'aide

-V,--version
Afficher le numéro de version du programme et quitter.
-h,--help
Afficher le message d'aide et quitter.
