NOM

itcl::delete - supprime des éléments dans l'interpréteur

SYNTAXE

itcl::delete option ?arg arg ...?

DESCRIPTION

La commande delete est utilisée pour supprimer des éléments dans l'interpréteur. Elle est implémentée comme un ensemble, ainsi les extensions peuvent ajouter leurs propres options et étendre le comportement de cette commande. Par défaut, la commande delete gère la destruction des espaces de noms.

L'argument option détermine quelle action est effectuée par la commande. Les options légales (qui peuvent être abrégées) sont :

supprimer classe nom ?nom...?
Supprime une ou plusieurs classes [incr Tcl] nommées nom. Cela supprime tous les objets de la classe, ainsi que toutes les classes dérivées.

Si une erreur survient lors de la destruction d'un objet, cela empêchera la destruction de la classe et de tous les objets restants. Pour détruire la classe entière sans tenir compte des erreurs, utilisez la commande "supprimer espace de noms".

supprimer objet nom ?nom...?
Supprime un ou plusieurs objets [incr Tcl] nommés nom. Un objet est supprimé en invoquant tous les destructeurs de sa hiérarchie de classes, dans l'ordre du plus spécifique au moins spécifique. Si tous les destructeurs réussissent, les données associées à l'objet sont supprimées et le nom est retiré comme commande de l'interpréteur.

Si la commande d'accès à un objet réside dans un autre espace de noms, alors son nom qualifié peut être utilisé :

itcl::delete object foo::bar::x

Si une erreur survient lors de la destruction d'un objet, la commande delete est interrompue et l'objet reste actif. Pour détruire un objet sans tenir compte des erreurs, utilisez la commande "rename" pour détruire la commande d'accès à l'objet.

supprimer espace de noms nom ?nom...?
Supprime un ou plusieurs espaces de noms nommés nom. Cela supprime toutes les commandes et variables dans l'espace de noms, et supprime également tous les espaces de noms enfants. Lorsqu'un espace de noms est supprimé, il est automatiquement retiré des listes d'importation de tous les autres espaces de noms.

MOTS-CLÉS

espace de noms, proc, variable, ensemble
