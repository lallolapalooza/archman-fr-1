NOM

Devel::Cover::Report::Html_minimal - Backend HTML pour Devel::Cover

VERSION

version 1.51

SYNTAXE

cover -report html_minimal

DESCRIPTION

Ce module fournit un mécanisme de rapport HTML pour les données de couverture. Il est conçu pour être appelé depuis le programme "cover".

Basé sur un original de Paul Johnson, le résultat a été grandement amélioré par Michael Carman (mjcarman@mchsi.com).

OPTIONS

Les options sont spécifiées en ajoutant les drapeaux appropriés au programme "cover". Ce format de rapport prend en charge les éléments suivants :

fichier_sortie
Spécifie le nom du fichier de sortie principal. Par défaut, il s'agit de coverage.html. Spécifiez index.html si vous souhaitez simplement publier l'ensemble du répertoire.
pod
Inclut le POD (et les lignes vides) dans le rapport de fichier. Ceci est activé par défaut. Il peut être désactivé avec -nopod.
donnees
Inclut le texte après les jetons "__DATA__" ou "__END__" dans le rapport de fichier. Par défaut, ce texte est tronqué.

Note : Si votre POD se trouve après un "__END__", vous devez spécifier 'donnees' pour l'inclure, et non 'pod'. L'option 'pod' ne s'applique qu'au POD situé avant le "__END__".

unifie
Génère un rapport « unifié » pour chaque fichier. Les données détaillées qui apparaissent normalement dans les rapports auxiliaires (branche, condition, etc.) sont placées dans le rapport de fichier, et les rapports auxiliaires ne sont pas générés.
titre_resume
Spécifie le titre du résumé. Par défaut, il s'agit de « Résumé de la couverture ».
