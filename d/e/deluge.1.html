DELUGE(1) Manuel des commandes générales DELUGE(1)

NOM

deluge - un client BitTorrent

SYNTAXE

deluge [options] [fichier-torrent]

DESCRIPTION

Deluge utilise un modèle client/serveur, avec deluged comme processus démon et deluge pour lancer une interface utilisateur.

Par défaut, Deluge s'exécutera en mode Autonome où la fonctionnalité du démon sera masquée. Vous pouvez passer en mode Client léger dans la boîte de dialogue Préférences.

OPTIONS

Options de configuration

-c chemin, --config=chemin
Définit l'emplacement du répertoire de configuration.

Options d'interface utilisateur

Voir deluge -h pour les interfaces utilisateur disponibles.

interface_utilisateur [args-interface] Une interface alternative à lancer, avec des arguments optionnels pour l'interface
-s interface_par_défaut, --set-default-ui=interface_par_défaut
Définit l'interface par défaut à exécuter lorsqu'aucune interface n'est spécifiée.

Options de journalisation

-l fichier, --logfile=fichier
Écrit dans le fichier journal spécifié au lieu de la sortie standard
-L niveau_journal, --loglevel=niveau_journal
Définit le niveau de journalisation (par défaut: erreur) : none, info, warning, error, debug
-q, --quiet
Définit le niveau de journalisation sur none, équivalent à -L none
--logrotate[=taille-max]
Active la rotation du fichier journal, avec une taille maximale optionnelle du fichier journal, par défaut: 2M (Le nombre de rotations du fichier journal est de 5)
--profile[=fichier]
Profilage avec cProfile. Sortie sur la sortie standard sauf si un nom de fichier est spécifié.

Options d'aide

-V, --version
Affiche le numéro de version du programme et quitte.
-h, --help
Affiche le message d'aide et quitte.
