deprecate(3perl) Guide de référence du programmeur Perl deprecate(3perl)

NOM

deprecate - Pragma Perl pour déprécier l'inclusion d'un module dans le noyau

SYNOPSIS

use deprecate;  # avertir de la future absence si chargé depuis le noyau

DESCRIPTION

Ce pragma simplifie la maintenance des modules à double vie qui ne seront plus inclus dans le noyau Perl dans une future version de Perl, mais qui y sont encore inclus actuellement.

Le but du pragma est d'alerter les utilisateurs sur le statut d'un tel module en émettant un avertissement qui les encourage à installer le module depuis CPAN, afin qu'une future mise à niveau vers une version de perl qui omet le module ne casse pas leur code.

Cet avertissement ne sera émis que si le module a été chargé à partir d'un répertoire de bibliothèque du noyau, ce qui permet d'inclure la ligne "use deprecate" dans la version CPAN du module. Étant donné que le pragma reste silencieux lorsque le module est exécuté à partir d'un répertoire de bibliothèque non-noyau, l'appel du pragma n'a pas besoin d'être patché ou retiré de la version du noyau ou de la version CPAN du module. Le même code exact peut être expédié dans les deux cas.

Avertissement important

Notez que lorsqu'un module s'installe depuis CPAN dans un répertoire de bibliothèque du noyau plutôt que dans les répertoires de bibliothèques du site, l'utilisateur n'obtient aucune protection du fait de son installation.

Dans le même temps, ce pragma ne peut pas détecter quand un tel module s'est installé depuis CPAN dans le répertoire du noyau, et il exhorte donc infiniment et inutilement l'utilisateur à mettre à niveau.

Par conséquent, les modules qui peuvent s'installer depuis CPAN dans le répertoire du noyau doivent s'assurer de ne pas appeler ce pragma lorsqu'ils l'ont fait. Généralement, cela signifie que la logique exacte de l'installeur doit être reflétée à l'intérieur du module. Par exemple :

# Makefile.PL
WriteMakefile(
    # ...
    INSTALLDIRS => ( "$]" >= 5.011 ? 'site' : 'perl' ),
);
# lib/Foo/Bar.pm
use if "$]" >= 5.011, 'deprecate';

(L'exemple ci-dessus montre le cas le plus important : lorsque la cible est une version de Perl antérieure à 5.12 (où les répertoires de bibliothèques du noyau ont la priorité sur les répertoires de bibliothèques du site) et que le module installé était inclus dans le noyau de cette version de Perl. Dans ces circonstances, une mise à niveau du module depuis CPAN n'est possible qu'en l'installant dans la bibliothèque du noyau.)

EXPORT

Aucun par défaut. La seule méthode est "import", appelée par "use deprecate;".
