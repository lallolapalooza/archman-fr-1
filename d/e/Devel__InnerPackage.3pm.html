Devel::InnerPackage(3) Documentation Perl fournie par l'utilisateur Devel::InnerPackage(3)

NOM

Devel::InnerPackage - trouver tous les paquets internes d'un paquet

SYNOPIS

use Foo::Bar;
use Devel::InnerPackage qw(list_packages);
my @inner_packages = list_packages('Foo::Bar');

DESCRIPTION

Étant donné un fichier comme celui-ci

package Foo::Bar;
sub foo {}
package Foo::Bar::Quux;
sub quux {}
package Foo::Bar::Quirka;
sub quirka {}
1;

alors

list_packages('Foo::Bar');

renverra

Foo::Bar::Quux
Foo::Bar::Quirka

MÉTHODES

list_packages <nom du paquet>

Retourne une liste de tous les paquets internes de ce paquet.
