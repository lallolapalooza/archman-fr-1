NOM

dex - Exécution de DesktopEntry

SYNTAXE

dex [options] [FichierDesktopEntry]...

DESCRIPTION

dex, DesktopEntry Execution, est un programme pour générer et exécuter des fichiers DesktopEntry de type Application.

OPTIONS

-h, --help
Afficher ce message d'aide et quitter
-a, --autostart
Démarrage automatique des programmes
-c CHEMIN, --create CHEMIN
Créer un fichier DesktopEntry pour le programme situé au chemin donné. Un argument optionnel est utilisé pour spécifier le nom du fichier DesktopEntry créé, ou spécifier - pour afficher le fichier sur la sortie standard. Par défaut, un nouveau fichier est créé avec l'extension .desktop.
-d, --dry-run
Exécution à blanc, n'exécute aucune commande
-e ENVIRONNEMENT, --environment ENVIRONNEMENT
Spécifier l'environnement de bureau pour lequel un démarrage automatique doit être effectué ; ne fonctionne qu'en combinaison avec --autostart
-s CHEMINSDECHERCHE, --search-paths CHEMINSDECHERCHE
Liste de chemins séparés par des deux-points pour rechercher des fichiers de bureau, remplaçant la liste de recherche par défaut
-t RÉPERTOIRE, --target-directory RÉPERTOIRE
Créer des fichiers dans le répertoire cible
--term TERMINAL
L'émulateur de terminal qui sera utilisé pour exécuter le programme si Terminal=true est défini dans le fichier de bureau, par défaut x-terminal-emulator
-w, --wait
Bloquer jusqu'à ce que le programme se termine
--test
Effectuer un auto-test
-v, --verbose
Sortie détaillée
-V, --version
Afficher les informations de version

EXEMPLES

Effectuer un démarrage automatique/exécuter tous les programmes dans les dossiers de démarrage automatique.

dex -a

Effectuer un démarrage automatique/exécuter tous les programmes dans les dossiers spécifiés.

dex -a -s /etc/xdg/autostart/:~/.config/autostart/

Prévisualiser les programmes qui seraient exécutés dans un démarrage automatique normal.

dex -ad

Prévisualiser les programmes qui seraient exécutés dans un démarrage automatique spécifique à GNOME.

dex -ad -e GNOME

Créer un DesktopEntry pour un programme dans le répertoire courant.

dex -c /usr/bin/skype

Créer un DesktopEntry pour un programme dans le répertoire de démarrage automatique.

dex -t ~/.config/autostart -c /usr/bin/skype /usr/bin/nm-applet

Exécuter un seul programme depuis la ligne de commande et activer la sortie détaillée.

dex -v skype.desktop

Exécuter un seul programme (avec Terminal=true dans le fichier de bureau) dans gnome-terminal.

dex --term gnome-terminal nvim.desktop

Exécuter un seul programme et bloquer jusqu'à ce qu'il se termine.

dex --wait nvim.desktop
