defrag.exfat(8) Manuel de l'administrateur système defrag.exfat(8)

NOM

defrag.exfat - Défragmenter ou évaluer la fragmentation d'un système de fichiers exFAT

SYNTAXE

defrag.exfat [-f | -a] appareil

defrag.exfat -h | --help

defrag.exfat -v | --version

DESCRIPTION

defrag.exfat est un utilitaire permettant de défragmenter des fichiers sur un appareil formaté en exFAT ou d'évaluer son état de fragmentation actuel.

La défragmentation réorganise les clusters de fichiers dispersés en blocs contigus, ce qui peut améliorer les performances d'E/S, en particulier sur les périphériques de stockage mécaniques.

Par défaut, lorsqu'aucune option n'est spécifiée, l'outil affichera un avertissement demandant à l'utilisateur d'exécuter d'abord fsck.exfat pour garantir la cohérence du système de fichiers.

Cet avertissement de sécurité peut être contourné en utilisant l'option -f.

L'option -a active le mode d'évaluation, qui analyse la fragmentation sans modifier le système de fichiers.

L'appareil cible doit être démonté avant d'exécuter cette commande.

OPTIONS

-f, --force
Effectuer la défragmentation sans afficher l'avertissement fsck. À utiliser avec prudence.
-a, --assessment
Évaluer l'état de fragmentation du volume exFAT sans apporter de modifications.
-v, --version
Afficher les informations de version et quitter.
-h, --help
Afficher les informations d'utilisation et quitter.

EXEMPLES

Défragmenter un appareil exFAT démonté (avec avertissement de sécurité) :

$ defrag.exfat /dev/sda1

Défragmenter sans demander de confirmation (mode forcé) :

$ defrag.exfat -f /dev/sda1

Évaluer l'état de fragmentation (lecture seule) :

$ defrag.exfat -a /dev/sda1

Afficher la version :

$ defrag.exfat -v

Afficher l'aide :

$ defrag.exfat -h

NOTES

Il est fortement recommandé d'exécuter fsck.exfat sur l'appareil avant la défragmentation pour garantir l'intégrité du système de fichiers.

Sauvegardez toujours les données critiques avant de défragmenter.
