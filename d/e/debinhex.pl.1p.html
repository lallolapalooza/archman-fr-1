NOM

debinhex.pl - utiliser Convert::BinHex pour décoder les fichiers BinHex

UTILISATION

Utilisation :

debinhex.pl [options] fichier ... fichier

Où les options sont :

-o dir    Sortie dans le répertoire donné (par défaut, sortie dans le répertoire du fichier)
-v        Sortie détaillée (normalement, une seule ligne par fichier est affichée)

DESCRIPTION

Chaque fichier est censé être un fichier BinHex. Par défaut, le fichier de sortie reçoit le nom que le fichier BinHex dicte, quel que soit le nom du fichier BinHex.
