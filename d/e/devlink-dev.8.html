devlink dev reload - effectue un rechargement à chaud du

pilote.

DEV - Spécifie le périphérique devlink à

recharger.

netns { PID | NAME | ID } - Spécifie l'espace de noms réseau dans lequel recharger, soit par pid, nom ou

id.

action { driver_reinit | fw_activate } - Spécifie l'action de rechargement requise. Si cet argument est omis, l'action driver_reinit sera utilisée. Notez que même si l'utilisateur demande une action spécifique, l'implémentation du pilote peut nécessiter d'effectuer une autre action en parallèle. Par exemple, certains pilotes ne prennent pas en charge la réinitialisation du pilote sans activation du firmware. Par conséquent, la commande devlink reload retourne la liste des actions qui ont été effectivement réalisées. driver_reinit - Réinitialisation des entités du pilote, appliquant les valeurs devlink-param et devlink-resource

.

fw_activate - Active le nouveau firmware si un tel image est stockée et en attente d'activation. Si aucune limitation n'est spécifiée, cette action peut impliquer une réinitialisation du firmware. Si aucune nouvelle image n'est en attente, cette action rechargera l'image du firmware

actuelle.

limit no_reset - Spécifie une limitation sur l'action de rechargement. Si cet argument est omis, la limite est non spécifiée et l'action de rechargement n'est pas limitée. Dans ce cas, l'implémentation du pilote peut inclure une réinitialisation ou une interruption de service selon les besoins pour effectuer les

actions.

no_reset - Aucune réinitialisation autorisée, aucune interruption de service autorisée, aucun basculement de lien et aucune configuration n'est

perdue.

Affiche les informations du périphérique fournies par le pilote. Cette commande peut être utilisée pour interroger les versions des composants matériels ou des composants du périphérique qui ne peuvent pas être mis à

Pour les composants firmware, running affiche les versions du firmware actuellement chargées dans le périphérique, tandis que stored rapporte les versions dans le flash du périphérique. Les versions running et stored peuvent différer après que le flash a été mis à jour, mais avant le
