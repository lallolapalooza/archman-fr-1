BrotliDecoderResult BrotliDecoderDecompressStream (BrotliDecoderState * state, size_t * available_in, const uint8_t ** next_in, size_t * available_out, uint8_t ** next_out, size_t *

total_out)

Décompresse le flux d'entrée vers le flux de sortie. Les valeurs *available_in et *available_out doivent spécifier le nombre d'octets adressables à *next_in et *next_out respectivement. Lorsque *available_out vaut 0, next_out peut être

NULL.

Après chaque appel, *available_in sera décrémenté du nombre d'octets d'entrée consommés, et le pointeur *next_in sera incrémenté de ce montant. De même, *available_out sera décrémenté du nombre d'octets de sortie écrits, et le pointeur *next_out sera incrémenté de ce

montant.

total_out, s'il n'est pas un pointeur nul, sera défini au nombre d'octets décompressés depuis la dernière initialisation de

l'état.

Note

:
L'entrée n'est jamais surconsommée, donc next_in et available_in pourront être passés au consommateur suivant une fois le décodage
terminé.

Paramètres

:
state instance du décodeur
available_in entrée : quantité d'entrée disponible ;
sortie : quantité d'entrée inutilisée
next_in pointeur vers l'octet compressé suivant
available_out entrée : longueur du tampon de sortie ;
sortie : taille restante du tampon de sortie
next_out curseur du tampon de sortie ; peut être NULL si available_out vaut 0
total_out nombre d'octets décompressés jusqu'à présent ; peut être NULL

Renvoie

:
BROTLI_DECODER_RESULT_ERROR si l'entrée est corrompue, l'allocation mémoire a échoué, les arguments étaient invalides, etc. ; utilisez BrotliDecoderGetErrorCode pour obtenir le code d'erreur détaillé

BROTLI_DECODER_RESULT_NEEDS_MORE_INPUT le décodage est bloqué jusqu'à ce que plus de données d'entrée soient

fournies

BROTLI_DECODER_RESULT_NEEDS_MORE_OUTPUT le décodage est bloqué jusqu'à ce que plus d'espace de sortie soit

fourni

BROTLI_DECODER_RESULT_SUCCESS le décodage est terminé,

plus aucune entrée ne

const uint8_t* BrotliDecoderTakeOutput (BrotliDecoderState * state, size_t * size)

Acquiert un pointeur vers le tampon de sortie interne. Cette méthode est utilisée pour faciliter et améliorer l'efficacité des liaisons linguistiques :

1.
pousser des données vers BrotliDecoderDecompressStream, jusqu'à ce que BROTLI_DECODER_RESULT_NEEDS_MORE_OUTPUT soit rapporté
2.
utiliser BrotliDecoderTakeOutput pour examiner les octets et les copier dans une entité spécifique au langage

Ceci peut également être utile s'il existe un flux de sortie capable de consommer toutes les données fournies (par exemple, lors de l'enregistrement de données sur le système de fichiers).

Attention :

Après chaque appel à BrotliDecoderTakeOutput, *size octets de sortie sont considérés comme consommés pour tous les appels consécutifs aux méthodes d'instance ; le pointeur retourné devient également invalide.

Remarque :

La sortie du décodeur n'est pas garantie d'être contiguë. Cela signifie qu'après un appel sans restriction de taille à BrotliDecoderTakeOutput, un appel immédiat suivant à BrotliDecoderTakeOutput peut retourner plus de données.

Paramètres :

state instance du décodeur
size en : nombre d'octets que l'appelant est prêt à prendre, 0 si n'importe quelle quantité pouvait être gérée ;
sortant : quantité de données pointée par le pointeur retourné et considérée comme consommée ;
la valeur sortante n'est jamais supérieure à la valeur entrante, sauf si elle est de 0

Retourne :

pointeur vers les données de sortie
