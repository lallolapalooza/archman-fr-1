NOM

Devel::GlobalDestruction - Fournit une fonction retournant l'équivalent de "${^GLOBAL_PHASE} eq 'DESTRUCT'" pour les perls plus anciens.

SYNOPSIS

package Foo;
use Devel::GlobalDestruction;
use namespace::clean; # pour éviter d'avoir une méthode "in_global_destruction"
sub DESTROY {
    return if in_global_destruction;
    do_something_a_little_tricky();
}

DESCRIPTION

La destruction globale de Perl est un peu délicate à gérer en ce qui concerne les finaliseurs, car elle n'est pas ordonnée et les objets peuvent parfois disparaître.

Écrire des destructeurs défensifs est difficile et ennuyeux, et généralement, si la destruction globale est en cours, seuls les destructeurs qui libèrent des ressources non locales au processus doivent réellement s'exécuter.

Pour ces constructeurs, vous pouvez éviter le désordre en vous retirant simplement si la destruction globale est en cours.

EXPORTATIONS

Ce module utilise Sub::Exporter::Progressive, donc les exportations peuvent être renommées, aliasées, etc. si Sub::Exporter est présent.

in_global_destruction
Retourne vrai si l'interpréteur est en phase de destruction globale. Dans perl 5.14+, ceci retourne "${^GLOBAL_PHASE} eq 'DESTRUCT'", et sur les perls antérieurs, il le détecte en utilisant la valeur de "PL_main_cv" ou "PL_dirty".
