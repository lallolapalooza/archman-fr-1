NOM

default.pa — Script de démarrage du serveur sonore PulseAudio

SYNTAXE

~/.config/pulse/default.pa

/etc/pulse/default.pa

/etc/pulse/system.pa

DESCRIPTION

Le serveur sonore PulseAudio interprète un script de configuration au démarrage, qui est principalement utilisé pour définir l'ensemble des modules à charger. Lorsque PulseAudio s'exécute en mode utilisateur et que ~/.config/pulse/default.pa existe, ce fichier est utilisé. Lorsque PulseAudio s'exécute en mode utilisateur et que ce fichier n'existe pas, /etc/pulse/default.pa est utilisé. Lorsque PulseAudio s'exécute en tant que service système, /etc/pulse/system.pa est utilisé.

Le script doit contenir des directives dans le langage CLI de PulseAudio, comme documenté dans pulse-cli-syntax(5).
