NOM

devnag - Préprocesseur pour le devanagari pour TeX

SYNTAXE

devnag in[.dn] [out[.tex]]

DESCRIPTION

devnag est un préprocesseur qui lit l'entrée devanagari translittérée délimitée par \dn et la convertit dans un format que TeX comprend.

Le préprocesseur gère les détails du placement des caractères tels que l'alignement des diacritiques vocaliques et des ligatures de consonnes. Le reste de la mise en page, cependant, doit être géré par l'utilisateur.

Pour la spécification du format, veuillez consulter la documentation fournie avec le paquet.

OPTIONS

in[.dn] out[.tex]
L'extension de fichier par défaut pour un fichier d'entrée est .dn et pour un fichier de sortie .tex. Le nom du fichier de sortie est facultatif. Si aucun nom de fichier de sortie n'est spécifié, le préprocesseur le nommera d'après le fichier d'entrée.
-v
rapporte la version de devnag
