NOM

defncopy — extraire les procédures et vues d'un serveur Microsoft.

SYNTAXE

defncopy [-v] [-U nom_utilisateur] [-P mot_de_passe] [-S serveur] [-D base_de_données] [-i fichier_entree] [-o fichier_sortie] [propriétaire.nom_objet [propriétaire.nom_objet ...]]

DESCRIPTION

defncopy est un utilitaire distribué avec FreeTDS. Il remplace un programme similaire du même nom distribué par Sybase.

defncopy lit le texte d'une procédure stockée ou d'une vue, et écrit un script approprié pour recréer la procédure ou la vue. Pour les tables, il lit la sortie de sp_help et construit une instruction ‘CREATE TABLE’, avec aussi des ‘CREATE INDEX’. propriétaire est facultatif si vous ou le propriétaire de la base de données êtes le propriétaire de la procédure/vue copiée. nom_objet est le nom de l'objet système que vous souhaitez extraire.

OPTIONS

-U nom_utilisateur
nom de connexion au serveur de base de données.
-P mot_de_passe
mot de passe du serveur de base de données.
-S serveur
serveur de base de données auquel se connecter.
-D base_de_données
base de données à utiliser. Facultatif si la procédure/vue extraite se trouve dans votre base de données par défaut.
-i fichier_entree
un script à appliquer à la base de données. Non implémenté actuellement.
-o fichier_sortie
un fichier pour contenir le script, par défaut la sortie standard.
-v
Afficher les informations de version et l'avis de droit d'auteur.

NOTES

defncopy est un filtre ; il lit depuis l'entrée standard, écrit vers la sortie standard, et écrit les erreurs vers la sortie d'erreur. Les options -i, -o, et -e remplacent ces valeurs par défaut.

defncopy utilise l'API db-lib fournie par FreeTDS. Cette API est bien sûr également disponible pour les développeurs d'applications.

STATUT DE SORTIE

defncopy se termine avec 0 en cas de succès, et >0 si le serveur ne peut pas traiter la requête.

defncopy signalera toutes les erreurs renvoyées par le serveur, mais continuera le traitement.

HISTORIQUE

defncopy est apparu pour la première fois dans FreeTDS 0.63.

AUTEURS

L'utilitaire defncopy a été écrit par James K. Lowden ⟨jklowden@schemamania.org.⟩

BOGUES

Fonctionne uniquement avec les serveurs Microsoft et les anciens serveurs Sybase. Ne crée pas de clés primaires. De nombreuses options sont définies par Sybase que cette version n'implémente pas. N'hésitez pas à corriger cette situation. En théorie, defncopy pourrait appliquer/produire du DDL pour tout objet système, mais actuellement seules les tables, procédures et vues sont supportées, et uniquement pour l'extraction.
