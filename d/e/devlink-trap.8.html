NOM

devlink-trap - configuration des pièges devlink

SYNOPIS


devlink [ OPTIONS ] trap { COMMANDE | help }

OPTIONS := { -v[erbose] | -s[tatistics] }

devlink trap show [ DEV trap TRAP ]

devlink trap set DEV trap TRAP [ action { trap | drop | mirror } ]

devlink trap group show [ DEV group GROUP ]

devlink trap group set DEV group GROUP [ action { trap | drop | mirror } ]
[ policer POLICER ] [ nopolicer ]

devlink trap policer set DEV policer POLICER [ rate RATE ] [ burst BURST ]

devlink trap help

DESCRIPTION

devlink trap show - affiche les pièges de paquets disponibles et leurs attributs

DEV - spécifie le périphérique devlink à partir duquel afficher les pièges de paquets. Si cet argument est omis, tous les pièges de paquets de tous les périphériques sont listés.

trap TRAP - spécifie le piège de paquet. Applicable uniquement si un périphérique devlink est également spécifié.

devlink trap set - définit les attributs d'un piège de paquet

DEV - spécifie le périphérique devlink auquel appartient le piège de paquet.

trap TRAP - spécifie le piège de paquet.

action { trap | drop | mirror }
action du piège de paquet.

trap - la copie unique du paquet est envoyée au CPU.

drop - le paquet est abandonné par le périphérique sous-jacent et une copie n'est pas envoyée au CPU.

mirror - le paquet est transféré par le périphérique sous-jacent et une copie est envoyée au CPU.

devlink trap group show - affiche les groupes de pièges de paquets disponibles et leurs attributs

DEV - spécifie le périphérique devlink à partir duquel afficher les groupes de pièges de paquets. Si cet argument est omis, tous les groupes de pièges de paquets de tous les périphériques sont listés.

group GROUP - spécifie le groupe de pièges de paquets. Applicable uniquement si un périphérique devlink est également spécifié.

devlink trap group set - définit les attributs d'un groupe de pièges de paquets

DEV - spécifie le périphérique devlink auquel appartient le groupe de pièges de paquets.

group GROUP - spécifie le groupe de pièges de paquets.

action { trap | drop | mirror }
action du piège de paquet. L'action est définie pour tous les pièges de paquets membres du groupe de pièges. Les actions des pièges non-drop ne peuvent pas être modifiées et sont donc ignorées.
policer POLICER
contrôleur de débit (policer) de piège de paquet. Le policer à lier au groupe de pièges de paquets. Une valeur de "0" délie le policer actuellement lié.
nopolicer
Délier le policer de piège de paquet du groupe de pièges de paquets.

devlink trap policer set - définit les attributs du policer de piège de paquet

DEV - spécifie le périphérique devlink auquel appartient le policer de piège de paquet.

policer POLICER - spécifie le policer de piège de paquet.

rate RATE - débit du policer de piège de paquet en paquets par seconde.

burst BURST - taille du burst du policer de piège de paquet en paquets.

EXEMPLES

devlink trap show

Liste les pièges de paquets disponibles.

devlink trap group show

Liste les groupes de pièges de paquets disponibles.

devlink -vs trap show pci/0000:01:00.0 trap source_mac_is_multicast

Affiche les attributs et les statistiques d'un piège de paquet spécifique.

devlink -s trap group show pci/0000:01:00.0 group l2_drops

Affiche les attributs et les statistiques d'un groupe de pièges de paquets spécifique.

devlink trap set pci/0000:01:00.0 trap source_mac_is_multicast action trap

Définit l'action d'un piège de paquet spécifique sur 'trap'.

devlink trap policer show

Liste les policiers de pièges de paquets disponibles.

devlink -s trap policer show pci/0000:01:00.0 policer 1

Affiche les attributs et les statistiques d'un policer de piège de paquet spécifique.

devlink trap policer set pci/0000:01:00.0 policer 1 rate 1000 burst 128

Définit le débit et la taille du burst d'un policer de piège de paquet spécifique.
