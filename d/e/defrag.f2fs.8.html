DEFRAG.F2FS(8) Manuel de l'administrateur système DEFRAG.F2FS(8)

NOM

defrag.f2fs - déplacer des blocs dans une zone donnée vers la région spécifiée

SYNTAXE

defrag.f2fs [ -s adresse de bloc de départ ] [ -l nombre de blocs ] [ -t adresse de bloc cible ] [ -i direction ] [ -d niveau de débogage ] périphérique

DESCRIPTION

defrag.f2fs est utilisé pour déplacer un nombre spécifié de blocs à partir d'une adresse de bloc donnée vers l'adresse de bloc cible avec une direction. périphérique est le fichier spécial correspondant au périphérique (par exemple, /dev/sdXX).

Par exemple, # defrag.f2fs -s 0x4000 -l 0x100 -t 0x10000 -i /dev/sdb1

Ceci déplace les blocs entre 0x4000 et 0x4100 vers la zone de gauche de 0x10000.

Le code de retour renvoyé par defrag.f2fs est 0 en cas de succès et -1 en cas d'échec.

OPTIONS

-s adresse de bloc de départ
Spécifie l'adresse de bloc de départ.
-l nombre de blocs
Spécifie le nombre de blocs à déplacer.
-t adresse de bloc cible
Spécifie l'adresse de bloc de destination.
-i direction
Définit la direction à gauche. Si elle n'est pas définie, la direction devient droite par défaut.
-d niveau de débogage
Spécifie le niveau des options de débogage. Le nombre par défaut est 0, qui affiche des messages de débogage de base.
