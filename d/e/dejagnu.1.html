DEJAGNU(1) Manuel des commandes générales (urm) DEJAGNU(1)

NOM

dejagnu — Lancement des commandes auxiliaires DejaGnu

SYNTAXE

dejagnu ⟨commande⟩ [--help | options...]

dejagnu --help

dejagnu --version

DESCRIPTION

La commande dejagnu recherche un script implémentant la commande demandée, sélectionne parmi plusieurs implémentations disponibles selon une liste interne fixe, et exécute la commande.

OPTIONS

--help
Affiche un message d'aide au lieu d'exécuter une commande. Si aucune commande n'est donnée, affiche l'utilisation brève de dejagnu lui-même.
-V, --version
Affiche une bannière de version pour le lanceur lui-même, y compris la version de DejaGnu. Toute commande donnée est ignorée.
-v, --verbose
Émet une sortie supplémentaire décrivant le fonctionnement du lanceur dejagnu lui-même. Cette option est également transmise à la commande invoquée.

Tous les arguments après le nom de la commande sont transmis à la commande invoquée.

ENVIRONNEMENT

DEJAGNULIBS
Si défini, indique l'emplacement de la bibliothèque DejaGnu dans le système de fichiers. La recherche décrite dans FICHIERS n'a pas lieu si DEJAGNULIBS est défini.
AWK
Nom de fichier complet pour un interpréteur Awk qui peut ou non être réellement GNU Awk. S'il n'est pas défini, le PATH sera recherché pour un programme awk. Si l'interpréteur Awk est réellement GNU Awk, l'option --posix sera donnée si une implémentation Awk est utilisée.
GAWK
Nom de fichier complet pour GNU Awk. S'il n'est pas défini, le PATH sera recherché pour un programme gawk.
BASH
Nom de fichier complet pour GNU Bash. S'il n'est pas défini, le PATH sera recherché pour un programme bash. Notez que Bash lui-même définit cette variable, même lorsqu'il est exécuté sous le nom de sh, même lorsqu'il exécute un script.
EXPECT
Nom de fichier complet pour Expect, qui est un interpréteur Tcl avec l'extension Expect déjà chargée. S'il n'est pas défini, le PATH sera recherché pour un programme expect. Notez que le cœur de DejaGnu est écrit en Expect, donc cet interpréteur devrait toujours être disponible.
TCLSH
Nom de fichier complet pour un interpréteur Tcl. S'il n'est pas défini, le PATH sera recherché pour un programme tclsh.

Notez que GNU Awk est considéré comme un sur-ensemble d'Awk et qu'Expect est considéré comme un sur-ensemble de Tcl, permettant au premier d'être utilisé pour exécuter des scripts écrits pour le second. Cela signifie que, bien que les programmes Awk soient généralement exécutés avec les extensions GNU désactivées en utilisant l'option --posix pour GNU Awk, les programmes Tcl peuvent être exécutés avec tclsh ou expect et doivent être écrits en conséquence.

FICHIERS

$DEJAGNULIBS/commands
Si DEJAGNULIBS est défini, tous les scripts de commande sont censés se trouver dans ce répertoire.

Sinon, le premier répertoire qui existe réellement dans la liste suivante est utilisé, où @bindir@ représente le répertoire contenant dejagnu lui-même.

  • @bindir@/../share/dejagnu/commands
  • @bindir@/../../share/dejagnu/commands
  • /usr/share/dejagnu/commands
  • /usr/local/share/dejagnu/commands

VOIR AUSSI

La documentation complète de DejaGnu est maintenue sous forme de manuel Texinfo. Si le programme info est correctement installé sur votre site, la commande info dejagnu devrait vous donner accès au manuel complet.

AUTEURS

Jacob Bachmeyer

BOGUES

Le nom de la commande doit précéder tous les autres arguments en raison des limitations du shell.
