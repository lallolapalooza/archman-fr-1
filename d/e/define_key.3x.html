NOM

define_key - définir un code de touche curses

SYNTAXE

#include <curses.h>
int define_key(const char *definition, int keycode);

DESCRIPTION

Ceci est une extension de la bibliothèque curses. Elle permet à une application de définir des codes de touches avec leurs chaînes de contrôle correspondantes, de sorte que la bibliothèque ncurses les interprète comme elle le ferait avec les codes prédéfinis dans la base de données terminfo.

Si definition est NULL, toute définition existante pour le code de touche est supprimée. De même, si le code de touche donné est négatif ou nul, toute chaîne existante pour la définition donnée est supprimée.

VALEUR DE RETOUR

Soit keycode doit être supérieur à zéro, soit definition doit être différent de NULL, sinon ERR est retourné. ERR peut également être retourné s'il n'y a pas assez de mémoire pour allouer les données nécessaires au stockage de la définition. Si aucune erreur n'est détectée, OK est retourné.

PORTABILITÉ

Ces routines sont spécifiques à ncurses. Elles n'étaient pas supportées sur les implémentations Version 7, BSD ou System V. Il est recommandé que tout code dépendant de ces routines soit conditionné à l'aide de NCURSES_VERSION.
