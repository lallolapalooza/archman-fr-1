NOM

Device::Modem::UsRobotics - extensions pour modems USR pour contrôler le mode auto

SYNTAXE

use Device::Modem::UsRobotics;
my $modem = Device::Modem::UsRobotics->new( port => '/dev/ttyS1' );
$modem->connect( baudrate => 9600 );
my %info = $modem->messages_info();
print "Il y a $info{unreleased_voice_msg} messages vocaux non lus sur $info{stored_voice_msg} au total\n";
print "Il y a $info{unreleased_fax_msg} messages fax non lus sur $info{stored_fax_msg} au total\n";
# Obtenir des détails sur le message n. X
my %msg = $modem->message_info(1);
      index type information attributs statut jour heure minute
      callerid page addresshigh addresslow checksum
print 'Ceci est un message ', ($msg{type} == 2 ? 'vocal' : 'fax'), "\n";
print 'Il provient du no. ', $msg{callerid}, "\n";
# ...
# Maintenant, effacer tous les messages
$modem->clear_memory();

AVERTISSEMENT

Ce module n'est pas encore documenté, et c'est un travail en cours très brut. Jusqu'à présent, il lit correctement les informations sur les messages vocaux/fax, mais lors de l'enregistrement des messages vocaux sur disque, ils sont parfois mal décodés.

Donc, si vous avez besoin d'un programme fonctionnel, consultez le bon vieux TkUsr de Ludovic Drolez, à moins que vous ne souhaitiez aider au développement de Device::Modem::UsRobotics.

MÉTHODES

clear_memory()

Utilisé pour effacer définitivement l'espace mémoire du modem. Il y a des espaces mémoire séparés, un pour les messages vocaux/fax et un pour les paramètres utilisateur. Exemples:

    $modem->clear_memory('user');     # ou $modem->clear_memory(1)
$modem->clear_memory('messages'); # ou $modem->clear_memory(2)

Pour effacer les deux, vous pouvez utiliser:

$modem->clear_memory('all');      # ou $modem->clear_memory(0);

Paramètres:

$memtype
Chaîne de caractères ou entier qui sélectionne le type de mémoire à effacer, où 0 est pour "all" (tout), 1 est pour la mémoire "user" (utilisateur), 2 est pour la mémoire "messages".
