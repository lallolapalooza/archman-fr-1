Paquet: kservice5

DESKTOPTOJSON(8) KDE Frameworks : KService DESKTOPTOJSON(8)

NOM

desktoptojson - Convertit un fichier .desktop en fichier .json.

SYNTAXE

desktoptojson --input FICHIER-DESKTOP --output FICHIER-JSON

desktoptojson {--version | --help}

DESCRIPTION

Le framework KService utilise les informations contenues dans les fichiers .desktop pour localiser les services, y compris les plugins pour les applications et les bibliothèques basées sur Qt5. Cependant, le système de plugins de Qt5 utilise des données JSON intégrées au plugin lui-même. desktoptojson permet d'utiliser également les informations contenues dans un fichier .desktop comme données intégrées pour un plugin Qt5 en convertissant les entrées du fichier .desktop en données JSON.

Les données JSON générées sont un objet JSON qui mappe les entrées du groupe [Desktop Entry] du fichier .desktop. Tous les autres groupes sont ignorés. La plupart des entrées sont simplement converties en chaînes JSON, mais certaines entrées (telles que Hidden et X-KDE-PluginInfo-EnabledByDefault) sont connues pour être des valeurs booléennes et converties en tant que telles, et de même certaines (telles que X-KDE-ServiceTypes et X-KDE-PluginInfo-Depends) sont toujours converties en tableaux de chaînes.

OPTIONS

--input FICHIER-DESKTOP

Le fichier .desktop à convertir.

--output FICHIER-JSON

Le fichier dans lequel écrire les données JSON générées.

--help

Affiche un bref texte d'aide.

--version

Affiche les informations de version.

UTILISATION

La plupart des utilisateurs de cet utilitaire utiliseront la macro CMake kservice_desktop_to_json dans le cadre du processus de compilation d'un plugin.

add_library(myplugin MODULE ${myplugin_SRCS})
kservice_desktop_to_json(myplugin myplugin.desktop)

Ceci produira le fichier JSON myplugin.json, qui pourra être référencé par les macros K_PLUGIN_FACTORY_WITH_JSON ou Q_PLUGIN_METADATA.

BOGUES

Veuillez utiliser le suivi des bogues de KDE[1] pour signaler les bogues.
