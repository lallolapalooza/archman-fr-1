Devel::Cover::Report::Compilation(3) Documentation Perl fournie par l'utilisateur Devel::Cover::Report::Compilation(3)

NOM

Devel::Cover::Report::Compilation - backend pour Devel::Cover

VERSION

version 1.51

SYNOPSIS

cover -report compilation

DESCRIPTION

Ce module fournit un mécanisme de rapport textuel pour les données de couverture. Il est conçu pour être appelé depuis le programme "cover".

Il produit un rapport par ligne, dans un format similaire aux messages d'erreur de compilation de Perl. Cela le rend facile à utiliser avec les outils de développement qui comprennent les formats de sortie de compilation, tels que le mode compilation d'Emacs, le quickfix de vim, ou les fonctions de navigation d'erreurs des IDE.

FORMAT DE SORTIE

Le rapport de compilation génère une sortie dans les formats suivants :

  • Instructions 
    Instruction non couverte à filename.pm ligne 42 :
  • Branches 
    Branche jamais vraie à filename.pm ligne 15 : condition
Branche jamais fausse à filename.pm ligne 20 : sauf condition
Branche jamais atteinte à filename.pm ligne 25 : condition
  • Conditions 
    Condition non couverte (gauche, droite) à filename.pm ligne 30 : expr && expr
  • Sous-programmes 
    Sous-programme non couvert function_name à filename.pm ligne 50
  • Documentation POD 
    Pod non couvert à filename.pm ligne 60

UTILISATION AVEC LES OUTILS DE DÉVELOPPEMENT

Mode compilation Emacs

Pour utiliser avec le mode compilation d'Emacs :

M-x compile
cover -report compilation

Ensuite, utilisez C-x ` (next-error) pour sauter à chaque emplacement non couvert.

Quickfix Vim

Pour utiliser avec le quickfix de vim :

:cgetexpr system('cover -report compilation')
:copen

Ensuite, utilisez :cn et :cp pour naviguer entre les emplacements non couverts.

TYPES DE COUVERTURE

Le rapport de compilation prend en charge tous les types de couverture standard de Devel::Cover :

  • statement - Instructions Perl individuelles
  • branch - Chemins d'exécution conditionnels
  • condition - Combinaisons de conditions booléennes
  • subroutine - Couverture d'appel de sous-programme
  • pod - Couverture de documentation POD

Utilisez les options de commande "cover" standard pour sélectionner les types à signaler :

cover -report compilation +statement +branch +condition +subroutine +pod

FONCTIONS

print_statement($db, $file, $options)

Affiche les informations de couverture des instructions non couvertes pour le fichier spécifié. Sortie d'une ligne par instruction non couverte dans le format :

"Instruction non couverte à $file ligne $numero_ligne:"

print_branches($db, $file, $options)

Affiche les informations de couverture des branches non couvertes pour le fichier spécifié. Signale les branches où un ou deux chemins d'exécution n'ont pas été pris. Affiche des informations détaillées sur quelle condition de branche n'a jamais été vraie, fausse ou atteinte.

print_conditions($db, $file, $options)

Affiche les informations de couverture des conditions non couvertes pour le fichier spécifié. Signale les conditions logiques qui n'ont pas été entièrement exercées, en montrant quelles parties des expressions booléennes complexes n'ont pas été testées.

print_subroutines($db, $file, $options)

Affiche les informations de couverture des sous-programmes non couverts pour le fichier spécifié. Signale les sous-programmes qui n'ont jamais été appelés pendant les tests.

print_pod($db, $file, $options)

Affiche les informations de couverture de la documentation POD (Plain Old Documentation) non couverte pour le fichier spécifié. Signale les sections de documentation POD qui n'ont pas de code testé correspondant.

report($pkg, $db, $options)

Point d'entrée principal pour générer des rapports de couverture de type compilation. Itère sur tous les fichiers et appelle les fonctions d'impression appropriées en fonction des types de couverture demandés dans les options.
