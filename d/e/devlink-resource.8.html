NOM

devlink-resource - configuration des ressources du périphérique devlink

SYNTAXE


devlink [ OPTIONS ] resource { COMMANDE | help }

OPTIONS := { -v[erbose] }

devlink resource show DEV

devlink resource help

devlink resource set DEV path RESOURCE_PATH size RESOURCE_SIZE

DESCRIPTION

devlink resource show - affiche les ressources du périphérique devlink

DEV - spécifie le périphérique devlink à afficher.


Le format est :
NOM_DU_BUS/ADRESSE_DU_BUS

devlink resource set - définit la taille d'une ressource spécifique

DEV - spécifie le périphérique devlink.

path RESOURCE_PATH
Chemin de la ressource.
size RESOURCE_SIZE
La nouvelle taille de la ressource.

EXEMPLES

devlink resource show pci/0000:01:00.0

Affiche les ressources du périphérique devlink spécifié.

devlink resource set pci/0000:01:00.0 path /kvd/linear size 98304

Définit la taille de la ressource spécifiée pour le périphérique devlink spécifié.
