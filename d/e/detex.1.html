DETEX(1) Manuel des commandes générales DETEX(1)

NOM

detex - un filtre pour supprimer les commandes TeX d'un fichier .tex.

SYNTAXE

detex [ -clnstw ] [ -e liste-environnements ] [ nom-de-fichier[.tex] ... ]

DESCRIPTION

Detex lit chaque fichier séquentiellement, supprime tous les commentaires et les séquences de contrôle TeX, et écrit le reste sur la sortie standard. Tout le texte en mode mathématique et en mode d'affichage est supprimé. Par défaut, detex suit les commandes \input. Si un fichier ne peut être ouvert, un message d'avertissement est affiché et la commande est ignorée. Si l'option -n est utilisée, aucune commande \input ou \include ne sera traitée. Cela permet le traitement de fichiers uniques. Si aucun fichier d'entrée n'est donné sur la ligne de commande, detex lit depuis l'entrée standard.

Si la séquence magique ``\begin{document}'' apparaît dans le texte, detex suppose qu'il traite une source LaTeX et detex reconnaît des constructions supplémentaires utilisées dans LaTeX. Celles-ci incluent les commandes \include et \includeonly. L'option -l peut être utilisée pour forcer le mode LaTeX et l'option -t peut être utilisée pour forcer le mode TeX indépendamment du contenu d'entrée.

Le texte dans divers modes d'environnement de LaTeX est ignoré. Les modes par défaut sont array, eqnarray, equation, longtable, picture, tabular et verbatim. L'option -e peut être utilisée pour spécifier une liste-environnements séparée par des virgules d'environnements à ignorer. La liste remplace les défauts, donc spécifier une liste vide n'ignore effectivement aucun environnement.

L'option -c peut être utilisée en mode LaTeX pour que detex émette les arguments des macros \cite, \ref et \pageref. Ceci peut être utile lors de l'envoi de la sortie à un vérificateur de style.

Detex suppose que les classes de caractères standard sont utilisées pour TeX. Detex autorise les espaces entre les séquences de contrôle et les caractères magiques comme `{` lors de la reconnaissance d'éléments comme les environnements LaTeX.

L'option -r tente de remplacer naïvement $..$, $$..$$, \(..\) et \[..\] par des noms et des verbes (en particulier, "nom" et "verbes") de manière à maintenir la lisibilité des phrases.

Si le drapeau -w est donné, la sortie est une liste de mots, un `mot' (chaîne de deux lettres ou plus et apostrophes commençant par une lettre) par ligne, et tous les autres caractères sont ignorés. Sans -w la sortie suit l'original, avec les suppressions mentionnées ci-dessus. Les caractères de saut de ligne sont préservés si possible afin que les lignes de sortie correspondent le plus fidèlement possible à l'entrée.

L'option -1 préfixera chaque ligne imprimée par `nom-de-fichier:numéro-de-ligne:` indiquant l'origine de cette ligne dans le document (La)TeX original.

La variable d'environnement TEXINPUTS est utilisée pour trouver les fichiers \input et \include. Comme TeX, elle interprète un `:' en début ou en fin comme le TEXINPUTS par défaut. Elle ne prend pas en charge la séquence magique d'expansion de répertoire `//'.

Detex gère maintenant les ligatures TeX de base comme un cas spécial, remplaçant les ligatures par des substituts de caractères acceptables. Cela élimine les erreurs d'orthographe introduites par leur simple suppression. Les ligatures sont \aa, \ae, \oe, \ss, \o, \l (et leurs équivalents en majuscules). Les caractères spéciaux "sans point" \i et \j sont également remplacés par i et j respectivement.

Notez que les versions précédentes de detex remplaçaient les séquences de contrôle par un espace pour éviter que les mots ne fusionnent. Cependant, cela provoquait la rupture des mots accentués au milieu des mots, générant des "erreurs d'orthographe" non désirables. Par conséquent, la nouvelle version supprime simplement ces accents. L'ancienne fonctionnalité peut être essentiellement dupliquée en utilisant l'option -s.

VOIR AUSSI

tex(1)

DIAGNOSTICS

L'imbrication de \input est autorisée mais le nombre de fichiers ouverts ne doit pas dépasser la limite du système sur le nombre de fichiers ouverts simultanément. Detex ignore les caractères d'option non reconnus après l'affichage d'un message d'avertissement.

AUTEUR

Initialement écrit par Daniel Trinkle, Département d'Informatique, Université Purdue.

Maintenu par Piotr Kubowicz https://github.com/pkubowicz/opendetex.

BOGUES

Detex n'est pas un interpréteur TeX (il lit essentiellement l'entrée avec un programme (f)lex), il est donc facilement confondu par certaines constructions. La plupart des erreurs résultent en trop de sortie plutôt que pas assez.

Exécuter du code source LaTeX sans ``\begin{document}'' à travers detex peut produire des erreurs.

Les suggestions d'amélioration sont (légèrement) encouragées.
