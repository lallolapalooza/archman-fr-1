NOM

deb-old - format de paquet binaire Debian ancien style

SYNTAXE

nom_fichier.deb

DESCRIPTION

Le format .deb est le format de fichier de paquet binaire de Debian. Cette page de manuel décrit le format ancien, utilisé avant Debian 0.93. Veuillez consulter deb(5) pour les détails du nouveau format.

FORMAT

Le fichier est composé de deux lignes d'informations de format en texte ASCII, suivies de deux fichiers ustar concaténés et compressés avec gzip.

La première ligne est le numéro de version du format, complété à 8 chiffres, et est 0.939000 pour toutes les archives au format ancien.

La deuxième ligne est une chaîne décimale (sans zéros en tête) indiquant la longueur du premier fichier tar compressé avec gzip.

Chacune de ces lignes est terminée par un unique caractère de nouvelle ligne.

Le premier fichier tar contient les informations de contrôle, sous forme d'une série de fichiers ordinaires. Le fichier control doit être présent, car il contient les informations de contrôle principales.

Dans certaines archives très anciennes, les fichiers du tar de contrôle peuvent éventuellement se trouver dans un sous-répertoire DEBIAN. Dans ce cas, le sous-répertoire DEBIAN sera également présent dans le tar de contrôle, et le tar de contrôle ne contiendra que des fichiers dans ce répertoire. Optionnellement, le tar de contrôle peut contenir une entrée pour ‘.’, c'est-à-dire le répertoire courant.

Le second fichier tar compressé avec gzip est l'archive du système de fichiers, contenant les noms de chemins relatifs au répertoire racine du système à installer. Les noms de chemins n'ont pas de barre oblique initiale.

VOIR AUSSI

deb(5), deb-control(5), dpkg-deb(1).
