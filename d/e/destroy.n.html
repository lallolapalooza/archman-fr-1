destroy(n) Commandes intégrées Tk destroy(n)

NOM

destroy - Détruit une ou plusieurs fenêtres

SYNTAXE

destroy ?fenêtre fenêtre ...?

DESCRIPTION

Cette commande supprime les fenêtres spécifiées par les arguments fenêtre, ainsi que tous leurs descendants. Si une fenêtre “.” est supprimée, toutes les fenêtres seront détruites et l'application se terminera (normalement). Les fenêtres sont détruites dans l'ordre, et si une erreur survient lors de la destruction d'une fenêtre, la commande s'interrompt sans détruire les fenêtres restantes. Aucune erreur n'est renvoyée si la fenêtre n'existe pas.

EXEMPLE

Détruit tous les boutons de sélection qui sont des enfants directs du widget donné :

proc killCheckbuttonChildren {parent} {
   foreach w [winfo children $parent] {
      if {[winfo class $w] eq "Checkbutton"} {
         destroy $w
      }
   }
}
