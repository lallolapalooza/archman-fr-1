NOM

depdiagram-prepare - Génère des fichiers dot Graphviz pour un ou tous les frameworks

VERSION

5.13.0

UTILISATION

utilisation: depdiagram-prepare [-h] (-s DIR | -a BASE_DIR) dot_dir

arguments positionnels:
dot_dir Répertoire de destination où les fichiers dot seront générés

arguments optionnels:
-h, --help affiche ce message d'aide et quitte
-s DIR, --single DIR Génère des fichiers dot pour le framework stocké dans DIR
-a BASE_DIR, --all BASE_DIR
Génère des fichiers dot pour tous les frameworks dont le répertoire se trouve dans
BASE_DIR
