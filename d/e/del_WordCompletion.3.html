DESCRIPTIO

N

La fonction cpl_complete_word() fait partie de la bibliothèque tecla (voir la page man libtecla(3)). Elle est généralement appelée en interne par gl_get_line(3), mais peut aussi être appelée

séparément.

Étant donné une ligne d'entrée contenant un mot incomplet à compléter, elle appelle une fonction de rappel fournie par l'utilisateur (ou la fonction de rappel de complétion de fichier fournie) pour rechercher tous les suffixes de complétion possibles pour ce mot. La fonction de rappel doit parcourir la ligne vers l'arrière, à partir de la position du curseur spécifiée, pour trouver le début du mot à compléter, puis rechercher toutes les complétions possibles de ce mot et les enregistrer, une à la fois, en appelant cpl_add_comple

tion().

Les descriptions des fonctions de ce module sont les suivantes

: 
  WordCompletion *new_WordCompletion(void
)

Cette fonction crée les ressources utilisées par la fonction cpl_complete_word(). En particulier, elle gère la mémoire utilisée pour retourner les résultats de l'appel à cpl_complete_

word(). 
  WordCompletion *del_WordCompletion(WordCompletion
*cpl)

Cette fonction supprime les ressources qui ont été retournées par un appel précédent à new_WordCompletion(). Elle retourne toujours NULL (c'est-à-dire un objet supprimé). Elle ne fait rien si l'argument cpl est NULL

.

Les fonctions de rappel qui recherchent les complétions possibles doivent être définies avec la macro suivante (qui est définie dans libtecla.h)

. 
  #define CPL_MATCH_FN(fn) int (fn)(WordCompletion *cpl, \
                                    void *data, \
                                    const char *line, \
                                    int
word_end)

Les fonctions de ce type sont appelées par cpl_complete_word(), et tous les arguments de la fonction de rappel sont ceux qui ont été passés à ladite fonction. En particulier, l'argument line contient la ligne d'entrée contenant le mot à compléter, et word_end est l'index du caractère qui suit le dernier caractère du mot incomplet dans cette chaîne. La fonction de rappel doit rechercher vers l'arrière à partir de word_end pour trouver le début du mot incomplet. Ce qui constitue le début d'un mot dépend clairement de l'application, il est donc logique que la fonction de rappel assume cette responsabilité. Par exemple, la fonction intégrée de complétion de nom de fichier parcourt la ligne vers l'arrière jusqu'à trouver un espace non échappé ou le début de la ligne. Ayant trouvé le début du mot, la fonction de rappel doit ensuite rechercher toutes les complétions possibles de ce mot et enregistrer chaque complétion via des appels séparés à cpl_add_completion(). Si la fonction de rappel a besoin d'accéder à une table de symboles propre à l'application, elle peut la passer, ainsi que toute autre donnée dont elle a besoin, via l'argument data. Cela élimine tout besoin de variables

globales.

La fonction de rappel doit retourner 0 si aucune erreur ne se produit. En cas d'échec, elle doit retourner 1 et enregistrer une description concise de l'erreur en appelant cpl_record_er

ror(). 
  void cpl_record_error(WordCompletion *cpl,
                        const char *errmsg)
;

Le dernier message d'erreur enregistré par l'appel à cpl_record_error() peut ensuite être interrogé en appelant cpl_last_error(), comme décrit plus

tard. 
  int cpl_add_completion(WordCompletion *cpl,
                         const char *line, int word_start,
                         int word_end, const char *suffix,
                         const char *type_suffix,
                         const char *cont_suffix)
;

La fonction cpl_add_completion() est appelée zéro fois ou plus par la fonction de rappel de complétion pour enregistrer chaque complétion possible dans l'objet WordCompletion spécifié. Ces complétions sont ensuite retournées par cpl_complete_word(), comme décrit plus tard. Les arguments cpl, line et word_end doivent être ceux qui ont été passés à la fonction de rappel. L'argument word_start doit être l'index dans la chaîne de la ligne d'entrée du début du mot qui est en cours de complétion. Cela doit être égal à word_end si une chaîne de longueur zéro est en cours de complétion. L'argument suffix est la chaîne qui devrait être ajoutée au mot incomplet pour le compléter. Si cela nécessite un échappement (par exemple l'ajout de barres obliques inverses avant des caractères spéciaux) pour être valide dans la ligne d'entrée affichée, cela doit être inclus. Une copie de la chaîne suffix est allouée en interne, il n'est donc pas nécessaire de conserver votre copie de la chaîne après le retour de cpl_add_comple

tion().

Notez que dans le tableau des complétions possibles que la fonction cpl_complete_word() retourne, le suffixe enregistré par cpl_add_completion() est listé avec la concaténation de ce suffixe et du mot situé entre word_start et word_end dans la ligne

d'entrée.

L'argument type_suffix spécifie une chaîne optionnelle à ajouter à la complétion si elle est affichée dans le cadre d'une liste de complétions par cpl_list_completions(). L'intention est que cela indique à l'utilisateur le type de chaque complétion. Par exemple, la fonction de complétion de fichier place un séparateur de répertoire après les complétions qui sont des répertoires, pour indiquer leur nature à l'utilisateur. De même, si la complétion était une fonction, vous pourriez indiquer cela à l'utilisateur en définissant type_suffix à "()". Notez que la chaîne type_suffix n'est pas copiée, donc si l'argument n'est pas une chaîne littérale entre guillemets, assurez-vous que la chaîne reste valide au moins aussi longtemps que les résultats de cpl_complete_word() sont

nécessaires.

L'argument cont_suffix est un suffixe de continuation à ajouter au mot complété dans la ligne d'entrée si c'est la seule complétion. C'est quelque chose qui ne fait pas partie de la complétion elle-même, mais qui donne à l'utilisateur une indication sur la manière dont il pourrait continuer à étendre le jeton. Par exemple, la fonction de rappel de complétion de fichier ajoute un séparateur de répertoire si le mot complété est un répertoire. Si le mot complété était un nom de fonction, vous pourriez de même aider l'utilisateur en faisant en sorte qu'une parenthèse ouvrante soit

ajoutée. 
  CplMatches *cpl_complete_word(WordCompletion *cpl,
                                const char *line,
                                int word_end, void *data,
                                CplMatchFn *match_fn)
;

La fonction cpl_complete_word() est normalement appelée en interne par gl_get_line(3), mais peut aussi être appelée séparément si vous allouez séparément un objet WordCompletion. Elle effectue la complétion de mot, comme décrit au début de cette section. Son premier argument est un objet de ressources précédemment retourné par new_WordCompletion(). L'argument line est la chaîne de la ligne d'entrée contenant le mot à compléter. L'argument word_end contient l'index du caractère dans la ligne d'entrée qui suit immédiatement le dernier caractère du mot à compléter. Lorsqu'elle est appelée par >gl_get_line(), c'est le caractère sur lequel l'utilisateur a appuyé TAB. L'argument match_fn est le pointeur de fonction de la fonction de rappel qui recherchera les complétions possibles du mot, comme décrit ci-dessus, et l'argument data permet à l'application de passer des données arbitraires à la fonction de rappel.

En l'absence d'erreurs, la fonction cpl_complete_word() renvoie un pointeur vers un conteneur CplMatches, tel que défini ci-dessous. Ce conteneur est alloué dans le cadre de l'objet cpl qui a été passé à cpl_complete_word() et changera donc à chaque appel utilisant le même argument cpl.

  typedef struct {
    char *completion;        /* Une chaîne de complétion correspondante */
    char *suffix;            /* La partie de la chaîne de complétion qui */
                             /* devrait être ajoutée pour compléter le */
                             /* mot d'origine. */
    const char *type_suffix; /* Un suffixe à ajouter lors de */
                             /* l'affichage des complétions, pour */
                             /* indiquer le type de la complétion. */
  } CplMatch;
  typedef struct {
    char *suffix;            /* La partie initiale commune */
                             /* de tous les suffixes de complétion. */
    const char *cont_suffix; /* Chaîne de continuation optionnelle */
                             /* à ajouter à la seule complétion lorsque */
                             /* nmatch==1. */
    CplMatch *matches;       /* Le tableau de chaînes de complétion possibles, */
                             /* triées par ordre lexical. */
    int nmatch;              /* Le nombre d'éléments dans le tableau */
                             /* matches[] ci-dessus. */
  } CplMatches;

Si une erreur survient lors de la complétion, cpl_complete_word() renvoie NULL. Une description de l'erreur peut être obtenue en appelant la fonction cpl_last_error().

  const char *cpl_last_error(WordCompletion *cpl);

La fonction cpl_last_error() renvoie une description succincte de l'erreur qui s'est produite lors du dernier appel à cpl_complete_word() ou cpl_add_completion().

  CplMatches *cpl_recall_matches(WordCompletion *cpl);

Par commodité, la valeur de retour du dernier appel à cpl_complete_word() peut être rappelée ultérieurement en appelant cpl_recall_matches(). Si cpl_complete_word() a renvoyé NULL, cpl_recall_matches() le fera également.

  int cpl_list_completions(CplMatches *result, FILE *fp,
                           int terminal_width);

Lorsque la fonction cpl_complete_word() renvoie plusieurs complétions possibles, la fonction cpl_list_completions() peut être appelée pour les afficher, convenablement disposées sur la largeur disponible du terminal. Elle organise les colonnes de complétions affichées pour qu'elles aient toutes la même largeur, définie par la complétion la plus longue. Elle ajoute également les chaînes type_suffix qui ont été enregistrées avec chaque complétion, indiquant ainsi leur type à l'utilisateur.

LA FONCTION DE RAPPEL INTÉGRÉE DE COMPÉTITION DE NOM DE FICHIER

Par défaut, la fonction gl_get_line(3) passe la fonction de rappel de complétion suivante à cpl_complete_word(). Cette fonction peut également être utilisée séparément, soit en l'envoyant à cpl_complete_word(), soit en l'appelant directement depuis votre propre fonction de rappel de complétion.

  CPL_MATCH_FN(cpl_file_completions);

Certains aspects du comportement de cette fonction de rappel peuvent être modifiés via son argument data. Si vous êtes satisfait de son comportement par défaut, vous pouvez passer NULL dans cet argument. Sinon, il doit s'agir d'un pointeur vers un objet CplFileConf, alloué préalablement en appelant new_CplFileConf().

  CplFileConf *new_CplFileConf(void);

Les objets CplFileConf encapsulent les paramètres de configuration de cpl_file_completions(). Ces paramètres, qui ont des valeurs par défaut au départ, peuvent être modifiés en appelant les fonctions d'accès décrites ci-dessous.

Par défaut, la fonction de rappel cpl_file_completions() recherche en arrière le début du nom de fichier en cours de complétion, en recherchant la première espace non échappée ou le début de la ligne d'entrée. Si vous souhaitez spécifier un emplacement différent, appelez cfc_file_start() avec l'index où commence le nom de fichier dans la ligne d'entrée. Passer start_index=-1 réactive le comportement par défaut.

  void cfc_file_start(CplFileConf *cfc, int start_index);

Par défaut, lorsque cpl_file_completions() examine un nom de fichier dans la ligne d'entrée, chaque antislash seul dans la ligne d'entrée est interprété comme un caractère spécial qui supprime toute signification spéciale du caractère qui le suit, comme une espace qui doit être prise comme faisant partie du nom de fichier plutôt que de délimiter le début du nom de fichier. Ces antislashs sont donc ignorés lors de la recherche de complétions, et ajoutés ensuite avant les espaces, les tabulations et les antislashs littéraux dans la liste des complétions. Pour que les antislashs non échappés soient traités comme des caractères normaux, appelez cfc_literal_escapes() avec une valeur non nulle dans son argument literal.

  void cfc_literal_escapes(CplFileConf *cfc, int literal);

Par défaut, cpl_file_completions() signale tous les fichiers dont le nom commence par le préfixe en cours de complétion. Si vous ne voulez qu'un sous-ensemble sélectionné de ces fichiers signalés dans la liste des complétions, vous pouvez l'organiser en fournissant une fonction de rappel qui prend le chemin complet d'un fichier et renvoie 0 si le fichier doit être ignoré, ou 1 s'il doit être inclus dans la liste des complétions. Pour enregistrer une telle fonction à utiliser par cpl_file_completions(), appelez cfc_set_check_fn() et passez-lui un pointeur vers la fonction, ainsi qu'un pointeur vers les données que vous souhaitez passer à cette fonction de rappel chaque fois qu'elle est appelée. Votre fonction de rappel peut prendre ses décisions en fonction de toute propriété du fichier, comme le nom du fichier lui-même, si le fichier est lisible, inscriptible ou exécutable, voire en fonction de ce que le fichier contient.

  #define CPL_CHECK_FN(fn) int (fn)(void *data, \
                                    const char *pathname)
  typedef CPL_CHECK_FN(CplCheckFn);
  void cfc_set_check_fn(CplFileConf *cfc,
                        CplCheckFn *chk_fn, void *chk_data);

La fonction cpl_check_exe() est une fonction de rappel fournie du type ci-dessus, à utiliser avec cpl_file_completions(). Elle renvoie une valeur non nulle si le nom de fichier qu'elle reçoit représente un fichier normal pour lequel l'utilisateur a la permission d'exécution. Vous pourriez l'utiliser pour que cpl_file_completions() ne liste que les complétions de fichiers exécutables.

Lorsque vous avez terminé avec une variable CplFileConf, vous pouvez la passer à la fonction destructeur del_CplFileConf() pour récupérer sa mémoire.

  CplFileConf *del_CplFileConf(CplFileConf *cfc);

SÉCURITÉ DES THREADS

Dans les programmes multithreadés, vous devriez utiliser la version libtecla_r.a de la bibliothèque. Celle-ci utilise les fonctions POSIX réentrantes lorsque disponibles (d'où le suffixe _r) et désactive les fonctionnalités qui reposent sur des fonctions système non réentrantes. Dans le cas de ce module, la seule fonctionnalité désactivée est la complétion de nom d'utilisateur dans les expressions ~username/, dans cpl_file_completions().

En utilisant la version libtecla_r.a de la bibliothèque, il est sûr d'utiliser les facilités de ce module dans plusieurs threads, à condition que chaque thread utilise un objet WordCompletion alloué séparément. En d'autres termes, si deux threads veulent effectuer une complétion de mots, ils devraient chacun appeler new_WordCompletion() pour allouer leurs propres objets de complétion.
