NOM

Devel::Cover::Truth_Table - Tables de vérité pour les objets de couverture.

VERSION

version 1.51

SYNOPSIS

use Devel::Cover::Truth_Table;
# $a || $b
my $or_tt  = Devel::Cover::Truth_Table->new_primitive('or_3', 0, 1, 1);
# $c && $d
my $and_tt = Devel::Cover::Truth_Table->new_primitive('and_3', 1, 0, 1);
# fusionner le contenu de $and_tt dans la colonne de droite de $or_tt, pour créer
# $a || ($c && $d)
$or_tt->right_merge($and_tt);
# obtenir une représentation textuelle (triée)
my @text = $or_tt->sort->text;
print "$_\n" foreach @text;
__END__

DESCRIPTION

Ce module fournit des méthodes pour créer et fusionner des primitives conditionnelles ("$a && $b", "$c || $d", etc.) en expressions composites plus complexes.

MÉTHODES

new_primitive($op, @couverture)

Crée une nouvelle table de vérité basée sur une des primitives intégrées, qui sont des sous-classes de Devel::Cover::DB::Condition. $op est l'un des suivants :

et_3
"and" ou "&&" avec trois chemins conditionnels.
ou_3
"or" ou "||" avec trois chemins conditionnels.
ou_2
"or" ou "||" avec deux chemins conditionnels. (c'est-à-dire, lorsque le côté droit de l'expression est une constante)
xor_4
"xor" avec quatre chemins conditionnels.

@couverture est une liste de booléens identifiant quels chemins possibles ont été couverts.

sort()

Trie une table de vérité (sur place) et retourne l'objet trié.

text()

Formate une table de vérité en un tableau de chaînes pour l'affichage.

html()

Formate une table de vérité en HTML.

error()

percentage()

Détermine la proportion des conditions possibles qui ont une couverture.

fusionner_droite($table_sous_jacente)

Fusionne les entrées de $table_sous_jacente dans la colonne de droite de la table.

fusionner_gauche($table_sous_jacente)

Fusionne les entrées de $table_sous_jacente dans la colonne de gauche de la table.
