NOM

Devel::Cover::Report::Vim - Backend pour afficher les données de couverture dans Vim

VERSION

version 1.51

SYNOPSIS

cover -report vim

DESCRIPTION

Ce module fournit un mécanisme de rapport pour afficher les données de couverture dans Vim. Il est conçu pour être appelé depuis le programme "cover".

Par défaut, la sortie de ce rapport est un fichier nommé "coverage.vim" dans le répertoire de la base de données de couverture. Pour l'utiliser, exécutez

:so cover_db/coverage.vim

et vous devriez voir des signes dans la colonne de gauche indiquant l'état de couverture de cette ligne.

Les signes sont les suivants :

P - Couverture de Pod
S - Couverture d'instructions
R - Couverture de sous-programmes
B - Couverture de branches
C - Couverture de conditions

Le dernier des critères, dans l'ordre donné ci-dessus, est celui qui est affiché. Les critères correctement couverts sont affichés en vert. Les critères incorrectement couverts sont affichés en rouge. Tout critère incorrectement couvert remplacera un critère correctement couvert.

Si la couverture du fichier affiché est obsolète, la fonction appelée CoverageOld() est appelée et reçoit le nom du fichier. De même, pour les données de couverture actuelles, la fonction CoverageValid est appelée.

Les signes peuvent être remplacés dans un fichier nommé devel-cover.vim situé quelque part sous le répertoire ~/.vim.

Par exemple, j'utilise le thème solarisé et je conserve les commandes suivantes dans mon fichier de configuration local ~/.vim/local/devel-cover.vim :

let s:fg_cover = "#859900"
let s:fg_error = "#dc322f"
let s:bg_valid = "#073642"
let s:bg_old   = "#342a2a"
let s:types = [ "pod", "subroutine", "statement", "branch", "condition", ]
for s:type in s:types
    exe "highlight cov_" . s:type .       " ctermbg=1 cterm=bold gui=NONE guifg=" . s:fg_cover
    exe "highlight cov_" . s:type . "_error ctermbg=1 cterm=bold gui=NONE guifg=" . s:fg_error
endfor
exe "highlight SignColumn ctermbg=0 guibg=" . s:bg_valid
" highlight cov ctermbg=8 guibg=#002b36
" highlight err ctermbg=0 guibg=#073642
function! s:set_bg(bg)
    for s:type in s:types
        exe "highlight cov_" . s:type .       " guibg=" . a:bg
        exe "highlight cov_" . s:type . "_error guibg=" . a:bg
    endfor
    exe "highlight SignColumn ctermbg=0 guibg=" . a:bg
endfunction
function! CoverageValid(filename)
    call s:set_bg(s:bg_valid)
endfunction
function! CoverageOld(filename)
    call s:set_bg(s:bg_old)
endfunction

Cette configuration définit la couleur de fond des signes en rouge foncé lorsque les données de couverture sont obsolètes.

coverage.vim ajoute deux commandes utilisateur : :Cov et :Uncov qui peuvent être utilisées pour basculer l'état des signes de couverture.

L'idée et le modèle vim sont effrontément volés à Simplecov-Vim. Voir https://github.com/nyarly/Simplecov-Vim
