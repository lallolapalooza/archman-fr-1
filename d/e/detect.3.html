detect(3) Manuel des fonctions de bibliothèque detect(3)

NOM

detect, detect_r - Détection du jeu de caractères et mesure de la précision du jeu de caractères

SYNTAXE

#include <chardet.h>

short detect (char * inbuf, DetectObj ** outbuf);

short detect_r (char * inbuf, size_t inlen, DetectObj ** outbuf);

DESCRIPTION

Stocke le jeu de caractères et la précision de inbuf dans outbuf.

L'API detect est obsolète car elle n'est pas binaire sûre. Utilisez ou remplacez par l'API detect_r.

Arguments :

inbuf

Chaîne d'entrée pour la détection.
inlen

Longueur de la chaîne d'entrée pour la détection.
outbuf

Stocke les informations de inbuf. La structure de outbuf est la suivante : 
typedef struct DetectObject {
	char * encoding;
	float confidence;
} DetectObj;

La variable outbuf doit être initialisée avec l'API detect_obj_init avant d'appeler cette API de détection.

VALEUR DE RETOUR

Retourne les conditions suivantes en fonction des cas.

CHARDET_SUCCESS

Détection réussie.
CHARDET_NO_RESULT

Échec de la détection.
CHARDET_NULL_OBJECT

outbuf n'a pas été initialisé avec chardet_obj_init.
CHARDET_OUT_OF_MEMORY

Erreur de manque de mémoire dans une API interne.

EXEMPLE

#include <chardet.h>
int main (void) {
	DetectObj *obj;
	char * checkstr = "안녕하세요";
	if ( (obj = detect_obj_init ()) == NULL ) {
		fprintf (stderr, "Échec d'allocation mémoire\n");
		return CHARDET_MEM_ALLOCATED_FAIL;
	}
	//switch (detect (checkstr, &obj))
	switch (detect_r (checkstr, strlen (checkstr), &obj))
	{
		case CHARDET_OUT_OF_MEMORY :
			fprintf (stderr, "Lors du traitement, une erreur de manque de mémoire s'est produite\n");
			detect_obj_free (&obj);
			return CHARDET_OUT_OF_MEMORY;
		case CHARDET_NULL_OBJECT :
			fprintf (stderr,
					"Le 2ème argument de chardet() doit être alloué en mémoire "
					"avec l'API detect_obj_init\n");
			return CHARDET_NULL_OBJECT;
	}
	# vérifier la présence d'un BOM dans obj avec la constante CHARDET_BOM_CHECK
	printf ("encodage : %s, confiance : %f, bom présent : %d\n", obj->encoding, obj->confidence, obj->bom);
	detect_obj_free (&obj);
    return 0;
}
