NOM

devlink - Outil Devlink

SYNTAXE


devlink [ OPTIONS ] { dev|port|monitor|sb|resource|region|health|trap } { COMMANDE | help }

devlink [ -force ] -batch fichier

OPTIONS

-V, --Version
Affiche la version de l'utilitaire devlink et quitte.
-b, -batch <FICHIER>
Lit les commandes du fichier fourni ou de l'entrée standard et les exécute. La première erreur entraînera la terminaison de devlink.
-force
Ne pas terminer devlink en cas d'erreurs en mode batch. S'il y a eu des erreurs lors de l'exécution des commandes, le code de retour de l'application sera non nul.
-n, --no-nice-names
Désactiver l'affichage des noms conviviaux, par exemple les ifnames de périphérique réseau au lieu de l'identification du port devlink.
-j, --json
Génère une sortie JSON.
-p, --pretty
Lorsqu'il est combiné avec -j, génère une sortie JSON formatée.
-v, --verbose
Active la sortie détaillée.
-s, --statistics
Affiche les statistiques.
-N, -Netns <NOMNS>
Commute vers l'espace de noms réseau spécifié.
-i, --iec
Affiche les débits lisibles par l'homme en unités IEC (par exemple, 1Ki = 1024).
-x, --hex
Affiche les nombres de vidage au format hexadécimal.

OBJET

dev
- appareil devlink.
port
- port devlink.
monitor
- surveiller les messages netlink.
sb
- configuration du tampon partagé devlink.
resource
- configuration de la ressource de l'appareil devlink.
region
- accès à la région d'adresse devlink
health
- reporting et récupération devlink
trap
- configuration des pièges devlink

COMMANDE

Spécifie l'action à effectuer sur l'objet. L'ensemble des actions possibles dépend du type d'objet. En règle générale, il est possible de show (ou list) les objets, mais certains objets n'autorisent pas toutes ces opérations ou ont des commandes supplémentaires. La commande help est disponible pour tous les objets. Elle affiche une liste des commandes disponibles et les conventions de syntaxe des arguments.

Si aucune commande n'est donnée, une commande par défaut est supposée. Habituellement, il s'agit de list ou, si les objets de cette classe ne peuvent pas être listés, de help.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.
