DESCRIPTIO

N

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient plutôt utiliser EVP_PKEY_check(3), EVP_PKEY_public_check(3), EVP_PKEY_private_check(3) et EVP_PKEY_param_c

heck(3).

DH_generate_parameters_ex() génère des paramètres Diffie-Hellman qui peuvent être partagés entre un groupe d'utilisateurs, et les stocke dans la structure DH fournie. Le générateur de nombres pseudo-aléatoires doit être initialisé avant de l'appeler. Les paramètres générés par DH_generate_parameters_ex() ne devraient pas être utilisés dans des schémas de

signature.

prime_len est la longueur en bits du nombre premier sûr à générer. generator est un petit nombre > 1, typiquement 2 ou

5.

Une fonction de rappel peut être utilisée pour fournir des informations sur la progression de la génération de clé. Si cb n'est pas NULL, elle sera appelée comme décrit dans BN_generate_prime(3) pendant la génération d'un nombre premier aléatoire, et lorsqu'un premier a été trouvé, BN_GENCB_call(cb, 3, 0) est appelé. Voir BN_generate_prime_ex(3) pour des informations sur la fonction BN_GENCB_ca

ll().

DH_generate_parameters() est similaire à DH_generate_prime_ex() mais attend une fonction de rappel de style ancien ; voir BN_generate_prime(3) pour des informations sur la fonction de rappel de style

ancien.

DH_check_params() confirme que p et g sont suffisamment plausibles pour être valides. Il s'agit d'une vérification légère ; si une vérification plus approfondie est nécessaire, utilisez DH_check(). La valeur de *codes est mise à jour avec tout problème trouvé. Si *codes vaut zéro, aucun problème n'a été trouvé, sinon les bits suivants peuvent être définis

:

IME

premier.

Si 0 est renvoyé ou si *codes est défini à une valeur non nulle, les paramètres fournis ne devraient pas être utilisés pour les opérations Diffie-Hellman, sinon les propriétés de sécurité de l'échange de clés ne sont pas

garanties.

DH_check_ex(), DH_check_params() et DH_check_pub_key_ex() sont similaires à DH_check() et DH_check_params() respectivement, mais les raisons d'erreur sont ajoutées à la file

d'erreurs du thread au lieu d'être fournies
comme valeurs de retour de la fonction.

VALEURS DE

RETOUR

DH_generate_parameters_ex(), DH_check() et DH_check_params() renvoient 1 si la vérification a pu être effectuée, 0

sinon.

DH_generate_parameters() renvoie un pointeur vers la structure DH ou NULL si la génération des paramètres

échoue.

DH_check_ex(), DH_check_params() et DH_check_pub_key_ex() renvoient 1 si la vérification réussit, 0 en cas

d'échec.

Les codes d'erreur peuvent être obtenus avec ERR_get_

error
(3).
