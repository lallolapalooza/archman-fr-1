DHEX(1) Manuel des commandes générales DHEX(1)

NOM

dhex — éditeur hexadécimal avec mode de comparaison

SYNTAXE

dhex [-x]

dhex [-h] [-v] [-g] [-k] [-ab -ad -ah -ao adresse_de_base] [-f fichier_de_config] [-m fichier_de_marqueurs] [-ob -od -oh -oo décalage] [-r journal_de_recherche] [-sa -sab chaîne (ascii)] [-sh -shb chaîne (hex)] [-w journal_de_recherche] [fichier]

dhex [-h] [-v] [-g] [-k] [-a1b -a1d -a1h -a1o adresse_de_base1] [-a2b -a2d -a2h -a2o adresse_de_base2] [-cb] [-cd limite_supérieure] [-cl] [-f fichier_de_config] [-m fichier_de_marqueurs] [-o1b -o1d -o1h -o1o décalage1] [-o2b -o2d -o2h -o2o décalage2] [-r1 journal_recherche1] [-r2 journal_recherche2] [-s1a -s1ab -s1h -s1hb chaîne (ascii/hex)] [-s2a -s2ab -s2h -s2hb chaîne (ascii/hex)] [-w1 journal_recherche1] [-w2 journal_recherche2] [fichier1 fichier2]

DESCRIPTION

dhex est un éditeur hexadécimal. Il peut être utilisé pour modifier des octets individuels dans de grands fichiers. Comme il s'agit d'un programme en mode texte basé sur ncurses, il peut fonctionner dans de nombreux scénarios. Sa caractéristique spéciale est le mode de comparaison : avec celui-ci, l'utilisateur dispose d'un outil visuel pour la comparaison de fichiers. Ce mode est appelé lorsque dhex est appelé avec deux fichiers au lieu d'un comme paramètres.

OPTIONS

Toutes les options ne sont pas sensibles à la casse et peuvent être fournies en caractères majuscules ou minuscules.

-ab -ad -ah -ao adresse_de_base
Après avoir chargé un fichier, chaque adresse reçoit une adresse de base autre que 0. Avec cela, il est plus facile de travailler sur des dumps de mémoire partiels. L'adresse de base peut être donnée en binaire avec [-ab], en décimal avec [-ad], en hexadécimal avec [-ah] ou en octal avec [-ao].
-a1b -a1d -a1h -a1o adresse_de_base1
 
-a2b -a2d -a2h -a2o adresse_de_base2
Pour le mode de comparaison, il est possible de définir deux adresses de base différentes. Encore une fois, une adresse binaire peut être donnée avec [-a1b -a2b], en décimal avec [-a1d -a2d], en hexadécimal avec [-a1h -a2h] ou en octal avec [-a1o -a2o].

Cette adresse de base est calculée dans les fichiers de marqueurs ainsi que dans les journaux de recherche.

-cb -cl
Mode de comparaison uniquement : les fichiers d'entrée peuvent être corrélés depuis la ligne de commande avec la meilleure correspondance -cb ou la plus longue correspondance -cl. C'est très lent.
-cd limite_supérieure
Mode de comparaison uniquement : les fichiers d'entrée peuvent être corrélés depuis la ligne de commande avec la différence minimale. Pour améliorer la vitesse de corrélation, une limite supérieure peut être fournie.
-f fichier_de_config
Habituellement, .dhexrc est lu depuis le répertoire personnel de l'appelant. Avec ce paramètre, tout autre fichier de configuration peut être chargé. Voir dhexrc(5) pour une description de son format de fichier.
-g
Affiche la licence
-x
Démarre le calculateur hexadécimal
-h
Affiche l'écran d'aide
-k
Démarre la configuration du clavier manuellement avant qu'un fichier ne soit chargé. Ceci est très utile lors de l'appel de dhex depuis un terminal exotique.
-m fichier_de_marqueurs
Il est possible dans dhex de définir des marque-pages et de les stocker dans un fichier de marqueurs pour une utilisation ultérieure. Avec ce paramètre, le fichier de marqueurs est lu au démarrage, rendant inutile leur lecture ultérieure via l'interface graphique. Leur format de fichier est décrit dans dhex_markers(5).
-ob -od -oh -oo décalage
Après avoir chargé un fichier, le curseur est positionné à 0, et la première page d'octets est affichée à l'écran. Avec l'un de ces paramètres, il est possible de commencer à une autre position dans le fichier. La position du curseur peut être donnée en nombre binaire avec [-ob], en nombre décimal avec [-od], en nombre hexadécimal avec [-oh] ou en nombre octal avec [-oo].
-o1b -o1d -o1h -o1o décalage1
 
-o2b -o2d -o2h -o2o décalage2
Pour le mode de comparaison, il est possible de définir deux positions de curseur différentes au démarrage. Encore une fois, les positions du curseur peuvent être données en nombre binaire avec [-o1b -o2b], en nombre décimal avec [-o1d -o2d], en nombre hexadécimal avec [-o1h -o2h] ou en nombre octal avec [-o1o -o2o].

-r searchlog
Lors de la recherche depuis la ligne de commande, les décalages sont lus à partir de ce fichier de log de recherche. Son format est décrit dans dhex_searchlog(5).
-r1 searchlog1
 
-r2 searchlog2
Lors de la recherche simultanée dans deux fichiers, les décalages peuvent être lus à partir de deux fichiers de logs de recherche différents.
-sa -sab -sh -shb string
Au lieu de définir le décalage du curseur à une valeur absolue, il est possible de rechercher une chaîne spécifique depuis la ligne de commande. S'il y a une [-ob -od -oh -oo offset] supplémentaire présente, la recherche commencera là. Il est possible de lire et d'écrire des logs de recherche avec [-r searchlog] et [-w searchlog] respectivement. Avec [-sa string], le texte est interprété comme ASCII. -s1a -s1ab -s1h -s1hb string1
 
-s2a -s2ab -s2h -s2hb string2

-v
Affiche la version de dhex.
-w searchlog

-w1 searchlog1
 
-w2 searchlog2
Lors de la recherche simultanée dans deux fichiers, écrit les résultats des deux recherches dans ces fichiers de log.

INTERFACE UTILISATEUR

Général

Les menus ont des raccourcis clavier, ils sont présentés dans une couleur différente. Pour passer d'un élément de menu au suivant, les touches fléchées ou la touche TAB peuvent être utilisées.

Les champs de saisie peuvent être fermés en appuyant sur ESC, ENTRÉE, ou une touche fléchée. Seule la pression sur ESC n'enregistrera pas les modifications effectuées.

Configuration du clavier

Lors de la première exécution de dhex, sans fichier de configuration présent, ou avec le paramètre -k, le premier écran affiché est celui de la configuration du clavier. Dans cet écran, le programme demande à l'utilisateur d'appuyer sur certaines touches. Celles-ci sont (dans l'ordre) ÉCHAP, F1, F2, F3, F4, F5, F6, F7, F8, F9, F10, RETOUR ARRIÈRE, SUPPR, ENTRÉE, TAB, HAUT, BAS, DROITE, GAUCHE, PG SUIV, PG PRÉC, DÉBUT, FIN. Il indique également à l'utilisateur ce qu'il a l'intention de faire avec ces touches plus tard. Ainsi, l'utilisateur peut décider de n'importe quelle alternative qu'il choisit. S'il ne souhaite pas lier une fonction spécifique à une certaine touche, il peut simplement appuyer sur ÉCHAP et passer à la question suivante.

Après avoir appuyé sur toutes les touches, l'utilisateur peut choisir s'il souhaite ou non écrire ces touches dans le fichier de configuration.

Écran principal

L'écran principal est divisé en trois colonnes : la première colonne contient le décalage dans le fichier pour la ligne courante. La deuxième colonne contient les octets du fichier au format hexadécimal. Enfin, la troisième colonne contient les mêmes octets, mais cette fois au format ASCII. Si un octet n'est pas imprimable, il est remplacé par un '.'. Le nombre d'octets affichés par ligne dépend de la largeur du terminal. Par exemple, si le terminal a une largeur de 80 caractères, 16 octets sont affichés par ligne.

Si aucun autre paramètre [-o] ou [-a] n'a été donné au démarrage, le curseur est positionné au décalage 0. Il est également affiché dans la colonne hexadécimale. Ici, il peut être déplacé avec les touches fléchées. En entrant un nombre hexadécimal, le fichier est modifié. Le fichier peut également être modifié dans la colonne ASCII, simplement en appuyant sur la touche TAB (ou la touche qui lui a été substituée dans la configuration du clavier). Appuyer à nouveau sur TAB ramènera le curseur dans la colonne hexadécimale. Appuyer sur F9 (ou sa substitut) annulera la dernière modification. Les modifications sont affichées dans une couleur différente.

La modification n'est pas possible en mode différentiel. Ici, appuyer sur les touches fléchées déplacera les deux fichiers de manière synchronisée.

Écran Accéder à

Appuyer sur F1 (ou sa substitut) ouvrira l'écran Accéder à.... Ici, il est possible de sauter directement à une adresse spécifique, sans avoir à faire défiler avec les touches fléchées. L'adresse peut être saisie dans le champ 'À', soit en absolu, soit en relatif (pour sauter une quantité spécifiée d'octets). Une adresse absolue est choisie en appuyant sur '=', et une adresse relative en appuyant sur '+' ou '-', pour un saut positif ou négatif respectivement. Indépendamment du mode d'adressage, elle doit être saisie sous forme de nombre hexadécimal.

Il est également possible de définir jusqu'à dix marque-pages dans cet écran : Appuyer sur '0'...'9' sélectionnera l'un d'eux. Déplacer le curseur sur "Définir" et appuyer sur ENTRÉE modifiera l'un de ces marque-pages. Les champs "Diff :" affichent la différence entre la position actuelle du curseur et le marque-page.

Les marque-pages peuvent être enregistrés et chargés. Pour cela, il y a les éléments "Sauvegarder les marqueurs" et "Charger les marqueurs" en bas. En sélectionnant l'un d'eux, l'utilisateur est invité à saisir un nom de fichier. Il est possible de charger un fichier de marque-pages au démarrage, en fournissant le paramètre [-m fichier_marqueurs]. dhex_markers(5) décrit le format des fichiers de marqueurs.

Recherche

Appuyer sur F2 (ou sa substitut) ouvrira l'écran Rechercher.... Ici, une courte chaîne peut être saisie (soit en hexadécimal, soit en ASCII). Si aucun fichier de log n'est sélectionné, le curseur sautera à la prochaine occurrence de cette chaîne de recherche lors de la sélection de "Aller". Il est possible de choisir si la recherche doit être effectuée vers l'avant ou vers l'arrière.

Pour sauter à l'occurrence suivante, il faut appuyer sur F3 (ou sa substitut). Pour sauter à la précédente, il faut appuyer sur F4. La recherche elle-même boucle aux bords du fichier, ce qui signifie que lorsqu'elle atteint la fin, elle recommencera depuis le début et vice versa.

Les logs de recherche sont une manière avancée de rechercher : écrire dans le log de recherche ne déplace pas le curseur d'une occurrence à l'autre. Au lieu de cela, il écrira les décalages de toutes les occurrences dans le fichier de log. Leur format est décrit dans dhex_searchlog(5).

Lire à partir de ce log de recherche signifie que la recherche ne couvre pas tout le fichier : seules les adresses fournies dans ce fichier sont recherchées. Il est ainsi possible de rechercher des modifications spécifiques. Comme par exemple, le nombre de vies stocké dans le fichier de sauvegarde d'un jeu. dhex_searchlog(5) décrit le format du log de recherche.

HexCal

Appuyer sur F5 (ou sa substitut) ouvrira une petite calculatrice 64 bits. Cette calculatrice est capable non seulement d'effectuer des opérations arithmétiques (+, -, *, /, modulo), mais aussi logiques. (et, ou, xor, décalage). Il y a trois colonnes pour saisir les nombres en format hexadécimal, décimal ou binaire. Appuyer sur 'x' fermera cet écran. L'utilisation de l'argument de ligne de commande [-x] le lancera depuis la ligne de commande.

Corrélation

Lorsque dhex(1) s'exécute en mode différentiel, appuyer sur F6 (ou sa substitut) ouvrira la boîte de dialogue de corrélation de fichiers. Celle-ci tentera de trouver le décalage optimal entre les deux fichiers. Trois algorithmes sont disponibles pour trouver ce décalage : la recherche de la meilleure correspondance (autant d'octets que possible sont identiques), la correspondance la plus longue (autant d'octets consécutifs correspondent que possible), ou la différence minimale (le moins de différences possibles entre les octets).

Bien que cela semble identique au premier abord, la recherche de la différence minimale est en fait plus rapide. Cela peut être encore amélioré si l'utilisateur définit une limite supérieure de différence.

Lors de la sélection de "Aller", le programme recherchera le décalage optimal. Cela prendra un certain temps.

Sauvegarde et sortie

Appuyer sur F10 (ou sa substitut) fermera dhex. En cas de modifications apportées au fichier, une boîte de dialogue de sauvegarde s'ouvre. Ici, il est possible de choisir d'écrire ou non les modifications dans le fichier.

FICHIERS

$HOME/.dhexrc : L'emplacement par défaut du fichier de configuration. Si la variable $HOME n'est pas définie, son emplacement doit être fourni manuellement.
