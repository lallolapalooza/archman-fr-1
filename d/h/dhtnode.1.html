NOM

dhtnode - un simple programme de nœud OpenDHT en ligne de commande.

SYNOPIS

dhtnode [-h] [-v [-l fichier_journal] [-L]] [-i [--sauvegarder-identite fichier]] [-d] [-s] [-n id_reseau] [-p port_local] [-b hote_amorcage[:port]] [--certificat fichier] [--cle-privee fichier] [--mot-de-passe-cle-privee mot_de_passe] [--serveur-proxy port] [--client-proxy serveur]

DESCRIPTION

Lance un nœud OpenDHT, avec une interface en ligne de commande (par défaut) ou en tant que démon (avec '-d' ou '-s'). Les commandes disponibles dans le shell interactif sont :

    h, help    Affiche ce message d'aide.
    q, quit    Quitte le programme.
    log        Démarre/arrête l'affichage des logs DHT.
    Informations sur le nœud :
    ll         Affiche les informations de base et les statistiques sur le nœud actuel.
    ls         Affiche les informations de base sur les recherches en cours.
    ld         Affiche les informations de base sur les valeurs actuellement stockées sur ce nœud.
    lr         Affiche la table de routage complète du nœud actuel.
    Opérations sur la DHT :
    b ip:port             Envoie un ping à un nœud potentiel à l'adresse IP/port donné.
    g [cle]               Récupère les valeurs à la [clé].
    l [cle]               Écoute les changements de valeur à la [clé].
    p [cle] [str]         Stocke la chaîne de caractères à la [clé].
    s [cle] [str]         Stocke la chaîne de caractères à la [clé], signée avec notre clé privée générée.
    e [cle] [dest] [str]  Stocke la chaîne de caractères à la [clé], chiffrée pour [dest] avec sa clé publique (si trouvée).

OPTIONS

-h
Affiche une aide.
-v
Active le mode verbeux (journalisation sur stdout/stderr par défaut).
-l fichier_journal
Écrit le journal dans un fichier au lieu de stdout/stderr.
-L
Écrit le journal dans syslog au lieu de stdout/stderr.
-i
Génère une identité cryptographique pour le nœud.
--sauvegarder-identite fichier
Sauvegarde l'identité générée (certificat et clé privée) dans le préfixe de fichier donné.
--certificat fichier
Charge le certificat d'identité depuis le fichier donné.
--cle-privee fichier
Charge la clé privée d'identité depuis le fichier donné.
--mot-de-passe-cle-privee mot_de_passe
Mot de passe à utiliser pour le chiffrement ou le déchiffrement de la clé privée (optionnel).
-d
Exécute le programme en mode démon (va se forker en arrière-plan).
-s
Exécute le programme en mode service (démon non-forkant).
-D
Active la découverte automatique des pairs locaux par multidiffusion.
-f fichier
Spécifie un chemin de fichier pour persister/charger l'état du nœud.
-n id_reseau
Spécifie l'identifiant du réseau. Cela vous permet de vous connecter à des réseaux distincts et empêche la fusion de deux réseaux différents (disponible depuis OpenDHT v0.6.1).
-p port_local
Utilise le port UDP port_local pour que le programme s'y lie.
-b hote_amorcage[:port]
Le programme a besoin d'un nœud auquel se connecter pour rejoindre le réseau. Vous utilisez cette option pour fournir l'adresse IP de ce nœud.
--serveur-proxy port_local
Exécute un serveur proxy lié à ce nœud DHT sur le port HTTP port_local.
--client-proxy serveur
Exécute ce nœud DHT en mode client proxy et se connecte à serveur.
