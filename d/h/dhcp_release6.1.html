DHCP_RELEASE(1) Manuel des commandes générales DHCP_RELEASE(1)

NOM

dhcp_release6 - Libère un bail DHCPv6 sur le serveur DHCP local dnsmasq.

SYNTAXE

dhcp_release6 --iface <interface> --client-id <client-id> --server-id id-serveur --iaid <iaid> --ip <IP> [--dry-run] [--help]

DESCRIPTION

Un utilitaire qui force le serveur DHCP fonctionnant sur cette machine à libérer un bail DHCPv6.

OPTIONS

-a, --ip
Adresse IPv6 à libérer.
-c, --client-id
Chaîne hexadécimale séparée par des deux-points représentant l'ID client DHCPv6. Normalement, il peut être trouvé dans le fichier des baux, tant côté client que côté serveur.
-d, --dry-run
Affiche la représentation hexadécimale du paquet de libération DHCPv6 généré sur la sortie standard et quitte.
-h, --help
Affiche les informations d'utilisation sur la sortie standard et quitte.
-i, --iaid
Représentation décimale de l'IAID DHCPv6. Normalement, il peut être trouvé dans le fichier des baux, tant côté client que côté serveur.
-n, --iface
Interface réseau à partir de laquelle envoyer un paquet de libération DHCPv6.
-s, --server-id
Chaîne hexadécimale séparée par des deux-points représentant l'ID serveur DHCPv6. Normalement, il peut être trouvé dans le fichier des baux, tant côté client que côté serveur.

NOTES

DOIT être exécuté en tant que root - échouera sinon.

LIMITATIONS

Utilisable uniquement sur les baux DHCP IPv6.
