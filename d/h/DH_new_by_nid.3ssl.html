DH_NEW_BY_NID(3ssl) OpenSSL DH_NEW_BY_NID(3ssl)

NOM

DH_new_by_nid, DH_get_nid - créer ou obtenir des paramètres nommés DH

SYNTAXE

#include <openssl/dh.h>

Les fonctions suivantes sont obsolètes depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

DH *DH_new_by_nid(int nid);
int DH_get_nid(const DH *dh);

DESCRIPTION

DH_new_by_nid() crée et renvoie une structure DH contenant les paramètres nommés nid. Actuellement, nid doit être NID_ffdhe2048, NID_ffdhe3072, NID_ffdhe4096, NID_ffdhe6144, NID_ffdhe8192, NID_modp_1536, NID_modp_2048, NID_modp_3072, NID_modp_4096, NID_modp_6144 ou NID_modp_8192.

DH_get_nid() détermine si les paramètres contenus dans dh correspondent à un groupe de nombres premiers sûrs nommés. Il renvoie le NID correspondant aux paramètres correspondants ou NID_undef s'il n'y a pas de correspondance. Cette fonction est obsolète.

VALEURS DE RETOUR

DH_new_by_nid() renvoie un ensemble de paramètres DH ou NULL si une erreur s'est produite.

DH_get_nid() renvoie le NID de l'ensemble correspondant de paramètres pour p et g et éventuellement q, sinon il renvoie NID_undef s'il n'y a pas de correspondance.

HISTORIQUE

Toutes ces fonctions ont été déclarées obsolètes dans OpenSSL 3.0.
