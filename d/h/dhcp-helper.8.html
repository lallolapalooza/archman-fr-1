NOM

dhcp-helper - Agent de relais DHCP/BOOTP.

SYNTAXE

dhcp-helper [OPTION]...

DESCRIPTION

dhcp-helper est un agent de relais DHCP et BOOTP. Il écoute les émissions DHCP et BOOTP sur les sous-réseaux directement connectés et les relaie vers des serveurs DHCP ou BOOTP situés ailleurs. Il relaie également les réponses des serveurs distants vers les hôtes partiellement configurés. Une fois que les hôtes sont entièrement configurés, ils peuvent communiquer directement avec leurs serveurs et n'ont plus besoin des services d'un relais.

OPTIONS

La seule option requise est au moins un serveur DHCP vers lequel relayer. La manière la plus simple de configurer dhcp-helper sur un routeur est de simplement donner l'interface vers le réseau contenant le serveur DHCP avec une option -b. Toutes les autres interfaces présentes sur la machine accepteront alors les requêtes DHCP. Sur une machine qui n'a pas d'interface sur le réseau contenant le serveur DHCP, utilisez une option -s à la place.

-s <serveur>
Spécifie un serveur DHCP ou BOOTP vers lequel relayer. Le serveur peut être donné sous forme de nom de machine ou d'adresse IP en point décimal. Plus d'un serveur peut être spécifié.
-b <interface>
Relais vers un serveur DHCP ou BOOTP par diffusion via <interface>. Cela élimine la nécessité de spécifier une adresse de serveur. <interface> est automatiquement ajoutée à la liste des interfaces qui ne recevront pas de requêtes DHCP.
-i <interface>
Spécifie sur quelles interfaces locales écouter les diffusions DHCP/BOOTP. Si aucune option -i n'est donnée, toutes les interfaces sont utilisées, à l'exception de celles spécifiées par les options -e et celles spécifiées par les options -b.
-e <interface>
Spécifie quelles interfaces locales exclure.
-p
Utilise des ports alternatifs (1067/1068) pour le client et le serveur DHCP.
-v
Affiche la version du logiciel et les informations de copyright.
-d
Mode débogage, ne change pas l'UID, n'écrit pas de fichier pid et ne se lance pas en arrière-plan.
-r <fichier>
Spécifie un chemin alternatif pour que dhcp-helper enregistre son identifiant de processus. Normalement /var/run/dhcp-helper.pid.
-u <nom_utilisateur>
Spécifie l'identifiant utilisateur auquel dhcp-helper se changera après le démarrage. Le démon doit normalement être démarré en tant que root, mais il abandonnera les privilèges root après le démarrage en changeant son ID vers un autre utilisateur. Normalement, cet utilisateur est "nobody", mais cela peut être annulé avec ce commutateur.

NOTES

Dhcp-helper nécessite un noyau Linux 2.2 ou supérieur. Les facilités "filtre de paquets Linux" et "socket de paquets" ne sont *pas* requises, ce qui constitue l'avantage principal de ce logiciel par rapport au démon de relais DHCP de l'ISC.
