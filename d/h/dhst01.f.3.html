sous-routine dhst01 (integer n, integer ilo, integer ihi, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldh, * ) h, integer ldh, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( lwork ) work, integer lwork, double precision, dimension( 2 ) result)

DHST01

But:

!>
!> DHST01 teste la réduction d'une matrice générale A en forme
!> d'Hessenberg supérieure: A = Q*H*Q'. Deux rapports de test sont calculés ;
!>
!> RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!> RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
!> La matrice Q est supposée être donnée explicitement telle qu'elle apparaîtrait
!> suite à DGEHRD + DORGHR.
!>
!> Dans cette version, ILO et IHI ne sont pas utilisés et sont supposés être 1 et
!> N, respectivement.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice A.  N >= 0.
!>

ILO

!>          ILO est un entier (INTEGER)
!>

IHI

!>          IHI est un entier (INTEGER)
!>
!>          On suppose que A est triangulaire supérieure dans les lignes et
!>          colonnes 1:ILO-1 et IHI+1:N, donc Q diffère de l'identité seulement
!>          dans les lignes et colonnes ILO+1:IHI.
!>

A

!>          A est un tableau de double précision (DOUBLE PRECISION), dimension (LDA,N)
!>          La matrice originale n par n, A.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

H

!>          H est un tableau de double précision (DOUBLE PRECISION), dimension (LDH,N)
!>          La matrice d'Hessenberg supérieure H issue de la réduction A = Q*H*Q'
!>          telle que calculée par DGEHRD.  H est supposée être nulle sous la
!>          première sous-diagonale.
!>

LDH

!>          LDH est un entier (INTEGER)
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

Q

!>          Q est un tableau de double précision (DOUBLE PRECISION), dimension (LDQ,N)
!>          La matrice orthogonale Q issue de la réduction A = Q*H*Q' telle que
!>          calculée par DGEHRD + DORGHR.
!>

LDQ

!>          LDQ est un entier (INTEGER)
!>          La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

WORK

!>          WORK est un tableau de double précision (DOUBLE PRECISION), dimension (LWORK)
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La longueur du tableau WORK.  LWORK >= 2*N*N.
!>

RESULT

!>          RESULT est un tableau de double précision (DOUBLE PRECISION), dimension (2)
!>          RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
