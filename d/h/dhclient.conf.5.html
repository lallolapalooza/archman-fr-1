pseudo "[[108 ]name" "real-name " { declarations ...

}

Dans certaines circonstances, il peut être utile de déclarer une pseudo-interface et de faire acquérir au client DHCP une configuration pour cette interface. Chaque interface que le client DHCP prend en charge a normalement une machine à états de client DHCP qui s'exécute dessus pour acquérir et maintenir son bail. Une pseudo-interface est simplement une autre machine à états qui s'exécute sur l'interface nommée real-name, avec son propre bail et son propre état. Si vous utilisez cette fonctionnalité, vous devez fournir un identifiant de client pour la pseudo-interface et pour l'interface réelle, et les deux identifiants doivent être différents. Vous devez également fournir un script client séparé pour la pseudo-interface afin de faire ce que vous voulez avec l'adresse IP.

Par 
exemple :
interface "ep0" {
	send dhcp-client-identifier "my-client-ep0";
}
pseudo "secondary" "ep0" {
	send dhcp-client-identifier "my-client-ep0-secondary";
	script "/etc/dhclient-secondary";
}
Le
script

client pour la pseudo-interface ne doit pas configurer l'interface en montée ou en descente - essentiellement, tout ce qu'il a à gérer sont les états où un bail a été acquis ou renouvelé, et les états où un bail a expiré. Chaque fois que le client essaie de renouveler le bail, il utilisera ce même type de média. Le bail doit expirer avant que le client ne revienne à la boucle à travers les types de média.
