sous-routine dhsein (character side, character eigsrc, character initv, logical, dimension( * ) select, integer n, double precision, dimension( ldh, * ) h, integer ldh, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, double precision, dimension( * ) work, integer, dimension( * ) ifaill, integer, dimension( * ) ifailr, integer info)

DHSEIN

But :

!>
!> DHSEIN utilise l'itération inverse pour trouver les vecteurs propres
!> droit et/ou gauche spécifiés d'une matrice de Hessenberg supérieure réelle H.
!>
!> Le vecteur propre droit x et le vecteur propre gauche y de la matrice H
!> correspondant à une valeur propre w sont définis par :
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> où y**h désigne la transposée conjuguée du vecteur y.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R' : ne calculer que les vecteurs propres droits ;
!>          = 'L' : ne calculer que les vecteurs propres gauches ;
!>          = 'B' : calculer à la fois les vecteurs propres droits et gauches.
!>

EIGSRC

!>          EIGSRC est CHARACTER*1
!>          Spécifie la source des valeurs propres fournies dans (WR,WI) :
!>          = 'Q' : les valeurs propres ont été trouvées à l'aide de DHSEQR ; ainsi, si
!>                 H a des éléments sous-diagonaux nuls, et est donc
!>                 triangulaire par blocs, on peut supposer que la j-ième
!>                 valeur propre est une valeur propre du bloc contenant
!>                 la j-ième ligne/colonne. Cette propriété permet à DHSEIN
!>                 d'effectuer l'itération inverse sur un seul bloc diagonal.
!>          = 'N' : aucune hypothèse n'est faite sur la correspondance
!>                 entre les valeurs propres et les blocs diagonaux. Dans
!>                 ce cas, DHSEIN doit toujours effectuer l'itération inverse
!>                 en utilisant toute la matrice H.
!>

INITV

!>          INITV est CHARACTER*1
!>          = 'N' : aucun vecteur initial n'est fourni ;
!>          = 'U' : les vecteurs initiaux fournis par l'utilisateur sont stockés dans les tableaux
!>                 VL et/ou VR.
!>

SELECT

!>          SELECT est un tableau LOGICAL, dimension (N)
!>          Spécifie les vecteurs propres à calculer. Pour sélectionner le
!>          vecteur propre réel correspondant à une valeur propre réelle WR(j),
!>          SELECT(j) doit être défini à .TRUE.. Pour sélectionner le vecteur
!>          propre complexe correspondant à une valeur propre complexe
!>          (WR(j),WI(j)), avec le conjugué complexe (WR(j+1),WI(j+1)),
!>          soit SELECT(j), soit SELECT(j+1), soit les deux doivent être définis à
!>          .TRUE. ; puis à la sortie SELECT(j) est .TRUE. et SELECT(j+1) est
!>          .FALSE..
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice H.  N >= 0.
!>

H

!>          H est un tableau DOUBLE PRECISION, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>          Si un NaN est détecté dans H, la routine retournera avec INFO=-6.
!>

LDH

!>          LDH est INTEGER
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

WR

!>          WR est un tableau DOUBLE PRECISION, dimension (N)
!>

WI

!>          WI est un tableau DOUBLE PRECISION, dimension (N)
!>
!>          À l'entrée, les parties réelle et imaginaire des valeurs propres de
!>          H ; une paire conjuguée complexe de valeurs propres doit être stockée dans
!>          des éléments consécutifs de WR et WI.
!>          À la sortie, WR peut avoir été modifié car les valeurs propres proches
!>          sont légèrement perturbées lors de la recherche de vecteurs
!>          propres indépendants.
!>

VL

!>          VL est un tableau DOUBLE PRECISION, dimension (LDVL,MM)
!>          À l'entrée, si INITV = 'U' et SIDE = 'L' ou 'B', VL doit
!>          contenir les vecteurs de départ pour l'itération inverse des
!>          vecteurs propres gauches ; le vecteur de départ pour chaque vecteur propre
!>          doit être dans la ou les mêmes colonnes où le vecteur propre sera
!>          stocké.
!>          À la sortie, si SIDE = 'L' ou 'B', les vecteurs propres gauches
!>          spécifiés par SELECT seront stockés consécutivement dans les
!>          colonnes de VL, dans le même ordre que leurs valeurs propres. Un
!>          vecteur propre complexe correspondant à une valeur propre complexe est
!>          stocké en deux colonnes consécutives, la première contenant la partie
!>          réelle et la seconde la partie imaginaire.
!>          Si SIDE = 'R', VL n'est pas référencé.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale du tableau VL.
!>          LDVL >= max(1,N) si SIDE = 'L' ou 'B' ; LDVL >= 1 sinon.
!>

VR

!>          VR est un tableau DOUBLE PRECISION, dimension (LDVR,MM)
!>          À l'entrée, si INITV = 'U' et SIDE = 'R' ou 'B', VR doit
!>          contenir les vecteurs de départ pour l'itération inverse des
!>          vecteurs propres droits ; le vecteur de départ pour chaque vecteur propre
!>          doit être dans la ou les mêmes colonnes où le vecteur propre sera
!>          stocké.
!>          À la sortie, si SIDE = 'R' ou 'B', les vecteurs propres droits
!>          spécifiés par SELECT seront stockés consécutivement dans les
!>          colonnes de VR, dans le même ordre que leurs valeurs propres. Un
!>          vecteur propre complexe correspondant à une valeur propre complexe est
!>          stocké en deux colonnes consécutives, la première contenant la partie
!>          réelle et la seconde la partie imaginaire.
!>          Si SIDE = 'L', VR n'est pas référencé.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale du tableau VR.
!>          LDVR >= max(1,N) si SIDE = 'R' ou 'B' ; LDVR >= 1 sinon.
!>

MM

!>          MM est INTEGER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est INTEGER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR requis pour
!>          stocker les vecteurs propres ; chaque vecteur propre réel sélectionné
!>          occupe une colonne et chaque vecteur propre complexe sélectionné
!>          occupe deux colonnes.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension ((N+2)*N)
!>

IFAILL

!>          IFAILL est un tableau INTEGER, dimension (MM)
!>          Si SIDE = 'L' ou 'B', IFAILL(i) = j > 0 si le vecteur propre
!>          gauche dans la i-ième colonne de VL (correspondant à la
!>          valeur propre w(j)) n'a pas convergé ; IFAILL(i) = 0 si le
!>          vecteur propre a convergé de manière satisfaisante. Si la i-ième et la (i+1)ième
!>          colonnes de VL contiennent un vecteur propre complexe, alors IFAILL(i) et
!>          IFAILL(i+1) sont définis à la même valeur.
!>          Si SIDE = 'R', IFAILL n'est pas référencé.
!>

IFAILR

!>          IFAILR est un tableau INTEGER, dimension (MM)
!>          Si SIDE = 'R' ou 'B', IFAILR(i) = j > 0 si le vecteur propre
!>          droit dans la i-ième colonne de VR (correspondant à la
!>          valeur propre w(j)) n'a pas convergé ; IFAILR(i) = 0 si le
!>          vecteur propre a convergé de manière satisfaisante. Si la i-ième et la (i+1)ième
!>          colonnes de VR contiennent un vecteur propre complexe, alors IFAILR(i) et>          IFAILR(i+1) sont définis à la même valeur.
!>          Si SIDE = 'L', IFAILR n'est pas référencé.
!>

INFO

!>          INFO est de type INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, i est le nombre de vecteurs propres qui
!>                n'ont pas convergé; voir IFAILL et IFAILR pour plus de
!>                détails.
!>
