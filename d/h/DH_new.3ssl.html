DH_NEW(3ssl) OpenSSL DH_NEW(3ssl)

NOM

DH_new, DH_free - allouer et libérer des objets DH

SYNOPSIS

#include <openssl/dh.h>

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

DH* DH_new(void);
void DH_free(DH *dh);

DESCRIPTION

DH_new() alloue et initialise une structure DH.

DH_free() libère la structure DH et ses composants. Les valeurs sont effacées avant que la mémoire ne soit retournée au système. Si dh est NULL, rien n'est fait.

VALEURS DE RETOUR

Si l'allocation échoue, DH_new() retourne NULL et définit un code d'erreur qui peut être obtenu par ERR_get_error(3). Sinon, elle retourne un pointeur vers la structure nouvellement allouée.

DH_free() ne retourne aucune valeur.

VOIR AUSSI

DH_new(3), ERR_get_error(3), DH_generate_parameters(3), DH_generate_key(3), EVP_PKEY-DH(7)

HISTORIQUE

Toutes ces fonctions ont été dépréciées dans OpenSSL 3.0.

Pour le remplacement, voir EVP_PKEY-DH(7).
