DHCPCLIENT(1) Daemon FreeRADIUS DHCPCLIENT(1)

NOM

dhcpclient - Envoyer une requête DHCP avec des attributs RADIUS fournis et obtenir la réponse.

SYNTAXE

dhcpclient [-d répertoire_raddb] [-D répertoire_dictionnaires] [-f fichier] [-h] [-i interface] [-t délai] [-v] [-x] serveur[:port] {discover|request|decline|release|inform|auto}

DESCRIPTION

dhcpclient est un programme client de test DHCP. Il peut envoyer des paquets DHCP arbitraires au serveur FreeRADIUS fonctionnant en tant que serveur DHCP, puis afficher la réponse. Il peut être utilisé pour tester les modifications apportées à la configuration du serveur radius, ou pour surveiller si un serveur radius est actif.

dhcpclient lit des paires attribut/valeur radius depuis son entrée standard, ou depuis un fichier spécifié sur la ligne de commande. Il encode ensuite ces paires attribut/valeur en utilisant le dictionnaire, et les envoie au serveur local/distant.

OPTIONS

-d répertoire_raddb
Le répertoire qui contient le fichier de dictionnaire utilisateur. La valeur par défaut est /etc/raddb.
-D répertoire_dictionnaires
Le répertoire qui contient le fichier de dictionnaire principal. La valeur par défaut est /usr/share/freeradius.
-f fichier[:fichier]
Fichier à partir duquel lire les paires attribut/valeur. Si ce n'est pas spécifié, elles sont lues depuis stdin. Cette option peut être spécifiée plusieurs fois, auquel cas les paquets sont envoyés dans l'ordre par fichier, et à l'intérieur de chaque fichier, du premier paquet au dernier. Une ligne vide sépare les paquets logiques dans un fichier.
-h
Afficher l'aide sur l'utilisation.
-i interface
Sélectionner quelle interface utiliser pour envoyer/recevoir au niveau du paquet sur une socket brute.
-t délai
Attendre délai secondes avant de décider que le NAS n'a pas répondu à une requête, et de renvoyer le paquet. Ceci peut être un nombre à virgule flottante, par exemple 2.2.
-v
Afficher les informations sur la version du programme.
-x
Afficher des informations de débogage.
serveur[:port]
Le nom d'hôte ou l'adresse IP du serveur distant. Optionnellement, un port UDP peut être spécifié. Si aucun port UDP n'est spécifié, il est recherché dans /etc/services. Le nom de service recherché est radacct pour les paquets de comptabilité, et radius pour toutes les autres requêtes. Si un service n'est pas trouvé dans /etc/services, 1813 et 1812 sont utilisés respectivement.
discover | request | decline | release | inform | auto
Options DHCP - utiliser le type pertinent pour les tests
