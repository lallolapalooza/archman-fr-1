sous-routine dhsein (caractère side, caractère eigsrc, caractère initv, logique, dimension( * ) select, entier n, double précision, dimension( ldh, * ) h, entier ldh, double précision, dimension( * ) wr, double précision, dimension( * ) wi, double précision, dimension( ldvl, * ) vl, entier ldvl, double précision, dimension( ldvr, * ) vr, entier ldvr, entier mm, entier m, double précision, dimension( * ) work, entier, dimension( * ) ifaill, entier, dimension( * ) ifailr, entier info)

DHSEIN

Objectif :

!>
!> DHSEIN utilise l'itération inverse pour trouver les vecteurs propres
!> droits et/ou gauches spécifiés d'une matrice H réelle de Hessenberg supérieure.
!>
!> Le vecteur propre droit x et le vecteur propre gauche y de la matrice H
!> correspondant à une valeur propre w sont définis par :
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> où y**h dénote la transposée conjuguée du vecteur y.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R': calcul des vecteurs propres droits uniquement ;
!>          = 'L': calcul des vecteurs propres gauches uniquement ;
!>          = 'B': calcul des deux vecteurs propres droits et gauches.
!>

EIGSRC

!>          EIGSRC est CHARACTER*1
!>          Spécifie la source des valeurs propres fournies dans (WR,WI) :
!>          = 'Q': les valeurs propres ont été trouvées en utilisant DHSEQR ; donc, si
!>                 H a des éléments sous-diagonaux nuls, et est donc
!>                 triangulaire par blocs, alors la j-ème valeur propre peut
!>                 être supposée être une valeur propre du bloc contenant
!>                 la j-ème ligne/colonne. Cette propriété permet à DHSEIN de
!>                 effectuer une itération inverse sur un seul bloc diagonal.
!>          = 'N': aucune hypothèse n'est faite sur la correspondance
!>                 entre les valeurs propres et les blocs diagonaux. Dans ce
!>                 cas, DHSEIN doit toujours effectuer une itération inverse
!>                 en utilisant la matrice H entière.
!>

INITV

!>          INITV est CHARACTER*1
!>          = 'N': aucun vecteur initial n'est fourni ;
!>          = 'U': des vecteurs initiaux fournis par l'utilisateur sont stockés dans les tableaux
!>                 VL et/ou VR.
!>

SELECT

!>          SELECT est un tableau LOGICAL, de dimension (N)
!>          Spécifie les vecteurs propres à calculer. Pour sélectionner le
!>          vecteur propre réel correspondant à une valeur propre réelle WR(j),
!>          SELECT(j) doit être mis à .TRUE.. Pour sélectionner le vecteur propre
!>          complexe correspondant à une valeur propre complexe
!>          (WR(j),WI(j)), avec son conjugué complexe (WR(j+1),WI(j+1)),
!>          soit SELECT(j) soit SELECT(j+1), soit les deux, doivent être mis à
!>          .TRUE. ; alors à la sortie SELECT(j) sera .TRUE. et SELECT(j+1) sera
!>          .FALSE..
!>

N

!>          N est un entier
!>          L'ordre de la matrice H. N >= 0.
!>

H

!>          H est un tableau DOUBLE PRECISION, de dimension (LDH,N)
!>          La matrice H de Hessenberg supérieure.
!>          Si un NaN est détecté dans H, la routine retournera avec INFO=-6.
!>

LDH

!>          LDH est un entier
!>          La dimension principale du tableau H. LDH >= max(1,N).
!>

WR

!>          WR est un tableau DOUBLE PRECISION, de dimension (N)
!>

WI

!>          WI est un tableau DOUBLE PRECISION, de dimension (N)
!>
!>          À l'entrée, les parties réelles et imaginaires des valeurs propres de
!>          H ; une paire de valeurs propres conjuguées complexes doit être stockée
!>          dans des éléments consécutifs de WR et WI.
!>          À la sortie, WR peut avoir été modifié car les valeurs propres proches
!>          sont légèrement perturbées lors de la recherche de vecteurs propres
!>          indépendants.
!>

VL

!>          VL est un tableau DOUBLE PRECISION, de dimension (LDVL,MM)
!>          À l'entrée, si INITV = 'U' et SIDE = 'L' ou 'B', VL doit
!>          contenir les vecteurs de départ pour l'itération inverse des
!>          vecteurs propres gauches ; le vecteur de départ pour chaque vecteur propre
!>          doit être dans les mêmes colonnes dans lesquelles le vecteur propre sera
!>          stocké.
!>          À la sortie, si SIDE = 'L' ou 'B', les vecteurs propres gauches
!>          spécifiés par SELECT seront stockés consécutivement dans les
!>          colonnes de VL, dans le même ordre que leurs valeurs propres. Un
!>          vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la partie réelle
!>          et la seconde la partie imaginaire.
!>          Si SIDE = 'R', VL n'est pas référencé.
!>

LDVL

!>          LDVL est un entier
!>          La dimension principale du tableau VL.
!>          LDVL >= max(1,N) si SIDE = 'L' ou 'B'; LDVL >= 1 sinon.
!>

VR

!>          VR est un tableau DOUBLE PRECISION, de dimension (LDVR,MM)
!>          À l'entrée, si INITV = 'U' et SIDE = 'R' ou 'B', VR doit
!>          contenir les vecteurs de départ pour l'itération inverse des
!>          vecteurs propres droits ; le vecteur de départ pour chaque vecteur propre
!>          doit être dans les mêmes colonnes dans lesquelles le vecteur propre sera
!>          stocké.
!>          À la sortie, si SIDE = 'R' ou 'B', les vecteurs propres droits
!>          spécifiés par SELECT seront stockés consécutivement dans les
!>          colonnes de VR, dans le même ordre que leurs valeurs propres. Un
!>          vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la partie réelle
!>          et la seconde la partie imaginaire.
!>          Si SIDE = 'L', VR n'est pas référencé.
!>

LDVR

!>          LDVR est un entier
!>          La dimension principale du tableau VR.
!>          LDVR >= max(1,N) si SIDE = 'R' ou 'B'; LDVR >= 1 sinon.
!>

MM

!>          MM est un entier
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est un entier
!>          Le nombre de colonnes dans les tableaux VL et/ou VR requis pour
!>          stocker les vecteurs propres ; chaque vecteur propre réel sélectionné
!>          occupe une colonne et chaque vecteur propre complexe sélectionné
!>          occupe deux colonnes.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension ((N+2)*N)
!>

IFAILL

!>          IFAILL est un tableau entier, de dimension (MM)
!>          Si SIDE = 'L' ou 'B', IFAILL(i) = j > 0 si le vecteur propre gauche
!>          dans la i-ème colonne de VL (correspondant à la valeur propre
!>          w(j)) n'a pas convergé ; IFAILL(i) = 0 si le
!>          vecteur propre a convergé de manière satisfaisante. Si les i-ème et (i+1)-ème
!>          colonnes de VL contiennent un vecteur propre complexe, alors IFAILL(i) et
!>          IFAILL(i+1) sont mis à la même valeur.
!>          Si SIDE = 'R', IFAILL n'est pas référencé.
!>

IFAILR

!>          IFAILR est un tableau entier, de dimension (MM)
!>          Si SIDE = 'R' ou 'B', IFAILR(i) = j > 0 si le vecteur propre droit
!>          dans la i-ème colonne de VR (correspondant à la valeur propre
!>          w(j)) n'a pas convergé ; IFAILR(i) = 0 si le
!>          vecteur propre a convergé de manière satisfaisante. Si les i-ème et (i+1)-ème
!>          colonnes de VR contiennent un vecteur propre complexe, alors IFAILR(i) et
!> IFAILR(i+1) sont définis à la même valeur. !> Si SIDE = 'L', IFAILR n'est pas référencé. !>

INFO

!>          INFO est de type INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  si INFO = i, i est le nombre de vecteurs propres qui
!>                 n'ont pas convergé ; voir IFAILL et IFAILR pour plus de
!>                 détails.
!>
