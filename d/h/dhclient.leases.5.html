NOM

dhclient.leases - Base de données des baux du client DHCP

DESCRIPTION

Le client DHCP de l'Internet Systems Consortium conserve une base de données persistante des baux qu'il a acquis et qui sont encore valides. La base de données est un fichier ASCII de format libre contenant une déclaration valide par bail. Si plus d'une déclaration apparaît pour un bail donné, la dernière dans le fichier est utilisée. Le fichier est écrit comme un journal, donc ce n'est pas une occurrence inhabituelle.

Le format des déclarations de bail est décrit dans dhclient.conf(5).
