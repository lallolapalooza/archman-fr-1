DHCP_RELEASE(1) Manuel des commandes générales DHCP_RELEASE(1)

NOM

dhcp_release - Libérer une concession DHCP sur le serveur DHCP dnsmasq local.

SYNOPSIS

dhcp_release <interface> <adresse> <adresse MAC> <id_client>

DESCRIPTION

Un utilitaire qui force le serveur DHCP exécuté sur cette machine à libérer une concession DHCP.

Envoie un message DHCPRELEASE via l'interface spécifiée pour dire au serveur DHCP local de supprimer une concession particulière.

L'argument interface est l'interface sur laquelle une requête DHCP serait reçue si elle venait du client, plutôt que d'être simulée ici.

L'argument adresse est une adresse IP en point-quad et est obligatoire.

L'adresse MAC est en hexadécimal séparé par des deux-points, et est obligatoire. Elle peut être préfixée par un octet de type d'adresse suivi de -, par exemple

10-11:22:33:44:55:66

mais si l'octet de type d'adresse est manquant, il est supposé être 1, le type pour ethernet. Cet encodage est celui utilisé dans les fichiers de concessions de dnsmasq.

L'id client est optionnel. S'il s'agit de "*", il est traité comme étant manquant.

NOTES

DOIT être exécuté en tant que root - échouera sinon.

LIMITATIONS

Utilisable uniquement sur les concessions DHCP IPv4.
