Documentation de la fonction/sous-routine

double precision function dqrt17 (character trans, integer iresid, integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldb, * ) c, double precision, dimension( lwork ) work, integer lwork)

DQRT17

Objectif :

!>
!> DQRT17 calcule le rapport
!>
!>    norm(R**T * op(A)) / ( norm(A) * alpha * max(M,N,NRHS) * EPS ),
!>
!> où R = B - op(A)*X, op(A) est A ou A**T, selon TRANS, EPS
!> est l'epsilon machine, et
!>
!>    alpha = norm(B) si IRESID = 1 (problème à résidu nul)
!>    alpha = norm(R) sinon (IRESID = 2).
!>
!> La norme utilisée est la norme 1.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie si la transposée de A est utilisée ou non.
!>          = 'N':  Pas de transposée, op(A) = A.
!>          = 'T':  Transposée, op(A) = A**T.
!>

IRESID

!>          IRESID est INTEGER
!>          IRESID = 1 indique un problème à résidu nul.
!>          IRESID = 2 indique un résidu non nul.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.
!>          Si TRANS = 'N', le nombre de lignes de la matrice B.
!>          Si TRANS = 'T', le nombre de lignes de la matrice X.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.
!>          Si TRANS = 'N', le nombre de lignes de la matrice X.
!>          Si TRANS = 'T', le nombre de lignes de la matrice B.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes des matrices X et B.
!>

A

!>          A est un tableau de type DOUBLE PRECISION, de dimension (LDA,N)
!>          La matrice A de dimensions m x n.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= M.
!>

X

!>          X est un tableau de type DOUBLE PRECISION, de dimension (LDX,NRHS)
!>          Si TRANS = 'N', la matrice X de dimensions n x nrhs.
!>          Si TRANS = 'T', la matrice X de dimensions m x nrhs.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.
!>          Si TRANS = 'N', LDX >= N.
!>          Si TRANS = 'T', LDX >= M.
!>

B

!>          B est un tableau de type DOUBLE PRECISION, de dimension (LDB,NRHS)
!>          Si TRANS = 'N', la matrice B de dimensions m x nrhs.
!>          Si TRANS = 'T', la matrice B de dimensions n x nrhs.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.
!>          Si TRANS = 'N', LDB >= M.
!>          Si TRANS = 'T', LDB >= N.
!>

C

!>          C est un tableau de type DOUBLE PRECISION, de dimension (LDB,NRHS)
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, de dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK. LWORK >= NRHS*(M+N).
!>
