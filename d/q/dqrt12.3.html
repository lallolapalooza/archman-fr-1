Documentation de la fonction/sous-routine

double precision function dqrt12 (integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision, dimension( lwork ) work, integer lwork)

DQRT12

Objectif :

!>
!> DQRT12 calcule les valeurs singulières `svlues' du trapèze supérieur
!> de A(1:M,1:N) et retourne le rapport
!>
!>      || svlues - s ||/(||s||*eps*max(M,N))
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          La matrice A de taille M par N. Seul le trapèze supérieur est référencé.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (min(M,N))
!>          Les valeurs singulières de la matrice A.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK. LWORK >= max(M*N + 4*min(M,N) +
!>          max(M,N), M*N+2*MIN( M, N )+4*N).
!>
