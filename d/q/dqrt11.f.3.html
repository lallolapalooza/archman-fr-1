Documentation de la fonction/du sous-programme

double precision function dqrt11 (integer m, integer k, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) tau, double precision, dimension( lwork ) work, integer lwork)

DQRT11

But :

!>
!> DQRT11 calcule le rapport de test
!>
!>       || Q'*Q - I || / (eps * m)
!>
!> où la matrice orthogonale Q est représentée par un produit de
!> transformations élémentaires. Chaque transformation a la forme
!>
!>    H(k) = I - tau(k) v(k) v(k)'
!>
!> où tau(k) est stocké dans TAU(k) et v(k) est un vecteur m-dimensionnel de la forme
!> [ 0 ... 0 1 x(k) ]', où x(k) est un vecteur de longueur m-k stocké
!> dans A(k+1:m,k).
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.
!>

K

!>          K est un ENTIER
!>          Le nombre de colonnes de A dont les entrées sous-diagonales
!>          contiennent des informations sur les transformations orthogonales.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,K)
!>          Le résultat (potentiellement partiel) d'une routine de réduction QR.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension de tête du tableau A.
!>

TAU

!>          TAU est un tableau DOUBLE PRECISION, de dimension (K)
!>          Les facteurs d'échelle tau pour les transformations élémentaires calculés
!>          par la routine de factorisation QR.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK.  LWORK >= M*M + M.
!>
