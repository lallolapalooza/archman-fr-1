sous-programme dqrt15 (integer scale, integer rksel, integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) s, integer rank, double precision norma, double precision normb, integer, dimension( 4 ) iseed, double precision, dimension( lwork ) work, integer lwork)

DQRT15

But :

!>
!> DQRT15 génère une matrice de rang plein ou déficient et de différentes
!> normes.
!>

Paramètres

SCALE 
!>          SCALE est un entier
!>          SCALE = 1 : matrice normalement mise à l'échelle
!>          SCALE = 2 : matrice mise à l'échelle supérieurement
!>          SCALE = 3 : matrice mise à l'échelle inférieurement
!>

RKSEL

!>          RKSEL est un entier
!>          RKSEL = 1 : matrice de rang plein
!>          RKSEL = 2 : matrice de rang déficient
!>

M

!>          M est un entier
!>          Le nombre de lignes de la matrice A.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de A.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de colonnes de B.
!>

A

!>          A est un tableau de double précision, dimension (LDA,N)
!>          La matrice A de dimensions M x N.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A.
!>

B

!>          B est un tableau de double précision, dimension (LDB, NRHS)
!>          Une matrice qui se trouve dans l'espace de portée de la matrice A.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B.
!>

S

!>          S est un tableau de double précision, dimension MIN(M,N)
!>          Valeurs singulières de A.
!>

RANK

!>          RANK est un entier
!>          nombre de valeurs singulières non nulles de A.
!>

NORMA

!>          NORMA est un double précision
!>          la norme un de A.
!>

NORMB

!>          NORMB est un double précision
!>          la norme un de B.
!>

ISEED

!>          ISEED est un tableau d'entiers, dimension (4)
!>          graine pour le générateur de nombres aléatoires.
!>

WORK

!>          WORK est un tableau de double précision, dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          taille de l'espace de travail requis.
!>          LWORK >= MAX(M+MIN(M,N),NRHS*MIN(M,N),2*N+M)
!>
