NOM

dqtool --- Affiche le contenu d'un fichier de tampon disque créé avec {{ site.product.short_name }}.

SYNOPSIS

dqtool [commande] [options]

DESCRIPTION

NOTE : L'application dqtool est distribuée avec l'application de journalisation système syslog-ng OSE, et fait généralement partie du paquet syslog-ng OSE. La dernière version de l'application syslog-ng OSE est disponible sur la page syslog-ng OSE.

Cette page de manuel n'est qu'un résumé.

L'application dqtool est un utilitaire qui peut être utilisé pour afficher et formater les messages stockés dans un fichier de tampon disque.

La commande cat

cat [options] [fichier]

Utilisez la commande cat pour afficher les messages de journal stockés dans le fichier de tampon disque (également appelé file d'attente disque), ainsi que des informations de l'en-tête du fichier de file d'attente disque. Les messages sont imprimés sur la sortie standard (stdout), il est donc possible d'utiliser grep et d'autres outils pour trouver des messages de journal particuliers, par exemple, dqtool cat /var/log/messages.lgs |grep 192.168.1.1.

La commande cat a les options suivantes :

•
--debug ou -d

Imprime les messages de diagnostic et de débogage sur stderr.

•
--help ou -h

Affiche un bref message d'aide.

•
--template=<template> ou -t

Formate les messages en utilisant le modèle spécifié.

•
--verbose ou -v

Imprime les messages verbeux sur stderr.

•
--version ou -V

Affiche les informations de version.

Exemple : La commande cat

./dqtool cat ../var/syslog-ng-00000.qf

La sortie ressemble à ceci :

Disk-buffer state loaded; filename='../var/syslog-ng-00000.qf', qoutlength='65', qbackloglength='0', qoverflowlength='9205', qdisklength='0' Mar 3 10:52:05 tristram localprg[1234]: seq: 0000011630, runid: 1267609923, stamp: 2010-03-03T10:52:05 PADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADD Mar 3 10:52:05 tristram localprg[1234]: seq: 0000011631, runid: 1267609923, stamp: 2010-03-03T10:52:05 PADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADD

La commande relocate

relocate [options] [fichiers]

Utilisez la commande relocate pour déplacer ou renommer des fichiers de tampon disque (également appelés files d'attente disque). Notez que cette option modifie le fichier de persistance. Arrêtez syslog-ng OSE avant d'utiliser cette commande.

La commande relocate a les options suivantes :

•
--all ou -a

Déplace tous les fichiers de tampon disque qui sont listés dans le fichier de persistance de syslog-ng OSE.

•
--new_path ou -n

Le répertoire où vous souhaitez déplacer les fichiers de tampon disque. Par exemple : /var/disk-buffers

•
--persist ou -p

Le chemin d'accès au fichier de persistance de syslog-ng OSE. La commande relocate met à jour automatiquement les entrées des fichiers de tampon disque dans le fichier de persistance.

Exemples

Déplacer un seul fichier de file d'attente :

bin/dqtool relocate --new_path /tmp/dq --persist var/syslog-ng.persist /tmp/syslog-ng-00000.rqf

Déplacer plusieurs fichiers de file d'attente :

bin/dqtool relocate --new_path /tmp/dq --persist var/syslog-ng.persist /tmp/syslog-ng-00000.rqf /tmp/syslog-ng-00001.rqf

Déplacer tous les fichiers de file d'attente :

bin/dqtool relocate --new_path /tmp/dq --persist var/syslog-ng.persist --all
