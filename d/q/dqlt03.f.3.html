sous-programme dqlt03 (integer m, integer n, integer k, double precision, dimension( lda, * ) af, double precision, dimension( lda, * ) c, double precision, dimension( lda, * ) cc, double precision, dimension( lda, * ) q, integer lda, double precision, dimension( * ) tau, double precision, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

DQLT03

But :

!>
!> DQLT03 teste DORMQL, qui calcule Q*C, Q'*C, C*Q ou C*Q'.
!>
!> DQLT03 compare les résultats d'un appel à DORMQL avec les résultats de
!> la formation explicite de Q par un appel à DORGQL, puis de la multiplication matricielle
!> par un appel à DGEMM.
!>

Paramètres

M 
!>          M est un ENTIER
!>          L'ordre de la matrice orthogonale Q.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de lignes ou de colonnes de la matrice C ; C est m-par-n si
!>          Q est appliquée à gauche, ou n-par-m si Q est appliquée à
!>          droite.  N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflexions élémentaires dont le produit définit la
!>          matrice orthogonale Q.  M >= K >= 0.
!>

AF

!>          AF est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          Détails de la factorisation QL d'une matrice m-par-n, telle que
!>          retournée par DGEQLF. Voir SGEQLF pour plus de détails.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>

CC

!>          CC est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>

Q

!>          Q est un tableau DOUBLE PRECISION, dimension (LDA,M)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux AF, C, CC et Q.
!>

TAU

!>          TAU est un tableau DOUBLE PRECISION, dimension (min(M,N))
!>          Les facteurs scalaires des réflexions élémentaires correspondant
!>          à la factorisation QL dans AF.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur de WORK.  LWORK doit être au moins M, et devrait être
!>          M*NB, où NB est la taille du bloc pour cet environnement.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (M)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (4)
!>          Les rapports de test comparent deux techniques pour multiplier une
!>          matrice aléatoire C par une matrice orthogonale m-par-m Q.
!>          RESULT(1) = norm( Q*C - Q*C )  / ( M * norm(C) * EPS )
!>          RESULT(2) = norm( C*Q - C*Q )  / ( M * norm(C) * EPS )
!>          RESULT(3) = norm( Q'*C - Q'*C )/ ( M * norm(C) * EPS )
!>          RESULT(4) = norm( C*Q' - C*Q' )/ ( M * norm(C) * EPS )
!>
