NOM

drumstick-guiplayer - Un utilitaire graphique Drumstick pour lire des fichiers MIDI.

SYNTAXE

drumstick-guiplayer [options...] [FICHIER]

DESCRIPTION

Ce programme est un exemple et un utilitaire de Drumstick. Vous pouvez l'utiliser pour lire des fichiers Standard MIDI Files et des fichiers Cakewalk WRK avec des contrôles graphiques.

ARGUMENTS

Les arguments suivants sont optionnels :

FICHIER

Le nom du fichier d'entrée (mid/kar/wrk/rmi).

-p|--port= client:port

Port de destination MIDI.

-h|--help

Affiche un résumé des options de ligne de commande et quitte.

-v|--version

Affiche le numéro de version du programme et quitte.

-style= style

Définit le style de l'interface graphique de l'application. Les valeurs possibles sont motif, windows et platinum. Si vous avez compilé Qt avec des styles supplémentaires ou si vous avez des styles supplémentaires en tant que plugins, ils seront disponibles via l'option de ligne de commande -style

-stylesheet= stylesheet

Définit la feuille de style de l'application. La valeur doit être le chemin d'accès à un fichier contenant la feuille de style. Note : Les URL relatives dans le fichier de la feuille de style sont relatives au chemin du fichier de la feuille de style.

-session= session

Restaure l'application à partir d'une session antérieure.

-widgetcount

Affiche un message de débogage à la fin concernant le nombre de widgets laissés non détruits et le nombre maximum de widgets ayant existé en même temps

-reverse

Définit la direction de la disposition de l'application sur Qt::RightToLeft

-graphicssystem

Définit le backend à utiliser pour les widgets à l'écran et les QPixmaps. Les options disponibles sont raster et opengl.

-display display

Définit l'affichage X (par défaut $DISPLAY).

-geometry geometry

Définit la géométrie du client de la première fenêtre affichée.

-fn|-font font

Définit la police de l'application. La police doit être spécifiée à l'aide d'une description de police logique X.

-bg|-background color

Définit la couleur d'arrière-plan par défaut et une palette d'applications (les nuances claires et foncées sont calculées).

-fg|-foreground color

Définit la couleur de premier plan par défaut.

-btn|-button color

Définit la couleur de bouton par défaut.

-name name

Définit le nom de l'application.

-title title

Définit le titre de l'application.

-visual TrueColor

Force l'application à utiliser une visualisation TrueColor sur un écran 8 bits.

-ncols count

Limite le nombre de couleurs allouées dans le cube de couleurs sur un écran 8 bits, si l'application utilise la spécification de couleur QApplication::ManyColor. Si count est 216, un cube de couleurs 6x6x6 est utilisé (c'est-à-dire 6 niveaux de rouge, 6 de vert et 6 de bleu) ; pour d'autres valeurs, un cube approximativement proportionnel à un cube 2x3x1 est utilisé.

-cmap

Fait installer à l'application une carte de couleurs privée sur un écran 8 bits.

-im

Définit le serveur de méthode d'entrée (équivalent à la définition de la variable d'environnement XMODIFIERS)

-inputstyle

Définit comment l'entrée est insérée dans le widget donné, par exemple, onTheSpot fait apparaître l'entrée directement dans le widget, tandis que overTheSpot fait apparaître l'entrée dans une boîte flottante au-dessus du widget et n'est pas insérée tant que l'édition n'est pas terminée.
