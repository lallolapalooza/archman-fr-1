Paquet: postgresql

DROP FOREIGN TABLE(7) Documentation PostgreSQL 18.1 DROP FOREIGN TABLE(7)

NOM

DROP_FOREIGN_TABLE - supprimer une table étrangère

SYNOPSIS

DROP FOREIGN TABLE [ IF EXISTS ] nom [, ...] [ CASCADE | RESTRICT ]

DESCRIPTION

DROP FOREIGN TABLE supprime une table étrangère. Seul le propriétaire d'une table étrangère peut la supprimer.

PARAMÈTRES

IF EXISTS

Ne lance pas d'erreur si la table étrangère n'existe pas. Un avis est émis dans ce cas.

nom

Le nom (potentiellement qualifié par un schéma) de la table étrangère à supprimer.

CASCADE

Supprimer automatiquement les objets qui dépendent de la table étrangère (par exemple, les vues), et par conséquent tous les objets qui dépendent de ces objets (voir Section 5.15).

RESTRICT

Refuser de supprimer la table étrangère si des objets en dépendent. C'est le comportement par défaut.

EXEMPLES

Pour détruire deux tables étrangères, films et distributors :

DROP FOREIGN TABLE films, distributors;

COMPATIBILITÉ

Cette commande est conforme à la norme ISO/IEC 9075-9 (SQL/MED), à l'exception près que la norme ne permet de supprimer qu'une seule table étrangère par commande, et à l'exception de l'option IF EXISTS, qui est une extension de PostgreSQL.

VOIR AUSSI

ALTER FOREIGN TABLE (ALTER_FOREIGN_TABLE(7)), CREATE FOREIGN TABLE (CREATE_FOREIGN_TABLE(7))
