DRUMSTICK-DUMPMID(1) Commandes utilisateur DRUMSTICK-DUMPMID(1)

NOM

drumstick-dumpmid - Un utilitaire en ligne de commande Drumstick pour décoder les événements MIDI.

SYNTAXE

drumstick-dumpmid [options]

DESCRIPTION

Ce programme est un exemple et un utilitaire de Drumstick. Vous pouvez l'utiliser pour décoder les événements MIDI standard sous forme de texte.

ARGUMENTS

L'argument suivant est obligatoire :

-p|--port= client:port

Une spécification client:port ALSA qui sera souscrite afin d'en lire les événements MIDI. La partie client peut être un numéro ou un nom, comme dans "20:0" ou "Virtual Piano:0".

Les arguments suivants sont optionnels :

-h|--help

Affiche un résumé des options de la ligne de commande et quitte.

-v|--version

Affiche le numéro de version du programme et quitte.
