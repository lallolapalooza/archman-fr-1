DROP AGGREGATE(7) Documentation PostgreSQL 18.1 DROP AGGREGATE(7)

NOM

DROP_AGGREGATE - supprimer une fonction d'agrégation

SYNTAXE

DROP AGGREGATE [ IF EXISTS ] nom ( signature_agregat ) [, ...] [ CASCADE | RESTRICT ]
où signature_agregat est :
* |
[ mode_arg ] [ nom_arg ] type_arg [ , ... ] |
[ [ mode_arg ] [ nom_arg ] type_arg [ , ... ] ] ORDER BY [ mode_arg ] [ nom_arg ] type_arg [ , ... ]

DESCRIPTION

DROP AGGREGATE supprime une fonction d'agrégation existante. Pour exécuter cette commande, l'utilisateur actuel doit être le propriétaire de la fonction d'agrégation.

PARAMETRES

IF EXISTS

Ne pas générer d'erreur si l'agrégat n'existe pas. Un avis est émis dans ce cas.

nom

Le nom (éventuellement qualifié par le schéma) d'une fonction d'agrégation existante.

mode_arg

Le mode d'un argument : IN ou VARIADIC. Si omis, la valeur par défaut est IN.

nom_arg

Le nom d'un argument. Notez que DROP AGGREGATE ne prête en fait aucune attention aux noms des arguments, car seuls les types de données des arguments sont nécessaires pour déterminer l'identité de la fonction d'agrégation.

type_arg

Un type de données d'entrée sur lequel opère la fonction d'agrégation. Pour faire référence à une fonction d'agrégation sans argument, écrivez * à la place de la liste des spécifications d'arguments. Pour faire référence à une fonction d'agrégation d'ensemble ordonné, écrivez ORDER BY entre les spécifications des arguments directs et agrégés.

CASCADE

Supprimer automatiquement les objets qui dépendent de la fonction d'agrégation (comme les vues qui l'utilisent), et à leur tour tous les objets qui dépendent de ces objets (voir la Section 5.15).

RESTRICT

Refuser de supprimer la fonction d'agrégation si des objets en dépendent. C'est le comportement par défaut.

NOTES

Les syntaxes alternatives pour faire référence aux agrégats d'ensembles ordonnés sont décrites dans ALTER AGGREGATE (ALTER_AGGREGATE(7)).

EXEMPLES

Pour supprimer la fonction d'agrégation myavg pour le type integer :

DROP AGGREGATE myavg(integer);

Pour supprimer la fonction d'agrégation hypothetical-set myrank, qui prend une liste arbitraire de colonnes de tri et une liste correspondante d'arguments directs :

DROP AGGREGATE myrank(VARIADIC "any" ORDER BY VARIADIC "any");

Pour supprimer plusieurs fonctions d'agrégation en une seule commande :

DROP AGGREGATE myavg(integer), myavg(bigint);

COMPATIBILITÉ

Il n'existe pas de commande DROP AGGREGATE dans la norme SQL.

VOIR AUSSI

ALTER AGGREGATE (ALTER_AGGREGATE(7)), CREATE AGGREGATE (CREATE_AGGREGATE(7))
