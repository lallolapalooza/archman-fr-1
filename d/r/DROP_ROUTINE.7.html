DROP_ROUTINE(7)

Paquet: postgresql

Licences: PostgreSQL

DROP ROUTINE(7) Documentation PostgreSQL 18.1 DROP ROUTINE(7)

NOM

DROP ROUTINE - supprimer une routine

SYNTAXE

DROP ROUTINE [ IF EXISTS ] nom [ ( [ [ mode_arg ] [ nom_arg ] type_arg [, ...] ] ) ] [, ...]
    [ CASCADE | RESTRICT ]

DESCRIPTION

DROP ROUTINE supprime la définition d'une ou plusieurs routines existantes. Le terme « routine » inclut les fonctions agrégées, les fonctions normales et les procédures. Voir DROP AGGREGATE (DROP_AGGREGATE(7)), DROP FUNCTION (DROP_FUNCTION(7)), et DROP PROCEDURE (DROP_PROCEDURE(7)) pour la description des paramètres, plus d'exemples et de détails.

NOTES

Les règles de recherche utilisées par DROP ROUTINE sont fondamentalement les mêmes que celles de DROP PROCEDURE ; en particulier, DROP ROUTINE partage le comportement de cette commande consistant à considérer une liste d'arguments sans marqueurs mode_arg comme pouvant utiliser la définition de la norme SQL selon laquelle les arguments OUT sont inclus dans la liste. (DROP AGGREGATE et DROP FUNCTION ne font pas cela.)

Dans certains cas où le même nom est partagé par des routines de différents types, il est possible que DROP ROUTINE échoue avec une erreur d'ambiguïté alors qu'une commande plus spécifique (DROP FUNCTION, etc.) fonctionnerait. La spécification plus attentive de la liste des types d'arguments résoudra également ces problèmes.

Ces règles de recherche sont également utilisées par d'autres commandes agissant sur des routines existantes, telles que ALTER ROUTINE et COMMENT ON ROUTINE.

EXEMPLES

Pour supprimer la routine foo pour le type entier :

DROP ROUTINE foo(integer);

Cette commande fonctionnera, que foo soit un agrégat, une fonction ou une procédure.

COMPATIBILITÉ

Cette commande est conforme à la norme SQL, avec les extensions PostgreSQL suivantes :

•La norme ne permet de supprimer qu'une seule routine par commande.
•L'option IF EXISTS est une extension.
•La capacité de spécifier les modes et noms d'arguments est une extension, et les règles de recherche diffèrent lorsque des modes sont fournis.
•Les fonctions agrégées définissables par l'utilisateur sont une extension.

VOIR AUSSI

DROP AGGREGATE (DROP_AGGREGATE(7)), DROP FUNCTION (DROP_FUNCTION(7)), DROP PROCEDURE (DROP_PROCEDURE(7)), ALTER ROUTINE (ALTER_ROUTINE(7))

Notez qu'il n'y a pas de commande CREATE ROUTINE.
