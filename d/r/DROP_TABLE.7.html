NOM

DROP_TABLE - supprimer une table

SYNTAXE

DROP TABLE [ IF EXISTS ] nom [, ...] [ CASCADE | RESTRICT ]

DESCRIPTION

DROP TABLE supprime des tables de la base de données. Seul le propriétaire de la table, le propriétaire du schéma et un superutilisateur peuvent supprimer une table. Pour vider une table de ses lignes sans détruire la table, utilisez DELETE ou TRUNCATE.

DROP TABLE supprime toujours les index, règles, déclencheurs et contraintes qui existent pour la table cible. Cependant, pour supprimer une table référencée par une vue ou une contrainte de clé étrangère d'une autre table, il faut spécifier CASCADE. (CASCADE supprimera complètement une vue dépendante, mais dans le cas d'une clé étrangère, il ne supprimera que la contrainte de clé étrangère, pas l'autre table entièrement.)

PARAMETRES

IF EXISTS

Ne génère pas d'erreur si la table n'existe pas. Un message est émis dans ce cas.

nom

Le nom (éventuellement qualifié par le schéma) de la table à supprimer.

CASCADE

Supprime automatiquement les objets qui dépendent de la table (tels que les vues), et par conséquent tous les objets qui dépendent de ces objets (voir la Section 5.15).

RESTRICT

Refuse de supprimer la table si des objets en dépendent. C'est le comportement par défaut.

EXEMPLES

Pour détruire deux tables, films et distributeurs :

DROP TABLE films, distributeurs;

COMPATIBILITE

Cette commande est conforme à la norme SQL, à l'exception près que la norme ne permet qu'une seule table à supprimer par commande, et à l'exception de l'option IF EXISTS, qui est une extension PostgreSQL.

VOIR AUSSI

ALTER TABLE (ALTER_TABLE(7)), CREATE TABLE (CREATE_TABLE(7))
