DRUMSTICK-DUMPRMI(1) Commandes utilisateur DRUMSTICK-DUMPRMI(1)

NOM

drumstick-dumprmi - Un utilitaire en ligne de commande Drumstick pour décoder les fichiers RIFF MIDI.

SYNTAXE

drumstick-dumprmi [options] {FICHIER}

DESCRIPTION

Ce programme est un exemple et un utilitaire de Drumstick. Vous pouvez l'utiliser pour décoder un fichier RIFF MIDI sous forme de texte, ou pour extraire les données intégrées dans des fichiers MIDI et DLS standard.

ARGUMENTS

L'argument suivant est requis :

FICHIER

Le nom du fichier RMI d'entrée.

Les arguments suivants sont optionnels :

-h|--help

Affiche un résumé des options de ligne de commande et quitte.

-v|--version

Affiche le numéro de version du programme et quitte.

-e|--extract

Extrait les données intégrées dans un fichier Standard MIDI séparé et dans un fichier DLS.
