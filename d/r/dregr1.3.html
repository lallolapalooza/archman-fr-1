No transpose, operation is Y = ALPHA*A*X + BETA*Y.

`'T'`

Transpose, operation is Y = ALPHA*A**T*X + BETA*Y.

`'C'`

Conjugate transpose, operation is Y = ALPHA*A**H*X + BETA*Y.

`INTEGER M`

The number of rows of the matrix A. M >= 0.

`INTEGER N`

The number of columns of the matrix A. N >= 0.

`INTEGER LY`

The number of elements of the vector Y. LY >= (1 + (M-1)*ABS(INC Y)) if TRANS = 'N', and LY >= (1 + (N-1)*ABS(INC Y)) if TRANS = 'T' or 'C'.

`INTEGER KL`

The number of subdiagonals of the matrix A. KL >= 0.

`INTEGER KU`

The number of superdiagonals of the matrix A. KU >= 0.

`DOUBLE PRECISION ALPHA`

The scalar factor of A.

`DOUBLE PRECISION, DIMENSION( LDA, * ) A`

The matrix A. LDA is the leading dimension of the array A. If TRANS = 'N', LDA must be at least max(1, M), and if TRANS = 'T' or 'C', LDA must be at least max(1, N).

`INTEGER LDA`

The leading dimension of the array A.

`DOUBLE PRECISION, DIMENSION( * ) X`

The vector X. The dimension of X must be at least max(1, 1 + (N-1)*ABS(INCX)) if TRANS = 'N', and max(1, 1 + (M-1)*ABS(INCX)) if TRANS = 'T' or 'C'.

`INTEGER INCX`

The increment between elements of X.

`DOUBLE PRECISION BETA`

The scalar factor of Y.

`DOUBLE PRECISION, DIMENSION( * ) Y`

The vector Y. The dimension of Y must be at least max(1, 1 + (M-1)*ABS(INCY)) if TRANS = 'N', and max(1, 1 + (N-1)*ABS(INCY)) if TRANS = 'T' or 'C'.

`INTEGER INCY`

The increment between elements of Y.

`DOUBLE PRECISION, DIMENSION( * ) YS`

The vector YS. YS is a scratch space. The dimension of YS must be at least max(1, N) if TRANS = 'N', and max(1, M) if TRANS = 'T' or 'C'.

Description

DREGR1 performs one of the matrix-vector operations

y = alpha*A*x + beta*y,

y = alpha*A**T*x + beta*y,

or

y = alpha*A**H*x + beta*y,

where A is an M-by-N band matrix with KL subdiagonals and KU superdiagonals, x and y are vectors, and alpha and beta are scalars. A**T denotes the transpose of A, and A**H denotes the conjugate transpose of A.

This routine is a modified version of the BLAS level 2 routine DGEMV. It is intended for use in the iterative refinement routines of LAPACK.
