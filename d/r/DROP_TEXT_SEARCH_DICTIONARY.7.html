DROP TEXT SEARCH DICTIONARY(7) Documentation PostgreSQL 18.1 DROP TEXT SEARCH DICTIONARY(7)

NOM

DROP_TEXT_SEARCH_DICTIONARY - supprime un dictionnaire de recherche textuelle

SYNTAXE

DROP TEXT SEARCH DICTIONARY [ IF EXISTS ] nom [ CASCADE | RESTRICT ]

DESCRIPTION

DROP TEXT SEARCH DICTIONARY supprime un dictionnaire de recherche textuelle existant. Pour exécuter cette commande, vous devez être le propriétaire du dictionnaire.

PARAMÈTRES

IF EXISTS

Ne génère pas d'erreur si le dictionnaire de recherche textuelle n'existe pas. Un message est émis dans ce cas.

nom

Le nom (éventuellement qualifié par le schéma) d'un dictionnaire de recherche textuelle existant.

CASCADE

Supprime automatiquement les objets qui dépendent du dictionnaire de recherche textuelle, et par conséquent tous les objets qui dépendent de ces objets (voir Section 5.15).

RESTRICT

Refuse de supprimer le dictionnaire de recherche textuelle si des objets en dépendent. C'est le comportement par défaut.

EXEMPLES

Supprimer le dictionnaire de recherche textuelle english :

DROP TEXT SEARCH DICTIONARY english;

Cette commande ne réussira pas s'il existe des configurations de recherche textuelle qui utilisent ce dictionnaire. Ajoutez CASCADE pour supprimer ces configurations ainsi que le dictionnaire.

COMPATIBILITÉ

Il n'existe pas d'instruction DROP TEXT SEARCH DICTIONARY dans la norme SQL.

VOIR AUSSI

ALTER TEXT SEARCH DICTIONARY (ALTER_TEXT_SEARCH_DICTIONARY(7)), CREATE TEXT SEARCH DICTIONARY (CREATE_TEXT_SEARCH_DICTIONARY(7))
