DROPSTATISTICS(7) Documentation PostgreSQL 18.1 DROPSTATISTICS(7)

NOM

DROP_STATISTICS - supprime les statistiques étendues

SYNTAXE

DROP STATISTICS [ IF EXISTS ] nom [, ...] [ CASCADE | RESTRICT ]

DESCRIPTION

DROP STATISTICS supprime un ou plusieurs objets de statistiques de la base de données. Seul le propriétaire de l'objet de statistiques, le propriétaire du schéma ou un superutilisateur peut supprimer un objet de statistiques.

PARAMETRES

IF EXISTS

Ne génère pas d'erreur si l'objet de statistiques n'existe pas. Un message est émis dans ce cas.

nom

Le nom (éventuellement qualifié par le schéma) de l'objet de statistiques à supprimer.

CASCADE
RESTRICT

Ces mots-clés n'ont aucun effet, car il n'y a aucune dépendance sur les statistiques.

EXEMPLES

Pour supprimer deux objets de statistiques dans des schémas différents, sans générer d'erreur s'ils n'existent pas :

DROP STATISTICS IF EXISTS
    accounting.users_uid_creation,
    public.grants_user_role;

COMPATIBILITE

Il n'existe pas de commande DROP STATISTICS dans la norme SQL.

VOIR AUSSI

ALTER STATISTICS (ALTER_STATISTICS(7)), CREATE STATISTICS (CREATE_STATISTICS(7))
