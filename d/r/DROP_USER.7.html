DROP USER(7) Documentation PostgreSQL 18.1 DROP USER(7)

NOM

DROP USER - supprimer un rôle de base de données

SYNTAXE

DROP USER [ IF EXISTS ] nom [, ...]

DESCRIPTION

DROP USER est simplement une autre orthographe pour DROP ROLE.

COMPATIBILITÉ

L'instruction DROP USER est une extension PostgreSQL. La norme SQL laisse la définition des utilisateurs à l'implémentation.

VOIR AUSSI

DROP ROLE (DROP_ROLE(7))
