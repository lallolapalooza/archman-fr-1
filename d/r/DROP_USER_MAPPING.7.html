DROP USER MAPPING(7) Documentation PostgreSQL 18.1 DROP USER MAPPING(7)

NOM

DROP USER MAPPING - supprime un mappage d'utilisateur pour un serveur étranger

SYNTAXE

DROP USER MAPPING [ IF EXISTS ] FOR { nom_utilisateur | USER | CURRENT_ROLE | CURRENT_USER | PUBLIC } SERVER nom_serveur

DESCRIPTION

DROP USER MAPPING supprime un mappage d'utilisateur existant depuis un serveur étranger.

Le propriétaire d'un serveur étranger peut supprimer des mappages d'utilisateur pour ce serveur pour n'importe quel utilisateur. De plus, un utilisateur peut supprimer un mappage d'utilisateur pour son propre nom d'utilisateur si le privilège USAGE sur le serveur a été accordé à l'utilisateur.

PARAMETRES

IF EXISTS

Ne génère pas d'erreur si le mappage d'utilisateur n'existe pas. Une notification est émise dans ce cas.

nom_utilisateur

Nom d'utilisateur du mappage. CURRENT_ROLE, CURRENT_USER et USER correspondent au nom de l'utilisateur courant. PUBLIC est utilisé pour correspondre à tous les noms d'utilisateur présents et futurs dans le système.

nom_serveur

Nom du serveur du mappage d'utilisateur.

EXEMPLES

Supprimer le mappage d'utilisateur bob pour le serveur foo s'il existe :

DROP USER MAPPING IF EXISTS FOR bob SERVER foo;

COMPATIBILITE

DROP USER MAPPING est conforme à la norme ISO/IEC 9075-9 (SQL/MED). La clause IF EXISTS est une extension de PostgreSQL.

VOIR AUSSI

CREATE USER MAPPING (CREATE_USER_MAPPING(7)), ALTER USER MAPPING (ALTER_USER_MAPPING(7))
