DROP OPERATOR CLASS(7) Documentation PostgreSQL 18.1 DROP OPERATOR CLASS(7)

NOM

DROP_OPERATOR_CLASS - supprimer une classe d'opérateurs

SYNTAXE

DROP OPERATOR CLASS [ IF EXISTS ] nom USING methode_index [ CASCADE | RESTRICT ]

DESCRIPTION

DROP OPERATOR CLASS supprime une classe d'opérateurs existante. Pour exécuter cette commande, vous devez être le propriétaire de la classe d'opérateurs.

DROP OPERATOR CLASS ne supprime aucun des opérateurs ou fonctions référencés par la classe. S'il existe des index dépendant de la classe d'opérateurs, vous devrez spécifier CASCADE pour que la suppression aboutisse.

PARAMETRES

IF EXISTS

Ne génère pas d'erreur si la classe d'opérateurs n'existe pas. Un avis est émis dans ce cas.

nom

Le nom (éventuellement qualifié par un schéma) d'une classe d'opérateurs existante.

methode_index

Le nom de la méthode d'accès aux index pour laquelle la classe d'opérateurs est définie.

CASCADE

Supprimer automatiquement les objets qui dépendent de la classe d'opérateurs (tels que les index), et par conséquent tous les objets qui dépendent de ces objets (voir la Section 5.15).

RESTRICT

Refuser la suppression de la classe d'opérateurs si des objets en dépendent. C'est le comportement par défaut.

NOTES

DROP OPERATOR CLASS ne supprimera pas la famille d'opérateurs contenant la classe, même s'il n'y a plus rien d'autre dans la famille (en particulier, dans le cas où la famille a été créée implicitement par CREATE OPERATOR CLASS). Une famille d'opérateurs vide est inoffensive, mais pour des raisons de propreté, vous pourriez vouloir supprimer la famille avec DROP OPERATOR FAMILY ; ou mieux encore, utiliser DROP OPERATOR FAMILY en premier lieu.

EXEMPLES

Supprimer la classe d'opérateurs B-tree widget_ops :

DROP OPERATOR CLASS widget_ops USING btree;

Cette commande ne réussira pas s'il existe des index qui utilisent la classe d'opérateurs. Ajoutez CASCADE pour supprimer ces index ainsi que la classe d'opérateurs.

COMPATIBILITÉ

Il n'existe pas d'instruction DROP OPERATOR CLASS dans la norme SQL.

VOIR AUSSI

ALTER OPERATOR CLASS (ALTER_OPERATOR_CLASS(7)), CREATE OPERATOR CLASS (CREATE_OPERATOR_CLASS(7)), DROP OPERATOR FAMILY (DROP_OPERATOR_FAMILY(7))
