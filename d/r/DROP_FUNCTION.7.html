DROP_FUNCTION(7)

Paquet: postgresql

Licences: PostgreSQL

DROP FUNCTION(7) Documentation PostgreSQL 18.1 DROP FUNCTION(7)

NOM

DROP_FUNCTION - supprimer une fonction

SYNTAXE

DROP FUNCTION [ IF EXISTS ] nom [ ( [ [ mode_arg ] [ nom_arg ] type_arg [, ...] ] ) ] [, ...]
    [ CASCADE | RESTRICT ]

DESCRIPTION

DROP FUNCTION supprime la définition d'une fonction existante. Pour exécuter cette commande, l'utilisateur doit être le propriétaire de la fonction. Les types d'arguments de la fonction doivent être spécifiés, car plusieurs fonctions différentes peuvent exister sous le même nom et avec des listes d'arguments différentes.

PARAMETRES

IF EXISTS

Ne génère pas d'erreur si la fonction n'existe pas. Un avis est émis dans ce cas.

nom

Le nom (éventuellement qualifié par un schéma) d'une fonction existante. Si aucune liste d'arguments n'est spécifiée, le nom doit être unique dans son schéma.

mode_arg

Le mode d'un argument : IN, OUT, INOUT, ou VARIADIC. Si omis, la valeur par défaut est IN. Notez que DROP FUNCTION ne tient pas réellement compte des arguments OUT, car seuls les arguments d'entrée sont nécessaires pour déterminer l'identité de la fonction. Il suffit donc de lister les arguments IN, INOUT et VARIADIC.

nom_arg

Le nom d'un argument. Notez que DROP FUNCTION ne tient pas réellement compte des noms d'arguments, car seuls les types de données des arguments sont nécessaires pour déterminer l'identité de la fonction.

type_arg

Le(s) type(s) de données des arguments de la fonction (éventuellement qualifié(s) par un schéma), le cas échéant.

CASCADE

Supprime automatiquement les objets qui dépendent de la fonction (tels que les opérateurs ou les déclencheurs), et en retour tous les objets qui dépendent de ces objets (voir la Section 5.15).

RESTRICT

Refuse de supprimer la fonction si des objets en dépendent. C'est le comportement par défaut.

EXEMPLES

Cette commande supprime la fonction racine carrée :

DROP FUNCTION sqrt(integer);

Supprimer plusieurs fonctions en une seule commande :

DROP FUNCTION sqrt(integer), sqrt(bigint);

Si le nom de la fonction est unique dans son schéma, il peut être fait référence sans liste d'arguments :

DROP FUNCTION update_employee_salaries;

Notez que c'est différent de

DROP FUNCTION update_employee_salaries();

qui fait référence à une fonction sans argument, tandis que la première variante peut faire référence à une fonction avec un nombre quelconque d'arguments, y compris zéro, tant que le nom est unique.

COMPATIBILITE

Cette commande est conforme à la norme SQL, avec ces extensions PostgreSQL :

•La norme n'autorise qu'une seule fonction à supprimer par commande.
•L'option IF EXISTS
•La capacité de spécifier les modes et les noms des arguments
