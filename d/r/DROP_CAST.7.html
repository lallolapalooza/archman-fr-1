DROP CAST(7) Documentation PostgreSQL 18.1 DROP CAST(7)

NOM

DROP_CAST - supprimer une conversion de type

SYNTAXE

DROP CAST [ IF EXISTS ] (type_source AS type_cible) [ CASCADE | RESTRICT ]

DESCRIPTION

DROP CAST supprime une conversion de type définie précédemment.

Pour pouvoir supprimer une conversion, vous devez posséder le type de données source ou cible. Ce sont les mêmes privilèges qui sont requis pour créer une conversion.

PARAMÈTRES

IF EXISTS

Ne génère pas d'erreur si la conversion n'existe pas. Une notice est émise dans ce cas.

type_source

Le nom du type de données source de la conversion.

type_cible

Le nom du type de données cible de la conversion.

CASCADE
RESTRICT

Ces mots-clés n'ont aucun effet, car il n'y a pas de dépendances sur les conversions.

EXEMPLES

Pour supprimer la conversion du type text vers le type int :

DROP CAST (text AS int);

COMPATIBILITÉ

La commande DROP CAST est conforme à la norme SQL.

VOIR AUSSI

CREATE CAST (CREATE_CAST(7))
