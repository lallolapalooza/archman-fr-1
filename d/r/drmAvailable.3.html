drmAvailable(3) Direct Rendering Manager drmAvailable(3)

Nom

drmAvailable - déterminer si un pilote noyau DRM a été chargé

Synopsis

#include <xf86drm.h>

int drmAvailable(void);

Description

drmAvailable permet à l'appelant de déterminer si un pilote DRM du noyau est chargé.

Valeur de retour

drmAvailable retourne 1 si un pilote DRM est actuellement chargé. Sinon, 0 est retourné.

Rapporter les bogues

Les bogues dans cette fonction doivent être signalés sur https://gitlab.freedesktop.org/mesa/libdrm/-/issues

Voir aussi

drm(7), drmOpen(3)
