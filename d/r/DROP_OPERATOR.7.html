DROP_OPERATOR(7)

Paquet: postgresql

Licences: PostgreSQL

DROP OPERATOR(7) Documentation PostgreSQL 18.1 DROP OPERATOR(7)

NOM

DROP_OPERATOR - supprimer un opérateur

SYNTAXE

DROP OPERATOR [ IF EXISTS ] nom ( { type_gauche | NONE } , type_droit ) [, ...] [ CASCADE | RESTRICT ]

DESCRIPTION

DROP OPERATOR supprime un opérateur existant du système de base de données. Pour exécuter cette commande, vous devez être le propriétaire de l'opérateur.

PARAMETRES

IF EXISTS

Ne génère pas d'erreur si l'opérateur n'existe pas. Un message d'avis est émis dans ce cas.

nom

Le nom (éventuellement qualifié par un schéma) d'un opérateur existant.

type_gauche

Le type de données de l'opérande gauche de l'opérateur ; écrire NONE si l'opérateur n'a pas d'opérande gauche.

type_droit

Le type de données de l'opérande droit de l'opérateur.

CASCADE

Supprime automatiquement les objets qui dépendent de l'opérateur (comme les vues qui l'utilisent), et à leur tour tous les objets qui dépendent de ces objets (voir Section 5.15).

RESTRICT

Refuse de supprimer l'opérateur si des objets en dépendent. C'est le comportement par défaut.

EXEMPLES

Supprimer l'opérateur de puissance a^b pour le type entier :

DROP OPERATOR ^ (integer, integer);

Supprimer l'opérateur préfixe de complément bit à bit ~b pour le type bit :

DROP OPERATOR ~ (none, bit);

Supprimer plusieurs opérateurs en une seule commande :

DROP OPERATOR ~ (none, bit), ^ (integer, integer);

COMPATIBILITE

Il n'y a pas d'instruction DROP OPERATOR dans la norme SQL.

VOIR AUSSI

CREATE OPERATOR (CREATE_OPERATOR(7)), ALTER OPERATOR (ALTER_OPERATOR(7))
