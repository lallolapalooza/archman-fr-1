DROP_RULE(7)

Paquet: postgresql

Licences: PostgreSQL

DROP RULE(7) Documentation PostgreSQL 18.1 DROP RULE(7)

NOM

DROP_RULE - supprimer une règle de réécriture

SYNTAXE

DROP RULE [ IF EXISTS ] nom ON nom_table [ CASCADE | RESTRICT ]

DESCRIPTION

DROP RULE supprime une règle de réécriture.

PARAMÈTRES

IF EXISTS

Ne lance pas d'erreur si la règle n'existe pas. Un avis est émis dans ce cas.

nom

Le nom de la règle à supprimer.

nom_table

Le nom (éventuellement qualifié par un schéma) de la table ou de la vue sur laquelle la règle s'applique.

CASCADE

Supprimer automatiquement les objets qui dépendent de la règle, et par conséquent tous les objets qui dépendent de ces objets (voir Section 5.15).

RESTRICT

Refuser de supprimer la règle si des objets en dépendent. C'est le comportement par défaut.

EXEMPLES

Pour supprimer la règle de réécriture newrule :

DROP RULE newrule ON mytable;

COMPATIBILITÉ

DROP RULE est une extension du langage PostgreSQL, tout comme l'ensemble du système de réécriture de requêtes.

VOIR AUSSI

CREATE RULE (CREATE_RULE(7)), ALTER RULE (ALTER_RULE(7))
