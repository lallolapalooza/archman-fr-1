DROP PUBLICATION(7) Documentation PostgreSQL 18.1 DROP PUBLICATION(7)

NOM

DROP PUBLICATION - supprimer une publication

SYNTAXE

DROP PUBLICATION [ IF EXISTS ] nom [, ...] [ CASCADE | RESTRICT ]

DESCRIPTION

DROP PUBLICATION supprime une publication existante de la base de données.

Une publication ne peut être supprimée que par son propriétaire ou par un superutilisateur.

PARAMETRES

IF EXISTS

Ne pas générer d'erreur si la publication n'existe pas. Un avis est émis dans ce cas.

nom

Le nom d'une publication existante.

CASCADE
RESTRICT

Ces mots-clés n'ont aucun effet, car il n'y a aucune dépendance vis-à-vis des publications.

EXEMPLES

Supprimer une publication :

DROP PUBLICATION ma_publication;

COMPATIBILITE

DROP PUBLICATION est une extension de PostgreSQL.

VOIR AUSSI

CREATE PUBLICATION (CREATE_PUBLICATION(7)), ALTER PUBLICATION (ALTER_PUBLICATION(7))
