double précision fonction drzt02 (entier m, entier n, double précision, dimension( lda, * ) af, entier lda, double précision, dimension( * ) tau, double précision, dimension( lwork ) work, entier lwork)

DRZT02

But :

!>
!> DRZT02 retourne
!>      || I - Q'*Q || / ( M * eps)
!> où la matrice Q est définie par les transformations de Householder
!> générées par DTZRZF.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice AF.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice AF.
!>

AF

!>          AF est un tableau DOUBLE PRÉCISION, de dimension (LDA,N)
!>          La sortie de DTZRZF.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau AF.
!>

TAU

!>          TAU est un tableau DOUBLE PRÉCISION, de dimension (M)
!>          Détails des transformations de Householder retournés par
!>          DTZRZF.
!>

WORK

!>          WORK est un tableau DOUBLE PRÉCISION, de dimension (LWORK)
!>

LWORK

!>          LWORK est ENTIER
!>          longueur du tableau WORK. LWORK >= N*N+N*NB.
!>
