NOM

DROP_TABLESPACE - supprimer un tablespace

SYNTAXE

DROP TABLESPACE [ IF EXISTS ] name

DESCRIPTION

DROP TABLESPACE supprime un tablespace du système.

Un tablespace ne peut être supprimé que par son propriétaire ou un superutilisateur. Le tablespace doit être vide de tout objet de base de données avant de pouvoir être supprimé. Il est possible que des objets dans d'autres bases de données résident encore dans le tablespace même si aucun objet dans la base de données actuelle n'utilise ce tablespace. De plus, si le tablespace est listé dans le paramètre temp_tablespaces de toute session active, la commande DROP pourrait échouer en raison de fichiers temporaires résidant dans le tablespace.

PARAMÈTRES

IF EXISTS

Ne génère pas d'erreur si le tablespace n'existe pas. Un message de notification est émis dans ce cas.

name

Le nom d'un tablespace.

NOTES

DROP TABLESPACE ne peut pas être exécuté à l'intérieur d'un bloc transactionnel.

EXEMPLES

Pour supprimer le tablespace mystuff du système :

DROP TABLESPACE mystuff;

COMPATIBILITÉ

DROP TABLESPACE est une extension PostgreSQL.

VOIR AUSSI

CREATE TABLESPACE (CREATE_TABLESPACE(7)), ALTER TABLESPACE (ALTER_TABLESPACE(7))
