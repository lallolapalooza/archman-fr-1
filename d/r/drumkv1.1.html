DRUMKV1(1) Manuel des commandes générales DRUMKV1(1)

NOM

drumkv1 - un échantillonneur de kit de batterie old-school

SYNTAXE

drumkv1_jack [options] [fichier-preset]

DESCRIPTION

Cette page de manuel documente brièvement la commande drumkv1_jack.

drumkv1 est un synthétiseur échantillonneur de kit de batterie old-school avec effets stéréo.

Fonctionnalités :

un client JACK autonome avec prise en charge de JACK-session, NSM et d'entrées MIDI JACK et ALSA ;
un plugin instrument LV2. URI : http://drumkv1.sourceforge.net/lv2

OPTIONS

-g, --no-gui

Désactive l'interface graphique utilisateur (GUI)

-n, --client-name=[étiquette]

Définit le nom du client JACK (par défaut : drumkv1)

-h, --help

Affiche l'aide concernant les options de la ligne de commande

-v, --version

Affiche les informations sur la version

FICHIERS

Les paramètres de configuration sont stockés dans ~/.config/rncbc.org/drumkv1.conf
