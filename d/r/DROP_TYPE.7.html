NOM

DROP_TYPE - supprimer un type de données

SYNTAXE

DROP TYPE [ IF EXISTS ] nom [, ...] [ CASCADE | RESTRICT ]

DESCRIPTION

DROP TYPE supprime un type de données défini par l'utilisateur. Seul le propriétaire d'un type peut le supprimer.

PARAMETRES

IF EXISTS

Ne génère pas d'erreur si le type n'existe pas. Un avis est émis dans ce cas.

nom

Le nom (éventuellement qualifié par le schéma) du type de données à supprimer.

CASCADE

Supprime automatiquement les objets qui dépendent du type (tels que les colonnes de table, les fonctions et les opérateurs), et à leur tour tous les objets qui dépendent de ces objets (voir Section 5.15).

RESTRICT

Refuse de supprimer le type si des objets en dépendent. C'est le comportement par défaut.

EXEMPLES

Pour supprimer le type de données box :

DROP TYPE box;

COMPATIBILITE

Cette commande est similaire à la commande correspondante dans la norme SQL, à l'exception de l'option IF EXISTS, qui est une extension PostgreSQL. Mais notez qu'une grande partie de la commande CREATE TYPE et des mécanismes d'extension de types de données dans PostgreSQL diffèrent de la norme SQL.

VOIR AUSSI

ALTER TYPE (ALTER_TYPE(7)), CREATE TYPE (CREATE_TYPE(7))
