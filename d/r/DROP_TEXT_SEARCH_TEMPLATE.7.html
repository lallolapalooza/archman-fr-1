DROP TEXT SEARCH TEMPLATE(7) Documentation PostgreSQL 18.1 DROP TEXT SEARCH TEMPLATE(7)

NAME

DROP_TEXT_SEARCH_TEMPLATE - supprimer un modèle de recherche textuelle

SYNOPSIS

DROP TEXT SEARCH TEMPLATE [ IF EXISTS ] nom [ CASCADE | RESTRICT ]

DESCRIPTION

DROP TEXT SEARCH TEMPLATE supprime un modèle de recherche textuelle existant. Vous devez être superutilisateur pour utiliser cette commande.

PARAMETERS

IF EXISTS

Ne pas générer d'erreur si le modèle de recherche textuelle n'existe pas. Une notification est émise dans ce cas.

nom

Le nom (éventuellement qualifié par un schéma) d'un modèle de recherche textuelle existant.

CASCADE

Supprimer automatiquement les objets qui dépendent du modèle de recherche textuelle, et par conséquent tous les objets qui dépendent de ces objets (voir Section 5.15).

RESTRICT

Refuser de supprimer le modèle de recherche textuelle si des objets en dépendent. C'est le comportement par défaut.

EXAMPLES

Supprimer le modèle de recherche textuelle thesaurus :

DROP TEXT SEARCH TEMPLATE thesaurus;

Cette commande ne réussira pas s'il existe des dictionnaires de recherche textuelle utilisant ce modèle. Ajoutez CASCADE pour supprimer ces dictionnaires avec le modèle.

COMPATIBILITY

Il n'existe pas d'instruction DROP TEXT SEARCH TEMPLATE dans la norme SQL.

SEE ALSO

ALTER TEXT SEARCH TEMPLATE (ALTER_TEXT_SEARCH_TEMPLATE(7)), CREATE TEXT SEARCH TEMPLATE (CREATE_TEXT_SEARCH_TEMPLATE(7))
