drmHandleEvent(3) Gestionnaire de rendu direct drmHandleEvent(3)

Nom

drmHandleEvent - lire et traiter les événements DRM en attente

Synopsis

#include <xf86drm.h>

int drmHandleEvent(int fd, drmEventContextPtr evctx);

Description

drmHandleEvent traite les événements DRM en attente sur le descripteur de fichier DRM passé en argument fd. Cette fonction doit être appelée après que le descripteur de fichier DRM ait été marqué comme lisible ; elle lira les événements et utilisera la structure evctx passée pour appeler des pointeurs de fonction avec les paramètres notés ci-dessous :

typedef struct _drmEventContext {
    int version;
    void (*vblank_handler) (int fd,
                            unsigned int sequence,
                            unsigned int tv_sec,
                            unsigned int tv_usec,
                            void *user_data)
    void (*page_flip_handler) (int fd,
                               unsigned int sequence,
                               unsigned int tv_sec,
                               unsigned int tv_usec,
                               void *user_data)
} drmEventContext, *drmEventContextPtr;

Valeur de retour

drmHandleEvent retourne 0 en cas de succès, ou s'il n'y a pas de données à lire depuis le descripteur de fichier. Retourne -1 si la lecture sur le descripteur de fichier échoue ou retourne moins qu'un enregistrement d'événement complet.

Rapporter les bogues

Les bogues de cette fonction doivent être signalés à https://gitlab.freedesktop.org/mesa/libdrm/-/issues

Voir aussi

drm(7), drm-kms(7), drmModePageFlip(3), drmWaitVBlank(3)
