NOM

dropbearkey - créer des clés privées pour l'utilisation avec dropbear(8) ou dbclient(1)

SYNTAXE

dropbearkey -t type -f fichier [-s bits] [-y]

DESCRIPTION

dropbearkey génère une clé privée SSH au format RSA, DSS, ECDSA ou Ed25519, et l'enregistre dans un fichier pour une utilisation avec le client ou le serveur Dropbear. Notez que certaines implémentations SSH utilisent le terme « DSA » plutôt que « DSS », ils signifient la même chose.

OPTIONS

-t type
Type de clé à générer. Doit être l'un des éléments suivants : rsa, ecdsa, ed25519 ou dss.
-f fichier
Écrit la clé secrète dans le fichier fichier. Pour l'authentification client, ~/.ssh/id_dropbear est chargé par défaut.
-s bits
Définit la taille de la clé à bits bits, doit être un multiple de 8 (facultatif).
-y
Affiche simplement la clé publique et l'empreinte pour la clé privée dans fichier.

NOTES

Le programme dropbearconvert(1) peut être utilisé pour convertir entre les formats de clés Dropbear et OpenSSH.

Dropbear ne prend pas en charge les clés chiffrées.

EXEMPLE

Générer une clé d'hôte :
# dropbearkey -t rsa -f /etc/dropbear/dropbear_rsa_host_key

Extraire une clé publique adaptée pour authorized_keys à partir d'une clé privée :
# dropbearkey -y -f id_rsa | grep "^ssh-rsa " >> authorized_keys
