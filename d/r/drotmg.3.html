sous-routine drotmg (double precision dd1, double precision dd2, double precision dx1, double precision dy1, double precision, dimension(5) dparam)

DROTMG

Objectif :

!>
!>    CONSTRUIRE LA MATRICE DE TRANSFORMATION DE GIVENS MODIFIÉE H QUI ANNULE
!>    LE DEUXIÈME COMPOSANT DU VECTEUR 2-DIEMNSIONNEL  (DSQRT(DD1)*DX1,DSQRT(DD2)*>    DY2)**T.
!>    AVEC DPARAM(1)=DFLAG, H A L'UNE DES FORMES SUIVANTES..
!>
!>    DFLAG=-1.D0     DFLAG=0.D0        DFLAG=1.D0     DFLAG=-2.D0
!>
!>      (DH11  DH12)    (1.D0  DH12)    (DH11  1.D0)    (1.D0  0.D0)
!>    H=(          )    (          )    (          )    (          )
!>      (DH21  DH22),   (DH21  1.D0),   (-1.D0 DH22),   (0.D0  1.D0).
!>    LES LOCATIONS 2-4 DE DPARAM CONTIENNENT DH11, DH21, DH12, ET DH22
!>    RESPECTIVEMENT. (LES VALEURS DE 1.D0, -1.D0, OU 0.D0 IMPLIQUÉES PAR LA
!>    VALEUR DE DPARAM(1) NE SONT PAS STOCKÉES DANS DPARAM.)
!>
!>    LES VALEURS DE GAMSQ ET RGAMSQ DÉFINIES DANS L'INSTRUCTION DATA PEUVENT
!>    ÊTRE INEXACTES. CECI EST ACCEPTABLE CAR ELLES SONT UNIQUEMENT UTILISÉES
!>    POUR TESTER LA TAILLE DE DD1 ET DD2. TOUTE LA MISE À L'ÉCHELLE EFFECTIVE
!>    DES DONNÉES EST FAITE EN UTILISANT GAM.
!>
!>

Paramètres

DD1 
!>          DD1 est DOUBLE PRECISION
!>

DD2

!>          DD2 est DOUBLE PRECISION
!>

DX1

!>          DX1 est DOUBLE PRECISION
!>

DY1

!>          DY1 est DOUBLE PRECISION
!>

DPARAM

!>          DPARAM est un tableau DOUBLE PRECISION, dimension (5)
!>     DPARAM(1)=DFLAG
!>     DPARAM(2)=DH11
!>     DPARAM(3)=DH21
!>     DPARAM(4)=DH12
!>     DPARAM(5)=DH22
!>
