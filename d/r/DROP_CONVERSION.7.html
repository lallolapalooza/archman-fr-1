DROP CONVERSION(7) Documentation PostgreSQL 18.1 DROP CONVERSION(7)

NOM

DROP_CONVERSION - supprimer une conversion

SYNTAXE

DROP CONVERSION [ IF EXISTS ] nom [ CASCADE | RESTRICT ]

DESCRIPTION

DROP CONVERSION supprime une conversion précédemment définie. Pour pouvoir supprimer une conversion, vous devez en être le propriétaire.

PARAMETRES

IF EXISTS

Ne génère pas d'erreur si la conversion n'existe pas. Un message d'information est émis dans ce cas.

nom

Le nom de la conversion. Le nom de la conversion peut être qualifié par un schéma.

CASCADE
RESTRICT

Ces mots clés n'ont aucun effet, car il n'y a pas de dépendances sur les conversions.

EXEMPLES

Pour supprimer la conversion nommée monnom :

DROP CONVERSION monnom;

COMPATIBILITE

Il n'existe pas d'instruction DROP CONVERSION dans la norme SQL, mais une instruction DROP TRANSLATION qui accompagne l'instruction CREATE TRANSLATION, similaire à l'instruction CREATE CONVERSION dans PostgreSQL.

VOIR AUSSI

ALTER CONVERSION (ALTER_CONVERSION(7)), CREATE CONVERSION (CREATE_CONVERSION(7))
