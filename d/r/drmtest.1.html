DRMTEST(1) Manuel des commandes générales DRMTEST(1)

NOM

drmtest - afficher une image de test

SYNTAXE

drmtest [options]

DESCRIPTION

drmtest affiche une image de test à l'écran.

OPTIONS

-h
Affiche les informations d'utilisation.
-c num
Choisit la carte graphique.
-o nom
Choisit la sortie (utilisez drminfo(1) pour afficher les choix valides).
-s sec
Définit le temps d'attente. La valeur par défaut est 60 secondes. Toute pression de touche quittera également drmtest.
-i fichier
Charge et affiche le fichier image donné au lieu de l'écran de test. Prend en charge les fichiers png et jpeg.
-f fmt
Choisit le format du framebuffer.
