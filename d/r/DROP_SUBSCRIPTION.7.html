DROP SUBSCRIPTION(7) Documentation PostgreSQL 18.1 DROP SUBSCRIPTION(7)

NOM

DROP_SUBSCRIPTION - supprimer un abonnement

SYNTAXE

DROP SUBSCRIPTION [ IF EXISTS ] nom [ CASCADE | RESTRICT ]

DESCRIPTION

DROP SUBSCRIPTION supprime un abonnement du cluster de bases de données.

Pour exécuter cette commande, l'utilisateur doit être le propriétaire de l'abonnement.

DROP SUBSCRIPTION ne peut pas être exécuté à l'intérieur d'un bloc de transaction si l'abonnement est associé à un slot de réplication. (Vous pouvez utiliser ALTER SUBSCRIPTION pour désactiver le slot.)

PARAMETRES

nom

Le nom d'un abonnement à supprimer.

CASCADE
RESTRICT

Ces mots-clés n'ont aucun effet, car il n'y a aucune dépendance sur les abonnements.

NOTES

Lors de la suppression d'un abonnement associé à un slot de réplication sur l'hôte distant (l'état normal), DROP SUBSCRIPTION se connectera à l'hôte distant et essaiera de supprimer le slot de réplication (et tous les slots de synchronisation de table restants) dans le cadre de son opération. Ceci est nécessaire pour que les ressources allouées à l'abonnement sur l'hôte distant soient libérées. Si cela échoue, soit parce que l'hôte distant n'est pas accessible, soit parce que le slot de réplication distant ne peut pas être supprimé ou n'existe pas ou n'a jamais existé, la commande DROP SUBSCRIPTION échouera. Pour procéder dans cette situation, désactivez d'abord l'abonnement en exécutant ALTER SUBSCRIPTION ... DISABLE, puis dissociez-le du slot de réplication en exécutant ALTER SUBSCRIPTION ... SET (slot_name = NONE). Après cela, DROP SUBSCRIPTION n'effectuera plus aucune action sur un hôte distant. Notez que si le slot de réplication distant existe toujours, il (et tout slot de synchronisation de table associé) devrait alors être supprimé manuellement ; sinon il continuera à réserver du WAL et pourrait éventuellement provoquer le remplissage du disque. Voir également la Section 29.2.1.

Si un abonnement est associé à un slot de réplication, alors DROP SUBSCRIPTION ne peut pas être exécuté à l'intérieur d'un bloc de transaction.

EXEMPLES

Supprimer un abonnement :

DROP SUBSCRIPTION mon_abonnement;

COMPATIBILITE

DROP SUBSCRIPTION est une extension PostgreSQL.

VOIR AUSSI

CREATE SUBSCRIPTION (CREATE_SUBSCRIPTION(7)), ALTER SUBSCRIPTION (ALTER_SUBSCRIPTION(7))
