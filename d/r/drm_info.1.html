NOM

drm_info - afficher des informations sur les périphériques DRM

SYNTAXE

drm_info [-j] [périphérique]...

DESCRIPTION

drm_info est un petit utilitaire pour afficher des informations sur les périphériques DRM.

périphérique doit être le chemin d'un périphérique DRM, par exemple "/dev/dri/card0". S'il n'est pas spécifié, tous les périphériques disponibles sont affichés.

OPTIONS

-j

Afficher les informations au format JSON. Par défaut, la sortie sera formatée de manière lisible par l'homme.

AUTEURS

Créé par Scott Anderson <scott@anderso.nz>, maintenu par Simon Ser <contact@emersion.fr>. Pour plus d'informations sur le développement de drm_info, voir https://gitlab.freedesktop.org/emersion/drm_info.
