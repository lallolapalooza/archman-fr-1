NOM

dropdb - supprimer une base de données PostgreSQL

SYNTAXE

dropdb [option-connexion...] [option...] nomdb

DESCRIPTION

dropdb détruit une base de données PostgreSQL existante. L'utilisateur qui exécute cette commande doit être un superutilisateur de la base de données ou le propriétaire de la base de données.

dropdb est un wrapper autour de la commande SQL DROP DATABASE. Il n'y a aucune différence effective entre la suppression de bases de données via cet utilitaire et via d'autres méthodes d'accès au serveur.

OPTIONS

dropdb accepte les arguments de ligne de commande suivants :

nomdb

Spécifie le nom de la base de données à supprimer.

-e
--echo

Affiche les commandes que dropdb génère et envoie au serveur.

-f
--force

Tente de terminer toutes les connexions existantes à la base de données cible avant de la supprimer. Voir DROP DATABASE (DROP_DATABASE(7)) pour plus d'informations sur cette option.

-i
--interactive

Demande une confirmation avant d'effectuer toute opération destructrice.

-V
--version

Affiche la version de dropdb et quitte.

--if-exists

Ne génère pas d'erreur si la base de données n'existe pas. Un avis est émis dans ce cas.

-?
--help

Affiche l'aide sur les arguments de la ligne de commande de dropdb et quitte.

dropdb accepte également les arguments de ligne de commande suivants pour les paramètres de connexion :

-h hôte
--host=hôte

Spécifie le nom d'hôte de la machine sur laquelle le serveur s'exécute. Si la valeur commence par un slash, elle est utilisée comme répertoire pour le socket Unix.

-p port
--port=port

Spécifie le port TCP ou l'extension du fichier de socket Unix local sur lequel le serveur écoute les connexions.

-U nomutilisateur
--username=nomutilisateur

Nom d'utilisateur pour se connecter.

-w
--no-password

Ne demande jamais de mot de passe. Si le serveur exige une authentification par mot de passe et qu'un mot de passe n'est pas disponible par d'autres moyens, tels qu'un fichier .pgpass, la tentative de connexion échouera. Cette option peut être utile dans les travaux par lots et les scripts où aucun utilisateur n'est présent pour saisir un mot de passe.

-W
--password

Force dropdb à demander un mot de passe avant de se connecter à une base de données.

Cette option n'est jamais essentielle, car dropdb demandera automatiquement un mot de passe si le serveur l'exige. Cependant, dropdb gaspillera une tentative de connexion pour découvrir que le serveur veut un mot de passe. Dans certains cas, il vaut la peine de taper -W pour éviter la tentative de connexion supplémentaire.

--maintenance-db=nomdb

Spécifie le nom de la base de données à laquelle se connecter pour supprimer la base de données cible. Si non spécifié, la base de données postgres sera utilisée ; si elle n'existe pas (ou est la base de données en cours de suppression), template1 sera utilisée. Il peut s'agir d'une chaîne de connexion. Si c'est le cas, les paramètres de la chaîne de connexion remplaceront toute option de ligne de commande conflictuelle.

ENVIRONNEMENT

PGHOST
PGPORT
PGUSER

Paramètres de connexion par défaut

PG_COLOR

Spécifie si les couleurs doivent être utilisées dans les messages de diagnostic. Les valeurs possibles sont toujours, auto et jamais.

Cet utilitaire, comme la plupart des autres utilitaires PostgreSQL, utilise également les variables d'environnement prises en charge par libpq (voir la section 32.15).

DIAGNOSTICS

En cas de difficultés, consultez DROP DATABASE (DROP_DATABASE(7)) et psql(1) pour des discussions sur les problèmes potentiels et les messages d'erreur. Le serveur de base de données doit être en cours d'exécution sur l'hôte ciblé. De plus, tous les paramètres de connexion par défaut et les variables d'environnement utilisés par la bibliothèque front-end libpq s'appliqueront.

EXEMPLES

Pour détruire la base de données demo sur le serveur de base de données par défaut :

$ dropdb demo

Pour détruire la base de données demo en utilisant le serveur sur l'hôte eden, port 5000, avec confirmation et un aperçu de la commande sous-jacente :

$ dropdb -p 5000 -h eden -i -e demo
La base de données "demo" sera définitivement supprimée.
Êtes-vous sûr ? (o/n) o
DROP DATABASE demo;
