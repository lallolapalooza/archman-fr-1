DROP TEXT SEARCH PARSER(7) Documentation PostgreSQL 18.1 DROP TEXT SEARCH PARSER(7)

NOM

DROP_TEXT_SEARCH_PARSER - supprimer un analyseur de recherche textuelle

SYNTAXE

DROP TEXT SEARCH PARSER [ IF EXISTS ] nom [ CASCADE | RESTRICT ]

DESCRIPTION

DROP TEXT SEARCH PARSER supprime un analyseur de recherche textuelle existant. Vous devez être superutilisateur pour utiliser cette commande.

PARAMETRES

IF EXISTS

Ne génère pas d'erreur si l'analyseur de recherche textuelle n'existe pas. Un avis est émis dans ce cas.

nom

Le nom (éventuellement qualifié par le schéma) d'un analyseur de recherche textuelle existant.

CASCADE

Supprime automatiquement les objets qui dépendent de l'analyseur de recherche textuelle, et par conséquent tous les objets qui dépendent de ces objets (voir Section 5.15).

RESTRICT

Refuse de supprimer l'analyseur de recherche textuelle si des objets en dépendent. C'est le comportement par défaut.

EXEMPLES

Supprimer l'analyseur de recherche textuelle my_parser :

DROP TEXT SEARCH PARSER my_parser;

Cette commande ne réussira pas s'il existe des configurations de recherche textuelle qui utilisent l'analyseur. Ajoutez CASCADE pour supprimer également ces configurations.

COMPATIBILITE

Il n'y a pas d'instruction DROP TEXT SEARCH PARSER dans la norme SQL.

VOIR AUSSI

ALTER TEXT SEARCH PARSER (ALTER_TEXT_SEARCH_PARSER(7)), CREATE TEXT SEARCH PARSER (CREATE_TEXT_SEARCH_PARSER(7))
