NOM

driverless - utilitaire de génération de PPD pour l'impression sans pilote

SYNTAXE

driverless [-h | --help | --version] [-d | -v | --debug] [list] [_ipps._tcp] [_ipp._tcp] [--std-ipp-uris] | [cat URI_du_pilote] | [URI_imprimante_IPP]

DESCRIPTION

driverless génère des fichiers PPD pour les imprimantes conçues pour l'impression IPP sans pilote (actuellement les imprimantes IPP Everywhere, AirPrint, Mopria et Wi-Fi-Direct, les imprimantes réseau, ainsi que les imprimantes IPP-over-USB avec l'aide d'ippusbxd(8)) en interrogeant les informations de capacité des imprimantes via IPP. Il peut être appelé soit pour lister les imprimantes appropriées sur le réseau, soit pour générer réellement le PPD. Il peut également être appelé par CUPS lorsque CUPS liste les PPD/pilotes disponibles ou crée des files d'attente d'impression, rendant la configuration des imprimantes sans pilote transparente avec les outils de configuration d'imprimantes.

driverless est placé dans /usr/lib/cups/driver/ pour lister les imprimantes capables d'impression sans pilote et générer des PPD pour celles-ci. Il doit également être placé dans /usr/lib/cups/backend/ (de préférence par un lien symbolique) pour lister les URI de périphériques IPP pour les imprimantes appropriées. Les outils de configuration d'imprimantes tels que system-config-printer, l'interface web de CUPS sur http://localhost:631/, et les utilitaires en ligne de commande de CUPS peuvent utiliser driverless avec CUPS pour lister les imprimantes disponibles capables d'impression sans pilote, déterminer leurs URI de périphériques IPP et générer des PPD pour elles. Les imprimantes seront configurées automatiquement et correctement pour l'impression sans pilote. Notez que l'impression sans pilote nécessite une communication IPP avec l'imprimante.

Un second lien symbolique vers /usr/lib/cups/driver/driverless depuis /usr/bin/ permet à driverless d'être appelé directement par un utilisateur.

OPTIONS

-h, --help, --version
Afficher la page d'aide, y compris le numéro de version.
-v, -d, --debug
Mode débogage, journalisation détaillée sur stderr.
list
Lister les URI de pilotes et les métadonnées pour toutes les imprimantes IPP/IPPS disponibles appropriées pour la génération de fichiers PPD sans pilote (à utiliser par CUPS).
_ipps._tcp
Rechercher uniquement les imprimantes IPPS prenant en charge l'impression sans pilote.
_ipp._tcp
Rechercher uniquement les imprimantes IPP prenant en charge l'impression sans pilote.
--std-ipp-uris
Afficher les URI sous forme standard
cat URI_du_pilote
Générer le fichier PPD pour le URI_du_pilote fourni à partir de la sortie de "list" (à utiliser par CUPS).
URI_imprimante_IPP
Générer le fichier PPD pour l'URI_imprimante_IPP fournie (les URI appropriées sont listées lors de l'appel de driverless sans options).

Lorsqu'il est appelé sans options, les URI d'imprimante IPP de toutes les imprimantes IPP disponibles capables d'impression sans pilote seront listées.

VOIR AUSSI

cups-browsed(8), ippfind(1), ippusbxd(8)

AUTEUR

Les auteurs de driverless sont listés dans /usr/share/doc/cups-filters/AUTHORS.
