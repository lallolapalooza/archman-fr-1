DROP FOREIGN DATA WRAPPER(7) Documentation PostgreSQL 18.1 DROP FOREIGN DATA WRAPPER(7)

NOM

DROP_FOREIGN_DATA_WRAPPER - supprimer un wrapper de données étrangères

SYNTAXE

DROP FOREIGN DATA WRAPPER [ IF EXISTS ] nom [, ...] [ CASCADE | RESTRICT ]

DESCRIPTION

DROP FOREIGN DATA WRAPPER supprime un wrapper de données étrangères existant. Pour exécuter cette commande, l'utilisateur courant doit être le propriétaire du wrapper de données étrangères.

PARAMETRES

IF EXISTS

Ne pas générer d'erreur si le wrapper de données étrangères n'existe pas. Une notification est émise dans ce cas.

nom

Le nom d'un wrapper de données étrangères existant.

CASCADE

Supprimer automatiquement les objets qui dépendent du wrapper de données étrangères (comme les tables étrangères et les serveurs), et par conséquent tous les objets qui dépendent de ces objets (voir Section 5.15).

RESTRICT

Refuser de supprimer le wrapper de données étrangères s'il existe des objets qui en dépendent. C'est le comportement par défaut.

EXEMPLES

Supprimer le wrapper de données étrangères dbi :

DROP FOREIGN DATA WRAPPER dbi;

COMPATIBILITE

DROP FOREIGN DATA WRAPPER est conforme à la norme ISO/IEC 9075-9 (SQL/MED). La clause IF EXISTS est une extension de PostgreSQL.

VOIR AUSSI

CREATE FOREIGN DATA WRAPPER (CREATE_FOREIGN_DATA_WRAPPER(7)), ALTER FOREIGN DATA WRAPPER (ALTER_FOREIGN_DATA_WRAPPER(7))
