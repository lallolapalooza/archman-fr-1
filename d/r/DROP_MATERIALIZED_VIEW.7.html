NOM

DROP_MATERIALIZED_VIEW - supprimer une vue matérialisée

SYNTAXE

DROP MATERIALIZED VIEW [ IF EXISTS ] nom [, ...] [ CASCADE | RESTRICT ]

DESCRIPTION

DROP MATERIALIZED VIEW supprime une vue matérialisée existante. Pour exécuter cette commande, vous devez être le propriétaire de la vue matérialisée.

PARAMETRES

IF EXISTS

Ne génère pas d'erreur si la vue matérialisée n'existe pas. Un avertissement est émis dans ce cas.

nom

Le nom (éventuellement qualifié par le schéma) de la vue matérialisée à supprimer.

CASCADE

Supprime automatiquement les objets qui dépendent de la vue matérialisée (telles que d'autres vues matérialisées ou des vues régulières), et à leur tour tous les objets qui dépendent de ces objets (voir la Section 5.15).

RESTRICT

Refuse de supprimer la vue matérialisée s'il existe des objets qui en dépendent. C'est le comportement par défaut.

EXEMPLES

Cette commande supprimera la vue matérialisée nommée order_summary :

DROP MATERIALIZED VIEW order_summary;

COMPATIBILITÉ

DROP MATERIALIZED VIEW est une extension PostgreSQL.

VOIR AUSSI
