DROP EVENT TRIGGER(7) Documentation PostgreSQL 18.1 DROP EVENT TRIGGER(7)

NOM

DROP_EVENT_TRIGGER - supprimer un déclencheur d'événement

SYNTAXE

DROP EVENT TRIGGER [ IF EXISTS ] nom [ CASCADE | RESTRICT ]

DESCRIPTION

DROP EVENT TRIGGER supprime un déclencheur d'événement existant. Pour exécuter cette commande, l'utilisateur actuel doit être le propriétaire du déclencheur d'événement.

PARAMETRES

IF EXISTS

Ne lance pas d'erreur si le déclencheur d'événement n'existe pas. Une notice est émise dans ce cas.

nom

Le nom du déclencheur d'événement à supprimer.

CASCADE

Supprime automatiquement les objets qui dépendent du déclencheur, et à leur tour tous les objets qui dépendent de ces objets (voir la Section 5.15).

RESTRICT

Refuse de supprimer le déclencheur si des objets en dépendent. C'est le comportement par défaut.

EXEMPLES

Détruire le déclencheur snitch :

DROP EVENT TRIGGER snitch;

COMPATIBILITE

Il n'y a pas d'instruction DROP EVENT TRIGGER dans la norme SQL.

VOIR AUSSI

CREATE EVENT TRIGGER (CREATE_EVENT_TRIGGER(7)), ALTER EVENT TRIGGER (ALTER_EVENT_TRIGGER(7))
