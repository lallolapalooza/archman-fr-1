DRRACKET(1) Manuel des commandes générales DRRACKET(1)

NOM

drracket - l'environnement de programmation Racket

SYNTAXE

drracket [ optionX ... ] [ fichier ... ]

DESCRIPTION

DrRacket est l'environnement de programmation Racket.

Le programme drracket traite les arguments de la ligne de commande qui ne sont pas des options comme des fichiers à ouvrir.

OPTIONS X

Lorsqu'il est exécuté sous X11, DrRacket accepte les options standards optionX suivantes : -display disp, -geometry geom, -bg couleur, -background couleur, -fg couleur, -foreground couleur, -fn police, -font police, -iconic, -name nom, -rv, -reverse, +rv, -selectionTimeout temps, -synchronous, -title nom, -xnllanguage lang, -xrm fichier.

De plus, l'option -singleInstance est traitée comme une option X (elle doit apparaître avant toutes les autres options) et elle exécute DrRacket en mode instance unique. En mode instance unique, lorsqu'une instance existante est en cours d'exécution avec le même nom d'hôte et de nom d'exécutable, tous les arguments non-options sont traités comme des noms de fichiers et envoyés à l'instance existante.

PLUS D'INFORMATIONS

Pour plus d'informations, exécutez


raco docs

pour ouvrir la documentation installée dans votre navigateur web.

Alternativement, consultez la documentation en ligne et d'autres informations disponibles à


http://racket-lang.org/
