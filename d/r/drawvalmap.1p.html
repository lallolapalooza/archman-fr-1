NOM

drawvalmap - Génère une sortie graphique des valeurs d'état de validation rencontrées par la bibliothèque de validation.

SYNTAXE

drawvalmap <fichier_log>

drawvalmap

DESCRIPTION

drawvalmap est un utilitaire simple qui peut être utilisé pour afficher les valeurs d'état de validation sous une forme graphique. L'entrée de ce script est un ensemble de messages de log qui peuvent être lus à partir d'un fichier ou d'une socket. La sortie est un fichier image contenant une image des différentes valeurs d'état de la chaîne d'authentification du validateur.

drawvalmap lit les données depuis STDIN si l'option fichier_log et socket sont toutes deux non spécifiées. Si l'option -f est donnée, le fichier image de sortie est intégré dans un fichier HTML avec le nom donné. Le fichier HTML se rafraîchit automatiquement selon la période de rafraîchissement fournie par l'option -r, permettant de suivre en permanence les changements du graphique de validation.

L'utilisation typique de ce script est la suivante :

# drawvalmap <fichier_log>

Il ne serait pas rare d'utiliser ce script à des fins de dépannages, auquel cas la sortie générée par un programme pilote serait "pipée" à ce script de la manière indiquée ci-dessous.

# dt-validate -o6:stdout secure.example.com. | drawvalmap -f val_log_map.html

Dans chaque cas, le script génère les résultats dans un fichier val_log_map.png. Dans le second cas, un fichier HTML nommé val_log_map.html est également généré.

OPTIONS

-a adresse-IP
Ceci change l'adresse à laquelle drawvalmap se lie à la valeur spécifiée. Cette option prend effet uniquement si l'option -s est également spécifiée.
-f fichier.ext
Ceci crée une image du type déterminé par l'extension du fichier.
-g xxxx (obsolète)
Utilisez -f à la place.
-h fichier.html
Ceci crée un fichier HTML avec le nom donné, qui contient l'image de la carte de validation.
-i chaîne_motif_ignoré
Ceci fait en sorte que drawvalmap ignore les enregistrements de log qui correspondent au motif ignoré donné.
-l événement_log1,événement_log2
Ceci fait en sorte que drawvalmap active l'affichage des événements pour la liste donnée de types de log. Les types d'événements de log suivants sont définis avec leur état activé par défaut indiqué entre parenthèses : SUCCESS(1), BOGUS(1), DATA_MISSING(1), ERROR(1), et IGNORED(0).
-m chaîne_motif_correspondant
Ceci fait en sorte que drawvalmap n'inclue que les enregistrements de log qui correspondent au motif donné. Si un enregistrement de log donné correspond à un motif donné par l'option -m et correspond également au motif donné par l'option -i, le résultat effectif est celui de l'ignorance de l'enregistrement.
-p port
Ceci change le port auquel drawvalmap se lie à la valeur spécifiée. Cette option prend effet uniquement si l'option -s est également spécifiée.
-r période_rafraîchissement
Ceci change la période de rafraîchissement dans le fichier HTML à la valeur donnée. La valeur par défaut est de 5 secondes.
-s
Ceci change le mode de fonctionnement pour lire l'entrée depuis une socket. L'adresse et le port par défaut auxquels drawvalmap se lie sont 127.0.0.1:1053.
