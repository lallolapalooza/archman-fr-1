DROP OPERATOR FAMILY(7) Documentation PostgreSQL 18.1 DROP OPERATOR FAMILY(7)

NOM

DROP OPERATOR FAMILY - supprimer une famille d'opérateurs

SYNOPIS

DROP OPERATOR FAMILY [ IF EXISTS ] nom USING méthode_index [ CASCADE | RESTRICT ]

DESCRIPTION

DROP OPERATOR FAMILY supprime une famille d'opérateurs existante. Pour exécuter cette commande, vous devez être le propriétaire de la famille d'opérateurs.

DROP OPERATOR FAMILY inclut la suppression de toutes les classes d'opérateurs contenues dans la famille, mais ne supprime aucun des opérateurs ou fonctions référencés par la famille. S'il existe des index dépendant des classes d'opérateurs au sein de la famille, vous devrez spécifier CASCADE pour que la suppression aboutisse.

PARAMÈTRES

IF EXISTS

Ne génère pas d'erreur si la famille d'opérateurs n'existe pas. Un avis est émis dans ce cas.

nom

Le nom (éventuellement qualifié par un schéma) d'une famille d'opérateurs existante.

méthode_index

Le nom de la méthode d'accès aux index pour laquelle la famille d'opérateurs est destinée.

CASCADE

Supprime automatiquement les objets qui dépendent de la famille d'opérateurs, et par conséquent tous les objets qui dépendent de ces objets (voir Section 5.15).

RESTRICT

Refuse de supprimer la famille d'opérateurs si des objets en dépendent. C'est le comportement par défaut.

EXEMPLES

Supprimer la famille d'opérateurs B-tree float_ops :

DROP OPERATOR FAMILY float_ops USING btree;

Cette commande ne réussira pas s'il existe des index utilisant des classes d'opérateurs dans la famille. Ajoutez CASCADE pour supprimer ces index ainsi que la famille d'opérateurs.

COMPATIBILITÉ

Il n'existe pas de commande DROP OPERATOR FAMILY dans la norme SQL.

VOIR AUSSI
