NOM

dcm-getframe - imprime une image d'un fichier DICOM PS3.10 sur la sortie standard

SYNTAXE

dcm-getframe [-v] fichier numéro-image

DESCRIPTION

Imprime une image d'un fichier DICOM PS3.10 sur la sortie standard.

OPTIONS

-o NOM-FICHIER-SORTIE
Écrit l'image dans NOM-FICHIER-SORTIE. Par défaut, l'image sera écrite sur stdout.
-h
Affiche le message d'aide (résumé d'utilisation) et quitte.
-V
Affiche la version et quitte.
-v
Augmente la verbosité de la journalisation à INFO.

STATUT DE SORTIE

dcm-getframe renvoie 0 en cas de succès, 1 si un fichier n'a pas pu être lu ou 2 si les arguments sont invalides.
