NOM

dconf-service - Service D-Bus pour les écritures dans la base de données dconf

SYNTAXE

dconf-service

DESCRIPTION

Le programme dconf-service fournit le nom ca.desrt.dconf sur le bus de session ou le bus système. Les utilisateurs ou les administrateurs n'auront jamais besoin de démarrer le service, car il sera automatiquement démarré par dbus-daemon(1) chaque fois qu'une application tentera d'écrire des paramètres.

La lecture des valeurs de la base de données dconf n'implique pas le service ; il n'est nécessaire que pour les écritures. Le service est sans état et peut se terminer librement à tout moment (et est donc robuste aux plantages).

VOIR AUSSI

dconf(7), dbus-daemon(1), systemd(1)
