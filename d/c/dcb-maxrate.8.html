NOM

dcb-maxrate - afficher / manipuler les paramètres de débit maximal des ports du sous-système DCB (Data Center Bridging)

SYNTAXE


dcb [ OPTIONS ] maxrate { COMMANDE | aide }

dcb maxrate show dev DEV [ tc-maxrate ]

dcb maxrate set dev DEV [ tc-maxrate CARTE-DEBIT ]

CARTE-DEBIT := [ CARTE-DEBIT ] MAPPING-DEBIT

MAPPING-DEBIT := { TC | tout }:DEBIT

TC := { 0 .. 7 }

DEBIT := { NOMBRE[bit] | NOMBREKbit | NOMBREMib | ... }

DESCRIPTION

dcb maxrate est utilisé pour configurer et inspecter le débit maximal auquel le trafic est autorisé à sortir d'une classe de trafic donnée.

PARAMÈTRES

La description suivante ne concerne que la direction d'écriture, c'est-à-dire telle qu'utilisée avec la commande set. Pour la commande show, le nom du paramètre doit être utilisé comme un simple mot-clé sans arguments supplémentaires. Cela indique à l'outil d'afficher la valeur d'un paramètre donné. Lorsque aucun paramètre n'est donné, l'outil affiche la configuration complète de maxrate.

tc-maxrate CARTE-DEBIT
CARTE-DEBIT utilise la syntaxe de tableau de paramètres, voir dcb(8) pour les détails. Les clés sont les indices TC, les valeurs sont les débits de trafic en bits par seconde. Les débits peuvent utiliser la notation documentée dans la section PARAMÈTRES de tc(8). Notez que sous cette notation, « bit » signifie bits par seconde tandis que « b » signifie octets par seconde. Lors de l'affichage, l'option de ligne de commande -i bascule entre l'utilisation des préfixes décadiques et ISO/CEI.

EXEMPLE & UTILISATION

Définir les débits de toutes les classes de trafic à 25 Gbit/s, sauf pour la TC 6, qui aura un débit de 100 Gbit/s :

# dcb maxrate set dev eth0 tc-maxrate all:25Gbit 6:100Gbit

Afficher ce qui a été défini :

# dcb maxrate show dev eth0
tc-maxrate 0:25Gbit 1:25Gbit 2:25Gbit 3:25Gbit 4:25Gbit 5:25Gbit 6:100Gbit 7:25Gbit

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.
