NOM

dcb-apptrust - afficher / configurer la confiance par sélecteur et l'ordre de confiance de la table de priorité des applications du sous-système DCB (Data Center Bridging).

SYNTAXE


dcb [ OPTIONS ] apptrust { COMMANDE | aide }

dcb apptrust show dev DEV [ order ]

dcb apptrust set dev DEV [ order LISTE-SEL ]

LISTE-SEL := [ LISTE-SEL ] SEL

SEL := { ethtype | stream-port | dgram-port | port | dscp | pcp }

DESCRIPTION

dcb apptrust est utilisé pour configurer la confiance et l'ordre de confiance par sélecteur de la Table de Priorité des Applications, voir dcb-app(8) pour plus de détails sur la configuration des entrées de la table APP.

La confiance du sélecteur peut être utilisée par la pile logicielle, ou les pilotes (le plus probablement les derniers), lors de la requête de la table APP, pour déterminer si une entrée APP doit prendre effet ou non. De plus, l'ordre des sélecteurs de confiance dictera quel sélecteur doit avoir la priorité, dans le cas où plusieurs sélecteurs de table APP différents seraient présents.

COMMANDES

show
Affiche tous les sélecteurs de confiance.
set
Définit une nouvelle liste de sélecteurs de confiance. Une liste vide est effectivement identique à la suppression totale de la confiance.

PARAMETRES

Ce qui suit décrit uniquement la direction d'écriture, c'est-à-dire telle qu'utilisée avec la commande set. Pour la commande show, le nom du paramètre doit être utilisé comme un simple mot-clé sans arguments supplémentaires. Ceci indique à l'outil d'afficher les valeurs d'un paramètre donné.

order LISTE-SEL
LISTE-SEL est une liste de noms de sélecteurs séparés par des espaces. Les valeurs de sélecteur possibles sont : ethtype, stream-port, dgram-port, port, dscp, et pcp

EXEMPLE & UTILISATION

Définit l'ordre de confiance à : dscp, pcp pour eth0 :

# dcb apptrust set dev eth0 order dscp pcp

Définit l'ordre de confiance à : port (stream ou dgram), pcp, ethtype pour eth1 :

# dcb apptrust set dev eth1 order port pcp ethtype

Affiche ce qui a été défini :

# dcb apptrust show dev eth0
order: port pcp ethtype

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.
