Documentation Fonction/Sous-programme

sous-programme dchklqtp (double précision thresh, logique tsterr, entier nm, entier, dimension( * ) mval, entier nn, entier, dimension( * ) nval, entier nnb, entier, dimension( * ) nbval, entier nout)

DCHKLQTP

Objectif :

!>
!> DCHKLQTP teste DTPLQT et DTPMLQT.
!>

Paramètres

THRESH 
!>          THRESH est DOUBLE PRECISION
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>          imprimer chaque rapport de test, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est LOGIQUE
!>          Indicateur qui détermine si les sorties d'erreur doivent être testées.
!>

NM

!>          NM est ENTIER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau ENTIER, de dimension (NM)
!>          Les valeurs de la dimension des lignes de la matrice M.
!>

NN

!>          NN est ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau ENTIER, de dimension (NN)
!>          Les valeurs de la dimension des colonnes de la matrice N.
!>

NNB

!>          NNB est ENTIER
!>          Le nombre de valeurs de NB contenues dans le vecteur NBVAL.
!>

NBVAL

!>          NBVAL est un tableau ENTIER, de dimension (NNB)
!>          Les valeurs de la taille de bloc NB.
!>

NOUT

!>          NOUT est ENTIER
!>          Le numéro d'unité pour la sortie.
!>
