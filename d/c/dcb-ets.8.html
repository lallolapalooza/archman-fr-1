    NOM

    dcb-ets - Outil pour manipuler les paquets dcb et ets

    SYNTAXE

    dcb-ets [OPTIONS] COMMANDE [ARGUMENTS]...

    DESCRIPTION

    L'outil dcb-ets est utilisé pour interagir avec les paquets DCB (Data Center Bridging) et ETS (Enhanced Transmission Selection). Il permet de visualiser, configurer et gérer les paramètres liés au DCB et à l'ETS sur les interfaces réseau.

    OPTIONS

    -i, --interface INTERFACE
    Spécifie l'interface réseau à utiliser.
    -l, --list
    Liste les configurations DCB/ETS disponibles.
    -c, --configure CONFIGURATION
    Applique une configuration DCB/ETS spécifiée.
    -s, --status
    Affiche le statut actuel des configurations DCB/ETS.
    -h, --help
    Affiche l'aide et quitte.

    EXEMPLES

    Pour lister les configurations DCB/ETS sur l'interface eth0 : 

    dcb-ets --interface eth0 --list

    Pour appliquer une configuration nommée "high_priority" à l'interface eth1 : 

    dcb-ets --interface eth1 --configure high_priority

    Pour afficher le statut actuel de l'interface eth0 : 

    dcb-ets --interface eth0 --status
