Documentation de la fonction/sous-routine

subroutine dckglm (integer nn, integer, dimension( * ) mval, integer, dimension( * ) pval, integer, dimension( * ) nval, integer nmats, integer, dimension( 4 ) iseed, double precision thresh, integer nmax, double precision, dimension( * ) a, double precision, dimension( * ) af, double precision, dimension( * ) b, double precision, dimension( * ) bf, double precision, dimension( * ) x, double precision, dimension( * ) work, double precision, dimension( * ) rwork, integer nin, integer nout, integer info)

DCKGLM

Objectif :

!>
!> DCKGLM teste DGGGLM - sous-routine pour résoudre le problème du modèle
!>                       linéaire généralisé.
!>

Paramètres

NN 
!>          NN est un ENTIER
!>          Le nombre de valeurs de N, M et P contenues dans les vecteurs
!>          NVAL, MVAL et PVAL.
!>

MVAL

!>          MVAL est un tableau ENTIER, dimension (NN)
!>          Les valeurs de la dimension de colonne de matrice M.
!>

PVAL

!>          PVAL est un tableau ENTIER, dimension (NN)
!>          Les valeurs de la dimension de colonne de matrice P.
!>

NVAL

!>          NVAL est un tableau ENTIER, dimension (NN)
!>          Les valeurs de la dimension de ligne de matrice N.
!>

NMATS

!>          NMATS est un ENTIER
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrices. Si NMATS >= NTYPES (le nombre maximal
!>          de types de matrices), alors tous les types différents sont
!>          générés pour les tests. Si NMATS < NTYPES, une autre ligne
!>          d'entrée est lue pour obtenir les numéros des types de matrices
!>          à utiliser.
!>

ISEED

!>          ISEED est un tableau ENTIER, dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires. Les
!>          éléments du tableau doivent être compris entre 0 et 4095, sinon
!>          ils seront réduits modulo 4096, et ISEED(4) doit être impair.
!>          À la sortie, la graine suivante dans la séquence de nombres
!>          aléatoires après la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est un DOUBLE PRECISION
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESID >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau DOUBLE PRECISION, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau DOUBLE PRECISION, dimension (NMAX*NMAX)
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (4*NMAX)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (NMAX)
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (NMAX*NMAX)
!>

NIN

!>          NIN est un ENTIER
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : Sortie réussie
!>          > 0 : Si DLATMS renvoie un code d'erreur, sa valeur absolue
!>                 est retournée.
!>
