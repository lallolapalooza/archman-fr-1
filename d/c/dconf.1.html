DCONF(1) Commandes utilisateur DCONF(1)

NOM

dconf — Outil simple pour manipuler une base de données dconf

SYNTAXE

dconf read [-d] CLÉ

dconf list RÉPERTOIRE

dconf write CLÉ VALEUR

dconf reset [-f] CHEMIN

dconf compile SORTIE RÉPERTOIRE_FICHIERS_CLÉS

dconf update [RÉPERTOIRE_BD]

dconf watch CHEMIN

dconf dump RÉPERTOIRE

dconf load [-f] RÉPERTOIRE

dconf help [COMMANDE]

DESCRIPTION

Le programme dconf peut effectuer diverses opérations sur une base de données dconf, comme lire ou écrire des valeurs individuelles ou des répertoires entiers. Cet outil opère directement sur dconf, sans utiliser les informations de schéma gsettings. Par conséquent, il ne peut pas effectuer de vérifications de type et de cohérence sur les valeurs. L'utilitaire gsettings(1) est une alternative si de telles vérifications sont nécessaires.

Les arguments RÉPERTOIRE doivent être des chemins de répertoire (commençant et finissant par '/'), les arguments CLÉ doivent être des chemins de clé (commençant, mais ne finissant pas par '/') et les arguments CHEMIN peuvent être soit des chemins de répertoire, soit des chemins de clé.

L'argument SORTIE doit être l'emplacement où écrire une base de données dconf (binaire) et l'argument RÉPERTOIRE_FICHIERS_CLÉS doit être un répertoire .d contenant des fichiers de clés.

Les arguments VALEUR doivent être au format GVariant, donc par exemple une chaîne de caractères doit inclure des guillemets explicites : "'foo'". Ce format est également utilisé lors de l'affichage des valeurs.

Notez que dconf a besoin d'une connexion de bus de session D-Bus pour écrire les modifications dans la base de données dconf.

COMMANDES

read

Lit la valeur d'une clé. Utiliser -d pour afficher la valeur par défaut plutôt que la valeur définie par l'utilisateur.

list

Liste les sous-clés et les sous-répertoires d'un répertoire.

write

Écrit une nouvelle valeur dans une clé.

reset

Réinitialise une clé ou un répertoire entier. Pour les répertoires, -f doit être spécifié.

compile

Compile une base de données binaire à partir de fichiers de clés.

Le résultat est toujours en ordre d'octets little-endian, il peut donc être installé en toute sécurité dans 'share'. S'il est utilisé sur une machine big-endian, dconf échangera automatiquement les octets lors de la lecture.

update

Met à jour les bases de données dconf du système.

watch

Surveille une clé ou un répertoire pour détecter les changements.

dump

Sauvegarde un sous-chemin entier sur la sortie standard. La sortie est dans un format similaire à un fichier de clés, avec des valeurs en syntaxe GVariant.

load

Peuple un sous-chemin à partir de l'entrée standard. Le format attendu est le même que celui produit par dump. Tenter de modifier des clés non inscriptibles annule la commande load. Pour ignorer les modifications apportées aux clés non inscriptibles à la place, utiliser -f.

help

Affiche l'aide et quitte. Si COMMANDE est fournie, affiche l'aide pour cette commande.

ENVIRONNEMENT

DCONF_PROFILE

Cette variable d'environnement détermine quel profil dconf utiliser. Voir dconf(7).

VOIR AUSSI

dconf(7), gsettings(1), dconf-editor(1)
