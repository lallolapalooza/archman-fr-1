NOM

dconvlum - Convertit les fichiers VeriLUM en fichiers d'affichage DCMTK

SYNOPIS

dconvlum fichier-entree fichier-sortie [ambiant]

DESCRIPTION

Programme en ligne de commande qui convertit un fichier VeriLUM avec des données de courbe caractéristique (CCx_xx.dat) dans un format utilisé pour la transformation de Barten dans cette boîte à outils. VeriLUM est un package de calibration d'ImageSmiths composé d'un photomètre (avec connecteur série RS232) et d'un logiciel sous Windows NT.

PARAMÈTRES

fichier-entree   Fichier de courbe caractéristique VeriLUM à convertir
fichier-sortie   Fichier d'affichage DCMTK à écrire
ambiant        Lumière ambiante (cd/m^2, valeur flottante)

NOTES

Le fichier de sortie décrivant la courbe caractéristique d'un système d'affichage (moniteur) est un simple fichier texte. Les lignes commençant par '#' sont traitées comme des commentaires et sont donc ignorées, tout comme les lignes vides. Ce programme de conversion crée automatiquement un tel fichier (y compris quelques lignes de commentaire) en transformant les informations stockées dans le fichier VeriLUM. Le nombre suivant le mot magique 'max' définit la valeur DDL maximale (par exemple, 255 pour les écrans 8 bits). Cette définition est requise avant que les données de luminance puissent être définies. Optionnellement, la valeur de la lumière ambiante peut également être spécifiée dans ce fichier. La valeur flottante (en candelas par mètre carré) doit suivre le mot 'amb'. Enfin, les valeurs de luminance sont définies pour chaque valeur correspondante de DDL (niveau de commande numérique). Les entrées ne sont pas nécessairement triées ou complètes, c'est-à-dire qu'il peut y avoir moins de 'max' + 1 entrées. Les valeurs manquantes sont calculées par interpolation par spline cubique.

Voir la partie 14 de la norme DICOM pour plus de détails sur la calibration de l'affichage et le modèle de Barten (y compris le GSDF).
