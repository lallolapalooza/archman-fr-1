NOM

dcd-server - serveur de complétion automatique pour le langage de programmation D

SYNOPSIS

dcd-server [-I répertoire] [-p|--port numéroDePort] [--tcp] [--socketFile cheminFichier] [--logLevel niveau] [-h|--help] [--version]

DESCRIPTION

dcd-server met en cache les informations sur les fichiers source D qui ont été trouvés

OPTIONS

-p, --port numéroDePort

Choisit le numéro de port sur lequel dcd-server écoute. Cet indicateur implique --tcp.
--tcp
Écoute sur une socket TCP au lieu d'une socket de domaine UNIX. C'est le comportement par défaut sous Windows.
--socketFile cheminFichier
Définit le chemin à utiliser pour la socket de domaine UNIX. N'a aucun effet si les indicateurs --tcp ou --port sont utilisés.
--logLevel niveau
Configure le niveau de journalisation pour dcd-server. Les valeurs valides sont all trace info warning error critical fatal off
-I répertoire
Inclut répertoire dans la liste des répertoires à analyser pour trouver les fichiers source. Cette option peut être spécifiée plusieurs fois.
-h, --help
Affiche un message d'aide.
--version
Affiche le numéro de version actuel et quitte.

FICHIERS

dcd-server peut être configuré en utilisant un fichier appelé dcd.conf Ce fichier doit être placé dans l'un des emplacements suivants :

•
/etc/dcd.conf

•
${XDG_CONFIG_HOME}/dcd/dcd.conf

•
${HOME}/.config/dcd/dcd.conf

Chaque ligne du fichier doit être un chemin à rechercher pour les fichiers source D. Une ligne dans dcd.conf est équivalente à passer cette même ligne à dcd-server avec l'option -I. Les lignes qui commencent par le caractère '#' sont ignorées.

Sauf si l'indicateur --tcp est utilisé, dcd-server utilisera par défaut la communication avec le client via une socket de domaine UNIX. dcd-server tentera de créer la socket aux emplacements suivants :

•
${XDG_RUNTIME_DIR}/dcd.socket

•
/tmp/dcd-${UID}.socket
