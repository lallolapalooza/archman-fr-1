NOM

dcb-dcbx - afficher / manipuler le DCBX (Data Center Bridging eXchange) du port

SYNTAXE


dcb [ OPTIONS ] dcbx { COMMANDE | help }

dcb dcbx show dev DEV

dcb dcbx set dev DEV [ host ] [ lld-managed ] [ cee ] [ ieee ] [ static ]

DESCRIPTION

Data Center Bridging eXchange (DCBX) est un protocole utilisé par les périphériques DCB pour échanger des informations de configuration avec les pairs directement connectés. L'objet DCBX Linux est un champ de bits d'un octet contenant des indicateurs qui configurent si DCBX est implémenté dans le périphérique ou dans l'hôte, et quelle version du protocole doit être utilisée. dcb dcbx est utilisé pour accéder à l'objet DCBX Linux par port.

Il existe deux modes principaux de fonctionnement : en mode host, le protocole DCBX est implémenté par l'agent LLDP de l'hôte, et les interfaces DCB sont utilisées pour propager les paramètres négociés aux périphériques capables. En mode lld-managed, la configuration est gérée par le périphérique, et les interfaces DCB sont utilisées pour l'inspection des paramètres négociés, et peuvent également être utilisées pour définir les paramètres initiaux.

PARAMETRES

Lorsqu'ils sont utilisés avec dcb dcbx set, les mots-clés suivants activent la configuration correspondante. Les mots-clés qui ne sont pas mentionnés dans la ligne de commande sont considérés comme désactivés. Lorsqu'ils sont utilisés avec show, chaque fonctionnalité activée est affichée par son mot-clé correspondant.

host
lld-managed
Le périphérique est en mode de fonctionnement hôte et, respectivement, en mode de fonctionnement lld-managed, comme décrit ci-dessus. En principe, ces deux mots-clés sont mutuellement exclusifs, mais dcb dcbx permet de les définir tous les deux et laisse le pilote les gérer comme il convient.
cee
ieee
Le périphérique prend en charge CEE (Converged Enhanced Ethernet) et, respectivement, la version IEEE de la spécification DCB. Généralement, un seul de ceux-ci sera défini, mais dcb dcbx ne l'impose pas.
static
indique que le moteur prend en charge la configuration statique. Aucune négociation réelle n'est effectuée, les paramètres négociés sont toujours la configuration initiale.

EXEMPLE & UTILISATION

Mettre le moteur DCB en mode de fonctionnement "host" et utiliser les interfaces DCB standardisées IEEE :

# dcb dcbx set dev eth0 host ieee

Afficher ce qui a été défini :

# dcb dcbx show dev eth0
host ieee

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.
