NOM

dc1394_vloopback - envoie la vidéo au format 0 au périphérique vloopback V4L

SYNTAXE

dc1394_vloopback [--daemon] [--pipe] [--guid=euid-camera] [--video1394=/dev/video1394/x] [--vloopback=/dev/video0] [--palette=yuv422|rgb24] [--width=n] [--height=n]

DESCRIPTION

Envoie une vidéo RGB au format 0 (640x480) au périphérique d'entrée vloopback, afin qu'elle puisse être consommée par des applications V4L sur le périphérique de sortie vloopback.

OPTIONS

--daemon
s'exécute en tant que démon, détaché de la console (optionnel).
--pipe
écrit les images sur le périphérique vloopback au lieu d'utiliser le mode mmap sans copie (optionnel).
--guid
sélectionne la caméra à utiliser (optionnel). par défaut, la première caméra sur n'importe quel port.
--video1394
spécifie le périphérique video1394 à utiliser (optionnel). par défaut, /dev/video1394/<numéro-port>.
--vloopback
spécifie le périphérique video4linux à utiliser (optionnel). par défaut, il est déterminé automatiquement.
--palette
spécifie la palette vidéo à utiliser (optionnel). yuv422 (par défaut) ou rgb24.
--width
définit la largeur initiale (par défaut=640)
--height
définit la hauteur initiale (par défaut=480)
--help
affiche le message d'aide
