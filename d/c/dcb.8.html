DCB(8) Linux DCB(8)

NOM

dcb - afficher / manipuler les paramètres DCB (Data Center Bridging)

SYNTAXE


dcb [ OPTIONS ] { app | buffer | ets | maxrate | pfc } { COMMANDE | help }

dcb [ -force ] -batch fichier

dcb [ OPTIONS ] help

OPTIONS

-n, --netns <ESPACENET>
bascule dcb vers l'espace de noms réseau spécifié ESPACENET.
-V, --Version
Affiche la version de l'utilitaire dcb et quitte.
-b, --batch <FICHIER>
Lit les commandes depuis le fichier fourni ou l'entrée standard et les exécute. La première erreur entraînera l'arrêt de dcb.
-f, --force
Ne pas arrêter dcb en cas d'erreurs en mode batch. S'il y a eu des erreurs lors de l'exécution des commandes, le code de retour de l'application sera non nul.
-i, --iec
Lors de l'affichage des débits, utilise les préfixes basés sur 1024 de l'ISO/IEC (Ki, Mi, Bi) au lieu de ceux basés sur 1000 (K, M, B).
-j, --json
Génère une sortie JSON.
-N, --Numeric
Si le sous-outil en question traduit les nombres en noms symboliques d'une quelconque manière, supprime cette traduction.
-p, --pretty
Lorsqu'il est combiné avec -j, génère une sortie JSON formatée.
-s, --statistics
Si l'objet en question contient des compteurs statistiques, affichez-les dans la sortie "show".

OBJETS

app
- Configuration de la table de priorités des applications
buffer
- Configuration des buffers du port
ets
- Configuration de l'ETS (Enhanced Transmission Selection)
maxrate
- Configuration du débit de transmission maximum par TC
pfc
- Configuration du PFC (Priority-based Flow Control)

COMMANDES

Une COMMANDE spécifie l'action à effectuer sur l'objet. L'ensemble des actions possibles dépend du type d'objet. En règle générale, il est possible de show (afficher) les objets et d'invoquer la commande topique help, qui affiche une liste des commandes disponibles et les conventions de syntaxe des arguments.

PARAMETRES DE TABLEAUX

Comme pour les commandes, la spécification des paramètres relève de la domaine des objets individuels (et de leurs commandes). Cependant, une grande partie de l'interface DCB tourne autour de tableaux de taille fixe qui spécifient une valeur par clé, par exemple par classe de trafic ou par priorité. Il existe donc une syntaxe unique pour ajuster les éléments de ces tableaux. Elle consiste en une série de paires CLE:VALEUR, où le sens des clés et valeurs individuelles dépend du paramètre.

Les éléments sont évalués de gauche à droite, les derniers remplaçant les précédents. Les éléments non spécifiés sur la ligne de commande sont interrogés au noyau et leur valeur actuelle est conservée.

À titre d'exemple, prenons un paramètre fictif tc-juju, qui peut être défini pour le trafic "charm" dans une TC donnée avec de la chance ou de la malchance. La CLE peut donc être 0..7 (comme d'habitude pour les numéros de TC dans DCB), et la VALEUR soit none, good (bon), soit bad (mauvais). Un exemple de modification de la valeur juju des TC 0 et 7, tout en laissant les autres intactes, serait alors :

# dcb foo set dev eth0 tc-juju 0:good 7:bad

Une clé spéciale, all, est reconnue et permet de définir la même valeur pour tous les éléments du tableau. Elle peut être combinée avec la syntaxe habituelle d'élément unique. Par exemple, dans ce qui suit, le juju de toutes les clés est défini sur none, sauf pour 0 et 7, qui ont d'autres valeurs :

# dcb foo set dev eth0 tc-juju all:none 0:good 7:bad

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.
