Documentation de la fonction/sous-routine

subroutine dchktp (logical, dimension( * ) dotype, integer nn, integer, dimension( * ) nval, integer nns, integer, dimension( * ) nsval, double precision thresh, logical tsterr, integer nmax, double precision, dimension( * ) ap, double precision, dimension( * ) ainvp, double precision, dimension( * ) b, double precision, dimension( * ) x, double precision, dimension( * ) xact, double precision, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer nout)

DCHKTP

Objectif :

!>
!> DCHKTP teste DTPTRI, -TRS, -RFS, et -CON, ainsi que DLATPS
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGICAL, de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .TRUE. ; si DOTYPE(j) = .FALSE., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un entier
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'entiers, de dimension (NN)
!>          Les valeurs de la dimension de colonne de matrice N.
!>

NNS

!>          NNS est un entier
!>          Le nombre de valeurs de NRHS contenues dans le vecteur NSVAL.
!>

NSVAL

!>          NSVAL est un tableau d'entiers, de dimension (NNS)
!>          Les valeurs du nombre de membres de droite NRHS.
!>

THRESH

!>          THRESH est un DOUBLE PRECISION
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>          imprimer chaque rapport de test, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGICAL
!>          Indicateur indiquant si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un entier
!>          La dimension principale des tableaux de travail. NMAX >= la
!>          valeur maximale de N dans NVAL.
!>

AP

!>          AP est un tableau DOUBLE PRECISION, de dimension
!>                      (NMAX*(NMAX+1)/2)
!>

AINVP

!>          AINVP est un tableau DOUBLE PRECISION, de dimension
!>                      (NMAX*(NMAX+1)/2)
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (NMAX*NSMAX)
!>          où NSMAX est la plus grande entrée dans NSVAL.
!>

X

!>          X est un tableau DOUBLE PRECISION, de dimension (NMAX*NSMAX)
!>

XACT

!>          XACT est un tableau DOUBLE PRECISION, de dimension (NMAX*NSMAX)
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension
!>                      (NMAX*max(3,NSMAX))
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (NMAX)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension
!>                      (max(NMAX,2*NSMAX))
!>

NOUT

!>          NOUT est un entier
!>          Le numéro de l'unité pour la sortie.
!>
