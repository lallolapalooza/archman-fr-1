Documentation de la fonction/sous-routine

sous-routine dchktb (logical, dimension( * ) dotype, integer nn, integer, dimension( * ) nval, integer nns, integer, dimension( * ) nsval, double precision thresh, logical tsterr, integer nmax, double precision, dimension( * ) ab, double precision, dimension( * ) ainv, double precision, dimension( * ) b, double precision, dimension( * ) x, double precision, dimension( * ) xact, double precision, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer nout)

DCHKTB

Objectif :

!>
!> DCHKTB teste DTBTRS, -RFS, et -CON, ainsi que DLATBS.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGICAL, de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .TRUE. ; si DOTYPE(j) = .FALSE., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un INTEGER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau INTEGER, de dimension (NN)
!>          Les valeurs de la dimension de colonne de la matrice N.
!>

NNS

!>          NNS est un INTEGER
!>          Le nombre de valeurs de NRHS contenues dans le vecteur NSVAL.
!>

NSVAL

!>          NSVAL est un tableau INTEGER, de dimension (NNS)
!>          Les valeurs du nombre de membres de droite NRHS.
!>

THRESH

!>          THRESH est un DOUBLE PRECISION
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utiliser THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGICAL
!>          Indicateur signalant si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un INTEGER
!>          La dimension principale des tableaux de travail.
!>          NMAX >= la valeur maximale de N dans NVAL.
!>

AB

!>          AB est un tableau DOUBLE PRECISION, de dimension (NMAX*NMAX)
!>

AINV

!>          AINV est un tableau DOUBLE PRECISION, de dimension (NMAX*NMAX)
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (NMAX*NSMAX)
!>          où NSMAX est la plus grande valeur dans NSVAL.
!>

X

!>          X est un tableau DOUBLE PRECISION, de dimension (NMAX*NSMAX)
!>

XACT

!>          XACT est un tableau DOUBLE PRECISION, de dimension (NMAX*NSMAX)
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension
!>                      (NMAX*max(3,NSMAX))
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension
!>                      (max(NMAX,2*NSMAX))
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (NMAX)
!>

NOUT

!>          NOUT est un INTEGER
!>          Le numéro de l'unité pour la sortie.
!>
