NOM

dcod2lum - Convertir un fichier de courbe caractéristique d'impression en format de copie souple

SYNTAXE

dcod2lum fichier-entree fichier-sortie

DESCRIPTION

Programme en ligne de commande qui convertit un fichier de courbe caractéristique d'impression en format de copie souple. En d'autres termes, les valeurs de densité optique (DO) mesurées à partir du fichier d'entrée sont transformées dans l'espace de luminance selon la formule :

  L = La + L0 * 10^(-D)

où L est la luminance résultante, La est la lumière ambiante réfléchie et L0 l'illumination (les deux mesurées en cd/m^2), 'D' la densité optique (DO). Veuillez noter que si aucune valeur d'illumination n'est spécifiée dans le fichier d'entrée (mot-clé lum), toutes les valeurs de densité optique sont mappées à une luminance constante.

PARAMETRES

fichier-entree   fichier de courbe caractéristique d'impression à convertir
fichier-sortie   fichier de courbe caractéristique de copie souple à écrire

NOTES

Le format des fichiers d'entrée et de sortie est décrit dans la documentation de l'outil en ligne de commande dcmdspfn. De plus, le dossier data contient des exemples de fichiers de caractéristiques pour les moniteurs, caméras, imprimantes et scanners.

FICHIERS

<datadir>/camera.lut - exemple de fichier de caractéristiques d'une caméra
<datadir>/monitor.lut - exemple de fichier de caractéristiques d'un moniteur
<datadir>/printer.lut - exemple de fichier de caractéristiques d'une imprimante
<datadir>/scanner.lut - exemple de fichier de caractéristiques d'un scanner

VOIR AUSSI
