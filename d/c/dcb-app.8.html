NOM

dcb-app - afficher / manipuler la table de priorités des applications du sous-système DCB (Data Center Bridging)

SYNTAXE


dcb [ OPTIONS ] app { COMMANDE | help }

dcb app { show | flush } dev DEV [ default-prio ] [ ethtype-prio ] [ stream-port-prio ] [ dgram-port-prio ] [ port-prio ] [ dscp-prio ] [ pcp-prio ]

dcb app { add | del | replace } dev DEV [ default-prio PRIO-LIST ] [ ethtype-prio ET-MAP ] [ stream-port-prio PORT-MAP ] [ dgram-port-prio PORT-MAP ] [ port-prio PORT-MAP ] [ dscp-prio DSCP-MAP ] [ pcp-prio PCP-MAP ]

PRIO-LIST := [ PRIO-LIST ] PRIO

ET-MAP := [ ET-MAP ] ET-MAPPING

ET-MAPPING := ET:PRIO

PORT-MAP := [ PORT-MAP ] PORT-MAPPING

PORT-MAPPING := PORT:PRIO

DSCP-MAP := [ DSCP-MAP ] DSCP-MAPPING

DSCP-MAPPING := { DSCP | all }:PRIO

PCP-MAP := [ PCP-MAP ] PCP-MAPPING

PCP-MAPPING := PCP:PRIO

ET := { 0x600 .. 0xffff }

PORT := { 1 .. 65535 }

DSCP := { 0 .. 63 }

PCP := { 0(nd/de) .. 7(nd/de) }

PRIO := { 0 .. 7 }

DESCRIPTION

dcb app est utilisé pour configurer la table APP, ou table de priorités des applications dans le sous-système DCB (Data Center Bridging). La table APP est utilisée pour attribuer une priorité au trafic en fonction de la valeur dans l'un des plusieurs en-têtes : EtherType, port de destination L4, ou DSCP. Elle permet également la configuration d'une priorité par défaut pour les ports qui est choisie si aucune autre règle de priorisation ne s'applique.

Les entrées DCB APP sont des triplets de sélecteur, identifiant de protocole et priorité. Le sélecteur est une énumération qui choisit l'un des espaces de noms de priorisation. Actuellement, il correspond principalement aux paramètres configurables décrits ci-dessous. L'identifiant de protocole est une valeur dans l'espace de noms du sélecteur. Par exemple, pour le sélecteur EtherType, les identifiants de protocole sont les EtherTypes individuels, pour DSCP ce sont les points de code individuels. La priorité est la priorité qui doit être attribuée au trafic correspondant au sélecteur et à l'identifiant de protocole.

La table APP est un ensemble d'entrées DCB APP. La seule exigence est que les entrées dupliquées ne soient pas ajoutées. Notamment, il est valide d'avoir des affectations de priorité conflictuelles pour le même sélecteur et identifiant de protocole. Par exemple, l'ensemble de deux entrées APP (DSCP, 10, 1) et (DSCP, 10, 2), où les paquets avec DSCP de 10 devraient recevoir les priorités 1 et 2, forment une table APP bien définie. L'outil dcb app permet une gestion de bas niveau de la table app en ajoutant et supprimant des triplets APP individuels via les commandes add et del. D'un autre côté, la commande replace fait ce que l'on voudrait typiquement dans cette situation - elle ajoute d'abord la nouvelle configuration, puis supprime celle obsolète, de sorte qu'une seule priorisation soit effective pour un sélecteur et un identifiant de protocole donnés.

COMMANDES

show
Affiche toutes les entrées avec un sélecteur donné. Lorsqu'aucun sélecteur n'est donné, affiche toutes les entrées de la table APP, classées par sélecteur.
flush
Supprime toutes les entrées avec un sélecteur donné. Lorsqu'aucun sélecteur n'est donné, supprime toutes les entrées de la table APP.
add
del
Ajoute et, respectivement, supprime des triplets APP individuels de et vers la table DCB APP.
replace
Prend la liste des entrées mentionnées comme paramètre, et ajoute celles qui ne sont pas encore présentes dans la table APP. Ensuite, supprime les entrées dont le sélecteur et l'identifiant de protocole ont été mentionnés en paramètre, mais pas avec la priorité exacte. Cela a pour effet, pour le sélecteur et l'identifiant de protocole donnés, que la table ne contient que la (les) priorité(s) donnée(s) en paramètre.

PARAMETRES

Le tableau suivant montre les paramètres tels qu'ils seraient utilisés avec les commandes add, del et replace. Pour show et flush, le nom du paramètre doit être utilisé comme un simple mot-clé sans arguments supplémentaires.

default-prio PRIO-LIST
La priorité à utiliser pour le trafic dont la priorité n'est pas autrement spécifiée. L'argument est une liste de priorités individuelles. Notez que les règles default-prio sont configurées comme des triplets (EtherType, 0, PRIO). dcb app traduit ces règles vers et depuis le nom symbolique default-prio.
ethtype-prio ET-MAP
ET-MAP utilise la syntaxe des paramètres de tableau, voir dcb(8) pour plus de détails. Les clés sont les valeurs EtherType. Les valeurs sont les priorités à attribuer au trafic avec l'EtherType correspondant.
stream-port-prio PORT-MAP
dgram-port-prio PORT-MAP
port-prio PORT-MAP
PORT-MAP utilise la syntaxe des paramètres de tableau, voir dcb(8) pour plus de détails. Les clés sont les numéros de port de destination L4 sur lesquels les correspondances sont effectuées, respectivement, pour le trafic TCP et SCTP, UDP et DCCP, et l'un ou l'autre de ceux-ci. Les valeurs sont les priorités qui doivent être attribuées au trafic correspondant.
dscp-prio DSCP-MAP
DSCP-MAP utilise la syntaxe des paramètres de tableau, voir dcb(8) pour plus de détails. Les clés sont les points DSCP, les valeurs sont les priorités attribuées au trafic avec le DSCP correspondant. Les points DSCP peuvent être écrits soit directement sous forme de valeurs numériques, soit en utilisant des noms symboliques spécifiés dans /etc/iproute2/rt_dsfield (notez cependant que le fichier spécifie les valeurs dsfield complètes de 8 bits, tandis que dcb app n'utilisera que les six bits supérieurs). dcb app show formatera de même les valeurs DSCP sous forme de noms symboliques si possible. L'option de ligne de commande -N désactive la traduction de l'affichage.
pcp-prio PCP-MAP
PCP-MAP utilise la syntaxe des paramètres de tableau, voir dcb(8) pour plus de détails. Les clés sont PCP/DEI. Les valeurs sont les priorités attribuées au trafic avec le PCP/DEI correspondant. Les valeurs PCP/DEI sont écrites comme une combinaison de valeurs numériques et symboliques, pour tenir compte des deux. PCP toujours sous forme numérique, par ex. 0 .. 7, et DEI sous forme symbolique, par ex. 'de' (drop-eligible), indiquant que le bit DEI est 1 ou 'nd' (not-drop-eligible), indiquant que le bit DEI est 0. En combinaison, 2de:1 se traduit par un mappage de PCP=2 et DEI=1 à la priorité 1.

EXEMPLE & UTILISATION

Prioriser le trafic avec DSCP 0 à la priorité 0, 24 à 3 et 48 à 6 :

# dcb app add dev eth0 dscp-prio 0:0 24:3 48:6

Ajouter une autre règle pour configurer DSCP 24 à la priorité 2 et afficher le résultat :

# dcb app add dev eth0 dscp-prio 24:2
# dcb app show dev eth0 dscp-prio
dscp-prio 0:0 CS3:2 CS3:3 CS6:6
# dcb -N app show dev eth0 dscp-prio
dscp-prio 0:0 24:2 24:3 48:6

Reconfigurer la table de sorte que la seule règle pour DSCP 24 soit l'attribution de la priorité 4 :

# dcb app replace dev eth0 dscp-prio 24:4
# dcb app -N show dev eth0 dscp-prio
dscp-prio 0:0 24:4 48:6

Vider toutes les règles DSCP :

# dcb app flush
