DCHKAB

Objectif :

!>
!> DCHKAB est le programme de test pour la routine LAPACK DOUBLE PRECISION
!> DSGESV/DSPOSV
!>
!> Le programme doit être piloté par un court fichier de données. Les 5 premières
!> lignes spécifient les dimensions du problème et les options du programme en
!> utilisant une entrée dirigée par liste. Les lignes restantes spécifient les
!> chemins de test LAPACK et le nombre de types de matrices à utiliser lors des
!> tests. Un exemple annoté de fichier de données peut être obtenu en
!> supprimant les 3 premiers caractères des 10 lignes suivantes :
!> Fichier de données pour tester DSGESV LAPACK DOUBLE PRECISION
!> 7                      Nombre de valeurs de M
!> 0 1 2 3 5 10 16        Valeurs de M (dimension de ligne)
!> 1                      Nombre de valeurs de NRHS
!> 2                      Valeurs de NRHS (nombre de côtés droits)
!> 20.0                   Seuil de la valeur du ratio de test
!> T                      Mettre T pour tester les routines LAPACK
!> T                      Mettre T pour tester les sorties d'erreur
!> DGE    11              Lister les types sur la ligne suivante si 0 < NTYPES < 11
!> DPO    9               Lister les types sur la ligne suivante si 0 < NTYPES <  9
!> 
!>  NMAX    INTEGER
!>          La valeur maximale autorisée pour N
!>
!>  MAXIN   INTEGER
!>          Le nombre de valeurs différentes qui peuvent être utilisées pour chacun
!>          de M, N, NRHS, NB et NX
!>
!>  MAXRHS  INTEGER
!>          Le nombre maximal de côtés droits
!>
!>  NIN     INTEGER
!>          Le numéro d'unité pour l'entrée
!>
!>  NOUT    INTEGER
!>          Le numéro d'unité pour la sortie
!>
