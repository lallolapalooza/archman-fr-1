NOM

dcd-client - client d'autocomplétion pour le langage de programmation D

SYNTAXE

dcd-client [-c, --cursorPos positionCurseur] [-p, --port numeroPort] [--tcp] [--socketFile cheminFichier] [-I repertoire] [-h, --help] [-l, --symbolLocation] [-s, --search nomSymbole] [-d, --doc] [-q, --query, --status] [--shutdown] [--clearCache] [--version] [nomFichier]

DESCRIPTION

dcd-client est un client pour dcd-server et est généralement utilisé par les scripts d'éditeurs de texte.

OPTIONS

-c, --cursorPos positionCurseur

Fournit l'autocomplétion à la position du curseur donnée. La position du curseur est mesurée en octets depuis le début du code source.
-p, --port numeroPort
Choisit le numéro de port sur lequel dcd-client écoute. Ce commutateur implique --tcp.
--tcp
Écoute sur une socket TCP au lieu d'une socket de domaine UNIX. C'est le comportement par défaut sous Windows.
--socketFile cheminFichier
Définit le chemin à utiliser pour la socket de domaine UNIX. N'a aucun effet si les commutateurs --tcp ou --port sont utilisés.
-I repertoire
Informe dcd-server de mettre en cache tous les fichiers source D trouvés dans repertoire afin qu'ils soient inclus dans les réponses aux futures requêtes dcd-client.
-h, --help
Affiche un message d'aide
-l, --symbolLocation
Obtient le nom du fichier et la position où le symbole à la position du curseur a été défini.
-s, --search nomSymbole
Liste les emplacements où des symboles avec le nomSymbole donné peuvent être trouvés.
-d, --doc
Récupère les commentaires de documentation associés au symbole à la position du curseur.
-q, --query, --status
Interroge le statut du serveur. Retourne 0 si le serveur est en cours d'exécution. Retourne 1 si le serveur n'a pas pu être contacté.
--shutdown
Demande au serveur de s'arrêter
--clearCache
Demande au serveur de vider son cache d'informations d'autocomplétion.
nomFichier
Fournit des informations d'autocomplétion pour le fichier avec le nom donné.
