sous-routine dchksb2stg (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) sd, double precision, dimension( * ) se, double precision, dimension( * ) d1, double precision, dimension( * ) d2, double precision, dimension( * ) d3, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( * ) work, integer lwork, double precision, dimension( * ) result, integer info)

DCHKSB2STG

But :

!>
!> DCHKSB2STG teste la réduction d'une matrice bande symétrique en forme
!> tridiagonale, utilisée avec le problème de valeurs propres symétrique.
!>
!> DSBTRD décompose une matrice bande symétrique A sous la forme U S U' , où ' signifie
!> transposée, S est symétrique tridiagonale, et U est orthogonale.
!> DSBTRD peut utiliser soit uniquement le triangle inférieur soit uniquement le triangle
!> supérieur de A ; DCHKSB2STG vérifie les deux cas.
!>
!> DSYTRD_SB2ST décompose une matrice bande symétrique A sous la forme U S U' ,
!> où ' signifie transposée, S est symétrique tridiagonale, et U est
!> orthogonale. DSYTRD_SB2ST peut utiliser soit uniquement le triangle inférieur soit uniquement le
!> triangle supérieur de A ; DCHKSB2STG vérifie les deux cas.
!>
!> DSTEQR décompose S sous la forme Z D1 Z'.
!> D1 est la matrice des valeurs propres calculée quand Z n'est pas calculée
!> et à partir du S résultant de DSBTRD (utilisée comme référence pour DSYTRD_SB2ST)
!> D2 est la matrice des valeurs propres calculée quand Z n'est pas calculée
!> et à partir du S résultant de DSYTRD_SB2ST .
!> D3 est la matrice des valeurs propres calculée quand Z n'est pas calculée
!> et à partir du S résultant de DSYTRD_SB2ST .
!>
!> Quand DCHKSB2STG est appelé, un certain nombre de tailles de matrices (), un certain
!> nombre de largeurs de bande (), et un certain nombre de types de matrices
!> sont spécifiés. Pour chaque taille (), chaque largeur de bande () inférieure ou
!> égale à , et chaque type de matrice, une matrice sera générée
!> et utilisée pour tester la routine de réduction bande symétrique. Pour chaque
!> matrice, un certain nombre de tests seront effectués :
!>
!> (1)     | A - V S V' | / ( |A| n ulp )  calculé par DSBTRD avec
!>                                         UPLO='U'
!>
!> (2)     | I - UU' | / ( n ulp )
!>
!> (3)     | A - V S V' | / ( |A| n ulp )  calculé par DSBTRD avec
!>                                         UPLO='L'
!>
!> (4)     | I - UU' | / ( n ulp )
!>
!> (5)     | D1 - D2 | / ( |D1| ulp )      où D1 est calculé par
!>                                         DSBTRD avec UPLO='U' et
!>                                         D2 est calculé par
!>                                         DSYTRD_SB2ST avec UPLO='U'
!>
!> (6)     | D1 - D3 | / ( |D1| ulp )      où D1 est calculé par
!>                                         DSBTRD avec UPLO='U' et
!>                                         D3 est calculé par
!>                                         DSYTRD_SB2ST avec UPLO='L'
!>
!> Les tailles sont spécifiées par un tableau NN(1:NSIZES) ; la valeur de
!> chaque élément NN(j) spécifie une taille.
!> Les types sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ;
!> si DOTYPE(j) est .TRUE., alors le type de matrice j sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des éléments également espacés
!>      1, ..., ULP et des signes aléatoires.
!>      (ULP = (premier nombre plus grand que 1) - 1 )
!> (4)  Une matrice diagonale avec des éléments géométriquement espacés
!>      1, ..., ULP et des signes aléatoires.
!> (5)  Une matrice diagonale avec des éléments 1, ULP, ..., ULP
!>      et des signes aléatoires.
!>
!> (6)  Identique à (4), mais multiplié par SQRT( seuil de débordement )
!> (7)  Identique à (4), mais multiplié par SQRT( seuil de dépassement négatif )
!>
!> (8)  Une matrice de la forme U' D U, où U est orthogonale et
!>      D a des éléments également espacés 1, ..., ULP avec des signes
!>      aléatoires sur la diagonale.
!>
!> (9)  Une matrice de la forme U' D U, où U est orthogonale et
!>      D a des éléments géométriquement espacés 1, ..., ULP avec des signes
!>      aléatoires sur la diagonale.
!>
!> (10) Une matrice de la forme U' D U, où U est orthogonale et
!>      D a des éléments 1, ULP,..., ULP avec des signes
!>      aléatoires sur la diagonale.
!>
!> (11) Identique à (8), mais multiplié par SQRT( seuil de débordement )
!> (12) Identique à (8), mais multiplié par SQRT( seuil de dépassement négatif )
!>
!> (13) Matrice symétrique avec des éléments aléatoires choisis dans (-1,1).
!> (14) Identique à (13), mais multiplié par SQRT( seuil de débordement )
!> (15) Identique à (13), mais multiplié par SQRT( seuil de dépassement négatif )
!>

Paramètres

NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il vaut zéro,
!>          DCHKSB2STG ne fait rien. Il doit être au moins zéro.
!>

NN

!>          NN est un tableau INTEGER, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées. Les valeurs doivent être au moins
!>          zéro.
!>

NWDTHS

!>          NWDTHS est INTEGER
!>          Le nombre de largeurs de bande à utiliser. S'il vaut zéro,
!>          DCHKSB2STG ne fait rien. Il doit être au moins zéro.
!>

KK

!>          KK est un tableau INTEGER, dimension (NWDTHS)
!>          Un tableau contenant les largeurs de bande à utiliser pour les matrices
!>          bandes. Les valeurs doivent être au moins zéro.
!>

NTYPES

!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il vaut zéro, DCHKSB2STG
!>          ne fait rien. Il doit être au moins zéro. S'il vaut MAXTYP+1
!>          et que NSIZES vaut 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser la matrice présente dans A.
!>          Cela n'est utile que si DOTYPE(1:MAXTYP) vaut .FALSE. et
!>          DOTYPE(MAXTYP+1) vaut .TRUE. .
!>

DOTYPE

!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) vaut .TRUE., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximal de types
!>          défini (PARAMETER MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une suite
!>          linéaire congruentielle limitée à de petits entiers, et doit donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées dans le
!>          prochain appel à DCHKSB2STG pour continuer la même suite de nombres
!>          aléatoires.
!>

THRESH

!>          THRESH est DOUBLE PRECISION
!>          Un test est considéré comme réussi si ERRBND, calculé comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être O(1), donc THRESH devrait être un multiple
!>          raisonnablement petit de 1, p. ex., 10 ou 100. En particulier,
!>          il ne devrait pas dépendre de la précision (simple vs. double)
!>          ni de la taille de la matrice. Il doit être au moins égal à zéro.
!>

NOUNIT

!>          NOUNIT est un INTEGER
!>          Le numéro d'unité FORTRAN pour l'affichage des messages d'erreur
!>          (p. ex., si une routine retourne IINFO différent de 0.)
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension
!>                            (LDA, max(NN))
!>          Utilisé pour stocker la matrice dont les valeurs propres doivent être
!>          calculées.
!>

LDA

!>          LDA est un INTEGER
!>          La dimension principale de A. Elle doit être au moins 2 (et non 1 !)
!>          et au moins max( KK )+1.
!>

SD

!>          SD est un tableau DOUBLE PRECISION, dimension (max(NN))
!>          Utilisé pour stocker la diagonale de la matrice tridiagonale calculée
!>          par DSBTRD.
!>

SE

!>          SE est un tableau DOUBLE PRECISION, dimension (max(NN))
!>          Utilisé pour stocker la sous-diagonale de la matrice tridiagonale
!>          calculée par DSBTRD.
!>

D1

!>          D1 est un tableau DOUBLE PRECISION, dimension (max(NN))
!>

D2

!>          D2 est un tableau DOUBLE PRECISION, dimension (max(NN))
!>

D3

!>          D3 est un tableau DOUBLE PRECISION, dimension (max(NN))
!>

U

!>          U est un tableau DOUBLE PRECISION, dimension (LDU, max(NN))
!>          Utilisé pour stocker la matrice orthogonale calculée par DSBTRD.
!>

LDU

!>          LDU est un INTEGER
!>          La dimension principale de U. Elle doit être au moins 1
!>          et au moins max( NN ).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK)
!>

LWORK

!>          LWORK est un INTEGER
!>          Le nombre d'entrées dans WORK. Il doit être au moins
!>          max( LDA+1, max(NN)+1 )*max(NN).
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (4)
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter
!>          un débordement.
!>

INFO

!>          INFO est un INTEGER
!>          Si 0, tout s'est déroulé correctement.
!>
!>-----------------------------------------------------------------------
!>
!>       Quelques variables et paramètres locaux :
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Réels 0 et 1.
!>       MAXTYP          Le nombre de types définis.
!>       NTEST           Le nombre de tests effectués, ou qui peuvent
!>                       être effectués jusqu'à présent, pour la matrice courante.
!>       NTESTT          Le nombre total de tests effectués jusqu'à présent.
!>       NMAX            La plus grande valeur dans NN.
!>       NMATS           Le nombre de matrices générées jusqu'à présent.
!>       NERRS           Le nombre de tests qui ont dépassé THRESH
!>                       jusqu'à présent.
!>       COND, IMODE     Valeurs à passer aux générateurs de matrices.
!>       ANORM           Norme de A ; passée aux générateurs de matrices.
!>
!>       OVFL, UNFL      Seuils de débordement et de sous-flux.
!>       ULP, ULPINV     Précision relative la plus fine et son inverse.
!>       RTOVFL, RTUNFL  Racines carrées des 2 valeurs précédentes.
!>               Les quatre tableaux suivants décodent JTYPE :
!>       KTYPE(j)        Le type général (1-10) pour le type .
!>       KMODE(j)        La valeur MODE à passer au générateur
!>                       de matrices pour le type .
!>       KMAGN(j)        L'ordre de grandeur ( O(1),
!>                       O(overflow^(1/2) ), O(underflow^(1/2) )
!>
