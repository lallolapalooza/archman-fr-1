sous-programme dchkec (double précision thresh, logique tsterr, entier nin, entier nout)

DCHKEC

But :

!>
!> DCHKEC teste les routines d'estimation de condition propre
!>        DLALN2, DLASY2, DLANV2, DLAQTR, DLAEXC,
!>        DTRSYL, DTREXC, DTRSNA, DTRSEN, DTGEXC
!>
!> Dans tous les cas, la routine exécute un ensemble fixe d'exemples numériques,
!> les soumet à divers tests, et compare les résultats des tests à un seuil THRESH.
!> De plus, DTREXC, DTRSNA et DTRSEN sont testés en lisant des exemples pré-calculés
!> à partir d'un fichier (sur l'unité d'entrée NIN). Les sorties sont écrites
!> sur l'unité de sortie NOUT.
!>

Paramètres

THRESH 
!>          THRESH est de type DOUBLE PRECISION
!>          Seuil pour les tests de résidus. Un rapport de test calculé passe
!>          le seuil s'il est inférieur à THRESH.
!>

TSTERR

!>          TSTERR est de type LOGICAL
!>          Indicateur qui signale si les sorties d'erreur doivent être testées.
!>

NIN

!>          NIN est de type INTEGER
!>          Le numéro d'unité logique pour l'entrée.
!>

NOUT

!>          NOUT est de type INTEGER
!>          Le numéro d'unité logique pour la sortie.
!>
