NOM

dcmftest - Teste si un fichier utilise le format partie 10 DICOM

SYNOPIS

dcmftest fichier...

DESCRIPTION

L'utilitaire dcmftest vérifie si les fichiers spécifiés sur la ligne de commande sont des fichiers DICOM au format partie 10 (avec en-tête méta).

PARAMÈTRES

dcmfile-in  Nom du fichier DICOM d'entrée à vérifier

NOTES

Tous les fichiers spécifiés sur la ligne de commande sont vérifiés pour la présence du "mot magique" DICOM 'DICM' à la position d'octet 128. Aucune tentative n'est faite pour analyser l'ensemble de données complet. Pour chaque fichier, le résultat du test est imprimé sur stdout sous la forme "oui : <nom de fichier>\n" ou "non : <nom de fichier>\n". L'utilitaire se termine avec un code de retour correspondant au nombre de fichiers jugés non-DICOM, c'est-à-dire si tous les fichiers passent comme fichiers DICOM, la valeur de retour est 0. Ce comportement est destiné à être utilisé dans les scripts shell.

VOIR AUSSI

dcmgpdir(1), dcmmkdir(1)
