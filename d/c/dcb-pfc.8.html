NOM

dcb-pfc - afficher / manipuler les paramètres PFC (Priority-based Flow Control) du sous-système DCB (Data Center Bridging)

SYNTAXE


dcb [ OPTIONS ] pfc { COMMANDE | help }

dcb pfc show dev DEV [ pfc-cap ] [ prio-pfc ] [ macsec-bypass ] [ delay ] [ requests ] [ indications ]

dcb pfc set dev DEV [ prio-pfc PFC-MAP ] [ macsec-bypass { on | off } ] [ delay ENTIER ]

PFC-MAP := [ PFC-MAP ] PFC-MAPPING

PFC-MAPPING := { PRIO | all }:{ on | off }

PRIO := { 0 .. 7 }

DESCRIPTION

dcb pfc est utilisé pour configurer les attributs Priority-based Flow Control via l'interface DCB (Data Center Bridging) de Linux. PFC permet de marquer les flux avec une certaine priorité comme sans perte, et contient la configuration associée, ainsi que les compteurs PFC.

PARAMETRES

Pour les paramètres de lecture-écriture, la description suivante concerne uniquement la direction d'écriture, c'est-à-dire telle qu'utilisée avec la commande set. Pour la commande show, le nom du paramètre doit être utilisé comme un mot-clé simple sans arguments supplémentaires. Cela indique à l'outil d'afficher la valeur d'un paramètre donné. Lorsque aucun paramètre n'est fourni, l'outil affiche la configuration PFC complète.

pfc-cap
Une propriété en lecture seule qui affiche le nombre de classes de trafic pouvant supporter simultanément le PFC.
requests
Un compte en lecture seule des trames PFC envoyées par classe de trafic. Affiché uniquement lorsque -s est donné, ou lorsqu'il est demandé explicitement.
indications
Un compte en lecture seule des trames PFC reçues par classe de trafic. Affiché uniquement lorsque -s est donné, ou lorsqu'il est demandé explicitement.
macsec-bypass { on | off }
Indique si la station émettrice est capable de contourner le traitement MACsec lorsque MACsec est désactivé.
prio-pfc PFC-MAP
PFC-MAP utilise la syntaxe des paramètres de tableau, voir dcb(8) pour plus de détails. Les clés sont les priorités, les valeurs sont des indicateurs on / off indiquant si le PFC est activé pour une priorité donnée.
delay ENTIER
La marge accordée pour le délai de propagation aller-retour du lien en bits. La valeur doit être comprise entre 0 et 65535.

EXEMPLE & UTILISATION

Activer le PFC sur les priorités 6 et 7, en laissant les autres intactes :

# dcb pfc set dev eth0 prio-pfc 6:on 7:on

Désactiver le PFC de toutes les priorités sauf 6 et 7, et configurer le délai à 4096 bits :

# dcb pfc set dev eth0 prio-pfc all:off 6:on 7:on delay 0x1000

Afficher ce qui a été configuré :

# dcb pfc show dev eth0
pfc-cap 8 macsec-bypass off delay 4096
prio-pfc 0:off 1:off 2:off 3:off 4:off 5:off 6:on 7:on

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.
