dblink_open(3)

Paquet: postgresql

Licences: PostgreSQL

DBLINK_OPEN(3) Documentation PostgreSQL 18.1 DBLINK_OPEN(3)

NOM

dblink_open - ouvre un curseur dans une base de données distante

SYNTAXE

dblink_open(text nom_curseur, text sql [, bool ignorer_erreur]) returns text
dblink_open(text nom_connexion, text nom_curseur, text sql [, bool ignorer_erreur]) returns text

DESCRIPTION

dblink_open() ouvre un curseur dans une base de données distante. Le curseur peut ensuite être manipulé avec dblink_fetch() et dblink_close().

ARGUMENTS

nom_connexion

Nom de la connexion à utiliser ; omettre ce paramètre pour utiliser la connexion sans nom.

nom_curseur

Le nom à attribuer à ce curseur.

sql

L'instruction SELECT que vous souhaitez exécuter dans la base de données distante, par exemple select * from pg_class.

ignorer_erreur

Si vrai (par défaut lorsqu'il est omis), une erreur déclenchée du côté distant de la connexion provoquera également une erreur locale. Si faux, l'erreur distante est signalée localement comme une NOTICE, et la valeur de retour de la fonction est définie sur ERREUR.

VALEUR DE RETOUR

Retourne le statut, soit OK soit ERREUR.

NOTES

Comme un curseur ne peut persister qu'à l'intérieur d'une transaction, dblink_open démarre un bloc de transaction explicite (BEGIN) du côté distant, si le côté distant n'était pas déjà dans une transaction. Cette transaction sera refermée lorsque le dblink_close correspondant sera exécuté. Notez que si vous utilisez dblink_exec pour modifier des données entre dblink_open et dblink_close, et qu'ensuite une erreur se produit ou que vous utilisez dblink_disconnect avant dblink_close, votre modification *sera perdue* car la transaction sera annulée.

EXEMPLES

SELECT dblink_connect('dbname=postgres options=-csearch_path=');
 dblink_connect
----------------
 OK
(1 row)
SELECT dblink_open('foo', 'select proname, prosrc from pg_proc');
 dblink_open
-------------
 OK
(1 row)
