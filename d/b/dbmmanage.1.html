Si vous spécifiez un nom_utilisateur, il n'affiche que l'enregistrement particulier. dbmmanage passwords.dat view BUGS Il faut savoir qu'il existe un certain nombre de formats de fichiers DBM différents, et qu'il est très probable que des bibliothèques pour plus d'un format existent sur votre système. Les trois exemples principaux sont SDBM, NDBM, le GDBM du projet GNU, et Berkeley DB 2. Malheureusement, toutes ces bibliothèques utilisent des formats de fichiers différents, et vous devez vous assurer que le format de fichier utilisé par fichier est le même format que dbmmanage s'attend à voir. dbmmanage n'a

actuellement

aucun moyen de déterminer de quel type de fichier DBM il s'agit. S'il est utilisé avec le mauvais format, il renverra simplement rien, ou peut créer un fichier DBM différent avec un nom différent, ou au pire, il peut corrompre le fichier DBM si vous essayez d'y écrire. dbmmanage a une liste de préférences de formats DBM, définie par le tableau @AnyDBM::ISA près du début du programme. Puisque nous préférons le format de fichier Berkeley DB 2, l'ordre dans lequel dbmmanage cherchera les bibliothèques système est Berkeley DB 2, puis NDBM, puis GDBM et ensuite SDBM.
