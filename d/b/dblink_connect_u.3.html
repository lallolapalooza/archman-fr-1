DBLINK_CONNECT_U(3) Documentation PostgreSQL 18.1 DBLINK_CONNECT_U(3)

NOM

dblink_connect_u - ouvre une connexion persistante à une base de données distante, sans sécurité

SYNTAXE

dblink_connect_u(texte connstr) retourne texte
dblink_connect_u(texte connname, texte connstr) retourne texte

DESCRIPTION

dblink_connect_u() est identique à dblink_connect(), sauf qu'elle permet aux non-superutilisateurs de se connecter en utilisant n'importe quelle méthode d'authentification.

Si le serveur distant sélectionne une méthode d'authentification qui n'implique pas de mot de passe, une usurpation d'identité et une élévation de privilèges subséquente peuvent se produire, car la session semblera provenir de l'utilisateur sous lequel le serveur PostgreSQL local s'exécute. De plus, même si le serveur distant exige un mot de passe, il est possible que le mot de passe soit fourni depuis l'environnement du serveur, comme un fichier ~/.pgpass appartenant à l'utilisateur du serveur. Cela ouvre non seulement un risque d'usurpation d'identité, mais aussi la possibilité d'exposer un mot de passe à un serveur distant non fiable. Par conséquent, dblink_connect_u() est initialement installée avec tous les privilèges révoqués de PUBLIC, la rendant non appelable sauf par les superutilisateurs. Dans certaines situations, il peut être approprié d'accorder la permission EXECUTE pour dblink_connect_u() à des utilisateurs spécifiques considérés comme fiables, mais cela doit être fait avec prudence. Il est également recommandé que tout fichier ~/.pgpass appartenant à l'utilisateur du serveur ne contienne *pas* d'entrées spécifiant un nom d'hôte générique.

Pour plus de détails, voir dblink_connect().
