dblink_close(3)

Paquet: postgresql

Licences: PostgreSQL

DBLINK_CLOSE(3) Documentation PostgreSQL 18.1 DBLINK_CLOSE(3)

NOM

dblink_close - ferme un curseur dans une base de données distante

SYNTAXE

dblink_close(text nom_curseur [, bool ignorer_erreur]) retourne text
dblink_close(text nom_connexion, text nom_curseur [, bool ignorer_erreur]) retourne text

DESCRIPTION

dblink_close ferme un curseur précédemment ouvert avec dblink_open.

ARGUMENTS

nom_connexion

Nom de la connexion à utiliser ; omettre ce paramètre utilise la connexion sans nom.

nom_curseur

Nom du curseur à fermer.

ignorer_erreur

Si vrai (la valeur par défaut lorsqu'elle est omise), une erreur levée du côté distant de la connexion provoque également une erreur locale. Si faux, l'erreur distante est rapportée localement comme une NOTICE, et la valeur de retour de la fonction est définie sur ERREUR.

VALEUR DE RETOUR

Retourne le statut, OK ou ERREUR.

NOTES

Si dblink_open a démarré un bloc de transaction explicite, et que c'est le dernier curseur ouvert restant dans cette connexion, dblink_close émettra le COMMIT correspondant.

EXEMPLES

SELECT dblink_connect('dbname=postgres options=-csearch_path=');
 dblink_connect
----------------
 OK
(1 rang)
SELECT dblink_open('foo', 'select proname, prosrc from pg_proc');
 dblink_open
-------------
 OK
(1 rang)
SELECT dblink_close('foo');
 dblink_close
--------------
 OK
(1 rang)
