NOM

DBM_Filter::compress - filtre pour DBM_Filter

SYNTAXE

use SDBM_File; # ou DB_File, GDBM_File, NDBM_File, ODBM_File
use DBM_Filter ;
$db = tie %hash, ...
$db->Filter_Push('compress');

DESCRIPTION

Ce filtre DBM compressera toutes les données avant de les écrire dans la base de données et les décompressera lors de la lecture.

Une erreur fatale sera générée si le module Compress::Zlib n'est pas disponible.

VOIR AUSSI

DBM_Filter, perldbmfilter, Compress::Zlib
