dblink_disconnect(3)

Paquet: postgresql

Licences: PostgreSQL

DBLINK_DISCONNECT(3) Documentation PostgreSQL 18.1 DBLINK_DISCONNECT(3)

NOM

dblink_disconnect - ferme une connexion persistante à une base de données distante

SYNTAXE

dblink_disconnect() retourne text
dblink_disconnect(text connname) retourne text

DESCRIPTION

dblink_disconnect() ferme une connexion précédemment ouverte par dblink_connect(). La forme sans argument ferme une connexion sans nom.

ARGUMENTS

connname

Le nom d'une connexion nommée à fermer.

VALEUR DE RETOUR

Retourne le statut, qui est toujours OK (car toute erreur provoque le lancement d'une exception par la fonction au lieu de retourner une valeur).

EXEMPLES

SELECT dblink_disconnect();
 dblink_disconnect
-------------------
 OK
(1 rangée)
SELECT dblink_disconnect('myconn');
 dblink_disconnect
-------------------
 OK
(1 rangée)
