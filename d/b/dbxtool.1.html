NOM

dbxtool - mécanisme pour distribuer et appliquer les mises à jour UEFI Secure Boot DBX

SYNTAXE

dbxtool [--dbx=fichier_dbx | -d fichier_dbx ] [ --list | -l ] [ --verbose | -v ] [ --apply | -a ] [ repertoire_maj | maj0 [ ... majN ]]

DESCRIPTION

dbxtool est un outil en ligne de commande et un service systemd à usage unique pour appliquer les mises à jour UEFI Secure Boot DBX.

OPTIONS

--dbx=fichier_dbx
Utilise un fichier spécifié pour dbx plutôt que la variable système. Cette option ne fonctionne qu'avec --list.
--list
Liste les entrées DBX dans la base de données système, ou dans une copie de celle-ci ou un fichier de mise à jour.
--verbose
Affiche de nombreuses informations détaillées sur ce que fait dbxtool.
--apply
Applique les mises à jour spécifiées sur la ligne de commande. Ne fonctionne pas avec --dbx. Cet argument nécessite soit un argument repertoire_maj, soit un ou plusieurs arguments majN.
repertoire_maj
Répertoire des mises à jour dbx. Les noms de fichiers doivent se terminer par ".bin". Cet argument ne fonctionne qu'avec --apply.
maj0
Une mise à jour dbx individuelle. Cet argument ne fonctionne qu'avec --apply.
