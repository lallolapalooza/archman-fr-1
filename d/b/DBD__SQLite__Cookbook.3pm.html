NOM

DBD::SQLite::Cookbook - Le cookbook DBD::SQLite

DESCRIPTION

Ceci est le cookbook DBD::SQLite.

Il est destiné à servir de lieu de stockage pour diverses fonctions et formules à utiliser dans les API de rappel de DBD::SQLite.

FONCTIONS AGREGÉES

Variance

Ceci est une fonction d'agrégation simple qui retourne une variance. Elle est adaptée d'un exemple d'implémentation dans pysqlite.

package variance;

sub new { bless [], shift; }

sub step {
    my ( $self, $value ) = @_;

    push @$self, $value;
}

sub finalize {
    my $self = $_[0];

    my $n = @$self;

    # La variance est NULL sauf s'il y a plus d'une ligne
    return undef unless $n || $n == 1;

    my $mu = 0;
    foreach my $v ( @$self ) {
        $mu += $v;
    }
    $mu /= $n;

    my $sigma = 0;
    foreach my $v ( @$self ) {
        $sigma += ($v - $mu)**2;
    }
    $sigma = $sigma / ($n - 1);

    return $sigma;
}

# NOTE : Si vous utilisez un ancien DBI (< 1.608),
# utilisez $dbh->func(..., "create_aggregate") à la place.
$dbh->sqlite_create_aggregate( "variance", 1, 'variance' );

La fonction peut ensuite être utilisée ainsi :

SELECT group_name, variance(score)
FROM results
GROUP BY group_name;

Variance (économe en mémoire)

Une fonction de variance plus efficace, optimisée pour l'utilisation de la mémoire au détriment de la précision :

package variance2;

sub new { bless {sum => 0, count=>0, hash=> {} }, shift; }

sub step {
    my ( $self, $value ) = @_;
    my $hash = $self->{hash};

    # en tronquant et en hachant, nous pouvons traiter beaucoup plus de points de données
    $value = int($value); # changer selon le besoin de précision
                          # utiliser sprintf pour la précision en virgule flottante arbitraire
    if (exists $hash->{$value}) {
        $hash->{$value}++;
    } else {
        $hash->{$value} = 1;
    }
    $self->{sum} += $value;
    $self->{count}++;
}

sub finalize {
    my $self = $_[0];

    # La variance est NULL sauf s'il y a plus d'une ligne
    return undef unless $self->{count} > 1;

    # calculer la moyenne
    my $mu = $self->{sum} / $self->{count};

    my $sigma = 0;
    while (my ($h, $v) = each %{$self->{hash}}) {
        $sigma += (($h - $mu)**2) * $v;
    }
    $sigma = $sigma / ($self->{count} - 1);

    return $sigma;
}

La fonction peut ensuite être utilisée ainsi :

SELECT group_name, variance2(score)
FROM results
GROUP BY group_name;

Variance (très évolutive)

Une troisième implémentation de variance, conçue pour des ensembles de données arbitrairement grands :

package variance3;

sub new { bless {mu=>0, count=>0, S=>0}, shift; }

sub step {
    my ( $self, $value ) = @_;
    $self->{count}++;
    my $delta = $value - $self->{mu};
    $self->{mu} += $delta/$self->{count};
    $self->{S} += $delta*($value - $self->{mu});
}

sub finalize {
    my $self = $_[0];
    return $self->{S} / ($self->{count} - 1);
}

La fonction peut ensuite être utilisée ainsi :

SELECT group_name, variance3(score)
FROM results
GROUP BY group_name;
