NOM

DBD::Gofer::Transport::pipeone - Transport client DBD::Gofer pour les tests

SYNTAXE

$original_dsn = "...";
DBI->connect("dbi:Gofer:transport=pipeone;dsn=$original_dsn",...)

ou, activer en définissant la variable d'environnement DBI_AUTOPROXY :

export DBI_AUTOPROXY="dbi:Gofer:transport=pipeone"

DESCRIPTION

Se connecter via DBD::Gofer et exécuter chaque requête en démarrant un sous-processus. C'est, comme on peut l'imaginer, spectaculairement inefficace !

Ceci est uniquement destiné aux tests. Il démontre en particulier que le côté serveur est complètement sans état.

Il fournit également une classe de base pour le transport beaucoup plus utile de DBD::Gofer::Transport::stream.
