DBUS-RUN-SESSION(1) Commandes utilisateur DBUS-RUN-SESSION(1)

NOM

dbus-run-session - démarre un processus en tant que nouvelle session D-Bus

SYNTAXE

dbus-run-session [--config-file NOMFICHIER] [--dbus-daemon BINAIRE] [--] PROGRAMME [ARGUMENTS...]

dbus-run-session --help

dbus-run-session --version

DESCRIPTION

dbus-run-session est utilisé pour démarrer une instance de bus de session de dbus-daemon à partir d'un script shell, et démarrer un programme spécifié dans cette session. Le dbus-daemon s'exécutera aussi longtemps que le programme, après quoi il se terminera.

Une utilisation consiste à exécuter un shell avec son propre dbus-daemon dans une session en mode texte ou SSH, et à faire en sorte que le dbus-daemon se termine automatiquement à la sortie du sous-shell, comme ceci :

dbus-run-session -- bash

ou pour remplacer complètement le shell de connexion, en combinant dbus-run-session avec l'instruction exec :

exec dbus-run-session -- bash

Une autre utilisation est d'exécuter des tests de régression et des choses similaires dans une session D-Bus isolée, afin d'éviter soit d'interférer avec la "vraie" session D-Bus, soit de dépendre de l'existence d'une session D-Bus active, par exemple :

dbus-run-session -- make check

ou (dans automake(1)) :

  AM_TESTS_ENVIRONMENT = export MY_DEBUG=all;
  LOG_COMPILER = dbus-run-session
  AM_LOG_FLAGS = --

OPTIONS

--config-file=NOMFICHIER, --config-file NOMFICHIER

Passe --config-file=NOMFICHIER au bus daemon, au lieu de lui passer l'argument --session. Voir dbus-daemon(1).

--dbus-daemon=BINAIRE, --dbus-daemon BINAIRE

Exécute BINAIRE en tant que dbus-daemon(1), au lieu de chercher dans le PATH de la manière habituelle un exécutable nommé dbus-daemon.

--help

Affiche les informations d'utilisation et quitte.

--version

Affiche la version de dbus-run-session et quitte.

STATUT DE SORTIE

dbus-run-session se termine avec le statut de sortie de PROGRAMME, 0 si les options --help ou --version ont été utilisées, 127 en cas d'erreur dans dbus-run-session lui-même, ou 128+n si le PROGRAMME a été tué par le signal n.

ENVIRONNEMENT

Le PATH est recherché pour trouver PROGRAMME, et (si l'option --dbus-daemon n'est pas utilisée ou si son argument ne contient pas de caractère /) pour trouver dbus-daemon.

L'adresse du bus de session est mise à disposition de PROGRAMME dans la variable d'environnement DBUS_SESSION_BUS_ADDRESS.

Les variables DBUS_SESSION_BUS_PID, DBUS_SESSION_BUS_WINDOWID, DBUS_STARTER_BUS_TYPE et DBUS_STARTER_ADDRESS sont supprimées de l'environnement, si présentes.

BOGUES

Veuillez envoyer les rapports de bogues à la liste de diffusion D-Bus ou au tracker de bogues, voir https://www.freedesktop.org/wiki/Software/dbus/

AUTEUR

Voir https://dbus.freedesktop.org/doc/AUTHORS
