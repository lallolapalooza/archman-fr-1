Fournir un DBD::File dérivé pour travailler avec des définitions de tables fixes à travers le système de fichiers afin de démontrer comment DBI / les DBD en Perl pur pourraient
gérer des bases de données avec des structures hiérarchiques.
DBD::
Join
Fournir un pilote DBI capable de gérer plusieurs connexions à d'autres bases de données (comme DBD::Multiplex), mais en leur permettant de pointer vers différentes sources
de données et en autorisant les jointures entre leurs tables :
# Exemple # Soit la table 'lsof' une table dans DBD::Sys donnant une liste des fichiers ouverts en utilisant l'utilitaire lsof # Soit la table 'dir' une table de DBD::Dir $sth = $dbh->prepare( "select * from dir,lsof where path='/documents' and dir.entry = lsof.filename" ) $sth->execute(); # donne tous les fichiers ouverts dans '/documents' ... # Soit la table 'filesys' une table DBD::Sys des systèmes de fichiers connus sur l'hôte courant # Soit la table 'applications' une table de votre base de données de gestion de configuration # où les applications courantes (relocalisables, avec des points de montage pour les systèmes de fichiers) # sont stockées $sth = dbh->prepare( "select * from applications,filesys where " . "application.mountpoint = filesys.mountpoint and ". "filesys.mounted is true" ); $sth->execute(); # donne toutes les applications actuellement montées
sur cet hôte
