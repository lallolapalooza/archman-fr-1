DBUS-UUIDGEN(1) Commandes utilisateur DBUS-UUIDGEN(1)

NOM

dbus-uuidgen - Utilitaire pour générer des UUID

SYNTAXE

dbus-uuidgen [--version] [--ensure [=FILENAME]] [--get [=FILENAME]]

DESCRIPTION

La commande dbus-uuidgen génère ou lit un identifiant unique universel (UUID).

Notez que l'UUID D-Bus n'a aucun rapport avec la RFC 4122 et ne génère pas d'UUID compatibles avec cette spécification. De nombreux systèmes ont une commande séparée pour cela (souvent appelée "uuidgen").

Voir https://www.freedesktop.org/wiki/Software/dbus/ pour plus d'informations sur D-Bus.

L'utilisation principale de dbus-uuidgen est de s'exécuter dans le script post-installation d'un paquet D-Bus comme ceci :

  dbus-uuidgen --ensure

Cela garantira que /var/lib/dbus/machine-id existe et contient l'UUID. Il ne remplacera pas un UUID existant, car cet identifiant doit rester fixe pour une machine donnée au moins jusqu'au prochain redémarrage.

Les propriétés importantes de l'UUID machine sont que 1) il reste inchangé jusqu'au prochain redémarrage et 2) il est différent pour toute paire d'instances du noyau du système d'exploitation en cours d'exécution. C'est-à-dire que si deux processus voient le même UUID, ils devraient également voir la même mémoire partagée, les mêmes sockets de domaine UNIX, les mêmes affichages X locaux, la même résolution de localhost.localdomain, les mêmes identifiants de processus, et ainsi de suite.

Si vous exécutez dbus-uuidgen sans aucune option, il affiche simplement un nouvel UUID généré de toutes pièces.

Si vous l'exécutez avec --get, il affiche l'UUID machine par défaut, ou l'UUID dans le fichier spécifié si vous spécifiez un fichier.

Si vous essayez de modifier un machine-id existant sur un système en cours d'exécution, cela entraînera probablement des problèmes. N'essayez pas de modifier ce fichier. De plus, ne le rendez pas identique sur deux systèmes différents ; il doit être différent chaque fois que deux noyaux différents sont en cours d'exécution.

L'UUID doit être différent sur deux machines virtuelles différentes, car il y a deux noyaux différents.

OPTIONS

Les options suivantes sont prises en charge :

--get[=FILENAME]

Si aucun nom de fichier n'est donné, utilise par défaut localstatedir/lib/dbus/machine-id (localstatedir est généralement /var). Si ce fichier existe et est valide, l'UUID contenu dans le fichier est affiché sur la sortie standard. Sinon, la commande se termine avec un code différent de zéro.

--ensure[=FILENAME]

Si aucun nom de fichier n'est donné, utilise par défaut localstatedir/lib/dbus/machine-id (localstatedir est généralement /var). Si ce fichier existe, il sera validé et un code d'échec sera retourné s'il contient la mauvaise chose. Si le fichier n'existe pas, il sera créé avec un nouvel UUID. En cas de succès, aucune sortie n'est produite.

--version

Affiche la version de dbus-uuidgen
