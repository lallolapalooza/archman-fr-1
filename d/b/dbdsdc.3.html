sous-routine dbdsdc (caractère uplo, caractère compq, entier n, double précision, dimension( * ) d, double précision, dimension( * ) e, double précision, dimension( ldu, * ) u, entier ldu, double précision, dimension( ldvt, * ) vt, entier ldvt, double précision, dimension( * ) q, entier, dimension( * ) iq, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier info)

DBDSDC

But :

!>
!> DBDSDC calcule la décomposition en valeurs singulières (SVD) d'une matrice
!> bidiagonale réelle N par N (supérieure ou inférieure) B :  B = U * S * VT,
!> en utilisant une méthode de type diviser pour régner, où S est une matrice
!> diagonale avec des éléments diagonaux non négatifs (les valeurs singulières
!> de B), et U et VT sont des matrices orthogonales de vecteurs singuliers
!> gauches et droits, respectivement. DBDSDC peut être utilisé pour calculer
!> toutes les valeurs singulières, et optionnellement, les vecteurs singuliers
!> ou les vecteurs singuliers sous forme compacte.
!>
!> Le code appelle actuellement DLASDQ si seules les valeurs singulières sont désirées.
!> Cependant, il peut être légèrement modifié pour calculer les valeurs singulières
!> en utilisant la méthode diviser pour régner.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : B est supérieure bidiagonale.
!>          = 'L' : B est inférieure bidiagonale.
!>

COMPQ

!>          COMPQ est CHARACTER*1
!>          Spécifie si les vecteurs singuliers doivent être calculés
!>          comme suit :
!>          = 'N' : Calculer uniquement les valeurs singulières ;
!>          = 'P' : Calculer les valeurs singulières et calculer les vecteurs
!>                  singuliers sous forme compacte ;
!>          = 'I' : Calculer les valeurs singulières et les vecteurs singuliers.
!>

N

!>          N est un entier
!>          L'ordre de la matrice B.  N >= 0.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice bidiagonale B.
!>          À la sortie, si INFO=0, les valeurs singulières de B.
!>

E

!>          E est un tableau de DOUBLE PRÉCISION, dimension (N-1)
!>          À l'entrée, les éléments de E contiennent les éléments
!>          hors diagonale de la matrice bidiagonale dont la SVD est désirée.
!>          À la sortie, E a été détruit.
!>

U

!>          U est un tableau de DOUBLE PRÉCISION, dimension (LDU,N)
!>          Si  COMPQ = 'I', alors :
!>             À la sortie, si INFO = 0, U contient les vecteurs singuliers
!>             gauches de la matrice bidiagonale.
!>          Pour d'autres valeurs de COMPQ, U n'est pas référencé.
!>

LDU

!>          LDU est un entier
!>          La dimension principale du tableau U.  LDU >= 1.
!>          Si des vecteurs singuliers sont désirés, alors LDU >= max( 1, N ).
!>

VT

!>          VT est un tableau de DOUBLE PRÉCISION, dimension (LDVT,N)
!>          Si  COMPQ = 'I', alors :
!>             À la sortie, si INFO = 0, VT**T contient les vecteurs singuliers
!>             droits de la matrice bidiagonale.
!>          Pour d'autres valeurs de COMPQ, VT n'est pas référencé.
!>

LDVT

!>          LDVT est un entier
!>          La dimension principale du tableau VT.  LDVT >= 1.
!>          Si des vecteurs singuliers sont désirés, alors LDVT >= max( 1, N ).
!>

Q

!>          Q est un tableau de DOUBLE PRÉCISION, dimension (LDQ)
!>          Si  COMPQ = 'P', alors :
!>             À la sortie, si INFO = 0, Q et IQ contiennent les vecteurs singuliers
!>             gauches et droits sous forme compacte,
!>             nécessitant O(N log N) d'espace au lieu de 2*N**2.
!>             En particulier, Q contient toutes les données de DOUBLE PRÉCISION dans
!>             LDQ >= N*(11 + 2*SMLSIZ + 8*INT(LOG_2(N/(SMLSIZ+1))))
!>             mots de mémoire, où SMLSIZ est retourné par ILAENV et
!>             est égal à la taille maximale des sous-problèmes au
!>             bas de l'arbre de calcul (généralement environ 25).
!>          Pour d'autres valeurs de COMPQ, Q n'est pas référencé.
!>

IQ

!>          IQ est un tableau d'entiers, dimension (LDIQ)
!>          Si  COMPQ = 'P', alors :
!>             À la sortie, si INFO = 0, Q et IQ contiennent les vecteurs singuliers
!>             gauches et droits sous forme compacte,
!>             nécessitant O(N log N) d'espace au lieu de 2*N**2.
!>             En particulier, IQ contient toutes les données d'entiers dans
!>             LDIQ >= N*(3 + 3*INT(LOG_2(N/(SMLSIZ+1))))
!>             mots de mémoire, où SMLSIZ est retourné par ILAENV et
!>             est égal à la taille maximale des sous-problèmes au
!>             bas de l'arbre de calcul (généralement environ 25).
!>          Pour d'autres valeurs de COMPQ, IQ n'est pas référencé.
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, dimension (MAX(1,LWORK))
!>          Si COMPQ = 'N' alors LWORK >= (4 * N).
!>          Si COMPQ = 'P' alors LWORK >= (6 * N).
!>          Si COMPQ = 'I' alors LWORK >= (3 * N**2 + 4 * N).
!>

IWORK

!>          IWORK est un tableau d'entiers, dimension (8*N)
!>

INFO

!>          INFO est un entier
!>          = 0 : succès de l'exécution.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : l'algorithme n'a pas réussi à calculer une valeur singulière.
!>                La mise à jour du processus diviser pour régner a échoué.
!>
