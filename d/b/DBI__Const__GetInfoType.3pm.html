NOM

DBI::Const::GetInfoType - Données décrivant les codes de type GetInfo

SYNOPIS

use DBI::Const::GetInfoType;

DESCRIPTION

Importe une table de hachage %GetInfoType qui mappe les noms des codes de type GetInfo à leurs valeurs numériques correspondantes. Par exemple :

$database_version = $dbh->get_info( $GetInfoType{SQL_DBMS_VER} );

L'interface de ce module est nouvelle et rien au-delà de ce qui est écrit ici n'est garanti.
