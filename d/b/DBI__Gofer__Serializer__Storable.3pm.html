NOM

DBI::Gofer::Serializer::Storable - Sérialisation Gofer utilisant Storable

SYNTAXE

$serializer = DBI::Gofer::Serializer::Storable->new();
$string = $serializer->serialize( $data );
($string, $deserializer_class) = $serializer->serialize( $data );
$data = $serializer->deserialize( $string );

DESCRIPTION

Utilise Storable::nfreeze() pour sérialiser et Storable::thaw() pour désérialiser.

La méthode serialize() définit localement $Storable::forgive_me = 1; afin de ne pas échouer si elle rencontre des types de données qui ne peuvent pas être sérialisés, tels que des références de code.

Voir aussi DBI::Gofer::Serializer::Base.
