DBSCAN(1) Manuel des commandes générales DBSCAN(1)

NOM

dbscan - analyse un fichier d'index de base de données du serveur d'annuaire et en extrait le contenu

SYNOPSIS

dbscan -f <nom_de_fichier> [-R] [-t <taille>] [-K <id_entrée>] [-k <clé>] [-l <taille>] [-G <n>] [-n] [-r] [-s]

DESCRIPTION

Analyse un fichier d'index de base de données du serveur d'annuaire et en extrait le contenu.

OPTIONS

Un résumé des options est inclus ci-dessous :

options communes :
-A, --ascii
extraire en données ascii
-D, --db-type <nom_de_fichier>
spécifier le type de base de données : bdb ou mdb
-f, --dbi <nom_de_fichier>
spécifier l'instance de base de données
-R, --raw
extraire en données brutes
-t, --truncate-entry <taille>
taille de troncature des entrées (octets)
options de fichier d'entrée :
-K, --entry-id <id_entrée>
ne rechercher qu'un ID d'entrée spécifique
options de fichier d'index :
-G, --id-list-min-size <n>
n'afficher que les entrées d'index comportant plus de <n> identifiants
-I, --import <fichier>
Importer une instance de base de données à partir d'un fichier. Nécessite le paramètre --do-it. ATTENTION ! Seules les instances de base de données id2entry et replication_changelog peuvent être importées par dbscan.
-k, --key <clé>
ne rechercher qu'une clé spécifique
-l, --id-list-max-size <taille>
taille maximale de la liste d'identifiants extraite (par défaut 4096 ; 40 octets <= taille <= 1048576 octets)
-n, --show-id-list-lenghts
afficher les longueurs des listes d'identifiants
--remove
supprimer une instance de base de données. Nécessite le paramètre --do-it
-r, --show-id-list
afficher le contenu de la liste d'identifiants
-S, --stats
afficher les statistiques
-X, --export <fichier>
Exporter l'instance de base de données vers un fichier
autres options :
-s, --summary
Résumé des décomptes d'index
-L, --list
Lister les instances de base de données
--do-it
confirmation requise pour les actions qui modifient le contenu de la base de données
-h, --help-it
afficher l'aide

USAGE

Exemples d'utilisation :

Lister les instances de base de données
dbscan -L /var/lib/dirsrv/slapd-supplier1/db
Extraire le fichier d'entrée :
dbscan -f id2entry.db4
Afficher les clés d'index dans cn.db4 :
dbscan -f cn.db4
Afficher les clés d'index dans cn sur lmdb :
dbscan -f /var/lib/dirsrv/slapd-supplier1/db/userroot/cn.db
(Note : utiliser dbscan -L db_home_dir pour obtenir le chemin de l'instance de base de données)
Afficher les clés d'index et le nombre d'entrées ayant la clé dans mail.db4 :
dbscan -r -f mail.db4
Afficher les clés d'index et les identifiants ayant plus de 20 identifiants dans sn.db4 :
dbscan -r -G 20 -f sn.db4
Afficher le résumé de objectclass.db4 :
dbscan -s -f objectclass.db4
