!>
!> Programme de test pour les Blas de niveau 3 en DOUBLE PRECISION.
!>
!> Le programme doit être piloté par un court fichier de données. Les 14
!> premiers enregistrements du fichier sont lus à l'aide d'une entrée
!> dirigée par liste, les 7 derniers enregistrements sont lus avec le
!> format ( A6, L2 ). Un exemple annoté d'un fichier de données peut
!> être obtenu en supprimant les 3 premiers caractères des 21 lignes
!> suivantes :
!> 'dblat3.out'      NOM DU FICHIER DE SORTIE RÉCAPITULATIF
!> 6                 NUMÉRO D'UNITÉ DU FICHIER RÉCAPITULATIF
!> 'DBLAT3.SNAP'     NOM DU FICHIER DE SORTIE D'INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER D'INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        DRAPEAU LOGIQUE, T POUR REMBOBINER LE FICHIER D'INSTANTANÉ APRÈS CHAQUE ENREGISTREMENT.
!> F        DRAPEAU LOGIQUE, T POUR S'ARRÊTER EN CAS D'ÉCHEC.
!> T        DRAPEAU LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR DE SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 3                 NOMBRE DE VALEURS D'ALPHA
!> 0.0 1.0 0.7       VALEURS D'ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> 0.0 1.0 1.3       VALEURS DE BETA
!> DGEMM   T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> DSYMM   T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> DTRMM   T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> DTRSM   T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> DSYRK   T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> DSYR2K  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> DGEMMTR T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!>
!> Détails supplémentaires
!> =======================
!>
!> Voir :
!>
!>    Dongarra J. J., Du Croz J. J., Duff I. S. et Hammarling S.
!>    A Set of Level 3 Basic Linear Algebra Subprograms.
!>
!>    Technical Memorandum No.88 (Revision 1), Mathematics and
!>    Computer Science Division, Argonne National Laboratory, 9700
!>    South Cass Avenue, Argonne, Illinois 60439, US.
!>
!> -- Écrit le 8 février 1989.
!>    Jack Dongarra, Argonne National Laboratory.
!>    Iain Duff, AERE Harwell.
!>    Jeremy Du Croz, Numerical Algorithms Group Ltd.
!>    Sven Hammarling, Numerical Algorithms Group Ltd.
!>
!>    10-9-00 :  Changer STATUS='NEW' en 'UNKNOWN' afin que les tests
!>              puissent être exécutés plusieurs fois sans supprimer les
!>              fichiers de sortie générés (susan)
!
>
