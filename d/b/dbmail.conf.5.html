NOM

dbmail.conf - fichier de configuration pour l'agent de livraison de messages DBMail.

SYNOPIS

Il y a 8 sections : DBMAIL, SMTP, LMTP, POP, IMAP, SIEVE, LDAP, DELIVERY. Le fichier de configuration par défaut contient la documentation pour tous les paramètres.

 #
 # Le format est le suivant

 #
 # Vous voudrez probablement l'un des suivants :

 #

 # Journalisation
 #
 # Les éléments suivants peuvent être remplacés dans les sections spécifiques aux services.

 # Si vous avez besoin d'un niveau de journalisation spécifique, des valeurs numériques sont disponibles :
 # La journalisation est divisée en 8 niveaux et chaque niveau peut être
 # activé ou désactivé individuellement.
 # Le fichier Stderr/journal enregistre toutes les entrées sur stderr ou dans le fichier journal.
 # La journalisation Syslog utilise la facilité mail et le niveau de journalisation de l'événement pour
 # la journalisation.
 # Syslog peut alors être configuré pour journaliser les données selon les niveaux.
 #
 # Définissez le niveau de journalisation sur la somme des valeurs à côté des niveaux que vous souhaitez enregistrer.
 #   1 = Urgence
 #   2 = Alerte
 #   4 = Critique
 #   8 = Erreur
 #  16 = Avertissement
 #  32 = Avis
 #  64 = Info
 # 128 = Débogage
 # 256 = Base de données -> Journalise au niveau de débogage
 #
 # Exemples :   0 = Rien
 #            31 = Urgence + Alerte + Critique + Erreur + Avertissement
 #           511 = Tout
 #
 #
 # Génère une entrée de journal pour les requêtes de base de données pour le niveau de journalisation, par nombre de
 # secondes d'exécution de la requête.

 query_time_notice     = 20
