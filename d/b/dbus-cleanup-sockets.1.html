NOM

dbus-cleanup-sockets - nettoie les sockets laissés dans un répertoire

SYNTAXE

dbus-cleanup-sockets [RÉPERTOIRE]

DESCRIPTION

La commande dbus-cleanup-sockets nettoie les sockets D-Bus inutilisés. Voir https://www.freedesktop.org/wiki/Software/dbus/ pour plus d'informations sur la situation générale.

Si aucun argument n'est fourni, dbus-cleanup-sockets nettoie les sockets dans le répertoire de sockets par défaut pour le bus de messages de la session utilisateur ; il s'agit généralement de /tmp. Vous pouvez facultativement passer un répertoire différent en ligne de commande.

Sous Linux, ce programme est essentiellement inutile, car D-Bus utilise par défaut des « sockets abstraits » qui existent uniquement en mémoire et n'ont pas de fichier correspondant dans /tmp.

Sur la plupart des autres saveurs d'UNIX, il est possible que les fichiers sockets soient laissés après la sortie anormale de programmes utilisant D-Bus ou sans fermeture de leurs connexions D-Bus. Ainsi, il pourrait être intéressant d'exécuter dbus-cleanup-sockets dans une tâche cron pour nettoyer les sockets abandonnés. Ou vous pouvez simplement ignorer les sockets abandonnés, ils ne font pas de mal, à part encombrer la sortie de « ls /tmp ».

AUTEUR

dbus-cleanup-sockets a été adapté par Havoc Pennington à partir de linc-cleanup-sockets écrit par Michael Meeks.

BOGUES

Veuillez envoyer les rapports de bogues à la liste de diffusion D-Bus ou au traqueur de bogues, voir https://www.freedesktop.org/wiki/Software/dbus/
