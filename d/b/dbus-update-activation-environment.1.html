NOM

dbus-update-activation-environment - met à jour l'environnement utilisé pour les services d'activation D-Bus

SYNTAXE

dbus-update-activation-environment [--systemd] [--verbose] --all | VAR... | VAR=VAL...

DESCRIPTION

dbus-update-activation-environment met à jour la liste des variables d'environnement utilisées par dbus-daemon --session lors de l'activation des services de session sans utiliser systemd.

Avec l'option --systemd, si une instance de systemd --user est disponible sur D-Bus, elle met également à jour la liste des variables d'environnement utilisées par systemd --user lors de l'activation des services utilisateur, y compris les services de session D-Bus pour lesquels dbus-daemon a été configuré pour déléguer l'activation à systemd. Ceci est très similaire à la commande import-environment fournie par systemctl(1)).

Les variables qui sont spéciales pour dbus-daemon ou systemd peuvent être définies, mais leurs valeurs seront remplacées lors du démarrage d'un service. Par exemple, il n'est pas utile d'ajouter DBUS_SESSION_BUS_ADDRESS à l'environnement d'activation de dbus-daemon, bien qu'il puisse toujours être utile de l'ajouter à l'environnement d'activation de systemd.

OPTIONS

--all

Définit toutes les variables d'environnement présentes dans l'environnement utilisé par dbus-update-activation-environment.

--systemd

Définit les variables d'environnement pour les services utilisateur systemd ainsi que pour les services de session D-Bus traditionnels.

--verbose

Affiche des messages sur la sortie d'erreur standard expliquant ce que dbus-update-activation-environment fait.

VAR

Si VAR est présent dans l'environnement de dbus-update-activation-environment, il est défini avec la même valeur pour les services D-Bus. Sa valeur doit être en UTF-8 (sinon, elle est ignorée avec un avertissement). Si VAR n'est pas présent dans l'environnement, cet argument est silencieusement ignoré.

VAR=VAL

Définit VAR à VAL, qui doit être en UTF-8.

EXEMPLES

dbus-update-activation-environment est principalement conçu pour être utilisé dans les scripts de démarrage de session X11 des distributions Linux, en conjonction avec la conception du « bus utilisateur ».

Pour propager DISPLAY et XAUTHORITY à dbus-daemon et, s'il est présent, à systemd, et propager DBUS_SESSION_BUS_ADDRESS à systemd :

        dbus-update-activation-environment --systemd \
            DBUS_SESSION_BUS_ADDRESS DISPLAY XAUTHORITY

Pour propager toutes les variables d'environnement sauf XDG_SEAT, XDG_SESSION_ID et XDG_VTNR à dbus-daemon (et, s'il est présent, à systemd) pour la compatibilité avec les anciens scripts de démarrage de session X11 :

        # dans un sous-shell pour que les variables restent définies dans le
        # script parent
        (
          unset XDG_SEAT
          unset XDG_SESSION_ID
          unset XDG_VTNR
          dbus-update-activation-environment --systemd --all
        )

STATUT DE SORTIE

dbus-update-activation-environment se termine avec le statut 0 en cas de succès, EX_USAGE (64) en cas d'options de ligne de commande invalides, EX_OSERR (71) s'il est impossible de se connecter au bus de session, ou EX_UNAVAILABLE (69) s'il est impossible de définir les variables d'environnement. D'autres codes de sortie non nuls pourraient être ajoutés dans les futures versions.

ENVIRONNEMENT

DBUS_SESSION_BUS_ADDRESS, XDG_RUNTIME_DIR et/ou DISPLAY sont utilisés pour trouver l'adresse du bus de session.

LIMITATIONS

dbus-daemon ne fournit pas de moyen de supprimer les variables d'environnement après qu'elles aient été définies (bien que systemd le fasse), donc dbus-update-activation-environment n'offre pas non plus cette fonctionnalité.

POSIX ne spécifie pas l'encodage des noms ou valeurs de variables d'environnement non-ASCII et autorise leur contenu à être n'importe quel octet non nul, mais ni dbus-daemon ni systemd ne prennent en charge les variables d'environnement avec des noms ou des valeurs non-UTF-8. Par conséquent, dbus-update-activation-environment suppose que tout nom ou valeur qui semble être du UTF-8 est destiné à être du UTF-8, et ignore les autres noms ou valeurs avec un avertissement.

BOGUES

Veuillez envoyer les rapports de bogues au traqueur de bogues D-Bus ou à la liste de diffusion. Voir https://www.freedesktop.org/wiki/Software/dbus/.
