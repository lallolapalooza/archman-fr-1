NOM

dblatex - convertir DocBook en LaTeX, DVI, PostScript, et PDF

SYNTAXE

dblatex [options] {fichier | -}

DESCRIPTION

Cette page de manuel documente brièvement la commande dblatex. Pour plus de détails, lisez le manuel PDF ; voir ci-dessous.

dblatex est un programme qui transforme vos documents SGML/XML DocBook en DVI, PostScript ou PDF en les traduisant d'abord en pur LaTeX. Les balisages MathML 2.0 sont également pris en charge. Il a été initialement conçu comme un clone de DB2LaTeX.

OPTIONS

Un résumé des options est inclus ci-dessous. Pour une description complète, consultez le manuel PDF.

-h, --help

Affiche un message d'aide et quitte.

-b backend, --backend=backend

Pilote backend à utiliser : pdftex (par défaut), dvips, ou xetex.

-B, --no-batch

Toute la sortie tex est imprimée.

-c config, -S config, --config=config

Fichier de configuration. Un fichier de configuration peut être utilisé pour regrouper toutes les options et personnalisations à appliquer.

-d, --debug

Mode de débogage : Conserve le répertoire temporaire dans lequel dblatex travaille réellement.

-D, --dump

Affiche la pile d'erreurs lors d'une erreur (à des fins de débogage).

-e indexstyle, --indexstyle indexstyle

Fichier de style d'index à passer à makeindex au lieu du style d'index par défaut de dblatex.

-f figure_format, --fig-format=figure_format

Format des figures d'entrée : fig, eps. Utilisé lorsque le format n'est pas déduit de l'extension du fichier de figure.

-F input_format, --input-format=input_format

Format du fichier d'entrée : sgml, xml (par défaut).

-i texinputs, --texinputs texinputs

Chemin ajouté à TEXINPUTS

-I figure_path, --fig-path=figure_path

Chemin de recherche supplémentaire pour les figures.

-l bst_path, --bst-path=bst_path

Chemin de recherche supplémentaire pour les styles BibTeX.

-L bib_path, --bib-path=bib_path

Chemin de recherche supplémentaire pour les bases de données BibTeX.

-m xslt, --xslt=xslt

Moteur XSLT à utiliser. Les moteurs disponibles sont : xsltproc (par défaut), 4xslt, saxon.

-o output, --output=output

Nom du fichier de sortie. S'il n'est pas spécifié, le nom du fichier d'entrée est utilisé, avec le suffixe du format de sortie. L'option est ignorée si plusieurs livres sont découpés à partir d'un ensemble. Dans ce cas, l'option -O est appliquée à la place.

-O output_dir, --output-dir=output_dir

Répertoire de sortie des livres construits à partir d'un ensemble. S'il n'est pas spécifié, le répertoire de travail actuel est utilisé à la place. L'option est ignorée si un seul document est généré, et l'option -o est prise en compte.

-p xsl_user, --xsl-user=xsl_user

Une feuille de style XSL utilisateur à utiliser. Plusieurs feuilles de style utilisateur peuvent être spécifiées, mais l'ordre des options est significatif : une feuille de style utilisateur a priorité sur les feuilles de style utilisateur définies précédemment.

-P param=value, --param=param=value

Définit un paramètre XSL depuis la ligne de commande.

-q, --quiet

Moins verbeux, affiche uniquement les messages de sortie TeX et les messages d'erreur.

-r [plugin:]script, --texpost=[plugin:]script

Script appelé à la toute fin de la compilation tex. Son rôle est de modifier le fichier tex ou l'un des fichiers de compilation avant le dernier passage. Le script peut être un plugin python. Dans ce cas, ajoutez le préfixe 'plugin:'.

-s latex_style, --texstyle=latex_style

Style LaTeX à appliquer. Il peut s'agir d'un nom de paquet, ou directement d'un chemin de paquet LaTeX. Un nom de paquet doit être sans chemin de répertoire et sans l'extension '.sty'. Au contraire, un chemin de paquet LaTeX complet peut contenir un chemin de répertoire, mais doit se terminer par l'extension '.sty'.

-t format, --type=format

Format de sortie. Formats disponibles : tex, dvi, ps, pdf (par défaut).

--dvi

Sortie DVI. Équivalent à -tdvi.

--pdf

Sortie PDF. Équivalent à -tpdf.

--ps

Sortie PostScript. Équivalent à -tps.

-T style, --style=style

Style de sortie, les styles prédéfinis sont : db2latex, simple, native (par défaut).

-v, --version

Affiche la version de dblatex.

-V, --verbose

Mode verbeux, affiche les commandes en cours d'exécution.

-x xslt_options, --xslt-opts=xslt_options

Arguments passés directement au moteur XSLT.

-X, --no-external

Désactive le support des fichiers texte externes. Ce support est nécessaire pour les appels de fonction sur des fichiers externes référencés par textdata ou imagedata, mais il peut être désactivé si le document ne contient pas de tels appels. La désactivation de ce support peut améliorer les performances de traitement pour les grands documents.

FICHIERS ET RÉPERTOIRES

$HOME/.dblatex/

Répertoire de configuration utilisateur.

/etc/dblatex/

Répertoire de configuration système.

Les styles de sortie prédéfinis se trouvent dans le répertoire de documentation du paquet installé.

VARIABLES D'ENVIRONNEMENT

DBLATEX_CONFIG_FILES

Répertoires de configuration supplémentaires pouvant contenir des fichiers de configuration dblatex.

EXEMPLES

Pour produire myfile.pdf à partir de myfile.xml :

dblatex myfile.xml

Pour définir certains paramètres XSL depuis la ligne de commande :

dblatex -P latex.babel.language=de myfile.xml

Pour utiliser votre feuille de style XSL :

dblatex -p myconfig.xsl myfile.xml

Pour utiliser le style de sortie db2latex :

dblatex -T db2latex myfile.xml

Pour appliquer votre propre style LaTeX :

dblatex -s mystyle myfile.xml
dblatex -s /chemin/vers/mystyle.sty myfile.xml

Pour passer des arguments supplémentaires au moteur XSLT :

dblatex -x "--path /chemin/pour/charger/entite" myfile.xml

Pour utiliser dblatex et le profilage :

xsltproc --param profile.attribute "'output'" \
         --param profile.value "'pdf'" \
         /chemin/vers/profilage/profile.xsl \
         myfile.xml | dblatex -o myfile.pdf -

Pour construire un ensemble de livres :

dblatex -O /chemin/vers/repertoire/decoupage -Pset.book.num=all myfile.xml
