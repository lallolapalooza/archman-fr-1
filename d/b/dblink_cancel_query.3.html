NOM

dblink_cancel_query - annule toute requête active sur la connexion nommée

SYNTAXE

dblink_cancel_query(text connname) returns text

DESCRIPTION

dblink_cancel_query tente d'annuler toute requête en cours sur la connexion nommée. Notez que cela n'est pas garanti de réussir (par exemple, la requête distante pourrait déjà être terminée). Une demande d'annulation améliore simplement les chances que la requête échoue bientôt. Vous devez toujours terminer le protocole de requête normal, par exemple en appelant dblink_get_result.

ARGUMENTS

connname

Nom de la connexion à utiliser.

VALEUR DE RETOUR

Retourne OK si la demande d'annulation a été envoyée, ou le texte d'un message d'erreur en cas d'échec.

EXEMPLES

SELECT dblink_cancel_query('dtest1');
