dbmail-export - exporter

une boîte aux lettres d
e DBMail au format mbox.

SYNOPSI

S 
dbmail-export [options] --user nom_utilisateur --mail
box boîte --out fichier dbmail-export [options] --user
nom_utilisateur --mailbox boîte --basedir répertoire

DESCRIPTIO

N

Le programme dbmail-export vous permet d'e

xporter une boîte aux lettres DBMail vers
une boîte aux lettres au format mbox.

OPTION

S

-u, --user

utilisateur
spécifier le propriétaire de la boîte aux lettres que vous souhaitez exporter, en utilisant les caractères génériques ? et * pour correspondre respectivement à un caractère ou aucun, ou un ou plusieurs caractères dans le nom
d'utilisateur.

-m, --mailbox

boîte
spécifier la boîte aux lettres que vous souhaitez
exporter.

-o, --out

fichier_sortie
spécifier le fichier dans lequel le courrier exporté sera
enregistré.

-b, --basedir

rép_base
spécifier le répertoire de base dans lequel les boîtes aux lettres exportées seront
enregistrées.

-s, --search

recherche
utiliser une chaîne de recherche IMAP SEARCH pour sélectionner les messages (par défaut : 1:*) par exemple, pour exporter tous les messages reçus en mai, utilisez : "1:* SINCE 1-May-2007 BEFORE
1-Jun-2007"

-d,

--set-del-flag
marquer les messages exportés comme \\Deleted (utiliser dbmail-util pour définir le statut sur supprimé)
.

-D, --set-del-statu

s
définir le statut des messages exportés comme supprimé (utiliser dbmail-util pour purger)
.

-r,

--recursive
exporter les boîtes aux lettres récurs
ivement (par défaut : vrai, sauf si l
'option -m est également spécifiée).

OPTIONS

COMMUNES

-f, --config

fichier_config
Spécifier un fichier de configuration alternatif.

Utiliser dbmail-<utilitair

e> --help pour afficher l
'emplacement par défaut.

-q,

--quiet
Ignorer silencieusement les invites interactives et les messages d'état utiles qui seraient autrement imprimés sur stdout. Utiliser deux -q pour silencier les erreurs qui seraient autrement imprimées sur
stderr.

-v,

--verbose
Opérer de manière verbeuse. Certains des utilitaires de la suite DBMail peuvent accepter deux -v pour une verbosité supplémentaire. Ceux qui ne comprennent pas cette convention ne se plaindront pas d'avoir le -v supplémentaire et opéreront simplement à leur verbosité
normale.

-V,

--version
Afficher la version et le copyright, puis
quitter.

-h,

--help
Afficher un bref
résumé des optio
ns, puis quitter.

EXEMPLE

S

Pour exporter et supprimer tous les messages appartenant à l'utilisateur Joe dans la boîte aux lettres Inbox de plus de 30 jours, essayez cette commande sous Linux

: 
dbmail-export --user joe \
    --mailbox inbox \
--out joesinbox.mbox \ --set-del-flag \ --se
arch "1:* BEFORE `date '+%e-%b-%Y' -d '30 days ago'`"

Une version BSD

: 
dbmail-export --user joe \
    --mailbox inbox \
--out joesinbox.mbox \ --set-del-flag \
--search "1:* BEFORE `date -v-30d '+%e-%b-%Y'`"

Notez le soin apporté aux guillemets bash et aux accents graves appelant la commande date(1). date(1) possède d'excellentes fonctionnalités pour récupérer des dates relatives. Si vous utilisez un autre shell, vous devrez peut-être utiliser des guillemets

différents.

Pour exporter toutes les boîtes aux lettres nommées Spam pour tous les utilisateurs vers des répertoires individuels suivant le motif SpamDump/<nom_utilisateur>/Spam, essayez cette commande

: 
dbmail-export --use
r \* --mailbox Spam
--basedir SpamDump

Notez la barre oblique inverse pour empêcher le shell d'étendre

le *, car nous voulons que ce * soit transmis à DBMail pour
extension en fonction de la liste interne des utilisateurs.
