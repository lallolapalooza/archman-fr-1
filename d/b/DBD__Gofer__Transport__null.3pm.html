NOM

DBD::Gofer::Transport::null - Transport client DBD::Gofer pour les tests

SYNOPSIS

my $original_dsn = "..."
DBI->connect("dbi:Gofer:transport=null;dsn=$original_dsn",...)

ou, activer en définissant la variable d'environnement DBI_AUTOPROXY :

export DBI_AUTOPROXY="dbi:Gofer:transport=null"

DESCRIPTION

Se connecter via DBD::Gofer mais exécuter les requêtes dans le même processus.

C'est un moyen rapide et simple de tester la compatibilité des applications avec les (quelques) restrictions imposées par DBD::Gofer.

Il fournit également un moyen simple et portable pour la suite de tests DBI d'être utilisée pour tester DBD::Gofer sur toutes les plateformes sans aucune configuration.

De plus, en mesurant la différence de performance entre les connexions normales et les connexions via "dbi:Gofer:transport=null", le coût de base de l'utilisation de DBD::Gofer peut être mesuré. De plus, le coût supplémentaire des transports plus avancés peut être isolé en comparant leurs performances avec le transport nul.

Le script "t/85gofer.t" de la distribution DBI inclut un benchmark comparatif.
