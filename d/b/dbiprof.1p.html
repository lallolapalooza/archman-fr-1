NOM

dbiprof - client en ligne de commande pour DBI::ProfileData

SYNTAXE

Voir un rapport des dix requêtes ayant le temps d'exécution total le plus long dans le fichier de profil prof1.out :

dbiprof prof1.out

Voir les 10 requêtes exécutées le plus fréquemment dans le fichier de profil dbi.prof (par défaut) :

dbiprof --sort count

Voir le même rapport avec 15 entrées :

dbiprof --sort count --number 15

DESCRIPTION

Cet outil est un client en ligne de commande pour DBI::ProfileData. Il vous permet d'analyser le fichier de données de profil produit par DBI::ProfileDumper et de générer divers rapports utiles.

OPTIONS

Ce programme accepte les options suivantes :

--number N
Produire N éléments dans le rapport. Par défaut, 10. Si défini sur "all", tous les résultats sont affichés.
--sort champ
Trier les résultats par le champ donné. Le tri par plusieurs champs n'est pas actuellement pris en charge (patchs bienvenus). Les champs de tri disponibles sont :
total
Trie par le temps total d'exécution sur toutes les exécutions. C'est le tri par défaut.
longest
Trie par la durée la plus longue d'une seule exécution.
count
Trie par le nombre total d'exécutions.
first
Trie par le temps pris lors de la première exécution.
shortest
Trie par la durée la plus courte d'une seule exécution.
key1
Trie par la valeur du premier élément du chemin (Path), qui doit être numérique. Vous pouvez également trier par "key2" et "key3".
--reverse
Inverse le tri sélectionné. Par exemple, pour voir un rapport du temps total le plus court : 
dbiprof --sort total --reverse
--match cleN=valeur
Ne considérer que les éléments où la clé spécifiée correspond à la valeur donnée. Les clés sont numérotées à partir de 1. Par exemple, supposons que vous ayez utilisé un chemin DBI::Profile comme suit : 
[ DBIprofile_Statement, DBIprofile_Methodname ]

Et que vous appeliez dbiprof comme ceci :

dbiprof --match key2=execute

Votre rapport n'affichera que les requêtes d'exécution, en excluant les préparations, les récupérations, etc.

Si la valeur donnée commence et se termine par des barres obliques ("/"), elle sera traitée comme une expression régulière. Par exemple, pour inclure uniquement les requêtes SELECT où key1 est l'instruction :

dbiprof --match key1=/^SELECT/

Par défaut, l'expression de correspondance est sensible à la casse, mais cela peut être modifié avec l'option --case-sensitive.

--exclude cleN=valeur
Exclure les éléments pour lesquels la clé spécifiée correspond à la valeur donnée. Par exemple, pour exclure toutes les entrées de préparation où key2 est le nom de la méthode : 
dbiprof --exclude key2=prepare

Comme avec "--match", si la valeur donnée commence et se termine par des barres obliques ("/"), elle sera traitée comme une expression régulière. Par exemple, pour exclure les requêtes UPDATE où key1 est l'instruction :

dbiprof --match key1=/^UPDATE/

Par défaut, l'expression d'exclusion est insensible à la casse, mais cela peut être modifié avec l'option --case-sensitive.

--case-sensitive
L'utilisation de cette option fait que --match et --exclude fonctionnent en respectant la casse. Désactivé par défaut.
--delete
Définit l'option "DeleteFiles" de DBI::ProfileData, ce qui entraîne la suppression des fichiers après lecture. Voir DBI::ProfileData pour plus de détails.
--dumpnodes
Imprimer la liste des nœuds sous la forme d'une structure de données Perl. Utilisez l'option "-sort" si vous voulez que la liste soit triée.
--version
Afficher le numéro de version de dbiprof et quitter.
