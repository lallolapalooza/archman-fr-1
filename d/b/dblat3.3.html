programme dblat3

DBLAT3

Objectif:

!>
!> Programme de test pour les BLAS de Niveau 3 en DOUBLE PRÉCISION.
!>
!> Le programme doit être piloté par un fichier de données court. Les 14 premières
!> lignes du fichier sont lues en utilisant une entrée dirigée par liste, les 7 dernières
!> lignes sont lues en utilisant le format ( A6, L2 ). Un exemple annoté d'un fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> 21 lignes suivantes:
!> 'dblat3.out'      NOM DU FICHIER DE SORTIE RÉCAPITULATIF
!> 6                 NUMÉRO D'UNITÉ DU FICHIER RÉCAPITULATIF
!> 'DBLAT3.SNAP'     NOM DU FICHIER DE SORTIE INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        FLAG LOGIQUE, T POUR REMbobiner LE FICHIER INSTANTANÉ APRÈS CHAQUE ENREGISTREMENT.
!> F        FLAG LOGIQUE, T POUR ARRÊTER EN CAS D'ÉCHEC.
!> T        FLAG LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 3                 NOMBRE DE VALEURS DE ALPHA
!> 0.0 1.0 0.7       VALEURS DE ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> 0.0 1.0 1.3       VALEURS DE BETA
!> DGEMM   T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DSYMM   T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DTRMM   T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DTRSM   T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DSYRK   T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DSYR2K  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DGEMMTR T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!>
!> Détails Supplémentaires
!> =====================
!>
!> Voir :
!>
!>    Dongarra J. J., Du Croz J. J., Duff I. S. and Hammarling S.
!>    A Set of Level 3 Basic Linear Algebra Subprograms.
!>
!>    Technical Memorandum No.88 (Revision 1), Mathematics and
!>    Computer Science Division, Argonne National Laboratory, 9700
!>    South Cass Avenue, Argonne, Illinois 60439, US.
!>
!> -- Écrit le 8 février 1989.
!>    Jack Dongarra, Laboratoire National d'Argonne.
!>    Iain Duff, AERE Harwell.
!>    Jeremy Du Croz, Numerical Algorithms Group Ltd.
!>    Sven Hammarling, Numerical Algorithms Group Ltd.
!>
!>    10-9-00: Changer STATUS='NEW' en 'UNKNOWN' afin que les testeurs
!>              puissent être exécutés plusieurs fois sans supprimer les fichiers de sortie générés (susan)
!>
