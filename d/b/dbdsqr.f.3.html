sous-routine dbdsqr (character uplo, integer n, integer ncvt, integer nru, integer ncc, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldvt, * ) vt, integer ldvt, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) work, integer info)

DBDSQR

But :

!>
!> DBDSQR calcule les valeurs singulières et, en option, les vecteurs singuliers
!> droits et/ou gauches à partir de la décomposition en valeurs singulières (SVD)
!> d'une matrice réelle bidiagonale N par N (supérieure ou inférieure) B en utilisant
!> l'algorithme QR implicite à décalage nul. La SVD de B a la forme
!>
!>    B = Q * S * P**T
!>
!> où S est la matrice diagonale des valeurs singulières, Q est une matrice
!> orthogonale des vecteurs singuliers gauches, et P est une matrice orthogonale
!> des vecteurs singuliers droits. Si des vecteurs singuliers gauches sont demandés,
!> cette sous-routine renvoie en fait U*Q au lieu de Q, et, si des vecteurs
!> singuliers droits sont demandés, cette sous-routine renvoie P**T*VT au lieu de
!> P**T, pour des matrices d'entrée réelles U et VT données. Lorsque U et VT sont
!> les matrices orthogonales qui réduisent une matrice générale A à une forme
!> bidiagonale : A = U*B*VT, telles que calculées par DGEBRD, alors
!>
!>    A = (U*Q) * S * (P**T*VT)
!>
!> est la SVD de A. En option, la sous-routine peut également calculer Q**T*C
!> pour une matrice d'entrée réelle C donnée.
!>
!> Voir  par J. Demmel et W. Kahan,
!> LAPACK Working Note #3 (ou SIAM J. Sci. Statist. Comput. vol. 11,
!> no 5, pp. 873-912, Sept 1990) et
!>  par
!> B. Parlett et V. Fernando, Technical Report CPAM-554, Mathematics
!> Department, University of California at Berkeley, juillet 1992
!> pour une description détaillée de l'algorithme.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : B est bidiagonale supérieure ;
!>          = 'L' : B est bidiagonale inférieure.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B. N >= 0.
!>

NCVT

!>          NCVT est INTEGER
!>          Le nombre de colonnes de la matrice VT. NCVT >= 0.
!>

NRU

!>          NRU est INTEGER
!>          Le nombre de lignes de la matrice U. NRU >= 0.
!>

NCC

!>          NCC est INTEGER
!>          Le nombre de colonnes de la matrice C. NCC >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice bidiagonale B.
!>          À la sortie, si INFO=0, les valeurs singulières de B en ordre
!>          décroissant.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (N-1)
!>          À l'entrée, les N-1 éléments hors diagonaux de la matrice
!>          bidiagonale B.
!>          À la sortie, si INFO = 0, E est détruit ; si INFO > 0, D et E
!>          contiendront les éléments diagonaux et superdiagonaux d'une
!>          matrice bidiagonale orthogonalement équivalente à celle donnée
!>          en entrée.
!>

VT

!>          VT est un tableau DOUBLE PRECISION, dimension (LDVT, NCVT)
!>          À l'entrée, une matrice VT de N par NCVT.
!>          À la sortie, VT est écrasée par P**T * VT.
!>          Non référencée si NCVT = 0.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT.
!>          LDVT >= max(1,N) si NCVT > 0 ; LDVT >= 1 si NCVT = 0.
!>

U

!>          U est un tableau DOUBLE PRECISION, dimension (LDU, N)
!>          À l'entrée, une matrice U de NRU par N.
!>          À la sortie, U est écrasée par U * Q.
!>          Non référencée si NRU = 0.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,NRU).
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (LDC, NCC)
!>          À l'entrée, une matrice C de N par NCC.
!>          À la sortie, C est écrasée par Q**T * C.
!>          Non référencée si NCC = 0.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C.
!>          LDC >= max(1,N) si NCC > 0 ; LDC >=1 si NCC = 0.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK)
!>          LWORK = 4*N, si NCVT = NRU = NCC = 0, et
!>          LWORK = 4*(N-1), sinon
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :
!>             si NCVT = NRU = NCC = 0,
!>                = 1, une scission a été marquée par une valeur positive dans E
!>                = 2, le bloc courant de Z n'a pas été diagonalisé après 30*N
!>                     itérations (dans la boucle while interne)
!>                = 3, le critère d'arrêt de la boucle while externe n'a pas été
!>                     atteint (le programme a créé plus de N blocs non réduits)
!>             sinon NCVT = NRU = NCC = 0,
!>                   l'algorithme n'a pas convergé ; D et E contiennent les
!>                   éléments d'une matrice bidiagonale qui est orthogonalement
!>                   similaire à la matrice d'entrée B ; si INFO = i, i
!>                   éléments de E n'ont pas convergé vers zéro.
!>

Paramètres internes :

!>  TOLMUL  DOUBLE PRECISION, par défaut = max(10,min(100,EPS**(-1/8)))
!>          TOLMUL contrôle le critère de convergence de la boucle QR.
!>          S'il est positif, TOLMUL*EPS est la précision relative
!>             souhaitée dans les valeurs singulières calculées.
!>          S'il est négatif, abs(TOLMUL*EPS*sigma_max) est la
!>             précision absolue souhaitée dans les valeurs singulières
!>             calculées (correspond à la précision relative
!>             abs(TOLMUL*EPS) dans la plus grande valeur singulière.
!>          abs(TOLMUL) devrait être compris entre 1 et 1/EPS, et de préférence
!>             entre 10 (pour une convergence rapide) et .1/EPS
!>             (pour qu'il y ait une certaine précision dans les résultats).
!>          Par défaut, on perd soit un huitième, soit 2 des
!>             chiffres décimaux disponibles dans chaque valeur singulière
!>             calculée (le plus petit des deux).
!>
!>  MAXITR  INTEGER, par défaut = 6
!>          MAXITR contrôle le nombre maximal de passes de
!>          l'algorithme dans sa boucle interne. L'algorithme s'arrête
!>          (et donc échoue à converger) si le nombre de passes
!>          dans la boucle interne dépasse MAXITR*N**2.
!>
!>

Remarque :

!>  Rapport de bogue de Cezary Dendek.
!>  Le 23 mars 2017, la variable INTEGER MAXIT = MAXITR*N**2 a été
!>  supprimée car elle peut facilement déborder (pour N supérieur ou égal
!>  à 18 919). Nous utilisons à la place MAXITDIVN = MAXITR*N.
!>
