NOM

dbmail-lmtpd - Le démon LMTP de DBMail reçoit les messages d'un MTA supportant le protocole Lightweight Mail Transport Protocol, tel que spécifié dans la RFC 2033.

SYNTAXE

dbmail-lmtpd [--config fichier_config] [--pidfile fichier_pid]
dbmail-lmtpd [--config fichier_config] [--pidfile fichier_pid] --no-daemon
dbmail-lmtpd [--config fichier_config] [--pidfile fichier_pid] --inetd

DESCRIPTION

Les agents de transfert de courrier, les MTA comme Postfix et Exim, parlent LMTP à leurs agents de livraison de courrier qui reçoivent et stockent les messages. DBMail implémente un tel système en utilisant un backend de base de données.

OPTIONS

-p, --pidfile fichier_pid

Spécifie un fichier PID alternatif. Par défaut, les démons utilisent dbmail-<daemon>.pid pour leurs fichiers PID, les sauvegardant dans le répertoire spécifié par l'entrée pid_directory dans dbmail.conf ou si elle n'existe pas, la valeur définie par l'option de configuration --localstatedir, et s'arrêteront si le fichier PID ne peut pas être écrit. Utilisez l'option -p fichier_pid pour placer le fichier PID dans l'emplacement préféré de votre système.

-n, --no-daemon

Pas de démonisation : mode inetd. Le programme reste attaché à la console depuis laquelle il a été lancé et lira et écrira sur stdin/stdout. Ceci est utile pour le débogage lorsqu'il est combiné avec l'option -v. Il est également utilisé pour l'exécution à partir de (x)inetd.

-D, --inetd

Pas de démonisation : Le programme reste attaché à la console et écoutera sur les sockets réseau définis dans dbmail.conf. Ceci est principalement utilisé pour xinetd (Extended Internet Service Daemon).

OPTIONS COMMUNES

-f, --config fichier_config

Spécifie un fichier de configuration alternatif.

Utilisez dbmail-<utilitaire> --help pour afficher l'emplacement par défaut.

-q, --quiet

Ignore silencieusement les invites interactives et les messages d'état utiles qui seraient autrement imprimés sur stdout. Utilisez deux -q pour faire taire les erreurs qui seraient autrement imprimées sur stderr.

-v, --verbose

Fonctionne de manière verbeuse. Certains utilitaires de la suite DBMail peuvent accepter deux -v pour une verbosité supplémentaire. Ceux qui ne comprennent pas cette convention ne se plaindront pas d'avoir le -v supplémentaire et fonctionneront simplement à leur verbosité normale.

-V, --version

Affiche la version et le copyright, puis quitte.

-h, --help

Affiche un bref résumé des options, puis quitte.
