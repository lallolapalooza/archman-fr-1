NOM

dblink_fetch - retourne des lignes à partir d'un curseur ouvert dans une base de données distante

SYNTAXE

dblink_fetch(text cursorname, int howmany [, bool fail_on_error]) returns setof record
dblink_fetch(text connname, text cursorname, int howmany [, bool fail_on_error]) returns setof record

DESCRIPTION

dblink_fetch récupère des lignes à partir d'un curseur précédemment établi par dblink_open.

ARGUMENTS

connname

Nom de la connexion à utiliser ; omettez ce paramètre pour utiliser la connexion non nommée.

cursorname

Nom du curseur à partir duquel récupérer.

howmany

Nombre maximum de lignes à récupérer. Les howmany lignes suivantes sont récupérées, en commençant à la position actuelle du curseur, en avançant. Une fois que le curseur a atteint sa fin, plus aucune ligne n'est produite.

fail_on_error

Si vrai (par défaut lorsqu'il est omis), alors une erreur survenant du côté distant de la connexion provoque également une erreur locale. Si faux, l'erreur distante est signalée localement comme un NOTICE, et la fonction ne retourne aucune ligne.

VALEUR DE RETOUR

La fonction retourne la ou les lignes récupérées du curseur. Pour utiliser cette fonction, vous devrez spécifier l'ensemble attendu de colonnes, comme discuté précédemment pour dblink.

NOTES

En cas d'inadéquation entre le nombre de colonnes de retour spécifié dans la clause FROM et le nombre réel de colonnes retournées par le curseur distant, une erreur sera générée. Dans ce cas, le curseur distant est toujours avancé du nombre de lignes qu'il aurait été si l'erreur ne s'était pas produite. Il en va de même pour toute autre erreur survenant dans la requête locale après que le FETCH distant ait été effectué.

EXEMPLES

(1 row)
SELECT dblink_open('foo', 'select proname, prosrc from pg_proc where proname like ''bytea%''');

-------------
 OK
(1 row)
