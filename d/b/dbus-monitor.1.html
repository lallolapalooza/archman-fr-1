DBUS-MONITOR(1) Commandes utilisateur DBUS-MONITOR(1)

NOM

dbus-monitor - Sonde de débogage pour imprimer les messages du bus de messages

SYNTAXE

dbus-monitor [--system | --session | --address ADRESSE] [--profile | --monitor | --pcap | --binary] [expressions_de_surveillance expressions]

DESCRIPTION

La commande dbus-monitor est utilisée pour surveiller les messages transitant par un bus de messages D-Bus. Voir https://www.freedesktop.org/wiki/Software/dbus/ pour plus d'informations sur le contexte général.

Il existe deux bus de messages bien connus : le bus de messages système (installé sur de nombreux systèmes comme le service « messagebus ») et le bus de messages de session de connexion utilisateur (démarré à chaque connexion d'un utilisateur). Les options --system et --session dirigent dbus-monitor pour surveiller respectivement le bus système ou le bus de session. Si aucune n'est spécifiée, dbus-monitor surveille le bus de session.

dbus-monitor dispose de deux modes de sortie texte différents : le mode de surveillance de style 'classique' et le mode profilage. Le format de profilage est un format compact avec une seule ligne par message et des informations de synchronisation à résolution de microsecondes. Les options --profile et --monitor sélectionnent respectivement le format de sortie de profilage et de surveillance.

dbus-monitor dispose également de deux modes de sortie binaire. Le mode binaire, sélectionné par --binary, émet le flux binaire complet des messages (sans la poignée de main d'authentification initiale). Le mode PCAP, sélectionné par --pcap, ajoute un en-tête de fichier PCAP au début de la sortie, et préfixe un en-tête de message PCAP à chaque message ; cela produit un fichier binaire qui peut être lu par, par exemple, Wireshark.

Si aucun mode n'est spécifié, dbus-monitor utilise le format de sortie de surveillance.

Pour que dbus-monitor puisse voir les messages qui vous intéressent, vous devez spécifier un ensemble d'expressions de surveillance comme vous vous attendriez à les passer à la fonction dbus_bus_add_match.

La configuration du bus de messages peut empêcher dbus-monitor de voir tous les messages, en particulier si vous exécutez le moniteur en tant qu'utilisateur non root.

OPTIONS

--system

Surveille le bus de messages système.

--session

Surveille le bus de messages de session. (C'est le mode par défaut.)

--address ADRESSE

Surveille un bus de messages arbitraire donné à ADRESSE.

--profile

Utilise le format de sortie de profilage.

--monitor

Utilise le format de sortie de surveillance. (C'est le mode par défaut.)

EXEMPLE

Voici un exemple d'utilisation de dbus-monitor pour surveiller les messages du moniteur de frappe de gnome

  dbus-monitor "type='signal',sender='org.gnome.TypingMonitor',interface='org.gnome.TypingMonitor'"
