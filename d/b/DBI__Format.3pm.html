NOM

DBI::Format - Un paquet pour afficher des tableaux de résultats

SYNOPSIS

# créer un nouvel objet de résultat
$r = DBI::Format->new('var1' => 'val1', ...);
# Le préparer pour la sortie en créant un en-tête
$r->header($sth, $fh);
# Dans une boucle, afficher les lignes
while ($ref = $sth->fetchrow_arrayref()) {
  $r->row($ref);
}
# Enfin, créer un pied de page
$r->trailer();

DESCRIPTION

CE PAQUET EST ENCORE TRÈS EXPÉRIMENTAL. LES CHOSES VONT CHANGER.

Ce paquet est utilisé pour rendre la sortie de DBI::Shell configurable. L'idée est de dériver une sous-classe pour tout type de tableau de sortie que vous pourriez créer. Exemples :

  • un format de sortie très simple comme celui offert par DBI::neat_list(). Voir "SOUS-CLASSES DISPONIBLES".
  • un format de boîte, comme offert par le module Data::ShowTable.
  • format HTML, comme utilisé dans les binaires CGI
  • postscript, à envoyer via un pipe à lpr ou quelque chose de similaire

À l'avenir, le paquet devrait également prendre en charge les méthodes interactives, par exemple la complétion par tabulation.

Voici les méthodes disponibles :

new(@attr)
new(\%attr)
(Méthode de classe) C'est le constructeur. Il est préférable d'appeler un constructeur de sous-classe. Le constructeur accepte soit une liste de paires clé/valeur, soit une référence de hachage.
header($sth, $fh)
(Méthode d'instance) Ceci est appelé lorsqu'un nouveau tableau de résultats doit être créé pour afficher les résultats du descripteur d'instruction $sth. L'argument (facultatif) $fh est un descripteur IO (ou tout objet prenant en charge une méthode print), généralement vous utilisez un objet IO::Wrap pour STDIN.

La méthode interrogera $sth pour ses attributs NAME, NUM_OF_FIELDS, TYPE, SCALE et PRECISION et affichera généralement un en-tête. En général, vous ne devez pas supposer que $sth est bien un descripteur d'instruction DBI et il vaut mieux le traiter comme une référence de hachage avec les attributs ci-dessus.

row($ref)
(Méthode d'instance) Affiche le contenu de la référence de tableau $ref. Généralement, vous obtenez cette référence de tableau en appelant $sth->fetchrow_arrayref().
trailer
(Méthode d'instance) Une fois que vous avez passé toutes les lignes de résultat au paquet de résultats, vous devez appeler la méthode trailer. Cette méthode peut, par exemple, afficher le nombre de lignes de résultat.

SOUS CLASSES DISPONIBLES

Tout d'abord, vous pouvez utiliser le paquet DBI::Format lui-même : ce n'est pas une classe de base abstraite, mais une valeur par défaut très simple utilisant DBI::neat_list().

Boites en ASCII

Cette sous-classe utilise le mode Box du module Data::ShowTable en interne. Data::ShowTable(3).

Raw

La ligne est écrite sans formatage. Les colonnes retournées dans une liste séparée par des virgules ou définie par l'utilisateur.

String

La ligne est écrite en utilisant un format de chaîne de caractères. Les futures versions incluront la possibilité de définir le format de chaîne.
