NOM

DBD::Sponge - Créer une poignée d'instruction DBI à partir de données Perl

SYNTAXE

my $sponge = DBI->connect("dbi:Sponge:","","",{ RaiseError => 1 });
my $sth = $sponge->prepare($statement, {
        rows => $data,
        NAME => $names,
        %attr
    }
);

DESCRIPTION

DBD::Sponge est utile pour rendre une structure de données Perl accessible via une poignée d'instruction DBI standard. Cela peut être utile aux auteurs de modules DBD qui ont besoin de transformer des données de cette manière.

MÉTHODES

connect()

my $sponge = DBI->connect("dbi:Sponge:","","",{ RaiseError => 1 });

Voici une syntaxe d'exemple pour créer une poignée de base de données pour le pilote Sponge. Aucun nom d'utilisateur ni mot de passe n'est nécessaire.

prepare()

my $sth = $sponge->prepare($statement, {
        rows => $data,
        NAME => $names,
        %attr
    }
);
  • Le $statement ici est une instruction arbitraire ou un nom que vous souhaitez fournir comme identité de vos données. Si vous utilisez DBI::Profile, il apparaîtra dans les données du profil.

    En général, on s'attend à ce que vous prépariez une poignée d'instruction comme si une instruction "select" avait été exécutée.

  • $data est une référence vers les données que vous fournissez, sous forme de tableau de tableaux.
  • $names est une référence à un tableau de noms de colonnes pour les $data que vous fournissez. Le nombre et l'ordre doivent correspondre au nombre et à l'ordre des colonnes de $data.
  • %attr est une table de hachage d'autres attributs DBI standard que vous pourriez passer à une instruction de préparation.

    Actuellement, seuls NAME, TYPE et PRECISION sont pris en charge.

BOGUES

L'utilisation de ce module pour préparer des instructions de type INSERT n'est pas actuellement documentée.
