NOM

dbmail-httpd - communique avec le protocole HTTP-1.1

SYNTAXE

dbmail-httpd [--config fichier_config] [--pidfile fichier_pid]
dbmail-httpd [--config fichier_config] [--pidfile fichier_pid] --no-daemon
dbmail-httpd [--config fichier_config] [--pidfile fichier_pid] --inetd

DESCRIPTION

Expose le modèle de données de DBMail via une API RESTful.

Veuillez consulter contrib/dbmailclient.php pour les chemins d'URL pris en charge.

OPTIONS

-p, --pidfile fichier_pid

Spécifiez un fichier PID alternatif. Par défaut, les démons utilisent dbmail-<démon>.pid pour leurs fichiers PID, les enregistrant dans le répertoire spécifié par l'entrée pid_directory dans dbmail.conf ou, si celle-ci n'existe pas, la valeur définie par l'option de configuration --localstatedir, et s'arrêteront si le fichier PID ne peut être écrit. Utilisez l'option -p fichier_pid pour placer le fichier PID à l'emplacement préféré de votre système.

-n, --no-daemon

Pas de démonisation : mode inetd. Le programme reste attaché à la console depuis laquelle il a été lancé et lira et écrira sur stdin/stdout. Ceci est utile pour le débogage lorsqu'il est combiné avec l'option -v. Il est également utilisé pour l'exécution depuis (x)inetd.

-D, --inetd

Pas de démonisation : Le programme reste attaché à la console et écoutera sur les sockets réseau définis dans dbmail.conf. Ceci est principalement utilisé pour xinetd (Extended Internet Service Daemon).

OPTIONS COMMUNES

-f, --config fichier_config

Spécifiez un fichier de configuration alternatif.

Utilisez dbmail-<utilitaire> --help pour afficher l'emplacement par défaut.

-q, --quiet

Ignore silencieusement les invites interactives et les messages de statut utiles qui seraient autrement imprimés sur stdout. Utilisez deux -q pour faire taire les erreurs qui seraient autrement imprimées sur stderr.

-v, --verbose

Fonctionnement en mode verbeux. Certains utilitaires de la suite DBMail peuvent accepter deux -v pour une verbosité supplémentaire. Ceux qui ne comprennent pas cette convention ne se plaindront pas d'avoir le -v supplémentaire et fonctionneront simplement à leur niveau de verbosité normal.

-V, --version

Affiche la version et le copyright, puis quitte.

-h, --help

Affiche un bref résumé des options, puis quitte.
