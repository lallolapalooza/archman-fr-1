DESC

RIP
TION

Le programme dbmail-util offre un nettoyage de la base de données et un contrôle d'intégrité. Tous les messages marqués pour suppression (statut 2) seront marqués pour la suppression définitive (statut 3). Tous les messages marqués pour la suppression définitive seront effacés de la base de données. Le contrôle d'intégrité vérifiera les mimeparts, les valeurs d'en-tête, les

messages et les boîtes aux lettres non connectés. 
Par défaut, les vérifications sont en lecture seule. Passez l'option --no pour
répondre non à toutes les invites. Passez l'option --yes pour effectuer de
s modifications en lecture-écriture, en répondant oui à toutes les invites.
