Documentation de la fonction/sous-routine

sous-routine dbdsvdx (character uplo, character jobz, character range, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision vl, double precision vu, integer il, integer iu, integer ns, double precision, dimension( * ) s, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DBDSVDX

But :

!>
!>  DBDSVDX calcule la décomposition en valeurs singulières (SVD) d'une matrice
!>  bidiagonale réelle N×N (supérieure ou inférieure) B, B = U * S * VT,
!>  où S est une matrice diagonale à éléments diagonaux non négatifs
!>  (les valeurs singulières de B), et U et VT sont des matrices
!>  orthogonales de vecteurs singuliers gauche et droit, respectivement.
!>
!>  Étant donné un B bidiagonal supérieur avec diagonale D = [ d_1 d_2 ... d_N ]
!>  et surdiagonale E = [ e_1 e_2 ... e_N-1 ], DBDSVDX calcule la
!>  décomposition en valeurs singulières de B à travers les valeurs propres et
!>  vecteurs propres de la matrice tridiagonale N*2×N*2
!>
!>        |  0  d_1                |
!>        | d_1  0  e_1            |
!>  TGK = |     e_1  0  d_2        |
!>        |         d_2  .   .     |
!>        |              .   .   . |
!>
!>  Si (s,u,v) est un triplet singulier de B avec ||u|| = ||v|| = 1, alors
!>  (+/-s,q), ||q|| = 1, sont des paires propres de TGK, avec q = P * ( u' +/-v' ) /
!>  sqrt(2) = ( v_1 u_1 v_2 u_2 ... v_n u_n ) / sqrt(2), et
!>  P = [ e_{n+1} e_{1} e_{n+2} e_{2} ... ].
!>
!>  Étant donné une matrice TGK, on peut soit a) calculer -s,-v et changer les signes
!>  afin que les valeurs singulières (et les vecteurs correspondants) soient déjà en
!>  ordre décroissant (comme dans DGESVD/DGESDD), soit b) calculer s,v et réordonner
!>  les valeurs (et les vecteurs correspondants). DBDSVDX implémente a) en
!>  appelant DSTEVX (bissection plus itération inverse, à remplacer
!>  par une version de l'algorithme Multiple Relative Robust Representation
!>  (MR³). (Voir P. Willems et B. Lang, A framework for the MR^3
!>  algorithm: theory and implementation, SIAM J. Sci. Comput.,
!>  35:740-766, 2013.)
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : B est bidiagonale supérieure ;
!>          = 'L' : B est bidiagonale inférieure.
!>

JOBZ

!>          JOBZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs singulières ;
!>          = 'V' : Calculer les valeurs singulières et les vecteurs singuliers.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs singulières seront trouvées.
!>          = 'V' : toutes les valeurs singulières dans l'intervalle semi-ouvert [VL,VU)
!>                  seront trouvées.
!>          = 'I' : les valeurs singulières de la ième à la IU-ième seront trouvées.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice bidiagonale.  N >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          Les n éléments diagonaux de la matrice bidiagonale B.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (max(1,N-1))
!>          Les (n-1) éléments surdiagonaux de la matrice bidiagonale
!>          B dans les éléments 1 à N-1.
!>

VL

!>         VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle dans
!>          lequel rechercher les valeurs singulières. VU > VL.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>         VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle dans
!>          lequel rechercher les valeurs singulières. VU > VL.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur singulière à retourner.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur singulière à retourner.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

NS

!>          NS est INTEGER
!>          Le nombre total de valeurs singulières trouvées.  0 <= NS <= N.
!>          Si RANGE = 'A', NS = N, et si RANGE = 'I', NS = IU-IL+1.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (N)
!>          Les premiers NS éléments contiennent les valeurs singulières sélectionnées
!>          en ordre croissant.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension (2*N,K)
!>          Si JOBZ = 'V', alors si INFO = 0 les premières NS colonnes de Z
!>          contiennent les vecteurs singuliers de la matrice B correspondant aux
!>          valeurs singulières sélectionnées, avec U dans les lignes 1 à N et V
!>          dans les lignes N+1 à N*2, c'est-à-dire
!>          Z = [ U ]
!>              [ V ]
!>          Si JOBZ = 'N', Z n'est pas référencé.
!>          Note : L'utilisateur doit s'assurer qu'au moins K = NS+1 colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de
!>          NS n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(2,N*2).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (14*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (12*N)
!>          Si JOBZ = 'V', alors si INFO = 0, les premiers NS éléments de
!>          IWORK sont zéro. Si INFO > 0, alors IWORK contient les indices
!>          des vecteurs propres qui n'ont pas convergé dans DSTEVX.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le ième argument avait une valeur illégale
!>          > 0 :  si INFO = i, alors i vecteurs propres n'ont pas convergé
!>                   dans DSTEVX. Les indices des vecteurs propres
!>                   (tels que retournés par DSTEVX) sont stockés dans le
!>                   tableau IWORK.
!>                si INFO = N*2 + 1, une erreur interne s'est produite.
!>
