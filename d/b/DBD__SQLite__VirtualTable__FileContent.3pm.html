NOM

DBD::SQLite::VirtualTable::FileContent -- table virtuelle pour visualiser le contenu des fichiers

SYNOPSIS

Dans Perl :

$dbh->sqlite_create_module(fcontent => "DBD::SQLite::VirtualTable::FileContent");

Ensuite, en SQL :

CREATE VIRTUAL TABLE tbl USING fcontent(
   source      = src_table,
   content_col = content,
   path_col    = path,
   expose      = "path, col1, col2, col3", -- ou "*"
   root        = "/foo/bar"
   get_content = Foo::Bar::read_from_file
  );
SELECT col1, path, content FROM tbl WHERE ...;

DESCRIPTION

Une table virtuelle "FileContent" est liée à une table source sous-jacente, qui possède une colonne contenant les chemins vers des fichiers. La table virtuelle se comporte comme une vue de base de données sur la table source, avec une colonne supplémentaire qui expose le contenu de ces fichiers.

Ceci est particulièrement utile comme "contenu externe" pour une table fulltext (voir DBD::SQLite::Fulltext_search) : la table d'index stocke des métadonnées sur les fichiers, puis le moteur fulltext peut indexer à la fois les métadonnées et le contenu des fichiers.

PARAMÈTRES

Les paramètres pour créer une table virtuelle "FileContent" sont spécifiés dans l'instruction "CREATE VIRTUAL TABLE", juste comme des déclarations de colonnes régulières, mais avec un signe '='. Les paramètres autorisés sont :

"source"
Le nom de la table source. Ce paramètre est obligatoire. Tous les autres paramètres sont facultatifs.
"content_col"
Le nom de la colonne virtuelle exposant le contenu des fichiers. La valeur par défaut est "content".
"path_col"
Le nom de la colonne dans "source" qui contient les chemins des fichiers. La valeur par défaut est "path".
"expose"
Une liste (entre guillemets doubles) de noms de colonnes source à exposer par la table virtuelle, séparés par des virgules. La valeur par défaut est "*", ce qui signifie toutes les colonnes source.
"root"
Un répertoire racine facultatif qui sera préfixé à la colonne path lors de l'ouverture des fichiers.
"get_content"
Nom qualifié complet d'une fonction Perl pour lire le contenu des fichiers. L'implémentation par défaut lit simplement le fichier entier dans une chaîne ; mais ce hook peut pointer vers des implémentations plus sophistiquées, comme par exemple une fonction qui supprimerait les balises html. La fonction hookée est appelée ainsi : 
$file_content = $get_content->($path, $root);
