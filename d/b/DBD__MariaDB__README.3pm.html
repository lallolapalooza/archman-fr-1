DBD::MariaDB - pilote de base de données pour Perl

Ceci est le pilote Perl DBI pour accéder aux bases de données MariaDB et MySQL.

Le but de notre effort était de corriger la compatibilité MariaDB, le support Unicode Perl et les bugs liés à la sécurité.

Ce pilote Perl DBI est un fork du pilote DBD::mysql et a été créé car lesdits problèmes dans le DBD::mysql original n'ont pas été résolus depuis plus d'un an.

Utilisation

L'utilisation de ce pilote Perl DBI est décrite dans DBD::MariaDB.

Installation

L'installation est décrite dans DBD::MariaDB::INSTALL.

Support

Ce module est fourni sans garantie et est distribué tel quel.

Les archives de la liste de diffusion sont disponibles sur le forum des utilisateurs Perl DBI https://groups.google.com/forum/#!forum/perl.dbi.users.
