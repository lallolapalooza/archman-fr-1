DESCRIPTIO

Ce document décrit l'installation et la configuration de DBD::mysql, le pilote DBI de Perl pour la base de données MySQL. Avant de continuer, assurez-vous que vous disposez des prérequis : Perl, MySQL et DBI. Pour plus de détails, consultez la section séparée « PRÉREQUIS »

.

Selon votre version de Perl, il est possible d'utiliser une distribution binaire de DBD::mysql. Si c'est possible, c'est recommandé. Sinon, vous devrez installer à partir des sources. Dans ce cas, vous aurez définitivement besoin d'un compilateur C. L'installation à partir des binaires et des sources est décrite dans des sections séparées. « INSTALLATION BINAIRE ». « INSTALLATION À PARTIR DES SOURCES »

.

Enfin, si vous rencontrez des problèmes, n'oubliez pas de lire la section sur les problèmes connus « PROBLÈMES CONNUS ». Si cela ne vous aide pas, vous devriez consulter la section « SUPPORT

»

CONNEXIONS CHIFFRÉES via

SSL

La connexion à vos serveurs via une connexion chiffrée (SSL) est uniquement possible si vous avez activé ce paramètre au moment de la compilation. Depuis la version 4.034, c'est le comportement par

défaut.

Tenter de se connecter à un serveur qui exige une connexion chiffrée sans avoir d'abord compilé DBD::mysql avec l' "--ssl" option résultera en une erreur qui donne l'impression que votre mot de passe est

incorrect.

Si vous souhaitez compiler DBD::mysql sans support SSL, ce que vous ne voudrez probablement faire que si vous ne pouvez pas installer les en-têtes libssl pour une raison quelconque, vous pouvez le faire en passant l' "--nossl" option à Makefile.PL ou en définissant

la variable d'environnem
ent DBD_MYSQL_NOSSL à '1'.
