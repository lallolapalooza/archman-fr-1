NOM

dblink_send_query - envoie une requête asynchrone à une base de données distante

SYNTAXE

dblink_send_query(text connname, text sql) returns int

DESCRIPTION

dblink_send_query envoie une requête à exécuter de manière asynchrone, c'est-à-dire sans attendre immédiatement le résultat. Il ne doit pas y avoir de requête asynchrone déjà en cours sur la connexion.

Après avoir réussi à expédier une requête asynchrone, le statut d'achèvement peut être vérifié avec dblink_is_busy, et les résultats sont finalement collectés avec dblink_get_result. Il est également possible de tenter d'annuler une requête asynchrone active en utilisant dblink_cancel_query.

ARGUMENTS

connname

Nom de la connexion à utiliser.

sql

L'instruction SQL que vous souhaitez exécuter dans la base de données distante, par exemple select * from pg_class.

VALEUR DE RETOUR

Renvoie 1 si la requête a été expédiée avec succès, 0 sinon.

EXEMPLES

SELECT dblink_send_query('dtest1', 'SELECT * FROM foo WHERE f1 < 3');
