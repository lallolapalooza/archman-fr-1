NOM

DBM_Filter::null - filtre pour DBM_Filter

SYNTAXE

use SDBM_File; # ou DB_File, GDBM_File, NDBM_File, ou ODBM_File
use DBM_Filter ;
$db = tie %hash, ...
$db->Filter_Push('null');

DESCRIPTION

Ce filtre garantit que toutes les données écrites dans le fichier DBM sont terminées par un caractère nul. Ceci est utile lorsque vous avez un script perl qui doit interopérer avec un fichier DBM qu'un programme C utilise également. Un problème assez courant est que l'application C inclut le caractère nul de terminaison dans une chaîne lors de l'écriture dans le fichier DBM. Ce filtre garantira que toutes les données écrites dans le fichier DBM peuvent être lues par l'application C.
