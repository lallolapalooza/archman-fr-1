NOM

dbprobe - informations sur le temps de réponse et la disponibilité de la base de données

SYNTAXE

dbprobe.pl [délai]

DESCRIPTION

L'utilitaire dbprobe est utilisé par pmdadbping(1) pour mesurer le temps de réponse d'une base de données. Une requête donnée est exécutée sur la base de données à l'intervalle demandé (délai, qui est de 60 secondes par défaut). Cette mesure du temps de réponse peut être exportée via le framework Performance Co-Pilot pour une surveillance en direct et historique à l'aide de pmdadbping(1).

VOIR AUSSI

PCPIntro(1), pmcd(1), pmdadbping(1) et DBI(3).
