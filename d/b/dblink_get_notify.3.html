NOM

dblink_get_notify - récupérer les notifications asynchrones sur une connexion

SYNTAXE

dblink_get_notify() renvoie un ensemble de (notify_name texte, be_pid entier, extra texte)
dblink_get_notify(texte nom_connexion) renvoie un ensemble de (notify_name texte, be_pid entier, extra texte)

DESCRIPTION

dblink_get_notify récupère les notifications sur la connexion non nommée, ou sur une connexion nommée si spécifiée. Pour recevoir des notifications via dblink, LISTEN doit d'abord être exécuté, en utilisant dblink_exec. Pour plus de détails, voir LISTEN(7) et NOTIFY(7).

ARGUMENTS

nom_connexion

Le nom d'une connexion nommée pour recevoir des notifications.

VALEUR DE RETOUR

Renvoie un ensemble de (notify_name texte, be_pid entier, extra texte), ou un ensemble vide si aucun.

EXEMPLES

SELECT dblink_exec('LISTEN virtual');
