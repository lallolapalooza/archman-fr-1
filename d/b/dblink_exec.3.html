dblink_exec(3)

Paquet: postgresql

Licences: PostgreSQL

DBLINK_EXEC(3) Documentation PostgreSQL 18.1 DBLINK_EXEC(3)

NOM

dblink_exec - exécute une commande dans une base de données distante

SYNTAXE

dblink_exec(text connname, text sql [, bool fail_on_error]) retourne text
dblink_exec(text connstr, text sql [, bool fail_on_error]) retourne text
dblink_exec(text sql [, bool fail_on_error]) retourne text

DESCRIPTION

dblink_exec exécute une commande (c'est-à-dire toute instruction SQL qui ne retourne pas de lignes) dans une base de données distante.

Lorsque deux arguments texte sont donnés, le premier est d'abord recherché comme nom de connexion persistante ; s'il est trouvé, la commande est exécutée sur cette connexion. S'il n'est pas trouvé, le premier argument est traité comme une chaîne d'informations de connexion comme pour dblink_connect, et la connexion indiquée est établie uniquement pour la durée de cette commande.

ARGUMENTS

connname

Nom de la connexion à utiliser ; omettre ce paramètre pour utiliser la connexion sans nom.

connstr

Une chaîne d'informations de connexion, comme décrit précédemment pour dblink_connect.

sql

La commande SQL que vous souhaitez exécuter dans la base de données distante, par exemple insert into foo values(0, 'a', '{"a0","b0","c0"}').

fail_on_error

Si vrai (valeur par défaut lorsqu'omise), alors une erreur levée du côté distant de la connexion provoque également une erreur locale. Si faux, l'erreur distante est signalée localement comme un NOTICE, et la valeur de retour de la fonction est définie sur ERREUR.

VALEUR DE RETOUR

Retourne l'état, soit la chaîne d'état de la commande, soit ERREUR.

EXEMPLES

SELECT dblink_connect('dbname=dblink_test_standby');
 dblink_connect
----------------
 OK
(1 row)
SELECT dblink_exec('insert into foo values(21, ''z'', ''{"a0","b0","c0"}'');');
   dblink_exec
-----------------
 INSERT 943366 1
(1 row)
SELECT dblink_connect('myconn', 'dbname=regression');
 dblink_connect
----------------
 OK
(1 row)
SELECT dblink_exec('myconn', 'insert into foo values(21, ''z'', ''{"a0","b0","c0"}'');');
   dblink_exec
------------------
 INSERT 6432584 1
(1 row)
SELECT dblink_exec('myconn', 'insert into pg_class values (''foo'')',false);
NOTICE:  sql error
DETAIL:  ERROR:  null value in column "relnamespace" violates not-null constraint
 dblink_exec
-------------
 ERROR
(1 row)
