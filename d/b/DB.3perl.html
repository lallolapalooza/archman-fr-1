DESCRIPTI

ON

Les informations de débogage de Perl sont souvent nécessaires non seulement pa

r les débogueurs, mais aussi par des modules qui ont besoin d'informations
« spéciales » pour faire correctement leur travail, comme les profileurs.

Ce module abstrait et fournit tous les points d'accès à la fonctionnalité de débogage interne de Perl, afin que diverses implémentations de débogueurs Perl (ou des paquets qui veulent simplement accéder aux données de débogage « privilégiées ») puissent toutes bénéficier du développement de ce code commun. Actuellement utilisé

par Swat, le débogueur graphique perl/Tk. 
Notez que plusieurs « interfaces » peuvent se connecter à cette
    API de débogage simultanément. Cela vise
à faciliter des choses comme le débogage avec une ligne de commande et une interface graphique en même t
emps, le débogage de débogueurs, etc. [Cela semble bien, mais cela nécessite un support sérieux -- GSAR]
