DBWRAP_TOOL(1) Outils d'administration système DBWRAP_TOOL(1)

NOM

dbwrap_tool - outil de manipulation de bas niveau de TDB/CTDB utilisant l'interface dbwrap

SYNTAXE

dbwrap_tool [-?|--help] [--usage] [--persistent] [--non-persistent] [-d|--debuglevel=NIVEAU_DEBUG] [--debug-stdout] [--configfile=FICHIER_CONFIG] [--option=nom=valeur] [-l|--log-basename=FICHIER_LOG] [--leak-report] [--leak-report-full] {<base de données>} {<opération>} [<clé> [<type> [<valeur>]]]

DESCRIPTION

Cet outil fait partie de la suite samba(7).

Le programme dbwrap_tool est utilisé pour lire et manipuler les bases de données TDB/CTDB en utilisant l'interface dbwrap.

Les opérations suivantes sur les bases de données sont disponibles:

•fetch: récupérer un enregistrement
•store: créer ou modifier un enregistrement
•delete: supprimer un enregistrement
•exists: tester l'existence d'un enregistrement
•erase: supprimer tous les enregistrements
•listkeys: lister tous les enregistrements disponibles
•listwatchers: lister les processus qui attendent des modifications sur un enregistrement

Les types suivants sont disponibles:

•int32: entier signé 32 bits
•uint32: entier non signé 32 bits
•string: "hello world"
•hex: chaînes hexadécimales comme "68656C6C6F20776F726C6400" ("hello world")

OPTIONS

--persistent

Ouvre la base de données en tant que base de données persistante.

Exactement une des options --persistent ou --non-persistent doit être spécifiée.

--non-persistent

Ouvre la base de données en tant que base de données non persistante.

Attention : ouvrir une base de données en mode non persistant lorsqu'il n'y a actuellement aucun autre ouvert effacera la base de données.

Exactement une des options --persistent ou --non-persistent doit être spécifiée.

-?|--help

Affiche un résumé des options de la ligne de commande.

--usage

Affiche un bref message d'utilisation.

-d|--debuglevel=niveau

niveau est un entier compris entre 0 et 10. La valeur par défaut si ce paramètre n'est pas spécifié est 1 pour les applications client.

Plus cette valeur est élevée, plus les fichiers journaux contiendront de détails sur les activités du serveur. Au niveau 0, seuls les erreurs critiques et les avertissements sérieux seront enregistrés. Le niveau 1 est un niveau raisonnable pour une utilisation quotidienne, il génère une petite quantité d'informations sur les opérations effectuées.

Les niveaux supérieurs à 1 généreront une quantité considérable de données de journalisation et ne devraient être utilisés que lors de l'investigation d'un problème. Les niveaux supérieurs à 3 sont conçus pour être utilisés uniquement par les développeurs et génèrent d'énormes quantités de données de journalisation, dont la plupart sont extrêmement cryptiques.

Notez que la spécification de ce paramètre ici remplacera le paramètre log level du fichier /etc/samba/smb.conf.

--debug-stdout

Cela redirigera la sortie de débogage vers STDOUT. Par défaut, tous les clients enregistrent sur STDERR.

--configfile=<fichier de configuration>

Le fichier spécifié contient les détails de configuration requis par le client. Les informations de ce fichier peuvent être générales pour le client et le serveur, ou fournir uniquement des options spécifiques au client telles que client smb encrypt. Voir /etc/samba/smb.conf pour plus d'informations. Le nom du fichier de configuration par défaut est déterminé au moment de la compilation.

--option=<nom>=<valeur>

Définit l'option smb.conf(5) "<nom>" à la valeur "<valeur>" depuis la ligne de commande. Cela remplace les valeurs par défaut compilées et les options lues depuis le fichier de configuration. Si un nom ou une valeur contient un espace, entourez tout --option=nom=valeur avec des guillemets.

-l|--log-basename=répertoire_log

Nom du répertoire de base pour les fichiers de journalisation/débogage. L'extension ".nom_programme" sera ajoutée (par exemple, log.smbclient, log.smbd, etc.). Le fichier journal n'est jamais supprimé par le client.

--leak-report

Active le rapport de fuite talloc à la sortie.

--leak-report-full

Active le rapport complet de fuite talloc à la sortie.

-V|--version

Affiche le numéro de version du programme.

COMMANDES

fetch

dbwrap_tool <base de données> fetch <clé> <type>

store

dbwrap_tool <base de données> store <clé> <type> <valeur>

delete

dbwrap_tool <base de données> delete <clé>

exists

dbwrap_tool <base de données> exists <clé>

erase

dbwrap_tool <base de données> erase

listkeys

dbwrap_tool <base de données> listkeys

listwatchers

dbwrap_tool <base de données> listwatchers

EXEMPLES

Lister toutes les clés de winbindd_idmap.tdb

dbwrap_tool --persistent winbindd_idmap.tdb listkeys

Récupérer l'enregistrement avec la clé "USER HWM" en tant que uint32

dbwrap_tool --persistent winbindd_idmap.tdb fetch "USER HWM" uint32

Supprimer l'enregistrement avec la clé "USER HWM"

dbwrap_tool --persistent winbindd_idmap.tdb delete "USER HWM"

Stocker et écraser l'enregistrement "USER HWM" avec la valeur 214

uint32: dbwrap_tool --persistent winbindd_idmap.tdb store "USER HWM" uint32 214 hex: dbwrap_tool --persistent winbindd_idmap.tdb store "USER HWM" hex D6000000
