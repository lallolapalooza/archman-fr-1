NOM

dbmail-sievecmd - manipule les scripts Sieve dans DBMail.

SYNTAXE

dbmail-sievecmd [options communes] -u nomutilisateur --list
dbmail-sievecmd [options communes] -u nomutilisateur --activate nomscript
dbmail-sievecmd [options communes] -u nomutilisateur --deactivate nomscript
dbmail-sievecmd [options communes] -u nomutilisateur --show nomscript
dbmail-sievecmd [options communes] -u nomutilisateur --import fichier
dbmail-sievecmd [options communes] -u nomutilisateur --edit nomscript
dbmail-sievecmd [options communes] -u nomutilisateur --remove nomscript

DESCRIPTION

DBMail stocke les scripts Sieve dans DBMail. Ces scripts sont utilisés pour trier le courrier entrant pour les utilisateurs de messagerie. Chaque utilisateur a son propre espace de script et peut télécharger des scripts vers le démon dbmail-sieved(8). L'utilitaire dbmail-sievecmd(8) fournit une méthode pratique à l'administrateur système pour travailler avec les scripts Sieve depuis la ligne de commande.

OPTIONS

-u, --user nomutilisateur

Spécifie l'utilisateur dont les scripts seront modifiés.

-l, --list

Liste les scripts appartenant à l'utilisateur.

-a, --activate nomscript

Active nomscript, désactivant tous les autres scripts.

-d, --deactivate nomscript

Désactive nomscript s'il était actif.

-c, --show nomscript

Affiche le script nommé.

-i, --import nomscript < fichier

Crée un script nommé nomscript en important fichier.

-e, --edit nomscript

Modifie le contenu du script nommé.

(si aucun script n'est donné, le script actif est affiché)

-r, --remove nomscript

Supprime le script nommé. Si le script était actif, aucun script ne sera actif après sa suppression.

OPTIONS COMMUNES

-f, --config fichierconfig

Spécifie un fichier de configuration alternatif.

Utilisez dbmail-<utilitaire> --help pour afficher l'emplacement par défaut.

-q, --quiet

Ignore silencieusement les invites interactives et les messages d'état utiles qui seraient autrement imprimés sur stdout. Utilisez deux -q pour faire taire les erreurs qui seraient autrement imprimées sur stderr.

-v, --verbose

Fonctionne de manière verbeuse. Certains utilitaires de la suite DBMail peuvent accepter deux -v pour une verbosité supplémentaire. Ceux qui ne comprennent pas cette convention ne se plaindront pas d'avoir le -v supplémentaire et fonctionneront simplement à leur verbosité normale.

-V, --version

Affiche la version et le copyright, puis quitte.

-h, --help

Affiche un bref résumé des options, puis quitte.
