NOM

dbmail-pop3d - Daemon POP3 fournissant le protocole Post Office Protocol, POP3, tel que spécifié dans la RFC 1939.

SYNTAXE

dbmail-pop3d [--config fichier_config] [--pidfile fichier_pid]
dbmail-pop3d [--config fichier_config] [--pidfile fichier_pid] --no-daemon
dbmail-pop3d [--config fichier_config] [--pidfile fichier_pid] --inetd

DESCRIPTION

Le daemon dbmail-pop3d est un serveur POP3 complet.

OPTIONS

-p, --pidfile fichier_pid

Spécifiez un fichier PID alternatif. Par défaut, les daemons utilisent dbmail-<daemon>.pid pour leurs fichiers PID, en les enregistrant dans le répertoire spécifié par l'entrée pid_directory dans dbmail.conf ou, si elle n'existe pas, dans la valeur définie par l'option de configuration --localstatedir, et s'arrêteront si le fichier PID ne peut pas être écrit. Utilisez l'option -p fichier_pid pour placer le fichier PID dans l'emplacement préféré de votre système.

-n, --no-daemon

Pas de daemonisation : mode inetd. Le programme reste attaché à la console depuis laquelle il a été démarré et lira et écrira sur stdin/stdout. Ceci est utile pour le débogage lorsqu'il est combiné avec l'option -v. Il est également utilisé pour le lancement depuis (x)inetd.

-D, --inetd

Pas de daemonisation : Le programme reste attaché à la console et écoutera sur les sockets réseau définis dans dbmail.conf. Ceci est principalement utilisé pour xinetd (Extended Internet Service Daemon).

OPTIONS COMMUNES

-f, --config fichier_config

Spécifiez un fichier de configuration alternatif.

Utilisez dbmail-<utilitaire> --help pour afficher l'emplacement par défaut.

-q, --quiet

Ignorez silencieusement les invites interactives et les messages d'état utiles qui seraient autrement imprimés sur stdout. Utilisez deux -q pour faire taire les erreurs qui seraient autrement imprimées sur stderr.

-v, --verbose

Fonctionne de manière verbeuse. Certains des utilitaires de la suite DBMail peuvent accepter deux -v pour une verbosité supplémentaire. Ceux qui ne comprennent pas cette convention ne se plaindront pas d'avoir le -v supplémentaire et fonctionneront simplement à leur niveau de verbosité normal.

-V, --version

Affiche la version et les droits d'auteur, puis quitte.

-h, --help

Affiche un bref résumé des options, puis quitte.
