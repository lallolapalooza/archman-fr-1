dblink_build_sql_delete(3)

Paquet: postgresql

Licences: PostgreSQL

DBLINK_BUILD_SQL_DELETE(3) Documentation PostgreSQL 18.1 DBLINK_BUILD_SQL_DELETE(3)

NOM

dblink_build_sql_delete - construit une instruction DELETE en utilisant les valeurs fournies pour les valeurs des champs de clé primaire

SYNTAXE

dblink_build_sql_delete(text relname,
                        int2vector primary_key_attnums,
                        integer num_primary_key_atts,
                        text[] tgt_pk_att_vals_array) returns text

DESCRIPTION

dblink_build_sql_delete peut être utile pour répliquer sélectivement une table locale vers une base de données distante. Elle construit une commande SQL DELETE qui supprimera la ligne avec les valeurs de clé primaire données.

ARGUMENTS

relname

Nom d'une relation locale, par exemple foo ou myschema.mytab. Inclure des guillemets doubles si le nom est en casse mixte ou contient des caractères spéciaux, par exemple "FooBar" ; sans guillemets, la chaîne sera convertie en minuscules.

primary_key_attnums

Numéros d'attribut (basés sur 1) des champs de clé primaire, par exemple 1 2.

num_primary_key_atts

Le nombre de champs de clé primaire.

tgt_pk_att_vals_array

Valeurs des champs de clé primaire à utiliser dans la commande DELETE résultante. Chaque champ est représenté sous forme de texte.

VALEUR DE RETOUR

Retourne l'instruction SQL demandée sous forme de texte.

NOTES

Depuis PostgreSQL 9.0, les numéros d'attribut dans primary_key_attnums sont interprétés comme des numéros de colonne logiques, correspondant à la position de la colonne dans SELECT * FROM relname. Les versions précédentes interprétaient les numéros comme des positions de colonne physiques. Il y a une différence si une ou plusieurs colonnes à gauche de la colonne indiquée ont été supprimées pendant la durée de vie de la table.

EXEMPLES

SELECT dblink_build_sql_delete('"MyFoo"', '1 2', 2, '{"1", "b"}');
           dblink_build_sql_delete
---------------------------------------------
 DELETE FROM "MyFoo" WHERE f1='1' AND f2='b'
(1 row)
