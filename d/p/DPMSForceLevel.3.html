DPMSForceLevel(3) FONCTIONS X DPMSForceLevel(3)

NOM

DPMSForceLevel - force un affichage capable de DPMS dans le niveau de puissance spécifié

SYNTAXE

cc [ indic ... ] fichier ... -lXext [ bibliothèque ... ]
#include <X11/extensions/dpms.h>
Status DPMSForceLevel ( Display *display, CARD16 level );

ARGUMENTS

display
Spécifie la connexion au serveur X
level
Spécifie le niveau auquel forcer la puissance

DESCRIPTION

La fonction DPMSForceLevel force un affichage capable de DPMS dans le niveau de puissance spécifié. Le level doit être l'un des quatre états suivants : DPMSModeOn, DPMSModeStandby, DPMSModeSuspend, ou DPMSModeOff. Des valeurs autres que celles-ci entraîneront une erreur BadValue. Si DPMS est désactivé sur l'affichage, tenter de définir le niveau de puissance sur l'affichage entraînera une erreur de protocole BadMatch.

VALEURS DE RETOUR

TRUE
La fonction DPMSForceLevel retourne toujours TRUE.

ERREURS

BadValue
Un niveau autre que DPMSModeOn, DPMSModeStandby, DPMSModeSuspend, ou DPMSModeOff a été spécifié.
BadMatch
DPMS est désactivé sur l'affichage spécifié.
