sous-routine dptrfs (integer n, integer nrhs, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) df, double precision, dimension( * ) ef, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer info)

DPTRFS

But:

!>
!> DPTRFS améliore la solution calculée pour un système d'équations linéaires
!> lorsque la matrice des coefficients est symétrique définie positive
!> et tridiagonale, et fournit des bornes d'erreur et des estimations d'erreur
!> rétrogrades pour la solution.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un entier (INTEGER)
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

D

!>          D est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau de double précision (DOUBLE PRECISION), dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice tridiagonale A.
!>

DF

!>          DF est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>          Les n éléments diagonaux de la matrice diagonale D issue de la
!>          factorisation calculée par DPTTRF.
!>

EF

!>          EF est un tableau de double précision (DOUBLE PRECISION), dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux du facteur bidiagonal unitaire
!>          L issu de la factorisation calculée par DPTTRF.
!>

B

!>          B est un tableau de double précision (DOUBLE PRECISION), dimension (LDB,NRHS)
!>          Le membre de droite de la matrice B.
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau de double précision (DOUBLE PRECISION), dimension (LDX,NRHS)
!>          En entrée, la matrice solution X, telle que calculée par DPTTRS.
!>          En sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est un entier (INTEGER)
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

FERR

!>          FERR est un tableau de double précision (DOUBLE PRECISION), dimension (NRHS)
!>          La borne d'erreur avant pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude de l'élément le plus grand
!>          dans (X(j) - XTRUE) divisée par la magnitude de l'élément le plus grand
!>          dans X(j).
!>

BERR

!>          BERR est un tableau de double précision (DOUBLE PRECISION), dimension (NRHS)
!>          L'erreur rétrograde relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans
!>          tout élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau de double précision (DOUBLE PRECISION), dimension (2*N)
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, alors le i-ème argument avait une valeur illégale
!>

Paramètres internes:

!>  ITMAX est le nombre maximum d'étapes de raffinement itératif.
!>
