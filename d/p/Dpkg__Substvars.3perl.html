NOM

Dpkg::Substvars - gérer la substitution de variables dans les chaînes

DESCRIPTION

Il fournit une classe capable de substituer des variables dans des chaînes.

MÉTHODES

$s = Dpkg::Substvars->new($file)
Crée un nouvel objet capable d'effectuer des substitutions. Par défaut, il contient des substitutions génériques comme ${Newline}, ${Space}, ${Tab}, ${dpkg:Version} et ${dpkg:Upstream-Version}.

Des substitutions supplémentaires seront lues à partir du fichier passé en paramètre.

Il garde une trace des substitutions qui ont réellement été utilisées (ne comptant que substvars(), et non get()), et avertit des substvars inutilisées lorsque cela est demandé. Les substitutions qui sont toujours présentes ne sont pas incluses dans ces avertissements.

$s->set($key, $value)
Ajoute/remplace une substitution.
$s->set_as_used($key, $value)
Ajoute/remplace une substitution et la marque comme utilisée (aucun avertissement ne sera produit même si elle n'est pas utilisée).
$s->set_as_auto($key, $value)
Ajoute/remplace une substitution et la marque comme utilisée et automatique (aucun avertissement ne sera produit même si elle n'est pas utilisée), et elle ne sera pas émise dans le fichier substvars.
$s->set_as_optional($key, $value)
Ajoute/remplace une substitution et la marque comme utilisée et optionnelle (aucun avertissement ne sera produit même si elle n'est pas utilisée).
$s->set_as_required($key, $value)
Ajoute/remplace une substitution et la marque comme requise (une erreur sera produite si elle n'est pas utilisée).
$s->get($key)
Récupère la valeur d'une substitution donnée.
$s->delete($key)
Supprime une substitution donnée.
$s->mark_as_used($key)
Empêche les avertissements concernant une substitution inutilisée, par exemple si elle est fournie par défaut.
$s->parse($fh, $desc)
Ajoute de nouvelles substitutions lues depuis le descripteur de fichier. $desc est utilisé pour identifier le descripteur de fichier dans les messages d'erreur.

Retourne le nombre de substitutions qui ont été analysées avec succès.

$s->load($file)
Ajoute de nouvelles substitutions lues depuis $file.
$s->set_version_substvars($sourceversion, $binaryversion)
Définit ${binary:Version}, ${source:Version} et ${source:Upstream-Version} en se basant sur les chaînes de version fournies.

Celles-ci ne feront jamais l'objet d'un avertissement lorsqu'elles ne sont pas utilisées.

$s->set_arch_substvars()
Définit les variables d'architecture : ${Arch}.

Celle-ci ne fera jamais l'objet d'un avertissement lorsqu'elle n'est pas utilisée.

$s->set_vendor_substvars()
Définit les variables du fournisseur : ${vendor:Name} et ${vendor:Id}.

Celles-ci ne feront jamais l'objet d'un avertissement lorsqu'elles ne sont pas utilisées.

$s->set_desc_substvars()
Définit les variables de description de la source : ${source:Synopsis} et ${source:Extended-Description}.

Celles-ci ne feront jamais l'objet d'un avertissement lorsqu'elles ne sont pas utilisées.

$s->set_field_substvars($ctrl, $prefix)
Définit les variables de champ à partir d'un objet Dpkg::Control, chaque variable ayant la forme "${$prefix:$field}".

Celles-ci ne feront jamais l'objet d'un avertissement lorsqu'elles ne sont pas utilisées.

$newstring = $s->substvars($string)
Substitue les variables dans $string et retourne le résultat dans $newstring.
$s->warn_about_unused()
Émet des avertissements pour toutes les variables qui ont été définies mais pas utilisées.
$s->set_msg_prefix($prefix)
Définit un préfixe affiché avant tous les messages d'avertissement/d'erreur produits par le module.
$s->filter(%opts)
Filtre les variables de substitution.

Options :

remove
Une fonction retournant un booléen, utilisée pour décider s'il faut supprimer une variable de substitution, exécutée comme $opts{remove}->($var).
keep
Une fonction retournant un booléen, utilisée pour décider s'il faut conserver la variable de substitution, exécutée comme $opts{keep}->($var).
"$s"
Retourne une représentation sous forme de chaîne de toutes les variables de substitution sauf les automatiques.
$str = $s->output([$fh])
Retourne toutes les variables de substitution sauf les automatiques. Si $fh est passé, les imprime dans le descripteur de fichier.
$s->save($file)
Stocke toutes les variables de substitution sauf les automatiques dans le fichier indiqué.

CHANGEMENTS

Version 2.03 (dpkg 1.22.15)

Nouvelles méthodes : $s->set_as_optional(), $s->set_as_required().

Version 2.02 (dpkg 1.22.7)

Nouvelle fonctionnalité : Ajout du support pour les variables de substitution requises.

Version 2.01 (dpkg 1.21.8)

Nouvelle fonctionnalité : Ajout du support pour les variables de substitution optionnelles.

Version 2.00 (dpkg 1.20.0)

Méthode supprimée : $s->no_warn().

Nouvelle méthode : $s->set_vendor_substvars().

Version 1.06 (dpkg 1.19.0)

Nouvelle méthode : $s->set_desc_substvars().

Version 1.05 (dpkg 1.18.11)

Substvar obsolète : Émet une erreur lors de l'utilisation de la substvar Source-Version.

Nouveau retour : $s->parse() retourne désormais le nombre de substvars analysées.

Nouvelle méthode : $s->set_field_substvars().

Version 1.04 (dpkg 1.18.0)

Nouvelle méthode : $s->filter().

Version 1.03 (dpkg 1.17.11)

Nouvelle méthode : $s->set_as_auto().

Version 1.02 (dpkg 1.16.5)

Nouvel argument : Accepte un $binaryversion dans $s->set_version_substvars(), le passage d'un seul argument reste pris en charge.

Nouvelle méthode : $s->mark_as_used().

Méthode obsolète : $s->no_warn(), utilisez plutôt $s->mark_as_used() .

Version 1.01 (dpkg 1.16.4)

Nouvelle méthode : $s->set_as_used().

Version 1.00 (dpkg 1.15.6)

Marque le module comme public.
