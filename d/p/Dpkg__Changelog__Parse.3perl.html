NOM

Dpkg::Changelog::Parse - analyseur générique de changelog pour dpkg-parsechangelog

DESCRIPTION

Ce module fournit un ensemble de fonctions qui reproduisent toutes les fonctionnalités de dpkg-parsechangelog.

FONCTIONS

$fields = changelog_parse(%opts)
Cette fonction analysera un changelog. En contexte de liste, elle retourne autant d'objets Dpkg::Control que le parseur en a créés. En contexte scalaire, elle ne retournera que le premier. Si le parseur n'a retourné aucune donnée, il retournera une liste vide en contexte de liste ou undef en contexte scalaire. Si le parseur a échoué, il mourra. Toute erreur d'analyse sera imprimée en avertissement sur la sortie standard d'erreur, mais cela peut être désactivé en passant $opts{verbose} à 0.

L'analyse elle-même est effectuée par un module de parseur (recherché dans les répertoires de librairies perl standards. Ce module est nommé selon le format qu'il est capable d'analyser, avec le nom capitalisé. Par défaut, c'est soit Dpkg::Changelog::Debian (du format « debian ») soit le nom du format recherché dans les 40 dernières lignes du changelog lui-même (extrait avec cette expression régulière perl « \schangelog-format:\s+([0-9a-z]+)\W »). Mais cela peut être remplacé avec $opts{changelogformat}.

Toutes les autres clés dans %opts sont transmises au constructeur du module de parseur.

Options :

fichier
Définit le fichier changelog à analyser. Par défaut, debian/changelog.
etiquette
Définit le nom du changelog utilisé dans les messages de sortie. Par défaut, $opts{fichier}.
compression
Définit un booléen indiquant s'il faut charger le fichier sans prise en charge de la compression. Si le fichier est le défaut, la compression est désactivée, sinon le défaut est d'activer la compression.
format_changelog
Définit le format d'entrée du changelog à utiliser.
format
Définit le format de sortie à utiliser. Par défaut, « dpkg ».
verbeux
Définit s'il faut imprimer les erreurs d'analyse sous forme d'avertissements sur la sortie standard d'erreur. Par défaut, vrai.
