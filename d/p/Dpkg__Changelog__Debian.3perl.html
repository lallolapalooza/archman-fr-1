NOM

Dpkg::Changelog::Debian - analyser les fichiers changelog Debian

DESCRIPTION

Cette classe représente un fichier changelog Debian comme un tableau d'entrées de changelog (Dpkg::Changelog::Entry::Debian). Elle implémente l'interface générique Dpkg::Changelog. Seules les méthodes spécifiques à cette implémentation sont décrites ci-dessous, les autres sont héritées.

Dpkg::Changelog::Debian analyse les changelogs Debian tels que décrits dans deb-changelog(5).

L'analyseur essaie d'ignorer la plupart des éléments superflus comme les commentaires de style # ou /* */, les mots-clés RCS, les modlines Vim, les variables locales Emacs et les éléments provenant d'anciens formats de changelog en fin de fichier. NOTE : la plupart de ceux-ci sont actuellement ignorés silencieusement, aucune erreur d'analyse n'est émise pour eux. Cela devrait être configurable à l'avenir.

MÉTHODES

$nombre = $c->parse($fh, $description)
Lit le handle de fichier et analyse un changelog Debian qu'il contient, pour stocker les entrées comme un tableau d'objets Dpkg::Changelog::Entry::Debian. Toutes les entrées précédentes dans l'objet sont réinitialisées avant l'analyse des nouvelles données.

Retourne le nombre d'entrées de changelog qui ont été analysées avec succès.
