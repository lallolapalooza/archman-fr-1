NOM

Dpkg::Compression::FileHandle - classe gérant de manière transparente la compression des fichiers

SYNOPSIS

use Dpkg::Compression::FileHandle;
my ($fh, @lines);
$fh = Dpkg::Compression::FileHandle->new(filename => 'sample.gz');
print $fh "Something\n";
close $fh;
$fh = Dpkg::Compression::FileHandle->new();
open($fh, '>', 'sample.bz2');
print $fh "Something\n";
close $fh;
$fh = Dpkg::Compression::FileHandle->new();
$fh->open('sample.xz', 'w');
$fh->print("Something\n");
$fh->close();
$fh = Dpkg::Compression::FileHandle->new(filename => 'sample.gz');
@lines = <$fh>;
close $fh;
$fh = Dpkg::Compression::FileHandle->new();
open($fh, '<', 'sample.bz2');
@lines = <$fh>;
close $fh;
$fh = Dpkg::Compression::FileHandle->new();
$fh->open('sample.xz', 'r');
@lines = $fh->getlines();
$fh->close();

DESCRIPTION

Dpkg::Compression::FileHandle est une classe qui peut être utilisée comme n'importe quel descripteur de fichier et qui gère de manière transparente les fichiers compressés. Par défaut, le schéma de compression est déduit du nom de fichier, mais vous pouvez modifier ce comportement avec la méthode set_compression().

Si vous n'ouvrez pas le fichier explicitement, il sera ouvert automatiquement lors de la première opération de lecture ou d'écriture en fonction du nom de fichier défini lors de la création (ou plus tard avec la méthode set_filename() ).

Une fois qu'un fichier a été ouvert, le descripteur de fichier doit être fermé avant de pouvoir en ouvrir un autre.

FONCTIONS STANDARD

Les fonctions standard agissant sur les descripteurs de fichier devraient accepter de manière transparente un objet Dpkg::Compression::FileHandle, y compris open() (uniquement lors de l'utilisation de la variante avec 3 paramètres), close(), binmode(), eof(), fileno(), getc(), print(), printf(), read(), sysread(), say(), write(), syswrite(), seek(), sysseek(), tell().

Notez cependant que seek() et sysseek() ne fonctionneront que sur les fichiers non compressés, car les fichiers compressés sont réellement des tuyaux vers les programmes de compression et on ne peut pas utiliser seek sur un tuyau.

MÉTHODES FileHandle

La classe hérite de IO::File, donc toutes les méthodes qui fonctionnent sur cette classe devraient aussi fonctionner pour Dpkg::Compression::FileHandle. Il peut y avoir des exceptions toutefois.

MÉTHODES PUBLIQUES

$fh = Dpkg::Compression::FileHandle->new(%opts)
Crée un nouveau descripteur de fichier prenant en charge la compression/décompression à la volée.

Options :

filename
Voir $fh->set_filename().
compression
Voir $fh->set_compression().
compression_level
Voir $fh->set_compression_level().
add_comp_ext
Si défini à vrai, l'extension correspondant au schéma de compression sélectionné est automatiquement ajoutée au nom de fichier enregistré. C'est évidemment incompatible avec la détection automatique de la méthode de compression.
$fh->ensure_open($mode, %opts)
S'assure que le fichier est ouvert dans le mode demandé ("r" pour lecture et "w" pour écriture). Les options sont transmises à l'appel spawn() du compresseur, si un est utilisé. Ouvre le fichier avec le nom de fichier enregistré si nécessaire. Si le fichier est déjà ouvert mais pas dans le mode demandé, une erreur est générée. spawn() Ouvre le fichier avec le nom de fichier enregistré si nécessaire. Si le fichier est déjà ouvert mais pas dans le mode demandé, une erreur est générée.
$fh->set_compression($comp)
Définit la méthode de compression utilisée. $comp devrait être l'une des méthodes prises en charge par Dpkg::Compression ou "none" ou "auto". "none" indique que le fichier n'est pas compressé et "auto" indique que la méthode doit être déduite de l'extension du nom de fichier utilisé.
$fh->set_compression_level($level)
Indique le niveau de compression souhaité. Il devrait s'agir d'une valeur acceptée par la fonction compression_is_valid_level() de Dpkg::Compression.
$fh->set_filename($name, [$add_comp_ext])
Utilise $name comme nom de fichier lorsque le fichier doit être ouvert/créé. Si $add_comp_ext est passé, il indique si l'extension par défaut de la méthode de compression doit être automatiquement ajoutée au nom de fichier (ou non).
$file = $fh->get_filename()
Retourne le nom de fichier qui serait utilisé lorsque le descripteur de fichier doit être ouvert (à la fois en mode lecture et en mode écriture). Cette fonction génère une erreur si "add_comp_ext" est activé alors que la méthode de compression est définie sur "auto". Le nom de fichier retourné inclut l'extension de la méthode de compression si "add_comp_ext" est activé.
$ret = $fh->use_compression()
Retourne "0" si aucune compression n'est utilisée, et la méthode de compression utilisée sinon. Si la compression est définie sur "auto", la valeur retournée dépend de l'extension du nom de fichier obtenu avec la méthode get_filename() .
$real_fh = $fh->get_filehandle()
Retourne le descripteur de fichier sous-jacent réel. Utile si vous souhaitez le transmettre dans une classe dérivée.

CLASSES DÉRIVÉES

Si vous souhaitez créer une classe qui hérite de Dpkg::Compression::FileHandle, vous devez savoir que l'objet est une référence à un GLOB retournée par Symbol::gensym() et en tant que tel, ce n'est pas un HASH.

Vous pouvez stocker des données internes dans un hash, mais vous devez utiliser "*$self-"{...}> pour accéder au hash associé comme dans l'exemple ci-dessous :

sub set_option {
    my ($self, $value) = @_;
    *$self->{option} = $value;
}
