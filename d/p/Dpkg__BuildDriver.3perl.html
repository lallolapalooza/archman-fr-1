NOM

Dpkg::BuildDriver - pilote la construction d'un paquet Debian

DESCRIPTION

Cette classe est utilisée par dpkg-buildpackage pour piloter la construction d'un paquet Debian.

Note : Ceci est un module privé, son API peut changer à tout moment.

MÉTHODES

$bd = Dpkg::BuildDriver->new(%opts)
Crée un nouvel objet Dpkg::BuildDriver. Il chargera un module de pilote de construction tel que demandé dans le champ Build-Drivers de l'objet Dpkg::Control::Info $opts{ctrl} ou, s'il n'est pas présent, il utilisera par défaut le pilote debian-rules.

Options :

ctrl (requis)
Un objet Dpkg::Control::Info.
root_cmd
Une chaîne de caractères avec la commande de gain de droits root à utiliser lorsque l'exécution d'une commande avec des droits de type root est nécessaire. Si elle est nécessaire et non définie, elle utilisera par défaut fakeroot si disponible ou le module échouera.
as_root
Un booléen pour forcer les appels de cible debian/rules comme si l'on avait des droits root, même s'ils ne nécessiteraient normalement pas d'être exécutés avec de tels droits. Cette option est appliquée globalement à toutes les cibles.

Note : Cette option n'est pertinente que pour les pilotes qui utilisent debian/rules.

debian_rules
Un tableau contenant la commande pour exécuter le fichier debian/rules et tout argument supplémentaire. Il vaut par défaut debian/rules.

Note : Cette option n'est pertinente que pour les pilotes qui utilisent debian/rules.

rrr_override
Une chaîne de caractères qui surcharge la valeur du champ Rules-Requires-Root.

Note : Cette option n'est pertinente que pour les pilotes qui utilisent debian/rules.

$bd->pre_check()
Effectue les vérifications spécifiques au pilote de construction, avant tout le reste.

Cela s'exécutera après le hook init, et avant "dpkg-source --before-build".

Note : Ceci est une méthode optionnelle qui peut être omise de l'implémentation du pilote.

$bool = $bd->need_build_task($build_task, binary_task)
Retourne si nous avons besoin d'utiliser la tâche de construction.

Note : Cette méthode est nécessaire tant que nous supportons la construction avec des droits de type root. Une fois que ce ne sera plus nécessaire, cette méthode sera dépréciée.

$bd->run_build_task($build_task, $binary_task)
Exécute la tâche de construction pour la construction.

Note : Ceci est une méthode optionnelle nécessaire tant que nous supportons la construction avec des droits de type root. Une fois que ce ne sera plus nécessaire, cette méthode sera dépréciée.

$bd->run_task($task)
Exécute la tâche donnée pour la construction.
