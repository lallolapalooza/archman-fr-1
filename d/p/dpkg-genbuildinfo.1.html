dpkg-genbuildinfo lit des informations à partir d'une arborescence de sources Debian décompressée et compilée ainsi qu'à partir des fichiers qu'elle a générés, et génère un fichier de contrôle Debian décrivant l'environnement de compilation et les artefacts de la compilation (fichier .buildinfo)

ENVIRONNEMEN

T
DEB_BUILD_OPTI
ONS
Cette variable peut être utilisée pour activer ou désactiver diverses fonctionnalités qui affectent les informations incluses dans le fichier .buildinfo, via l'option buildinfo (depuis dpkg 1.18.19). Cette option contient une liste de fonctionnalités séparées par des virgules, préfixées par les modificateurs« + » ou« - », pour indiquer s'il faut les activer ou les désactiver. La fonctionnalité spéciale« all » peut être utilisée pour activer ou désactiver toutes les autres fonctionnalités. La fonctionnalité« path » contrôle s'il faut inclure inconditionnellement le champ Build-Pat
h.
DEB_BUILD_AR
CH
Définit l'architecture de compilation. Cela affecte la valeur du champ Build-Architecture et la vérification du mode de compilation
croisée.
DEB_HOST_AR
CH
Définit l'architecture hôte. Cela affecte le nom de fichier utilisé pour le fichier .buildinfo et la vérification du mode de compilation
croisée.
DPKG_COLO
RS
Définit le mode de couleur (depuis dpkg 1.18.5). Les valeurs actuellement acceptées sont : auto (par défaut), always et neve
r.
DPKG_N
LS
Si défini, il sera utilisé pour décider s'il faut activer la prise en charge des langues natives, également connue sous le nom de prise en charge de l'internationalisation (ou i18n) (depuis dpkg 1.19.0). Les valeurs acceptées sont : 0 et 1 (par
dé
fau
t).
