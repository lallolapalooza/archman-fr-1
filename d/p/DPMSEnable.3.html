NOM

DPMSEnable - active le DPMS sur l'écran spécifié

SYNTAXE

cc [ flag ... ] file ... -lXext [ library ... ]
#include <X11/extensions/dpms.h>
Status DPMSEnable ( Display *display );

ARGUMENTS

display
Spécifie la connexion au serveur X

DESCRIPTION

La fonction DPMSEnable active le Display Power Management Signaling (DPMS) sur le display spécifié. Lorsque le DPMS est activé, le DPMS utilise les valeurs de délai d'attente actuellement sauvegardées. Il déclenchera le niveau de puissance DPMS approprié en fonction des valeurs de délai d'attente. Voir DPMSSetTimeouts. Tous les écrans physiques sont affectés par DPMSEnable en même temps.

Si DPMSEnable est appelé sur un display où le DPMS est déjà activé, ou sur un display qui ne prend pas en charge le DPMS, aucune modification n'est apportée et aucune erreur n'est retournée.

VALEURS DE RETOUR

TRUE
La fonction DPMSEnable retourne toujours TRUE.

VOIR AUSSI

DPMSCapable(3), DPMSDisable(3), DPMSGetTimeouts(3), DPMSSetTimeouts(3)
