NOM

Dpkg::Path - quelques fonctions communes de gestion de chemins

DESCRIPTION

Elle fournit quelques fonctions pour manipuler divers chemins.

FONCTIONS

get_pkg_root_dir($file)
Cette fonction parcourt la hiérarchie des répertoires vers le haut pour trouver le répertoire qui contient le sous-répertoire "DEBIAN" et elle renvoie son chemin. Ce répertoire est la racine d'un paquet en cours de construction.

Si aucun sous-répertoire DEBIAN n'est trouvé, elle renvoie undef.

relative_to_pkg_root($file)
Renvoie le nom de fichier relatif à get_pkg_root_dir($file).
guess_pkg_root_dir($file)
Cette fonction tente de deviner le répertoire racine de l'arbre de construction du paquet. Elle utilise d'abord get_pkg_root_dir(), mais elle se rabat sur une vérification moins précise : elle utilise le répertoire parent qui est un sous-répertoire du répertoire debian.

Elle peut toujours renvoyer undef si un fichier en dehors du sous-répertoire debian est fourni.

check_files_are_the_same($file1, $file2, $resolve_symlink)
Cette fonction vérifie que les deux fichiers sont identiques en s'assurant que les numéros de périphérique et les numéros d'inode retournés par stat()/lstat() sont identiques. Si $resolve_symlink est vrai, alors stat() est utilisé, sinon lstat() est utilisé.
canonpath($file)
Cette fonction renvoie un chemin nettoyé. Elle simplifie les doubles // et supprime les /./ et /../ intelligemment. Pour /../, elle simplifie le chemin uniquement si l'élément précédent n'est pas un lien symbolique. Elle ne doit donc être utilisée que sur des noms de fichiers réels.
$newpath = resolve_symlink($symlink)
Renvoie le nom du fichier pointé par le lien symbolique. Le nouveau nom est canonisée par canonpath().
check_directory_traversal($basedir, $dir)
Cette fonction vérifie que le répertoire $dir ne contient aucun lien symbolique qui irait au-delà de $basedir (qui devrait être égal ou un parent de $dir).
$cmdpath = find_command($command)
Renvoie le chemin de la commande si elle est définie et disponible sur un chemin absolu ou relatif ou dans le $PATH, undef sinon.
$control_file = get_control_path($pkg, $filetype)
Renvoie le chemin du fichier de contrôle de type $filetype pour le paquet donné.
@control_files = get_control_path($pkg)
Renvoie le chemin de tous les fichiers de contrôle disponibles pour le paquet donné.
$file = find_build_file($basename)
Sélectionne la bonne variante du fichier donné : la variante spécifique à l'architecture ("$basename.$arch") a la priorité sur la variante spécifique au système d'exploitation ("$basename.$os") qui a la priorité sur la variante par défaut ("$basename"). Si aucun des fichiers n'existe, alors elle renvoie undef.
@files = find_build_file($basename)
Renvoie les variantes disponibles du fichier donné. Renvoie une liste vide si aucun des fichiers n'existe.
