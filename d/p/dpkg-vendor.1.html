NOM

dpkg-vendor - interroge des informations sur les fournisseurs de distribution

SYNTAXE

dpkg-vendor [option...] commande

DESCRIPTION

dpkg-vendor est un outil pour interroger des informations sur les fournisseurs listés dans /etc/dpkg/origins. /etc/dpkg/origins/default contient des informations sur le fournisseur actuel.

Les fichiers d'origine fournissent des métadonnées sur des fournisseurs spécifiques, tels que leur URL ou où signaler des bogues, et sont généralement utilisés à la fois pour déterminer le comportement des outils et le contenu résultant lors de la création de paquets ciblant un fournisseur spécifique, et pour décrire la provenance des paquets.

Les paquets peuvent explicitement déclarer leur fournisseur en incluant un champ Origin ; sinon, le fournisseur d'un paquet sans tel champ est supposé être celui pointé par le lien symbolique default.

Le lien symbolique default est également utilisé pour désigner l'origine de l'installation actuelle gérée par dpkg, qu'il s'agisse d'une distribution complète ou d'une superposition sur un système de base existant qui ne contient aucun système de gestion de paquets ou en possède un natif.

Ce programme a été introduit dans dpkg 1.15.1.

COMMANDES

--is fournisseur
Se termine avec un code de sortie 0 si le fournisseur actuel est fournisseur. Sinon, se termine avec un code de sortie 1.
--derives-from fournisseur
Se termine avec un code de sortie 0 si la distribution du fournisseur actuel est un dérivé de fournisseur, sinon se termine avec un code de sortie 1. Elle utilise le champ Parent pour parcourir tous les ancêtres du fournisseur actuel.
--query champ
Affiche sur la sortie standard la valeur du champ spécifique au fournisseur pour le fournisseur actuel.
--help
Affiche le message d'utilisation et quitte.
--version
Affiche la version et quitte.

OPTIONS

--vendor fournisseur
Suppose que le fournisseur actuel est fournisseur au lieu de le découvrir via la variable d'environnement DEB_VENDOR ou /etc/dpkg/origins/default.

ENVIRONNEMENT

DEB_VENDOR
Ce paramètre définit le fournisseur actuel. S'il n'est pas défini, il découvrira le fournisseur actuel en lisant /etc/dpkg/origins/default.
DPKG_COLORS
Définit le mode couleur (depuis dpkg 1.18.5). Les valeurs actuellement acceptées sont : auto (par défaut), always et never.
DPKG_NLS
Si défini, il sera utilisé pour décider si l'on active le support des langues natives, également connu sous le nom d'internationalisation (ou i18n) (depuis dpkg 1.19.0). Les valeurs acceptées sont : 0 et 1 (par défaut).

FICHIERS

Support de packaging

/usr/share/dpkg/vendor.mk
Extrait de Makefile qui définit le fournisseur actuel et son parent dans des variables, et fournit des macros make pour vérifier les dérivés (depuis dpkg 1.16.1).
