Documentation de la fonction/sous-programme

sous-routine dptt05 (entier n, entier nrhs, double précision, dimension( * ) d, double précision, dimension( * ) e, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( ldx, * ) x, entier ldx, double précision, dimension( ldxact, * ) xact, entier ldxact, double précision, dimension( * ) ferr, double précision, dimension( * ) berr, double précision, dimension( * ) reslts)

DPTT05

Objectif:

!>
!> DPTT05 teste les bornes d'erreur de l'affinage itératif pour la
!> solution calculée d'un système d'équations A*X = B, où A est une
!> matrice symétrique tridiagonale d'ordre n.
!>
!> RESLTS(1) = test de la borne d'erreur
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Une valeur élevée est retournée si ce rapport n'est pas inférieur à un.
!>
!> RESLTS(2) = résidu de la routine d'affinage itératif
!>           = le maximum de BERR / ( NZ*EPS + (*) ), où
!>             (*) = NZ*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>             et NZ = nombre maximum de non-zéros dans une ligne de A, plus 1
!>

Paramètres

N 
!>          N est ENTIER
!>          Le nombre de lignes des matrices X, B, et XACT, et l'ordre
!>          de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de colonnes des matrices X, B, et XACT.
!>          NRHS >= 0.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau DOUBLE PRÉCISION, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice tridiagonale A.
!>

B

!>          B est un tableau DOUBLE PRÉCISION, dimension (LDB,NRHS)
!>          Les vecteurs du côté droit pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau DOUBLE PRÉCISION, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés. Chaque vecteur est stocké comme
!>          une colonne de la matrice X.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

XACT

!>          XACT est un tableau DOUBLE PRÉCISION, dimension (LDX,NRHS)
!>          Les vecteurs solution exacts. Chaque vecteur est stocké comme
!>          une colonne de la matrice XACT.
!>

LDXACT

!>          LDXACT est ENTIER
!>          La dimension principale du tableau XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR est un tableau DOUBLE PRÉCISION, dimension (NRHS)
!>          Les bornes d'erreur avant estimées pour chaque vecteur solution
!>          X.  Si XTRUE est la vraie solution, FERR borne la magnitude
!>          de la plus grande entrée dans (X - XTRUE) divisée par la magnitude
!>          de la plus grande entrée dans X.
!>

BERR

!>          BERR est un tableau DOUBLE PRÉCISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque
!>          vecteur solution (c'est-à-dire, le plus petit changement relatif
!>          dans n'importe quelle entrée de A ou B qui rend X une solution
!>          exacte).
!>

RESLTS

!>          RESLTS est un tableau DOUBLE PRÉCISION, dimension (2)
!>          Le maximum sur les vecteurs solution NRHS des rapports :
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
