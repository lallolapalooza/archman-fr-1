NOM

Dpkg::Vendor::Ubuntu - Classe de fournisseur Ubuntu

DESCRIPTION

Cette classe de fournisseur personnalise le comportement des scripts dpkg pour le comportement et les politiques spécifiques à Ubuntu.

Note: Il s'agit d'un module privé, son API peut changer à tout moment.

FONCTIONS PUBLIQUES

$bugs = Dpkg::Vendor::Ubuntu::find_launchpad_closes($changes)
Prend une chaîne de caractères comme argument et recherche les mentions "LP: #123456, #654321", qui sont des références à des bogues sur Launchpad. Retourne tous les numéros de bogues fermés sous forme de référence de tableau.
