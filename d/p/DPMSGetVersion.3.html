DPMSGetVersion(3) FONCTIONS X DPMSGetVersion(3)

NOM

DPMSGetVersion - retourne la version de l'extension DPMS implémentée par le serveur X

SYNTAXE

cc [ flag ... ] fichier ... -lXext [ bibliothèque ... ]
#include <X11/extensions/dpms.h>
Status DPMSGetVersion
(
      Display *display,
      int *major_version,
      int *minor_version
);

ARGUMENTS

display
Spécifie la connexion au serveur X
major_version
Spécifie l'emplacement de retour pour la version majeure de l'extension
minor_version
Spécifie l'emplacement de retour pour la version mineure de l'extension

DESCRIPTION

La fonction DPMSGetVersion retourne la version de l'extension Display Power Management Signaling (DPMS) implémentée par le serveur X. Elle retourne un numéro de version majeure et mineure. Le numéro de version majeure sera incrémenté pour les changements incompatibles de protocole, et le numéro de version mineure sera incrémenté pour les changements mineurs et ascendants compatibles.

VALEURS DE RETOUR

TRUE
La fonction DPMSGetVersion retourne TRUE lorsque l'extension est supportée et que les valeurs sont retournées.
FALSE
La fonction DPMSGetVersion retourne FALSE lorsque l'extension n'est pas supportée.

VOIR AUSSI

DPMSCapable(3), DPMSQueryExtension(3)
