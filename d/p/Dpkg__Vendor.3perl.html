NOM

Dpkg::Vendor - obtenir l'accès à certaines informations spécifiques au vendeur

DESCRIPTION

Les fichiers dans $Dpkg::CONFDIR/origins/ peuvent fournir des informations sur divers vendeurs qui fournissent des paquets Debian. Actuellement, ces fichiers ressemblent à ceci :

Vendor: Debian
Vendor-URL: https://www.debian.org/
Bugs: debbugs://bugs.debian.org

Si le vendeur dérive d'un autre vendeur, le fichier doit documenter la relation en listant la distribution de base dans le champ Parent :

Parent: Debian

Le fichier doit être nommé selon le nom du vendeur. La convention habituelle est de nommer le fichier du vendeur en utilisant le nom du vendeur en minuscules, mais une certaine variation est permise. Notamment, les espaces sont remplacés par des tirets ('-'), et le fichier peut avoir la même casse que le champ Vendor, ou être capitalisé.

FONCTIONS

$dir = get_vendor_dir()
Retourne le nom du répertoire d'origines dpkg actuel, où sont stockés les fichiers du vendeur.
$fields = get_vendor_info([$name])
Retourne un objet Dpkg::Control avec les informations analysées à partir du fichier du vendeur correspondant dans $Dpkg::CONFDIR/origins/. Si $name est omis, il utilisera $Dpkg::CONFDIR/origins/default qui est censé être un lien symbolique vers le vendeur du système d'exploitation actuellement installé. Retourne undef s'il n'y a pas de fichier pour le vendeur donné.
$name = get_vendor_file([$name])
Vérifie s'il existe un fichier pour le vendeur donné et retourne son nom.

Le nom du fichier du vendeur sera dérivé du nom du vendeur, en remplaçant tout nombre de caractères non alphanumériques (c'est-à-dire [^A-Za-z0-9]) par "-", puis le nom résultant sera essayé en séquence en le mettant en minuscules, en le laissant tel quel, en le mettant en minuscules puis en le capitalisant, et en le capitalisant.

$name = get_current_vendor()
Retourne le nom du vendeur actuel. Si DEB_VENDOR est défini, il l'utilise d'abord, sinon il se rabat sur l'analyse de $Dpkg::CONFDIR/origins/default. Si ce fichier n'existe pas, il retourne undef.
$object = get_vendor_object($name)
Retourne l'objet Dpkg::Vendor::* du vendeur correspondant. Si $name est omis, retourne l'objet du vendeur actuel. Si aucun vendeur ne peut être identifié, alors retourne l'objet Dpkg::Vendor::Default.

Le nom du module sera dérivé du nom du vendeur, en divisant les parties autour des séparateurs de groupes de caractères non alphanumériques (c'est-à-dire [^A-Za-z0-9]), en capitalisant ou en mettant en minuscules et en capitalisant chaque partie, puis en les joignant sans les séparateurs. La casse attendue est donc basée sur celle du champ Vendor dans le fichier origins.

run_vendor_hook($hookid, @params)
Exécute un hook implémenté par l'objet vendeur actuel.

CHANGEMENTS

Version 1.03 (dpkg 1.22.12)

Comportement obsolète : get_vendor_file() et get_vendor_object() ne prennent plus en charge le comportement déprécié de 1.02.

Version 1.02 (dpkg 1.21.10)

Comportement déprécié : get_vendor_file() charge les fichiers du vendeur sans remappage de caractères spéciaux. get_vendor_object() charge les noms de modules du vendeur sans suppression de caractères spéciaux.

Version 1.01 (dpkg 1.17.0)

Nouvelle fonction : get_vendor_dir().

Version 1.00 (dpkg 1.16.1)

Marque le module comme public.
