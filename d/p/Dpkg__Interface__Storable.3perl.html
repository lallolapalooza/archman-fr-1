NOM

Dpkg::Interface::Storable - méthodes communes liées à la sérialisation d'objets

DESCRIPTION

Dpkg::Interface::Storable est uniquement destiné à être utilisé comme classe parente pour d'autres classes. Il fournit des méthodes communes qui sont toutes implémentées sur deux méthodes de base : parse() et output().

MÉTHODES DE BASE

Ces méthodes doivent être fournies par la classe qui souhaite hériter de Dpkg::Interface::Storable afin que les méthodes fournies puissent fonctionner.

$obj->parse($fh[, $desc])
Cette méthode initialise l'objet avec les données stockées dans le fichier. $desc est optionnel et est une description textuelle du fichier utilisée dans les messages d'erreur.
$string = $obj->output([$fh])
Cette méthode retourne une représentation sous forme de chaîne de caractères de l'objet dans $string et écrit la même chaîne dans $fh (s'il est défini).

MÉTHODES FOURNIES

$obj->load($nom_fichier, %opts)
Initialise l'objet avec les données stockées dans le fichier. Le fichier peut être compressé, il sera décompressé à la volée en utilisant un objet Dpkg::Compression::FileHandle. Si $opts{compression} est faux, le support de la décompression sera désactivé. Si $nom_fichier est "-", alors l'entrée standard est lue (aucune compression n'est autorisée dans ce cas).
$obj->save($nom_fichier, %opts)
Stocke l'objet dans le fichier. Si le nom du fichier se termine par une extension de compression connue, il sera compressé à la volée en utilisant un objet Dpkg::Compression::FileHandle. Si $opts{compression} est faux, le support de la compression sera désactivé. Si $nom_fichier est "-", alors la sortie standard est utilisée (les données sont écrites sans compression dans ce cas).
"$obj"
Retourne une représentation sous forme de chaîne de caractères de l'objet.

CHANGEMENTS

Version 1.01 (dpkg 1.19.0)

Nouvelles options : Les méthodes $obj->load() et $obj->save() prennent en charge une nouvelle option de compression.

Version 1.00 (dpkg 1.15.6)

Marque le module comme public.
