NOM

Dpkg::Control::FieldsCore - gère la liste des champs de contrôle officiels

DESCRIPTION

Le module contient une liste de noms de champs avec des méta-données associées expliquant dans quel type d'informations de contrôle ils sont autorisés. Les types sont les constantes CTRL_* exportées par Dpkg::Control.

FONCTIONS

$f = field_capitalize($field_name)
Retourne le nom du champ correctement capitalisé. Tous les caractères sont en minuscule, sauf le premier de chaque mot (les mots sont séparés par un tiret dans les noms de champs).
$bool = field_is_official($fname)
Retourne vrai si le champ est officiel et connu.
$bool = field_is_allowed_in($fname, @types)
Retourne vrai (1) si le champ $fname est autorisé dans tous les types listés. Notez que vous pouvez utiliser des ensembles de types au lieu de types individuels (ex: CTRL_FILE_CHANGES | CTRL_CHANGELOG).

field_allowed_in(A|B, C) retourne vrai uniquement si le champ est autorisé dans C et soit dans A soit dans B.

Un indéfini est retourné pour les champs non officiels.

$new_field = field_transfer_single($from, $to, $field)
Si approprié, copie la valeur du champ nommé $field provenant de l'objet Dpkg::Control $from vers l'objet Dpkg::Control $to.

Les champs officiels ne sont copiés que si le champ est autorisé dans les deux types d'objets. Les champs personnalisés sont traités d'une manière spécifique. Lorsque la cible n'est pas parmi CTRL_DSC, CTRL_DEB ou CTRL_FILE_CHANGES, ils sont toujours copiés tels quels (le préfixe X- est conservé). Sinon, ils ne sont pas copiés sauf si l'objet cible correspond à la destination cible encodée dans le nom du champ. Le X initial dénotant les champs personnalisés peut être suivi d'une ou plusieurs lettres parmi « S » (Source : correspond à CTRL_DSC), « B » (Binary : correspond à CTRL_DEB) ou « C » (Changes : correspond à CTRL_FILE_CHANGES).

Retourne indéfini si rien n'a été copié ou le nom du nouveau champ ajouté à $to sinon.

@field_list = field_transfer_all($from, $to)
Transfère tous les champs appropriés de $from vers $to. Appelle field_transfer_single() sur tous les champs disponibles dans $from.

Retourne la liste des champs qui ont été ajoutés à $to.

@field_list = field_ordered_list($type)
Retourne une liste ordonnée de champs pour un type d'information de contrôle donné. Cette liste peut être utilisée pour afficher les champs dans un ordre prévisible. La liste peut être vide pour les types où l'ordre n'a pas beaucoup d'importance.
($source, $version) = field_parse_binary_source($ctrl)
Analyse le champ Source dans une section de contrôle de paquet binaire. Le champ contient le nom du paquet source à partir duquel il a été construit, et éventuellement un espace et la version source entre parenthèses si elle est différente de la version binaire.

Retourne une liste avec le nom $source et la $version source, ou indéfini ou une liste vide lorsque $ctrl ne contient pas de section de contrôle de paquet binaire. Ni $source ni $version ne sont validés, mais cela peut être fait avec Dpkg::Package::pkg_name_is_illegal() et Dpkg::Version::version_check().

@field_list = field_list_src_dep()
Liste des champs contenant des informations de type dépendances dans un paquet source Debian.
@field_list = field_list_pkg_dep()
Liste des champs contenant des informations de type dépendances dans un paquet binaire Debian. Les champs qui expriment de réelles dépendances sont triés du plus fort au plus faible.
$dep_type = field_get_dep_type($field)
Retourne le type de la dépendance exprimée par le champ donné. Peut être « normal » pour un champ de dépendance réel (Pre-Depends, Depends, ...) ou « union » pour d'autres champs de relation partageant la même syntaxe (Conflicts, Breaks, ...). Retourne indéfini pour les champs qui ne sont pas des dépendances.
$sep_type = field_get_sep_type($field)
Retourne le type du séparateur de valeur de champ. Peut être l'un de FIELD_SEP_UNKNOWN, FIELD_SEP_SPACE, FIELD_SEP_COMMA ou FIELD_SEP_LINE.
$value = field_get_default_value($field)
Retourne la valeur par défaut (le cas échéant) pour le champ. S'il n'y a pas de valeur par défaut, il retourne « undef ».
field_register($field, $allowed_types, %opts)
Enregistre un nouveau champ comme étant autorisé dans les informations de contrôle des types spécifiés. %opts est facultatif.
$bool = field_insert_after($type, $ref, @fields)
Place le champ après un autre ($ref) dans la sortie des informations de contrôle du type $type.

Retourne vrai si le champ a été inséré, sinon faux.

$bool = field_insert_before($type, $ref, @fields)
Place le champ avant un autre ($ref) dans la sortie des informations de contrôle du type $type.

Retourne vrai si le champ a été inséré, sinon faux.
