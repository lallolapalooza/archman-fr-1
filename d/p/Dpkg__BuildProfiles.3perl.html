NOM

Dpkg::BuildProfiles - gérer les profils de construction

DESCRIPTION

Le module Dpkg::BuildProfiles fournit des fonctions pour gérer les profils de construction.

FONCTIONS

@profils = get_build_profiles()
Obtenir un tableau avec les profils de construction actifs actuellement, provenant de la variable d'environnement DEB_BUILD_PROFILES.
set_build_profiles(@profils)
Définir @profils comme les profils de construction actifs actuels, en définissant la variable d'environnement DEB_BUILD_PROFILES.
@profils = parse_build_profiles($chaine)
Analyse une spécification de profils de construction, en un tableau de références de tableaux.
evaluate_restriction_formula(\@formule, \@profils)
Évaluer si une formule de restriction de la forme "<foo bar> <baz>", donnée sous forme de tableau imbriqué, est vraie ou fausse, étant donné le tableau des profils de construction activés.
