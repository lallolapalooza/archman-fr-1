COMMANDE

S
-l, --list [motif-de-nom-de-p
aquet...]
Liste tous les paquets connus correspondant à un ou plusieurs motifs, quel que soit leur statut, ce qui inclut tout paquet réel ou virtuel référencé dans n'importe quel champ de relation de dépendance (tel que Breaks, Enhances, etc.). Si aucun motif-de-nom-de-paquet n'est donné, liste tous les paquets dans /var/lib/dpkg/status, à l'exclusion de ceux marqués comme non-installés (c'est-à-dire ceux qui ont été précédemment purgés). Les caractères génériques de shell normaux sont autorisés dans le motif-de-nom-de-paquet. Veuillez noter que vous devrez probablement mettre le motif-de-nom-de-paquet entre guillemets pour empêcher le shell d'effectuer l'expansion des noms de fichiers. Par exemple, cela listera tous les noms de paquets commençant par « libc6 »
: 
dpkg-qu
ery -l '
libc6*'

Le format de sortie de cette option n'est pas configurable, mais varie automatiquement pour s'adapter à la largeur du terminal. Il est destiné à la lecture par un humain et n'est pas facilement lisible par une machine. Voir -W (--show) et --showformat pour une manière de

-W, --show [motif-de-nom-de-p
aquet...]
Tout comme l'option --list, cela listera tous les paquets correspondant aux motifs donnés. Cependant, la sortie peut être personnalisée à l'aide de l'option --showformat.

Le format de sortie par défaut donne une ligne par paquet correspondant, chaque ligne se composant du nom du paquet et de sa version installée, séparés par une tabulation. Le nom du paquet sera qualifié par l'architecture pour les paquets avec un champ Multi-Arch ayant la valeur same ou avec une architecture étrangère, qui est une architecture qui n'est ni l'architecture native ni al

l
.
-s, --status [nom-de-paqu
et...]
Rapporte le statut des paquets spécifiés. Cela affiche simplement l'entrée dans la base de données de statut des paquets installés. Si aucun nom-de-paquet n'est spécifié, il affichera toutes les entrées de paquets dans la base de données de statut (depuis dpkg 1.19.1). Lorsque plusieurs noms-de-paquets sont listés, les entrées de statut demandées sont séparées par une ligne vide, dans le même ordre que spécifié dans la liste
d'arguments.
-L, --listfiles nom-de-paqu
et...
Liste les fichiers installés sur votre système à partir du nom-de-paquet. Lorsque plusieurs noms-de-paquets sont listés, les listes de fichiers demandées sont séparées par une ligne vide, dans le même ordre que spécifié dans la liste d'arguments.

Chaque diversion de fichier est imprimée sur sa propre ligne après son fichier détourné, précédée de l'une des chaînes localisées

suivantes :


détourné localement vers : détourné-vers
le paquet détourne les autres vers : détourné-vers
détourné par paquet vers : détourné-

vers

Astuce : Lors de l'analyse de la sortie par une machine, il est d'usage de définir la locale sur C.UTF-8 pour obtenir des résultats reproductibles. Sur certains systèmes, cela peut également nécessiter d'adapter la variable d'environnement LANGUAGE de manière appropriée si elle est déjà définie (voir locale(

7)).

Cette commande ne listera pas les fichiers su

pplémentaires créés par les scripts de mainten

--control-list nom-de-paq

show.
--control-show nom-de-paquet fichier-de-cont
rôle
Affiche le fichier-de-contrôle installé sur votre système à partir du nom-de-paquet sur la sortie standard (depuis dpkg 1.16.
5).
-c, --control-path nom-de-paquet [fichier-de-contr
ôle]
Liste les chemins des fichiers de contrôle installés sur votre système à partir du nom-de-paquet (depuis dpkg 1.15.4). Si un fichier-de-contrôle est spécifié, ne liste que le chemin de ce fichier de contrôle s'il est présent.

Avertissement : Cette commande est obsolète car elle donne un accès direct à la base de données interne de dpkg, veuillez plutôt utiliser --control-list et --control-show pour tous les cas où ces commandes pourraient donner le même résultat final. Cependant, tant qu'il existe au moins un cas où cette commande est nécessaire (c'

est-à-dire lorsqu'il faut retirer un script de maintenance postrm nuisible), et tant
qu'il n'y a pas de bonne solution pour cela, cette commande ne sera pas supprimée.
-S, --search motif-de-recherche-de
-fichier...
Recherche les paquets qui possèdent des fichiers correspondant aux motifs donnés. Les caractères génériques de shell standard peuvent être utilisés dans le motif, où l'astérisque (*) et le point d'interrogation (?) correspondront à une barre oblique, et la barre oblique inverse (\) sera utilisée comme caractère d'échappement.

Si le premier caractère du motif-de-recherche-de-fichier n'est ni «*[?/ », il sera considéré comme une correspondance de sous-chaîne et sera implicitement entouré par «* » (comme dans *motif-de-recherche-de-fichier*). Si la chaîne suivante contient l'un des caractères «*[? \ », elle sera traitée comme un motif glob, sinon tout «/ » final ou «/. » sera supprimé et une recherche littérale de chemin sera

effectuée.

Cette commande ne listera pas les fichiers supplémentaires créés par les scripts de maintenance, ni ne listera les

alternatives.

Le format de sortie consiste en une ligne par motif correspondant, avec une liste des paquets possédant le chemin d'accès séparés par une virgule (U+002C «, ») et une espace (U+0020 « »), suivie d'un deux-points (U+003A «: ») et d'une espace, suivie du chemin d'accès.

Comme ceci : 
nom-paquet1, nom-paquet2 : chemin1
nom-paquet3 :
chemin2

Les diversions de fichiers sont imprimées avec les chaînes localisées

suivantes :


diversion par nom-paquet depuis : détourné-de
diversion par nom-paquet vers : détourné-

vers

ou pour les diversions

locales :


diversion locale depuis : détourné-de
diversion locale vers : détourné-

vers

Indice : Lors de l'analyse par machine de la sortie, il est d'usage de définir la locale sur C.UTF-8 pour obtenir des résultats reproductibles.

-p, --print-avail [nom-paquet...]
Affiche les détails des paquets, tels qu'ils se trouvent dans /var/lib/dpkg/available. Si aucun nom-paquet n'est spécifié, il affichera toutes les entrées de paquets dans la base de données available (depuis dpkg 1.19.1). Lorsque plusieurs nom-paquet sont listés, les entrées available demandées sont séparées par une ligne vide, dans le même ordre qu'elles ont été spécifiées dans la liste des arguments.

Les utilisateurs des interfaces basées sur APT devraient plutôt utiliser apt show nom-paquet car le fichier available n'est tenu à jour que lorsque dselect est utilisé.

-?, --help
Affiche le message d'utilisation et quitte.
--version
Affiche la version et quitte.

OPTIONS

--admindir=rep
Change l'emplacement de la base de données dpkg. L'emplacement par défaut est /var/lib/dpkg.
--root=répertoire
Définit le répertoire racine à répertoire, ce qui définit le répertoire administratif à «répertoire/var/lib/dpkg» (depuis dpkg 1.21.0).
--load-avail
Charge également le fichier available lors de l'utilisation des commandes --show et --list, qui interrogent maintenant par défaut uniquement le fichier de statut (depuis dpkg 1.16.2).
--no-pager
Désactive l'utilisation de tout paginateur lors de l'affichage des informations (depuis dpkg 1.19.2).
-f, --showformat=format
Cette option est utilisée pour spécifier le format de la sortie que produira --show (option courte depuis dpkg 1.13.1). Le format est une chaîne qui sera affichée pour chaque paquet listé.

Dans la chaîne de format, “\” introduit des séquences d'échappement :

\n nouvelle ligne
\r retour chariot
\t tabulation

“\” avant tout autre caractère supprime la signification spéciale du caractère suivant, ce qui est utile pour “\” et “$”.

Les informations sur les paquets peuvent être incluses en insérant des références de variables aux champs des paquets en utilisant la syntaxe “${champ[;largeur]}”. Les champs sont affichés alignés à droite sauf si la largeur est négative, auquel cas l'alignement à gauche sera utilisé. Les champs suivants sont reconnus mais ne sont pas nécessairement disponibles dans le fichier de statut (seuls les champs internes ou les champs stockés dans le paquet binaire s'y retrouvent) :

Les champs virtuels suivants sont générés par dpkg-query à partir des valeurs d'autres champs (notez qu'ils n'utilisent pas de noms de champs valides pour les fichiers de contrôle) :

binary:Package
Il contient le nom du paquet binaire avec un qualificateur d'architecture possible comme “libc6:amd64” (depuis dpkg 1.16.2). Un qualificateur d'architecture sera présent pour rendre le nom du paquet sans ambiguïté, pour les paquets ayant un champ Multi-Arch avec la valeur same ou avec une architecture étrangère, qui est une architecture qui n'est ni l'architecture native ni all.
binary:Synopsis
Il contient la description courte du paquet (depuis dpkg 1.19.1).
binary:Summary
Ceci est un alias pour binary:Synopsis (depuis dpkg 1.16.2).
db:Status-Abbrev
Il contient le statut abrégé du paquet (en trois caractères), tel que “ii ” ou “iHR” (depuis dpkg 1.16.2). Voir la description de la commande --list pour plus de détails.
db:Status-Want
Il contient le statut souhaité du paquet, partie du champ Status (depuis dpkg 1.17.11).
db:Status-Status
Il contient le mot de statut du paquet, partie du champ Status (depuis dpkg 1.17.11).
db:Status-Eflag
Il contient le drapeau d'erreur de statut du paquet, partie du champ Status (depuis dpkg 1.17.11).
db-fsys:Files
Il contient la liste des entrées du système de fichiers du paquet séparées par des nouvelles lignes (depuis dpkg 1.19.3).
db-fsys:Last-Modified
Il contient l'horodatage en secondes de la dernière modification des entrées du système de fichiers du paquet (depuis dpkg 1.19.3).
source:Package
Il contient le nom du paquet source pour ce paquet binaire (depuis dpkg 1.16.2).
source:Version
Il contient la version du paquet source pour ce paquet binaire (depuis dpkg 1.16.2).
source:Upstream-Version
Il contient la version amont du paquet source pour ce paquet binaire (depuis dpkg 1.18.16).

La chaîne de format par défaut est “${binary:Package}\t${Version}\n”. En fait, tous les autres champs trouvés dans le fichier de statut (c'est-à-dire les champs définis par l'utilisateur) peuvent également être demandés. Ils seront affichés tels quels, sans conversion ni vérification d'erreur.

Pour obtenir le nom du mainteneur de dpkg et la version installée, vous pouvez exécuter :

dpkg-query -f='${binary:Package} ${Version}\t${Maintainer}\n' \
 -W dpkg

STATUT DE SORTIE

0
La requête demandée a été effectuée avec succès.
1
La requête demandée a échoué entièrement ou partiellement, en raison de l'absence de fichier ou de paquet (sauf pour --control-path, --control-list et --control-show où de telles erreurs sont fatales).
2
Erreur fatale ou irrécupérable due à une utilisation invalide de la ligne de commande, ou à des interactions avec le système, telles que l'accès à la base de données, les allocations mémoire, etc.

ENVIRONNEMENT

Environnement externe

SHELL
Définit le programme à exécuter lors du lancement d'une commande via un shell (depuis dpkg 1.19.2).
PAGER
DPKG_PAGER
Définit la commande de pagination à utiliser (depuis dpkg 1.19.1), qui sera exécutée avec « $SHELL -c ». Si SHELL n'est pas défini, « sh » sera utilisé à la place.

DPKG_PAGER remplace la variable d'environnement PAGER (depuis dpkg 1.19.2). Si aucun des programmes désignés par DPKG_PAGER ou PAGER n'est présent, les programmes suivants seront essayés dans l'ordre (depuis dpkg 1.22.12) : le programme de pagination par défaut more, puis less, more, et enfin cat.

DPKG_ROOT
Si elle est définie et que l'option --root n'a pas été spécifiée, elle sera utilisée comme répertoire racine du système de fichiers (depuis dpkg 1.21.0).
DPKG_ADMINDIR
Si elle est définie et que l'option --admindir n'a pas été spécifiée, elle sera utilisée comme répertoire de données de dpkg.
DPKG_DEBUG
Définit le masque de débogage (depuis dpkg 1.21.10) à partir d'une valeur octale. Les indicateurs actuellement acceptés sont décrits dans l'option dpkg --debug, mais tous ces indicateurs peuvent ne pas avoir d'effet sur ce programme.
DPKG_COLORS
Définit le mode couleur (depuis dpkg 1.18.5). Les valeurs actuellement acceptées sont : auto (par défaut), always et never.
DPKG_NLS
Si elle est définie, elle sera utilisée pour décider si l'on active le support de la langue nationale, également connu sous le nom d'internationalisation (ou i18n) (depuis dpkg 1.22.7). Les valeurs acceptées sont : 0 et 1 (par défaut).

Environnement interne

LESS
Défini par dpkg-query à « -FRSXMQ », s'il n'est pas déjà défini, lors du lancement d'un programme de pagination (depuis dpkg 1.19.2). Pour modifier le comportement par défaut, cette variable peut être pré-définie à une autre valeur, y compris une chaîne vide, ou les variables PAGER ou DPKG_PAGER peuvent être définies pour désactiver des options spécifiques avec « -+ », par exemple DPKG_PAGER="less -+F".

SECURITE

Les opérations de requête ne devraient jamais nécessiter les privilèges de root, et déléguer leur exécution à des utilisateurs non privilégiés via une commande de gain-de-privilèges peut avoir des implications de sécurité (telles qu'une escalade de privilèges), par exemple lorsqu'un programme de pagination est automatiquement invoqué par l'outil.
