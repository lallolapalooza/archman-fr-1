NOM

Dpkg::Source::Format - manipuler les fichiers debian/source/format

DESCRIPTION

Ce module fournit une classe capable de manipuler les fichiers debian/source/format des paquets sources Debian.

MÉTHODES

$f = Dpkg::Source::Format->new(%opts)
Crée un nouvel objet correspondant au fichier debian/source/format d'un paquet source.

Options :

filename
Définit le nom du fichier à utiliser pour analyser et définir le format.
format
Définit et valide le format à utiliser au lieu de charger le fichier par défaut, si aucun nom de fichier n'a été spécifié.
$f->set_from_parts($major[, $minor[, $variant]])
Définit le format source à partir de ses parties. La partie $major est obligatoire. Les parties $minor et $variant sont optionnelles.

Remarque : Cette fonction n'effectue aucune validation.

($major, $minor, $variant) = $f->set($format)
Définit (et valide) le $format source spécifié. Retournera les parties du format analysées sous forme de liste, les parties optionnelles $minor et $variant peuvent être indéfinies.
($major, $minor, $variant) = $f->get()
$format = $f->get()
Récupère le format source, soit sous forme de scalaire correctement formaté, soit sous forme de liste de ses parties, où les parties optionnelles $minor et $variant peuvent être indéfinies.
$count = $f->parse($fh, $desc)
Analyse la chaîne de format source à partir de $fh, avec la description du descripteur de fichier $desc.
$count = $f->load($filename)
Analyse le contenu de $filename pour obtenir une chaîne de format de paquet source.
$str = $f->output([$fh])
"$f"
Retourne une chaîne représentant la version du format du paquet source. Si $fh est défini, imprime la chaîne sur le descripteur de fichier.
$f->save($filename)
Sauvegarde le format du paquet source dans le $filename donné.
