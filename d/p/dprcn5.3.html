SYNOPIS

Cette page de manuel documente la sous-routine dprcn5 dans LAPACK.

Elle est utilisée comme partie de la suite de tests pour les routines de BLAS de niveau 3, spécifiquement pour les opérations impliquant des matrices générales et triangulaires.

subroutine dprcn5 (integer nout, integer nc, character*13 sname, integer iorder, character*1 uplo, character*1 transa, integer n, integer k, double precision alpha, integer lda, integer ldb, double precision beta, integer ldc)

Définition à la ligne 2066 du fichier c_dblat3.f.

Cette sous-routine vérifie les routines de BLAS de niveau 3 impliquant des multiplications de matrices mixtes, notamment celles qui impliquent des matrices triangulaires.

  • nout : Entier, unité de sortie pour les messages d'erreur.
  • nc : Entier, nombre de cas de test.
  • sname : Caractère*13, nom de la sous-routine testée.
  • iorder : Entier, ordre des paramètres.
  • uplo : Caractère*1, spécifie si la matrice triangulaire est supérieure ('U') ou inférieure ('L').
  • transa : Caractère*1, spécifie la forme de la première matrice (par exemple, 'N' pour non transposée, 'T' pour transposée).
  • n : Entier, dimension de la matrice carrée.
  • k : Entier, dimension de la matrice.
  • alpha : Double précision, scalaire pour la première multiplication.
  • lda : Entier, largeur de référence de la première matrice.
  • ldb : Entier, largeur de référence de la seconde matrice.
  • beta : Double précision, scalaire pour la seconde multiplication.
  • ldc : Entier, largeur de référence de la matrice résultante.

Elle est appelée par les routines de test générales pour effectuer des tests numériques sur les routines de BLAS de niveau 3, en comparant les résultats obtenus avec les valeurs attendues.
