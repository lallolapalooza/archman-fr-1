NOM

Dpkg::BuildTree - gérer les actions de l'arbre de construction

DESCRIPTION

Le module Dpkg::BuildTree fournit des fonctions pour gérer les actions de l'arbre de construction.

Note : Ceci est un module privé, son API peut changer à tout moment.

MÉTHODES

$bt = Dpkg::BuildTree->new(%opts)
Crée un nouvel objet Dpkg::BuildTree.

Options :

dir
Le répertoire de l'arbre de construction. S'il n'est pas spécifié, il suppose le répertoire de travail actuel.
$bt->clean()
Nettoie l'arbre de construction, en supprimant tous les artefacts générés par dpkg.
$bt->needs_root()
Vérifie si l'arbre de construction nécessite root pour être construit.
