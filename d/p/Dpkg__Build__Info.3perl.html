NOM

Dpkg::Build::Info - gérer les informations de compilation

DESCRIPTION

Le module Dpkg::Build::Info fournit des fonctions pour gérer les informations de compilation.

Ce module est déprécié, utilisez Dpkg::BuildInfo à la place.

FONCTIONS

@envvars = get_build_env_allowed()
Obtenir un tableau avec la liste autorisée des variables d'environnement qui peuvent affecter la compilation, mais qui ne révèlent pas d'informations personnelles.

Ceci est un alias déprécié pour Dpkg::BuildInfo::get_build_env_allowed().

@envvars = get_build_env_whitelist()
Ceci est un alias déprécié pour Dpkg::BuildInfo::get_build_env_allowed().
