subroutine dptsvx (character fact, integer n, integer nrhs, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) df, double precision, dimension( * ) ef, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer info)

DPTSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices PT

But :

!>
!> DPTSVX utilise la factorisation A = L*D*L**T pour calculer la solution
!> d'un système d'équations linéaires réelles A*X = B, où A est une matrice
!> tridiagonale symétrique définie positive de dimension N par N
!> et X et B sont des matrices de dimension N par NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation du conditionnement
!> sont également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la matrice A est factorisée sous la forme A = L*D*L**T, où L
!>    est une matrice bidiagonale inférieure unitaire et D est diagonale. La
!>    factorisation peut également être considérée comme ayant la forme
!>    A = U**T*D*U.
!>
!> 2. Si le mineur principal initial d'ordre i n'est pas positif,
!>    la routine retourne avec INFO = i. Sinon, la forme factorisée
!>    de A est utilisée pour estimer le condition number de la matrice
!>    A. Si le réciproque du condition number est inférieur à la précision
!>    machine, INFO = N+1 est retourné comme avertissement, mais la routine
!>    continue néanmoins pour résoudre X et calculer les bornes d'erreur comme
!>    décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la matrice solution
!>    calculée et calculer les bornes d'erreur et les estimations d'erreur
!>    arrière pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Indique si la forme factorisée de A a été
!>          fournée à l'entrée.
!>          = 'F' : À l'entrée, DF et EF contiennent la forme factorisée de A.
!>                  D, E, DF et EF ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans DF et EF et
!>                  factorisée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice tridiagonale A.
!>

DF

!>          DF est un tableau DOUBLE PRECISION, dimension (N)
!>          Si FACT = 'F', alors DF est un argument d'entrée et à l'entrée
!>          contient les n éléments diagonaux de la matrice diagonale D
!>          de la factorisation L*D*L**T de A.
!>          Si FACT = 'N', alors DF est un argument de sortie et à la sortie
!>          contient les n éléments diagonaux de la matrice diagonale D
!>          de la factorisation L*D*L**T de A.
!>

EF

!>          EF est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Si FACT = 'F', alors EF est un argument d'entrée et à l'entrée
!>          contient les (n-1) éléments sous-diagonaux du facteur
!>          bidiagonal unitaire L de la factorisation L*D*L**T de A.
!>          Si FACT = 'N', alors EF est un argument de sortie et à la sortie
!>          contient les (n-1) éléments sous-diagonaux du facteur
!>          bidiagonal unitaire L de la factorisation L*D*L**T de A.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>          La matrice des seconds membres B de dimension N par NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de dimension N par NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          Le condition number réciproque de la matrice A. Si RCOND
!>          est inférieur à la précision machine (en particulier, si
!>          RCOND = 0), la matrice est singulière à la précision de travail.
!>          Cette condition est indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          La borne d'erreur directe pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la solution réelle correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du
!>          plus grand élément de X(j).
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire le plus petit changement relatif dans n'importe quel
!>          élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : le mineur principal initial d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être complétée, et la solution n'a pas été
!>                       calculée. RCOND = 0 est retourné.
!>                = N+1 : U est non singulier, mais RCOND est inférieur à la précision
!>                       machine, ce qui signifie que la matrice est singulière
!>                       à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il y a un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!>
