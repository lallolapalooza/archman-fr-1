DPORFSX

Objectif :

!>
!>    DPORFSX améliore la solution calculée d'un système d'équations linéaires
!>    quand la matrice des coefficients est symétrique définie positive, et fournit des bornes d'erreur et des estimations d'erreur arrière
!>    pour la solution. En plus de la borne d'erreur globale (normwise), le code
!>    fournit une borne d'erreur composante par composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires d'origine peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED et S
!>    ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système déséquilibré d'origine.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment l'amélioration est effectuée, mais souvent
!>     les valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0 ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U':  La partie triangulaire supérieure de A est stockée ;
!>       = 'L':  La partie triangulaire inférieure de A est stockée.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme de l'équilibrage qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     la solution et les bornes d'erreur correctement.
!>       = 'N':  Aucun équilibrage
!>       = 'Y':  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(S) * A * diag(S).
!>               Le membre de droite B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est tableau DOUBLE PRECISION, dimension (LDA,N)
!>     La matrice symétrique A.  Si UPLO = 'U', la partie triangulaire
!>     supérieure N par N de A contient la partie triangulaire supérieure
!>     de la matrice A, et la partie strictement triangulaire inférieure de A
!>     n'est pas référencée.  Si UPLO = 'L', la partie triangulaire
!>     inférieure N par N de A contient la partie triangulaire inférieure
!>     de la matrice A, et la partie strictement triangulaire supérieure de A
!>     n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est tableau DOUBLE PRECISION, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T, tel que calculé par DPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

S

!>          S est tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle pour A.  Si EQUED = 'Y', A est multiplié à
!>     gauche et à droite par diag(S).  S est un argument d'entrée si FACT =
!>     'F' ; sinon, S est un argument de sortie.  Si FACT = 'F' et EQUED
!>     = 'Y', chaque élément de S doit être positif.  Si S est en sortie, chaque
!>     élément de S est une puissance du radix. Si S est en entrée, chaque
!>     élément de S devrait être une puissance du radix pour assurer une solution fiable
!>     et des estimations d'erreur. L'échelonnage par des puissances du radix ne provoque pas
!>     d'erreurs d'arrondi à moins que le résultat ne sous-dépasse ou ne dépasse.
!>     Les erreurs d'arrondi lors de l'échelonnage conduisent à une amélioration avec une matrice qui
!>     n'est pas équivalente à la matrice d'entrée, produisant des estimations d'erreur
!>     qui peuvent ne pas être fiables.
!>

B

!>          B est tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>     La matrice du membre de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par DGETRS.
!>     À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Conditionnement réciproque échelonné. C'est une estimation du
!>     conditionnement réciproque de Skeel de la matrice A après
!>     équilibrage (si effectué). Si cela est inférieur à la précision de la machine
!>     (en particulier, si c'est zéro), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être petite même
!>     si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

BERR

!>          BERR est tableau DOUBLE PRECISION, dimension (NRHS)
!>     Erreur arrière relative composante par composante. C'est l'erreur
!>     relative composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans n'importe quel élément de A ou B qui
!>     fait de X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque membre de droite
!>     et chaque type (global ou composante par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et numéros de condition correspondant à
!>     l'erreur relative globale (normwise), qui est définie comme suit :
!>
!>     Erreur relative globale dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) con

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations
!>     sur diverses bornes d'erreur et nombres d'état correspondant à
!>     l'erreur relative composante par composante, qui est définie
!>     comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur
!>     solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend
!>     l'erreur relative composante par composante), et le type
!>     d'information d'erreur décrit ci-dessous. Il y a actuellement
!>     jusqu'à trois informations renvoyées pour chaque second
!>     membre. Si la précision composante par composante n'est pas
!>     demandée (PARAMS(3) = 0.0), alors ERR_BNDS_COMP n'est pas
!>     accédé. Si N_ERR_BNDS < 3, alors au plus les premières entrées
!>     (:,N_ERR_BNDS) sont renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les
!>     trois champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre d'état réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : l'erreur avant estimée, presque
!>              certainement dans un facteur 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne
!>              doit être prise en compte que si le booléen précédent
!>              est vrai.
!>
!>     err = 3  Nombre d'état réciproque : nombre d'état réciproque
!>              estimé composante par composante. Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si
!>              l'estimation d'erreur est . Ces nombres d'état
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf))
!>              pour une matrice Z correctement mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met chaque ligne de
!>              A*diag(x) à l'échelle par une puissance de la base
!>              afin que toutes les sommes absolues des lignes de Z
!>              soient approximativement 1.
!>
!>     Voir la note de travail Lapack 165 pour plus de détails et de
!>     précautions supplémentaires.
!>

NPARAMS

!>          NPARAMS est INTEGER
!>     Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0,
!>     le tableau PARAMS n'est jamais référencé et les valeurs par
!>     défaut sont utilisées.
!>

PARAMS

!>          PARAMS est un tableau DOUBLE PRECISION, dimension (NPARAMS)
!>     Spécifie les paramètres de l'algorithme. Si une entrée est
!>     < 0.0, alors cette entrée sera remplie avec la valeur par
!>     défaut utilisée pour ce paramètre. Seules les positions
!>     jusqu'à NPARAMS sont accédées ; les valeurs par défaut sont
!>     utilisées pour les paramètres de numéro supérieur.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Effectuer ou non l'affinage
!>            itératif.
!>         Défaut : 1.0D+0
!>            = 0.0 : Aucun affinage n'est effectué et aucune borne
!>                    d'erreur n'est calculée.
!>            = 1.0 : Utiliser l'algorithme d'affinage en double
!>                    précision, éventuellement avec des calculs
!>                    double-simple si l'environnement de compilation
!>                    ne supporte pas DOUBLE PRECISION.
!>              (les autres valeurs sont réservées pour une utilisation
!>              future)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximal de
!>            calculs de résidu autorisés pour l'affinage.
!>         Défaut : 10
!>         Agressif : Définir à 100 pour permettre la convergence en
!>                     utilisant des factorisations approchées ou des
!>                     factorisations autres que LU. Si la factorisation
!>                     utilise une technique autre que l'élimination
!>                     gaussienne, les garanties dans err_bnds_norm et
!>                     err_bnds_comp peuvent ne plus être dignes de
!>                     confiance.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3 : Drapeau déterminant si le code
!>            essaiera de trouver une solution avec une petite erreur
!>            relative composante par composante dans l'algorithme en
!>            double précision. Positif est vrai, 0.0 est faux.
!>         Défaut : 1.0 (tenter la convergence composante par
!>         composante)
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (4*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie. La solution pour chaque second membre
!>         est garantie.
!>       < 0 : Si INFO = -i, le i-ème argument avait une valeur
!>         illégale
!>       > 0 et <= N : U(INFO,INFO) est exactement zéro. La
!>         factorisation a été complétée, mais le facteur U est
!>         exactement singulier, donc la solution et les bornes
!>         d'erreur n'ont pas pu être calculées. RCOND = 0 est
!>         renvoyé.
!>       = N+J : La solution correspondant au J-ème second membre
!>         n'est pas garantie. Les solutions correspondant aux autres
!>         seconds membres K avec K > J peuvent ne pas non plus être
!>         garanties, mais seul le premier tel second membre est
!>         rapporté. Si une petite erreur composante par composante
!>         n'est pas demandée (PARAMS(3) = 0.0) alors le J-ème second
!>         membre est le premier avec une borne d'erreur en norme qui
!>         n'est pas garantie (le plus petit J tel que
!>         ERR_BNDS_NORM(J,1) = 0.0). Par défaut (PARAMS(3) = 1.0)
!>         le J-ème second membre est le premier avec une borne
!>         d'erreur en norme ou composante par composante qui n'est
!>         pas garantie (le plus petit J tel que soit
!>         ERR_BNDS_NORM(J,1) = 0.0 soit ERR_BNDS_COMP(J,1) = 0.0).
!>         Voir la définition de ERR_BNDS_NORM(:,1) et
!>         ERR_BNDS_COMP(:,1). Pour obtenir des informations sur tous
!>         les seconds membres, vérifiez ERR_BNDS_NORM ou
!>         ERR_BNDS_COMP.
!>
