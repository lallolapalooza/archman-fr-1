NOM

Dpkg::Control::Info - analyse les fichiers comme debian/control

DESCRIPTION

Il fournit une classe pour accéder aux données des fichiers qui suivent la même syntaxe que debian/control.

MÉTHODES

$c = Dpkg::Control::Info->new(%opts)
Crée un nouvel objet Dpkg::Control::Info. Charge debian/control par défaut. Si un seul scalaire est passé, il sera utilisé comme nom de fichier à charger au lieu du défaut. Si le nom de fichier est "-", il analyse l'entrée standard. Si le nom de fichier est indéfini, aucun chargement ne sera effectué.

Options :

filename
Charge le fichier à partir du nom de fichier, au lieu de debian/control.
$c->reset()
Réinitialise ce qui a été lu.
$c->parse($fh, $description)
Analyse un fichier de contrôle à partir du handle de fichier donné. Se termine en cas d'erreurs. $description est utilisée pour décrire le handle de fichier, idéalement c'est un nom de fichier ou une description de l'origine des données. Elle est utilisée dans les messages d'erreur. Les données dans l'objet sont réinitialisées avant d'analyser de nouveaux fichiers de contrôle.
$c->load($file)
Charge le contenu de $file. Se termine en cas d'erreurs. Si le fichier est "-", il charge depuis l'entrée standard.
$c->[0]
$c->get_source()
Retourne un objet Dpkg::Control contenant les champs concernant le paquet source.
$c->get_pkg_by_idx($idx)
Retourne un objet Dpkg::Control contenant les champs concernant le paquet binaire numéroté $idx (en commençant à 1).
$c->get_pkg_by_name($name)
Retourne un objet Dpkg::Control contenant les champs concernant le paquet binaire nommé $name.
$c->get_packages()
Retourne une liste contenant les objets Dpkg::Control pour tous les paquets binaires.
$str = $c->output([$fh])
Retourne le contenu d'information dans une chaîne. Si $fh est spécifié, l'imprime dans le handle de fichier.
"$c"
Retourne une représentation textuelle du contenu.
@{$c}
Retourne une liste d'objets Dpkg::Control, le premier correspondant aux informations source et les suivants aux informations des paquets binaires.
