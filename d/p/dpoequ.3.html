subroutine dpoequ (integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision scond, double precision amax, integer info)

DPOEQU

Objectif :

!>
!> DPOEQU calcule les mises à l'échelle des lignes et des colonnes destinées à équilibrer
!> une matrice symétrique définie positive A et à réduire son nombre de conditionnement
!> (par rapport à la norme deux). S contient les facteurs d'échelle,
!> S(i) = 1/sqrt(A(i,i)), choisis de manière que la matrice mise à l'échelle B avec
!> les éléments B(i,j) = S(i)*A(i,j)*S(j) ait des uns sur la diagonale. Ce
!> choix de S met le nombre de conditionnement de B à un facteur N du
!> plus petit nombre de conditionnement possible sur toutes les mises à l'échelle diagonales possibles.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau de type DOUBLE PRECISION, de dimension (LDA,N)
!>          La matrice symétrique définie positive N x N dont les facteurs d'échelle doivent être calculés.
!>          Seuls les éléments diagonaux de A sont référencés.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

S

!>          S est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est de type DOUBLE PRECISION
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle par S.
!>

AMAX

!>          AMAX est de type DOUBLE PRECISION
!>          Valeur absolue du plus grand élément de la matrice. Si AMAX est très
!>          proche du dépassement de capacité ou de la sous-capacite, la matrice
!>          doit être mise à l'échelle.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument était illégal
!>          > 0 : si INFO = i, le i-ème élément diagonal est non positif.
!>
