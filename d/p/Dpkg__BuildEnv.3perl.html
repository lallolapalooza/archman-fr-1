NOM

Dpkg::BuildEnv - suivre l'environnement de construction

DESCRIPTION

Le module Dpkg::BuildEnv est utilisé par dpkg-buildflags pour suivre les variables d'environnement de construction utilisées et modifiées.

Note : Ceci est un module privé, son API peut changer à tout moment.

FONCTIONS

set($nomvar, $valeur)
Met à jour la variable d'environnement de construction $nomvar avec la valeur $valeur. Enregistre son accès et sa modification.
get($nomvar)
Récupère la valeur de la variable d'environnement de construction $nomvar. Enregistre son accès.
has($nomvar)
Retourne une valeur booléenne indiquant si la variable d'environnement existe. Enregistre son accès.
@liste = liste_accessee()
Retourne une liste de toutes les variables d'environnement qui ont été accédées.
@liste = liste_modifiees()
Retourne une liste de toutes les variables d'environnement qui ont été modifiées.
