DPOSVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices

PO

But

: 
!>
!>    DPOSVXX utilise la factorisation de Cholesky A = U**T*U ou A = L*L**T
!>    pour calculer la solution d'un système d'équations linéaires en double
!>    précision A * X = B, où A est une matrice symétrique définie positive
!>    de dimension N par N et X et B sont des matrices de dimension N par NRHS.
!>
!>    Si cela est demandé, les bornes d'erreur tant globales (norme) que
!>    maximales composante par composante sont renvoyées. DPOSVXX renverra une
!>    solution avec une erreur garantie minuscule (O(eps) où eps est la
!>    précision machine de travail), sauf si la matrice est très mal
!>    conditionnée, auquel cas un avertissement est renvoyé. Les nombres de
!>    condition pertinents sont également calculés et renvoyés.
!>
!>    DPOSVXX accepte les factorisations et facteurs d'équilibrage fournis par
!>    l'utilisateur ; voir les définitions des options FACT et EQUED.
!>    La résolution avec raffinement en utilisant une factorisation issue d'un
!>    appel précédent à DPOSVXX produira également une solution avec des
!>    erreurs ou des avertissements de l'ordre de O(eps), mais nous ne pouvons
!>    pas faire cette affirmation pour des factorisations et facteurs
!>    d'équilibrage généraux fournis par l'utilisateur s'ils diffèrent de ce
!>    que DPOSVXX produirait lui-même.
!
>

Description

: 
!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs de mise à l'échelle en double précision
!>    sont calculés pour équilibrer le système :
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle de la
!>    matrice A, mais si l'équilibrage est utilisé, A est remplacée par
!>    diag(S)*A*diag(S) et B par diag(S)*B.
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibrage si FACT = 'E') comme
!>       A = U**T* U,  si UPLO = 'U', ou
!>       A = L * L**T,  si UPLO = 'L',
!>    où U est une matrice triangulaire supérieure et L est une matrice
!>    triangulaire inférieure.
!>
!>    3. Si le mineur principal initial d'ordre i n'est pas positif,
!>    alors la routine renvoie avec INFO = i. Sinon, la forme factorisée
!>    de A est utilisée pour estimer le nombre de condition de la matrice
!>    A (voir l'argument RCOND). Si l'inverse du nombre de condition
!>    est inférieur à la précision machine, la routine continue néanmoins
!>    pour résoudre X et calculer les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme
!>    factorisée de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    la routine utilisera le raffinement itératif pour essayer d'obtenir
!>    une petite erreur et de petites bornes d'erreur. Le raffinement calcule
!>    le résidu avec au moins deux fois la précision de travail.
!>
!>    6. Si l'équilibrage a été utilisé, la matrice X est multipliée à gauche
!>    par diag(S) afin qu'elle résolve le système original
!>    avant équilibrage.
!
> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     réglages déterminent la manière dont le raffinement est effectué, mais
!>     souvent les valeurs par défaut sont acceptables. Si les valeurs par
!>     défaut sont acceptables, les utilisateurs peuvent passer NPARAMS = 0,
!>     ce qui empêche le code source d'accéder à l'argument PARAMS.
!
>

Paramètre

s
FACT 
!>          FACT est CHARACTER*1
!>     Indique si la forme factorisée de la matrice A est
!>     fournée à l'entrée, et si ce n'est pas le cas, si la matrice A doit
!>     être équilibrée avant d'être factorisée.
!>       = 'F' : À l'entrée, AF contient la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été
!>               équilibrée avec les facteurs de mise à l'échelle donnés par S.
!>               A et AF ne sont pas modifiées.
!>       = 'N' : La matrice A sera copiée dans AF et factorisée.
!>       = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!
>

UPL

O 
!>          UPLO est CHARACTER*1
!>       = 'U' : Le triangle supérieur de A est stocké ;
!>       = 'L' : Le triangle inférieur de A est stocké.
!
>

N 
!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A. N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>     Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>     des matrices B et X. NRHS >= 0.
!
>

A 
!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>     À l'entrée, la matrice symétrique A, sauf si FACT = 'F' et EQUED =
!>     'Y', auquel cas A doit contenir la matrice équilibrée
!>     diag(S)*A*diag(S). Si UPLO = 'U', la partie triangulaire supérieure
!>     N par N de A contient la partie triangulaire supérieure de la
!>     matrice A, et la partie strictement triangulaire inférieure de A n'est
!>     pas référencée. Si UPLO = 'L', la partie triangulaire inférieure
!>     N par N de A contient la partie triangulaire inférieure de la matrice A, et
!>     la partie strictement triangulaire supérieure de A n'est pas référencée. A n'est
!>     pas modifiée si FACT = 'F' ou 'N', ou si FACT = 'E' et EQUED =
!>     'N' à la sortie.
!>
!>     À la sortie, si FACT = 'E' et EQUED = 'Y', A est remplacée par
!>     diag(S)*A*diag(S).
!
>

LD

A 
!>          LDA est INTEGER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!
>

A

F 
!>          AF est un tableau DOUBLE PRECISION, dimension (LDAF,N)
!>     Si FACT = 'F', alors AF est un argument d'entrée et à l'entrée
!>     contient le facteur triangulaire U ou L de la factorisation
!>     de Cholesky A = U**T*U ou A = L*L**T, dans le même format de
!>     stockage que A. Si EQUED .ne. 'N', alors AF est la forme
!>     factorisée de la matrice équilibrée diag(S)*A*diag(S).
!>
!>     Si FACT = 'N', alors AF est un argument de sortie et à la sortie
!>     renvoie le facteur triangulaire U ou L de la factorisation
!>     de Cholesky A = U**T*U ou A = L*L**T de la matrice
!>     originale A.
!>
!>     Si FACT = 'E', alors AF est un argument de sortie et à la sortie
!>     renvoie le facteur triangulaire U ou L de la factorisation
!>     de Cholesky A = U**T*U ou A = L*L**T de la matrice
!>     équilibrée A (voir la description de A pour la forme de la
!>     matrice équilibrée).
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibrage qui a été effectuée.
!>       = 'N' : Pas d'équilibrage (toujours vrai si FACT = 'N').
!>       = 'Y' : Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(S) * A * diag(S).
!>     EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>     argument de sortie.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle des lignes de A.  Si EQUED = 'Y', A est multiplié à
!>     gauche et à droite par diag(S).  S est un argument d'entrée si FACT =
!>     'F' ; sinon, S est un argument de sortie.  Si FACT = 'F' et EQUED
!>     = 'Y', chaque élément de S doit être positif.  Si S est en sortie, chaque
!>     élément de S est une puissance de la base. Si S est en entrée, chaque élément
!>     de S devrait être une puissance de la base pour garantir une solution
!>     et des estimations d'erreur fiables. La mise à l'échelle par des puissances de la base ne cause
!>     pas d'erreurs d'arrondi sauf si le résultat déborde ou est sous le seuil de représentation.
!>     Les erreurs d'arrondi pendant la mise à l'échelle conduisent à un raffinement avec une matrice qui
!>     n'est pas équivalente à la matrice d'entrée, produisant des estimations d'erreur
!>     qui peuvent ne pas être fiables.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>     À l'entrée, la matrice du second membre B de dimension N par NRHS.
!>     À la sortie,
!>     si EQUED = 'N', B n'est pas modifié ;
!>     si EQUED = 'Y', B est écrasé par diag(S)*B ;
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>     Si INFO = 0, la matrice solution X de dimension N par NRHS du système
!>     d'équations original.  Notez que A et B sont modifiés à la sortie si
!>     EQUED .ne. 'N', et la solution du système équilibré est
!>     inv(diag(S))*X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Réciproque du nombre de condition mis à l'échelle.  C'est une estimation du
!>     réciproque du nombre de condition de Skeel de la matrice A après
!>     équilibrage (si effectué).  Si ceci est inférieur à la précision
!>     machine (en particulier, si c'est zéro), la matrice est singulière
!>     à la précision de travail.  Notez que l'erreur peut encore être petite même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!>

RPVGRW

!>          RPVGRW est DOUBLE PRECISION
!>     Réciproque de la croissance du pivot.  À la sortie, ceci contient le réciproque
!>     du facteur de croissance du pivot norm(A)/norm(U). La
!>     norme est utilisée.  Si ceci est beaucoup plus petit que 1, alors la stabilité de
!>     la factorisation LU de la matrice A (équilibrée) pourrait être mauvaise.
!>     Cela signifie également que la solution X, les nombres de condition estimés,
!>     et les bornes d'erreur pourraient ne pas être fiables. Si la factorisation échoue avec
!>     0<INFO<=N, alors ceci contient le réciproque du facteur de croissance du pivot
!>     pour les INFO premières colonnes de A.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>     Erreur arrière relative composante par composante.  C'est l'
!>     erreur arrière relative composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire la plus petite variation relative dans n'importe quel élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque second membre
!>     et chaque type (dans la norme ou composante par composante).  Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à l'
!>     erreur relative dans la norme, qui est définie comme suit :
!>
!>     Erreur relative dans la norme dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur comme décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              réciproque du nombre de condition est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Réciproque du nombre de condition : Réciproque estimé du
!>              nombre de condition dans la norme.  Comparé avec le seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces réciproques de nombres de
!>              condition sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z mise à l'échelle de manière appropriée.
!>              Soit Z = S*A, où S met chaque ligne à l'échelle par une puissance de la
!>              base de sorte que toutes les sommes absolues des lignes de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des avertissements
!>     supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à l'
!>     erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend l'
!>     erreur relative composante par composante), et le type d'information
!>     d'erreur comme décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations retournées pour chaque second membre. Si la précision
!>     composante par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé.  Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              réciproque du nombre de condition est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Réciproque du nombre de condition : Réciproque estimé du
!>              nombre de condition composante par composante.  Comparé avec le seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces réciproques de nombres de
!>              condition sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z mise à l'échelle de manière appropriée.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met chaque ligne de
!>              A*diag(x) à l'échelle par une puissance de la base de sorte que toutes les sommes absolues des lignes
!>              de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des avertissements
!>     supplémentaires.
!>

NPARAMS

!>          NPARAMS est INTEGER
!>     Spécifie le nombre de paramètres définis dans PARAMS.  Si <= 0, le
!>     tableau PARAMS n'est jamais référencé et les valeurs par défaut sont utilisées.
!>

PARAMS

!>          PARAMS est un tableau DOUBLE PRECISION, dimension NPARAMS
!>     Spécifie les paramètres de l'algorithme.  Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre.  Seules les positions jusqu'à NPARAMS sont accédées ; les valeurs par défaut
!>     sont utilisées pour les paramètres de numérotation supérieure.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : S'il faut effectuer le raffinement
!>            itératif ou non.
!>         Par défaut : 1.0D+0
!>            = 0.0 :  Aucun raffinement n'est effectué, et aucune borne d'erreur n'est
!>                    calculée.
!>            = 1.0 :  Utiliser l'algorithme de raffinement de précision extra.
!>              (les autres valeurs sont réservées pour une utilisation future)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximal de calculs de résidu
!>            autorisés pour le raffinement.
!>         Par défaut : 10
!>         Agressif : Définir à 100 pour permettre la convergence en utilisant des factorisations
!>                     approchées ou des factorisations autres que LU. Si
!>                     la factorisation utilise une technique autre que
!>                     l'élimination gaussienne, les garanties dans
!>                     err_bnds_norm et err_bnds_comp peuvent ne plus être
!>                     dignes de confiance.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3 : Drapeau déterminant si le code
!>            tentera de trouver une solution avec une petite erreur relative
!>            composante par composante dans l'algorithme en double précision.  Positif
!>            est vrai, 0.0 est faux.
!>         Par défaut : 1.0 (tenter la convergence composante par composante)
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (4*N)

IWORK

!>          IWORK est un tableau INTEGER, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>       = 0 :  Sortie réussie. La solution pour chaque second membre est
!>         garantie.
!>       < 0 :  Si INFO = -i, le i-ème argument avait une valeur illégale
!>       > 0 et <= N :  U(INFO,INFO) est exactement zéro.  La factorisation
!>         a été complétée, mais le facteur U est exactement singulier, donc
!>         la solution et les bornes d'erreur n'ont pas pu être calculées. RCOND = 0
!>         est retourné.
!>       = N+J : La solution correspondant au J-ème second membre n'est
!>         pas garantie. Les solutions correspondant aux autres seconds
!>         membres K avec K > J peuvent ne pas être garanties non plus, mais
!>         seul le premier tel second membre est signalé. Si une petite erreur
!>         composante par composante n'est pas demandée (PARAMS(3) = 0.0) alors
!>         le J-èmeht-hand side est le premier avec une borne d'erreur normwise qui n'est pas garantie (le plus petit J tel que ERR_BNDS_NORM(J,1) = 0.0). Par défaut (PARAMS(3) = 1.0), le J-ième membre de droite est le premier avec une borne d'erreur normwise ou composante par composante qui n'est pas garantie (le plus petit J tel que ERR_BNDS_NORM(J,1) = 0.0 ou ERR_BNDS_COMP(J,1) = 0.0). Voir la définition de ERR_BNDS_NORM(:,1) et ERR_BNDS_COMP(:,1). Pour obtenir des informations sur tous les membres de droite, consultez ERR_BNDS_NORM ou ERR_BNDS_COMP.
