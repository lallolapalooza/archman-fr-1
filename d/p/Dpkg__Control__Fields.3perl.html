NOM

Dpkg::Control::Fields - gérer les champs de contrôle (liste de champs officiels)

DESCRIPTION

Ce module contient une liste de noms de champs neutres du point de vue du vendeur et spécifiques au vendeur, avec des métadonnées associées expliquant dans quel type d'informations de contrôle ils sont autorisés. Les noms de champs neutres du point de vue du vendeur et toutes les fonctions sont hérités de Dpkg::Control::FieldsCore.
