NOM

Dpkg::Deps::KnownFacts - liste des paquets réels et virtuels installés

DESCRIPTION

Cette classe représente une liste de paquets installés et une liste de paquets virtuels fournis (par l'ensemble des paquets installés).

MÉTHODES

$facts = Dpkg::Deps::KnownFacts->new();
Crée un nouvel objet.
$facts->add_installed_package($package, $version, $arch, $multiarch)
Enregistre que la version donnée du paquet est installée. Si $version/$arch est indéfini, nous savons que le paquet est installé mais nous ne connaissons pas sa version/architecture. $multiarch est le champ Multi-Arch du paquet. Si $multiarch est indéfini, il sera équivalent à "Multi-Arch: no".

Notez que $multiarch n'est utilisé que si $arch est fourni.

$facts->add_provided_package($virtual, $relation, $version, $by)
Enregistre que le paquet "$by" fournit le paquet $virtual. $relation et $version correspondent à la relation associée donnée dans le champ Provides (si présent).
$facts->evaluate_simple_dep()
Cette méthode est privée et ne doit pas être utilisée sauf depuis Dpkg::Deps.

CHANGEMENTS

Version 2.00 (dpkg 1.20.0)

Méthode supprimée : $facts->check_package().

Version 1.01 (dpkg 1.16.1)

Nouvelle option : $facts->add_installed_package() accepte maintenant 2 paramètres supplémentaires ($arch et $multiarch).

Méthode dépréciée : $facts->check_package() est obsolète, elle n'aurait pas dû faire partie de l'API publique.

Version 1.00 (dpkg 1.15.6)

Marque le module comme public.
