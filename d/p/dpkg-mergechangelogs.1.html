NOM

dpkg-mergechangelogs - Fusionne 3 fichiers debian/changelog

SYNTAXE

dpkg-mergechangelogs [option...] ancien nouveau-a nouveau-b [sortie]

DESCRIPTION

Ce programme utilise les 3 versions fournies du fichier de changelog Debian pour générer un fichier de changelog fusionné. Le changelog résultant est stocké dans le fichier sortie ou envoyé sur la sortie standard si ce paramètre n'est pas donné.

Chaque entrée est identifiée par son numéro de version et elles sont supposées ne pas être conflictuelles, elles sont simplement fusionnées dans le bon ordre (par numéro de version décroissant). Lorsque --merge-prereleases est utilisé, la partie du numéro de version après la dernière tilde est supprimée afin que 1.0-1~exp1 et 1.0-1~exp5 soient considérés comme la même entrée. Lorsque la même version est disponible à la fois dans nouveau-a et nouveau-b, une fusion standard à 3 voies ligne par ligne est tentée (à condition que le module Algorithm::Merge soit disponible — il fait partie du paquet libalgorithm-merge-perl — sinon vous obtiendrez un conflit global sur le contenu de l'entrée).

Ce programme a été introduit dans dpkg 1.15.7.

OPTIONS

--merge-unreleased
Ignore le numéro de version lorsque les entrées sont marquées comme UNRELEASED (depuis dpkg 1.21.0).

Ceci est utile lorsque vous avez des développements divergents pour des versions qui n'ont pas encore été publiées. Par exemple, 2.1-1 est publié, puis le développement se poursuit pour le nouveau 2.2-1 et ensuite pour 2.3-1, où il est logique de terminer avec une entrée coalescente pour 2.3-1 incluant tout le développement effectué dans 2.2-1.

-m, --merge-prereleases
Supprime la partie après la dernière tilde dans le numéro de version lors de la comparaison des versions pour déterminer si deux entrées sont supposées être identiques ou non.

Ceci est utile lorsque vous continuez à utiliser la même entrée de changelog mais que vous augmentez son numéro de version régulièrement. Par exemple, vous pourriez avoir 2.3-1~exp1, 2.3-1~exp2, ... jusqu'à la publication officielle 2.3-1 et il s'agit toutes de la même entrée de changelog qui a évolué au fil du temps.

--help
Affiche le message d'utilisation et quitte.
--version
Affiche la version et quitte.

ENVIRONNEMENT

DPKG_COLORS
Définit le mode couleur (depuis dpkg 1.18.5). Les valeurs actuellement acceptées sont : auto (par défaut), always et never.
DPKG_NLS
Si défini, il sera utilisé pour décider d'activer ou non le support de la langue native, également connu sous le nom d'internationalisation (ou i18n) (depuis dpkg 1.19.0). Les valeurs acceptées sont : 0 et 1 (par défaut).

LIMITATIONS

Tout ce qui n'est pas analysé par Dpkg::Changelog est perdu pendant la fusion. Cela peut inclure des éléments tels que des commentaires qui n'étaient pas censés s'y trouver, etc.

INTÉGRATION AVEC GIT

Si vous souhaitez utiliser ce programme pour fusionner les fichiers de changelog Debian dans un dépôt git, vous devez d'abord enregistrer un nouveau pilote de fusion dans .git/config ou ~/.gitconfig :

[merge "dpkg-mergechangelogs"]
   name = pilote de fusion debian/changelog
   driver = dpkg-mergechangelogs -m %O %A %B %A

Ensuite, vous devez configurer l'attribut de fusion pour le fichier debian/changelog, soit dans .gitattributes dans le dépôt lui-même, soit dans .git/info/attributes :

debian/changelog merge=dpkg-mergechangelogs
2025-06-30 1.22.21-dirty
