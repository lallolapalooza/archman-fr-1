NOM

Dpkg::Control::Changelog - représente les champs d'informations générés par dpkg-parsechangelog

DESCRIPTION

Cette classe dérive directement de Dpkg::Control avec le type CTRL_CHANGELOG.

MÉTHODES

$c = Dpkg::Control::Changelog->new()
Crée un nouvel ensemble vide de champs liés au changelog.
