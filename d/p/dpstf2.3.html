Documentation de la fonction/sous-routine

sous-routine dpstf2 (caractère uplo, entier n, double précision, dimension( lda, * ) a, entier lda, entier, dimension( n ) piv, entier rank, double précision tol, double précision, dimension( 2*n ) work, entier info)

DPSTF2 calcule la factorisation de Cholesky avec pivotement complet d'une matrice réelle symétrique positive semi-définie A.

Objectif :

!>
!> DPSTF2 calcule la factorisation de Cholesky avec pivotement
!> complet d'une matrice réelle symétrique positive semi-définie A.
!>
!> La factorisation a la forme
!>    P**T * A * P = U**T * U ,  si UPLO = 'U',
!>    P**T * A * P = L  * L**T,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est triangulaire inférieure, et
!> P est stocké sous forme de vecteur PIV.
!>
!> Cet algorithme ne tente pas de vérifier que A est positive
!> semi-définie. Cette version de l'algorithme appelle BLAS de niveau 2.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de DOUBLE PRÉCISION, dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A. Si UPLO = 'U', la partie
!>          supérieure triangulaire de taille n par n de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la
!>          partie inférieure triangulaire de taille n par n de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          À la sortie, si INFO = 0, le facteur U ou L de la factorisation
!>          de Cholesky comme ci-dessus.
!>

PIV

!>          PIV est un tableau de ENTIER, dimension (N)
!>          PIV est tel que les entrées non nulles sont P( PIV(K), K ) = 1.
!>

RANK

!>          RANK est ENTIER
!>          Le rang de A donné par le nombre d'étapes que l'algorithme
!>          a complétées.
!>

TOL

!>          TOL est DOUBLE PRÉCISION
!>          Tolérance définie par l'utilisateur. Si TOL < 0, alors N*U*MAX( A( K,K ) )
!>          sera utilisée. L'algorithme se termine à la (K-1)ème étape
!>          si le pivot <= TOL.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, dimension (2*N)
!>          Espace de travail.
!>

INFO

!>          INFO est ENTIER
!>          < 0 : Si INFO = -K, le K-ième argument avait une valeur illégale,
!>          = 0 : algorithme terminé avec succès, et
!>          > 0 : la matrice A est soit de rang déficient avec un rang calculé
!>               tel que retourné dans RANK, soit n'est pas positive semi-définie. Voir
!>               la section 7 du document de travail LAPACK #161 pour plus
!>               d'informations.
!>
