NOM

Dpkg::Arch - gérer les architectures

DESCRIPTION

Le module Dpkg::Arch fournit des fonctions pour gérer les architectures Debian, les jokers et le mappage depuis et vers les triplets GNU.

Aucun symbole n'est exporté par défaut. Le tag :all peut être utilisé pour importer tous les symboles. Les tags :getters, :parsers, :mappers et :operators peuvent être utilisés pour importer des sous-ensembles de symboles spécifiques.

FONCTIONS

$arch = get_raw_build_arch()
Obtient l'architecture de construction Debian brute, sans prendre en compte les variables de l'environnement.
$arch = get_build_arch()
Obtient l'architecture de construction Debian, en utilisant DEB_BUILD_ARCH de l'environnement si disponible.
$arch = get_raw_host_arch()
Obtient l'architecture hôte Debian brute, sans prendre en compte les variables de l'environnement.
$arch = get_host_arch()
Obtient l'architecture hôte Debian, en utilisant DEB_HOST_ARCH de l'environnement si disponible.
@arch_list = get_valid_arches()
Obtient un tableau avec toutes les architectures Debian actuellement connues.
$multiarch = gnutriplet_to_multiarch($gnutriplet)
Mappe un triplet GNU vers un triplet multiarch Debian.
$multiarch = debarch_to_multiarch($arch)
Mappe une architecture Debian vers un triplet multiarch Debian.
$gnutriplet = debarch_to_gnutriplet($arch)
Mappe une architecture Debian vers un triplet GNU.
$arch = gnutriplet_to_debarch($gnutriplet)
Mappe un triplet GNU vers une architecture Debian.
$bool = debarch_eq($arch_a, $arch_b)
Évalue l'égalité d'une architecture Debian, en la comparant à une autre architecture Debian. Aucune correspondance avec joker n'est effectuée.
$bool = debarch_is($arch, $arch_wildcard)
Évalue l'identité d'une architecture Debian, en la faisant correspondre à un joker d'architecture.
$bool = debarch_is_wildcard($arch)
Évalue si une architecture Debian est un joker d'architecture.
$bool = debarch_is_illegal($arch, %opts)
Valide un nom d'architecture.

Options :

positive
Si défini à une valeur vraie, seules les architectures positives seront acceptées, sinon les architectures négatives sont autorisées.
$bool = debarch_is_concerned($arch, @arches)
Évalue si une architecture Debian s'applique à la liste des restrictions d'architecture, comme on le trouve habituellement dans les dépendances entre crochets.
@array = debarch_list_parse($arch_list, %opts)
Analyse une liste d'architectures.

Options :

positive
Si défini à une valeur vraie, seules les architectures positives seront acceptées, sinon les architectures négatives sont autorisées.

CHANGEMENTS

Version 1.03 (dpkg 1.19.1)

Nouveau argument : Accepte une option "positive" dans debarch_is_illegal() et debarch_list_parse().

Version 1.02 (dpkg 1.18.19)

Nouveaux tags d'importation : ":all", ":getters", ":parsers", ":mappers", ":operators".

Version 1.01 (dpkg 1.18.5)

Nouvelles fonctions : debarch_is_illegal(), debarch_list_parse().

Version 1.00 (dpkg 1.18.2)

Marque le module comme public.
