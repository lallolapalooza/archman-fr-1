NOM

dpkg-scanpackages — crée les fichiers d'index Packages

SYNTAXE

dpkg-scanpackages [option...] chemin-binaire [fichier-prioritaire [préfixe-chemin]] > Packages

DESCRIPTION

dpkg-scanpackages parcourt un arbre de paquets binaires Debian et crée un fichier Packages, utilisé par apt(8), dselect(1), etc., pour informer l'utilisateur des paquets disponibles à l'installation. Ces fichiers Packages sont identiques à ceux trouvés sur les sites d'archives Debian et les disques de médias. Vous pourriez utiliser dpkg-scanpackages vous-même si vous créez un répertoire de paquets locaux à installer sur un cluster de machines.

Note : Si vous souhaitez accéder au fichier Packages généré avec apt(8), vous devrez probablement compresser le fichier avec xz(1) (générant un fichier Packages.xz), bzip2(1) (générant un fichier Packages.bz2) ou gzip(1) (générant un fichier Packages.gz). apt(8) ignore les fichiers Packages non compressés sauf lors d'un accès local (c'est-à-dire les sources file://).

chemin-binaire est le nom de l'arbre des paquets binaires à traiter (par exemple, contrib/binary-i386). Il est préférable de le rendre relatif à la racine de l'archive Debian, car chaque champ Filename dans le nouveau fichier Packages commencera par cette chaîne.

fichier-prioritaire est le nom d'un fichier à lire qui contient des informations sur la façon dont le paquet s'intègre dans la distribution (le fichier peut être compressé depuis dpkg 1.15.5) ; voir deb-override(5).

préfixe-chemin est une chaîne optionnelle à ajouter aux champs Filename.

Si plusieurs versions d'un paquet sont trouvées, seule la plus récente est incluse dans la sortie. Si elles ont la même version et ne diffèrent que par leur architecture, seule la première trouvée est utilisée.

OPTIONS

-t, --type type
Analyse les paquets de type *.type au lieu de *.deb.
-e, --extra-override fichier
Analyse le fichier pour trouver des priorités supplémentaires (le fichier peut être compressé depuis dpkg 1.15.5). Voir deb-extra-override(5) pour plus d'informations sur son format.
-a, --arch arch
Utilise un motif composé de *_all.deb et *_arch.deb au lieu d'analyser tous les debs.
-h, --hash liste-hash
Génère uniquement les hachages de fichiers pour la liste spécifiée et séparée par des virgules (depuis dpkg 1.17.14). La valeur par défaut est de générer tous les hachages actuellement pris en charge. Valeurs prises en charge : md5, sha1, sha256.
-m, --multiversion
Inclut tous les paquets trouvés dans la sortie.
-M, --medium chaine-id
Ajoute un champ X-Medium contenant la valeur chaine-id (depuis dpkg 1.15.5). Ce champ est requis si vous souhaitez générer des fichiers Packages.cd pour être utilisés par la méthode d'accès media de dselect.
-?, --help
Affiche le message d'utilisation et quitte.
--version
Affiche la version et quitte.

ENVIRONNEMENT

DPKG_COLORS
Définit le mode couleur (depuis dpkg 1.18.5). Les valeurs actuellement acceptées sont : auto (par défaut), always (toujours) et never (jamais).
DPKG_NLS
Si défini, il sera utilisé pour décider s'il faut activer le support des langues natives, également connu sous le nom d'internationalisation (ou i18n) (depuis dpkg 1.19.0). Les valeurs acceptées sont : 0 et 1 (par défaut).

DIAGNOSTICS

dpkg-scanpackages affiche les erreurs habituelles qui s'expliquent d'elles-mêmes. Il émet également des avertissements concernant les paquets qui se trouvent dans le sous-répertoire incorrect, qui sont dupliqués, qui ont un champ Filename dans leur fichier de contrôle, qui sont manquants dans le fichier prioritaire ou qui ont des substitutions de mainteneur qui n'ont pas d'effet.

VOIR AUSSI

dpkg(1), dselect(1), deb-override(5), deb-extra-override(5), dpkg-scansources(1).
