Documentation de la fonction/sous-programme

sous-routine dpoequ (integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision scond, double precision amax, integer info)

DPOEQU

But :

!>
!> DPOEQU calcule des mises à l'échelle des lignes et des colonnes destinées à équilibrer
!> une matrice A symétrique définie positive et à réduire son nombre de conditionnement
!> (par rapport à la norme deux). S contient les facteurs d'échelle,
!> S(i) = 1/sqrt(A(i,i)), choisis de sorte que la matrice mise à l'échelle B avec
!> les éléments B(i,j) = S(i)*A(i,j)*S(j) ait des uns sur la diagonale. Ce
!> choix de S met le nombre de conditionnement de B à un facteur N du
!> nombre de conditionnement le plus petit possible sur toutes les mises à l'échelle diagonales possibles.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          La matrice N x N symétrique définie positive dont les facteurs d'échelle
!>          doivent être calculés. Seuls les éléments diagonaux de A
!>          sont référencés.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est DOUBLE PRECISION
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle par S.
!>

AMAX

!>          AMAX est DOUBLE PRECISION
!>          Valeur absolue de l'élément de matrice le plus grand. Si AMAX est très
!>          proche du dépassement ou très proche de la sous-estimation, la matrice
!>          devrait être mise à l'échelle.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le i-ème élément diagonal est non positif.
!>
