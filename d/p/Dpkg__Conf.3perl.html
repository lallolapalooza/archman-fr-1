NOM

Dpkg::Conf - analyse les fichiers de configuration dpkg

DESCRIPTION

L'objet Dpkg::Conf peut être utilisé pour lire les options d'un fichier de configuration. Il peut exporter un tableau qui peut ensuite être analysé exactement comme @ARGV.

MÉTHODES

$conf = Dpkg::Conf->new(%opts)
Crée un nouvel objet Dpkg::Conf.

Options :

allow_short
Si défini à vrai (la valeur par défaut est faux), alors les options courtes sont autorisées dans le fichier de configuration, elles doivent être précédées d'un seul tiret.
@$conf
@options = $conf->get_options()
Retourne la liste des options qui peuvent être analysées comme @ARGV.
$conf->load($file)
Lit les options à partir d'un fichier. Retourne le nombre d'options analysées.
$conf->load_system_config($file)
Lit les options à partir d'un fichier de configuration système.

Retourne le nombre d'options analysées.

$conf->load_user_config($file)
Lit les options à partir d'un fichier de configuration utilisateur. Il essaiera d'utiliser le répertoire XDG, soit $XDG_CONFIG_HOME/dpkg/ ou $HOME/.config/dpkg/.

Retourne le nombre d'options analysées.

$conf->load_config($file)
Lit les options à partir des fichiers de configuration système et utilisateur.

Retourne le nombre d'options analysées.

$conf->parse($fh)
Analyse les options à partir d'un descripteur de fichier. Lorsque appelé plusieurs fois, les options analysées sont accumulées.

Retourne le nombre d'options analysées.

$conf->filter(%opts)
Filtre la liste des options de configuration.

Options :

remove
Une fonction retournant une valeur booléenne, utilisée pour décider s'il faut supprimer l'option de configuration, exécutée comme $opts{remove}->($option).
keep
Une fonction retournant une valeur booléenne, utilisée pour décider s'il faut conserver l'option de configuration, exécutée comme $opts{keep}->($option).
$string = $conf->output([$fh])
Écrit les options dans le descripteur de fichier donné (s'il est défini) et retourne une représentation textuelle du contenu qui serait écrit.
"$conf"
Retourne une représentation textuelle du contenu.
$conf->save($file)
Sauvegarde les options dans un fichier.
