NOM

Dpkg::Control::HashCore - analyser et manipuler une stanza de champs deb822

DESCRIPTION

La classe Dpkg::Control::Hash est une représentation de type hash d'un ensemble de champs similaires à RFC822. Les noms des champs sont insensibles à la casse et sont toujours capitalisés de la même manière lors de la sortie (voir la fonction field_capitalize() dans Dpkg::Control::Fields). L'ordre dans lequel les champs ont été définis est mémorisé et est utilisé pour pouvoir restituer le même contenu. L'ordre de sortie peut également être annulé si nécessaire.

Vous pouvez stocker des valeurs arbitraires dans le hash, elles seront toujours correctement échappées dans la sortie pour se conformer à la syntaxe des fichiers de contrôle. Ceci est principalement pertinent pour les valeurs multilignes : tandis que la première ligne est toujours sortie inchangée directement après le nom du champ, les lignes supplémentaires sont modifiées. Les lignes vides et les lignes ne contenant que des points sont préfixées par " ." (espace + point) tandis que les autres lignes sont préfixées par un seul espace.

Pendant l'analyse, les espaces de fin sont supprimés sur toutes les lignes tandis que les espaces de début ne sont supprimés que sur la première ligne de chaque champ.

MÉTHODES

$c = Dpkg::Control::Hash->new(%opts)
Crée un nouvel objet avec les options indiquées.

Options :

nom
Le nom convivial des informations stockées dans l'objet. Il peut être utilisé dans certains messages d'erreur ou avertissements. Un nom par défaut peut être défini en fonction du type.
allow_pgp
Configure l'analyseur pour accepter les signatures OpenPGP autour des informations de contrôle. La valeur peut être 0 (par défaut) ou 1.
allow_duplicate
Configure l'analyseur pour autoriser les champs dupliqués dans les informations de contrôle. La dernière valeur remplace toutes les valeurs précédentes. La valeur peut être 0 (par défaut) ou 1.
keep_duplicate
Configure l'analyseur pour conserver les valeurs des champs dupliqués trouvés dans les informations de contrôle (lorsque allow_duplicate est activé), sous forme de références de tableau. La valeur peut être 0 (par défaut) ou 1.
drop_empty
Définit si les champs vides sont supprimés lors de la sortie. La valeur peut être 0 (par défaut) ou 1.
is_pgp_signed
Défini par l'analyseur (à partir de dpkg 1.17.0) s'il trouve une signature OpenPGP autour des informations de contrôle. La valeur peut être 0 (par défaut) ou 1, et undef lorsque l'option n'est pas prise en charge par le code (dans les versions antérieures à dpkg 1.17.0).
$c->set_options($option, %opts)
Modifie la valeur d'une ou plusieurs options.
$value = $c->get_option($option)
Retourne la valeur de l'option correspondante.
$c->parse_error($file, $fmt, ...)
Affiche un message d'erreur et quitte en cas d'erreurs de syntaxe lors de l'analyse.
$c->parse($fh, $description)
Analyse un fichier de contrôle à partir du descripteur de fichier donné. Quitte en cas d'erreurs. $description est utilisé pour décrire le descripteur de fichier, idéalement un nom de fichier ou une description de l'origine des données. Il est utilisé dans les messages d'erreur. Lorsqu'il est appelé plusieurs fois, les champs analysés sont accumulés.

Retourne vrai si des champs ont été analysés.

$c->load($file)
Analyse le contenu de $file. Quitte en cas d'erreurs. Retourne vrai si des champs ont été analysés.
$c->find_custom_field($name)
Scanne les champs et recherche un champ personnalisé dont le nom correspond à l'expression régulière suivante : /X[SBC]*-$name/i. Retourne le nom du champ trouvé ou undef si rien n'a été trouvé.
$c->get_custom_field($name)
Identifie un champ personnalisé et récupère sa valeur.
$str = $c->output()
"$c"
Obtient une représentation sous forme de chaîne des informations de contrôle. Les champs sont triés dans l'ordre dans lequel ils ont été lus ou définis, sauf si l'ordre a été annulé avec set_output_order().
$c->output($fh)
Imprime la représentation sous forme de chaîne des informations de contrôle sur un descripteur de fichier.
$c->save($filename)
Écrit la représentation sous forme de chaîne des informations de contrôle dans un fichier.
$c->set_output_order(@fields)
Définit l'ordre dans lequel les champs seront affichés dans la méthode output().
$c->apply_substvars($substvars)
Met à jour tous les champs en remplaçant les références de variables par la valeur correspondante stockée dans l'objet Dpkg::Substvars.
