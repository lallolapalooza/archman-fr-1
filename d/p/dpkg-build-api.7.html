NOM

dpkg-build-api - niveau d'API de construction de paquet source dpkg

SYNTAXE

Build-Depends:
 dpkg-build-api (= 1),

DESCRIPTION

Le niveau d'API de construction de paquet source dpkg, définit une interface versionnée pour les paquets sources, où chaque niveau d'API fournit des comportements et des garanties spécifiques.

Ces interfaces peuvent alors être adoptées par les paquets de manière progressive, et supprimées plus facilement que les changements de comportement globaux.

La déclaration de cette API est faite via les dépendances de construction, dans l'une des sections Build-Depends, Build-Depends-Indep ou Build-Depends-Arch, ou via la variable d'environnement DPKG_BUILD_API, qui remplacera ces dernières si les deux sont présentes, et pourrait émettre un avertissement si elles sont différentes.

NIVEAUX D'API

v2
Ce niveau est toujours en développement et ne peut pas être déclaré via les dépendances de construction.
v1
C'est le niveau recommandé. Depuis dpkg 1.22.0.

Changements par rapport à v0 :

  • dpkg-shlibdeps n'utilise plus la variable d'environnement LD_LIBRARY_PATH. L'option -l doit être utilisée à la place.
  • dpkg-buildpackage utilise par défaut la valeur no pour Rules-Requires-Root. Pour restaurer le comportement de v0 (d'avant dpkg 1.22.13), Rules-Requires-Root doit être défini à binary-targets.
  • dpkg-buildpackage attend que toutes les cibles requises de debian/rules soient supportées et ne contient plus de code de compatibilité ascendante. Les cibles requises sont clean, build, build-indep, build-arch, binary-indep et binary-arch.
  • vendor.mk utilise par défaut dpkg_vendor_derives_from_v1 pour la macro dpkg_vendor_derives_from. Pour restaurer le comportement de v0, définissez dpkg_vendor_derives_from à dpkg_vendor_derives_from_v0.
  • default.mk inclut par défaut buildtools.mk.
v0
C'est le niveau global actuel, équivalent à ne pas en spécifier. Les interfaces et les comportements fournis sont soumis aux mises à jour normales des interfaces globales, qui ont tendance à nécessiter des cycles de dépréciation plus longs et/ou des transitions coordonnées.
