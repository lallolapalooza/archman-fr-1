NOM

dpkg-scansources - créer des fichiers d'index Sources

SYNTAXE

dpkg-scansources [option...] répertoire-binaire [fichier-de-remplacement [préfixe-chemin]] > Sources

DESCRIPTION

dpkg-scansources scanne le répertoire-binaire donné pour les fichiers .dsc. Ceux-ci sont utilisés pour créer un index source Debian, qui est envoyé sur la sortie standard.

Le fichier-de-remplacement, s'il est donné, est utilisé pour définir les priorités dans les sections d'index résultantes et pour remplacer le champ mainteneur donné dans les fichiers .dsc. Le fichier peut être compressé (depuis dpkg 1.15.5). Voir deb-override(5) pour le format de ce fichier.

Note: Comme le fichier de remplacement est indexé par paquet binaire, et non par paquet source, il y a un léger problème ici. L'implémentation actuelle utilise la priorité la plus élevée de tous les paquets binaires produits par un fichier .dsc pour la priorité du paquet source, et l'entrée de remplacement du premier paquet binaire listé dans le fichier .dsc pour modifier les informations du mainteneur. Cela pourrait changer.

Le préfixe-chemin, s'il est donné, est ajouté devant le champ répertoire dans l'index source généré. Vous l'utilisez généralement pour que les champs répertoire contiennent le chemin depuis le haut de la hiérarchie des archives Debian.

Note: Si vous souhaitez accéder au fichier Sources généré avec apt(8), vous devrez probablement compresser le fichier avec gzip(1) (en générant un fichier Sources.gz). apt(8) ignore les fichiers Sources non compressés, sauf en accès local (c'est-à-dire les sources file://).

OPTIONS

-n, --no-sort
Ne pas trier les sections d'index. Normalement, elles sont triées par nom de paquet source.
-e, --extra-override fichier
Scanner fichier pour trouver des remplacements supplémentaires (depuis dpkg 1.15.4 ; le fichier peut être compressé depuis dpkg 1.15.5). Voir deb-extra-override(5) pour plus d'informations sur son format.
-s, --source-override fichier
Utiliser fichier comme fichier de remplacement source (le fichier peut être compressé depuis dpkg 1.15.5). Par défaut, c'est le nom du fichier de remplacement que vous avez spécifié avec .src ajouté.

Le fichier de remplacement source est dans un format différent de celui du fichier de remplacement binaire. Il contient seulement deux champs séparés par des espaces, le premier est le nom du paquet source et le second est la section. Les lignes vides et les lignes de commentaire sont ignorées de la manière habituelle. Si un paquet apparaît dans les deux fichiers, le remplacement source prend la priorité pour définir la section.

--debug
Activer le débogage.
--help
Afficher le message d'utilisation et quitter.
--version
Afficher la version et quitter.

ENVIRONNEMENT

DPKG_COLORS
Définit le mode couleur (depuis dpkg 1.18.5). Les valeurs actuellement acceptées sont : auto (par défaut), always et never.
DPKG_NLS
Si défini, il sera utilisé pour décider s'il faut activer le support de la langue nationale, également connu sous le nom d'internationalisation (ou i18n) (depuis dpkg 1.19.0). Les valeurs acceptées sont : 0 et 1 (par défaut).

VOIR AUSSI

deb-override(5), deb-extra-override(5), dpkg-scanpackages(1).
