Dpkg::BuildOptions(3perl) libdpkg-perl Dpkg::BuildOptions(3perl)

NOM

Dpkg::BuildOptions - analyser et mettre à jour les options de construction

DESCRIPTION

Cette classe peut être utilisée pour manipuler les options stockées dans des variables d'environnement comme DEB_BUILD_OPTIONS et DEB_BUILD_MAINT_OPTIONS.

MÉTHODES

$bo = Dpkg::BuildOptions->new(%opts)
Crée un nouvel objet Dpkg::BuildOptions. Il sera initialisé en fonction de la valeur de la variable d'environnement nommée DEB_BUILD_OPTIONS.

Options :

envvar
Définit le nom de la variable d'environnement à utiliser au lieu de DEB_BUILD_OPTIONS pour initialiser les indicateurs de construction.
$bo->reset()
Réinitialise l'objet pour qu'il n'ait aucune option (il est vide).
$bo->merge($content, $source)
Fusionne les options définies dans $content et enregistre qu'elles proviennent de la source $source. $source est principalement utilisé dans les messages d'avertissement actuellement pour indiquer où des options invalides ont été détectées.

$content est une liste d'options séparées par des espaces avec des valeurs optionnelles assignées, par exemple « nocheck parallel=2 ».

$bo->set($option, $value, [$source])
Stocke l'option donnée dans l'objet avec la valeur donnée. Il est légitime qu'une valeur soit indéfinie si l'option est un simple booléen (sa présence signifie vrai, son absence signifie faux). La $source est facultative et indique d'où provient l'option.

Les options connues ont leurs valeurs vérifiées pour leur cohérence. Les options sans valeurs voient leur valeur supprimée et les options avec des valeurs invalides sont écartées.

$bo->get($option)
Retourne la valeur associée à l'option. Elle peut être indéfinie même si l'option existe. Vous pourriez vouloir vérifier avec $bo->has($option) pour confirmer si l'option est stockée dans l'objet.
$bo->has($option)
Retourne une valeur booléenne indiquant si l'option est stockée dans l'objet.
$bo->parse_features($option, $use_feature)
Analyse les valeurs de $option, comme un ensemble de caractéristiques connues à activer ou désactiver, tel que spécifié dans la référence de hachage $use_feature.

Chaque caractéristique est préfixée par un caractère '+' ou '-' comme marqueur pour l'activer ou la désactiver. La caractéristique spéciale « all » peut être utilisée pour agir sur toutes les caractéristiques connues.

Les caractéristiques inconnues ou mal formées généreront des avertissements.

$string = $bo->output($fh)
Retourne une représentation textuelle des options de construction adaptée pour être assignée à une variable d'environnement. Peut éventuellement écrire cette chaîne dans le descripteur de fichier donné.
$bo->export([$var])
Exporte les options de construction vers la variable d'environnement donnée. Si omise, la variable d'environnement définie au moment de la création est supposée. La valeur définie pour la variable est également retournée.

CHANGEMENTS

Version 1.02 (dpkg 1.18.19)

Nouvelle méthode : $bo->parse_features().

Version 1.01 (dpkg 1.16.1)

Permet d'utiliser une autre variable d'environnement au lieu de DEB_BUILD_OPTIONS. Ajoute ainsi le support de l'option « envvar » à la création.

Version 1.00 (dpkg 1.15.6)

Marque le module comme public.
