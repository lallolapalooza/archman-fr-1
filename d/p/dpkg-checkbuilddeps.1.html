NOM

dpkg-checkbuilddeps - vérifier les dépendances et conflits de compilation

SYNTAXE

dpkg-checkbuilddeps [option...] [fichier-contrôle]

DESCRIPTION

Ce programme vérifie les paquets installés sur le système par rapport aux dépendances et conflits de compilation listés dans le fichier de contrôle. Si l'une d'entre elles n'est pas satisfaite, elle est affichée et le programme se termine avec un code de retour non nul.

Par défaut, debian/control est lu, mais un nom de fichier de contrôle alternatif peut être spécifié sur la ligne de commande.

OPTIONS

--admindir=dir
Change l'emplacement de la base de données dpkg (depuis dpkg 1.14.0). L'emplacement par défaut est /var/lib/dpkg.
-A
Ignore les lignes Build-Depends-Arch et Build-Conflicts-Arch (depuis dpkg 1.16.4). À utiliser lorsque seuls des paquets indépendants de l'architecture seront construits, ou combinez avec -B lorsque seul un paquet source doit être construit.
-B
Ignore les lignes Build-Depends-Indep et Build-Conflicts-Indep. À utiliser lorsque seuls des paquets dépendants de l'architecture seront construits, ou combinez avec -A lorsque seul un paquet source doit être construit.
-I
Ignore les dépendances et conflits de compilation intégrés (depuis dpkg 1.18.2). Ce sont des dépendances implicites généralement requises sur une distribution spécifique, l'ensemble de paquets dit Build-Essential.
-d chaîne-dépendances-compilation
-c chaîne-conflits-compilation
Utilise les dépendances/conflits de compilation donnés au lieu de ceux contenus dans le fichier debian/control (depuis dpkg 1.14.17).
-a arch
Vérifie les dépendances/conflits de compilation en supposant que le paquet décrit dans le fichier de contrôle est destiné à être construit pour l'architecture hôte donnée au lieu de l'architecture du système actuel (depuis dpkg 1.16.2).
-P profil[,...]
Vérifie les dépendances/conflits de compilation en supposant que le paquet décrit dans le fichier de contrôle est destiné à être construit pour le(s) profil(s) de compilation donné(s) (depuis dpkg 1.17.2). L'argument est une liste de noms de profils séparés par des virgules.
-?, --help
Affiche le message d'utilisation et quitte.
--version
Affiche la version et quitte.

ENVIRONNEMENT

DEB_HOST_ARCH
Définit l'architecture hôte. Cela affecte la logique de résolution des dépendances, qui pourrait alors ne pas correspondre à ce que dpkg du système considère comme satisfiable.
DEB_BUILD_PROFILES
Si défini, il sera utilisé comme profil(s) de compilation actif(s) pour le paquet en cours de construction. C'est une liste de noms de profils séparés par des espaces. Ignoré par l'option -P.
DPKG_COLORS
Définit le mode couleur (depuis dpkg 1.18.5). Les valeurs actuellement acceptées sont : auto (par défaut), always et never.
DPKG_NLS
Si défini, il sera utilisé pour décider s'il faut activer le support des langues naturelles, également connu sous le nom d'internationalisation (ou i18n) (depuis dpkg 1.19.0). Les valeurs acceptées sont : 0 et 1 (par défaut).
