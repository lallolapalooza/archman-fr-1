NOM

Dpkg::Changelog::Entry::Debian - représente une entrée de journal des changements Debian

DESCRIPTION

Cette classe représente une entrée de journal des changements Debian. Elle implémente l'interface générique Dpkg::Changelog::Entry. Seules les fonctions spécifiques à cette implémentation sont décrites ci-dessous, les autres sont héritées.

MÉTHODES

@items = $entry->get_change_items()
Retourne une liste d'éléments de changement. Chaque élément contient au moins une ligne. Une ligne de changement commençant par un astérisque indique le début d'un nouvel élément. Toute ligne de changement comme ""[ Raphaël Hertzog ]"" est traitée comme un élément à part entière, même si elle commence un ensemble d'éléments attribués à cette personne (la ligne suivante commencera nécessairement un nouvel élément).
@errors = $entry->parse_header()
@errors = $entry->parse_trailer()
Retourne une liste d'erreurs. Chaque élément de la liste est un message d'erreur décrivant le problème. Si la liste vide est retournée, aucune erreur n'a été trouvée.
$entry->normalize()
Normalise le contenu. Supprime les espaces en fin de ligne, utilise une seule ligne vide pour séparer chaque partie.
$src = $entry->get_source()
Retourne le nom du paquet source associé à l'entrée du journal des changements.
$ver = $entry->get_version()
Retourne la version associée à l'entrée du journal des changements.
@dists = $entry->get_distributions()
Retourne une liste des distributions cibles pour cette version.
$ctrl = $entry->get_optional_fields()
Retourne un ensemble de champs optionnels exposés par l'entrée du journal des changements. Elle retourne toujours un objet Dpkg::Control (qui peut être vide).
$urgency = $entry->get_urgency()
Retourne l'urgence du téléversement associé.
$maint = $entry->get_maintainer()
Retourne la chaîne identifiant la personne qui a signé cette entrée de journal des changements.
$time = $entry->get_timestamp()
Retourne l'horodatage de l'entrée du journal des changements.
$time = $entry->get_timepiece()
Retourne l'horodatage de l'entrée du journal des changements sous forme d'un objet Time::Piece.

Cette fonction peut retourner undef s'il n'y avait pas d'horodatage.

FONCTIONS UTILITAIRES

$bool = match_header($line)
Vérifie si la ligne correspond à une ligne d'en-tête valide du journal des changements.
$bool = match_trailer($line)
Vérifie si la ligne correspond à une ligne de pied de page valide du journal des changements.
@closed_bugs = find_closes($changes)
Prend une chaîne de caractères en argument et recherche les déclarations "Closes: #123456, #654321" telles que supportées par le logiciel d'archive Debian. Retourne tous les numéros de bugs fermés dans un tableau.
