NOM

dpkg-divert - remplacer la version d'un fichier fournie par un paquet

SYNOPSIS

dpkg-divert [option...] commande

DESCRIPTION

dpkg-divert est l'utilitaire utilisé pour configurer et mettre à jour la liste des détournements.

Les détournements de fichiers sont un moyen de forcer dpkg(1) à ne pas installer un fichier à son emplacement, mais à un emplacement détourné . Les détournements peuvent être utilisés dans les scripts de mainteneur de paquets pour déplacer un fichier lorsqu'il cause un conflit. Les administrateurs système peuvent également les utiliser pour remplacer le fichier de configuration de certains paquets, ou chaque fois que certains fichiers (qui ne sont pas marqués comme « conffiles ») doivent être préservés par dpkg, lors de l'installation d'une version plus récente d'un paquet contenant ces fichiers.

COMMANDES

[--add] fichier
Ajouter un détournement pour fichier. Le fichier n'est actuellement pas renommé, voir --rename.
--remove fichier
Supprimer un détournement pour fichier. Le fichier n'est actuellement pas renommé, voir --rename.
--list [motif-glob]
Lister tous les détournements, ou ceux correspondant à motif-glob.
--listpackage fichier
Afficher le nom du paquet qui détourne fichier (depuis dpkg 1.15.0). Affiche LOCAL si fichier est détourné localement et rien si fichier n'est pas détourné.
--truename fichier
Afficher le nom réel d'un fichier détourné.

OPTIONS

--admindir répertoire
Définir le répertoire d'administration sur répertoire. Par défaut, c'est «/var/lib/dpkg» si DPKG_ADMINDIR n'a pas été défini.
--instdir répertoire
Définir le répertoire d'installation, qui fait référence au répertoire où les paquets sont installés (depuis dpkg 1.19.2). Par défaut, c'est «/» si DPKG_ROOT n'a pas été défini.
--root répertoire
Définir le répertoire racine sur répertoire, ce qui définit le répertoire d'installation sur «répertoire» et le répertoire d'administration sur «répertoire/var/lib/dpkg» (depuis dpkg 1.19.2) si DPKG_ROOT n'a pas été défini.
--divert détourné-vers
détourné-vers est l'emplacement où les versions de fichier, telles que fournies par d'autres paquets, seront détournées.
--local
Spécifie que toutes les versions de ce fichier fournies par les paquets sont détournées. Cela signifie qu'il n'y a pas d'exceptions, et quel que soit le paquet installé, le fichier est détourné. Cela peut être utilisé par un administrateur pour installer une version modifiée localement.
--package paquet
paquet est le nom d'un paquet dont la copie de fichier ne sera pas détournée, c.-à-d. fichier sera détourné pour tous les paquets sauf paquet.
--quiet
Mode silencieux, c.-à-d. aucune sortie verbeuse.
--rename
Déplacer réellement le fichier de côté (ou le remettre). dpkg-divert interrompra l'opération si le fichier de destination existe déjà. C'est le comportement courant utilisé pour les détournements de fichiers provenant de l'ensemble de paquets nonessentiels (voir --no-rename pour plus de détails).
--no-rename
Spécifie que le fichier ne doit pas être renommé lors de l'ajout ou de la suppression du détournement dans la base de données (depuis dpkg 1.19.1). C'est destiné aux détournements de fichiers provenant de l'ensemble de paquets essentiels , où la disparition temporaire du fichier original n'est pas acceptable, car elle peut rendre le système non fonctionnel. C'est le comportement par défaut, mais cela changera dans le cycle dpkg 1.20.x.
--test
Mode test, c.-à-d. ne pas effectuer réellement de changements, juste démontrer.
-?, --help
Afficher le message d'utilisation et quitter.
--version
Afficher la version et quitter.

CODE DE RETOUR

0
L'action demandée a été effectuée avec succès.
2
Erreur fatale ou irrécupérable due à une utilisation invalide de la ligne de commande, ou à des interactions avec le système, telles que des accès à la base de données, des allocations de mémoire, etc.

ENVIRONNEMENT

DPKG_ROOT
S'il est défini et que les options --instdir ou --root n'ont pas été spécifiées, il sera utilisé comme répertoire racine du système de fichiers (depuis dpkg 1.19.2).
DPKG_ADMINDIR
S'il est défini et que les options --admindir ou --root n'ont pas été spécifiées, il sera utilisé comme répertoire de données dpkg .
DPKG_MAINTSCRIPT_PACKAGE
S'il est défini et que les options --local et --package n'ont pas été spécifiées, dpkg-divert l'utilisera comme nom de paquet.
DPKG_DEBUG
Définit le masque de débogage (depuis dpkg 1.21.10) à partir d'une valeur octale. Les indicateurs actuellement acceptés sont décrits dans l'option dpkg --debug , mais tous ces indicateurs peuvent ne pas avoir d'effet sur ce programme.
DPKG_COLORS
Définit le mode couleur (depuis dpkg 1.18.5). Les valeurs actuellement acceptées sont : auto (par défaut), always et never.
DPKG_NLS
S'il est défini, il sera utilisé pour décider s'il faut activer la prise en charge des langues natives, également connue sous le nom de prise en charge de l'internationalisation (ou i18n) (depuis dpkg 1.22.7). Les valeurs acceptées sont : 0 et 1 (par défaut).

FICHIERS

/var/lib/dpkg/diversions
Fichier qui contient la liste actuelle des détournements du système. Il est situé dans le répertoire d'administration dpkg , avec d'autres fichiers importants pour dpkg, tels que status ou available.

Remarque: dpkg-divert conserve l'ancienne copie de ce fichier, avec l'extension -old, avant de la remplacer par la nouvelle.

NOTES

Lors de l'ajout, la valeur par défaut est --local et --divert original.distrib. Lors de la suppression, --package ou --local et --divert doivent correspondre s'ils sont spécifiés.

Les répertoires ne peuvent pas être détournés avec dpkg-divert.

Il faut faire attention lors du détournement de bibliothèques partagées, ldconfig(8) crée un lien symbolique basé sur le champ DT_SONAME intégré dans la bibliothèque. Comme ldconfig ne prend pas en compte les détournements (seul dpkg le fait), le lien symbolique peut finir par pointer vers la bibliothèque détournée, si une bibliothèque détournée a le même SONAME que celle non détournée.

EXEMPLES

Pour détourner toutes les copies d'un /usr/bin/example vers /usr/bin/example.foo, c.-à-d. indiquer à tous les paquets fournissant /usr/bin/example de l'installer comme /usr/bin/example.foo, en effectuant le renommage si nécessaire :

dpkg-divert --divert /usr/bin/example.foo --rename /usr/bin/example

Pour supprimer ce détournement :

dpkg-divert --rename --remove /usr/bin/example

Pour détourner tout paquet essayant d'installer /usr/bin/example vers /usr/bin/example.foo, sauf les vôtres wibble paquet :

dpkg-divert --package wibble --divert /usr/bin/example.foo \
   --rename /usr/bin/example

Pour supprimer cette diversion :

dpkg-divert --package wibble --rename --remove /usr/bin/example
