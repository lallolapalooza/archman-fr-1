NOM

dpkg-buildtree - utilitaire d'aide pour les opérations sur l'arbre de construction pendant la compilation de paquets

SYNTAXE

dpkg-buildtree [option...] [commande]

DESCRIPTION

dpkg-buildtree est un outil pour effectuer des opérations courantes sur l'arbre de construction d'un paquet source.

Ce programme a été introduit dans dpkg 1.22.3.

COMMANDES

nettoyer
Supprime tous les artefacts générés pendant une compilation par les divers outils dpkg, et les noms de chemins utilisés ou contrôlés par les outils dpkg qui peuvent être nettoyés en toute sécurité. Ces fichiers sont utilisés pour suivre l'état entre les exécutions de compilation de paquets, et sont dans de nombreux cas des détails d'implémentation internes dont le responsable de paquet ne devrait pas se soucier, ou ce sont des répertoires intermédiaires contenant des artefacts de compilation.
est-sans-racine
Vérifie si l'arbre de construction peut être construit sans privilèges root (depuis dpkg 1.22.12).

Cette commande peut être utilisée en toute sécurité même avec des versions où la commande n'était pas encore disponible, car la valeur par défaut sera alors celle historique où root était requis.

--help
Affiche le message d'utilisation et quitte.
--version
Affiche la version et quitte.

ENVIRONNEMENT

DPKG_COLORS
Définit le mode couleur. Les valeurs actuellement acceptées sont : auto (par défaut), always (toujours) et never (jamais).
DPKG_NLS
Si défini, il sera utilisé pour décider si le support de la langue native, également appelé internationalisation (ou i18n), doit être activé. Les valeurs acceptées sont : 0 et 1 (par défaut).

FICHIERS

Fichiers nettoyés

debian/files
debian/files.new
Fichiers générés par dpkg-distaddfile(1).
debian/substvars
debian/substvars.new
Fichiers générés par dpkg-shlibdeps(1).
debian/tmp
Répertoire intermédiaire contenant le contenu à utiliser lors de la création d'un paquet. dpkg-gencontrol(1) et dpkg-gensymbols(1) génèrent des fichiers à l'intérieur.

EXEMPLES

Utilisation dans debian/rules

Vous pouvez appeler dpkg-buildtree clean depuis la cible clean de debian/rules, après avoir effectué les autres nettoyages nécessaires.

Par exemple, pour un système de construction de type autoconf :

clean:
      [ ! -f Makefile ] || $(MAKE) distclean
      dpkg-buildtree clean
