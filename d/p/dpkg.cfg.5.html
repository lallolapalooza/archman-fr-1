NOM

dpkg.cfg - fichier de configuration de dpkg

DESCRIPTION

Ce fichier contient les options par défaut pour dpkg. Chaque ligne contient une seule option qui est exactement identique à une option de ligne de commande normale pour dpkg, à l'exception des tirets initiaux qui ne sont pas utilisés ici. Les guillemets entourant les valeurs des options sont supprimés. Les commentaires sont autorisés en commençant une ligne par un signe dièse (‘#’).

FICHIERS
