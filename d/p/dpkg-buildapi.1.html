NOM

dpkg-buildapi - retourne le niveau de l'API de construction à utiliser lors de la construction de paquets

SYNTAXE

dpkg-buildapi [option...] [commande]

DESCRIPTION

dpkg-buildapi est un outil pour récupérer le niveau de l'API dpkg-build-api(7) à utiliser lors de la construction de paquets source Debian.

Ce programme a été introduit dans dpkg 1.22.0.

COMMANDES

--help
Affiche le message d'utilisation et quitte.
--version
Affiche la version et quitte.

OPTIONS

-cfichier-contrôle
Spécifie le fichier de contrôle source principal à partir duquel lire les informations. La valeur par défaut est debian/control.

ENVIRONNEMENT

DPKG_BUILD_API
Le niveau de l'API de construction à utiliser. Ceci est destiné à être utilisé en interne par les outils exécutés depuis debian/rules afin d'éviter d'avoir à analyser debian/control plusieurs fois, et non pour définir le niveau global de l'API de construction depuis debian/rules, sinon les pilotes de construction (tels que dpkg-buildpackage(1)) ne pourront pas y accéder.
DPKG_COLORS
Définit le mode couleur. Les valeurs actuellement acceptées sont : auto (par défaut), always (toujours) et never (jamais).
DPKG_NLS
Si définie, elle sera utilisée pour décider s'il faut activer le support des langues natives, également connu sous le nom d'internationalisation (ou i18n). Les valeurs acceptées sont : 0 et 1 (par défaut).

FICHIERS

Support d'empaquetage

/usr/share/dpkg/buildapi.mk
Extrait de Makefile qui analyse le niveau de l'API de construction dans une variable.
