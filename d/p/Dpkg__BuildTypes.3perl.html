NOM

Dpkg::BuildTypes - suivre les types de construction

DESCRIPTION

Le module Dpkg::BuildTypes est utilisé par divers outils pour suivre et décider quels artefacts doivent être construits.

Les types de construction sont des constantes binaires qui sont exportées par défaut. Plusieurs types peuvent être combinés par OU (OR).

Note : Il s'agit d'un module privé, son API peut changer à tout moment.

CONSTANTES

BUILD_DEFAULT
Cette construction est la valeur par défaut.
BUILD_SOURCE
Cette construction inclut les artefacts sources.
BUILD_ARCH_DEP
Cette construction inclut les artefacts binaires dépendants de l'architecture.
BUILD_ARCH_INDEP
Cette construction inclut les artefacts binaires indépendants de l'architecture.
BUILD_BINARY
Cette construction inclut les artefacts binaires.
BUILD_FULL
Cette construction inclut les artefacts sources et binaires.

FONCTIONS

build_has_any($bits)
Retourne une valeur booléenne indiquant si le type de construction actuel contient l'un des $bits spécifiés.
build_has_all($bits)
Retourne une valeur booléenne indiquant si le type de construction actuel contient tous les $bits spécifiés.
build_has_none($bits)
Retourne une valeur booléenne indiquant si le type de construction actuel ne contient aucun des $bits spécifiés.
build_is($bits)
Retourne une valeur booléenne indiquant si le type de construction actuel est l'ensemble spécifié de $bits.
set_build_type($build_type, $build_option, %opts)
Définit le type de construction actuel sur $build_type, qui a été spécifié via l'option de ligne de commande $build_option.

La fonction vérifiera et arrêtera les affectations de types de construction incompatibles, ce comportement peut être désactivé en utilisant l'option booléenne "nocheck".

set_build_type_from_options($build_types, $build_option, %opts)
Définit le type de construction actuel à partir d'une liste de composants de type de construction séparés par des virgules.

La fonction vérifiera et arrêtera les affectations de types de construction incompatibles, ce comportement peut être désactivé en utilisant l'option booléenne "nocheck".

set_build_type_from_targets($build_targets, $build_option, %opts)
Définit le type de construction actuel à partir d'une liste de composants de cible de construction séparés par des virgules.

La fonction vérifiera et arrêtera les affectations de types de construction incompatibles, ce comportement peut être désactivé en utilisant l'option booléenne "nocheck".

get_build_options_from_type()
Obtient le type de construction actuel sous forme d'un ensemble d'options séparées par des virgules.
