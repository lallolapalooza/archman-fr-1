NOM

Dpkg::Compression::Process - exécuter des processus de compression/décompression

DESCRIPTION

Ce module fournit une interface orientée objet pour exécuter et gérer des processus de compression/décompression.

MÉTHODES

$proc = Dpkg::Compression::Process->new(%opts)
Crée une nouvelle instance de l'objet.

Options :

compression
Voir $proc->set_compression().
compression_level
Voir $proc->set_compression_level().
$proc->set_compression($comp)
Sélectionne la méthode de compression à utiliser. Une erreur est générée si la méthode n'est pas supportée selon compression_is_supported() (de Dpkg::Compression).
$proc->set_compression_level($level)
Sélectionne le niveau de compression à utiliser. Une erreur est générée si le niveau n'est pas valide selon compression_is_valid_level() (de Dpkg::Compression).
@exec = $proc->get_compress_cmdline()
@exec = $proc->get_uncompress_cmdline()
Retourne une liste prête à être passée à exec(), son premier élément est le nom du programme (soit pour la compression, soit pour la décompression) et les éléments suivants sont les paramètres du programme.

Lorsqu'il est exécuté, le programme agit comme un filtre entre son entrée standard et sa sortie standard.

$proc->compress(%opts)
Démarre un programme compresseur. Vous devez indiquer d'où il lira ses données non compressées et où il écrira ses données compressées. Ceci est réalisé en passant un paramètre "to_*" et un paramètre "from_*" tels qu'acceptés par Dpkg::IPC::spawn().

Vous devez appeler wait_end_process() après avoir appelé cette méthode pour fermer correctement le sous-processus (et vérifier qu'il s'est terminé sans erreur).

Options :

Voir Dpkg::IPC::spawn().

$proc->uncompress(%opts)
Démarre un programme décompresseur. Vous devez indiquer d'où il lira ses données compressées et où il écrira ses données non compressées. Ceci est réalisé en passant un paramètre "to_*" et un paramètre "from_*" tels qu'acceptés par Dpkg::IPC::spawn().

Vous devez appeler wait_end_process() après avoir appelé cette méthode pour fermer correctement le sous-processus (et vérifier qu'il s'est terminé sans erreur).

Options :

Voir Dpkg::IPC::spawn().

$proc->wait_end_process(%opts)
Appelle Dpkg::IPC::wait_child() pour attendre que le sous-processus se termine et vérifier son code de retour. Toute option donnée sera transmise à la fonction wait_child(). Notamment, vous pouvez utiliser l'option "nocheck" pour vérifier vous-même le code de retour au lieu de laisser wait_child() le faire à votre place.

Options :

Voir Dpkg::IPC::wait_child().
