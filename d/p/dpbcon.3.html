sous-programme dpbcon (caractère uplo, entier n, entier kd, double précision, dimension( ldab, * ) ab, entier ldab, double précision anorm, double précision rcond, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier info)

DPBCON

But:

!>
!> DPBCON estime l'inverse du nombre de conditionnement (en norme
!> 1) d'une matrice bande symétrique réelle définie positive A, en utilisant
!> la factorisation de Cholesky A = U**T*U ou A = L*L**T calculée par DPBTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et l'inverse du nombre de
!> conditionnement est calculé comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U':  Le facteur triangulaire supérieur est stocké dans AB;
!>          = 'L':  Le facteur triangulaire inférieur est stocké dans AB.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est ENTIER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau de DOUBLE PRECISION, dimension (LDAB,N)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T de la matrice bande A, stocké dans les
!>          KD+1 premières lignes du tableau.  La j-ème colonne de U ou L est
!>          stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO ='U', AB(kd+1+i-j,j) = U(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO ='L', AB(1+i-j,j)    = L(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

ANORM

!>          ANORM est DOUBLE PRECISION
!>          La norme 1 (ou norme infinie) de la matrice bande symétrique A.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'inverse du nombre de conditionnement de la matrice A,
!>          calculé comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, dimension (3*N)
!>

IWORK

!>          IWORK est un tableau de ENTIER, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortée avec succès
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
