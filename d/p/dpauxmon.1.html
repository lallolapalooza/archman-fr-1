NOM

dpauxmon - Fournir des interfaces pour capturer des données du canal AUX de DisplayPort.

SYNTAXE

dpauxmon [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interface> ] [ --extcap-config ] [ --extcap-capture-filter=<capture filter> ] [ --capture ] [ --fifo=<chemin vers fichier ou tube> ] [ --interface_id=<ID d'interface à capturer> ]

dpauxmon --extcap-interfaces

dpauxmon --extcap-interface=<interface> --extcap-dlts

dpauxmon --extcap-interface=<interface> --extcap-config

dpauxmon --extcap-interface=<interface> --fifo=<chemin vers fichier ou tube> --capture --interface_id=interface_id

DESCRIPTION

dpauxmon est un outil extcap qui peut capturer des données du canal AUX de DisplayPort à partir des pilotes du noyau Linux en utilisant l'interface netlink générique.

Interfaces supportées:

1.dpauxmon

OPTIONS

--help

Affiche les arguments du programme.

--version

Affiche la version du programme.

--extcap-interfaces

Liste les interfaces disponibles.

--extcap-interface=<interface>

Utilise les interfaces spécifiées.

--extcap-dlts

Liste les DLTs de l'interface spécifiée.

--extcap-config

Liste les options de configuration de l'interface spécifiée.

--capture

Démarre la capture à partir de l'interface spécifiée et l'enregistre à l'emplacement spécifié par --fifo.

--fifo=<chemin vers fichier ou tube>

Enregistre le paquet capturé dans un fichier ou l'envoie via un tube.

--interface_idt=<identifiant d'interface>

L'interface pour la capture.

EXEMPLES

Pour voir les arguments du programme :

dpauxmon --help

Pour voir la version du programme :

dpauxmon --version

Pour voir les interfaces :

dpauxmon --extcap-interfaces

Une seule interface (dpauxmon) est supportée.

Exemple de sortie

interface {value=dpauxmon}{display=Capture du canal AUX DisplayPort}

Pour voir les DLTs de l'interface :

dpauxmon --extcap-interface=dpauxmon --extcap-dlts

Exemple de sortie

dlt {number=275}{name=dpauxmon}{display=DLT du moniteur du canal AUX DisplayPort}

Pour voir les options de configuration de l'interface :

dpauxmon --extcap-interface=dpauxmon --extcap-config

Exemple de sortie

dpauxmon --extcap-interface=dpauxmon --extcap-config
arg {number=0}{call=--interface_id}{display=ID d'interface}
    {type=unsigned}{tooltip=L'ID d'interface}
    {required=true}

Pour capturer :

dpauxmon --extcap-interface=dpauxmon --fifo=/tmp/dpauxmon.pcap --capture --interface_id 0
