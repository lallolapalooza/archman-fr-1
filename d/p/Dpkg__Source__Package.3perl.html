DESCRIPTIO

N

Ce module fournit une classe capable de manipuler les paquets source Debian. Bien qu'i

l prenne en charge à la fois l'extraction et la création de paquets source, la seule
API officiellement prise en charge est celle qui permet l'extraction du paquet source.

Vérifie les sommes de contrôle intégrées au fichier DSC. Cela nécessite la présence des autres fichiers constituant le paquet source. Si une incohérence est découverte, une erreur est immédiatement levée. Elle s'assure qu'au moins une somme de contrôle forte est présente.

Convertit une signature d'un format binaire vers un format ASCII blindé. Si le fichier de signature n'existe pas, l'opération est sans effet. Si le fichier de signature est déjà en format ASCII blindé, il est simplement copié, sinon il est converti du format binaire vers le format ASCII

Vérifie les signatures des tarballs amont originaux @asc en utilisant les clés publiques amont. Si une incohérence est découverte, une erreur est immédiatement
