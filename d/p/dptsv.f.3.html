Documentation de fonction/sous-programme

sous-programme dptsv (entier n, entier nrhs, double précision, dimension( * ) d, double précision, dimension( * ) e, double précision, dimension( ldb, * ) b, entier ldb, entier info)

DPTSV calcule la solution du système d'équations linéaires A * X = B pour les matrices PT

Objectif :

!>
!> DPTSV calcule la solution d'un système réel d'équations linéaires
!> A*X = B, où A est une matrice tridiagonale symétrique définie positive
!> N-par-N, et X et B sont des matrices N-par-NRHS.
!>
!> A est factorisée comme A = L*D*L**T, et la forme factorisée de A est ensuite
!> utilisée pour résoudre le système d'équations.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, de dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A. À la sortie, les n éléments diagonaux de la matrice diagonale
!>          D de la factorisation A = L*D*L**T.
!>

E

!>          E est un tableau de DOUBLE PRÉCISION, de dimension (N-1)
!>          À l'entrée, les (n-1) éléments sous-diagonaux de la matrice
!>          tridiagonale A. À la sortie, les (n-1) éléments sous-diagonaux du
!>          facteur bidiagonal unitaire L de la factorisation L*D*L**T de
!>          A. (E peut aussi être considéré comme la superdiagonale du
!>          facteur bidiagonal unitaire U de la factorisation U**T*D*U de
!>          A.)
!>

B

!>          B est un tableau de DOUBLE PRÉCISION, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B des membres de droite N-par-NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X N-par-NRHS.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                n'est pas positif, et la solution n'a pas été
!>                calculée. La factorisation n'a pas été achevée
!>                sauf si i = N.
!>
