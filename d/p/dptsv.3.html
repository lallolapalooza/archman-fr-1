Documentation de fonction/sous-programme

sous-programme dptsv (entier n, entier nrhs, double précision, dimension( * ) d, double précision, dimension( * ) e, double précision, dimension( ldb, * ) b, entier ldb, entier info)

DPTSV calcule la solution du système d'équations linéaires A * X = B pour les matrices PT

Objectif :

!>
!> DPTSV calcule la solution d'un système linéaire réel
!> A*X = B, où A est une matrice tridiagonale symétrique définie positive
!> de taille N x N, et X et B sont des matrices N x NRHS.
!>
!> A est factorisée comme A = L*D*L**T, et la forme factorisée de A est alors
!> utilisée pour résoudre le système d'équations.
!>

Paramètres

N 
!>          N est ENTIER
!>          Ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, de dimension (N)
!>          À l'entrée, les N éléments diagonaux de la matrice tridiagonale
!>          A.  À la sortie, les N éléments diagonaux de la matrice diagonale
!>          D de la factorisation A = L*D*L**T.
!>

E

!>          E est un tableau DOUBLE PRÉCISION, de dimension (N-1)
!>          À l'entrée, les N-1 éléments sous-diagonaux de la matrice tridiagonale
!>          A.  À la sortie, les N-1 éléments sous-diagonaux du facteur
!>          bidiagonal unitaire L de la factorisation L*D*L**T de
!>          A.  (E peut également être considéré comme la superdiagonale du facteur
!>          bidiagonal unitaire U de la factorisation U**T*D*U de A.)
!>

B

!>          B est un tableau DOUBLE PRÉCISION, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B du côté droit de taille N x NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                n'est pas positif, et la solution n'a pas été
!>                calculée.  La factorisation n'a pas été terminée
!>                sauf si i = N.
!>
