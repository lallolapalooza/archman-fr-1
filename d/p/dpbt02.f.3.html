sous-routine dpbt02 (caractère uplo, entier n, entier kd, entier nrhs, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( ldx, * ) x, entier ldx, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( * ) rwork, double précision resid)

DPBT02

But :

!>
!> DPBT02 calcule le résidu d'une solution d'un système d'équations
!> hermitien par bande  A*x = b:
!>    RESID = norm( B - A*X ) / ( norm(A) * norm(X) * EPS)
!> où EPS est la précision machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure
!>          de la matrice A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits. NRHS >= 0.
!>

A

!>          A est un tableau DOUBLE PRÉCISION, de dimension (LDA,N)
!>          La matrice hermitienne par bande originale A. Si UPLO = 'U',
!>          la partie triangulaire supérieure de A est stockée comme une
!>          matrice par bande ; si UPLO = 'L', la partie triangulaire
!>          inférieure de A est stockée. Les colonnes de la
!>          triangle approprié sont stockées dans les colonnes
!>          de A et les diagonales du triangle sont stockées dans les lignes
!>          de A.  Voir DPBTRF pour plus de détails.
!>

LDA

!>          LDA est INTEGER.
!>          La dimension principale du tableau A.  LDA >= max(1,KD+1).
!>

X

!>          X est un tableau DOUBLE PRÉCISION, de dimension (LDX,NRHS)
!>          Les vecteurs solution calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.   LDX >= max(1,N).
!>

B

!>          B est un tableau DOUBLE PRÉCISION, de dimension (LDB,NRHS)
!>          À l'entrée, les vecteurs du côté droit pour le système d'équations
!>          linéaires.
!>          À la sortie, B est écrasé par la différence B - A*X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, de dimension (N)
!>

RESID

!>          RESID est DOUBLE PRÉCISION
!>          Le maximum sur le nombre de côtés droits de
!>          norm(B - A*X) / ( norm(A) * norm(X) * EPS ).
!>
