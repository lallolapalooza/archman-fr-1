NOM

Dpkg::Gettext - enveloppe pratique autour de Locale::gettext

DESCRIPTION

Le module Dpkg::Gettext est une enveloppe pratique du module Locale::gettext, pour garantir que nous avons toujours des fonctions gettext qui fonctionnent, et pour ajouter des alias couramment utilisés.

ENVIRONNEMENT

DPKG_NLS
Lorsqu'elle est définie à 0, cette variable d'environnement désactivera le Support Linguistique National dans tous les modules Dpkg.

VARIABLES

$Dpkg::Gettext::DEFAULT_TEXT_DOMAIN
Spécifie le nom du domaine de texte par défaut à utiliser avec les alias de fonction courts. Ceci est destiné à être utilisé par les modules Dpkg, de sorte qu'ils puissent produire des messages localisés même lorsque le programme appelant a défini le domaine courant avec textdomain(). Si vous souhaitez utiliser les alias pour vos propres modules, vous pourriez vouloir définir cette variable à undef, ou à un autre domaine, mais alors les modules Dpkg ne produiront pas de messages localisés.

FONCTIONS

$domain = textdomain($new_domain)
Fallback de compatibilité textdomain() lorsque Locale::gettext n'est pas disponible.

Si $new_domain n'est pas undef, il définira le domaine courant à $new_domain. Retourne le domaine courant, après l'avoir éventuellement modifié.

$trans = gettext($msgid)
Fallback de compatibilité gettext() lorsque Locale::gettext n'est pas disponible.

Retourne $msgid.

$trans = ngettext($msgid, $msgid_plural, $n)
Fallback de compatibilité ngettext() lorsque Locale::gettext n'est pas disponible.

Retourne $msgid si $n est 1 ou $msgid_plural sinon.

$trans = g_($msgid)
Appelle dgettext() sur le $msgid et retourne sa traduction pour la locale courante. Si dgettext() n'est pas disponible, retourne simplement $msgid.
$trans = C_($msgctxt, $msgid)
Appelle dgettext() sur le $msgid et retourne sa traduction pour le $msgctxt spécifique fourni. Si dgettext() n'est pas disponible, retourne simplement $msgid.
$trans = P_($msgid, $msgid_plural, $n)
Appelle dngettext(), retournant la traduction correcte pour la forme plurielle en fonction de $n. Si dngettext() n'est pas disponible, retourne $msgid si $n est 1 ou $msgid_plural sinon.
$msgid = N_($msgid)
Une pseudo-fonction servant de marqueur pour l'extraction automatique des messages, mais n'appelle pas gettext(). La traduction à l'exécution se fait à un autre endroit du code.
