Documentation de la fonction/sous-routine

sous-routine dpptrs (caractère uplo, entier n, entier nrhs, double précision, dimension( * ) ap, double précision, dimension( ldb, * ) b, entier ldb, entier info)

DPPTRS

But :

!>
!> DPPTRS résout un système d'équations linéaires A*X = B avec une matrice A symétrique
!> définie positive en stockage compact, en utilisant la factorisation de Cholesky
!> A = U**T*U ou A = L*L**T calculée par DPPTRF.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U': le triangle supérieur de A est stocké ;
!>          = 'L': le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AP

!>          AP est un tableau DOUBLE PRECISION, de dimension (N*(N+1)/2)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T, stocké compact par colonne dans un
!>          tableau linéaire.  La j-ième colonne de U ou L est stockée dans le tableau AP
!>          comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) pour j<=i<=n.
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice du côté droit B.
!>          À la sortie, la matrice solution X.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>
