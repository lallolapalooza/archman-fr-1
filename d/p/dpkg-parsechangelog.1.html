FORMATS DU JOURNAL DES

MODIFICATIONS

Il est possible d'utiliser un format différent du format standard, en fournissant un analyseur pour ce format

alternatif.

Afin que dpkg-parsechangelog exécute le nouvel analyseur, une ligne doit être incluse dans les 40 dernières lignes du fichier du journal des modifications, correspondant à l'expression régulière Perl : «\schangelog-format:\s+([0-9a-z]+)\W ». La partie entre parenthèses devrait être le nom du format. Par exemple

:
@@@ changelog-format : otherforma
t @@@

Les noms de formats de journal des modifications sont des chaînes non vides de caractères alphanumériques minuscules (« a-z0-9 »)

.

Si une telle ligne existe, alors dpkg-parsechangelog cherchera l'analyseur sous la forme d'un module perl Dpkg::Changelog::Otherformat ; c'est une erreur qu'il ne soit pas présent. Le nom de l'analyseur dans le module perl sera automatiquement mis en majuscule. Le format de journal des modifications par défaut est debian, et un analyseur est fourni par défaut pour

celui-ci.

L'analyseur devrait être dérivé de la classe Dpkg::Changelog et implémenter l'interface documentée

requise.

Si le format de journal des modifications qui est analysé laisse toujours ou presque toujours une ligne vide entre les notes de changement individuelles, ces lignes vides devraient être supprimées afin de rendre la sortie résultante

compacte.

Si le format de journal des modifications ne contient pas d'informations de date ou de nom de paquet, ces informations devraient être omises de la sortie. L'analyseur ne devrait pas tenter de les synthétiser ou de les trouver à partir d'autres sources.r

sources.

Si le journal des modifications n'a pas le format attendu, l'analyseur doit signaler une erreur plutôt que d'essayer de s'en sortir et de générer éventuellement une sortie

incorrecte.

Un analyseur de journal des m

odifications ne doit pas inte
ragir avec l'utilisateur.
