NOM

dpkg-genchanges - génère des fichiers .changes Debian

SYNTAXE

dpkg-genchanges [option...]

DESCRIPTION

dpkg-genchanges lit des informations à partir d'un arbre source Debian décompressé et construit, ainsi que des fichiers qu'il a générés, et crée un fichier de contrôle de téléversement Debian (fichier .changes).

OPTIONS

--build=type
Spécifie le type de construction à partir d'une liste de composants séparés par des virgules (depuis dpkg 1.18.5).

Les valeurs autorisées sont :

source
Téléverse le paquet source.
any
Téléverse les paquets binaires spécifiques à l'architecture.
all
Téléverse les paquets binaires indépendants de l'architecture.
binary
Téléverse les paquets binaires spécifiques et indépendants de l'architecture. C'est un alias pour any,all.
full
Téléverse tout. C'est un alias pour source,any,all, et identique au cas par défaut lorsqu'aucune option de construction n'est spécifiée.
-g
Équivalent à --build=source,all (depuis dpkg 1.17.11).
-G
Équivalent à --build=source,any (depuis dpkg 1.17.11).
-b
Équivalent à --build=binary ou --build=any,all.
-B
Équivalent à --build=any.
-A
Équivalent à --build=all.
-S
Équivalent à --build=source.

Les options -sx contrôlent si l'archive source originale est incluse dans le téléversement si des sources sont générées (c'est-à-dire si -b ou -B n'ont pas été utilisés).

-si
Par défaut, ou si spécifié, la source originale sera incluse seulement si le numéro de version amont (la version sans epoch et sans révision Debian) diffère du numéro de version amont de la précédente entrée du journal des modifications.
-sa
Force l'inclusion de la source originale.
-sd
Force l'exclusion de la source originale et inclut seulement le diff.
-vversion
Utilise les informations du journal des modifications de toutes les versions strictement postérieures à version.
-Cdescription-changes
Lit la description des modifications depuis le fichier description-changes au lieu d'utiliser les informations du fichier de journal des modifications de l'arborescence source.
-madresse-mainteneur
Utilise adresse-mainteneur comme nom et adresse e-mail du mainteneur pour ce paquet, au lieu d'utiliser les informations du fichier de contrôle de l'arborescence source.
-eadresse-mainteneur
Utilise adresse-mainteneur comme nom et adresse e-mail du mainteneur pour ce téléversement, au lieu d'utiliser les informations du journal des modifications de l'arborescence source.
-Vnom=valeur
Définit une variable de substitution de sortie. Voir deb-substvars(5) pour une discussion sur la substitution de sortie.
-Tfichier-variables-subst
Lit les variables de substitution dans fichier-variables-subst ; la valeur par défaut est debian/substvars. Aucune substitution de variable n'est effectuée sur aucun des champs qui sont générés, à l'exception des contenus extraits du champ Description de chaque paquet binaire (depuis dpkg 1.19.0), cependant la variable spéciale Format remplacera le champ du même nom. Cette option peut être utilisée plusieurs fois pour lire des variables de substitution à partir de plusieurs fichiers (depuis dpkg 1.15.6).
-Dchamp=valeur
Remplace ou ajoute un champ de fichier de contrôle de sortie.
-Uchamp
Supprime un champ de fichier de contrôle de sortie.
-cfichier-controle
Spécifie le fichier de contrôle source principal pour lire les informations. La valeur par défaut est debian/control.
-lfichier-journal
Spécifie le fichier de journal des modifications pour lire les informations. La valeur par défaut est debian/changelog.
-ffichier-liste-fichiers
Lit la liste des fichiers à téléverser ici, au lieu d'utiliser debian/files.
-Fformat-journal
Spécifie le format du journal des modifications. Voir dpkg-parsechangelog(1) pour des informations sur les formats alternatifs.
-urép-fichiers-téléversement
Recherche les fichiers à téléverser dans rép-fichiers-téléversement au lieu de .. (dpkg-genchanges a besoin de trouver ces fichiers pour pouvoir inclure leurs tailles et leurs sommes de contrôle dans le fichier .changes).
-q
Habituellement, dpkg-genchanges affichera des messages informatifs sur la sortie d'erreur standard, par exemple sur le nombre de fichiers sources du paquet qui sont téléversés. -q supprime ces messages.
-O[nom-fichier]
Imprime le fichier de modifications sur la sortie standard (par défaut) ou sur nom-fichier s'il est spécifié (depuis dpkg 1.18.5).
-?, --help
Affiche le message d'utilisation et quitte.
--version
Affiche la version et quitte.

ENVIRONNEMENT

DEB_HOST_ARCH
Définit l'architecture hôte.
DPKG_COLORS
Définit le mode couleur (depuis dpkg 1.18.5). Les valeurs actuellement acceptées sont : auto (par défaut), always et never.
DPKG_NLS
Si défini, il sera utilisé pour décider s'il faut activer le support des langues natives, également connu sous le nom d'internationalisation (ou i18n) (depuis dpkg 1.19.0). Les valeurs acceptées sont : 0 et 1 (par défaut).

FICHIERS

debian/files
La liste des fichiers générés qui font partie du téléversement en cours de préparation. dpkg-genchanges lit les données ici lors de la production d'un fichier .changes.

VOIR AUSSI

deb-substvars(5), deb-src-control(5), deb-src-files(5), deb-changelog(5), deb-changes(5).
