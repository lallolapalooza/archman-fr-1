NOM

DPMSDisable - désactive le DPMS sur l'affichage spécifié

SYNTAXE

cc [ indicateur ... ] fichier ... -lXext [ bibliothèque ... ]
#include <X11/extensions/dpms.h>
Status DPMSDisable ( Display *display );

ARGUMENTS

display
Spécifie la connexion au serveur X

DESCRIPTION

La fonction DPMSDisable désactive la signalisation de gestion de l'alimentation de l'affichage (DPMS) sur l'affichage spécifié. Lorsque désactivé, DPMS règle l'affichage sur DPMSModeOn. Si DPMSDisable est invoquée sur un affichage avec DPMS déjà désactivé ou sur un affichage qui ne supporte pas DPMS, aucun changement n'est effectué et aucune erreur n'est retournée.

VALEURS DE RETOUR

TRUE
La fonction DPMSDisable retourne toujours TRUE.

VOIR AUSSI

DPMSCapable(3), DPMSEnable(3)
