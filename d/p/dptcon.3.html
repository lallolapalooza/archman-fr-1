Documentation de la fonction/sous-routine

sous-routine dptcon (integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision anorm, double precision rcond, double precision, dimension( * ) work, integer info)

DPTCON

But :

!>
!> DPTCON calcule l'inverse du nombre de conditionnement (en norme 1)
!> d'une matrice tridiagonale symétrique réelle définie positive
!> en utilisant la factorisation A = L*D*L**T ou A = U**T*D*U calculée par
!> DPTTRF.
!>
!> Norm(inv(A)) est calculée par une méthode directe, et l'inverse du
!> nombre de conditionnement est calculé comme suit :
!>              RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          Les n éléments diagonaux de la matrice diagonale D de la
!>          factorisation de A, tels que calculés par DPTTRF.
!>

E

!>          E est un tableau de type DOUBLE PRECISION, de dimension (N-1)
!>          Les (n-1) éléments hors diagonale du facteur bidiagonal unitaire
!>          U ou L de la factorisation de A, tels que calculés par DPTTRF.
!>

ANORM

!>          ANORM est de type DOUBLE PRECISION
!>          La norme 1 de la matrice originale A.
!>

RCOND

!>          RCOND est de type DOUBLE PRECISION
!>          L'inverse du nombre de conditionnement de la matrice A,
!>          calculé comme RCOND = 1/(ANORM * AINVNM), où AINVNM est la
!>          norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, de dimension (N)
!>

INFO

!>          INFO est de type INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
