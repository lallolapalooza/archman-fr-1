sous-routine dpbstf (caractère uplo, entier n, entier kd, double précision, dimension( ldab, * ) ab, entier ldab, entier info)

DPBSTF

But:

!>
!> DPBSTF calcule une factorisation de Cholesky divisée d'une matrice bande
!> symétrique définie positive réelle A.
!>
!> Cette routine est conçue pour être utilisée conjointement avec DSBGST.
!>
!> La factorisation a la forme  A = S**T*S  où S est une matrice bande
!> de même bande que A et de la structure suivante:
!>
!>   S = ( U    )
!>       ( M  L )
!>
!> où U est triangulaire supérieure d'ordre m = (n+kd)/2, et L est
!> triangulaire inférieure d'ordre n-m.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est ENTIER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau de DOUBLE PRECISION, dimension (LDAB,N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice bande
!>          symétrique A, stocké dans les kd+1 premières lignes du tableau. La
!>          colonne j de A est stockée dans la colonne j du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>
!>          À la sortie, si INFO = 0, le facteur S de la factorisation de Cholesky
!>          divisée A = S**T*S. Voir Détails supplémentaires.
!>

LDAB

!>          LDAB est ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

INFO

!>          INFO est ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0: si INFO = i, la factorisation n'a pas pu être complétée,
!>               car l'élément mis à jour a(i,i) était négatif ; la
!>               matrice A n'est pas définie positive.
!>

Détails supplémentaires:

!>
!>  Le schéma de stockage bande est illustré par l'exemple suivant, lorsque
!>  N = 7, KD = 2 :
!>
!>  S = ( s11  s12  s13                     )
!>      (      s22  s23  s24                )
!>      (           s33  s34                )
!>      (                s44                )
!>      (           s53  s54  s55           )
!>      (                s64  s65  s66      )
!>      (                     s75  s76  s77 )
!>
!>  Si UPLO = 'U', le tableau AB contient :
!>
!>  à l'entrée :                      à la sortie :
!>
!>   *    *   a13  a24  a35  a46  a57   *    *   s13  s24  s53  s64  s75
!>   *   a12  a23  a34  a45  a56  a67   *   s12  s23  s34  s54  s65  s76
!>  a11  a22  a33  a44  a55  a66  a77  s11  s22  s33  s44  s55  s66  s77
!>
!>  Si UPLO = 'L', le tableau AB contient :
!>
!>  à l'entrée :                      à la sortie :
!>
!>  a11  a22  a33  a44  a55  a66  a77  s11  s22  s33  s44  s55  s66  s77
!>  a21  a32  a43  a54  a65  a76   *   s12  s23  s34  s54  s65  s76   *
!>  a31  a42  a53  a64  a64   *    *   s13  s24  s53  s64  s75   *    *
!>
!>  Les éléments du tableau marqués * ne sont pas utilisés par la routine.
!>
