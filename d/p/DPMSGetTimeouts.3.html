NOM

DPMSGetTimeouts - récupère les valeurs de délai d'attente utilisées par le serveur X pour les temporisations DPMS

SYNTAXE

cc [ flag ... ] fichier ... -lXext [ bibliothèque ... ]
#include <X11/extensions/dpms.h>
Bool DPMSGetTimeouts
(
      Display *display,
      CARD16 *standby,
      CARD16 *suspend,
      CARD16 *off
);

ARGUMENTS

display
Spécifie la connexion au serveur X
standby
Spécifie le délai d'attente actuel en veille en secondes
suspend
Spécifie le délai d'attente actuel en suspension en secondes
off
Spécifie le délai d'attente actuel en arrêt en secondes

DESCRIPTION

La fonction DPMSGetTimeouts récupère les valeurs de délai d'attente utilisées par le serveur X pour les temporisations DPMS.

La valeur standby est la durée d'inactivité en secondes avant que le mode veille ne soit activé. Une valeur de zéro indique que ce mode a été désactivé.

La valeur suspend est la durée d'inactivité en secondes avant que le deuxième niveau d'économie d'énergie ne soit activé. Une valeur de zéro indique que ce mode a été désactivé.

La valeur off est la durée d'inactivité en secondes avant que le troisième et dernier niveau d'économie d'énergie ne soit activé. Une valeur de zéro indique que ce mode a été désactivé.

VALEURS DE RETOUR

TRUE
La fonction DPMSGetTimeouts renvoie TRUE lorsque des valeurs sont renvoyées.
FALSE
La fonction DPMSGetTimeouts renvoie FALSE lorsqu'aucune valeur n'est renvoyée.

VOIR AUSSI
