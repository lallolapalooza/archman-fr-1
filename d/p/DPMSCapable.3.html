DPMSCapable(3) FONCTIONS X DPMSCapable(3)

NOM

DPMSCapable - retourne la capacité DPMS du serveur X

SYNTAXE

cc [ option ... ] fichier ... -lXext [ bibliothèque ... ]
#include <X11/extensions/dpms.h>
Bool DPMSCapable ( Display *display );

ARGUMENTS

display
Spécifie la connexion au serveur X

DESCRIPTION

La fonction DPMSCapable retourne la capacité de gestion de l'alimentation de l'affichage (DPMS) du serveur X, soit TRUE (capable de DPMS) soit FALSE (incapable de DPMS).

VALEURS DE RETOUR

Vrai
La fonction DPMSCapable retourne Vrai si le serveur X est capable de DPMS.
Faux
La fonction DPMSCapable retourne Vrai si le serveur X est incapable de DPMS.
