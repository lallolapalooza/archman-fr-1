Documentation de fonction/sous-programme

sous-programme dpbequ (caractère uplo, entier n, entier kd, double précision, dimension( ldab, * ) ab, entier ldab, double précision, dimension( * ) s, double précision scond, double précision amax, entier info)

DPBEQU

Objectif:

!>
!> DPBEQU calcule des mises à l'échelle de lignes et de colonnes destinées à équilibrer une
!> matrice bande symétrique définie positive A et à réduire son nombre de conditionnement
!> (par rapport à la norme deux). S contient les facteurs d'échelle,
!> S(i) = 1/sqrt(A(i,i)), choisis de telle sorte que la matrice mise à l'échelle B avec
!> des éléments B(i,j) = S(i)*A(i,j)*S(j) ait des uns sur la diagonale. Ce
!> choix de S met le nombre de conditionnement de B à un facteur N du
!> plus petit nombre de conditionnement possible sur toutes les mises à l'échelle diagonales possibles.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  La partie triangulaire supérieure de A est stockée ;
!>          = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

KD

!>          KD est un ENTIER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KD >= 0.
!>

AB

!>          AB est un tableau DOUBLE PRÉCISION, dimension (LDAB,N)
!>          La partie triangulaire supérieure ou inférieure de la matrice bande symétrique A,
!>          stockée dans les KD+1 premières lignes du tableau. La j-ième colonne
!>          de A est stockée dans la j-ième colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension principale du tableau A. LDAB >= KD+1.
!>

S

!>          S est un tableau DOUBLE PRÉCISION, dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est un DOUBLE PRÉCISION
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas nécessaire de mettre à l'échelle avec S.
!>

AMAX

!>          AMAX est un DOUBLE PRÉCISION
!>          Valeur absolue de l'élément de matrice le plus grand. Si AMAX est très
!>          proche du débordement ou très proche du sous-débordement, la matrice
!>          devrait être mise à l'échelle.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, le i-ème élément diagonal est non positif.
!>
