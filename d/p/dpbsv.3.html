sous-routine dpbsv (character uplo, integer n, integer kd, integer nrhs, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldb, * ) b, integer ldb, integer info)

DPBSV calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

But :

!>
!> DPBSV calcule la solution d'un système linéaire réel
!>    A * X = B,
!> où A est une matrice bande symétrique définie positive de taille N x N et X
!> et B sont des matrices de taille N x NRHS.
!>
!> La décomposition de Cholesky est utilisée pour factoriser A en
!>    A = U**T * U,  si UPLO = 'U', ou
!>    A = L * L**T,  si UPLO = 'L',
!> où U est une matrice bande triangulaire supérieure, et L est une matrice bande
!> triangulaire inférieure, avec le même nombre de superdiagonales ou
!> de sous-diagonales que A. La forme factorisée de A est ensuite utilisée pour résoudre le
!> système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AB

!>          AB est un tableau DOUBLE PRECISION, de dimension (LDAB,N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          symétrique A, stocké dans les KD+1 premières lignes du tableau.
!>          La j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) pour max(1,j-KD)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(N,j+KD).
!>          Voir ci-dessous pour plus de détails.
!>
!>          En sortie, si INFO = 0, le facteur triangulaire U ou L de la
!>          décomposition de Cholesky A = U**T*U ou A = L*L**T de la matrice bande
!>          A, dans le même format de stockage que A.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (LDB,NRHS)
!>          En entrée, la matrice membre de droite B de taille N x NRHS.
!>          En sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                de A n'est pas positif, donc la factorisation n'a pas pu
!>                être complétée, et la solution n'a pas été calculée.
!>

Détails supplémentaires :

!>
!>  Le schéma de stockage bande est illustré par l'exemple suivant, lorsque
!>  N = 6, KD = 2, et UPLO = 'U' :
!>
!>  À l'entrée :                    À la sortie :
!>
!>      *    *   a13  a24  a35  a46      *    *   u13  u24  u35  u46
!>      *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
!>     a11  a22  a33  a44  a55  a66     u11  u22  u33  u44  u55  u66
!>
!>  De même, si UPLO = 'L', le format de A est le suivant :
!>
!>  À l'entrée :                    À la sortie :
!>
!>     a11  a22  a33  a44  a55  a66     l11  l22  l33  l44  l55  l66
!>     a21  a32  a43  a54  a65   *      l21  l32  l43  l54  l65   *
!>     a31  a42  a53  a64   *    *      l31  l42  l53  l64   *    *
!>
!>  Les éléments de tableau marqués * ne sont pas utilisés par la routine.
!>
