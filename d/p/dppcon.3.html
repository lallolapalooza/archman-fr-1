sous-programme dppcon (caractère uplo, entier n, double précision, dimension( * ) ap, double précision anorm, double précision rcond, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier info)

DPPCON

But:

!>
!> DPPCON estime l'inverse du nombre de conditionnement (en
!> norme 1) d'une matrice symétrique réelle définie positive et
!> empaquetée, en utilisant la factorisation de Cholesky A = U**T*U
!> ou A = L*L**T calculée par DPPTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et l'inverse du
!> nombre de conditionnement est calculé comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': le triangle supérieur de A est stocké ;
!>          = 'L': le triangle inférieur de A est stocké.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

AP

!>          AP est un tableau de DOUBLE PRÉCISION, de dimension (N*(N+1)/2)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T, empaqueté par colonne dans un
!>          tableau linéaire. La j-ème colonne de U ou L est stockée dans
!>          le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) pour j<=i<=n.
!>

ANORM

!>          ANORM est de DOUBLE PRÉCISION
!>          La norme 1 (ou norme infinie) de la matrice symétrique A.
!>

RCOND

!>          RCOND est de DOUBLE PRÉCISION
!>          L'inverse du nombre de conditionnement de la matrice A,
!>          calculé comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, de dimension (3*N)
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, de dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
