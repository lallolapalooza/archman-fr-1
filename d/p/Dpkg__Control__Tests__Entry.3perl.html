NOM

Dpkg::Control::Tests::Entry - représente une entrée de suite de tests

DESCRIPTION

Cette classe représente une entrée de suite de tests.

MÉTHODES

Toutes les méthodes de Dpkg::Control sont disponibles. Celles listées ci-dessous sont soit nouvelles, soit remplacées avec un comportement différent.

$entry = Dpkg::Control::Tests::Entry->new(%opts)
Crée un nouvel objet. Il ne représente pas une véritable entrée de test de contrôle tant qu'une analyse n'a pas réussi ou qu'elle n'a pas été construite à partir de zéro.

Les options sont transmises au constructeur Dpkg::Control->new().

$entry->parse($fh, $desc)
Analyse une entrée de test de contrôle à partir d'un descripteur de fichier. Lorsqu'elle est appelée plusieurs fois, les champs analysés sont accumulés.

Retourne vrai si l'analyse a réussi.
