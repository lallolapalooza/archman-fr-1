NOM

Dpkg::BuildAPI - gère les versions de l'API de construction

DESCRIPTION

Le module Dpkg::BuildAPI fournit des fonctions pour récupérer le niveau actuel de l'API de construction de dpkg.

Note: Il s'agit d'un module privé, son API peut changer à tout moment.

FONCTIONS

$level = get_build_api([$ctrl])
Récupère le niveau de l'API de construction, à partir de la variable d'environnement DPKG_BUILD_API, ou si elle n'est pas définie et qu'un objet $ctrl Dpkg::Control::Info est passé en argument, depuis ses champs de dépendances de construction. Si aucun objet $ctrl n'est passé, la valeur précédemment obtenue est renvoyée.
reset_build_api()
Réinitialise le niveau de l'API de construction mis en cache.
