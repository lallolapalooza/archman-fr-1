DPIPE(1) Manuel des commandes générales DPIPE(1)

NOM

dpipe - commande de canal bidirectionnel

SYNTAXE

dpipe [ commande [ arguments ] ] = [ commande [ arguments ] ]
dpipe [ commande [ arguments ] ] = [ commande [ arguments ] ] [ = [ commande [ arguments ] ] ] ...

DESCRIPTION

dpipe est un outil général permettant d'exécuter deux commandes en détournant la sortie standard de la première vers l'entrée standard de la seconde, et vice-versa. C'est l'extension bidirectionnelle de la syntaxe | (pipe) utilisée par tous les shells. Le signe = a été choisi comme métaphore de deux lignes de communication parallèles entre les commandes. Il est également possible de chaîner plusieurs outils. Les programmes intermédiaires communiquent en utilisant l'entrée standard et la sortie standard avec l'outil précédent et alternent l'entrée et la sortie standard (descripteurs de fichiers numéro 3 et 4 respectivement) vers l'outil suivant. Si un outil intermédiaire doit traiter uniquement les données circulant dans une seule direction, utilisez { ou } comme suffixe pour le = précédent et préfixe pour le suivant.
Cet outil a été écrit pour le projet Virtual Distributed Ethernet.

EXEMPLE

dpipe a = b
les commandes a et b sont connectées bidirectionnellement : l'entrée standard de a est connectée à la sortie standard de b et vice-versa.
dpipe a = b = c
a et b sont connectés comme ci-dessus. L'entrée standard alternée de b est connectée à la sortie standard de c, et la sortie standard alternée de b à l'entrée standard de c.
dpipe a =} b }= c
Ceci est un cycle de pipes : la sortie standard de a est connectée à l'entrée standard de b, la sortie standard de b à l'entrée standard de c, et la sortie standard de c à l'entrée standard de a.
dpipe a =} b }={ c {= d = e
toutes les notations peuvent être mélangées. ceci est a -> b -> d -> c et retour à a; les ports alternés de d sont connectés à e.

OPTIONS

aucune option.
