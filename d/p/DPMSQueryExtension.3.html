NOM

DPMSQueryExtension - interroge le serveur X pour déterminer la disponibilité de l'Extension DPMS

SYNTAXE

cc [ flag ... ] file ... -lXext [ library ... ]
#include <X11/extensions/dpms.h>
Bool DPMSQueryExtension
(
      Display *display,
      int *event_base,
      int *error_base
);

ARGUMENTS

display
Spécifie la connexion au serveur X
event_base
Spécifie l'emplacement de retour pour l'événement de base attribué
error_base
Spécifie l'emplacement de retour pour l'erreur de base attribuée

DESCRIPTION

La fonction DPMSQueryExtension interroge le serveur X pour déterminer la disponibilité de l'Extension de Signalisation de Gestion d'Alimentation d'Affichage (DPMS). Si l'extension est disponible, elle retourne TRUE, et event_base et error_base sont définis aux numéros d'événement et d'erreur de base, respectivement. Sinon, la valeur de retour est FALSE, et les valeurs de event_base et error_base ne sont pas définies.

VALEURS DE RETOUR

TRUE
La fonction DPMSQueryExtension retourne TRUE si l'extension est disponible, et event_base et error_base sont définis au numéro d'événement de base et au numéro d'erreur de base pour l'extension, respectivement.
FALSE
La fonction DPMSQueryExtension retourne FALSE si l'extension n'est pas disponible, et les valeurs de event_base et error_base ne sont pas définies.
