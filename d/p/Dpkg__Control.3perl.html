NOM

Dpkg::Control - analyser et manipuler les informations officielles de type control

DESCRIPTION

L'objet Dpkg::Control est une version intelligente de Dpkg::Control::Hash. Il associe un type aux informations de contrôle. Ce type peut être utilisé pour savoir quels champs sont autorisés et dans quel ordre ils doivent être affichés.

Les types sont des constantes exportées par défaut. Voici la liste complète :

CTRL_UNKNOWN
Ce type est le type par défaut, il indique que le type des informations de contrôle n'est pas encore connu.
CTRL_TMPL_SRC
Correspond au premier paragraphe du paquet source dans un debian/control fichier dans un paquet source Debian.
CTRL_TMPL_PKG
Correspond aux paragraphes suivants des paquets binaires dans un debian/control fichier dans un paquet source Debian.
CTRL_REPO_RELEASE
Correspond à un fichier Release dans un dépôt.
CTRL_REPO_SRC
Correspond à un paragraphe dans un fichier Sources d'un dépôt de paquets source.
CTRL_REPO_PKG
Correspond à un paragraphe dans un fichier Packages d'un dépôt de paquets binaires.
CTRL_DSC
Correspond à un fichier .dsc d'un paquet source Debian.
CTRL_DEB
Correspond au fichier control généré par dpkg-gencontrol (DEBIAN/control) et au même fichier à l'intérieur des paquets .deb.
CTRL_FILE_BUILDINFO
Correspond à un fichier .buildinfo.
CTRL_FILE_CHANGES
Correspond à un fichier .changes.
CTRL_FILE_VENDOR
Correspond à un fichier de fournisseur dans $Dpkg::CONFDIR/origins/.
CTRL_FILE_STATUS
Correspond à un paragraphe dans le fichier status de dpkg ($Dpkg::ADMINDIR/status).
CTRL_CHANGELOG
Correspond à la sortie de dpkg-parsechangelog.
CTRL_COPYRIGHT_HEADER
Correspond au paragraphe d'en-tête dans un debian/copyright fichier au format lisible par la machine.
CTRL_COPYRIGHT_FILES
Correspond à un paragraphe de fichiers dans un debian/copyright fichier au format lisible par la machine.
CTRL_COPYRIGHT_LICENSE
Correspond à un paragraphe de licence dans un debian/copyright fichier au format lisible par la machine.
CTRL_TESTS
Correspond à un fichier de contrôle de tests de paquet source dans debian/tests/control.
CTRL_INFO_SRC
Alias obsolète de CTRL_TMPL_SRC.
CTRL_INFO_PKG
Alias obsolète de CTRL_TMPL_PKG.
CTRL_PKG_SRC
Alias obsolète de CTRL_DSC.
CTRL_PKG_DEB
Alias obsolète de CTRL_DEB.
CTRL_INDEX_SRC
Alias obsolète de CTRL_REPO_SRC.
CTRL_INDEX_PKG
Alias obsolète de CTRL_REPO_PKG.

MÉTHODES

Toutes les méthodes de Dpkg::Control::Hash sont disponibles. Celles listées ci-dessous sont soit nouvelles, soit redéfinies avec un comportement différent.

$c = Dpkg::Control->new(%opts)
Crée un nouvel objet de contrôle deb822.

Options :

type
Définit le type de contrôle deb822, utilisé pour configurer les valeurs par défaut des autres options.

Voir set_options() pour plus de détails.

$c->set_options(%opts)
Change la valeur d'une ou plusieurs options.

Options :

type
Définit le type de l'objet de contrôle deb822, utilisé pour définir les valeurs par défaut des autres options.

L'ordre de sortie est également défini pour correspondre à la liste ordonnée retournée par Dpkg::Control::Fields::field_ordered_list($type).

name
Définit une description textuelle du type d'informations de contrôle.
allow_pgp
Définit si l'analyseur accepte les signatures OpenPGP autour des informations de contrôle deb822.

Par défaut, il est défini à 1 pour CTRL_DSC, CTRL_FILE_CHANGES et CTRL_REPO_RELEASE et à 0 sinon.

allow_duplicate
Définit si l'analyseur autorise les champs en double dans les informations de contrôle deb822.
keep_duplicate
Définit si l'analyseur conservera les valeurs des champs en double trouvés dans les informations de contrôle deb822 (lorsque allow_duplicate est activé), sous forme de références de tableau.
drop_empty
Définit si les champs vides sont supprimés lors de la sortie.

Par défaut, il est défini à 0 pour CTRL_TMPL_SRC et CTRL_TMPL_PKG et à 1 sinon.

$c->get_type()
Retourne le type d'informations de contrôle stockées. Voir le paramètre type défini lors de new().
