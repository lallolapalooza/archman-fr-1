NOM

docker-manifest - Gérer les manifests et listes de manifests d'images Docker

SYNOPIS

docker manifest COMMAND

DESCRIPTION

La commande docker manifest possède des sous-commandes pour gérer les manifests et les listes de manifests d'images. Une liste de manifests vous permet d'utiliser un seul nom pour faire référence à la même image construite pour plusieurs architectures.

Pour voir l'aide d'une sous-commande, utilisez :

docker manifest CMD --help

Pour plus de détails sur l'utilisation des listes de manifests Docker, consultez la spécification du registre v2.
