double précision fonction dsdot (entier n, réel, dimension(*) sx, entier incx, réel, dimension(*) sy, entier incy)

DSDOT

Objectif :

!>
!> Calcule le produit interne de deux vecteurs avec accumulation et résultat
!> en précision étendue.
!>
!> Renvoie le produit scalaire en double précision accumulé en double précision,
!> pour SX et SY en simple précision.
!> DSDOT = somme pour I de 0 à N-1 de  SX(LX+I*INCX) * SY(LY+I*INCY),
!> où LX = 1 si INCX .GE. 0, sinon LX = 1+(1-N)*INCX, et LY est
!> défini de manière similaire en utilisant INCY.
!>

Paramètres

N 
!>          N est un ENTIER
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

SX

!>          SX est un tableau RÉEL, de dimension(N)
!>         vecteur en simple précision avec N éléments
!>

INCX

!>          INCX est un ENTIER
!>          espacement de stockage entre les éléments de SX
!>

SY

!>          SY est un tableau RÉEL, de dimension(N)
!>         vecteur en simple précision avec N éléments
!>

INCY

!>          INCY est un ENTIER
!>         espacement de stockage entre les éléments de SY
!>

Retourne

DSDOT 
!>          DSDOT est un DOUBLE PRÉCISION
!>         DSDOT  produit scalaire en double précision (zéro si N.LE.0)
!>
