SYNOPSI

docker inspect [OPTIONS] NAME|ID [NAME|ID..

DESCRIPTIO

N

Cela affiche les informations de bas niveau sur les objets Docker (par exemple conteneur, image, volume, réseau, nœud, service ou tâche) i

dentifiés par nom ou ID. Par défaut, tous les résultats sont rendus dans un tableau JSON. Si le conteneur et l'image portent le même nom, c
ela renverra le JSON du conteneur pour un type non spécifié. Si un format est spécifié, le modèle donné sera exécuté pour chaque résultat.

EXEMPLE

S

Obtenir des informations sur une image lorsque le nom de l'image entre en conflit avec le nom du conteneur, par exemple si l'image et le conteneur sont tous deux nommés rhel7

: 
$ docker inspect --type=image rhel7

 ....

: 
$ docker inspect --format='{{range $p, $conf := .NetworkSettings.Ports}} \
  {{$p}} -> {{(index $conf 0).HostPort}} {{end}}' d2cc496561d6
