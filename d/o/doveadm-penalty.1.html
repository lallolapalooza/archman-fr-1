NOM

doveadm-penalty - Afficher les pénalités actuelles

SYNTAXE

doveadm [OPTIONS GLOBALES] penalty [-a chemin_socket_anvil] [ip [/ masque]]

DESCRIPTION

La commande doveadm penalty peut être utilisée pour consulter les pénalités actuelles.

OPTIONS GLOBALES

Options globales de doveadm(1)

-D

Active la verbosité et les messages de débogage.

-O

Ne pas lire de fichier de configuration, utiliser seulement les valeurs par défaut. Le paramètre dovecot_storage_version est défini par défaut sur la dernière version, mais peut être remplacé avec

-k

Préserve l'environnement entier pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris un compteur de progression.

-i nom_instance

Si vous utilisez plusieurs instances de Dovecot, choisissez le fichier de configuration basé sur ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier_configuration

Lit la configuration à partir du fichier_configuration donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer ceci vers le socket de configuration d'une instance exécutant une version compatible.

-o parametre=valeur

Remplace le parametre de configuration de /etc/dovecot/dovecot.conf et de l'userdb avec la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

OPTIONS

-a chemin_socket_anvil

Cette option est utilisée pour spécifier un socket alternatif. L'argument de l'option est soit un chemin absolu vers un socket de domaine UNIX local, soit un nom d'hôte et un port (nom_hôte:port), afin de se connecter à un hôte distant via un socket TCP.

Par défaut, doveadm(1) utilisera le socket

ARGUMENTS

ip [/masque]

Pour réduire/filtrer la sortie, fournissez une adresse IP ou une plage de réseaux en notation CIDR (ip/masque).

EXEMPLE

doveadm penalty
IP               pénalité dernière_pénalité        dernière_mise_à_jour
192.0.2.222            3 2010-06-15 15:19:27 15:19:27
192.0.2.53             3 2010-06-15 15:19:34 15:19:34

SIGNALEMENT DE BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Des informations sur le signalement de bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
