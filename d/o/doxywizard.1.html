NOM

Doxywizard - un outil pour configurer et exécuter Doxygen sur vos fichiers source

SYNTAXE

doxywizard [Doxyfile]

DESCRIPTION

Doxywizard est une interface graphique interactive pour l'outil Doxygen, permettant de configurer et d'exécuter Doxygen sur vos fichiers source.
