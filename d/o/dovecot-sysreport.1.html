NOM

dovecot-sysreport - Utilitaire de rapport système de Dovecot

SYNTAXE

dovecot-sysreport [-h|--help] [-c|--core [binaire] core [...]] [-d|--destination dest] [-k|--keeptemp]

DESCRIPTION

dovecot-sysreport est un utilitaire qui doit être utilisé pour collecter des informations du système actuel afin de les signaler pour les corrections de bugs de dovecot. Il collectera la sortie ps de dovecot, l'état des services, l'état des processus, la sortie de la commande uptime, le log d'erreurs, un dump des statistiques et, s'il est fourni, un fichier core ainsi que ses dépendances binaires.

OPTIONS

-h|--help

Affiche un message d'aide.

-c|--config fichier_config_racine

Définit le fichier racine de la configuration de dovecot. S'il n'est pas défini, il sera supposé être dans le chemin de configuration par défaut.

-o|--core [ binaire ] core [...]

Inclut les fichiers core ainsi que leurs dépendances extraites du fichier binaire spécifié.

-d|--destination dest

Définit l'emplacement du fichier où l'archive du rapport doit être placée. La valeur par défaut est dovecot-sysreport-<hostname>-<timestamp_actuel>.tar.gz dans le répertoire courant.

-k|--keeptemp

Si défini, les fichiers temporaires ne seront pas supprimés à la fin.

SIGNALER LES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Des informations sur la façon de signaler les bogues sont disponibles sur : https://dovecot.org/bugreport.html
