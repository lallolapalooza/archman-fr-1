NOM

doveadm-instance - Gérer la liste des instances Dovecot en cours d'exécution

SYNTAXE

doveadm [OPTIONS GLOBALES] instance list [-c] [nom]

doveadm [OPTIONS GLOBALES] instance remove nom

DESCRIPTION

Les commandes doveadm instance sont utilisées pour gérer la liste des instances Dovecot en cours d'exécution sur le serveur. Dans la plupart des installations, il n'y a qu'une seule instance Dovecot, mais dans certains cas, il peut être utile d'en avoir plus (par exemple, exécuter un proxy et un backend sur le même serveur).

Les instances sont ajoutées à la liste automatiquement au démarrage de Dovecot. Chaque instance est identifiée de manière unique par son réglage base_dir. Les instances peuvent être nommées en réglant instance_name dans le dovecot.conf de chaque instance. Lorsqu'une instance est nommée, elle peut être facilement accédée en donnant le paramètre de ligne de commande -i nom_instance aux binaires Dovecot (par exemple, doveadm).

OPTIONS GLOBALES

doveadm(1) global

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise simplement les valeurs par défaut. Le réglage dovecot_storage_version prend par défaut la dernière version, mais peut être remplacé par

-k

Préserve l'environnement entier pour doveadm, pas seulement le réglage import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom-instance

Si vous utilisez plusieurs instances Dovecot, choisissez le fichier de configuration basé sur ce nom d'instance.

Voir le réglage instance_name pour plus d'informations.

-c fichier-config

Lit la configuration à partir du fichier-config donné. Par défaut, il lit d'abord le socket de configuration, puis revient à /etc/dovecot/dovecot.conf. Vous pouvez également pointer cela vers le socket de configuration d'une instance exécutant une version compatible.

-o réglage=valeur

Remplace le réglage de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Pour remplacer plusieurs réglages, l'option -o peut être spécifiée plusieurs fois.

-f formateur

Spécifie le formateur pour le formatage de la sortie. Les formateurs supportés sont :

flow

imprime chaque ligne avec des paires clé=valeur.

json

imprime un tableau JSON d'objets JSON.

pager

imprime chaque paire clé: valeur sur sa propre ligne et sépare les enregistrements par un caractère de saut de page (^L).

tab

imprime un en-tête de tableau suivi de lignes de valeurs séparées par des tabulations.

table

imprime un en-tête de tableau suivi de lignes de valeurs ajustées.

ARGUMENTS

nom

La valeur du réglage instance_name d'une instance. Chaque instance peut également être identifiée de manière unique par son réglage base_dir.

COMMANDES

instance list

doveadm [OPTIONS GLOBALES] instance list [-c] [nom]

Cette commande liste les instances Dovecot vues.

-c

Sortir le chemin de configuration au lieu des informations d'instance.

instance remove

doveadm [OPTIONS GLOBALES] instance remove nom

Cette commande supprime l'instance spécifiée.

SIGNALER LES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur la façon de signaler les bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
