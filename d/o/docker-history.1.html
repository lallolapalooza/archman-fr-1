NOM

docker-history - Afficher l'historique d'une image

SYNTAXE

docker history [OPTIONS] IMAGE

DESCRIPTION

Alias de docker image history.

OPTIONS

--format="" Formater la sortie en utilisant un modèle personnalisé : 'table' : Afficher la sortie au format tableau avec les en-têtes de colonne (par défaut) 'table TEMPLATE' : Afficher la sortie au format tableau en utilisant le modèle Go donné 'json' : Afficher au format JSON 'TEMPLATE' : Afficher la sortie en utilisant le modèle Go donné. Se référer à https://docs.docker.com/go/formatting/ pour plus d'informations sur le formatage de la sortie avec des modèles.

-H, --human[=true] Afficher les tailles et les dates dans un format lisible par l'homme.

--no-trunc[=false] Ne pas tronquer la sortie.

--platform="" Afficher l'historique pour la plateforme donnée. Formaté comme "os[/arch[/variant]]" (par exemple, "linux/amd64").

-q, --quiet[=false] N'afficher que les identifiants d'image.
