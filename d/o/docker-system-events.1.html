NAME

docker-system-events — Écouter les événements Docker

SYNOPSIS

docker system events [--filter=filter] [--format=format] [--since=timestamp] [--until=timestamp]

DESCRIPTION

La commande docker system events renvoie les informations sur les événements qui se produisent sur le daemon Docker. Les événements sont générés par le daemon et non par les conteneurs.

Pour obtenir un flux continu d'événements, laissez la commande en cours d'exécution. La commande se termine lorsqu'elle est interrompue par Ctrl+C.

Utilisez l'option --filter pour ne filtrer que les événements qui vous intéressent.

Utilisez l'option --format pour formater la sortie avec un template Go.

Utilisez l'option --since et --until pour spécifier une plage de temps pour les événements.

EXAMPLES

Listening for Docker events

L'exemple suivant affiche les événements à mesure qu'ils se produisent :

    $ docker system events
    2016-07-20T15:09:51.511619761+02:00 kill (id: 74074f7a707d)
    2016-07-20T15:09:51.511719593+02:00 die (id: 74074f7a707d)
    2016-07-20T15:09:51.511883878+02:00 exit (id: 74074f7a707d, code: 0)

Listening for events since a given date

L'exemple suivant affiche tous les événements depuis le 19 juillet 2016 à 10 h 00 min 00 s :

    $ docker system events --since 2016-07-19T10:00:00Z

Format

L'exemple suivant affiche les événements avec un format personnalisé :

    $ docker system events --format '{{.Action}} - {{.Actor.ID}}'
    kill - 74074f7a707d
    die - 74074f7a707d
    exit - 74074f7a707d

Utilisez l'option --format pour spécifier un template Go pour formater la sortie. Les données disponibles pour le templating sont les événements bruts renvoyés par l'API Docker.

Vous pouvez accéder aux champs de l'objet d'événement comme suit :

.ID : ID de l'objet qui a généré l'événement.

.Type : Type de l'objet qui a généré l'événement (par ex. : 

container
).

.Action : Action qui a déclenché l'événement (par ex. : 

run
, 
start
, 
stop
).

.Actor : Informations sur l'acteur qui a généré l'événement.

.Attributes : Attributs supplémentaires associés à l'événement.

**Aide au templating :**

Vous pouvez utiliser les fonctions d'aide disponibles dans le package template de Go. Pour accéder à un attribut spécifique de l'acteur, utilisez .Actor.Attributes["key"].

Pour plus d'informations sur le templating Go, voir : https://docs.docker.com/go/formatting/

label : Filtrez par label d'objet. Le format est 

label="<key>"

label="<key>=<value>"
. Par exemple, 
--filter label="com.docker.compose.project=myapp"
.

label!= : Filtrez les objets qui n'ont pas un label spécifique. Le format est 

label!="<key>"
ou 
label!="<key>=<value>"
.

id : Filtrez par ID d'objet. Par exemple, 

--filter id=74074f7a707d
.

**Exemples de filtres :**

Pour n'afficher que les événements die :

    $ docker system events --filter 'event=die'

Pour n'afficher que les événements associés au conteneur nommé my_container :

    $ docker system events --filter 'name=my_container'

Pour n'afficher que les événements associés aux conteneurs portant le label com.example.key=value :

    $ docker system events --filter 'label=com.example.key=value'

Pour n'afficher que les événements associés au conteneur avec l'ID 74074f7a707d :

    $ docker system events --filter 'id=74074f7a707d'

Vous pouvez utiliser plusieurs filtres. Les événements ne seront affichés que s'ils correspondent à tous les filtres spécifiés.

    $ docker system events --filter 'event=start' --filter 'name=my_container'

OPTIONS

--filter=filter Filtrer les événements selon une condition

--format=format Formater la sortie à l'aide d'un template Go

--since=timestamp Afficher tous les événements créés depuis le timestamp

--until=timestamp Afficher les événements jusqu'à ce timestamp
