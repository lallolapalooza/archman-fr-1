NOM

doveadm-who - Afficher qui est connecté au serveur Dovecot

SYNOPSIS

doveadm [OPTIONS GLOBALES] who [-1] [-f champ_passdb] [-a chemin_socket_anvil] [masque_utilisateur] [ip [/ bits]]

DESCRIPTION

La commande who est utilisée pour afficher quels utilisateurs, depuis quels hôtes, sont actuellement connectés à quel service.

OPTIONS GLOBALES

Options globales de doveadm(1)

-D

Active la verbosité et les messages de débogage. verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise uniquement les valeurs par défaut. Le paramètre dovecot_storage_version prend par défaut la dernière version, mais peut être remplacé avec

-k

Préserve tout l'environnement pour doveadm, et pas seulement le paramètre import_environment .

-v

Active la verbosité, y compris le compteur de progression.

-i nom_instance

Si vous utilisez plusieurs instances Dovecot, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier_configuration

Lit la configuration depuis le fichier_configurationdonné. Par défaut, il lit d'abord le socket de configuration, puis utilise /etc/dovecot/dovecot.conf. Vous pouvez également pointer vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de la base d'utilisateurs (userdb) par la valeurdonnée. Afin de remplacer plusieurs paramètres, l' -o peut être spécifié plusieurs fois.

-f formateur

Spécifie le formateur pour formater la sortie. Les formateurs pris en charge sont :

flow

affiche chaque ligne avec des paires clé=valeur .

json

affiche un tableau JSON d'objets JSON.

pager

affiche chaque paire clé: valeur sur sa propre ligne et sépare les enregistrements avec un caractère de saut de page (^L).

tab

affiche un en-tête de tableau suivi de lignes de valeurs séparées par des tabulations.

table

affiche un en-tête de tableau suivi de lignes de valeurs alignées.

Cette commande utilise par défaut le formateur de sortie table.

OPTIONS

-1

Affiche une ligne par utilisateur et par connexion. Sinon, les connexions sont regroupées par nom d'utilisateur.

-a chemin_socket_anvil

Cette option est utilisée pour spécifier un socket alternatif. L'argument de l'option est soit un chemin absolu vers un socket de domaine UNIX local, soit un nom d'hôte et un port (nom_hôte:port), afin de se connecter à un hôte distant via un socket TCP.

Par défaut, doveadm(1) utilisera le socket

-f champ_passdb

Champ de nom d'utilisateur alternatif à utiliser pour la requête, tel que renvoyé par la passdb. Seuls les champs de la passdb commençant par le préfixe user_ sont suivis.

ARGUMENTS

ip [/ bits]

Spécifiez une adresse ip ou une plage réseau, en notation CIDR, pour réduire le résultat aux connexions correspondantes.

masque_utilisateur

Liste uniquement les utilisateurs dont le nom de connexion correspond au masque_utilisateur, ou au nom d'utilisateur alternatif (champ user_*) si le paramètre -f est utilisé. Il est également possible d'utiliser des caractères génériques dans le nom d'utilisateur .

EXEMPLE

Afficher les sessions authentifiées, filtrées par l'adresse IP du client :

doveadm who ::1
username                       # proto (pids)        (ips)
jane                           2 imap  (30155 30412) (::1)
$ doveadm who 192.0.2.0/24
username                        # proto (pids)  (ips)
john@example.com                1 imap  (30257) (192.0.2.34)

Afficher les sessions authentifiées, filtrées par nom d'utilisateur :

doveadm who pvo
username         # proto (pids)                    (ips)
pvo              1 sieve (30343)                   (fd95:4eed:38ba::25)
pvo              4 imap  (25693 25686 25679 25669) (fd95:4eed:38ba::25)
$ doveadm who ja\*
username                    # proto (pids)        (ips)
james                       1 imap  (30091)       (127.0.0.1)
jane                        2 imap  (30155 30412) (::1)

SIGNALEMENT DE BOGUES

Signalez les bogues, en incluant la sortie de doveconf -n , à la liste de diffusion de Dovecot ⟨dovecot@dovecot.org⟩. Des informations sur le signalement de bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
