NOM

docker-container-run - Créer et exécuter un nouveau conteneur à partir d'une image

SYNOPSIS

docker container run [OPTIONS] IMAGE [COMMAND] [ARG...]

DESCRIPTION

Alias pour docker run.

OPTIONS

--add-host= Ajouter une correspondance personnalisée hôte-vers-IP (hôte:ip)

--annotation=map[] Ajouter une annotation au conteneur (transmise à l'exécuteur OCI)

-a, --attach= Se connecter à STDIN, STDOUT ou STDERR

--blkio-weight=0 Poids relatif d'E/S de bloc, entre 10 et 1000, ou 0 pour désactiver (par défaut 0)

--blkio-weight-device=[] Poids d'E/S de bloc (poids relatif de l'appareil)

--cap-add= Ajouter des capacités Linux

--cap-drop= Abandonner des capacités Linux

--cgroup-parent="" Cgroup parent optionnel pour le conteneur

--cgroupns="" Espace de noms cgroup à utiliser (host|private) 'host' : exécuter le conteneur dans l'espace de noms cgroup de l'hôte Docker 'private' : exécuter le conteneur dans son propre espace de noms cgroup privé '': utiliser l'espace de noms cgroup tel que configuré par l'option
default-cgroupns-mode du démon (par défaut)

--cidfile="" Écrire l'identifiant du conteneur dans le fichier

--cpu-count=0 Nombre de CPU (Windows uniquement)

--cpu-percent=0 Pourcentage de CPU (Windows uniquement)

--cpu-period=0 Limiter la période CFS (Completely Fair Scheduler) du CPU

--cpu-quota=0 Limiter le quota CFS (Completely Fair Scheduler) du CPU

--cpu-rt-period=0 Limiter la période temps réel du CPU en microsecondes

--cpu-rt-runtime=0 Limiter l'exécution temps réel du CPU en microsecondes

-c, --cpu-shares=0 Partages de CPU (poids relatif)

--cpus= Nombre de CPU

--cpuset-cpus="" CPU sur lesquels autoriser l'exécution (0-3, 0,1)

--cpuset-mems="" MEM sur lesquels autoriser l'exécution (0-3, 0,1)

-d, --detach[=false] Exécuter le conteneur en arrière-plan et afficher l'identifiant du conteneur

--detach-keys="" Remplacer la séquence de touches pour détacher un conteneur

--device= Ajouter un périphérique hôte au conteneur

--device-cgroup-rule= Ajouter une règle à la liste des périphériques autorisés du cgroup

--device-read-bps=[] Limiter le débit de lecture (octets par seconde) depuis un périphérique

--device-read-iops=[] Limiter le débit de lecture (E/S par seconde) depuis un périphérique

--device-write-bps=[] Limiter le débit d'écriture (octets par seconde) vers un périphérique

--device-write-iops=[] Limiter le débit d'écriture (E/S par seconde) vers un périphérique

--dns= Définir des serveurs DNS personnalisés

--dns-option= Définir les options DNS

--dns-search= Définir des domaines de recherche DNS personnalisés

--domainname="" Nom de domaine NIS du conteneur

--entrypoint="" Remplacer le ENTRYPOINT par défaut de l'image

-e, --env= Définir des variables d'environnement

--env-file= Lire un fichier de variables d'environnement

--expose= Exposer un port ou une plage de ports

--gpus= Périphériques GPU à ajouter au conteneur ('all' pour passer tous les GPU)

--group-add= Ajouter des groupes supplémentaires à rejoindre

--health-cmd="" Commande à exécuter pour vérifier l'état de santé

--health-interval=0s Délai entre les exécutions de la vérification (ms|s|m|h) (par défaut 0s)

--health-retries=0 Nombre d'échecs consécutifs nécessaires pour signaler un état malsain

--health-start-interval=0s Délai entre les exécutions de la vérification pendant la période de démarrage (ms|s|m|h) (par défaut 0s)

--health-start-period=0s Période de démarrage pour l'initialisation du conteneur avant le début du décompte des health-retries (ms|s|m|h) (par défaut 0s)

--health-timeout=0s Délai maximum autorisé pour l'exécution d'une vérification (ms|s|m|h) (par défaut 0s)

--help[=false] Afficher l'utilisation

-h, --hostname="" Nom d'hôte du conteneur

--init[=false] Exécuter un init à l'intérieur du conteneur qui transmet les signaux et récolte les processus

-i, --interactive[=false] Maintenir STDIN ouvert même si non connecté

--io-maxbandwidth=0 Limite de bande passante E/S maximale pour le lecteur système (Windows uniquement)

--io-maxiops=0 Limite E/S par seconde maximale pour le lecteur système (Windows uniquement)

--ip= Adresse IPv4 (ex. 172.30.100.104)

--ip6= Adresse IPv6 (ex. 2001:db8::33)

--ipc="" Mode IPC à utiliser

--isolation="" Technologie d'isolation du conteneur

-l, --label= Définir des métadonnées sur un conteneur

--label-file= Lire un fichier d'étiquettes délimité par des lignes

--link= Ajouter un lien vers un autre conteneur

--link-local-ip= Adresses IPv4/IPv6 link-local du conteneur

--log-driver="" Pilote de journalisation pour le conteneur

--log-opt= Options du pilote de journalisation

--mac-address="" Adresse MAC du conteneur (ex. 92:d0:c6:0a:29:33)

-m, --memory=0 Limite de mémoire

--memory-reservation=0 Limite souple de mémoire

--memory-swap=0 Limite d'échange égale à mémoire plus échange : '-1' pour activer un échange illimité

--memory-swappiness=-1 Régler la tendance à l'échange de mémoire du conteneur (0 à 100)

--mount= Attacher un montage de système de fichiers au conteneur

--name="" Assigner un nom au conteneur

--network= Connecter un conteneur à un réseau

--network-alias= Ajouter un alias au niveau du réseau pour le conteneur

--no-healthcheck[=false] Désactiver tout HEALTHCHECK spécifié par le conteneur

--oom-kill-disable[=false] Désactiver le tueur OOM

--oom-score-adj=0 Régler les préférences OOM de l'hôte (-1000 à 1000)

--pid="" Espace de noms PID à utiliser

--pids-limit=0 Régler la limite de PIDs du conteneur (définir -1 pour illimité)

--platform="" Définir la plateforme si le serveur est multi-plateforme

--privileged[=false] Accorder des privilèges étendus à ce conteneur

-p, --publish= Publier le(s) port(s) du conteneur vers l'hôte

-P, --publish-all[=false] Publier tous les ports exposés vers des ports aléatoires

--pull="missing" Récupérer l'image avant de l'exécuter ("always", "missing", "never")

-q, --quiet[=false] Supprimer la sortie de récupération

--read-only[=false] Monter le système de fichiers racine du conteneur en lecture seule

--restart="no" Politique de redémarrage à appliquer lorsque un conteneur se termine

--rm[=false] Supprimer automatiquement le conteneur et ses volumes anonymes associés lorsqu'il se termine

--runtime="" Exécuteur à utiliser pour ce conteneur

--security-opt= Options de sécurité

--shm-size=0 Taille de /dev/shm

--sig-proxy[=true] Transmettre les signaux reçus au processus

--stop-signal="" Signal pour arrêter le conteneur

--stop-timeout=0 Délai d'attente (en secondes) pour arrêter un conteneur

--storage-opt= Options du pilote de stockage pour le conteneur

--sysctl=map[] Options sysctl

--tmpfs= Monter un répertoire tmpfs

-t, --tty[=false] Allouer un pseudo-TTY

--ulimit=[] Options ulimit

--use-api-socket[=false] Monter par liaison le socket de l'API Docker et l'authentification requise

-u, --user="" Nom d'utilisateur ou UID (format : [:])

--userns="" Espace de noms utilisateur à utiliser

--uts="" Espace de noms UTS à utiliser

-v, --volume= Monter un volume par liaison

--volume-driver="" Pilote de volume optionnel pour le conteneur

--volumes-from= Monter les volumes du(des) conteneur(s) spécifié(s)

-w, --workdir="" Répertoire de travail à l'intérieur du conteneur

VOIR AUSSI
