NOM

podman-machine-start - Démarre une machine virtuelle

SYNTAXE

podman machine start [nom]

DESCRIPTION

Démarre une machine virtuelle pour Podman.

Uniquement sans privilèges (rootless).

Podman sur MacOS et Windows nécessite une machine virtuelle. Ceci est dû au fait que les conteneurs sont basés sur Linux ; ils ne fonctionnent pas sur d'autres systèmes d'exploitation car leurs fonctionnalités principales sont liées au noyau Linux. Podman machine doit être utilisé pour gérer les machines MacOS et Windows, mais peut être utilisé en option sous Linux.

Le nom de machine par défaut est podman-machine-default. Si aucun nom de machine n'est spécifié comme argument, alors podman-machine-default sera démarré.

Une seule VM gérée par Podman peut être active à la fois. Si une VM est déjà en cours d'exécution, podman machine start renvoie une erreur.

podman machine start démarre une machine virtuelle Linux où les conteneurs sont exécutés.

OPTIONS

--help

Affiche le message d'utilisation.

--no-info

Supprime les conseils d'information.

--quiet, -q

Supprime la sortie d'état du démarrage de la machine.

EXEMPLES

Démarrer la machine Podman spécifiée.

$ podman machine start myvm
Starting machine "myvm"
This machine is currently configured in rootless mode. If your containers
require root permissions (e.g. ports < 1024), or if you run into compatibility
issues with non-podman clients, you can switch using the following command:
	podman machine set --rootful myvm
API forwarding listening on: /var/folders/my/k1kpd8ds7p938mchyb1r_4mw0000gn/T/podman/myvm-api.sock
The system helper service is not installed; the default Docker API socket
address can't be used by podman. If you would like to install it, run the following commands:
        sudo /opt/homebrew/Cellar/podman/5.2.4/bin/podman-mac-helper install
        podman machine stop myvm; podman machine start myvm
You can still connect Docker API clients by setting DOCKER_HOST using the
following command in your terminal session:
        export DOCKER_HOST='unix:///var/folders/my/k1kpd8ds7p938mchyb1r_4mw0000gn/T/podman/myvm-api.sock'
Machine "myvm" started successfully

Démarrer avec --no-info :

$ podman machine start --no-info myvm
Starting machine "myvm"
Machine "myvm" started successfully

Démarrer avec --quiet :

$ podman machine start --quiet myvm
Machine "myvm" started successfully
