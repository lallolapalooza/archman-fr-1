NOM

doveadm-indexer - Commandes relatives à la gestion du processus d'indexation

SYNTAXE

doveadm [OPTIONS GLOBALES] indexer commande [OPTIONS] [ARGUMENTS]

DESCRIPTION

doveadm indexer peut être utilisé pour gérer le processus d'indexation.

OPTIONS GLOBALES

Options globales de doveadm(1).

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise uniquement les valeurs par défaut. Le paramètre dovecot_storage_version est défini sur la dernière version par défaut, mais peut être remplacé avec

-k

Conserve l'intégralité de l'environnement pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom-instance

Si plusieurs instances de Dovecot sont utilisées, choisit le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier-config

Lit la configuration à partir du fichier-config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer ceci vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

-f formateur

Spécifie le formateur pour formater la sortie. Les formateurs pris en charge sont :

flow

imprime chaque ligne avec des paires clé=valeur.

json

imprime un tableau JSON d'objets JSON.

pager

imprime chaque paire clé : valeur sur sa propre ligne et sépare les enregistrements par un caractère de saut de page (^L).

tab

imprime un en-tête de tableau suivi de lignes de valeurs séparées par des tabulations.

table

imprime un en-tête de tableau suivi de lignes de valeurs ajustées.

COMMANDES

indexer add

doveadm [OPTIONS GLOBALES] indexer add [-h] [-n max_recent] utilisateur boîte-aux-lettres

Ajoute une demande d'indexation pour le utilisateur et la boîte-aux-lettres donnés à la file d'attente de l'indexeur. Cela fonctionne de la même manière que la commande doveadm index -q.

-h

Ajoute la demande d'indexation en tête de la file d'attente. Par défaut, la demande est ajoutée à la fin de la file d'attente.

-n max_recent

Une valeur entière, qui spécifie le nombre maximum de messages \Recent dans les boîtes aux lettres. Si la boîte aux lettres contient plus de max_recent messages avec le drapeau \Recent défini, la boîte aux lettres ne sera pas indexée. Cela peut être utile pour éviter une indexation inutile pour les grandes boîtes aux lettres qui ne sont jamais ouvertes.

indexer remove

doveadm [OPTIONS GLOBALES] indexer remove masque_utilisateur [masque_boite-aux-lettres]

Supprime toutes les demandes d'indexation correspondant au masque_utilisateur (et masque_boite-aux-lettres). Il est possible d'utiliser des caractères génériques. Les demandes qui sont actuellement traitées par un indexer-worker ne sont pas listées ; utilisez plutôt doveadm kick pour les ignorer.

indexer list

doveadm [OPTIONS GLOBALES] indexer list masque_utilisateur

Liste toutes les demandes d'indexation mises en file d'attente correspondant au masque_utilisateur. Il est possible d'utiliser des caractères génériques. Les demandes qui sont actuellement traitées par un indexer-worker ne sont pas listées ; utilisez plutôt doveadm who pour les voir.

SIGNALER LES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur la manière de signaler les bogues sont disponibles sur : https://dovecot.org/bugreport.html
