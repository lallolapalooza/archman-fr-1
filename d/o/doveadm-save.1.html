DOVEADM-SAVE(1) Dovecot DOVEADM-SAVE(1)

NOM

doveadm-save - Sauvegarde un email dans la boîte aux lettres d'un utilisateur

SYNTAXE

doveadm [OPTIONS GLOBALES] save [-S socket_path] -A [-m boite] [-U uid] [-g guid] [-r date_reception] [fichier_mail]

doveadm [OPTIONS GLOBALES] save [-S socket_path] -F fichier [-m boite] [-U uid] [-g guid] [-r date_reception] [fichier_mail]

doveadm [OPTIONS GLOBALES] save [-S socket_path] --no-userdb-lookup [-m boite] [-U uid] [-g guid] [-r date_reception] [fichier_mail]

doveadm [OPTIONS GLOBALES] save [-S socket_path] -u utilisateur [-m boite] [-U uid] [-g guid] [-r date_reception] [fichier_mail]

DESCRIPTION

doveadm save peut être utilisé pour sauvegarder des messages. Cela peut être utile pour les scripts et le débogage. Sieve n'est pas appelé pour les messages sauvegardés, mais le quota est appliqué.

OPTIONS GLOBALES

doveadm(1) global

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise seulement les valeurs par défaut. Le paramètre dovecot_storage_version est défini par défaut à la dernière version, mais peut être remplacé par

-k

Conserve l'environnement entier pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris un compteur de progression.

-i nom_instance

Si plusieurs instances de Dovecot sont utilisées, choisit le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier_config

Lit la configuration à partir du fichier_config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer ceci vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de la base d'utilisateurs par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

OPTIONS

-A

Si l'option -A est présente, la commande sera exécutée pour tous les utilisateurs. L'utilisation de cette option en combinaison avec les utilisateurs système de userdb { driver = passwd } n'est pas recommandée, car elle inclut également les utilisateurs avec un UID inférieur à celui configuré avec le paramètre first_valid_uid.

Lorsque le module userdb SQL est utilisé, assurez-vous que le paramètre userdb_sql_iterate_query correspond à la disposition de votre base de données.

Lors de l'utilisation du module userdb LDAP, assurez-vous que les paramètres userdb_fields et userdb_ldap_iterate_fields correspondent à votre schéma LDAP. Sinon, doveadm(1) ne pourra pas itérer sur tous les utilisateurs.

-F fichier

Exécute la commande pour tous les utilisateurs du fichier. Ceci est similaire à l'option -A, mais au lieu d'obtenir la liste des utilisateurs de la base d'utilisateurs, ils sont lus depuis le fichier donné. Le fichier contient un nom d'utilisateur par ligne.

--no-userdb-lookup

Ne pas effectuer de recherche dans la base d'utilisateurs. Utiliser la variable d'environnement USER pour spécifier le nom d'utilisateur.

-S socket_path

L'argument de l'option est soit un chemin absolu vers un socket UNIX local, soit un nom d'hôte et un port (nom_hôte:port), afin de se connecter à un hôte distant via un socket TCP.

Cela permet à un administrateur d'exécuter des commandes de messagerie doveadm(1) via le socket donné.

-u utilisateur/masque

Exécute la commande uniquement pour l'utilisateur donné. Il est également possible d'utiliser les jokers '*' et '?' (par exemple, -u *@example.org).

-m boite

Sauvegarde le mail dans la boîte spécifiée au lieu de INBOX.

-U uid

Sauvegarde le mail en utilisant l'UID donné, si possible.

-g guid

Sauvegarde le mail en utilisant le GUID donné.

-r date_reception

Sauvegarde le mail en utilisant le timestamp de date de réception donné. Ceci est au format "timestamp humain" tel que décrit par doveadm-search-query(7).

ARGUMENTS

fichier_mail

Les données du message à sauvegarder.

  • Si fichier_mail est -, le message est lu depuis stdin (par défaut).
  • Sinon, fichier_mail est interprété comme un chemin de fichier.

EXEMPLE

echo "hello, world" | doveadm save -u testuser@testdomain

SIGNALEMENT DE BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur le signalement de bogues sont disponibles sur : https://dovecot.org/bugreport.html
