val symbol_docs : Lexing.position * Lexing.position -> Docstrings.docs

Récupère la documentation de l'élément pour le symbole courant. Cela marque également cette documentation (pour les avertissements d'ambiguïté).

val symbol_docs_lazy : Lexing.position * Lexing.position -> Docstrings.docs Lazy.t

val rhs_docs : Lexing.position -> Lexing.position -> Docstrings.docs

Récupère la documentation de l'élément pour les symboles entre deux positions. Cela marque également cette documentation (pour les avertissements d'ambiguïté).

val rhs_docs_lazy : Lexing.position -> Lexing.position -> Docstrings.docs Lazy.t

val mark_symbol_docs : Lexing.position * Lexing.position -> unit

Marque la documentation de l'élément pour le symbole courant (pour les avertissements d'ambiguïté).

val mark_rhs_docs : Lexing.position -> Lexing.position -> unit

Marque comme associée la documentation de l'élément pour les symboles entre deux positions (pour les avertissements d'ambiguïté)

val symbol_info : Lexing.position -> Docstrings.info

Récupère les informations du champ pour le symbole courant.

val rhs_info : Lexing.position -> Docstrings.info

Récupère les informations du champ suivant le symbole à une position donnée.

val symbol_text : Lexing.position -> Docstrings.text

Récupère le texte précédant le symbole courant.

val symbol_text_lazy : Lexing.position -> Docstrings.text Lazy.t

val rhs_text : Lexing.position -> Docstrings.text

Récupère le texte précédant le symbole à la position donnée.

val rhs_text_lazy : Lexing.position -> Docstrings.text Lazy.t

Texte supplémentaire

Il peut y avoir un texte supplémentaire attaché aux délimiteurs d'un bloc (par exemple, struct et end). Ceci est récupéré par les fonctions suivantes, qui sont appliquées au contenu du bloc plutôt qu'aux délimiteurs.

val symbol_pre_extra_text : Lexing.position -> Docstrings.text

Récupère le texte supplémentaire précédant le symbole courant

val symbol_post_extra_text : Lexing.position -> Docstrings.text

Récupère le texte supplémentaire suivant le symbole courant

val rhs_pre_extra_text : Lexing.position -> Docstrings.text

Récupère le texte supplémentaire précédant le symbole à la position donnée

val rhs_post_extra_text : Lexing.position -> Docstrings.text

Récupère le texte supplémentaire suivant le symbole à la position donnée

val rhs_post_text : Lexing.position -> Docstrings.text

Récupère le texte suivant le symbole à la position donnée
