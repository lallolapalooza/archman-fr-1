NOM

doveadm-flags - Ajouter, supprimer ou remplacer les indicateurs des messages

SYNTAXE

doveadm [OPTIONS GLOBALES] flags [-S socket_path] -A commande indicateurs requête_de_recherche

doveadm [OPTIONS GLOBALES] flags [-S socket_path] -F fichier commande indicateurs requête_de_recherche

doveadm [OPTIONS GLOBALES] flags [-S socket_path] --no-userdb-lookup commande indicateurs requête_de_recherche

doveadm [OPTIONS GLOBALES] flags [-S socket_path] -u utilisateur commande indicateurs requête_de_recherche

DESCRIPTION

Cette commande est utilisée pour manipuler les indicateurs des messages.

OPTIONS GLOBALES

doveadm(1) global

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise simplement les valeurs par défaut. Le paramètre dovecot_storage_version est par défaut à la dernière version, mais peut être remplacé par

-k

Préserve tout l'environnement pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom_instance

Si plusieurs instances Dovecot sont utilisées, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier_config

Lit la configuration à partir du fichier_config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer ceci vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de la base d'utilisateurs par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

OPTIONS

-A

Si l'option -A est présente, la commande sera effectuée pour tous les utilisateurs. L'utilisation de cette option en combinaison avec les utilisateurs système de userdb { driver = passwd } n'est pas recommandée, car elle contient également des utilisateurs avec un UID inférieur à celui configuré avec le paramètre first_valid_uid.

Lorsque le module userdb SQL est utilisé, assurez-vous que le paramètre userdb_sql_iterate_query correspond à votre disposition de base de données.

Lors de l'utilisation du module userdb LDAP, assurez-vous que les paramètres userdb_fields et userdb_ldap_iterate_fields correspondent à votre schéma LDAP. Sinon, doveadm(1) ne pourra pas itérer sur tous les utilisateurs.

-F fichier

Exécute la commande pour tous les utilisateurs du fichier. Ceci est similaire à l'option -A, mais au lieu d'obtenir la liste des utilisateurs de la base d'utilisateurs, ils sont lus à partir du fichier donné. Le fichier contient un nom d'utilisateur par ligne.

--no-userdb-lookup

Ne pas effectuer de recherche dans la base d'utilisateurs. Utiliser la variable d'environnement USER pour spécifier le nom d'utilisateur.

-S socket_path

L'argument de l'option est soit un chemin absolu vers un socket de domaine UNIX local, soit un nom d'hôte et un port (nom_hôte:port), afin de se connecter à un hôte distant via un socket TCP.

Cela permet à un administrateur d'exécuter des commandes de messagerie doveadm(1) via le socket donné.

-u utilisateur/masque

Exécute la commande uniquement pour l'utilisateur donné. Il est également possible d'utiliser les jokers '*' et '?' (par exemple, -u *@example.org).

ARGUMENTS

indicateurs

Indicateurs de message tels que décrits dans RFC 3501, section 2.3.2 (Attribut de message d'indicateurs) :

Un ou plusieurs indicateurs et/ou mots-clés peuvent être spécifiés.

requête_de_recherche

Manipule les indicateurs des messages correspondant à la requête de recherche donnée. Voir doveadm-search-query(7) pour les détails.

COMMANDES

flags add

doveadm [OPTIONS GLOBALES] flags add [-u utilisateur | -A | -F fichier | --no-userdb-lookup] [-S socket_path] indicateurs requête_de_recherche

Cette commande est utilisée pour étendre l'ensemble actuel d'indicateurs avec les indicateurs donnés.

flags remove

doveadm [OPTIONS GLOBALES] flags remove [-u utilisateur | -A | -F fichier | --no-userdb-lookup] [-S socket_path] indicateurs requête_de_recherche

Afin de supprimer les indicateurs donnés de l'ensemble actuel d'indicateurs, utilisez cette commande.

flags replace

doveadm [OPTIONS GLOBALES] flags replace [-u utilisateur | -A | -F fichier | --no-userdb-lookup] [-S socket_path] indicateurs requête_de_recherche

Cette commande est utilisée pour remplacer TOUS les indicateurs actuels par les indicateurs donnés.

EXEMPLE

Lister et manipuler les indicateurs de message du message avec uid 81563 :

doveadm fetch -u bob 'uid flags' mailbox dovecot uid 81563
uid: 81563
flags: \Answered \Seen NonJunk
doveadm flags remove -u bob NonJunk mailbox dovecot uid 81563
doveadm flags add -u bob '\Flagged $Forwarded' mailbox dovecot uid 81563

SIGNALEMENT DE BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur le signalement des bogues sont disponibles sur : https://dovecot.org/bugreport.html
