NOM

podman-system-connection - Gérer la ou les destinations du ou des services Podman

SYNTAXE

podman system connection sous-commande

DESCRIPTION

Gérer la ou les destinations du ou des services Podman.

L'utilisateur est invité à saisir le mot de passe de connexion ssh ou la phrase secrète du fichier clé si nécessaire. ssh-agent est pris en charge s'il est en cours d'exécution.

Podman gère la connexion système en écrivant et en lisant le fichier podman-connections.json situé dans $XDG_CONFIG_HOME/containers ou, si l'environnement n'est pas défini, il utilise par défaut $HOME/.config/containers. Ou la variable d'environnement PODMAN_CONNECTIONS_CONF peut être définie sur un chemin de fichier complet que podman utilisera à la place. Ce fichier est géré par les commandes podman et ne doit jamais être modifié directement par les utilisateurs. Pour configurer manuellement les connexions, utilisez service_destinations dans containers.conf.

Si la colonne ReadWrite dans la sortie de podman system connection list est définie sur true, la connexion est stockée dans le fichier podman-connections.json, sinon elle est stockée dans containers.conf et ne peut donc pas être modifiée avec les commandes podman system connection.

COMMANDES

Commande Page de manuel Description
add podman-system-connection-add(1) Enregistrer une destination pour le service Podman
default podman-system-connection-default(1) Définir une destination nommée comme défaut pour le service Podman
list podman-system-connection-list(1) Lister la ou les destinations du ou des services Podman
remove podman-system-connection-remove(1) Supprimer une destination nommée
rename podman-system-connection-rename(1) Renommer la destination pour le service Podman

EXEMPLE

Lister les connexions système :

$ podman system connection list
