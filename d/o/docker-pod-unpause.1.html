NOM

podman-pod-unpause - Réactive un ou plusieurs pods

SYNOPSIS

podman pod unpause [options] pod ...

DESCRIPTION

Réactive tous les processus en pause dans les conteneurs d'un ou plusieurs pods. Vous pouvez utiliser les identifiants ou les noms des pods en entrée.

OPTIONS

--all, -a

Réactive tous les pods.

--latest, -l

Au lieu de fournir le nom ou l'identifiant du pod, réactive le dernier pod créé. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (à l'exception de WSL2))

EXEMPLE

Réactive un pod avec un nom donné :

podman pod unpause monpodweb

Réactive un pod avec un identifiant donné :

podman pod unpause 860a4b23

VOIR AUSSI

podman(1), podman-pod(1), podman-pod-pause(1)
