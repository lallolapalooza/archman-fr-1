docker-generate(1) Manuel des commandes générales docker-generate(1)

NOM

docker-generate - Générer des données structurées basées sur des conteneurs, des pods ou des volumes

SYNOPSIS

docker generate sous-commande

DESCRIPTION

La commande generate crée une sortie structurée (comme YAML) basée sur un conteneur, un pod ou un volume.

COMMANDES

Commande Page de manuel Description
kube podman-kube-generate(1) Générer des fichiers YAML Kubernetes basés sur des conteneurs, des pods ou des volumes.
spec podman-generate-spec(1) Générer du JSON Specgen basé sur des conteneurs ou des pods.
systemd podman-generate-systemd(1) [DÉPRECÉ] Générer un ou plusieurs fichiers d'unité systemd pour un conteneur ou un pod.

VOIR AUSSI

podman(1), podman-pod(1), podman-container(1)
