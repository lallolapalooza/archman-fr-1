NOM

doveadm-mail-dict - gestionnaire de dictionnaires de courrier

SYNTAXIS

doveadm [OPTIONS GLOBALES] mail dict set [-u utilisateur] [-t horodatage-millisecondes] [-e secondes-expiration] nom-filtre-config clé valeur

doveadm [OPTIONS GLOBALES] mail dict unset [-u utilisateur] [-t horodatage-millisecondes] nom-filtre-config clé

DESCRIPTION

Les commandes de dictionnaire de courrier permettent de manipuler les données stockées dans les dictionnaires de configuration associés au courrier des utilisateurs.

set

doveadm [OPTIONS GLOBALES] mail dict set [-A | -u utilisateur | -F fichier] [-S chemin_socket] [-t horodatage-millisecondes] [-e secondes-expiration] nom-filtre-config clé valeur

Définit/crée des clés dans le dictionnaire.

-t horodatage-millisecondes

Définit également l'horodatage.

-e secondes-expiration

Définit également la durée de vie de la clé.

clé

La clé à définir.

valeur

La valeur à définir.

unset

doveadm [OPTIONS GLOBALES] mail dict unset [-u utilisateur] [-t horodatage-millisecondes] nom-filtre-config clé

doveadm [OPTIONS GLOBALES] mail dict unset [-A | -u utilisateur | -F fichier] [-S chemin_socket] [-t horodatage-millisecondes] nom-filtre-config clé

Supprime une clé du dictionnaire.

-t horodatage-millisecondes

Définit également l'horodatage.

clé

La clé à supprimer.

SIGNALER DES BOGUES

Signalez les bogues, en incluant la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Des informations sur la manière de signaler les bogues sont disponibles sur : https://dovecot.org/bugreport.html
