NOM

podman-system-renumber - Migre les numéros de verrouillage pour gérer un changement dans le nombre maximal de verrous

SYNTAXE

podman system renumber

DESCRIPTION

podman system renumber renumérote les verrous utilisés par les conteneurs et les pods.

Chaque conteneur et pod Podman se voit attribuer un verrou au moment de sa création, jusqu'à un nombre maximum contrôlé par le paramètre num_locks dans containers.conf.

Lorsque tous les verrous disponibles sont épuisés, aucun conteneur ou pod supplémentaire ne peut être créé tant que certains conteneurs et pods existants ne sont pas supprimés. Ceci peut être évité en augmentant le nombre de verrous disponibles via la modification de containers.conf et en exécutant ensuite podman system renumber pour préparer les nouveaux verrous (et réallouer les numéros de verrous pour qu'ils correspondent à la nouvelle structure).

podman system renumber doit être appelé après toute modification de num_locks ; le non-respect de cette règle entraîne des erreurs au démarrage de Podman, car le nombre de verrous disponibles entre en conflit avec le nombre de verrous configuré.

podman system renumber peut également être utilisé pour migrer les versions 1.0 et antérieures de Podman, qui utilisaient un schéma de verrouillage différent, vers le nouveau modèle de verrouillage. Il n'est pas strictement nécessaire de le faire, mais il est fortement recommandé de le faire, car des interblocages pourraient survenir autrement.

Si possible, évitez d'appeler podman system renumber pendant que d'autres processus Podman sont en cours d'exécution.

EXEMPLES

Renuméroter les verrous des conteneurs et des pods après avoir modifié le paramètre num_locks dans containers.conf.

$ podman system renumber

VOIR AUSSI

podman(1), podman-system(1), containers.conf(5)
