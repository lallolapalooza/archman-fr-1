Module DLS
: sig end

Stockage local au domaine

type 'a key

Type d'une clé DLS

val new_key : ?split_from_parent:('a -> 'a) -> (unit -> 'a) -> 'a key

new_key f retourne une nouvelle clé associée à l'initialiseur f pour accéder aux variables locales au domaine.

Si split_from_parent n'est pas fourni, la valeur pour un nouveau domaine sera calculée à la demande par le nouveau domaine : le premier appel à get appellera l'initialiseur f et stockera cette valeur.

Attention. f peut être appelé plusieurs fois si un autre appel à get survient pendant l'initialisation sur le même domaine. Seule la 'première' valeur calculée sera utilisée, les autres valeurs désormais inutiles seront ignorées. Votre fonction d'initialisation doit supporter cette situation, ou contenir une logique pour détecter ce cas et échouer.

Si split_from_parent est fourni, la création d'un domaine dériva la valeur enfant (pour cette clé) de la valeur parent. Ce calcul se produit dans le domaine parent et se produit toujours, que le domaine enfant l'utilise ou non. Si la fonction de découpage est coûteuse ou nécessite un calcul côté enfant, envisagez d'utiliser 'a Lazy.t key :

        let init () = ...
        let split_from_parent parent_value =
          ... calcul côté parent ...;
          lazy (
            ... calcul côté enfant ...
          )
        let key = Domain.DLS.new_key ~split_from_parent init
        let get () = Lazy.force (Domain.DLS.get key)

Dans ce cas, une partie du calcul se produit dans le domaine enfant ; en particulier, il peut accéder à parent_value simultanément avec le domaine parent, ce qui peut nécessiter une synchronisation explicite pour éviter les conditions de concurrence.

val get : 'a key -> 'a

get k retourne v si une valeur v est associée à la clé k dans l'état local au domaine de l'appelant. Sinon, définit la valeur de k avec son initialiseur et la retourne.

val set : 'a key -> 'a -> unit

set k v met à jour l'état local au domaine de l'appelant pour associer la clé k à la valeur v. Cela écrase toute valeur précédente associée à k, qui ne pourra pas être restaurée plus tard.
