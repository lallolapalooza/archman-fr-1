NOM

docker-load - Charge une image depuis une archive tar ou STDIN

SYNTAXE

docker load [OPTIONS]

DESCRIPTION

Alias de docker image load.

OPTIONS

-i, --input="" Lit depuis un fichier archive tar, au lieu de STDIN

--platform=[] Charge uniquement la ou les plateformes données. Formaté comme une liste séparée par des virgules de "os[/arch[/variant]]" (par exemple, "linux/amd64,linux/arm64/v8").

-q, --quiet[=false] Supprime la sortie de chargement
