NOM

doveadm-proxy - Gérer les connexions proxy Dovecot (obsolète)

SYNTAXE

doveadm [OPTIONS GLOBALES] [-f formateur] proxy kick|list [OPTIONS] [ARGUMENTS]

DESCRIPTION

Ces commandes sont des alias pour les commandes doveadm-kick(1) et doveadm-who(1).

SIGNALLER LES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur le signalement des bogues sont disponibles sur : https://dovecot.org/bugreport.html
