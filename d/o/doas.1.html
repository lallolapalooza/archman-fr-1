NOM

doas — exécute des commandes en tant qu'un autre utilisateur

SYNOPSIS

doas [-Lns] [-C config] [-u utilisateur] commande [arguments]

DESCRIPTION

L'utilitaire doas exécute la commande donnée en tant qu'un autre utilisateur. L'argument commande est obligatoire sauf si -C, -L, ou -s est spécifié.

L'utilisateur devra s'authentifier en entrant son mot de passe, sauf configuration contraire.

Par défaut, un nouvel environnement est créé. Les variables HOME, LOGNAME, PATH, SHELL, et USER ainsi que la umask(2) sont définies avec des valeurs appropriées pour l'utilisateur cible. DOAS_USER est défini avec le nom de l'utilisateur exécutant doas. Les variables DISPLAY et TERM sont héritées de l'environnement courant. Ce comportement peut être modifié par le fichier de configuration. Le répertoire de travail n'est pas changé.

Les options sont les suivantes :

-C config
Analyse et vérifie le fichier de configuration config, puis quitte. Si commande est fournie, doas effectuera également la correspondance des commandes. Dans ce dernier cas, 'permit', 'permit nopass' ou 'deny' sera affiché sur la sortie standard, en fonction des résultats de la correspondance des commandes. Aucune commande n'est exécutée.
-L
Efface toute authentification persistante des invocations précédentes, puis quitte immédiatement. Aucune commande n'est exécutée.
-n
Mode non interactif, échoue si la règle correspondante n'a pas l'option nopass.
-s
Exécute le shell de SHELL ou de /etc/passwd.
-u utilisateur
Exécute la commande en tant que utilisateur. La valeur par défaut est root.

STATUT DE SORTIE

L'utilitaire doas se termine avec le code 0 en cas de succès, et >0 si une erreur se produit. Il peut échouer pour l'une des raisons suivantes :

  • Le fichier de configuration /etc/doas.conf n'a pas pu être analysé.
  • L'utilisateur a tenté d'exécuter une commande qui n'est pas autorisée.
  • Le mot de passe était incorrect.
  • La commande spécifiée n'a pas été trouvée ou n'est pas exécutable.

VOIR AUSSI

su(1), doas.conf(5)

HISTORIQUE

La commande doas est apparue pour la première fois dans OpenBSD 5.8.
