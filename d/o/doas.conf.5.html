DOAS.CONF(5) Manuel des formats de fichiers DOAS.CONF(5)

NOM

doas.conf — fichier de configuration de doas

DESCRIPTION

L'utilitaire doas(1) exécute des commandes en tant qu'autres utilisateurs selon les règles du fichier de configuration doas.conf.

Les règles ont le format suivant :

permit|deny [options] identité [as cible] [cmd commande [args ...]]

Les règles se composent des parties suivantes :

permit|deny
L'action à effectuer si cette règle correspond.
options
Les options sont :
nopass
L'utilisateur n'est pas tenu de saisir un mot de passe.
nolog
Ne pas enregistrer l'exécution réussie de la commande dans syslogd(8).
persist
Après que l'utilisateur s'est authentifié avec succès, ne pas redemander de mot de passe pendant un certain temps.
keepenv
Les variables d'environnement autres que celles listées dans doas(1) sont conservées lors de la création de l'environnement pour le nouveau processus.
setenv { [variable ...] [variable=valeur ...] }
Conserver ou définir les variables spécifiées séparées par des espaces. Les variables peuvent également être supprimées avec un ‘-’ en préfixe ou définies en utilisant la syntaxe de droite. Si le premier caractère de valeur est un ‘$’, alors la valeur à définir est prise à partir de la variable d'environnement existante du nom indiqué. Cette option est traitée après la création de l'environnement par défaut.
identité
Le nom d'utilisateur à faire correspondre. Les groupes peuvent être spécifiés en préfixant par deux-points (‘:’). Les ID numériques sont également acceptés.
as cible
L'utilisateur cible pour lequel l'utilisateur exécutant est autorisé à exécuter la commande. La valeur par défaut est tous les utilisateurs.
cmd commande
La commande que l'utilisateur est autorisé ou interdit d'exécuter. La valeur par défaut est toutes les commandes. Il est conseillé de spécifier des chemins absolus. Si un chemin relatif est spécifié, seul un PATH restreint sera recherché.
args [argument ...]
Arguments de la commande. Les arguments de commande fournis par l'utilisateur doivent correspondre à ceux spécifiés. Le mot-clé args seul signifie que la commande doit être exécutée sans aucun argument.

La dernière règle correspondante détermine l'action effectuée. Si aucune règle ne correspond, l'action est refusée.

Les commentaires peuvent être placés n'importe où dans le fichier en utilisant le signe dièse (‘#’), et s'étendent jusqu'à la fin de la ligne courante.

Les règles d'échappement suivantes s'appliquent :

  • Le texte entre une paire de guillemets doubles (‘"’) est pris tel quel.
  • Le caractère antislash (‘\’) échappe le caractère suivant, y compris les caractères de nouvelle ligne, en dehors des commentaires ; en conséquence, les commentaires ne peuvent pas s'étendre sur plusieurs lignes.
  • Si des guillemets ou des antislashs sont utilisés dans un mot, celui-ci n'est pas considéré comme un mot-clé.

FICHIERS

/etc/doas.conf
Fichier de configuration de doas(1).
/etc/examples/doas.conf
Exemple de fichier de configuration.

EXEMPLES

L'exemple suivant autorise l'utilisateur aja à installer des paquets depuis un miroir préféré ; le groupe wheel à exécuter des commandes en tant que n'importe quel utilisateur tout en conservant les variables d'environnement PS1 et SSH_AUTH_SOCK et en annulant ENV ; autorise tedu à exécuter procmap en tant que root sans mot de passe ; et autorise en outre root à exécuter des commandes sans restriction en tant que lui-même tout en conservant le PATH d'origine.

permit persist setenv { PKG_CACHE PKG_PATH } aja cmd pkg_add
permit setenv { -ENV PS1=$DOAS_PS1 SSH_AUTH_SOCK } :wheel
permit nopass tedu as root cmd /usr/sbin/procmap
permit nopass keepenv setenv { PATH } root as root

VOIR AUSSI

doas(1), syslogd(8)

HISTORIQUE

Le fichier de configuration doas.conf est apparu pour la première fois dans OpenBSD 5.8.
