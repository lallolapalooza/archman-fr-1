NOM

doveadm-force-resync - Réparer des boîtes aux lettres corrompues

SYNTAXE

doveadm [OPTIONS GLOBALES] force-resync [-S chemin_socket] -A boîte_aux_lettres

doveadm [OPTIONS GLOBALES] force-resync [-S chemin_socket] -F fichier boîte_aux_lettres

doveadm [OPTIONS GLOBALES] force-resync [-S chemin_socket] --no-userdb-lookup boîte_aux_lettres

doveadm [OPTIONS GLOBALES] force-resync [-S chemin_socket] -u utilisateur boîte_aux_lettres

DESCRIPTION

Dans certaines circonstances, il peut arriver que dovecot(1) soit incapable de résoudre automatiquement les problèmes avec les boîtes aux lettres. Dans de telles situations, la commande

OPTIONS GLOBALES

Options globales de doveadm(1)

-D

Active la verbeusité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise simplement les valeurs par défaut. Le paramètre dovecot_storage_version est défini par défaut à la dernière version, mais peut être remplacé avec

-k

Préserve l'environnement complet pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbeusité, y compris le compteur de progression.

-i nom_instance

Si plusieurs instances de Dovecot sont utilisées, choisit le fichier de configuration basé sur ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier_config

Lit la configuration à partir du fichier_config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de la base d'utilisateurs par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

OPTIONS

-A

Si l'option -A est présente, la commande sera exécutée pour tous les utilisateurs. L'utilisation de cette option en combinaison avec les utilisateurs système de userdb { driver = passwd } n'est pas recommandée, car elle inclut également les utilisateurs avec un UID inférieur à celui configuré avec le paramètre first_valid_uid.

Lorsque le module userdb SQL est utilisé, assurez-vous que le paramètre userdb_sql_iterate_query correspond à la disposition de votre base de données.

Lorsque le module userdb LDAP est utilisé, assurez-vous que les paramètres userdb_fields et userdb_ldap_iterate_fields correspondent à votre schéma LDAP. Sinon, doveadm(1) ne pourra pas itérer sur tous les utilisateurs.

-F fichier

Exécute la commande pour tous les utilisateurs du fichier. Ceci est similaire à l'option -A, mais au lieu d'obtenir la liste des utilisateurs à partir de la base d'utilisateurs, ils sont lus à partir du fichier donné. Le fichier contient un nom d'utilisateur par ligne.

--no-userdb-lookup

N'effectue pas de recherche dans la base d'utilisateurs. Utilise la variable d'environnement USER pour spécifier le nom d'utilisateur.

-S chemin_socket

L'argument de l'option est soit un chemin absolu vers un socket de domaine UNIX local, soit un nom d'hôte et un port (nom_hote:port), afin de se connecter à un hôte distant via un socket TCP.

Cela permet à un administrateur d'exécuter des commandes de courrier doveadm(1) via le socket donné.

-u utilisateur/masque

Exécute la commande uniquement pour l'utilisateur donné. Il est également possible d'utiliser les jokers '*' et '?' (par exemple, -u *@example.org).

ARGUMENTS

boîte_aux_lettres

Le nom de la boîte aux lettres à corriger. Avec mdbox, toutes les boîtes aux lettres sont corrigées, vous pouvez donc utiliser par exemple INBOX comme nom.

EXEMPLE

Corriger la boîte INBOX de bob :

doveadm force-resync -u bob INBOX

SIGNALER LES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur le signalement des bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
