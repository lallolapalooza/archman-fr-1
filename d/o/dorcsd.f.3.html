sous-routine récursive dorcsd (caractère jobu1, caractère jobu2, caractère jobv1t, caractère jobv2t, caractère trans, caractère signs, entier m, entier p, entier q, double précision, dimension( ldx11, * ) x11, entier ldx11, double précision, dimension( ldx12, * ) x12, entier ldx12, double précision, dimension( ldx21, * ) x21, entier ldx21, double précision, dimension( ldx22, * ) x22, entier ldx22, double précision, dimension( * ) theta, double précision, dimension( ldu1, * ) u1, entier ldu1, double précision, dimension( ldu2, * ) u2, entier ldu2, double précision, dimension( ldv1t, * ) v1t, entier ldv1t, double précision, dimension( ldv2t, * ) v2t, entier ldv2t, double précision, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier info)

DORCSD

Objectif:

!>
!> DORCSD calcule la décomposition CS d'une matrice orthogonale M-par-M partitionnée X:
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**T
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 est P-par-Q. Les matrices orthogonales U1, U2, V1 et V2 sont P-par-P,
!> (M-P)-par-(M-P), Q-par-Q et (M-Q)-par-(M-Q), respectivement. C et S sont
!> des matrices diagonales non négatives R-par-R satisfaisant C^2 + S^2 = I,
!> où R = MIN(P,M-P,Q,M-Q).
!>

Paramètres

JOBU1 
!>          JOBU1 est CHARACTER
!>          = 'Y':      U1 est calculé;
!>          sinon:      U1 n'est pas calculé.
!>

JOBU2

!>          JOBU2 est CHARACTER
!>          = 'Y':      U2 est calculé;
!>          sinon:      U2 n'est pas calculé.
!>

JOBV1T

!>          JOBV1T est CHARACTER
!>          = 'Y':      V1T est calculé;
!>          sinon:      V1T n'est pas calculé.
!>

JOBV2T

!>          JOBV2T est CHARACTER
!>          = 'Y':      V2T est calculé;
!>          sinon:      V2T n'est pas calculé.
!>

TRANS

!>          TRANS est CHARACTER
!>          = 'T':      X, U1, U2, V1T et V2T sont stockés en ordre par ligne;
!>          sinon:      X, U1, U2, V1T et V2T sont stockés en ordre par colonne.
!>

SIGNS

!>          SIGNS est CHARACTER
!>          = 'O':      Le bloc inférieur gauche est rendu non positif (la
!>                       convention);
!>          sinon:      Le bloc supérieur droit est rendu non positif (la
!>                       convention).
!>

M

!>          M est ENTIER
!>          Le nombre de lignes et de colonnes de X.
!>

P

!>          P est ENTIER
!>          Le nombre de lignes de X11 et X12. 0 <= P <= M.
!>

Q

!>          Q est ENTIER
!>          Le nombre de colonnes de X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est un tableau DOUBLE PRÉCISION, dimension (LDX11,Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est désirée.
!>

LDX11

!>          LDX11 est ENTIER
!>          La dimension principale de X11. LDX11 >= MAX(1,P).
!>

X12

!>          X12 est un tableau DOUBLE PRÉCISION, dimension (LDX12,M-Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est désirée.
!>

LDX12

!>          LDX12 est ENTIER
!>          La dimension principale de X12. LDX12 >= MAX(1,P).
!>

X21

!>          X21 est un tableau DOUBLE PRÉCISION, dimension (LDX21,Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est désirée.
!>

LDX21

!>          LDX21 est ENTIER
!>          La dimension principale de X11. LDX21 >= MAX(1,M-P).
!>

X22

!>          X22 est un tableau DOUBLE PRÉCISION, dimension (LDX22,M-Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est désirée.
!>

LDX22

!>          LDX22 est ENTIER
!>          La dimension principale de X11. LDX22 >= MAX(1,M-P).
!>

THETA

!>          THETA est un tableau DOUBLE PRÉCISION, dimension (R), où R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) et
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 est un tableau DOUBLE PRÉCISION, dimension (LDU1,P)
!>          Si JOBU1 = 'Y', U1 contient la matrice orthogonale P-par-P U1.
!>

LDU1

!>          LDU1 est ENTIER
!>          La dimension principale de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 est un tableau DOUBLE PRÉCISION, dimension (LDU2,M-P)
!>          Si JOBU2 = 'Y', U2 contient la matrice orthogonale (M-P)-par-(M-P)
!>          U2.
!>

LDU2

!>          LDU2 est ENTIER
!>          La dimension principale de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T est un tableau DOUBLE PRÉCISION, dimension (LDV1T,Q)
!>          Si JOBV1T = 'Y', V1T contient la matrice orthogonale Q-par-Q
!>          V1**T.
!>

LDV1T

!>          LDV1T est ENTIER
!>          La dimension principale de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

V2T

!>          V2T est un tableau DOUBLE PRÉCISION, dimension (LDV2T,M-Q)
!>          Si JOBV2T = 'Y', V2T contient la matrice orthogonale (M-Q)-par-(M-Q)
!>          V2**T.
!>

LDV2T

!>          LDV2T est ENTIER
!>          La dimension principale de V2T. Si JOBV2T = 'Y', LDV2T >=
!>          MAX(1,M-Q).
!>

WORK

!>          WORK est un tableau DOUBLE PRÉCISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>          Si INFO > 0 à la sortie, WORK(2:R) contient les valeurs PHI(1),
!>          ..., PHI(R-1) qui, avec THETA(1), ..., THETA(R),
!>          définissent la matrice restante sous forme bidiagonale par blocs
!>          en cas de non-convergence. INFO spécifie le nombre de PHI non nuls.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (M-MIN(P, M-P, Q, M-Q))
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  DBBCSD n'a pas convergé. Voir la description de WORK
!>                ci-dessus pour plus de détails.
!>
