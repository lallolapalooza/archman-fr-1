NOM

Doxygen - système de documentation pour divers langages de programmation

DESCRIPTION

Doxygen est un système de documentation pour C++, C, Java, Objective-C, IDL (saveurs CORBA et Microsoft), Fortran, Python, VHDL et, dans une certaine mesure, PHP, C# et D.

Vous pouvez utiliser Doxygen de plusieurs manières :

1) Générer un fichier de configuration modèle* :
doxygen [-s] -g [NomFichierConfig]
2) Mettre à jour un fichier de configuration existant* :
doxygen [-s] -u [NomFichierConfig]
3) Générer la documentation en utilisant un fichier de configuration existant* :
doxygen [NomFichierConfig]
4) Générer un fichier modèle qui contrôle la mise en page de la documentation générée :
doxygen -l [NomFichierMiseEnPage]

Si NomFichierMiseEnPage est omis, DoxygenLayout.xml sera utilisé comme nom de fichier.
Si - est utilisé pour NomFichierMiseEnPage, Doxygen écrira sur la sortie standard.
5) Générer un fichier feuille de style modèle pour RTF, HTML ou LaTeX :
RTF : doxygen -w rtf FichierFeuilleStyle
HTML : doxygen -w html FichierEntete FichierPiedDePage FichierFeuilleStyle [FichierConfig]
LaTeX : doxygen -w latex FichierEntete FichierPiedDePage FichierFeuilleStyle [FichierConfig]
6) Générer un fichier d'extensions RTF :
RTF : doxygen -e rtf FichierExtensions

Si - est utilisé pour FichierExtensions, Doxygen écrira sur la sortie standard.
7) Comparer le fichier de configuration utilisé avec le fichier de configuration modèle :
doxygen -x [FichierConfig]

Comparer le fichier de configuration utilisé avec le fichier de configuration modèle

sans remplacer les variables d'environnement ou les variables de remplacement de type CMake :
doxygen -x_noenv [FichierConfig]
8) Afficher une liste d'emojis intégrés.
doxygen -f emoji NomFichierSortie

Si - est utilisé pour NomFichierSortie, Doxygen écrira sur la sortie standard.
*) Si -s est spécifié, les commentaires des éléments de configuration dans le fichier de configuration seront omis.
Si NomFichierConfig est omis, 'Doxyfile' sera utilisé par défaut.
Si - est utilisé pour FichierConfig, Doxygen écrira / lira la configuration depuis / vers la sortie / entrée standard.

Si -q est utilisé pour une exécution de documentation Doxygen, Doxygen considérera cela comme si QUIET=YES avait été défini.

-v affiche la chaîne de version, -V affiche des informations étendues sur la version

-h,-? affiche l'aide sur l'utilisation

doxygen -d affiche des indicateurs d'utilisation supplémentaires à des fins de débogage
