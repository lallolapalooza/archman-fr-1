Documentation de la fonction/sous-programme

subroutine dopmtr (character side, character uplo, character trans, integer m, integer n, double precision, dimension( * ) ap, double precision, dimension( * ) tau, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) work, integer info)

DOPMTR

Objectif :

!>
!> DOPMTR écrase la matrice générale réelle M-par-N C avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> où Q est une matrice réelle orthogonale d'ordre nq, avec nq = m si
!> SIDE = 'L' et nq = n si SIDE = 'R'. Q est définie comme le produit de
!> nq-1 réflexions élémentaires, tel que retourné par DSPTRD en utilisant
!> le stockage compact :
!>
!> si UPLO = 'U', Q = H(nq-1) . . . H(2) H(1);
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(nq-1).
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**T par la Gauche ;
!>          = 'R': appliquer Q ou Q**T par la Droite.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U': stockage compact triangulaire supérieur utilisé dans
!>                 l'appel précédent à DSPTRD ;
!>          = 'L': stockage compact triangulaire inférieur utilisé dans
!>                 l'appel précédent à DSPTRD.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': Pas de transposée, appliquer Q ;
!>          = 'T': Transposée, appliquer Q**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

AP

!>          AP est un tableau DOUBLE PRECISION, de dimension
!>                               (M*(M+1)/2) si SIDE = 'L'
!>                               (N*(N+1)/2) si SIDE = 'R'
!>          Les vecteurs qui définissent les réflexions élémentaires, tels
!>          que retournés par DSPTRD. AP est modifié par la routine mais
!>          restauré à la sortie.
!>

TAU

!>          TAU est un tableau DOUBLE PRECISION, de dimension (M-1) si SIDE = 'L'
!>                                     ou (N-1) si SIDE = 'R'
!>          TAU(i) doit contenir le facteur scalaire de la réflexion
!>          élémentaire H(i), tel que retourné par DSPTRD.
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (LDC,N)
!>          À l'entrée, la matrice C M-par-N.
!>          À la sortie, C est écrasé par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension
!>                                   (N) si SIDE = 'L'
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
