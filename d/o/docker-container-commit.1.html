NOM

docker-container-commit - Crée une nouvelle image à partir des modifications d'un conteneur

SYNTAXE

docker container commit [OPTIONS] CONTENEUR [RÉPERTOIRE[:TAG]]

DESCRIPTION

Crée une nouvelle image à partir d'un conteneur existant spécifié par son nom ou son identifiant. La nouvelle image contiendra le contenu du système de fichiers du conteneur, *à l'exclusion* de tout volume de données. Voir docker-tag(1) pour plus d'informations sur les noms d'image et d'étiquette valides.

Bien que la commande docker commit soit un moyen pratique d'étendre une image existante, il est préférable d'utiliser un Dockerfile et docker build pour générer des images que vous avez l'intention de partager avec d'autres personnes.

EXEMPLES

Créer une nouvelle image à partir d'un conteneur existant

Un conteneur Fedora existant a eu Apache installé pendant son exécution en mode interactif avec le shell bash. Apache est également en cours d'exécution. Pour créer une nouvelle image, exécutez docker ps pour trouver l'ID du conteneur, puis exécutez :

$ docker commit -m="Ajouté Apache à l'image de base Fedora" \
  -a="Un Administrateur" 98bd7fc99854 fedora/fedora_httpd:20

Notez que seuls les caractères a-z, 0-9, -, _ sont autorisés lors de la nomination des images à partir d'un conteneur existant.

Appliquer des instructions Dockerfile spécifiées lors de la validation de l'image

Si un conteneur existant a été créé sans la variable d'environnement DEBUG définie sur "true", vous pouvez créer une nouvelle image basée sur ce conteneur en obtenant d'abord l'ID du conteneur avec docker ps, puis en exécutant :

$ docker container commit -c="ENV DEBUG=true" 98bd7fc99854 image-debug

OPTIONS

-a, --author="" Auteur (par exemple, "John Hannibal Smith hannibal@a-team.com ⟨mailto:hannibal@a-team.com⟩")

-c, --change= Applique une instruction Dockerfile à l'image créée

-m, --message="" Message de validation

--no-pause[=false] Désactive la mise en pause du conteneur pendant la validation
