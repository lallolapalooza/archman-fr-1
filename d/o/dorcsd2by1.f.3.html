DORCSD2BY1

But :

!>
!> DORCSD2BY1 calcule la décomposition CS d'une matrice X de taille M par Q
!> à colonnes orthonormales qui a été partitionnée en une structure de
!> blocs 2 par 1 :
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 est de taille P par Q. Les matrices orthogonales U1, U2 et V1 sont
!> respectivement de tailles P par P, (M-P) par (M-P) et Q par Q. C et S
!> sont des matrices diagonales non négatives de taille R par R
!> satisfaisant C^2 + S^2 = I, où R = MIN(P,M-P,Q,M-Q). I1 est une matrice
!> identité de taille K1 par K1 et I2 est une matrice identité de taille
!> K2 par K2, où K1 = MAX(Q+P-M,0), K2 = MAX(Q-P,0).
!>

Paramètres

JOBU1 
!>          JOBU1 est de type CHARACTER
!>          = 'Y' :      U1 est calculée ;
!>          sinon :      U1 n'est pas calculée.
!>

JOBU2

!>          JOBU2 est de type CHARACTER
!>          = 'Y' :      U2 est calculée ;
!>          sinon :      U2 n'est pas calculée.
!>

JOBV1T

!>          JOBV1T est de type CHARACTER
!>          = 'Y' :      V1T est calculée ;
!>          sinon :      V1T n'est pas calculée.
!>

M

!>          M est de type INTEGER
!>          Le nombre de lignes de X.
!>

P

!>          P est de type INTEGER
!>          Le nombre de lignes de X11. 0 <= P <= M.
!>

Q

!>          Q est de type INTEGER
!>          Le nombre de colonnes de X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est un tableau de type DOUBLE PRECISION, de dimension (LDX11,Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est souhaitée.
!>

LDX11

!>          LDX11 est de type INTEGER
!>          La dimension principale de X11. LDX11 >= MAX(1,P).
!>

X21

!>          X21 est un tableau de type DOUBLE PRECISION, de dimension (LDX21,Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est souhaitée.
!>

LDX21

!>          LDX21 est de type INTEGER
!>          La dimension principale de X21. LDX21 >= MAX(1,M-P).
!>

THETA

!>          THETA est un tableau de type DOUBLE PRECISION, de dimension (R), où R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) et
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 est un tableau de type DOUBLE PRECISION, de dimension (P)
!>          Si JOBU1 = 'Y', U1 contient la matrice orthogonale U1 de taille P par P.
!>

LDU1

!>          LDU1 est de type INTEGER
!>          La dimension principale de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 est un tableau de type DOUBLE PRECISION, de dimension (M-P)
!>          Si JOBU2 = 'Y', U2 contient la matrice orthogonale U2 de taille
!>          (M-P) par (M-P).
!>

LDU2

!>          LDU2 est de type INTEGER
!>          La dimension principale de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T est un tableau de type DOUBLE PRECISION, de dimension (Q)
!>          Si JOBV1T = 'Y', V1T contient la matrice orthogonale V1**T de
!>          taille Q par Q.
!>

LDV1T

!>          LDV1T est de type INTEGER
!>          La dimension principale de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne la valeur optimale de LWORK.
!>          Si INFO > 0 à la sortie, WORK(2:R) contient les valeurs PHI(1),
!>          ..., PHI(R-1) qui, combinées avec THETA(1), ..., THETA(R),
!>          définissent la matrice restante sous forme bidiagonale par blocs
!>          après non-convergence. INFO spécifie le nombre
!>          de PHI non nuls.
!>

LWORK

!>          LWORK est de type INTEGER
!>          La dimension du tableau WORK.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau d'espace de travail, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau de type INTEGER, de dimension (M-MIN(P,M-P,Q,M-Q))
!>

INFO

!>          INFO est de type INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 :  DBBCSD n'a pas convergé. Voir la description de WORK
!>                ci-dessus pour plus de détails.
!>

    Name

    dorcsd2by1 - double-precision real general matrix

    Library

    liblapack.a

    Fortran Module Index

    This subroutine is part of the LAPACK library. For further information, please consult the LAPACK documentation.

    Description

    dorcsd2by1 can be used to compute the Schur factorization of a general double-precision real matrix.

    The Schur factorization of a matrix A is a decomposition of A into the form A = QZQT, where Q is an orthogonal matrix and Z is an upper quasi-triangular matrix. The upper quasi-triangular matrix Z has the property that it is block upper triangular, where each block on the diagonal is either a 1-by-1 matrix or a 2-by-2 matrix.

    Parameters

    A
    (input) DOUBLE PRECISION array, dimension (LDA,N). The N-by-N matrix A to be factorized.
    LDA
    (input) INTEGER. The leading dimension of the array A. LDA >= max(1,N).
    Q
    (output) DOUBLE PRECISION array, dimension (LDQ,N). If JOBU = 'Q' or 'S' or 'B', the N-by-N orthogonal matrix Q.
    LDQ
    (input) INTEGER. The leading dimension of the array Q. LDQ >= max(1,N).
    Z
    (output) DOUBLE PRECISION array, dimension (LDZ,N). The upper quasi-triangular matrix Z.
    LDZ
    (input) INTEGER. The leading dimension of the array Z. LDZ >= max(1,N).
    WORK
    (workspace) DOUBLE PRECISION array, dimension (LWORK).
    LWORK
    (input) INTEGER. The dimension of the array WORK. LWORK >= max(1,N).
    INFO
    (output) INTEGER. = 0: successful exit < 0: if INFO = -i, the i-th argument had an illegal value.
