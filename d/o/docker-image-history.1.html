NOM

docker-image-history - Afficher l'historique d'une image

SYNTAXE

docker image history [OPTIONS] IMAGE

DESCRIPTION

Affiche l'historique de la création d'une image (quand et comment).

EXEMPLES

$ docker history fedora
IMAGE          CREATED          CREATED BY                                      SIZE                COMMENT
105182bb5e8b   5 days ago       /bin/sh -c #(nop) ADD file:71356d2ad59aa3119d   372.7 MB
73bd853d2ea5   13 days ago      /bin/sh -c #(nop) MAINTAINER Lokesh Mandvekar   0 B
511136ea3c5a   10 months ago                                                    0 B                 Imported from -

Afficher les commentaires dans l'historique de l'image

La commande docker commit possède un drapeau -m pour ajouter des commentaires à l'image. Ces commentaires seront affichés dans l'historique de l'image.

$ sudo docker history docker:scm
IMAGE               CREATED             CREATED BY                                      SIZE                COMMENT
2ac9d1098bf1        3 months ago        /bin/bash                                       241.4 MB            Added Apache to Fedora base image
88b42ffd1f7c        5 months ago        /bin/sh -c #(nop) ADD file:1fd8d7f9f6557cafc7   373.7 MB            
c69cab00d6ef        5 months ago        /bin/sh -c #(nop) MAINTAINER Lokesh Mandvekar   0 B                 
511136ea3c5a        19 months ago                                                       0 B                 Imported from -

Mise en forme de la sortie

L'option de mise en forme (--format) formate la sortie de l'historique en utilisant un modèle Go.

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.ID ID de l'image
.CreatedSince Temps écoulé depuis la création de l'image si --human=true, sinon l'horodatage de la création de l'image
.CreatedAt Horodatage de la création de l'image
.CreatedBy Commande utilisée pour créer l'image
.Size Taille du disque de l'image
.Comment Commentaire de l'image

Lors de l'utilisation de l'option --format, la commande history produira soit les données exactement comme le modèle le déclare, soit, lors de l'utilisation de la directive table, inclura également les en-têtes de colonnes.

L'exemple suivant utilise un modèle sans en-têtes et affiche les entrées ID et CreatedSince séparées par un deux-points pour toutes les images :

$ docker images --format "{{.ID}}: {{.CreatedSince}} ago"
cc1b61406712: 2 weeks ago
<missing>: 2 weeks ago
<missing>: 2 weeks ago
<missing>: 2 weeks ago
<missing>: 2 weeks ago
<missing>: 3 weeks ago
<missing>: 3 weeks ago
<missing>: 3 weeks ago

OPTIONS

--format="" Formate la sortie en utilisant un modèle personnalisé : 'table' : Affiche la sortie au format tableau avec les en-têtes de colonne (par défaut) 'table TEMPLATE' : Affiche la sortie au format tableau en utilisant le modèle Go donné 'json' : Affiche en format JSON 'TEMPLATE' : Affiche la sortie en utilisant le modèle Go donné. Référez-vous à https://docs.docker.com/go/formatting/ pour plus d'informations sur la mise en forme de la sortie avec des modèles.

-H, --human[=true] Affiche les tailles et les dates dans un format lisible par l'homme.

--no-trunc[=false] Ne pas tronquer la sortie.

--platform="" Affiche l'historique pour la plateforme donnée. Formaté comme "os[/arch[/variant]]" (par exemple, "linux/amd64").

-q, --quiet[=false] N'affiche que les IDs d'image.
