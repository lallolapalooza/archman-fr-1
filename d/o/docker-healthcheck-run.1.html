NOM

podman-healthcheck-run - Exécute une vérification de santé de conteneur

SYNOPSIS

podman healthcheck run conteneur

DESCRIPTION

Exécute manuellement la commande de vérification de santé définie dans un conteneur en cours d'exécution. Les codes d'erreur résultants sont définis comme suit :

  • 0 = la commande de vérification de santé a réussi
  • 1 = la commande de vérification de santé a échoué
  • 125 = une erreur s'est produite

Les erreurs possibles qui peuvent survenir pendant la vérification de santé sont : * impossible de trouver le conteneur * le conteneur n'a pas de vérification de santé définie * le conteneur n'est pas en cours d'exécution

OPTIONS

--help

Affiche le message d'utilisation

EXEMPLES

Exécutez les vérifications de santé dans le conteneur spécifié :

$ podman healthcheck run monapplicationweb
