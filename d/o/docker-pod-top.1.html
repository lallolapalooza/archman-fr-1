NOM

podman-pod-top - Afficher les processus en cours d'exécution des conteneurs d'un pod

SYNOPSIS

podman pod top [options] pod [descripteurs-format]

DESCRIPTION

Affiche les processus en cours d'exécution des conteneurs d'un pod. Les descripteurs-format sont compatibles avec les descripteurs de format AIX de ps (1) mais étendus pour imprimer des informations supplémentaires, telles que le mode seccomp ou les capacités effectives d'un processus donné. Les descripteurs peuvent être passés comme arguments séparés ou comme un seul argument séparé par des virgules.

OPTIONS

--help, -h

Affiche le message d'utilisation

--latest, -l

Au lieu de fournir le nom ou l'ID du pod, utiliser le dernier pod créé. Note : le dernier pod démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exception de WSL2))

DESCRIPTEURS FORMAT

Pour une liste complète des descripteurs disponibles, voir podman-top(1)

EXEMPLES

Affiche les données top pour le pod spécifié. Par défaut, podman-pod-top affiche des données similaires à ps -ef :

$ podman pod top b031293491cc
USER   PID   PPID   %CPU    ELAPSED             TTY   TIME   COMMAND
root   1     0      0.000   2h5m38.737137571s   ?     0s     top
root   8     0      0.000   2h5m15.737228361s   ?     0s     top

La sortie peut être contrôlée en spécifiant des descripteurs de format comme arguments après le pod.

Affiche les champs de données top du pod pid,seccomp, args et %C sur le dernier pod créé. (Cette option -l n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exception de WSL2))

$ podman pod top -l pid seccomp args %C
PID   SECCOMP   COMMAND   %CPU
1     filter    top       0.000
1     filter    /bin/sh   0.000

VOIR AUSSI

podman(1), podman-pod(1), ps(1), seccomp(2), proc(5), capabilities(7)
