NOM

doveadm-log - Localiser, tester ou rouvrir les fichiers de log de Dovecot

SYNOPIS

doveadm [OPTIONS GLOBALES] log errors [-s timestamp_min]

doveadm [OPTIONS GLOBALES] log find [répertoire]

doveadm [OPTIONS GLOBALES] log reopen

doveadm [OPTIONS GLOBALES] log test

DESCRIPTION


sont utilisés pour localiser et rouvrir les fichiers de log de dovecot(1). Il est également possible de tester les cibles configurées du

OPTIONS GLOBALES

doveadm(1) global

-D

Active les messages de verbosité et de débogage.

-O

Ne pas lire de fichier de configuration, utiliser uniquement les valeurs par défaut. Le paramètre dovecot_storage_version prend par défaut la dernière version, mais peut être remplacé par

-k

Conserver l'environnement entier pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom_instance

Si plusieurs instances Dovecot sont utilisées, choisir le fichier de configuration basé sur ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier_config

Lire la configuration depuis le fichier_config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer ceci vers le socket de configuration d'une instance en cours d'exécution d'une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de l'userdb avec la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

COMMANDES

log errors

doveadm [OPTIONS GLOBALES] log errors [-s timestamp_min]

La commande log errors est utilisée pour afficher les 1000 dernières erreurs et avertissements. Si aucune sortie n'est générée, aucune erreur ne s'est produite depuis le dernier démarrage.

-s timestamp_min

Une valeur entière, représentant les secondes depuis l'époque - également connue sous le nom d'horodatage Unix. Lorsqu'un timestamp_min est donné, doveadm(1) n'affichera que les erreurs survenues depuis ce point dans le temps.

log find

doveadm [OPTIONS GLOBALES] log find [répertoire]


La commande est utilisée pour afficher l'emplacement des fichiers de log, vers lesquels dovecot(1) enregistre ses messages via

log reopen

doveadm [OPTIONS GLOBALES] log reopen

Cette commande provoque l'envoi d'un signal SIGUSR1 par doveadm au processus maître, ce qui lui fait rouvrir tous les fichiers de log configurés dans les paramètres log_path, info_log_path et debug_log_path. Ces paramètres sont configurés dans /etc/dovecot/conf.d/10-logging.conf.

Le processus maître signale également au processus de log de faire de même. Ceci est principalement utile après avoir fait pivoter manuellement les fichiers de log.

log test

doveadm [OPTIONS GLOBALES] log test

Cette commande provoque l'écriture par doveadm du message "Ceci est le log de priorité de Dovecot (horodatage)" dans les fichiers de log configurés. Les priorités utilisées sont : debug, info, warning, error et fatal.

EXEMPLE

Cet exemple montre comment localiser les fichiers de log utilisés par dovecot(1) :

doveadm log find
Recherche des fichiers de log à partir de /var/log
Debug : /var/log/dovecot.debug
Info : /var/log/mail.log
Avertissement : /var/log/mail.log
Erreur : /var/log/mail.log
Fatal : /var/log/mail.log
