NOM

doveadm - Utilitaire d'administration de Dovecot

SYNTAXE

doveadm [-DOkv] [-i nom-instance] [-c fichier-config] [-o clef=valeur [ .. ]] [-f formateur] commande [options-commande] [arguments-commande]

DESCRIPTION

doveadm est l'outil d'administration de Dovecot. Il peut être utilisé pour gérer diverses parties de Dovecot, ainsi que pour accéder aux boîtes aux lettres des utilisateurs.

Exécutez doveadm help pour obtenir la liste des commandes disponibles.

OPTIONS GÉNÉRALES

doveadm(1) général

-D

Active la verbeuxité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise seulement les valeurs par défaut. Le paramètre dovecot_storage_version est par défaut la dernière version, mais peut être remplacé avec

-k

Préserve l'environnement entier pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbeuxité, incluant un compteur de progression.

-i nom-instance

Si vous utilisez plusieurs instances de Dovecot, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier-config

Lit la configuration à partir du fichier-config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer cela vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

-f formateur

Spécifie le formateur pour formater la sortie. Les formateurs supportés sont :

flow

affiche chaque ligne avec des paires clef=valeur.

json

affiche un tableau JSON d'objets JSON.

pager

affiche chaque paire clef: valeur sur sa propre ligne et sépare les enregistrements par un caractère de saut de page (^L).

tab

affiche un en-tête de tableau suivi de lignes de valeurs séparées par des tabulations.

table

affiche un en-tête de tableau suivi de lignes de valeurs ajustées.

COMMANDES

Ces commandes interagissent directement avec le processus maître de Dovecot.

doveadm recharger

Force dovecot(1) à recharger la configuration.

doveadm arreter

Arrête dovecot(1) et tous ses processus enfants.

STATUT DE SORTIE

doveadm se terminera avec l'une des valeurs suivantes :

0

La commande sélectionnée a été exécutée avec succès.

64

Erreur d'utilisation de la ligne de commande.

65

Erreur de format des données ou opération impossible.

67

L'utilisateur n'existe pas.

68

Le fichier d'entrée, l'adresse ou une autre ressource n'existe pas.

73

Impossible de créer le fichier de sortie.

75

Une erreur temporaire s'est produite, vérifiez les logs.

76

Erreur de protocole lors de la connexion à l'hôte distant.

77

Erreur de permission.

78

Erreur de configuration.

127

Erreur inconnue.

ENVIRONNEMENT

USER

Cette variable d'environnement est utilisée pour déterminer l'utilisateur si une commande accepte un utilisateur mais qu'aucun n'a été spécifié.

SIGNALEMENT DES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur le signalement des bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
