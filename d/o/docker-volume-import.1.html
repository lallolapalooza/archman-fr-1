NOM

podman-volume-import - Importer le contenu d'une archive dans un volume podman existant

SYNOPSIS

podman volume import volume [source]

DESCRIPTION

podman volume import importe le contenu d'une archive dans le point de montage du volume podman. Le contenu du volume est fusionné avec le contenu de l'archive, le second ayant priorité. podman volume import peut consommer une entrée dirigée lorsque - est utilisé comme chemin source.

Le volume donné doit déjà exister et n'est pas créé par podman-volume import.

--help

Affiche l'énoncé d'utilisation

EXEMPLES

Importer le contenu d'un volume nommé depuis le fichier spécifié.

$ podman volume import monvol test.tar

Importer le contenu d'un volume nommé depuis stdin.

$ gunzip -c hello.tar.gz | podman volume import monvol -

Exporter le contenu d'un volume nommé et le diriger vers le volume nommé via stdin.

$ podman volume export ancienmonvol | podman volume import monvol -
