NOM

docker-swarm-init - Initialiser un swarm

SYNTAXE

docker swarm init [OPTIONS]

DESCRIPTION

Initialiser un swarm

OPTIONS

--advertise-addr="" Adresse annoncée (format : "[:port]")

--autolock[=false] Activer le verrouillage automatique du gestionnaire (nécessite une clé de déverrouillage pour démarrer un gestionnaire arrêté)

--availability="active" Disponibilité du nœud ("active", "pause", "drain")

--cert-expiry=2160h0m0s Période de validité des certificats de nœud (ns|us|ms|s|m|h)

--data-path-addr="" Adresse ou interface à utiliser pour le trafic du chemin de données (format : "")

--data-path-port=0 Numéro de port à utiliser pour le trafic du chemin de données (1024 - 49151). Si aucune valeur n'est définie ou si elle est définie à 0, le port par défaut (4789) est utilisé.

--default-addr-pool=[] pool d'adresses par défaut au format CIDR

--default-addr-pool-mask-length=24 longueur du masque de sous-réseau du pool d'adresses par défaut

--dispatcher-heartbeat=5s Période du heartbeat du dispatcher (ns|us|ms|s|m|h)

--external-ca= Spécifications d'un ou plusieurs points de terminaison de signature de certificat

--force-new-cluster[=false] Forcer la création d'un nouveau cluster à partir de l'état actuel

--listen-addr=0.0.0.0:2377 Adresse d'écoute (format : "[:port]")

--max-snapshots=0 Nombre d'instantanés Raft supplémentaires à conserver

--snapshot-interval=10000 Nombre d'entrées de journal entre les instantanés Raft

--task-history-limit=5 Limite de rétention de l'historique des tâches
