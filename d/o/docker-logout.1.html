NOM

docker-logout - Se déconnecter d'un registre

SYNTAXE

docker logout [SERVEUR]

DESCRIPTION

Se déconnecte d'un registre Docker situé sur le SERVEUR spécifié. Vous pouvez spécifier une URL ou un nom d'hôte pour la valeur SERVEUR. Si vous ne spécifiez pas de SERVEUR, la commande tente de vous déconnecter du registre public de Docker situé à l'adresse https://registry-1.docker.io/ par défaut.

EXEMPLES

Se déconnecter d'un registre sur votre localhost

# docker logout localhost:8080

Voir aussi

docker-login(1) pour se connecter à un registre.
