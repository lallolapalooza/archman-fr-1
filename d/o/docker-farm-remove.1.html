NOM

podman-farm-remove - Supprimer une ou plusieurs fermes

SYNOPIS

podman farm remove [options] nom

podman farm rm [options] nom

DESCRIPTION

Supprime une ou plusieurs fermes.

OPTIONS

--all, -a

Supprime toutes les fermes.

EXEMPLE

Supprimer la ferme spécifiée :

$ podman farm remove farm1

Supprimer toutes les fermes :

$ podman farm rm --all

VOIR AUSSI

podman(1), podman-farm(1)
