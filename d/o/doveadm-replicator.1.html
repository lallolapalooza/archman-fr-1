NOM

doveadm-replicator - Gérer la réplication de courrier des utilisateurs

SYNTAXE

doveadm [-Dv] [-f formateur] replicator commande [OPTIONS] [ARGUMENTS]

DESCRIPTION

Les COMMANDES de doveadm replicator peuvent être utilisées pour gérer la réplication automatisée du courrier des utilisateurs.

OPTIONS

Options globales de doveadm(1) :

-D
Active les messages de verbosité et de débogage.
-f formateur
Spécifie le formateur pour formater la sortie. Les formateurs supportés sont :
flux
imprime chaque ligne avec des paires clé=valeur.
pager
imprime chaque paire clé: valeur sur sa propre ligne et sépare les enregistrements par un saut de page (^L).
tab
imprime un en-tête de tableau suivi de lignes de valeurs séparées par des tabulations.
table
imprime un en-tête de tableau suivi de lignes de valeurs ajustées.
-o parametre=valeur
Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.
-v
Active la verbosité, y compris le compteur de progression.

Cette commande utilise par défaut le formateur de sortie flux (sans le préfixe clé=).

Options spécifiques à la commande :

-a chemin_socket_replicator
Cette option est utilisée pour spécifier un chemin absolu vers un socket domaine UNIX alternatif.

Par défaut, doveadm(1) utilisera le socket /run/dovecot/replicator-doveadm. Le socket peut se trouver dans un autre répertoire si le paramètre base_dir par défaut a été remplacé dans /etc/dovecot/dovecot.conf.

ARGUMENTS

masque_utilisateur
Spécifie pour quels utilisateurs la commande doit être exécutée. Dans la plupart des cas, vous voudrez utiliser des motifs contenant des caractères génériques, par exemple \*@example.net pour tous les utilisateurs du domaine example.net, ou simplement \* pour tous les utilisateurs.

Lorsque le module userdb SQL est utilisé, assurez-vous que le paramètre iterate_query dans /etc/dovecot/dovecot-sql.conf.ext correspond à la structure de votre base de données. Lors de l'utilisation du module userdb LDAP, assurez-vous que les paramètres iterate_attrs et iterate_filter dans /etc/dovecot/dovecot-ldap.conf.ext correspondent à votre schéma LDAP. Sinon, doveadm(1) sera incapable d'itérer sur tous les utilisateurs.

COMMANDES

replicator add

doveadm replicator add [-a chemin_socket_replicator] masque_utilisateur

Ajoute l'utilisateur spécifié (ou les utilisateurs) au réplicateur. Si le masque_utilisateur contient des caractères génériques "?" ou "*", la liste des noms d'utilisateur est recherchée dans l'userdb.

replicator dsync-status

doveadm replicator dsync-status [-a chemin_socket_replicator]

Affiche l'état des processus dsync en cours d'exécution.

replicator remove

doveadm replicator remove [-a chemin_socket_replicator] nom_utilisateur

Supprime l'utilisateur spécifié du réplicateur.

replicator replicate

doveadm replicator replicate [-a chemin_socket_replicator] [-f] [-p priorité] masque_utilisateur

Démarre immédiatement la réplication pour les utilisateurs spécifiés. Si le paramètre -f est donné, une réplication complète est effectuée pour l'utilisateur. Vous pouvez également spécifier la priorité, qui peut être haute ou basse. Si le masque d'utilisateur contient des caractères génériques "?" ou "*", la liste des noms d'utilisateur est recherchée parmi les utilisateurs actuellement présents dans le réplicateur (pas dans l'userdb).

replicator status

doveadm replicator status [-a chemin_socket_replicator] masque_utilisateur

Affiche l'état de réplication des utilisateurs.

SIGNALER  LES  BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot <dovecot@dovecot.org>. Les informations sur la manière de signaler les bogues sont disponibles sur : http://dovecot.org/bugreport.html
