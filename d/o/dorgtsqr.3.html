Documentation de la fonction/sous-programme

sous-programme dorgtsqr (integer m, integer n, integer mb, integer nb, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( * ) work, integer lwork, integer info)

DORGTSQR

Objectif:

!>
!> DORGTSQR génère une matrice réelle M-par-N, Q_out, à colonnes orthogonales,
!> qui sont les N premières colonnes d'un produit de matrices orthogonales réelles
!> réelles d'ordre M retournées par DLATSQR
!>
!>      Q_out = premières_N_colonnes_de( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Voir la documentation de DLATSQR.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB

!>          MB est un entier (INTEGER)
!>          La taille de bloc de ligne utilisée par DLATSQR pour retourner
!>          les tableaux A et T. MB > N.
!>          (Notez que si MB > M, alors M est utilisé à la place de MB
!>          comme taille de bloc de ligne).
!>

NB

!>          NB est un entier (INTEGER)
!>          La taille de bloc de colonne utilisée par DLATSQR pour retourner
!>          les tableaux A et T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille de bloc de colonne).
!>

A

!>          A est un tableau de double précision (DOUBLE PRECISION)
!>          dimension (LDA,N)
!>
!>          À l'entrée :
!>
!>             Les éléments sur et au-dessus de la diagonale ne sont pas accédés.
!>             Les éléments en dessous de la diagonale représentent la matrice
!>             trapézoïdale inférieure unitaire bloquée V calculée par DLATSQR
!>             qui définit les matrices d'entrée Q_in(k) (les uns sur la
!>             diagonale ne sont pas stockés) (même format que la sortie A
!>             en dessous de la diagonale dans DLATSQR).
!>
!>          À la sortie :
!>
!>             Le tableau A contient une matrice orthogonale M-par-N Q_out,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires orthogonaux.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

T

!>          T est un tableau de double précision (DOUBLE PRECISION)
!>          dimension (LDT, N * NIRB)
!>          où NIRB = Nombre_de_blocs_de_lignes_d'entrée
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Soit NICB = Nombre_de_blocs_de_colonnes_d'entrée
!>                   = CEIL(N/NB)
!>
!>          Les réflecteurs de blocs triangulaires supérieurs utilisés pour définir les
!>          matrices d'entrée Q_in(k), k=(1:NIRB*NICB). Les réflecteurs de blocs
!>          sont stockés sous forme compacte dans NBL * NIRB colonnes de blocs de taille NB
!>          de T et consistent en NICB plus petits blocs de colonnes NB*NB triangulaires supérieurs.
!>          (même format que la sortie T dans DLATSQR).
!>

LDT

!>          LDT est un entier (INTEGER)
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB1,N)).
!>

WORK

!>          (espace de travail) Tableau de double précision (DOUBLE PRECISION), dimension (MAX(2,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK. LWORK >= (M+NB)*N.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et aucun
!>          message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
