NOM

docker-system-df - Afficher l'utilisation du disque Docker

SYNTAXE

docker system df [OPTIONS]

DESCRIPTION

Afficher l'utilisation du disque Docker

OPTIONS

--format="" Formater la sortie en utilisant un modèle personnalisé : 'table' : Afficher la sortie au format tableau avec des en-têtes de colonne (par défaut) 'table TEMPLATE' : Afficher la sortie au format tableau en utilisant le modèle Go donné 'json' : Afficher au format JSON 'TEMPLATE' : Afficher la sortie en utilisant le modèle Go donné. Référez-vous à https://docs.docker.com/go/formatting/ pour plus d'informations sur le formatage de la sortie avec des modèles

-v, --verbose[=false] Afficher des informations détaillées sur l'utilisation de l'espace

VOIR AUSSI
