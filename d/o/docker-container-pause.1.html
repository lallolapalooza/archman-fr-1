NOM

docker-container-pause - Met en pause tous les processus d'un ou plusieurs conteneurs

SYNTAXE

docker container pause CONTENEUR [CONTENEUR...]

DESCRIPTION

La commande docker container pause suspend tous les processus des conteneurs spécifiés. Sous Linux, elle utilise le cgroup freezer. Traditionnellement, lors de la suspension d'un processus, le signal SIGSTOP est utilisé, ce qui est observable par le processus suspendu. Avec le cgroup freezer, le processus ignore qu'il est suspendu et ne peut pas le détecter, puis repris. Sous Windows, seuls les conteneurs Hyper-V peuvent être mis en pause.

Voir la documentation du cgroup freezer ⟨https://www.kernel.org/doc/Documentation/cgroup-v1/freezer-subsystem.txt⟩ pour plus de détails.

Utilisez docker-container-unpause(1) pour reprendre tous les processus d'un conteneur.
