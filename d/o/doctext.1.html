NOM

doctext - Génère des pages de documentation à partir de fichiers source

SYNTAXE

doctext [ -mpath chemin ] [ -ext n ] [ -I fichier ] [ -latex ]
[ -html ] [ -index fichier ] [ -indexdir fichier ]
[ -jumpfile fichier ] [ -outfile fichier ]
[ -mapref fichier ] [ -nolocation ] [ -location ]
[ -defn fichier_defn ] [ -dosnl ] [ -skipprefix nom ]
[ -ignore chaîne ] [ -oldargstyle ]
[ -heading chaîne ] [ -basedir répertoire ] noms_de_fichiers
[ -Wargdesc ] [ -Wnone ]

PARAMETRES D'ENTRÉE

-mpath chemin
- Définit le chemin où les pages man seront écrites
-ext n
- Définit l'extension (1-9,l, etc.)
-nolocation
- Ne pas indiquer le nom du fichier d'où proviennent les informations de la page man
-I fichier
- Le fichier contient les includes publics nécessaires à ces routines
-latex
- Générer une sortie latex plutôt que des fichiers au format man
-html
- Générer une sortie html (WWW) plutôt que des fichiers au format man
-man
- Générer une sortie man (nroff) (par défaut)
-index fichier
- Générer un fichier d'index approprié pour tohtml (pour générer des fichiers WWW)
-defn fichier_defn
- Lire les commandes de ce fichier après avoir chargé les commandes par défaut
-mapref fichier
- Lire la base de données des hyperliens et l'appliquer à la sortie
-indexdir répertoire
- Définit le répertoire racine pour les entrées du fichier d'index. Par exemple
-index foo.cit -indexdir "http://www.mcs.anl.gov/foo/man"
-outfile fichier
- Placer les pages man dans le fichier indiqué
-heading nom
- Nom pour l'en-tête (milieu de la ligne supérieure)
-quotefmt
- supporter '\\tt' et `\\em`
-oldargstyle
- Permettre plusieurs '. ' pour une liste d'arguments, au lieu d'utiliser '+ .... -' pour les listes d'arguments à entrées multiples.
-skipprefix nom
- ignorer 'nom' au début de chaque ligne. Ceci peut être utilisé pour les sources Fortran ou Shell
-ignore chaîne
- ignorer 'nom' dans un synopsis de fonction. Ceci peut être utilisé pour supprimer des mots-clés spéciaux nécessaires à la construction de la routine mais non nécessaires à l'utilisateur (par exemple, des mots-clés d'exportation spéciaux lors de la construction de DLLs)
-keyword fichier
- Placer les entrées de mots-clés à la fin du fichier spécifié
-locdir répertoire
- Utilise le répertoire dans le champ Location:
-dosnl
- Générer des fichiers de style DOS (retour chariot-nouvelle ligne au lieu de nouvelle ligne seulement)
noms_de_fichiers
- Noms des fichiers à partir desquels les documents doivent être extraits
-Wargdesc
- Avertir sur les arguments sans description
-Wnone
- Désactiver les avertissements

EMPLACEMENT

doctext.cc
