DESCRIPTIO

N

podman ps liste les conteneurs en cours d'exécution sur le système. Utilisez le drapeau --all pour afficher les informations de tous les conteneurs. Par défaut, il liste

:
  • l'identifiant du
    • conteneur
  • le nom de l'image utilisée par le
    • conteneur
  • la COMMANDE exécutée par le
    • conteneur
  • l'heure de création du
    • conteneur
  • l'état du
    • conteneur
  • les correspondances de ports utilisées par le
    • conteneur
  • les noms
    • alterna
tifs du c
onteneur

OPTION

S

--all, -

a

Affiche tous les conteneurs, par défaut seuls les conteneurs en cours d'exécution sont

listés.

Remarque : Podman partage le stockage des conteneurs avec d'autres outils tels que Buildah et CRI-O. Dans certains cas, ces conteneurs externes peuvent également exister dans le même stockage. Utilisez l'option --external pour voir ces conteneurs externes.

Les conteneurs externes af
fichent l'état 'storage'.

--externa

l

Affiche les conteneurs externes qui ne sont pas contrôlés par Podman mais sont stockés dans le stockage des conteneurs. Ces conteneurs externes sont

généralement créés via d'autres technologies de conteneurs telles que Buildah ou CRI-O et peuvent dépendre des mêmes images de conteneurs que cel
les utilisées par Podman. Les conteneurs externes sont indiqués par 'buildah' ou 'storage' dans les colonnes COMMANDE et ÉTAT de la sortie de ps.

--filter, -

f

Filtre les conteneurs affichés dans la sortie. Plusieurs filtres peuvent être donnés en utilisant plusieurs fois le drapeau --filter. Les filtres avec la même clé fonctionnent de manière inclusive, à l'exception de label qui est exclusif. Les filtres avec des clés différentes fonctionnent toujours de manière

exclusive.

c

Force la synchronisation de l'état du conteneur avec l'exécuteur OCI. Dans certains cas, l'état d'un conteneur dans l'exéc

uteur peut devenir désynchronisé avec l'état de Podman. Cela met à jour l'état de Podman en fonction de ce que l'exécuteu
r OCI rapporte. La synchronisation forcée est beaucoup plus lente, mais peut résoudre les problèmes d'état incohérent.
