podman-farm-list(1) Manuel des commandes générales podman-farm-list(1)

NOM

podman-farm-list - Lister les fermes existantes

SYNTAXE

podman farm list [options]

podman farm ls [options]

DESCRIPTION

Liste toutes les fermes existantes.

OPTIONS

--format=format

Change le format de sortie par défaut. Peut être d'un type supporté comme 'json' ou un template Go. Les placeholders valides pour le template Go sont listés ci-dessous :

Placeholder Description
.Connections Liste de toutes les connexions système dans la ferme
.Default Indique si la ferme est la ferme par défaut
.Name Nom de la ferme
.ReadWrite Indique si cette ferme peut être modifiée à l'aide des commandes podman farm

EXEMPLE

Lister toutes les fermes :

$ podman farm list
Nom         Connexions  Défaut      Écriture
farm1       [f38 f37]    faux        vrai
farm2       [f37]        vrai        vrai

Afficher les fermes au format JSON :

$ podman farm list --format json
[
  {
    "Nom": "farm1",
    "Connexions": [
      "f38",
      "f37"
    ],
    "Défaut": false,
    "Écriture": true
  },
  {
    "Nom": "farm2",
    "Connexions": [
      "f37"
    ],
    "Défaut": true,
    "Écriture": true
  }
]

Afficher uniquement les noms de fermes :

$ podman farm list --format "{{.Name}}"
farm1
farm2

Afficher des informations détaillées sur les fermes :

$ podman farm list --format "Ferme : {{.Name}} (Défaut : {{.Default}}, Écriture : {{.ReadWrite}})\nConnexions : {{.Connections}}"
Ferme : farm1 (Défaut : faux, Écriture : vrai)
Connexions : [f38 f37]
Ferme : farm2 (Défaut : vrai, Écriture : vrai)
Connexions : [f37]
