NOM

docker-volume - Gérer les volumes

SYNTAXE

docker volume COMMAND

DESCRIPTION

La commande docker volume contient des sous-commandes pour gérer les volumes de données. Un volume de données est un répertoire spécialement désigné qui contourne la gestion du pilote de stockage.

Les volumes de données conservent les données indépendamment du cycle de vie d'un conteneur. Lorsque vous supprimez un conteneur, le démon Docker ne supprime aucun volume de données. Vous pouvez partager des volumes entre plusieurs conteneurs. De plus, vous pouvez partager des volumes de données avec d'autres ressources informatiques de votre système.

Pour voir l'aide d'une sous-commande, utilisez :

docker volume COMMAND --help

Pour plus de détails sur l'utilisation de docker volume, consultez la documentation en ligne de Docker.
