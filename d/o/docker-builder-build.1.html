NOM

docker-builder-build - Construit une image à partir d'un Dockerfile

SYNTAXE

docker builder build [OPTIONS] PATH | URL | -

DESCRIPTION

Construit une image à partir d'un Dockerfile

OPTIONS

--add-host= Ajoute un mappage personnalisé hôte-IP ("hôte:ip")

--build-arg= Définit les variables de temps de construction

--cache-from=[] Images à considérer comme sources de cache

--cgroup-parent="" Définit le cgroup parent pour les instructions "RUN" pendant la construction

--compress[=false] Compresse le contexte de construction en gzip

--cpu-period=0 Limite la période CFS (Completely Fair Scheduler) du CPU

--cpu-quota=0 Limite le quota CFS (Completely Fair Scheduler) du CPU

-c, --cpu-shares=0 Parts CPU (poids relatif)

--cpuset-cpus="" CPUs dans lesquels autoriser l'exécution (0-3, 0,1)

--cpuset-mems="" MEMs dans lesquels autoriser l'exécution (0-3, 0,1)

-f, --file="" Nom du Dockerfile (Par défaut "PATH/Dockerfile")

--force-rm[=false] Supprime toujours les conteneurs intermédiaires

--iidfile="" Écrit l'ID de l'image dans le fichier

--isolation="" Technologie d'isolation du conteneur

--label= Définit des métadonnées pour une image

-m, --memory=0 Limite de mémoire

--memory-swap=0 Limite de swap égale à la mémoire plus le swap : -1 pour activer le swap illimité

--network="default" Définit le mode réseau pour les instructions RUN pendant la construction

--no-cache[=false] N'utilise pas le cache lors de la construction de l'image

--platform="" Définit la plateforme si le serveur est capable de gérer plusieurs plateformes

--pull[=false] Tente toujours de récupérer une version plus récente de l'image

-q, --quiet[=false] Supprime la sortie de construction et affiche l'ID de l'image en cas de succès

--rm[=true] Supprime les conteneurs intermédiaires après une construction réussie

--security-opt=[] Options de sécurité

--shm-size=0 Taille de "/dev/shm"

--squash[=false] Écrase les nouvelles couches construites en une seule nouvelle couche

-t, --tag= Nom et éventuellement un tag au format "nom:tag"

--target="" Définit l'étape de construction cible à construire.

--ulimit=[] Options ulimit
