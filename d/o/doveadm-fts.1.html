fts

rescan

doveadm [OPTIONS GLOBALES] fts rescan [-u utilisateur | -A | -F fichier | --no-userdb-lookup] [-S chemin-socket] [namespace

]

Analyse les courriers présents dans l'index de recherche de texte intégral et les compare à ceux réellement présents dans les boîtes aux lettres. Cela supprime de l'index les courriers déjà purgés et s'assure que le prochain doveadm index indexera tous les courriers manquants (s'il y en a). Notez que la plupart des pilotes FTS n'implémente

nt pas cela correctement, mais suppriment plutôt tous les i
ndex FTS. Cela pourrait changer dans les futures versions.

fts flatcurve

check

doveadm [OPTIONS GLOBALES] fts flatcurve check [-u utilisateur | -A | -F fichier | --no-userdb-lookup] [-S chemin-socket] [boîte_aux_lettre ...

]

Effectue une vérification simple sur les bases de données Xapian de Dovecot et tente de corriger les erreurs de base (c'est la même vérification que celle effectuée par la commande xapian-check avec l'option de ligne de commande -F)

.

boîte_aux_lettre est la liste des boîtes aux lettres à traiter. Il est possible d'utiliser des caractères génériques (* et ?) dans cette

valeur.

Pour chaque boîte aux lettres ayant des données FTS, elle produit les champs clé/valeur suivants

:

| Clé | Valeur | | --- | ----- | | mailbox | Le nom de la boîte aux lettres lisible par un humain. (clé masquée) | | guid | Le GUID de la boîte aux lettres. | | errors | Le nombre d'erreurs signalées par la bibliothèque Xapian. | | shards | Le nombre de fragments d'index traités.

|

remove

doveadm [OPTIONS GLOBALES] fts flatcurve remove [-u utilisateur | -A | -F fichier | --no-userdb-lookup] [-S chemin-socket] [boîte_aux_lettre ...

:

| Clé | Valeur | | --- | ----- | | mailbox | Le nom de la boîte aux lettres lisible par un humain. (clé masquée) | | guid | Le GUID de la boîte aux lettres.

|
