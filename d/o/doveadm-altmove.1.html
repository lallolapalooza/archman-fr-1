NOM

doveadm-altmove - Déplacer les courriels correspondants vers le stockage alternatif (dbox uniquement)

SYNTAXE

doveadm [OPTIONS GLOBALES] altmove [-r] [-S socket_path] -A requête_recherche

doveadm [OPTIONS GLOBALES] altmove [-r] [-S socket_path] -F fichier requête_recherche

doveadm [OPTIONS GLOBALES] altmove [-r] [-S socket_path] --no-userdb-lookup requête_recherche

doveadm [OPTIONS GLOBALES] altmove [-r] [-S socket_path] -u utilisateur requête_recherche

DESCRIPTION

Cette commande peut être utilisée avec le stockage sdbox ou mdbox pour déplacer les courriels vers un chemin de stockage alternatif lorsque mail_alt_path est spécifié pour l'emplacement du courrier.

Dans la première forme, doveadm(1) exécutera le

Dans la deuxième forme, la commande sera exécutée pour tous les utilisateurs listés dans le fichier donné.

Dans la troisième forme, la commande sera exécutée pour l'utilisateur contenu dans la variable d'environnement USER.

Dans la dernière forme, seuls les courriels correspondants de l'utilisateur (ou des utilisateurs) donné(s) seront déplacés vers le stockage alternatif.

OPTIONS GLOBALES

doveadm(1) global

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise uniquement les valeurs par défaut. Le paramètre dovecot_storage_version est défini par défaut sur la dernière version, mais peut être remplacé avec

-k

Préserve l'environnement entier pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom-instance

Si vous utilisez plusieurs instances Dovecot, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier-config

Lit la configuration à partir du fichier-config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Afin de remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

OPTIONS

-A

Si l'option -A est présente, la commande sera exécutée pour tous les utilisateurs. L'utilisation de cette option en combinaison avec les utilisateurs système de userdb { driver = passwd } n'est pas recommandée, car elle contient également des utilisateurs avec un UID inférieur à celui configuré avec le paramètre first_valid_uid.

Lorsque le module userdb SQL est utilisé, assurez-vous que le paramètre userdb_sql_iterate_query correspond à la disposition de votre base de données.

Lors de l'utilisation du module userdb LDAP, assurez-vous que les paramètres userdb_fields et userdb_ldap_iterate_fields correspondent à votre schéma LDAP. Sinon, doveadm(1) ne pourra pas itérer sur tous les utilisateurs.

-F fichier

Exécute la commande pour tous les utilisateurs du fichier. Ceci est similaire à l'option -A, mais au lieu d'obtenir la liste des utilisateurs à partir de l'userdb, ils sont lus à partir du fichier donné. Le fichier contient un nom d'utilisateur par ligne.

--no-userdb-lookup

Ne pas effectuer de recherche userdb. Utiliser la variable d'environnement USER pour spécifier le nom d'utilisateur.

-r

Lorsque l'option -r est donnée, cette commande fonctionne dans l'autre sens. Les courriels seront déplacés du stockage alternatif vers l'emplacement de courrier par défaut.

-S socket_path

L'argument de l'option est soit un chemin absolu vers un socket de domaine UNIX local, soit un nom d'hôte et un port (nom-hôte:port), afin de connecter un hôte distant via un socket TCP.

Cela permet à un administrateur d'exécuter des commandes de courrier doveadm(1) via le socket donné.

-u utilisateur/masque

Exécute la commande uniquement pour l'utilisateur donné. Il est également possible d'utiliser les caractères génériques '*' et '?' (par exemple, -u *@example.org).

ARGUMENTS

requête_recherche

Les messages correspondant à cette requête de recherche seront déplacés vers le stockage alt. Voir doveadm-search-query(7) pour plus de détails.

FICHIERS

/etc/dovecot/conf.d/10-mail.conf

Emplacements des boîtes aux lettres et espaces de noms.

EXEMPLE

Cet exemple déplace les courriels marqués comme lus (seen) et plus anciens qu'une semaine vers le stockage alternatif sous /nfsmount :

mail_driver = mdbox
mail_path = ~/mdbox
mail_alt_path = /nfsmount/%{home}/mdbox
doveadm altmove -u johnd@example.com seen savedbefore 1w<

SIGNALEMENT DE BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur le signalement des bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
