NOM

podman-machine-list - Lister les machines virtuelles

SYNTAXE

podman machine list [options]

podman machine ls [options]

DESCRIPTION

Lister les machines virtuelles gérées par Podman.

Podman sur MacOS et Windows nécessite une machine virtuelle. Ceci est dû au fait que les conteneurs sont basés sur Linux - les conteneurs ne fonctionnent pas sur d'autres systèmes d'exploitation car leurs fonctionnalités de base sont liées au noyau Linux. Podman machine doit être utilisé pour gérer les machines MacOS et Windows, mais peut être utilisé optionnellement sur Linux.

Rootless uniquement.

NOTE : Le fichier de configuration podman-machine est géré sous le répertoire $XDG_CONFIG_HOME/containers/podman/machine/. Modifier la variable d'environnement $XDG_CONFIG_HOME pendant que les machines sont en cours d'exécution peut entraîner un comportement inattendu. (voir podman(1))

OPTIONS

--all-providers

Afficher les machines de tous les fournisseurs

--format=format

Modifier le format de sortie par défaut. Il peut s'agir d'un type supporté tel que 'json' ou d'un modèle Go. Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.CPUs Nombre de CPU
.Created Temps depuis la création de la VM
.Default VM par défaut
.DiskSize Taille du disque de la VM
.IdentityPath Chemin du fichier d'identité ssh
.LastUp Temps depuis la dernière exécution de la VM
.Memory Mémoire allouée pour la VM
.Name Nom de la VM
.Port Port SSH pour se connecter à la VM
.RemoteUsername Nom d'utilisateur de la VM pour Podman rootless
.Running VM en cours d'exécution
.Stream Nom du flux
.Swap Swap alloué pour la VM
.UserModeNetworking Si la VM utilise le réseau en mode utilisateur
.VMType Type de VM

--help

Afficher le message d'utilisation.

--noheading, -n

Omettre les en-têtes de tableau de la liste.

--quiet, -q

Afficher uniquement le nom de la machine. Ceci implique également qu'aucun en-tête de tableau n'est imprimé.

EXEMPLES

Lister toutes les machines Podman.

$ podman machine list
NOM                    TYPE DE VM  CRÉÉ      DERNIÈRE EXÉCUTION  CPU  MÉMOIRE  TAILLE DISQUE
podman-machine-default  qemu        2 semaines  2 semaines    1     2.147Go     10.74Go

Lister toutes les machines Podman en utilisant le format de tableau spécifié.

$ podman machine ls --format "table {{.Name}}\t{{.VMType}}\t{{.Created}}\t{{.LastUp}}"
NOM                    TYPE DE VM  CRÉÉ      DERNIÈRE EXÉCUTION
podman-machine-default  qemu        2 semaines  2 semaines

Lister toutes les machines Podman au format json.

$ podman machine ls --format json
[
    {
        "Name": "podman-machine-default",
        "Default": false,
        "Created": "2021-12-27T10:36:14.373347492-05:00",
        "Running": false,
        "LastUp": "2021-12-27T11:22:50.17333371-05:00",
        "Stream": "default",
        "VMType": "qemu",
        "CPUs": 1,
        "Memory": "2147483648",
        "DiskSize": "10737418240"
    }
]
