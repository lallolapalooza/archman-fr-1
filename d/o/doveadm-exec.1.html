NOM

doveadm-exec - Exécute facilement des commandes du répertoire libexec de Dovecot.

SYNTAXE

doveadm [OPTIONS GLOBALES] exec binaire [arguments du binaire]

DESCRIPTION

Cette commande permet aux administrateurs et aux utilisateurs locaux d'exécuter simplement des commandes depuis /usr/libexec/dovecot. Par exemple, un utilisateur système connecté pourrait démarrer une session IMAP pré-authentifiée en utilisant la commande : doveadm exec imap. Un administrateur utiliserait la commande doveadm exec imap -u nom_utilisateur.

OPTIONS GLOBALES

doveadm(1) global

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise seulement les valeurs par défaut. Le paramètre dovecot_storage_version est par défaut la dernière version, mais peut être remplacé par

-k

Conserve l'environnement entier pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom_instance

Si vous utilisez plusieurs instances Dovecot, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier_config

Lit la configuration à partir du fichier_config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

ARGUMENTS

binaire

le nom d'un exécutable situé dans /usr/libexec/dovecot.

arguments du binaire

options et arguments qui seront transmis au binaire.

EXEMPLE

Cet exemple montre comment livrer un message d'un fichier à la boîte aux lettres d'un utilisateur.

doveadm exec dovecot-lda -d user@example.net -f admin@example.net < ~/stuff/welcome.msg

SIGNALER LES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur la façon de signaler les bogues sont disponibles sur : https://dovecot.org/bugreport.html
