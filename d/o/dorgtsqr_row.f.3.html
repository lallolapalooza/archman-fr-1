Documentation de la fonction/sous-programme

subroutine dorgtsqr_row (integer m, integer n, integer mb, integer nb, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( * ) work, integer lwork, integer info)

DORGTSQR_ROW

Objectif :

!>
!> DORGTSQR_ROW génère une matrice réelle M-par-N Q_out avec des
!> colonnes orthonormées à partir de la sortie de DLATSQR. Ces N colonnes
!> orthonormées sont les N premières colonnes d'un produit de matrices unitaires
!> complexes Q(k)_in d'ordre M, qui sont retournées par DLATSQR dans un
!> format spécial.
!>
!>      Q_out = premieres_colonnes_N_de( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Les matrices d'entrée Q(k)_in sont stockées dans des blocs de lignes et de
!> colonnes dans A. Voir la documentation de DLATSQR pour plus de détails sur
!> le format de Q(k)_in, où chaque Q(k)_in est représentée par des transformations
!> de Householder par blocs. Cette routine appelle une routine auxiliaire
!> DLARFB_GETT, où le calcul est effectué sur chaque bloc individuel. L'algorithme
!> balaie d'abord des blocs de colonnes de taille NB de droite à gauche en
!> commençant dans le bloc de ligne inférieur et continue jusqu'au bloc de
!> ligne supérieur (d'où _ROW dans le nom de la routine). Ce balayage est dans
!> l'ordre inverse de celui dans lequel DLATSQR génère les blocs de sortie.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB

!>          MB est INTEGER
!>          La taille du bloc de lignes utilisé par DLATSQR pour retourner
!>          les tableaux A et T. MB > N.
!>          (Notez que si MB > M, alors M est utilisé à la place de MB
!>          comme taille du bloc de lignes).
!>

NB

!>          NB est INTEGER
!>          La taille du bloc de colonnes utilisé par DLATSQR pour retourner
!>          les tableaux A et T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille du bloc de colonnes).
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>
!>          À l'entrée :
!>
!>             Les éléments sur et au-dessus de la diagonale ne sont pas utilisés
!>             en entrée. Les éléments en dessous de la diagonale représentent
!>             la matrice trapézoïdale inférieure par blocs unitaire V calculée
!>             par DLATSQR qui définit les matrices d'entrée Q_in(k) (les uns sur
!>             la diagonale ne sont pas stockés). Voir DLATSQR pour plus de
!>             détails.
!>
!>          À la sortie :
!>
!>             Le tableau A contient une matrice orthonormée M-par-N Q_out,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires
!>             orthogonaux.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau DOUBLE PRECISION,
!>          dimension (LDT, N * NIRB)
!>          où NIRB = Nombre de blocs de lignes d'entrée
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Soit NICB = Nombre de blocs de colonnes d'entrée
!>                   = CEIL(N/NB)
!>
!>          Les réflecteurs de blocs triangulaires supérieurs utilisés pour définir
!>          les matrices d'entrée Q_in(k), k=(1:NIRB*NICB). Les blocs de
!>          réflecteurs sont stockés sous forme compacte dans NIRB séquences
!>          de réflecteurs de blocs. Chacune des NIRB séquences de réflecteurs
!>          de blocs est stockée dans un bloc de colonnes NB-par-N plus grand
!>          de T et consiste en NICB blocs de colonnes plus petits NB-par-NB
!>          triangulaires supérieurs. Voir DLATSQR pour plus de détails sur
!>          le format de T.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB,N)).
!>

WORK

!>          (Espace de travail) Tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= NBLOCAL * MAX(NBLOCAL,(N-NBLOCAL)),
!>          où NBLOCAL=MIN(NB,N).
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et aucun
!>          message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
