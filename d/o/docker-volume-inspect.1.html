NOM

docker-volume-inspect - Afficher des informations détaillées sur un ou plusieurs volumes

SYNTAXE

docker volume inspect [OPTIONS] VOLUME [VOLUME...]

DESCRIPTION

Retourne des informations sur un ou plusieurs volumes. Par défaut, cette commande affiche tous les résultats dans un tableau JSON. Vous pouvez spécifier un format alternatif pour exécuter un modèle donné pour chaque résultat. Le package https://pkg.go.dev/text/template de Go décrit tous les détails du format.

OPTIONS

-f, --format="" Formater la sortie à l'aide d'un modèle personnalisé : 'json' : Afficher au format JSON 'MODÈLE' : Afficher la sortie en utilisant le modèle Go donné. Voir https://docs.docker.com/go/formatting/ pour plus d'informations sur la mise en forme de la sortie avec des modèles.
