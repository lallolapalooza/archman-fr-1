Name:
doveadm-search - search mailboxes
Synopsis:
doveadm search [OPTIONS] <expression>
Description:

Searches mailboxes for messages matching the given expression. The results are printed to standard output.

Global options:
--help
Show help message and exit.
--version
Show version information and exit.
Options:
--all-mailboxes
Search all mailboxes, not just the current one.
--count
Print only the number of messages found.
--debug
Enable debugging output.
--doveconf <file>
Use specified config file.
--format <format>
Print results in the given format. Supported formats: text (default) list raw
--machine-readable
Print results in a machine-readable format.
--verbose
Enable verbose output.
Arguments:
<expression>
The search expression. This is a space-separated list of keywords and their arguments. The following keywords are supported: ALL ANSWERED CC <address> DELETED DRAFT FLAGGED FROM <address> HEADER <field> <value> KEYWORD <keyword> NEW OLD ON <date> OR ORPHANED REPLIED SAVED SENT SIZE <size> SUBJECT <text> TEXT <text> TO <address> UNDELETED UNKEYWORD <keyword> UNSEEN X-GM-MSGID <id> X-GM-THRID <id>
Example:

Search for all messages from "john.doe@example.com":

doveadm search FROM "john.doe@example.com"

Search for all unread messages with "important" in the subject:

doveadm search UNSEEN SUBJECT "important"
Reporting bugs:

Report bugs to the Dovecot mailing list: <dovecot@dovecot.org>
