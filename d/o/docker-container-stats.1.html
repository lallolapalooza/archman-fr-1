NOM

docker-container-stats - Affiche un flux en direct des statistiques d'utilisation des ressources d'un ou plusieurs conteneurs

SYNTAXE

docker container stats [OPTIONS] [CONTAINER...]

DESCRIPTION

Affiche un flux en direct des statistiques d'utilisation des ressources d'un ou plusieurs conteneurs.

FORMAT

Formate la sortie en utilisant le modèle Go fourni.
Espaces réservés valides :
.Container - Nom ou ID du conteneur.
.Name - Nom du conteneur.
.ID - ID du conteneur.
.CPUPerc - Pourcentage du CPU.
.MemUsage - Utilisation de la mémoire.
.NetIO - Entrées/sorties réseau.
.BlockIO - Entrées/sorties disque.
.MemPerc - Pourcentage de mémoire (Non disponible sous Windows).
.PIDs - Nombre de PIDs (Non disponible sous Windows).

EXEMPLES

Exécution de docker container stats sur tous les conteneurs en cours d'exécution.

$ docker container stats
CONTAINER           CPU %               MEM USAGE / LIMIT     MEM %               NET I/O             BLOCK I/O
1285939c1fd3        0.07%               796 KiB / 64 MiB        1.21%               788 B / 648 B       3.568 MB / 512 KB
9c76f7834ae2        0.07%               2.746 MiB / 64 MiB      4.29%               1.266 KB / 648 B    12.4 MB / 0 B
d1ea048f04e4        0.03%               4.583 MiB / 64 MiB      6.30%               2.854 KB / 648 B    27.7 MB / 0 B

Exécution de docker container stats sur plusieurs conteneurs par nom et par ID.

$ docker container stats fervent_panini 5acfcb1b4fd1
CONTAINER           CPU %               MEM USAGE/LIMIT     MEM %               NET I/O
5acfcb1b4fd1        0.00%               115.2 MiB/1.045 GiB   11.03%              1.422 kB/648 B
fervent_panini      0.02%               11.08 MiB/1.045 GiB   1.06%               648 B/648 B

Exécution de docker container stats avec un format personnalisé sur tous les conteneurs (en cours d'exécution et arrêtés).

$ docker container stats --all --format "table {{.ID}}\t{{.Name}}\t{{.CPUPerc}}\t{{.MemUsage}}"
CONTAINER ID                                                       NAME                     CPU %               MEM USAGE / LIMIT
c9dfa83f0317f87637d5b7e67aa4223337d947215c5a9947e697e4f7d3e0f834   ecstatic_noether         0.00%               56KiB / 15.57GiB
8f92d01cf3b29b4f5fca4cd33d907e05def7af5a3684711b20a2369d211ec67f   stoic_goodall            0.07%               32.86MiB / 15.57GiB
38dd23dba00f307d53d040c1d18a91361bbdcccbf592315927d56cf13d8b7343   drunk_visvesvaraya       0.00%               0B / 0B
5a8b07ec4cc52823f3cbfdb964018623c1ba307bce2c057ccdbde5f4f6990833   big_heisenberg           0.00%               0B / 0B

drunk_visvesvaraya et big_heisenberg sont des conteneurs arrêtés dans l'exemple ci-dessus.

Exécution de docker container stats au format JSON.

$ docker container stats --format json
{"BlockIO":"43.9MB / 0B","CPUPerc":"0.00%","Container":"14c505d03da8","ID":"14c505d03da8","MemPerc":"0.21%","MemUsage":"4.242MiB / 1.944GiB","Name":"registry","NetIO":"4.17kB / 0B","PIDs":"13"}

OPTIONS

-a, --all[=false] Afficher tous les conteneurs (par défaut, affiche uniquement ceux en cours d'exécution)

--format="" Formate la sortie à l'aide d'un modèle personnalisé : 'table' : Affiche la sortie au format tableau avec les en-têtes de colonne (par défaut) 'table TEMPLATE' : Affiche la sortie au format tableau en utilisant le modèle Go donné 'json' : Affiche au format JSON 'TEMPLATE' : Affiche la sortie en utilisant le modèle Go donné. Référez-vous à https://docs.docker.com/go/formatting/ pour plus d'informations sur la mise en forme de la sortie avec des modèles.

--no-stream[=false] Désactive le streaming des statistiques et ne récupère que le premier résultat.

--no-trunc[=false] Ne pas tronquer la sortie.
