NOM

docker-container-attach - Connecter les flux d'entrée, de sortie et d'erreur standard locaux à un conteneur en cours d'exécution

SYNTAXE

docker container attach [OPTIONS] CONTENEUR

DESCRIPTION

La commande docker attach permet de se connecter à un conteneur en cours d'exécution en utilisant son ID ou son nom, soit pour visualiser sa sortie en cours, soit pour le contrôler de manière interactive. Vous pouvez vous connecter au même processus contenu plusieurs fois simultanément, à la manière d'un partage d'écran, ou visualiser rapidement la progression de votre processus détaché.

Pour arrêter un conteneur, utilisez CTRL-c. Cette séquence de touches envoie SIGKILL au conteneur. Vous pouvez vous détacher du conteneur (et le laisser en cours d'exécution) en utilisant une séquence de touches configurable. La séquence par défaut est CTRL-p CTRL-q. Vous configurez la séquence de touches en utilisant l'option --detach-keys ou un fichier de configuration. Voir config-json(5) pour la documentation sur l'utilisation d'un fichier de configuration.

Il est interdit de rediriger l'entrée standard d'une commande docker attach lors de la connexion à un conteneur activé pour TTY (c'est-à-dire lancé avec -i et -t).

EXEMPLES

Connexion à un conteneur

Dans cet exemple, la commande top est exécutée dans un conteneur à partir d'une image ubuntu, en mode détaché, puis on s'y connecte, et enfin on termine le conteneur avec CTRL-c :

$ docker run -d --name topdemo alpine top -b
$ docker attach topdemo
Mem: 2395856K used, 5638884K free, 2328K shrd, 61904K buff, 1524264K cached
CPU:   0% usr   0% sys   0% nic  99% idle   0% io   0% irq   0% sirq
Load average: 0.15 0.06 0.01 1/567 6
PID  PPID USER     STAT   VSZ %VSZ CPU %CPU COMMAND
1     0 root     R     1700   0%   3   0% top -b
^C

Remplacer la séquence de détachement

Utilisez l'option --detach-keys pour remplacer la séquence de touches Docker pour le détachement. Ceci est utile si la séquence par défaut de Docker entre en conflit avec une séquence de touches que vous utilisez pour d'autres applications. Il existe deux façons de définir votre propre séquence de touches de détachement : comme remplacement par conteneur individuel ou comme propriété de configuration pour l'ensemble de votre configuration.

Pour remplacer la séquence d'un conteneur individuel, utilisez le drapeau --detach-keys=clé avec la commande docker attach. Le format de la clé est soit une lettre [a-Z], soit ctrl-valeur, où valeur est l'un des éléments suivants :

  • a-z (un seul caractère alphabétique minuscule)
  • @ (arobase)
  • [ (crochet ouvrant)
  • *\\* (deux barres obliques inverses)
  • _ (underscore)
  • ^ (accent circonflexe)

Ces valeurs a, ctrl-a, X, ou *ctrl-\* sont tous des exemples de séquences de touches valides. Pour configurer une séquence de touches par défaut différente pour tous les conteneurs, voir docker(1).

OPTIONS

--detach-keys="" Remplacer la séquence de touches pour détacher un conteneur

--no-stdin[=false] Ne pas attacher STDIN

--sig-proxy[=true] Transmettre tous les signaux reçus au processus
