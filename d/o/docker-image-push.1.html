NOM

docker-image-push - Télécharger une image vers un registre

SYNTAXE

docker image push [OPTIONS] NOM[:TAGUEUR]

DESCRIPTION

Utilisez docker image push pour partager vos images vers le registre Docker Hub ⟨https://hub.docker.com⟩ ou vers un registre auto-hébergé.

Consultez docker-image-tag(1) pour plus d'informations sur les noms d'images et de tagueurs valides.

Interrompre le processus docker image push, par exemple en appuyant sur CTRL-c pendant son exécution dans un terminal, arrête l'opération de téléchargement.

Les identifiants du registre sont gérés par docker-login(1).

EXEMPLES

Télécharger une nouvelle image vers un registre

Sauvegardez d'abord la nouvelle image en trouvant l'identifiant du conteneur (en utilisant docker container ls) puis en la commitant sous un nouveau nom d'image. Notez que seuls les caractères a-z0-9-_. sont autorisés lors de la nomination des images :

# docker container commit c16378f943fe rhel-httpd

Maintenant, téléchargez l'image vers le registre en utilisant l'identifiant de l'image. Dans cet exemple, le registre est sur un hôte nommé registry-host et écoute sur le port 5000. Pour ce faire, taguez l'image avec le nom d'hôte ou l'adresse IP, et le port du registre :

# docker image tag rhel-httpd registry-host:5000/myadmin/rhel-httpd:latest
# docker image push registry-host:5000/myadmin/rhel-httpd:latest

Vérifiez que cela a fonctionné en exécutant :

# docker image ls

Vous devriez voir rhel-httpd et registry-host:5000/myadmin/rhel-httpd listés.

Télécharger tous les tagueurs d'une image

Utilisez l'option -a (ou --all-tags) pour télécharger tous les tagueurs d'une image locale.

L'exemple suivant crée plusieurs tagueurs pour une image, et télécharge tous ces tagueurs vers Docker Hub.

$ docker image tag myimage registry-host:5000/myname/myimage:latest
$ docker image tag myimage registry-host:5000/myname/myimage:v1.0.1
$ docker image tag myimage registry-host:5000/myname/myimage:v1.0
$ docker image tag myimage registry-host:5000/myname/myimage:v1

L'image est maintenant tagueé sous plusieurs noms :

$ docker image ls
REPOSITORY                          TAG        IMAGE ID       CREATED      SIZE
myimage                             latest     6d5fcfe5ff17   2 hours ago  1.22MB
registry-host:5000/myname/myimage   latest     6d5fcfe5ff17   2 hours ago  1.22MB
registry-host:5000/myname/myimage   v1         6d5fcfe5ff17   2 hours ago  1.22MB
registry-host:5000/myname/myimage   v1.0       6d5fcfe5ff17   2 hours ago  1.22MB
registry-host:5000/myname/myimage   v1.0.1     6d5fcfe5ff17   2 hours ago  1.22MB

Lors du téléchargement avec l'option --all-tags, tous les tagueurs de l'image registry-host:5000/myname/myimage sont téléchargés :

OPTIONS

-a, --all-tags[=false] Télécharger tous les tagueurs d'une image vers le dépôt

--platform="" Télécharger un manifeste spécifique à une plateforme en tant qu'image à plateforme unique vers le registre. L'index d'images ne sera pas téléchargé, ce qui signifie que d'autres manifestes, y compris les attestations, ne seront pas conservés. 'os[/arch[/variant]]' : Plateforme explicite (par exemple, linux/amd64)

-q, --quiet[=false] Supprimer la sortie détaillée
