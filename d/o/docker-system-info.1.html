NOM

docker-system-info - Afficher les informations système globales

SYNTAXE

docker system info [OPTIONS]

DESCRIPTION

Cette commande affiche des informations globales sur l'installation de Docker. Les informations affichées incluent la version du noyau, le nombre de conteneurs et d'images. Le nombre d'images affiché correspond au nombre d'images uniques. Une même image étiquetée sous différents noms n'est comptée qu'une seule fois.

Si un format est spécifié, le modèle donné sera exécuté au lieu du format par défaut. Le package text/template de Go décrit tous les détails du format.

En fonction du pilote de stockage utilisé, des informations supplémentaires peuvent être affichées, telles que le nom du pool, le fichier de données, le fichier de métadonnées, l'espace de données utilisé, l'espace total de données, l'espace de métadonnées utilisé et l'espace total de métadonnées.

Le fichier de données est l'emplacement où les images sont stockées et le fichier de métadonnées est l'emplacement où les métadonnées relatives à ces images sont stockées. Lors de la première exécution, Docker alloue une certaine quantité d'espace de données et d'espace de métadonnées à partir de l'espace disponible sur le volume où /var/lib/docker est monté.

Vous pouvez également spécifier le format de sortie :

$ docker info --format '{{json .}}'
{"ID":"4cee4408-10d2-4e17-891c-a41736ac4536","Containers":14, ...}

OPTIONS

-f, --format="" Formate la sortie en utilisant un modèle personnalisé : 'json' : Affiche au format JSON 'TEMPLATE' : Affiche la sortie en utilisant le modèle Go donné. Référez-vous à https://docs.docker.com/go/formatting/ pour plus d'informations sur le formatage de la sortie avec des modèles.
