NOM

docker-cp - Copie des fichiers/dossiers entre un conteneur et le système de fichiers local

SYNTAXE

docker cp [OPTIONS] CONTENEUR:SRC_PATH DEST_PATH|- docker cp [OPTIONS] SRC_PATH|- CONTENEUR:DEST_PATH

DESCRIPTION

Alias pour docker container cp.

OPTIONS

-a, --archive[=false] Mode archive (copie toutes les informations uid/gid)

-L, --follow-link[=false] Suit toujours les liens symboliques dans SRC_PATH

-q, --quiet[=false] Supprime l'affichage de la progression pendant la copie. L'affichage de la progression est automatiquement supprimé s'il n'y a pas de terminal attaché
