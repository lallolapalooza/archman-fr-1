NOM

doveadm-help - Afficher des informations sur les commandes doveadm

SYNOPIS

doveadm [OPTIONS GLOBALES] help [commande]

DESCRIPTION

Sans argument commande, doveadm help affichera :

  • le synopsis de la plupart des commandes doveadm(1),
  • des groupes de commandes, par exemple log ou mailbox.

Lorsque le nom d'une commande (ou d'un groupe) est donné, il affichera la page man correspondante.

OPTIONS GLOBALES

Global doveadm(1)

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise seulement les valeurs par défaut. Le paramètre dovecot_storage_version est défini par défaut sur la dernière version, mais peut être outrepassé avec

-k

Préserve l'environnement entier pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom-instance

Si plusieurs instances Dovecot sont utilisées, choisit le fichier de configuration basé sur ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier-config

Lit la configuration à partir du fichier-config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer ceci vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Outrepasse le paramètre de configuration de /etc/dovecot/dovecot.conf et de l'userdb avec la valeur donnée. Afin d'outrepasser plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

SIGNALEMENT DE BOGUES

Signalez les bugs, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Des informations sur le signalement de bugs sont disponibles à l'adresse : https://dovecot.org/bugreport.html
