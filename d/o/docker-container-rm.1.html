NOM

docker-container-rm - Supprime un ou plusieurs conteneurs

SYNTAXE

docker container rm [OPTIONS] CONTENEUR [CONTENEUR...]

DESCRIPTION

docker container rm supprime un ou plusieurs conteneurs du nœud hôte. Le nom ou l'ID du conteneur peut être utilisé. Ceci ne supprime pas les images. Vous ne pouvez pas supprimer un conteneur en cours d'exécution sauf si vous utilisez l'option -f. Pour voir tous les conteneurs sur un hôte, utilisez la commande docker container ls -a.

EXEMPLES

Suppression d'un conteneur en utilisant son ID

Pour supprimer un conteneur en utilisant son ID, trouvez-le à partir d'une commande docker ps -a, ou utilisez l'ID retourné par la commande docker run, ou récupérez-le à partir d'un fichier utilisé pour le stocker en utilisant docker run --cidfile :

docker container rm abebf7571666

Suppression d'un conteneur en utilisant le nom du conteneur

Le nom du conteneur peut être trouvé en utilisant la commande docker ps -a. Utilisez ce nom comme suit :

docker container rm hopeful_morse

Suppression d'un conteneur et de tous les volumes associés

$ docker container rm -v redis
redis

Cette commande supprimera le conteneur et tous les volumes qui lui sont associés. Notez que si un volume a été spécifié avec un nom, il ne sera pas supprimé.

$ docker create -v awesome:/foo -v /bar --name hello redis
hello
$ docker container rm -v hello

Dans cet exemple, le volume pour /foo restera intact, mais le volume pour /bar sera supprimé. Le même comportement s'applique aux volumes hérités avec --volumes-from.

OPTIONS

-f, --force[=false] Force la suppression d'un conteneur en cours d'exécution (utilise SIGKILL)

-l, --link[=false] Supprime le lien spécifié

-v, --volumes[=false] Supprime les volumes anonymes associés au conteneur
