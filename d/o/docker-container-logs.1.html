NOM

docker-container-logs - Récupérer les logs d'un conteneur

SYNTAXE

docker container logs [OPTIONS] CONTENEUR

DESCRIPTION

La commande docker container logs récupère par lots les logs présents pour un conteneur au moment de l'exécution. Cela ne garantit pas l'ordre d'exécution lorsqu'il est combiné avec `docker run` (c'est-à-dire que votre `run` n'a peut-être généré aucun log au moment où vous exécutez `docker container logs`).

La commande docker container logs --follow combine les commandes docker container logs et docker attach. Elle renverra d'abord tous les logs depuis le début, puis continuera à diffuser en continu la nouvelle sortie du stdout et stderr du conteneur.

Attention : Cette commande ne fonctionne que pour les pilotes de journalisation json-file ou journald.

Les options --since et --until peuvent être des horodatages Unix, des horodatages formatés par date, ou des chaînes de durée Go supportées par ParseDuration ⟨https://pkg.go.dev/time#ParseDuration⟩ (par exemple, 10m, 1h30m) calculées par rapport à l'heure de la machine cliente. Les formats supportés pour les horodatages formatés par date incluent RFC3339Nano, RFC3339, 2006-01-02T15:04:05, 2006-01-02T15:04:05.999999999, 2006-01-02T07:00, et 2006-01-02. Le fuseau horaire local sur le client sera utilisé si vous ne fournissez pas de décalage de fuseau horaire Z ou +-00:00 à la fin de l'horodatage. Lors de la fourniture d'horodatages Unix, entrez les secondes [.nanosecondes], où les secondes sont le nombre de secondes écoulées depuis le 1er janvier 1970 (minuit UTC/GMT), sans compter les secondes bissextiles (également appelé époque Unix ou temps Unix), et le champ optionnel .nanosecondes est une fraction de seconde ne dépassant pas neuf chiffres. Vous pouvez combiner les options --since ou --until avec l'une ou les deux options --follow ou --tail.

La commande docker container logs --details ajoutera des attributs supplémentaires, tels que les variables d'environnement et les labels, fournis à --log-opt lors de la création du conteneur.

Afin de récupérer les logs avant un point temporel spécifique, exécutez :

$ docker run --name test -d busybox sh -c "while true; do $(echo date); sleep 1; done"
$ date
Mar 14 Nov 2017 16:40:00 CET
$ docker logs -f --until=2s test
Mar 14 Nov 2017 16:40:00 CET
Mar 14 Nov 2017 16:40:01 CET
Mar 14 Nov 2017 16:40:02 CET

OPTIONS

--details[=false] Afficher les détails supplémentaires fournis aux logs

-f, --follow[=false] Suivre la sortie des logs

--since="" Afficher les logs depuis un horodatage (par ex. "2013-01-02T13:23:37Z") ou relatif (par ex. "42m" pour 42 minutes)

-n, --tail="all" Nombre de lignes à afficher depuis la fin des logs

-t, --timestamps[=false] Afficher les horodatages

--until="" Afficher les logs avant un horodatage (par ex. "2013-01-02T13:23:37Z") ou relatif (par ex. "42m" pour 42 minutes)
