doublecmd(1) Manuel des commandes générales doublecmd(1)

NOM

doublecmd - Gestionnaire de fichiers de type Commander à double panneau.

SYNTAXE

doublecmd [-C] [-T] [-P G|D] [ chemin1 ] [ chemin2 ]
doublecmd [-C] [-T] [-P G|D] [-G chemin1 ] [-D chemin2 ]

DESCRIPTION

Double Commander est un gestionnaire de fichiers open source, gratuit et multiplateforme, avec deux panneaux côte à côte. Il est inspiré de Total Commander et présente quelques nouvelles idées.

OPTIONS

Les options ne sont PAS sensibles à la casse.

<chemin1> [<chemin2>]
Si un chemin est passé, il est chargé dans le panneau actif. Si deux chemins sont passés, le premier est chargé dans le panneau de gauche et le second dans le panneau de droite.
Les noms de répertoires contenant des espaces doivent être mis entre guillemets doubles.
Spécifiez toujours le chemin complet.
-C, --client
Si Double Commander est déjà en cours d'exécution, il est activé et les chemins de la ligne de commande sont transmis à cette instance.
-G <chemin>
Définit le répertoire à afficher dans le panneau de gauche.
-D <chemin>
Définit le répertoire à afficher dans le panneau de droite.
-P G|D
Définit le panneau actif au démarrage du programme : -P G pour la gauche et -P D pour la droite.
-T
Ouvre le(s) répertoire(s) passé(s) dans de nouveaux onglet(s).
--config-dir=<chemin>
Définit un chemin de répertoire personnalisé avec les fichiers de configuration de Double Commander.
Par défaut, c'est $HOME/.config/doublecmd.
--servername=x
Définit le nom de l'instance (serveur) de Double Commander, qui peut ensuite être utilisé pour passer des paramètres.
S'il n'y a pas d'instance existante, elle est créée.
S'il existe déjà une instance et que l'instance actuelle est un client, les paramètres sont envoyés au serveur (c'est-à-dire à l'instance existante).
S'il existe déjà une instance et que l'instance actuelle n'est pas un client (c'est-à-dire que « Autoriser une seule copie de DC à la fois » est faux et qu'aucune option --client / -c n'a été donnée), alors le nom du serveur fourni par l'utilisateur est modifié : d'abord, on ajoute simplement un nombre final « 2 ».
S'il y a déjà un nombre final, on l'augmente de 1, jusqu'à trouver un nom de serveur qui n'est pas encore occupé, puis on crée une instance avec ce nom de serveur.
--no-splash
Désactive l'écran de démarrage au lancement de DC.
