DESCRIPTIO

N

Le shell exécutera les commandes du fichier dans l'environnement

courant.

Si fichier ne contient pas de <slash>, le shell utilisera le chemin de recherche spécifié par PATH pour trouver le répertoire contenant fichier. Contrairement à la recherche normale de commandes, cependant, le fichier recherché par l'utilitaire dot n'a pas besoin d'être exécutable. Si aucun fichier lisible n'est trouvé, un shell non interactif se terminera ; un shell interacti

f écrira un message de diagnostic sur l'erreur standard, mais cette
condition ne doit pas être considérée comme une erreur de syntaxe.

JUSTIFICATIO

N

Certaines implémentations anciennes recherchaient le fichier dans le répertoire courant, même si la valeur de PATH le désactivait. Ce comportement a été omis de ce volume de POSIX.1‐2017 en raison de préoccupations concernant l'introduction de la vulnérabilité aux chevaux de Troie que l'utilisateur pourrait essayer d'éviter en laissant dot hors de PATH

.

La version KornShell de dot accepte des arguments facultatifs qui sont affectés aux paramètres positionnels. Il s'agit d'une extension valide qui permet à un script dot de se comporter de maniè

re identique à
une fonction.
