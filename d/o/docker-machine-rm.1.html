NOM

podman-machine-rm - Supprimer une machine virtuelle

SYNTAXE

podman machine rm [options] [nom]

DESCRIPTION

Supprime une machine virtuelle et ses fichiers associés. Ce qui est effectivement supprimé dépend du type de machine virtuelle. Pour toutes les machines virtuelles, les connexions système podman générées sont supprimées. Les fichiers d'allumage générés pour cette VM sont également supprimés, tout comme son fichier image sur le système de fichiers.

Les utilisateurs reçoivent un affichage de ce qui est supprimé et doivent confirmer, sauf si l'option --force est utilisée.

Le nom de machine par défaut est podman-machine-default. Si aucun nom de machine n'est spécifié en tant qu'argument, alors podman-machine-default sera supprimé.

Rootless uniquement.

OPTIONS

--force, -f

Arrête et supprime sans confirmation.

--help

Affiche le message d'utilisation.

--save-ignition

Ne supprime pas le fichier d'allumage généré.

--save-image

Ne supprime pas l'image de la VM.

EXEMPLES

Supprime la machine Podman spécifiée.

$ podman machine rm test1
Les fichiers suivants seront supprimés :
/home/user/.config/containers/podman/machine/qemu/test1.ign
/home/user/.local/share/containers/podman/machine/qemu/test1_fedora-coreos-33.20210315.1.0-qemu.x86_64.qcow2
/home/user/.config/containers/podman/machine/qemu/test1.json
Êtes-vous sûr de vouloir continuer ? [y/N] y

Supprime la machine Podman spécifiée même si elle est en cours d'exécution.

$ podman machine rm -f test1
$
