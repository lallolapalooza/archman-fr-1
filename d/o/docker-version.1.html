NOM

docker-version - Afficher les informations de version de Docker

SYNTAXE

docker version [OPTIONS]

DESCRIPTION

La commande version affiche le numéro de version actuel pour tous les composants Docker versionnés indépendamment.

EXEMPLES

Afficher les informations de version de Docker

La sortie par défaut rend toutes les informations de version divisées en deux sections ; la section « Client » contient des informations sur la CLI Docker et les composants client, et la section « Serveur » contient des informations sur le moteur Docker et les composants utilisés par le moteur, tels que les moteurs OCI « Containerd » et « Runc ».

Les informations affichées peuvent différer en fonction de la manière dont vous avez installé Docker et des composants utilisés. L'exemple suivant montre la sortie sur une machine macOS exécutant Docker Desktop :

$ docker version
Client: Docker Engine - Community
 Version:           28.5.1
 API version:       1.51
 Go version:        go1.24.8
 Git commit:        e180ab8
 Built:             Wed Oct  8 12:16:17 2025
 OS/Arch:           darwin/arm64
 Context:           desktop-linux
Server: Docker Desktop 4.49.0 (12345)
 Engine:
  Version:          28.5.1
  API version:      1.51 (minimum version 1.24)
  Go version:       go1.24.8
  Git commit:       f8215cc
  Built:            Wed Oct  8 12:18:25 2025
  OS/Arch:          linux/arm64
  Experimental:     false
 containerd:
  Version:          1.7.27
  GitCommit:        05044ec0a9a75232cad458027ca83437aae3f4da
 runc:
  Version:          1.2.5
  GitCommit:        v1.2.5-0-g59923ef
 docker-init:
  Version:          0.19.0
  GitCommit:        de40ad0

Obtenir la version du serveur :

$ docker version --format '{{.Server.Version}}'
28.5.1

Exporter les données brutes :

Pour afficher tous les champs disponibles, vous pouvez utiliser le format {{json .}}.

$ docker version --format '{{json .}}'
{"Client":"Version":"28.5.1","ApiVersion":"1.51", ...}

OPTIONS

-f, --format="" Format de sortie à l'aide d'un modèle personnalisé : 'json' : Afficher au format JSON 'TEMPLATE' : Afficher la sortie à l'aide du modèle Go donné. Consulter https://docs.docker.com/go/formatting/ pour plus d'informations sur le formatage de la sortie avec des modèles.
