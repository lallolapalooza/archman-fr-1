Documentation de la fonction/de la sous-routine

sous-routine dorbdb1 (integer m, integer p, integer q, double precision, dimension(ldx11,*) x11, integer ldx11, double precision, dimension(ldx21,*) x21, integer ldx21, double precision, dimension(*) theta, double precision, dimension(*) phi, double precision, dimension(*) taup1, double precision, dimension(*) taup2, double precision, dimension(*) tauq1, double precision, dimension(*) work, integer lwork, integer info)

DORBDB1

But :

!>
!> DORBDB1 réduit simultanément en bidiagonalisation les blocs d'une
!> matrice haute et étroite X avec des colonnes orthonormales :
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 est de dimension P-par-Q, et X21 est de dimension (M-P)-par-Q. Q ne doit pas être supérieur à P,
!> M-P, ou M-Q. Les routines DORBDB2, DORBDB3 et DORBDB4 traitent les cas où
!> Q n'est pas la dimension minimale.
!>
!> Les matrices orthogonales P1, P2 et Q1 sont de dimensions P-par-P, (M-P)-par-(M-P),
!> et (M-Q)-par-(M-Q), respectivement. Elles sont représentées implicitement par
!> des vecteurs de Householder.
!>
!> B11 et B12 sont des matrices bidiagonales de dimension Q-par-Q représentées implicitement par
!> les angles THETA et PHI.
!>
!>

Paramètres

M 
!>          M est un INTEGER
!>           Le nombre de lignes de X11 plus le nombre de lignes de X21.
!>

P

!>          P est un INTEGER
!>           Le nombre de lignes de X11. 0 <= P <= M.
!>

Q

!>          Q est un INTEGER
!>           Le nombre de colonnes de X11 et de X21. 0 <= Q <=
!>           MIN(P,M-P,M-Q).
!>

X11

!>          X11 est un tableau DOUBLE PRECISION, dimension (LDX11,Q)
!>           À l'entrée, le bloc supérieur de la matrice X à réduire. À
!>           la sortie, les colonnes de tril(X11) spécifient les réflecteurs pour P1 et
!>           les lignes de triu(X11,1) spécifient les réflecteurs pour Q1.
!>

LDX11

!>          LDX11 est un INTEGER
!>           La dimension principale de X11. LDX11 >= P.
!>

X21

!>          X21 est un tableau DOUBLE PRECISION, dimension (LDX21,Q)
!>           À l'entrée, le bloc inférieur de la matrice X à réduire. À
!>           la sortie, les colonnes de tril(X21) spécifient les réflecteurs pour P2.
!>

LDX21

!>          LDX21 est un INTEGER
!>           La dimension principale de X21. LDX21 >= M-P.
!>

THETA

!>          THETA est un tableau DOUBLE PRECISION, dimension (Q)
!>           Les entrées des blocs bidiagonaux B11, B21 sont définies par
!>           THETA et PHI. Voir Détails supplémentaires.
!>

PHI

!>          PHI est un tableau DOUBLE PRECISION, dimension (Q-1)
!>           Les entrées des blocs bidiagonaux B11, B21 sont définies par
!>           THETA et PHI. Voir Détails supplémentaires.
!>

TAUP1

!>          TAUP1 est un tableau DOUBLE PRECISION, dimension (P)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           P1.
!>

TAUP2

!>          TAUP2 est un tableau DOUBLE PRECISION, dimension (M-P)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           P2.
!>

TAUQ1

!>          TAUQ1 est un tableau DOUBLE PRECISION, dimension (Q)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           Q1.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK)
!>

LWORK

!>          LWORK est un INTEGER
!>           La dimension du tableau WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, une interrogation de l'espace de travail est supposée ; la routine
!>           calcule uniquement la taille optimale du tableau WORK, renvoie
!>           cette valeur comme la première entrée du tableau WORK, et aucun message d'erreur
!>           lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un INTEGER
!>           = 0 :  sortie réussie.
!>           < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

!>
!>  Les blocs bidiagonaux supérieurs B11, B21 sont représentés implicitement par
!>  les angles THETA(1), ..., THETA(Q) et PHI(1), ..., PHI(Q-1). Chaque entrée
!>  dans chaque bande bidiagonale est un produit d'un sinus ou cosinus d'un THETA
!>  avec un sinus ou cosinus d'un PHI. Voir [1] ou DORCSD pour plus de détails.
!>
!>  P1, P2 et Q1 sont représentés comme des produits de réflecteurs élémentaires.
!>  Voir DORCSD2BY1 pour plus de détails sur la génération de P1, P2 et Q1 à l'aide de DORGQR
!>  et DORGLQ.
!>

Références :
