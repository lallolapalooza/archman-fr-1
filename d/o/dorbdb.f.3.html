DORBD

B

But

: 
!>
!> DORBDB met simultanément en forme bidiagonale les blocs d'une matrice
!> orthogonale X partitionnée de taille M par M :
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**T
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0 0  I ]
!>
!> X11 est de taille P par Q. Q ne doit pas être supérieur à P, M-P, ou M-Q. (Si ce
!> n'est pas le cas, alors X doit être transposé et/ou permuté. Cela peut
!> être fait en temps constant à l'aide des options TRANS et SIGNS. Voir DORCSD
!> pour plus de détails.)
!>
!> Les matrices orthogonales P1, P2, Q1 et Q2 sont respectivement de tailles P par P, (M-P) par
!> (M-P), Q par Q et (M-Q) par (M-Q). Elles sont
!> représentées implicitement par des vecteurs de Householder.
!>
!> B11, B12, B21 et B22 sont des matrices bidiagonales de taille Q par Q représentées
!> implicitement par les angles THETA et PHI.
!
>

NAME


dorbdb


décomposition de valeurs singulières bidiagonales d'une matrice bidiagonale de grande taille

Function/Subroutine Documentation




  SUBROUTINE DORDBB( VECTS, ROL, THETA, PHI, A )

  -- /Author/
  --
  -- Univ. of Tennessee
  -- Univ. of California Berkeley
  -- Univ. of Colorado Denver
  -- NAG Ltd.
  --
  -- /Details:/
  --
  -- This routine implements the description in Chapter 3 of the LAPACK
  -- Users' Guide.
  --
  -- The bidiagonal blocks B11, B12, B21, and B22 are represented
  -- implicitly by angles THETA(1), ..., THETA(Q) and PHI(1), ...,
  -- PHI(Q-1). B11 and B21 are upper bidiagonal, while B21 and B22 are
  -- lower bidiagonal. Every entry in each bidiagonal band is a product
  -- of a sine or cosine of a THETA with a sine or cosine of a PHI. See
  -- [1] or DORCSD for details.
  --
  -- P1, P2, Q1, and Q2 are represented as products of elementary
  -- reflectors. See DORCSD for details on generating P1, P2, Q1, and Q2
  -- using DORGQR and DORGLQ.
  --
  -- /References:/
  --
  -- [1] Brian D. Sutton. Computing the complete CS
  --     decomposition. Numer. Algorithms, 50(1):33-65, 2009.
  --
  -- Argument Description:
  --
  -- VECTS   (input) LOGICAL
  --         = TRUE.:  the bidiagonal vectors are computed and stored in
  --                  A.
  --         = FALSE.: the bidiagonal vectors are not computed.
  --
  -- ROL     (output) INTEGER
  --         The number of rows and columns of the bidiagonal blocks
  --         A11, A12, A21, A22.
  --
  -- THETA   (output) DOUBLE PRECISION array, DIMENSION ( Q )
  --         The angles used to represent the bidiagonal blocks.
  --
  -- PHI     (output) DOUBLE PRECISION array, DIMENSION ( Q - 1 )
  --         The angles used to represent the bidiagonal blocks.
  --
  -- A       (input/output) DOUBLE PRECISION array, DIMENSION ( LDA, N )
  --         On entry, the bidiagonal matrix A.
  --         On exit, if VECTS = TRUE, the bidiagonal matrix is
  --         overwritten by information which, when processed by
  --         DORCSD, yields the bidiagonal vectors.
  --
  -- INFO    (output) INTEGER
  --         = 0:  successful exit.
  --         < 0:  if INFO = -i, the i-th argument had an illegal value.
  --

Further Details:




  The bidiagonal blocks B11, B12, B21, and B22 are represented
  implicitly by angles THETA(1), ..., THETA(Q) and PHI(1), ...,
  PHI(Q-1). B11 and B21 are upper bidiagonal, while B21 and B22 are
  lower bidiagonal. Every entry in each bidiagonal band is a product
  of a sine or cosine of a THETA with a sine or cosine of a PHI. See
  [1] or DORCSD for details.

  P1, P2, Q1, and Q2 are represented as products of elementary
  reflectors. See DORCSD for details on generating P1, P2, Q1, and Q2
  using DORGQR and DORGLQ.
