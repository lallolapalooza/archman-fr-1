NOM

doveadm-index - Indexer les boîtes aux lettres

SYNTAXE

doveadm [OPTIONS GLOBALES] index [-S socket_path] -A [-q] [-n max_recent] mailbox

doveadm [OPTIONS GLOBALES] index [-S socket_path] -F fichier [-q] [-n max_recent] mailbox

doveadm [OPTIONS GLOBALES] index [-S socket_path] --no-userdb-lookup [-q] [-n max_recent] mailbox

doveadm [OPTIONS GLOBALES] index [-S socket_path] -u utilisateur [-q] [-n max_recent] mailbox

DESCRIPTION

Ajoute les messages non indexés d'une boîte aux lettres dans un fichier d'index/cache. Si la recherche plein texte est activée, ajoute également les messages non indexés à la base de données fts.

La mise en cache n'ajoute que les champs qui ont été précédemment ajoutés aux décisions de mise en cache de la boîte aux lettres, elle ne fera donc rien d'utile pour les boîtes aux lettres auxquelles le client de l'utilisateur n'a pas encore accédé. Vous pouvez utiliser la commande doveadm dump pour afficher les décisions de mise en cache actuelles d'une boîte aux lettres spécifique.

Les messages peuvent également être ajoutés automatiquement à l'index de recherche plein texte en utilisant :

fts_autoindex = yes

OPTIONS GÉNÉRALES

doveadm(1) général

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise seulement les valeurs par défaut. Le réglage dovecot_storage_version est défini par défaut sur la dernière version, mais peut être remplacé par

-k

Préserve l'environnement entier pour doveadm, pas seulement le réglage import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom-instance

Si plusieurs instances Dovecot sont utilisées, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le réglage instance_name pour plus d'informations.

-c fichier-config

Lit la configuration depuis le fichier-config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer vers le socket de configuration d'une instance exécutant une version compatible.

-o réglage=valeur

Remplace le réglage de configuration de /etc/dovecot/dovecot.conf et de la base de données utilisateurs par la valeur donnée. Pour remplacer plusieurs réglages, l'option -o peut être spécifiée plusieurs fois.

OPTIONS

-A

Si l'option -A est présente, la commande sera effectuée pour tous les utilisateurs. L'utilisation de cette option en combinaison avec les utilisateurs système de userdb { driver = passwd } n'est pas recommandée, car elle contient également les utilisateurs avec un UID inférieur à celui configuré avec le réglage first_valid_uid.

Lorsque le module de base de données utilisateur SQL est utilisé, assurez-vous que le réglage userdb_sql_iterate_query correspond à la disposition de votre base de données.

Lors de l'utilisation du module de base de données utilisateur LDAP, assurez-vous que les réglages userdb_fields et userdb_ldap_iterate_fields correspondent à votre schéma LDAP. Sinon, doveadm(1) ne pourra pas itérer sur tous les utilisateurs.

-F fichier

Exécute la commande pour tous les utilisateurs du fichier. Ceci est similaire à l'option -A, mais au lieu d'obtenir la liste des utilisateurs à partir de la base de données utilisateurs, ils sont lus depuis le fichier donné. Le fichier contient un nom d'utilisateur par ligne.

-n max_recent

Une valeur entière, qui spécifie le nombre maximum de messages \Recent dans les boîtes aux lettres. Si la boîte aux lettres contient plus de max_recent messages avec le drapeau \Recent défini, la boîte aux lettres ne sera pas indexée. Ceci peut être utile pour éviter une indexation inutile pour les grandes boîtes aux lettres qui ne sont jamais ouvertes.

--no-userdb-lookup

Ne pas effectuer de recherche dans la base de données utilisateurs. Utilisez la variable d'environnement USER pour spécifier le nom d'utilisateur.

-q

Met en file d'attente l'indexation pour être exécutée par le processus d'indexation. Sans -q, l'indexation est effectuée directement par le processus doveadm(1). Certains pilotes ne peuvent pas gérer plusieurs processus mettant à jour les index simultanément, donc -q doit généralement être utilisé en production.

-S socket_path

L'argument de l'option est soit un chemin absolu vers un socket de domaine UNIX local, soit un nom d'hôte et un port (nom-hôte:port), afin de se connecter à un hôte distant via un socket TCP.

Cela permet à un administrateur d'exécuter les commandes de messagerie doveadm(1) via le socket donné.

-u utilisateur/masque

Exécute la commande uniquement pour l'utilisateur donné. Il est également possible d'utiliser les jokers '*' et '?' (par exemple, -u *@example.org).

ARGUMENTS

mailbox

Le nom de la boîte aux lettres à indexer.

EXEMPLE

Indexer la boîte INBOX de bob :

doveadm index -u bob INBOX

SIGNALER DES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur la façon de signaler les bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
