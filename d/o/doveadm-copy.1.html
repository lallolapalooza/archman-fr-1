NOM

doveadm-copy - Copie les messages correspondant à la requête de recherche donnée dans une autre boîte aux lettres

SYNTAXE

doveadm [OPTIONS GLOBALES] move [-S socket_path] -A destination [user source_user] requête_de_recherche

doveadm [OPTIONS GLOBALES] move [-S socket_path] -F fichier destination [user source_user] requête_de_recherche

doveadm [OPTIONS GLOBALES] move [-S socket_path] --no-userdb-lookup destination [user source_user] requête_de_recherche

doveadm [OPTIONS GLOBALES] move [-S socket_path] -u utilisateur destination [user source_user] requête_de_recherche

doveadm [OPTIONS GLOBALES] copy [-S socket_path] -A destination [user source_user] requête_de_recherche

doveadm [OPTIONS GLOBALES] copy [-S socket_path] -F fichier destination [user source_user] requête_de_recherche

doveadm [OPTIONS GLOBALES] copy [-S socket_path] --no-userdb-lookup destination [user source_user] requête_de_recherche

doveadm [OPTIONS GLOBALES] copy [-S socket_path] -u utilisateur destination [user source_user] requête_de_recherche

DESCRIPTION

doveadm move peut être utilisé pour déplacer des courriels entre boîtes aux lettres pour un ou plusieurs utilisateurs. La requête_de_recherche est utilisée pour restreindre les messages qui sont déplacés dans la boîte aux lettres de destination.

doveadm copy se comporte de la même manière que doveadm move, sauf que les messages copiés ne seront pas supprimés après la copie.

Dans la première forme, doveadm(1) itérera sur tous les utilisateurs, trouvés dans le configuré

Dans la deuxième forme, doveadm(1) itérera sur tous les utilisateurs, trouvés dans le donné

Dans la troisième forme, les courriels correspondants seront déplacés ou copiés uniquement pour le(s) utilisateur(s) donné(s).

OPTIONS GÉNÉRALES

doveadm(1) général

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise seulement les valeurs par défaut. Le réglage dovecot_storage_version est par défaut la dernière version, mais peut être remplacé avec

-k

Préserve l'environnement entier pour doveadm, pas seulement le réglage import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom_instance

Si vous utilisez plusieurs instances de Dovecot, choisissez le fichier de configuration basé sur ce nom d'instance.

Voir le réglage instance_name pour plus d'informations.

-c fichier_config

Lit la configuration depuis le fichier_config donné. Par défaut, il lit d'abord le socket de configuration, puis revient à /etc/dovecot/dovecot.conf. Vous pouvez aussi pointer ceci vers le socket de configuration d'une instance en cours d'exécution compatible.

-o réglage=valeur

Remplace le réglage de configuration de /etc/dovecot/dovecot.conf et de la base d'utilisateurs par la valeur donnée. Pour remplacer plusieurs réglages, l'option -o peut être spécifiée plusieurs fois.

OPTIONS

-A

Si l'option -A est présente, la commande sera exécutée pour tous les utilisateurs. Utiliser cette option en combinaison avec les utilisateurs système de userdb { driver = passwd } n'est pas recommandé, car elle contient également les utilisateurs avec un UID inférieur à celui configuré avec le réglage first_valid_uid.

Lorsque le module userdb SQL est utilisé, assurez-vous que le réglage userdb_sql_iterate_query correspond à la structure de votre base de données.

Lorsque le module userdb LDAP est utilisé, assurez-vous que les réglages userdb_fields et userdb_ldap_iterate_fields correspondent à votre schéma LDAP. Sinon, doveadm(1) sera incapable d'itérer sur tous les utilisateurs.

-F fichier

Exécute la commande pour tous les utilisateurs du fichier. Ceci est similaire à l'option -A, mais au lieu d'obtenir la liste des utilisateurs à partir de la base d'utilisateurs, ils sont lus à partir du fichier donné. Le fichier contient un nom d'utilisateur par ligne.

--no-userdb-lookup

N'effectue pas de recherche dans la base d'utilisateurs. Utilisez la variable d'environnement USER pour spécifier le nom d'utilisateur.

-S socket_path

L'argument de l'option est soit un chemin absolu vers un socket de domaine UNIX local, soit un nom d'hôte et un port (nom_hôte:port), afin de se connecter à un hôte distant via un socket TCP.

Cela permet à un administrateur d'exécuter des commandes de messagerie doveadm(1) via le socket donné.

-u utilisateur/masque

Exécute la commande uniquement pour l'utilisateur donné. Il est également possible d'utiliser les jokers '*' et '?' (par exemple -u *@example.org).

ARGUMENTS

destination

Le nom de la boîte aux lettres de destination, dans laquelle les courriels doivent être déplacés ou copiés. La boîte aux lettres de destination doit exister, sinon cette commande échouera.

requête_de_recherche

Déplace/copie les messages correspondant à la requête de recherche donnée. Voir doveadm-search-query(7) pour les détails.

user source_user


suivi d'un nom d'utilisateur valide. Lorsque cet argument est présent, doveadm(1) appliquera le

Limitation : Actuellement, les utilisateurs spécifiés par -u utilisateur et user source_user doivent partager le même UID et GID système.

EXEMPLE

Déplacer les messages de jane - reçus en septembre 2011 - de sa boîte INBOX vers son archive :

doveadm move -u jane Archive/2011/09 mailbox INBOX BEFORE \
  2011-10-01 SINCE 01-Sep-2011

SIGNÀLER LES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur la façon de signaler les bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
