NOM

podman-machine - Gérer la machine virtuelle de Podman

SYNTAXE

podman machine sous-commande

DESCRIPTION

podman machine est un ensemble de sous-commandes qui gèrent la machine virtuelle de Podman.

Podman sur MacOS et Windows nécessite une machine virtuelle. Ceci est dû au fait que les conteneurs sont basés sur Linux - les conteneurs ne fonctionnent pas sur d'autres systèmes d'exploitation car les fonctionnalités de base des conteneurs sont liées au noyau Linux. podman machine doit être utilisé pour gérer les machines MacOS et Windows, mais peut être utilisé facultativement sous Linux.

Toutes les commandes podman machine sont réservées à un usage sans privilèges (rootless).

NOTE : Le fichier de configuration de podman-machine est géré dans le répertoire $XDG_CONFIG_HOME/containers/podman/machine/. La modification de la variable d'environnement $XDG_CONFIG_HOME pendant que les machines sont en cours d'exécution peut entraîner un comportement inattendu.

Le comportement de podman machine peut être modifié via la section [machine] du fichier containers.conf(5).

ssh podman-machine-ssh(1) Se connecte en SSH à une machine virtuelle
start podman-machine-start(1) Démarre une machine virtuelle
stop podman-machine-stop(1) Arrête une machine virtuelle
