NOM

docker-network-connect - Connecter un conteneur à un réseau

SYNTAXE

docker network connect [OPTIONS] NETWORK CONTENEUR

DESCRIPTION

Connecte un conteneur à un réseau. Vous pouvez connecter un conteneur par son nom ou son ID. Une fois connecté, le conteneur peut communiquer avec d'autres conteneurs du même réseau.

$ docker network connect multi-host-network container1

Vous pouvez également utiliser l'option docker run --network=<nom-du-réseau> pour démarrer un conteneur et le connecter immédiatement à un réseau.

$ docker run -itd --network=multi-host-network --ip 172.20.88.22 --ip6 2001:db8::8822 busybox

Vous pouvez mettre en pause, redémarrer et arrêter les conteneurs connectés à un réseau. Un conteneur se connecte à ses réseaux configurés lorsqu'il démarre.

Si spécifié, l'adresse IP du conteneur est réappliquée lorsqu'un conteneur arrêté est redémarré. Si l'adresse IP n'est plus disponible, le conteneur ne démarre pas. Une façon de garantir que l'adresse IP est disponible est de spécifier une plage --ip-range lors de la création du réseau, et de choisir les adresses IP statiques en dehors de cette plage. Cela garantit que l'adresse IP n'est pas attribuée à un autre conteneur tant que ce conteneur n'est pas sur le réseau.

$ docker network create --subnet 172.20.0.0/16 --ip-range 172.20.240.0/20 multi-host-network
$ docker network connect --ip 172.20.128.2 multi-host-network container2

Pour vérifier que le conteneur est connecté, utilisez la commande docker network inspect. Utilisez docker network disconnect pour supprimer un conteneur du réseau.

Une fois connectés dans un réseau, les conteneurs peuvent communiquer en utilisant uniquement l'adresse IP ou le nom d'un autre conteneur. Pour les réseaux overlay ou les plugins personnalisés prenant en charge la connectivité multi-hôtes, les conteneurs connectés au même réseau multi-hôtes mais lancés depuis différents moteurs peuvent également communiquer de cette manière.

Vous pouvez connecter un conteneur à un ou plusieurs réseaux. Les réseaux n'ont pas besoin d'être du même type. Par exemple, vous pouvez connecter un seul conteneur à des réseaux bridge et overlay.

OPTIONS

--alias=[] Ajouter un alias dans le périmètre du réseau pour le conteneur

--driver-opt=[] Options du pilote pour le réseau

--gw-priority=0 La plus haute valeur de gw-priority fournit la passerelle par défaut. Accepte les valeurs positives et négatives.

--ip= Adresse IPv4 (par ex. "172.30.100.104")

--ip6= Adresse IPv6 (par ex. "2001:db8::33")

--link= Ajouter un lien vers un autre conteneur

--link-local-ip=[] Ajouter une adresse link-local pour le conteneur
