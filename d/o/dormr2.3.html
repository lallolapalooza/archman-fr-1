Documentation de la fonction/sous-routine

sous-routine dormr2 (caractère side, caractère trans, entier m, entier n, entier k, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( * ) tau, double précision, dimension( ldc, * ) c, entier ldc, double précision, dimension( * ) work, entier info)

DORMR2 multiplie une matrice générale par la matrice orthogonale issue d'une factorisation RQ déterminée par sgerqf (algorithme non bloqué).

Objectif :

!>
!> DORMR2 écrase la matrice réelle générale m par n C avec
!>
!>       Q * C  si SIDE = 'L' et TRANS = 'N', ou
!>
!>       Q**T* C  si SIDE = 'L' et TRANS = 'T', ou
!>
!>       C * Q  si SIDE = 'R' et TRANS = 'N', ou
!>
!>       C * Q**T si SIDE = 'R' et TRANS = 'T',
!>
!> où Q est une matrice orthogonale réelle définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> comme retourné par DGERQF. Q est d'ordre m si SIDE = 'L' et d'ordre n
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**T par la gauche
!>          = 'R': appliquer Q ou Q**T par la droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': appliquer Q  (Pas de transposée)
!>          = 'T': appliquer Q' (Transposée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau de DOUBLE PRECISION, de dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, comme retourné par
!>          DGERQF dans les k dernières lignes de son argument de tableau A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

TAU

!>          TAU est un tableau de DOUBLE PRECISION, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), comme retourné par DGERQF.
!>

C

!>          C est un tableau de DOUBLE PRECISION, de dimension (LDC,N)
!>          À l'entrée, la matrice m par n C.
!>          À la sortie, C est écrasé par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, de dimension
!>                                   (N) si SIDE = 'L',
!!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
