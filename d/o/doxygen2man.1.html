NOM

doxygen2man - Un outil pour générer des pages de manuel à partir de fichiers XML Doxygen

SYNTAXE

doxygen2man [OPTIONS] <fichier XML>

DESCRIPTION

C'est un outil pour générer des pages API de manuel à partir d'un fichier d'en-tête annoté par Doxygen. Exécutez d'abord doxygen sur le fichier, puis exécutez ce programme sur le fichier XML principal qu'il a créé et sur le répertoire contenant les fichiers auxiliaires. Il générera ensuite de nombreux fichiers de manuel *.3 que vous pourrez ensuite distribuer avec votre bibliothèque.

Vous devrez invoquer ce programme une fois pour chaque fichier .h de votre bibliothèque, en utilisant le nom du fichier .xml généré. Ce fichier sera généralement appelé quelque chose comme <fichier-en-tête>_8h.xml, par exemple qbipcs_8h.xml

Si vous souhaitez une sortie HTML, utilisez simplement nroff sur les fichiers générés comme vous le feriez avec n'importe quelle autre page de manuel.

OPTIONS

-a
Imprimer un dump ASCII des pages de manuel sur stdout
-m
Écrire les fichiers de manuel dans <répertoire de sortie>
-P
Imprimer la section PARAMS
-s <n>
Écrire les pages de manuel dans la section <n> (par défaut 3)
-p <paquet>
Utiliser le nom <paquet>. Par défaut <Package>
-H <en-tête>
Définir l'en-tête (par défaut
-I <inclusion>
Définir le nom du fichier d'en-tête (par défaut celui dans le fichier XML ou unknown.h)
-i <préfixe>
Définir le préfixe pour les fichiers d'en-tête (par exemple, qb/) s'ils sont installés dans un sous-répertoire de /usr/include
-C <entreprise>
Définir le nom de l'entreprise dans le copyright (par défaut Red Hat)
-D <date>
Date à imprimer en haut des pages de manuel (format non vérifié, par défaut : aujourd'hui)
-Y <année>
Année à imprimer à la fin de la ligne de copyright (par défaut : l'année en cours)
-S <année>
Année à imprimer au début de la ligne de copyright (par défaut : 2010)
-o <répertoire>
Écrire toutes les pages de manuel dans <répertoire> (par défaut .)
-d <répertoire>
Répertoire pour les fichiers XML (./xml/)
-c
Utiliser la ligne de Copyright du fichier d'en-tête comme ligne de copyright dans la page de manuel. Cela nécessite que doxygen2man ait accès au fichier .h d'origine (voir l'option -O ci-dessous) et que la ligne Copyright ait un format défini. Elle doit se trouver dans les 10 premières lignes du fichier et commencer par le texte « * Copyright ». Si cette ligne n'est pas trouvée, l'année en cours ou celle donnée par l'option -Y sera utilisée.
-O
Spécifie le répertoire contenant les fichiers d'en-tête d'origine. Ceci est (actuellement) uniquement utilisé par l'option -c ci-dessus.
-h
Afficher le texte d'utilisation
