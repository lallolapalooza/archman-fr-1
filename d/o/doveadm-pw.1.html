NOM

doveadm-pw - Générateur et validateur de hachage de mot de passe Dovecot

SYNTAXE

doveadm [OPTIONS GLOBALES] pw -l

doveadm [OPTIONS GLOBALES] pw [-p mot de passe] [-r tours] [-s schéma] [-u utilisateur] [-V]

doveadm [OPTIONS GLOBALES] pw -t hachage [-p mot de passe] [-u utilisateur]

DESCRIPTION

doveadm pw est utilisé pour générer des hachages de mot de passe pour différents schémas de mot de passe et éventuellement vérifier le hachage généré.

Tous les hachages de mot de passe générés ont un préfixe {schéma}, par exemple {SHA512-CRYPT.HEX}. Toutes les passdb ont un schéma par défaut pour les mots de passe stockés sans le préfixe {schéma}. Le schéma par défaut peut être remplacé en stockant le mot de passe avec le préfixe du schéma.

Si vous souhaitez utiliser cette fonctionnalité pour vérifier ou générer des mots de passe sans configurer Dovecot au préalable, vous pouvez utiliser doveadm -O pw pour ce faire.

OPTIONS GLOBALES

doveadm(1) global

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise simplement les valeurs par défaut. Le paramètre dovecot_storage_version est par défaut la dernière version, mais peut être remplacé par

-k

Préserve l'environnement entier pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom-instance

Si plusieurs instances Dovecot sont utilisées, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier-config

Lit la configuration à partir du fichier-config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer ceci vers le socket de configuration d'une instance en cours d'exécution compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Afin de remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

OPTIONS

-l

Liste tous les schémas de mot de passe pris en charge et quitte avec succès.

Il existe jusqu'à trois schémas de mot de passe optionnels : BLF-CRYPT (Blowfish crypt), SHA256-CRYPT et SHA512-CRYPT. Leur disponibilité dépend de la libc actuellement utilisée par le système.

-p mot de passe


a été donné, doveadm(1) demandera interactivement un mot de passe. (Attention, l'utilisation de cette option signifie que le mot de passe en texte clair sera dans l'historique de votre shell !)

-r tours

Les schémas de mot de passe BLF-CRYPT, SHA256-CRYPT et SHA512-CRYPT supportent un nombre variable de tours de chiffrement. Le tableau suivant montre le nombre minimum/maximum de tours de chiffrement par schéma. Lorsque l'option -r a été omise, le nombre par défaut de tours de chiffrement sera appliqué.

| Schéma | Minimum | Maximum | Défaut | | ------ | ------- | ------- | ------- | | BLF-CRYPT | 4 | 31 | 5 | | SHA256-CRYPT | 1000 | 999999999 | 5000 | | SHA512-CRYPT | 1000 | 999999999 | 5000 |

-s schéma

Le schéma de mot de passe qui doit être utilisé pour générer le mot de passe haché. Par défaut, le schéma CRYPT sera utilisé (avec le format bcrypt $2y$). Il est également possible d'ajouter un suffixe d'encodage au schéma. Les suffixes d'encodage pris en charge sont : .b64, .base64 et .hex.

Voir également password_schemes pour plus de détails sur les schémas de mots de passe.

-t hachage


option. Lorsqu'aucun mot de passe n'a été spécifié, doveadm(1) demandera interactivement un mot de passe.

-u utilisateur


nom doit également être donné, car le nom d'utilisateur fait partie du hachage généré. Pour plus d'informations sur Digest-MD5, lisez également auth_digest_md5. Pour les autres schémas, ce n'est pas nécessaire.

-V

Lorsque cette option est donnée, le mot de passe haché sera vérifié en interne. Le résultat de la vérification sera affiché après le mot de passe haché, entre parenthèses.

EXEMPLE

Un hachage ARGON2ID (la meilleure sécurité à l'heure actuelle, bien qu'il puisse être lourd sur un serveur occupé) :

doveadm pw -s ARGON2ID
``ldas;l;als;las;lkas

SIGNALEMENT DE BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Des informations sur le signalement des bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
