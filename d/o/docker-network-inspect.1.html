SYNOPSI

S

DESCRIPTIO

N

Retourne des informations sur un ou plusieurs réseaux. Par défaut, cette commande affiche tous les résultats dans un objet JSON. Par exemple, si vous connectez deux conteneurs au réseau par défaut bridg

e : 
$ sudo docker run -itd --name=container1 busybox
f2870c98fd504370fb86e59f32cd0753b1ac9b69b7d80566ffc7192a82b3ed27
$ sudo docker run -itd --name=container2 busybox
bda12f8922785d1f160be70736f26c1e331ab8aaf8ed8d56728508f2e2fd472
7

La commande network inspect affiche les conteneurs, par identifiant, dans ses résultats. Vous pouvez spécifier un format alternatif pour exécuter un modèle donné pour chaque résultat. Le paquet Go text/template ⟨https://pkg.go.dev/text/template⟩ décrit tous les détails du

format.

docker network inspect --verbose pour les réseaux overlay en mode swarm affiche des détails spécifiques au service tels que le VIP du service et les correspondances de ports. Il affiche également les adresses IP des tâches du service, ainsi que les adresses IP des nœuds où les tâches

s'exécutent.
