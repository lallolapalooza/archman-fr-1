DOSBOX(1) Manuel des commandes générales DOSBOX(1)

NOM

dosbox - un émulateur x86/DOS avec son/graphiques

SYNOPSIS

dosbox [-fullscreen] [-startmapper] [-noautoexec] [-securemode] [-userconf] [-scaler scaler] [-forcescaler scaler] [-conf configfile] [-lang langfile] [file] [-c command] [-exit] [-machine machinetype]

dosbox -version

dosbox -editconf program

dosbox -opencaptures program

dosbox -printconf

dosbox -eraseconf

dosbox -resetconf

dosbox -erasemapper

dosbox -resetmapper

DESCRIPTION

Cette page de manuel documente brièvement dosbox, un émulateur x86/DOS.

L'argument facultatif file doit être un exécutable DOS ou un répertoire. S'il s'agit d'un exécutable DOS (.com .exe .bat), le programme s'exécutera automatiquement. S'il s'agit d'un répertoire, une session DOS sera lancée avec le répertoire monté comme C:\.

Pour une introduction, tapez INTRO dans dosbox.

OPTIONS

Un résumé des options est inclus ci-dessous.

-fullscreen
Lance dosbox en mode plein écran.
-startmapper
Lance le mappage de touches interne au démarrage de dosbox. Vous pouvez l'utiliser pour modifier les touches dosbox utilise.
-noautoexec
Ignore la section [autoexec] du fichier de configuration chargé.
-securemode
Identique à -noautoexec, mais ajoute config.com -securemode à la fin de AUTOEXEC.BAT (ce qui à son tour désactive tout changement de la façon dont les lecteurs sont montés dans dosbox)
-userconf
Charge le fichier de configuration situé dans ~/.dosbox. Peut être combiné avec l'option -conf .
-scaler scaler
Utilise le mise à l'échelle graphique spécifié par scaler. Consultez le fichier de configuration pour les mises à l'échelle disponibles
-forcescaler scaler
Similaire au paramètre -scaler , mais tente de forcer l'utilisation de la mise à l'échelle spécifiée même si elle ne correspond pas.
-c command
Exécute la command spécifiée avant d'exécuter file. Plusieurs commandes peuvent être spécifiées. Chaque command doit commencer par -c cependant. Une commande peut être : un programme interne, une commande DOS ou un exécutable sur un lecteur monté.
-conf configfile
Lance dosbox avec les options spécifiées dans configfile. Ce fichier a une section dans laquelle vous pouvez placer des commandes que vous souhaitez exécuter au démarrage. Plusieurs configfiles peuvent être présents sur la ligne de commande.
-lang langfile
Lance dosbox avec la langue spécifiée dans langfile.
-exit
dosbox se fermera lorsque le programme DOS spécifié par file se termine.
-machine machinetype
Configure dosbox pour émuler un type de machine spécifique. Les choix valides sont : hercules, cga, tandy, pcjr, ega, vgaonly, svga_s3(défaut), svga_et3000, svga_et4000, svga_paradise, vesa_nolfb, vesa_oldvbe. Le machinetype influence à la fois la carte vidéo et les cartes son disponibles.
-version
Affiche les informations de version et quitte. Utile pour les interfaces.
-editconf program
appelle program avec comme premier paramètre le fichier de configuration. Vous pouvez spécifier cette commande plus d'une fois. Dans ce cas, il passera au program suivant si le premier échoue à démarrer.
-opencaptures program
appelle program avec comme premier paramètre l'emplacement du dossier des captures.
-printconf
affiche l'emplacement du fichier de configuration par défaut.
-eraseconf, -resetconf
supprime le fichier de configuration par défaut.
-erasemapper, -resetmapper
supprime le fichier de mappage configuré dans le fichier de configuration par défaut propre.

COMMANDES INTERNES

dosbox prend en charge la plupart des commandes DOS trouvées dans command.com. De plus, les commandes supplémentaires suivantes sont disponibles :

MOUNT [-t type] [-size size] driveletter sourcedirectory [-ioctl] [-usecd number] [-label drivelabel] [-freesize freesize]

MOUNT -cd

MOUNT -u driveletter

Programme pour monter des répertoires locaux comme lecteurs dans dosbox.

driveletter
La lettre de lecteur dans dosbox (ex. C).
sourcedirectory
Le répertoire local que vous voulez avoir dans dosbox.
-t type
Type du répertoire monté. Pris en charge : dir (standard), floppy, cdrom.
-size drivesize
Définit la taille du lecteur. Consultez les exemples dans le README pour plus de détails.
-freesize size_in_mb
Définit la quantité d'espace libre disponible sur un lecteur en Mo. C'est une version plus simple de -size.
-label drivelabel
Définit le nom du lecteur à drivelabel. Nécessaire sur certains systèmes si l'étiquette du cd n'est pas lue correctement. Utile quand un programme ne trouve pas son cdrom. Si vous ne spécifiez pas d'étiquette et qu'aucun support de bas niveau n'est sélectionné (-usecd # et/ou -ioctl/aspi) :

Pour win32 : l'étiquette est extraite de "Real Drive".

Pour Linux : l'étiquette est définie à NO_LABEL.
Si vous spécifiez une étiquette, cette étiquette sera conservée tant que le lecteur
est monté. Elle ne sera pas mise à jour !!
-ioctl
Force l'utilisation des commandes ioctl.
-usecd number
Force l'utilisation du support cdrom de SDL pour le numéro de lecteur. Le numéro peut être trouvé par -cd.
-cd
Affiche tous les lecteurs cdrom détectés et leurs numéros. À utiliser avec -usecd.
-u
Démonte un lecteur monté. Ne fonctionne pas sur les lecteurs virtuels (comme Z:\)

Exemple :

Pour monter votre répertoire /home/dos/dosgames comme lecteur C dans dosbox:
mount c /home/dos/dosgames
MEM

Affiche la quantité de mémoire libre

CONFIG [-writeconf] [-writelang] file

CONFIG -securemode

Écrit la configuration ou les paramètres de langue actuels dans file, qui se trouve sur le système de fichiers local. Pas un lecteur monté dans dosbox.
