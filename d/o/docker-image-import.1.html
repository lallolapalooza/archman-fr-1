NOM

docker-image-import - Importe le contenu d'une archive pour créer une image de système de fichiers

SYNTAXE

docker image import [OPTIONS] fichier|URL|- [RÉPERTOIRE[:TAG]]

DESCRIPTION

Crée une nouvelle image de système de fichiers à partir du contenu d'une archive (.tar, .tar.gz, .tgz, .bzip, .tar.xz, .txz), puis la taggue éventuellement.

EXEMPLES

Importer depuis un emplacement distant

# docker image import http://example.com/exampleimage.tgz example/imagerepo

Importer depuis un fichier local

Importation dans Docker via un pipe et stdin :

# cat exampleimage.tgz | docker image import - example/imagelocal

Importation avec un message de commit.

# cat exampleimage.tgz | docker image import --message "Nouvelle image importée depuis une archive" - exampleimagelocal:new

Importation dans une image Docker à partir d'un fichier local.

# docker image import /chemin/vers/exampleimage.tgz

Importer depuis un fichier local et taguer

Importation dans Docker via un pipe et stdin :

# cat exampleimageV2.tgz | docker image import - example/imagelocal:V-2.0

Importer depuis un répertoire local

# tar -c . | docker image import - exampleimagedir

Appliquer des instructions Dockerfile spécifiques lors de l'importation de l'image

Cet exemple définit la variable d'environnement Docker DEBUG sur true par défaut.

# tar -c . | docker image import -c="ENV DEBUG=true" - exampleimagedir

Lorsque le daemon supporte plusieurs systèmes d'exploitation

Si le daemon supporte plusieurs systèmes d'exploitation et que l'image importée ne correspond pas au système d'exploitation par défaut, il peut être nécessaire d'ajouter --platform. Ceci serait nécessaire lors de l'importation d'une image Linux dans un daemon Windows.

# docker image import --platform=linux .\linuximage.tar

Voir aussi

docker-export(1) pour exporter le contenu d'un système de fichiers sous forme d'archive tar vers STDOUT.

OPTIONS

-c, --change= Applique une instruction Dockerfile à l'image créée

-m, --message="" Définit le message de commit pour l'image importée

--platform="" Définit la plateforme si le serveur est capable de gérer plusieurs plateformes

VOIR AUSSI
