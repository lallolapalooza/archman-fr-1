NOM

doveadm-service-stop - Arrête les services Dovecot

SYNTAXE

doveadm [OPTIONS GLOBALES] service stop service [service [...]]

DESCRIPTION

doveadm service stop arrête les processus de service Dovecot listés.

OPTIONS GLOBALES

doveadm(1) global

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise juste les valeurs par défaut. Le réglage dovecot_storage_version utilise par défaut la dernière version, mais peut être remplacé par

-k

Préserve l'environnement complet pour doveadm, pas seulement le réglage import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom-instance

Si plusieurs instances Dovecot sont utilisées, choisit le fichier de configuration en fonction de ce nom d'instance.

Voir le réglage instance_name pour plus d'informations.

-c fichier-config

Lit la configuration depuis le fichier-config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer ceci vers le socket de configuration d'une instance exécutant une version compatible.

-o réglage=valeur

Remplace le réglage de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Pour remplacer plusieurs réglages, l'option -o peut être spécifiée plusieurs fois.

-f formateur

Spécifie le formateur pour formater la sortie. Les formateurs supportés sont :

flow

affiche chaque ligne avec des paires clé=valeur.

json

affiche un tableau JSON d'objets JSON.

pager

affiche chaque paire clé: valeur sur sa propre ligne et sépare les enregistrements par un caractère de saut de page (^L).

tab

affiche un en-tête de tableau suivi de lignes de valeurs séparées par des tabulations.

table

affiche un en-tête de tableau suivi de lignes de valeurs ajustées.

ARGUMENTS

service

La liste des services à arrêter.

EXEMPLES

$ doveadm service stop stats

SIGNALER LES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Des informations sur le signalement des bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
