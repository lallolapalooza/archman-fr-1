Le moteur interrompt une opération de téléchargement lorsque la connexion entre le démon du moteur Docker et le client Docker qui initie le téléchargement est perdue. Si la connexion avec le démon du moteur est perdue pour d'autres raisons qu'une interaction manuelle, le téléchargement est également annulé.
