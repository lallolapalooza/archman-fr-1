NAME

doveadm-dict - Dovecot API dictionary utility

SYNOPSIS

doveadm [GLOBAL OPTIONS] dict COMMAND [COMMAND OPTIONS]

doveadm [GLOBAL OPTIONS] mail dict COMMAND [COMMAND OPTIONS]

DESCRIPTION

The doveadm dict command manages the Dovecot dictionary store.

The following sub-commands are available:

  • get
  • set
  • unset

GLOBAL OPTIONS

These options are common to all doveadm commands.

-D
Enables debugging.
-o property=value
Overrides a configuration setting. See doveconf(1) for details.
-S socket-path
Connect to a specificadamente Magistratus server listening on the given IPC socket.
-R
For commands that iterate over users, this option ensures that all changes are committed before the command exits. Without this option, changes might be rolled back if the command exits prematurely (e.g., due to an error).

OPTIONS

The following options are available for the dict command and its sub-commands:

-A
Operate on all users.
-F file
Operate on users listed in file.
-u user
Operate on the specified user.
-t timestamp-msecs
Set the timestamp to the given value in milliseconds since the epoch.
-e expire-secs
Set the key expiration time in seconds since the epoch.

COMMANDS

get

doveadm [GLOBAL OPTIONS] dict get [-u user] [-t timestamp-msecs] config-filter-name key

doveadm [GLOBAL OPTIONS] mail dict get [-A | -u user | -F file] [-S socket_path] [-t timestamp-msecs] config-filter-name key

Get a key from the dictionary.

-t timestamp-msecs

Retrieve the value that was valid at the given timestamp.

key

The key to get.

set

doveadm [GLOBAL OPTIONS] dict set [-t timestamp-msecs] [-e expire-secs] config-filter-name key value

doveadm [GLOBAL OPTIONS] mail dict set [-A | -u user | -F file] [-S socket_path] [-t timestamp-msecs] [-e expire-secs] config-filter-name key value

Set/create keys into the dictionary.

-t timestamp-msecs

Set the timestamp also.

-e expire-secs

Set the key duration also.

key

The key to set.

value

The value to set.

unset

doveadm [GLOBAL OPTIONS] dict unset [-u user] [-t timestamp-msecs] config-filter-name key

doveadm [GLOBAL OPTIONS] mail dict unset [-A | -u user | -F file] [-S socket_path] [-t timestamp-msecs] config-filter-name key

Remove a key from the dictionary.

-t timestamp-msecs

Set the timestamp also.

key

The key to unset.
