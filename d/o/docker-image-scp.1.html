NOM

podman-image-scp - Copie sécurisée d'une image d'un hôte à un autre

SYNTAXE

podman image scp [options] nom[:tag]

DESCRIPTION

podman image scp copie les images de conteneurs entre des hôtes sur un réseau. Cette commande peut copier des images vers l'hôte distant ou depuis l'hôte distant, ainsi qu'entre deux hôtes distants. Remarque : :: est utilisé pour spécifier le nom de l'image selon que Podman sauvegarde ou charge. Les images peuvent également être transférées du stockage rootful vers le stockage rootless sur la même machine sans utiliser sshd. Cette fonctionnalité n'est pas prise en charge sur le client distant, y compris les machines Mac et Windows (à l'exception de WSL2).

podman image scp [OPTIONS GLOBALES]

podman image scp [OPTIONS] NOM[:TAG] [NOMHOTE::]

podman image scp [OPTIONS] [NOMHOTE::]NOMIMAGE

podman image scp [OPTIONS] [NOMHOTE::]NOMIMAGE [NOMHOTE::]

OPTIONS

--help, -h

Imprime le message d'utilisation

--quiet, -q

Supprime la sortie

EXEMPLES

Copie l'image spécifiée vers le stockage local :

$ podman image scp alpine
Loaded image: docker.io/library/alpine:latest

Copie l'image spécifiée depuis le stockage local vers la connexion distante :

$ podman image scp alpine Fedora::/home/charliedoern/Documents/alpine
Getting image source signatures
Copying blob 72e830a4dff5 done
Copying config 85f9dc67c7 done
Writing manifest to image destination
Storing signatures
Loaded image: docker.io/library/alpine:latest

Copie l'image spécifiée d'une connexion distante à une connexion distante :

$ podman image scp Fedora::alpine RHEL::
Loaded image: docker.io/library/alpine:latest

Copie l'image spécifiée via ssh vers le stockage local :

$ podman image scp charliedoern@192.168.68.126:22/run/user/1000/podman/podman.sock::alpine
WARN[0000] Unknown connection name given. Please use system connection add to specify the default remote socket location

Copying config 1f97f0559c done
Writing manifest to image destination
Storing signatures
Loaded image: docker.io/library/alpine:latest

Copie l'image spécifiée du compte root vers le stockage local des comptes utilisateur :

$ sudo podman image scp root@localhost::alpine username@localhost::
