NOM

docker-login - Authentification auprès d'un registre

SYNOPSIS

docker login [OPTIONS] [SERVER]

DESCRIPTION

Se connecte à un Registre Docker situé sur le SERVER spécifié. Vous pouvez spécifier une URL ou un nom d'hôte pour la valeur SERVER. Si vous ne spécifiez pas de SERVER, la commande utilise le registre public de Docker situé à https://registry-1.docker.io/ par défaut. Pour obtenir un nom d'utilisateur/mot de passe pour le registre public de Docker, créez un compte sur Docker Hub.

docker login nécessite que l'utilisateur utilise sudo ou soit root, sauf dans les cas suivants :

1.
connexion à un démon distant, tel qu'un docker engine provisionné par docker-machine.
2.
l'utilisateur est ajouté au groupe docker. Cela aura un impact sur la sécurité de votre système ; le groupe docker est équivalent à root. Voir la surface d'attaque du démon Docker ⟨https://docs.docker.com/engine/security/#docker-daemon-attack-surface⟩ pour plus de détails.

Vous pouvez vous connecter à n'importe quel dépôt public ou privé pour lequel vous avez des identifiants. Lorsque vous vous connectez, la commande stocke les identifiants encodés dans $HOME/.docker/config.json sous Linux ou %USERPROFILE%/.docker/config.json sous Windows.

EXEMPLES

Se connecter à un registre sur votre localhost

# docker login localhost:8080

Voir aussi

docker-logout(1) pour se déconnecter d'un registre.

OPTIONS

-p, --password="" Mot de passe ou jeton d'accès personnel (PAT)

--password-stdin[=false] Récupère le mot de passe ou le jeton d'accès personnel (PAT) depuis stdin

-u, --username="" Nom d'utilisateur
