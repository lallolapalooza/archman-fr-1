subroutine dorgbr (vect, m, n, k, a, lda, tau, work, lwork, info)
DORGBR

Documentation de la fonction/sous-routine

sous-routine dorgbr (character vect, integer m, integer n, integer k, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) tau, double precision, dimension( * ) work, integer lwork, integer info)

DORGBR

But :

!>
!> DORGBR génère l'une des matrices orthogonales réelles Q ou P**T
!> déterminées par DGEBRD lors de la réduction d'une matrice réelle A
!> à sa forme bidiagonale : A = Q * B * P**T. Q et P**T sont définies
!> comme des produits de réflexions élémentaires H(i) ou G(i)
!> respectivement.
!>
!> Si VECT = 'Q', on suppose que A était une matrice M-par-K, et Q est
!> d'ordre M :
!> si m >= k, Q = H(1) H(2) . . . H(k) et DORGBR retourne les n premières
!> colonnes de Q, où m >= n >= k ;
!> si m < k, Q = H(1) H(2) . . . H(m-1) et DORGBR retourne Q comme une
!> matrice M-par-M.
!>
!> Si VECT = 'P', on suppose que A était une matrice K-par-N, et P**T est
!> d'ordre N :
!> si k < n, P**T = G(k) . . . G(2) G(1) et DORGBR retourne les m premières
!> lignes de P**T, où n >= m >= k ;
!> si k >= n, P**T = G(n-1) . . . G(2) G(1) et DORGBR retourne P**T comme
!> une matrice N-par-N.
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          Spécifie si la matrice Q ou la matrice P**T est requise,
!>          telle que définie dans la transformation appliquée par DGEBRD :
!>          = 'Q' : générer Q ;
!>          = 'P' : générer P**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice Q ou P**T à retourner.
!>          M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice Q ou P**T à retourner.
!>          N >= 0.
!>          Si VECT = 'Q', M >= N >= min(M,K) ;
!>          si VECT = 'P', N >= M >= min(N,K).
!>

K

!>          K est INTEGER
!>          Si VECT = 'Q', le nombre de colonnes de la matrice originale
!>          M-par-K réduite par DGEBRD.
!>          Si VECT = 'P', le nombre de lignes de la matrice originale
!>          K-par-N réduite par DGEBRD.
!>          K >= 0.
!>

A

!>          A est tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, les vecteurs qui définissent les réflexions
!>          élémentaires, tels que retournés par DGEBRD.
!>          À la sortie, la matrice M-par-N Q ou P**T.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est tableau DOUBLE PRECISION, dimension
!>                                (min(M,K)) si VECT = 'Q'
!>                                (min(N,K)) si VECT = 'P'
!>          TAU(i) doit contenir le facteur scalaire de la réflexion
!>          élémentaire H(i) ou G(i), qui détermine Q ou P**T, tel que
!>          retourné par DGEBRD dans son argument de tableau TAUQ ou TAUP.
!>

WORK

!>          WORK est tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,min(M,N)).
!>          Pour une performance optimale, LWORK >= min(M,N)*NB, où NB
!>          est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et
!>          aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
