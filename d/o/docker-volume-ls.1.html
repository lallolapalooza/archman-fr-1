NOM

docker-volume-ls - Lister les volumes

SYNTAXE

docker volume ls [OPTIONS]

DESCRIPTION

Liste tous les volumes gérés par Docker. Vous pouvez filtrer en utilisant l'option -f ou --filter. Le format de filtrage est une paire clé=valeur. Pour spécifier plusieurs filtres, passez plusieurs options (par exemple, --filter "foo=bar" --filter "bif=baz")

Les filtres actuellement pris en charge sont :

  • dangling (booléen - true ou false, 1 ou 0)
  • driver (nom d'un pilote de volume)
  • label (label=<clé> ou label=<clé>=<valeur>)
  • name (nom d'un volume)

OPTIONS

--cluster[=false] Afficher uniquement les volumes du cluster et utiliser le formatage de la liste des volumes du cluster

-f, --filter= Fournir des valeurs de filtre (par exemple "dangling=true")

--format="" Formater la sortie à l'aide d'un modèle personnalisé : 'table' : Afficher la sortie au format tableau avec les en-têtes de colonne (par défaut) 'table MODÈLE' : Afficher la sortie au format tableau en utilisant le modèle Go donné 'json' : Afficher au format JSON 'MODÈLE' : Afficher la sortie en utilisant le modèle Go donné. Référez-vous à https://docs.docker.com/go/formatting/ pour plus d'informations sur le formatage de la sortie avec des modèles

-q, --quiet[=false] Afficher uniquement les noms des volumes
