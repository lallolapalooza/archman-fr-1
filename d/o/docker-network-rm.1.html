NOM

docker-network-rm - Supprime un ou plusieurs réseaux

SYNTAXE

docker network rm RESEAU [RESEAU...]

DESCRIPTION

Supprime un ou plusieurs réseaux par leur nom ou identifiant. Pour supprimer un réseau, vous devez d'abord déconnecter tous les conteneurs qui y sont connectés. Pour supprimer le réseau nommé « my-network » :

$ docker network rm my-network

Pour supprimer plusieurs réseaux en une seule commande docker network rm, fournissez plusieurs noms ou identifiants de réseau. L'exemple suivant supprime un réseau avec l'identifiant 3695c422697f et un réseau nommé my-network :

$ docker network rm 3695c422697f my-network

Lorsque vous spécifiez plusieurs réseaux, la commande tente de les supprimer un par un. Si la suppression d'un réseau échoue, la commande continue avec le suivant sur la liste et tente de le supprimer. La commande signale le succès ou l'échec pour chaque suppression.

OPTIONS

-f, --force[=false] Ne pas générer d'erreur si le réseau n'existe pas
