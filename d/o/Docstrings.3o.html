Fonctions set

Ces fonctions sont utilisées par l'analyseur lexical pour associer les docstrings aux positions des jetons.

val set_pre_docstrings : Lexing.position -> docstring list -> unit

Docstrings immédiatement précédant un jeton

val set_post_docstrings : Lexing.position -> docstring list -> unit

Docstrings immédiatement suivant un jeton

val set_floating_docstrings : Lexing.position -> docstring list -> unit

Docstrings non immédiatement adjacentes à un jeton

val set_pre_extra_docstrings : Lexing.position -> docstring list -> unit

Docstrings immédiatement suivant le jeton qui précède celui-ci

val set_post_extra_docstrings : Lexing.position -> docstring list -> unit

Docstrings immédiatement précédant le jeton qui suit celui-ci

Éléments

Le type Docstrings.docs représente la documentation attachée à un élément.

type docs = {
docs_pre : docstring option ;
docs_post : docstring option ;
}

val empty_docs : docs

val docs_attr : docstring -> Parsetree.attribute

val add_docs_attrs : docs -> Parsetree.attributes -> Parsetree.attributes

Convertit la documentation d'un élément en attributs et les ajoute à une liste d'attributs

val symbol_docs : unit -> docs

Récupère la documentation de l'élément pour le symbole courant. Marque également cette documentation (pour les avertissements d'ambiguïté).

val symbol_docs_lazy : unit -> docs Lazy.t

val rhs_docs : int -> int -> docs

Récupère la documentation de l'élément pour les symboles entre deux positions. Marque également cette documentation (pour les avertissements d'ambiguïté).

val rhs_docs_lazy : int -> int -> docs Lazy.t

val mark_symbol_docs : unit -> unit

Marque la documentation de l'élément pour le symbole courant (pour les avertissements d'ambiguïté).

val mark_rhs_docs : int -> int -> unit

Marque comme associée la documentation de l'élément pour les symboles entre deux positions (pour les avertissements d'ambiguïté)

Champs et constructeurs

Le type Docstrings.info représente la documentation attachée à un champ ou un constructeur.

type info = docstring option

val empty_info : info

val info_attr : docstring -> Parsetree.attribute

val add_info_attrs : info -> Parsetree.attributes -> Parsetree.attributes

Convertit les informations de champ en attributs et les ajoute à une liste d'attributs

val symbol_info : unit -> info

Récupère les informations du champ pour le symbole courant.

val rhs_info : int -> info

Récupère les informations du champ suivant le symbole à une position donnée.

Commentaires non attachés

Le type Docstrings.text représente la documentation qui n'est attachée à rien.

type text = docstring list

val empty_text : text

val empty_text_lazy : text Lazy.t

val text_attr : docstring -> Parsetree.attribute

val add_text_attrs : text -> Parsetree.attributes -> Parsetree.attributes

Convertit le texte en attributs et les ajoute à une liste d'attributs

val symbol_text : unit -> text

Récupère le texte précédant le symbole courant.

val symbol_text_lazy : unit -> text Lazy.t

val rhs_text : int -> text

Récupère le texte précédant le symbole à la position donnée.

val rhs_text_lazy : int -> text Lazy.t

Texte supplémentaire

Il peut y avoir du texte supplémentaire attaché aux délimiteurs d'un bloc (par exemple struct et end ). Ce texte est récupéré par les fonctions suivantes, qui sont appliquées au contenu du bloc plutôt qu'aux délimiteurs.

val symbol_pre_extra_text : unit -> text

Récupère le texte supplémentaire précédant le symbole courant

val symbol_post_extra_text : unit -> text

Récupère le texte supplémentaire suivant le symbole courant

val rhs_pre_extra_text : int -> text

Récupère le texte supplémentaire précédant le symbole à la position donnée

val rhs_post_extra_text : int -> text

Récupère le texte supplémentaire suivant le symbole à la position donnée

val rhs_post_text : int -> text

Récupère le texte suivant le symbole à la position donnée
