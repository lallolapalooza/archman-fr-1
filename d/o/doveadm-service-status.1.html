NOM

doveadm-service-status - Afficher des informations sur les services dovecot

SYNOPSIS

doveadm [OPTIONS GLOBALES] service status [service [...]]

DESCRIPTION

doveadm service status produit un tableau avec une ligne pour chaque service, contenant les détails suivants :

name

le nom du service

process_count

le nombre de processus réellement en cours d'exécution pour le service

process_avail

le nombre de processus supplémentaires qui peuvent être créés pour le service

process_limit

le nombre maximum de processus pouvant être actifs pour le service

client_limit

le nombre maximum de connexions que le service gérera simultanément

throttle_secs

le nombre de secondes d'attente avant de lancer un autre processus lorsque les processus meurent de manière inattendue et prématurée pour le service

exit_failure_last

l'horodatage du moment où le dernier processus a été terminé de manière anormale pour le service

exit_failures_in_sec

le nombre de processus terminés de manière anormale pour le service au cours de la dernière seconde

last_drop_warning

l'horodatage du moment où un avertissement "dropping client connections" a été consigné pour la dernière fois

listen_pending

si le processus maître met en file d'attente des connexions qui doivent être distribuées

listening

si le service est en écoute

doveadm_stop

si le service a été arrêté par doveadm(1)

process_total

le nombre total de processus créés pour le service depuis le démarrage du service.

OPTIONS GLOBALES

Options globales de doveadm(1)

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise simplement les valeurs par défaut. Le dovecot_storage_version paramètre a par défaut la dernière version, mais peut être remplacé avec

-k

Préserve l'environnement entier pour doveadm, pas seulement le import_environment paramètre.

-v

Active la verbosité, y compris le compteur de progression.

-i instance-name

Si vous utilisez plusieurs instances Dovecot, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c config-file

Lit la configuration à partir du config-filedonné. Par défaut, il lit d'abord la socket de configuration, puis utilise /etc/dovecot/dovecot.conf /etc/dovecot/dovecot.confVous pouvez également pointer vers la socket de configuration d'une instance exécutant une version compatible.

-o setting=value

Remplace le setting de configuration de /etc/dovecot/dovecot.conf et de la userdb avec la valuedonnée. Afin de remplacer plusieurs paramètres, l' -o option peut être spécifiée plusieurs fois.

-f formatter

Spécifie le formatter pour formater la sortie. Les formateurs pris en charge sont :

flow

affiche chaque ligne avec des paires key=value .

json

affiche un tableau JSON d'objets JSON.

pager

affiche chaque paire key: value sur sa propre ligne et sépare les enregistrements avec le caractère de saut de page (^L).

tab

affiche un en-tête de tableau suivi de lignes de valeurs séparées par des tabulations.

table

affiche un en-tête de tableau suivi de lignes de valeurs ajustées.

ARGUMENTS

service (optionnel)

Filtre la liste selon le ou les services spécifiés. Par défaut, tous les services dovecot sont listés.

EXEMPLES

doveadm service status
name: imap-login
process_count: 0
process_avail: 0
process_limit: 1
client_limit: 1000
throttle_secs: 0
exit_failure_last: 0
exit_failures_in_sec: 0
last_drop_warning: 0
listen_pending: n
listening: y
doveadm_stop: n
process_total: 0

SIGNALEMENT DE BOGUES

Signalez les bogues, y compris la sortie de doveconf -n , à la liste de diffusion de Dovecot Mailing List ⟨dovecot@dovecot.org⟩. Des informations sur la façon de signaler les bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
