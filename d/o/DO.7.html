NOM

DO - exécuter un bloc de code anonyme

SYNTAXE

DO [ LANGUAGE nom_langage ] code

DESCRIPTION

DO exécute un bloc de code anonyme, ou en d'autres termes une fonction anonyme transitoire dans un langage procédural.

Le bloc de code est traité comme s'il s'agissait du corps d'une fonction sans paramètres, retournant void. Il est analysé et exécuté une seule fois.

La clause LANGUAGE optionnelle peut être écrite avant ou après le bloc de code.

PARAMETRES

code

Le code du langage procédural à exécuter. Ceci doit être spécifié comme une chaîne de caractères littérale, tout comme dans CREATE FUNCTION. L'utilisation d'une chaîne délimitée par des dollars est recommandée.

nom_langage

Le nom du langage procédural dans lequel le code est écrit. Si omise, la valeur par défaut est plpgsql.

NOTES

Le langage procédural à utiliser doit déjà avoir été installé dans la base de données courante au moyen de CREATE EXTENSION. plpgsql est installé par défaut, mais d'autres langages ne le sont pas.

L'utilisateur doit avoir le privilège USAGE pour le langage procédural, ou doit être un superutilisateur si le langage n'est pas de confiance. Il s'agit des mêmes exigences de privilèges que pour la création d'une fonction dans ce langage.

Si DO est exécuté dans un bloc de transaction, alors le code de la procédure ne peut pas exécuter d'instructions de contrôle de transaction. Les instructions de contrôle de transaction ne sont autorisées que si DO est exécuté dans sa propre transaction.

EXEMPLES

Accorder tous les privilèges sur toutes les vues du schéma public au rôle webuser :

DO $$DECLARE r record;
BEGIN
    FOR r IN SELECT table_schema, table_name FROM information_schema.tables
             WHERE table_type = 'VIEW' AND table_schema = 'public'
    LOOP
        EXECUTE 'GRANT ALL ON ' || quote_ident(r.table_schema) || '.' || quote_ident(r.table_name) || ' TO webuser';
    END LOOP;
END$$;

COMPATIBILITE

Il n'y a pas d'instruction DO dans la norme SQL.
