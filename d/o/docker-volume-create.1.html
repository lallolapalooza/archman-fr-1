NOM

docker-volume-create - Crée un volume

SYNTAXE

docker volume create [OPTIONS] [VOLUME]

DESCRIPTION

Crée un nouveau volume que les conteneurs peuvent utiliser et dans lequel stocker des données. Si aucun nom n'est spécifié, Docker génère un nom aléatoire. Vous créez un volume puis configurez le conteneur pour l'utiliser, par exemple :

$ docker volume create hello
hello
$ docker run -d -v hello:/world busybox ls /world

Le montage est créé à l'intérieur du répertoire /src du conteneur. Docker ne prend pas en charge les chemins relatifs pour les points de montage à l'intérieur du conteneur.

Plusieurs conteneurs peuvent utiliser le même volume en même temps. Ceci est utile si deux conteneurs ont besoin d'accéder à des données partagées. Par exemple, si un conteneur écrit et l'autre lit les données.

Options spécifiques au pilote

Certains pilotes de volume peuvent accepter des options pour personnaliser la création du volume. Utilisez les drapeaux -o ou --opt pour passer les options du pilote :

$ docker volume create --driver fake --opt tardis=blue --opt timey=wimey

Ces options sont passées directement au pilote de volume. Les options pour différents pilotes de volume peuvent avoir des effets différents (ou aucun).

Le pilote local intégré sous Windows ne prend en charge aucune option.

Le pilote local intégré sous Linux accepte des options similaires à la commande mount de Linux :

$ docker volume create --driver local --opt type=tmpfs --opt device=tmpfs --opt o=size=100m,uid=1000

Un autre exemple :

$ docker volume create --driver local --opt type=btrfs --opt device=/dev/sda2

OPTIONS

--availability="active" Disponibilité du volume cluster ("active", "pause", "drain")

-d, --driver="local" Spécifie le nom du pilote de volume

--group="" Groupe de volumes cluster (volumes cluster)

--label= Définit les métadonnées d'un volume

--limit-bytes=0 Taille minimale du volume cluster en octets

-o, --opt=map[] Définit les options spécifiques au pilote

--required-bytes=0 Taille maximale du volume cluster en octets

--scope="single" Portée d'accès du volume cluster ("single", "multi")

--secret=map[] Secrets du volume cluster

--sharing="none" Partage d'accès du volume cluster ("none", "readonly", "onewriter", "all")

--topology-preferred= Une topologie dans laquelle le volume cluster serait préféré

--topology-required= Une topologie à partir de laquelle le volume cluster doit être accessible

--type="block" Type d'accès du volume cluster ("mount", "block")
