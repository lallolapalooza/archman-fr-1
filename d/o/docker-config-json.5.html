NOM

HOME/.docker/config.json - Fichier de configuration Docker par défaut

INTRODUCTION

Par défaut, la ligne de commande Docker stocke ses fichiers de configuration dans un répertoire nommé .docker dans votre répertoire $HOME. Docker gère la plupart des fichiers dans le répertoire de configuration et vous ne devriez pas les modifier. Cependant, vous pouvez modifier le fichier config.json pour contrôler certains aspects du comportement de la commande docker.

Actuellement, vous pouvez modifier le comportement de la commande docker en utilisant des variables d'environnement ou des options de ligne de commande. Vous pouvez également utiliser des options dans config.json pour modifier certains des mêmes comportements. Lorsque vous utilisez ces mécanismes, vous devez garder à l'esprit l'ordre de priorité entre eux. Les options de ligne de commande remplacent les variables d'environnement et les variables d'environnement remplacent les propriétés que vous spécifiez dans un fichier config.json.

Le fichier config.json stocke un encodage JSON de plusieurs propriétés :

  • La propriété HttpHeaders spécifie un ensemble d'en-têtes à inclure dans tous les messages envoyés du client Docker au démon. Docker n'essaie pas d'interpréter ou de comprendre ces en-têtes ; il les insère simplement dans les messages. Docker n'autorise pas ces en-têtes à modifier les en-têtes qu'il définit lui-même.
  • La propriété psFormat spécifie le format par défaut pour la sortie de docker ps. Lorsque le drapeau --format n'est pas fourni avec la commande docker ps, le client Docker utilise cette propriété. Si cette propriété n'est pas définie, le client se rabat sur le format de tableau par défaut. Pour une liste des directives de formatage prises en charge, voir docker-ps(1).
  • La propriété detachKeys spécifie la séquence de touches par défaut qui détache le conteneur. Lorsque le drapeau --detach-keys n'est pas fourni avec docker attach, docker exec, docker run ou docker start, le client Docker utilise cette propriété. Si cette propriété n'est pas définie, le client se rabat sur la séquence par défaut ctrl-p,ctrl-q.
  • La propriété imagesFormat spécifie le format par défaut pour la sortie de docker images. Lorsque le drapeau --format n'est pas fourni avec la commande docker images, le client Docker utilise cette propriété. Si cette propriété n'est pas définie, le client se rabat sur le format de tableau par défaut. Pour une liste des directives de formatage prises en charge, voir docker-images(1).

Vous pouvez spécifier un emplacement différent pour les fichiers de configuration via la variable d'environnement DOCKER_CONFIG ou l'option de ligne de commande --config. Si les deux sont spécifiés, alors l'option --config remplace la variable d'environnement DOCKER_CONFIG :

docker --config ~/testconfigs/ ps

Cette commande demande à Docker d'utiliser les fichiers de configuration dans le répertoire ~/testconfigs/ lors de l'exécution de la commande ps.

Exemples

Voici un exemple de fichier config.json :

{
  "HttpHeaders": {
    "MonEntete": "MaValeur"
  },
  "psFormat": "table {{.ID}}\\t{{.Image}}\\t{{.Command}}\\t{{.Labels}}",
  "imagesFormat": "table {{.ID}}\\t{{.Repository}}\\t{{.Tag}}\\t{{.CreatedAt}}",
  "detachKeys": "ctrl-e,e"
}
