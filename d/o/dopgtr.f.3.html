subroutine dopgtr (uplo, n, ap, tau, q, ldq, work, info)
DOPGTR

Documentation de la fonction/sous-programme

sous-programme dopgtr (caractère uplo, entier n, double précision, dimension( * ) ap, double précision, dimension( * ) tau, double précision, dimension( ldq, * ) q, entier ldq, double précision, dimension( * ) work, entier info)

DOPGTR

Objectif:

!>
!> DOPGTR génère une matrice orthogonale réelle Q qui est définie comme le
!> produit de n-1 réflecteurs élémentaires H(i) d'ordre n, tels que retournés par
!> DSPTRD en utilisant un stockage compact :
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': stockage compact triangulaire supérieur utilisé dans l'appel
!>                 précédent à DSPTRD ;
!>          = 'L': stockage compact triangulaire inférieur utilisé dans l'appel
!>                 précédent à DSPTRD.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice Q. N >= 0.
!>

AP

!>          AP est un tableau de DOUBLE PRECISION, dimension (N*(N+1)/2)
!>          Les vecteurs qui définissent les réflecteurs élémentaires, tels que
!>          retournés par DSPTRD.
!>

TAU

!>          TAU est un tableau de DOUBLE PRECISION, dimension (N-1)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par DSPTRD.
!>

Q

!>          Q est un tableau de DOUBLE PRECISION, dimension (LDQ,N)
!>          La matrice orthogonale Q de taille N x N.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= max(1,N).
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, dimension (N-1)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
