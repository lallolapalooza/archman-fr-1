NOM

docker-plugin-ls - Lister les plugins

SYNTAXE

docker plugin ls [OPTIONS]

DESCRIPTION

Liste tous les plugins actuellement installés. Vous pouvez installer des plugins en utilisant la commande docker plugin install. Vous pouvez également filtrer à l'aide de l'indicateur -f ou --filter.

Filtres

Filtrer la sortie en fonction de ces conditions :
- enabled=(true|false) - plugins activés ou non
- capability= - filtre les plugins en fonction des capacités (actuellement volumedriver, networkdriver, ipamdriver, ou authz)

Format

Formater la sortie en utilisant le modèle Go donné.
Marqueurs valides :
.ID - ID du plugin.
.Name - Nom du plugin.
.Description - Description du plugin.
.Enabled - Si le plugin est activé ou non.

EXEMPLES

Afficher tous les plugins

$ docker plugin ls
ID                  NAME                                    DESCRIPTION                         ENABLED
869080b57404        tiborvass/sample-volume-plugin:latest   A sample volume plugin for Docker   true
141bf6c02ddd        vieux/sshfs:latest                      sshFS plugin for Docker             false

Afficher les plugins avec leur ID et nom

$ docker plugin ls --format "{{.ID}}: {{.Name}}"
869080b57404: tiborvass/sample-volume-plugin:latest

Afficher les plugins au format JSON

$ docker plugin ls --format json
{"Description":"A sample volume plugin for Docker","Enabled":true,"ID":"2788a2da7e12","Name":"tiborvass/sample-volume-plugin:latest","PluginReference":"docker.io/tiborvass/sample-volume-plugin:latest"}

Afficher les plugins actifs

$ docker plugin ls --filter enabled=true
ID                  NAME                                    DESCRIPTION                         ENABLED
869080b57404        tiborvass/sample-volume-plugin:latest   A sample volume plugin for Docker   true

Afficher les plugins avec la capacité volumedriver

$ docker plugin ls --filter capability=volumedriver --format "table {{.ID}}\t{{.Name}}"
ID                  Name
869080b57404        tiborvass/sample-volume-plugin:latest

OPTIONS

-f, --filter= Fournir des valeurs de filtre (par exemple "enabled=true")

--format="" Formater la sortie en utilisant un modèle personnalisé : 'table' : Afficher la sortie au format tableau avec les en-têtes de colonne (par défaut) 'table TEMPLATE' : Afficher la sortie au format tableau en utilisant le modèle Go donné 'json' : Afficher au format JSON 'TEMPLATE' : Afficher la sortie en utilisant le modèle Go donné. Consulter https://docs.docker.com/go/formatting/ pour plus d'informations sur la mise en forme de la sortie avec des modèles.

--no-trunc[=false] Ne pas tronquer la sortie

-q, --quiet[=false] Afficher uniquement les ID des plugins
