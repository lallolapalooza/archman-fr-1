NOM

doveadm-process-status - Affiche des informations sur les processus dovecot

SYNTAXE

doveadm [OPTIONS GLOBALES] process status [service [...]]

DESCRIPTION

doveadm process status produit un tableau avec une ligne pour chaque processus, contenant les détails suivants :

name

le nom du processus

pid

le pid du processus

available_count

le nombre de clients supplémentaires pouvant se connecter au processus

total_count

le nombre de clients connectés

idle_start

l'horodatage lorsque le processus est passé en mode inactif, 0 s'il est actif

last_status_update

l'horodatage de la dernière mise à jour du processus

last_kill_sent

l'horodatage du dernier signal SIGINT envoyé au processus

OPTIONS GLOBALES

doveadm(1) global

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise uniquement les valeurs par défaut. Le réglage dovecot_storage_version est par défaut à la dernière version, mais peut être remplacé avec

-k

Préserve l'intégralité de l'environnement pour doveadm, pas seulement le réglage import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom-instance

Si plusieurs instances Dovecot sont utilisées, choisit le fichier de configuration basé sur ce nom d'instance.

Voir le réglage instance_name pour plus d'informations.

-c fichier-config

Lit la configuration à partir du fichier-config spécifié. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer ceci vers le socket de configuration d'une instance en cours d'exécution compatible.

-o réglage=valeur

Remplace le réglage de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Pour remplacer plusieurs réglages, l'option -o peut être spécifiée plusieurs fois.

-f formateur

Spécifie le formateur pour formater la sortie. Les formateurs supportés sont :

flow

imprime chaque ligne avec des paires clé=valeur.

json

imprime un tableau JSON d'objets JSON.

pager

imprime chaque paire clé: valeur sur sa propre ligne et sépare les enregistrements par un caractère de saut de page (^L).

tab

imprime un en-tête de tableau suivi de lignes de valeurs séparées par des tabulations.

table

imprime un en-tête de tableau suivi de lignes de valeurs ajustées.

ARGUMENTS

service (optionnel)

Filtre les processus selon le ou les services spécifiés. Par défaut, tous les processus dovecot sont listés.

EXEMPLES

doveadm process status
name   pid    available_count total_count idle_start last_status_update last_kill_sent
stats  132400 999             5           0          1685365436         0
log    132356 971             29          0          1685352909         0
config 132357 999             6           0          1685365436         0
anvil  132355 1000            0           1685352908 1685352908         0

SIGNALEMENT DE BOGUES

Signalez les bugs, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur le signalement de bugs sont disponibles sur : https://dovecot.org/bugreport.html
