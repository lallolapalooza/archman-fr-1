NOM

docker-container-exec - Exécute une commande dans un conteneur en cours d'exécution

SYNTAXE

docker container exec [OPTIONS] CONTENEUR COMMANDE [ARG...]

DESCRIPTION

Exécute un processus dans un conteneur en cours d'exécution.

La commande démarrée à l'aide de docker exec ne s'exécutera que tant que le processus principal du conteneur (PID 1) est en cours d'exécution, et ne sera pas redémarrée si le conteneur est redémarré.

Si le conteneur est suspendu, alors la commande docker exec attendra que le conteneur soit débloqué, puis s'exécutera.

CAPACITÉS

privileged donne au processus des capacités Linux étendues (voir https://man7.org/linux/man-pages/man7/capabilities.7.html).

Sans ce drapeau, le processus exécuté par docker exec dans un conteneur en cours d'exécution possède les mêmes capacités que le conteneur, qui peuvent être limitées. Définissez --privileged pour donner toutes les capacités au processus.

UTILISATEUR

user définit le nom d'utilisateur ou l'UID utilisé et facultativement le nom du groupe ou le GID pour la commande spécifiée.

Les exemples suivants sont tous valides :
--user [utilisateur | utilisateur:groupe | uid | uid:gid | utilisateur:gid | uid:groupe ]

Sans cet argument, la commande sera exécutée en tant que root dans le conteneur.

Statut de sortie

Le code de sortie de docker exec donne des informations sur la raison pour laquelle le conteneur n'a pas pu exécuter la commande ou pourquoi il s'est arrêté. Lorsque docker exec se termine avec un code non nul, les codes de sortie suivent la norme chroot, voir ci-dessous :

126 si la commande contenue ne peut pas être invoquée

$ docker exec busybox /etc; echo $?
# exec: "/etc": permission denied
  docker: Error response from daemon: Contained command could not be invoked
  126

127 si la commande contenue ne peut pas être trouvée

$ docker exec busybox foo; echo $?
# exec: "foo": executable file not found in $PATH
  docker: Error response from daemon: Contained command not found or does not exist
  127

Code de sortie de la commande contenue sinon

$ docker exec busybox /bin/sh -c 'exit 3' 
# 3

OPTIONS

-d, --detach[=false] Mode détaché : exécute la commande en arrière-plan

--detach-keys="" Surcharge la séquence de touches pour détacher un conteneur

-e, --env= Définit des variables d'environnement

--env-file= Lit un fichier de variables d'environnement

-i, --interactive[=false] Maintient STDIN ouvert même si non attaché

--privileged[=false] Donne des privilèges étendus à la commande

-t, --tty[=false] Alloue un pseudo-TTY

-u, --user="" Nom d'utilisateur ou UID (format : "[:]")

-w, --workdir="" Répertoire de travail à l'intérieur du conteneur
