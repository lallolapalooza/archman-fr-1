NOM

doveadm-deduplicate - Supprimer les messages dupliqués

SYNOPIS

doveadm [OPTIONS GLOBALES] deduplicate [-u utilisateur | -A | -F fichier | --no-userdb-lookup] [-S chemin_socket] [-m] requête_recherche

DESCRIPTION

La déduplication entre plusieurs boîtes aux lettres n'est pas prise en charge.

OPTIONS GLOBALES

Global doveadm(1)

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise simplement les valeurs par défaut. Le paramètre dovecot_storage_version est défini sur la dernière version, mais peut être remplacé par

-k

Préserve l'environnement entier pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom_instance

Si vous utilisez plusieurs instances Dovecot, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier_config

Lit la configuration depuis le fichier_config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de la base d'utilisateurs par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

OPTIONS

-A

Si l'option -A est présente, la commande sera exécutée pour tous les utilisateurs. L'utilisation de cette option en combinaison avec les utilisateurs système de userdb { driver = passwd } n'est pas recommandée, car elle inclut également les utilisateurs avec un UID inférieur à celui configuré avec le paramètre first_valid_uid.

Lorsque le module userdb SQL est utilisé, assurez-vous que le paramètre userdb_sql_iterate_query correspond à votre structure de base de données.

Lors de l'utilisation du module userdb LDAP, assurez-vous que les paramètres userdb_fields et userdb_ldap_iterate_fields correspondent à votre schéma LDAP. Sinon, doveadm(1) ne pourra pas itérer sur tous les utilisateurs.

-F fichier

Exécute la commande pour tous les utilisateurs du fichier. C'est similaire à l'option -A, mais au lieu d'obtenir la liste des utilisateurs à partir de la base d'utilisateurs, ils sont lus depuis le fichier donné. Le fichier contient un nom d'utilisateur par ligne.

--no-userdb-lookup

Ne pas effectuer de recherche dans la base d'utilisateurs. Utiliser la variable d'environnement USER pour spécifier le nom d'utilisateur.

-m


l'option est donnée, doveadm(1) effectuera la déduplication par l'en-tête Message-Id. Par défaut, la déduplication sera effectuée par les GUID des messages.

-S chemin_socket

L'argument de l'option est soit un chemin absolu vers un socket UNIX de domaine local, soit un nom d'hôte et un port (nom_hôte:port), afin de se connecter à un hôte distant via un socket TCP.

Cela permet à un administrateur d'exécuter des commandes de messagerie doveadm(1) via le socket donné.

-u utilisateur/masque

Exécute la commande uniquement pour l'utilisateur donné. Il est également possible d'utiliser les jokers '*' et '?' (par exemple -u *@example.org).

ARGUMENTS

requête_recherche

EXEMPLE

Cet exemple montre comment lister et supprimer les messages dupliqués d'une boîte aux lettres.

doveadm -f table fetch -u jane 'guid uid' mailbox a_Box | sort
guid                             uid
8aad0f0a30169f4bea620000ca356bad 18751
8aad0f0a30169f4bea620000ca356bad 18756
923e301ab9219b4b4f440000ca356bad 18748
923e301ab9219b4b4f440000ca356bad 18753
doveadm deduplicate -u jane mailbox a_Box
doveadm -f table fetch -u jane 'guid uid' mailbox a_Box | sort
guid                             uid
8aad0f0a30169f4bea620000ca356bad 18751
923e301ab9219b4b4f440000ca356bad 18748
a7999e1530739c4bd26d0000ca356bad 18749
