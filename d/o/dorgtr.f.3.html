Documentation de la fonction/sous-routine

sous-routine dorgtr (caractère uplo, entier n, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( * ) tau, double précision, dimension( * ) work, entier lwork, entier info)

DORGTR

But:

!>
!> DORGTR génère une matrice orthogonale réelle Q qui est définie comme le
!> produit de n-1 réflexions élémentaires de taille N, comme retourné par
!> DSYTRD :
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': Le triangle supérieur de A contient les réflexions élémentaires
!>                 provenant de DSYTRD ;
!>          = 'L': Le triangle inférieur de A contient les réflexions élémentaires
!>                 provenant de DSYTRD.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice Q. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          En entrée, les vecteurs qui définissent les réflexions élémentaires,
!>          comme retournés par DSYTRD.
!>          En sortie, la matrice orthogonale N-par-N Q.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau DOUBLE PRECISION, dimension (N-1)
!>          TAU(i) doit contenir le facteur scalaire de la réflexion élémentaire
!>          H(i), comme retourné par DSYTRD.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,N-1).
!>          Pour une performance optimale LWORK >= (N-1)*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>
