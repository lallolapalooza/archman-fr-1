NOM

docker - Interface en ligne de commande pour les images et conteneurs Docker

SYNTAXE

docker [OPTIONS] COMMAND [ARG...]

docker [--help|-v|--version]

DESCRIPTION

docker est un client pour interagir avec le démon (voir dockerd(8)) via la CLI.

La CLI Docker possède plus de 30 commandes. Les commandes sont listées ci-dessous et chacune possède sa propre page de manuel qui explique son utilisation et ses arguments.

Pour voir la page de manuel d'une commande, exécutez man docker .

OPTIONS

--help
Affiche l'énoncé d'utilisation

--config=""
Spécifie l'emplacement des fichiers de configuration du client Docker. Le défaut est '~/.docker'.

-D, --debug=true|false
Active le mode de débogage. Le défaut est false.

-H, --host=[unix:///var/run/docker.sock]: tcp://[hôte]:[port][chemin] auquel se lier ou unix://[/chemin/vers/socket] à utiliser.
Le ou les sockets auxquels se lier en mode démon spécifiés à l'aide d'un ou plusieurs
tcp://hôte:port/chemin, unix:///chemin/vers/socket, fd://* ou fd://socketfd.
Si le port tcp n'est pas spécifié, alors il sera par défaut soit 2375 lorsque
--tls est désactivé, soit 2376 lorsque --tls est activé, ou --tlsverify est spécifié.

-l, --log-level="debug|info|warn|error|fatal"
Définit le niveau de journalisation. Le défaut est info.

--tls=true|false
Utilise TLS ; implicite par --tlsverify. Le défaut est false.

--tlscacert=~/.docker/ca.pem
Fait confiance aux certificats signés uniquement par cette CA.

--tlscert=~/.docker/cert.pem
Chemin vers le fichier de certificat TLS.

--tlskey=~/.docker/key.pem
Chemin vers la clé TLS.

--tlsverify=true|false
Utilise TLS et vérifie le client distant (démon : vérifie le client, client : vérifie le démon).
Le défaut est false.

-v, --version=true|false
Affiche les informations de version et quitte. Le défaut est false.

COMMANDES

Utilisez "docker help" ou "docker --help" pour obtenir un aperçu des commandes disponibles.

EXEMPLES

Pour des exemples de client spécifiques, consultez la page de manuel de la commande Docker concernée. Par exemple :

man docker-run
