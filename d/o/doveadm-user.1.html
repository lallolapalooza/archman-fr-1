NOM

doveadm-user - Effectuer une recherche d'utilisateur dans les userdb de Dovecot

SYNOPIS

doveadm [OPTIONS GLOBALES] user [-a chemin_socket_userdb] [-f champ] [-u] [-x info_authentification] utilisateur...

DESCRIPTION

La commande user est utilisée pour effectuer une recherche d'utilisateur - pour afficher les informations que Dovecot voit concernant l'utilisateur (s), ou s'il existe réellement dans les userdb configuré (s).

L'info_authentification peut être utile lorsque la userdb est par exemple une base de données SQL et que vous utilisez des %variables, comme %{protocol} ou %{local_ip}, dans le paramètre userdb_sql_query. Ou lorsque vous avez configuré la userdb de cette manière :

userdb passwd-file {
  passwd_file_path = /etc/%{protocol}.passwd
}

OPTIONS GLOBALES

doveadm(1) global

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise simplement les valeurs par défaut. Le paramètre dovecot_storage_version prend la dernière version par défaut, mais peut être remplacé par

-k

Préserve tout l'environnement pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris un compteur de progression.

-i nom_instance

Si vous utilisez plusieurs instances Dovecot, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier_config

Lit la configuration à partir du fichier_config spécifié. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer cela vers le socket de configuration d'une instance exécutant une version compatible.

-o parametre=valeur

Remplace le parametre de configuration de /etc/dovecot/dovecot.conf et de la userdb par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

OPTIONS

-a chemin_socket_userdb

Cette option est utilisée pour spécifier un chemin absolu vers un socket de domaine UNIX alternatif.

Par défaut, doveadm(1) utilisera le socket

-f champ

Lorsque cette option et le nom d'un champ userdb sont donnés, doveadm(1) n'affichera que la valeur du champ spécifié.

-u

Lorsque cette option est donnée, doveadm(1) n'affichera que les valeurs du

-x info_authentification

info_authentification spécifie des conditions supplémentaires pour la commande user. La chaîne d'option info_authentification doit être donnée sous forme de paire nom = valeur. Pour plusieurs conditions, l'option -x peut être fournie plusieurs fois.

Les noms possibles pour l'info_authentification sont :

service

Le service pour lequel la recherche userdb doit être testée. La valeur peut être le nom d'un service, couramment utilisé avec Dovecot. Par exemple : imap, pop3 ou smtp.

session

Identifiant de session.

lip

L'adresse IP locale (serveur) pour le test.

rip

L'adresse IP distante (client) pour le test.

lport

Le port local, par exemple 143

rport

Le port distant, par exemple 24567

real_lip

L'IP locale à laquelle le client s'est connecté sur cet hôte.

real_rip

L'IP distante d'où le client s'est connecté à cet hôte.

real_lport

Le port local auquel le client s'est connecté à cet hôte.

real_rport

Le port distant d'où le client s'est connecté à cet hôte.

forward_<champ>

Champ à transférer en tant que %{forward:champ} au processus d'authentification.

ARGUMENTS

utilisateur

Est le nom d'utilisateur de connexion. Selon la configuration, un nom d'utilisateur peut être par exemple jane ou john@example.com. Il est également possible d'utiliser les jokers '*' et '?' (par exemple, -u \*@example.org).

EXEMPLE

Effectuer une recherche d'utilisateur pour les utilisateurs jane et john@example.com :

doveadm user jane john@example.com
userdb: jane
  uid       : 8001
  gid       : 8001
  home      : /home/jane
  mail_path : ~/sdbox
  plugins   : sieve
  quota_storage_size: 150M
userdb: john@example.com
  home      : /srv/mail/8/70312/79832
  uid       : 79832
  gid       : 70312
  mail_path : ~/mdbox

Recherche d'utilisateur, utilisant des jokers :

doveadm user \*.?oe@example.net
jane.doe@example.net
judy.roe@example.net
john.doe@example.net

SIGNALEMENT DES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur le signalement des bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html
