NOM

doveadm - Dovecot's administration tool

SYNTAXIS

doveadm [options] command [args]

DESCRIPTION

doveadm is a command-line tool for managing Dovecot. It can be used to perform various administrative tasks, such as managing users, mailboxes, and mail itself.

The command is divided into several subcommands, each responsible for a specific set of tasks.

OPTIONS GLOBALES

These options apply to all doveadm commands.

-c file
Use specified configuration file instead of the default.
-f command
Run a specific command on all users.
-i
Iterate over users and run specified command for each user.
-o property=value
Overrides a configuration file setting.
-S socket_path
Connect to the given listen socket.
-v
Enable verbosity.

STATUT DE SORTIE

doveadm will exit with one of the following values:

0

Selected command was executed successful.

64

Command line usage error.

65

Data format error or operation is not possible.

67

User does not exist.

68

Input file, address or other resource does not exist.

73

Cannot create output file.

75

There was some temporary error, check logs.

76

Protocol error during remote host connection.

77

Permission error.

78

Configuration error.

127

Unknown error.
