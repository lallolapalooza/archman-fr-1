DESCRIPTIO

N

doveconf lit et analyse les fichiers de configuration de Dovecot et les convertit dans un format plus simple utilisé par le reste de

Dovecot.

Tous les programmes autonomes, tels que dovecot(1), obtiendront d'abord leurs paramètres en exécutant doveconf, sauf s'ils peuvent les obtenir en se connectant au socket UNIX de

configuration.

Pour les administrateurs système, doveconf est principalement utile pour afficher

la configuration dans une
sortie facilement lisible.

F

Afficher la configuration dans un format basé sur les filtres, qui est la manière dont Dovecot y accède en interne. Cela peut être utile pour déboguer pourquoi la configuration ne fonctionne pas comme

prévu.

Les paramètres sont regroupés dans différentes « structures », qui sont toutes accessibles indépendamment. Une nouvelle structure commence dans la sortie par # nom_de_structure

.

Ensuite vient la liste des filtres, qui commencent par :FILTER suivi du filtre dans la syntaxe de filtre d'événement. Un filtre vide correspond à tout. Les filtres sont traités de la fin au début. Les paramètres sont pris du premier filtre correspondant (c'est-à-dire le dernier dans la sortie). Comme tous les filtres n'ont pas tous les paramètres définis, le traitement continue jusqu'à ce que tous les paramètres aient été

trouvés.

Les filtres de liste nommés tels que protocols = imap pop3 sont affichés comme protocol/imap=yes et protocol/pop3=yes # stop list. Le « stop list » signifie que la valeur n'est pas modifiée par les filtres suivants qui correspondent. Si le paramètre avait été défini comme protocols { imap=yes, pop3=yes }, le « stop list » serait absent, car ce paramètre ajoute seulement les protocoles, il ne remplace pas la

liste.

Les groupes de paramètres sont inclus dans les lignes :INCLUDE. Les inclusions sont traitées en dernier, après que tous les fi

ltres ont été appliqués, de sorte q
