NOM

docker-image-rm - Supprime une ou plusieurs images

SYNTAXE

docker image rm [OPTIONS] IMAGE [IMAGE...]

DESCRIPTION

Supprime (et désétiquette) une ou plusieurs images du nœud hôte. Si une image a plusieurs étiquettes, l'utilisation de cette commande avec l'étiquette en paramètre ne supprime que l'étiquette. Si l'étiquette est la seule pour l'image, l'image et l'étiquette sont supprimées.

Cela ne supprime pas les images d'un registre. Vous ne pouvez pas supprimer une image d'un conteneur en cours d'exécution à moins d'utiliser l'option -f. Pour voir toutes les images sur un hôte, utilisez la commande docker image ls.

EXEMPLES

Suppression d'une image

Voici un exemple de suppression d'une image :

docker image rm fedora/httpd

OPTIONS

-f, --force[=false] Force la suppression de l'image

--no-prune[=false] Ne supprime pas les parents sans étiquette

--platform=[] Supprime uniquement la variante de plateforme donnée. Formaté comme "os[/arch[/variant]]" (par exemple, "linux/amd64")
