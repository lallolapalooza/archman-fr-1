NOM

doveadm-mailbox - Commandes liées à la gestion des boîtes aux lettres

SYNOPSIS

doveadm [OPTIONS GLOBALES] [-f formateur] commande_boîte_aux_lettres [OPTIONS] [ARGUMENTS]

DESCRIPTION

doveadm mailbox peut être utilisé pour interroger et modifier les boîtes aux lettres.

OPTIONS GLOBALES

Options globales de doveadm(1)

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise simplement les valeurs par défaut. Le dovecot_storage_version paramètre a par défaut la dernière version, mais peut être remplacé avec

-k

Préserve l'environnement complet pour doveadm, pas seulement le import_environment paramètre.

-v

Active la verbosité, y compris le compteur de progression.

-i nom_instance

Si vous utilisez plusieurs instances Dovecot, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le instance_name paramètre pour plus d'informations.

-c fichier_configuration

Lit la configuration depuis le fichier_configurationdonné. Par défaut, il lit d'abord la socket de configuration, puis utilise /etc/dovecot/dovecot.conf. Vous pouvez également pointer vers la socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de la userdb avec la valeurdonnée. Afin de remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

-f formateur

Spécifie le formateur pour formater la sortie. Les formateurs pris en charge sont :

flow

affiche chaque ligne avec des paires clé=valeur .

json

affiche un tableau JSON d'objets JSON.

pager

affiche chaque paire clé: valeur sur sa propre ligne et sépare les enregistrements avec un caractère de saut de page (^L).

tab

affiche un en-tête de tableau suivi de lignes de valeurs séparées par des tabulations.

table

affiche un en-tête de tableau suivi de lignes de valeurs alignées.

OPTIONS

-A

Si l'option -A est présente, la commande sera exécutée pour tous les utilisateurs. L'utilisation de cette option en combinaison avec les utilisateurs système de userdb { driver = passwd } n'est pas recommandée, car elle contient également des utilisateurs avec un UID inférieur à celui configuré avec le first_valid_uid paramètre.

Lorsque le module userdb SQL est utilisé, assurez-vous que le userdb_sql_iterate_query paramètre correspond à la disposition de votre base de données.

Lors de l'utilisation du module userdb LDAP, assurez-vous que le userdb_fields paramètre et le userdb_ldap_iterate_fields paramètre correspondent à votre schéma LDAP. Sinon doveadm(1) ne sera pas en mesure d'itérer sur tous les utilisateurs.

-F fichier

Exécute la commande pour tous les utilisateurs du fichier. C'est similaire à l'option -A , mais au lieu d'obtenir la liste des utilisateurs depuis la userdb, ils sont lus depuis le fichierdonné. Le fichier contient un nom d'utilisateur par ligne.

--no-userdb-lookup

N'effectue pas de recherche dans la userdb. Utilise la variable d'environnement USER pour spécifier le nom d'utilisateur.

-S chemin_socket

L'argument de l'option est soit un chemin absolu vers une socket de domaine UNIX locale, soit un nom d'hôte et un port (nom_hôte:port), afin de se connecter à un hôte distant via une socket TCP.

Cela permet à un administrateur d'exécuter les commandes de courrier doveadm(1) via la socket donnée.

-u utilisateur/masque

Exécute la commande uniquement pour l' utilisateurdonné. Il est également possible d'utiliser les caractères génériques '*' et '?' (par ex. -u *@example.org).

ARGUMENTS

boîte_aux_lettres

Est le nom d'une boîte aux lettres, tel que visible par les clients IMAP, sauf au format UTF-8. Le séparateur de hiérarchie entre une boîte aux lettres parente et enfant est généralement '/' ou '.', mais cela dépend du format de stockage des boîtes aux lettres et de la configuration de l'espace de noms sélectionnés. Les noms de boîtes aux lettres peuvent également nécessiter un préfixe d'espace de noms.

COMMANDES

mailbox create

doveadm [OPTIONS GLOBALES] mailbox create [-A | -u utilisateur | -F fichier | --no-userdb-lookup] [-S chemin_socket] [-g guid] [-s] boîte_aux_lettres...

Cette commande est utilisée pour créer une ou plusieurs boîtes aux lettres. Le format des boîtes aux lettres créées dépend du mail_driver paramètre, ou du champ mail de l'utilisateur, retourné par la userdb.

-g guid

Crée la boîte aux lettres avec le GUID spécifié.

-s

Lorsque cette option est donnée, les boîtes aux lettres créées seront également ajoutées aux abonnements de l'utilisateur.

mailbox cryptokey

doveadm [OPTIONS GLOBALES] mailbox cryptokey export|generate|list|password

Cette commande est utilisée pour gérer les clés cryptographiques du plugin mail crypt. Veuillez consulter doveadm-mailbox-cryptokey(1) pour plus de détails.

mailbox delete

doveadm [OPTIONS GLOBALES] mailbox delete [-A | -u utilisateur | -F fichier | --no-userdb-lookup] [-S chemin_socket] [-s] [-r] [-e] [-Z] boîte_aux_lettres...

Cette commande supprime une boîte aux lettres et purge tous les messages qu'elle contient. Si la boîte aux lettres a des enfants, ils ne seront pas supprimés, sauf si -r est donné.

-r

Supprime les boîtes aux lettres récursivement

-s

Désabonne les boîtes aux lettres supprimées.

-e

Exige que les boîtes aux lettres soient vides avant la suppression.

-Z

Supprime la boîte aux lettres aussi efficacement que possible, mais l'utilisateur peut ne pas être dans un état totalement cohérent par la suite. Par exemple, le quota peut être incorrect. Cette option est principalement utile lors de la suppression de l'utilisateur entier.

mailbox list

doveadm [OPTIONS GLOBALES] mailbox list [-7 | -8] [-A | -u utilisateur | -F fichier | --no-userdb-lookup] [-S chemin_socket] [-s] [boîte_aux_lettres ...]

Pour obtenir un aperçu des boîtes aux lettres existantes, utilisez cette commande. Il est également possible d'utiliser des caractères génériques dans le nom de la boîte aux lettres .

Lorsque l' -s option est présente, seules les boîtes aux lettres souscrites seront listées. Les abonnements listés peuvent également contenir des boîtes aux lettres déjà

supprimées.

mailbox cache purge

doveadm [OPTIONS GLOBALES] mailbox cache purge [-A | -u utilisateur | -F fichier | --no-userdb-lookup] [-S chemin_socket] mailbox ...

Purger le fichier dovecot.index.cache. Le plus important est que cela libère de l'espace disque des mails qui ont déjà été supprimés. Normalement, il n'est pas nécessaire d'exécuter cette commande manuellement, car la compression est également exécutée automatiquement.

mailbox cache decision

doveadm [OPTIONS GLOBALES] mailbox cache decision [-A | -u utilisateur | -F fichier | --no-userdb-lookup] [-S chemin_socket] [--all] [--fields liste de champs] [--last-used horodatage unix] [--decision non|temp|oui] mailbox ...

Cette commande est utilisée pour lister ou modifier les décisions de mise en cache pour les champs dans une ou plusieurs boîtes aux lettres. Vous pouvez lister les décisions en omettant les paramètres decision et last-used.

--all

Lister ou modifier tous les champs.

--fields

Lister ou modifier ces champs séparés par des virgules/espaces.

--decision

Définir la décision de mise en cache du champ. Oui signifie qu'il est toujours mis en cache. Temp signifie qu'il est mis en cache provisoirement. Non signifie que le champ n'est pas mis en cache.

--last-used

Définir l'horodatage de la dernière utilisation du champ.

NOTE : Cette commande ne peut pas être utilisée pour ajouter de nouveaux champs au cache ! Vous devez d'abord les ajouter à la configuration. Définir la mise en cache sur non ne supprimera pas immédiatement le champ du cache, cela cessera d'ajouter le champ au cache.

mailbox cache remove

doveadm [OPTIONS GLOBALES] mailbox cache remove [-A | -u utilisateur | -F fichier | --no-userdb-lookup] [-S chemin_socket] requête de recherche

Supprimer les mails correspondants du cache.

ATTENTION ! Cette commande peut effacer TOUTES les données mises en cache, entraînant une lenteur du système.

Voir doveadm-search-query(7) pour la syntaxe de la requête de recherche.

EXEMPLE

Lister les boîtes aux lettres souscrites, commençant par 'dovecot', de l'utilisateur bob :

doveadm mailbox list -s -u bob dovecot\*
dovecot
dovecot/pigeonhole
dovecot/pigeonhole/2.0

Maintenant, regardez l'état des boîtes aux lettres dovecot de l'utilisateur bob :

doveadm -f table mailbox status -u bob "messages vsize" dovecot\*
mailbox                                    messages vsize
dovecot                                    20501    93968492
dovecot/pigeonhole                         0        0
dovecot/pigeonhole/2.0                     47       323474

Conversion d'un nom de boîte aux lettres internationalisé de mUTF-7 vers UTF-8 et vice versa :

doveadm mailbox mutf7 -7 "~peter/mail/&U,BTFw-/&ZeVnLIqe-"
~peter/mail/台北/日本語
doveadm mailbox mutf7 ~peter/mail/台北/日本語
~peter/mail/&U,BTFw-/&ZeVnLIqe-
