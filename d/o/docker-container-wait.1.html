NOM

docker-container-wait - Bloque jusqu'à ce qu'un ou plusieurs conteneurs s'arrêtent, puis affiche leurs codes de sortie.

SYNOPIS

docker container wait CONTENEUR [CONTENEUR...]

DESCRIPTION

Bloque jusqu'à ce qu'un conteneur s'arrête, puis affiche son code de sortie.

EXEMPLES

$ docker run -d fedora sleep 99
079b83f558a2bc52ecad6b2a5de13622d584e6bb1aea058c11b36511e85e7622
$ docker container wait 079b83f558a2bc
0
