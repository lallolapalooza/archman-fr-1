NOM

                    
podman-pod-ps - Lister les conteneurs dans les pods

                

                

                    
SYNOPSIS

                    
podman pod ps [options] [pod]...

                

                

                    
DESCRIPTION

                    
La commande podman pod ps renvoie une liste
                        des conteneurs dans les pods. Vous pouvez filtrer cette
                        liste en utilisant diverses options.

                

                

                    
OPTIONS

                    

                        
--all, -a

                        
Ne pas omettre les conteneurs arrêtés.

                        
--ctr-ids

                        
Afficher les identifiants de conteneur.

                        
--ctr-names

                        
Afficher les noms des conteneurs.

                        
--filter condition, -f
                            condition

                        
Filtrer la sortie selon une condition donnée. Les
                            conditions de filtrage sont des paires clé=valeur. Les
                            filtres valides sont :
                            
    
                                
  • ctr-ids=ID L'ID du conteneur
                                    à filtrer.
    • 
                                
  • ctr-number=nombre Le nombre de
                                    conteneurs dans le pod.
    • 
                                
  • ctr-status=statut Le statut du
                                    conteneur. Les valeurs acceptées sont «
                                    created », « running », « exited », « paused
                                    », « restarting », « removing », « dead ».
    • 
                                
  • id=ID L'ID du pod à
                                    filtrer.
    • 
                                
  • label=label Les labels à filtrer.
                                    Les étiquettes sont sous forme de clé=valeur.
    • 
                                
  • name=nom Le nom du pod à
                                    filtrer.
    • 
                                
  • status=statut Le statut du pod.
                                    Les valeurs acceptées sont « created »,
                                    « running », « paused », « restarting »,
                                    « exited », « removing », « dead », «
                                    unknown », « degraded ».
    • 
                                
  • until=timestamp Les pods créés
                                    avant un horodatage donné. L'horodatage peut
                                    être Unix, format ISO, ou relatif (par ex.
                                    « 2m » pour 2 minutes).
    • 
                            

                        

                        
--format format

                        
Utiliser un format Go [golang] spécifié pour imprimer
                            les informations sur les conteneurs. Les valeurs par
                            défaut sont «
                            table ».

                        
--last, -l

                        
Afficher le dernier conteneur arrêté.

                        
--latest

                        
Afficher le pod le plus récemment créé.

                        
--no-trunc

                        
Ne pas tronquer la sortie.

                        
--pod-ids

                        
Afficher les identifiants de pod.

                        
--pod-names

                        
Afficher les noms de pod.

                        
--quiet, -q

                        
N'afficher que les identifiants de pod.

                        
--size

                        
Taille du pod.

                        
--sync

                        
Synchroniser les statuts des conteneurs.

                    

                

                

                    
EXEMPLES

                    
Lister tous les pods et leurs conteneurs.

                    
$ podman pod ps
POD ID        NAME         STATUS      CREATED        INFRA ID      # OF CONTAINERS
95938982244d  nettest      Running     4 minutes ago  a28d133e8c63  3
deee8956522e  utility      Running     4 minutes ago  6b730e3ac334  3
06c3a107763a  maintenance  Degraded    4 minutes ago  67e500cbb678  3
1e3424d7e9c0  db-cluster   Degraded    4 minutes ago  d6650a490b69  3
952330c7cff0  web-app      Running     4 minutes ago  b0f247c49669  3

                    
Lister tous les pods en cours d'exécution avec
                        les noms des conteneurs.

                    
$ podman pod ps --ctr-names
POD ID         NAME   STATUS    CREATED        INFRA ID       NAMES
314f4da82d74   hi     Created   17 hours ago   a9f2d2165675   jovial_jackson,hopeful_archimedes,vibrant_ptolemy,heuristic_jennings,keen_raman,hopeful_newton,mystifying_bose,silly_lalande,serene_lichterman ...

                    
Lister tous les pods en cours d'exécution avec
                        les identifiants des conteneurs

                    
$ podman pod ps --filter ctr-ids=aceb3b775797
POD ID        NAME        STATUS      CREATED        INFRA ID      # OF CONTAINERS
952330c7cff0  web-app     Running     3 minutes ago  b0f247c49669  3

                    
Lister tous les pods avec exactement 2
                        conteneurs

                    
$ podman pod ps --filter ctr-number=2
POD ID        NAME         STATUS      CREATED        INFRA ID      # OF CONTAINERS
b2ae050d17be  labeled-pod  Running     2 minutes ago  fda2a486b939  2

                    
Lister les pods avec des conteneurs en statut
                        exited

                    
$ podman pod ps --filter ctr-status=exited
POD ID        NAME         STATUS      CREATED        INFRA ID      # OF CONTAINERS
06c3a107763a  maintenance  Degraded    4 minutes ago  67e500cbb678  3
1e3424d7e9c0  db-cluster   Degraded    4 minutes ago  d6650a490b69  3

                    
Lister tous les pods actuels

                    
$ podman pod ps
POD ID        NAME         STATUS      CREATED        INFRA ID      # OF CONTAINERS
95938982244d  nettest      Running     4 minutes ago  a28d133e8c63  3
deee8956522e  utility      Running     4 minutes ago  6b730e3ac334  3
06c3a107763a  maintenance  Degraded    4 minutes ago  67e500cbb678  3
1e3424d7e9c0  db-cluster   Degraded    4 minutes ago  d6650a490b69  3
952330c7cff0  web-app      Running     4 minutes ago  b0f247c49669  3

                    
Filtrer un pod par ID

                    
$ podman pod ps --filter id=95938982244d
POD ID        NAME        STATUS      CREATED        INFRA ID      # OF CONTAINERS
95938982244d  nettest     Running     4 minutes ago  a28d133e8c63  3

                    
Filtrer un pod par label

                    
$ podman pod ps --filter label=tier=frontend
POD ID        NAME         STATUS      CREATED       INFRA ID      # OF CONTAINERS
b2ae050d17be  labeled-pod  Running     1 second ago  fda2a486b939  2

                    
Filtrer un pod par nom

                    
$ podman pod ps --filter name=db-cluster
POD ID        NAME        STATUS      CREATED        INFRA ID      # OF CONTAINERS
1e3424d7e9c0  db-cluster  Degraded    4 minutes ago  d6650a490b69  3

                    
Filtrer un pod par statut (par ex.
                        Degraded)

                    
$ podman pod ps --filter status=degraded
POD ID        NAME         STATUS      CREATED        INFRA ID      # OF CONTAINERS
95938982244d  nettest      Degraded    7 minutes ago  a28d133e8c63  3
06c3a107763a  maintenance  Degraded    8 minutes ago  67e500cbb678  3
1e3424d7e9c0  db-cluster   Degraded    8 minutes ago  d6650a490b69  3
952330c7cff0  web-app      Degraded    8 minutes ago  b0f247c49669  3

                    
Filtrer les pods créés avant un seuil de
                        temps (--until)

                    
$ podman pod ps --filter until=2m

b2ae050d17be  labeled-pod  Running     3 minutes ago  fda2a486b939  2
95938982244d  nettest      Degraded    8 minutes ago  a28d133e8c63  3
