NOM

doveadm-rebuild - Commandes liées à la reconstruction de divers aspects des courriels correspondant à la requête de recherche donnée.

SYNOPSIS

doveadm [OPTIONS GLOBALES] [-f formatter] rebuild <command> [-S socket_path] -A search_query

doveadm [OPTIONS GLOBALES] [-f formatter] rebuild <command> [-S socket_path] -F file search_query

doveadm [OPTIONS GLOBALES] [-f formatter] rebuild <command> [-S socket_path] --no-userdb-lookup search_query

doveadm [OPTIONS GLOBALES] [-f formatter] rebuild <command> [-S socket_path] -u user search_query

OPTIONS GLOBALES

Les options globales de doveadm(1)

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise simplement les valeurs par défaut. Le paramètre dovecot_storage_version a par défaut la valeur de la dernière version, mais peut être remplacé avec

-k

Préserve l'environnement entier pour doveadm, pas seulement le paramètre import_environment .

-v

Active la verbosité, y compris le compteur de progression.

-i instance-name

Si vous utilisez plusieurs instances Dovecot, choisissez le fichier de configuration basé sur ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c config-file

Lit la configuration depuis le config-filedonné. Par défaut, il lit d'abord la config socket, puis revient à /etc/dovecot/dovecot.conf. Vous pouvez aussi pointer vers la config socket d'une instance exécutant une version compatible.

-o setting=value

Remplace le paramètre de configuration setting de /etc/dovecot/dovecot.conf et de la userdb avec la valuedonnée. Afin de remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

-f formatter

Spécifie le formatter pour formater la sortie. Les formatters supportés sont :

flow

affiche chaque ligne avec des paires key=value .

json

affiche un tableau JSON d'objets JSON.

pager

affiche chaque paire key: value sur sa propre ligne et sépare les enregistrements avec le caractère de saut de page (^L).

tab

affiche un en-tête de tableau suivi de lignes de valeurs séparées par des tabulations.

table

affiche un en-tête de tableau suivi de lignes de valeurs alignées.

Cette commande utilise par défaut le formateur de sortie flow (sans le préfixe key =).

OPTIONS

-A

Si l'option -A est présente, la commande sera exécutée pour tous les utilisateurs. L'utilisation de cette option en combinaison avec les utilisateurs système de userdb { driver = passwd } n'est pas recommandée, car elle contient aussi des utilisateurs avec un UID inférieur à celui configuré avec le paramètre first_valid_uid .

Lorsque le module userdb SQL est utilisé, assurez-vous que le paramètre userdb_sql_iterate_query correspond à la disposition de votre base de données.

Lors de l'utilisation du module userdb LDAP, assurez-vous que les paramètres userdb_fields et userdb_ldap_iterate_fields correspondent à votre schéma LDAP. Sinon doveadm(1) ne pourra pas itérer sur tous les utilisateurs.

-F file

Exécute la commande pour tous les utilisateurs dans le filedonné. C'est similaire à l'option -A , mais au lieu d'obtenir la liste des utilisateurs depuis la userdb, ils sont lus depuis le filedonné. Le file contient un nom d'utilisateur par ligne.

--no-userdb-lookup

N'effectue pas de recherche dans la userdb. Utilise la variable d'environnement USER pour spécifier le nom d'utilisateur.

-S socket_path

L'argument de l'option est soit un chemin absolu vers un socket de domaine UNIX local, soit un nom d'hôte et un port (hostname:port), afin de se connecter à un hôte distant via un socket TCP.

Cela permet à un administrateur d'exécuter les commandes de courrier de doveadm(1) via le socket donné.

-u user/mask

Exécute la commande uniquement pour l' userdonné. Il est aussi possible d'utiliser les caractères génériques '*' et '?' (ex. -u *@example.org).

ARGUMENTS

search_query

Réinitialise l'indicateur de pièce jointe pour les messages correspondant à cette requête de recherche. Voir doveadm-search-query(7) pour les détails.

doveadm rebuild attachments -u bob ALL

    NOM

    doveadm-rebuild - reconstruire les index d'e-mails

    SYNOPSIS

    doveadm rebuild [-A|-m] [<user> ...]

    DESCRIPTION

    La commande doveadm rebuild est utilisée pour reconstruire les index d'e-mails pour un ou plusieurs utilisateurs. Elle peut être utilisée pour résoudre les problèmes de corruption d'index ou pour s'assurer que les index sont à jour.

    OPTIONS

    Notez que toutes ces options ne sont pas nécessairement disponibles pour toutes les versions de Dovecot.

    -A

    Traiter tous les utilisateurs. Requiert des privilèges root.

    -m

    Traiter tous les utilisateurs ayant des boîtes aux lettres partagées. Requiert des privilèges root.

    ARGUMENTS

    <user> ...

    Un ou plusieurs noms d'utilisateur pour lesquels reconstruire les index.

    EXEMPLE

    Pour reconstruire les index de l'utilisateur john :

    doveadm rebuild john

    Pour reconstruire les index de tous les utilisateurs :

    doveadm rebuild -A

    SIGNALEMENT DE BOGUES

    Veuillez signaler les bogues à https://github.com/dovecot/core/issues
