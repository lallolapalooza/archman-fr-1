NOM

docker-container-diff - Examiner les modifications des fichiers ou répertoires dans le système de fichiers d'un conteneur

SYNTAXE

docker container diff CONTENEUR

DESCRIPTION

Liste les fichiers et répertoires modifiés dans le système de fichiers d'un conteneur depuis sa création. Trois types de modification sont suivis :

Symbole Description
A Un fichier ou répertoire a été ajouté
D Un fichier ou répertoire a été supprimé
C Un fichier ou répertoire a été modifié

Vous pouvez utiliser l'identifiant complet ou abrégé du conteneur ou le nom du conteneur défini à l'aide de l'option docker run --name.

EXEMPLES

Examiner les modifications d'un conteneur nginx :

$ docker diff 1fdfd1f54c1b
C /dev
C /dev/console
C /dev/core
C /dev/stdout
C /dev/fd
C /dev/ptmx
C /dev/stderr
C /dev/stdin
C /run
A /run/nginx.pid
C /var/lib/nginx/tmp
A /var/lib/nginx/tmp/client_body
A /var/lib/nginx/tmp/fastcgi
A /var/lib/nginx/tmp/proxy
A /var/lib/nginx/tmp/scgi
A /var/lib/nginx/tmp/uwsgi
C /var/log/nginx
A /var/log/nginx/access.log
A /var/log/nginx/error.log
