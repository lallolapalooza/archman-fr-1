NOM

doveadm-dump - Extraire le contenu de l'index/journal binaire de Dovecot

SYNOPIS

doveadm [OPTIONS GLOBALES] dump [-t type] chemin [arguments spécifiques au type]

DESCRIPTION

Dovecot utilise plusieurs fichiers d'index et journaux binaires afin d'améliorer les performances d'accès aux courriels. Pour certains formats de boîte aux lettres, comme sdbox et mdbox, les fichiers d'index font partie du format lui-même. Pour plus de détails sur les fichiers d'index, voir [[link,design_index_format_main].

doveadm dump est utilisé pour afficher le contenu de ces fichiers d'index/journaux de boîtes aux lettres, dans un format lisible par l'homme. Ceci est principalement utile pour les développeurs de Dovecot lors du débogage d'un problème.

OPTIONS GLOBALES

doveadm(1) global

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise simplement les valeurs par défaut. Le paramètre dovecot_storage_version est défini par défaut sur la dernière version, mais peut être remplacé par

-k

Préserve tout l'environnement pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom-instance

Si vous utilisez plusieurs instances de Dovecot, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier-config

Lit la configuration à partir du fichier-config donné. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

OPTIONS

-t type


a été omis, doveadm(1) essaie de détecter le type de

type peut être :

dbox : => m.n (fichier de boîte aux lettres sdbox ou mdbox)

fts-expunge-log : Extraire la liste des courriels supprimés dans dovecot-expunges.log.

fts-flatcurve : Extraire les mots-clés indexés dans le répertoire d'index fts-flatcurve et leurs fréquences.

imap-compress : Décompresser un journal de trafic IMAP, qui contient des données compressées à l'aide de l'extension IMAP COMPRESSION.

dcrypt-file : Extraire les métadonnées d'un fichier crypté par dcrypt.

arguments spécifiques au type

clé_privée=/chemin : pour décrypter le contenu du fichier.

mot_de_passe=secret : pour décrypter la clé privée.

dcrypt-key : Extraire les métadonnées d'une clé dcrypt.

arguments spécifiques au type

clé_privée=/chemin

pour décrypter le contenu du fichier.

mot_de_passe=secret

pour décrypter la clé privée.

dump=pem|dovecot|jwk

pour spécifier le format d'extraction.

index : => dovecot.index, dovecot.map.index

arguments spécifiques au type

uid=nombre : Extraire uniquement le message avec l'UID

log : => dovecot.index.log, dovecot.map.index.log

mailboxlog : => dovecot.mailbox.log

thread : => dovecot.index.thread

ARGUMENTS

chemin

Le chemin vers le stockage dbox correspondant, l'index ou le fichier journal. Si seul un répertoire est spécifié, doveadm tente de détecter le type de fichiers qu'il contient et de les extraire.

EXEMPLE

Examiner le contenu de l'index d'une boîte aux lettres :

doveadm dump ~/Maildir/.work/
