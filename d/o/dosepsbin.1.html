NOM

dosepsbin -- Extraire des sections PS/WMF/TIFF des fichiers binaires EPS DOS

VERSION

2012-03-22 v1.2

SYNTAXE

Le programme dosepsbin analyse un fichier EPS qui n'est pas un fichier PostScript ASCII simple mais est fourni sous forme de fichier binaire EPS DOS.

dosepsbin [options] <fichier d'entrée>

Il analyse d'abord le fichier d'entrée, valide son en-tête et résume les sections disponibles. Selon les options données, les sections sont ensuite écrites dans des fichiers.

Options :

--eps-file <fichier>      Écrit la section PS dans <fichier>.
--wmf-file <fichier>      Écrit la section WMF dans <fichier>.
--tiff-file <fichier>     Écrit la section TIFF dans <fichier>.
--inputfile <fichier>     Le nom du fichier d'entrée.
--verbose              Sortie détaillée.
--quiet                Seules les erreurs et les avertissements sont imprimés.
--help                 Message d'aide bref.
--man                  Documentation complète.
--version              Affiche l'identification de la version.

Les fichiers de sortie doivent être différents du fichier d'entrée.

DESCRIPTION

Format de fichier binaire EPS DOS

Un fichier Encapsulated PostScript (EPS) peut également être fourni dans un format binaire spécial pour prendre en charge l'inclusion d'une miniature. Le format de fichier commence par un en-tête binaire qui contient les positions des sections possibles :

* Postscript (PS)
* Format Metafile Windows (WMF)
* Format d'image Tag (TIFF)

La section PS doit être présente et soit le fichier WMF, soit le fichier TIFF doit être fourni.

OPTIONS

--eps-file=<fichier>
La section PS est écrite dans <fichier>. Le fichier de sortie doit être différent du fichier d'entrée.
--wmf-file=<fichier>
La section WMF est écrite dans <fichier> si elle est présente. Le fichier de sortie doit être différent du fichier d'entrée.
--tiff-file=<fichier>
La section TIFF est écrite dans <fichier> si elle est présente. Le fichier de sortie doit être différent du fichier d'entrée.
--inputfile=<fichier>
Le fichier d'entrée peut également être fourni directement sur la ligne de commande. Si le fichier n'existe pas, le fichier avec l'extension `.eps' est essayé.
--verbose
Messages détaillés.
--quiet
Aucun message n'est imprimé, sauf les erreurs et les avertissements.
--help
Affiche l'écran d'aide.
--man
Imprime la page de manuel.
--version
Affiche l'identification de la version et quitte.

EXEMPLES

La commande suivante extrait la section PS du fichier test.eps et enregistre le résultat dans le fichier test-ps.eps :

dosepsbin --eps-file test-ps.eps test.eps
