NOM

doveadm-fs - Interagir avec le système de fichiers de stockage de courrier abstrait

SYNTAXE

doveadm [OPTIONS GLOBALES] fs commande nom-du-filtre-de-configuration [ARGUMENTS]

doveadm [OPTIONS GLOBALES] mail fs commande [OPTIONS] nom-du-filtre-de-configuration [ARGUMENTS]

DESCRIPTION

Les commandes doveadm fs sont utilisées pour interagir de manière abstraite avec le pilote de stockage défini dans la configuration de Dovecot. Cela permet d'accéder à la structure de la boîte aux lettres sans avoir besoin de connaître les détails de conception du pilote de stockage.

nom-du-filtre-de-configuration

Nom du filtre à utiliser lors de la recherche des paramètres fs. Par exemple mail_attachments, obox, metacache, fts/dovecot. Il est également possible d'utiliser un nom de filtre vide et de spécifier les paramètres fs à l'aide du paramètre -o.

OPTIONS GLOBALES

doveadm(1) global

-D

Active la verbosité et les messages de débogage.

-O

Ne lit aucun fichier de configuration, utilise simplement les valeurs par défaut. Le paramètre dovecot_storage_version par défaut est la dernière version, mais peut être remplacé avec

-k

Préserve tout l'environnement pour doveadm, pas seulement le paramètre import_environment.

-v

Active la verbosité, y compris le compteur de progression.

-i nom-instance

Si vous utilisez plusieurs instances Dovecot, choisissez le fichier de configuration en fonction de ce nom d'instance.

Voir le paramètre instance_name pour plus d'informations.

-c fichier-configuration

Lit la configuration à partir du fichier-configuration spécifié. Par défaut, il lit d'abord le socket de configuration, puis se rabat sur /etc/dovecot/dovecot.conf. Vous pouvez également pointer ceci vers le socket de configuration d'une instance exécutant une version compatible.

-o paramètre=valeur

Remplace le paramètre de configuration de /etc/dovecot/dovecot.conf et de la base de données utilisateur par la valeur spécifiée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

-f formateur

Spécifie le formateur pour la mise en forme de la sortie. Les formateurs pris en charge sont :

flow

affiche chaque ligne avec des paires clé=valeur.

json

affiche un tableau JSON d'objets JSON.

pager

affiche chaque paire clé: valeur sur sa propre ligne et sépare les enregistrements par un caractère de saut de page (^L).

tab

affiche un en-tête de tableau suivi de lignes de valeurs séparées par des tabulations.

table

affiche un en-tête de tableau suivi de lignes de valeurs ajustées.

OPTIONS

-A

Si l'option -A est présente, la commande sera exécutée pour tous les utilisateurs. L'utilisation de cette option en combinaison avec les utilisateurs système de userdb { driver = passwd } n'est pas recommandée, car elle inclut également les utilisateurs avec un UID inférieur à celui configuré avec le paramètre first_valid_uid.

Lorsque le module userdb SQL est utilisé, assurez-vous que le paramètre userdb_sql_iterate_query correspond à la disposition de votre base de données.

Lors de l'utilisation du module userdb LDAP, assurez-vous que les paramètres userdb_fields et userdb_ldap_iterate_fields correspondent à votre schéma LDAP. Sinon, doveadm(1) sera incapable d'itérer sur tous les utilisateurs.

-u utilisateur/masque

Exécute la commande uniquement pour l'utilisateur spécifié. Il est également possible d'utiliser les jokers '*' et '?' (par exemple -u *@example.org).

-F fichier

Exécute la commande pour tous les utilisateurs du fichier. Ceci est similaire à l'option -A, mais au lieu d'obtenir la liste des utilisateurs à partir de la base de données utilisateur, elle est lue à partir du fichier spécifié. Le fichier contient un nom d'utilisateur par ligne.

-S chemin-socket

L'argument de l'option est soit un chemin absolu vers un socket de domaine UNIX local, soit un nom d'hôte et un port (nom-hôte:port), afin de connecter un hôte distant via un socket TCP.

Cela permet à un administrateur d'exécuter des commandes de courrier doveadm(1) via le socket spécifié.

COMMANDES

copier

doveadm [OPTIONS GLOBALES] fs copy nom-du-filtre-de-configuration chemin-source chemin-destination

doveadm [OPTIONS GLOBALES] mail fs copy [-A | -u utilisateur | -F fichier] [-S chemin-socket] nom-du-filtre-de-configuration chemin-source chemin-destination

Copie le chemin source vers le chemin de destination.

supprimer

doveadm [OPTIONS GLOBALES] fs delete [-R] [-n compteur] nom-du-filtre-de-configuration chemin [chemin ...]

doveadm [OPTIONS GLOBALES] mail fs delete [-A | -u utilisateur | -F fichier] [-S chemin-socket] [-R] [-n compteur] nom-du-filtre-de-configuration chemin [chemin ...]

Supprime toutes les données associées au chemin fourni.

-R

Supprime récursivement les fichiers.

-n compteur

Nombre maximum d'opérations parallèles à effectuer.

obtenir

doveadm [OPTIONS GLOBALES] fs get nom-du-filtre-de-configuration chemin

doveadm [OPTIONS GLOBALES] mail fs get [-A | -u utilisateur | -F fichier] [-S chemin-socket] nom-du-filtre-de-configuration chemin

Récupère les données associées au chemin fourni.

iterer

doveadm [OPTIONS GLOBALES] fs iter nom-du-filtre-de-configuration chemin

doveadm [OPTIONS GLOBALES] mail fs iter [-A | -u utilisateur | -F fichier] [-S chemin-socket] nom-du-filtre-de-configuration chemin

Itère sur tous les fichiers de données dans le chemin fourni.

iterer-reps

doveadm [OPTIONS GLOBALES] fs iter-dirs nom-du-filtre-de-configuration chemin

doveadm [OPTIONS GLOBALES] mail fs iter-dirs [-A | -u utilisateur | -F fichier] [-S chemin-socket] nom-du-filtre-de-configuration chemin

Itère sur tous les répertoires dans le chemin fourni.

poser

doveadm [OPTIONS GLOBALES] fs put [-h hash] [-m clé=valeur] nom-du-filtre-de-configuration chemin-entree chemin

doveadm [OPTIONS GLOBALES] mail fs put [-A | -u utilisateur | -F fichier] [-S chemin-socket] [-h hash] [-m clé=valeur] nom-du-filtre-de-configuration chemin-entree chemin

Écrit des données dans le chemin spécifié.

-h hash

Spécifie le hash à utiliser.

-m clé=valeur

Ajoute des métadonnées pour le fichier.

chemin-entree

Le chemin du fichier d'entrée. L'entrée standard est utilisée si ce paramètre est omis.

chemin

Le chemin de destination pour écrire les données.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

socket_path] [-h hash] [-m key=value] nom-filtre-config chemin

Stocke les données au chemin fourni.

-h hash

Enregistre le hash fourni comme hash de contenu. Doit être en MD5 ou SHA256 en hexadécimal.

-m key=value

Attribue une valeur à une métadonnée. Peut être fournie autant de fois que nécessaire. Nécessite soit metawrap comme pilote, soit un pilote FS capable de métadonnées.

stat

doveadm [OPTIONS GLOBALES] fs stat nom-filtre-config chemin

doveadm [OPTIONS GLOBALES] mail fs stat [-A | -u utilisateur | -F fichier] [-S socket_path] nom-filtre-config chemin

Récupère le statut des fichiers pour le chemin fourni. Actuellement, seule la taille totale (en octets) de l'élément est retournée.

SIGNALER LES BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur le signalement des bogues sont disponibles à l'adresse : https://dovecot.org/bugreport.html

EXEMPLE

Comment décompresser un fichier.

doveadm -o fs=compress,posix -o fs/compress/fs_driver=compress -o fs/posix/fs_driver=posix -o fs_posix_prefix=/tmp/ fs get "" test.gz

Utilisation d'un filtre nommé.

doveadm mail fs -u testuser get obox path/to/file
