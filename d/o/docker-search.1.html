NOM

docker-search - Rechercher des images sur Docker Hub

SYNOPSIS

docker search [OPTIONS] TERM

DESCRIPTION

Recherche sur Docker Hub des images correspondant au TERM spécifié. Le tableau d'images renvoyé affiche le nom, la description (tronquée par défaut), le nombre d'étoiles attribuées, si l'image est officielle et si elle est automatisée.

FILTRE

Filtre la sortie en fonction des conditions suivantes :
- stars=
- is-automated=(true|false) (obsolète)
- is-official=(true|false)

EXEMPLES

Rechercher sur Docker Hub des images classées

Recherche dans un registre le terme 'fedora' et n'affiche que les images classées à 3 étoiles ou plus :

$ docker search --filter=stars=3 fedora
NAME      DESCRIPTION                        STARS     OFFICIAL
fedora    Official Docker builds of Fedora   1150      [OK]

OPTIONS

-f, --filter= Filtre la sortie en fonction des conditions fournies

--format="" Prétraitement de la recherche en utilisant un modèle Go

--limit=0 Nombre maximum de résultats de recherche

--no-trunc[=false] Ne pas tronquer la sortie
