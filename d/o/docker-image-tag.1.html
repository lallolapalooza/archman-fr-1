NOM

docker-image-tag - Crée une étiquette TARGET_IMAGE qui fait référence à SOURCE_IMAGE

SYNOPSIS

docker image tag SOURCE_IMAGE[:TAG] TARGET_IMAGE[:TAG]

DESCRIPTION

Attribue un nouvel alias à une image dans un registre. Un alias fait référence au nom complet de l'image, y compris l'ÉTAPE facultative après le ':'.

OPTIONS

NOM
Le nom de l'image composé de composants de nom séparés par des barres obliques,
précédé éventuellement du nom d'hôte du registre. Le nom d'hôte doit être conforme aux
règles DNS standard, mais ne peut pas contenir de traits de soulignement. Si un nom d'hôte est
présent, il peut éventuellement être suivi d'un numéro de port au format
:8080. S'il n'est pas présent, la commande utilise le registre public de Docker situé à
registry-1.docker.io par défaut. Les composants du nom peuvent contenir des lettres minuscules,
des chiffres et des séparateurs. Un séparateur est défini comme un point, un ou
deux traits de soulignement, ou un ou plusieurs tirets. Un composant de nom ne peut pas commencer ou se terminer
par un séparateur.

ÉTAPE (TAG)
L'étiquette attribuée à l'image pour versionner et distinguer les images portant le même
nom. Le nom de l'étiquette doit être un caractère ASCII valide et peut contenir des lettres minuscules et
majuscules, des chiffres, des traits de soulignement, des points et des tirets. Un nom d'étiquette
ne peut pas commencer par un point ou un tiret et peut contenir un maximum de 128
caractères.

EXEMPLES

Étiquetage d'une image référencée par son ID

Pour étiqueter une image locale avec l'ID « 0e5574283393 » dans le répertoire « fedora » avec « version1.0 » :

docker image tag 0e5574283393 fedora/httpd:version1.0

Étiquetage d'une image référencée par son Nom

Pour étiqueter une image locale nommée « httpd » dans le répertoire « fedora » avec « version1.0 » :

docker image tag httpd fedora/httpd:version1.0

Notez que comme le nom de l'étiquette n'est pas spécifié, l'alias est créé pour une version locale existante httpd:latest.

Étiquetage d'une image référencée par Nom et Étiquette

Pour étiqueter une image locale nommée « httpd » et portant l'étiquette « test » dans le répertoire « fedora » avec « version1.0.test » :

docker image tag httpd:test fedora/httpd:version1.0.test

Étiquetage d'une image pour un registre privé

Avant de pousser une image vers un registre privé et non vers le registre Docker central, vous devez l'étiqueter avec le nom d'hôte et le port (si nécessaire) du registre.

docker image tag 0e5574283393 myregistryhost:5000/fedora/httpd:version1.0
