NOM

docker-node-update - Mettre à jour un nœud

SYNTAXE

docker node update [OPTIONS] NODE

DESCRIPTION

Mettre à jour un nœud

OPTIONS

--availability="" Disponibilité du nœud ("active", "pause", "drain")

--label-add= Ajouter ou mettre à jour une étiquette de nœud ("clé=valeur")

--label-rm= Supprimer une étiquette de nœud si elle existe

--role="" Rôle du nœud ("worker", "manager")
