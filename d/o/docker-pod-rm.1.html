NOM

podman-pod-rm - Supprime un ou plusieurs pods et conteneurs arrêtés

SYNOPSIS

podman pod rm [options] pod

DESCRIPTION

podman pod rm supprime un ou plusieurs pods arrêtés et leurs conteneurs de l'hôte. Le nom ou l'ID du pod peut être utilisé. L'option -f arrête tous les conteneurs puis les supprime avant de supprimer le pod. Si tous les conteneurs ajoutés par l'utilisateur sont dans un état terminé, le pod est supprimé.

OPTIONS

--all, -a

Supprime tous les pods. Peut être utilisé conjointement avec -f.

--force, -f

Arrête les conteneurs en cours d'exécution et supprime tous les conteneurs arrêtés avant la suppression du pod.

--ignore, -i

Ignore les erreurs lorsque les pods spécifiés ne sont pas dans le magasin de conteneurs. Un utilisateur pourrait avoir décidé de supprimer manuellement un pod, ce qui entraînerait un échec lors de la directive ExecStop d'un service systemd faisant référence à ce pod.

--latest, -l

Au lieu de fournir le nom ou l'ID du pod, utilise le dernier pod créé. Note : le dernier pod démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (à l'exclusion de WSL2)).

--pod-id-file=fichier

Lit l'ID du pod à partir du fichier spécifié et supprime le pod. Peut être spécifié plusieurs fois.

Si spécifié, le fichier d'ID de pod est supprimé en même temps que le pod.

--time, -t=secondes

Nombre de secondes à attendre avant d'arrêter de force les conteneurs en cours d'exécution dans le pod. Utilisez -1 pour une attente infinie.

L'option --force doit être spécifiée pour utiliser l'option --time.

EXEMPLE

Supprime un pod avec un nom donné :

podman pod rm monpodserveurweb

Supprime plusieurs pods avec des noms et/ou des ID donnés :

podman pod rm monpodserveurweb monpodserveurflask 860a4b23

Supprime de force un pod avec un ID donné :

podman pod rm -f 860a4b23

Supprime de force tous les pods :

podman pod rm -f -a
podman pod rm -fa

Supprime un pod en utilisant l'ID spécifié dans un fichier donné :

podman pod rm --pod-id-file /chemin/vers/fichier/id

STATUT DE SORTIE

0 Tous les pods spécifiés ont été supprimés

1 L'un des pods spécifiés n'existait pas, et aucune autre défaillance

2 L'un des pods spécifiés est attaché à un conteneur

125 La commande échoue pour toute autre raison
