NAME

dnf5-specs - Spécifications pour les paquets dnf5

DESCRIPTION

Ce manuel décrit les spécifications utilisées par dnf5 pour gérer les paquets.

GLOBS

Les motifs glob (globs) sont utilisés pour faire correspondre plusieurs fichiers.

PACKAGES

Les paquets sont les unités de base de la distribution logicielle.

COMPS

Les "comps" (component groups) sont des groupes de paquets logiques.

MODULES

Les modules permettent de gérer des ensembles de logiciels interconnectés.

TRANSACTIONS

Les transactions sont des ensembles d'opérations sur les paquets qui sont exécutées de manière atomique.
