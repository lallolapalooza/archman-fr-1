NOM

dnie-tool - affiche des informations sur les jetons de sécurité basés sur DNIe

SYNTAXE

dnie-tool [OPTIONS]

DESCRIPTION

L'utilitaire dnie-tool est utilisé pour afficher des informations supplémentaires sur le DNIe, la carte d'identité nationale espagnole.

OPTIONS

--idesp, -i

Affiche la valeur IDESP du DNIe.

--data, -d

Affiche les informations personnelles du DNIe. Lit et imprime le numéro du DNIe ainsi que le Nom et le Prénom de l'utilisateur.

--all, -a

Affiche toutes les informations disponibles. Cette commande est équivalente à -d -i -V -s

--serial, -s

Affiche le numéro de série du DNIe.

--version, -V

Affiche la version du logiciel du DNIe. Affiche la version du logiciel du SE du DNIe embarqué.

--pin pin, -p pin

Ces options peuvent être utilisées pour spécifier la valeur du PIN sur la ligne de commande. Si la valeur est définie sur env:VARIABLE, la valeur de la variable d'environnement spécifiée est utilisée. Par défaut, le code est demandé sur la ligne de commande si nécessaire.

Notez que sur la plupart des systèmes d'exploitation, n'importe quel utilisateur peut afficher la ligne de commande de n'importe quel processus sur le système en utilisant des utilitaires tels que ps(1). Par conséquent, vous devriez préférer passer les codes via une variable d'environnement sur un système non sécurisé.

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est un ATR, le lecteur avec une carte correspondante sera choisi.

--wait, -w

Fait attendre dnie-tool jusqu'à ce que le jeton soit inséré dans le lecteur.

--verbose, -v

Rend dnie-tool plus verbeux. Spécifiez cet indicateur plusieurs fois pour activer la sortie de débogage dans la bibliothèque opensc.
