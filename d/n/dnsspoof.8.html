NOM

dnsspoof - Forge des réponses aux requêtes DNS d'adresse / pointeur

SYNTAXE

dnsspoof [-i interface] [-f fichier_hotes] [expression]

DESCRIPTION


dnsspoof forge des réponses aux requêtes DNS arbitraires d'adresse / pointeur sur le réseau local (LAN). Ceci est utile pour contourner les contrôles d'accès basés sur les noms d'hôte ou pour implémenter une variété d'attaques de type homme du milieu (man-in-the-middle).

OPTIONS

-i interface
Spécifie l'interface à utiliser.
-f fichier_hotes
Spécifie le chemin d'accès d'un fichier au format hosts(5). Un seul nom d'hôte est autorisé par ligne (pas d'alias), bien que les noms d'hôte puissent contenir des jokers (tels que *.doubleclick.net).
expression
Spécifie une expression de filtre tcpdump(8) pour sélectionner le trafic à écouter.

Si aucun fichier_hotes n'est spécifié, les réponses seront forgées pour toutes les requêtes d'adresse sur le LAN avec comme réponse l'adresse IP de la machine locale.

FICHIERS

/usr/share/dsniff/dnsspoof.hosts
Fichier d'hôtes exemple.

VOIR AUSSI
