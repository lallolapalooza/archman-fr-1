NOM

dnf5-environment - Commande d'environnement

SYNOPSIS

dnf5 environment <sous-commande> [options] [<spécification-environnement>...]

DESCRIPTION

La commande environment dans DNF5 propose plusieurs requêtes pour obtenir des informations sur les environnements et les groupes qui y sont associés. Vous pouvez installer des environnements avec la commande install comme suit : install @id-environnement.

Des arguments optionnels spécification-environnement peuvent être passés pour ne filtrer que les environnements ayant des noms spécifiques.

SOUS-COMMANDES

list
Lister les environnements disponibles.
info
Afficher les détails sur les environnements.

OPTIONS

--available
Afficher uniquement les environnements disponibles. Ceux qui ne sont pas installés, mais que DNF5 connaît.
--installed
Afficher uniquement les environnements installés.

EXEMPLES

dnf5 environment list
Afficher la liste de tous les environnements.
dnf5 environment info "KDE Plasma Workspaces"
Afficher des informations détaillées sur l'environnement KDE.
