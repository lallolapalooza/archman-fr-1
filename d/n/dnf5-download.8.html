NOM

dnf5-download - Commande de téléchargement

SYNTAXE

dnf5 download [options] <spécification-paquet-NPFB>...

DESCRIPTION

La commande download dans DNF5 est utilisée pour télécharger les paquets binaires et sources définis dans les arguments spécification-paquet-NPFB dans le répertoire de travail courant.

OPTIONS

--arch
Limite aux paquets des architectures données. Cette option peut être utilisée plusieurs fois.
--resolve
Résout les dépendances des paquets spécifiés et télécharge ceux qui manquent.
--alldeps
À utiliser conjointement avec --resolve, télécharge toutes les dépendances, sans ignorer celles déjà installées.
--from-repo=ID_REPO,...
Les paquets (ou leurs Provides) explicitement spécifiés sur la ligne de commande ne seront recherchés que dans les dépôts spécifiés.
Ces dépôts sont automatiquement activés.
L'activation et la désactivation des dépôts s'appliquent toujours. Les dépendances de ces paquets seront résolues à partir de tout dépôt activé.
--destdir=<chemin>
Définit le répertoire utilisé pour télécharger les paquets. L'emplacement par défaut est le répertoire de travail courant.
--skip-unavailable
Permet d'ignorer les paquets non disponibles dans les dépôts. Tous les paquets disponibles seront téléchargés.
--srpm
Télécharge le rpm source. Active les dépôts sources de tous les dépôts binaires activés.
--url
Affiche la liste des URL où les rpms peuvent être téléchargés au lieu de les télécharger.
--urlprotocol
À utiliser conjointement avec --url. Filtre les URL pour les protocoles spécifiés : http, https, ftp, ou file. Cette option peut être utilisée plusieurs fois.
--allmirrors
À utiliser conjointement avec --url. Affiche les URL séparées par des espaces de tous les miroirs disponibles pour chaque paquet.

EXEMPLES

dnf5 download kernel-headers-0:5.17.0-300.fc36.i686
Télécharge le paquet kernel-headers en utilisant le format NEVRA complet.
dnf5 download rpm rpm-devel
Télécharge tous les paquets ayant le nom rpm ou rpm-devel.
dnf5 download maven-compiler-plugin --resolve --alldeps
Télécharge le paquet maven-compiler-plugin avec toutes ses dépendances.
dnf5 download --destdir /tmp/mes_paquets maven-compiler-plugin
Télécharge le paquet maven-compiler-plugin dans le répertoire /tmp/mes_paquets.
dnf5 download --url --urlprotocol http python
Affiche l'URL http pour télécharger le paquet python.
dnf5 download python --arch x86_64
Télécharge python avec l'architecture x86_64.
dnf5 download dnf5 --srpm
Télécharge le rpm source dnf5.
