La modification signifie que le nouveau dépôt est ajouté au fichier existant ou qu'un dépôt avec le même identifiant est remplacé dans le fichier. Avant que la nouvelle

setopt [--create-missing-dir] <[identifiant_de_depot.]nom_option=valeur>
+
Définit des options dans le fichier de configuration principal et dans le fichier de substitution de configuration des dépôts.

La configuration principale est d'abord lue à partir des fichiers des répertoires de dépôt (drop-in), puis à partir du fichier de configuration principal (par défaut /etc/dnf/dnf.conf). Ainsi, les options du fichier de configuration principal sont lues en dernier et remplacent les valeurs des mêmes options définies dans les répertoires de

dépôt.

La configuration des dépôts est lue à partir des fichiers de configuration des dépôts puis ajustée à l'aide des substitutions de configuration des dépôts. Les fichiers de substitution de configuration des dépôts sont lus à partir du répertoire de substitution des dépôts de la distribution (/usr/share/dnf5/repos.override.d) et à partir du répertoire de substitution des dépôts du système (/etc/dnf/repos.override.d). Si un fichier avec le même nom est présent dans les deux répertoires de substitution, seul le fichier du répertoire de substitution du système est utilisé. Ainsi, le fichier de substitution de la distribution peut simplement être masqué en créant un fichier avec le même nom dans le répertoire de substitution du système. Tous les fichiers de substitution utilisés sont triés par ordre alphabétique selon leurs noms, puis appliqués dans cet ordre. La substitution du fichier suivant écrase la précédente---la dernière substitution

l'emporte.

La commande setopt écrit les substitutions de configuration des dépôts dans un fichier nommé 99-config_manager.repo situé dans le répertoire de substitution des dépôts du système. Les paramètres des dépôts ne sont écrits que dans ce fichier de substitution. Le fichier de configuration d'origine du dépôt n'est pas modifié. L'identifiant du dépôt peut contenir des jokers (globs). Les fichiers de substitution prennent également en charge les jokers. Mais la commande setopt résout le motif repoid, et les substitutions sont définies pour chaque dépôt correspondant indépendamment. C

ela signifie que les dépôts ajoutés plus tard
ne seront pas affectés par ces substitutions.

La commande unsetopt supprime des options du fichier de configuration principal (par défaut /etc/dnf/dnf.conf). Cependant, les options peuvent toujours être définies dans les fichiers de configuration des répertoires de dépôt (par exemple, la configuration par défaut de la distribution)

La commande unsetopt supprime les substitutions de configuration des dépôts du fichier nommé 99-config_manager.repo situé dans le répertoire de substitution des dépôts du système. Cependant, les substitutions peuvent toujours être définies dans d'autres fichiers de substitution des dépôts (par exemple, les substitutions par défaut de la distribution). Les sections vides sont supprimées du fichier de substitution de configuration. L'identifiant du dépôt peut contenir des jokers.
