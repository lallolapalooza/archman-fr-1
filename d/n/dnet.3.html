DESCRIPTIO

N

dnet fournit une interface simplifiée et portable à plusieurs routines réseau de bas niveau, incluant la manipulation des adresses réseau, la recherche et la manipulation du cache arp(4) et de la table route(4), le filtrage réseau (pare-feu), la recherche et la manipulation des interfaces réseau, ainsi que la transmission brute de paquets IP et de trames Ethernet. Elle est destinée à compléter les fonctionnalités offertes par pcap(

3).

De plus, dnet fournit également des définitions indépendantes de la plateforme pour divers formats et valeurs de protocoles réseau, destinées à la programmation réseau portable de bas niveau, ainsi qu'une API simple de manipulation de tampons

binaires.

Adressage

réseau

Les adresses réseau sont décrites par la structure suivante

: 
struct addr {
	uint16_t		addr_type;
	uint16_t		addr_bits;
	union {
		eth_addr_t	__eth;
		ip_addr_t	__ip;
		ip6_addr_t	__ip6;

		uint8_t		__d
ata8[16]; uint16_t __data16[8]; uint32_t __data32[4]; } __addr_u; }; #define addr_eth __addr_u.__eth #define addr_ip __addr_u.__ip #de
fine addr_ip6 __addr_u.__ip6 #define addr_data8 __addr_u.__data8 #define addr_data16 __addr_u.__data16 #define addr_data32 __addr_u.__data32

Les valeurs suivantes sont définies pour addr_ty

pe : 
#define ADDR_TYPE_NONE		0	/* No address set */
#define	ADDR_TYP
E_ETH 1 /* Ethernet */ #define ADDR_TYPE_IP 2 /* Internet Pro
tocol v4 */ #define ADDR_TYPE_IP6 3 /* Internet Protocol v6 */

Le champ addr_bits indique la longueur du masque réseau en

bits.

addr_cmp() compare les adresses réseau a et b, et renvoie un entier inférieur, égal ou supérieur à zéro si a est, respectivement, pour être inférieur à, égal à, ou supérieur à b. Les deux adresses doivent être du même type d'adresse.

addr_bcast() calcule l'adresse de diffusion pour le réseau spécifié dans a et l'écrit dans b.

addr_net() calcule l'adresse réseau pour le réseau spécifié dans a et l'écrit dans b.

addr_ntop() convertit une adresse du format réseau en chaîne de caractères.

addr_pton() convertit une adresse d'une chaîne de caractères au format réseau.

addr_ntoa() convertit une adresse du format réseau en chaîne de caractères, renvoyant un pointeur vers le résultat dans une mémoire statique.

addr_aton() est un synonyme de addr_pton().

addr_ntos() convertit une adresse du format réseau en la structure sockaddr appropriée.

addr_ston() convertit une adresse d'une structure sockaddr au format réseau.

addr_btos() convertit une longueur de masque réseau en un masque réseau spécifié comme une structure sockaddr.

addr_stob() convertit un masque réseau spécifié dans une structure sockaddr en une longueur de masque réseau.

addr_btom() convertit une longueur de masque réseau en un masque réseau en ordre des octets réseau.

addr_mtob() convertit un masque réseau en ordre des octets réseau en une longueur de masque réseau.

Protocole de résolution d'adresses

Les entrées du cache ARP sont décrites par la structure suivante :

struct arp_entry {
	struct addr	arp_pa;		/* adresse protocole */
	struct addr	arp_ha;		/* adresse matérielle */
};

arp_open() est utilisé pour obtenir un descripteur permettant d'accéder au cache arp(4) du noyau.

arp_add() ajoute une nouvelle entrée ARP.

arp_delete() supprime l'entrée ARP pour l'adresse protocole spécifiée par arp_pa.

arp_get() récupère l'entrée ARP pour l'adresse protocole spécifiée par arp_pa.

arp_loop() itère sur le cache arp(4) du noyau, appelant la callback spécifiée avec chaque entrée et le contexte arg passé à arp_loop().

arp_close() ferme le descripteur spécifié.

Tampons binaires

Les tampons binaires sont décrits par la structure suivante :

typedef struct blob {
	u_char		*base;		/* début des données */
	int		 off;		/* décalage dans les données */
	int		 end;		/* fin des données */
	int		 size;		/* taille de l'allocation */
} blob_t;

blob_new() est utilisé pour allouer un nouveau tampon binaire dynamique, renvoyant NULL en cas d'échec.

blob_read() lit len octets à partir du décalage actuel dans le tampon b vers buf, renvoyant le nombre total d'octets lus, ou -1 en cas d'échec.

blob_write() écrit len octets de buf dans le tampon b, avançant le décalage actuel. Il renvoie le nombre d'octets écrits, ou -1 en cas d'échec.

blob_seek() repositionne le décalage dans le tampon b à off, selon la directive whence (voir lseek(2) pour les détails), renvoyant le nouveau décalage absolu, ou -1 en cas d'échec.

blob_index() renvoie le décalage de la première occurrence dans le tampon b du buflen, ou -1 en cas d'échec.

blob_rindex() renvoie le décalage de la dernière occurrence dans le tampon b du buflen, ou -1 en cas d'échec.

blob_pack() convertit et écrit, et blob_unpack() lit et convertit des données dans le tampon b selon le format donné fmt comme décrit ci-dessous, renvoyant 0 en cas de succès, et -1 en cas d'échec.

La chaîne de format est composée de zéro ou plusieurs directives : caractères ordinaires (pas % ), qui sont copiés vers / lus depuis le tampon, et spécifications de conversion, chacune résultant en la lecture / écriture de zéro ou plusieurs arguments suivants.

Chaque spécification de conversion est introduite par le caractère % , et peut être préfixée par un spécificateur de longueur. Les arguments doivent correspondre correctement (après promotion de type) aux spécificateurs de longueur et de conversion.

Le spécificateur de longueur est soit une chaîne de chiffres décimaux spécifiant la longueur de l'argument suivant, soit le caractère littéral * indiquant que la longueur doit être lue à partir d'un argument entier pour l'argument qui le suit.

Les spécificateurs de conversion et leurs significations sont :

D
Un entier de 32 bits non signé en ordre des octets réseau.
H
Un entier de 16 bits non signé en ordre des octets réseau.
b
Un tampon binaire (spécificateur de longueur requis).
c
Un caractère non signé.
d
Un entier de 32 bits non signé en ordre des octets hôte.
h
Un entier de 16 bits non signé en ordre des octets hôte.
s
Une chaîne C terminée par un caractère nul, dont la longueur maximale doit être spécifiée lors du déballage.

Des routines de conversion personnalisées et leurs spécificateurs peuvent être enregistrés via blob_register_pack(), actuellement non documenté.

blob_print() affiche len octets du contenu du tampon b à partir du décalage actuel dans le style spécifié ; actuellement seul “hexl” est disponible.

blob_free() désalloue la mémoire associée au tampon b et renvoie NULL.

Ethernet

eth_open() est utilisé pour obtenir un descripteur pour transmettre des trames Ethernet brutes via le périphérique réseau spécifié.

eth_get() récupère l'adresse MAC matérielle pour l'interface spécifiée par e.

eth_set() configure l'adresse MAC matérielle pour l'interface spécifiée par e.

eth_send() transmet len octets de la trame Ethernet pointée par buf.

eth_close() ferme le descripteur spécifié.
