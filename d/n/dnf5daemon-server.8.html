NOM

dnf5daemon-server - Service de gestion de paquets avec une interface DBus

SYNOPIS

systemctl start dnf5daemon-server

DESCRIPTION

dnf5daemon-server est l'interface D-Bus pour le gestionnaire de paquets libdnf5.

FICHIERS

Configuration de dnf5daemon-server
/etc/dnf/dnf5daemon-server.conf

Utilisez la section [main] pour remplacer toute option de configuration principale de DNF5. Voir dnf5.conf(5), Options de configuration principales <#conf-main-options-label>.
