NOM

dnssec-revoke - définir le bit REVOKED sur une clé DNSSEC

SYNTAXE

dnssec-revoke [-hr] [-v niveau] [-V] [-K répertoire] [-E moteur] [-f] [-R] {fichier_clé}

DESCRIPTION

dnssec-revoke lit un fichier de clé DNSSEC, définit le bit REVOKED sur la clé tel que défini dans la RFC 5011 https://datatracker.ietf.org/doc/html/rfc5011.html, et crée une nouvelle paire de fichiers de clé contenant la clé maintenant révoquée.

OPTIONS

-h
Cette option affiche un message d'utilisation et quitte.
-K répertoire
Cette option définit le répertoire où doivent se trouver les fichiers de clé.
-r
Cette option indique de supprimer les fichiers de jeu de clés d'origine après avoir écrit les nouveaux fichiers de jeu de clés.
-v niveau
Cette option définit le niveau de débogage.
-V
Cette option affiche les informations de version.
-E moteur
Cette option spécifie le matériel cryptographique à utiliser, le cas échéant.

Lorsque BIND 9 est compilé avec OpenSSL, cela doit être défini sur l'identifiant du moteur OpenSSL qui pilote l'accélérateur cryptographique ou le module de service matériel (généralement pkcs11).

-f
Cette option indique un écrasement forcé et amène dnssec-revoke à écrire la nouvelle paire de clés, même si un fichier existant correspond à l'algorithme et à l'ID de clé de la clé révoquée.
-R
Cette option imprime le tag de clé de la clé avec le bit REVOKE défini, mais ne révoque pas la clé.
