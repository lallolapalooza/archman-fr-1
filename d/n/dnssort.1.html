NOM

dnssort - trier les noms d'hôtes DNS

SYNTAXE

dnssort [-r] [FICHIERS]

DESCRIPTION

Écrit la concaténation triée de tous les fichiers spécifiés sur la sortie standard. Si aucun n'est spécifié, l'entrée standard est utilisée.

OPTIONS

--help
Affiche une aide et quitte.
-r
Inverse les comparaisons de tri.
--version
Affiche la version du programme et la licence, puis quitte.
