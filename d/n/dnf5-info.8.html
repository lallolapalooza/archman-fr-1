NOM

dnf5-info - Commande d'information

SYNTAXE

dnf5 info [options] [<spécification-paquet-NI>...]

DESCRIPTION

Affiche des informations détaillées sur les paquets en fonction des paramètres fournis.

OPTIONS

--showduplicates
Affiche toutes les versions des paquets, pas seulement la plus récente.
--installed-from-repo=ID_DEPOT,...
Filtre les paquets installés par l'ID du dépôt à partir duquel ils ont été installés.
--installed
Liste uniquement les paquets installés.
--available
Liste uniquement les paquets disponibles.
--extras
Liste uniquement les extras : paquets installés sur le système qui ne sont disponibles dans aucun dépôt connu.
--obsoletes
Liste uniquement les paquets installés sur le système qui sont obsolètes par des paquets dans n'importe quel dépôt connu.
--recent
Liste uniquement les paquets récemment ajoutés aux dépôts.
--upgrades
Liste uniquement les mises à jour disponibles pour les paquets installés.
--autoremove
Liste uniquement les paquets qui seront supprimés par la commande autoremove <#autoremove-command-ref-label>.

EXEMPLES

dnf5 info
Affiche des informations détaillées sur les paquets installés et disponibles.
dnf5 info --recent gnome*
Affiche des informations sur les paquets récents dont le nom commence par gnome.
