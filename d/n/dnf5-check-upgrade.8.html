NOM

dnf5-check-upgrade - Commande Check-Upgrade

SYNTAXE

dnf5 check-upgrade [options] [<spécification-paquet-N>...]

DESCRIPTION

Vérifie de manière non interactive les mises à jour disponibles pour les paquets spécifiés. Si aucun <spécification-paquet-N> n'est fourni, il vérifie les mises à jour pour l'ensemble du système.

DNF5 se terminera avec le code 100` si des mises à jour sont disponibles et les listera ; 0 si aucune mise à jour n'est disponible.

OPTIONS

--changelogs
Affiche les journaux de modification des paquets.
--advisories=NOM_ANNONCE,...
Inclut le contenu des annonces portant les noms spécifiés.
C'est une option de liste.
Les valeurs attendues sont des identifiants d'annonce, par exemple FEDORA-2201-123.
Toute commande de transaction (installation, mise à niveau) échouera avec une erreur s'il n'y a pas d'annonce existante dans la liste ; ceci peut être contourné en utilisant l'option --skip-unavailable.
--advisory-severities=GRAVITE_ANNONCE,...
Inclut le contenu des annonces ayant la gravité spécifiée.
C'est une option de liste.
Les valeurs acceptées sont : critical, important, moderate, low, none.
--bzs=ID_BUGZILLA,...
Inclut le contenu des annonces qui corrigent un ticket de l'ID Bugzilla donné.
C'est une option de liste.
Les valeurs attendues sont des identifiants numériques, par exemple 123123.
Toute commande de transaction (installation, mise à niveau) échouera avec une erreur s'il n'y a pas d'annonce corrigeant le ticket donné ; ceci peut être contourné en utilisant l'option --skip-unavailable.
--cves=ID_CVE,...
Inclut le contenu des annonces qui corrigent un ticket de l'ID CVE (Common Vulnerabilities and Exposures) donné.
C'est une option de liste.
Les valeurs attendues sont des identifiants de chaîne au format CVE, par exemple CVE-2201-0123.
Toute commande de transaction (installation, mise à niveau) échouera avec une erreur s'il n'y a pas d'annonce corrigeant le ticket donné ; ceci peut être contourné en utilisant l'option --skip-unavailable.
--security
Inclut le contenu des annonces de sécurité.
--bugfix
Inclut le contenu des annonces de correction de bugs.
--enhancement
Inclut le contenu des annonces d'amélioration.
--newpackage
Inclut le contenu des annonces de nouveaux paquets.
--minimal
Rapporte les versions les plus basses des paquets qui corrigent les annonces de type correction de bug, amélioration, sécurité ou nouveau paquet. Si une option limitant les annonces est utilisée, elle rapporte les versions les plus basses des paquets qui corrigent les annonces correspondant aux propriétés d'annonce sélectionnées."

EXEMPLES

dnf5 check-upgrade
Affiche une liste des paquets pour lesquels des mises à jour sont disponibles.
dnf5 check-upgrade --changelogs
Affiche les journaux de modification pour tous les paquets ayant des mises à jour en attente.
