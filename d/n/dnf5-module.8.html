NOM

dnf5-module - Commande de module

SYNTAXE

dnf5 module <sous-commande> [options] [<spécification-module>...]

DESCRIPTION

La modularité est une autre façon de construire, d'organiser et de livrer des paquets.

Actuellement, seul un support de base est disponible pour la gestion des modules, car ils ne sont plus pris en charge dans les distributions RPM grand public.

Pour plus de détails, voir : https://docs.pagure.org/modularity/.

SOUS-COMMANDES

list
Liste les flux de modules. Les options --enabled et --disabled
     affinent la liste demandée.
info
Affiche les détails sur les flux de modules.
enable
Active les flux de modules et rend leurs paquets disponibles.
disable
Désactive les modules, y compris tous leurs flux.
reset
Réinitialise l'état du module afin qu'il ne soit plus activé ni désactivé.

OPTIONS POUR LIST ET INFO

--enabled
N'affiche que les modules activés.
--disabled
N'affiche que les modules désactivés.

OPTIONS POUR ENABLE, DISABLE, RESET

--skip-broken
Résout les problèmes de dépendance en supprimant les éléments qui causent
     des problèmes de la transaction.
     Utilisé avec la commande enable.
--skip-unavailable
Permet de sauter les modules qui ne sont pas disponibles dans les dépôts.
     Tous les éléments restants seront traités.

EXEMPLES

dnf5 module list
Liste tous les flux de modules disponibles pour votre système.
dnf5 module enable nodejs:8
Rend les paquets du flux Node.js 8 disponibles pour l'installation.
