NOM

dnf5-copr - Commande Copr

SYNTAXE

dnf5 copr <sous-commande> [options] [arguments]

DESCRIPTION

La commande copr dans DNF5 est utilisée pour gérer les dépôts Copr (modules complémentaires fournis par les utilisateurs/la communauté/des tiers) sur le système local.

SOUS-COMMANDES

list
Lister les dépôts Copr.
enable <project-spec> [<chroot>]
Télécharger les informations du dépôt depuis un serveur Copr et l'installer en tant que fichier
    /etc/yum.repos.d/*.repo.
disable <project-spec>
Désactiver le dépôt Copr spécifié (s'il existe), conserver le fichier
    /etc/yum.repos.d/*.repo - définir simplement enabled=0.
remove <project-spec>
Supprimer le dépôt Copr spécifié du système. Supprime également le fichier
    /etc/yum.repos.d/*.repo.
debug
Afficher les informations utiles pour le débogage du système.

OPTIONS

--hub
Nom d'hôte du hub Copr (serveur d'interface web/API). Par défaut copr.fedorainfracloud.org.

ARGUMENTS

<project-spec>
Identifiant du projet Copr à activer. Utiliser soit le format PROPRIÉTAIRE/PROJET, soit HUB/PROPRIÉTAIRE/PROJET.

HUB peut être soit le nom d'hôte du frontend Copr (par exemple copr.fedorainfracloud.org), soit un raccourci (par exemple fedora). Si HUB n'est pas spécifié, celui par défaut, ou celui spécifié par --hub <ARG>, est utilisé.

PROPRIÉTAIRE est soit un nom d'utilisateur, soit un @nomdegroupe.

PROJET peut être un nom de projet simple, ou un "répertoire de projet" contenant des deux-points, par exemple projet:personnalisé:123.

Exemple : fedora/@footeam/coolproject.

<chroot>
Chroot spécifié au format NOM-RELEASE-ARCH, par exemple fedora-rawhide-ppc64le. Lorsqu'il n'est pas spécifié, la commande dnf copr tente de le détecter.

EXEMPLES

dnf5 copr enable rhscl/perl516 epel-6-x86_64
Activer le dépôt Copr rhscl/perl516, en utilisant le chroot epel-6-x86_64.
dnf5 copr disable rhscl/perl516
Désactiver le dépôt Copr rhscl/perl516
dnf5 copr list
Lister les dépôts Copr configurés sur le système.
