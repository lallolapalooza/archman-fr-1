dnf5.conf-todo - Options documentées/implémentées dans DNF mais pas dans DNF5

DNF5 a certaines options qui ne sont pas encore implémentées ou documentées. Cette section marque les options de configuration manquantes. Certaines options peuvent être dupliquées dans la Référence de configuration DNF5 <#dnf5-conf-label>. En cas de doublons, cette section doit être considérée comme invalide et l'option comme implémentée et documentée. Si vous trouvez un problème, veuillez ouvrir un ticket sur https://github.com/rpm-software-management/dnf5/issues.

Cette section ne suit aucune option obsolète. Pour ces options, voir Options de configuration obsolètes <#dnf5-conf-deprecated-label>

autocheck_running_kernel
booléen <#boolean-label>

Vérification automatique s'il existe un module noyau plus récent installé avec une mise à jour de sécurité que le noyau actuellement en cours d'exécution.

Par défaut : True.

debuglevel
entier <#integer-label>

Niveau de sortie des messages de débogage, dans la plage 0 à 10. Plus le nombre est élevé, plus la sortie de débogage est importante sur la sortie standard.

Par défaut : 2.

diskspacecheck
booléen <#boolean-label>

Si activé, contrôle si rpm doit vérifier l'espace disque disponible pendant la transaction.

Par défaut : True.

exit_on_lock
booléen <#boolean-label>

Si activé, DNF5 se terminera immédiatement lorsque quelque chose d'autre détient le verrou.

Par défaut : False.

gpgkey_dns_verification
booléen <#boolean-label>

Si activé, DNF5 tentera de vérifier automatiquement les clés de vérification OpenPGP en utilisant le système DNS.

Cette option nécessite que le module python unbound (python3-unbound) soit installé sur le système client. Ce système a deux fonctionnalités principales. La première est de vérifier si les clés déjà installées ont été révoquées. La suppression automatique de la clé n'est pas encore disponible, c'est donc à l'utilisateur de supprimer les clés révoquées du système. La seconde fonctionnalité est la vérification automatique des nouvelles clés lorsqu'un dépôt est ajouté au système. En mode interactif, le résultat est écrit dans la sortie comme une suggestion à l'utilisateur. En mode non interactif (c'est-à-dire lorsque -y est utilisé), ce système acceptera automatiquement les clés disponibles dans le DNS et correctement signées à l'aide de DNSSEC. Il acceptera également les clés qui n'existent pas dans le système DNS et dont la NON-existence est prouvée cryptographiquement à l'aide de DNSSEC. Ceci est principalement destiné à préserver la compatibilité descendante.

Par défaut : False.

module_obsoletes
booléen <#boolean-label>

Si activé, DNF5 tente d'appliquer les obsolescences modulaires lorsque c'est possible.

Par défaut : False.

rpmverbosity
chaîne <#string-label>

Niveau de sortie de débogage des scriptslets RPM. L'une des valeurs suivantes : critical, emergency, error, warn, info ou debug.

Par défaut : info.

upgrade_group_objects_upgrade
booléen <#boolean-label>

Si activé, effectue l'exécution automatique de la mise à niveau de groupe lors de l'exécution de la commande upgrade.

Par défaut : True.

color
chaîne <#string-label>

Contrôle si DNF5 utilise une sortie colorée sur la ligne de commande. Valeurs possibles : auto, never, always.

Par défaut : auto.

color_list_installed_older
couleur <#color-label>

Couleur des paquets installés plus anciens que n'importe quelle version parmi les paquets disponibles. L'option est utilisée lors des opérations de liste.

Par défaut : yellow.

color_list_installed_newer
couleur <#color-label>

Couleur des paquets installés plus récents que n'importe quelle version parmi les paquets disponibles. L'option est utilisée lors des opérations de liste.

Par défaut : bold,yellow.

color_list_installed_reinstall
couleur <#color-label>

Couleur des paquets installés qui font partie des paquets disponibles et peuvent être réinstallés. L'option est utilisée lors des opérations de liste.

Par défaut : dim,cyan.

color_list_installed_extra
couleur <#color-label>

Couleur des paquets installés qui n'ont aucune version parmi les paquets disponibles. L'option est utilisée lors des opérations de liste.

Par défaut : bold,red.
