NOM

DNSSEC-Tools - Une suite d'outils et de bibliothèques pour utiliser DNSSEC

DESCRIPTION

Le paquet DNSSEC-Tools contient une grande variété d'outils utiles aux opérateurs de zones, aux opérateurs de résolveurs, aux opérateurs réseau, aux développeurs d'applications et aux utilisateurs finaux de DNSSEC.

Le meilleur endroit pour en apprendre davantage sur les outils qui font partie du paquet est le site web suivant, qui classe les outils selon le public visé :

http://www.dnssec-tools.org/wiki/index.php/DNSSEC-Tools_Components

De plus, assurez-vous de consulter les tutoriels disponibles à l'adresse suivante :

http://www.dnssec-tools.org/wiki/index.php/Tutorials

LICENCE

Les DNSSEC-Tools sont distribués sous licence BSD, dont les détails peuvent être trouvés dans le fichier COPYING présent dans la distribution.
