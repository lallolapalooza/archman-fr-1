NOM

dnf5-remove - Commande de suppression

SYNTAXE

dnf5 remove [options] <spécification-paquet-NF>|@<spécification-groupe>|@<spécification-environnement>...

DESCRIPTION

La commande remove dans DNF5 est utilisée pour supprimer des paquets, groupes ou environnements installés du système.

Si vous souhaitez conserver les dépendances qui ont été installées avec le paquet donné, définissez l'option de configuration clean_requirements_on_remove sur False.

OPTIONS

--installed-from-repo=REPO_ID,...
Filtre les paquets installés par l'identifiant du dépôt à partir duquel ils ont été installés.
--no-autoremove
Désactive la suppression des dépendances qui ne sont plus utilisées.
--offline
Stocke la transaction à effectuer hors ligne. Voir la commande offline <#ref-commande-offline>, dnf5-offline(8).
--store=CHEMIN
Stocke la transaction actuelle dans un répertoire au CHEMIN spécifié au lieu de l'exécuter.
La transaction stockée peut être effectuée par la commande replay <#ref-commande-replay>, dnf5-replay(8).

EXEMPLES

dnf5 remove tito
Supprime le paquet tito.
