dnsget(1) Manuel des commandes générales dnsget(1)

NOM

dnsget - utilitaire de requête DNS

SYNTAXE

dnsget [-v|-q] [-c classe] [-t type] [-o opt,opt,...] nom...

DESCRIPTION

dnsget est une commande simple pour effectuer des requêtes DNS, similaire à host(1) et dig(1). Il est utilisable aussi bien pour des scénarios interactifs/de débogage que dans des scripts. Le programme est implémenté en utilisant la bibliothèque udns(3).

Par défaut, dnsget produit une sortie lisible par l'homme, similaire à

alias.example.com. CNAME www.example.com.
www.example.com. A 192.168.1.1
www.example.com. MX 10 mx.example.com.
ce qui est suffisant pour voir comment un nom donné se résout. Le format de sortie est contrôlable avec les options -v et -q -- la première augmente le niveau de verbosité jusqu'à imprimer le contenu DNS complet de tous les paquets envoyés et reçus, ce qui est adapté au débogage des problèmes DNS, tandis que la seconde réduit le niveau, rendant la sortie plus silencieuse, jusqu'au résultat brut sans messages d'erreur, ce qui est bon pour les scripts.

OPTIONS

Les options suivantes sont reconnues par dnsget :

-v
produit une sortie plus détaillée. Plus il y a de -v, plus les détails produits sont nombreux. Avec un seul -v,dnsget affichera le contenu de tous les paquets DNS reçus (sous forme lisible), tandis qu'avec -vv, il affichera également tous les paquets DNS sortants.
-q
l'inverse de -v -- produit une sortie moins détaillée. Avec un seul -q,dnsget n'affichera que les données (décodées) des enregistrements de ressources (RR) DNS finaux, tandis que -qq supprimera également les messages d'erreur.
-t type
demande le(s) enregistrement(s) du type type donné. Par défaut, dnsget demandera un enregistrement d'adresse IPv4 (A), ou un enregistrement PTR si l'argument en question est une adresse IPv4 ou IPv6. Les types reconnus incluent A, AAAA, MX, TXT, CNAME, PTR, NS, SOA, ANY et d'autres.
-c classe
demande le(s) enregistrement(s) DNS de la classe classe donnée. Par défaut, dnsget utilise la classe IN. Les classes valides incluent IN, CH, HS, ANY.
-a
(option de compatibilité). Équivalent à définir le type de requête sur ANY et à augmenter le niveau de verbosité (-v).
-C
(prévu)
-x
(prévu)
-o opt,opt,...
(peut être spécifié plusieurs fois). Définit les options du résolveur (sous la forme option:valeur) comme s'ils étaient définis dans la variable d'environnement $RES_OPTIONS, ou définit des indicateurs de requête :
timeout:sec
Définit le délai d'attente initial de la requête à sec.
attempts:num
réessaie chaque requête num fois avant d'échouer.
udpbuf:octets
définit la taille du tampon UDP DNS à octets octets. Les valeurs valides vont de 512 à 65535. Si octets est supérieur à 512, les extensions EDNS0 (RFC 2671) seront utilisées.
port:num
Utilise le numéro de port UDP donné num au lieu du port par défaut 53 (domain).
aa
définit le bit de requête AA (authentification seulement).
nord
ne définit pas le bit de requête RD (récursion désirée) (défini par défaut).
dnssec ou do
définit l'indicateur de requête DNSSEC OK (DO) (dnsget ne vérifie pas les signatures DNSSEC, il les affiche seulement; ceci est défini dans le RR EDNS).
cd
définit le bit de requête CD (vérification désactivée).
-n serveur_de_noms
Utilise le(s) serveur(s) de noms donné(s) (peut être spécifié plusieurs fois) au lieu de celui par défaut. L'utilisation de cette option a le même effet que les variables d'environnement $NSCACHEIP ou $NAMESERVERS, à la seule différence que seules les adresses IPv4 sont reconnues pour l'instant, et qu'il est possible de spécifier des noms (qui seront résolus en utilisant les paramètres par défaut) au lieu d'adresses IP.
-h
affiche une aide courte et quitte.

VALEUR DE RETOUR

Lorsque tous les noms ont été résolus avec succès, dnsget se termine avec un statut de sortie zéro. Si au moins un nom n'a pas été trouvé, dnsget se terminera avec le code de retour 100. Si une autre erreur s'est produite lors de la résolution du nom, il se terminera avec le code 99. En cas d'erreur d'utilisation ou d'initialisation, dnsget retournera 1.

VOIR AUSSI

host(1) dig(1) resolv.conf(5) udns(3).
