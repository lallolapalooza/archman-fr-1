NOM

dnf5-check - Commande de vérification

SYNTAXE

dnf5 check [options]

DESCRIPTION

Vérifie la base de données de paquets locale et produit des informations sur tous les problèmes rencontrés. L'ensemble des vérifications effectuées peut être spécifié avec des options.

OPTIONS

--dependencies
Affiche les dépendances manquantes et les conflits.
--duplicates
Affiche les paquets dupliqués.
--obsoleted
Affiche les paquets obsolètes.

EXEMPLES

dnf5 check
Affiche tous les problèmes.
dnf5 check --dependencies --obsoleted
Affiche les dépendances manquantes, les conflits et les paquets obsolètes.
