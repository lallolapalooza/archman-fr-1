NOM

dnf5-system-state - État du système

DESCRIPTION

L'état du système DNF5 se compose de plusieurs fichiers TOML dont l'emplacement est déterminé par l'option de configuration system_state_dir (dnf5.conf(5), system_state_dir <#system-state-dir-options-label>). DNF5 utilise l'état du système pour :

1.
Stocker les raisons pour lesquelles chaque paquet installé a été ajouté au système. Les raisons peuvent être « user » pour les paquets que l'utilisateur a explicitement demandé à DNF5 d'installer, « dependency » et « weak dependency » pour les paquets tirés comme dépendances d'un autre paquet, « group » pour les paquets installés par un groupe, ou « external » pour les paquets installés par un autre outil (par exemple, rpm).
2.
Suivre les groupes installés et les paquets installés par ces groupes.
3.
Suivre les groupes environnementaux installés.

La manière de stocker l'état du système DNF5 est un détail d'implémentation interne et peut changer à tout moment. Pour modifier l'état, utilisez toujours l'interface en ligne de commande DNF5 ou l'API DNF5.

RÉCUPÉRATION D'UN ÉTAT DE SYSTÈME CORROMPU

Si les fichiers d'état du système sont corrompus, sauvegardez et supprimez simplement le fichier TOML corrompu mentionné dans le message d'erreur. Il sera régénéré lors de la prochaine transaction DNF5 réussie. Les fichiers régénérés peuvent manquer de certaines données, telles que les raisons pour lesquelles les paquets ont été installés ou les dépôts à partir desquels ils ont été installés.
