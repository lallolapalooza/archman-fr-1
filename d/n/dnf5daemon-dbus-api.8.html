Remarque : Bien que la plupart des méthodes suivantes puissent être appelées avec succès par un utilisateur normal, une authentification par un utilisateur administratif est requise pour certaines d'entre elles (par ex. Goal.do_transaction(), Repo.confirm_key(), Repo.enable(), Repo.disable()). Cette authentification est gérée en appelant la méthode CheckAuthorization() de l'interface D-Bus Polkit org.freedesktop.PolicyKit1.Authority. Le drapeau AllowUserInteraction est défini pour cet appel, indiquant que si un agent d'authentification est disponible, l'appel est bloqué pendant

que l'utilisateur est invité à s'authentifier. Un délai d'attente codé
en dur de 2 minutes est défini pour l'interaction avec l'utilisateur.

interface org.rpm.dnf.v0.rpm.Rpm
méthode list(a{sv} options) -> (aa{sv} packages)
Arguments
•
options (a{sv}) -- un tableau de paires clé/valeur
Retourne
•
packages (aa{sv}) -- tableau de paquets renvoyés avec les attributs demandés

Obtient la liste des paquets qui correspondent aux filtres donnés. Comme la méthode renvoie les paquets directement dans le message de réponse de la méthode D-Bus, qui a une taille limitée, il est possible que la taille de l'ensemble de paquets demandé dépasse cette limite. Si vous demandez un grand nombre de paquets et/ou un grand nombre d'attributs de paquet, veuillez envisager d'utiliser la méthode list_fd().

Les options et filtres suivants sont pris en charge :

•
package_attrs : liste de chaînes
liste des attributs de paquet renvoyés. Les attributs pris en charge sont name, epoch, version, release, arch, repo_id, from_repo_id, is_installed, install_size, download_size, buildtime, sourcerpm, summary, url, license, description, files, changelogs, provides, requires, requires_pre, conflicts, obsoletes, recommends, suggests, enhances, supplements, evr, nevra, full_nevra, reason, vendor, group.
•
with_nevra : bool (par défaut true)
correspond aux modèles par rapport aux NEVRA des paquets disponibles
•
with_provides : bool (par défaut true)
correspond aux modèles par rapport aux provides des paquets disponibles
•
with_filenames : bool (par défaut true)
correspond aux modèles par rapport aux noms des fichiers dans les paquets disponibles
•
with_binaries : bool (par défaut true)
correspond aux modèles par rapport aux noms des binaires dans /usr/(s)bin des paquets disponibles
•
with_src : bool (par défaut true)
inclut les paquets sources dans les résultats
•
icase : bool (par défaut true)
ignore la casse lors de la mise en correspondance des modèles
•
patterns : liste de chaînes
tout paquet correspondant à l'un des modèles est renvoyé
•
scope : chaîne (par défaut "all")
limite les paquets à l'un des : "all", "installed", "available", "upgrades", "upgradable"
•
arch : liste de chaînes
limite l'ensemble résultant aux paquets des architectures données
•
repo : liste de chaînes
limite l'ensemble résultant aux paquets des dépôts donnés
•
latest-limit : int
limite l'ensemble résultant à seulement <limit> des paquets les plus récents pour chaque nom et architecture
•
whatprovides : liste de chaînes
limite l'ensemble résultant aux paquets qui fournissent des capacités données
•
whatdepends : liste de chaînes
limite l'ensemble résultant aux paquets qui requièrent, améliorent, recommandent, suggèrent ou complètent des capacités données
•
whatrequires : liste de chaînes
limite l'ensemble résultant aux paquets qui requièrent des capacités données
•
whatrecommends : liste de chaînes
limite l'ensemble résultant aux paquets qui recommandent des capacités données
•
whatenhances : liste de chaînes
limite l'ensemble résultant aux paquets qui améliorent des capacités données
•
whatsuggests : liste de chaînes
limite l'ensemble résultant aux paquets qui suggèrent des capacités données
•
whatsupplements : liste de chaînes
limite l'ensemble résultant aux paquets qui complètent des capacités données
•
whatobsoletes : liste de chaînes
limite l'ensemble résultant aux paquets qui obsolètent des capacités données
•
whatconflicts : liste de chaînes
limite l'ensemble résultant aux paquets qui entrent en conflit avec des capacités données

Les options inconnues sont ignorées.

Le serveur a un délai d'attente de 30 secondes pendant lequel il attend que le client lise les données

interface org.rpm.dnf.v0.History
méthode recent_changes(a{sv} options) -> (a{saa{sv}} changeset)
Arguments
•
options (a{sv}) -- un tableau de paires clé/valeur
Retourne
•
changeset (a{saa{sv}}) -- un dictionnaire {"<type_de_changement>":[<paquet>,<paquet>,...]}

Obtient une liste des paquets qui ont été récemment modifiés. La clé « type_de_changement » dans le dictionnaire de sortie peut être l'une des suivantes : « installed », « removed », « upgraded » ou « downgraded ». Les paquets dans la sortie sont représentés comme des dictionnaires contenant l'ensemble des attributs demandés pour les paquets modifiés.

Pour les paquets installés, mis à niveau et rétrogradés, la version actuellement installée est retournée.

Pour les paquets mis à niveau et rétrogradés, l'attribut « original_evr » est également inclus, contenant l'EVR du paquet avant le changement.

Si demandé, les paquets mis à niveau peuvent également inclure un champ de liste « advisories », indiquant le nom des mises à jour qui contiennent la version mise à niveau (c'est-à-dire actuellement installée) du paquet. Si l'option « all_advisories » est définie, les avis pour toutes les versions entre la version originale et la version actuellement installée sont également inclus.

Pour les paquets supprimés, seuls le nom, l'architecture et l'EVR de la version supprimée sont fournis.

Les options et filtres suivants sont pris en charge :

•
upgraded_packages : booléen, par défaut « true »
Indique s'il faut inclure les paquets mis à niveau dans la sortie.
•
downgraded_packages : booléen, par défaut « true »
Indique s'il faut inclure les paquets rétrogradés dans la sortie.
•
installed_packages : booléen, par défaut « true »
Indique s'il faut inclure les paquets installés dans la sortie.
•
removed_packages : booléen, par défaut « true »
Indique s'il faut inclure les paquets supprimés dans la sortie.
•
include_advisory : booléen, par défaut « true »
Indique s'il faut inclure des « avis » dans les attributs des paquets mis à niveau.
•
all_advisories : booléen, par défaut « false »
N'a de sens que si include_advisory=true. Inclut également les avis pour toutes les versions entre l'originale et celle actuellement installée.
•
package_attrs : liste de chaînes, par défaut ["name", "summary", "evr", "arch"]
Liste des attributs de paquet qui sont retournés pour chaque paquet modifié. Les attributs pris en charge sont les mêmes que dans la méthode list() de l'interface Rpm.
