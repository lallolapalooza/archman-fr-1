NOM

dnf5-list - Commande de liste

SYNOPIS

dnf5 list [options] [<spécification-paquet-NI>...]

DESCRIPTION

Affiche des listes de paquets basées sur les paramètres fournis.

OPTIONS

--showduplicates
Affiche toutes les versions des paquets, pas seulement la dernière.
--installed-from-repo=REPO_ID,...
Filtre les paquets installés par l'ID du dépôt à partir duquel ils ont été installés.
--installed
Liste uniquement les paquets installés.
--available
Liste uniquement les paquets disponibles.
--extras
Liste uniquement les extras : paquets installés sur le système qui ne sont disponibles dans aucun dépôt connu.
--obsoletes
Liste uniquement les paquets installés sur le système qui sont obsolètes par des paquets de tout dépôt connu.
--recent
Liste uniquement les paquets récemment ajoutés aux dépôts.
--upgrades
Liste uniquement les mises à niveau disponibles pour les paquets installés.
--autoremove
Liste uniquement les paquets qui seront supprimés par la commande autoremove <#autoremove-command-ref-label>.

EXEMPLES

dnf5 list
Liste les paquets installés et disponibles.
dnf5 list --available --showduplicates
Liste tous les paquets disponibles, y compris toutes les versions disponibles.
dnf5 list kernel*
Liste les paquets installés et disponibles dont les noms commencent par kernel.
