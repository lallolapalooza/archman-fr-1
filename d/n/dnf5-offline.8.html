NOM

dnf5-offline - Commande hors ligne

SYNTAXE

dnf5 offline <sous-commande> [options]

DESCRIPTION

La commande offline est utilisée pour gérer les transactions « hors ligne »---transactions qui s'exécutent lors du démarrage du système dans un environnement minimal. L'exécution d'une transaction dans cet environnement réduit peut être plus sûre que de l'exécuter lorsque le système est démarré normalement, car la transaction est moins susceptible d'interférer avec les processus en cours.

Les transactions hors ligne peuvent être initiées en spécifiant le drapeau --offline sur n'importe quelle opération (install, upgrade, distro-sync, etc.), ou via dnf5 system-upgrade download. Une fois qu'une transaction hors ligne est initiée, exécutez dnf5 offline reboot pour redémarrer et commencer la transaction.

Les données des transactions hors ligne sont stockées dans le répertoire « état du système » à l'adresse /usr/lib/sysimage/libdnf5/offline.

SOUS-COMMANDES

clean
Supprime toute transaction hors ligne stockée et efface les fichiers de paquets mis en cache.
log
Permet de voir une liste des démarrages pendant lesquels une transaction hors ligne a été tentée, ou d'afficher les journaux d'une transaction hors ligne tentée. Les journaux d'un des démarrages peuvent être affichés en spécifiant l'un des numéros de la première colonne avec l'argument --number. Les nombres négatifs peuvent être utilisés pour numéroter les démarrages du dernier au premier. Par exemple, log --number=-1 peut être utilisé pour voir les journaux de la dernière transaction hors ligne.
reboot
Prépare le système à effectuer la transaction hors ligne et redémarre pour lancer la transaction. Cette commande ne peut être exécutée qu'après l'initiation d'une transaction hors ligne (par exemple, via dnf5 system-upgrade download).
status
Affiche l'état de la transaction hors ligne actuelle.
_execute
Exécute la transaction dans l'environnement hors ligne.

Attention :

À usage interne uniquement. N'est pas destiné à être exécuté par l'utilisateur.

OPTIONS

--number=<numéro de démarrage>
Affiche le journal spécifié par le numéro. Exécutez dnf5 offline log avec --number d'abord pour obtenir une liste de journaux parmi lesquels choisir.
Utilisé avec la sous-commande log.
--poweroff
Le système s'éteindra après la fin de la transaction au lieu de redémarrer. Si la transaction a échoué, le système redémarrera au lieu de s'éteindre même avec ce drapeau.
Utilisé avec la sous-commande reboot.

ENVIRONNEMENT

DNF_SYSTEM_UPGRADE_NO_REBOOT
S'il est défini, le système ne sera pas redémarré ou éteint par DNF5 lorsque le flux de travail normal le ferait.

EXEMPLES

dnf5 install --offline hello
Prépare l'installation du paquet hello comme une transaction hors ligne.
dnf5 offline status
Affiche l'état de la transaction hors ligne actuelle.
dnf5 offline reboot --poweroff
Redémarre et exécute la transaction hors ligne, puis éteint le système après la fin de la transaction.
dnf5 offline log
Liste les démarrages pendant lesquels une transaction hors ligne a été tentée.
dnf5 offline log --number=-1
Affiche le journal du dernier démarrage pendant lequel une transaction hors ligne a été tentée.
