NOM

dnf5-downgrade - Commande de rétrogradation

SYNOPSIS

dnf5 downgrade [options] <spec-paquet-NPFB>...

DESCRIPTION

La commande downgrade de DNF5 est utilisée pour rétrograder chaque paquet spécifié dans la liste spec-paquet-NPFB vers la version la plus élevée installable parmi toutes les versions inférieures connues, si possible. Lorsque la version est explicitement donnée dans l'argument et qu'elle est inférieure à la version du paquet installé, elle rétrograde vers celle-ci.

OPTIONS

--allowerasing
Permet la suppression de paquets installés pour résoudre d'éventuels problèmes de dépendances.
--skip-broken
Résout les problèmes de dépendances en supprimant les paquets qui causent des problèmes de la transaction.
--skip-unavailable
Permet d'ignorer les paquets qu'il n'est pas possible de rétrograder. Tous les paquets restants seront rétrogradés.
--allow-downgrade
Active la rétrogradation des dépendances lors de la résolution de l'opération demandée.
--no-allow-downgrade
Désactive la rétrogradation des dépendances lors de la résolution de l'opération demandée.
--installed-from-repo=ID_REPO,...
Filtre les paquets installés par l'ID du dépôt à partir duquel ils ont été installés.
--from-repo=ID_REPO,...
Les paquets (ou leurs fournitures) spécifiés explicitement sur la ligne de commande ne seront recherchés que dans les dépôts spécifiés.
Ces dépôts sont activés automatiquement.
L'activation et la désactivation des dépôts s'appliquent toujours. Les dépendances de ces paquets seront résolues à partir de n'importe quel dépôt activé.
--downloadonly
Télécharge l'ensemble des paquets résolus sans exécuter de transaction RPM.
--offline
Stocke la transaction à effectuer hors ligne. Voir la commande offline <#offline-command-ref-label>, dnf5-offline(8).
--store=CHEMIN
Stocke la transaction actuelle dans un répertoire au CHEMIN spécifié au lieu de l'exécuter.
La transaction stockée peut être effectuée par la commande replay <#replay-command-ref-label>, dnf5-replay(8).

EXEMPLES

dnf5 downgrade nano-0:6.0-2.fc36
Rétrograder le paquet nano vers la version donnée.
dnf5 downgrade gcc glibc --allowerasing
Rétrograder les paquets gcc, glibc et autoriser la suppression de paquets installés si nécessaire.
