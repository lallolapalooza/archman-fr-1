NOM

dnf5-forcearch - Paramètre Forcearch

DESCRIPTION

Le paramètre --forcearch=<arch> remplace l'architecture système détectée par DNF 5. Il permet d'interroger les dépôts pour des paquets non compatibles avec votre système hôte et de les installer. N'importe quelle architecture peut être spécifiée, mais l'utilisation d'un paquet avec une architecture non supportée nativement par votre CPU nécessitera une émulation d'une sorte, par exemple en utilisant qemu-user-static.

--forcearch est supporté par les commandes suivantes : distro-sync, download, group, info, install, list, makecache, repo, repoquery, search et swap.

EXEMPLES

dnf5 install --forcearch=aarch64 mon-paquet-exemple
Installe la version de mon-paquet-exemple pour l'architecture AArch64, quel que soit l'architecture du système hôte.
dnf5 download --forcearch=s390x hello
Télécharge le paquet hello pour l'architecture s390x.
dnf5 repoquery --forcearch=aarch64 --arch=aarch64
Interroge tous les paquets disponibles pour l'architecture AArch64. Si votre système a une architecture native différente, alors --arch et --forcearch sont tous deux nécessaires ici. --arch filtrera pour uniquement les paquets avec l'architecture aarch64, et --forcearch définira les variables de substitution « arch » et « basearch » pour garantir que les bons dépôts sont interrogés.
