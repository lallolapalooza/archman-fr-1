NOM

dnstcpbench - outil pour effectuer des benchmarks TCP de serveurs de noms

SYNTAXE

dnstcpbench [OPTION]... ADRESSE-DISTANTE [PORT-DISTANT]

DESCRIPTION

dnstcpbench lit des requêtes DNS (par défaut depuis l'entrée standard) et les envoie en parallèle à un serveur de noms distant. Par défaut, TCP/IP est utilisé, mais optionnellement, UDP est essayé en premier, ce qui permet le benchmarking du repli TCP/IP.

Le programme rapporte à la fois les moyennes et les médianes des requêtes par seconde ainsi que les latences UDP et TCP. Chaque requête ne compte qu'une seule fois, même si elle est d'abord essayée sur UDP. Cela signifie effectivement que l'option '-u' peut réduire les taux de requêtes si de nombreuses requêtes sont déroutées vers TCP.

Le format d'entrée est une requête par ligne : qname espace qtype. Un exemple :

www.powerdns.com ANY

Lors du benchmarking sur des périodes prolongées, il peut être nécessaire d'activer le recyclage de TIME_WAIT, car les tuples de ports TCP/IP pourraient autrement s'épuiser. Sur Linux, cela se fait en exécutant :

echo 1 > /proc/sys/net/ipv4/tcp_tw_recycle

L'équivalent pour IPv6 est inconnu.

OPTIONS

ADRESSE-DISTANTE
IPv4 ou IPv6 à tester.
PORT-DISTANT
Port à tester, par défaut 53.
-f <NOMFICHIER>, --fichier <NOMFICHIER>
NOMFICHIER à partir duquel lire les requêtes. Par défaut, l'entrée standard si non spécifié.
-h, --aide
Fournit un message d'aide.
--timeout-msec <MSEC>
MSEC millisecondes à attendre pour une réponse.
-u, --udp-dabord
Tente la résolution via UDP d'abord, n'utilise TCP que si une réponse tronquée est reçue.
-v, --verbeux
Soit verbeux sur ce que fait le programme.
--workers <NB>
Utilise NB threads de travail parallèles.

BOGUES

Actuellement, le code de timeout n'effectue pas réellement de connexions ou d'écritures non bloquantes. Ainsi, une connexion lente ou des écritures lentes entraîneront toujours de faibles performances et des retards.

Les statistiques de requêtes par seconde en médiane sont rapportées comme 0 pour les exécutions de moins d'une seconde.
