NOM

dnf5-clean - Commande de nettoyage

SYNTAXE

dnf5 clean [options] <types_de_cache>...

DESCRIPTION

La commande clean de DNF5 est utilisée pour supprimer les métadonnées de dépôt temporairement conservées ou pour marquer le cache comme expiré.

Les arguments dans types_de_cache spécifient quels types de données mises en cache doivent être nettoyés :

all
Supprime toutes les données temporaires de dépôt du système.
packages
Supprime tous les paquets mis en cache.
metadata
Supprime les métadonnées des dépôts.
Cela supprimera les fichiers que DNF5 utilise pour déterminer la disponibilité des paquets à distance.
L'utilisation de cette option entraînera le téléchargement de toutes les métadonnées par DNF5 lors de la prochaine exécution.
dbcache
Supprime les fichiers de cache générés à partir des métadonnées des dépôts.
Cela force DNF5 à régénérer les fichiers de cache lors de la prochaine exécution.
expire-cache
Marque les métadonnées des dépôts comme expirées.
Cela force DNF5 à vérifier la validité du cache lors de la prochaine exécution.

EXEMPLES

dnf5 clean all
Nettoie toutes les données mises en cache des dépôts.
dnf5 clean packages dbcache
Nettoie tous les paquets mis en cache et les métadonnées dbcache.
