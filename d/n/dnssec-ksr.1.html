    dnssec-ksr(8)

    CHOOSE A VALID DOMAIN NAME TO USE WITH DNSSEC-KSR

    OPTIONS

    The dnssec-ksr command accepts the following options:

    -a, --algorithm
    The signing algorithm to use. Possible values are 1 (RSA/MD5), 2 (Diffie-Hellman), 3 (DSA/SHA1), 4 (RSA/SHA1), 5 (RSA/SHA256), 7 (RSA/SHA384), 8 (RSA/SHA512), 13 (ECDSA/P-256/SHA256), 14 (ECDSA/P-384/SHA384), 15 (ECDSA/P-521/SHA512). Default is 8 (RSA/SHA512).
    -c, --chain
    The name of the chain to sign.
    -d, --domain
    The domain name to sign.
    -e, --expires
    The number of days until the key expires. Default is 30.
    -f, --force
    Overwrite existing keys without prompting.
    -h, --help
    Print a help message and exit.
    -k, --keytype
    The type of key to generate. Possible values are KSK (key signing key) and ZSK (zone signing key). Default is ZSK.
    -l, --lifetime
    The lifetime of the key in days. Default is 30.
    -n, --name
    The name of the key. Default is generated from the domain name and key type.
    -o, --output
    The output file to write the keys to. Default is to print to stdout.
    -p, --parent
    The parent domain name. Required when signing a chain.
    -q, --quiet
    Do not print any output.
    -s, --serial
    The serial number of the zone.
    -t, --type
    The type of record to generate. Possible values are A, AAAA, CNAME, MX, NS, PTR, SOA, SPF, SRV, TXT. Default is A.
    -v, --version
    Print program version and exit.
    -w, --wait
    The number of days to wait before expiring the key. Default is 30.
    -z, --zone
    The zone file to read.

    EXAMPLES

    dnssec-ksr -d example.com -k KSK -l 365 -o example.com.ksk.key
Generate a KSK for example.com with a lifetime of 365 days and save it to example.com.ksk.key.

dnssec-ksr -d www.example.com -p example.com -k ZSK -l 90 -o www.example.com.zsk.key
Generate a ZSK for www.example.com with a lifetime of 90 days and save it to www.example.com.zsk.key.
The parent domain is example.com.
