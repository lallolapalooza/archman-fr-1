NOM

dnf5-system-upgrade - Commande System-Upgrade

SYNTAXE

dnf5 system-upgrade <sous-commande> [options]

DESCRIPTION

La commande system-upgrade est utilisée pour mettre à jour le système vers une nouvelle version majeure. D'abord, la sous-commande download télécharge les paquets pendant que le système fonctionne normalement. Ensuite, la sous-commande reboot redémarre le système dans un environnement minimal « hors ligne » pour appliquer les mises à jour.

dnf5 system-upgrade est la méthode recommandée pour mettre à jour un système vers une nouvelle version majeure. Avant de continuer, assurez-vous que votre système est entièrement mis à jour (dnf5 --refresh upgrade).

system-upgrade partage de nombreuses sous-commandes avec la sous-commande offline <#offline-command-ref-label>.

SOUS-COMMANDES

clean
Voir dnf5-offline(8), Commande hors ligne <#offline-command-ref-label>
download
Télécharge tous les paquets nécessaires pour la mise à niveau vers une nouvelle version majeure et vérifie qu'ils peuvent être installés.
log
Voir dnf5-offline(8), Commande hors ligne <#offline-command-ref-label>
reboot
Voir dnf5-offline(8), Commande hors ligne <#offline-command-ref-label>

OPTIONS

--releasever=<version>
Obligatoire. La version vers laquelle effectuer la mise à niveau. Définit $releasever dans tous les dépôts activés. Généralement un nombre, ou rawhide.
--no-downgrade
Se comporte comme dnf5 update : n'installe pas les paquets de la nouvelle version s'ils sont plus anciens que ceux actuellement installés. C'est l'inverse du comportement par défaut, qui se comporte comme dnf5 distro-sync, installant toujours les paquets de la nouvelle version, même s'ils sont plus anciens que la version actuellement installée.
--allowerasing
Permet la suppression des paquets installés pour résoudre d'éventuels problèmes de dépendances.
--number=<numéro de démarrage>
Voir dnf5-offline(8), Commande hors ligne <#offline-command-ref-label>
--poweroff
Voir dnf5-offline(8), Commande hors ligne <#offline-command-ref-label>

ENVIRONNEMENT

Voir dnf5-offline(8), Commande hors ligne <#offline-command-ref-label>.

EXEMPLES

Utilisation typique de mise à niveau

dnf5 --refresh upgrade

dnf5 system-upgrade download --releasever 40

dnf5 system-upgrade reboot

Afficher les journaux de la dernière tentative de mise à niveau

dnf5 system-upgrade log --number=-1
