NOM

dnf5-repo - Commande Repo

SYNTAXE

dnf5 repo <sous-commande> [options] [<spécification-repo>...]

DESCRIPTION

La commande repo de DNF5 offre plusieurs requêtes pour obtenir des informations sur les dépôts configurés sur le système.

SOUS-COMMANDES

list
Lister les dépôts disponibles.
info
Afficher des informations détaillées sur les dépôts.

OPTIONS

--all
Afficher les informations sur tous les dépôts connus.
--enabled
Afficher les informations uniquement sur les dépôts activés.
C'est le comportement par défaut.
--disabled
Afficher les informations uniquement sur les dépôts désactivés.

EXEMPLES

dnf5 repo info --all
Afficher des informations détaillées sur tous les dépôts connus.
dnf5 repo list --disabled *-debuginfo
Afficher les dépôts désactivés liés au débogage.
dnf5 config-manager setopt repo_id.enabled=0
Désactiver de manière persistante un dépôt en utilisant la commande du plugin config-manager.
Voir dnf5-config-manager(8) pour plus de détails.
