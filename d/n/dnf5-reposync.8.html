NOM

dnf5-reposync - Commande Reposync

SYNTAXE

dnf5 [OPTIONS GLOBALES] reposync [OPTIONS]

DESCRIPTION

La commande reposync crée des copies locales de dépôts distants. Elle évite de re-télécharger les paquets déjà présents dans le répertoire local.

Par défaut, reposync synchronise tous les dépôts activés. Cependant, vous pouvez personnaliser l'ensemble des dépôts à synchroniser en utilisant des options DNF5 standards telles que --repo, --enable-repo ou --disable-repo.

OPTIONS

--arch=<architecture>, -a <architecture>
Télécharge uniquement les paquets pour l'architecture spécifiée. Cette option peut être spécifiée plusieurs fois. Le comportement par défaut est de télécharger les paquets pour toutes les architectures.
--delete
Supprime les paquets locaux qui ne sont plus présents dans le dépôt distant.
--destdir=<chemin>
Spécifie le chemin racine où les dépôts téléchargés sont stockés, relatif au répertoire de travail courant. Par défaut, il s'agit du répertoire de travail courant. Chaque dépôt téléchargé aura un sous-répertoire nommé d'après son identifiant dans ce chemin.
--download-metadata
Télécharge toutes les métadonnées du dépôt. La copie téléchargée est instantanément utilisable comme dépôt sans avoir à exécuter createrepo_c. Lorsqu'elle est utilisée avec --newest-only, seules les dernières versions de paquets sont téléchargées. Cependant, les métadonnées feront toujours référence aux paquets plus anciens. Pour éviter les problèmes causés par des fichiers RPM manquants, envisagez de mettre à jour les métadonnées en utilisant createrepo_c --update. Sinon, DNF rencontrera des erreurs lors de la tentative d'installation de paquets anciens.
--gpgcheck, -g
Supprime les paquets qui échouent à la vérification de signature OpenPGP après le téléchargement. La commande se termine avec le code 1 si au moins un paquet est supprimé.

Note : Pour les dépôts configurés avec gpgcheck=0, les signatures OpenPGP ne sont pas vérifiées, même lorsque cette option est utilisée.

--metadata-path=<chemin>
Spécifie le chemin racine où les fichiers de métadonnées téléchargés sont stockés. S'il n'est pas spécifié, il prend par défaut la valeur de --destdir.
--newest-only, -n
Télécharge uniquement les dernières versions de paquets de chaque dépôt.
--norepopath
Empêche l'ajout de l'identifiant du dépôt au chemin de téléchargement. Cette option ne peut être utilisée que lors de la synchronisation d'un seul dépôt. (Le comportement par défaut ajoute l'identifiant du dépôt au chemin.)
--remote-time
Tente de définir les horodatages des fichiers locaux téléchargés pour qu'ils corresponden à ceux du côté distant.
--safe-write-path=<chemin>
Définit le préfixe du chemin du système de fichiers où reposync est autorisé à écrire des fichiers. S'il n'est pas spécifié, il prend par défaut le chemin de téléchargement du dépôt. Cette option est utile pour les dépôts qui utilisent des emplacements relatifs de paquets sortant du répertoire du dépôt (par exemple, ../packages_store/foo.rpm).

Attention : Tout fichier sous le safe-write-path peut être écrasé. Cette option ne peut être utilisée que lors de la synchronisation d'un seul dépôt.

--srpm
Télécharge les paquets sources. Équivalent à utiliser --arch=src.
--urls, -u
Affiche les URL des fichiers qui seraient téléchargés sans les télécharger effectivement.

EXEMPLES

dnf reposync --repoid=le_repo
Synchronise tous les paquets du dépôt dont l'identifiant est le_repo. La copie synchronisée est sauvegardée dans le sous-répertoire le_repo du répertoire de travail courant.
dnf reposync --destdir=/mon/chemin/repos/ --repoid=le_repo
Synchronise tous les paquets du dépôt dont l'identifiant est le_repo. Dans ce cas, les fichiers sont sauvegardés dans le répertoire /mon/chemin/repos/le_repo.
dnf reposync --repoid=le_repo --download-metadata
Synchronise tous les paquets et métadonnées du dépôt le_repo.

Un dépôt synchronisé avec l'option --download-metadata peut être directement utilisé avec DNF, par exemple en utilisant l'option --repofrompath :

dnf --repofrompath=depotsynced,le_repo --repoid=depotsynced list --available
