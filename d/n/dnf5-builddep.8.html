NOM

dnf5-builddep - Commande Builddep

SYNTAXE

dnf5 builddep [options] [<paquet>...]

DESCRIPTION

Installe les dépendances manquantes pour la construction d'un paquet RPM.

Avertissement :

Les dépendances de construction dans un paquet source (c.-à-d. src.rpm) peuvent être différentes de ce que vous attendez car les dépendances ont été évaluées par rapport aux macros définies sur l'hôte de construction du paquet.

OPTIONS

-D "macro expr", --define="macro expr"
Définit une macro rpm. Définit la valeur "expr" à la macro "macro" lors de l'analyse des fichiers spec. Ne s'applique pas aux fichiers rpm source.
--with=OPTION, --without=OPTION
Active ou désactive la construction conditionnelle d'OPTION lors de l'analyse des fichiers spec. Ne s'applique pas aux fichiers rpm source.
--allowerasing
Autorise la suppression de paquets installés pour résoudre tout problème potentiel de dépendances.
--skip-unavailable
Autorise le saut des paquets qu'il est impossible de rétrograder. Tous les paquets restants seront rétrogradés.
--allow-downgrade
Autorise la rétrogradation des dépendances lors de la résolution de l'opération demandée.
--no-allow-downgrade
Désactive la rétrogradation des dépendances lors de la résolution de l'opération demandée.
--from-repo=REPO_ID,...
Les paquets (ou leurs 'provides') explicitement spécifiés sur la ligne de commande ne seront recherchés que dans les dépôts spécifiés.
Ces dépôts sont automatiquement activés.
L'activation et la désactivation des dépôts s'appliquent toujours. Les dépendances de ces paquets seront résolues à partir de n'importe quel dépôt activé.
--spec
Traite les arguments de la ligne de commande qui suivent cette option comme des fichiers spec.
--srpm
Traite les arguments de la ligne de commande qui suivent cette option comme des rpm source.
--offline
Stocke la transaction à effectuer hors ligne. Voir la commande offline <#offline-command-ref-label>, dnf5-offline(8).
--store=PATH
Stocke la transaction actuelle dans un répertoire au PATH spécifié au lieu de l'exécuter.
La transaction stockée peut être effectuée par la commande replay <#replay-command-ref-label>, dnf5-replay(8).

ARGUMENTS

<paquet>
Soit le chemin vers un fichier .src.rpm, .nosrc.rpm ou .spec, soit un paquet disponible dans un dépôt.

EXEMPLES

dnf builddep foobar.spec
Installe les exigences de construction nécessaires, définies dans le fichier foobar.spec.
dnf builddep foobar-1.0-1.src.rpm
Installe les exigences de construction nécessaires, définies dans le fichier foobar-1.0-1.src.rpm.
dnf builddep foobar-1.0-1
Recherche foobar-1.0-1 dans les dépôts activés et installe les exigences de construction pour son rpm source.
dnf builddep -D 'scl python27' python-foobar.spec
Installe les exigences de construction nécessaires pour la version SCL python27 de python-foobar.
dnf builddep --without=selinux foobar.spec
Installe les exigences de construction nécessaires à l'exception de celles pour le support optionnel SELinux.
