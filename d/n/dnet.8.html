S

Envoyer un datagramme UDP contenant du shellcode aléatoire

: 
dnet hex "\xeb\x1f\x5e\x89\x76\x08\x31\xc0\x88\x46\x07\x89" \
"\x46\x0c\xb0\x0b\x89\xf3\x8
d\x4e\x08\x8d\x56\x0c\xcd\x80" \ "\x31\xdb\x89\xd8\x40\xcd\x80\xe8\xdc\xff\xff\xff/bin/sh"
| \ dnet udp sport 555 dport 666 | \ dnet ip proto udp src 1.2.3.4 dst 5.6.7.8 | dnet send

Enregistrer une requête ARP dans un fichier et l'envoyer deux fois

: 
dnet arp op req sha 0:d:e:a:d:0 spa 10.0.0.3 tpa 10.0.0.4 |
\ dnet eth type arp src 0:d:e:a:d:0 dst ff:ff:ff:ff:ff:ff
> arp.pkt dnet send fxp0 < arp.pkt dnet send fxp0 < arp.pkt

Envoyer un paquet ping fragmenté

: 
# Créer le paquet ping avec l'en-tête IP, pour définir la somme de contrôle ICMP
echo "monkey monkey monkey monkey" | dnet ic
mp type 8 code 0 | \ dnet ip proto icmp src 1.2.3.4 dst 5.6.7.8 > ping.pkt # Retirer l'en-tête IP dd if=ping.pkt of=ping.dat
a bs=20 skip=1 # Fragmenter la charge utile IP split -b 24 ping.data p. # Envoyer les fragments dnet ip id 1 off 0+ proto
icmp src 1.2.3.4 dst 5.6.7.8 < p.aa | \ dnet send dnet ip id 1 off 24 proto icmp src 1.2.3.4 dst 5.6.7.8 < p.ab | \ dnet send
