NOM

dnf5-search - Commande de recherche

SYNTAXE

dnf5 search [options] <mot-clé>...

DESCRIPTION

La commande search de DNF5 est utilisée pour rechercher des paquets en faisant correspondre les mots-clés donnés par l'utilisateur avec divers métadonnées.

Par défaut, la commande recherche toutes les clés demandées (opération ET) dans les champs *Name* ou *Summary* des métadonnées du paquet RPM. La recherche ne respecte pas la casse et les jokers sont pris en charge.

OPTIONS

--all
Recherche également les motifs à l'intérieur des champs Description et URL.
En appliquant cette option, la recherche liste les paquets qui correspondent à au moins une des clés (opération OU).
--showduplicates
Affiche toutes les versions des paquets, pas seulement les plus récentes.

EXEMPLES

dnf5 search kernel
Recherche le mot-clé kernel dans les champs de métadonnées des paquets Name ou Summary.
dnf5 search rpm dbus
Recherche les paquets contenant les deux mots-clés rpm et dbus dans les champs Name ou Summary.
dnf5 search --all fedora gnome kde
Recherche les paquets contenant l'un des mots-clés donnés dans les champs Name, Summary, Description ou URL.
