DNSREPLAY(1) Serveur autoritaire PowerDNS DNSREPLAY(1)

NOM

dnsreplay - Un outil de débogage de serveur DNS PowerDNS

SYNTAXE

dnsreplay [OPTION]... NOMFICHIER ADRESSE [PORT]

DESCRIPTION

Ce programme prend des questions et des réponses enregistrées et les rejoue sur le serveur de noms spécifié, en rapportant ensuite quel pourcentage des réponses correspondaient, étaient pires ou meilleures.

dnsreplay compare les réponses et d'autres métriques avec celles trouvées dans le fichier dump.

Par défaut, il ne rejouera que les requêtes avec le drapeau "recursion-desired" activé.

OPTIONS

NOMFICHIER
doit être un fichier PCAP. Les requêtes sont envoyées au serveur DNS spécifié par ADRESSE et PORT.
ADRESSE
Adresse IPv4 ou IPv6 du serveur de noms auquel rejouer NOMFICHIER.
PORT
si omis, 53 sera utilisé.
--help, -h
Affiche un résumé des options.
--ecs-mask <VAL>
Lors du transfert EDNS d'une adresse IP, masque le premier octet avec cette valeur.
--ecs-stamp <DRAPEAU>
Ajoute l'adresse IP d'origine en tant qu'option EDNS Client Subnet lors du transfert vers le serveur de référence.
--packet-limit <NB>
Arrête après avoir rejoué NB paquets. La valeur par défaut pour NB est 0, ce qui signifie aucune limite.
--pcap-dns-port <VAL>
Examine les paquets provenant de ou à destination de ce port dans le PCAP. La valeur par défaut est 53.
--quiet <DRAPEAU>
Si DRAPEAU est défini sur 1, dnsreplay ne sera pas très verbeux avec sa sortie. C'est la valeur par défaut.
--recursive <DRAPEAU>
Si DRAPEAU est défini sur 1, dnsreplay ne rejouera que les requêtes avec le drapeau "recursion desired" activé. C'est la valeur par défaut.
--source-from-pcap <DRAPEAU>
Si DRAPEAU est défini sur 1, dnsreplay enverra les requêtes rejouées à partir de l'adresse IP source et du port présents dans le fichier PCAP. Cela nécessite le support d'IP_TRANSPARENT. La valeur par défaut est 0, ce qui signifie que les requêtes rejouées seront envoyées depuis une adresse locale.
--source-ip <VAL>
Envoie les requêtes rejouées depuis l'adresse IP source spécifiée dans VAL. La valeur par défaut est d'envoyer depuis une adresse locale.
--source-port <VAL>
Envoie les requêtes rejouées depuis le port source spécifié dans VAL. La valeur par défaut est d'envoyer depuis un port aléatoire sélectionné par le noyau.
--speedup <FACTEUR>
Rejoue les requêtes avec ce FACTEUR d'accélération. La valeur par défaut est 1.
--timeout-msec <MSEC>
Attend au moins MSEC millisecondes pour une réponse. La valeur par défaut est 500.

BOGUES

dnsreplay n'a pas de gestion certaine des timeouts. Il gère au plus 65536 réponses en attente.

VOIR AUSSI

pcap(3PCAP), tcpdump(8), dnswasher(1)
