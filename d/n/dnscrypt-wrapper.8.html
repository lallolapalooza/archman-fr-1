DNSCRYPT-WRAPPER(8) Manuel d'administration DNSCRYPT-WRAPPER(8)

NOM

dnscrypt-wrapper - Crée un modèle de site Web vide presque prêt pour le déploiement.

SYNTAXE

dnscrypt-wrapper [-h] [-a <str>] [-r <str>] [-U] [-u <str>] [-l <str>] [-p <str>] [-d] [-V] [-v] [--gen-cert-file] [--gen-crypt-keypair] [--gen-provider-keypair] [--show-provider-publickey-fingerprint] [--provider-cert-file=<str>] [--provider-name=<str>] [--provider-publickey-file=<str>] [--provider-secretkey-file=<str>] [--crypt-secretkey-file=<str>] [--cert-file-expire-days=<int>]

DESCRIPTION

dnscrypt-wrapper DNSCrypt est un protocole qui authentifie les communications entre un client DNS et un résolveur DNS. Il empêche l'usurpation DNS. Il utilise des signatures cryptographiques pour vérifier que les réponses proviennent du résolveur DNS choisi et qu'elles n'ont pas été modifiées.

OPTIONS

-h, --help,
Affiche le message d'aide de dnscrypt-wrapper et quitte.
-a <str>, --listen-address=<str>
Définit l'adresse locale sur laquelle écouter (par défaut : 0.0.0.0:53).
 <str>-r, --resolver-address=<str>
Définit le serveur DNS résolveur amont (<adresse:port>).
-U, --unauthenticated
Autorise et transmet les requêtes non authentifiées (par défaut : désactivé).
-u <str>, --user=<str>
Exécute le service en tant qu'utilisateur donné.
-l <str>, --logfile=<str>
Chemin du fichier de journalisation (par défaut : stdout).
-p <str>, --pidfile=<str>
Chemin du fichier PID (par défaut : aucun).
-d, --daemonize
Exécute en tant que démon (par défaut : désactivé).
-V, --verbose
Définit le service pour être plus verbeux. Spécifiez plusieurs -VVV pour augmenter la verbosité.
-v, --version
Affiche les informations de version et quitte.
--gen-cert-file
Génère un certificat pré-signé.
--gen-crypt-keypair
Génère une paire de clés cryptographiques.
--gen-provider-keypair
Génère une paire de clés de fournisseur.
--show-provider-publickey-fingerprint
Affiche l'empreinte de la clé publique du fournisseur.
--provider-cert-file=<str>
Fichier de certificat (par défaut : ./dnscrypt.cert).
--provider-name=<str>
Nom du fournisseur.
--provider-publickey-file=<str>
Fichier de clé publique du fournisseur (par défaut : ./public.key).
--provider-secretkey-file=<str>
Fichier de clé secrète du fournisseur (par défaut : ./secret.key).
--crypt-secretkey-file=<str>
Fichier de clé secrète de cryptage (par défaut : ./crypt_secret.key).
--cert-file-expire-days=<int>
Nombre de jours d'expiration du fichier de certificat (par défaut : 365).
