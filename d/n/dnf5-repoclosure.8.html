NOM

dnf5-repoclosure - Commande Repoclosure

SYNTAXE

dnf5 repoclosure [options] [<spécification-paquet>...]

DESCRIPTION

La commande repoclosure vous permet d'analyser les métadonnées des paquets à partir de plusieurs dépôts. Elle vérifie toutes les dépendances des paquets et fournit une liste des paquets ayant des dépendances non résolues.

Par défaut, repoclosure prend en compte tous les dépôts activés lors de la vérification des dépendances. Cependant, vous pouvez personnaliser l'ensemble des dépôts en utilisant des options DNF5 standard telles que --repo, --enable-repo ou --disable-repo.

OPTIONS

--arch <architecture>
Interroger uniquement les paquets pour une architecture spécifiée, peut être spécifié plusieurs fois (par défaut, toutes les architectures compatibles avec votre système).
--best
Vérifier uniquement les paquets les plus récents par architecture.
--check=ID_DEPOT,...
Spécifier les dépôts à vérifier, peut être spécifié plusieurs fois (par défaut, tous les dépôts activés).
Les valeurs acceptées sont les identifiants de dépôt, ou un motif d'identifiants.
--newest
Vérifier uniquement les paquets les plus récents dans les dépôts.
<spécification-paquet>
Vérifier la fermeture uniquement pour ce paquet.

EXEMPLES

dnf5 repoclosure
Afficher une liste des dépendances non résolues pour tous les dépôts activés.
dnf5 repoclosure --repo rawhide --arch noarch --arch x86_64
Afficher une liste des dépendances non résolues pour le dépôt rawhide et les paquets d'architectures noarch et x86_64.
dnf5 repoclosure --repo rawhide zmap
Afficher une liste des dépendances non résolues pour le paquet zmap du dépôt rawhide.
dnf5 repoclosure --repo rawhide --check myrepo
Afficher une liste des dépendances non résolues pour myrepo, un module complémentaire pour le dépôt rawhide.
