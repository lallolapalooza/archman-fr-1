NOM

dnf5-provides - Commande Fournit

SYNOPSIS

dnf5 provides [options globales] <package-spec-PFB>...

DESCRIPTION

La commande provides dans DNF5 trouve les paquets qui fournissent le <package-spec-PFB> donné.

EXEMPLES

dnf5 provides tito
Affiche quels paquets fournissent la commande tito.
dnf5 provides /usr/bin/tito
Affiche quel paquet fournit le fichier /usr/bin/tito
dnf5 provides zless
Il n'y a pas de Provides pour zless, mais un paquet contenant zless existe.
Affiche le paquet qui fournit le fichier /usr/bin/zless

Remarque :

Nouveau comportement : si un ou plusieurs paquets ne sont pas trouvés par provides, DNF5 renverra désormais le code de sortie 1 et listera tous les 'provides' qui ne correspondent pas à la fin de la sortie.
dnf5 provides rpm nonexistent_package
Affiche les 'provides' pour rpm et informe dans stderr que nonexistent_package
n'a correspondu à aucun résultat.
