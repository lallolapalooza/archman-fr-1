NOM

dnf5-repomanage - Commande Repomanage

SYNTAXE

dnf5 [OPTIONS GLOBALES] repomanage [OPTIONS] <chemin>

DESCRIPTION

repomanage affiche les paquets les plus récents ou les plus anciens dans un dépôt spécifié par <chemin> pour un transfert facile vers xargs ou des programmes similaires. Si <chemin> ne contient pas repodata/repomd.xml, il recherche des paquets rpm qui sont alors utilisés à la place. Si les données du dépôt sont présentes, repomanage les utilise comme source de vérité, il ne vérifie pas qu'elles correspondent aux paquets rpm présents. En fait, repomanage peut fonctionner uniquement avec les données du dépôt, aucun paquet rpm n'est nécessaire.

Si <chemin> spécifie une URL distante, repomanage tente de télécharger les données du dépôt distant dans un répertoire temporaire et de les utiliser.

OPTIONS

--nouveau
Affiche les N paquets les plus récents pour chaque nom.architecture (par défaut).
--ancien
Affiche tous les paquets sauf les N plus récents pour chaque nom.architecture
-g <N>, --garder <N>
Définit le nombre de paquets N pour --nouveau et --ancien (par défaut : 1)
-e, --espace
Affiche les paquets séparés par des espaces au lieu de nouvelles lignes

EXEMPLES

dnf repomanage --nouveau .
Affiche les paquets les plus récents dans le dépôt courant (répertoire).
dnf repomanage --nouveau --garder 2 ~/
Affiche les 2 versions les plus récentes de chaque paquet dans le répertoire "home".
dnf repomanage --ancien --espace .
Affiche tous les paquets sauf les plus récents, séparés par un espace, dans le dépôt courant (répertoire).
dnf repomanage http://download.example/repo/
Télécharge les métadonnées du dépôt dans un répertoire temporaire, les charge et affiche les paquets les plus récents.
