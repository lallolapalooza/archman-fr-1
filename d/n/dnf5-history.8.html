NOM

dnf5-history - Commande d'historique

SYNOPSIS

dnf5 history <sous-commande> [options] [<transaction-spec>]

DESCRIPTION

La commande history dans DNF5 permet à l'utilisateur de voir ce qui s'est passé lors des transactions passées et propose plusieurs opérations sur ces transactions, comme les annuler et les réexécuter. Afin d'utiliser les transactions dans ces commandes, on suppose qu'elles ont été enregistrées lors de l'utilisation de l'option de configuration history_record .

Pour plus d'informations sur <transaction-spec> voir dnf5-specs(7), Spécification des motifs <#transaction-spec-label>.

SOUS-COMMANDES

list
Liste les informations sur les transactions enregistrées dans le système.
Si aucune <transaction-spec> n'est spécifiée, toutes les transactions sont utilisées.
info
Affiche les détails sur des transactions spécifiques.
Si aucune <transaction-spec> n'est spécifiée, la dernière transaction est utilisée.
undo
Annule toutes les actions de la transaction spécifiée.
Exactement une transaction doit être spécifiée par <transaction-spec>.
redo
Réexécute la transaction spécifiée.
Utilise automatiquement --ignore-extras et --ignore-installed.
Contrairement aux autres commandes d'historique, elle remplace les raisons pour les paquets de la transaction qui sont déjà installés.
Cette commande est utile pour terminer des transactions interrompues.
Exactement une transaction doit être spécifiée par <transaction-spec>.
rollback
Annule toutes les transactions effectuées après la transaction spécifiée.
Exactement une transaction doit être spécifiée par <transaction-spec>.
store
Stocke la transaction dans un répertoire.
Si aucune <transaction-spec> n'est spécifiée, la dernière transaction est utilisée.

OPTIONS POUR LIST ET INFO

--reverse
Inverse l'ordre des transactions dans la sortie.
--contains-pkgs=NOM_DE_PAQUET,...
Affiche uniquement les transactions contenant des paquets avec les noms spécifiés.
Il s'agit d'une option de liste. Les motifs (globs) sont pris en charge.

OPTIONS POUR UNDO, ROLLBACK ET REDO

--skip-unavailable
Autorise le saut des actions sur les paquets qui ne peuvent pas être effectuées.
--offline
Stocke la transaction pour qu'elle soit effectuée hors ligne. Voir la commande offline <#offline-command-ref-label>, dnf5-offline(8).
--store=CHEMIN
Stocke la transaction actuelle dans un répertoire au CHEMIN spécifié au lieu de l'exécuter.
La transaction stockée peut être effectuée par la commande replay <#replay-command-ref-label>, dnf5-replay(8).

OPTIONS POUR UNDO ET ROLLBACK

--ignore-extras
Ne considère pas les paquets supplémentaires ajoutés à la transaction comme des erreurs.
Ils seront toujours signalés comme des avertissements.
--ignore-installed
Ne considère pas les écarts entre les paquets installés et ceux de la transaction stockée comme des erreurs.
Ils seront toujours signalés comme des avertissements.
L'utilisation de cette option peut entraîner une transaction vide.
Pour les actions d'installation, ignore les paquets déjà installés.
Pour les actions de mise à niveau, ignore les groupes ou environnements qui ne sont pas installés.
Pour les actions de suppression, ignore les paquets/groupes/environnements non installés.

EXEMPLES

dnf5 history list
Liste toutes les transactions, la transaction la plus récente étant imprimée en premier.
dnf5 history info 4
Affiche les informations détaillées sur la quatrième transaction.
dnf5 history info last
Affiche les informations détaillées sur la dernière transaction.
dnf5 history info last-1
Affiche les informations détaillées sur l'avant-dernière transaction.
dnf5 history list 4..8
Liste les transactions dont l'identifiant est compris entre 4 et 8.
dnf5 history undo last
Annule la dernière transaction.
dnf5 history undo 4 --ignore-extras
Annule la quatrième transaction en ignorant les paquets supplémentaires ajoutés à la transaction d'annulation.
