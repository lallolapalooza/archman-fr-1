NOM

dnf5-versionlock - Commande Versionlock

SYNOPIS

dnf5 versionlock <sous-commande> <paquet-spec-N>...

DESCRIPTION

La commande versionlock dans DNF5 prend un ensemble de noms et de versions de paquets et exclut toutes les autres versions de ces paquets. Cela vous permet de protéger les paquets contre les mises à jour vers de nouvelles versions. Alternativement, elle accepte une version spécifique de paquet à exclure des mises à jour, par exemple, lorsqu'il est nécessaire de sauter une version spécifique d'un paquet qui présente des problèmes connus.

Le plugin parcourra chaque entrée du fichier versionlock et exclura tout paquet du nom donné qui ne correspond pas aux conditions listées dans le fichier. Ceci est essentiellement la même chose que d'utiliser dnf5 --exclude pour le nom du paquet lui-même (car vous ne pouvez pas exclure les paquets installés), mais dnf verra toujours les versions que vous avez installées/verrouillées comme disponibles afin que dnf reinstall fonctionne toujours.

Notez que la commande versionlock n'applique aucune exclusion dans les opérations non transactionnelles comme repoquery, list, info, etc.

SOUS-COMMANDES

add
Ajoute un verrouillage de version pour tous les paquets disponibles correspondant au spécificateur. Cela signifie que seules les versions des paquets représentées par package-spec-N sont disponibles pour les opérations transactionnelles. Les NEVRAs à verrouiller sont d'abord recherchés parmi les paquets installés, puis (si aucun n'est trouvé) dans tous les paquets actuellement disponibles.
exclude
Ajoute une exclusion (dans versionlock) pour les paquets disponibles correspondant au spécificateur. Cela signifie que les paquets représentés par package-spec-N seront exclus des opérations transactionnelles.
clear
Supprime toutes les entrées de verrouillage de version.
delete
Supprime toute entrée de verrouillage de version correspondante.
list
Liste les entrées de verrouillage de version actuelles.

EXEMPLES

dnf5 versionlock add acpi
Si le paquet acpi est installé, verrouillez-le à la version actuellement installée. S'il n'est pas installé, verrouillez acpi à n'importe laquelle des versions actuellement disponibles.
dnf5 versionlock list
Affiche la configuration actuelle de versionlock.
dnf5 versionlock delete acpi
Supprime toutes les règles pour le paquet acpi.
dnf5 versionlock exclude iftop-1.2.3-7.fc38
Exclut la version iftop-1.2.3-7.fc38.

FORMAT DU FICHIER VERSIONLOCK

Le fichier versionlock est un fichier TOML stocké à l'emplacement /etc/dnf/versionlock.toml. Le fichier doit contenir la clé version, la version actuellement supportée est 1.0. Ensuite, il contient packages - une liste d'entrées de verrouillage. Chaque entrée se compose du nom du paquet et d'une liste de conditions. La spécification du nom du paquet prend en charge la même correspondance de modèles glob que le shell. Toutes les conditions doivent être vraies pour qu'un paquet corresponde (elles sont combinées à l'aide de l'opérateur logique ET). Toutes les entrées sont ensuite combinées à l'aide de l'opérateur logique OU.

Exemple de fichier versionlock

version = "1.0"
# conserve le paquet bash à la version 0:5.2.15-5.fc39
[[packages]]
name = "bash"               # nom du paquet
comment = "description"     # description facultative de l'entrée
[[packages.conditions]]     # conditions pour le paquet "bash"
key = "evr"                 # les clés epoch, evr et arch sont supportées
comparator = "="            # les opérateurs <, <=, =, >=, > et != sont supportés
value = "0:5.2.15-5.fc39"   # modèle à faire correspondre
# exclut la version iftop-1.2.3-7.fc38 (dnf5 versionlock exclude iftop-1.2.3-7.fc38)
[[packages]]
name = "iftop"
[[packages.conditions]]
key = "evr"
comparator = "!="
value = "0:1.0-0.31.pre4.fc39"
# conserve la version majeure 3 de acpi
[[packages]]
name = "acpi"
[[packages.conditions]]
key = "evr"
comparator = "<"
value = "4"
[[packages.conditions]]
key = "evr"
comparator = ">="
value = "3"
# conserve tous les paquets *nvidia* à la version 3:570.*
[[packages]]
name = "*nvidia*"
[[packages.conditions]]
key = "evr"
comparator = ">="
value = "3:570"
[[packages.conditions]]
key = "evr"
comparator = "<"
value = "3:571"
