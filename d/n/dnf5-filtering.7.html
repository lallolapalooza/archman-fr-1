NOM

dnf5-filtering - Filtrage des paquets

DESCRIPTION

Le filtrage des paquets supprime des paquets de l'ensemble des paquets disponibles, les rendant invisibles pour la plupart des commandes DNF5. En conséquence, ces paquets ne peuvent être inclus dans aucune transaction.

Il existe plusieurs façons de filtrer un paquet :

FILTRAGE DES EXCLUSIONS GLOBALES

Le filtrage des exclusions peut être ajusté à l'aide des options de configuration includepkgs ou excludepkgs dans le fichier de configuration DNF5. Pour désactiver les exclusions, vous pouvez utiliser l'option de configuration disable_excludes :

dnf5 --setopt=disable_excludes=* install bash

Pour plus de détails sur les options de configuration, consultez dnf5.conf(5), référence de configuration DNF5 <#dnf5-conf-label>.

FILTRAGE DES EXCLUSIONS DE DÉPÔT

Similaire aux exclusions globales, mais cette configuration est spécifique au dépôt et n'affecte que les paquets au sein du dépôt où les exclusions sont définies.

FILTRAGE DES EXCLUSIONS UTILISATEUR

Les utilisateurs de l'API disposent d'une option supplémentaire pour affiner les paquets exclus en utilisant les méthodes *_user_excludes() et *_user_includes de l'objet PackageSack. Voir API PackageSack.

VERSIONLOCK

De plus, la fonctionnalité de versionlock est implémentée en utilisant le filtrage des exclusions. Cependant, ces exclusions ne sont appliquées que pendant les opérations transactionnelles. Pour plus de détails, voir dnf5-versionlock(8), commande Versionlock <#versionlock-command-ref-label>.

FILTRAGE MODULAIRE

Pour plus de détails sur le fonctionnement du filtrage modulaire, veuillez consulter dnf5-modularity(7), la documentation sur la modularité <#modularity-misc-ref-label>.

Avec la modularité, seuls les paquets RPM des flux de modules actifs sont inclus dans l'ensemble des paquets disponibles. Les paquets RPM des flux de modules inactifs, ainsi que les paquets non modulaires portant le même nom ou offrant les mêmes capacités qu'un paquet d'un flux de module actif, sont filtrés. Le filtrage modulaire ne s'applique pas aux paquets ajoutés depuis la ligne de commande, aux paquets installés, ni aux paquets provenant de dépôts avec module_hotfixes=true dans leur fichier .repo.

La désactivation du filtrage modulaire n'est pas recommandée, car elle pourrait entraîner un état dégradé du système. Pour désactiver le filtrage modulaire pour un dépôt spécifique, spécifiez module_hotfixes=true dans le fichier .repo ou utilisez --setopt=<repo_id>.module_hotfixes=true.
