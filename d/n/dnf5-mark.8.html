NOM

dnf5-mark - Commande de marquage

SYNTAXE

dnf5 mark <sous-commande> [options globales] [<id-groupe>] <spécification-paquet-NPFB>...

DESCRIPTION

La commande mark dans DNF5 est utilisée pour changer la raison des paquets installés définis dans les arguments spécification-paquet-NPFB.

SOUS-COMMANDES

user
Marque le paquet comme installé par l'utilisateur.

Cela peut être utile si un paquet a été installé en tant que dépendance et que vous souhaitez qu'il reste sur le système lorsque la commande remove est exécutée avec l'option de configuration clean_requirements_on_remove définie à True.

dependency
Marque le paquet comme une dépendance.

Cela peut être utile si vous, en tant qu'utilisateur, n'avez pas besoin d'un paquet spécifique. Le paquet reste installé sur le système, mais sera supprimé lorsque la commande remove sera exécutée avec l'option de configuration clean_requirements_on_remove définie à True.

Vous devriez utiliser cette opération plutôt que la commande remove si vous n'êtes pas sûr que le paquet soit une exigence d'un autre paquet installé par l'utilisateur sur le système.

weak
Marque le paquet comme une dépendance faible.
group
Marque le paquet comme installé par le groupe défini dans l'argument id-groupe.

Cela peut être utile si un paquet a été installé en tant que dépendance ou par l'utilisateur et que vous souhaitez qu'il soit protégé et traité comme un membre du groupe, comme lors de la commande group remove.

OPTIONS

--skip-unavailable
Permet de sauter les paquets qui ne sont pas installés sur le système. Tous les paquets installés restants seront marqués.
--offline
Stocke la transaction à effectuer hors ligne. Voir la commande offline <#offline-command-ref-label>, dnf5-offline(8).
--store=CHEMIN
Stocke la transaction actuelle dans un répertoire au CHEMIN spécifié au lieu de l'exécuter.
La transaction stockée peut être effectuée par la commande replay <#replay-command-ref-label>, dnf5-replay(8).

EXEMPLES

dnf5 mark user fuse-devel
Marque le paquet fuse-devel comme installé par l'utilisateur.
dnf5 mark group xfce-desktop vim-enhanced
Marque le paquet vim-enhanced comme installé par le groupe xfce-desktop.
