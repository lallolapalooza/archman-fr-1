NOM

dnf5-comps - Groupes et environnements de composition DNF5

DESCRIPTION

Les fichiers de composition (comps) sont utilisés pour regrouper des paquets en groupes fonctionnels. Ils sont stockés dans les fichiers de métadonnées du dépôt sous le nom de fichier comps.xml.

Il existe deux types de structures qui peuvent être utilisées pour le regroupement. Le premier est un groupe qui est composé de listes de paquets. Le second est un environnement qui est composé de groupes.

Chaque environnement est constitué de groupes obligatoires et facultatifs. Tous les groupes obligatoires doivent être installés, de sorte que l'environnement est marqué comme installé. Les groupes facultatifs ne sont pas installés par défaut, ils doivent être ajoutés à l'aide de l'argument --with-optional.

Dans le groupe, il y a quatre niveaux de paquets :

obligatoire
Ce sont les paquets essentiels pour la fonctionnalité du groupe.
Ils doivent être installés pour que le groupe soit considéré comme installé.
par défaut
Ce sont les paquets installés avec les paquets obligatoires.
Ils peuvent être exclus, par exemple en utilisant l'argument --exclude=PACKAGE-SPEC-N,....
facultatif
Ces paquets ne sont pas installés par défaut.
Ils peuvent être inclus en utilisant l'argument --with-optional.
conditionnel
Ces paquets sont apportés dans la transaction si leur paquet requis doit être installé.

Pour les commandes opérant avec des groupes et des environnements, voir les références ci-dessous.
