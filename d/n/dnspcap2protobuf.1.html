NOM

dnspcap2protobuf - Un outil pour convertir des PCAP de trafic DNS en Protobuf PowerDNS

SYNOPSIS

dnspcap2protobuf FICHIERPcap FICHIERSortie

DESCRIPTION

dnspcap2protobuf lit le fichier PCAP FICHIERPcap pour les requêtes et réponses DNS et écrit celles-ci dans le format protobuf de PowerDNS dans FICHIERSortie.

OPTIONS

--help
Afficher un résumé des options.
--version
Afficher la version de dnspcap2protobuf
