NOM

dnsdict6

SYNTAXE

dnsdict6 [-d4] [-s|-m|-l|-x|-u] [-t THREADS] [-D] domaine [fichier-dictionnaire]

Énumère un domaine pour les entrées DNS, il utilise un fichier dictionnaire s'il est fourni ou une liste intégrée sinon. Cet outil est basé sur dnsmap de gnucitizen.org.

OPTIONS

 -4      dump aussi les adresses IPv4
 -t NO   spécifier le nombre de threads à utiliser (par défaut : 8, max : 32).
 -D      dump la liste de mots intégrée sélectionnée, pas de scan.
 -d      afficher les informations IPv6 sur les informations de domaine DNS NS et MX.
 -e      ignorer les erreurs NS pour le domaine
 -S      effectuer une devinette de nom de service SRV
 -[smlxu] choisir la taille du dictionnaire par -s(mall=100), -m(edium=1419) (PAR DÉFAUT)
           -l(arge=2601), -x(treme=5886) ou -u(ber=16724)
