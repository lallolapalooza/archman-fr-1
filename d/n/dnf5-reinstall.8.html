NOM

dnf5-reinstall - Commande de réinstallation

SYNTAXE

dnf5 reinstall [options globales] <spécification-paquet-NPFB>...

DESCRIPTION

La commande reinstall de DNF5 est utilisée pour réinstaller les paquets définis dans les arguments spécification-paquet-NPFB.

OPTIONS

--allowerasing
Permet la suppression de paquets installés pour résoudre tout problème potentiel de dépendance.
--skip-broken
Résout les problèmes de dépendance en supprimant les paquets qui causent des problèmes de la transaction.
--skip-unavailable
Permet d'ignorer les paquets impossibles à réinstaller. Tous les paquets restants seront réinstallés.
--allow-downgrade
Active la rétrogradation des dépendances lors de la résolution de l'opération demandée.
--no-allow-downgrade
Désactive la rétrogradation des dépendances lors de la résolution de l'opération demandée.
--installed-from-repo=ID_REPO,...
Filtre les paquets installés par l'ID du dépôt à partir duquel ils ont été installés.
--from-repo=ID_REPO,...
Les paquets (ou leurs Provides) spécifiés explicitement sur la ligne de commande seront uniquement recherchés dans les dépôts spécifiés.
Ces dépôts sont automatiquement activés.
L'activation et la désactivation des dépôts s'appliquent toujours. Les dépendances de ces paquets seront résolues à partir de n'importe quel dépôt activé.
--downloadonly
Télécharge l'ensemble de paquets résolu sans exécuter de transaction RPM.
--offline
Stocke la transaction à effectuer hors ligne. Voir la commande offline <#offline-command-ref-label>, dnf5-offline(8).
--store=CHEMIN
Stocke la transaction actuelle dans un répertoire au CHEMIN spécifié au lieu de l'exécuter.
La transaction stockée peut être exécutée par la commande replay <#replay-command-ref-label>, dnf5-replay(8).

EXEMPLES

dnf5 reinstall tito
Réinstalle le paquet tito.
dnf5 reinstall ~/Downloads/tito-0.6.21-1.fc36.noarch.rpm
Réinstalle le paquet tito à partir du fichier rpm local.
Ceci peut être utile par exemple lorsque le paquet donné n'est disponible dans aucun dépôt activé.
