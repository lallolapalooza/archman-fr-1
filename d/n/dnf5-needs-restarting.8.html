NOM

dnf5-needs-restarting - Commande Needs-restarting

SYNTAXE

dnf5 needs-restarting [--services | -s]

DESCRIPTION

La commande needs-restarting détermine si le système doit être redémarré pour appliquer pleinement les changements provenant de l'installation et des mises à jour des paquets. Sans aucune option, dnf5 needs-restarting indiquera si des paquets importants ont été installés ou mis à jour depuis le démarrage. Cet ensemble de paquets importants comprend le noyau, systemd, chaque paquet listé ici : https://access.redhat.com/solutions/27943, et tout paquet marqué d'un avis reboot_suggested.

La commande needs-restarting se terminera avec le code 1 si un redémarrage est recommandé, ou, lorsqu'elle est appelée avec --services, si un service systemd doit être redémarré. Si aucune action n'est recommandée, needs-restarting se terminera avec le code 0.

OPTIONS

-s, --services
Liste les services systemd qui doivent être redémarrés. Si le paquet fournissant le service, ou l'une de ses dépendances, a été mis à jour depuis le démarrage du service, alors le redémarrage du service sera recommandé. Notez que cette approche est assez agressive pour recommander un redémarrage lorsqu'il n'est pas strictement nécessaire.
