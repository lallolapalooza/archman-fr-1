dfu-prefix(1)

Paquet: dfu-util

Licences: GPL2

DFU-PREFIX(1) DFU-PREFIX(1)

NOM

dfu-prefix - ajoute, vérifie ou supprime un préfixe spécial de fichier firmware

SYNTAXE

dfu-prefix [ -s adresse | -L ] --add FICHIER_DFU

dfu-prefix [ -T | -L ] --check FICHIER_DFU

dfu-prefix [ -T | -L ] --delete FICHIER_DFU

dfu-prefix --help

dfu-prefix --version

DESCRIPTION

Le programme dfu-prefix peut être utilisé pour ajouter, vérifier ou supprimer un préfixe utilisé par certains fabricants de matériel. Le format Stellaris de TI et le format LPC de NXP sont supportés.

Notez qu'un fichier firmware DFU standard n'a pas de concept de préfixe, et un outil hôte DFU comme dfu-util transmet le préfixe à l'appareil dans le cadre de la charge utile normale du firmware.

OPTIONS

-s, --stellaris-address adresse
(en combinaison avec --add) Ajoute un préfixe d'adresse Stellaris TI au fichier
-T, --stellaris
(en combinaison avec --delete ou --check) Agit sur le préfixe d'adresse Stellaris TI du fichier
-L, --lpc-prefix
(en combinaison avec --add ou --delete ou --check) Utilise le format de préfixe DFU LPC NXP
-h, --help
Affiche un message d'aide.
-V, --version
Affiche la version du logiciel.

EXEMPLES

dfu-prefix --stellaris-address 0x0100 --add firmware.dfu
Ajoute un préfixe Stellaris avec l'adresse de chargement 0x0100
dfu-prefix --stellaris --check firmware.dfu
Vérifie le fichier firmware.dfu pour un préfixe Stellaris
dfu-prefix --lpc-prefix --delete firmware.dfu
Supprime un préfixe LPC du fichier firmware.dfu

VALEURS DE RETOUR

0
Succès (également si le préfixe est manquant)
-64
Erreur d'utilisation
