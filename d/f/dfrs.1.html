dfrs(1) Manuel des commandes générales dfrs(1)

NOM

dfrs - Afficher l'utilisation de l'espace disque avec des graphiques et des couleurs

SYNTAXE

dfrs [OPTION]... [FICHIER]...

DESCRIPTION

dfrs affiche la quantité d'espace disque disponible sur le système de fichiers contenant chaque nom de fichier argument. Si aucun nom de fichier n'est donné, l'espace disponible sur tous les systèmes de fichiers montés est affiché.

dfrs(1) est un outil similaire à df(1) sauf qu'il est capable d'afficher un graphique avec les données et d'utiliser des couleurs.

Sans aucun argument, la taille est affichée au format lisible par l'homme.

OPTIONS

Afficher des informations sur le système de fichiers sur lequel chaque FICHIER réside, ou tous les systèmes de fichiers réguliers par défaut.

-a, --more

Afficher plus de systèmes de fichiers ; utiliser -a deux fois pour tout afficher

-aa, --all

Afficher tous les systèmes de fichiers

-c

Forcer les couleurs même si la sortie standard n'est pas un tty. Ceci est utile avec watch -c

--color [QUAND]

Coloriser la sortie ; QUAND peut être 'auto' (par défaut si omis), 'always' (toujours), ou 'never' (jamais)

-i, --inodes

Afficher l'utilisation des inodes au lieu des blocs

-h, --human-readable

Afficher les tailles dans des puissances de 1024 (par exemple, 1023M)

-H, --si

Afficher les tailles dans des puissances de 1000 (par exemple, 1.1G)

--total

Produire et afficher un total général

-l, --local

Limiter l'affichage aux systèmes de fichiers locaux

--no-aliases

Ne pas résoudre les alias de raccourci de système de fichiers (par exemple, LVM)

--columns [COLONNE]...

Afficher les colonnes définies sous forme de liste séparée par des virgules ; COLONNE peut être : filesystem, type, bar, used, used_percentage, available, available_percentage, capacity, mounted_on

--mounts [FICHIER]

Fichier à partir duquel obtenir les informations de montage (par exemple, /proc/mounts ou /etc/mtab)

-V, --version

Imprime les informations de version

--help

Afficher un court texte d'aide.

BOGUES

Les bogues peuvent être signalés sur le traqueur de bogues https://github.com/anthraxx/dfrs/issues
