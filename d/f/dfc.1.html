dfc(1) COMMANDES UTILISATEUR dfc(1)

NOM

dfc - affiche des informations sur l'utilisation de l'espace des systèmes de fichiers avec style

SYNOPSIS

dfc [OPTION(S)] [-c WHEN] [-e FORMAT] [-p FSNAME] [-q SORTBY] [-t FSTYPE] [-u UNIT]

DESCRIPTION

dfc(1) est un outil similaire à df(1) sauf qu'il est capable d'afficher un graphique en plus des données et d'utiliser la couleur (le mode couleur est "color-auto" par défaut mais vous pouvez changer cela avec l'option "-c").

La taille disponible correspond à l'espace disponible du point de vue d'un utilisateur et non de la perspective du superutilisateur (c'est-à-dire : utilisez f_bavail au lieu de f_bfree).

Sans aucun argument, la taille est affichée au format lisible par l'humain. Notez que lorsque vous utilisez le format lisible par l'humain, il peut y avoir un arrondi lors du calcul de la taille. Si vous voulez une précision maximale, utilisez l'option "-u" et choisissez l'unité.

dfc(1) possède également une fonctionnalité intégrée qui permet à la sortie de s'ajuster automatiquement en fonction de la largeur du terminal. Si vous voulez ignorer ce comportement, utilisez l'option "-f".

OPTIONS

-a
Tout afficher (ne pas omettre de système de fichiers).
-b
Ne pas afficher la barre de graphique.
-c [WHEN]
Choisir le mode couleur où WHEN est l'une des sous-options suivantes :

"always" : la couleur sera toujours utilisée, peu importe ce qu'est "stdout".

"auto" : c'est la valeur par défaut lorsque "-c" n'est pas activé. La couleur n'est utilisée que si "stdout" est un terminal. Par exemple, la couleur sera désactivée avec cette option si vous redirigez la sortie de dfc(1) vers une autre commande.

"never" : la couleur ne sera jamais utilisée.

-d
Afficher la taille utilisée.
-e [FORMAT]
Permet d'exporter la sortie de dfc(1) vers le FORMAT spécifié. FORMAT est l'un des suivants :

"csv" : sortie au format de fichier "valeurs séparées par des virgules". Exemple d'utilisation :

dfc -e csv > foo.csv

"html" : la sortie est formatée en HTML. Exemple d'utilisation :

dfc -e html -Tadiso -c always > index.html

"json" : la sortie est formatée en JSON. Exemple d'utilisation :

dfc -e json -Tisod > report.json

"tex" : la sortie est formatée en TeX. Exemple d'utilisation :

dfc -e tex -c always > report.tex

"text" : sortie texte (par défaut).

-f
Ignorer le comportement d'ajustement automatique en forçant l'affichage des informations. Cette option peut être utile lors de la redirection de la sortie de dfc(1).
-h
Afficher un texte d'aide court.
-i
Afficher des informations sur les inœuds.
-l
Afficher uniquement les informations sur les systèmes de fichiers montés localement.
-m
Utiliser les unités SI (métriques) (c'est-à-dire : la taille est calculée en utilisant les puissances de 10 au lieu des puissances de 2).
-M
Ne pas afficher "monté sur".
-n
Ne pas afficher l'en-tête.
-o
Afficher les options de montage.
-p [FSNAME]
Permet d'effectuer un filtrage sur le nom du système de fichiers. FSNAME peut être n'importe quoi. Par exemple, si vous voulez voir uniquement les systèmes de fichiers dont le nom commence par "/dev", vous utiliseriez ce qui suit :

dfc -p /dev

Cela ne sortira que les systèmes de fichiers dont les noms sont, par exemple, "/dev/sda1", "/dev/root", "/dev", etc.

La sélection multiple est prise en charge. Dans ce cas, FSNAME doit être une liste séparée par des virgules (sans espaces). Par exemple, si vous voulez filtrer "/dev" et "tmpfs", vous utiliseriez ce qui suit :

dfc -p /dev,tmpfs

Vous pouvez également utiliser la correspondance négative pour filtrer la sortie. Pour ce faire, vous devez simplement préfixer FSNAME d'un "-". Dans l'exemple suivant, dfc(1) affichera tous les noms de systèmes de fichiers sauf ceux mentionnés :

dfc -p -proc,/dev/sdc,run

-q [SORTBY]
Permet de trier la sortie en fonction de SORTBY.

SORTBY peut prendre l'une de ces trois valeurs : "name", "type", "mount".

Lorsque vous utilisez "name", la sortie est triée par nom de système de fichiers. Lorsque vous utilisez "type", la sortie est triée par type de système de fichiers. Lorsque vous utilisez "mount", la sortie est triée par points de montage.

-s
Additionner l'utilisation totale.
-t [FSTYPE]
Permet d'effectuer un filtrage sur le type de système de fichiers. FSTYPE peut prendre n'importe quelle valeur de système de fichiers connue. Par exemple, "ext4", "ufs", "tmpfs", "reiserfs", etc. Vous pouvez également utiliser le filtrage par joker, tout comme avec l'option -p. Par exemple, si vous utilisez ce qui suit :


dfc -t ext

Cela permettra à tout type de système de fichiers dont le nom commence par "ext" de passer le filtre, par exemple, "ext2", "ext3" et "ext4".

La sélection multiple sur les systèmes de fichiers est également possible. Dans ce cas, FSTYPE doit être une liste séparée par des virgules (sans espaces). Par exemple, si vous voulez filtrer "ext4" et "tmpfs", vous utiliseriez ce qui suit :

dfc -t ext4,tmpfs

Vous pouvez également utiliser la correspondance négative pour filtrer la sortie. Pour ce faire, vous devez simplement préfixer FSTYPE d'un "-". Dans l'exemple suivant, dfc(1) affichera tous les types de systèmes de fichiers sauf ceux mentionnés :

dfc -t -rootfs,tmpfs

-T
Afficher le type de système de fichiers.
-u [UNIT]
Afficher la taille en utilisant l'unité spécifiée. UNIT peut prendre l'une des valeurs suivantes :

"h" : lisible par l'humain (par défaut lorsque l'option "-u" n'est pas utilisée).

"b" : Afficher les octets.

"k" : Afficher la taille en Kio.

"m" : Afficher la taille en Mio.

"g" : Afficher la taille en Gio.

"t" : Afficher la taille en Tio.

"p" : Afficher la taille en Pio.

"e" : Afficher la taille en Eio.

"z" : Afficher la taille en Zio.

"y" : Afficher la taille en Yio.

REMARQUE : Lorsque vous utilisez l'option "-u" avec l'option "-m", ces sous-options sont remplacées par leurs équivalents SI.

-v
Afficher la version de dfc(1) et quitter.
-w
Utiliser une barre plus large pour le graphique.
-W
Nom de chemin large (évite la troncature du nom de fichier). Peut nécessiter un affichage plus grand.

FICHIER DE CONFIGURATION

Le fichier de configuration est facultatif. Il permet de changer les couleurs par défaut de dfc(1), les valeurs lorsque les couleurs changent et le symbole du graphique en mode texte, ainsi que de modifier les couleurs utilisées dans l'export HTML.

Si vous voulez l'utiliser, placez-le ici :

$XDG_CONFIG_HOME/dfc/dfcrc

Si votre système d'exploitation ne prend pas en charge la spécification des répertoires de base XDG, il devrait alors être placé ici :

$HOME/.config/dfc/dfcrc

Ou, en dernier recours :

$HOME/.dfcrc

REMARQUE : Les deux derniers choix ne peuvent être choisis que si votre OS ne prend pas en charge la spécification des répertoires de base XDG.
