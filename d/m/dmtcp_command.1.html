DMTCP_COMMAND(1) Checkpointing multi-threadé distribué DMTCP_COMMAND(1)

NOM

dmtcp_command -- envoie une commande au coordinateur DMTCP à distance.

SYNTAXE

dmtcp_commmand [OPTIONS] commande [commande...]

DESCRIPTION

dmtcp_command est un outil pour envoyer des commandes utilisateur au coordinateur DMTCP à distance.

OPTIONS

-h, --coord-host nom_hote (variable d'environnement DMTCP_COORD_HOST)

Nom d'hôte où dmtcp_coordinator est exécuté (défaut : localhost)
-p, --port port (variable d'environnement DMTCP_PORT)

Port où dmtcp_coordinator est exécuté (défaut : 7779)
--quiet

Ignorer l'avis de copyright
--help

Afficher ce message et quitter.
--version

Afficher les informations de version et quitter.

Commandes pour le Coordinateur

-s --status

Afficher le message de statut
-c, --checkpoint

Checkpoint de tous les nœuds
-bc, --bcheckpoint

Checkpoint de tous les nœuds, bloquant jusqu'à la fin
-i, --interval <val>

Mettre à jour l'intervalle de checkpointing à <val> secondes (0=jamais)
-k, --kill

Arrêter tous les nœuds
-q, --quit

Arrêter tous les nœuds et quitter

SIGNALEMENT DE BOGUES
