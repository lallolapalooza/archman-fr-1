dmmp_path_group_array_get(3) API Device Mapper Multipath — Manuel libdmmp dmmp_path_group_array_get(3)

NOM

dmmp_path_group_array_get - Récupérer le tableau de pointeurs des groupes de chemins.

SYNTAXE

void dmmp_path_group_array_get (struct dmmp_mpath *dmmp_mp, struct dmmp_path_group ***dmmp_pgs, uint32_t *dmmp_pg_count);

ARGUMENTS

dmmp_mp
Pointeur de 'struct dmmp_mpath'. Si ce pointeur est NULL, votre programme sera terminé par assert.
dmmp_pgs
Pointeur de sortie du tableau de pointeurs 'struct dmmp_path_group'. Si ce pointeur est NULL, votre programme sera terminé par assert.
dmmp_pg_count
Pointeur de sortie de uint32_t. Contient la taille du tableau de pointeurs 'dmmp_pgs'. Si ce pointeur est NULL, votre programme sera terminé par assert.

DESCRIPTION

Récupère les groupes de chemins d'un mpath donné.

La mémoire du tableau de pointeurs de sortie est détenue par 'struct dmmp_mpath', il n'est pas nécessaire de libérer cette mémoire, les ressources seront libérées lorsque dmmp_mpath_array_free sera appelée.

RETOUR

void
