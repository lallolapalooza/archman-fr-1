DM-TOOL(1) Manuel des commandes générales DM-TOOL(1)

NOM

dm-tool - un outil pour contrôler le gestionnaire d'affichage

SYNOPSIS

dm-tool [ OPTIONS ] COMMANDE [ ARGS ]

DESCRIPTION

dm-tool est un outil pour communiquer avec le gestionnaire d'affichage LightDM.

OPTIONS

-h, --help
Afficher les options d'aide
--version
Afficher la version de publication
--session-bus
Tenter de se connecter au gestionnaire d'affichage en utilisant le bus de session. Ceci est utile si vous exécutez un gestionnaire d'affichage en mode test. Si cette option n'est pas présente, dm-tool se connectera en utilisant le bus système.
Les commandes suivantes sont disponibles :
switch-to-greeter
Basculer vers l'écran de connexion approprié pour se connecter à une nouvelle session.
switch-to-user NOMUTILISATEUR [SESSION]
Basculer vers une session utilisateur. Si cet utilisateur est déjà connecté, le gestionnaire d'affichage basculera vers cette session, sinon une nouvelle session sera lancée. Si l'authentification est requise, un écran de connexion sera lancé pour la collecter. Si l'option session est fournie, ce type de session sera utilisé, sinon le défaut pour cet utilisateur sera utilisé.
switch-to-guest [SESSION]
Basculer vers une session invité. Si la session invité est déjà active, le gestionnaire d'affichage basculera vers cette session, sinon la session invité sera lancée. Si l'option session est fournie, ce type de session sera utilisé, sinon le défaut pour l'utilisateur invité sera utilisé.
lock
Verrouiller le siège actuel. Cela basculera vers un écran de connexion avec un indice que l'écran est verrouillé. Vous pouvez revenir à cette session en vous authentifiant dans l'écran de connexion.
list-seats
Lister les sièges actifs et les sessions en cours d'exécution.
add-nested-seat
Démarrer un serveur X à l'intérieur d'une session et le connecter à un gestionnaire d'affichage.
add-local-x-seat NUMÉRO_AFFICHAGE
Connecter un serveur X existant au gestionnaire d'affichage.
add-seat TYPE [NOM=VALEUR...]
Ajouter un siège dynamique.

ENVIRONNEMENT

XDG_SEAT_PATH
Utilisé par dm-tool pour déterminer dans quelle session du gestionnaire d'affichage il est en cours d'exécution. Lors de l'exécution de dm-tool en dehors d'un gestionnaire d'affichage, utilisez sa commande list-seats pour afficher les sessions actives et définir la session à laquelle se connecter avec : export XDG_SEAT_PATH=/org/freedesktop/DisplayManager/SeatX où SeatX est l'une des sessions listées.
