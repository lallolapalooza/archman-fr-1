NOM

dmmp_context_new - Crée une structure dmmp_context.

SYNTAXE

struct dmmp_context * dmmp_context_new (void);

ARGUMENTS

void
aucun argument

DESCRIPTION

Le niveau de journalisation par défaut (DMMP_LOG_PRIORITY_DEFAULT) est DMMP_LOG_PRIORITY_WARNING, ce qui signifie que seuls les messages d'avertissement et d'erreur seront transmis à la fonction de gestion des journaux. La fonction de gestion des journaux par défaut imprime les messages de journal sur la sortie d'erreur standard (STDERR). Pour modifier cela, utilisez dmmp_context_log_func_set pour définir votre propre gestionnaire de journaux. Consultez la page de manuel libdmmp.h(3) pour plus de détails.

RETOUR

Pointeur vers 'struct dmmp_context'. Doit être libéré par dmmp_context_free.
