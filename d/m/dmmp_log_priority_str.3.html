NOM

dmmp_log_priority_str - Convertit la priorité de journalisation en chaîne de caractères.

SYNTAXE

const char * dmmp_log_priority_str (int priority);

ARGUMENTS

priority
int. Priorité de journalisation.

DESCRIPTION

Convertit la priorité de journalisation en chaîne de caractères (const char *).

RETOUR

const char *. Les chaînes valides sont :

* "ERROR" pour DMMP_LOG_PRIORITY_ERROR

* "WARN " pour DMMP_LOG_PRIORITY_WARNING

* "INFO " pour DMMP_LOG_PRIORITY_INFO

* "DEBUG" pour DMMP_LOG_PRIORITY_DEBUG

* "Argument invalide" pour une priorité de journalisation invalide.
