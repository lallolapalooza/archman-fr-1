NOM

dmmp_path_group_status_str - Convertir le statut d'un groupe de chemins en chaîne de caractères.

SYNTAXE

const char * dmmp_path_group_status_str (uint32_t pg_status);

ARGUMENTS

pg_status
uint32_t. Statut du groupe de chemins. Si la valeur fournie n'est pas un statut de groupe de chemins valide, renvoie "Argument invalide".

DESCRIPTION

Convertit le statut de groupe de chemins uint32_t en chaîne de caractères (const char *).

RETOUR

const char *. Les chaînes valides sont :

* "Argument invalide"

* "undef"

* "enabled"

* "disabled"

* "active"
