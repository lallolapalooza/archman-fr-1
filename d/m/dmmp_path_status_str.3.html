NOM

dmmp_path_status_str - Convertit le statut d'un chemin en chaîne de caractères.

SYNTAXE

const char * dmmp_path_status_str (uint32_t path_status);

ARGUMENTS

path_status
uint32_t. Statut du chemin. Si la valeur fournie n'est pas un statut de chemin valide, renvoie "Invalid argument".

DESCRIPTION

Convertit le statut de chemin uint32_t en chaîne de caractères (const char *):

* DMMP_PATH_STATUS_UNKNOWN -- "undef"

* DMMP_PATH_STATUS_DOWN -- "faulty"

* DMMP_PATH_STATUS_UP -- "ready"

* DMMP_PATH_STATUS_SHAKY -- "shaky"

* DMMP_PATH_STATUS_GHOST -- "ghost"

* DMMP_PATH_STATUS_PENDING -- "pending"

* DMMP_PATH_STATUS_TIMEOUT -- "timeout"

* DMMP_PATH_STATUS_REMOVED -- "removed"

* DMMP_PATH_STATUS_DELAYED -- "delayed"

RETOUR

const char *. La signification de la valeur du statut.
