DMTCP_SRUN_HELPER(1) Point de contrôle distribué multithreadé DMTCP_SRUN_HELPER(1)

NOM

dmtcp_srun_helper -- Il s'agit d'un programme d'assistance qui ne doit pas être exécuté par l'utilisateur.

SYNTAXE

dmtcp_srun_helper [OPTIONS] commande [commande...]

DESCRIPTION

dmtcp_srun_helper ne doit pas être utilisé directement.

OPTIONS

aucune option

Ceci est un programme d'assistance. Veuillez ne pas essayer d'exécuter ce programme directement.

SIGNALER LES BOGUES

Signaler les bogues à : dmtcp-forum@lists.sourceforge.net
Page d'accueil de DMTCP : http://dmtcp.sourceforge.net
