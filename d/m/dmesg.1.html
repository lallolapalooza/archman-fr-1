DMESG(1) Commandes Utilisateur DMESG(1)

NOM

dmesg - afficher ou contrôler le tampon circulaire du noyau

SYNTAXE

dmesg [options]

dmesg --clear

dmesg --read-clear [options]

dmesg --console-level niveau

dmesg --console-on

dmesg --console-off

DESCRIPTION

dmesg est utilisé pour examiner ou contrôler le tampon circulaire du noyau.

L'action par défaut consiste à afficher tous les messages du tampon circulaire du noyau.

OPTIONS

Les options --clear, --read-clear, --console-on, --console-off et --console-level s'excluent mutuellement.

-C, --clear

Vide le tampon circulaire.

-c, --read-clear

Vide le tampon circulaire après avoir affiché son contenu.

-D, --console-off

Désactive l'affichage des messages sur la console.

-d, --show-delta

Affiche l'horodatage et le delta de temps entre les messages. S'il est utilisé avec --notime, seul le delta de temps sans l'horodatage est affiché.

-E, --console-on

Active l'affichage des messages sur la console.

-e, --reltime

Affiche l'heure locale et le delta dans un format lisible par l'homme. Attention, la conversion à l'heure locale peut être inexacte (voir -T pour plus de détails).

-F, --file fichier

Lit les messages syslog du fichier donné. Notez que -F ne prend pas en charge les messages au format kmsg. Voir -K à la place.

-f, --facility liste

Restreint la sortie à la liste spécifiée (séparée par des virgules) de facilites. Par exemple :

dmesg --facility=daemon

affichera uniquement les messages des démons système. Pour toutes les facilites prises en charge, consultez la sortie de --help.

-H, --human

Active la sortie lisible par l'homme. Voir aussi --color, --reltime et --nopager.

-J, --json

Utilise le format de sortie JSON. Le format de sortie de l'heure est uniquement au format "sec.usec", le niveau de priorité du log n'est pas décodé par défaut (utilisez --decode pour séparer en facilité et priorité), les autres options pour contrôler le format de sortie ou le format de l'heure sont ignorées silencieusement.

-K, --kmsg-file fichier

Lit les messages de /dev/kmsg du fichier donné. Des enregistrements différents sont censés être séparés par un octet NULL.

-k, --kernel

Affiche les messages du noyau.

-L, --color[=quand]

Colore la sortie. L'argument optionnel quand peut être auto, never ou always. Si l'argument quand est omis, il prend par défaut la valeur auto. Les couleurs peuvent être désactivées ; pour la valeur par défaut intégrée actuelle, consultez la sortie de --help. Voir également la section COULEURS ci-dessous.

-l, --level liste

Restreint la sortie à la liste spécifiée (séparée par des virgules) de niveaux. Par exemple :

dmesg --level=err,warn

affichera uniquement les messages d'erreur et d'avertissement. Pour tous les niveaux pris en charge, consultez la sortie de --help.

L'ajout d'un plus + à un nom de niveau inclut également tous les niveaux supérieurs. Par exemple :

dmesg --level=err+

affichera les niveaux err, crit, alert et emerg.

Le préfixe ajoutera tous les niveaux inférieurs.

-n, --console-level niveau

Définit le niveau auquel l'affichage des messages est effectué sur la console. Le niveau est un numéro de niveau ou une abréviation du nom du niveau. Pour tous les niveaux pris en charge, consultez la sortie de --help.

Par exemple, -n 1 ou -n emerg empêche tous les messages, à l'exception des messages d'urgence (panic), d'apparaître sur la console. Elle continuent d'être écrites dans /proc/kmsg, donc syslogd(8) peut toujours être utilisé pour contrôler exactement où les messages du noyau apparaissent. Lorsque l'option -n est utilisée, dmesg n'affichera pas et ne videra pas le tampon circulaire du noyau.

--noescape

Les caractères non imprimables et potentiellement non sécurisés (par exemple, séquences multi-octets corrompues, caractères de contrôle de terminal, etc.) sont échappés au format \x<hex> pour des raisons de sécurité par défaut. Cette option désactive complètement cette fonctionnalité. Elle est utilisable par exemple à des fins de débogage avec --raw. Soyez prudent et ne l'utilisez pas par défaut.

-P, --nopager

Ne pas rediriger la sortie vers un pager. Un pager est activé par défaut pour la sortie --human.

-p, --force-prefix

Ajoute des informations de facilité, de niveau ou d'horodatage à chaque ligne d'un message multi-lignes.

-r, --raw

Affiche le tampon de message brut, c'est-à-dire, ne supprime pas les préfixes de niveau de journalisation, mais tous les caractères non imprimables sont toujours échappés (voir également --noescape).

Notez que le format brut réel dépend de la méthode utilisée par dmesg pour lire les messages du noyau. Le périphérique /dev/kmsg utilise un format différent de syslog(2). Pour des raisons de compatibilité ascendante, dmesg renvoie toujours les données au format syslog(2). Il est possible de lire les données brutes réelles de /dev/kmsg en utilisant, par exemple, la commande 'dd if=/dev/kmsg iflag=nonblock'.

-S, --syslog

Force dmesg à utiliser l'interface noyau syslog(2) pour lire les messages du noyau. Par défaut, il utilise /dev/kmsg plutôt que syslog(2) depuis le noyau 3.5.0.

-s, --buffer-size taille

Utilise un tampon de taille pour interroger le tampon circulaire du noyau. La valeur par défaut est 16392. (La taille par défaut du tampon syslog du noyau était de 4096 au début, 8192 depuis 1.3.54, 16384 depuis 2.1.113.) Si vous avez configuré le tampon du noyau pour qu'il soit plus grand que la valeur par défaut, cette option peut être utilisée pour visualiser l'intégralité du tampon.

-T, --ctime

Affiche des horodatages lisibles par l'homme.

Attention, l'horodatage peut être inexact ! La source de l'heure utilisée pour les journaux n'est pas mise à jour après la MISE EN VEILLE/REPRISE du système. Les horodatages sont ajustés en fonction du delta actuel entre les horloges de démarrage et monotoniques, cela ne fonctionne que pour les messages affichés après la dernière reprise.

--since heure

Affiche les enregistrements depuis l'heure spécifiée. La granularité sous-seconde est prise en charge. Il est possible de spécifier l'heure de manière absolue ainsi que par notation relative (par exemple, 'il y a 1 heure'). Soyez conscient que l'horodatage peut être inexact et consultez --ctime pour plus de détails.

--until heure

Affiche les enregistrements jusqu'à l'heure spécifiée. La granularité sous-seconde est prise en charge. Il est possible de spécifier l'heure de manière absolue ainsi que par notation relative (par exemple, 'il y a 1 heure'). Soyez conscient que l'horodatage peut être inexact et consultez --ctime pour plus de détails.

-t, --notime

N'affiche pas les horodatages du noyau.

--time-format format

Affiche les horodatages en utilisant le format donné, qui peut être ctime, reltime, delta, iso ou raw. Les trois premiers formats sont des alias des options spécifiques au format horaire. Le format raw utilise le format d'horodatage par défaut montrant les secondes depuis le démarrage. Le format iso est une implémentation par dmesg du format d'horodatage ISO-8601. Le but de ce format est de faciliter la comparaison des horodatages entre deux systèmes, et tout autre traitement. La définition de l'horodatage iso est : AAAA-MM-JJ<T>HH:MM:SS,<microsecondes>←+><décalage de fuseau horaire par rapport à UTC>.

Le format iso a le même problème que ctime : l'heure peut être inexacte lorsque le système est suspendu puis

repris.

--time-format peut être utilisé plusieurs fois avec différentes valeurs pour format afin de produire chaque format

spécifié.

Le delta suit toujours ctime ou raw si spé

cifié ensemble.

COULEUR

S

La coloration de la sortie est implémentée par la fonctionnalité terminal-colors.d(5). La coloration implicite peut être désactivée par un fichier

vide

/etc/terminal-colors.d/dmesg.disable

pour la commande dmesg ou pour tous les outils

par

/etc/terminal-colors.d/disable

Depuis la version 2.41, la variable d'environnement $NO_COLOR est également prise en charge pour désactiver la coloration de la sortie, sauf si elle est explicitement activée par une option de ligne de

commande.

Le répertoire spécifique à l'utilisateur $XDG_CONFIG_HOME/terminal-colors.d ou $HOME/.config/terminal-colors.d remplace le paramètre

global.

Notez que la coloration de la sortie peut être activée par défaut, et dans ce cas les répertoires terminal-colors.d n'ont pas besoin d'exister

encore.
