DMTCP_RESTART(1) Point de contrôle multi-threadé distribué DMTCP_RESTART(1)

NOM

dmtcp_restart -- redémarre les processus à partir des images de point de contrôle données.

SYNTAXE

dmtcp_restart [OPTIONS] ckpt1.dmtcp [ckpt2.dmtcp...]

DESCRIPTION

dmtcp_restart redémarre les processus à partir des fichiers d'image de point de contrôle donnés. Notez que DMTCP écrit également un script shell pour redémarrer tous les processus. Il est écrit dans le répertoire courant du coordinateur par défaut.

OPTIONS

Connexion au coordinateur DMTCP

-h, --coord-host nom_hote (variable d'environnement DMTCP_COORD_HOST)

Nom d'hôte où dmtcp_coordinator est exécuté (défaut : localhost)
-p, --coord-port port (variable d'environnement DMTCP_COORD_PORT)

Port où dmtcp_coordinator est exécuté (défaut : 7779)
--port-file nom_fichier

Fichier pour écrire le numéro de port d'écoute. (Utile avec --port 0, qui est utilisé pour attribuer un port aléatoire)
-j, --join

Rejoindre un coordinateur existant, lever une erreur si aucun n'existe déjà
--new-coordinator

Créer un nouveau coordinateur sur le port donné. Échouer si un coordinateur existe déjà sur le port donné. Le port peut être spécifié avec --coord-port, ou avec la variable d'environnement DMTCP_COORD_PORT. Si aucun port n'est spécifié, démarrer le coordinateur sur un port aléatoire (identique à la spécification du port '0').
-i, -interval secondes (variable d'environnement DMTCP_CHECKPOINT_INTERVAL)

Temps en secondes entre les points de contrôle automatiques. 0 implique jamais (point de contrôle manuel uniquement) ; si non défini et aucune variable d'environnement, utiliser la valeur par défaut définie dans dmtcp_coordinator ou dmtcp_command. Non autorisé si --join est spécifié

Autres options

--run-as-root

Permettre à root d'exécuter dmtcp_restart et désactiver la vérification d'UID. (défaut : désactivé)
--no-strict-uid-checking (variable d'environnement DMTCP_DISABLE_UID_CHECKING)

Désactiver la vérification d'UID pour l'image du point de contrôle. Cela permet à l'image du point de contrôle d'être redémarrée par un utilisateur différent de celui qui l'a créée.
--ckptdir chemin (variable d'environnement DMTCP_CHECKPOINT_DIR)

Répertoire pour stocker les images de point de contrôle (défaut : utiliser le même répertoire que celui utilisé lors du point de contrôle précédent)
--tmpdir chemin (variable d'environnement DMTCP_TMPDIR)

Répertoire pour stocker les fichiers temporaires (défaut : $TMDPIR/dmtcp-$USER@$HOST ou /tmp/dmtcp-$USER@$HOST)
-q, --quiet (ou définir la variable d'environnement DMTCP_QUIET = 0, 1 ou 2)

Ignorer les messages NOTE ; si donné deux fois, ignorer également les avertissements (WARNINGs)
--help

Afficher ce message et quitter.
--version

Afficher les informations de version et quitter.
