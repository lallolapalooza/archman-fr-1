NOM

dmmp_strerror - Convertir un code d'erreur en chaîne de caractères.

SYNTAXE

const char * dmmp_strerror (int rc);

ARGUMENTS

rc
int. Code de retour des fonctions libdmmp. Lorsque le code d'erreur fourni n'est pas un code d'erreur valide, retourne "Argument invalide".

DESCRIPTION

Convertir un code d'erreur (int) en chaîne de caractères (const char *):

* DMMP_OK -- "OK"

* DMMP_ERR_BUG -- "BUG de la bibliothèque libdmmp"

* DMMP_ERR_NO_MEMORY -- "Pas assez de mémoire"

* DMMP_ERR_IPC_TIMEOUT -- "Délai d'attente lors de la communication avec multipathd, essayez de définir une valeur de délai d'attente plus grande via dmmp_context_timeout_set ()"

* DMMP_ERR_IPC_ERROR -- "Erreur lors de la communication avec le démon multipathd"

* DMMP_ERR_NO_DAEMON -- "Le démon multipathd n'est pas démarré"

* DMMP_ERR_INCOMPATIBLE -- "La version du démon multipathd n'est pas compatible avec la bibliothèque actuelle"

* Autre numéro d'erreur invalide -- "Argument invalide"

RETOUR

const char *. La signification du code d'erreur fourni.
