dmmp_reconfig(3) API Device Mapper Multipath - Manuel de libdmmp dmmp_reconfig(3)

NOM

dmmp_reconfig - Demander au démon multipathd de procéder à une reconfiguration.

SYNTAXE

int dmmp_reconfig (struct dmmp_context *ctx);

ARGUMENTS

ctx
Pointeur vers 'struct dmmp_context'. Si ce pointeur est NULL, votre programme sera terminé par un assert.

DESCRIPTION

Demande au démon multipathd de procéder à une reconfiguration.

VALEUR DE RETOUR

int. Les codes d'erreur valides sont :

* DMMP_OK

* DMMP_ERR_BUG

* DMMP_ERR_NO_MEMORY

* DMMP_ERR_NO_DAEMON

* DMMP_ERR_PERMISSION_DENY

Le numéro d'erreur peut être converti en chaîne de caractères par dmmp_strerror.
