NOM

dmmp_flush_mpath - Vider la carte de multiplexage spécifiée si elle n'est pas utilisée.

SYNOPSIS

int dmmp_flush_mpath (struct dmmp_context *ctx, const char *mpath_name);

ARGUMENTS

ctx
Pointeur vers 'struct dmmp_context'. Si ce pointeur est NULL, votre programme sera terminé par assert.
mpath_name
const char *. Le nom de la carte de multiplexage du périphérique.

DESCRIPTION

Vide une carte de multiplexage de périphérique spécifiée par le paramètre, si elle n'est pas utilisée.

RETOUR

int. Les codes d'erreur valides sont :

* DMMP_OK

* DMMP_ERR_BUG

* DMMP_ERR_NO_MEMORY

* DMMP_ERR_NO_DAEMON

* DMMP_ERR_MPATH_BUSY

* DMMP_ERR_MPATH_NOT_FOUND

* DMMP_ERR_INVALID_ARGUMENT

* DMMP_ERR_PERMISSION_DENY

Le numéro d'erreur peut être converti en chaîne de caractères par dmmp_strerror.
