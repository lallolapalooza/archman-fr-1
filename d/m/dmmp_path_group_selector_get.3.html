NOM

dmmp_path_group_selector_get - Récupérer le sélecteur de groupe de chemins.

SYNTAXE

const char * dmmp_path_group_selector_get (struct dmmp_path_group *dmmp_pg);

ARGUMENTS

dmmp_pg
Pointeur de 'struct dmmp_path_group'. Si ce pointeur est NULL, votre programme sera terminé par assert.

DESCRIPTION

Le sélecteur de groupe de chemins détermine quel chemin dans le groupe de chemins actif sera utilisé pour la prochaine opération d'E/S.

RETOUR

const char *.
