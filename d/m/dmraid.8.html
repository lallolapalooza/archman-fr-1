DESCRIPTIO

N

dmraid découvre les périphériques de blocs et les périphériques RAID logiciels (par ex. ATARAID) en utilisant plusieurs gestionnaires de formats de métadonnées différents qui prennent en charge divers formats (par ex. la série Highpoint 37x). Il permet d'activer des ensembles RAID composés de 2 ou plusieurs périphériques RAID découverts, d'afficher les propriétés des périphériques et des ensembles (voir l'option -l pour les formats de métadonnées pris en charge). L'accès aux ensembles RAID activés se fait via les nœuds device-mapper /dev/mapper/RaidSetName. RaidSetName commence par le nom du format (voir l'option -l) ce qui permet d'accéder facilement à tous les ensembles RAID d'un format spécifique avec certaines options (par ex. -a ci-dessous)

.

OPTION

S
-a, --activate {y|n} [RAID set.
..]
Active ou désactive tout ou un ensemble RAID logiciel particulier. Active ou désactive automatiquement la surveillance des périphériques, sauf si l'option [-I|--ignoremonitoring] est donnée en même temps, empêchant ainsi toute interaction avec le démon de surveillance des périphériques dmeventd. Si -I est utilisé lors de l'activation initiale d'un ensemble RAID, -ay peut être utilisé plus tard pour activer la surveillance des périphériques sur de tels ensembles RAID actifs si le format RAID le prend en charge. Voir dmevent_tool(8) pour la gestion de la surveillance des périphériques via cet outil. Si des gestionnaires de formats de métadonnées sont choisis avec -f, seuls les ensembles RAID avec ces formats peuvent être activés ou désactivés. Utile si les périphériques ont plusieurs signatures de métadonnées. Lors de l'activation des ensembles RAID, -p désactive l'activation des partitions sur ceux-ci, et -Z fera dire à dmraid au noyau de supprimer les partitions des disques sous-jacents à l'ensemble, c'est-à-dire si sda fait partie de l'ensemble, supprimer sda1, sda2, etc. Cela empêche les applications d'accéder directement aux disques en contournant dmraid. Les noms d'ensemble RAID donnés sur la ligne de commande n'ont pas besoin d'être entièrement spécifiés (par ex. « dmraid -ay sil » activerait tous les ensembles Silicon Image Medley RAID découverts)
.

{-r|--raid_devices} [chemin-périphérique.
..]
Liste tous les périphériques RAID découverts avec le format, le niveau de RAID, les secteurs utilisés et le décalage des données dans le périphérique. Dans le cas où un gestionnaire de format de métadonnées est choisi avec -f, seuls les périphériques RAID avec un tel format peuvent être découverts. Utile si les périphériques ont plusieurs signatures de métadonnées. Si -D est ajouté à -r, les métadonnées RAID sont déversées dans un sous-répertoire nommé dmraid.format_name (par ex. format_name = isw) dans des fichiers nommés devicename.dat. Le décalage en octets où se trouvent les métadonnées sur le périphérique est écrit dans les fichiers nommés devicename.offset et la taille du périphérique en secteurs dans les fichiers nommés devicename.size.

Si -E est ajouté à -r, les métadonnées RAID sur les périphériques sont conditionnellement effacées. Utile pour effacer d'anciennes métadonnées après qu'un nouveau type différent a été stocké sur un périphérique afin d'éviter de les découvrir toutes les deux. Si vous entrez l'option -E, -D sera appliqué afin d'avoir un secours au cas où les mauvaises métadonnées ont été effacées. Une copie manuelle sur le périphérique est nécessaire pour récupérer après l'effacement des mauvaises métadonnées en utilisant les fichiers déversés devicename_formatname.dat et devicename_formatname.offset. Par exemple, pour restaurer tous les fichiers *.dat du répertoire de travail vers les périphériques respectifs

:

for f in *.dat
do
dd if=$f of=/dev/${f%%.dat} \
seek=`cat ${f%%dat}offset` bs=1
don

S

« dmraid -l » liste tous les formats de métadonnées pris en charge avec leurs noms ainsi que quelques informations descriptives, par ex. :
hpt37x : (+) Highpoint HPT37X
hpt45x : (+) Highpoint HPT45X
isw : (+) Intel Software RAID
lsi : (0) LSI Logic MegaRAID
nvidia : (+) NVidia RAID
pdc : (+) Promise FastTrack
sil : (+) Silicon Image(tm) Medley(tm)
via : (+) VIA Software RAID
dos : (+) Partitions DOS sur RAID logiciels
(0) : Découvrir, (+) : Découvrir+Active

r

« dmraid -ay » active tous les groupes RAID logiciels

découverts.

« dmraid -an » désactive tous les groupes RAID logiciels actifs qui ne sont pas ouverts (par ex., système de fichiers monté dessus)

.

« dmraid -ay -f pdc » (pdc trouvé via « dmraid -l ») active tous les groupes RAID logiciels au format Promise découverts et ignore tous les autres formats pris en

charge.

« dmraid -r » découvre tous les périphériques RAID logiciels pris en charge sur votre système, par ex. :
