DMTCP_COORDINATOR(1) Point de contrôle distribué multithreadé DMTCP_COORDINATOR(1)

NOM

dmtcp_coordinater -- coordonne les points de contrôle entre plusieurs processus.

SYNTAXE

dmtcp_coordinater [OPTIONS]

DESCRIPTION

dmtcp_coordinator coordonne les points de contrôle entre plusieurs processus.

OPTIONS

-p,

--coord-port port (variable d'environnement DMTCP_COORD_PORT)
Port sur lequel écouter (par défaut : 7779)
--port-file nom_fichier

Fichier où écrire le numéro de port d'écoute. (Utile avec --coord-port 0, qui est utilisé pour assigner un port aléatoire)
--ckptdir chemin (variable d'environnement DMTCP_CHECKPOINT_DIR)

Répertoire pour stocker dmtcp_restart_script.sh (par défaut : ./)
--tmpdir chemin (variable d'environnement DMTCP_TMPDIR)

Répertoire pour stocker les fichiers temporaires (par défaut : variable d'environnement TMPDIR ou /tmp)
--exit-on-last

Quitter automatiquement lorsque le dernier client se déconnecte
--exit-after-ckpt

Quitter automatiquement après la création du point de contrôle
--daemon

S'exécuter silencieusement en arrière-plan après s'être détaché du processus parent.
-i,

--interval <val> (variable d'environnement DMTCP_CHECKPOINT_INTERVAL)
Temps en secondes entre les points de contrôle automatiques (par défaut : 0, désactivé)
-q, --quiet

Ignorer l'avis de copyright.
--help

Afficher ce message et quitter.
--version

Afficher les informations de version et quitter.

Commandes pour le Coordinateur

l: Lister les nœuds connectés
s: Afficher le message d'état
c: Effectuer un point de contrôle de tous les nœuds
i: Afficher l'intervalle de point de contrôle actuel
(Pour modifier l'intervalle de point de contrôle, utilisez dmtcp_command)
k: Tuer tous les nœuds
q: Tuer tous les nœuds et quitter
?: Afficher ce message
