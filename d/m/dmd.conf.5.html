NOM

dmd.conf - fichier de configuration pour dmd(1)

SYNTAXE

/etc/dmd.conf

DESCRIPTION

dmd recherchera le fichier d'initialisation dmd.conf dans les répertoires suivants :

1.
Le répertoire de travail courant.
2.
$HOME
3.
Le répertoire contenant l'exécutable dmd.
4.
/etc

S'il est trouvé, les paramètres des variables d'environnement dans le fichier remplaceront toutes les configurations existantes.

Ceci est utile pour rendre dmd indépendant des programmes qui utilisent les variables d'environnement de manière conflictuelle.

SYNTAXE DU FICHIER

Les variables d'environnement suivent l'en-tête [Environment], sous forme de paires nom=valeur ou nom?=valeur. Les commentaires sont des lignes commençant par ;. Les noms de variables sont toujours convertis en majuscules, donc si vous utilisez name=value, c'est en fait la variable avec le nom NAME qui sera écrite. Si la syntaxe nom?=valeur est utilisée, la variable avec NAME ne sera écrite que si elle était définie auparavant (dans ce cas, la valeur originale est préservée).

EXEMPLE

; fichier dmd.conf pour dmd

; Les noms entourés de %% sont recherchés dans l'environnement existant

; et insérés. Le nom spécial %@P% est remplacé par le chemin

; de ce fichier.

[Environment]

DFLAGS="-I%@P%/../src/phobos"

FICHIERS

/etc/dmd.conf
