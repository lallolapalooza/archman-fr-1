DMTCP_LAUNCH(1) Checkpointing multi-threadé distribué DMTCP_LAUNCH(1)

NOM

dmtcp_launch -- lance un processus sous le contrôle de DMTCP.

SYNTAXE

dmtcp_launch [OPTIONS] <commande> [args...]

DESCRIPTION

dmtcp_launch lance un processus sous le contrôle de DMTCP.

Une utilisation typique est :
rm ckpt_a.out_*.dmtcp # Supprime toute copie obsolète de l'image de checkpoint
dmtcp_launch --interval 5 a.out
dmtcp_command --checkpoint # Exécuter dans une autre fenêtre
# Tue le processus a.out en cours d'exécution
dmtcp_restart ckpt_a.out_*.dmtcp

OPTIONS

Connexion au coordinateur DMTCP

-h, --coord-host nomhote (variable d'environnement DMTCP_COORD_HOST)

Nom d'hôte où dmtcp_coordinator est exécuté (défaut : localhost)
-p, --coord-port port (variable d'environnement DMTCP_COORD_PORT)

Port où dmtcp_coordinator est exécuté (défaut : 7779)
--port-file nomfichier

Fichier dans lequel écrire le numéro de port de l'écouteur. (Utile avec --coord-port 0, qui est utilisé pour attribuer un port aléatoire)
-j, --join

Rejoindre un coordinateur existant, générer une erreur si aucun n'existe déjà
--new-coordinator

Créer un nouveau coordinateur au port donné. Échouer si un port existe déjà sur le port donné. Le port peut être spécifié avec --coord-port, ou avec la variable d'environnement DMTCP_COORD_PORT. Si aucun port n'est spécifié, démarrer le coordinateur à un port aléatoire (équivalent à spécifier le port '0').
--no-coordinator

Exécuter le processus en mode autonome sans coordinateur.
Utiliser dmtcp_command ou --interval pour demander des checkpoints.
-i, --interval secondes (variable d'environnement DMTCP_CHECKPOINT_INTERVAL)

Temps en secondes entre les checkpoints automatiques. 0 signifie jamais (checkpoint manuel seulement); si non défini et aucune variable d'environnement, utiliser la valeur par défaut définie dans dmtcp_coordinator ou dmtcp_command. Non autorisé si --join est spécifié

Génération d'image de checkpoint

--gzip, --no-gzip (variable d'environnement DMTCP_GZIP=[01])

Activer/désactiver la compression des images de checkpoint (défaut : 1 (activé))
ATTENTION : gzip ajoute des secondes. Sans gzip, le checkpoint est souvent < 1s
--ckptdir chemin (variable d'environnement DMTCP_CHECKPOINT_DIR)

Répertoire pour stocker les images de checkpoint (défaut : répertoire courant au lancement)
--ckpt-open-files

Checkpoint des fichiers ouverts et restauration de l'ancien répertoire de travail. (défaut : ne fait ni l'un ni l'autre)
--checkpoint-open-files

Obsolète. Utiliser --ckpt-open-files à la place.
--ckpt-signal numéro_de_signum

Numéro de signal utilisé en interne par DMTCP pour le checkpointing (défaut : 12)
--ckpt-signal numéro_de_signum

Obsolète. Utiliser --ckpt-signal à la place.

Activer/désactiver les plugins

--with-plugin plugins (variable d'environnement DMTCP_PLUGIN)

Liste de plugins DMTCP séparés par des deux-points à précharger avec DMTCP. (Les chemins absolus sont requis.)
--batch-queue, --rm

Activer le support pour les gestionnaires de ressources (Torque PBS et SLURM). (défaut : désactivé)
--ptrace

Activer le support pour l'appel système PTRACE pour gdb/strace etc. (défaut : désactivé)
--modify-env

Mettre à jour les variables d'environnement en fonction de l'environnement sur l'hôte de redémarrage (par exemple, DISPLAY=$DISPLAY). Ceci peut être défini dans un fichier dmtcp_env.txt. (défaut : désactivé)
--ib, --infiniband

Activer le plugin InfiniBand. (défaut : désactivé)
--disable-alloc-plugin (variable d'environnement DMTCP_ALLOC_PLUGIN=[01])

Désactiver le plugin d'allocation (défaut : activé).
--disable-dl-plugin (variable d'environnement DMTCP_DL_PLUGIN=[01])

Désactiver le plugin dl (défaut : activé).
--disable-all-plugins (POUR EXPERTS SEULEMENT, POUR LE DÉBOGAGE)

Désactiver tous les plugins.

Autres options

--prefix chemin

Préfixe où DMTCP est installé sur les nœuds distants.
--tmpdir chemin (variable d'environnement DMTCP_TMPDIR)

Répertoire pour stocker les fichiers temporaires (défaut : $TMDPIR/dmtcp-$USER@$HOST ou /tmp/dmtcp-$USER@$HOST)
-q, --quiet (ou définir la variable d'environnement DMTCP_QUIET = 0, 1, ou 2)

Ignorer les messages NOTE; si donné deux fois, ignorer aussi les AVERTISSEMENTS
--help

Afficher ce message et quitter.
--version

Afficher les informations de version et quitter.
