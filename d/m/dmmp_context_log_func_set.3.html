dmmp_context_log_func_set(3) API Device Mapper Multipath - Manuel libdmmp dmmp_context_log_func_set(3)

NOM

dmmp_context_log_func_set - Définit la fonction de gestion des logs.

SYNTAXE

void dmmp_context_log_func_set (struct dmmp_context *ctx, void (*log_func) (struct dmmp_context *ctx, int priority, const char *file, int line, const char *func_name, const char *format, va_list args));

ARGUMENTS

ctx
Pointeur vers 'struct dmmp_context'. Si ce pointeur est NULL, votre programme sera terminé par un assert.
log_func
Pointeur vers la fonction de gestion des logs. Si défini à NULL, tous les logs seront ignorés.

DESCRIPTION

Définit un gestionnaire de logs personnalisé. Le gestionnaire de logs sera appelé lorsqu'un message de log est égal ou plus important (valeur plus faible) que le réglage de priorité des logs. Veuillez consulter la page de manuel libdmmp.h(3) pour plus de détails sur l'utilisation.

RETOUR

void
