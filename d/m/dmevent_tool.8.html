NOM

dmevent_tool - Un utilitaire utilisé pour charger une DSO dans dmeventd et enregistrer/désenregistrer des périphériques auprès de lui pour la surveillance

SYNTAXE

dmevent_tool -[Vhmru] {nom du périphérique RAID} {Nom de la DSO}

DESCRIPTION

dmevent_tool est un utilitaire en espace utilisateur utilisé pour enregistrer/désenregistrer des DSO auprès du démon dmeventd.

S'il est utilisé avec le paramètre de ligne de commande -m, les utilisateurs peuvent afficher tous les périphériques activement surveillés par dmeventd.

OPTIONS

-V Afficher la version de dmevent_tool

-{h/?} Afficher ces informations d'aide

-m[r|u] Lister tous les périphériques de mappage de périphériques actuellement actifs
et leur statut actuel avec dmeventd
pour les périphériques enregistrés (-r)/désenregistrés (-m)
Syntaxe : dmevent_tool -m[u|r]

-a[r|u] Identique à -m, mais uniquement pour les périphériques avec UUID !
Syntaxe : dmevent_tool -a[u|r]

-r Enregistrer un périphérique auprès de dmeventd
Syntaxe : dmevent_tool -r <nom du périphérique> <chemin de la bibliothèque DSO>
Exemple : dmevent_tool -r isw_abcdeh_Volume0 libdmraid-events.so

-u Désenregistrer un périphérique auprès de dmeventd
Syntaxe : dmevent_tool -u <nom du périphérique> [<chemin de la bibliothèque DSO>]
Exemple : dmevent_tool -u isw_abcdefgh_Volume0

EXEMPLES

dmevent_tool -m est utilisé pour afficher tous les périphériques activement surveillés
dmevent_tool -m
Nom du périphérique : isw_defeaigdde_Volume0_dmraid00
DSO enregistrée : libdmraid-events.so
UUID : isw_defeaigdde_Volume0_dmraid00
statut : Actif
périphérique maître #: 253
périphérique secondaire #: 0
périphérique en lecture seule : Non
nombre d'événements noyau enregistrés : 0
disques SATA dans ce groupe de volumes : /dev/sdb /dev/sdc

dmevent_tool -r est utilisé pour enregistrer un périphérique de groupe de volumes auprès de dmeventd
dmevent_tool -r isw_defeaigdde_Volume0_dmraid00 libdmraid-events.so

dmevent_tool -u est utilisé pour désenregistrer un groupe de volumes de dmeventd
dmevent_tool -u isw_defeaigdde_Volume0_dmraid00

DIAGNOSTIC

dmevent_tool renvoie un code de sortie de 0 en cas de succès ou 1 en cas d'erreur.
