NOM

dmmp_context_log_priority_set - Définir la priorité de journalisation.

SYNTAXE

void dmmp_context_log_priority_set (struct dmmp_context *ctx, int priority);

ARGUMENTS

ctx
Pointeur de 'struct dmmp_context'. Si ce pointeur est NULL, votre programme sera terminé par un assert.
priority
int, priorité de journalisation.

DESCRIPTION

Lorsque la bibliothèque génère un message de journalisation, seuls les messages de priorité égale ou supérieure (valeur inférieure) seront transmis à la fonction de gestionnaire de journalisation. Les valeurs de priorité de journalisation valides sont :

* DMMP_LOG_PRIORITY_ERROR -- 3

* DMMP_LOG_PRIORITY_WARNING -- 4

* DMMP_LOG_PRIORITY_INFO -- 5

* DMMP_LOG_PRIORITY_DEBUG -- 7

RETOUR

void
