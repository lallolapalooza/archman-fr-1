d2i_SSL_SESSION(3ssl)

Paquet: openssl

Licences: Apache-2.0

D2I_SSL_SESSION(3ssl) OpenSSL D2I_SSL_SESSION(3ssl)

NOM

d2i_SSL_SESSION, d2i_SSL_SESSION_ex, i2d_SSL_SESSION - convertir un objet SSL_SESSION de/vers sa représentation ASN1

SYNOPSIS

#include <openssl/ssl.h>
SSL_SESSION *d2i_SSL_SESSION(SSL_SESSION **a, const unsigned char **pp,
                             long length);
SSL_SESSION *d2i_SSL_SESSION_ex(SSL_SESSION **a, const unsigned char **pp,
                                long length, OSSL_LIB_CTX *libctx,
                                const char *propq);
int i2d_SSL_SESSION(SSL_SESSION *in, unsigned char **pp);

DESCRIPTION

Ces fonctions décodent et encodent un objet SSL_SESSION. Pour les détails de l'encodage, voir d2i_X509(3).

Les objets SSL_SESSION conservent des informations de liaison internes concernant la liste de cache de session, lorsqu'ils sont insérés dans le cache de session d'un objet SSL_CTX. Un objet SSL_SESSION, quel que soit son compteur de références, ne doit donc être utilisé qu'avec un seul objet SSL_CTX (et les objets SSL créés à partir de cet objet SSL_CTX).

VALEURS DE RETOUR

d2i_SSL_SESSION() et d2i_SSL_SESSION_ex() retournent un pointeur vers le nouvel objet SSL_SESSION alloué. En cas d'échec, le pointeur NULL est retourné et le message d'erreur peut être récupéré de la pile d'erreurs.

i2d_SSL_SESSION() retourne la taille de la représentation ASN1 en octets. Lorsque la session n'est pas valide, 0 est retourné et aucune opération n'est effectuée.

VOIR AUSSI

ssl(7), SSL_SESSION_free(3), SSL_CTX_sess_set_get_cb(3), d2i_X509(3)

HISTORIQUE

La fonction d2i_SSL_SESSION_ex() a été ajoutée dans OpenSSL 3.2.
