d2i_PKCS8PrivateKey_bio(3ssl)

NOM

d2i_PKCS8PrivateKey_bio, d2i_PKCS8PrivateKey_fp, i2d_PKCS8PrivateKey_bio, i2d_PKCS8PrivateKey_fp, i2d_PKCS8PrivateKey_nid_bio, i2d_PKCS8PrivateKey_nid_fp - Fonctions pour la clé privée au format PKCS#8

#include <openssl/pem.h>
EVP_PKEY *d2i_PKCS8PrivateKey_bio(BIO *bp, EVP_PKEY **x, pem_password_cb *cb, void *u);
EVP_PKEY *d2i_PKCS8PrivateKey_fp(FILE *fp, EVP_PKEY **x, pem_password_cb *cb, void *u);
int i2d_PKCS8PrivateKey_bio(BIO *bp, const EVP_PKEY *x, const EVP_CIPHER *enc,
                            char *kstr, int klen,
                            pem_password_cb *cb, void *u);
int i2d_PKCS8PrivateKey_fp(FILE *fp, const EVP_PKEY *x, const EVP_CIPHER *enc,
                           char *kstr, int klen,
                           pem_password_cb *cb, void *u);
int i2d_PKCS8PrivateKey_nid_bio(BIO *bp, const EVP_PKEY *x, int nid,
                                char *kstr, int klen,
                                pem_password_cb *cb, void *u);
int i2d_PKCS8PrivateKey_nid_fp(FILE *fp, const EVP_PKEY *x, int nid,
                               char *kstr, int klen,
                               pem_password_cb *cb, void *u);

DESCRIPTION

Les fonctions PKCS#8 encodent et décodent les clés privées au format PKCS#8 en utilisant les algorithmes de chiffrement par mot de passe PKCS#5 v1.5 et PKCS#5 v2.0.

À part l'utilisation de DER par opposition à PEM, ces fonctions sont identiques aux fonctions PEM correspondantes décrites dans PEM_read_PrivateKey(3).

NOTES

Ces fonctions sont actuellement la seule façon de stocker des clés privées chiffrées en utilisant le format DER.

Actuellement, toutes les fonctions utilisent des BIO ou des pointeurs de fichiers, il n'y a pas de fonctions qui supportent la protection par mot de passe et travaillent directement sur la mémoire : cela peut être facilement contourné en convertissant les tampons en BIO mémoire, voir BIO_s_mem(3) pour les détails. Si la protection par mot de passe n'est pas requise, la fonction i2d_PKCS8PrivateKey(3) encode une clé privée sous forme DER PKCS#8 non chiffrée.

Ces fonctions ne font aucune supposition concernant la phrase secrète reçue du callback de mot de passe. Elle sera simplement traitée comme une séquence d'octets.

VALEUR DE RETOUR

d2i_PKCS8PrivateKey_bio() et d2i_PKCS8PrivateKey_fp() retournent une structure EVP_PKEY valide ou NULL si une erreur s'est produite.

i2d_PKCS8PrivateKey_bio(), i2d_PKCS8PrivateKey_fp(), i2d_PKCS8PrivateKey_nid_bio() et i2d_PKCS8PrivateKey_nid_fp() retournent 1 en cas de succès ou 0 en cas d'erreur.

VOIR AUSSI
