DESCRIPTIO

N

d2 compile et rend file.d2 vers file.svg | file.png | file.pdf | file.pptx | file.gif | file.t

xt.

La valeur par défaut est file.svg si aucun chemin de sortie n'est

passé.

Passez - pour que d2 lise depuis stdin ou écrive vers

stdout.

N'utilisez jamais la présence du fichier de sortie pour vérifier le succès. Utilisez toujours le code de sortie de d2. En effet, parfois lorsqu'une erreur survient pendant le rendu, d2 écrit quand même un rendu partiel afin de permettre l'itération sur un diagramme

défectueux.

Voir plus de documentation, le code source et la licence sur https://oss.terrastru

ct.com/d2.

Icônes hébergées sur https://icons.terras

truct.com.

Exécuteur du playground sur https://play

.d2lan
g.com.

OPTION

S
-w, --watch fal
se
Surveille les modifications de l'entrée et recharge en direct. Utilisez $PORT et $HOST pour spécifier l'adresse
d'écoute.
-h, --host localho
st
Adresse d'écoute de l'hôte lorsqu'elle est utilisée avec watc
h.
-p, --port
0
Port d'écoute lorsqu'il est utilisé avec watc
h.
-t, --theme
0
Définit l'ID du thème du
diagramme.
--dark-theme -
1
Le thème à utiliser lorsque le navigateur du visualiseur est en mode sombre. Lorsqu'il est laissé non défini --theme est utilisé à la fois pour le mode clair et le mode sombre. Notez que les styles explicites définis dans le code D2 seront toujours appliqués et cela peut produire des résultats inattendus. Nous prévoyons de résoudre ce problème en rendant les cartes de style de D2 spécifiques au mode clair/sombre. Voir https://github.com/terrastruct/d2/issues/8
31.
-s, --sketch fal
se
Rend le diagramme pour qu'il ait l'air d'être esquissé à la
main.
--center fl
ag
Centre le SVG dans la viewbox conteneur, comme l'écran de votre
navigateur.
--scale -
1
Met l'échelle de la sortie. Ex. 0.5 pour diviser la taille par deux. La valeur par défaut -1 signifie que les SVG s'adapteront à l'écran et tous les autres utiliseront leur taille de rendu par défaut. La valeur 1 désactive l'adaptation des SVG à
l'écran.
--font-regul
ar
Chemin vers le fichier .ttf à utiliser pour la police régulière. Si aucun n'est fourni, Source Sans Pro Regular est
utilisé.
--font-ital
ic
Chemin vers le fichier .ttf à utiliser pour la police italique. Si aucun n'est fourni, Source Sans Pro Regular-Italic est
utilisé.
--font-bo
ld
Chemin vers le fichier .ttf à utiliser pour la police grasse. Si aucun n'est fourni, Source Sans Pro Bold est
utilisé.
--font-semib
old
Chemin vers le fichier .ttf à utiliser pour la police semi-grasse. Si aucun n'est fourni, Source Sans Pro Semibold est
utilisé.
--font-mo
no
Chemin vers le fichier .ttf à utiliser pour la police à chasse fixe. Si aucun n'est fourni, Source Code Pro Regular est
utilisé.
--font-mono-b
old
Chemin vers le fichier .ttf à utiliser pour la police à chasse fixe grasse. Si aucun n'est fourni, Source Code Pro Bold est
utilisé.
--font-mono-ita
lic
Chemin vers le fichier .ttf à utiliser pour la police à chasse fixe italique. Si aucun n'est fourni, Source Code Pro Italic est
utilisé.
--font-mono-semib
old
Chemin vers le fichier .ttf à utiliser pour la police à chasse fixe semi-grasse. Si aucun n'est fourni, Source Code Pro Semibold est
utilisé.
--pad 10
0
Pixels de marge autour du diagramme
rendu.
--animate-interval
0
Si spécifié, plusieurs tableaux sont regroupés en 1 SVG qui transitionne à travers chaque tableau à l'intervalle (en millisecondes). Ne peut être utilisé qu'avec les exports SVG et
GIF.
--browser tr
ue
Exécutable du navigateur que watch ouvre. La valeur 0 n'ouvre aucun
navigateur.
-l, --layout dag
re
Définit le moteur de disposition du diagramme à la chaîne passée. Pour une liste des options disponibles, exécutez layou
t.
-b, --bundle tr
ue
Regroupe tous les assets et calques dans le svg de
sortie.
--force-appendix fal
se
Un appendice pour les info-bulles et les liens est ajouté aux exports PNG car ils ne sont pas interactifs. Définir cette option à true ajoute également un appendice aux exports
SVG.
--targ
et
Tableau cible à rendre. Passez une chaîne vide pour cibler le tableau racine. Si la cible se termine par '*', elle sera rendue avec tous ses scénarios, étapes et calques. Sinon, seul le tableau cible sera rendu. Ex. --target='' pour ne rendre que le tableau racine ou --target='layers.x.*' pour rendre le calque 'x' avec tous ses
enfants.
-d, --deb
ug
Affiche les journaux de
débogage.
--img-cache tr
ue
En mode watch, les images utilisées dans les icônes sont mises en cache pour les compilations ultérieures. Cela devrait être désactivé si les images peuvent
changer.
--timeout 12
0
Le nombre maximal de secondes pendant lesquelles D2 s'exécute avant d'atteindre le délai d'attente et de se terminer. Lors du rendu d'un grand diagramme, il est recommandé pour augmenter cette
valeur.
--check fal
se
Vérifie que les fichiers spécifiés sont correctement
formatés.
--salt stri
ng
Ajoute une valeur de sel pour s'assurer que la sortie utilise des ID uniques. C'est utile lors de la génération de plusieurs diagrammes identiques destinés à être inclus dans le même document HTML, afin que les ID en double ne provoquent pas de HTML invalide. La valeur de sel est une chaîne qui sera ajoutée aux ID dans la sortie.
.
-h, --he
lp
Affiche les informations d'utilisation et se
termine.
-v, --versi
on
Affiche les informations de version et se
termine.
--stdout-format stri
ng
Définit le format de sortie lors de l'écriture sur stdout. Les formats pris en charge sont : png, svg, ascii, txt, pdf, pptx, gif. Utilisé uniquement lorsque la sortie est définie sur stdout
(-).
--no-xml-tag fal
se
Omet la balise XML (<?xml ...?>) des fichiers SVG de sortie. Utile lors de la génération de SVG pour une intégration HTML
directe.
--omit-version fal
se
omet la version de D2 de l'image
générée.
--ascii-mode extend
ed
Mode de rendu ASCII pour les sort
ies texte. Options : 'standard' (
caractères ASCII de base) ou
'extended' (caractères Unicode).
