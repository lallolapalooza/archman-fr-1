DESCRIPTIO

N

"DateTime::Span" est un module pour gérer des intervalles de dates et heures, également connus sous le nom de plages ou de périodes ("de X à Y, incluant toutes les dates et heures intermédiaires")

.

Ceci est différent d'un "DateTime::Set", qui est composé de points individuels de dates et heures par opposition à une plage. Il existe également un module "DateTime::SpanSet" pour gérer d

es ensembles
d'intervalles.

  • from_datetimes

    Crée un nouvel intervalle basé sur une date et une heure de début et

    de fin.

    Un intervalle 'fermé' inclut ses dates

    de fin : 
    $span = DateTime::Span->from_datetimes( start => $dt1, end =>
    $dt2 );

    Un intervalle 'ouvert' n'inclut pas ses dates

    de fin : 
    $span = DateTime::Span->from_datetimes( after => $dt1, before =>
    $dt2 );

    Un intervalle 'semi-ouvert' inclut l'une de ses dates

    de fin : 
    $span = DateTime::Span->from_datetimes( start => $dt1, before => $dt2 );
$span = DateTime::Span->from_datetimes( after => $dt1, end =>
    $dt2 );

    Un intervalle peut avoir seulement une date de début, ou seulement une date de fin. Ces intervalles se terminent, ou commencent, à une date imaginaire 'pour

    toujours' : 
    $span = DateTime::Span->from_datetimes( start => $dt1 );
$span = DateTime::Span->from_datetimes( end => $dt2 );
$span = DateTime::Span->from_datetimes( after => $dt1 );
$span = DateTime::Span->from_datetimes( before =>
    $dt2 );

    Vous ne pouvez pas fournir à la fois un argument "start" et "after", ni un argument "end" et "before". L'une de ces conditions provoquera la mort de la méthode from_datetimes()

    .

    "end" est incluse dans l'intervalle. Une date et une heure passé
