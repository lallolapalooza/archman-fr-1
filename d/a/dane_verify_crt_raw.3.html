NOM

dane_verify_crt_raw - Fonction d'API

SYNTAXE

#include <gnutls/dane.h>

int dane_verify_crt_raw(dane_state_t s, const gnutls_datum_t * chain, unsigned chain_size, gnutls_certificate_type_t chain_type, dane_query_t r, unsigned int sflags, unsigned int vflags, unsigned int * verify);

ARGUMENTS

dane_state_t s
Une structure d'état DANE (peut être NULL)
const gnutls_datum_t * chain
Une chaîne de certificats
unsigned chain_size
La taille de la chaîne
gnutls_certificate_type_t chain_type
Le type de la chaîne de certificats
dane_query_t r
Données DANE à vérifier
unsigned int sflags
Indicateurs pour l'initialisation de s (si NULL)
unsigned int vflags
Indicateurs de vérification; une liste OR de dane_verify_flags_t.
unsigned int * verify
Une liste OR de dane_verify_status_t.

DESCRIPTION

C'est la fonction de bas niveau de dane_verify_crt(). Voir la fonction de haut niveau pour la documentation.

Cette fonction n'effectue aucune résolution, elle utilise les entrées mises en cache de r.

RETOUR

Un code d'erreur négatif en cas d'erreur et DANE_E_SUCCESS (0) lorsque les entrées DANE ont été analysées avec succès, indépendamment de savoir si elles ont été vérifiées (voir verify pour cette information). Si aucune entrée utilisable n'a été rencontrée, DANE_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
