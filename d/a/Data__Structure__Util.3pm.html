NOM

Data::Structure::Util - Modifier la nature des données au sein d'une structure

SYNOPSIS

use Data::Structure::Util qw(
  has_utf8 utf8_off utf8_on unbless get_blessed get_refs
  has_circular_ref circular_off signature
);
# récupérer les objets dans la structure de données
my $objects_arrayref = get_blessed( $data );
# retirer le blessing de tous les objets
unbless( $data );
if ( has_circular_ref( $data ) ) {
    print "Removing circular ref!\n";
    circular_off( $data );
}
# reconvertir en latin1 si nécessaire et possible
utf8_off( $data ) if defined has_utf8( $data );

DESCRIPTION

"Data::Structure::Util" est une boîte à outils pour manipuler les données à l'intérieur d'une structure de données. Elle peut traiter un arbre entier et effectuer l'opération demandée sur chaque élément approprié.

Par exemple : Elle peut transformer toutes les chaînes au sein d'une structure de données en utf8 ou transformer toute chaîne utf8 en retour vers l'encodage par défaut. Elle peut retirer le blessing de n'importe quelle référence. Elle peut collecter tous les objets ou détecter s'il existe une référence circulaire.

Elle est écrite en C pour une vitesse décente.

FONCTIONS

Toutes les fonctions de Data::Structure::Util opèrent sur un arbre entier. Si vous leur passez un scalaire simple, elles opéreront sur ce scalaire unique. Cependant, si vous leur passez une référence vers un hash, un tableau, ou un scalaire, elles itéreront à travers cette structure et appliqueront la manipulation à tous les éléments, et à leur tour s'il s'agit de références vers des hashes, des tableaux ou des scalaires, à tous leurs éléments, et ainsi de suite, récursivement.

Pour des raisons de vitesse, toutes les manipulations qui altèrent la structure de données effectuent une manipulation sur place, ce qui signifie que plutôt que de retourner une copie modifiée de la structure de données, la structure de données passée est celle qui a été modifiée.

Manipulation des structures de données

has_circular_ref($ref)
Cette fonction détecte si la structure de données passée possède une référence circulaire, c'est-à-dire s'il est possible, en suivant les références contenues dans la structure, de revenir à une partie de la structure de données que vous avez déjà visitée. Les structures de données qui ont des références circulaires ne seront pas automatiquement récupérées par le ramasse-miettes de Perl.

Si une référence circulaire est détectée, la fonction retourne une référence vers un élément à l'intérieur du circuit, sinon la fonction retournera une valeur fausse.

Si la version de perl que vous utilisez supporte les références faibles, alors toute référence faible trouvée dans la structure de données ne sera pas traversée, ce qui signifie que les références circulaires dont les liens ont été affaiblis avec succès ne seront pas retournées par cette fonction.

circular_off($ref)
Détecte les références circulaires dans $ref (comme ci-dessus) et affaiblit un lien dans chacune d'elles afin qu'elles puissent être correctement récupérées par le ramasse-miettes lorsque plus aucune référence externe à la structure de données n'est présente.

Cela signifie qu'une (ou plusieurs) des références dans la structure de données sera informée qu'elle ne doit pas compter dans le comptage de références. Vous devez être conscient que si vous modifiez plus tard la structure de données et ne laissez certaines de ses parties 'accessibles' que via des références affaiblies, ces parties de la structure de données seront immédiatement récupérées par le ramasse-miettes car les références affaiblies ne seront pas suffisamment fortes pour maintenir la connexion par elles-mêmes.

Le nombre de références affaiblies est retourné.

get_refs($ref)
Examine la structure de données et retourne une référence vers un tableau plat qui contient une copie de chaque référence dans la structure de données que vous avez passée.

Par exemple :

my $foo = {
    first  => [ "inner", "array", { inmost => "hash" } ],
    second => \"refed scalar",
};
use Data::Dumper;
# dire à Data::Dumper d'afficher les nœuds plusieurs fois
$Data::Dumper::Deepcopy = 1;
print Dumper get_refs( $foo );
$VAR1 = [
    { 'inmost' => 'hash' },
    [ 'inner', 'array', { 'inmost' => 'hash' } ],
    \'refed scalar',
    {
        'first'  => [ 'inner', { 'inmost' => 'hash' }, 'array' ],
        'second' => \'refed scalar'
    }
];

Comme vous pouvez le voir, la structure de données est traversée en profondeur d'abord, donc les références les plus hautes devraient être les derniers éléments du tableau. Voir get_blessed($ref) ci-dessous pour une fonction similaire pour les objets bénis.

signature($ref)
Retourne un md5 de la structure de données passée. Tout changement, aussi petit soit-il, de la structure de données causera le retour d'un md5 différent.

La fonction examine la structure, les adresses, les types de valeurs et les drapeaux pour générer la signature, ce qui signifie que même des structures de données qui sembleraient identiques lorsqu'elles sont affichées avec Data::Dumper produisent des signatures différentes :

$ref1 = { key1 => [] };
$ref2 = $ref1;
$ref2->{key1} = [];
# ceci produit le même résultat, car elles ont la même apparence
# même si ce sont des structures de données différentes
use Data::Dumper;
use Digest::MD5 qw(md5_hex);
print md5_hex( Dumper( $ref1 ) ), " ", md5_hex( Dumper( $ref2 ) ), "\n";
# cb55d41da284a5869a0401bb65ab74c1 cb55d41da284a5869a0401bb65ab74c1
# ceci produit des résultats différents
use Data::Structure::Util qw(signature);
print signature( $ref1 ), " ", signature( $ref2 ), "\n";
# 5d20c5e81a53b2be90521167aefed9db 8b4cba2cbae0fec4bab263e9866d3911

Blessing des objets

unbless($ref)
Retire le blessing de tous les objets trouvés dans la structure de données passée. Par exemple : 
my $foo = {
    'a' => bless( { 'b' => bless( {}, "c" ), }, "d" ),
    'e' => [ bless( [], "f" ), bless( [], "g" ), ]
};
use Data::Dumper;
use Data::Structure::Util qw(unbless);
print Dumper( unbless( $foo ) );
$VAR1 = {
    'a' => { 'b' => {} },
    'e' => [ [], [] ]
};

Notez que la structure cherche à l'intérieur des objets bénis d'autres objets à débénir.

get_blessed($ref)
Examine la structure de données et retourne une référence vers un tableau plat qui contient chaque objet dans la structure de données que vous avez passée. Par exemple : 
my $foo = {
    'a' => bless( { 'b' => bless( {}, "c" ), }, "d" ),
    'e' => [ bless( [], "f" ), bless( [], "g" ), ]
};
use Data::Dumper;
# dire à Data::Dumper d'afficher les nœuds plusieurs fois
$Data::Dumper::Deepcopy = 1;
use Data::Structure::Util qw(get_blessed);
print Dumper( get_blessed( $foo ) );
$VAR1 = [
    bless( {}, 'c' ),
    bless( { 'b' => bless( {}, 'c' ) }, 'd' ),
    bless( [], 'f' ),
    bless( [], 'g' )
];

Cette fonction est essentiellement la même que "get_refs" mais ne retourne que les objets bénis plutôt que tous les objets. Comme avec cette fonction, la structure de données est traversée en profondeur d'abord, donc les objets les plus hauts devraient être les derniers éléments du tableau. Notez également (comme le montre l'exemple ci-dessus) que les objets à l'intérieur d'autres objets sont retournés.

Fonctions de manipulation utf8

Ces fonctions vous permettent de manipuler l'état des drapeaux utf8 dans les scalaires contenus dans la structure de données. Des informations sur le drapeau utf8 et sa signification peuvent être trouvées dans Encode.

has_utf8($var)
Retourne $var si le drapeau utf8 est activé pour $var ou pour tout scalaire qu'une structure de données passée dans $var contient. 
print "this will be printed"  if defined has_utf8( "\x{1234}" );
print "this won't be printed" if defined has_utf8( "foo bar" );

Notez que vous ne devriez pas vérifier la véracité de la valeur de retour de cette fonction lorsque vous l'appelez avec un seul scalaire car il est possible d'avoir une chaîne "0" ou "" pour laquelle le drapeau utf8 est activé ; Puisque "undef" ne peut jamais avoir le drapeau utf8 set la fonction ne renverra jamais une valeur définie si la structure de données ne contient pas de scalaire marqué utf8.

_utf8_off($var)
Désactive récursivement le drapeau utf8 sur tous les scalaires dans $var. C'est la même chose que la fonction "_utf8_off" de Encode mais s'applique à toute chaîne dans $var. La structure de données est convertie sur place et, par commodité, la variable passée est renvoyée par la fonction.

Cette fonction n'effectue aucune conversion d'ensemble de caractères sur les chaînes stockées dans l'un des scalaires de la structure de données passée. Cela signifie que si perl stockait internement un caractère sous forme de séquence d'octets dans l'encodage utf8, chaque octet de cette séquence sera dès lors traité comme un caractère à part entière.

Par exemple :

my $emoticons = { smile => "\x{236a}" };
use Data::Structure::Util qw(_utf8_on);
print length( $emoticons->{smile} ), "\n";    # affiche 1
_utf8_off( $emoticons );
print length( $emoticons->{smile} ), "\n";    # affiche 3
_utf8_on($var)
Active récursivement le drapeau utf8 sur tous les scalaires dans $var. C'est la même chose que la fonction "_utf8_on" de Encode mais s'applique à toute chaîne dans $var. La structure de données est convertie sur place et, par commodité, la variable passée est renvoyée par la fonction.

Comme ci-dessus, cela n'effectue aucune conversion d'ensemble de caractères, ce qui signifie que sauf si votre chaîne contient les séquences d'octets utf8 valides pour les caractères que vous voulez, vous êtes dans de beaux draps. Dans certains cas des séquences d'octets incorrectes peuvent faire planter perl. En particulier, le moteur d'expressions régulières a des problèmes importants avec un utf8 invalide qui a été incorrectement marqué comme utf8. Vous devriez savoir ce que vous faites si vous utilisez cette fonction ; Envisagez d'utiliser le module Encode comme alternative.

Exemple contraire à ce qui précède :

my $emoticons = { smile => "\342\230\272" };
use Data::Structure::Util qw(_utf8_on);
print length( $emoticons->{smile} ), "\n";    # affiche 3
_utf8_on( $emoticons );
print length( $emoticons->{smile} ), "\n";    # affiche 1
utf8_on($var)
Cette routine effectue un "sv_utf8_upgrade" sur chaque scalaire chaîne dans la structure de données passée qui n'a pas le drapeau utf8 activé. Cela fera que perl changera la méthode qu'il utilise internement pour stocker la chaîne de l'encodage natif (normalement Latin-1 sauf si les locales entrent en jeu) vers un encodage utf8 et définira le drapeau utf8 pour ce scalaire. Cela signifie que les lettres d'un seul octet seront maintenant représentées par des séquences multi-octets. Cependant, tant que la "use bytes" pragma n'est pas en vigueur, la chaîne aura la même longueur car pour perl la chaîne contient toujours le même nombre de caractères (mais pas d'octets).

Cette routine est significativement différente de "_utf8_on"; Cette routine suppose que votre chaîne est encodée en utf8 mais a été marquée (à tort) comme étant dans l'encodage natif. Cette routine suppose que votre chaîne est encodée dans l'encodage natif et marquée comme telle, mais vous préféreriez qu'elle soit encodée et marquée comme utf8.

utf8_off($var)
Cette routine effectue un "sv_utf8_downgrade" sur chaque scalaire chaîne dans la structure de données passée qui a le drapeau utf8 activé. Cela fera que perl changera la méthode qu'il utilise internement pour stocker la chaîne de l'encodage utf8 vers l'encodage natif (normalement Latin-1 sauf si les locales sont utilisées) et désactivera le drapeau utf8 pour ce scalaire. Cela signifie que les séquences multi-octets qui représentent un caractère unique seront remplacées par un octet par caractère. Cependant, tant que la "use bytes" pragma n'est pas en vigueur, la chaîne aura la même longueur car pour perl la chaîne contient toujours le même nombre de caractères (mais pas d'octets).

Veuillez noter que toutes les chaînes ne peuvent pas être converties de utf8 vers l'encodage natif ; Dans le cas où le caractère utf8 n'a pas de caractère correspondant dans l'encodage natif, Perl mourra avec l'exception "Wide character in subroutine entry".

Cette routine est significativement différente de "_utf8_off"; Cette routine suppose que votre chaîne est encodée en utf8 et que vous voulez simplement la marquer comme étant dans l'encodage natif afin que perl traite chaque octet composant les séquences de caractères comme un caractère à part entière dans l'encodage natif. Cette routine suppose que votre chaîne est encodée en utf8, mais vous voulez que chaque caractère actuellement représenté par des chaînes multi-octets soit remplacé par la représentation en un seul octet du même caractère.

BOGUES

signature() est sensible à l'algorithme de randomisation des hachages

Ce module ne parcourt que les hachages, listes et références de scalaires de base. Il n'essaie rien de plus compliqué.
