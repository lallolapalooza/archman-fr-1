NOM

davix-get - Outil de téléchargement basé sur libdavix

SYNTAXE

davix-get [options]... url davix-get [options]... url fichier_local

DESCRIPTION

davix-get est un outil pour télécharger des ressources depuis des services compatibles HTTP, Webdav ou REST.
La commande supporte les protocoles Http (http(s)://), WebDav (dav(s)://) et S3 (s3(s)://).

Les ressources cibles peuvent être un fichier unique ou une collection.
Dans le cas d'une collection, toutes les sous-collections seront également téléchargées.

davix-get est propulsé par libdavix. Voir libdavix(3) pour plus de détails.

OPTIONS

Options communes :

--debug
Mode débogage
--header, -H
Ajoute un champ d'en-tête à la requête (ex : -H "Depth: 1" )
--help, -h
Affiche ce message d'aide
--metalink OPT
Support Metalink. (OPT=failover[défaut]|no)
--module, -P PLUGIN_NAME
Charge un plugin ou un profil par son nom
--redirection OPT
Support de redirection transparent. (OPT=yes[défaut]|no)
--proxy, -x URL
Serveur proxy SOCKS5 URL. (ex : socks5://login:pass@socks.example.org)
--trace
Traçe des étendues spécifiques, les options incluent :
file - Interface fichier Davix
posix - Interface POSIX Davix
xml - Sortie de l'analyseur XML
ssl - Détails SSL et certificats
header - En-têtes des requêtes HTTP
body - Corps des requêtes HTTP
chain - Informations sur les chaînes d'E/S
core - Informations sur la configuration et les outils en ligne de commande Davix
grid - Diverses informations de tiers
socket - Informations sur les sockets
locks - Informations sur le verrouillage WebDAV
all - Traçe tout
--version
Affiche la version

Options de sécurité :

--capath CA_PATH
Ajoute un répertoire d'autorité de certification supplémentaire
--cert, -E CRED_PATH
Certificat client au format PEM
--key priv_path
Clé privée au format PEM
--insecure, -k
Désactive les vérifications de credentials SSL
--userlogin
Nom d'utilisateur pour l'authentification login/mot de passe
--userpass
Mot de passe utilisateur pour l'authentification login/mot de passe
--s3secretkey
Authentification AWS S3 : clé secrète
--s3accesskey
Authentification AWS S3 : clé d'accès
--s3region
Authentification AWS S3 : région
--s3token
Jeton de sécurité AWS S3 - utilisé avec les identifiants temporaires STS
--s3alternate
Spécifiez ce drapeau si vous devez utiliser une URL S3 basée sur le chemin
--azurekey
Clé d'authentification Azure

EXEMPLES

Télécharger le contenu et l'imprimer sur stdout
davix-get http://example.org/dir1/dir2/file1

Télécharger le contenu dans un fichier local
davix-get s3://bucket.example.org/collection/file2 /tmp/file2

Télécharger le contenu dans un fichier local avec authentification VOMS dans un environnement Grid
davix-get -P grid davs://grid-storage.example.org/dir1/file1 /tmp/file1

Télécharger le contenu et l'imprimer sur stdout, en utilisant un jeton OAuth
davix-get https://example.org/dir1/tmpfile -H "Authorization: Bearer mytoken"

Télécharger une collection dans un répertoire local
davix-get dav://example.org/dir ./mydir
