NOM

Date::Manip::Examples - exemples d'utilisation de Date::Manip

DESCRIPTION

Ce document contient un certain nombre d'exemples sur la façon d'effectuer des opérations courantes avec Date::Manip. Je serai heureux d'ajouter de nouveaux exemples au fil du temps et j'accueille volontiers les suggestions et les exemples à inclure.

Dans la plupart des cas, un exemple inclura deux façons différentes d'obtenir la réponse. La première façon utilisera les nouveaux modules OO (depuis la version 6.00). La seconde utilisera l'ancienne interface fonctionnelle.

Il convient de noter que chaque fois que vous souhaitez travailler avec des fuseaux horaires alternatifs, l'interface OO est FORTEMENT recommandée car l'interface fonctionnelle ne préserve pas les informations de fuseau horaire avec la date et peut donc donner des résultats incorrects dans certains cas. Cependant, travailler dans le fuseau horaire du système devrait donner des résultats corrects.

Il convient de noter que, dans les exemples ci-dessous, il semble que la méthode OO nécessite souvent plus de lignes de code que l'interface fonctionnelle. Il existe plusieurs façons de raccourcir la méthode OO, mais pour les exemples, j'ai voulu inclure toutes les étapes explicitement.

ANALYSE D'UNE DATE

Les dates peuvent être analysées pratiquement sous n'importe quel format couramment utilisé :

Méthode OO
$date = new Date::Manip::Date;
$err = $date->parse("today");
$err = $date->parse("1st Thursday in June 1992");
$err = $date->parse("05/10/93");
$err = $date->parse("12:30 Dec 12th 1880");
$err = $date->parse("8:00pm December tenth");
Fonctionnelle
$date = ParseDate("today");
$date = ParseDate("1st Thursday in June 1992");
$date = ParseDate("05/10/93");
$date = ParseDate("12:30 Dec 12th 1880");
$date = ParseDate("8:00pm December tenth");

Le manuel Date::Manip::Date contient une liste de tous les formats valides.

ANALYSE D'UNE DURÉE

Les durées (appelées deltas) peuvent également être analysées :

Méthode OO
$delta = new Date::Manip::Delta;
$err = $delta->parse("in 12 hours");
$err = $delta->parse("-1:30:0");
$err = $delta->parse("4 business days later");
Fonctionnelle
$delta = ParseDateDelta("in 12 hours");
$delta = ParseDateDelta("-1:30:0");
$delta = ParseDateDelta("4 business days later");

POUR CALCULER LA DURÉE ENTRE DEUX DATES

$datestr1 = "Jan 30 1999 13:00 EST";
$datestr2 = "2/Mar/1999 15:30:00 +0500";
Méthode OO
$date1 = new Date::Manip::Date;
$date2 = $date1->new_date();
$err = $date1->parse($datestr1);
$err = $date2->parse($datestr2);

Pour obtenir une durée exacte entre les deux dates (exprimée uniquement en heures, minutes, secondes), utilisez :

$delta = $date1->calc($date2);

Pour obtenir une durée approximative (exprimée en années, mois, semaines, etc. en termes auxquels un humain penserait généralement), utilisez :

$delta = $date1->calc($date2,"approx");
Fonctionnelle
$date1 = ParseDate($string1);
$date2 = ParseDate($string2);

Pour obtenir une durée exacte :

$delta = DateCalc($date1,$date2);

et la durée approximative :

$delta = DateCalc($date1,$date2,1);

Le manuel Date::Manip::Calc contient des informations à ce sujet et sur d'autres types de calculs.

POUR AJOUTER UNE DURÉE À UNE DATE

Pour trouver une seconde date située une durée donnée avant ou après une première date, utilisez ce qui suit :

$datestr  = "Jan 30 1999 13:00 EST";
$deltastr = "12 hours ago";
$deltastr = "in 3 business days";
Méthode OO
$date = new Date::Manip::Date;
$delta = $date->new_delta();
$date->parse($datestr);
$delta->parse($deltastr);
$d = $date->calc($delta);
Fonctionnelle
$date = DateCalc($datestr,$deltastr);

Si le delta est un delta ouvré, il effectuera un calcul en mode ouvré.

Le manuel Date::Manip::Calc contient des informations à ce sujet et sur d'autres types de calculs.

COMPARER DEUX DATES

Pour prendre deux dates différentes et voir laquelle est la plus ancienne, faites ce qui suit :

$datestr1 = "Jan 30 1999 13:00 EST";
$datestr2 = "2/Mar/1999 15:30:00 +0500";
Méthode OO
$date1 = new Date::Manip::Date;
$date2 = $date1->new_date;
$date1->parse($datestr1);
$date2->parse($datestr2);
$date1->cmp($date2);
   => -1, 0, 1
Fonctionnelle
$date1 = ParseDate($datestr1);
$date2 = ParseDate($datestr2);
Date_Cmp($date1,$date2);
   => -1, 0, 1

POUR EXTRAIRE DES INFORMATIONS D'UNE DATE OU D'UN DELTA

Si vous avez une date ou un delta, vous pouvez en extraire des informations comme suit :

$datestr  = "1:24:08 PM EST Feb 3, 1996";
$deltastr = "12 hours ago";
Méthode OO
$date = new Date::Manip::Date;
$delta = $date->new_delta();
$date->parse($datestr);
$delta->parse($deltastr);
$str = $date->printf("It is now %T on %b %e, %Y.");
  =>  "It is now 13:24:08 on Feb  3, 1996."
$str = $delta->printf("In %hv hours, %mv minutes, %sv seconds");
  => "In -12 hours, 0 minutes, 0 seconds";
Fonctionnelle
$str = UnixDate($datestr,"It is now %T on %b %e, %Y.");
  =>  "It is now 13:24:08 on Feb  3, 1996."
$str = Delta_Format($deltastr,"In %hv hours, %mv minutes, %sv seconds");
  => "In -12 hours, 0 minutes, 0 seconds";

Le manuel Date::Manip::Date contient tous les codes de format qui peuvent être utilisés pour extraire des informations d'une date. Le manuel Date::Manip::Delta contient les codes pour un delta.

TRAVAILLER AVEC L'ÉPOQUE

Date::Manip peut facilement être utilisé pour travailler avec le nombre de secondes depuis l'époque (1er janvier 1970 00:00:00 UTC).

Si vous avez une date et que vous souhaitez savoir combien de secondes se sont écoulées depuis l'époque, vous pouvez le faire des manières suivantes :

$datestr  = "1999-04-30-15:30:00 EDT";
$secs  = 1234567;
Méthode OO
Pour savoir combien de secondes se sont écoulées à une certaine date, vous pouvez faire ce qui suit : 
$date     = new Date::Manip::Date;
$err      = $date->parse($datestr);
$str      = $date->printf('%s');
   => nombre de secondes

Pour trouver la date correspondant à un certain nombre de secondes depuis l'époque, vous pouvez utiliser ce qui suit :

$date  = new Date::Manip::Date;
$err   = $date->parse("epoch $secs");

$date contient maintenant la date souhaitée (dans le fuseau horaire local)

Fonctionnelle
Pour savoir combien de secondes se sont écoulées : 
$str = UnixDate($datestr,'%s');
  => nombre de secondes

Pour trouver la date correspondant à un nombre de secondes depuis l'époque :

$date = ParseDateString("epoch $secs");

Notez que Date::Manip fonctionne à la fois avec des secondes positives (pour les dates postérieures à l'époque) et des secondes négatives (pour les dates antérieures à l'époque).

ÉVÉNEMENTS RÉCURRENTS

Pour trouver une liste de dates où un événement récurrent se produit (même des récurrences très complexes), faites ce qui suit :

Méthode OO
# Pour trouver le 2ème mardi de chaque mois du 1er janvier 1999 au 30 avril 1999
$recur = new Date::Manip::Recur;
$start = $recur->new_date();
$end   = $recur->new_date();
$start->parse("Jan 1 1999");
$end->parse("Apr 30 1999");
$recur->parse("0:1*2:2:0:0:0",$start,$end);
@date = $recur->dates();
# Pour trouver le lundi de Pâques de 1997 à 1999
$recur = new Date::Manip::Recur;
$recur->parse("*1997-1999:0:0:0:0:0:0*EASTER,ND1");
@date = $recur->dates();
Fonctionnel
# Pour trouver le 2ème mardi de chaque mois du 1er janvier 1999 au 30 avril 1999
@date = ParseRecur("0:1*2:2:0:0:0","","Jan 1 1999","Apr 30 1999");
# Pour trouver le lundi de Pâques de 1997 à 1999.
@date = ParseRecur("*1997-1999:0:0:0:0:0:0*EASTER,ND1");

Le manuel Date::Manip::Recur contient des informations sur les événements récurrents.

TRAVAILLER AVEC DES DATES DANS UNE AUTRE LANGUE

Si vous souhaitez travailler avec des dates dans une langue autre que l'anglais (mais que vous ne travaillez qu'avec une seule langue), faites ce qui suit :

Méthode OO
$date = new Date::Manip::Date;
$date->config("Language","French","DateFormat","non-US");
$date->parse("1er decembre 1990");
Fonctionnel
Date_Init("Language=French","DateFormat=non-US");
$date = ParseDate("1er decembre 1990");

Le manuel Date::Manip::Config contient une liste de toutes les langues prises en charge (dans la section sur la variable de configuration Language). La signification de la variable de configuration DateFormat y est également incluse.

TRAVAILLER AVEC DEUX LANGUES DIFFÉRENTES

Si vous souhaitez travailler avec des dates dans deux langues (ou plus), il est FORTEMENT recommandé d'utiliser l'interface OO. L'interface fonctionnelle sera beaucoup plus lente car elle doit réinitialiser de nombreux éléments spécifiques à la langue à chaque fois que vous passez d'une langue à l'autre.

Méthode OO
$date_eng = new Date::Manip::Date;
$date_eng->config("Language","English","DateFormat","US");
$date_fre = new Date::Manip::Date;
$date_fre->config("Language","French","DateFormat","non-US");

Utilisez l'objet $date_eng pour effectuer des opérations en anglais, et l'objet $date_fre pour effectuer des opérations en français.

Fonctionnel
Si vous travaillez à la fois avec des dates françaises et anglaises, vous pouvez appeler ce qui suit pour alterner entre elles : 
Date_Init("Language=French","DateFormat=non-US");
Date_Init("Language=English","DateFormat=US");

Ceci n'est PAS recommandé. Utilisez plutôt la méthode OO.
