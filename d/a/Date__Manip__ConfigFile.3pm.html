NOM

Date::Manip::ConfigFile - fichier de configuration d'exemple

DESCRIPTION

Date::Manip est un module hautement configurable. De nombreuses options peuvent être définies dans un fichier de configuration. Ce document inclut un fichier de configuration d'exemple.

Le fichier de configuration se compose de trois sections. La première section contient les variables de configuration. Ceci est décrit plus en détail dans le document Date::Manip::Config.

La deuxième section est la section de définition des jours fériés. La troisième section est la section de définition des événements. Ces deux sections sont décrites plus en détail dans le document Date::Manip::Holidays.

EXEMPLE DE FICHIER DE CONFIGURATION

Le fichier de configuration d'exemple ci-dessous fonctionne pour les versions récentes de Date::Manip. Certaines variables de configuration peuvent changer ou être obsolètes, et d'autres peuvent ne pas fonctionner avec les versions antérieures de Date::Manip, il est donc fortement suggéré de consulter la documentation de la version de Date::Manip que vous utilisez pour confirmer les variables de configuration que vous souhaitez inclure.

################################
# VARIABLES DE CONFIGURATION
################################
# Voir la page de manuel Date::Manip::Config pour une description de toutes les
# variables de configuration.
# Pour inclure des informations de configuration à partir de fichiers de
# configuration supplémentaires :
ConfigFile              = /chemin/vers/un/autre/fichier/config
ConfigFile              = /chemin/vers/un/autre/fichier/config2
# Pour gérer d'autres langues
Language                = Français
DateFormat              = US
Encoding                =
# Définir le fuseau horaire actuel :
SetDate                 = now,America/New_York
# Définir la semaine de travail
WorkWeekBeg             = 1
WorkWeekEnd             = 5
WorkDay24Hr             = 0
WorkDayBeg              = 08:00
WorkDayEnd              = 17:00
TomorrowFirst           = 1
# Variables diverses
YYtoYYYY                = 89
FirstDay                = 1
Use_POSIX_Printf        = 0
Week1ofYear             = jan4
Printable               = 0
DefaultTime             = midnight
RecurRange              = none
################################
# JOURS FÉRIÉS
################################
# Voir la page de manuel Date::Manip::Holidays pour une description de
# cette section.
*HOLIDAYS
# JOURS FÉRIÉS FÉDÉRAUX
##################
# Vous pouvez exprimer le Jour de l'An comme le jour réel (1er janvier)
# ou le jour observé (1er janvier ou le jour de semaine le plus proche).
# Vous ne pouvez pas inclure LES DEUX car une fois qu'un jour est marqué comme
# jour férié, une deuxième définition le traitera comme un week-end
# et choisira un autre jour pour attribuer le jour férié
# (il y aurait donc deux jours désignés comme Jour de l'An).
# 1er Janvier                         = Jour de l'An
1*1:0:1:0:0:0*DWD               = Jour de l'An (observé)
# Deux façons différentes de définir le jour MLK
troisième lundi de janvier             = Anniversaire de Martin Luther King Jr.
# 1*1:3:1:0:0:0                 = Anniversaire de Martin Luther King Jr.
# Observé par les employés fédéraux à Washington D.C.
# 20 janvier                        = Jour d'inauguration
troisième lundi de février             = Anniversaire de Washington
dernier lundi de mai              = Memorial Day
1er lundi de septembre              = Fête du Travail
deuxième lundi d'octobre            = Fête de Colomb
# 4 juillet                         = Fête de l'Indépendance
1*7:0:4:0:0:0*DWD               = Fête de l'Indépendance
# 11/11                         = Jour des anciens combattants
1*11:0:11:0:0:0*DWD             = Jour des anciens combattants
# Pour définir à la fois Thanksgiving et le jour suivant, utilisez les
# deux lignes suivantes :
quatrième jeudi de novembre               = Thanksgiving
1*11:4:4:0:0:0*FD1              = Jour après Thanksgiving
# 25 décembre                        = Noël
1*12:0:25:0:0:0*DWD             = Noël
# JOURS FÉRIÉS D'EXEMPLE
##################
# Vous pouvez définir un jour férié unique en spécifiant
# le jour et l'année.
6/2/1999                        = Un jour férié spécial pour 1999
################################
# ÉVÉNEMENTS
################################
# Voir la page de manuel Date::Manip::Holidays pour une description de
# cette section.
*EVENTS
2000-02-01               = Event01
2000-02-01-12:00:00      = Event02
02-01                    = Event03
02-01 12:00:00           = Event04
1*2:0:3:13:00:00         = Event05
2000-02-05 10:00:00 ; 2000-02-05 10:59:59 = Event06
2000-02-05          ; 2000-02-06          = Event07
02-05               ; 02-06               = Event08
2000-02-07 10:00:00 ; 0:0:0:0:3:0:0       = Event09
02-07 10:00:00      ; 0:0:0:0:4:0:0       = Event10
1*2:0:7:10:00:00    ; 0:0:0:0:5:0:0       = Event11
