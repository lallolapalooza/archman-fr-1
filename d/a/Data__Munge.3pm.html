DESCRIPTIO

N

Ce module définit quelques fonctions utilitaires généralement utiles. J'en avais assez de les redéfinir ou de les contourner, alors j'ai écrit ce

module.

Fonction

list2re
LIST
Convertit une liste de chaînes en une expression rationnelle qui correspond à l'une des chaînes. Surtout utile en combinaison avec "keys". Exemple : 
my $re = list2re keys %hash;
$str =~ s/($re)/$hash{$1}
/g;

Cette fonction fait parti

culièrement attention à g
érer correctement
plusieurs cas limites :
  • Liste vide : une liste d'arguments vide donne une expression rationnelle qui ne correspond à
    • rien.
  • Chaîne vide : une liste d'arguments composée d'une seule chaîne vide donne une expression rationnelle qui correspond à la chaîne vide (et rien d'autre)
    • .
  • Préfixes : les chaînes d'entrée sont triées par longueur décroissante pour s'assurer que les correspondances plus longues sont essayées avant les correspondances plus courtes. Sinon "list2re('ab', 'abcd')" générerait "qr/ab|abcd/", qui (à lui seul) ne peut jamais correspondre à "abcd" (car "ab" est essayé en premier, et il réussit toujours là où "abcd"
    • pou

byval BLOC
SCALAIRE
Prend un bloc de code et une valeur, exécute le bloc avec $_ défini à cette valeur, et renvoie la valeur finale de $_. La valeur globale de $_ n'est pas affectée. $_ n'est pas non plus aliasée à la valeur d'entrée, donc modifier $_ dans le bloc n'affectera pas la valeur passée. Exemple : 
foo(byval { s/!/?/g } $str);
# Appelle foo() avec la valeur de $str, mais tous les '!' ont été remplacés par '?'.
# $str lui-même n'est pas
modifié.

Depuis perl 5.14, vous pouvez aussi utiliser le drapeau "

/r" : 
foo($str =~ s/!/?
/gr);

Mais "byval" fonctionne sur toutes les versions de perl et n'est pas limité à "s//

/
".
mapval BLOC
LISTE
Fonctionne comme une combinaison de "map" et "byval" ; c'est-à-dire qu'il se comporte comme "map", mais $_ est une copie, pas un alias de l'élément courant, et la valeur de retour est prise depuis $_ à nouveau (il ignore la valeur renvoyée par le bloc). Exemple : 
my @foo = mapval { chomp } @bar;
# @foo contient une copie de @bar
où tous les éléments ont été chompés. # Cela pourrait aussi s'éc
rire chomp(my @foo = @bar); mais ce n'est pas # toujours possible.
submatch
es
Renvoie une liste des chaînes capturées par la dernière correspondance de motif réussie. Normalement, vous n'avez pas besoin de cette fonction car c'est exactement ce que "m//" renvoie en contexte liste. Cependant, "submatches" fonctionne aussi dans d'autres contextes tels que le côté droit de "s//...
/e".

trim
CHAÎNE
Renvoie CHAÎNE avec tout l'espace blanc initial et final supprimé. Comme "length", elle renvoie "undef" si l'entrée est "undef

elem SCALAIRE,
RÉFÉRENCE_TABLEAU
Renvoie une valeur booléenne indiquant si SCALAIRE est un élément de RÉFÉRENCE_TABLEAU ou non. Deux scalaires sont considérés comme égaux s'ils sont tous les deux "undef", s'ils sont tous les deux des références vers la même chose, ou s'ils ne sont tous les deux pas des références et "eq" l'un à l'autre.

Ceci est implémenté comme une recherche linéaire dans RÉFÉRENCE_TABLEAU qui se termine tôt si une correspondance est trouvée (c'est-à-dire que "elem 'A', ['A', 1 .. 9999]" ne regardera même pas les éléments "1 ..

is_callable
SCALAIRE
Renvoie une valeur booléenne indiquant si SCALAIRE peut être appelé en tant que fonction. C'est le cas si SCALAIRE est soit une référence à une sous-routine (comme "\&foo" ou "sub { ... }") soit un objet avec un opérateur '&{}' surchargé (voir "*" Dereferencing" dans overload)
.
eval_string
CHAÎNE
Évalue CHAÎNE tout comme "eval" mais n'attrape pas les exceptions. Avertissement : contrairement à "eval", le code s'exécute dans une portée lexicale vide : 
my $foo = "Hello, world!\n";
eval_string 'print $foo';
# Meurt : Global symbol "$foo" requires explicit package
name

C'est-à-dire que le code évalué ne peut pas voir les variables de la portée de l'appel à "eval_string".

slurp
FILEHANDLE
Lit et retourne toutes les données restantes de FILEHANDLE sous forme de chaîne, ou "undef" s'il atteint la fin de fichier. (L'interaction avec les descripteurs de fichier non bloquants n'est actuellement pas bien définie.)

"slurp $handle" est équivalent à "do { local $/; scalar rea

dline
$handle }".
rec
BLOCK
Crée une sous-routine anonyme comme "sub BLOCK" le ferait, mais fournit à la sous-routine appelée un argument supplémentaire pouvant être utilisé pour la récursion : 
my $code = rec {
  my ($rec, $n) = @_;
  $rec->($n - 1) if $n > 0;
  print $n, "\n";
};
$code->
(4);

C'est-à-dire, lorsque la sous-routine est appelée, un premier argument implicite est passé dans $_[0] (tous les arguments normaux sont décalés d'un cran). Ce premier argument est une référence vers la sous-routine elle-même. Cette référence peut être utilisée pour appeler la récursion directement ou pour enregistrer la sous-routine comme gestionnaire dans un système d'événements, par

exemple.

Une note sur la définition de fonctions anonymes récursives : le faire correctement est plus compliqué qu'il n'y paraît au premier abord. La solution la plus simple utilisant une variable lexicale et une fermeture fuit de la mémoire car elle crée un cycle de références. À partir de perl 5.16 il existe une constante "__SUB__" qui est équivalente à $rec ci-dessus, et c'est bien ce que ce module utilise (si disponible)

.

Cependant, ce module fonctionne même sur les anciennes versions d

e perl en recourant soit à des références faibles (si dis
ponibles), soit à un schéma de « fausse récursion » qui
instancie dynamiquement une nouvelle sous-routine pour chaque app
el au lieu de créer un cycle. Ce dernier recours est plus
lent que les références faibles mais fonctionne partout.
