Toutes ces méthodes renvoient une référence de tableau contenant les données

spécifiées.

Les méthodes dont le nom contient "format" devraient renvoyer des chaînes pouvant être utilisées comme partie d'une phrase, comme "the month of July". Les valeurs en mode autonome (stand alone) sont destinées à être utilisées dans des choses comme les calendriers plutôt que dans une

phrase.

Les formes étroites (narrow) peuvent ne pas être uniques (par exemple, dans l'en-tête de colonne des jours d'un calendrier, il est acceptable d'avoir "T" pour mardi (Tuesday) et jeudi (Thursday))

.

Le nom large (wide) devrait toujours être le nom complet de l'objet en question. Le nom étroit (narrow) ne devrait comporter qu'un ou deux

caractères.

Ces méthodes renvoient une référence vers les données stockées dans l'objet de locale. Si vous modifiez le contenu de cette référence, cela affectera les données dans l'objet de locale ! Vous devriez d'ab

ord cloner les données si
vous souhaitez les modifier.

Ces méthodes renvoient des chaînes appropriées pour la "DateTime->format_cldr" méthode.

$locale->format_for($name)

Elles sont accessibles en passant un nom à "$locale->format_for(...)", où le nom est un spécificateur de format de style CLDR.

La valeur de retour est une chaîne adaptée pour être passée à "$dt->format_cldr", vous pouvez donc faire quelque chose comme ceci :

print $dt->format_cldr( $dt->locale->format_for('MMMdd') )

ce qui pour la locale "en" affichera quelque chose comme "08 Jul".

Notez que la localisation peut également inclure du texte supplémentaire spécifique à la locale. Par exemple, le format "MMMMd" pour la locale "zh" inclut les caractères chinois pour "jour" (日) et mois (月), vous obtenez donc quelque chose comme "8月23日".

$locale->available_formats

Cela devrait renvoyer une liste de tous les noms de formats qui peuvent être passés à "$locale->format_for".

Voir la documentation des locales individuelles pour les détails et les exemples de ces formats. Les noms de formats disponibles varient selon la locale.

$locale->glibc_datetime_format

$locale->glibc_date_format

$locale->glibc_date_1_format

$locale->glibc_time_format

$locale->glibc_time_12_format

Ces méthodes renvoient des chaînes appropriées pour la "DateTime->strftime" méthode. Cependant, il vous est fortement recommandé d'utiliser les autres méthodes de format, qui utilisent les données de format CLDR. Elles sont principalement incluses pour le bénéfice de DateTime::Format::Strptime.

$locale->version

La version CLDR à partir de laquelle cette locale a été générée.

$locale->prefers_24_hour_time

Renvoie un booléen indiquant si la locale préfère ou non le format 24 heures.

$locale->first_day_of_week

Renvoie un nombre de 1 à 7 indiquant le premier jour local de la semaine, avec lundi étant 1 et dimanche étant 7.

$locale->locale_data

Renvoie un clone des données d'origine utilisées pour créer cette locale sous forme de hash. Cela est ici pour faciliter la création de locales personnalisées via "DateTime::Locale-"register_data_locale>.
