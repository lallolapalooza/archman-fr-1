NOM

daxctl-list - afficher les régions Device-DAX de la plateforme, les périphériques et leurs attributs en JSON.

SYNTAXE

daxctl list [<options>]

Parcourt toutes les régions device-dax du système et liste toutes les instances de périphériques ainsi que certains de leurs attributs majeurs.

Des options peuvent être spécifiées pour limiter la sortie aux objets d'une certaine classe. Les classes sont les régions ou les périphériques. Par défaut, daxctl list sans aucune option est équivalent à :

daxctl list --devices

EXEMPLE

# daxctl list --regions --devices
{
  "id":1,
  "devices":[
    {
      "chardev":"dax1.0",
      "size":3233808384
    }
  ]
}

OPTIONS

-r, --region=

Une région device-dax est une plage de mémoire contiguë qui héberge un ou plusieurs périphériques /dev/daxX.Y, où X est l'identifiant de la région et Y est l'identifiant de l'instance du périphérique. Le mot-clé all peut être spécifié pour effectuer l'opération sur toutes les régions du système.

-d, --dev=

Spécifie le nom d'un périphérique dax, un tuple <id région>.<id instance>, ou le mot-clé all pour filtrer la liste. Par exemple, pour lister la première instance de périphérique dans la région1 :
# daxctl list --dev=1.0
{
  "chardev":"dax1.0",
  "size":3233808384
}

-D, --devices

Inclure les informations sur les instances de périphériques device-dax dans la liste (par défaut)

-M, --mappings

Inclure les informations sur les mappages des instances de périphériques device-dax dans la liste

-R, --regions

Inclure les informations sur les régions dans la liste

-i, --idle

Inclure les périphériques inactifs (non activés / de taille zéro) dans la liste

-u, --human

Par défaut, daxctl list affichera des données brutes au format entier, adaptées aux machines. Avec cette option, les nombres représentant la taille du stockage seront formatés en chaînes de caractères lisibles par l'homme avec des unités, tandis que les autres champs seront convertis en chaînes hexadécimales. Exemple :
# daxctl list
{
  "chardev":"dax1.0",
  "size":32828817408
}
# daxctl list --human
{
  "chardev":"dax1.0",
  "size":"30.57 GiB (32.83 GB)"
}
