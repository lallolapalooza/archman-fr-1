NOM

Data::Perl::Role::Bool - Classe enveloppante pour les valeurs booléennes.

VERSION

version 0.002011

SYNOPSIS

use Data::Perl qw/bool/;
my $bool = bool(0);
$bool->toggle; # 1
$bool->unset; # 0

DESCRIPTION

Cette classe fournit un wrapper et des méthodes pour interagir avec des valeurs booléennes.

MÉTHODES FOURNIES

Aucune de ces méthodes n'accepte d'arguments.

new($valeur)
Construit un nouvel objet Data::Perl::Collection::Bool initialisé avec la valeur fournie, et le retourne.
set
Définit la valeur à 1 et retourne 1.
unset
Définit la valeur à 0 et retourne 0.
toggle
Inverse la valeur. Si elle est vraie, la définit sur fausse, et vice versa.

Retourne la nouvelle valeur.

not
Équivalent de 'not $valeur'.
