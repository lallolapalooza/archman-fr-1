NOM

Date::Manip::Lang::spanish - Prise en charge de la langue espagnole.

RÉSUMÉ

Ce module contient une liste de mots et d'expressions prenant en charge la langue. Il n'est pas destiné à être utilisé directement (d'autres modules Date::Manip le chargeront au besoin).

EXPRESSIONS DE LANGUE

Voici une liste de tous les mots et expressions de langue utilisés pour écrire des heures et/ou des dates.

Toutes les chaînes ne sont pas sensibles à la casse.

Heures du matin/ après-midi
Voici une liste d'expressions utilisées pour désigner l'heure du matin ou de l'après-midi lorsqu'une heure est saisie au format 12 heures plutôt qu'au format 24 heures. Par exemple, en anglais, l'heure « 17:00 » pourrait être spécifiée comme « 5:00 PM ».

L'heure du matin et de l'après-midi peut être désignée par les ensembles de mots suivants :

AM
A.M.
PM
P.M.
Chaque ou tous
Il existe une liste de mots qui spécifient chaque occurrence de quelque chose. Ils sont utilisés dans les phrases suivantes : 
EACH Monday
EVERY Monday
EVERY month

Les mots suivants peuvent être utilisés :

cada
Prochaine/précédente/dernière occurrence
Il existe une liste de mots pouvant être utilisés pour spécifier la prochaine, la précédente, ou la dernière occurrence de quelque chose. Ces mots pourraient être utilisés dans les phrases suivantes : 
NEXT week
LAST Tuesday
PREVIOUS Tuesday
LAST day of the month

Les mots suivants peuvent être utilisés :

Prochaine occurrence :

siguiente

Occurrence précédente :

anterior

Dernière occurrence :

ultimo
último
Mots delta pour avancer/ reculer dans le temps
Lors de l'analyse des deltas, il existe des mots pouvant être utilisés pour spécifier que le delta se référera à une heure dans le futur ou à une heure dans le passé (par rapport à une date). En anglais, par exemple, vous pourriez dire : 
IN 5 days
5 days AGO

Les mots suivants peuvent être utilisés pour spécifier des deltas qui se réfèrent à des dates dans le passé ou le futur respectivement :

hace
en
later
Mode ouvré
Cela contient deux listes de mots pouvant être utilisées pour spécifier un delta standard (c'est-à-dire non ouvré) ou un delta ouvré.

Auparavant, elle était utilisée pour indiquer si le delta était approximatif ou exact, mais maintenant cette liste n'est pas utilisée sauf pour forcer le delta à être standard.

Les mots suivants peuvent être utilisés :

exactamente
aproximadamente

Les mots suivants peuvent être utilisés pour spécifier un delta ouvré :

laborales

Al escribir fechas en formas comunes, hay una serie de palabras que normalmente no son importantes.

Frecuentemente hay una palabra que aparece en una frase para indicar que se va a especificar una hora a continuación. En inglés, usarías la palabra AT en el

Palabras que establecen la
    fecha, la hora, o 
ambas
  
Hay algunas palabras que se pueden usar para especificar una fecha, una hora, o ambas
      en relación con el momento actual.
    
Las palabras que establecen la fecha son similares a las palabras en inglés
        'yesterday' o 'tomorrow'. Se especifican como un delta que se añade
        a la hora actual para obtener una fecha. La hora NO se establece, por lo que
        el delta solo se usa parcialmente (solo debería incluir los campos de año, mes, semana
        y 
día).
    
Se pueden usar las siguientes 
palabras:
        
Hoy                  0:0:0:0:0:0:0
ayer                 -0:0:0:1:0:0:0
manana               +0:0:0:1:0:0:0
mañana               +0:0:0:1:
0:0:0
    
Las palabras que establecen solo la hora del día son similares a las palabras en inglés
        'noon' o 
'midnight'.
    
Se pueden usar las siguientes 
palabras:
        
medianoche           00:00:00
mediodia             12:
00:00

        la hora y fecha

En inglés, la palabra 'now' es una de

Se pueden usar las siguientes

Al especificar la hora del día, el separador más común es los dos puntos (:) que
      se puede usar para ambos separadores.
    
Algunos idiomas usan pares diferentes. Por ejemplo, el francés permite
        especificar la hora como 13h30:20, por lo que usaría los siguientes
     
   pares:
        
: :

h :
    
La primera columna es el separador hora-minuto y la segunda
        columna es el separador minuto-segundo. Ambas son expresiones regulares de perl.
        Al crear una nueva traducción, ten en cuenta que las expresiones regulares
        con caracteres utf-8 pueden ser complicadas. Por ejemplo, no
        incluyas la expresión '[x]' donde 'x' es un carácter 
utf-8.
