NOM

Date::Manip::Interfaces - Description des interfaces fonctionnelles et orientées objet

DESCRIPTION

Il existe trois façons différentes d'utiliser Date::Manip. Une description complète de chacune est incluse ci-dessous. Elles sont :

Interface fonctionnelle (version 5)
Date::Manip version 5 fonctionne sur de très anciennes versions de perl. Si vous devez utiliser Date::Manip avec une version de perl antérieure à 5.10, c'est la seule interface disponible.
Interface fonctionnelle (version 6)
Lorsque Date::Manip a été réécrit (version 6), il a utilisé certaines fonctionnalités de perl 5.10. C'est l'interface recommandée si vous maintenez un script qui utilise l'interface fonctionnelle, mais qu'une version plus récente de perl est disponible.
Interface orientée objet
L'interface OO est l'interface recommandée dans la mesure du possible. C'est la seule qui donne accès à toutes les fonctionnalités du module.

VERSION 5 ET VERSION 6

Date::Manip version 5.xx a été disponible pendant de nombreuses années, mais souffrait de plusieurs faiblesses. Il était lent et ne gérait pas correctement les fuseaux horaires ni l'heure d'été. Il a été écrit comme interface fonctionnelle, même si une interface orientée objet aurait été préférable. Il avait l'avantage de fonctionner sur de très anciennes versions de perl (il est connu pour fonctionner sur perl 5.6 et peut fonctionner sur des versions encore plus anciennes de perl).

Date::Manip version 6.00 était une réécriture complète du module. Pour des informations détaillées sur les différences, veuillez consulter le document Date::Manip::Changes5to6. La réécriture était nécessaire pour gérer les opérations sur les fuseaux horaires, en plus de nombreuses autres améliorations, notamment de bien meilleures performances et une analyse plus robuste.

La réécriture a utilisé des fonctionnalités introduites dans perl 5.10 qui ont rendu les routines d'analyse de dates nettement plus claires. De plus, la version 6.xx a été écrite comme un ensemble de modules orientés objet qui sont beaucoup plus puissants que l'ancienne interface fonctionnelle. Pour la rétrocompatibilité, une nouvelle interface fonctionnelle a été réécrite (qui est simplement un ensemble de fonctions d'enveloppe qui appellent les méthodes OO) qui est presque entièrement rétrocompatible avec l'interface version 5.xx.

La distribution Date::Manip inclut ces trois interfaces : l'ancienne interface version 5, ainsi que la nouvelle interface OO et l'interface fonctionnelle rétrocompatible. De plus, les trois sont installées, vous pouvez donc utiliser l'interface qui convient.

Puisqu'il existe trois interfaces différentes, le choix de l'interface est nécessaire.

Si vous travaillez sur un système avec une très ancienne version de perl (antérieure à 5.10), l'interface version 5 est votre seule option.

Si vous êtes sur un système fonctionnant avec une version plus récente de perl, mais que vous devez prendre en charge un script écrit avec l'interface fonctionnelle, vous pouvez utiliser l'interface fonctionnelle version 6.

Pour tous les autres, il est fortement recommandé d'utiliser l'interface orientée objet.

Une description plus détaillée de chaque interface est incluse ci-dessous. Si vous savez déjà quelle interface vous souhaitez utiliser, rendez-vous directement à la section « VOIR AUSSI » de Date::Manip pour la documentation de chaque interface.

INTERFACE FONCTIONNELLE (VERSION 5)

Lorsque vous utilisez une version de perl antérieure à 5.10, c'est la seule interface disponible. Cette interface est documentée dans le document Date::Manip::DM5. Cette interface a plusieurs faiblesses qu'il faut comprendre lors de son utilisation :

Support limité
L'interface fonctionnelle version 5 n'est plus développée et seul un support limité est disponible.

Depuis décembre 2012, aucun développement ne sera fait et je ne corrigerai aucun bug restant dans la version 5. Si un correctif est fourni par quelqu'un d'autre pour corriger des bugs, je l'appliquerai, à condition qu'il s'applique proprement et que le code résultant continue de passer tous les tests. Je n'appliquerai pas de correctifs pour ajouter des fonctionnalités.

J'ai l'intention de le supprimer dans la version 7.00.

Support limité des fuseaux horaires
Le support des fuseaux horaires est extrêmement limité et souvent incorrect. Le manque de support des fuseaux horaires était la raison principale de la réécriture de Date::Manip.

L'interface version 5 ne gère pas correctement les changements d'heure d'été.

Problèmes de performance
Un temps considérable a été consacré à l'accélération de Date::Manip et des tests de performance assez simples montrent que la version 6 est environ deux fois plus rapide que la version 5.

N'hésitez pas à m'envoyer un e-mail pour vos préoccupations et commentaires.

INTERFACE FONCTIONNELLE (VERSION 6)

L'interface fonctionnelle version 6 est presque entièrement identique à l'interface fonctionnelle version 5, sauf qu'elle utilise les modules orientés objet pour faire tout le vrai travail.

Le support des fuseaux horaires est grandement amélioré, mais reste quelque peu limité. Puisque l'interface version 6 est rétrocompatible, les dates ne stockent pas d'informations de fuseau horaire en elles-mêmes, donc le programmeur est responsable de garder la trace du fuseau horaire de chaque date. Si vous voulez un accès complet au support des fuseaux horaires offert par Date::Manip, vous devez utiliser l'interface orientée objet.

Pour la plupart, les scripts écrits pour les anciennes versions de Date::Manip continueront de fonctionner (et les scripts écrits pour l'interface fonctionnelle version 6 fonctionneront avec l'interface version 5), cependant dans quelques cas, vous devrez peut-être modifier vos scripts. Veuillez consulter le document Date::Manip::Migration5to6 pour une liste des changements qui peuvent être nécessaires.

INTERFACE ORIENTÉE OBJET

Depuis la version 6.00, Date::Manip se compose d'un ensemble de modules OO. Chacun a son propre document (voir la section « VOIR AUSSI » de Date::Manip).

L'interface OO se compose des modules suivants : Date::Manip::Date, Date::Manip::Delta, Date::Manip::Recur, Date::Manip::TZ et Date::Manip::Base.

L'interface orientée objet est le seul moyen d'obtenir toutes les fonctionnalités de Date::Manip. Elle supporte pleinement les fuseaux horaires (et l'heure d'été).

SÉLECTION D'UNE INTERFACE

Si vous utilisez une ancienne version de perl, l'interface fonctionnelle version 5 est la seule disponible pour vous, et elle sera utilisée automatiquement.

Si vous utilisez une version plus récente de perl (5.10 ou supérieure), vous pouvez utiliser les modules orientés objet en les chargeant directement, ou vous pouvez utiliser une interface fonctionnelle.

Si vous utilisez une interface fonctionnelle, elle utilisera par défaut l'interface version 6, mais vous pouvez choisir d'exécuter l'interface version 5 de l'une des trois manières suivantes :

Utiliser l'interface OO
En incluant l'un des éléments suivants : 
use Date::Manip::Date;
use Date::Manip::Delta;
use Date::Manip::Recur;
use Date::Manip::TZ;
use Date::Manip::Base;

vous avez accès à l'interface OO pour les types d'objets appropriés.

Utiliser l'interface fonctionnelle par défaut
En incluant : 
use Date::Manip;

dans votre script, l'une des interfaces fonctionnelles sera chargée. Si vous utilisez une version de perl antérieure à 5.10, ce sera automatiquement l'interface version 5. Si vous utilisez une version plus récente de perl, l'interface version 6 sera chargée automatiquement.

Variable d'environnement DATE_MANIP
En définissant la variable d'environnement DATE_MANIP à 'DM5' avant d'exécuter le script perl, l'interface version 5 sera utilisée.
Variable Date::Manip::Backend
Alternativement, vous pouvez définir la variable Date::Manip::Backend à 'DM5' avant de charger le module. Typiquement, cela sera de la manière suivante : 
BEGIN {
     $Date::Manip::Backend = 'DM5';
}
use Date::Manip;

Une fois qu'une interface fonctionnelle est chargée, vous ne pouvez plus basculer entre les interfaces version 5 et version 6.
