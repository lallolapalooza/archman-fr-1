NOM

dab — Jeu de Dots and Boxes

SYNTAXE

dab [niveau]

DESCRIPTION

dab est un jeu où chaque joueur essaie de compléter le plus de cases. Un tour consiste à placer une bordure d'une case ; le joueur qui place la quatrième et dernière bordure d'une case obtient le point pour cette case et a un autre tour.

Les touches utilisées sont les touches de vi : k pour haut, j pour bas, h pour gauche, et l pour droite. ⟨espace⟩ place une nouvelle bordure, q quitte le jeu.

Option de support : niveau définit le niveau de départ.
