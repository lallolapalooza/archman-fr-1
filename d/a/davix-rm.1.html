DAVIX-RM(1) outil de suppression DAVIX-RM(1)

NOM

davix-rm - Outil de suppression basé sur libdavix.

SYNTAXE

davix-rm [options]... url

DESCRIPTION

davix-rm est un outil pour supprimer des ressources sur des services compatibles HTTP, Webdav ou REST.
Les commandes peuvent supprimer des ressources et des conteneurs de ressources.
Il prend en charge les protocoles Http (http(s)://), WebDav (dav(s)://) et S3 (s3(s)://).

davix-rm est alimenté par libdavix. Voir libdavix(3) pour plus de détails.

OPTIONS

Options communes :

--debug
Mode de débogage
--header, -H
Ajouter un champ d'en-tête à la requête (ex : -H "Depth: 1" )
--help, -h
Afficher ce message d'aide
--metalink OPT
Support Metalink. (OPT=failover[défaut]|no)
--module, -P PLUGIN_NAME
Charger un plugin ou un profil par son nom
--redirection OPT
Support de la redirection transparente. (OPT=yes[défaut]|no)
--proxy, -x URL
Serveur proxy SOCKS5 URL. (ex : socks5://login:pass@socks.example.org)
--trace
Traces des étendues spécifiques, les options incluent :
file - Interface fichier Davix
posix - Interface POSIX Davix
xml - Sortie du parseur XML
ssl - Détails SSL et certificats
header - En-têtes des requêtes HTTP
body - Corps des requêtes HTTP
chain - Informations sur les chaînes d'E/S
core - Informations de configuration et diverses
grid - Informations diverses provenant de tiers
socket - Informations sur les sockets
locks - Informations sur le verrouillage WebDAV
all - Tout tracer
--version
Afficher la version

Options de sécurité :

--capath CA_path
Ajouter un répertoire supplémentaire d'autorités de certification
--cert, -E cred_path
Certificat client au format PEM
--key priv_path
Clé privée au format PEM
--insecure, -k
Désactiver les vérifications d'identifiants SSL
--userlogin
Identifiant utilisateur pour l'authentification par nom d'utilisateur/mot de passe
--userpass
Mot de passe utilisateur pour l'authentification par nom d'utilisateur/mot de passe
--s3secretkey
Authentification AWS S3 : clé secrète
--s3accesskey
Authentification AWS S3 : clé d'accès
--s3region
Authentification AWS S3 : région
--s3token
Jeton de sécurité AWS S3 - utilisé avec les identifiants temporaires STS
--s3alternate
Spécifiez ce drapeau si vous devez utiliser une URL S3 basée sur le chemin
--azurekey
Clé d'authentification Azure

EXEMPLES

Supprimer un fichier via http
davix-rm https://example.org/file1

Supprimer un répertoire via WebDav
davix-rm dav://webdav.example.org/collection/collection_to_delete

Supprimer une ressource sur un stockage Grid avec authentification VOMS
davix-rm -P grid davs://grid-storage.example.org/dir1/dir2/
