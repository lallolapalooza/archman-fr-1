DateTime::Format::W3CDTF(3) Documentation Perl fournie par l'utilisateur DateTime::Format::W3CDTF(3)

NOM

DateTime::Format::W3CDTF - Analyser et formater les chaînes de date/heure W3CDTF

VERSION

Ce document décrit la version 0.08 de DateTime::Format::W3CDTF

SYNOPSIS

use DateTime::Format::W3CDTF;
my $w3c = DateTime::Format::W3CDTF->new(strict => 1);
my $dt = $w3c->parse_datetime( '2003-02-15T13:50:05-05:00' );
# 2003-02-15T13:50:05-05:00
$w3c->format_datetime($dt);

DESCRIPTION

Ce module comprend le format de date/heure W3CDTF, un profil ISO 8601, défini à http://www.w3.org/TR/NOTE-datetime. Ce format est le format de date natif de RSS 1.0.

Il peut être utilisé pour analyser ces formats afin de créer les objets appropriés.

MÉTHODES

Cette API est actuellement expérimentale et pourrait changer à l'avenir.

  • new()

    Retourne un nouvel objet analyseur W3CDTF. Accepte une seule option "strict" :

    DateTime::Format::W3CDTF->new(strict => 1);

    Si vraie, parse_datetime() et format_datetime() n'accepteront et ne retourneront respectivement que des chaînes au format W3CDTF. En particulier, le format W3CDTF exige que toutes les composantes horaires aient des fuseaux horaires.

    Si fausse, les fuseaux horaires sont facultatifs.

  • parse_datetime($string)

    Étant donné une chaîne de date/heure W3CDTF, cette méthode retournera un nouvel objet "DateTime".

    Si une chaîne mal formatée est fournie, cette méthode peut planter.

  • format_datetime($datetime)

    Étant donné un objet "DateTime", cette méthode retourne une chaîne de date/heure W3CDTF.

    NOTE : Depuis la version 0.4, format_datetime n'essaie plus de tronquer les dates sans composante horaire. Ceci est dû au fait que "DateTime" ne distingue pas entre une date sans composante horaire et minuit.

  • format_date($datetime)

    Étant donné un objet "DateTime", retourne une chaîne de date/heure W3CDTF sans la composante horaire.
