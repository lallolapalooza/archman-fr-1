NOM

Data::Random::WordList - Module Perl pour obtenir des mots aléatoires à partir d'une liste de mots

SYNOPIS

use Data::Random::WordList;
my $wl = new Data::Random::WordList( wordlist => '/usr/dict/words' );
my @rand_words = $wl->get_words(10);
$wl->close();

DESCRIPTION

Data::Random::WordList est un module qui gère un fichier contenant une liste de mots.

Le module s'attend à ce que chaque ligne du fichier de liste de mots contienne un seul mot. Il pourrait ainsi être facilement utilisé pour sélectionner des lignes aléatoires d'un fichier, mais par souci de cohérence, je continuerai à désigner chaque ligne comme un mot.

Le module utilise un descripteur de fichier persistant afin qu'il n'y ait pas beaucoup de surcharge chaque fois que vous souhaitez récupérer une liste de mots aléatoires. Cependant, il est beaucoup plus efficace de récupérer plusieurs mots à la fois que d'en obtenir un seul à la fois, à plusieurs reprises.

Le module s'abstient également de lire l'intégralité du fichier en mémoire, ce qui peut le rendre plus sûr à utiliser avec de plus grands fichiers.

METHODES

new()

Retourne une référence vers un nouvel objet Data::Random::WordList. Utilisez le paramètre « wordlist » pour initialiser l'objet :

•
wordlist - le chemin d'accès au fichier de liste de mots. Si aucun chemin n'est fourni, la liste de mots distribuée avec ce module est utilisée.

get_words([NUM])

NUM contient le nombre de mots que vous souhaitez obtenir de la liste de mots. NUM vaut 1 par défaut s'il n'est pas spécifié. get_words() meurt si NUM est supérieur au nombre de mots dans la liste de mots. Cette fonction retourne un tableau ou une référence de tableau selon le contexte dans lequel elle est appelée.

close()

Ferme le descripteur de fichier associé à la liste de mots. Il est bon de le faire chaque fois que vous avez terminé avec la liste de mots.
