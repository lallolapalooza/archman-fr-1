NOM

darktable-generate-cache - mettre à jour le cache des miniatures de darktable

SYNOPSIS

darktable-generate-cache [-h, --help; --version] [-m, --max-mip <0-7>] [--core <options darktable>]

DESCRIPTION

darktable est une application de flux de travail photographique numérique pour Linux, Mac OS X et plusieurs autres Unix. Elle est décrite plus en détail dans darktable(1).

darktable-generate-cache met à jour le cache des miniatures de darktable. Vous pouvez lancer ce programme pour générer toutes les miniatures manquantes en arrière-plan lorsque votre ordinateur est inactif.

OPTIONS

Tous les paramètres sont facultatifs. S'il est lancé sans paramètres, darktable-generate-cache utilise des valeurs par défaut raisonnables.

-h, --help
Affiche les informations d'utilisation et se termine.
--version
Affiche les informations de copyright et de version et se termine.
--min-mip <0-7>
-m, --max-mip <0-7>
darktable peut gérer et stocker des miniatures avec jusqu'à huit étapes de résolution différentes pour chaque image. Ces paramètres définissent la résolution maximale qui doit être générée et sont par défaut dans la plage 0-2. Il n'est normalement pas nécessaire de générer toutes les résolutions possibles ici ; les résolutions manquantes seront automatiquement générées par darktable dès qu'elles seront nécessaires. Lorsqu'il est demandé de générer plusieurs résolutions à la fois, les images de résolution inférieure sont rapidement sous-échantillonnées à partir de l'image de plus haute résolution.
--min-imgid <N>
--max-imgid <N>
Spécifie la plage des identifiants d'image internes de la base de données à traiter. Si aucune plage n'est donnée, darktable-generate-cache traitera toutes les images de la collection entière.
--core <options darktable>
Tous les paramètres de ligne de commande suivant --core sont transmis au cœur de darktable et traités comme des paramètres standard. Voir darktable(1) pour une description détaillée des options.
