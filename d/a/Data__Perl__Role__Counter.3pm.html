Data::Perl::Role::Counter(3) Documentation Perl fournie par l'utilisateur Data::Perl::Role::Counter(3)

NOM

Data::Perl::Role::Counter - Classe d'encapsulation pour un simple compteur numérique.

VERSION

version 0.002011

SYNOPSIS

use Data::Perl qw/counter/;
my $c = counter(4);
$c->inc;   # $c == 5
$c->reset; # $c == 0

DESCRIPTION

Cette classe fournit un wrapper et des méthodes pour un simple compteur numérique.

MÉTHODES FOURNIES

new($valeur)
Construit un nouvel objet Data::Perl::Collection::Counter initialisé avec la valeur passée et le retourne.
set($valeur)
Définit le compteur à la valeur spécifiée et retourne la nouvelle valeur.

Cette méthode requiert un seul argument.

inc
inc($arg)
Augmente la valeur de l'attribut du montant de l'argument, ou de 1 si aucun argument n'est donné. Cette méthode retourne la nouvelle valeur.

Cette méthode accepte un seul argument.

dec
dec($arg)
Diminue la valeur de l'attribut du montant de l'argument, ou de 1 si aucun argument n'est donné. Cette méthode retourne la nouvelle valeur.

Cette méthode accepte un seul argument.

reset
Réinitialise la valeur stockée dans cet emplacement à sa valeur par défaut et retourne la nouvelle valeur.
