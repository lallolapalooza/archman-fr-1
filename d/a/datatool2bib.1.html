DATATOOL2BIB(1) datatool2bib DATATOOL2BIB(1)

NOM

datatool2bib [option]+ fichier-entrée fichier-bib

DESCRIPTION

Convertit un fichier .tex contenant des bases de données datatool.sty en un fichier .bib au format requis pour bib2gls. Distribué avec bib2gls.

La bibliothèque TeX Parser est utilisée pour analyser l'entrée, qui peut être un fichier DTLTEX ou DBTEX ou un fichier contenant des commandes de construction de base de données, telles que "\DTLnewdb" ou "\DTLaction". Le fichier d'entrée peut également être un fichier CSV s'il est utilisé avec --read.

Les paquets datatool et datagidx sont automatiquement implémentés afin que le fichier d'entrée n'ait pas besoin de les inclure avec "\usepackage". En général, il est préférable de ne pas inclure l'intégralité du document mais plutôt d'inclure un fichier contenant uniquement les commandes de construction de base de données, car la bibliothèque TeX Parser ne dispose que d'un ensemble limité de commandes qu'elle reconnaît.

OPTIONS

OPTIONS GÉNÉRALES

--help ou -h
Affiche le message d'aide et quitte.
--version ou -v
Affiche les informations de version et quitte.
--silent ou --quiet ou -q
Supprime tous les messages sauf les erreurs.
--verbose
Active le mode verbeux.
--no-verbose
Désactive le mode verbeux.
--debug [n]
Affiche les messages de débogage.
--debug-mode paramètre
Peut être utilisé à la place de --debug lorsque le numéro de niveau est difficile à mémoriser. Valeur identique à celle de l'option bib2gls --debug-mode .
--no-debug
Désactive le mode de débogage. Équivalent à --debug 0.
--log-file nom-fichier
Journalise les messages dans le fichier indiqué. Principalement destiné aux messages de débogage, l'activation du mode de débogage créera automatiquement un fichier de transcription, mais sinon aucun fichier ne sera créé à moins que cette option ne soit utilisée.

OPTIONS D'ENCODAGE ET DE LOCALISATION

--texenc nom
Définit l'encodage des caractères sur nom pour les fichiers .tex d'entrée.
--bibenc nom
Définit l'encodage des caractères sur nom pour les fichiers .bib de sortie.
--locale étiquette-langue
Utilise les fichiers de ressources linguistiques associés à l'étiquette de langue étiquette-languedonnée. S'il n'existe pas de fichier approprié, le fichier en (anglais) sera utilisé.

OPTIONS DE FILTRAGE

--preamble-only ou -p
Analyse uniquement le préambule du document. C'est-à-dire, arrête l'analyse si "\begin{document}" est rencontré.
--no-preamble-only
Analyse l'intégralité du document (par défaut).
--ignore-fields liste ou -f liste
Ignore tous les champs de la listeséparée par des virgules. Chaque élément de la liste doit identifier le champ par sa clé de colonne originale sensible à la casse.

Cette option est cumulative.

--no-ignore-fields
Annule l'effet de --ignore-fields.
--skip-datagidx
Ignore la base de données interne spéciale datagidx . (Par défaut.)
--no-skip-datagidx
N'ignore pas la base de données interne spéciale datagidx .

OPTIONS DE FICHIER DE SORTIE

--overwrite
Écrase les fichiers .bib existants.
--no-overwrite
N'écrase pas les fichiers .bib existants.
--split
Sépare les entrées en fichiers distincts selon la base de données.
--no-split
Ne sépare pas les entrées en fichiers distincts (par défaut).

OPTIONS D'AJUSTEMENT

--space-sub valeur ou -s valeur
Remplace les espaces dans les étiquettes par valeur.
--field-map correspondances ou -m correspondances
Ajoute des correspondances entre clés de colonnes source et étiquettes de champs de destination. L'argument doit être une liste séparée par des virgules de paires clé-colonne=champ-bib . Cette option est cumulative.
--no-field-map
Annule toutes les correspondances appliquées avec --field-map.
--index-conversion ou -i
Toutes les entrées qui seraient normalement converties en @entry et qui n'ont pas de champ description seront converties en @index.
--no-index-conversion
Ne remplace pas @entry par @index si la description est manquante (par défaut).
--detect-symbols
Tente de détecter les entrées qui devraient être @symbol ou @number en se basant sur la valeur du champ name .
--no-detect-symbols
Ne tente pas la détection des symboles (par défaut).
--label clé-colonne ou -L
Utilise la colonne identifiée par clé-colonne pour l'étiquette de l'entrée. La clé de colonne par défaut est Label donc si la base de données n'a pas de colonne avec cette clé, vous devrez soit spécifier une colonne avec --label soit utiliser --auto-label. Cette option est ignorée avec --auto-label.
--auto-label ou -a
Génère automatiquement les étiquettes des entrées au lieu d'utiliser une valeur de colonne.
--no-auto-label
Ne génère pas automatiquement les étiquettes des entrées. Utilise la colonne identifiée par --label pour l'étiquette de l'entrée. (Par défaut.)
--auto-label-prefix préfixe
Utilise préfixe lors de la génération automatique des étiquettes d'entrées. Ignoré avec --no-auto-label.
--adjust-gls
Ajuste les étiquettes dans des commandes comme "\gls" dans les valeurs de champs. (Par défaut.) Cela remplacera également les commandes datagidx.sty comme "\glsnl" par l'équivalent le plus proche dans glossaries.sty .
--no-adjust-gls
N'ajuste pas les étiquettes dans des commandes comme "\gls" dans les valeurs de champs.
--dependency-field nom-champ
Définit le nom du champ de dépendance. N'a aucun effet avec --no-strip-glsadd. Avec --strip-glsadd, l'étiquette de l'argument "\glsadd" supprimé sera ajoutée au champ identifié par nom-champ. La valeur par défaut est dependency qui sera ignorétriés par bib2gls sauf instruction contraire (via l'alias de champ, etc.).
--no-dependency-field
Ne pas enregistrer les étiquettes de toute instance "\glsadd" supprimée.
--strip
Active toutes les options de suppression.
--no-strip
Désactive toutes les options de suppression.
--strip-glsadd
Supprime "\glsadd" et son argument des valeurs de champ. (Par défaut.)
--no-strip-glsadd
Ne pas supprimer "\glsadd" des valeurs de champ.
--strip-acronym-font
Supprime "\acronymfont" des valeurs de champ. (Par défaut.)
--no-strip-acronym-font
Ne pas supprimer "\acronymfont" des valeurs de champ.
--strip-acronym-text
Supprime le champ text pour les acronymes identifiés par "\newacro". (Par défaut.)
--no-strip-acronym-text
Ne pas supprimer le champ text pour les acronymes.
--strip-acronym-name
Supprime le champ name pour les acronymes identifiés par "\newacro". (Par défaut.)
--no-strip-acronym-name
Ne pas supprimer le champ name pour les acronymes.
--strip-case-change
Supprime des valeurs de champ les commandes de changement de casse connues (telles que "\makefirstuc" ou "\capitalisewords").
--nostrip-case-change
Ne pas supprimer les commandes de changement de casse. (Par défaut.)

AUTRES OPTIONS

Ces options correspondent aux fonctionnalités introduites dans datatool.sty version 3.0, qui dispose d'un paramètre stockant la valeur numérique et le symbole de devise (le cas échéant) lors de l'analyse des données. La chaîne d'origine (nombre formaté), la valeur numérique et le symbole de devise sont stockés dans un format de donnée spécial, qui s'expande normalement vers son texte formaté d'origine mais permet aussi d'extraire facilement les informations précédemment analysées sans avoir à reanalyser les données.

--setup options
Implémente "\DTLsetup{"options"}" au début. Cela peut inclure des options telles que "store-datum", "new-value-expand", "new-value-trim" et "default-name".
--read options
Au lieu de simplement analyser le fichier d'entrée comme un fichier .tex normal, la source est présentée au analyseur TeX comme "\DTLread["options"]{"fichier-entrée"}" où les options peuvent être utilisées pour spécifier le format du fichier (par exemple, "format=tsv").

Si la liste options est vide (après suppression des espaces), cela devient équivalent à --no-read.

--no-read
Le fichier d'entrée est analysé comme un fichier .tex normal, qui peut être le document complet ou un fichier qui peut être "\input" dans un document. (Par défaut.)
--save-value suffixe
Si une valeur de champ est analysée et identifiée comme numérique, la valeur numérique non formatée sera enregistrée dans un champ dont le nom est construit à partir du nom de champ d'origine suivi du suffixedonné.
--no-save-value
Ne pas enregistrer la valeur numérique dans un champ séparé. (Par défaut.)
--save-currency suffixe
Si une valeur de champ est analysée et identifiée comme des données de devise, le symbole de devise sera enregistré dans un champ dont le nom est construit à partir du nom de champ d'origine suivi du suffixedonné.
--no-save-currency
Ne pas enregistrer le symbole de devise dans un champ séparé. (Par défaut.)
--save-datum
Équivalent à : 
--save-value '-value' --save-currency '-currency'
--no-save-datum
Équivalent à --no-save-value --no-save-currency.
