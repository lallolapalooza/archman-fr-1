STRUCTURES

CIRCULAIRES

Comparer une structure circulaire à elle-même renvoie vrai

: 
$x = \$y;
$y = \$x;
Compare([$x, $y], [$x, $y])
;

Et sur un sujet vaguement connexe, si vous essayez de comparer des structures imbriquées de manière folle, le m

odule émettra un avertissement. Pour que cela vous concerne, vous devez atteindre environ cent niveaux de profon
deur cependant, et si vous le faites vous avez de plus gros problèmes que je ne peux pas résoudre pour vous ;-)

GREFFON

S

Le module accepte des greffons afin que vous puissiez fournir des routines spécialisées pour comparer vos propres objets et types de données. Pour plus de détails, voir Data::Compare::

Plugins.

Les greffons ne sont *pas* disponibles lors de l'exécution en mode "taint". Vous pouvez également empêcher le chargement des greffons en fournissant une liste vide comme argument à import() - c'est-à-dire, en faisant ceci

: 
use Data::Compare ()
;

Quelques fonctions sont fournies pour examiner quelles fonctionnalités ont été rendues disponibles via les greffons

paramètre.

EXPORT

S

Pour des raisons historiques, la fonction Compare() est exportée. Si vous ne le souhaitez pas, passez une liste vide à import() comme expliqué dans la section GREFFONS. Si vous ne voulez aucune exportation mais que vous voulez les greffons, alors passez la liste vide, puis appelez la méthode de classe register_plugins

: 
use Data::Compare ();
Data::Compare->register_plugins
;

ou vous pourriez l'appe

ler en tant que fonction
si cela vous convient.

BOGUE

S

La prise en charge des greffons n'est pas tout à fait terminée (voir le problème Github #5 http://github.com/DrHyde/perl-modules-Data-Compare/issues/5 pour les détails) mais elle est utilisable. Les éléments manquants sont des fioritures plutôt que la fonctionnalité de

base.

Les greffons sont indisponibles si vous ne pouvez pas changer de répertoire courant. Cela peut se produire si vous avez démarré votre processus en tant qu'utilisateur privilégié puis réduit vos privilèges. Si cela vous concerne, veuillez fournir un patch portable avec des

tests.

Les rapports de bogues

doivent être faits sur
Github ou par e-mail.
