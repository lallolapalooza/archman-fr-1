NOM

Data::Perl - Classes de base encapsulant les types de données Perl fondamentaux.

VERSION

version 0.002011

SYNOPSIS

use Data::Perl;
my $array = array(1,2,3, qw/a b c/);
$array->count; # 6
my @elements = $array->grep(sub {/b/}); # (b)
my $hash = hash(a => 1, b => 2);
$hash->keys; # ('a', 'b');
my $number = number(5);
$number->add(10); # 15
my $string = string("foo\n");
$string->chomp; # renvoie 1, supprime le retour à la ligne
my $counter = counter();
$counter->inc; # le compteur vaut maintenant 1
my $sub = code(sub { 'foo' });
$sub->execute; # renvoie 'foo'
$foo

DESCRIPTION

Data::Perl est une collection de classes qui encapsulent les types de données fondamentaux existant en Perl. Ces classes et méthodes, dans leur état actuel, tentent de reproduire les fonctionnalités fournies par les Traits Natifs de Moose. Il est important de noter que toutes les classes ne valident actuellement pas les entrées du constructeur.

Data::Perl est une classe conteneur pour les classes suivantes :

  • Data::Perl::Collection::Hash
  • Data::Perl::Collection::Array
  • Data::Perl::String
  • Data::Perl::Number
  • Data::Perl::Counter
  • Data::Perl::Bool
  • Data::Perl::Code

API ALPHA

L'API fournie par ces modules est actuellement considérée comme alpha et non définitive. L'API VA changer. Si vous écrivez du code que vous ne toucherez plus pendant des années, n'utilisez pas ce module tant que cet avertissement n'aura pas été retiré.

FONCTIONS FOURNIES

Data::Perl exporte des fonctions de construction d'aide pour interagir avec les classes ci-dessus :

  • hash(clé, valeur, ...)

    Renvoie un objet Data::Perl::Collection::Hash initialisé avec les arguments clé/valeur optionnellement passés.

  • array(@arguments)

    Renvoie un objet Data::Perl::Collection::Array initialisé avec les valeurs optionnellement passées.

  • string($argument)

    Renvoie un objet Data::Perl::String initialisé avec le scalaire optionnellement passé comme argument.

  • number($argument)

    Renvoie un objet Data::Perl::Number initialisé avec le scalaire optionnellement passé comme argument.

  • counter($argument)

    Renvoie un objet Data::Perl::Counter initialisé avec le scalaire optionnellement passé comme argument.

  • bool($argument)

    Renvoie un objet Data::Perl::Bool initialisé avec la valeur de vérité du scalaire passé comme argument.

  • code($argument)

    Renvoie un objet Data::Perl::Code initialisé avec le coderef scalaire optionnellement passé comme argument.
