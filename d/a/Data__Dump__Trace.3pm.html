Data::Dump::Trace(3) Documentation Perl fournie par l'utilisateur Data::Dump::Trace(3)

NOM

Data::Dump::Trace - Utilitaires pour tracer les appels de fonctions et de méthodes

SYNOPSIS

use Data::Dump::Trace qw(autowrap mcall);
autowrap("LWP::UserAgent" => "ua", "HTTP::Response" => "res");
use LWP::UserAgent;
$ua = mcall(LWP::UserAgent => "new");      # au lieu de LWP::UserAgent->new;
$ua->get("http://www.example.com")->dump;

DESCRIPTION

Les fonctions suivantes sont fournies :

autowrap( $classe )
autowrap( $classe => $prefixe )
autowrap( $classe1 => $prefixe1, $classe2 => $prefixe2, ... )
autowrap( $classe1 => \%info1, $classe2 => \%info2, ... )
Enregistre les classes dont les objets sont automatiquement enveloppés lorsqu'ils sont retournés par l'une des fonctions d'appel ci-dessous. Si $prefixe est fourni, il sera utilisé pour nommer les objets.

Une alternative consiste à passer une table de hachage %info pour chaque classe. Les clés reconnues sont :

prefix => $chaîne
La chaîne de préfixe utilisée pour nommer les objets de ce type.
proto => \%table
Une table de hachage de prototypes à utiliser pour les méthodes lorsqu'un objet est enveloppé.
wrap( nom => $str, fonction => \&fonction, proto => $proto )
wrap( nom => $str, obj => $obj, proto => \%table )
Retourne une fonction ou un objet enveloppé. Lorsqu'une fonction enveloppée est invoquée, une trace est imprimée après le retour de la fonction sous-jacente. Lorsqu'une méthode est invoquée sur un objet enveloppé, une trace est imprimée après le retour des méthodes sur les objets sous-jacents.

Voir "Prototypes" pour la description de l'argument "proto".

call( $nom, \&fonction, $proto, @ARGS )
Appelle la fonction donnée avec les arguments donnés. La trace utilisera $nom comme nom de la fonction.

Voir "Prototypes" pour la description de l'argument $proto.

mcall( $classe, $méthode, $proto, @ARGS )
mcall( $objet, $méthode, $proto, @ARGS )
Appelle la méthode donnée avec les arguments donnés.

Voir "Prototypes" pour la description de l'argument $proto.

trace( $symbole, $prototype )
Remplace la fonction donnée par $symbole par une fonction enveloppée.

Prototypes

Note : La syntaxe de chaîne de prototype décrite ici est expérimentale et** **est susceptible de changer dans les révisions de cette interface.

L'argument $proto pour call() et mcall() peut optionnellement fournir un prototype pour l'appel de fonction. Cela donne à l'outil de traçage des indications sur la meilleure façon de formater les listes d'arguments et s'il y a des arguments *in/out* ou *out*. La forme générale du prototype est :

<arguments> = <valeur_retournée>

Le prototype par défaut est "@ = @" ; liste de valeurs en entrée et liste de valeurs en sortie.

La valeur '%' peut être utilisée à la fois pour les arguments et la valeur de retour pour indiquer que les listes de style paire clé/valeur sont utilisées.

Alternativement, les arguments positionnels individuels peuvent être listés, chacun représenté par une lettre :

"i"
argument d'entrée
"o"
argument de sortie
"O"
argument d'entrée et de sortie

Si le prototype de la valeur de retour a "!" ajouté, cela signale que la fonction définit errno ($!) lorsqu'elle retourne une valeur fausse. La trace affichera la valeur actuelle d'errno dans ce cas.

Si le prototype de la valeur de retour ressemble à un nom de variable (avec le préfixe "$"), et que la fonction retourne un objet béni, alors le nom de la variable sera utilisé comme préfixe et l'objet retourné sera tracé automatiquement.
