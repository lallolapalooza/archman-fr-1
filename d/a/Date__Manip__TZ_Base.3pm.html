NOM

Date::Manip::TZ_Base - Méthodes communes aux classes TZ et Base

SYNTAXE

La classe Date::Manip::TZ_Base est une deuxième classe de base utilisée pour les classes Date::Manip suivantes :

Date::Manip::Base
Date::Manip::TZ

Ce module n'est pas destiné à être appelé directement et n'effectue aucune fonction utile par lui-même. Utilisez plutôt les différentes classes dérivées qui en héritent.

DESCRIPTION

Ce module ne contient aucune méthode publique et est utilisé en interne par les classes Base et TZ. Dans certains cas, les opérations de date de base dépendent des informations de fuseau horaire, et toutes les opérations de fuseau horaire dépendent de la classe de base. Afin d'éviter une dépendance circulaire, j'ai créé cette classe qui m'a permis de l'éviter.
