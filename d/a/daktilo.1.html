daktilo(1) Manuel des commandes générales daktilo(1)

NOM

daktilo - Transformez votre clavier en machine à écrire ! 📇

SYNTAXE

daktilo [-v|--verbose]... [-p|--preset] [-l|--list-presets] [--list-devices] [-d|--device] [-c|--config] [-i|--init] [--variate-volume] [--variate-tempo] [-h|--help] [-V|--version]

DESCRIPTION

Transformez votre clavier en machine à écrire ! 📇

OPTIONS

-v, --verbose
Active la journalisation détaillée
-p, --preset=PRESET
Définit le nom du préréglage sonore à utiliser.

Peut être spécifié plusieurs fois pour jouer plusieurs préréglages simultanément.

Peut également être spécifié avec la variable d'environnement PRESET.
-l, --list-presets
Liste les préréglages disponibles
--list-devices
Liste les périphériques de sortie disponibles
-d, --device=DEVICE
Définit le périphérique de lecture
Peut également être spécifié avec la variable d'environnement DAKTILO_DEVICE.
-c, --config=PATH
Définit le fichier de configuration
Peut également être spécifié avec la variable d'environnement DAKTILO_CONFIG.
-i, --init
Écrit le fichier de configuration par défaut
--variate-volume=POURCENT_HAUT[,POURCENT_BAS]
Varie le volume +/- en pourcentage
Peut également être spécifié avec la variable d'environnement DAKTILO_VOLUME.
--variate-tempo=POURCENT_HAUT[,POURCENT_BAS]
Varie le tempo +/- en pourcentage
Peut également être spécifié avec la variable d'environnement DAKTILO_TEMPO.
-h, --help
Affiche l'aide (voir un résumé avec '-h')
-V, --version
Affiche la version
