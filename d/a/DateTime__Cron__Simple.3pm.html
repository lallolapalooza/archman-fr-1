NOM

DateTime::Cron::Simple - Analyser une entrée cron et vérifier par rapport à l'heure actuelle

SYNOPSIS

use DateTime::Cron::Simple;
$c = DateTime::Cron::Simple->new($cron);
$boolean = $c->validate_time;
$c->new_cron($cron);

DESCRIPTION

Ce module est une manière rapide et simple de déterminer si un format d'heure cron est valide pour la date et l'heure actuelles.

Une entrée cron suit le format cron de crontab(5).

La fonction validate_time utilise la date et l'heure actuelles pour la comparaison, mais acceptera également un objet DateTime valide en tant que paramètre.

FONCTIONS

new
$c = DateTime::Cron::Simple->new('0-59/2 10,12 * * 5');

Crée une entrée cron.

new_cron
$c->new_cron($cron);

Met à jour l'entrée cron avec l'argument donné.

validate_time
$boolean = $c->validate_time;
$boolean = $c->validate_time($dt);

Valide une date et une heure par rapport à l'entrée cron. Si l'argument est omis, il valide par rapport à l'heure actuelle ("DateTime-"now>).

_parse_cron_field
$data = $c->_parse_cron_field($field, $min, $max)

EXEMPLE

use DateTime::Cron::Simple;
$c = DateTime::Cron::Simple->new('0-59/2 10,12 * * 5');
if($c->validate_time) { ... }
$c->new_cron('* * 1 * 0');
if($c->validate_time) { ... }

VOIR AUSSI

DateTime::Event::Cron

Il est très probable que ce module soit bientôt obsolète. Il a été créé sans coordination avec les développeurs des modules DateTime, qui peuvent être joints via

http://datetime.perl.org/
datetime@perl.org (la liste de diffusion)

Ce module appartiendrait mieux à l'espace de noms DateTime::Event ou alors sa fonctionnalité serait incorporée dans DateTime::Event::Cron. Cette version est transitoire, pendant que la bonne méthode est étudiée.
