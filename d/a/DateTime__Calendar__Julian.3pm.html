NOM

DateTime::Calendar::Julian - Dates dans le calendrier julien

SYNTAXE

use DateTime::Calendar::Julian;
$dt = DateTime::Calendar::Julian->new( year  => 964,
                                       month => 10,
                                       day   => 16,
                                     );
# conversion Julian vers Grégorien...
$dtgreg = DateTime->from_object( object => $dt );
print $dtgreg->datetime;  # affiche '0964-10-21T00:00:00'
# ... et retour
$dtjul = DateTime::Calendar::Julian->from_object( object => $dtgreg );
print $dtjul->datetime;  # affiche '0964-10-16J00:00:00'

DESCRIPTION

DateTime::Calendar::Julian implémente le calendrier julien. Ce module implémente toutes les méthodes de DateTime ; voir la page de manuel DateTime(3) pour toutes les méthodes.

MÉTHODES

Ce module implémente une méthode supplémentaire par rapport à celles de DateTime, et modifie la sortie d'une autre méthode.

  • calendar_name

    Retourne 'Julian'.

  • gregorian_deviation

    Retourne la différence en jours entre le calendrier grégorien et le calendrier julien.

  • datetime 
    print $dt->datetime( $sep ), "\n";

    Cette méthode est équivalente à

    join $sep, $dt->ymd( '-' ), $dt->hms( ':' );

    L'argument $sep vaut par défaut 'J'.

    Attention : l'argument optionnel a été ajouté à cette méthode dans la version 1.02, pour suivre tardivement un changement apporté à la version 1.43 de DateTime publiée le 29/05/2017. La correction de ce point restaure le comportement de stringification original de cette classe, qui était de retourner une chaîne ISO-8601 à moins qu'un formateur ne soit défini. Avant ce changement, la stringification séparait la date et l'heure soit par un 'T', soit par un 'J', selon la version de DateTime installée.

Note qu'à partir de la version "0.106_01", les méthodes relatives aux trimestres devraient fonctionner.

CONTEXTE

Le calendrier julien a été introduit par Jules César en 46 av. J.-C. Il comportait une année de douze mois de 365 jours, avec une année bissextile en février tous les quatre ans. Ce calendrier a été adopté par l'Église chrétienne en 325 apr. J.-C. Vers 532 apr. J.-C., Denys le Petit a déplacé le point de départ du calendrier julien au moment calculé de la naissance de Jésus-Christ. En dehors des opinions divergentes sur le début de l'année (souvent le 1er janvier, mais aussi Noël, Pâques, le 25 mars et d'autres dates), ce calendrier est resté inchangé jusqu'à la réforme du calendrier du pape Grégoire XIII en 1582. Certains pays récalcitrants, cependant, ont utilisé le calendrier julien jusqu'au 18ème siècle, voire plus tard.

Ce module utilise le calendrier julien proleptique pour les années antérieures à 532 apr. J.-C., voire 46 av. J.-C. Cela signifie que les dates sont calculées comme si ce calendrier avait existé sans changement depuis le début des temps. Il est supposé que le 1er janvier est le premier jour de l'année.

Notez que les années av. J.-C. sont représentées par des nombres négatifs, 0 désignant l'an 1 av. J.-C. (il n'y a pas eu d'année 0 apr. J.-C. !), -1 l'an 2 av. J.-C., etc.
