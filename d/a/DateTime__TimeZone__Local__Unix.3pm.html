NOM

DateTime::TimeZone::Local::Unix - Déterminer le fuseau horaire du système local sur Unix

VERSION

version 2.65

SYNTAXE

my $tz = DateTime::TimeZone->new( name => 'local' );
my $tz = DateTime::TimeZone::Local->TimeZone();

DESCRIPTION

Ce module fournit des méthodes pour déterminer le fuseau horaire local sur une plateforme Unix.

COMMENT LE FUSEAU HORAIRE EST DÉTERMINÉ

Cette classe essaie les méthodes suivantes pour déterminer le fuseau horaire local, dans l'ordre indiqué ici :

  • $ENV{TZ}

    Elle vérifie $ENV{TZ} pour un nom de fuseau horaire valide.

  • /etc/timezone

    Si ce fichier existe, il est lu et son contenu est utilisé comme nom de fuseau horaire.

    Notez que ce fichier peut être obsolète sur de nombreux systèmes, car les distributions modernes peuvent ne pas bien gérer la mise à jour de ce fichier. Si vous constatez que ce fichier n'est pas mis à jour, vous pourriez envisager de le supprimer afin que l'une des méthodes suivantes puisse être utilisée.

  • /etc/localtime

    Si ce fichier est un lien symbolique vers un fichier de fuseau horaire de la base de données Olson (généralement dans /usr/share/zoneinfo), alors il utilise le nom du chemin du fichier cible pour déterminer le nom du fuseau horaire. Par exemple, si le chemin est /usr/share/zoneinfo/America/Chicago, le fuseau horaire est "America/Chicago".

    Certains systèmes copient simplement le fichier pertinent vers /etc/localtime au lieu de créer un lien symbolique. Dans ce cas, nous recherchons dans /usr/share/zoneinfo un fichier qui a la même taille et le même contenu que /etc/localtime pour déterminer le fuseau horaire local.

  • /etc/TIMEZONE

    Si ce fichier existe, il est ouvert et nous recherchons une ligne commençant par "TZ = ...". Si cela est trouvé, cela devrait indiquer un nom de fuseau horaire.

  • /etc/sysconfig/clock

    Si ce fichier existe, il est ouvert et nous recherchons une ligne commençant par "TIMEZONE = ..." ou "ZONE = ...". Si cela est trouvé, cela devrait indiquer un nom de fuseau horaire.

  • /etc/default/init

    Si ce fichier existe, il est ouvert et nous recherchons une ligne commençant par "TZ=...". Si cela est trouvé, cela devrait indiquer un nom de fuseau horaire.

Note : Certains systèmes, tels que les machines virtuelles, peuvent ne pas disposer de ces fichiers. Vous pouvez confirmer que c'est le cas en exécutant :

$ ls -l /etc/localtime /etc/timezone /etc/TIMEZONE \
    /etc/sysconfig/clock /etc/default/init

Dans ce cas, lorsque vous recherchez la gestion des fuseaux horaires, vous risquez d'obtenir une exception :

$ perl -wle 'use DateTime; DateTime->now( time_zone => "local" )'
Cannot determine local time zone

Dans ce cas, vous devriez consulter les pages de manuel de votre système pour obtenir des détails sur la manière de résoudre ce problème. Dans un cas signalé, une machine virtuelle FreeBSD avait été créée sans aucun de ces fichiers. L'utilisateur a pu exécuter l'utilitaire FreeBSD tzsetup. Cela a installé /etc/localtime, après quoi le diagnostic de fuseau horaire ci-dessus s'est exécuté silencieusement, c'est-à-dire sans générer d'exception.
