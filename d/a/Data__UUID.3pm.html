NOM

Data::UUID - Identifiants Uniques Universels/Globaux (GUIDs/UUIDs)

VOIR AU LIEU DE?

Le module Data::GUID fournit une autre interface pour générer des GUIDs. Actuellement, il repose sur Data::UUID, mais ce ne sera peut-être pas le cas à l'avenir. Son interface pourrait être un peu plus simple pour le programmeur Perl moyen.

SYNOPSIS

use Data::UUID;

$ug    = Data::UUID->new;
$uuid1 = $ug->create();
$uuid2 = $ug->create_from_name(<espace de noms>, <nom>);
$res   = $ug->compare($uuid1, $uuid2);
$str   = $ug->to_string( $uuid );
$uuid  = $ug->from_string( $str );

DESCRIPTION

Ce module fournit un cadre pour générer des UUIDs de version 3 (Identifiants Uniques Universels, également connus sous le nom de GUIDs (Identifiants Uniques Globaux). Un UUID est long de 128 bits et est garanti d'être différent de tous les autres UUIDs/GUIDs générés jusqu'à l'an 3400 de notre ère.

Les UUIDs étaient initialement utilisés dans le Network Computing System (NCS) et plus tard dans l'environnement de calcul distribué (DCE) de l'Open Software Foundation. Actuellement, de nombreuses technologies différentes s'appuient sur les UUIDs pour fournir une identité unique à divers composants logiciels. Microsoft COM/DCOM, par exemple, utilise les GUIDs très extérieurement pour identifier de manière unique les classes, les applications et les composants sur les systèmes connectés au réseau.

L'algorithme de génération d'UUID, utilisé par cette extension, est décrit dans le brouillon Internet "UUIDs and GUIDs" par Paul J. Leach et Rich Salz. (Voir RFC 4122.) Il fournit un cadre raisonnablement efficace et fiable pour générer des UUIDs et prend en charge des taux d'allocation assez élevés - 10 millions par seconde par machine - et est donc adapté à l'identification d'objets à durée de vie extrêmement courte et très persistants sur un système donné ainsi qu'à travers le réseau.

Ce module fournit plusieurs méthodes pour créer un UUID. Dans toutes les méthodes, "<espace de noms>" est un UUID et "<nom>" est une chaîne de caractères libre.

# crée un UUID binaire (valeur binaire de 16 octets).
$ug->create();
$ug->create_bin();
# crée un UUID binaire (valeur binaire de 16 octets) basé sur un espace
# de noms et une chaîne de nom particuliers.
$ug->create_from_name(<espace de noms>, <nom>);
$ug->create_from_name_bin(<espace de noms>, <nom>);
# crée une chaîne UUID, en utilisant le format de chaîne UUID conventionnel,
# tel que : 4162F712-1DD2-11B2-B17E-C09EFE1DC403
# Notez que les chiffres A-F sont capitalisés, ce qui est contraire à rfc4122
$ug->create_str();
$ug->create_from_name_str(<espace de noms>, <nom>);
# crée une chaîne UUID sous forme de chaîne hexadécimale,
# tel que : 0x4162F7121DD211B2B17EC09EFE1DC403
# Notez que les chiffres A-F sont capitalisés, ce qui est contraire à rfc4122
$ug->create_hex();
$ug->create_from_name_hex(<espace de noms>, <nom>);
# crée une chaîne UUID sous forme de chaîne encodée en Base64
$ug->create_b64();
$ug->create_from_name_b64(<espace de noms>, <nom>);
Les UUIDs binaires peuvent être convertis en chaînes imprimables en utilisant les méthodes suivantes :
# convertir en représentation de chaîne conventionnelle
$ug->to_string(<uuid>);
# convertir en chaîne hexadécimale (en utilisant des lettres majuscules, plutôt que minuscules)
$ug->to_hexstring(<uuid>);
# convertir en chaîne encodée en Base64
$ug->to_b64string(<uuid>);
Inversement, les chaînes UUID peuvent être reconverties en forme binaire :
# recréer un UUID binaire à partir d'une chaîne
$ug->from_string(<uuid>);
$ug->from_hexstring(<uuid>);
# recréer un UUID binaire à partir d'une chaîne encodée en Base64
$ug->from_b64string(<uuid>);
Enfin, deux UUIDs binaires peuvent être comparés en utilisant la méthode suivante :
# renvoie -1, 0 ou 1 selon que uuid1 est inférieur,
# égal ou supérieur à uuid2
$ug->compare(<uuid1>, <uuid2>);

Exemples :

use Data::UUID;
# cela crée un nouvel UUID sous forme de chaîne, basé sur l'espace de noms standard
# UUID NameSpace_URL et le nom "www.mycompany.com"
$ug = Data::UUID->new;
print $ug->create_from_name_str(NameSpace_URL, "www.mycompany.com");

EXPORT

Le module permet l'exportation de plusieurs UUIDs d'espaces de noms standards :

NameSpace_DNS
NameSpace_URL
NameSpace_OID
NameSpace_X500
