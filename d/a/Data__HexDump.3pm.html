NOM

Data::HexDump - Générateur d'extraits hexadécimaux

SYNOPIS

Interface fonctionnelle :

use Data::HexDump;
print HexDump($donnees_chaine);

Interface objet :

use Data::HexDump;
my $dumper = Data::HexDump->new();
print while $_ = $dumper->dump;

DESCRIPTION

Ce module générera un extrait hexadécimal d'une chaîne de données ou d'un fichier. Vous pouvez utiliser la fonction exportée, comme montré dans la SYNOPIS ci-dessus, ou l'interface objet, décrite ci-dessous.

Le deuxième exemple de la SYNOPIS a généré la sortie suivante :

          00 01 02 03 04 05 06 07 - 08 09 0A 0B 0C 0D 0E 0F  0123456789ABCDEF
00000000  23 21 2F 75 73 72 2F 62 - 69 6E 2F 70 65 72 6C 0A  #!/usr/bin/perl.
00000010  75 73 65 20 73 74 72 69 - 63 74 3B 0A 75 73 65 20  use strict;.use
00000020  77 61 72 6E 69 6E 67 73 - 3B 0A 0A 70 72 69 6E 74  warnings;..print
00000030  20 22 48 65 6C 6C 6F 2C - 20 77 6F 72 6C 64 5C 6E   "Hello, world\n
00000040  22 3B 0A                                           ";.

Le résultat est retourné dans une chaîne. Chaque ligne du résultat se compose du décalage dans la source dans la colonne la plus à gauche de chaque ligne, suivi d'une ou plusieurs colonnes de données de la source en hexadécimal. La colonne la plus à droite de chaque ligne montre les caractères imprimables (tous les autres sont représentés par des points).

Interface fonctionnelle

Ce module exporte une seule fonction, "HexDump", qui prend une valeur scalaire et renvoie une chaîne contenant l'extrait hexadécimal des données passées.

Interface objet

Vous construisez d'abord un objet "Data::HexDump", puis vous lui indiquez où obtenir les données, et ensuite vous générez l'extrait hexadécimal :

my $dh = Data::HexDump->new();
$dh->data($scalaire);      # Extraire les données de ce scalaire
$dh->fh($fh);            # Lire ce descripteur de fichier
$dh->file($nom_fichier);    # Lire ce fichier et en extraire le contenu
print while $_ = $dh->dump;

Les différentes sources potentielles de données sont considérées dans l'ordre indiqué ci-dessus, donc si vous passez à la méthode "data", les appels ultérieurs à fh() ou file() n'auront aucun effet.

VOIR AUSSI

Data::Hexify, par Johan Vromans, est une autre option simple, similaire à ce module. Dernière publication en 2004.

Data::Hexdumper (par David Cantrell, DCANTRELL) est un autre générateur d'extraits hexadécimaux, avec plus de fonctionnalités que ce module.

App::colourhexdump (par Kent Fredric, RIP) fournit un script qui offre une sortie colorisée avec mise en surbrillance des classes de caractères.

Data::HexDump::Range fournit plus de fonctions, une sortie couleur, et la capacité de sauter des parties non intéressantes des données d'entrée.

Data::HexDump::XXD fournit des extraits hexadécimaux comme xxd. Il ne dit pas ce qu'est xxd, ni ne fournit de lien, et il n'y a pas d'exemple de sortie. Mais si vous connaissez et aimez xxd, celui-ci pourrait vous convenir !

Devel::Hexdump fournit quelques options de configuration, mais il existe d'autres modules plus complets, et celui-ci n'a pas d'exemple de sortie dans la documentation.

Data::Peek est une collection de fonctions pour afficher des données, y compris "DHexDump" qui génère un simple extrait hexadécimal à partir d'une chaîne.

String::HexConvert convertira les chaînes ASCII en hexadécimal et inversement.
