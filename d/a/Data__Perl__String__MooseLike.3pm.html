NOM

Data::Perl::String::MooseLike - sous-classe de data::Perl::String qui simule les traits natifs de Moose.

VERSION

version 0.001009

SYNOPSIS

use Data::Perl::Collection::String::MooseLike;
my $string = Data::Perl::Collection::String::MooseLike->new("this is a string\n");
$string->chomp;
$string->substr(); # etc

DESCRIPTION

Cette classe fournit un wrapper et des méthodes pour interagir avec une chaîne de caractères. Toutes les méthodes sont écrites pour émuler/correspondre au comportement existant des traits natifs de Moose. Vous devriez probablement regarder la documentation de Data::Perl à la place.
