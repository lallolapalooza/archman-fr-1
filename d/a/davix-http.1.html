DAVIX-HTTP(1) Outil de requête HTTP DAVIX-HTTP(1)

NOM

davix-http - Outil de requête HTTP basé sur libdavix

SYNTAXE

davix-http [options]... url

DESCRIPTION

davix-http est un outil utilisant libdavix pour exécuter des requêtes HTTP
Il peut être utilisé pour interagir avec des services web RESTful.

Voir libdavix(3) pour les détails.

OPTIONS

Options de requête :

--data
Contenu de la requête
--request, -X
Méthode de requête à utiliser (ex : GET, PUT, PROPFIND, etc..)

Options communes :

--debug
Mode débogage
--header, -H
Ajouter un champ d'en-tête à la requête (par ex. : -H "Depth: 1" )
--help, -h
Afficher ce message d'aide
--metalink OPT
Support Metalink. (OPT=failover[défaut]|no)
--module, -P PLUGIN_NAME
Charger un plugin ou un profil par nom
--redirection OPT
Support de redirection transparent. (OPT=yes[défaut]|no)
--proxy, -x URL
Serveur proxy SOCKS5 URL. (ex : socks5://login:pass@socks.example.org)
--trace
Traces un périmètre spécifique, les options incluent :
file - Interface de fichier Davix
posix - Interface POSIX Davix
xml - Sortie du parseur XML
ssl - Détails SSL et certificats
header - En-têtes des requêtes HTTP
body - Corps des requêtes HTTP
chain - Infos sur les chaînes d'E/S
core - Infos de configuration et diverses
grid - Infos diverses de tiers
socket - Infos sur les sockets
locks - Infos sur le verrouillage WebDAV
all - Trace tout
--version
Afficher la version

Options de sécurité :

--capath CA_path
Ajouter un répertoire d'autorité de certification supplémentaire
--cert, -E cred_path
Certificat client au format PEM
--key priv_path
Clé privée au format PEM
--insecure, -k
Désactiver les vérifications des identifiants SSL
--userlogin
Identifiant utilisateur pour l'authentification par identifiant/mot de passe
--userpass
Mot de passe utilisateur pour l'authentification par identifiant/mot de passe
--s3secretkey
Authentification AWS S3 : clé secrète
--s3accesskey
Authentification AWS S3 : clé d'accès
--s3region
Authentification AWS S3 : région
--s3token
Jeton de sécurité AWS S3 - utilisé avec les identifiants temporaires STS
--s3alternate
Spécifier ce drapeau si vous avez besoin d'utiliser une URL S3 basée sur le chemin
--azurekey
Clé d'authentification Azure

EXEMPLES

Exécuter une requête GET en HTTP
davix-http http://example.org/

Exécuter une requête HEAD en HTTP + TLS avec authentification utilisateur
davix-http -X HEAD https://login:password@example.org

Exécuter une requête PUT avec S3 sur https et un contenu de base
davix-http -X PUT s3s://bucket.example.org/mifile -d "Bonjour Le Monde"
