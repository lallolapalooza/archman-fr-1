NOM

DateTime::TimeZone::UTC - Le fuseau horaire UTC

VERSION

version 2.65

SYNOPSIS

my $utc_tz = DateTime::TimeZone::UTC->new;

DESCRIPTION

Cette classe est utilisée pour fournir l'API DateTime::TimeZone nécessaire à DateTime.pm pour le fuseau horaire UTC, qui n'est pas explicitement inclus dans la base de données des fuseaux horaires Olson.

Le décalage pour cet objet sera toujours de zéro.

UTILISATION

Cette classe a les mêmes méthodes qu'un objet de fuseau horaire réel, mais la méthode category() retourne undef et is_utc() retourne true.

SUPPORT
