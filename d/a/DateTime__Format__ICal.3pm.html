DESCRIPTIO

N

Ce module comprend les formats de date/heure et de durée ICa

l, tels que définis dans la RFC 2445. Il peut être utilisé po
ur analyser ces formats afin de créer les objets appropriés.

MÉTHODE

S

Cette classe propose les méthodes

suivantes.
  • parse_datetime($string)

    Étant donné une chaîne de date/heure iCal, cette méthode renvoie un nouvel objet "DateTime

    ".

    Si une chaîne mal formatée est fournie, cette méthode peut échouer

    (die)
    • .
  • parse_duration($string)

    Étant donné une chaîne de durée iCal, cette méthode renvoie un nouvel objet "DateTime::Dur

    ation".

    Si une chaîne mal formatée est fournie, cette méthode peut échouer

    (die)
    • .
  • parse_period($string)

    Étant donné une chaîne de période iCal, cette méthode renvoie un nouvel objet "DateTime::

    Span".

    Si une chaîne mal formatée est fournie, cette méthode peut échouer

    (die)
    • .
  • parse_recurrence( recurrence => $string, ... )

    Étant donné une description de récurrence iCal, cette méthode utilise "DateTime::Event::ICal" pour créer un objet "DateTime::Set" représentant cette récurrence. Tous les paramètres fournis à cette méthode en plus de "recurrence" sont transmis directement à la méthode "DateTime::Event::ICal->

    recur".

    Si une chaîne mal formatée est fournie, cette méthode peut échouer

    (die).

    Cette méthode accepte les paramètres optionnels "dtstart" et "dtend". Ces paramètres doivent être des objets "DateTime

    ".

    La spécification iCal exige que "dtstart" soit toujours inclus dans l'ensemble de récurrence, sauf s'il s'agit d'une instruction "exrule". Comme nous ne savons pas quel type d'instruction est analysé, nous n'incluons pas "dtstart" dans l'ens

    emble de r
    • écurrence.
  • format_datetime($datetime)

    Étant donné un objet "DateTime", cette méthode renvoie une chaîne de date/heure

    iCal.

    La spécification iCal exige que les dates/heure soient formatées soit en tant que temps flottants (sans fuseau horaire), soit en UTC (avec un suffixe 'Z'), soit avec un identifiant de fuseau horaire au début ('TZID=America/Chicago;...'). Si cette méthode est demandée pour formater un objet "DateTime" qui a un fuseau horaire ne comportant qu'un décalage, l'objet sera converti en fuseau horaire UTC en interne avant le

    formatage.

    Par exemple, ce

    code : 
    my $dt = DateTime->new( year => 1900, hour => 15, time_zone => '-0100' );
print $ical->format_datetime($dt)
    ;

    affichera la chaîne

    "19000101T160000Z
    • ".
  • format_duration($duration)

    Étant donné un objet "DateTime::Duration", cette méthode renvoie une chaîne de durée

    iCal.

    Le standard iCal ne permet pas les mois ou les années dans une durée, donc si une durée pour laquelle delta_months() n'est pas zéro est fournie, cette méthode échouera

    (die)
    • .
  • format_period($span)

    Étant donné un objet "DateTime::Span", cette méthode renvoie une chaîne de période iCal, en utilisant le format "DateTime/

    DateT
    • ime".
  • format_period_with_duration($span)

    Étant donné un objet "DateTime::Span", cette méthode renvoie une chaîne de période iCal, en utilisant le format "DateTime/

    Durat
    • ion".
  • format_recurrence($arg [,$arg...] )

    Cette méthode renvoie une liste de chaînes contenant des instructions ICal. En contexte scalaire, elle renvoie une seule chaîne qui peut contenir des sauts de ligne

    intégrés.

    L'argument peut être une liste "DateTime", une liste "DateTime::Span", un "DateTime::Set", ou un "DateTime::Sp

    anSet".

    Les valeurs "DATE" ICal ne sont pas prises en charge. Chaque fois qu'une valeur de date est trouvée, un "DATE-TIME" est

    généré.

    Si une récurrence a un "DTSTART" ou "DTEND" associé, ces valeurs doivent être formatées en utilisant format_datetime(). La méthode format_recurrence() ne le fera pas pour

    vous.

    Si une "union" ou un "complement" de récurrences est formaté, on suppose qu'ils ont la même valeur "DTSTART

    ".

    Seules les opérations "union" et "complement" sont prises en charge pour les récurrences. C'est une limitation de la spécification

    ICal.

    Si un ensemble est fourni qu'elle ne peut pas formater, cette méthode peut échouer

    (die).

    Seuls les objets "DateTime::Set::ICal" sont formatables. Un ensemble peut changer de classe après certaines opérations

    d'ensemble : 
    $recurrence = $recurrence->union( $dt_set );
# Ok - $recurrence est toujours un DT::Set::ICal
$recurrence = $dt_set->union( $recurrence );
# Pas Ok ! - $recurrence est maintenant un DT:
    :Set

    Les seules récurrences non bornées actuellement prises en charge sont celles générées par le module "DateTime::Event::

    ICal".

    Vous pouvez ajouter le support du formatage ICal à une récurrence personnalisée en utilisant le module "DateTime::Set::

    ICal" : 
    $custom_recurrence =
    DateTime::Set::ICal->from_recurrence
        ( recurrence =>
          sub { $_[0]->truncate( to => 'month' )->add( months => 1 ) }
        );
$custom_recurrence->set_ical( include => [ 'FREQ=MONTHLY'
    ]
)
;
