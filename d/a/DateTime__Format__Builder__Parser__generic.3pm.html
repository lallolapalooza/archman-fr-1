VERSION

version 0.83

MÉTHODES

Utiles

new

Constructeur standard. Retourne une référence à une table de hachage bénie ; tous les arguments sont placés dans la table de hachage. Ceci est utile pour stocker des informations entre les méthodes.

generic_parser

Ceci est une méthode fournie uniquement pour le bénéfice des implémentations de "Parser". Elle abstrait de manière semi-élégante une grande partie du travail impliqué.

Fondamentalement, elle prend des paramètres correspondant aux divers rappels des déclarations de parser et en fait une référence de code.

Les rappels actuellement reconnus sont :

  • on_match
  • on_fail
  • preprocess
  • postprocess

Méthodes pour la création de sous-classes

Ce sont des méthodes que vous devriez définir lors de l'écriture de votre propre sous-classe.

Note : ces méthodes n'existent pas dans cette classe. Il ne sert à rien d'essayer d'appeler "$self->SUPER::do_match( ... )".

do_match

"do_match" est la première phase. Les arguments sont la date et @args. "self", "label", "args". La valeur de retour doit être définie si vous réussissez la correspondance.

post_match

"post_match" est appelée après l'exécution du rappel approprié parmi "on_match"/"on_fail". Elle reçoit la date, la valeur de retour de "do_match" et la table de hachage de parsing.

Sa valeur de retour est utilisée comme argument "post" pour le rappel "postprocess", et comme second argument pour "make".

make

"make" prend l'entrée originale, la valeur de retour de "post_match" et la table de hachage de parsing, et doit retourner un objet "DateTime" ou indéfini.

Délégations

Pour l'utilisation de "Parser", ce module délègue également "valid_params" et "params". Ceci est juste une commodité pour éviter de taper ce qui suit :

DateTime::Format::Builder::Parser->valid_params(...)

Au lieu de cela, nous pouvons taper :

$self->valid_params(...);
__PACKAGE__->valid_params(...);
