NOM

Data::Perl::Bool::MooseLike - sous-classe de data::Perl::Bool qui simule les traits natifs de Moose.

VERSION

version 0.001009

SYNOPSIS

# vous ne devriez pas consommer cette classe directement.

DESCRIPTION

Cette classe fournit un wrapper et des méthodes pour interagir avec un booléen. Toutes les méthodes sont écrites pour émuler/correspondre au comportement existant des traits natifs de Moose.

VOIR AUSSI

  • Data::Perl
  • Data::Perl::Role::Collection::Bool
