Data::Perl::Collection::Array(3) Documentation Perl Contribuée par l'Utilisateur Data::Perl::Collection::Array(3)

NOM

Data::Perl::Collection::Array - Classe d'encapsulation pour la structure d'array intégrée de Perl.

VERSION

version 0.002011

SYNOPSIS

use Data::Perl qw/array/;
my $array = array(1, 2, 3);
$array->push(5);
$array->grep(sub { $_ > 2 })->map(sub { $_ ** 2 })->elements; # (3, 5);

DESCRIPTION

Cette classe est un simple consommateur du rôle Data::Perl::Role::Collection::Array, qui fournit toute la fonctionnalité. Vous voudrez probablement regarder là-bas à la place.
