Data::Perl::Collection::Hash::MooseLike(3) Documentation Perl Contribuée par l'Utilisateur Data::Perl::Collection::Hash::MooseLike(3)

NOM

Data::Perl::Collection::Hash::MooseLike - Sous-classe de Collection::Hash qui simule les traits natifs de Moose.

VERSION

version 0.001009

SYNOPSIS

use Data::Perl::Collection::Hash::MooseLike;
my $hash = Data::Perl::Collection::Hash::MooseLike->new(a => 1, b => 2);
$hash->values; # (1, 2)
$hash->set('foo', 'bar'); # (a => 1, b => 2, foo => 'bar')

DESCRIPTION

Cette classe fournit un wrapper et des méthodes pour interagir avec une table de hachage. Toutes les méthodes sont écrites pour émuler/correspondre au comportement existant des traits natifs de Moose.

DIFFÉRENCES DE FONCTIONNALITÉ

get($key, $key, ...)
Récupère les valeurs de la table de hachage.

En contexte de liste, renvoie une liste de valeurs de la table de hachage pour les clés données. En contexte scalaire, renvoie la valeur de la dernière clé spécifiée.

set($key, $value, ...)
Définit les éléments de la table de hachage avec les valeurs données. Renvoie les nouvelles valeurs définies pour chaque clé, dans le même ordre que les clés passées à la méthode.

Cette méthode nécessite au moins deux arguments et attend un nombre pair d'arguments.

delete($key, $key, ...)
Supprime les éléments avec les clés données.

En contexte de liste, renvoie une liste de valeurs de la table de hachage pour les clés supprimées. En contexte scalaire, renvoie la valeur de la dernière clé spécifiée.
