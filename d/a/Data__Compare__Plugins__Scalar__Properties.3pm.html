NOM

Data::Compare::Plugin::Scalar::Properties - plugin pour Data::Compare afin de gérer les objets Scalar::Properties.

DESCRIPTION

Permet à Data::Compare de Faire Ce Qui Est Juste pour les objets Scalar::Properties.

comparaison d'un objet Scalar::Properties et d'un scalaire ordinaire
Si vous comparez un scalaire et un Scalar::Properties, alors ils seront considérés comme identiques si les deux valeurs sont identiques, quelle que soit la présence de propriétés.
comparaison de deux objets Scalar::Properties
Si vous comparez deux objets Scalar::Properties, alors ils ne seront considérés comme identiques que si les valeurs et les propriétés correspondent.
