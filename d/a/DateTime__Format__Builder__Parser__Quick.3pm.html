NOM

DateTime::Format::Builder::Parser::Quick - Utiliser simplement un autre formateur

VERSION

version 0.83

SYNOPIS

use DateTime::Format::Builder (
    parsers => {
        parse_datetime => [
            { Quick => 'DateTime::Format::HTTP' },
            { Quick => 'DateTime::Format::Mail' },
            { Quick => 'DateTime::Format::IBeat' },
        ]
    }
);
# est équivalent à
use DateTime::Format::HTTP;
use DateTime::Format::Mail;
use DateTime::Format::IBeat;
use DateTime::Format::Builder (
    parsers => {
        parse_datetime => [
            sub {
                eval { DateTime::Format::HTTP->parse_datetime( $_[1] ) }
            },
            sub {
                eval { DateTime::Format::Mail->parse_datetime( $_[1] ) }
            },
            sub {
                eval { DateTime::Format::IBeat->parse_datetime( $_[1] ) }
            },
        ]
    }
);

(Ces deux morceaux de code se trouvent dans la suite de tests ; l'un sous le nom de quick.t, l'autre sous le nom de fall.t.)

DESCRIPTION

"Quick" ajoute un analyseur qui permet des raccourcis lors de l'écriture d'appels assez standards et banals à d'autres modules de formatage.

SPÉCIFICATION

"Quick" a deux clés, l'une optionnelle.

Le mot-clé "Quick" doit avoir comme argument soit un objet, soit un nom de classe. S'il s'agit d'un nom de classe, la classe est appelée avec "use".

Le mot-clé "method" est optionnel avec une valeur par défaut de "parse_datetime". C'est soit le nom de la méthode à appeler sur l'objet, soit une référence à un morceau de code.

Dans tous les cas, le code résultant ressemble à ceci :

my $rv = $Quick->$method($date);
