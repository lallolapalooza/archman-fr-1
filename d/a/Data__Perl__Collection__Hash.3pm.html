Data::Perl::Collection::Hash(3) Documentation Perl fournie par l'utilisateur Data::Perl::Collection::Hash(3)

NOM

Data::Perl::Collection::Hash - Classe d'encapsulation pour la structure de hachage intégrée de Perl.

VERSION

version 0.002011

SYNTAXE

use Data::Perl qw/hash/;
my $hash = hash(a => 1, b => 2);
$array->push(5);
$hash->values; # (1, 2)
$hash->set('foo', 'bar'); # (a => 1, b => 2, foo => 'bar')

DESCRIPTION

Cette classe est un simple consommateur du rôle Data::Perl::Role::Collection::Hash, qui fournit toute la fonctionnalité. Vous voudrez probablement regarder là à la place.
