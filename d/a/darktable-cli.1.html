NOM

darktable-cli - une variante de darktable en ligne de commande

SYNTAXE

darktable-cli IMG_1234.{RAW,...} [<fichier xmp>] <fichier de sortie> [options] [--core <options darktable>]

Options :

--width <largeur max>
--height <hauteur max>
--bpp <bpp>
--hq <0|1|false|true>
--upscale <0|1|false|true>
--export_masks <0|1|false|true>
--style <nom du style>
--style-overwrite
--apply-custom-presets <0|1|false|true>
--verbose
--help
--version

DESCRIPTION

darktable est une application de flux de travail pour la photographie numérique pour Linux, Mac OS X et plusieurs autres Unices. Elle est décrite plus en détail dans darktable(1).

darktable-cli est une variante en ligne de commande destinée à l'exportation d'images à partir d'un fichier brut et de son fichier xmp associé.

OPTIONS

L'utilisateur doit fournir un nom de fichier d'entrée et un nom de fichier de sortie. Tous les autres paramètres sont facultatifs.

<fichier d'entrée>
Le nom du fichier d'entrée à exporter.
<fichier xmp>
Le nom facultatif d'un fichier compagnon XMP contenant les données de la pile d'historique à appliquer lors de l'exportation. Si cette option n'est pas fournie, darktable recherchera un fichier XMP qui appartient au fichier d'entrée donné.
<fichier de sortie>
Le nom du fichier de sortie. darktable déduit le format du fichier d'exportation à partir de l'extension du fichier. Vous pouvez également utiliser toutes les variables disponibles dans le module d'exportation de darktable dans le nom du fichier de sortie.
--width <largeur max>
Ce paramètre facultatif permet de limiter la largeur de l'image exportée à ce nombre de pixels.
--height <hauteur max>
Ce paramètre facultatif permet de limiter la hauteur de l'image exportée à ce nombre de pixels.
--bpp <bpp>
Un paramètre facultatif pour définir la profondeur de bits de l'image exportée ; les valeurs autorisées dépendent du format de fichier. Actuellement, cette option n'est pas encore fonctionnelle. Si vous avez besoin de définir la profondeur de bits, vous devez utiliser la solution de contournement suivante : 
--core --conf plugins/imageio/format/<FORMAT>/bpp=<VALUE>

où FORMAT est le nom du format de sortie sélectionné, par exemple png.

--hq <0|1|true|false>
Un indicateur qui définit si la rééchantillonnage de haute qualité doit être utilisé lors de l'exportation. Par défaut, il est défini sur true.
--upscale <0|1|true|false>
Un indicateur qui définit si la mise à l'échelle vers le haut est autorisée lors de l'exportation. Par défaut, il est défini sur false.
--export_masks <0|1|true|false>
Un indicateur qui définit si les masques utilisés dans l'image seront stockés en tant que calques dans l'image exportée (à condition que le format le supporte). Par défaut, il est défini sur false.
--style <nom du style>
Spécifie le nom d'un style à appliquer lors de l'exportation. Si un style est spécifié, le chemin du répertoire de configuration de darktable doit également être spécifié (c'est-à-dire --core --configdir ~/.config/darktable). Par défaut, aucun style n'est spécifié.
--style-overwrite
Le style spécifié écrase la pile d'historique au lieu d'y être ajouté.
--apply-custom-presets
Avec cette option, vous pouvez décider si darktable charge son ensemble de paramètres par défaut à partir de data.db et les applique. Sinon, les paramètres par défaut fournis avec darktable sont utilisés.

Définissez cet indicateur sur false afin d'exécuter plusieurs instances.

--verbose
Active la sortie détaillée.
--core <options darktable>
Tous les paramètres de ligne de commande suivant --core sont passés au noyau de darktable et traités comme des paramètres standard. Voir darktable(1) pour une description détaillée des options.
