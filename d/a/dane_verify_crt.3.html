NOM

dane_verify_crt - Fonction d'API

SYNTAXE

#include <gnutls/dane.h>

int dane_verify_crt(dane_state_t s, const gnutls_datum_t * chain, unsigned chain_size, gnutls_certificate_type_t chain_type, const char * hostname, const char * proto, unsigned int port, unsigned int sflags, unsigned int vflags, unsigned int * verify);

ARGUMENTS

dane_state_t s
Une structure d'état DANE (peut être NULL)
const gnutls_datum_t * chain
Une chaîne de certificats
unsigned chain_size
La taille de la chaîne
gnutls_certificate_type_t chain_type
Le type de la chaîne de certificats
const char * hostname
Le nom d'hôte associé à la chaîne
const char * proto
Le protocole du service connectant (ex: tcp)
unsigned int port
Le port du service connectant (ex: 443)
unsigned int sflags
Indicateurs pour l'initialisation de s (si NULL)
unsigned int vflags
Indicateurs de vérification; une liste OR de dane_verify_flags_t.
unsigned int * verify
Une liste OR de dane_verify_status_t.

DESCRIPTION

Cette fonction vérifiera la chaîne de certificats donnée par rapport aux contraintes CA et/ou au certificat disponible via DANE. Si aucune information via DANE ne peut être obtenue, l'indicateur DANE_VERIFY_NO_DANE_INFO est défini. Si une signature DNSSEC n'est pas disponible pour l'enregistrement DANE, l'indicateur de vérification DANE_VERIFY_NO_DNSSEC_DATA est défini.

En raison des nombreuses options possibles de DANE, il n'y a pas un seul modèle de menace contrecarré. Lors de la notification à l'utilisateur des résultats de la vérification DANE, il peut être préférable de mentionner : "La vérification DANE n'a pas rejeté le certificat", plutôt que de mentionner une vérification DANE réussie.

Notez que cette fonction est conçue pour être exécutée en plus de la vérification PKIX - chaîne de certificats. Pour être exécutée indépendamment, l'indicateur DANE_VFLAG_ONLY_CHECK_EE_USAGE doit être spécifié ; dans ce cas, la fonction vérifiera si la clé du pair correspond à la clé annoncée dans l'entrée DANE.

RETOUR

Un code d'erreur négatif en cas d'erreur et DANE_E_SUCCESS (0) lorsque les entrées DANE ont été correctement analysées, indépendamment du fait qu'elles aient été vérifiées (voir verify pour cette information). Si aucune entrée utilisable n'a été rencontrée, DANE_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
