NOM

dane_state_set_dlv_file - fonction d'API

SYNTAXE

#include <gnutls/dane.h>

int dane_state_set_dlv_file(dane_state_t s, const char * file);

ARGUMENTS

dane_state_t s
La structure à désinitialiser
const char * file
Le fichier contenant les clés DLV.

DESCRIPTION

Cette fonction définit un fichier avec des clés de confiance pour la validation par recherche dans la base de données DNSSEC (DNSSEC Lookaside Validation - DLV).
