rand_words(

Renvoie une liste de mots aléatoires à partir d'une liste de mots. Voir ci-dessous pour les paramètres

possibles.
  • wordlist - le chemin vers le fichier de liste de mots. Beaucoup de systèmes en ont un à /usr/dict/words. Vous pouvez également fournir facultativement un objet Data::Random::WordList pour conserver une liste de mots persistante. La valeur par défaut est la liste de mots distribuée avec ce
    • module.
  • min - le nombre minimum de mots à renvoyer. La valeur par défaut est
    • 1.
  • max - le nombre maximum de mots à renvoyer. La valeur par défaut est
    • 1.
  • size - le nombre de mots à renvoyer. La valeur par défaut est 1. Si vous fournissez une valeur pour 'size', alors 'min' et 'max' ne sont pas pris en
    • compte.
  • shuffle - si les mots doivent être mélangés aléatoirement ou non. Mettez ceci à 0 si vous n
    • e voulez pas que les mots soient mélangés. La valeur par défaut est 1. Random::Data::WordLi
st renvoie les mots dans l'ordre dans lequel ils apparaissent dans le fichier de liste de
mots, donc le mélange permettra de s'assurer que les résultats sont un peu plus aléatoires.

rand_date(

)

Renvoie une date aléatoire sous la forme "AAAA-MM-JJ". Les années à 2 chiffres ne sont actuellement pas prises en charge. Des efforts sont faits pour s'assurer que vous obtenez une date réellement valide--c'est-à-dire que la date du 31 février ne vous sera jamais renvoyée. Voir les options ci-dessous pour savoir comment contrôler la plage de dates. Voici quelques exemples

: 
# renvoie une date quelque part entre la date actuelle et un an à partir de la date actuelle
$date = rand_date();
# renvoie une date quelque part entre le 21 septembre 1978 et le 21 septembre 1979
$date = rand_date( min => '1978-9-21' );
# renvoie une date quelque part entre le 21 septembre 1978 et la date actuelle
$date = rand_date( min => '1978-9-21', max => 'now' );
# renvoie une date quelque part entre la date actuelle et le 21 septembre 2008
$date = rand_date( min => 'now', max => '2008-9-21' )
;

Voir ci-dessous pour les paramètres

possibles.
  • min - la date minimale à renvoyer. Elle doit être sous la forme "AAAA-MM-JJ" ou vous pouvez utiliser alternativement la chaîne "now" pour représenter la date actuelle. La valeur par défaut est la date actuelle
    • ;
  • max - la date maximale à renvoyer. Elle doit être sous la f
    • orme "AAAA-MM-JJ" ou vous pouvez utiliser alternative
ment la chaîne "now" pour représenter la date actuel
le. La valeur par défaut est un an après la date minimale ;

rand_time(

)

Renvoie une heure aléatoire sous la forme "HH:MM:SS". Les heures sur 24 heures sont prises en charge. Voir les options ci-dessous pour savoir comment contrôler la plage horaire. Voici quelques exemples

: 
# renvoie une heure aléatoire sur 24 heures (entre 00:00:00 et 23:59:59)
$time = rand_time();
# renvoie une heure quelque part entre 04:00:00 et la fin de la journée
$time = rand_time( min => '4:0:0' );
# renvoie une heure quelque part entre 8:00:00 et l'heure actuelle (si elle est après 8:00)
$time = rand_time( min => '12:00:00', max => 'now' );
# renvoie une heure quelque part entre l'heure actuelle et la fin de la journée
$time = rand_time( min => 'now' )
;

Voir ci-dessous pour les paramètres

possibles.
  • min - l'heure minimale à renvoyer. Elle doit être sous la forme "HH:MM:SS" ou vous pouvez utiliser alternativement la chaîne "now" pour représenter l'heure actuelle. La valeur par défaut est 00:00:
    • 00 ;
  • max - l'heure maximale à renvoyer. Elle doit être sou
    • s la forme "HH:MM:SS" ou vous pouvez utiliser a
lternativement la chaîne "now" pour représenter
l'heure actuelle. La valeur par défaut est 23:59:59 ;

rand_datetime(

)

Renvoie une date et une heure aléatoires sous la forme "AAAA-MM-JJ HH:MM:SS". Voir les options ci-dessous pour savoir comment contrôler la plage de dates/heures. Voici quelques exemples

: 
# renvoie une date quelque part entre la date/heure actuelle et un an à partir de la date/heure actuelle
$datetime = rand_datetime();
# renvoie une date quelque part entre 4:00 le 21 septembre 1978 et 4:00 le 21 septembre 1979
$datetime = rand_datetime( min => '1978-9-21 4:0:0' );
# renvoie une date quelque part entre 4:00 le 21 septembre 1978 et la date actuelle
$datetime = rand_datetime( min => '1978-9-21 4:0:0', max => 'now' );
# renvoie une date quelque part entre la date/heure actuelle et la fin de la journée du 21 septembre 2008
$datetime = rand_datetime( min => 'now', max => '2008-9-21 23:59:59' )
;

Voir ci-dessous pour les paramètres

possibles.
  • min - la date/heure minimale à renvoyer. Elle doit être sous la forme "AAAA-MM-JJ HH:MM:SS" ou vous pouvez utiliser alternativement la chaîne "now" pour représenter la date/heure actuelle. La valeur par défaut est la date/heure actuelle
    • ;

    • me "AAAA-MM-JJ HH:MM:SS" ou vous pouvez utiliser alternativem
ent la chaîne "now" pour représenter la date/heure actuelle.
La valeur par défaut est un an après la date/heure minimale ;
