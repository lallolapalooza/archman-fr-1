DateTime::TimeZone::Floating(3pm) Documentation Perl fournie par l'utilisateur DateTime::TimeZone::Floating(3pm)

NOM

DateTime::TimeZone::Floating - Un fuseau horaire qui est toujours local

VERSION

version 2.65

SYNOPSIS

my $floating_tz = DateTime::TimeZone::Floating->new;

DESCRIPTION

Cette classe est utilisée pour fournir l'API DateTime::TimeZone requise par DateTime.pm, mais pour les heures flottantes, telles que définies par la spécification RFC 2445. Une heure flottante n'a pas de fuseau horaire et a un décalage effectif de zéro.

UTILISATION

Cette classe possède les mêmes méthodes qu'un objet de fuseau horaire réel. La méthode short_name_for_datetime() renvoie la chaîne "floating" et la méthode category() renvoie "undef".
