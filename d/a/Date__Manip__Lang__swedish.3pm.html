NOM

Date::Manip::Lang::swedish - Prise en charge de la langue suédoise.

SYNOPSIS

Ce module contient une liste de mots et d'expressions prenant en charge la langue. Il n'est pas destiné à être utilisé directement (d'autres modules Date::Manip le chargeront selon les besoins).

EXPRESSIONS DE LANGUE

Voici une liste de tous les mots et expressions de langue utilisés pour écrire des heures et/ou des dates.

Toutes les chaînes ne tiennent pas compte de la casse.

Heures du matin/ après-midi
Voici une liste d'expressions utilisées pour désigner l'heure du matin ou de l'après-midi lorsqu'une heure est saisie en format 12 heures plutôt qu'en format 24 heures. Par exemple, en anglais, l'heure « 17:00 » pourrait être spécifiée comme « 5:00 PM ».

L'heure du matin et de l'après-midi peut être désignée par les ensembles de mots suivants :

FM
EM
Chaque ou tous
Il existe une liste de mots qui spécifient chaque occurrence de quelque chose. Ils sont utilisés dans les phrases suivantes : 
EACH Monday
EVERY Monday
EVERY month

Les mots suivants peuvent être utilisés :

varje
Prochaine/précédente/dernière occurrence
Il existe une liste de mots qui peuvent être utilisés pour spécifier l'occurrence suivante, précédente ou dernière de quelque chose. Ces mots pourraient être utilisés dans les phrases suivantes : 
NEXT week
LAST Tuesday
PREVIOUS Tuesday
LAST day of the month

Les mots suivants peuvent être utilisés :

Occurrence précédente :

Dernière occurrence :

Mots delta pour aller en avant/en arrière dans le temps
Lors de l'analyse des deltas, il existe des mots qui peuvent être utilisés pour spécifier que le delta fera référence à un moment dans le futur ou dans le passé (par rapport à une certaine date). En anglais, par exemple, vous pourriez dire : 
IN 5 days
5 days AGO

Les mots suivants peuvent être utilisés pour spécifier des deltas qui font référence à des dates dans le passé ou le futur respectivement :

sedan
om
senare
Mode professionnel
Cela contient deux listes de mots qui peuvent être utilisées pour spécifier un delta standard (c'est-à-dire non professionnel) ou un delta professionnel.

Auparavant, elle était utilisée pour indiquer si le delta était approximatif ou exact, mais maintenant cette liste n'est pas utilisée sauf pour forcer le delta à être standard.

Les mots suivants peuvent être utilisés :

ungefär

Les mots suivants peuvent être utilisés pour spécifier un delta professionnel :

Mots ignorés
Lors de l'écriture de dates sous des formes courantes, il y a un certain nombre de mots qui ne sont généralement pas importants.

Il y a souvent un mot qui apparaît dans une phrase pour désigner qu'une heure va être spécifiée ensuite. En anglais, vous utiliseriez le mot AT dans l'exemple :

December 3 at 12:00

Les mots suivants peuvent être utilisés :

kl
kl.
klockan

Un autre mot est utilisé pour désigner un membre d'un ensemble. En anglais, vous utiliseriez les mots IN ou OF :

1st day OF December
1st day IN December

Les mots suivants peuvent être utilisés :

om

Un autre mot est utilisé pour spécifier que quelque chose est à une certaine date. En anglais, vous utiliseriez ON :

ON July 5th

Les mots suivants peuvent être utilisés :

pa
på
Mots qui définissent la date, l'heure, ou les deux
Il existe des mots qui peuvent être utilisés pour spécifier une date, une heure, ou les deux par rapport à maintenant.

Les mots qui définissent la date sont similaires aux mots anglais « yesterday » ou « tomorrow ». Ils sont spécifiés comme un delta qui est ajouté à l'heure actuelle pour obtenir une date. L'heure n'est PAS définie, donc le delta n'est utilisé que partiellement (il ne devrait inclure que les champs année, mois, semaine et jour).

Les mots suivants peuvent être utilisés :

i dag                0:0:0:0:0:0:0
i gar                -0:0:0:1:0:0:0
i går                -0:0:0:1:0:0:0
i morgon             +0:0:0:1:0:0:0
idag                 0:0:0:0:0:0:0
igar                 -0:0:0:1:0:0:0
igår                 -0:0:0:1:0:0:0
imorgon              +0:0:0:1:0:0:0

Les mots qui définissent seulement l'heure du jour sont similaires aux mots anglais « noon » ou « midnight ».

Les mots suivants peuvent être utilisés :

midnatt              00:00:00
mitt pa dagen        12:00:00
        midi        12:00:00

Des mots qui définissent la date et l'heure entières (par rapport à la date et l'heure actuelles) sont également disponibles.

En anglais, le mot « now » fait partie de cette catégorie.

Les mots suivants peuvent être utilisés :

nu                   0:0:0:0:0:0:0
Séparateurs heure/minute/seconde
Lors de la spécification de l'heure, le séparateur le plus courant est les deux-points (:), qui peut être utilisé pour les deux séparateurs.

Certaines langues utilisent des paires différentes. Par exemple, le français permet de spécifier l'heure sous la forme 13h30:20, il utiliserait donc les paires suivantes :

: :
h :

La première colonne est le séparateur heure-minute et la seconde colonne est le séparateur minute-seconde. Les deux sont des expressions régulières perl. Lors de la création d'une nouvelle traduction, gardez à l'esprit que les expressions régulières avec des caractères utf-8 peuvent être délicates. Par exemple, n'incluez pas l'expression '[x]' où 'x' est un caractère utf-8.

Une paire de deux-points est TOUJOURS autorisée pour toutes les langues. Si une langue autorise des paires supplémentaires, elles sont listées ici :

\.  :
Séparateur de fraction de seconde
Lors de la spécification des fractions de seconde, la méthode la plus courante est d'utiliser un point décimal (.). Certaines langues peuvent spécifier un séparateur différent qui pourrait être utilisé. Si c'est le cas, il s'agit d'une expression régulière.

Le point décimal est TOUJOURS autorisé pour toutes les langues. Si une langue autorise un autre séparateur, il est listé ici :

Non défini dans cette langue
