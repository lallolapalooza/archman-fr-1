NOM

davix-ls - Outil de liste basé sur libdavix

SYNTAXE

davix-ls [options]... url

DESCRIPTION

davix-ls est un outil pour lister les ressources dans des répertoires ou des collections avec des services compatibles HTTP, Webdav ou REST.
La commande supporte WebDav (dav(s)://) et S3 (s3(s)://).

davix-ls est alimenté par libdavix. Voir libdavix(3) pour les détails.

OPTIONS

Options de liste :

-l --long-list :
Mode de liste long
--s3-listing :
Mode de liste de compartiment S3 - plat, semi ou hiérarchique (par défaut)
--s3-maxkeys :
Nombre maximum d'entrées retournées par la requête de liste de compartiment S3. par défaut : 10000

Options communes :

--debug
Mode débogage
--header, -H
Ajouter un champ d'en-tête à la requête (par ex. : -H "Depth: 1" )
--help, -h
Afficher ce message d'aide
--metalink OPT
Support Metalink. (OPT=failover[défaut]|no)
--module, -P PLUGIN_NAME
Charger un plugin ou un profil par son nom
--redirection OPT
Support de redirection transparent. (OPT=yes[défaut]|no)
--proxy, -x URL
Serveur proxy SOCKS5 URL. (ex : socks5://login:pass@socks.example.org)
--trace
Traque des portées spécifiques, les options incluent :
file - Interface fichier Davix
posix - Interface POSIX Davix
xml - Sortie du parseur XML
ssl - Détails SSL et certificats
header - En-têtes des requêtes HTTP
body - Corps des requêtes HTTP
chain - Informations sur les chaînes IO
core - Informations de configuration et des outils en ligne de commande Davix
grid - Informations diverses de tiers
socket - Informations sur les sockets
locks - Informations sur les verrous WebDAV
all - Traque tout
--version
Afficher la version

Options de sécurité :

--capath CA_path
Ajouter un répertoire d'autorité de certification supplémentaire
--cert, -E cred_path
Certificat client au format PEM
--key priv_path
Clé privée au format PEM
--insecure, -k
Désactiver les vérifications d'authentification SSL
--userlogin
Nom d'utilisateur pour l'authentification login/mot de passe
--userpass
Mot de passe utilisateur pour l'authentification login/mot de passe
--s3secretkey
Authentification AWS S3 : clé secrète
--s3accesskey
Authentification AWS S3 : clé d'accès
--s3region
Authentification AWS S3 : région
--s3token
Jeton de sécurité AWS S3 - utilisé avec les identifiants temporaires STS
--s3alternate
Spécifiez ce drapeau si vous devez utiliser une URL S3 basée sur le chemin
--azurekey
Clé d'authentification Azure

EXEMPLES

Liste de répertoire WebDav
davix-ls dav://example.org/dir1/dir2/

Liste de compartiment AWS S3
davix-ls s3://bucket.example.org/collection/

Liste longue avec authentification VOMS WebDav dans un environnement Grid
davix-ls -P grid davs://grid-storage.example.org/dir1/dir2/

Liste longue avec WebDav + TLS listing de répertoire
davix-ls -l davs://example.org/dir1/dir2/
