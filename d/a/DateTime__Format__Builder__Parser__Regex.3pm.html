NOM

DateTime::Format::Builder::Parser::Regex - Analyse d'expressions régulières pour les dates

VERSION

version 0.83

SYNOPSIS

my $parser = DateTime::Format::Builder->create_parser(
    regex  => qr/^(\d\d\d\d)(\d\d)(\d\d)T(\d\d)(\d\d)(\d\d)$/,
    params => [qw( year month day hour minute second )],
);

SPÉCIFICATION

En plus des clés communes, "Regex" prend en charge :

  • regex

    regex est une expression régulière qui devrait capturer des éléments de la chaîne de date/heure. C'est un élément requis. C'est la clé dont la présence indique que la spécification appartient à cette classe.

  • params

    params est un tableau d'alias de noms de clés. Les captures de l'expression régulière sont mappées à ces alias (de $1 au premier élément, $2 au deuxième, etc.) et transmises à "DateTime->new". C'est un élément requis.

  • extra

    extra est une table de hachage d'arguments supplémentaires que vous souhaitez fournir à "DateTime->new". Par exemple, vous pourriez définir les valeurs par défaut pour l'"year" ou "time_zone" :

    extra => { year => 2004, time_zone => "Australia/Sydney" },
  • constructor est soit un tableau, soit un pointeur de fonction. Si c'est un tableau, le premier élément est un nom de classe ou un objet, et le second élément est un nom de méthode (ou un pointeur de fonction puisque Perl autorise ce genre de chose). Les arguments de l'appel sont tout ce qui se trouve dans $p et tout ce qui est donné dans l'option "extra" ci-dessus.

    Si seul un pointeur de fonction est fourni, alors il est appelé avec les arguments $self, $p et "extra".

    En bref :

    $self->$coderef( %{$p}, %{ $self->{extra} } );

    La méthode est censée renvoyer un objet DateTime valide, ou "undef" en cas d'échec, mais peut conceptuellement retourner n'importe quoi. Tant que c'est 'true'.
