NOM

Date::Manip::Lang::finnish - Prise en charge de la langue finnoise.

RÉSUMÉ

Ce module contient une liste de mots et d'expressions prenant en charge la langue. Il n'est pas destiné à être utilisé directement (d'autres modules Date::Manip le chargeront au besoin).

EXPRESSIONS LINGUISTIQUES

Voici une liste de tous les mots et expressions linguistiques utilisés pour écrire des heures et/ou des dates.

Toutes les chaînes sont insensibles à la casse.

Heures du matin/ de l'après-midi
Voici une liste d'expressions utilisées pour désigner l'heure du matin ou de l'après-midi lorsqu'une heure est saisie en format 12 heures plutôt qu'en format 24 heures. Par exemple, en anglais, l'heure « 17:00 » pourrait être spécifiée comme « 5:00 PM ».

L'heure du matin et de l'après-midi peut être désignée par les ensembles de mots suivants :

AM
A.M.
aamulla
aamupäivällä
aamupaivalla
PM
P.M.
illalla
iltapäivällä
iltapaivalla
Chaque ou tous
Il existe une liste de mots qui spécifient chaque occurrence de quelque chose. Ils sont utilisés dans les phrases suivantes : 
EACH Monday
EVERY Monday
EVERY month

Les mots suivants peuvent être utilisés :

joka
jokainen
Prochaine/précédente/dernière occurrence
Il existe une liste de mots qui peuvent être utilisés pour spécifier l'occurrence suivante, précédente ou dernière de quelque chose. Ces mots pourraient être utilisés dans les phrases suivantes : 
NEXT week
LAST Tuesday
PREVIOUS Tuesday
LAST day of the month

Les mots suivants peuvent être utilisés :

Prochaine occurrence :

ensi

Occurrence précédente :

viime

Dernière occurrence :

viimeinen
Mots delta pour avancer/ reculer dans le temps
Lors de l'analyse des deltas, il existe des mots qui peuvent être utilisés pour spécifier que le delta se référera à un moment dans le futur ou dans le passé (par rapport à une certaine date). En anglais, par exemple, vous pourriez dire : 
IN 5 days
5 days AGO

Les mots suivants peuvent être utilisés pour spécifier des deltas qui se réfèrent respectivement à des dates passées ou futures :

sitten
ssa
myöhemmin
myohemmin

Mots ignorés
Lors de l'écriture des dates sous leurs formes courantes, il existe un certain nombre de mots qui ne sont généralement pas importants.

Il y a souvent un mot qui apparaît dans une phrase pour indiquer qu'une heure va être spécifiée ensuite. En anglais, vous utiliseriez le mot AT dans l'exemple :

3 décembre à 12:00

Les mots suivants peuvent être utilisés :

kello

Un autre mot est utilisé pour désigner un membre d'un ensemble. En anglais, vous utiliseriez les mots IN ou OF :

1er jour DE décembre
1er jour EN décembre

Les mots suivants peuvent être utilisés :

Non défini dans cette langue

Un autre mot est utilisé pour spécifier que quelque chose est à une certaine date. En anglais, vous utiliseriez ON :

LE 5 juillet

Les mots suivants peuvent être utilisés :

Non défini dans cette langue
Mots qui définissent la date, l'heure, ou les deux
Il existe des mots qui peuvent être utilisés pour spécifier une date, une heure, ou les deux par rapport à maintenant.

Les mots qui définissent la date sont similaires aux mots anglais 'yesterday' ou 'tomorrow'. Ils sont spécifiés comme un delta qui est ajouté à l'heure actuelle pour obtenir une date. L'heure n'est PAS définie cependant, donc le delta n'est utilisé que partiellement (il ne devrait inclure que les champs année, mois, semaine et jour).

Les mots suivants peuvent être utilisés :

huomenna             +0:0:0:1:0:0:0
tanaan               0:0:0:0:0:0:0
toissapaivana        -0:0:0:2:0:0:0
toissapäivänä        -0:0:0:2:0:0:0
tänään               0:0:0:0:0:0:0
yesterdayeilen       -0:0:0:1:0:0:0
ylihuomenna          +0:0:0:2:0:0:0

Les mots qui ne définissent que l'heure du jour sont similaires aux mots anglais 'noon' ou 'midnight'.

Les mots suivants peuvent être utilisés :

keskipaiva           12:00:00
keskipaivalla        12:00:00
keskipäivä           12:00:00
keskipäivällä        12:00:00
keskiyo              00:00:00
keskiyolla           00:00:00
keskiyö              00:00:00
keskiyöllä           00:00:00

Des mots qui définissent à la fois l'heure et la date (par rapport à l'heure et à la date actuelles) sont également disponibles.

En anglais, le mot 'now' est l'un d'entre eux.

Les mots suivants peuvent être utilisés :

nyt                  0:0:0:0:0:0:0
Séparateurs heure/minute/seconde
Lors de la spécification de l'heure du jour, le séparateur le plus courant est les deux-points (:) qui peut être utilisé pour les deux séparateurs.

Certaines langues utilisent des paires différentes. Par exemple, le français vous permet de spécifier l'heure sous la forme 13h30:20, il utiliserait donc les paires suivantes :

: :
h :

La première colonne est le séparateur heure-minute et la deuxième colonne est le séparateur minute-seconde. Les deux sont des expressions régulières perl. Lors de la création d'une nouvelle traduction, soyez conscient que les expressions régulières avec des caractères utf-8 peuvent être délicates. Par exemple, n'incluez pas l'expression '[x]' où 'x' est un caractère utf-8.

Une paire de deux-points est TOUJOURS autorisée pour toutes les langues. Si une langue autorise des paires supplémentaires, elles sont listées ici :

\.  \.
Séparateur de fraction de seconde
Lors de la spécification des fractions de seconde, la méthode la plus courante est d'utiliser un point décimal (.). Certaines langues peuvent spécifier un séparateur différent qui pourrait être utilisé. Si c'est le cas, c'est une expression régulière.

Le point décimal est TOUJOURS autorisé pour toutes les langues. Si une langue autorise un autre séparateur, il est listé ici :

Non défini dans cette langue
