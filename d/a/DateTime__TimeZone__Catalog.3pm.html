NOM

DateTime::TimeZone::Catalog - Fournit une liste de tous les noms de fuseaux horaires valides

DESCRIPTION

Ce module contient une liste énumérée de tous les fuseaux horaires système connus, afin que les applications puissent facilement présenter une liste de fuseaux horaires.
