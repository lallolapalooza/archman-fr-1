NOM

Data::Uniqid - Extension Perl pour la génération simple d'identifiants uniques

SYNPOSIS

use Data::Uniqid qw ( suniqid uniqid luniqid );

$id = suniqid;
$id = uniqid;
$id = luniqid;

DESCRIPTION

Data::Uniqid fournit trois routines simples pour générer des identifiants uniques. Ces identifiants sont codés en système Base62 pour les rendre courts et pratiques (par exemple, pour les utiliser dans une URL).

suinqid
  génère un identifiant très court valide uniquement pour le localhost et avec une 
  durée de vie de 1 jour

uniqid
  génère un identifiant court valide sur l'hôte local 
luniqid 
  génère un identifiant long valide partout et pour toujours
