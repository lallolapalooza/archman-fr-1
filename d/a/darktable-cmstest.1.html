NOM

darktable-cmstest - tester si le sous-système de gestion des couleurs de votre ordinateur est correctement configuré

SYNTAXE

darktable-cmstest

DESCRIPTION

darktable est une application de flux de travail pour la photographie numérique pour Linux, Mac OS X et plusieurs autres Unix. Elle est décrite plus en détail dans darktable(1).

darktable-cmstest examine si le sous-système de gestion des couleurs de votre ordinateur est correctement configuré et affiche des informations utiles sur les profils de moniteur installés.
