NOM

Data::Grove -- support pour les structures profondément imbriquées

SYNTAXE

use Data::Grove;
$objet = MonPackage->new;
package MonPackage;
@ISA = qw{Data::Grove};

DESCRIPTION

"Data::Grove" fournit un support pour les structures d'arbre ou de graphe profondément imbriquées. "Data::Grove" est destiné principalement aux auteurs de modules Perl écrivant des modules avec de nombreux types ou classes d'objets qui doivent être manipulés et étendus d'une manière cohérente et flexible.

"Data::Grove" est mieux utilisé en créant un ensemble de classes de base de ``données'' puis en ajoutant incrémentalement des fonctionnalités aux classes de données de base en utilisant des modules d'``extension''. Une raison de cette conception est que les classes de données peuvent être remplacées et que les modules d'extension peuvent fonctionner avec de nouvelles sources de données. Par exemple, ces autres sources de données pourraient être basées sur des disques, des réseaux ou construites au-dessus d'une base de données relationnelle.

Deux modules d'extension fournis avec "Data::Grove" sont "Data::Grove::Parent" et "Data::Grove::Visitor". "Data::Grove::Parent" ajoute une propriété `"Parent"' aux objets grove et implémente une méthode `"root"' pour les objets grove afin de retourner le nœud racine de l'arbre depuis n'importe quel point de l'arbre, et une méthode `"rootpath"' pour retourner une liste de nœuds entre le nœud racine et le nœud ``courant''. "Data::Grove::Visitor" ajoute des méthodes de rappel `"accept"' et `"accept_name"' qui rappellent votre gestionnaire ou module récepteur par nom de type d'objet ou par nom de l'objet.

"Data::Grove" les objets ne contiennent pas de références parentales, la récupération de mémoire de Perl les supprimera lorsqu'ils ne seront plus référencés et que des sous-structures pourront être partagées entre plusieurs structures. "Data::Grove::Parent" est utilisé pour créer des objets temporaires avec des pointeurs parents.

Les propriétés des classes de données sont accessibles directement en utilisant les fonctions de hachage de Perl (c'est-à-dire `"$objet->{Propriété}"'). Les modules d'extension peuvent également définir des propriétés qu'ils supportent ou utilisent, par exemple Data::Grove::Parent ajoute les propriétés `"Parent"' et `"Raw"' et Visitor dépend des propriétés `"Name"' et `"Content"'.

Voir le module "XML::Grove" pour un exemple d'implémentation de "Data::Grove".

MÉTHODES

nouveau( PROPRIÉTÉS )
Retourne un nouvel objet béni dans SubClass, avec les propriétés données. PROPRIÉTÉS peut être soit une liste de paires clé/valeur, soit un seul hachage contenant des paires clé/valeur, soit un objet "Data::Grove" existant. Si un objet "Data::Grove" existant est passé à `nouveau()', une copie superficielle de cet objet sera retournée. Une copie superficielle signifie que vous obtenez un nouvel objet, mais que tous les objets sous-jacents font toujours référence aux objets d'origine.
