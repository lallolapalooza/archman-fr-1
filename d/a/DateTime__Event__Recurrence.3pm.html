ion de DateTime::Set pour créer

SYNOPSI

S 
use DateTime;
use DateTime::Event::Recurrence;

my $dt = DateTime->new( year   => 2000,
                        month  => 6,
                        day    => 20,
                      );
my $daily_set = DateTime::Event::Recurrence->daily;
my $dt_next = $daily_set->next( $dt );
my $dt_previous = $daily_set->previous( $dt );
my $bool = $daily_set->contains( $dt );
my @days = $daily_set->as_list( start => $dt1, end => $dt2 );
my $iter = $daily_set->iterator;
while ( my $dt = $iter->next ) {
    print ' ', $dt->datetime;
}

DESCRIPTIO

N

Ce module fournit des méthodes de commodité qui vous permettent de créer facilement des objets "DateTime::Set" pour diverses récurrences, telles que « une fois par mois » ou « chaque jour ». Vous pouvez également créer des récurrences plus complexes, telles que « chaque lundi, mercredi et jeudi à 10h00 et 14h00

»
.

UTILISATI

ON
•
yearly monthly weekly daily hourly minutely secondly

Ces méthodes renvoient toutes un nouvel objet "DateTime::Set" représentant la récurrence

donnée. 
my $daily_set = DateTime::Event::Recurrence->
daily;

Si aucun paramètre n'est donné, les membres de l'ensemble se produisent chacun au début de la récurrence spécifiée. début de la récurrence

spécifiée.

Par exemple, par défaut, la méthode monthly() renvoie un ensemble contenant le premier jour de chaque

mois.

Sans paramètres, la méthode weekly() renvoie un ensemble contenant les lun

dis.

Cependant, vous pouvez passer des paramètres pour modifier le moment où ces datetimes se produisent. Les paramètres sont les mêmes que ceux donnés au constructeur "DateTime::Duration" pour spécifier la longueur d'une durée. Par exemple, pour créer un ensemble représentant une récurrence quotidienne à 10h30 chaque jour, nous écrivons

ceci : 
my $daily_at_10_30_set =
    DateTime::Event::Recurrence->daily( hours => 10, minutes =>
30 );

Pour représenter chaque mardi (deuxième jour de la

semaine) : 
my $weekly_on_tuesday_set =
    DateTime::Event::Recurrence->weekly( days =>
2 );

Une durée négative compte à rebours depuis la fin de la période. Cela est fait de la même manière que ce qui est spécifié dans la RFC 2445

(iCal).

Les durées négatives sont utiles pour créer des récurrences telles que le dernier jour de cha

que mois : 
my $last_day_of_month_set =
    DateTime::Event::Recurrence->monthly( days =>
-1 );

Vous pouvez également fournir plusieurs ensembles d'arguments de durée, comme

ceci : 
my $set = DateTime::Event::Recurrence->daily
              ( hours =>   [ 10, 14,  -1 ],
                minutes => [ 15, 30, -15 ],
);

Cela spécifie une récurrence se produisant chaque jour à ces 9 heures

différentes : 
10:15,  10:30,  10:45,   # +10h         ( +15min / +30min / dernière 15min (-15) )
14:15,  14:30,  14:45,   # +14h         ( +15min / +30min / dernière 15min (-15) )
23:15,  23:30,  23:45,   # dernière 1h (-1) ( +15min / +30min / dernière 15min
(-15) )

Pour créer un ensemble de récurrences se produisant toutes les trente secondes, nous pourrions

faire ceci : 
my $every_30_seconds_set =
    DateTime::Event::Recurrence->minutely( seconds => [ 0, 30
] );

Ce qui suit est également valide. Voir la section sur le paramètre

"interval" : 
my $every_30_seconds_set =
    DateTime::Event::Recurrence->secondly( interval =>
30
)
;

DateTimes

invalides

Les valeurs invalides sont ignorées à

l'exécution.

Par exemple, lorsque des jours sont ajoutés à un mois, le résultat est vérifié pour un jour inexistant (comme le 31 ou le 30), et les datetimes invalides sont

ignorés.

Un autre exemple serait de créer un ensemble via la méthode daily() et de spécifier "hours

=>
25".

Le paramètre

"days"

Le paramètre "days" peut être combiné avec les récurrences yearly, monthly et weekly, ce qui donne six significations possibles

: 
# mardi de chaque semaine
my $set = DateTime::Event::Recurrence->weekly( days => 2 );
# 10ème jour de chaque mois
my $set = DateTime::Event::Recurrence->monthly( days => 10 );
# deuxième semaine complète de chaque mois, le mardi
my $set = DateTime::Event::Recurrence->monthly( weeks => 2, days => 2 );
# 10ème jour de chaque année
my $set = DateTime::Event::Recurrence->yearly( days => 10 );
# 10ème jour de chaque décembre
my $set = DateTime::Event::Recurrence->yearly( months => 12, days => 10 );
# deuxième semaine de chaque année, le mardi
my $set = DateTime::Event::Recurrence->yearly( weeks => 2, days => 2 )
;

Les jours de la semaine peuvent également être appelés par leur nom, comme spécifié dans la RFC 2445 (iCal)

: 
my $weekly_on_tuesday_set =
    DateTime::Event::Recurrence->weekly( days => 'tu' )
;

Le paramètre "days" a pour valeur par défaut « le premier jour ». Voir aussi la section sur le paramètre "week_start_day"

. 
# deuxième semaine complète de chaque mois, le lundi
my $set = DateTime::Event::Recurrence->monthly( weeks => 2 );
# deuxième mardi de chaque mois
my $set = DateTime::Event::Recurrence->monthly( weeks => 2, days => "tu", week_start_day => "1tu"
)
;

Les paramètres "interval" et

"start"

Le paramètre "interval" représente la fréquence à laquelle la règle de récurrence se

répète.

Le paramètre optionnel "start" spécifie où commencer le comptage

: 
my $dt_start = DateTime->new( year => 2003, month => 6, day => 15 );
my $set = DateTime::Event::Recurrence->daily
              ( interval => 11,
                hours    => 10,
                minutes  => 30,
                start    => $dt_start,
              )
;

Cela spécifie une récurrence qui se produit à 10h30 le jour spécifié par "start => $dt", puis tous les 11 jours avant et après $dt. Nous obtenons donc un ensemble comme celui-ci

: 
...
2003-06-04T10:30:00,
2003-06-15T10:30:00,
2003-06-26T10:30:00,
..
.

Dans ce cas, la méthode est utilisée pour spécifier l'unité, donc daily() signifie que notre unité est un jour, et "interval => 11" spécifie la quantité de notre

unité.

Le paramètre "start

" ne doit avoir au
cun fuseau horaire.

Le paramètre "week_start_day

"

Le "week_start_day" représente la manière dont la « première semaine » d'une période est calculée

:

"mo", "tu", "we", "th", "fr", "sa", "su" - La première semaine est celle qui commence par ce jour de la semaine et qui a le plus de jours dans cette période. Fonctionne pour les récurrences "weekly" et "yearly"

.

"1mo", "1tu", "1we", "1th", "1fr", "1sa", "1su" - La première semaine est celle qui commence par ce jour de la semaine et qui a tous les jours dans cette période. Cela fonctionne pour les récurrences weekly(), monthly() et yearly

().

Le "week_start_day" a pour valeur par défaut "1mo", sauf dans les récurrences yearly (yearly()) qui ont pou

r valeur par
défaut "mo".

FUSEAUX

HORAIRES

Les récurrences sont créées dans le fuseau horaire « flottant », comme spécifié dans le module "Date

Time".

Si vous souhaitez spécifier un fuseau horairepour une récurrence, vous pouvez faire ceci en appelant set_time_zone() sur l'ensemble retourné

: 
my $daily = DateTime::Event::Recurrence->daily;
$daily->set_time_zone( 'Europe/Berlin' )
;

Vous pouvez également passer un objet "DateTime.pm" avec un fuseau horaire à la méthode next() ou previous() de l'ensemble

: 
my $dt = DateTime->today( time_zone => 'Europe/Berlin' );
my $next = $daily->next($dt)
;

Une récurrence peut être affectée par les changements d'heure d'été, il serait donc possible de spécifier une récurrence qui crée des dates et heures inexistantes. Comme "DateTime.pm" lance une exception s'il lui est demandé de créer une date et heure inexistante, veuillez faire attention lorsque vous définissez un fuseau horaire pour votre

récurrence.

Il pourrait être préférable d'utiliser toujours "U

TC" pour vos ensembles, puis de convertir l'o
bjet retourné vers le fuseau horaire souhaité.

Secondes

intercalaires

Il n'y a pas de secondes intercalaires, car les récurrences sont créées dans le fuseau horaire

'floating'.

La valeur 60 pour les secondes (la seconde intercalaire) est ignorée. Si vous voulez vraiment la seconde intercalaire, alors spécifiez la seconde comme -

1
.
