SYNOPSI

S

Ce module contient une liste de mots et d'expressions prenant en

charge la langue. Il n'est pas destiné à être utilisé direct
ement (d'autres modules Date::Manip le chargeront au besoin).

EXPRESSIONS DE LA

LANGUE

Voici une liste de tous les mots et expressions de la langue utilisés pour écrire des heures et/ou des

dates.

Toutes les chaînes ne sont pas sensibles à la

casse.

Mots
ignorés
Lors de l'écriture des dates sous des formes courantes, il y a un certain nombre de mots qui ne sont généralement pas importants.

Il y a souvent un mot qui apparaît dans une phrase pour désigner qu'une heure va être spécifiée ensuite. En anglais, vous utiliseriez le mot AT dans

l'exemple : 
3 décembre à
12:00

Les mots suivants peuvent être

utilisés : 
kl
kl.
klokken

Un autre mot est utilisé pour désigner un membre d'un ensemble. En anglais, vous utiliseriez les mots

IN ou OF : 
1er jour DE décembre
1er jour EN
décembre

Les mots suivants peuvent être

utilisés : 
første
foerste

Un autre mot est utilisé pour spécifier que quelque chose est à une certaine date. En anglais, vous

utiliseriez ON : 
LE 5
juillet

Les mots suivants peuvent être

utilisés : 
på
p
aa
Mots qui définissent la date, l'heure, ou les
deux
Il y a certains mots qui peuvent être utilisés pour spécifier une date, une heure, ou les deux par rapport à maintenant.

Les mots qui définissent la date sont similaires aux mots anglais « yesterday » ou « tomorrow ». Ils sont spécifiés comme un delta qui est ajouté à l'heure actuelle pour obtenir une date. L'heure n'est PAS définie cependant, donc le delta n'est utilisé que partiellement (il ne devrait inclure que les champs année, mois, semaine et

jour).

Les mots suivants peuvent être

utilisés : 
i dag                0:0:0:0:0:0:0
i gaar               -0:0:0:1:0:0:0
i går                -0:0:0:1:0:0:0
i morgen             +0:0:0:1:
0:0:0

Les mots qui définissent seulement l'heure du jour sont similaires aux mots anglais « noon » ou « midnight

».

Les mots suivants peuvent être

utilisés : 
midnatt              00:00:00
midt paa dagen       12:00:00
midt på dagen        12:
00:00

Les mots qui définissent l'heure et la date entières (par rapport à l'heure et la date actuelles) sont également

disponibles.

En anglais, le mot « now » fait partie de

ceux-ci.

Les mots suivants peuvent être

utilisés : 
naa                  0:0:0:0:0:0:0
nå                   0:0:0:0:
0:
0:0 t id="Heure/Minute/Seconde">Heure/Minute/Seconde séparateurs
Lors de la spécification de l'heure, le séparateur le plus courant est les deux-points (:), qui peut être utilisé pour les deux séparateurs.

Certaines langues utilisent des paires différentes. Par exemple, le français vous permet de spécifier l'heure sous la forme 13h30:20, il utiliserait donc les paires suivantes :

: :
h :

La première colonne est le séparateur heure-minute et la seconde colonne est le séparateur minute-seconde. Les deux sont des expressions régulières perl. Lors de la création d'une nouvelle traduction, notez que les expressions régulières avec des caractères utf-8 peuvent être délicates. Par exemple, n'incluez pas l'expression '[x]' où 'x' est un caractère utf-8.

Une paire de deux-points est TOUJOURS autorisée pour toutes les langues. Si une langue autorise des paires supplémentaires, elles sont listées ici :

Non défini dans cette langue
Séparateur de seconde fractionnaire
Lors de la spécification des secondes fractionnaires, la méthode la plus courante est d'utiliser un point décimal (.). Certaines langues peuvent spécifier un séparateur différent qui pourrait être utilisé. Si c'est le cas, c'est une expression régulière.

Le point décimal est TOUJOURS autorisé pour toutes les langues. Si une langue autorise un autre séparateur, il est listé ici :

Non défini dans cette langue
