Data::Perl::Role::Collection::Hash(3) Documentation Perl fournie par l'utilisateur Data::Perl::Role::Collection::Hash(3)

NOM

Data::Perl::Role::Collection::Hash - Classe d'encapsulation pour la structure de hachage intégrée de Perl.

VERSION

version 0.002011

SYNOPSIS

use Data::Perl qw/hash/;
my $hash = hash(a => 1, b => 2);
$hash->values; # (1, 2)
$hash->set('foo', 'bar'); # (a => 1, b => 2, foo => 'bar')

DESCRIPTION

Cette classe fournit un wrapper et des méthodes pour interagir avec un hachage. Toutes les méthodes qui retournent une liste le font via un objet Data::Perl::Collection::Array.

MÉTHODES FOURNIES

new($key, $value, ...)
Étant donné une liste optionnelle de clés/valeurs, construit un nouvel objet Data::Perl::Collection::Hash initialisé avec les clés/valeurs et le retourne.
get($key, $key2, $key3...)
Retourne une liste de valeurs dans le hachage pour les clés données.

Cette méthode nécessite au moins un argument.

set($key => $value, $key2 => $value2...)
Définit les éléments dans le hachage aux valeurs données. Il retourne les nouvelles valeurs définies pour chaque clé, dans le même ordre que les clés passées à la méthode.

Cette méthode nécessite au moins deux arguments, et s'attend à un nombre pair d'arguments.

delete($key, $key2, $key3...)
Supprime les éléments avec les clés données.

Retourne une liste de valeurs dans le hachage pour les clés supprimées.

keys
Retourne la liste des clés dans le hachage.

Cette méthode n'accepte aucun argument.

exists($key)
Retourne vrai si la clé donnée est présente dans le hachage.

Cette méthode nécessite un seul argument.

defined($key)
Retourne vrai si la valeur d'une clé donnée est définie.

Cette méthode nécessite un seul argument.

values
Retourne la liste des valeurs dans le hachage.

Cette méthode n'accepte aucun argument.

kv
Retourne les paires clé/valeur dans le hachage sous forme de tableau de références de tableaux. 
for my $pair ( $object->option_pairs ) {
    print "$pair->[0] = $pair->[1]\n";
}

Cette méthode n'accepte aucun argument.

elements/all
Retourne les paires clé/valeur dans le hachage sous forme de liste aplatie.

Cette méthode n'accepte aucun argument.

clear
Réinitialise le hachage à une valeur vide, comme "%hash = ()".

Cette méthode n'accepte aucun argument.

count
Retourne le nombre d'éléments dans le hachage. Utile également pour vérifier si ce n'est pas vide : "has_options => 'count'".

Cette méthode n'accepte aucun argument.

is_empty
Si le hachage est peuplé, retourne faux. Sinon, retourne vrai.

Cette méthode n'accepte aucun argument.

accessor($key)
accessor($key, $value)
Si un argument est passé, retourne la valeur de la clé spécifiée. Si deux arguments sont passés, définit la valeur de la clé spécifiée.

Lorsqu'elle est appelée comme un setter, cette méthode retourne la valeur qui a été définie.

shallow_clone
Cette méthode retourne un clone superficiel de la référence de hachage. La valeur retournée est une référence à un nouveau hachage avec les mêmes clés et valeurs. Il est *superficiel* car toutes les valeurs qui étaient des références dans l'original seront les *mêmes* références dans le clone.
_array_class
Le nom de la classe dont les listes retournées sont des instances ; c'est-à-dire "Data::Perl::Collection::Array".

Les sous-classes de cette classe peuvent remplacer cette méthode.

Notez que "each" est délibérément omis, en raison de son interaction avec état de l'itérateur de hachage. "keys" ou "kv" sont beaucoup plus sûrs.
