DATACOPY(FreeTDS) FreeTDS (manuel de référence FreeTDS) DATACOPY(FreeTDS)

NOM

datacopy — déplacer les données d'une table entre deux serveurs

SYNTAXE

datacopy [-vdE] {-t | -a | -c propriétaire} [-b taille_lot] [-p taille_paquet] [-S serveur/nomutilisateur/motdepasse/base_de_données/table_ou_vue] [-D serveur/nomutilisateur/motdepasse/base_de_données/table] [-T taille_texte]

DESCRIPTION

datacopy est un utilitaire distribué avec FreeTDS. datacopy déplacera les données d'une table d'un serveur à un autre sans nécessiter de fichiers intermédiaires. datacopy est beaucoup plus rapide et plus efficace que freebcp out/in.

datacopy utilise l'API bcp de db-lib intégrée à FreeTDS. Cette API est également disponible pour les développeurs d'applications.

datacopy peut être utilisé pour migrer des données entre Sybase ASE et SQL Server ou vice versa.

OPTIONS

-t
Tronque la table cible avant de charger les données.
-a
Ajoute les données à la table cible.
-c propriétaire
Crée la table cible avec le même schéma que la table source. datacopy soumettra une commande ‘CREATE TABLE’ sur le serveur cible en utilisant le propriétaire spécifié dans la commande, par ex. ‘CREATE TABLE propriétaire.table (...).’
-b taille_lot
Le nombre de lignes par lot de données copiées. Chaque lot de données est effectivement 'validé' dans la base de données. La valeur par défaut est 1000.
-p taille_paquet
Le nombre d'octets, par paquet réseau, envoyés vers et depuis les serveurs. Une taille de paquet augmentée peut améliorer les performances.
-T taille_texte
Spécifie la taille de la colonne TEXT/IMAGE depuis le réseau.
-v
Produit une sortie détaillée, y compris des chronométrages de diagnostic.
-d
Produit une sortie TDSDUMP de FreeTDS. (Débogage sérieux uniquement !)
-S serveur/nomutilisateur/motdepasse/base_de_données/table_ou_vue
Les informations de connexion pour le serveur source et l'emplacement/nom de la table (ou vue) à copier. Si non spécifié, datacopy invite l'utilisateur à fournir les informations.
-D serveur/nomutilisateur/motdepasse/base_de_données/table
Les informations de connexion pour le serveur de destination et l'emplacement/nom de la table cible. Si non spécifié, datacopy invite l'utilisateur à fournir les informations.
-E
Conserve les valeurs d'identité.

VOIR AUSSI

freebcp(1), defncopy(1), bsqldb(1), tsql(1), Guide de l'utilisateur FreeTDS.

HISTORIQUE

datacopy est apparu pour la première fois dans FreeTDS 0.64.
