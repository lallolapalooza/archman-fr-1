NOM

Data::Perl::Role::Collection::Array - Classe d'emballage pour la structure de tableau intégrée de Perl.

VERSION

version 0.002011

SYNOPSIS

use Data::Perl qw/array/;
my $array = array(1, 2, 3);
$array->push(5);
$array->grep(sub { $_ > 2 })->map(sub { $_ ** 2 })->elements; # (3, 5);

DESCRIPTION

Cette classe fournit un emballage et des méthodes pour interagir avec un tableau. Toutes les méthodes qui retournent une liste le font via un objet Data::Perl::Collection::Array.

MÉTHODES FOURNIES

new($value, $value, ....)
Construit un nouvel objet Data::Perl::Collection::Array initialisé avec les valeurs passées et le retourne.
count
Retourne le nombre d'éléments dans le tableau. 
$stuff = Data::Perl::Collection::Array->new(qw/foo bar baz boo/);
print $stuff->count; # affiche 4

Cette méthode n'accepte aucun argument.

is_empty
Retourne une valeur booléenne qui est vraie lorsque le tableau n'a aucun élément. 
$stuff->is_empty ? die "No options!\n" : print "Good boy.\n";

Cette méthode n'accepte aucun argument.

elements/all
Retourne tous les éléments du tableau sous forme de tableau (pas une référence de tableau). 
my @options = $stuff->elements;
print "@options\n";    # affiche "foo bar baz boo"

Cette méthode n'accepte aucun argument.

get($index)
Retourne un élément du tableau par son index. Vous pouvez aussi utiliser des index négatifs, tout comme avec la gestion des tableaux intégrée de Perl. 
my $option = $stuff->get(1);
print "$option\n";    # affiche "bar"

Si l'élément spécifié n'existe pas, cela retournera "undef".

Cette méthode n'accepte qu'un seul argument.

pop
Tout comme la fonction intégrée de Perl "pop".

Cette méthode n'accepte aucun argument.

push($value1, $value2, value3 ...)
Tout comme la fonction intégrée de Perl "push". Retourne le nombre d'éléments dans le nouveau tableau.

Cette méthode accepte un nombre quelconque d'arguments.

shift
Tout comme la fonction intégrée de Perl "shift".

Cette méthode n'accepte aucun argument.

unshift($value1, $value2, value3 ...)
Tout comme la fonction intégrée de Perl "unshift". Retourne le nombre d'éléments dans le nouveau tableau.

Cette méthode accepte un nombre quelconque d'arguments.

splice($offset, $length, @values)
Tout comme la fonction intégrée de Perl "splice". En contexte scalaire, cela retourne le dernier élément supprimé, ou "undef" si aucun élément n'a été supprimé. En contexte liste, cela retourne tous les éléments supprimés du tableau, emballés dans un objet Collection::Array.

Cette méthode requiert au moins un argument.

first( sub { ... } )
Cette méthode retourne le premier élément correspondant dans le tableau, tout comme la fonction "first" de List::Util. La correspondance est faite avec une référence de sous-programme que vous passez à cette méthode. La sous-programme sera appelée pour chaque élément du tableau jusqu'à ce qu'un élément corresponde ou que tous les éléments aient été vérifiés. 
my $found = $stuff->find_option( sub {/^b/} );
print "$found\n";    # affiche "bar"

Cette méthode requiert un seul argument.

first_index( sub { ... } )
Cette méthode retourne l'index du premier élément correspondant dans le tableau, tout comme la fonction "first_index" de List::MoreUtils. La correspondance est faite avec une référence de sous-programme que vous passez à cette méthode. La sous-programme sera appelée pour chaque élément du tableau jusqu'à ce qu'un élément corresponde ou que tous les éléments aient été vérifiés.

Cette méthode requiert un seul argument.

grep( sub { ... } )
Cette méthode retourne chaque élément correspondant à un critère donné, tout comme la fonction "grep" intégrée de Perl. Cette méthode requiert un sous-programme qui implémente la logique de correspondance. La liste retournée est fournie sous forme d'objet Collection::Array. 
my @found = $stuff->grep( sub {/^b/} );
print "@found\n";    # affiche "bar baz boo"

Cette méthode requiert un seul argument.

map( sub { ... } )
Cette méthode transforme chaque élément du tableau et retourne un nouveau tableau, tout comme la fonction "map" intégrée de Perl. Cette méthode requiert un sous-programme qui implémente la transformation. La liste retournée est fournie sous forme d'objet Collection::Array. 
my @mod_options = $stuff->map( sub { $_ . "-tag" } );
print "@mod_options\n";    # affiche "foo-tag bar-tag baz-tag boo-tag"

Cette méthode requiert un seul argument.

reduce( sub { ... } )
Cette méthode transforme un tableau en une seule valeur, en passant à une fonction la valeur courante et la valeur suivante du tableau, tout comme la fonction "reduce" de List::Util. La réduction est faite avec une référence de sous-programme que vous passez à cette méthode. 
my $found = $stuff->reduce( sub { $_[0] . $_[1] } );
print "$found\n";    # affiche "foobarbazboo"

Cette méthode requiert un seul argument.

sort
sort( sub { ... } )
Retourne les éléments du tableau dans l'ordre trié.

Vous pouvez fournir une référence de sous-programme facultative pour le tri (comme vous pouvez le faire avec la fonction "sort" intégrée de Perl). Cependant, au lieu d'utiliser $a et $b dans ce sous-programme, vous devrez utiliser $_[0] et $_[1]. La liste retournée est fournie sous forme d'objet Collection::Array.

# croissant ASCIIbetique
my @sorted = $stuff->sort();
# Décroissant alphabétique
my @sorted_options = $stuff->sort( sub { lc $_[1] cmp lc $_[0] } );
print "@sorted_options\n";    # affiche "foo boo baz bar"

Cette méthode accepte un seul argument.

sort_in_place
sort_in_place( sub { ... } )
Trie le tableau sur place, modifiant la valeur de l'attribut.

Vous pouvez fournir une référence de sous-programme facultative pour le tri (comme vous pouvez le faire avec la fonction "sort" intégrée de Perl). Cependant, au lieu d'utiliser $a et $b, vous devrez utiliser $_[0] et $_[1] à la place. La liste retournée est fournie sous forme d'objet Collection::Array.

Cette méthode accepte un seul argument.

reverse
Retourne les éléments du tableau dans l'ordre inversé. La liste retournée est fournie sous forme d'objet Collection::Array.

Cette méthode n'accepte aucun argument.

<dt id="shuffle">shuffle
Renvoie les éléments du tableau dans un ordre aléatoire, comme "shuffle" de List::Util. La liste renvoyée est fournie sous la forme d'un objet Collection::Array.

Cette méthode n'accepte aucun argument.

uniq
Renvoie le tableau avec tous les éléments dupliqués supprimés, comme "uniq" de List::MoreUtils. La liste renvoyée est fournie sous la forme d'un objet Collection::Array.

Cette méthode n'accepte aucun argument.

head($count)
Renvoie les premiers $count éléments du tableau. Si $count est supérieur au nombre d'éléments du tableau, le tableau (sans "undef"superflus) est renvoyé. Un $count négatif signifie « tous les éléments sauf les $count derniers ». La liste renvoyée est fournie sous la forme d'un objet Collection::Array.
tail($count)
Renvoie les $count derniers éléments du tableau. Si $count est supérieur au nombre d'éléments du tableau, le tableau (sans "undef"superflus) est renvoyé. Un $count négatif signifie « tous les éléments sauf les $count premiers ». La liste renvoyée est fournie sous la forme d'un objet Collection::Array.
join($str)
Concatène chaque élément du tableau en utilisant le séparateur donné en argument, tout comme la fonction "join" de Perl. 
my $joined = $stuff->join(':');
print "$joined\n";    # affiche "foo:bar:baz:boo"

Cette méthode nécessite un seul argument.

print($handle, $str)
Affiche la sortie de join($str) sur $handle. $handle vaut STDOUT par défaut, et join $str vaut join()'s valeur par défaut ','. 
$joined = $stuff->print(*STDERR, ';'); # affiche foo;bar;baz sur STDERR
set($index, $value)
Étant donné un index et une valeur, définit la valeur de l'élément du tableau spécifié.

Cette méthode renvoie la valeur à l'index $index après l'affectation.

Cette méthode nécessite deux arguments.

delete($index)
Supprime l'élément à l'index donné du tableau.

Cette méthode renvoie la valeur supprimée, soit sous forme de tableau ou de scalaire selon la sémantique du contexte de splice. Notez que si aucune valeur n'existe, elle

renverra "undef".

Cette méthode nécessite un argument.

insert($index, $value)
Insère un nouvel élément dans le tableau à l'index donné.

Cette méthode renvoie la nouvelle valeur à l'index $index, soit sous forme de tableau ou de scalaire selon la sémantique du contexte de splice.

Cette méthode nécessite deux arguments.

clear
Vide le tableau entier, comme "@array = ()".

Cette méthode ne définit pas de valeur de retour.

Cette méthode n'accepte aucun argument.

accessor($index)
accessor($index, $value)
Cette méthode fournit un accesseur get/set pour le tableau, basé sur les index de tableau. Si un seul argument est passé, elle renvoie la valeur à l'index spécifié. Si deux arguments sont passés, elle définit la valeur de l'index spécifié.

Lorsqu'elle est appelée en tant que setter, cette méthode renvoie la nouvelle valeur à l'index $index.

Cette méthode accepte un ou deux arguments.

natatime($n)
natatime($n, $code)
Cette méthode renvoie un itérateur qui, à chaque appel, renvoie $n éléments supplémentaires du tableau, dans l'ordre, comme "natatime" de List::MoreUtils. Un coderef peut être fourni en option ; il sera appelé sur chaque groupe de $n éléments du tableau.

Cette méthode accepte un ou deux arguments.

shallow_clone
Cette méthode renvoie une copie superficielle de la référence de tableau. La valeur de retour est une référence vers un nouveau tableau avec les mêmes éléments. Elle est superficielle car tout élément qui était une référence dans l'original sera la même référence dans la copie.
flatten
Cette méthode renvoie une liste d'éléments du tableau. Cette méthode est un alias de la méthode elements .
flatten_deep($level)
Cette méthode renvoie une liste aplatie d'éléments du tableau. Elle aplatira les tableaux contenus dans le tableau racine récursivement - la profondeur est contrôlée par le paramètre optionnel $level .
