PRÉFAC

E

Ce paquet se compose d'une bibliothèque C et d'un module Perl (qui utilise la bibliothèque C en interne) pour toutes sortes de calculs de dates basés sur le calendrier grégorien (celui utilisé dans tous les pays occidentaux aujourd'hui), se conformant ainsi à toutes les normes et standards pertinents : ISO/R 2015-1971, DIN 1355 et, dans une certaine mesure, ISO 8601 (lorsqu'il s'applique)

.

(Voir aussi http://www.engelschall.com/u/sb/download/Date-Calc/DIN1355/ pour un scan de partie du document « DIN 1355 » (en allemand))

.

Le module gère bien entendu correctement les numéros d'année à partir de 2000 (conformité « Year 2000 » ou « Y2K ») -- en fait tous les numéros d'année de 1 au plus grand entier positif représentable sur votre système (qui est au moins 32767) peuvent être

traités.

Ceci n'est cependant pas vrai pour les fonctions d'importation/exportation de ce paquet qui constituent une interface aux fonctions POSIX internes de date et d'heure de votre système, qui ne peuvent couvrir que des dates dans les plages suivantes

: 
01-Jan-1970 00:00:00 GMT .. 19-Jan-2038 03:14:07 GMT [Unix etc.]
01-Jan-1904 00:00:00 LT  .. 06-Feb-2040 06:28:15 LT  [MacOS Classic]
(LT = heure
locale)

Notez que ce paquet projette le calendrier grégorien en arrière jusqu'à l'année 1 ap. J.-C. -- même si le calendrier grégorien n'a été adopté qu'en 1582, principalement par les pays catholiques européens, en obéissance au décret correspondant du pape Grégoire XIII de cette

année.

Certains pays (principalement protestants) ont continué à utiliser le calendrier julien (utilisé jusqu'alors) jusqu'à aussi tard que le début du 20e

siècle.

Enfin, notez que ce paquet n'est pas destiné à faire tout ce que vous pourriez jamais imaginer automatiquement pour vous ; il est plutôt destiné à servir d'outils (au meilleur de l'esprit et des traditions d'UNIX) qui devrait cependant toujours vous amener là où vous voulez

aller.

                    $result--;

            }
        }
        if ($temp != 0)
        {
            $temp /= 7;
            $result -= ($temp << 1);
        }
    }
    if ($minus) { return -$result; }
    else        { return  $result;
} }
