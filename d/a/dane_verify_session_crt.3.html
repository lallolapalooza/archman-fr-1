NOM

dane_verify_session_crt - fonction d'API

SYNOPIS

#include <gnutls/dane.h>

int dane_verify_session_crt(dane_state_t s, gnutls_session_t session, const char * hostname, const char * proto, unsigned int port, unsigned int sflags, unsigned int vflags, unsigned int * verify);

ARGUMENTS

dane_state_t s
Une structure d'état DANE (peut être NULL)
gnutls_session_t session
Une session gnutls
const char * hostname
Le nom d'hôte associé à la chaîne
const char * proto
Le protocole du service connecté (par ex. tcp)
unsigned int port
Le port du service connecté (par ex. 443)
unsigned int sflags
Indicateurs pour l'initialisation de s (si NULL)
unsigned int vflags
Indicateurs de vérification ; une liste OR de dane_verify_flags_t.
unsigned int * verify
Une liste OR de dane_verify_status_t.

DESCRIPTION

Cette fonction vérifiera la chaîne de certificats de la session par rapport aux contraintes CA et/ou au certificat disponible via DANE. Voir dane_verify_crt() pour plus d'informations.

Cela ne vérifiera pas la validité de la chaîne ; à moins que la vérification DANE ne soit limitée aux certificats finaux, cela doit être effectué séparément en utilisant gnutls_certificate_verify_peers3().

RETOUR

un code d'erreur négatif en cas d'erreur et DANE_E_SUCCESS (0) lorsque les entrées DANE ont été correctement analysées, que celles-ci aient été vérifiées ou non (voir verify pour cette information). Si aucune entrée utilisable n'a été rencontrée, DANE_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
