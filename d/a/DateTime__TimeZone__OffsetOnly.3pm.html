NOM

DateTime::TimeZone::OffsetOnly - Un objet DateTime::TimeZone qui ne contient qu'un décalage

VERSION

version 2.65

SYNOPSIS

my $offset_tz = DateTime::TimeZone->new( name => '-0300' );

DESCRIPTION

Cette classe est utilisée pour fournir l'API DateTime::TimeZone nécessaire à DateTime.pm, mais avec un décalage fixe. Un objet de cette classe retourne toujours le même décalage que celui donné dans son constructeur, quelle que soit la date.

UTILISATION

Cette classe a les mêmes méthodes qu'un objet fuseau horaire réel, mais la méthode category() retourne undef.

DateTime::TimeZone::OffsetOnly->new ( offset => $offset )

La valeur fournie au paramètre offset doit être une chaîne de caractères telle que "+0300". Les chaînes seront converties en nombres par la fonction DateTime::TimeZone::offset_as_seconds().

$tz->offset_for_datetime( $datetime )

Quelle que soit la date donnée, le décalage fourni au constructeur est toujours utilisé.

$tz->name()

$tz->short_name_for_datetime()

Ces deux méthodes retournent le décalage sous forme de chaîne de caractères.
