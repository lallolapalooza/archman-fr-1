DateTime::TimeZone::Local(3) Documentation Perl fournie par l'utilisateur DateTime::TimeZone::Local(3)

NOM

DateTime::TimeZone::Local - Déterminer le fuseau horaire du système local

VERSION

version 2.65

SYNTAXE

my $tz = DateTime::TimeZone->new( name => 'local' );
my $tz = DateTime::TimeZone::Local->TimeZone();

DESCRIPTION

Ce module fournit une interface pour déterminer le fuseau horaire du système local. La plupart des fonctionnalités pour ce faire se trouvent dans des sous-classes spécifiques au système d'exploitation.

UTILISATION

Cette classe fournit les méthodes suivantes :

DateTime::TimeZone::Local->TimeZone()

Ceci tente de charger une sous-classe appropriée et lui demande de trouver le fuseau horaire local. Cette méthode est appelée lorsque vous transmettez "local" comme nom de fuseau horaire à "DateTime:TimeZone->new()".

Si votre système d'exploitation n'est pas explicitement géré, vous pouvez créer un module dont le nom est de la forme "DateTime::TimeZone::Local::$^O". S'il existe, il sera utilisé au lieu de se rabattre sur la sous-classe Unix.

Si aucun module spécifique au système d'exploitation n'existe, nous nous rabattons sur l'utilisation de la sous-classe Unix.

Voir DateTime::TimeZone::Local::Unix, DateTime::TimeZone::Local::Android, DateTime::TimeZone::Local::hpux, DateTime::TimeZone::Local::Win32, et DateTime::TimeZone::Local::VMS pour les détails spécifiques au système d'exploitation.

SOUS CLASSEMENT

Si vous souhaitez créer une nouvelle sous-classe spécifique au système d'exploitation, il existe plusieurs méthodes fournies par ce module que vous devriez connaître.

$class->Methods()

Cette méthode doit être fournie par votre classe. Elle doit fournir une liste de méthodes qui seront appelées pour tenter de déterminer le fuseau horaire local.

Chacune de ces méthodes est censée renvoyer un nouvel objet "DateTime::TimeZone" si elle parvient à déterminer le fuseau horaire.

$class->FromEnv()

Cette méthode essaie de trouver un fuseau horaire valide dans une valeur de %ENV. Elle appelle "$class->EnvVars()" pour déterminer quelles clés examiner.

Pour l'utiliser à partir d'une sous-classe, renvoyez simplement "FromEnv" comme l'un des éléments de "$class->Methods()".

$class->EnvVars()

Cette méthode doit être fournie par votre sous-classe. Elle doit renvoyer une liste de variables d'environnement à vérifier par "$class->FromEnv()".

Votre classe doit toujours inclure la clé "TZ" parmi les variables à vérifier.

$class->_IsValidName($name)

Étant donné un nom de fuseau horaire possible, ceci renvoie un booléen indiquant si le nom semble valide ou non. Il renvoie toujours faux pour "local" afin d'éviter les boucles infinies.

EXEMPLE SOUS CLASSE

Voici un exemple simple de sous-classe :

package DateTime::TimeZone::SomeOS;
use strict;
use warnings;
use base 'DateTime::TimeZone::Local';
sub Methods { qw( FromEnv FromEther ) }
sub EnvVars { qw( TZ ZONE ) }
sub FromEther
{
    my $class = shift;
    ...
}
