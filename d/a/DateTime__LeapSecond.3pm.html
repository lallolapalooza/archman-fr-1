DateTime::LeapSecond(3pm) Documentation Perl fournie par l'utilisateur DateTime::LeapSecond(3pm)

NOM

DateTime::LeapSecond - table et utilitaires des secondes intercalaires

VERSION

version 1.66

SYNOPSIS

use DateTime;
use DateTime::LeapSecond;
print "Les secondes intercalaires entre les années 1990 et 2000 sont ";
print DateTime::Leapsecond::leap_seconds($utc_rd_2000)
    - DateTime::Leapsecond::leap_seconds($utc_rd_1990);

DESCRIPTION

Ce module est utilisé pour calculer les secondes intercalaires pour un jour Rata Die donné. Il est utilisé lorsque DateTime ne peut pas compiler la version XS de ce code.

Cette bibliothèque est connue pour être précise pour les dates jusqu'à juin 2020.

Il n'y a pas de secondes intercalaires avant 1972, car c'est l'année où ce système a été implémenté.

  • leap_seconds($rd)

    Retourne le nombre de secondes intercalaires accumulées pour un jour donné.

  • extra_seconds($rd)

    Retourne le nombre de secondes intercalaires pour un jour donné, dans la plage -2 .. 2.

  • day_length($rd)

    Retourne le nombre de secondes pour un jour donné, dans la plage 86398 .. 86402.
