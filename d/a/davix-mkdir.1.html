NOM

davix-mkdir - Outil de création de répertoires basé sur libdavix.

SYNOPSIS

davix-mkdir [options]... url

DESCRIPTION

davix-mkdir est un outil pour créer des répertoires ou des collections avec des services compatibles HTTP, Webdav ou REST.
La commande supporte les protocoles Http (http(s)://), WebDav (dav(s)://) et S3 (s3(s)://).

davix-mkdir est alimenté par libdavix. Voir libdavix(3) pour plus de détails.

OPTIONS

Options communes :

--debug
Mode débogage
--header, -H
Ajouter un champ d'en-tête à la requête (ex : -H "Depth: 1" )
--help, -h
Afficher ce message d'aide
--metalink OPT
Support Metalink. (OPT=failover[défaut]|no)
--module, -P PLUGIN_NAME
Charger un plugin ou un profil par nom
--redirection OPT
Support de redirection transparent. (OPT=yes[défaut]|no)
--proxy, -x URL
URL du serveur proxy SOCKS5. (ex : socks5://login:pass@socks.example.org)
--trace
Traçe des portées spécifiques, les options incluent :
file - Interface fichier Davix
posix - Interface POSIX Davix
xml - Sortie de l'analyseur XML
ssl - Détails SSL et certificats
header - En-têtes des requêtes HTTP
body - Corps des requêtes HTTP
chain - Informations sur les chaînes d'IO
core - Informations de configuration et diverses
grid - Informations diverses provenant de tiers
socket - Informations sur les sockets
locks - Informations sur le verrouillage WebDAV
all - Traçe tout
--version
Afficher la version

Options de sécurité :

--capath CA_path
Ajouter un répertoire supplémentaire d'autorités de certification
--cert, -E cred_path
Certificat client au format PEM
--key priv_path
Clé privée au format PEM
--insecure, -k
Désactiver les vérifications de credentials SSL
--userlogin
Identifiant utilisateur pour l'authentification login/mot de passe
--userpass
Mot de passe utilisateur pour l'authentification login/mot de passe
--s3secretkey
Authentification AWS S3 : clé secrète
--s3accesskey
Authentification AWS S3 : clé d'accès
--s3region
Authentification AWS S3 : région
--s3token
Jeton de sécurité AWS S3 - utilisé avec les credentials temporaires STS
--s3alternate
Spécifiez ce drapeau si vous avez besoin d'utiliser une URL S3 basée sur le chemin
--azurekey
Clé d'authentification Azure

EXEMPLES

Créer un répertoire via WebDav
davix-mkdir dav://webdav.example.org/dir/directory_to_create

Créer un répertoire sur un stockage Grid avec authentification VOMS
davix-mkdir -P grid davs://grid-storage.example.org/dir1/directory_to_create
