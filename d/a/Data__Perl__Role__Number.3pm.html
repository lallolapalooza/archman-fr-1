NOM

Data::Perl::Role::Number - Classe enveloppante pour les nombres scalaires Perl.

VERSION

version 0.002011

SYNOPSIS

use Data::Perl qw/number/;
my $num = number(123);
$num->add(5); # $num == 128
$num->div(2); # $num == 64

DESCRIPTION

Cette classe fournit un enveloppement et des méthodes pour interagir avec des chaînes scalaires.

MÉTHODES FOURNIES

Toutes ces méthodes modifient la valeur de l'attribut sur place. Toutes les méthodes retournent la nouvelle valeur.

new($valeur)
Construit un nouvel objet Data::Perl::Collection::Number initialisé avec la valeur passée, et le retourne.
add($valeur)
Ajoute la valeur actuelle de l'attribut à $valeur.
sub($valeur)
Soustrait $valeur de la valeur actuelle de l'attribut.
mul($valeur)
Multiplie la valeur actuelle de l'attribut par $valeur.
div($valeur)
Divise la valeur actuelle de l'attribut par $valeur.
mod($valeur)
Retourne la valeur actuelle de l'attribut modulo $valeur.
abs
Définit la valeur actuelle de l'attribut à sa valeur absolue.
