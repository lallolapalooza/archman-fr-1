SYNOPSI

S 
use DateTime;
use DateTime::Event::ICal;
my $dt = DateTime->new( year   => 2000,
                        month  => 6,
                        day    => 20,
                      );
my $set = DateTime::Event::ICal->recur( 
     dtstart => $dt,
     freq =>    'daily',
     bymonth => [ 10, 12 ],
     byhour =>  [ 10 ]
);
my $dt_next = $set->next( $dt );
my $dt_previous = $set->previous( $dt );
my $bool = $set->contains( $dt );
my @days = $set->as_list( start => $dt1, end => $dt2 );
my $iter = $set->iterator;
while ( my $dt = $iter->next ) {
    print ' ', $dt->datetime;
}

Ce module fournit des méthodes de convenance qui vous permettent de créer facilement des objets "DateTime::Set" pour

Cette méthode prend des paramètres qui correspondent aux parties de règle

  • dtstart

    Un objet DateTime, qui est la date de

    début.

    Cette date et heure n'est pas incluse dans la récurrence, sauf si elle satisfait les règles de la

    récurrence.

    Un ensemble peut donc être utilisé pour créer des règles d'exclusion (rfc2445 "exrule"), qui n'incluent pas "dtst

    • l" est inutile, bien que cela soit actuellement autorisé.
  • freq

    L'un des

    suivants : 
    "yearly", "monthly", "weekly", "daily",
"hourly", "minutely",
    "secondly"

    Voir la documentation de "DateTime::Event::Recurrence"

    L'intervalle entre les récurrences. C'est un multiplicateur pour la valeur spécifiée par "freq". La valeur par défaut

    Donc, si vous spécifiez une "freq" de "yearly" et
