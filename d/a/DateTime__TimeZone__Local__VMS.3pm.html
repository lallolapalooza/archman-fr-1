NOM

DateTime::TimeZone::Local::VMS - Déterminer le fuseau horaire local du système sur VMS

VERSION

version 2.65

SYNOPSIS

my $tz = DateTime::TimeZone->new( name => 'local' );
my $tz = DateTime::TimeZone::Local->TimeZone();

DESCRIPTION

Ce module fournit des méthodes pour déterminer le fuseau horaire local sur une plateforme VMS.

NOTE : Il s'agit essentiellement d'une ébauche en attente d'une implémentation par quelqu'un qui connaît quelque chose sur VMS.

COMMENT LE FUSEAU HORAIRE EST DÉTERMINÉ

Cette classe essaie les méthodes suivantes pour déterminer le fuseau horaire local :

•
%ENV

Nous vérifions les variables d'environnement suivantes :

  • TZ
  • SYS$TIMEZONE_RULE
  • SYS$TIMEZONE_NAME
  • UCX$TZ
  • TCPIP$TZ
