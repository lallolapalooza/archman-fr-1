NOM

Date::Language::Bulgarian - localisation pour Date::Format

DESCRIPTION

C'est la localisation bulgare pour Date::Format. Il est important de noter que le code source de ce module est en utf8. Toutes les chaînes qu'il produit sont en utf8, donc il est actuellement sûr de l'utiliser uniquement avec l'anglais. Il vous appartient d'essayer et de convertir la sortie lors de l'utilisation de différents Date::Language::* dans la même application. Ceci devrait être abordé à l'avenir.

SYNTAXE

use strict; 
use warnings;
use Date::Language;
local $\=$/;
my $template ='%a %b %e %T %Y (%Y-%m-%d %H:%M:%S)';
my $time=1290883821; #ou utilisez simplement time();
my @lt = localtime($time);
my %languages = qw(English GMT German EEST Bulgarian EET);
binmode(select,':utf8');
foreach my $l(keys %languages){
    my $lang = Date::Language->new($l);
    my $zone = $languages{$l};
    print $/. "$l $zone";
    print $lang->time2str($template, $time);
    print $lang->time2str($template, $time, $zone);
    print $lang->strftime($template, \@lt);
}
