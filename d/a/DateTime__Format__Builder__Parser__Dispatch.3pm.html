NOM

DateTime::Format::Builder::Parser::Dispatch - Dirige les analyseurs par groupe

VERSION

version 0.83

SYNOPIS

package SampleDispatch;
use DateTime::Format::Builder (
    parsers => {
        parse_datetime => [
            {
                Dispatch => sub {
                    return 'fnerk';
                }
            }
        ]
    },
    groups => {
        fnerk => [
            {
                regex  => qr/^(\d{4})(\d\d)(\d\d)$/,
                params => [qw( year month day )],
            },
        ]
    }
);

DESCRIPTION

"Dispatch" ajoute un autre type d'analyseur à "Builder", permettant de diriger l'analyse selon des noms de groupe.

SPÉCIFICATION

"Dispatch" n'a qu'une seule clé : "Dispatch". La valeur doit être une référence à une sous-routine qui renvoie l'une des valeurs suivantes :

  • "undef", signifiant qu'aucun groupe n'a pu être trouvé.
  • Une liste vide, signifiant qu'aucun groupe n'a pu être trouvé.
  • Une seule chaîne de caractères, signifiant : utiliser ce groupe.
  • Une liste de chaînes de caractères, signifiant : utiliser ces groupes dans cet ordre.

Les groupes sont spécifiés de manière très similaire à l'exemple dans le SYNOPSIS. Ils suivent le même format que lorsque vous les spécifiez pour les méthodes.

EFFETS DE BORD

Votre analyseur de groupe peut également être un analyseur Dispatch. Ainsi, vous pourriez potentiellement vous retrouver avec un analyseur récursif à l'infini.
