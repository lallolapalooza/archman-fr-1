DESCRIPTIO

N

Il s'agit d'une classe simple pour représenter des objets de durée. Ces objets sont utilisés à chaque fois que vous effectuez des calculs de dates avec

DateTime.

Voir la section « How DateTime Math Works » de la documentation de DateTime pour plus de détails. En résumé : on ne peut pas en g

énéral convertir entre secondes, minutes, jours et mois, donc cette classe ne le fera jamais. À la place, créez la durée avec
les unités désirées dès le départ, par exemple en appelant la méthode de soustraction/delta appropriée sur un objet DateTime.

Retourne la longueur de la durée dans les unités (n'importe lesquelles de celles qui peuvent être passées à "DateTime::Duration->new") données comme arguments. $dur->in_units( 'weeks', 'days' );      # (0, 0)

DateTime::Duration->compare( $duration1, $duration2, $base_datetime

)

Ceci est une méthode de classe qui peut être utilisée pour comparer ou trier des durées. La comparaison est effectuée en ajoutant chaque durée à l'objet DateTime spécifié et en comparant les dates et heures résultantes. Cela est nécessaire car, sans une base, de nombreuses durées ne sont pas comparables. Par exemple, 1 mois peut être plus ou moins long que 29 jours, selon la date et l'heure à laquelle il est

ajouté.

Si aucune date et heure de base n'est donnée, le résultat de "DateTime->now" est utilisé à la place. L'utilisation de cette valeur par défaut donnera des résultats non répétables si elle est utilisée pour comparer deux objets durée contenant des unités différentes. Elle donnera également des résultats non répétables si les durées contiennent plusieurs types d'unités, comme les mois et les

jours.

Cependant, si vous savez que les deux objets ne consistent qu'en un seul type d'unité (mois ou jours ou heures, etc.), et que chaque durée contient le même type d'

unité, alors les résultats de la c
omparaison seront répétables.

$dur->years, $dur->months, $dur->weeks, $dur->days, $dur->hours, $dur->minutes, $dur->seconds, $dur->

nanoseconds

Ces méthodes retournent des nombres indiquant combien de l'unité donnée l'objet représente, après avoir effectué une conversion vers toute unité plus grande. Par exemple, les jours sont d'abord convertis en semaines, puis le reste est retourné. Ces nombres sont toujours

positifs.

Voici ce que chaque méthode retourne

: 
$dur->years       == abs( $dur->in_units('years') )
$dur->months      == abs( ( $dur->in_units( 'months', 'years' ) )[0] )
$dur->weeks       == abs( $dur->in_units( 'weeks' ) )
$dur->days        == abs( ( $dur->in_units( 'days', 'weeks' ) )[0] )
$dur->hours       == abs( $dur->in_units( 'hours' ) )
$dur->minutes     == abs( ( $dur->in_units( 'minutes', 'hours' ) )[0] )
$dur->seconds     == abs( $dur->in_units( 'seconds' ) )
$dur->nanoseconds == abs( ( $dur->in_units( 'nanoseconds', 'seconds' ) )[0]
)

Si cela semble confus, rappelez-vous que vous pouvez toujours utiliser la "$dur->in_units" méthode pour spécifier exactement ce que vous
