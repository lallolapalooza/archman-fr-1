NOM

dane_query_to_raw_tlsa - Fonction de l'API

SYNTAXE

#include <gnutls/dane.h>

int dane_query_to_raw_tlsa(dane_query_t q, unsigned int * data_entries, char *** dane_data, int ** dane_data_len, int * secure, int * bogus);

ARGUMENTS

dane_query_t q
La structure du résultat de la requête
unsigned int * data_entries
Pointeur défini sur le nombre d'entrées dans la requête
char *** dane_data
Pointeur contenant un tableau d'éléments rdata DNS, terminé par un pointeur NULL ; l'appelant doit garantir que les données référencées restent valides jusqu'à l'appel de dane_query_deinit().
int ** dane_data_len
Pointeur contenant la longueur n en octets des éléments dane_data
int * secure
Pointeur mis à vrai si le résultat est validé de manière sécurisée, faux si la validation a échoué ou si le domaine interrogé n'a aucune information de sécurité
int * bogus
Pointeur mis à vrai si le résultat n'était pas sécurisé en raison d'un échec de sécurité

DESCRIPTION

Cette fonction fournira les données DANE de la réponse de la requête.

Les pointeurs dane_data et dane_data_len sont alloués avec gnutls_malloc() pour contenir les données de la structure de résultat de la requête (les éléments individuels
dane_data pointent simplement vers les données d'origine et ne sont pas alloués séparément). Les dane_data retournés ne sont valides que pendant la durée de vie de q.

RETOUR

En cas de succès, DANE_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
