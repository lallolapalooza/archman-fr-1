NOM

Date::Manip::Lang::turkish - Support de la langue turque.

SYNOPSIS

Ce module contient une liste de mots et d'expressions prenant en charge la langue. Il n'est pas destiné à être utilisé directement (d'autres modules Date::Manip le chargeront selon les besoins).

EXPRESSIONS DE LA LANGUE

Voici une liste de tous les mots et expressions de la langue utilisés pour écrire des heures et/ou des dates.

Toutes les chaînes ne sont pas sensibles à la casse.

Heures du matin/ de l'après-midi
Voici une liste d'expressions utilisées pour désigner l'heure du matin ou de l'après-midi lorsqu'une heure est saisie en format 12 heures plutôt qu'en format 24 heures. Par exemple, en anglais, l'heure « 17:00 » pourrait être spécifiée comme « 5:00 PM ».

L'heure du matin et de l'après-midi peut être désignée par les ensembles de mots suivants :

ögleden önce
ogleden once
öğleden sonra
ogleden sonra
Chaque ou tous
Il existe une liste de mots qui spécifient chaque occurrence de quelque chose. Ceux-ci sont utilisés dans les phrases suivantes : 
EACH Monday
EVERY Monday
EVERY month

Les mots suivants peuvent être utilisés :

her
Prochaine/précédente/dernière occurrence
Il existe une liste de mots qui peuvent être utilisés pour spécifier la prochaine, la précédente ou la dernière occurrence de quelque chose. Ces mots pourraient être utilisés dans les phrases suivantes : 
NEXT week
LAST Tuesday
PREVIOUS Tuesday
LAST day of the month

Les mots suivants peuvent être utilisés :

Prochaine occurrence :

gelecek
sonraki

Occurrence précédente :

onceki
önceki

Dernière occurrence :

son
sonuncu
Mots delta pour aller en avant/en arrière dans le temps
Lors de l'analyse des deltas, il y a des mots qui peuvent être utilisés pour spécifier que le delta fera référence à un moment futur ou à un moment passé (par rapport à une certaine date). En anglais, par exemple, vous pourriez dire : 
IN 5 days
5 days AGO

Les mots suivants peuvent être utilisés pour spécifier des deltas qui font référence à des dates passées ou futures respectivement :

gecmis
geçmiş
gecen
geçen
gelecek
sonra
Mode affaires
Cela contient deux listes de mots qui peuvent être utilisées pour spécifier un delta standard (c'est-à-dire non-affaires) ou un delta affaires.

Auparavant, elle était utilisée pour indiquer si le delta était approximatif ou exact, mais maintenant cette liste n'est pas utilisée sauf pour forcer le delta à être standard.

Les mots suivants peuvent être utilisés :

tam
yaklasik
yaklaşık

Les mots suivants peuvent être utilisés pour spécifier un delta affaires :

Mots ignorés
Lors de l'écriture de dates sous des formes courantes, il y a un certain nombre de mots qui ne sont généralement pas importants.

Il y a souvent un mot qui apparaît dans une phrase pour désigner qu'une heure va être spécifiée ensuite. En anglais, vous utiliseriez le mot AT dans l'exemple :

December 3 at 12:00

Les mots suivants peuvent être utilisés :

saat

Un autre mot est utilisé pour désigner un membre d'un ensemble. En anglais, vous utiliseriez les mots IN ou OF :

1st day OF December
1st day IN December

Les mots suivants peuvent être utilisés :

of

Un autre mot est utilisé pour spécifier que quelque chose est à une certaine date. En anglais, vous utiliseriez ON :

ON July 5th

Les mots suivants peuvent être utilisés :

on
Mots qui définissent la date, l'heure, ou les deux
Il y a certains mots qui peuvent être utilisés pour spécifier une date, une heure, ou les deux par rapport à maintenant.

Mots that set the date are similar to the English words 'yesterday' or 'tomorrow'. These are specified as a delta which is added to the current time to get a date. The time is NOT set however, so the delta is only partially used (it should only include year, month, week, and day fields).

The following words may be used:

bugun                0:0:0:0:0:0:0
bugün                0:0:0:0:0:0:0
dun                  -0:0:0:1:0:0:0
dün                  -0:0:0:1:0:0:0
yarin                +0:0:0:1:0:0:0
yarın                +0:0:0:1:0:0:0

Words that set only the time of day are similar to the English words 'noon' or 'midnight'.

The following words may be used:

gece yarisi          00:00:00
gece yarısı          00:00:00
oglen                12:00:00
yarim                12:30:00
yarım                12:30:00
öğlen                12:00:00

Words that set the entire time and date (relative to the current time and date) are also available.

In English, the word 'now' is one of these.

The following words may be used:

simdi                0:0:0:0:0:0:0
şimdi                0:0:0:0:0:0:0
Hour/Minute/Second separators
When specifying the time of day, the most common separator is a colon (:) which can be used for both separators.

Some languages use different pairs. For example, French allows you to specify the time as 13h30:20, so it would use the following pairs:

: :
h :

The first column is the hour-minute separator and the second column is the minute-second separator. Both are perl regular expressions. When creating a new translation, be aware that regular expressions with utf-8 characters may be tricky. For example, don't include the expression '[x]' where 'x' is a utf-8 character.

A pair of colons is ALWAYS allowed for all languages. If a language allows additional pairs, they are listed here:

Not defined in this language
Fractional second separator
When specifying fractional seconds, the most common way is to use a decimal point (.). Some languages may specify a different separator that might be used. If this is done, it is a regular expression.

The decimal point is ALWAYS allowed for all languages. If a language allows another separator, it is listed here:

Not defined in this language
