NOM

cdawson, dawson - intégrale de Dawson

SYNTAXE

#include <cerf.h>

double _Complex cdawson ( double _Complex z );

double dawson ( double x );

DESCRIPTION

La fonction cdawson renvoie l'intégrale de Dawson D(z) = exp(-z^2) intégrale de 0 à z de exp(t^2) dt = sqrt(pi)/2 * exp(-z^2) * erfi(z).

La fonction dawson prend un argument réel x et renvoie le résultat réel D(x).

VOIR AUSSI

Le calcul de D(z) est basé sur la fonction de Faddeeva w_of_z(3); pour calculer D(x), la partie imaginaire im_w_of_x(3) est utilisée.

Autres fonctions d'erreur complexes : w_of_z(3), voigt(3), cerf(3), erfcx(3), erfi(3).

Page d'accueil : http://apps.jcns.fz-juelich.de/libcerf
