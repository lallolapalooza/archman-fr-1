DESCRIPTIO

N

DateTime::Locale est principalement une fabrique pour les différentes sous-classes de locale. Il fournit également quelques fonctions pour obtenir des informations sur toutes les locales

disponibles.

Si vous souhaitez savoir quelles méthodes sont dis

ponibles pour les objets de locale, veuillez li
re la documentation de DateTime::Locale::FromData.

UTILISATI

ON

Ce module fournit les méthodes de classe suivantes

:

DateTime::Locale->load( $locale_code | $locale_name

)

Renvoie l'objet de locale pour le code ou le nom de locale spécifié - voir la documentation de DateTime::Locale::Catalog pour la liste des codes et noms disponibles. Le nom fourni peut être soit le nom anglais, soit le nom

natif.

Si la locale demandée est introuvable, une recherche de repli a lieu pour trouver un remplaçant

approprié.

L'ordre de la recherche de repli est

: 
{langue}-{écriture}-{territoire}
{langue}-{écriture}
{langue}-{territoire}-{variante}
{langue}-{territoire}
{langue}

Ex. Pour le code de locale "es-XX-UNKNOWN", la recherche de repli serait

: 
es-XX-UNKNOWN   # Échec - pas une telle locale
es-XX           # Échec - pas une telle locale
es              # Trouvé - la locale es est renvoyée comme
                # la correspondance la plus proche de l'identifiant
demandé

Ex. Pour le code de locale "es-Latn-XX", la recherche de repli serait

: 
es-Latn-XX      # Échec - pas une telle locale
es-Latn         # Échec - pas une telle locale
es-XX           # Échec - pas une telle locale
es              # Trouvé - la locale es est renvoyée comme
                # la correspondance la plus proche de l'identifiant
demandé

Si aucun remplaçant approprié n'est trouvé, une exception est

levée.

La locale chargée est mise en cache, afin que les objets de locale puissent être des singletons. Appeler "DateTime::Locale->register_from_data", "DateTime::Locale->add_aliases", ou "DateTime::Locale->remove_

alias" efface
le cache.

DateTime::Locale->register_from_data( $locale_data

)

Cette méthode vous permet d'enregistrer une locale personnalisée. Les données pour la locale sont spécifiées sous forme de hash (ou hashref) où les clés correspondent aux noms de méthodes données dans DateTime::Locale::

FromData.

Si vous voulez juste faire de petits changements par rapport à une locale existante, vous pouvez obtenir les données de cette locale en appelant "$locale->local

e_data".

Voici un exemple de création d'une locale personnalisée basée sur "en-US

" : 
my $locale = DateTime::Locale->load('en-US');
my %data   = $locale->locale_data;
$data{code}               = 'en-US-CUSTOM';
$data{time_format_medium} = 'HH:mm:ss';
DateTime::Locale->register_from_data(%data);
# Affiche 18:24:38
say DateTime->now( locale => 'en-US-CUSTOM' )->strftime('%X');
# Affiche 6:24:38 PM
say DateTime->now( locale => 'en-US' )->strftime('%X')
;

Les clés qui doivent être présentes dans le hash sont les mêmes que les méthodes d'accès fournies par DateTime::Locale::FromData, à l'exception des suivantes

CHARGEMENT DES LOCALES DANS UN SYSTÈME

PRÉ-FORK

Si vous exécutez une application qui utilise le pré-fork (par exemple avec Starman), vous devriez essayer de

charger toutes les locales que vous aurez besoin dans le processus parent. Les locales sont chargées à la
demande, donc les charger une fois dans chaque enfant gaspillera de la mémoire qui pourrait être partagée.

BUGS DE DONNÉES

CLDR

Veuillez noter que toutes les données de locale ont été générées à partir des données de locale du projet CLDR (Common Locale Data Repository). Les données sont incomplètes et peuvent contenir des erreurs dans certaines

locales.

Lors de la signalement d'erreurs dans les données, veuillez d'abord vérifier les sources de données principales, puis si nécessaire signaler les erreurs directement à la source principale via le système de rapport de bugs CLDR. Voir http://unicode.org/cldr/filing_bug_reports.html pour les

détails.

Une fois ces erreurs confirmées, veuillez transmet

tre le rapport d'erreur et les corrections à
la liste de diffusion DateTime, datetime@perl.org.
