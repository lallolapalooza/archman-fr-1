LOCALE

S

Toute méthode prenant des arguments de code ou de nom de locale doit utiliser l'une des valeurs listées ci-dessous. Les codes et les noms sont sensibles à la casse. Le code commence par le code de langue ISO639-1 et peut également inclure des informations identifiant le territoire, l'écriture ou la variante, en tout ou en

partie.

Sélectionnez toujours la locale correspondant le plus près - par exemple, les Canadiens français choisiraient "fr-CA" plutôt que fr - et utilisez toujours les codes de locale de préférence aux noms ; les codes de locale offrent une meilleure compatibilité lors de l'utilisation de modules tiers

localisés.
