DESCRIPTIO

N

Effectue des opérations numériques/textuelles sur l'entrée provenant de

stdin.

'op' est l'opération à effectuer. Si une opération primaire est utilisée, elle doit être listée en premier, éventuellement suivie d'autres opérations. 'champ' est le champ d'entrée à utiliser. 'champ' peut être un nombre (1=premier champ), ou un nom de champ lors de l'utilisation des options -H ou --header-in. Plusieurs champs peuvent être listés avec une virgule (ex. 1,6,8). Une plage de champs peut être listée avec un tiret (ex. 2-8). Utilisez des deux-points pour les opérations qui nécessitent une paire de champs (ex. 'pcov 2:6')

Opérations

primaires

Les opérations primaires affectent la manière dont le fichier est traité. Si elles sont utilisées, l'opération primaire doit être listée en premier. EXEMPLES

Utilisation basique

Afficher la somme et la moyenne des valeurs du champ 1 :

$ seq 10 | datamash sum 1 mean 1
55  5.5

Grouper l'entrée en fonction du champ 1, et sommer les valeurs (par groupe) du champ 2 :

$ cat example.txt
A  10
A  5
B  9
B  11
$ datamash -g 1 sum 2 < example.txt
A  15
B  20
$ datamash groupby 1 sum 2 < example.txt
A  15
B  20

Une entrée non triée doit être triée (avec '-s') :

$ cat example.txt
A  10
C  4
B  9
C  1
A  5
B  11
$ datamash -s -g1 sum 2 < example.txt
A  15
B  20
C  5

Ce qui est équivalent à :

$ cat example.txt | sort -k1,1 | datamash -g 1 sum 2

Lignes d'entête

Utilisez -H (--headers) si le fichier d'entrée contient une ligne d'entête :

# Étant donné un fichier avec nom d'étudiant, majeure, score de test...
$ head -n5 scores_h.txt
Nom            Majeure            Score
Shawn          Ingénierie      47
Caleb          Commerce         87
Christian      Commerce         88
Derek          Arts             60
# Calculer la moyenne et l'écart-type pour chaque majeure
$ datamash --sort --headers --group 2 mean 3 pstdev 3 < scores_h.txt
 (ou utiliser la forme courte)
$ datamash -sH -g2 mean 3 pstdev 3 < scores_h.txt
 (ou utiliser les noms de champs)
$ datamash -sH -g Majeure mean Score pstdev Score < scores_h.txt
GroupBy(Majeure)    mean(Score)   pstdev(Score)
Arts              68.9          10.1
Commerce          87.3           4.9
Ingénierie       66.5          19.1
Santé-Médecine   90.6           8.8
Sciences-Vie      55.3          19.7
Sciences-Sociales   60.2          16.6

Les noms de champs doivent être échappés avec une barre oblique inverse s'ils commencent par un chiffre ou contiennent des caractères spéciaux (tiret, deux-points, virgules). Notez l'interaction entre l'échappement avec une barre oblique inverse et le quoting du shell. La commande équivalente suivante somme les valeurs d'un champ nommé "FOO-BAR" :

$ datamash -H sum FOO\\-BAR < input.txt
$ datamash -H sum 'FOO\-BAR' < input.txt
$ datamash -H sum "FOO\\-BAR" < input.txt

Ignorer les lignes de commentaires

Utilisez -C (--skip-comments) pour ignorer les lignes commençant par les caractères '#' ou ';' (et les espaces optionnels qui les précèdent) :

$ cat in.txt
 #foo   3
bar     5
;baz    7
$ datamash sum 2 < in.txt
15
$ datamash -C sum 2 < in.txt
5

NOM

datamash - Outil de ligne de commande pour les opérations de manipulation de données

SYNTAXE

datamash [OPTION]... OPERATION... [FIELD]...

DESCRIPTION

datamash est un outil de ligne de commande pour effectuer des opérations de calcul et de manipulation de données sur des fichiers texte structurés en colonnes. Il est particulièrement utile pour l'analyse rapide de données brutes sans avoir à écrire de scripts complexes.

Champs multiples

Utilisez une virgule ou un tiret pour spécifier plusieurs champs. Les commandes suivantes sont équivalentes :

$ seq 9 | paste - - -
1   2   3
4   5   6
7   8   9
$ seq 9 | paste - - - | datamash sum 1 sum 2 sum 3
12  15  18
$ seq 9 | paste - - - | datamash sum 1,2,3
12  15  18
$ seq 9 | paste - - - | datamash sum 1-3
12  15  18

Arrondi

Les commandes suivantes illustrent les différentes opérations d'arrondi :

$ ( echo X ; seq -1.25 0.25 1.25 ) \
      | datamash --full -H round 1 ceil 1 floor 1 trunc 1 frac 1
  X     round(X)  ceil(X)  floor(X)  trunc(X)   frac(X)
-1.25   -1        -1       -2        -1         -0.25
-1.00   -1        -1       -1        -1          0
-0.75   -1         0       -1         0         -0.75
-0.50   -1         0       -1         0         -0.5
-0.25    0         0       -1         0         -0.25
 0.00    0         0        0         0          0
 0.25    0         1        0         0          0.25
 0.50    1         1        0         0          0.5
 0.75    1         1        0         0          0.75
 1.00    1         1        1         1          0
 1.25    1         2        1         1          0.25

Inversion des champs

$ seq 6 | paste - - | datamash reverse
2    1
4    3
6    5

Transposition d'un fichier

$ seq 6 | paste - - | datamash transpose
1    3    5
2    4    6

Suppression des lignes dupliquées

Supprime les lignes avec une valeur de clé dupliquée dans le champ 1 (Contrairement aux opérations first et last, rmdup est beaucoup plus rapide et ne nécessite pas de trier le fichier avec -s) :

# Étant donné une liste de fichiers et d'identifiants d'échantillons :
$ cat INPUT
SampleID  File
2         cc.txt
3         dd.txt
1         ab.txt
2         ee.txt
3         ff.txt
# Supprime les lignes avec des identifiants d'échantillons dupliqués (champ 1) :
$ datamash rmdup 1 < INPUT
# ou utiliser un nom de champ :
$ datamash -H rmdup SampleID < INPUT
SampleID  File
2         cc.txt
3         dd.txt
1         ab.txt

Checksums

Calcule la valeur de hachage sha1 de chaque fichier TXT, après avoir calculé la valeur sha1 du contenu de chaque fichier :

$ sha1sum *.txt | datamash -Wf sha1 2

Vérification de la structure du fichier

Vérifie la structure du fichier d'entrée : assure que toutes les lignes ont le même nombre de champs, ou le nombre attendu de lignes/champs :

$ seq 10 | paste - - | datamash check && echo ok || echo fail
5 lignes, 2 champs
ok
$ seq 13 | paste - - - | datamash check && echo ok || echo fail
ligne 4 (3 champs) :
  10  11  12
ligne 5 (2 champs) :
  13
datamash: échec de la vérification : la ligne 5 a 2 champs (la ligne précédente en avait 3)
fail
$ seq 10 | paste - - | datamash check 2 fields 5 lines
5 lignes, 2 champs
$ seq 10 | paste - - | datamash check 4 fields
ligne 1 (2 champs) :
  1     2
datamash: échec de la vérification : la ligne 1 a 2 champs (attendu 4)
$ seq 10 | paste - - | datamash check 7 lines
datamash: échec de la vérification : l'entrée comportait 5 lignes (attendu 7)

Tableaux croisés dynamiques

La tabulation croisée compare la relation entre deux champs. Étant donné le fichier d'entrée suivant :

$ cat input.txt
a    x    3
a    y    7
b    x    21
a    x    40

Affiche la tabulation croisée entre le premier champ (a/b) et le second champ (x/y) - en comptant combien de fois chaque paire apparaît (note : le tri est requis) :

$ datamash -s crosstab 1,2 < input.txt
     x    y
a    2    1
b    1    N/A

Une opération de groupement facultative peut être utilisée à la place du comptage :

$ datamash -s crosstab 1,2 sum 3 < input.txt
     x    y
a    43   7
b    21   N/A
$ datamash -s crosstab 1,2 unique 3 < input.txt
     x    y
a    3,40 7
b    21   N/A

Regroupement de valeurs numériques

Regroupe les valeurs d'entrée dans des intervalles de taille 5 :

$  ( echo X ; seq -10 2.5 10 ) \
      | datamash -H --full bin:5 1
    X  bin(X)
-10.0    -10
 -7.5    -10
 -5.0     -5
 -2.5     -5
  0.0      0
  2.5      0
  5.0      5
  7.5      5
 10.0     10

Regroupement de valeurs textuelles

Hache toute valeur d'entrée en un entier numérique. Un usage typique serait de diviser un fichier d'entrée en N morceaux, en s'assurant que toutes les valeurs d'une certaine clé seront stockées dans le même morceau :

$ cat input.txt
PatientA   10
PatientB   11
PatientC   12
PatientA   14
PatientC   15
Chaque ID de patient est haché dans un bin entre 0 et 9 et imprimé dans le dernier champ :
$ datamash --full strbin 1 < input.txt
PatientA   10    5
PatientB   11    6
PatientC   12    7
PatientA   14    5
PatientC   15    7
La division du fichier d'entrée en morceaux peut être faite avec awk :
$ cat input.txt \
    | datamash --full strbin 1 \
    | awk '{print > $NF ".txt"}'

Extraction de nombres avec getnum

L'opération 'getnum' extrait une valeur numérique du champ :

$ echo zoom-123.45xyz | datamash getnum 1
123.45
getnum accepte une option facultative TYPE d'une seule lettre :
    getnum:n - nombres naturels (entiers positifs, y compris zéro)
    getnum:i - entiers
    getnum:d - nombres décimaux
    getnum:p - nombres décimaux positifs (c'est la valeur par défaut)
    getnum:h - nombres hexadécimaux
    getnum:o - nombres octaux

Exemples :

$ echo zoom-123.45xyz | datamash getnum 1
123.45
$ echo zoom-123.45xyz | datamash getnum:n 1
123
$ echo zoom-123.45xyz | datamash getnum:i 1
-123
$ echo zoom-123.45xyz | datamash getnum:d 1
123.45
$ echo zoom-123.45xyz | datamash getnum:p 1
-123.45
# Hexadécimal 0x123 = 291 décimal
$ echo zoom-123.45xyz | datamash getnum:h 1
291
# Octal 0123 = 83 décimal
$ echo zoom-123.45xyz | datamash getnum:o 1
83
