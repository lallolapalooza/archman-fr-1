DVI2FAX(1) Manuel des commandes générales DVI2FAX(1)

NOM

dvi2fax - convertir un fichier DVI TeX en format de fax G3

SYNTAXE

dvi2fax [-hi|-lo] fichier[.dvi] [options pour dvips]

DESCRIPTION

dvi2fax utilise dvips(1) pour convertir un fichier DVI TeX en PostScript, puis gs(1) pour convertir le PostScript en format de fichier de fax G3.

OPTIONS

-hi utiliser une résolution de fax élevée (204x196 dpi) (par défaut).

-lo utiliser une résolution de fax basse (204x98).

Les options de dvips peuvent suivre le nom du fichier.

EXEMPLE

Exemple : dvi2fax foo -l 2

VOIR AUSSI

dvips(1), gs(1).
