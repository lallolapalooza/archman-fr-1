NOM

dvired - imprimer des fichiers dvi

SYNTAXE

dvired [ options ] fichier

DESCRIPTION

dvired se comporte comme dvips, à la différence près que deux pages logiques sont placées sur chaque feuille de papier physique.

Pour les options, voir dvips(1). Ce programme interprète uniquement les options suivantes :

-o fichier - rediriger la sortie dans fichier.

-P imprimante - diriger la sortie vers imprimante.

-f - diriger la sortie vers stdout.

Toute autre option est transmise directement à dvips.

EXEMPLES

On suppose que la variable PRINTER est définie.

dvired -Plw foo - envoyer la sortie à l'imprimante lw.
dvired -o foo.ps foo - envoyer la sortie au fichier foo.ps.
dvired -pp4-7 foo - envoyer 4 pages (réduites sur 2 feuilles) de foo à l'imprimante.
dvired foo -f | ghostview - - prévisualiser la sortie avec ghostview.

VOIR AUSSI

dvips(1)

BOGUES

dvired est codé en dur pour la taille de papier A4. Si vous souhaitez l'utiliser avec d'autres formats, vous devez modifier les paramètres dans le code source.
