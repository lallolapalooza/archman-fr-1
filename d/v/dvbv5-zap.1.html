dvbv5-zap(1) Commandes utilisateur dvbv5-zap(1)

NOM

dvbv5-zap - Outil DVBv5 pour le syntonisation de services

SYNTAXE

dvbv5-zap [OPTION]... nom-canal

dvbv5-zap [OPTION]... nom-fréquence (pour le mode moniteur ou tous les PID)

DESCRIPTION

dvbv5-zap est un outil de syntonisation en ligne de commande pour les services de télévision numérique qui est conforme à la version 5 de l'API DVB, et rétrocompatible avec l'ancienne API DVB v3.

dvbv5-zap utilise par défaut un nouveau format de fichier de canaux/services capable de prendre en charge tous les types de normes de télévision numérique. Il peut également prendre en charge le format hérité utilisé par les anciennes dvb-apps.

L'outil dvbv5-zap peut être utilisé dans plusieurs modes différents, en fonction des paramètres utilisés.

Veuillez noter que, pour pouvoir l'utiliser en mode enregistrement, où les Identifiants de Paquets (PID) audio et vidéo sont envoyés vers un nœud d'enregistrement dvr, le fichier d'entrée devrait contenir les PID, c'est-à-dire qu'ils devraient avoir été produits par une application de zap TV numérique comme dvbv5-zap.

OPTIONS

-c, --canaux= fichier-nom-canal
Lire la liste des canaux depuis le 'fichier'. Par défaut : ~/.tzap/channels.conf.
-3, --dvbv3
Forcer dvbv5-zap à utiliser uniquement DVBv3. Utile pour tester si la prise en charge de l'API héritée fonctionne.
-a, --adaptateur=adaptateur#
Utiliser l'adaptateur donné. Valeur par défaut : 0.
-A, --pid_audio=pid_audio#
Sélectionner un Identifiant de Paquet (PID) audio différent. Par défaut, utiliser le premier PID audio trouvé dans le fichier-nom-canal.
-C, --cc=code_pays
Définir le pays par défaut à utiliser par les analyseurs MPEG-TS, en code ISO 3166-1 à deux lettres. S'il n'est pas spécifié, le jeu de caractères par défaut est déduit des variables d'environnement de locale.
-d, --demux=demux#
Utiliser le démultiplexeur donné. Valeur par défaut : 0.
-f, --frontend=frontend#
Utiliser le frontal donné. Valeur par défaut : 0.
-I, --format_entree=format
Format du fichier d'entrée. Veuillez noter que les caps sont ignorés. Il peut s'agir de :
canal - pour un fichier de canaux compatible avec dvb-apps ;

zap - pour un fichier zap compatible avec dvb-apps ;

dvbv5 (par défaut) - pour le format des applications dvbv5.

-l, --lnbf=type_LNBf
Type de LNBf à utiliser. 'help' liste ceux disponibles.
-L, --recherche=chaîne
Rechercher/chercher une chaîne dans le trafic. Utilisé uniquement en mode moniteur.
-m, --moniteur
Activer le mode moniteur. Dans ce mode, il surveillera le trafic DVB pour tous les Identifiants de Paquets (PID) reçus par l'appareil, affichant les Identifiants de Paquets (éventuellement filtrés par une chaîne), et présentant quelques statistiques de trafic : nombre de paquets par seconde, nombre de Kilo-octets par seconde et trafic total. Ces statistiques sont affichées par PID et le total par MPEG-TS.
-o, --sortie=fichier
Nom du fichier de sortie. S'il est spécifié, il exportera le contenu du MPEG-TS dans le fichier avec le premier PID vidéo et le premier PID audio (ou celui spécifié par pid_audio#). Utilisez -o - pour diriger la sortie vers stdout.
-p, --pat
Ajouter les tables PAT et PMT MPEG-TS à l'enregistrement TS (implique -r).
-P, --tous-pids
Ne filtrer aucun pid. Au lieu de cela, afficher tous les pid.
-r, --enregistrer
Configurer le /dev/dvb/adapteradaptateur#/dvr0 pour l'enregistrement MPEG-TS.
-s, --silence
Augmenter le silence (peut être utilisé plusieurs fois).
-S, --numero_sat=numero_satellite
Numéro du satellite. Utilisé uniquement sur les systèmes de diffusion satellite. S'il n'est pas spécifié, désactive le commutateur satellite DISEqC.
-t, --delai=secondes
Durée en secondes pendant laquelle l'outil restera actif pour la syntonisation et l'enregistrement. Utile si vous souhaitez enregistrer un programme dont vous connaissez la durée.
-U, --freq_bpf=fréquence
Fréquence du filtre passe-bande SCR/Unicable à utiliser, en kHz. Utilisé uniquement sur les systèmes de diffusion satellite.
-v, --verbeux
Être verbeux. Utile pour vérifier si le MPEG-TS se déroule correctement. Cette option peut être utilisée plusieurs fois pour augmenter la verbosité.
-V, --pid_video=programme_pid_video#
Programme pid vidéo à utiliser (par défaut 0)
-w, --lna=LNA
Activer, désactiver ou mettre l'alimentation LNA en mode automatique. Tous les frontaux ne le prennent pas en charge. Les valeurs valides sont :

0 - désactiver

1 - activer
-1 - automatique
-W, --attente=temps
Ajoute un temps d'attente supplémentaire pour la complétion des commandes DISEqC.
-x, --quitter
Quitter après la syntonisation.
-X, --faible_trafic
Affiche également le trafic DVB avec moins d'un paquet par seconde. Utilisé uniquement en mode moniteur.
-?, --aide
Affiche l'aide d'utilisation.
--usage
Donne un court message d'utilisation.
--version
Affiche la version du programme.

ÉTAT DE SORTIE

En cas de succès, retourne 0.

EXEMPLES

Enregistrement d'une chaîne

L'utilisation typique consiste à syntoniser une chaîne et à la mettre en mode enregistrement :

$ dvbv5-zap -c dvb_channel.conf 'musique' -r
using demux '/dev/dvb/adapter0/demux0'
reading channels from file 'dvb_channel.conf'
service has pid type 05: 204
tuning to 573000000 Hz
audio pid 104
dvb_set_pesfilter 104
Lock (0x1f) Quality= Good Signal= 100.00% C/N= -13.80dB UCB= 70 postBER= 3.14x10^-3 PER= 0
DVR interface '/dev/dvb/adapter0/dvr0' can now be opened

La chaîne peut être regardée en lisant le contenu de l'interface DVR, avec un lecteur qui reconnaît le format MPEG-TS.

Par exemple, cette chaîne audio seule peut être lue avec mplayer :

$ mplayer -cache 800 /dev/dvb/adapter0/dvr0
