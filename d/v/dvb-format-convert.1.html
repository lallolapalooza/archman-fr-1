NOM

dvb-format-convert - Outil DVBv5 pour les conversions de formats de fichiers

SYNTAXE

dvb-format-convert [OPTION]... fichier-entrée fichier-sortie

DESCRIPTION

dvb-format-convert est un outil destiné à convertir entre différents formats de fichiers. Il est conforme à la version 5 de l'API DVB, capable de représenter toutes les propriétés sur n'importe quel standard supporté par les pilotes TV numériques Linux.

Il existe actuellement 3 formats différents supportés pour l'entrée :

  • dvbv5 - le format standard de libdvbv5, capable de représenter tous les différents standards TV ;
  • channel - le format de canal hérité de dvb-apps, qui ne supporte que les standards ATSC, DVB-C, DVB-S et DVB-T, étendu pour supporter également le format s2-scan pour les fichiers DVB-S2, et pour supporter DVB-T2.
  • zap - le format hérité de dvb-apps pour le réglage, qui ne supporte que les standards ATSC, DVB-C, DVB-S et DVB-T.

Il existe un format de sortie supplémentaire :

•
vdr - le format utilisé par l'application vdr. Il supporte toutes les fonctionnalités trouvées jusqu'à la version 2.1.6 de vdr.

Malheureusement, le format zap hérité de dvb-apps n'enregistre pas le standard DVB, donc toute conversion vers et/ou depuis ce format nécessite un paramètre supplémentaire pour spécifier le système de diffusion.

OPTIONS

Les options suivantes sont valides :
-I, --input-format=format
Format du fichier d'entrée. Formats d'entrée supportés : channel, zap et dvbv5.
-O, --output-format=format
Format du fichier de sortie. Formats de sortie supportés : vdr, channel, zap et dvbv5.
-s, --delsys=system
Type de système de diffusion. Nécessaire si le format d'entrée ou de sortie est ZAP.
-?, --help
Affiche l'aide d'utilisation.
--usage
Donne un bref message d'utilisation.
-V, --version
Affiche la version du programme.

EXEMPLES

Conversion d'un fichier channel depuis le format hérité de dvb-apps

Lit un fichier au format fichier channel dvb-apps et l'écrit au format dvbv5.

$ dvb-format-convert -I channel -O dvbv5 dvbc-channel-legacy dvbc-channel
Lecture du fichier dvbc-channel-legacy
Écriture du fichier dvbc-channel

Convertir un fichier dvbv5 avec des programmes en format zap hérité de dvb-apps

Lit un fichier généré par dvbv5-scan au format dvbv5 et écrit un nouveau fichier au format zap de dvb-apps.

$ dvb-format-convert -I dvbv5 -O zap -s dvbc/annex_a dvb_channel.conf legacy.conf
Lecture du fichier dvb_channel.conf
Écriture du fichier legacy.conf
AVERTISSEMENT : PID vidéo manquant lors de l'analyse de l'entrée 6 de legacy.conf
AVERTISSEMENT : PID vidéo manquant lors de l'analyse de l'entrée 7 de legacy.conf
AVERTISSEMENT : PID vidéo manquant lors de l'analyse de l'entrée 8 de legacy.conf
AVERTISSEMENT : PID audio manquant lors de l'analyse de l'entrée 8 de legacy.conf

Veuillez noter que le format hérité de dvb-apps suppose que chaque canal aura un (et un seul) PID audio et un (et un seul) PID vidéo, tandis que le format dvbv5 supporte plusieurs PID par type de service.
