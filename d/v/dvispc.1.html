DVISPC(1) Manuel des commandes générales DVISPC(1)

NOM

dvispc - Modifier un fichier DVI pour le rendre indépendant des pages dans les specials

SYNTAXE

dvispc [-c] [-bvz] fichier_dvi_entree [fichier_dvi_sortie]

dvispc -d fichier_dvi_entree

dvispc -s [-p..] fichier_dvi_entree [fichier_texte_sortie]

dvispc -a [-ltv] [-J..] [-p..] [-r..] fichier_dvi_entree [fichier_texte_sortie]

dvispc -x[..] [-ltv] [-r..] [fichier_texte_entree] fichier_dvi_sortie

DESCRIPTION

Dvispc est un utilitaire pour modifier/éditer des fichiers DVI TeX avec les fonctionnalités suivantes:


Option de mode -c (par défaut) :
corriger un DVI d'entrée pour le rendre indépendant des pages dans les specials (par défaut)


Option de mode -d :
exécution à blanc pour vérifier si un DVI d'entrée est indépendant des pages dans les specials


Option de mode -s :
afficher tous les specials dans le DVI d'entrée


Option de mode -a :
traduire DVI en Texte (comme dv2dt dans dtl)


Option de mode -x :
traduire Texte en DVI (comme dt2dv dans dtl)

(1) La fonctionnalité *principale* de dvispc est la première, pour créer un fichier DVI indépendant des pages.

Un fichier DVI «pur» doit être effectivement indépendant des pages. Cependant, ces dernières années, des fichiers DVI avec beaucoup de \special's (couleur, annotation etc.) sont couramment utilisés, et ils ne sont pas toujours indépendants des pages. Dans un tel cas, par exemple, dviselect ou dvidvi ne parvient pas à conserver les \special's (par exemple, la couleur de page pourrait être perdue).

Le programme dvispc corrige ces fichiers DVI «dépendants» des pages pour les rendre indépendants, afin qu'ils puissent être traités en toute sécurité par dviselect ou dvidvi, puis convertis correctement dans d'autres formats tels que PostScript et PDF.

(2) Pour savoir si une telle correction est nécessaire ou non, dvispc -d suffit.

(3) Le mode -s liste tous les specials trouvés dans le DVI d'entrée tels quels, précédés d'un numéro indiquant la page où ils apparaissent. Par exemple,

[1]
{color push Black}
{color pop}
{color push rgb 1 0 0}
{color pop}
[2]
{color push Black}
{color pop}

Cette fonctionnalité est équivalente au programme dvispecials du package TeX-Guy http://www-masu.ist.osaka-u.ac.jp/%7Ekakugawa/TeX-Guy/ et dvii -s https://ctan.org/pkg/dvii.

(4) Les modes -a et -x correspondent respectivement à dv2dt et dt2dv du package dtl (= DVI Text Language). Par défaut, dvispc -a formate le texte de sortie dans son propre style, mais un format compatible DTL est disponible avec l'option -t. De plus, dvispc -x peut accepter une entrée texte compatible DTL.

SPECIALS SUPPORTÉS

Actuellement, dvispc prend en charge les éléments suivants :


specials compatibles dvips
color push, color pop, background
specials dvipdfm(x)
pdf:bcolor, pdf:ecolor, pdf:bgcolor, pdf:bann, pdf:eann
specials tpic :
pn

D'autres specials pourraient être pris en charge à l'avenir si nécessaire.

VOIR AUSSI

dviselect(1), dvidvi(1), dvips(1), dvipdfmx(1)
