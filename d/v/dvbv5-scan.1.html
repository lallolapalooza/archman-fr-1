DESCRIPTIO

N

dvbv5-scan est un outil de ligne de commande pour la recherche de fréquences des services de télévision numérique, conforme à la version 5 de l'API DVB, et rétrocompatible avec l'API DVB v3 plus

ancienne.

dvbv5-scan utilise par défaut le nouveau format de fichier de canaux/services, qu'il est capable de supporter pour tous les types de normes de télévision numérique. Il peut également supporter l'ancien format utilisé par les anciennes applications

dvb-apps.

Un canal physique unique (également appelé transpondeur) peut contenir plusieurs canaux virtuels, encapsulés via un flux de transport

MPEG.

Ces canaux virtuels sont appelés « services » dans la terminologie MPEG-TS, et peuvent contenir un ou plusieurs éléments audio, vidéo et d'autres types

d'éléments.

Le but de dvbv5-scan est de rechercher une liste de canaux physiques/transpondeurs et d'y identifier les services MPEG-TS

disponibles.

L'outil dvbv5-scan est suffisamment intelligent pour récupérer

les informations du Network Information Table (NIT) du MPE
G-TS concernant les autres canaux disponibles sur le flux.
