DVDXCHAP(1) Commandes utilisateur DVDXCHAP(1)

NOM

dvdxchap - Extraire les informations de chapitres des DVD

SYNTAXE

dvdxchap [options] SOURCE-DVD

DESCRIPTION

Ce programme extrait les informations de chapitres d'un DVD et les affiche sous une forme utilisable par ogmmerge(1).

-t, --titre num
Utiliser le titre 'num'. Le défaut est 1.
-c, --chapitre début[-fin]
N'afficher que la plage de chapitres donnée et ajuster tous les timecodes pour qu'ils commencent à 0. Le défaut est d'afficher tous les chapitres.
-v
Augmenter la verbosité
-V
Afficher les informations de version
-h
Afficher l'aide

EXEMPLES

La sortie générée par dvdxchap aura la forme

CHAPTER01=00:01:35.240
CHAPTER01NAME=Chapitre 01
CHAPTER02=00:03:40:300
CHAPTER02NAME=Chapitre 02
etc.

Vous devriez rediriger sa sortie vers un fichier, éditer les noms des chapitres et utiliser le fichier résultant comme entrée pour ogmmerge(1).
