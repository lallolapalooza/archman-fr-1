DVITODVI(1) Manuel des commandes générales DVITODVI(1)

NOM

dvitodvi - réorganiser les pages d'un fichier DVI

SYNTAXE

dvitodvi [ -q ] [ -i fichier_entree ] [ -o fichier_sortie ] [ -wlargeur ] [ -hhauteur ] spec_pages [ fichier_entree [ fichier_sortie ] ]

DESCRIPTION

Dvitodvi réorganise les pages d'un fichier DVI, créant un nouveau fichier DVI. Dvitodvi peut être utilisé pour effectuer un grand nombre de réorganisations arbitraires de documents, y compris la préparation pour l'impression 2-en-1, 4-en-1, de livrets, l'inversion, la sélection des côtés recto ou verso des documents, le redimensionnement, etc.

Les spec_pages suivent la syntaxe :

spec_pages
= [modulo:][mag@]specs
specs
= spec[+specs][,specs]
spec
= [-]numpage[(xoff,yoff)]

modulo est le nombre de pages dans chaque bloc. La valeur de modulo doit être supérieure à 0 ; la valeur par défaut est 1. Le paramètre optionnel mag ajuste le grossissement du fichier par le grossissement spécifié. Le grossissement et le modulo peuvent être spécifiés dans l'ordre inverse si désiré. Les specs sont les spécifications de pages pour les pages de chaque bloc. La valeur de numpage dans chaque spec doit être comprise entre 0 (pour la première page du bloc) et modulo-1 (pour la dernière page de chaque bloc) inclus. Les dimensions optionnelles xoff et yoff décalent la page du montant spécifié (positif). xoff et yoff sont en points PostScript, mais peuvent être suivis des unités cm ou in pour convertir en centimètres ou en pouces, ou du drapeau w ou h pour spécifier comme un multiple de la largeur ou de la hauteur. Si le signe moins optionnel est spécifié, la page est relative à la fin du document, au lieu du début.

Si les specs de page sont séparées par + les pages seront fusionnées en une seule page ; si elles sont séparées par , elles seront sur des pages séparées. S'il n'y a qu'une seule spécification de page, avec numpage zéro, le numpage peut être omis.

L'option -w donne la largeur utilisée par le spécificateur de dimension w, et l'option -h donne la hauteur utilisée par le spécificateur de dimension h. Ces dimensions sont également utilisées (après redimensionnement) pour définir le chemin de découpage pour chaque page.

Dvitodvi imprime normalement les numéros de page des pages réorganisées ; l'option -q supprime cela.

EXEMPLES

Cette section contient quelques exemples de réorganisations. Pour mettre deux pages sur une seule feuille (de papier A3 paysage), la pagespec à utiliser est :

2:0+1(21cm,0)

Pour réduire une page A3 à la taille A4, la pagespec à utiliser est :

700@(-.3in,-.3in)

Pour sélectionner toutes les pages impaires dans l'ordre inverse, utilisez :

2:-0

BOGUES

Dvitodvi n'ajuste pas certains des paramètres dans le postambule. Cela peut poser problème si ces valeurs sont utilisées pour dimensionner certaines structures dans les programmes de conversion de sortie.
