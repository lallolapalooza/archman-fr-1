NOM

dvdunauthor - Décode la structure du fichier DVD-Video

SYNTAXE

dvdunauthor [ chemin ]

DESCRIPTION

dvdunauthor décode la structure du répertoire DVD-Video spécifiée, plaçant dans le répertoire courant un fichier de contrôle XML et les fichiers MPEG-2 correspondants (avec une extension .vob) que dvdauthor peut (espérons-le) interpréter pour recréer la structure du répertoire DVD-Video.

UTILISATION

dvdunauthor chemin

AVERTISSEMENTS

Aucun.

BOGUES

Dépend de libdvdread pour décoder la structure DVD-Video et signaler toute erreur lors de cette tentative. Cependant, libdvdread peut parfois se terminer sans signaler d'erreur.
