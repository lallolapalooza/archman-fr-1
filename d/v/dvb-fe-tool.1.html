NOM

dvb-fe-tool - Outil DVBv5 pour l'inspection/modification des paramètres du frontend

SYNOPSIS

dvb-fe-tool [OPTION]...

DESCRIPTION

dvbv5-fe-tool est une ligne de commande pour les services de télévision numérique conforme à la version 5 de l'API DVB, et rétrocompatible avec l'ancienne API DVB v3.

dvb-fe-tool est un outil pour inspecter et modifier les paramètres de réglage directement au niveau du frontend de télévision numérique. S'il est appelé sans aucun paramètre, il affichera les capacités du périphérique.

OPTIONS

Les options suivantes sont valides :
-3, --dvbv3
Utiliser DVBv3 uniquement
-a, --adapter=ADAPTER
Adaptateur de télévision numérique à utiliser. Par défaut : 0.
-A, --acoustical
émet un bip si la qualité du signal est bonne. Active également le mode femon. Veuillez noter que le bip de la console doit être activé dans votre gestionnaire de fenêtres.
-d, --set-delsys=PARAMS
Définit le système de diffusion à celui spécifié dans PARAMS. Utilisez help pour afficher tous les systèmes de diffusion pris en charge.
-f, --frontend=FRONTEND
Frontend de télévision numérique à utiliser. Par défaut : 0.
-g, --get
Récupère les paramètres du frontend.
-m, --femon
Surveille l'état de verrouillage du frontend et les statistiques disponibles pour un frontend qui est déjà en cours de streaming via une autre application. Cela ouvre le frontend en mode lecture seule.
-v, --verbose
Active les messages de débogage.
-?, --help
Affiche l'aide d'utilisation.
--usage
Donne un court message d'utilisation.
-V, --version
Affiche la version du programme.

CODE DE RETOUR

En cas de succès, retourne 0.

EXEMPLES

Afficher les capacités du périphérique

C'est le comportement par défaut. Il ouvrira le frontend et affichera quelles capacités il prend en charge et quelle est la version de l'API DVB.

$ dvb-fe-tool
Device DRXK DVB-C DVB-T (/dev/dvb/adapter0/frontend0) capabilities:
     CAN_FEC_1_2
     CAN_FEC_2_3
     CAN_FEC_3_4
     CAN_FEC_5_6
     CAN_FEC_7_8
     CAN_FEC_AUTO
     CAN_GUARD_INTERVAL_AUTO
     CAN_HIERARCHY_AUTO
     CAN_INVERSION_AUTO
     CAN_MUTE_TS
     CAN_QAM_16
     CAN_QAM_32
     CAN_QAM_64
     CAN_QAM_128
     CAN_QAM_256
     CAN_RECOVER
     CAN_TRANSMISSION_MODE_AUTO
DVB API Version 5.10, Current v5 delivery system: DVBC/ANNEX_A
Supported delivery systems:
    [DVBC/ANNEX_A]
     DVBC/ANNEX_C
     DVBT

Définir le système de diffusion

Certains périphériques (comme l'exemple ci-dessus) prennent en charge plusieurs systèmes de diffusion. Les anciennes applications DVB peuvent ne pas être capables de passer d'un système de diffusion à un autre, car cette fonctionnalité n'a été ajoutée qu'à la version 5.5 de l'API DVB.

Cette fonctionnalité permet d'utiliser ces applications héritées.

$ dvb-fe-tool -d dvbc/annex_c
Changing delivery system to: DVBC/ANNEX_C

Obtenir les paramètres actuels du frontend

L'outil peut également être utilisé pour obtenir les paramètres actuels. Dans ce cas, il ouvrira le frontend en mode lecture seule, ce qui permet de l'appeler alors qu'une autre application de télévision numérique est en cours d'exécution.

$ dvb-fe-tool -g
FREQUENCY = 573000000
MODULATION = QAM/256
INVERSION = AUTO
SYMBOL_RATE = 5217000
INNER_FEC = NONE
DELIVERY_SYSTEM = DVBC/ANNEX_A

Surveiller le frontend

Le dvb-fe-tool peut également être utilisé pour surveiller les statistiques d'un frontend DVB sans toucher au périphérique, en utilisant le paramètre --femon (ou -m). L'utilisation typique est de pouvoir lire les statistiques alors qu'un autre programme ou application DVB est en cours d'utilisation.

Dans ce mode, il continuera à imprimer les statistiques du frontend chaque seconde, jusqu'à ce que le programme soit interrompu avec CTRL-C :

Par exemple, pendant que dvbv5-zap règle un canal, il produira :

$ dvb-fe-tool --femon
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.40dB UCB= 370 postBER= 28.0x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.80dB UCB= 370 postBER= 25.3x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.30dB UCB= 370 postBER= 25.7x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.30dB UCB= 370 postBER= 28.4x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.50dB UCB= 370 postBER= 26.5x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.50dB UCB= 370 postBER= 26.9x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.20dB UCB= 370 postBER= 28.6x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.70dB UCB= 370 postBER= 26.7x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.80dB UCB= 370 postBER= 23.3x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.50dB UCB= 370 postBER= 26.7x10^-6 PER= 0

Si la sortie d'erreur standard est la console, les messages seront colorés en fonction de la qualité du signal.

Les types de statistiques présentés et leurs unités dépendront de ceux pris en charge par le matériel que vous utilisez. Ils peuvent donc varier d'un matériel à l'autre.

Dans ce mode, il prend également en charge la sortie d'un signal audible si la qualité est bonne, en utilisant le paramètre '-A'.

Veuillez noter que, sur les systèmes Linux modernes, l'audio du système doit être activé dans votre gestionnaire de fenêtres et le thème audio doit être configuré pour produire un son lorsque BELL (caractère) est envoyé au terminal.

NOTE :

C/N dans les statistiques ci-dessus signifie rapport Porteuse/Bruit. C'est le rapport Signal/Bruit mesuré sur la porteuse pilote ou simplement le rapport Signal/Bruit pour les types de modulation où une seule porteuse est utilisée, comme DVB-C ou DVB-S.
