DVDSTYLER(1) Manuel des commandes générales DVDSTYLER(1)

NOM

dvdstyler - système d'authoring DVD multiplateforme pour la production de DVD vidéo

SYNOPIS

dvdstyler [options] fichiers...

DESCRIPTION

Cette page de manuel documente brièvement les commandes dvdstyler.

DVDStyler est un programme d'authoring pour produire des DVD vidéo.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous. Pour une description complète, consultez les fichiers Info.

-e, --stderr
Écrit les messages de journal dans la sortie d'erreur standard.
-h, --help
Affiche un résumé des options.
-s, --start
Démarre automatiquement la génération et la gravure.
-v, --version
Affiche la version du programme.
