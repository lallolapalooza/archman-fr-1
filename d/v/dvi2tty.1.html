DESCRIPTIO

N

dvi2tty convertit un fichier DVI TeX dans un format approprié pour les terminaux et les imprimantes ligne. Le programme est destiné à être utilisé pour la relecture préliminaire de documents composés avec TeX. Par défaut, la sortie est dirigée vers le terminal, éventuellement via un visualiseur (selon la manière dont le programme a été installé), mais elle peut être dirigée vers un fichier ou un

tube.

La sortie laisse beaucoup à désirer, mais reste utile si vous voulez éviter de vous déplacer vers l'imprimante laser (ou autre) pour chaque itération de votre document.
Puisque dvi2tty produit une sortie pour les terminaux et les imprimantes ligne, la représentation des documents est naturellement assez primitive. En principe, les changements de polices sont totalement ignorés, mais dvi2tty reconnaît quelques symboles mathématiques et spéciaux qui peuvent être affichés sur un terminal ASCII ordinaire, tels que les symboles '+' et

'-'.

Si la largeur du texte de sortie nécessite plus de colonnes que ce qui tient sur une ligne (cf. l'option -w), il est coupé en plusieurs lignes par dvi2tty, bien qu'il soit imprimé comme une seule ligne sur les périphériques de sortie TeX réguliers (par exemple, les imprimantes laser). Pour indiquer qu'une ligne coupée est en réalité une seule ligne logique, un astérisque (``*'') en dernière position signifie que la ligne logique se poursuit sur la ligne physique suivante produite par dvi2tty. Une telle ligne de continuation commence par une espace et un astérisque dans les deux premières

colonnes.

Les options peuvent être spécifiées dans la variable d'environnement DVI2TTY. Toute option de la ligne de commande, en conflit avec celle de l'environnement, remplacera celle de l'environnement

.

Options

:
-o
file
Écrire la sortie dans le fichier « file
».
-p
list
Imprimer les pages choisies par list. Les numéros font référence aux numéros de page TeX (connus sous le nom de \count0). Un exemple de format pour list est « 1,3:6,8 » pour choisir les pages 1, 3 à 6 et 8. Des nombres négatifs peuvent être utilisés exactement comme en TeX, par exemple, -1 vient avant -4 comme dans « -p-1:-4,
17 ».
-P
list
Comme -p sauf que les numéros de page font référence à l'ordre séquentiel des pages dans le fichier dvi. Les nombres négatifs n'ont pas beaucoup de sens ici.
..
-w
n
Spécifier la largeur du terminal n. Plage valide 16–132. La valeur par défaut est 80. Si votre terminal est capable d'afficher en 132 colonnes, il pourrait être judicieux d'utiliser -w132 et de basculer le terminal dans ce mode car la sortie en aura probablement meilleure
apparence.
-
v
Spécifier la hauteur des lignes. Valeur par défaut 450000. Permet d'ajuster
l'interligne.
-
q
Ne pas faire passer la sortie par un visualiseur. Cela peut être le défaut sur certains systèmes (selon les caprices de la personne qui a installé le programme)
.
-e
n
Cette option peut être utilisée pour influencer l'espacement entre les mots. Avec une valeur négative, le nombre d'espaces entre les mots diminue, avec une valeur positive, il augmente. -e-11 semble bien
fonctionner.
-
f
Faire passer la sortie par un visualiseur, $PAGER s'il est défini, ou ce que l'installateur du programme a compilé (souvent « more »). Cela peut être le défaut, mais il est toujours possible de rediriger la sortie avec « > », le visualiseur ne sera pas utilisé si la sortie ne va pas vers un
terminal.
-
F
Spécifier le programme visualiseur à utiliser. Cela remplace la variable d'environnement $PAGER et le visualiseur par
défaut.
-Fpr
og
Utiliser « prog » comme programme dans lequel faire passer la sortie. Peut être utilisé pour choisir un visualiseur alternatif (par exemple, « -Fless
»).
-
t
Les polices \tt ont été utilisées (au lieu de cm) pour produire le fichier
dvi.
-
a
Dvi2tty essaie normalement de produire les caractères accentués. Avec l'option -a, les caractères accentués sont produits sans le signe
d'accent.
-
l
Marquer les sauts de page avec la séquence de deux caractères « ^L ». Par défaut, ils sont marqués avec un caractère de saut de
page.
-
c
Ne pas essayer de traduire les caractères (comme le mode scandinave/latin1) sauf lors de l'utilisation d'une police
tt.
-
u
Option de bascule pour traiter certains caractères latin1. Utilisez ceci si vos périphériques de sortie prennent en charge les caractères latin1. Notez que cela peut interférer avec -s. Il vaut mieux ne pas utiliser -u et -s
ensemble.
-
s
Option de bascule pour traiter les caractères scandinaves spéciaux qui sur la plupart des (?) terminaux en Scandinavie sont mappés à « {|}[\] ». Notez que cela peut interférer avec -u. Il vaut mieux ne pas utiliser -u et -s
ensemble.
-
J
Détecter automatiquement le format dvi NTT JTeX, ASCII pTeX et
upTeX.
-
N
Afficher le dvi NTT
JTeX.
-
A
Afficher le dvi ASCII
pTeX.
-
U
Afficher le dvi
upTeX.
-Ee
nc
Définir l'encodage japonais de sortie. L'argument enc 'e', 's', 'j' et 'u' désigne respectivement EUC-JP, Shift_JIS, ISO-2022-JP et
UTF-8.
-bdel
im
Imprimer le nom des polices lors du passage à celle-ci (et à la fin de celle-ci). L'argument delim est utilisé pour délimiter le nom de la
police.
-
h
Afficher un
message d'aid
e et quitter
avec succès.
