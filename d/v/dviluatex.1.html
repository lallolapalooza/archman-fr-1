DESCRIPTIO

N

Exécute le programme de composition luaTeX sur NOMTEX, créant généralement NOMTEX.pdf. Les COMMANDES restantes sont traitées comme une entrée luaTeX, après la lecture de NOMTEX

.

Alternativement, si le premier argument non-option commence par une barre oblique inverse, tous les arguments non-options sont interprétés comme une ligne d'entrée

luaTeX.

Alternativement, si le premier argument non-option commence par un &, le mot suivant est considéré comme le FMT à lire, remplaçant tout le reste. Les arguments restants sont traités comme

ci-dessus.

Si aucun argument ni option n'est spécifié, une invite de saisie est

affichée.

S'il est appelé texlua, il agit comme un interpréteur Lua. S'il est appelé comme texluac, il agit comme un compilateur de code intermédiaire

Lua.

LuaTeX est né comme une version étendue de pdfTeX avec prise en charge d'Unicode et des polices OpenType, un langage de script Lua intégré, les extensions e-TeX et Omega, ainsi qu'un moteur MetaPost intégré, capable de créer des fichiers PDF ainsi que des fichiers DVI. Pour plus d'informations sur luatex, voir http://www.luatex.org ; et vous pouvez lire le manuel de LuaTeX en utilisant l'utilitaire texdoc (texdoc lua

tex).

Toute l'entrée et la sortie de texte de LuaTeX est considérée comme du texte Unicode, bien que divers filtres permettent de prendre en charge n'importe quel

encodage.

En mode DVI, LuaTeX peut être utilisé comme un remplacement complet pour le moteur

TeX.

En mode PDF, LuaTeX peut gérer nativement les formats graphiques PDF, JPG, JBIG2 et PNG. LuaTeX ne peut pas inclure de fichiers graphiques PostScript ou Encapsulated PostScript (EPS) ; convertissez-les d'abord en PDF en utilisant epstopdf (1)

.

La variante luajittex inclut le compilateur just-in-time de

Lua.

La variante luahbtex peut utiliser le moteu

r HarfBuzz pour la mise en forme des glyphe
s, au lieu du shaper intégré de LuaTeX.

OPTION

S

Lorsque l'exécutable LuaTeX démarre, il recherche l'option --lua de la ligne de commande. S'il n'y a pas d'option --lua, la ligne de commande est interprétée de manière similaire à celle de pdfTeX et Aleph traditionnels. Mais si l'option est présente, LuaTeX entrera dans un mode alternatif d'analyse de la ligne de commande par rapport aux programmes web2c standard. La présence de --lua rend la plupart des autres options peu fiables, car le fichier d'initialisation lua peut désactiver kpathsea et/ou accrocher des fonctions à divers rappels (callbacks)

.

Les deux options suivantes modifient le comportement de l'exécutable

--luaon
ly
Démarre LuaTeX comme interpréteur Lua. Dans ce mode, il définira arg[0] sur le nom du script trouvé, poussant les options précédentes dans les valeurs négatives et le reste de la ligne de commande dans les valeurs positives, exactement comme l'interpréteur Lua. LuaTeX se terminera immédiatement après l'exécution du script Lua
spécifié.

Démarre LuaTeX comme compilateur de code intermédiaire Lua. Dans ce mode, LuaTeX est exactement comme luac de la distribution Lua autonome, sauf qu'il n'a pas l'option -l, et qu'il accepte (mais ignore) l'option --luac

OPTIONS

-jobname=NAME
Use NAME for the output file name.
-output-directory=DIR
Use DIR for output files.
-interaction=MODE
Set interaction level to MODE.
-quiet, -interaction=batchmode
Turn off most warnings and diagnostics.
-nonstopmode, -interaction=nonstopmode
Stop on error.
-scrollmode, -interaction=scrollmode
Continue on error, but ask user if they want to continue.
-batchmode, -interaction=batchmode
Stop on error.
-draftmode
Use draft mode.
-true
Use true mode.
-help
Display help message and exit.
-ini
Initialize format.
-version
Print version information and exit.
-showversion
Print version information but continue processing.
-file-line-error, -file-line-error-special
Start errors messages with file and line numbers.
-no-file-line-error
Don't start error messages with file and line numbers.
-fmt=NAME
Use format file NAME.
- Ogunits=NUMBER
Set the value of Ogunits to NUMBER.
-etex
Enable E-TeX extensions.
-parse-first-line
Enable parsing of the first line.
-no-parse-first-line
Disable parsing of the first line.
-8bit
Use 8-bit file names.
-Woption
Pass option to the Web compiler.
-Loption
Pass option to the Lua interpreter.
-etex=NUMBER
Enable/disable E-TeX extensions.
-etex=0
Disable E-TeX extensions.
-etex=1
Enable E-TeX extensions.
-synctex=NUMBER
Enable/disable SyncTeX extension.
-synctex=0
Disable SyncTeX extension.
-synctex=1
Enable SyncTeX extension.
-synctex=2
Enable SyncTeX extension (write output to file).
-ctex=NUMBER
Enable/disable SyncTeX extension.
--version
Print version information and exit.
--credits
Print credits and version details.
Les options suivantes sont ignorées :
--8bit, --etex, --parse-first-line, --no-parse-first-line
Ceux-ci sont toujours activés.
--default-translate-file=TCXNAME, --translate-file=TCXNAME
Ceux-ci sont toujours désactivés.

AUTEURS

Les auteurs principaux de LuaTeX sont Taco Hoekwater, Hartmut Henkel, Hans Hagen et Luigi Scarso, avec l'aide de Martin Schröder, Karel Skoupy et Han The Thanh.

TeX a été conçu par Donald E. Knuth, qui l'a implémenté en utilisant son système Web pour les programmes Pascal. Il a été porté sous Unix à Stanford par Howard Trickey, et à Cornell par Pavel Curtis. La version maintenant offerte avec la distribution Unix TeX est celle générée par le système Web vers C (web2c), initialement écrit par Tomas Rokicki et Tim Morgan.

La page d'accueil de LuaTeX est http://luatex.org.
