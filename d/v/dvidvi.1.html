DVIDVI(L) DVIDVI(L)

NOM

dvidvi - sélectionne et/ou réorganise les pages d'un fichier TeX dvi

SYNTAXE

dvidvi [param] infile outfile

DESCRIPTION

Introduction

Le programme dvidvi convertit un fichier dvi en un autre fichier dvi, avec éventuellement certains changements.

Paramètres

-f n la page n est la première page sélectionnée
-l n la page n est la dernière page sélectionnée
-n n sélectionne au maximum n pages. Notez que n est le nombre de pages sélectionnées, indépendamment du nombre de pages réellement contenues dans une feuille -i { n1..n2 | n1 }[,...]
inclut les pages (les plages sont autorisées). Lorsque cette option est utilisée, SEULEMENT les pages spécifiées sont sélectionnées. Cependant, nous pouvons exclure de ces pages avec l'option -x -x { n1..n2 | n1 }[,...]
exclut les pages (les plages sont autorisées) -q travaille en mode silencieux, c'est-à-dire ne pas afficher à l'écran les messages sur la façon dont le travail est effectué. -r inverse l'ordre des pages.

Les numéros de page pour les options ci-dessus -f -l -i et -x peuvent être spécifiés de différentes manières.
1) Si un nombre n est donné, il est interprété comme la n-ième page depuis le début du fichier .dvi. Bien sûr, ce nombre est indépendant du numéro de page attribué par TeX. 2) Les numéros de page TeX sont ceux qui sont réellement écrits sur la page ; ces numéros de page peuvent être modifiés, par exemple, en utilisant les commandes TeX \pagenumbering, \setcounter{page}{n}, et \addtocounter{page}{n}. Un numéro de page TeX peut être spécifié en faisant précéder le numéro n du caractère @. Ainsi, si vous spécifiez -f @25 -l @30 vous sélectionnez les pages entre 25 et 30, ces nombres étant ceux attribués par TeX. 3) Cependant, plusieurs pages peuvent avoir le même numéro de page TeX dans un fichier .dvi. Par exemple, les pages introductives d'un livre sont numérotées i, ii, et ainsi de suite jusqu'à ce que le premier chapitre commence, puis les pages sont numérotées 1, 2, etc. Dans ce cas, les pages numérotées i et 1 dans le fichier .dvi ont le même numéro de page TeX. Si vous voulez sélectionner, par exemple, la deuxième occurrence de la page numérotée 1, vous pouvez spécifier un numéro de page comme (@2)1. Ainsi @1 est équivalent à (@1)1. Par exemple, si vous spécifiez -f (@2)1 -l(@2)10 vous sélectionnez les pages entre 1 et 10 du premier chapitre, pas les pages introductives entre i et x.

Il existe un autre paramètre qui indique à dvidvi comment vous souhaitez modifier la disposition et les spécifications des pages. C'est le paramètre -m.
* Le nombre précédant le deux-points est la valeur du modulo. Tout sera fait par morceaux de pages de cette taille. S'il n'y a pas de deux-points, la valeur par défaut est supposée être un. Le dernier morceau de pages est complété avec autant de pages blanches que nécessaire. * Après les deux-points se trouve une liste de numéros de page séparés par des virgules. Ces numéros de page sont par rapport au morceau de pages actuel, et doivent se trouver dans la plage zéro à la valeur du modulo moins un. Si un signe moins précède le nombre, alors la page est prise du morceau miroir ; s'il y a m morceaux, alors le morceau miroir du morceau n est le morceau numéroté m-n-1. En termes simples, c'est le morceau portant le même numéro, mais en partant de la fin. Ceci peut être utilisé pour inverser les pages. Si aucun nombre n'est donné, le numéro de page par défaut est 1. * Après chaque numéro de page se trouve une valeur de décalage optionnelle entre parenthèses, qui consiste en une paire de dimensions séparées par des virgules. Chaque dimension est un nombre décimal avec une unité de mesure optionnelle. L'unité de mesure par défaut est le pouce, ou la dernière unité de mesure utilisée. Toutes les unités sont en dimensions réelles. Les unités de mesure autorisées sont les mêmes que celles autorisées par TeX : in, mm, cm, pt, pc, dd, et cc.

EXEMPLES


-m - Inverse l'ordre des pages. Cette fois, le modulo et le numéro de page sont tous deux par défaut. -m 2:0 Sélectionne les pages première, troisième, cinquième, etc. du fichier. Imprime celle-ci après avoir imprimé la suivante, en retirant le papier du bac d'alimentation et en le réinsérant dans l'alimentation papier. -m 2:-1 Sélectionne les pages deuxième, quatrième, etc. et les écrit dans l'ordre inverse. -m 4:-1,2(4.25in,0in) -m 4:-3,0(4.25in,0in)
Utile pour imprimer un petit livret, quatre pages par feuille, recto-verso, pour l'agrafer au milieu. Imprimez la première, remettez la pile dans l'imprimante à l'envers, et imprimez la deuxième. Les spécifications `in' sont superflues. -m ,(1pt,1)
Faites peur à votre administrateur système ! En fait, les choses sont tellement floues avec cette option que vous pourriez vouloir envoyer des lettres à vos ennemis imprimées de cette façon. De *longues* lettres. -m 4:0(5.5in,4.25),3(0,4.25) -m 4:1(0in,4.25),2(5.5,4.25)
Imprime une carte de quatre pages sur une seule feuille. Imprimez la première, faites pivoter le papier de 180 degrés et alimentez-le à nouveau. (Les gens de PostScript peuvent faire des tours amusants avec PostScript, donc ce n'est pas nécessaire.)
