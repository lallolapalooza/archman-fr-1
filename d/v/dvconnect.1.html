NOM

dvconnect - recevoir ou transmettre du DV brut via le périphérique video1394

SYNTAXE

dvconnect [ options ] fichiers dv bruts ou '-- -' pour stdin/stdout

DESCRIPTION

dvconnect capture des flux DV bruts depuis ou envoie des flux DV bruts vers le périphérique video1394 de Linux IEEE 1394.

--version
affiche le numéro de version de dvconnect.
-s, --send
envoie des données au lieu de capturer.
-v, --verbose
affiche des informations d'état pendant la réception / l'envoi.
-c, --channel=nombre
canal sur lequel envoyer / recevoir (plage : 0 - 63, par défaut = 63).
-k, --kbuffers=nombre
nombre de tampons d'images kernel video1394 à utiliser. par défaut = 8.
--start-frame=compte
commence à l'image compte (par défaut 0).
-e, --end-frame=compte
finit à l'image compte (par défaut illimité).
--cip-n-ntsc=nombre
compteur de synchronisation cip n ntsc (par défaut : 2436).
--cip-d-ntsc=nombre
compteur de synchronisation cip d ntsc (par défaut : 38400).
--syt-offset=nombre
décalage syt (par défaut : 10000 plage : 10000-26000).
-b, --buffers=nombre
nombre maximum de tampons de threads d'entrée/sortie de fichiers à utiliser. par défaut = 250.
-u, --underrun-data=nom_fichier
fichier contenant l'image à envoyer en cas de sous-dépassement.
-d, --device=nom_fichier
spécifie le périphérique video1394 (par défaut /dev/video1394/0).

Options d'aide

-?, --help
affiche le message d'aide.
--usage
affiche un bref message d'utilisation.

VOIR AUSSI
