DVIBOOK(1) Manuel des commandes générales DVIBOOK(1)

NOM

dvibook - réorganise les pages d'un fichier DVI en signatures

SYNTAXE

dvibook [ -q ] [ -s<num> ] [ -r ] [ -i fichier_entree ] [ -o fichier_sortie ] [ fichier_entree [ fichier_sortie ] ]

DESCRIPTION

Dvibook réorganise les pages d'un fichier DVI produit par TeX en « signatures » pour l'impression de livres ou de livrets, créant un nouveau fichier DVI utilisable par n'importe lequel des programmes de conversion TeX.

L'option -s sélectionne la taille de la signature qui sera utilisée. La taille de la signature est le nombre de côtés qui seront pliés et reliés ensemble ; le nombre donné doit être un multiple de quatre. Par défaut, une seule signature est utilisée pour l'ensemble du fichier. Des côtés vierges supplémentaires seront ajoutés si le fichier ne contient pas un multiple de quatre pages.

Par défaut, dvibook réorganise les pages en signatures pour une reliure côté gauche ; l'option -r passe à des signatures pour une reliure côté droit. Cela peut être utile pour les documents pTeX en écriture verticale (tate-kumi).

Dvibook affiche normalement les numéros de page des pages réorganisées ; l'option -q supprime cet affichage.

AUTEUR

Angus Duggan, d'après dviselect(1), par Chris Torek, University of Maryland. Actuellement maintenu dans le cadre de TeX Live (https://tug.org/texlive).

VOIR AUSSI

dvitodvi(1), dviconcat(1), dviselect(1), latex(1), tex(1)
MC-TeX User's Guide

BOGUES

Dvibook n'ajuste pas les paramètres dans le postamble ; cependant, puisque ces valeurs sont normalement utilisées uniquement pour dimensionner certaines structures dans les programmes de conversion de sortie, et que les paramètres n'ont jamais besoin d'être ajustés à la hausse, cela ne s'est pas avéré être un problème.
