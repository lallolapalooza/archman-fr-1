NOM

dvihp - convertir un fichier TeX DVI en Hewlett-Packard PCL

SYNTAXE

dvihp [options] fichier.dvi[.dvi]

DESCRIPTION

dvihp traduit le fichier.dvi donné en Hewlett-Packard PCL en utilisant dvicopy(1) puis $DVILJ (dvilj4 par défaut).

En l'absence d'autres options, la sortie PCL est envoyée à $SPOOL (lpr par défaut).

OPTIONS

Les options sont reconnues à partir de dvips lorsque possible :

-A
imprimer les pages impaires
-B
imprimer les pages paires
-d n
définir les bits de débogage à n (voir la documentation)
-D n
définir la résolution à n
-f
exécuter en tant que filtre
-l n
ne pas imprimer les pages après n
-m
alimentation manuelle
-n n
imprimer n pages
-O a,b
définir/changer le décalage papier à a,b mm.
-o s
sortie vers s au lieu de mettre en file d'attente
-p n
ne pas imprimer les pages avant n.
-Ps
transmettre directement à lpr.
-v
fonctionnement verbeux.
-x n
définir le grossissement à n.
--help
écrire le résumé d'utilisation.

Les autres options sont transmises au programme dvilj.

BOGUES

Envoyez les rapports de bogues par e-mail à tex-k@tug.org.

VOIR AUSSI

dvicopy(1), dvilj4(1).
