NOM

dvipos - calculer les positions dans un fichier DVI

SYNTAXE

dvipos [ OPTION... ] fichier_entree[.dvi]

DESCRIPTION

dvipos analyse un fichier DVI à la recherche des spéciaux pos:. Il reconnaît actuellement pos:pxy, pos:pxywhd, pos:pxyplus, pos:begbox, pos:endbox, pos:beglines, et pos:endlines. Il génère ensuite les informations de ces spéciaux ainsi que des informations qu'un seul postprocesseur DVI peut déterminer, comme la position actuelle en x et y. La sortie ressemble à : 

\pospxywhd{texte:54}{54}{10663sp}{8535sp}{21326sp}{34081sp}{0sp}

et convient pour être inclus dans un fichier auxiliaire tex(1) ou pdftex(1), tel que document.tuo, à lire lors de la prochaine exécution du moteur de composition tex(1) ou similaire.

OPTIONS

-h, --help
afficher l'aide.
-W, --warning
afficher les avertissements.
-v, --verbose
afficher la sortie détaillée.
-d, --debug
afficher les données de débogage de dvitype(1).
-s, --smashchars
considérer la hauteur et la profondeur comme nulles.
-o, --output=FICHIER
envoyer toute la sortie vers FICHIER. Sans cette option, la sortie va vers stdout.
-b, --bbox[=FICHIER]
envoyer la boîte englobante vers FICHIER (FICHIER par défaut est fichier_entree.pos).
-f, --framed[=BASE]
demander une copie du fichier DVI, BASE.dvi, avec les boîtes englobantes encadrées (FICHIER par défaut est fichier_entree_frames.dvi). Voir l'option --framesize.
-m, --mag=INT
remplacer le grossissement de tex(1) par INT.
-w, --framesize=INT
définir la taille de la règle d'encadrement par INT (par défaut 6554 = .1pt).
-p, --pages=X:Y
définir les plages de pages de X à Y.

UTILISATION

dvipos est exécuté principalement en coulisses par texexec(1) de ConTeXt entre les exécutions de tex(1) ou pdftex(1), afin de fournir des informations et d'obtenir des informations sur les graphiques positionnels. Ces graphiques sont fournis par l'interface MetaFun de mpost(1). dvipos n'est pas utilisé (ou nécessaire) en mode de sortie PDF mais est nécessaire pour le mode de sortie DVI. pdftex(1) à partir de la version 1.40 peut produire des informations de position même en mode DVI, donc une fois que les macros ConTeXt tireront parti de cette fonctionnalité, le besoin de dvipos diminuera.

En attendant, voici une utilisation typique de dvipos : 

dvipos notes.dvi
Les informations de position générées sont collectées par texexec(1) pour être incluses dans le fichier auxiliaire notes.tuo à utiliser lors de la prochaine exécution.

EXEMPLES

Extraire les positions du fichier doc.dvi, avec sortie vers doc.loc :
dvipos -o doc.loc doc.dvi
Identique à ci-dessus, mais envoyer également les informations bbox vers doc.pos :
dvipos -b -o doc.loc doc.dvi
Au lieu de cela, envoyer les informations bbox vers /tmp/debug.pos :
dvipos -b=/tmp/debug.pos -o doc.loc doc.dvi

VOIR AUSSI

dvips(1), dvitype(1), mpost(1), pdftex(1), tex(1), texexec(1).

Pour en savoir plus sur les graphiques positionnels, consultez la documentation MetaFun sur le wiki ConTeXt ⟨URL : https://wiki.contextgarden.net/MetaFun ⟩.

BOGUES

Si vous spécifiez un fichier pour l'option -b, vous devez joindre l'option et le nom avec = plutôt qu'avec un espace (plus courant) : 

dvipos -b=/tmp/debug.pos notes.dvi

fonctionne, mais 

dvipos -b /tmp/debug.pos notes.dvi

ne fonctionne pas.
