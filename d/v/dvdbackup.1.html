dvdbackup(1) Manuel des commandes générales dvdbackup(1)

NOM

dvdbackup - Outil pour sauvegarder des DVD

SYNTAXE

dvdbackup [OPTION]...

DESCRIPTION

Cette page de manuel documente brièvement la commande dvdbackup. Cette page de manuel a été écrite pour la distribution Debian car le programme original n'a pas de page de manuel. dvdbackup est un outil pour extraire des données de DVD vidéo. Il présente les avantages d'être petit, rapide et facile à utiliser.

OPTIONS

Un résumé des options est inclus ci-dessous.

-h, --help
affiche un bref message d'utilisation
-V, --version
affiche les informations de version
-I, --info
pour obtenir des informations sur le DVD
-M, --mirror
sauvegarde le DVD entier
-F, --feature
sauvegarde le film principal du DVD
-T X, --titleset=X
sauvegarde le titleset X
-t X, --title=X
sauvegarde le titre X
-s X, --start=X
sauvegarde à partir du chapitre X
-e X, --end=X
sauvegarde jusqu'au chapitre X
-i PÉRIPHÉRIQUE, --input=PÉRIPHÉRIQUE
où PÉRIPHÉRIQUE est votre appareil DVD. Ce commutateur ne doit être utilisé que si le nœud de votre périphérique DVD n'est pas /dev/dvd
-o RÉPERTOIRE, --output=RÉPERTOIRE
où RÉPERTOIRE est votre cible de sauvegarde. Si non spécifié, le répertoire de travail actuel sera utilisé.
-v, --verbose
affiche plus d'informations sur la progression
-n NOM, --name=NOM
(optionnel) définit le titre - utile si la détection automatique échoue
-a 0, --aspect=0
pour obtenir un rapport d'aspect 4:3 au lieu de 16:9 si les deux sont présents
-r {a,b,m}, --error={a,b,m}
sélectionne la gestion des erreurs de lecture : a=abandon, b=sauter bloc, m=sauter plusieurs blocs (par défaut)
-p, --progress
affiche les informations de progression lors de la copie des VOB

Notes sur les options

-a est une option pour le commutateur -F et n'a aucun effet sur les autres options.
-s et -e devraient de préférence être utilisés avec -t.

Informations générales sur la sauvegarde

Si votre répertoire de sauvegarde est /mon/dvd/backup/dir/ spécifié avec le flag -o, alors dvdbackup créera une structure DVD-Video sous /mon/dvd/backup/dir/NOM_DU_TITRE/VIDEO_TS. Si le flag -o est omis, le répertoire courant est utilisé.

Comme le titre est "unique" vous pouvez utiliser le même répertoire pour toutes vos sauvegardes de DVD. S'il arrive qu'il ait un titre générique, dvdbackup se terminera avec une valeur de retour de 2, et vous devrez spécifier un nom de titre avec le commutateur -n.

dvdbackup imitera toujours la structure DVD-Video originale. Par conséquent, si vous utilisez par exemple le commutateur -M (mirror), vous obtiendrez un duplicata exact de l'original. Cela signifie que chaque fichier aura la même taille que le fichier original. Il en va de même pour les commutateurs -F et -T.

Cependant, le commutateur -t et (-t -s/-e) est un peu différent. Les secteurs de titre seront écrits dans le fichier original mais pas au même offset que l'original, car il peut y avoir des blancs dans la structure des cellules que nous ne remplissons pas.

EXEMPLES

dvdbackup -I
recueille des informations sur le DVD. /dev/dvd est le périphérique par défaut essayé - vous devez utiliser -i si le nom de votre périphérique est différent.
dvdbackup -M
sauvegarde le DVD entier. Cette action crée une structure DVD-Video valide qui peut être gravée sur un DVD-/+R(W) à l'aide de genisoimage.
dvdbackup -F
sauvegarde le film principal du DVD. Cette action crée une structure DVD-Video du titleset du film principal. Notez que cela ne produira pas une image immédiatement regardable - vous aurez besoin d'un autre programme comme dvdauthor pour aider à construire les fichiers IFO.

dvdbackup choisit par défaut la version 16:9 du film principal si une version 4:3 est également présente sur le DVD. Pour obtenir la version 4:3, utilisez -a 0.

dvdbackup fait de son mieux pour deviner quel est le film principal du DVD - en cas d'échec, veuillez envoyer un rapport de bug.

dvdbackup -T 2
sauvegarde le titleset 2, c'est-à-dire tous les fichiers VTS_02_X.XXX. Cette action crée une structure DVD-Video du titleset spécifié. Notez que cela ne produira pas une image immédiatement regardable - vous aurez besoin d'un autre programme comme dvdauthor pour aider à construire les fichiers IFO.
dvdbackup -t 1
sauvegarde le titre 1. Cette action sauvegarde toutes les cellules qui forment le titre spécifié. Notez qu'il peut y avoir des blancs de secteur entre une cellule et une autre. dvdbackup sauvegardera tous les secteurs appartenant au titre, mais sautera les secteurs qui ne font pas partie du titre.
dvdbackup -t 1 -s 20 -e 25
Cette action sauvegardera les chapitres 20 à 25 du titre 1. Comme pour la sauvegarde d'un titre, il peut y avoir des blancs de secteur entre un chapitre (cellule) et un autre. dvdbackup sauvegardera tous les secteurs appartenant au titre 1, chapitres 20 à 25, mais sautera les secteurs qui ne font pas partie du titre 1, chapitres 20 à 25.

Pour sauvegarder un seul chapitre, par exemple le chapitre 20, faites -s 20 -e 20.
Pour sauvegarder du chapitre 20 à la fin, utilisez uniquement -s 20.
Pour sauvegarder jusqu'au chapitre 20 depuis le premier chapitre, utilisez uniquement -e 20.

Vous pouvez omettre le commutateur -t et laisser le programme deviner le titre, bien que cela ne soit pas recommandé.

Si vous spécifiez un chapitre supérieur au dernier chapitre du titre, dvdbackup tronquera au chapitre le plus élevé du titre.

STATUT DE SORTIE

0
en cas de succès
1
en cas d'erreur d'utilisation
2
en cas d'erreur de nom de titre
-1
en cas d'échec

NOM

dvdbackup - Sauvegarde des DVD

SYNOPIS

dvdbackup [-M] [-i appareil] [-o répertoire] [-p] [-f fichier] [-n nom] [-a] [-c chaîne] [-l niveau] [-d] [-h]

DESCRIPTION

dvdbackup est un programme destiné à copier des DVD vers un fichier image. Il est conçu pour être simple et facile à utiliser. Le programme lit un DVD depuis un appareil et crée une copie brute ou un fichier image de celui-ci.

OPTIONS

-M
Force la copie de l'intégralité du DVD, même si le dernier bloc est corrompu.
-i appareil
Spécifie le périphérique d'entrée DVD. Par défaut, il s'agit de /dev/sr0.
-o répertoire
Spécifie le répertoire de sortie où le fichier image sera créé. Par défaut, il s'agit du répertoire courant.
-p
Crée un fichier de sauvegarde au format .iso. Si cette option n'est pas utilisée, le fichier sera au format .img.
-f fichier
Spécifie le nom du fichier de sortie. Si cette option n'est pas utilisée, un nom sera généré automatiquement basé sur le titre du DVD et la date.
-n nom
Utilise nom comme nom de répertoire pour le fichier de sauvegarde. Ceci est utile si vous voulez organiser vos sauvegardes par titre.
-a
Sauvegarde toutes les pistes du DVD. Par défaut, seules les pistes vidéo sont sauvegardées.
-c chaîne
Utilise chaîne comme étiquette pour le volume.
-l niveau
Définit le niveau de journalisation. Les niveaux valides sont 0 (aucun) à 4 (détaillé). Par défaut, le niveau est 2.
-d
Active le mode de débogage.
-h
Affiche l'aide et quitte.

Notes sur les options

  • Si vous utilisez l'option -f, le nom du fichier de sortie est directement spécifié. Sinon, un nom est généré.
  • L'option -n peut être utilisée en conjonction avec -f pour créer un sous-répertoire nommé nom dans le répertoire de sortie spécifié par -o, et y placer le fichier de sauvegarde.

Informations générales sur la sauvegarde

dvdbackup crée une copie image du DVD. Cette image peut ensuite être utilisée pour graver un autre DVD ou montée comme un périphérique virtuel. Le programme prend en charge la copie de DVD avec protection CSS, mais nécessite une clé CSS valide. L'extraction de clés CSS peut être illégale dans certaines juridictions.

EXEMPLES

Pour sauvegarder le DVD dans le lecteur /dev/sr0 dans le répertoire courant, en créant un fichier .iso nommé mon_film.iso :
dvdbackup -p -f mon_film.iso

Pour sauvegarder toutes les pistes du DVD dans /dev/sr1 dans le répertoire /mnt/backups, en utilisant un nom de fichier généré automatiquement et en créant un sous-répertoire nommé TITRE_DVD :
dvdbackup -i /dev/sr1 -o /mnt/backups -n TITRE_DVD -a

STATUT DE SORTIE

0 : Succès
1 : Erreur générale
2 : Erreur de syntaxe de la ligne de commande
3 : Erreur lors de la lecture du DVD
4 : Erreur lors de l'écriture du fichier
