DVITOMP(1) Manuel des commandes générales DVITOMP(1)

NOM

dvitomp - convertir un fichier DVI TeX en un fichier MetaPost MPXFILE

SYNTAXE

dvitomp [OPTIONS] fichier.dvi [fichier.mpx]

mpost --dvitomp fichier.dvi [fichier.mpx]

DESCRIPTION

dvitomp traduit le fichier fichier.dvi donné en un fichier MetaPost MPXFILE. Le fichier fichier.mpx par défaut est le nom de base de fichier.dvi prolongé par .mpx.

OPTIONS

-help
affiche le résumé de l'utilisation et quitte.
-version
affiche les informations sur la version et quitte.

BOGUES

Envoyez les rapports de bugs par courriel à metapost@tug.org.
