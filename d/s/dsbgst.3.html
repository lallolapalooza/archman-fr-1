sous-routine dsbgst (character vect, character uplo, integer n, integer ka, integer kb, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldbb, * ) bb, integer ldbb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( * ) work, integer info)

DSBGST

But:

!>
!> DSBGST réduit un problème aux valeurs propres généralisé symétrique-défini
!> réel à bande A*x = lambda*B*x à la forme standard C*y = lambda*y,
!> de sorte que C ait la même largeur de bande que A.
!>
!> B doit avoir été préalablement factorisé comme S**T*S par DPBSTF, en utilisant une
!> factorisation de Cholesky divisée. A est écrasé par C = X**T*A*X, où
!> X = S**(-1)*Q et Q est une matrice orthogonale choisie pour préserver la
!> largeur de bande de A.
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          = 'N':  ne pas former la matrice de transformation X ;
!>          = 'V':  former X.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  le triangle supérieur de A est stocké ;
!>          = 'L':  le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!>

KA

!>          KA est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KA >= 0.
!>

KB

!>          KB est INTEGER
!>          Le nombre de super-diagonales de la matrice B si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KA >= KB >= 0.
!>

AB

!>          AB est un tableau DOUBLE PRECISION, dimension (LDAB,N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice bande symétrique
!>          A, stocké dans les KA+1 premières lignes du tableau. La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) pour max(1,j-ka)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+ka).
!>
!>          À la sortie, la matrice transformée X**T*A*X, stockée dans le même
!>          format que A.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KA+1.
!>

BB

!>          BB est un tableau DOUBLE PRECISION, dimension (LDBB,N)
!>          Le facteur bande S de la factorisation de Cholesky divisée de
!>          B, tel que retourné par DPBSTF, stocké dans les KB+1 premières lignes de
!>          ce tableau.
!>

LDBB

!>          LDBB est INTEGER
!>          La dimension principale du tableau BB.  LDBB >= KB+1.
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (LDX,N)
!>          Si VECT = 'V', la matrice X de taille n par n.
!>          Si VECT = 'N', le tableau X n'est pas référencé.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.
!>          LDX >= max(1,N) si VECT = 'V' ; LDX >= 1 sinon.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>
