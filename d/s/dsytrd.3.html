Documentation de la fonction/sous-programme

sous-routine dsytrd (caractère uplo, entier n, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( * ) d, double précision, dimension( * ) e, double précision, dimension( * ) tau, double précision, dimension( * ) work, entier lwork, entier info)

DSYTRD

But :

!>
!> DSYTRD réduit une matrice symétrique réelle A à une forme tridiagonale symétrique
!> T par une transformation de similarité orthogonale :
!> Q**T * A * Q = T.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>          En entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          triangulaire supérieure N-par-N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          triangulaire inférieure N-par-N de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>          En sortie, si UPLO = 'U', la diagonale et la première superdiagonale
!>          de A sont écrasées par les éléments correspondants de la
!>          matrice tridiagonale T, et les éléments au-dessus de la première
!>          superdiagonale, avec le tableau TAU, représentent la matrice
!>          orthogonale Q comme un produit de réflecteurs élémentaires ; si UPLO
!>          = 'L', la diagonale et la première sous-diagonale de A sont écrasées
!>          par les éléments correspondants de la matrice tridiagonale
!>          T, et les éléments en dessous de la première sous-diagonale, avec
!>          le tableau TAU, représentent la matrice orthogonale Q comme un produit
!>          de réflecteurs élémentaires. Voir Détails supplémentaires.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

D

!>          D est un tableau DOUBLE PRECISION, de dimension (N)
!>          Les éléments diagonaux de la matrice tridiagonale T :
!>          D(i) = A(i,i).
!>

E

!>          E est un tableau DOUBLE PRECISION, de dimension (N-1)
!>          Les éléments hors diagonale de la matrice tridiagonale T :
!>          E(i) = A(i,i+1) si UPLO = 'U', E(i) = A(i+1,i) si UPLO = 'L'.
!>

TAU

!>          TAU est un tableau DOUBLE PRECISION, de dimension (N-1)
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.  LWORK >= 1.
!>          Pour une performance optimale LWORK >= N*NB, où NB est la
!>          taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  Si UPLO = 'U', la matrice Q est représentée comme un produit de réflecteurs
!>  élémentaires
!>
!>     Q = H(n-1) . . . H(2) H(1).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**T
!>
!>  où tau est un scalaire réel, et v est un vecteur réel avec
!>  v(i+1:n) = 0 et v(i) = 1 ; v(1:i-1) est stocké en sortie dans
!>  A(1:i-1,i+1), et tau dans TAU(i).
!>
!>  Si UPLO = 'L', la matrice Q est représentée comme un produit de réflecteurs
!>  élémentaires
!>
!>     Q = H(1) H(2) . . . H(n-1).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**T
!>
!>  où tau est un scalaire réel, et v est un vecteur réel avec
!>  v(1:i) = 0 et v(i+1) = 1 ; v(i+2:n) est stocké en sortie dans A(i+2:n,i),
!>  et tau dans TAU(i).
!>
!>  Le contenu de A en sortie est illustré par les exemples suivants
!>  avec n = 5 :
!>
!>  si UPLO = 'U' :                       si UPLO = 'L' :
!>
!>    (  d   e   v2  v3  v4 )              (  d                  )
!>    (      d   e   v3  v4 )              (  e   d              )
!>    (          d   e   v4 )              (  v1  e   d          )
!>    (              d   e  )              (  v1  v2  e   d      )
!>    (                  d  )              (  v1  v2  v3  e   d  )
!>
!>  où d et e désignent les éléments diagonaux et hors diagonale de T, et vi
!>  désigne un élément du vecteur définissant H(i).
!>
