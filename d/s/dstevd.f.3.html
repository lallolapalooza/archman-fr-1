sous-routine dstevd (jobz, n, d, e, z, ldz, work, lwork, iwork, liwork, info)
DSTEVD calcule les valeurs propres et, éventuellement, les vecteurs propres gauche et/ou droite pour d'autres matrices

Documentation de la fonction/sous-routine

sous-routine dstevd (caractère jobz, entier n, double précision, dimension( * ) d, double précision, dimension( * ) e, double précision, dimension( ldz, * ) z, entier ldz, double précision, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier liwork, entier info)

DSTEVD calcule les valeurs propres et, éventuellement, les vecteurs propres gauche et/ou droite pour d'autres matrices

Objectif :

!>
!> DSTEVD calcule toutes les valeurs propres et, éventuellement, les vecteurs propres d'une
!> matrice tridiagonale symétrique réelle. Si des vecteurs propres sont désirés,
!> elle utilise un algorithme de "diviser pour régner".
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice.  N >= 0.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          En entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A.
!>          En sortie, si INFO = 0, les valeurs propres par ordre croissant.
!>

E

!>          E est un tableau de DOUBLE PRÉCISION, dimension (N-1)
!>          En entrée, les (n-1) éléments sous-diagonaux de la matrice
!>          tridiagonale A, stockés dans les éléments 1 à N-1 de E.
!>          En sortie, le contenu de E est détruit.
!>

Z

!>          Z est un tableau de DOUBLE PRÉCISION, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient les vecteurs propres
!>          orthonormés de la matrice A, avec la i-ème colonne de Z
!>          contenant le vecteur propre associé à D(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION,
!>                                         dimension (LWORK)
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          Si JOBZ  = 'N' ou N <= 1, LWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 1, LWORK doit être au moins
!>                         ( 1 + 4*N + N**2 ).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK et IWORK,
!>          retourne ces valeurs comme premières entrées des tableaux WORK
!>          et IWORK, et aucun message d'erreur lié à LWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, dimension (MAX(1,LIWORK))
!>          En sortie, si INFO = 0, IWORK(1) retourne le LIWORK optimal.
!>

LIWORK

!>          LIWORK est un ENTIER
!>          La dimension du tableau IWORK.
!>          Si JOBZ  = 'N' ou N <= 1, LIWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK doit être au moins 3+5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK et
!>          IWORK, retourne ces valeurs comme premières entrées des tableaux
!>          WORK et IWORK, et aucun message d'erreur lié à LWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  Exécution réussie
!>          < 0:  Si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  Si INFO = i, l'algorithme n'a pas convergé ; i
!>                éléments hors diagonale de E n'ont pas convergé vers zéro.
!>
