DSNIFF(8) Manuel de l'administrateur système DSNIFF(8)

NOM

dsniff - renifleur de mots de passe

SYNTAXE

dsniff [-c] [-d] [-m] [-n] [-i interface | -p fichier_pcap] [-s taille_capture] [-f services] [-t declencheur[,...]]] [-r|-w fichier_sauvegarde] [expression]

DESCRIPTION


dsniff est un renifleur de mots de passe qui gère les protocoles FTP, Telnet, SMTP, HTTP, POP, poppass, NNTP, IMAP, SNMP, LDAP, Rlogin, RIP, OSPF, PPTP MS-CHAP, NFS, VRRP, YP/NIS, SOCKS, X11, CVS, IRC, AIM, ICQ, Napster, PostgreSQL, Meeting Maker, Citrix ICA, Symantec pcAnywhere, NAI Sniffer, Microsoft SMB, Oracle SQL*Net, Sybase et Microsoft SQL.

dsniff détecte et analyse automatiquement de manière minimale chaque protocole d'application, ne sauvegardant que les éléments intéressants, et utilise Berkeley DB comme format de fichier de sortie, n'enregistrant que les tentatives d'authentification uniques. Le réassemblage complet TCP/IP est fourni par libnids(3).

J'ai écrit dsniff avec des intentions honnêtes - pour auditer mon propre réseau, et pour démontrer l'insécurité des protocoles réseau en clair. S'il vous plaît, n'abusez pas de ce logiciel.

OPTIONS

-c
Effectuer un réassemblage de flux TCP en duplex partiel, pour gérer le trafic acheminé de manière asymétrique (comme lors de l'utilisation d'arpspoof(8) pour intercepter le trafic client destiné à la passerelle locale).
-d
Activer le mode de débogage.
-m
Activer la détection automatique de protocole.
-n
Ne pas résoudre les adresses IP en noms d'hôtes.
-i interface
Spécifier l'interface sur laquelle écouter.
-p fichier_pcap
Plutôt que de traiter le contenu des paquets observés sur le réseau, traiter le fichier de capture PCAP donné.
-s taille_capture
Analyser au maximum les taille_capture premiers octets de chaque connexion TCP, plutôt que la valeur par défaut de 1024.
-f services
Charger les déclencheurs à partir d'un fichier services.
-t declencheur[,...]
Charger les déclencheurs à partir d'une liste séparée par des virgules, spécifiée comme port/proto=service (par exemple, 80/tcp=http).
-r fichier_sauvegarde
Lire les sessions reniflées à partir d'un fichier_sauvegarde créé avec l'option -w.
-w fichier
Écrire les sessions reniflées dans fichier_sauvegarde plutôt que de les analyser et de les afficher.
expression
Spécifier une expression de filtrage tcpdump(8) pour sélectionner le trafic à renifler.

Lors de la réception d'un signal de suspension, dsniff enregistrera sa table de déclencheurs actuelle dans dsniff.services.

FICHIERS

/usr/share/dsniff/dsniff.services
Table de déclencheurs par défaut
/usr/share/dsniff/dsniff.magic
Magie des protocoles réseau

VOIR AUSSI

arpspoof(8), libnids(3), services(5), magic(5)

AUTEUR

BOGUES

La fonction de détection automatique de protocole de dsniff est basée sur la commande classique file(1) d'Ian Darwin, et partage ses limitations et bogues historiques.
