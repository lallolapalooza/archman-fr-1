dssi_osc_send(1) Manuel des commandes générales dssi_osc_send(1)

NOM

dssi_osc_send - envoyer des messages OSC aux applications DSSI.

SYNTAXE

dssi_osc_send <option> <URL OSC> <valeurs>

DESCRIPTION

dssi_osc_send envoie des méthodes OSC DSSI aux applications DSSI. dssi_osc_send est généralement utilisé pour contrôler les hôtes DSSI (éventuellement pour un fonctionnement scripté), ou pour tester les interfaces utilisateur DSSI.

OPTIONS

-c
Envoyer un message `control'. Nécessite deux valeurs dans la section <valeurs> : port de contrôle et valeur. Par exemple, pour définir le port de contrôle 1 à 0.1 :
dssi_osc_send -c <URL OSC> 1 0.1
-p
Envoyer un message `program'. Nécessite deux valeurs dans la section <valeurs> : banque et numéro de programme. Par exemple, pour sélectionner la banque 0, programme numéro 7 :
dssi_osc_send -p <URL OSC> 0 7
-m
Envoyer un message `midi'. Nécessite quatre nombres dans la section <valeurs>. Par exemple, pour envoyer un "note on", do central, vélocité 64 :
dssi_osc_send -m <URL OSC> 0 144 60 64
-C
Envoyer un message `configure'. Les <valeurs> sont la paire clé et valeur. Par exemple, pour envoyer la clé `load' et la valeur `/tmp/patches.pat' :
dssi_osc_send -C <URL OSC> load /tmp/patches.pat
-s
Envoyer un message `show'.
dssi_osc_send -s <URL OSC>
-h
Envoyer un message `hide'.
dssi_osc_send -h <URL OSC>
-q
Envoyer un message `quit'.
dssi_osc_send -q <URL OSC>
-e
Envoyer un message `exiting'.
dssi_osc_send -e <URL OSC>
<URL OSC>
L'URL à laquelle se connecter. Par exemple :
osc.udp://localhost:19383/dssi/test.1
osc.udp://my.host.org:10886/dssi/xsynth-dssi/Xsynth/chan00

VOIR AUSSI

dssi_osc_update(1).
