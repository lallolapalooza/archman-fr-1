sous-programme dstt22 (integer n, integer m, integer kband, double precision, dimension( * ) ad, double precision, dimension( * ) ae, double precision, dimension( * ) sd, double precision, dimension( * ) se, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldwork, * ) work, integer ldwork, double precision, dimension( 2 ) result)

DSTT22

But:

!>
!> DSTT22  vérifie un ensemble de M valeurs propres et vecteurs propres,
!>
!>     A U = U S
!>
!> où A est une matrice symétrique tridiagonale, les colonnes de U sont orthogonales,
!> et S est diagonale (si KBAND=0) ou symétrique tridiagonale (si KBAND=1).
!> Deux tests sont effectués :
!>
!>    RESULT(1) = | U' A U - S | / ( |A| m ulp )
!>
!>    RESULT(2) = | I - U'U | / ( m ulp )
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          La taille de la matrice. Si elle est nulle, DSTT22 ne fait rien.
!>          Doit être au moins zéro.
!>

M

!>          M est un entier (INTEGER)
!>          Le nombre de paires propres à vérifier. Si elle est nulle, DSTT22 ne fait rien.
!>          Doit être au moins zéro.
!>

KBAND

!>          KBAND est un entier (INTEGER)
!>          La largeur de bande de la matrice S. Elle ne peut être que zéro ou un.
!>          Si zéro, alors S est diagonale, et SE n'est pas référencé. Si
!>          un, alors S est symétrique tridiagonale.
!>

AD

!>          AD est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>          La diagonale de la matrice A originale (non factorisée). A est
!>          supposée être symétrique tridiagonale.
!>

AE

!>          AE est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>          La partie sous-diagonale de la matrice A originale (non factorisée). A est
!>          supposée être symétrique tridiagonale. AE(1) est ignoré,
!>          AE(2) est l'élément (1,2) et (2,1), etc.
!>

SD

!>          SD est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>          La diagonale de la matrice S (symétrique tri-) diagonale.
!>

SE

!>          SE est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>          La partie sous-diagonale de la matrice S (symétrique tri-) diagonale.
!>          Non référencé si KBSND=0. Si KBAND=1, alors AE(1) est
!>          ignoré, SE(2) est l'élément (1,2) et (2,1), etc.
!>

U

!>          U est un tableau de double précision (DOUBLE PRECISION), dimension (LDU, N)
!>          La matrice orthogonale dans la décomposition.
!>

LDU

!>          LDU est un entier (INTEGER)
!>          La dimension principale de U. LDU doit être au moins N.
!>

WORK

!>          WORK est un tableau de double précision (DOUBLE PRECISION), dimension (LDWORK, M+1)
!>

LDWORK

!>          LDWORK est un entier (INTEGER)
!>          La dimension principale de WORK. LDWORK doit être au moins
!>          max(1,M).
!>

RESULT

!>          RESULT est un tableau de double précision (DOUBLE PRECISION), dimension (2)
!>          Les valeurs calculées par les deux tests décrits ci-dessus. Les
!>          valeurs sont actuellement limitées à 1/ulp, pour éviter le débordement.
!>
