DSYEQUB

But:

!>
!> DSYEQUB calcule les mises à l'échelle des lignes et des colonnes destinées à
!> équilibrer une matrice symétrique A (par rapport à la norme euclidienne) et
!> à réduire son nombre de conditionnement. Les facteurs d'échelle S sont calculés
!> par l'algorithme BIN (voir les références) de sorte que la matrice mise à l'échelle
!> B avec les éléments B(i,j) = S(i)*A(i,j)*S(j) ait un nombre de
!> conditionnement dans un facteur N du plus petit nombre de conditionnement possible
!> sur toutes les mises à l'échelle diagonales possibles.
!>

Paramètres

UPLO 
!>          UPLO est CARACTÈRE*1
!>          = 'U': le triangle supérieur de A est stocké ;
!>          = 'L': le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRÉCISION, dimension (LDA,N)
!>          La matrice symétrique N par N dont les facteurs d'échelle doivent être
!>          calculés.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

S

!>          S est un tableau DOUBLE PRÉCISION, dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est DOUBLE PRÉCISION
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et que AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle avec S.
!>

AMAX

!>          AMAX est DOUBLE PRÉCISION
!>          La plus grande valeur absolue d'un élément de matrice. Si AMAX est
!>          très proche du débordement ou très proche de la sous-débordement,
!>          la matrice doit être mise à l'échelle.
!>

WORK

!>          WORK est un tableau DOUBLE PRÉCISION, dimension (2*N)
!>

INFO

!>          INFO est ENTIER
!>          = 0: succès de l'exécution
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0: si INFO = i, le i-ème élément diagonal est non positif.
!>
