DSA_generate_parameters(3ssl)

Paquet: openssl

Licences: Apache-2.0

DSA_GENERATE_PARAMETERS(3ssl) OpenSSL DSA_GENERATE_PARAMETERS(3ssl)

NOM

DSA_generate_parameters_ex, DSA_generate_parameters - générer des paramètres DSA

SYNTAXE

#include <openssl/dsa.h>

Les fonctions suivantes sont obsolètes depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

int DSA_generate_parameters_ex(DSA *dsa, int bits,
                               const unsigned char *seed, int seed_len,
                               int *counter_ret, unsigned long *h_ret,
                               BN_GENCB *cb);

Les fonctions suivantes sont obsolètes depuis OpenSSL 0.9.8 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

DSA *DSA_generate_parameters(int bits, unsigned char *seed, int seed_len,
                             int *counter_ret, unsigned long *h_ret,
                             void (*callback)(int, int, void *), void *cb_arg);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont obsolètes. Les applications doivent utiliser à la place EVP_PKEY_paramgen_init(3) et EVP_PKEY_keygen(3) comme décrit dans EVP_PKEY-DSA(7).

DSA_generate_parameters_ex() génère les nombres premiers p et q ainsi qu'un générateur g à utiliser dans DSA et stocke le résultat dans dsa.

bits est la longueur du nombre premier p à générer. Pour les longueurs inférieures à 2048 bits, la longueur de q est de 160 bits ; pour les longueurs égales ou supérieures à 2048 bits, la longueur de q est définie à 256 bits.

Si seed est NULL, les nombres premiers seront générés aléatoirement. Si seed_len est inférieur à la longueur de q, une erreur est retournée.

DSA_generate_parameters_ex() place le nombre d'itérations dans *counter_ret et un compteur utilisé pour trouver un générateur dans *h_ret, à moins que ceux-ci ne soient NULL.

Une fonction de rappel peut être utilisée pour fournir des informations sur la progression de la génération de clé. Si cb n'est pas NULL, elle sera appelée comme indiqué ci-dessous. Pour des informations sur la structure BN_GENCB et la fonction BN_GENCB_call discutées ci-dessous, reportez-vous à BN_generate_prime(3).

DSA_generate_parameters() est similaire à DSA_generate_parameters_ex() mais attend une fonction de rappel à l'ancienne ; voir BN_generate_prime(3) pour des informations sur la fonction de rappel à l'ancienne.

  • Lorsqu'un candidat pour q est généré, BN_GENCB_call(cb, 0, m++) est appelé (m est 0 pour le premier candidat).
  • Lorsqu'un candidat pour q a passé un test par division par essais, BN_GENCB_call(cb, 1, -1) est appelé. Pendant qu'un candidat pour q est testé par des tests de primalité de Miller-Rabin, BN_GENCB_call(cb, 1, i) est appelé dans la boucle externe (une fois pour chaque témoin qui confirme que le candidat peut être premier) ; i est le compteur de boucle (commençant à 0).
  • Lorsqu'un nombre premier q a été trouvé, BN_GENCB_call(cb, 2, 0) et BN_GENCB_call(cb, 3, 0) sont appelés.
  • Avant qu'un candidat pour p (autre que le premier) ne soit généré et testé, BN_GENCB_call(cb, 0, counter) est appelé.
  • Lorsqu'un candidat pour p a passé le test par division par essais, BN_GENCB_call(cb, 1, -1) est appelé. Pendant qu'il est testé par le test de primalité de Miller-Rabin, BN_GENCB_call(cb, 1, i) est appelé dans la boucle externe (une fois pour chaque témoin qui confirme que le candidat peut être premier). i est le compteur de boucle (commençant à 0).
  • Lorsqu'un p a été trouvé, BN_GENCB_call(cb, 2, 1) est appelé.
  • Lorsqu'un générateur a été trouvé, BN_GENCB_call(cb, 3, 1) est appelé.

VALEURS DE RETOUR

DSA_generate_parameters_ex() retourne 1 en cas de succès, ou 0 sinon. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

DSA_generate_parameters() retourne un pointeur vers la structure DSA ou NULL si la génération des paramètres échoue.

BOGUES

Les longueurs de seed supérieures à 20 ne sont pas prises en charge.

VOIR AUSSI

DSA_new(3), ERR_get_error(3), RAND_bytes(3), DSA_free(3), BN_generate_prime(3)

HISTORIQUE

DSA_generate_parameters_ex() a été dépréciée dans OpenSSL 3.0.

DSA_generate_parameters() a été dépréciée dans OpenSSL 0.9.8 ; utilisez DSA_generate_parameters_ex() à la place.
