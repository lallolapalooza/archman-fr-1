dsp56k(4) Manuel des pilotes de périphériques dsp56k(4)

NOM

dsp56k - interface pour DSP56001

SYNTAXE

#include <asm/dsp56k.h>
ssize_t read(int fd, void *data, size_t length);
ssize_t write(int fd, void *data, size_t length);
int ioctl(int fd, DSP56K_UPLOAD, struct dsp56k_upload *program);
int ioctl(int fd, DSP56K_SET_TX_WSIZE, int wsize);
int ioctl(int fd, DSP56K_SET_RX_WSIZE, int wsize);
int ioctl(int fd, DSP56K_HOST_FLAGS, struct dsp56k_host_flags *flags);
int ioctl(int fd, DSP56K_HOST_CMD, int cmd);

CONFIGURATION

Le périphérique dsp56k est un périphérique caractère avec le numéro majeur 55 et le numéro mineur 0.

DESCRIPTION

Le Motorola DSP56001 est un processeur de signal numérique programmable de 24 bits que l'on trouve dans les ordinateurs compatibles Atari Falcon030. Le fichier spécial dsp56k est utilisé pour contrôler le DSP56001, et pour envoyer et recevoir des données en utilisant le port hôte bidirectionnel avec handshake.

Pour envoyer un flux de données au processeur de signal, utilisez write(2) sur le périphérique, et read(2) pour recevoir les données traitées. Les données peuvent être envoyées ou reçues par quantités de 8, 16, 24 ou 32 bits du côté hôte, mais seront toujours vues comme des quantités de 24 bits dans le DSP56001.

Les appels ioctl(2) suivants sont utilisés pour contrôler le périphérique dsp56k :

DSP56K_UPLOAD
réinitialise le DSP56001 et télécharge un programme. Le troisième argument ioctl(2) doit être un pointeur vers une structure struct dsp56k_upload dont les membres .bin pointe vers un programme binaire DSP56001, et .len est défini à la longueur du programme, comptée en mots de 24 bits.
DSP56K_SET_TX_WSIZE
définit la taille des mots d'émission. Les valeurs autorisées sont dans la plage de 1 à 4, et représentent le nombre d'octets qui seront envoyés à la fois au DSP56001. Ces quantités de données seront soit complétées par des octets contenant zéro, soit tronquées pour s'adapter au format de données natif de 24 bits du DSP56001.
DSP56K_SET_RX_WSIZE
définit la taille des mots de réception. Les valeurs autorisées sont dans la plage de 1 à 4, et représentent le nombre d'octets qui seront reçus à la fois du DSP56001. Ces quantités de données seront soit tronquées, soit complétées par un octet nul ('\0'), pour s'adapter au format de données natif de 24 bits du DSP56001.
DSP56K_HOST_FLAGS
lit et écrit les drapeaux hôtes. Les drapeaux hôtes sont quatre bits à usage général qui peuvent être lus à la fois par l'ordinateur hôte et par le DSP56001. Les bits 0 et 1 peuvent être écrits par l'hôte, et les bits 2 et 3 peuvent être écrits par le DSP56001.
Pour accéder aux drapeaux hôtes, le troisième argument ioctl(2) doit être un pointeur vers une structure struct dsp56k_host_flags. Si un bit 0 ou 1 est défini dans le membre .dir, le bit correspondant dans .out sera écrit dans les drapeaux hôtes. L'état de tous les drapeaux hôtes sera renvoyé dans les quatre bits inférieurs du membre .status.
DSP56K_HOST_CMD
envoie une commande hôte. Les valeurs autorisées sont dans la plage de 0 à 31, et représentent une commande définie par l'utilisateur gérée par le programme en cours d'exécution dans le DSP56001.
