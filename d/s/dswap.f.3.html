sous-programme dswap (integer n, double precision, dimension(*) dx, integer incx, double precision, dimension(*) dy, integer incy)

DSWAP

Objectif:

!>
!>    DSWAP échange deux vecteurs.
!>    utilise des boucles déroulées pour des incréments égaux à 1.
!>

Paramètres

N 
!>          N est un ENTIER
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

DX

!>          DX est un tableau DOUBLE PRECISION, dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un ENTIER
!>         espacement de stockage entre les éléments de DX
!>

DY

!>          DY est un tableau DOUBLE PRECISION, dimension ( 1 + ( N - 1 )*abs( INCY ) )
!>

INCY

!>          INCY est un ENTIER
!>         espacement de stockage entre les éléments de DY
!>
