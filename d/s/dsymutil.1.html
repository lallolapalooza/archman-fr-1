NOM

dsymutil - manipule les fichiers d'archives de symboles de débogage DWARF

SYNTAXE

dsymutil [options] executable

DESCRIPTION

dsymutil relie les informations de débogage DWARF trouvées dans les fichiers objets d'un exécutable executable en utilisant les informations de symboles de débogage contenues dans sa table de symboles. Par défaut, les informations de débogage reliées sont placées dans un paquet .dSYM portant le même nom que l'exécutable.

OPTIONS

--accelerator=<type d'accélérateur>
Spécifie le type désiré de table d'accélérateur. Les options valides sont 'Apple', 'Dwarf', 'Default' et 'None'.
--arch <arch>
Relie les informations de débogage DWARF uniquement pour les types d'architectures CPU spécifiés. Les architectures peuvent être spécifiées par leur nom. Lors de l'utilisation de cette option, une erreur sera retournée si une architecture ne peut pas être reliée correctement. Cette option peut être spécifiée plusieurs fois, une fois pour chaque architecture désirée. Toutes les architectures CPU seront reliées par défaut et toute architecture qui ne pourra pas être reliée correctement entraînera une erreur de retour de dsymutil.
--build-variant-suffix <suffix=variante_de_build>
Spécifie le suffixe de variante de build utilisé pour construire le fichier exécutable. Il peut y avoir plusieurs variantes pour la binaire d'un produit, chacune construite légèrement différemment. Les variantes de build les plus courantes sont 'debug' et 'profile'. Définir la variable d'environnement DYLD_IMAGE_SUFFIX fera en sorte que dyld charge la variante spécifiée à l'exécution.
--dump-debug-map
Affiche la carte de débogage de l'exécutable (la liste des fichiers objets contenant les informations de débogage) au format YAML et quitte. Aucune liaison DWARF n'aura lieu.
-D <chemin>

Spécifie un répertoire contenant des fichiers dSYM à rechercher. Ceci est utilisé pour les bibliothèques fusionnables, afin que dsymutil sache où rechercher les fichiers dSYM contenant des informations de débogage sur les symboles présents dans ces bibliothèques.

--fat64
Utilise un en-tête 64 bits lors de l'émission de binaires universelles.
--flat, -f
Produit un fichier dSYM plat. Une extension .dwarf sera ajoutée au nom de l'exécutable, sauf si le fichier de sortie est spécifié en utilisant l'option -o.
--gen-reproducer
Génère un reproducteur constitué des fichiers objets d'entrée. Alias de --reproducer=GenerateOnExit.
--help, -h
Affiche cette aide.
--keep-function-for-static
Fait en sorte qu'une variable statique conserve la fonction englobante même si elle aurait été omise autrement.
--minimize, -z
Lorsqu'elle est utilisée lors de la création d'un fichier dSYM, cette option supprime l'émission des sections .debug_inlines, .debug_pubnames et .debug_pubtypes car dsymutil dispose actuellement de meilleurs équivalents : .apple_names et .apple_types. Lorsqu'elle est utilisée conjointement avec l'option --update, cette option entraîne la suppression des tables d'accélérateur redondantes.
--no-object-timestamp
Ne vérifie pas l'horodatage des fichiers objets.
--no-odr
N'utilise pas l'ODR (One Definition Rule) pour l'unicité des types C++.
--no-output
Effectue la liaison en mémoire, mais n'émet pas le fichier résultat.
--no-swiftmodule-timestamp
Ne vérifie pas l'horodatage des fichiers swiftmodule.
--num-threads <threads>, -j <threads>
Spécifie le nombre maximum (n) de threads simultanés à utiliser lors de la liaison de plusieurs architectures.
--object-prefix-map <prefix=remapped>
Remappe les chemins des fichiers objets (mais pas les chemins sources) avant le traitement. Utilisez ceci pour les objets Clang où l'emplacement du cache des modules a été remappé à l'aide de -fdebug-prefix-map ; pour aider dsymutil à trouver le cache des modules Clang.
--oso-prepend-path <chemin>
Spécifie un chemin à préfixer à tous les chemins des fichiers objets de symboles de débogage.
--out <nomdefichier>, -o <nomdefichier>
Spécifie un chemin alternatif pour placer le paquet dSYM. Le chemin par défaut du paquet dSYM est créé en ajoutant .dSYM au nom de l'exécutable.
-q, --quiet
Active le mode silencieux et limite la sortie.
--remarks-drop-without-debug
Supprime les remarques sans emplacements de débogage valides. Sans ce drapeau, toutes les remarques sont conservées.
--remarks-output-format <format>
Spécifie le format à utiliser lors de la sérialisation des remarques liées.
--remarks-prepend-path <chemin>
Spécifie un répertoire à préfixer aux chemins des fichiers de remarques externes.
--reproducer <mode>
Spécifie le mode de génération du reproducteur. Les options valides sont 'GenerateOnExit', 'GenerateOnCrash', 'Use', 'Off'.
--statistics
Affiche des statistiques sur la contribution de chaque fichier objet aux informations de débogage liées. Ceci affiche un tableau après la liaison avec le nom du fichier objet, la taille des informations de débogage dans le fichier objet (en octets) et la taille contribuée (en octets) au dSYM lié. Le tableau est trié par taille de sortie, listant les fichiers objets avec la plus grande contribution en premier.
-s, --symtab
Affiche la table de symboles trouvée dans executable ou les fichiers objets et quitte.
-S
Produit une sortie d'assemblage textuel au lieu d'un fichier compagnon dSYM binaire.
--toolchain <toolchain>
Intègre la toolchain dans la liste de propriétés du paquet dSYM.
-u, --update
Met à jour un fichier dSYM existant pour contenir les dernières tables d'accélérateur et d'autres optimisations DWARF. Cette option reconstruira les tables d'accélérateur hachées '.apple_names' et '.apple_types'.
--use-reproducer <path>
Utiliser les fichiers objets du chemin du reproducteur donné. Alias pour --reproducer=Use.
--verbose
Afficher des informations détaillées lors de l'édition de liens.
--verify
Exécuter le vérificateur DWARF sur les informations de débogage DWARF liées.
-v, --version
Afficher la version de l'outil.
-y
Traiter executable comme une carte de débogage YAML plutôt qu'un executable.

CODE DE RETOUR

dsymutil renvoie 0 si les informations de débogage DWARF ont été liées avec succès. Sinon, il renvoie 1.
