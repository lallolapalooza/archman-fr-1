Documentation de la fonction/sous-programme

sous-programme dstech (integer n, double precision, dimension( * ) a, double precision, dimension( * ) b, double precision, dimension( * ) eig, double precision tol, double precision, dimension( * ) work, integer info)

DSTECH

Objectif :

!>
!>    Soit T la matrice tridiagonale avec les entrées diagonales A(1) ,...,
!>    A(N) et les entrées hors diagonales B(1) ,..., B(N-1)).  DSTECH vérifie si
!>    EIG(1) ,..., EIG(N) sont effectivement des valeurs propres précises de T.
!>    Il le fait en développant chaque EIG(I) dans un intervalle
!>    [SVD(I) - EPS, SVD(I) + EPS], en fusionnant les intervalles qui se chevauchent le cas échéant,
!>    et en utilisant des suites de Sturm pour compter et vérifier si chaque
!>    intervalle résultant contient le bon nombre de valeurs propres (en utilisant
!>    DSTECT).  Ici, EPS = TOL*MAZHEPS*MAXEIG, où MACHEPS est la précision machine
!>    et MAXEIG est la valeur absolue de la plus grande valeur propre. Si chaque intervalle contient le bon nombre de
!>    valeurs propres, INFO = 0 est retourné, sinon INFO est l'indice de
!>    la première valeur propre du premier intervalle incorrect.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          La dimension de la matrice tridiagonale T.
!>

A

!>          A est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>          Les entrées diagonales de la matrice tridiagonale T.
!>

B

!>          B est un tableau de double précision (DOUBLE PRECISION), dimension (N-1)
!>          Les entrées hors diagonales de la matrice tridiagonale T.
!>

EIG

!>          EIG est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>          Les valeurs propres supposées à vérifier.
!>

TOL

!>          TOL est un réel double précision (DOUBLE PRECISION)
!>          Tolérance d'erreur pour la vérification, un multiple de la
!>          précision machine.
!>

WORK

!>          WORK est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>

INFO

!>          INFO est un entier (INTEGER)
!>          0  si toutes les valeurs propres sont correctes (à
!>             1 +- TOL*MAZHEPS*MAXEIG près)
!>          >0 si l'intervalle contenant la INFO-ième valeur propre
!>             contient un nombre incorrect de valeurs propres.
!>
