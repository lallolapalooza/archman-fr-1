subroutine dsgesv (n, nrhs, a, lda, ipiv, b, ldb, x, ldx, work, swork, iter, info)
DSGESV calcule la solution du système d'équations linéaires A * X = B pour les matrices GE (précision mixte avec raffinement itératif)

Documentation de la fonction/de la

sous-routine

subroutine dsgesv (integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( n, * ) work, real, dimension( * ) swork, integer iter, integer

info)

DSGESV calcule la solution du système d'équations linéaires A * X = B pour les matrices GE (précision mixte avec raffinement

itératif)

But

: 
!>
!> DSGESV calcule la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice N×N et X et B sont des matrices N×NRHS.
!>
!> DSGESV tente d'abord de factoriser la matrice en PRÉCISION SIMPLE
!> et d'utiliser cette factorisation dans une procédure de raffinement
!> itératif pour produire une solution avec une qualité d'erreur
!> arrière normée en PRÉCISION DOUBLE (voir ci-dessous). Si l'approche
!> échoue, la méthode passe à une factorisation et une résolution en
!> PRÉCISION DOUBLE.
!>
!> Le raffinement itératif ne sera pas une stratégie gagnante si le
!> rapport des performances en PRÉCISION SIMPLE sur les performances
!> en PRÉCISION DOUBLE est trop faible. Une stratégie raisonnable
!> devrait prendre en compte le nombre de seconds membres et la taille
!> de la matrice. Cela pourrait être fait avec un appel à ILAENV dans
!> le futur. Jusqu'à présent, nous essayons toujours le raffinement
!> itératif.
!>
!> Le processus de raffinement itératif s'arrête si
!>     ITER > ITERMAX
!> ou si pour tous les seconds membres nous avons :
!>     RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX
!> où
!>     o ITER est le numéro de l'itération courante dans le processus
!>       de raffinement itératif
!>     o RNRM est la norme infinie du résidu
!>     o XNRM est la norme infinie de la solution
!>     o ANRM est la norme opérateur infinie de la matrice A
!>     o EPS est l'epsilon machine retournée par DLAMCH('Epsilon')
!> Les valeurs ITERMAX et BWDMAX sont fixées à 30 et 1.0D+00
!> respectivement.
!
>

Paramètre

s
N 
!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes de la matrice B.  NRHS >= 0.
!
>

A 
!>          A est un tableau DOUBLE PRECISION,
!>          dimension (LDA,N)
!>          À l'entrée, la matrice des coefficients A de taille N×N.
!>          À la sortie, si le raffinement itératif a été utilisé avec
!>          succès (INFO = 0 et ITER >= 0, voir la description ci-dessous),
!>          alors A est inchangée ; si la factorisation en double
!>          précision a été utilisée (INFO = 0 et ITER < 0, voir la
!>          description ci-dessous), alors le tableau A contient les
!>          facteurs L et U de la factorisation A = P*L*U ; les éléments
!>          diagonaux unitaires de L ne sont pas stockés.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot qui définissent la matrice de
!>          permutation P ; la ligne i de la matrice a été échangée avec
!>          la ligne IPIV(i). Correspond soit à la factorisation en
!>          précision simple (si INFO = 0 et ITER >= 0) soit à la
!>          factorisation en précision double (si INFO = 0 et ITER < 0).
!
>

B 
!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>          La matrice des seconds membres B de taille N×NRHS.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!
>

X 
!>          X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Si INFO = 0, la matrice solution X de taille N×NRHS.
!
>

LD

X 
!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (N,NRHS)
!>          Ce tableau est utilisé pour contenir les vecteurs résidus.
!
>

SWOR

K 
!>          SWORK est un tableau REAL, dimension (N*(N+NRHS))
!>          Ce tableau est utilisé pour la matrice en précision simple
!>          et les seconds membres ou les solutions en précision simple.
!
>

ITE

R 
!>          ITER est INTEGER
!>          < 0 : le raffinement itératif a échoué, la factorisation en
!>               précision double a été effectuée
!>               -1 : la routine est revenue à la pleine précision pour
!>                    des raisons spécifiques à l'implémentation ou à la
!>                    machine
!>               -2 : la réduction de précision a provoqué un débordement,
!>                    la routine est revenue à la pleine précision
!>               -3 : échec de SGETRF
!>               -31: arrêt du raffinement itératif après la 30e itération
!>          > 0 : le raffinement itératif a été utilisé avec succès.
!>               Retourne le nombre d'itérations
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur
!>                illégale
!>          > 0 :  si INFO = i, U(i,i) calculé en PRÉCISION DOUBLE est
!>                exactement zéro. La factorisation a été complétée,
!>                mais le facteur U est exactement singulier, donc la
!>                solution n'a pas pu être calculée.
!
>
