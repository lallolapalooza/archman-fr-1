dssi_analyse_plugin(1) Manuel des commandes générales dssi_analyse_plugin(1)

NOM

dssi_analyse_plugin - décrire un plugin DSSI

SYNTAXE

dssi_analyse_plugin [-v|--verbose] [chemin]<nomlib>[:<étiquette>]

DESCRIPTION

dssi_analyse_plugin liste les informations sur les plugins DSSI dans une bibliothèque partagée DSSI spécifiée nomlib. Si étiquette est fournie, seules les informations du plugin étiqueté étiquette seront listées, sinon, tous les plugins de la bibliothèque partagée seront listés. Si chemin n'est pas fourni, la bibliothèque partagée est recherchée dans la liste des répertoires séparés par des deux-points spécifiée dans la variable d'environnement DSSI_PATH.

OPTIONS

-v
--verbose
Permet à dssi_analyse_plugin d'être plus verbeux dans ses rapports. En particulier, il listera les noms de programmes par défaut pour chaque plugin, le cas échéant.

EXEMPLES

La commande suivante affichera des informations sur tous les plugins de la bibliothèque partagée /usr/local/lib/dssi/calf.so, y compris les noms de programmes par défaut :

$ dssi_analyse_plugin -v /usr/local/lib/dssi/calf.so

La commande suivante recherchera la bibliothèque partagée trivial_sampler.so en utilisant DSSI_PATH, et affichera des informations sur le plugin mono_sampler :

$ dssi_analyse_plugin trivial_sampler.so:mono_sampler

ENVIRONNEMENT

DSSI_PATH
Une liste de répertoires séparés par des deux-points à scanner pour les plugins DSSI.

CONFORMITÉ

DSSI RFC version 1.0.

VOIR AUSSI

dssi_list_plugins(1), http://dssi.sourceforge.net/
