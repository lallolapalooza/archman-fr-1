sous-routine dsyl01 (double precision thresh, integer, dimension( 3 ) nfail, double precision, dimension( 2 ) rmax, integer, dimension( 2 ) ninfo, integer knt)

DSYL01

Objectif :

!>
!> DSYL01 teste DTRSYL et DTRSYL3, routines pour résoudre l'équation matricielle
!> de Sylvester
!>
!>    op(A)*X + ISGN*X*op(B) = scale*C,
!>
!> où A et B sont supposées être sous forme canonique de Schur, op() représente une
!> transposition optionnelle, et ISGN peut être -1 ou +1. Scale est une sortie
!> inférieure ou égale à 1, choisie pour éviter le débordement dans X.
!>
!> Le code de test vérifie que le résidu suivant ne dépasse pas
!> le seuil fourni :
!>
!>    norm(op(A)*X + ISGN*X*op(B) - scale*C) /
!>        (EPS*max(norm(A),norm(B))*norm(X))
!>
!> Cette routine complète DGET35 en testant avec des matrices aléatoires plus grandes,
!> dont certaines nécessitent un changement d'échelle de X pour éviter le débordement.
!>
!>

Paramètres :

THRESH 
!>          THRESH est de type DOUBLE PRECISION
!>          Un test sera compté comme si le résidu, calculé comme
!>          décrit ci-dessus, dépasse THRESH.
!>

NFAIL

!>          NFAIL est un tableau d'entiers, de dimension (3)
!>          NFAIL(1) = Nombre de fois où le résidu de DTRSYL dépasse le seuil THRESH
!>          NFAIL(2) = Nombre de fois où le résidu de DTRSYL3 dépasse le seuil THRESH
!>          NFAIL(3) = Nombre de fois où DTRSYL3 et DTRSYL diffèrent
!>

RMAX

!>          RMAX est de type DOUBLE PRECISION, de dimension (2)
!>          RMAX(1) = Valeur du rapport de test le plus élevé pour DTRSYL
!>          RMAX(2) = Valeur du rapport de test le plus élevé pour DTRSYL3
!>

NINFO

!>          NINFO est un tableau d'entiers, de dimension (2)
!>          NINFO(1) = Nombre de fois où DTRSYL renvoie un INFO attendu
!>          NINFO(2) = Nombre de fois où DTRSYL3 renvoie un INFO attendu
!>

KNT

!>          KNT est un entier
!>          Nombre total d'exemples testés.
!>

Définition à la ligne 88 du fichier dsyl01.f.
