DSPOSV calcule la solution du système d'équations linéaires A * X = B pour les matrices

PO

But

: 
!>
!> DSPOSV calcule la solution d'un système réel d'équations linéaires
!>    A * X = B,
!> où A est une matrice symétrique définie positive de dimension N par N et X et B
!> sont des matrices de dimension N par NRHS.
!>
!> DSPOSV tente d'abord de factoriser la matrice en PRÉCISION SIMPLE
!> et d'utiliser cette factorisation dans une procédure d'affinage itératif
!> pour produire une solution avec une qualité d'erreur arrière normative
!> en PRÉCISION DOUBLE (voir ci-dessous). Si l'approche échoue, la méthode passe à une
!> factorisation et une résolution en PRÉCISION DOUBLE.
!>
!> L'affinage itératif ne sera pas une stratégie gagnante si
!> le rapport des performances en PRÉCISION SIMPLE sur les performances en
!> PRÉCISION DOUBLE est trop faible. Une stratégie raisonnable devrait prendre en
!> compte le nombre de seconds membres et la taille de la matrice.
!> Cela pourrait être fait avec un appel à ILAENV à l'avenir. Jusqu'à présent, nous
!> essayons toujours l'affinage itératif.
!>
!> Le processus d'affinage itératif s'arrête si
!>     ITER > ITERMAX
!> ou pour tous les seconds membres nous avons :
!>     RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX
!> où
!>     o ITER est le numéro de l'itération courante dans le processus
!>       d'affinage itératif
!>     o RNRM est la norme infinie du résidu
!>     o XNRM est la norme infinie de la solution
!>     o ANRM est la norme d'opérateur infinie de la matrice A
!>     o EPS est l'epsilon machine renvoyé par DLAMCH('Epsilon')
!> Les valeurs ITERMAX et BWDMAX sont fixées à 30 et 1.0D+00
!> respectivement.
!
>

Paramètre

s
UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!
>

N 
!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!
>

A 
!>          A est un tableau DOUBLE PRECISION,
!>          dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          triangulaire supérieure de A de dimension N par N contient la partie
!>          triangulaire supérieure de la matrice A, et la partie
!>          triangulaire strictement inférieure de A n'est pas référencée.  Si UPLO = 'L', la
!>          partie triangulaire inférieure de A de dimension N par N contient la partie
!>          triangulaire inférieure de la matrice A, et la partie
!>          triangulaire strictement supérieure de A n'est pas référencée.
!>          À la sortie, si l'affinage itératif a été utilisé avec succès
!>          (INFO = 0 et ITER >= 0, voir la description ci-dessous), alors A est
!>          inchangé, si une factorisation en double précision a été utilisée
!>          (INFO = 0 et ITER < 0, voir la description ci-dessous), alors le
!>          tableau A contient le facteur U ou L de la factorisation
!>          de Cholesky A = U**T*U ou A = L*L**T.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!
>

B 
!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>          La matrice des seconds membres B de dimension N par NRHS.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!
>

X 
!>          X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Si INFO = 0, la matrice solution X de dimension N par NRHS.
!
>

LD

X 
!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (N,NRHS)
!>          Ce tableau est utilisé pour stocker les vecteurs résiduels.
!
>

SWOR

K 
!>          SWORK est un tableau REAL, dimension (N*(N+NRHS))
!>          Ce tableau est utilisé pour conserver la matrice en simple précision et les
!>          seconds membres ou les solutions en simple précision.
!
>

ITE

R 
!>          ITER est INTEGER
!>          < 0 : l'affinage itératif a échoué, une factorisation en
!>               double précision a été effectuée
!>               -1 : la routine est revenue à la pleine précision pour
!>                    des raisons liées à l'implémentation ou à la machine
!>               -2 : la réduction de précision a provoqué un débordement,
!>                    la routine est revenue à la pleine précision
!>               -3 : échec de SPOTRF
!>               -31 : arrêt de l'affinage itératif après la 30e
!>                    itération
!>          > 0 : l'affinage itératif a été utilisé avec succès.
!>               Renvoie le nombre d'itérations
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                de (DOUBLE PRECISION) A n'est pas positif, donc la
!>                factorisation n'a pas pu être terminée, et la solution
!>                n'a pas été calculée.
!
>
