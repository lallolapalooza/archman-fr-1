Documentation de la fonction/sous-programme

sous-programme dstevx (caractère jobz, caractère range, entier n, double précision, dimension( * ) d, double précision, dimension( * ) e, double précision vl, double précision vu, entier il, entier iu, double précision abstol, entier m, double précision, dimension( * ) w, double précision, dimension( ldz, * ) z, entier ldz, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

DSTEVX calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour D'AUTRES matrices

Objectif :

!>
!> DSTEVX calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique réelle A. Les valeurs propres et
!> les vecteurs propres peuvent être sélectionnés en spécifiant soit une plage de valeurs,
!> soit une plage d'indices pour les valeurs propres souhaitées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' :  Calculer seulement les valeurs propres ;
!>          = 'V' :  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs propres de l'indice IL à IU seront trouvées.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice.  N >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          En entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A.
!>          En sortie, D peut être multiplié par un facteur constant choisi
!>          pour éviter le débordement/sous-dépassement dans le calcul des valeurs propres.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (max(1,N-1))
!>          En entrée, les (n-1) éléments sous-diagonaux de la matrice tridiagonale
!>          A dans les éléments 1 à N-1 de E.
!>          En sortie, E peut être multiplié par un facteur constant choisi
!>          pour éviter le débordement/sous-dépassement dans le calcul des valeurs propres.
!>

VL

!>          VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          parcourir pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          parcourir pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>          lorsqu'elle est déterminée à se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur
!>          ou égal à zéro, alors EPS*|T| sera utilisé à
!>          sa place, où |T| est la norme 1 de la matrice tridiagonale.
!>
!>          Les valeurs propres seront calculées le plus précisément lorsque ABSTOL est
!>          réglé sur deux fois le seuil de sous-dépassement 2*DLAMCH('S'), et non zéro.
!>          Si cette routine se termine avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de régler ABSTOL sur
!>          2*DLAMCH('S').
!>
!>          Voir par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées en
!>          ordre croissant.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension (LDZ, max(1,M) )
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre échoue à converger (INFO > 0), alors cette
!>          colonne de Z contient la dernière approximation du
!>          vecteur propre, et l'indice du vecteur propre est retourné
!>          dans IFAIL. Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension de tête du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (5*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau INTEGER, dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui ont échoué à converger.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  succès de l'exécution
!>          < 0 :  si INFO = -i, alors le i-ème argument avait une valeur illégale
!>          > 0 :  si INFO = i, alors i vecteurs propres ont échoué à converger.
!>                Leurs indices sont stockés dans le tableau IFAIL.
!>
