Documentation de la fonction/sous-programme

sous-programme dstevd (caractère jobz, entier n, double précision, dimension( * ) d, double précision, dimension( * ) e, double précision, dimension( ldz, * ) z, entier ldz, double précision, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier liwork, entier info)

DSTEVD calcule les valeurs propres et, optionnellement, les vecteurs propres gauche et/ou droite pour d'AUTRES matrices

Objectif:

!>
!> DSTEVD calcule toutes les valeurs propres et, optionnellement, les vecteurs propres d'une
!> matrice tridiagonale symétrique réelle. Si des vecteurs propres sont désirés, il
!> utilise un algorithme de type diviser pour régner.
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calcul des valeurs propres seulement ;
!>          = 'V':  Calcul des valeurs propres et des vecteurs propres.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice.  N >= 0.
!>

D

!>          D est un tableau de DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A.
!>          À la sortie, si INFO = 0, les valeurs propres sont triées par ordre croissant.
!>

E

!>          E est un tableau de DOUBLE PRECISION, dimension (N-1)
!>          À l'entrée, les (n-1) éléments sous-diagonaux de la matrice tridiagonale
!>          A, stockés dans les éléments 1 à N-1 de E.
!>          À la sortie, le contenu de E est détruit.
!>

Z

!>          Z est un tableau de DOUBLE PRECISION, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient les vecteurs propres orthonormés
!>          de la matrice A, avec la i-ème colonne de Z
!>          contenant le vecteur propre associé à D(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION,
!>                                         dimension (LWORK)
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si JOBZ  = 'N' ou N <= 1 alors LWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 1 alors LWORK doit être au moins
!>                         ( 1 + 4*N + N**2 ).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement les tailles optimales des tableaux WORK et IWORK,
!>          renvoie ces valeurs comme premières entrées des tableaux WORK
!>          et IWORK, et aucun message d'erreur relatif à LWORK ou
!>          LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau de INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) contient le LIWORK optimal.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si JOBZ  = 'N' ou N <= 1 alors LIWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 1 alors LIWORK doit être au moins 3+5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule seulement les tailles optimales des tableaux WORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK et IWORK, et aucun message d'erreur relatif à
!>          LWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, l'algorithme n'a pas convergé ; i
!>                éléments non diagonaux de E n'ont pas convergé vers zéro.
!>
