DSBGV

X

But

: 
!>
!> DSBGVX calcule les valeurs propres sélectionnées et, optionnellement, les vecteurs propres
!> d'un problème de valeurs propres généralisé symétrique-défini positif par bandes, de
!> la forme A*x=(lambda)*B*x.  Ici, A et B sont supposés symétriques
!> et par bandes, et B est également défini positif.  Les valeurs propres et
!> les vecteurs propres peuvent être sélectionnés en spécifiant soit toutes les valeurs propres,
!> un intervalle de valeurs ou un intervalle d'indices pour les valeurs propres désirées.
!
>

Paramètre

s
JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' :  calcule uniquement les valeurs propres ;
!>          = 'V' :  calcule les valeurs propres et les vecteurs propres.
!
>

RANG

E 
!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs propres de la ième à la IU-ième seront trouvées.
!
>

UPL

O 
!>          UPLO est CHARACTER*1
!>          = 'U' :  les triangles supérieurs de A et B sont stockés ;
!>          = 'L' :  les triangles inférieurs de A et B sont stockés.
!
>

N 
!>          N est INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!
>

K

A 
!>          KA est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KA >= 0.
!
>

K

B 
!>          KB est INTEGER
!>          Le nombre de superdiagonales de la matrice B si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KB >= 0.
!
>

A

B 
!>          AB est un tableau DOUBLE PRECISION, dimension (LDAB, N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice
!>          symétrique par bandes A, stocké dans les premières ka+1 lignes du tableau.  La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) pour max(1,j-ka)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+ka).
!>
!>          À la sortie, le contenu de AB est détruit.
!
>

LDA

B 
!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KA+1.
!
>

B

B 
!>          BB est un tableau DOUBLE PRECISION, dimension (LDBB, N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice
!>          symétrique par bandes B, stocké dans les premières kb+1 lignes du tableau.  La
!>          j-ième colonne de B est stockée dans la j-ième colonne du tableau BB
!>          comme suit :
!>          si UPLO = 'U', BB(ka+1+i-j,j) = B(i,j) pour max(1,j-kb)<=i<=j ;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) pour j<=i<=min(n,j+kb).
!>
!>          À la sortie, le facteur S de la factorisation de Cholesky scindée
!>          B = S**T*S, tel que retourné par DPBSTF.
!
>

LDB

B 
!>          LDBB est INTEGER
!>          La dimension principale du tableau BB.  LDBB >= KB+1.
!
>

Q 
!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ, N)
!>          Si JOBZ = 'V', la matrice n par n utilisée dans la réduction de
!>          A*x = (lambda)*B*x à la forme standard, c'est-à-dire C*x = (lambda)*x,
!>          et par conséquent C à la forme tridiagonale.
!>          Si JOBZ = 'N', le tableau Q n'est pas référencé.
!
>

LD

Q 
!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.  Si JOBZ = 'N',
!>          LDQ >= 1. Si JOBZ = 'V', LDQ >= max(1,N).
!
>

V

L 
!>          VL est DOUBLE PRECISION
!>
!>          Si RANGE='V', la borne inférieure de l'intervalle dans
!>          lequel rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!
>

V

U 
!>          VU est DOUBLE PRECISION
!>
!>          Si RANGE='V', la borne supérieure de l'intervalle dans
!>          lequel rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!
>

I

L 
!>          IL est INTEGER
!>
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!
>

I

U 
!>          IU est INTEGER
!>
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!
>

ABSTO

L 
!>          ABSTOL est DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approchée est acceptée comme convergée
!>          lorsqu'il est déterminé qu'elle se situe dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine.  Si ABSTOL est inférieur ou
!>          égal à zéro, alors  EPS*|T|  sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant A à la forme tridiagonale.
!>
!>          Les valeurs propres seront calculées avec le plus d'exactitude lorsque ABSTOL est
!>          défini à deux fois le seuil de débordement inférieur 2*DLAMCH('S'), et non à zéro.
!>          Si cette routine se termine avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*DLAMCH('S').
!
>

M 
!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!
>

Z 
!>          Z est un tableau DOUBLE PRECISION, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient la matrice Z des
!>          vecteurs propres, avec la ième colonne de Z contenant le
!>          vecteur propre associé à W(i).  Les vecteurs propres sont
!>          normalisés de sorte que Z**T*B*Z = I.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!
>

LD

Z 
!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!&gt;          WORK est un tableau DOUBLE PRECISION, dimension (7*N)
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (5*N)
!
>

IFAI

L 
!>          IFAIL est un tableau INTEGER, dimension (M)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont nuls.  Si INFO > 0, alors IFAIL contient les
!>          indices des valeurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          <= N: si INFO = i, alors i vecteurs propres n'ont pas convergé.
!>                  Leurs indices sont stockés dans IFAIL.
!>          > N:  DPBSTF a renvoyé un code d'erreur ; c'est-à-dire,
!>                si INFO = N + i, pour 1 <= i <= N, alors le mineur
!>                principal de tête d'ordre i de B n'est pas positif.
!>                La factorisation de B n'a pas pu être complétée et
!>                aucune valeur propre ou vecteur propre n'a été calculé.
!
>
