Documentation de la fonction/sous-programme

sous-programme dsygs2 (integer itype, character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, integer info)

DSYGS2 réduit un problème aux valeurs propres généralisé symétrique réel défini à sa forme standard, en utilisant les résultats de factorisation obtenus à partir de spotrf (algorithme non bloqué).

Objectif :

!>
!> DSYGS2 réduit un problème aux valeurs propres généralisé symétrique réel défini
!> à sa forme standard.
!>
!> Si ITYPE = 1, le problème est A*x = lambda*B*x,
!> et A est écrasé par inv(U**T)*A*inv(U) ou inv(L)*A*inv(L**T)
!>
!> Si ITYPE = 2 ou 3, le problème est A*B*x = lambda*x ou
!> B*A*x = lambda*x, et A est écrasé par U*A*U**T ou L**T *A*L.
!>
!> B doit avoir été préalablement factorisé comme U**T *U ou L*L**T par DPOTRF.
!>

Paramètres

ITYPE 
!>          ITYPE est INTEGER
!>          = 1 : calculer inv(U**T)*A*inv(U) ou inv(L)*A*inv(L**T) ;
!>          = 2 ou 3 : calculer U*A*U**T ou L**T *A*L.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée, et comment B a été factorisé.
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimensions (LDA,N)
!>          En entrée, la matrice symétrique A. Si UPLO = 'U', la partie
!>          supérieure triangulaire de A, de taille n x n, contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la
!>          partie inférieure triangulaire de A, de taille n x n, contient la
!>          partie triangulaire inférieure de la matrice A, et la partie
!>          strictement supérieure triangulaire de A n'est pas référencée.
!>
!>          En sortie, si INFO = 0, la matrice transformée, stockée dans le
!>          même format que A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimensions (LDB,N)
!>          Le facteur triangulaire de la factorisation de Cholesky de B,
!>          tel que retourné par DPOTRF.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès.
!>          < 0 : si INFO = -i, le i-ème argument était illégal.
!>
