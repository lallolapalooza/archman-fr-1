COMMANDE 'dsctl ldifgen users'

utilisation : dsctl [-v] [-j] [instance] ldifgen users [-h] [--number NUMBER]
[--suffix SUFFIX]
[--parent PARENT] [--generic]
[--start-idx START_IDX]
[--rdn-cn] [--localize]
[--ldif-file LDIF_FILE]

OPTIONS 'dsctl ldifgen users'

--number NUMBER
Le nombre d'utilisateurs à créer.
--suffix SUFFIX
Le suffixe de la base de données où les entrées seront créées.
--parent PARENT
L'entrée parente sous laquelle les entrées utilisateur doivent être créées. Si elle n'est pas spécifiée, les entrées sont stockées sous des unités organisationnelles aléatoires.
--generic
Crée des entrées génériques au format "uid=user####". Ces entrées sont également compatibles avec ldclt.
--start-idx START_IDX
Pour les LDIF génériques, vous pouvez choisir l'index de départ des entrées utilisateur. La valeur par défaut est "0".
--rdn-cn
Utilise l'attribut "cn" comme attribut RDN dans le DN au lieu de "uid"
--localize
Localise les données LDIF
--ldif-file LDIF_FILE
Le nom du fichier LDIF. L'emplacement par défaut est le répertoire LDIF du serveur avec le nom 'ldifgen.ldif'
