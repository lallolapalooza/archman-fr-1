NOM

dscreate

SYNTAXE

dscreate [-h] [-v] [-j] {from-file,interactive,create-template,ds-root} ...

ARGUMENTS POSITIONNELS

dscreate from-file
Crée une instance de serveur d'annuaire à partir d'un fichier de réponses inf
dscreate interactive
Démarre l'installateur interactif pour l'installation du serveur d'annuaire
dscreate create-template
Affiche un exemple de fichier de réponses inf, ou fournit un nom de fichier pour l'écrire sur disque.
dscreate ds-root
Prépare un répertoire racine dans lequel un utilisateur non root peut créer, exécuter et administrer des instances.

COMMANDE 'dscreate from-file'

utilisation: dscreate from-file [-h] [-n] fichier

fichier
Fichier inf à utiliser avec les réponses préparées. Vous pouvez en générer un exemple avec 'dscreate create-template'

OPTIONS 'dscreate from-file'

-n, --dryrun
Valide seulement le système et les configurations. N'altère pas le système.

COMMANDE 'dscreate interactive'

utilisation: dscreate interactive [-h]

COMMANDE 'dscreate create-template'

utilisation: dscreate create-template [-h] [--advanced] [fichier_template]

fichier_template
Écrit l'exemple de template dans ce fichier

OPTIONS 'dscreate create-template'

--advanced
Ajoute des options avancées au template - la modification des options avancées peut entraîner l'échec de l'installation de votre instance

COMMANDE 'dscreate ds-root'

utilisation: dscreate ds-root [-h] dir_racine [dir_bin]

dir_racine
Un répertoire qui sera utilisé comme racine virtuelle.
dir_bin
Un répertoire dans lequel les wrappers d'administration sont installés. (Devrait être dans le PATH)

OPTIONS

-v, --verbose
Affiche un suivi détaillé des opérations pendant l'exécution de la commande
-j, --json
Retourne le résultat sous forme de message json

COMMENTAIRES

Exemple d'installation par un utilisateur non root:
PATH=$HOME/bin:$PATH # Devrait être dans .profile
dscreate ds-root $HOME/mydsroot $HOME/bin
hash -d dscreate # commande bash pour s'assurer que le nouveau wrapper dscreate sera utilisé
dscreate interactive
# Remarque: Assurez-vous d'utiliser un numéro de port non privilégié (c'est-à-dire > 1000)
