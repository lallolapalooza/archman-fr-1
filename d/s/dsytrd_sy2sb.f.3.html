NAME

    
dsytrd_sy2sb — DSYTRD_SY2SB is a subroutine that reduces a symmetric matrix to tridiagonal form.
    






    
SYNOPSIS

    
Subroutine dsytrd_sy2sb(UPLO, N, A, LDA, E, TAU, WORK, LWORK, INFO)

    
    

        
CHARACTER*1 UPLO

        
Specifies whether the matrix A is upper or lower triangular.

        
INTEGER N

        
The order of the matrix A.

        
DOUBLE PRECISION, DIMENSION(LDA,*) A

        
On entry, the symmetric matrix A.

        
INTEGER LDA

        
The leading dimension of the array A.

        
DOUBLE PRECISION, DIMENSION(*) E

        
On exit, the diagonal elements of the tridiagonal matrix T.

        
DOUBLE PRECISION, DIMENSION(*) TAU

        
On exit, the scalars of the elementary reflectors whose product defines the orthogonal transformation.

        
DOUBLE PRECISION, DIMENSION(*) WORK

        
Workspace array.

        
INTEGER LWORK

        
The dimension of the array WORK.

        
INTEGER INFO

        
0 if successful, a positive integer if a certain warning has been issued.

    






    
Function/Subroutine Documentation

    
This subroutine is part of the LAPACK library, which provides routines for linear algebra computations. DSYTRD_SY2SB specifically is designed to reduce a real symmetric matrix A to the tridiagonal form T by an orthogonal similarity transformation: A = Q * T * QT. The transformation is determined by the elementary reflectors returned in the array TAU. The subroutine overwrites the upper or lower triangle of A with the tridiagonal matrix T.

    
The parameter UPLO indicates whether the matrix A is stored in upper ('U') or lower ('L') triangular form. N is the size of the matrix. LDA is the leading dimension of the array A. The array E stores the diagonal elements of the tridiagonal matrix T. TAU contains the scalar factors of the elementary reflectors. WORK is a user-supplied workspace array, and LWORK is its size. INFO is an output parameter indicating the status of the computation.

Example Usage (Illustrative, not actual code)

    

PROGRAM EXAMPLE
  IMPLICIT NONE
  INTEGER :: N, LDA, LWORK, INFO
  DOUBLE PRECISION, ALLOCATABLE :: A(:,:), E(:), TAU(:), WORK(:)

  ! Define matrix size and leading dimension
  N = 5
  LDA = N
  
  ! Allocate arrays
  ALLOCATE(A(LDA,N), E(N), TAU(N))

  ! Initialize matrix A (e.g., a symmetric matrix)
  ! A = ... 

  ! Query the optimal workspace size
  LWORK = -1
  CALL dsytrd_sy2sb('U', N, A, LDA, E, TAU, WORK, LWORK, INFO)
  DEALLOCATE(WORK) ! Free temporary WORK array
  ALLOCATE(WORK(INT(A(1,1)))) ! Allocate WORK with optimal size
  LWORK = INT(A(1,1))

  ! Perform the reduction
  CALL dsytrd_sy2sb('U', N, A, LDA, E, TAU, WORK, LWORK, INFO)

  ! Check INFO for errors
  IF (INFO .NE. 0) THEN
    PRINT *, 'Error during dsytrd_sy2sb execution: ', INFO
  ELSE
    ! Matrix A now contains the tridiagonal matrix T in its upper/lower triangle
    ! E contains the diagonal elements of T
    ! TAU contains the scalar factors of the reflectors
    PRINT *, 'Matrix reduced to tridiagonal form successfully.'
    ! Further processing with E, TAU, and the modified A can be done here
  END IF

  ! Deallocate arrays
  DEALLOCATE(A, E, TAU, WORK)
END PROGRAM EXAMPLE
