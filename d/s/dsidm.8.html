NOM

dsidm

SYNTAXE

dsidm [-h] [-v] [-j] [-b BASEDN] [-D BINDDN] [-w BINDPW] [-W] [-y PWDFILE] [-Z] instance {compte,groupe,initialiser,init,uniteorganisationnelle,ou,posixgroup,utilisateur,config_client,role,service,groupeunique} ...

ARGUMENTS POSITIONNELS

dsidm compte
Gérer les comptes génériques, avec des tâches comme modifier, verrouiller et déverrouiller. Pour créer un compte, voir plutôt la sous-commande "utilisateur".
dsidm groupe
Gérer les groupes. L'unité organisationnelle (par défaut "ou=groups") doit exister avant de gérer les groupes. Les groupes utilisent l'objectclass "groupOfNames" et l'attribut de regroupement "member"
dsidm initialiser
Initialiser un backend avec des informations de domaine et des entrées d'exemple
dsidm uniteorganisationnelle
Gérer les unités organisationnelles
dsidm posixgroup
Gérer les groupes posix. L'unité organisationnelle (par défaut "ou=groups") doit exister avant de gérer les groupes posix.
dsidm utilisateur
Gérer les utilisateurs posix. L'unité organisationnelle (par défaut "ou=people") doit exister avant de gérer les utilisateurs.
dsidm config_client
Afficher et générer des exemples de configurations client pour ce serveur LDAP
dsidm role
Gérer les rôles.
dsidm service
Gérer les comptes de service. L'unité organisationnelle (par défaut "ou=Services") doit exister avant de gérer les comptes de service.
dsidm groupeunique
Gérer les groupes. L'unité organisationnelle (par défaut "ou=groups") doit exister avant de gérer les groupes. Les groupes uniques utilisent l'objectclass "groupOfUniqueNames" et l'attribut de regroupement "uniquemember"

COMMANDE 'dsidm compte'

usage: dsidm instance compte [-h]
{liste,obtenir-par-dn,modifier-par-dn,renommer-par-dn,supprimer,verrouiller,deverrouiller,etat-entree,etat-sous-arbre,reinitialiser_mot_de_passe,changer_mot_de_passe,mise_a_jour_massive} ...

ARGUMENTS POSITIONNELS 'dsidm compte'

dsidm compte liste
lister les comptes qui peuvent se connecter au répertoire (retourne le DN complet de l'entrée)

obtenir-par-dn <dn>
dsidm compte modifier-par-dn
modifier-par-dn <dn> <ajouter|supprimer|remplacer>:<attribut>:<valeur> ...
dsidm compte renommer-par-dn
renommer l'objet
dsidm compte supprimer
supprime le compte
dsidm compte verrouiller
verrouiller
dsidm compte deverrouiller
deverrouiller
dsidm compte etat-entree
état d'une entrée unique
dsidm compte etat-sous-arbre
état d'un sous-arbre
dsidm compte reinitialiser_mot_de_passe
Réinitialiser le mot de passe d'un compte. Ceci doit être effectué par un administrateur du répertoire.
dsidm compte changer_mot_de_passe
Changer le mot de passe d'un compte. Ceci peut être effectué par n'importe quel utilisateur (avec les droits appropriés)
dsidm compte mise_a_jour_massive
Effectuer une opération commune sur un ensemble d'entrées
