Paquet: openssl

DSA_SIGN(3ssl) OpenSSL DSA_SIGN(3ssl)

NOM

DSA_sign, DSA_sign_setup, DSA_verify - Signatures DSA

SYNTAXE

#include <openssl/dsa.h>

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

int DSA_sign(int type, const unsigned char *dgst, int len,
             unsigned char *sigret, unsigned int *siglen, DSA *dsa);
int DSA_sign_setup(DSA *dsa, BN_CTX *ctx, BIGNUM **kinvp, BIGNUM **rp);
int DSA_verify(int type, const unsigned char *dgst, int len,
               unsigned char *sigbuf, int siglen, DSA *dsa);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient plutôt utiliser EVP_PKEY_sign_init(3), EVP_PKEY_sign(3), EVP_PKEY_verify_init(3) et EVP_PKEY_verify(3).

DSA_sign() calcule une signature numérique sur le digest du message de len octets dgst en utilisant la clé privée dsa et place son encodage ASN.1 DER à sigret. La longueur de la signature est placée dans *siglen. sigret doit pointer vers des octets de mémoire à hauteur de DSA_size(dsa).

DSA_sign_setup() est défini uniquement pour la compatibilité binaire ascendante et ne doit pas être utilisé. Depuis OpenSSL 1.1.0, le type DSA est opaque et le résultat de DSA_sign_setup() ne peut pas être utilisé de toute façon : appeler cette fonction ne causera qu'une surcharge et n'affectera pas la pré-computation de la signature réelle.

DSA_verify() vérifie que la signature sigbuf de taille siglen correspond à un digest de message donné dgst de taille len. dsa est la clé publique du signataire.

Le paramètre type est ignoré.

Le générateur aléatoire doit être amorcé lorsque DSA_sign() (ou DSA_sign_setup()) est appelé. Si l'amorçage ou le réamorçage automatique du CSPRNG OpenSSL échoue en raison de circonstances externes (voir RAND(7)), l'opération échouera.

VALEURS DE RETOUR

DSA_sign() et DSA_sign_setup() retournent 1 en cas de succès, 0 en cas d'erreur. DSA_verify() retourne 1 pour une signature valide, 0 pour une signature incorrecte et -1 en cas d'erreur. Les codes d'erreur peuvent être obtenus via ERR_get_error(3).

CONFORME À

US Federal Information Processing Standard FIPS186-4 (Digital Signature Standard, DSS), ANSI X9.30

VOIR AUSSI

HISTORIQUE

Toutes ces fonctions ont été dépréciées dans OpenSSL 3.0.
