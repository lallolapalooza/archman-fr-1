DS-REPLCHECK(1) Manuel des commandes générales DS-REPLCHECK(1)

NOM

ds-replcheck

SYNOPSIS

ds-replcheck [-h] [-v] {online,offline,state} ...

DESCRIPTION

Outil de comparaison de réplication (v2.0). Ce script peut être utilisé pour comparer deux
répliques afin de vérifier si elles sont synchronisées.

OPTIONS

Sous-commandes

ds-replcheck online
Compare deux répliques en ligne pour détecter des différences
ds-replcheck offline
Compare deux fichiers LDIF de réplication pour détecter des différences (fichier LDIF généré par 'db2ldif -r')
ds-replcheck state
Obtient l'état général de la réplication entre deux répliques

    NAME

    ds-replcheck - check replication status of DS directory server

    SYNOPSIS

    ds-replcheck [options] [host[:port]]

    DESCRIPTION

    ds-replcheck checks the replication status of a Directory Server (DS) directory server. It connects to the specified server (or the default server if none is given) and queries the replication agreement status.

    OPTIONS

    -D binddn
    The DN to bind as. Defaults to the consumer DN.
    -w password -wfile file
    The password for the bind DN. If not specified, a random password will be generated and printed to stderr.
    -h host
    The host to connect to.
    -p port
    The port to connect to.
    -V
    Show version and exit.
    -v
    Be verbose.

    EXAMPLES

    
        ds-replcheck localhost:389
        ds-replcheck -D "cn=manager,cn=config" -w mypassword localhost:389

    EXIT STATUS

    Returns 0 on success, non-zero on failure.

    NOM

    ds-replcheck - vérifier l'état de réplication du serveur d'annuaire DS

    SYNOPSIS

    ds-replcheck [options] [hôte[:port]]

    DESCRIPTION

    ds-replcheck vérifie l'état de réplication d'un serveur d'annuaire (DS) du serveur d'annuaire. Il se connecte au serveur spécifié (ou au serveur par défaut si aucun n'est donné) et interroge l'état des accords de réplication.

    OPTIONS

    -D dn_liaison
    Le DN pour se lier. Par défaut, le DN du consommateur.
    -w motdepasse -wfile fichier
    Le mot de passe du DN de liaison. S'il n'est pas spécifié, un mot de passe aléatoire sera généré et imprimé sur stderr.
    -h hôte
    L'hôte auquel se connecter.
    -p port
    Le port auquel se connecter.
    -V
    Afficher la version et quitter.
    -v
    Être verbeux.

    EXEMPLES

    
        ds-replcheck localhost:389
        ds-replcheck -D "cn=manager,cn=config" -w monmotdepasse localhost:389

    STATUT DE SORTIE

    Retourne 0 en cas de succès, une valeur non nulle en cas d'échec.
