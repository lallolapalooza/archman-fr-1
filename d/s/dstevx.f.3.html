subroutine dstevx (character jobz, character range, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer

info)

DSTEVX calcule les valeurs propres et, de manière optionnelle, les vecteurs propres gauche et/ou droit pour les matrices

OTHER

But

: 
!>
!> DSTEVX calcule les valeurs propres sélectionnées et, de manière optionnelle,
!> les vecteurs propres d'une matrice tridiagonale symétrique réelle A. Les
!> valeurs propres et les vecteurs propres peuvent être sélectionnés en
!> spécifiant soit une plage de valeurs, soit une plage d'indices pour les
!> valeurs propres souhaitées.
!
>

Paramètre

s
JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : calcule uniquement les valeurs propres ;
!>          = 'V' : calcule les valeurs propres et les vecteurs propres.
!
>

RANG

E 
!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs propres de la IL-ième à la IU-ième seront trouvées.
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice. N >= 0.
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A.
!>          À la sortie, D peut être multiplié par un facteur constant choisi
!>          pour éviter le dépassement/sous-flux lors du calcul des valeurs
!>          propres.
!
>

E 
!>          E est un tableau DOUBLE PRECISION, dimension (max(1,N-1))
!>          À l'entrée, les (n-1) éléments sous-diagonaux de la matrice
!>          tridiagonale A dans les éléments 1 à N-1 de E.
!>          À la sortie, E peut être multiplié par un facteur constant choisi
!>          pour éviter le dépassement/sous-flux lors du calcul des valeurs
!>          propres.
!
>

V

L 
!>          VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle dans
!>          lequel rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!
>

V

U 
!>          VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle dans
!>          lequel rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!
>

I

L 
!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!
>

I

U 
!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!
>

ABSTO

L 
!>          ABSTOL est DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approchée est acceptée comme convergée
!>          lorsqu'il est déterminé qu'elle se situe dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur
!>          ou égal à zéro, alors EPS*|T| sera utilisé à la place,
!>          où |T| est la 1-norme de la matrice tridiagonale.
!>
!>          Les valeurs propres seront calculées avec la plus grande précision
!>          lorsque ABSTOL est défini à deux fois le seuil de sous-flux
!>          2*DLAMCH('S'), et non à zéro. Si cette routine retourne avec
!>          INFO>0, indiquant que certains vecteurs propres n'ont pas convergé,
!>          essayez de définir ABSTOL à 2*DLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!
>

M 
!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres
!>          sélectionnées dans l'ordre croissant.
!
>

Z 
!>          Z est un tableau DOUBLE PRECISION, dimension (LDZ, max(1,M) )
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, avec la i-ième
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne converge pas (INFO > 0), alors cette
!>          colonne de Z contient la dernière approximation du vecteur propre,
!>          et l'indice du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Remarque : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!
>

LD

Z 
!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (5*N)
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (5*N)
!
>

IFAI

L 
!>          IFAIL est un tableau INTEGER, dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, alors i vecteurs propres n'ont pas convergé.
!>                Leurs indices sont stockés dans le tableau IFAIL.
!
>
