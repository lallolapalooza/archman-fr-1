Documentation de la fonction/sous-programme

double precision function dsxt1 (integer ijob, double precision, dimension( * ) d1, integer n1, double precision, dimension( * ) d2, integer n2, double precision abstol, double precision ulp, double precision unfl)

DSXT1

But :

!>
!> DSXT1  calcule la différence entre un ensemble de valeurs propres.
!> Le résultat est retourné comme la valeur de la fonction.
!>
!> IJOB = 1 :   Calcule   max { min | D1(i)-D2(j) | }
!>                         i     j
!>
!> IJOB = 2 :   Calcule   max { min | D1(i)-D2(j) | /
!>                         i     j
!>                              ( ABSTOL + |D1(i)|*ULP ) }
!>

Paramètres

IJOB 
!>          IJOB est un entier
!>          Spécifie le type de tests à effectuer. (Voir ci-dessus.)
!>

D1

!>          D1 est un tableau DOUBLE PRECISION, dimension (N1)
!>          Le premier tableau.  D1 doit être dans l'ordre croissant, c'est-à-dire,
!>          D1(j) <= D1(j+1).
!>

N1

!>          N1 est un entier
!>          La longueur de D1.
!>

D2

!>          D2 est un tableau DOUBLE PRECISION, dimension (N2)
!>          Le second tableau.  D2 doit être dans l'ordre croissant, c'est-à-dire,
!>          D2(j) <= D2(j+1).
!>

N2

!>          N2 est un entier
!>          La longueur de D2.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRECISION
!>          La tolérance absolue, utilisée comme mesure de l'erreur.
!>

ULP

!>          ULP est DOUBLE PRECISION
!>          Précision machine.
!>

UNFL

!>          UNFL est DOUBLE PRECISION
!>          Le plus petit nombre positif dont l'inverse ne provoque pas de
!>          dépassement.
!>
