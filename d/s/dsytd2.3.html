subroutine dsytd2 (character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) tau, integer info)

DSYTD2 réduit une matrice symétrique réelle à sa forme tridiagonale symétrique réelle par une transformation d'orthogonalité par similarité (algorithme non bloqué).

Objectif :

!>
!> DSYTD2 réduit une matrice symétrique réelle A à la forme tridiagonale symétrique T
!> par une transformation d'orthogonalité par similarité : Q**T * A * Q = T.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée :
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de type DOUBLE PRECISION, de dimensions (LDA,N)
!>          À l'entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire N x N principale de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure triangulaire N x N principale de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>          À la sortie, si UPLO = 'U', la diagonale et la première superdiagonale
!>          de A sont écrasées par les éléments correspondants de la
!>          matrice tridiagonale T, et les éléments au-dessus de la première
!>          superdiagonale, avec le tableau TAU, représentent la matrice
!>          orthogonale Q comme un produit de réflecteurs élémentaires ; si UPLO
!>          = 'L', la diagonale et la première sous-diagonale de A sont écrasées
!>          par les éléments correspondants de la matrice tridiagonale T, et les
!>          éléments sous la première sous-diagonale, avec le tableau TAU,
!>          représentent la matrice orthogonale Q comme un produit de réflecteurs
!>          élémentaires. Voir Détails supplémentaires.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

D

!>          D est un tableau de type DOUBLE PRECISION, de dimensions (N)
!>          Les éléments diagonaux de la matrice tridiagonale T :
!>          D(i) = A(i,i).
!>

E

!>          E est un tableau de type DOUBLE PRECISION, de dimensions (N-1)
!>          Les éléments hors diagonale de la matrice tridiagonale T :
!>          E(i) = A(i,i+1) si UPLO = 'U', E(i) = A(i+1,i) si UPLO = 'L'.
!>

TAU

!>          TAU est un tableau de type DOUBLE PRECISION, de dimensions (N-1)
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

!>
!>  Si UPLO = 'U', la matrice Q est représentée comme un produit de réflecteurs
!>  élémentaires
!>
!>     Q = H(n-1) . . . H(2) H(1).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**T
!>
!>  où tau est un scalaire réel, et v est un vecteur réel avec
!>  v(i+1:n) = 0 et v(i) = 1 ; v(1:i-1) est stocké à la sortie dans
!>  A(1:i-1,i+1), et tau dans TAU(i).
!>
!>  Si UPLO = 'L', la matrice Q est représentée comme un produit de réflecteurs
!>  élémentaires
!>
!>     Q = H(1) H(2) . . . H(n-1).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**T
!>
!>  où tau est un scalaire réel, et v est un vecteur réel avec
!>  v(1:i) = 0 et v(i+1) = 1 ; v(i+2:n) est stocké à la sortie dans A(i+2:n,i),
!>  et tau dans TAU(i).
!>
!>  Le contenu de A à la sortie est illustré par les exemples suivants
!>  avec n = 5 :
!>
!>  si UPLO = 'U' :                       si UPLO = 'L' :
!>
!>    (  d   e   v2  v3  v4 )              (  d                  )
!>    (      d   e   v3  v4 )              (  e   d              )
!>    (          d   e   v4 )              (  v1  e   d          )
!>    (              d   e  )              (  v1  v2  e   d      )
!>    (                  d  )              (  v1  v2  v3  e   d  )
!>
!>  où d et e dénotent les éléments diagonaux et hors diagonale de T, et vi
!>  dénote un élément du vecteur définissant H(i).
!>
