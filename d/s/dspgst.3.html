DSPGST

Documentation de la fonction/sous-programme

sous-programme dspgst (integer itype, character uplo, integer n, double precision, dimension( * ) ap, double precision, dimension( * ) bp, integer info)

DSPGST

Objectif :

!>
!> DSPGST réduit un problème généralisé propre symétrique réel
!> à la forme standard, en utilisant un stockage compacté.
!>
!> Si ITYPE = 1, le problème est A*x = lambda*B*x,
!> et A est écrasé par inv(U**T)*A*inv(U) ou inv(L)*A*inv(L**T)
!>
!> Si ITYPE = 2 ou 3, le problème est A*B*x = lambda*x ou
!> B*A*x = lambda*x, et A est écrasé par U*A*U**T ou L**T*A*L.
!>
!> B doit avoir été préalablement factorisé en U**T*U ou L*L**T par DPPTRF.
!>

Paramètres

ITYPE 
!>          ITYPE est un entier (INTEGER)
!>          = 1 : calculer inv(U**T)*A*inv(U) ou inv(L)*A*inv(L**T) ;
!>          = 2 ou 3 : calculer U*A*U**T ou L**T*A*L.
!>

UPLO

!>          UPLO est une chaîne de caractères (CHARACTER*1)
!>          = 'U' : le triangle supérieur de A est stocké et B est factorisé en
!>                  U**T*U ;
!>          = 'L' : le triangle inférieur de A est stocké et B est factorisé en
!>                  L*L**T.
!>

N

!>          N est un entier (INTEGER)
!>          L'ordre des matrices A et B. N >= 0.
!>

AP

!>          AP est un tableau de double précision (DOUBLE PRECISION), dimensionné (N*(N+1)/2)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice symétrique
!>          A, stocké de manière compactée dans un tableau linéaire. La j-ième colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>
!>          À la sortie, si INFO = 0, la matrice transformée, stockée dans le
!>          même format que A.
!>

BP

!>          BP est un tableau de double précision (DOUBLE PRECISION), dimensionné (N*(N+1)/2)
!>          Le facteur triangulaire de la factorisation de Cholesky de B,
!>          stocké dans le même format que A, tel que retourné par DPPTRF.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
