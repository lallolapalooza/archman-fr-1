sous-routine dspt01 (caractère uplo, entier n, double précision, dimension( * ) a, double précision, dimension( * ) afac, entier, dimension( * ) ipiv, double précision, dimension( ldc, * ) c, entier ldc, double précision, dimension( * ) rwork, double précision resid)

DSPT01

But :

!>
!> DSPT01 reconstruit une matrice symétrique indéfinie empaquetée A à partir de sa
!> factorisation bloc L*D*L' ou U*D*U' et calcule le résidu
!>      norme( C - A ) / ( N * norme(A) * EPS ),
!> où C est la matrice reconstruite et EPS est le epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (N*(N+1)/2)
!>          La matrice symétrique originale A, stockée comme une matrice
!>          triangulaire empaquetée.
!>

AFAC

!>          AFAC est un tableau DOUBLE PRECISION, dimension (N*(N+1)/2)
!>          La forme factorisée de la matrice A, stockée comme une matrice
!>          triangulaire empaquetée.  AFAC contient la matrice diagonale bloc D
!>          et les multiplicateurs utilisés pour obtenir le facteur L ou U à partir de la
!>          factorisation bloc L*D*L' ou U*D*U' telle que calculée par DSPTRF.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot de DSPTRF.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (LDC,N)
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C.  LDC >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Si UPLO = 'L', norme(L*D*L' - A) / ( N * norme(A) * EPS )
!>          Si UPLO = 'U', norme(U*D*U' - A) / ( N * norme(A) * EPS )
!>
