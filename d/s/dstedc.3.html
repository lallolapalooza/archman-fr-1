sous-routine dstedc (character compz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer

DSTED

C

But

: 
!>
!> DSTEDC calcule toutes les valeurs propres et, en option, les vecteurs
!> propres d'une matrice symétrique tridiagonale en utilisant la méthode
!> de la division et de la conquête. Les vecteurs propres d'une matrice
!> symétrique réelle pleine ou bande peuvent également être trouvés si
!> DSYTRD ou DSPTRD ou DSBTRD a été utilisé pour réduire cette matrice
!> à une forme tridiagonale.
!>
!
>

Paramètre

s
COMPZ 
!>          COMPZ est CHARACTER*1
!>          = 'N' :  Calcule uniquement les valeurs propres.
!>          = 'I' :  Calcule également les vecteurs propres de la matrice tridiagonale.
!>          = 'V' :  Calcule également les vecteurs propres de la matrice
!>                  symétrique dense d'origine. À l'entrée, Z contient la matrice
!>                  orthogonale utilisée pour réduire la matrice d'origine à
!>                  une forme tridiagonale.
!
>

N 
!>          N est INTEGER
!>          La dimension de la matrice symétrique tridiagonale.  N >= 0.
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les éléments diagonaux de la matrice tridiagonale.
!>          À la sortie, si INFO = 0, les valeurs propres dans l'ordre croissant.
!
>

E 
!>          E est un tableau DOUBLE PRECISION, dimension (N-1)
!>          À l'entrée, les éléments sous-diagonaux de la matrice tridiagonale.
!>          À la sortie, E a été détruit.
!
>

Z 
!>          Z est un tableau DOUBLE PRECISION, dimension (LDZ,N)
!>          À l'entrée, si COMPZ = 'V', alors Z contient la matrice orthogonale
!>          utilisée dans la réduction à une forme tridiagonale.
!>          À la sortie, si INFO = 0, alors si COMPZ = 'V', Z contient les
!>          vecteurs propres orthonormaux de la matrice symétrique d'origine,
!>          et si COMPZ = 'I', Z contient les vecteurs propres orthonormaux
!>          de la matrice symétrique tridiagonale.
!>          Si COMPZ = 'N', alors Z n'est pas référencé.
!
>

LD

Z 
!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1.
!>          Si des vecteurs propres sont souhaités, alors LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si COMPZ = 'N' ou N <= 1, alors LWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1, alors LWORK doit être au moins
!>                         ( 1 + 3*N + 2*N*lg N + 4*N**2 ),
!>                         où lg( N ) = plus petit entier k tel
!>                         que 2**k >= N.
!>          Si COMPZ = 'I' et N > 1, alors LWORK doit être au moins
!>                         ( 1 + 4*N + N**2 ).
!>          Notez que pour COMPZ = 'I' ou 'V', si N est inférieur ou
!>          égal à la taille minimale de division, généralement 25, alors LWORK
!>          n'a besoin que d'être max(1,2*(N-1)).
!>
!>          Si LWORK = -1, alors une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) renvoie le LIWORK optimal.
!
>

LIWOR

K 
!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si COMPZ = 'N' ou N <= 1, alors LIWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1, alors LIWORK doit être au moins
!>                         ( 6 + 6*N + 5*N*lg N ).
!>          Si COMPZ = 'I' et N > 1, alors LIWORK doit être au moins
!>                         ( 3 + 5*N ).
!>          Notez que pour COMPZ = 'I' ou 'V', si N est inférieur ou
!>          égal à la taille minimale de division, généralement 25, alors LIWORK
!>          n'a besoin que d'être 1.
!>
!>          Si LIWORK = -1, alors une interrogation d'espace de travail est supposée ; la
!>          routine calcule uniquement la taille optimale du tableau IWORK,
!>          renvoie cette valeur comme première entrée du tableau IWORK, et
!>          aucun message d'erreur lié à LIWORK n'est émis par XERBLA.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 :  L'algorithme n'a pas réussi à calculer une valeur propre pendant
!>                le traitement de la sous-matrice située dans les lignes et colonnes
!>                INFO/(N+1) à mod(INFO,N+1).
!
>
