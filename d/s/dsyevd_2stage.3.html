sous-routine dsyevd_2stage (character jobz, character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) w, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer

DSYEVD_2STAGE calcule les valeurs propres et, optionnellement, les vecteurs propres gauche et/ou droit pour les matrices

SY

But

: 
!>
!> DSYEVD_2STAGE calcule toutes les valeurs propres et, optionnellement, les vecteurs propres d'une
!> matrice symétrique réelle A en utilisant la technique à 2 étapes pour
!> la réduction en tridiagonale. Si des vecteurs propres sont souhaités, elle utilise un
!> algorithme de type diviser pour régner.
!>
!
>

Paramètre

s
JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' :  Calcule les valeurs propres uniquement ;
!>          = 'V' :  Calcule les valeurs propres et les vecteurs propres.
!>                   Non disponible dans cette version.
!
>

UPL

O 
!>          UPLO est CHARACTER*1
!>          = 'U' :  Le triangle supérieur de A est stocké ;
!>          = 'L' :  Le triangle inférieur de A est stocké.
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!
>

A 
!>          A est un tableau DOUBLE PRECISION, dimension (LDA, N)
!>          À l'entrée, la matrice symétrique A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N par N principale de A contient la
!>          partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N par N principale de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          À la sortie, si JOBZ = 'V', alors si INFO = 0, A contient les
!>          vecteurs propres orthonormaux de la matrice A.
!>          Si JOBZ = 'N', alors à la sortie le triangle inférieur (si UPLO='L')
!>          ou le triangle supérieur (si UPLO='U') de A, y compris la
!>          diagonale, est détruit.
!
>

LDA !> LDA est INTEGER !> La dimension principale du tableau

A. LDA >= max(1,N). !> W 
!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!
>

WO

RK 
!>          WORK est un tableau DOUBLE PRECISION,
!>                                         dimension (LWORK)
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si N <= 1,               LWORK doit être au moins 1.
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, dimension) où
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 2*N+1
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 2*N+1
!>                                   où KD est la taille de bloc de la réduction,
!>                                   FACTOPTNB est le bloc utilisé par l'algorithme QR ou LQ,
!>                                   généralement FACTOPTNB=128 est un bon choix
!>                                   NTHREADS est le nombre de fils d'exécution utilisé lorsque
!>                                   la compilation openMP est activée, sinon =1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être au moins
!>                                                1 + 6*N + 2*N**2.
!>
!>          Si LWORK = -1, alors une interrogation d'espace de travail est supposée ; la routine
!>          ne calcule que les tailles optimales des tableaux WORK et IWORK
!>          renvoie ces valeurs comme les premières entrées des tableaux WORK
!>          et IWORK, et aucun message d'erreur lié à LWORK ou
!>          LIWORK n'est émis par
XERBLA. !>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) renvoie le LIWORK optimal.
!
>

LIWOR

K 
!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si N <= 1,                LIWORK doit être au moins 1.
!>          Si JOBZ  = 'N' et N > 1, LIWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK doit être au moins 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une interrogation d'espace de travail est supposée ; la
!>          routine ne calcule que les tailles optimales des tableaux WORK et
!>          IWORK, renvoie ces valeurs comme les premières entrées des
!>          tableaux WORK et IWORK, et aucun message d'erreur lié à
!>          LWORK ou LIWORK n'est émis par XERBLA.
!>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  si INFO = i et JOBZ = 'N', alors l'algorithme a échoué
!>                à converger ; i éléments hors diagonale d'une forme
!>                tridiagonale intermédiaire n'ont pas convergé vers zéro ;
!>                si INFO = i et JOBZ = 'V', alors l'algorithme a échoué
!>                à calculer une valeur propre tout en travaillant sur la sous-matrice
!>                située dans les lignes et colonnes INFO/(N+1) à
!>                mod(INFO,N+1).
!
>
