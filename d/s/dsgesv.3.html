DSGESV calcule la solution du système d'équations linéaires A * X = B pour les matrices GE (précision mixte avec raffinement itératif)

Documentation de la fonction/sous-routine

sous-routine dsgesv (integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( n, * ) work, real, dimension( * ) swork, integer iter, integer info)

DSGESV calcule la solution du système d'équations linéaires A * X = B pour les matrices GE (précision mixte avec raffinement itératif)

Objectif :

!>
!> DSGESV calcule la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice N-par-N et X et B sont des matrices N-par-NRHS.
!>
!> DSGESV tente d'abord de factoriser la matrice en SIMPLE PRÉCISION
!> et utilise cette factorisation dans une procédure de raffinement itératif
!> pour produire une solution avec une qualité d'erreur arrière normée en
!> DOUBLE PRÉCISION (voir ci-dessous). Si l'approche échoue, la méthode passe
!> à une factorisation et une résolution en DOUBLE PRÉCISION.
!>
!> Le raffinement itératif ne sera pas une stratégie gagnante si
!> le rapport performance SIMPLE PRÉCISION sur performance DOUBLE PRÉCISION
!> est trop faible. Une stratégie raisonnable devrait prendre en compte
!> le nombre de membres de droite et la taille de la matrice.
!> Cela pourrait être fait avec un appel à ILAENV à l'avenir. Jusqu'à présent, nous
!> essayons toujours le raffinement itératif.
!>
!> Le processus de raffinement itératif est arrêté si
!>     ITER > ITERMAX
!> ou pour tous les RHS nous avons :
!>     RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX
!> où
!>     o ITER est le numéro de l'itération courante dans le processus
!>       de raffinement itératif
!>     o RNRM est la norme infinie du résidu
!>     o XNRM est la norme infinie de la solution
!>     o ANRM est la norme d'opérateur infinie de la matrice A
!>     o EPS est l'epsilon machine retourné par DLAMCH('Epsilon')
!> Les valeurs ITERMAX et BWDMAX sont fixées à 30 et 1.0D+00
!> respectivement.
!>

Paramètres

N 
!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau DOUBLE PRÉCISION,
!>          dimension (LDA,N)
!>          À l'entrée, la matrice de coefficients A N-par-N.
!>          À la sortie, si le raffinement itératif a été utilisé avec succès
!>          (INFO = 0 et ITER >= 0, voir la description ci-dessous), alors A est
!>          inchangée, si la factorisation en double précision a été utilisée
!>          (INFO = 0 et ITER < 0, voir la description ci-dessous), alors le
!>          tableau A contient les facteurs L et U de la factorisation
!>          A = P*L*U ; les éléments de diagonale unitaires de L ne sont pas stockés.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot qui définissent la matrice de permutation P ;
!>          la ligne i de la matrice a été échangée avec la ligne IPIV(i).
!>          Correspond soit à la factorisation en simple précision
!>          (si INFO = 0 et ITER >= 0) soit à la factorisation en double précision
!>          (si INFO = 0 et ITER < 0).
!>

B

!>          B est un tableau DOUBLE PRÉCISION, dimension (LDB,NRHS)
!>          La matrice B des membres de droite N-par-NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau DOUBLE PRÉCISION, dimension (LDX,NRHS)
!>          Si INFO = 0, la matrice solution X N-par-NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

WORK

!>          WORK est un tableau DOUBLE PRÉCISION, dimension (N,NRHS)
!>          Ce tableau est utilisé pour contenir les vecteurs résiduels.
!>

SWORK

!>          SWORK est un tableau REAL, dimension (N*(N+NRHS))
!>          Ce tableau est utilisé pour utiliser la matrice en simple précision et les
!>          membres de droite ou les solutions en simple précision.
!>

ITER

!>          ITER est INTEGER
!>          < 0 : le raffinement itératif a échoué, la factorisation en
!>               double précision a été effectuée
!>               -1 : la routine est revenue à la précision complète pour
!>                    des raisons d'implémentation ou spécifiques à la machine
!>               -2 : la réduction de la précision a provoqué un débordement,
!>                    la routine est revenue à la précision complète
!>               -3 : échec de SGETRF
!>               -31: arrêt du raffinement itératif après la 30ème
!>                    itérations
!>          > 0 : le raffinement itératif a été utilisé avec succès.
!>               Retourne le nombre d'itérations
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, U(i,i) calculé en DOUBLE PRÉCISION est
!>                exactement zéro. La factorisation a été complétée,
!>                mais le facteur U est exactement singulier, donc la solution
!>                n'a pas pu être calculée.
!>
