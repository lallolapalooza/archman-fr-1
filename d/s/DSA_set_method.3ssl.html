DSA_set_method(3ssl)

Paquet: openssl

Licences: Apache-2.0

DSA_SET_METHOD(3ssl) OpenSSL DSA_SET_METHOD(3ssl)

NOM

DSA_set_default_method, DSA_get_default_method, DSA_set_method, DSA_new_method, DSA_OpenSSL - sélectionner une méthode DSA

SYNOPSIS

#include <openssl/dsa.h>

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

void DSA_set_default_method(const DSA_METHOD *meth);
const DSA_METHOD *DSA_get_default_method(void);
int DSA_set_method(DSA *dsa, const DSA_METHOD *meth);
DSA *DSA_new_method(ENGINE *engine);
const DSA_METHOD *DSA_OpenSSL(void);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications doivent utiliser des fournisseurs à la place des remplacements de méthodes.

Une DSA_METHOD spécifie les fonctions qu'OpenSSL utilise pour les opérations DSA. En modifiant la méthode, des implémentations alternatives telles que des accélérateurs matériels peuvent être utilisées. IMPORTANT : Voir la section NOTES pour des informations importantes sur la façon dont ces fonctions d'API DSA sont affectées par l'utilisation des appels d'API ENGINE.

Initialement, la DSA_METHOD par défaut est l'implémentation interne d'OpenSSL, telle que retournée par DSA_OpenSSL().

DSA_set_default_method() fait de meth la méthode par défaut pour toutes les structures DSA créées ultérieurement. NB : Ce n'est vrai que tant qu'aucun ENGINE n'a été défini par défaut pour DSA, donc cette fonction n'est plus recommandée. Cette fonction n'est pas thread-safe et ne doit pas être appelée en même temps que d'autres fonctions OpenSSL.

DSA_get_default_method() renvoie un pointeur vers la DSA_METHOD par défaut actuelle. Cependant, la signification de ce résultat dépend de l'utilisation ou non de l'API ENGINE, donc cette fonction n'est plus recommandée.

DSA_set_method() sélectionne meth pour effectuer toutes les opérations utilisant la clé dsa. Cela remplacera la DSA_METHOD utilisée par la clé DSA et si la méthode précédente était fournie par un ENGINE, le handle vers cet ENGINE sera libéré lors du changement. Il est possible d'avoir des clés DSA qui ne fonctionnent qu'avec certaines implémentations de DSA_METHOD (par exemple, d'un module ENGINE qui prend en charge les clés protégées par matériel embarqué), et dans de tels cas, tenter de modifier la DSA_METHOD pour la clé peut avoir des résultats inattendus. Voir DSA_meth_new(3) pour des informations sur la construction d'objets DSA_METHOD personnalisés ;

DSA_new_method() alloue et initialise une structure DSA de sorte que engine sera utilisé pour les opérations DSA. Si engine est NULL, l'engine par défaut pour les opérations DSA est utilisé, et si aucun ENGINE par défaut n'est défini, la DSA_METHOD contrôlée par DSA_set_default_method() est utilisée.

VALEURS DE RETOUR

DSA_OpenSSL() et DSA_get_default_method() renvoient des pointeurs vers les DSA_METHODs respectifs.

DSA_set_default_method() ne renvoie aucune valeur.

DSA_set_method() renvoie une valeur non nulle si meth fourni a été défini avec succès comme méthode pour dsa (y compris le déchargement du handle ENGINE si la méthode précédente était fournie par un ENGINE).

DSA_new_method() renvoie NULL et définit un code d'erreur qui peut être obtenu par ERR_get_error(3) si l'allocation échoue. Sinon, il renvoie un pointeur vers la structure nouvellement allouée.

VOIR AUSSI

DSA_new(3), DSA_new(3), DSA_meth_new(3)

HISTORIQUE

Toutes ces fonctions ont été dépréciées dans OpenSSL 3.0.
