Documentation de la fonction/sous-programme

double precision function dsdot (integer n, real, dimension(*) sx, integer incx, real, dimension(*) sy, integer incy)

DSDOT

Objectif :

!>
!> Calcule le produit scalaire de deux vecteurs avec accumulation
!> et résultat en précision étendue.
!>
!> Retourne le produit scalaire D.P. accumulé en D.P., pour les
!> vecteurs S.P. SX et SY.
!> DSDOT = somme pour I = 0 à N-1 de  SX(LX+I*INCX) * SY(LY+I*INCY),
!> où LX = 1 si INCX .GE. 0, sinon LX = 1+(1-N)*INCX, et LY est
!> défini de manière similaire en utilisant INCY.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

SX

!>          SX est un tableau réel (REAL array), dimension(N)
!>         vecteur en précision simple avec N éléments
!>

INCX

!>          INCX est un entier (INTEGER)
!>          pas de stockage entre les éléments de SX
!>

SY

!>          SY est un tableau réel (REAL array), dimension(N)
!>         vecteur en précision simple avec N éléments
!>

INCY

!>          INCY est un entier (INTEGER)
!>         pas de stockage entre les éléments de SY
!>

Retourne

DSDOT 
!>          DSDOT est une double précision (DOUBLE PRECISION)
!>         DSDOT  produit scalaire en double précision (zéro si N.LE.0)
!>
