NOM

dselect.cfg - fichier de configuration de dselect

DESCRIPTION

Ce fichier contient les options par défaut pour dselect. Chaque ligne contient une seule option qui est exactement la même qu'une option de ligne de commande normale pour dselect, à l'exception des tirets précédant les options qui ne sont pas utilisés ici. Les guillemets entourant les valeurs des options sont supprimés. Les commentaires sont autorisés en commençant une ligne par un signe dièse (‘#’).

FICHIERS

/etc/dpkg/dselect.cfg
