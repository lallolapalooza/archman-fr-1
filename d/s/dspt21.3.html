!> !> DSPT21 vérifie généralement une décomposition de la forme !> !> A = U S U**T !> !> où **T signifie transposée, A est symétrique (stockée au format compact), U !> est orthogonale, et S est diagonale (si KBAND=0) ou !> symétrique tridiagonale (si KBAND=1). Si ITYPE=1, alors U est représentée !> comme une matrice dense, sinon U est exprimée comme un produit de !> transformations de Householder, dont les vecteurs sont stockés dans le tableau !> et dont les constantes d'échelle sont dans nous utiliserons la !> lettre pour désigner le produit des transformations de Householder !> (qui devrait être égal à U). !> !> Plus précisément, si ITYPE=1, alors : !> !> RESULT(1) = | A - U S U**T | / ( |A| n ulp ) et !> RESULT(2) = | I - U U**T | / ( n ulp ) !> !> Si ITYPE=2, alors : !> !> RESULT(1) = | A - V S V**T | / ( |A| n ulp ) !> !> Si ITYPE=3, alors : !> !> RESULT(1) = | I - V U**T | / ( n ulp ) !> !> Le stockage compact signifie que, par exemple, si UPLO='U', les colonnes !> du triangle supérieur de A sont stockées les unes après les autres, de sorte !> que A(1,j+1) suit immédiatement A(j,j) dans le tableau AP. De même, si !> UPLO='L', les colonnes du triangle inférieur de A sont stockées les unes !> après les autres dans AP, de sorte que A(j+1,j+1) suit immédiatement A(n,j) !> dans le tableau AP. Cela signifie que A(i,j) est stockée dans : !> !> AP( i + j*(j-1)/2 ) si UPLO='U' !> !> AP( i + (2*n-j)*(j-1)/2 ) si UPLO='L' !> !> Le tableau VP entretient la même relation avec la matrice V que A avec !> AP. !> !> Pour ITYPE > 1, la transformation U est exprimée comme un produit !> de transformations de Householder : !> !> Si UPLO='U', alors V = H(n-1)...H(1), où !> !> H(j) = I - tau(j) v(j) v(j)**T !> !> et les premiers j-1 éléments de v(j) sont stockés dans V(1:j-1,j+1), !> (c'est-à-dire, VP( j*(j+1)/2 + 1 : j*(j+1)/2 + j-1 ) ), !> le j-ième élément est 1, et les n-j derniers éléments

sont 0. !> !> Si UPLO='L', alors V = H(1)...H(n-1), où !> !> H(j) = I - tau(j) v(j) v(j)**T !> !> et les j premiers éléments de v(j) sont 0, le (j+1)-ième est 1, et les !> éléments du (j+2)-ième au n-ième sont stockés dans V(j+2:n,j) (c'est-à-dire, !> dans VP( (2*n-j)*(j-1)/2 + j+2 : (2*n-j)*(j-1)/2 + n ) .) !>

!> RESULT(1) = | I - V U**T | / ( n ulp ) !>

!>          La bande de la matrice.  Elle ne peut être que zéro ou un.

A

P 
!>          AP est un tableau DOUBLE PRECISION, dimension (N*(N+1)/2)
!>          La matrice originale (non factorisée).  Elle est supposée
!>          symétrique, et contient les colonnes de seulement le triangle
!>          supérieur (UPLO='U') ou seulement le triangle inférieur (UPLO='L'),
!>          compactées les unes après les autres.
!>

D 
!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          La diagonale de la matrice (symétrique tri-) diagonale.
!
>

E 
!>          E est un tableau DOUBLE PRECISION, dimension (N-1)
!>          La sous-diagonale de la matrice (symétrique tri-) diagonale.
!>          E(1) est l'élément (1,2) et (2,1), E(2) est l'élément (2,3) et
!>          (3,2), etc.
!>          Non référencée si KBAND=0.
!>

U 
!>          U est un tableau DOUBLE PRECISION, dimension (LDU, N)
!>          Si ITYPE=1 ou 3, ceci contient la matrice orthogonale dans
!>          la décomposition, exprimée comme une matrice dense.  Si ITYPE=2,
!>          alors elle n'est pas référencée.
!
>

LD

U 
!>          LDU est INTEGER
!>          La dimension principale de U.  LDU doit être au moins N et
!>          au moins 1.
!
>

V

P 
!>          VP est un tableau DOUBLE PRECISION, dimension (N*(N+1)/2)
!>          Si ITYPE=2 ou 3, les colonnes de ce tableau contiennent les
!>          vecteurs de Householder utilisés pour décrire la matrice orthogonale
!>          dans la décomposition, comme décrit dans le but.
!>          *NOTE* Si ITYPE=2 ou 3, V est modifiée et restaurée.  La
!>          sous-diagonale (si UPLO='L') ou la sur-diagonale (si UPLO='U')
!>          est mise à un, puis réinitialisée à sa valeur originale, pendant
!>          le cours du calcul.
!>          Si ITYPE=1, alors elle n'est ni référencée ni modifiée.
!>

TA

U

!>          Si ITYPE < 2, alors TAU n'est pas référencée.
