Documentation de la fonction/sous-programme

sous-programme dsytrf_rk (caractere uplo, entier n, double precision, dimension( lda, * ) a, entier lda, double precision, dimension( * ) e, entier, dimension( * ) ipiv, double precision, dimension( * ) work, entier lwork, entier info)

DSYTRF_RK calcule la factorisation d'une matrice réelle symétrique indéfinie en utilisant la méthode de pivotement diagonal de Bunch-Kaufman bornée (rook) (algorithme bloc BLAS3).

Objectif :

!> DSYTRF_RK calcule la factorisation d'une matrice réelle symétrique A
!> en utilisant la méthode de pivotement diagonal de Bunch-Kaufman bornée (rook) :
!>
!>    A = P*U*D*(U**T)*(P**T) ou A = P*L*D*(L**T)*(P**T),
!>
!> où U (ou L) est une matrice triangulaire supérieure (ou inférieure) unitaire,
!> U**T (ou L**T) est la transposée de U (ou L), P est une matrice de permutation,
!> P**T est la transposée de P, et D est symétrique et bloc-diagonale avec
!> des blocs diagonaux de 1x1 et 2x2.
!>
!> C'est la version bloquée de l'algorithme, appelant BLAS de Niveau 3.
!> Pour plus d'informations, voir la section Détails supplémentaires.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure
!>          de la matrice symétrique A est stockée :
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A.
!>            Si UPLO = 'U' : la partie supérieure de N lignes sur N colonnes
!>            de A contient la partie triangulaire supérieure de la matrice A,
!>            et la partie strictement triangulaire inférieure de A n'est pas
!>            référencée.
!>
!>            Si UPLO = 'L' : la partie inférieure de N lignes sur N colonnes
!>            de A contient la partie triangulaire inférieure de la matrice A,
!>            et la partie strictement triangulaire supérieure de A n'est pas
!>            référencée.
!>
!>          À la sortie, contient :
!>            a) UNIQUEMENT les éléments diagonaux de la matrice symétrique
!>               bloc-diagonale D sur la diagonale de A, c'est-à-dire
!>               D(k,k) = A(k,k) ; (les éléments superdiagonaux (ou sous-diagonaux)
!>               de D sont stockés à la sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : facteur U dans la partie superdiagonale de A.
!>               Si UPLO = 'L' : facteur L dans la partie sous-diagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau DOUBLE PRECISION, de dimension (N)
!>          À la sortie, contient les éléments superdiagonaux (ou sous-diagonaux)
!>          de la matrice symétrique bloc-diagonale D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) est mis à 0 ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          NOTE : Pour un bloc diagonal 1x1 D(k), où
!>          1 <= k <= N, l'élément E(k) est mis à 0 dans les deux
!>          cas UPLO = 'U' ou UPLO = 'L'.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          IPIV décrit la matrice de permutation P dans la factorisation
!>          de la matrice A comme suit. La valeur absolue de IPIV(k)
!>          représente l'indice de la ligne et de la colonne qui ont été
!>          échangées avec la k-ième ligne et colonne. La valeur de UPLO
!>          décrit l'ordre dans lequel les échanges ont été appliqués.
!>          De plus, le signe de IPIV représente la structure de bloc
!>          de la matrice symétrique bloc-diagonale D avec des blocs
!>          diagonaux de 1x1 ou 2x2 qui correspondent à 1 ou 2 échanges
!>          à chaque étape de factorisation. Pour plus d'informations, voir la
!>          section Détails supplémentaires.
!>
!>          Si UPLO = 'U',
!>          ( dans l'ordre de factorisation, k décroît de N à 1 ) :
!>            a) Une seule entrée positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la matrice A(1:N,1:N) ;
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k-1) < 0 signifie :
!>               D(k-1:k,k-1:k) est un bloc diagonal 2x2.
!>               (NOTE : les entrées négatives dans IPIV n'apparaissent QUE par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la matrice A(1:N,1:N).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k-1) != k-1, les lignes et colonnes
!>                  k-1 et -IPIV(k-1) ont été échangées
!>                  dans la matrice A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, aucun échange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), toujours ABS( IPIV(k) ) <= k.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE en sortie.
!>
!>          Si UPLO = 'L',
!>          ( dans l'ordre de factorisation, k augmente de 1 à N ) :
!>            a) Une seule entrée positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la matrice A(1:N,1:N).
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k+1) < 0 signifie :
!>               D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>               (NOTE : les entrées négatives dans IPIV n'apparaissent QUE par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la matrice A(1:N,1:N).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k+1) != k+1, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées (attention, traduction originale incorrecte, devrait être k et -IPIV(k) pour le 1er cas, et k+1 et -IPIV(k+1) pour le 2ème cas, ou une autre formulation si c'est une erreur dans le texte source)
!>                  dans la matrice A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, aucun échange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), toujours ABS( IPIV(k) ) >= k.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE en sortie.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (MAX(1,LWORK)).
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur de WORK.  LWORK >= 1.  Pour de meilleures performances
!>          LWORK >= N*NB, où NB est la taille de bloc retournée
!>          par ILAENV.
!>
!>          Si LWORK = -1, alors une requête de mémoire vive est supposée ;
!>          la routine calcule seulement la taille optimale du tableau
!>          WORK, la retourne comme première entrée du tableau
!>          WORK, et aucun message d'erreur lié à LWORK n'est émis
!>          par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>
!>          < 0 : Si INFO = -k, le k-ième argument avait une valeur illégale
!>
!>          > 0 : Si INFO = k, la matrice A est singulière, car :
!>                 Si UPLO = 'U' : la colonne k dans la partie
!>                 triangulaire supérieure de A contient que des zéros.
!>                 Si UPLO = 'L' : la colonne k dans la partie
!>                 triangulaire inférieure de A contient que des zéros.
!>
!>               Par conséquent D(k,k) est exactement zéro, et les éléments
!>               superdiagonaux de la colonne k de U (ou les éléments
!>               sous-diagonaux de la colonne k de L) sont tous des zéros.
!>               La factorisation a été complétée, mais le bloc

NAME

dsytrf_rk.f — real double precision symmetric indefinite factorization routines using rook's ;

SYNOPSIS

 subroutine dsytrf_rk(UPLO, N, A, LDA, IPIV, WORK, LWORK, INFO)
  character UPLO
  integer N
  double precision A(LDA,*)
  integer IPIV(*)
  double precision WORK(*)
  integer LWORK
  integer INFO

Function/Subroutine Documentation

!> \brief \parblock
!>  dsytrf_rk computes the factorization of a real symmetric indefinite
!>  matrix A using the rook's algorithm with partial pivoting.
!>
!>  The factorization is of the form
!>
!>  A = P * U * T * U**T * P**T  or  A = P * L * T * L**T * P**T
!>
!>  where U is a block upper triangular matrix with block diagonal form
!>  where the diagonal blocks are unit 1-by-1 or 2-by-2 matrices.
!>  T is a block diagonal matrix in which the diagonal blocks are
!>  either unit 1-by-1 or 2-by-2 matrices.
!>  L is a block lower triangular matrix and P is a permutation matrix.
!>  The block size of U and L is at most 2.
!>
!> \parblock
!>
!>  In the case of A = P * L * T * L**T * P**T, L is represented implicitly
!>  by entries in the lower triangle of A.
!>  T is represented by the diagonal entries of A.
!>
!> \parblock
!>  The factorization is computed by the routine dsytrf.
!>
!> \parblock
!>  Arguments:
!>
!>  UPLO: CHARACTER*1. Must be 'U' or 'L'.
!>         On entry, UPLO specifies whether the upper or lower
!>        triangular part of the symmetric matrix A is to be
!>        referenced:
!>         UPLO = 'U' => Uses upper triangular part
!>         UPLO = 'L' => Uses lower triangular part
!>
!>  N: INTEGER.
!>     On entry, N is the order of the matrix A. N >= 0.
!>
!>  A: DOUBLE PRECISION array, dimension (LDA, N).
!>     On entry, the symmetric matrix A.
!>     On exit, if INFO = 0, the details of the factorization are
!>     stored in the upper triangular part of A.
!>
!>  LDA: INTEGER.
!>      On entry, LDA is the leading dimension of the array A.
!>      LDA >= max(1, N).
!>
!>  IPIV: INTEGER array, dimension (N).
!>       On exit, the pivot indices, stored in two parts. The length
!>       of the attached array is N.
!>
!>  WORK: DOUBLE PRECISION array, dimension (LWORK).
!>       On exit, WORK(1) contains the minimum LWORK.
!>
!>  LWORK: INTEGER.
!>        On entry, the dimension of the array WORK. LWORK >= 1.
!>        Choose LWORK = N + NB*NB if NB > 1.
!>
!>  INFO: INTEGER.
!>       On exit: INFO = 0 if the factorization has completed
!>                successfully.
!>                INFO > 0 if INFO = k, dsqrtfa: (k, k) block
!>                of T is not positive definite. The factorization
!>                has been completed, but it is not valid.
!>                INFO < 0 if INFO = -k, then the k-th argument
!>                had an illegal value.
!>
!>  Details:
!>     The unique factorization is obtained using rook's algorithm with
!>     partial pivoting, which computes an ULU decomposition of A.
!>     The implementation details are based on the work of
!>     Du Croz, Hammarling, Nicholson and Rees.
!>
!>     The factorization is of the form
!>
!>     A = P*U*T*U**T*P**T
!>
!>     where U is block upper triangular with diagonal blocks of order 1 or 2,
!>     and T is a block diagonal matrix with diagonal blocks of order 1 or 2.
!>
!>     If UPLO = 'U', then A = P*U*T*U**T*P**T, where U is block upper
!>     triangular and T is block diagonal.
!>
!>     If UPLO = 'L', then A = P*L*T*L**T*P**T, where L is block lower
!>     triangular and T is block diagonal.
!>
!>     The diagonal matrix T is represented by storing its diagonal blocks
!>     in the array A. The multipliers used to form U or L are stored
!>     in the other triangle of A.
!>
!>     The permutation P is given by the array IPIV.
!>
!>     NOTE: The factorization completes even if T is not positive definite.
!>           The user must check INFO(K) for K > 0.
!>           If INFO(K) > 0, then the K-th diagonal block of T is not
!>           positive definite. In this case, the diagonal matrix D is
!>           exactly singular, and division by zero will occur if
!>           it is used to solve a system of equations.
!>
!>           NOTE: INFO only stores the first occurrence of
!>           a singularity, any subsequent occurrence of singularity
!>           is not stored in INFO even though the factorization
!>           always completes.
!>
