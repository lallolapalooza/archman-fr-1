DSA_do_sign(3ssl)

Paquet: openssl

DSA_DO_SIGN(3ssl) OpenSSL DSA_DO_SIGN(3ssl)

NOM

DSA_do_sign, DSA_do_verify - opérations de signature DSA brutes

SYNTAXE

#include <openssl/dsa.h>

Les fonctions suivantes sont obsolètes depuis OpenSSL 3.0 et peuvent être complètement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7).

DSA_SIG *DSA_do_sign(const unsigned char *dgst, int dlen, DSA *dsa);
int DSA_do_verify(const unsigned char *dgst, int dgst_len,
                  DSA_SIG *sig, DSA *dsa);

DESCRIPTION

Toutes les fonctions décrites dans cette page sont obsolètes. Les applications devraient utiliser à la place EVP_PKEY_sign_init(3), EVP_PKEY_sign(3), EVP_PKEY_verify_init(3) et EVP_PKEY_verify(3).

DSA_do_sign() calcule une signature numérique sur le condensat de message de len octets dgst en utilisant la clé privée dsa et la retourne dans une structure DSA_SIG nouvellement allouée.

DSA_sign_setup(3) peut être utilisé pour pré-calculer une partie de l'opération de signature au cas où la génération de signature serait critique en termes de temps.

DSA_do_verify() vérifie que la signature sig correspond à un condensat de message donné dgst de taille len. dsa est la clé publique du signataire.

VALEURS DE RETOUR

DSA_do_sign() retourne la signature, NULL en cas d'erreur. DSA_do_verify() retourne 1 pour une signature valide, 0 pour une signature incorrecte et -1 en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

DSA_new(3), ERR_get_error(3), RAND_bytes(3), DSA_SIG_new(3), DSA_sign(3)

HISTORIQUE

Toutes ces fonctions ont été obsolètes dans OpenSSL 3.0.
