DSYEVR_2STAGE calcule les valeurs propres et, en option, les vecteurs propres gauche et/ou droit pour les matrices SY

But :

!>
!> DSYEVR_2STAGE calcule les valeurs propres sélectionnées et, en option, les vecteurs propres
!> d'une matrice symétrique réelle A en utilisant la technique en 2 étapes pour
!> la réduction en tridiagonale. Les valeurs propres et les vecteurs propres peuvent être
!> sélectionnées en spécifiant soit un intervalle de valeurs soit un intervalle
!> d'indices pour les valeurs propres souhaitées.
!>
!> DSYEVR_2STAGE réduit d'abord la matrice A en forme tridiagonale T par un appel
!> à DSYTRD. Ensuite, chaque fois que c'est possible, DSYEVR_2STAGE appelle DSTEMR pour calculer
!> le spectre propre en utilisant les représentations robustes relatives. DSTEMR
!> calcule les valeurs propres par l'algorithme dqds, tandis que les vecteurs
!> propres orthogonaux sont calculés à partir de diverses représentations L D L^T
!> (également connues sous le nom de représentations robustes relatives). L'orthogonalisation
!> de Gram-Schmidt est évitée autant que possible. Plus précisément,
!> les différentes étapes de l'algorithme sont les suivantes.
!>
!> Pour chaque bloc (sous-matrice) non réduit de T,
!>    (a) Calculer T - sigma I = L D L^T, de sorte que L et D
!>        définissent toutes les valeurs propres voulues avec une grande précision relative.
!>        Cela signifie que de petites variations relatives des entrées de D et L
!>        n'entraînent que de petites variations relatives des valeurs propres et
!>        des vecteurs propres. La représentation standard (non factorisée) de la
!>        matrice tridiagonale T n'a pas cette propriété en général.
!>    (b) Calculer les valeurs propres avec une précision appropriée.
!>        Si les vecteurs propres sont souhaités, l'algorithme n'atteint la pleine
!>        précision des valeurs propres calculées qu'à l'instant précédant
!>        le calcul des vecteurs correspondants, voir les étapes c) et d).
!>    (c) Pour chaque groupe de valeurs propres proches, sélectionner un nouveau
!>        décalage (shift) proche du groupe, trouver une nouvelle factorisation, et affiner
!>        les valeurs propres décalées avec une précision appropriée.
!>    (d) Pour chaque valeur propre avec une séparation relative suffisante, calculer
!>        le vecteur propre correspondant en formant une factorisation tordue à révélation de rang.
!>        Retourner à (c) pour tous les groupes restants.
!>
!> La précision souhaitée de la sortie peut être spécifiée par le paramètre
!> d'entrée ABSTOL.
!>
!> Pour plus de détails, voir la documentation de DSTEMR et :
!> - Inderjit S. Dhillon et Beresford N. Parlett :
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, août 2004.
!> - Inderjit Dhillon et Beresford Parlett : SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. Aussi LAPACK Working Note 154.
!> - Inderjit Dhillon : ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mai 1997.
!>
!>
!> Remarque 1 : DSYEVR_2STAGE appelle DSTEMR lorsque le spectre complet est demandé
!> sur les machines qui se conforment à la norme de virgule flottante ieee-754.
!> DSYEVR_2STAGE appelle DSTEBZ et SSTEIN sur les machines non-ieee et
!> lorsque des demandes de spectre partiel sont faites.
!>
!> L'exécution normale de DSTEMR peut créer des NaN et des infinis et
!> peut donc s'interrompre en raison d'une exception de virgule flottante dans les environnements
!> qui ne gèrent pas les NaN et les infinis de la manière par défaut de la norme ieee.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : calculer uniquement les valeurs propres ;
!>          = 'V' : calculer les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs propres de la IL-ième à la IU-ième seront trouvées.
!>          Pour RANGE = 'V' ou 'I' et IU - IL < N - 1, DSTEBZ et
!>          DSTEIN sont appelés
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA, N)
!>          À l'entrée, la matrice symétrique A. Si UPLO = 'U', la
!>          partie triangulaire supérieure N par N de A contient la
!>          partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure N par N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          À la sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

VL

!>          VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle dans
!>          lequel rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle dans
!>          lequel rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approchée est acceptée comme convergée
!>          lorsqu'il est déterminé qu'elle se situe dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la 1-norme de la matrice tridiagonale obtenue
!>          en réduisant A en forme tridiagonale.
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si une grande précision relative est importante, définissez ABSTOL à
!>          DLAMCH( 'Safe minimum' ). Le faire garantira que les
!>          valeurs propres sont calculées avec une grande précision relative lorsque
!>          c'est possible dans les futures versions. Le code actuel ne faites about high relative accuracy, but
!>          future releases will. See J. Barlow and J. Demmel,
!>          , LAPACK Working Note #7, for a discussion
!>          of which matrices define their eigenvalues to high relative
!>          accuracy.
!>

M

!>          M is INTEGER
!>          The total number of eigenvalues found.  0 <= M <= N.
!>          If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.
!>

W

!>          W is DOUBLE PRECISION array, dimension (N)
!>          The first M elements contain the selected eigenvalues in
!>          ascending order.
!>

Z

!>          Z is DOUBLE PRECISION array, dimension (LDZ, max(1,M))
!>          If JOBZ = 'V', then if INFO = 0, the first M columns of Z
!>          contain the orthonormal eigenvectors of the matrix A
!>          corresponding to the selected eigenvalues, with the i-th
!>          column of Z holding the eigenvector associated with W(i).
!>          If JOBZ = 'N', then Z is not referenced.
!>          Note: the user must ensure that at least max(1,M) columns are
!>          supplied in the array Z; if RANGE = 'V', the exact value of M
!>          is not known in advance and an upper bound must be used.
!>          Supplying N columns is always safe.
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of the array Z.  LDZ >= 1, and if
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
!>          The support of the eigenvectors in Z, i.e., the indices
!>          indicating the nonzero elements in Z. The i-th eigenvector
!>          is nonzero only in elements ISUPPZ( 2*i-1 ) through
!>          ISUPPZ( 2*i ). This is an output of DSTEMR (tridiagonal
!>          matrix). The support of the eigenvectors of A is typically
!>          1:N because of the orthogonal transformations applied by DORMTR.
!>          Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If N <= 1,               LWORK must be at least 1.
!>          If JOBZ = 'N' and N > 1, LWORK must be queried.
!>                                   LWORK = MAX(1, 26*N, dimension) where
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 5*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 5*N
!>                                   where KD is the blocking size of the reduction,
!>                                   FACTOPTNB is the blocking used by the QR or LQ
!>                                   algorithm, usually FACTOPTNB=128 is a good choice
!>                                   NTHREADS is the number of threads used when
!>                                   openMP compilation is enabled, otherwise =1.
!>          If JOBZ = 'V' and N > 1, LWORK must be queried. Not yet available
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!>          On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.
!>          If N <= 1, LIWORK >= 1, else LIWORK >= 10*N.
!>
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal size of the IWORK array,
!>          returns this value as the first entry of the IWORK array, and
!>          no error message related to LIWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  Internal error
!>
