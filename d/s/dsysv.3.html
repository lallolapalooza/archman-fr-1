sous-routine dsysv (uplo, n, nrhs, a, lda, ipiv, b, ldb, work, lwork, info)
DSYSV calcule la solution du système d'équations linéaires A * X = B pour les matrices SY symétriques

Documentation de la fonction/sous-routine

sous-routine dsysv (caractère uplo, entier n, entier nrhs, double précision, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( * ) work, entier lwork, entier info)

DSYSV calcule la solution du système d'équations linéaires A * X = B pour les matrices symétriques SY

Objectif :

!>
!> DSYSV calcule la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice symétrique N x N et X et B sont des matrices N x NRHS.
!>
!> La méthode de pivotement diagonal est utilisée pour factoriser A en
!>    A = U * D * U**T,  si UPLO = 'U', ou
!>    A = L * D * L**T,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et triangulaires unitaires supérieures (inférieures), et D est symétrique et bloc-diagonale avec
!> des blocs diagonaux 1x1 et 2x2. La forme factorisée de A est alors
!> utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U':  La partie triangulaire supérieure de A est stockée ;
!>          = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau de DOUBLE PRÉCISION, de dimension (LDA,N)
!>          En entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire principale N x N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          inférieure triangulaire principale N x N de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          En sortie, si INFO = 0, la matrice bloc-diagonale D et les
!>          multiplicateurs utilisés pour obtenir le facteur U ou L à partir de
!>          la factorisation A = U*D*U**T ou A = L*D*L**T calculée par
!>          DSYTRF.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau de ENTIERS, de dimension (N)
!>          Détails des échanges et de la structure de bloc de D, tels que
!>          déterminés par DSYTRF.  Si IPIV(k) > 0, alors les lignes et colonnes
!>          k et IPIV(k) ont été échangées, et D(k,k) est un bloc diagonal 1x1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0,
!>          alors les lignes et colonnes k-1 et -IPIV(k) ont été échangées et
!>          D(k-1:k,k-1:k) est un bloc diagonal 2x2.  Si UPLO = 'L' et
!>          IPIV(k) = IPIV(k+1) < 0, alors les lignes et colonnes k+1 et
!>          -IPIV(k) ont été échangées et D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>

B

!>          B est un tableau de DOUBLE PRÉCISION, de dimension (LDB,NRHS)
!>          En entrée, la matrice membre de droite B de taille N x NRHS.
!>          En sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La longueur de WORK.  LWORK >= 1, et pour une performance optimale
!>          LWORK >= max(1,N*NB), où NB est la taille de bloc optimale pour
!>          DSYTRF.
!>          pour LWORK < N, TRS sera effectué avec BLAS de niveau 2
!>          pour LWORK >= N, TRS sera effectué avec BLAS de niveau 3
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) est exactement zéro.  La factorisation
!>               a été complétée, mais la matrice bloc-diagonale D est
!>               exactement singulière, donc la solution n'a pas pu être calculée.
!>
