DSA_new(3ssl)

DSA_NEW(3ssl) OpenSSL DSA_NEW(3ssl)

NOM

DSA_new, DSA_free - allouer et libérer des objets DSA

SYNTAXE

#include <openssl/dsa.h>

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

DSA* DSA_new(void);
void DSA_free(DSA *dsa);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient plutôt utiliser EVP_PKEY_new(3) et EVP_PKEY_free(3).

DSA_new() alloue et initialise une structure DSA. Elle est équivalente à l'appel de DSA_new_method(NULL).

DSA_free() libère la structure DSA et ses composants. Les valeurs sont effacées avant que la mémoire ne soit retournée au système. Si dsa est NULL, rien n'est fait.

VALEURS DE RETOUR

Si l'allocation échoue, DSA_new() retourne NULL et définit un code d'erreur qui peut être obtenu par ERR_get_error(3). Sinon, elle retourne un pointeur vers la structure nouvellement allouée.

DSA_free() ne retourne aucune valeur.

VOIR AUSSI

EVP_PKEY_new(3), EVP_PKEY_free(3), DSA_new(3), ERR_get_error(3), DSA_generate_parameters(3), DSA_generate_key(3)

HISTORIQUE

Toutes ces fonctions ont été dépréciées dans OpenSSL 3.0.
