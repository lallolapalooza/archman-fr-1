Documentation de la fonction/sous-routine

sous-routine dsysvx (character fact, character uplo, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

DSYSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices SY

But :

!>
!> DSYSVX utilise la factorisation par pivot diagonal pour calculer la
!> solution d'un système d'équations linéaires réelles A * X = B,
!> où A est une matrice symétrique N par N et X et B sont des matrices
!> N par NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation du conditionnement sont
!> également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la méthode de pivot diagonal est utilisée pour factoriser A.
!>    La forme de la factorisation est
!>       A = U * D * U**T,  si UPLO = 'U', ou
!>       A = L * D * L**T,  si UPLO = 'L',
!>    où U (ou L) est un produit de matrices de permutation et de matrices
!>    triangulaires supérieures (inférieures) unitaires, et D est symétrique et
!>    bloc-diagonale avec des blocs diagonaux de taille 1 par 1 et 2 par 2.
!>
!> 2. Si certains D(i,i)=0, de sorte que D est exactement singulière, la routine
!>    retourne avec INFO = i. Sinon, la forme factorisée de A est utilisée
!>    pour estimer le nombre de condition de la matrice A. Si le
!>    réciproque du nombre de condition est inférieur à la précision machine,
!>    INFO = N+1 est retourné comme avertissement, mais la routine continue
!>    tout de même pour résoudre X et calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la matrice solution
!>    calculée et calculer les bornes d'erreur et les estimations d'erreur arrière
!>    pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Indique si la forme factorisée de A a été
!>          fournée à l'entrée.
!>          = 'F' : À l'entrée, AF et IPIV contiennent la forme factorisée de
!>                  A. AF et IPIV ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AF et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          La matrice symétrique A. Si UPLO = 'U', la partie triangulaire
!>          supérieure principale N par N de A contient la partie triangulaire
!>          supérieure de la matrice A, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée. Si UPLO = 'L', la partie
!>          triangulaire inférieure principale N par N de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est un tableau DOUBLE PRECISION, dimension (LDAF,N)
!>          Si FACT = 'F', alors AF est un argument d'entrée et à l'entrée
!>          contient la matrice bloc-diagonale D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L à partir de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T telle que calculée par DSYTRF.
!>
!>          Si FACT = 'N', alors AF est un argument de sortie et à la sortie
!>          retourne la matrice bloc-diagonale D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L à partir de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T.
!>

LDAF

!>          LDAF est INTEGER
!>          La dimension principale du tableau AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et à l'entrée
!>          contient les détails des interchanges et la structure bloc
!>          de D, telle que déterminée par DSYTRF.
!>          Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été
!>          interchangées et D(k,k) est un bloc diagonal de taille 1 par 1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0, alors les lignes et
!>          colonnes k-1 et -IPIV(k) ont été interchangées et D(k-1:k,k-1:k)
!>          est un bloc diagonal de taille 2 par 2. Si UPLO = 'L' et IPIV(k) =
!>          IPIV(k+1) < 0, alors les lignes et colonnes k+1 et -IPIV(k) ont été
!>          interchangées et D(k:k+1,k:k+1) est un bloc diagonal de taille 2 par 2.
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et à la sortie
!>          contient les détails des interchanges et la structure bloc
!>          de D, telle que déterminée par DSYTRF.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>          La matrice second membre B de taille N par NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N par NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'estimation du réciproque du nombre de condition de la matrice
!>          A. Si RCOND est inférieur à la précision machine (en
!>          particulier, si RCOND = 0), la matrice est singulière à la
!>          précision de travail. Cette condition est indiquée par un code de retour
!>          INFO > 0.
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la solution réelle correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du
!>          plus grand élément de X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          surestimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A

NAME


dsysvx - dsysvx






SYNOPSIS


        SUBROUTINE DSYSVX( FACT, UPLO, N, NRHS, DLINKS, D, E, IPIV,
 &                   ZF, LDF, INFO )



Parameters:




FACT          CHARACTER*1




FACT specifies the form of the problem to be solved:


    

  • ‘N’: the routines DSYTRF and DSYTRS will be called to factor A and then solve the system of equations.


  • ‘F’: the routine DSYTRF is called to factor A. The factorization is assumed to have been completed by the user.


    Constraint: FACT = ‘N’ or ‘F’.
    


    UPLO           CHARACTER*1
    

    

    UPLO specifies whether the matrix A is upper triangular or lower triangular:
    

      

    • ‘U’: Upper triangle of A is stored and.
    

  • ‘L’: Lower triangle of A is stored.


    Constraint: UPLO = ‘U’ or ‘L’.
    


    N            INTEGER
    

    

    The order of the matrix A; the number of linear equations, N.
    

    Constraint: N >= 0.
    

    

    NRHS          INTEGER
    

    

    The number of right hand side vectors, i.e., the number of systems to be solved.
    

    Constraint: NRHS >= 0.
    

    

    DLINKS       DOUBLE PRECISION array, dimension (N)
    

    

    On entry, DLINKS contains the diagonal elements of the diagonal matrix D.
    

    On exit, DLINKS contains the diagonal elements of the diagonal matrix D if FACT = ‘N’. If FACT = ‘F’, DLINKS is unchanged.
    

    

    D             DOUBLE PRECISION array, dimension (N)
    

    

    On entry, D contains the diagonal elements of the diagonal matrix D.
    

    On exit, D contains the diagonal elements of the diagonal matrix D if FACT = ‘N’. If FACT = ‘F’, D is unchanged.
    

    

    E             DOUBLE PRECISION array, dimension (N-1)
    

    

    On entry, E contains the off-diagonal elements of the tridiagonal matrix T.
    

    On exit, E contains the off-diagonal elements of the tridiagonal matrix T if FACT = ‘N’. If FACT = ‘F’, E is unchanged.
    

    

    IPIV          INTEGER array, dimension (N)
    

    

    On entry, the pivot indices; for 1 <= K <= N, the pivot element is in row K, or the K-th block of rows, and is K. IPIV(K) can be positive or negative. If IPIV(K) = K, then row K of the matrix is a single block. If IPIV(K) = L < K, then rows K and L and columns K and L form a 2-by-2 pivot block.
    

    On exit, IPIV contains details of the factorization.
    

    If FACT = ‘F’, IPIV must contain the pivot indices from the previous factorization.
    

    

    ZF            DOUBLE PRECISION array, dimension (LDF,NRHS)
    

    

    On entry, the N-by-NRHS matrix Z of right hand side vectors, Z.  The matrices X and B.
    

    On exit, if INFO = 0 or INFO = N+1, ZF contains the solution X to the system of equations Ax = B. Particularly, if FACT = ‘F’, ZF contains the solution X to the system of equations.
    

    

    LDF           INTEGER
    

    

    The leading dimension of the array ZF. LDF >= max(1,N).
    

    

    INFO          INTEGER
    

    

    = 0: successful exit
    

    < 0: if INFO = -i, the i-th argument had an illegal value
    

    > 0: if INFO = i, and i is
    

                          <= N:  D(i,i) is exactly zero. The factorization
                             has been completed but the factor D is exactly
                             singular, so the solution and error bounds could
                             not be computed. RCOND = 0 is returned.
                      = N+1: D is nonsingular, but RCOND is less than machine
                             precision, meaning that the matrix is singular
                             to working precision.  Nevertheless, the
                             solution and error bounds are computed because
                             there are a number of situations where the
                             computed solution can be more accurate than the
                             value of RCOND would suggest.

    Function/Subroutine Documentation
    

    Purpose
    

    

    DSYSVX uses the Diagonal Complete Pivoting LU factorization to solve the general
    banded system of linear equations A*X = B, where A is a real symmetric banded
    matrix, or to factorize the matrix A and then solve the factored system.
    

    The symmetric banded matrix A is factored as A = P*D*Q**T*U**T*U*Q, where P is a
    permutation matrix, D is a diagonal matrix, and U is a unit upper triangular
    matrix. This factorization is computed by the routines DSYTRF and DSYTRD.
    

    The factored system is then solved for X using the routine DSYTRS.
    

    The routine differs from the driver routine DSYGVX in that it does not compute
    condition numbers or error bounds. It is more efficient for repeated solution
    of systems with the same matrix A.
