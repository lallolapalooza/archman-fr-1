DSYSV_AA calcule la solution du système d'équations linéaires A * X = B pour les matrices SY

Objectif :

!>
!> DSYSV calcule la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice symétrique de taille N-par-N et X et B sont des matrices
!> de taille N-par-NRHS.
!>
!> L'algorithme d'Aasen est utilisé pour factoriser A sous la forme
!>    A = U**T * T * U,  si UPLO = 'U', ou
!>    A = L * T * L**T,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutations et de matrices
!> triangulaires supérieures (ou inférieures) unitaires, et T est symétrique
!> tridiagonale. La forme factorisée de A est ensuite utilisée pour résoudre
!> le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          En entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          supérieure de la matrice A, de taille N-par-N, contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          triangulaire inférieure de A n'est pas référencée. Si UPLO = 'L', la
!>          partie inférieure de la matrice A, de taille N-par-N, contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée.
!>
!>          En sortie, si INFO = 0, la matrice tridiagonale T et les multiplicateurs
!>          utilisés pour obtenir le facteur U ou L de la
!>          factorisation A = U**T*T*U ou A = L*T*L**T, tels que calculés par
!>          DSYTRF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          En sortie, il contient les détails des échanges, c'est-à-dire que
!>          la ligne et la colonne k de A ont été échangées avec la
!>          ligne et la colonne IPIV(k).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>          En entrée, la matrice B de taille N-par-NRHS du membre de droite.
!>          En sortie, si INFO = 0, la matrice solution X de taille N-par-NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur de WORK.  LWORK >= MAX(1,2*N,3*N-2), et pour
!>          une performance optimale, LWORK >= MAX(1,N*NB), où NB est
!>          la taille de bloc optimale pour DSYTRF_AA.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) est exactement zéro. La factorisation
!>               a été complétée, mais la matrice diagonale par blocs D est
!>               exactement singulière, donc la solution n'a pas pu être calculée.
!>
