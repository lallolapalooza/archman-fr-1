DSTEVR calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
d'une matrice tridiagonale symétrique réelle T. Les valeurs propres et les
vecteurs propres peuvent être sélectionnés en spécifiant soit une plage de valeurs
soit une plage d'indices pour les valeurs propres désirées.

Objectif:

!>
!> DSTEVR calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique réelle T. Les valeurs propres et les
!> vecteurs propres peuvent être sélectionnés en spécifiant soit une plage de valeurs
!> soit une plage d'indices pour les valeurs propres désirées.
!>
!> Chaque fois que possible, DSTEVR appelle DSTEMR pour calculer le spectre
!> des valeurs propres en utilisant des Représentations Relativement Robustes. DSTEMR
!> calcule les valeurs propres par l'algorithme dqds, tandis que les vecteurs propres
!> orthogonaux sont calculés à partir de diverses représentations L D L^T
!> (également connues sous le nom de Représentations Relativement Robustes). L'orthogonalisation
!> de Gram-Schmidt est évitée autant que possible. Plus précisément,
!> les différentes étapes de l'algorithme sont les suivantes. Pour le i-ème
!> bloc non réduit de T,
!>    (a) Calculer T - sigma_i = L_i D_i L_i^T, tel que L_i D_i L_i^T
!>         soit une représentation relativement robuste,
!>    (b) Calculer les valeurs propres, lambda_j, de L_i D_i L_i^T avec une haute
!>         précision relative par l'algorithme dqds,
!>    (c) S'il existe un cluster de valeurs propres proches, sigma_i
!>         proche du cluster, et aller à l'étape (a),
!>    (d) Étant donnée la valeur propre approximative lambda_j de L_i D_i L_i^T,
!>         calculer le vecteur propre correspondant en formant une
!>         factorisation torsadée révélatrice de rang.
!> La précision de sortie désirée peut être spécifiée par le paramètre
!> d'entrée ABSTOL.
!>
!> Pour plus de détails, voir , par Inderjit Dhillon,
!> Division de l'informatique Rapport technique n° UCB//CSD-97-971,
!> UC Berkeley, mai 1997.
!>
!>
!> Note 1 : DSTEVR appelle DSTEMR lorsque le spectre complet est demandé
!> sur les machines conformes à la norme de virgule flottante ieee-754.
!> DSTEVR appelle DSTEBZ et DSTEIN sur les machines non-ieee et
!> lorsque des requêtes de spectre partiel sont faites.
!>
!> L'exécution normale de DSTEMR peut créer des NaN et des infinis et
!> peut donc avorter en raison d'une exception de virgule flottante dans les environnements
!> qui ne gèrent pas les NaN et les infinis selon la manière par défaut de la norme ieee.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées.
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I': les valeurs propres de l'indice IL à IU seront trouvées.
!>          Pour RANGE = 'V' ou 'I' et IU - IL < N - 1, DSTEBZ et
!>          DSTEIN sont appelés.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice.  N >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          En entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A.
!>          En sortie, D peut être multiplié par un facteur constant choisi
!>          pour éviter le dépassement ou le sous-dépassement lors du calcul des valeurs propres.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (max(1,N-1))
!>          En entrée, les (n-1) éléments sous-diagonaux de la matrice
!>          tridiagonale A dans les éléments 1 à N-1 de E.
!>          En sortie, E peut être multiplié par un facteur constant choisi
!>          pour éviter le dépassement ou le sous-dépassement lors du calcul des valeurs propres.
!>

VL

!>          VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>          lorsqu'elle est déterminée comme se situant dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          par réduction de A en forme tridiagonale.
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si une haute précision relative est importante, réglez ABSTOL sur
!>          DLAMCH( 'Safe minimum' ). Cela garantira que
!>          les valeurs propres sont calculées avec une haute précision relative lorsque
!>          possible dans les futures versions. Le code actuel ne fait
!>          aucune garantie quant à une haute précision relative, mais
!>          les futures versions le feront. Voir J. Barlow et J. Demmel,
!>          , LAPACK Working Note #7, pour une discussion
!>          sur les matrices qui définissent leurs valeurs propres avec une haute précision
!>          relative.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées en
!>          ordre croissant.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension (LDZ, max(1,M) )
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et

NAME

dstevr

an LAPACK routine to compute the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

SYNOPSIS

    SUBROUTINE DSTEVR( JOBZ, RANGE, N, D, E, VL, VU, IL, IU,
  &                   KEY, WORK, LWORK, IWORK, LIWORK, Z, LDZ, ISUPPZ, INFO )

JOBZ

    CHARACTER*1           :: JOBZ
    
    
        
  • 'N': compute only the eigenvalues of A.
    • 
        
  • 'V': compute the eigenvalues and eigenvectors of A.
    •

RANGE

    CHARACTER*1           :: RANGE
    
    
        
  • 'A': all eigenvalues will be found.
    • 
        
  • 'V': all eigenvalues in the interval (VL, VU] will be found.
    • 
        
  • 'I': the IL-th to IU-th eigenvalues will be found.
    •

N

    INTEGER               :: N
    
    
        
  • The order of the matrix A.  0 <= N.
    •

D

    DOUBLE PRECISION array, dimension (N)
    
    
        
  • The diagonal entries of the tridiagonal matrix A.
    •

E

    DOUBLE PRECISION array, dimension (N-1)
    
    
        
  • The off-diagonal entries of the tridiagonal matrix A.
    •

VL

    DOUBLE PRECISION       :: VL
    
    
        
  • The lower or upper bound of the interval for the desired eigenvalues.
    • 
        
  • Used only if RANGE = 'V'.
    •

VU

    DOUBLE PRECISION       :: VU
    
    
        
  • The lower or upper bound of the interval for the desired eigenvalues.
    • 
        
  • Used only if RANGE = 'V'.
    •

IL

    INTEGER               :: IL
    
    
        
  • The rank of the desired eigenvalue.  Used only if RANGE = 'I'.
    •

IU

    INTEGER               :: IU
    
    
        
  • The rank of the desired eigenvalue.  Used only if RANGE = 'I'.
    •

KEY

    INTEGER               :: KEY
    
    
        
  • KEY = 1:          Eigenvalues and eigenvectors, smallest to largest
    • 
        
  • KEY = 0:          Eigenvalues and eigenvectors, largest to smallest
    • 
        
  • KEY = -1:         Eigenvalues and eigenvectors, smallest to largest
    • 
        
  • KEY = 2:          Eigenvalues and eigenvectors, largest to smallest
    • 
        
  • KEY = -2:         Eigenvalues and eigenvectors, smallest to largest
    • 
    

    
    
        
  • Used only if RANGE = 'I' or 'V'.
    •

WORK

    DOUBLE PRECISION array, dimension (MAX(1,LWORK))
    
    
        
  • Local auxiliary workspace.
    •

LWORK

    INTEGER               :: LWORK
    
    
        
  • The dimension of the array WORK. LWORK >= max(1,20*N).
    • 
        
  • If LWORK = -1, then a workspace query is assumed; the routine only

    INTEGER array, dimension (MAX(1,LIWORK))

            calculates the optimal sizes of the WORK and IWORK arrays, returns
            these values as the first entries of the WORK and IWORK arrays, and
            no error message related to LWORK or LIWORK is issued by XERBLA.

Z

    DOUBLE PRECISION array, dimension (LDZ,*)
    
    
        
  • The basis for the subspace of A.
    •

LDZ

    INTEGER               :: LDZ
    
    
        
  • The leading dimension of the array Z. LDZ >= max(1,N).
    •

ISUPPZ

    INTEGER array, dimension ( 2*max(1,M) )
    
    
        
  • The support of the eigenvectors in Z, i.e., the indices indicating the nonzero elements in Z. The i-th eigenvector is nonzero only in elements ISUPPZ( 2*i-1 ) through ISUPPZ( 2*i ). Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1
    •

WORK

    WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
    On exit, if INFO = 0, WORK(1) returns the optimal (and
    minimal) LWORK.

LWORK

    LWORK is INTEGER
    The dimension of the array WORK.  LWORK >= max(1,20*N).

    If LWORK = -1, then a workspace query is assumed; the routine
    only calculates the optimal sizes of the WORK and IWORK
    arrays, returns these values as the first entries of the WORK
    and IWORK arrays, and no error message related to LWORK or
    LIWORK is issued by XERBLA.

IWORK

    IWORK is INTEGER array, dimension (MAX(1,LIWORK))
    On exit, if INFO = 0, IWORK(1) returns the optimal (and
    minimal) LIWORK.

LIWORK

    LIWORK is INTEGER
    The dimension of the array IWORK.  LIWORK >= max(1,10*N).

    If LIWORK = -1, then a workspace query is assumed; the
    routine only calculates the optimal sizes of the WORK and
    IWORK arrays, returns these values as the first entries of
    the WORK and IWORK arrays, and no error message related to
    LWORK or LIWORK is issued by XERBLA.

INFO

    INFO is INTEGER
    = 0:  successful exit
    < 0:  if INFO = -i, the i-th argument had an illegal value
    > 0:  Internal error
