Documentation de la fonction/sous-routine

sous-routine dsgt01 (integer itype, character uplo, integer n, integer m, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) d, double precision, dimension( * ) work, double precision, dimension( * ) result)

DSGT01

Objectif :

!>
!> DDGT01 vérifie une décomposition de la forme
!>
!>    A Z   =  B Z D ou
!>    A B Z =  Z D ou
!>    B A Z =  Z D
!>
!> où A est une matrice symétrique, B est
!> symétrique définie positive, Z est orthogonale et D est diagonale.
!>
!> L'un des rapports de test suivants est calculé :
!>
!> ITYPE = 1:  RESULT(1) = | A Z - B Z D | / ( |A| |Z| n ulp )
!>
!> ITYPE = 2:  RESULT(1) = | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!> ITYPE = 3:  RESULT(1) = | B A Z - Z D | / ( |A| |Z| n ulp )
!>

Paramètres

ITYPE 
!>          ITYPE est de type INTEGER
!>          La forme du problème propre généralisé symétrique.
!>          = 1:  A*z = (lambda)*B*z
!>          = 2:  A*B*z = (lambda)*z
!>          = 3:  B*A*z = (lambda)*z
!>

UPLO

!>          UPLO est de type CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure des
!>          matrices symétriques A et B est stockée.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est de type INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

M

!>          M est de type INTEGER
!>          Le nombre de valeurs propres trouvées.  0 <= M <= N.
!>

A

!>          A est un tableau de type DOUBLE PRECISION, dimension (LDA, N)
!>          La matrice symétrique originale A.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau de type DOUBLE PRECISION, dimension (LDB, N)
!>          La matrice symétrique définie positive originale B.
!>

LDB

!>          LDB est de type INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

Z

!>          Z est un tableau de type DOUBLE PRECISION, dimension (LDZ, M)
!>          Les vecteurs propres calculés du problème propre généralisé.
!>

LDZ

!>          LDZ est de type INTEGER
!>          La dimension principale du tableau Z.  LDZ >= max(1,N).
!>

D

!>          D est un tableau de type DOUBLE PRECISION, dimension (M)
!>          Les valeurs propres calculées du problème propre généralisé.
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, dimension (N*N)
!>

RESULT

!>          RESULT est un tableau de type DOUBLE PRECISION, dimension (1)
!>          Le rapport de test tel que décrit ci-dessus.
!>
