sous-programme dsygvx (entier itype, caractere jobz, caractere range, caractere uplo, entier n, double precision, dimension( lda, * ) a, entier lda, double precision, dimension( ldb, * ) b, entier ldb, double precision vl, double precision vu, entier il, entier iu, double precision abstol, entier m, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, entier ldz, double precision, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

DSYGVX

Objectif:

!>
!> DSYGVX calcule les valeurs propres sélectionnées, et éventuellement, les vecteurs propres
!> d'un problème généralisé symétrique-défini réel, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x. Ici A
!> et B sont supposés symétriques et B est aussi définie positive.
!> Les valeurs propres et les vecteurs propres peuvent être sélectionnés en spécifiant soit une
!> plage de valeurs, soit une plage d'indices pour les valeurs propres désirées.
!>

Paramètres

ITYPE 
!>          ITYPE est un ENTIER
!>          Spécifie le type de problème à résoudre :
!>          = 1 :  A*x = (lambda)*B*x
!>          = 2 :  A*B*x = (lambda)*x
!>          = 3 :  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est un CARACTERE*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est un CARACTERE*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs propres de rang IL à IU seront trouvées.
!>

UPLO

!>          UPLO est un CARACTERE*1
!>          = 'U' : le triangle supérieur de A et B est stocké ;
!>          = 'L' : le triangle inférieur de A et B est stocké.
!>

N

!>          N est un ENTIER
!>          L'ordre du faisceau de matrices (A,B).  N >= 0.
!>

A

!>          A est un tableau de DOUBLE PRECISION, dimension (LDA, N)
!>          En entrée, la matrice symétrique A.  Si UPLO = 'U',
!>          la partie triangulaire supérieure N-par-N de A contient la
!>          partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N-par-N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>
!>          En sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau de DOUBLE PRECISION, dimension (LDB, N)
!>          En entrée, la matrice symétrique B.  Si UPLO = 'U',
!>          la partie triangulaire supérieure N-par-N de B contient la
!>          partie triangulaire supérieure de la matrice B.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N-par-N de B contient
!>          la partie triangulaire inférieure de la matrice B.
!>
!>          En sortie, si INFO <= N, la partie de B contenant la matrice est
!>          écrasée par le facteur triangulaire U ou L de la factorisation de
!>          Cholesky B = U**T*U ou B = L*L**T.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

VL

!>          VL est un DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est un DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est un ENTIER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est un ENTIER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est un DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>          lorsqu'elle est déterminée se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine.  Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant C à forme tridiagonale, où C est la matrice symétrique
!>          du problème symétrique standard auquel le problème généralisé
!>          est transformé.
!>
!>          Les valeurs propres seront calculées de manière la plus précise lorsque ABSTOL
!>          est réglé sur deux fois le seuil de sous-flux 2*DLAMCH('S'), pas zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de régler ABSTOL sur
!>          2*DLAMCH('S').
!>

M

!>          M est un ENTIER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau de DOUBLE PRECISION, dimension (N)
!>          En cas de sortie normale, les M premiers éléments contiennent les
!>          valeurs propres sélectionnées par ordre croissant.
!>

Z

!>          Z est un tableau de DOUBLE PRECISION, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Les vecteurs propres sont normalisés comme suit :
!>          si ITYPE = 1 ou 2, Z**T*B*Z = I ;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et
!>          l'indice du vecteur propre est retourné dans IFAIL.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          En sortie, si INFO =

LWOR

K 
!>          LWORK est un entier
!>          La longueur du tableau WORK.  LWORK >= max(1,8*N).
!>          Pour une efficacité optimale, LWORK >= (NB+3)*N,
!>          où NB est la taille de bloc pour DSYTRD retournée par ILAENV.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!
>

K 
!>          IWORK est un tableau d'entiers, dimension (5*N)
!
>

IFAI

L 
!>          IFAIL est un tableau d'entiers, dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont nuls.  Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', IFAIL n'est pas référencé.
!
>

INF

O 
!>          INFO est un entier
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  DPOTRF ou DSYEVX a renvoyé un code d'erreur :
!>             <= N:  si INFO = i, DSYEVX n'a pas convergé ;
!>                    i vecteurs propres n'ont pas convergé.  Leurs indices
!>                    sont stockés dans le tableau IFAIL.
!>             > N:   si INFO = N + i, pour 1 <= i <= N, alors le mineur
!>                    principal de tête d'ordre i de B n'est pas positif.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>
