Documentation de la fonction/sous-routine

sous-routine dsyrfsx (character uplo, character equed, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( * ) s, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DSYRFSX

But :

!>
!>    DSYRFSX améliore la solution calculée d'un système d'équations
!>    linéaires lorsque la matrice des coefficients est symétrique
!>    indéfinie, et fournit des bornes d'erreur et des estimations
!>    d'erreur arrière pour la solution. En plus de la borne d'erreur
!>    au sens de la norme, le code fournit, si possible, une borne
!>    d'erreur maximale composante par composante. Voir les commentaires
!>    pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des bornes
!>    d'erreur.
!>
!>    Le système d'équations linéaires d'origine peut avoir été
!>    équilibré avant l'appel de cette routine, comme décrit par les
!>    arguments EQUED et S ci-dessous. Dans ce cas, la solution et les
!>    bornes d'erreur renvoyées correspondent au système d'origine non
!>    équilibré.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     réglages déterminent la manière dont le raffinement est effectué, mais
!>     souvent les valeurs par défaut sont acceptables. Si les valeurs par
!>     défaut sont acceptables, les utilisateurs peuvent passer NPARAMS = 0,
!>     ce qui empêche le code source d'accéder à l'argument PARAMS.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U' : le triangle supérieur de A est stocké ;
!>       = 'L' : le triangle inférieur de A est stocké.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibrage qui a été appliquée à A
!>     avant l'appel de cette routine. Ceci est nécessaire pour
!>     calculer correctement la solution et les bornes d'erreur.
!>       = 'N' : pas d'équilibrage
!>       = 'Y' : équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(S) * A * diag(S).
!>               Le second membre B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>     des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>     La matrice symétrique A. Si UPLO = 'U', la partie triangulaire
!>     supérieure principale N×N de A contient la partie triangulaire
!>     supérieure de la matrice A, et la partie strictement
!>     triangulaire inférieure de A n'est pas référencée. Si
!>     UPLO = 'L', la partie triangulaire inférieure principale N×N
!>     de A contient la partie triangulaire inférieure de la matrice
!>     A, et la partie strictement triangulaire supérieure de A n'est
!>     pas référencée.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est un tableau DOUBLE PRECISION, dimension (LDAF,N)
!>     La forme factorisée de la matrice A. AF contient la matrice
!>     diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L à partir de la factorisation
!>     A = U*D*U**T ou A = L*D*L**T telle que calculée par DSYTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Détails des permutations et de la structure par blocs de D
!>     tels que déterminés par DSYTRF.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle pour A. Si EQUED = 'Y', A est multiplié
!>     à gauche et à droite par diag(S). S est un argument d'entrée si
!>     FACT = 'F' ; sinon, S est un argument de sortie. Si FACT = 'F'
!>     et EQUED = 'Y', chaque élément de S doit être positif. Si S est
!>     en sortie, chaque élément de S est une puissance de la base. Si
!>     S est en entrée, chaque élément de S devrait être une puissance
!>     de la base pour garantir une solution et des estimations
!>     d'erreur fiables. La mise à l'échelle par des puissances de la
!>     base ne provoque pas d'erreurs d'arrondi, sauf si le résultat
!>     déborde ou est sous le seuil de représentabilité. Les erreurs
!>     d'arrondi pendant la mise à l'échelle conduisent à un
!>     raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui
!>     peuvent ne pas être fiables.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>     La matrice du second membre B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par DGETRS.
!>     À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Nombre de condition réciproque mis à l'échelle. Ceci est une
!>     estimation du nombre de condition réciproque de Skeel de la
!>     matrice A après équilibrage (si effectué). Si celui-ci est
!>     inférieur à la précision machine (en particulier, s'il est
!>     nul), la matrice est singulière à la précision de travail.
!>     Notez que l'erreur peut encore être petite même si ce nombre
!>     est très petit et que la matrice semble mal conditionnée.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>     Erreur arrière relative composante par composante. Il s'agit
!>     de l'erreur arrière relative composante par composante de
!>     chaque vecteur solution X(j) (c'est-à-dire le plus petit
!>     changement relatif dans n'importe quel élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à renvoyer pour chaque second membre
!>     et chaque type (au sens de la norme ou composante par
!>     composante). Voir ERR_BNDS_NORM et ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations
!>     sur diverses bornes d'erreur et nombres de condition
!>     correspondant à l'erreur relative au sens de la norme, qui est
!>     définie comme suit :
!>
!>     Erreur relative au sens de la norme dans le ième vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que
!>     décrit ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée, presque
!>              certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne
!>              doit être prise que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque estimé dans la norme. Comparé avec le seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si
!>              l'estimation d'erreur est . Ces nombres de condition
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf))
!>              pour une matrice Z correctement mise à l'échelle.
!>              Soit Z = S*A, où S met chaque ligne à l'échelle par une
!>              puissance de la base afin que toutes les sommes
!>              absolues de lignes de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et de
!>     précautions supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations
!>     sur diverses bornes d'erreur et nombres de condition correspondant
!>     à l'erreur relative composante par composante, qui est définie
!>     comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur
!>     solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend
!>     l'erreur relative composante par composante) et le type
!>     d'information d'erreur tel que décrit ci-dessous. Il y a
!>     actuellement jusqu'à trois informations retournées pour chaque
!>     second membre. Si la précision composante par composante n'est
!>     pas demandée (PARAMS(3) = 0.0), alors ERR_BNDS_COMP n'est pas
!>     accédé. Si N_ERR_BNDS < 3, alors au plus les premières entrées
!>     (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée, presque
!>              certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne
!>              doit être prise que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque estimé composante par composante. Comparé
!>              avec le seuil sqrt(n) * dlamch('Epsilon') pour
!>              déterminer si l'estimation d'erreur est . Ces nombres
!>              de condition réciproques sont 1 / (norm(Z^{-1},inf) *
!>              norm(Z,inf)) pour une matrice Z correctement mise à
!>              l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met chaque ligne de
!>              A*diag(x) à l'échelle par une puissance de la base afin
!>              que toutes les sommes absolues de lignes de Z soient
!>              approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et de
!>     précautions supplémentaires.
!>

NPARAMS

!>          NPARAMS est INTEGER
!>     Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0,
!>     le tableau PARAMS n'est jamais référencé et les valeurs par
!>     défaut sont utilisées.
!>

PARAMS

!>          PARAMS est un tableau DOUBLE PRECISION, dimension (NPARAMS)
!>     Spécifie les paramètres de l'algorithme. Si une entrée est
!>     < 0.0, alors cette entrée sera remplie avec la valeur par défaut
!>     utilisée pour ce paramètre. Seules les positions jusqu'à NPARAMS
!>     sont accédées ; les valeurs par défaut sont utilisées pour les
!>     paramètres de numéro supérieur.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Indique s'il faut effectuer
!>            l'affinage itératif ou non.
!>         Valeur par défaut : 1.0D+0
!>            = 0.0 :  Aucun affinage n'est effectué et aucune borne
!>                    d'erreur n'est calculée.
!>            = 1.0 :  Utiliser l'algorithme d'affinage en double
!>                    précision, éventuellement avec des calculs
!>                    single-double si l'environnement de compilation ne
!>                    supporte pas DOUBLE PRECISION.
!>              (les autres valeurs sont réservées pour une utilisation
!>              future)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximal de calculs de
!>            résidu autorisés pour l'affinage.
!>         Valeur par défaut : 10
!>         Agressif : Définir à 100 pour permettre la convergence en
!>                     utilisant des factorisations approchées ou des
!>                     factorisations autres que LU. Si la factorisation
!>                     utilise une technique autre que l'élimination
!>                     gaussienne, les garanties dans err_bnds_norm et
!>                     err_bnds_comp peuvent ne plus être dignes de
!>                     confiance.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3 : Drapeau déterminant si le code
!>            tentera de trouver une solution avec une petite erreur
!>            relative composante par composante dans l'algorithme en
!>            double précision. Positif est vrai, 0.0 est faux.
!>         Valeur par défaut : 1.0 (tenter la convergence composante
!>         par composante)
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (4*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>       = 0 :  Sortie réussie. La solution à chaque second membre est
!>         garantie.
!>       < 0 :  Si INFO = -i, le i-ème argument avait une valeur
!>         illégale
!>       > 0 et <= N :  U(INFO,INFO) est exactement zéro. La
!>         factorisation a été complétée, mais le facteur U est
!>         exactement singulier, donc la solution et les bornes d'erreur
!>         n'ont pas pu être calculées. RCOND = 0 est retourné.
!>       = N+J : La solution correspondant au J-ème second membre n'est
!>         pas garantie. Les solutions correspondant aux autres seconds
!>         membres K avec K > J peuvent ne pas être garanties non plus,
!>         mais seul le premier de ces seconds membres est rapporté. Si
!>         une petite erreur composante par composante n'est pas
!>         demandée (PARAMS(3) = 0.0) alors le J-ème second membre est
!>         le premier avec une borne d'erreur dans la norme qui n'est
!>         pas garantie (le plus petit J tel que ERR_BNDS_NORM(J,1) =
!>         0.0). Par défaut (PARAMS(3) = 1.0) le J-ème second membre
!>         est le premier avec une borne d'erreur dans la norme ou
!>         composante par composante qui n'est pas garantie (le plus
!>         petit J tel que soit ERR_BNDS_NORM(J,1) = 0.0 soit
!>         ERR_BNDS_COMP(J,1) = 0.0). Voir la définition de
!>         ERR_BNDS_NORM(:,1) et ERR_BNDS_COMP(:,1). Pour obtenir des
!>         informations sur tous les seconds membres, vérifier
!>         ERR_BNDS_NORM ou ERR_BNDS_COMP.
!>
