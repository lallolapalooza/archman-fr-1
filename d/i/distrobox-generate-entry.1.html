DISTROBOX-GENERATE-ENTRY(1) Manuel utilisateur DISTROBOX-GENERATE-ENTRY(1)

NOM

distrobox generate-entry

DESCRIPTION

distrobox-generate-entry créera une icône de bureau pour l'un des distroboxes disponibles. Celle-ci sera ensuite supprimée lorsque vous supprimerez le distrobox correspondant.

SYNTAXE

distrobox generate-entry

--help/-h :      afficher ce message
--all/-a :       effectuer pour tous les distroboxes
--delete/-d :    supprimer l'entrée
--icon/-i :      spécifier une icône personnalisée [/path/to/icon] (défaut automatique)
--root/-r :      effectuer sur les distroboxes rootful
--verbose/-v :   afficher plus de détails
--version/-V :   afficher la version

EXEMPLES

Générer une entrée pour un conteneur

distrobox generate-entry mon-nom-de-conteneur

Spécifier une icône personnalisée pour l'entrée

distrobox generate-entry mon-nom-de-conteneur --icon /chemin/vers/icone.png

Générer une entrée pour tous les distroboxes

distrobox generate-entry --all

Supprimer une entrée

distrobox generate-entry nom-du-conteneur --delete
