diffman-git(1) Manuel des commandes générales diffman-git(1)

NOM

diffman-git - comparer les modifications des pages man ligne par ligne

SYNOPSIS

diffman-git [options-diff ...] [[commit-base] commit]

DESCRIPTION

La commande diffman-git formate une page man selon deux commites git(1), puis exécute diff(1) sur les sorties formatées.

Si le commit n'est pas spécifié, elle compare le répertoire de travail avec HEAD.

Si le commit-base n'est pas spécifié, la comparaison est faite avec le commit précédent.

OPTIONS

-s
Signaler quand deux fichiers sont identiques.
-Un
Afficher n lignes de contexte unifié (par défaut 3).
-w
Ignorer tout espace blanc.

ENVIRONNEMENT

Voir man(1).

EXEMPLES

$ MAN_KEEP_FORMATTING= diffman-git 437e4afec6ca | less -R;
--- 437e4afec6ca^:man/man3/sem_open.3
+++ 437e4afec6ca:man/man3/sem_open.3
@@ -14,3 +14,2 @@
-     sem_t *sem_open(const char *name, int oflag);
-     sem_t *sem_open(const char *name, int oflag,
-                     mode_t mode, unsigned int value);
+     sem_t *sem_open(const char *name, int oflag, ...
+                     /* mode_t mode, unsigned int value */ );

VOIR AUSSI

diff(1), man(1), git(1), less(1)
