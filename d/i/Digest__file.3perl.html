NOM

Digest::file - Calculer les digests de fichiers

SYNTAXE

# Commande "md5sum" de pauvre
use Digest::file qw(digest_file_hex);
for (@ARGV) {
    print digest_file_hex($_, "MD5"), "  $_\n";
}

DESCRIPTION

Ce module fournit 3 fonctions pratiques pour calculer le digest des fichiers. Les fonctions suivantes sont fournies :

digest_file( $fichier, $algorithme, [$arg,...] )
Cette fonction calcule et retourne le digest binaire des octets du fichier donné. La fonction échouera si elle ne parvient pas à ouvrir ou lire le fichier.

Le $algorithme est une chaîne telle que "MD2", "MD5", "SHA-1", "SHA-512". Les arguments supplémentaires sont passés au constructeur pour l'implémentation de l'algorithme donné.

digest_file_hex( $fichier, $algorithme, [$arg,...] )
Identique à digest_file(), mais retourne le digest sous forme hexadécimale.
digest_file_base64( $fichier, $algorithme, [$arg,...] )
Identique à digest_file(), mais retourne le digest sous forme de chaîne encodée en base64.
