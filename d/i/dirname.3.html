basename(3) Manuel des fonctions de bibliothèque basename(3)

NOM

basename, dirname - analyser les composants d'un chemin d'accès

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <libgen.h>
char *dirname(char *path);
char *basename(char *path);

DESCRIPTION

Attention : il existe deux fonctions basename différentes ; voir ci-dessous.

Les fonctions dirname() et basename() décomposent une chaîne de chemin d'accès terminée par un caractère nul en composants de répertoire et de nom de fichier. Dans le cas le plus courant, dirname() renvoie la chaîne jusqu'au dernier '/', sans l'inclure, et basename() renvoie le composant suivant le dernier '/'. Les caractères '/' finaux ne sont pas comptés comme faisant partie du chemin d'accès.

Si path ne contient pas de barre oblique, dirname() renvoie la chaîne "." tandis que basename() renvoie une copie de path. Si path est la chaîne "/", alors dirname() et basename() renvoient toutes deux la chaîne "/". Si path est un pointeur nul ou pointe vers une chaîne vide, alors dirname() et basename() renvoient toutes deux la chaîne ".".

La concaténation de la chaîne renvoyée par dirname(), d'une chaîne "/" et de la chaîne renvoyée par basename() produit un chemin d'accès complet.

dirname() et basename() peuvent modifier le contenu de path, il peut donc être souhaitable de passer une copie lors de l'appel à l'une de ces fonctions.

Ces fonctions peuvent renvoyer des pointeurs vers une mémoire allouée statiquement qui peut être écrasée par des appels ultérieurs. Alternativement, elles peuvent renvoyer un pointeur vers une partie de path, de sorte que la chaîne référencée par path ne doit pas être modifiée ou libérée tant que le pointeur renvoyé par la fonction n'est plus requis.

La liste d'exemples suivante (tirée de SUSv2) montre les chaînes renvoyées par dirname() et basename() pour différents chemins :

path dirname basename
/usr/lib /usr lib
/usr/ / usr
usr . usr
/ / /
. . .
.. . ..

VALEUR DE RETOUR

dirname() et basename() renvoient toutes deux des pointeurs vers des chaînes terminées par un caractère nul. (Ne pas passer ces pointeurs à free(3).)

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
basename (), dirname () Thread safety MT-Safe

VERSIONS

Il existe deux versions différentes de basename() : la version POSIX décrite ci-dessus et la version GNU, que l'on obtient après


    #define _GNU_SOURCE         /* Voir feature_test_macros(7) */
    #include <string.h>

La version GNU ne modifie jamais son argument et renvoie la chaîne vide lorsque path a une barre oblique finale, et en particulier aussi lorsque c'est "/". Il n'y a pas de version GNU de dirname().

Avec glibc, on obtient la version POSIX de basename() lorsque <libgen.h> est inclus, et la version GNU sinon.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

BOGUES

Dans l'implémentation glibc, les versions POSIX de ces fonctions modifient l'argument path et provoquent un segfault lorsqu'elles sont appelées avec une chaîne statique comme "/usr/".

Avant glibc 2.2.1, la version glibc de dirname() ne gérait pas correctement les chemins avec des barres obliques finales et provoquait un segfault si on lui donnait un argument NULL.

EXEMPLES

L'extrait de code suivant démontre l'utilisation de basename() et dirname() : 

char *dirc, *basec, *bname, *dname;
char *path = "/etc/passwd";
dirc = strdup(path);
basec = strdup(path);
dname = dirname(dirc);
bname = basename(basec);
printf("dirname=%s, basename=%s\n", dname, bname);

VOIR AUSSI

basename(1), dirname(1)
