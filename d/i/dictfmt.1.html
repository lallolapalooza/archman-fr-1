dictfmt lit un fichier,

Par défaut, l'index est trié selon la locale C, et seuls les caractères alphanumériques et les espaces sont utilisés pour le tri, cependant cela peut être modifié avec les options --locale et --allchars. ( nom_de_base est généralement choisi pour correspondre au nom de base de FICHIER , mais cela n'est pas obligatoire. ) Sauf si la base de données

est

extrêmement petite, il est fortement recommandé que nom_de_base.dict soit compressé avec /usr/bin/dictzip pour créer nom_de_base.dict.dz. (dictzip est inclus dans le paquet source dictd.) FICHIER peut être dans l'un

des

plusieurs formats décrits par les options de format -c5, -t, -e, -f, -h, -j, -p, -i ou -I. Exactement une de ces options doit être donnée. dictfmt préfixe le fichier .dict

de

plusieurs en-têtes. L'en-tête 00-database-url donne la valeur de l'option -u comme URL du site à partir duquel la base de données originale a été obtenue. L'en-tête 00-database-short donne la valeur de l'option -s comme nom court du dictionnaire. (Ce « nom court » est le nom d'identification donné par l'option « dict- D ».) Si les options -u et/ou -s sont omises, ces valeurs seront affichées comme « unknown », ce qui est indésirable pour une base de données distribuée publiquement. La date de conversion (formatage) est donnée dans

l'en-tête

00-database-info. Tout le texte du fichier d'entrée avant le premier mot-clé (tel que défini par l'option de formatage

appropriée) est ajouté à cet en-tête. Tout le texte du fichier d'entrée suivant un mot-clé, jusqu'au prochain mot-
clé, est copié sans modification dans le fichier .dict. OPTIONS DE FORMATAGE -c5 FICHIER est formaté avec des mots-clés
