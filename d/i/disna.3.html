subroutine ddisna (character job, integer m, integer n, double precision, dimension( * ) d, double precision, dimension( * ) sep, integer

info)

DDISN

A

But

: 
!>
!> DDISNA calcule les nombres de condition réciproques pour les vecteurs propres
!> d'une matrice symétrique réelle ou hermitienne complexe, ou pour les vecteurs
!> singuliers gauche ou droite d'une matrice générale m par n. Le nombre de
!> condition réciproque est l'« écart » entre la valeur propre ou la valeur
!> singulière correspondante et la plus proche des autres.
!>
!> La borne d'erreur, mesurée par l'angle en radians, dans le I-ème vecteur
!> calculé est donnée par
!>
!>        DLAMCH( 'E' ) * ( ANORM / SEP( I ) )
!>
!> où ANORM = 2-norm(A) = max( abs( D(j) ) ). SEP(I) ne doit pas être
!> inférieur à DLAMCH( 'E' )*ANORM afin de limiter la taille de
!> la borne d'erreur.
!>
!> DDISNA peut également être utilisé pour calculer des bornes d'erreur pour les
!> vecteurs propres du problème de valeurs propres symétrique défini généralisé.
!
>

Paramètre

s
JOB 
!>          JOB est CHARACTER*1
!>          Spécifie pour quel problème les nombres de condition réciproques
!>          doivent être calculés :
!>          = 'E' : les vecteurs propres d'une matrice symétrique/hermitienne ;
!>          = 'L' : les vecteurs singuliers gauche d'une matrice générale ;
!>          = 'R' : les vecteurs singuliers droit d'une matrice générale.
!
>

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice. M >= 0.
!
>

N 
!>          N est INTEGER
!>          Si JOB = 'L' ou 'R', le nombre de colonnes de la matrice,
!>          auquel cas N >= 0. Ignoré si JOB = 'E'.
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension (M) si JOB = 'E'
!>                              dimension (min(M,N)) si JOB = 'L' ou 'R'
!>          Les valeurs propres (si JOB = 'E') ou les valeurs singulières (si JOB =
!>          'L' ou 'R') de la matrice, soit en ordre croissant, soit en ordre
!>          décroissant. S'il s'agit de valeurs singulières, elles doivent être
!>          non négatives.
!
>

SE

P 
!>          SEP est un tableau DOUBLE PRECISION, dimension (M) si JOB = 'E'
!>                               dimension (min(M,N)) si JOB = 'L' ou 'R'
!>          Les nombres de condition réciproques des vecteurs.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!
>
