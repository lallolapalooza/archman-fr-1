NOM

display_qt - un exemple Gnu Radio gr-qtgui

DESCRIPTION

Affiche une interface graphique à l'aide de QT d'une onde sinusoïdale dans du bruit.

Le programme exemple instancie un graphe de flux GNU Radio utilisant une source d'onde sinusoïdale, une source de bruit et des blocs gr-qtgui. Ce nouvel exemple (depuis la version 3.7.10) montre comment construire une application entièrement en C++ basée sur QT.
