NOM

DISCARD - ignorer l'état de la session

SYNTAXE

DISCARD { ALL | PLANS | SEQUENCES | TEMPORARY | TEMP }

DESCRIPTION

DISCARD libère les ressources internes associées à une session de base de données. Cette commande est utile pour réinitialiser partiellement ou entièrement l'état de la session. Il existe plusieurs sous-commandes pour libérer différents types de ressources ; la variante DISCARD ALL englobe toutes les autres et réinitialise également des états supplémentaires.

PARAMETRES

PLANS

Libère tous les plans de requête mis en cache, forçant une replanification lors de la prochaine utilisation de l'instruction préparée associée.

SEQUENCES

Ignore toutes les informations mises en cache relatives aux séquences, y compris les informations currval()/lastval() et toutes les valeurs de séquence pré-allouées qui n'ont pas encore été retournées par nextval(). (Voir CREATE SEQUENCE (CREATE_SEQUENCE(7)) pour une description des valeurs de séquence pré-allouées.)

TEMPORARY ou TEMP

Supprime toutes les tables temporaires créées dans la session courante.

ALL

Libère toutes les ressources temporaires associées à la session courante et réinitialise la session à son état initial. Actuellement, cela a le même effet que l'exécution de la séquence d'instructions suivante : 
CLOSE ALL;
SET SESSION AUTHORIZATION DEFAULT;
RESET ALL;
DEALLOCATE ALL;
UNLISTEN *;
SELECT pg_advisory_unlock_all();
DISCARD PLANS;
DISCARD TEMP;
DISCARD SEQUENCES;

NOTES

DISCARD ALL ne peut pas être exécuté à l'intérieur d'un bloc de transaction.

COMPATIBILITE

DISCARD est une extension PostgreSQL.
