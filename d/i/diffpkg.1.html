NOM

diffpkg - Compare les fichiers de paquets en utilisant différents modes.

SYNTAXE

diffpkg [OPTIONS] [MODES] [FICHIER|NOMPKG...]

DESCRIPTION

Recherche un paquet construit localement correspondant au PKGBUILD, et télécharge la dernière version de ce paquet depuis les dépôts Pacman. Il compare ensuite les archives des paquets en utilisant différents modes tout en utilisant par défaut une simple liste de contenu tar.

Lorsqu'un seul paquet est fourni, il est utilisé pour comparer avec le paquet construit localement. Lorsqu'il y a deux paquets fournis, les deux paquets sont comparés l'un à l'autre.

Dans tous les cas, un nom de paquet sera converti en nom de fichier depuis le cache ou le pool, et diffpkg procédera comme si ce nom de fichier avait été initialement spécifié.

OPTIONS

-M, --makepkg-config

Définit un fichier de configuration makepkg alternatif

-P, --pool=RÉPERTOIRE

Recherche la cible de diff dans le répertoire du pool (défaut '/srv/ftp/pool')

-v, --verbose

Fournit une sortie plus détaillée/non filtrée

-h, --help

Affiche un texte d'aide

OPTIONS DE SORTIE

--color[=QUAND]

Colore la sortie ; QUAND peut être 'jamais', 'toujours', ou 'auto' ; --color seul signifie --color=auto

-u, -U, --unified

Produit une sortie avec 3 lignes de contexte unifié

-y, --side-by-side

Produit une sortie en deux colonnes

-W, --width[=NB]

Produit au maximum NB (défaut 'auto') colonnes d'impression ; NB peut être 'auto', 'columns' ou un nombre. 'auto' sera résolu à la longueur de ligne maximale des deux fichiers, garantissant que le diff ne sera pas coupé.

MODES

-l, --list

Active le mode de comparaison de liste de contenu tar (défaut)

-d, --diffoscope

Active le mode de comparaison diffoscope

-p, --pkginfo

Active le mode de comparaison .PKGINFO

-b, --buildinfo

Active le mode de comparaison .BUILDINFO
