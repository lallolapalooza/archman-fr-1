Module Digest.MD5

DOCUMENTATION

Module MD5
: S

MD5 est la fonction de hachage MD5. Elle produit des résumés de 128 bits (16 octets) et n'est absolument pas sécurisée sur le plan cryptographique. Elle ne doit être utilisée que pour la compatibilité avec des conceptions antérieures qui imposent l'utilisation de MD5.

Depuis 5.2

type t = string

Le type des résumés.

val hash_length : int

La longueur des résumés, en octets.

val compare : t -> t -> int

Compare deux résumés, avec la même spécification que compare .

val equal : t -> t -> bool

Teste l'égalité de deux résumés.

val string : string -> t

Retourne le résumé de la chaîne donnée.

val bytes : bytes -> t

Retourne le résumé de la séquence d'octets donnée.

val substring : string -> int -> int -> t

substring s ofs len retourne le résumé de la sous-chaîne de s commençant à l'index ofs et contenant len caractères.

val subbytes : bytes -> int -> int -> t

subbytes s ofs len retourne le résumé de la sous-séquence de s commençant à l'index ofs et contenant len octets.

val channel : in_channel -> int -> t

Lit les caractères du canal et retourne leur résumé. Voir Digest.channel pour la spécification complète.

val file : string -> t

Retourne le résumé du fichier dont le nom est donné.

val output : out_channel -> t -> unit

Écrit un résumé sur le canal de sortie donné.

val input : in_channel -> t

Lit un résumé depuis le canal d'entrée donné.

val to_hex : t -> string

Retourne la représentation hexadécimale imprimable du résumé donné.

Lève Invalid_argument si la longueur de l'argument n'est pas hash_length ,

val of_hex : string -> t

Convertit une représentation hexadécimale en résumé correspondant.

Lève Invalid_argument si la longueur de l'argument n'est pas 2 * hash_length , ou si les arguments contiennent des caractères non hexadécimaux.
