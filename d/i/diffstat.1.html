diff et affiche un histogramme des insertions, suppressions et modifications par fichier. Diffstat est un programme utile pour examiner les fichiers de correctifs volumineux et complexes. Si le nom du fichier d'entrée se termine par « .bz2 », « .gz », « .lzma », « .xz », « .zst », « .z » ou « .Z »

NOM

diffstat — résume les statistiques de diff

SYNOPSIS

diffstat [-a] [-b] [-C] [-f format] [-m] [-n] [-o fichier] [-p nombre] [-R] [-r fichier] [-s] [-S] [-u] [-x flag] [-z] [diff]

DESCRIPTION

Le programme diffstat prend le résultat d'un programme diff et produit un résumé des fichiers qui ont été modifiés. Il compte le nombre de lignes insérées et supprimées pour chaque fichier.

Le programme diffstat est conçu pour fonctionner avec le résultat du programme diff. Il peut également accepter l'entrée provenant des programmes bzip2, compress, gzip, lzop, xz, et zstd.

Les programmes de décompression attendus sont bzip2, lzop, uncompress, gzip, xz, et zstd. Le programme diffstat suppose que leurs options de décompression sont les mêmes que celles spécifiées dans les variables d'environnement.

OPTIONS

Le programme diffstat n'a pas d'options.

ENVIRONNEMENT

Diffstat s'exécute dans un environnement POSIX.

Vous pouvez outrepasser les chemins des programmes compilés pour décompresser les fichiers d'entrée en définissant des variables d'environnement correspondant à leurs noms :

DIFFSTAT_BZCAT_PATH
DIFFSTAT_BZIP2_PATH
DIFFSTAT_COMPRESS_PATH
DIFFSTAT_GZIP_PATH
DIFFSTAT_LZCAT_PATH
DIFFSTAT_PCAT_PATH
DIFFSTAT_UNCOMPRESS_PATH
DIFFSTAT_XZ_PATH
DIFFSTAT_ZCAT_PATH
DIFFSTAT_ZSTD_PATH

Cependant, diffstat suppose que le programme résultant utilise les mêmes options en ligne de commande, par exemple "-c" pour décompresser vers la sortie standard.

FICHIERS

Diffstat est un module binaire unique, qui n'utilise aucun fichier auxiliaire.

BOGUES

Diffstat fait de nombreuses suppositions sur le format de sortie de diff.

Il n'y a aucun moyen d'obtenir un nom de fichier à partir du résultat de diff standard entre deux fichiers sans options. Les diffs contextuels fonctionnent, tout comme les diffs unifiés.

Il n'y a pas de moyen simple de déterminer le degré de chevauchement entre les affichages « avant » et « après » des lignes modifiées. Diffstat compte simplement le nombre de lignes insérées et supprimées pour approximer les lignes modifiées pour l'option -m.
