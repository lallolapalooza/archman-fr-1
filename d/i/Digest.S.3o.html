NOM

Digest.S - La signature d'une fonction de hachage qui produit des résumés de longueur hash_length à partir de chaînes de caractères, tableaux d'octets et fichiers.

Type de module

Module type Digest.S

Documentation

Module type S
= sig end

La signature d'une fonction de hachage qui produit des résumés de longueur hash_length à partir de chaînes de caractères, tableaux d'octets et fichiers.

Depuis 5.2

type t = string

Le type des résumés.

val hash_length : int

La longueur des résumés, en octets.

val compare : t -> t -> int

Compare deux résumés, avec la même spécification que compare .

val equal : t -> t -> bool

Teste l'égalité de deux résumés.

val string : string -> t

Retourne le résumé de la chaîne de caractères donnée.

val bytes : bytes -> t

Retourne le résumé de la séquence d'octets donnée.

val substring : string -> int -> int -> t

substring s ofs len retourne le résumé du sous-chaîne de s commençant à l'indice ofs et contenant len caractères.

val subbytes : bytes -> int -> int -> t

subbytes s ofs len retourne le résumé de la sous-séquence de s commençant à l'indice ofs et contenant len octets.

val channel : in_channel -> int -> t

Lit des caractères depuis le canal et retourne leur résumé. Voir Digest.channel pour la spécification complète.

val file : string -> t

Retourne le résumé du fichier dont le nom est donné.

val output : out_channel -> t -> unit

Écrit un résumé sur le canal de sortie donné.

val input : in_channel -> t

Lit un résumé depuis le canal d'entrée donné.

val to_hex : t -> string

Retourne la représentation hexadécimale imprimable du résumé donné.

Lève Invalid_argument si la longueur de l'argument n'est pas hash_length ,

val of_hex : string -> t

Convertit une représentation hexadécimale en résumé correspondant.

Lève Invalid_argument si la longueur de l'argument n'est pas 2 * hash_length , ou si l'argument contient des caractères non hexadécimaux.
