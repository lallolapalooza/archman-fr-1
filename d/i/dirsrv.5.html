DIRSRV(5) Formats de Fichier DIRSRV(5)

NOM

/etc/sysconfig/dirsrv - Fichier d'environnement Systemd qui affecte toutes les instances du serveur d'annuaires.

SYNTAXE

/etc/sysconfig/dirsrv

DESCRIPTION

dirsrv

Ce fichier est sourcé par dirsrv au démarrage pour définir l'environnement par défaut pour toutes les instances du serveur d'annuaires. Pour définir des valeurs par défaut spécifiques à une instance, utilisez le fichier du même répertoire appelé dirsrv-instance où « instance » est le nom de votre instance de serveur d'annuaires, par exemple dirsrv-localhost pour l'instance slapd-localhost.

Ce fichier est au format systemd EnvironmentFile - voir man systemd.exec

EXEMPLE

LD_PRELOAD=/usr/lib64/dirsrv/lib/libjemalloc.so.2
