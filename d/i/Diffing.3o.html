Différenciation paramétrique

Ce module implémente la différenciation sur des listes de contenu arbitraire. Il est paramétré par

- Le contenu des deux listes

- Le témoin d'égalité lorsqu'un élément est conservé

- Le témoin de différenciation lorsqu'un élément est modifié

La différenciation est étendue pour maintenir un état dépendant des changements calculés lors de la traversée des deux listes.

L'algorithme sous-jacent est une modification de l'algorithme de Wagner-Fischer (voir https://en.wikipedia.org/wiki/Wagner%E2%80%93Fischer_algorithm).

Nous fournissons la garantie suivante : étant donné deux listes l et r, si des patchs différents conduisent à des états différents, nous disons que l'état diverge.

- Nous retournons toujours le patch optimal sur les préfixes de l et r sur lesquels l'état ne diverge pas.

- Sinon, nous retournons un patch correct mais non optimal où les sous-patchs sans états divergents sont optimaux pour l'état initial donné.

Plus précisément, l'optimalité de Wagner-Fischer dépend de la propriété que la distance d'édition entre un préfixe k de l'entrée gauche et un préfixe l de l'entrée droite d(k,l) satisfait

d(k,l) = min ( coût_suppr + d(k-1,l), coût_insertion + d(k,l-1), coût_changement + d(k-1,l-1) )

Sous cette hypothèse, il est optimal de choisir de manière gourmande l'état du patch minimal transformant le préfixe k gauche en le préfixe l droit comme représentant des états de tous les patchs possibles transformant le préfixe k gauche en le préfixe l droit.

Si cette propriété n'est pas satisfaite, nous pouvons toujours choisir de manière gourmande un état représentant. Cependant, le patch calculé n'est plus garanti d'être globalement optimal. Néanmoins, il s'agit toujours d'un patch correct, qui est même optimal parmi tous les patchs explorés.

module type Defs = sig end

Les types de base d'une implémentation de différenciation

type change_kind =
| Deletion
| Insertion
| Modification
| Preservation

Le type de changements qui est utilisé pour partager l'impression et le style entre les implémentations

val prefix : (int * change_kind) Format_doc.printer

val style : change_kind -> Misc.Style.style list

type ('left, 'right, 'eq, 'diff) change =
| Delete of 'left
| Insert of 'right
| Keep of 'left * 'right * 'eq
| Change of 'left * 'right * 'diff

val classify : ('a, 'b, 'c, 'd) change -> change_kind

module Define : (D : Defs) -> sig end

Define(Defs) crée les types de différenciation à partir des types définis dans Defs et des foncteurs qui doivent être instanciés avec les paramètres de l'algorithme de différenciation.
