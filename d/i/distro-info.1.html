DISTRO-INFO(1) Manuel des commandes générales DISTRO-INFO(1)

NOM

distro-info - fournit des informations sur les versions des distributions

SYNTAXE

distro-info [OPTIONS]

DESCRIPTION

distro-info est un lien symbolique vers la commande distro-info pour votre distribution. Sur Debian, il pointe vers debian-distro-info et sur Ubuntu vers ubuntu-distro-info. Toutes les options décrites dans cette page de manuel sont disponibles dans toutes les commandes distro-info. Toutes les autres options, non décrites ici, sont spécifiques à la distribution.

OPTIONS

--date=DATE
date pour le calcul de la version (par défaut : epoch tiré de la variable d'environnement SOURCE_DATE_EPOCH si définie, sinon aujourd'hui)
-h, --help
affiche le message d'aide et quitte
-a, --all
liste toutes les versions connues
-y[MILESTONE], --days[=MILESTONE]
affiche le nombre de jours restants avant que la version spécifiée n'atteigne le jalon spécifié. MILESTONE peut être l'un de created, release, eol, ou eol-server. Si aucun jalon n'est spécifié, suppose release. Pour les options qui renvoient une liste, affiche la sortie normale suivie d'un espace et du nombre de jours jusqu'au jalon spécifié.
-d, --devel
dernière version de développement
--series=SERIES
série pour laquelle calculer la version
-s, --stable
dernière version stable
--supported
liste de toutes les versions prises en charge, y compris les versions de développement
--unsupported
liste de toutes les versions stables non prises en charge
-c, --codename
affiche le nom de code (par défaut)
-r, --release
affiche le numéro de version
-f, --fullname
affiche le nom complet

VOIR AUSSI

debian-distro-info(1), ubuntu-distro-info(1)
