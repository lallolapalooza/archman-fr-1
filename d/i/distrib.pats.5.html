NOM

distrib.pats - Valeurs par défaut pour le champ d'en-tête Distribution

DESCRIPTION

Le fichier pathetc/distrib.pats est utilisé par nnrpd pour déterminer le corps par défaut du champ d'en-tête Distribution. Les lignes vides et les lignes commençant par un signe numéro ("#") sont ignorées. Toutes les autres lignes se composent de trois champs séparés par un deux-points :

<poids>:<motif>:<valeur>

Le premier champ est le poids à attribuer à cette correspondance. Si un groupe de nouvelles correspond à plusieurs lignes, la ligne ayant le poids le plus élevé est utilisée. Il doit s'agir d'un entier arbitraire supérieur à zéro. L'ordre des lignes dans le fichier n'est important que si les groupes ont un poids égal (auquel cas, la première ligne correspondante sera utilisée).

Le second champ est soit le nom d'un groupe de nouvelles, soit un motif de style uwildmat pour spécifier un ensemble de groupes de nouvelles.

Le troisième champ est le corps qui doit être utilisé pour le champ d'en-tête Distribution d'un article posté, si cette ligne a été choisie comme meilleure correspondance et qu'aucun champ d'en-tête Distribution n'a été fourni par l'utilisateur. Il peut s'agir d'une chaîne vide, spécifiant qu'aucun champ d'en-tête Distribution ne doit être ajouté. S'il n'est pas vide, il est préférable de n'utiliser que des caractères US-ASCII pour ce champ ; sinon, assurez-vous qu'il est encodé en UTF-8.

Lorsqu'un post est reçu par nnrpd qui ne contient pas déjà un champ d'en-tête Distribution, chaque groupe de nouvelles auquel un article est posté sera vérifié successivement dans ce fichier, et la ligne correspondante avec le poids le plus élevé sera utilisée comme corps du champ d'en-tête Distribution. Si aucune ligne ne correspond, ou si la ligne correspondante a une chaîne vide pour son troisième champ, aucun champ d'en-tête ne sera ajouté. Dans le cas où une distribution est ajoutée par nnrpd, assurez-vous qu'elle n'est pas rejetée par l'entrée "ME" de newsfeeds.

Une liste de distributions recommandées peut être spécifiée et décrite dans distributions(5).
