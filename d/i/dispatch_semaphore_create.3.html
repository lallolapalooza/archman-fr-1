NOM

dispatch_semaphore_create, dispatch_semaphore_signal, dispatch_semaphore_wait — semaphore de comptage synchronisé

SYNOPSIS

#include <dispatch/dispatch.h>

dispatch_semaphore_t
dispatch_semaphore_create(long count);

long
dispatch_semaphore_signal(dispatch_semaphore_t semaphore);

long
dispatch_semaphore_wait(dispatch_semaphore_t semaphore, dispatch_time_t timeout);

DESCRIPTION

Les sémaphores de dispatch sont utilisés pour synchroniser les threads.

La fonction dispatch_semaphore_wait() décrémente le sémaphore. Si la valeur résultante est inférieure à zéro, elle attend un signal d'un thread qui incrémente le sémaphore en appelant dispatch_semaphore_signal() avant de retourner. Le paramètre timeout est créable avec les fonctions dispatch_time(3) ou dispatch_walltime(3). Si le délai d'attente est atteint sans réception de signal, le sémaphore est ré-incrémenté avant que la fonction ne retourne.

La fonction dispatch_semaphore_signal() incrémente le sémaphore de comptage. Si la valeur précédente était inférieure à zéro, elle réveille l'un des threads qui attendent dans dispatch_semaphore_wait() avant de retourner.

SYNCHRONISATION_DE_COMPLETION

Si le paramètre count est égal à zéro, alors le sémaphore est utile pour synchroniser l'achèvement du travail. Par exemple :

sema = dispatch_semaphore_create(0);

dispatch_async(queue, ^{
	foo();
	dispatch_semaphore_signal(sema);
});

bar();

dispatch_semaphore_wait(sema, DISPATCH_TIME_FOREVER);

POULE_DE_RESSOURCES_FINIE

Si le paramètre count est supérieur à zéro, alors le sémaphore est utile pour gérer une poule de ressources finie. Par exemple, une bibliothèque qui souhaite limiter l'utilisation des descripteurs Unix :

sema = dispatch_semaphore_create(getdtablesize() / 4);

À chaque allocation de descripteur Unix :

dispatch_semaphore_wait(sema, DISPATCH_TIME_FOREVER);
fd = open("/etc/services", O_RDONLY);

Lors de la fermeture de chaque descripteur :

close(fd);
dispatch_semaphore_signal(sema);

VALEURS_DE_RETOUR

La fonction dispatch_semaphore_create() retourne NULL si aucune mémoire n'est disponible ou si le paramètre count est inférieur à zéro.

La fonction dispatch_semaphore_signal() retourne une valeur non nulle lorsqu'un thread est réveillé. Sinon, zéro est retourné.

La fonction dispatch_semaphore_wait() retourne zéro en cas de succès et une valeur non nulle après l'expiration du délai d'attente. Si le délai d'attente est DISPATCH_TIME_FOREVER, alors dispatch_semaphore_wait() attend indéfiniment et retourne toujours zéro.

MODÈLE_MÉMOIRE

Les sémaphores de dispatch sont conservés et libérés via des appels à dispatch_retain() et dispatch_release().

AVERTISSEMENTS

Les sémaphores de dispatch déséquilibrés ne peuvent pas être libérés. Pour un sémaphore donné, les appels à dispatch_semaphore_signal() et dispatch_semaphore_wait() doivent être équilibrés avant que dispatch_release() ne soit appelé sur celui-ci.
