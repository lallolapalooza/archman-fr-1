distccmon-text(1) Manuel des commandes générales distccmon-text(1)

NOM

distccmon-text - Affiche les jobs de compilation actuels sous forme de texte.

SYNTAXE

distccmon-text [DÉLAI]

DESCRIPTION

Affiche les jobs de compilation actuels sous forme de texte. distccmon-text doit être exécuté sur la machine cliente, avec le même paramètre pour DISTCC_DIR (ou le répertoire personnel) que l'utilisateur exécutant le client distcc.

OPTIONS

DÉLAI
met à jour de manière répétée après délai secondes (fractionnaire).

FORMAT DE SORTIE

La sortie de distccmon-text contient une ligne pour chaque job en cours de compilation. Chaque ligne contient les colonnes suivantes :

PID
Identifiant du processus client distcc.
ÉTAT
Identifie la phase de fonctionnement. Dans l'ordre, elles peuvent être "Startup" (Démarrage), "Blocked" (Bloqué), "Connected" (Connecté), "Preprocess" (Prétraitement), "Conect" (Connexion - *note : coquille dans l'original*), "Send" (Envoi), "Receive" (Réception) et "Done" (Terminé).
FICHIER
Le nom du fichier d'entrée, s'il est connu.
HÔTE[SLOT]
Le nom d'hôte de compilation. Peut être suivi entre crochets de l'indice de slot pour cet hôte.

Lorsqu'un délai est spécifié, chaque bloc de sortie est terminé par une ligne vide.

EXEMPLES

Pour afficher les jobs actuellement actifs (mis à jour chaque seconde) :

distccmon-text 1

Pour afficher le statut une seule fois :

distccmon-text
