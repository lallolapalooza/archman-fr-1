display(1) Manuel des commandes générales display(1)

NOM

display - affiche une image ou une séquence d'images sur n'importe quel serveur X.

SYNOPSIS

magick display [options] fichier-entrée

APERÇU

Le programme display fait partie de la suite d'outils ImageMagick(1). Utilisez-le pour afficher une image ou une séquence d'images sur n'importe quel serveur X.

Pour plus d'informations sur la commande display, dirigez votre navigateur vers file:///usr/share/doc/ImageMagick-7/www/display.html ou https://imagemagick.org/script/display.php.

DESCRIPTION

Paramètres d'image :
-alpha option on, activate, off, deactivate, set, opaque, copy
transparent, extract, background, or shape
-antialias supprimer l'anticrénelage des pixels
-authenticate value déchiffrer l'image avec ce mot de passe
-backdrop afficher l'image centrée sur un fond
-colormap type Shared or Private
-colorspace type espace colorimétrique alternatif de l'image
-comment string annoter l'image avec un commentaire
-compress type type de compression des pixels lors de l'écriture de l'image
-decipher filename convertir les pixels chiffrés en pixels en clair
-deskew threshold redresser une image
-define format:option
définir une ou plusieurs options de format d'image
-delay centiseconds afficher l'image suivante après une pause
-density geometry densité horizontale et verticale de l'image
-depth value profondeur de bits de l'image
-display server afficher l'image sur ce serveur X
-dispose method méthode de traitement des couches
-dither method appliquer une diffusion d'erreur à l'image
-endian type ordre des octets (MSB ou LSB) de l'image
-equalize effectuer une égalisation d'histogramme sur une image
-filter type utiliser ce filtre lors du redimensionnement d'une image
-format "string" afficher les caractéristiques formatées de l'image
-fuzz distance les couleurs à cette distance sont considérées comme égales
-geometry geometry taille et emplacement préférés de la fenêtre de l'image
-gravity type placement horizontal et vertical du fond
-identify identifier le format et les caractéristiques de l'image
-immutable l'image affichée ne peut pas être modifiée
-interlace type type de schéma d'entrelacement de l'image
-interpolate method méthode d'interpolation de la couleur des pixels
-label string attribuer une étiquette à une image
-limit type value limite de ressources du cache de pixels
-loop iterations boucler les images puis quitter
-map type afficher l'image en utilisant cette table de couleurs standard
-matte stocker le canal de transparence si l'image en possède un
-monitor surveiller la progression
-page geometry taille et emplacement du canevas d'une image
-profile filename ajouter, supprimer ou appliquer un profil d'image
-quality value niveau de compression JPEG/MIFF/PNG
-quantize colorspace réduire les couleurs dans cet espace colorimétrique
-quiet supprimer tous les messages d'avertissement
-regard-warnings prêter attention aux messages d'avertissement
-remote command exécuter une commande dans un processus display distant
-repage geometry taille et emplacement du canevas d'une image (opérateur)
-respect-parentheses les paramètres restent en vigueur jusqu'à la limite des parenthèses
-sampling-factor geometry
facteur d'échantillonnage horizontal et vertical
-scenes range plage de scènes de l'image
-seed value initialiser une nouvelle séquence de nombres pseudo-aléatoires
-set property value définir une propriété d'image
-size geometry largeur et hauteur de l'image
-support factor support de redimensionnement : > 1.0 est flou, < 1.0 est net
-texture filename nom de la texture à carreler sur le fond de l'image
-transparent-color color
couleur transparente
-treedepth value profondeur de l'arbre de couleurs
-update seconds détecter quand le fichier image est modifié et réafficher
-verbose afficher des informations détaillées sur l'image
-visual type afficher l'image en utilisant ce type visuel
-virtual-pixel method
méthode d'accès aux pixels virtuels
-window id afficher l'image sur l'arrière-plan de cette fenêtre
-window-group id quitter le programme quand cet identifiant de fenêtre est détruit
-write filename écrire l'image dans un fichier

Opérateurs d'image :
-auto-orient orienter automatiquement l'image
-border geometry entourer l'image d'une bordure de couleur
-channel mask définir le masque de canal de l'image
-clip découper le long du premier chemin du profil 8BIM
-clip-path id découper le long d'un chemin nommé du profil 8BIM
-colors value nombre préféré de couleurs dans l'image
-contrast améliorer ou réduire le contraste de l'image
-crop geometry taille et emplacement préférés de l'image recadrée
-despeckle réduire les taches dans une image
-edge factor appliquer un filtre pour détecter les contours de l'image
-enhance appliquer un filtre numérique pour améliorer une image bruitée
-extent geometry définir la taille de l'image
-extract geometry extraire une zone de l'image
-flip retourner l'image verticalement
-flop retourner l'image horizontalement
-frame geometry entourer l'image d'une bordure ornementale
-gamma value niveau de correction gamma
-monochrome transformer l'image en noir et blanc
-negate remplacer chaque pixel par sa couleur complémentaire
-normalize transformer l'image pour couvrir toute la plage de couleurs
-raise value éclaircir/assombrir les bords de l'image pour créer un effet 3D
-resample geometry changer la résolution d'une image
-resize geometry redimensionner l'image
-roll geometry faire défiler une image verticalement ou horizontalement
-rotate degrees appliquer une rotation Paeth à l'image
-sample geometry mettre à l'échelle l'image par échantillonnage de pixels
-segment value segmenter une image
-sharpen geometry accentuer l'image
-strip supprimer tous les profils et commentaires de l'image
-threshold value seuiller l'image
-thumbnail geometry créer une miniature de l'image
-trim recadrer les bords de l'image

Opérateurs de séquence d'images :
-coalesce fusionner une séquence d'images
-flatten aplatir une séquence d'images

Options diverses :
-debug events afficher des informations de débogage détaillées
-help afficher les options du programme
-log format format des informations de débogage
-list type afficher une liste des arguments d'options pris en charge
-version afficher les informations de version

En plus de celles listées ci-dessus, vous pouvez spécifier ces ressources X standard en tant qu'options en ligne de commande : -background, -bordercolor, -borderwidth, -font, -foreground, -iconGeometry, -iconic, -mattecolor, -name, -shared-memory, -usePixmap, ou -title.

Par défaut, le format d'image de « fichier » est déterminé par son nombre magique. Pour spécifier un format d'image particulier, faites précéder le nom de fichier d'un nom de format d'image et d'un deux-points (par exemple ps:image) ou spécifiez le type d'image comme suffixe du nom de fichier (par exemple image.ps). Spécifiez « fichier » comme « - » pour l'entrée ou la sortie standard.

Boutons :
1 appuyer pour afficher ou masquer le widget de commande
2 appuyer et faire glisser pour agrandir une région d'une image
3 appuyer pour charger une image depuis un répertoire d'images visuel

NOTE

Le programme display utilise par défaut la résolution de l'écran X. Pour afficher les formats vectoriels à leur taille prévue, remplacez la résolution par défaut :


display -density 72 drawing.svg
