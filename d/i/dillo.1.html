dillo(1) COMMANDES UTILISATEUR dillo(1)

NOM

dillo - navigateur web

SYNTAXE

dillo [OPTION]... [--] [URL|FICHIER]...

DESCRIPTION

Dillo est un navigateur web graphique léger qui vise à être sécurisé. Il gère HTTP en interne, et les URI FILE, FTP et DATA sont gérés via un système de plugins (dpi). De plus, le support HTTPS *EXPÉRIMENTAL* peut être activé. FTP et le gestionnaire de téléchargement de Dillo utilisent tous deux le téléchargeur wget(1).

Dillo affiche les fichiers HTML, texte, PNG, JPEG, GIF, SVG et WebP. Il gère les cookies, l'authentification HTTP (de base et résumé), les proxys (de base), et certains CSS.

Les framesets sont affichés comme des liens vers les frames, et il n'y a actuellement aucun support pour javascript ou la vidéo.

Afin d'utiliser la fonction de césure, les fichiers de modèles de CTAN doivent être installés dans /usr/lib/dillo/hyphenation/. Cela peut être fait avec le script dillo-install-hyphenation. Appelez-le avec des codes de langue ISO-639-1 comme arguments, ou sans arguments pour obtenir plus d'aide.

OPTIONS

-f, --fullwindow
Démarrer en mode plein écran : masquer la barre d'adresse, les boutons de navigation, le menu et la barre d'état.
-g, -geometry GEO
Définir la position initiale de la fenêtre où GEO est LxH[{+-}X{+-}Y].
-h, --help
Afficher ce texte d'aide et quitter.
-l, --local
Ne pas charger les images ou les feuilles de style, ni suivre les redirections, pour ces FICHIERs ou URL. Ceci est destiné à être utilisé avec les e-mails HTML.
-v, --version
Afficher les informations de version et quitter.
-x, --xid XID
Ouvrir la première fenêtre Dillo dans une fenêtre existante dont l'ID est XID.

STATUT DE SORTIE

0
Aucune erreur.
1
Erreur interne.
2
Erreur dans les arguments de la ligne de commande.

ENVIRONNEMENT

HOME (ou HOMEDRIVE et HOMEPATH sur Cygwin)
Répertoire personnel de l'utilisateur.
http_proxy
URL du proxy pour acheminer le trafic HTTP/HTTPS.

FICHIERS

dpid
Démon de plugin Dillo
dpidc
Programme de contrôle pour dpid.
~/.dillo/bm.txt
Signets utilisateur
~/.dillo/certs/
Certificats sauvegardés pour HTTPS.
~/.dillo/cookies.txt
Cookies stockés
~/.dillo/cookiesrc
Paramètres des cookies
~/.dillo/dillorc
Fichier de configuration.
~/.dillo/domainrc
Règles pour les requêtes inter-domaines.
~/.dillo/dpid_comm_keys
Clés utilisées dans la communication du démon dpid.
~/.dillo/dpidrc
Contient le nom du répertoire contenant les dpis, et associe les fichiers dpi aux protocoles.
~/.dillo/keysrc
Raccourcis clavier.
~/.dillo/style.css
Feuille de style utilisateur.
/usr/lib/dillo/hyphenation/
Fichiers de modèles de césure.
