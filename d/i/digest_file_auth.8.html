NOM

digest_file_auth - Aide à l'authentification par fichier de résumé pour Squid.

Version 1.1

SYNTAXE

digest_file_auth [-c] fichier

DESCRIPTION

digest_file_auth est un programme binaire d'authentification installé pour Squid. Il gère le protocole d'authentification par résumé et s'authentifie auprès d'un backend de fichier texte. Ce programme détectera automatiquement l'existence d'un identifiant de canal de concurrence et s'ajustera en conséquence. Il peut être utilisé avec n'importe quelle valeur de 0 ou supérieure pour le paramètre auth_param children concurrency=.

OPTIONS

-c
Accepte les mots de passe hachés par résumé plutôt que les mots de passe en texte clair dans le fichier de mots de passe

CONFIGURATION

Format du fichier de base de données des noms d'utilisateur :

- les lignes de commentaires sont possibles et doivent commencer par un '#';
- les lignes vides ou blanches sont possibles;
- le format d'entrée en texte clair est nom_utilisateur:mot_de_passe
- le format d'entrée HA1 est nom_utilisateur:domaine:HA1

Pour construire un backend intégré au répertoire, vous devez pouvoir calculer le HA1 renvoyé à squid. Pour éviter de stocker un mot de passe en texte clair, vous pouvez calculer MD5(nom_utilisateur:domaine:mot_de_passe) lorsque l'utilisateur change son mot de passe, et stocker le tuple nom_utilisateur:domaine:HA1. puis trouver la correspondance nom_utilisateur:domaine lorsque squid demande le HA1.

Cette implémentation pourrait être améliorée en utilisant un tel triple pour le format de fichier. Cependant, stocker un tel triple n'améliore pas beaucoup la sécurité : en cas de compromission, la combinaison nom_utilisateur:domaine:HA1 est l'équivalent du texte clair - aux fins de l'authentification par résumé, elle permet à l'utilisateur d'accéder. La synchronisation des mots de passe n'est pas abordée par le résumé - juste la prévention de la compromission sur le réseau.
