DISTROBOX-EPHEMERAL(1) Manuel utilisateur DISTROBOX-EPHEMERAL(1)

NOM

distrobox ephemeral
distrobox-ephemeral

DESCRIPTION

distrobox-ephemeral crée une distrobox temporaire qui est automatiquement détruite lorsque la commande est terminée.

SYNTAXE

distrobox ephemeral

--root/-r:      lance podman/docker/lilipod avec des privilèges root. Notez que si vous avez besoin de root, c'est la manière préférée
            plutôt que "sudo distrobox" (note : si vous utilisez un programme autre que 'sudo' pour les privilèges root,
            spécifiez-le via la variable d'environnement DBX_SUDO_PROGRAM, ou la variable de configuration 'distrobox_sudo_program')
--verbose/-v:       affiche plus de détails
--help/-h:      affiche ce message
--/-e:          termine les arguments exécute le reste comme commande à exécuter à la connexion   par défaut : shell par défaut de ${USER}
--version/-V:       affiche la version

EXEMPLES

distrobox-ephemeral --image alpine:latest -- cat /etc/os-release
distrobox-ephemeral --root --verbose --image alpine:latest --volume /opt:/opt

Vous pouvez également utiliser les options de distrobox-create pour personnaliser le conteneur éphémère à exécuter.

VOIR AUSSI

distrobox-create --help
man distrobox-create

VARIABLES ENVIRONNEMENT

distrobox-ephemeral appelle distrobox-create, VOIR AUSSI distrobox-create(1) pour
une liste des variables d'environnement prises en charge à utiliser.
