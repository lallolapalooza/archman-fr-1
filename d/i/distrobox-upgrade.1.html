DISTROBOX-UPGRADE(1) Manuel de l'utilisateur DISTROBOX-UPGRADE(1)

NOM

distrobox-upgrade

DESCRIPTION

distrobox-upgrade entrera dans la liste spécifiée de conteneurs et effectuera une mise à niveau à l'aide du gestionnaire de paquets du conteneur.

SYNTAXE

distrobox upgrade

--help/-h:      afficher ce message
--all/-a:       effectuer pour toutes les distroboxes
--running:      effectuer uniquement pour les distroboxes en cours d'exécution
--root/-r:      lancer podman/docker/lilipod avec des privilèges root. Notez que si vous avez besoin de root, c'est la méthode préférée
            au lieu de « sudo distrobox » (note : si vous utilisez un programme autre que 'sudo' pour les privilèges root,
            spécifiez-le via la variable d'environnement DBX_SUDO_PROGRAM, ou la variable de configuration 'distrobox_sudo_program')
--verbose/-v:       afficher plus de détails
--version/-V:       afficher la version

EXEMPLES

Mettre à niveau toutes les distroboxes

distrobox-upgrade --all

Mettre à niveau toutes les distroboxes en cours d'exécution

distrobox-upgrade --all --running

Mettre à niveau une distrobox spécifique

distrobox-upgrade alpine-linux

Mettre à niveau une liste de distroboxes

distrobox-upgrade alpine-linux ubuntu22 my-distrobox123

Mettre à jour automatiquement toutes les distributions

Vous pouvez créer un service systemd pour effectuer distrobox-upgrade automatiquement, cet exemple montre comment l'exécuter quotidiennement :

~/.config/systemd/user/distrobox-upgrade.service

[Unit]
Description=Mise à jour automatique de distrobox-upgrade
[Service]
Type=simple
ExecStart=distrobox-upgrade --all
StandardOutput=null

~/.config/systemd/user/distrobox-upgrade.timer

[Unit]
Description=Déclencheur de mise à jour automatique de distrobox-upgrade
[Timer]
OnBootSec=1h
OnUnitInactiveSec=1d
[Install]
WantedBy=timers.target

Ensuite, exécutez simplement systemctl --user daemon-reload && systemctl --user enable --now distrobox-upgrade.timer
