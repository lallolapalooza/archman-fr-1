div(3) Manuel des fonctions de bibliothèque div(3)

NOM

div, ldiv, lldiv, imaxdiv - calculer le quotient et le reste d'une division entière

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
div_t div(int dividende, int diviseur);
ldiv_t ldiv(long dividende, long diviseur);
lldiv_t lldiv(long long dividende, long long diviseur);
#include <inttypes.h>
imaxdiv_t imaxdiv(intmax_t dividende, intmax_t diviseur);
Exigences pour les macros de test de fonctionnalité dans glibc (voir feature_test_macros(7)) :

lldiv() :

    _ISOC99_SOURCE ou _POSIX_C_SOURCE >= 200112L

DESCRIPTION

La fonction div() calcule la valeur dividende/diviseur et renvoie le quotient et le reste dans une structure nommée div_t qui contient deux membres entiers (dans un ordre non spécifié) nommés quot et rem. Le quotient est arrondi vers zéro. Le résultat satisfait quot*diviseur+rem = dividende.

Les fonctions ldiv(), lldiv() et imaxdiv() font de même, divisant des nombres du type indiqué et renvoyant le résultat dans une structure du nom indiqué, dans tous les cas avec des champs quot et rem du même type que les arguments de la fonction.

VALEUR RENVOYÉE

La structure div_t (etc.).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
div (), ldiv (), lldiv (), imaxdiv () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C89, C99, SVr4, 4.3BSD.

lldiv() et imaxdiv() ont été ajoutés en C99.

EXEMPLES

Après


div_t q = div(-5, 3);

les valeurs q.quot et q.rem sont respectivement -1 et -2.

VOIR AUSSI

abs(3), remainder(3)
