DIRNAME(3P) Manuel du programmeur POSIX DIRNAME(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

dirname — signaler le nom du répertoire parent d'un chemin de fichier

SYNOPIS

#include <libgen.h>
char *dirname(char *path);

DESCRIPTION

La fonction dirname() prend un pointeur vers une chaîne de caractères contenant un chemin, et retourne un pointeur vers une chaîne qui est un chemin du répertoire parent de ce fichier. La fonction dirname() ne résout pas le chemin ; le résultat n'est pas affecté par l'existence ou le type de fichier de path. Les caractères '/' finaux dans le chemin qui ne sont pas aussi des caractères '/' initiaux ne sont pas comptés comme faisant partie du chemin.

Si path ne contient pas de '/', alors dirname() retourne un pointeur vers la chaîne ".". Si path est un pointeur nul ou pointe vers une chaîne vide, dirname() retourne un pointeur vers la chaîne ".".

La fonction dirname() peut modifier la chaîne pointée par path, et peut retourner un pointeur vers une mémoire statique qui peut ensuite être écrasée par un appel ultérieur à dirname().

La fonction dirname() n'est pas nécessairement thread-safe.

VALEUR DE RETOUR

La fonction dirname() retourne un pointeur vers une chaîne comme décrit ci-dessus.

La fonction dirname() peut modifier la chaîne pointée par path, et peut retourner un pointeur vers une mémoire interne. Le pointeur retourné peut être invalidé ou la mémoire peut être écrasée par un appel ultérieur à dirname(). Le pointeur retourné peut également être invalidé si le thread appelant est terminé.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Le fragment de code suivant lit un chemin, change le répertoire de travail courant vers le répertoire parent, et ouvre le fichier.

char *path = NULL, *pathcopy;
size_t buflen = 0;
ssize_t linelen = 0;
int fd;
linelen = getline(&path, &buflen, stdin);
path[linelen-1] = 0;
pathcopy = strdup(path);
if (chdir(dirname(pathcopy)) < 0) {
    ...
}
if ((fd = open(basename(path), O_RDONLY)) >= 0) {
    ...
    close (fd);
}
...
free (pathcopy);
free (path);

La section EXEMPLES de la fonction basename() (voir basename()) inclut un tableau montrant les résultats du traitement de plusieurs chemins exemples par les fonctions basename() et dirname() ainsi que par les utilitaires basename et dirname.

UTILISATION PAR L'APPLICATION

Les fonctions dirname() et basename() ensemble produisent un chemin complet. L'expression dirname(path) obtient le chemin du répertoire où basename(path) est trouvé.

Comme le sens des "//" initiaux est dépendant de l'implémentation, dirname("//foo) peut retourner soit "//" soit '/' (mais rien d'autre).
