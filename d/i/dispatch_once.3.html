dispatch_once(3) Manuel des fonctions de bibliothèque dispatch_once(3)

NOM

dispatch_once — exécute un bloc une seule fois

SYNTAXE

#include <dispatch/dispatch.h>

void
dispatch_once(dispatch_once_t *predicate, void (^block)(void));

void
dispatch_once_f(dispatch_once_t *predicate, void *context, void (*function)(void *));

DESCRIPTION

La fonction dispatch_once() fournit un mécanisme simple et efficace pour exécuter un initialiseur exactement une fois, similaire à pthread_once(3). Un code bien conçu masque l'utilisation de l'initialisation paresseuse. Par exemple :

FILE *getlogfile(void)
{
	static dispatch_once_t pred;
	static FILE *logfile;

	dispatch_once(&pred, ^{
		logfile = fopen(MY_LOG_FILE, "a");
	});

	return logfile;
}

FONDAMENTAUX

La fonction dispatch_once() est une enveloppe autour de dispatch_once_f().
