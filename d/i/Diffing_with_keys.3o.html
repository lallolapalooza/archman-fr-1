Lors de la comparaison de listes où chaque élément possède une clé distincte, nous pouvons affiner le correctif de comparaison en introduisant deux mouvements d'édition composites : les échanges et les déplacements.

Les échanges (Swap) échangent la position de deux éléments. Le coût d'un échange est défini à 2 * changement - epsilon. Les déplacements (Move) changent la position d'un élément. Le coût d'un déplacement est défini à suppression + ajout - epsilon.

Lorsque le coût suppression + ajout est supérieur à changement et avec ces poids spécifiques, le correctif optimal avec des échanges et des déplacements peut être calculé directement et à moindre coût à partir du correctif optimal d'origine.

type 'a with_pos = {
pos : int ;
data : 'a ;
}

val with_pos : 'a list -> 'a with_pos list

type ('l, 'r, 'diff) mismatch =
| Name of {
pos : int ;
got : string ;
expected : string ;
types_match : bool ;
}
| Type of {
pos : int ;
got : 'l ;
expected : 'r ;
reason : 'diff ;
}

type ('l, 'r, 'diff) change =
| Change of ('l, 'r, 'diff) mismatch
| Swap of {
pos : int * int ;
first : string ;
last : string ;
}
| Move of {
name : string ;
got : int ;
expected : int ;
}
| Insert of {
pos : int ;
insert : 'r ;
}
| Delete of {
pos : int ;
delete : 'l ;
}

Cette version spécialisée des changements introduit deux changements composites : Move (Déplacer) et Swap (Échanger).
