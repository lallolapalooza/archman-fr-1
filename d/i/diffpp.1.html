NOM

diffpp - imprimer joliment les sorties de diff avec GNU enscript

SYNTAXE

diffpp fichier_courant < fichier_diff

DESCRIPTION

Diffpp convertit les fichiers de sortie du programme diff(1) dans un format adapté à l'impression avec GNU enscript(1). Le programme annote les modifications avec les échappements spéciaux d'enscript, de sorte qu'enscript puisse mettre en évidence les portions modifiées du fichier. Toutes les lignes modifiées et ajoutées sont imprimées avec un fond gris, les lignes supprimées sont marquées avec des caractères moins (`-') ; diffpp imprime un caractère moins pour chaque ligne supprimée.

EXEMPLES

La manière la plus simple d'utiliser diffpp est de l'utiliser comme un filtre d'entrée pour enscript. Si un filtre d'entrée est spécifié pour enscript, il est utilisé pour prétraiter le flux de données entrant. Le filtrage ne modifie aucune chaîne d'en-tête ni aucune estampille temporelle de fichier qui pourrait être imprimée dans les en-têtes d'enscript ; seules les données entrantes sont modifiées.

enscript -G2re --filter='rcsdiff %s | diffpp %s' *.c *.h
Imprimer les modifications entre les fichiers source actuels et leurs dernières versions RCS.
enscript -G2re --filter='diff %s~ %s | diffpp %s' *.c *.h
Imprimer les modifications entre les fichiers source et les fichiers de sauvegarde correspondants.
