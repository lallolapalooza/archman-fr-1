NOM

distrobox-host-exec

DESCRIPTION

distrobox-host-exec permet d'exécuter une commande sur l'hôte, tout en étant à l'intérieur d'un conteneur.

En coulisses, distrobox-host-exec utilise host-spawn, un projet qui permet d'exécuter des commandes sur l'hôte. Si l'outil n'est pas trouvé, l'utilisateur sera invité à l'installer.

SYNTAXE

Passez simplement à « distrobox-host-exec » n'importe quelle commande et tous ses arguments, s'il y en a.

--help/-h :      affiche ce message
--verbose/-v :       affiche plus de détails
--version/-V :       affiche la version
--yes/-Y :       Répond automatiquement oui à la demande :
                            host-spawn sera installé sur le système invité
                            si host-spawn n'est pas détecté.
                            Ce comportement est par défaut lors de l'exécution dans un shell non interactif.

Si aucune commande n'est fournie, elle exécutera « $SHELL ».

Alternativement, vous pouvez créer un lien symbolique d'une commande nommée vers distrobox-host-exec et ensuite appeler cette commande par son nom sur l'hôte, tout en étant à l'intérieur d'un conteneur.

EXEMPLES

Exécuter des commandes individuelles

distrobox-host-exec ls
distrobox-host-exec bash -l
distrobox-host-exec flatpak run org.mozilla.firefox
distrobox-host-exec podman ps -a

Se connecter au shell de l'hôte

~$: distrobox-host-exec # Pas de commande, exécute "$SHELL" sur l'hôte
~$: distrobox-host-exec # Cette commande s'exécute maintenant sur l'hôte
You must run  distrobox-host-exec inside a container!

Lien symbolique des commandes de l'hôte

Utilisez le nom de la commande de l'hôte pour créer un lien symbolique vers distrobox-host-exec. Vous pouvez ensuite appeler la commande de l'hôte depuis l'intérieur du conteneur.

~$: git # Nous n'avons pas git dans le conteneur
bash: git: commande introuvable
~$: sudo ln -s /usr/bin/distrobox-host-exec /usr/local/bin/git
~$: git version
git version 2.51.1

Vous pouvez contrôler podman sur l'hôte depuis l'intérieur du conteneur comme suit :

~$: ln -s /usr/bin/distrobox-host-exec /usr/local/bin/podman
~$: ls -l /usr/local/bin/podman
lrwxrwxrwx. 1 root root 51 Jul 11 19:26 /usr/local/bin/podman -> /usr/bin/distrobox-host-exec
~$: podman version
...cela s'exécute sur l'hôte...
