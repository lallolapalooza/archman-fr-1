DISTROBOX-RM(1) Manuel utilisateur DISTROBOX-RM(1)

NOM

distrobox rm
distrobox-rm

DESCRIPTION

distrobox-rm supprime l'une des distributions disponibles.

SYNTAXE

distrobox rm

--all/-a:       supprime toutes les distroboxes
--force/-f:     force la suppression
--rm-home:      supprime le dossier personnel monté s'il diffère de celui de l'utilisateur hôte
--root/-r:      lance podman/docker/lilipod avec les privilèges root. Notez que si vous avez besoin des privilèges root, c'est la manière préférée
            plutôt que "sudo distrobox" (note : si un programme autre que 'sudo' est nécessaire pour les privilèges root,
            spécifiez-le via la variable d'environnement DBX_SUDO_PROGRAM, ou la variable de configuration 'distrobox_sudo_program')
--help/-h:      affiche ce message
--verbose/-v:       affiche plus de détails
--version/-V:       affiche la version

EXEMPLES

distrobox-rm nom-du-conteneur [--force] [--all]

Vous pouvez également utiliser les variables d'environnement pour spécifier le gestionnaire de conteneur et le nom :

DBX_CONTAINER_MANAGER="docker" DBX_CONTAINER_NAME=test-alpine distrobox-rm

VARIABLES D'ENVIRONNEMENT

DBX_CONTAINER_MANAGER
DBX_CONTAINER_NAME
DBX_NON_INTERACTIVE
DBX_SUDO_PROGRAM
