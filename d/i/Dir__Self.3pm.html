Dir::Self(3) Documentation Perl fournie par l'utilisateur Dir::Self(3)

NOM

Dir::Self - une constante __DIR__ pour le répertoire de votre fichier source

SYNOPSIS

use Dir::Self;

use lib __DIR__ . "/lib";

my $conffile = __DIR__ . "/config";

DESCRIPTION

Perl possède deux pseudo-constantes décrivant l'emplacement actuel dans votre code source, "__FILE__" et "__LINE__". Ce module ajoute "__DIR__", qui s'étend au répertoire où se trouve votre fichier source, sous forme de chemin absolu.

Ceci est utile si votre code souhaite accéder à des fichiers dans le même répertoire, comme des modules d'aide ou des données de configuration. C'est un peu comme FindBin sauf que ce n'est pas limité au programme principal, c'est-à-dire que vous pouvez également l'utiliser dans des modules. Et cela fonctionne réellement.

Depuis la version 0.10, chaque utilisation de "__DIR__" recalcule le nom du répertoire ; cela garantit que les fichiers dans des répertoires différents partageant le même nom de paquet obtiennent des résultats corrects. Si vous ne souhaitez pas cela, "use Dir::Self qw(:static)" créera une véritable constante "__DIR__" dans votre paquet qui contiendra le nom du répertoire au moment de l'"use".
