DIFFUSE(1) Manuel Diffuse DIFFUSE(1)

NOM

diffuse - outil graphique pour la fusion et la comparaison de fichiers texte

SYNTAXE

diffuse [-h | -? | --help | -v | --version]

diffuse [--no-rcfile | --rcfile fichier] [[option...] | [fichier...]...]

DESCRIPTION

Diffuse est un outil graphique pour la fusion et la comparaison de fichiers texte. Diffuse est capable de comparer un nombre arbitraire de fichiers côte à côte et donne aux utilisateurs la capacité d'ajuster manuellement la mise en correspondance des lignes et d'éditer directement les fichiers. Diffuse peut également récupérer des révisions de fichiers depuis les dépôts Bazaar, CVS, Darcs, Git, Mercurial, Monotone, RCS et Subversion pour la comparaison et la fusion.

OPTIONS

Options d'aide

Si une option d'aide est spécifiée, elle doit être le seul argument spécifié sur la ligne de commande. Diffuse quittera immédiatement après avoir affiché les informations d'aide.

-h, -?, --help

Affiche les informations d'utilisation.

-v, --version

Affiche le numéro de version et les informations de copyright.

Options de configuration

Si une option de configuration est spécifiée, elle doit être le premier argument spécifié sur la ligne de commande.

--no-rcfile

Ne lit aucun fichier d'initialisation.

--rcfile fichier

Ne lit les commandes d'initialisation que depuis le fichier fichier.

Options générales

-c, --commit rev

Ouvre des onglets de comparaison de fichiers séparés pour tous les fichiers affectés par le commit rev à partir des chemins restants spécifiés dans les arguments de la ligne de commande.

-D, --close-if-same

Ferme tous les onglets sans différences.

-e, --encoding codec

Utilise codec pour lire et écrire des fichiers.

-L, --label étiquette

Affiche étiquette au lieu du nom du fichier.

-m, --modified

Ouvre des onglets de comparaison de fichiers séparés pour tous les fichiers modifiés à partir des chemins restants spécifiés dans les arguments de la ligne de commande.

-r, --revision rev

Inclut la révision rev du prochain fichier nommé dans les arguments de la ligne de commande dans un onglet de comparaison de fichiers.

-s, --separate

Ouvre tous les fichiers restants spécifiés dans les arguments de la ligne de commande dans des onglets de comparaison de fichiers séparés.

-t, --tab

Démarre un nouvel onglet pour tous les fichiers restants nommés dans les arguments de la ligne de commande.

-V, --vcs vcs-list

Recherche les systèmes de contrôle de version dans l'ordre : vcs-list.

--line ligne

Commence avec la ligne ligne sélectionnée.

--null-file

Crée un panneau de comparaison de fichiers vide.

Options d'affichage

Les options d'affichage spécifiées dans les arguments de la ligne de commande remplaceront les valeurs de préférence enregistrées.

-b, --ignore-space-change

Ignore les changements dans la quantité d'espaces blancs.

-B, --ignore-blank-lines

Ignore les changements dont les lignes sont toutes vides.

-E, --ignore-end-of-line

Ignore les différences de fin de ligne.

-i, --ignore-case

Ignore les différences de casse dans le contenu des fichiers.

-w, --ignore-all-space

Ignore tous les espaces blancs.

COMPARAISON DE FICHIERS

Utilisez les éléments de menu Fichier → Nouvelle fusion de fichiers à 2 voies, Fichier → Nouvelle fusion de fichiers à 3 voies et Fichier → Nouvelle fusion de fichiers N voies pour créer des onglets supplémentaires pour la comparaison de fichiers texte. Les noms de fichiers et les révisions peuvent être spécifiés soit dans les arguments de la ligne de commande utilisés pour invoquer Diffuse, soit dans les champs de la boîte de dialogue Ouvrir un fichier.

Diffuse affiche les fichiers côte à côte en insérant des espaces pour aligner les lignes de texte similaires. Les différences sont mises en évidence avec une couleur d'arrière-plan différente.

Résumé de la comparaison

Un résumé des fichiers comparés se trouve dans la marge droite. Le résumé illustre où des espaces ont été insérés pour aligner les lignes de texte correspondantes et met en évidence les différences à l'aide de couleurs. Les modifications manuelles sont également mises en évidence en vert. Un curseur bleu identifie la région actuellement visualisée. La région visualisée peut être modifiée en cliquant n'importe où sur le résumé.

Sélection

Les lignes de texte peuvent être sélectionnées à l'aide du pointeur de la souris ou du clavier. Sélectionnez les lignes de texte avec le pointeur de la souris en cliquant sur une ligne. Cliquez et faites glisser pour sélectionner plusieurs lignes. Maintenir la touche Maj enfoncée lors du clic étendra la sélection actuelle. Sélectionnez les lignes à l'aide du clavier en appuyant sur les touches Page Haut/Bas ou les touches fléchées. Étendez la sélection actuelle en maintenant la touche Maj enfoncée et en appuyant sur les touches Page Haut/Bas ou les touches fléchées. Déplacez la sélection vers un fichier adjacent à l'aide des touches fléchées gauche et droite.

Mise en correspondance des lignes

Le pointeur de la souris ou le clavier peuvent être utilisés pour aligner manuellement les lignes de texte avec les fichiers adjacents. Pour aligner les lignes de texte à l'aide du pointeur de la souris, sélectionnez une ligne de texte avec le bouton gauche de la souris, cliquez avec le bouton droit sur une ligne de texte d'un fichier adjacent, et choisissez Aligner avec la sélection. Pour aligner les lignes de texte à l'aide du clavier, déplacez la sélection avec les touches du curseur, appuyez sur la barre d'espace pour sélectionner la ligne de texte actuelle, déplacez la sélection avec les touches du curseur vers une ligne de texte dans un fichier adjacent, et appuyez sur la barre d'espace pour sélectionner la ligne de texte cible. Appuyer sur la touche Échap annulera l'opération.

Utilisez l'élément de menu Isoler pour empêcher les lignes sélectionnées d'être mises en correspondance avec des lignes des fichiers adjacents.

Édition

Appuyez sur la touche Entrée ou double-cliquez sur une zone de texte pour entrer en mode d'édition de texte. Le curseur changera pour indiquer le mode d'édition de texte et la barre d'état en bas de la fenêtre affichera la position de la colonne du curseur.

En mode d'édition de texte, le texte peut être sélectionné avec le pointeur de la souris en cliquant et en faisant glisser. La sélection actuelle peut être étendue en maintenant la touche Maj enfoncée et en déplaçant le curseur en cliquant avec le pointeur de la souris ou en appuyant sur l'une des touches fléchées, Inicio, Fin, Page Haut/Bas. Les mots individuels peuvent être sélectionnés en double-cliquant dessus avec le pointeur de la souris. Les lignes entières peuvent être sélectionnées en tripe-cliquant dessus avec le pointeur de la souris.

Modifiez le texte en tapant sur le clavier. Les lignes modifiées seront mises en évidence en vert. Utilisez les éléments de menu Annuler et Rétablir pour annuler et rétablir les opérations précédemment effectuées.

Appuyez sur la touche Échap ou cliquez sur la zone de texte d'un autre fichier à l'aide du bouton gauche de la souris pour quitter le mode d'édition.

Fusion

Utilisez les boutons de différence ou les éléments de menu pour naviguer entre les blocs de différences dans un fichier. Lors de la navigation, Diffuse déplacera la sélection vers le prochain ensemble continu de lignes présentant des différences ou des modifications.

Utilisez les boutons de fusion ou les éléments de menu pour copier des blocs de texte dans la plage sélectionnée de lignes. Les éléments de menu Annuler et Rétablir peuvent être utilisés pour annuler et rétablir les opérations précédemment effectuées. Toutes les modifications apportées à un ensemble de lignes peuvent être annulées à l'aide de l'élément de menu Effacer les modifications, quel que soit l'ordre dans lequel les modifications ont été apportées.

CONTRÔLE DE

VERSION

Diffuse peut récupérer les révisions de fichiers depuis plusieurs systèmes de contrôle de version via leur interface en ligne de commande. La version Microsoft Windows de Diffuse est capable d'utiliser à la fois les versions Cygwin et natives des systèmes de contrôle de version pris en charge. Lors de l'utilisation de Diffuse avec Cygwin, assurez-vous que les préférences Cygwin de Diffuse décrivent correctement votre système. Si la préférence « Update paths for Cygwin » existe pour un système de contrôle de version, elle doit être activée pour utiliser la version

Cygwin.

Les systèmes de contrôle de version sont sensibles au chemin du système et aux autres paramètres de variables d'environnement. La préférence « Launch from a Bash login shell » peut être utilisée pour définir facilement l'environnement pour les systèmes de contrôle de version

Cygwin.

Coloration syntaxique

syntax nom [état_initial balise_par_défaut]

Déclare un nouveau style de coloration syntaxique appelé nom. La coloration syntaxique utilise une machine à états simple qui transitionne entre des états lorsque certains motifs sont appariés. L'état initial de la machine à états sera état_initial. Tous les caractères non appariés par un motif seront balisés comme balise_par_défaut pour la coloration. Le style de coloration syntaxique appelé nom peut être supprimé en omettant état_initial et balise_par_défaut.

syntax_files nom [motif]

Spécifie que les fichiers dont le nom correspond à motif doivent être colorés en utilisant le style de coloration syntaxique appelé nom. Les motifs utilisés pour apparier les fichiers à utiliser avec le style de coloration syntaxique appelé nom peuvent être supprimés en omettant motif.

syntax_magic nom [motif [ignorecase]]

Spécifie que les fichiers dont la première ligne correspond à motif doivent être colorés en utilisant le style de coloration syntaxique appelé nom. Les motifs utilisés pour apparier les fichiers à utiliser avec le style de coloration syntaxique appelé nom peuvent être supprimés en omettant motif.

syntax_pattern nom état_initial état_final balise motif [ignorecase]

Ajoute un motif au style de coloration syntaxique précédemment déclaré. Les motifs sont essayés un à la fois dans l'ordre où ils ont été déclarés jusqu'à ce que la première correspondance soit trouvée. Un motif ne sera utilisé pour apparier des caractères que si la machine à états est dans l'état état_initial. La machine à états transitionnera vers état_final si le motif défini par motif est apparié. L'appariement de motifs insensible à la casse sera utilisé si ignorecase est spécifié. Tous les caractères appariés par le motif seront balisés comme balise pour la coloration.

vos préférences enregistrées (%HOME%\.config\diffuse\prefs sur Microsoft Windows)

~/.local/share/diffuse/state

données persistantes entre les sessions (%HOME%\.local\share\diffuse\state sur Microsoft Windows)
