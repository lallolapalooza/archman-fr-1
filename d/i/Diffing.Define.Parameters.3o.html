type update_result

val weight : Diffing.Define.change -> int

weight ch retourne le poids du changement ch. Utilisé pour trouver le plus petit patch.

val test : D.state -> D.left -> D.right -> (D.eq, D.diff) result

test st xl xr teste si les éléments xl et xr sont compatibles ( Ok ) ou non ( Error ).

val update : Diffing.Define.change -> D.state -> update_result

update ch st retourne le nouvel état après application d'un changement. Le type update_result contient également les expansions dans le cas variadique.
