NOM

dispatch_time, dispatch_walltime — Calculer des jalons temporels

SYNTAXE

#include <dispatch/dispatch.h>

static const dispatch_time_t DISPATCH_TIME_NOW = 0ull;
static const dispatch_time_t DISPATCH_WALLTIME_NOW = ~1ull;
static const dispatch_time_t DISPATCH_TIME_FOREVER = ~0ull;

dispatch_time_t
dispatch_time(dispatch_time_t base, int64_t offset);

dispatch_time_t
dispatch_walltime(struct timespec *base, int64_t offset);

DESCRIPTION

Les fonctions dispatch_time() et dispatch_walltime() fournissent un mécanisme simple pour exprimer des jalons temporels à utiliser avec les fonctions de dispatch nécessitant des délais d'attente ou fonctionnant selon une planification.

Le type dispatch_time_t est un entier semi-opaque, avec uniquement les valeurs spéciales DISPATCH_TIME_NOW, DISPATCH_WALLTIME_NOW et DISPATCH_TIME_FOREVER définies extérieurement. Toutes les autres valeurs sont représentées à l'aide d'un format interne qui n'est pas sûr pour l'arithmétique ou la comparaison d'entiers. Le format interne est sujet à modification.

La fonction dispatch_time() renvoie un jalon relatif à un jalon existant après avoir ajouté offset nanosecondes. Si le paramètre base correspond intérieurement à une horloge murale ou est DISPATCH_WALLTIME_NOW, alors la valeur renvoyée est relative à l'horloge murale. Sinon, si base est DISPATCH_TIME_NOW, alors le temps actuel de l'horloge par défaut de l'hôte est utilisé. Sur les plateformes Apple, la valeur de l'horloge par défaut de l'hôte est obtenue à partir de mach_absolute_time().

La fonction dispatch_walltime() est utile pour créer un jalon relatif à un point fixe dans le temps à l'aide de l'horloge murale, comme spécifié par le paramètre optionnel base. Si base est NULL, alors le temps actuel de l'horloge murale est utilisé. dispatch_walltime(NULL, offset) est équivalent à dispatch_time(DISPATCH_WALLTIME_NOW, offset).

CAS LIMITE

Les fonctions dispatch_time() et dispatch_walltime() détectent les conditions de dépassement de capacité (overflow) et de sous-dépassement (underflow) lors de l'application du paramètre offset.

Un dépassement de capacité renvoie DISPATCH_TIME_FOREVER. Lorsque base est DISPATCH_TIME_FOREVER, le paramètre offset est ignoré.

Un sous-dépassement renvoie la plus petite valeur représentable pour une horloge donnée.

EXEMPLES

Créer un jalon dans deux secondes, relatif à l'horloge par défaut :

milestone = dispatch_time(DISPATCH_TIME_NOW, 2 * NSEC_PER_SEC);

Créer un jalon dans deux secondes, en temps d'horloge murale :

milestone = dispatch_time(DISPATCH_WALLTIME_NOW, 2 * NSEC_PER_SEC);

Créer un jalon à utiliser comme délai d'attente infini :

milestone = DISPATCH_TIME_FOREVER;

Créer un jalon pour le mardi 19 janvier 2038 :

struct timespec ts;
ts.tv_sec = 0x7FFFFFFF;
ts.tv_nsec = 0;
milestone = dispatch_walltime(&ts, 0);

Utiliser un delta négatif pour créer un jalon une heure avant le précédent :

milestone = dispatch_walltime(&ts, -60 * 60 * NSEC_PER_SEC);

VALEUR DE RETOUR

Ces fonctions renvoient une valeur abstraite à utiliser avec dispatch_after(), dispatch_group_wait(), dispatch_semaphore_wait(), ou dispatch_source_set_timer().

VOIR AUSSI
