NOM

dictunformat - créer un fichier de base de données brut à partir d'un fichier .dict et .index

SYNTAXE

dictunformat [OPTIONS] nom_fichier_index

DESCRIPTION

dictunformat prend un fichier d'index de dictionnaire en paramètre et un fichier de base de données de dictionnaire sur l'entrée standard et génère une base de données brute qui peut être utilisée pour créer une base de données DICT par dictfmt -t. Ceci peut être utile si l'on souhaite créer un dictionnaire pour une locale différente de celle pour laquelle l'original a été créé, ou si l'on souhaite corriger ou compléter un dictionnaire préexistant.

OPTIONS

--help
affiche un message d'utilisation et quitte.
--headword-separator sep
sep est le séparateur de mots-clés utilisé lors de la création du dictionnaire original. (Voir --headword-separator dans dictfmt (1)).
nom_fichier_index
est le fichier .index du dictionnaire original.
