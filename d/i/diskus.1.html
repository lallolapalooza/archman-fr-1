DISKUS(1) Manuel des commandes générales DISKUS(1)

NOM

diskus - Calculer l'utilisation du disque pour les entrées de système de fichiers données

SYNTAXE

diskus [OPTIONS] [chemin...]

OPTIONS

-j, --threads <N>
Définir le nombre de threads (par défaut : 3 x nombre de cœurs)
--size-format <type>
Format de sortie pour les tailles de fichiers (décimal : MB, binaire : MiB) [par défaut : décimal] [valeurs possibles : decimal, binary]
-v, --verbose
Ne pas masquer les erreurs de système de fichiers
-b, --apparent-size
Calculer la taille apparente au lieu de l'utilisation du disque
-h, --help
Affiche les informations d'aide
-V, --version
Affiche les informations de version

ARGUMENTS

<chemin>...
Liste des chemins de système de fichiers
