DISTROBOX-STOP(1) Manuel utilisateur DISTROBOX-STOP(1)

NOM

distrobox stop
distrobox-stop

DESCRIPTION

distrobox-stop arrête une distrobox en cours d'exécution.

Les Distroboxes sont laissées en cours d'exécution, même après en être sorti, afin que les entrées ultérieures soient vraiment rapides. C'est ainsi qu'elles peuvent être arrêtées.

SYNTAXE

distrobox stop

--all/-a:       arrête toutes les distroboxes
--yes/-Y:       non interactif, arrête sans demander
--help/-h:      affiche ce message
--root/-r:      lance podman/docker/lilipod avec les privilèges root. Notez que si vous avez besoin de privilèges root, c'est la méthode préférée
            plutôt que "sudo distrobox" (note : si vous utilisez un programme autre que 'sudo' pour les privilèges root,
            spécifiez-le via la variable d'environnement DBX_SUDO_PROGRAM, ou la variable de configuration 'distrobox_sudo_program')
--verbose/-v:       affiche plus de détails (verbeux)
--version/-V:       affiche la version

EXEMPLES

distrobox-stop nom-conteneur1 nom-conteneur2
distrobox-stop nom-conteneur
distrobox-stop --all

Vous pouvez également utiliser des variables d'environnement pour spécifier le gestionnaire de conteneur et le nom :

DBX_CONTAINER_MANAGER="docker" DBX_CONTAINER_NAME=test-alpine distrobox-stop

VARIABLES ENVIRONNEMENT

DBX_CONTAINER_MANAGER
DBX_CONTAINER_NAME
DBX_NON_INTERACTIVE
DBX_SUDO_PROGRAM
