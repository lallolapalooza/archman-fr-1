DISTROBOX-LIST(1) Manuel utilisateur DISTROBOX-LIST(1)

NOM

distrobox list
distrobox-list

DESCRIPTION

distrobox-list liste les distroboxes disponibles. Il les détecte et les liste séparément des autres conteneurs normaux.

SYNTAXE

distrobox list

--help/-h:      afficher ce message
--no-color:     désactiver le formatage des couleurs
--root/-r:      lancer podman/docker/lilipod avec les privilèges root. Notez que si vous avez besoin de root, c'est la méthode préférée
            plutôt que « sudo distrobox » (note : si vous utilisez un programme autre que « sudo » pour les privilèges root,
            spécifiez-le via la variable d'environnement DBX_SUDO_PROGRAM, ou la variable de configuration 'distrobox_sudo_program')
--verbose/-v:       afficher plus de détails
--version/-V:       afficher la version

EXEMPLES

distrobox-list

Vous pouvez également utiliser des variables d'environnement pour spécifier le gestionnaire de conteneurs

DBX_CONTAINER_MANAGER="docker" distrobox-list

VARIABLES D'ENVIRONNEMENT

DBX_CONTAINER_MANAGER
DBX_SUDO_PROGRAM
[IMAGE: image] image
