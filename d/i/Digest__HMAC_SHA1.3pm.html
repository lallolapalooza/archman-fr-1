Digest__HMAC_SHA1(3pm)

Paquet: perl-digest-hmac

Licences: PerlArtistic

Digest::HMAC_SHA1(3) Documentation Perl fournie par la communauté Digest::HMAC_SHA1(3)

NOM

Digest::HMAC_SHA1 - Hachage clé pour l'authentification de messages

SYNTAXE

# Style fonctionnel
use Digest::HMAC_SHA1 qw(hmac_sha1 hmac_sha1_hex);
$digest = hmac_sha1($data, $key);
print hmac_sha1_hex($data, $key);
# Style objet
use Digest::HMAC_SHA1;
$hmac = Digest::HMAC_SHA1->new($key);
$hmac->add($data);
$hmac->addfile(*FILE);
$digest = $hmac->digest;
$digest = $hmac->hexdigest;
$digest = $hmac->b64digest;

DESCRIPTION

Ce module fournit le hachage HMAC-SHA-1.

VOIR AUSSI

Digest::HMAC, Digest::SHA, Digest::HMAC_MD5
