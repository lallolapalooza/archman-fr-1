NOM

distrobox-export

DESCRIPTION

Exportation d'applications et de binaires

distrobox-export s'occupe d'exporter une application ou un binaire du conteneur vers l'hôte.

L'application exportée sera facilement disponible dans votre lanceur normal et sera automatiquement lancée depuis le conteneur dont elle est exportée.

SYNTAXE

distrobox-export

--app/-a:       nom de l'application à exporter ou chemin absolu vers le fichier .desktop à exporter
--bin/-b:       chemin absolu du binaire à exporter
--list-apps:        lister les applications exportées de ce conteneur
--list-binaries     lister les binaires exportés de ce conteneur, utiliser -ep pour spécifier des chemins personnalisés à rechercher
--delete/-d:        supprimer l'application ou le binaire exporté
--export-label/-el: libellé à ajouter au nom de l'application exportée.
            Utiliser "none" pour désactiver.
            Par défaut (sur \$nom_conteneur)
--export-path/-ep:  chemin où exporter le binaire
--extra-flags/-ef:  indicateurs supplémentaires à ajouter à la commande
--enter-flags/-nf:  indicateurs à ajouter à distrobox-enter
--sudo/-S:      spécifier si l'élément exporté doit être exécuté avec sudo
--help/-h:      afficher ce message
--verbose/-v:       afficher plus de détails
--version/-V:       afficher la version

Vous voudrez peut-être installer des applications graphiques ou des outils CLI dans votre distrobox. Utiliser distrobox-export depuis l'intérieur du conteneur vous permettra de les utiliser directement depuis l'hôte.

EXEMPLES

distrobox-export --app mpv [--extra-flags "indicateurs"] [--delete] [--sudo]
distrobox-export --bin /chemin/vers/bin [--export-path ~/.local/bin] [--extra-flags "indicateurs"] [--delete] [--sudo]

Exemple d'exportation d'application

distrobox-export --app abiword

Cet outil copiera simplement les fichiers .desktop originaux ainsi que les icônes nécessaires, ajoutera le préfixe /usr/local/bin/distrobox-enter -n nom_distrobox -e ... aux commandes à exécuter, et les enregistrera dans votre répertoire personnel pour être utilisés directement depuis l'hôte comme une application normale.

distrobox-export --app /opt/application/mon-app.desktop

Ceci ignorera la recherche du fichier desktop dans les chemins canoniques et utilisera simplement le chemin de fichier fourni.

Exemple d'exportation de binaire

distrobox-export --bin /usr/bin/code --extra-flags "--foreground" --export-path $HOME/.local/bin

Dans le cas de l'exportation de binaires, vous devrez spécifier où l'exporter (--export-path) et l'outil créera un petit script wrapper qui exécutera distrobox-enter -e depuis l'hôte, le binaire désiré. Cela peut être utile avec l'utilisation de direnv pour avoir différentes versions du même binaire basées sur votre env ou projet.

Les binaires exportés seront exportés dans le répertoire “–export-path” choisi sous forme de script wrapper qui agit naturellement à la fois sur l'hôte et dans le conteneur.

Indicateurs supplémentaires

Vous pouvez spécifier des indicateurs supplémentaires à ajouter à la commande, par exemple si vous souhaitez exporter une application electron, vous pourriez ajouter l'indicateur “–foreground” à la commande :

distrobox-export --app atom --extra-flags "--foreground"
distrobox-export --bin /usr/bin/vim --export-path ~/.local/bin --extra-flags "-p"

Cela fonctionne pour les binaires et les applications. Les indicateurs supplémentaires ne sont utilisés que lorsque l'application ou le binaire exporté est utilisé depuis l'hôte, leur utilisation à l'intérieur du conteneur ne les inclura pas.

Désinstallation

L'option “–delete” désinstallera une application ou un binaire

distrobox-export --app atom --delete
distrobox-export --bin /usr/bin/vim --export-path ~/.local/bin --delete

Exécuter en tant que root dans le conteneur

L'option “–sudo” lancera l'élément exporté en tant que root à l'intérieur du distrobox.

Notes

Notez que vous pouvez utiliser –app OU –bin, mais pas les deux. [IMAGE: export-app] export-app

NOTE : certaines applications electron comme vscode et atom nécessitent des indicateurs supplémentaires pour fonctionner depuis l'intérieur du conteneur, utilisez l'option --extra-flags pour fournir une série d'indicateurs, par exemple :

distrobox-export --app atom --extra-flags "--foreground"
