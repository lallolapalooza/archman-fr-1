NOM

dispatch — le framework dispatch

SYNOPIS

#include <dispatch/dispatch.h>

DESCRIPTION

Le framework dispatch permet de planifier des blocs pour une exécution asynchrone et concurrente via les fonctions principales décrites dans dispatch_async(3) et dispatch_apply(3).

Les files d'attente dispatch sont les unités organisationnelles de base des blocs. Plusieurs files d'attente sont créées par défaut, et les applications peuvent en créer d'autres pour leur propre usage. Voir dispatch_queue_create(3) pour plus d'informations.

Les groupes dispatch permettent aux applications de suivre la progression des blocs soumis aux files d'attente et d'agir lorsque les blocs sont terminés. Voir dispatch_group_create(3) pour plus d'informations.

Le framework dispatch fournit également des fonctions pour surveiller les événements système sous-jacents et soumettre automatiquement les blocs de gestionnaires d'événements aux files d'attente dispatch.
