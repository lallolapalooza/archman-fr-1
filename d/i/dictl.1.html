DICTL(1) Manuel des commandes générales DICTL(1)

NOM

dictl - script d'encapsulation pour dict qui permet d'utiliser des dictionnaires encodés en utf-8 sur un terminal qui n'est pas compatible utf-8.

SYNTAXE

dictl [OPTIONS] [mot]

DESCRIPTION

dictl appelle dict avec les arguments fournis sur la ligne de commande. dictl utilise la valeur de la variable d'environnement DICTL_CHARSET comme jeu de caractères préféré de l'utilisateur. Si cette variable est vide, dictl tente de déterminer le jeu de caractères à utiliser à partir de la sortie de la commande locale.

Les arguments passés à dictl, y compris mot, sont convertis depuis le jeu de caractères préféré de l'utilisateur vers le jeu de caractères du serveur spécifié par la variable DICTL_SERVER_CHARSET (utf-8 s'il n'est pas défini), et passés à dict. La sortie du serveur de dict est convertie dans le jeu de caractères préféré de l'utilisateur.

NOTE : Parce que iconv omet les caractères invalides de la sortie,
recode -f est utilisé pour les conversions de jeux de caractères par défaut. Si vous préférez iconv, définissez la variable DICTL_USE_ICONV à une chaîne non vide. Si vous voulez utiliser konwert, définissez DICTL_USE_KONWERT à une chaîne non vide.

Étant donné que recode, iconv et konwert ne prennent pas en charge la conversion vers ou depuis les locales "C" ou "POSIX", il est recommandé à tous les utilisateurs dont la locale est "C" ou "POSIX" de définir DICTL_CHARSET sur "latin1" (ISO_8859-1).

OPTIONS

dictl accepte toutes les options de dict telles que décrites dans dict(1).
