NOM

dict_lookup - Client du protocole DICT

SYNTAXE

dict_lookuop [options]

DESCRIPTION

dict_lookup lit la sélection X, puis ouvre un émulateur de terminal et exécute le client dict à l'intérieur, permettant à l'utilisateur de visualiser le contenu à l'aide d'un pagineur. Il est judicieux de configurer le lancement de dict_lookup sur un raccourci clavier dans le gestionnaire de fenêtres.

OPTIONS

-h
affiche le message d'aide.
-x x
coordonnée X de l'émulateur de terminal.
-x Y
coordonnée Y de l'émulateur de terminal.
-s Lxl
largeur et hauteur de l'émulateur de terminal séparées par 'x'.
-q requête
requête, si elle est spécifiée, la sélection X n'est pas lue.

ENVIRONNEMENT

dict_lookup reconnaît les variables d'environnement suivantes. La valeur par défaut est spécifiée entre crochets.

D_AWK_PROG
Interpréteur AWK à utiliser. [awk]
D_XCLIP_PROG
application xclip. [xclip]
D_XTERM_PROG
xterm ou émulateur de terminal équivalent. [xterm]
D_UTF8_LOCALE
locale UTF-8. [en_US.UTF-8]
D_DICT_PROG
programme client de dictionnaire. [dict]
D_DICT_SERVER
Option pour le client de dictionnaire spécifiant le serveur. [-h dict.org]
D_DICT_PORT
Option pour le client de dictionnaire spécifiant le port. [-p 2628]
D_DICT_DB_OPT
Option pour le client de dictionnaire spécifiant la base de données. [-d foldoc]
D_XTERM_CLASS
Option pour l'émulateur de terminal spécifiant la classe. [-class XTerm]
D_XTERM_NAME
Option pour l'émulateur de terminal spécifiant le nom. [-name xterm_dict]
D_XTERM_TITLE
Option pour l'émulateur de terminal spécifiant le titre. [-title dict_lookup]
D_TEXT_WIDTH
Programme calculant la largeur du texte pour un texte donné. [cyrillic_text_width] cyrillic_text_width ne fonctionne pas correctement pour le japonais, le coréen, le chinois et certaines autres langues.
D_TERM_X
Coordonnée X de l'émulateur de terminal. [+200]
D_TERM_Y
Coordonnée Y de l'émulateur de terminal. [+200]
D_TERM_H
Hauteur de l'émulateur de terminal. [+40]
D_PAGER
Pagineur. [less]

VOIR AUSSI

dict(1), less(1), xterm(1), dictd(8), http://www.dict.org, RFC 2229
