Diffing variadique

Le diffing variadique permet d'étendre les listes qui sont différées pendant le diffing. dans une direction spécifique.

Paramètres :

"*"

sig end

val diff : D.state -> D.left array -> D.right array -> Diffing.Define.patch

diff state l r calcule le patch optimal entre l et r , en utilisant l'état initial state .
