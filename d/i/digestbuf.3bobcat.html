DESCRIPTIO

N

Les objets FBB::DigestBuf sont des objets std::streambuf qui peuvent être utilisés pour initialiser des objets std::

ostream.

L'empreinte de message de toutes les informations insérées dans un tel std::ostream est

calculée.

Toutes les empreintes de message définies par la bibliothèque OpenSSL qui peuvent être sélectionnées par nom peuvent être utilisées en combinaison avec des objets

DigestBuf.

Les algorithmes d'empreinte de message actuellement pris en charge sont affichés par la commande openssl list -digest-commands. Les noms des algorithmes d'empreinte peuvent être utilisés

pour sélectionner un algorithme d'empreinte pou
r le constructeur de la classe, ci-dessous.

DigestBuf(char const *digestName, size_t bufsize = 1024) :
Ce constructeur initialise le streambuf, le configurant pour l'algorithme d'empreinte de message spécifié avec type. Les algorithmes d'empreinte de message spécifiés dans la section DESCRIPTION peuvent être utilisés ici. Par exemple, pour utiliser l'algorithme sha256, spécifiez "sha256
".
L'argument bufsize spécifie la taille du tampon interne utilisé par DigestBuf pour stocker temporairement les caractères entrants. L'argum
ent par défaut fourni devrait
convenir dans tous les cas normaux.

FONCTIONS

MEMBRES

Tous les membres de std::streambuf sont disponibles, car FBB::DigestBuf hérite de cette

classe.
o
void eoi() :
Ce membre termine le calcul de l'empreinte de message. Il est nécessaire car l'objet DigestBuf n'a aucun moyen externe pour décider si toutes les informations pour lesquelles calculer l'empreinte ont été reçues ou non. L'approche générale à suivre lors du calcul d'une empreinte de message est donc : 
    1. créer un objet DigestBuf
    2. l'utiliser pour créer un objet std::ostream
    3. insérer des informations
dans l'objet ostream 4. appeler le membre eoi() de l'objet DigestBuf ou insérer le manipulateur e
oi dans l'ostream (voir ci-dessous) 5. obtenir/traiter la valeur de hachage à partir de l'objet DigestBuf.
o
std::string const &hash() const :
Ce membre renvoie la valeur de hachage calculée par l'objet DigestBuf. Sa valeur n'est définie qu'après avoir appelé close(). La valeur de hachage est renvoyée dans un objet std::string. Le membre length() de cette chaîne contient le nombre de caractères utilisés par la valeur de hachage, et son membre data() pointe vers les caractères de la valeur de hachage. Notez que la valeur d'un caractère d'une valeur de hachage peut être 0 (ne pas confondre avec ’0’
).
o
void reset() :
Ce membre réinitialise le calcul de l'empreinte de message. Une fois qu'une empreinte de message a été calculée pour, disons, un flux streamA, ce membre peut être appelé, après quoi l'empreinte pour un flux streamB peut être calculée en utilisant le même objet
Dige
stB
uf.

MANIPULATEU

R
o
FBB::eoi :
Le manipulateur eoi peut être inséré dans l' ostream pour compléter l'empreinte. Il effectue les mêmes actions que le membre eoi. S'il est inséré dans un simple std::ostream
, rien
ne se
passe.

EXEMPL

E 
#include <iostream>
#include <ostream>
#include <bobcat/digestbuf>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
try
{
    DigestBuf digestbuf(argc == 1 ? "sha256" : argv[1]);
    ostream out(&digestbuf);
    string hw("hello world\n");
    out << hw << eoi;
    cout << ">" << digestbuf << "<" << endl;
    digestbuf.reset();
    out.write(hw.c_str(), hw.length()) << eoi;
    cout << ">" << digestbuf << "<" << endl;
}
catch(exception const &err)
{
    cout << err.what() << endl;
    return 1;
}
