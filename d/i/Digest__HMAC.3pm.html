NOM

Digest::HMAC - Hachage clé pour l'authentification de message

SYNTAXE

# Style fonctionnel
use Digest::HMAC qw(hmac hmac_hex);
$digest = hmac($data, $key, \&myhash);
print hmac_hex($data, $key, \&myhash);
# Style OO
use Digest::HMAC;
$hmac = Digest::HMAC->new($key, "Digest::MyHash");
$hmac->add($data);
$hmac->addfile(*FILE);
$digest = $hmac->digest;
$digest = $hmac->hexdigest;
$digest = $hmac->b64digest;

DESCRIPTION

HMAC est utilisé pour les vérifications d'intégrité de message entre deux parties qui partagent une clé secrète, et fonctionne en combinaison avec un autre algorithme de Digest, généralement MD5 ou SHA-1. Le mécanisme HMAC est décrit dans la RFC 2104.

HMAC suit l'interface commune "Digest::", mais le constructeur prend la clé secrète et le nom d'un autre "Digest::" simple comme argument.

La fonction hmac() et hmac_hex() et le constructeur Digest::HMAC->new() prennent également un argument optionnel $blocksize. L'algorithme HMAC suppose que le digesteur hache en itérant une fonction de compression de base sur des blocs de données et que le $blocksize doit correspondre à la longueur en octets de ces blocs.

Le $blocksize par défaut est 64, ce qui convient aux fonctions de hachage MD5 et SHA-1. Pour des algorithmes plus robustes, le bloc de taille devra probablement être augmenté.

VOIR AUSSI

Digest::HMAC_MD5, Digest::HMAC_SHA1

RFC 2104
