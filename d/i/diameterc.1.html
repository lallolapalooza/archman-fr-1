diameterc(1) Commandes utilisateur diameterc(1)

NOM

diameterc - Compiler un dictionnaire diameter en source Erlang

SYNTAXE

diameterc [<options>] <fichier>

DESCRIPTION

L'utilitaire diameterc est utilisé pour compiler un fichier de dictionnaire diameter en source Erlang. La source résultante implémente l'interface diameter requise pour encoder et décoder les messages et les AVPs du dictionnaire.

Le module diameter_make fournit une interface de compilation alternative.

UTILISATION

Compile un seul fichier dictionnaire en source Erlang. Les options valides sont les suivantes.

-i <rep>

Ajoute le répertoire spécifié au début du chemin de code. Utilisez pour pointer vers des fichiers beam compilés à partir de dictionnaires hérités. @inherits dans un fichier dictionnaire crée une dépendance beam, pas une dépendance erl/hrl.

Plusieurs options -i peuvent être spécifiées.

-o <rep>

Écrit la source générée dans le répertoire spécifié. Par défaut, le répertoire de travail courant.

-E

Supprime la génération de fichiers .erl.

-H

Supprime la génération de fichiers .hrl.

--name <nom>

Nomme le module de sortie.

--prefix <prefixe>

Transforme le dictionnaire d'entrée avant la compilation, en définissant @name ou @prefix sur la chaîne spécifiée.

--inherits <arg>

Transforme le dictionnaire d'entrée avant la compilation, en ajoutant @inherits de la chaîne spécifiée.

Deux formes de --inherits ont une signification spéciale:

--inherits -
--inherits Prev/Mod

La première a pour effet de supprimer tous les héritages précédents, la seconde de remplacer un héritage précédent de Prev par un héritage de Mod. Cela permet de modifier la sémantique du dictionnaire d'entrée sans modifier le fichier lui-même.

Plusieurs options --inherits peuvent être spécifiées.

STATUT DE SORTIE

Retourne 0 en cas de succès, une valeur non nulle en cas d'échec.

VOIR AUSSI
