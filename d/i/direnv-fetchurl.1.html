NOM

direnv fetchurl - Récupère une URL sur le disque

SYNTAXE

direnv fetchurl []

DESCRIPTION

Cette commande télécharge l'URL donnée dans un emplacement fixe sur le disque, basé sur le contenu du fichier récupéré.

Ceci a été introduit pour éviter une dépendance à curl ou wget, tout en promouvant une manière plus sécurisée de récupérer des données depuis Internet. Utilisez ceci au lieu de curl <url> | sh.

Cette commande a deux modes de fonctionnement :

1.
Transmettez simplement l'URL pour découvrir le hash d'intégrité.
2.
Transmettez l'URL et le hash d'intégrité pour obtenir l'emplacement sur disque.

Comme l'emplacement sur disque est basé sur le hash, cela agit également comme un cache. Une implication de cette conception est que les URLs doivent être stables et retourner toujours le même contenu.

Les fichiers téléchargés sont marqués comme lecture seule et exécutables, de sorte qu'ils peuvent également être utilisés pour récupérer et exécuter des binaires statiques.

OPTIONS


Une URL HTTP qui retourne du contenu lors de requêtes GET HTTP. Les redirections 301 et autres sont suivies.


Lorsqu'il est passé, l'intégrité du contenu récupéré sera validée
par rapport au hash donné. L'encodage du hash est basé sur la spécification
SRI du W3C (voir https://www.w3.org/TR/SRI/ ).

SORTIE

direnv fetchurl produit une sortie différente en fonction de l'argument.

Si le hash-d-integrite est passé, elle affichera le chemin vers l'emplacement sur disque, si la récupération a réussi.

Si seule l'url est passée, elle affichera le hash ainsi que des instructions lisibles par l'homme. Si la sortie standard n'est pas un tty, seul le hash sera affiché.

EXEMPLE

$ ./direnv fetchurl https://releases.nixos.org/nix/nix-2.3.7/install
Hash trouvé : sha256-7Gxl5GzI9juc/U30Igh/pY+p6+gj5Waohfwql3jHIds=
Invoquez fetchurl à nouveau avec le hash comme argument pour obtenir l'emplacement sur disque :
  direnv fetchurl "https://releases.nixos.org/nix/nix-2.3.7/install" "sha256-7Gxl5GzI9juc/U30Igh/pY+p6+gj5Waohfwql3jHIds="
  #=> /home/zimbatm/.cache/direnv/cas/sha256-7Gxl5GzI9juc_U30Igh_pY+p6+gj5Waohfwql3jHIds=

VARIABLES D'ENVIRONNEMENT

XDG_CACHE_HOME
Cette variable est utilisée pour sélectionner l'emplacement sur disque des URLs
récupérées sous la forme $XDG_CACHE_HOME/direnv/cas. Si XDG_CACHE_HOME n'est pas définie ou est vide,
elle prend par défaut $HOME/.cache.
