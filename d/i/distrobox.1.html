COMPATIBILIT

É

Ce projet n'a pas besoin d'une image dédiée. Il peut utiliser n'importe quelle image OCI de docker-hub, quay.io ou de tout registre de votre

choix.

De nombreuses images cloud sont volontairement allégées pour réduire leur taille et peuvent ne pas inclure de commandes telles que qui, mount, less ou vi). Des paquets supplémentaires peuvent être installés une fois à l'intérieur du conteneur. Nous recommandons d'utiliser votre outil d'automatisation préféré à l'intérieur du conteneur si vous vous retrouvez à devoir créer de nouveaux conteneurs de manière répétée. Le maintien de votre propre image personnalisée est également une

option.

La principale préoccupation est d'avoir les utilitaires Linux de base (mount), les utilitaires de gestion des utilisateurs de base (usermod, passwd), et sudo correctement

configuré.

ANCIENNES

Pour les anciennes distributions comme CentOS 5, CentOS 6, Debian 6, Ubuntu 12.04, la compatibilité n'est pas

l'hôte.

Gardez également à l'esprit que les miroirs peuvent être hors service pour de t

elles anciennes versions, vous devrez donc construire une image distrobox pe
