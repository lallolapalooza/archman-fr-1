NOM

Digest::base - Classe de base pour les digest

SYNTAXE

package Digest::Foo;
use base 'Digest::base';

DESCRIPTION

La classe "Digest::base" fournit des implémentations des méthodes "addfile" et "add_bits" basées sur "add", et des méthodes "hexdigest" et "b64digest" basées sur "digest".

Les implémentations de digest peuvent vouloir hériter de cette classe pour obtenir ces implémentations des méthodes alternatives add et digest. Une sous-classe minimale doit implémenter elle-même les méthodes suivantes :

new
clone
add
digest

Les arguments et le comportement attendu de ces méthodes sont décrits dans Digest.
