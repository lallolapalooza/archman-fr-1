NOM

diagtool - outil de diagnostic de clang

SYNTAXE

diagtool commande [arguments]

DESCRIPTION

diagtool est une combinaison de quatre outils pour traiter les diagnostics dans clang.

SOUS-COMMANDES

diagtool est séparé en plusieurs sous-commandes, chacune adaptée à un objectif différent. Un bref résumé de chaque commande suit, avec plus de détails dans les sections suivantes.

  • find-diagnostic-id - Affiche l'identifiant du diagnostic donné.
  • list-warnings - Liste les avertissements et leurs drapeaux correspondants.
  • show-enabled - Affiche les avertissements activés pour une ligne de commande donnée.
  • tree - Affiche les drapeaux d'avertissement dans une vue arborescente.

find-diagnostic-id

diagtool find-diagnostic-id nom-du-diagnostic

list-warnings

diagtool list-warnings

show-enabled

diagtool show-enabled [options] fichier ...

tree

diagtool tree [groupe-de-diagnostics]
