NOM

dict - Manipuler des dictionnaires

SYNOPSIS

dict option arg ?arg ...?

DESCRIPTION

Exécute une des plusieurs opérations sur des valeurs de dictionnaire ou des variables contenant des valeurs de dictionnaire (voir la section VALEURS DE DICTIONNAIRE ci-dessous pour une description), en fonction de option. Les options légales (qui peuvent être abrégées) sont :

dict append variableDictionnaire clé ?chaîne ...?
Ajoute la chaîne (ou les chaînes) donnée(s) à la valeur à laquelle la clé donnée correspond dans la valeur de dictionnaire contenue dans la variable donnée, en réécrivant la valeur de dictionnaire résultante dans cette variable. Les clés inexistantes sont traitées comme si elles correspondaient à une chaîne vide. La valeur de dictionnaire mise à jour est retournée.
dict create ?clé valeur ...?
Retourne un nouveau dictionnaire qui contient chacune des associations clé/valeur listées comme arguments (clés et valeurs alternées, chaque clé étant suivie de sa valeur associée.)
dict exists valeurDictionnaire clé ?clé ...?
Retourne une valeur booléenne indiquant si la clé donnée (ou le chemin de clés à travers un ensemble de dictionnaires imbriqués) existe dans la valeur de dictionnaire donnée. Ceci retourne une valeur vraie exactement quand dict get sur ce chemin réussira.
dict filter valeurDictionnaire typeFiltre arg ?arg ...?
Prend une valeur de dictionnaire et retourne un nouveau dictionnaire qui ne contient que les paires clé/valeur qui correspondent au type de filtre spécifié (qui peut être abrégé.) Les types de filtre supportés sont :
dict filter valeurDictionnaire clé ?motifGlob ...?
La règle de clé ne correspond qu'aux paires clé/valeur dont les clés correspondent à l'un des motifs donnés (dans le style de string match.)
dict filter valeurDictionnaire script {variableClé variableValeur} script
La règle de script teste la correspondance en assignant la clé à la variableClé et la valeur à la variableValeur, puis évalue le script donné qui devrait résulter en une valeur booléenne (la paire clé/valeur n'étant incluse dans le résultat de dict filter que lorsqu'une valeur vraie est retournée.) Notez que le premier argument après le mot de sélection de la règle est une liste de deux éléments. Si le script retourne avec une condition de TCL_BREAK, aucune autre paire clé/valeur n'est considérée pour l'inclusion dans le résultat, et une condition de TCL_CONTINUE est équivalente à un résultat faux. Les paires clé/valeur sont testées dans l'ordre où les clés ont été insérées dans le dictionnaire.
dict filter valeurDictionnaire valeur ?motifGlob ...?
La règle de valeur ne correspond qu'aux paires clé/valeur dont les valeurs correspondent à l'un des motifs donnés (dans le style de string match.)
dict for {variableClé variableValeur} valeurDictionnaire corps
Cette commande prend trois arguments, le premier est une liste de deux noms de variables (pour la clé et la valeur respectivement de chaque association dans le dictionnaire), le second est la valeur du dictionnaire à parcourir, et le troisième est un script à évaluer pour chaque association avec les variables clé et valeur correctement définies (de la manière de foreach.) Le résultat de la commande est une chaîne vide. Si une évaluation du corps génère un résultat TCL_BREAK, aucune autre paire du dictionnaire ne sera parcourue et la commande dict for se terminera immédiatement avec succès. Si une évaluation du corps génère un résultat TCL_CONTINUE, cela sera traité exactement comme un résultat TCL_OK normal. L'ordre d'itération est l'ordre dans lequel les clés ont été insérées dans le dictionnaire.
dict get valeurDictionnaire ?clé ...?
Étant donné une valeur de dictionnaire (premier argument) et une clé (deuxième argument), ceci récupérera la valeur pour cette clé. Lorsque plusieurs clés sont fournies, le comportement de la commande sera comme si le résultat de dict get $dictVal $clé était passé comme premier argument à dict get avec les arguments restants comme arguments secondaires (et éventuellement suivants.) Ceci facilite les recherches dans des dictionnaires imbriqués. Par exemple, les deux commandes suivantes sont équivalentes :
dict get $dict foo bar spong
dict get [dict get [dict get $dict foo] bar] spong

Si aucune clé n'est fournie, dict get retournera une liste contenant des paires d'éléments d'une manière similaire à array get. C'est-à-dire, le premier élément de chaque paire serait la clé et le second élément serait la valeur pour cette clé.

C'est une erreur de tenter de récupérer une valeur pour une clé qui n'est pas présente dans le dictionnaire.

dict incr variableDictionnaire clé ?incrément?
Ajoute la valeur d'incrémentation donnée (un entier qui vaut 1 par défaut si non spécifié) à la valeur à laquelle la clé donnée correspond dans la valeur de dictionnaire contenue dans la variable donnée, en réécrivant la valeur de dictionnaire résultante dans cette variable. Les clés inexistantes sont traitées comme si elles correspondaient à 0. C'est une erreur d'incrémenter une valeur pour une clé existante si cette valeur n'est pas un entier. La valeur de dictionnaire mise à jour est retournée.
dict info valeurDictionnaire
Retourne des informations (destinées à être affichées aux utilisateurs) sur le dictionnaire donné, bien que le format de ces données dépende de l'implémentation du dictionnaire. Pour les dictionnaires implémentés par des tables de hachage, il est attendu que cela retourne la chaîne produite par Tcl_HashStats, similaire à array statistics.
dict keys valeurDictionnaire ?motifGlob?
Retourne une liste de toutes les clés dans la valeur de dictionnaire donnée. Si un motif est fourni, seules les clés qui y correspondent (conformément aux règles de string match) seront retournées. Les clés retournées le seront dans l'ordre où elles ont été insérées dans le dictionnaire.
dict lappend variableDictionnaire clé ?valeur ...?
Ajoute les éléments donnés à la valeur de liste à laquelle la clé donnée correspond dans la valeur de dictionnaire contenue dans la variable donnée, en réécrivant la valeur de dictionnaire résultante dans cette variable. Les clés inexistantes sont traitées comme si elles correspondaient à une liste vide, et il est légal qu'il n'y ait aucun élément à ajouter à la liste. C'est une erreur que la valeur à laquelle la clé correspond ne puisse pas être représentée comme une liste. La valeur de dictionnaire mise à jour est retournée.
dict map {variableClé variableValeur} valeurDictionnaire corps
Cette commande applique une transformation à chaque élément d'un dictionnaire, retournant un nouveau dictionnaire. Elle prend trois arguments : le premier est une liste de deux noms de variables (pour la clé et la valeur respectivement de chaque association dans le dictionnaire), le second la valeur du dictionnaire à itérer, et le troisième un script à évaluer pour chaque association avec les variables clé et valeur définies appropriément (de la manière de lmap). Dans une itération où le script évalué se termine normalement (TCL_OK, par opposition à une error, etc.), le résultat du script est placé dans un dictionnaire accumulateur en utilisant la clé qui est le contenu actuel de la variable variableClé à ce moment. Le résultat de la commande dict map est le dictionnaire accumulateur après que toutes les clés aient été itérées.

Si l'évaluation du corps pour une étape particulière génère un break, aucune autre paire du dictionnaire ne sera itérée et la commande dict map se terminera immédiatement avec succès. Si l'évaluation du corps pour une étape particulière génère un résultat continue, l'itération actuelle est abandonnée et le dictionnaire accumulateur n'est pas modifié. L'ordre d'itération est l'ordre naturel du dictionnaire (typ

VALEU

RS DE
DICTIONNAIRE Les

dictionnaires sont

des

valeurs qui contiennent un mappage efficace, préservant l'ordre, de clés arbitraires vers des valeurs arbitraires. Chaque clé dans le dictionnaire correspond à une seule valeur. Elles ont un format textuel qui est exactement celui de toute liste avec un nombre pair d'éléments, chaque mappage dans le dictionnaire étant représenté comme deux éléments dans la liste. Lorsqu'une commande prend un dictionnaire et produit un nouveau dictionnaire basé sur celui-ci (soit en le retournant, soit en l'écrivant dans la variable à partir de laquelle le dictionnaire de départ a été lu), le nouveau dictionnaire aura le même ordre de clés, modulo toute clé supprimée et avec les nouvelles clés ajoutées à la fin. Lorsqu'une chaîne est interprétée comme un dictionnaire et qu'elle aurait autrement des clés en double, seule la dernière valeur pour une clé particulière est utilisée ; les autres sont ignorées, ce qui signifie que « apple banana » et « apple carrot apple banana » sont des dictionnaires équivalents (avec

différentes

représentations de chaînes). Les opérations qui dérivent un nouveau dictionnaire d'un ancien (par exemple, des mises à jour comme dict set et dict unset) préservent l'ordre des clés dans le dictionnaire. Les ex

ceptions à cela sont pour toute nouvelle clé qu'elles aj
outent, qui est appendée à la séquence, et toute clé qui est

supprimée

,

qui est excisée de

l'ordre.

proc sumDictionary {varName} {
    upvar 1 $varName vbl
    foreachkey [
dict keys $vbl] {
        # Fabriquer une entrée dans le sous-dictionnaire

}
