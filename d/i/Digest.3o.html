Module Digest
: sig end

Message digest.

Ce module fournit des fonctions pour calculer des « digests », également appelés « hashes », de chaînes de caractères ou de fichiers de longueur arbitraire. Les algorithmes de hachage supportés sont BLAKE2 et MD5.

Fonctions de base

Les fonctions de cette section utilisent la fonction de hachage MD5 pour produire des digests de 128 bits (16 octets). MD5 n'est pas cryptographiquement sécurisé. Par conséquent, ces fonctions ne doivent pas être utilisées pour des applications sensibles à la sécurité. Les fonctions BLAKE2 ci-dessous sont cryptographiquement sécurisées.

type t = string

Le type des digests : chaînes de 16 octets.

val compare : t -> t -> int

La fonction de comparaison pour les digests de 16 octets, avec la même spécification que compare et l'implémentation partagée avec String.compare . Avec le type t , cette fonction compare permet au module Digest d'être passé en argument aux foncteurs Set.Make et Map.Make .

val substring : string -> int -> int -> t

Digest.substring s ofs len retourne le digest de la sous-chaîne de s commençant à l'indice ofs et contenant len caractères.

val subbytes : bytes -> int -> int -> t

Digest.subbytes s ofs len retourne le digest de la sous-séquence de s commençant à l'indice ofs et contenant len octets.

Depuis 4.02

val channel : in_channel -> int -> t

Si len est non négatif, Digest.channel ic len lit len caractères du canal ic et retourne leur digest, ou lève End_of_file si la fin du fichier est atteinte avant la lecture de len caractères. Si len est négatif, Digest.channel ic len lit tous les caractères de ic jusqu'à la fin du fichier et retourne leur digest.

val file : string -> t

Retourne le digest du fichier dont le nom est donné.

val output : out_channel -> t -> unit

Écrit un digest sur le canal de sortie donné.

val input : in_channel -> t

Lit un digest depuis le canal d'entrée donné.

val to_hex : t -> string

Retourne la représentation hexadécimale imprimable du digest donné.

Lève Invalid_argument si l'argument n'est pas exactement 16 octets.

Interface générique

module type S = sig end

La signature pour une fonction de hachage qui produit des digests de longueur hash_length à partir de chaînes de caractères, de tableaux d'octets et de fichiers.

Depuis 5.2

Fonctions de hachage spécifiques

module BLAKE128 : S

BLAKE128 est la fonction de hachage BLAKE2b produisant des digests de 128 bits (16 octets). Elle est cryptographiquement sécurisée. Cependant, la petite taille des digests permet des attaques par force brute en 2{^64} tentatives.

Depuis 5.2

module BLAKE256 : S

BLAKE256 est la fonction de hachage BLAKE2b produisant des digests de 256 bits (32 octets). Elle est cryptographiquement sécurisée, et la taille des digests est suffisante pour déjouer les attaques par force brute.

Depuis 5.2

module BLAKE512 : S

BLAKE512 est la fonction de hachage BLAKE2b produisant des digests de 512 bits (64 octets). Elle est cryptographiquement sécurisée, et la taille des digests est suffisante pour déjouer les attaques par force brute.

Depuis 5.2

module MD5 : S

MD5 est la fonction de hachage MD5. Elle produit des digests de 128 bits (16 octets) et n'est pas du tout cryptographiquement sécurisée. Elle ne devrait être utilisée que pour la compatibilité avec des conceptions antérieures qui exigent l'utilisation de MD5.

Depuis 5.2
