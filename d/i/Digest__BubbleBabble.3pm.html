NOM

Digest::BubbleBabble - Créer des empreintes bubble-babble

SYNOPSIS

# Créer une empreinte d'une chaîne simple.
use Digest::BubbleBabble qw( bubblebabble );
my $fingerprint = bubblebabble( Digest => "Pineapple" );
# Créer une empreinte d'un hachage SHA-1.
use Digest::SHA1 qw( sha1 );
$fingerprint = bubblebabble( Digest => sha1("hello") );

DESCRIPTION

Digest::BubbleBabble prend un condensat de message (souvent généré par l'un ou l'autre des algorithmes de condensat de message MD5 ou SHA-1) et crée une empreinte de ce condensat au format « bubble babble ». Le bubble babble est une méthode de représentation d'un condensat de message comme une chaîne de mots « réels », pour rendre l'empreinte plus facile à retenir. Les « mots » ne sont pas nécessairement des mots réels, mais ils ressemblent plus à des mots qu'une chaîne de caractères hexadécimaux.

Le condensat de message en bubble babble est utilisé par la suite SSH2 (et, par conséquent, par Net::SSH::Perl, l'implémentation Perl de SSH) pour afficher des empreintes de clés faciles à retenir. La clé (une clé DSA ou RSA) est convertie dans une forme textuelle, condensée en utilisant Digest::SHA1, et passée à travers bubblebabble pour créer l'empreinte de clé.

UTILISATION

Digest::BubbleBabble exporte conditionnellement une fonction appelée bubblebabble ; pour importer la fonction, vous devez choisir de l'importer, comme ceci :

use Digest::BubbleBabble qw( bubblebabble );

bubblebabble( Digest => $digest )

Prend actuellement seulement une paire d'arguments, dont la clé doit être Digest, dont la valeur est le condensat de message réel $digest. Vous devriez générer ce condensat de message vous-même en utilisant soit Digest::MD5 soit Digest::SHA1.

Retourne la forme bubble babble du condensat.
