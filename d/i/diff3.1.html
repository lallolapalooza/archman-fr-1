DIFF3(1) Commandes utilisateur DIFF3(1)

NOM

diff3 - comparer trois fichiers ligne par ligne

SYNTAXE

diff3 [OPTION]... MONFICHIER ANCIENFICHIER VOTREFICHIER

DESCRIPTION

Comparer trois fichiers ligne par ligne.

Les arguments obligatoires pour les options longues sont aussi obligatoires pour les options courtes.

-A, --show-all
afficher tous les changements, en encadrant les conflits
-e, --ed
générer un script ed intégrant les changements de ANCIENFICHIER vers VOTREFICHIER dans MONFICHIER
-E, --show-overlap
similaire à -e, mais encadre les conflits
-3, --easy-only
similaire à -e, mais n'intègre que les changements non superposés
-x, --overlap-only
similaire à -e, mais n'intègre que les changements superposés
-X
similaire à -x, mais encadre les conflits
-i
ajouter les commandes 'w' et 'q' aux scripts ed
-m, --merge
générer le fichier fusionné réel, selon -A si aucune autre option n'est donnée
-a, --text
traiter tous les fichiers comme du texte
--strip-trailing-cr
supprimer le retour chariot final à l'entrée
-T, --initial-tab
aligner les tabulations en préfixant une tabulation
--diff-program=PROGRAMME
utiliser PROGRAMME pour comparer les fichiers
-L, --label=LABEL
utiliser LABEL à la place du nom de fichier (peut être répété jusqu'à trois fois)
--help
afficher cette aide et quitter
-v, --version
afficher les informations de version et quitter

Le format de sortie par défaut est une représentation des changements quelque peu lisible par l'homme.

Les options -e, -E, -x, -X (et leurs équivalents longs) génèrent un script ed au lieu de la sortie par défaut.

Enfin, l'option -m (--merge) fait que diff3 effectue la fusion en interne et génère le fichier fusionné réel. Pour des entrées inhabituelles, cela est plus robuste que l'utilisation de ed.

Si un FICHIER est '-', lire l'entrée standard. Le code de sortie est 0 en cas de succès, 1 en cas de conflits, 2 en cas de problème.
