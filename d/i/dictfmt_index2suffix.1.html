NOM

dictfmt_index2suffix - Crée un fichier .suffix à partir d'un fichier .index de base de données DICTD

SYNTAXE

dictfmt_index2suffix [OPTIONS] [fichier_index]

DESCRIPTION

dictfmt_index2suffix crée un fichier d'index de suffixe sur la sortie standard à partir du fichier d'index donné en entrée standard ou sur la ligne de commande. Un fichier d'index de suffixe est identique au fichier .index sauf que les caractères des mots principaux sont inversés. Un fichier d'index de suffixe est normalement nommé <basename>.suffix, mais ce n'est pas obligatoire tant que le nom approprié est utilisé dans le fichier de configuration dictd.

OPTIONS

--help
affiche un message d'utilisation et quitte
--locale locale
utilise la locale spécifiée pour trier le fichier .suffix. Si cette option est omise, la locale par défaut "C" est utilisée.
fichier_index
le fichier .index à convertir.
