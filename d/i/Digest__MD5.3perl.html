Digest::MD5(3perl) Guide de référence des programmeurs Perl Digest::MD5(3perl)

NOM

Digest::MD5 - Interface Perl pour l'algorithme MD5

SYNOPSIS

# Style fonctionnel
use Digest::MD5 qw(md5 md5_hex md5_base64);
my $digest = md5($data);
my $digest = md5_hex($data);
my $digest = md5_base64($data);
# Style orienté objet
use Digest::MD5;
my $ctx = Digest::MD5->new;
$ctx->add($data);
$ctx->addfile($file_handle);
$digest = $ctx->digest;
$digest = $ctx->hexdigest;
$digest = $ctx->b64digest;

DESCRIPTION

Le "Digest::MD5" module vous permet d'utiliser l'algorithme de message digest MD5 de RSA Data Security Inc. depuis des programmes Perl. L'algorithme prend en entrée un message de longueur arbitraire et produit en sortie une « empreinte » ou « message digest » de 128 bits de l'entrée.

Notez que l'algorithme MD5 n'est plus aussi fort qu'il l'était. Depuis 2005, il est facile de générer des messages différents produisant le même digest MD5. Il semble toujours difficile de générer des messages produisant un digest donné, mais il est probablement judicieux de passer à des algorithmes plus forts pour les applications qui dépendent du digest pour identifier de manière unique un message.

Le "Digest::MD5" module fournit une interface procédurale pour une utilisation simple, ainsi qu'une interface orientée objet capable de traiter des messages de longueur arbitraire et de lire directement des fichiers.

FONCTIONS

Les fonctions suivantes sont fournies par le "Digest::MD5" module. Aucune de ces fonctions n'est exportée par défaut.

md5($data,...)
Cette fonction concatène tous les arguments, calcule le digest MD5 de ce « message » et le retourne sous forme binaire. La chaîne retournée fera 16 octets de long.

Le résultat de md5("a", "b", "c") sera exactement le même que le résultat de md5("abc").

md5_hex($data,...)
Identique à md5(), mais retournera le digest sous forme hexadécimale. La longueur de la chaîne retournée sera de 32 et elle ne contiendra que des caractères de cet ensemble : '0'..'9' et 'a'..'f'.
md5_base64($data,...)
Identique à md5(), mais retournera le digest sous forme de chaîne encodée en base64. La longueur de la chaîne retournée sera de 22 et elle ne contiendra que des caractères de cet ensemble : 'A'..'Z', 'a'..'z', '0'..'9', '+' et '/'.

Notez que la chaîne encodée en base64 retournée n'est pas complétée pour être un multiple de 4 octets de long. Si vous souhaitez l'interopérabilité avec d'autres digests md5 encodés en base64, vous voudrez peut-être ajouter la chaîne redondante "==" au résultat.

MÉTHODES

L'interface orientée objet pour "Digest::MD5" est décrite dans cette section. Après qu'un objet "Digest::MD5" a été créé, vous ajouterez des données et demanderez enfin le digest dans un format approprié. Un seul objet peut être utilisé pour calculer plusieurs digests.

Les méthodes suivantes sont fournies :

$md5 = Digest::MD5->new
Le constructeur retourne un nouvel objet "Digest::MD5" qui encapsule l'état de l'algorithme de message digest MD5.

S'il est appelé comme méthode d'instance (c'est-à-dire $md5->new), il réinitialisera simplement l'état de l'objet à l'état d'un objet nouvellement créé. Aucun nouvel objet n'est créé dans ce cas.

$md5->reset
Ceci est simplement un alias pour $md5->new.
$md5->clone
Ceci est une copie de l'objet $md5 . C'est utile lorsque vous ne voulez pas détruire l'état du digest, mais avez besoin d'une valeur intermédiaire du digest, par exemple lors du calcul de digests de manière itérative sur un flux de données continu. Exemple : 
my $md5 = Digest::MD5->new;
while (<>) {
    $md5->add($_);
    print "Line $.: ", $md5->clone->hexdigest, "\n";
}
$md5->add($data,...)
Les $data fournis en argument sont ajoutés au message pour lequel nous calculons le digest. La valeur de retour est l'objet $md5 lui-même.

Toutes ces lignes auront le même effet sur l'état de l'objet $md5 :

$md5->add("a"); $md5->add("b"); $md5->add("c");
$md5->add("a")->add("b")->add("c");
$md5->add("a", "b", "c");
$md5->add("abc");
$md5->addfile($io_handle)
Le $io_handle sera lu jusqu'à EOF et son contenu sera ajouté au message pour lequel nous calculons le digest. La valeur de retour est l'objet $md5 lui-même.

La addfile() méthode émettra un croak() si elle échoue à lire des données pour une raison quelconque. Si elle émet un croak, il est imprévisible quel sera l'état de l'objet $md5 . La addfile() méthode a peut-être pu lire le fichier partiellement avant d'échouer. Il est probablement judicieux de supprimer ou de réinitialiser l'objet $md5 si cela se produit.

Dans la plupart des cas, vous voudrez vous assurer que le $io_handle est en "binmode" avant de le passer en argument à la addfile() méthode.

$md5->add_bits($data, $nbits)
$md5->add_bits($bitstring)
Comme l'algorithme MD5 est orienté octet, vous ne pouvez ajouter des bits que par multiples de 8, vous voudrez donc probablement utiliser add() à la place. La add_bits() méthode est fournie pour la compatibilité avec d'autres implémentations de digest. Voir Digest pour la description des arguments que add_bits() prend.
$md5->digest
Retourne le digest binaire du message. La chaîne retournée fera 16 octets de long.

Notez que l'opération "digest" est effectivement une opération destructive, à lecture unique. Une fois qu'elle a été effectuée, l'objet "Digest::MD5" est automatiquement "réinitialisé" et peut être utilisé pour calculer une autre valeur de digest. Appelez $md5->clone->digest si vous voulez calculer le digest sans réinitialiser l'état du digest.

$md5->hexdigest
Identique à $md5->digest, mais retournera le digest sous forme hexadécimale. La longueur de la chaîne retournée sera de 32 et elle ne contiendra que des caractères de cet ensemble : '0'..'9' et 'a'..'f'.
$md5->b64digest
Identique à $md5->digest, mais retournera le digest sous forme de chaîne encodée en base64. La longueur de la chaîne retournée sera de 22 et elle ne contiendra que des caractères de cet ensemble : 'A'..'Z', 'a'..'z', '0'..'9', '+' et '/'.

La chaîne encodée en base64 retournée n'est pas complétée pour être un multiple de 4 octets de long. Si vous souhaitez l'interopérabilité avec d'autres digests md5 encodés en base64, vous voudrez peut-être ajouter la chaîne "==" au résultat.

@ctx = $md5->context
$md5->context(@ctx)
Sauvegarde ou restaure l'état interne. Lorsqu'il est appelé sans arguments, retourne une liste : le nombre de blocs traités, un tampon d'état interne de 16 octets, puis éventuellement jusqu'à 63 octets de données non traitées s'il y en a. Lorsqu'il reçoit ces mêmes arguments, il restaure l'état. Ceci n'est utile que pour des opérations spécialisées.

EXEMPLES

La façon la plus simple d'utiliser cette bibliothèque est d'importer la md5_hex() fonction (ou l'une de ses cousines) :

use Digest::MD5 qw(md5_hex);
print "Digest is ", md5_hex("foobarbaz"), "\n";

L'exemple ci-dessus afficherait le message :

Digest is 6df23dc03f9b54cc38a0fc1483df6e21

La même somme de contrôle peut aussi être calculée en style orienté objet :

use Digest::MD5;
my $md5 = Digest::MD5->new;
$md5->add('foo', 'bar');
$md5->add('baz');
my $digest = $md5->hexdigest;
print "Digest is $digest\n";

Avec le style orienté objet, vous pouvez découper le message arbitrairement. Celans que nous ne sommes plus limités à avoir de la place pour le message entier en mémoire, c'est-à-dire que nous pouvons traiter des messages de n'importe quelle taille.

Ceci est utile pour calculer une somme de contrôle de fichiers :

use Digest::MD5;
my $filename = shift || "/etc/passwd";
open (my $fh, '<', $filename) or die "Can't open '$filename': $!";
binmode($fh);
my $md5 = Digest::MD5->new;
while (<$fh>) {
    $md5->add($_);
}
close($fh);
print $md5->b64digest, " $filename\n";

Ou nous pouvons utiliser la méthode addfile pour une lecture plus efficace du fichier :

use Digest::MD5;
my $filename = shift || "/etc/passwd";
open (my $fh, '<', $filename) or die "Can't open '$filename': $!";
binmode ($fh);
print Digest::MD5->new->addfile($fh)->hexdigest, " $filename\n";

Comme l'algorithme MD5 n'est défini que pour des chaînes d'octets, il ne peut pas être utilisé sur des chaînes contenant des caractères dont le nombre ordinal est supérieur à 255 (chaînes Unicode). Les fonctions et méthodes MD5 échoueront si vous essayez de leur fournir de telles données d'entrée :

use Digest::MD5 qw(md5_hex);
my $str = "abc\x{300}";
print md5_hex($str), "\n";  # croaks
# Wide character in subroutine entry

Ce que vous pouvez faire, c'est calculer la somme de contrôle MD5 de la représentation UTF-8 de telles chaînes. Cela est réalisé en filtrant la chaîne à travers encode_utf8() fonction :

use Digest::MD5 qw(md5_hex);
use Encode qw(encode_utf8);
my $str = "abc\x{300}";
print md5_hex(encode_utf8($str)), "\n";
# 8c2d46911f3f5a326455f0ed7a8ed3b3
