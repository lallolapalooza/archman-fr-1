NOM

dictfmt_index2word - Crée un fichier d'index .word à partir d'un fichier .index d'une base de données DICTD

SYNTAXE

dictfmt_index2word [OPTIONS] [fichier_index]

DESCRIPTION

dictfmt_index2word crée un fichier d'index de mots sur la sortie standard pour le fichier d'index donné en entrée standard ou en argument de ligne de commande. Un fichier d'index de mots indexe chaque sous-mot des mots composés des en-têtes du fichier .index, vers le fichier .dict sous-jacent. Un fichier d'index de mots est généralement nommé <basename>.word, mais ce n'est pas obligatoire tant que le nom approprié est utilisé dans le fichier de configuration de dictd.

OPTIONS

--help
affiche un message d'utilisation et quitte
--locale locale
utilise la locale pour trier le fichier .word. Si cette option est omise, la locale par défaut "C" est utilisée.
fichier_index
le fichier .index à convertir.
