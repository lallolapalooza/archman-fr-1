NOM

DJabberd::Component::Node - Spécialisation de DJabberd::Agent::Node sachant qu'elle appartient à un composant

DESCRIPTION

Cette classe abstraite est une spécialisation de DJabberd::Agent::Node. La seule différence entre cette classe et sa parente est que les nœuds représentés par cette classe « savent » qu'ils appartiennent à un composant et en conservent une référence.

SYNTAXE

Créez votre classe de nœud comme sous-classe de cette classe :

package MyPackage::DJabberd::MyNode;
use base DJabberd::Component::Node;

# Exemple d'un agent qui répond aux messages de chat entrants

sub handle_message {
    my ($self, $vhost, $stanza) = @_;

    my $response = $stanza->make_response();
    $response->set_raw("<body>Bonjour. Je suis un agent logiciel.</body>");
    $response->deliver($vhost);
}

La classe peut ensuite être instanciée à partir d'une méthode dans une instance DJabberd::Component :

# $self ici est un objet DJabberd::Component
my $node = MyPackage::DJabberd::MyNode->new(
    component => $self,
    nodename => "bob",
);

L'instance créée ci-dessus acceptera les stanzas adressées au nœud « bob » dans le domaine appartenant au composant donné.

Il n'est pas possible d'utiliser directement des sous-classes de cette classe comme plugins de diffusion, car elles doivent être associées à un composant au moment de l'exécution.

VOIR AUSSI

Voir aussi DJabberd::Agent::Node, DJabberd::Component.
