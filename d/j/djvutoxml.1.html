DÉFINITION DU TYPE DE DOCUMENT

DJVUXML

Le fichier de définition du type de document

(DTD)
/usr/share/d
jvu/pubtext/D
jVuXML-s.dtd

définit l'entrée et la sortie des outils XML de

DjVu.

Le DTD DjVuXML-s est une simplification du DTD HTML

:
http://www.w3c.org/T
R/1998/REC-html40-19
980424/sgml/dtd.html

avec quelques nouveaux attributs ajoutés spécifiques à DjVu. Chacune des pages spécifiées d'un document DjVu est représentée comme élément OBJECT dans le élément BODY du fichier XML. Chaque élément OBJECT peut contenir plusieurs éléments PARAM pour spécifier des attributs tels que le nom de la page, la résolution et le facteur gamma. Chaque élément OBJECT peut également contenir un élément HIDDENTEXT pour spécifier le texte caché (généré généralement avec un moteur OCR) dans la page DjVu. De plus, chaque élément OBJECT peut référencer un seul élément MAP de zone qui contient plusieurs éléments AREA pour représenter toutes les zones d'hy

perliens et de surlign
age dans le document DjVu.

Éléments

PARAM

Les éléments PARAM légaux d'un OBJECT DjVu incluent, sans s'y limiter, PAGE pour spécifier le nom de la page, GAMMA pour spécifier le facteur de correction gamma (normalement 2,2), et DPI pour spécifier l

a résolution
de la page.

Éléments

HIDDENTEXT

Les éléments HIDDENTEXT se composent d'éléments imbriqués de PAGECOLUMNS, REGION, PARAGRAPH, LINE et WORD. L'élément le plus profondément imbriqué spécifié doit indiquer les coordonnées délimitant l'élément en orientation de haut en bas. Le corps de l'élément le plus profondément imbriqué doit contenir le texte. La plupart des documents DjVu utilisent soit LINE WORD comme élément de niveau le plus bas, mais tout élément est légal comme élément de niveau le plus bas. Une espace est toujours ajoutée entre les éléments WORD et un retour à la ligne est toujours ajouté entre les éléments LINE. Comme les langues telles que le japonais n'utilisent pas d'espaces entre les mots, il est courant que les moteurs OCR asiatiques utilisent WORD comm

e carac
tères.

Éléments

MAP

Le corps des éléments MAP se compose d' éléments AREA. En plus des attributs listés

dans
http://www.w3.org/TR/1998/REC-html40-1
9980424/struct/obje
cts.html#edef-AREA,

les attributs bordertype, bordercolor, border et highlight ont été ajoutés pour spécifier respectivement le type de bordure, la couleur de la bordure, la largeur de la bordure et les couleurs de surlignage. Les valeurs légales pour chacun de ces attributs sont listées dans le DTD DjVuXML-s. De plus, la forme oval a été ajoutée à la liste légale des formes. Un o

vale utilise une boîte
délimitante rectangulaire.
