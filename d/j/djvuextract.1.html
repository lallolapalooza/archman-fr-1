NOM

djvuextract - Extraire des blocs d'un fichier image DjVu.

SYNTAXE

djvuextract [-page=numéro_page] fichier.djvu [id_bloc=nom_fichier]...

DESCRIPTION

Le programme djvuextract extrait les données brutes des blocs d'un fichier DjVu fichier.djvu. Ces blocs peuvent ensuite être réassemblés dans des fichiers DjVu à l'aide du programme djvumake.

L'option -page peut être utilisée pour spécifier une page particulière. Sinon, la première page du document est supposée. Chaque argument restant spécifie que les données brutes associées à tous les blocs nommés id_bloc seront concaténées dans le fichier nommé nom_fichier. Les blocs nommés BG44 et FG44 sont traités légèrement différemment: le programme génère des fichiers IW44 valides au lieu de simplement sauvegarder les données brutes.

Voir la page de manuel djvumake(1) pour des informations connexes.
