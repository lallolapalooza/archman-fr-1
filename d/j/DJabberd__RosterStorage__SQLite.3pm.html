NOM

DJabberd::RosterStorage::SQLite - stocker votre liste de contacts Jabber dans SQLite

SYNOPSIS

<Vhost yourserver.com>
   ...
   <Plugin DJabberd::RosterStorage::SQLite>
      Database roster.sqlite
   </Plugin>
   ...
 </VHost>

DESCRIPTION

Ceci stocke votre liste de contacts Jabber ("buddy list") dans une base de données SQLite.

Le schéma est automatiquement créé lors de la première utilisation.

ATTENTION : BLOQUE !

Ce plugin bloque. C'est-à-dire qu'il n'effectue pas les accès à la base de données de manière asynchrone dans un thread séparé. Ce n'est pas un bon plugin à utiliser si vous voulez que DJabberd fonctionne bien avec beaucoup d'utilisateurs.

Cela dit, une certaine entreprise l'utilise pour environ 100 employés sans problème.
