NOM

DJabberd::Component::External - Interface vers les plugins externes implémentant JEP-0114

DESCRIPTION

Ce composant fournit le support pour connecter des composants externes qui supportent le Protocole de Composant Jabber spécifié dans JEP-0114. Spécifiez le port TCP sur lequel le composant externe se connectera et le secret qu'il utilisera pour s'authentifier. Ces éléments doivent correspondre aux paramètres équivalents dans la propre configuration du composant.

Vous pouvez également spécifier une option ListenAddr, qui définit l'adresse IP de l'interface sur laquelle écouter. Par défaut, nous n'écoutons que sur l'adresse de bouclage, 127.0.0.1. Alternativement, vous pouvez fournir un socket de domaine UNIX (un chemin absolu commençant par une barre oblique) et omettre le paramètre ListenPort pour attendre une connexion sur un socket de domaine UNIX. La plupart des composants ne supportent cependant pas les sockets de domaine UNIX.

Veuillez noter que ce composant n'implémente que la variation "accepter" du protocole, où DJabberd ouvre un socket d'écoute et attend que le composant se connecte. La variation "connecter", où le composant attend que DJabberd s'y connecte, n'est pas supportée.

SYNTAXE

<Plugin DJabberd::Component::External>
  ListenPort 23534
  Secret somesecret
</Plugin>
