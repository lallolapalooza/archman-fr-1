NOM

djvmcvt - Convertir des documents DjVu multipages.

SYNTAXE

   Création d'un document regroupé :

djvmcvt -b[undled] docin.djvu docout.djvu

   Création d'un document indirect :

djvmcvt -i[ndirect] docin.djvu dir index.djvu

DESCRIPTION

Ce programme convertit tout document DjVu multipage soit au format regroupé, soit au format indirect multipage. Le fichier d'entrée docin.djvu doit être soit le nom de fichier d'un document regroupé, soit le fichier d'index d'un document indirect.

OPTIONS

-b[undled]
Crée un document DjVu multipage regroupé nommé docout.djvu.
-i[ndirect]
Crée un document DjVu multipage indirect. Tous les fichiers composant le document indirect seront stockés dans le répertoire dir. Le fichier d'index sera nommé index.djvu.
