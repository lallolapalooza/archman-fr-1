NOM

djview4 - Visionneuse autonome DjVu

SYNOPIS

djview4 [options] [argument]

DESCRIPTION

Visionneuse autonome pour fichiers DjVu. Les fonctionnalités incluent la navigation dans les documents, le zoom et le déplacement des images de page, la production et l'affichage de miniatures, l'affichage des plans du document, la recherche de mots particuliers dans la couche texte masquée du document, la copie du texte masqué dans le presse-papiers, l'enregistrement des pages et des documents sous forme de fichiers multipages groupés ou indirects, et l'impression des pages et des documents. La visionneuse peut afficher simultanément plusieurs pages en utilisant une disposition côte à côte ou continue.

ARGUMENT DE LIGNE DE COMMANDE ET OPTIONS

Ce programme peut s'exécuter comme un programme autonome ou comme un processus esclave pour le plugin navigateur DjVu nsdejavu. En mode autonome, l'argument de ligne de commande argument peut être :

  • Le nom du fichier d'un document DjVu valide.
  • Une URL de document DjVu locale de la forme :
file:///chemin/nom.djvu[?djvuopts&mot-clé=valeur&...]
Les crochets délimitent les composants optionnels de l'URL. Diverses options peuvent être spécifiées en utilisant une syntaxe similaire à celle des arguments CGI. Spécifier les options de cette manière est très utile pour un plugin navigateur car il n'y a pas d'arguments de ligne de commande. Dans le cas d'une visionneuse autonome, toutes les options peuvent être spécifiées en tant qu'arguments de ligne de commande.
*
Une URL de document DjVu distante de la forme :
http://hôte/chemin/nom.djvu[?djvuopts&mot-clé=valeur&...]
https://hôte/chemin/nom.djvu[?djvuopts&mot-clé=valeur&...]
La navigation dans les documents DjVu distants avec la visionneuse autonome est moins efficace qu'avec le plugin navigateur. La visionneuse autonome ne bénéficie pas des stratégies de mise en cache et des paramètres de proxy du navigateur. Les paramètres de proxy pour la visionneuse autonome peuvent être définis indépendamment via la boîte de dialogue des préférences.

Une liste étendue d'options est reconnue. La plupart des options peuvent être spécifiées en tant qu'arguments de ligne de commande commençant par le tiret habituel (-) ou en utilisant la syntaxe des arguments CGI dans l'URL du document. Certaines options ne sont cependant significatives qu'en tant qu'arguments de ligne de commande. D'autres options ne sont reconnues que lors de l'exécution de la version X11 du programme djview4.

OPTIONS DE LIGNE DE COMMANDE

Les options suivantes ne sont significatives que lorsqu'elles sont spécifiées sur la ligne de commande.

-help
Affiche un bref message d'aide.
-verbose
Affiche des messages informatifs sur la console. Cette option est très utile car elle affiche des messages concernant les constructions non reconnues dans les couches d'annotation et de lien hypertexte DjVu.
-fullscreen, -fs
Démarre djview4 en mode plein écran. Utilisez la touche ESC pour quitter le mode plein écran.
-slideshow[=arg]
Démarre djview4 en mode diaporama. L'argument numérique optionnel arg spécifie le nombre de secondes avant de passer à la page suivante. Utilisez la touche ESC pour quitter le mode diaporama.
-style=nom_style
Spécifie le style de l'interface utilisateur graphique. Les valeurs reconnues pour nom_style dépendent de la version installée de la boîte à outils Qt. Les noms de style courants incluent cde, motif, plastique, platinum, et windows.

OPTIONS X11

Les options de ligne de commande suivantes sont reconnues par la version X11 du programme djview4. Contrairement à la plupart des options de djview4, les options X11 qui nécessitent un argument n'utilisent pas le caractère égal pour introduire leur argument.

-display nom_affichage
Spécifie que les fenêtres djview4 doivent apparaître sur l'affichage X11 nom_affichage.
-geometry LxH+X+Y
Spécifie la taille et la position initiales de la première fenêtre en utilisant la syntaxe traditionnelle de spécification de géométrie X11. Les arguments numériques L et H représentent la largeur et la hauteur initiales de la fenêtre. Les arguments numériques X et Y indiquent la position de la fenêtre par rapport au coin supérieur gauche de l'écran.
-name nom
Définit le nom de l'application.
-title titre
Définit le titre de la première fenêtre.
-fn nom_police, -font nom_police
Spécifie le nom de la police par défaut utilisée pour les boutons et les menus. La police doit être spécifiée à l'aide d'une chaîne de description de police logique X.
-bg couleur, -background couleur
Spécifie la couleur d'arrière-plan par défaut pour les éléments de l'interface utilisateur graphique. La couleur doit être fournie sous forme de nom de couleur X11 standard.
-fg couleur, -foreground couleur
Spécifie la couleur de premier plan par défaut pour les éléments de l'interface utilisateur graphique. La couleur doit être fournie sous forme de nom de couleur X11 standard.
-btn couleur
Spécifie la couleur de bouton par défaut. La couleur doit être fournie sous forme de nom de couleur X11 standard.
-ncols nombre
Limite le nombre de couleurs allouées sur un écran 8 bits. Le cube de couleurs par défaut contient 216 couleurs distinctes.
-cmap
Force l'allocation d'une carte de couleurs privée sur un écran 8 bits. Cela peut augmenter la qualité des couleurs mais provoquer des scintillements lorsque la fenêtre de la visionneuse est activée.

OPTIONS GÉNÉRALES

Les options suivantes peuvent être spécifiées en tant qu'options de ligne de commande ou peuvent être passées en augmentant l'URL du document à l'aide d'une syntaxe similaire à celle des arguments CGI

http://.../file.djvu?djvuopts&clé=valeur&clé=valeur&...

Afin de séparer les arguments CGI réels de ces options, la visionneuse ne reconnaît que les mots-clés qui apparaissent après le mot djvuopts. Les mots-clés clé sont dérivés des noms d'options en supprimant les tirets initiaux.

-page=nom_page
Affiche une page spécifique du document. La visionneuse recherche d'abord une page dont l'identifiant correspond à l'argument nom_page. Sinon, si nom_page est un nombre précédé du caractère + ou -, la visionneuse effectue un déplacement relatif par rapport à la page actuelle. Sinon, à partir de la page actuelle et en revenant au début, elle recherche une page dont le titre correspond à l'argument nom_page. Sinon, si nom_page est numérique, il est interprété comme un numéro de page ordinal. Sinon, enfin, la visionneuse recherche une page dont le nom correspond à nom_page.
-pageno=numéro_page

ENVIRONNEMEN

T

Définir la variable d'environnement DJVIEW_VERBOSE à une valeur non nulle est équivalent à appeler djview avec l'option -verbose. Définir la variable d'environnement DJVIEW_OPENGL aux valeurs 0 ou 1 remplace les paramètres de préférence concernant le rendu

OpenGL.

Lorsque l'utilisateur clique sur un hyperlien djvu pointant vers une page web, le programme essaie d'abord d'exécuter les programmes de navigateur web dont les noms sont listés dans la variable d'environnement séparée par des deux-points BROWSER, puis essaie des valeurs par défaut raisonnables dépendantes de la

plateforme.

La langue de l'interface utilisateur est déterminée en cherchant d'abord un ensemble complet de fichiers de traduction pour la langue spécifiée dans la boîte de dialogue des préférences, puis pour les langues ISO 639 spécifiées dans la variable d'environnement séparée par des deux-points LANGUAGE, et enfin la langue spécifiée par la locale du système. Si toutes ces reche

rches échouent, la langue de l'interface
utilisateur revient à l'anglais par défaut.
