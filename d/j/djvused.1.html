DESCRIPTIO

N

Le programme djvused est un puissant outil en ligne de commande pour manipuler des documents multi-pages, créer ou modifier des blocs d'annotation, créer ou modifier des couches de texte caché, pré-calculer des images miniatures, et plus encore. Le programme lit d'abord le document DjVu djvufile et exécute un certain nombre de commandes

djvused.

Les commandes djvused peuvent être lues depuis un fichier spécifique (lorsque l'option -f est spécifiée), lues depuis la ligne de commande (lorsque l'option -e est spécifiée), ou lues dep

uis l'entrée stand
ard (par défaut).

DJVUSED

Djvused utilise une syntaxe simple avec parenthèses pour représenter à la fois les annotations et le texte

caché.
  • Cette syntaxe est la syntaxe native utilisée par DjVu pour stocker les annotations. Le programme djvused compresse simplement les données d'annotation en utilisant l'algorithme bzz(1
    • ).
  • Cette syntaxe diffère de la syntaxe native utilisée par DjVu pour stocker le texte caché. Le programme djvused effectue les traductions entre la représentation b
    • inaire compacte utilisée par
DjVu et la syntaxe facilement
modifiable avec parenthèses.

Syntaxe

générale

Les fichiers djvused sont des fichiers texte ASCII. Les caractères légaux dans les fichiers djvused sont les caractères imprimables ASCII et les caractères espace, tab, cr et nl. L'utilisation d'autres caractères a des résultats

indéfinis.

Les fichiers djvused sont composés d'une séquence d'expressions séparées par des caractères blancs (espace, tab, cr ou nl). Il y a quatre types d'expressions, à savoir les entiers, les symboles, les chaînes et les

listes.
Entiers
:
Les nombres entiers sont représentés par un ou plusieurs chiffres, avec l'interprétation
habituelle.
Symboles
:
Les symboles, ou identifiants, sont des séquences de caractères ascii imprimables représentant un nom ou un mot-clé. Les caractères acceptables sont les caractères alphanumériques, le caractère de soulignement "_", le caractère moins "-" et le caractère dièse "#". Les noms ne doivent pas commencer par un chiffre ou un caractère
moins.
Chaînes
:
Les chaînes désignent une séquence arbitraire d'octets, généralement interprétée comme une séquence de caractères encodés en UTF-8. Les chaînes dans les fichiers djvused sont similaires aux chaînes dans le langage C. Elles sont entourées de guillemets doubles. Certaines séquences de caractères commençant par une barre oblique inverse ("\") ont une signification particulière. Une barre oblique inverse suivie de la lettre "a", "b", "t", "n", "v", "f", "r", "\" et représente respectivement le caractère ascii BEL(007), BS(008), HT(009), LF(010), VT(011), FF(012), CR(013), BACKSLASH(134) et DOUBLEQUOTE(042). Une barre oblique inverse suivie d'un à trois chiffres représente l'octet dont le code octal est exprimé par les chiffres. Toutes les autres séquences de barres oblique inverse sont illégales. Tous les caractères ascii non imprimables doivent être
échappés.
Listes
:
Les listes sont des séquences d'expressions sé
parées par des blancs et entourées de parenthè
ses. Tous les types d'expressions sont acceptab
les dans une liste, y compris les sous-listes.

Syntaxe du texte

caché

Les éléments constitutifs de la syntaxe du texte caché sont des listes représentant chaque composant structurel du texte caché. Les composants structurels ont la forme suivante

:
(type xmin ymin xmax ymax ..
.
)

Le symbole type doit être l'un de page, column, region, para, line, word ou char, listés ici par ordre d'importance décroissante. Les entiers xmin, ymin, xmax et ymax représentent les coordonnées d'un rectangle indiquant la position du composant structurel dans la page. Les coordonnées sont mesurées en pixels et ont leur origine dans le coin inférieur gauche de la page. Les expressions restantes dans la liste sont soit une chaîne unique représentant le texte encodé associé à ce composant structurel, soit une séquence de composants structurels d'un type

inférieur.

Le texte caché pour chaque page est simplement représenté par un seul élément structurel de type page. Divers niveaux d'information structurelle sont acceptables. Par exemple, le composant de niveau page peut seulement spécifier un

e chaîne de niveau page, ou seulement fournir une liste de lignes, o
u fournir une hiérarchie complète jusqu'aux caractères individuels.

sommaire/signet

La syntaxe du sommaire est une liste unique de la

forme
(bookmarks ..
.

Le premier élément de la liste est le symbole bookmarks. Les éléments suivants sont des listes représentant les entrées de sommaire de premier niveau. Chaque entrée de sommaire est représentée par une liste de la forme suivante

:
(title url ..

La chaîne title est le titre de l'entrée de sommaire. La chaîne de destination url peut être soit une URL arbitraire encodée en pourcentage, soit composée du caractère dièse ("#") suivi d'un nom ou d'un numéro de page, soit composée du caractère point d'interrogation ("?") suivi d'argumen

ts de style cgi interprétés par le visualiseur djvu. Les expressions resta
ntes dans la liste décrivent les sous-entrées de cette entrée de sommaire.
