DJVUXML(1) Outils XML DjVuLibre DJVUXML(1)

NOM

djvutoxml, djvuxmlparser - Outils XML DjVuLibre.

SYNTAXE

djvutoxml [options] fichier.djvu [fichier_xml_sortie]
djvuxmlparser [ -o fichier.djvu ] fichier_xml_entree

DESCRIPTION

Les outils XML DjVuLibre permettent de modifier les métadonnées, les liens hypertextes et le texte caché associés aux fichiers DjVu. Contrairement à djvused(1), les outils XML DjVuLibre s'appuient sur la technologie XML et peuvent tirer parti des éditeurs et des validateurs XML.

DJVUTOXML

Le programme djvutoxml crée un fichier XML fichier_xml_sortie contenant une référence au document DjVu original fichier.djvu ainsi que des balises décrivant les métadonnées, les liens hypertextes et le texte caché associés au fichier DjVu.

Les options suivantes sont supportées :

--page num_page
Sélectionne une page dans un document multipage. Sans cette option, djvutoxml génère le XML correspondant à toutes les pages du document.
--with-text
Spécifie que l'élément HIDDENTEXT pour chaque page doit être inclus dans la sortie. S'il est spécifié sans l'indicateur --with-anno, alors --without-anno est implicite. Si aucune des options --with-text, --without-text, --with-anno, ou --without-anno, n'est spécifiée, alors les options --with-text et --with-anno sont implicites.
--without-text
Spécifie de ne pas générer l'élément HIDDENTEXT pour chaque page. S'il est spécifié sans l'indicateur --without-anno, alors l'option --with-anno est implicite.
--with-anno
Spécifie que l'élément MAP de la zone pour chaque page doit être inclus dans la sortie. S'il est spécifié sans l'indicateur --with-text, alors l'option --without-text est implicite.
--without-anno
Spécifie que l'élément MAP de la zone pour chaque page ne doit pas être inclus dans la sortie. S'il est spécifié sans l'indicateur --without-text, alors l'option --with-text est implicite.

DJVUXMLPARSER

Les fichiers produits par djvutoxml peuvent ensuite être modifiés à l'aide d'un éditeur de texte ou d'un éditeur XML. Le programme djvuxmlparser analyse le fichier XML fichier_xml_entree afin de modifier les métadonnées du fichier DjVu correspondant.

-o fichier.djvu
En principe, le fichier DjVu cible est le fichier référencé par l'élément OBJECT du fichier XML. Cette option permet de remplacer le nom de fichier spécifié dans l'élément OBJECT.

DÉCLARATION DE TYPE DJVUXML

Le fichier de déclaration de type de document (DTD)

/usr/share/djvu/pubtext/DjVuXML-s.dtd

définit les entrées et sorties des outils XML DjVu.

Le DTD DjVuXML-s est une simplification du DTD HTML :

http://www.w3c.org/TR/1998/REC-html40-19980424/sgml/dtd.html

avec quelques attributs nouveaux spécifiques à DjVu. Chacune des pages spécifiées d'un document DjVu est représentée comme des éléments OBJECT au sein de l'élément BODY du fichier XML. Chaque élément OBJECT peut contenir plusieurs éléments PARAM pour spécifier des attributs tels que le nom de la page, la résolution et le facteur gamma. Chaque élément OBJECT peut également contenir un élément HIDDENTEXT pour spécifier le texte caché (généralement généré avec un moteur OCR) dans la page DjVu. De plus, chaque élément OBJECT peut référencer un élément MAP de zone unique qui contient plusieurs éléments AREA pour représenter toutes les zones de liens hypertextes et de surlignage dans le document DjVu.

   Éléments PARAM

Les éléments PARAM valides d'un OBJECT DjVu incluent, mais ne sont pas limités à, PAGE pour spécifier le nom de la page, GAMMA pour spécifier le facteur de correction gamma (normalement 2.2) et DPI pour spécifier la résolution de la page.

   Éléments HIDDENTEXT

Les éléments HIDDENTEXT sont composés d'éléments imbriqués de PAGECOLUMNS, REGION, PARAGRAPH, LINE, et WORD. L'élément le plus imbriqué spécifié doit indiquer les coordonnées de délimitation de l'élément dans une orientation de haut en bas. Le corps de l'élément le plus imbriqué doit contenir le texte. La plupart des documents DjVu utilisent soit LINE soit WORD comme niveau le plus bas, mais tout élément est légal comme élément le plus bas. Un espace blanc est toujours ajouté entre les éléments WORD et un saut de ligne est toujours ajouté entre les éléments LINE. Étant donné que les langues comme le japonais n'utilisent pas d'espaces entre les mots, il est très courant que les moteurs OCR asiatiques utilisent WORD comme caractères.

   Éléments MAP

Le corps des éléments MAP est composé d'éléments AREA. En plus des attributs listés dans

http://www.w3.org/TR/1998/REC-html40-19980424/struct/objects.html#edef-AREA,

les attributs bordertype, bordercolor, border, et highlight ont été ajoutés pour spécifier respectivement le type de bordure, la couleur de bordure, la largeur de bordure et les couleurs de surlignage. Les valeurs légales pour chacun de ces attributs sont listées dans le DTD DjVuXML-s. De plus, la forme oval a été ajoutée à la liste des formes légales. Un ovale utilise une boîte englobante rectangulaire.

BOGUES

Il aurait peut-être été préférable d'utiliser des feuilles de style CC2 avec des éléments HTML standard au lieu de définir l'élément HIDDENTEXT.

CRÉDITS

Les outils et le DTD XML DjVu ont été écrits par Bill C. Riemers <docbill@sourceforge.net> et Fred Crary.
