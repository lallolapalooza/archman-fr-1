NOM

DJabberd::SASL::ManagerBase - Classe de base abstraite pour l'objet principal SASL.

DESCRIPTION

Le gestionnaire SASL est l'objet principal instancié lorsqu'une négociation commence. C'est un wrapper autour d'Authen::SASL, plus quelques outils.

INTERFACE

voir Authen::SASL et Authen::SASL::Perl pour les méthodes de base.

plugin

renvoie le plugin DJabberd::SASL responsable de l'instanciation de ce gestionnaire.

server_new

a la même interface, mais renvoie une instance DJabberd::SASL::Connection au lieu d'une classe de gestion de mécanisme SASL normale.

is_mechanism_supported($mechanism)

Les sous-classes devraient fournir cette méthode.

renvoie vrai ou faux selon que $mechanism est pris en charge par l'implémentation sous-jacente et la configuration actuelle.
