NOM

DJabberd::Agent::Node - Classe abstraite pour un agent qui gère un nœud spécifique

SYNOPSIS

package MyPackage::DJabberd::MyNode;
use base DJabberd::Agent::Node;

# Exemple d'un agent qui répond aux messages de chat entrants

sub handle_message {
    my ($self, $vhost, $stanza) = @_;

    my $response = $stanza->make_response();
    $response->set_raw("<body>Bonjour. Je suis un agent logiciel.</body>");
    $response->deliver($vhost);
}

Cette classe fournit une classe parente pour les agents qui reçoivent des strophes adressées à un nom de nœud particulier au sein d'un domaine.

Un tel agent est souvent appelé un "Bot". Une API de plus haut niveau pour implémenter des "chat bots" est également fournie dans DJabberd::Bot.

UTILISATION

Cette classe est une spécialisation de DJabberd::Agent. Dans la plupart des cas, les utilisateurs de cette classe utiliseront l'API exposée par DJabberd::Agent. Cependant, il y a un comportement spécial à noter et des méthodes supplémentaires qui ne font pas partie de la classe agent de base.

handles_destination($self, $to_jid, $vhost)

Cette classe fournit une version surchargée de cette méthode qui répond avec une valeur vraie si et seulement si le domaine et le nom du nœud du JID de destination correspondent à ceux gérés par cette instance.

vcard($self, $requester_jid)

La version surchargée de cette méthode retournera une vCard où le nom complet est défini sur le nom du nœud de cette instance. Les sous-classes voudront probablement la surcharger pour faire quelque chose de plus sophistiqué.

VOIR AUSSI

Voir aussi DJabberd::Agent, DJabberd::Component.
