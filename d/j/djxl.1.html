NOM

djxl - décompresse les images JPEG XL

SYNTAXE

djxl [options...] input.jxl [sortie]

DESCRIPTION

djxl décompresse une image ou une animation JPEG XL. Le format de sortie est déterminé par l'extension du fichier de sortie, qui peut être .png, .jpg, .ppm, .pfm. Si le fichier d'entrée JPEG XL contient une animation, plusieurs fichiers de sortie seront produits, avec des noms de la forme "sortie-numéro_de_frame.ext".

OPTIONS

-h, --help

Affiche les options supportées par djxl.

-j, --pixels_to_jpeg

Par défaut, si le JPEG XL d'entrée contient un fichier JPEG recompresé, djxl reconstruit le fichier JPEG original exact si le fichier de sortie a l'extension .jpg (ou .jpeg). Ce drapeau oblige le décodeur à décoder l'image en pixels et à encoder un nouveau JPEG (avec perte) dans ce cas.

-q qualité, --jpeg_quality=qualité

Lors du décodage en .jpg, utilise cette qualité de sortie. Cette option active implicitement l'option --pixels_to_jpeg.

EXEMPLES

# Décompresser un fichier JPEG XL en PNG
$ djxl input.jxl output.png
# Reconstruire un fichier JPEG recompresé sans perte
$ djxl lossless-jpeg.jxl reconstructed.jpeg
