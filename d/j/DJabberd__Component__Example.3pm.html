NOM

DJabberd::Component::Example - Un exemple de composant de service DJabberd

SYNTAXE

<Subdomain example>
    <Plugin DJabberd::Component::Example>
        Greeting Hello, world!
    </Plugin>
</Subdomain>

Cette classe implémente un composant très simple qui répond à tous les messages entrants avec un message d'accueil prédéfini et qui renvoie une vCard pour lui-même lorsqu'elle est demandée. Vous pouvez modifier le message d'accueil renvoyé en utilisant le paramètre de configuration facultatif Greeting ci-dessus.

Cet exemple expose également un nœud appelé "somebloke" qui répond à tous les messages avec une surprise britannique authentique.

Cet exemple utilise l'API de plus haut niveau fournie par DJabberd::Agent, dont DJabberd::Component hérite. DJabberd::Component::External sert d'exemple sur la façon de gérer les strophes à un niveau inférieur en remplaçant la méthode "handle_stanza".
