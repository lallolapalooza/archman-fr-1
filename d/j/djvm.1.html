NOM

djvm - Manipuler les documents DjVu multi-pages groupés.

SYNTAXE

   Création d'un document groupé:

djvm -c[reate] doc.djvu page1.djvu ... pageN.djvu

   Insertion:

djvm -i[nsert] doc.djvu page.djvu [numéro_page]

   Suppression:

djvm -d[elete] doc.djvu numéro_page

   Listage:

djvm -l[ist] doc.djvu

DESCRIPTION

Ce programme crée ou modifie un document DjVu multi-pages groupé. Les documents groupés multi-pages peuvent être utilisés directement ou convertis en document indirect en utilisant la commande djvmcvt.

OPTIONS

-c[reate]
Crée un document DjVu groupé nommé doc.djvu en collectant les fichiers page1.djvu à pageN.djvu.
-i[nsert]
Modifie le document DjVu groupé nommé doc.djvu en insérant le fichier page.djvu comme page numéro_page. Omettre l'argument numéro_page signifie que la page doit être ajoutée à la fin du document. Le fichier page.djvu peut également être un document DjVu multi-pages. Toutes les pages seront insérées à l'emplacement spécifié.
-d[elete]
Supprime la page numéro_page du document DjVu multi-pages groupé doc.djvu.
-l[ist]
Liste tous les fichiers composants du document DjVu multi-pages doc.djvu.
