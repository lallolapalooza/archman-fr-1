NOM

DJabberd::SASL::Connection - classe de base abstraite pour les connexions SASL

DESCRIPTION

Une instance de cet objet est créée par un gestionnaire SASL et attachée à l'objet de connexion (DJabberd::Connection) lorsqu'une négociation SASL est en cours ou a été effectuée. Les instances de cette classe (ou de ses sous-classes) ont la même interface que l'objet de connexion d'Authen::SASL (server_start, server_step, need_step, is_success, error...).

MÉTHODES ADDITIONNELLES

jid_authentifié

Une chaîne de caractères représentant le jid authentifié à l'issue de la négociation.

définir_jid_authentifié($chaîne_jid)

Définit le jid_authentifié
