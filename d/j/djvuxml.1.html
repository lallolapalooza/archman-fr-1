DJVUXML(1) Outils XML de DjVuLibre DJVUXML(1)

NOM

djvutoxml, djvuxmlparser - Outils XML de DjVuLibre.

SYNOPSIS

djvutoxml [options] fichierdjvu [fichierxml]
djvuxmlparser [ -o fichierdjvu ] fichierxml

DESCRIPTION

Les outils XML de DjVuLibre permettent de modifier les métadonnées, les hyperliens et le texte caché associés aux fichiers DjVu. Contrairement à djvused(1) les outils XML de DjVuLibre reposent sur la technologie XML et peuvent tirer parti des éditeurs et vérificateurs XML.

DJVUTOXML

Le programme djvutoxml crée un fichier XML fichierxml contenant une référence au document DjVu d'origine fichierdjvu ainsi que des balises décrivant les métadonnées, les hyperliens et le texte caché associés au fichier DjVu.

Les options suivantes sont prises en charge :

--page numéro
Sélectionne une page dans un document multipages. Sans cette option, djvutoxml produit le XML correspondant à toutes les pages du document.
--with-text
Indique que l'élément HIDDENTEXT de chaque page doit être inclus dans la sortie. S'il est spécifié sans l'indicateur --with-anno alors l'option --without-anno est implicite. Si aucun des indicateurs --with-text, --without-text, --with-anno, ou --without-anno, n'est spécifié, alors les indicateurs --with-text et --with-anno sont implicites.
--without-text
Indique de ne pas produire l'élément HIDDENTEXT pour chaque page. S'il est spécifié sans l'indicateur --without-anno alors l'indicateur --with-anno est implicite.
--with-anno
Indique que l'élément de zone MAP de chaque page doit être inclus dans la sortie. S'il est spécifié sans l'indicateur --with-text alors l'indicateur --without-text est implicite.
--without-anno
Indique que l'élément de zone MAP de chaque page ne doit pas être inclus dans la sortie. S'il est spécifié sans l'indicateur --without-text alors l'indicateur --with-text est implicite.

DJVUXMLPARSER

Les fichiers produits par djvutoxml peuvent ensuite être modifiés à l'aide d'un éditeur de texte ou d'un éditeur XML. Le programme djvuxmlparser analyse le fichier XML fichierxml afin de modifier les métadonnées du fichier DjVu correspondant.

-o fichierdjvu
En principe, le fichier DjVu cible est le fichier référencé par l'élément OBJECT du fichier XML. Cette option permet de remplacer le nom de fichier spécifié dans l'élément OBJECT .

DÉFINITION DU TYPE DE DOCUMENT DJVUXML

Le fichier de définition du type de document (DTD)

/usr/share/djvu/pubtext/DjVuXML-s.dtd

définit l'entrée et la sortie des outils XML de DjVu.

Le DTD DjVuXML-s est une simplification du DTD HTML :

http://www.w3c.org/TR/1998/REC-html40-19980424/sgml/dtd.html

avec quelques nouveaux attributs ajoutés spécifiques à DjVu. Chacune des pages spécifiées d'un document DjVu est représentée comme un élément OBJECT à l'intérieur de l'élément BODY du fichier XML. Chaque élément OBJECT peut contenir plusieurs éléments PARAM pour spécifier des attributs tels que le nom de la page, la résolution et le facteur gamma. Chaque élément OBJECT peut également contenir un élément HIDDENTTEXT pour spécifier le texte caché (généré habituellement avec un moteur OCR) à l'intérieur de la page DjVu. De plus, chaque élément OBJECT peut référencer un seul élément de zone MAP qui contient plusieurs éléments AREA pour représenter toutes les zones d'hyperliens et de surlignage à l'intérieur du document DjVu.

Éléments PARAM

Les éléments PARAM valides d'un OBJECT DjVu incluent mais ne sont pas limités à PAGE pour spécifier le nom de la page, GAMMA pour spécifier le facteur de correction gamma (normalement 2,2), et DPI pour spécifier la résolution de la page.

Éléments HIDDENTEXT

Les éléments HIDDENTEXT se composent d'éléments imbriqués de PAGECOLUMNS, REGION, PARAGRAPH, LINE, et WORD. L'élément imbriqué le plus profond spécifié doit indiquer les coordonnées de délimitation de l'élément en orientation de haut en bas. Le contenu de l'élément imbriqué le plus profond doit contenir le texte. La plupart des documents DjVu utilisent soit LINE soit WORD comme élément de niveau le plus bas, mais tout élément est valide comme élément de niveau le plus bas. Un espace est toujours ajouté entre les éléments WORD et un retour à la ligne est toujours ajouté entre les éléments LINE . Comme les langues telles que le japonais n'utilisent pas d'espaces entre les mots, il est courant que les moteurs OCR asiatiques utilisent WORD pour les caractères à la place.

Éléments MAP

Le contenu des éléments MAP se compose d'éléments AREA . En plus des attributs listés dans

http://www.w3.org/TR/1998/REC-html40-19980424/struct/objects.html#edef-AREA,

les attributs bordertype, bordercolor, borderet highlight ont été ajoutés pour spécifier respectivement le type de bordure, la couleur de la bordure, la largeur de la bordure et les couleurs de surlignage. Les valeurs valides pour chacun de ces attributs sont listées dans le DTD DjVuXML-s. De plus, la forme oval a été ajoutée à la liste des formes valides. Un ovale utilise une boîte de délimitation rectangulaire.

BOGUES

Il aurait peut-être été préférable d'utiliser des feuilles de style CC2 avec des éléments HTML standard au lieu de définir l'élément HIDDENTEXT .

    DJVUXML DOCUMENT TYPE DEFINITION

    Le fichier XML DjVu est défini par le document type definition (DTD) suivant :

        <!ELEMENT djvutext (
        pagina+
    )>
    <!ATTLIST djvutext
        version CDATA #REQUIRED
    >
    <!ELEMENT pagina (
        texte | image | parametre | bloc_texte | bloc_image
    )*>
    <!ATTLIST pagina
        id CDATA #REQUIRED
        top CDATA #IMPLIED
        left CDATA #IMPLIED
        width CDATA #IMPLIED
        height CDATA #IMPLIED
    >
    <!ELEMENT texte (#PCDATA)>
    <!ATTLIST texte
        top CDATA #IMPLIED
        left CDATA #IMPLIED
        width CDATA #IMPLIED
        height CDATA #IMPLIED
    >
    <!ELEMENT image EMPTY>
    <!ATTLIST image
        top CDATA #IMPLIED
        left CDATA #IMPLIED
        width CDATA #IMPLIED
        height CDATA #IMPLIED
        source CDATA #REQUIRED
        title CDATA #IMPLIED
    >
    <!ELEMENT bloc_texte (
        texte+
    )>
    <!ATTLIST bloc_texte
        top CDATA #IMPLIED
        left CDATA #IMPLIED
        width CDATA #IMPLIED
        height CDATA #IMPLIED
    >
    <!ELEMENT bloc_image (
        image+
    )>
    <!ATTLIST bloc_image
        top CDATA #IMPLIED
        left CDATA #IMPLIED
        width CDATA #IMPLIED
        height CDATA #IMPLIED
    >
    <!ELEMENT parametre (
        parametre*
    )>
    <!ATTLIST parametre
        name CDATA #REQUIRED
        value CDATA #REQUIRED
    >
    <!ELEMENT djvusegment (
        texte | image | parametre | bloc_texte | bloc_image | djvusegment
    )*>
    <!ATTLIST djvusegment
        top CDATA #IMPLIED
        left CDATA #IMPLIED
        width CDATA #IMPLIED
        height CDATA #IMPLIED
    >
    <!ELEMENT djvuhidden (
        texte | image | parametre | bloc_texte | bloc_image | djvusegment | djvuhidden
    )*>
    <!ATTLIST djvuhidden
        top CDATA #IMPLIED
        left CDATA #IMPLIED
        width CDATA #IMPLIED
        height CDATA #IMPLIED
    >
    <!ELEMENT djvumap (
        texte | image | parametre | bloc_texte | bloc_image | djvusegment | djvuhidden | djvumap
    )*>
    <!ATTLIST djvumap
        top CDATA #IMPLIED
        left CDATA #IMPLIED
        width CDATA #IMPLIED
        height CDATA #IMPLIED
    >
    <!ELEMENT djvukey (
        texte | image | parametre | bloc_texte | bloc_image | djvusegment | djvuhidden | djvumap | djvukey
    )*>
    <!ATTLIST djvukey
        top CDATA #IMPLIED
        left CDATA #IMPLIED
        width CDATA #IMPLIED
        height CDATA #IMPLIED
    >
    <!ELEMENT djvutextonly (
        texte | image | parametre | bloc_texte | bloc_image | djvusegment | djvuhidden | djvumap | djvukey | djvutextonly
    )*>
    <!ATTLIST djvutextonly
        top CDATA #IMPLIED
        left CDATA #IMPLIED
        width CDATA #IMPLIED
        height CDATA #IMPLIED
    >
    <!ELEMENT djvufreetext (
        texte | image | parametre | bloc_texte | bloc_image | djvusegment | djvuhidden | djvumap | djvukey | djvutextonly | djvufreetext
    )*>
    <!ATTLIST djvufreetext
        top CDATA #IMPLIED
        left CDATA #IMPLIED
        width CDATA #IMPLIED
        height CDATA #IMPLIED
    >

       PARAM Elements

    Les éléments param sont utilisés pour stocker des attributs globaux tels que le nom du document, le nom de l'auteur, le titre, etc.

       HIDDENTEXT Elements

    Les éléments djvuhidden sont utilisés pour le texte caché.

       MAP Elements

    Les éléments djvumap sont utilisés pour définir des liens hypertexte.
