NOM

MD2, MD4, MD5, MD2_Init, MD2_Update, MD2_Final, MD4_Init, MD4_Update, MD4_Final, MD5_Init, MD5_Update, MD5_Final - Fonctions de hachage MD2, MD4 et MD5

SYNTAXE

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

#include <openssl/md2.h>
unsigned char *MD2(const unsigned char *d, unsigned long n, unsigned char *md);
int MD2_Init(MD2_CTX *c);
int MD2_Update(MD2_CTX *c, const unsigned char *data, unsigned long len);
int MD2_Final(unsigned char *md, MD2_CTX *c);

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

#include <openssl/md4.h>
unsigned char *MD4(const unsigned char *d, unsigned long n, unsigned char *md);
int MD4_Init(MD4_CTX *c);
int MD4_Update(MD4_CTX *c, const void *data, unsigned long len);
int MD4_Final(unsigned char *md, MD4_CTX *c);

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

#include <openssl/md5.h>
unsigned char *MD5(const unsigned char *d, unsigned long n, unsigned char *md);
int MD5_Init(MD5_CTX *c);
int MD5_Update(MD5_CTX *c, const void *data, unsigned long len);
int MD5_Final(unsigned char *md, MD5_CTX *c);

DESCRIPTION

Toutes les fonctions décrites dans cette page sont dépréciées. Les applications devraient utiliser à la place EVP_DigestInit_ex(3), EVP_DigestUpdate(3) et EVP_DigestFinal_ex(3).

MD2, MD4 et MD5 sont des fonctions de hachage cryptographiques avec une sortie de 128 bits.

MD2(), MD4() et MD5() calculent le résumé de message MD2, MD4 et MD5 des n octets à l'adresse d et le placent dans md (qui doit avoir de la place pour MD2_DIGEST_LENGTH == MD4_DIGEST_LENGTH == MD5_DIGEST_LENGTH == 16 octets de sortie). Si md est NULL, le résumé est placé dans un tableau statique.

Les fonctions suivantes peuvent être utilisées si le message n'est pas entièrement stocké en mémoire :

MD2_Init() initialise une structure MD2_CTX.

MD2_Update() peut être appelée de manière répétée avec des morceaux du message à hacher (len octets à l'adresse data).

MD2_Final() place le résumé du message dans md, qui doit avoir de la place pour MD2_DIGEST_LENGTH == 16 octets de sortie, et efface le MD2_CTX.

MD4_Init(), MD4_Update(), MD4_Final(), MD5_Init(), MD5_Update() et MD5_Final() sont analogues en utilisant une structure MD4_CTX et MD5_CTX. Le paramètre NE DOIT PAS être NULL.

Les applications devraient utiliser les fonctions de niveau supérieur EVP_DigestInit(3) etc. au lieu d'appeler directement les fonctions de hachage.

NOTE

MD2, MD4 et MD5 sont recommandés uniquement pour la compatibilité avec les applications existantes. Dans les nouvelles applications, les hachages de la famille SHA-2 ou SHA-3 devraient être préférés.

VALEUR DE RETOUR

MD2(), MD4() et MD5() retournent des pointeurs vers la valeur de hachage.

MD2_Init(), MD2_Update(), MD2_Final(), MD4_Init(), MD4_Update(), MD4_Final(), MD5_Init(), MD5_Update() et MD5_Final() retournent 1 en cas de succès, 0 sinon.
