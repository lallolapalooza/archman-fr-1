MDC2_Init(3ssl)

Paquet: openssl

MDC2_INIT(3ssl) OpenSSL MDC2_INIT(3ssl)

NOM

MDC2, MDC2_Init, MDC2_Update, MDC2_Final - Fonction de hachage MDC2

SYNTAXE

#include <openssl/mdc2.h>

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

unsigned char *MDC2(const unsigned char *d, unsigned long n,
                    unsigned char *md);
int MDC2_Init(MDC2_CTX *c);
int MDC2_Update(MDC2_CTX *c, const unsigned char *data,
                unsigned long len);
int MDC2_Final(unsigned char *md, MDC2_CTX *c);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient utiliser à la place EVP_DigestInit_ex(3), EVP_DigestUpdate(3) et EVP_DigestFinal_ex(3).

MDC2 est une méthode pour construire des fonctions de hachage avec une sortie de 128 bits à partir de chiffrements par bloc. Ces fonctions sont une implémentation de MDC2 avec DES.

MDC2() calcule le condensat de message MDC2 des n octets de d et le place dans md (qui doit avoir de la place pour MDC2_DIGEST_LENGTH == 16 octets de sortie). Si md est NULL, le condensat est placé dans un tableau statique.

Les fonctions suivantes peuvent être utilisées si le message n'est pas entièrement stocké en mémoire :

MDC2_Init() initialise une structure MDC2_CTX.

MDC2_Update() peut être appelée à plusieurs reprises avec des fragments du message à hacher (len octets à data).

MDC2_Final() place le condensat du message dans md, qui doit avoir de la place pour MDC2_DIGEST_LENGTH == 16 octets de sortie, et efface le MDC2_CTX.

Les applications devraient utiliser les fonctions de plus haut niveau EVP_DigestInit(3) etc. au lieu d'appeler directement les fonctions de hachage.

VALEURS DE RETOUR

MDC2() retourne un pointeur vers la valeur de hachage.

MDC2_Init(), MDC2_Update() et MDC2_Final() retournent 1 en cas de succès, 0 sinon.

CONFORMITÉ

ISO/IEC 10118-2:2000 Hash-Function 2, avec DES comme chiffrement par bloc sous-jacent.

VOIR AUSSI

EVP_DigestInit(3)

HISTORIQUE

Toutes ces fonctions ont été dépréciées dans OpenSSL 3.0.
