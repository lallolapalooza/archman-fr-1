MIME::Base64(3perl) Guide de référence du programmeur Perl MIME::Base64(3perl)

NOM

MIME::Base64 - Encodage et décodage de chaînes base64

SYNOPSIS

use MIME::Base64;
$encoded = encode_base64('Aladdin:open sesame');
$decoded = decode_base64($encoded);

DESCRIPTION

Ce module fournit des fonctions pour encoder et décoder des chaînes vers et depuis le codage base64 spécifié dans la RFC 2045 - MIME (Multipurpose Internet Mail Extensions). Le codage base64 est conçu pour représenter des séquences arbitraires d'octets sous une forme qui n'a pas besoin d'être lisible par l'homme. Un sous-ensemble de 65 caractères ([A-Za-z0-9+/=]) de l'US-ASCII est utilisé, permettant de représenter 6 bits par caractère imprimable.

Les fonctions principales suivantes sont fournies :

encode_base64( $octets )
encode_base64( $octets, $eol );
Encode des données en appelant la fonction encode_base64(). Le premier argument est la chaîne d'octets à encoder. Le second argument est la séquence de fin de ligne à utiliser. Il est facultatif et vaut par défaut "\n". La chaîne encodée retournée est divisée en lignes de 76 caractères au maximum chacune et se terminera par $eol, sauf si elle est vide. Passez une chaîne vide comme second argument si vous ne souhaitez pas que la chaîne encodée soit divisée en lignes.

La fonction provoquera une erreur avec "Wide character in subroutine entry" si $octets contient des caractères dont le code est supérieur à 255. Le codage base64 n'est défini que pour les caractères mono-octet. Utilisez le module Encode pour sélectionner l'encodage d'octets que vous souhaitez.

decode_base64( $str )
Décode une chaîne base64 en appelant la fonction decode_base64(). Cette fonction prend un seul argument qui est la chaîne à décoder et retourne les données décodées.

Tout caractère ne faisant pas partie du sous-ensemble de 65 caractères base64 est ignoré silencieusement. Les caractères survenant après un caractère de remplissage '=' ne sont jamais décodés.

Si vous préférez ne pas importer ces routines dans votre espace de noms, vous pouvez les appeler ainsi :

use MIME::Base64 ();
$encoded = MIME::Base64::encode($decoded);
$decoded = MIME::Base64::decode($encoded);

Fonctions supplémentaires non exportées par défaut :

encode_base64url( $octets )
decode_base64url( $str )
Encode et décode selon le schéma base64 pour les « applications URL » [1]. Il s'agit d'une variante de l'encodage base64 qui n'utilise pas de remplissage, ne divise pas la chaîne en plusieurs lignes et utilise les caractères « - » et « _ » au lieu de « + » et « / » pour éviter d'utiliser des caractères réservés aux URL.
encoded_base64_length( $octets )
encoded_base64_length( $octets, $eol )
Retourne la longueur que la chaîne encodée aurait sans l'encoder réellement. Cela retournera la même valeur que "length(encode_base64($octets))", mais devrait être plus efficace.
decoded_base64_length( $str )
Retourne la longueur que la chaîne décodée aurait sans la décoder réellement. Cela retournera la même valeur que "length(decode_base64($str))", mais devrait être plus efficace.

EXEMPLES

Si vous souhaitez encoder un gros fichier, vous devriez l'encoder par morceaux multiples de 57 octets. Cela garantit que les lignes base64 s'alignent et que vous ne vous retrouvez pas avec du remplissage au milieu. 57 octets de données remplissent une ligne base64 complète (76 == 57*4/3) :

use MIME::Base64 qw(encode_base64);
open(FILE, "/var/log/wtmp") or die "$!";
while (read(FILE, $buf, 60*57)) {
    print encode_base64($buf);
}

ou si vous savez que vous avez assez de mémoire

use MIME::Base64 qw(encode_base64);
local($/) = undef;  # tout lire d'un coup
print encode_base64(<STDIN>);

La même approche en ligne de commande :

perl -MMIME::Base64 -0777 -ne 'print encode_base64($_)' <fichier

Le décodage ne nécessite pas le mode tout lire si chaque ligne contient un multiple de quatre caractères base64 :

perl -MMIME::Base64 -ne 'print decode_base64($_)' <fichier

Perl v5.8 et supérieur autorise les caractères Unicode étendus dans les chaînes. De telles chaînes ne peuvent pas être encodées directement, car l'encodage base64 n'est défini que pour les caractères mono-octet. La solution est d'utiliser le module Encode pour sélectionner l'encodage d'octets souhaité. Par exemple :

use MIME::Base64 qw(encode_base64);
use Encode qw(encode);
$encoded = encode_base64(encode("UTF-8", "\x{FFFF}\n"));
print $encoded;
