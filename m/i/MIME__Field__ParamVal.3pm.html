NOM

MIME::Field::ParamVal - sous-classe de Mail::Field, pour les champs MIME structurés

SYNOPSIS

# Créer un objet pour un champ content-type :
$field = new Mail::Field 'Content-type';
# Définir certains attributs :
$field->param('_'        => 'text/html');
$field->param('charset'  => 'us-ascii');
$field->param('boundary' => '---ABC---');
# Identique :
$field->set('_'        => 'text/html',
            'charset'  => 'us-ascii',
            'boundary' => '---ABC---');
# Obtenir un attribut, ou undef s'il n'est pas présent :
print "pas d'id !"  if defined($field->param('id'));
# Identique, mais utiliser une chaîne vide pour les valeurs manquantes :
print "pas d'id !"  if ($field->paramstr('id') eq '');
# Afficher sous forme de chaîne :
print $field->stringify, "\n";

DESCRIPTION

Ceci est une classe mère abstraite de la plupart des champs MIME. Elle gère les champs avec une syntaxe générale comme celle-ci :

Content-Type: Message/Partial;
    number=2; total=3;
    id="oc=jpbe0M2Yt4s@thumper.bellcore.com"

Les commentaires sont pris en charge *entre* les éléments, comme ceci :

Content-Type: Message/Partial; (un commentaire)
    number=2  (un autre commentaire) ; (encore un autre commentaire) total=3;
    id="oc=jpbe0M2Yt4s@thumper.bellcore.com"

INTERFACE PUBLIQUE

set [\%PARAMHASH | KEY=>VAL,...,KEY=>VAL]
Méthode d'instance. Définit ce champ. Le paramhash doit contenir les noms de paramètres en *minuscules*, le nom de paramètre spécial "_" signifiant le paramètre "défaut" (sans nom) pour le champ : 
# Configurer pour être...
#
#     Content-type: Message/Partial; number=2; total=3; id="ocj=pbe0M2"
#
$conttype->set('_'       => 'Message/Partial',
               'number'  => 2,
               'total'   => 3,
               'id'      => "ocj=pbe0M2");

Notez qu'un seul argument est interprété comme une *référence* à un paramhash, tandis que plusieurs arguments sont interprétés comme les éléments du paramhash eux-mêmes.

Fournir undef pour un hashref, ou un ensemble vide de valeurs, efface effectivement l'objet.

L'objet lui-même est retourné.

parse_params CHAINE
Méthode utilitaire de classe/instance. Extrait les informations de paramètre d'un champ structuré et les retourne sous forme de référence de hachage. Par exemple, voici un champ avec des paramètres : 
Content-Type: Message/Partial;
    number=2; total=3;
    id="oc=jpbe0M2Yt4s@thumper.bellcore.com"

Voici comment les extraire :

$params = $class->parse_params('content-type');
if ($$params{'_'} eq 'message/partial') {
    $number = $$params{'number'};
    $total  = $$params{'total'};
    $id     = $$params{'id'};
}

Comme les noms de champs, les noms de paramètres sont convertis en minuscules. Le paramètre spécial '_' fait référence au paramètre par défaut du champ.

NOTE : Ceci a été fourni comme une méthode publique pour assurer la compatibilité ascendante, mais vous ne devriez probablement pas l'utiliser.

parse CHAINE
Méthode de classe/instance. Analyse la chaîne dans l'instance. Toute information précédente est effacée. L'objet lui-même est retourné.

Peut également être utilisé comme constructeur.

param NOMPARAMÈTRE,[VALEUR]
Méthode d'instance. Retourne le paramètre donné, ou undef s'il n'est pas présent. Avec un argument, définit le paramètre à cette VALEUR. Le NOMPARAMÈTRE est insensible à la casse. Un "_" fait référence au paramètre "défaut".
paramstr NOMPARAMÈTRE,[VALEUR]
Méthode d'instance. Comme param() : retourne le paramètre donné, ou une chaîne *vide* s'il n'est pas présent. Avec un argument, définit le paramètre à cette VALEUR. Le NOMPARAMÈTRE est insensible à la casse. Un "_" fait référence au paramètre "défaut".
stringify
Méthode d'instance. Convertit le champ en une chaîne et la retourne.
tag
Méthode d'instance, abstraite. Retourne l'étiquette (tag) pour ce champ.
