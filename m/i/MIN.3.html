MAX(3) Manuel des fonctions de bibliothèque MAX(3)

NOM

MAX, MIN — maximum ou minimum de deux valeurs

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <sys/param.h>
MAX(a, b);
MIN(a, b);

DESCRIPTION

Ces macros retournent le maximum ou le minimum de a et b.

VALEUR DE RETOUR

Ces macros retournent la valeur de l'un de leurs arguments, potentiellement convertie dans un autre type (voir ERREURS).

ERREURS

Ces macros peuvent déclencher l'exception flottante « invalide » lorsque l'un des arguments est NaN.

NORMES

GNU, BSD.

NOTES

Si l'un des arguments est de type à virgule flottante, vous préférerez peut-être utiliser fmax(3) ou fmin(3), qui peuvent gérer les NaN.

Les arguments peuvent être évalués plus d'une fois, ou pas du tout.

Certains systèmes UNIX peuvent fournir ces macros dans un autre en-tête, ou pas du tout.

BOGUES

En raison des conversions arithmétiques habituelles, le résultat de ces macros peut être très différent de l'un ou l'autre des arguments. Pour éviter cela, assurez-vous que les deux arguments ont le même type.

EXEMPLES

#include <stdio.h>
#include <stdlib.h>
#include <sys/param.h>
int
main(int argc, char *argv[])
{
    int a, b, x;
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <num> <num>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    a = atoi(argv[1]);
    b = atoi(argv[2]);
    x = MAX(a, b);
    printf("MAX(%d, %d) est %d\n", a, b, x);
    exit(EXIT_SUCCESS);
}

VOIR AUSSI

fmax(3), fmin(3)
