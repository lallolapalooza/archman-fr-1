NOM

MIME::Charset - Informations sur les jeux de caractères pour MIME

SYNOPSIS

use MIME::Charset:
$charset = MIME::Charset->new("euc-jp");

Obtenir des informations sur les jeux de caractères :

$benc = $charset->body_encoding; # par ex. "Q"
$cset = $charset->as_string; # par ex. "US-ASCII"
$henc = $charset->header_encoding; # par ex. "S"
$cset = $charset->output_charset; # par ex. "ISO-2022-JP"

Traduire des données textuelles :

$text = $charset->decode(
    ""=?UTF-8?Q?Perl=E8=A8=80=E8=AA=9E?""
);
($text, $charset, $encoding) =
    $charset->header_encode(
       "\xc9\xc2\xc5\xaa\xc0\xde\xc3\xef\xc5\xaa".
       "\xc7\xd1\xca\xaa\xbd\xd0\xce\xcf\xb4\xef",
       Charset => 'euc-jp');
# ...renvoie par ex. (, "ISO-2022-JP", "B").
($text, $charset, $encoding) =
    $charset->body_encode(
        "Collectioneur path\xe9tiquement ".
        "\xe9clectique de d\xe9chets",
        Charset => 'latin1');
# ...renvoie par ex. (, "ISO-8859-1", "QUOTED-PRINTABLE").
$len = $charset->encoded_header_len(
    "Perl\xe8\xa8\x80\xe8\xaa\x9e",
    Charset => 'utf-8',
    Encoding => "b");
# ...renvoie par ex. 28.

Manipulation des valeurs par défaut de la bibliothèque :

MIME::Charset::alias("csEUCKR", "euc-kr");
MIME::Charset::default("iso-8859-1");
MIME::Charset::fallback("us-ascii");

Fonctions non-OO (pourraient être obsolètes dans un futur proche) :

use MIME::Charset qw(:info);
$benc = body_encoding("iso-8859-2"); # "Q"
$cset = canonical_charset("ANSI X3.4-1968"); # "US-ASCII"
$henc = header_encoding("utf-8"); # "S"
$cset = output_charset("shift_jis"); # "ISO-2022-JP"
use MIME::Charset qw(:trans);
($text, $charset, $encoding) =
    header_encode(
       "\xc9\xc2\xc5\xaa\xc0\xde\xc3\xef\xc5\xaa".
       "\xc7\xd1\xca\xaa\xbd\xd0\xce\xcf\xb4\xef",
       "euc-jp");
# ...renvoie (, "ISO-2022-JP", "B").
($text, $charset, $encoding) =
    body_encode(
        "Collectioneur path\xe9tiquement ".
        "\xe9clectique de d\xe9chets",
        "latin1");
# ...renvoie (, "ISO-8859-1", "QUOTED-PRINTABLE").
$len = encoded_header_len(
    "Perl\xe8\xa8\x80\xe8\xaa\x9e", "b", "utf-8"); # 28

DESCRIPTION

MIME::Charset fournit des informations sur les jeux de caractères utilisés dans les messages MIME sur Internet.

Définitions

Le charset est le « jeu de caractères » utilisé dans MIME pour désigner une méthode de conversion d'une séquence d'octets en une séquence de caractères. Il inclut à la fois les concepts de « jeu de caractères codés » (CCS) et de « schéma d'encodage » (CES) de l'ISO/IEC.

L'encoding est la méthode utilisée dans MIME pour désigner la représentation d'un corps de message ou d'un champ d'en-tête sous forme de séquences de caractères imprimables US-ASCII.

Constructeur

$charset = MIME::Charset->new([CHARSET [, OPTS]])
Crée un objet de type charset.

OPTS peut accepter les paires clé-valeur suivantes. NOTE : Lorsque le support Unicode/multioctets est désactivé (voir "USE_ENCODE"), la conversion ne sera pas effectuée. Par conséquent, cette option n'aura aucun effet.

Mapping => MAPTYPE
Les mappages utilisés pour les noms de charset sont-ils étendus ou non ? "EXTENDED" utilise des mappages étendus. "STANDARD" utilise des mappages standardisés stricts. La valeur par défaut est "EXTENDED".

Obtenir des informations sur les jeux de caractères

$charset->body_encoding
body_encoding CHARSET
Obtient le type d'encodage recommandé pour le corps du message pour CHARSET. La valeur retournée sera l'un des éléments suivants : "B" (BASE64), "Q" (QUOTED-PRINTABLE), "S" (le moindre des deux) ou "undef" (pas de transfert ; 7BIT ou 8BIT). Ce ne sera pas toujours le même que le type d'encodage pour l'en-tête du message.
$charset->as_string
canonical_charset CHARSET
Obtient le nom canonique d'un charset.
$charset->decoder
Obtient l'objet "Encode::Encoding" pour décoder des chaînes en Unicode à l'aide du charset. Si le charset n'est pas spécifié ou n'est pas reconnu par cette bibliothèque, undef sera retourné.
$charset->dup
Obtient une copie de l'objet charset.
$charset->encoder([CHARSET])
Obtient l'objet "Encode::Encoding" pour encoder une chaîne Unicode en utilisant le charset recommandé pour les messages Internet.

Si un CHARSET optionnel est spécifié, il remplacera l'encodeur (et le nom du charset de sortie) de l'objet $charset par ceux de CHARSET, l'objet $charset se convertissant ainsi entre le charset d'origine et le nouveau CHARSET.

$charset->header_encoding
header_encoding CHARSET
Obtient le schéma d'encodage recommandé pour l'en-tête du message de CHARSET. La valeur retournée sera l'un des éléments suivants : "B", "Q", "S" (le moindre des deux) ou "undef" (non encodé). Ce ne sera pas toujours le même que le type d'encodage pour le corps du message.
$charset->output_charset
output_charset CHARSET
Obtient un charset compatible avec le CHARSET donné et recommandé pour les messages MIME sur Internet (s'il est connu de cette bibliothèque).

Lorsque le support Unicode/multioctets est désactivé (voir "USE_ENCODE"), cette fonction retournera simplement le résultat de "canonical_charset".

Traduire les données textuelles

$charset->body_encode(STRING [, OPTS])
body_encode STRING, CHARSET [, OPTS]
Obtient les données converties (si nécessaire) et le type d'encodage recommandé pour le corps du message de STRING. CHARSET est le charset pour lequel STRING est encodé.

OPTS peut accepter les paires clé-valeur suivantes. NOTE : Lorsque le support Unicode/multioctets est désactivé (voir "USE_ENCODE"), la conversion ne sera pas effectuée. Par conséquent, ces options n'auront aucun effet.

Detect7bit => YESNO
Tente de détecter le charset 7 bits lorsque CHARSET n'est pas spécifié. La valeur par défaut est "YES".
Replacement => REPLACEMENT
Schéma de gestion des erreurs. Voir "Gestion des erreurs".

Une liste de 3 éléments (chaîne convertie, charset de sortie, type d'encodage) sera retournée. Le type d'encodage sera l'un des éléments suivants : "BASE64", "QUOTED-PRINTABLE", "7BIT" ou "8BIT". Si le charset de sortie ne peut être déterminé et que la chaîne convertie contient des octets non ASCII, le charset de sortie sera "undef" et le type d'encodage sera "BASE64". Le charset de sortie sera "US-ASCII" si et seulement si la chaîne ne contient aucun octet non ASCII.

$charset->decode(STRING [,CHECK])
Décode STRING en Unicode.

Note : Lorsque le support Unicode/multioctets est désactivé (voir "USE_ENCODE"), cette fonction s'arrêtera.

detect_7bit_charset CHAÎNE
Devine le jeu de caractères 7 bits qui peut encoder une CHAÎNE. Si STRING contient des octets 8 bits, "undef" sera retourné. Sinon, le jeu de caractères par défaut sera retourné pour les jeux de caractères inconnus.
$charset->encode(CHAÎNE [, VÉRIFIER])
Encode la CHAÎNE (Unicode ou non-Unicode) en utilisant le jeu de caractères compatible recommandé pour les messages sur Internet (si ce module le connaît). Notez que la chaîne sera décodée en Unicode puis encodée même si le jeu de caractères compatible était égal au jeu de caractères d'origine.

Note : Lorsque le support Unicode/multioctets est désactivé (voir "USE_ENCODE"), cette fonction échouera.

$charset->encoded_header_len(CHAÎNE [, ENCODAGE])
encoded_header_len CHAÎNE, ENCODAGE, CHARSET
Obtenir la longueur de la CHAÎNE encodée pour l'en-tête du message (sans repliement).

ENCODAGE peut être l'un de "B", "Q" ou "S" (le plus court entre "B" ou "Q").

$charset->header_encode(CHAÎNE [, OPTS])
header_encode CHAÎNE, CHARSET [, OPTS]
Obtenir les données converties (si nécessaire) de la CHAÎNE et le schéma d'encodage recommandé pour ces données pour les en-têtes de message. CHARSET est le jeu de caractères par lequel la CHAÎNE est encodée.

OPTS peut accepter les paires clé-valeur suivantes. NOTE : Lorsque le support Unicode/multioctets est désactivé (voir "USE_ENCODE"), la conversion ne sera pas effectuée. Ces options n'auront donc aucun effet.

Detect7bit => OUI/NON
Essayer de détecter automatiquement le jeu de caractères 7 bits lorsque CHARSET n'est pas donné. Par défaut, c'est "OUI".
Replacement => REMPLACEMENT
Spécifie le schéma de gestion des erreurs. Voir "Gestion des erreurs".

Une liste de 3 éléments (chaîne convertie, jeu de caractères de sortie, schéma d'encodage) sera retournée. Le schéma d'encodage sera soit "B", "Q", soit "undef" (peut ne pas être encodé). Si le jeu de caractères de sortie ne peut être déterminé et que la chaîne convertie contient des octets non-ASCII, le jeu de caractères de sortie sera "8BIT" (ce n'est *pas* un nom de jeu de caractères, mais une valeur spéciale pour représenter des données non encodables) et le schéma d'encodage sera "undef" (ne devrait pas être encodé). Le jeu de caractères de sortie sera "US-ASCII" si et seulement si la chaîne ne contient aucun octet non-ASCII.

$charset->undecode(CHAÎNE [,VÉRIFIER])
Encode la chaîne Unicode CHAÎNE en chaîne d'octets par le jeu de caractères d'entrée de $charset. Ceci est équivalent à "$charset->decoder->encode()".

Note : Lorsque le support Unicode/multioctets est désactivé (voir "USE_ENCODE"), cette fonction échouera.

Manipulation des Valeurs par Défaut du Module

alias ALIAS [, CHARSET]
Obtenir/définir un alias de jeu de caractères pour les noms canoniques déterminés par "canonical_charset".

Si CHARSET est donné et n'est pas faux, ALIAS sera assigné comme un alias de CHARSET. Sinon, l'alias ne sera pas modifié. Dans les deux cas, le nom de jeu de caractères actuel auquel ALIAS est assigné sera retourné.

default [CHARSET]
Obtenir/définir le jeu de caractères par défaut.

Le jeu de caractères par défaut est utilisé par ce module lorsque le contexte du jeu de caractères est inconnu. Il est recommandé aux modules utilisant ce module d'utiliser ce jeu de caractères lorsque le contexte est inconnu ou qu'un défaut implicite est attendu. Par défaut, c'est "US-ASCII".

Si CHARSET est donné et n'est pas faux, il sera défini comme le jeu de caractères par défaut. Sinon, le jeu de caractères par défaut ne sera pas modifié. Dans les deux cas, le jeu de caractères par défaut actuel sera retourné.

NOTE : Le jeu de caractères par défaut *ne devrait pas* être modifié.

fallback [CHARSET]
Obtenir/définir le jeu de caractères de repli.

Le jeu de caractères de repli est utilisé par ce module lorsque la conversion par le jeu de caractères donné échoue et que le schéma de gestion des erreurs "FALLBACK" est spécifié. Les modules utilisant ce module peuvent utiliser ce jeu de caractères comme dernier recours pour la conversion. Par défaut, c'est "UTF-8".

Si CHARSET est donné et n'est pas faux, il sera défini comme le jeu de caractères de repli. Si CHARSET est "NONE", le jeu de caractères de repli sera indéfini. Sinon, le jeu de caractères de repli ne sera pas modifié. Dans tous les cas, le jeu de caractères de repli actuel sera retourné.

NOTE : Il *est* utile de spécifier "US-ASCII" comme jeu de caractères de repli, car le résultat de la conversion sera lisible sans information de jeu de caractères.

recommended CHARSET [, ENCODAGE_EN_TETE, ENCODAGE_CORPS [, CHARSET_ENC]]
Obtenir/définir les profils de jeu de caractères.

Si des arguments optionnels sont donnés et que l'un d'eux n'est pas faux, les profils pour CHARSET seront définis par ces arguments. Sinon, les profils ne seront pas modifiés. Dans les deux cas, les profils actuels pour CHARSET seront retournés sous forme de liste de 3 éléments (ENCODAGE_EN_TETE, ENCODAGE_CORPS, CHARSET_ENC).

ENCODAGE_EN_TETE est le schéma d'encodage recommandé pour l'en-tête du message. Il peut être l'un de "B", "Q", "S" (le plus court entre les deux) ou "undef" (peut ne pas être encodé).

ENCODAGE_CORPS est l'encodage de transfert recommandé pour le corps du message. Il peut être l'un de "B", "Q", "S" (le plus court entre les deux) ou "undef" (peut ne pas être encodé en transfert).

CHARSET_ENC est un jeu de caractères compatible avec le CHARSET donné et recommandé pour les messages MIME sur Internet. Si la conversion n'est pas nécessaire (ou si ce module ne connaît pas de jeu de caractères approprié), CHARSET_ENC est "undef".

NOTE : Cette fonction, dans les futures versions, pourrait accepter plus d'arguments optionnels (par exemple, des propriétés pour gérer les largeurs de caractères, le comportement de repliement de ligne, ...). Le format de la valeur retournée pourrait donc probablement changer. Utilisez "header_encoding", "body_encoding" ou "output_charset" pour obtenir un profil particulier.

Constantes

USE_ENCODE
Indicateur de support Unicode/multioctets. Une chaîne non vide sera définie lorsque le support Unicode et multioctets est activé. Actuellement, cet indicateur sera non vide sur Perl 5.7.3 ou plus récent, et une chaîne vide sur les versions de Perl antérieures.

Gestion des Erreurs

"body_encode" et "header_encode" acceptent les options "Replacement" suivantes :

"DEFAULT"
Insère un caractère de substitution à la place d'un caractère malformé. Pour les encodages basés sur UCM, <subchar> sera utilisé.
"FALLBACK"
Essaye le schéma "DEFAULT" en utilisant le jeu de caractères de repli (voir "fallback"). Lorsque le jeu de caractères de repli est indéfini et que la conversion provoque une erreur, le code échouera avec un message d'erreur.
"CROAK"
Le code échouera immédiatement en cas d'erreur avec un message d'erreur. Par conséquent, vous devriez intercepter l'erreur fatale avec eval{} à moins que vous ne vouliez vraiment qu'elle échoue en cas d'erreur. Synonyme : "STRICT".
"PERLQQ"
"HTMLCREF"
"XMLCREF"
Utilise les schémas "FB_PERLQQ", "FB_HTMLCREF" ou "FB_XMLCREF" définis par le module Encode.
valeurs numériques
Les valeurs numériques sont également autorisées. Pour plus de détails, voir "Handling Malformed Data" dans Encode.

Si le schéma de gestion des erreurs n'est pas spécifié ou si un schéma inconnu est spécifié, "DEFAULT" sera supposé.

Fichier de Configuration

Les valeurs par défaut intégrées pour les paramètres d'options peuvent être remplacées par le fichier de configuration : MIME/Charset/Defaults.pm. Pour plus de détails, lisez MIME/Charset/Defaults.pm.sample.

Changements Incompatibles

Release 1.001
•
La méthode new() retourne un objet lorsque l'argument CHARSET n'est pas spécifié.
Release 1.005
•
Restreint les caractères dans les mots encodés conformément à la section 5 (3) de la RFC 2047. Cela affecte également la valeur de retour de la méthode encoded_header_len().
Release 1.008.2
  • La méthode body_encoding() peut également retourner "S".
  • La valeur de retour de la méthode body_encode() pour UTF-8 peut inclure "QUOTED-PRINTABLE" qui, dans les versions antérieures, était fixe à "BASE64".
