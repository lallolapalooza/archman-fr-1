NOM

MIME::QuotedPrint - Encodage et décodage des chaînes quoted-printable

SYNOPSIS

use MIME::QuotedPrint;
$encoded = encode_qp($decoded);
$decoded = decode_qp($encoded);

DESCRIPTION

Ce module fournit des fonctions pour encoder et décoder des chaînes vers et depuis l'encodage quoted-printable spécifié dans le RFC 2045 - MIME (Multipurpose Internet Mail Extensions). L'encodage quoted-printable est destiné à représenter des données qui consistent principalement en octets correspondant à des caractères imprimables dans l'ensemble de caractères ASCII. Chaque caractère non imprimable (tel que défini par les Anglo-saxons) est représenté par un triplet composé du caractère "=" suivi de deux chiffres hexadécimaux.

Les fonctions suivantes sont fournies :

encode_qp( $str)
encode_qp( $str, $eol)
encode_qp( $str, $eol, $binmode )
Cette fonction retourne une version encodée de la chaîne ($str) fournie en argument.

Le deuxième argument ($eol) est la séquence de fin de ligne à utiliser. Il est optionnel et vaut par défaut "\n". Chaque occurrence de "\n" est remplacée par cette chaîne, et elle est également utilisée pour des "bris de ligne doux" supplémentaires afin de s'assurer qu'aucune ligne ne dépasse 76 caractères. Passez-la sous la forme "\015\012" pour produire des données adaptées à une utilisation externe. La chaîne "\r\n" produit le même résultat sur de nombreuses plateformes, mais pas toutes.

Le troisième argument ($binmode) activera le mode binaire s'il est passé comme valeur VRAIE. En mode binaire, "\n" sera encodé de la même manière que tout autre caractère non imprimable. Cela garantit qu'un décodeur obtiendra exactement la même chaîne, quelle que soit la séquence de fin de ligne utilisée. En général, il est préférable d'utiliser l'encodage base64 pour les données binaires ; voir MIME::Base64.

Une valeur $eol de "" (chaîne vide) est spéciale. Dans ce cas, aucun "bris de ligne doux" n'est introduit et le mode binaire est effectivement activé de sorte que tout "\n" dans les données d'origine soit également encodé.

decode_qp( $str )
Cette fonction retourne la version texte brut de la chaîne fournie en argument. Les lignes du résultat se terminent par "\n", même si l'argument $str contient des lignes se terminant par "\r\n".

Si vous préférez ne pas importer ces routines dans votre espace de noms, vous pouvez les appeler ainsi :

use MIME::QuotedPrint ();
$encoded = MIME::QuotedPrint::encode($decoded);
$decoded = MIME::QuotedPrint::decode($encoded);

Perl v5.8 et versions ultérieures autorisent les caractères Unicode étendus dans les chaînes. De telles chaînes ne peuvent pas être encodées directement, car l'encodage quoted-printable n'est défini que pour les caractères mono-octet. La solution consiste à utiliser le module Encode pour sélectionner l'encodage d'octets souhaité. Par exemple :

use MIME::QuotedPrint qw(encode_qp);
use Encode qw(encode);
$encoded = encode_qp(encode("UTF-8", "\x{FFFF}\n"));
print $encoded;
