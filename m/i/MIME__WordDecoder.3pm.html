NAME

MIME::WordDecoder - décoder des mots RFC 2047 vers une représentation locale

AVERTISSEMENT : Une grande partie de ce module est obsolète et peut l'être. La seule fonction que vous devriez utiliser pour décoder du MIME est mime_to_perl_string.

SYNOPSIS

Voir MIME::Words pour les bases des mots RFC 2047. Voir DESCRIPTION pour le fonctionnement de cette classe.

use MIME::WordDecoder;
### Obtenir le décodeur par défaut (utilisé par unmime()):
$wd = default MIME::WordDecoder;
### Obtenir un décodeur qui mappe vers ISO-8859-1 (Latin1):
$wd = supported MIME::WordDecoder 'ISO-8859-1';
### Décoder une chaîne MIME (par exemple, en Latin1) en utilisant le décodeur par défaut:
$str = $wd->decode('To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld>');
### Décoder une chaîne en utilisant le décodeur par défaut, style non OO:
$str = unmime('To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld>');
### Décoder une chaîne vers une chaîne Perl interne, style non OO
### Le résultat est probablement avec le flag UTF8 activé.
$str = mime_to_perl_string('To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld>');

DESCRIPTION

AVERTISSEMENT : Une grande partie de ce module est obsolète et peut l'être. Il duplique (très mal) la fonctionnalité du module standard 'Encode'. La seule fonction sur laquelle vous devriez compter est mime_to_perl_string.

Un MIME::WordDecoder consiste, fondamentalement, en une carte qui associe un nom de jeu de caractères (US-ASCII, ISO-8859-1, etc.) à une sous-routine qui sait comment convertir les octets dans ce jeu de caractères vers une représentation cible. Idéalement, cette représentation cible serait Unicode, mais nous ne voulons pas être trop spécifiques sur la traduction : si vous voulez convertir des chaînes MIME directement en Big5, c'est votre décision.

La sous-routine sera appelée avec deux arguments : DATA (les données dans le jeu de caractères donné) et CHARSET (le nom du jeu de caractères en majuscules).

Par exemple :

### Garder les caractères 7 bits tels quels, et convertir les caractères 8 bits en '#':
sub keep7bit {
    local $_ = shift;
    tr/\x00-\x7F/#/c;
    $_;
}

Voici un décodeur qui l'utilise :

### Construire un décodeur:
$wd = MIME::WordDecoder->new({'US-ASCII'   => 'KEEP',   ### sub { $_[0] }
                              'ISO-8859-1' => \&keep7bit,
                              'ISO-8859-2' => \&keep7bit,
                              'Big5'       => 'WARN',
                              '*'          => 'DIE'));
### Convertir quelques textes MIME en une chaîne ASCII pure...
$ascii = $wd->decode('To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld>');
### ...qui contiendra maintenant : "To: Keld J#rn Simonsen <keld>"

Le décodeur UTF-8 convertit tout en une représentation Perl interne, activant potentiellement le flag UTF8 en interne. Utilisez-le ainsi :

$wd = supported MIME::WordDecoder 'UTF-8';
$perl_string = $wd->decode('To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld>');
# $perl_string sera une chaîne valide avec le flag UTF8 activé.

Généralement, vous devriez utiliser le décodeur UTF-8 plutôt que unmime.

INTERFACE PUBLIQUE

default [DECODER]
Méthode de classe. Obtient/définit le DECODER par défaut.
supported CHARSET, [DECODER]
Méthode de classe. Si seul CHARSET est donné, retourne un objet DECODER qui mappe les données dans ce jeu de caractères (le jeu de caractères est forcé en majuscules). 
$wd = supported MIME::WordDecoder 'ISO-8859-1';

Si DECODER est donné, installe un tel objet :

MIME::WordDecoder->supported('ISO-8859-1' =>
                             (new MIME::WordDecoder::ISO_8859 '1'));

Vous ne devriez pas écraser cette méthode.

new [\@HANDLERS]
Méthode de classe, constructeur. Si \@HANDLERS est donné, alors \@HANDLERS est passé à handler() pour initialiser la carte interne.
handler CHARSET=>\&SUBREF, ...
Méthode d'instance. Définit la sous-routine SUBREF pour un jeu de caractères donné, pour autant de paires que vous le souhaitez.

Lors de la traduction d'un texte MIME codé, une sous-routine donnée sera appelée lorsqu'un bloc de texte dans le jeu de caractères CHARSET sera traduit. La sous-routine sera appelée avec les arguments suivants :

DATA    - les données dans le jeu de caractères donné.
CHARSET - le nom du jeu de caractères en majuscules, ce qui peut être utile si vous utilisez le même SUBREF pour plusieurs CHARSETs.
DECODER - le décodeur lui-même, s'il contient des informations de configuration dont votre fonction de gestionnaire a besoin.

Par exemple :

$wd = new MIME::WordDecoder;
$wd->handler('US-ASCII'   => 'KEEP');
$wd->handler('ISO-8859-1' => \&handle_latin1,
             'ISO-8859-2' => \&handle_latin1,
             '*'          => 'DIE');

Notez que, comme pour %SIG, le SUBREF peut également être pris d'un ensemble de mots-clés spéciaux :

KEEP     Passe les données sans changement.
IGNORE   Ignore les données dans ce jeu de caractères, sans avertissement.
WARN     Ignore les données dans ce jeu de caractères, avec avertissement.
DIE      Lève une exception fatale avec le message "can't handle character set".

La sous-routine pour le jeu de caractères spécial 'raw' est utilisée pour le texte non-MIME (non codé MIME), qui est censé être en ASCII. Le gestionnaire pour 'raw' se comporte par défaut comme spécifié pour 'US-ASCII' au moment de la construction.

La sous-routine pour le jeu de caractères spécial '*' est utilisée pour tout jeu de caractères non reconnu. Le comportement par défaut pour '*' est WARN.

decode STRING
Méthode d'instance. Décode une STRING qui peut contenir des composants MIME codés vers une représentation locale (par exemple, UTF-8, etc.).
unmime STRING
Fonction, exportée. Décode la STRING donnée en utilisant le décodeur default(). Voir default().

Vous devriez envisager d'utiliser le décodeur UTF-8 plutôt que unmime. Celui-ci décode les chaînes MIME en une représentation Perl interne.

mime_to_perl_string
Fonction, exportée. Décode la STRING donnée en une chaîne Perl interne Unicode. Vous devriez utiliser cette fonction de préférence à toutes les autres.

Le résultat de mime_to_perl_string est susceptible d'avoir le flag UTF8 activé dans la chaîne Perl.

SOUS-CLASSES

MIME::WordDecoder::ISO_8859
Un décodeur simple qui conserve les caractères 7 bits US-ASCII et les caractères 8 bits des jeux de caractères ISO-8859, ainsi que les caractères 8 bits des jeux indiqués. Il conserve également les caractères 8 bits des jeux de caractères indiqués. 
### Construire:
$wd = new MIME::WordDecoder::ISO_8859 2;    ### ISO-8859-2
### Que faire avec les caractères inconnus (peut aussi être vide):
### La valeur par défaut est '?'.
$wd->unknown('?');
### Réduire les séquences de caractères inconnus à un seul caractère inconnu?
### La valeur par défaut est false.
$wd->collapse(1);

Selon http://czyborra.com/charsets/iso8859.html (env. Novembre 2000) :

ISO 8859 est une série complète de 10 (et bientôt même plus) jeux de caractères graphiques multilingues standard (8 bits) pour écrire dans des langues alphabétiques :

 1. Latin1 (Europe occidentale)
 2. Latin2 (Europe orientale)
 3. Latin3 (Europe du sud)
 4. Latin4 (Europe du nord)
 5. Cyrillique
 6. Arabe
 7. Grec
 8. Hébreu
 9. Latin5 (Turc)
10. Latin6 (Nordique)

Les jeux de caractères ISO 8859 ne sont pas aussi complets que le véritable grand Unicode, mais ils sont disponibles et utilisables depuis un certain temps (enregistrés pour la première fois comme jeux de caractères pour une utilisation avec MIME) et offraient déjà une amélioration significative par rapport au traditionnel US-ASCII 7 bits.

Les caractères 0 à 127 sont toujours identiques à US-ASCII, et les positions 128 à 159 contiennent certains caractères de contrôle moins utilisés : les C1 de ISO 6429.

MIME::WordDecoder::US_ASCII
Une sous-classe du décodeur ISO-8859-1 qui ignore les 8 bits des jeux de caractères.

MIME::WordDecoder(3pm) - Perl manual page

NAME

MIME::WordDecoder - Decode MIME encoded words

SYNOPSIS

  use MIME::WordDecoder;
  my $decoder = MIME::WordDecoder->new();
  my $text = $decoder->decode($encoded_text);

DESCRIPTION

MIME::WordDecoder is a simple class for decoding MIME encoded words. Encoded words are defined in RFC 2047 and are used to represent non-ASCII characters in email headers.

The decode() method takes a string containing zero or more encoded words and returns a new string with all encoded words decoded.

For example:

    use MIME::WordDecoder;
    my $decoder = MIME::WordDecoder->new();
    my $header = 'Subject: =?ISO-8859-1?Q?This_is_a_test? =?UTF-8?B?4pyTIOKIlSA=9Q?=';
    my $decoded_header = $decoder->decode($header);
    # $decoded_header will be 'Subject: This is a test Äåä'

PUBLIC INTERFACE

new()
Creates a new MIME::WordDecoder object.
decode($string)
Decodes all MIME encoded words in the given string. It handles both quoted-printable (Q) and base64 (B) encodings. It also handles multiple encoded words within the same string.

SUBCLASSES

There are no public subclasses of MIME::WordDecoder.
