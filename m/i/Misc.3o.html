Exceptions et finalisation

val try_finally : ?always:(unit -> unit) -> ?exceptionally:(unit -> unit) -> (unit -> 'a) -> 'a

try_finally work ~always ~exceptionally est conçu pour exécuter du code dans work qui peut échouer avec une exception, et possède deux types de routines de nettoyage : always , qui doit être exécutée après chaque exécution de la fonction (typiquement, libérer des ressources système), et exceptionally , qui ne doit être exécutée que si work ou always a échoué avec une exception (typiquement, annuler des changements d'état visibles par l'utilisateur qui n'auraient de sens que si la fonction s'achevait correctement). Par exemple :

      let objfile = outputprefix ^ ".cmo" in
      let oc = open_out_bin objfile in
      Misc.try_finally
        (fun () ->
           bytecode
           ++ Timings.(accumulate_time (Generate sourcefile))
               (Emitcode.to_file oc modulename objfile);
           Warnings.check_fatal ())
        ~always:(fun () -> close_out oc)
        ~exceptionally:(fun _exn -> remove_file objfile);

Si exceptionally échoue avec une exception, elle est propagée comme d'habitude.

Si always ou exceptionally utilisent des exceptions en interne pour le contrôle de flux mais ne lèvent pas, alors try_finally prend soin de préserver toute trace d'exception provenant de work ou always pour faciliter le débogage.

val reraise_preserving_backtrace : exn -> (unit -> unit) -> 'a

reraise_preserving_backtrace e f est équivalent à (f (); raise e) sauf que la trace de pile actuelle est préservée, même si f utilise des exceptions en interne.

Opérations sur les listes

val map_end : ('a -> 'b) -> 'a list -> 'b list -> 'b list

map_end f l t est équivalent à map f l @ t , mais plus efficace.

val rev_map_end : ('a -> 'b) -> 'a list -> 'b list -> 'b list

rev_map_end f l t est équivalent à map f (rev l) @ t , mais plus efficace.

val map_left_right : ('a -> 'b) -> 'a list -> 'b list

Similaire à List.map , avec un ordre d'évaluation garanti de gauche à droite.

val for_all2 : ('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Identique à List.for_all mais pour un prédicat binaire. De plus, ce for_all2 ne plante jamais : étant donné deux listes de longueurs différentes, il renvoie faux.

val replicate_list : 'a -> int -> 'a list

replicate_list elem n est la liste contenant n éléments tous identiques à elem .

val list_remove : 'a -> 'a list -> 'a list

list_remove x l renvoie une copie de l avec le premier élément égal à x retiré.

val split_last : 'a list -> 'a list * 'a

Renvoie le dernier élément et les autres éléments de la liste donnée.

val repeated_label : (string option * 'a) list -> string option

Détecte un label répété - à utiliser avec des tuples labellisés.

Crée une table de hachage avec la taille initiale donnée et la remplit avec les liaisons fournies.

Opérations sur les fichiers et les chemins de fichiers

val find_in_path : string list -> string -> string

Recherche un fichier dans une liste de répertoires.

val find_in_path_rel : string list -> string -> string

Recherche un fichier relatif dans une liste de répertoires.

val normalized_unit_filename : string -> (string, string) Result.t

Normalise le nom de fichier Foo.ml en foo.ml , en utilisant NFC et la mise en minuscules. Renvoie Error si l'entrée n'est pas une séquence d'octets utf-8 valide.

val find_in_path_normalized : string list -> string -> string

Identique à Misc.find_in_path_rel , mais recherche également le nom de fichier d'unité normalisé, c'est-à-dire que si le nom est Foo.ml , elle autorise /path/Foo.ml et /path/foo.ml à correspondre.

val remove_file : string -> unit

Supprime le fichier donné s'il existe et est un fichier régulier. Ne fait rien pour les autres types de fichiers. Ne lève jamais d'erreur.

val expand_directory : string -> string -> string

expand_directory alt file développe éventuellement un + au début de file en alt (un répertoire racine alternatif).

val split_path_contents : ?sep:char -> string -> string list

split_path_contents ?sep s interprète s comme la valeur d'une variable de type "PATH" et renvoie la liste de répertoires correspondante. s est divisée en utilisant le délimiteur spécifique à la plateforme, ou ~sep si elle est passée.

Renvoie la liste vide si s est vide.

val copy_file : in_channel -> out_channel -> unit

copy_file ic oc lit le contenu du fichier ic et le copie vers oc . Elle s'arrête à la rencontre d'EOF sur ic .

val copy_file_chunk : in_channel -> out_channel -> int -> unit

copy_file_chunk ic oc n lit n octets depuis ic et les copie vers oc . Elle lève End_of_file en rencontrant EOF sur ic .

val string_of_file : in_channel -> string

string_of_file ic lit le contenu du fichier ic et le copie dans une chaîne. Elle s'arrête à la rencontre d'EOF sur ic .

val output_to_file_via_temporary : ?mode:open_flag list -> string -> (string -> out_channel -> 'a) -> 'a

Produit une sortie dans un fichier temporaire, puis le renomme (aussi atomiquement que possible) vers le nom de fichier de sortie désiré. output_to_file_via_temporary filename fn ouvre un fichier temporaire qui est passé à fn (nom + canal de sortie). Lorsque fn renvoie, le canal est fermé et le fichier temporaire est renommé en filename .

val protect_writing_to_file : filename:string -> f:(out_channel -> 'a) -> 'a

Ouvre le filename donné en écriture (en mode binaire), passe l'out_channel à la fonction donnée, puis ferme le canal. Si la fonction lève une exception, alors filename sera supprimé.

val concat_null_terminated : string list -> string

concat_null_terminated [x1;x2; ... xn] est équivalent à x1 ^ "\000" ^ x2 ^ "\000" ^ ... ^ xn ^ "\000"

val split_null_terminated : string -> string list

split_null_terminated s est similaire à String.split_on_char '\000' mais ignore le séparateur final, s'il y en a un.

val chop_extensions : string -> string

Renvoie le nom de fichier donné sans ses extensions. L'extension est le plus long suffixe commençant par

un point et ne pas inclure un séparateur de répertoire, par exemple .xyz.uvw.

Retourne le nom donné s'il ne contient pas d'extension.

val find_first_mono : (int -> bool) -> int

find_first_mono p prend un prédicat entier p : int -> bool que l'on suppose : 1. monotone sur les nombres naturels : si a <= b alors p a implique p b , 2. satisfait pour certains nombres naturels dans l'intervalle 0; max_int (ce qui est équivalent à : p max_int = true ).

find_first_mono p est le plus petit nombre naturel N qui satisfait p , calculé en O(log(N)) appels à p .

Notre implémentation prend en charge deux cas où les préconditions sur p ne sont pas respectées :

-Si p est toujours false , nous retournons silencieusement max_int au lieu de boucler ou de planter.

-Si p n'est pas monotone mais devient éventuellement vrai, nous retournons une valeur satisfaisante.

Opérations sur les chaînes

val search_substring : string -> string -> int -> int

search_substring pat str start retourne la position de la première occurrence de la chaîne pat dans la chaîne str . La recherche commence à l'indice start dans str . Lève Not_found si pat n'est pas trouvé.

val replace_substring : before:string -> after:string -> string -> string

replace_substring ~before ~after str remplace toutes les occurrences de before par after dans str et retourne la chaîne résultante.

val rev_split_words : string -> string list

rev_split_words s découpe s en mots séparés par des espaces et retourne la liste des mots dans l'ordre inverse.

val cut_at : string -> char -> string * string

String.cut_at s c retourne une paire contenant la sous-chaîne avant la première occurrence de c dans s , et la sous-chaîne après la première occurrence de c dans s . let (before, after) = String.cut_at s c in
before ^ String.make 1 c ^ after est l'identité si s contient c .

Lève Not_found si le caractère n'apparaît pas dans la chaîne.

Depuis 4.01

val ordinal_suffix : int -> string

ordinal_suffix n est le suffixe approprié à ajouter au numéral n sous forme de nombre ordinal : 1 -> "st" , 2 -> "nd" , 3 -> "rd" , 4 -> "th" , et ainsi de suite. Gère les grands nombres (par exemple, 42 -> "nd" ) et les nombres 11-13 (qui obtiennent tous "th" ) correctement.

val normalise_eol : string -> string

normalise_eol s retourne une copie fraîche de s avec les caractères '\r' supprimés. Destiné au prétraitement du texte qui sera ensuite imprimé sur un canal qui effectue des transformations EOL (c'est-à-dire Windows).

val delete_eol_spaces : string -> string

delete_eol_spaces s retourne une copie fraîche de s avec les espaces de fin de ligne supprimés. Destiné à normaliser la sortie du toplevel pour les tests.

Opérations sur les références

type ref_and_value =
| R : 'a ref * 'a -> ref_and_value

val protect_refs : ref_and_value list -> (unit -> 'a) -> 'a

protect_refs l f définit temporairement r à v pour chaque R (r, v) dans l tout en exécutant f . Les contenus précédents des références sont restaurés même si f lève une exception, sans altérer la trace de l'exception.

val get_ref : 'a list ref -> 'a list

get_ref lr retourne le contenu de la référence de liste lr et réinitialise son contenu à la liste vide.

val set_or_ignore : ('a -> 'b option) -> 'b option ref -> 'a -> unit

set_or_ignore f opt x définit opt à f x s'il retourne Some _ , ou le laisse inchangé s'il retourne None .

Correction orthographique et suggestions ``avez-vous voulu dire''

val edit_distance : string -> string -> int -> int option

edit_distance a b cutoff calcule la distance d'édition entre les chaînes a et b . Pour des raisons d'efficacité, elle utilise une coupure : si la distance d est inférieure à cutoff , elle retourne Some d , sinon None .

L'algorithme de distance actuellement utilisé est le Damerau-Levenshtein : il calcule le nombre d'insertions, de suppressions, de substitutions de lettres, ou d'échanges de lettres adjacentes pour passer d'un mot à l'autre. L'algorithme spécifique peut changer à l'avenir.

val spellcheck : string list -> string -> string list

spellcheck env name prend une liste de noms env qui existent dans l'environnement actuel et un name erroné, et retourne une liste de suggestions prises de env , qui sont suffisamment proches de name pour qu'il puisse s'agir d'une faute de frappe pour l'un d'eux.

val align_hint : prefix:string -> main:Format_doc.t -> hint:Format_doc.t -> Format_doc.t * Format_doc.t

aligned_hint main hint aligne verticalement un message main et un message d'aide hint . L'alignement vertical est contrôlé par l'utilisation de boîtes @{<ralign> ...
@} : le début d'une boîte, dans l'aide ou le message principal, sera décalé vers la gauche pour assurer que la fin des deux boîtes est alignée verticalement, en tenant compte d'un prefix préexistant avant le message principal. Par exemple,

let main, sub =
  align_hint
    ~prefix:"Error: "
    (doc_printf "@{<ralign>The value @}%a is not an instance variable"
      Style.inline_code "foobar"
    )
    (doc_printf
      "@{<ralign>Did you mean @}%a" Style.inline_code "foobaz"
    ) in
   printf "Error: %a%a" pp_doc main pp_doc sub

produit le texte suivant :

Error:   The value "foobaz" is not an instance variable
Hint: Did you mean "foobar"?

où le message principal a été décalé vers la gauche pour aligner "foobaz" et "foobar" .

val align_error_hint : main:Format_doc.t -> hint:Format_doc.t -> Format_doc.t * Format_doc.t

Identique à align_hint ~prefix:"Error: "

val aligned_hint : prefix:string -> Format_doc.formatter -> ('a, Format_doc.formatter, unit, Format_doc.t option -> unit) format4 -> 'a

aligned_hint ~prefix fmt ... hint aligne l'aide potentielle avec le message d'erreur principal généré par la chaîne de format fmt avant d'imprimer les deux messages.

val did_you_mean : ?pp:string Format_doc.printer -> string list -> Format_doc.t option

did_you_mean ~pp choices suggère que l'utilisateur a peut-être voulu dire l'une des options dans choices .

Chaque choix est imprimé avec la fonction pp , ou Style.inline_code si pp = None .
