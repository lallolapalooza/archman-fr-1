NOM

MIME::Type - description d'un type MIME

SYNOPIS

use MIME::Types;
my $mimetypes = MIME::Types->new;
my MIME::Type $plaintext = $mimetypes->type('text/plain');
print $plaintext->mediaType;   # text
print $plaintext->subType;     # plain
my @ext = $plaintext->extensions;
print "@ext"                   # txt asc c cc h hh cpp
print $plaintext->encoding     # 8bit
if($plaintext->isBinary)       # false
if($plaintext->isText)         # true
if($plaintext->equals('text/plain') {...}
if($plaintext eq 'text/plain') # same
print MIME::Type->simplified('x-appl/x-zip') #  'appl/zip'

DESCRIPTION

Les types MIME sont utilisés dans les entités MIME, par exemple dans le trafic e-mail et HTTP. Parfois, des connaissances réelles sur un type MIME sont nécessaires. Les objets de "MIME::Type" stockent les informations sur un tel type.

SURCHARGÉ

surcharge : "" transformation en chaîne
La transformation en chaîne (utilisation de l'objet dans un contexte où une chaîne est requise) aboutira au nom du type, de la même manière que type() retourne.

exemple : utilisation de la transformation en chaîne

my $mime = MIME::Type->new('text/html');
print "$mime\n";   # transformation explicite en chaîne
print $mime;       # transformation implicite en chaîne
surcharge : == comparaison numérique
Compare si le type() des objets est le même.
surcharge : cmp comparaison de chaînes
Lorsqu'un objet MIME::Type est comparé à une chaîne ou à un autre objet MIME::Type, la méthode equals() est appelée. La comparaison est intelligente, ce qui signifie qu'elle étend la comparaison de chaînes commune avec certaines fonctionnalités définies dans les RFC associées.

MÉTHODES

Initiation

$class->new(%options)
Crée (instancie) un nouvel objet MIME::Type qui gère un type MIME. 
-Option    --Défaut
 charset     undef
 encoding    <dépendant du type>
 extensions  []
 simplified  <dérivé du type>
 system      undef
 type        <requis>
charset => $charset
Spécifie le charset par défaut pour ce type.
encoding => '7bit'|'8bit'|'base64'|'quoted-printable'
Comment ces données doivent-elles être encodées pour être transportées en toute sécurité. Le défaut dépend du type : les MIME avec comme type principal "text/" auront par défaut "quoted-printable" et tous les autres "base64".
extensions => REF-ARRAY
Un tableau d'extensions qui utilisent ce MIME.
simplified => CHAÎNE
L'étiquette principale et l'étiquette secondaire des types MIME peuvent toutes deux commencer par "x-", pour indiquer qu'il s'agit d'un nom non enregistré. Bien sûr, après l'enregistrement, ce drapeau peut disparaître ce qui ajoute à la confusion. La chaîne simplifiée a les "x-" supprimés et sont traduits en minuscules.
system => REGEX
Expression régulière qui définit pour quels systèmes cette règle est valide. La REGEX est comparée à $^O.
type => CHAÎNE
Le type défini ici. Il se compose d'un type et d'un sous-type, tous deux insensibles à la casse. Ce module retournera en minuscules, mais acceptera les majuscules.

Attributs

$obj->charset()
[2.28] RFC6657 prescrit que les enregistrements IANA pour les types de la catégorie texte explicitement indiquent leur jeu de caractères par défaut. MIME-Types contient une liste produite manuellement de ces valeurs par défaut.

Cette méthode peut également retourner "_REQUIRED", lorsqu'il n'y a pas de valeur par défaut, ou "_FRAMED" lorsque le jeu de caractères est déterminé par le contenu.

$obj->encoding()
Retourne le type d'encodage requis pour transporter des données de ce type en toute sécurité.
$obj->extensions()
Retourne une liste d'extensions connues pour être utilisées pour ce type MIME.
$any->simplified( [$string] )
Retourne le type MIME simplifié pour cet objet ou la CHAÎNE spécifiée. Les noms de types MIME peuvent être officiellement enregistrés. Jusque-là, ils doivent porter un préfixe "x-" pour l'indiquer. Bien sûr, après reconnaissance, le "x-" peut disparaître. Dans de nombreux cas, nous préférons la version simplifiée du type.

exemple : résultats de simplified()

my $mime = MIME::Type->new(type => 'x-appl/x-zip');
print $mime->simplified;                     # 'appl/zip'
print $mime->simplified('text/PLAIN');       # 'text/plain'
print MIME::Type->simplified('x-xyz/x-abc'); # 'xyz/abc'
$obj->system()
Retourne l'expression régulière qui peut être utilisée pour déterminer si ce type est actif sur le système sur lequel vous travaillez.
$obj->type()
Retourne le type long de cet objet, par exemple 'text/plain'

Connaissance

$obj->defaultCharset()
[2.29] Conformément à RFC6657, tous les types "text/*" doivent soit spécifier un jeu de caractères par défaut dans leur enregistrement IANA, soit exiger le paramètre charset. Les types non textuels peuvent également exiger un jeu de caractères.

Il est difficile d'extraire ces informations des fichiers d'enregistrement IANA de manière automatique, elles sont donc maintenues manuellement.

exemple : utilisation du jeu de caractères par défaut

$charset //= $type->defaultCharset // 'utf-8';
$obj->equals($string|$mime)
Compare cet objet de type MIME avec une CHAÎNE ou un autre objet. En cas de CHAÎNE, une simplification aura lieu.
$obj->isAscii()
Ancien nom pour isText().
$obj->isBinary()
Retourne "vrai" si le type n'est pas connu comme étant du texte. Voir isText().
$obj->isExperimental()
[2.00] Retourne "vrai" si le type est défini pour un usage expérimental ; le sous-type commence par "x."
$obj->isPersonal()
[2.00] Retourne "vrai" si le type est défini par une personne pour un usage privé ; le sous-type commence par "prs."
$obj->isRegistered()
Les types MIME qui ne sont ni enregistrés par l'IANA ni définis dans les RFC doivent commencer par un "x-". Cela s'applique aussi bien au type média qu'au sous-type. Si l'un des types commence par "x-", cette méthode retournera "faux".
$obj->isSignature()
Retourne "vrai" si le type est dans la liste des signatures connues.
$obj->isText()
[2.05] Tous les types qui peuvent avoir l'attribut charset, sont du texte. Cependant, il n'y a actuellement aucun enregistrement des attributs dans ce module... donc nous devinons.
$obj->isVendor()
[2.00] Retourne "vrai" si le type est défini par un fournisseur ; le sous-type commence par "vnd."
$obj->mediaType()
Le type média du MIME simplifié. Pour 'text/plain', il retournera 'text'.

Pour des raisons historiques, la méthode 'mainType' peut toujours être utilisée pour récupérer la même valeur. Cependant, cette méthode est obsolète.

$obj->subType()
Le sous-type du mime simplifié. Pour 'text/plain', il renverra 'plain'.

DIAGNOSTICS

Erreur : Le type est un paramètre obligatoire.
Lors de la création d'un objet MIME::Type, le type lui-même doit être spécifié avec le drapeau "type". Coulé par new()
