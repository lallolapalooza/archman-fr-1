MIME::Decoder::BinHex(3) Documentation Perl fournie par l'utilisateur MIME::Decoder::BinHex(3)

NOM

MIME::Decoder::BinHex - décode un flux "binhex"

SYNTAXE

Un objet décodeur générique ; voir MIME::Decoder pour son utilisation.

Prend également en charge une méthode preamble() pour récupérer le texte avant la partie binhex du flux.

DESCRIPTION

Une sous-classe de MIME::Decoder pour un encodage non standard où les données sont encodées en binhex. Encodages MIME non standard courants pour cela :

x-uu
x-uuencode

VOIR AUSSI

MIME::Decoder
