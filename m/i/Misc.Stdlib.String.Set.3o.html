Ensembles

type elt

Le type des éléments des ensembles.

type t

Le type des ensembles.

val empty : t

L'ensemble vide.

val add : elt -> t -> t

add x s renvoie un ensemble contenant tous les éléments de s, plus x. Si x était déjà dans s, s est renvoyé inchangé (le résultat de la fonction est alors physiquement identique à s).

Avant 4.03 L'égalité physique n'était pas garantie.

val singleton : elt -> t

singleton x renvoie l'ensemble unique ne contenant que x.

val remove : elt -> t -> t

remove x s renvoie un ensemble contenant tous les éléments de s, à l'exception de x. Si x n'était pas dans s, s est renvoyé inchangé (le résultat de la fonction est alors physiquement identique à s).

Avant 4.03 L'égalité physique n'était pas garantie.

Union d'ensembles.

val inter : t -> t -> t

Intersection d'ensembles.

val disjoint : t -> t -> bool

Teste si deux ensembles sont disjoints.

Différence d'ensembles : diff s1 s2 contient les éléments de s1 qui ne sont pas dans s2.

val cardinal : t -> int

Renvoie le nombre d'éléments d'un ensemble.

Éléments

val elements : t -> elt list

Renvoie la liste de tous les éléments de l'ensemble donné. La liste renvoyée est triée par ordre croissant selon la comparaison Ord.compare, où Ord est l'argument donné à Set.Make.

val min_elt : t -> elt

Renvoie le plus petit élément de l'ensemble donné (selon la comparaison Ord.compare), ou lève Not_found si l'ensemble est vide.

val min_elt_opt : t -> elt option

Renvoie le plus petit élément de l'ensemble donné (selon la comparaison Ord.compare), ou None si l'ensemble est vide.

val max_elt_opt : t -> elt option

Similaire à Set.S.min_elt_opt, mais renvoie le plus grand élément de l'ensemble donné.

Depuis 4.05

val choose : t -> elt

Renvoie un élément de l'ensemble donné, ou lève Not_found si l'ensemble est vide. L'élément choisi est indéterminé, mais des éléments égaux sont choisis pour des ensembles égaux.

val choose_opt : t -> elt option

Renvoie un élément de l'ensemble donné, ou None si l'ensemble est vide. L'élément choisi est indéterminé, mais des éléments égaux sont choisis pour des ensembles égaux.

Recherche

val find : elt -> t -> elt

find x s renvoie l'élément de s égal à x (selon Ord.compare), ou lève Not_found si un tel élément n'existe pas.

Depuis 4.01

val find_opt : elt -> t -> elt option

find_opt x s renvoie l'élément de s égal à x (selon Ord.compare), ou None si un tel élément n'existe pas.

Depuis 4.05

val find_first : (elt -> bool) -> t -> elt

find_first f s, où f est une fonction monotone croissante, renvoie le plus petit élément e de s tel que f e, ou lève Not_found si un tel élément n'existe pas.

Par exemple, find_first (fun e -> Ord.compare e x >= 0) s renverra le premier élément e de s tel que Ord.compare e x >= 0 (intuitivement : e >= x), ou lèvera Not_found si x est plus grand que n'importe quel élément de s.

Depuis 4.05

val find_first_opt : (elt -> bool) -> t -> elt option

find_first_opt f s, où f est une fonction monotone croissante, renvoie une option contenant le plus petit élément e de s tel que f e, ou None si un tel élément n'existe pas.

Depuis 4.05

val find_last : (elt -> bool) -> t -> elt

find_last f s, où f est une fonction monotone décroissante, renvoie le plus grand élément e de s tel que f e, ou lève Not_found si un tel élément n'existe pas.

Depuis 4.05

Parcours

val iter : (elt -> unit) -> t -> unit

iter f s applique f dans l'ordre à tous les éléments de s. Les éléments de s sont présentés à f par ordre croissant selon la comparaison du type d'éléments.

val fold : (elt -> 'acc -> 'acc) -> t -> 'acc -> 'acc

fold f s init calcule (f xN ... (f x2 (f x1 init))...), où x1 ... xN sont les éléments de s par ordre croissant.

Transformation

val map : (elt -> elt) -> t -> t

map f s est l'ensemble dont les éléments sont f a0, f a1... f aN, où a0, a1... aN sont les éléments de s.

Les éléments sont passés à f par ordre croissant selon la comparaison du type d'éléments.

Si aucun élément de s n'est modifié par f, s est renvoyé inchangé. (Si chaque sortie de f est physiquement identique à son entrée, l'ensemble renvoyé est physiquement identique à s.)

Depuis 4.04

val filter : (elt -> bool) -> t -> t

filter f s renvoie l'ensemble de tous les éléments de s qui satisfont le prédicat f. Si f est vrai pour tous les éléments de s, s est renvoyé inchangé (le résultat de la fonction est alors physiquement identique à s).

Avant 4.03 L'égalité physique n'était pas garantie.

val filter_map : (elt -> elt option) -> t -> t

filter_map f s renvoie l'ensemble de tous les v tels que f x = Some v pour un élément x de s.

Par exemple,

filter_map (fun n -> if n mod 2 = 0 then Some (n / 2) else None) s
est l'ensemble des moitiés des éléments pairs de s.

Si aucun élément de s n'est modifié ou supprimé par f (si f x = Some x pour chaque élément x), alors s est renvoyé inchangé : le résultat de la fonction est alors physiquement identique à s.

Depuis 4.11
