NOM

MIME::Decoder - un objet pour décoder la partie corps d'un flux MIME

SYNTAXE

Avant de lire la suite, vous devriez consulter MIME::Tools pour vous assurer que vous comprenez où ce module s'insère dans le tableau d'ensemble des choses. Allez-y, faites-le maintenant. Je vous attends.

Prêt ? Ok...

Décodage d'un flux de données

Voici un programme de filtrage simple pour lire des données quoted-printable depuis STDIN (jusqu'à EOF) et écrire les données décodées sur STDOUT :

use MIME::Decoder;
$decoder = new MIME::Decoder 'quoted-printable' or die "non supporté";
$decoder->decode(\*STDIN, \*STDOUT);

Encodage d'un flux de données

Voici un programme de filtrage simple pour lire des données binaires depuis STDIN (jusqu'à EOF) et écrire des données encodées en base64 sur STDOUT :

use MIME::Decoder;
$decoder = new MIME::Decoder 'base64' or die "non supporté";
$decoder->encode(\*STDIN, \*STDOUT);

Encodages non standards

Vous pouvez écrire et installer vos propres décodeurs afin que MIME::Decoder les connaisse :

use MyBase64Decoder;
install MyBase64Decoder 'base64';

Vous pouvez également tester si un encodage donné est supporté :

if (supported MIME::Decoder 'x-uuencode') {
    ### nous pouvons encoder en uuencode !
}

DESCRIPTION

Cette classe abstraite, et ses sous-classes concrètes privées (voir ci-dessous) fournissent une interface orientée objet aux actions de...

  • Décodage d'un flux encodé MIME
  • Encodage d'un flux de données brutes en un flux encodé MIME.

Le constructeur de MIME::Decoder prend le nom d'un encodage ("base64", "7bit", etc.), et retourne une instance d'une sous-classe de MIME::Decoder dont la méthode decode() effectuera l'action de décodage appropriée, et dont la méthode encode() effectuera l'action d'encodage appropriée.

INTERFACE PUBLIQUE

Interface standard

Si tout ce que vous faites est d'utiliser cette classe, voici tout ce dont vous aurez besoin...

new ENCODAGE
Méthode de classe, constructeur. Crée et retourne un nouvel objet décodeur capable de gérer l'ENCODAGE donné. 
my $decoder = new MIME::Decoder "7bit";

Retourne la valeur indéfinie si aucun décodeur connu n'est approprié.

best ENCODAGE
Méthode de classe, constructeur. Exactement comme new(), sauf que celle-ci utilise par défaut "binary" pour tout encodage non supporté, après avoir émis un avertissement approprié (c'est une erreur fatale s'il n'y a pas de décodeur binaire). 
my $decoder = best MIME::Decoder "x-gzip64";

Retournera soit un décodeur, soit lèvera une exception fatale.

decode INSTREAM,OUTSTREAM
Méthode d'instance. Décode le document en attente dans le descripteur d'entrée INSTREAM, en écrivant les informations décodées dans le descripteur de sortie OUTSTREAM.

Lisez la section de ce document sur les descripteurs d'E/S pour plus d'informations sur les arguments. Notez que vous pouvez toujours fournir des descripteurs de fichier non bénis de style ancien pour INSTREAM et OUTSTREAM.

Retourne vrai en cas de succès, lève une exception en cas d'échec.

encode INSTREAM,OUTSTREAM
Méthode d'instance. Encode le document en attente dans le descripteur de fichier INSTREAM, en écrivant les informations encodées dans le flux de sortie OUTSTREAM.

Lisez la section de ce document sur les descripteurs d'E/S pour plus d'informations sur les arguments. Notez que vous pouvez toujours fournir des descripteurs de fichier non bénis de style ancien pour INSTREAM et OUTSTREAM.

Retourne vrai en cas de succès, lève une exception en cas d'échec.

encoding
Méthode d'instance. Retourne l'encodage pour lequel cet objet a été créé, converti en minuscules (par exemple, "base64").
head [HEAD]
Méthode d'instance. Complètement optionnel : certains décodeurs doivent connaître un peu le fichier qu'ils encodent/décodent ; par exemple, x-uu aime avoir le nom de fichier. HEAD est tout objet qui répond à des messages comme : 
$head->mime_attr('content-disposition.filename');
supported [ENCODAGE]
Méthode de classe. Avec un seul argument (un nom d'ENCODAGE), retourne vrai si cet encodage est actuellement géré, et faux sinon. L'ENCODAGE sera automatiquement converti en minuscules : 
if (supported MIME::Decoder '7BIT') {
    ### oui, nous pouvons le gérer...
}
else {
    ### revenons en arrière et abandonnons...
}

Sans argument, retourne une référence vers une table de hachage de tous les décodeurs disponibles, où la clé est le nom de l'encodage (tout en minuscules, comme '7bit'), et la valeur est vraie (il se trouve que c'est le nom de la classe qui gère le décodage, mais vous ne devriez probablement pas vous y fier). Vous pouvez modifier cette table en toute sécurité ; cela ne changera pas la façon dont le module effectue ses recherches. Seule "install" peut faire cela.

Merci à Achim Bohnet pour avoir suggéré cette méthode.

Interface de sous-classe

Si vous écrivez (ou installez) une nouvelle sous-classe de décodeur, il y a quelques autres méthodes que vous devrez connaître :

decode_it INSTREAM,OUTSTREAM
Méthode d'instance abstraite. Le back-end de la méthode decode. Elle prend un descripteur d'entrée ouvert en lecture (INSTREAM), et un descripteur de sortie ouvert en écriture (OUTSTREAM).

Si vous écrivez votre propre sous-classe de décodeur, vous devez redéfinir cette méthode dans votre classe. Votre méthode doit lire depuis le descripteur d'entrée via getline() ou read(), décoder cette entrée, et imprimer les données décodées dans le descripteur de sortie via print(). Vous pouvez le faire comme bon vous semble, tant que le résultat final est le même.

Notez que les références non bénies et les globrefs sont automatiquement transformés en descripteurs d'E/S pour vous par decode(), vous n'avez donc pas à vous en soucier.

Votre méthode doit retourner soit "undef" (pour indiquer un échec), soit 1 (pour indiquer un succès). Elle peut également lancer une exception pour indiquer un échec.

encode_it INSTREAM,OUTSTREAM
Méthode d'instance abstraite. Le back-end de la méthode encode. Elle prend un descripteur d'entrée ouvert en lecture (INSTREAM), et un descripteur de sortie ouvert en écriture (OUTSTREAM).

Si vous écrivez votre propre sous-classe de décodeur, vous devez redéfinir cette méthode dans votre classe. Votre méthode doit lire depuis le descripteur d'entrée via getline() ou read(), encoder cette entrée, et imprimer les données encodées dans le descripteur de sortie via print(). Vous pouvez le faire comme bon vous semble, tant que le résultat final est le même.

Notez que les références non bénies et les globrefs sont automatiquement transformés en descripteurs d'E/S pour vous par encode(), vous n'avez donc pas à vous en soucier.

Votre méthode doit retourner soit "undef" (pour indiquer un échec), soit 1 (pour indiquer un succès). Elle peut également lancer une exception pour indiquer un échec.

NOM

MIME::Decoder

SYNTAXE

use MIME::Decoder;

DESCRIPTION

MIME::Decoder est un module Perl qui fournit un décodeur pour le contenu MIME. Il vous permet de décoder des données encodées dans divers formats, tels que quoted-printable, base64, et d'autres.

INTERFACE PUBLIQUE

L'interface publique de MIME::Decoder comprend des méthodes pour décoder et encoder des données. Ces méthodes sont appelées avec les arguments appropriés et renvoient les données décodées ou encodées.

SOUS-CLASSES DE DÉCODEUR

Vous n'avez pas besoin d'"utiliser" d'autres modules Perl ; les sous-classes "standard" suivantes sont incluses dans le cadre de MIME::Decoder :

Class:                         Gère les encodages :
------------------------------------------------------------
MIME::Decoder::Binary          binary
MIME::Decoder::NBit            7bit, 8bit
MIME::Decoder::Base64          base64
MIME::Decoder::QuotedPrint     quoted-printable

Les sous-classes "non standard" suivantes sont également incluses :

Class:                         Gère les encodages :
------------------------------------------------------------
MIME::Decoder::UU              x-uu, x-uuencode
MIME::Decoder::Gzip64          x-gzip64            ** nécessite gzip !

NOTES

Descripteurs d'entrée/sortie

Depuis MIME-tools 2.0, cette classe doit fonctionner avec la nouvelle classe MIME::Body... ce qui signifie que les routines d'entrée et de sortie ne peuvent pas simplement supposer qu'elles traitent des descripteurs de fichiers.

Par conséquent, tout ce que MIME::Decoder et ses sous-classes exigent (et, par conséquent, tout ce qu'elles peuvent supposer) est que les flux d'entrée (INSTREAMs) et de sortie (OUTSTREAMs) soient des objets qui répondent à un sous-ensemble des messages définis dans l'interface IO::Handle ; au minimum :

print
getline
read(BUF,NBYTES)

Merci à Achim Bohnet d'avoir suggéré ce modèle d'E/S plus générique.

Écrire un décodeur

Si vous expérimentez avec vos propres encodages, vous voudrez probablement écrire un décodeur. Voici les bases :

1.
Créez un module, comme "MyDecoder::", pour votre décodeur. Déclarez-le comme sous-classe de MIME::Decoder.
2.
Créez les méthodes d'instance suivantes dans votre classe, comme décrit ci-dessus :
decode_it
encode_it
init
3.
Dans votre programme d'application, activez votre décodeur pour un ou plusieurs encodages comme ceci :
require MyDecoder;
install MyDecoder "7bit";   ### utilise MyDecoder pour décoder "7bit"
install MyDecoder "x-foo";  ### utilise également MyDecoder pour décoder "x-foo"

Pour illustrer, voici une classe de décodeur personnalisée pour l'encodage "quoted-printable" :

package MyQPDecoder;
@ISA = qw(MIME::Decoder);
use MIME::Decoder;
use MIME::QuotedPrint;
### decode_it - la méthode de décodage privée
sub decode_it {
    my ($self, $in, $out) = @_;
    local $_;
    while (defined($_ = $in->getline)) {
        my $decoded = decode_qp($_);
        $out->print($decoded);
    }
    1;
}
### encode_it - la méthode d'encodage privée
sub encode_it {
    my ($self, $in, $out) = @_;
    my ($buf, $nread) = ('', 0);
    while ($in->read($buf, 60)) {
        my $encoded = encode_qp($buf);
        $out->print($encoded);
    }
    1;
}

C'est tout. La tâche était assez simple car l'encodage "quoted-printable" peut facilement être converti ligne par ligne... tout comme même "7bit" et "8bit" (puisque tous ces encodages garantissent des lignes courtes, avec un maximum de 1000 caractères). La bonne nouvelle est qu'il est très probable qu'il sera tout aussi facile d'écrire un MIME::Decoder pour tout futur encodage standard.

Le décodeur "binary", cependant, a vraiment nécessité des lectures et écritures par blocs : voir "MIME::Decoder::Binary" pour plus de détails.
