NOM

MIME::Types - Définition des types MIME

HÉRITAGE

MIME::Types
  est un Exporter

SYNTAXE

use MIME::Types;
my $mt    = MIME::Types->new(...);    # Objet MIME::Types
my $type  = $mt->type('text/plain');  # Objet MIME::Type
my $type  = $mt->mimeTypeOf('gif');
my $type  = $mt->mimeTypeOf('picture.jpg');
my @types = $mt->httpAccept('text/html, application/json;q=0.1')

DESCRIPTION

"MIME Type" est l'ancien nom de "Media Type". Ce module date de 1999 et les changements de nom sont douloureux, nous gardons donc le nom original.

Les types de médias sont utilisés dans de nombreuses applications (par exemple, dans les courriels et le trafic HTTP) pour indiquer le type de contenu transmis ou attendu. Lisez RFC6838 https://www.rfc-editor.org/rfc/rfc6838 (enregistrements) et RFC9694 https://www.rfc-editor.org/rfc/rfc9694 (niveaux supérieurs) pour la spécification.

Il faut parfois beaucoup de connaissances sur un type MIME, mais ce module ne connaît que les extensions de fichiers qui sont liées à certains types de fichiers. Il peut également être utilisé pour produire le bon format : les types non enregistrés auprès de l'IANA doivent utiliser des préfixes « x- ».

Cet objet gère une très longue liste de types connus, combinée à partir de diverses sources. Par exemple, il contient tous les types IANA et ceux connus d'Apache. C'est probablement la table la plus complète du monde !

MIME::Types et les robots (fork)

Si votre programme utilise fork (généralement pour un démon), vous voudrez que la table des types soit initialisée avant de commencer à forker. Ainsi, appelez d'abord

my $mt = MIME::Types->new;

Ensuite, chaque fois que vous créez cet objet (vous pouvez en fait réutiliser l'objet que nous avons créé ici), vous obtiendrez un accès à la **même table globale** de types.

MÉTHODES

Constructeurs

$class->new(%options)
Crée un objet "MIME::Types" qui gère les données. Dans l'implémentation actuelle, peu importe si vous créez cet objet plusieurs fois dans votre programme, mais cela pourrait changer à l'avenir.
db_file => FICHIER
Emplacement de la base de données contenant les informations sur les types. Ce paramètre ne sera appliqué que lors de la première instanciation de cet objet. [2.10] Ce paramètre peut être remplacé globalement par la variable d'environnement "PERL_MIME_TYPE_DB", ce qui peut être nécessaire dans les cas de PAR ou d'installations compliquées. Pour PAR, vous devrez probablement définir cette variable sur "inc/lib/MIME/types.db"
only_complete => BOOLEAN
N'inclut que les définitions complètes de types MIME : nécessite au moins une extension connue. Cela réduira considérablement le nombre d'entrées et donc la consommation de mémoire.
only_iana => BOOLEAN
Charge uniquement les types actuellement connus de l'IANA.
skip_extensions => BOOLEAN
Évite de charger la table pour mapper les extensions aux types, qui est assez volumineuse.

Connaissances

$obj->addType($type, ...)
Ajoute un ou plusieurs types MIME à la liste des types connus. Chaque type est un "MIME::Type", qui doit être expérimental : il doit commencer par "x-", qu'il s'agisse du type principal ou du sous-type.
$obj->extensions()
Retourne une liste de toutes les extensions définies.
$obj->listTypes()
Retourne une liste de tous les noms de types MIME. Cela n'instanciera pas d'objets "MIME::Type". Voir types()
$obj->mimeTypeOf($filename)
Retourne l'objet "MIME::Type" qui correspond au fichier NOMDEFICHIER (ou simplement à son extension) ou "undef" si le type de fichier est inconnu. L'extension est utilisée et considérée en majuscules.
$obj->type($string)
Retourne le "MIME::Type" qui décrit le type associé à CHAINE. [2.00] Ne retournera qu'un seul type.
$obj->types()
Retourne une liste de tous les types MIME définis. Pour des raisons de compatibilité, cela retournera des objets "MIME::Type", qui seront retournés. Voir listTypes().

Support HTTP

$obj->httpAccept($header)
[2.07] Décompose un en-tête HTTP-Accept typique et le trie en fonction des informations de priorité incluses. Retourne une liste triée de types, le type de priorité la plus élevée étant le premier. La liste peut contenir '*'/*' (accepter tout) ou '*' comme sous-type.
$obj->httpAcceptBest($accept|\@types, @have)
[2.07] La chaîne $accept est traitée par httpAccept() pour trier les types en fonction de la priorité. Vous pouvez également passer une liste de types triés @types qui pourraient résulter de cet appel de méthode précédent.
$obj->httpAcceptSelect($accept|\@types, @filenames|\@filenames)
[2.07] Comme httpAcceptBest(), mais maintenant il ne retournera pas une paire avec le type et le nom du fichier, mais seulement le type. Si $accept est undef, il retourne le premier nom de fichier.

use File::Glob   'bsd_glob';    # gestion des noms contenant des espaces
my @filenames   = bsd_glob "$imagedir/$fnbase.*;
my $accept      = $req->header('Accept');

MIME::Types(3pm) - Documentation Perl

NOM

MIME::Types - découvrir les types MIME pour les fichiers

INHERITANCE

Aucune classe parente.

SYNOPSIS

  use MIME::Types;
  my $mime = MIME::Types->new();
  my $types = $mime->mimeTypeOf('file.ext');
  my @types = $mime->suffixes('image/gif');
  my @filenames = $mime->by_type('text/html');
  $mime->read; # lire les types MIME d'un fichier.
  $mime->read('/path/to/mime.types');
  my $result = $mime->AcceptSelect($accept, @filenames);
  my $code = defined $mime ? HTTP_NOT_ACCEPTABLE : HTTP_OK;

DESCRIPTION

Ce module fournit une interface pour découvrir les types MIME associés aux extensions de fichier. Il peut également être utilisé pour obtenir des extensions de fichier pour un type MIME donné.

Le module est basé sur une table qui est initialisée à partir de sources standard (comme le fichier mime.types) et qui peut être enrichie par l'utilisateur.

METHODS

new()
Crée une nouvelle instance de MIME::Types.
mimeTypeOf(FILENAME|SUFFIX)
Retourne le type MIME pour le nom de fichier ou l'extension fournis. Si le type MIME est inconnu, une chaîne vide est retournée.

Exemple :

  my $types = MIME::Types->new;
  my $mediatype = $types->mimeTypeOf('image.gif'); # Retourne 'image/gif'
  my $mediatype = $types->mimeTypeOf('.gif');     # Retourne 'image/gif'
suffixes(TYPE)
Retourne une liste des extensions de fichier connues pour le type MIME donné.

Exemple :

  my @extensions = $types->suffixes('image/gif'); # Retourne ('gif', 'jfif', 'jfi')
by_type(TYPE)
Retourne une liste de noms de fichiers qui correspondent au type MIME spécifié. La correspondance se fait sur la base des types MIME définis dans la table interne.

Exemple :

  my @files = $types->by_type('text/html');
read([FILENAME])
Lit les informations sur les types MIME. S'il n'y a pas d'argument, il essaie de lire la table de types MIME par défaut (souvent dans /etc/mime.types ou des emplacements similaires). Si un nom de fichier est fourni, il lit la table de ce fichier. Cela peut être utilisé pour charger des configurations personnalisées. Plusieurs appels à read ajouteront les types lus à la table existante.
AcceptSelect(ACCEPT, @FILENAMES)
Cette méthode est utilisée pour déterminer si un client HTTP accepte un des types MIME des fichiers fournis. ACCEPT est généralement l'en-tête HTTP Accept. Elle retourne une liste des noms de fichiers qui sont acceptés par le client. S'il n'y a pas de correspondance, une liste vide est retournée. Le code de statut HTTP approprié peut être déduit de la présence ou de l'absence d'un type MIME cohérent.

Exemple :

  my $accept = $request->header('Accept');
  my @filenames = ('index.html', 'logo.png', 'style.css');
  my @selected_files = $mime->AcceptSelect($accept, @filenames);
  my $code = @selected_files ? HTTP_OK : HTTP_NOT_ACCEPTABLE;

FONCTIONS

Les fonctions suivantes sont fournies pour la compatibilité ascendante avec les versions [0.06] et antérieures de MIME::Types. Ce code provient de Jeff Okamoto okamoto@corp.hp.com et d'autres.

par_mediatype(TYPE)
Cette fonction prend un type de média et retourne une liste ou un tableau anonyme de tableaux anonymes à trois éléments dont les valeurs sont le suffixe de nom de fichier utilisé pour l'identifier, le type de média et un encodage de contenu.

"TYPE" peut être un nom de type complet (contient '/', et sera mis en correspondance en entier), un type partiel (qui est utilisé comme expression régulière) ou une vraie expression régulière.

par_suffix(NOMFICHIER|SUFFIXE)
Comme "mimeTypeOf", mais ne retourne pas un objet "MIME::Type". Si le type de fichier est inconnu, le type de média et l'encodage retournés sont des chaînes vides.

Exemple : utilisation de la fonction par_suffix()

use MIME::Types 'par_suffix';
my ($mediatype, $encoding) = par_suffix('image.gif');
my $refdata = par_suffix('image.gif');
my ($mediatype, $encoding) = @$refdata;
importer_mime_types()
Cette méthode a été supprimée : les types MIME ne sont utiles que s'ils sont compris par de nombreuses parties. Par conséquent, l'IANA leur attribue des noms qui peuvent être utilisés. Dans la table conservée par ce module "MIME::Types", tous ces noms, ainsi que les noms temporaires les plus couramment utilisés, sont conservés. Lorsque des noms semblent manquer, veuillez contacter le mainteneur pour leur inclusion.
