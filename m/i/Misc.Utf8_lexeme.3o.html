Module Utf8_lexeme
: sig end

type t = string

val normalize : string -> (t, t) Result.t

Normalise la chaîne encodée en UTF-8 donnée. Les séquences UTF-8 invalides entraînent une erreur et sont remplacées par U+FFFD. Les caractères d'identifiant sont mis sous forme normalisée NFC. Les autres caractères Unicode ne sont pas modifiés.

val capitalize : string -> (t, t) Result.t

Comme normalize , mais si la chaîne commence par un caractère d'identifiant en minuscule, il est remplacé par le caractère majuscule correspondant. Les caractères suivants ne sont pas modifiés.

val uncapitalize : string -> (t, t) Result.t

Comme normalize , mais si la chaîne commence par un caractère d'identifiant en majuscule, il est remplacé par le caractère minuscule correspondant. Les caractères suivants ne sont pas modifiés.

val is_capitalized : t -> bool

Retourne true si la chaîne normalisée donnée commence par un caractère d'identifiant en majuscule, false sinon. Peut retourner des résultats erronés si la chaîne n'est pas normalisée.

val is_valid_identifier : t -> bool

Vérifie si la chaîne normalisée donnée est un identifiant OCaml valide :

-tous les caractères sont des caractères d'identifiant

-il ne commence pas par un chiffre ou une apostrophe

val is_lowercase : t -> bool

Retourne true si la chaîne normalisée donnée ne contient que des caractères d'identifiant en minuscule, false sinon. Peut retourner des résultats erronés si la chaîne n'est pas normalisée.

type validation_result =
| Valid
| Invalid_character of Uchar.t
(* Caractère non autorisé
*)
| Invalid_beginning of Uchar.t
(* Caractère non autorisé comme premier caractère
*)

val validate_identifier : ?with_dot:bool -> t -> validation_result

Comme is_valid_identifier , mais retourne un code d'erreur plus détaillé. Les points peuvent être autorisés pour étendre le support aux identifiants de type chemin.

val starts_like_a_valid_identifier : t -> bool

Vérifie si la chaîne normalisée donnée commence par un caractère d'identifiant autre qu'un chiffre ou une apostrophe. Les caractères suivants ne sont pas vérifiés.
