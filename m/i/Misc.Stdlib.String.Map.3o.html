val ajouter : cle -> 'a -> 'a t -> 'a t

ajouter cle donnee c renvoie une carte contenant les mêmes associations que c , plus une association de cle à donnee . Si cle était déjà associée dans c à une valeur physiquement égale à donnee , c est renvoyée inchangée (le résultat de la fonction est alors physiquement égal à c ). Sinon, l'association précédente de cle dans c disparaît.

val ajouter_a_liste : cle -> 'a -> 'a list t -> 'a list t

ajouter_a_liste cle donnee c est c avec cle associée à l tel que l est donnee :: Map.trouver cle c si cle était associée dans c et [donnee] sinon.

val mettre_a_jour : cle -> ('a option -> 'a option) -> 'a t -> 'a t

mettre_a_jour cle f c renvoie une carte contenant les mêmes associations que c , à l'exception de l'association de cle . Selon la valeur de y où y est f (trouver_opt cle c) , l'association de cle est ajoutée, supprimée ou mise à jour. Si y est None , l'association est supprimée si elle existe ; sinon, si y est Some z alors cle est associée à z dans la carte résultante. Si cle était déjà associée dans c à une valeur physiquement égale à z , c est renvoyée inchangée (le résultat de la fonction est alors physiquement égal à c ).

val fusionner : (cle -> 'a option -> 'b option -> 'c option) -> 'a t -> 'b t -> 'c t

fusionner f c1 c2 calcule une carte dont les clés sont un sous-ensemble des clés de c1 et c2 . La présence de chaque telle association, et la valeur correspondante, sont déterminées par la fonction f . En termes de l'opération trouver_opt , nous avons trouver_opt x (fusionner f c1 c2) = f x (trouver_opt x c1) (trouver_opt x c2) pour toute clé x , à condition que f x None None = None .

Depuis 3.12

val union : (cle -> 'a -> 'a -> 'a option) -> 'a t -> 'a t -> 'a t

union f c1 c2 calcule une carte dont les clés sont un sous-ensemble des clés de c1 et c2 . Lorsque la même association est définie dans les deux arguments, la fonction f est utilisée pour les combiner. C'est un cas particulier de fusionner : union f c1 c2 est équivalent à fusionner f' c1 c2 , où

- f' _cle None None = None

- f' _cle (Some v) None = Some v

- f' _cle None (Some v) = Some v

- f' cle (Some v1) (Some v2) = f cle v1 v2

Depuis 4.05

val trouver_premier : (cle -> bool) -> 'a t -> cle * 'a

trouver_premier f c , où f est une fonction monotone croissante, renvoie l'association de c avec la plus petite clé k telle que f k , ou lève Not_found si aucune telle clé n'existe.

Par exemple, trouver_premier (fun k -> Ord.compare k x >= 0) c renverra la première association k, v de c où Ord.compare k x >= 0 (intuitivement : k >= x ), ou lèvera Not_found si x est plus grand que tout élément de c .

Module

val map : ('a -> 'b) -> 'a t -> 'b t

map f m retourne une carte avec le même domaine que m, où la valeur associée a de toutes les liaisons de m a été remplacée par le résultat de l'application de f à a. Les liaisons sont passées à f dans l'ordre croissant par rapport à l'ordre sur le type des clés.

val mapi : (key -> 'a -> 'b) -> 'a t -> 'b t

Identique à Map.S.map, mais la fonction reçoit en arguments la clé et la valeur associée pour chaque liaison de la carte.

val filter : (key -> 'a -> bool) -> 'a t -> 'a t

filter f m retourne la carte avec toutes les liaisons de m qui satisfont le prédicat p. Si toutes les liaisons de m satisfont f, m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m).

Avant 4.03 L'égalité physique n'était pas garantie.

val filter_map : (key -> 'a -> 'b option) -> 'a t -> 'b t

filter_map f m applique la fonction f à chaque liaison de m, et construit une carte à partir des résultats. Pour chaque liaison (k, v) dans la carte d'entrée :

- si f k v est None alors k n'est pas dans le résultat,

- si f k v est Some v' alors la liaison (k, v') est dans la carte de sortie.

Par exemple, la fonction suivante sur des cartes dont les valeurs sont des listes

        filter_map
          (fun _k li -> match li with [] -> None | _::tl -> Some tl)
          m
supprime toutes les liaisons de m dont la valeur est une liste vide, et retire le premier élément de chaque valeur non vide.

val split : key -> 'a t -> 'a t * 'a option * 'a t

split x m retourne un triplet (l, data, r), où l est la carte avec toutes les liaisons de m dont la clé est strictement inférieure à x ; r est la carte avec toutes les liaisons de m dont la clé est strictement supérieure à x ; data est None si m ne contient aucune liaison pour x, ou Some v si m lie v à x.

Prédicats et comparaisons

val is_empty : 'a t -> bool

Teste si une carte est vide ou non.

val mem : key -> 'a t -> bool

mem x m retourne True si m contient une liaison pour x, et False sinon.

val equal : (( 'a -> 'a -> bool ) -> 'a t -> 'a t -> 'a t -> bool)

equal cmp m1 m2 teste si les cartes m1 et m2 sont égales, c'est-à-dire, contiennent des clés égales et les associent à des données égales. cmp est le prédicat d'égalité utilisé pour comparer les données associées aux clés.

val compare : (( 'a -> 'a -> int ) -> 'a t -> 'a t -> 'a t -> int)

Ordre total entre les cartes. Le premier argument est un ordre total utilisé pour comparer les données associées aux clés égales dans les deux cartes.

val for_all : (key -> 'a -> bool) -> 'a t -> bool

for_all f m vérifie si toutes les liaisons de la carte satisfont le prédicat f.
