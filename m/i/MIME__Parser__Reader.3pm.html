NOM

MIME::Parser::Reader - un lecteur orienté ligne pour un MIME::Parser

SYNTAXE

Ce module est utilisé en interne par MIME::Parser ; vous n'avez probablement pas besoin de le consulter. Mais au cas où...

### Créez un lecteur de haut niveau, où les morceaux se terminent à la fin du fichier :
$rdr = MIME::Parser::Reader->new();
### Démarrez un lecteur enfant, où les morceaux se terminent également à une limite :
$subrdr = $rdr->spawn->add_boundary($bound);
### Démarrez un lecteur enfant, où les morceaux se terminent également à une chaîne donnée :
$subrdr = $rdr->spawn->add_terminator($string);
### Lisez jusqu'à la limite ou le terminateur :
$subrdr->read_chunk($in, $out);

DESCRIPTION

Un lecteur orienté ligne capable de gérer une fin de flux virtuelle définie par une collection de limites.

Attention : il s'agit d'une classe privée destinée uniquement à l'utilisation par MIME::Parser. Cette classe n'a pas d'interface publique officielle.
