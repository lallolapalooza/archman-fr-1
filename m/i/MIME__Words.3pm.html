NOM

MIME::Words - gérer les mots codés RFC 2047

SYNTAXE

Avant de lire plus loin, vous devriez consulter MIME::Tools pour vous assurer que vous comprenez où ce module s'inscrit dans le grand schéma des choses. Allez-y, faites-le maintenant. J'attendrai.

Prêt ? Ok...

use MIME::Words qw(:all);
### Décoder la chaîne en une autre chaîne, en oubliant les encodeurs :
$decoded = decode_mimewords(
      'To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld@dkuug.dk>',
      );
### Diviser la chaîne en un tableau de paires [DONNÉES, CHARSET] décodées :
@decoded = decode_mimewords(
      'To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld@dkuug.dk>',
      );
### Coder un seul mot non sécurisé :
$encoded = encode_mimeword("\xABFran\xE7ois\xBB");
### Coder une chaîne, en recherchant les mots non sécurisés à l'intérieur :
$encoded = encode_mimewords("Moi et \xABFran\xE7ois\xBB dans le village");

DESCRIPTION

Amis des États-Unis, vous ne savez peut-être pas de quoi diable parle ce module. Européens, Russes, etc., vous le savez peut-être. ":-)".

Par exemple, voici un exemple d'en-tête MIME valide que vous pourriez rencontrer :

From: =?US-ASCII?Q?Keith_Moore?= <moore@cs.utk.edu>
To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld@dkuug.dk>
CC: =?ISO-8859-1?Q?Andr=E9_?= Pirard <PIRARD@vm1.ulg.ac.be>
Subject: =?ISO-8859-1?B?SWYgeW91IGNhbiByZWFkIHRoaXMgeW8=?=
 =?ISO-8859-2?B?dSB1bmRlcnN0YW5kIHRoZSBleGFtcGxlLg==?=
 =?US-ASCII?Q?.._cool!?=

Les champs se décodent essentiellement en (bien sûr, je ne peux qu'approximer avec des séquences 7 bits /o et 'e) :

From: Keith Moore <moore@cs.utk.edu>
To: Keld J/orn Simonsen <keld@dkuug.dk>
CC: Andr'e  Pirard <PIRARD@vm1.ulg.ac.be>
Subject: Si vous pouvez lire ceci, vous comprenez l'exemple... cool !

INTERFACE PUBLIQUE

decode_mimewords ENCODED
Fonction. Traite la chaîne ENCODED en recherchant les chaînes codées de type RFC 2047 "Q" (quoted-printable, en quelque sorte) ou "B" (base64), et les décode.

Dans un contexte de tableau, divise la chaîne ENCODED en une liste de paires décodées "[DONNÉES, CHARSET]", et renvoie cette liste. Les données non codées sont renvoyées dans un tableau à un élément "[DONNÉES]", donnant un CHARSET effectif de "undef".

$enc = '=?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld@dkuug.dk>';
foreach (decode_mimewords($enc)) {
    print "", ($_->[1] || 'US-ASCII'), ": ", $_->[0], "\n";
}

Dans un contexte scalaire, joint les éléments de "données" de la liste ci-dessus, et renvoie le résultat. Note : C'est une perte d'information, et vous n'en voulez probablement pas, mais si vous savez que tous les CHARSET dans la chaîne ENCODED sont identiques, cela pourrait vous être utile. (Avant d'utiliser ceci, veuillez consulter "unmime" dans MIME::WordDecoder, ce qui est probablement ce que vous voulez.)

En cas d'erreur de syntaxe, $@ contiendra une description de l'erreur, mais l'analyse se poursuivra au mieux (pour obtenir quelque chose lors du décodage des en-têtes). $@ sera faux si aucune erreur n'a été détectée.

Tous les arguments après ENCODED sont interprétés comme une table de hachage d'options :

encode_mimeword RAW, [ENCODAGE], [CHARSET]
Fonction. Code un seul "mot" RAW contenant des caractères non sécurisés. Le "mot" sera entièrement codé. 
### Coder "<<François>>" :
$encoded = encode_mimeword("\xABFran\xE7ois\xBB");

Vous pouvez spécifier l'ENCODAGE ("Q" ou "B"), qui par défaut est "Q". Vous pouvez spécifier le CHARSET, qui par défaut est "iso-8859-1".

encode_mimewords RAW, [OPTS]
Fonction. Étant donné une chaîne RAW, recherche et code toutes les séquences de caractères "non sécurisés" : 
### Coder une chaîne avec quelques "mots" non sécurisés :
$encoded = encode_mimewords("Moi et \xABFran\xE7ois\xBB");

Renvoie la chaîne codée. Tous les arguments après RAW sont interprétés comme une table de hachage d'options :

Charset
Code tout le contenu non sécurisé avec ce jeu de caractères. Le défaut est 'ISO-8859-1', alias "Latin-1".
Encoding
L'encodage à utiliser, "q" ou "b". Le défaut est "q".

Attention : il s'agit d'une solution de contournement rapide et descriptive, destinée aux jeux de caractères qui chevauchent ASCII. Elle ne respecte pas les règles RFC 2047 concernant l'utilisation de mots codés dans les en-têtes de message. Vous voudrez peut-être créer votre propre variante, en utilisant encode_mimeword(), pour votre application. Merci à Jan Kasprzak de m'avoir rappelé cela.

VOIR AUSSI

MIME::Base64, MIME::QuotedPrint, MIME::Tools

Pour des implémentations de cette fonction ou de fonctions similaires (en particulier, avec le support UTF8), consultez :

Encode::MIME::Header, MIME::EncWords, MIME::AltWords

Dans un avenir quelconque, l'une de ces implémentations remplacera probablement MIME::Words et MIME::Words deviendra obsolète.

NOTES

Exporte ses fonctions principales par défaut, en suivant le style de MIME::Base64 et MIME::QuotedPrint.
