NOM

MIME::Decoder::QuotedPrint - encoder/décoder un flux "quoted-printable"

SYNOPIS

Un objet décodeur générique ; voir MIME::Decoder pour l'utilisation.

DESCRIPTION

Une sous-classe de MIME::Decoder pour l'encodage "quoted-printable". Le nom a été choisi pour correspondre au package utilitaire MIME::QuotedPrint préexistant, que cette classe utilise réellement pour traduire chaque ligne.

  • Le décodeur effectue une traduction ligne par ligne de l'entrée vers la sortie.
  • L'encodeur effectue une traduction ligne par ligne, en cassant les lignes de sorte qu'elles respectent la limite standard de 76 caractères pour cet encodage.

Note : tout comme MIME::QuotedPrint, nous utilisons actuellement le caractère "\n" natif pour les sauts de ligne, et non "CRLF". Cela pourra nécessiter un changement dans les futures versions.
