Extensions du module List

type 'a t = 'a list

val compare : ('a -> 'a -> int) -> 'a t -> 'a t -> int

L'ordre lexicographique supporté par l'ordre fourni. Il n'y a aucune contrainte sur les longueurs relatives des listes.

val equal : ('a -> 'a -> bool) -> 'a t -> 'a t -> bool

Retourne true si et seulement si les listes données ont la même longueur et le même contenu par rapport à la fonction d'égalité donnée.

val some_if_all_elements_are_some : 'a option t -> 'a t option

Si tous les éléments de la liste donnée sont Some _ alors Some xs est retourné avec xs étant le contenu de ces Some, l'ordre étant préservé. Sinon retourne None.

val map2_prefix : ('a -> 'b -> 'c) -> 'a t -> 'b t -> 'c t * 'b t

let r1, r2 = map2_prefix f l1 l2 Si l1 est de longueur n et l2 = h2 @ t2 avec h2 de longueur n, r1 est List.map2 f l1 h1 et r2 est t2.

val iteri2 : (int -> 'a -> 'b -> unit) -> 'a list -> 'b list -> unit

Identique à List.iter2, mais la fonction est appliquée à l'index de l'élément comme premier argument (en comptant à partir de 0).

val split_at : int -> 'a t -> 'a t * 'a t

split_at n l retourne la paire before, after où before sont les n premiers éléments de l et after les éléments restants. Si l a moins de n éléments, lève Invalid_argument.

val chunks_of : int -> 'a t -> 'a t t

chunks_of n t retourne une liste de listes non vides dont la concaténation est égale à la liste originale. Chaque liste contient n éléments, sauf éventuellement la dernière liste, qui peut en contenir moins. chunks_of lève une exception si n <= 0.

val is_prefix : equal:('a -> 'a -> bool) -> 'a list -> of_:'a list -> bool

Retourne true si et seulement si la liste donnée, par rapport à la fonction d'égalité donnée sur les membres de la liste, est un préfixe de la liste of_.

type 'a longest_common_prefix_result = private {
longest_common_prefix : 'a list ;
first_without_longest_common_prefix : 'a list ;
second_without_longest_common_prefix : 'a list ;
}

val find_and_chop_longest_common_prefix : equal:('a -> 'a -> bool) -> first:'a list -> second:'a list -> 'a longest_common_prefix_result

Retourne la plus longue liste qui, par rapport à la fonction d'égalité fournie, est un préfixe des deux listes données. Les listes d'entrée, chacune avec son plus long préfixe commun retiré, sont également retournées.
