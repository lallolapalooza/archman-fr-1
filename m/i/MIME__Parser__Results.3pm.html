NOM

MIME::Parser::Results - résultats de la dernière entité analysée

SYNOPIS

Avant de lire plus loin, vous devriez consulter MIME::Parser pour vous assurer que vous comprenez où ce module s'intègre dans le grand schéma des choses. Allez-y, faites-le maintenant. J'attendrai.

Prêt ? Ok...

### Analyser, obtenir les résultats :
my $entity = eval { $parser->parse(\*STDIN); };
my $results  = $parser->results;
### Obtenir tous les messages enregistrés :
@msgs = $results->msgs;
### Obtenir les messages de types spécifiques (teste également s'il y a eu des problèmes) :
$had_errors   = $results->errors;
$had_warnings = $results->warnings;
### Obtenir l'en-tête le plus externe :
$top_head  = $results->top_head;

DESCRIPTION

Résultats de la dernière analyse par MIME::Parser.

INTERFACE PUBLIQUE

new
Constructeur.
msgs
Méthode d'instance. Renvoie tous les messages que nous avons enregistrés, dans l'ordre. Chaque message est une chaîne commençant par son type suivi de ": " ; les types actuels sont "debug", "warning", et "error".
errors
Méthode d'instance. Renvoie tous les messages d'erreur que nous avons enregistrés, dans l'ordre. Une façade pratique vers msgs().
warnings
Méthode d'instance. Renvoie tous les messages d'avertissement que nous avons enregistrés, dans l'ordre. Une façade pratique vers msgs().
top_head
Méthode d'instance. Renvoie l'en-tête le plus externe, si nous avons pu le lire. Cela peut être utile si l'analyse échoue.
