XtPopdown(3) FONCTIONS XT XtPopdown(3)

NOM

XtPopdown, XtCallbackPopdown - dissocier une fenêtre contextuelle

SYNTAXE

#include <X11/Intrinsic.h>

void XtPopdown(Widget popup_shell);

void XtCallbackPopdown(Widget w, XtPointer client_data, XtPointer call_data);

ACTIONS

void XtMenuPopdown(String shell_name);

ARGUMENTS

call_data
Spécifie les données de rappel, qui ne sont pas utilisées par cette procédure.
client_data
Spécifie un pointeur vers la structure XtPopdownID.
popup_shell
Spécifie le widget shell à dissocier.
shell_name
Spécifie le nom du widget shell à dissocier.
w
Spécifie le widget.

DESCRIPTION

La fonction XtPopdown effectue les opérations suivantes :

  • Appelle XtCheckSubclass pour s'assurer que popup_shell est une sous-classe de Shell.
  • Vérifie que popup_shell est actuellement "popped_up" (affiché) ; sinon, elle génère une erreur.
  • Dissocie la fenêtre de popup_shell.
  • Si grab_kind de popup_shell est XtGrabNonexclusive ou XtGrabExclusive, elle appelle XtRemoveGrab.
  • Définit le champ popped_up du shell contextuel à False.
  • Appelle les procédures de rappel de la liste popdown_callback du shell.

La fonction XtCallbackPopdown convertit le paramètre de données client en un pointeur XtPopdownID :

typedef struct {
        Widget shell_widget;
        Widget enable_widget;
} XtPopdownIDRec, *XtPopdownID;

shell_widget est le shell contextuel à dissocier, et enable_widget est le widget qui a été utilisé pour l'afficher.

XtCallbackPopdown appelle XtPopdown avec le shell_widget spécifié, puis appelle XtSetSensitive pour réactiver l'enable_widget.

Si aucun nom de shell n'est donné, XtMenuPopdown appelle XtPopdown avec le widget pour lequel la traduction est spécifiée. Si un nom de shell est spécifié dans la table de traduction, XtMenuPopdown essaie de trouver le shell en parcourant l'arbre des widgets en partant du parent du widget dans lequel il est invoqué. S'il trouve un shell portant le nom spécifié dans les enfants contextuels de ce parent, il dissocie le shell ; sinon, il remonte la chaîne des parents si nécessaire. Si XtMenuPopdown atteint le widget shell de niveau supérieur de l'application et ne trouve pas de shell correspondant, il génère une erreur.
