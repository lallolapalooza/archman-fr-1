NOM

Memory::Usage - Outils pour déterminer l'utilisation réelle de la mémoire

VERSION

Version 0.201

SYNOPIS

use Memory::Usage;
my $mu = Memory::Usage->new();
# Enregistrer la quantité de mémoire utilisée par le processus actuel
$mu->record('début du travail');
# Faire la chose que vous voulez mesurer
$object->something_memory_intensive();
# Enregistrer la quantité utilisée par la suite
$mu->record('après something_memory_intensive()');
# Afficher un rapport
$mu->dump();

DESCRIPTION

Ce module vous permet de tenter de mesurer, du point de vue de votre système d'exploitation, la quantité de mémoire utilisée par un processus à un moment donné.

MÉTHODES

Méthodes de classe

new ( )
Crée un nouvel objet Memory::Usage. Cet objet contiendra l'état d'utilisation tel qu'enregistré au fil du temps.

Méthodes d'instance

record ( $message [, $pid ])
Enregistre l'utilisation de la mémoire au moment de l'appel, en l'enregistrant en interne avec le message fourni. Prend éventuellement un identifiant de processus pour enregistrer l'utilisation de la mémoire, qui par défaut est le processus actuel.
report ( )
Génère un rapport sur l'utilisation de la mémoire.
dump ( )
Imprime le rapport sur l'utilisation de la mémoire sur stderr.
state ( )
Retourne une référence d'array de l'état interne. La référence d'array retournée contient zéro ou plusieurs références à des arrays avec les colonnes suivantes (dans l'ordre). Toutes les tailles sont en kilo-octets.
timestamp (en secondes depuis l'époque)
message (tel que passé à ->record())
taille de la mémoire virtuelle
taille de l'ensemble résident
taille de la mémoire partagée
taille du texte (alias code ou exécutable)
taille des données et de la pile

VOIR AUSSI

  • Memchmark

    Exécute itérativement des coderefs (similaire à Benchmark) et compare leur utilisation mémoire. Utile pour optimiser des sous-routines spécifiques avec une utilisation mémoire importante une fois que vous les avez identifiées comme gourmandes en mémoire. Utilise la même technique pour collecter les informations d'utilisation que ce module, donc la précision et la justesse en souffrent de manière similaire.

  • Devel::Size

    Affiche la taille des variables Perl. Utile également pour les micro-optimisations lorsque vous savez ce que vous recherchez. Examine les détails internes de Perl, donc la précision est bonne.
