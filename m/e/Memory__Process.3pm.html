Memory__Process(3pm)

Paquet: perl-memory-process

Licences: PerlArtistic, GPL

Process(3) Documentation Perl Contribuée par les Utilisateurs Process(3)

NOM

Memory::Process - Classe Perl pour déterminer l'utilisation réelle de la mémoire.

SYNOPSIS

use Memory::Process;
my $m = Memory::Process->new(%params);
$m->dump;
$m->record($message, $pid);
my @report = $m->report;
my $report = $m->report;
$m->reset;
$m->state;

MÉTHODES

"new"

my $m = Memory::Process->new(%params);

Constructeur.

Retourne une instance de l'objet.

"dump"

$m->dump;

Affiche le rapport sur STDERR.

Retourne la valeur de retour de print().

"record"

$m->record($message, $pid);

Définit un enregistrement. Si le message n'est pas défini, utilise ''.

Retourne undef.

"report"

my @report = $m->report;
my $report = $m->report;

Obtient le rapport.

En contexte scalaire, retourne une chaîne avec le rapport. En contexte de tableau, retourne un tableau de lignes de rapport. La première ligne est le titre.

"reset"

$m->reset;

Réinitialise les enregistrements.

Retourne undef.

"state"

$m->state;

Obtient l'état interne.

Chaque élément d'état est composé de :

- horodatage (en secondes depuis l'époque)
- message (provenant de record())
- taille de la mémoire virtuelle (en Ko)
- taille du jeu résident (en Ko)
- taille de la mémoire partagée (en Ko)
- taille du texte (en Ko)
- taille des données et de la pile (en Ko)

Retourne une référence à un tableau contenant les éléments d'état.

EXEMPLE1

use strict;
use warnings;
use Memory::Process;
# Objet.
my $m = Memory::Process->new;
# Processus d'exemple.
$m->record("Avant ma grosse méthode");
my $var = ('foo' x 100);
sleep 1;
$m->record("Après ma grosse méthode");
sleep 1;
$m->record("Fin");
# Affiche le rapport.
print $m->report."\n";
# Sortie similaire à :
#   time    vsz (  diff)    rss (  diff) shared (  diff)   code (  diff)   data (  diff)
#      1  19120 (     0)   2464 (     0)   1824 (     0)      8 (     0)   1056 (     0) Après ma grosse méthode
#      2  19120 (     0)   2464 (     0)   1824 (     0)      8 (     0)   1056 (     0) Fin
