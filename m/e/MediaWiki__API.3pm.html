Paquet: perl-mediawiki-api

MediaWiki::API(3) Documentation Perl contribuée par l'utilisateur MediaWiki::API(3)

NOM

MediaWiki::API - Fournit une interface Perl pour l'API MediaWiki (https://www.mediawiki.org/wiki/API)

VERSION

Version 0.52

SYNOPSIS

Ce module fournit une interface entre Perl et l'API MediaWiki (https://www.mediawiki.org/wiki/API) permettant la création de scripts pour automatiser l'édition et l'extraction de données à partir de sites pilotés par MediaWiki comme Wikipedia.

use MediaWiki::API;
my $mw = MediaWiki::API->new();
$mw->{config}->{api_url} = 'https://fr.wikipedia.org/w/api.php'; # Exemple pour Wikipedia en français
# se connecter au wiki
$mw->login( { lgname => 'nom_utilisateur', lgpassword => 'mot_de_passe' } )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};
# obtenir une liste d'articles dans une catégorie
my $articles = $mw->list ( {
  action => 'query',
  list => 'categorymembers',
  cmtitle => 'Catégorie:Perl',
  cmlimit => 'max' } )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};
# et imprimer les titres des articles
foreach (@{$articles}) {
    print "$_->{title}\n";
}
# obtenir des informations sur l'utilisateur
my $userinfo = $mw->api( {
  action => 'query',
  meta => 'userinfo',
  uiprop => 'blockinfo|hasmsg|groups|rights|options|editcount|ratelimits' } );
  ...

FONCTIONS

MediaWiki::API->new( $config_hashref )

Retourne un objet API MediaWiki. Vous pouvez passer une configuration sous forme de hashref lors de l'appel de new, ou définir la configuration plus tard. Lors de la création d'un nouvel objet, les valeurs par défaut pour le délai maximum et les nouvelles tentatives sont définies.

my $mw = MediaWiki::API->new( { api_url => 'https://fr.wikipedia.org/w/api.php' }  );

Les options de configuration sont :

  • api_url = 'Chemin vers api.php de MediaWiki' ;
  • files_url = 'URL de base pour les fichiers' ; (nécessaire si l'api renvoie une URL relative pour les images comme /images/a/picture.jpg)
  • upload_url = 'https://fr.wikipedia.org/wiki/Spécial:Téléverser' ; (chemin vers la page spéciale de téléversement requise si vous souhaitez téléverser des images)
  • on_error = Référence de fonction à appeler si une erreur se produit dans le module.
  • use_http_get = Booléen 0 ou 1 (par défaut 0). Si défini à 1, le module Perl utilisera la méthode GET http pour accéder à l'api. Par défaut, il utilise la méthode POST. Notez que le module utilisera toujours POST pour les appels d'api qui nécessitent POST, quelle que soit la valeur de cette option de configuration. Actuellement, les actions suivantes fonctionneront avec GET : query, logout, paraminfo - voir la configuration get_actions ci-dessous.
  • get_actions = Hashref (par défaut { 'query' => 1, 'logout' => 1, 'paraminfo' => 1 } ). Ceci contient les actions de l'API qui sont prises en charge par la méthode GET http si elle est activée. Certains wikis peuvent avoir des extensions qui ajoutent plus de fonctions qui fonctionnent avec une requête http GET. Si c'est le cas, vous pouvez ajouter des actions au besoin.
  • retries = Valeur entière ; Le nombre de nouvelles tentatives pour envoyer une requête API si une erreur http ou une erreur de décodage JSON se produit. Par défaut 0 (essayer une seule fois - ne pas réessayer). Si max_retries est défini à 4 et que le wiki est indisponible, l'erreur ne sera signalée qu'après la 5ème tentative de connexion.
  • retry_delay = Valeur entière en secondes ; Le temps d'attente avant de réessayer une requête en cas d'erreur HTTP ou d'erreur de décodage JSON.
  • max_lag = Valeur entière en secondes ; Wikipedia fonctionne sur un cluster de bases de données et, par conséquent, des taux d'édition élevés entraînent un décalage des serveurs esclaves. Si cette option de configuration est définie, et que le décalage est supérieur à la valeur de max_lag, l'api attendra avant de réessayer la requête. 5 est une valeur recommandée. Plus d'informations sur ce sujet peuvent être trouvées sur https://www.mediawiki.org/wiki/Manual:Maxlag_parameter. Notez que l'option de configuration inclut un trait de soulignement, donc faites correspondre le schéma de nommage des autres options de configuration.
  • max_lag_delay = Valeur entière en secondes ; Cette option de configuration spécifie le délai d'attente avant de réessayer une requête lorsque le serveur a signalé un décalage supérieur à la valeur de max_lag. Par défaut, il est de 5 si l'option de configuration max_lag est utilisée.
  • max_lag_retries = Valeur entière ; Le nombre de nouvelles tentatives pour envoyer une requête API si le serveur a signalé un décalage supérieur à la valeur de max_lag. Si le nombre maximum de nouvelles tentatives est atteint, une erreur est renvoyée. Définir ceci à une valeur négative comme -1 signifie que la requête est renvoyée jusqu'à ce que le max_lag des serveurs soit inférieur au seuil ou qu'une autre erreur se produise. Par défaut 4.
  • no_proxy = Booléen ; Défini à 1 pour désactiver l'utilisation de tout proxy défini dans l'environnement. Notez que par défaut, si vous avez des variables d'environnement proxy définies, le module tentera de les utiliser. Cette fonctionnalité a été ajoutée à la version 0.29. Les versions antérieures ignorent tous les paramètres proxy, mais vous pouvez le définir vous-même en appelant MediaWiki::API->{ua}->env_proxy() après avoir créé une nouvelle instance de la classe API. Plus d'informations sur env_proxy peuvent être trouvées sur http://search.cpan.org/~gaas/libwww-perl-5.834/lib/LWP/UserAgent.pm#Proxy_attributes

Un exemple pour la configuration on_error pourrait être quelque chose comme :

$mw->{config}->{on_error} = \&on_error;
sub on_error {
  print "Code d'erreur : " . $mw->{error}->{code} . "\n";
  print $mw->{error}->{stacktrace}."\n";
  die;
}

Les erreurs sont stockées dans $mw->{error}->{code} avec plus d'informations dans $mw->{error}->{details}. $mw->{error}->{stacktrace} comprend les détails et une trace de pile pour localiser d'où proviennent les problèmes (dans un code qui utilise ce module, par exemple).

Les codes d'erreur sont les suivants :

  • ERR_NO_ERROR = 0 (Aucune erreur)
  • ERR_CONFIG = 1 (Erreur de configuration)
  • ERR_HTTP = 2 (Erreur de connexion liée à HTTP)
  • ERR_API = 3 (Erreur renvoyée par l'API MediaWiki)
  • ERR_LOGIN = 4 (Erreur de connexion à MediaWiki)
  • ERR_EDIT = 5 (Erreur avec une fonction d'édition)
  • ERR_PARAMS = 6 (Erreur avec les paramètres passés à une fonction d'aide)
  • ERR_UPLOAD = 7 (Erreur avec la fonction de téléversement de fichiers)
  • ERR_DOWNLOAD = 8 (Erreur lors du téléchargement d'un fichier)

Autres paramètres et objets utiles dans l'objet MediaWiki::API :

  • MediaWiki::API->{ua} = L'objet LWP::UserAgent. Vous pourriez le modifier pour obtenir ou modifier les cookies (MediaWiki::API->{ua}->cookie_jar) ou pour changer la chaîne UserAgent envoyée par ce module Perl (MediaWiki::API->{ua}->agent)
  • MediaWiki::API->{response} = L'objet de réponse dernier renvoyé par LWP::UserAgent après une requête API.

MediaWiki::API->login( $query_hashref )

Se connecte à un MediaWiki. Les paramètres sont ceux utilisés par l'API MediaWiki (https://www.mediawiki.org/wiki/API:Login). Renvoie un hashref avec certains détails de connexion, ou undef en cas d'échec de connexion. Si Mediawiki demande un LoginToken, la connexion est retentée, mais avec le token envoyé lors de la première connexion. Les erreurs sont stockées dans MediaWiki::API->{error}->{code} et MediaWiki::API->{error}->{details}.

my $mw = MediaWiki::API->new( { api_url => 'https://fr.wikipedia.org/w/api.php' }  );
# se connecter au wiki
$mw->login( {lgname => 'nom_utilisateur', lgpassword => 'mot_de_passe' } )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

MediaWiki::API->api( $query_hashref, $options_hashref )

Appelle l'interface API MediaWiki. Les paramètres sont passés sous forme de hashref décrits sur la page de l'API MediaWiki (https://www.mediawiki.org/wiki/API). Renvoie un hashref avec les résultats de l'appel ou undef en cas d'échec, avec le code d'erreur et les détails stockés dans MediaWiki::API->{error}->{code} et MediaWiki::API->{error}->{details}. MediaWiki::API utilise le module LWP::UserAgent pour envoyer les requêtes http à l'API MediaWiki. Après tout appel API, l'objet de réponse renvoyé par LWP::UserAgent est disponible dans $mw->{response}. Cette fonction ne modifiera PAS le query_hashref d'entrée de quelque manière que ce soit.

binmode STDOUT, ':utf8';
# obtenir le nom du site
if ( my $ref = $mw->api( { action => 'query', meta => 'siteinfo' } ) ) {
  print $ref->{query}->{general}->{sitename};
}
# liste des titres pour "Albert Einstein" dans différentes langues.
my $titles

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

= $mw->api( { action => 'query', titles => 'Albert Einstein', prop => 'langlinks', lllimit => 'max' } ) || die $mw->{error}->{code} . ': ' . $mw->{error}->{details}; my ($pageid,$langlinks) = each ( %{ $titles->{query}->{pages} } ); foreach ( @{ $langlinks->{langlinks} } ) { print "$_->{'*'}\n"; }

L'API de MediaWiki utilise UTF-8 et les chaînes de paramètres à 8 bits sont encodées automatiquement par l'appel API. Si vos paramètres sont déjà en UTF-8, cela sera détecté et l'encodage sera ignoré. Si vos paramètres contiennent pour une raison quelconque des données UTF-8 mais qu'aucun indicateur UTF-8 n'est défini (c'est-à-dire que vous n'avez pas utilisé le pragma "use utf8;"), vous devriez empêcher le ré-encodage en passant une option skip_encoding => 1 dans le $options_hash. Par exemple :

my $mw = MediaWiki::API->new();
$mw->{config}->{api_url} = 'https://fr.wiktionary.org/w/api.php';
my $query = {action => 'query',
  list => 'categorymembers',
  cmlimit => 'max'};
$query->{cmtitle} ="Cat\x{e9}gorie:moyen_fran\x{e7}ais"; # chaîne latin1
$mw->list ( $query ); # ok 
$query->{cmtitle} = "Cat". pack("U", 0xe9)."gorie:moyen_fran".pack("U",0xe7)."ais"; # chaîne unicode
$mw->list ( $query ); # ok
$query->{cmtitle} ="Cat\x{c3}\x{a9}gorie:moyen_fran\x{c3}\x{a7}ais";  # données unicode sans indicateur utf-8
# $mw->list ( $query ); # PAS OK
$mw->list ( $query, {skip_encoding => 1} ); # ok

Si vous appelez une fonction API qui nécessite le téléchargement d'un fichier, par exemple import ou upload, spécifiez le fichier à télécharger comme un arrayref contenant le nom du fichier local. L'API peut renvoyer un avertissement, par exemple pour indiquer que le fichier est un doublon. Pour ignorer les avertissements et forcer le téléchargement, utilisez ignorewarnings => 1. Tous les paramètres, comme tout le reste, peuvent être trouvés sur la page API de MediaWiki.

$mw->api( {
  action => 'import',
  xml => ['wiki_dump.xml']
 } );
$mw->api( {
  action => 'upload',
  filename => 'test.png',
  comment => 'a test image',
  file => ['test.png'],
 } );

Vous pouvez également fournir les données à télécharger directement, si vous souhaitez lire les données vous-même. Dans ce cas, fournissez un arrayref avec trois paramètres, commençant par un "undef", suivi du nom du fichier, puis d'une paire Content => $data contenant les données.

$mw->api( {
  action => 'import',
  xml => [ undef, 'wiki_dump.xml', Content => $data ]
 } );
$mw->api( {
  action => 'upload',
  filename => 'test.png',
  comment => 'a test image',
  file => [ undef, 'test.png', Content => $data ],
 } );

MediaWiki::API->logout()

Déconnecte l'utilisateur actuel et efface les cookies et jetons de modification associés.

MediaWiki::API->edit( $query_hashref, $options_hashref )

Une fonction d'aide pour effectuer des modifications en utilisant l'API de MediaWiki. Les paramètres sont passés sous forme de hashref décrits sur la page d'édition de l'API de MediaWiki (https://www.mediawiki.org/wiki/API:Changing_wiki_content). Notez que vous avez besoin de $wgEnableWriteAPI = true dans votre LocalSettings.php pour utiliser ces fonctionnalités. Cette fonction modifiera le hashref d'entrée.

Actuellement

  • Créer/Modifier des pages (Mediawiki >= 1.13 )
  • Déplacer des pages (Mediawiki >= 1.12 )
  • Annuler (Rollback) (Mediawiki >= 1.12 )
  • Supprimer des pages (Mediawiki >= 1.12 )
  • Télécharger des images (Mediawiki >= 1.16 )
  • Importer des pages (Mediawiki >= 1.15 )
  • (Dé)protéger des pages (Mediawiki >= 1.12 )
  • (Dé)bloquer des utilisateurs (Mediawiki >= 1.12 )
  • (Ne pas) mettre une page en suivi (Mediawiki >= 1.18 )
  • Envoyer un e-mail à un utilisateur (Mediawiki >= 1.14 )
  • Patrouiller les modifications (Mediawiki >= 1.14 )

sont pris en charge via cet appel. Utilisez cet appel pour modifier des pages sans avoir à vous soucier d'obtenir d'abord un jeton de modification de l'API. La fonction mettra en cache les jetons de modification pour accélérer les modifications futures.

Retourne un hashref avec les résultats de l'appel ou undef en cas d'échec avec le code d'erreur et les détails stockés dans MediaWiki::API->{error}->{code} et MediaWiki::API->{error}->{details}.

Le hashref d'options contient actuellement un paramètre optionnel (skip_encoding => 1). Ceci est décrit ci-dessus dans la documentation de l'appel MediaWiki::API->api.

Voici quelques exemples d'extraits de code. Le premier exemple consiste à ajouter du texte à une page existante (si la page n'existe pas, rien ne se passera). Notez que l'horodatage de la révision que nous modifions est sauvegardé. Cela nous permet d'éviter les conflits de modification. La valeur est renvoyée à la fonction d'édition, et si quelqu'un avait modifié la page entre-temps, une erreur sera renvoyée.

my $pagename = "Wikipedia:Sandbox";
my $ref = $mw->get_page( { title => $pagename } );
unless ( $ref->{missing} ) {
  my $timestamp = $ref->{timestamp};
  $mw->edit( {
    action => 'edit',
    title => $pagename,
    basetimestamp => $timestamp, # pour éviter les conflits d'édition
    text => $ref->{'*'} . "\nTexte supplémentaire" } )
    || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};
}

Le code suivant supprime une page nommée "DeleteMe". Vous pouvez spécifier une raison pour la suppression, sinon une raison générée sera utilisée.

# supprimer une page
$mw->edit( {
  action => 'delete', title => 'DeleteMe', reason => 'ne plus être nécessaire' } ) 
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

Ce code déplace une page de MoveMe à MoveMe2.

# déplacer une page
$mw->edit( {
  action => 'move', from => 'MoveMe', to => 'MoveMe2' } )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

Le script suivant annule une ou plusieurs modifications de l'utilisateur MrVandal. Si l'utilisateur n'est pas le dernier éditeur de la page, une erreur sera renvoyée. Si aucun utilisateur n'est passé, les modifications de celui qui a modifié la page en dernier seront annulées.

$mw->edit( {
  action => 'rollback', title => 'Sandbox', user => 'MrVandal' } )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

MediaWiki::API->get_page( $params_hashref )

Une fonction d'aide pour obtenir le contenu le plus récent de la page (et d'autres métadonnées) pour une page. Elle appelle la fonction api de plus bas niveau avec une requête de révisions pour obtenir la révision la plus récente.

# obtenir le contenu d'une page
my $page = $mw->get_page( { title => 'Main Page' } );
# imprimer le contenu de la page
print $page->{'*'};

Retourne un hashref avec les clés suivantes ou undef en cas d'erreur. Si la page est manquante, le hashref retourné ne contiendra que ns, title et une clé appelée "missing".

  • '*' - contenu de la page
  • 'pageid' - id de la page
  • 'revid' - id de la révision
  • 'timestamp' - horodatage de la révision
  • 'user' - utilisateur qui a effectué la révision
  • 'title' - titre de la page
  • 'ns' - espace de noms dans lequel se trouve la page
  • 'size' - taille de la page en octets

Des informations complètes à leur sujet peuvent être lues sur (https://www.mediawiki.org/wiki/API:Query_-_Properties#revisions_.2F_rv)

MediaWiki::API->list( $query_hashref, $options_hashref )

Une fonction d'aide pour obtenir des listes en utilisant l'API de MediaWiki. Les paramètres sont passés sous forme de hashref qui sont décrits sur la page d'édition de l'API de MediaWiki (https://www.mediawiki.org/wiki/API:Query_-_Lists). Cette fonction modifie le query_hashref d'entrée.

Cette fonction retournera une référence à un tableau de hachages ou undef en cas d'échec. Elle gère l'obtention de listes de données à partir de l'API de MediaWiki, en continuant la requête avec une autre connexion si nécessaire. Le options_hashref contient actuellement trois paramètres :

  • max => valeur
  • hook => \&fonction_hook
  • skip_encoding => 1

La valeur de max spécifie le nombre maximum de "requêtes" qui seront utilisées pour extraire les données. Par exemple, la limite par défaut par requête est de 10 éléments, mais cela peut être augmenté à 500 pour les utilisateurs normaux et plus pour les administrateurs et les bots. Si la limite est augmentée à 500 et que max était défini à 2, un maximum de 1000 résultats serait retourné.

Si vous souhaitez traiter de grandes listes, par exemple les articles d'une grande catégorie, vous pouvez passer une fonction hook, qui recevra une référence à un tableau de résultats pour chaque connexion de requête.

Le paramètre skip_encoding fonctionne comme décrit ci-dessus dans la documentation de l'appel MediaWiki::API->api.

binmode STDOUT, ':utf8';
# traiter les 400 premiers articles dans l'espace de noms principal de la catégorie "Surnames".
# obtenir 100 à la fois, avec un maximum de 4 et passer chaque 100 à notre hook.
$mw->list ( { action => 'query',
              list => 'categorymembers',
              cmtitle => 'Category:Surnames',
              cmnamespace => 0,
              cmlimit=>'100' },
            { max => 4, hook => \&print_articles } )
|| die $mw->{error}->{code} . ': ' . $mw->{error}->{details};
# imprimer le nom de chaque article
sub print_articles {
  my ($ref) = @_;
  foreach (@$ref) {
    print "$_->{title}\n";
  }
}

MediaWiki::API->upload( $params_hashref )

Cette fonction est dépréciée. Pour les téléchargements sur les versions 1.16 ou ultérieures de mediawiki, il est recommandé d'utiliser MediaWiki::API->edit ou MediaWiki::API->api directement, qui a une bien meilleure gestion des erreurs et prend en charge le téléchargement de fichiers en passant simplement un nom de fichier.

Une fonction pour télécharger des fichiers sur un MediaWiki. Cette fonction n'utilise pas l'API MediaWiki actuellement car la prise en charge du téléchargement de fichiers n'est pas encore implémentée. Au lieu de cela, elle télécharge en utilisant la page Special:Upload, et à ce titre une valeur de configuration supplémentaire est nécessaire.

my $mw = MediaWiki::API->new( {
 api_url => 'https://en.wikipedia.org/w/api.php' }  );
# configurer l'emplacement spécial de téléchargement.
$mw->{config}->{upload_url} = 'https://en.wikipedia.org/wiki/Special:Upload';

La fonction upload est ensuite appelée comme suit

# télécharger un fichier sur MediaWiki
open FILE, "myfile.jpg" or die $!;
binmode FILE;
my ($buffer, $data);
while ( read(FILE, $buffer, 65536) )  {
  $data .= $buffer;
}
close(FILE);
$mw->upload( { title => 'file.jpg',
               summary => 'Ceci est le résumé pour la page Image:file.jpg',
               data => $data } ) || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

La vérification des erreurs est limitée. Notez également que le module forcera un téléchargement de fichier, ignorant tout avertissement concernant la taille du fichier ou l'écrasement d'un ancien fichier.

MediaWiki::API->download( $params_hashref )

VERSION

Une fonction pour télécharger des images/fichiers depuis un MediaWiki. Une URL de fichier peut devoir être configurée si l'API renvoie une URL relative.

my $mw = MediaWiki::API->new( {
  api_url => 'https://www.exotica.org.uk/mediawiki/api.php' }  );
# configurer l'URL du fichier. Wikipedia n'en a pas besoin mais le wiki ExoticA en a besoin.
$mw->{config}->{files_url} = 'https://www.exotica.org.uk';

La fonction de téléchargement est ensuite appelée comme suit :

my $file = $mw->download( { title => 'Image:Mythic-Beasts_Logo.png'} )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

Si le fichier n'existe pas (sur le wiki), une chaîne vide est retournée. Si le fichier ne peut pas être téléchargé, undef est retourné.
