type !+'a t

val vide : 'a t

La map vide.

val ajouter : cle:cle -> donnee:'a -> 'a t -> 'a t

ajouter ~cle ~donnee m retourne une map contenant les mêmes associations que m, plus une association de cle à donnee. Si cle est déjà associée dans m à une valeur physiquement égale à donnee, m est retournée sans changement (le résultat de l'opération est alors physiquement égal à m). Sinon, l'association précédente de cle dans m est supprimée.

Avant 4.03 L'égalité physique n'était pas garantie.

val ajouter_a_liste : cle:cle -> donnee:'a -> 'a list t -> 'a list t

ajouter_a_liste ~cle ~donnee m est m avec cle associée à l où l est donnee :: Map.find cle m si cle était associée dans m, ou [donnee] sinon.

val mettre_a_jour : cle:cle -> f:('a option -> 'a option) -> 'a t -> 'a t

mettre_a_jour ~cle ~f m retourne une map ayant les mêmes associations que m, à l'exception de l'association de cle. Selon la valeur de y où y est f (find_opt cle m), l'association de cle est ajoutée, supprimée ou mise à jour. Si y est None, l'association de cle est supprimée si elle existe ; sinon, si y est Some z, cle est associée à z dans la map résultante. Si cle était déjà associée dans m à une valeur physiquement égale à z, m est retournée sans changement (le résultat de l'opération est alors physiquement égal à m).

val singleton : cle -> 'a -> 'a t

singleton x y retourne la map d'une seule entrée ayant l'association y pour x.

val supprimer : cle -> 'a t -> 'a t

supprimer x m retourne une map ayant les mêmes associations que m, à l'exception de x qui n'est pas associée dans la map résultante. Si x n'était pas dans m, m est retournée sans modification (le résultat de l'opération est alors physiquement égal à m).

Avant 4.03 L'égalité physique n'était pas garantie.

val fusionner : f:(cle:cle -> 'a option -> 'b option -> 'c option) -> 'a t -> 'b t -> 'c t

fusionner ~f m1 m2 calcule une map dont les clés sont un sous-ensemble des clés de m1 et de m2. La présence de chaque association ainsi que la valeur correspondante sont déterminées par la fonction f. En termes de l'opération find_opt, nous avons find_opt x (fusionner f m1 m2) = f x (find_opt x m1) (find_opt x m2) pour toute clé x, à condition que f x None None = None.

Depuis 3.12

val union : f:(cle:cle -> 'a -> 'a -> 'a option) -> 'a t -> 'a t -> 'a t

union ~f m1 m2 calcule une map dont les clés sont un sous-ensemble des clés de m1 et de m2. Lorsque la même association est définie dans les deux arguments, la fonction f est utilisée pour les combiner. Ceci est un cas particulier de fusionner : union f m1 m2 est équivalent à fusionner f' m1 m2, où

- f' _cle None None = None - f' _cle (Some v) None = Some v - f' _cle None (Some v) = Some v - f' cle (Some v1) (Some v2) = f cle v1 v2

Recherche

val trouver : cle -> 'a t -> 'a

trouver x m retourne la valeur actuelle de x dans m, ou lève Not_found s'il n'existe pas d'association de x dans m.

val trouver_opt : cle -> 'a t -> 'a option

trouver_opt x m retourne Some v si la valeur actuelle de x dans m est v, ou None s'il n'existe pas d'association de x dans m.

Depuis 4.05

val trouver_premiere : f:(cle -> bool) -> 'a t -> cle * 'a

trouver_premiere ~f m , où f est une fonction monotone croissante, retourne l'association de m avec la plus petite clé k telle que f k, ou lève Not_found s'il n'existe pas une telle clé.

Par exemple, trouver_premiere (fun k -> Ord.compare k x >= 0) m retournera la première association k, v de m où Ord.compare k x >= 0 (intuitivement : k >= x), ou lèvera Not_found si x est plus grand que tout élément de m.

trouver_premiere_opt ~f m , où f est une fonction monotone croissante, retourne une option contenant l'association de m avec la plus petite clé k telle que f k, ou None s'il n'existe pas une telle clé.

Parcours

val iter : f:(cle:cle -> donnee:'a -g

t; unit) -> 'a t -> unit

iter ~f m applique f à toutes les liaisons de la map m. f reçoit la clé comme premier argument, et la valeur associée comme second argument. Les liaisons sont passées à f par ordre croissant par rapport à l'ordre sur le type des clés.

val fold : f:(key:key -> data:'a -> 'acc -> 'acc) -> 'a t -> init:'acc -> 'acc

fold ~f m ~init calcule (f kN dN ... (f k1 d1 init)...) , où k1 ... kN sont les clés de toutes les liaisons dans m (par ordre croissant), et d1 ... dN sont les données associées.

Transformation

val map : f:('a -> 'b) -> 'a t -> 'b t

map ~f m retourne une map ayant le même domaine que m , où la valeur associée a de toutes les liaisons de m a été remplacée par le résultat de l'application de f à a. Les liaisons sont passées à f par ordre croissant par rapport à l'ordre sur le type des clés.

val mapi : f:(key -> 'a -> 'b) -> 'a t -> 'b t

Identique à MoreLabels.Map.S.map , mais la fonction reçoit en arguments à la fois la clé et la valeur associée pour chaque liaison de la map.

val filter : f:(key -> 'a -> bool) -> 'a t -> 'a t

filter ~f m retourne la map contenant toutes les liaisons de m qui satisfont le prédicat f. Si toutes les liaisons de m satisfont f, m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m).

Avant4.03 L'égalité physique n'était pas garantie.

Depuis 3.12

val filter_map : f:(key -> 'a -> 'b option) -> 'a t -> 'b t

filter_map ~f m applique la fonction f à chaque liaison de m, et construit une map à partir des résultats. Pour chaque liaison (k, v) dans la map d'entrée :

- si f k v est None alors k n'est pas dans le résultat,

- si f k v est Some v' alors la liaison (k, v') est dans la map de sortie.

Par exemple, la fonction suivante sur des maps dont les valeurs sont des listes

          filter_map
            (fun _k li -> match li with [] -> None | _::tl -> Some tl)
            m
supprime toutes les liaisons de m dont la valeur est une liste vide, et dépile le premier élément de chaque valeur non vide.

val partition : f:(key -> 'a -> bool) -> 'a t -> 'a t * 'a t

partition ~f m retourne un couple de maps (m1, m2) , où m1 contient toutes les liaisons de m qui satisfont le prédicat f, et m2 est la map contenant toutes les liaisons de m qui ne satisfont pas f.

Depuis 3.12

val split : key -> 'a t -> 'a t * 'a option * 'a t

split x m retourne un triplet (l, data, r) , où l est la map contenant toutes les liaisons de m dont la clé est strictement inférieure à x ; r est la map contenant toutes les liaisons de m dont la clé est strictement supérieure à x ; data est None si m ne contient aucune liaison pour x, ou Some v si m associe v à x.

Prédicats et comparaisons

val is_empty : 'a t -> bool

Teste si une map est vide ou non.

val mem : key -> 'a t -> bool

mem x m retourne true si m contient une liaison pour x, et false sinon.

val equal : cmp:('a -> 'a -> bool) -> 'a t -> 'a t -> bool

equal ~cmp m1 m2 teste si les maps m1 et m2 sont égales, c'est-à-dire, contiennent des clés égales et leur associent des données égales. cmp est le prédicat d'égalité utilisé pour comparer les données associées aux clés.

val compare : cmp:('a -> 'a -> int) -> 'a t -> 'a t -> int

Ordre total entre les maps. Le premier argument est un ordre total utilisé pour comparer les données associées aux clés égales dans les deux maps.

val for_all : f:(key -> 'a -> bool) -> 'a t -> bool

for_all ~f m vérifie si toutes les liaisons de la map satisfont le prédicat f.

Depuis 3.12

val exists : f:(key -> 'a -> bool) -> 'a t -> bool

exists ~f m vérifie si au moins une liaison de la map satisfait le prédicat f.
