NOM

Mouse::Meta::Class - Le métaclasse de classe Mouse

VERSION

Ce document décrit la version de Mouse v2.6.0

DESCRIPTION

Cette classe est un protocole d'objet méta pour les classes Mouse, qui est un sous-ensemble de Moose::Meta:::Class.

MÉTHODES

"initialize(NomClasse) -> Mouse::Meta::Class"

Trouve ou crée une instance de "Mouse::Meta::Class" pour le NomClasse donné. Une seule instance doit exister pour une classe donnée.

"nom -> NomClasse"

Retourne le nom de la classe propriétaire.

"superclasses -> NomsClasses" superclasse(NomsClasses)

Obtient (ou définit) la liste des superclasses de la classe propriétaire.

"ajouter_méthode(nom => CodeRef)"

Ajoute une méthode à la classe propriétaire.

"a_méthode(nom) -> Bool"

Retourne si nous avons une méthode avec le nom donné.

"obtenir_méthode(nom) -> Mouse::Meta::Méthode | undef"

Retourne une Mouse::Meta::Méthode avec le nom donné.

Notez que vous pouvez également utiliser "$métaclasse->nom->peut($nom)" pour le corps d'une méthode.

"obtenir_liste_méthodes -> Noms"

Retourne une liste de noms de méthodes qui sont définies dans la classe locale. Si vous voulez une liste de toutes les méthodes applicables pour une classe, utilisez la méthode "obtenir_toutes_les_méthodes".

"obtenir_toutes_les_méthodes -> (Mouse::Meta::Méthode)"

Retourne la liste de toutes les instances de Mouse::Meta::Méthode associées à la classe et ses superclasses.

"ajouter_attribut(nom => spécification | Mouse::Meta::Attribut)"

Commence à suivre les Mouse::Meta::Attribut existants pour la classe propriétaire.

"a_attribut(Nom) -> Bool"

Retourne si nous avons un Mouse::Meta::Attribut avec le nom donné.

"obtenir_attribut Nom -> Mouse::Meta::Attribut | undef"

Retourne le Mouse::Meta::Attribut avec le nom donné.

"obtenir_liste_attributs -> Noms"

Retourne une liste de noms d'attributs qui sont définis dans la classe locale. Si vous voulez une liste de tous les attributs applicables pour une classe, utilisez la méthode "obtenir_tous_les_attributs".

"obtenir_tous_les_attributs -> (Mouse::Meta::Attribut)"

Retourne la liste de toutes les instances de Mouse::Meta::Attribut associées à cette classe et ses superclasses.

"isa_linéarisée -> [NomsClasses]"

Retourne la liste des classes dans l'ordre de dispatch des méthodes, avec les doublons supprimés.

"nouvel_objet(Paramètres) -> Instance"

Crée une nouvelle instance.

"cloner_objet(Instance, Paramètres) -> Instance"

Clone l'instance donnée qui doit être une instance gouvernée par ce métaclasse.

"lever_erreur(Message, Paramètres)"

Lève une erreur avec le message donné.
