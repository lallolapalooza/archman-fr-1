val seeded_hash : int -> t -> int

Une fonction de hachage ensemencée sur les clés. Le premier argument est la graine. Il doit être vrai que si equal x y est vrai, alors seeded_hash seed x = seeded_hash seed y pour toute valeur de seed . Un choix approprié pour seeded_hash est la fonction MoreLabels.Hashtbl.seeded_hash ci-dessous.
