NOM

Module::Install::Base - Classe de base pour les extensions Module::Install

SYNTAXE

Dans une extension Module::Install :

use Module::Install::Base ();
@ISA = qw(Module::Install::Base);

DESCRIPTION

Ce module fournit les méthodes essentielles pour toutes les extensions Module::Install, en particulier le constructeur commun "new" et le répartiteur de méthodes "AUTOLOAD".

MÉTHODES

new(%args)
Constructeur -- doit préserver au moins _top
AUTOLOAD
Le répartiteur principal - copie les extensions si elles manquent
_top()
Retourne l'objet Module::Install de niveau supérieur.
admin()
Retourne l'objet Module::Install::Admin associé à l'objet "_top" lors de la première exécution (c'est-à-dire quand il n'y avait pas de répertoire inc/ au démarrage du programme) ; lors des exécutions ultérieures (côté utilisateur), retourne un faux objet admin avec une méthode "AUTOLOAD" vide qui ne fait rien du tout.
is_admin()
Indique s'il s'agit de la première exécution de l'installateur (côté auteur). C'est-à-dire quand il n'y avait pas de répertoire inc/ au démarrage du programme. Vrai si c'est le cas. Faux sinon.
