Module::Loaded(3perl) Guide du programmeur Perl Module::Loaded(3perl)

NOM

Module::Loaded - marquer des modules comme chargés ou déchargés

SYNTAXE

use Module::Loaded;
$bool = mark_as_loaded('Foo');   # Foo.pm est maintenant marqué comme chargé
$loc  = is_loaded('Foo');        # l'emplacement de Foo.pm est réglé sur
                                 # l'emplacement du chargeur
eval "require 'Foo'";            # est maintenant une opération nulle
$bool = mark_as_unloaded('Foo'); # Foo.pm n'est plus marqué comme chargé
eval "require 'Foo'";            # essaiera de trouver Foo.pm dans @INC

DESCRIPTION

Lors des tests d'applications, on se retrouve souvent à devoir fournir dans l'environnement de test des fonctionnalités qui seraient normalement fournies par des modules externes. Plutôt que de manipuler la variable %INC à la main pour marquer ces modules externes comme chargés, afin qu'ils ne soient pas tentés d'être chargés par Perl, ce module vous offre un moyen très simple de marquer les modules comme chargés et/ou déchargés.

FONCTIONS

$bool = mark_as_loaded( PACKAGE );

Marque le paquet comme chargé pour Perl. "PACKAGE" peut être un mot-clé nu ou une chaîne de caractères.

Si le module est déjà chargé, "mark_as_loaded" émettra un avertissement (carp) à ce sujet et vous indiquera à partir d'où le "PACKAGE" a été chargé précédemment.

$bool = mark_as_unloaded( PACKAGE );

Marque le paquet comme déchargé pour Perl, ce qui est l'exact opposé de "mark_as_loaded". "PACKAGE" peut être un mot-clé nu ou une chaîne de caractères.

Si le module est déjà déchargé, "mark_as_unloaded" émettra un avertissement (carp) à ce sujet et vous indiquera que le "PACKAGE" a déjà été déchargé.

$loc = is_loaded( PACKAGE );

"is_loaded" vous indique si "PACKAGE" a déjà été marqué comme chargé. "PACKAGE" peut être un mot-clé nu ou une chaîne de caractères.

Il renvoie faux si "PACKAGE" n'a pas encore été chargé et l'emplacement à partir duquel il est censé être chargé en cas de succès.
