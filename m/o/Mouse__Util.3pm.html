NOM

Mouse::Util - Utilitaires pour travailler avec les classes Mouse

VERSION

Ce document décrit la version v2.6.0 de Mouse

SYNTAXE

use Mouse::Util; # active strict et warnings

DESCRIPTION

Ce module fournit un ensemble de fonctions utilitaires. Beaucoup de ces fonctions sont destinées à être utilisées dans Mouse lui-même ou dans les modules MouseX, mais certaines d'entre elles peuvent être utiles dans votre propre code.

IMPLÉMENTATIONS POUR

Fonctions de Moose::Util

english_listi(@items)

Fonctions de Class::MOP

Les fonctions suivantes ne sont pas exportables.

"Mouse::Util::is_class_loaded($classname) -> Bool"

Retourne si $classname est réellement chargée ou non. Elle utilise une heuristique qui vérifie l'existence de $VERSION, @ISA, et toute méthode définie localement.

"Mouse::Util::load_class($classname) -> ClassName"

Ceci chargera la classe $classname donnée (ou échouera si elle ne peut être chargée). Cette fonction peut être utilisée à la place d'astuces comme "eval "use $module ()"" ou en utilisant "require".
