NOM

Module::CoreList::Utils - quelles utilitaires sont livrés avec les versions de perl

SYNOPSIS

use Module::CoreList::Utils;
print $Module::CoreList::Utils::utilities{5.009003}{ptar}; # affiche 1
print Module::CoreList::Utils->first_release('corelist');
# affiche 5.008009
print Module::CoreList::Utils->first_release_by_date('corelist');
# affiche 5.009002

DESCRIPTION

Module::CoreList::Utils fournit des informations sur les utilitaires principaux et "dual-life" livrés avec chaque version de perl.

Il offre plusieurs mécanismes pour interroger ces informations.

Une API fonctionnelle est disponible pour que les programmeurs puissent interroger les informations.

Les programmeurs peuvent également interroger la structure de hachage contenue pour trouver des informations pertinentes.

FONCTIONS API

Ce sont les fonctions disponibles, elles peuvent être appelées comme des fonctions ou des méthodes de classe :

Module::CoreList::Utils::first_release('corelist'); # comme fonction
Module::CoreList::Utils->first_release('corelist'); # méthode de classe
"utilities"
Requiert une version de perl comme argument, retourne une liste d'utilitaires qui ont été livrés avec cette version de perl, ou undef/liste vide si cette version de perl n'existe pas.
first_release( UTILITAIRE )
Requiert le nom d'un UTILITAIRE comme argument, retourne la version de perl lorsque cet utilitaire est apparu pour la première fois dans le cœur de perl, ordonné par le numéro de version de perl, ou undef ( en contexte scalaire ) ou une liste vide ( en contexte liste ) si cet utilitaire n'est pas dans le cœur.
first_release_by_date( UTILITAIRE )
Requiert le nom d'un UTILITAIRE comme argument, retourne la version de perl lorsque cet utilitaire est apparu pour la première fois dans le cœur de perl, ordonné par la date de sortie, ou undef ( en contexte scalaire ) ou une liste vide ( en contexte liste ) si cet utilitaire n'est pas dans le cœur.
removed_from( UTILITAIRE )
Prend le nom d'un UTILITAIRE comme argument, retourne la première version de perl où cet utilitaire a été retiré du cœur. Retourne undef si l'utilitaire donné n'a jamais été dans le cœur ou est toujours dans le cœur.
removed_from_by_date( UTILITAIRE )
Prend le nom d'un UTILITAIRE comme argument, retourne la première version de perl par date de sortie où cet utilitaire a été retiré du cœur. Retourne undef si l'utilitaire donné n'a jamais été dans le cœur ou est toujours dans le cœur.

STRUCTURES DE DONNEES

Ce sont les structures de hachage disponibles :

%Module::CoreList::Utils::utilities
Une hachure de hachures indexée sur la version de perl telle qu'indiquée dans $]. La hachure de second niveau est une paire utilitaire / définie.
