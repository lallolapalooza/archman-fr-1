Moo::Role(3) Documentation Perl fournie par l'utilisateur Moo::Role(3)

NOM

Moo::Role - Support minimal d'orientation objet pour les Rôles

SYNTAXE

package My::Role;
use Moo::Role;
use strictures 2;
sub foo { ... }
sub bar { ... }
has baz => (
  is => 'ro',
);
1;

Et ailleurs :

package Some::Class;
use Moo;
use strictures 2;
# bar est importé, mais pas foo
with 'My::Role';
sub foo { ... }
1;

DESCRIPTION

"Moo::Role" s'appuie sur Role::Tiny, consultez donc cette documentation pour la plupart des informations sur son fonctionnement (en particulier, l'utilisation de "Moo::Role" active également `strict` et `warnings`). Le principal ajout ici est une fonctionnalité supplémentaire pour rendre les rôles plus « Moosey » ; c'est-à-dire qu'il ajoute la méthode "has".

SOUS-ROUTINES IMPORTEES

Voir « SOUS-ROUTINES IMPORTEES » dans Role::Tiny pour toutes les autres sous-routines importées par ce module.

has

has attr => (
  is => 'ro',
);

Déclare un attribut pour la classe à composer. Voir "has" dans Moo pour toutes les options.

NETTOYAGE DES IMPORTATIONS

Moo::Role nettoie automatiquement ses propres méthodes importées et toutes les importations déclarées avant l'instruction "use Moo::Role". Tout ce qui est importé après "use Moo::Role" sera composé dans les packages consommateurs. Un package qui consomme ce rôle :

package My::Role::ID;
use Digest::MD5 qw(md5_hex);
use Moo::Role;
use Digest::SHA qw(sha1_hex);
requires 'name';
sub as_md5  { my ($self) = @_; return md5_hex($self->name);  }
sub as_sha1 { my ($self) = @_; return sha1_hex($self->name); }
1;

…disposera désormais d'une méthode "$self->sha1_hex()" disponible, qui ne fera probablement pas ce que vous attendez. En revanche, un appel à "$self->md5_hex()" provoquera une erreur avec le message utile : "Can't locate object method "md5_hex"".

Voir « NETTOYAGE DES IMPORTATIONS » dans Moo pour plus de détails.
