NOM

Mouse::Object - L'objet de base pour les classes Mouse

VERSION

Ce document décrit la version v2.6.0 de Mouse

MÉTHODES

"$class->new(%args | \%args) -> Objet"

Instancie un nouvel objet "Mouse::Object". Ceci est évidemment destiné aux sous-classes.

"$class->BUILDARGS(@args) -> HashRef"

Permet de remplacer les arguments que "new" prend. Il doit retourner un HashRef de paramètres.

"$object->BUILDALL(\%args)"

Appelle "BUILD" sur chaque classe dans la hiérarchie des classes. Ceci est appelé à la fin de "new".

"$object->BUILD(\%args)"

Vous pouvez placer toute logique d'initialisation métier dans les méthodes BUILD. Vous n'avez pas besoin de redispatcher ou de retourner une valeur spécifique.

"$object->DEMOLISHALL"

Appelle "DEMOLISH" sur chaque classe dans la hiérarchie des classes. Ceci est appelé au moment de la "DESTROY".

"$object->DEMOLISH"

Vous pouvez placer toute logique de désinitialisation métier dans les méthodes DEMOLISH. Vous n'avez pas besoin de redispatcher ou de retourner une valeur spécifique.

"$object->does($nom_role) -> Bool"

Ceci vérifie si la classe invocante fait un $nom_role donné. Ceci est similaire à "isa" pour les objets, mais vérifie les rôles à la place.

"$object->dump($profondeur_max) -> Str"

Ceci est une utilité pratique pour déverser un objet avec Data::Dumper. Par défaut, la profondeur maximale est de 3, pour éviter de faire des dégâts.

"$object->meta() -> MetaClass"

Ceci est une méthode qui fournit l'accès à la métaclasse de l'objet.
