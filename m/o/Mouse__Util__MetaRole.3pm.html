NOM

Mouse::Util::MetaRole - Appliquer des rôles à n'importe quelle classe méta, ainsi qu'à la classe de base des objets

SYNOPIS

package MyApp::Mouse;
use Mouse ();
use Mouse::Exporter;
use Mouse::Util::MetaRole;
use MyApp::Role::Meta::Class;
use MyApp::Role::Meta::Method::Constructor;
use MyApp::Role::Object;
Mouse::Exporter->setup_import_methods( also => 'Mouse' );
sub init_meta {
    shift;
    my %args = @_;
    Mouse->init_meta(%args);
    Mouse::Util::MetaRole::apply_metaroles(
        for             => $args{for_class},
        class_metaroles => {
            class       => ['MyApp::Role::Meta::Class'],
            constructor => ['MyApp::Role::Meta::Method::Constructor'],
        },
    );
    Mouse::Util::MetaRole::apply_base_class_roles(
        for   => $args{for_class},
        roles => ['MyApp::Role::Object'],
    );
    return $args{for_class}->meta();
}

DESCRIPTION

Ce module utilitaire est conçu pour aider les auteurs d'extensions Mouse à écrire des extensions qui peuvent coopérer avec d'autres extensions Mouse. Pour ce faire, vous devez écrire vos extensions sous forme de rôles, qui peuvent ensuite être appliqués dynamiquement aux classes méta de l'appelant.

Ce module garantit la préservation des superclasses et des rôles existants déjà définis pour les objets méta, ce qui signifie qu'un nombre quelconque d'extensions peuvent appliquer des rôles dans n'importe quel ordre.

UTILISATION

Il est très important de n'appeler les fonctions de ce module que lorsque votre module est importé par l'appelant. Le processus d'application de rôles à la classe méta réinitialise l'objet de la classe méta, ce qui efface tous les attributs déjà définis. Cependant, tant que vous faites cela lorsque votre module est importé, l'appelant n'aura pas encore d'attributs définis.

La manière la plus simple de s'en assurer est d'utiliser Mouse::Exporter, qui peut générer la méthode "init_meta" appropriée pour vous, et s'assurer qu'elle est appelée lors de l'importation.

FONCTIONS

Ce module fournit deux fonctions.

apply_metaroles( ... )

Cette fonction appliquera des rôles à une ou plusieurs classes méta pour la classe spécifiée. Elle accepte les paramètres suivants :

  • for => $name

    Ceci spécifie la classe ou pour laquelle modifier les classes méta. Il peut s'agir d'un nom de package ou d'un objet méta approprié (une classe Mouse::Meta::Class ou Mouse::Meta::Role).

  • class_metaroles => \%roles

    Ceci est une référence de hachage spécifiant quels rôles méta seront appliqués à la classe méta de la classe et à ses classes méta et classes auxiliaires contenues.

    Chaque clé doit à son tour pointer vers une référence de tableau de noms de rôles.

    Elle accepte les clés suivantes :

class
attribute
method
constructor
destructor
•
role_metaroles => \%roles

Ceci est une référence de hachage spécifiant quels rôles méta seront appliqués à la classe méta du rôle et à ses classes méta et classes auxiliaires contenues.

Elle accepte les clés suivantes :

role
method

apply_base_class_roles( for => $class, roles => \@roles )

Cette fonction appliquera les rôles spécifiés à la classe de base de l'objet.
