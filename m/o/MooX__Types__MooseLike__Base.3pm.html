NAME

MooX::Types::MooseLike::Base - Une collection de types Moose-like de base pour Moo

SYNOPSIS

package MyPackage;
use Moo;
use MooX::Types::MooseLike::Base qw(:all);
has "beers_by_day_of_week" => (
    isa => HashRef
);
has "current_BAC" => (
    isa => Num
);
# Ils supportent aussi is_$type. Par exemple, on peut l'utiliser comme suit
has 'legal_age' => (
    is => 'ro',
    isa => sub { die "$_[0] n'est pas légal"
                 unless (is_Int($_[0]) && $_[0] > 17) },
);

DESCRIPTION

Les attributs Moose (comme Moose) ont une propriété 'isa'. Ce module fournit quelques types de base pour cette propriété. Vous pouvez importer tous les types avec la balise ':all' ou importer une liste de types comme suit :

use MooX::Types::MooseLike::Base qw/HashRef ArrayRef/;

vous pouvez alors déclarer certains attributs comme suit :

has 'contact' => (
  is => 'ro',
  isa => HashRef,
);
has 'guest_list' => (
  is => 'ro',
  isa => ArrayRef[HashRef],
);

Ces types fournissent un contrôle tel que l'attribut contact est une référence de tableau ("array"), et que la guest_list est une référence de tableau de hachages ("array of hash").

TYPES PARAMÉTRÉS

Paramétrage des types avec un seul type

Les types suivants peuvent être paramétrés avec d'autres types.

ArrayRef

Par exemple, ArrayRef[HashRef]

HashRef

ScalarRef

Maybe

Par exemple, Maybe[Int] serait un entier ou undef

Paramétrage des types avec plusieurs types

AnyOf

Vérifie si l'attribut est l'un des types listés (c'est-à-dire, union). Prend une liste de types comme argument.

isa => AnyOf[Int, ArrayRef[Int], HashRef[Int]]

Note : AnyOf reçoit un ArrayRef[CodeRef]

AllOf

Vérifie si l'attribut correspond à tous les types listés (c'est-à-dire, intersection). Prend une liste de types comme argument. Par exemple :

isa => AllOf[
  InstanceOf['Human'],
  ConsumerOf['Air'],
  HasMethods['breath', 'dance']
],

Paramétrage des types avec des chaînes (multiples)

De plus, nous avons des types paramétrés qui acceptent des arguments de chaînes.

InstanceOf

Vérifie si l'attribut est une instance d'un objet d'une ou plusieurs classes. Utilise "blessed" et "isa" pour ce faire. Prend une liste de noms de classe comme argument. Par exemple :

isa => InstanceOf['MyClass','MyOtherClass']

Note : InstanceOf reçoit un ArrayRef[Str]

ConsumerOf

Vérifie si l'attribut est un objet et utilise un ou plusieurs rôles. Utilise "blessed" et "does" pour ce faire. Prend une liste de noms de rôles comme arguments. Par exemple :

isa => ConsumerOf['My::Role', 'My::AnotherRole']

HasMethods

Vérifie si l'attribut est un objet et possède une ou plusieurs méthodes. Utilise "blessed" et "can" pour ce faire. Prend une liste de noms de méthodes comme arguments. Par exemple :

isa => HasMethods[qw/postulate contemplate liberate/]

Enum

Vérifie si l'attribut est l'une des valeurs énumérées. Prend une liste de valeurs possibles comme argument. Par exemple :

isa => Enum['rock', 'spock', 'paper', 'lizard', 'scissors']
