Module::CoreList(3perl) Manuel des développeurs Perl Module::CoreList(3perl)

NOM

Module::CoreList - quels modules ont été inclus avec chaque version de Perl

SYNOPSIS

use Module::CoreList;
print $Module::CoreList::version{5.00503}{CPAN}; # imprime 1.48
print Module::CoreList->first_release('File::Spec');
# imprime 5.00405
print Module::CoreList->first_release_by_date('File::Spec');
# imprime 5.005
print Module::CoreList->first_release('File::Spec', 0.82);
# imprime 5.006001
if (Module::CoreList::is_core('File::Spec')) {
  print "File::Spec est un module core\n";
}
print join ', ', Module::CoreList->find_modules(qr/Data/);
   # imprime 'Data::Dumper'
print join ', ',
         Module::CoreList->find_modules(qr/test::h.*::.*s/i, 5.008008);
   # imprime 'Test::Harness::Assert, Test::Harness::Straps'
print join ", ", @{ $Module::CoreList::families{5.005} };
   # imprime "5.005, 5.00503, 5.00504"

DESCRIPTION

Module::CoreList fournit des informations sur les modules core et les modules à double vie inclus dans chaque version de Perl.

Il offre plusieurs mécanismes pour interroger ces informations.

Il existe un utilitaire nommé corelist fourni avec ce module qui est une méthode pratique pour interroger depuis la ligne de commande.

Une API fonctionnelle est également disponible pour les programmeurs qui souhaitent interroger les informations.

Les programmeurs peuvent également interroger les structures de données contenues pour trouver des informations pertinentes.

FONCTIONS API

Ce sont les fonctions disponibles, elles peuvent être appelées comme des fonctions ou comme des méthodes de classe :

Module::CoreList::first_release('File::Spec'); # comme fonction
Module::CoreList->first_release('File::Spec'); # comme méthode de classe
first_release( MODULE )
Comportement à partir de la version 2.11

Nécessite un nom de module comme argument, retourne la version de Perl à laquelle ce module a été inclus dans le core, triée par numéro de version de Perl, ou indéfini (en contexte scalaire) ou une liste vide (en contexte de liste) si ce module n'est pas dans le core.

first_release_by_date( MODULE )
Nécessite un nom de module comme argument, retourne la version de Perl à laquelle ce module a été inclus dans le core, triée par date de sortie, ou indéfini (en contexte scalaire) ou une liste vide (en contexte de liste) si ce module n'est pas dans le core.
"find_modules( REGEX, [ LISTE_DE_PERLS ] )"
Reçoit une expression régulière comme argument, retourne une liste de modules qui correspondent à l'expression régulière donnée. Si seule une expression régulière est fournie, elle s'applique à tous les modules de toutes les versions de Perl. Vous pouvez éventuellement fournir une liste de versions de Perl pour limiter la recherche de l'expression régulière.
find_version( VERSION_PERL )
Reçoit une version de Perl comme argument. Une fois terminée avec succès, retourne une référence à un hash. Chaque élément de ce hash a une clé qui est le nom d'un module (p. ex., 'File::Path') qui était inclus avec cette version de Perl et une valeur qui est la version numérique (p. ex., '2.09') du module qui était inclus avec cette version de Perl. Retourne "undef" en cas d'erreur.
"is_core( MODULE, [ VERSION_MODULE, [ VERSION_PERL ] ] )"
Disponible à partir de la version 2.99.

Retourne vrai si le module MODULE a été inclus dans la version spécifique de Perl spécifiée. Vous pouvez éventuellement spécifier une version minimale du module et vous pouvez également spécifier une version de Perl. Si aucune version de Perl n'est spécifiée, is_core() utilisera la version numérique de Perl en cours d'exécution (c'est-à-dire $]).

Si vous souhaitez spécifier la version de Perl, mais que vous n'importez pas la version du module, passez "undef" pour la version du module :

"is_deprecated( MODULE, VERSION_PERL )"
Disponible à partir de la version 2.22.

Retourne vrai si le module MODULE est marqué comme obsolète dans la version spécifiée de Perl. Si VERSION_PERL n'est pas spécifiée, la version actuelle de Perl est utilisée.

deprecated_in( MODULE )
Disponible à partir de la version 2.77.

Retourne la première version de Perl dans laquelle le module MODULE a été marqué comme obsolète. Retourne "undef" si le module n'a pas été marqué comme obsolète.

removed_from( MODULE )
Disponible à partir de la version 2.32.

Prend un nom de module comme argument, retourne la première version de Perl dans laquelle ce module a été retiré du core. Retourne undef si le module donné n'a jamais été dans le core ou est toujours dans le core.

removed_from_by_date( MODULE )
Disponible à partir de la version 2.32.

Prend un nom de module comme argument, retourne la première version de Perl par date de sortie dans laquelle ce module a été retiré du core. Retourne undef si le module donné n'a jamais été dans le core ou est toujours dans le core.

"changes_between( VERSION_PERL, VERSION_PERL )"
Disponible à partir de la version 2.66.

Étant donné deux versions de Perl, retourne une liste de paires décrivant les changements dans le contenu des modules core entre elles. La liste est formatée pour être stockée dans un hash. Les clés sont les noms de bibliothèques et les valeurs sont des références à des hashes. Chaque hash a une entrée pour l'un ou les deux de "left" et "right", qui donnent les versions de la bibliothèque dans chaque distribution Perl de gauche et de droite.

Par exemple, cela pourrait retourner ces données (entre autres) pour la différence entre 5.008000 et 5.008001 :

'Pod::ParseLink'  => { left => '1.05', right => '1.06' },
'Pod::ParseUtils' => { left => '0.22', right => '0.3'  },
'Pod::Perldoc'    => {                 right => '3.10' },
'Pod::Perldoc::BaseTo' => {            right => undef  },

Ceci montre que deux bibliothèques sont mises à jour et deux sont ajoutées, l'une desquelles a une version indéfinie dans la version de droite.

STRUCTURES DE DONNÉES

Ce sont les structures de données hash disponibles :

%Module::CoreList::version
Un hash de hashes qui est clé par la version de Perl indiquée dans $]. Le second niveau du hash contient des paires module => version.

Note : la version d'un module peut être indéfinie, auquel cas la valeur est "undef", vous devez donc utiliser "exists $version{$foo}{$bar}" si vous testez cela.

Depuis la version 2.10, le module spécial "Unicode" fait référence à la version du jeu de caractères Unicode groupé avec Perl.

%Module::CoreList::delta
Disponible à partir de la version 3.00.

C'est un hash de hashes qui est clé par la version de Perl. Chaque hash clé aura les clés suivantes :

delta_from - une version de Perl antérieure sur laquelle les modifications sont basées
changed    - un hash de modules/versions qui ont changé
removed    - un hash de modules qui ont été retirés
%Module::CoreList::released
Clé par version de Perl, contient les dates de sortie en format ISO, obtenues de perlhist.
%Module::CoreList::families
Nouveau, en 1.96, un hash qui regroupe les versions de Perl connues par leurs numéros de version principaux.
%Module::CoreList::deprecated
Un hash de hashes clé par version de Perl et nom de module. Si un module est défini, il indique que le module est obsolète dans cette version de Perl et qu'il est prévu de le supprimer du core dans le futur.
%Module::CoreList::upstream
Un hash contenant des informations sur la destination des correctifs pour chaque module core.

UPSTREAM indique où les correctifs doivent aller. "undef" signifie que cela n'a pas été discuté pour le module en question. "blead" signifie que la copie du module dans les sources de blead doit être considérée comme canonique, "cpan" signifie que le module sur CPAN doit être corrigé en premier. "first-come" signifie que blead peut être corrigé librement.

CAVEATS

Module::CoreList couvre actuellement les versions 5.000, 5.001, 5.002, 5.003_07, 5.004, 5.004_05, 5.005, 5.005_03, 5.005_04 et 5.7.3 de perl.

Toutes les versions stables de perl depuis 5.6.0 sont couvertes.

Toutes les versions de développement de perl depuis 5.9.0 sont couvertes.
