NOM

Mouse::Util::TypeConstraints - Système de contraintes de type pour Mouse

VERSION

Ce document décrit la version de Mouse v2.6.0

SYNOPSIS

use Mouse::Util::TypeConstraints;
subtype 'Natural'
    => as 'Int'
    => where { $_ > 0 };
subtype 'NaturalLessThanTen'
    => as 'Natural'
    => where { $_ < 10 }
    => message { "Ce nombre ($_) n'est pas inférieur à dix !" };
coerce 'Num'
    => from 'Str'
      => via { 0+$_ };
enum 'RGBColors' => qw(red green blue);
no Mouse::Util::TypeConstraints;

DESCRIPTION

Ce module donne à Mouse la capacité de créer des contraintes de type personnalisées à utiliser dans la définition d'attributs. Cela simplifie la validation des paramètres et rend votre code plus facile à lire, car vous pouvez vous référer aux contraintes par leur nom.

Avertissement Important

Ce n'est pas un système de types pour Perl 5. Ce sont des contraintes de type, et elles ne sont pas utilisées par Mouse, sauf si vous le lui indiquez. Aucune inférence de type n'est effectuée, les expressions ne sont pas typées, etc., etc., etc.

Une contrainte de type est essentiellement une petite fonction "vérifie si une valeur est valide". Une contrainte peut être attachée à un attribut.

Avertissement Légèrement Moins Important

Il est toujours conseillé de citer vos noms de types.

Cela empêche Perl d'essayer d'exécuter l'appel comme un appel d'objet indirect. Cela peut être un problème lorsque vous avez un sous-type portant le même nom qu'une classe valide.

Par exemple :

subtype DateTime => as Object => where { $_->isa('DateTime') };

fonctionne *très bien*, tandis que ceci :

use DateTime;
subtype DateTime => as Object => where { $_->isa('DateTime') };

cause des problèmes silencieux et beaucoup de problèmes. La solution simple, ainsi que la sécurité future de vos sous-types de classes qui n'ont pas encore été créées, est de citer le nom du type :

use DateTime;
subtype 'DateTime' => as 'Object' => where { $_->isa('DateTime') };

Contraintes de Type par Défaut

Ce module fournit également une hiérarchie simple pour les types Perl 5, représentée visuellement ci-dessous.

Any

     Bool
     Maybe[`a]
     Undef
     Defined
         Value
             Str
                 Num
                     Int
                 ClassName
                 RoleName
         Ref
             ScalarRef
             ArrayRef[`a]
             HashRef[`a]
             CodeRef
             RegexpRef
             GlobRef
                 FileHandle

NOTE : Tout type suivi d'un paramètre de type "[`a]" peut être paramétré, ce qui signifie que vous pouvez dire :

ArrayRef[Int]    # un tableau d'entiers
HashRef[CodeRef] # une table de hachage de chaînes vers des références de code
Maybe[Str]       # la valeur peut être une chaîne ou indéfinie

Si Mouse rencontre un nom entre parenthèses qu'il ne reconnaît pas comme un type existant, il suppose qu'il s'agit d'un nom de classe, par exemple "ArrayRef[DateTime]".

NOTE : La contrainte de type "Undef" fonctionne correctement en général, mais des cas limites peuvent encore exister, veuillez l'utiliser avec parcimonie.

NOTE : La contrainte de type "ClassName" effectue une vérification complexe de l'existence d'un paquet. Cela signifie que votre classe **doit** être chargée pour que cette contrainte de type fonctionne.

NOTE : La contrainte de type "RoleName" vérifie qu'une chaîne est un *nom de paquet* qui est un rôle, tel que 'MyApp::Role::Comparable'. La contrainte de type "Role" vérifie qu'un *objet* se conforme au rôle spécifié.

Nommage des Contraintes de Type

Les noms de types déclarés via ce module ne peuvent contenir que des caractères alphanumériques, des points (.) et des points-virgules (;).

Étant donné que les types créés par ce module sont globaux, il est suggéré de nommer vos types de manière similaire à la façon dont vous nommez vos modules. Ainsi, au lieu de créer un type *Color* pour votre module My::Graphics, vous appelleriez le type My::Graphics::Types::Color.

Utilisation avec d'autres Modules de Contraintes

Ce module peut bien fonctionner avec d'autres modules de contraintes avec quelques ajustements. La clause "where" dans les types attend une référence "CODE" qui vérifie le premier argument et renvoie un booléen. Comme la plupart des modules de contraintes fonctionnent de manière similaire, il devrait être simple de les adapter pour qu'ils fonctionnent avec Mouse.

Par exemple, voici comment vous pourriez l'utiliser avec Declare::Constraints::Simple pour déclarer un type entièrement nouveau.

type 'HashOfArrayOfObjects',
    {
    where => IsHashRef(
        -keys   => HasLength,
        -values => IsArrayRef(IsObject)
    )
};

Voici un exemple d'utilisation de Test::Deep et de sa fonction "eq_deeply" non liée aux tests.

type 'ArrayOfHashOfBarsAndRandomNumbers'
    => where {
        eq_deeply($_,
            array_each(subhashof({
                bar           => isa('Bar'),
                random_number => ignore()
            })))
      };
