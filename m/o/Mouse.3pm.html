NOM

Mouse - Moose sans les antilopes

VERSION

Ce document décrit la version de Mouse v2.6.0

SYNOPSIS

package Point;
use Mouse; # active automatiquement strict et warnings
has 'x' => (is => 'rw', isa => 'Int');
has 'y' => (is => 'rw', isa => 'Int');
sub clear {
    my($self) = @_;
    $self->x(0);
    $self->y(0);
}
__PACKAGE__->meta->make_immutable();
package Point3D;
use Mouse;
extends 'Point';
has 'z' => (is => 'rw', isa => 'Int');
after 'clear' => sub {
    my($self) = @_;
    $self->z(0);
};
__PACKAGE__->meta->make_immutable();

DESCRIPTION

Moose est un système d'objets postmoderne pour Perl5. Moose est incroyable.

Cependant, Moose a un coût de compilation. Bien que des progrès considérables aient été réalisés au fil des ans, le coût de compilation est rédhibitoire pour certaines applications très spécifiques. Si vous écrivez une application en ligne de commande ou un script CGI où le temps d'initialisation est essentiel, vous ne pourrez peut-être pas utiliser Moose (nous vous recommandons d'utiliser des environnements d'exécution Perl persistants tels que FastCGI pour ces derniers, si possible).

Mouse est un système d'objets compatible avec Moose, qui cherche à atténuer ce coût en fournissant une partie des fonctionnalités de Moose.

Nous essayons également d'avoir le moins de dépendances possible. Mouse a actuellement aucune dépendance à l'exception des modules de construction et de test. Mouse fonctionne également sans XS, bien qu'il dispose d'un backend XS pour le rendre plus rapide.

Compatibilité avec Moose

La compatibilité avec Moose a été la préoccupation majeure. L'interface douce est hautement compatible avec Moose. Même les messages d'erreur sont tirés de Moose. Le code de Mouse exécute sa suite de tests seulement 4 fois plus rapidement.

L'idée est que si vous avez besoin du pouvoir supplémentaire, vous devriez être capable d'exécuter "s/Mouse/Moose/g" dans votre code et que rien ne casse. À cette fin, nous avons écrit Any::Moose qui agira comme Mouse, à moins que Moose ne soit chargé, auquel cas il agira comme Moose. Étant donné que Mouse est un peu plus permissif que Moose, s'il y a des erreurs inhabituelles, il serait utile d'exécuter:

ANY_MOOSE=Moose perl your-script.pl

pour voir si l'erreur est causée par Mouse. Les diagnostics et validations de Moose sont également meilleurs.

Voir aussi Mouse::Spec pour la compatibilité et l'incompatibilité avec Moose.

Extensions de Mouse

Ne copiez pas le code de MooseX vers MouseX. Si vous avez besoin d'extensions, vous devriez passer à Moose. Nous n'avons pas besoin de deux ensembles d'extensions parallèles !

Si vous devez absolument écrire une extension de Mouse, veuillez contacter la liste de diffusion de Moose ou #moose sur IRC au préalable.

MOTS-CLÉS

"$object->meta -> Mouse::Meta::Class"

Retourne le constructeur de métaclasse de cette classe.

"extends superclasses"

Définit les superclasses de cette classe.

"before (method|methods|regexp) => CodeRef"

Installe un modificateur de méthode "before". Voir "before" dans Moose.

"after (method|methods|regexp) => CodeRef"

Installe un modificateur de méthode "after". Voir "after" dans Moose.

"around (method|methods|regexp) => CodeRef"

Installe un modificateur de méthode "around". Voir "around" dans Moose.

"has (name|names) => parameters"

Ajoute une propriété (ou si un tableau de noms est passé, plusieurs propriétés) à cette classe. Options:

"is => ro|rw|bare"
L'option is accepte soit rw (pour lecture/écriture), ro (pour lecture seule) ou bare (sans rien). Ceux-ci créeront un accesseur lecteur/écrivain ou un accesseur en lecture seule, en utilisant le même nom que le $name de la propriété.

Si vous voulez avoir plus de contrôle sur la façon dont vos accesseurs sont nommés, vous pouvez utiliser les options "reader", "writer" et "accessor", mais si vous utilisez celles-ci, vous n'avez pas besoin de l'option is.

"isa => TypeName | ClassName"
Fournit une validation de type dans le constructeur et l'accesseur. Les types suivants sont pris en charge. Tout type inconnu est considéré comme un contrôle de classe (par exemple, "isa => 'DateTime'" n'accepte que les objets DateTime). 
Any Item Bool Undef Defined Value Num Int Str ClassName
Ref ScalarRef ArrayRef HashRef CodeRef RegexpRef GlobRef
FileHandle Object

Pour plus d'informations sur les contraintes de type, voir Mouse::Util::TypeConstraints.

"does => RoleName"
Accepte le nom d'un rôle que la valeur stockée dans cette propriété est censée avoir consommé.
"coerce => Bool"
Tente d'utiliser la coercition avec la contrainte de type fournie pour changer la valeur passée à tout accesseur ou constructeur. Vous devez spécifier une contrainte de type pour que cela fonctionne. Voir Moose::Cookbook::Basics::Recipe5 pour un exemple.
"required => Bool"
Une valeur est-elle requise pour cette propriété? Si la propriété est paresseuse ou a un constructeur, alors fournir une valeur pour la propriété dans le constructeur est optionnel.
"init_arg => Str | Undef"
Permet d'utiliser un nom de clé différent dans le constructeur. S'il est undef, la propriété ne peut pas être passée au constructeur.
"default => Value | CodeRef"
Définit la valeur par défaut de la propriété. Si la valeur par défaut est une référence de code, elle sera invoquée pour obtenir la valeur par défaut. En raison des bizarreries de Perl, toute référence nue est interdite, vous devez envelopper la référence dans une référence de code. Sinon, toutes les instances partageront la même référence.
"lazy => Bool"
Si spécifié, la valeur par défaut est calculée à la demande plutôt qu'au moment de la construction.
"predicate => Str"
Permet de spécifier un nom de méthode pour installer une méthode prédicat, qui vérifie si la propriété a une valeur. Elle n'invoque pas une valeur par défaut ou une méthode de constructeur.
"clearer => Str"
Permet d'installer une méthode pour effacer la valeur de la propriété de l'instance. Lors de la lecture suivante, la valeur par défaut ou la méthode de constructeur sera invoquée.
"handles => HashRef|ArrayRef|Regexp"
Permet de spécifier des méthodes à déléguer à la propriété. L'ArrayRef transmet les noms de méthodes donnés aux appels de méthode de la propriété. Le HashRef mappe les méthodes locales aux noms distants de la propriété. D'autres formes de "handles", comme RoleName et CodeRef, ne sont pas encore prises en charge.
"weak_ref => Bool"
Permet de référencer automatiquement de manière faible toute référence stockée dans la propriété.

L'utilisation de cette fonctionnalité nécessite Scalar::Util!

"trigger => CodeRef"
Chaque fois que la valeur de la propriété est définie (via l'accesseur ou le constructeur), le déclencheur est appelé. Le déclencheur reçoit comme arguments l'instance, la nouvelle valeur et éventuellement l'ancienne valeur si elle est différente de l'ancienne.

Mouse - New Perl Projects: Documentation

NAME

Mouse - Object-oriented programming system for Perl

VERSION

2.6.0

SYNOPSIS

In your class file:

  package My::Class;
  use Mouse;

  has 'foo' => (
      is       => 'rw',
      isa      => 'Str',
      required => 1,
  );

  has 'bar' => (
      is       => 'rw',
      isa      => 'Int',
      default  => 0,
  );

  sub BUILD {
      my ($self) = @_;
      # ...
  }

  sub BUILD__foo {
      my ($self) = @_;
      # ...
  }

  sub BUILD__bar {
      my ($self) = @_;
      # ...
  }

  1;

In another file:

  use My::Class;
  my $obj = My::Class->new( foo => 'hello' );
  $obj->foo('world');
  print $obj->foo; # world
  print $obj->bar; # 0

DESCRIPTION

Mouse is a powerful object-oriented programming system for Perl. It provides features that are common in other OO languages like Java and Python, but that are difficult to implement in Perl without a framework.

Mouse is heavily inspired by Moose, and aims to provide a simpler and more lightweight alternative.

KEYWORDS

Mouse provides the following keywords that you can use within your class definitions:

"has"
Declares an attribute.
"extends"
Declares a superclass.
"with"
Declares roles to be mixed in.
"inline"
Instructs Mouse to generate optimized code for your class.
"method"
Declares a method.
"around"
Declares an around modifier for a method.
"before"
Declares a before modifier for a method.
"after"
Declares an after modifier for a method.

has options

The has keyword accepts the following options:

"is => ('ro' | 'rw' | 'rr')"
Specifies the visibility of the attribute. "ro" is read-only, "rw" is read-write, and "rr" is required read-write (must be provided at creation).
"isa => TypeConstraint"
Specifies the type constraint for the attribute. This can be a scalar type (e.g., "Str", "Int") or a more complex type constraint from a module like Types::Standard.
"required => Bool"
If true, the attribute must be provided when the object is created. This is equivalent to "is => 'rr'".
"default => Value | \&CODE"
Specifies a default value for the attribute. If a code reference is provided, it will be called at object creation time to determine the default value. The code reference receives the object as its first argument.
"builder => Str"
Defines a method name to be called to provide the default value of the attribute. "builder => 'build_foo'" is mostly equivalent to "default => sub { $_[0]->build_foo }".
"auto_deref => Bool"
Allows you to automatically dereference ArrayRef and HashRef attributes in list context. In scalar context, the reference is returned (NOT the list length or bucket status). You must specify an appropriate type constraint to use auto_deref.
"lazy_build => Bool"
Automatically define the following options: 
has $attr => (
    # ...
    lazy      => 1
    builder   => "_build_$attr",
    clearer   => "clear_$attr",
    predicate => "has_$attr",
);

"confess(message) -> BOOM"

"confess" in Carp for your convenience.

"blessed(value) -> ClassName | undef"

"blessed" in Scalar::Util for your convenience.

MISC

import

Importing Mouse will default your class' superclass list to Mouse::Object. You may use "extends" to replace the superclass list.

unimport

Please unimport Mouse ("no Mouse") so that if someone calls one of the keywords (such as "extends") it will break loudly instead breaking subtly.

DEVELOPMENT

Here is the repo: https://github.com/xslate/p5-Mouse.

You can build, test, and release it with Minilla.

cpanm Minilla
minil build
minil test
minil release

Note that Build.PL and README.md are generated by Minilla, so you should not edit them. Edit minil.toml and lib/Mouse.pm instead.
