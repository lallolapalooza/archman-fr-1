NOM

MooX::Types::MooseLike - quelques types et un constructeur de type façon Moose

SYNOPSIS

package MyApp::Types;
use MooX::Types::MooseLike;
use base qw(Exporter);
our @EXPORT_OK = ();
# Définir quelques types
my $defs = [{
  name => 'MonType',
  test => sub { predicate($_[0]) },
  message => sub { "$_[0] n'est pas le type souhaité !" }
},
{
  name => 'VarChar',
  test => sub {
    my ($value, $param) = @_;
    length($value) <= $param;
  },
  message => sub { "$_[0] est trop long ! Il devrait être inférieur ou égal à $_[1]." }
}];
# Rendre les types disponibles - cela les ajoute automatiquement à @EXPORT_OK.
MooX::Types::MooseLike::register_types($defs, __PACKAGE__);
...
# Quelque part dans le code qui utilise le type
package MyApp::Foo;
use Moo;
use MyApp::Types qw(MonType VarChar);
has attribute => (
  is  => 'ro',
  isa => MonType,
);
has string => (
  is  => 'ro',
  isa => VarChar[25]
);

DESCRIPTION

Ce module offre la possibilité de créer votre propre ensemble de types façon Moose. Ces types personnalisés peuvent ensuite être utilisés pour décrire des champs dans des classes basées sur Moo.

Consultez MooX::Types::MooseLike::Base pour une liste des types de base disponibles. Sa source fournit également un exemple sur la façon de créer des types de base, paramétrables et non paramétrables.

FONCTIONS

register_types

register_types( types, package, moose_namespace )

Installe les types donnés dans le package. Cela rend les types automatiquement exportables en les ajoutant à @EXPORT_OK du package. Les types sont attendus sous la forme d'un tableau référencé où chaque type est du format suivant :

{
  name            => 'MonType',
  test            => sub { check_the_value_somehow($_[0]) },
  message         => sub { "$_[0] n'est pas le type souhaité !" },
  subtype_of      => 'TypeParent',           # Optionnel
  from            => 'Some::Parent::CoolTypes',  # Optionnel
  parameterizable => sub { ... },                # Optionnel
  inflate         => sub { ... },                # Optionnel
}

Un type peut être déclaré avec une référence (subtype_of) vers un type précédemment déclaré. Dans ce cas, le nouveau type héritera du comportement du type référencé.

Le type référencé peut provenir du même package ou d'un package tiers :

MooX::Types::MooseLike::register_types([{
  name       => 'GreaterThan10',
  subtype_of => 'Int',
  from       => 'MooX::Types::MooseLike::Base',
  test       => sub { $_[0] > 10 },
  message    => sub { 'pas supérieur à 10' },
}], __PACKAGE__);
MooX::Types::MooseLike::register_types([{
  name       => 'Between10And20',
  subtype_of => 'GreaterThan10',
  from       => __PACKAGE__,
  test       => sub { $_[0] < 20 },
  message    => sub { 'pas un entier entre 10 et 20' },
}], __PACKAGE__);
MooX::Types::MooseLike::register_types([{
  name       => 'Between10And30',
  subtype_of => GreaterThan10(),
  test       => sub { $_[0] < 30 },
  message    => sub { 'pas un entier entre 10 et 30' },
}], __PACKAGE__);

exception_message

exception_message( valeur, partie_de_la_chaine_exception )

Fonction d'aide à utiliser dans la définition d'un type :

{
  ...
  message => sub { return exception_message($_[0], 'un HashRef' },
  ...
}

En cas de non-concordance de la <valeur> avec les contraintes de type, cela produit le message :

"<valeur> n'est pas un HashRef !"

inflate_type

inflate_type( coderef )

Gonfle le type en un type Moose. Nécessite Moose.
