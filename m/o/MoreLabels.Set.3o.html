Module Set
: sig end

Ensembles sur des types ordonnés.

Ce module implémente la structure de données d'ensembles, étant donné une fonction de tri total sur les éléments de l'ensemble. Toutes les opérations sur les ensembles sont purement applicatives (sans effets de bord). L'implémentation utilise des arbres binaires équilibrés, et est donc raisonnablement efficace : l'insertion et la recherche d'appartenance prennent un temps logarithmique par rapport à la taille de l'ensemble, par exemple.

Le foncteur MoreLabels.Set.Make construit des implémentations pour tout type, étant donné une fonction compare . Par exemple :

       module IntPairs =
         struct
           type t = int * int
           let compare (x0,y0) (x1,y1) =
             match Stdlib.compare x0 x1 with
                 0 -> Stdlib.compare y0 y1
               | c -> c
         end
       module PairsSet = Set.Make(IntPairs)
       let m = PairsSet.(empty |> add (2,3) |> add (5,7) |> add (11,13))

Ceci crée un nouveau module PairsSet , avec un nouveau type PairsSet.t d'ensembles de int * int .
