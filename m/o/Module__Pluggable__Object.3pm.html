NOM

Module::Pluggable::Object - donne automatiquement à votre module la capacité d'avoir des plugins

SYNOPSIS

Utilisation simple de Module::Pluggable -

package MyClass;
use Module::Pluggable::Object;
my $finder = Module::Pluggable::Object->new(%opts);
print "Mes plugins sont : ".join(", ", $finder->plugins)."\n";

DESCRIPTION

Fournit un moyen simple mais, espérons-le, extensible d'avoir des 'plugins' pour votre module. Clairement, ce ne sera pas la solution ultime mais cela me convient.

Essentiellement, tout ce qu'il fait est d'exporter une méthode dans votre espace de noms qui parcourt un chemin de recherche pour les fichiers .pm et les transforme en noms de classes.

Optionnellement, il instancie ces classes pour vous.

Cet objet est encapsulé par "Module::Pluggable". Si vous voulez faire quelque chose d'inhabituel ou ajouter des fonctionnalités spéciales non générales, il est préférable de l'encapsuler et de produire votre propre sous-classe.
