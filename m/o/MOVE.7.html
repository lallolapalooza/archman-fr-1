Paquet: postgresql

Licences: PostgreSQL

MOVE(7) Documentation PostgreSQL 18.1 MOVE(7)

NOM

MOVE - positionner un curseur

SYNTAXE

MOVE [ direction ] [ FROM | IN ] nom_curseur
où direction peut être l'un des éléments suivants :
    NEXT
    PRIOR
    FIRST
    LAST
    ABSOLUTE compte
    RELATIVE compte
    compte
    ALL
    FORWARD
    FORWARD compte
    FORWARD ALL
    BACKWARD
    BACKWARD compte
    BACKWARD ALL

DESCRIPTION

MOVE repositionne un curseur sans récupérer de données. MOVE fonctionne exactement comme la commande FETCH, sauf qu'il ne fait que positionner le curseur et ne renvoie pas de lignes.

Les paramètres de la commande MOVE sont identiques à ceux de la commande FETCH ; consultez FETCH(7) pour plus de détails sur la syntaxe et l'utilisation.

SORTIES

En cas de succès, une commande MOVE renvoie une étiquette de commande de la forme

MOVE compte

Le compte est le nombre de lignes qu'une commande FETCH avec les mêmes paramètres aurait renvoyées (éventuellement zéro).

EXEMPLES

BEGIN WORK;
DECLARE liahona CURSOR FOR SELECT * FROM films;
-- Sauter les 5 premières lignes :
MOVE FORWARD 5 IN liahona;
MOVE 5
-- Récupérer la 6ème ligne du curseur liahona :
FETCH 1 FROM liahona;
 code  | title  | did | date_prod  |  kind  |  len
-------+--------+-----+------------+--------+-------
 P_303 | 48 Hrs | 103 | 1982-10-22 | Action | 01:37
(1 row)
-- Fermer le curseur liahona et terminer la transaction :
CLOSE liahona;
COMMIT WORK;

COMPATIBILITÉ

Il n'y a pas d'instruction MOVE dans la norme SQL.

VOIR AUSSI

CLOSE(7), DECLARE(7), FETCH(7)
