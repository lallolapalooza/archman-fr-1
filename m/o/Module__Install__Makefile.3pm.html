NOM

Module::Install::MakeMaker - Règles d'extension pour ExtUtils::MakeMaker

SYNTAXE

Dans votre Makefile.PL :

use inc::Module::Install;
WriteMakefile();

DESCRIPTION

Ce module est une enveloppe autour de ExtUtils::MakeMaker. Il exporte deux fonctions : "prompt" (un alias pour "ExtUtils::MakeMaker::prompt") et "WriteMakefile".

La fonction "WriteMakefile" transmettra les fonctions d'association clé/valeur à "ExtUtils::MakeMaker::WriteMakefile". Les paramètres requis "NAME" et "VERSION" (ou "VERSION_FROM") ne sont pas nécessaires s'ils peuvent être trouvés sans ambiguïté dans votre code.

OPTIONS DE CONFIGURATION

Ce module ajoute également certains paramètres de configuration qui lui sont propres :

NOM

Le paramètre NAME est requis par ExtUtils::MakeMaker. Si vous avez un seul module dans votre distribution, ou si le nom du module indiqué par le répertoire courant existe sous lib/, ce module utilisera le nom de paquet deviné comme valeur par défaut.

Si ce module ne trouve pas de valeur par défaut pour "NAME", il vous demandera de la spécifier manuellement.

VERSION

ExtUtils::MakeMaker requiert le paramètre "VERSION" ou "VERSION_FROM". Si ce module peut deviner la "VERSION" du paquet, il tentera de l'analyser à partir de celui-ci.

Si ce module ne trouve pas de valeur par défaut pour "VERSION", il vous demandera de la spécifier manuellement.

CIBLES DE FABRICATION

ExtUtils::MakeMaker vous fournit de nombreuses cibles "make" utiles. Une cible "make" est le mot que vous spécifiez après "make", comme "test" pour "make test". Certaines des cibles les plus utiles sont :

  • all

    C'est la cible par défaut. Lorsque vous tapez "make", cela équivaut à entrer "make all". Cette cible compile tout votre code et le place dans le répertoire "blib".

  • test

    Exécute la suite de tests de votre distribution.

  • install

    Copie le contenu du répertoire "blib" dans les répertoires appropriés de votre installation Perl.

  • dist

    Crée une archive de distribution, prête à être téléchargée sur CPAN ou partagée avec un ami.

  • clean distclean purge

    Supprime les fichiers créés par "perl Makefile.PL" et "make".

  • help

    Identique à la saisie de "perldoc ExtUtils::MakeMaker".

Ce module modifie le comportement de certaines de ces cibles, en fonction de vos exigences, et ajoute également les cibles suivantes à votre Makefile :

  • cpurge

    Identique à purge, sauf qu'elle supprime également les fichiers originellement ajoutés par ce module lui-même.

  • chelp

    Raccourci pour taper "perldoc Module::Install".

  • distsign

    Raccourci pour taper "cpansign -s", pour les utilisateurs de Module::Signature afin de signer la distribution avant sa publication.
