NOM

Mouse::Meta::TypeConstraint - Le métaclasse de contrainte de type Mouse

VERSION

Ce document décrit la version v2.6.0 de Mouse

DESCRIPTION

Cette classe représente une contrainte de type, incluant les contraintes de type intégrées, les contraintes de type union, les contraintes de type paramétrables/paramétrées, ainsi que les contraintes de type personnalisées.
