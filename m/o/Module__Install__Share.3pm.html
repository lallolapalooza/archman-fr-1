NOM

Module::Install::Share - Installe les fichiers non-code pour une utilisation au moment de l'exécution

SYNTAXE

# Place tout dans le répertoire ./share/ dans le chemin 'auto' de la distribution
install_share 'share';
# Identique à ci-dessus en utilisant le nom de répertoire par défaut
install_share;

DESCRIPTION

En plus des modules Perl et des applications binaires Perl, certaines distributions ont besoin d'installer des fichiers de données en lecture seule à un emplacement sur le système de fichiers pour être utilisés au moment de l'exécution.

Les schémas XML, les fichiers de données YAML et les bases de données SQLite sont des exemples du type de choses que les distributions pourraient typiquement avoir besoin de rendre disponibles après l'installation.

"Module::Install::Share" est une extension de Module::Install qui fournit des commandes pour permettre à ces fichiers d'être installés à l'emplacement applicable sur le disque.

Pour localiser les fichiers après l'installation afin qu'ils puissent être utilisés dans votre module, consultez le module compagnon de cette extension, File::ShareDir.

À FAIRE

Actuellement, "install_share" installe non seulement les fichiers que vous voulez, mais s'il est appelé par l'auteur, il copiera également les répertoires .svn et autres de contrôle de source, et d'autres saletés.

Améliorer cela pour copier uniquement les fichiers sous share qui sont dans le MANIFEST, ou éventuellement ceux qui ne sont pas dans MANIFEST.SKIP.
