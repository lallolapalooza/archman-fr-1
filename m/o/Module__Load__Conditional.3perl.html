Module::Load::Conditional(3perl) Guide de référence pour programmeurs Perl Module::Load::Conditional(3perl)

NOM

Module::Load::Conditional - Recherche d'informations sur les modules / chargement de modules à la volée

SYNOPSIS

use Module::Load::Conditional qw[can_load check_install requires];
my $use_list = {
        CPANPLUS        => 0.05,
        LWP             => 5.60,
        'Test::More'    => undef,
};
print can_load( modules => $use_list )
        ? 'tous les modules ont été chargés avec succès'
        : 'échec du chargement des modules requis';
my $rv = check_install( module => 'LWP', version => 5.60 )
            or print 'LWP n\'est pas installé !';
print 'LWP mis à jour' if $rv->{uptodate};
print "La version de LWP est $rv->{version}\n";
print "LWP est installé depuis le fichier $rv->{file}\n";
print "Les modules requis doivent être installés :\n";
print join "\n", requires('LWP');
### permet à M::L::C de regarder dans %INC, pas seulement de parcourir @INC
$Module::Load::Conditional::CHECK_INC_HASH = 1;
### réinitialise le cache de 'can_load'
undef $Module::Load::Conditional::CACHE;
### ne pas afficher d'avertissement de Module::Load::Conditional -- par défaut est '1'
$Module::Load::Conditional::VERBOSE = 0;
### La dernière erreur survenue lors d'un appel à 'can_load'
my $err = $Module::Load::Conditional::ERROR;

DESCRIPTION

Module::Load::Conditional offre des moyens simples de vérifier et, dans certains cas, de charger n'importe quel module installé sur votre système lors de l'exécution.

Il peut charger plusieurs modules en même temps ou aucun si l'un d'eux ne peut être chargé. Il gère également toute vérification d'erreur.

Méthodes

$href = check_install( module => NOM [, version => VERSION, verbose => BOULEEN ] );

check_install permet de vérifier si un module spécifique est installé ou non. Vous pouvez l'appeler avec les arguments suivants :

module
Nom du module que vous souhaitez vérifier -- c'est un paramètre obligatoire
version
La version que ce module nécessite -- facultatif
verbose
Devriez-vous être averti de ce qu'il fait ? -- par défaut est $Module::Load::Conditional::VERBOSE

Il retournera undef s'il n'a pas pu trouver où le module était installé, ou une référence vers un hash avec les clés suivantes s'il a pu trouver le fichier :

file
Chemin complet du fichier contenant le module
dir
Répertoire, ou plus précisément l'entrée @INC où le module a été chargé.
version
Le numéro de version du module installé - ce sera "undef" si le module n'a pas de numéro de version (ou s'il n'est pas analysable), ou si la variable $Module::Load::Conditional::FIND_VERSION est définie à vrai. (Voir la section "VARIABLES GLOBALES" pour plus de détails)
uptodate
Une valeur booléenne indiquant si le module trouvé est au moins de la version spécifiée. Si vous n'avez pas spécifié de version, uptodate sera vrai si le module a été trouvé. S'il n'y a pas de version analysable trouvée dans le module, ce sera aussi vrai, car "check_install" n'avait aucun moyen de vérifier clairement.

$bool = can_load( modules => { NOM => VERSION [,NOM => VERSION] }, [verbose => BOULEEN, nocache => BOULEEN, autoload => BOULEEN] )

can_load détermine s'il peut charger une liste de modules, éventuellement avec des versions. S'il peut tout charger, il le fera. Si un ou plusieurs ne peuvent pas être chargés, aucun ne sera chargé.

C'est particulièrement utile si vous avez plus d'une façon de résoudre un problème dans un programme, et que vous ne voulez continuer que si tous les modules peuvent être chargés, et ne pas les charger s'ils ne le peuvent pas.

Cette fonction utilise la fonction "load" ou la fonction "autoload_remote" de Module::Load comme base.

can_load prend les arguments suivants :

modules
Un hashref de paires module/version. La version indique la version minimale à charger. Si aucune version n'est fournie, on suppose que n'importe quelle version est suffisante.
verbose
Faut-il afficher des avertissements si un module ne peut pas être chargé ? La valeur par défaut est d'utiliser la valeur de $Module::Load::Conditional::VERBOSE.
nocache
can_load conserve ses résultats dans un cache, il ne chargera donc pas le même module deux fois, ni n'essaiera de charger un module qui a déjà échoué auparavant. Par défaut, can_load vérifie le cache, mais vous pouvez changer cela en spécifiant "nocache" à vrai.
autoload
Contrôle si les fonctions d'un module chargé doivent être importées dans le package de l'appelant. La valeur par défaut est de ne rien importer.

Voir la fonction "load" et la fonction "autoload_remote" de Module::Load pour plus de détails.

@list = requires( MODULE );

requires vous permet de savoir quels modules un module spécifique requiert. C'est particulièrement utile lorsque vous écrivez un module pour une publication publique et que vous listez ses dépendances.

requires ne prend qu'un seul argument : le nom d'un module. Il vérifie d'abord s'il peut charger ce module, et renvoie undef s'il ne peut pas. Sinon, il renvoie une liste de modules et de pragmas qui seraient chargés en son nom.

Note : La liste renvoyée par "require" provient de votre installation perl et de votre installation actuelle.

VARIABLES GLOBALES

Le comportement de Module::Load::Conditional peut être modifié en changeant les variables globales suivantes :

$Module::Load::Conditional::VERBOSE

Ceci contrôle si Module::Load::Conditional émettra des avertissements et des explications sur les raisons pour lesquelles certains éléments ont pu échouer. Si vous définissez ceci à 0, Module::Load::Conditional n'émettra aucun avertissement. La valeur par défaut est 0.

$Module::Load::Conditional::FIND_VERSION

Ceci contrôle si Module::Load::Conditional essaiera d'analyser (et d'évaluer) la version du module qu'il essaie de charger.

Si vous ne voulez pas faire cela, définissez cette variable à "faux". Alors, les comparaisons de version ne seront pas possibles, et Module::Load::Conditional ne pourra pas vous dire quelle version du module vous avez.

NOM

Module::Load::Conditional

SYNOPIS

use Module::Load::Conditional;

DESCRIPTION

Module::Load::Conditional est un module qui fournit le chargement conditionnel de modules Perl. Il vous permet de contrôler si certains modules sont chargés en fonction de conditions spécifiques.

Méthodes

Ce module fournit les méthodes suivantes :

  • can_load()

  • FORCE_SAFE_INC()

  • CHECK_INC_HASH()

  • CACHE()

  • ERROR()

  • DEPRECATED()

Variables Globales

Les variables suivantes sont utilisées dans Module::Load::Conditional :

  • $FIND_VERSION

  • $Module::Load::Conditional::CHECK_INC_HASH

  • $Module::Load::Conditional::FORCE_SAFE_INC

  • $Module::Load::Conditional::CACHE

  • $Module::Load::Conditional::ERROR

  • $Module::Load::Conditional::DEPRECATED

$Module::Load::Conditional::CHECK_INC_HASH

Ceci contrôle si Module::Load::Conditional vérifie son hash %INC pour voir si un module est disponible. Par défaut, seul @INC est scanné pour voir si un module est physiquement sur votre système de fichiers ou disponible via un crochet @INC. S'il est défini à true, toute entrée dans %INC est considérée comme fiable et renvoyée.

La valeur par défaut est 0 ;

$Module::Load::Conditional::FORCE_SAFE_INC

Ceci contrôle si Module::Load::Conditional nettoie @INC en supprimant le caractère ".". La valeur par défaut est 0, mais pourrait changer dans une future version.

$Module::Load::Conditional::CACHE

Ceci stocke le cache de la fonction can_load. Si vous souhaitez vider le cache actuel, vous pouvez définir cette variable à undef.

$Module::Load::Conditional::ERROR

Ceci stocke une chaîne du dernier erreur qui s'est produite lors d'un appel à can_load. Il est utile de l'inspecter lorsque can_load renvoie undef.

$Module::Load::Conditional::DEPRECATED

Ceci contrôle si Module::Load::Conditional vérifie si un module de cœur à double durée de vie a été obsolète. S'il est défini à true, check_install renvoie false à uptodate si un module à double durée de vie chargé depuis $Config{privlibexp} est trouvé.

La valeur par défaut est 0;
