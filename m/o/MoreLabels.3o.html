Module MoreLabels
: sig end

Bibliothèques étiquetées supplémentaires.

Ce méta-module fournit des versions étiquetées des modules MoreLabels.Hashtbl , MoreLabels.Map et MoreLabels.Set.

Ce module est destiné à être utilisé via open MoreLabels qui remplace MoreLabels.Hashtbl , MoreLabels.Map et MoreLabels.Set par leurs homologues étiquetés.

Par exemple:

     open MoreLabels
     Hashtbl.iter ~f:(fun ~key ~data -> g key data) table

module Hashtbl : sig end

module Map : sig end

module Set : sig end
