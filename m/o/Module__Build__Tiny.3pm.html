Module::Build::Tiny(3pm) Documentation Perl fournie par la communauté Module::Build::Tiny(3pm)

NOM

Module::Build::Tiny - Un remplaçant léger de Module::Build

VERSION

version 0.052

SYNOPSIS

use Module::Build::Tiny;
Build_PL();

DESCRIPTION

De nombreuses distributions Perl utilisent un fichier Build.PL au lieu d'un fichier Makefile.PL pour piloter la configuration, la construction, les tests et l'installation de la distribution. Traditionnellement, Build.PL utilise Module::Build comme système de construction sous-jacent. Ce module fournit un remplacement simple, léger et direct.

Alors que Module::Build compte plus de 6 700 lignes de code ; ce module en compte moins de 200, tout en prenant en charge les fonctionnalités nécessaires à la plupart des distributions.

Pris en charge

  • Distributions Perl pures
  • Construction de XS ou C
  • Fichiers de test récursifs
  • MYMETA
  • Génération de pages man
  • Code généré à partir de fichiers PL
  • Module sharedirs
  • Prérequis dynamiques

Non pris en charge

  • Génération de documentation HTML
  • Extension de Module::Build::Tiny

Structure du répertoire

Vos fichiers .pm, .xs et .pod doivent se trouver dans lib/. Tous les exécutables doivent se trouver dans script/. Les fichiers de test doivent se trouver dans t/. Les sharedirs de distribution doivent se trouver dans share/, les sharedirs de module se trouvent sous module-share (par exemple, module-share/Foo-Bar pour le module "Foo::Bar").

Les fichiers ".c" dans le répertoire src/ sont compilés avec le fichier .xs correspondant au nom de la distribution.

UTILISATION

Toutes ces commandes fonctionnent à peu près comme leurs équivalents Module::Build.

perl Build.PL

Build [ build ]

Build test

Build install

Cela prend en charge les options suivantes :

  • verbose
  • install_base
  • installdirs
  • prefix
  • install_path
  • destdir
  • uninst
  • config
  • pure-perl
  • create_packlist

AUTORAT

Ce module ne prend pas en charge la création d'auteur. Pour développer des modules en utilisant Module::Build::Tiny, l'utilisation de Dist::Zilla::Plugin::ModuleBuildTiny ou App::ModuleBuildTiny est recommandée.

FICHIER DE CONFIGURATION ET ENVIRONNEMENT

Les options peuvent être fournies dans la variable d'environnement "PERL_MB_OPT" de la même manière qu'avec Module::Build. Cela doit être fait pendant l'étape de configuration.

Incompatibilités

  • Analyse des arguments

    Module::Build a une manière très permissive de gérer les arguments. Module::Build::Tiny ne prend en charge qu'un sous-ensemble (raisonnable) de cela. En particulier, "./Build destdir=/foo" ne fonctionne pas, vous devrez le passer comme "./Build --destdir=/foo".

  • .modulebuildrc

    Module::Build::Tiny ne prend pas en charge les fichiers .modulebuildrc. En particulier, cela signifie que les versions de local::lib antérieures à 1.006008 peuvent échouer avec "ERROR: Can't create /usr/local/somepath". Si le résultat de "perl -Mlocal::lib" contient "MODULEBUILDRC" mais pas "PERL_MB_OPT ", vous devrez le mettre à jour pour résoudre ce problème.
