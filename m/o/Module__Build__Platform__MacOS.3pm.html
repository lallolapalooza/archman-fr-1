NOM

Module::Build::Platform::MacOS - Classe de construction pour les plateformes MacOS

DESCRIPTION

Le seul but de ce module est d'hériter de "Module::Build::Base" et de remplacer quelques méthodes. Veuillez consulter Module::Build pour la documentation.

Méthodes remplacées

new()
MacPerl ne définit pas $Config{sitelib} ni $Config{sitearch} pour une raison quelconque, mais $Config{installsitelib} et $Config{installsitearch} sont présents. Nous copions donc les variables d'installation vers l'autre emplacement.
make_executable()
Sur MacOS, nous définissons le type et le créateur de fichier sur MacPerl afin qu'il s'exécute par un double-clic.
dispatch()
Comme il n'y a pas de moyen facile de dire "./Build test" sur MacOS, si dispatch est appelé sans arguments et sans @ARGV, une boîte de dialogue apparaîtra pour demander quelle action effectuer et quels arguments supplémentaires.

L'action par défaut est "test".

ACTION_realclean()
Il faut déverrouiller le programme Build avant de le supprimer.
