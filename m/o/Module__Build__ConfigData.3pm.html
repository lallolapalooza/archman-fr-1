NOM

Module::Build::ConfigData - Configuration pour Module::Build

SYNOPSIS

use Module::Build::ConfigData;
$valeur = Module::Build::ConfigData->config('foo');
$valeur = Module::Build::ConfigData->feature('bar');
@noms = Module::Build::ConfigData->config_names;
@noms = Module::Build::ConfigData->feature_names;
Module::Build::ConfigData->set_config(foo => $nouvelle_valeur);
Module::Build::ConfigData->set_feature(bar => $nouvelle_valeur);
Module::Build::ConfigData->write;  # Sauvegarder les changements

DESCRIPTION

Ce module contient les données de configuration du module "Module::Build". Il fournit également une interface programmatique pour obtenir ou définir ces données de configuration. Notez que pour réellement apporter des modifications, vous devrez disposer des droits d'écriture sur le module "Module::Build::ConfigData", et vous devriez essayer de comprendre les répercussions de vos actions.

MÉTHODES

config($name)
Étant donné un argument de type chaîne de caractères, retourne la valeur de l'élément de configuration portant ce nom, ou "undef" si aucun élément de ce nom n'existe.
feature($name)
Étant donné un argument de type chaîne de caractères, retourne la valeur de la fonctionnalité portant ce nom, ou "undef" si aucune fonctionnalité de ce nom n'existe.
set_config($name, $valeur)
Définit l'élément de configuration portant le nom donné à la valeur donnée. La valeur peut être n'importe quel scalaire Perl qui se sérialisera correctement à l'aide de "Data::Dumper". Cela inclut les références, les objets (généralement) et les structures de données complexes. Cela n'inclut probablement pas les éléments transitoires comme les descripteurs de fichiers ou les sockets.
set_feature($name, $valeur)
Définit la fonctionnalité portant le nom donné à la valeur booléenne donnée. La valeur sera automatiquement convertie en 0 ou 1.
config_names()
Retourne une liste de tous les noms des éléments de configuration actuellement définis dans "Module::Build::ConfigData", ou dans un contexte scalaire, le nombre d'éléments.
feature_names()
Retourne une liste de tous les noms des fonctionnalités actuellement définies dans "Module::Build::ConfigData", ou dans un contexte scalaire, le nombre de fonctionnalités.
auto_feature_names()
Retourne une liste de tous les noms des fonctionnalités dont la disponibilité est déterminée dynamiquement, ou dans un contexte scalaire, le nombre de ces fonctionnalités. N'inclut pas les fonctionnalités qui ont été définies ultérieurement à une valeur fixe.
write()
Valide toutes les modifications apportées par set_config() et set_feature() sur le disque. Nécessite des droits d'écriture sur le module "Module::Build::ConfigData".
