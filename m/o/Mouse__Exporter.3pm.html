Mouse::Exporter(3pm) Documentation Perl Contribuée par les Utilisateurs Mouse::Exporter(3pm)

NOM

Mouse::Exporter - créer des méthodes import() et unimport() tout comme Mouse.pm

VERSION

Ce document décrit la version de Mouse v2.6.0

SYNOPSIS

package MyApp::Mouse;
use Mouse ();
use Mouse::Exporter;
Mouse::Exporter->setup_import_methods(
  as_is => [ 'has_rw', 'other_sugar', \&Some::Random::thing ],
  also  => 'Mouse',
);
sub has_rw {
    my $meta = caller->meta;
    my ( $name, %options ) = @_;
    $meta->add_attribute(
      $name,
      is => 'rw',
      %options,
    );
}
# puis plus tard ...
package MyApp::User;
use MyApp::Mouse;
has 'name';
has_rw 'size';
thing;
no MyApp::Mouse;

DESCRIPTION

Ce module encapsule l'exportation de fonctions de sucre (sugar functions) d'une manière similaire à "Mouse.pm". Il le fait en construisant des méthodes "import" et "unimport" personnalisées pour votre module, basées sur une spécification que vous fournissez.

Notez que "Mouse::Exporter" ne fournit pas l'option "with_meta", mais vous pouvez facilement obtenir la métaclasse en utilisant "caller->meta" comme le montre le "SYNOPSIS".

MÉTHODES

setup_import_methods( ARGS )

"build_import_methods( ARGS ) -> (\&import, \&unimport)"
