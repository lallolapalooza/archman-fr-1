NOM

Module::Install::PAR - Prise en charge de Module::Install pour les paquets PAR::Dist

SYNTAXE

Pour offrir à vos utilisateurs la possibilité d'installer des binaires si nous ne pouvons pas compiler une version XS du module, vous pouvez utiliser ce stub simplifié :

use inc::Module::Install;

name            'Foo';
all_from        'lib/Foo.pm';

# De quel répertoire CPAN allons-nous télécharger les binaires ?
par_base        'SMUELLER';

unless ( can_xs ) {
    my $okay = extract_par( fetch_par );
    if (not $okay) {
        die "Aucun compilateur et aucun paquet binaire trouvés. Abandon.\n";
    }
}

WriteAll;

DESCRIPTION

Ce module ajoute quelques directives à Module::Install relatives à l'installation et à la création de distributions PAR::Dist.

par_base

Cette directive définit l'ID CPAN à partir duquel les binaires seront téléchargés. Par exemple, vous pouvez choisir de télécharger les binaires depuis http://www.cpan.org/authors/id/S/SM/SMUELLER/ ou son homologue ftp en écrivant :

par_base 'SMUELLER';

Par défaut, le nom du fichier à télécharger est généré à partir du nom de la distribution, de sa version, de votre nom de plateforme et de votre version de perl, concaténés avec des tirets.

La directive prend cependant un deuxième argument optionnel qui spécifie le nom du fichier à télécharger. (Bien que "par_base" ne télécharge pas de fichiers elle-même, voir ci-dessous.)

par_base 'SMUELLER', 'foo';

Une fois que "fetch_par" est appelé, le fichier 'foo' sera téléchargé depuis le répertoire CPAN de SMUELLER. (Il n'existe pas.)

Le deuxième argument pourrait être utilisé pour télécharger des binaires indépendants de la plateforme :

par_base 'SMUELLER', "Some-Distribution-0.01.par";

fetch_par

Récupère le fichier .par précédemment référencé dans la documentation de la directive "par_base".

"fetch_par" peut être utilisé sans arguments si la directive "par_base" a été utilisée auparavant. Il retournera le nom du fichier qu'il a récupéré.

Si le premier argument est une URL ou un ID utilisateur CPAN, le fichier est téléchargé depuis ce répertoire sauf si une URL a été précédemment définie. (Relisez cela.)

Si le deuxième argument est un nom de fichier, il est utilisé comme nom du fichier à télécharger.

Si le fichier n'a pas pu être récupéré, un message d'erreur approprié indiquant qu'aucun paquet n'est disponible, etc., est affiché. Vous pouvez désactiver cela en spécifiant un troisième argument vrai.

# Essayer de récupérer le paquet (voir par_base) mais
# ne pas être verbeux sur les échecs
my $file = fetch_par('', '', undef);

extract_par

Prend le nom d'un fichier archive PAR::Dist comme premier argument. Le répertoire 'blib/' de cette archive est extrait et 'pm_to_blib' est créé.

Utilisation raccourcie typique :

extract_par( fetch_par ) or die "Impossible d'installer l'archive PAR::Dist.";

make_par

Cette directive nécessite PAR::Dist (version 0.03 ou supérieure) sur votre système. (Et vérifie qu'il est disponible avant de continuer.)

Crée une archive PAR::Dist à partir du sous-répertoire 'blib/'.

Le premier argument doit être le nom de l'archive PAR::Dist à créer.

Si votre Makefile.PL a une directive "par_base", la cible de construction "make par" sera disponible. Elle utilise cette directive "make_par" en interne, donc sur votre système de développement, vous pouvez faire ceci pour créer une archive binaire .par pour votre plateforme :

perl Makefile.PL
make
make par
