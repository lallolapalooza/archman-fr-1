NOM

Mozilla::CA - Bundle de certificats CA de Mozilla au format PEM

SYNTAXE

use IO::Socket::SSL;
use Mozilla::CA;
my $host = "www.paypal.com";
my $client = IO::Socket::SSL->new(
    PeerHost => "$host:443",
    SSL_verify_mode => 0x02,
    SSL_ca_file => Mozilla::CA::SSL_ca_file(),
)
    || die "Impossible de se connecter : $@";
$client->verify_hostname($host, "http")
    || die "échec de la vérification du nom d'hôte";

DESCRIPTION

Mozilla::CA fournit une copie du bundle de certificats d'autorité de certification de Mozilla dans un format utilisable par les modules et bibliothèques basés sur OpenSSL.

Le module fournit une seule fonction :

SSL_ca_file()
Retourne le chemin absolu du fichier PEM du bundle de certificats CA de Mozilla.
