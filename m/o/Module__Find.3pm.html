NOM

Module::Find - Trouver et utiliser des modules installés dans une (sous)catégorie

SYNOPSIS

use Module::Find;
# utiliser tous les modules dans le dossier Plugins/
@found = usesub Mysoft::Plugins;
# utiliser les modules dans tous les sous-dossiers
@found = useall Mysoft::Plugins;
# trouver tous les modules DBI::...
@found = findsubmod DBI;
# trouver tout dans le dossier CGI/
@found = findallmod CGI;

# définir vos propres répertoires de recherche (utilise @INC normalement)
setmoduledirs(@INC, @plugindirs, $appdir);

# non exporté par défaut
use Module::Find qw(ignoresymlinks followsymlinks);

# ignorer les liens symboliques
ignoresymlinks();

# suivre les liens symboliques (par défaut)
followsymlinks();

DESCRIPTION

Module::Find permet de trouver et d'utiliser des modules dans des catégories. Ceci peut être très utile pour auto-détecter des modules de driver ou de plugin. Vous pouvez différencier entre la recherche dans la catégorie elle-même ou dans toutes ses sous-catégories.

Si vous voulez que Module::Find recherche dans un répertoire spécifique sur votre disque dur (comme le dossier plugins de votre installation logicielle), assurez-vous de modifier @INC avant d'appeler les fonctions de Module::Find.

FONCTIONS

setmoduledirs(@directories)
Définit les répertoires à parcourir pour trouver les modules. Si rien n'est défini, Module::Find utilisera @INC. Si vous utilisez cette fonction, @INC n'est pas inclus automatiquement, donc ajoutez-le si vous le souhaitez. Définissez à undef pour revenir au comportement par défaut.
"@found = findsubmod Module::Category"
Retourne les modules trouvés dans les sous-dossiers Module/Category de votre installation Perl. Par exemple, findsubmod CGI retourne CGI::Session, mais pas CGI::Session::File.
"@found = findallmod Module::Category"
Retourne les modules trouvés dans les sous-dossiers Module/Category de votre installation Perl. Par exemple, findallmod CGI retourne CGI::Session et aussi CGI::Session::File.
"@found = usesub Module::Category"
Utilise et retourne les modules trouvés dans les sous-dossiers Module/Category de votre installation Perl. Par exemple, usesub CGI retourne CGI::Session, mais pas CGI::Session::File. Si un module s'exécute lors du chargement, usesub s'arrêtera également à ce stade.
"@found = useall Module::Category"
Utilise et retourne les modules trouvés dans les sous-dossiers Module/Category de votre installation Perl. Par exemple, useall CGI retourne CGI::Session et aussi CGI::Session::File. Si un module s'exécute lors du chargement, useall s'arrêtera également à ce stade.
ignoresymlinks()
Ne pas suivre les liens symboliques. Cette fonction n'est pas exportée par défaut.
followsymlinks()
Suivre les liens symboliques (comportement par défaut). Cette fonction n'est pas exportée par défaut.
