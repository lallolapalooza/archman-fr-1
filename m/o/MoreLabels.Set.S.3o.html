val add : elt -> t -> t

Ajoute un élément x à s. add x s retourne un ensemble contenant tous les éléments de s ainsi que x. Si x était déjà dans s, s est retourné sans changement (le résultat de la fonction est physiquement égal à s).

Avant 4.03 L'égalité physique n'est pas garantie.

Depuis 4.05

val find_first : f:(elt -> bool) -> t -> elt

find_first ~f s, où f est une fonction monotone croissante, retourne le plus petit élément e de s tel que f e, ou lève Not_found s'il n'existe pas un tel élément.

Par exemple, find_first (fun e -> Ord.compare e x >= 0) s retourne le premier élément e de s tel que Ord.compare e x >= 0 (intuitivement : e >= x), ou lève Not_found si x est plus grand que n'importe quel élément de s.

Parcours

val iter : f:(elt -> unit) -> t -> unit

iter ~f s applique f dans l'ordre à tous les éléments de s. Les éléments de s sont présentés à f par ordre croissant selon l'ordre des types d'éléments.

val fold : f:(elt -> 'acc -> 'acc) -> t -> init:'acc -> 'acc

fold ~f s init calcule (f xN ... (f x2 (f x1 init))...), où x1 ... xN sont les éléments de s par ordre croissant.

Transformation

val map : f:(elt -> elt) -> t -> t

map ~f s est l'ensemble dont les éléments sont f a0, f a1, ..., f aN, où a0, a1, ..., aN sont les éléments de s.

Les éléments sont passés à f par ordre croissant selon l'ordre des types d'éléments.

Si aucun élément de s n'est modifié par f, s est retourné sans changement. (Si chaque sortie de f est physiquement égale à son entrée, l'ensemble retourné est physiquement égal à s.)

Depuis 4.04

val filter : f:(elt -> bool) -> t -> t

filter ~f s retourne l'ensemble de tous les éléments de s qui satisfont le prédicat f. Si f satisfait tous les éléments de s, s est retourné sans changement (le résultat de la fonction est physiquement égal à s).

Avant 4.03 L'égalité physique n'est pas garantie.

val filter_map : f:(elt -> elt option) -> t -> t

filter_map ~f s retourne l'ensemble de tous les v tels que f x = Some v pour un élément x de s.

Par exemple,

filter_map (fun n -> if n mod 2 = 0 then Some (n / 2) else None) s
est l'ensemble des moitiés des éléments pairs de s.

Si aucun élément de s n'est modifié ou supprimé par f (si f x = Some x pour chaque élément x), alors s est retourné sans changement : le résultat de la fonction est physiquement égal à s.

val split : elt -> t -> t * bool * t

split x s retourne un triplet (l, present, r) , où l est l'ensemble des éléments de s strictement inférieurs à x ; r est l'ensemble des éléments de s strictement supérieurs à x ; present vaut false si s ne contient aucun élément égal à x , ou true si s contient un élément égal à x .

Prédicats et comparaisons

val is_empty : t -> bool

Teste si un ensemble est vide ou non.

val mem : elt -> t -> bool

mem x s teste si x appartient à l'ensemble s .

val equal : t -> t -> bool

equal s1 s2 teste si les ensembles s1 et s2 sont égaux, c'est-à-dire s'ils contiennent des éléments égaux.

val compare : t -> t -> int

Ordre total entre ensembles. Peut être utilisé comme fonction d'ordonnancement pour créer des ensembles d'ensembles.

val subset : t -> t -> bool

subset s1 s2 teste si l'ensemble s1 est un sous-ensemble de l'ensemble s2 .

val for_all : f:(elt -> bool) -> t -> bool

for_all ~f s vérifie si tous les éléments de l'ensemble satisfont le prédicat f .

val exists : f:(elt -> bool) -> t -> bool

exists ~f s vérifie si au moins un élément de l'ensemble satisfont le prédicat f .
