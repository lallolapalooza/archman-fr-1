NOM

Module::Install::Admin::Include - méthodes d'inclusion pour Module::Install

auto_include_dependent_dists

Récupère tout ce qui se trouve dans les build_requires de ce module et tente d'inclure récursivement tout (au niveau de la distribution entière).

include_dependent_dists $package

Étant donné le nom d'un paquet de module, inclut récursivement chaque paquet dont ce module a besoin.

include_one_dist $module

Étant donné le nom d'un module, $module, détermine quels modules se trouvent dans la distribution contenant ce module et copie tous ces fichiers dans ./inc. Je parie qu'il existe un moyen d'exploiter une logique plus intelligente de PAR.

Étant donné le nom d'un module, renvoie le fichier sur CPAN contenant sa dernière version.

Prend la sortie de CPAN::Module->cpan_file et renvoie tous les modules que CPAN.pm sait être dans cette distribution. Il y a probablement un meilleur moyen en utilisant CPANPLUS
