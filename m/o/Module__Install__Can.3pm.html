NOM

Module::Install::Can - Fonctions utilitaires pour la détection de capacités

DESCRIPTION

"Module::Install::Can" contient un certain nombre de fonctions que les auteurs peuvent utiliser lors de la création d'installateurs intelligents personnalisés. Les fonctions simplifient les tests standard de sorte que vous puissiez exprimer vos dépendances et conditions de manière beaucoup plus simple, et rendre votre installateur beaucoup plus facile à maintenir.

COMMANDES

can_use

can_use('Module::Name');
can_use('Module::Name', 1.23);

La fonction "can_use" teste la capacité de charger un module nommé spécifique. Actuellement, elle charge également réellement le module dans le processus, bien que cela puisse changer à l'avenir.

Elle accepte un deuxième paramètre optionnel d'un numéro de version. La version actuellement installée du module sera testée pour s'assurer qu'elle est égale ou supérieure à la version spécifiée.

Elle renvoie vrai si le module peut être chargé, ou faux (dans les deux contextes scalaire et liste) sinon.

can_run

can_run('cvs');

La fonction "can_run" teste la capacité d'exécuter une commande ou un programme nommé sur le système local.

Elle renvoie vrai si c'est possible, ou faux (dans les deux contextes scalaire et liste) sinon.

can_cc

can_cc();

La fonction "can_cc" teste la capacité de localiser un compilateur C fonctionnel sur le système local. Elle renvoie vrai si le compilateur C peut être trouvé, ou faux (dans les deux contextes scalaire et liste) sinon.

can_xs

can_xs();

La fonction "can_xs" teste la présence d'un compilateur C fonctionnel et des en-têtes corrects pour construire des modules XS par rapport à l'instance actuelle de Perl.

À FAIRE

Actuellement, l'utilisation d'une commande "can_foo" dans un seul domaine de problème (par exemple "can_use") entraîne l'inclusion de fonctionnalités supplémentaires provenant de différents domaines de problème (par exemple "can_run").

Ce module devrait finalement être divisé, et les fonctions individuelles redistribuées à différentes extensions spécifiques à un domaine.
