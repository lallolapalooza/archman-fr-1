type t

Le type des clés de la table de hachage.

val equal : t -> t -> bool

Le prédicat d'égalité utilisé pour comparer les clés.

val hash : t -> int

Une fonction de hachage sur les clés. Elle doit être telle que si deux clés sont égales selon equal , alors elles ont des valeurs de hachage identiques calculées par hash . Exemples : les paires ( equal , hash ) appropriées pour des types de clés arbitraires incluent

- ( (=) , MoreLabels.Hashtbl.HashedType.hash ) pour comparer les objets par structure (à condition que les objets ne contiennent pas de flottants)

- ( (fun x y -> compare x y = 0) , MoreLabels.Hashtbl.HashedType.hash ) pour comparer les objets par structure et gérer nan correctement

- ( (==) , MoreLabels.Hashtbl.HashedType.hash ) pour comparer les objets par égalité physique (par exemple, pour des objets mutables ou cycliques).
