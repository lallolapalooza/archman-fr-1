val ajouter : clé:clé -> donnée:'a -> 'a t -> 'a t

ajouter ~clé ~donnée m retourne une carte contenant les mêmes associations que m , plus une association de clé à donnée . Si clé était déjà associée dans m à une valeur physiquement égale à donnée , m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m ). Sinon, l'association précédente de clé dans m disparaît.

Avant4.03 L'égalité physique n'était pas garantie.

val ajouter_a_liste : clé:clé -> donnée:'a -> 'a list t -> 'a list t

ajouter_a_liste ~clé ~donnée m est m avec clé associée à l telle que l est donnée :: Map.trouver clé m si clé était associée dans m et [donnée] sinon.

val mettre_a_jour : clé:clé -> f:('a option -> 'a option) -> 'a t -> 'a t

mettre_a_jour ~clé ~f m retourne une carte contenant les mêmes associations que m , à l'exception de l'association de clé . Selon la valeur de y où y est f (trouver_opt clé m) , l'association de clé est ajoutée, supprimée ou mise à jour. Si y est None , l'association est supprimée si elle existe ; sinon, si y est Some z alors clé est associée à z dans la carte résultante. Si clé était déjà associée dans m à une valeur physiquement égale à z , m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m ).

val supprimer : clé -> 'a t -> 'a t

supprimer x m retourne une carte contenant les mêmes associations que m , à l'exception de x qui n'est pas associé dans la carte résultante. Si x n'était pas dans m , m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m ).

val fusionner : f:(clé -> 'a option -> 'b option -> 'c option) -> 'a t -> 'b t -> 'c t

fusionner ~f m1 m2 calcule une carte dont les clés sont un sous-ensemble des clés de m1 et de m2 . La présence de chaque association, et la valeur correspondante, est déterminée par la fonction f . En termes de l'opération trouver_opt , nous avons trouver_opt x (fusionner f m1 m2) = f x (trouver_opt x m1) (trouver_opt x m2) pour toute clé x , à condition que f x None None = None .

Depuis 3.12

val union : f:(clé -> 'a -> 'a -> 'a option) -> 'a t -> 'a t -> 'a t

union ~f m1 m2 calcule une carte dont les clés sont un sous-ensemble des clés de m1 et de m2 . Lorsque la même association est définie dans les deux arguments, la fonction f est utilisée pour les combiner. C'est un cas particulier de fusionner : union f m1 m2 est équivalent à fusionner f' m1 m2 , où

- f' _clé None None = None

- f' _clé (Some v) None = Some v

- f' _clé None (Some v) = Some v

- f' clé (Some v1) (Some v2) = f clé v1 v2

Recherche

val trouver : clé -> 'a t -> 'a

trouver x m retourne la valeur actuelle de x dans m , ou lève Not_found si aucune association pour x n'existe.

val trouver_opt : clé -> 'a t -> 'a option

trouver_opt x m retourne Some v si la valeur actuelle de x dans m est v , ou None si aucune association pour x n'existe.

Depuis 4.05

val trouver_premier : f:(clé -> bool) -> 'a t -> clé * 'a

trouver_premier ~f m , où f est une fonction monotoniquement croissante, retourne l'association de m avec la plus petite clé k telle que f k , ou lève Not_found si aucune clé de ce type n'existe.

Par exemple, trouver_premier (fun k -> Ord.comparer k x >= 0) m retournera la première association k, v de m où Ord.comparer k x >= 0 (intuitivement : k >= x ), ou lèvera Not_found si x est plus grand que n'importe quel élément de m .

Parcours

val iter : f:(key:key -> data:'a -> unit) -> 'a t -> unit

iter ~f m applique f à toutes les associations dans la carte m . f reçoit la clé comme premier argument, et la valeur associée comme second argument. Les associations sont passées à f dans l'ordre croissant par rapport à l'ordre sur le type des clés.

val fold : f:(key:key -> data:'a -> 'acc -> 'acc) -> 'a t -> init:'acc -> 'acc

fold ~f m ~init calcule (f kN dN ... (f k1 d1 init)...) , où k1 ... kN sont les clés de toutes les associations dans m (par ordre croissant), et d1 ... dN sont les données associées.

Transformation

val map : f:('a -> 'b) -> 'a t -> 'b t

map ~f m retourne une carte avec le même domaine que m , où la valeur associée a de toutes les associations de m a été remplacée par le résultat de l'application de f à a . Les associations sont passées à f dans l'ordre croissant par rapport à l'ordre sur le type des clés.

val mapi : f:(key -> 'a -> 'b) -> 'a t -> 'b t

Identique à MoreLabels.Map.S.map , mais la fonction reçoit en arguments la clé et la valeur associée pour chaque association de la carte.

val filter : f:(key -> 'a -> bool) -> 'a t -> 'a t

filter ~f m retourne la carte avec toutes les associations de m qui satisfont le prédicat f . Si toutes les associations dans m satisfont f , m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m )

Depuis 3.12

val filter_map : f:(key -> 'a -> 'b option) -> 'a t -> 'b t

filter_map ~f m applique la fonction f à chaque association de m , et construit une carte à partir des résultats. Pour chaque association (k, v) dans la carte d'entrée :

- si f k v est None alors k n'est pas dans le résultat,

- si f k v est Some v' alors l'association (k, v') est dans la carte de sortie.

Par exemple, la fonction suivante sur les cartes dont les valeurs sont des listes

          filter_map
            (fun _k li -> match li with [] -> None | _::tl -> Some tl)
            m
supprime toutes les associations de m dont la valeur est une liste vide, et retire le premier élément de chaque valeur non vide.

Depuis 4.11

val partition : f:(key -> 'a -> bool) -> 'a t -> 'a t * 'a t

partition ~f m retourne un couple de cartes (m1, m2) , où m1 contient toutes les associations de m qui satisfont le prédicat f , et m2 est la carte avec toutes les associations de m qui ne satisfont pas f .

Depuis 3.12

val split : key -> 'a t -> 'a t * 'a option * 'a t

split x m retourne un triple (l, data, r) , où l est la carte avec toutes les associations de m dont la clé est strictement inférieure à x ; r est la carte avec toutes les associations de m dont la clé est strictement supérieure à x ; data est None si m ne contient aucune association pour x , ou Some v si m associe v à x .

Prédicats et comparaisons

val is_empty : 'a t -> bool

Teste si une carte est vide ou non.

val mem : key -> 'a t -> bool

mem x m retourne true si m contient une association pour x , et false sinon.

val equal : cmp:('a -> 'a -> bool) -> 'a t -> 'a t -> bool

equal ~cmp m1 m2 teste si les cartes m1 et m2 sont égales, c'est-à-dire, contiennent des clés égales et leur associent des données égales. cmp est le prédicat d'égalité utilisé pour comparer les données associées aux clés.

val compare : cmp:('a -> 'a -> int) -> 'a t -> 'a t -> int

Ordre total entre cartes. Le premier argument est un ordre total utilisé pour comparer les données associées aux clés égales dans les deux cartes.

val for_all : f:(key -> 'a -> bool) -> 'a t -> bool

for_all ~f m vérifie si toutes les associations de la carte satisfont le prédicat f .

val exists : f:(key -> 'a -> bool) -> 'a t -> bool

exists ~f m vérifie si au moins une association de la carte satisfait le prédicat f .
