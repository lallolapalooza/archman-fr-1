NOM

Module::Build::Notes - Créer des modules de configuration de distribution persistants

DESCRIPTION

Ce module est utilisé en interne par Module::Build pour créer des fichiers de configuration persistants qui peuvent être installés avec une distribution. Voir Module::Build::ConfigData pour un exemple.
