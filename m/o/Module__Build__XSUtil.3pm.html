NOM

Module::Build::XSUtil - Une classe Module::Build pour la construction de modules XS

SYNOPSIS

Utilisation dans votre Build.PL

use strict;
use warnings;
use Module::Build::XSUtil;

my $builder = Module::Build::XSUtil->new(
    dist_name            => 'Votre-Module-XS',
    license              => 'perl',
    dist_author          => 'Votre Nom <votre.nom@exemple.com>',
    dist_version_from    => 'lib/Votre/Module/XS',
    generate_ppport_h    => 'lib/Votre/Module/XS/ppport.h',
    generate_xshelper_h  => 'lib/Votre/Module/XS/xshelper.h',
    needs_compiler_c99   => 1,
);

$builder->create_build_script();

Utilisation dans un module constructeur personnalisé.

package builder::MonConstructeur;
use strict;
use warnings;
use base 'Module::Build::XSUtil';

sub new {
    my ($class, %args) = @_;
    my $self = $class->SUPER::new(
        %args,
        generate_ppport_h    => 'lib/Votre/Module/XS/ppport.h',
        generate_xshelper_h  => 'lib/Votre/Module/XS/xshelper.h',
        needs_compiler_c99   => 1,
    );
    return $self;
}

1;

DESCRIPTION

Module::Build::XSUtil est une sous-classe de Module::Build pour prendre en charge la construction de modules XS.

Voici une liste des nouveaux paramètres dans la méthode Module::Build::new :

needs_compiler_c99
Cette option vérifie la disponibilité d'un compilateur C99. S'il n'est pas disponible, Build.PL se termine avec un code 0.
needs_compiler_cpp
Cette option vérifie la disponibilité d'un compilateur C++. S'il n'est pas disponible, Build.PL se termine avec un code 0.

En outre, ajoute 'extra_compiler_flags' et 'extra_linker_flags' pour C++.

generate_ppport_h
Génère ppport.h à l'aide de Devel::PPPort.
generate_xshelper_h
Génère xshelper.h, un fichier d'en-tête d'aide pour inclure EXTERN.h, perl.h, XSUB.h et ppport.h, et définit certaines constructions de portabilité qui ne sont pas prises en charge par ppport.h.

Il est adapté de Module::Install::XSUtil.

cc_warnings
Active l'indicateur d'avertissements du compilateur. Il est activé par défaut.
-g options
Si vous appelez Build.PL avec l'option '-g', il construira avec les options de débogage.
