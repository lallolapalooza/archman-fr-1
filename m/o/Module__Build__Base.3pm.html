NOM

Module::Build::Base - Méthodes par défaut pour Module::Build

SYNOPIS

Voir la documentation de Module::Build.

DESCRIPTION

Le module "Module::Build::Base" définit la fonctionnalité principale de "Module::Build". Ses méthodes peuvent être remplacées par l'un des modules spécifiques à la plateforme dans le namespace "Module::Build::Platform::", mais l'intention ici est de rendre ce module de base aussi neutre que possible vis-à-vis de la plateforme. Heureusement, Perl dispose de plusieurs outils de base dans le namespace "File::" pour cela, donc la tâche n'est pas très difficile.

Voir la documentation de "Module::Build" pour plus de détails.
