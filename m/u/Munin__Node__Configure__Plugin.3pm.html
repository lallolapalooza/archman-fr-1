NOM

Munin::Node::Configure::Plugin - Classe représentant un plugin, avec ses services installés et suggérés.

SYNOPSIS

my $plugin = Munin::Node::Configure::Plugin->new();

MÉTHODES

new(%args)
Constructeur.

Les arguments requis sont 'name' et 'path', qui doivent être le nom de base et le chemin complet du plugin, respectivement.

is_wildcard()
Retourne vrai si le plugin est un wildcard. Dans le cas des plugins SNMP, seuls les plugins double-wildcard retourneront vrai (par ex. 'snmp__memory' retournerait faux, mais 'snmp__if_' retournerait vrai).
is_snmp()
Retourne vrai si le plugin est un plugin SNMP.
in_family(@families)
Retourne vrai si la famille du plugin est dans @families, faux sinon.
is_installed()
Retourne 'yes' si un ou plusieurs liens vers ce plugin existent dans le répertoire des services, 'no' sinon.
suggestion_string()
Retourne une chaîne détaillant si autoconf considère que le plugin doit être installé ou non. La chaîne peut également indiquer la raison pour laquelle le plugin a refusé d'être installé, ou la liste des suggestions qu'il a fournies, si ces informations sont disponibles.
installed_services_string()
Retourne une chaîne détaillant quels wildcards sont installés pour ce plugin.
services_to_add()
services_to_remove()
Retourne une liste de noms de services qui devraient être ajoutés ou supprimés pour ce plugin.
add_instance($name)
Associe un lien du répertoire des services à ce plugin.
add_suggestions(@suggestions)
Ajoute @suggestions à la liste des wildcards suggérés pour ce plugin. Ils ne sont pas validés.
read_magic_markers()
Définit la famille et les capacités à partir des marqueurs magiques intégrés dans l'exécutable du plugin, comme spécifié dans http://munin-monitoring.org/wiki/ConcisePlugins#Magicmarkers
parse_autoconf_response(@response)
Analyse et valide la réponse autoconf du plugin, dans le format spécifié par http://munin-monitoring.org/wiki/ConcisePlugins#autoconf

Une entrée invalide provoquera la journalisation d'une erreur pour le plugin.

parse_suggest_response(@response)
Valide les suggestions du plugin.

Des suggestions invalides provoqueront la journalisation d'une erreur pour le plugin.

parse_snmpconf_response(@response)
Analyse et valide la réponse snmpconf du plugin, dans le format spécifié par http://munin-monitoring.org/wiki/ConcisePlugins#suggest

Une entrée invalide ou incohérente provoquera la journalisation d'une erreur pour le plugin.

log_error($message)
Journalise une erreur pour une récupération ultérieure. L'erreur sera également affichée si la sortie de débogage est activée.
