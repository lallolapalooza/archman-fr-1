Munin::Node::Configure::PluginList(3pm) Documentation Perl contribuée par l'utilisateur Munin::Node::Configure::PluginList(3pm)

NOM

Munin::Node::Configure::PluginList - Chargement et liste d'une collection de plugins

SYNOPSIS

my $plugins = Munin::Node::Configure::PluginList->new(
      libdir     => '/usr/share/munin/plugins/',
      servicedir => '/etc/munin/plugins/',
);
$plugins->load('auto');
foreach my $plugin ($plugins->list) {
      # faire quelque chose avec chaque plugin 'auto' à tour de rôle
}

SOUS-ROUTINES

new(%args)
Constructeur.

Les arguments requis sont 'libdir' et 'servicedir', qui sont respectivement le répertoire de bibliothèque des plugins et le répertoire des services.

load(@families)
Trouve tous les plugins dans 'libdir' qui appartiennent à l'une des @families, ainsi que toutes les instances de ces plugins dans 'servicedir'.
list()
Retourne une liste d'objets Munin::Node::Configure::Plugin actuellement chargés, triés par ordre alphabétique.
names()
Retourne les noms des plugins actuellement chargés.
