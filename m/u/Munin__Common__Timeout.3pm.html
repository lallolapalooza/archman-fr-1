Munin::Common::Timeout(3pm) Documentation Perl fournie par la communauté Munin::Common::Timeout(3pm)

NOM

Munin::Common::Timeout - Exécute du code avec un délai d'attente. Peut être imbriqué.

SYNTAXE

use Munin::Common::Timeout;
do_with_timeout(50, sub {
    # ...
       do_with_timeout(5, sub {
               # ...
               # ...
       });
    # ...
});

DESCRIPTION

Voir aussi Time::Out, Sys::AlarmCall

SOUS-PROGRAMMES

do_with_timeout
my $finished_with_no_timeout = do_with_timeout($seconds, $code_ref)
    or die "Dépassement de délai !";

Exécute $block avec un délai d'attente de $seconds secondes. Retourne la valeur de retour de $block s'il s'est terminé dans le délai imparti. Si le délai est atteint et que le code est toujours en cours d'exécution, il est arrêté et undef est retourné.

NB : chaque $code_ref doit retourner quelque chose de défini, sinon l'appelant ne saura pas si un délai a été atteint.

Les appels à do_with_timeout() peuvent être imbriqués. Toutes les exceptions levées par $block sont propagées.
