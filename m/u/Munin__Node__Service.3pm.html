Munin::Node::Service(3pm) Documentation Perl fournie par l'utilisateur Munin::Node::Service(3pm)

NOM

Munin::Node::Service - Méthodes liées à la gestion des services Munin

SYNTAXE

my $services = Munin::Node::Service->new(timeout => 30);
$services->prepare_plugin_environment;
if ($services->is_a_runnable_service($file_name)) {
   $services->fork_service($file_name);
}

MÉTHODES

new
my $services = Munin::Node::Service->new(%args);

Constructeur. Tous les arguments sont optionnels. Les arguments valides sont :

"servicedir"
Le répertoire qui sera recherché pour les services.
"defuser", "defgroup"
L'uid et le gid par défaut sous lesquels les services s'exécuteront. Les directives spécifiques de service utilisateur et groupe (telles que définies par les fichiers de configuration du service) auront la priorité sur celles-ci.
"timeout"
Le délai d'attente par défaut pour les services. Les services qui prennent plus de temps que cela pour s'exécuter seront tués. Les délais d'attente spécifiques aux services (tels que définis dans les fichiers de configuration des services) auront la priorité sur cette valeur.
is_a_runnable_service
my $bool = $services->is_a_runnable_service($file_name);

Exécute divers tests sur $file_name dans le répertoire des services, pour essayer de déterminer s'il s'agit d'un service exécutable.

list
my @services = $services->list;

Retourne une liste de tous les services exécutables dans le répertoire.

prepare_plugin_environment
$services->prepare_plugin_environment(@services);

Effectue diverses tâches requises par les plugins avant leur exécution, telles que le chargement des configurations de service et l'exportation des variables d'environnement communes.

export_service_environment
$services->export_service_enviromnent($service);

Exporte toutes les variables d'environnement spécifiques au service $service.

change_real_and_effective_user_and_group
$service->change_real_and_effective_user_and_group($service);

Modifie les identifiants utilisateur et groupe effectifs et réels du processus courant pour ceux spécifiés dans la configuration, ou l'utilisateur ou le groupe par défaut sinon. Modifie également les identifiants utilisateur et groupe réels si le système d'exploitation le prend en charge.

En cas d'échec, provoque la sortie du processus.

exec_service
$service->exec_service($service, [@arguments]);

Remplace le processus courant par une instance du service $service dans $directory, exécuté avec l'environnement et les privilèges corrects.

Cette fonction ne retourne jamais. Le processus s'exécutera exit(2) si le service à exécuter échoue à la vérification de sécurité.

fork_service
$result = $service->fork_service($service, [$argument]);

Identique à exec_service(), sauf qu'il exécute le service dans un sous-processus. Si le service prend plus de temps que le délai d'attente, il sera terminé.

Retourne une référence de hachage contenant (entre autres choses) la sortie et la valeur de sortie du service. (Voir la documentation de run_as_child() dans Munin::Node::Service pour une description complète.)
