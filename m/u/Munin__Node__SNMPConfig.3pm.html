Munin__Node__SNMPConfig(3pm)

Paquet: munin-node

Licences: GPL

Munin::Node::SNMPConfig(3pm) Documentation Perl fournie par la communauté Munin::Node::SNMPConfig(3pm)

NOM

Munin::Node::SNMPConfig - Sous-programmes fournissant les capacités d'analyse SNMP de munin-node-configure.

SYNOPSIS

my $snmp = Munin::Node::SNMPConfig->new(
      community => 'secret',
      version   => 1,
);
$snmp->probe_hosts(\%plugins);

SOUS-PROGRAMMES

nouveau(%arguments)
Constructeur. Les arguments valides sont :
hotes
La liste des hôtes à analyser, dans un format compris par Munin::Node::Configure::HostEnumeration. Obligatoire.
port
Port de connexion. Par défaut 161.
version
La version SNMP à utiliser. Par défaut '2c'.
communaute
La chaîne de communauté à utiliser pour les versions SNMP 1 ou 2c. Par défaut 'public'.
domaine
Le domaine de transport à utiliser pour l'échange de messages SNMP. Par défaut UDP/IPv4. Valeurs possibles : 'udp', 'udp4', 'udp/ipv4' ; 'udp6', 'udp/ipv6' ; 'tcp', 'tcp4', 'tcp/ipv4' ; 'tcp6', 'tcp/ipv6'.
nom_utilisateur
Le nom d'utilisateur SNMPv3 à utiliser.
mot_de_passe_authentification
Mot de passe d'authentification SNMPv3. Facultatif lorsque le chiffrement est également activé, auquel cas il prend par défaut la valeur du mot de passe de confidentialité ("mot_de_passe_confidentialite"). Le mot de passe est envoyé chiffré (hash unidirectionnel) sur le réseau.
protocole_authentification
Protocole d'authentification SNMPv3. L'un des 'md5' ou 'sha' (HMAC-MD5-96, RFC1321 et SHA-1/HMAC-SHA-96, NIST FIPS PIB 180, RFC2264). Par défaut 'md5'.
mot_de_passe_confidentialite
Mot de passe de confidentialité SNMPv3 pour activer le chiffrement. Un mot de passe vide ('') est considéré comme aucun mot de passe et n'activera pas le chiffrement.

La confidentialité nécessite un v3privprotocol ainsi qu'un v3authprotocol et un v3authpassword, mais tous ceux-ci ont des valeurs par défaut (respectivement 'des', 'md5' et la valeur v3privpassword) et peuvent donc être omis.

protocole_confidentialite
Si le v3privpassword est défini, ce paramètre contrôle le type de chiffrement utilisé pour assurer la confidentialité dans la session. Seule la méthode de chiffrement 'des', très faible, est officiellement supportée. Par défaut 'des'.

Le module Perl implémentant (Net::SNMP) supporte également '3des' (CBC-3DES-EDE alias Triple-DES, NIST FIPS 46-3) tel que spécifié dans le brouillon IETF draft-reeder-snmpv3-usm-3desede. Que cela fonctionne ou non avec un appareil particulier, nous ne le savons pas.

lancer_sondes($plugins)
Se connecte à chaque hôte à tour de rôle et vérifie quels plugins il prend en charge, en fonction des OID qu'ils ont rapportés lors de snmpconf. Si toutes les exigences sont satisfaites, il sera ajouté à la liste de suggestions du plugin correspondant.

$plugins doit être un objet Munin::Node::Configure::PluginList.
