Munin::Node::Configure::Debug(3pm) Documentation Perl fournie par l'utilisateur Munin::Node::Configure::Debug(3pm)

NOM

Munin::Node::Configure::Debug - Affiche un message de débogage dans le format standard de munin-node-configure.

SYNTAXE

DEBUG('Ceci est un message de débogage');

SOUS-PROGRAMMES

DEBUG($message)
Affiche $message dans le format standard de munin-node-configure (vers STDOUT, précédé d'un caractère '#'), seulement si le drapeau DEBUG a été défini dans l'instance Config.

$message ne doit pas avoir de '#' en début, ni de saut de ligne en fin.
