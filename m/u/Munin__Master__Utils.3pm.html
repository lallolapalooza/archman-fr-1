NOM

Munin::Master::Utils - Exporte de nombreuses fonctions utilitaires.

SYNOPSIS

use Munin::Master::Utils;

SOUS-ROUTINES

munin_category_status
Obtient le statut actuel d'une catégorie.

Paramètres :
- $hash: Référence vers le nœud de hachage dont les enfants doivent être vérifiés
- $limits: Référence vers le nœud racine de l'arbre des limites
- $category: La catégorie à examiner
- $check_draw: [facultatif] Ignorer les champs non dessinés

Retourne :
- Succès : Le statut du champ
- Échec : undef

munin_readconfig_base
Lit le fichier de configuration, les fichiers du répertoire d'inclusion, et initialise des valeurs par défaut importantes qui sont facultatives.

Paramètres :
- $file: Nom du fichier munin.conf. S'il est omis, le nom de fichier par défaut est utilisé.

Retourne :
- Succès : Le hachage $config (également mis en cache dans le module)

- Échec : undef

- Échec : undef

munin_find_field
Recherche dans un hachage pour trouver des nœuds de hachage avec $field défini.

Paramètres :
- $hash: Référence vers un hachage à rechercher
- $field: Le nom du champ à rechercher, ou une expression régulière
- $avoid: [facultatif] Arrêter de parcourir plus loin si ce champ est trouvé

Retourne :
- Succès : Une référence vers un tableau des nœuds de hachage contenant $field.
- Échec : undef

- Succès : Contenu du champ
- Échec : $default s'il est défini, sinon undef
