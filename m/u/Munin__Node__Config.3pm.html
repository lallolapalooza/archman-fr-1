Munin::Node::Config(3pm) Documentation Perl fournie par la communauté Munin::Node::Config(3pm)

NOM

Munin::Node::Config - Conteneur de configuration de nœud singleton. Lit les fichiers de configuration.

SYNTAXE

$config = Munin::Node::Config->instance();
$config->parse_config_from_file('/etc/munin/munin-node.conf');
print $config->{fqdn}, "\n";

MÉTHODES

instance
$config = Munin::Node::Config->instance();

Retourne l'instance singleton de cette classe.

reinitialize
$config->reinitialize();

Supprime toutes les variables de configuration

$config->reinitialize(\%variables);

Supprime toutes les variables de configuration et réinitialise l'objet avec les valeurs de \%variables.

parse_config_from_file
$config->parse_config_from_file($filename);

Analyse la configuration du nœud munin à partir d'un fichier. Se termine si le fichier échoue aux vérifications de sécurité.

parse_config
$config->parse_config($io_handle);

Analyse la configuration du nœud munin à partir d'un descripteur de fichier.

process_plugin_configuration_files
$config->process_plugin_configuration_files();

Analyse tous les fichiers non ignorés dans le dossier de configuration des plugins.

parse_plugin_config_file
$config->parse_plugin_config_file($file);

Analyse la configuration du plugin dans $file.

parse_plugin_config
$config->parse_plugin_config($io_handle);

Analyse la configuration du plugin à partir d'un IO::Handle.

apply_wildcards
$config->apply_wildcards();

Applique le contenu de toute section de configuration de plugin générique aux plugins correspondants.
