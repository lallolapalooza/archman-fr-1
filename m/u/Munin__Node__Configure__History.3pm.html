Munin::Node::Configure::History(3pm) Documentation Perl Contribuée par l'Utilisateur Munin::Node::Configure::History(3pm)

NOM

Munin::Node::Configure::History - Filtrage des plugins basé sur la version de Munin avec laquelle ils ont été distribués pour la première fois.

SYNOPSIS

my $plugin = Munin::Node::Configure::History->new(
    newer        => '1.3.3',
    history_file => 'plugins/plugins.history',
);

MÉTHODES

new(%args)
Constructeur.

L'argument 'history_file' est requis et doit être le chemin vers le fichier d'historique des plugins. L'argument 'newer' est optionnel et doit être la version de la publication avant laquelle les plugins doivent être ignorés.

load()
Charge l'historique des plugins depuis history_file. Termine l'exécution en cas d'échec si 'newer' ne correspond pas à une publication valide ou si le fichier n'est pas lisible.
trop_ancien($plugin)
Prend un objet Munin::Node::Configure::Plugin. Renvoie false sauf si le plugin doit être ignoré, true sinon (c'est-à-dire si 'newer' n'était pas défini, si le plugin est contribué par l'utilisateur, etc.).
