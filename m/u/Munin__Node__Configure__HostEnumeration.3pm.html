NOM

Munin::Node::Configure::HostEnumeration - Prend une liste d'hôtes et retourne les IP correspondantes sous forme de quadruplets pointés.

SYNTAXE

@hosts = ('switch1', 'host1/24', '10.0.0.60/30');
foreach my $host (expand_hosts(@hosts)) {
    # ...
}

SOUS PROGRAMMES

expand_hosts
@expanded = expand_hosts(@list);

Prend une liste d'hôtes et retourne les IP correspondantes sous forme de quadruplets pointés.

Les éléments peuvent être spécifiés comme nom d'hôte ou IP en quadruplet pointé, avec ou sans masque de réseau.

Actuellement, seuls les adresses IPv4 sont supportées.
