NOM

munin-html - Un programme pour dessiner des pages html sur une installation Munin

SYNTAXE

munin-html [options]

OPTIONS

--service <service>
Compatibilité. Aucun effet.
--host <hôte>
Compatibilité. Aucun effet.
--nofork
Compatibilité. Aucun effet.
--config <fichier>
Utiliser <fichier> comme fichier de configuration. [/etc/munin/munin.conf]
--help
Afficher le message d'aide.
--[no]debug
Si défini, afficher les messages de débogage. [--nodebug]

DESCRIPTION

Munin-html fait partie du paquet Munin, qui est utilisé en combinaison avec le nœud Munin. Munin est un ensemble de programmes permettant de collecter des données à partir des nœuds Munin, de les graphique, de créer des pages html, et éventuellement d'avertir Nagios de toute valeur hors limite.

Munin-html crée les pages html.

FICHIERS

/etc/munin/munin.conf
/var/lib/munin/datafile
/var/log/munin/munin-html
/usr/share/munin/www/*
/run/munin/*

Veuillez signaler les autres bogues dans le traqueur de bogues sur http://munin-monitoring.org/.
