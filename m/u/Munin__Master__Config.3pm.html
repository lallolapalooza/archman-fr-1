NOM

Munin::Master::Config - Détient la configuration du maître.

MÉTHODES

instance
my $config = Munin::Master::Config->instance;

Renvoie l'instance de configuration singleton (éventuellement nouvellement créée).

set_value
$config->set_value($longkey, $value);

Définit une valeur dans la configuration, où $longkey est la valeur complète séparée par des ;:.

parse_config
$config->parse_config($io);

Remplit les champs de $config à partir du fichier de configuration référencé par le descripteur de fichier $io.

look_up
my $value = $config->look_up($key);

Recherche un groupe/hôte par une clé telle que "localdomain;localhost", etc. Si le chemin n'existe pas, il est créé avec la classe et autres attributs corrects.

La recherche s'arrête au nom de l'hôte. Si quelque chose manque en cours de route, undef est renvoyé.

get_groups_and_hosts
my $gah = $config->get_groups_and_hosts();

Renvoie tous les groupes et hôtes définis dans la configuration.

get_all_hosts
my $hosts = $config->get_all_hosts();

Renvoie une liste de tous les hôtes définis dans la configuration.

set
$config->set(\%attrs);

Définit les clés et les valeurs dans $config conformément à celles présentes dans %attrs.
