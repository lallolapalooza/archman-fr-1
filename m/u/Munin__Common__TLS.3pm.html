Munin::Common::TLS(3pm) Documentation Perl fournie par l'utilisateur Munin::Common::TLS(3pm)

NOM

Munin::Node::TLS - Classe de base abstraite implémentant le protocole STARTTLS

SYNOPSIS

Ne devrait pas être appelé directement. Voir le synopsis pour Munin::Common::TLSServer et Munin::Common::TLSClient.

MÉTHODES

new
my $tls = Munin::Common::TLSFoo->new({ # Remplacez Foo par Client ou Server
    # Attributs obligatoires :  
    logger      => \&une_fonction_logger,
    read_fd     => fileno($socket),
    read_func   => \&une_fonction_lecture_socket,
    write_fd    => fileno($socket),
    write_func  => \&une_fonction_lecture_socket,
    # Attributs optionnels                          PAR DEFAUT
    DEBUG              => 0,                       # 0
    tls_ca_cert        => "chemin/vers/cert_ca.pem",   # ''
    tls_cert           => "chemin/vers/cert.pem",      # ''
    tls_paranoia       => 1,                       # 0
    tls_priv           => "chemin/vers/cle_privee.pem",  # ''
    tls_vdepth         => 5,                       # 0
    tls_verify         => 1,                       # 0
});

Constructeur. Ne devrait pas être appelé directement. Ceci documente les attributs communs à Munin::Common::TLSServer et Munin::Common::TLSClient.

read
my $msg = $tls->read();

Lecture cryptée.

write
$tls->write($msg);

Écriture cryptée.

session_started
my $bool = $tls->session_started();

Retourne vrai si l'objet TLS est prêt à lire/écrire des données cryptées.
