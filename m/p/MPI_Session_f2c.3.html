MPI_SESSION_F2C(3) Open MPI MPI_SESSION_F2C(3)

MPI_Session_c2f, MPI_Session_f2c - Traduit un descripteur de session C en un descripteur de session de style INTEGER Fortran, ou vice versa.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Session_f2c(const MPI_Fint *f_session, MPI_Session *c_session)
int MPI_Session_c2f(const MPI_Session *c_session, MPI_Fint *f_session)

PARAMÈTRES

  • f_session: Objet de session MPI de style mpi INTEGER
  • c_session: Objet de session MPI de style C

DESCRIPTION

Ces deux procédures sont fournies en C pour convertir une session Fortran (qui est un tableau d'entiers) en une session C (qui est une structure), et vice versa. La conversion porte sur toutes les informations de session, y compris celles qui sont cachées. Autrement dit, aucune information de session n'est perdue lors de la conversion.

Lors de l'utilisation de MPI_Session_f2c(), si f_session est une session Fortran valide, alors MPI_Session_f2c() retourne dans c_session une session C valide avec le même contenu. Si f_session est la valeur Fortran de MPI_SESSION_NULL, ou si f_session n'est pas une session Fortran valide, alors l'appel est erroné.

Lors de l'utilisation de MPI_Session_c2f(), la conversion inverse est appliquée. Si c_session est MPI_SESSION_NULL, ou si c_session n'est pas une session C valide, alors l'appel est erroné.

NOTES

Ces fonctions ne sont disponibles qu'en C ; elles ne sont disponibles dans aucune des interfaces MPI Fortran.
