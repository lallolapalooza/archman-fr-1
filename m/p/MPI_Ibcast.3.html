MPI_Ibcast(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

MPI_IBCAST(3) Open MPI MPI_IBCAST(3)

MPI_Bcast, MPI_Ibcast - Diffuse un message du processus avec le rang root vers tous les autres processus du groupe.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Bcast(void *buffer, int count, MPI_Datatype datatype,
    int root, MPI_Comm comm)
int MPI_Ibcast(void *buffer, int count, MPI_Datatype datatype,
    int root, MPI_Comm comm, MPI_Request *request)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme: INCLUDE 'mpif.h'
MPI_BCAST(BUFFER, COUNT, DATATYPE, ROOT, COMM, IERROR)
    <type>  BUFFER(*)
    INTEGER COUNT, DATATYPE, ROOT, COMM, IERROR
MPI_IBCAST(BUFFER, COUNT, DATATYPE, ROOT, COMM, REQUEST, IERROR)
    <type>  BUFFER(*)
    INTEGER COUNT, DATATYPE, ROOT, COMM, REQUEST, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Bcast(buffer, count, datatype, root, comm, ierror)
    TYPE(*), DIMENSION(..) :: buffer
    INTEGER, INTENT(IN) :: count, root
    TYPE(MPI_Datatype), INTENT(IN) :: datatype
    TYPE(MPI_Comm), INTENT(IN) :: comm
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPI_Ibcast(buffer, count, datatype, root, comm, request, ierror)
    TYPE(*), DIMENSION(..), ASYNCHRONOUS :: buffer
    INTEGER, INTENT(IN) :: count, root
    TYPE(MPI_Datatype), INTENT(IN) :: datatype
    TYPE(MPI_Comm), INTENT(IN) :: comm
    TYPE(MPI_Request), INTENT(OUT) :: request
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETRES ENTRÉE/SORTIE

  • buffer: Adresse de départ du tampon (choix).
  • count: Nombre d'éléments dans le tampon (entier).
  • datatype: Type de données du tampon (handle).
  • root: Rang de la racine de diffusion (entier).
  • comm: Communicateur (handle).

PARAMETRES SORTIE

  • request: Requête (handle, non bloquant uniquement).
  • ierror: Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

MPI_Bcast diffuse un message du processus de rang root vers tous les processus du groupe, y compris lui-même. Il est appelé par tous les membres du groupe en utilisant les mêmes arguments pour comm et root. Au retour, le contenu du tampon de communication de la racine a été copié vers tous les processus.

Les types de données généraux et dérivés sont autorisés pour datatype. La signature de type de count et datatype sur n'importe quel processus doit être égale à la signature de type de count et datatype à la racine. Cela implique que la quantité de données envoyées doit être égale à la quantité reçue, pairwise entre chaque processus et la racine. MPI_Bcast et toutes les autres routines collectives de déplacement de données font cette restriction. Des mappings de types distincts entre l'expéditeur et le récepteur sont toujours autorisés.

Exemple : Diffusion de 100 entiers depuis le processus 0 vers tous les processus du groupe.

MPI_Comm comm;
int array[100];
int root=0;
//...
MPI_Bcast( array, 100, MPI_INT, root, comm);

Comme dans plusieurs de nos fragments de code exemples, nous supposons que certaines variables (comme comm dans l'exemple ci-dessus) ont été assignées avec des valeurs appropriées.

QUAND LE COMMUNICATEUR EST UN INTER-COMMUNICATEUR

Lorsque le communicateur est un inter-communicateur, le processus racine dans le premier groupe diffuse des données vers tous les processus du second groupe. Le premier groupe définit le processus racine. Ce processus utilise MPI_ROOT comme valeur de son argument root. Les processus restants utilisent MPI_PROC_NULL comme valeur de leur argument root. Tous les processus du second groupe utilisent le rang de ce processus racine dans le premier groupe comme valeur de leur argument root. Les tampons de réception des processus du second groupe doivent être cohérents avec le tampon d'envoi du processus racine du premier groupe.

NOTES

Cette fonction ne prend pas en charge l'option 'in-place'.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire, avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de Sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle Monde, ou l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme par tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus associés à la fenêtre ou au fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des Erreurs de la norme MPI-3.1 pour plus d'informations.
