MPI_T_pvar_get_info — Interroger les informations d'une variable de performance

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_T_pvar_get_info(int pvar_index, char *name, int *name_len,
                        int *verbosity, int *var_class, MPI_Datatype *datatype, MPI_T_enum *enumtype,
                        char *desc, int *desc_len, int *bind, int *readonly, int *continuous,
                        int *atomic)

PARAMETRES D'ENTREE

•
pvar_index: Index de la variable de performance à interroger.

PARAMETRES D'ENTREE/SORTIE

  • name_len: Longueur de la chaîne et/ou du tampon pour le nom.
  • desc_len: Longueur de la chaîne et/ou du tampon pour la description.

PARAMETRES DE SORTIE

  • name: Tampon pour renvoyer la chaîne contenant le nom de la variable de performance.
  • verbosity: Niveau de verbosité de cette variable.
  • var_class: Classe de la variable de performance.
  • datatype: Type de données MPI des informations stockées dans la variable de performance.
  • enumtype: Descripteur optionnel pour les informations d'énumération.
  • desc: Tampon pour renvoyer la chaîne contenant la description de la variable de performance.
  • bind: Type d'objet MPI auquel cette variable doit être liée.
  • readonly: Indicateur indiquant si la variable peut être écrite/réinitialisée.
  • continuous: Indicateur indiquant si la variable peut être démarrée et arrêtée ou si elle est active en continu.
  • atomic: Indicateur indiquant si la variable peut être lue et réinitialisée de manière atomique.

DESCRIPTION

MPI_T_pvar_get_info peut être utilisée pour interroger les informations d'une variable de performance. La fonction renvoie la verbosité, la classe, le type de données, le type d'énumération et la liaison de la variable de contrôle interrogée dans les arguments verbosity, var_class, datatype, enumtype et bind respectivement. Les indicateurs indiquant si la variable est en lecture seule, continue ou atomique sont renvoyés dans readonly, continuous et atomic en conséquence. Voir la section 14.3.7 de MPI-3 pour plus d'informations. Voir la page de manuel de MPI_T_cvar_get_info pour des informations sur la verbosité des variables.

CLASSE DE VARIABLE

Les variables de performance sont classées en catégories qui décrivent leur valeur initiale, leurs types valides et leur comportement. La classe renvoyée dans le paramètre var_class peut être l'une des suivantes :

  • MPI_T_PVAR_CLASS_STATE: La variable représente un ensemble d'états discrets qui peuvent être décrits par un énumérateur. Les variables de cette classe doivent être représentées par un MPI_INT. La valeur de départ est l'état actuel de la variable.
  • MPI_T_PVAR_CLASS_LEVEL: La variable représente le niveau d'utilisation actuel d'une ressource. Les variables de cette classe doivent être représentées par un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG ou MPI_DOUBLE. La valeur de départ est le niveau d'utilisation actuel de la ressource.
  • MPI_T_PVAR_CLASS_SIZE: La variable représente la taille fixe d'une ressource. Les variables de cette classe sont représentées par un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG ou MPI_DOUBLE. La valeur de départ est la taille actuelle de la ressource.
  • MPI_T_PVAR_CLASS_PERCENTAGE: La variable représente le niveau d'utilisation en pourcentage actuel d'une ressource. Les variables de cette classe sont représentées par un MPI_DOUBLE. La valeur de départ est le niveau d'utilisation en pourcentage actuel de la ressource.
  • MPI_T_PVAR_CLASS_HIGHWATERMARK: La variable représente le pic (high watermark) d'utilisation d'une ressource. Les variables de cette classe sont représentées par un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG ou MPI_DOUBLE. La valeur de départ est l'utilisation actuelle de la ressource.
  • MPI_T_PVAR_CLASS_LOWWATERMARK: La variable représente le creux (low watermark) d'utilisation d'une ressource. Les variables de cette classe sont représentées par un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG ou MPI_DOUBLE. La valeur de départ est l'utilisation actuelle de la ressource.
  • MPI_T_PVAR_CLASS_COUNTER: La variable représente un compte du nombre d'occurrences d'un événement spécifique. Les variables de cette classe sont représentées par un MPI_UNSIGNED, MPI_UNSIGNED_LONG ou MPI_UNSIGNED_LONG_LONG. La valeur de départ est 0.
  • MPI_T_PVAR_CLASS_AGGREGATE: La variable représente une valeur agrégée qui représente une somme d'arguments traités lors d'un événement spécifique. Les variables de cette classe sont représentées par un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG ou MPI_DOUBLE. La valeur de départ est 0.
  • MPI_T_PVAR_CLASS_TIMER: La variable représente le temps agrégé passé par l'implémentation MPI lors du traitement d'un événement, d'un type d'événement, ou d'une section de code. Les variables de cette classe sont représentées par un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG ou MPI_DOUBLE. Si la variable est représentée par un MPI_DOUBLE, les unités seront les mêmes que celles utilisées par MPI_Wtime(). La valeur de départ est 0.
  • MPI_T_PVAR_CLASS_GENERIC: La variable ne rentre dans aucune autre classe. Peut être représentée par un type pris en charge par l'interface d'informations de l'outil MPI (voir DATATYPE). La valeur de départ est spécifique à la variable.

Pour plus d'informations, voir la section 14.3.7 de MPI-3.

TYPE DE DONNEES

Le type de données renvoyé par MPI_T_pvar_get_info est limité à l'un des types de données suivants : MPI_INT, MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG, MPI_COUNT, MPI_CHAR et MPI_DOUBLE. Pour plus d'informations sur les types de données dans l'interface d'informations des outils MPI, voir la section 14.3.5 de MPI-3.

LIAISON

Les variables de performance peuvent être liées à un objet MPI. La liaison renvoyée dans le paramètre bind peut être l'une des suivantes :

  • MPI_T_BIND_NO_OBJECT: Aucun objet
  • MPI_T_BIND_MPI_COMM: Communicateur MPI
  • MPI_T_BIND_MPI_DATATYPE: Type de données MPI
  • MPI_T_BIND_MPI_ERRHANDLER: Gestionnaire d'erreurs MPI
  • MPI_T_BIND_MPI_FILE: Handle de fichier MPI
  • MPI_T_BIND_MPI_GROUP: Groupe MPI
  • MPI_T_BIND_MPI_OP: Opérateur de réduction MPI
  • MPI_T_BIND_MPI_REQUEST: Requête MPI
  • MPI_T_BIND_MPI_WIN: Fenêtre MPI pour la communication unidirectionnelle
  • MPI_T_BIND_MPI_MESSAGE: Objet message MPI
  • MPI_T_BIND_MPI_INFO: Objet info MPI

Pour plus d'informations, voir la section 14.3.2 de MPI-3.

NOTES

Cette fonction d'interface d'outils MPI renvoie deux chaînes de caractères. Cette fonction prend deux arguments pour chaque chaîne : un tampon pour stocker la chaîne, et une longueur qui doit initialement spécifier la taille du tampon. Si la longueur fournie est n, alors cette fonction copiera au maximum n - 1 caractères de la chaîne dans le tampon correspondant et définira la longueur sur le nombre de caractères copiés - 1. Si l'argument de longueur est NULL ou si la valeur spécifiée dans la longueur est 0, le tampon de chaîne correspondant est ignoré et la chaîne n'est pas renvoyée. Pour plus d'informations, voir la section 14.3.3 de MPI-3.

ERREURS

MPI_T_pvar_get_info échouera si :

  • MPI_T_ERR_NOT_INITIALIZED: L'interface des outils MPI n'est pas initialisée
  • MPI_T_ERR_INVALID_INDEX: L'index de la variable de performance est invalide
