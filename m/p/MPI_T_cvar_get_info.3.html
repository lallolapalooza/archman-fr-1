MPI_T_cvar_get_info — Interroger les informations d'une variable de compteur

Syntaxe

Syntaxe C

#include <mpi.h>
int MPI_T_cvar_get_info(int cvar_index, char *name, int *name_len,
                        int *verbosity, MPI_Datatype *datatype, MPI_T_enum *enumtype,
                        const *desc, int *desc_len, int *bind, int *scope)

Paramètres d'entrée

•
cvar_index: Index de la variable de compteur à interroger.

Paramètres d'entrée/sortie

  • name_len: Taille de la chaîne et/ou du tampon pour le nom.
  • desc_len: Taille de la chaîne et/ou du tampon pour la description.

Paramètres de sortie

  • name: Tampon pour retourner la chaîne de nom de la variable de compteur.
  • verbosity: Niveau de verbosité de cette variable.
  • datatype: Type de données MPI des informations stockées dans la variable de compteur.
  • enumtype: Descripteur optionnel d'informations d'énumération.
  • desc: Tampon pour retourner la chaîne de description de la variable de compteur.
  • bind: Type d'objet MPI auquel cette variable doit être liée.
  • scope: Portée dans laquelle des modifications peuvent être apportées à cette variable.

Description

MPI_T_cvar_get_info peut être utilisée pour interroger les informations d'une variable de compteur. La fonction retourne le niveau de verbosité, le type de données MPI, le type d'énumération, la liaison et la portée de la variable interrogée dans les arguments verbosity, datatype, enumtype, bind et scope, respectivement. Les variables de compteur dans Open MPI sont les mêmes que les paramètres MCA.

Verbosité

Comme Open MPI expose un très grand nombre de paramètres MCA (variables de compteur), les variables de compteur sont classées en neuf niveaux de verbosité correspondant au niveau équivalent ompi_info. Les neuf niveaux sont (par ordre croissant) :

1.
MPI_T_VERBOSITY_USER_BASIC : informations de base intéressantes pour les utilisateurs
2.
MPI_T_VERBOSITY_USER_DETAIL : informations détaillées intéressantes pour les utilisateurs
3.
MPI_T_VERBOSITY_USER_ALL : toutes les autres informations intéressantes pour les utilisateurs
4.
MPI_T_VERBOSITY_TUNER_BASIC : informations de base nécessaires au réglage
5.
MPI_T_VERBOSITY_TUNER_DETAIL : informations détaillées nécessaires au réglage
6.
MPI_T_VERBOSITY_TUNER_ALL : toutes les autres informations nécessaires au réglage
7.
MPI_T_VERBOSITY_MPIDEV_BASIC : informations de base pour les développeurs MPI
8.
MPI_T_VERBOSITY_MPIDEV_DETAIL : informations détaillées pour les développeurs MPI
9.
MPI_T_VERBOSITY_MPIDEV_ALL : toutes les autres informations pour les développeurs MPI

Pour plus d'informations, voir MPI-3 section 14.3.1.

Type de données

Le type de données retourné par MPI_T_cvar_get_info est limité à l'un des types de données suivants : MPI_INT, MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG, MPI_COUNT, MPI_CHAR, et MPI_DOUBLE. Pour plus d'informations sur les types de données dans MPI_T, voir MPI-3 section 14.3.5.

Portée

La portée décrit quand et comment des modifications peuvent être apportées à une variable de compteur. Selon MPI-3 section 14.3.6, la portée peut être l'une des suivantes :

  • MPI_T_SCOPE_CONSTANT : lecture seule, valeur constante
  • MPI_T_SCOPE_READONLY : lecture seule, ne peut pas être écrite, mais peut changer
  • MPI_T_SCOPE_LOCAL : peut être écrite, l'écriture est une opération locale
  • MPI_T_SCOPE_GROUP : peut être écrite, doit être effectuée dans un groupe de processus, tous les processus d'un groupe doivent avoir des valeurs cohérentes
  • MPI_T_SCOPE_GROUP_EQ : peut être écrite, doit être effectuée dans un groupe de processus, tous les processus d'un groupe doivent avoir la même valeur
  • MPI_T_SCOPE_TODO : peut être écrite, doit être effectuée sur tous les processus, tous les processus connectés doivent avoir des valeurs cohérentes
  • MPI_T_SCOPE_TODO_EQ : peut être écrite, doit être effectuée sur tous les processus, tous les processus connectés doivent avoir la même valeur

Pour plus d'informations, voir MPI-3 section 14.3.6 Tableau 14.4.

Notes

Cette fonction d'interface d'outillage MPI retourne deux chaînes. Cette fonction prend deux arguments pour chaque chaîne : un tampon pour stocker la chaîne et une longueur qui doit initialement spécifier la taille du tampon. Si la valeur passée est n, cette fonction copiera au maximum n-1 caractères de la chaîne dans le tampon correspondant et définira la longueur sur le nombre de caractères copiés - 1. Si l'argument de longueur est NULL ou si la valeur spécifiée est 0, le tampon correspondant est ignoré et la chaîne n'est pas retournée.

Open MPI ne prend actuellement pas en charge la liaison des variables de compteur à des objets MPI.

Erreurs

MPI_T_cvar_get_info échouera si :

  • MPI_T_ERR_NOT_INITIALIZED : l'interface d'outillage MPI n'est pas initialisée
  • MPI_T_ERR_INVALID_INDEX : l'index de la variable de compteur est invalide
