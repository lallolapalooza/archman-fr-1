MPI_COMM_REMOTE_SIZE(3) Open MPI MPI_COMM_REMOTE_SIZE(3)

MPI_Comm_remote_size — Détermine la taille du groupe distant associé à un intercommunicateur.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Comm_remote_size(MPI_Comm comm, int *size)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_COMM_REMOTE_SIZE(COMM, SIZE, IERROR)
     INTEGER COMM, SIZE, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Comm_remote_size(comm, size, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, INTENT(OUT) :: size
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRE D'ENTRÉE

•
comm: Communicateur (descripteur).

PARAMÈTRES DE SORTIE

  • size: Nombre de processus dans le groupe distant de comm (entier).
  • ierror: Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

MPI_Comm_remote_size détermine la taille du groupe distant associé à un intercommunicateur.

Les accesseurs d'intercommunicateur (MPI_Comm_test_inter, MPI_Comm_remote_size, MPI_Comm_remote_group) sont toutes des opérations locales.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI courant associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou via l'argument CLI mpi_initial_errhandler pour mpiexec ou la clé d'information pour MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'abandon de tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
