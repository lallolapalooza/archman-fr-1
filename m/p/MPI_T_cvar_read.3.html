MPI_T_cvar_read — Lire la valeur d'une variable de contrôle

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_T_cvar_read(MPI_T_cvar_handle handle, const void *buf)

PARAMÈTRES ENTRANTS

  • handle : Handle de la variable de contrôle à lire.
  • buf : Adresse initiale de l'emplacement de stockage pour la valeur de la variable.

DESCRIPTION

MPI_T_cvar_read lit la valeur de la variable de contrôle identifiée par le handle spécifié dans handle et stocke la valeur dans le tampon pointé par buf. L'appelant doit s'assurer que le tampon pointé par buf est suffisamment grand pour contenir la valeur entière de la variable de contrôle.

ERREURS

MPI_T_cvar_read échouera si :

  • MPI_T_ERR_NOT_INITIALIZED : L'interface des outils MPI n'est pas initialisée
  • MPI_T_ERR_INVALID_HANDLE : Le handle est invalide

VOIR AUSSI :

  • MPI_T_cvar_handle_alloc
  • MPI_T_cvar_get_info
