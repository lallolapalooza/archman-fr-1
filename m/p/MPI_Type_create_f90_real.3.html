MPI_TYPE_CREATE_F90_REAL(3) Open MPI MPI_TYPE_CREATE_F90_REAL(3) 
MPI_Type_create_f90_real - Renvoie un type de données MPI réel borné

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Type_create_f90_real(int p, int r, MPI_Datatype *newtype)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_TYPE_CREATE_F90_REAL (P, R, NEWTYPE, IERROR)
     INTEGER P, R, NEWTYPE, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Type_create_f90_real(p, r, newtype, ierror)
     INTEGER, INTENT(IN) :: p, r
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES ENTRANTS

  • p: Précision, en chiffres décimaux (entier).
  • r: Plage d'exposants décimaux (entier).

PARAMÈTRES SORTANTS

  • newtype: Nouveau type de données (descripteur).
  • ierror: Fortran uniquement : statut d'erreur (entier).

DESCRIPTION

Cette fonction fournit un moyen de déclarer des types de données MPI REAL paramétrés par KIND. Les arguments sont interprétés de manière similaire à la fonction F90 SELECTED_REAL_KIND. Les paramètres p et r doivent être des entiers scalaires. L'argument p représente le niveau de précision numérique requis, en chiffres décimaux. Le paramètre r indique la plage d'exposants souhaitée : le type de données renvoyé aura au moins un exposant compris entre +r et -r (inclus).

Soit p, soit r, mais pas les deux, peut être omis des appels à SELECTED_REAL_KIND. De même, l'un des arguments de MPI_Type_create_f90_real peut être défini sur MPI_UNDEFINED.

NOTES

Il est erroné de fournir des valeurs pour p et r non prises en charge par le compilateur.

La fonction Fortran SELECTED_REAL_KIND associe un grand nombre de paires (p,r) à un nombre beaucoup plus petit de paramètres KIND pris en charge par le compilateur. Les paramètres KIND ne sont pas spécifiés par le langage et ne sont pas portables. Du point de vue du langage, les variables du même type de base et du même paramètre KIND sont équivalentes, même si leurs paramètres KIND ont été générés par des arguments (p,r) différents pour SELECTED_REAL_KIND. Cependant, afin de faciliter l'interopérabilité dans un environnement hétérogène, l'équivalence est définie plus strictement pour les types de données renvoyés par MPI_Type_create_f90_real. Deux types de données MPI, chacun généré par cette fonction, correspondront si et seulement s'ils ont des valeurs identiques pour p et r.

L'interaction entre les types de données renvoyés par cette fonction et la représentation de données external32 - utilisée par MPI_Pack_external, MPI_Unpack_external et de nombreuses fonctions MPI_File - est subtile. La représentation external32 des types de données renvoyés est la suivante.

if (p > 33) and/or (r > 4931):
        external32 size = n/a (undefined)
else if (p > 15) and/or (r > 307):
        external32 size = 16
else if (p > 6) and/or (r > 37):
        external32 size = 8
else:
        external32 size = 4

Si la représentation external32 d'un type de données est indéfinie, il en va de même pour les résultats de l'utilisation de ce type de données dans des opérations qui nécessitent le format external32. Il faut veiller à ne pas utiliser des types de données incompatibles indirectement, par exemple, en tant que partie d'un autre type de données ou via un type de données dupliqué, dans ces fonctions.

Si une variable est déclarée en spécifiant une valeur KIND non défaut qui n'a pas été obtenue avec SELECTED_REAL_KIND (c'est-à-dire que p et/ou r sont inconnus), la seule façon d'obtenir un type de données MPI correspondant est d'utiliser les fonctions MPI_Sizeof et MPI_Type_match_size.

ERREURS

Presque toutes les routines MPI renvoient une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de Sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt de tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort était appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort était appelé sur un communicateur contenant le groupe des processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'arrête que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
