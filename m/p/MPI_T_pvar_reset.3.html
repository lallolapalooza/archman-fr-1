MPI_T_pvar_reset — Réinitialiser la valeur d'une variable de performance

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_T_pvar_reset(MPI_T_pvar_session session, MPI_T_pvar_handle handle)

PARAMÈTRES D'ENTRÉE

  • session: Session d'expérience de performance.
  • handle: Handle de variable de performance ou MPI_T_PVAR_ALL_HANDLES.

DESCRIPTION

MPI_T_pvar_reset met la variable de performance spécifiée par le handle dans handle à sa valeur initiale. La valeur spéciale MPI_T_PVAR_ALL_HANDLES peut être passée dans handle pour réinitialiser tous les handles en lecture-écriture dans la session spécifiée dans session.

ERREURS

MPI_T_pvar_reset échouera si :

  • MPI_T_ERR_NOT_INITIALIZED : L'interface des outils MPI n'est pas initialisée
  • MPI_T_ERR_INVALID_HANDLE : Le handle est invalide
  • MPI_T_ERR_INVALID_SESSION : L'argument session n'est pas une session valide
  • MPI_T_ERR_PVAR_NO_WRITE : La variable ne peut pas être réinitialisée
