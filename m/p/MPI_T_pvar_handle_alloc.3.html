MPI_T_PVAR_HANDLE_ALLOC(3) Open MPI MPI_T_PVAR_HANDLE_ALLOC(3)

MPI_T_pvar_handle_alloc, MPI_T_pvar_handle_free - Alloue/libère des descripteurs de variables de performance MPI

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_T_pvar_handle_alloc(int session, int pvar_index, void *obj_handle,
                            MPI_T_pvar_handle *handle, int *count)
int MPI_T_pvar_handle_free(int session, MPI_T_pvar_handle *handle)

DESCRIPTION

MPI_T_pvar_handle_alloc lie la variable de performance spécifiée par pvar_index à l'objet MPI spécifié par obj_handle dans la session identifiée par le paramètre session. L'objet est passé dans l'argument obj_handle comme une adresse vers une variable locale qui stocke le descripteur de l'objet. Si MPI_T_pvar_get_info retourne MPI_T_BIND_NO_OBJECT comme liaison pour la variable, l'argument obj_handle est ignoré. Le descripteur alloué pour référencer la variable est retourné dans l'argument handle. Après un retour réussi, count contient le nombre d'éléments (du type de données retourné par un appel précédent à MPI_T_pvar_get_info) utilisés pour représenter cette variable.

La valeur de pvar_index doit être comprise entre 0 et num_pvar - 1, où num_pvar est le nombre de variables de performance disponibles tel que déterminé par un appel précédent à MPI_T_pvar_get_num. Le type de l'objet MPI auquel il fait référence doit être cohérent avec le type retourné dans l'argument de liaison lors d'un appel précédent à MPI_T_pvar_get_info.

MPI_T_pvar_handle_free libère un descripteur alloué par MPI_T_pvar_handle_alloc et définit l'argument handle à MPI_T_PVAR_HANDLE_NULL.

ERREURS

MPI_T_pvar_handle_alloc échouera si :

  • MPI_T_ERR_NOT_INITIALIZED : L'interface MPI Tools n'est pas initialisée
  • MPI_T_ERR_INVALID_INDEX : L'index de la variable de performance est invalide
  • MPI_T_ERR_OUT_OF_HANDLES : Plus aucun descripteur n'est disponible

MPI_T_pvar_handle_free échouera si :

  • MPI_T_ERR_NOT_INITIALIZED : L'interface MPI Tools n'est pas initialisée
  • MPI_T_ERR_INVALID_HANDLE : Le descripteur est invalide ou l'argument de descripteur passé n'est pas associé à l'argument de session

  • MPI_T_pvar_get_num
