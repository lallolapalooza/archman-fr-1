MPI_Status_set_elements(3)

Paquet: openmpi

MPI_Status_set_elements(3) Open MPI MPI_Status_set_elements(3)

MPI_Status_set_elements, MPI_Status_set_elements_x - Modifie la partie opaque de status pour permettre à MPI_Get_elements de retourner count.

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_Status_set_elements(MPI_Status *status, MPI_Datatype datatype, int count)
int MPI_Status_set_elements_x(MPI_Status *status, MPI_Datatype datatype, MPI_Count count)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_STATUS_SET_ELEMENTS(STATUS, DATATYPE, COUNT, IERROR)
     INTEGER STATUS(MPI_STATUS_SIZE), DATATYPE, COUNT, IERROR
MPI_STATUS_SET_ELEMENTS_X(STATUS, DATATYPE, COUNT, IERROR)
     INTEGER STATUS(MPI_STATUS_SIZE), DATATYPE
        INTEGER(KIND=MPI_COUNT_KIND) COUNT
        INTEGER IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Status_set_elements(status, datatype, count, ierror)
     TYPE(MPI_Status), INTENT(INOUT) :: status
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER, INTENT(IN) :: count
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPI_Status_set_elements_x(status, datatype, count, ierror)
     TYPE(MPI_Status), INTENT(INOUT) :: status
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER(KIND = MPI_COUNT_KIND), INTENT(IN) :: count
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRE D'ENTRÉE/SORTIE

•
status : Statut à associer avec count (status).

PARAMÈTRES D'ENTRÉE

  • datatype : Type de données associé avec count (handle).
  • count : Nombre d'éléments à associer avec status (entier).

PARAMÈTRE DE SORTIE

•
ierror : Statut d'erreur uniquement en Fortran : Code d'erreur (entier).

DESCRIPTION

MPI_Status_set_elements modifie la partie opaque de status de telle sorte qu'un appel à MPI_Get_elements ou MPI_Get_elements_x retourne count. MPI_Get_count retournera une valeur compatible.

Un appel ultérieur à MPI_Get_count(status, datatype, count), MPI_Get_elements(status, datatype, count) ou MPI_Get_elements_x(status, datatype, count) doit utiliser un argument de type de données qui a la même signature que l'argument de type de données utilisé dans l'appel à MPI_Status_set_elements.*

NOTES

Les utilisateurs doivent être avertis de ne pas réutiliser les champs de statut pour des valeurs en dehors de ce qui est prévu. Cela peut conduire à des résultats inattendus lors de l'utilisation de l'objet de statut. Par exemple, appeler MPI_Get_elements peut provoquer une erreur si la valeur est hors plage, ou une telle erreur pourrait ne pas être détectée. L'argument extra_state fourni avec une requête généralisée peut être utilisé pour renvoyer des informations qui n'appartiennent logiquement pas à l'état. De plus, modifier les valeurs dans un état qui a été réglé en interne par MPI, tel que MPI_Recv, peut entraîner des résultats imprévisibles et est fortement déconseillé.

ERREURS

La plupart des routines MPI renvoient une valeur d'erreur ; dans les routines C, le résultat est la valeur de retour de la fonction et dans les routines Fortran, le dernier argument.

Avant de renvoyer la valeur d'erreur, le gestionnaire d'erreurs actuel associé à l'objet de communication (par exemple, le communicateur, la fenêtre, le fichier) est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, l'appel est considéré comme associé à MPI_COMM_SELF et le gestionnaire d'erreurs correspondant est appelé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le modèle de Sessions est utilisé exclusivement), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle Monde, ou l'argument mpi_initial_errhandler de mpiexec ou la clé info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. S'il n'y a pas d'autre gestionnaire d'erreurs approprié, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et MPI_ERRORS_ABORT pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs par défaut qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL : Arrête tous les processus MPI connectés.
  • MPI_ERRORS_ABORT : Gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est invoqué sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est invoqué sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est invoqué sur une session, il arrête uniquement le processus local.
  • MPI_ERRORS_RETURN : Renvoie le code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler et MPI_Comm_set_errhandler
  • MPI_File_create_errhandler et MPI_File_set_errhandler
  • MPI_Session_create_errhandler et MPI_Session_set_errhandler ou dans MPI_Session_init
  • MPI_Win_create_errhandler et MPI_Win_set_errhandler

Remarque : MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section sur la gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
