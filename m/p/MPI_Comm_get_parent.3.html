MPI_COMM_GET_PARENT(3) Open MPI MPI_COMM_GET_PARENT(3)

MPI_Comm_get_parent — Retourne le communicateur parent de l'intercommunicateur du processus lancé.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Comm_get_parent(MPI_Comm *parent)

Syntaxe Fortran

USE MPI
! Ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_COMM_GET_PARENT(PARENT, IERROR)
     INTEGER PARENT, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Comm_get_parent(parent, ierror)
     TYPE(MPI_Comm), INTENT(OUT) :: parent
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES DE SORTIE

  • parent : Le communicateur parent (handle).
  • ierror : Uniquement Fortran : Statut d'erreur (entier).

DESCRIPTION

Si un processus a été démarré avec MPI_Comm_spawn ou MPI_Comm_spawn_multiple, MPI_Comm_get_parent retourne l'intercommunicateur “parent” du processus courant. Cet intercommunicateur parent est créé implicitement dans MPI_Init et est le même intercommunicateur retourné par l'appel de lancement effectué par le parent.

Si le processus n'a pas été lancé, MPI_Comm_get_parent retourne MPI_COMM_NULL.

Après que le communicateur parent a été libéré ou déconnecté, MPI_Comm_get_parent retourne MPI_COMM_NULL.

NOTES

MPI_Comm_get_parent retourne un handle vers un seul intercommunicateur. Appeler MPI_Comm_get_parent une seconde fois retourne un handle vers le même intercommunicateur. Libérer le handle avec MPI_Comm_disconnect ou MPI_Comm_free invalidera d'autres références à l'intercommunicateur (en le rendant dangling). Notez qu'appeler MPI_Comm_free sur le communicateur parent n'est pas utile.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C en tant que résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreur MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreur MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de Sessions), l'erreur déclenche le gestionnaire d'erreur initial. Le gestionnaire d'erreur initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou via l'argument de ligne de commande mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreur approprié n'a été défini, alors le gestionnaire d'erreur MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreur MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'abandon du programme par tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, il n'abandonne que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
