MPI_Type_create_keyval(3) Open MPI MPI_Type_create_keyval(3)

MPI_Type_create_keyval génère une nouvelle clé d'attribut pour le cache des types de données.

Syntaxe

Syntaxe C

#include <mpi.h>
int MPI_Type_create_keyval(MPI_Type_copy_attr_function *type_copy_attr_fn,
     MPI_Type_delete_attr_function *type_delete_attr_fn,
     int *type_keyval, void *extra_state)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme: INCLUDE 'mpif.h'
MPI_TYPE_CREATE_KEYVAL(TYPE_COPY_ATTR_FN, TYPE_DELETE_ATTR_FN,
             TYPE_KEYVAL, EXTRA_STATE, IERROR)
     EXTERNAL TYPE_COPY_ATTR_FN, TYPE_DELETE_ATTR_FN
     INTEGER TYPE_KEYVAL, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) EXTRA_STATE

Syntaxe Fortran 2008

USE mpi_f08
MPI_Type_create_keyval(type_copy_attr_fn, type_delete_attr_fn, type_keyval,
             extra_state, ierror)
     PROCEDURE(MPI_Type_copy_attr_function) :: type_copy_attr_fn
     PROCEDURE(MPI_Type_delete_attr_function) :: type_delete_attr_fn
     INTEGER, INTENT(OUT) :: type_keyval
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: extra_state
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Paramètres d'entrée

  • type_copy_attr_fn: Fonction de rappel pour type_keyval (fonction).
  • type_delete_attr_fn: Fonction de suppression de rappel pour type_keyval (fonction).
  • extra_state: État supplémentaire pour les fonctions de rappel.

Paramètres de sortie

  • type_keyval: Clé d'accès future (entier).
  • ierror: Fortran uniquement : code d'erreur (entier).

Description

MPI_Type_create_keyval génère une nouvelle clé d'attribut pour le cache des types de données. Cette routine remplace partiellement MPI_Keyval_create.

L'argument type_copy_attr_fn peut être spécifié comme MPI_TYPE_NULL_COPY_FN ou MPI_TYPE_DUP_FN depuis C ou Fortran. MPI_TYPE_NULL_COPY_FN est une fonction qui ne retourne que flag = 0 et MPI_SUCCESS. MPI_TYPE_DUP_FN est une fonction de copie simple qui définit flag = 1, renvoie la valeur de attribute_val_in dans attribute_val_out et renvoie MPI_SUCCESS.

L'argument type_delete_attr_fn peut être spécifié comme MPI_TYPE_NULL_DELETE_FN depuis C ou Fortran. MPI_TYPE_NULL_DELETE_FN est une fonction qui ne fait rien d'autre que de renvoyer MPI_SUCCESS. Les fonctions de rappel C sont:

typedef int MPI_Type_copy_attr_function(MPI_Datatype oldtype,
            int type_keyval, void *extra_state, void *attribute_val_in,
            void *attribute_val_out, int *flag);
typedef int MPI_Type_delete_attr_function(MPI_Datatype type, int type_keyval,
             void *attribute_val, void *extra_state);

Les fonctions de rappel Fortran sont:

SUBROUTINE TYPE_COPY_ATTR_FN(OLDTYPE, TYPE_KEYVAL, EXTRA_STATE,
             ATTRIBUTE_VAL_IN, ATTRIBUTE_VAL_OUT, FLAG, IERROR)
    INTEGER OLDTYPE, TYPE KEYVAL, IERROR
    INTEGER(KIND=MPI_ADDRESS_KIND) EXTRA_STATE,
        ATTRIBUTE_VAL_IN, ATTRIBUTE_VAL_OUT
    LOGICAL FLAG
SUBROUTINE TYPE_DELETE_ATTR_FN(TYPE, TYPE_KEYVAL, ATTRIBUTE_VAL, EXTRA_STATE,
             IERROR)
    INTEGER TYPE, TYPE_KEYVAL, IERROR
    INTEGER(KIND=MPI_ADDRESS_KIND) ATTRIBUTE VAL, EXTRA_STATE

Erreurs

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C la retournent en tant que résultat de fonction, les routines Fortran la retournent dans le dernier paramètre.

Le gestionnaire d'erreurs MPI actif associé à l'objet de communication (par exemple, le communicateur, la fenêtre, le fichier) est appelé avant le retour de la valeur d'erreur. Si un appel MPI n'a pas d'objet de communication associé, l'appel est considéré comme attaché à MPI_COMM_SELF et le gestionnaire d'erreurs MPI approprié sera appelé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire après MPI_Init/MPI_Init_thread, ou lorsqu'il est utilisé exclusivement dans le modèle de session), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être défini en utilisant MPI_Comm_set_errhandler sur le modèle mondial, ou spécifié dans mpiexec ou dans une clé d'information via le paramètre CLI mpi_initial_errhandler. Si aucun autre gestionnaire d'erreurs approprié n'est défini, MPI_ERRORS_RETURN sera appelé pour les fonctions d'E/S MPI et MPI_ERRORS_ABORT pour les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL fait en sorte que le programme termine tous les processus MPI connectés.
  • MPI_ERRORS_ABORT est un gestionnaire d'erreurs qui peut être appelé sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il se comporte comme un appel à MPI_Abort sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il se comporte comme un appel à MPI_Abort sur le communicateur contenant les groupes de processus correspondants. S'il est appelé sur une session, il termine uniquement le processus local.
  • MPI_ERRORS_RETURN renvoie un code d'erreur à l'application.

Les applications MPI peuvent également définir leur propre gestionnaire d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas que les programmes MPI puissent continuer après une erreur.

Voir la liste des codes d'erreur MPI dans la page man MPI.

Voir la section sur la gestion des erreurs dans la norme MPI-3.1.
