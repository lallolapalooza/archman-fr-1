MPI_Dims_create(3) Open MPI MPI_Dims_create(3)

MPI_Dims_create — Crée une répartition de processeurs dans un espace de coordonnées cartésiennes.

Syntaxe

Syntaxe C

#include <mpi.h>
int MPI_Dims_create(int nnodes, int ndims, int dims[])

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_DIMS_CREATE(NNODES, NDIMS, DIMS, IERROR)
     INTEGER NNODES, NDIMS, DIMS(*), IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Dims_create(nnodes, ndims, dims, ierror)
     INTEGER, INTENT(IN) :: nnodes, ndims
     INTEGER, INTENT(INOUT) :: dims(ndims)
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Paramètres d'entrée

  • nnodes: Nombre de nœuds dans une grille de coordonnées (entier).
  • ndims: Nombre de dimensions cartésiennes (entier).

Paramètre d'entrée/sortie

•
dims: Tableau d'entiers de taille ndims spécifiant le nombre de nœuds dans chaque dimension.

Paramètre de sortie

•
ierror: En Fortran uniquement : code d'état d'erreur (entier).

Description

Pour les topologies cartésiennes, la fonction MPI_Dims_create aide l'utilisateur à sélectionner une répartition équilibrée des processus par direction de coordonnées, en fonction du nombre de processus dans le groupe à équilibrer et des contraintes que l'utilisateur peut spécifier. Une application courante est de diviser tous les processus (la taille du groupe de MPI_COMM_WORLD) en une topologie n-dimensionnelle.

Les valeurs du tableau dims sont définies pour décrire une grille de coordonnées cartésiennes avec ndims dimensions et un total de nnodes nœuds. Les valeurs sont définies de manière aussi proche que possible, en utilisant un algorithme de divisibilité approprié. L'appelant peut encore contraindre le comportement de cette routine en spécifiant des éléments du tableau dims. Si dims[i] est défini sur un nombre positif, la routine ne modifiera pas le nombre de nœuds dans la direction i ; seules les entrées où dims[i] = 0 sont modifiées par l'appelant.

Les valeurs négatives de dims[i] sont des erreurs. Une erreur se produit si nnodes n'est pas divisible par ((pi) / (i, dims[i] != 0)).

Pour dims[i] défini par l'appelant, dims[i] est trié dans un ordre non croissant. Le tableau dims convient pour être utilisé comme entrée pour la routine MPI_Cart_create. MPI_Dims_create est locale.

Exemple :

dims
avant                                     dims
appel            fonction                  après
-----------------------------------------------------
(0,0)           MPI_Dims_create(6, 2, dims)     (3,2)
(0,0)           MPI_Dims_create(7, 2, dims)     (7,1)
(0,3,0)         MPI_Dims_create(6, 3, dims)     (2,3,1)
(0,3,0)         MPI_Dims_create(7, 3, dims)     appel erroné
------------------------------------------------------

Erreurs

La plupart des routines MPI retournent une valeur d'erreur ; en C, la valeur de retour de la fonction ; en Fortran, le dernier argument de la routine.

Avant de retourner la valeur d'erreur, le gestionnaire d'erreurs associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) lié à l'appel est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, l'appel est considéré comme associé à MPI_COMM_SELF et appellera le gestionnaire d'erreurs correspondant. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le Modèle de Session est utilisé exclusivement), le gestionnaire d'erreurs initial est déclenché. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lorsqu'on utilise le Modèle du Monde, ou via le paramètre mpi_initial_errhandler dans mpiexec ou la clé info dans MPI_Comm_spawn/MPI_Comm_spawn_multiple. S'il n'y a pas d'autre gestionnaire d'erreurs approprié, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs par défaut qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL — Arrête tous les processus connectés à MPI.
  • MPI_ERRORS_ABORT — Gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est invoqué sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est invoqué sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est invoqué sur une session, il arrête uniquement le processus local.
  • MPI_ERRORS_RETURN — Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou dans MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Note : Les programmes MPI ne garantissent pas qu'ils peuvent continuer après une erreur.

Pour une liste complète des codes d'erreur MPI, voir la page de manuel MPI.

Pour plus d'informations sur les gestionnaires d'erreurs, voir la section sur la gestion des erreurs de la norme MPI-3.1.
