MPI_Win_start — Démarre une époque d'accès RMA pour win

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Win_start(MPI_Group group, int assert, MPI_Win win)

Syntaxe Fortran

USE MPI
! Ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_WIN_START(GROUP, ASSERT, WIN, IERROR)
     INTEGER GROUP, ASSERT, WIN, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Win_start(group, assert, win, ierror)
     TYPE(MPI_Group), INTENT(IN) :: group
     INTEGER, INTENT(IN) :: assert
     TYPE(MPI_Win), INTENT(IN) :: win
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETRES ENTRANTS

  • group : Le groupe des processus cibles (handle).
  • assert : Assertion du programme (entier).
  • win : Objet fenêtre (handle).

PARAMETRES SORTANTS

•
ierror : Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

MPI_Win_start est un appel de synchronisation de communication MPI unilatérale qui démarre une époque d'accès RMA pour win. Les appels RMA émis sur win pendant cette époque doivent accéder uniquement aux fenêtres des processus du groupe group. Chaque processus dans group doit émettre un appel correspondant à MPI_Win_post. MPI_Win_start peut bloquer jusqu'à ce que les appels MPI_Win_post correspondants aient été exécutés, mais n'est pas obligé de le faire.

Le paramètre assert est utilisé pour fournir des assertions sur le contexte de l'appel qui peuvent être utilisées pour diverses optimisations. (Voir la section 6.4.4 de la norme MPI-2.) Une valeur de assert = 0 est toujours valide. La valeur d'assertion suivante est supportée :

MPI_MODE_NOCHECK
Lorsque cette valeur est passée à cet appel, la bibliothèque suppose que l'appel post sur la cible a été effectué et qu'il n'est pas nécessaire pour la bibliothèque de vérifier si un tel appel a été effectué.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier paramètre.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions), l'erreur élève le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information pour MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'abandon du programme par tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, il n'abandonne que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
