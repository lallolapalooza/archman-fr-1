NAME

MP3::Info - Manipuler ou récupérer des informations de fichiers audio MP3

SYNOPSIS

#!perl -w
use MP3::Info;
my $file = 'Pearls_Before_Swine.mp3';
set_mp3tag($file, 'Pearls Before Swine', q"77's",
        'Sticks and Stones', '1990',
        q"(c) 1990 77's LTD.", 'rock & roll');
my $tag = get_mp3tag($file) or die "No TAG info";
$tag->{GENRE} = 'rock';
set_mp3tag($file, $tag);
my $info = get_mp3info($file);
printf "$file length is %d:%d\n", $info->{MM}, $info->{SS};
my $mp3 = new MP3::Info $file;
$mp3->title('Perls Before Swine');
printf "$file length is %s, title is %s\n",
        $mp3->time, $mp3->title;

DESCRIPTION

$mp3 = MP3::Info->new(FILE)
Interface OOP pour le reste de la bibliothèque. Les mêmes clés disponibles via get_mp3info et get_mp3tag sont disponibles sur l'objet renvoyé (en majuscules ou minuscules ; mais noter que la valeur "VERSION" renvoie la version de la bibliothèque, pas celle du MP3).

Passer une valeur à l'une des fonctions changera la valeur pour cette balise dans le fichier MP3.

use_mp3_utf8([STATUS])
Indique à MP3::Info (ou pas) de renvoyer des informations de balises en UTF-8. TRUE est 1, FALSE est 0. La valeur par défaut est TRUE si elle est disponible.

Vous ne pourrez l'activer que si le module Encode est disponible. Les balises ID3v2 seront converties en UTF-8 en fonction de l'encodage spécifié dans chaque balise ; les balises ID3v1 seront considérées comme du latin-1 et converties en UTF-8.

La fonction renvoie le statut (TRUE/FALSE). Si aucun argument n'est spécifié ou si un argument non accepté est spécifié, la fonction renvoie simplement le statut.

Cette fonction n'est pas exportée par défaut, mais peut être exportée avec le tag ":utf8" ou ":all".

use_winamp_genres()
Place les genres WinAmp dans @mp3_genres et %mp3_genres (ajoute 68 genres supplémentaires à la liste par défaut de 80). C'est un fonctionnement séparé car ce sont des genres non standard, mais ils sont inclus en raison de leur large utilisation.

Vous pouvez importer les structures de données avec l'une des suivantes :

use MP3::Info qw(:genres);
use MP3::Info qw(:DEFAULT :genres);
use MP3::Info qw(:all);
remove_mp3tag (FILE [, VERSION, BUFFER])
Peut supprimer les balises ID3v1 ou ID3v2. VERSION doit être 1 pour ID3v1 (la valeur par défaut), 2 pour ID3v2, et "ALL" pour les deux.

Pour ID3v1, supprime les 128 derniers octets du fichier s'ils commencent par le texte 'TAG'. Le fichier sera 128 octets plus court.

Pour ID3v2, supprime la balise ID3v2. Comme une balise ID3v2 se trouve au début du fichier, le fichier est réécrit après la suppression des données de la balise. Le tampon pour réécrire le fichier est de 4 Mo. La valeur du tampon (en octets) peut modifier la taille du tampon.

Renvoie le nombre d'octets supprimés, ou -1 si aucune balise n'a été supprimée, ou undef en cas d'erreur.

set_mp3tag (FILE, TITLE, ARTIST, ALBUM, YEAR, COMMENT, GENRE [, TRACKNUM])
set_mp3tag (FILE, $HASHREF)
Ajoute ou modifie des informations de balise dans un fichier audio MP3. Remplace toute information existante dans le fichier.

Les champs sont TITLE, ARTIST, ALBUM, YEAR, COMMENT, GENRE. Tous les champs sont limités à 30 octets, sauf YEAR, qui est limité à 4 octets, et GENRE, qui est un champ dans le fichier. Le genre passé dans la fonction est une chaîne de texte en minuscules, représentant un genre trouvé dans @mp3_genres.

Vous pouvez passer une liste de valeurs ou un hashref du type renvoyé par "get_mp3tag".

Si TRACKNUM est présent (pour ID3v1.1), le champ COMMENT peut contenir seulement 28 octets.

La prise en charge de ID3v2 peut éventuellement arriver. Note : si vous définissez une balise dans un fichier avec ID3v2, la balise définie sera uniquement pour ID3v1[.1], et si vous appelez "get_mp3tag" sur le fichier, il affichera la balise ID3v2 (non modifiée), à moins que vous ne spécifiiez ID3v1.

get_mp3tag (FILE [, VERSION, RAW_V2, APE2])
Renvoie une référence de hachage avec les informations de balise d'un fichier audio MP3. Les champs renvoyés sont les mêmes que ceux fournis dans "set_mp3tag", sauf dans le cas de RAW_V2.

Si VERSION est 1, les informations sont obtenues de la balise ID3v1 (si elle est présente). Si VERSION est 2, les informations sont obtenues de la balise ID3v2 (si elle est présente). Si VERSION n'est pas spécifié ou est faux, la balise ID3v1 est lue (si elle est présente) puis, si elle est présente, toute information de la balise ID3v1 existante est écrasée.

Si RAW_V2 est 1, les données de la balise ID3v2 sont renvoyées sans manipulation de l'encodage du texte. Le nom du champ est le même que l'ID de la balise (ID vers nom des balises dans le global %v2_tag_names).

Si RAW_V2 est 2, les données de la balise ID3v2 sont renvoyées, qui sont manipulées pour Unicode si nécessaire, etc. Il accepte également plusieurs valeurs pour un champ donné (comme les commentaires) et les place dans un arrayref.

Si APE est 1, une balise APE est recherchée avant toute autre balise.

Si le numéro de version d'ID3v2 est inférieur à ID3v2.2.0 ou supérieur à ID3v2.4.0, les informations ne seront pas lues.

Les chaînes renvoyées seront en latin-1, sauf si UTF-8 est spécifié (use_mp3_utf8), (sauf si RAW_V2 est 1).

Il renvoie également une clé TAGVERSION, qui contient la version ID3 utilisée pour les données renvoyées (si l'argument TAGVERSION est 0, il peut contenir deux versions).

get_mp3info (FILE)
Renvoie une référence de hachage avec les informations du fichier audio MP3. Ces informations ne peuvent pas être modifiées. Les données renvoyées incluent : 
VERSION         Version audio MPEG (1, 2, 2.5)
LAYER           Description de la couche MPEG (1, 2, 3)
STEREO          Vrai si l'audio est en stéréo
VBR             Vrai si le débit binaire est variable
BITRATE         Débit binaire en kbps (moyen pour les fichiers VBR)
FREQUENCY       Fréquence en kHz
SIZE            Octets dans le flux audio
OFFSET          Décalage en octets où commence le flux
SECS            Secondes totales
MM              Minutes
SS              Secondes restantes
MS              Millisecondes restantes
TIME            Temps en MM:SS
COPYRIGHT       Vrai si l'audio est protégé par copyright
PADDING         Vrai si les trames MP3 sont remplies
MODE            Mode de canal (0 = stéréo, 1 = stéréo conjointe,
                2 = double canal, 3 = canal unique)
FRAMES          Nombre approximatif de trames
FRAME_LENGTH    Taille approximative d'une trame
VBR_SCALE       Échelle VBR depuis l'en-tête VBR

En cas d'erreur, renvoie rien et définit $@.

DÉPANNAGE

Si vous rencontrez une erreur, veuillez soumettre un correctif (voir la page du projet dans "VOIR AUSSI"). Si vous ne parvenez pas à comprendre pourquoi cela ne fonctionne pas pour vous, veuillez envoyer le fichier MP3 dans un endroit où je peux l'obtenir (de préférence par FTP, HTTP ou .Mac iDisk) et envoyez un e-mail sur où je peux obtenir le fichier, avec une description détaillée du problème.

Si je le télécharge après avoir diagnostiqué le problème, je ne conserverai pas le fichier MP3 s'il ne m'est pas lisible. Dites-moi simplement s'il m'est lisible de le conserver ou non.

DESCRIPTION

This module provides an interface to read and write MP3 file tags.

DÉPANNAGE

If MP3::Info doesn't seem to be working, check out the following:

  • Are you running a recent version of Perl?
  • Is the MP3 file you're trying to read corrupted?
  • Are you running the latest version of MP3::Info?
