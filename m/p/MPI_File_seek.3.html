MPI_FILE_SEEK(3) Open MPI MPI_FILE_SEEK(3)

MPI_File_seek — Met à jour les pointeurs de fichiers individuels (non collectifs).

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_File_seek(MPI_File fh, MPI_Offset offset,
     int whence)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne: INCLUDE 'mpif.h'
MPI_FILE_SEEK(FH, OFFSET, WHENCE, IERROR)
     INTEGER FH, WHENCE, IERROR
     INTEGER(KIND=MPI_OFFSET_KIND)   OFFSET

Syntaxe Fortran 2008

USE mpi_f08
MPI_File_seek(fh, offset, whence, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     INTEGER(KIND=MPI_OFFSET_KIND), INTENT(IN) :: offset
     INTEGER, INTENT(IN) :: whence
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETRES ENTRANT

  • fh: Handle de fichier (handle).
  • offset: Décalage de fichier (entier).
  • whence: Mode de mise à jour (entier).

PARAMETRE SORTANT

•
ierror: Fortran seulement : Statut d'erreur (entier).

DESCRIPTION

MPI_File_seek met à jour le pointeur de fichier individuel selon whence, qui peut prendre les valeurs possibles suivantes :

  • MPI_SEEK_SET - Le pointeur est défini à offset.
  • MPI_SEEK_CUR - Le pointeur est défini à la position actuelle du pointeur plus offset.
  • MPI_SEEK_END - Le pointeur est défini à la fin du fichier plus offset.

L' offset peut être négatif, ce qui permet de se déplacer en arrière dans le fichier. Il est erroné de se déplacer vers une position négative dans le fichier. La fin du fichier est définie comme étant l'emplacement du prochain élément de données élémentaire immédiatement après le dernier élément de données accédé, même si cet emplacement est un trou.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C en tant que résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du Modèle de Sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler à mpiexec ou la clé d'information à MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions MPI d'E/S et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt de tous les processus MPI connectés par le programme.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
