MPI_T_PVAR_SESSION_FREE(3) Open MPI MPI_T_PVAR_SESSION_FREE(3)

MPI_T_pvar_session_create, MPI_T_pvar_session_free - Créer/libérer une session de variables de performance

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_T_pvar_session_create(MPI_T_pvar_session *session)
int MPI_T_pvar_session_free(MPI_T_pvar_session *session)

DESCRIPTION

MPI_T_pvar_session_create crée une session pour accéder aux variables de performance. La nouvelle session est retournée dans le paramètre session.

MPI_T_pvar_session_free libère une session allouée par MPI_T_pvar_session_create et met le paramètre session à MPI_T_PVAR_SESSION_NULL.

ERREURS

MPI_T_pvar_session_create échouera si :

  • MPI_T_ERR_NOT_INITIALIZED : L'interface des outils MPI n'est pas initialisée
  • MPI_T_ERR_MEMORY : Pas assez de mémoire
  • MPI_T_ERR_OUT_OF_SESSIONS : Aucune session disponible

MPI_T_pvar_session_free échouera si :

  • MPI_T_ERR_NOT_INITIALIZED : L'interface des outils MPI n'est pas initialisée
  • MPI_T_ERR_INVALID_SESSION : Le paramètre session n'est pas une session valide
