MPI_FILE_WRITE_AT_ALL(3) Open MPI MPI_FILE_WRITE_AT_ALL(3)

MPI_File_write_at_all — Écrit dans un fichier à des offsets explicitement spécifiés (bloquant, collectif).

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_File_write_at_all(MPI_File fh, MPI_Offset offset, const void *buf,
     int count, MPI_Datatype datatype, MPI_Status *status)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_FILE_WRITE_AT_ALL(FH, OFFSET, BUF, COUNT,
     DATATYPE, STATUS, IERROR)
     <type>  BUF(*)
     INTEGER FH, COUNT, DATATYPE, STATUS(MPI_STATUS_SIZE), IERROR
     INTEGER(KIND=MPI_OFFSET_KIND)   OFFSET

Syntaxe Fortran 2008

USE mpi_f08
MPI_File_write_at_all(fh, offset, buf, count, datatype, status, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     INTEGER(KIND=MPI_OFFSET_KIND), INTENT(IN) :: offset
     TYPE(*), DIMENSION(..), INTENT(IN) :: buf
     INTEGER, INTENT(IN) :: count
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     TYPE(MPI_Status) :: status
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES D'ENTRÉE

  • fh: Handle de fichier (handle).
  • offset: Offset de fichier (entier).
  • buf: Adresse initiale du tampon (choix).
  • count: Nombre d'éléments dans le tampon (entier).
  • datatype: Type de données de chaque élément du tampon (handle).

PARAMÈTRES DE SORTIE

  • status: Objet statut (statut).
  • ierror: Fortran uniquement : statut d'erreur (entier).

DESCRIPTION

MPI_File_write_at_all est une routine collective qui tente d'écrire dans le fichier associé à fh (à la position offset) un total de count éléments de données de type datatype à partir du tampon utilisateur buf. L'offset est en unités etype par rapport à la vue actuelle. C'est-à-dire que les trous ne sont pas comptés lors de la détermination d'un offset. Les données sont écrites dans les parties du fichier spécifiées par la vue actuelle. MPI_File_write_at_all stocke le nombre d'éléments datatype effectivement écrits dans status. Tous les autres champs de status sont indéfinis.

Il est erroné d'appeler cette fonction si le mode MPI_MODE_SEQUENTIAL a été spécifié lors de l'ouverture du fichier.

ERREURS

Presque toutes les routines MPI renvoient une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de Sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle Monde, ou par l'argument de ligne de commande mpi_initial_errhandler de mpiexec ou par la clé d'info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'abandon du programme par tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Consultez la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Consultez la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
