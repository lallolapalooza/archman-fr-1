MPI_T_category_get_cvars — Interroger quelles variables de contrôle sont dans une catégorie

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_T_category_get_cvars(int cat_index, int len, int indices[])

PARAMÈTRES ENTRANTS

  • cat_index: Index de la catégorie à interroger.
  • len: La longueur du tableau d'indices.

PARAMÈTRES SORTANTS

•
indices: Un tableau d'entiers de taille len, indiquant les indices des variables de contrôle.

DESCRIPTION

MPI_T_category_get_cvars peut être utilisé pour interroger quelles variables de contrôle sont contenues dans une catégorie particulière.

ERREURS

MPI_T_category_get_cvars échouera si :

  • MPI_T_ERR_NOT_INITIALIZED: L'interface des outils MPI n'est pas initialisée
  • MPI_T_ERR_INVALID_INDEX: L'index de la catégorie est invalide
