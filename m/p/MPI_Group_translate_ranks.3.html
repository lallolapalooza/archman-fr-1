MPI_GROUP_TRANSLATE_RANKS(3) Open MPI MPI_GROUP_TRANSLATE_RANKS(3)

MPI_Group_translate_ranks — Traduit les rangs des processus d'un groupe à ceux d'un autre groupe.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Group_translate_ranks(MPI_Group group1, int n,
     const int ranks1[], MPI_Group group2, int ranks2[])

Syntaxe Fortran

USE MPI
! Ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_GROUP_TRANSLATE_RANKS(GROUP1, N, RANKS1, GROUP2, RANKS2,
             IERROR)
     INTEGER GROUP1, N, RANKS1(*), GROUP2, RANKS2(*), IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Group_translate_ranks(group1, n, ranks1, group2, ranks2, ierror)
     TYPE(MPI_Group), INTENT(IN) :: group1, group2
     INTEGER, INTENT(IN) :: n, ranks1(n)
     INTEGER, INTENT(OUT) :: ranks2(n)
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES D'ENTRÉE

  • group1: Premier groupe (handle).
  • n: Nombre de rangs dans les tableaux ranks1 et ranks2 (entier).
  • ranks1: Tableau de zéro ou plusieurs rangs valides dans group1.
  • group2: Deuxième groupe (handle).

PARAMÈTRES DE SORTIE

  • ranks2: Tableau des rangs correspondants dans group2, MPI_UNDEFINED lorsqu'aucune correspondance n'existe.
  • ierror: Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

Cette fonction est importante pour déterminer la numérotation relative des mêmes processus dans deux groupes différents. Par exemple, si l'on connaît les rangs de certains processus dans le groupe de MPI_COMM_WORLD, on pourrait vouloir connaître leurs rangs dans un sous-ensemble de ce groupe.

ERREURS

Presque toutes les routines MPI renvoient une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de Sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler de mpiexec ou la clé info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme par tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
