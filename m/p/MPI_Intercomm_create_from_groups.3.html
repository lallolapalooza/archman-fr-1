MPI_Intercomm_create_from_groups — Crée un nouvel inter-communicateur à partir d'un groupe local et distant et d'une étiquette de chaîne

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_Intercomm_create_from_groups(MPI_Group local_group, int local_leader, MPI_Group remote_group, int remote_leader, const char *stringtag, MPI_Info info, MPI_Errhandler errhandler, MPI_Comm *newintercomm)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_INTERCOMM_CREATE_FROM_GROUPS(LOCAL_GROUP, LOCAL_LEADER, REMOTE_GROUP, REMOTE_LEADER, STRINGTAG, INFO, ERRHANDLER, NEWINTERCOMM, IERROR)
    INTEGER LOCAL_GROUP, LOCAL_LEADER, REMOTE_GROUP, REMOTE_LEADER, INFO, ERRHANDLER, NEWINTERCOMM, IERROR
    CHARACTER*(*) STRINGTAG

Syntaxe Fortran 2008

USE mpi_f08
MPI_Intercomm_create_from_groups(local_group, local_leader, remote_group, remote_leader, stringtag, info, errhandler, newintercomm, ierror)
    TYPE(MPI_Group), INTENT(IN) :: local_group, remote_group
    INTEGER, INTENT(IN) :: local_leader, remote_leader
    CHARACTER(LEN=*), INTENT(IN) :: stringtag
    TYPE(MPI_Info), INTENT(IN) :: info
    TYPE(MPI_Errhandler), INTENT(IN) :: errhandler
    TYPE(MPI_Comm), INTENT(OUT) :: newintercomm
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES D'ENTRÉE

  • local_group : Groupe local (gestionnaire)
  • local_leader : rang du leader du groupe local dans local_group (entier)
  • remote_group : Groupe distant (gestionnaire)
remote_leader
rang du leader distant dans remote_group, significatif uniquement au niveau du leader local (entier)
  • stringtag : Identifiant unique pour cette opération (chaîne)
  • info : objet info (gestionnaire)
errhandler
gestionnaire d'erreurs à attacher au nouvel inter-communicateur (gestionnaire)

PARAMÈTRES DE SORTIE

  • newintercomm : Nouvel inter-communicateur (gestionnaire).
  • ierror : Fortran seulement : Statut d'erreur (entier).

DESCRIPTION

MPI_Intercomm_create_from_groups crée un inter-communicateur. Contrairement à MPI_Intercomm_create, cette fonction utilise en entrée des groupes locaux et distants préalablement définis et disjoints. Le processus MPI appelant doit être membre du groupe local. L'appel est collectif sur l'union des groupes local et distant. Tous les processus MPI impliqués doivent fournir une valeur identique pour l'argument stringtag. Au sein de chaque groupe, tous les processus MPI doivent fournir des arguments local_group et local_leader identiques. Les jokers ne sont pas autorisés pour les arguments remote_leader et local_leader. L'argument stringtag sert le même objectif que le stringtag utilisé dans la fonction MPI_Comm_create_from_group ; il différencie les appels concurrents dans un environnement multithread. Le stringtag ne doit pas dépasser MPI_MAX_STRINGTAG_LEN caractères. Pour C, cela inclut l'espace pour un caractère de fin de chaîne nul. Dans le cas où MPI_GROUP_EMPTY est fourni comme local_group ou remote_group, ou les deux, l'appel est une opération locale et MPI_COMM_NULL est retourné comme newintercomm.

NOTES

L'argument errhandler spécifie un gestionnaire d'erreurs à attacher au nouvel inter-communicateur. L'argument info fournit des indices et des assertions, éventuellement dépendant de l'implémentation MPI, qui indiquent les caractéristiques souhaitées et guident la création de l'inter-communicateur. MPI_MAX_STRINGTAG_LEN doit avoir une valeur d'au moins 63.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou en utilisant exclusivement le modèle de sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou via l'argument de ligne de commande mpiexec initial_error_handler ou la clé d'information de MPI_Comm_create_from_group/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt de tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être appelé sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.

NOM

MPI_Intercomm_create_from_groups — Créer un intercomunicateur à partir de groupes MPI

SYNTAXIS

SYNTAXE C

int MPI_Intercomm_create_from_groups(MPI_Group group1, MPI_Group group2, MPI_Comm local_comm, MPI_Comm *intercomm);

SYNTAXE FORTRAN

SUBROUTINE MPI_INTERCOMM_CREATE_FROM_GROUPS(GROUP1, GROUP2, LOCAL_COMM, INTERCOMM, IERROR)

SYNTAXE FORTRAN77

INTEGER GROUP1, GROUP2, LOCAL_COMM, INTERCOMM, IERROR

PARAMÈTRES D'ENTRÉE

  • group1 : Premier groupe MPI.
  • group2 : Deuxième groupe MPI.
  • local_comm : Communicateur local contenant des processus appartenant aux deux groupes.

PARAMÈTRES DE SORTIE

  • intercomm : Nouvel intercomunicateur créé.
  • IERROR : Erreur Fortran.

DESCRIPTION

MPI_Intercomm_create_from_groups crée un nouvel intercomunicateur intercomm à partir de deux groupes MPI, group1 et group2. Le communicateur local local_comm doit contenir des processus appartenant aux deux groupes.

Les processus dans group1 formeront un côté de l'intercommunicateur, et les processus dans group2 formeront l'autre côté. L'intercommunicateur résultant permettra une communication entre les processus des deux groupes.

ERREURS

Aucune erreur spécifique documentée.
