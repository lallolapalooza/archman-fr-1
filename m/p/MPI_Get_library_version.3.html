MPI_Get_library_version — Renvoie une chaîne de la version actuelle d'Open MPI

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Get_library_version(char *version, int *resultlen)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_GET_LIBRARY_VERSION(VERSION, RESULTLEN, IERROR)
    CHARACTER*(*)   NAME
    INTEGER RESULTLEN, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Get_library_version(version, resulten, ierror)
    CHARACTER(LEN=MPI_MAX_LIBRARY_VERSION_STRING), INTENT(OUT) :: version
    INTEGER, INTENT(OUT) :: resultlen
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES DE SORTIE

  • version : Une chaîne de caractères contenant la version d'Open MPI (chaîne).
resultlen
Longueur (en caractères) du résultat renvoyé dans version (entier).
•
ierror : Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

Cette routine renvoie une chaîne de caractères représentant la version de la bibliothèque MPI. L'argument version est une chaîne de caractères pour une flexibilité maximale.

Le nombre de caractères réellement écrits est renvoyé dans le paramètre de sortie, resultlen. En C, un caractère ‘0’ est également stocké à version[resultlen]. resultlen ne peut pas être supérieur à (MPI_MAX_LIBRARY_VERSION_STRING - 1). En Fortran, version est complété par des espaces sur la droite. resultlen ne peut pas être supérieur à MPI_MAX_LIBRARY_VERSION_STRING.

NOTE

La chaîne de version qui est passée doit avoir une longueur d'au moins MPI_MAX_LIBRARY_VERSION_STRING caractères.

MPI_Get_library_version est l'une des rares fonctions qui peuvent être appelées avant MPI_Init et après MPI_Finalize.

ERREURS

Presque toutes les routines MPI renvoient une valeur d'erreur ; en C, la valeur est le résultat de la fonction, et en Fortran, elle est dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le modèle de sessions est utilisé exclusivement), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lorsque le modèle World est utilisé, ou par l'argument CLI mpi_initial_errhandler de mpiexec ou par la clé d'informations de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions MPI d'E/S et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme sur tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
