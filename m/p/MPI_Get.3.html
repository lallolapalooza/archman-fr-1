MPI_Get, MPI_Rget - Copie de données depuis la mémoire cible vers la mémoire source.

MPI_Rget(void *origin_addr, int origin_count, MPI_Datatype
     origin_datatype, int target_rank, MPI_Aint target_disp,

Paramètres d'entrée

  • origin_addr : Adresse du buffer source (entrée).
origin_count
Nombre d'éléments dans le buffer source (entier non négatif).
  • origin_datatype : Type de données de chaque élément dans le buffer source (handle).
  • target_rank : Rang de la cible (entier non négatif).
target_disp
Déplacement depuis le début de la fenêtre jusqu'au début du buffer cible (entier non négatif).
•
target_count
Nombre d'éléments dans le buffer cible (entier non négatif).
  • target_datatype : Type de données de chaque élément dans le buffer cible (handle).
  • win : Objet de fenêtre utilisé pour la communication (handle).

Paramètre de sortie

  • request : MPI_Rget : demande RMA
  • ierror : Fortran uniquement : code d'erreur (entier).

Description

MPI_Get copie des données de la mémoire cible vers la mémoire source, de manière similaire à MPI_Put, mais le sens du transfert de données est inversé. Le type de données source ne doit pas spécifier des éléments qui se chevauchent dans le buffer source. Le buffer cible doit être contenu dans la fenêtre cible, et les données copiées doivent tenir sans troncature dans le buffer source. Seuls les processus du même nœud peuvent accéder à la fenêtre cible.

MPI_Rget est similaire à MPI_Get, sauf qu'il alloue une demande de communication et l'associe au handle de demande (l'argument request), qui peut être utilisé pour attendre ou vérifier l'achèvement de l'opération. L'achèvement d'une opération MPI_Rget indique que les données sont disponibles dans le buffer source. Si origin_addr pointe vers la mémoire associée à une fenêtre, les données deviennent disponibles dans la copie privée de cette fenêtre.

Erreurs

La plupart des routines MPI retournent une valeur d'erreur ; dans les routines C, le résultat est retourné comme valeur de retour de la fonction, et dans les routines Fortran, dans le dernier argument.

Avant de retourner la valeur d'erreur, le gestionnaire d'erreur associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) utilisé est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, l'appel est considéré comme associé à MPI_COMM_SELF et le gestionnaire correspondant est appelé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le modèle de session est utilisé exclusivement), l'erreur déclenche le gestionnaire d'erreur initial. Le gestionnaire d'erreur initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lorsqu'on utilise le modèle du monde, ou via l'argument mpi_initial_errhandler de mpiexec ou la clé info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreur approprié n'est configuré, le gestionnaire MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire MPI_ERRORS_ABORT pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreur prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL : Le programme abandonne tous les processus MPI connectés.
  • MPI_ERRORS_ABORT : Un gestionnaire d'erreur qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est invoqué sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est invoqué sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est invoqué sur une session, il abandonne uniquement le processus local.
  • MPI_ERRORS_RETURN : Retourne un code d'erreur au programme.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreur en appelant :

  • MPI_Comm_create_errhandler suivi de MPI_Comm_set_errhandler
  • MPI_File_create_errhandler suivi de MPI_File_set_errhandler
  • MPI_Session_create_errhandler suivi de MPI_Session_set_errhandler ou dans MPI_Session_init
  • MPI_Win_create_errhandler suivi de MPI_Win_set_errhandler

Note : MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Consultez la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Consultez la section sur la gestion des erreurs de la spécification MPI-3.1 pour plus d'informations.
