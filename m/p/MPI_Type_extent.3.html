MPI_TYPE_EXTENT(3) Open MPI MPI_TYPE_EXTENT(3)

MPI_Type_extent — Retourne l'étendue d'un type de données — cette routine est obsolète en faveur de MPI_Type_get_extent.

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_Type_extent(MPI_Datatype datatype, MPI_Aint *extent)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_TYPE_EXTENT(DATATYPE, EXTENT, IERROR)
     INTEGER DATATYPE, EXTENT, IERROR

PARAMÈTRE D'ENTRÉE

•
datatype : Type de données (handle).

PARAMÈTRES DE SORTIE

  • extent : Étendue du type de données (entier).
  • ierror : Uniquement Fortran : Statut d'erreur (entier).

DESCRIPTION

Notez que l'utilisation de cette routine est obsolète depuis MPI-2. Veuillez utiliser MPI_Type_get_extent à la place.

MPI_Type_extent retourne l'étendue d'un type de données, la différence entre les bornes supérieure et inférieure du type de données.

En général, si

Typemap = {(type(0), disp(0)), ..., (type(n-1), disp(n-1))}

alors la borne inférieure de Typemap est définie comme

            ( min(j) disp(j)                         si aucune entrée n'a
lb(Typemap)=(                                        de borne inférieure de
            (min(j) {disp(j) tel que type(j) = lb} type de base sinon

De même, la borne supérieure de Typemap est définie comme

            (max(j) disp(j) + sizeof(type(j)) + e    si aucune entrée n'a
ub(Typemap)=(                                        de borne supérieure de
            (max(j) {disp(j) tel que type(j) = ub} type de base sinon

Alors

extent(Typemap) = ub(Typemap) - lb(Typemap)

Si type(i) nécessite un alignement à une adresse d'octet qui est un multiple de k(i), alors e est le plus petit incrément non négatif nécessaire pour arrondir extent(Typemap) au multiple suivant de max(i) k(i).

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire, avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le modèle de Sessions est utilisé exclusivement), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou par l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme pour tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, seul le processus local est arrêté.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
