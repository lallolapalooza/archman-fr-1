MPI_Win_post — Démarre une époque d'exposition RMA pour la fenêtre locale associée à win

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_Win_post(MPI_Group group, int assert, MPI_Win win)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_WIN_POST(GROUP, ASSERT, WIN, IERROR)
     INTEGER GROUP, ASSERT, WIN, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Win_post(group, assert, win, ierror)
     TYPE(MPI_Group), INTENT(IN) :: group
     INTEGER, INTENT(IN) :: assert
     TYPE(MPI_Win), INTENT(IN) :: win
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES D'ENTRÉE

  • group : Le groupe des processus d'origine (handle)
  • assert : Assertion de programme (entier)
  • win : Objet fenêtre (handle)

PARAMÈTRES DE SORTIE

•
ierror : Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

Démarre une époque d'exposition RMA pour la fenêtre locale associée à win. Seuls les processus appartenant à group doivent accéder à la fenêtre avec des appels RMA sur win pendant cette époque. Chaque processus de group doit émettre un appel correspondant à MPI_Win_start. MPI_Win_post ne bloque pas.

Le paramètre assert est utilisé pour fournir des assertions sur le contexte de

l'appel qui peuvent être utilisées pour diverses optimisations. Une valeur de assert ^ 0 est toujours valide. Les valeurs d'assertion suivantes sont prises en charge :

MPI_MODE_NOCHECK
Les appels correspondants à MPI_Win_start n'ont pas encore eu lieu sur les processus d'origine lorsque cet appel est effectué. Cette assertion doit être présente pour tous les appels correspondants à MPI_Win_start s'ils sont utilisés.
MPI_MODE_NOSTORE
Indique que la fenêtre locale n'a pas été mise à jour par des stockages locaux ou des appels de réception dans l'époque précédente.
MPI_MODE_NOPUT
Indique que la fenêtre locale ne sera pas mise à jour par des appels de mise ou d'accumulation jusqu'à la synchronisation d'attente suivante.

ERREURS

Presque toutes les routines MPI renvoient une valeur d'erreur ; les routines C en tant que résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire, avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou par l'argument de ligne de commande mpi_initial_errhandler de mpiexec ou la clé info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme de tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être appelé sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, il n'arrête que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
