MPI_Pcontrol — Contrôle le profilage.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Pcontrol(const int level, ... )

Syntaxe Fortran

USE MPI
! ou l'ancienne forme: INCLUDE 'mpif.h'
MPI_PCONTROL(LEVEL)
     INTEGER LEVEL

Syntaxe Fortran 2008

USE mpi_f08
MPI_Pcontrol(level)
     INTEGER, INTENT(IN) :: level

PARAMETRE ENTRÉE

•
level: Niveau de profilage.

DESCRIPTION

Les bibliothèques MPI elles-mêmes n'utilisent pas cette routine ; elles retournent simplement immédiatement au code utilisateur. Cependant, la présence d'appels à cette routine permet à un paquet de profilage d'être explicitement appelé par l'utilisateur.

Comme MPI n'a aucun contrôle sur l'implémentation du code de profilage, nous sommes incapables de spécifier précisément les sémantiques qui seront fournies par les appels à MPI_Pcontrol. Cette imprécision s'étend au nombre d'arguments de la fonction, et à leurs types de données.

Cependant, pour fournir un certain niveau de portabilité des codes utilisateur vers différentes bibliothèques de profilage, nous demandons les significations suivantes pour certaines valeurs de level :

o level==0 Le profilage est désactivé.

o level==1 Le profilage est activé à un niveau de détail normal par défaut.

o level==2 Les tampons de profilage sont vidés. (Cela peut être une opération nulle dans certains profileurs).

o Toutes les autres valeurs de level ont des effets et des arguments supplémentaires définis par la bibliothèque de profilage.

Nous demandons également que l'état par défaut après l'appel de MPI_Init soit que le profilage soit activé au niveau normal par défaut (c'est-à-dire, comme si MPI_Pcontrol avait été appelé avec l'argument 1). Cela permet aux utilisateurs de lier avec une bibliothèque de profilage et d'obtenir une sortie de profilage sans avoir à modifier leur code source.

La fourniture de MPI_Pcontrol comme opération nulle dans la bibliothèque MPI standard permet aux utilisateurs de modifier leur code source pour obtenir des informations de profilage plus détaillées, tout en pouvant lier exactement le même code contre la bibliothèque MPI standard.

NOTES

Cette routine fournit une interface commune pour le contrôle du profilage. L'interprétation de level et de tout autre argument est laissée à la bibliothèque de profilage.

Cette fonction ne retourne pas de valeur d'erreur. Par conséquent, le résultat de son appel avant MPI_Init ou après MPI_Finalize est indéfini.
