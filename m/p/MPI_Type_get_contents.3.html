MPI_Type_get_contents(3) Open MPI MPI_Type_get_contents(3)

MPI_Type_get_contents — Renvoie des informations sur les arguments utilisés dans la création d'un type de données.

Syntaxe

Syntaxe C

#include <mpi.h>
int MPI_Type_get_contents(MPI_Datatype datatype, int max_integers,
     int max_addresses, int max_datatypes, int array_of_integers[], MPI_Aint array_of_addresses[], MPI_Datatype array_of_datatypes[])

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_TYPE_GET_CONTENTS(DATATYPE, MAX_INTEGERS, MAX_ADDRESSES,
             MAX_DATATYPES, ARRAY_OF_INTEGERS, ARRAY_OF_ADDRESSES,
             ARRAY_OF_DATATYPES, IERROR)
     INTEGER DATATYPE, MAX_INTEGERS, MAX_ADDRESSES, MAX_DATATYPES
     INTEGER ARRAY_OF_INTEGERS(*), ARRAY_OF_DATATYPES(*), IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) ARRAY_OF_ADDRESSES(*)

Syntaxe Fortran 2008

USE mpi_f08
MPI_Type_get_contents(datatype, max_integers, max_addresses, max_datatypes,
     array_of_integers, array_of_addresses, array_of_datatypes,
             ierror)
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER, INTENT(IN) :: max_integers, max_addresses, max_datatypes
     INTEGER, INTENT(OUT) :: array_of_integers(max_integers)
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(OUT) ::
     array_of_addresses(max_addresses)
     TYPE(MPI_Datatype), INTENT(OUT) :: array_of_datatypes(max_datatypes)
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Paramètres d'entrée

  • datatype : Type de données à inspecter (handle).
  • max_integers : Nombre d'éléments dans array_of_integers (entier non négatif).
  • max_addresses : Nombre d'éléments dans array_of_addresses (entier non négatif).
  • max_datatypes : Nombre d'éléments dans array_of_datatypes (entier non négatif).

Paramètres de sortie

  • array_of_integers : Contient les arguments entiers utilisés dans la construction du datatype (tableau d'entiers).
  • array_of_addresses : Contient les arguments d'adresse utilisés dans la construction du datatype (tableau d'entiers).
  • array_of_datatypes : Contient les arguments de type de données utilisés dans la construction du datatype (tableau d'entiers).
  • ierror : En Fortran uniquement : Code d'erreur (entier).

Description

Pour le type de données donné, MPI_Type_get_envelope renvoie des informations sur le nombre et le type des arguments utilisés dans l'appel qui a créé le type de données. Les valeurs du nombre d'arguments renvoyées peuvent être utilisées pour fournir des tableaux suffisamment grands dans le décodeur MPI_Type_get_contents. Cet appel et la signification des valeurs renvoyées sont décrits ci-dessous. Le combinator reflète l'appel au constructeur de type de données MPI qui a été utilisé pour créer datatype.

Le paramètre datatype doit être un type de données prédéfini ou dérivé. L'appel est erroné si datatype est un type de données prédéfini.

Les valeurs données pour max_integers, max_addresses et max_datatypes doivent être au moins aussi grandes que les valeurs renvoyées dans num_integers, num_addresses et num_datatypes dans l'appel :ref:`MPI_Type_get_envelope` pour le même argument de type de données.

Les types de données renvoyés dans array_of_datatypes sont des handles vers des objets de type de données équivalents au type de données utilisé dans l'appel d'origine. S'il s'agissait de types de données dérivés, alors les types de données renvoyés sont de nouveaux objets de type de données, et l'utilisateur doit libérer ces types de données avec :ref:`MPI_Type_free`. S'il s'agissait de types de données prédéfinis, alors le type de données renvoyé est identique à ce type de données prédéfini (constant) et ne peut pas être libéré.

Les types de données renvoyés à partir de types de données dérivés ont par défaut un état engagé, c'est-à-dire que les types de données peuvent être engagés ou non. De plus, le contenu des propriétés des types de données renvoyés est indéfini.

Note : MPI_Type_get_contents peut être appelé avec un argument de type de données qui a été construit en utilisant MPI_Type_create_f90_real, MPI_Type_create_f90_integer ou MPI_Type_create_f90_complex (un type de données prédéfini). Dans ce cas, un tableau vide de array_of_datatypes est renvoyé.

Dans les anciens appels au constructeur de types de données MPI-1, les arguments d'adresse en Fortran sont de type INTEGER. Dans les versions ultérieures de la norme MPI, les arguments d'adresse sont de type INTEGER(KIND=MPI_ADDRESS_KIND). L'appel MPI_Type_get_contents renvoie toutes les adresses dans un argument de type INTEGER(KIND=MPI_ADDRESS_KIND). C'est vrai même si les anciens appels au constructeur de types de données MPI-1 ont été utilisés. Par conséquent, l'emplacement des valeurs renvoyées peut être considéré comme renvoyé par les Liaisons C. Il peut également être déterminé en observant les appels actuels du constructeur de types de données MPI pour les anciens appels du modèle MPI-1 impliquant des adresses.

Erreurs

La plupart des routines MPI renvoient une valeur d'erreur ; les routines C renvoient le résultat de la fonction et les routines Fortran dans le dernier argument.

Avant de renvoyer la valeur d'erreur, le gestionnaire d'erreurs actuel associé à l'objet de communication (par exemple, le communicateur, la fenêtre, le fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme associé à MPI_COMM_SELF et appellera le gestionnaire d'erreurs associé à MPI_COMM_SELF. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le modèle de sessions est utilisé exclusivement), le gestionnaire d'erreurs initial est lancé. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lorsqu'on utilise le modèle du Monde, ou via le paramètre CLI mpi_initial_errhandler de mpiexec ou la clé d'info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. S'il n'y a pas d'autre gestionnaire d'erreurs approprié configuré, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL : Arrête tous les processus MPI connectés.
  • MPI_ERRORS_ABORT : Gestionnaire qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est invoqué sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est invoqué sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est invoqué sur une session, il arrête uniquement le processus local.
  • MPI_ERRORS_RETURN : Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou dans MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Note : Il n'est pas garanti qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel de MPI pour une liste complète des codes d'erreur MPI.

Voir la section sur la gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
