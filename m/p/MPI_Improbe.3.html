MPI_IMPROBE(3) Open MPI MPI_IMPROBE(3)

MPI_Improbe — Sonde de correspondance non bloquante pour un message.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Improbe(int source, int tag, MPI_Comm comm,
     int *flag, MPI_Message *message, MPI_Status *status)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_IMPROBE(SOURCE, TAG, COMM, FLAG, MESSAGE, STATUS, IERROR)
     LOGICAL FLAG
     INTEGER SOURCE, TAG, COMM, MESSAGE
     INTEGER STATUS(MPI_STATUS_SIZE), IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Improbe(source, tag, comm, flag, message, status, ierror)
     INTEGER, INTENT(IN) :: source, tag
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, INTENT(OUT) :: flag
     TYPE(MPI_Message), INTENT(OUT) :: message
     TYPE(MPI_Status) :: status
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES D'ENTRÉE

  • source : Rang de la source ou MPI_ANY_SOURCE (entier).
  • tag : Valeur du tag ou MPI_ANY_TAG (entier).
  • comm : Communicateur (descripteur).

PARAMÈTRES DE SORTIE

  • flag : Indicateur (logique).
  • message : Message (descripteur).
  • status : Objet de statut (statut).
  • ierror : Fortran seulement : Statut d'erreur (entier).

DESCRIPTION

Comme MPI_Probe et MPI_Iprobe, les opérations MPI_Mprobe et MPI_Improbe permettent d'interroger les messages entrants sans les recevoir réellement, à la différence près que MPI_Mprobe et MPI_Improbe fournissent un mécanisme pour recevoir le message spécifique qui a été trouvé, indépendamment des autres opérations de sonde ou de réception intermédiaires. Cela donne à l'application une opportunité de décider comment recevoir le message, en fonction des informations renvoyées par la sonde. En particulier, l'application peut allouer de la mémoire pour le tampon de réception selon la longueur du message sondé.

Une sonde de correspondance avec MPI_PROC_NULL comme source renvoie flag = vrai,

message = MPI_MESSAGE_NO_PROC, et l'objet status renvoie source ^ MPI_PROC_NULL, tag ^ MPI_ANY_TAG, et count ^ 0.

MPI_Iprobe renvoie une valeur vraie dans flag si un message a été trouvé et peut être reçu en passant le descripteur message aux fonctions MPI_Mrecv ou MPI_Imrecv, à condition que la source ne soit pas MPI_PROC_NULL.

ERREURS

Presque toutes les routines MPI renvoient une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/ MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusivement du modèle de sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou via l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/ MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt de tous les processus MPI connectés par le programme.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
