MPI_T_enum_get_item — Requête d'informations sur un énumérateur

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_T_enum_get_item(MPI_T_enum enumtype, int index, int *value, char *name,
                        int *name_len)

PARAMÈTRES D'ENTRÉE

  • enumtype: Énumération à interroger.
  • index: Numéro de la valeur à interroger dans cette énumération.

PARAMÈTRES D'ENTRÉE/SORTIE

•
name_len: Longueur de la chaîne et/ou du tampon pour le nom.

PARAMÈTRES DE SORTIE

  • value: Valeur de la variable.
  • name: Tampon pour retourner la chaîne contenant le nom de la catégorie.

DESCRIPTION

MPI_T_enum_get_item peut être utilisé pour interroger des informations sur un élément d'un énumérateur. Cette fonction retourne la valeur de l'énumération dans le paramètre value.

NOTES

Cette fonction d'interface d'outil MPI retourne le nom de l'élément sous forme de chaîne de caractères. Cette fonction prend deux arguments pour la chaîne : un tampon pour stocker la chaîne, et une longueur qui doit initialement spécifier la taille du tampon. Si la longueur passée est n, cette fonction copiera au maximum n - 1 caractères de la chaîne dans le tampon et réglera la longueur au nombre de caractères copiés - 1. Si l'argument longueur est NULL ou si la valeur spécifiée est 0, le tampon de chaîne est ignoré et la chaîne n'est pas retournée. Pour plus d'informations, voir la section 14.3.3 de MPI-3.

ERREURS

MPI_T_enum_get_item échouera si :

  • MPI_T_ERR_NOT_INITIALIZED: L'interface des outils MPI n'est pas initialisée.
  • MPI_T_ERR_INVALID_INDEX: L'énumération est invalide ou a été supprimée.
