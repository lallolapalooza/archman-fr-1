MPI_WIN_ALLOCATE(3) Open MPI MPI_WIN_ALLOCATE(3)

MPI_Win_allocate — Appel MPI unidirectionnel qui alloue de la mémoire et renvoie un objet fenêtre pour les opérations RMA.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Win_allocate (MPI_Aint size, int disp_unit, MPI_Info info,
                      MPI_Comm comm, void *baseptr, MPI_Win *win)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_WIN_ALLOCATE(SIZE, DISP_UNIT, INFO, COMM, BASEPTR, WIN, IERROR)
     INTEGER(KIND=MPI_ADDRESS_KIND) SIZE, BASEPTR
     INTEGER DISP_UNIT, INFO, COMM, WIN, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Win_allocate(size, disp_unit, info, comm, baseptr, win, ierror)
     USE, INTRINSIC :: ISO_C_BINDING, ONLY : C_PTR
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: size
     INTEGER, INTENT(IN) :: disp_unit
     TYPE(MPI_Info), INTENT(IN) :: info
     TYPE(MPI_Comm), INTENT(IN) :: comm
     TYPE(C_PTR), INTENT(OUT) :: baseptr
     TYPE(MPI_Win), INTENT(OUT) :: win
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES ENTRANTS

  • size: Taille de la fenêtre en octets (entier non négatif).
  • disp_unit: Unité de déplacement locale, en octets (entier positif).
  • info: Argument info (handle).
  • comm: Communicateur (handle).

PARAMÈTRES RENVOYÉS

  • baseptr: Adresse initiale de la fenêtre.
  • win: Objet fenêtre renvoyé par l'appel (handle).
  • ierror: Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

MPI_Win_allocate est un appel collectif exécuté par tous les processus du groupe de comm. Sur chaque processus, il alloue de la mémoire d'au moins size octets, renvoie un pointeur vers celle-ci et renvoie un objet fenêtre qui peut être utilisé par tous les processus de comm pour effectuer des opérations RMA. La mémoire renvoyée consiste en size octets locaux à chaque processus, commençant à l'adresse baseptr et est associée à la fenêtre comme si l'utilisateur avait appelé MPI_Win_create sur une mémoire existante. L'argument size peut être différent à chaque processus et size = 0 est valide ; cependant, une bibliothèque peut allouer et exposer plus de mémoire afin de créer une allocation symétrique globale et rapide. La discussion et les justifications de MPI_Alloc_mem et MPI_Free_mem dans la section 8.2 de MPI-3.1 s'appliquent également à MPI_Win_allocate ; en particulier, voir la justification dans la section 8.2 de MPI-3.1 pour une explication du type utilisé pour baseptr.

L'argument de l'unité de déplacement est fourni pour faciliter l'arithmétique d'adresse dans les opérations RMA : l'argument de déplacement cible d'une opération RMA est mis à l'échelle par le facteur disp_unit spécifié par le processus cible, lors de la création de la fenêtre.

Pour les clés d'information prises en charge, voir MPI_Win_create.

NOTES

Les choix courants pour disp_unit sont 1 (pas de mise à l'échelle), et (en syntaxe C) sizeof(type), pour une fenêtre constituée d'un tableau d'éléments de type type. Ce dernier choix permettra d'utiliser des indices de tableau dans les appels RMA, et de les mettre à l'échelle correctement aux déplacements en octets, même dans un environnement hétérogène.

Appeler MPI_Win_free désallouera la mémoire allouée par MPI_Win_allocate. Il est donc erroné de libérer manuellement baseptr.

NOTES C

Bien que baseptr soit de type void *, c'est pour permettre une utilisation facile de tout objet pointeur pour ce paramètre. Cet argument est en réalité un type void **.

ERREURS

Presque toutes les routines MPI renvoient une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire, avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou par l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme de tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.

MPI_WIN_ALLOCATE — Alloue une fenêtre d’une taille spécifiée.

SYNTAX

C

int MPI_Win_allocate(MPI_Aint size, int disp_unit, MPI_Info info, MPI_Comm comm, void *baseptr);

Fortran

SUBROUTINE MPI_Win_allocate(size, disp_unit, info, comm, baseptr, ierr)
INTEGER,INTENT(OUT):: size, disp_unit, ierr
INTEGER,INTENT(IN):: info, comm
TYPE(MPI_Aint),INTENT(OUT):: baseptr

C++

WinMPI::Win(MPI::Aint size, int disp_unit, const MPI::Info& info, const MPI::Comm& comm);

DESCRIPTION

La fonction MPI_Win_allocate alloue un objet de fenêtre d’une taille spécifiée par l’argument size. L’argument disp_unit spécifie l’unité de déplacement pour l’adresse de base de la fenêtre. La fenêtre allouée peut être utilisée pour la communication d’accès direct à la mémoire sur le segment de mémoire alloué. L’argument info peut être utilisé pour spécifier des attributs de la fenêtre, tels que des informations sur le partage ou la localité. La fenêtre est associée à l’objet communicateur comm. L’argument baseptr renvoie l’adresse de base du segment de mémoire alloué.

PARAMÈTRES

size
Nombre d’octets à allouer pour la fenêtre. (Entier d’entrée)
disp_unit
Unité de déplacement pour les adresses dans la fenêtre. (Entier d’entrée)
info
Objet d’informations spécifiant des attributs de la fenêtre. (Entier d’entrée)
comm
Communicateur associé à la fenêtre. (Entier d’entrée)
baseptr
Pointeur vers l’adresse de base du segment de mémoire alloué. (Pointeur de sortie)
ierr
Code de retour. (Entier de sortie)

ERREURS

Toutes les routines MPI peuvent échouer. Les routines MPI peuvent échouer si l’objet communicateur spécifié n’est pas valide ou si un autre des paramètres spécifiés n’est pas valide. Pour plus de détails, voir la section « Gestion des erreurs » du manuel MPI.

NOTES

La fonction MPI_Win_allocate est une extension de la norme MPI-3. Elle n’est pas disponible dans les versions antérieures de MPI.

C NOTES

Dans la version C, baseptr est un pointeur de type void*. Il est de la responsabilité du programmeur de convertir ce pointeur vers le type de données approprié.

ERREURS

Aucune.
