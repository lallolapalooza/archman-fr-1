MPI_Comm_test_inter — Teste si un communicateur est un intercommunicateur.

Syntaxe

Syntaxe C

#include <mpi.h>
int MPI_Comm_test_inter(MPI_Comm comm, int *flag)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_COMM_TEST_INTER(COMM, FLAG, IERROR)
     INTEGER COMM, IERROR
     LOGICAL FLAG

Syntaxe Fortran 2008

USE mpi_f08
MPI_Comm_test_inter(comm, flag, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     LOGICAL, INTENT(OUT) :: flag
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Paramètres d'entrée

•
comm : Communicateur (handle).

Paramètres de sortie

  • flag (Logique.) :
  • ierror : Fortran uniquement : Statut d'erreur (entier).

Description

Cette routine locale permet à l'application de déterminer le type d'un communicateur. Elle renvoie vrai pour un intercommunicateur, faux pour un intracommunicateur.

Le type de communicateur affecte également la valeur renvoyée par trois fonctions supplémentaires. Lorsqu'il s'agit d'un intracommunicateur (permettant la communication au sein d'un groupe), les fonctions suivantes renvoient les valeurs attendues, taille du groupe, groupe et rang. Lorsqu'il s'agit d'un intercommunicateur, cependant, elles renvoient les valeurs suivantes :

MPI_Comm_size
Renvoie la taille du groupe local.
MPI_Comm_group
Renvoie le groupe local.
MPI_Comm_rank
Renvoie le rang dans le groupe local.

Pour renvoyer le groupe distant et la taille du groupe distant d'un intercommunicateur, utilisez les fonctions MPI_Comm_remote_group et MPI_Comm_remote_size.

L'opération MPI_Comm_compare est valide pour les intercommunicateurs. Les deux communicateurs doivent être soit des intracommunicateurs, soit des intercommunicateurs, sinon MPI_UNEQUAL sera renvoyé. Les groupes locaux et distants doivent être comparés correctement pour obtenir les résultats MPI_CONGRUENT et MPI_SIMILAR. Il est possible que MPI_SIMILAR soit renvoyé car le groupe local ou distant était similaire mais pas identique.

Les accesseurs d'intercommunicateurs (MPI_Comm_test_inter, MPI_Comm_remote_size, MPI_Comm_remote_group) sont toutes des opérations locales.

Erreurs

Presque toutes les routines MPI renvoient une valeur d'erreur ; dans les routines C, la valeur d'erreur est renvoyée comme résultat de la fonction et dans les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, la fonction de gestionnaire d'erreur associée à l'objet de communication (par exemple, communicateur, fenêtre, fichier) utilisé est appelée. S'il n'y a pas d'objet de communication associé à l'appel MPI, l'appel est considéré comme étant associé à MPI_COMM_SELF et le gestionnaire d'erreur correspondant est appelé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le modèle de Sessions est utilisé exclusivement), l'erreur élève le gestionnaire d'erreur initial. Le gestionnaire d'erreur initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lorsque le modèle du Monde est utilisé, ou via l'argument mpi_initial_errhandler de mpiexec ou la clé d'information MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreur approprié n'est défini, le gestionnaire d'erreur MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreur MPI_ERRORS_ABORT pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreur par défaut qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Déclenche l'arrêt de l'exécution de tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreur qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est invoqué sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est invoqué sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur qui contient le groupe des processus dans la fenêtre ou le fichier correspondant. S'il est invoqué sur une session, il arrête uniquement le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreur en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou dans MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Note : Les gestionnaires d'erreur MPI ne garantissent pas qu'une application MPI puisse continuer après une erreur.

Voir la section Gestion des erreurs de la documentation MPI-3.1 pour plus d'informations.
