MPI_Session_init(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

MPI_Session_init(3) Open MPI MPI_Session_init(3)

MPI_Session_init crée un nouveau handle de session.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Session_init(MPI_Info info, MPI_Errhandler errhandler, MPI_Session *session)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_SESSION_INIT(INFO, ERRHANDLER, SESSION, IERROR)
    INTEGER INFO, ERRHANDLER, SESSION, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Session_init(info, errhandler, session, ierror)
    TYPE(MPI_Info), INTENT(IN) :: info
    TYPE(MPI_Errhandler), INTENT(IN) :: errhandler
    TYPE(MPI_Session), INTENT(OUT) :: session
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Paramètres d'entrée

  • info : handle d'informations
errhandler
gestionnaire d'erreurs à associer au handle de session retourné

Paramètres de sortie

  • session : Nouvelle session (handle).
  • ierror : Fortran seulement : État d'erreur (entier).

Description

MPI_Session_init est utilisé pour créer une session MPI. Le handle de session retourné peut être utilisé pour interroger le système d'exécution sur les caractéristiques du processus dans lequel il s'exécute, ainsi que d'autres ressources système. D'autres communications MPI peuvent également être initiées dans le contexte d'un handle de session. Toutes les sessions doivent être finalisées en utilisant MPI_Session_finalize avant que le processus MPI ne se termine.

Plusieurs sessions peuvent être créées et détruites au cours de la vie d'un processus MPI. Ceci est différent du modèle du monde MPI, qui ne peut être initié qu'une seule fois (puis finalisé) au cours de la vie d'un processus MPI.

Notes

L'argument info est utilisé pour demander des fonctionnalités MPI et des capacités spécifiques à l'implémentation MPI.

L'argument errhandler spécifie un gestionnaire d'erreurs à appeler si l'appel à MPI_Session_init rencontre une erreur.

Erreurs

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C retournent la valeur d'erreur comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs actuel associé à l'objet de communication (par exemple, communicator, window, file) de l'appel est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, l'appel est considéré comme associé à MPI_COMM_SELF et le gestionnaire d'erreurs associé est invoqué. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le modèle de sessions est utilisé exclusivement), l'erreur initiale est générée. Le gestionnaire d'erreur initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle mondial, ou via l'argument CLI mpi_initial_errhandler pour mpiexec, ou la clé info pour MPI_Comm_spawn/MPI_Comm_spawn_multiple. S'il n'y a pas d'autre gestionnaire d'erreur approprié, le gestionnaire d'erreur MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreur MPI_ERRORS_ABORT pour les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme pour tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être appelé sur un communicator, une window, un file ou une session. Lorsqu'il est appelé sur un communicator, il agit comme si MPI_Abort avait été appelé sur ce communicator. S'il est appelé sur une window ou un file, il agit comme si MPI_Abort avait été appelé sur un communicator contenant les processus dans la window ou le file correspondant. S'il est appelé sur une session, il arrête uniquement le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Note : MPI ne garantit pas qu'une application MPI puisse continuer après une erreur.

Voir la section sur la gestion des erreurs de la documentation MPI-3.1 pour plus d'informations.
