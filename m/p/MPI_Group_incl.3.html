MPI_GROUP_INCL(3) Open MPI MPI_GROUP_INCL(3)

MPI_Group_incl — Produit un groupe en réorganisant un groupe existant et en ne prenant que les membres listés.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Group_incl(MPI_Group group, int n, const int ranks[],
    MPI_Group *newgroup)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_GROUP_INCL(GROUP, N, RANKS, NEWGROUP, IERROR)
    INTEGER GROUP, N, RANKS(*), NEWGROUP, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Group_incl(group, n, ranks, newgroup, ierror)
    TYPE(MPI_Group), INTENT(IN) :: group
    INTEGER, INTENT(IN) :: n, ranks(n)
    TYPE(MPI_Group), INTENT(OUT) :: newgroup
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES ENTRANTS

  • group : Groupe (handle).
n
Nombre d'éléments dans le tableau ranks (et taille du nouveau groupe) (entier).
•
ranks
Rangs des processus dans le groupe à faire apparaître dans le nouveau groupe (tableau d'entiers).

PARAMÈTRES SORTANTS

•
newgroup
Nouveau groupe dérivé du ci-dessus, dans l'ordre défini par ranks (handle).
•
ierror : Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

La fonction MPI_Group_incl crée un groupe group_out qui se compose des n processus du groupe avec les rangs rank[0], …, rank[n-1] ; le processus avec le rang i dans group_out est le processus avec le rang ranks[i] dans group. Chacun des n éléments de ranks doit être un rang valide dans group et tous les éléments doivent être distincts, sinon le programme est erroné. Si n = 0, alors group_out est MPI_GROUP_EMPTY. Cette fonction peut, par exemple, être utilisée pour réorganiser les éléments d'un groupe.

NOTE

Cette implémentation ne vérifie actuellement pas l'absence de doublons dans la liste des rangs.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de Sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler à mpiexec ou la clé d'information à MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme pour tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
