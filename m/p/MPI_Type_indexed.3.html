MPI_Type_indexed, MPI_Type_create_hindexed - Crée un type de données indexé.

Syntaxe

Syntaxe C

#include <mpi.h>
int MPI_Type_indexed(int count, const int array_of_blocklengths[],
     const int array_of_displacements[], MPI_Datatype oldtype,
     MPI_Datatype *newtype)
int MPI_Type_create_hindexed(int count,
     const int array_of_blocklengths[],
     const MPI_Aint array_of_displacements[], MPI_Datatype oldtype,
     MPI_Datatype *newtype)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_TYPE_INDEXED(COUNT, ARRAY_OF_BLOCKLENGTHS,
             ARRAY_OF_DISPLACEMENTS, OLDTYPE, NEWTYPE, IERROR)
     INTEGER COUNT, ARRAY_OF_BLOCKLENGTHS(*)
     INTEGER ARRAY_OF_DISPLACEMENTS(*), OLDTYPE, NEWTYPE
     INTEGER IERROR
MPI_TYPE_CREATE_HINDEXED(COUNT, ARRAY_OF_BLOCKLENGTHS,
             ARRAY_OF_DISPLACEMENTS, OLDTYPE, NEWTYPE, IERROR)
     INTEGER COUNT, ARRAY_OF_BLOCKLENGTHS(*)
     INTEGER OLDTYPE, NEWTYPE
     INTEGER(KIND=MPI_ADDRESS_KIND) ARRAY_OF_DISPLACEMENTS(*)
     INTEGER IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Type_indexed(count, array_of_blocklengths, array_of_displacements,
             oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: count, array_of_blocklengths(count),
     array_of_displacements(count)
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPI_Type_create_hindexed(count, array_of_blocklengths,
             array_of_displacements, oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: count, array_of_blocklengths(count)
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) ::
     array_of_displacements(count)
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Paramètres d'entrée

  • count: Nombre de blocs — également le nombre d'entrées dans array_of_displacements et array_of_blocklengths (entier non négatif).
  • array_of_blocklengths: Nombre d'éléments par bloc (tableau d'entiers non négatifs).
  • array_of_displacements: Décalage de chaque bloc, en multiples de l'extension du type ancien pour MPI_Type_indexed et en octets pour MPI_Type_create_hindexed (tableau d'entiers pour MPI_TYPE_INDEXED, tableau de MPI_Aint pour MPI_TYPE_CREATE_HINDEXED).
  • oldtype: Ancien type de données (handle).

Paramètres de sortie

  • newtype: Nouveau type de données (handle).
  • ierror: En Fortran uniquement : Code d'erreur (entier).

Description

La fonction MPI_Type_indexed permet de répliquer un type de données ancien dans une séquence de blocs (chaque bloc est une concaténation du type ancien), où chaque bloc peut contenir un nombre différent de copies et avoir un décalage différent. Tous les décalages de bloc sont des multiples de l'extension du type de données ancien.

Exemple : Supposons que le type ancien ait un type de mappage {(double, 0), (char, 8)}, avec une extension de 16. Soit B = (3, 1) et D = (4, 0). Un appel à MPI_Type_indexed(2, B, D, oldtype, newtype) renvoie un type de données avec un type de mappage

{(double, 64), (char, 72), (double, 80), (char, 88),
(double, 96), (char, 104),
(double, 0), (char, 8)}

C'est-à-dire trois copies du type ancien commençant au décalage 4 x 16 = 64, et une copie commençant au décalage 0.

En général, supposez que le type ancien a un type de mappage

{(type(0), disp(0)), ..., (type(n-1), disp(n-1))},
avec une extension ex. Soit B l'argument array_of_blocklength et D l'argument array_of_displacements. Le nouveau type de données a
n x S ^count-1
    i = 0           B[i]  entrées :
    {(type(0), disp(0) + D[0]* ex), ...,
    (type(n-1), disp(n-1) + D[0]* ex), ...,
    (type(0), disp(0) + (D[0] + B[0] -1)* ex), ...,
    (type(n-1), disp(n-1) + (D[0]+ B[0] -1)* ex), ...,
    (type(0), disp(0) + D[count-1]* ex), ...,
    (type(n-1), disp(n-1) + D[count-1]* ex), ...,
    (type(0), disp(0) +  (D[count-1] + B[count-1] -1)* ex), ...,
    (type(n-1), disp(n-1) + (D[count-1] + B[count-1] -1)* ex)}

Un appel à MPI_Type_vector(count, blocklength, stride, oldtype, newtype) est équivalent à un appel à MPI_Type_indexed(count, B, D, oldtype, newtype) où

    D[j] = j * stride, j = 0,..., count-1
et
    B[j] = blocklength, j = 0, .., count-1

La fonction MPI_Type_create_hindexed est identique à MPI_Type_indexed, sauf que les décalages de bloc dans array_of_displacements sont spécifiés en octets, et non en multiples de l'extension du type ancien.

Erreurs

La plupart des routines MPI renvoient une valeur d'erreur ; dans les routines C, le résultat est la valeur de retour de la fonction, et dans les routines Fortran, dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs associé à l'objet de communication (par exemple, le communicateur, la fenêtre, le fichier) actuel est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, l'appel est considéré comme associé à MPI_COMM_SELF et appellera le gestionnaire d'erreurs associé à MPI_COMM_SELF. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsqu'on utilise exclusivement le modèle de session), l'erreur appelle le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lorsqu'on utilise le modèle de monde, ou l'argument mpi_initial_errhandler de mpiexec ou la clé d'info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'est défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT pour les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs par défaut qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque la terminaison du programme de tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être appelé sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, seul le processus local est arrêté.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Note : MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section sur la gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
