MPIX_Query_cuda_support(3)

Paquet: openmpi

MPIX_QUERY_CUDA_SUPPORT(3) Open MPI MPIX_QUERY_CUDA_SUPPORT(3)

MPIX_Query_cuda_support - Renvoie 1 s'il existe un support CUDA et 0 sinon.

SYNTAXE

Syntaxe C

#include <mpi.h>
#include <mpi-ext.h>
int MPIX_Query_cuda_support(void)

Syntaxe Fortran

Il n'y a pas de liaison Fortran pour cette fonction.

Syntaxe C++

Il n'y a pas de liaison C++ pour cette fonction.

DESCRIPTION

Cette fonction fait partie d'une extension Open MPI ; elle ne fait pas partie de la norme MPI.

Cette routine renvoie 1 si la bibliothèque MPI a été compilée avec la bibliothèque NVIDIA CUDA et si le runtime prend en charge les tampons CUDA. Sinon, elle renvoie 0. Cette routine doit être appelée après l'initialisation de MPI, par exemple, par un appel à MPI_Init(3) ou MPI_Init_thread(3).

L'inclusion du fichier spécifique à Open MPI <mpi-ext.h> définira le macro du préprocesseur C OMPI_HAVE_MPI_EXT à 1. Sinon, il sera indéfini. Ce macro peut être utilisé par les applications comme sentinelle pour savoir si <mpi-ext.h> a été inclus ou non.

L'extension CUDA Open MPI est construite par défaut (indépendamment du fait qu'Open MPI ait été compilé ou non avec le support CUDA), mais elle aurait pu être désactivée par une action administrative. Il est donc plus sûr pour les applications de vérifier que le macro du préprocesseur OMPI_HAVE_MPI_EXT_CUDA est défini et est égal à 1 pour savoir si la fonction MPIX_Query_CUDA_support() est disponible. La vérification de ce macro protège également l'utilisation de cette fonction lors de la compilation de l'application avec d'anciennes versions d'Open MPI ou d'autres implémentations MPI qui n'ont pas cette fonction.

EXEMPLES

#include <stdio.h>
#include <mpi.h>
#include <mpi-ext.h> /* Nécessaire pour la vérification CUDA-aware */
int main(int argc, char *argv[])
{
    MPI_Init(&argc, &argv);
    bool happy = false;
#if defined(OMPI_HAVE_MPI_EXT_CUDA) && OMPI_HAVE_MPI_EXT_CUDA
    happy = (bool) MPIX_Query_cuda_support();
#endif
    if (happy) {
        printf("Cette installation Open MPI dispose du support CUDA-aware.\n");
    } else {
        printf("Cette installation Open MPI ne dispose pas du support CUDA-aware.\n");
    }
    MPI_Finalize();
    return 0;
}
