MPI_Type_match_size — Retourne un type de données MPI d'un type et d'une taille donnés

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Type_match_size(int typeclass, int size,
     MPI_Datatype *type)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_TYPE_MATCH_SIZE(TYPECLASS, SIZE, TYPE, IERROR)
     INTEGER TYPECLASS, SIZE, TYPE, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Type_match_size(typeclass, size, datatype, ierror)
     INTEGER, INTENT(IN) :: typeclass, size
     TYPE(MPI_Datatype), INTENT(OUT) :: datatype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETRES ENTRANTS

  • typeclass : Spécificateur de type générique (entier).
  • size : Taille, en octets, de la représentation (entier).

PARAMETRES SORTANTS

  • type : Type de données avec le type et la taille corrects (handle).
  • ierror : Fortran seulement : Statut d'erreur (entier).

DESCRIPTION

La fonction retourne un type de données MPI correspondant à une variable locale de type (typeclass, size). Le type retourné est une référence (handle) à un type prédéfini nommé, et non un duplicata. Ce type ne peut pas être libéré.

La valeur de typeclass peut être définie à MPI_TYPECLASS_REAL, MPI_TYPECLASS_INTEGER, ou MPI_TYPECLASS_COMPLEX, correspondant au type de données souhaité.

MPI_type_match_size peut être utilisé pour obtenir un type spécifique à la taille qui correspond à un type intrinsèque numérique Fortran : appeler d'abord MPI_Sizeof pour calculer la taille de la variable, puis appeler MPI_Type_match_size pour trouver un type approprié. En C, utiliser l'builtin sizeof au lieu de MPI_Sizeof.

Il est erroné de spécifier une taille non supportée par le compilateur.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du Modèle de Sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou par l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme pour tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
