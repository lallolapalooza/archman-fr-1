MPI_CART_SUB(3) Open MPI MPI_CART_SUB(3)

MPI_Cart_sub — Partitions un communicateur en sous-groupes, qui forment des sous-grilles cartésiennes de dimension inférieure.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Cart_sub(MPI_Comm comm, const int remain_dims[], MPI_Comm *comm_new)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_CART_SUB(COMM, REMAIN_DIMS, COMM_NEW, IERROR)
    INTEGER COMM, COMM_NEW, IERROR
    LOGICAL REMAIN_DIMS(*)

Syntaxe Fortran 2008

USE mpi_f08
MPI_Cart_sub(comm, remain_dims, newcomm, ierror)
    TYPE(MPI_Comm), INTENT(IN) :: comm
    LOGICAL, INTENT(IN) :: remain_dims(*)
    TYPE(MPI_Comm), INTENT(OUT) :: newcomm
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETRES ENTRANTS

  • comm : Communicateur avec structure cartésienne (handle).
remain_dims
Le i-ème élément de remain_dims spécifie si la i-ème dimension est conservée dans la sous-grille (true) ou abandonnée (false) (vecteur logique).

PARAMETRES SORTANTS

•
comm_new
Communicateur contenant la sous-grille qui inclut le processus appelant (handle).
•
ierror : Fortran seulement : Statut d'erreur (entier).

DESCRIPTION

Si une topologie cartésienne a été créée avec MPI_Cart_create, la fonction MPI_Cart_sub peut être utilisée pour partitionner le groupe du communicateur en sous-groupes qui forment des sous-grilles cartésiennes de dimension inférieure, et pour construire pour chaque sous-groupe un communicateur avec la topologie cartésienne associée. (Cette fonction est étroitement liée à MPI_Comm_split.)

Exemple : Supposons que MPI_Cart_create( ..., comm) ait défini une grille (2 x 3 x 4). Soit remain_dims = (true, false, true). Alors un appel à

MPI_Cart_sub(comm, remain_dims, comm_new);

créera trois communicateurs, chacun avec huit processus dans une topologie cartésienne 2 x 4. Si remain_dims = (false, false, true), alors l'appel à MPI_Cart_sub(comm, remain_dims, comm_new) créera six communicateurs disjoints, chacun avec quatre processus, dans une topologie cartésienne unidimensionnelle.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire, avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsqu'on utilise exclusivement le modèle de Sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou via l'argument de ligne de commande mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme sur tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
