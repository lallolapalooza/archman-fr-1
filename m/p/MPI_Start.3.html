MPI_START(3) Open MPI MPI_START(3)

MPI_Start — Initialise une communication à l'aide d'un descripteur de requête persistant.

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_Start(MPI_Request *request)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_START(REQUEST, IERROR)
     INTEGER REQUEST, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Start(request, ierror)
     TYPE(MPI_Request), INTENT(INOUT) :: request
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRE D'ENTRÉE

•
request : Descripteur de communication (handle).

PARAMÈTRE DE SORTIE

•
ierror : Fortran seulement : Statut d'erreur (entier).

DESCRIPTION

Une communication (envoi ou réception) qui utilise une requête persistante est initiée par la fonction MPI_Start.

L'argument, request, est un descripteur retourné par l'une des fonctions d'initialisation de requête de communication persistante (MPI_Send_init, MPI_Bsend_init, MPI_Ssend_init, MPI_Rsend_init, MPI_Recv_init). La requête associée doit être inactive et devient active une fois l'appel effectué.

Si la requête concerne un envoi en mode prêt (ready mode), une réception correspondante doit être postée avant l'appel. À partir du moment où l'appel est effectué jusqu'à la fin de l'opération, le tampon de communication ne doit pas être accédé.

L'appel est local, avec des sémantiques similaires aux opérations de communication non bloquantes (voir la Section 3.7 de la Norme MPI, « Communication non bloquante. ») C'est-à-dire qu'un appel à MPI_Start avec une requête créée par MPI_Send_init démarre une communication de la même manière qu'un appel à MPI_Isend ; un appel à MPI_Start avec une requête créée par MPI_Bsend_init démarre une communication de la même manière qu'un appel à MPI_Ibsend ; et ainsi de suite.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreur MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreur MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions) l'erreur déclenche le gestionnaire d'erreur initial. Le gestionnaire d'erreur initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument de ligne de commande mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreur approprié n'a été défini, alors le gestionnaire d'erreur MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreur MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreur prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'abandon du programme par tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreur qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, il n'abandonne que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreur en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
