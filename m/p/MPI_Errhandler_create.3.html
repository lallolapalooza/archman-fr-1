MPI_Errhandler_create(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

MPI_ERRHANDLER_CREATE(3) Open MPI MPI_ERRHANDLER_CREATE(3)

MPI_Errhandler_create — Crée un gestionnaire d'erreurs de type MPI — cette routine est dépréciée au profit de MPI_Comm_create_errhandler.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Errhandler_create(MPI_Handler_function *function,
     MPI_Errhandler *errhandler)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_ERRHANDLER_CREATE(FUNCTION, ERRHANDLER, IERROR)
     EXTERNAL        FUNCTION
     INTEGER ERRHANDLER, IERROR

PARAMÈTRE D'ENTRÉE

•
function : procédure de gestion des erreurs définie par l'utilisateur.

PARAMÈTRES DE SORTIE

  • errhandler : gestionnaire d'erreurs MPI (handle).
  • ierror : Fortran uniquement : statut d'erreur (entier).

DESCRIPTION

Notez que l'utilisation de cette routine est dépréciée depuis MPI-2. Utilisez plutôt MPI_Comm_create_errhandler.

Enregistre la routine utilisateur 'function' pour être utilisée comme gestionnaire d'erreurs MPI. Retourne dans 'errhandler' un handle vers le gestionnaire d'erreurs enregistré.

En langage C, la routine utilisateur doit être une fonction C de type MPI_Handler_function, qui est définie comme suit :

typedef void (MPI_Handler_function)(MPI_Comm *, int *, ...);

Le premier argument est le communicateur en cours d'utilisation. Le second est le code d'erreur à retourner par la routine MPI qui a déclenché l'erreur. Si la routine aurait retourné MPI_ERR_IN_STATUS, il s'agit du code d'erreur retourné dans le statut de la requête qui a provoqué l'invocation du gestionnaire d'erreurs. Les arguments restants sont des arguments stdargs dont le nombre et la signification dépendent de l'implémentation. Une implémentation doit clairement documenter ces arguments. Les adresses sont utilisées de manière à ce que le gestionnaire puisse être écrit en Fortran.

NOTE

La norme MPI stipule qu'une implémentation peut faire de la valeur de sortie (errhandler) simplement l'adresse de la fonction. Cependant, l'action de MPI_Errhandler_free rend cela impossible, car il est requis de définir la valeur de l'argument à MPI_ERRHANDLER_NULL. De plus, le gestionnaire d'erreurs réel doit rester jusqu'à ce que tous les communicateurs qui l'utilisent soient libérés.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C en résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI courant associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou en utilisant exclusivement le modèle de Sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou via l'argument de ligne de commande mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme sur tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'arrête que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
