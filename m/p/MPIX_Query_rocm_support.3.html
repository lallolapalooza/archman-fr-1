MPIX_Query_rocm_support(3)

Paquet: openmpi

MPIX_QUERY_ROCM_SUPPORT(3) Open MPI MPIX_QUERY_ROCM_SUPPORT(3)

MPIX_Query_rocm_support - Retourne 1 s'il existe une prise en charge ROCm consciente de MPI et 0 sinon.

SYNTAXE

Syntaxe C

#include <mpi.h>
#include <mpi-ext.h>
int MPIX_Query_rocm_support(void)

Syntaxe Fortran

Il n'y a pas de liaison Fortran pour cette fonction.

Syntaxe C++

Il n'y a pas de liaison C++ pour cette fonction.

DESCRIPTION

Cette fonction fait partie d'une extension Open MPI ; elle ne fait pas partie de la norme MPI.

Cette routine retourne 1 si la bibliothèque MPI a été compilée avec la bibliothèque AMD ROCm et si le runtime prend en charge les tampons ROCm. Sinon, elle retourne 0. Cette routine doit être appelée après l'initialisation de MPI, par exemple, par un appel à MPI_Init(3) ou MPI_Init_thread(3).

L'inclusion du fichier spécifique à Open MPI <mpi-ext.h> définira la macro du préprocesseur C OMPI_HAVE_MPI_EXT à 1. Sinon, elle sera non définie. Cette macro peut être utilisée par les applications comme un indicateur pour savoir si <mpi-ext.h> a été inclus ou non.

L'extension ROCm d'Open MPI est construite par défaut (indépendamment du fait qu'Open MPI ait été compilé avec la prise en charge de ROCm ou non), mais elle pourrait avoir été désactivée par une action administrative. Il est donc préférable que les applications vérifient que la macro du préprocesseur OMPI_HAVE_MPI_EXT_ROCM est définie et est égale à 1 pour savoir si la fonction MPIX_Query_rocm_support() est disponible. La vérification de cette macro protège également l'utilisation de cette fonction lors de la compilation de l'application avec des versions plus anciennes d'Open MPI ou d'autres implémentations MPI qui n'ont pas cette fonction.

EXEMPLES

#include <stdio.h>
#include <mpi.h>
#include <mpi-ext.h> /* Nécessaire pour la vérification ROCm */
int main(int argc, char *argv[])
{
    MPI_Init(&argc, &argv);
    bool happy = false;
#if defined(OMPI_HAVE_MPI_EXT_ROCM) && OMPI_HAVE_MPI_EXT_ROCM
    happy = (bool) MPIX_Query_rocm_support();
#endif
    if (happy) {
        printf("Cette installation Open MPI dispose d'une prise en charge ROCm.\n");
    } else {
        printf("Cette installation Open MPI ne dispose pas d'une prise en charge ROCm.\n");
    }
    MPI_Finalize();
    return 0;
}
