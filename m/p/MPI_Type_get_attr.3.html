MPI_TYPE_GET_ATTR(3) Open MPI MPI_TYPE_GET_ATTR(3)

MPI_Type_get_attr — Retourne l'attribut associé à un type de données.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Type_get_attr(MPI_Datatype type, int type_keyval, void *attribute_val, int *flag)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_TYPE_GET_ATTR(TYPE, TYPE_KEYVAL, ATTRIBUTE_VAL, FLAG, IERROR)
     INTEGER TYPE, TYPE_KEYVAL, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) ATTRIBUTE_VAL
     LOGICAL FLAG

Syntaxe Fortran 2008

USE mpi_f08
MPI_Type_get_attr(datatype, type_keyval, attribute_val, flag, ierror)
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER, INTENT(IN) :: type_keyval
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(OUT) :: attribute_val
     LOGICAL, INTENT(OUT) :: flag
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES ENTRANTS

  • type: Type de données auquel l'attribut est attaché (handle).
  • type_keyval: Valeur de clé (entier).

PARAMÈTRES SORTANTS

  • attribute_val: Valeur de l'attribut, sauf si flag = faux
  • flag: « faux » si aucun attribut n'est associé à la clé (logique).
  • ierror: Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

Pour le type de données donné, MPI_Type_get_attr retourne une valeur d'attribut correspondant à la valeur de clé spécifiée.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C en tant que résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle du monde, ou via l'argument de ligne de commande mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme pour tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, seul le processus local est avorté.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
