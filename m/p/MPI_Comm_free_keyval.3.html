MPI_COMM_FREE_KEYVAL(3) Open MPI MPI_COMM_FREE_KEYVAL(3)

MPI_Comm_free_keyval — Libère la clé d'attribut pour l'attribut de cache de communicateur.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Comm_free_keyval(int *comm_keyval)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_COMM_FREE_KEYVAL(COMM_KEYVAL, IERROR)
     INTEGER COMM_KEYVAL, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Comm_free_keyval(comm_keyval, ierror)
     INTEGER, INTENT(INOUT) :: comm_keyval
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRE D'ENTRÉE/SORTIE

•
comm_keyval:

PARAMÈTRE DE SORTIE

•
ierror: Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

MPI_Comm_free_keyval libère une clé d'attribut existante. Cette fonction définit la valeur de keyval à MPI_KEYVAL_INVALID. Notez qu'il n'est pas une erreur de libérer une clé d'attribut en cours d'utilisation, car la libération réelle n'a lieu qu'après la libération de toutes les références (dans d'autres communicateurs sur le processus) à la clé. Ces références doivent être explicitement libérées par le programme, soit via des appels à MPI_Comm_delete_attr qui libèrent une instance d'attribut, soit via des appels à MPI_Comm_free qui libèrent toutes les instances d'attribut associées au communicateur libéré.

Cet appel est identique à l'appel MPI_Keyval_free mais est nécessaire pour correspondre à la fonction de création spécifique au communicateur introduite dans la norme MPI-2. L'utilisation de MPI_Keyval_free est dépréciée.

NOTES

Les valeurs de clé sont globales (elles peuvent être utilisées avec tous les communicateurs).

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de Sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle Monde, ou l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'abandon de tous les processus MPI connectés par le programme.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Consultez la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Consultez la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
