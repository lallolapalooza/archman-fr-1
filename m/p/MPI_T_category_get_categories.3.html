MPI_T_category_get_categories — Interroger les catégories contenues dans une catégorie

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_T_category_get_categories(int cat_index, int len, int indices[])

PARAMÈTRES ENTRANTS

  • cat_index: Index de la catégorie à interroger.
  • len: La longueur du tableau d'indices.

PARAMÈTRES SORTANTS

•
indices: Un tableau d'entiers de taille len, indiquant les indices des catégories.

DESCRIPTION

MPI_T_category_get_categories peut être utilisé pour interroger quelles autres catégories sont contenues dans une catégorie.

ERREURS

MPI_T_category_get_categories échouera si :

  • MPI_T_ERR_NOT_INITIALIZED: L'interface des outils MPI n'a pas été initialisée
  • MPI_T_ERR_INVALID_INDEX: L'indice de catégorie est invalide
