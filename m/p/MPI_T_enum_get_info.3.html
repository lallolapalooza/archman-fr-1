MPI_T_enum_get_info — Interroger des informations sur un énumérateur

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_T_enum_get_info(MPI_T_enum enumtype, int *num, char *name, int *name_len)

PARAMÈTRES D'ENTRÉE

•
enumtype : Énumérateur à interroger.

PARAMÈTRES D'ENTRÉE/SORTIE

•
name_len : Longueur de la chaîne et/ou du tampon pour le nom.

PARAMÈTRES DE SORTIE

  • num : nombre de valeurs discrètes représentées par cette énumération.
  • name : Tampon pour retourner la chaîne contenant le nom de la catégorie.

DESCRIPTION

MPI_T_enum_get_info peut être utilisée pour interroger des informations sur un énumérateur. La fonction retourne le nombre de valeurs discrètes représentées par cet énumérateur dans le paramètre num.

NOTES

Cette fonction d'interface d'outils MPI retourne le nom de l'énumération sous forme de chaîne de caractères. Cette fonction prend deux arguments pour la chaîne : name qui spécifie un tampon où le nom doit être stocké, et name_len qui doit initialement spécifier la taille du tampon pointé par name. Cette fonction copiera au maximum name_len - 1 caractères du nom et définira name_len au nombre de caractères retournés + 1. Si name_len est NULL ou si la valeur spécifiée dans name_len est 0, le tampon name est ignoré et le nom de l'énumération n'est pas retourné.

ERREURS

MPI_T_enum_get_info échouera si :

  • MPI_T_ERR_NOT_INITIALIZED : L'interface des outils MPI n'est pas initialisée
  • MPI_T_ERR_INVALID_INDEX : L'énumération est invalide ou a été supprimée
