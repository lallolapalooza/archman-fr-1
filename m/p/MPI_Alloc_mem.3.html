MPI_ALLOC_MEM(3) Open MPI MPI_ALLOC_MEM(3)

MPI_Alloc_mem — Alloue un segment de mémoire spécifié.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Alloc_mem(MPI_Aint size, MPI_Info info, void *baseptr)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_ALLOC_MEM(SIZE, INFO, BASEPTR, IERROR)
     INTEGER INFO, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) SIZE, BASEPTR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Alloc_mem(size, info, baseptr, ierror)
     USE, INTRINSIC :: ISO_C_BINDING, ONLY
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: size
     TYPE(MPI_Info), INTENT(IN) :: info
     TYPE(C_PTR), INTENT(OUT) :: baseptr
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETRES D'ENTRÉE

  • size : Taille du segment de mémoire en octets (entier non négatif).
  • info : Argument d'information (handle).

PARAMETRES DE SORTIE

  • baseptr : Pointeur vers le début du segment de mémoire alloué.
  • ierror : Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

MPI_Alloc_mem alloue size octets de mémoire. L'adresse de départ de cette mémoire est retournée dans la variable baseptr.

NOTES C

Le paramètre baseptr est de type void * pour permettre le passage de n'importe quel objet pointeur pour ce paramètre. L'argument fourni doit être un pointeur vers un pointeur de type arbitraire (par exemple, void **).

NOTES FORTRAN

Les appels MPI_Alloc_mem nécessitent l'utilisation du module iso_c_binding en raison de l'utilisation de TYPE(C_PTR).

use iso_c_binding
type(c_ptr) :: alloc_ptr
integer :: size, ierr
double precision, pointer :: array(:,:)
! Un tableau 2D de 100 éléments
size = 10 * 10
call MPI_Alloc_Mem(size * 8, MPI_INFO_NULL, alloc_ptr, ierr)
! Pointer vers le tableau
call c_f_pointer(alloc_ptr, array, [10, 10])
! ... utiliser le tableau ...
! Libérer la mémoire, pas besoin de alloc_ptr
call MPI_Free_mem(array, ierr)

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler à mpiexec ou la clé d'information à MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme pour tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
