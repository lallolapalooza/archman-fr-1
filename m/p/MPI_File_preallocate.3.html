MPI_File_preallocate(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

MPI_File_preallocate(3) Open MPI MPI_File_preallocate(3)

MPI_File_preallocate préalloue une certaine taille d'espace dans la partie initiale d'un fichier (collaboratif).

Syntaxe

Syntaxe C

#include <mpi.h>
int MPI_File_preallocate(MPI_File fh, MPI_Offset size)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_FILE_PREALLOCATE(FH, SIZE, IERROR)
     INTEGER FH, IERROR
     INTEGER(KIND=MPI_OFFSET_KIND)   SIZE

Syntaxe Fortran 2008

USE mpi_f08
MPI_File_preallocate(fh, size, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     INTEGER(KIND=MPI_OFFSET_KIND), INTENT(IN) :: size
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Paramètre d'entrée/sortie

fh
Handle de fichier.

Paramètre d'entrée

size
Taille à préallouer pour le fichier, en octets (entier).

Paramètre de sortie

ierror
Fortran uniquement : Code d'erreur (entier).

Description

MPI_File_preallocate garantit que de l'espace est réservé pour les size premiers octets du fichier associé à fh. MPI_File_preallocate peut être une opération très lente.

MPI_File_preallocate est collaboratif ; tous les processus du groupe doivent passer des valeurs identiques pour size. Les régions du fichier qui ont déjà été écrites ne sont pas affectées. Pour les nouvelles régions du fichier, MPI_File_preallocate a le même effet que l'écriture de données indéfinies. Si la taille est supérieure à la taille actuelle du fichier, la taille du fichier est augmentée à size. Si la taille est inférieure ou égale à la taille actuelle du fichier, la taille du fichier reste inchangée.

Le traitement des pointeurs de fichier, des accès non bloquants et de la cohérence des fichiers est le même qu'avec MPI_File_set_size. Si le mode MPI_MODE_SEQUENTIAL a été spécifié lors de l'ouverture du fichier, il est erroné d'appeler cette routine.

Notes

Lorsque la routine collaborative MPI_File_set_size est utilisée sur un fichier UNIX, si la taille définie est inférieure à la taille actuelle du fichier, le fichier est tronqué à la position définie par la taille. Si la taille définie est supérieure à la taille actuelle du fichier, la taille du fichier devient la taille définie. L'augmentation de la taille du fichier via MPI_File_set_size crée de nouvelles régions dans le fichier avec des décalages entre l'ancienne taille du fichier et la nouvelle taille plus grande.

Les fichiers d'entrée de Sun MPI I/O n'allouent pas nécessairement d'espaces de fichier pour ces nouvelles régions. Vous pouvez réserver des espaces de fichier en utilisant la routine MPI_File_preallocate ou via une lecture ou une écriture à certaines positions.

Erreurs

La plupart des routines MPI retournent une valeur d'erreur ; les routines C retournent le résultat de la fonction et les routines Fortran dans le dernier argument.

Avant de retourner la valeur d'erreur, le gestionnaire d'erreurs associé à l'objet de communication actuel (par exemple, communicateur, fenêtre, fichier) est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, l'appel est considéré comme associé à MPI_COMM_SELF et le gestionnaire d'erreurs correspondant est appelé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque vous utilisez le modèle de Sessions exclusivement), l'erreur élève le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle de Monde, ou via l'argument mpi_initial_errhandler de mpiexec ou la clé info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. S'il n'y a pas d'autre gestionnaire d'erreurs approprié, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs par défaut qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL provoque l'abandon de tous les processus MPI connectés par le programme.
  • MPI_ERRORS_ABORT un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est invoqué sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est invoqué sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus correspondant à la fenêtre ou au fichier. S'il est invoqué sur une session, seul le processus local est abandonné.
  • MPI_ERRORS_RETURN retourne un code d'erreur à l'application.

Les programmes MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Remarque : Les programmes MPI ne garantissent pas de pouvoir continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section sur la gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
