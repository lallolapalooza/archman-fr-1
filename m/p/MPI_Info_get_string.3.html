MPI_INFO_GET_STRING(3) Open MPI MPI_INFO_GET_STRING(3)

MPI_Info_get_string — Récupère la valeur associée à une clé dans un objet info.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Info_get_string(MPI_Info info, const char *key, int *buflen, char *value, int *flag)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_INFO_GET_STRING(INFO, KEY, BUFLEN, VALUE, FLAG, IERROR)
     INTEGER INFO, BUFLEN, IERROR
     CHARACTER*(*) KEY, VALUE
     LOGICAL FLAG

Syntaxe Fortran 2008

USE mpi_f08
MPI_Info_get_string(info, key, buflen, value, flag, ierror)
     TYPE(MPI_Info), INTENT(IN) :: info
     CHARACTER(LEN=*), INTENT(IN) :: key
     INTEGER, INTENT(INOUT) :: buflen
     CHARACTER(LEN=valuelen), INTENT(OUT) :: value
     LOGICAL, INTENT(OUT) :: flag
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES ENTRANTS

  • info: Objet Info (handle).
  • key: Clé (chaîne).

PARAMÈTRE SORTANT

  • buflen À l'entrée, longueur de l'argument value. Au retour, défini à la taille requise pour: contenir la chaîne value (entier).
  • value: Valeur (chaîne).
  • flag: Retourne vrai si la clé est définie, faux sinon (booléen).
  • ierror: Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

MPI_Info_get_string récupère la valeur associée à la key dans info, s'il y en a une. Si une telle clé existe dans l'info, elle met flag à vrai et retourne la valeur dans value, sinon elle met flag à faux et laisse value inchangée. buflen à l'entrée est la taille du tampon fourni, pour la sortie de buflen c'est la taille du tampon nécessaire pour stocker la chaîne de valeur. Si le buflen passé dans la fonction est inférieur à la taille réelle nécessaire pour stocker la chaîne de valeur (y compris le terminateur nul en C), la valeur est tronquée. Au retour, la valeur de buflen sera définie à la taille de tampon requise pour contenir la chaîne de valeur. Si buflen est défini à 0, value n'est pas modifié. En C, buflen inclut l'espace requis pour le terminateur nul. En C, cette fonction retourne une chaîne terminée par un caractère nul dans tous les cas où la valeur d'entrée buflen est supérieure à 0.

Si key est plus grande que MPI_MAX_INFO_KEY, l'appel est erroné.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire, avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de Sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler à mpiexec ou la clé d'info à MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme pour tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
