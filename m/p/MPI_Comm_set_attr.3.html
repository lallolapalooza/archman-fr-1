MPI_COMM_SET_ATTR(3) Open MPI MPI_COMM_SET_ATTR(3)

MPI_Comm_set_attr — Stocke la valeur d'attribut associée à une clé.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Comm_set_attr(MPI_Comm comm, int comm_keyval, void *attribute_val)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_COMM_SET_ATTR(COMM, COMM_KEYVAL, ATTRIBUTE_VAL, IERROR)
     INTEGER COMM, COMM_KEYVAL, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) ATTRIBUTE_VAL

Syntaxe Fortran 2008

USE mpi_f08
MPI_Comm_set_attr(comm, comm_keyval, attribute_val, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, INTENT(IN) :: comm_keyval
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: attribute_val
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRE ENTRÉE/SORTIE

•
comm: Communicateur à partir duquel l'attribut sera attaché (handle).

PARAMÈTRES D'ENTRÉE

  • comm_keyval: Valeur de clé (entier).
  • attribute_val: Valeur de l'attribut.

PARAMÈTRE DE SORTIE

•
ierror: Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

MPI_Comm_set_attr stocke la valeur d'attribut spécifiée attribute_val pour une récupération ultérieure par MPI_Comm_get_attr. Si la valeur est déjà présente, le résultat est comme si MPI_Comm_delete_attr avait été appelée précédemment pour supprimer la valeur précédente (et la fonction de rappel delete_fn avait été exécutée), et qu'une nouvelle valeur avait ensuite été stockée. L'appel est erroné s'il n'y a pas de clé avec la valeur comm_keyval ; en particulier, MPI_KEYVAL_INVALID est une valeur de clé erronée. L'appel échouera si la fonction delete_fn a renvoyé un code d'erreur autre que MPI_SUCCESS.

Cette fonction remplace MPI_Attr_put, dont l'utilisation est dépréciée. La liaison C est identique. La liaison Fortran diffère en ce que attribute_val est un entier de taille d'adresse.

NOTES

Les valeurs des attributs permanents MPI_TAG_UB, MPI_HOST, MPI_IO et MPI_WTIME_IS_GLOBAL ne peuvent pas être modifiées.

Le type de la valeur de l'attribut dépend de l'utilisation de C ou de Fortran. En C, une valeur d'attribut est un pointeur (void *) ; en Fortran, il s'agit d'un système d'entiers unique de taille d'adresse pour lequel un pointeur ne rentre pas dans un entier.

Si un attribut est déjà présent, la fonction de suppression (spécifiée lors de la création de la clé correspondante) sera appelée.

ERREURS

Presque toutes les routines MPI renvoient une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI courant associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme pour tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être appelé sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
