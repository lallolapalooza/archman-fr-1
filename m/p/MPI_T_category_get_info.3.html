MPI_T_category_get_info — Interroger des informations d'une catégorie

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_T_category_get_info(int cat_index, char *name, int *name_len,
char *desc, int *desc_len, int *num_cvars, int *num_pvars,
int *num_categories)

PARAMÈTRES D'ENTRÉE

•
cat_index: Index de la catégorie à interroger.

PARAMÈTRES D'ENTRÉE/SORTIE

  • name_len: Longueur de la chaîne et/ou du tampon pour le nom.
  • desc_len: Longueur de la chaîne et/ou du tampon pour la description.

PARAMÈTRES DE SORTIE

  • name: Tampon pour retourner la chaîne contenant le nom de la catégorie.
  • desc: Tampon pour retourner la chaîne contenant la description de la catégorie.
  • num_cvars: Nombre de variables de contrôle dans la catégorie.
  • num_pvars: Nombre de variables de performance dans la catégorie.
  • num_categories: Nombre de catégories contenues dans la catégorie.

DESCRIPTION

MPI_T_category_get_info peut être utilisé pour interroger des informations d'une catégorie. La fonction retourne le nombre de variables de contrôle, de variables de performance et de sous-catégories dans la catégorie interrogée dans les arguments num_cvars, num_pvars et num_categories, respectivement.

NOTES

Cette fonction d'interface d'outils MPI retourne deux chaînes. Cette fonction prend deux arguments pour chaque chaîne : un tampon pour stocker la chaîne et une longueur qui doit initialement spécifier la taille du tampon. Si la longueur passée est n, cette fonction copiera au maximum n - 1 caractères de la chaîne dans le tampon correspondant et définira la longueur au nombre de caractères copiés - 1. Si l'argument longueur est NULL ou si la valeur spécifiée dans la longueur est 0, le tampon de chaîne correspondant est ignoré et la chaîne n'est pas retournée.

ERREURS

MPI_T_category_get_info échouera si :

  • MPI_T_ERR_NOT_INITIALIZED: L'interface des outils MPI n'est pas initialisée.
  • MPI_T_ERR_INVALID_INDEX: L'index de la catégorie est invalide.
