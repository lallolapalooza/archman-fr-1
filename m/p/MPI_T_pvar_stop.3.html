MPI_T_PVAR_STOP(3) Open MPI MPI_T_PVAR_STOP(3)

MPI_T_pvar_start, MPI_T_pvar_stop - Démarrer/arrêter une variable de performance

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_T_pvar_start(MPI_T_pvar_session session, MPI_T_pvar_handle handle)
int MPI_T_pvar_stop(MPI_T_pvar_session session, MPI_T_pvar_handle handle)

PARAMÈTRES ENTRANTS

  • session: Session d'expérience de performance.
  • handle: Handle de la variable de performance.

DESCRIPTION

MPI_T_pvar_start démarre la variable de performance avec le handle spécifié dans handle. La valeur spéciale MPI_T_PVAR_ALL_HANDLES peut être passée dans handle pour démarrer tous les handles non continus dans la session spécifiée dans session.

MPI_T_pvar_stop arrête la variable de performance avec le handle spécifié dans handle. La valeur spéciale MPI_T_PVAR_ALL_HANDLES peut être passée dans handle pour arrêter tous les handles non continus dans la session spécifiée dans session.

Les variables de performance continues ne peuvent être ni démarrées ni arrêtées.

ERREURS

MPI_T_pvar_start et MPI_T_pvar_stop() échoueront si :

  • MPI_T_ERR_NOT_INITIALIZED : L'interface des outils MPI n'est pas initialisée
  • MPI_T_ERR_INVALID_SESSION : Le paramètre session n'est pas une session valide
  • MPI_T_ERR_INVALID_HANDLE : Handle invalide ou handle non associé à la session
  • MPI_T_ERR_PVAR_NO_STARTSTOP : La variable ne peut pas être démarrée ou arrêtée
