MPI_FILE_DELETE(3) Open MPI MPI_FILE_DELETE(3)

MPI_File_delete — Supprime un fichier.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_File_delete(const char *filename, MPI_Info info)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_FILE_DELETE(FILENAME, INFO, IERROR)
     CHARACTER*(*)   FILENAME
     INTEGER INFO, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_File_delete(filename, info, ierror)
     CHARACTER(LEN=*), INTENT(IN) :: filename
     TYPE(MPI_Info), INTENT(IN) :: info
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES D'ENTRÉE

  • filename: Nom du fichier à supprimer (chaîne).
  • info: Objet d'informations (handle).

PARAMÈTRE DE SORTIE

•
ierror: Uniquement en Fortran : statut d'erreur (entier).

DESCRIPTION

MPI_File_delete supprime le fichier identifié par le nom de fichier filename, à condition qu'il ne soit pas actuellement ouvert par un processus. Il est considéré comme une erreur de supprimer un fichier avec MPI_File_delete si un processus l'a ouvert, mais MPI_File_delete ne vérifie pas cela. Si le fichier n'existe pas, MPI_File_delete renvoie une erreur de la classe MPI_ERR_NO_SUCH_FILE.

ERREURS

Presque toutes les routines MPI renvoient une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le modèle de Sessions est utilisé exclusivement), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme pour tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être appelé sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Consultez la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Consultez la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
