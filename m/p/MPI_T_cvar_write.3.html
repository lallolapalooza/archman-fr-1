MPI_T_cvar_write — Écrit la valeur d'une variable de contrôle liée

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_T_cvar_write(MPI_T_cvar_handle handle, const void *buf)

PARAMÈTRES D'ENTRÉE

  • handle: Handle de la variable de contrôle à écrire.
  • buf: Adresse initiale de l'emplacement de stockage pour la valeur de la variable.

DESCRIPTION

MPI_T_cvar_write définit la valeur de la variable de contrôle identifiée par le handle spécifié dans handle à partir du tampon fourni dans buf. L'appelant doit s'assurer que le tampon spécifié dans buf est suffisamment grand pour contenir la valeur entière de la variable de contrôle. Si la variable a une portée globale, tout appel d'écriture doit être émis sur tous les processus MPI connectés. Pour plus d'informations, voir la section 14.3.6 de MPI-3.

ERREURS

MPI_T_cvar_write échouera si :

  • MPI_T_ERR_NOT_INITIALIZED: L'interface MPI Tools n'est pas initialisée
  • MPI_T_ERR_INVALID_HANDLE: Le handle est invalide
  • MPI_T_ERR_CVAR_SET_NOT_NOW: La variable ne peut pas être définie à ce moment
  • MPI_T_ERR_CVAR_SET_NEVER: La variable ne peut pas être définie avant la fin de l'exécution

VOIR AUSSI :

  • MPI_T_cvar_handle_alloc
  • MPI_T_cvar_get_info
