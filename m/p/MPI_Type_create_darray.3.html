MPI_TYPE_CREATE_DARRAY(3) Open MPI MPI_TYPE_CREATE_DARRAY(3)

MPI_Type_create_darray — Crée un type de données tableau distribué ;

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_Type_create_darray(int size, int rank, int ndims,
     const int array_of_gsizes[], const int array_of_distribs[],
     const int array_of_dargs[], const int array_of_psizes[],
     int order, MPI_Datatype oldtype, MPI_Datatype *newtype)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_TYPE_CREATE_DARRAY(SIZE, RANK, NDIMS, ARRAY_OF_GSIZES,
     ARRAY_OF_DISTRIBS, ARRAY_OF_DARGS, ARRAY_OF_PSIZES, ORDER,
     OLDTYPE, NEWTYPE, IERROR)
     INTEGER SIZE, RANK, NDIMS, ARRAY_OF_GSIZES(*), ARRAY_OF_DISTRIBS(*),
             ARRAY_OF_DARGS(*), ARRAY_OF_PSIZES(*), ORDER, OLDTYPE,
             NEWTYPE, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Type_create_darray(size, rank, ndims, array_of_gsizes,
     array_of_distribs, array_of_dargs, array_of_psizes, order,
             oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: size, rank, ndims, array_of_gsizes(ndims),
     array_of_distribs(ndims), array_of_dargs(ndims),
     array_of_psizes(ndims), order
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES D'ENTRÉE

  • size : Taille du groupe de processus (entier positif).
  • rank : Rang dans le groupe de processus (entier non négatif).
  • ndims : Nombre de dimensions du tableau ainsi que du réseau de processus (entier positif).
  • array_of_gsizes : Nombre d'éléments de type oldtype dans chaque dimension du tableau global (tableau d'entiers positifs).
  • array_of_distribs : Distribution du tableau dans chaque dimension (tableau d'états).
  • array_of_dargs : Argument de distribution dans chaque dimension (tableau d'entiers positifs).
  • array_of_psizes : Taille du réseau de processus dans chaque dimension (tableau d'entiers positifs).
  • order : Indicateur de l'ordre de stockage du tableau (état).
  • oldtype : Ancien type de données (handle).

PARAMÈTRES DE SORTIE

  • newtype : Nouveau type de données (handle).
  • ierror : Fortran seulement : Statut d'erreur (entier).

DESCRIPTION

MPI_Type_create_darray peut être utilisé pour générer les types de données correspondant à la distribution d'un tableau ndims-dimensionnel d'éléments oldtype sur une grille ndims-dimensionnelle de processus logiques. Les dimensions inutilisées de array_of_psizes doivent être définies à 1. Pour qu'un appel à MPI_Type_create_darray soit correct, l'équation

  ndims-1
pi              array_of_psizes[i] = size
  i=0

doit être satisfaite. L'ordre des processus dans la grille de processus est supposé être ligne par ligne (row-major), comme dans le cas des topologies de processus cartésiennes virtuelles dans la Norme MPI.

Chaque dimension du tableau peut être distribuée de l'une des trois manières suivantes :

  • MPI_DISTRIBUTE_BLOCK - Distribution par blocs
  • MPI_DISTRIBUTE_CYCLIC - Distribution cyclique
  • MPI_DISTRIBUTE_NONE - Dimension non distribuée.

La constante MPI_DISTRIBUTE_DFLT_DARG spécifie un argument de distribution par défaut. L'argument de distribution pour une dimension qui n'est pas distribuée est ignoré. Pour toute dimension i dans laquelle la distribution est MPI_DISTRIBUTE_BLOCK, il est erroné de spécifier array_of_dargs[i] * array_of_psizes[i] < array_of_gsizes[i].

Par exemple, la disposition HPF ARRAY(CYCLIC(15)) correspond à MPI_DISTRIBUTE_CYCLIC avec un argument de distribution de 15, et la disposition HPF ARRAY(BLOCK) correspond à MPI_DISTRIBUTE_BLOCK avec un argument de distribution de MPI_DISTRIBUTE_DFLT_DARG.

L'argument order est utilisé comme dans MPI_Type_create_subarray pour spécifier l'ordre de stockage. Par conséquent, les tableaux décrits par ce constructeur de type peuvent être stockés en ordre Fortran (colonne par colonne) ou C (ligne par ligne). Les valeurs valides pour order sont MPI_ORDER_FORTRAN et MPI_ORDER_C.

Cette routine crée un nouveau type de données MPI avec un typemap défini en termes d'une fonction appelée « cyclic() » (voir ci-dessous).

Sans perte de généralité, il suffit de définir le typemap pour le cas MPI_DISTRIBUTE_CYCLIC où MPI_DISTRIBUTE_DFLT_DARG n'est pas utilisé.

MPI_DISTRIBUTE_BLOCK et MPI_DISTRIBUTE_NONE peuvent être réduits au cas MPI_DISTRIBUTE_CYCLIC pour la dimension i comme suit.

MPI_DISTRIBUTE_BLOCK avec array_of_dargs[i] égal à MPI_DISTRIBUTE_DFLT_DARG est équivalent à MPI_DISTRIBUTE_CYCLIC avec array_of_dargs[i] défini à

(array_of_gsizes[i] + array_of_psizes[i] - 1)/array_of_psizes[i]

Si array_of_dargs[i] n'est pas MPI_DISTRIBUTE_DFLT_DARG, alors MPI_DISTRIBUTE_BLOCK et DISTRIBUTE_CYCLIC sont équivalents.

MPI_DISTRIBUTE_NONE est équivalent à MPI_DISTRIBUTE_CYCLIC avec array_of_dargs[i] défini à array_of_gsizes[i].

Enfin, MPI_DISTRIBUTE_CYCLIC avec array_of_dargs[i] égal à MPI_DISTRIBUTE_DFLT_DARG est équivalent à MPI_DISTRIBUTE_CYCLIC avec array_of_dargs[i] défini à 1.

NOTES

Pour les tableaux Fortran et C, l'ordre des processus dans la grille de processus est supposé être ligne par ligne (row-major). Ceci est cohérent avec l'ordre utilisé dans les topologies de processus cartésiennes virtuelles en MPI. Pour créer de telles topologies de processus virtuelles, ou pour trouver les coordonnées d'un processus dans la grille de processus, etc., les utilisateurs peuvent utiliser les fonctions correspondantes fournies en MPI.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou en utilisant exclusivement le modèle de sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler à mpiexec ou la clé info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'abandon du programme par tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_W
