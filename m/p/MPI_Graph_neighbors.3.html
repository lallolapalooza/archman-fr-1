Paquet: openmpi

MPI_GRAPH_NEIGHBORS(3) Open MPI MPI_GRAPH_NEIGHBORS(3)

MPI_Graph_neighbors — Retourne les voisins d'un nœud associé à une topologie de graphe.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Graph_neighbors(MPI_Comm comm, int rank, int maxneighbors,
     int neighbors[])

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_GRAPH_NEIGHBORS(COMM, RANK, MAXNEIGHBORS, NEIGHBORS, IERROR)
     INTEGER COMM, RANK, MAXNEIGHBORS, NEIGHBORS(*), IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Graph_neighbors(comm, rank, maxneighbors, neighbors, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, INTENT(IN) :: rank, maxneighbors
     INTEGER, INTENT(OUT) :: neighbors(maxneighbors)
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES ENTRANTS

  • comm : Communicateur avec topologie de graphe (handle).
  • rank : Rang du processus dans le groupe de comm (entier).
  • maxneighbors : Taille du tableau neighbors (entier).

PARAMÈTRES SORTANTS

  • neighbors : Rangs des processus qui sont voisins du processus spécifié (tableau d'entiers).
  • ierror : Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

Exemple : Supposons que comm est un communicateur avec une topologie shuffle-exchange. Le groupe a 2n membres. Chaque processus est étiqueté par a(1), …, a(n) avec a(i) E{0,1}, et a trois voisins : échange (a(1), …, a(n) = a(1), …, a(n-1), a(n) (a = 1 - a), shuffle (a(1), …, a(n)) = a(2), …, a(n), a(1), et unshuffle (a(1), …, a(n)) = a(n), a(1), …, a(n-1). La liste d'adjacence du graphe est illustrée ci-dessous pour n=3.

                 échange                 shuffle         unshuffle
nœud             voisins(1)    voisins(2)    voisins(3)
0(000)       1               0               0
1(001)       0               2               4
2(010)       3               4               1
3(011)       2               6               5
4(100)       5               1               2
5(101)       4               3               6
6(110)       7               5               3
7(111)       6               7               7

Supposons que le communicateur comm ait cette topologie associée. Le fragment de code suivant parcourt les trois types de voisins et effectue une permutation appropriée pour chacun.

!  supposer : chaque processus a stocké un nombre réel A.
!  extraire les informations de voisinage
CALL MPI_COMM_RANK(comm, myrank, ierr)
CALL MPI_GRAPH_NEIGHBORS(comm, myrank, 3, neighbors, ierr)
!  effectuer la permutation d'échange
CALL MPI_SENDRECV_REPLACE(A, 1, MPI_REAL, neighbors(1), 0, &
                          neighbors(1), 0, comm, status, ierr)
!  effectuer la permutation shuffle
CALL MPI_SENDRECV_REPLACE(A, 1, MPI_REAL, neighbors(2), 0, &
                          neighbors(3), 0, comm, status, ierr)
!  effectuer la permutation unshuffle
CALL MPI_SENDRECV_REPLACE(A, 1, MPI_REAL, neighbors(3), 0, &
                          neighbors(2), 0, comm, status, ierr)

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou via l'argument de ligne de commande mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme sur tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, seul le processus local est arrêté.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
