MPI_Register_datarep(3)

MPI_Register_datarep(3) Open MPI MPI_Register_datarep(3)

MPI_Register_datarep définit la représentation des données.

Syntaxe

Syntaxe C

#include <mpi.h>
int MPI_Register_datarep(const char *datarep,
     MPI_Datarep_conversion_function *read_conversion_fn,
     MPI_Datarep_conversion_function *write_conversion_fn,
     MPI_Datarep_extent_function *dtype_file_extent_fn,
     void *extra_state)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_REGISTER_DATAREP(DATAREP, READ_CONVERSION_FN,
     WRITE_CONVERSION_FN, DTYPE_FILE_EXTENT_FN,
     EXTRA_STATE, IERROR)
     CHARACTER*(*)   DATAREP
     EXTERNAL        READ_CONVERSION_FN, WRITE_CONVERSION_FN, DTYPE_FILE_EXTENT_FN
     INTEGER IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND)  EXTRA_STATE

Syntaxe Fortran 2008

USE mpi_f08
MPI_Register_datarep(datarep, read_conversion_fn, write_conversion_fn,
             dtype_file_extent_fn, extra_state, ierror)
     CHARACTER(LEN=*), INTENT(IN) :: datarep
     PROCEDURE(MPI_Datarep_conversion_function) :: read_conversion_fn
     PROCEDURE(MPI_Datarep_conversion_function) :: write_conversion_fn
     PROCEDURE(MPI_Datarep_extent_function) :: dtype_file_extent_fn
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: extra_state
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Paramètres d'entrée

  • datarep: Nom de la représentation de données (chaîne de caractères).
  • read_conversion_fn: Fonction appelée pour convertir de la représentation fichier à la représentation native (fonction).
  • write_conversion_fn: Fonction appelée pour convertir de la représentation native à la représentation fichier (fonction).
  • dtype_file_extent_fn: Fonction appelée pour obtenir la taille d'un type de données tel qu'il est représenté dans le fichier (fonction).
  • extra_state: État supplémentaire.

Paramètre de sortie

•
ierror: Statut d'erreur (entier) en Fortran seulement.

Description

MPI_Register_datarep définit une représentation de données. Elle associe l'identifiant de la représentation de données (une chaîne de caractères) aux fonctions qui convertissent de la représentation fichier à la représentation native et vice-versa, à la fonction qui obtient la taille d'un type de données tel qu'il est représenté dans le fichier, ainsi qu'à "l'état supplémentaire" utilisé pour passer des arguments. Une fois qu'une représentation de données a été enregistrée par cette routine, vous pouvez spécifier son identifiant comme argument à MPI_File_set_view, ce qui entraînera l'appel des fonctions de conversion spécifiées lors des opérations d'accès aux données ultérieures. L'appel associera read_conversion_fn, write_conversion_fn et dtype_file_extent_fn à l'identifiant de la représentation de données datarep. datarep peut ensuite être utilisé comme argument à MPI_File_set_view, entraînant l'appel des fonctions de conversion lors des opérations d'accès aux données ultérieures pour convertir tous les éléments de données accédés entre la représentation fichier et la représentation native. MPI_Register_datarep est une opération locale et n'enregistre la représentation de données que pour le processus MPI appelant. Si datarep est déjà défini, une erreur de classe MPI_ERR_DUP_DATAREP sera générée en utilisant le gestionnaire d'erreurs par défaut pour le fichier. La longueur d'une chaîne de représentation de données est limitée à la valeur de MPI_MAX_DATAREP_STRING. MPI_MAX_DATAREP_STRING doit avoir une valeur d'au moins 64. Aucune routine n'est fournie pour supprimer les représentations de données et libérer les ressources associées ; il n'est pas attendu qu'une application en génère un grand nombre.

Notes

Chaque routine d'E/S MPI inclut un argument final, IERROR, qui n'est pas défini dans les sections PARAMÈTRES. Cet argument est utilisé pour retourner le statut d'erreur de la routine dans le style typique des routines de bibliothèque Fortran.

Chaque routine retourne une valeur d'erreur sous forme de valeur de retour entière.

Les classes d'erreur se trouvent dans mpi.h (pour C) et mpif.h (pour Fortran).

Erreurs

La plupart des routines MPI retournent une valeur d'erreur ; dans le cas des routines C, le résultat est retourné sous forme de valeur de retour de la fonction, et dans le cas des routines Fortran, dans le dernier argument.

Avant de retourner la valeur d'erreur, le gestionnaire d'erreurs associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) lié à l'appel est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, l'appel est considéré comme associé à MPI_COMM_SELF et le gestionnaire d'erreurs associé à MPI_COMM_SELF est appelé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le modèle de sessions est utilisé exclusivement), le gestionnaire d'erreurs initial est levé. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle du Monde, ou via l'argument mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs par défaut qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL provoque l'arrêt de tous les processus MPI connectés par le programme.
  • MPI_ERRORS_ABORT un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est invoqué sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est invoqué sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est invoqué sur une session, seul le processus local est abandonné.
  • MPI_ERRORS_RETURN retourne un code d'erreur à l'application.

Les programmes MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler suivi de MPI_Comm_set_errhandler
  • MPI_File_create_errhandler suivi de MPI_File_set_errhandler
  • MPI_Session_create_errhandler suivi de MPI_Session_set_errhandler ou dans MPI_Session_init
  • MPI_Win_create_errhandler suivi de MPI_Win_set_errhandler

Remarque : MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section sur la gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
