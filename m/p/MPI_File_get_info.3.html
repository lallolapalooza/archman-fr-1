MPI_File_get_info(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

MPI_File_get_info(3) Open MPI MPI_File_get_info(3)

MPI_File_get_info renvoie un nouvel objet d'informations contenant les valeurs des indices actuels associés à un fichier.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_File_get_info(MPI_File fh, MPI_Info *info_used)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme: INCLUDE 'mpif.h'
MPI_FILE_GET_INFO(FH, INFO_USED, IERROR)
     INTEGER FH, INFO_USED, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_File_get_info(fh, info_used, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     TYPE(MPI_Info), INTENT(OUT) :: info_used
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES D'ENTRÉE

•
fh: Handle de fichier.

PARAMÈTRES DE SORTIE

  • info_used: Nouveau handle d'objet d'informations.
  • ierror: Fortran seulement : statut d'erreur (entier).

DESCRIPTION

MPI_File_get_info renvoie un nouvel objet d'informations contenant tous les indices actuels associés au fichier fh. L'état actuel de tous les indices utilisés par le système pour ce fichier ouvert est renvoyé dans info_used. L'utilisateur doit libérer info_used en utilisant MPI_Info_free.

Remarque : L'ensemble des indices renvoyés dans info_used peut être plus grand ou plus petit que l'ensemble des indices fournis dans MPI_File_open, MPI_File_set_view ou MPI_File_set_info, car le système peut ne pas reconnaître certains indices que l'utilisateur a définis et peut définir automatiquement d'autres indices que l'utilisateur n'a pas demandés. Voir la section INDICES pour une liste des indices qui peuvent être définis.

INDICES

Les indices suivants peuvent être utilisés comme valeurs pour le paramètre info_used.

INDICES POUVANT ÊTRE DÉFINIS

  • shared_file_timeout : Durée (en secondes) d'attente avant de sortir avec MPI_ERR_TIMEDOUT pour accéder au pointeur de fichier partagé.
  • rwlock_timeout : Durée (en secondes) d'attente avant de sortir avec MPI_ERR_TIMEDOUT pour acquérir un verrou de lecture ou d'écriture sur un bloc contigu d'un fichier Unix avant de sortir.
  • noncoll_read_bufsize : Taille maximale du tampon utilisé par MPI I/O pour satisfaire les requêtes de lecture dans les routines d'accès aux données non collectives.

    • REMARQUE :

Une taille de tampon inférieure à la distance (en octets) entre le premier octet et le dernier octet de la requête d'accès dans un fichier Unix entraîne MPI I/O à itérer et à effectuer plusieurs appels read() ou write() de niveau UNIX. Si la requête inclut plusieurs blocs non contigus de données et que la taille du tampon est supérieure à la taille de ces blocs, les appels read() ou write() (effectués au niveau d'E/S de MPI) accéderont à des données non demandées par ce processus afin de réduire le nombre total d'appels write(). Si ce comportement n'est pas souhaitable, la taille du tampon doit être réduite à celle des blocs contigus au sein de la requête agrégée.
  • noncoll_write_bufsize : Taille maximale du tampon utilisé par MPI I/O pour satisfaire les requêtes d'écriture dans les routines d'accès aux données non collectives.

    • Voir la remarque précédente concernant noncoll_read_bufsize.

  • coll_read_bufsize : Taille maximale du tampon utilisé par MPI I/O pour satisfaire les requêtes de lecture dans les routines d'accès aux données collectives.

    • Voir la remarque précédente concernant noncoll_read_bufsize.

  • coll_write_bufsize : Taille maximale du tampon utilisé par MPI I/O pour satisfaire les requêtes d'écriture dans les routines d'accès aux données collectives.

    • Voir la remarque précédente concernant noncoll_read_bufsize.

  • mpiio_concurrency : (booléen) contrôle si les routines d'E/S non bloquantes peuvent lier un thread supplémentaire à un LWP.
  • mpiio_coll_contiguous : (booléen) contrôle si les accès aux données collectifs suivants demanderont des régions contiguës du fichier.

INDICES NON MODIFIABLES

•
filename : Utilisez cet indice pour obtenir le nom du fichier.

ERREURS

Plus de 90 % des routines MPI renvoient une valeur d'erreur ; dans les routines C, la valeur d'erreur est le résultat de la fonction et dans les routines Fortran, le dernier argument est la valeur d'erreur.

Avant de renvoyer la valeur d'erreur, le gestionnaire d'erreurs actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, l'appel est considéré comme associé à MPI_COMM_SELF et le gestionnaire d'erreurs correspondant est appelé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsqu'on utilise exclusivement le modèle de Sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lorsqu'on utilise le modèle du Monde, ou via l'option mpi_initial_errhandler de mpiexec ou le paramètre d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. S'il n'y a pas d'autre gestionnaire d'erreurs approprié, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt de tous les processus MPI connectés par le programme.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est invoqué sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est invoqué sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier respectif. S'il est invoqué sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou dans MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Remarque : MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section sur la gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
