MPI_Comm_split_type(3) Open MPI MPI_Comm_split_type(3)

MPI_Comm_split_type — Crée de nouveaux communicateurs de communication basés sur les couleurs et les clés.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Comm_split_type(MPI_Comm comm, int split_type, int key,
     MPI_Info info, MPI_Comm *newcomm)

Syntaxe Fortran

USE MPI
! ou bien : INCLUDE 'mpif.h'
MPI_COMM_SPLIT_TYPE(COMM, SPLIT_TYPE, KEY, INFO, NEWCOMM, IERROR)
     INTEGER COMM, SPLIT_TYPE, KEY, INFO, NEWCOMM, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Comm_split_type(comm, split_type, key, info, newcomm, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, INTENT(IN) :: split_type, key
     TYPE(MPI_Info), INTENT(IN) :: info
     TYPE(MPI_Comm), INTENT(OUT) :: newcomm
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETRES D'ENTREE

  • comm: Communicateur (handle).
  • split_type: Type de processus à regrouper (entier).
  • key: Contrôle de l'attribution du rang (entier).
  • info: Argument d'information (handle).

PARAMETRES DE SORTIE

  • newcomm: Nouveau communicateur (handle).
  • ierror: Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

Cette fonction divise le groupe associé à comm en sous-groupes, selon le type spécifié par split_type. Chaque sous-groupe contient tous les processus du même type. Au sein de chaque sous-groupe, les processus sont ordonnés selon la valeur de l'argument key, les égalités étant résolues selon leur rang dans le groupe d'origine. Un nouveau communicateur est créé pour chaque sous-groupe et est renvoyé dans newcomm. Il s'agit d'un appel collectif ; tous les processus doivent fournir le même split_type, mais chaque processus peut fournir des valeurs différentes pour key. L'exception est qu'un processus peut fournir la valeur MPI_UNDEFINED, auquel cas newcomm renvoie MPI_COMM_NULL.

TYPES DE REGROUPEMENT

MPI_COMM_TYPE_SHARED
Ce type divise le communicateur en sous-communicateurs, chacun pouvant créer une zone de mémoire partagée.
OMPI_COMM_TYPE_NODE
Alias pour MPI_COMM_TYPE_SHARED.
OMPI_COMM_TYPE_HWTHREAD
Ce type divise le communicateur en sous-communicateurs, chacun appartenant au même thread matériel.
OMPI_COMM_TYPE_CORE
Ce type divise le communicateur en sous-communicateurs, chacun appartenant au même cœur de traitement.
OMPI_COMM_TYPE_L1CACHE
Ce type divise le communicateur en sous-communicateurs, chacun appartenant au même cache L1.
OMPI_COMM_TYPE_L2CACHE
Ce type divise le communicateur en sous-communicateurs, chacun appartenant au même cache L2.
OMPI_COMM_TYPE_L3CACHE
Ce type divise le communicateur en sous-communicateurs, chacun appartenant au même cache L3.
OMPI_COMM_TYPE_SOCKET
Ce type divise le communicateur en sous-communicateurs, chacun appartenant à la même socket.
OMPI_COMM_TYPE_NUMA
Ce type divise le communicateur en sous-communicateurs, chacun appartenant au même nœud NUMA.
OMPI_COMM_TYPE_BOARD
Ce type divise le communicateur en sous-communicateurs, chacun appartenant à la même carte mère.
OMPI_COMM_TYPE_HOST
Ce type divise le communicateur en sous-communicateurs, chacun appartenant au même hôte.
OMPI_COMM_TYPE_CU
Ce type divise le communicateur en sous-communicateurs, chacun appartenant à la même unité de calcul.
OMPI_COMM_TYPE_CLUSTER
Ce type divise le communicateur en sous-communicateurs, chacun appartenant au même cluster.

NOTES

Les clés portant le préfixe OMPI_ au lieu de MPI_ sont spécifiques à Open MPI et ne font pas partie de la norme MPI. Leur utilisation doit être protégée par le macro OPEN_MPI dans le préprocesseur C.

ERREURS

La plupart des routines MPI renvoient une valeur d'erreur ; dans le cas des routines C, le résultat est renvoyé comme valeur de retour de la fonction ; dans le cas des routines Fortran, le dernier argument est la valeur d'erreur.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreur associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) concerné est appelé. S'il n'y a pas d'objet de communication associé à l'appel MPI, l'appel est considéré comme associé à MPI_COMM_SELF et le gestionnaire d'erreur associé à MPI_COMM_SELF sera appelé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le modèle de Sessions est utilisé exclusivement), l'erreur appelle le gestionnaire d'erreur initial. Le gestionnaire d'erreur initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle du Monde, ou via l'argument CLI mpi_initial_errhandler de mpiexec ou via le paramètre info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. S'il n'y a pas d'autre gestionnaire d'erreur approprié configuré, le gestionnaire d'erreur_mpi_errors_return est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreur_mpi_errors_abort pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreur par défaut qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du processus MPI connecté par le programme.
  • MPI_ERRORS_ABORT Gestionnaire d'erreur qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est invoqué sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est invoqué sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus correspondant à la fenêtre ou au fichier. S'il est invoqué sur une session, seul le processus local est arrêté.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreur en appelant :

  • MPI_Comm_create_errhandler après MPI_Comm_set_errhandler
  • MPI_File_create_errhandler après MPI_File_set_errhandler
  • MPI_Session_create_errhandler après MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler après MPI_Win_set_errhandler

Remarque : les gestionnaires d'erreur MPI ne garantissent pas qu'un programme MPI puisse continuer après une erreur.

Consultez la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Consultez la section sur la gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
