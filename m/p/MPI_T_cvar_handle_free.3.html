MPI_T_cvar_handle_free(3)

MPI_T_CVAR_HANDLE_FREE(3) Open MPI MPI_T_CVAR_HANDLE_FREE(3)

MPI_T_cvar_handle_alloc, MPI_T_cvar_handle_free - Allouer/libérer des descripteurs de variables de contrôle

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_T_cvar_handle_alloc(int cvar_index, void *obj_handle,
                            MPI_T_cvar_handle *handle, int *count)
int MPI_T_cvar_handle_free(MPI_T_cvar_handle *handle)

DESCRIPTION

MPI_T_cvar_handle_alloc lie la variable de contrôle spécifiée par cvar_index à l'objet MPI spécifié par obj_handle. Si MPI_T_cvar_get_info renvoie MPI_T_BIND_NO_OBJECT comme liaison de la variable, l'argument obj_handle est ignoré. Le nombre de valeurs représentées par cette variable de contrôle est renvoyé dans le paramètre count. Si la variable de contrôle représente une chaîne de caractères, count sera la longueur maximale de la chaîne.

MPI_T_cvar_handle_free libère un descripteur alloué par MPI_T_cvar_handle_alloc et met l'argument handle à MPI_T_CVAR_HANDLE_NULL.

NOTES

Open MPI ne prend actuellement pas en charge la liaison des objets MPI aux variables de contrôle, donc l'argument obj_handle est toujours ignoré.

ERREURS

MPI_T_cvar_handle_alloc échouera si :

  • MPI_T_ERR_NOT_INITIALIZED : L'interface des outils MPI n'est pas initialisée
  • MPI_T_ERR_INVALID_INDEX : L'indice de la variable de contrôle est invalide
  • MPI_T_ERR_OUT_OF_HANDLES : Plus aucun descripteur disponible

MPI_T_cvar_handle_free échouera si :

  • MPI_T_ERR_NOT_INITIALIZED : L'interface des outils MPI n'est pas initialisée
  • MPI_T_ERR_INVALID_HANDLE : Le descripteur est invalide
