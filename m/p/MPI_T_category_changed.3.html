MPI_T_category_changed — Obtenir un horodatage pour les catégories

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_T_category_changed(int *stamp)

PARAMÈTRES ENTRANTS

•
stamp: Un horodatage virtuel pour indiquer le dernier changement apporté aux catégories.

DESCRIPTION

Si deux appels successifs à cette routine renvoient le même horodatage, il est garanti qu'aucune catégorie n'a été modifiée ou ajoutée. Si l'horodatage du second appel est supérieur, cela signifie que des catégories ont été ajoutées ou modifiées.

ERREURS

MPI_T_category_changed échouera si :

•
MPI_T_ERR_NOT_INITIALIZED: L'interface MPI Tools n'est pas initialisée
