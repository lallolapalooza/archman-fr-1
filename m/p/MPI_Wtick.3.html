MPI_Wtick — Retourne la résolution de MPI_Wtime.

SYNTAXE

Syntaxe C

#include <mpi.h>
double MPI_Wtick()

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
DOUBLE PRECISION MPI_WTICK()

Syntaxe Fortran 2008

USE mpi_f08
DOUBLE PRECISION MPI_WTICK()

VALEUR DE RETOUR

Résolution en secondes de MPI_Wtime.

DESCRIPTION

MPI_Wtick retourne la résolution de MPI_Wtime en secondes. C'est-à-dire qu'elle retourne, sous forme de valeur double précision, le nombre de secondes entre les ticks successifs de l'horloge. Par exemple, si l'horloge est implémentée par le matériel comme un compteur qui est incrémenté chaque milliseconde, la valeur retournée par MPI_Wtick devrait être 10^-3.

NOTE

Cette fonction ne retourne pas de valeur d'erreur. Par conséquent, le résultat de son appel avant MPI_Init ou après MPI_Finalize est indéfini.
