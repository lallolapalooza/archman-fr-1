MPI_STATUS_F082C(3) Open MPI MPI_STATUS_F082C(3)

MPI_Status_f082c, MPI_Status_c2f08 - Traduit un statut C en statut Fortran 2008, ou vice versa.

SYNTAX

Syntaxe C

#include <mpi.h>
int MPI_Status_f082c(const MPI_F08_status *f08_status, MPI_Status *c_status)
int MPI_Status_c2f08(const MPI_Status *c_status, MPI_F08_status *f08_status)

PARAMÈTRES

  • f08_status : objet de statut MPI de style mpi_f08
  • c_status : objet de statut MPI de style C

DESCRIPTION

Ces deux procédures sont fournies en C pour convertir un statut Fortran 2008 (qui est un type dérivé composé d'entiers) en un statut C (qui est une structure), et vice versa. La conversion porte sur toutes les informations du statut, y compris celles qui sont cachées. C'est-à-dire qu'aucune information de statut n'est perdue lors de la conversion.

Lors de l'utilisation de MPI_Status_f082c, si f08_status est un statut Fortran valide, mais pas la valeur Fortran de MPI_F08_STATUS_IGNORE ou MPI_F08_STATUSES_IGNORE, alors MPI_Status_f082c retourne dans c_status un statut C valide avec le même contenu. Si f08_status est la valeur Fortran de MPI_STATUS_IGNORE ou MPI_STATUSES_IGNORE, ou si f08_status n'est pas un statut Fortran valide, alors l'appel est erroné.

Lors de l'utilisation de MPI_Status_c2f08, la conversion inverse est appliquée. Si c_status est MPI_STATUS_IGNORE ou MPI_STATUSES_IGNORE, ou si c_status n'est pas un statut C valide, alors l'appel est erroné.

Le statut d'entrée a les mêmes valeurs de source, de balise et de code d'erreur que le statut de sortie, et retourne les mêmes réponses lorsqu'il est interrogé pour le nombre, les éléments et l'annulation. La fonction de conversion peut être appelée avec un argument de statut d'entrée dont le champ d'erreur est indéfini, auquel cas la valeur du champ d'erreur dans l'argument de statut de sortie est indéfinie.

NOTES

Ces fonctions ne sont disponibles qu'en C ; elles ne sont disponibles dans aucune des interfaces Fortran MPI.
