MPI_COMM_CREATE_ERRHANDLER(3) Open MPI MPI_COMM_CREATE_ERRHANDLER(3)

MPI_Comm_create_errhandler — Crée un gestionnaire d'erreurs pouvant être associé aux communicateurs.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Comm_create_errhandler(MPI_Comm_errhandler_function *function,
    MPI_Errhandler *errhandler)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_COMM_CREATE_ERRHANDLER(FUNCTION, ERRHANDLER, IERROR)
    EXTERNAL    FUNCTION
    INTEGER ERRHANDLER, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Comm_create_errhandler(comm_errhandler_fn, errhandler, ierror)
    PROCEDURE(MPI_Comm_errhandler_function) :: comm_errhandler_fn
    TYPE(MPI_Errhandler), INTENT(OUT) :: errhandler
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

NOTE SUR LE NOM DE TYPE DÉPRÉCIÉ

MPI-2.2 a déprécié le type MPI_Comm_errhandler_fn en faveur de MPI_Comm_errhandler_function. Open MPI prend en charge les deux noms (en fait, les noms _fn sont des typedefs vers les noms _function).

PARAMÈTRE D'ENTRÉE

•
function : Procédure (fonction) de gestion des erreurs définie par l'utilisateur.

PARAMÈTRES DE SORTIE

  • errhandler : Gestionnaire d'erreurs MPI (handle).
  • ierror : Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

MPI_Comm_create_errhandler crée un gestionnaire d'erreurs qui peut être attaché aux communicateurs. Cette fonction est identique à MPI_Errhandler_create, dont l'utilisation est dépréciée. En C, la routine utilisateur doit être une fonction de type MPI_Comm_errhandler_function, qui est définie comme suit :

typedef void MPI_Comm_errhandler_function(MPI_Comm *, int *, ...);

Le premier argument est le communicateur en cours d'utilisation. Le second est le code d'erreur à retourner par la routine MPI qui a déclenché l'erreur. Ce typedef remplace MPI_Handler_function, dont l'utilisation est dépréciée. En Fortran, la routine utilisateur doit avoir la forme suivante :

SUBROUTINE COMM_ERRHANDLER_FUNCTION(COMM, ERROR_CODE, ...)
   INTEGER COMM, ERROR_CODE

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; en C, sous forme de résultat de retour de la fonction, et en Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme étant attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou en utilisant exclusivement le modèle de sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lorsque le modèle World est utilisé, ou via l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme sur tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, il n'aborte que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
