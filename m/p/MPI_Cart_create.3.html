MPI_CART_CREATE(3) Open MPI MPI_CART_CREATE(3)

MPI_Cart_create — Crée un nouveau communicateur auquel des informations de topologie cartésienne ont été attachées.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Cart_create(MPI_Comm comm_old, int ndims, const int dims[],
    const int periods[], int reorder, MPI_Comm *comm_cart)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_CART_CREATE(COMM_OLD, NDIMS, DIMS, PERIODS, REORDER,
        COMM_CART, IERROR)
    INTEGER COMM_OLD, NDIMS, DIMS(*), COMM_CART, IERROR
    LOGICAL PERIODS(*), REORDER

Syntaxe Fortran 2008

USE mpi_f08
MPI_Cart_create(comm_old, ndims, dims, periods, reorder, comm_cart, ierror)
    TYPE(MPI_Comm), INTENT(IN) :: comm_old
    INTEGER, INTENT(IN) :: ndims, dims(ndims)
    LOGICAL, INTENT(IN) :: periods(ndims), reorder
    TYPE(MPI_Comm), INTENT(OUT) :: comm_cart
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES D'ENTRÉE

  • comm_old : Communicateur d'entrée (handle).
  • ndims : Nombre de dimensions de la grille cartésienne (entier).
dims
Tableau d'entiers de taille ndims spécifiant le nombre de processus dans chaque dimension.
•
periods
Tableau logique de taille ndims spécifiant si la grille est périodique (vrai) ou non (faux) dans chaque dimension.
•
reorder
Le classement peut être réordonné (vrai) ou non (faux) (logique).

PARAMÈTRES DE SORTIE

  • comm_cart : Communicateur avec la nouvelle topologie cartésienne (handle).
  • ierror : Uniquement Fortran : Statut d'erreur (entier).

DESCRIPTION

MPI_Cart_create renvoie un handle vers un nouveau communicateur auquel la topologie cartésienne est attachée. Si reorder = faux, alors le rang de chaque processus dans le nouveau groupe est identique à son rang dans l'ancien groupe. Sinon, la fonction peut réordonner les processus (éventuellement pour choisir un bon embedding de la topologie virtuelle sur la machine physique). Si la taille totale de la grille cartésienne est inférieure à la taille du groupe de comm, alors certains processus se voient attribuer MPI_COMM_NULL, par analogie avec MPI_Comm_split. L'appel est erroné s'il spécifie une grille plus grande que la taille du groupe.

ERREURS

Presque toutes les routines MPI renvoient une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI actuellement associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de Sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme pour tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'arrête que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
