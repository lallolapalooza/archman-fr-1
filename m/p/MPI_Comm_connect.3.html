MPI_COMM_CONNECT(3) Open MPI MPI_COMM_CONNECT(3)

MPI_Comm_connect — Établit une communication avec un serveur.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Comm_connect(const char *port_name, MPI_Info info, int root,
    MPI_Comm comm, MPI_Comm *newcomm)

Syntaxe Fortran

USE MPI
! ou l'ancienne forme : INCLUDE 'mpif.h'
MPI_COMM_CONNECT(PORT_NAME, INFO, ROOT, COMM, NEWCOMM, IERROR)
    CHARACTER*(*)   PORT_NAME
    INTEGER     INFO, ROOT, COMM, NEWCOMM, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Comm_connect(port_name, info, root, comm, newcomm, ierror)
    CHARACTER(LEN=*), INTENT(IN) :: port_name
    TYPE(MPI_Info), INTENT(IN) :: info
    INTEGER, INTENT(IN) :: root
    TYPE(MPI_Comm), INTENT(IN) :: comm
    TYPE(MPI_Comm), INTENT(OUT) :: newcomm
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRES ENTRÉE

  • port_name : Nom du port (chaîne de caractères, utilisé uniquement sur la racine).
info
Options données par la racine pour la connexion (descripteur, utilisé uniquement sur la racine). Aucune option n'est actuellement prise en charge.
  • root : Rang dans comm du nœud racine (entier).
  • comm : Intracommunicateur sur lequel l'appel est collectif (descripteur).

PARAMÈTRES SORTIE

  • newcomm : Intercommunicateur avec le client comme groupe distant (descripteur)
  • ierror : Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

MPI_Comm_connect établit une communication avec un serveur spécifié par port_name. Il est collectif sur le communicateur appelant et retourne un intercommunicateur dans lequel le groupe distant a participé à un appel MPI_Comm_accept. L'appel MPI_Comm_connect doit être effectué uniquement après que l'appel MPI_Comm_accept ait été effectué par le job MPI agissant en tant que serveur. Si le port nommé n'existe pas (ou a été fermé), MPI_Comm_connect déclenche une erreur de classe MPI_ERR_PORT. MPI ne garantit pas un traitement équitable des tentatives de connexion. C'est-à-dire que les tentatives de connexion ne sont pas nécessairement satisfaites dans l'ordre où elles ont été initiées, et la concurrence avec d'autres tentatives de connexion peut empêcher qu'une tentative de connexion particulière ne soit satisfaite. Le paramètre port_name est l'adresse du serveur. Il doit être identique au nom retourné par MPI_Open_port sur le serveur.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF en utilisant le modèle Monde, ou l'argument de ligne de commande mpi_initial_errhandler pour mpiexec ou la clé d'informations pour MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme sur tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort était appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort était appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'arrête que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
