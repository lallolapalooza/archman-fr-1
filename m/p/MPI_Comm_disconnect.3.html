MPI_COMM_DISCONNECT(3) Open MPI MPI_COMM_DISCONNECT(3)

MPI_Comm_disconnect — Désalloue un objet communicateur et définit le descripteur sur MPI_COMM_NULL.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Comm_disconnect(MPI_Comm *comm)

Syntaxe Fortran

USE MPI
! Ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_COMM_DISCONNECT(COMM, IERROR)
    INTEGER COMM, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Comm_disconnect(comm, ierror)
    TYPE(MPI_Comm), INTENT(INOUT) :: comm
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRE ENTRÉE/SORTIE

•
comm : Communicateur (descripteur).

PARAMÈTRE DE SORTIE

•
ierror : Uniquement en Fortran : Statut d'erreur (entier).

DESCRIPTION

MPI_Comm_disconnect attend que toutes les communications en cours sur comm soient terminées en interne, désalloue l'objet communicateur et définit le descripteur sur MPI_COMM_NULL. C'est une opération collective. Elle ne peut pas être appelée avec les communicateurs MPI_COMM_WORLD ou MPI_COMM_SELF. MPI_Comm_disconnect ne peut être appelée que si toutes les communications sont terminées et appariées, de sorte que les données mises en mémoire tampon puissent être livrées à leur destination. Cette exigence est la même que pour MPI_Finalize. MPI_Comm_disconnect a la même action que MPI_Comm_free, à la différence qu'elle attend que les communications en cours se terminent en interne et garantit le comportement des processus déconnectés.

NOTES

Pour déconnecter deux processus, vous devrez peut-être appeler MPI_Comm_disconnect, MPI_Win_free et MPI_File_close pour supprimer tous les chemins de communication entre les deux processus. Notez qu'il peut être nécessaire de déconnecter plusieurs communicateurs (ou de libérer plusieurs fenêtres ou fichiers) avant que deux processus ne soient complètement indépendants.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle Sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler pour mpiexec ou la clé d'information pour MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme de tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort était appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort était appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page man MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
