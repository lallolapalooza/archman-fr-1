MPI_FILE_GET_TYPE_EXTENT(3) Open MPI MPI_FILE_GET_TYPE_EXTENT(3)

MPI_File_get_type_extent — Retourne l'étendue du type de données dans un fichier.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_File_get_type_extent(MPI_File fh, MPI_Datatype
     datatype, MPI_Aint *extent)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_FILE_GET_TYPE_EXTENT(FH, DATATYPE, EXTENT, IERROR)
     INTEGER FH, DATATYPE, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND)  EXTENT

Syntaxe Fortran 2008

USE mpi_f08
MPI_File_get_type_extent(fh, datatype, extent, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(OUT) :: extent
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETRES D'ENTRÉE

  • fh: Handle de fichier (handle).
  • datatype: Type de données (handle).

PARAMETRES DE SORTIE

  • extent: Étendue du type de données (entier).
  • ierror: Fortran uniquement : Statut d'erreur (entier).

DESCRIPTION

MPI_File_get_type_extent peut être utilisée pour calculer l'extent pour datatype dans le fichier. L'étendue est la même pour tous les processus accédant au fichier associé à fh. Si la vue actuelle utilise une représentation de données définie par l'utilisateur, MPI_File_get_type_extent utilise la fonction de rappel dtype_file_extent_fn pour calculer l'étendue.

NOTES

Si la représentation des données du fichier est autre que “native”, il faut être prudent lors de la construction des etypes et des filetypes. N'importe laquelle des fonctions de construction de types de données peut être utilisée ; cependant, pour les fonctions qui acceptent des déplacements en octets, les déplacements doivent être spécifiés en termes de leurs valeurs dans le fichier pour la représentation des données du fichier utilisée. MPI interprétera ces déplacements en octets tels quels ; aucune mise à l'échelle ne sera effectuée. La fonction MPI_File_get_type_extent peut être utilisée pour calculer les étendues des types de données dans le fichier. Pour les etypes et filetypes qui sont des types de données portables, MPI mettra à l'échelle les déplacements dans les types de données pour correspondre à la représentation des données du fichier. Les types de données passés en arguments aux routines de lecture/écriture spécifient la disposition des données en mémoire ; par conséquent, ils doivent toujours être construits avec des déplacements correspondant aux déplacements en mémoire.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de Sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument de ligne de commande mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme pour tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
