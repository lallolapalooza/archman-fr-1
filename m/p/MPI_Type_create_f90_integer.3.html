MPI_TYPE_CREATE_F90_INTEGER(3) Open MPI MPI_TYPE_CREATE_F90_INTEGER(3) 
MPI_Type_create_f90_integer - Retourne un type de données entier MPI borné

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Type_create_f90_integer(int r, MPI_Datatype *newtype)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_TYPE_CREATE_F90_INTEGER (R, NEWTYPE, IERROR)
     INTEGER R, NEWTYPE, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Type_create_f90_integer(r, newtype, ierror)
     INTEGER, INTENT(IN) :: r
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMÈTRE D'ENTRÉE

•
r: Précision, en chiffres décimaux (entier).

PARAMÈTRES DE SORTIE

  • newtype: Nouveau type de données (descripteur).
  • ierror: Fortran uniquement : statut d'erreur (entier).

DESCRIPTION

Cette fonction fournit un moyen de déclarer des types de données ENTIERS MPI paramétrés par KIND. L'argument est interprété de manière similaire à la fonction F90 SELECTED_INT_KIND : r doit être un entier scalaire et représente le niveau de précision numérique souhaité, en chiffres décimaux.

NOTES

Il est erroné de fournir une valeur pour r non prise en charge par le compilateur.

La fonction Fortran SELECTED_INT_KIND mappe un grand nombre de valeurs r à un nombre beaucoup plus petit de paramètres KIND pris en charge par le compilateur. Les paramètres KIND ne sont pas spécifiés par le langage et ne sont pas portables. Du point de vue du langage, les variables du même type de base et du même paramètre KIND sont équivalentes, même si leurs paramètres KIND ont été générés par des arguments r différents à SELECTED_INT_KIND. Cependant, afin de faciliter l'interopérabilité dans un environnement hétérogène, l'équivalence est définie plus strictement pour les types de données retournés par MPI_Type_create_f90_integer. Deux types de données MPI, chacun généré par cette fonction, correspondront si et seulement s'ils ont des valeurs identiques pour r.

L'interaction entre les types de données retournés par cette fonction et la représentation de données external32 - utilisée par MPI_Pack_external, MPI_Unpack_external et de nombreuses fonctions MPI_File - est subtile. La représentation external32 des types de données retournés est la suivante.

if (r > 38):
        taille external32 = n/a (indéfinie)
else if (r > 18):
        taille external32 = 16
else if (r > 9):
        taille external32 = 8
else if (r > 4):
        taille external32 = 4
else if (r > 2):
        taille external32 = 2
else:
        taille external32 = 1

Si la représentation external32 d'un type de données est indéfinie, il en va de même pour les résultats de l'utilisation de ce type de données dans des opérations nécessitant le format external32. Des précautions doivent être prises pour ne pas utiliser des types de données incompatibles indirectement, par exemple, dans le cadre d'un autre type de données ou via un type de données dupliqué, dans ces fonctions.

Si une variable est déclarée avec une valeur KIND non par défaut qui n'a pas été obtenue avec SELECTED_INT_KIND (c'est-à-dire, r est inconnu), la seule façon d'obtenir un type de données MPI correspondant est d'utiliser les fonctions MPI_Sizeof et MPI_Type_match_size.

ERREURS

Presque toutes les routines MPI retournent une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit retournée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, le communicateur, la fenêtre, le fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire, avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme sur tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe de processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Retourne un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou à MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.

MPI_Type_create_f90_integer

MPI_Type_create_f90_integer(3) Anglais | Français

Nom

MPI_Type_create_f90_integer - Crée un type de données MPI correspondant à un entier de Fortran 90.

Syntaxe

Interface C

int MPI_Type_create_f90_integer(int kind, MPI_Datatype *newtype);

Interface Fortran

CALL MPI_Type_create_f90_integer(KIND, NEWTYPE, IERROR)
INTEGER NEWTYPE, IERROR

Description

La routine MPI_Type_create_f90_integer crée un type de données MPI qui correspond au type entier Fortran 90 spécifié par le paramètre kind.

Le paramètre kind spécifie la forme de l'entier Fortran 90. Les valeurs possibles pour kind sont définies dans le langage Fortran 90.

Paramètres

  • kind - (Entrée) Le paramètre de forme spécifiant le type entier Fortran 90.
  • newtype - (Sortie) Le nouveau type de données MPI créé.
  • IERROR - (Sortie) Code d'erreur Fortran.

Valeurs de retour

Si l'opération réussit, le nouveau type de données MPI est retourné dans newtype. Sinon, une valeur d'erreur est retournée.

Notes

Cette routine est utile lorsque vous avez besoin de créer des types de données MPI qui correspondent directement aux types de données natifs de Fortran 90 pour des raisons de compatibilité ou de performance.
