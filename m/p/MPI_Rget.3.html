PARAMÈTRES ENTRANTS

  • origin_addr : Adresse initiale du tampon d'origine (choix).
origin_count
Nombre d'entrées dans le tampon d'origine (entier non négatif).
  • origin_datatype : Type de données de chaque entrée dans le tampon d'origine (handle).
  • target_rank : Rang de la cible (entier non négatif).
target_disp
Déplacement depuis le début de la fenêtre jusqu'au début du tampon cible (entier non négatif).
•
target_count
Nombre d'entrées dans le tampon cible (entier non négatif).
  • datatype cible : type de données de chaque entrée dans le tampon cible (handle)
  • win : objet fenêtre utilisé pour la communication (handle)

PARAMÈTRE DE SORTIE

  • request : MPI_Rget : requête RMA
  • ierror : Fortran uniquement : statut d'erreur (entier).

DESCRIPTION

MPI_Get copie des données de la mémoire cible vers l'origine, similaire à MPI_Put, sauf que la direction du transfert de données est inversée. L'origin_datatype ne peut pas spécifier des entrées qui se chevauchent dans le tampon d'origine. Le tampon cible doit être contenu dans la fenêtre cible, et les données copiées doivent tenir, sans troncature, dans le tampon d'origine. Seuls les processus du même nœud peuvent accéder à la fenêtre cible.

MPI_Rget est similaire à MPI_Get, sauf qu'il alloue un objet de requête de communication et l'associe au handle de requête (l'argument request) qui peut être utilisé pour attendre ou tester l'achèvement. L'achèvement d'une opération MPI_Rget indique que les données sont disponibles dans le tampon d'origine. Si origin_addr pointe vers la mémoire attachée à une fenêtre, les données deviennent disponibles dans la copie privée de cette fenêtre.

ERREURS

Presque toutes les routines MPI renvoient une valeur d'erreur ; les routines C comme résultat de retour de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lors de l'utilisation exclusive du modèle de sessions) l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou par l'argument CLI mpi_initial_errhandler de mpiexec ou la clé d'information de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt du programme de tous les processus MPI connectés.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être appelé sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus de la fenêtre ou du fichier correspondant. S'il est appelé sur une session, n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou lors de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Voir la page de manuel MPI pour une liste complète des codes d'erreur MPI.

Voir la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
