DESCRIPTION

Les handles sont passés entre Fortran et C en utilisant un wrapper C explicite pour convertir les handles Fortran en handles C. Il n'y a pas d'accès direct aux handles C en Fortran. La définition de type MPI_Fint est fournie en C pour un entier de taille correspondant à un INTEGER Fortran ; généralement, MPI_Fint sera équivalent à int. Les fonctions de traduction de handle sont fournies en C pour convertir un handle Fortran (qui est un entier) en un handle C, et vice versa.

Par exemple, si comm est un handle Fortran valide pour un communicateur, alors MPI_Comm_f2c renvoie un handle C valide pour ce même communicateur ; si comm = MPI_COMM_NULL (valeur Fortran), alors MPI_Comm_f2c renvoie un handle C nul ; si comm est un handle Fortran invalide, alors MPI_Comm_f2c renvoie un handle C invalide.

NOTE

Cette fonction ne renvoie aucune valeur d'erreur. Par conséquent, le résultat de son appel avant MPI_Init ou après MPI_Finalize est indéfini.
