MPI_WIN_UNLOCK(3) Open MPI MPI_WIN_UNLOCK(3)

MPI_Win_unlock — Termine une époque d'accès RMA initiée par un appel à MPI_Win_lock.

SYNTAXE

Syntaxe C

#include <mpi.h>
int MPI_Win_unlock(int rank, MPI_Win win)

Syntaxe Fortran

USE MPI
! ou la forme plus ancienne : INCLUDE 'mpif.h'
MPI_WIN_UNLOCK(RANK, WIN, IERROR)
     INTEGER RANK, WIN, IERROR

Syntaxe Fortran 2008

USE mpi_f08
MPI_Win_unlock(rank, win, ierror)
     INTEGER, INTENT(IN) :: rank
     TYPE(MPI_Win), INTENT(IN) :: win
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETRES D'ENTRÉE

  • rank : Rang de la fenêtre (entier non négatif).
  • win : Objet fenêtre (handle).

PARAMETRE DE SORTIE

•
ierror : Uniquement en Fortran : Statut d'erreur (entier).

DESCRIPTION

MPI_Win_unlock termine une époque d'accès RMA initiée par un appel à MPI_Win_lock. Les opérations RMA émises pendant cette période seront terminées à la fois à l'origine et à la cible lorsque l'appel retournera.

Les verrous sont utilisés pour protéger les accès à la fenêtre cible verrouillée effectués par des appels RMA émis entre l'appel de verrouillage et de déverrouillage, et pour protéger les accès locaux de chargement/stockage à une fenêtre locale verrouillée exécutés entre l'appel de verrouillage et de déverrouillage. Les accès protégés par un verrou exclusif ne seront pas concurrents au niveau du site de la fenêtre avec d'autres accès à la même fenêtre qui sont protégés par verrou. Les accès protégés par un verrou partagé ne seront pas concurrents au niveau du site de la fenêtre avec des accès protégés par un verrou exclusif à la même fenêtre.

ERREURS

La quasi-totalité des routines MPI renvoient une valeur d'erreur ; les routines C comme résultat de la fonction et les routines Fortran dans le dernier argument.

Avant que la valeur d'erreur ne soit renvoyée, le gestionnaire d'erreurs MPI actuel associé à l'objet de communication (par exemple, communicateur, fenêtre, fichier) est appelé. Si aucun objet de communication n'est associé à l'appel MPI, alors l'appel est considéré comme attaché à MPI_COMM_SELF et appellera le gestionnaire d'erreurs MPI associé. Lorsque MPI_COMM_SELF n'est pas initialisé (c'est-à-dire avant MPI_Init/MPI_Init_thread, après MPI_Finalize, ou lorsque le modèle de Sessions est utilisé exclusivement), l'erreur déclenche le gestionnaire d'erreurs initial. Le gestionnaire d'erreurs initial peut être modifié en appelant MPI_Comm_set_errhandler sur MPI_COMM_SELF lors de l'utilisation du modèle World, ou l'argument CLI mpi_initial_errhandler de mpiexec ou une clé d'info pour MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si aucun autre gestionnaire d'erreurs approprié n'a été défini, alors le gestionnaire d'erreurs MPI_ERRORS_RETURN est appelé pour les fonctions d'E/S MPI et le gestionnaire d'erreurs MPI_ERRORS_ABORT est appelé pour toutes les autres fonctions MPI.

Open MPI inclut trois gestionnaires d'erreurs prédéfinis qui peuvent être utilisés :

  • MPI_ERRORS_ARE_FATAL Provoque l'arrêt de tous les processus MPI connectés par le programme.
  • MPI_ERRORS_ABORT Un gestionnaire d'erreurs qui peut être invoqué sur un communicateur, une fenêtre, un fichier ou une session. Lorsqu'il est appelé sur un communicateur, il agit comme si MPI_Abort avait été appelé sur ce communicateur. S'il est appelé sur une fenêtre ou un fichier, il agit comme si MPI_Abort avait été appelé sur un communicateur contenant le groupe des processus dans la fenêtre ou le fichier correspondant. S'il est appelé sur une session, il n'interrompt que le processus local.
  • MPI_ERRORS_RETURN Renvoie un code d'erreur à l'application.

Les applications MPI peuvent également implémenter leurs propres gestionnaires d'erreurs en appelant :

  • MPI_Comm_create_errhandler puis MPI_Comm_set_errhandler
  • MPI_File_create_errhandler puis MPI_File_set_errhandler
  • MPI_Session_create_errhandler puis MPI_Session_set_errhandler ou au moment de MPI_Session_init
  • MPI_Win_create_errhandler puis MPI_Win_set_errhandler

Notez que MPI ne garantit pas qu'un programme MPI puisse continuer après une erreur.

Consultez la page man MPI pour une liste complète des codes d'erreur MPI.

Consultez la section Gestion des erreurs de la norme MPI-3.1 pour plus d'informations.
