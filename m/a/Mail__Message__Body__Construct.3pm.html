NOM

Mail::Message::Body::Construct - ajoute des fonctionnalités à Mail::Message::Body

SYNOPIS

DESCRIPTION

Ce paquet ajoute des fonctionnalités complexes à la classe Mail::Message::Body. Ces fonctions sont moins utilisées, donc de nombreux programmes ne compileront pas ce paquet.

MÉTHODES

Construction d'un corps

$obj->attach(@messages, %options)
Crée un message multipart contenant ce corps et les @messages spécifiés. Les options sont passées au constructeur du corps multipart. Si vous avez besoin de plus de contrôle, créez vous-même le corps multipart. Jetez au moins un œil à Mail::Message::Body::Multipart.

Les parties du message seront coercées en Mail::Message::Part, vous pouvez donc attacher des objets Mail::Internet ou MIME::Entity si vous le souhaitez --voir Mail::Message::coerce(). Un nouveau corps avec les messages attachés est retourné.

» exemple :

my $pgpkey = Mail::Message::Body::File->new(file => 'a.pgp');
my $msg    = Mail::Message->buildFromBody($message->decoded->attach($pgpkey));
# Le dernier message du corps multipart $multi devient une entité $entity coercée.
my $entity  = MIME::Entity->new;
my $multi   = $msg->body->attach($entity);
# Créez maintenant un nouveau message
my $msg     = Mail::Message->new(head => ..., body => $multi);
$obj->concatenate(@components)
Concatène le contenu textuel d'une LISTE d'éléments en un nouveau corps. L'objet corps résultant est basé sur l'appelant, qui peut lui-même ne pas être inclus dans le résultat.

Spécifiez une liste de @components textuels. Chaque composant peut être

  • un message (Mail::Message, le corps du message est utilisé),
  • un corps simple (Mail::Message::Body),
  • "undef" (qui sera ignoré),
  • un scalaire (qui est divisé en lignes), ou
  • un tableau de scalaires (chacun fournissant une ligne).

» exemple :

# tous les arguments sont Mail::Message::Body.
my $sum = $body->concatenate($preamble, $body, $epilogue, "-- \n" , $sig);
$obj->foreachLine(CODE)
Crée un nouveau corps en effectuant une action sur chacune de ses lignes. Si aucune des lignes n'est modifiée, le corps actuel est retourné, sinon un nouveau corps est créé du même type que l'actuel.

Le "CODE" fait référence à une sous-routine qui est appelée, où $_ contient la ligne d'origine du corps. NE CHANGEZ PAS $_ !!! Le résultat de la routine est pris comme nouvelle ligne. Lorsque la routine retourne "undef", la ligne sera ignorée.

» exemple :

my $content  = $msg->decoded;
my $reply    = $content->foreachLine( sub { '> '.$_ } );
my $rev      = $content->foreachLine( sub { reverse } );
sub filled() { length $_ > 1 ? $_ : undef }
my $nonempty = $content->foreachLine( \&filled );
my $WRONG    = $content->foreachLine( sub { s/a/A/ } );
my $right    = $content->foreachLine( sub { s/a/A/r });
$obj->stripSignature(%options)
Supprime la signature du corps. Le corps doit déjà être décodé sinon les mauvaises lignes pourraient être supprimées. Est retourné le corps dépouillé et, en contexte de liste, également la signature, encapsulée dans son propre objet corps. Le séparateur de signature est la première ligne du corps de signature retourné.

La signature est ajoutée par l'expéditeur pour se présenter. Elle est superflue dans certaines situations, par exemple si vous souhaitez créer une réponse au message de la personne, vous n'avez pas besoin d'inclure cette signature.

Si le corps n'avait pas de signature, l'objet corps d'origine est retourné, et "undef" pour le corps de signature.

-Option     --Défaut
 max_lines    10
 pattern      qr/^--\s?$/
 result_type  <identique à l'actuel>
max_lines => ENTIER|undef
Le nombre maximum de lignes qui peuvent constituer la longueur d'une signature. Spécifiez "undef" pour supprimer la limite.
pattern => REGEX|CHAÎNE|CODE
Quel motif définit la ligne qui indique le séparateur entre le message et la signature. En cas de CHAÎNE, cela est mis en correspondance avec le début de la ligne, et REGEX est une expression régulière complète.

En cas de CODE, chaque ligne (de la dernière à la première) est passée à la sous-routine spécifiée comme premier argument. La sous-routine doit retourner TRUE lorsque le séparateur est trouvé.

result_type => CLASSE
Le type de corps à créer pour le corps dépouillé (et éventuellement aussi pour contenir la signature dépouillée)

» exemple :

my $start = $message->decoded;
my $start = $body->decoded;
my $stripped = $start->stripSignature;
my ($stripped, $sign) = $start->stripSignature
    (max_lines => 5, pattern => '-*-*-');
