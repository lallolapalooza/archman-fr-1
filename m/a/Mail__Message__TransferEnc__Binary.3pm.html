NOM

Mail::Message::TransferEnc::Binary - encode/decode les corps de message binaires

HÉRITAGE

Mail::Message::TransferEnc::Binary
  est un Mail::Message::TransferEnc
  est un Mail::Reporter

SYNOPSIS

my Mail::Message $msg = ...;
my $decoded = $msg->decoded;
my $encoded = $msg->encode(transfer => 'binary');

DESCRIPTION

Encode ou décode les corps de message pour l'encodage de transfert binaire. Il s'agit d'un encodage nul.

Étends "DESCRIPTION" dans Mail::Message::TransferEnc.

MÉTHODES

Étends "MÉTHODES" dans Mail::Message::TransferEnc.

DIAGNOSTICS

Erreur : Le décodeur pour l'encodage de transfert $type ne fonctionne pas : $@
La compilation de l'encodage de transfert requis a généré des erreurs, ce qui signifie que le décodeur ne peut pas être utilisé. Lancée par create()
Avertissement : Aucun décodeur pour l'encodage de transfert $type.
Un décodeur pour le type d'encodage de transfert spécifié n'est pas implémenté. Lancée par create()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où elle devrait l'être. Ce message signifie que d'autres classes liées implémentent cette méthode, mais pas la classe en question. Vous devriez probablement enquêter et informer l'auteur du paquet. Lancée par notImplemented()
