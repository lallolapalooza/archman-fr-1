Mail::DKIM::SignerPolicy(3) Documentation Perl fournie par l'utilisateur Mail::DKIM::SignerPolicy(3)

NOM

Mail::DKIM::SignerPolicy - détermine les paramètres de signature d'un message

VERSION

version 1.20240923

DESCRIPTION

Une « politique de signature » (signer policy) est un objet, une classe ou une fonction utilisée par Mail::DKIM::Signer pour déterminer quelles signatures ajouter au message courant. Pour tirer parti des politiques de signature, créez votre propre classe Perl qui hérite de la classe Mail::DKIM::SignerPolicy. La seule méthode que vous devez implémenter est la méthode apply().

La méthode apply() prend en paramètre l'objet Mail::DKIM::Signer. À l'aide de cet objet, elle peut déterminer certaines propriétés du message (par exemple, l'adresse From: ou l'adresse Sender:). Elle définit ensuite diverses propriétés du signataire selon les besoins. La méthode apply() doit retourner une valeur non nulle si le message doit être signé. Si une valeur fausse est retournée, le message est « sauté » (c'est-à-dire non signé).

Voici un exemple de politique qui retourne toujours les mêmes valeurs :

package MySignerPolicy;
use base 'Mail::DKIM::SignerPolicy';
sub apply
{
    my $self = shift;
    my $signer = shift;

    $signer->algorithm('rsa-sha1');
    $signer->method('relaxed');
    $signer->domain('example.org');
    $signer->selector('selector1');
    $signer->key_file('private.key');

    return 1;
}

Pour utiliser cette politique, spécifiez simplement le nom de la classe comme paramètre Policy...

my $dkim = Mail::DKIM::Signer->new(
                Policy => 'MySignerPolicy',
           );

AVANCÉ

Vous pouvez également faire en sorte que la politique construise effectivement la signature à utiliser par le Signer. Pour ce faire, appelez la méthode add_signature() du signataire depuis votre rappel apply(). Par exemple :

sub apply
{
    my $self = shift;
    my $signer = shift;

    $signer->add_signature(
            new Mail::DKIM::Signature(
                Algorithm => $signer->algorithm,
                Method => $signer->method,
                Headers => $signer->headers,
                Domain => $signer->domain,
                Selector => $signer->selector,
            ));
    return;
}

Encore une fois, si vous ne voulez aucune signature, retournez zéro ou undef. Si vous utilisez add_signature() pour créer une signature, la signature par défaut ne sera pas créée, même si vous retournez une valeur non nulle.
