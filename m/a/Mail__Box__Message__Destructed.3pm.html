NOM

Mail::Box::Message::Destruido - un message détruit

HÉRÉDITÉ

Mail::Box::Message::Destruido
  est un Mail::Box::Message
  est un Mail::Message
  est un Mail::Reporter

SYNTAXE

$folder->message(3)->détruire;

DESCRIPTION

Lorsqu'une boîte aux lettres est lue, chaque message est analysé en structures Perl. En particulier, la structure de l'en-tête peut consommer un grand volume de mémoire (les corps des messages peuvent être déplacés vers des fichiers temporaires externes). Les messages détruits suppriment de force toutes les informations d'en-tête et de corps et sont donc beaucoup plus petits. Certaines informations utiles sont toujours présentes dans l'objet.

AVERTISSEMENT : une fois qu'un message a été détruit, il ne peut plus être ramené à la vie. La destruction impose une suppression irréversible de la boîte aux lettres. Si vous avez une boîte aux lettres ouverte en mode lecture seule, le message restera dans cette boîte aux lettres, mais sinon, il peut être supprimé.

DIAGNOSTICS

Erreur : Impossible de convertir une classe (class) en destruction
Seuls les objets réels de Mail::Box::Message peuvent être détruits en objets de type Mail::Box::Message::Destructed. Les messages Mail::Message libèrent leur mémoire immédiatement lorsque la dernière référence est perdue. Casté par coerce()
Erreur : Impossible d'inclure la réponse source comme $include.
Alternative inconnue pour le paramètre de réponse (include). Les options valides sont "NO", "INLINE", "ATTACH" et "ENCAPSULATE". Casté par forward()
Erreur : Impossible d'inclure la réponse source comme $include.
Alternative inconnue pour le paramètre de réponse (include) dans la méthode reply(). Les options valides sont "NO", "INLINE" et "ATTACH". Casté par reply()
Erreur : Le message détruit n'a pas d'étiquettes sauf 'deleted'
Casté par label()
Erreur : Les messages détruits ne peuvent pas être ravivés
Une fois qu'un message est détruit, il ne peut pas être ravivé. La destruction est une optimisation de l'utilisation de la mémoire : si vous souhaitez une fonctionnalité de ravivage, vous ne pouvez pas utiliser Mail::Box::Message::destruct(). Casté par label()
Erreur : La méthode bounce nécessite To, Cc ou Bcc
La méthode bounce() envoie un message reçu à quelqu'un d'autre sans modification ; vous devez spécifier sa nouvelle destination. Si vous ne souhaitez spécifier aucune destination, vous cherchez probablement reply(). Lorsque vous souhaitez modifier le contenu, utilisez forward(). Casté par bounce()
Erreur : La méthode forwardAttach nécessite un préambule
Casté par forwardAttach()
Erreur : La méthode forwardEncapsulate nécessite un préambule
Casté par forwardEncapsulate()
Erreur : Aucune adresse pour créer l'expéditeur
Casté par forward()
