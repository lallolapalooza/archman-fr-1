NOM

Mail::Box::Search::SpamAssassin - sélectionner les messages indésirables avec Mail::SpamAssassin

HEREDITE

Mail::Box::Search::SpamAssassin
  est un Mail::Box::Search
  est un Mail::Reporter

SYNOPIS

use Mail::Box::Manager;
my $mgr    = Mail::Box::Manager->new;
my $folder = $mgr->open('Inbox');
my $spam = Mail::Box::Search::SpamAssassin->new;
if($spam->search($message)) {...}
my @msgs   = $filter->search($folder);
foreach my $msg ($folder->messages)
{   $msg->delete if $msg->label('spam');
}
my $spam2 = Mail::Box::Search::SpamAssassin->new(livrer => 'SUPPRIMER');
$spam2->search($folder);
$mgr->moveMessages($spamfolder, $folder->messages('spam'));

DESCRIPTION

Spam signifie "e-mail non sollicité", et est nommé ainsi d'après un sketch des Monty Python. Bien que Monty Python soit amusant, le spam est une plaie : il fait perdre inutilement des minutes précieuses à la plupart des gens : factures téléphoniques, boîtes aux lettres trop pleines qui bloquent les e-mails légitimes, et suppression accidentelle d'e-mails légitimes qui ressemblent à du spam. Le spam est le fléau d'Internet.

Heureusement, Mail::Box peut être utilisé comme filtre anti-spam, en combinaison avec le module utile Mail::SpamAssassin (qui doit être installé séparément). Chaque message qui est recherché est enveloppé dans un objet Mail::Message::Wrapper::SpamAssassin.

La version 2 du module spam-assassin n'est pas vraiment bien adaptée aux objets Mail::Message, ce qui rendra cette recherche encore plus lente que la détection de spam ne l'est déjà.

Marque tous les messages sélectionnés avec le $label spécifié. Si cette option est explicitement définie à "undef", l'étiquette ne sera pas définie.
limit => $nombre
log => NIVEAU
logical => 'REPLACE'|'AND'|'OR'|'NOT'|'AND NOT'|'OR NOT'
multiparts => BOOLEEN
rewrite_mail => BOOLEEN
Ajoute des lignes à l'en-tête du message décrivant les résultats de l'analyse anti-spam. Voir la sous-routine rewrite_mail de Mail::SpamAssassin::PerMsgStatus.
sa_options => \%options
Les %options pour créer l'objet interne Mail::SpamAssassin ; voir sa page de manuel pour les options disponibles. D'autres réglages peuvent être fournis via le mécanisme de fichier de configuration de SpamAssassin, qui est expliqué dans Mail::SpamAssassin::Conf.
spam_assassin => $objet
Fournit un objet Mail::SpamAssassin $objet à utiliser pour la recherche de spam. Si aucun n'est spécifié, un est créé en interne. L'objet peut être récupéré avec assassinator().
