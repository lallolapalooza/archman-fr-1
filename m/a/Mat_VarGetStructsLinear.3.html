NOM

Mat_VarGetStructsLinear — Indexage linéaire d'une variable de structure

SYNTAXE

#include <matio.h>

matvar_t *
Mat_VarGetStructsLinear(const matvar_t *matvar, int start, int stride, int edge, int copy_fields);

DESCRIPTION

La fonction Mat_VarGetStructsLinear() sélectionne un sous-tableau d'un tableau de structures matvar. Chacun des éléments du sous-tableau contient tous les champs de la structure. L'indexation commence à l'élément start dans le tableau (0 étant le premier élément), et lit toutes les stride valeurs (1 étant chaque élément, 2 tous les deux éléments, etc.). Le nombre total d'éléments dans le sous-tableau est spécifié comme edge. Le tableau d'origine doit avoir au moins start+(stride-1)*edge+1 éléments. L'option copy_fields spécifie si les champs de la structure d'origine sont copiés pour le nouveau sous-tableau. Si elle est définie sur 0, les champs du tableau de structures renvoyé ont le même pointeur que le tableau d'origine, et le champ data de la structure du sous-tableau. Le sous-tableau est marqué avec le drapeau de conservation de la mémoire, indiquant que les champs ne doivent pas être libérés. Ils sont libérés lorsque la structure d'origine est libérée.

VALEUR DE RETOUR

Un sous-tableau du tableau de structures d'origine, ou NULL en cas d'erreur.
