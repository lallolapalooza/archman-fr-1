NOM

Mail::Cap - comprendre les fichiers mailcap

SYNTAXE

my $mc   = Mail::Cap->new;
my $desc = $mc->description('image/gif');
print "GIF desc: $desc\n";
my $cmd  = $mc->viewCmd('text/plain; charset=iso-8859-1', 'file.txt');

DESCRIPTION

Analyse les fichiers mailcap tels que spécifiés dans "RFC 1524 --A User Agent Configuration Mechanism For Multimedia Mail Format Information>. Dans la description ci-dessous, $type fait référence au type MIME tel que spécifié dans l'en-tête "Content-Type" des messages mail ou HTTP. Des exemples de types sont :

image/gif
text/html
text/plain; charset=iso-8859-1

Vous pourriez également consulter la distribution File::MimeInfo, qui accède à des tables utilisées par de nombreuses applications sur un système, et qui a donc supplanté les spécifications mail-cap sur les systèmes modernes (UNIX).

MÉTHODES

Constructeurs

Mail::Cap->new(%options)
Crée et initialise un nouvel objet Mail::Cap. Si vous lui passez un argument, il essaiera d'analyser le fichier spécifié. Sans argument, il recherchera le fichier mailcap en utilisant le chemin mailcap standard, ou la variable d'environnement MAILCAPS s'il est défini. 
-Option  --Défaut
 filename  undef
 take      'FIRST'
filename => FILENAME
Ajoute le fichier spécifié à la liste des emplacements standard. Ce fichier est essayé en premier.
take => 'ALL'|'FIRST'
Inclut tous les fichiers mailcap trouvés. Par défaut, seul le premier fichier est analysé, mais la RFC nous dit d'inclure TOUS les fichiers. Pour maintenir la compatibilité descendante, le défaut ne prend que le PREMIER.

Exemple :

$mcap = new Mail::Cap;
$mcap = new Mail::Cap "/mydir/mailcap";
$mcap = new Mail::Cap filename => "/mydir/mailcap";
$mcap = new Mail::Cap take => 'ALL';
$mcap = Mail::Cap->new(take => 'ALL');

Exécution de commandes

Ces méthodes invoquent un programme approprié pour présenter ou manipuler l'objet média dans le fichier spécifié. Elles renvoient toutes 1 si une commande a été trouvée, et 0 sinon. Vous pourriez tester $? pour le résultat de la commande.

$obj->compose($type, $file)
$obj->edit($type, $file)
$obj->print($type, $file)
$obj->view($type, $file)

Créateur de commande

Ces méthodes renvoient une chaîne qui peut être passée à system() afin d'invoquer un programme approprié pour présenter ou manipuler l'objet média dans le fichier spécifié. Elle renverra "undef" si aucune spécification appropriée n'existe.

$obj->composeCmd($type, $file)
$obj->editCmd($type, $file)
$obj->printCmd($type, $file)
$obj->viewCmd($type, $file)

Recherche de définitions

Les méthodes renvoient le champ mailcap correspondant pour le type.

$obj->description($type)
$obj->field($type, $field)
Renvoie le champ spécifié pour le type. Renvoie undef si aucune spécification n'existe.
$obj->nametemplate($type)
$obj->textualnewlines($type)
$obj->x11_bitmap($type)
