NOM

Mail::SpamAssassin::Plugin::DMARC - vérifier la politique DMARC

SYNOPSIS

loadplugin Mail::SpamAssassin::Plugin::DMARC
ifplugin Mail::SpamAssassin::Plugin::DMARC
  header DMARC_PASS eval:check_dmarc_pass()
  describe DMARC_PASS politique de passage DMARC
  tflags DMARC_PASS net nice
  score DMARC_PASS -0.001
  header DMARC_REJECT eval:check_dmarc_reject()
  describe DMARC_REJECT politique de rejet DMARC
  tflags DMARC_REJECT net
  score DMARC_REJECT 0.001
  header DMARC_QUAR eval:check_dmarc_quarantine()
  describe DMARC_QUAR politique de mise en quarantaine DMARC
  tflags DMARC_QUAR net
  score DMARC_QUAR 0.001
  header DMARC_NONE eval:check_dmarc_none()
  describe DMARC_NONE politique DMARC aucune
  tflags DMARC_NONE net
  score DMARC_NONE 0.001
  header DMARC_MISSING eval:check_dmarc_missing()
  describe DMARC_MISSING politique DMARC manquante
  tflags DMARC_MISSING net
  score DMARC_MISSING 0.001
endif

DESCRIPTION

Ce plugin vérifie si les e-mails correspondent à la politique DMARC. Le plugin nécessite que les plugins DKIM et SPF soient activés.

dmarc_save_reports ( 0 | 1 ) (défaut: 0)
Enregistrer les rapports DMARC en utilisant Mail::DMARC::Store. Le fichier mail-dmarc.ini doit être configuré pour enregistrer et envoyer les rapports DMARC.
