Module Map
: sig end

Tables d'association sur des types ordonnés.

Ce module implémente des tables d'association applicatives, également connues sous le nom de cartes finies ou dictionnaires, étant donné une fonction d'ordre total sur les clés. Toutes les opérations sur les cartes sont purement applicatives (aucun effet de bord). L'implémentation utilise des arbres binaires équilibrés, et par conséquent, la recherche et l'insertion prennent un temps logarithmique par rapport à la taille de la carte.

Par exemple :

     module IntPairs =
       struct
         type t = int * int
         let compare (x0,y0) (x1,y1) =
           match Stdlib.compare x0 x1 with
               0 -> Stdlib.compare y0 y1
             | c -> c
       end
     module PairsMap = Map.Make(IntPairs)
     let m = PairsMap.(empty |> add (0,1) "hello" |> add (1,0) "world")

Ceci crée un nouveau module PairsMap , avec un nouveau type 'a PairsMap.t de cartes de int * int à 'a . Dans cet exemple, m contient des valeurs de type string donc son type est string PairsMap.t .
