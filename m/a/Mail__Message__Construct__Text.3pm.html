NOM

Mail::Message::Construct::Text - capturer un Mail::Message sous forme de texte

SYNOPSIS

my $text = $msg->string;
my $text = "$msg";   # via overload
my @text = $msg->lines;
my @text = @$lines;  # via overload
my $fh   = $msg->file;
my $line = <$fh>;
$msg->printStructure;

DESCRIPTION

Une fonctionnalité complexe sur les objets Mail::Message est implémentée dans différents fichiers qui sont chargés à la demande. Ce fichier implémente la fonctionnalité liée à la création de réponses aux messages.

MÉTHODES

Le message entier en texte

$obj->file()
Retourne le message sous forme de handle de fichier.
$obj->lines()
Retourne le message entier sous forme d'ensemble de lignes. En contexte LIST, des copies des lignes sont retournées. En contexte SCALAR, une référence à un tableau de lignes est retournée.
$obj->printStructure( [$fh|undef],[$indent] )
Imprime la structure d'un message sur le handle de fichier spécifié $fh ou sur le handle sélectionné. Lorsque "undef" est explicitement spécifié comme handle, la sortie est retournée sous forme de chaîne.

Le sujet du message et les types de toutes les parties composantes sont affichés.

$indent spécifie la chaîne d'indentation initiale : elle est ajoutée devant chaque ligne. Le $indent doit contenir au moins un espace blanc.

» exemple:

my $msg = ...;
$msg->printStructure(\*OUTPUT);
$msg->printStructure;
my $struct = $msg->printStructure(undef);
# Sortie possible pour un message :
multipart/mixed: message transféré de Pietje Puk (1550 octets)
   text/plain (164 octets)
   message/rfc822 (1043 octets)
      multipart/alternative: Une alternative multipartite (942 octets)
         text/plain (148 octets, supprimé)
         text/html (358 octets)
$obj->string()
Retourne le message entier sous forme de chaîne.
