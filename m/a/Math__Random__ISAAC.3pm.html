NOM

Math::Random::ISAAC - Interface Perl à l'algorithme de génération de nombres aléatoires ISAAC

VERSION

version 1.004

SYNTAXE

use Math::Random::ISAAC;
my $rng = Math::Random::ISAAC->new(@seeds);
for (0..30) {
  print 'Résultat : ' . $rng->irand() . "\n";
}

DESCRIPTION

Comme pour d'autres algorithmes de génération de nombres pseudo-aléatoires (PRNG) comme le Mersenne Twister (voir Math::Random::MT), cet algorithme est conçu pour prendre des informations de germe et produire des résultats apparemment aléatoires en sortie.

Cependant, ISAAC (Indirection, Shift, Accumulate, Add, and Count) a des objectifs différents de ces algorithmes courants. En particulier, il est très rapide - en moyenne, il nécessite seulement 18,75 cycles d'horloge machine pour générer une valeur de 32 bits. Cela le rend adapté aux applications où un grand volume de données aléatoires doit être généré rapidement, comme dans les simulations utilisant la méthode Monte Carlo ou pour les jeux.

Les résultats sont uniformément distribués, non biaisés et imprévisibles, sauf si vous connaissez la graine. Cet algorithme a été publié par Bob Jenkins dans la seconde moitié des années 90 et, malgré les efforts de nombreux chercheurs en sécurité, aucun attaquant pratique n'a été trouvé à ce jour.

AVERTISSEMENT D'UTILISATION

Aucune méthode pour fournir des données de germe initiales n'a été fournie par l'auteur. Sur son site web, Bob Jenkins écrit :

Le semis d'un générateur de nombres aléatoires est presque aussi difficile que le problème de l'encryptage du semis avec un chiffre par blocs.

Dans le même esprit, par défaut, ce module ne sème pas l'algorithme du tout - il remplit simplement l'état avec des zéros - si aucune graine n'est fournie. L'idée est de rappeler aux utilisateurs que la sélection d'une bonne graine est importante pour leur objectif, et que le module peut commode établir quelque chose comme « localtime  » en coulisses, ce qui peut être préjudiciable aux utilisateurs à long terme, car ils ne comprennent pas les limitations de le faire ainsi.

Le type de graine que vous souhaitez utiliser dépend entièrement du but dans lequel vous utilisez cet algorithme dans votre programme. Voici quelques méthodes de semis possibles :

1 Math::TrulyRandom
Le module Math::TrulyRandom fournit un moyen d'obtenir des données aléatoires vraies à l'aide d'interruptions de synchronisation. C'est probablement l'une des meilleures façons de semer l'algorithme.
2 /dev/random
L'utilisation du périphérique d'entrée aléatoire du système est, en théorie, la meilleure idée, car elle recueille de l'entropie à partir de diverses sources, y compris des temporisateurs d'interruptions, d'autres interruptions de périphériques, etc. Cependant, il n'est pas portable sur autre chose que les systèmes de type Unix, et pourrait ne pas produire de bonnes données sur certains systèmes.
3 localtime()
Cela fonctionne pour des choses basiques comme les simulations, mais produit une sortie moins aléatoire, surtout si de nouvelles instances sont créées rapidement (car les graines seraient les mêmes en résolution de seconde).
4 Time::HiRes
Théoriquement, l'utilisation de Time::HiRes est la même que l'option (2), mais vous obtenez une résolution de temps plus élevée, il est donc moins probable que vous obteniez la même graine deux fois. Remarque : vous devez convertir la sortie en un entier à un moment donné, peut-être en prenant les bits les plus significatifs ou en utilisant une fonction de hachage. Cela serait moins susceptible aux doublons, mais toujours pas idéal.

MÉTHODES

new

Math::Random::ISAAC->new( @seeds )

Crée un objet «  Math::Random::ISAAC » basé sur l'algorithme de la version optimisée C/XS, Math::Random::ISAAC::XS, ou se rabat sur le module Pure Perl inclus, Math::Random::ISAAC::PP.

Exemple de code :

my $rng = Math::Random::ISAAC->new(time);

Cette méthode retournera un objet «  Math::Random::ISAAC » approprié ou lèvera une exception en cas d'erreur.

rand

$rng->rand()

Retourne un nombre flottant à double précision normalisé entre 0 et 1 (inclus ; c'est un intervalle fermé).

En interne, il prend simplement un entier non signé uniformément distribué de «  $rng->irand() » et le divise par «  2**32-1 » (taille maximale d'un entier non signé).

Exemple de code :

my $next = $rng->rand();

Cette méthode retournera un nombre flottant à double précision ou lèvera une exception en cas d'erreur.

irand

$rng->irand()

Retourne le prochain entier aléatoire de 32 bits. Il retournera une valeur telle que : «  0 <= x <= 2**32-1 ».

Exemple de code :

my $next = $rng->irand();

Cette méthode retournera un entier non signé de 32 bits ou lèvera une exception en cas d'erreur.

OBJECTIF

Le but de ce module est de fournir une interface simple aux deux implémentations compatibles de ce module, à savoir Math::Random::ISAAC::XS et Math::Random::ISAAC::PP.

Si, pour une raison quelconque, vous souhaitez déterminer quelle version du module est incluse par «  Math::Random::ISAAC », alors :

print 'Type de backend : ', $Math::Random::ISAAC::DRIVER, "\n";

Pour forcer l'utilisation de l'un ou l'autre, chargez simplement le module approprié :

use Math::Random::ISAAC::XS;
my $rng = Math::Random::ISAAC::XS->new();
# ou
use Math::Random::ISAAC::PP;
my $rng = Math::Random::ISAAC::PP->new();

VOIR AUSSI

Math::Random::ISAAC::XS, la version optimisée C/XS de ce module, qui sera utilisée automatiquement si disponible.

http://burtleburtle.net/bob/rand/isaacafa.html, la page de Bob Jenkins sur ISAAC, qui explique l'algorithme ainsi que les attaquants potentiels.

http://eprint.iacr.org/2006/438.pdf, un article intitulé «  On the pseudo-random generator ISAAC », qui affirme qu'il existe de nombreuses graines produisant des résultats non uniformes. L'auteur, Jean-Philippe Aumasson, soutient qu'ISAAC devrait utiliser des rotations (décalages circulaires) au lieu des décalages normaux pour augmenter la diffusion de l'état, entre autres.

http://eprint.iacr.org/2001/049.pdf, un article de Marina Pudovkina discutant des attaques à texte clair contre le générateur de clé ISAAC. Entre autres, elle note que la complexité temporelle est «  Tmet = 4.67*10^1240 », donc il reste un chiffrement sûr pour les applications pratiques.

PRÉCAUTIONS

  • Il n'y a pas de méthode pour ressemer les algorithmes. Ceci n'est pas nécessaire car on peut simplement appeler «  new » avec de nouvelles données de graine périodiquement.

    • Cependant, cela fournit également une solution simple :

    Comme ISAAC est conçu pour être un chiffrement sûr, si vous voulez le ressemer, une façon est d'utiliser un autre chiffrement pour semer une version initiale d'ISAAC, puis d'utiliser la sortie d'ISAAC comme graine pour d'autres instances d'ISAAC lorsque vous en avez besoin.
  • Il n'y a aucun moyen de cloner une instance de PRNG. Je ne sais pas pourquoi ce serait nécessaire ou utile. Envoyez-moi un rapport de bug avec une explication et je l'examinerai pour la prochaine version.

DESCRIPTION

Math::Random::ISAAC est un module Perl qui fournit une génération de nombres aléatoires à l'aide de l'algorithme ISAAC. Ce module est conçu pour être efficace et sécurisé, en mettant l'accent sur la génération de nombres aléatoires de haute qualité adaptés à diverses applications.

MÉTHODES

Le module fournit plusieurs méthodes pour générer des nombres aléatoires, notamment :

  • new() - Crée une nouvelle instance du générateur de nombres aléatoires.

  • shuffle() - Mélange la séquence de nombres aléatoires.

  • random() - Renvoie un nombre aléatoire de la séquence.

  • seed() - Initialise le générateur de nombres aléatoires avec une valeur donnée.

BUT

Le but de ce module est de fournir un générateur de nombres aléatoires fiable et efficace qui peut être utilisé dans diverses applications, telles que les simulations, la cryptographie et d'autres scénarios où des nombres aléatoires sont nécessaires.
