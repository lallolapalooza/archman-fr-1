NOM

Mail::DKIM::Canonicalization::DkimCommon - canonisation commune

VERSION

version 1.20240923

DESCRIPTION

Cette classe implémente des fonctionnalités communes à toutes les méthodes de canonisation DKIM actuellement définies, mais pas nécessairement communes aux futures méthodes de canonisation.

Pour les fonctionnalités communes à toutes les méthodes de canonisation (y compris les méthodes futures), voir Mail::DKIM::Canonicalization::Base.
