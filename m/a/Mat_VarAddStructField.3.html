MAT_VARADDSTRUCTFIELD(3) Manuel des fonctions de bibliothèque MAT_VARADDSTRUCTFIELD(3)

NOM

Mat_VarAddStructField — Ajoute un champ à un tableau de structures.

SYNTAXE

#include <matio.h>

int
Mat_VarAddStructField(matvar_t *matvar, const char *fieldname);

DESCRIPTION

La fonction Mat_VarAddStructField() ajoute un nom de champ à la variable de structure matvar.

VALEURS DE RETOUR

0 est retourné en cas de succès.

VOIR AUSSI
