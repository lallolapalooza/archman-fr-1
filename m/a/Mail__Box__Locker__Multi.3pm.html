NOM

Mail::Box::Locker::Multi - verrouille un dossier de toutes les manières possibles

HÉRÉDITÉ

Mail::Box::Locker::Multi
  est un Mail::Box::Locker
  est un Mail::Reporter

SYNTAXE

Voir Mail::Box::Locker

DESCRIPTION

Le verrouilleur "::Multi" verrouille un dossier de toutes les manières possibles. Ainsi, la probabilité qu'un autre programme laisse le dossier tranquille pendant notre accès est la plus élevée.

Les verrous NFS et Flock sont essayés. D'autres pourraient être ajoutés lorsque les méthodes de verrouillage seront étendues. DotLock chevauche NFS-lock, mais NFS-lock est plus sûr, donc cette version est préférée.

Étends "DESCRIPTION" dans Mail::Box::Locker.

use => TABLEAU-de-(NOMS|VERROUILLEUR)
Tableau de NOMS de types de verrouilleurs ou d'objets VERROUILLEUR à utiliser pour verrouiller un dossier. Les NOMS de types sont convertis en objets. Lorsque vous créez vos propres objets VERROUILLEUR, assurez-vous de définir le délai d'attente très court (de préférence à 1).

Certains types de verrouillage ne sont pas disponibles sur certaines plateformes, ils ne seront donc pas exclus de la liste par défaut (NFS POSIX Flock).

» exemple : utiliser un sous-ensemble de verrouilleurs multiples

my $locker = Mail::Box::Locker::Multi->new(use => ['DOTLOCK','FLOCK']);
