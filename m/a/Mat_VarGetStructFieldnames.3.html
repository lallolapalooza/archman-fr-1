NOM

Mat_VarGetStructFieldnames — Récupère les noms des champs d'une variable de structure.

SYNOPIS

#include <matio.h>

char * const *
Mat_VarGetStructFieldnames(const matvar_t *matvar);

DESCRIPTION

La fonction Mat_VarGetStructFieldnames() retourne les noms des champs de la variable de structure matvar.

VALEUR DE RETOUR

Un tableau de noms de champs est retourné si la variable est une variable de structure valide. Sinon, NULL est retourné. La fonction Mat_VarGetNumberOfFields() retourne le nombre de champs pour la structure.
