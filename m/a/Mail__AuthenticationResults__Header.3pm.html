Mail::AuthenticationResults::Header(3) Documentation Perl fournie par l'utilisateur Mail::AuthenticationResults::Header(3)

NOM

Mail::AuthenticationResults::Header - Classe modélisant l'ensemble entier de l'en-tête Authentication Results

VERSION

version 2.20250709

DESCRIPTION

Cette classe représente l'ensemble principal des résultats d'authentification.

Veuillez consulter Mail::AuthenticationResults::Header::Base.
