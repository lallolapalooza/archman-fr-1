NAME

Mail::DKIM::TextWrap - module de texte écrit pour être utilisé avec DKIM

VERSION

version 1.20240923

DESCRIPTION

Ceci est un module de texte général que j'ai écrit car j'avais des besoins spécifiques avec Mail::DKIM qu'aucun des modules de texte contemporains n'offrait.

En particulier, il offre la possibilité de changer les options de césure au milieu d'un paragraphe. Par exemple, avec une signature DKIM :

DKIM-Signature: a=rsa; c=simple; h=first:second:third:fourth;
        b=Xr2mo2wmb1LZBwmEJElIPezal7wQQkRQ8WZtxpofkNmXTjXf8y2f0

on peut insérer des sauts de ligne autour de n'importe quel deux-points du tag h=, ou de n'importe quel caractère du tag b=. La façon dont j'ai implémenté cela a été de sérialiser la signature un élément à la fois, en changeant les options de césure au début et à la fin de chaque tag.

SYNOPSIS (POUR LES UTILISATEURS DE MAIL::DKIM)

use Mail::DKIM::TextWrap;

Ajoutez simplement la ligne ci-dessus à tout programme qui utilise Mail::DKIM::Signer et vos signatures seront automatiquement coupées à 72 caractères.

SYNOPSIS (POUR LES AUTRES UTILISATEURS)

my $output = "";
my $tw = Mail::DKIM::TextWrap->new(
                Margin => 10,
                Output => \$output,
            );
$tw->add("Mary had a little lamb, whose fleece was white as snow.\n");
$tw->finish;
print $output;

OPTIONS DE CÉSURE

Les options de césure peuvent être spécifiées lors de l'appel à new(), ou en changeant la propriété au besoin. Par exemple, pour changer le nombre de caractères autorisés par ligne :

$tw->{Margin} = 20;
Break
une expression régulière qui correspond aux caractères où un saut de ligne peut être inséré. Les sauts de ligne sont insérés APRÈS un sous-chaîne correspondante. La valeur par défaut est "/\s/".
BreakBefore
une expression régulière qui correspond aux caractères où un saut de ligne peut être inséré. Les sauts de ligne sont insérés AVANT une sous-chaîne correspondante. Bien que Break soit normalement utilisé, il est souvent préférable d'utiliser BreakBefore. La valeur par défaut est "undef".
Margin
définit combien de caractères sont autorisés par ligne. La valeur par défaut est 72. Si aucun emplacement de césure n'est trouvé dans une ligne, la ligne s'étend au-delà de cette marge.
Separator
le texte à insérer lorsqu'un saut de ligne est nécessaire. La valeur par défaut est "\n". Si vous souhaitez définir un retrait pour la ligne suivante (par exemple, toutes les lignes sauf la première commencent par quatre espaces), utilisez quelque chose comme "\n".
Swallow
une expression régulière qui correspond aux caractères qui peuvent être omis lorsqu'un saut de ligne se produit. Par exemple, si vous insérez un saut de ligne entre deux mots, vous remplacez un espace par le saut de ligne, donc vous omettez l'espace. D'un autre côté, si vous insérez un saut de ligne entre deux parties d'un mot composé, vous coupez au trait d'union, mais vous voulez toujours afficher le trait d'union. La valeur par défaut est "/\s/".

CONSTRUCTEUR

new() - créer un objet de césure de texte

my $tw = Mail::DKIM::TextWrap->new(
                    Output => \$output,
                    %wrapping_options,
                );

L'objet de césure de texte encapsule les options actuelles et l'état actuel de la chaîne de texte. En plus de spécifier les options de césure comme décrit dans la section précédente, les options suivantes sont reconnues :

Output
une référence scalaire ou une référence glob, qui spécifie où le texte "coupé" doit être écrit. S'il n'est pas spécifié, STDOUT est utilisé par défaut.

MÉTHODES

add() - traiter du texte qui peut être coupé

$tw->add("Mary had a little lamb.\n");

Vous pouvez add() tout le texte en une seule fois, ou add() le texte par morceaux en appelant add() plusieurs fois.

finish() - appeler quand il n'y a plus de texte à ajouter

$tw->finish;

Appelez ceci lorsque vous avez terminé d'ajouter du texte, afin que tout texte restant dans les tampons de TextWrap soit émis.

flush() - émettre le texte partiel actuel, s'il y en a

$tw->flush;

Appelez ceci lorsque vous changez les options de césure de TextWrap au milieu d'une chaîne de mots. Il permet explicitement un saut de ligne à la position actuelle de la chaîne, quel que soit l'endroit où elle correspond au schéma de césure actuel.
