Mail::SpamAssassin::Plugin::Pyzor(3) Documentation Perl Contribuée par l'Utilisateur Mail::SpamAssassin::Plugin::Pyzor(3)

NOM

Mail::SpamAssassin::Plugin::Pyzor - effectue une vérification Pyzor des messages

SYNTAXE

loadplugin     Mail::SpamAssassin::Plugin::Pyzor

DESCRIPTION

Pyzor est un système collaboratif et réseau pour détecter et bloquer le spam à l'aide d'empreintes d'identification des messages.

Voir http://pyzor.org/ pour plus d'informations sur Pyzor.

RÉGLAGES UTILISATEUR

use_pyzor (0|1) (par défaut : 1)
Si Pyzor doit être utilisé, s'il est disponible.
pyzor_count_min NOMBRE (par défaut : 5)
Cette option définit la fréquence à laquelle la somme de contrôle du corps d'un message doit avoir été signalée au serveur Pyzor avant que SpamAssassin ne considère la vérification Pyzor comme correspondante.

Comme la plupart des clients ne devraient pas signaler automatiquement ces sommes de contrôle, vous devriez définir cette valeur à un nombre relativement bas, par exemple 5.

pyzor_welcomelist_min NOMBRE (par défaut : 10)
Anciennement pyzor_whitelist_min qui fonctionnera de manière interchangeable jusqu'à la version 4.1.

Cette option définit la fréquence à laquelle la somme de contrôle du corps d'un message doit avoir été ajoutée à la liste blanche (welcomelisted) sur le serveur Pyzor pour que SpamAssassin envisage d'ignorer le résultat. La décision finale est prise par pyzor_welcomelist_factor.

pyzor_welcomelist_factor NOMBRE (par défaut : 0.2)
Anciennement pyzor_whitelist_factor qui fonctionnera de manière interchangeable jusqu'à la version 4.1.

Ignore le résultat Pyzor si REPORTCOUNT x NOMBRE >= pyzor_welcomelist_min. Pour le réglage par défaut, cela signifie : 50 rapports nécessitent 10 entrées dans la liste blanche.

RÉGLAGES ADMINISTRATEUR

pyzor_fork (0|1) (par défaut : 1)
Au lieu d'exécuter Pyzor de manière synchrone, crée un processus séparé pour cela et lit les résultats plus tard (similaire aux recherches DNS asynchrones). Augmente le débit. Considéré comme expérimental sous Windows, où la valeur par défaut est 0.
pyzor_perl (0|1) (par défaut : 0)
Au lieu d'exécuter le client Pyzor, utilise un client Perl pur.
pyzor_timeout n (par défaut : 5)
Combien de secondes attendre Pyzor avant que l'analyse ne se poursuive sans les résultats Pyzor. Une valeur numérique peut éventuellement être suffixée par une unité de temps (s, m, h, d, w, indiquant les secondes (par défaut), les minutes, les heures, les jours, les semaines).

Vous pouvez configurer Pyzor pour qu'il ait son propre délai d'attente par serveur. Configurez le délai d'attente de ce plugin en gardant cela à l'esprit. Le délai d'attente de ce plugin est un plafond maximum. Si Pyzor prend plus de temps que cela pour compléter sa communication avec tous les serveurs, aucun résultat n'est utilisé par SpamAssassin.

Les serveurs Pyzor ne synchronisent pas encore leurs serveurs, il peut donc être bénéfique d'en vérifier et d'en signaler plus d'un. Voir la liste de diffusion pyzor-users pour les serveurs alternatifs qui ne sont pas publiés via 'pyzor discover'.

Si vous utilisez plusieurs serveurs Pyzor, une bonne règle générale serait de définir le délai d'attente du plugin SpamAssassin comme étant le même ou juste un peu plus que le délai d'attente par serveur Pyzor (par exemple, 3.5 et 2 pour deux serveurs Pyzor). Si plus d'un de vos serveurs Pyzor expire constamment, envisagez d'en supprimer un.

pyzor_options options
Spécifie des options supplémentaires pour la commande pyzor(1). Notez que seuls les caractères de la plage [0-9A-Za-z =,._/-] sont autorisés pour des raisons de sécurité.
pyzor_path STRING
Cette option indique à SpamAssassin où trouver spécifiquement le client "pyzor" au lieu de laisser SpamAssassin le trouver dans le PATH actuel. Notez que si le mode tainting est activé dans l'interpréteur Perl, vous devriez l'utiliser, car le PATH actuel aura été effacé.
pyzor_server_file FICHIER
Chemin du fichier de configuration des serveurs Pyzor, utilisé par l'implémentation Perl de Pyzor. Par défaut, Pyzor se connectera à public.pyzor.org sur le port 24441.
