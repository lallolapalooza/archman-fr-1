Mat_VarWrite(3)

Paquet: libmatio

Licences: BSD-2-Clause

MAT_VARWRITE(3) Manuel des fonctions de bibliothèque MAT_VARWRITE(3)

NOM

Mat_VarWrite — Écrit une variable MATLAB dans un fichier MAT MATLAB.

SYNTAXE

#include <matio.h>

int
Mat_VarWrite(mat_t *matfp, matvar_t *matvar, enum matio_compression compress);

DESCRIPTION

La fonction Mat_VarWrite() écrit la variable MATLAB matvar dans le fichier MAT matfp, qui doit être ouvert en écriture. Si le fichier MAT est un fichier MAT de version 5 ou HDF5, l'option compress permet d'écrire la variable en utilisant la compression zlib si elle est disponible. Si la compression n'est pas disponible, la variable est écrite sans compression.

VALEURS DE RETOUR

La fonction renvoie 0 si la variable a été écrite avec succès dans le fichier MAT. Sinon, une valeur d'erreur est renvoyée.

EXEMPLES

Cet exemple de programme crée un fichier MAT nommé par le premier argument du programme et écrit la variable nommée m_pi dans le fichier.

#include <math.h>
#include "matio.h"

int
main(int argc, char **argv)
{
    mat_t    *matfp;
    matvar_t *matvar;
    size_t    dims[2] = {1, 1};
    double    m_pi = M_PI;

    matfp = Mat_CreateVer(argv[1], NULL, MAT_FT_DEFAULT);
    if ( NULL == matfp ) {
        fprintf(stderr, "Erreur lors de la création du fichier MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    matvar = Mat_VarCreate("m_pi", MAT_C_DOUBLE, MAT_T_DOUBLE,
                           2, dims, &m_pi, 0);
    if ( NULL != matvar ) {
        Mat_VarWrite(matfp, matvar, MAT_COMPRESSION_ZLIB);
        Mat_VarFree(matvar);
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
