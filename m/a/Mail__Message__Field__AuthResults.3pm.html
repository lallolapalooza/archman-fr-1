NOM

Mail::Message::Field::AuthResults - champ d'en-tête de message résultat d'authentification

HÉRÉDITÉ

Mail::Message::Field::AuthResults
  est un Mail::Message::Field::Structured
  est un Mail::Message::Field::Full
  est un Mail::Message::Field
  est un Mail::Reporter

SYNTAXE

my $f = Mail::Message::Field->new('Authentication-Results' => '...');
my $g = Mail::Message::Field->new('Authentication-Results');
$g->addResult(method => 'dkim', result => 'fail');

DESCRIPTION

Les agents de transfert de courrier peuvent vérifier l'authenticité d'un message entrant. Ils ajoutent des en-têtes 'Authentication-Results', peut-être plus d'un. Cette implémentation est basée sur la RFC7601.

DIAGNOSTICS

Avertissement : le contenu du champ n'est pas numérique : $content
La valeur numérique d'un champ est demandée (par exemple, les champs "Lines" ou "Content-Length" doivent être numériques), cependant les données contiennent des caractères étranges. Converti par toInt()
Erreur : nom de champ trop long (max $longueur), dans '$nom'
Il n'est pas spécifié dans les RFCs quelle est la longueur maximale d'un nom de champ, mais il devrait au moins être quelques caractères plus court que la longueur de ligne. Converti par fold()
Avertissement : caractère illégal dans le jeu de caractères '$charset'
Le champ est créé avec une chaîne utf8 qui ne contient que des données du jeu de caractères spécifié. Cependant, ce jeu de caractères ne peut jamais être un nom valide car il contient des caractères qui ne sont pas autorisés. Converti par encode()
Avertissement : caractère illégal dans le nom de champ $nom
Un nouveau champ est en cours de création et contient des caractères non autorisés par les RFCs. L'utilisation de ce champ dans des messages peut perturber d'autres clients de messagerie ou agents de transfert, et par conséquent mutiler ou détruire votre message. Converti par consume()
Avertissement : caractère illégal dans la langue '$lang'
Le champ est créé avec des données spécifiées comme étant dans une certaine langue, cependant, le nom de la langue ne peut pas être valide : il contient des caractères qui ne sont pas autorisés par les RFCs. Converti par encode()
Avertissement : encodage illégal '$encoding', utilisé 'q'
Les RFCs autorisent uniquement l'encodage base64 ("b " ou "B ") ou quoted-printable ("q" ou "Q"). Les autres options que ces quatre sont illégales. Converti par encode()
Erreur : aucun attribut pour Authentication-Results
Il n'est pas possible d'ajouter des attributs à ce champ. Converti par addAttribute()
Erreur : le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode alors qu'il le devrait. Ce message signifie que d'autres classes apparentées implémentent cette méthode, mais la classe en question ne le fait pas. Vous devriez probablement enquêter à ce sujet et informer l'auteur du paquet. Converti par notImplemented()
