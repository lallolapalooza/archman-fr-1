NOM

Mail::SpamAssassin::Plugin::Bayes - déterminer la probabilité de spam à l'aide d'un classificateur bayésien

DESCRIPTION

Ceci est un classificateur probabiliste de style bayésien, utilisant un algorithme basé sur celui détaillé dans l'article de Paul Graham, A Plan For Spam, disponible à l'adresse :

http://www.paulgraham.com/spam.html

Il incorpore également certains autres aspects tirés de la page web de Graham Robinson sur le sujet à l'adresse :

http://radio.weblogs.com/0101454/stories/2002/09/16/spamDetection.html

Et le combinateur de probabilité chi-carré tel que décrit ici :

http://www.linuxjournal.com/print.php?sid=6467

Les résultats sont incorporés dans SpamAssassin sous les règles BAYES_*.

RÉGLAGES UTILISATEUR

bayes_stopword_languages lang (défaut : en)
Langues activées pour le traitement des mots vides de bayes. Chaque langue a une expression régulière de mots vides par défaut, les jetons correspondant à cette expression régulière ne seront pas pris en compte dans le traitement bayésien.

Des expressions régulières personnalisées pour des langues supplémentaires peuvent être définies dans "local.cf".

Des expressions régulières personnalisées peuvent être spécifiées en utilisant le mot-clé "bayes_stopword_lang" comme dans l'exemple suivant :

bayes_stopword_languages en se
bayes_stopword_en (?:you|me)
bayes_stopword_se (?:du|mig)

Les expressions régulières sont insensibles à la casse et seront automatiquement ancrées au début et à la fin.

Pour désactiver l'utilisation des mots vides, spécifiez "bayes_stopword_languages disable".

Une seule ligne de configuration bayes_stopword_languages ou bayes_stopword_xx peut être utilisée. Une nouvelle ligne de configuration remplacera l'ancienne, par exemple celles de l'ensemble de règles par défaut de SpamAssassin (60_bayes_stopwords.cf).

bayes_max_token_length (défaut : 15)
Configurez le nombre maximum de caractères qu'un jeton peut contenir.
