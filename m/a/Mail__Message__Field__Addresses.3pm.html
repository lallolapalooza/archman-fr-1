NOM

Mail::Message::Field::Addresses - Champs contenant des adresses électroniques

HÉRITAGE

Mail::Message::Field::Addresses
  est un Mail::Message::Field::Structured
  est un Mail::Message::Field::Full
  est un Mail::Message::Field
  est un Mail::Reporter

SYNOPSIS

my $cc = Mail::Message::Field::Full->new('Cc');
my $me = Mail::Message::Field::Address->parse('"Test" <test@mail.box>')
   or die;
my $other = Mail::Message::Field::Address->new(phrase => 'Other',
      address => 'other@example.com')
   or die;
$cc->addAddress($me);
$cc->addAddress($other, group => 'them');
$cc->addAddress(phrase => 'third', address => 'more@any.museum',
  group => 'them');
my $group = $cc->addGroup(name => 'collegues');
$group->addAddress($me);
$group->addAddress(phrase => "You", address => 'you@example.com');
my $msg = Mail::Message->build(Cc => $cc);
print $msg->string;
my $g  = Mail::Message::Field::AddrGroup->new(...);
$cc->addGroup($g);

DESCRIPTION

Tous les champs d'en-tête qui contiennent uniquement des adresses électroniques. Toutes les adresses électroniques n'ont pas les mêmes possibilités, mais elles sont analysées de la même manière : vous ne savez jamais à quel point les applications qui produisent ces messages sont défectueuses.

Lorsque vous tenterez de créer des structures non autorisées pour un certain type de champ, vous serez averti.

RFC5322 a autorisé les groupes d'adresses pour les champs "To" et "Cc", mais pas pour les champs "From" et "Sender". Cette restriction a été levée par RFC6854 (2013). https://www.rfc-editor.org/rfc/rfc6854

SYNOPSIS

 use Mail::Message::Field::AddrList;

 my $field = Mail::Message::Field::AddrList->new;
 my $group = $field->addGroup( name => 'list-id' );
 $group->addAddress( 'name@example.com' );
 $group->addAddress( '"Another Name" <another@example.com>' );

 print $field->asString, "\n";
 # list-id: "name@example.com", "Another Name" <another@example.com>

 my @all_addresses = $field->addresses;
 my $list_id_group = $field->group( 'list-id' );
 my @list_id_addresses = $list_id_group->addresses;

DESCRIPTION

This is a list of addresses. An address list can contain zero or more groups of addresses. Each group can contain zero or more addresses.

Example:

To: John Doe <john@example.com>,
    Jane Smith <jane@example.com>; the-friends
Cc: undisclosed-recipients: ;

In this example, there are three groups of addresses. The first group is named undef and contains two addresses. The second group is named the-friends and contains no addresses. The third group is named Cc and contains no addresses.

The header fields of type Mail::Message::Field::AddrList are:

Cc
From
Resent-Cc
Resent-From
Resent-To
Sender
To

DIAGNOSTICS

Warning: Field content is not numerical: $content
The numeric value of a field is requested (for instance the "Lines" or "Content-Length" fields should be numerical), however the data contains weird characters. Cast by toInt()
Error: Field name too long (max $length), in '$name'
It is not specified in the RFCs how long a field name can be, but at least it should be a few characters shorter than the line wrap. Cast by fold()
Warning: Illegal character in charset '$charset'
The field is created with an utf8 string which only contains data from the specified character set. However, that character set can never be a valid name because it contains characters which are not permitted. Cast by encode()
Warning: Illegal character in field name $name
A new field is being created which does contain characters not permitted by the RFCs. Using this field in messages may break other e-mail clients or transfer agents, and therefore mutulate or extinguish your message. Cast by consume()
Warning: Illegal character in language '$lang'
The field is created with data which is specified to be in a certain language, however, the name of the language cannot be valid: it contains characters which are not permitted by the RFCs. Cast by encode()
Warning: Illegal encoding '$encoding', used 'q'
The RFCs only permit base64 ("b " or "B ") or quoted-printable ("q" or "Q") encoding. Other than these four options are illegal. Cast by encode()
Error: No attributes for address fields.
Is is not possible to add attributes to address fields: it is not permitted by the RFCs. Cast by addAttribute()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()

Mail::Message::Field::Addresses(3pm) - Perl

NAME

Mail::Message::Field::Addresses - represent a list of addresses

INHERITANCE

Mail::Message::Field::Addresses is a subclass of Mail::Message::Field.

SYNOPSIS

 use Mail::Message::Field::Addresses;
 use Mail::Address;

 # Create from a string
 my $addresses= Mail::Message::Field::Addresses->new(
     'X-Mailer: MyMailer<>'
 );
 print $addresses->as_string;
 # => X-Mailer: MyMailer<>

 # Create from a list of Mail::Address objects
 my @addrs= (
     Mail::Address->new('sender@example.com'),
     Mail::Address->new('To: Recipient <recipient@example.org>')
 );
 my $rcpt= Mail::Message::Field::Addresses->new(
     Field => 'To',
     Value => \@addrs
 );
 print $rcpt->as_string;
 # => To: sender@example.com, Recipient <recipient@example.org>

 # Access the addresses
 my $first_address= $rcpt->[0];
 print $first_address->full_name; # => Recipient
 print $first_address->email;    # => recipient@example.org

DESCRIPTION

This class implements the message header fields that contain lists of addresses, like To, Cc, Bcc, From, Reply-To, etc.

It inherits from Mail::Message::Field and extends it with methods to parse and represent the list of addresses.

The field value is parsed into a list of Mail::Address objects. This list is directly accessible via array-like operations on the Mail::Message::Field::Addresses object.

OVERLOADED

Mail::Message::Field::Addresses overloads the following operators:

[]
Array dereferencing, to access the list of Mail::Address objects. For example, $field->[0] returns the first address.
"scalar"
Returns the number of addresses in the list.

METHODS

See Mail::Message::Field for the methods inherited from the parent class.

add( $address )
Add a Mail::Address object or a string that can be parsed into one. Returns the added address.
append( $address )
Same as add().
email_list()
Returns a comma-separated string of the email addresses. Example: "sender@example.com, recipient@example.org".
parse( $string )
Parse the given string into a list of Mail::Address objects. This method is called by new().

DETAILS

The parser used is Mail::Address. The behaviour of the parser dictates how complex address strings are interpreted.

DIAGNOSTICS

The methods will croak on error, e.g. when Mail::Address->parse() fails.
