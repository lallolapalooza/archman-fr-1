HÉRITAGE

  est une Mail::Box
  est une Mail::Reporter

DIAGNOSTICS

Attention : Modifications non écrites dans le dossier en lecture seule $self.
Vous avez ouvert le dossier en lecture seule - ce qui est la valeur par défaut définie par new(access) -, effectué des modifications, et souhaitez maintenant le fermer. Définissez close(force) si vous souhaitez outrepasser le mode d'accès, ou fermez le dossier avec close(write) défini sur "NEVER". Appel par close()
Erreur : Copie échouée pour un message.
Pour une raison quelconque, par exemple disque plein, suppression par un processus externe, ou protection en lecture, il est impossible de copier un des messages. La copie se poursuivra pour les autres messages. Appel par copyTo()
Erreur : Le dossier de destination $name n'est pas accessible en écriture.
Le dossier vers lequel les messages sont copiés n'est pas ouvert en accès en écriture (voir new(access)). Ceci n'a pas de relation avec la permission d'écriture du dossier, qui est contrôlée par votre système d'exploitation. Appel par copyTo()
Attention : Différents messages avec l'ID $msgid
L'ID du message est découvert plus d'une fois dans le même dossier, mais le contenu du message semble être différent. Cela ne devrait pas être possible : chaque message doit être unique. Appel par messageId()
Erreur : Le dossier $name est ouvert en lecture seule
Vous ne pouvez pas écrire dans ce dossier à moins de l'avoir ouvert en écriture ou en ajout avec new(access), ou que l'option "force" soit définie sur "true". Appel par write()
Erreur : Le dossier $name n'a pas été supprimé : non accessible en écriture.
Le dossier doit être ouvert en accès en écriture via new(access), sinon sa suppression sera refusée. Ainsi, vous pouvez avoir la permission d'écriture selon le système d'exploitation, mais cela ne signifie pas automatiquement que cette méthode "delete" vous le permet. La remarque inverse est également valable. Appel par delete()
Erreur : Période de temps '$timespan' non valide spécifiée.
La chaîne ne respecte pas les règles strictes de la syntaxe de la période de temps autorisée en tant que paramètre. Appel par timespan2seconds()
Attention : L'ID de message '$msgid' ne contient pas de domaine.
Conformément aux RFC, les IDs de message doivent contenir une partie aléatoire unique, puis un "@", et enfin un nom de domaine. Ceci est fait pour éviter la création de deux messages avec le même ID. L'avertissement apparaît lorsque le "@" est manquant dans la chaîne. Appel par messageId()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode alors qu'il le devrait. Ce message signifie que d'autres classes liées implémentent cette méthode, mais pas la classe en question. Vous devriez probablement enquêter et peut-être informer l'auteur du paquet. Appel par notImplemented()
Erreur : Impossible de créer le sous-dossier $name de $folder.
La copie inclut les sous-dossiers, mais pour une raison quelconque, il n'a pas été possible d'en copier un. La copie se poursuivra pour tous les autres sous-dossiers. Appel par copyTo()
Erreur : Écriture du dossier $name a échoué
Pour une raison quelconque (vous avez probablement reçu d'autres messages d'erreur concernant ce problème), il est impossible d'écrire le dossier, bien que vous devriez le pouvoir car des modifications ont été apportées. Appel par write()
