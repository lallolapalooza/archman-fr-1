NAME

Mail::Message::Head::SpamGroup - champs d'en-tête liés à la lutte contre le spam

INHERITANCE

Mail::Message::Head::SpamGroup
  est une Mail::Message::Head::FieldGroup
  est une Mail::Reporter

SYNOPSIS

my $sg = Mail::Message::Head::SpamGroup->new(head => $head, ...);
$head->addSpamGroup($sg);
my $sg = $head->addSpamGroup( <options> );
$sg->delete;
my @sgs = $head->spamGroups;

DESCRIPTION

Un groupe de spam est un ensemble de champs d'en-tête qui sont ajoutés par un logiciel de détection et de lutte contre le spam. Cette classe connaît divers détails concernant ce logiciel.

Étendu de la description dans Mail::Message::Head::FieldGroup.

$any->fighter($name, %options)
Obtient les configurations d'un certain spam-fighter, éventuellement après les avoir définies. La méthode knownFighters() renvoie les noms définis. Les noms sont sensibles à la casse.

Les %options sont toutes celles passées comme configurations au spamfilter, sauf celles spécifiées ici spécifiquement.

-Option --Défaut
 fields   <requis>
 isspam   <requis>
 version  undef
fields => REGEXP
L'expression régulière indiquant quels champs d'en-tête sont ajoutés par le logiciel de détection et de lutte contre le spam.
isspam => COD
Le COD doit renvoyer "true" ou "false", pour indiquer si le spamfighter pense que le message contient du spam. Le COD ref est appelé avec l'objet spamgroup (en cours de construction) et l'en-tête inspecté.
version => COD
Peut être appelé pour collecter le nom officiel et la version du logiciel utilisé pour détecter le spam. Le COD ref est appelé avec l'objet spamgroup (en cours de construction) et l'en-tête inspecté.

» exemple : ajouter vos propres définitions de spam-fighter

Mail::Message::Head::SpamGroup->fighter( 'MY-OWN',
   fields => qw/^x-MY-SPAM-DETECTOR-/,
   isspam => sub { my ($sg, $head) = @_; $head->fields > 100 },
);
$obj->from($head|$message, %options)
Renvoie une liste d'objets "Mail::Message::Head::SpamGroup", basée sur le $message ou l'$head spécifié. Améliore la base, voir les constructeurs dans Mail::Message::Head::FieldGroup 
-Option --Défaut
 types   undef
types => ARRAY-OF-NAMES
Seuls les types spécifiés seront testés. Si le TABLEAU est vide, une liste vide est renvoyée. Sans cette option, tous les groupes sont renvoyés.
$any->habeasSweFieldsCorrect( [$message|$head] )
Renvoie une valeur "true" si le $message ou $head contient des en-têtes "Habeas-SWE" corrects. Sans argument, est utilisé comme méthode d'instance sur un Spam-Group existant.

» exemple : vérifier les en-têtes Habeas-SWE

if(Mail::Message::Head::SpamGroup->habeasSweFieldsCorrect($message))
{   $message->label(spam => 0);
}
my $sg = $message->head->spamGroups('Habeas-SWE');
if($sg->habeasSweFieldsCorrect) { ... };
use List::Util 'first';
if(first {$_->habeasSweFieldsCorrect} $head->spamGroups)
{   ...
}

Renvoie une liste non ordonnée de tous les noms représentant des spam-fighters prédéfinis. Vous pouvez demander des détails à leur sujet, et enregistrer d'autres fighters avec la méthode fighter().

$obj->spamDetected( [BOOLEAN] )
Renvoie (après établissement) si ce groupe d'en-têtes de spam pense que c'est du spam. Voir Mail::Message::Head::Complete::spamDetected().

» exemple :

die if $head->spamDetected;
foreach my $sg ($head->spamGroups)
{   print $sg->type." found spam\n" if $sg->spamDetected;
}
