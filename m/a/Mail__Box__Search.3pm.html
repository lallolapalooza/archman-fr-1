NOM

Mail::Box::Search - sélectionner des messages dans une boîte aux lettres

HÉRITAGE

Mail::Box::Search
  est un Mail::Reporter
Mail::Box::Search est étendu par
  Mail::Box::Search::Grep
  Mail::Box::Search::SpamAssassin
  Mail::Server::IMAP4::Search

SYNTAXE

use Mail::Box::Manager;
my $mgr    = Mail::Box::Manager->new;
my $folder = $mgr->open('Inbox');
my $filter = Mail::Box::Search::[quelquechose]->new;
my @msgs   = $filter->search($folder, ...);
if($filter->search($message)) {...}

DESCRIPTION

Cette classe "Mail::Box::Search" est la classe de base pour divers algorithmes d'analyse de messages. Les messages sélectionnés peuvent être étiquetés. Les opérations booléennes sur les messages sont prises en charge.

Recherches actuellement implémentées :

Mail::Box::Search::Grep
Fait correspondre l'en-tête ou le corps à une expression régulière à la manière de "grep" UNIX.
Mail::Box::Search::SpamAssassin
Tente de détecter le spam, en utilisant Mail::SpamAssassin.
Mail::Box::Search::IMAP
Recherche dans un dossier IMAP en utilisant les dossiers spéciaux de l'interface IMAP. EN COURS DE CONSTRUCTION jusqu'à ce que Mail::Transport::IMAP4 soit terminé.

binaries => BOULEEN
Indique s'il faut inclure les corps binaires dans la recherche.
decode => BOULEEN
Décode les messages avant que la recherche n'ait lieu. Même les messages en texte brut peuvent être encodés, par exemple en "quoted-printable", ce qui peut perturber les résultats. Cependant, le décodage ralentira la recherche.
delayed => BOULEEN
Inclut les messages retardés (qui seront analysés) dans la recherche. Si vous définissez ceci sur "faux", vous pourriez trouver moins de correspondances.
deleted => BOULEEN
Dans la plupart des cas, vous ne serez pas intéressé par les résultats trouvés dans les messages marqués pour suppression. Cependant, avec cette option, vous pouvez spécifier que vous voulez qu'ils soient également recherchés.
deliver => undef|CODE|'DELETE'
La fonctionnalité exacte de ce paramètre diffère selon la méthode de recherche, lisez donc la page de manuel applicable. Dans tous les cas, "undef" signifie que les détails ne sont pas collectés pour cette recherche, ce qui est la recherche la plus rapide.

"DELETE" marquera le message comme étant destiné à la suppression. Vous pouvez également spécifier votre propre référence CODE. Avec une référence à un tableau, les informations sur les correspondances sont collectées sous forme de liste de hachages, un hachage par correspondance.

in => 'HEAD'|'BODY'|'MESSAGE'
Où chercher la correspondance.
label => $label
Marque tous les messages sélectionnés avec l'étiquette spécifiée. Si ce champ n'est pas spécifié, le message n'aura pas d'étiquette ; search() renvoie également une LISTE des messages sélectionnés.
limit => $nombre
Limite la recherche au $nombre de messages spécifié. Lorsque le $nombre est positif, la recherche commence au premier message du dossier ou du fil de discussion. Un $nombre négatif commence à la fin du dossier. Si la limite est définie à zéro, il n'y a pas de limite.
log => NIVEAU
logical => 'REPLACE'|'AND'|'OR'|'NOT'|'AND NOT'|'OR NOT'
Applicable uniquement en combinaison avec une "label". Comment gérer les étiquettes existantes. Dans le cas de "REPLACE", les messages qui portent déjà l'étiquette sont retirés de leur sélection (sauf s'ils correspondent à nouveau). Avec "AND", le message doit être sélectionné par cette recherche et porter déjà l'étiquette, sinon l'étiquette ne sera pas définie. Spécifiez "OR" pour que les messages nouvellement sélectionnés soient ajoutés à l'ensemble des messages déjà sélectionnés.

"NOT" est "vrai" pour les messages qui ne remplissent pas la recherche. La sortie détaillée contiendra toujours les endroits où la correspondance a été trouvée, mais ces messages formeront l'ensemble complémentaire des messages qui seront étiquetés et renvoyés.

multiparts => BOULEEN
Les multiparts doivent-ils être inclus dans les résultats de la recherche ? Certains MUA ont des problèmes pour gérer les détails reçus de la recherche. Lorsque ce drapeau est désactivé, le corps des multiparts sera ignoré. La recherche des parties inclura le préambule et l'épilogue.
trace => NIVEAU

NOM

$obj->inBody($part, $body)
Teste si le corps contient l'information demandée. Voir les paramètres spécifiques du module de recherche.
$obj->inHead($part, $head)
Teste si l'en-tête contient l'information demandée. Voir les paramètres spécifiques du module de recherche.
$obj->search($folder|$thread|$message|ARRAY)
Vérifie quels messages du $folder (Mail::Box) correspondent aux paramètres de recherche. Les messages correspondants sont retournés sous forme de liste. Vous pouvez également spécifier un $thread (un Mail::Box::Thread::Node), un message unique $message (un Mail::Message), ou un "ARRAY" de messages.

Parfois, nous savons que nous n'avons besoin que d'une correspondance. Dans ce cas, la recherche s'arrêtera à la première correspondance trouvée. Par exemple, lorsque "limit" est -1 ou 1, ou lorsque la recherche est effectuée dans un contexte scalaire.

» exemple:

my $grep = Mail::Box::Search::Grep->new(
  match   => 'My Name Is Nobody',
  deliver => 'PRINT'
);
$grep->search($folder);
my $message = $folder->message(3);
$grep->search($message);
my $thread  = $message->threadStart;
$grep->search($thread);
$obj->searchPart($part)
Recherche dans cette partie du message $part des correspondances.

DIAGNOSTICS

Erreur : Impossible de rechercher dans le corps.
L'objet de recherche n'implémente pas inBody() et ne peut donc pas rechercher dans le corps d'un message. Créé par new().
Erreur : Impossible de rechercher dans l'en-tête.
L'objet de recherche n'implémente pas inHead() et ne peut donc pas rechercher dans l'en-tête d'un message. Créé par new().
Erreur : Impossible de savoir comment livrer les résultats via $way.
Les résultats de la recherche ne peuvent pas être livrés via la méthode spécifique, car il s'agit d'une alternative non définie. Créé par new().
Erreur : Le paquet $package n'implémente pas $method.
Erreur_FATALE : Le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où il le devrait. Ce message signifie que d'autres classes liées implémentent également cette méthode, mais pas la classe en question. Vous devriez probablement enquêter sur cela et probablement signaler l'auteur du paquet. Créé par notImplemented().
Erreur : La recherche dans BODY, HEAD ou MESSAGE n'est pas $in.
Le paramètre "in" définit seulement trois noms. Créé par new().
