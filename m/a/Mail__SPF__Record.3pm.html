Mail::SPF::Record(3) Documentation Perl fournie par l'utilisateur Mail::SPF::Record(3)

NOM

Mail::SPF::Record - Classe de base abstraite pour les enregistrements SPF

VERSION

version 3.20250505

SYNOPIS

Créer un enregistrement à partir d'une chaîne

use Mail::SPF::v1::Record;
my $record = Mail::SPF::v1::Record->new_from_string("v=spf1 a mx -all");

Créer un enregistrement synthétiquement

use Mail::SPF::v2::Record;
my $record = Mail::SPF::v2::Record->new(
    scopes      => ['mfrom', 'pra'],
    terms       => [
        Mail::SPF::Mech::A->new(),
        Mail::SPF::Mech::MX->new(),
        Mail::SPF::Mech::All->new(qualifier => '-')
    ],
    global_mods => [
        Mail::SPF::Mod::Exp->new(domain_spec => 'spf-exp.example.com')
    ]
);

DESCRIPTION

Mail::SPF::Record est une classe de base abstraite pour les enregistrements SPF. Elle ne peut pas être instanciée directement. Créez une instance d'une sous-classe concrète à la place.

Constructeur

Les constructeurs suivants sont fournis :

new(%options): retourne Mail::SPF::Record
Crée un nouvel objet d'enregistrement SPF.

%options est une liste de paires clé/valeur représentant l'une des options suivantes :

text
Une chaîne indiquant le texte non analysé de l'enregistrement.
scopes
Une référence vers un tableau de chaînes indiquant les portées couvertes par l'enregistrement (voir la description de l'option "scope" du constructeur "new" de Mail::SPF::Request).
terms
Une référence vers un tableau d'objets Mail::SPF::Term (c.-à-d. Mail::SPF::Mech ou Mail::SPF::Mod) qui composent l'enregistrement. Les objets Mail::SPF::GlobalMod ne doivent pas être inclus ici, mais doivent plutôt être spécifiés en utilisant l'option "global_mods".
global_mods
Une référence vers un tableau d'objets Mail::SPF::GlobalMod qui sont des modificateurs globaux de l'enregistrement.
new_from_string($text, %options): retourne Mail::SPF::Record; lance Mail::SPF::ENothingToParse, Mail::SPF::EInvalidRecordVersion, Mail::SPF::ESyntaxError
Crée un nouvel objet d'enregistrement SPF en analysant la chaîne et les options fournies.

Méthodes de classe

Les méthodes de classe suivantes sont fournies :

version_tag_pattern: retourne Regexp
Abstraite. Retourne une expression régulière qui correspond à une balise de version valide.

Cette méthode est abstraite et doit être implémentée par les sous-classes de Mail::SPF::Record.

default_qualifier: retourne chaîne
Retourne le qualificateur par défaut, c'est-à-dire '+'.
results_by_qualifier: retourne hash de chaîne
Retourne une référence vers une table de hachage qui mappe les qualificateurs aux codes de résultat comme suit : 
 Qualificateur | Code de résultat
-----------+-------------
     +     | pass
     -     | fail
     ~     | softfail
     ?     | neutral

Méthodes d'instance

Les méthodes d'instance suivantes sont fournies :

text: retourne chaîne; lance Mail::SPF::ENoUnparsedText
Retourne le texte non analysé de l'enregistrement. Lance une exception Mail::SPF::ENoUnparsedText si l'enregistrement a été créé synthétiquement au lieu d'être analysé, et qu'aucun texte n'a été fourni.
version_tag: retourne chaîne
Abstraite. Retourne la balise de version de l'enregistrement.

Cette méthode est abstraite et doit être implémentée par les sous-classes de Mail::SPF::Record.

scopes: retourne liste de chaîne
Retourne une liste des portées couvertes par l'enregistrement. Voir la description de l'option "scopes" du constructeur "new".
terms: retourne liste de Mail::SPF::Term
Retourne une liste des termes qui composent l'enregistrement, à l'exclusion des modificateurs globaux, qui sont retournés par la méthode "global_mods". Voir la description de l'option "terms" du constructeur "new".
global_mods: retourne liste de Mail::SPF::GlobalMod
Retourne une liste des modificateurs globaux de l'enregistrement, triés par ordre croissant de priorité du modificateur. Voir la description de l'option "global_mods" du constructeur "new".
global_mod($mod_name): retourne Mail::SPF::GlobalMod
Retourne le modificateur global du nom donné s'il est présent dans l'enregistrement. Retourne undef sinon. Utilisez cette méthode si vous souhaitez récupérer un modificateur global spécifique par opposition à tous.
stringify: retourne chaîne
Retourne la balise de version et les termes de l'enregistrement (y compris les modificateurs globaux) formatés en chaîne de caractères. Vous pouvez simplement utiliser un objet Mail::SPF::Record comme chaîne pour le même effet, voir "SURCHARGE".
eval($server, $request): lance Mail::SPF::Result
Évalue l'enregistrement SPF dans le contexte des paramètres de la requête représentés par l'objet Mail::SPF::Request donné. L'objet Mail::SPF::Server donné est utilisé pour effectuer les recherches DNS. Lance un objet Mail::SPF::Result correspondant à l'issue de l'évaluation ; voir Mail::SPF::Result. Voir RFC 4408, 4.6 et 4.7, pour l'algorithme exact utilisé.

SURCHARGE

Si un objet Mail::SPF::Record est utilisé comme une chaîne, la méthode "stringify" est utilisée pour convertir l'objet en une chaîne.
