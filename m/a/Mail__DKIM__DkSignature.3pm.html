Mail__DKIM__DkSignature(3pm)

Paquet: perl-mail-dkim

Licences: PerlArtistic, GPL

Mail::DKIM::DkSignature(3) Documentation Perl contribuée par l'utilisateur Mail::DKIM::DkSignature(3)

NOM

Mail::DKIM::DkSignature - représente un en-tête DomainKeys-Signature

VERSION

version 1.20240923

CONSTRUCTEURS

new()

Crée une nouvelle signature DomainKey à partir de paramètres

my $signature = Mail::DKIM::DkSignature->new(
                    [ Algorithm => 'rsa-sha1', ]
                    [ Signature => $base64, ]
                    [ Method => 'simple', ]
                    [ Domain => 'example.org', ]
                    [ Headers => 'from:subject:date:message-id', ]
                    [ Query => 'dns', ]
                    [ Selector => 'alpha', ]
                    [ Key => $private_key, ]
                );

parse()

Crée une nouvelle signature à partir d'un en-tête DomainKey-Signature

my $sig = Mail::DKIM::DkSignature->parse(
                'DomainKey-Signature: a=rsa-sha1; b=yluiJ7+0=; c=nofws'
          );

Construit une signature en analysant le contenu de l'en-tête DomainKey-Signature fourni. Vous n'êtes pas obligé d'inclure le nom de l'en-tête (c'est-à-dire "DomainKey-Signature:") mais c'est recommandé, afin que le nom de l'en-tête puisse être conservé et retourné de la même manière dans "as_string()".

Remarque : L'entrée de ce constructeur est dans le même format que la sortie de la méthode as_string.

MÉTHODES

as_string()

Convertit l'en-tête de signature sous forme de chaîne de caractères.

print $signature->as_string . "\n";

sorties

DomainKey-Signature: a=rsa-sha1; b=yluiJ7+0=; c=nofws

Comme indiqué dans l'exemple, la méthode as_string peut être utilisée pour générer l'en-tête DomainKey-Signature qui est préfixé à un message signé.

algorithm()

Obtient ou définit le champ algorithme (a=)

L'algorithme utilisé pour générer la signature. La valeur par défaut est "rsa-sha1", une somme de contrôle SHA-1 signée par RSA.

canonicalization()

Obtient ou définit le champ canonicalisation (c=).

$signature->canonicalization('nofws');
$signature->canonicalization('simple');
$method = $signature->canonicalization;

Canonicalisation du message (par défaut "simple"). Cela informe le vérificateur du type de canonicalisation utilisé pour préparer le message à la signature.

domain()

Obtient ou définit le champ domaine (d=).

my $d = $signature->domain;          # obtient la valeur du domaine
$signature->domain('example.org');   # définit la valeur du domaine

Le domaine de l'entité signataire, tel que spécifié dans la signature. C'est le domaine qui sera interrogé pour la clé publique.

headerlist()

Obtient ou définit le champ des en-têtes signés (h=).

$signature->headerlist('a:b:c');
my $headerlist = $signature->headerlist;
my @headers = $signature->headerlist;

Champs d'en-tête signés. Une liste séparée par des deux-points des noms de champs d'en-tête qui identifient les champs d'en-tête présentés à l'algorithme de signature.

En contexte scalaire, la liste des noms de champs d'en-tête sera retournée sous forme d'une seule chaîne, les noms étant joints par des deux-points. En contexte de liste, les noms de champs d'en-tête seront retournés sous forme de liste.

identity()

Obtient l'identité de signature.

my $i = $signature->identity;

Dans les signatures DomainKey, l'identité de signature est la première adresse trouvée dans l'en-tête Sender ou l'en-tête From. Ce champ est rempli par le vérificateur lors du traitement d'une signature DomainKey.

identity_source()

Détermine quel en-tête contenait l'identité.

my $source = $signature->identity_source;

Si le message est en cours de vérification, cette méthode vous indiquera lequel des en-têtes du message a été utilisé pour déterminer l'identité de la signature. Les valeurs possibles sont "header.sender" et "header.from".

protocol()

Obtient ou définit le champ des méthodes de requête (q=).

Une liste séparée par des deux-points des méthodes de requête utilisées pour récupérer la clé publique (par défaut "dns").

selector()

Obtient ou définit le champ sélecteur (s=).

Le sélecteur subdivise l'espace de noms pour la balise "d=" (domaine).

signature()

Obtient ou définit le champ données de signature (b=).

Les données de signature. Les espaces blancs sont automatiquement supprimés de la valeur retournée.

VOIR AUSSI

Mail::DKIM::Signature pour les en-têtes DKIM-Signature
