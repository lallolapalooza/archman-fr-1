Nom

Mail::Message::Field::Unstructured - champ sans structure intelligent

Héritage

Mail::Message::Field::Unstructured
  est une Mail::Message::Field::Full
  est une Mail::Message::Field
  est une Mail::Reporter

SYNTAXE

my $f = Mail::Message::Field::Unstructured->new('Comments', 'hi!');

DESCRIPTION

Les champs sans structure contiennent des informations qui ne sont restreintes d'aucune manière. RFC2822 définit certains champs sans structure, mais par défaut, tous les champs inconnus sont également sans structure. Les éléments comme les attributs et les commentaires n'ont pas de sens pour les champs sans structure, mais le codage, si.

A étendu "DESCRIPTION" dans Mail::Message::Field::Full.

Lorsque le $data est spécifié comme une seule ligne, le contenu est considéré comme correctement (caractère) codé et échappé. Généralement, c'est une ligne telle qu'elle est lue du fichier. Le pliage de la ligne est conservé tel quel.
En cas de plus d'un argument fourni, le second est considéré comme le CORPS. Les attributs et autres éléments spéciaux ne sont pas définis pour les champs sans structure, ils ne sont donc pas valides en tant qu'options. Le CORPS peut être une chaîne unique, un objet unique ou un tableau d'objets. Les objets sont sérialisés (en une liste séparée par des virgules). Chaque élément du CORPS est interprété avec le codage spécifié.
Si le CORPS est vide, la construction de l'objet échoue : "undef" est retourné. Améliore la base, voir "MÉTHODES" dans Mail::Message::Field::Full

DIAGNOSTICS

Avertissement : Les attributs ne sont pas pris en charge pour les champs non structurés
Lancé par new()
Avertissement : Le contenu du champ n'est pas numérique : $content
La valeur numérique d'un champ est requise (par exemple, le champ "Lines" ou "Content-Length"), mais la donnée contient des caractères étranges. Lancé par toInt()
Erreur : Nom de champ trop long (max $length), dans '$name'
La longueur maximale d'un nom de champ n'est pas spécifiée dans les RFC, mais il doit au moins être un peu plus court que la limite de ligne. Lancé par fold()
Avertissement : Caractère illégal dans le jeu de caractères '$charset'
Le champ est créé avec une chaîne utf8 qui ne contient que des données du jeu de caractères spécifié. Cependant, ce jeu de caractères ne peut pas être un nom valide car il contient des caractères non autorisés. Lancé par encode()
Avertissement : Caractère illégal dans le nom de champ $name
Un nouveau champ est créé qui contient des caractères non autorisés par les RFC. L'utilisation de ce champ dans les messages peut casser d'autres clients de messagerie ou des relais, et par conséquent, muter ou éteindre votre message. Lancé par consume()
Avertissement : Encodage illégal '$encoding', utilisé 'q'
Les RFC n'autorisent que le codage base64 ("b" ou "B"), ou quoted-printable ("q" ou "Q"). Quatre autres options sont illégales. Lancé par encode()
Avertissement : Pas d'extras pour les champs non structurés
Lancé par new()
Erreur : Le package $package n'implémente pas $method.
Erreur : La classe $package n'implémente pas $method. Lancé par notImplemented()
