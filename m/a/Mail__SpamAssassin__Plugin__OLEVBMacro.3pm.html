NOM

Mail::SpamAssassin::Plugin::OLEVBMacro - analyse les documents Office à la recherche de preuves de Macros OLE ou d'autres exploits

SYNTAXE

loadplugin Mail::SpamAssassin::Plugin::OLEVBMacro
ifplugin Mail::SpamAssassin::Plugin::OLEVBMacro
  body     OLEMACRO eval:check_olemacro()
  describe OLEMACRO Pièce jointe contenant une macro Office
  body     OLEOBJ eval:check_oleobject()
  describe OLEOBJ Pièce jointe contenant un objet Ole
  body     OLERTF eval:check_olertfobject()
  describe OLERTF Pièce jointe contenant un objet Ole Rtf
  body     OLEMACRO_MALICE eval:check_olemacro_malice()
  describe OLEMACRO_MALICE Macro Office potentiellement malveillante
  body     OLEMACRO_ENCRYPTED eval:check_olemacro_encrypted()
  describe OLEMACRO_ENCRYPTED Contient un document Office crypté
  body     OLEMACRO_RENAME eval:check_olemacro_renamed()
  describe OLEMACRO_RENAME Contient un document Office renommé
  body     OLEMACRO_ZIP_PW eval:check_olemacro_zip_password()
  describe OLEMACRO_ZIP_PW Contient un document Office protégé par mot de passe dans un zip
  body     OLEMACRO_CSV eval:check_olemacro_csv()
  describe OLEMACRO_CSV Détection d'un fichier csv malveillant tentant d'exécuter cmd.exe
  body     OLEMACRO_DOWNLOAD_EXE eval:check_olemacro_download_exe()
  describe OLEMACRO_DOWNLOAD_EXE Détection de code malveillant dans le document Office tentant de télécharger un fichier .exe
  body     OLEMACRO_URI_TARGET eval:check_olemacro_redirect_uri()
  describe OLEMACRO_URI_TARGET URI à l'intérieur d'un document Office
  body     OLEMACRO_MHTML_TARGET eval:check_olemacro_mhtml_uri()
  describe OLEMACRO_MHTML_TARGET URI mhtml exploitable à l'intérieur d'un document Office
endif

DESCRIPTION

Ce plugin détecte les Macros OLE ou d'autres exploits à l'intérieur des documents Office joints aux e-mails. Il peut détecter des documents à l'intérieur de fichiers zip ainsi que des documents cryptés.

EXIGENCES

Ce plugin nécessite les modules Perl Archive::Zip et IO::String.

PREFERENCES UTILISATEUR

Les options suivantes peuvent être utilisées dans les fichiers de configuration globaux ("local.cf") et spécifiques à l'utilisateur ("user_prefs") pour personnaliser la manière dont le module gère les documents joints :

olemacro_num_mime (par défaut : 5)
Configure le nombre maximum de parties MIME correspondantes (pièces jointes) que le plugin analysera.
olemacro_num_zip (par défaut : 8)
Configure le nombre maximum de fichiers correspondants à l'intérieur du zip à analyser. Pour désactiver l'analyse des zip, définissez 0.
olemacro_zip_depth (par défaut : 2)
Profondeur de récursion dans les fichiers zip.
olemacro_extended_scan ( 0 | 1 ) (par défaut : 0)
Analyse tous les fichiers à la recherche de fichiers potentiels de type Office et/ou de macros ; le paramètre "olemacro_skip_exts" sera toujours respecté. Ce paramètre est désactivé par défaut ; cette option n'est nécessaire que pour exécuter la règle "eval:check_olemacro_renamed". Si ce paramètre est activé, envisagez d'ajuster les valeurs pour "olemacro_num_mime" et "olemacro_num_zip" et préparez-vous à une charge CPU plus importante.
olemacro_prefer_contentdisposition ( 0 | 1 ) (par défaut : 1)
Choisissez si le nom de fichier de l'en-tête content-disposition doit être préféré en cas d'ambiguïté lors de la tentative d'obtention du nom de fichier.
olemacro_max_file (par défaut : 1024000)
Limite la quantité d'octets que le plugin décodera et analysera à partir des objets MIME (pièces jointes).
olemacro_exts (par défaut : (?:doc|docx|dot|pot|ppa|pps|ppt|rtf|sldm|xl|xla|xls|xlsx|xlt|xltx|xslb)$)
Définit l'expression régulière insensible à la casse utilisée pour configurer les extensions ciblées par le plugin pour l'analyse des macros.
olemacro_macro_exts (par défaut : (?:docm|dotm|ppam|potm|ppst|ppsm|pptm|sldm|xlm|xlam|xlsb|xlsm|xltm|xps)$)
Définit l'expression régulière insensible à la casse utilisée pour configurer les extensions que le plugin traite comme contenant une macro.
olemacro_skip_exts (par défaut : (?:dotx|potx|ppsx|pptx|sldx)$)
Définit l'expression régulière insensible à la casse utilisée pour configurer les extensions que le plugin doit ignorer complètement ; il s'agit de fichiers garantis sans macro.
olemacro_skip_ctypes (par défaut : ^(?:text\/))
Définit l'expression régulière insensible à la casse utilisée pour configurer les types de contenu que le plugin doit ignorer complètement ; il s'agit de types garantis sans macro.
olemacro_zips (par défaut : (?:zip)$)
Définit l'expression régulière insensible à la casse utilisée pour configurer les extensions que le plugin cible comme fichiers zip ; les fichiers listés dans les configurations ci-dessus sont également testés comme fichiers zip.
olemacro_download_marker (par défaut : (?:cmd(?:\.exe)? \/c ms\^h\^ta ht\^tps?:\/\^\/))
Définit l'expression régulière insensible à la casse utilisée pour faire correspondre le script utilisé pour télécharger des fichiers depuis le document Office.
