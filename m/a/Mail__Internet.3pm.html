NOM

Mail::Internet - manipuler des messages électroniques

SYNTAXIS

use Mail::Internet;
my $msg = Mail::Internet->new(\*STDIN);

DESCRIPTION

Ce paquet implémente la lecture, la création, la manipulation et l'écriture de messages électroniques. Parfois, l'implémentation essaie d'être trop intelligente, mais dans le cas général, elle fonctionne comme prévu.

Si vous écrivez une nouvelle application, vous devriez utiliser la distribution Mail::Box, qui a plus de fonctionnalités et gère mieux les messages selon les RFC. Voir http://perl.overmeer.net/mailbox/. Vous pouvez aussi choisir MIME::Entity, pour avoir au moins un certain support multipart dans votre application.

MÉTHODES

Constructeurs

$obj->dup()
Clone le message entier. L'en-tête et le corps sont profondément copiés : un nouvel objet Mail::Internet est retourné.
$obj->extract(\@lignes)
Extrait l'en-tête et le corps d'un TABLEAU de lignes de message. Nécessite un objet déjà créé avec new(), dont le contenu sera écrasé.
$obj->new( [$arg], [%options] )
Mail::Internet->new( [$arg], [%options] )
$arg est optionnel et peut être un descripteur de fichier (référence GLOB) ou une référence à un tableau. S'il est donné, le nouvel objet sera initialisé avec les en-têtes et le corps de la liste de lignes lues depuis le descripteur de fichier.

Les paramètres Mail::Header::new() %options "Modify", "MailFrom" et "FoldLength" peuvent également être donnés.

-Option--Défaut
 Body    []
 Header  undef
Body => TABLEAU-DE-LIGNES
La valeur de cette option doit être une référence à un tableau contenant les lignes du corps du message. Chaque ligne doit se terminer par "\n" (LF). Si Body est fourni, "Mail::Internet" n'essaiera pas de lire le corps depuis $arg (même s'il est spécifié).
Header => Mail::Header
La valeur de cette option doit être un objet Mail::Header. S'il est donné, "Mail::Internet" n'essaiera pas de lire un en-tête de message depuis $arg, s'il a été spécifié.
$obj->read($fh)
Lit un message depuis le descripteur de fichier $fh dans un objet message existant. Il est recommandé d'utiliser new() avec $fh comme premier argument.

Accesseurs

$obj->body( [$corps] )
Retourne le corps du message. C'est une référence à un tableau. Chaque entrée du tableau représente une ligne du message.

Si $corps est fourni, il peut s'agir d'une référence à un tableau ou d'un tableau, auquel cas le corps sera remplacé. Si une référence est passée, elle est utilisée directement et n'est pas copiée, donc tout changement ultérieur de ce tableau affecte le contenu du corps.

$obj->head()
Retourne l'objet "Mail::Header" qui contient les en-têtes du message actuel.

Traitement du message dans son ensemble

$obj->as_mbox_string( [$deja_echappe] )
Retourne le message sous forme de chaîne au format mbox. $deja_echappe, s'il est vrai, indique que escape_from() a été appelé sur cet objet.
$obj->as_string()
Retourne le message sous forme d'une seule chaîne.
$obj->print( [$fh] )
Imprime l'en-tête, le corps ou le message entier sur le descripteur de fichier $fh. $fd doit être une référence à un GLOB. Si $fh n'est pas donné, la sortie sera envoyée à STDOUT.

Exemple :

$mail->print( \*STDOUT );  # Imprime le message sur STDOUT
$obj->print_body( [$fh] )
Imprime uniquement le corps sur $fh (par défaut STDOUT).
$obj->print_header( [$fh] )
Imprime uniquement l'en-tête sur $fh (par défaut STDOUT).

Traitement de l'en-tête

Beaucoup de ces méthodes ne sont que des enveloppes autour des méthodes fournies par Mail::Header.

$obj->add(PAIRS)
Les PAIRS sont le champ et le contenu du champ. Pour chaque PAIR, Mail::Header::add() est appelé. Tous les champs sont ajoutés après les champs existants. Le dernier ajouté est retourné.
$obj->combine( $tag, [$with] )
Voir Mail::Header::combine().
$obj->delete( $tag, [$tags] )
Supprime tous les champs portant le nom $tag. Mail::Header::delete() effectue le travail.
$obj->fold( [$longueur] )
Voir Mail::Header::fold().
$obj->fold_length( [$tag], [$longueur] )
Voir Mail::Header::fold_length().
$obj->get( $tag, [$tags] )
Dans un contexte de liste, tous les champs portant le nom $tag sont retournés. Dans un contexte scalaire, seul le premier champ correspondant au premier $tag trouvé est retourné. Mail::Header::get() est appelé pour récupérer les données.
$obj->header(\@lignes)
Voir Mail::Header::header().
$obj->replace(PAIRS)
Les PAIRS sont le champ et le contenu du champ. Pour chaque PAIR, Mail::Header::replace() est appelé avec l'index 0. Si un champ $field est déjà dans l'en-tête, il sera supprimé d'abord. Ne spécifiez pas le même nom de champ deux fois.

Traitement du corps

$obj->remove_sig( [$nlines] )
Tente de supprimer une signature utilisateur du corps d'un message. Il le fait en recherchant une ligne égale à '-- ' dans les $nlines dernières lignes du message. Si elle est trouvée, cette ligne et toutes celles qui suivent sont supprimées. Si $nlines n'est pas spécifié, une valeur par défaut de 10 est utilisée. Ce serait plus utile dans les scripts de réponse automatique.
$obj->sign(%options)
Ajoute votre signature au corps. remove_sig() supprimera d'abord les signatures existantes. 
-Option--Défaut
 File       undef
 Signature  []
File => DÉSCRIPTEUR_FICHIER
Prend de la ligne de fichier $DÉSCRIPTEUR_FICHIER toutes les lignes à partir du premier "--".
Signature => CHAÎNE|TABLEAU-DE-LIGNES
$obj->tidy_body()
Supprime toutes les lignes au début et à la fin du corps qui ne contiennent que des espaces blancs.

Fonctionnalité de haut niveau

$obj->escape_from()
Peut causer des problèmes dans certaines applications si un message contient une ligne commençant par `From ', en particulier lors de la division d'un dossier. Cette méthode insère un "`" au début de toute ligne correspondant au motif d'expression régulière "/^"*From/>
$obj->nntppost( [%options] )
Publie un article via NNTP. Nécessite que Net::NNTP soit installé. 
-Option--Défaut
 Debug   <faux>
 Host    <requis>
 Port    119

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

>
Debug => BOOLEAN
Valeur de débogage à passer à Net::NNTP, voir Net::NNTP
Host => NOM_HOTE|Objet Net::NNTP
Nom du serveur NNTP auquel se connecter, ou un objet Net::NNTP à utiliser.
Port => ENTIER
Numéro de port auquel se connecter sur l'hôte distant
$obj->reply(%options)
Crée un nouvel objet avec l'en-tête initialisé pour une réponse à l'objet courant. Le corps sera une copie du message courant indenté.

Le fichier ".mailhdr" dans votre répertoire personnel (s'il existe) sera lu en premier, pour fournir des valeurs par défaut.

-Option  --Défaut
 Exclude   []
 Indent    '>'
 Keep      []
 ReplyAll  false
Exclude => TABLEAU-DE-CHAMPS
Supprime les CHAMPS listés du message produit.
Indent => CHAÎNE
Utilisé comme chaîne d'indentation. La chaîne peut contenir "%%" pour obtenir un seul "%", %f pour obtenir le prénom, %F est la première lettre de %f, %l est le nom de famille, %L sa première lettre, %n la chaîne complète de l'expéditeur, et %I la première lettre de chaque nom dans la chaîne de l'expéditeur.
Keep => TABLEAU-DE-CHAMPS
Copie les CHAMPS listés du message original.
ReplyAll => BOOLEAN
Inclut automatiquement toutes les adresses To et Cc du courrier original, en excluant celles mentionnées dans la liste Bcc.
$obj->send( [$type, [$args...]] )
Envoie un message Mail::Internet en utilisant Mail::Mailer. $type et $args sont passés à Mail::Mailer::new().
$obj->smtpsend( [%options] )
Envoie un message Mail::Internet en utilisant SMTP direct aux ADRESSES données, chacune pouvant être une chaîne ou une référence à une liste d'adresses e-mail. Si aucun des champs "To", <Cc> ou "Bcc" n'est donné, alors les adresses sont extraites du message envoyé.

La valeur de retour sera une liste d'adresses e-mail auxquelles le message a été envoyé. Si le message n'a pas été envoyé, la liste sera vide.

Nécessite que Net::SMTP et Net::Domain soient installés.

-Option  --Défaut
 Bcc       undef
 Cc        undef
 Debug     <false>
 Hello     localhost.localdomain
 Host      $ENV{SMTPHOSTS}
 MailFrom  Mail::Util::mailaddress()
 Port      25
 To        undef
Bcc => ADRESSES
Cc => ADRESSES
Debug => BOOLEAN
Valeur de débogage à passer à Net::SMTP, voir <Net::SMTP>
Hello => CHAÎNE
Envoie une commande HELO (ou EHLO) au serveur avec le nom donné.
Host => NOM_HOTE
Nom du serveur SMTP auquel se connecter, ou un objet Net::SMTP à utiliser.

Si "Host" n'est pas donné, alors l'hôte SMTP est trouvé en tentant de se connecter d'abord aux hôtes spécifiés dans $ENV{SMTPHOSTS}, une liste séparée par des deux-points, puis "mailhost" et "localhost".

MailFrom => ADRESSE
L'adresse e-mail utilisée comme expéditeur. Par défaut, Mail::Util::mailaddress() fournit l'adresse de l'expéditeur.
Port => ENTIER
Numéro de port auquel se connecter sur l'hôte distant
To => ADRESSES
$obj->unescape_from(())
Supprime l'échappement ajouté par escape_from().
