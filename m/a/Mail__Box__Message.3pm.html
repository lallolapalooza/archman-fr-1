NOM

Mail::Box::Message - gérer un message dans un dossier de courrier

HIÉRARCHIE

Mail::Box::Message
  est un Mail::Message
  est un Mail::Reporter
Mail::Box::Message est étendu par
  Mail::Box::Dir::Message
  Mail::Box::File::Message
  Mail::Box::Message::Destructed
  Mail::Box::Net::Message

SYNTAXE

# Généralement, ces objets message sont créés indirectement
use Mail::Box::Manager;
my $manager = Mail::Box::Manager->new;
my $folder  = $manager->open(folder => 'Mail/Drafts');
my $msg     = $folder->message(1);
$msg->delete;
$msg->size;   # et bien plus encore

DESCRIPTION

Ces pages décrivent uniquement les méthodes relatives aux dossiers. Si vous accédez aux connaissances d'un message, lisez Mail::Message.

Au cours de sa vie, un message passera par différentes étapes. Ces étapes ont été introduites pour réduire le temps d'accès au dossier. En changeant d'étape, les objets de l'en-tête et du corps du message peuvent changer.

$obj->copyTo($folder, %options)
Copier le message dans le $folder ouvert indiqué, sans supprimer l'original. Le message converti (le clone dans le dossier de destination) est retourné. 
-Option      --Défaut
 shallow       false
 shallow_body  false
 shallow_head  false
 share         false
shallow => BOOLEAN
Utilisé pour clone(shallow).
shallow_body => BOOLEAN
Utilisé pour clone(shallow_body).
shallow_head => BOOLEAN
Utilisé pour clone(shallow_head).
share => BOOLEAN
Essayer de partager le stockage physique du message entre les deux dossiers. Parfois, ils peuvent même être de types différents. Lorsque ce n'est pas possible, ces options seront ignorées silencieusement.

» exemple :

my $draft = $mgr->open(folder => 'Draft');
$message->copyTo($draft, share => 1);

$obj->moveTo($folder, %options)
Déplace le message de ce dossier vers le $folder spécifié. Ceci créera d'abord une copie à l'aide de clone(). Ensuite, ce message original sera marqué pour être supprimé. Ainsi, jusqu'à ce que le dossier source soit fermé, deux copies du message peuvent rester en mémoire.

La nouvelle copie du message créée (faisant partie du dossier de destination) est renvoyée. Toutes les %options sont passées à copyTo()

-Option      --Default
 shallow_body  undef
 share         <true sauf si shallow_body existe>
shallow_body => BOOLEAN
Crée uniquement un corps superficiel, ce qui signifie que l'en-tête ne peut pas être réutilisé. Un message ne peut donc pas être partagé dans le stockage sauf indication contraire.
share => BOOLEAN
Lorsqu'il y a une possibilité que le message original puisse être restauré, alors ceci doit être défini sur "false". Sinon, une copie superficielle sera faite, qui partagera l'en-tête qui peut être modifié dans le message restauré.

» exemple : de déplacement d'un message

my $trash = Mail::Box::Mbox->new(folder => 'trash');
my $t = $msg->moveTo($trash);

est équivalent à

my $t = $msg->copyTo($trash, share => 1);

$obj->destruct()
Supprime la majeure partie de la mémoire occupée par le message en détachant l'en-tête et le corps. Ensuite, l'objet se transforme en Mail::Box::Message::Destructed qui interceptera toutes les tentatives d'accès à l'en-tête et au corps. Soyez prudent avec l'utilisation de cette méthode. Améliore la base, voir "Cleanup" dans Mail::Message

DIAGNOSTICS

Erreur: impossible de convertir un objet $class en objet $class
Effectuée par coerce()
Erreur: impossible d'inclure la source d'envoi comme $include.
Valeurs inconnues pour l'option d'inclusion (forward(include)). Les valeurs valides sont "NO", "INLINE", "ATTACH", et "ENCAPSULATE". Effectuée par forward()
Erreur: impossible d'inclure la source de réponse comme $include.
Valeurs inconnues pour l'option d'inclusion (include) de reply(). Les valeurs valides sont "NO", "INLINE", et "ATTACH". Effectuée par reply()
Erreur: la méthode bounce requiert To, Cc, ou Bcc.
La méthode bounce() envoie un message reçu à quelqu'un d'autre sans modification ; vous devez spécifier sa nouvelle destination. Si vous ne voulez pas spécifier de destination, vous cherchez probablement reply(). Si vous voulez modifier le contenu, utilisez forward(). Effectuée par bounce()
Erreur: la méthode forwardAttach requiert un prélude.
Effectuée par forwardAttach()
Erreur: la méthode forwardEncapsulate requiert un prélude.
Effectuée par forwardEncapsulate()
Erreur: aucune adresse pour créer l'envoi en transfert.
Si un message en transfert est créé, une adresse de destination doit être spécifiée. Effectuée par forward()
Erreur: aucun transporteur par défaut trouvé pour envoyer le message.
Le mécanisme send() n'avait pas assez d'informations pour trouver automatiquement un agent de transport pour envoyer ce message. Spécifiez un transporteur explicitement en utilisant l'option "via". Effectuée par send()
Erreur: aucune règle de reconstruction $name définie.
Effectuée par rebuild()
Erreur: uniquement build() de Mail::Message ; ceci n'est pas encore dans un dossier.
Vous pourriez vouloir construire un message pour le stocker dans une sorte de dossier, mais cela doit se faire en deux étapes. D'abord, créez un message normal de Mail::Message, puis ajoutez le message au dossier. Pendant ce processus Mail::Box::addMessage(), le message sera coerce()-d au type de message correct, ajoutant les informations de stockage et autres. Effectuée par build()
Erreur: le paquet $package n'implémente pas $method.
Une erreur fatale : le paquet spécifié (ou l'une de ses superclasses) n'implémente pas cette méthode là où il le devrait. Ce message signifie que d'autres classes liées implémentent cette méthode, mais pas la classe en question. Vous devriez probablement enquêter sur cela et probablement signaler à l'auteur du paquet. Effectuée par notImplemented()
Erreur: le cast commence avec un objet.
Effectuée par coerce()
