NOM

Mail::Message::Dummy - un espace réservé pour des messages manquants

HEREDITE

Mail::Message::Dummy
  est un Mail::Message
  est un Mail::Reporter

SYNOPSIS

DESCRIPTION

Les messages factices (dummy) sont utilisés par les modules qui maintiennent des listes ordonnées de messages, généralement basées sur l'ID du message. Un bon exemple est Mail::Box::Thread::Manager, qui détecte les messages liés en analysant les en-têtes des messages connus pour leurs références à d'autres messages. Tant que les messages référencés ne sont pas trouvés dans la boîte aux lettres, leur place est occupée par un espace réservé.

Soyez prudent lorsque vous utilisez des modules qui peuvent créer des messages factices. Avant d'essayer d'accéder à l'en-tête ou au corps, utilisez isDummy() pour vérifier si le message est un message factice.

DIAGNOSTICS

Erreur : Impossible de coercer un objet $class en un objet $class
Causé par coerce()
Erreur : Impossible d'inclure la source forward comme $include.
Valeur inconnue pour le paramètre forward(include). Les options valides sont "NO", "INLINE", "ATTACH" et "ENCAPSULATE". Causé par forward()
Erreur : Impossible d'inclure la source reply comme $include.
Valeur inconnue pour le paramètre include de reply(). Les options valides sont "NO", "INLINE" et "ATTACH". Causé par reply()
Erreur : Un message-Id est requis pour un dummy.
Un message dummy remplace un message réel. Lors de la création d'un message dummy, l'identifiant du message qu'il remplace doit être connu. Causé par new()
Erreur : La méthode bounce requiert To, Cc ou Bcc
La méthode bounce() renvoie un message reçu à quelqu'un d'autre sans modification ; sa nouvelle destination doit être spécifiée. Si aucune destination n'est spécifiée, vous cherchez probablement reply(). Lorsque vous souhaitez modifier le contenu, utilisez forward(). Causé par bounce()
Erreur : La méthode forwardAttach requiert un préambule
Causé par forwardAttach()
Erreur : La méthode forwardEncapsulate requiert un préambule
Causé par forwardEncapsulate()
Erreur : Aucune adresse pour créer le forward à.
Si un message de type forward est créé, une adresse de destination doit être spécifiée. Causé par forward()
Erreur : Impossible de trouver le Mailer par défaut pour envoyer le message.
Le mécanisme d'envoi send() n'avait pas assez d'informations pour trouver automatiquement un agent d'envoi. Spécifiez un Mailer explicitement en utilisant l'option "via". Causé par send()
Erreur : Aucune règle de reconstruction $name définie.
Causé par rebuild()
Erreur : Seulement build() de Mail::Message; vous n'êtes pas encore dans un dossier
Voulez-vous construire un message pour le stocker dans un type de dossier ? Vous devez le faire en deux étapes. Premièrement, créez un message normal de Mail::Message, et ajoutez-le ensuite au dossier. Durant ce processus Mail::Box::addMessage(), le message sera coerce() en type correct, ajoutant les informations de stockage et autres. Causé par build()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifié (ou l'une de ses superclasses) n'implémente pas cette méthode là où il le devrait. Cela signifie que d'autres classes apparentées implémentent cette méthode, mais la classe en question ne le fait pas. Vous devriez probablement enquêter sur cela et probablement informer l'auteur du paquet. Causé par notImplemented()
Erreur : Impossible de prendre le head/body d'un message dummy
Les messages dummy sont des placeholders dans les fils de discussion : le fil de discussion a détecté l'existence du message, car il a trouvé le message-id dans le champ Reply-To ou References, mais il n'avait pas encore trouvé l'en-tête et le corps du message. Utilisez isDummy() pour savoir si le nœud du fil de discussion a retourné un dummy ou non. Causé par head()
