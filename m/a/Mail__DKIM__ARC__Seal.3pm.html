Mail::DKIM::ARC::Seal - représente un en-tête ARC-Seal

VERSION

version 1.20240923

CREATEURS

new() - crée une nouvelle signature à partir des paramètres

my $signature = Mail::DKIM::ARC::Seal->new(
                    [ Algorithm => 'rsa-sha256', ]
                    [ Signature => $base64, ]
                    [ Domain => 'example.org', ]
                    [ Instance => 1, ]
                    [ Chain => 'none', ] # none|fail|pass
                    [ Query => 'dns', ]
                    [ Selector => 'alpha', ]
                    [ Timestamp => time(), ]
                    [ Expiration => time() + 86400, ]
                );

Le ARC-Seal est similaire à une signature DKIM mais avec les changements suivants :

https://tools.ietf.org/html/draft-ietf-dmarc-arc-protocol-06

5.1.1.1. Balises dans la valeur du champ d'en-tête ARC-Seal

Les balises suivantes sont les seules balises prises en charge pour un champ
ARC-Seal. Elles DOIVENT toutes être présentes. Les balises inconnues DOIVENT
être ignorées et n'affectent pas la validité de l'en-tête.
o  a = algorithme de hachage ; la syntaxe est la même que la balise "a=" définie
   à la Section 3.5 de [RFC6376] ;
o  b = signature numérique ; la syntaxe est la même que la balise "b=" définie
   à la Section 3.5 de [RFC6376] ;
o  cv = statut de validation de la chaîne : valeurs valides :
   *  'none' = aucune chaîne préexistante ;
   *  'fail' = la chaîne telle que reçue ne valide pas ou ne peut pas valider ; ou
   *  'pass' = chaîne valide reçue.
o  d = domaine pour la clé ; la syntaxe est la même que la balise "d=" définie
   à la Section 3.5 de [RFC6376] ;
o  i = "instance" ou numéro de séquence ; incrémenté monotonically à chaque
   entité "scellant", commençant par '1', voir la Section 5.1.1.1.1 concernant la
   plage valide
o  s = sélecteur pour la clé ; la syntaxe est la même que la balise "s=" définie
   à la Section 3.5 de [RFC6376] ;
o  t = horodatage ; la syntaxe est la même que la balise "t=" définie à la
   Section 3.5 de [RFC6376].

chain() - obtient ou définit le paramètre de chaîne (cv=)

Cela doit être l'une des valeurs "pass", "fail" ou "none". Pour qu'une chaîne soit valide, le tout premier sceau (i=1) DOIT être cv=none, et tous les sceaux suivants DOIVENT être cv=pass.

instance() - obtient ou définit le champ d'instance de signature (i=)

my $i = $signature->instance;

Les instances doivent être des entiers inférieurs à 1024 selon la spécification.
