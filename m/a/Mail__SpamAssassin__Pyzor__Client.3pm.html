NOM

Mail::SpamAssassin::Pyzor::Client - Logique du client Pyzor

SYNOPSIS

use Mail::SpamAssassin::Pyzor::Client ();
use Mail::SpamAssassin::Pyzor::Digest ();
my $client = Mail::SpamAssassin::Pyzor::Client->new();
my $digest = Mail::SpamAssassin::Pyzor::Digest::get( $msg );
my $check_ref = $client->check($digest);
die $check_ref->{'Diag'} if $check_ref->{'Code'} ne '200';
my $report_ref = $client->report($digest);
die $report_ref->{'Diag'} if $report_ref->{'Code'} ne '200';

DESCRIPTION

Un client Pyzor http://pyzor.org basique qui n'implémente actuellement que les fonctionnalités nécessaires pour Mail::SpamAssassin.

DÉTAILS DU PROTOCOLE

Le protocole Pyzor n'est pas un standard publié, et il semble qu'il n'y ait pas de documentation publique significative. Ce qui suit est suffisamment d'informations, largement glanées à partir de posts de forums et d'ingénierie inverse, pour faciliter une utilisation efficace de ce module :

Pyzor est un protocole orienté RPC, basé sur des messages. Chaque message est un simple dictionnaire de clés et de valeurs ASCII 7 bits. Les réponses du serveur incluent toujours au moins les éléments suivants :

  • "Code" - Similaire aux codes de statut HTTP ; tout ce qui n'est pas 200 est une erreur.
  • "Diag" - Similaire aux raisons de statut HTTP : une description textuelle du statut.

(NB : Il existe des en-têtes de réponse standard supplémentaires qui ne sont utiles que pour le protocole lui-même et ne font donc pas partie des retours de ce module.)

Fiabilité

Pyzor utilise UDP plutôt que TCP, donc aucun message n'est garanti d'atteindre sa destination. Une erreur de transmission peut survenir dans la requête ou la réponse ; dans les deux cas, une erreur de délai d'attente en résultera. Ces erreurs sont représentées par des instances lancées de Mail::Pyzor::X::Timeout.

CONSTRUCTEUR

new(%OPTS)

Crée un nouveau client pyzor.

Entrée
%OPTS sont (toutes optionnelles) :
  • "server_host" - L'hôte du serveur pyzor à connecter (par défaut "public.pyzor.org")
  • "server_port" - Le port du serveur pyzor à connecter (par défaut 24441)
  • "username" - Le nom d'utilisateur à présenter au serveur pyzor (par défaut "anonymous")
  • "password" - Le mot de passe à présenter au serveur pyzor (par défaut vide)
  • "timeout" - Le temps maximum, en secondes, à attendre pour une réponse du serveur pyzor (par défaut 3.5)
Sortie
Retourne un objet Mail::SpamAssassin::Pyzor::Client.

MÉTHODES DE REQUÊTE

report($digest)

Signale le résumé d'un message de spam au serveur pyzor. Cette fonction lancera une exception en cas d'échec de messagerie ou de délai d'attente.

Entrée
$digest "SCALAR"
Le résumé du message à signaler, tel que donné par Mail::SpamAssassin::Pyzor::Digest::get().
Sortie
"HASHREF"
Retourne une référence de hachage des attributs standard notés ci-dessus.

check($digest)

Vérifie le résumé d'un message pour voir si le serveur pyzor a un rapport pour celui-ci. Cette fonction lancera une exception en cas d'échec de messagerie ou de délai d'attente.

Entrée
$digest "SCALAR"
Le résumé du message à vérifier, tel que donné par Mail::SpamAssassin::Pyzor::Digest::get().
Sortie
"HASHREF"
Retourne une référence de hachage des attributs standard notés ci-dessus, ainsi que les éléments suivants :
  • "Count" - Le nombre de rapports que le serveur a reçus pour le résumé donné.
  • "WL-Count" - Le nombre de demandes de liste blanche que le serveur a reçues pour le résumé donné.
