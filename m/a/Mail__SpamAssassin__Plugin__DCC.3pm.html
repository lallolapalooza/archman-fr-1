NOM

Mail::SpamAssassin::Plugin::DCC - effectuer la vérification DCC des messages

SYNTAXE

loadplugin Mail::SpamAssassin::Plugin::DCC
full DCC_CHECK        eval:check_dcc()
full DCC_CHECK_50_79  eval:check_dcc_reputation_range('50','79')

DESCRIPTION

Le DCC ou Distributed Checksum Clearinghouse est un système de serveurs qui compilent et comptent les valeurs de checksum de milliers de messages électroniques. Les valeurs peuvent être utilisées par SpamAssassin pour détecter et filtrer les spams.

Voir https://www.dcc-servers.net/dcc/ pour plus d'informations sur DCC.

Note : DCC est désactivé par défaut dans "v310.pre" car son utilisation nécessite un logiciel qui n'est pas distribué avec SpamAssassin et qui a des restrictions de licence pour certaines utilisations commerciales. Voir la licence DCC sur https://www.dcc-servers.net/dcc/LICENSE pour les détails.

Activez-le en décommentant "loadplugin Mail::SpamAssassin::Plugin::DCC" dans confdir/v310.pre ou en utilisant la ligne suivante dans votre local.pre. Il peut également être nécessaire d'installer un paquet, port, rpm, ou équivalent de votre fournisseur de système d'exploitation ou un tarball de source primaire sur https://www.dcc-servers.net/dcc/#download. Voir aussi https://www.dcc-servers.net/dcc/INSTALL.html

BALISES

Les balises suivantes sont ajoutées à l'ensemble, disponibles pour utilisation dans les rapports, en-têtes, autres plugins, etc. :

_DCCB_    ID du serveur DCC dans le champ d'en-tête X-DCC-*-Metrics
_DCCR_    corps de X-DCC-*-Metrics
_DCCREP_  Réputation DCC ou pourcentage de spam reçu depuis
            logiciel DCC commercial

PARAMÈTRES UTILISATEUR

use_dcc (0|1) (par défaut: 1)
Utiliser DCC si disponible ?
use_dcc_rep (0|1) (par défaut: 1)
Utiliser la fonction de réputation commerciale de DCC si disponible ? Notez que les données de réputation sont gratuites depuis la version 2.x de DCC, où elles sont automatiquement utilisées.
dcc_body_max NOMBRE
dcc_fuz1_max NOMBRE
dcc_fuz2_max NOMBRE
Définir depuis combien de temps le corps du message/fuz1/fuz2 doit avoir été signalé avant que SpamAssassin ne considère la vérification DCC comme effectuée. 999999 est la valeur pour beaucoup.

La valeur par défaut est 999999 pour toutes ces options.

dcc_rep_percent NOMBRE
Seul le logiciel DCC commercial fournit les réputations DCC (mais depuis la version 2.x, elles sont utilisées pour tous). Une réputation DCC est le pourcentage de spam reçu depuis le dernier relais non fiable sur le chemin du message, tel que mesuré par toutes les installations DCC commerciales. Voir http://www.rhyolite.com/dcc/reputations.html. Vous devriez mettre en liste blanche vos relais de confiance ou MX dans /var/dcc/whiteclnt comme décrit sur la page principale de DCC afin d'éviter que vos propres MX ne soient considérés comme des sources de spam. Voir https://www.dcc-servers.net/dcc/dcc-tree/dcc.html#White-and-Blacklists. La valeur par défaut est 90.

PARAMÈTRES ADMINISTRATEUR

dcc_timeout n (par défaut: 5)
Combien de temps attendre pour que DCC se termine avant de continuer sans résultats. Une valeur numérique peut avoir une unité de temps (s, m, h, d, w, indiquant secondes (par défaut), minutes, heures, jours, semaines).
dcc_home CHAÎNE
Cette option indique à SpamAssassin où trouver le répertoire de données de DCC. S'il n'est pas spécifié, il essaie d'utiliser le répertoire local configuré avec la commande "cdcc homedir". Il essaie /var/dcc si cette commande échoue.
dcc_dccifd_path CHAÎNE
Cette option indique à SpamAssassin où trouver le socket de dccifd au lieu d'un socket local dans "dcc_home" nommé "dccifd". Si un socket est spécifié ou trouvé, utilisez cet emplacement à la place de "dccproc".

S'il est spécifié, "dcc_dccifd_path" est le chemin absolu du socket local ou un socket INET spécifié sous la forme "[Host]:Port" ou "Host:Port". L'hôte peut être une adresse IPv4 ou IPv6 ou un nom d'hôte. Le port est un numéro de port TCP. Les crochets sont obligatoires pour une adresse IPv6.

La valeur par défaut est "undef".

dcc_path CHAÎNE
Où trouver le client "dccproc" au lieu de compter sur SpamAssassin pour le trouver dans le répertoire courant ou dans "dcc_home/bin". Ceci doit souvent être configuré, car le répertoire courant est nettoyé par le mode taint dans l'interpréteur Perl.

S'il est trouvé un socket "dccifd" dans "dcc_home" ou s'il est explicitement spécifié avec "dcc_dccifd_path", utiliser l'interface dccifd(8) à la place de "dccproc".

La valeur par défaut est "undef".

dcc_options options
Définir des options supplémentaires pour la commande dccproc(8). Seuls les caractères dans la plage [0-9A-Za-z ,._/-] sont autorisés pour des raisons de sécurité.

La valeur par défaut est "undef".

dccifd_options options
Définir des options supplémentaires à envoyer à dccifd via le protocole ASCII décrit sur la page dccifd(8). Seuls les caractères dans la plage [0-9A-Za-z ,._/-] sont autorisés pour des raisons de sécurité.

La valeur par défaut est "undef".

dcc_learn_score n (par défaut: undef)
Signaler les messages avec des scores totaux supérieurs au seuil de spam de SpamAssassin à DCC comme étant du spam.
