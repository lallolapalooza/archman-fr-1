NOM

Mail::Message::Body::Lines - corps d'un message stocké comme un tableau de lignes

HÉRITAGE

Mail::Message::Body::Lines
  est une Mail::Message::Body
  est une Mail::Reporter

SYNOPSIS

Voir Mail::Message::Body

DESCRIPTION

Le corps (le contenu) d'un message peut être stocké sous diverses formes. Dans cette page de manuel, la fonctionnalité supplémentaire que vous avez lorsque vous stockez un message dans un tableau de lignes est décrite.

Stocker un message entier comme un tableau de lignes est utile lorsque les données ne sont pas codées et que vous souhaitez les traiter ligne par ligne (une pratique courante pour l'inspection des corps de messages).

DIAGNOSTICS

Avertissement : Le jeu de caractères $name est inconnu
L'encodage ou le décodage du corps d'un message rencontre un jeu de caractères qui n'est pas compris par le module Encode de Perl. Lancé par encode()
Avertissement : Content-Transfer-Encoding `$encoding' nécessite un jeu de caractères explicite, par défaut utf-8
Lancé par encode()
Avertissement : Aucun décodeur défini pour le codage de transfert $name.
Les données (corps du message) sont encodées d'une manière qui n'est pas actuellement comprise, par conséquent aucun décodage (ou recodage) ne peut avoir lieu. Lancé par encode()
Avertissement : Aucun encodeur défini pour le codage de transfert $name.
Les données (corps du message) ont été décodées, mais l'encodage requis est inconnu. Les données décodées sont retournées. Lancé par encode()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où il le devrait. Ce message signifie que d'autres classes liées implémentent cette méthode, mais pas la classe en question. Vous devriez probablement enquêter sur cela et probablement en informer l'auteur du paquet. Lancé par notImplemented()
Erreur : Impossible de lire le fichier $filename pour les lignes du corps du message : $!
Un objet Mail::Message::Body::Lines doit être créé à partir d'un fichier nommé, mais il est impossible de lire ce fichier pour récupérer les lignes qu'il contient. Lancé par new()
Avertissement : Terminateur de ligne inconnu $eol ignoré
Lancé par eol()
