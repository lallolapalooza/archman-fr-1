Mail::Server(3) Documentation Perl fournie par l'utilisateur Mail::Server(3)

NOM

Mail::Server - Classe de base pour les serveurs d'e-mails dans MailBox

HIÉRARCHIE

Mail::Server
  est un Mail::Reporter
Mail::Server est étendu par
  Mail::Server::IMAP4

SYNOPSIS

my $server = Mail::Server::IMAP4->new($msg);
my $server = Mail::Server::POP3->new($msg);

DESCRIPTION

Ce module est un espace réservé, logique dans la hiérarchie des classes. Pour l'instant, aucun serveur complet n'a été implémenté, mais certaines parties de IMAP4 existent.

Serveurs :

•
Mail::Server::IMAP4

Implémentation partielle d'IMAP4.

Étendu la section "DESCRIPTION" de Mail::Reporter.

Étendu la section "METHODS" de Mail::Reporter.
