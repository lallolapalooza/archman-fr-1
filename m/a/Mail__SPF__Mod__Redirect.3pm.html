Mail::SPF::Mod::Redirect(3) Documentation Perl fournie par l'utilisateur Mail::SPF::Mod::Redirect(3)

NOM

Mail::SPF::Mod::Redirect - classe de modificateur "redirect" de l'enregistrement SPF

VERSION

version 3.20250505

DESCRIPTION

Un objet de la classe Mail::SPF::Mod::Redirect représente un modificateur d'enregistrement SPF de type "redirect".

Constructeurs

Les constructeurs suivants sont fournis :

new(%options): retourne Mail::SPF::Mod::Redirect
Crée un nouvel objet modificateur SPF "redirect".

%options est une liste de paires clé/valeur représentant n'importe laquelle des options suivantes :

domain_spec
Voir "new" dans Mail::SPF::Mod.
new_from_string($text, %options): retourne Mail::SPF::Mod::Redirect; lance Mail::SPF::ENothingToParse, Mail::SPF::EInvalidMod
Crée un nouvel objet modificateur SPF "redirect" en analysant la chaîne et les options fournies.

Méthodes de classe

Les méthodes de classe suivantes sont fournies :

name: retourne chaîne
Retourne 'redirect'.
name_pattern: retourne Regexp
Retourne une expression régulière qui correspond au nom du modificateur 'redirect'.
precedence: retourne nombre réel
Retourne une valeur de précédence de 0.8. Voir "precedence" dans Mail::SPF::Mod.

Méthodes d'instance

Les méthodes d'instance suivantes sont fournies :

params
Voir "params" dans Mail::SPF::Mod.
domain_spec: retourne Mail::SPF::MacroString
Retourne le paramètre "domain-spec" du modificateur.
process($server, $request, $result): lance Mail::SPF::Result
Si aucun mécanisme n'a correspondu lors de l'évaluation de l'enregistrement SPF actuel, effectue une vérification SPF récursive à l'aide des objets serveur SPF et de requête donnés et en substituant le nom du domaine cible du modificateur au domaine d'autorité de la requête. Le résultat de la vérification SPF récursive est ensuite lancé comme résultat de l'évaluation de l'enregistrement actuel. Cependant, si le domaine cible n'a pas d'enregistrement SPF acceptable, un résultat "permerror" est lancé. Voir RFC 4408, 6.1, pour les détails.

Voir Mail::SPF::Mod pour les autres méthodes d'instance prises en charge.
