Mail__DKIM__ARC__MessageSignature(3pm)

Paquet: perl-mail-dkim

Mail::DKIM::ARC::MessageSignature(3) Documentation Perl fournie par l'utilisateur Mail::DKIM::ARC::MessageSignature(3)

NOM

Mail::DKIM::ARC::MessageSignature - Sous-classe de Mail::DKIM::Signature représentant un en-tête ARC-Message-Signature

VERSION

version 1.20240923

CONSTRUCTEURS

new() - crée une nouvelle signature à partir de paramètres

my $signature = Mail::DKIM::ARC::MessageSignature->new(
                    [ Algorithm => 'rsa-sha256', ]
                    [ Signature => $base64, ]
                    [ Method => 'relaxed', ]
                    [ Domain => 'example.org', ]
                    [ Instance => 1, ]
                    [ Headers => 'from:subject:date:message-id', ]
                    [ Query => 'dns', ]
                    [ Selector => 'alpha', ]
                    [ Timestamp => time(), ]
                    [ Expiration => time() + 86400, ]
                );

Les seules différences entre ce module et Mail::DKIM::Signature sont le nom de l'en-tête et le fait que 'instance' est un entier plutôt qu'une valeur encodée en base64.

instance() - obtient ou définit l'instance de signature (champ i=)

my $i = $signature->instance;

Les instances doivent être des entiers inférieurs à 1024 selon la spécification.

NOTE : le champ i= est "Identity" dans DKIM et est une valeur base64, mais dans ARC c'est "Instance" et un entier. La routine d'analyse ne vérifie pas que la valeur i= est un nombre.

VOIR AUSSI

Mail::DKIM::Signature pour les en-têtes DKIM-Signature
