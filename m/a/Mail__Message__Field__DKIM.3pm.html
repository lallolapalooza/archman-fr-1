NOM

Mail::Message::Field::DKIM - champ d'en-tête de message pour les signatures DKIM

HERITAGE

Mail::Message::Field::DKIM
  est un Mail::Message::Field::Structured
  est un Mail::Message::Field::Full
  est un Mail::Message::Field
  est un Mail::Reporter

SYNOPSIS

my $f = Mail::Message::Field->new('DKIM-Signature' => '...');
my $g = Mail::Message::Field->new('DKIM-Signature');
$g->add...

DESCRIPTION

Décode les informations contenues dans un en-tête DKIM. Vous pouvez également construire des en-têtes DKIM-Signature de cette manière. Cependant, la vérification et la signature ne sont pas encore implémentées.

Cette implémentation est basée sur la RFC6376.

DIAGNOSTICS

Avertissement : le contenu du champ n'est pas numérique : $content
La valeur numérique d'un champ est demandée (par exemple, la valeur de "Lines" ou "Content-Length" doit être numérique), mais le contenu contient des caractères étranges. Converti par toInt()
Erreur : Nom de champ trop long (max $length), dans '$name'
Il est spécifié comment le nom d'un champ peut être long dans les RFCs, mais il devrait au moins être un peu plus court que la limite de ligne. Converti par fold()
Avertissement : Caractère illégal dans le jeu de caractères '$charset'
Le champ a été créé avec une chaîne utf8 ne contenant que des données du jeu de caractères spécifié. Cependant, ce jeu de caractères ne peut pas être valide car il contient des caractères qui ne sont pas autorisés. Converti par encode()
Avertissement : Caractère illégal dans le nom de champ $name
Un nouveau champ est créé qui contient des caractères non autorisés par les RFCs. L'utilisation de ce champ dans les messages peut casser d'autres clients de messagerie ou transferts et donc muter ou éteindre votre message. Converti par consume()
Avertissement : Caractère illégal dans la langue '$lang'
Le champ a été créé avec des données spécifiées pour être dans une langue donnée, mais le nom de la langue ne peut pas être valide : il contient des caractères non autorisés par les RFCs. Converti par encode()
Avertissement : Encodage illégal '$encoding', utilisé 'q'
Les RFCs n'autorisent que l'encodage base64 ("b " ou "B ") ou quoted-printable ("q" ou "Q"). Les autres options sont illégales. Converti par encode()
Erreur : Pas d'attributs pour les en-têtes DKIM
Il n'est pas possible d'ajouter d'attributs à ce champ. Converti par setAttribute()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifié (ou l'une de ses superclasses) n'implémente pas cette méthode alors qu'il devrait. Ce message signifie que certaines autres classes liées implémentent cette méthode, mais pas la classe en question. Vous devriez probablement enquêter là-dessus et probablement signaler l'auteur du paquet. Converti par notImplemented()
