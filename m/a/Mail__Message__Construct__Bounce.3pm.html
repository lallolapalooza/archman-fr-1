NOM

Mail::Message::Construct::Bounce - renvoyer un Mail::Message

SYNTAXE

$message->bounce(To => 'you')->send;

DESCRIPTION

Les fonctionnalités complexes des objets Mail::Message sont implémentées dans différents fichiers qui sont chargés à la demande. Ce fichier implémente la fonctionnalité liée au renvoi de messages vers d'autres destinations.

Attention : le renvoi de messages était une pratique très courante par le passé, mais elle ne fonctionne pas bien avec la protection anti-spam SPF. À moins que vous ne renvoyiez des messages provenant de votre propre infrastructure, vous risquez de voir le message rejeté par les filtres anti-spam des destinataires. La solution consiste à implémenter ARC... ce que la suite MailBox n'a pas essayé (pas encore).

MÉTHODES

Construction d'un message

$obj->bounce( [<$rg_object|%options>] )
Le programme appelant cette méthode se considère comme une étape intermédiaire dans le processus de livraison du message ; il laisse donc un groupe réexpédié de champs d'en-tête comme trace.

Lorsqu'un message est reçu, l'agent de transfert de courrier (MTA) ajoute un champ "Received" à l'en-tête. En tant que %options, vous pouvez spécifier des lignes qui sont ajoutées au groupe réexpédié de ce champ reçu. "Resent-*" est automatiquement préfixé aux noms de champs, sauf s'ils sont déjà présents.

Vous pouvez également spécifier un objet Mail::Message::Head::ResentGroup (RG) instancié. Voir Mail::Message::Head::ResentGroup::new() pour les options disponibles. Ceci est requis si vous souhaitez ajouter un nouveau groupe réexpédié : créez également une nouvelle ligne "Received" dans l'en-tête.

Si vous prévoyez de modifier le corps d'un message de rebond, ne le faites pas ! Les messages de rebond ont le même message-id que le message original, et par conséquent devraient avoir le même contenu (les message-ids sont universellement uniques). Si vous insistez, utilisez Mail::Message::body().

» exemple :

my $bounce = $folder->message(3)->bounce(To => 'you', Bcc => 'everyone');
$bounce->send;
$outbox->addMessage($bounce);
my $rg     = Mail::Message::Head::ResentGroup->new(To => 'you',
   Received => 'from ... by ...');
$msg->bounce($rg)->send;

DIAGNOSTICS

Erreur : la méthode bounce nécessite To, Cc, ou Bcc
La méthode bounce() du message transmet un message reçu à quelqu'un d'autre sans modification ; vous devez spécifier sa nouvelle destination. Si vous avez l'envie de ne pas spécifier de destination, vous cherchez probablement reply(). Lorsque vous souhaitez modifier le contenu, utilisez forward(). Causé par bounce()
