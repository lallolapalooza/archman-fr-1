Nom

Mail::Message::Field::Attribute - un attribut d'un champ complet

Héritage

Mail::Message::Field::Attribute
  est un Mail::Reporter

Synopsis

my $field    = $msg->head->get('Content-Disposition') or return;
my $full     = $field->study;   # analyse complète en unicode
my $filename = $full->attribute('filename')           or return;
print ref $filename;     # ce nom de classe
print $filename;         # le contenu des attributs en utf-8
print $filename->value;  # identique
print $filename->string; # imprimer tel que trouvé dans le fichier
$filename->print(\*OUT); # imprimer tel que trouvé dans le fichier

Description

Les attributs dans les champs MIME peuvent être assez complexes, et donc potentiellement lents et gourmands en mémoire. Les modules Mail::Message::Field::Fast et Mail::Message::Field::Flex simplifient considérablement les attributs, ce qui peut entraîner un comportement erroné dans de rares cas. Avec l'augmentation des langues non occidentales sur Internet, le besoin de concernant les en-têtes complexes devient plus pressant.

Un "Mail::Message::Field::Attribute" peut être trouvé dans n'importe quel champ structuré de Mail::Message::Field::Full.

Étendu de la section "DESCRIPTION" dans Mail::Reporter.

SURCHARGE

surcharge : `` chaîne
Retourne le contenu décodé de l'attribut.
surcharge : cmp comparaison de chaîne
Si le second argument est un champ, alors le nom de l'attribut (sensible à la casse) et la valeur décodée doivent être égaux. Sinon, la valeur est comparée.

Constructeurs

Étendu de la section "Constructors" dans Mail::Reporter.

$class->new( <$name, [$value] | STRING>, %options )
Crée un nouvel attribut $name avec le $value optionnel. Si $value n'est pas spécifié, le premier argument de cette méthode est examiné pour voir s'il contient un signe égal '='. Si ce caractère est présent, l'argument est considéré comme une "STRING", contenant un attribut pré-formaté qui est ensuite analysé. Sinon, l'argument est considéré comme un nom sans valeur $value : la valeur sera définie plus tard par value().

Le type d'encodage appliqué dépend des %options et de la présence de caractères non-ASCII dans le $value. Le $name ne peut contenir que des caractères ASCII, il n'est donc pas encodé.

Pour des raisons de performance, les attributs ne sont pas dérivés de la classe de base Mail::Reporter. Voir les améliorations de base dans Constructors dans Mail::Reporter.

-Option           --Défini dans     --Valeur par défaut
 charset                             'us-ascii'
 language                            undef
 log                Mail::Reporter   'WARNINGS'
 trace              Mail::Reporter   'WARNINGS'
 use_continuations                   <C<true>>
charset => STRING
La valeur $value est traduite de l'utf-8 (interne de Perl) vers ce jeu de caractères, et la chaîne résultante est ensuite encodée si nécessaire. "us-ascii" est l'encodage normal pour les e-mails. Les noms de jeux de caractères valides peuvent être trouvés avec Encode::encodings(':all').
language => STRING
Le RFC2231 ajoute la possibilité de spécifier une langue avec le champ. Si aucune langue n'est spécifiée, aucune n'est incluse dans l'encodage. Les noms de langue valides sont définis par le RFC2130. Ce module n'a qu'un support limité pour cette fonctionnalité.
log => LEVEL
---
trace => LEVEL
---
use_continuations => BOOLEAN
Les continuations sont utilisées pour diviser les paramètres longs en morceaux ne dépassant pas 76 caractères. Les encodages sont définis dans le RFC2231, mais ne sont pas pris en charge par tous les programmes clients.

» Exemple :

my $fn    = Mail::Message::Field::Attribute->new(filename => 'xyz');
my $fattr = 'Mail::Message::Field::Attribute';  # abréviation
my $fn    = $fattr->new(
  filename => "Re\xC7u",
  charset  => 'iso-8859-15',
  language => 'nl-BE'
);
print $fn;
  # -->  filename*=iso-8859-15'nl-BE'Re%C7u

L'attribut

$obj->addComponent(STRING)
Un composant est un paramètre tel que défini par RFC2045, utilisant optionnellement l'encodage ou les continuations telles que définies par RFC2231. Les composants d'un attribut sont trouvés lors de l'analyse d'un champ. Les RFCs sont très stricts quant aux caractères valides, mais nous ne pouvons pas l'être : vous devez accepter ce qui arrive si vous le pouvez.

» Exemple :

my $param = Mail::Message::Field::Attribute->new;
$param->addComponent("filename*=iso10646'nl-BE'%Re\47u");
$obj->charset()
Retourne le jeu de caractères utilisé pour ce paramètre. Si un composant ajouté contient des informations sur le jeu de caractères, celui-ci est trouvé directement. Il est à noter qu'un jeu de caractères est insensible à la casse.
$obj->language()
Retourne la langue définie dans l'argument. Si aucune langue n'est définie, "undef" est retourné, ce qui doit être interprété comme "ANY".
$obj->name()
Retourne le nom de cet attribut.
$obj->string()
Lorsqu'il est appelé dans un contexte de liste, les lignes sont retournées une par une pour être post-traitées. Dans un contexte scalaire, il retourne la liste formatée de l'attribut.
$obj->value( [STRING] )
Retourne la valeur de ce paramètre, ou

NOM

Mail::Message::Field::Attribute - Interface pour manipuler les champs d'en-tête d'un message

HÉRITAGE

Mail::Message::Field::Attribute hérite de Mail::Message::Field et implémente Mail::Message::Field::List.

SYNOPSIS

    use Mail::Message::Field::Attribute;

    # Créer un attribut
    my $obj = Mail::Message::Field::Attribute->new(name => 'X-My-Header', value => 'some value');

    # Accéder aux valeurs
    my $name  = $obj->name;
    my $value = $obj->value;

    # Modifier les valeurs
    $obj->value('new value');

    # Encoder et décoder
    my $encoded = $obj->encode;
    my $decoded = $obj->decode;

DESCRIPTION

Cette classe fournit une interface pour manipuler les champs d'en-tête de type attribut (comme les en-têtes 'Content-Type', 'Content-Disposition', etc.) d'un message MIME. Elle gère les sous-parties d'un attribut et permet l'encodage/décodage de ces valeurs.

SURGARGÉ

Aucune surcharge de méthode spécifique à cette classe.

MÉTHODES

Attributs getters et setters

$obj->name([$new_name])
Retourne ou définit le nom de l'attribut. Le nom est stocké sans sensibilité à la casse.
$obj->value([$new_value])
Retourne ou définit la valeur principale de l'attribut. La valeur est stockée telle quelle.
$obj->components()
Retourne une liste des composants de l'attribut. Ceci est généralement utilisé pour les attributs complexes comme 'Content-Type' avec ses paramètres.
$obj->addComponent($component)
Ajoute un composant à la liste des composants de l'attribut. Le composant doit être une instance de Mail::Message::Field::Attribute::Component.
$obj->getComponent($name)
Récupère un composant spécifique par son nom.
$obj->removeComponent($name)
Supprime un composant par son nom.

Encodage d'attribut

$obj->decode()
Traduit toutes les continuations connues en une valeur. La valeur produite est retournée et peut être encodée en utf-8 ou être une chaîne de caractères simple.
$obj->encode()
Encode l'attribut et ses composants dans une chaîne de caractères formatée selon les normes RFC. Ceci inclut l'encodage des noms de paramètres et des valeurs si nécessaire. L'encodage est effectué en dernier recours, après avoir éventuellement défini le nom.

Internes

$obj->mergeComponent($attribute)
Fusionne les composants de l'attribut spécifié dans cet attribut. Ceci est nécessaire lorsque les composants du même attribut sont créés séparément. La fusion est requise par l'analyse des champs.

DIAGNOSTICS

Avertissement : Caractère illégal dans le nom du paramètre '$name'
Le nom du paramètre spécifié contient des caractères qui ne sont pas autorisés par les RFC. Il est préférable de changer le nom pour quelque chose qui est accepté, ou de risquer que les applications corrompent ou ignorent le message. Lancé par new()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode alors qu'il le devrait. Ce message signifie que d'autres classes apparentées implémentent cette méthode, mais pas la classe en question. Probablement, vous devriez enquêter et informer l'auteur du paquet. Lancé par notImplemented()
Erreur : Trop tard pour fusionner : la valeur a déjà été modifiée.
Lancé par mergeComponent()
