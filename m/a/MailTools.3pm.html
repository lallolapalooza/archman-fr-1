NOM

MailTools - ensemble d'anciens modules de messagerie

SYNTAXE

# Ceci est un espace réservé pour la distribution

DESCRIPTION

MailTools est un bundle : une ancienne forme de regroupement de paquets en une seule distribution. Heureusement, il peut également être distribué comme s'il s'agissait d'une distribution normale.

Attention : Le code que vous trouverez ici est très ancien. Il fonctionne pour des courriels simples, mais si vous commencez un nouveau projet, veuillez utiliser des bibliothèques plus sophistiquées. La principale raison pour laquelle vous trouvez encore ce code sur CPAN est que de nombreux livres l'utilisent comme exemple.

Composant

Dans cette distribution, vous trouverez

Mail::Address
Analyse les adresses e-mail à partir d'une ligne d'en-tête.
Mail::Cap
Interprète les fichiers mailcap : mappages des types de fichiers aux applications tels qu'utilisés par de nombreux programmes de messagerie en ligne de commande.
Mail::Field
Simplifie l'accès à (certains) champs d'en-tête d'e-mail. Utilisé par Mail::Header.
Mail::Filter
Traite les messages Mail::Internet.
Mail::Header
Collection d'objets Mail::Field, représentant l'en-tête d'un objet Mail::Internet.
Mail::Internet
Représente un seul message e-mail, avec en-tête et corps.
Mail::Mailer
Envoie des e-mails Mail::Internet via smtp direct ou les MTA locaux.
Mail::Send
Construit un objet Mail::Internet, puis l'envoie en utilisant Mail::Mailer.
Mail::Util
Fonctions "intelligentes" sur lesquelles vous ne devriez pas compter.
