MAT_GETVERSION(3) Manuel des fonctions de bibliothèque MAT_GETVERSION(3)

NOM

Mat_GetVersion — Retourne la version d'un fichier MAT MATLAB étant donné une structure de fichier MAT.

SYNTAXE

#include <matio.h>

enum mat_ft
Mat_GetVersion(const mat_t *matfp);

DESCRIPTION

La fonction Mat_GetVersion() retourne la version du fichier MAT MATLAB donné par la structure du fichier MAT.

VALEUR DE RETOUR

La valeur de retour est l'une des suivantes :

  • MAT_FT_MAT4 si le fichier est un fichier MAT version 4.
  • MAT_FT_MAT5 si le fichier est un fichier MAT version 5.
  • MAT_FT_MAT73 si le fichier est un fichier MAT HDF5.

VOIR AUSSI
