NOM

Mail::Message::Field::Fast - une ligne d'un en-tête de message

HERITAGE

Mail::Message::Field::Fast
  est un Mail::Message::Field
  est un Mail::Reporter

SYNOPSIS

Voir Mail::Message::Field

DESCRIPTION

C'est l'implémentation plus rapide, mais moins flexible, d'un champ d'en-tête. Les données sont stockées dans un tableau, et certains hacks sont utilisés pour accélérer les choses. Soyez indulgent avec moi, et considérez que chaque message contient plusieurs de ces lignes, donc la vitesse est très importante ici.

$class->new(($ligne | $nom, $corps, [$attributs]), %options)
Le constructeur de cet objet ne suit pas la pratique habituelle au sein de la suite Mail::Box : il n'utilise pas le constructeur Mail::Reporter::new(). Par conséquent, il n'a pas de fonctions de journalisation ou de suivi.

La méthode peut être utilisée de l'une des manières suivantes :

  • new($ligne, %options)

    Passe une $ligne telle qu'elle pourrait être trouvée dans un fichier : une ligne (éventuellement repliée) qui est terminée par un saut de ligne.

  • new($nom, $corps, [$attributs], %options)

    Un ensemble de valeurs qui façonnent la ligne.

Crée un nouvel objet de champ d'en-tête. Spécifiez toute la $ligne (octets encodés) en une seule fois, et elle sera divisée pour vous. Si vous avez déjà les parties de la ligne d'en-tête, vous pouvez les spécifier séparément en tant que $nom et $corps du champ.

Si vous spécifiez un objet $corps unique, ou un TABLEAU d'objets, ceux-ci sont traités pour devenir appropriés pour remplir un champ, généralement par simple stringification. Lorsque vous spécifiez un ou plusieurs objets Mail::Address, ceux-ci sont transformés en une chaîne en utilisant leur méthode "format". Vous pouvez également ajouter un Mail::Message::Field, dont le corps est utilisé. En cas de tableau, les éléments sont joints en une seule chaîne avec une virgule.

Les $attributs peuvent être exactement une chaîne qui peut contenir plusieurs attributs à la fois, cités et formatés comme requis par RFC2822. Alternativement, une liste de paires clé-valeur peut être utilisée. Dans ce cas, les valeurs seront citées si nécessaire et tout sera formaté comme l'exige le protocole. Améliore la base, voir "Constructeurs" dans Mail::Message::Field

-Option--Défini dans     --Défaut
 log     Mail::Reporter   <désactivé>
 trace   Mail::Reporter   <désactivé>
log => NIVEAU
trace => NIVEAU

» exemple :

my $mime = Mail::Message::Field->new(
  'Content-Type: text/plain; charset=US-ASCII');
my $mime = Mail::Message::Field->new(
  'Content-Type' => 'text/plain; charset=US-ASCII');
my $mime = Mail::Message::Field->new(
  'Content-Type' => 'text/plain', 'charset=US-ASCII');
my $mime = Mail::Message::Field->new(
  'Content-Type' => 'text/plain', charset => 'Latin1');
my $mime = Mail::Message::Field->new(
  To => Mail::Address->new('Mon', 'moi@exemple.com');
my $mime = Mail::Message::Field->new( Cc => [
  Mail::Address->new('Toi', 'toi@exemple.com'),
  Mail::Address->new('Lui', 'lui@exemple.com')
]);

Mais en pratique, vous pouvez simplement appeler

my $head = Mail::Message::Head->new;
$head->add( 'Content-Type' => 'text/plain', charset => 'utf8');

qui appelle implicitement ce constructeur (si nécessaire). Vous pouvez spécifier les mêmes choses pour Mail::Message::Head::Complete::add() que ce que ce "new" accepte.

DIAGNOSTICS

Avertissement: Le contenu du champ n'est pas numérique : $contenu
La valeur numérique d'un champ est demandée (par exemple, les champs "Lines" ou "Content-Length" devraient être numériques), cependant les données contiennent des caractères étranges. Caster par toInt()
Erreur: Nom de champ trop long (max $longueur), dans '$nom'
Il n'est pas spécifié dans les RFC quelle est la longueur maximale d'un nom de champ, mais il devrait au moins être quelques caractères plus court que le retour à la ligne. Caster par fold()
Avertissement: Caractère illégal dans le nom de champ $nom
Un nouveau champ est en cours de création qui contient des caractères non permis par les RFC. L'utilisation de ce champ dans des messages peut endommager d'autres clients de messagerie ou agents de transfert, et donc altérer ou détruire votre message. Caster par consommer()
Erreur: Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où elle devrait. Ce message signifie que d'autres classes apparentées implémentent cette méthode, mais que la classe en question ne le fait pas. Vous devriez probablement enquêter à ce sujet et probablement en informer l'auteur du paquet. Caster par nonImplémenté()
