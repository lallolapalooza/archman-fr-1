NOM

Mail::SPF::SenderIPAddrMech - Classe de base abstraite pour les mécanismes d'enregistrement SPF qui opèrent sur l'adresse IP de l'expéditeur SMTP

VERSION

version 3.20250505

DESCRIPTION

Mail::SPF::SenderIPAddrMech est une classe de base abstraite pour les mécanismes d'enregistrement SPF qui opèrent sur l'adresse IP de l'expéditeur SMTP. Elle ne peut pas être instanciée directement. Créez une instance d'une sous-classe concrète à la place.
