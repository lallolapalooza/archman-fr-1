DESCRIPTION

DIAGNOSTICS

Erreur : Le paquet $package n'implémente pas $méthode.
Erreur fatale : le paquet spécifié (ou une de ses superclasses) n'implémente pas cette méthode là où elle devrait l'être. Ce message indique que d'autres classes apparentées implémentent cette méthode, bien que la classe en question ne le fasse pas. Vous devriez probablement enquêter sur cela et probablement signaler cela à l'auteur du paquet. Appel par notImplemented()
Avertissement : Fin inattendue de l'en-tête dans $source : $line
Pendant l'analyse d'un message provenant de la source spécifiée (généralement un nom de fichier), le parseur a rencontré une erreur de syntaxe. Selon la spécification MIME dans les RFCs, chaque ligne d'en-tête doit contenir un deux-points ou commencer par un espace blanc pour indiquer un champ replacé. Apparemment, cet en-tête contient une ligne qui commence à la première position, mais pas avec un nom de champ.

Par défaut, l'analyse de l'en-tête s'arrêtera. S'il y a d'autres lignes d'en-tête après la ligne erronée, elles seront ajoutées au corps du message. En cas de nouveau(fix_header_errors) défini, l'analyse de l'en-tête continuera. La ligne erronée sera ajoutée au champ précédent. Appel par readHeader()

NAME

Mail::Box::Parser::Lines - generic parser for mail files

INHERITANCE

Mail::Box::Parser::Lines

??? Mail::Box::Parser

SYNOPSIS

  use Mail::Box::Parser::Lines;

  # read a specific file
  my $parser = Mail::Box::Parser::Lines->new(file => 'mail.txt');
  my $box    = $parser->read;

  # read multiple files
  my $parser = Mail::Box::Parser::Lines->new(files => ['mail1.txt', 'mail2.txt']);
  my $box    = $parser->read;

  # create a new mailbox
  my $box = Mail::Box::new();
  # ... add messages ...
  my $parser = Mail::Box::Parser::Lines->new(box => $box);
  $parser->write;

DESCRIPTION

This parser reads a list of files as one mailbox. It is the default parser used by Mail::Box->new() when no specific parser is selected.

The parser can read one or more files, which are then treated as a single mailbox. This is useful for mail files where multiple messages are stored sequentially in a single file, separated by standard mail separators (like From <date> lines).

The parser can also be used to write a mailbox back to disk. By default, it will write all messages into a single file. The filename is taken from the file option passed to new(). If this option is not specified, no writing will happen.

METHODS

new( %arguments )

Creates a new parser object. The following arguments are accepted:

file => $filename

Specifies the file to read from or write to. If this option is given, it will be used for both reading and writing.

files => [ $filename1, $filename2, ... ]

Specifies a list of files to read from. All files are concatenated into a single mailbox.

box => $mailbox

Specifies the mailbox object to read from (if not given via file(s)) or to write to. If not specified, a new empty mailbox is created when reading.

default_date => $date_string

When a message does not have a date header, this string will be used as the default date. The string must be in a format that can be parsed by Mail::Transport::Mailbox::Date::parse. Defaults to the current time.

read()

Reads the messages from the specified file(s) and returns a Mail::Box object.

write()

Writes the messages from the associated Mail::Box object to the specified file. If no file was specified during initialization, this method does nothing.

DIAGNOSTICS

The parser can die with the following messages:

  • Cannot open file "filename" for reading: $!
  • Cannot open file "filename" for writing: $!
  • No file(s) specified to read from.
  • No mailbox object specified to write to.
