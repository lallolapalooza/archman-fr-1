NOM

Mail::SPF::v1::Record - classe d'enregistrement SPFv1

VERSION

version 3.20250505

SYNOPSIS

Voir Mail::SPF::Record.

DESCRIPTION

Un objet de la classe Mail::SPF::v1::Record représente un enregistrement SPFv1 ("v=spf1").

Constructeurs

Les constructeurs suivants sont fournis :

new(%options): retourne Mail::SPF::v1::Record
Crée un nouvel objet d'enregistrement SPFv1.

%options est une liste de paires clé/valeur représentant n'importe laquelle des options suivantes :

text
terms
global_mods
Voir "new" dans Mail::SPF::Record.
scopes
Voir "new" dans Mail::SPF::Record. Comme les enregistrements SPFv1 couvrent toujours implicitement les portées "helo" et "mfrom", cette option doit être exactement ['helo', 'mfrom'] (ou ['mfrom', 'helo']) ou être omise.
new_from_string($text, %options): retourne Mail::SPF::v1::Record; lance Mail::SPF::ENothingToParse, Mail::SPF::EInvalidRecordVersion, Mail::SPF::ESyntaxError
Crée un nouvel objet d'enregistrement SPFv1 en analysant la chaîne et les options fournies.

Méthodes de classe

Les méthodes de classe suivantes sont fournies :

version_tag_pattern: retourne Regexp
Retourne une expression régulière qui correspond à une balise de version de 'v=spf1'.
default_qualifier
results_by_qualifier
Voir "Méthodes de classe" dans Mail::SPF::Record.
