NOM

Mail::SpamAssassin::SQLBasedAddrList - Liste d'adresses basée sur SQL pour SpamAssassin

SYNOPIS

  my $factory = Mail::SpamAssassin::SQLBasedAddrList->new()
  $spamtest->set_persistent_addr_list_factory ($factory);
... appels dans les classes SpamAssassin...

SpamAssassin appellera:

  my $addrlist = $factory->new_checker($spamtest);
  $entry = $addrlist->get_addr_entry ($addr, $origip);
...

DESCRIPTION

Une implémentation de liste d'adresses persistante basée sur SQL.

Voir "Mail::SpamAssassin::PersistentAddrList" pour plus d'informations.

Utilise l'accès au module DBI::DBD à votre base de données préférée (testé avec MySQL, SQLite et PostgreSQL) pour stocker les listes d'adresses auto-bienvenues des utilisateurs.

La structure de table par défaut ressemble à ceci : CREATE TABLE awl (
username varchar(100) NOT NULL default '',
email varchar(255) NOT NULL default '',
ip varchar(40) NOT NULL default '',
msgcount int(11) NOT NULL default '0',
totscore float NOT NULL default '0',
signedby varchar(255) NOT NULL default '',
last_hit timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
PRIMARY KEY (username,email,signedby,ip) ) TYPE=MyISAM;

Votre définition de table peut changer en fonction du pilote de base de données que vous choisissez. Il existe une option de configuration pour remplacer le nom de la table.

Ce module introduit plusieurs nouvelles variables de configuration :

user_awl_dsn

user_awl_sql_username

user_awl_sql_password

user_awl_sql_table

user_awl_sql_override_username

voir "Mail::SpamAssassin::Conf" pour plus d'informations.

new

classe publique (Mail::SpamAssassin::SQLBasedAddrList) new ()

Description : Cette méthode crée une nouvelle instance de l'usine SQLBasedAddrList et appelle la méthode new du parent (PersistentAddrList).

new_checker

instance publique (Mail::SpamAssassin::SQLBasedAddrList) new_checker (\% $main)

Description : Cette méthode est appelée pour configurer une nouvelle interface de vérification et retourner une copie bénie de celle-ci. C'est ici que nous configurons la connexion à la base de données SQL en fonction des valeurs de configuration.

get_addr_entry

instance publique (\%) get_addr_entry (Chaîne $addr, Chaîne $signedby)

Description : Cette méthode prend une $addr donnée et la divise entre le composant adresse e-mail et le composant ip, puis effectue une recherche dans la base de données. Si rien n'est trouvé dans la base de données, un hachage d'entrée vide est créé et renvoyé, sinon une entrée contenant les informations trouvées est renvoyée. Si une option de configuration with_awl_signer est activée, seules les adresses signées par l'identité de signature donnée sont prises en compte, ou, si $signedby est indéfini (ou vide), seules les entrées non signées sont considérées.

Une clé, "exists_p", est définie à 1 si une entrée existe déjà dans la base de données, sinon elle est définie à 0.

add_score

instance publique (\%) add_score (\% $entry, Entier $score)

Description : Cette méthode ajoute un $score donné à une $entry donnée. Si l'entrée était marquée comme n'existant pas dans la base de données, une entrée sera insérée, sinon une simple mise à jour sera effectuée.

NOTE : Ce code utilise un appel SQL auto-référentiel (c'est-à-dire set foo = foo + 1) qui est pris en charge par la plupart des systèmes de gestion de bases de données modernes, mais pas par tout ce qui s'appelle une base de données SQL.

remove_entry

instance publique () remove_entry (\% $entry)

Description : Cette méthode supprime une $entry donnée de la base de données. Si la partie ip de l'adresse de l'entrée est égale à "none", alors supprimez également les entrées perl-IP pour cette adresse.

finish

instance publique () finish ()

Description : Cette méthode fournit le nettoyage nécessaire pour la liste d'adresses.

_unpack_addr

instance privée (Chaîne, Chaîne) _unpack_addr(chaîne $addr)

Description : Cette méthode divise une adresse d'auto-liste d'accueil en ses deux composants, l'adresse e-mail et l'adresse ip.
