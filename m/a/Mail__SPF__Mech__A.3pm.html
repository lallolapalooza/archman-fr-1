Mail::SPF::Mech::A(3) Documentation Perl fournie par l'utilisateur Mail::SPF::Mech::A(3)

NOM

Mail::SPF::Mech::A - classe de mécanisme SPF record "a"

VERSION

version 3.20250505

DESCRIPTION

Un objet de la classe Mail::SPF::Mech::A représente un mécanisme de SPF record de type "a".

Constructeurs

Les constructeurs suivants sont fournis :

new(%options): retourne Mail::SPF::Mech::A
Crée un nouvel objet de mécanisme SPF record "a".

%options est une liste de paires clé/valeur représentant n'importe laquelle des options suivantes :

qualifier
domain_spec
ipv4_prefix_length
ipv6_prefix_length
Voir "new" dans Mail::SPF.
new_from_string($text, %options): retourne Mail::SPF::Mech::A; lance Mail::SPF::ENothingToParse, Mail::SPF::EInvalidMech
Crée un nouvel objet de mécanisme SPF record "a" en analysant la chaîne et les options données.

Méthodes de classe

Les méthodes de classe suivantes sont fournies :

default_qualifier
default_ipv4_prefix_length
default_ipv6_prefix_length
qualifier_pattern
Voir "Méthodes de classe" dans Mail::SPF::Mech.
name: retourne string
Retourne 'a'.
name_pattern: retourne Regexp
Retourne une expression régulière qui correspond à un nom de mécanisme de 'a'.

Méthodes d'instance

Les méthodes d'instance suivantes sont fournies :

text
qualifier
params
stringify
domain
match_in_domain
Voir "Méthodes d'instance" dans Mail::SPF::Mech.
domain_spec: retourne Mail::SPF::MacroString
Retourne le paramètre "domain-spec" du mécanisme.
ipv4_prefix_length: retourne integer
Retourne la longueur du préfixe réseau IPv4 du mécanisme.
ipv6_prefix_length: retourne integer
Retourne la longueur du préfixe réseau IPv6 du mécanisme.
match($server, $request): retourne boolean
Vérifie si le nom de domaine cible du mécanisme (c'est-à-dire l'une de ses adresses hôtes DNS "A" ou "AAAA") correspond à l'adresse IP de la requête donnée (voir "ip_address" dans Mail::SPF::Request), et retourne true si c'est le cas, ou false sinon. Les longueurs de préfixe réseau IP du mécanisme sont respectées lors de la correspondance des enregistrements d'adresse avec l'adresse IP de la requête. Voir RFC 4408, 5, pour l'algorithme exact utilisé.
