NOM

Mail::Box::File::Message - un message dans un dossier Mbox

HIÉRARCHIE

Mail::Box::File::Message
  est un Mail::Box::Message
  est un Mail::Message
  est un Mail::Reporter
Mail::Box::File::Message est étendu par
  Mail::Box::Mbox::Message

SYNOPSIS

my $folder  = new Mail::Box::File folder => $ENV{MAIL}, ...;
my $message = $folder->message(0);

DESCRIPTION

Gère un message dans un dossier basé sur des fichiers, toute extension de Mail::Box::File.

Étendu la section "DESCRIPTION" de Mail::Box::Message.

Beaucoup de gens détestent les dossiers de style fichier car ils stockent les messages dans un seul fichier, où une ligne commençant par "From " précède l'en-tête. Si nous recevons un message d'un dossier basé sur des fichiers, nous stockons cette ligne. Si nous écrivons dans un tel fichier, mais qu'il n'y a pas de telle ligne stockée, alors nous essayons d'en générer une.

Si $line est fourni, alors la ligne de commencement est définie sur cette valeur.

Les dossiers Mbox contiennent plusieurs messages dans un seul fichier, utilisant une ligne de séparation pour les distinguer. Typiquement, ces lignes commencent par "From ". Les lignes à l'intérieur du message pourraient interférer avec cette séparation et devraient donc être traduites.

Cette méthode retournera le texte échappé du corps sous forme de référence.

$obj->ecrire( [$fh] )
Écrit un message sur un descripteur de fichier. Il s'agit du message incluant la ligne 'From ' initiale et le blanc final. La ligne From peut interférer avec les lignes du corps : ces lignes sont échappées avec un '>'. Améliore la base, voir "Le message" dans Mail::Message

» exemple:

$msg->ecrire(\*FICHIER);    # imprime le message avec encapsulage vers FICHIER
$msg->ecrire;            # message avec encapsulage vers descripteur de fichier sélectionné
$msg->imprimer(\*FICHIER);    # le message sans encapsulage.

DIAGNOSTICS

Erreur: Impossible de coercer un objet $class en objet $class
Lancé par coercer()
Erreur: Impossible d'inclure la source de transfert en tant que $inclure.
Alternative inconnue pour le transfert(inclure). Les choix valides sont "NON", "EN_LIGNE", "PJ", et "ENCAPSULER". Lancé par transfert()
Erreur: Impossible d'inclure la source de réponse en tant que $inclure.
Alternative inconnue pour l'option "inclure" de répondre(). Les choix valides sont "NON", "EN_LIGNE", et "PJ". Lancé par répondre()
Erreur: La méthode renvoyer nécessite un À, Cc, ou Cci
La méthode renvoyer() d'un message transfère un message reçu à quelqu'un d'autre sans modification ; vous devez spécifier sa nouvelle destination. Si vous n'avez pas l'envie de spécifier de destination, vous cherchez probablement répondre(). Lorsque vous souhaitez modifier le contenu, utilisez transférer(). Lancé par renvoyer()
Erreur: La méthode transfertPJ nécessite un préambule
Lancé par transfertPJ()
Erreur: La méthode transfertEncapsuler nécessite un préambule
Lancé par transfere
Erreur : Aucune adresse pour créer le transfert.
Si un message de transfert est créé, une adresse de destination doit être spécifiée. Lancé par forward()
Erreur : Aucun expéditeur par défaut trouvé pour envoyer le message.
Le mécanisme send() du message n'avait pas assez d'informations pour trouver automatiquement un agent de transfert de courrier pour envoyer ce message. Spécifiez un expéditeur explicitement en utilisant l'option "via". Lancé par send()
Erreur : Aucune règle de reconstruction $name définie.
Lancé par rebuild()
Erreur : Seuls les objets build() de Mail::Message sont autorisés ; ils ne sont pas encore dans un dossier
Vous pourriez vouloir construire un message à stocker dans une sorte de dossier, mais vous devez le faire en deux étapes. D'abord, créez un objet Mail::Message normal, puis ajoutez-le au dossier. Pendant ce processus de Mail::Box::addMessage(), le message sera coerce()-d vers le type de message approprié, en ajoutant les informations de stockage et autres. Lancé par build()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où elle devrait l'être. Ce message signifie que certaines autres classes liées implémentent cette méthode, mais que la classe en question ne le fait pas. Probablement, vous devriez enquêter sur cela et probablement informer l'auteur du paquet. Lancé par notImplemented()
Erreur : Impossible de lire le corps différé.
Lancé par loadBody()
Erreur : la coercition commence avec un objet
Lancé par coerce()
