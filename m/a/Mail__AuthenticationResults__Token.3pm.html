Mail::AuthenticationResults::Token(3) Documentation Perl fournie par l'utilisateur Mail::AuthenticationResults::Token(3)

NOM

Mail::AuthenticationResults::Token - Classe de base pour la modélisation des parties d'en-tête AuthenticationResults

VERSION

version 2.20250709

DESCRIPTION

Classes représentant un en-tête Authentication Results tokenisé, utilisé pour l'analyse

MÉTHODES

new( $header, $args )

Retourne un nouvel objet Token analysé à partir de la chaîne $header donnée en utilisant $args

La valeur de $args dépend de la sous-classe de Token utilisée, les types possibles sont :

Mail::AuthenticationResults::Token::Assignment un opérateur d'affectation Mail::AuthenticationResults::Token::Comment un commentaire Mail::AuthenticationResults::Token::QuotedString une chaîne entre guillemets Mail::AuthenticationResults::Token::Separator un séparateur Mail::AuthenticationResults::Token::String une chaîne

new_from_value( $value )

Crée un nouveau token à partir de la valeur donnée

value()

Retourne la valeur de l'instance Token actuelle.

remainder()

Retourne le reste de la chaîne d'en-tête après l'analyse du token actuel.

parse()

Exécute l'analyseur sur le $header actuel et configure value() et remainder().

is()

Retourne le type de token que nous sommes.
