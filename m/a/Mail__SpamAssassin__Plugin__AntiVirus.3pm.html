Mail::SpamAssassin::Plugin::AntiVirus(3) Documentation Perl fournie par l'utilisateur Mail::SpamAssassin::Plugin::AntiVirus(3)

NOM

AntiVirus - tests antivirus simples

SYNOPIS

loadplugin     Mail::SpamAssassin::Plugin::AntiVirus
body MICROSOFT_EXECUTABLE eval:check_microsoft_executable()
body MIME_SUSPECT_NAME    eval:check_suspect_name()

DESCRIPTION

La règle MICROSOFT_EXECUTABLE fonctionne en vérifiant 3 possibilités dans le message, dans n'importe quelle partie application/* ou texte/* du message :

- dans les parties texte, recherche une chaîne de début d'exécutable encodée en uu
- dans les parties application, recherche des noms de fichiers se terminant par une extension exécutable
- dans les parties application, recherche une chaîne de début d'exécutable encodée en base64
