NAME Documentation des paquets contribués de Perl Mail::Message::Replace::MailInternet(3)

NAME

Mail::Message::Replace::MailInternet - wrapper pour Mail::Internet

INHERITANCE

Mail::Message::Replace::MailInternet
  est un Mail::Message
  est un Mail::Reporter

SYNOPSIS

# changement
use Mail::Internet;
# à la place de
use Mail::Message::Replace::MailInternet;
# dans le code existant, et le code continuera de fonctionner, mais
# avec les caractéristiques de Mail::Message.

DESCRIPTION

Ce module est un wrapper pour Mail::Message, qui simule un objet Mail::Internet. L'espace de noms de ce module est détourné et de nombreuses méthodes sont ajoutées.

La plupart des méthodes fonctionneront sans changement, mais vous devrez peut-être revoir vos appels à smtpsend() et send().

Alternative inconnue pour le courrier (forward(include)). Les valeurs valides sont "NO", "INLINE", "ATTACH" et "ENCAPSULATE". Lancé avec forward()
Erreur: Mail::Internet ne prend pas en charge ce type de données

La méthode bounce() renvoie un message reçu à un autre sans modifications; vous devez spécifier To, Cc ou Bcc.
Mail::Message::Replace::MailInternet(3pm)

NAME

Mail::Message::Replace::MailInternet - implementations for mail message replacement

INHERITANCE

Mail::Message::Replace
Mail::Message

SYNOPSIS

  use Mail::Message::Replace::MailInternet;

  my $msg = Mail::Message->new();
  $msg->replaceWith( $new_content );
  $msg->replaceWith( $new_message );
  $msg->replaceWith( $new_sender );

DESCRIPTION

This class provides the implementations for the replacement methods defined in the parent class Mail::Message::Replace.

OVERLOADED

The following methods are overloaded:

  <
                
  <<

METHODS

bounce()
Forward the message to a new destination. When you wish to send the message to a new destination, use bounce(). When you wish to modify the content, use forward(). Cast by bounce()
forward()
Forward the message to a new destination. When you wish to send the message to a new destination, use bounce(). When you wish to modify the content, use forward(). Cast by forward()
forwardAttach()
See Mail::Message::Transfer. Cast by forwardAttach()
forwardEncapsulate()
See Mail::Message::Transfer. Cast by forwardEncapsulate()
makeMessage()
Create a new Mail::Message object. This method may be overridden to create a more specific message object. Cast by makeMessage()
replaceWith()
Replace the current message object with a new one. The new message can be a string, a Mail::Message object, or a sender object. Cast by replaceWith()

DETAILS

The following methods are used to replace the content of a message.

build()
Create a new Mail::Message object. This method may be overridden to create a more specific message object. Cast by build()
coerce()
Convert the message into the specific type required by the folder it is added to. Cast by coerce()
forward()
Forward the message to a new destination. If you have the urge not to specify any destination, you probably are looking for reply(). When you wish to modify the content, use forward(). Cast by bounce()

DIAGNOSTICS

Error: Method forwardAttach requires a preamble
Cast by forwardAttach()
Error: Method forwardEncapsulate requires a preamble
Cast by forwardEncapsulate()
Error: No address to create forwarded to.
If a forward message is created, a destination address must be specified. Cast by forward()
Error: No rebuild rule $name defined.
Cast by rebuild()
Error: Only build() Mail::Message's; they are not in a folder yet
You may wish to construct a message to be stored in a some kind of folder, but you need to do that in two steps. First, create a normal Mail::Message, and then add it to the folder. During this Mail::Box::addMessage() process, the message will get coerce()-d into the right message type, adding storage information and the like. Cast by build()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
