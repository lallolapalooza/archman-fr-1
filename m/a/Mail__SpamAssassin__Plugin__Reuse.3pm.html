NOM

Mail::SpamAssassin::Plugin::Reuse - Pour réutiliser les anciens hits de règles lors d'un contrôle de masse

SYNTAXE

loadplugin    Mail::SpamAssassin::Plugin::Reuse
ifplugin      Mail::SpamAssassin::Plugin::Reuse
reuse NETWORK_RULE [ NETWORK_RULE_OLD_NAME ]
run_reuse_tests_only 0/1
endif

DESCRIPTION

Le but de ce plugin est de travailler en conjonction avec mass-check --reuse pour mapper les règles détectées dans les messages d'entrée aux règles détectées dans la sortie du contrôle de masse.

run_reuse_tests_only 1 est une option spéciale pour l'utilisation de spamassassin/spamd. Seuls les tests réutilisables seront exécutés. Il activera également les recherches réseau/DNS. Ceci est principalement destiné au traitement de masse rapide des messages du corpus, afin qu'ils puissent être réutilisés correctement plus tard. Par exemple :
spamd --pre="loadmodule Mail::SpamAssassin::Plugin::Reuse" \
--pre="run_reuse_tests_only 1" ... Un tel spamd dédié pourrait être scripté pour ajouter efficacement l'en-tête X-Spam-Status aux messages.
