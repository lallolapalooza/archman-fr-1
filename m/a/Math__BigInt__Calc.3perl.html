Math::BigInt::Calc(3perl) Guide de référence du programmeur Perl Math::BigInt::Calc(3perl)

NOM

Math::BigInt::Calc - module Perl pur pour supporter Math::BigInt

SYNTAXE

# pour l'utiliser avec Math::BigInt
use Math::BigInt lib => 'Calc';
# pour l'utiliser avec Math::BigFloat
use Math::BigFloat lib => 'Calc';
# pour l'utiliser avec Math::BigRat
use Math::BigRat lib => 'Calc';
# définir explicitement la longueur de base et si on utilise « use integer »
use Math::BigInt::Calc base_len => 4, use_int => 1;
use Math::BigInt lib => 'Calc';

DESCRIPTION

Math::BigInt::Calc hérite de Math::BigInt::Lib.

Dans cette bibliothèque, les nombres sont représentés en interne dans la base B = 10**N, où N est le plus grand entier possible qui ne cause pas de débordement dans les calculs intermédiaires. Les éléments de base B sont stockés dans un tableau, l'élément le moins significatif étant stocké dans l'élément zéro du tableau. Il n'y a pas d'éléments zéro de tête, à l'exception d'un seul élément zéro lorsque le nombre est zéro. Par exemple, si B = 10000, le nombre 1234567890 est représenté en interne comme [7890, 3456, 12].

OPTIONS

Lors du chargement du module, il calcule l'exposant maximal, c'est-à-dire la puissance de 10, qui peut être utilisée avec et sans "use integer" dans les calculs. Par défaut, cet exposant maximal est utilisé. Si la combinaison de la valeur 'base_len' et de la valeur 'use_int' dépasse la valeur maximale, une erreur est levée.

base_len
La longueur de base peut être spécifiée explicitement avec l'option 'base_len'. La valeur doit être un entier positif. 
use Math::BigInt::Calc base_len => 4;  # utilise 10000 comme base interne
use_int
Cette option est utilisée pour spécifier si "use integer" doit être utilisé dans les calculs internes. La valeur est interprétée comme une valeur booléenne, donc utilisez 0 ou "" pour faux et tout le reste pour vrai. Si 'base_len' n'est pas spécifié avec 'use_int', la valeur actuelle pour la longueur de base est utilisée. 
use Math::BigInt::Calc use_int => 1;   # utilise « use integer » en interne

MÉTHODES

Cet aperçu ne contient que les méthodes spécifiques à "Math::BigInt::Calc". Pour les autres méthodes, voir Math::BigInt::Lib.

_base_len()
Spécifie la longueur de base désirée et s'il faut activer "use integer" dans les calculs. 
Math::BigInt::Calc -> _base_len($base_len, $use_int);

Notez qu'il est préférable de spécifier la longueur de base et s'il faut utiliser des entiers comme options lors du chargement du module, par exemple comme ceci

use Math::BigInt::Calc base_len => 6, use_int => 1;

VOIR AUSSI

Certains des modules qui utilisent ces bibliothèques Math::BigInt, Math::BigFloat, et Math::BigRat.
