NOM

Mail::SpamAssassin::Plugin::Razor2 - effectue la vérification Razor des messages

SYNOPSIS

loadplugin     Mail::SpamAssassin::Plugin::Razor2

DESCRIPTION

Vipul's Razor est un réseau distribué et collaboratif de détection et de filtrage de spam basé sur les soumissions de spam par les utilisateurs. La détection est effectuée avec des signatures qui repèrent efficacement le contenu de spam mutant et l'entrée utilisateur est validée par des attributions de réputation.

Voir http://razor.sourceforge.net/ pour plus d'informations sur Razor.

DÉPENDANCES

Razor2 nécessite le module Perl "Razor2::Client::Agent" pour être installé.

DÉFINITIONS DE RÈGLES

Razor2 calcule une signature pour chaque partie d'un message multipartie, puis compare ces signatures à une base de données de signatures de spam connues. Le serveur renvoie une valeur de confiance (0-100) pour chaque partie du message. La partie ayant la valeur de confiance la plus élevée est utilisée comme valeur de confiance pour le message.

Les règles d'évaluation suivantes sont fournies par ce plugin :

full   RULENAME   eval:check_razor2()
   Retourne vrai si la valeur de confiance du message est supérieure ou égale à `min_cf` telle que définie dans
   le fichier de configuration Razor2 'razor-agent.conf(1)'.
full   RULENAME   eval:check_razor2_range(<engine>,<min>,<max>)
   <engine>  Numéro du moteur (4, 8 ou '')
   <min>     Valeur de confiance minimale (0-100)
   <max>     Valeur de confiance maximale (0-100)
   Retourne vrai si la valeur de confiance du spam pour le message est supérieure ou égale à <min> et
   inférieure ou égale à <max>. Si <engine> n'est pas spécifié, le moteur avec la valeur de confiance la plus élevée
   est utilisé.

PARAMÈTRES UTILISATEUR

use_razor2 (0|1) (par défaut: 1)
Si Razor2 doit être utilisé, s'il est disponible.

PARAMÈTRES ADMINISTRATEUR

razor_fork (0|1) (par défaut: 1)
Au lieu d'exécuter Razor2 de manière synchrone, créez un processus séparé pour celui-ci et lisez les résultats plus tard (similaire aux recherches DNS asynchrones). Augmente le débit. Considéré comme expérimental sous Windows, où la valeur par défaut est 0.
razor_timeout n (par défaut: 5)
Combien de secondes vous attendez que Razor se termine avant de continuer sans les résultats
razor_config nom_fichier
Définir le nom du fichier utilisé pour stocker les paramètres de configuration de Razor. Actuellement, cela est laissé à la décision de Razor.
