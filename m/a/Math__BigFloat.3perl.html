DESCRIPCIÓN

Math::BigFloat ofrece soporte para números de punto flotante de precisión arbitraria. También se proporciona sobre carga para operadores de Perl.

Todas las operaciones (incluyendo operaciones básicas de matemáticas) se sobre cargan si declaras tus números de punto flotante de precisión arbitraria como

$x = Math::BigFloat->new('12_3.456_789_123_456_789E-2');

Las operaciones con operadores sobre cargados preservan los argumentos, lo cual es lo que esperas.

Entrada

Valores de entrada a estas rutinas pueden ser cualquier número escalar o cadena que parezca un número. Cualquier valor aceptado por Perl como constante numérica literal se acepta aquí.

  • El espaciado de inicio y fin de línea se ignora.
  • Los ceros de inicio y fin se ignoran, excepto para números de punto flotante con exponente binario, en cuyo caso el número se interpreta como un número de punto flotante octal. Por ejemplo, "01.4p+0" da 1.5, "00.4p+0" da 0.5, pero "0.4p+0" da NaN. Y aunque "0377" da 255, "0377p0" da 255.
  • Si la cadena tiene un prefijo "0x" o "0X", se interpreta como un número hexadecimal.
  • Si la cadena tiene un prefijo "0o" o "0O", se interpreta como un número octal. También se interpreta un literal de punto flotante con prefijo "0" como número octal.
  • Si la cadena tiene un prefijo "0b" o "0B", se interpreta como un número binario.
  • Los caracteres subrayados están permitidos de la misma manera que en las constantes numéricas literales.
  • Si la cadena no puede ser interpretada, se devuelve NaN.
  • Para números de punto flotante hexadecimal, octal y binario, el exponente debe estar separado del significado (mantisa) por la letra "p" o "P", no "e" o "E" como en los números decimales.

Salida

Valores de salida son generalmente objetos Math::BigFloat.

Los operadores booleanos is_zero(), is_one(), is_inf(), etc. devuelven verdadero o falso.

Los operadores de comparación bcmp() y bacmp() devuelven -1, 0, 1, o undef.

MÉTODOS

Math::BigFloat soporta todos los métodos que Math::BigInt soporta, excepto que calcula resultados no enteros cuando es posible. Por favor consulta Math::BigInt para una descripción completa de cada método. A continuación, se muestran solo las diferencias más importantes:

Métodos de configuración

accuracy()
$x->accuracy(5);           # local para $x
CLASS->accuracy(5);        # global para todos los miembros de CLASS
                           # Nota: Esto también aplica a new()!
$A = $x->accuracy();       # leer la precisión que afecta a $x
$A = CLASS->accuracy();    # leer la precisión global

Establece o obtiene la precisión global o local, es decir, cuántos dígitos significativos tiene los resultados. Si estableces una precisión global, esto también aplica a new()!

Advertencia! La precisión está fija, por ejemplo, una vez que creaste un número bajo el influjo de "CLASS->accuracy($A)", todos los resultados de operaciones matemáticas con ese número también se redondean.

En la mayoría de los casos, deberías redondear los resultados explícitamente usando uno de los métodos round() en Math::BigInt, bround() en Math::BigInt o bfround() en Math::BigInt, o pasando la precisión deseada como parámetro adicional a la operación matemática:

my $x = Math::BigInt->new(30000);
my $y = Math::BigInt->new(7);
print scalar $x->copy()->bdiv($y, 2);           # imprimir 4300
print scalar $x->copy()->bdiv($y)->bround(2);   # imprimir 4300
precision()
$x->precision(-2);        # local para $x, redondea al segundo dígito a la derecha de la coma
                          # $x->precision(2);         # mismo, redondea al segundo dígito a la izquierda de la coma
                          # CLASS->precision(5);      # Global para todos los miembros de CLASS
                          # Esto también aplica a new()!
                          # CLASS->precision(-5);     # mismo
                          $P = CLASS->precision();  # leer precisión global
                          $P = $x->precision();     # leer precisión que afecta a $x

Nota: Tal vez quieras usar accuracy() en lugar de precision(). Con accuracy() establece el número de dígitos que cada resultado debería tener, y con precision() establece el lugar donde se redondeará!

Métodos de constructor

from_dec()
$x -> from_hex("314159");
$x = Math::BigInt -> from_hex("314159");

Interpreta el input como un número decimal. Es equivalente a new(), pero no acepta nada salvo cadenas representando números finitos, decimales.

from_hex()
$x -> from_hex("0x1.921fb54442d18p+1");
$x = Math::BigFloat -> from_hex("0x1.921fb54442d18p+1");

Interpreta el input como una cadena hexadecimal. El prefijo ("0x", "x", ignorando mayúsculas y minúsculas) es opcional. Una sola barra de subrayado ("_") puede colocarse entre dos dígitos. Si el input es inválido, se devuelve NaN. El exponente está en base 2 usando dígitos decimales.

Si se llama como un método de instancia, el valor se asigna al invocand.

from_oct()
$x -> from_oct("1.3267p-4");
$x = Math::BigFloat -> from_oct("1.3267p-4");

Interpreta el input como una cadena octal. Una sola barra de subrayado ("_") puede colocarse entre dos dígitos. Si el input es inválido, se devuelve NaN. El exponente está en base 2 usando dígitos decimales.

Si se llama como un método de instancia, el valor se asigna al invocand.

from_bin()
$x -> from_bin("0b1.1001p-4");
$x = Math::BigFloat -> from_bin("0b1.1001p-4");

Interpreta el input como una cadena binaria. Un prefijo ("0b" o "b", ignorando mayúsculas y minúsculas) es opcional. Una sola barra de subrayado ("_") puede colocarse entre dos dígitos. Si el input es inválido, se devuelve NaN. El exponente está en base 2 usando dígitos decimales.

Si se llama como un método de instancia, el valor se asigna al invocand.

from_bytes()
$x = Math::BigFloat->from_bytes("\xf3\x6b");  # $x = 62315

Interpreta el input como una cadena de bytes, asumiendo un orden de bytes de endianness. El output siempre es un número entero no negativo y finito.

Ver from_bytes() en Math::BigInt.

from_ieee754()
Interpreta el input como un valor codificado según IEEE754-2008. El input puede ser dado como una cadena de bytes, cadena hexadecimal o cadena binaria. El input se asume que está en orden de bytes de endianness.
# Both $dbl, $xr, $xh, and $xb below are 3.141592...
$dbl = unpack "d>", "\x40\x09\x21\xfb\x54\x44\x2d\x18";
$raw = "\x40\x09\x21\xfb\x54\x44\x2d\x18";          # raw bytes
$xr  = Math::BigFloat -> from_ieee754($raw, "binary64");
$hex = "400921fb54442d18";
$xh  = Math::BigFloat -> from_ieee754($hex, "binary64");
$bin = "0100000000001001001000011111101101010100010001000010110100011000";
$xb  = Math::BigFloat -> from_ieee754($bin, "binary64");

Los formatos soportados son todos los formatos IEEE754 binarios: "binary16", "binary32", "binary64", "binary128", "binary160", "binary192", "binary224", "binary256", etc. donde el número de bits es un múltiplo de 32 para todos los formatos mayores que "binary128". Las alias son "half" ("binary16"), "single" ("binary32"), "double" ("binary64"), "quadruple" ("binary128"), "octuple" ("binary256"), y "sexdecuple" ("binary512").

Ver también to_ieee754().

from_base()
$x = Math::BigFloat -> from_base(10, 2, 3);

Interpreta el input como un número en base 2, 3, 4, 5, 6, 7, 8, 9 o 10. El segundo parámetro es el sistema de numeración que se usa.

Voir "from_base()" dans Math::BigInt.
bpi()
print Math::BigFloat->bpi(100), "\n";

Calcule PI à N décimales (y compris le 3 avant la virgule). Le résultat est arrondi selon le mode d'arrondi actuel, qui est par défaut "even" (pair).

Cette méthode a été ajoutée dans la v1.87 de Math::BigInt (juin 2007).

as_int()
$y = $x -> as_int();        # $y est un Math::BigInt

Retourne $x comme un objet Math::BigInt, indépendamment de la montée ou de la descente en gamme. Si $x est fini, mais pas un entier, $x est tronqué.

as_rat()
$y = $x -> as_rat();        # $y est un Math::BigRat

Retourne $x comme un objet Math::BigRat, indépendamment de la montée ou de la descente en gamme. L'appelant n'est pas modifié.

as_float()
$y = $x -> as_float();      # $y est un Math::BigFloat

Retourne $x comme un objet Math::BigFloat, indépendamment de la montée ou de la descente en gamme. L'appelant n'est pas modifié.

Méthodes arithmétiques

bdiv()
$x->bdiv($y);               # $x prend la valeur du quotient
($q, $r) = $x->bdiv($y);    # $q est le quotient, $r est le reste

C'est un alias pour "bfdiv()".

bmod()
$x->bmod($y);

Retourne $x modulo $y. Quand $x est fini, et $y est fini et non nul, le résultat est identique au reste après division par plancher (division F). Si, de plus, $x et $y sont des entiers, le résultat est identique au résultat de l'opérateur % de Perl.

bfdiv()
$q = $x->bfdiv($y);
($q, $r) = $x->bfdiv($y);

En contexte scalaire, divise $x par $y et retourne le résultat à la précision ou l'exactitude demandée, ou à la précision par défaut. En contexte de liste, effectue une division par plancher (division F), retournant un entier $q et un reste $r

$q = floor($x / $y)
$r = $x - $q * $y

de sorte que la relation suivante est toujours vérifiée :

$x = $q * $y + $r

Le reste (modulo) est égal à ce que retourne "$x->bmod($y)".

binv()
$x->binv();

Inverse la valeur de $x, c'est-à-dire, calcule 1/$x.

bmuladd()
$x->bmuladd($y,$z);

Multiplie $x par $y, puis ajoute $z au résultat.

Cette méthode a été ajoutée dans la v1.87 de Math::BigInt (juin 2007).

bexp()
$x->bexp($accuracy);            # calcule e ** X

Calcule l'expression "e ** $x" où "e" est le nombre d'Euler.

Cette méthode a été ajoutée dans la v1.82 de Math::BigInt (avril 2007).

bnok()
Voir "bnok()" dans Math::BigInt.
bperm()
Voir "bperm()" dans Math::BigInt.
bsin()
my $x = Math::BigFloat->new(1);
print $x->bsin(100), "\n";

Calcule le sinus de $x, en modifiant $x en place.

Cette méthode a été ajoutée dans la v1.87 de Math::BigInt (juin 2007).

bcos()
my $x = Math::BigFloat->new(1);
print $x->bcos(100), "\n";

Calcule le cosinus de $x, en modifiant $x en place.

Cette méthode a été ajoutée dans la v1.87 de Math::BigInt (juin 2007).

batan()
my $x = Math::BigFloat->new(1);
print $x->batan(100), "\n";

Calcule l'arctangente de $x, en modifiant $x en place. Voir aussi "batan2()".

Cette méthode a été ajoutée dans la v1.87 de Math::BigInt (juin 2007).

batan2()
my $y = Math::BigFloat->new(2);
my $x = Math::BigFloat->new(3);
print $y->batan2($x), "\n";

Calcule l'arctangente de $y divisé par $x, en modifiant $y en place. Voir aussi "batan()".

Cette méthode a été ajoutée dans la v1.87 de Math::BigInt (juin 2007).

bgcd()
$x -> bgcd($y);             # PGCD de $x et $y
$x -> bgcd($y, $z, ...);    # PGCD de $x, $y, $z, ...

Retourne le plus grand commun diviseur (PGCD), qui est le nombre de plus grande valeur absolue tel que $x/$pgcd, $y/$pgcd, ... soit un entier. Par exemple, lorsque les opérandes sont 0.8 et 1.2, le PGCD est 0.4. C'est une généralisation du PGCD ordinaire pour les entiers. Voir "gcd()" dans Math::BigInt.

bstr()
my $x = Math::BigRat->new('8/4');
print $x->bstr(), "\n";             # affiche 1/2

Retourne une chaîne représentant le nombre.

bsstr()
Voir "bsstr()" dans Math::BigInt.
bnstr()
Voir "bnstr()" dans Math::BigInt.
bestr()
Voir "bestr()" dans Math::BigInt.
bdstr()
Voir "bdstr()" dans Math::BigInt.
to_bytes()
Voir "to_bytes()" dans Math::BigInt.
to_ieee754()
Encode l'appelant sous forme de chaîne d'octets dans le format spécifié par IEEE 754-2008. Notez que la valeur encodée est la représentation la plus proche possible de la valeur. Cette valeur peut ne pas être exactement la même que la valeur dans l'appelant. 
# $x = 3.1415926535897932385
$x = Math::BigFloat -> bpi(30);
$b = $x -> to_ieee754("binary64");  # encode en 8 octets
$h = unpack "H*", $b;               # "400921fb54442d18"
# 3.141592653589793115997963...
$y = Math::BigFloat -> from_ieee754($h, "binary64");

Tous les formats binaires d'IEEE 754-2008 sont acceptés. Par commodité, certains alias sont reconnus : "half" pour "binary16", "single" pour "binary32", "double" pour "binary64", "quadruple" pour "binary128", "octuple" pour "binary256", et "sexdecuple" pour "binary512".

Voir aussi "from_ieee754()", https://en.wikipedia.org/wiki/IEEE_754.

EXACTITUDE ET PRÉCISION

Voir aussi : Arrondi.

Math::BigFloat supporte à la fois la précision (arrondi à une certaine place avant ou après la virgule) et l'exactitude (arrondi à un certain nombre de chiffres). Pour une documentation complète, des exemples et des conseils sur ces sujets, veuillez consulter la grande section sur l'arrondi dans Math::BigInt.

Comme des opérations comme sqrt(2) ou "1 / 3" doivent être présentées avec une exactitude limitée, faute de quoi une opération consommerait toutes les ressources, chaque opération ne produit pas plus que le nombre de chiffres demandé.

S'il n'y a pas de précision ou d'exactitude globale définie, et si l'opération en question n'a pas été appelée avec une précision ou une exactitude demandée, et si l'entrée $x n'a pas d'exactitude ou de précision définie, alors un paramètre de repli sera utilisé. Pour des raisons historiques, il est appelé "div_scale" et peut être accédé via :

$d = Math::BigFloat->div_scale();       # requête
Math::BigFloat->div_scale($n);          # définition à $n chiffres

La valeur par défaut pour "div_scale" est 40.

Dans le cas où le résultat d'une opération a plus de chiffres que spécifié, il est arrondi. Le mode d'arrondi utilisé est soit le mode par défaut, soit celui fourni à l'opération après le *scale* :

$x = Math::BigFloat->new(2);
Math::BigFloat->accuracy(5);              # 5 chiffres max
$y = $x->copy()->bdiv(3);                 # donne 0.66667
$y = $x->copy()->bdiv(3,6);               # donne 0.666667
$y = $x->copy()->bdiv(3,6,undef,'odd');   # donne 0.666667
Math::BigFloat->round_mode('zero');
$y = $x->copy()->bdiv(3,6);               # donnera aussi 0.666667

Notez que "Math::BigFloat->accuracy()" et "Math::BigFloat->precision()" définissent les variables globales, et donc **n'importe quel** nombre nouvellement créé sera soumis à l'arrondi global **immédiatement**. Cs signifie que dans les exemples ci-dessus, le 3 comme argument à "bdiv()" obtiendra également une précision de 5.

Il est moins déroutant soit de calculer le résultat entièrement, puis de l'arrondir explicitement, soit d'utiliser les paramètres supplémentaires des fonctions mathématiques comme suit :

use Math::BigFloat;
$x = Math::BigFloat->new(2);
$y = $x->copy()->bdiv(3);
print $y->bround(5),"\n";               # donne 0.66667
ou
use Math::BigFloat;
$x = Math::BigFloat->new(2);
$y = $x->copy()->bdiv(3,5);             # donne 0.66667
print "$y\n";

Arrondi

bfround ( +$scale )
Arrondit à la $scale-ième place à gauche du '.', en comptant à partir du point. Le premier chiffre est numéroté 1.
bfround ( -$scale )
Arrondit à la $scale-ième place à droite du '.', en comptant à partir du point.
bfround ( 0 )
Arrondit à un entier.
bround ( +$scale )
Préserve la précision à $scale chiffres à partir de la gauche (alias chiffres significatifs) et remplit le reste avec des zéros. Si le nombre est compris entre 1 et -1, les chiffres significatifs sont comptés à partir du premier non-zéro après le '.'
bround ( -$scale ) et bround ( 0 )
Ce sont effectivement des opérations nulles.

Toutes les fonctions d'arrondi prennent comme deuxième paramètre un mode d'arrondi parmi les suivants : 'even', 'odd', '+inf', '-inf', 'zero', 'trunc' ou 'common'.

Le mode d'arrondi par défaut est 'even'. En utilisant "Math::BigFloat->round_mode($round_mode);" vous pouvez obtenir et définir le mode par défaut pour les arrondis ultérieurs. L'utilisation de "$Math::BigFloat::$round_mode" n'est plus prise en charge. Le deuxième paramètre des fonctions d'arrondi remplace alors temporairement le défaut.

La méthode "as_int()" retourne un BigInt à partir d'un Math::BigFloat. Elle utilise 'trunc' comme mode d'arrondi pour la rendre équivalente à :

$x = 2.5;
$y = int($x) + 2;

Vous pouvez outrepasser cela en passant le mode d'arrondi désiré comme paramètre à "as_int()" :

$x = Math::BigFloat->new(2.5);
$y = $x->as_number('odd');      # $y = 3

LITTÉRAUX NUMÉRIQUES

Après "use Math::BigFloat ':constant'" tous les littéraux numériques dans la portée donnée sont convertis en objets "Math::BigFloat". Cette conversion a lieu au moment de la compilation.

Par exemple,

perl -MMath::BigFloat=:constant -le 'print 2e-150'

affiche la valeur exacte de 2e-150. Notez que sans conversion des constantes, l'expression 2e-150 est calculée en utilisant des scalaires Perl, ce qui conduit à un résultat inexact.

Notez que les chaînes de caractères ne sont pas affectées, de sorte que

use Math::BigFloat qw/:constant/;
$y = "1234567890123456789012345678901234567890"
        + "123456789123456789";

ne vous donnera pas ce que vous attendez. Vous avez besoin d'un explicite Math::BigFloat->new() autour d'au moins un des opérandes. Vous devriez également mettre entre guillemets les grandes constantes pour éviter la perte de précision :

use Math::BigFloat;
$x = Math::BigFloat->new("1234567889123456789123456789123456789");

Sans les guillemets, Perl convertit le grand nombre en une constante en virgule flottante au moment de la compilation, puis convertit le résultat en un objet Math::BigFloat au moment de l'exécution, ce qui entraîne un résultat inexact.

Littéraux flottants hexadécimaux, octaux et binaires

Perl (et ce module) accepte les littéraux flottants hexadécimaux, octaux et binaires, mais utilisez-les avec prudence avec les versions de Perl antérieures à v5.32.0, car certaines versions de Perl donnent silencieusement le mauvais résultat. Voici quelques exemples de différentes façons d'écrire le nombre décimal 314.

Littéraux flottants hexadécimaux :

0x1.3ap+8         0X1.3AP+8
0x1.3ap8          0X1.3AP8
0x13a0p-4         0X13A0P-4

Littéraux flottants octaux (avec préfixe "0") :

01.164p+8         01.164P+8
01.164p8          01.164P8
011640p-4         011640P-4

Littéraux flottants octaux (avec préfixe "0o") (nécessite v5.34.0) :

0o1.164p+8        0O1.164P+8
0o1.164p8         0O1.164P8
0o11640p-4        0O11640P-4

Littéraux flottants binaires :

0b1.0011101p+8    0B1.0011101P+8
0b1.0011101p8     0B1.0011101P8
0b10011101000p-2  0B10011101000P-2

Bibliothèque mathématique

Les calculs avec les nombres sont effectués (par défaut) par un module appelé Math::BigInt::Calc. Cela équivaut à dire :

use Math::BigFloat lib => "Calc";

Vous pouvez changer cela en utilisant :

use Math::BigFloat lib => "GMP";

Note : Les paquets à usage général ne doivent pas être explicites quant à la bibliothèque à utiliser ; laissez à l'auteur du script le soin de décider quelle est la meilleure.

Note : Le mot-clé 'lib' émettra un avertissement lorsque la bibliothèque demandée n'a pas pu être chargée. Pour supprimer l'avertissement, utilisez plutôt 'try' :

use Math::BigFloat try => "GMP";

Si votre script fonctionne avec des nombres énormes et que Calc est trop lent pour eux, vous pouvez également spécifier le chargement de l'une de ces bibliothèques et si aucune d'elles ne peut être utilisée, le code mourra :

use Math::BigFloat only => "GMP,Pari";

Le code suivant essaiera d'abord de trouver Math::BigInt::Foo, puis Math::BigInt::Bar, et lorsque cela échouera également, il reviendra à Math::BigInt::Calc :

use Math::BigFloat lib => "Foo,Math::BigInt::Bar";

Voir la documentation de la bibliothèque de bas niveau respective pour plus de détails.

Voir Math::BigInt pour plus de détails sur l'utilisation d'une bibliothèque de bas niveau différente.

EXPORT

"Math::BigFloat" n'exporte rien par défaut, mais peut exporter la méthode "bpi()" :

use Math::BigFloat qw/bpi/;
print bpi(10), "\n";
Modification et =
Attention à : 
$x = Math::BigFloat->new(5);
$y = $x;

Cela ne fera pas ce que vous pensez, par exemple, créer une copie de $x. Au lieu de cela, cela crée simplement une deuxième référence au même objet et la stocke dans $y. Ainsi, tout ce qui modifie $x modifiera $y (sauf les opérateurs mathématiques surchargés), et vice versa. Voir Math::BigInt pour les détails et comment éviter cela.

precision() vs. accuracy()
Un piège courant est d'utiliser "precision()" lorsque vous souhaitez arrondir un résultat à un certain nombre de chiffres : 
use Math::BigFloat;
Math::BigFloat->precision(4);           # ne fait pas ce que vous
                                        # pensez qu'il fait
my $x = Math::BigFloat->new(12345);     # arrondit $x à "12000"!
print "$x\n";                           # imprime "12000"
my $y = Math::BigFloat->new(3);         # arrondit $y à "0"!
print "$y\n";                           # imprime "0"
$z = $x / $y;                           # 12000 / 0 => NaN!
print "$z\n";
print $z->precision(),"\n";             # 4

Remplacer "precision()" par "accuracy()" n'est probablement pas non plus ce que vous voulez :

use Math::BigFloat;
Math::BigFloat->accuracy(4);          # active l'arrondi global :
my $x = Math::BigFloat->new(123456);  # arrondi immédiatement
                                      #   à "12350"
print "$x\n";                         # imprime "123500"
my $y = Math::BigFloat->new(3);       # arrondi à "3
print "$y\n";                         # imprime "3"
print $z = $x->copy()->bdiv($y),"\n"; # 41170
print $z->accuracy(),"\n";            # 4

Ce que vous voulez utiliser à la place est :

use Math::BigFloat;
my $x = Math::BigFloat->new(123456);    # pas d'arrondi
print "$x\n";                           # imprime "123456"
my $y = Math::BigFloat->new(3);         # pas d'arrondi
print "$y\n";                           # imprime "3"
print $z = $x->copy()->bdiv($y,4),"\n"; # 41150
print $z->accuracy(),"\n";              # undef

En plus de calculer ce que vous attendiez, le dernier exemple ne "contamine" pas non plus le résultat avec un réglage de précision ou d'exactitude, ce qui influencerait toute opération ultérieure.

NOM

Math::BigFloat

SYNTAXE

Utilisez ce module pour effectuer des opérations arithmétiques à précision arbitraire sur des nombres à virgule flottante.

DESCRIPTION

Math::BigFloat est un module Perl qui fournit des opérations arithmétiques à précision arbitraire sur des nombres à virgule flottante. Il prend en charge des opérations telles que l'addition, la soustraction, la multiplication, la division et l'exponentiation. Le module est conçu pour gérer de très grands nombres avec une grande précision, ce qui le rend adapté aux applications nécessitant des calculs arithmétiques précis.

MÉTHODES

Les méthodes suivantes sont disponibles dans Math::BigFloat :

  • add - Ajoute deux nombres.
  • subtract - Soustrait un nombre d'un autre.
  • multiply - Multiplie deux nombres.
  • divide - Divise un nombre par un autre.
  • exponentiate - Élève un nombre à une puissance.

LITTÉRAUX NUMÉRIQUES

Le module prend en charge les littéraux numériques suivants :

  • bigfloat - Représente un grand nombre à virgule flottante.
  • bigfloat - Représente un grand nombre à virgule flottante.

EXPORTATIONS

Les fonctions suivantes sont exportées :

  • add - Ajoute deux nombres.
  • subtract - Soustrait un nombre d'un autre.
  • multiply - Multiplie deux nombres.
  • divide - Divise un nombre par un autre.
  • exponentiate - Élève un nombre à une puissance.

BOGUES

Les bogues suivants sont connus :

  • Problème de précision en virgule flottante dans certains cas.
  • Mauvaise gestion des grands nombres dans certains scénarios.
