NOM

HashBL - Requête des listes de blocage DNS (et non-hashées)

SYNOPSIS

loadplugin Mail::SpamAssassin::Plugin::HashBL
# Exemples d'utilisation non fonctionnels (remplacer xxx.example.invalid par une liste réelle)
# Requêtes documentées dans la section suivante
header   HASHBL_EMAIL eval:check_hashbl_emails('ebl.example.invalid')
describe HASHBL_EMAIL Message contient une adresse email trouvée dans EBL
tflags   HASHBL_EMAIL net
# Changer googlemail.com en gmail.com, appliqué avant acl/welcomelist
hashbl_email_domain_alias gmail.com googlemail.com
# Interroger seulement gmail.com
hashbl_acl_freemail gmail.com
header   HASHBL_OSENDR eval:check_hashbl_emails('rbl.example.invalid/A', 'md5/max=10/shuffle', 'X-Original-Sender', '^127\.', 'freemail')
describe HASHBL_OSENDR Message contient une adresse email trouvée dans HASHBL
tflags   HASHBL_OSENDR net
body     HASHBL_BTC eval:check_hashbl_bodyre('btcbl.example.invalid', 'sha1/max=10/shuffle', '\b([13][a-km-zA-HJ-NP-Z1-9]{25,34})\b')
describe HASHBL_BTC Message contient une adresse Bitcoin trouvée dans BTCBL
tflags   HASHBL_BTC net
header   HASHBL_URI eval:check_hashbl_uris('rbl.example.invalid', 'sha1', '^127\.', 'X-Some-ID')
describe HASHBL_URI Message contient une URI trouvée dans rbl
tflags   HASHBL_URI net
body     HASHBL_ATTACHMENT eval:check_hashbl_attachments('attbl.example.invalid', 'sha256')
describe HASHBL_ATTACHMENT Message contient une pièce jointe trouvée dans attbl
tflags   HASHBL_ATTACHMENT net
# Capturer une balise en utilisant la fonction de capture regex de SA 4.0
header   __X_SOME_ID X-Some-ID =~ /^(?<XSOMEID>\d{10,20})$/
# Interroger la valeur de la balise telle quelle, à partir d'un DNSBL
header   HASHBL_TAG eval:check_hashbl_tag('idbl.example.invalid/A', 'raw', 'XSOMEID', '^127\.')

DESCRIPTION

Ce plugin prend en charge divers types de requêtes de listes de blocage DNS (hashées ou non hashées).

OPTS communs qui s'appliquent à toutes les fonctions :
raw      pas de hash, interroge tel quel (peut échouer si la valeur n'est pas un nom de domaine valide)
md5      hash avec MD5
sha1     hash avec SHA1
sha256   hash avec SHA256 encodé en Base32
case     conserver la casse avant le hash, par défaut en majuscules
max=x    nombre maximum de requêtes (par défaut est 10 si non spécifié)
shuffle  si le maximum est dépassé, mélanger les requêtes avant de tronquer à la limite

Les options multiples peuvent être séparées par un slash.

Si OPTS est vide ou non spécifié, la valeur par défaut est utilisée, telle que documentée pour chaque type de requête. Si des options sont définies, toutes les exigences doivent être explicitement définies.

règle d'en-tête check_hashbl_emails('bl.example.invalid/A', 'OPTS', 'HEADERS', '^127\.')
Vérifie les adresses e-mail des listes de blocage DNS. Note : le corps peut être spécifié avec les en-têtes pour rechercher des adresses e-mail dans le corps du message. Le type de règle doit être « header ».

Le type de requête DNS peut être ajouté à la liste avec /A (par défaut) ou /TXT.

La valeur par défaut de OPTS est sha1/notag/noquote/max=10/shuffle.

Autres options prises en charge :

nodot    supprime les points dans le nom d'utilisateur de l'adresse e-mail
notag    supprime les balises dans le nom d'utilisateur de l'adresse e-mail
nouri    ignore les adresses e-mail dans les uris
noquote  ignore les adresses e-mail dans < > ou les citations possibles
user     interroge uniquement la partie utilisateur de l'adresse e-mail
host     interroge uniquement la partie hôte de l'adresse e-mail
domain   interroge uniquement la partie domaine de l'adresse e-mail (partie hôte + supprimer le domaine)

Les HEADERS par défaut sont ALLFROM/Reply-To/body.

HEADERS fait référence à une liste séparée par des traits d'union des en-têtes à traiter :

ALL           tous les en-têtes
ALLFROM       tous les en-têtes From tels que retournés par $pms->all_from_addrs()
EnvelopeFrom  en-tête d'expédition (Return-Path etc)
<HeaderName>  n'importe quel en-tête tel qu'utilisé avec les règles d'en-tête ou $pms->get()
body          toutes les adresses e-mail trouvées dans le corps du message

Si HEADERS est vide («  ») ou non spécifié, la valeur par défaut est utilisée.

Un sous-test regexp optionnel pour correspondre à la réponse DNS (par défaut : « ^127\. »).

Pour le blocage public des e-mails, voir : http://msbl.org/ebl.html

# Exemple d'utilisation, voir https://msbl.org/ebl.html avant de l'utiliser
header   HASHBL_EMAIL eval:check_hashbl_emails('ebl.msbl.org')
describe HASHBL_EMAIL Message contient une adresse e-mail trouvée dans EBL
tflags   HASHBL_EMAIL net

Le regex par défaut pour faire correspondre et capturer les e-mails peut être remplacé par "hashbl_email_regex". De plus, la liste d'accueil par défaut peut être modifiée par "hashbl_email_welcomelist". Ne modifiez que si vous savez ce que vous faites, consultez le code source du plugin pour les valeurs par défaut. Exemple : hashbl_email_regex \S+@\S+.com

règle d'en-tête check_hashbl_uris('bl.example.invalid/A', 'OPTS', '^127\.')
Vérifie toutes les URIs analysées du message de la liste de blocage DNS.

Le type de requête DNS peut être ajouté à la liste avec /A (par défaut) ou /TXT.

La valeur par défaut de OPTS est sha1/max=10/shuffle.

Un sous-test regexp optionnel pour correspondre à la réponse DNS (par défaut : « ^127\. »).

[raw]body RÈGLE check_hashbl_bodyre('bl.example.invalid/A', 'OPTS', '\b(match)\b', '^127\.')
Recherche dans le corps du message une correspondance regex et interroge le texte capturé. La regex doit avoir un seul groupe de capture ( ) pour le texte ($1). Le type de règle doit être « body » ou « rawbody ».

Le type de requête DNS peut être ajouté à la liste avec /A (par défaut) ou /TXT.

La valeur par défaut de OPTS est sha1/max=10/shuffle.

Autres options prises en charge :

num      supprime les caractères non numériques

Un sous-test regexp optionnel pour correspondre à la réponse DNS (par défaut : « ^127\. »).

règle d'en-tête check_hashbl_tag('bl.example.invalid/A', 'OPTS', 'TAGNAME', '^127\.')
Interroge la valeur de la balise _TAGNAME_ de SpamAssassin à partir de la liste de blocage DNS.

Le type de requête DNS peut être ajouté à la liste avec /A (par défaut) ou /TXT.

La valeur par défaut de OPTS est sha1/max=10/shuffle.

Autres options prises en charge :

ip        interroge uniquement si la valeur est une adresse IPv4/IPv6 valide
ipv4      interroge uniquement si la valeur est une adresse IPv4 valide
ipv6      interroge uniquement si la valeur est une adresse IPv6 valide
revip     inverse l'adresse IP avant la requête
fqdn      interroge uniquement si la valeur est une adresse FQDN (es_fqdn_valid)
tld       interroge uniquement si la valeur a un TLD valide (es_domain_valid)
trim      supprime le nom d'hôte jusqu'au domaine (trim_domain)
Si ip/ipv4/ipv6 et fqdn/tld sont tous deux activés, un seul d'entre eux est nécessaire pour correspondre. FQDN et TLD sont tous deux nécessaires pour une vérification complète FQDN+TLD.

Un sous-test regexp optionnel pour correspondre à la réponse DNS (par défaut : « ^127\. »).

règle d'en-tête check_hashbl_attachments('bl.example.invalid/A', 'OPTS', '^127\.')
Vérifie toutes les pièces jointes (mimeparts) du message de la liste de blocage DNS.

Le type de requête DNS peut être ajouté à la liste avec /A (par défaut) ou /TXT.

La valeur par défaut de OPTS est sha1/max=10/shuffle.

Autres options prises en charge :

minsize=x  ignore toute partie inférieure à x octets
maxsize=x  ignore toute partie supérieure à x octets

Un sous-test regexp optionnel pour correspondre à la réponse DNS (par défaut : « ^127\. »).

Les noms de fichiers spécifiques de pièces jointes peuvent être ignorés avec "hashbl_ignore". Exemple : hashbl_ignore safe.pdf

Les types MIME spécifiques de pièces jointes peuvent être ignorés avec "hashbl_ignore". Exemple : hashbl_ignore text/plain

valeur hashbl_ignore [valeur...]
Ignore toute requête si la valeur hash ou la valeur d'origine (par exemple, e-mail) correspond. Plusieurs valeurs séparées par des espaces peuvent être spécifiées. La correspondance est insensible à la casse.

Tous les hôtes ou leur partie domaine qui correspondent à uridnsbl_skip_domains sont également ignorés par défaut.
