NOM

Mail::AuthenticationResults::Header::SubEntry - Classe modélisant les parties d'une sous-entrée d'en-tête de résultats d'authentification

VERSION

version 2.20250709

DESCRIPTION

Une sous-entrée est un résultat qui se rapporte à une classe d'entrée principale, par exemple, si l'entrée principale est « dkim=pass », la sous-entrée peut être « domain.d=example.com ».

Des commentaires peuvent être associés à la sous-entrée en tant qu'enfants.

Veuillez consulter Mail::AuthenticationResults::Header::Base
