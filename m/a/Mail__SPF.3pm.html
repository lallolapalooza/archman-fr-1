Mail::SPF(3) Documentation Perl fournie par l'utilisateur Mail::SPF(3)

NOM

Mail::SPF - Une implémentation orientée objet de Sender Policy Framework

VERSION

version 3.20250505

SYNOPSIS

use Mail::SPF;
my $spf_server  = Mail::SPF::Server->new();
my $request     = Mail::SPF::Request->new(
    versions        => [1, 2],              # optionnel
    scope           => 'mfrom',             # ou 'helo', 'pra'
    identity        => 'fred@example.com',
    ip_address      => '192.168.0.1',
    helo_identity   => 'mta.example.com'    # optionnel,
                                            #   pour l'expansion de macro %{h}
);
my $result      = $spf_server->process($request);
print("$result\n");
my $result_code     = $result->code;        # 'pass', 'fail', etc.
my $local_exp       = $result->local_explanation;
my $authority_exp   = $result->authority_explanation
    if $result->is_code('fail');
my $spf_header      = $result->received_spf_header;

DESCRIPTION

Mail::SPF est une implémentation orientée objet de Sender Policy Framework (SPF). Voir https://tools.ietf.org/html/rfc7208 pour plus d'informations sur SPF.

Cette collection de classes vise à se conformer entièrement à la spécification SPF (RFC 4408) afin de servir à la fois d'implémentation SPF de qualité de production et de référence pour d'autres développeurs d'implémentations SPF.

VOIR AUSSI

Mail::SPF::Server, Mail::SPF::Request, Mail::SPF::Result

Pour la disponibilité, le support et les informations de licence, voir le fichier README inclus avec Mail::SPF.
