NOM

Mail::DKIM::PrivateKey - une clé privée chargée en mémoire pour la signature DKIM

VERSION

version 1.20240923

SYNOPSIS

my $key1 = Mail::DKIM::PrivateKey->load(
              File => '/chemin/vers/cle_privee.key');
my $key2 = Mail::DKIM::PrivateKey->load(
              Data => $base64);
# utiliser la clé chargée dans un objet de signature DKIM
my $dkim = Mail::DKIM::Signer->new(
              Key => $key2,
            );

CONSTRUCTEUR

load() - charge une clé privée en mémoire

my $key1 = Mail::DKIM::PrivateKey->load(
              File => '/chemin/vers/cle_privee.key');

Charge la clé encodée en Base64 à partir du fichier spécifié.

my $key2 = Mail::DKIM::PrivateKey->load(Data => $base64);

Charge la clé encodée en Base64 à partir d'une chaîne déjà en mémoire.

my $key3 = Mail::DKIM::PrivateKey->load(Cork => $objet_openssl);

Crée un objet enveloppant Mail::DKIM::PrivateKey pour l'objet clé OpenSSL donné. L'objet clé doit être de type Crypt::OpenSSL::RSA.

MÉTHODES

cork() - accède à l'objet clé OpenSSL sous-jacent

$objet_openssl = $key->cork;

L'objet retourné est de type Crypt::OpenSSL::RSA.

sign_digest()

Signe cryptographiquement le résumé du message donné.

$key->sign_digest('SHA-1', sha1('mon texte de message'));

Le premier paramètre est le nom du digest : l'un parmi "SHA-1", "SHA-256".

Le deuxième paramètre est le résumé du message sous forme de chaîne binaire.

Le résultat devrait être le résumé signé sous forme de chaîne binaire.
