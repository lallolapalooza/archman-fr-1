NOM

Mail::SpamAssassin::Plugin::Phishing - vérifier les URI par rapport à un flux de phishing

SYNTAXE

loadplugin Mail::SpamAssassin::Plugin::Phishing
ifplugin Mail::SpamAssassin::Plugin::Phishing
  phishing_openphish_feed /etc/mail/spamassassin/openphish-feed.txt
  phishing_phishtank_feed /etc/mail/spamassassin/phishtank-feed.csv
  body     URI_PHISHING      eval:check_phishing()
  describe URI_PHISHING      Url match phishing in feed
endif

DESCRIPTION

Ce plugin trouve les URI utilisés dans les campagnes de phishing détectées par les flux OpenPhish, PhishTank ou PhishStats.

Le flux gratuit Openphish est mis à jour toutes les 6 heures et peut être téléchargé à partir de https://openphish.com/feed.txt.

Le flux gratuit PhishTank est mis à jour toutes les 1 heures et peut être téléchargé à partir de http://data.phishtank.com/data/online-valid.csv. Pour éviter les limites de téléchargement, une inscription est requise.

PREFERENCES ADMINISTRATEUR

Les options suivantes peuvent être utilisées dans les fichiers de configuration au niveau du site ("local.cf") pour personnaliser la façon dont le module gère les URI de phishing

phishing_openphish_feed
Chemin absolu du flux de données OpenPhish téléchargé.
phishing_phishtank_feed
Chemin absolu du flux de données PhishTank téléchargé.
phishing_uri_noparam ( 0 | 1 ) (défaut : 0)
Si cette option est activée, les paramètres des URI ne seront pas pris en considération lors de l'analyse du flux de données des URI de phishing. Si cette option est activée et que l'URI sans paramètres est "générique" (comme https://www.kisa.link/url_redirector.php?url=...) l'URI sera ignorée.
