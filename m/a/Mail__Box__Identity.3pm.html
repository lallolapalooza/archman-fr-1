NOM

Mail::Box::Identity - représente un dossier non ouvert

HÉRITAGE

Mail::Box::Identity
  est un User::Identity::Item
Mail::Box::Identity
  est un Mail::Reporter

SYNOPIS

use User::Identity;
use Mail::Box::Identity;
my $me   = User::Identity->new(...);
my $mailbox = Mail::Box::Identity->new(...);
$me->add(folders => $mailbox);
# Plus simple
use User::Identity;
my $me   = User::Identity->new(...);
my $addr = $me->add(folders => ...);

DESCRIPTION

L'objet "Mail::Box::Identity" contient la description d'une seule boîte aux lettres. Les boîtes aux lettres sont collectées par un objet Mail::Box::Collection. Cela correspond par exemple à "\NoSelect" d'IMAP.

Presque toutes les méthodes peuvent retourner "undef".

Sous-dossiers

$obj->addSubfolder(Mail::Box::Identity-objet|$data)
Ajoute un nouveau dossier dans l'administration. Avec $data, un nouvel objet sera instancié en premier. L'identité est retournée en cas de succès.
$obj->folder( [..., $name] )
Retourne l'objet du sous-dossier avec $name ou "undef" s'il n'existe pas. Lorsque plusieurs NOMS sont ajoutés, ces dossiers parents sont parcourus en premier. Sans aucun $name, l'objet courant est retourné.

» exemple : obtenir un dossier

my $a = $user->folders->folder('b', 'a');
my $name  = "a:b:c";
my $delim = ":";
my $f = $user->folders->folder(split $delim, $name);
$obj->foreach(CODE)
Pour chaque sous-dossier trouvé en dessous de ce point, appelle "CODE". Ce dossier courant est appelé en premier. Attention, vous pourriez trouver des identités avec le drapeau deleted() activé.
$obj->open(%options)
Ouvre le dossier décrit par cette identité. Retourne un objet Mail::Box. Les options sont passées à Mail::Box::Manager::open().
$obj->remove( [$name] )
Supprime le dossier (plus les sous-dossiers) avec le $name. Sans $name, cette "Mail::Box::Identity" elle-même est supprimée.

La structure supprimée est retournée, ce qui est "undef" si elle n'est pas trouvée. Ceci est seulement une suppression administrative, vous avez toujours besoin d'un Mail::Box::Manager::delete().

$obj->rename( $folder, [$newsubname] )
Déplace le dossier vers un $folder parent différent, sous un NOUVEAU NOM DE SOUS-DOSSIER.

» exemple : renommer un dossier

my $top = $user->topfolder;
my $new = $top->folder('xyz') or die;
my $f   = $top->folder('abc', 'def')->rename($new, '123');
print $f->name;      # 123
print $f->fullname;  # =/xyz/123
$obj->subfolderNames()
Méthode de commodité : retourne les noms des sous-dossiers collectés.
$obj->subfolders()
Retourne les sous-dossiers ou "undef" s'il n'y en a pas. Cette information est évaluée paresseusement et mise en cache. Dans un contexte de LISTE, les objets dossiers sont retournés (objets Mail::Box::Identity), dans un contexte SCALAIRE la collection, le Mail::Box::Collection.

DIAGNOSTICS

Erreur : Il n'est pas permis d'ajouter des sous-dossiers à $name
Le drapeau inferiors() interdit la création de sous-dossiers pour ce dossier. Lancé par addSubfolder()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où elle devrait l'être. Ce message signifie que d'autres classes associées implémentent cette méthode, mais la classe en question ne le fait pas. Vous devriez probablement enquêter sur cela et probablement informer l'auteur du paquet. Lancé par notImplemented()
Erreur : Le dossier de niveau supérieur ne peut pas être supprimé de cette manière
La structure d'administration des dossiers Mail::Box::Identity nécessite un répertoire racine. Cette racine est enregistrée quelque part (par exemple par un Mail::Box::Manage::User). Si vous avez besoin de supprimer la racine, vous devez chercher une méthode de cet objet. Lancé par remove()
Erreur : Le répertoire de niveau supérieur nécessite un type de dossier explicite
Lancé par folderType()
Erreur : Le répertoire de niveau supérieur nécessite un emplacement explicite
Lancé par location()
Erreur : impossible de charger le module de collection pour $type ($class) : $err
Soit le $type spécifié n'existe pas, soit le module nommé $class renvoie des erreurs de compilation. Si le type tel que spécifié dans l'avertissement n'est pas le nom d'un paquet, vous avez spécifié un surnom qui n'était pas défini. Vous avez peut-être oublié le 'require' du paquet qui définit le surnom. Lancé par addCollection()
Erreur : Collection invalide $name.
La collection avec $name n'existe pas et ne peut pas être créée. Lancé par add()
Erreur : cet $object n'est pas une collection.
Lancé par addCollection()
