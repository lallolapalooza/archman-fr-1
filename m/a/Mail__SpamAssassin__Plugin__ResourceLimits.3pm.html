NOM

Mail::SpamAssassin::Plugin::ResourceLimits - Limite la mémoire et/ou le CPU des processus fils de spamd

SYNOPSIS

# Ce plugin est réservé à l'administrateur et ne peut être spécifié dans la configuration utilisateur.
loadplugin     Mail::SpamAssassin::Plugin::ResourceLimits
# Définit RLIMIT_CPU de BSD::Resource. La limite est basée sur le temps CPU maximum en secondes.
resource_limit_cpu 120
# Définit RLIMIT_RSS et RLIMIT_AS via BSD::Resource.
resource_limit_cpu 536870912

DESCRIPTION

Ce module utilise BSD::Resource pour garantir que vos processus fils de spamd ne dépassent pas les limites spécifiées de CPU ou de mémoire. Si c'est le cas, le processus fils sera terminé. Voir BSD::Resource pour plus de détails.

NOTE : Comme ce plugin utilise BSD::Resource, il ne fonctionnera pas sous Windows.

PARAMÈTRES ADMINISTRATEUR

resource_limit_cpu 120 (par défaut : 0 ou pas de limite)
Nombre de cycles CPU autorisés pour ce processus avant qu'il ne se termine.
resource_limit_mem 536870912 (par défaut : 0 ou pas de limite)
Le nombre maximum d'octets de mémoire autorisés pour :
  • l'espace d'adressage (virtuel)
  • la taille résidente (RSS)
