NOM

Mail::Message::Head::FieldGroup - un sous-ensemble de champs dans un en-tête

HÉRITAGE

Mail::Message::Head::FieldGroup
  est un Mail::Reporter
Mail::Message::Head::FieldGroup est étendu par
  Mail::Message::Head::ListGroup
  Mail::Message::Head::ResentGroup
  Mail::Message::Head::SpamGroup

SYNOPSIS

N'est pas instancié directement.

DESCRIPTION

Certains champs ont une signification combinée : un ensemble de champs qui représentent une étape intermédiaire lors du transport du message (un *groupe resent*, implémenté dans Mail::Message::Head::ResentGroup), des champs ajoutés par des logiciels de listes (implémenté dans Mail::Message::Head::ListGroup), ou des champs ajoutés par des logiciels de détection de spam (implémenté par Mail::Message::Head::SpamGroup). Chaque ensemble de champs peut être extrait ou ajouté en tant que groupe avec des objets basés sur l'implémentation de cette classe.

Étendu de "DESCRIPTION" dans Mail::Reporter.

$obj->clone()
Crée une copie de cet objet. Les noms des champs rassemblés sont copiés et l'information de type de liste est conservée. Il n'y a pas de copie profonde pour l'en-tête : seul le pointeur est copié.
$obj->from($head|$message)
Crée un groupe de champs basé sur le message spécifié $message ou l'en-tête $head. Cela peut retourner un ou plusieurs objets, dépendant du type de groupe. Les champs de liste sont tous stockés dans un seul objet, là où les groupes resent et spam peuvent apparaître plus d'une fois.
$any->implementedTypes()
Retourne une liste de chaînes contenant toutes les valeurs possibles pour type().
$class->new(@fields, %options)
Construit un objet qui maintient un ensemble de champs @fields. Les @fields peuvent être spécifiés comme des objets "Mail::Message::Field" ou comme des paires clé-valeur. Les %options et les @fields (en tant que paires clé-valeur) peuvent être mélangés : ils se distinguent par leur nom, là où les champs commencent toujours par une lettre majuscule. Les objets de champ doivent toujours être placés avant les %options. Améliore la base, voir "Constructors" dans Mail::Reporter

L'en-tête

$obj->add( <$field, $value> | $object )
Ajoute un champ à l'en-tête, en utilisant le groupe de champs. Quand le groupe de champs est déjà associé à un en-tête réel, il apparaîtra dans celui-ci aussi bien qu'enregistré dans cet ensemble. Si aucun en-tête n'est défini, le champ n'apparaîtra qu'interne.

» exemple : ajouter un champ à un groupe de liste détaché

my $this = Mail::Message::Head::ListGroup->new(...);
$this->add('List-Id' => 'mailbox');
$msg->addListGroup($this);
$msg->send;

» exemple : ajouter un champ à un groupe de liste attaché

my $lg = Mail::Message::Head::ListGroup->from($msg);
$lg->add('List-Id' => 'mailbox');
$obj->addFields( [$fieldnames] )
Ajoute certains $fieldnames à la collection.
$obj->attach($head)
Ajoute un groupe de champs à un message $head. Les champs sont clonés (!) dans l'en-tête, ainsi l'objet groupe peut être réutilisé.

» exemple : attacher un groupe de liste à un message

my $lg = Mail::Message::Head::ListGroup->new(...);
$lg->attach($msg->head);
$msg->head->addListGroup($lg);   # identique
$msg->head->addSpamGroup($sg);   # également implémenté avec attach
$obj->delete()
Supprime toutes les lignes d'en-tête qui sont liées à ce groupe de champs.
$obj->fieldNames()
Retourne les noms des champs utilisés dans ce groupe.
$obj->fields()
Retourne les champs définis pour ce groupe.
$obj->head()
Retourne l'objet en-tête, qui inclut ces champs.

Accès à l'en-tête

$obj->software()
Retourne le nom du logiciel tel que défini dans les en-têtes. Peut être légèrement différent du résultat de type(), mais généralement pas très différent.
$obj->type()
Retourne un nom abstrait pour le groupe de champs ; le logiciel qui le contrôle. "undef" est retourné dans le cas où le type n'est pas défini. Les noms valides dépendent du type de groupe : voir les pages man correspondantes. Une liste complète de tous les types peut être obtenue avec implementedTypes().
$obj->version()
Retourne le numéro de version du logiciel qui a produit les champs. Certains types de logiciels laissent une telle trace, d'autres cas retourneront "undef".

Internes

$obj->collectFields( [$name] )
Parcourt l'en-tête à la recherche de champs qui se trouvent généralement dans un groupe de champs avec le nom spécifié $name. Pour les groupes de listes, vous ne pouvez pas spécifier $name : une seule collection d'en-têtes sera trouvée (tous les en-têtes sont considérés comme produits par exactement un paquet de logiciels de listes).

Cette méthode est appelée automatiquement lors de la construction d'un groupe de champs via from() sur un en-tête ou un message existant.

Sont retournés les noms des champs d'en-tête de liste trouvés, dans un contexte scalaire le nombre de champs. Une liste/un nombre vide indique qu'aucun groupe n'a été trouvé.

Assurez-vous de notifier l'auteur de MailBox si vous constatez que trop ou trop peu de champs sont inclus.

$obj->detected($type, $software, $version)
Définit les valeurs pour le type de groupe, le logiciel et la version, potentiellement à "undef".
