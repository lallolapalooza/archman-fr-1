DESCRIPTION

Mail::Box::Parser::C implémente l'analyse des messages en C ANSI, en utilisant l'installation d'extension XS de Perl.

C'est un module optionnel pour MailBox, et il sera (une fois installé) automatiquement utilisé par MailBox pour analyser le contenu des messages de courrier électronique lorsque le message est fourni sous forme de flux de fichiers. Dans tous les autres cas, MailBox utilisera Mail::Box::Parser::Perl.

Ceci est une version de maintenance pour l'ancienne interface. Lisez https://github.com/markov2/perl5-Mail-Box/wiki/ pour savoir comment passer à la version 4.
