NOM

Mail::Box::Search::Grep - sélectionner des messages dans une boîte aux lettres comme le fait grep

HIÉRARCHIE

Mail::Box::Search::Grep
  est un Mail::Box::Search
  est un Mail::Reporter

SYNTAXE

use Mail::Box::Manager;
my $mgr    = Mail::Box::Manager->new;
my $folder = $mgr->open('Inbox');
my $filter = Mail::Box::Search::Grep->new(
   label => 'selected',
   in => 'BODY', match => qr/abc?d*e/
);
my @msgs   = $filter->search($folder);
my $filter = Mail::Box::Search::Grep->new(
  field => 'To',
  match => $my_email,
);
if($filter->search($message)) {...}

DESCRIPTION

Essayer de trouver des chaînes de texte dans l'en-tête et le pied de page des messages. Divers moyens de limiter la recherche à certains champs d'en-tête, à l'en-tête entier, au corps uniquement, au message entier, mais même aux parties multiples binaires, sont fournis.

Le nom grep est dérivé de l'outil UNIX grep, qui signifie : "Get Regular Expression and Print" (Obtenir une expression régulière et imprimer). Bien que vous puissiez rechercher en utilisant des expressions régulières (à la manière de Perl), vous n'êtes pas obligé d'imprimer ces résultats.

binaries => BOOLEAN
decode => BOOLEAN
delayed => BOOLEAN
deleted => BOOLEAN
deliver => undef|CODE|'DELETE'|LABEL|'PRINT'|REF-ARRAY
Stocker les détails sur l'endroit où la correspondance a été trouvée. La recherche peut prendre beaucoup plus de temps lorsque cette fonction est activée.

Lorsqu'un ARRAY est spécifié, il contiendra une liste de références vers des hachages. Chaque hachage contient les informations d'une correspondance. Une correspondance dans une ligne d'en-tête entraînera une ligne avec les champs "message", "part" et "field", où le champ est un objet Mail::Message::Field. Lorsque la correspondance se trouve dans le corps, le hachage contiendra un "message", "part", "linenr" et "line".

En cas de référence CODE, cette routine est appelée pour chaque correspondance. Le premier argument est cet objet de recherche et le second une référence au même hachage qui serait stocké dans le tableau.

L'option "PRINT" appellera printMatchedHead() ou printMatchedBody() lorsqu'une ligne d'en-tête ou de corps correspondante est trouvée. La sortie est minimisée en n'imprimant pas à nouveau les informations du message sur des correspondances multiples dans le même message.

"DELETE" marquera le message comme à supprimer en cas de correspondance. Lorsqu'une partie d'une partie multiple est mise en correspondance, le message entier sera marqué pour suppression.

field => undef|$field|REGEX|CODE
Non valide en combinaison avec l'option "in" réglée sur "BODY". Transmet un nom de $field complet (insensible à la casse). Utilise une REGEX pour sélectionner plusieurs lignes d'en-tête à analyser. CODE est une routine qui est appelée pour chaque champ de l'en-tête. CODE est appelée avec l'en-tête comme premier argument et le champ comme second argument. Si CODE renvoie "vrai", le message est sélectionné.
in => 'HEAD'|'BODY'|'MESSAGE'
label => $label
limit => $nombre
log => LEVEL
logical => 'REPLACE'|'AND'|'OR'|'NOT'|'AND NOT'|'OR NOT'
match => STRING|REGEX|CODE
Le modèle à rechercher peut être une EXPRESSION RÉGULIÈRE, ou une CHAÎNE. Dans les deux cas, la correspondance réussit si elle est trouvée n'importe où dans les champs sélectionnés.

Avec une référence CODE, cette fonction sera appelée pour chaque champ ou ligne de corps. Lorsque le résultat est "vrai", les détails sont livrés. Les formats d'appel sont

$code->($head, $field);          # pour les recherches HEAD
$code->($body, $linenr, $line);  # pour les recherches BODY

Le $head ou $body sont respectivement la tête ou le corps d'un message. Le $field est une ligne d'en-tête qui correspond. Le $line et le $linenr indiquent la ligne correspondante dans le corps.

Attention, lorsque vous recherchez dans "MESSAGE", le code doit accepter les deux formats.

multiparts => BOOLEAN
trace => LEVEL
