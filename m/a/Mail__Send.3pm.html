NOM

Mail::Send - Interface simple de messagerie électronique

SYNTAXE

require Mail::Send;
$msg = Mail::Send->new;
$msg = Mail::Send->new(Subject => 'exemple', To => 'timbo');
$msg->to('utilisateur@hote');
$msg->to('utilisateur@hote', 'utilisateur2@example.com');
$msg->subject('sujet d\'exemple');
$msg->cc('utilisateur@hote');
$msg->bcc('quelqun@ailleurs');
$msg->set($header, @valeurs);
$msg->add($header, @valeurs);
$msg->delete($header);
# Lance le programme de messagerie et définit les en-têtes. Le descripteur de fichier retourné
# par open() est une instance de la classe Mail::Mailer.
# Les arguments passés à la méthode open() sont transmis au constructeur Mail::Mailer.
$fh = $msg->open;   # un programme de messagerie par défaut
$fh = $msg->open('sendmail'); # explicite
print $fh "Corps du message";
$fh->close          # termine le message et l'envoie
    or die "impossible d'envoyer le message entier : $!\n";

DESCRIPTION

Mail::Send crée des messages électroniques sans utiliser les connaissances de Mail::Header, ce qui signifie que toute l'échappement et le pliage doivent être faits par vous ! De plus : n'oubliez pas d'échapper les points en début de ligne. La simplicité a son prix.

Lorsque vous aurez le temps, jetez un œil à Mail::Transport qui fait partie de la suite MailBox.

MÉTHODES

Constructeurs

Mail::Send->new(PAIRS)
Une liste de champs d'en-tête (fournis sous forme de PAIRES clé-valeur) peut être utilisée pour initialiser l'objet, limitée aux quelques-uns fournis sous forme de méthodes : "to", "subject", "cc", et "bcc". Pour les autres champs d'en-tête, utilisez add().

Champs d'en-tête

$obj->add($nom_champ, @valeurs)
Ajoute des valeurs à la liste des valeurs définies pour le $nom_champ.
$obj->bcc(@valeurs)
$obj->cc(@valeurs)
$obj->delete($nom_champ)
$obj->set($nom_champ, @valeurs)
Les @valeurs remplaceront les anciennes valeurs pour le $nom_champ. La liste des valeurs après modification est retournée.
$obj->subject(@valeurs)
$obj->to(@valeurs)

Envoi

$obj->open(%options)
Les %options sont utilisées pour initier un objet programme de messagerie via Mail::Mailer::new(). Ensuite, Mail::Mailer::open() est appelé avec les informations collectées dans cet objet "Mail::Send".

Attention : ce module implémente le smtp brut, ce qui signifie que vous devez échapper les lignes commençant par un point en en ajoutant un devant.
