NOM

PhishTag - Plugin SpamAssassin pour rediriger les liens dans les e-mails entrants.

SYNOPIS

loadplugin     Mail::SpamAssassin::Plugin::PhishTag
trigger_ratio    0.1
trigger_target   RULE_NAME  http://www.antiphishing.org/consumer_recs.html

DESCRIPTION

PhishTag permet aux administrateurs de réécrire les liens dans les e-mails qui déclenchent certains tests, de préférence les tests de blocage anti-hameçonnage. Le plugin inhibera le blocage d'une partie des e-mails qui déclenchent le test par SpamAssassin, et les laissera passer dans la boîte de réception des utilisateurs après la réécriture. Il est utile pour former les utilisateurs d'e-mails sur les politiques de l'entreprise et l'utilisation générale des e-mails.

OPTIONS

Les options suivantes peuvent être définies en modifiant le fichier de configuration.

  • trigger_ratio pourcentage_valeur

    Définit la probabilité en pourcentage que un test positif déclenche la réécriture de l'e-mail, par exemple 0.1 réécrira en moyenne 1 e-mail sur 1000 qui correspondent au déclencheur.

  • trigger_target NOM_REGLE url_http

    Le nom du test qui déclencherait la réécriture de l'e-mail ; tous les URL seront remplacés par url_http.
