NOM

FreeMail - vérifie les en-têtes/corps des messages pour les domaines de courriels gratuits

SYNOPSIS

Si, par exemple, l'adresse de l'expéditeur est un courriel gratuit, et que l'adresse Reply-To ou une adresse trouvée dans le corps du message est une autre adresse de courriel gratuit, renvoie succès. Bon signe pour les arnaques nigérianes, etc. Idée de test de Marc Perkel.

Dispose également de fonctions distinctes pour vérifier diverses parties du message concernant les courriels gratuits.

CONFIGURATION

freemail_domains domaine ...

Liste des domaines à utiliser dans les vérifications.
Les expressions régulières ne sont pas prises en charge, mais les caractères génériques suivants fonctionnent :
? pour un seul caractère (ne correspond pas à un point)
* pour plusieurs caractères (ne correspond pas à un point)
Par exemple :
freemail_domains hotmail.com hotmail.co.?? yahoo.* yahoo.*.*

freemail_welcomelist email/domaine ...

Précédemment freemail_whitelist qui fonctionnera de manière interchangeable jusqu'à la version 4.1.
Les emails ou domaines listés ici sont ignorés (prétendez qu'ils ne sont pas
des courriels gratuits). Pas de caractères génériques !

freemail_import_welcomelist_auth 1/0

Les entrées dans welcomelist_auth seront également utilisées pour considérer les emails
ou domaines comme non gratuits. Par défaut : 0.

freemail_import_def_welcomelist_auth 1/0

Les entrées dans def_welcomelist_auth seront également utilisées pour considérer les emails
ou domaines comme non gratuits. Par défaut : 0.

header FREEMAIL_REPLYTO eval:check_freemail_replyto(['option'])

Vérifie/compare les adresses de courriels gratuits trouvées dans les en-têtes et le corps.
Options possibles :
replyto      L'adresse From: ou du corps est différente de celle de Reply-To
             (c'est le comportement par défaut)
reply        comme ci-dessus, mais si aucun en-tête Reply-To n'est trouvé,
             compare From: et le corps

header FREEMAIL_FROM eval:check_freemail_from(['regex'])

Vérifie tous les en-têtes "from" possibles pour voir si l'expéditeur est un courriel gratuit.
Utilise la fonction SA all_from_addrs() (inclut 'Resent-From', 'From',
'EnvelopeFrom', etc.).
Ajoutez une expression régulière optionnelle pour faire correspondre les adresses email trouvées. Par exemple,
pour vérifier si l'utilisateur se termine par un chiffre : check_freemail_from('\d@')
Si vous utilisez plusieurs règles check_freemail_from avec des expressions régulières, rappelez-vous
qu'elles peuvent correspondre à différents emails provenant de différents en-têtes. Pour faire correspondre
uniquement un en-tête spécifique, utilisez check_freemail_header.

header FREEMAIL_HDRX eval:check_freemail_header('en-tête' [, 'regex'])

Recherche dans l'en-tête défini une adresse de courriel gratuit. Expression régulière optionnelle pour faire correspondre
l'adresse trouvée (comme dans check_freemail_from).

header FREEMAIL_BODY ['regex'])

Recherche dans le corps une adresse de courriel gratuit. Avec une expression régulière optionnelle pour faire correspondre.
