NOM

Mail::Box::Mbox::Message - un message dans un dossier Mbox

HEREDITE

Mail::Box::Mbox::Message
  est un Mail::Box::File::Message
  est un Mail::Box::Message
  est un Mail::Message
  est un Mail::Reporter

SYNTAXE

my $folder  = Mail::Box::Mbox->new(folder => $ENV{MAIL}, ...);
my $message = $folder->message(0);

DESCRIPTION

Gère un message dans un dossier Mail::Box::Mbox.

Étendu de "DESCRIPTION" dans Mail::Box::File::Message.

METHODES

Étendu de "METHODS" dans Mail::Box::File::Message.

DIAGNOSTICS

Erreur: Impossible de coercer un objet $class en un objet $class
Causé par coerce()
Erreur: Impossible d'inclure la source de transfert en tant que $include.
Alternative inconnue pour le transfert (inclure). Les choix valides sont "NO", "INLINE", "ATTACH", et "ENCAPSULATE". Causé par forward()
Erreur: Impossible d'inclure la source de réponse en tant que $include.
Alternative inconnue pour l'option "include" de reply(). Les choix valides sont "NO", "INLINE", et "ATTACH". Causé par reply()
Erreur: La méthode bounce nécessite To, Cc, ou Bcc
La méthode bounce() transfère un message reçu à quelqu'un d'autre sans modification ; vous devez spécifier sa nouvelle destination. Si vous avez l'envie de ne pas spécifier de destination, vous recherchez probablement reply(). Lorsque vous souhaitez modifier le contenu, utilisez forward(). Causé par bounce()
Erreur: La méthode forwardAttach nécessite un préambule
Causé par forwardAttach()
Erreur: La méthode forwardEncapsulate nécessite un préambule
Causé par forwardEncapsulate()
Erreur: Aucune adresse pour créer le transfert.
Si un message de transfert est créé, une adresse de destination doit être spécifiée. Causé par forward()
Erreur: Aucun agent d'envoi de courrier par défaut trouvé pour envoyer le message.
Le mécanisme send() du message n'avait pas assez d'informations pour trouver automatiquement un agent de transfert de courrier pour envoyer ce message. Spécifiez un agent de transfert explicitement en utilisant l'option "via". Causé par send()
Erreur: Aucune règle de reconstruction $name définie.
Causé par rebuild()
Erreur: Seulement les Mail::Message's build(); ils ne sont pas encore dans un dossier
Vous souhaitiez peut-être construire un message à stocker dans une sorte de dossier, mais vous devez le faire en deux étapes. D'abord, créez un Mail::Message normal, puis ajoutez-le au dossier. Pendant ce processus Mail::Box::addMessage(), le message sera coerce()-d dans le bon type de message, ajoutant des informations de stockage et autres. Causé par build()
Erreur: Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode alors qu'il le devrait. Ce message signifie que certaines autres classes liées implémentent cette méthode, mais la classe en question ne le fait pas. Vous devriez probablement enquêter là-dessus et peut-être informer l'auteur du paquet. Causé par notImplemented()
Erreur: Impossible de lire le corps retardé.
Causé par loadBody()
Erreur: la coercition commence avec un certain objet
Causé par coerce()
