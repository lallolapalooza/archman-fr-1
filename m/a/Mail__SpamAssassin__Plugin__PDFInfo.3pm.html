NOM

Mail::SpamAssassin::Plugin::PDFInfo - Plugin PDFInfo pour SpamAssassin

SYNTAXE

loadplugin     Mail::SpamAssassin::Plugin::PDFInfo

DESCRIPTION

Ce plugin aide à détecter les spams utilisant des fichiers PDF joints.

Voir "Utilisation:" ci-dessous - plus de documentation se trouve dans 20_pdfinfo.cf

Plugin PDFInfo pour SpamAssassin

Changements:
  0.8 - ajout de la détection .fdf (merci John Lundin) [axb]
  0.7 - correction du bug de compte de corps/pdf vide (merci Jeremy) [axb]
  0.6 - ajout du support des balises - PDFCOUNT, PDFVERSION, PDFPRODUCER, etc.
      - correction du problème sur perl 5.6.1 où pdf_match_details() n'arrivait pas à appeler
        _find_pdf_mime_parts(), ce qui entraînait aucune détection des parties mime pdf.
      - support quoted-printable - nécessite MIME::QuotedPrint (qui devrait être dans chaque
        installation comme partie du paquet MIME-Base64 qui est une exigence de SA)
      - ajout de la fonction simple pdf_is_empty_body() qui compte les octets du corps moins la
        ligne de sujet. Peut ajouter un paramètre <octets> optionnel si vous avez besoin d'autoriser quelques octets.
  0.5 - correction des avertissements pour undef $pdf_tags
      - suppression de { } et \ avant d'exécuter eval dans pdf_match_details pour éviter les erreurs eval
  0.4 - ajout de la fonction pdf_is_encrypted()
      - ajout d'une option pour rechercher la hauteur/largeur d'image sur la même ligne
  0.3 - ajout d'une 2ème md5 floue qui utilise la disposition des balises pdf comme données
      - renommage de pdf_image_named() en pdf_named()
         - Les images PDF sont encapsulées et n'ont pas de noms. Nous faisons correspondre le nom de fichier PDF.
      - renommage de pdf_image_name_regex() en pdf_name_regex()
         - Les images PDF sont encapsulées et n'ont pas de noms. Nous faisons correspondre le nom de fichier PDF.
      - légère modification de pdf_image_count() et ajout de pdf_count().
         - pdf_count() vérifie combien de pièces jointes pdf il y a dans le mail
         - pdf_image_count() vérifie combien d'images sont trouvées dans tous les pdf du mail.
      - suppression de la restriction selon laquelle le pdf doit contenir une image pour être md5.
      - ajout de la fonction pdf_match_details() pour vérifier les 'détails' suivants :
         - author: Auteur du PDF si spécifié
         - producer: Logiciel utilisé pour produire le PDF
         - creator: Logiciel utilisé pour produire le PDF, généralement similaire à producer
         - title: Titre du PDF
         - created: Date de création
         - modified: Dernière modification
  0.2 - support de l'octet-stream PDF
  0.1 - simple portage du code de imageinfo, et renommé en pdfinfo.
        - suppression de tout le support de png, gif et jpg du code.
        - préfixage de pdf_ à tous les noms de fonctions pour éviter les conflits avec ImageInfo dans SA 3.2.
Utilisation:
 pdf_count()
    body RULENAME  eval:pdf_count(<min>,[max])
       min: requis, le message contient au moins x parties mime pdf
       max: optionnel, si spécifié, ne doit pas contenir plus de x parties mime pdf
 pdf_image_count()
    body RULENAME  eval:pdf_image_count(<min>,[max])
       min: requis, le message contient au moins x images dans les pièces jointes pdf.
       max: optionnel, si spécifié, le message ne doit pas contenir plus de x images pdf
 pdf_pixel_coverage()
    body RULENAME  eval:pdf_pixel_coverage(<min>,[max])
       min: requis, le message contient au moins cette zone de pixels
       max: optionnel, si spécifié, le message ne doit pas contenir plus que cette zone de pixels
 pdf_named()
    body RULENAME  eval:pdf_named(<string>)
       string: correspondance exacte du nom de fichier, si vous avez besoin d'une correspondance partielle, voir pdf_name_regex()
 pdf_name_regex()
    body RULENAME  eval:pdf_name_regex(<regex>)
       regex: expression régulière, voir exemples dans les règles
 pdf_match_md5()
    body RULENAME  eval:pdf_match_md5(<string>)
       string: md5 hex de 32 octets
 pdf_match_fuzzy_md5()
    body RULENAME  eval:pdf_match_md5(<string>)
       string: md5 hex de 32 octets - voir les règles pour obtenir le md5 flou
 pdf_match_details()
    body RULENAME  eval:pdf_match_details(<detail>,<regex>);
       detail: author, creator, created, modified, producer, title
       regex: expression régulière, voir exemples dans les règles
 pdf_is_encrypted()
    body RULENAME eval:pdf_is_encrypted()
 pdf_is_empty_body()
    body RULENAME eval:pdf_is_empty_body(<bytes>)
       bytes: nombre maximum d'octets à autoriser et à considérer comme vide
 pdf_image_to_text_ratio()
    body RULENAME eval:pdf_image_to_text_ratio(<min>,<max>)
       Ratio calculé comme longueur_du_corps / zone_totale_image
       min: ratio minimum
       max: ratio maximum
 pdf_image_size_exact()
    body RULENAME eval:pdf_image_size_exact(<h>,<w>)
       h: hauteur de l'image exactement h
       w: largeur de l'image exactement w
 pdf_image_size_range()
    body RULENAME eval:pdf_image_size_range(<minh>,<minw>,[<maxh>],[<maxw>])
       minh: hauteur de l'image au moins minh
       minw: largeur de l'image au moins minw
       maxh: (optionnel) hauteur de l'image au plus maxh
       maxw: (optionnel) largeur de l'image au plus maxw
 REMARQUE : Voir les règles pour plus d'exemples qui ne sont pas documentés ici.
