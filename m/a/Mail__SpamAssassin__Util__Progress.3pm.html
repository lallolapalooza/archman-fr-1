NOM

Mail::SpamAssassin::Util::Progress - Support de barre de progression pour SpamAssassin

SYNOPSIS

my $progress = Mail::SpamAssassin::Util::Progress->new({total => 100});
$msgcount = 0;
foreach my $message (@messages) {
  # faire quelque chose ici
  $msgcount++;
  $progress->update($msgcount);
}
$progress->final();

DESCRIPTION

Ce module implémente une barre de progression destinée à être utilisée dans les scripts et modules SpamAssassin. Il vous permet de créer la barre de progression, de la mettre à jour et d'afficher les résultats finaux d'une exécution particulière.

new

classe publique (Mail::SpamAssassin::Util::Progress) new (\% $args)

Description : Crée un nouvel objet Mail::SpamAssassin::Util::Progress, les valeurs valides pour le hashref $args sont :

total (requis)
Le nombre total de messages attendus à traiter. Cet élément est requis.
fh [optionnel]
Un descripteur de fichier optionnel peut être passé, sinon STDERR sera utilisé par défaut.
term [optionnel]
Le module tentera de déterminer si un terminal valide existe sur le descripteur de fichier STDIN. Cet élément vous permet de remplacer cette valeur.

init_bar

instance publique () init_bar()

Description : Cette méthode crée la barre de progression initiale et est appelée automatiquement depuis new. De plus, vous pouvez appeler init_bar sur un objet existant pour réinitialiser la barre à son état d'origine.

update

instance publique () update ([Integer $num_done])

Description : Cette méthode est celle qui est appelée pour mettre à jour la barre de progression. Vous pouvez éventuellement passer une valeur entière indiquant le nombre de messages traités. Si vous ne passez rien, la valeur num_done sera incrémentée de un.

final

instance publique () final ([Integer $num_done])

Description : Cette méthode doit être appelée une fois tout le traitement terminé. Elle affichera le calcul final des messages par seconde et le temps total écoulé. Vous pouvez éventuellement passer une valeur num_done, sinon elle utilisera la valeur calculée lors du dernier appel à update.
