NOM

Mail::Address - analyse les adresses électroniques

SYNTAXE

use Mail::Address;
my @addrs = Mail::Address->parse($line);
foreach $addr (@addrs) {
    print $addr->format,"\n";
}

DESCRIPTION

"Mail::Address" extrait et manipule les adresses électroniques d'un en-tête de message. Il ne peut pas être utilisé pour extraire des adresses d'un texte quelconque. Vous pouvez utiliser ce module pour créer des champs conformes à RFC822.

Bien que "Mail::Address" soit un sujet très populaire pour les livres, et soit utilisé dans de nombreuses applications, il fait un très mauvais travail sur les champs de message les plus complexes. Il ne gère que les formats d'adresse simples (ce qui couvre environ 95% de ce que l'on peut trouver). Les problèmes concernent

  • pas de support pour les groupes d'adresses, même pas avec le point-virgule comme séparateur entre les adresses ;
  • support limité des échappements dans les phrases et les commentaires. Il y a des cas où il peut se tromper ; et
  • vous devez prendre soin de la plupart des échappements lorsque vous créez une adresse vous-même : "Mail::Address" ne le fait pas pour vous.

Souvent, des demandes sont faites aux mainteneurs de ce code pour améliorer cette situation, mais ce n'est pas une bonne idée, car cela casserait des milliards d'applications existantes. Si vous souhaitez une implémentation entièrement conforme à la RFC2822, vous pouvez jeter un œil à Mail::Message::Field::Full, partie de MailBox.

. Exemple

my $s = Mail::Message::Field::Full->new($from_header);
# ref $s isa Mail::Message::Field::Addresses;
my @g = $s->groups;          # tous les groupes, au moins un
# ref $g[0] isa Mail::Message::Field::AddrGroup;
my $ga = $g[0]->addresses;   # adresses du groupe
my @a = $s->addresses;       # toutes les adresses
# ref $a[0] isa Mail::Message::Field::Address;

MÉTHODES

Constructeurs

Mail::Address->new( $phrase, $adresse, [ $commentaire ] )
Crée un nouvel objet "Mail::Address" qui représente une adresse avec les éléments donnés. Dans un message, ces 3 éléments seraient vus comme suit : 
PHRASE <ADRESSE> (COMMENTAIRE)
ADRESSE (COMMENTAIRE)

exemple :

Mail::Address->new("Perl5 Porters", "perl5-porters@africa.nicoh.com");
$obj->parse($ligne)
Analyse la ligne donnée et retourne une liste d'objets "Mail::Address" extraits. La ligne serait normalement une prise depuis une ligne To, Cc ou Bcc d'un message.

exemple :

my @addr = Mail::Address->parse($line);

Accesseurs

$obj->address()
Retourne la partie adresse de l'objet.
$obj->comment()
Retourne la partie commentaire de l'objet.
$obj->format(@adresses)
Retourne une chaîne représentant l'adresse dans une forme appropriée pour être placée sur une ligne "To", "Cc", ou "Bcc" d'un message. Cette méthode est appelée sur la première adresse à utiliser ; les autres adresses spécifiées seront ajoutées, séparées par des virgules.
$obj->phrase()
Retourne la partie phrase de l'objet.

Accesseurs intelligents

$obj->host()
Retourne l'adresse sans l'identifiant utilisateur et le '@'
$obj->name()
En utilisant les informations contenues dans l'objet, tente d'identifier le nom de la personne ou du groupe.

Note : Cette fonction essaie d'être intelligente avec la "phrase" de l'adresse électronique, ce qui est probablement une très mauvaise idée. Envisagez d'utiliser phrase() lui-même.

$obj->user()
Retourne l'adresse sans le '@' et le domaine de messagerie.
