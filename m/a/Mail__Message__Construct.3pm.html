NOM

Mail::Message::Construct - étend la fonctionnalité d'un Mail::Message

SYNOPSIS

# Voir Mail::Message

DESCRIPTION

Des fonctionnalités complexes sur les objets Mail::Message sont implémentées dans différents fichiers qui sont chargés automatiquement. Ce fichier implémente les fonctionnalités liées à la création de réponses aux messages.

Les constructeurs suivants sont disponibles :

Mail::Message::Construct::Bounce
Mail::Message::Construct::Build
Mail::Message::Construct::Forward
Mail::Message::Construct::Read
Mail::Message::Construct::Rebuild
Mail::Message::Construct::Reply
Mail::Message::Construct::Text

MÉTHODES

$obj->AUTOLOAD()
Lorsqu'une méthode inconnue est appelée sur ce message, cela peut signifier que tout le code n'est pas compilé. Pour des raisons de performance, la plupart des activités complexes sur les messages sont chargées dynamiquement à partir d'autres paquets. Une erreur sera produite si le chargement n'aide pas à résoudre la méthode demandée. Améliore la base, voir "Gestion des erreurs" dans Mail::Reporter
