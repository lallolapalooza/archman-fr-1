Math::BigInt::FastCalc(3perl) Guide de référence du programmeur Perl Math::BigInt::FastCalc(3perl)

NOM

Math::BigInt::FastCalc - Math::BigInt::Calc avec des extensions XS pour plus de vitesse

SYNOPIS

# pour l'utiliser avec Math::BigInt
use Math::BigInt lib => 'FastCalc';
# pour l'utiliser avec Math::BigFloat
use Math::BigFloat lib => 'FastCalc';
# pour l'utiliser avec Math::BigRat
use Math::BigRat lib => 'FastCalc';

DESCRIPTION

Math::BigInt::FastCalc hérite de Math::BigInt::Calc.

Fournit un support pour les calculs avec des grands entiers. N'est pas destiné à être utilisé par d'autres modules. D'autres modules qui proposent les mêmes fonctions peuvent également être utilisés pour supporter Math::BigInt, comme Math::BigInt::GMP ou Math::BigInt::Pari.

Afin de permettre l'utilisation de plusieurs bibliothèques de grands entiers, Math::BigInt a été réécrit pour utiliser des modules bibliothèques pour les routines mathématiques de base. Tout module qui suit la même API que celle-ci peut être utilisé à la place en utilisant le code suivant :

use Math::BigInt lib => 'libname';

'libname' est soit le nom complet ('Math::BigInt::Pari'), soit seulement la version courte comme 'Pari'. Pour utiliser cette bibliothèque :

use Math::BigInt lib => 'FastCalc';

Le comportement par défaut est de choisir la meilleure représentation interne des grands entiers, mais la longueur de base utilisée dans la représentation interne peut être spécifiée explicitement. Notez que cela doit être fait avant que Math::BigInt ne soit chargé. Par exemple,

use Math::BigInt::FastCalc base_len => 3;
use Math::BigInt lib => 'FastCalc';

STOCKAGE

Math::BigInt::FastCalc fonctionne exactement comme Math::BigInt::Calc. Les nombres sont stockés sous forme décimale, découpés en parties.

MÉTHODES

Les fonctions suivantes sont maintenant implémentées dans FastCalc.xs :

_is_odd         _is_even        _is_one         _is_zero
_is_two         _is_ten
_zero           _one            _two            _ten
_acmp           _len
_inc            _dec
__strip_zeros   _copy
