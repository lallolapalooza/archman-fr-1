NOM

Mail::Field::Generic - implémentation pour les champs non spécifiques

HÉRITAGE

Mail::Field::Generic
  est un Mail::Field

SYNOPSIS

use Mail::Field;
my $field = Mail::Field->new('Subject', 'some subject text');
my $field = Mail::Field->new(subject => 'some subject text');

DESCRIPTION

Une implémentation générique pour les champs d'en-tête sans implémentation propre. Ceci convient pour les champs comme "Subject", "X-Mailer", etc., où le champ ne contient qu'une chaîne de caractères sans importance/format particulier.

DIAGNOSTICS

Erreur : sous-routine indéfinie <méthode> appelée
Les objets Mail::Field utilisent l'autoloading pour compiler de nouvelles fonctionnalités. Apparemment, la méthode appelée n'est pas implémentée pour la classe spécifique de l'objet champ.
