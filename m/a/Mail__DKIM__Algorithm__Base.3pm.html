NOM

Mail::DKIM::Algorithm::Base - classe de base pour les « algorithmes » DKIM

VERSION

version 1.20240923

SYNOPSIS

my $algorithm = new Mail::DKIM::Algorithm::rsa_sha1(
                    Signature => $dkim_signature
                );
# ajouter les en-têtes
$algorithm->add_header("Subject: ceci est le sujet\015\012");
$algorithm->finish_header;
# ajouter le corps
$algorithm->add_body("Ceci est le corps.\015\012");
$algorithm->add_body("Une autre ligne du corps.\015\012");
$algorithm->finish_body;
# maintenant signer ou vérifier...
# TODO...

CONSTRUCTEUR

Vous ne devriez pas créer un objet de cette classe directement. Utilisez plutôt l'une des classes d'implémentation d'algorithme DKIM, comme rsa_sha1 :

my $algorithm = new Mail::DKIM::Algorithm::rsa_sha1(
                    Signature => $dkim_signature
                );

MÉTHODES

add_body() - alimente une partie du corps dans l'algorithme/la canonisation

$algorithm->add_body("Ceci est le corps.\015\012");
$algorithm->add_body("Une autre ligne du corps.\015\012");

Le corps doit être alimenté ligne par ligne.

add_header() - alimente un champ d'en-tête dans l'algorithme/la canonisation

$algorithm->add_header("Subject: ceci est le sujet\015\012");

L'en-tête doit commencer par le nom du champ d'en-tête et se poursuivre à travers toutes les lignes pliées (y compris les séquences <CRLF> intégrées). Il se termine par le <CRLF> à la fin du champ d'en-tête.

finish_body() - signale la fin du corps du message

$algorithm->finish_body

Appelez cette méthode lorsque toutes les lignes du corps ont été soumises. Après avoir appelé cette méthode, utilisez sign() ou verify() pour obtenir les résultats de l'algorithme.

finish_header() - signale la fin du bloc d'en-têtes

$algorithm->finish_header;

Appelez cette méthode lorsque tous les en-têtes ont été soumis.

sign() - génère une signature à l'aide d'une clé privée

$base64 = $algorithm->sign($private_key);

signature() - obtient/définit la signature sur laquelle travaille cet algorithme

my $old_signature = $algorithm->signature;
$algorithm->signature($new_signature);

verify() - vérifie une signature

$result = $algorithm->verify();

Doit être appelé après finish_body().

Le résultat est une valeur vraie/fausse : vrai indique que les données de signature sont valides, faux indique qu'elles sont invalides.

Pour une signature invalide, les détails peuvent être obtenus à partir de $algorithm->{verification_details} ou $@.
