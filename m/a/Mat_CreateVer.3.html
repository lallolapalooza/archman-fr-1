Mat_CreateVer(3)

Paquet: libmatio

Licences: BSD-2-Clause

MAT_CREATEVER(3) Manuel des fonctions de bibliothèque MAT_CREATEVER(3)

NOM

Mat_CreateVer, Mat_Create — Crée un fichier MAT MATLAB.

SYNTAXE

#include <matio.h>

mat_t *
Mat_CreateVer(const char *matname, const char *hdr_str, enum mat_ft mat_file_ver);

mat_t *
Mat_Create(const char *matname, const char *hdr_str);

DESCRIPTION

La fonction Mat_CreateVer() crée un fichier MAT MATLAB ouvert en accès en écriture. Le paramètre hdr_str est une chaîne de caractères écrite dans l'en-tête du fichier pour les versions MAT 5 et 7.3 (HDF). Seuls les 128 premiers octets de la chaîne sont écrits. Si hdr_str est NULL, une chaîne par défaut est écrite, contenant la plateforme, la date, et la version de la bibliothèque matio.

Le paramètre mat_file_ver spécifie la version du fichier MAT à créer. La bibliothèque matio peut écrire des fichiers version 4 (MAT_FT_MAT4), version 5 (MAT_FT_MAT5) et un format de fichier HDF5 introduit dans la version 7.3 de MATLAB (MAT_FT_MAT73).

La fonction Mat_Create() est équivalente à un appel de Mat_CreateVer() avec MAT_FT_DEFAULT comme version de fichier.

EXEMPLES

#include <stdlib.h>
#include <stdio.h>
#include "matio.h"

int main(int argc, char **argv)
{
    mat_t *matfp;

    matfp = Mat_CreateVer(argv[1], NULL, MAT_FT_73);
    if ( NULL == matfp ) {
        fprintf(stderr, "Erreur lors de la création du fichier MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
