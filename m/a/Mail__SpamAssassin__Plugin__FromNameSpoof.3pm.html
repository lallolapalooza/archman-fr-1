NOM

FromNameSpoof - Effectue divers tests pour détecter les tentatives d'usurpation d'identité en utilisant la section du nom dans l'en-tête From

SYNOPIS

loadplugin Mail::SpamAssassin::Plugin::FromNameSpoof

# Le nom et l'adresse From ne correspondent pas, la correspondance dépend du paramètre C<fns_check>
header  __PLUGIN_FROMNAME_SPOOF  eval:check_fromname_spoof()
# Le nom et l'adresse From ne correspondent pas (identique à la règle ci-dessus et C<fns_check 0>)
header  __PLUGIN_FROMNAME_DIFFERENT  eval:check_fromname_different()
# Les domaines du nom et de l'adresse From diffèrent
header  __PLUGIN_FROMNAME_DOMAIN_DIFFER  eval:check_fromname_domain_differ()
# Le nom From ressemble à une adresse e-mail (pas identique à l'adresse From)
header  __PLUGIN_FROMNAME_EMAIL  eval:check_fromname_contains_email()
# Le nom From correspond à une adresse To:
header  __PLUGIN_FROMNAME_EQUALS_TO  eval:check_fromname_equals_to()
# Les propriétaires du nom et de l'adresse From diffèrent
header  __PLUGIN_FROMNAME_OWNERS_DIFFER  eval:check_fromname_owners_differ()
# Le nom From correspond à l'adresse Reply-To:
header  __PLUGIN_FROMNAME_EQUALS_REPLYTO  eval:check_fromname_equals_replyto()

DESCRIPTION

Effectue divers tests sur l'en-tête From:name pour détecter les usurpations d'identité. Des mesures sont en place pour garantir un minimum de faux positifs.

CONFIGURATION

Le plugin vous permet d'ignorer les e-mails qui ont été signés par DKIM par des expéditeurs spécifiques :

fns_ignore_dkim googlegroups.com

FromNameSpoof permet une proximité configurable lors de la correspondance entre From:addr et From:name, la proximité peut être ajustée avec :

fns_extrachars 50

Note : FromNameSpoof détecte le "propriétaire" d'un domaine par la recherche suivante :

<propriétaire>.<tld>

Par défaut, FromNameSpoof ignore le TLD lors de la comparaison des adresses :

fns_check 1

Niveaux de vérification :

0 - Vérification stricte de From:name != From:addr
1 - Autorise les TLD différents
2 - Autorise les alias différents mais le même domaine

Les informations de "propriétaire" peuvent également être mappées comme alias avec "fns_add_addrlist". Par exemple, pour considérer "googlemail.com" comme "gmail" :

fns_add_addrlist (gmail) *@googlemail.com

TAGS

Les balises suivantes sont ajoutées à l'ensemble si une usurpation d'identité est détectée. Elles sont disponibles pour être utilisées dans les rapports, les champs d'en-tête, d'autres plugins, etc. :

_FNSFNAMEADDR_
  Adresse d'usurpation détectée à partir de l'en-tête From:name
_FNSFNAMEDOMAIN_
  Domaine d'usurpation détecté à partir de l'en-tête From:name
_FNSFNAMEOWNER_
  Propriétaire d'usurpation détecté à partir de l'en-tête From:name
_FNSFADDRADDR_
  Adresse From:addr réelle
_FNSFADDRDOMAIN_ 
  Domaine From:addr réel
_FNSFADDROWNER_
  Propriétaire From:addr réel

EXEMPLE

header  __PLUGIN_FROMNAME_SPOOF  eval:check_fromname_spoof()
header  __PLUGIN_FROMNAME_EQUALS_TO  eval:check_fromname_equals_to()
meta     FROMNAME_SPOOF_EQUALS_TO (__PLUGIN_FROMNAME_SPOOF && __PLUGIN_FROMNAME_EQUALS_TO)
describe FROMNAME_SPOOF_EQUALS_TO Le nom From est une usurpation pour ressembler à l'adresse To:
score    FROMNAME_SPOOF_EQUALS_TO 1.2
