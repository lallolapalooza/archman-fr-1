Nom

Mail::Box::Locker::Mutt - verrouiller un dossier en utilisant mutt_dotlock

Héritage

Mail::Box::Locker::Mutt
  est un Mail::Box::Locker
  est un Mail::Reporter

Synopsis

Voir Mail::Box::Locker

Description

Le lecteur de courrier « mutt » inclut un programme séparé qui est spécialisé dans le verrouillage des dossiers. Cette classe de verrou est basée sur ce programme externe. Le programme mutt n'est pas installé automatiquement.
