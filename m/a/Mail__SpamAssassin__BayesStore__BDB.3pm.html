Mail::SpamAssassin::BayesStore::BDB - Implémentation du module de stockage bayésien BDB

DESCRIPTION

Ce module implémente un module de stockage bayésien basé sur BDB.

get_storage_variables

instance publique (@) get_storage_variables ()

Description : Cette méthode récupère les diverses variables administratives utilisées par le processus Bayes et la base de données.

Les valeurs retournées dans le tableau sont dans l'ordre suivant :

0 : base de comptage de scan

1 : nombre de spams

2 : nombre de hams

3 : nombre de jetons dans la base de données

4 : heure d'accès la plus récente d'expiration

5 : heure d'accès la plus ancienne d'un jeton dans la base de données

6 : valeur de la version de la base de données

7 : dernière synchronisation du journal

8 : dernier delta d'heure d'accès

9 : dernier compteur de réduction d'expiration

10 : heure d'accès la plus récente d'un jeton dans la base de données

NOM

Mail::SpamAssassin::BayesStore::BDB

DESCRIPTION

Ce module fournit un stockage bayésien basé sur BDB (Berkeley DB), utilisé pour la détection de spam dans les messages électroniques.

MÉTHODES

Les fonctions disponibles sont les suivantes :

nspam_nham_get

instance publique ($spam_count, $ham_count)

Cette méthode récupère le nombre total de spams et le nombre total de ham appris.

nspam_nham_change

instance publique (Boolean) nspam_nham_change (Integer $num_spam, Integer $num_ham)

Cette méthode met à jour le nombre de spams et le nombre de ham dans la base de données.

tok_touch

instance publique (Boolean) tok_touch (String $token, String $atime)

Cette méthode met à jour la date de modification (atime) des jetons donnés ($token).

Il est supposé que le jeton existe déjà dans la base de données.

Les atimes des versions anciennes ne seront pas mises à jour.

tok_touch_all

instance publique (Boolean) tok_touch (\@ $tokens, String $atime)

Cette méthode effectue une mise à jour en masse des jetons donnés ($tokens), si l'atime existant est inférieure à ($atime).

Il est supposé que les jetons existent déjà dans la base de données.

Il est recommandé de ne pas toucher plus de N_SIGNIFICANT_TOKENS, de sorte que des hypothèses puissent être faites sur la manière de gérer les données (sans nécessiter de batch, comme dans tok_get_all).

cleanup

instance publique (Boolean) cleanup ()

Cette méthode effectue tout nettoyage nécessaire avant d'effectuer l'opération suivante.

get_magic_re

instance publique (String) get_magic_re ()

Cette méthode renvoie un modèle d'expression régulière qui indique un jeton magique.

Non utilisé dans l'implémentation BDB.

sync

instance publique (Boolean) sync (\% $opts)

Cette méthode effectue une synchronisation de la base de données.

perform_upgrade

instance publique (Boolean) perform_upgrade (\% $opts);

Cette méthode effectue une mise à niveau de la base de données d'une version à une autre, non utilisée dans cette implémentation.

clear_database

instance publique (Boolean) clear_database ()

Cette méthode supprime toutes les entrées pour un utilisateur donné.

Les appelants doivent noter que toute erreur renvoyée par cette méthode pourrait entraîner une incohérence de la base de données pour l'utilisateur donné.

backup_database

instance publique (Boolean) backup_database ()

Cette méthode effectue une sauvegarde de la base de données dans un format lisible par le système.

restore_database

instance publique (Boolean) restore_database (String $filename, Boolean $showdots)

Cette méthode restaure la base de données à partir du fichier donné ($filename).

Les appelants doivent noter que toute erreur renvoyée par cette méthode pourrait entraîner une incohérence de la base de données pour l'utilisateur donné.

db_readable

instance publique (Boolean) db_readable()

Cette méthode renvoie une valeur booléenne indiquant si la base de données est dans un état lisible.

db_writable

instance publique (Boolean) db_writable()

Cette méthode renvoie une valeur booléenne indiquant si la base de données est dans un état accessible en écriture.

_extract_atime

instance privée () _extract_atime (String $token, String $value, String $index)

Cette méthode garantit que la connexion à la base de données est correctement configurée et fonctionnelle. Si elle réussit, elle initialisera les variables bayésiennes de l'utilisateur afin qu'elles puissent commencer à utiliser la base de données immédiatement.
