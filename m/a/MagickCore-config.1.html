MAGICKCORE-CONFIG(1) Manuel des commandes générales MAGICKCORE-CONFIG(1)

NOM

MagickCore-config — obtenir des informations sur la version installée d'ImageMagick

SYNTAXE

MagickCore-config [--cflags] [--cppflags] [--exec-prefix] [--ldflags] [--libs] [--prefix] [--version]

DESCRIPTION

L'utilitaire MagickCore-config affiche les indicateurs du compilateur et de l'éditeur de liens requis pour compiler et lier des programmes qui utilisent l'interface de programmation applicative ImageMagick Core.

Les options suivantes sont disponibles :

--cppflags, --cflags, --cxxflags
Affiche les indicateurs du compilateur nécessaires pour trouver les fichiers d'inclusion C d'ImageMagick(1) et les définitions pour s'assurer que les structures de données ImageMagick correspondent entre votre programme et les bibliothèques installées.
--prefix, --exec-prefix
Affiche le répertoire sous lequel les binaires et exécutables spécifiques à la cible sont installés.
--ldflags, --libs
Affiche les indicateurs de l'éditeur de liens nécessaires pour lier avec la bibliothèque ImageMagick(1).
--version
Affiche la version de la distribution ImageMagick(1) sur la sortie standard.
--coder-path
Affiche le chemin où les modules de codeur d'ImageMagick(1) sont installés.
--filter-path
Affiche le chemin où les modules de filtre d'ImageMagick(1) sont installés.

EXEMPLES

Pour afficher la version de la distribution installée d'ImageMagick, utilisez :

MagickCore-config --version

Pour compiler un programme qui appelle l'interface de programmation applicative d'ImageMagick(1), utilisez :

cc `MagickCore-config --cppflags --ldflags` program.c
