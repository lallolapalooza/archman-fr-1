NOM

Mail::Box::MH::Message - un message dans un dossier MH

HÉRITAGE

Mail::Box::MH::Message
  est un Mail::Box::Dir::Message
  est un Mail::Box::Message
  est un Mail::Message
  est un Mail::Reporter

SYNOPIS

my $folder = new Mail::Box::MH ...
my $message = $folder->message(10);

DESCRIPTION

Une "Mail::Box::MH::Message" représente un message dans un dossier Mail::Box::MH. Chaque message est stocké dans un fichier séparé, comme pour tous les types de dossiers Mail::Box::Dir.

Le fichier .mh_sequences

Généralement, le fichier qui contient les étiquettes s'appelle ".mh_sequences". Les messages MH sont numérotés à partir de 1. Comme exemple de contenu pour ".mh_sequences" :

cur: 93
unseen: 32 35-56 67-80

Pour généraliser les étiquettes sur les messages, deux sont traitées spécialement :

  • cur

    Le "cur" spécifie le numéro du message où l'utilisateur a arrêté de lire les e-mails de ce dossier lors du dernier accès. Internement dans ces modules, cela est appelé l'étiquette "current".

  • unseen

    Avec "unseen" sont listés les messages qui n'ont jamais été lus. Cela doit être une erreur de conception de MH : cela doit être une source de confusion. Les gens ne devraient jamais utiliser des étiquettes avec une négation dans le nom :

    if($seen)           if(!$unseen)    # beurk !
if(!$seen)          if($unseen)
unless($seen)       unless($unseen) # beurk !

    Donc : l'étiquette "unseen" est traduite en "seen" pour un usage interne.

DIAGNOSTICS

Erreur : Impossible de coercer un objet $class en objet $class
Lancé par coerce()
Erreur : Impossible de créer un parseur pour $filename.
Pour une raison quelconque (le message précédent vous l'a déjà indiqué), il n'a pas été possible de créer un parseur de message pour le nom de fichier spécifié. Lancé par parser()
Erreur : Impossible d'inclure la source de renvoi comme $include.
Alternative inconnue pour la fonction forward(include). Les choix valides sont "NO", "INLINE", "ATTACH", et "ENCAPSULATE". Lancé par forward()
Erreur : Impossible d'inclure la source de réponse comme $include.
Alternative inconnue pour l'option "include" de reply(). Les choix valides sont "NO", "INLINE", et "ATTACH". Lancé par reply()
Erreur : Impossible d'écrire le message dans $filename: $!
Lorsqu'un message modifié ou nouveau est écrit sur le disque, il est d'abord écrit dans un fichier temporaire dans le répertoire du dossier. Pour une raison quelconque, il est impossible de créer ce fichier. Lancé par create()
Erreur : Échec du déplacement de $new vers $filename : $!
Lorsqu'un message modifié ou nouveau est écrit sur le disque, il est d'abord écrit dans un fichier temporaire dans le répertoire du dossier. Ensuite, le nouveau fichier est déplacé pour remplacer le fichier existant. Apparemment, cette dernière opération échoue. Lancé par create()
Erreur : La méthode bounce nécessite To, Cc, ou Bcc
La méthode bounce() d'un message transfère un message reçu à quelqu'un d'autre sans modification ; vous devez spécifier sa nouvelle destination. Si vous avez l'envie de ne spécifier aucune destination, vous cherchez probablement reply(). Lorsque vous souhaitez modifier le contenu, utilisez forward(). Lancé par bounce()
