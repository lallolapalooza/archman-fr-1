MagickWand-Config(1) Manuel des commandes générales MagickWand-Config(1)

NOM

MagickWand-config - obtenir des informations sur la version installée de Magick Wand

SYNTAXE

MagickWand-config [--cflags] [--cppflags] [--exec-prefix] [--ldflags] [--libs] [--prefix] [--version]

DESCRIPTION

MagickWand-config affiche les indicateurs du compilateur et de l'éditeur de liens requis pour compiler et lier des programmes utilisant l'interface de programmation d'applications Wand.

EXEMPLES

Pour afficher la version de la distribution Wand installée, utilisez :

  MagickWand-config --version

Pour compiler un programme qui appelle l'interface de programmation d'applications Wand, utilisez :

  cc `MagickWand-config --cflags --cppflags --ldflags --libs` program.c

OPTIONS

--cflags
Affiche les indicateurs du compilateur qui ont été utilisés pour compiler libWand.
--cppflags
Affiche les indicateurs du préprocesseur qui sont nécessaires pour trouver les fichiers d'en-tête C de Wand et les définitions afin de garantir que les structures de données de Wand correspondent entre votre programme et les bibliothèques installées.
--exec-prefix
Affiche le répertoire sous lequel les binaires et exécutables spécifiques à la cible sont installés.
--ldflags
Affiche les indicateurs de l'éditeur de liens qui sont nécessaires pour lier avec la bibliothèque Wand.
--libs
Affiche les indicateurs de l'éditeur de liens qui sont nécessaires pour lier un programme avec libWand.
--version
Affiche la version de la distribution Wand sur la sortie standard.
