NOM

Mail::Message::Body::Delayed - le corps d'un Mail::Message mais pas encore lu.

HÉRÉDITÉ

Mail::Message::Body::Delayed implémente Mail::Message::Body
Mail::Message::Body::Delayed
  est un Mail::Reporter

SYNOPSIS

Voir Mail::Message::Body

DESCRIPTION

Les corps de ce type seront remplacés par un autre type au moment où le contenu est accédé. Dans cette documentation vous trouverez la description de la façon dont un corps de message est chargé en différé.

Hérite de "DESCRIPTION" de Mail::Reporter.

OVERLOADÉ

overload: "" chaîne
Renvoie le corps comme une chaîne -- ce qui déclenche la complétion -- sauf si il est appelé pour produire une chaîne pour Carp. Le dernier évite des récursions profondes.

» exemple : chaîne de corps différé

print $msg->body;   # implicite par print
my $body = $msg->body;
my $x    = "$body"; # explicite par interpolation
overload: @{} accès comme TABLEAU
Quand un objet corps est utilisé comme référence de tableau, les lignes du corps sont renvoyées. C'est la même chose que d'utiliser la méthode lines.
overload: bool existence
Renvoie toujours une valeur true, nécessaire pour les objets surchargés afin d'être utilisés comme dans if($body). Sinon, il faut if(defined $body) pour éviter une erreur d'exécution.
