NOM

Mail::Box::Maildir - gérer les dossiers Maildir

HÉRÉDITÉ

Mail::Box::Maildir
  est un Mail::Box::Dir
  est un Mail::Box
  est un Mail::Reporter

SYNTAXE

use Mail::Box::Maildir;
my $folder = Mail::Box::Maildir->new(folder => $ENV{MAIL}, ...);

DESCRIPTION

Cette documentation décrit le fonctionnement des boîtes aux lettres Maildir et ce que vous pouvez faire avec l'objet dossier "Mail::Box::Maildir".

Maildir **n'est PAS pris en charge sous Windows**, car il crée des noms de fichiers qui ne sont pas acceptés par le système Windows.

Comment fonctionnent les dossiers Maildir

Les dossiers de type Maildir utilisent un répertoire pour stocker les messages d'un dossier. Chaque message est stocké dans un fichier séparé. Cela semble utile, car les modifications apportées à un dossier n'affectent que quelques-uns de ces petits fichiers, contrairement aux dossiers basés sur des fichiers où les modifications apportées à un dossier entraînent la réécriture de grands fichiers de dossier.

Cependant, les dossiers de type Maildir se comportent très mal si vous avez besoin des informations d'en-tête de tous les messages. Par exemple, si vous voulez avoir toutes les informations sur tous les fils de discussion de messages (voir Mail::Box::Thread::Manager) dans un dossier, cela nécessite de lire toutes les lignes d'en-tête dans tous les fichiers de message. Et normalement, vous voulez lire les messages en tant que fils de discussion. Les dossiers Maildir gardent une quantité minimale d'informations visibles dans le nom du fichier, ce qui peut rendre le dossier légèrement plus rapide que MH.
