Mail::SPF::MacroString(3) Documentation Perl fournie par l'utilisateur Mail::SPF::MacroString(3)

NOM

Mail::SPF::MacroString - Classe pour les chaînes de macros SPF

VERSION

version 3.20250505

SYNOPSIS

Fournir le contexte d'expansion tôt

use Mail::SPF::MacroString;
my $macrostring = Mail::SPF::MacroString->new(
    text    => '%{ir}.%{v}._spf.%{d2}',
    server  => $server,
    request => $request
);
my $expanded = $macrostring->expand;

Fournir le contexte d'expansion tardivement

use Mail::SPF::MacroString;
my $macrostring = Mail::SPF::MacroString->new(
    text    => '%{ir}.%{v}._spf.%{d2}'
);
my $expanded1 = $macrostring->expand($server, $request1);
$macrostring->context($server, $request2);
my $expanded2 = $macrostring->expand;

DESCRIPTION

Un objet de la classe Mail::SPF::MacroString représente une chaîne de macros qui peut être développée en une chaîne de caractères dans le contexte d'une requête SPF.

Constructeur

Le constructeur suivant est fourni :

new(%options): retourne Mail::SPF::MacroString
Crée un nouvel objet de chaîne de macros SPF.

%options est une liste de paires clé/valeur représentant n'importe laquelle des options suivantes :

text
Requis. Le texte non développé de la nouvelle chaîne de macros.
server
L'objet Mail::SPF::Server qui doit être utilisé lors du développement de la chaîne de macros. Un objet serveur n'a pas besoin d'être attaché statiquement à la chaîne de macros ; il peut être spécifié dynamiquement lors de l'appel de la méthode "expand".
request
L'objet Mail::SPF::Request qui doit être utilisé lors du développement de la chaîne de macros. Un objet requête n'a pas besoin d'être attaché statiquement à la chaîne de macros ; il peut être spécifié dynamiquement lors de l'appel de la méthode "expand".
is_explanation
Un booléen indiquant si la chaîne de macros est une chaîne d'explication obtenue via un modificateur "exp". Si vrai, les macros "c", "r" et "t" peuvent apparaître dans la chaîne de macros, sinon elles ne le peuvent pas, et si elles le font, une exception Mail::SPF::EInvalidMacro sera levée lors du développement de la chaîne de macros. Par défaut à faux.

Méthodes d'instance

Les méthodes d'instance suivantes sont fournies :

text: retourne chaîne
Retourne le texte non développé de la chaîne de macros.
context($server, $request): lève Mail::SPF::EOptionRequired
Attache les objets Mail::SPF::Server et Mail::SPF::Request fournis comme contexte pour la chaîne de macros.
expand: retourne chaîne; lève Mail::SPF::EMacroExpansionCtxRequired, Mail::SPF::EInvalidMacroString, Mail::SPF::Result::PermError
expand($server, $request): retourne chaîne; lève Mail::SPF::EMacroExpansionCtxRequired, Mail::SPF::EInvalidMacroString, Mail::SPF::Result::PermError
Développe le texte de la chaîne de macros en utilisant soit le contexte spécifié par un appel précédent à la méthode context(), soit le contexte fourni, et retourne la chaîne résultante. Voir RFC 4408, 8, pour la manière dont les macros sont développées.
is_explanation: retourne booléen
Retourne vrai si la chaîne de macros est une chaîne d'explication obtenue via un modificateur "exp". Voir la description de l'option "is_explanation" du constructeur "new".
stringify: retourne chaîne
Retourne le texte développé de la chaîne de macros si un contexte est attaché à l'objet. Retourne le texte non développé sinon. Vous pouvez simplement utiliser un objet Mail::SPF::MacroString comme une chaîne pour le même effet, voir "OVERLOADING".

OVERLOADING

Si un objet Mail::SPF::MacroString est utilisé comme une chaîne, la méthode "stringify" est utilisée pour convertir l'objet en une chaîne.

VOIR AUSSI

Mail::SPF, Mail::SPF::Record, Mail::SPF::Server, Mail::SPF::Request

http://tools.ietf.org/html/rfc4408
