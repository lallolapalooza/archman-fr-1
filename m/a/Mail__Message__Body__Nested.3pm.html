NOM

Le corps (contenu) d'un message peut être stocké dans divers modes. Cette page de manuel décrit la fonctionnalité supplémentaire disponible lorsqu'un message contient un message imbriqué, comme "message/rfc822".

Un message imbriqué est différent d'un message multipart qui ne contient qu'un seul élément, car un message imbriqué possède un ensemble complet de champs d'en-tête définis par le RFC882, alors qu'une partie d'un multipart n'en a que quelques-uns. Mais comme nous ne suivons pas la présence de tous les champs, nous utilisons toujours "Mail::Message::Part".

AVERTISSEMENT : Depuis 2023, au moins Outlook a commencé à mal interpréter le RFC6533. Les corps de type 'message/rfc822' ne peuvent être que des corps 'imbriqués', mais lorsqu'ils ont (illégalement) un Content-Transfer-Encoding, ils peuvent maintenant se comporter comme des parties normales du message (comme un fichier pdf ou une image).

Étendu de "DESCRIPTION" dans Mail::Message::Body.

NAME

Mail::Message::Body::Multipart - body with multiple parts

SYNOPSIS

  use Mail::Message::Body;
  use Mail::Message::Part;
  # ...
  my $body = $message->body;
  # ...
  # multi-part specific methods
  $body->addPart($part);
  $body->parts;
  $body->walk(CODE);
  # inherited methods
  $body->string;
  $body->print;
  $body->message;
  # etc.

DESCRIPTION

This class represents a MIME multi-part message body. A multi-part body can contain other parts, which can themselves be multi-part bodies or single bodies.

This class extends Mail::Message::Body. All methods defined in the parent class are available on Mail::Message::Body::Multipart objects as well, unless they are overridden.

Adding and retrieving parts

addPart( $part )
Add a new part to this body. The argument must be a Mail::Message::Part object. The part is appended to the end of the list of existing parts.
parts
Returns an array of the Mail::Message::Part objects that constitute this body. The order is preserved.
walk( CODE )
Recursively walks through all parts of this body. For each part found, the given CODE is executed with the part as the only argument. The walk stops when CODE returns a defined value. This value is then returned by walk.

The walk proceeds in depth-first order.

Example:

  my $found_part = $body->walk(sub {
      my $part = shift;
      return $part if $part->mimeType eq 'text/plain';
  });

Returns the value returned by CODE when it was executed for the first time, or undef if the callback never returned a defined value.

DIAGNOSTICS

Warning: Charset $name is not known
The encoding or decoding of a message body encounters a character set which is not understood by Perl's Encode module. Cast by encode()
Warning: Content-Transfer-Encoding `$encoding' requires explicit charset, defaulted to utf-8
Cast by encode()
Warning: No decoder defined for transfer encoding $name.
The data (message body) is encoded in a way which is not currently understood, therefore no decoding (or recoding) can take place. Cast by encode()
Warning: No encoder defined for transfer encoding $name.
The data (message body) has been decoded, but the required encoding is unknown. The decoded data is returned. Cast by encode()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
Warning: Unknown line terminator $eol ignored
Cast by eol()
Error: You cannot use foreachLine on a nested
foreachLine() should be used on decoded message bodies only, because it would modify the header of the encapsulated message. which is clearly not acceptable. Cast by foreachLine()
