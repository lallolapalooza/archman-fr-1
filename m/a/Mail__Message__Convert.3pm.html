SYNTAXE

Les méthodes disponibles sont très spécifiques aux convertisseurs.

DESCRIPTION

Cette classe est la base pour différents convertisseurs de messages (et de parties de message).

Étends "DESCRIPTION" dans Mail::Reporter.

Convertisseurs entre objets de message

En interne, Mail::Message::coerce() est appelée quand des objets externes sont utilisés là où des objets de message sont attendus. Cette méthode créera automatiquement les objets de conversion et les réutilisera.

  • Mail::Message::Convert::MailInternet

    Convertit les messages simples d'Email::Simple en objets Mail::Message.

  • Mail::Message::Convert::MimeEntity

    Convertit les messages plus complexes de MIME::Entity en objets Mail::Message.

  • Mail::Message::Convert::EmailSimple

    Convertit les messages d'Email::Simple en objets Mail::Message.

Autres convertisseurs

  • Mail::Message::Convert::Html

    Effectue des manipulations sur HTML/XMHTML sans aide de modules externes.

  • Mail::Message::Convert::HtmlFormatText

    Convertit les objets de corps HTML en objets texte brut en utilisant le module HTML::FormatText.

  • Mail::Message::Convert::HtmlFormatPS

    Convertit les objets de corps HTML en objets PostScript en utilisant le module HTML::FormatPS.

  • Mail::Message::Convert::TextAutoformat

    Convertit un message texte en texte en utilisant Text::Autoformat.

champs => NOMS|ARRAY-OF-NOMS|REGEXS
Sélectionne les champs d'en-tête à traiter. Les autres champs ne seront pas utilisés. La valeur de cette option est passée à Mail::Message::Head::Complete::grepNames() lorsque les convertisseurs doivent sélectionner des lignes d'en-tête. Par défaut, les champs "To", "From", "Cc", "Bcc", "Date", "Subject", et leurs correspondants "Resent-" sont sélectionnés. Spécifiez une liste vide pour tous les champs.
log => NIVEAU
trace => NIVEAU
