Mat_VarCreateStruct(3)

Paquet: libmatio

Licences: BSD-2-Clause

MAT_VARCREATESTRUCT(3) Manuel des fonctions de bibliothèque MAT_VARCREATESTRUCT(3)

NOM

Mat_VarCreateStruct — Crée une variable de type structure.

SYNTAXE

#include <matio.h>

matvar_t *
Mat_VarCreateStruct(const char *name, int rank, const size_t *dims, const char **fields, unsigned nfields);

DESCRIPTION

La fonction Mat_VarCreateStruct() crée une variable de type structure nommée name qui peut être écrite dans un fichier MAT.

VALEURS DE RETOUR

Si la variable de structure a été créée avec succès, un pointeur vers la variable est retourné. Sinon, NULL est retourné. Le pointeur vers la variable de structure doit être libéré lorsqu'il n'est plus nécessaire en utilisant Mat_VarFree(). Les noms des champs sont copiés dans la fonction, et doivent donc être libérés après l'appel de la fonction si nécessaire.

EXEMPLES

Cet exemple de programme ouvre un fichier MAT nommé par le premier argument du programme, et écrit une structure nommée a dans le fichier.

#include "matio.h"

int
main(int argc, char **argv)
{
    mat_t    *matfp;
    matvar_t *matvar;
    matvar_t *field;
    const char *fields[2] = {"field1", "field2"};
    double       data1 = 1, data2 = 2;
    size_t       dims[2] = {1, 1};

    matfp = Mat_Open(argv[1], MAT_ACC_RDWR);
    if ( NULL == matfp ) {
        fprintf(stderr, "Erreur lors de l'ouverture du fichier MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    dims[0] = 1; dims[1] = 1;
    matvar = Mat_VarCreateStruct("a", 2, dims, fields, 2);
    if ( NULL == matvar ) {
        Mat_Close(matfp);
        return EXIT_FAILURE;
    }

    field = Mat_VarCreate(NULL, MAT_C_DOUBLE, MAT_T_DOUBLE, 2, dims, &data1,
                MAT_F_DONT_COPY_DATA);
    Mat_VarSetStructFieldByName(matvar, "field1", 0, field);

    field = Mat_VarCreate(NULL, MAT_C_DOUBLE, MAT_T_DOUBLE, 2, dims, &data2,
                MAT_F_DONT_COPY_DATA);
    Mat_VarSetStructFieldByName(matvar, "field2", 0, field);

    Mat_VarWrite(matfp, matvar, MAT_COMPRESSION_NONE);
    Mat_VarFree(matvar);

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
