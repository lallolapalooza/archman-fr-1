NOM

Mail::Sendmail - Mailer indépendant de la plateforme

SYNOPSIS

use Mail::Sendmail;
%mail = ( To      => 'you@there.com',
          From    => 'me@here.com',
          Message => "This is a very short message"
         );
sendmail(%mail) or die $Mail::Sendmail::error;
print "OK. Log says:\n", $Mail::Sendmail::log;

DESCRIPTION

Envoi d'e-mails indépendamment de la plateforme depuis votre script Perl. Ne nécessite que Perl 5 et une connexion Internet.

Mail::Sendmail prend un hash avec le message à envoyer et l'envoie à votre serveur de courrier. Il est intentionnellement très facile à configurer et à utiliser. Voir aussi "CARACTÉRISTIQUES" ci-dessous, et comme d'habitude, lire cette documentation.

Il y a aussi une FAQ (voir "NOTES").

INSTALLATION

Meilleur
"perl -MCPAN -e "install Mail::Sendmail""
Traditionnel
perl Makefile.PL
make
make test
make install
Manuel
Placez Sendmail.pm dans le dossier lib/perl de votre script Perl. 
(ex. c:\Perl\site\lib\Mail\
 ou  /usr/lib/perl5/site_perl/Mail/
 ou  n'importe où sur votre système.  
        Ils sont prêts lorsque vous exécutez C< perl -V >)
PPM d'ActivePerl
Selon votre version de PPM : 
ppm install --location=http://alma.ch/perl/ppm Mail-Sendmail

ou

ppm install http://alma.ch/perl/ppm/Mail-Sendmail.ppd

Mais cela vous empêche de voir les autres fichiers (Changes, Todo, test.pl, ...).

En haut de Sendmail.pm, définissez votre serveur SMTP par défaut, sauf si vous le spécifiez avec chaque message ou si vous voulez utiliser le défaut (localhost).

Installez MIME::QuotedPrint. Ce n'est pas obligatoire, mais c'est recommandé.

CARACTÉRISTIQUES

Détection automatique du fuseau horaire, en-tête Date, encodage MIME quoted-printable (si MIME::QuotedPrint est installé), le tout pouvant être outrepassé.

Support pour Bcc: et Cc:.

Permet les noms réels dans les champs From:, To: et Cc:.

N'envoie pas d'en-tête X-Mailer: (sauf si vous le spécifiez), et permet d'envoyer n'importe quel en-tête que vous voulez.

Réessais configurables et utilisation de serveurs alternatifs si le serveur de messagerie est hors service.

Rapport d'erreurs en texte brut.

Support expérimental pour l'authentification SMTP.

LIMITATIONS

Les en-têtes ne sont pas encodés, même s'ils contiennent des caractères accentués.

Comme le message complet est en mémoire, il n'est pas adapté à l'envoi de gros fichiers joints.

Le serveur SMTP doit être configuré manuellement dans Sendmail.pm ou dans votre script, sauf si vous avez un serveur de messagerie sur localhost.

Ne fonctionne pas sur OpenVMS, comme on me l'a dit. Je ne peux pas le tester.

CONFIGURATION

Serveur SMTP par défaut
C'est probablement ce que vous voulez configurer. Cela se fait généralement via $mailcfg{smtp}, que vous pouvez éditer en haut du fichier Sendmail.pm. C'est une référence vers une liste de serveurs SMTP. Vous pouvez aussi le définir depuis votre script :

"unshift @{$Mail::Sendmail::mailcfg{'smtp'}} , 'my.mail.server';"

Alternativement, vous pouvez spécifier le serveur dans le hash %mail que vous envoyez depuis votre script, ce qui fera la même chose :

"$mail{smtp} = 'my.mail.server';"

Une future version (espérons-le) essaiera de définir des valeurs par défaut utiles pour vous lors de l'exécution de Makefile.PL.

Autres configurations
Voir %mailcfg sous "DÉTAILS" pour d'autres options de configuration.

DÉTAILS

sendmail()

sendmail est le seul élément exporté dans l'espace de noms par défaut.

"sendmail(%mail) || print "Error sending mail: $Mail::Sendmail::error\n";"

Prend un hash avec le message complet, avec des clés pour tous les en-têtes et le corps, ainsi que pour certaines options spécifiques.

Renvoie 1 en cas de succès ou 0 en cas d'erreur, et réécrit $Mail::Sendmail::error et $Mail::Sendmail::log.

Les clés ne sont pas sensibles à la casse.

Le séparateur deux-points après les en-têtes n'est pas nécessaire.

La partie Body peut être nommée 'Body', 'Message' ou 'Text'.

Le serveur SMTP peut être nommé 'Smtp' ou 'Server'. Si la connexion à l'un échoue, les autres dans $mailcfg{smtp} seront essayés.

Les en-têtes suivants sont ajoutés sauf si vous les spécifiez vous-même :

Mime-Version: 1.0
Content-Type: 'text/plain; charset="iso-8859-1"'
Content-Transfer-Encoding: quoted-printable
ou (si MIME::QuotedPrint n'est pas installé)
Content-Transfer-Encoding: 8bit
Date: [chaîne renvoyée par time_to_date()]

Si vous souhaitez utiliser un expéditeur de courrier différent de l'en-tête From:, définissez $mail{Sender} dans votre hash %mail.

Les éléments suivants ne sont pas exportés par défaut, mais vous pouvez y accéder avec leur nom complet, ou demander leur exportation sur la ligne d'utilisation comme ceci : "use Mail::Sendmail qw(sendmail $address_rx time_to_date);"

options d'injection dans votre%mail hash

Les options suivantes peuvent être définies dans votre hash %mail. Les clés correspondantes seront supprimées avant l'envoi du courrier.

$mail{smtp} ou $mail{server}
Le serveur SMTP à essayer en premier. Sera ajouté
$mail{port}
Cette option sera supprimée. Pour utiliser un port non standard, définissez-le dans votre nom de serveur :

$mail{server}='my.smtp.server:2525' essaiera de se connecter au port 2525 sur le serveur my.smtp.server

$mail{auth}
Ce doit être une référence vers un hash avec toutes vos options d'authentification :

$mail{auth} = \%options; ou $mail{auth} = {user="username", password="password", method="DIGEST-MD5", required="0"};

user
nom d'utilisateur
pass ou password
mot de passe
method
méthode optionnelle. Comparé (non sensible à la casse) aux méthodes disponibles. Si vide, essaiera toutes les méthodes disponibles.
required
optionnel. Par défaut, c'est false. S'il est défini à true, la livraison ne sera pas tentée si l'authentification échoue. S'il est false ou indéfini et que l'authentification échoue ou n'est pas disponible, la livraison sera tentée sans authentification.

(authentification différente pour différents serveurs ?)

$Mail::Sendmail::error

Lorsque vous n'exécutez pas avec le flag -w, le module n'envoie pas d'erreurs à STDERR, mais celles qui doivent être regrettées sont sauvegardées ici. Vous devriez vérifier si cela dit quelque chose.

$Mail::Sendmail::log

Un résumé que vous pourriez écrire dans un fichier journal après chaque envoi.

Autre
Le code est un peu comme une vieille pipe, simple et ne fait pas de choses compliquées. Le but est juste d'envoyer du courrier. J'ai l'intention de ne pas y ajouter de fonctionnalités qui pourraient perturber les utilisateurs existants. Par exemple, je n'ai aucune intention de supporter l'authentification POP/IMAP pour récupérer les messages, ou de créer des e-mails graphiques pour vous.

$Mail::Sendmail::address_rx

Une regex pratique pour reconnaître les adresses e-mail.

Une regex correcte pour les adresses e-mail valides a été écrite par l'un des juges du concours Perl obscurci... :-) Elle est assez grande. Celle-ci est une tentative de compromis raisonnable, et devrait accepter toutes les adresses de style Internet du monde réel. La partie domaine est requise et les commentaires ou caractères qui devraient être cités ne sont pas pris en charge.

Exemple:
  $rx = $Mail::Sendmail::address_rx;
  if (/$rx/) {
    $address=$1;
    $user=$2;
    $domain=$3;
  }

%Mail::Sendmail::mailcfg

Ce hash contient les options de configuration à l'échelle de l'installation. Vous l'éditez normalement une fois (si jamais) dans Sendmail.pm et l'oubliez, mais vous pourriez aussi y accéder depuis vos scripts. Pour des raisons de lisibilité, je suppose que vous l'avez importé (avec quelque chose comme "use Mail::Sendmail qw(sendmail %mailcfg)").

Les clés ne sont pas sensibles à la casse : elles sont toutes converties en minuscules avant utilisation. Écrire "$mailcfg{Port} = 2525;" est correct : la valeur par défaut $mailcfg{port} (25) sera supprimée et remplacée par votre nouvelle valeur de 2525.

$mailcfg{smtp}
"$mailcfg{smtp} = [qw(localhost my.other.mail.server)];"

C'est une référence à une liste de serveurs smtp, donc si votre serveur principal est en panne, le module essaie le suivant. Si l'un de vos serveurs utilise un port spécial, ajoutez-le au nom du serveur avec un deux-points devant, pour remplacer le port par défaut (comme dans my.special.server:2525).

Par défaut : localhost.

$mailcfg{from}
"$mailcfg{from} = 'Mailing script me@mydomain.com';"

Adresse d'expéditeur utilisée si vous n'en fournissez pas dans votre script. Ne doit pas être de type 'user@localhost' car cela pourrait ne pas être valide sur l'hôte du destinataire.

Par défaut : indéfini.

$mailcfg{mime}
"$mailcfg{mime} = 1;"

Définissez ceci à 0 si vous ne voulez aucun encodage MIME automatique. Vous n'en avez normalement pas besoin, le module devrait faire 'La bonne chose' de toute façon.

Par défaut : 1;

$mailcfg{retries}
"$mailcfg{retries} = 1;"

Combien de fois la connexion au même serveur SMTP doit-elle être retentée en cas d'échec.

Par défaut : 1;

$mailcfg{delay}
"$mailcfg{delay} = 1;"

Nombre de secondes à attendre entre les tentatives. Ce délai se produit également avant d'essayer le serveur suivant dans la liste, si les tentatives pour le serveur actuel ont été épuisées. Pour les scripts CGI, vous voulez peu de tentatives et de courts délais pour retourner une page de résultats avant que la connexion http n'expire. Pour les scripts non surveillés, vous voudrez peut-être utiliser de nombreuses tentatives et de longs délais pour avoir une bonne chance que votre e-mail soit envoyé même en cas d'échecs temporaires sur votre réseau.

Par défaut : 1 (seconde);

$mailcfg{tz}
"$mailcfg{tz} = '+0800';"

Normalement, votre fuseau horaire est défini automatiquement, à partir de la différence entre time() et gmtime(). Ceci vous permet de remplacer la détection automatique dans les cas où votre système est confus (comme certains systèmes Win32 dans des zones qui n'utilisent pas l'heure d'été : voir l'article de la base de connaissances Microsoft Q148681)

Par défaut : indéfini (détection automatique à l'exécution).

$mailcfg{port}
"$mailcfg{port} = 25;"

Port utilisé lorsqu'aucun n'est spécifié dans le nom du serveur.

Par défaut : 25.

$mailcfg{debug}
"$mailcfg{debug} = 0;"

Affiche des informations sur STDERR. Le maximum actuel est 6, ce qui affiche toute la session SMTP, à l'exception des données dépassant 500 octets.

Par défaut : 0;

UN AUTRE EXEMPLE

use Mail::Sendmail;
print "Testing Mail::Sendmail version $Mail::Sendmail::VERSION\n";
print "Default server: $Mail::Sendmail::mailcfg{smtp}->[0]\n";
print "Default sender: $Mail::Sendmail::mailcfg{from}\n";
%mail = (
    #To      => 'Pas de champ To cette fois, seulement Bcc et Cc',
    #From    => 'pas nécessaire, utiliser la valeur par défaut',
    Bcc     => 'Quelqu\'un <lui@là.com>, Une autre personne elle@là.com',
    # seules les adresses sont extraites de Bcc, les vrais noms sont ignorés
    Cc      => 'Encore quelqu\'un <xz@quelquechose.com>',
    # Cc apparaîtra dans l'en-tête. (Bcc n'apparaîtra pas)
    Subject => 'Message de test',
    'X-Mailer' => "Mail::Sendmail version $Mail::Sendmail::VERSION",
);
$mail{Smtp} = 'special_server.for-this-message-only.domain.com';
$mail{'X-custom'} = 'Mon en-tête personnalisé supplémentaire';
$mail{'mESSaGE : '} = "La clé du message a l'air terrible, mais fonctionne.";
# tricher sur la date :
$mail{Date} = Mail::Sendmail::time_to_date( time() - 86400 );
if (sendmail %mail) { print "Mail envoyé OK.\n" }
else { print "Erreur lors de l'envoi du mail: $Mail::Sendmail::error \n" }
print "\n\$Mail::Sendmail::log dit:\n", $Mail::Sendmail::log;

Voir également http://alma.ch/perl/Mail-Sendmail-FAQ.html pour des exemples de mails HTML et d'envoi de pièces jointes.

CHANGEMENTS

Principaux changements depuis la version 0.79 :

Support expérimental de l'authentification SMTP (LOGIN PLAIN CRAM-MD5 DIGEST-MD5)

Correction d'un bug où un RCPT TO: refusé arrêtait tout

Envoi de EHLO et analyse de la réponse

Meilleure gestion des réponses multi-lignes et meilleurs messages d'erreur

Les fins de ligne non conformes sont également normalisées dans les en-têtes

Conserve maintenant l'en-tête Sender s'il a été utilisé. Les versions précédentes ne l'utilisaient que pour la commande MAIL FROM: et le supprimaient.

Voir le fichier Changes pour l'historique complet. Si vous ne l'avez pas parce que vous l'avez installé via PPM, vous pouvez également trouver le dernier sur http://alma.ch/perl/scripts/Sendmail/Changes.

NOTES

MIME::QuotedPrint est utilisé par défaut sur chaque message si disponible. Il permet l'envoi fiable de caractères accentués, et prend également en charge les lignes trop longues (ce qui peut arriver dans les e-mails HTML). Il est disponible dans le package MIME-Base64 sur http://www.perl.com/CPAN/modules/by-module/MIME/ ou via PPM.

Consultez http://alma.ch/perl/Mail-Sendmail-FAQ.html pour des informations supplémentaires (CGI, exemples d'envoi de pièces jointes, e-mails HTML, etc...)

Vous pouvez utiliser ce module librement. (Quelqu'un s'est plaint que c'était trop vague. Donc, plus précisément : faites ce que vous voulez avec, mais soyez averti que des choses terribles vous arriveront si vous l'utilisez mal, comme pour envoyer du spam, ou... ?)

Merci aux nombreux utilisateurs qui m'ont envoyé des retours, des rapports de bugs, des suggestions, etc.
