NOM

Mail::Message::TransferEnc - encodeur/décodeur de transfert de message

HÉRITAGE

Mail::Message::TransferEnc
  est un Mail::Reporter
Mail::Message::TransferEnc est étendu par
  Mail::Message::TransferEnc::Base64
  Mail::Message::TransferEnc::Binary
  Mail::Message::TransferEnc::EightBit
  Mail::Message::TransferEnc::QuotedPrint
  Mail::Message::TransferEnc::SevenBit

SYNOPSIS

my Mail::Message $msg = ...;
my $decoded = $msg->decoded;
my $encoded = $msg->encode(transfer => 'base64');

DESCRIPTION

Cette classe est la base pour divers encodeurs et décodeurs, qui sont utilisés pendant le transport du message. Ces paquets, et tous ceux qui en sont dérivés, sont invoqués par les méthodes Mail::Message::decoded() et Mail::Message::encode() du message :

my $message = $folder->message(3);
my $decoded_body = $message->decoded;
my $encoded_body = $message->encode(transfer => 'base64');

Les règles pour les encodages de transfert sont spécifiées dans la RFC4289. La liste complète des encodages de transfert de contenu autorisés se trouve à https://www.iana.org/assignments/transfer-encodings/transfer-encodings.xhtml

Les codeurs/décodeurs suivants sont actuellement supportés (avril 2025, la liste complète sur l'IANA) :

  • Mail::Message::TransferEnc::Base64

    "base64" pour les informations binaires.

  • Mail::Message::TransferEnc::SevenBit

    "7bit" uniquement pour les caractères ASCII standard.

  • Mail::Message::TransferEnc::EightBit

    "8bit" pour les données de jeux de caractères étendus, non encodées.

  • Mail::Message::TransferEnc::QuotedPrint

    "quoted-printable" données de jeux de caractères étendus encodées.

L'encodeur

$class->addTransferEncoder($type, $class)
Ajoute un nouvel encodeur à la liste connue par la suite Mail::Box. Le $type se trouve dans l'en-tête du message dans le champ "Content-Transfer-Encoding".
$obj->create($type, %options)
Crée un nouveau codeur/décodeur basé sur le type requis.
$obj->name()
Le nom de l'encodeur. La casse n'est pas significative.

Encodage

$obj->check($body, %options)
Vérifie si le corps est correctement encodé. Si oui, la référence du corps est renvoyée avec le drapeau "checked" activé. Sinon, un nouvel objet est créé et renvoyé. 
-Option     --Default
 result_type  <type du corps source>
result_type => CLASS
Le type du corps à produire, lorsque le vérificateur décide de renvoyer des données modifiées.
$obj->decode($body, %options)
Utilise l'encodeur pour décoder le contenu de $body. Un nouveau corps est renvoyé. 
-Option     --Default
 result_type  <type du corps source>
result_type => CLASS
Le type du corps à produire, lorsque le décodeur décide de renvoyer des données modifiées.
$obj->encode($body, %options)
Utilise l'encodeur pour encoder le contenu de $body. 
-Option     --Default
 result_type  <type du corps source>
result_type => CLASS
Le type du corps à produire, lorsque le décodeur décide de renvoyer des données modifiées.

DIAGNOSTICS

Erreur: Le décodeur pour l'encodage de transfert $type ne fonctionne pas : $@
La compilation de l'encodage de transfert requis a entraîné des erreurs, ce qui signifie que le décodeur ne peut pas être utilisé. Lancé par create()
Avertissement: Aucun décodeur pour l'encodage de transfert $type.
Un décodeur pour le type d'encodage de transfert spécifié n'est pas implémenté. Lancé par create()
Erreur: Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode alors qu'il le devrait. Ce message signifie que d'autres classes apparentées implémentent cette méthode, mais que la classe en question ne le fait pas. Vous devriez probablement investiguer cela et informer l'auteur du paquet. Lancé par notImplemented()
