NOM

Mail::Message::TransferEnc::EightBit - encode/decode les corps de messages 8 bits

HÉRÉDITÉ

Mail::Message::TransferEnc::EightBit
  est un Mail::Message::TransferEnc
  est un Mail::Reporter

SYNTAXE

my Mail::Message $msg = ...;
my $decoded = $msg->decoded;
my $encoded = $msg->encode(transfer => '8bit');

DESCRIPTION

Encode ou décode les corps de messages pour le codage de transfert 8 bits. Ce n'est qu'un encodage très léger. Selon les spécifications :

La section 2.8 du RFC-2045 définit les données `8bit' légales :

"Les données 8 bits" désignent des données qui sont toutes représentées par
des lignes relativement courtes de 998 octets ou moins entre les séquences
de séparation de ligne CRLF [RFC-821]), mais les octets avec des valeurs
décimales supérieures à 127 peuvent être utilisés. Comme avec les données
"7 bits", les octets CR et LF ne se produisent que dans le cadre des séquences
de séparation de ligne CRLF et aucun NUL n'est autorisé.

Comme vous pouvez le conclure sans risque : le décodage de ces corps ne demande aucun travail.

Étends "DESCRIPTION" dans Mail::Message::TransferEnc.

Étends "METHODS" dans Mail::Message::TransferEnc.
