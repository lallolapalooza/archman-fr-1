MAT_VARREADINFO(3) Manuel des fonctions de bibliothèque MAT_VARREADINFO(3)

NOM

Mat_VarReadInfo — Lit les informations d'une variable spécifique dans un fichier MAT MATLAB.

SYNOPSIS

#include <matio.h>

matvar_t *
Mat_VarReadInfo(mat_t *matfp, const char *name);

DESCRIPTION

La fonction Mat_VarReadInfo() lit les informations de la variable name dans le fichier MAT ouvert.

VALEUR DE RETOUR

Si la variable a été trouvée dans le fichier MAT et que les informations la concernant ont été lues avec succès, un pointeur vers la structure de variable MATLAB est retourné. Si la variable n'a pas été trouvée, ou s'il y a eu une erreur lors de la lecture des informations de la variable, NULL est retourné.

EXEMPLES

#include "matio.h"

int
main(int argc, char **argv)
{
    mat_t    *matfp;
    matvar_t *matvar;

    matfp = Mat_Open(argv[1], MAT_ACC_RDONLY);
    if ( NULL == matfp ) {
        fprintf(stderr, "Erreur d'ouverture du fichier MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    matvar = Mat_VarReadInfo(matfp, "x");
    if ( NULL != matvar ) {
        Mat_VarPrint(matvar);
        Mat_VarFree(matvar);
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
