NOM

Mail::SpamAssassin::Pyzor::Digest - Module Digest Pyzor

SYNOPSIS

my $digest = Mail::SpamAssassin::Pyzor::Digest::get( $mime_text );

DESCRIPTION

Réimplémentation de https://github.com/SpamExperts/pyzor/blob/master/pyzor/digest.py.

FONCTIONS

$hex = get( $MSG )

Cela prend un message électronique au format texte MIME brut (c'est-à-dire tel qu'il est enregistré dans le format mbox standard) et retourne le digest Pyzor du message en hexadécimal en minuscules.

La sortie de cette fonction doit être normalement identique à celle de la commande "digest" du script "pyzor". Elle convient pour une utilisation dans les méthodes de requête de Mail::SpamAssassin::Pyzor::Client.
