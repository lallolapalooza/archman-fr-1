NOM

Mail::Box-Index - liste de toute la documentation étendue

DESCRIPTION

Toutes les méthodes définies par MailBox sont documentées, mais vous devez encore comprendre l'image globale : les relations entre les modules et les méthodes. Ces explications plus larges sont incluses dans les DÉTAILS des pages de manuel, et listées ci-dessous. Bien sûr, chaque page a également une section DESCRIPTION, qui donne quelques informations essentielles sur le module.

Seule la version HTML de cette page de manuel listera les sections.
