NOM

Mail::Message::Body::String - corps d'un Mail::Message stocké comme une chaîne unique

HERITAGE

Mail::Message::Body::String
  est un Mail::Message::Body
  est un Mail::Reporter

SYNOPSIS

Voir Mail::Message::Body

DESCRIPTION

Le corps (le contenu) d'un message peut être stocké de diverses manières. Dans cette documentation, vous trouverez la description des fonctionnalités supplémentaires dont vous disposez lorsqu'un message est stocké sous forme d'une seule variable scalaire.

Stocker l'intégralité du message dans une chaîne n'est un choix judicieux que lorsque le contenu est petit ou codé. Même s'il est stocké comme une variable scalaire, vous pouvez toujours traiter le corps comme si les données étaient stockées ligne par ligne ou dans un fichier externe, mais ce sera plus lent.

DIAGNOSTICS

Attention : Jeu de caractères $name inconnu
Le traitement du corps du message rencontre un jeu de caractères que le module Encode de Perl ne comprend pas. Transmis par encode()
Attention : Content-Transfer-Encoding `$encoding' nécessite un charset explicite, utilise utf-8 par défaut
Transmis par encode()
Attention : Aucun décodeur défini pour le codage de transfert $name.
Les données (corps du message) sont encodées d'une manière qui n'est actuellement pas comprise, elles ne peuvent donc pas être décodées (ou réencodées). Transmis par encode()
Attention : Aucun encodeur défini pour le codage de transfert $name.
Les données (corps du message) ont été décodées, mais le codage requis est inconnu. Les données décodées sont retournées. Transmis par encode()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet (ou l'une de ses superclasses) n'implémente pas cette méthode là où il devrait. Ce message indique que d'autres classes liées implémentent cette méthode, mais que la classe en question ne le fait pas. Vous devriez probablement enquêter et en informer l'auteur du paquet. Transmis par notImplemented()
Erreur : Impossible de lire le fichier $filename pour le corps de message scalaire : $!
Un objet Mail::Message::Body::String tente d'être créé à partir d'un fichier nommé, mais le fichier ne peut pas être lu pour en récupérer les lignes. Transmis par new()
Attention : La limite de fin de ligne $eol est ignorée
Transmis par eol()
