NOM

Mat_GetDir — Retourne une liste des noms de variables d'un fichier MAT MATLAB étant donné une structure de fichier MAT

SYNTAXE

#include <matio.h>

char * const *
Mat_GetDir(mat_t *matfp, size_t *n);

DESCRIPTION

La fonction Mat_GetDir() retourne une liste des noms de variables d'un fichier MAT MATLAB étant donné la structure du fichier MAT. L'argument de sortie n contient le nombre de variables du fichier MAT MATLAB.

VALEURS DE RETOUR

La fonction retourne une liste en lecture seule des noms de variables d'un fichier MAT MATLAB.
