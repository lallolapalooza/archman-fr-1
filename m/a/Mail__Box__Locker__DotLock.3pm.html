NOM

Mail::Box::Locker::DotLock - verrouiller un dossier avec un fichier séparé

HÉRÉDITÉ

Mail::Box::Locker::DotLock
  est un Mail::Box::Locker
  est un Mail::Reporter

SYNOPSIS

Voir Mail::Box::Locker

DESCRIPTION

L'objet "::DotLock" verrouille le dossier en créant un fichier dont le nom est le même que celui du dossier, suffixé par ".lock".

NOM

Mail::Box::Locker::DotLock - Verrouillage simple de fichiers avec un fichier .lock

HÉRITAGE

Mail::Box::Locker::DotLock hérite de Mail::Box::Locker.

SYNOPIS

  use Mail::Box::Locker::DotLock;

  # ... création d'une boîte ...
  $box->open($lock); # $lock est une instance de Mail::Box::Locker::DotLock

  # ...
  $box->close;

DESCRIPTION

Ce module implémente le mécanisme de verrouillage pour les boîtes aux lettres qui utilisent des fichiers simples. Il se base sur la création d'un fichier .lock pour indiquer qu'une boîte est en cours d'utilisation.

MÉTHODES

lock()
Tente de créer le fichier de verrouillage. Si le fichier existe déjà, cela indique qu'une autre instance utilise la boîte. Le module peut être configuré pour attendre ou échouer dans ce cas.
unlock()
Supprime le fichier de verrouillage.

DIAGNOSTICS

Les erreurs lors de la création ou de la suppression du fichier de verrouillage seront signalées sous forme d'erreurs Perl standards.
