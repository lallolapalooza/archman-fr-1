Math::BigRat(3perl) Guide de référence pour programmeurs Perl Math::BigRat(3perl)

NOM

Math::BigRat - paquet de mathématiques pour nombres rationnels de taille arbitraire

SYNOPSIS

use Math::BigRat;
# Constructeur par défaut (retourne toujours un nouvel objet)
$x = Math::BigRat->new($str);             # par défaut 0
$x = Math::BigRat->new('256');            # depuis décimal
$x = Math::BigRat->new('0256');           # depuis décimal
$x = Math::BigRat->new('0xcafe');         # depuis hexadécimal
$x = Math::BigRat->new('0x1.fap+7');      # depuis hexadécimal
$x = Math::BigRat->new('0o377');          # depuis octal
$x = Math::BigRat->new('0o1.35p+6');      # depuis octal
$x = Math::BigRat->new('0b101');          # depuis binaire
$x = Math::BigRat->new('0b1.101p+3');     # depuis binaire
# Méthodes de constructeur spécifiques (sans préfixe; lorsqu'utilisé comme méthode d'instance, la valeur est attribuée à celle invoquée)
$x = Math::BigRat->from_dec('234');       # depuis décimal
$x = Math::BigRat->from_hex('cafe');      # depuis hexadécimal
$x = Math::BigRat->from_hex('1.fap+7');   # depuis hexadécimal
$x = Math::BigRat->from_oct('377');       # depuis octal
$x = Math::BigRat->from_oct('1.35p+6');   # depuis octal
$x = Math::BigRat->from_bin('1101');      # depuis binaire
$x = Math::BigRat->from_bin('1.101p+3');  # depuis binaire
$x = Math::BigRat->from_bytes($bytes);    # depuis une chaîne d'octets
$x = Math::BigRat->from_base('why', 36);  # depuis n'importe quelle base
$x = Math::BigRat->from_base_num([1, 0], 2);  # depuis n'importe quelle base
$x = Math::BigRat->from_ieee754($b, $fmt);    # depuis des octets IEEE-754
$x = Math::BigRat->bzero();               # crée un +0
$x = Math::BigRat->bone();                # crée un +1
$x = Math::BigRat->bone('-');             # crée un -1
$x = Math::BigRat->binf();                # crée un +inf
$x = Math::BigRat->binf('-');             # crée un -inf
$x = Math::BigRat->bnan();                # crée un Not-A-Number
$x = Math::BigRat->bpi();                 # retourne pi
$y = $x->copy();        # crée une copie (pas $y = $x)
$y = $x->as_int();      # retourne comme Math::BigInt
$y = $x->as_float();    # retourne comme Math::BigFloat
$y = $x->as_rat();      # retourne comme Math::BigRat
# Méthodes booléennes (ne modifient pas l'objet invoqué)
$x->is_zero();          # vrai si $x est 0
$x->is_one();           # vrai si $x est +1
$x->is_one("+");        # vrai si $x est +1
$x->is_one("-");        # vrai si $x est -1
$x->is_inf();           # vrai si $x est +inf ou -inf
$x->is_inf("+");        # vrai si $x est +inf
$x->is_inf("-");        # vrai si $x est -inf
$x->is_nan();           # vrai si $x est NaN
$x->is_finite();        # vrai si -inf < $x < inf
$x->is_positive();      # vrai si $x > 0
$x->is_pos();           # vrai si $x > 0
$x->is_negative();      # vrai si $x < 0
$x->is_neg();           # vrai si $x < 0
$x->is_non_positive()   # vrai si $x <= 0
$x->is_non_negative()   # vrai si $x >= 0
$x->is_odd();           # vrai si $x est impair
$x->is_even();          # vrai si $x est pair
$x->is_int();           # vrai si $x est un entier
# Méthodes de comparaison (ne modifient pas l'objet invoqué)
$x->bcmp($y);           # comparer des nombres (undef, < 0, == 0, > 0)
$x->bacmp($y);          # comparer des valeurs absolues (undef, < 0, == 0, > 0)
$x->beq($y);            # vrai si $x == $y
$x->bne($y);            # vrai si $x != $y
$x->blt($y);            # vrai si $x < $y
$x->ble($y);            # vrai si $x <= $y
$x->bgt($y);            # vrai si $x > $y
$x->bge($y);            # vrai si $x >= $y
# Méthodes arithmétiques (modifient l'objet invoqué)
$x->bneg();             # négation
$x->babs();             # valeur absolue
$x->bsgn();             # fonction signe (-1, 0, 1, ou NaN)
$x->bdigitsum();        # somme des décimales
$x->binc();             # incrémente $x de 1
$x->bdec();             # décrémente $x de 1
$x->badd($y);           # addition (ajoute $y à $x)
$x->bsub($y);           # soustraction (soustrait $y de $x)
$x->bmul($y);           # multiplication (multiplie $x par $y)
$x->bmuladd($y, $z);    # $x = $x * $y + $z
$x->bdiv($y);           # division (arrondi vers le bas)
$x->bmod($y);           # modulo (x % y)
$x->bmodinv($mod);      # inverse modulaire
$x->bmodpow($y, $mod);  # exponentiation modulaire ((x ** y) % mod)
$x->btdiv($y);          # division (arrondi vers zéro), attribue le quotient à $x
$x->btmod($y);          # modulo (arrondi vers zéro)
$x->binv()              # inverse (1/$x)
$x->bpow($y);           # puissance des arguments (x ** y)
$x->blog();             # logarithme de $x en base e (nombre d'Euler)
$x->blog($base);        # logarithme de $x en base $base (ex: base 2)
$x->bexp();             # calcule e ** $x où e est le nombre d'Euler
$x->bilog2();           # logarithme en base 2 de $x arrondi vers le bas à un entier
$x->bilog10();          # logarithme en base 10 de $x arrondi vers le bas à un entier
$x->bclog2();           # logarithme en base 2 de $x arrondi vers le haut à un entier
$x->bclog10();          # logarithme en base 10 de $x arrondi vers le haut à un entier
$x->bnot()              # opérateur logique NOT (complément à deux)
# Méthodes d'arrondi (modifient l'objet invoqué)
$x->round($A, $P, $R);  # arrondir à la précision ou l'exactitude en utilisant le mode d'arrondi $R
$x->bround($n);         # exactitude : conserve $n chiffres
$x->bfround($n);        # $n > 0: arrondit au $n-ième chiffre à gauche de la virgule
                        # $n < 0: arrondit au $n-ième chiffre à droite de la virgule
$x->bfloor();           # arrondir vers moins l'infini
$x->bceil();            # arrondir vers plus l'infini
$x->bint();             # arrondir vers zéro
# Autres méthodes mathématiques (ne modifient pas l'objet invoqué)
$x->bgcd($y);           # plus grand diviseur commun
$x->blcm($y);           # plus petit commun multiple
# Méthodes de propriétés des objets (ne modifient pas l'objet invoqué)
$x->sign();             # signe, +, -, ou NaN
$x->digit($n);          # le $n-ième chiffre, compté depuis la droite
$x->digit(-$n);         # le $n-ième chiffre, compté depuis la gauche
$x->digitsum();         # somme des décimales
$x->length();           # nombre de chiffres dans le nombre
$x->mantissa();         # retourne la mantisse (signée) sous forme de Math::BigInt
$x->exponent();         # retourne l'exposant sous forme de Math::BigInt
$x->parts();            # retourne (mantisse, exposant) sous forme de Math::BigInt
$x->sparts();           # mantisse et exposant (comme entiers)
$x->nparts();           # mantisse et exposant (normalisés)
$x->eparts();           # mantisse et exposant (notation d'ingénierie)
$x->dparts();           # partie entière et fractionnaire
$x->fparts();           # numérateur et dénominateur
$x->numerator();        # numérateur
$x->denominator();      # dénominateur
# Méthodes de conversion (ne modifient pas l'objet invoqué)
$x->bstr();             # notation décimale (peut être avec des zéros de remplissage)
$x->bnstr();            # notation en forme normalisée
$x->bestr();            # notation en notation d'ingénierie
$x->bdstr();            # notation décimale (sans remplissage)
$x->bfstr();            # notation en forme fractionnaire
$x->to_hex();           # sous forme de chaîne hexadécimale signée
$x->to_bin();           # sous forme de chaîne binaire signée
$x->to_oct();           # sous forme de chaîne octale signée
$x->to_bytes();         # sous forme de chaîne d'octets
$x->to_base($b);        # sous forme de chaîne dans n'importe quelle base
$x->to_base_num($b);    # sous forme de tableau d'entiers dans n'importe quelle base
$x->to_ieee754($fmt);   # sous forme d'octets selon IEEE 754-2008
$x->as_hex();           # sous forme de chaîne hexadécimale avec préfixe "0x"
$x->as_bin();           # sous forme de chaîne binaire avec préfixe "0b"
$x->as_oct();           # sous forme de chaîne octale avec préfixe "0"
# Autres méthodes de conversion (ne modifient pas l'objet invoqué)
$x->numify();           # retourne comme scalaire (peut dépasser ou sous-estimer)

DESCRIPTION

Math::BigRat complète Math::Bi

gInt et Math::BigFloat en fournissant un support pour les nombres rationnels arbitrairement grands.

Bibliothèque Math

Vous pouvez changer le module sous-jacent qui effectue les opérations mathématiques de bas niveau en utilisant :

use Math::BigRat try => 'GMP';

Note : Ceci nécessite l'installation de Math::BigInt::GMP.

Ce qui suit essaiera d'abord de trouver Math::BigInt::Foo, puis Math::BigInt::Bar, et quand cela échoue également, reviendra à Math::BigInt::Calc :

use Math::BigRat try => 'Foo,Math::BigInt::Bar';

Si vous souhaitez être averti lorsque le fallback se produit, remplacez « try » par « lib » :

use Math::BigRat lib => 'Foo,Math::BigInt::Bar';

Si vous souhaitez que le code plante à la place, remplacez « try » par « only » :

use Math::BigRat only => 'Foo,Math::BigInt::Bar';

MÉTHODES

Toutes les méthodes non listées ici sont dérivées de Math::BigFloat (ou Math::BigInt), assurez-vous donc de consulter ces deux modules pour plus d'informations.

new()
$x = Math::BigRat->new('1/3');

Crée un nouvel objet Math::BigRat. L'entrée peut se présenter sous diverses formes :

$x = Math::BigRat->new(123);                            # scalaires
$x = Math::BigRat->new('inf');                          # infini
$x = Math::BigRat->new('123.3');                        # flottant
$x = Math::BigRat->new('1/3');                          # chaîne simple
$x = Math::BigRat->new('1 / 3');                        # espacé
$x = Math::BigRat->new('1 / 0.1');                      # avec des flottants
$x = Math::BigRat->new(Math::BigInt->new(3));           # BigInt
$x = Math::BigRat->new(Math::BigFloat->new('3.1'));     # BigFloat
$x = Math::BigRat->new(Math::BigInt::Lite->new('2'));   # BigLite
# Vous pouvez également donner D et N comme des objets différents :
$x = Math::BigRat->new(
        Math::BigInt->new(-123),
        Math::BigInt->new(7),
     );                      # => -123/7
from_dec()
my $h = Math::BigRat->from_dec("1.2");

Crée un BigRat à partir d'un nombre décimal sous forme de chaîne. Il est équivalent à « new() », mais n'accepte que des chaînes représentant des nombres décimaux finis.

from_hex()
my $h = Math::BigRat->from_hex("0x10");

Crée un BigRat à partir d'un nombre hexadécimal sous forme de chaîne.

from_oct()
my $o = Math::BigRat->from_oct("020");

Crée un BigRat à partir d'un nombre octal sous forme de chaîne.

from_bin()
my $b = Math::BigRat->from_bin("0b10000000");

Crée un BigRat à partir d'un nombre binaire sous forme de chaîne.

from_bytes()
$x = Math::BigRat->from_bytes("\xf3\x6b");  # $x = 62315

Interprète l'entrée comme une chaîne d'octets, en supposant un ordre des octets big-endian. La sortie est toujours un entier non négatif et fini.

Voir « from_bytes() » dans Math::BigInt.

from_ieee754()
# Définit $x à 13176795/4194304, la valeur la plus proche de pi qui peut être
# représentée au format binaire32 (simple précision)
$x = Math::BigRat -> from_ieee754("40490fdb", "binary32");

Interprète l'entrée comme une valeur codée telle que décrite dans IEEE754-2008.

Voir « from_ieee754() » dans Math::BigFloat.

from_base()
Voir « from_base() » dans Math::BigInt.
bzero()
$x = Math::BigRat->bzero();

Crée un nouvel objet BigRat représentant zéro. S'il est utilisé sur un objet, il le définira à zéro :

$x->bzero();
bone()
$x = Math::BigRat->bone($sign);

Crée un nouvel objet BigRat représentant un. L'argument optionnel est soit '-', soit '+', indiquant si vous voulez un ou moins un. S'il est utilisé sur un objet, il le définira à un :

$x->bone();                 # +1
$x->bone('-');              # -1
binf()
$x = Math::BigRat->binf($sign);

Crée un nouvel objet BigRat représentant l'infini. L'argument optionnel est soit '-', soit '+', indiquant si vous voulez l'infini ou moins l'infini. S'il est utilisé sur un objet, il le définira à l'infini :

$x->binf();
$x->binf('-');
bnan()
$x = Math::BigRat->bnan();

Crée un nouvel objet BigRat représentant NaN (Not A Number). S'il est utilisé sur un objet, il le définira à NaN :

$x->bnan();
bpi()
$x = Math::BigRat -> bpi();         # précision par défaut
$x = Math::BigRat -> bpi(7);        # précision spécifiée

Retourne une approximation rationnelle de PI précise à la précision spécifiée ou à la précision par défaut si aucune précision n'est spécifiée. Si appelée en tant que méthode d'instance, la valeur est affectée à l'invocateur.

$x = Math::BigRat -> bpi(1);        # retourne "3"
$x = Math::BigRat -> bpi(3);        # retourne "22/7"
$x = Math::BigRat -> bpi(7);        # retourne "355/113"
copy()
my $z = $x->copy();

Crée une copie profonde de l'objet.

Veuillez consulter la documentation dans Math::BigInt pour plus de détails.

as_int()
$y = $x -> as_int();        # $y est un Math::BigInt

Retourne $x sous forme d'objet Math::BigInt quel que soit le passage à une classe supérieure ou inférieure. Si $x est fini, mais pas un entier, $x est tronqué.

as_rat()
$y = $x -> as_rat();        # $y est un Math::BigRat

Retourne $x sous forme d'objet Math::BigRat quel que soit le passage à une classe supérieure ou inférieure. L'invocateur n'est pas modifié.

as_float()
$x = Math::BigRat->new('13/7');
print $x->as_float(), "\n";             # '1'
$x = Math::BigRat->new('2/3');
print $x->as_float(5), "\n";            # '0.66667'

Retourne une copie de l'objet sous forme d'objet Math::BigFloat quel que soit le passage à une classe supérieure ou inférieure, en préservant la précision souhaitée, ou les 40 chiffres par défaut.

bround()/round()/bfround()
Ne sont pas encore implémentés.
is_zero()
print "$x est 0\n" if $x->is_zero();

Retourne vrai si $x est exactement zéro, faux sinon.

is_one()
print "$x est 1\n" if $x->is_one();

Retourne vrai si $x est exactement un, faux sinon.

is_finite()
$x->is_finite();    # vrai si $x n'est ni +inf, ni -inf, ni NaN

Retourne vrai si l'invocateur est un nombre fini, c'est-à-dire qu'il n'est ni +inf, ni -inf, ni NaN.

is_positive()
is_pos()
print "$x est >= 0\n" if $x->is_positive();

Retourne vrai si $x est positif (supérieur ou égal à zéro), faux sinon. Veuillez noter que '+inf' est également positif, tandis que 'NaN' et '-inf' ne le sont pas.

« is_positive() » est un alias pour « is_pos() ».

is_negative()
is_neg()
print "$x est < 0\n" if $x->is_negative();

Retourne vrai si $x est négatif (inférieur à zéro), faux sinon. Veuillez noter que '-inf' est également négatif, tandis que 'NaN' et '+inf' ne le sont pas.

« is_negative() » est un alias pour « is_neg() ».

is_odd()
print "$x est impair\n" if $x->is_odd();

Retourne vrai si $x est impair, faux sinon.

is_even()
print "$x est pair\n" if $x->is_even();

Retourne vrai si $x est pair, faux sinon.

is_int()
print "$x est un entier\n" if $x->is_int();

Retourne vrai si $x a un dénominateur de 1 (c'est-à-dire pas de partie fractionnaire), faux sinon. Veuillez noter que '-inf', 'inf' et 'NaN' ne sont pas des entiers.

Méthodes de comparaison

Aucune de ces méthodes ne modifie l'objet invocateur. Notez qu'un "NaN" n'est ni inférieur, ni supérieur, ni égal à quoi que ce soit d'autre, même à un "NaN".

bcmp()
$x->bcmp($y);

Compare $x

avec $y et prend en compte le signe. Retourne -1, 0, 1 ou undef.

bacmp()
$x->bacmp($y);

Compare $x à $y en ignorant leur signe. Retourne -1, 0, 1 ou undef.

beq()
$x -> beq($y);

Retourne vrai si et seulement si $x est égal à $y, et faux sinon.

bne()
$x -> bne($y);

Retourne vrai si et seulement si $x n'est pas égal à $y, et faux sinon.

blt()
$x -> blt($y);

Retourne vrai si et seulement si $x est inférieur à $y, et faux sinon.

ble()
$x -> ble($y);

Retourne vrai si et seulement si $x est inférieur ou égal à $y, et faux sinon.

bgt()
$x -> bgt($y);

Retourne vrai si et seulement si $x est supérieur à $y, et faux sinon.

bge()
$x -> bge($y);

Retourne vrai si et seulement si $x est supérieur ou égal à $y, et faux sinon.

blsft()/brsft()
Utilisé pour décaler les nombres vers la gauche/droite.

Veuillez consulter la documentation de Math::BigInt pour plus de détails.

bneg()
$x->bneg();

Utilisé pour nier l'objet sur place.

bnorm()
$x->bnorm();

Réduit le nombre à sa forme la plus courte. Cette routine est appelée automatiquement chaque fois qu'elle est nécessaire.

binc()
$x->binc();

Incrémente $x de 1 et retourne le résultat.

bdec()
$x->bdec();

Décrémente $x de 1 et retourne le résultat.

badd()
$x->badd($y);

Ajoute $y à $x et retourne le résultat.

bsub()
$x->bsub($y);

Soustrait $y de $x et retourne le résultat.

bmul()
$x->bmul($y);

Multiplie $x par $y et retourne le résultat.

bdiv()
$q = $x->bdiv($y);
($q, $r) = $x->bdiv($y);

En contexte scalaire, divise $x par $y et retourne le résultat. En contexte de liste, effectue une division entière (division F), retournant un entier $q et un reste $r tels que $x = $q * $y + $r. Le reste (modulo) est égal à ce qui est retourné par "$x->bmod($y)".

bmod()
$x->bmod($y);

Retourne $x modulo $y. Lorsque $x est fini, et $y est fini et non nul, le résultat est identique au reste après une division entière (division F). Si, en outre, $x et $y sont des entiers, le résultat est identique au résultat de l'opérateur % de Perl.

binv()
$x->binv();

Inverse de $x.

bsqrt()
$x->bsqrt();

Calcule la racine carrée de $x.

bpow()
$x->bpow($y);

Calcule $x ** $y.

Veuillez consulter la documentation de Math::BigInt pour plus de détails.

broot()
$x->broot($n);

Calcule la racine N-ième de $x.

bmodpow()
$num->bmodpow($exp,$mod);           # exponentiation modulaire
                                    # ($num**$exp % $mod)

Retourne la valeur de $num élevé à la puissance $exp dans le module $mod en utilisant l'exponentiation binaire. "bmodpow" est bien supérieur à l'écriture

$num ** $exp % $mod

car c'est beaucoup plus rapide : il réduit les variables internes au module chaque fois que c'est possible, donc il opère sur des nombres plus petits.

"bmodpow" prend également en charge les exposants négatifs.

bmodpow($num, -1, $mod)

est exactement équivalent à

bmodinv($num, $mod)
bmodinv()
$x->bmodinv($mod);          # inverse multiplicative modulaire

Retourne l'inverse multiplicative de $x modulo $mod. Si

$y = $x -> copy() -> bmodinv($mod)

alors $y est le nombre le plus proche de zéro, et avec le même signe que $mod, satisfaisant

($x * $y) % $mod = 1 % $mod

Si $x et $y sont non nuls, ils doivent être premiers entre eux, c'est-à-dire "bgcd($y, $mod)==1". '"NaN"' est retourné lorsqu'il n'existe pas d'inverse multiplicative modulaire.

blog()
$x->blog($base, $accuracy);         # logarithme de x en base $base

Si $base n'est pas défini, le nombre d'Euler (e) est utilisé :

print $x->blog(undef, 100);         # log(x) à 100 décimales
bexp()
$x->bexp($accuracy);        # calcule e ** X

Calcule deux entiers A et B tels que A/B est égal à "e ** $x", où "e" est le nombre d'Euler.

Cette méthode a été ajoutée dans la version v0.20 de Math::BigRat (mai 2007).

Voir aussi "blog()".

bnok()
Voir "bnok()" dans Math::BigInt.
bperm()
Voir "bperm()" dans Math::BigInt.
bfac()
$x->bfac();

Calcule la factorielle de $x. Par exemple :

print Math::BigRat->new('3/1')->bfac(), "\n";   # 1*2*3
print Math::BigRat->new('5/1')->bfac(), "\n";   # 1*2*3*4*5

Ne fonctionne actuellement que pour les entiers.

band()
$x->band($y);               # ET logique bit à bit
bior()
$x->bior($y);               # OU logique bit à bit inclusif
bxor()
$x->bxor($y);               # OU logique bit à bit exclusif
bnot()
$x->bnot();                 # NON logique bit à bit (complément à deux)
bfloor()
$x->bfloor();

Arrondit $x vers moins l'infini, c'est-à-dire définit $x au plus grand entier inférieur ou égal à $x.

bceil()
$x->bceil();

Arrondit $x vers plus l'infini, c'est-à-dire définit $x au plus petit entier supérieur ou égal à $x.

bint()
$x->bint();

Arrondit $x vers zéro.

bgcd()
$x -> bgcd($y);             # PGCD de $x et $y
$x -> bgcd($y, $z, ...);    # PGCD de $x, $y, $z, ...

Retourne le plus grand commun diviseur (PGCD), qui est le nombre avec la plus grande valeur absolue tel que $x/$gcd, $y/$gcd, ... est un entier. Par exemple, lorsque les opérandes sont 4/5 et 6/5, le PGCD est 2/5. Ceci est une généralisation du PGCD ordinaire pour les entiers. Voir "gcd()" dans Math::BigInt.

digit()
print Math::BigRat->new('123/1')->digit(1);     # 1
print Math::BigRat->new('123/1')->digit(-1);    # 3

Renvoie le N-ième chiffre de X, X étant une valeur entière.

$len = $x->length();

Renvoie la longueur de $x en chiffres pour les valeurs entières.

($n, $d) = $x->parts();

Renvoie une liste contenant le numérateur (entier) et le dénominateur (entier positif sans signe) sous forme de BigInt.

$x->dparts();

Renvoie la partie entière et la partie fractionnaire.

$x->fparts();

LITÉRAUX NUMÉRIQUES

Après "use Math::BigRat ':constant'", tous les littéraux numériques dans la portée donnée sont convertis en objets "Math::BigRat". Cette conversion a lieu au moment de la compilation. Chaque nombre non entier est converti en NaN.

Par exemple,

perl -MMath::BigRat=:constant -le 'print 2**150'

imprime la valeur exacte de "2**150". Notez que sans la conversion des constantes en objets, l'expression "2**150" est calculée en utilisant les scalaires Perl, ce qui peut entraîner un résultat inexact.

Notez que les chaînes de caractères ne sont pas affectées, donc

use Math::BigRat qw/:constant/;
$x = "1234567890123456789012345678901234567890"
        + "123456789123456789";

donne ce que vous attendez. Vous devez appeler explicitement "Math::BigRat->new() sur au moins l'un des opérandes. Vous devez également mettre entre guillemets les grandes constantes pour éviter toute perte de précision :

use Math::BigRat;
$x = Math::BigRat->new("1234567889123456789123456789123456789");

Sans guillemets, Perl convertit d'abord la grande constante en une valeur flottante au moment de la compilation, puis la convertit en un objet Math::BigRat au moment de l'exécution, ce qui entraîne un résultat inexact.

Littéraux flottants hexadécimaux, octaux et binaires

Perl (et ce module) accepte les littéraux flottants hexadécimaux, octaux et binaires, mais il faut être prudent avec les versions de Perl antérieures à v5.32.0, car certaines versions de Perl agissent silencieusement et donnent un résultat incorrect. Ci-dessous quelques exemples de différentes manières d'écrire le nombre décimal 314.

Littéraux flottants hexadécimaux :

0x1.3ap+8         0X1.3AP+8
0x1.3ap8          0X1.3AP8
0x13a0p-4         0X13A0P-4

Littéraux flottants octaux (avec préfixe « 0 ») :

01.164p+8         01.164P+8
01.164p8          01.164P8
011640p-4         011640P-4

Littéraux flottants octaux (avec préfixe « 0o ») : (nécessite v5.34.0)

0o1.164p+8        0O1.164P+8
0o1.164p8         0O1.164P8
0o11640p-4        0O11640P-4

Littéraux flottants binaires :

0b1.0011101p+8    0B1.0011101P+8
0b1.0011101p8     0B1.0011101P8
0b10011101000p-2  0B10011101000P-2
