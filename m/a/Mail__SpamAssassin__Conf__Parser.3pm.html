NOM

Mail::SpamAssassin::Conf::Parser - analyser la configuration de SpamAssassin

SYNOPIS

(voir Mail::SpamAssassin)

DESCRIPTION

Mail::SpamAssassin est un module permettant d'identifier les spams grâce à l'analyse de texte et à plusieurs listes de blocage en temps réel basées sur Internet.

Cette classe est utilisée en interne par SpamAssassin pour analyser ses fichiers de configuration. Veuillez vous référer à la documentation de "Mail::SpamAssassin" pour les interfaces publiques.

STRUCTURE D'UN BLOC DE CONFIGURATION

Voici la structure d'un bloc de paramètre de configuration. Chacun est une référence de hachage (hashref) qui peut contenir ces clés :

setting
le nom du paramètre qu'il modifie, par exemple « required_score ». ceci sert également de valeur par défaut pour 'command' (ci-dessous). CECI EST REQUIS.
command
La chaîne de commande utilisée dans le fichier de configuration pour ce paramètre. Facultatif ; 'setting' sera utilisé comme commande si ceci est omis.
aliases
Un [aryref] d'autres alias pour la même commande. facultatif.
type
Le type de ce paramètre : 
- $CONF_TYPE_NOARGS: ne doit pas avoir d'argument, comme "clear_headers"
- $CONF_TYPE_STRING: chaîne de caractères
- $CONF_TYPE_NUMERIC: valeur numérique (flottant ou entier)
- $CONF_TYPE_BOOL: booléen (0/non ou 1/oui)
- $CONF_TYPE_TEMPLATE: modèle, comme "report"
- $CONF_TYPE_ADDRLIST: liste d'adresses e-mail, comme "welcomelist_from"
- $CONF_TYPE_HASH_KEY_VALUE: paire clé/valeur de hachage, comme "describe" ou tflags
- $CONF_TYPE_STRINGLIST liste de chaînes, stockée comme un tableau
- $CONF_TYPE_IPADDRLIST liste d'adresses IP, stockée comme un tableau de SA::NetSet
- $CONF_TYPE_DURATION un intervalle de temps non négatif en secondes - une valeur numérique
                     (flottant ou entier), éventuellement suffixé par une unité de temps (s, m,
                     h, d, w), les secondes sont implicites si l'unité est manquante

Si ceci est défini, et qu'un bloc 'code' n'existe pas déjà, un bloc 'code' est attribué en fonction du type.

En outre, la suite de tests SpamAssassin validera que les paramètres ne « fuient » pas entre les utilisateurs.

Notez que les paramètres de type $CONF_TYPE_HASH_KEY_VALUE nécessitent que la valeur ne soit pas vide, sinon un message d'avertissement sera généré.

code
Une sous-routine pour traiter le paramètre. L'UN DES éléments code OU type EST REQUIS. Les arguments passés à la fonction sont "($self, $key, $value, $line)", où $key est le paramètre (*pas* la commande), $value est la chaîne de valeur, et $line est la ligne entière.

Il existe deux valeurs de retour spéciales que la sous-routine code peut retourner pour signaler une erreur dans la configuration :

$Mail::SpamAssassin::Conf::MISSING_REQUIRED_VALUE -- ce paramètre exige qu'une valeur soit définie, mais aucune n'a été fournie.

$Mail::SpamAssassin::Conf::INVALID_VALUE -- ce paramètre exige une valeur parmi un ensemble de valeurs « valides », mais l'utilisateur a fourni une valeur invalide.

$Mail::SpamAssassin::Conf::INVALID_HEADER_FIELD_NAME -- ce paramètre exige un nom de champ d'en-tête syntaxiquement valide, mais l'utilisateur a fourni un nom invalide.

Toute autre valeur — y compris "undef" — retournée par la sous-routine est considérée comme un succès.

Il est conseillé de définir un 'type', si possible, décrivant comment vos paramètres sont stockés dans l'objet Conf ; cela permet à la suite de tests SpamAssassin de valider que les paramètres ne « fuient » pas entre les utilisateurs.

default
La valeur par défaut pour le paramètre. peut être omis si la valeur par défaut est d'un type non scalaire, qui doit être défini dans le constructeur de Conf. note pour les types de chemin : utiliser « __userstate__ » est recommandé pour les valeurs par défaut, car cela permet aux utilisateurs du module Mail::SpamAssassin qui définissent ce paramètre de configuration de recevoir les valeurs correctes.
is_priv
Défini à 1 si ce paramètre nécessite 'allow_user_rules' lorsqu'il est exécuté à partir de spamd.
is_admin
Défini à 1 si ce paramètre ne peut être défini que dans la configuration globale lorsqu'il est exécuté à partir de spamd. (Tous les paramètres peuvent être utilisés par des programmes locaux exécutés directement par l'utilisateur.)
