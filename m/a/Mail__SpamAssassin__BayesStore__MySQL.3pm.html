NOM

Mail::SpamAssassin::BayesStore::MySQL - Implémentation du module de stockage bayésien spécifique à MySQL

DESCRIPTION

Ce module implémente un module de stockage bayésien basé spécifiquement sur MySQL. Il nécessite que vous utilisiez au moins la version 4.1 de MySQL. Si vous utilisez une version de MySQL inférieure à 4.1, plusieurs aspects de ce module échoueront et pourraient potentiellement corrompre les données de votre base de données bayésienne.

De plus, ce module supportera le rollback en cas d'erreur si vous utilisez le type de table de base de données InnoDB dans MySQL. Pour plus d'informations, veuillez consulter les instructions dans sql/README.bayes.

Ce module est également compatible avec MariaDB et DBD::MariaDB peut être utilisé à la place du pilote DBD::mysql.

MÉTHODES

expiration_jeton

instance publique (Entier, Entier,
Entier, Entier) expiration_jeton(\% $opts,
Entier $newdelta,
@ @vars)

Description : Cette méthode effectue l'expiration spécifique à la base de données des jetons en fonction de $newdelta et @vars passés.

seen_put

publique (Booléen) seen_put (chaîne $msgid,
caractère $flag)

Description : Cette méthode enregistre $msgid comme étant du type donné par $flag. $flag est l'une des deux valeurs : 's' pour spam et 'h' pour ham.

seen_delete

instance publique (Booléen) seen_delete (chaîne $msgid)

Description : Cette méthode supprime $msgid de la base de données.

set_last_expire

instance publique (Booléen) set_last_expire (Entier $time)

Description : Cette méthode définit l'heure de la dernière expiration.

set_running_expire_tok

instance publique (Chaîne $time) set_running_expire_tok ()

Description : Cette méthode définit l'heure à laquelle une expiration commence à s'exécuter.

remove_running_expire_tok

instance publique (Booléen) remove_running_expire_tok ()

Description : Cette méthode supprime la ligne dans la base de données qui indique qu'une expiration est en cours d'exécution.

tok_get

instance publique (Entier, Entier, Entier) tok_get (Chaîne $token)

Description : Cette méthode récupère un jeton spécifié ($token) de la base de données et retourne son nombre de spams, son nombre de ham et l'heure du dernier accès.

tok_get_all

instance publique (\@) tok_get (@ $tokens)

Description : Cette méthode récupère les jetons spécifiés ($tokens) du stockage et retourne une référence de tableau de tableaux contenant le nombre de spams, le nombre de ham et l'heure du dernier accès.

nspam_nham_change

instance publique (Booléen) nspam_nham_change (Entier $num_spam,
Entier $num_ham)

Description : Cette méthode met à jour le nombre de spams et le nombre de ham dans la base de données.

tok_touch

instance publique (Booléen) tok_touch (Chaîne $token,
Chaîne $atime)

Description : Cette méthode met à jour l'heure d'accès ($atime) des jetons spécifiés ($token).

On suppose que le jeton existe déjà dans la base de données.

tok_touch_all

instance publique (Booléen) tok_touch (@ $tokens
Chaîne $atime)

Description : Cette méthode effectue une mise à jour en masse de la liste des jetons spécifiés ($tokens), si l'heure d'accès existante du jeton est inférieure à $atime.

On suppose que les jetons existent déjà dans la base de données.

Nous ne devrions jamais manipuler plus de N_SIGNIFICANT_TOKENS, nous pouvons donc faire des hypothèses sur la façon de gérer les données (c'est-à-dire qu'il n'est pas nécessaire de grouper par lots comme nous le faisons dans tok_get_all).

cleanup

instance publique (Booléen) cleanup ()

Description : Cette méthode effectue tout nettoyage nécessaire avant de passer à l'opération suivante.

clear_database

instance publique (Booléen) clear_database ()

Description : Cette méthode supprime tous les enregistrements pour un utilisateur particulier.

Les appelants doivent être conscients que toute erreur renvoyée par cette méthode pourrait entraîner une incohérence de la base de données pour l'utilisateur donné.
