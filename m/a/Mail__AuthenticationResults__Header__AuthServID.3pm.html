NOM

Mail::AuthenticationResults::Header::AuthServID - Classe modélisant la partie AuthServID de l'en-tête Authentication Results

VERSION

version 2.20250709

DESCRIPTION

L'AuthServID est généralement la première section d'un en-tête Authentication Results ; il enregistre le serveur responsable de l'exécution des vérifications Authentication Results, et peut également contenir un numéro de version (supposé être 1 s'il n'est pas présent).

Certains fournisseurs ajoutent également des entrées secondaires supplémentaires au champ, c'est pourquoi cette classe est capable d'être un parent pour les types de version, de commentaire et d'entrée secondaire.

Cette classe est définie comme la valeur d'une classe Mail::AuthenticationResults::Header.

Veuillez consulter Mail::AuthenticationResults::Header::Base
