NOM

Mail::Message::Field::Structured - une ligne d'un en-tête de message structuré

HÉRÉDITÉ

Mail::Message::Field::Structured
  est un Mail::Message::Field::Full
  est un Mail::Message::Field
  est un Mail::Reporter
Mail::Message::Field::Structured est étendu par
  Mail::Message::Field::Addresses
  Mail::Message::Field::AuthResults
  Mail::Message::Field::DKIM
  Mail::Message::Field::Date
  Mail::Message::Field::URIs

SYNOPIS

my $f = Mail::Message::Field::Full
           ->new('Content-Type' => 'text/html');
my @encode = (charset => 'jp', use_continuations => 1);
$f->attribute('filename=passwd');
$f->attribute(filename => 'passwd', @encode);
my $attr = Mail::Message::Field::Attribute->new(...);
$f->attribute($attr);

  • new($line)

    Passe une $line telle qu'elle pourrait être trouvée dans un fichier : une ligne (potentiellement pliée) qui est terminée par un saut de ligne.

  • new($name, $body, @attributes, %options)

    Un ensemble de valeurs qui façonnent la ligne.

Le $name est un nom d'en-tête bien formé (vous pouvez utiliser wellformedName()) pour être sûr de la casse. Le $body est une chaîne, un objet de corps, ou un TABLEAU d'objets de corps. Dans le cas d'objets, ils doivent correspondre au constructeur du champ : les types acceptés peuvent différer. La LISTE @attributes contient des objets Mail::Message::Field::Attribute. Enfin, il y a quelques %options. Améliore la base, voir "METHODS" dans Mail::Message::Field::Full

-Option    --Défini dans                --Par défaut
 attributes                              +[ ]
 charset     Mail::Message::Field::Full  undef
 datum                                   undef
 encoding    Mail::Message::Field::Full  'q'
 force       Mail::Message::Field::Full  false
 language    Mail::Message::Field::Full  undef
 log         Mail::Reporter              'WARNINGS'
 trace       Mail::Reporter              'WARNINGS'
attributes => \@attributes|\%attributes
Il existe plusieurs façons de spécifier ces attributs : passer un TABLEAU qui est une liste de paires clé-valeur représentant @attributes, ou un HASH contenant ces paires, ou un TABLEAU avec des objets Mail::Message::Field::Attribute.
charset => $charset
datum => $date
Le nom de la méthode body est très déroutant, même dans le RFC. Dans MailBox, pour des raisons historiques, body() renvoie la partie du contenu du champ avant le premier point-virgule. foldedBody() et unfoldedBody() traitent le champ entier.

Il n'y a pas de nom commun pour la partie des données avant les paramètres (attributs) dans le contenu du champ mentionné dans les RFC, appelons-la donc "datum".

encoding => 'q'|'Q'|'b'|'B'
force => BOOLEAN
language => $language
log => LEVEL
trace => LEVEL

» exemple: d'un champ structuré

my @attrs   = (Mail::Message::Field::Attribute->new(...), ...);
my %options = (extra => 'la couleur bleue');
my $t = Mail::Message::Field::Full->new(To => \@addrs, @attrs, %options);

Accès au contenu

Étend "Accès au contenu" dans Mail::Message::Field::Full.

$obj->addresses()
Hérité, voir "Accès au contenu" dans Mail::Message::Field
$obj->attrPairs()
Retourne une liste avec les paires nom d'attribut et valeur.
$obj->attribute( $object|<STRING, %options>|<$name,$value,%options> )
Ajoute un attribut au champ. Les attributs sont ajoutés de gauche à droite dans la représentation textuelle du champ, bien que l'ordre des attributs n'ait pas d'importance, selon les RFC.

Vous pouvez passer un objet Mail::Message::Field::Attribute entièrement préparé comme $object, si vous souhaitez effectuer vous-même toutes les préparations pour une représentation correcte des données. Vous pouvez également passer une seule "STRING", qui est un attribut entièrement préparé. Cette "STRING" ne sera pas modifiée, alors faites attention aux guillemets et aux encodages.

Comme troisième possibilité, vous pouvez spécifier un nom d'attribut $name et sa valeur $value. Un objet attribut vous sera créé implicitement dans les deux cas où un tel objet n'est pas fourni, en passant les %options. Voir Mail::Message::Field::Attribute::new() pour les %options disponibles.

L'objet attribut est retourné, cependant, lorsque des continuations sont utilisées, il peut s'agir d'un objet que vous connaissez déjà. "undef" est retourné lorsque la construction échoue (lorsque l'attribut est incorrect). Améliore la base, voir "Accès au contenu" dans Mail::Message::Field

» exemple:

$f->attribute(filename => 'passwd');
$f->attribute(filename => 'passwd', use_continuations => 0);
my $attr = Mail::Message::Field::Attribute->new(...);
$f->attribute($attr);
$obj->attributes()
Retourne une liste avec tous les attributs, qui sont tous des objets Mail::Message::Field::Attribute. Les attributs ne sont pas ordonnés de quelque manière que ce soit. La liste peut être vide. Les attributs doubles ou les continuations sont fusionnés en un seul. Améliore la base, voir "Accès au contenu" dans Mail::Message::Field

DIAGNOSTICS

Avertissement : Le contenu du champ n'est pas numérique : $content
La valeur numérique d'un champ est demandée (par exemple, les champs "Lines" ou "Content-Length" devraient être numériques), cependant les données contiennent des caractères étranges. Lancé par toInt()
Erreur : Nom de champ trop long (max $length), dans '$name'
Il n'est pas spécifié dans les RFC quelle est la longueur maximale d'un nom de champ, mais au moins il devrait être quelques caractères plus court que la limite de retour à la ligne. Lancé par fold()
Avertissement : Caractère illégal dans le jeu de caractères '$charset'
Le champ est créé avec une chaîne utf8 qui ne contient que des données du jeu de caractères spécifié. Cependant, ce jeu de caractères ne peut jamais être un nom valide car il contient des caractères qui ne sont pas autorisés. Lancé par encode()
Avertissement : Caractère illégal dans le nom de champ $name
Un nouveau champ est en cours de création et contient des caractères non autorisés par les RFC. L'utilisation de ce champ dans des messages peut casser d'autres clients de messagerie ou agents de transfert, et donc mutiler ou détruire votre message. Lancé par consume()
Avertissement : Caractère illégal dans la langue '$lang'
Le champ est créé avec des données spécifiées pour être dans une certaine langue, cependant, le nom de la langue ne peut pas être valide : il contient des caractères qui ne sont pas autorisés par les RFC. Lancé par encode()
Avertissement : Encodage illégal '$encoding', utilisé 'q'
Les RFC n'autorisent que l'encodage base64 ("b " ou "B ") ou quoted-printable ("q" ou "Q"). D'autres options que ces quatre sont illégales. Lancé par encode()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode alors qu'il le devrait. Ce message signifie que certaines autres classes apparentées implémentent cette méthode alors que la classe en question ne le fait pas. Vous devriez probablement enquêter à ce sujet et probablement en informer l'auteur du paquet. Lancé par notImplemented()
