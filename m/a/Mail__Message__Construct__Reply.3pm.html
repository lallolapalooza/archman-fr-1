NOM

Mail::Message::Construct::Reply - répondre à un Mail::Message

SYNOPSIS

my Mail::Message $reply = $message->reply;
my $quoted  = $message->replyPrelude($head->get('From'));

DESCRIPTION

Les fonctionnalités complexes sur les objets Mail::Message sont implémentées dans différents fichiers qui sont chargés à la demande. Ce fichier implémente les fonctionnalités liées à la création de réponses aux messages.

MÉTHODES

Construction d'un message

$obj->reply(%options)
Démarre une réponse à ce message. Certaines des lignes d'en-tête du message original seront prises. Un identifiant de message sera attribué. Certaines lignes d'en-tête seront mises à jour pour faciliter la détection des fils de discussion (voir Mail::Box::Thread::Manager).

Vous pouvez répondre à un message entier ou à une partie de message. Vous pourriez vouloir outrepasser certains des paramètres d'en-tête par défaut pour la réponse immédiatement, ou vous pouvez le faire plus tard avec "set" sur l'en-tête.

Les ADRESSES peuvent être spécifiées sous forme de chaîne de caractères, ou d'objet Mail::Address, ou sous forme de tableau d'objets Mail::Address.

Toutes les %options qui ne sont pas listées ci-dessous ET qui commencent par une majuscule, seront ajoutées comme en-têtes supplémentaires à la réponse.

-Option         --Défaut
 Bcc              undef
 Cc               <'cc' dans le courant>
 From             <'to' dans le courant>
 Message-ID       <généré de manière unique>
 Subject          replySubject()
 To               <expéditeur dans le courant>
 body             undef
 group_reply      true
 include          'INLINE'
 max_signature    10
 message_type     Mail::Message
 postlude         undef
 prelude          undef
 quote            '> '
 signature        undef
 strip_signature  qr/^--\s/
Bcc => ADRESSES
Destinataires de copies carbone sans publication : leurs noms ne seront pas rendus publics aux autres destinataires du message.
Cc => ADRESSES
Les destinataires en copie carbone, par défaut une copie du champ "Cc" du message source.
From => ADRESSES
Votre identification, par défaut prise du champ "To" du message source.
Message-ID => CHAÎNE
Fournissez une CHAÎNE comme identifiant de message spécifique pour la réponse. Par défaut, un est généré pour vous. S'il n'y a pas d'angles autour de votre identifiant, ils seront ajoutés.
Subject => CHAÎNE|CODE
Force la ligne d'objet à la CHAÎNE spécifique, ou au résultat de la subroutine spécifiée par CODE. La subroutine sera appelée en passant l'objet du message original comme seul argument. Par défaut, Mail::Message::replySubject() est utilisé.
To => ADRESSES
La destination de votre message. Par défaut prise du champ "Reply-To" du message source. Si ce champ n'est pas présent non plus, la ligne "From" est analysée. Si tout échoue, "undef" est retourné par cette méthode : aucun message de réponse produit.
body => CORPS
Habituellement, la méthode de réponse peut créer un message agréable et suffisant à partir du corps du message source. Dans le cas où vous souhaitez un reformatage plus compliqué, vous pouvez également créer un corps vous-même au préalable, et le passer à cette méthode "reply". Certaines des autres options de cette méthode seront ignorées dans ce cas.
group_reply => BOOLEEN
Les personnes listées dans les en-têtes "Cc" (celles qui ont reçu le message auquel vous répondez maintenant) recevront-elles aussi ce message en copie carbone ?
include => 'NO'|'INLINE'|'ATTACH'
Faut-il inclure le message auquel il s'agit d'une réponse dans le message ? Si "NO" alors non. Avec "INLINE" un corps de réponse est composé. "ATTACH" créera un corps multi-parties, où le message original est ajouté après le corps spécifié. Il n'est possible d'intégrer que des messages textuels, par conséquent les messages binaires ou multipartites seront toujours joints en tant que pièce jointe.
max_signature => ENTIER
Passé à "stripSignature" sur le corps en tant que paramètre "max_lines". Seulement efficace pour les messages à partie unique.
message_type => CLASSE
Crée un message avec le type demandé. Par défaut, ce sera un Mail::Message. C'est correct, car il sera converti dans le type de message de dossier approprié lorsqu'il sera ajouté à ce dossier.
postlude => CORPS|LIGNES
La ou les lignes qui seront ajoutées après les lignes de réponse citées. Créez d'abord un corps. Cela ne devrait pas inclure la signature, qui a sa propre option. La signature sera ajoutée après l'épilogue lorsque la réponse sera INTÉGRÉE.
prelude => CORPS|LIGNES
La ou les lignes qui seront ajoutées avant les lignes de réponse citées. Si rien n'est spécifié, le résultat de la méthode replyPrelude() est pris. Lorsque "undef" est spécifié, aucun préambule ne sera ajouté.
quote => CODE|CHAÎNE
Modifie les lignes d'une réponse INTÉGRÉE avec CODE, ou en ajoutant une CHAÎNE au début de chaque ligne. La routine spécifiée par CODE est appelée lorsque la ligne est dans $_.

Par défaut, '> ' est ajouté avant chaque ligne. Spécifiez "undef" pour désactiver la citation. Cette option est traitée après que le corps ait été décodé.

signature => CORPS|MESSAGE
La signature à ajouter en cas de réponse multipartite. Le type mime du corps de la signature devrait indiquer qu'il est utilisé comme tel. Cependant, en mode INTÉGRÉ, le corps sera pris, une ligne contenant '-- ' sera ajoutée avant, et ajoutée derrière l'épilogue.
strip_signature => REGEXP|CHAÎNE|CODE
Supprime la signature de l'expéditeur. La valeur de ce paramètre est passée à Mail::Message::Body::stripSignature(pattern) sauf si le texte source n'est pas inclus. La signature est retirée du message avant la citation.

Lorsqu'un corps multipart est rencontré, et que le message est inclus pour être JOINT, les parties qui ressemblent à des signatures seront supprimées. S'il ne reste qu'un seul message, il sera ajouté comme une seule pièce jointe, sinon un multipart imbriqué sera le résultat. La valeur de cette option n'a pas d'importance, tant qu'elle est présente. Voir Mail::Message::Body::Multipart.

» exemple :

my $reply = $msg->reply(
  prelude         => "Pas de spam, s'il vous plaît !\n\n",
  postlude        => "\nSalutations\n",
  strip_signature => 1,
  signature       => $my_pgp_key,
  group_reply     => 1,
  'X-Extra'       => 'en-tête supplémentaire',
);
$obj->replyPrelude( [CHAÎNE|$champ|$adresse|TABLEAU-de-ces-choses] )
Produit une liste de lignes (généralement une seule), qui précéderont le corps cité du message. "CHAÎNE" doit être conforme à la spécification d'adresse e-mail RFC822, et est généralement le contenu d'une ligne d'en-tête "To" ou "From". Si un $champ est spécifié, le corps du champ doit être conforme. Sans argument -ou lorsque l'argument est "undef"- une ligne légèrement différente est produite.

$any->replySubject(CHAÎNE)
Crée un sujet pour un message qui est une réponse à celui-ci. Cette routine tente de compter le niveau de réponse dans le champ sujet, et de le transformer en une forme standard. Veuillez contribuer aux améliorations.

» exemple :

subject                 --> Re: subject
Re: subject             --> Re[2]: subject
Re[X]: subject          --> Re[X+1]: subject
subject (Re)            --> Re[2]: subject
subject (Forw)          --> Re[2]: subject
<vide>                  --> Re: votre mail

DIAGNOSTICS

Erreur : Impossible d'inclure la source de la réponse en tant que $include.
Option inconnue pour l'option « include » de reply(). Les choix valides sont "NO", "INLINE", et "ATTACH". Lancé par reply()
