NOM

Mail::Message::Head::ListGroup - champs d'en-tête liés aux listes de diffusion

HIÉRARCHIE

Mail::Message::Head::ListGroup
  est un Mail::Message::Head::FieldGroup
  est un Mail::Reporter

SYNOPSIS

my $lg = Mail::Message::Head::ListGroup->new(head => $head, ...);
$head->addListGroup($lg);
my $lg = $head->addListGroup(...);
$lg->delete;

DESCRIPTION

Un *groupe de listes* est un ensemble de champs d'en-tête ajoutés par les logiciels de gestion de listes de diffusion. Cette classe connaît divers détails sur ces logiciels.

Les connaissances et les messages de test utilisés pour implémenter initialement ce module proviennent de Mail::ListDetector, écrit par Michael Stevens mailto:michael@etla.org. La logique est repensée pour ajouter de la flexibilité et utiliser les fonctionnalités puissantes de MailBox.

$obj->collectFields()
Analyse l'en-tête à la recherche des champs qui sont généralement contenus dans les logiciels de listes de diffusion. Cette méthode est appelée automatiquement lorsqu'un groupe de listes est construit from() un en-tête ou un message existant.

Sont retournés les noms des champs d'en-tête de liste trouvés, en contexte scalaire le nombre. Une liste/un zéro vide indique qu'il ne s'agit pas d'un message de liste de diffusion.

NOM

Mail::Message::Head::ListGroup - détection des listes de diffusion dans un en-tête de message

INHERITANCE

Extends Mail::Message::Head::FieldGroup.

$obj->addList( $type, $address )
Ajoute une nouvelle liste à détecter.
$obj->all()
Retourne une liste de toutes les listes de diffusion détectées.
$obj->collect()

Détecte toutes les listes de diffusion connues dans les en-têtes.

Les listes sont triées par ordre alphabétique de leur nom de type.

$obj->find( $type )

Trouve la liste de diffusion du type spécifié.

Exemple:

  $obj->find('ListServ')
$obj->import( $file )
Lit la définition des listes depuis un fichier.
$obj->remove( $type )
Supprime une liste de la détection.
$obj->type( $type )

Retourne le type de la liste de diffusion.

Exemple:

  $obj->type('ListServ') # Retourne 'ListServ'

SYNOPSIS

  use Mail::Message::Head::ListGroup;

  my $group = Mail::Message::Head::ListGroup->new;

  # Détecter les listes connues
  $group->collect;

  # Obtenir la liste des listes trouvées
  my @lists = $group->all;

  # Obtenir une liste spécifique
  my $listserv = $group->find('ListServ');
  if ($listserv) {
    print "Liste ListServ trouvée\n";
  }

DESCRIPTION

La classe Mail::Message::Head::ListGroup gère la détection des champs d'en-tête spécifiques aux listes de diffusion.

Elle peut identifier un grand nombre de logiciels de listes de diffusion, y compris ceux définis par les RFC 2919 et 2369.

DÉTAILS

Champs de listes de diffusion

Listes détectées

La classe Mail::Message::Head::ListGroup peut détecter de nombreuses listes de diffusion différentes, certaines très populaires et d'autres rares.

De nombreux champs dans un en-tête sont ajoutés lorsque le message transite par un serveur de listes de diffusion. Chaque logiciel de liste a défini ses propres champs, parfois avec des définitions contradictoires. Il existe également deux RFC sur les listes de diffusion : "rfc2919" et "rfc2369".

Les listes suivantes sont actuellement détectées. Entre parenthèses se trouve la chaîne retournée par type() lorsque celle-ci diffère du nom du logiciel.

  • CommuniGate

    Implémentation commerciale historique pour MacOS par Stalker Software Inc. https://www.stalker.com/mac/default.html

  • CommuniGate Pro (CommuniGatePro)

    Implémentation commerciale conforme à la RFC 2919 par Stalker Software Inc. https://www.stalker.com

  • Ecartis

    Gestionnaire de listes de diffusion commercial, anciennement connu sous le nom de Listar. Produit par NodeRunner Computing. Voir https://www.ecartis.com.

  • Ezmlm

    Gestionnaire de listes de diffusion open source, disponible sur https://www.ezmlm.org.

  • FML

    Gestionnaire de listes de diffusion open source, voir https://www.fml.org.

  • Listar

    Ancien nom d'Ecartis.

  • Listbox

    Listes de diffusion définies sur https://listbox.com.

  • Mailman

    Gestionnaire de listes de diffusion de GNU, disponible sur https://www.list.org.

  • Majordomo

    Gestionnaire de listes de diffusion gratuit (sous licence) par Great Circle Associates, disponible sur https://www.greatcircle.com/majordomo/

  • Smartlist
