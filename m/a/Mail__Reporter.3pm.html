SYNOPSIS

$folder->log(WARNING => 'dégage');
print $folder->trace;        # niveau actuel
$folder->trace('PROGRESS');  # définir le niveau
print $folder->errors;
print $folder->report('PROGRESS');

DESCRIPTION

La classe "Mail::Reporter" est la classe de base pour toutes les classes, sauf Mail::Message::Field::Fast car cela deviendrait lent... Cette classe de base est utilisée lors de l'initialisation des objets, et pour configurer et enregistrer les messages d'erreur.

MÉTHODES

La classe "Mail::Reporter" est la base de près de tous les autres objets. Elle peut stocker et rapporter des problèmes, et contient le constructeur général new().

Constructeurs

$class->new(%options)
Ce conteneur d'erreurs est également le constructeur de base pour tous les modules, (tant qu'il n'y a pas besoin d'un autre objet de base) Le constructeur accepte toujours les %options suivantes liées aux rapports d'erreurs. 
-Option--Default
 log     'WARNINGS'
 trace   'WARNINGS'
log => NIVEAU
Les messages de log dont la priorité est supérieure ou égale au niveau spécifié sont stockés en interne et peuvent être récupérés ultérieurement. La valeur par défaut globale pour cette option peut être modifiée avec defaultTrace().

Les niveaux connus sont "INTERNAL", "ERRORS", "WARNINGS", "PROGRESS", "NOTICES" "DEBUG", et "NONE". Le niveau "PROGRESS" concerne la lecture et l'écriture des dossiers. "NONE" ne fera enregistrer que les erreurs "INTERNAL". Soit dit en passant : "ERROR" est un alias pour "ERRORS", tout comme "WARNING" est un alias pour "WARNINGS", et "NOTICE" pour "NOTICES".

trace => NIVEAU
Les messages de trace dont le niveau est supérieur ou égal au niveau spécifié sont directement affichés en utilisant warn. La valeur par défaut globale pour cette option peut être modifiée avec defaultTrace().

Attributs

$obj->logSettings()
Retourne une liste de paires "(clé =" valeur)> qui peuvent être utilisées pour initialiser un nouvel objet avec les mêmes paramètres de log que celui-ci.

» exemple :

$head->new($folder->logSettings);

Gestion des erreurs

$obj->AUTOLOAD()
Par défaut, produit un avertissement agréable si les sous-classes ne peuvent pas résoudre une méthode.
$obj->addReport($object)
Ajoute le rapport d'un autre $object au rapport de cet objet. Ceci est utile lorsque des actions complexes utilisent des objets temporaires qui ne sont pas retournés à l'application principale mais dont l'application principale aimerait connaître les problèmes.
$any->defaultTrace( [$level]|[$loglevel, $tracelevel]|[$level, $callback] )
Rapporte le niveau de log et de trace par défaut utilisé pour les objets sous forme de liste de deux éléments. Lorsqu'il n'est pas explicitement défini, les deux sont réglés sur "WARNINGS".

Cette méthode a trois utilisations différentes. Lorsqu'un seul argument est spécifié, ce $level est défini pour le loglevel et le tracelevel.

Avec deux arguments, le second détermine quelle configuration vous souhaitez. Si le deuxième argument est une référence CODE, vous installez une $callback. Le loglevel sera réglé sur NONE, et tous les avertissements produits dans votre programme seront passés à la fonction $callback. Cette fonction recevra le niveau du problème, l'objet ou la classe qui rapporte le problème, et le texte du problème en arguments.

Dans tous les cas, deux valeurs sont retournées : la première est le niveau de log, la seconde représente le niveau de trace. Ce sont deux variables spéciales : en contexte numérique, elles fournissent une valeur (la valeur utilisée en interne), et en contexte chaîne, le nom de la chaîne. Attention, la chaîne est toujours au forme singulière !

» exemple : définition des niveaux de log

my ($loglevel, $tracelevel) = Mail::Reporter->defaultTrace;
Mail::Reporter->defaultTrace('NOTICES');
my ($l, $t) = Mail::Reporter->defaultTrace('WARNINGS', 'DEBUG');
print $l;     # affiche "WARNING"  (pas de S !)
print $l+0;   # affiche "4"
print "Même pas" if $l >= $self->logPriority('ERROR');
Mail::Reporter->defaultTrace('NONE');  # silencieux tous les rapports
$folder->defaultTrace('DEBUG');   # Toujours défini comme défaut global !
$folder->trace('DEBUG');          # défaut local

» exemple : installation d'un callback

Mail::Reporter->defaultTrace
$obj->errors()
Équivalent à "<$folder-"report('ERRORS')>>
$any->log( [$level, [$strings]] )
En tant que méthode d'instance, cette fonction a trois objectifs différents. Sans aucun argument, elle retourne un scalaire contenant le nombre qui est utilisé en interne pour représenter le niveau de log actuel, et la représentation textuelle de la chaîne en même temps. Voir la méthode "dualvar" de Scalar::Util pour une explication.

Avec un argument, un nouveau niveau de détail de log est défini (spécifiez un nombre ou l'une des chaînes prédéfinies). Avec plus d'arguments, c'est un rapport qui peut devoir être enregistré ou tracé.

En tant que méthode de classe, seul un message peut être passé. La valeur de configuration globale définie avec defaultTrace() est utilisée pour décider si le message est affiché ou ignoré.

Chaque entrée de log a un $level et une chaîne de texte qui sera construite en joignant les $strings. S'il n'y a pas de nouvelle ligne, elle sera ajoutée.

» exemple :

print $message->log;      # peut afficher "NOTICE"
print $message->log +0;   # peut afficher "3"
$message->log('ERRORS');  # définit un nouveau niveau, retourne la valeur numérique
$message->log(WARNING => "Ce message est trop volumineux.");
$folder ->log(NOTICE  => "Impossible de lire depuis le fichier $filename.");
$manager->log(DEBUG   => "Salut !", reverse sort @l);
Mail::Message->log(ERROR => 'Inconnu');
$any->logPriority($level)
Un niveau d'erreur (log ou trace) a plus d'une représentation : une valeur numérique et une ou plusieurs chaînes. Par exemple, 4, 'WARNING', et 'WARNINGS' sont toutes identiques. Vous pouvez spécifier l'une quelconque d'entre elles, et en retour, vous obtenez une variable double (voir la méthode "dualvar" de Scalar::Util) qui contient le nombre et la forme singulière.

Plus le nombre est élevé, plus le message est important. Seuls les messages concernant les problèmes "INTERNAL" sont plus importants que "NONE"

NOM

NOM
Mail::Reporter - Journalisation des messages

HÉRITAGE

HÉRITAGE
Mail::Reporter ISA Mail::Reporter

SYNOPSIS

SYNOPSIS
use Mail::Reporter;

DESCRIPTION

DESCRIPTION
Mail::Reporter est un module Perl qui permet la journalisation des messages. Il fournit des méthodes pour contrôler les niveaux de journalisation et récupérer les messages journalisés.

MÉTHODES

MÉTHODES
logPriority($level) - Définit le niveau de priorité de journalisation.
notImplemented() - Journalise une erreur interne et plante, utilisé par les auteurs d'extensions.
report($level) - Retourne les rapports journalisés sous forme de liste de chaînes. Si un niveau est spécifié, retourne les journaux pour ce niveau.
reportAll($level) - Rapporte tous les messages de cet objet et de ses objets gérés. Retourne une liste de triplets avec l'objet, le niveau et le message.
trace($level) - Change le niveau de traçage de l'objet. Retourne le niveau actuel si aucun argument n'est spécifié.
warnings() - Équivalent à report('WARNINGS')
