Mail::SPF::Mech::PTR(3) Documentation Perl fournie par l'utilisateur Mail::SPF::Mech::PTR(3)

NOM

Mail::SPF::Mech::PTR - Classe de mécanisme SPF "ptr"

VERSION

version 3.20250505

DESCRIPTION

Un objet de classe Mail::SPF::Mech::PTR représente un mécanisme d'enregistrement SPF de type "ptr".

Constructeurs

Les constructeurs suivants sont fournis :

new(%options): retourne Mail::SPF::Mech::PTR
Crée un nouvel objet de mécanisme SPF "ptr".

%options est une liste de paires clé/valeur représentant l'une des options suivantes :

qualifier
domain_spec
Voir "new" dans Mail::SPF::Mech.
new_from_string($text, %options): retourne Mail::SPF::Mech::PTR; lève Mail::SPF::ENothingToParse, Mail::SPF::EInvalidMech
Crée un nouvel objet de mécanisme SPF "ptr" en analysant la chaîne et les options fournies.

Méthodes de classe

Les méthodes de classe suivantes sont fournies :

default_qualifier
qualifier_pattern
Voir "Méthodes de classe" dans Mail::SPF::Mech.
name: retourne chaîne
Retourne 'ptr'.
name_pattern: retourne Regexp
Retourne une expression régulière qui correspond au nom du mécanisme 'ptr'.

Méthodes d'instance

Les méthodes d'instance suivantes sont fournies :

text
qualifier
params
stringify
Voir "Méthodes d'instance" dans Mail::SPF::Mech.
domain_spec: retourne Mail::SPF::MacroString
Retourne le paramètre "domain-spec" du mécanisme.
match($server, $request): retourne booléen
Vérifie si le nom de domaine cible du mécanisme, ou un sous-domaine de celui-ci, est un nom de domaine "valide" pour l'adresse IP de la requête donnée (voir "ip_address" dans Mail::SPF::Request), et retourne true si c'est le cas, ou false sinon. Voir "valid_domain_for_ip_address" dans Mail::SPF::Util pour la manière dont les domaines sont validés. Voir RFC 4408, 5.5, pour la description d'un algorithme équivalent.
