NOM

Mail::Box::Net::Message - un message d'un dossier distant

HÉRITAGE

Mail::Box::Net::Message
  est un Mail::Box::Message
  est un Mail::Message
  est un Mail::Reporter
Mail::Box::Net::Message est étendu par
  Mail::Box::IMAP4::Message
  Mail::Box::POP3::Message

SYNOPSIS

my $folder = Mail::Box:POP3->new(...);
my $message = $folder->message(10);

DESCRIPTION

Un Mail::Box::Net::Message représente un message dans un dossier qui ne peut être accédé que via une sorte de protocole. Pour l'instant, seul un client POP3 est disponible. IMAP, DBI et NNTP sont d'autres candidats.

Étendu la "DESCRIPTION" dans Mail::Box::Message.

DIAGNOSTICS

Erreur : Impossible de convertir un objet $class en objet $class
Lancé par coerce()
Erreur : Impossible d'inclure une source de redirection comme $include.
Alternative inconnue pour la redirection (include). Les choix valides sont "NO", "INLINE", "ATTACH", et "ENCAPSULATE". Lancé par forward()
Erreur : Impossible d'inclure une source de réponse comme $include.
Alternative inconnue pour l'option "include" de reply(). Les choix valides sont "NO", "INLINE", et "ATTACH". Lancé par reply()
Erreur : La méthode bounce nécessite To, Cc, ou Bcc
La méthode bounce() d'un message transfère un message reçu à quelqu'un d'autre sans modification ; vous devez spécifier sa nouvelle destination. Si vous avez l'envie de ne pas spécifier de destination, vous cherchez probablement reply(). Lorsque vous souhaitez modifier le contenu, utilisez forward(). Lancé par bounce()
Erreur : La méthode forwardAttach nécessite un préambule
Lancé par forwardAttach()
Erreur : La méthode forwardEncapsulate nécessite un préambule
Lancé par forwardEncapsulate()
Erreur : Aucune adresse pour créer une redirection.
Si un message de redirection est créé, une adresse de destination doit être spécifiée. Lancé par forward()
Erreur : Aucun agent de transfert de courrier par défaut trouvé pour envoyer le message.
Le mécanisme send() du message n'avait pas assez d'informations pour trouver automatiquement un agent de transfert de courrier pour envoyer ce message. Spécifiez un agent de transfert explicitement en utilisant les options "via". Lancé par send()
Erreur : Aucune règle de reconstruction $name définie.
Lancé par rebuild()
Erreur : Seulement les messages Mail::Message construits ; ils ne sont pas encore dans un dossier
Vous souhaitez peut-être construire un message à stocker dans une sorte de dossier, mais vous devez le faire en deux étapes. D'abord, créez un Mail::Message normal, puis ajoutez-le au dossier. Pendant ce processus Mail::Box::addMessage(), le message sera converti (coerce()-d) dans le bon type de message, en ajoutant les informations de stockage, etc. Lancé par build()
