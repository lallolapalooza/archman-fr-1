MAT_VARDELETE(3) Manuel des fonctions de bibliothèque MAT_VARDELETE(3)

NOM

Mat_VarDelete — Supprime une variable MAT d'un fichier.

SYNTAXE

#include <matio.h>

int
Mat_VarDelete(mat_t *matfp, const char *name);

DESCRIPTION

La fonction Mat_VarDelete() supprime la variable MAT name du fichier MAT donné par la structure de fichier MAT matfp.

VALEURS DE RETOUR

La fonction retourne 0 en cas de succès. Sinon, une valeur d'erreur est retournée.
