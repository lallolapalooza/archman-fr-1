NOM

Mail::SpamAssassin::Plugin::AutoLearnThreshold - discriminateur basé sur le seuil pour l'apprentissage automatique de Bayes

SYNTAXE

loadplugin     Mail::SpamAssassin::Plugin::AutoLearnThreshold

DESCRIPTION

Ce plugin implémente le discriminateur d'apprentissage automatique basé sur le seuil pour le sous-système Bayes de SpamAssassin. L'apprentissage automatique est un mécanisme par lequel les courriels à score élevé (ou à score faible, pour les non-spams) sont introduits dans ses systèmes d'apprentissage sans intervention de l'utilisateur, pendant le balayage.

Notez que certains tests sont ignorés lors de la détermination si un message doit être entraîné :

  • règles avec tflags définis à 'learn' (les règles bayésiennes)
  • règles avec tflags définis à 'userconf' (configuration utilisateur)
  • règles avec tflags définis à 'noautolearn'

Notez également que l'apprentissage automatique s'effectue en utilisant les scores de l'ensemble de scores 0 ou 1, selon l'ensemble de scores utilisé lors de la vérification du message. Il est probable que les scores de vérification et d'apprentissage automatique du message soient différents.

RÉGLAGES UTILISATEUR

Les paramètres de configuration suivants sont utilisés pour contrôler l'apprentissage automatique :

bayes_auto_learn_threshold_nonspam n.nn (défaut : 0.1)
Le seuil de score en dessous duquel un courriel doit être classé, pour être introduit automatiquement dans les systèmes d'apprentissage de SpamAssassin en tant que message non-spam.
bayes_auto_learn_threshold_spam n.nn (défaut : 12.0)
Le seuil de score au-dessus duquel un courriel doit être classé, pour être introduit automatiquement dans les systèmes d'apprentissage de SpamAssassin en tant que message spam.

Note : SpamAssassin nécessite au moins 3 points de l'en-tête, et 3 points du corps pour apprendre automatiquement en tant que spam. Par conséquent, la valeur minimale fonctionnelle pour cette option est de 6.

Si l'option de test "autolearn_header" ou "autolearn_body" est définie, les points de cette règle sont forcés de compter comme provenant de l'en-tête ou du corps respectivement. Ceci peut être utile pour ajuster certaines méta-règles.

Si l'option de test "autolearn_force" est définie, la valeur minimale restera à 6 points mais il n'y a aucune exigence que les points proviennent de règles d'en-tête et de corps. Cette option est utile pour l'apprentissage automatique avec des règles considérées comme des indicateurs extrêmement fiables de la nature spam d'un message.

bayes_auto_learn_on_error (0 | 1) (défaut : 0)
Lorsque "bayes_auto_learn_on_error" est désactivé, l'apprentissage automatique sera effectué même si le classificateur bayésien est déjà d'accord avec la nouvelle classification (c'est-à-dire qu'il a produit BAYES_00 pour ce que nous essayons maintenant de lui apprendre en tant que ham, ou a produit BAYES_99 pour le spam). C'est un réglage traditionnel, le défaut a été choisi pour conserver la compatibilité rétroactive.

Lorsque "bayes_auto_learn_on_error" est activé, l'apprentissage automatique ne sera effectué que lorsqu'un classificateur bayésien avait une opinion différente de celle que l'apprenant automatique essaie maintenant de lui enseigner (c'est-à-dire qu'il a fait une erreur de jugement). Cette stratégie peut ou peut ne pas produire de meilleures classifications futures, mais fonctionne généralement très bien, tout en évitant un surapprentissage inutile et en ralentissant la croissance de la base de données.
