Magick++-Config(1) Manuel des commandes générales Magick++-Config(1)

NOM

Magick++-config - obtenir des informations sur la version installée de Magick++

SYNTAXE

Magick++-config [--cppflags] [--cxxflags] [--exec-prefix] [--ldflags] [--libs] [--prefix] [--version]

DESCRIPTION

Magick++-config imprime les options du compilateur et de l'éditeur de liens requises pour compiler et lier les programmes qui utilisent l'interface de programmation d'applications C++ d'ImageMagick (connue sous le nom de Magick++ ).

EXEMPLES

Pour imprimer la version de la distribution installée de Magick++, utilisez :

  Magick++-config --version

Pour compiler un programme qui appelle l'interface de programmation d'applications C++ d'ImageMagick, utilisez :

  c++ `Magick++-config --cxxflags --cppflags --ldflags --libs` programme.cpp

OPTIONS

--cppflags
Imprime les options du préprocesseur nécessaires pour trouver les fichiers d'en-tête C et C++ d'ImageMagick et les définitions pour assurer que les structures de données d'ImageMagick correspondent entre votre programme et les bibliothèques installées.
--cxxflags
Imprime les options du compilateur utilisées pour compiler libMagick++.
--exec-prefix
Imprime le répertoire sous lequel les binaires spécifiques à la cible et les exécutables sont installés.
--ldflags
Imprime les options de l'éditeur de liens nécessaires pour lier la bibliothèque libMagick++.
--libs
Imprime les options de l'éditeur de liens nécessaires pour lier un programme avec libMagick++.
--prefix
Imprime le répertoire sous lequel le paquet est installé.
--version
Imprime la version de la distribution ImageMagick sur la sortie standard.
