NOM

Mail::SpamAssassin::Message::Node - décoder, rendre et rendre disponibles les parties d'un message MIME

DESCRIPTION

Ce module encapsule un message de courrier électronique et permet l'accès aux différentes parties d'un message MIME.

MÉTHODES PUBLIQUES

new()
Crée et retourne un objet Node vide. Est généralement appelé par des fonctions dans Message.
find_parts()
Utilisé pour rechercher dans l'arborescence des parties MIME spécifiques. Retourne un tableau de nœuds (enfants dans l'arborescence) qui correspondent au regexp. Les paramètres qui peuvent être passés sont (dans l'ordre, tous scalaires) :

Regexp - Est utilisé pour correspondre à chaque partie d'en-tête MIME du type de contenu, spécifiquement le type et non le reste de l'en-tête. Exemple : « Content-type: text/html; encoding=quoted-printable » a un type de « text/html ». Si aucun regexp n'est spécifié, find_parts() retournera un tableau vide.

Leaves_seulement - Par défaut, find_parts() retournera toute partie qui correspond au regexp, y compris les multipart. Si vous ne voulez voir que les feuilles de l'arborescence (c'est-à-dire les parties qui ne sont pas des multipart), définissez ceci à 1 (vrai).

Récursif - Par défaut, lorsque find_parts() trouve un multipart qui a des parties en dessous, il descend récursivement vers tous les enfants. Si vous définissez à 0, vous ne verrez que la partie et ses enfants directs.

header()
Stocke et récupère les en-têtes d'une partie MIME spécifique. Le premier paramètre est le nom de l'en-tête. S'il n'y a pas d'autre paramètre, l'en-tête est récupéré. S'il y a un deuxième paramètre, l'en-tête est stocké.

Les noms d'en-tête sont insensibles à la casse et sont stockés à la fois sous forme brute et décodée. En utilisant header(), seule la forme décodée peut être récupérée.

Pour la récupération, si header() est appelé dans un contexte d'array, un tableau est retourné avec chaque entrée d'en-tête dans un élément différent. Dans un contexte scalaire, le dernier en-tête spécifique est retourné.

ex: Si 'Subject' est spécifié comme en-tête, et qu'il y a 2 en-têtes Subject dans un message, le dernier (en bas) est retourné dans le contexte scalaire ou les deux sont retournés dans le contexte d'array.

raw_header()
Récupère la version brute des en-têtes d'une partie MIME spécifique. Le seul paramètre est le nom de l'en-tête. Les noms d'en-tête sont insensibles à la casse.

Pour la récupération, si raw_header() est appelé dans un contexte d'array, un tableau est retourné avec chaque entrée d'en-tête dans un élément différent. Dans un contexte scalaire, le dernier en-tête spécifique est retourné.

ex: Si 'Subject' est spécifié comme en-tête, et qu'il y a 2 en-têtes Subject dans un message, le dernier (en bas) est retourné dans le contexte scalaire ou les deux sont retournés dans le contexte d'array.

add_body_part()
Ajoute un objet Node enfant à l'objet Node actuel.
is_leaf()
Retourne vrai si le nœud en question est une feuille de l'arborescence (c'est-à-dire qu'il n'a pas ses propres enfants). Note : cette fonction peut retourner des résultats inattendus, à moins que le message n'ait été parsé avec _do_parse() !
raw()
Retourne une référence à l'array de texte brut. Ceci est considéré comme en lecture seule.
decode()
Si nécessaire, décode le texte de la partie comme base64 ou quoted-printable. Le texte décodé est retourné sous forme de chaîne scalaire. Un paramètre optionnel peut être passé, qui limite la quantité retournée. Si le scalaire n'est pas nécessaire, appeler avec « 0 » comme paramètre.
rendered()
rendered() prend une partie MIME de type text/* et tente de la rendre en un texte scalaire. Il rend toujours text/html, et utilise une heuristique pour déterminer si d'autres parties text/* doivent être considérées comme text/html. Deux scalaires sont retournés : le type rendu (soit text/html, soit le type original), et le texte rendu.
set_rendered($texte, $type)
Définit le texte et le type rendus pour la partie donnée. Si le type n'est pas spécifié et que le texte est une valeur définie, une valeur par défaut de 'text/plain' est utilisée. Ceci peut être utilisé, par exemple, pour rendre des parties non textuelles à l'aide de plugins.
visible_rendered()
Rend et retourne le texte visible dans cette partie.
invisible_rendered()
Rend et retourne le texte invisible dans cette partie.
content_summary()
Retourne un tableau de scalaires décrivant les parties MIME du message. Note : cette fonction nécessite que le message ait été préalablement parsé !
delete_header()
Supprime l'en-tête spécifié (décodé et brut) des informations du Node.
get_header()
Récupère un en-tête spécifique. Il aura un saut de ligne à la fin et sera déplié. Le premier paramètre est le nom de l'en-tête (insensible à la casse), et le deuxième paramètre (optionnel) indique s'il faut retourner l'en-tête brut.

Si get_header() est appelé dans un contexte d'array, un tableau est retourné avec chaque entrée d'en-tête dans un élément différent. Dans un contexte scalaire, le dernier en-tête spécifique est retourné.

ex: Si 'Subject' est spécifié comme en-tête, et qu'il y a 2 en-têtes Subject dans un message, le dernier (en bas) du message est retourné dans le contexte scalaire ou les deux sont retournés dans le contexte d'array.

Note : Retourner le dernier champ d'en-tête (pas le premier) est cohérent avec les signatures DKIM, qui recherchent et couvrent plusieurs champs d'en-tête de manière descendante selon le tag 'h'. Gardez-le ainsi.

get_all_headers()
Récupère tous les en-têtes. Chaque en-tête aura un saut de ligne à la fin et sera déplié. Le premier paramètre (optionnel) indique s'il faut retourner les en-têtes bruts, et le deuxième paramètre (optionnel) indique s'il faut inclure le séparateur mbox.

Si get_all_header() est appelé dans un contexte d'array, un tableau est retourné avec chaque entrée d'en-tête dans un élément différent. Dans un contexte scalaire, les en-têtes sont retournés dans un seul scalaire.
