NOM

Mail::Box::MH::Labels - maintenir des étiquettes relatives aux messages MH

HÉRITAGE

Mail::Box::MH::Labels
  est un Mail::Reporter

SYNOPSIS

my $labels = Mail::Box::MH::Labels->new;
$labels->read(...)
$labels->write(...)

DESCRIPTION

Les dossiers de messages de type MH utilisent un fichier dédié par répertoire de dossier pour lister des étiquettes spéciales aux messages de ce dossier. En faisant cela, les agents de messagerie peuvent éviter d'analyser tous les messages, ce qui est très coûteux en ressources.

Les étiquettes peuvent être utilisées pour regrouper des messages, par exemple pour refléter quels messages ont été lus ou lesquels ressemblent à du spam. Certaines étiquettes sont prédéfinies, mais d'autres peuvent être ajoutées sans limitation.

La table des étiquettes

$obj->append($messages)
Ajoute les informations d'étiquette concernant les $messages spécifiés à la fin du fichier d'étiquettes. Les informations ne seront pas fusionnées avec les informations déjà présentes dans le fichier d'étiquettes.
$obj->get($msgnr)
Vérifie s'il y a des informations d'étiquette pour le message $msgnr.
$obj->print($fh, $messages)
Imprime les étiquettes des messages spécifiés dans le fichier ouvert.
$obj->read()
Lit toutes les informations d'étiquette depuis le fichier.
$obj->write(@messages)
Écrit les étiquettes relatives aux @messages spécifiés dans le fichier d'étiquettes.
