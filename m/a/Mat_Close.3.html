MAT_CLOSE(3) Manuel des fonctions de bibliothèque MAT_CLOSE(3)

NOM

Mat_Close — Ferme un fichier MAT MATLAB ouvert.

SYNTAXE

#include <matio.h>

int
Mat_Close(mat_t *matfp);

DESCRIPTION

La fonction Mat_Close() ferme un fichier MAT MATLAB ouvert avec Mat_Open() ou créé avec Mat_CreateVer().

VALEURS DE RETOUR

La fonction retourne 0 en cas de succès. Sinon, une valeur d'erreur est retournée.

EXEMPLES

#include "matio.h"

int main(int argc, char **argv)
{
    mat_t *matfp;

    matfp = Mat_Open(argv[1], MAT_ACC_RDONLY);
    if ( NULL == matfp ) {
        fprintf(stderr, "Erreur lors de l'ouverture du fichier MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
