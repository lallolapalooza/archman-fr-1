NOM

Mail::SpamAssassin::BayesStore::PgSQL - Implémentation du module de stockage bayésien spécifique à PostgreSQL

DESCRIPTION

Ce module implémente une implémentation spécifique à PostgreSQL d'un module de stockage bayésien.

Il hérite de Mail::SpamAssassin::BayesStore::SQL et remplace toute méthode qui fait des appels SQL liés à la colonne 'token'. Comme PostgreSQL utilise BYTEA pour le type de colonne 'token', vous devez vous assurer que le pilote DBD effectue le bon échappement. Vous pouvez y parvenir en liant la colonne 'token' à un type spécifique.

Dans les versions 8.3 et supérieures, le mode 'sync_commit' est désactivé pour améliorer les performances. Les données ne sont garanties d'être stockées qu'après (3 * wal_writer_delay) (par défaut : 0.6s) de leur écriture. Cet équilibre fonctionne bien pour le bayésien, car nous nous intéressons aux données agrégées et qu'une courte période peut être perdue sans sacrifier la précision.

MÉTHODES

token_expiration

méthode publique (Entier, Entier, Entier, Entier) token_expiration(\% $opts,
Entier $newdelta,
@ @vars)

Description : Cette méthode effectue l'expiration spécifique à la base de données des tokens basée sur la valeur passée dans $newdelta et @vars.

seen_put

méthode publique (Booléen) seen_put (chaîne $msgid,
caractère $flag)

Description : Cette méthode enregistre $msgid comme le type donné par $flag. $flag est l'une des deux valeurs : 's' pour spam et 'h' pour ham.

seen_delete

méthode publique (Booléen) seen_delete (chaîne $msgid)

Description : Cette méthode supprime $msgid de la base de données.

set_last_expire

méthode publique (Booléen) set_last_expire (Entier $time)

Description : Cette méthode définit l'heure de la dernière expiration.

set_running_expire_tok

méthode publique (chaîne $time) set_running_expire_tok ()

Description : Cette méthode définit l'heure à laquelle l'expiration commence.

remove_running_expire_tok

méthode publique (Booléen) remove_running_expire_tok ()

Description : Cette méthode supprime la ligne dans la base de données qui indique que l'expiration est en cours.

tok_get

méthode publique (Entier, Entier, Entier) tok_get (chaîne $token)

Description : Cette méthode récupère un token spécifié ($token) de la base de données et renvoie son nombre de spams, son nombre de non-spams et l'heure de sa dernière consultation.

tok_get_all

méthode publique (\@) tok_get (@ $tokens)

Description : Cette méthode récupère les tokens spécifiés ($tokens) de la base de données et renvoie une référence d'array d'arrays contenant le nombre de spams, le nombre de non-spams et l'heure de leur dernière consultation.

nspam_nham_change

méthode publique (Booléen) nspam_nham_change (Entier $num_spam,
Entier $num_ham)

Description : Cette méthode met à jour le nombre de spams et le nombre de non-spams dans la base de données.

tok_touch

méthode publique (Booléen) tok_touch (chaîne $token,
chaîne $atime)

Description : Cette méthode met à jour l'heure d'accès (atime) des tokens spécifiés ($token).

On suppose que le token existe déjà dans la base de données.

tok_touch_all

méthode publique (Booléen) tok_touch (\@ $tokens,
chaîne $atime)

Description : Cette méthode met à jour en masse les heures d'accès (atime) d'une liste de tokens spécifiés ($tokens), si l'heure existante est inférieure à $atime.

On suppose que les tokens existent déjà dans la base de données.

Nous ne devrions jamais toucher plus de N_SIGNIFICANT_TOKENS, donc nous pouvons faire des hypothèses sur la manière de gérer les données (par exemple, ne pas avoir besoin de faire de lots, comme nous le faisons dans tok_get_all).

cleanup

méthode publique (Booléen) cleanup ()

Description : Cette méthode effectue tout nettoyage nécessaire avant de passer à l'opération suivante.

clear_database

méthode publique (Booléen) clear_database ()

Description : Cette méthode supprime tous les enregistrements pour un utilisateur donné.

Les appelants doivent être conscients que toute erreur renvoyée par cette méthode peut entraîner une incohérence de la base de données pour l'utilisateur donné.

MÉTHODES PRIVÉES

_connect_db

méthode privée (Booléen) _connect_db ()

Description : Cette méthode se connecte à la base de données SQL.

_put_token

méthode privée (Booléen) _put_token (chaîne $token,
entier $spam_count,
entier $ham_count,
chaîne $atime)

Description : Cette méthode effectue le travail d'insertion ou de mise à jour d'un token dans la base de données.

_put_tokens

méthode privée (Booléen) _put_tokens (\% $token,
entier $spam_count,
entier $ham_count,
chaîne $atime)

Description : Cette méthode effectue le travail d'insertion ou de mise à jour de tokens dans la base de données.

_token_select_string

méthode privée (chaîne) _token_select_string

Description : Cette méthode renvoie la chaîne à utiliser dans les requêtes SELECT pour représenter la colonne token.
