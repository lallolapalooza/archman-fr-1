NOM

Mail::Box::Collection - une collection de sous-dossiers

HEREDITE

Mail::Box::Collection
  est un User::Identity::Collection
  est un User::Identity::Item
Mail::Box::Collection
  est un Mail::Reporter

SYNOPIS

DESCRIPTION

L'objet Mail::Box::Collection gère un ensemble d'objets Mail::Box::Identity, décrivant chacun l'emplacement d'une seule boîte aux lettres (dossier). La collection est utilisée par l'objet Mail::Box::Manage::User pour administrer les dossiers d'un utilisateur unique, même si ces dossiers sont fermés.

Mail::Box::Collection(3pm)

NAME

Mail::Box::Collection - Abstract collection of mail messages

INHERITANCE

Mail::Box::Collection is an abstract class.

  isa Mail::Box::Root
  isa Mail::Box::Role::SubFolder
  isa Mail::Box::Role::Cloneable
  isa Mail::Box::Role::Stateless
  isa Mail::Box::Role::Logger
  isa Mail::Box::Role::Package
  isa Class::Object::Class
      All the common methods for Mail-Box objects

SYNOPSIS

  use Mail::Box;
  # Load a folder
  my $box = Mail::Box->new named            => 'maildir:~/Maildir',
                         charset->{         => 'UTF-8',
                                         message => 'UTF-8',
                                         header  => 'UTF-8',
                                        };
  
  # Get a collection of folders
  my $folders = $box->listChildren;
  
  # Get a folder
  my $folder = $folders->get('INBOX');
  
  # Number of messages
  print $folder->messageCount, "\n";
  
  # Iterate over messages
  $folder->messages(
      sub {
          my ($message, $folder_id) = @_;
          print $message->subject, "\n";
      });

DESCRIPTION

This is an abstract base class for all collection objects within the Mail-Box distribution. A collection is a container for mail messages or other mail boxes (sub-folders).

Examples of concrete classes are:

  • Mail::Box::IMAP4

  • Mail::Box::Local::Folder

  • Mail::Box::Mbox

  • Mail::Box::Maildir

  • Mail::Box::Net::POP3

This class defines the interface that all collection objects must implement. The actual implementation of these methods is found in the concrete classes.

OVERLOADED

  - string overload
      Returns the name of the collection.

METHODS

add(COLLECTION)
Adds a new sub-collection (folder) to this one. See also addCollection().
addCollection(COLLECTION)
Adds a new sub-collection (folder) to this one. This is the preferred method over add().
addRole(ROLE)
Adds a role to this collection. Roles are objects that add extra functionality to the collection, like message searching or message manipulation.
close()
Closes the collection and releases any resources associated with it. This includes flushing any pending changes to disk or network.
clone()
Creates a copy of this collection. The copy is independent of the original, meaning that changes to one will not affect the other.
delete(MESSAGE)
Deletes a message from the collection. MESSAGE can be a message object or a message ID.
deleteCollection(COLLECTION)
Deletes a sub-collection (folder) from this one. COLLECTION can be a collection object or the name of the folder.
get(NAME)
Returns the sub-collection (folder) named NAME. Returns undef if the folder does not exist.
getFolder(NAME)
Returns the sub-collection (folder) named NAME. This is an alias for get().
getFreeSpace()
Returns the amount of free space available in the collection, in bytes.
getMessage(ID)
Returns the message with the specified ID. Returns undef if the message does not exist.
getMessageCount()
Returns the number of messages in the collection.
getRole(ROLE_NAME)
Returns the role object with the specified ROLE_NAME. Returns undef if the role does not exist.
getSize()
Returns the total size of all messages in the collection, in bytes.
isReadOnly()
Returns true if the collection is read-only, false otherwise.
list(OPTIONS)
Returns a list of all messages in the collection. OPTIONS can be used to filter the messages. See also messages().
listChildren()
Returns a list of all sub-collections (folders) in this collection.
messages(BLOCK)
Iterates over all messages in the collection, executing the BLOCK for each message. The block receives the message object and its ID as arguments.
move(MESSAGE, DESTINATION)
Moves a message to a different collection. MESSAGE can be a message object or a message ID. DESTINATION is the name of the destination collection.
new(%OPTIONS)
Creates a new collection object. The %OPTIONS are passed to the constructor of the concrete class.
newChild(%OPTIONS)
Creates a new sub-collection (folder) within this collection. The %OPTIONS are passed to the constructor of the concrete class.
parent()
Returns the parent collection of this collection.
rename(OLD_NAME, NEW_NAME)
Renames a sub-collection (folder). OLD_NAME and NEW_NAME are the names of the folder.
renameCollection(OLD_NAME, NEW_NAME)
Renames a sub-collection (folder). This is an alias for rename().
renameMessage(MESSAGE, NEW_ID)
Renames a message. MESSAGE can be a message object or a message ID. NEW_ID is the new message ID.
save(MESSAGE)
Saves a message to the collection. If the message already exists, it will be overwritten.
search(CRITERIA, BLOCK)
Searches for messages matching the given CRITERIA and executes the BLOCK for each matching message. See Mail::Box::Search for details on search criteria.
stat()
Returns a hash containing statistics about the collection, such as the number of messages, total size, and free space.
sync()
Synchronizes the collection with the underlying storage. This ensures that any changes made to the collection are saved.
trace(LEVEL, MESSAGE)
Logs a message at the specified LEVEL. This method is intended for debugging purposes.
