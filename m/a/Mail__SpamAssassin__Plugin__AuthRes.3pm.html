NOM

Mail::SpamAssassin::Plugin::AuthRes - utilise les champs d'en-tête Authentication-Results

SYNOPSIS

Configuration de SpamAssassin :

loadplugin Mail::SpamAssassin::Plugin::AuthRes

authres_trusted_authserv myserv.example.com authres_networks all

DESCRIPTION

Ce plugin analyse les champs d'en-tête Authentication-Results et peut fournir les résultats obtenus à d'autres plugins, afin d'éviter de répéter des vérifications déjà effectuées.

PARAMETRES ADMINISTRATEUR

authres_networks interne/de confiance/tout (par défaut : interne)
Traite les en-têtes Authentication-Results définis par les serveurs de ces réseaux (fait référence aux zones *_networks de SpamAssassin). Tout en-tête en dehors de ceci est complètement ignoré (affecte tous les paramètres du module). 
interne   = internal_networks
de confiance    = internal_networks + trusted_networks
tout        = tout ci-dessus + tout externe

Définir "tout" est sûr uniquement si vos serveurs MX filtrent correctement tous les en-têtes A-R entrants, et que vous utilisez authres_trusted_authserv pour faire correspondre votre authserv-id. Ceci convient par exemple à OpenDKIM par défaut. Ces paramètres peuvent aussi être requis si vos filtres n'insèrent pas l'en-tête A-R à la bonne position au-dessus de l'en-tête Received interne (quelques contrevenants connus : OpenDKIM, OpenDMARC, amavisd-milter).

authres_trusted_authserv authservid1 id2 ... (par défaut : aucun)
IDs de serveurs d'authentification de confiance (le premier mot semblable à un nom de domaine du champ Authentication-Results, aussi connu sous le nom de "authserv-id").

Notez que si défini, TOUS les en-têtes A-R sont ignorés à moins qu'une correspondance ne soit trouvée.

Son utilisation est fortement recommandée, éventuellement avec authres_networks tout.

authres_ignored_authserv authservid1 id2 ... (par défaut : aucun)
IDs de serveurs d'authentification ignorés (le premier mot semblable à un nom de domaine du champ Authentication-Results, aussi connu sous le nom de "authserv-id").

Tout en-tête A-R est ignoré si une correspondance est trouvée.

METADONNEES

Les en-têtes analysés sont stockés dans $pms->{authres_parsed}, sous forme de hachage d'un tableau de hachages où les résultats sont collectés par méthode. Par exemple, le champ d'en-tête :

Authentication-Results: server.example.com;
  spf=pass smtp.mailfrom=bounce.example.org;
  dkim=pass header.i=@example.org;
  dkim=fail header.i=@another.signing.domain.example

Produit la structure suivante :

$pms->{authres_parsed} = {
  'dkim' => [
    {
      'properties' => {
        'header' => {
          'i' => '@example.org'
        }
      },
      'authserv' => 'server.example.com',
      'result' => 'pass',
      'version' => 1,
      'reason' => ''
    },
    {
      'properties' => {
        'header' => {
          'i' => '@another.signing.domain.example'
        }
      },
      'result' => 'fail',
      'authserv' => 'server.example.com',
      'version' => 1,
      'reason' => ''
    },
  ],
}

Dans chaque tableau, l'ordre des résultats est l'original, ce qui devrait être les résultats les plus récents en premier.

Pour vérifier le résultat des méthodes, $pms->{authres_result} est disponible :

$pms->{authres_result} = {
  'dkim' => 'pass',
  'spf' => 'fail',
}

FONCTIONS EVALUATION

header NOM_REGLE eval:check_authres_result(methode, resultat)
Peut être utilisé pour vérifier les résultats.

Référence des méthodes et valeurs de résultat valides : "https://www.iana.org/assignments/email-auth/email-auth.xhtml"

De plus, la valeur de résultat 'manquant' peut être utilisée pour vérifier s'il n'y a aucun résultat.

ifplugin Mail::SpamAssassin::Plugin::AuthRes
ifplugin !(Mail::SpamAssassin::Plugin::SPF)
  header  SPF_PASS      eval:check_authres_result('spf', 'pass')
  header  SPF_FAIL      eval:check_authres_result('spf', 'fail')
  header  SPF_SOFTFAIL  eval:check_authres_result('spf', 'softfail')
  header  SPF_TEMPFAIL  eval:check_authres_result('spf', 'tempfail')
endif
ifplugin !(Mail::SpamAssassin::Plugin::DKIM)
  header  DKIM_VERIFIED  eval:check_authres_result('dkim', 'pass')
  header  DKIM_INVALID   eval:check_authres_result('dkim', 'fail')
endif
endif
