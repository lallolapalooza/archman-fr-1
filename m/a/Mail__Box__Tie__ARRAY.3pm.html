NOM

Mail::Box::Tie::ARRAY - accéder à un dossier de messages existant en tant que tableau

HEREDITE

Mail::Box::Tie::ARRAY
  est un Mail::Box::Tie

SYNOPSIS

use Mail::Box::Manager;
my $mgr    = Mail::Box::Manager->new;
my $folder = $mgr->open(folder => 'inbox');
use Mail::Box::Tie::ARRAY;
tie my(@inbox), 'Mail::Box::Tie::ARRAY', $folder;
# déprécié, mais fonctionne aussi
use Mail::Box::Tie;
tie my(@inbox), 'Mail::Box::Tie', $folder;
foreach (@inbox) {print $_->short}
print $_->print foreach @inbox;
my $emails = @inbox;
print $inbox[3];
print scalar @inbox;
push @inbox, Mail::Box::Message->new(...);
delete $inbox[6];
print $inbox[0]->head->get('status');
my $folder = tied @inbox;
untie @inbox;

DESCRIPTION

Certainement, lorsque vous considérez un dossier comme une liste de messages, il est logique d'accéder au dossier via un tableau.

Toutes les opérations sur les tableaux ne sont pas supportées. En fait, la plupart des fonctions qui réduiraient la taille du tableau sont modifiées pour marquer les messages en vue de leur suppression.

Exemples de ce que vous ne pouvez pas faire :

shift/unshift/pop/splice @inbox;

Interface liée

$obj->DELETE()
Marque un message pour suppression. Attention, le message reste dans le dossier et n'est pas supprimé avant que le dossier ne soit écrit.

» exemple :

delete $inbox[5];
$inbox[5]->delete;   #identique
$obj->FETCH($index)
Récupère le message situé à l'index indiqué dans la liste des messages contenus dans ce dossier. Les messages marqués pour suppression seront retournés comme "undef".

» exemple :

print $inbox[3];     # 4ème message du dossier
print @inbox[3,0];   # 4ème et premier du dossier
print $inbox[-1];    # dernier message
$obj->FETCHSIZE()
Retourne le nombre total de messages dans un dossier. Ceci est appelé lorsque le tableau du dossier est utilisé dans un contexte scalaire, par exemple.

» exemple :

if(@inbox > 10)    # contient plus de 10 messages ?
my $nrmsgs = @inbox;
$obj->PUSH(@messages)
Ajoute @messages à la fin du dossier.

» exemple :

push @inbox, $newmsg;
$obj->STORE($index, $message)
Le remplacement aléatoire de message n'est pas autorisé — cela perturberait les fils de discussion, etc. Une erreur survient si vous essayez de le faire. La seule chose autorisée est de stocker un message au premier indice libre à la fin du dossier (ce qui est également réalisable avec PUSH()).

» exemple :

$inbox[8]  = $add;
$inbox[-1] = $add;
push @inbox, $add;
$obj->STORESIZE($length)
Marque tous les messages de $length jusqu'à la fin du dossier comme devant être supprimés.

DÉTAILS

Dossier lié en tant que tableau

Limitations

Ce module implémente "TIEARRAY", "FETCH", "STORE", "FETCHSIZE", "STORESIZE", "DELETE", "PUSH", et "DESTROY".

Ce module n'implémente pas toutes les autres méthodes décrites dans la documentation de Tie::Array, car le tableau réel de messages n'est pas autorisé à rétrécir ou à être mutilé.
