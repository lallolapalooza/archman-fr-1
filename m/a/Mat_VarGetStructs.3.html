NOM

Mat_VarGetStructs — Indexer une variable de structure en utilisant des tranches de chaque dimension

SYNTAXE

#include <matio.h>

matvar_t *
Mat_VarGetStructs(const matvar_t *matvar, cons int *start, const int *stride, const int *edge, int copy_fields);

DESCRIPTION

La fonction Mat_VarGetStructs() sélectionne un sous-tableau d'un tableau de structures matvar. Chacun des éléments du sous-tableau contient tous les champs de la structure. L'index de chaque dimension commence à l'élément start dans le tableau (0 étant le premier élément), et lit toutes les stride valeurs (1 étant chaque élément, 2 tous les deux éléments, etc.). Le nombre total d'éléments dans le sous-tableau est spécifié par edge. L'option copy_fields spécifie si les champs de la structure d'origine sont copiés pour le nouveau sous-tableau. Si elle est définie sur 0, les champs du tableau de structures retourné ont le même pointeur que le tableau d'origine, et le champ data de la structure du sous-tableau. Le sous-tableau est marqué avec le drapeau de conservation de la mémoire indiquant que les champs ne doivent pas être libérés. Ils sont libérés lorsque la structure d'origine est libérée.

VALEURS DE RETOUR

Un sous-tableau du tableau de structures d'origine, ou NULL en cas d'erreur.
