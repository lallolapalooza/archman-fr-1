NOM

Markdown.pl - Convertir la syntaxe Markdown en (X)HTML

DESCRIPTION

Ce programme est distribué dans le cadre du module Perl Text::Markdown, illustrant un exemple d'utilisation.

Markdown peut être appelé sur n'importe quel fichier contenant la syntaxe Markdown, et produira le (X)HTML correspondant sur STDOUT :

$ cat fichier.txt
Ceci est un *test*.
Absolument _rien_ à voir ici. _Juste un **test**_ !
* test
* Oui, test.
$ Markdown.pl fichier.txt
<p>Ceci est un <em>test</em>.</p>
<p>Absolument <em>rien</em> à voir ici. <em>Juste un <strong>test</strong></em> !</p>
<ul>
<li>test</li>
<li>Oui, test.</li>
</ul>

Si aucun fichier n'est spécifié, il attendra son entrée depuis STDIN :

$ echo "Un **simple** test" | markdown
<p>Un <strong>simple</strong> test</p>

OPTIONS

version
Affiche les informations complètes pour cette version.
shortversion
Affiche uniquement le numéro de version.
html4tags
Produit des balises de style HTML 4 au lieu de XHTML - XHTML nécessite que les éléments qui ne ferment pas un bloc (c'est-à-dire la balise "hr") indiquent qu'ils ne seront pas fermés, en se fermant avec "/>". Le style HTML 4 affichera simplement la balise telle quelle : 
$ echo '---' | markdown
<hr />
$ echo '---' | markdown --html4tags
<hr>
help
Affiche cette documentation.
