NOM

Mail::Message::Convert::HtmlFormatText - Convertir le HTML en Texte

HEREDITE

Mail::Message::Convert::HtmlFormatText
  est un Mail::Message::Convert
  est un Mail::Reporter

SYNOPIS

use Mail::Message::Convert::HtmlFormatText;
my $af = Mail::Message::Convert::HtmlFormatText->new;
my $plain_body = $af->format($body);

DESCRIPTION

Convertit les objets de corps de message HTML/XHTML en corps de texte brut en utilisant HTML::FormatText. Ce paquet requiert HTML::TreeBuilder et HTML::FormatText qui ne sont pas installés par défaut avec Mail::Box. Voir également Mail::Message::rebuild() avec la règle "text_alternative_for_html".

Ce module est un petit wrapper autour de HTML::FormatText.
