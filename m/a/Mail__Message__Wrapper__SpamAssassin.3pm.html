Mail::Message::Wrapper::SpamAssassin(3) Documentation Perl fournie par l'utilisateur Mail::Message::Wrapper::SpamAssassin(3)

NOM

Mail::Message::Wrapper::SpamAssassin - Connecter un Mail::Message avec Mail::SpamAssassin

HERITAGE

Mail::Message::Wrapper::SpamAssassin
  est un Mail::SpamAssassin::Message

SYNTAXE

# ATTENTION : nécessite SpamAssassin ANCIEN 2.x, pas le nouveau 3.x
# Voir Mail::Box::Search::SpamAssassin pour l'interface préférée
# Cependant, il est possible de faire :
my $msg    = ...;   # un objet Mail::Message quelconque
my $sa     = Mail::Message::Wrapper::SpamAssassin->new($msg);
my $spam   = Mail::SpamAssassin->new;
my $status = $spam->check($sa);
$msg->label(spam => 1) if $status->is_spam;
$status->rewrite_mail;  # Ajoute des lignes de spam à l'en-tête

DESCRIPTION

ATTENTION : Ce module ne fonctionne qu'avec l'ancienne version de SpamAssassin : version 2.x. Les versions plus récentes 3.x ont modifié la manière dont les messages sont conservés. Merci de contribuer à améliorer le code.

La classe "Mail::Message::Wrapper::SpamAssassin" -- désolé pour le nom de paquet long -- est un wrapper autour de Mail::SpamAssassin::Message, qui est une interface pour le logiciel de détection de spam Mail::SpamAssassin.

METHODES

$class->new($message, %options)
Crée un wrapper autour du $message. Les champs déjà présents d'une exécution précédente de Spam::Assassin (ou probablement des lignes factices) sont d'abord supprimés.
