NOM

DNSEVAL - recherche d'URL contre des listes noires DNS

SYNOPBIS

loadplugin Mail::SpamAssassin::Plugin::DNSEval
rbl_headers EnvelopeFrom,Reply-To,Disposition-Notification-To
header     RBL_IP    eval:check_rbl_headers('rbl', 'rbl.example.com.', '127.0.0.2')
describe   RBL_IP    Adresse de l'expéditeur associée à des domaines de spam
tflags     RBL_IP    net
reuse      RBL_IP
Tflags supplémentaires pris en charge à partir de SpamAssassin 3.4.3 :
 domains_only - seuls les composants "hôte" de "nom de domaine" (non-IP) sont interrogés
 ips_only - seuls les adresses IP en tant que composant "hôte" seront interrogés

DESCRIPTION

Le plugin DNSEval interroge le DNS pour voir si un domaine ou une adresse IP présente dans l'un des en-têtes d'un e-mail se trouve sur une RBL particulière.

PRÉFÉRENCES UTILISATEUR

Les options suivantes peuvent être utilisées dans les fichiers de configuration au niveau du site ("local.cf") et spécifiques à l'utilisateur ("user_prefs") pour personnaliser la manière dont SpamAssassin traite les messages électroniques entrants.

rbl_headers
Cette option indique à SpamAssassin dans quels en-têtes rechercher le contenu
utilisé pour interroger la RBL spécifiée.
Si le contenu des en-têtes contient une adresse e-mail, une adresse IP
ou un nom de domaine, il sera vérifié sur la RBL spécifiée.
L'option de configuration peut être remplacée en passant une liste d'en-têtes comme
dernier paramètre à check_rbl_headers.
Les en-têtes vérifiés par défaut sont :
  • EnvelopeFrom
  • Reply-To
  • Disposition-Notification-To
  • X-WebmailclientIP
  • X-Source-IP
check_rbl_from_domain
Ceci vérifie tous les noms de domaine des adresses d'expéditeur en tant qu'alternative à check_rbl_from_host. Depuis la v3.4.1, il a été amélioré pour inclure un sous-test pour un octet spécifique.
check_rbl_ns_from
Ceci vérifie le serveur DNS du nom de domaine de l'adresse d'expéditeur. Il est possible d'inclure un sous-test pour un octet spécifique.
check_rbl_rcvd
Ceci vérifie tous les domaines ou adresses IP des en-têtes reçus contre une RBL spécifique. Il est possible d'inclure un sous-test pour un octet.
