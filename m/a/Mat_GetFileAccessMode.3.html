MAT_GETFILEACCESSMODE(3) Manuel des fonctions de bibliothèque MAT_GETFILEACCESSMODE(3)

NOM

Mat_GetFileAccessMode — Retourne le mode d'accès au fichier d'un fichier MAT MATLAB étant donné une structure de fichier MAT.

SYNTAXE

#include <matio.h>

enum mat_acc
Mat_GetFileAccessMode(const mat_t *matfp);

DESCRIPTION

La fonction Mat_GetFileAccessMode() retourne le mode d'accès au fichier MAT MATLAB donné par la structure de fichier MAT.

VALEURS DE RETOUR

La valeur de retour est l'une des suivantes :

  • MAT_ACC_RDONLY si le fichier est ouvert en lecture seule ou pas ouvert du tout.
  • MAT_ACC_RDWR si le fichier est ouvert en lecture/écriture.

VOIR AUSSI

Mat_CreateVer(3), Mat_Open(3), Mat_GetFilename(3), Mat_GetHeader(3)
