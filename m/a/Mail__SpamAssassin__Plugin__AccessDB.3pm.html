NOM

Mail::SpamAssassin::Plugin::AccessDB - vérifier le message contre la base de données d'accès

SYNTAXE

loadplugin     Mail::SpamAssassin::Plugin::AccessDB
header   ACCESSDB  eval:check_access_database('/etc/mail/access.db')
describe ACCESSDB  Message would have been caught by accessdb
tflags   ACCESSDB  userconf
score    ACCESSDB  2

DESCRIPTION

De nombreux MTA prennent en charge les bases de données d'accès, telles que Sendmail, Postfix, etc. Ce plugin effectue des vérifications similaires pour voir si un message aurait été signalé.

La règle renvoie false si une entrée n'est pas trouvée, ou si l'entrée a un RHS (Right-Hand Side) de OK ou SKIP.

La règle renvoie true si une entrée existe et a un RHS de REJECT, ERROR, ou DISCARD.

Remarque : seul le premier mot (divisé par des caractères non alphanumériques) du RHS est vérifié, donc "error:5.7.1:..." signifie "ERROR".
