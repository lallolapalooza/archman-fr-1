NOM

Mail::Box::MH::Index - maintenir des fichiers d'index pour les messages.

HIÉRARCHIE

Mail::Box::MH::Index
  hérite de Mail::Reporter

SYNOPSIS

my $index = Mail::Box::MH::Index->new;
$index->read(...)
$index->write(...)

DESCRIPTION

Les boîtes aux lettres qui stockent leurs données dans un seul fichier par message sont très inefficaces pour produire des listes d'objets et calculer des fils de discussion de messages. L'objet Mail::Box::MH::Index peut stocker et lire les en-têtes d'un ensemble de messages Mail::Box::MH::Message qui font partie d'une seule boîte aux lettres Mail::Box::MH dans un seul fichier.

Lorsque la fonctionnalité de Mail::Box::MH::Index est activée en spécifiant Mail::Box::MH::new(keep_index) lors de l'ouverture d'une boîte aux lettres, le fichier d'index est lu automatiquement. Lorsque la boîte aux lettres est fermée, un nouveau fichier d'index est créé.

Une attention particulière est portée pour éviter les problèmes lorsque l'utilisateur modifie ou supprime des fichiers de message sans mettre à jour l'index. Si l'index n'est pas fiable, il ne sera pas utilisé (ce qui peut coûter en performance pour le lecteur de la boîte aux lettres).

L'index

$obj->append(@messages)
Ajouter @messages au fichier d'index.
$obj->get($msgfile)
Vérifier s'il y a des informations d'en-tête pour le fichier de message $msgfile. Le nom de fichier représente un message dans une boîte aux lettres de type répertoire. Cette méthode retourne un objet de la nouvelle classe (head_type) spécifiée lors de la création de l'objet d'index, ou "undef" si l'information est introuvable ou non fiable - c'est-à-dire que la taille du fichier a changé.
$obj->read()
Lire le fichier d'index. Après cet appel, les objets d'en-tête peuvent être demandés avec la méthode get().
$obj->write(@messages)
Écrire un fichier d'index contenant les en-têtes spécifiés @messages (objets Mail::Message).
