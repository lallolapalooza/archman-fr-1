NOM

Mail::Util - fonctions utilitaires de courrier

HERITAGE

Mail::Util
  est un Exporter

SYNTAXE

use Mail::Util qw( ... );

DESCRIPTION

Ce paquet fournit plusieurs fonctions utilitaires liées au courrier. Toute fonction requise doit être explicitement listée sur la ligne d'utilisation pour être exportée dans le paquet appelant.

FONCTIONS

mailaddress( [$adresse] )
Retourne une estimation de l'adresse de courrier de l'utilisateur actuel. L'utilisateur peut forcer la valeur de retour en définissant la variable d'environnement MAILADDRESS. [2.10] Vous pouvez définir la $adresse via le paramètre.

ATTENTION : Lorsqu'elle n'est pas fournie via la variable d'environnement, <mailaddress> examine divers fichiers de configuration et autres données environnementales. Bien que cela semble être un comportement intelligent, ce n'est pas (à mon avis) assez prévisible pour être utilisé. Veuillez définir explicitement MAILADDRESS, et ne vous fiez pas à la « détection automatique », même lorsqu'elle produit une adresse correcte (pour le moment).

exemple :

# dans votre script principal
$ENV{MAILADDRESS} = 'moi@example.com';
# partout ailleurs
use Mail::Util 'mailaddress';
print mailaddress;
# depuis la v2.10
mailaddress "moi@example.com";
maildomain()
Tente de déterminer la chaîne de domaine de courrier de l'utilisateur actuel via les méthodes suivantes
  • Recherche la variable d'environnement MAILDOMAIN, qui peut être définie de l'extérieur du programme. C'est de loin la meilleure façon de configurer le domaine.
  • Recherche un fichier sendmail.cf et extrait le paramètre DH
  • Recherche un fichier de configuration smail et utilise le premier hôte défini dans hostname(s)
  • Tente une connexion SMTP (si Net::SMTP existe) d'abord vers mailhost puis localhost
  • Utilise la valeur de Net::Domain::domainname (si Net::Domain existe)

ATTENTION : Sur les machines modernes, il n'y a qu'une seule bonne façon de fournir des informations à cette méthode : la première ; configurez toujours explicitement MAILDOMAIN.

exemple :

# dans votre script principal
$ENV{MAILDOMAIN} = 'example.com';
# partout ailleurs
use Mail::Util 'maildomain';
print maildomain;
read_mbox($fichier)
Lit le $fichier, un fichier de boîte aux lettres binmail, et retourne une liste de références. Chaque référence est une référence à un tableau contenant un message.

ATTENTION : Cette méthode ne met pas entre guillemets les lignes qui commencent accidentellement aussi par le séparateur de message "From", donc cette implémentation peut être considérée comme défectueuse. Voir Mail::Box::Mbox
