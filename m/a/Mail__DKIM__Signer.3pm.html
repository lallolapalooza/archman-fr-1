Mail::DKIM::Signer(3) Documentation soumise par les utilisateurs de Perl Mail::DKIM::Signer(3)

NOM

Mail::DKIM::Signer - génère une signature DKIM pour un message

VERSION

version 1.20240923

SYNOPIS

use Mail::DKIM::Signer;
use Mail::DKIM::TextWrap;  # recommandé
# créer un objet signataire
my $dkim = Mail::DKIM::Signer->new(
                Algorithm => 'rsa-sha1',
                Method => 'relaxed',
                Domain => 'example.org',
                Selector => 'selector1',
                KeyFile => 'private.key',
                Headers => 'x-header:x-header2',
           );
# lire un email depuis un fichier d'entrée
$dkim->load(*STDIN);
# ou lire un email et le passer à la signature, une ligne à la fois
while (<STDIN>)
{
    # supprimer les terminaisons locales
    chomp;
    s/\015$//;
    # utiliser les terminaisons SMTP
    $dkim->PRINT("$_\015\012");
}
$dkim->CLOSE;
# quel est le résultat de la signature ?
my $signature = $dkim->signature;
print $signature->as_string;

DESCRIPTION

Cette classe fait partie de Mail::DKIM et est responsable de la génération de signatures pour un message donné. Vous créez un objet de cette classe, en spécifiant les paramètres de la signature que vous souhaitez créer, ou en spécifiant une fonction de rappel afin que les paramètres de la signature puissent être déterminés plus tard. Ensuite, vous lui donnez le message complet via "PRINT()", en terminant par "CLOSE()". Enfin, utilisez la méthode "signatures()" pour accéder aux signatures générées.

Style de signature

Mail::DKIM inclut un module de signature qui insère des sauts de ligne dans la signature générée afin qu'elle soit plus agréable dans le message final. Pour activer ce module, il suffit d'appeler

use Mail::DKIM::TextWrap;

dans votre programme avant de générer la signature.

CONSTRUCTEUR

new()

Crée un objet signataire.

# créer un signataire utilisant la politique par défaut
my $dkim = Mail::DKIM::Signer->new(
                Algorithm => 'rsa-sha1',
                Method => 'relaxed',
                Domain => 'example.org',
                Selector => 'selector1',
                KeyFile => 'private.key',
                Headers => 'x-header:x-header2',
           );
# créer un signataire utilisant une politique personnalisée
my $dkim = Mail::DKIM::Signer->new(
                Policy => $policyfn,
           );

La politique par défaut crée une signature DKIM en utilisant les paramètres spécifiés, mais seulement si l'expéditeur du message correspond au domaine. Les paramètres suivants peuvent être passés à ce new() pour influencer la signature résultante : Algorithm, Method, Domain, Selector, KeyFile, Identity, Timestamp, Expiration.

Si vous souhaitez un comportement différent, vous pouvez fournir une "politique de signature". Une politique de signature est une sous-routine ou une classe qui détermine les paramètres de la signature une fois que les en-têtes du message ont été analysés. Voir la section "POLITIQUES DE SIGNATURE" pour plus d'informations.

Voir Mail::DKIM::SignerPolicy pour plus d'informations sur les objets de politique.

En plus des paramètres illustrés ci-dessus, les suivants sont reconnus :

Key
au lieu d'utiliser "KeyFile", utilisez "Key" pour utiliser un objet clé privée déjà chargé à partir de Mail::DKIM::PrivateKey.
Headers
une liste séparée par des deux-points des en-têtes à signer, ceci est ajouté à la liste des en-têtes par défaut comme montré dans la spécification DKIM.

Pour chaque en-tête spécifié, tous les en-têtes de ce type présents dans le message seront signés, mais les en-têtes non présents ne seront pas signés.

Si vous souhaitez un contrôle plus fin sur les en-têtes signés, utilisez plutôt la méthode extended_headers().

La liste par défaut des en-têtes est la suivante :

From Sender Reply-To Subject Date
Message-ID To Cc MIME-Version
Content-Type Content-Transfer-Encoding Content-ID Content-Description
Resent-Date Resent-From Resent-Sender Resent-To Resent-cc
Resent-Message-ID
In-Reply-To References
List-Id List-Help List-Unsubscribe List-Subscribe
List-Post List-Owner List-Archive
Tags
un hashref optionnel d'étiquettes supplémentaires à ajouter à la signature DKIM générée.

MÉTHODES

PRINT()

Envoie une partie du message à la signature.

$dkim->PRINT("a line of the message\015\012");

Envoie le contenu du message à signer à la signature. L'API est conçue de cette manière afin que le message complet ne soit pas obligé d'être lu en mémoire d'un coup.

Note : bien que la méthode PRINT() attende que vous utilisiez les caractères de fin SMTP, vous ne devez pas utiliser la technique de bourrage de points décrite dans le RFC 2821 section 4.5.2, ni utiliser une séquence de <CR><LF>.<CR><LF> pour terminer le message.

CLOSE()

Appelez ceci lorsque vous avez fini d'envoyer le message.

$dkim->CLOSE;

Cette méthode termine le processus de canonisation, calcule un hash et génère une signature.

extended_headers()

Cette méthode surcharge les en-têtes à signer et permet un contrôle plus fin que ce qui peut être obtenu avec le paramètre Headers dans le constructeur.

La méthode attend un HashRef à passer.

Les clés sont les en-têtes à signer, et les valeurs sont le nombre d'en-têtes de ce type à signer, ou les valeurs spéciales '*' et '+'.

* signera tous les en-têtes de ce type présents dans le message.

+ signera tous les en-têtes de ce type plus 1 présents dans le message pour empêcher l'ajout d'en-têtes supplémentaires.

Vous pouvez écraser n'importe quel en-tête par défaut en l'incluant dans le hashref, et les désactiver en donnant une valeur de 0.

Les clés sont insensibles à la casse, et les valeurs sont ajoutées jusqu'à la valeur la plus élevée.

Headers => {
    'X-test'  => '*',
    'x-test'  => '1',
    'Subject' => '+',
    'Sender'  => 0,
},

add_signature()

Utilisé par les politiques de signature pour créer une nouvelle signature.

$dkim->add_signature(new Mail::DKIM::Signature(...));

Les politiques de signature peuvent utiliser cette méthode pour spécifier les paramètres complets de la signature à ajouter, y compris le type de signature. Pour plus d'informations, voir Mail::DKIM::SignerPolicy.

algorithm()

Obtient ou définit l'algorithme sélectionné.

$alg = $dkim->algorithm;
$dkim->algorithm('rsa-sha1');

domain()

Obtient ou définit le domaine sélectionné.

$alg = $dkim->domain;
$dkim->domain('example.org');

load()

Charge le message entier depuis un descripteur de fichier.

$dkim->load($file_handle);

Lit un message entier depuis le fichier désigné, en le passant à la signature. Le message doit utiliser des fins de ligne <CRLF> (conformément au protocole SMTP).

headers()

Détermine quels en-têtes seront inclus dans la signature.

my $headers = $dkim->headers;

Ceci est une chaîne contenant les noms des champs d'en-tête qui seront signés, séparés par des deux-points.

key()

Obtient ou définit l'objet clé privée.

my $key = $dkim->key;
$dkim->key(Mail::DKIM::PrivateKey->load(File => 'private.key'));

L'objet clé peut être n'importe quel objet implémentant la méthode sign_digest(). (Fournir votre propre objet peut être utile si vos clés réelles sont stockées hors processus.)

Si vous utilisez cette méthode pour spécifier une clé privée, vous ne devez pas utiliser "key_file()".

key_file()

Obtient ou définit le nom du fichier contenant la clé privée.

my $filename = $dkim->key_file;
$dkim->key_file('private.key');

Le fichier de clé privée est utilisé pour lire l'objet de clé privée. Le nom du fichier doit être spécifié comme "private.key".

Mail::DKIM::Signer(3pm) - Manuel de Perl

NAME

Mail::DKIM::Signer - firma de correos electrónicos usando DKIM

VERSION

1.20240923-2

SYNOPSIS

    use Mail::DKIM;

    # Crear un nuevo firmante
    my $dkim = Mail::DKIM->new(
        domain    => 'example.org',
        selector  => 'mx1',
        key_file  => '/path/to/private.key',
        # o key => $private_key_string,
        # o key_command => '/usr/bin/myssh-agent /path/to/private.key',
    );

    # Alternativamente, pasar una política
    my $policy = sub { ... };
    my $dkim = Mail::DKIM->new( policy => $policy );

    # Preparar el mensaje para ser firmado
    $dkim->header_hash( \%headers );
    $dkim->body_hash( $body );

    # Generar la firma
    my $signed_message = $dkim->sign($message);

    # O acceder a la firma generada
    $dkim->sign($message); # o $dkim->sign_headers_and_body(...)
    my $signature_text = $dkim->signature_text;
    my $dkim_header = $dkim->dkim_header;

    # O para añadir la firma a un mensaje existente
    my $signed_message = $dkim->add_signature($message);

    # Acceder a los métodos
    my $domain = $dkim->domain;
    my $selector = $dkim->selector;
    my $method = $dkim->method;
    my $algorithm = $dkim->algorithm;
    my $from = $dkim->message_originator;
    my $sender = $dkim->message_sender;

DESCRIPTION

Esta clase proporciona la funcionalidad para firmar correos electrónicos usando el estándar DomainKeys Identified Mail (DKIM).

Los objetos de firmante se construyen típicamente con el método "new()" y luego se utilizan para firmar un mensaje de correo electrónico. El proceso de firma implica el cálculo de hashes para la cabecera y/o el cuerpo del mensaje, y luego la firma de esos hashes usando la clave privada especificada. La firma resultante se añade al mensaje en forma de cabecera DKIM-Signature.

La clase se basa en las siguientes especificaciones:

  • RFC 5586 (DKIM Core)
  • RFC 6376 (DKIM Core - Revisión)
  • RFC 8301 (DKIM Core - Revisión 2)
  • RFC 8004 (DKIM: Usos adicionales para la autoridad de registro DNS)
  • RFC 4697 (DKIM - Autenticación de dominio con Identificación de claves)
  • RFC 6377 (DKIM - Autenticación de dominio con Identificación de claves)
  • RFC 5672 (DKIM: Algoritmos de firma - Ed25519)
  • RFC 8463 (DKIM: Algoritmos de firma - RSA con SHA-224)

La clase también soporta Archiving, Reporting, and Compliance (ARC), tal como se define en RFC 4871.

CONSTRUCTOR

new()

Crea y devuelve un nuevo objeto Mail::DKIM::Signer.

Mail::DKIM->new( %args )

Los argumentos aceptados son:

algorithm
El algoritmo de firma a utilizar. Los valores posibles son los enumerados en "algorithm()". El valor por defecto es "rsa-sha256".
body_hash
El hash del cuerpo del mensaje. Se utiliza cuando se firma un mensaje sin el cuerpo presente (por ejemplo, una cabecera DKIM-Signature generada por adelantado). El valor debe ser la cadena codificada en base64 del hash del cuerpo.
canonicalization
Ver "method()".
domain
El dominio DKIM a utilizar. Ver "domain()".
identity
La identidad DKIM a utilizar. Ver "identity()".
key
La clave privada como una cadena. Si utilizas este argumento, no uses key_file o key_command.
key_command
Un comando que se ejecutará para obtener la clave privada. El estándar output del comando se utilizará como la clave privada. Si utilizas este argumento, no uses key o key_file.
key_file
La ruta al archivo que contiene la clave privada. Si utilizas este argumento, no uses key o key_command.
method
El método de canonización a utilizar. Ver "method()".
policy
Un objeto o clase con un método apply(), o una referencia a una subrutina. Ver la sección SIGNER POLICIES.
selector
El selector DKIM a utilizar. Ver "selector()".

METHODS

add_signature()

Añade un objeto de firma existente a este firmante.

    $dkim->add_signature( $signature );

Esto es típicamente utilizado por un objeto de política para añadir múltiples firmas o firmas DKIM/DomainKey de estilo antiguo.

algorithm()

Obtener o establecer el algoritmo de firma actual.

    my $alg = $dkim->algorithm;
    $dkim->algorithm('rsa-sha1');

Los algoritmos válidos son:

  • rsa-sha1
  • rsa-sha256
  • rsa-sha512
  • ecdsa-sha2-nistp256
  • ecdsa-sha2-nistp384
  • ecdsa-sha2-nistp521
  • ed25519
  • ed448

body_hash()

Establecer el hash del cuerpo del mensaje. Esto se utiliza cuando se añade una firma a un mensaje existente donde el cuerpo ya ha sido hasheado. La cadena debe estar codificada en base64.

$dkim->body_hash($base64_body_hash);

canonicalization()

Obtener o establecer el método de canonización seleccionado.

$alg = $dkim->canonicalization;
$dkim->canonicalization('relaxed/simple');

Los métodos de canonización válidos son:

  • simple
  • relaxed
  • simple/simple
  • simple/relaxed
  • relaxed/simple
  • relaxed/relaxed

El primer componente es el método de canonización de la cabecera, y el segundo es el método de canonización del cuerpo.

Nota: El uso de "method()" es preferido sobre "canonicalization()".

dkim_header()

Devuelve la cabecera DKIM-Signature generada, incluyendo el salto de línea al final.

my $dkim_header = $dkim->dkim_header;

Esto sólo tiene sentido si ya se ha llamado a sign() o sign_headers_and_body().

domain()

Obtener o establecer el dominio DKIM actual.

my $domain = $dkim->domain;
$dkim->domain('example.com');

domain_from_headers()

Extrae y devuelve el dominio de la cabecera del remitente.

my $domain = $dkim->domain_from_headers;

Esto busca la cabecera 'From' y extrae el dominio de la dirección de correo electrónico.

headers()

Devuelve una lista de las cabeceras que se firmarán.

my @headers_to_sign = $dkim->headers;

Si se llama a header_hash() o sign_headers(), esta lista se basa en esos argumentos. Si no, se basa en la cabecera 'From', 'To', 'Subject', 'Date', 'Message-ID', y cualquier cabecera DKIM/ARC preexistente.

header_hash()

Establece los hashes de las cabeceras a firmar. El argumento debe ser un hash de referencias a cabeceras, donde las claves son los nombres de las cabeceras (sin distinción entre mayúsculas y minúsculas) y los valores son las cabeceras correspondientes (como una cadena o una lista de cadenas).

my $headers_ref = {
    'from' => 'User <user@example.com>',
    'to'   => 'Recipient <recipient@example.com>',
};
$dkim->header_hash($headers_ref);

Si se pasa un hash vacío, se borrará el hash de cabeceras precalculado.

Nota: si se llama a esto después de sign(), no tendrá efecto.

identity()

Obtener o establecer la identidad DKIM actual.

my $identity = $dkim->identity;
$dkim->identity('user@example.org');

Esto se utiliza típicamente con el tag 'i' en la cabecera DKIM-Signature.

key()

Obtener o establecer la clave privada.

my $key = $dkim->key;
$dkim->key($private_key_string);

Si utilizas este método para especificar un archivo de clave privada, no uses "key()".

method()

Obtener o establecer el método de canonización seleccionado.

$alg = $dkim->method;
$dkim->method('relaxed');

message_originator()

Acceder a la cabecera "From".

my $address = $dkim->message_originator;

Devuelve la "dirección de origen" encontrada en el mensaje, como un objeto Mail::Address. Esto es típicamente la (primera) dirección de nombre y correo electrónico encontrada en la cabecera From: . Si no hay una cabecera From: , se devuelve una objeto Mail::Address vacío.

Para obtener solo la dirección de correo electrónico, haz:

my $email = $dkim->message_originator->address;

Ver también "message_sender()".

message_sender()

Acceder a la cabecera "From" o "Sender".

my $address = $dkim->message_sender;

Devuelve la "dirección del emisor" encontrada en el mensaje, como un objeto Mail::Address. Esto es típicamente la (primera) dirección de nombre y correo electrónico encontrada en la cabecera Sender: . Si no hay una cabecera Sender: , es la (primera) dirección de nombre y correo electrónico en la cabecera From: . Si no hay ninguna cabecera, se devuelve un objeto Mail::Address vacío.

Para obtener solo la dirección de correo electrónico, haz:

my $email = $dkim->message_sender->address;

La "dirección del emisor" es el buzón del agente responsable de la transmisión del mensaje. Por ejemplo, si un secretario enviará un mensaje para otra persona, la "dirección del emisor" sería el secretario y la "dirección de origen" sería la persona real.

policy()

Obtener el objeto de política utilizado por este firmante.

my $policy = $dkim->policy;

selector()

Obtener o establecer el selector actual.

$alg = $dkim->selector;
$dkim->selector('alpha');

sign()

Genera una firma DKIM para el mensaje dado y devuelve el mensaje firmado.

my $signed_message = $dkim->sign($message);

Si el mensaje ya contiene una cabecera DKIM-Signature, se eliminará y se reemplazará por una nueva.

Si se proporciona un argumento opcional 1, el método generará sólo la firma y la añadirá al mensaje, pero no devolverá el mensaje completo.

 $dkim->sign($message, 1); # Añade la firma al $message

Si se pasa un argumento opcional 0, el método generará la firma pero no modificará el mensaje original. Devolverá la firma generada.

my $signature = $dkim->sign($message, 0);

signature()

Acceder al objeto de firma generado.

my $signature = $dkim->signature;

Devuelve el objeto de firma generado. El firma es un objeto de tipo Mail::DKIM::Signature. Si se han generado múltiples firmas, este método devuelve la última una.

La firma (como texto) debe ser preparada antes del mensaje para producir el mensaje resultado. Por lo menos, debe preceder a cualquier cabecera que se haya firmado.

signature_text()

Devuelve la firma DKIM-Signature generada como una cadena.

my $signature_text = $dkim->signature_text;

Esto sólo tiene sentido si ya se ha llamado a sign() o sign_headers_and_body().

signatures()

Acceder a la lista de objetos de firma generados.

my @signatures = $dkim->signatures;

Devuelve todas las firmas generadas, como una lista.

sign_headers_and_body()

Calcula los hashes de cabecera y cuerpo, y devuelve la cadena de cabecera DKIM-Signature generada.

my $signature_header = $dkim->sign_headers_and_body($message);

El $message puede ser una cadena o un objeto IO::Handle.

SIGNER POLICIES

El constructor new() toma un argumento opcional de tipo Policy. Este puede ser un objeto o clase con un método apply(), o simplemente una referencia a una subrutina. El método/subrutina se llamará con el objeto de firmante como argumento. La política está responsable de verificar el mensaje y especificar parámetros de firma. La política debe devolver un valor no cero para crear la firma, de lo contrario no se crearía ninguna. Ejemplo:

my $policyfn = sub {
    my $dkim = shift;
    # especificar parámetros de firma
    $dkim->algorithm('rsa-sha1');
    $dkim->method('relaxed');
    $dkim->domain('example.org');
    $dkim->selector('mx1');
    # devolver valor no cero para crear la firma
    return 1;
};

O la política puede crear la firma realmente usando el método add_signature() dentro del objeto de política. Si añades una firma, no necesitas devolver un valor no cero. Este mecanismo puede utilizarse para crear múltiples firmas, o para crear las firmas antiguas de estilo DomainKey.

my $policyfn = sub {
    my $dkim = shift;
    $dkim->add_signature(
            new Mail::DKIM::Signature(
                    Algorithm => 'rsa-sha1',
                    Method => 'relaxed',
                    Headers => $dkim->headers,
                    Domain => 'example.org',
                    Selector => 'mx1',
            ));
    $dkim->add_signature(
            new Mail::DKIM::DkSignature(
                    Algorithm => 'rsa-sha1',
                    Method => 'nofws',
                    Headers => $dkim->headers,
                    Domain => 'example.org',
                    Selector => 'mx1',
            ));
    return;
};

Si no se especifica una política, se usa el política por defecto. El política por defecto firma cada mensaje usando el dominio, el algoritmo, el método y el selector especificados en el constructor new().
