Mail::DKIM::Policy(3) Documentation Perl fournie par l'utilisateur Mail::DKIM::Policy(3)

NOM

Mail::DKIM::Policy - classe de base abstraite pour les politiques de "signature" de l'expéditeur

VERSION

version 1.20240923

SYNOPSIS

# obtenir toutes les politiques qui s'appliquent à un message vérifié
foreach my $policy ($dkim->policies)
{
    # le nom de cette politique
    my $name = $policy->name;
    # l'emplacement dans le DNS où cette politique a été trouvée
    my $location = $policy->location;
    # appliquer cette politique au message en cours de vérification
    my $result = $policy->apply($dkim);
}

DESCRIPTION

Entre les différentes versions des normes DomainKeys/DKIM, plusieurs formes de politiques de signature de l'expéditeur ont été définies. Afin que la bibliothèque Mail::DKIM supporte ces différentes politiques, elle utilise plusieurs sous-classes distinctes. Toutes les sous-classes supportent cette interface générale, de sorte qu'un programme utilisant Mail::DKIM puisse supporter toutes les politiques trouvées pour un message.

MÉTHODES

Ces méthodes sont supportées par toutes les classes implémentant l'interface Mail::DKIM::Policy.

apply()

Applique la politique aux résultats d'un vérificateur DKIM.

my $result = $policy->apply($dkim_verifier);

L'appelant doit fournir une instance de Mail::DKIM::Verifier, qui a déjà été alimentée avec le message en cours de vérification.

Les résultats possibles sont :

accepter
Le message est approuvé par la politique de signature de l'expéditeur.
rejeter
Le message est rejeté par la politique de signature de l'expéditeur.
neutre
Le message n'est ni approuvé ni rejeté par la politique de signature de l'expéditeur. Il peut être considéré comme suspect.

as_string()

La politique sous forme de chaîne de caractères.

Notez que la chaîne retournée par cette méthode n'aura pas nécessairement les balises ordonnées de la même manière que le texte trouvé dans le DNS.

is_implied_default_policy()

Cette politique est-elle implicite ?

my $is_implied = $policy->is_implied_default_policy;

Si vous récupérez la politique pour un domaine particulier, mais que ce domaine n'a pas de politique publiée, alors la "politique par défaut" est en vigueur. Utilisez cette méthode pour détecter quand cela se produit.

location()

D'où la politique a été récupérée.

Il s'agit généralement d'un nom de domaine, le nom de domaine où la politique a été publiée.

Si rien n'est publié pour le domaine, et que la politique par défaut a été retournée à la place, l'emplacement sera "undef".

name()

Identifie le type de politique.

Ceci retourne actuellement des chaînes comme "sender", "author" et "ADSP". Ceci est susceptible de changer dans la prochaine version de Mail::DKIM.

VOIR AUSSI

Mail::DKIM::DkPolicy - pour les politiques de signature de l'expéditeur DomainKeys RFC4870 (historique)

Mail::DKIM::DkimPolicy - pour les politiques de signature de l'expéditeur DKIM des premières ébauches

Mail::DKIM::AuthorDomainPolicy - pour les pratiques de signature de domaine d'auteur (ADSP)
