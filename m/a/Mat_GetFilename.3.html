MAT_GETFILENAME(3) Manuel des fonctions de bibliothèque MAT_GETFILENAME(3)

NOM

Mat_GetFilename — Retourne le nom de fichier d'un fichier MAT MATLAB donné une structure de fichier MAT.

SYNTAXE

#include <matio.h>

const char *
Mat_GetFilename(const mat_t *matfp);

DESCRIPTION

La fonction Mat_GetFilename() retourne le nom de fichier du fichier MAT MATLAB donné par la structure de fichier MAT.

VALEURS DE RETOUR

La fonction retourne le nom de fichier en lecture seule du fichier MAT MATLAB ouvert.

VOIR AUSSI

Mat_CreateVer(3), Mat_Open(3), Mat_GetFileAccessMode(3), Mat_GetHeader(3), Mat_GetVersion(3)
