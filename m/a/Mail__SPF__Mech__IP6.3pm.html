NOM

Mail::SPF::Mech::IP6 - classe de mécanisme "ip6" pour les enregistrements SPF

VERSION

version 3.20250505

DESCRIPTION

Un objet de la classe Mail::SPF::Mech::IP6 représente un mécanisme de type "ip6" dans un enregistrement SPF.

Constructeurs

Les constructeurs suivants sont fournis :

new(%options): retourne Mail::SPF::Mech::IP6
Crée un nouvel objet de mécanisme "ip6" pour un enregistrement SPF.

%options est une liste de paires clé/valeur représentant les options suivantes :

qualificatif
reseau_ip
Voir "new" dans Mail::SPF::Mech.
new_from_string($texte, %options): retourne Mail::SPF::Mech::IP6; lance Mail::SPF::ENothingToParse, Mail::SPF::EInvalidMech
Crée un nouvel objet de mécanisme "ip6" pour un enregistrement SPF en analysant la chaîne et les options fournies.

Méthodes de classe

Les méthodes de classe suivantes sont fournies :

qualificatif_par_defaut
longueur_prefixe_ipv6_par_defaut
motif_qualificatif
Voir "Méthodes de classe" dans Mail::SPF::Mech.
nom: retourne string
Retourne 'ip6'.
motif_nom: retourne Regexp
Retourne une expression régulière qui correspond au nom du mécanisme 'ip6'.

Méthodes d'instance

Les méthodes d'instance suivantes sont fournies :

texte
qualificatif
parametres
chaine
Voir "Méthodes d'instance" dans Mail::SPF::Mech.
reseau_ip: retourne NetAddr::IP
Retourne le paramètre de réseau d'adresse IP du mécanisme.
correspond($serveur, $requete): retourne booléen
Retourne vrai si le "reseau_ip" du mécanisme est égal ou contient l'adresse IP de la requête donnée, ou faux sinon. Voir RFC 4408, 5.6, pour plus de détails.
