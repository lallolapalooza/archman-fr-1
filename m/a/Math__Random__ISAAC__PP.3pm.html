Math::Random::ISAAC::PP(3) Documentation Perl fournie par l'utilisateur Math::Random::ISAAC::PP(3)

NOM

Math::Random::ISAAC::PP - Port Pure Perl de l'algorithme PRNG ISAAC

VERSION

version 1.004

SYNOPSIS

Ce module implémente la même interface que "Math::Random::ISAAC" et peut être utilisé comme un remplacement direct. Cependant, il est recommandé de laisser le module "Math::Random::ISAAC" décider d'utiliser la version PurePerl ou XS de ce module, au lieu de choisir manuellement.

Sélectionner le backend à utiliser manuellement n'a que deux utilisations:

  • Si vous essayez d'éviter le petit surcoût occasionné par la répartition des appels de méthodes vers les modules backend appropriés.
  • Si vous testez le module pour ses performances et souhaitez décider explicitement quel module vous souhaitez utiliser.

Exemple de code:

# Avec Math::Random::ISAAC
my $rng = Math::Random::ISAAC->new(time);
my $rand = $rng->rand();
# Avec Math::Random::ISAAC::PP
my $rng = Math::Random::ISAAC::PP->new(time);
my $rand = $rng->rand();
