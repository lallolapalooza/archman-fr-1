Mat_VarReadNext(3)

Paquet: libmatio

Licences: BSD-2-Clause

MAT_VARREADNEXT(3) Manuel des fonctions de bibliothèque MAT_VARREADNEXT(3)

NOM

Mat_VarReadNext — Lit les informations et les données de la prochaine variable dans un fichier MAT MATLAB.

SYNTAXE

#include <matio.h>

matvar_t *
Mat_VarReadNext(mat_t *matfp);

DESCRIPTION

La fonction Mat_VarReadNext() lit les informations et les données de la prochaine variable stockée dans le fichier MAT ouvert.

VALEURS DE RETOUR

S'il existe une autre variable dans le fichier MAT et qu'elle est lue avec succès, un pointeur vers la structure de variable MATLAB est retourné. S'il n'y a plus de variables, ou s'il y a eu une erreur lors de la lecture de la variable, NULL est retourné.

EXEMPLES

Cet exemple de programme ouvre un fichier MAT nommé par le premier argument du programme, et utilise Mat_VarReadNext() pour lire chaque variable du fichier. Pour chaque variable lue, la fonction Mat_VarPrint(3) est utilisée pour afficher les informations et les données de la variable.

#include <stdlib.h>
#include <stdio.h>
#include "matio.h"

int
main(int argc, char **argv)
{
    mat_t    *matfp;
    matvar_t *matvar;

    matfp = Mat_Open(argv[1], MAT_ACC_RDONLY);
    if ( NULL == matfp ) {
        fprintf(stderr, "Erreur lors de l'ouverture du fichier MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    while ( NULL != (matvar = Mat_VarReadNext(matfp)) ) {
        Mat_VarPrint(matvar, 1);
        Mat_VarFree(matvar);
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
