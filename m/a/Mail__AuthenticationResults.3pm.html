NOM

Mail::AuthenticationResults - En-têtes d'e-mails d'Authentication-Results orientés objet

VERSION

version 2.20250709

DESCRIPTION

En-têtes d'e-mails d'Authentication-Results orientés objet.

Ce parseur gère la plupart des styles d'en-têtes Authentication-Results rencontrés dans la nature, mais n'est pas encore entièrement conforme à la RFC7601.

Différences par rapport à la RFC7601

Les paires clé/valeur sont analysées lorsqu'elles sont présentes dans la section authserv-id, ce qui est contraire à la RFC mais a été vu dans les en-têtes ajoutés par Yahoo!.

Les commentaires ajoutés entre les paires clé/valeur seront ajoutés après celles-ci dans les structures de données et lors de leur conversion en chaîne.

MÉTHODES

new()

Retourne un nouvel objet Mail::AuthenticationResults.

parser()

Retourne un nouvel objet Mail::AuthenticationResults::Parser pour l'en-tête $auth_results fourni.
