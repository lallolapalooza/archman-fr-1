Mail::Mailer(3) Documentation Perl contribuée par les utilisateurs Mail::Mailer(3)

NOM

Mail::Mailer - envoyer des courriels simples

HÉRITAGE

Mail::Mailer
  est un IO::Handle

SYNOPIS

use Mail::Mailer;
use Mail::Mailer qw(mail);    # spécifie le mailer par défaut
$mailer = Mail::Mailer->new;
$mailer = Mail::Mailer->new($type, @args);
$mailer->open(\%headers);
print $mailer $body;
$mailer->close
    or die "impossible d'envoyer tout le message: $!\n";

DESCRIPTION

Envoie des courriels en utilisant l'un des méthodes préinstallées. Comme argument TYPE à la méthode new(), vous pouvez spécifier l'un des suivants :

"sendmail"
Utilise le programme "sendmail" pour envoyer les courriels.
"smtp"
Utilise le protocole "smtp" via Net::SMTP pour envoyer les courriels. Le serveur à utiliser peut être spécifié dans @args avec
$mailer = Mail::Mailer->new('smtp', Server => $server);

Le mailer smtp ne gère pas les lignes "Cc" et "Bcc", ni leurs frères "Resent-*". L'option "Debug" active la sortie de débogage de "Net::SMTP".

[ajouté 2.21] Vous pouvez également utiliser les options "StartTLS => 1" pour mettre à jour la connexion avec STARTTLS. La même application s'applique à l'option "SSL => 1".

Vous pouvez également utiliser l'option "Auth => [ $user, $password ]" pour l'authentification SASL. Pour que cela fonctionne, vous devez installer vous-même la distribution Authen::SASL : elle n'est pas installée automatiquement.

"smtps"
Cette option est dépréciée lorsque vous avez "libnet" 1.28 (2014) et supérieur. Utilise le protocole smtp sur ssl via Net::SMTP::SSL pour envoyer des courriels. L'utilisation est identique à "smtp". Vous devez également installer Authen::SASL.
$mailer = Mail::Mailer->new('smtps', Server => $server);
"qmail"
Utilise le programme qmail-inject de qmail pour envoyer les courriels.
"testfile"
Utilisé pour le débogage, affiche les données dans le fichier nommé dans $Mail::Mailer::testfile::config{outfile} qui par défaut s'appelle "mailer.testfile". Aucun courriel n'est jamais envoyé.

"Mail::Mailer" recherchera dans l'ordre les exécutables suivants. Le mailer par défaut sera le premier trouvé.

MÉTHODES

Constructeurs

Mail::Mailer->new($type, %options)
Le $type est l'un des implémenteurs d'envoi de courriels, tel que décrit dans le chapitre DESCRIPTION de cette page de manuel. Les %options sont passées à cet implémenteur.
$obj->open(HASH)
La HASH contient des paires clé-valeur, où la clé est le nom du champ d'en-tête (par exemple, "To"), et la valeur est le contenu correspondant du champ d'en-tête. La valeur peut être un scalaire (par exemple, "gnat@frii.com") ou une référence à un tableau de scalaires (par exemple, "ex, ['gnat@frii.com', 'Tim.Bunce@ig.co.uk']").

DÉTAILS

VARIABLES D'ENVIRONNEMENT

PERL_MAILERS
Augmente/ouvre le choix du binaire utilisé pour envoyer nos messages électroniques.

Format :

"type1:mailbinary1;mailbinary2;...:type2:mailbinaryX;...:..."

Exemple : si vous souhaitez utiliser un binaire sendmail privé au lieu de mailx, vous pouvez définir

"PERL_MAILERS"

à :

"mail:/no/path/to/|sendmail:$HOME/test/bin/sendmail"

Sur les systèmes où les noms de fichiers peuvent contenir des ":", utilisez "|" comme séparateur entre les groupes de types.

"mail:c:/no/path/to|sendmail:$HOME/test/bin/sendmail"

BOGUES

Mail::Mailer n'aide pas au double pliage et ne protège pas contre diverses attaques par script web, par exemple, où une nouvelle ligne est insérée dans le contenu d'un champ.
