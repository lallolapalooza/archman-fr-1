Mail::Box::Tie(3) Documentation Perl fournie par l'utilisateur Mail::Box::Tie(3)

NOM

Mail::Box::Tie - accéder à un dossier de messages existant comme un tableau ou une table de hachage

HERITAGE

Mail::Box::Tie est étendu par
  Mail::Box::Tie::ARRAY
  Mail::Box::Tie::HASH

SYNOPIS

Comme un tableau :

tie my(@inbox), Mail::Box::Tie::ARRAY => $folder;
print $inbox[3];

Ou comme une table de hachage :

tie my(%inbox), Mail::Box::Tie::HASH => $folder;
print $inbox{'<12379.124879@example.com>'};

DESCRIPTION

Les dossiers ressemblent certainement à un tableau de messages, alors pourquoi ne pas y accéder comme tel ? Ou bien, l'ordre n'a pas d'importance, mais les identifiants de messages sont importants (pour donner des relations) : pourquoi ne pas y accéder à partir d'une table de hachage basée sur cet identifiant de message ? Les programmes utilisant l'une de ces liaisons auront l'air plus simples que les programmes utilisant les appels de méthode plus traditionnels.

MÉTHODES

Constructeurs

$class->new($folder, $type)
N'appelez pas cette méthode directement, mais via l'interface tie.

Attributs

$obj->folder()
$obj->type()
