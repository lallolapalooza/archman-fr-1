NOM

Math::Round - Extension Perl pour arrondir des nombres

SYNOPIS

use Math::Round qw(...ceux que vous voulez... ou :all);
$arrondi = round($scalaire);
@arrondis = round(LIST...);
$arrondi = nearest($cible, $scalaire);
@arrondis = nearest($cible, LIST...);
# et d'autres fonctions comme décrites ci-dessous

DESCRIPTION

Math::Round fournit des fonctions qui arrondissent les nombres de différentes manières. Les fonctions round et nearest sont exportées par défaut ; d'autres sont disponibles comme décrit ci-dessous. L'utilisation de "use ... qw(:all)" exporte toutes les fonctions.

FONCTIONS

round LIST
Arrondit les nombres à l'entier le plus proche. En contexte scalaire, retourne une seule valeur ; en contexte de liste, retourne une liste de valeurs. Les nombres se situant exactement à mi-chemin entre deux entiers sont arrondis vers l'infini ; c'est-à-dire que les valeurs positives sont arrondies vers le haut (par exemple, 2.5 devient 3) et les valeurs négatives vers le bas (par exemple, -2.5 devient -3).
round_even LIST
Arrondit les nombres à l'entier le plus proche. En contexte scalaire, retourne une seule valeur ; en contexte de liste, retourne une liste de valeurs. Les nombres se situant exactement à mi-chemin entre deux entiers sont arrondis vers l'entier pair le plus proche ; par exemple, 2.5 devient 2, 3.5 devient 4, et -2.5 devient -2.
round_odd LIST
Arrondit les nombres à l'entier le plus proche. En contexte scalaire, retourne une seule valeur ; en contexte de liste, retourne une liste de valeurs. Les nombres se situant exactement à mi-chemin entre deux entiers sont arrondis vers l'entier impair le plus proche ; par exemple, 3.5 devient 3, 4.5 devient 5, et -3.5 devient -3.
round_rand LIST
Arrondit les nombres à l'entier le plus proche. En contexte scalaire, retourne une seule valeur ; en contexte de liste, retourne une liste de valeurs. Les nombres se situant exactement à mi-chemin entre deux entiers sont arrondis aléatoirement vers le haut ou vers le bas. Par exemple, sur un grand nombre d'essais, 2.5 deviendra 2 la moitié du temps et 3 l'autre moitié.
nearest CIBLE, LIST
Arrondit les nombres au multiple le plus proche de la valeur cible. La CIBLE doit être positive. En contexte scalaire, retourne une seule valeur ; en contexte de liste, retourne une liste de valeurs. Les nombres se situant exactement à mi-chemin entre deux multiples de la cible sont arrondis vers l'infini. Par exemple : 
nearest(10, 44)    donne  40
nearest(10, 46)            50
nearest(10, 45)            50
nearest(25, 328)          325
nearest(.1, 4.567)          4.6
nearest(10, -45)          -50
nearest_ceil CIBLE, LIST
Arrondit les nombres au multiple le plus proche de la valeur cible. La CIBLE doit être positive. En contexte scalaire, retourne une seule valeur ; en contexte de liste, retourne une liste de valeurs. Les nombres se situant exactement à mi-chemin entre deux multiples de la cible sont arrondis vers le haut, c'est-à-dire le multiple le plus proche de celui qui est algébriquement suivant. Par exemple : 
nearest_ceil(10, 44)    donne  40
nearest_ceil(10, 45)            50
nearest_ceil(10, -45)          -40
nearest_floor CIBLE, LIST
Arrondit les nombres au multiple le plus proche de la valeur cible. La CIBLE doit être positive. En contexte scalaire, retourne une seule valeur ; en contexte de liste, retourne une liste de valeurs. Les nombres se situant exactement à mi-chemin entre deux multiples de la cible sont arrondis vers le bas, c'est-à-dire le multiple le plus proche de celui qui est algébriquement suivant. Par exemple : 
nearest_floor(10, 44)    donne  40
nearest_floor(10, 45)            40
nearest_floor(10, -45)          -50
nearest_rand CIBLE, LIST
Arrondit les nombres au multiple le plus proche de la valeur cible. La CIBLE doit être positive. En contexte scalaire, retourne une seule valeur ; en contexte de liste, retourne une liste de valeurs. Les nombres se situant exactement à mi-chemin entre deux multiples de la cible sont arrondis aléatoirement vers le haut ou vers le bas. Par exemple, sur un grand nombre d'essais, nearest(10, 45) deviendra 40 la moitié du temps et 50 l'autre moitié.
nlowmult CIBLE, LIST
Retourne le multiple inférieur le plus proche pour les nombres dans LIST. La CIBLE doit être positive. En contexte scalaire, retourne une seule valeur ; en contexte de liste, retourne une liste de valeurs. Les nombres situés entre deux multiples de la cible sont ramenés au multiple de LIST qui est algébriquement inférieur. Par exemple : 
nlowmult(10, 44)    donne  40
nlowmult(10, 46)            40
nlowmult(25, 328)          325
nlowmult(.1, 4.567)          4.5
nlowmult(10, -41)          -50
nhimult CIBLE, LIST
Retourne le multiple supérieur le plus proche pour les nombres dans LIST. La CIBLE doit être positive. En contexte scalaire, retourne une seule valeur ; en contexte de liste, retourne une liste de valeurs. Les nombres situés entre deux multiples de la cible sont ramenés au multiple de LIST qui est algébriquement supérieur. Par exemple : 
nhimult(10, 44)    donne  50
nhimult(10, 46)            50
nhimult(25, 328)          350
nhimult(.1, 4.512)          4.6
nhimult(10, -49)          -40

VARIABLE

La variable $Math::Round::half est utilisée par la plupart des routines de ce module. Sa valeur est légèrement supérieure à 0.5, pour des raisons expliquées ci-dessous. Si vous constatez que votre application ne donne pas les résultats escomptés, vous pouvez réinitialiser cette variable à votre convenance.

AVERTISSEMENT SUR LES NOMBRES À VIRGULE FLOTTANTE

Les nombres à virgule flottante sont un sous-ensemble rationnel des nombres réels, donc les opérations avec eux ne sont pas toujours exactes. Les nombres qui se situent exactement à mi-chemin entre deux autres peuvent vous surprendre ; par exemple, 0.85 n'est pas exactement à mi-chemin entre 0.8 et 0.9, et (0.75 - 0.7) n'est pas identique à (0.85 - 0.8).

Pour donner des résultats plus prévisibles, ces routines utilisent une valeur pour un demi-marge légèrement supérieure à 0.5. Cependant, si les nombres à arrondir sont stockés sous forme de nombres à virgule flottante, ils seront soumis aux caprices de votre matériel, de votre compilateur C, etc.
