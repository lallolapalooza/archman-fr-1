NOM

Math::Base85 - Extension Perl pour les nombres base 85, tels que référencés par la RFC 1924

SYNTAXE

use Math::Base85;
$bigint = from_base85($number);
$b85str = to_base85($bigint);

DESCRIPTION

La RFC 1924 décrit une représentation compacte et de taille fixe des adresses IPv6 qui utilise un système de numération en base 85. Ce module gère certains des détails les plus complexes de celle-ci.

Les nombres en base 85 (de 0 à 84) sont les suivants :

0..9 A..Z a..z ! # $ % & ( ) * + - ; < = > ? @ ^ _ ` { | } ~

Pour le moment, il n'y a pas grand-chose dans ce module. Mais il devrait être suffisant pour les besoins de la RFC 1924.

Ce module possède une variable appelée $Math::Base85::base85_digits, qui est une chaîne contenant les chiffres de l'alphabet base 85 du plus bas (0) au plus haut (~), dans cet ordre.

De plus, les deux fonctions suivantes sont définies pour une utilisation générale. (Elles seront exportées sur demande.)

from_base85

Paramètres

Une chaîne composée de chiffres valides en base 85.

Retourne

Un objet "Math::BigInt" représentant le nombre.

to_base85

Paramètres

Un objet "Math::BigInt".

Retourne

Une chaîne de chiffres en base 85 représentant le nombre.
