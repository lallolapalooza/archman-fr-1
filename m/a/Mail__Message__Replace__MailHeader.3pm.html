NOM

Mail::Message::Replace::MailHeader : objet Mail::Header factice

HÉRITAGE

Mail::Message::Replace::MailHeader
                          est une Mail::Message::Head::Complete
                          est une Mail::Message::Head
                          est une Mail::Reporter

SYNOPSIS

# Changer
use Mail::Internet;
use Mail::Header;
# dans du code existant, et le code continuera de fonctionner, mais
# avec les caractéristiques de Mail::Message.

DESCRIPTION

Ce module est une couche autour de Mail::Message::Head::Complete, qui simule un objet Mail::Header. L'espace de noms de ce module est hérité et de nombreuses méthodes sont ajoutées.

Plus de méthodes fonctionneront sans changement, mais vous devriez tester votre logiciel à nouveau. De petits changements ont été apportés à fold_length(), header_hashref().

Accès à l'en-tête

Simulation de Mail::Header

$obj->as_string()
Retourne l'en-tête entier sous forme d'un grand scalaire. Appelle Mail::Message::Head::Complete::string().
$obj->cleanup()
Nettoie l'utilisation de la mémoire. Pas nécessaire ici.
$obj->combine( $tag, [$with] )
Je ne vois aucune raison valable pour cette commande, donc je ne l'ai pas implémentée.
$obj->dup()
Duplique l'en-tête, ce qui est simplement clone().
$obj->empty()
Vide toute la table de hachage. Mieux vaut ne pas l'utiliser (créez simplement un autre objet d'en-tête), bien que cela devrait fonctionner.
$obj->exists()
Retourne s'il y a des champs.
$obj->extract(\@lines)
Extrait (et supprime) les champs d'en-tête du tableau.
$obj->fold( [$length] )
Replie tous les champs de l'en-tête, à $length ou ce que fold_length() retourne.
$obj->fold_length( [[$tag], $length] )
Retourne la longueur de ligne, éventuellement après l'avoir définie à $length. L'ancienne valeur est retournée. L'argument $tag est ignoré, car il est stupide d'avoir des lignes qui se replient différemment. Cette méthode ne peut plus être appelée statiquement.
$obj->header( [ARRAY] )
Extrait les champs de "ARRAY", si spécifié, puis replie les champs. Retourne un tableau avec tous les champs, produit via orderedFields().
$obj->header_hashref(HASH)
Si vous utilisez cette méthode, vous devez être stupide... enfin : je ne veux pas la supporter pour l'instant : utilisez add() et ses amis.
$obj->mail_from( ['IGNORE'|'ERROR'|'COERCE'|'KEEP'] )
Que faire lorsqu'une ligne d'en-tête de la forme `From ' est rencontrée. Les valeurs valides sont "IGNORE" - ignorer et rejeter l'en-tête, "ERROR" - déclencher une erreur (appeler die), "COERCE" - les renommer en Mail-From et "KEEP" - les conserver.
$obj->modify( [BOOLEAN] )
Replie les en-têtes lorsqu'ils sont ajoutés.
$obj->read($file)
Lit l'en-tête à partir du fichier $file. Améliore la base, voir "Internes" dans Mail::Message::Head
$obj->tags()
Retourne tous les noms des champs, implémentés par Mail::Message::Head::Complete::names().
$obj->unfold( [$tag] )
Supprime le repli pour toutes les instances de $tag, ou pour tous les champs à la fois.

DIAGNOSTICS

Attention: Impossible de supprimer le champ $name de l'en-tête : non trouvé.
Vous demandez la suppression d'un champ qui n'est pas connu dans l'en-tête. L'utilisation de delete(), reset(), ou set() pour effectuer cette tâche n'entraînera pas d'avertissements : ces méthodes vérifient d'abord l'existence du champ. Lancé par removeField()
Attention: Les objets de champ ont un nom implicite ($name)
Lancé par build()
Erreur: Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où elle devrait l'être. Ce message signifie que d'autres classes liées implémentent cette méthode, mais que la classe en question ne le fait pas. Vous devriez probablement enquêter sur cela et probablement informer l'auteur du paquet. Lancé par notImplemented()
