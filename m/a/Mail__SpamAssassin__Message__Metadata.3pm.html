NOM

Mail::SpamAssassin::Message::Metadata - extrait les métadonnées d'un message

DESCRIPTION

Cette classe est chargée d'extraire les "métadonnées" des messages pour les utiliser comme jetons Bayes, données pour les tests `eval`, ou d'autres règles. Les métadonnées sont des données supplémentaires déduites du message, comme dans les exemples ci-dessous.

Elles sont conservées sous deux formes:

1. Sous forme de paires nom-valeur de chaînes de caractères, présentées au format d'en-tête de courrier. Par exemple, "X-Languages" =>
"en". C'est la forme générale pour des métadonnées simples utiles comme
jetons Bayes, pouvant être ajoutées aux messages marqués via
"add_header", etc., comme l'inférence de relais de confiance et la détection de
langue.

2. Sous forme de structures de données plus complexes sur l'objet
$msg->{metadata}. C'est la forme utilisée pour des métadonnées comme
les données d'analyse HTML, qui y sont stockées pour être accessibles par le
code des règles `eval`. Comme ce ne sont pas de simples chaînes de caractères,
elles ne sont pas ajoutées comme jetons Bayes par défaut (Bayes a besoin de
chaînes simples).
