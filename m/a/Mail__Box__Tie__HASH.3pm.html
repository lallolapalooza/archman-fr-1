NOM

Mail::Box::Tie::HASH - accéder à un dossier de messages existant comme une table de hachage

HÉRITAGE

Mail::Box::Tie::HASH
  est un Mail::Box::Tie

SYNOPSIS

tie my(%inbox), 'Mail::Box::Tie::HASH', $folder;
foreach my $msgid (keys %inbox)
{   print $inbox{$msgid};
    delete $inbox{$msgid};
}
$inbox{$msg->messageId} = $msg;

DESCRIPTION

Certainement, lorsque vous considérez un dossier comme un ensemble de messages liés basés sur l'ID du message, il est logique d'accéder au dossier via une table de hachage.

Pour une table de hachage liée, l'ID du message est utilisé comme clé. L'ID du message est généralement unique, mais lorsque deux instances ou plus du même message se trouvent dans le même dossier, l'une sera marquée pour suppression et l'autre sera retournée.

Cette implémentation utilise des routines d'accès de dossier de base qui sont liées à l'ID du message.

Interface liée

$obj->CLEAR()
Supprime le contenu de la table de hachage. Ce n'est pas vraiment possible, mais tous les messages seront marqués pour suppression.

» exemple :

%inbox = ();
%inbox = ($msg->messageId, $msg); # avant d'ajouter le message
$obj->DELETE($message_id)
Supprime le message avec le $message_id spécifié.

» exemple :

delete $inbox{$msgid};
$obj->EXISTS($message_id)
Vérifie si un message avec un certain $message_id existe.

» exemple :

if(exists $inbox{$msgid}) ...
$obj->FETCH($message_id)
Récupère le message avec l'ID spécifié. Le message retourné peut être factice si la détection de fil de messages est utilisée. Retourne "undef" s'il n'y a pas de message avec l'ID spécifié.

» exemple :

my $msg = $inbox{$msgid};
if($inbox{$msgid}->isDummy)  ...
$obj->FIRSTKEY()
Voir NEXTKEY().
$obj->NEXTKEY($previous)
FIRSTKEY() retourne la première paire ID de message/message du dossier, et NEXTKEY retourne la paire ID de message/message du message suivant, dans l'ordre où le message est stocké dans le dossier.

Les messages marqués pour suppression ne seront pas retournés. Voir la méthode Mail::Box::messages() du type de dossier pour plus d'informations sur l'ordre des messages du dossier.

» exemple :

foreach my $msgid (keys %inbox) ...
foreach my $msg (values %inbox) ...
while(my ($msgid, $msg) = each %inbox) {
   $msg->print unless $msg->isDeleted;
}
$obj->STORE(undef, $message)
Stocke un message dans le dossier. La clé doit être "undef", car l'ID du message du message spécifié est utilisé. Ceci est montré dans le premier exemple. Cependant, comme vous le voyez, il est un peu compliqué de spécifier "undef", par conséquent la chaîne "undef" est également acceptée.

Le message peut être converti en quelque chose qui peut être stocké dans le type de dossier concerné. L'instance ajoutée est retournée.

» exemple :

$inbox{ (undef) } = $msg;
$inbox{undef} = $msg;
