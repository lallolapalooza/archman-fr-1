NAME

DecodeShortURLs - Vérifier les URL raccourcies

SYNOPSIS

loadplugin    DecodeShortURLs
url_shortener tinyurl.com
url_shortener_get bit.ly
body HAS_SHORT_URL          eval:short_url()
describe HAS_SHORT_URL      Le message contient une ou plusieurs URL raccourcies
body SHORT_URL_REDIR        eval:short_url_redir()
describe SHORT_URL_REDIR    Le message contient une URL raccourcie qui a entraîné une redirection valide
body SHORT_URL_CHAINED      eval:short_url_chained()
describe SHORT_URL_CHAINED  Le message contient une URL raccourcie qui mène à d'autres URL raccourcies
body SHORT_URL_MAXCHAIN     eval:short_url_maxchain()
describe SHORT_URL_MAXCHAIN Le message contient une URL raccourcie qui entraîne trop de redirections
body SHORT_URL_LOOP         eval:short_url_loop()
describe SHORT_URL_LOOP     Le message contient une URL raccourcie qui boucle sur elle-même
body SHORT_URL_200          eval:short_url_code('200') # Peut vérifier n'importe quel code HTTP non-redirection
describe SHORT_URL_200      Le message contient une URL raccourcie retournant le code HTTP 200
body SHORT_URL_404          eval:short_url_code('404') # Peut vérifier n'importe quel code HTTP non-redirection
describe SHORT_URL_404      Le message contient une URL raccourcie retournant le code HTTP 404
uri URI_TINYURL_BLOCKED      m,https://tinyurl.com/app/nospam,
describe URI_TINYURL_BLOCKED Le message contient une URL tinyurl qui a été bloquée en raison d'abus
uri URI_BITLY_BLOCKED       m,^https://bitly.com/a/blocked,
describe URI_BITLY_BLOCKED  Le message contient une URL bit.ly qui a été bloquée en raison d'abus

DESCRIPTION

Ce plugin recherche les URL raccourcies par une liste de services de raccourcissement d'URL. Lorsqu'il trouve une URL correspondante, le plugin enverra une requête HTTP au service de raccourcissement d'URL et récupérera l'en-tête Location qui pointe vers la véritable URL raccourcie. Cette URL sera ensuite ajoutée à la liste des URI extraites par SpamAssassin, qui peut être accessible par des règles URI et des plugins comme URIDNSBL.

Ce plugin suivra les redirections chaînées, où une URL raccourcie mène à une autre URL raccourcie. La profondeur maximale des redirections chaînées peut être configurée avec "max_short_url_redirections".

Un maximum de "max_short_urls" URL raccourcies sera vérifié dans un message (10 par défaut). Le régler à 0 désactive les requêtes HTTP, ne permettant que le test short_url() et le rapport des liens raccourcis trouvés.

Toutes les règles de type supportées pour la vérification des URL raccourcies et de leur statut de redirection sont documentées dans la section SYNOPSIS.

NOTES

Ce plugin s'exécute sur le hook check_dnsbl (priorité -100), lui permettant de modifier la liste des URI analysées avant les règles URI normales ou le plugin URIDNSBL.

PARAMÈTRES UTILISATEUR

url_shortener domaine [domaine...] (valeur par défaut : aucun)
Domaines à considérer comme un lien raccourci. Si le domaine commence par un point, le TLD principal de niveau 3 est vérifié.
url_shortener_get domaine [domaine...] (valeur par défaut : aucun)
Alias pour "url_shortener". La requête HTTP sera effectuée avec la méthode GET, au lieu de la méthode HEAD par défaut. Ceci est nécessaire pour que des services comme bit.ly retournent correctement une URL bloquée.
clear_url_shortener [domaine] [domaine...]
Supprime les domaines configurés pour url_shortener et url_shortener_get, par exemple, pour remplacer les valeurs par défaut à partir d'une mise à jour du pipeline. Si des domaines sont spécifiés, seuls ceux-ci sont supprimés de la liste.

PARAMÈTRES ADMINISTRATEUR

url_shortener_cache_type (valeur par défaut : aucun)
Le type de cache utilisé. Actuellement, seule la valeur "dbi" est prise en charge, ce qui implique que "url_shortener_cache_dsn" est une chaîne de connexion DBI. Le module DBI est requis.
url_shortener_cache_dsn (valeur par défaut : aucun)
La chaîne de connexion à la base de données DBI à utiliser.

Pour SQLite, la base de données sera créée automatiquement si elle n'existe pas, et le chemin et le fichier spécifiés doivent être lisibles et écrivables par l'utilisateur exécutant spamassassin ou spamd.

Pour MySQL/MariaDB ou PostgreSQL, voir sql-directory pour les clauses de création de tables de base de données.

Le module DBI approprié pour votre base de données est requis. Par exemple, DBD::SQLite, DBD::mysql, DBD::MariaDB ou DBD::Pg.

La version minimale requise de SQLite est 3.24.0 (disponible à partir de DBD::SQLite 1.59_01).

Exemple :

url_shortener_cache_dsn dbi:SQLite:dbname=/var/lib/spamassassin/DecodeShortURLs.db
url_shortener_cache_username (valeur par défaut : aucun)
L'utilisateur à utiliser pour se connecter à la base de données. Non utilisé pour SQLite.
url_shortener_cache_password (valeur par défaut : aucun)
Le mot de passe à utiliser pour se connecter à la base de données. Non utilisé pour SQLite.
url_shortener_cache_ttl (valeur par défaut : 86400)
La durée pendant laquelle une entrée de cache est valide, en secondes. La valeur par défaut est 86400 (1 jour).

Voir "url_shortener_cache_autoclean" pour le nettoyage de la base de données.

PARAMÈTRES DU RÉDACTEUR

url_shortener_cache_autoclean (valeur par défaut : 1000)
Supprime automatiquement les anciennes entrées de la base de données. La valeur décrit la probabilité d'une exécution aléatoire de 1/x. La valeur par défaut de 1000 signifie que le nettoyage est effectué environ une fois tous les 1000 messages traités. Une valeur de 1 signifie que la base de données est nettoyée chaque fois qu'un message est traité.
url_shortener_loginfo (valeur par défaut : 0 (désactivé))
Si cette option est activée (réglée sur 1), les URL raccourcies et les URL décodées sont journalisées avec une priorité d'information.
url_shortener_timeout (valeur par défaut : 5)
Le temps maximum qu'une requête HTTP pour une URL raccourcie peut prendre, en secondes.
max_short_urls (valeur par défaut : 10)
Le nombre maximum d'URL raccourcies à rechercher par message. Les redirections chaînées ne sont pas comptées, seulement les URL raccourcies initiales.

Le régler à 0 désactive les requêtes HTTP, ne permettant que le test short_url() et le rapport de toute URL raccourcie trouvée.

max_short_url_redirections (valeur par défaut : 10)
La profondeur maximale des redirections chaînées qu'une URL raccourcie peut générer.
url_shortener_user_agent (valeur par défaut : Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/101.0.4951.67 Safari/537.36)
La valeur User-Agent utilisée pour les requêtes HTTP. Certains services exigent qu'elle ressemble à celle d'un navigateur courant.
