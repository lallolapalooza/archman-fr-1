NAME

Mail::Box::Locker::FcntlLock - verrouiller un répertoire avec File::FcntlLock

INHERITANCE

Mail::Box::Locker::FcntlLock
  est un Mail::Box::Locker
  est un Mail::Reporter

SYNOPSIS

Voir Mail::Box::Locker

DESCRIPTION

Cet objet de verrouillage utilise File::FcntlLock, et a été contribué par Jim in Aus. Il est similaire à Mail::Box::Locker::POSIX, mais fonctionne sur plus de systèmes, par exemple Darwin.

Vous devrez installer File::FcntlLock séparément : il n'y a pas de dépendance de la distribution MailBox.

DIAGNOSTICS

Attention : Car c'est déjà verrouillé avec lockf
Émis par lock()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifié (ou l'un de ses ancêtres) n'implémente pas cette méthode là où il le devrait. Ce message signifie que certaines classes liées implémentent cette méthode alors que la classe en question ne le fait pas. Vous devriez probablement examiner cela et informer l'auteur du paquet. Émis par notImplemented()
Erreur : Impossible de vérifier le fichier de verrouillage $file pour $folder : $!
Pour vérifier si le nom de fichier est utilisé pour verrouiller un répertoire, le fichier doit être ouvert. Apparemment, cela échoue, ce qui ne signifie ni que le répertoire est verrouillé ni qu'il est déverrouillé. Émis par isLocked()
Erreur : Impossible d'ouvrir le fichier de verrouillage $file pour $folder : $!
Pour le verrouillage de type FcntlLock, le fichier $folder doit être ouvert, ce qui n'est pas possible pour la raison spécifiée. Émis par lock()
Erreur : Impossible d'obtenir un verrou FcntlLock sur $file pour $folder : $!
Tentative de verrouillage du $folder, mais cela n'a pas abouti. Le code d'erreur reçu du système indique que cela ne réussira jamais, il est donc inutile de réessayer. Émis par lock()
