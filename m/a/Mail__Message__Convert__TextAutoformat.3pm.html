NOM

Mail::Message::Convert::TextAutoformat - Reformatte les messages texte brut

HÉRITAGE

Mail::Message::Convert::TextAutoformat
  est un Mail::Message::Convert
  est un Mail::Reporter

SYNOPSIS

use Mail::Message::Convert::TextAutoformat;
my $af = Mail::Message::Convert::TextAutoformat->new;
my $beautified_body = $af->autoformatBody($body);

DESCRIPTION

Joue avec le texte brut, par exemple le corps avec le type "text/plain" en utilisant Text::Autoformat de Damian Conway.

Conversion

$obj->autoformatBody($body)
Formate un seul corps de message (un objet Mail::Message::Body) en un nouveau objet de corps en utilisant Text::Autoformat.

Le corps doit avoir le type de contenu "text/plain", sinon le résultat est probablement étrange.
