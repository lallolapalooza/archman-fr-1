MAPS

type key

Le type des clés de la map.

type !+'a t

Le type des maps de type key vers type 'a .

val empty : 'a t

La map vide.

val add : key -> 'a -> 'a t -> 'a t

add key data m retourne une map contenant les mêmes associations que m , plus une association de key à data . Si key était déjà associé dans m à une valeur physiquement égale à data , m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m ). Sinon, l'association précédente de key dans m disparaît.

Avant 4.03 L'égalité physique n'était pas garantie.

val add_to_list : key -> 'a -> 'a list t -> 'a list t

add_to_list key data m est m avec key associée à l telle que l est data :: Map.find key m si key était associé dans m et [data] sinon.

Depuis 5.1

val update : key -> ('a option -> 'a option) -> 'a t -> 'a t

update key f m retourne une map contenant les mêmes associations que m , à l'exception de l'association de key . Selon la valeur de y où y est f (find_opt key m) , l'association de key est ajoutée, supprimée ou mise à jour. Si y est None , l'association est supprimée si elle existe ; sinon, si y est Some z , alors key est associée à z dans la map résultante. Si key était déjà associée dans m à une valeur physiquement égale à z , m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m ).

Depuis 4.06

val singleton : key -> 'a -> 'a t

singleton x y retourne la map à un élément qui associe y à x .

Depuis 3.12

val remove : key -> 'a t -> 'a t

remove x m retourne une map contenant les mêmes associations que m , à l'exception de x qui est désassocié dans la map retournée. Si x n'était pas dans m , m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m ).

Avant 4.03 L'égalité physique n'était pas garantie.

val merge : (key -> 'a option -> 'b option -> 'c option) -> 'a t -> 'b t -> 'c t

merge f m1 m2 calcule une map dont les clés sont un sous-ensemble des clés de m1 et de m2 . La présence de chaque association, et la valeur correspondante, est déterminée par la fonction f . En termes de l'opération find_opt , nous avons find_opt x (merge f m1 m2) = f x (find_opt x m1) (find_opt x m2) pour toute clé x , à condition que f x None None = None .

Depuis 3.12

val union : (key -> 'a -> 'a -> 'a option) -> 'a t -> 'a t -> 'a t

union f m1 m2 calcule une map dont les clés sont un sous-ensemble des clés de m1 et de m2 . Lorsque la même association est définie dans les deux arguments, la fonction f est utilisée pour les combiner. Ceci est un cas particulier de merge : union f m1 m2 est équivalent à merge f' m1 m2 , où

- f' _key None None = None

- f' _key (Some v) None = Some v

- f' _key None (Some v) = Some v

- f' key (Some v1) (Some v2) = f key v1 v2

Depuis 4.03

val bindings : 'a t -> (key * 'a) list

Retourne la liste de toutes les associations de la map donnée. La liste renvoyée est triée par ordre croissant des clés par rapport à l'ordre Ord.compare , où Ord est l'argument donné à Map.Make .

RECHERCHE

val find : key -> 'a t -> 'a

find x m retourne la valeur actuelle de x dans m , ou lève Not_found si aucune association pour x n'existe.

val find_opt : key -> 'a t -> 'a option

find_opt x m retourne Some v si la valeur actuelle de x dans m est v , ou None si aucune association pour x n'existe.

Depuis 4.05

val find_first : (key -> bool) -> 'a t -> key * 'a

find_first f m , où f est une fonction monotonically croissante, retourne l'association de m avec la clé la plus petite k telle que f k , ou lève Not_found si aucune clé de ce type n'existe.

Par exemple, find_first (fun k -> Ord.compare k x >= 0) m retournera la première association k, v de m où Ord.compare k x >= 0 (intuitivement : k >= x ), ou lève Not_found si x est plus grand que tout élément de m .

Depuis 4.05

val find_first_opt : (key -> bool) -> 'a t -> (key * 'a) option

find_first_opt f m , où f est une fonction monotonically croissante, retourne une option contenant l'association de m avec la clé la plus petite k telle que f k , ou None si aucune clé de ce type n'existe.

Depuis 4.05

val find_last : (key -> bool) -> 'a t -> key * 'a

find_last f m , où f est une fonction monotonically décroissante, retourne l'association de m avec la clé la plus grande k telle que f k , ou lève Not_found si aucune clé de ce type n'existe.

Depuis 4.05

MODULE PARTITIONNÉ

Module Map.Make peut être instancié par n'importe quel module implémentant Map.OrderedType :

Example

module IntMap = Map.Make(struct type t = int let compare = compare end)

Crée une map d'entiers.

module StringMap = Map.Make(String)

Crée une map de chaînes de caractères.

Note La plupart des modules de map pré-définis dans la bibliothèque standard (par exemple, Map.Int , Map.String , etc.) sont construits à l'aide de ce functor.

Transformation

val map : ('a -> 'b) -> 'a t -> 'b t

map f m renvoie une carte ayant le même domaine que m, où la valeur associée a de toutes les liaisons de m a été remplacée par le résultat de l'application de f à a. Les liaisons sont passées à f dans l'ordre croissant par rapport à l'ordre sur le type des clés.

val mapi : (clé -> 'a -> 'b) -> 'a t -> 'b t

Identique à Map.S.map, mais la fonction reçoit en arguments la clé et la valeur associée pour chaque liaison de la carte.

val filter : (clé -> 'a -> bool) -> 'a t -> 'a t

filter f m renvoie la carte avec toutes les liaisons de m qui satisfont le prédicat p. Si toutes les liaisons de m satisfont f, m est renvoyée inchangée (le résultat de la fonction est alors physiquement égal à m).

Depuis 3.12

val filter_map : (clé -> 'a -> 'b option) -> 'a t -> 'b t

filter_map f m applique la fonction f à chaque liaison de m et construit une carte à partir des résultats. Pour chaque liaison (k, v) dans la carte d'entrée :

- si f k v est None alors k n'est pas dans le résultat,

- si f k v est Some v' alors la liaison (k, v') est dans la carte de sortie.

Par exemple, la fonction suivante sur des cartes dont les valeurs sont des listes

        filter_map
          (fun _k li -> match li with [] -> None | _::tl -> Some tl)
          m
supprime toutes les liaisons de m dont la valeur est une liste vide, et dépile le premier élément de chaque valeur non vide.

Depuis 4.11

val partition : (clé -> 'a -> bool) -> 'a t -> 'a t * 'a t

partition f m renvoie un couple de cartes (m1, m2), où m1 contient toutes les liaisons de m qui satisfont le prédicat f, et m2 est la carte avec toutes les liaisons de m qui ne satisfont pas f.

Depuis 3.12

val split : clé -> 'a t -> 'a t * 'a option * 'a t

split x m renvoie un triplet (l, data, r), où l est la carte avec toutes les liaisons de m dont la clé est strictement inférieure à x ; r est la carte avec toutes les liaisons de m dont la clé est strictement supérieure à x ; data est None si m ne contient aucune liaison pour x, ou Some v si m associe v à x.

Prédicats et comparaisons

val is_empty : 'a t -> bool

Teste si une carte est vide ou non.

val mem : clé -> 'a t -> bool

mem x m renvoie true si m contient une liaison pour x, et false sinon.

val equal : ('a -> 'a -> bool) -> 'a t -> 'a t -> bool

equal cmp m1 m2 teste si les cartes m1 et m2 sont égales, c'est-à-dire, contiennent des clés égales et leur associent des données égales. cmp est le prédicat d'égalité utilisé pour comparer les données associées aux clés.

val compare : ('a -> 'a -> int) -> 'a t -> 'a t -> int

Ordre total entre les cartes. Le premier argument est un ordre total utilisé pour comparer les données associées aux clés égales dans les deux cartes.

val for_all : (clé -> 'a -> bool) -> 'a t -> bool

for_all f m vérifie si toutes les liaisons de la carte satisfont le prédicat f.

Depuis 3.12

val exists : (clé -> 'a -> bool) -> 'a t -> bool

exists f m vérifie si au moins une liaison de la carte satisfait le prédicat f.
