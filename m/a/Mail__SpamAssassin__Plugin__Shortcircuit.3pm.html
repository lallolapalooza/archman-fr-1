NOM

Mail::SpamAssassin::Plugin::Shortcircuit - court-circuitage de l'évaluation pour certaines règles

SYNTAXE

loadplugin     Mail::SpamAssassin::Plugin::Shortcircuit
report Content analysis details:   (_SCORE_ points, _REQD_ requis, s/c _SCTYPE_)
add_header all Status "_YESNO_, score=_SCORE_ required=_REQD_ tests=_TESTS_ shortcircuit=_SCTYPE_ autolearn=_AUTOLEARN_ version=_VERSION_"

DESCRIPTION

Ce plugin implémente un court-circuitage simple basé sur des tests. Le court-circuitage d'un test forcera le saut de toutes les autres règles en attente si ce test est déclenché. En outre, une règle symbolique, "SHORTCIRCUIT", sera déclenchée.

Il est recommandé d'utiliser la directive "priority" pour définir les règles ayant des valeurs S/O fortes (par exemple, 1.0) pour qu'elles soient exécutées en premier, et pour effectuer une classification instantanée des spams ou des ham (non-spams) en basant sur cela.

PARAMETRES DE CONFIGURATION

Les paramètres de configuration suivants sont utilisés pour contrôler le court-circuitage :

shortcircuit NOM_TEST_SYMBOLIQUE {ham|spam|on|off}
Le court-circuitage d'un test forcera le saut de toutes les autres règles en attente si ce test est déclenché.

Il est recommandé d'utiliser la directive "priority" pour définir les règles ayant des valeurs S/O fortes (par exemple, 1.0) pour qu'elles soient exécutées en premier, et pour effectuer une classification instantanée des spams ou des ham en basant sur cela.

Pour outrepasser un test qui utilise le court-circuitage, vous pouvez définir le type de classification sur "off".

Notez que les requêtes DNS et autres requêtes réseau sont lancées lorsque SA atteint la priorité -100. Si vous souhaitez court-circuiter l'analyse avant que toute requête réseau ne soit envoyée, vous devez définir une priorité inférieure à -100 pour toute règle de ce type, comme -200 dans les exemples ci-dessous.

Le test court-circuité sera automatiquement défini avec la priorité -200, mais seulement si la priorité d'origine reste inchangée à la valeur par défaut de 0.

on
Court-circuite le reste des tests, mais ne fait pas de classification stricte de spam ou de ham. Au lieu de cela, il utilise le score par défaut de la règle qui est court-circuitée. Cela vous permettrait, par exemple, de définir une règle comme suit : 
body TEST /test/
describe TEST test rule that scores barely over spam threshold
score TEST 5.5
priority TEST -200
shortcircuit TEST on

Le résultat d'un message frappant la règle ci-dessus serait un score final de 5.5, au lieu de 100 (par défaut) s'il était classé comme spam.

off
Désactive le court-circuitage sur ladite règle.
spam
Court-circuite la règle en utilisant un ensemble de valeurs par défaut ; remplace le score par défaut de cette règle par le score de "shortcircuit_spam_score", définit le tflag "noautolearn", et définit la priorité à -200. Autrement dit, équivalent à : 
shortcircuit TEST on
priority TEST -200
score TEST 100
tflags TEST noautolearn
ham
Court-circuite la règle en utilisant un ensemble de valeurs par défaut ; remplace le score par défaut de cette règle par le score de "shortcircuit_ham_score", définit les tflags "noautolearn" et "nice", et définit la priorité à -200. Autrement dit, équivalent à : 
shortcircuit TEST on
priority TEST -200
score TEST -100
tflags TEST noautolearn nice
shortcircuit_spam_score n.nn (par défaut : 100)
Lorsque le court-circuitage est utilisé sur une règle, et que le type de classification de court-circuitage est défini sur "spam", cette valeur doit être appliquée à la place du score par défaut pour cette règle.
shortcircuit_ham_score n.nn (par défaut : -100)
Lorsque le court-circuitage est utilisé sur une règle, et que le type de classification de court-circuitage est défini sur "ham", cette valeur doit être appliquée à la place du score par défaut pour cette règle.
shortcircuit_min_ham_score n.nn (par défaut : undef)
Lorsque shortcircuit_min_ham_score est défini, SpamAssassin arrête le traitement lorsque le score total sera inférieur à cette valeur.
shortcircuit_max_spam_score n.nn (par défaut : undef)
Lorsque shortcircuit_max_spam_score est défini, SpamAssassin arrête le traitement lorsque le score total sera supérieur à cette valeur.

TAGS

Les balises suivantes sont ajoutées à l'ensemble disponible pour une utilisation dans les rapports, les en-têtes, etc. :

_SC_              statut de court-circuitage (classification et nom de la règle)
_SCRULE_          nom de la règle ayant provoqué le court-circuitage 
_SCTYPE_          classification du court-circuitage ("spam", "ham", "default", "none")
