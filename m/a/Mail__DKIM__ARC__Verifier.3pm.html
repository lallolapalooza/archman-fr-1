NAME

Mail::DKIM::ARC::Verifier - vérifie un message ARC-Sealed

VERSION

version 1.20240923

SYNOPSIS

use Mail::DKIM::ARC::Verifier;
# créer un objet vérificateur
my $arc = Mail::DKIM::ARC::Verifier->new();
# lire un message d'un fichier
$arc->load(*STDIN);
# ou lire un message et le passer au vérificateur de manière incrémentielle
while (<STDIN>)
{
    # supprimer les fins de ligne locales
    chomp;
    s/\015$//;
    # utiliser les fins de ligne SMTP
    $arc->PRINT("$_\015\012");
}
$arc->CLOSE;
# quel est le résultat de la vérification ?
my $result = $arc->result;
# imprimer les résultats pour toutes les signatures de message et les sceaux dans le message
foreach my $signature ($arc->signatures)
{
    print $signature->prefix() . ' v=' . $signature->instance .
                                   ' ' . $signature->result_detail . "\n";
}
# exemple de sortie. Notez que seule la dernière signature-arc-message doit correspondre, car d'autres étapes peuvent avoir modifié la signature. Ce qui importe, c'est que tous les sceaux ARC soient valides et que la signature-arc-message la plus récente soit valide.

DESCRIPTION

L'objet vérificateur permet de scanner un message électronique pour trouver des sceaux ARC et leurs signatures associées afin de les vérifier. Le vérificateur suit l'état du message lors de sa lecture en mémoire. Lorsque le message a été complètement lu, les signatures sont vérifiées et les résultats de la vérification sont accessibles.

Pour utiliser le vérificateur, créez d'abord l'objet vérificateur. Ensuite, commencez à "alimenter" le message à vérifier. Une fois toutes les _en-têtes_ lues, le vérificateur :

1. vérifie si des signatures ARC-message ont été trouvées
2. interroge les clés publiques nécessaires pour vérifier les signatures
3. établit les algorithmes et objets de canonicalisation appropriés
4. canonicalise les en-têtes et calcule le hash des en-têtes

Ensuite, une fois que le _corps_ du message a été entièrement transmis au vérificateur, le hash du corps est calculé et les signatures sont vérifiées.

Les résultats de la vérification peuvent être vérifiés avec "result()" ou "signatures()".

Le résultat final est calculé selon l'algorithme décrit dans https://tools.ietf.org/html/draft-ietf-dmarc-arc-protocol-06 - si TOUS les sceaux ARC sont valides et que la signature-arc-message la plus récente est valide, alors le sceau est intouché.

CONSTRUCTEUR

new()

Crée un objet vérificateur orienté objet.

my $arc = Mail::DKIM::ARC::Verifier->new();
my $arc = Mail::DKIM::ARC::Verifier->new(%options);

Les seules options supportées pour le moment sont :

AS_Canonicalization
si spécifié, le message canonisé du sceau ARC-Seal est écrit dans la référence de chaîne ou le fichier.
AMA_Canonicalization
si spécifié, le message canonisé de la signature-arc-message est écrit dans la référence de chaîne ou le fichier.
Strict
si vrai, rejette les signatures SHA1 et les clés publiques de moins de 1024 bits.

MÉTHODES

PRINT()

Transmet une partie du message au vérificateur.

$arc->PRINT("une ligne du message\015\012");
$arc->PRINT('plus de');
$arc->PRINT(" le message\015\012au revoir\015\012");

Transmet le contenu du message à vérifier au vérificateur. L'API est conçue ainsi pour que le message complet ne soit pas nécessaire à charger en une seule fois.

Note : bien que la méthode PRINT() attende que vous utilisiez les caractères de fin de ligne SMTP, vous ne devez pas utiliser la technique de "dot-stuffing" décrite dans le RFC 2821 section 4.5.2. vous ne devez pas non plus utiliser une séquence de pour terminer le message.

CLOSE()

Appelez cette fonction lorsque vous avez fini de transmettre le message.

$arc->CLOSE;

Cette méthode termine le processus de canonicalisation, calcule un hash et vérifie la signature.

load()

Charge le message complet à partir d'un fichier de lecture.

$arc->load($file_handle);

Lit un message complet à partir du fichier désigné, le transmettant au vérificateur. Le message doit utiliser des fins de ligne (identique au protocole SMTP).

message_originator()

Accès à l'en-tête "From".

my $address = $arc->message_originator;

Retourne l'"adresse d'origine" trouvée dans le message, en tant qu'objet Mail::Address. Il s'agit généralement du (premier) nom et de l'adresse e-mail dans l'en-tête From : . S'il n'y a pas d'en-tête From, un objet Mail::Address vide est retourné.

Pour obtenir uniquement l'adresse e-mail, faites :

my $email = $arc->message_originator->address;

Voir aussi "message_sender()".

message_sender()

Accès à l'en-tête "From" ou "Sender".

my $address = $arc->message_sender;

Retourne l'"expéditeur" trouvé dans le message, en tant qu'objet Mail::Address. Il s'agit généralement du (premier) nom et de l'adresse e-mail dans l'en-tête Sender : . S'il n'y a pas d'en-tête Sender, il s'agit du (premier) nom et de l'adresse e-mail dans l'en-tête From : . Si aucun des deux en-têtes n'est présent, un objet Mail::Address vide est retourné.

Pour obtenir uniquement l'adresse e-mail, faites :

my $email = $arc->message_sender->address;

L'"expéditeur" est la boîte aux lettres de l'agent responsable de la transmission réelle du message. Par exemple, si une secrétaire envoyait un message pour une autre personne, l'"expéditeur" serait la secrétaire et l'"origine" serait la personne réelle.

result()

Accès au résultat de la vérification.

my $result = $arc->result;

Donne le résultat de la vérification. Les valeurs suivantes sont possibles :

pass
Retourné si une chaîne ARC valide a été trouvée, avec tous les sceaux ARC valides et la plus récente (indice le plus élevé) signature-arc-message valide.
fail
Retourné si un sceau ARC échoue, ou si la signature-arc-message échoue. Il s'agira également d'un échec en cas d'erreur temporaire DNS, ce qui est un défaut connu dans cette version de ARC::Verifier. Les versions futures peuvent rejeter ce message directement (4xx) et demander aux expéditeurs de réessayer plus tard pour éviter de créer une chaîne brisée. Il n'y a pas de "temperror" pour ARC, car cela n'a pas de sens de signer une chaîne avec temperror, et tous les spammeurs en utiliseraient un.
invalid
Retourné si un sceau ARC ne peut pas être vérifié en raison d'un problème dans la signature elle-même ou dans la clé publique. C'est-à-dire que la signature ne peut pas être traitée.
none
Retourné si aucun en-tête ARC n'a été trouvé.

result_detail()

Accès au résultat, plus les détails si disponibles.

my $detail = $arc->result_detail;

Le détail est construit en prenant le résultat (par exemple, "pass", "fail", "invalid" ou "none") et en ajoutant tous les détails fournis par le processus de vérification pour le sceau ARC le plus élevé entre parenthèses.

Les résultats suivants de la méthode result_detail() sont possibles :

pass
fail (bad RSA signature)
fail (OpenSSL error: ...)
fail (message has been altered)
fail (body has been altered)
invalid (bad instance)
invalid (invalid domain in d tag)
invalid (missing q tag)
invalid (missing d tag)
invalid (missing s tag)
invalid (unsupported version 0.1)
invalid (unsupported algorithm ...)
invalid (unsupported canonicalization ...)
invalid (unsupported query protocol ...)
invalid (signature is expired)
invalid (public key: not available)
invalid (public key: u

signatures()

Accédez à toutes les signatures de ce message.

my @all_signatures = $arc->signatures;

Utilisez $signature->result ou $signature->result_detail pour accéder aux résultats de vérification de chaque signature.

Utilisez $signature->instance et $signature->prefix pour trouver l'instance et le nom d'en-tête de chaque signature.
