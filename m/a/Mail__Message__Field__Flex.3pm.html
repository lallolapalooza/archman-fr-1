Mail::Message::Field::Flex - ligne d'un champ d'en-tête

HERITAGE

Mail::Message::Field::Flex

SYNOPSIS

DESCRIPTION

Ceci est l'implémentation flexible d'un champ : il peut facilement être étendu car il stocke ses données dans une hash et les constructeurs ("new") et initialiseur ("init") sont séparés. Cependant, vous devez en payer le prix en performance. Mail::Message::Field::Fast est plus rapide (comme son nom l'indique).

$class->new($line | ($name, ($body|$object|\@objects), [@attributes], [\%options|\@options]))
Si vous êtes dans cette classe flexible de champs d'en-tête, vous avez plus de fonctionnalités qu'avec Mail::Message::Field::Fast. Entre autres, vous pouvez spécifier des options lors de la création. Les arguments possibles sont :
  • new $line

    Passe une $line telle qu'elle pourrait être trouvée dans un fichier : une ligne (éventuellement décomposée) se terminant par un nouveau ligne.

  • new $name, ($body|$object|\@objects), [@attributes], [\%options|\@options]

    Un ensemble de valeurs formant la ligne.

Pour distinguer les différents paramètres, vous devrez spécifier les @options comme une liste de paires d'options, ou une HASH de %options. Les @attributes sont une liste plate de paires clé-valeur. Le $body est spécifié comme une chaîne, un $object ou un ARRAY de @objects. Voir Mail::Message::Field. Améliore la base, voir "Constructeurs" dans Mail::Message::Field

-Option    --Défini dans     --Valeur par défaut

 log         Mail::Reporter   'WARNINGS'

attributes => \@attributes|\%attributes
Un ARRAY contenant des paires clé-valeur représentant @attributes, ou une référence à une HASH avec ces paires. C'est une notation alternative pour spécifier @attributes directement comme arguments de méthode.

Une liste préformatée d'attributs.

NAME

Mail::Message::Field::Flex - flexible message field handling

INHERITANCE

Mail::Message::Field::Flex
ISA Mail::Message::Field

SYNOPSIS

    use Mail::Message::Field::Flex;

    my $field = Mail::Message::Field::Flex->new('Subject', 'A new subject');
    print $field->text;

    my $field2 = Mail::Message::Field::Flex->new(
        'Content-Type', 'text/plain',
        'charset' => 'US-ASCII',
    );

DESCRIPTION

This class is a subclass of Mail::Message::Field. It is the default implementation for message fields.

The main difference from the parent class is that the name of the field is not checked for compliance with RFC-822.

DIAGNOSTICS

Warning: Field content is not numerical: $content
The numeric value of a field is requested (for instance the "Lines" or "Content-Length" fields should be numerical), however the data contains weird characters. Cast by toInt()
Error: Field name too long (max $length), in '$name'
It is not specified in the RFCs how long a field name can be, but at least it should be a few characters shorter than the line wrap. Cast by fold()
Warning: Illegal character in field name $name
A new field is being created which does contain characters not permitted by the RFCs. Using this field in messages may break other e-mail clients or transfer agents, and therefore mutulate or extinguish your message. Cast by consume()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
