Mail::SPF::Result(3) Documentation Perl Contribuée par l'Utilisateur Mail::SPF::Result(3)

NOM

Mail::SPF::Result - Classe de résultat SPF

VERSION

version 3.20250505

SYNOPSIS

Pour l'utilisation générale des objets Mail::SPF::Result dans le code qui appelle Mail::SPF, voir Mail::SPF. Pour l'interface détaillée de Mail::SPF::Result et de ses dérivés, voir ci-dessous.

Lancer des résultats

package Mail::SPF::Foo;
use Error ':try';
use Mail::SPF::Result;
sub foo {
    if (...) {
        $server->throw_result('pass', $request)
    }
    else {
        $server->throw_result('permerror', $request, 'Invalid foo');
    }
}

Capturer des résultats

package Mail::SPF::Bar;
use Error ':try';
use Mail::SPF::Foo;
try {
    Mail::SPF::Foo->foo();
}
catch Mail::SPF::Result with {
    my ($result) = @_;
    ...
};

Utilisation des résultats

my $result_name     = $result->name;
my $result_code     = $result->code;
my $request         = $result->request;
my $local_exp       = $result->local_explanation;
my $authority_exp   = $result->authority_explanation
    if $result->can('authority_explanation');
my $spf_header      = $result->received_spf_header;

DESCRIPTION

Un objet de classe Mail::SPF::Result représente le résultat d'une requête SPF.

Il n'est généralement pas nécessaire de construire directement un objet de résultat SPF en utilisant le constructeur "new". Utilisez plutôt la méthode de classe "throw" pour signaler au code appelant qu'un résultat SPF définitif a été déterminé. Autrement dit, utilisez Mail::SPF::Result et ses dérivés comme des exceptions. Voir Error ou "eval" dans perlfunc pour savoir comment gérer les exceptions en Perl.

Constructeur

Le constructeur suivant est fourni :

new($serveur, $request): retourne Mail::SPF::Result
new($serveur, $request, $texte): retourne Mail::SPF::Result
Crée un nouvel objet de résultat SPF et lui associe les objets Mail::SPF::Server et Mail::SPF::Request donnés. Un texte de résultat optionnel peut être spécifié.

Méthodes de classe

Les méthodes de classe suivantes sont fournies :

throw($serveur, $request): lance Mail::SPF::Result
throw($serveur, $request, $texte): lance Mail::SPF::Result
Lance un nouvel objet de résultat SPF, lui associant les objets Mail::SPF::Server et Mail::SPF::Request donnés. Un texte de résultat optionnel peut être spécifié.

Note: N'écrivez pas de code invoquant "throw" sur des noms de classe de résultat littéraux car cela ignorerait toute classe de résultat dérivée fournie par les modules d'extension Mail::SPF. Appelez plutôt la méthode "throw_result" sur un objet Mail::SPF::Server.

name: retourne chaîne
Abstrait. Retourne le nom du résultat de la classe (ou de l'objet) du résultat. Pour les classes de la hiérarchie Mail::SPF::Result::*, cela correspond approximativement à la partie finale du nom de la classe. Par exemple, retourne "neutral-by-default" si invoqué sur Mail::SPF::Result::NeutralByDefault. Voir également la méthode "code". Cette méthode peut également être utilisée comme méthode d'instance.

Cette méthode doit être implémentée par les sous-classes de Mail::SPF::Result pour lesquelles le nom du résultat diffère du code du résultat.

class: retourne classe
class($nom): retourne classe
Mappe le nom de résultat donné à la classe Mail::SPF::Result::* correspondante, ou retourne la classe de base du résultat (la classe sur laquelle elle est invoquée) si aucun nom de résultat n'est donné. Si un nom de résultat inconnu est spécifié, retourne undef.
isa_by_name($nom): retourne booléen
Si la classe (ou l'objet) sur laquelle cette méthode est invoquée représente le nom de résultat donné (ou un nom dérivé), retourne true. Sinon, retourne false. Cette méthode peut également être utilisée comme méthode d'instance.

Par exemple, "Mail::SPF::Result::NeutralByDefault->isa_by_name('neutral')" retourne true.

code: retourne chaîne
Abstrait. Retourne le code de résultat SPF de base ("pass", "fail", "softfail", "neutral", "none", "error", "permerror", "temperror") de la classe de résultat sur laquelle elle est invoquée. Tous les codes de résultat valides sont également des noms de résultat valides, mais l'inverse n'est pas vrai. Cette méthode peut également être utilisée comme méthode d'instance.

Cette méthode est abstraite et doit être implémentée par les sous-classes de Mail::SPF::Result.

is_code($code): retourne booléen
Si la classe (ou l'objet) sur laquelle cette méthode est invoquée représente le code de résultat donné, retourne true. Sinon, retourne false. Cette méthode peut également être utilisée comme méthode d'instance.

Note: La méthode "isa_by_name" fournit un superset de la fonctionnalité de cette méthode.

received_spf_header_name: retourne chaîne
Retourne 'Received-SPF' comme nom de champ pour les champs d'en-tête "Received-SPF". Cette méthode doit être surchargée par les modules d'extension Mail::SPF qui fournissent des fonctionnalités non standard (telles que la politique locale) avec la capacité de diluer la pureté des résultats SPF, afin de ne pas tromper les utilisateurs du champ d'en-tête en lui faisant croire qu'il s'agit d'une indication d'un résultat SPF naturel.

Méthodes d'instance

Les méthodes d'instance suivantes sont fournies :

throw: lance Mail::SPF::Result
throw($serveur, $request): lance Mail::SPF::Result
throw($serveur, $request, $texte): lance Mail::SPF::Result
Relance un objet de résultat SPF existant. Si les objets Mail::SPF::Server et Mail::SPF::Request sont spécifiés, il les associe à l'objet de résultat, remplaçant les objets serveur et requête précédents. Si un texte de résultat est également spécifié, il remplace le texte de résultat précédent.
server: retourne Mail::SPF::Server
Retourne l'objet serveur Mail::SPF qui a produit le résultat en question.
request: retourne Mail::SPF::Request
Retourne la requête SPF qui a conduit au résultat en question.
text: retourne chaîne
Retourne le message texte de l'objet de résultat.
