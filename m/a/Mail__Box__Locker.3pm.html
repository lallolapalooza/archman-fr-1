NAME

Mail::Box::Locker - gérer le verrouillage des fichiers de mail

INHERITANCE

Mail::Box::Locker
  est un Mail::Reporter
Mail::Box::Locker est étendu par
  Mail::Box::Locker::DotLock
  Mail::Box::Locker::FcntlLock
  Mail::Box::Locker::Flock
  Mail::Box::Locker::Multi
  Mail::Box::Locker::Mutt
  Mail::Box::Locker::NFS
  Mail::Box::Locker::POSIX

SYNOPSIS

use Mail::Box::Locker;
my $locker = new Mail::Box::Locker(folder => $folder);
$locker->lock;
$locker->isLocked;
$locker->hasLock;
$locker->unlock;
use Mail::Box;
my $folder = Mail::Box->new(lock_method => 'DOTLOCK');
print $folder->locker->type;

DESCRIPTION

Chaque objet Mail::Box crée son propre objet "Mail::Box::Locker" qui gérera le verrouillage des fichiers de mail. Vous pouvez accéder directement à l'objet depuis l'objet dossier, comme montré dans les exemples ci-dessous.

Constructeurs

Étend "Constructeurs" dans Mail::Reporter.

$class->new(%options)
Crée un nouveau verrou. Vous pouvez le faire directement. Cependant, dans la plupart des cas, le verrou ne sera pas instancié séparément, mais sera le deuxième objet dans une construction multithread avec un objet Mail::Box.

Généralement, le programme client spécifie le comportement de verrouillage via les options fournies à l'objet dossier. Étend la base, voir "Constructeurs" dans Mail::Reporter.

-Option --Defini dans     --Défaut
 expires                   1 heure
 file                      undef
 folder                    <C<undef>>
 log      Mail::Reporter   'WARNINGS'
 method                    'DOTLOCK'
 timeout                   10
 trace    Mail::Reporter   'WARNINGS'
expires => $secondes
Combien de temps un verrou peut-il durer ? Si un programme différent laisse un verrou expiré, il sera supprimé automatiquement après le nombre de secondes spécifié.
file => $fichier
Nom du fichier $fichier à verrouiller. Par défaut, le nom du dossier est utilisé.
folder => $folder
Quel est le dossier à verrouiller, un objet Mail::Box.
log => LEVEL
method => $nom|CLASSE|\@noms
Quel est le type de verrou, spécifié comme l'un des jetons suivants comme $nom. Vous pouvez également spécifier un nom de classe ou plusieurs @noms. Dans le cas de plusieurs @noms, un gestionnaire 'multi' sera initié avec tous les @noms spécifiés.

Les noms de méthode de verrouillage pris en charge sont (en minuscules également acceptés).

'DOTLOCK'
Le gestionnaire de dossier crée un fichier indiquant qu'il est en cours d'utilisation. Cela peut être problématique, car tous les programmes de messagerie ne s'accordent pas sur le nom du fichier à créer.

Dans différents types de dossiers, le fichier de verrouillage diffère. Voir la documentation de chaque dossier, qui décrit la stratégie de verrouillage et les options spéciales pour modifier le comportement par défaut.

'FLOCK'
Pour certains gestionnaires de dossiers, le verrouillage est basé sur un mécanisme de verrouillage de fichier fourni par le système d'exploitation. Ne fonctionne pas sur tous les systèmes, tels que les systèmes de fichiers réseau, et ne fonctionne pas non plus sur les dossiers basés sur des répertoires (Mail::Box::Dir et dérivés).
'FCNTLLOCK'
Verrouillage POSIX via File::FcntlLock, qui fonctionne sur plus de plateformes. Cependant, ce module nécessite un compilateur C pour être installé.
'POSIX'
Utiliser le verrouillage POSIX standard fcntl.
'MULTI'
Utiliser toutes les méthodes de verrouillage disponibles en même temps, afin d'augmenter la probabilité que le dossier ne soit pas modifié par d'autres programmes utilisant une méthode de verrouillage non spécifiée. Lorsqu'une des méthodes de verrouillage empêche l'accès, le verrouillage échoue.
'MUTT'
Utiliser le programme externe 'mutt_dotlock' pour verrouiller et déverrouiller.
'NFS'
Un type de mécanisme de verrouillage 'dotlock' adapté pour fonctionner sur NFS. Une précaution supplémentaire est requise, car un 'open O_EXCL' sur NFS n'est pas une action atomique.
'NONE'
Utiliser le verrouillage sous forme nulle.

Une autre option est de créer votre propre classe dérivée de "Mail::Box::Locker", qui implémente la méthode de verrouillage souhaitée. (Pensez à la proposer dans le cadre du module public Mail::Box !) Créez une instance de cette classe avec ce paramètre :

my $locker = Mail::Box::Locker::MyOwn->new;
$folder->open(locker => $locker);
timeout => $secondes|'NOTIMEOUT'
Combien de temps faut-il attendre pour obtenir le verrou. La requête de verrouillage échouera lorsque le nombre de secondes spécifié sera atteint. Si 'NOTIMEOUT' est spécifié, le module attendra jusqu'à ce que le verrou puisse être acquis.

Est-il possible de limiter le temps d'attente en fonction de la plateforme et de la méthode de verrouillage ? Par exemple, la méthode 'dotlock' sous Windows attend toujours jusqu'à ce que le verrou soit obtenu.

Verrouillage

$obj->hasLock()
Vérifie si le dossier possède le verrou.
$obj->isLocked()
Teste si le dossier est verrouillé par ce programme ou par un autre.
$obj->lock($folder)
Obtient un verrou sur un dossier. Retournera "false" si le verrouillage échoue.
$obj->unlock()
Déverrouille un dossier.
