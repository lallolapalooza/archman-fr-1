NOM

Mail::Message::Body::Multipart - corps d'un message avec annexes

HÉRITAGE

Mail::Message::Body::Multipart
  est un Mail::Message::Body
  est un Mail::Reporter

SYNOPSIS

Voir Mail::Message::Body
si($body->isMultipart) {
   mon @attachments = $body->parts;
   mon $attachment3 = $body->part(2);
   mon $before      = $body->preamble;
   mon $after       = $body->epilogue;
   $body->part(1)->delete;
}

DESCRIPTION

Le contenu (corps) d'un message peut être stocké de différentes manières. Sur cette page de manuel, la fonctionnalité supplémentaire dont vous disposez lorsqu'un message contient des annexes (parties) est décrite.

Le nombre d'alternatives multipart est en augmentation. Une liste complète est maintenue par IANA af

  • multipart/mixed
  • multipart/alternative
  • multipart/related
  • multipart/report, RFC6522
  • multipart/signed, RFC1847
  • multipart/encrypted
  • multipart/multilingual, RFC8255 (non utilisé)

Le texte qui est inclus dans le corps principal après la dernière séparation. Ceci est généralement vide et sans signification.

Fournit un objet $body ou du texte brut $text (qui sera automatiquement converti en un corps de type text/plain).

file => FILENAME|FILEHANDLE|IOHANDLE
filename => FILENAME

parts => [$message, $body, ...]
Définit une liste initiale de parties dans ce corps. Il peut s'agir d'objets $message complets, ou d'objets $body qui sont convertis en messages avant utilisation. Chaque message est converti en un objet Mail::Message::Part.

Les objets MIME::Entity et Mail::Internet sont acceptables dans la liste, car ils peuvent être convertis en objets Mail::Message::Part. Les valeurs "undef" sont ignorées silencieusement.

preamble => $body|$text
Le texte qui est inclus dans le corps avant la première partie. Il est courant d'inclure un texte pour avertir l'utilisateur que le message est multipart. Cependant, cela était utile autrefois : la plupart des agents de messagerie sont très capables de prévenir l'utilisateur eux-mêmes.

Fournit un objet $body ou du texte brut $text (qui sera automatiquement converti en un corps de type text/plain).

trace => LEVEL
transfer_encoding => STRING|FIELD

» exemple:

mon $intro = Mail::Message::Body->new(data => ['part one']);
mon $pgp   = Mail::Message::Body->new(data => ['part three']);
mon $body  = Mail::Message::Body::Multipart->new(
  boundary => time . '--it-s-mine',
  preamble => "This is a multi-part message in MIME format.\n\n",
  parts    => [ $intro, $folder->message(3)->decoded, $pgp ],
);

$obj->foreachComponent(CODE)
Exécute le "CODE" pour chaque composant du message : le préambule, l'épilogue et chacune des parties.

Chaque composant est un corps et est passé comme deuxième argument au "CODE". Le premier argument est une référence à ce corps multi-parties. Le "CODE" renvoie un objet corps. Lorsque l'un des corps retournés diffère du corps qui a été passé, un nouveau corps multi-parties sera retourné. Les références aux corps non modifiés et aux corps modifiés seront incluses dans ce nouveau multipart.

» exemple :

my $checked = $multi->foreachComponent(sub {$_[1]->check});
$obj->foreachLine((CODE))
Il n'est PAS possible d'appeler un code pour chaque ligne d'un multipart, car cela endommagerait non seulement le corps de chaque partie du message, mais aussi les en-têtes et les séparateurs de parties. Améliore la base, voir "Construction d'un corps" dans Mail::Message::Body::Construct
$obj->stripSignature(%options)
Supprime toutes les parties qui contiennent des données généralement définies comme étant une signature. Le module MIME::Type fournit ces connaissances. Un nouveau multipart est renvoyé, contenant les parties restantes. Aucune %options n'est définie pour le moment, bien que certaines puissent être spécifiées, car cette méthode surcharge la méthode "stripSignature" pour les corps normaux. Améliore la base, voir "Construction d'un corps" dans Mail::Message::Body::Construct

$obj->part($index)
Retourne uniquement la partie avec l'$index spécifié. Vous pouvez utiliser une valeur négative ici, qui compte à partir de la fin de la liste. Les parties marquées pour suppression sont incluses dans le décompte.

» exemple :

$message->body->part(2)->print;
$body->part(1)->delete;
$obj->parts( [<'ALL'|'ACTIVE'|'DELETED'|'RECURSE'|$filter>] )
Retourne toutes les parties par défaut, ou lorsque "ALL" est spécifié. "ACTIVE" retourne les parties qui ne sont pas marquées pour suppression, par opposition à "DELETED". "RECURSE" descend dans tous les multi-parties imbriqués pour collecter toutes les parties.

Vous pouvez également spécifier une référence de code qui est appelée pour chaque partie imbriquée. Le premier argument sera la partie du message. Lorsque le code renvoie "vrai", la partie est incorporée dans la liste de retour.

» exemple :

print "Nombre de pièces jointes: ",
   scalar $message->body->parts('ACTIVE');
foreach my $part ($message->body->parts) {
   print "Type: ", $part->get('Content-Type');
}
$obj->preamble()
Retourne le préambule ; le texte avant la première partie du message (avant le premier véritable fichier joint). Le préambule est stocké dans un objet BODY, et son encodage est pris de l'en-tête multipart.

DIAGNOSTICS

Avertissement : Jeu de caractères $name inconnu
L'encodage ou le décodage d'un corps de message rencontre un jeu de caractères non compris par le module Encode de Perl. Généré par encode()
Avertissement : Content-Transfer-Encoding `$encoding' nécessite un jeu de caractères explicite, utilisé par défaut : utf-8
Généré par encode()
Erreur : Les données ne sont pas convertibles en message (type : $type)
Un objet qui n'est pas coercible en objet Mail::Message::Part a été passé à l'initialisation. Les données sont ignorées. Généré par new()
Avertissement : Aucun décodeur défini pour l'encodage de transfert $name.
Les données (corps du message) sont encodées d'une manière qui n'est pas actuellement comprise, par conséquent aucun décodage (ou ré-encodage) ne peut avoir lieu. Généré par encode()
Avertissement : Aucun encodeur défini pour l'encodage de transfert $name.
Les données (corps du message) ont été décodées, mais l'encodage requis est inconnu. Les données décodées sont retournées. Généré par encode()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où elle devrait l'être. Ce message signifie que d'autres classes apparentées implémentent cette méthode, mais que la classe en question ne le fait pas. Vous devriez probablement enquêter à ce sujet et probablement informer l'auteur du paquet. Généré par notImplemented()
Erreur : Critère inconnu $what pour sélectionner des parties.
Les choix valides pour la sélection de parties sont "ALL", "ACTIVE", "DELETED", "RECURSE" ou une référence de code. Cependant, un autre argument a été passé. Généré par parts()
Avertissement : Terminateur de ligne inconnu $eol ignoré
Généré par eol()
Erreur : Vous ne pouvez pas utiliser foreachLine sur un objet multipartite
foreachLine() doit être utilisé uniquement sur des corps de message décodés, car il tenterait de modifier également les en-têtes de partie et les séparateurs, ce qui est clairement inacceptable. Généré par foreachLine()
