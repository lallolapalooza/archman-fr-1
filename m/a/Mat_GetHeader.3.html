MAT_GETHEADER(3) Manuel des fonctions de bibliothèque MAT_GETHEADER(3)

NOM

Mat_GetHeader — Retourne l'en-tête d'un fichier MAT MATLAB étant donné une structure de fichier MAT.

SYNTAXE

#include <matio.h>

const char *
Mat_GetHeader(const mat_t *matfp);

DESCRIPTION

La fonction Mat_GetHeader() retourne l'en-tête du fichier MAT MATLAB donné par la structure du fichier MAT.

VOIR AUSSI

Mat_CreateVer(3), Mat_Open(3), Mat_GetFileAccessMode(3), Mat_GetFilename(3), Mat_GetVersion(3)
