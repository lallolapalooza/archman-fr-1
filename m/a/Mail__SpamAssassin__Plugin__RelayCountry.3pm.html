NOM

RelayCountry - ajoute des métadonnées de message indiquant le code pays de chaque relais

SYNTAXE

loadplugin     Mail::SpamAssassin::Plugin::RelayCountry

DESCRIPTION

Le plugin RelayCountry tente de déterminer les codes pays des domaines de chaque relais utilisé dans le chemin de livraison des messages et d'ajouter ces informations aux métadonnées du message.

Les en-têtes et balises de métadonnées suivants sont ajoutés :

X-Relay-Countries           _RELAYCOUNTRY_
  Tous les relais non fiables. Contient tous les relais à partir de la
  bordure des réseaux de confiance (trusted_networks). Cette méthode a été utilisée
  par défaut depuis les premières versions de SA.
X-Relay-Countries-External  _RELAYCOUNTRYEXT_
  Tous les relais externes. Contient tous les relais à partir de la
  bordure des réseaux internes (internal_networks). Peut être utile dans certains
  cas où trusted_networks/msa_networks s'étendent au-delà de la bordure
  interne et que ces derniers doivent également être vérifiés.
X-Relay-Countries-All       _RELAYCOUNTRYALL_
  Tous les relais possibles (internes + externes).
X-Relay-Countries-Auth      _RELAYCOUNTRYAUTH_
  Auth contiendra tous les relais à partir du premier relais qui a utilisé
  l'authentification. Par exemple, cela pourrait être utilisé pour vérifier des
  utilisateurs locaux piratés arrivant de pays inattendus. S'il n'y a pas de relais
  authentifiés, ce champ sera vide.

PREREQUIS

Ce plugin utilise Mail::SpamAssassin::GeoDB et nécessite un module pris en charge par celui-ci, par exemple MaxMind::DB::Reader (GeoIP2).
