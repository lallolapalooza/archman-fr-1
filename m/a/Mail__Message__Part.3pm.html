NAME

Mail::Message::Part - une partie d'un message, mais un message en soi

INHERITANCE

Mail::Message::Part
  est un Mail::Message
  est un Mail::Reporter

SYNOPSIS

my Mail::Message $message = ...;
if($message->isMultipart) {
   my Mail::Message::Part $part;
   foreach $part ($message->body->parts) {
      $part->print(\*OUT);
      my $attached_head = $part->head;
      my $attached_body = $part->body;      # encodé tel quel
      my $attached_body = $part->decoded;   # transfer-encoding retiré
   }
}

DESCRIPTION

Un objet "Mail::Message::Part" contient un message qui est inclus dans le corps d'un autre message. Par exemple, les pièces jointes sont des parties.

Le MAIL::MESSAGE EST LE PREMIER. Une partie est un message spécial : elle a une référence à son message parent, et n'est généralement pas sous-classée dans des variantes spécifiques de boîtes aux lettres.

DIAGNOSTICS

Erreur : Impossible d'inclure la source d'un message de transfert comme $include.
La valeur alternative inconnue pour le mode d'inclusion (forward(include)). Les valeurs valides sont "NO", "INLINE", "ATTACH" et "ENCAPSULATE". Causé par forward()
Erreur : Impossible d'inclure la source d'un message de réponse comme $include.
Le mode d'inclusion (include) de la méthode reply() a une valeur inconnue. Les valeurs valides sont "NO", "INLINE" et "ATTACH". Causé par reply()
Erreur : La méthode bounce() nécessite To, Cc ou Bcc.
La méthode bounce() renvoie un message reçu à quelqu'un d'autre sans modifications ; sa nouvelle destination doit être spécifiée. Si vous ne souhaitez pas spécifier de destination, vous recherchez probablement la méthode reply(). Pour modifier le contenu, utilisez la méthode forward(). Causé par bounce()
Erreur : La méthode forwardAttach() nécessite un prélude.
Causé par forwardAttach()
Erreur : La méthode forwardEncapsulate() nécessite un prélude.
Causé par forwardEncapsulate()
Erreur : Impossible de créer le destinataire d'un message de transfert.
Si un message de transfert est créé, un destinataire doit être spécifié. Causé par forward()
Erreur : Aucun Mailer par défaut trouvé pour envoyer le message.
Le mécanisme d'envoi du message send() n'avait pas suffisamment d'informations pour trouver automatiquement un agent d'envoi. Spécifiez explicitement un Mailer en utilisant l'option "via". Causé par send()
Erreur : Aucune règle de reconstruction $name définie.
Causé par rebuild()
Erreur : Seuls les messages créés avec build() par Mail::Message peuvent être construits ; ils ne sont pas encore dans un dossier.
Vous pourriez vouloir construire un message pour le stocker dans une sorte de dossier, mais cela doit se faire en deux étapes. Tout d'abord, créez un message Mail::Message normal, puis ajoutez-y
