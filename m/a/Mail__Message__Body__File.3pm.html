NAME

Mail::Message::Body::File - corps d'un message temporairement stocké dans un fichier

INHERITANCE

Mail::Message::Body::File
  est un Mail::Message::Body
  est un Mail::Reporter

SYNOPSIS

Voir Mail::Message::Body

DESCRIPTION

Le corps (contenu) d'un message peut être stocké de différentes manières. Cette documentation décrit les fonctionnalités supplémentaires disponibles lorsqu'un message est stocké dans un fichier.

Stocker un message entier sous forme de fichier est utile lorsque le corps est volumineux. Bien que l'accès via un fichier soit lent, cela économise beaucoup de mémoire.

DIAGNOSTICS

Erreur: Impossible d'écrire dans le fichier de corps temporaire $filename : $!
Le corps du message doit être stocké dans un fichier temporaire (probablement parce qu'il s'agit d'un corps volumineux), mais pour la raison indiquée, ce fichier ne peut pas être créé. Lancé par new()
Avertissement : Jeu de caractères $name inconnu
L'encodage ou le décodage d'un corps de message rencontre un jeu de caractères qui n'est pas compris par le module Encode de Perl. Lancé par encode()
Avertissement : Content-Transfer-Encoding `$encoding' nécessite un jeu de caractères explicite, par défaut utf-8
Lancé par encode()
Avertissement : Aucun décodeur défini pour le codage de transfert $name.
Les données (corps du message) sont codées d'une manière qui n'est pas actuellement comprise, par conséquent aucun décodage (ou recodage) ne peut avoir lieu. Lancé par encode()
Avertissement : Aucun encodeur défini pour le codage de transfert $name.
Les données (corps du message) ont été décodées, mais l'encodage requis est inconnu. Les données décodées sont retournées. Lancé par encode()
Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où il le devrait. Ce message signifie que certaines autres classes liées implémentent cette méthode, mais que la classe en question ne le fait pas. Vous devriez probablement enquêter à ce sujet et probablement en informer l'auteur du paquet. Lancé par notImplemented()
Erreur : Impossible de lire le fichier $filename pour le fichier de corps du message : $!
Un objet Mail::Message::Body::File doit être créé à partir d'un fichier nommé, mais il est impossible de lire ce fichier pour récupérer les lignes qu'il contient. Par conséquent, aucune copie dans un fichier temporaire ne peut être effectuée. Lancé par new()
Avertissement : Terminant de ligne inconnu $eol ignoré
Lancé par eol()
