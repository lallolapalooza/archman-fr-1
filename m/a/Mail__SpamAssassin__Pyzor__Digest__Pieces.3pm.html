NOM

Mail::SpamAssassin::Pyzor::Digest::Pieces - Module de logique backend Pyzor

DESCRIPTION

Ce module héberge la logique backend pour Mail::SpamAssassin::Pyzor::Digest.

Il réimplémente la logique trouvée dans le module digest.py de pyzor (https://github.com/SpamExperts/pyzor/blob/master/pyzor/digest.py).

FONCTIONS

$chaîne_ar = digest_payloads( $EMAIL_MIME )

Ceci imite la méthode d'objet correspondante dans digest.py. Il renvoie une référence à un tableau de chaînes. Chaque chaîne peut être une chaîne d'octets ou une chaîne de caractères (par exemple, décodée en UTF-8).

NB : RFC 2822 stipule que les corps de messages doivent utiliser des retours à la ligne CRLF, et non des LF simples (ni des CR simples). Nous allons donc convertir tous les CR simples dans un corps de message en quoted-printable en CRLF. Python, cependant, ne fait pas cela, donc la sortie de notre implémentation de digest_payloads() diverge de celle de l'original Python. Cela ne fait finalement aucune différence puisque les espaces de fin de ligne sont supprimés quoi qu'il arrive, mais il est nécessaire d'en tenir compte lors de la comparaison de la sortie de notre implémentation avec la sortie Python.

normaliser( $CHAÎNE )

Ceci imite la méthode d'objet correspondante dans digest.py. Elle modifie $CHAÎNE en place.

Comme avec l'implémentation d'origine, si $CHAÎNE contient des caractères Unicode (décodés), ces caractères seront analysés en conséquence. Ainsi :

$str = "123\xc2\xa0";   # [ c2 a0 ] == \u00a0, espace insécable
normalize($str);

Ce qui précède laissera $str inchangé, mais ceci :

utf8::decode($str);
normalize($str);

... supprimera les deux derniers octets de $str.

$yn = doit_gérer_ligne( $CHAÎNE )

Ceci imite la méthode d'objet correspondante dans digest.py. Elle renvoie un booléen.

$sr = assembler_lignes( \@LIGNES )

Ceci assemble un tampon de chaîne à partir de @LIGNES. La chaîne est le tampon d'octets qui sera haché pour produire la somme de contrôle du message.

Chaque membre de @LIGNES est censé être une chaîne d'octets, pas une chaîne de caractères.

($principal, $sous, $encodage, $valeur_de_vérification) = analyser_type_contenu( $TYPE_CONTENU )

@lignes = découper_lignes( $TEXTE )

Imite "str.splitlines()". (cf. "pydoc str")

Renvoie une liste simple en contexte de liste. Renvoie le nombre d'éléments à retourner en contexte scalaire.
