NOM

Mail::SpamAssassin::Client - Client pour le protocole spamd

SYNOPIS

my $client = Mail::SpamAssassin::Client->new({
                              port => 783,
                              host => 'localhost',
                              username => 'someuser'});
ou
my $client = Mail::SpamAssassin::Client->new({
                              socketpath => '/path/to/socket',
                              username => 'someuser'});
Prend éventuellement en charge le délai d'attente (timeout), qui est appliqué à IO::Socket pour la
connexion initiale. S'il n'est pas fourni, il est de 30 secondes par défaut.
if ($client->ping()) {
  print "Ping is ok\n";
}
my $result = $client->process($testmsg);
if ($result->{isspam} eq 'True') {
  do something with spam message here
}

DESCRIPTION

Mail::SpamAssassin::Client est un module qui fournit une implémentation perl du protocole spamd.

MÉTHODES PUBLIQUES

new

public class (Mail::SpamAssassin::Client) new (\% $args)

Description : Cette méthode crée un nouvel objet Mail::SpamAssassin::Client.

process

public instance (\%) process (String $msg)

Description : Cette méthode appelle le serveur spamd avec la commande PROCESS.

La valeur de retour est une référence de hachage contenant plusieurs informations, si disponibles :

content_length

isspam

score

threshold

message

report

spam_report

public instance (\%) spam_report (String $msg)

Description : La méthode implémente l'appel report.

Voir la méthode process pour la valeur de retour.

spam_report_ifspam

public instance (\%) spam_report_ifspam (String $msg)

Description : La méthode implémente l'appel report_ifspam. Un rapport ne sera retourné que si le message est un spam.

Voir la méthode process pour la valeur de retour.

check

public instance (\%) check (String $msg)

Description : La méthode implémente l'appel check.

Voir la méthode process pour la valeur de retour.

headers

public instance (\%) headers (String $msg)

Description : Cette méthode implémente l'appel headers.

Voir la méthode process pour la valeur de retour.

learn

public instance (Boolean) learn (String $msg, Integer $learntype)

Description : Cette méthode implémente l'appel learn. $learntype doit être un entier, 0 pour spam, 1 pour ham et 2 pour oublier. La valeur de retour est un booléen indiquant si le message a été appris ou non.

Une valeur de retour undef indique qu'il y a eu une erreur et vous devriez vérifier les valeurs resp_code/resp_msg pour déterminer quelle était l'erreur.

report

public instance (Boolean) report (String $msg)

Description : Cette méthode fournit l'interface report à spamd.

revoke

public instance (Boolean) revoke (String $msg)

Description : Cette méthode fournit l'interface revoke à spamd.

ping

public instance (Boolean) ping ()

Description : Cette méthode effectue un ping du serveur et retourne 0 ou 1 selon que le serveur a répondu correctement.

MÉTHODES PRIVÉES

_create_connection

private instance (IO::Socket) _create_connection ()

Description : Cette méthode établit une connexion IO::Socket appropriée en fonction des arguments utilisés lors de la création de l'objet client.

En cas d'échec, elle définit un code d'erreur interne et retourne undef.

_parse_response_line

private instance (@) _parse_response_line (String $line)

Description : Cette méthode analyse la ligne/l'en-tête de réponse initiale du serveur et retourne ses parties.

Nous l'avons en tant que méthode séparée au cas où nous déciderions un jour de faire des choses plus élaborées avec la ligne de réponse.

_clear_errors

private instance () _clear_errors ()

Description : Cette méthode efface toutes les erreurs actuelles.

_filter

private instance (\%) _filter (String $msg, String $command)

Description : Effectue l'appel réel au serveur spamd pour les différentes méthodes de filtrage (c'est-à-dire PROCESS, CHECK, HEADERS, etc.). La commande passée est envoyée au serveur spamd.

La valeur de retour est une référence de hachage contenant plusieurs informations, si disponibles :

content_length

isspam

score

threshold

message (si disponible)

report (si disponible)
