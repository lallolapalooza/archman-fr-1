Mail::DKIM::PublicKey(3) Documentation Perl fournie par l'utilisateur Mail::DKIM::PublicKey(3)

NOM

Mail::DKIM::PublicKey - Représente une clé DKIM

VERSION

version 1.20240923

CONSTRUCTEUR

fetch() - récupère un enregistrement de clé publique depuis DNS

my $public_key = Mail::DKIM::PublicKey->fetch(
                    Protocol => 'dns',
                    Selector => 'brisbane',
                    Domain => 'example.com',
                  );

Si la clé publique est trouvée, un objet Mail::DKIM::PublicKey est retourné, représentant les informations trouvées dans DNS. Si la clé publique n'existe pas dans DNS, alors "undef" est retourné. Si une erreur DNS survient lors de la récupération de la clé, alors cette méthode appellera "die". Si la clé publique a été trouvée, mais n'est pas valide (par exemple, elle est "révoquée"), alors cette méthode appellera "die".

MÉTHODES

granularity() - obtient ou définit le champ de granularité (g=)

my $g = $public_key->granularity;
$public_key->granularity('*');

Granularité de la clé. La valeur doit correspondre à la partie locale du champ effectif "i=" de l'en-tête DKIM-Signature. La granularité est une valeur littérale, ou un motif avec un seul caractère joker '*' qui correspond à zéro ou plusieurs caractères.

Si aucune granularité n'est définie, alors la valeur par défaut, '*', sera retournée.
