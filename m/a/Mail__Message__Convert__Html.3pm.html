NOM

Mail::Message::Convert::Html - Formater des messages en HTML

HÉRITAGE

Mail::Message::Convert::Html
                              est un Mail::Message::Convert
                              est un Mail::Reporter

SYNOPIS

use Mail::Message::Convert::Html;
    my $Html = Mail::Message::Convert::Html->new;
    print $html->fieldToHtml($head);
    print $html->headToHtmlHead($head);
    print $html->headToHtmlTable($head);
    print $html->textToHtml($text);

DESCRIPTION

Le paquet contient divers traducteurs qui gèrent le HTML ou le XHTML sans l'aide de modules externes. Il existe d'autres modules liés au HTML qui nécessitent des paquets supplémentaires à installer.

Conversion

Étendu par Converting dans Mail::Message::Convert.

$obj->fieldContentsToHtml( $field, [$subject] )
Formate un champ d'en-tête en HTML. Lorsque la ligne d'en-tête contient généralement des adresses électroniques, la ligne est analysée et les adresses valides sont liées avec un lien "mailto:". Le champ $subject peut être spécifié pour l'inclure dans ce lien.
$obj->fieldToHtml( $field, [$subject] )
Reformate une ligne d'en-tête en HTML. Le nom du champ $field est imprimé en gras, suivi du contenu formaté, qui est produit par fieldContentsToHtml().
$obj->headToHtmlHead($head, $meta)
Traduit les lignes d'en-tête sélectionnées (champs) en un en-tête HTML. Chaque champ sélectionné aura sa propre ligne meta avec le même nom que la ligne. De plus, le champ "Subject" sera converti en "title", et le champ "From" sera utilisé comme auteur de "Author".

De plus, vous pouvez spécifier vos propres champs meta, qui remplaceront les champs d'en-tête. Les champs vides ne seront pas inclus. Lorsque un "title" est spécifié, il deviendra le titre HTML, sinon le champ "Subject" sera utilisé. Dans un contexte de liste, les lignes sont traitées séparément ; dans un contexte scalaire, le texte complet est renvoyé en une seule fois.

Si vous avez besoin d'ajouter des lignes à l'en-tête (par exemple, des lignes http-equiv), insérez les lignes avant le dernier élément de la liste renvoyée.

» exemple :

my @head = $html->headToHtmlHead(
                $head,
                description => 'This is a message',
                generator   => 'Mail::Box',
            );
            splice @head, -1, 0, '<meta http-equiv=...>';
            print @head;
$obj->headToHtmlTable( $head, [$table_params] )
Produit une table d'affichage des champs sélectionnés de l'en-tête. Les paramètres optionnels $table_params sont ajoutés comme paramètres à l'élément TABLE produit. Dans un contexte de liste, chaque ligne est renvoyée séparément ; dans un contexte scalaire, tout est renvoyé en une seule fois.
$obj->selectedFields($head)
Hérité, voir Converting dans Mail::Message::Convert
$obj->textToHtml($lines)
Traduit une ou plusieurs lignes de texte en HTML. Chaque ligne est traitée une par une, et seules des choses simples sont traduites. "textToHtml" peut convertir de grands textes de manière décentralisée. Dans un contexte scalaire, les résultats sont renvoyés en une seule fois.

DIAGNOSTICS

Erreur : Le paquet $package n'implémente pas $method.
Erreur fatale : le paquet spécifié (ou l'une de ses superclasses) n'implémente pas cette méthode là où il le devrait. Ce message signifie que certaines autres classes liées implémentent cette méthode, mais que la classe en question ne le fait pas. Vous devriez probablement enquêter sur cela et probablement signaler le problème à l'auteur du paquet. Causé par notImplemented()
