NOM

Mail::AuthenticationResults::Header::Base - Classe de base pour la modélisation des parties de l'en-tête Authentication Results

VERSION

version 2.20250709

DESCRIPTION

Ensemble de classes représentant les différentes parties et sous-parties des en-têtes Authentication Results.

  • Mail::AuthenticationResults::Header représente un ensemble complet d'en-têtes Authentication Results
  • Mail::AuthenticationResults::Header::AuthServID représente la partie AuthServID de l'ensemble
  • Mail::AuthenticationResults::Header::Comment représente un commentaire
  • Mail::AuthenticationResults::Header::Entry représente une entrée principale
  • Mail::AuthenticationResults::Header::Group représente un groupe de parties, typiquement comme un résultat de recherche
  • Mail::AuthenticationResults::Header::SubEntry représente une sous-entrée partie
  • Mail::AuthenticationResults::Header::Version représente une partie de version
