Mail::Header(3) Documentation Perl fournie par l'utilisateur Mail::Header(3)

NOM

Mail::Header - manipuler les en-têtes MIME

SYNOPSIS

use Mail::Header;

my $head = Mail::Header->new;
my $head = Mail::Header->new( \*STDIN );
my $head = Mail::Header->new( [<>], Modify => 0);

DESCRIPTION

Lire, écrire, créer et manipuler les en-têtes MIME, la partie principale de chaque message e-mail moderne, mais également utilisés dans d'autres protocoles comme HTTP. Les champs sont conservés dans des objets Mail::Field.

Soyez conscient que les champs d'en-tête ont chacun une partie nom, qui doit être traitée sans tenir compte de la casse, et une partie contenu, qui peut être repliée sur plusieurs lignes.

Mail::Header ne suit pas toujours strictement les RFC, n'aide pas avec les encodages de caractères. Il n'utilise pas de références faibles là où il le pourrait (car elles n'existaient pas lorsque le module a été écrit), ce qui coûte en performance et rend l'implémentation un peu plus compliquée. L'implémentation de Mail::Message::Head est beaucoup plus récente et donc meilleure.

MÉTHODES

Constructeurs

$obj->dup()
Crée un duplicata de l'objet courant.
$obj->new( [$source], [%options] )
Mail::Header->new( [$source], [%options] )
La variable $source peut être soit un descripteur de fichier (référence à un GLOB) soit une référence vers un tableau. Si elle est fournie, le nouvel objet sera initialisé avec les en-têtes soit à partir du tableau, soit lus à partir du descripteur de fichier.

Les variables %options sont une liste d'options fournies sous forme de paires clé-valeur, comme une table de hachage. Les options valides sont

-Option    --Défaut
 FoldLength  79
 MailFrom    'KEEP'
 Modify      false
FoldLength => ENTIER
La longueur de ligne par défaut à utiliser lors du repliage des lignes d'en-tête. Voir fold_length().
MailFrom => 'IGNORE'|'COERCE'|'KEEP'|'ERROR'
Voir la méthode mail_from().
Modify => BOOLÉEN
Si cette valeur est vraie alors les en-têtes seront reformatés, sinon le format des lignes d'en-tête restera inchangé.

Constructeurs "Fake"

Attention, les constructeurs suivants nécessitent un objet en-tête déjà créé, dont le contenu original sera détruit.

$obj->empty()
Vide un objet "Mail::Header" existant de toutes ses lignes.
$obj->extract(TABLEAU)
Extrait un en-tête du tableau donné dans un objet Mail::Header existant. "extract" modifiera ce tableau. Renvoie l'objet sur lequel la méthode a été appelée.
$obj->header( [TABLEAU] )
"header" effectue plusieurs opérations. D'abord, il extrait un en-tête du TABLEAU s'il est fourni. Ensuite, il re-formate l'en-tête (si le reformatage est autorisé), et enfin renvoie une référence vers un tableau qui contient l'en-tête sous une forme imprimable.
$obj->header_hashref( [HASH] )
Comme header(), mais il finira par définir les en-têtes à partir d'une référence de hachage, et il renverra les en-têtes sous forme de référence de hachage.

exemple :

$fields->{From} = 'Tobias Brox <tobix@cpan.org>';
$fields->{To}   = ['you@somewhere', 'me@localhost'];
$head->header_hashref($fields);
$obj->read($fh)
Lit un en-tête à partir du descripteur de fichier donné dans un objet Mail::Header existant.

Accesseurs

$obj->fold_length( [$tag], [$length] )
Définit la longueur de repliement par défaut pour toutes les étiquettes ou une seule. Sans arguments, la longueur de repliement par défaut est renvoyée. Avec deux arguments, il définit la longueur de repliement pour l'étiquette donnée et renvoie la valeur précédente. Si seule la variable $length est fournie, elle définit la longueur de repliement par défaut pour l'objet courant.

Dans la forme à deux arguments, "fold_length" peut être appelée comme méthode statique, définissant des longueurs de repliement par défaut pour les étiquettes qui seront utilisées par tous les objets "Mail::Header". Voir la méthode "fold" pour une description sur la façon dont "Mail::Header" utilise ces valeurs.

$obj->mail_from('IGNORE'|'COERCE'|'KEEP'|'ERROR')
Ceci spécifie quoi faire lorsqu'une ligne `From ' est rencontrée. Les valeurs valides sont "IGNORE" - ignorer et rejeter l'en-tête, "ERROR" - invoquer une erreur (appeler die), "COERCE" - renommer en Mail-From et "KEEP" - les conserver.
$obj->modify( [$value] )
Si $value est faux, alors "Mail::Header" n'effectuera aucun reformatage automatique des en-têtes, autre que de s'assurer que la ligne commence par les étiquettes données.

Traitement

$obj->add( $tag, $line [, $index] )
Ajoute une nouvelle ligne à l'en-tête. Si $tag est "undef", l'étiquette sera extraite du début de la ligne donnée. Si $index est fourni, la nouvelle ligne sera insérée dans l'en-tête à l'endroit donné, sinon la nouvelle ligne sera ajoutée à la fin de l'en-tête.
$obj->as_string()
Renvoie l'en-tête sous forme de chaîne unique.
$obj->cleanup()
Supprime toute ligne d'en-tête qui, autre que l'étiquette, ne contient que des espaces blancs.
$obj->combine( $tag [, $with] )
Combine toutes les occurrences de $tag en une seule. Les lignes seront jointes avec $with, ou un simple espace si non fourni. Le nouvel élément sera positionné dans l'en-tête où se trouvait la première occurrence, toutes les autres occurrences de $tag seront supprimées.
$obj->count($tag)
Renvoie le nombre de fois que l'étiquette donnée apparaît dans l'en-tête.
$obj->delete( $tag [, $index ] )
Supprime une étiquette de l'en-tête. Si un $index est donné, alors la N-ième occurrence de l'étiquette sera supprimée. Si aucun $index n'est donné, alors toutes les occurrences de l'étiquette seront supprimées.
$obj->fold( [$length] )
Replie l'en-tête. Si $length n'est pas fourni, alors "Mail::Header" utilise les règles suivantes pour déterminer la longueur de repliement d'une ligne.
$obj->get( $tag [, $index] )
Obtient le texte d'une ligne. Si un $index est donné, alors le texte de la N-ième occurrence sera renvoyé. S'il n'est pas donné, la valeur de retour dépend du contexte dans lequel "get" a été appelé. Dans un contexte de tableau, une liste de tout le texte de toutes les occurrences de $tag sera renvoyée. Dans un contexte scalaire, le texte de la première occurrence sera renvoyé.

Les lignes sont dépliées, mais toujours terminées par un retour à la ligne (voir "chomp")

$obj->print( [$fh] )
Imprime l'en-tête dans le descripteur de fichier donné, ou "STDOUT" si aucun descripteur de fichier n'est fourni.
$obj->replace( $tag, $line [, $index ] )
Remplace une ligne dans l'en-tête. Si $tag est "undef", l'étiquette sera extraite du début de la ligne donnée. Si $index est donné, la nouvelle ligne remplacera la N-ième occurrence de cette étiquette, sinon la première occurrence de l'étiquette est remplacée. Si l'étiquette n'apparaît pas dans l'en-tête, une nouvelle ligne sera ajoutée à l'en-tête.
$obj->tags()

NOM

Mail::Header

SYNOPIS

Mail::Header->new( $header )

DESCRIPTION

Retourne un tableau de toutes les étiquettes qui existent dans l'en-tête. Chaque étiquette n'apparaîtra qu'une seule fois dans la liste. L'ordre des étiquettes n'est pas spécifié.

MÉTHODES

Mail::Header->new( [$header] )

Crée un nouvel objet Mail::Header à partir d'un en-tête donné.

Mail::Header->tags()

Retourne un tableau de toutes les étiquettes qui existent dans l'en-tête. Chaque étiquette n'apparaîtra qu'une seule fois dans la liste. L'ordre des étiquettes n'est pas spécifié.

Mail::Header->unfold( [$tag] )

Déplie toutes les occurrences de l'étiquette donnée afin qu'elles ne s'étendent pas sur plusieurs lignes. Si $tag n'est pas donné, alors toutes les lignes sont dépliées.

Le processus de dépliage est incorrect mais (pour des raisons de compatibilité) ne sera pas réparé : un seul espace au début de la ligne doit être supprimé, pas tous.
