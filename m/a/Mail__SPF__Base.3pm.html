NOM

Mail::SPF::Base - Classe de base pour les classes Mail::SPF

VERSION

version 3.20250505

SYNOPSIS

use base 'Mail::SPF::Base';
sub new {
    my ($class, @options) = @_;
    my $self = $class->SUPER::new(@options);
    ...
    return $self;
}

DESCRIPTION

Mail::SPF::Base est une classe de base commune pour toutes les classes Mail::SPF.

Constructeur

Le constructeur suivant est fourni :

new(%options): retourne Mail::SPF::Base
Crée un nouvel objet de la classe sur laquelle le constructeur a été invoqué. Les options fournies sont stockées sous forme de paires clé/valeur dans le nouvel objet.

Le constructeur "new" peut également être appelé sur un objet, auquel cas l'objet est cloné. Toute option fournie remplace celles de l'ancien objet.

Il n'y a pas d'options communes définies dans Mail::SPF::Base.

Méthodes de classe

Les méthodes de classe suivantes sont fournies :

classe: retourne chaîne
Retourne le nom de la classe de la classe ou de l'objet sur lequel elle est invoquée.

Méthodes de classe

Les méthodes de classe suivantes sont fournies :

make_accessor($name, $readonly): retourne réf-code
Crée une méthode d'accès dans la classe sur laquelle elle est invoquée. L'accesseur porte le nom donné et accède au champ de l'objet du même nom. Si $readonly est vrai, l'accesseur est rendu en lecture seule.

Méthodes d'instance

Il n'y a pas de méthodes d'instance communes définies dans Mail::SPF::Base.
