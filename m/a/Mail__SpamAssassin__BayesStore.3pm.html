NOM

Mail::SpamAssassin::BayesStore - Module de stockage pour le classifieur bayésien par défaut

DESCRIPTION

Il s'agit de l'API publique pour les méthodes de stockage des classifieurs bayésiens. Toute implémentation de module de stockage pour le classifieur bayésien par défaut doit implémenter ces méthodes.

MÉTHODES

new
classe publique (Mail::SpamAssassin::BayesStore) new (Mail::SpamAssassin::Plugin::Bayes $bayes)

Description : Cette méthode crée une nouvelle instance de l'objet Mail::SpamAssassin::BayesStore. Vous devez lui passer un objet de type Mail::SpamAssassin::Plugin::Bayes, qui sera stocké pour une utilisation ultérieure dans le module.

DB_VERSION
instance publique (Valeur entière) DB_VERSION ()

Description : Cette méthode renvoie la version de base de données actuellement prise en charge par l'implémentation.

read_db_configs
instance publique () read_db_configs ()

Description : Cette méthode lit les variables de configuration nécessaires à partir de l'objet de configuration, puis appelle la méthode read_db_configs de Mail::SpamAssassin::Plugin::Bayes.

prefork_init
instance publique (Valeur booléenne) prefork_init ()

Description : Cette méthode est appelée dans le processus parent juste avant la division des processus enfants.

spamd_child_init
instance publique (Valeur booléenne) spamd_child_init ()

Description : Cette méthode est appelée dans un processus enfant après sa création.

tie_db_readonly
instance publique (Valeur booléenne) tie_db_readonly ()

Description : Cette méthode ouvre la base de données en lecture seule.

tie_db_writable
instance publique (Valeur booléenne) tie_db_writable ()

Description : Cette méthode ouvre la base de données en écriture.

Tout appelant de cette méthode doit s'assurer d'appeler untie_db() par la suite.

untie_db
instance publique () untie_db ()

Description : Cette méthode détache la base de données.

calculate_expire_delta
instance publique (%) calculate_expire_delta (Integer $newest_atime,
Integer $start,
Integer $max_expire_mult)

Description : Cette méthode effectue un calcul sur les données afin de déterminer le temps d'accès optimal pour l'expiration des jetons.

token_expiration
instance publique (Entier, Entier, Entier, Entier) token_expiration(\% $opts,
Integer $newest_atime,
Integer $newdelta)

Description : Cette méthode effectue l'expiration des jetons dans la base de données selon les valeurs transmises de $newest_atime et $newdelta spécifiées.

expire_old_tokens
instance publique (Valeur booléenne) expire_old_tokens (\% hashref)

Description : Cette méthode expire les anciens jetons de la base de données.

expire_old_tokens_trapped
instance publique (Valeur booléenne) expire_old_tokens_trapped (\% $opts)

Description : Cette méthode effectue l'expiration des jetons.

XXX Plus d'informations sur la méthode et le reste

sync_due
instance publique (Valeur booléenne) sync_due ()

Description : Cette méthode détermine si une synchronisation est nécessaire.

expiry_due
instance publique (Valeur booléenne) expiry_due ()

Description : Cette méthode détermine si une expiration est nécessaire.

seen_get
instance publique (Caractère) seen_get (String $msgid)

Description : Cette méthode récupère la valeur stockée, si elle existe, pour $msgid. La valeur renvoyée est la chaîne stockée ('s' pour spam et 'h' pour ham) ou undef si $msgid n'est pas trouvée.

seen_put
instance publique (Valeur booléenne) seen_put (String $msgid, Caractère $flag)

Description : Cette méthode enregistre $msgid comme le type donné par $flag. $flag est l'une des deux valeurs 's' pour spam et 'h' pour ham.

seen_delete
instance publique (Valeur booléenne) seen_delete (String $msgid)

Description : Cette méthode supprime $msgid de la base de données.

get_storage_variables
instance publique (@) get_storage_variables ()

Description : Cette méthode récupère les variables administratives utilisées par l'implémentation de stockage bayésien.

Les valeurs renvoyées dans le tableau sont dans l'ordre suivant :

0 : base du nombre de scans

1 : nombre de spams

2 : nombre de ham

3 : nombre de jetons dans la base de données

4 : dernier temps d'expiration

5 : plus ancien jeton dans la base de données

6 : valeur de version de la base de données

7 : dernière synchronisation du journal

8 : dernier delta d'acces

9 : dernier compteur d'expiration

10 : dernier temps d'acces d'un jeton dans la base de données

dump_db_toks
instance publique () dump_db_toks (String $template, String $regex, @ @vars)

Description : Cette méthode parcourt tous les jetons, calcule la probabilité de chaque jeton, puis imprime le résultat selon le modèle fourni.

set_last_expire
instance publique (Valeur booléenne) _set_last_expire (Integer $time)

Description : Cette méthode définit la dernière heure d'expiration.

get_running_expire_tok
instance publique (Temps) get_running_expire_tok ()

Description : Cette méthode détermine si une expiration est en cours et renvoie le temps de début de cette expiration.

set_running_expire_tok
instance publique (Temps) set_running_expire_tok ()

Description : Cette méthode définit l'heure d'expiration en cours à l'heure actuelle.

remove_running_expire_tok
instance publique (Valeur booléenne) remove_running_expire_tok ()

Description : Cette méthode supprime une heure d'expiration en cours qui avait été précédemment définie.

tok_get
instance publique (Entier, Entier, Temps) tok_get (String $token)

Description : Cette méthode récupère le jeton spécifié ($token) de la base de données et renvoie le compte de spam, le compte de ham et le temps d'accès récent.

tok_get_all
instance publique (\@) tok_get_all (@ @tokens)

Description : Cette méthode récupère les jetons spécifiés (@tokens) de la base de données et renvoie une référence de tableau de tableaux contenant le compte de spam, le compte de ham et le temps d'accès récent.

tok_count_change
instance publique (\@) tok_count_change (@ @tokens)

Description : Cette méthode modifie le nombre des jetons (@tokens) dans la base de données.

NOM DESCRIPTION MÉTHODES
tok_count_change
instance publique (Booléen) tok_count_change (Entier $spam_count,
Entier $ham_count,
Chaîne $token,
Temps $atime)

Description : Cette méthode prend un $spam_count et $ham_count et les ajoute à $token en mettant à jour également l'heure d'accès ($atime) du $token.

multi_tok_count_change
instance publique (Booléen) multi_tok_count_change (Entier $spam_count,
Entier $ham_count, \% $tokens, Chaîne $atime)

Description : Cette méthode prend un $spam_count et $ham_count et les ajoute à tous les jetons de la référence de hachage $tokens, en mettant également à jour l'heure d'accès ($atime) de chaque jeton.

nspam_nham_get
instance publique (Entier, Entier) nspam_nham_get ()

Description : Cette méthode récupère le nombre total de spams et le nombre total de ham actuellement stockés.

nspam_nham_change
instance publique (Booléen) nspam_nham_change (Entier $num_spam,
Entier $num_ham)

Description : Cette méthode met à jour le nombre de spams et le nombre de ham dans la base de données.

tok_touch
instance publique (Booléen) tok_touch (Chaîne $token,
Temps $atime)

Description : Cette méthode met à jour l'heure d'accès du jeton donné ($token).

tok_touch_all
instance publique (Booléen) tok_touch_all (\@ $tokens,
Temps $atime)

Description : Cette méthode effectue une mise à jour massive de la liste de jetons donnée $tokens, si l'heure d'accès existante du jeton est inférieure à $atime.

cleanup
instance publique (Booléen) cleanup ()

Description : Cette méthode effectue tout nettoyage nécessaire avant de passer à l'opération suivante.

get_magic_re
instance publique get_magic_re (Chaîne)

Description : Cette méthode renvoie une expression régulière qui indique un jeton magique.

sync
instance publique (Booléen) sync (\% $opts)

Description : Cette méthode effectue une synchronisation de la base de données.

perform_upgrade
instance publique (Booléen) perform_upgrade (\% $opts)

Description : Cette méthode est une méthode utilitaire qui effectue les mises à niveau nécessaires entre les versions. Elle doit savoir comment gérer les versions précédentes et ce qui doit être fait pour les mettre à niveau.

Une valeur de retour vraie indique le succès.
