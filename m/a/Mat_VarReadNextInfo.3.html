Mat_VarReadNextInfo(3)

Paquet: libmatio

Licences: BSD-2-Clause

MAT_VARREADNEXTINFO(3) Manuel des fonctions de bibliothèque MAT_VARREADNEXTINFO(3)

NOM

Mat_VarReadNextInfo — Lit les informations de la prochaine variable dans un fichier MAT MATLAB.

SYNTAXE

#include <matio.h>

matvar_t *
Mat_VarReadNextInfo(mat_t *matfp);

DESCRIPTION

La fonction Mat_VarReadNextInfo() lit les informations de la prochaine variable stockée dans le fichier MAT ouvert.

VALEURS DE RETOUR

S'il existe une autre variable dans le fichier MAT et qu'elle est lue avec succès, un pointeur vers la structure de variable MATLAB est retourné. S'il n'y a plus de variables, ou s'il y a eu une erreur lors de la lecture de la variable, NULL est retourné.

EXEMPLES

Cet exemple de programme ouvre un fichier MAT nommé par le premier argument du programme et utilise Mat_VarReadNextInfo() pour lire les informations sur chaque variable du fichier. Pour chaque variable lue, le nom, la taille et la classe sont imprimés dans un format similaire à la commande whos de MATLAB.

#include <math.h>
#include <stdlib.h>
#include <stdio.h>
#include "matio.h"

static char *mxclass[17] = {"cell", "struct", "object", "char", "sparse",
                            "double", "single", "int8", "uint8", "int16",
                            "uint16", "int32", "uint32", "int64", "uint64",
                            "function", "opaque"
                           };

int
main(int argc, char **argv)
{
    mat_t *matfp;
    matvar_t *matvar;
    char size[32] = {' ',};

    matfp = Mat_Open(argv[1], MAT_ACC_RDONLY);
    if ( NULL == matfp ) {
        fprintf(stderr, "Erreur lors de l'ouverture du fichier MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    printf("%-32s%-16s%-16s%-16s0, "Nom", "Taille", "Octets", "Classe");
    while ( NULL != (matvar = Mat_VarReadNextInfo(matfp)) ) {
        printf("%-32s", matvar->name);
        if ( matvar->rank > 0 ) {
            int cnt;
            int i;
            cnt = snprintf(size, sizeof(size), "%zd", matvar->dims[0]);
            for ( i = 1; i < matvar->rank; i++ ) {
                if ( ceil(log10((double)matvar->dims[i])) + 1 < 32 ) {
                    cnt += snprintf(size + cnt, sizeof(size) - cnt,
                        "x%zd", matvar->dims[i]);
                    if ( cnt >= sizeof(size) ) {
                        break;
                    }
                }
            }
            printf("%-16s", size);
        } else {
            printf("                ");
        }
        snprintf(size, sizeof(size), "%zd", Mat_VarGetSize(matvar));
        printf("%-16s", size);
        printf("%-16s0, mxclass[matvar->class_type - 1]);

        Mat_VarFree(matvar);
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
