MAT_VARFREE(3) Manuel des fonctions de bibliothèque MAT_VARFREE(3)

NOM

Mat_VarFree — Libère la structure d'une variable MAT.

SYNTAXE

#include <matio.h>

void
Mat_VarFree(matvar_t *matvar);

DESCRIPTION

La fonction Mat_VarFree() libère la mémoire utilisée par une structure de variable MAT. Si la variable n'a pas été créée avec le drapeau MAT_F_DONT_COPY_DATA, les données de la variable sont également libérées.

VOIR AUSSI

Mat_VarCreate(3), Mat_VarCreateStruct(3)
