NOM

Mail::SpamAssassin::Plugin::WelcomeListSubject - welcomelist par sujet d'en-tête

SYNTAXE

loadplugin Mail::SpamAssassin::Plugin::WelcomeListSubject
header SUBJECT_IN_WELCOMELIST eval:check_subject_in_welcomelist()
header SUBJECT_IN_BLOCKLIST eval:check_subject_in_blocklist()
score SUBJECT_IN_WELCOMELIST -100
score SUBJECT_IN_BLOCKLIST 100
welcomelist_subject [Bug *]
blocklist_subject Make Money Fast

DESCRIPTION

Ce module de plugin SpamAssassin fournit des tests eval pour l'accueil et le blocage de chaînes particulières dans l'en-tête Sujet. La chaîne correspondra n'importe où dans le sujet. La valeur pour welcomelist_subject ou blocklist_subject sont des chaînes qui peuvent contenir des motifs de type file -glob, similaires aux autres options de configuration *_subject. Notez que chaque sujet/chaîne doit être une commande *_subject séparée, tous les espaces blancs sont inclus dans la chaîne.
