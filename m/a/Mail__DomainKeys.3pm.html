SYNOPSIS

Mail::DomainKeys est une implémentation Perl du protocole de signature d'e-mails de Yahoo.

Cette bibliothèque permet de signer et de vérifier des signatures conformément à la version 03 du brouillon de la spécification DomainKeys :

http://www.ietf.org/internet-drafts/draft-delany-domainkeys-base-03.txt

Un exemple simple

Cet exemple montre le vérificateur de signature DomainKeys le plus simple possible.

require Mail::DomainKeys::Message;
# charger un message depuis un descripteur de fichier
my $mail = load Mail::DomainKeys::Message(File => \*STDIN) or
  die "impossible de charger le message\n";
# vérifier que l'expéditeur a un domaine pleinement qualifié    
$mail->senderdomain or
  die "impossible de vérifier le message : pas de domaine d'expéditeur\n";  
# vérifier si l'e-mail est signé par DomainKeys
$mail->signed or
  die "pas de signature\n";
# vérifier la signature  
if ($mail->verify) {
  print STDERR "signature valide\n";
  exit 0;
}
# la signature n'était pas valide
die "impossible de vérifier la signature\n";

Cet exemple montre le signataire DomainKeys le plus simple possible.

require Mail::DomainKeys::Message;
require Mail::DomainKeys::Key::Private;
# charger le message, ou échouer en essayant
my $mail = load Mail::DomainKeys::Message(File => \*STDIN) or
  die "impossible de charger le message";
# charger la clé privée, ou échouer en essayant
my $priv = load Mail::DomainKeys::Key::Private(File => "private.key") or
  die "impossible de charger la clé";
# signer le message en utilisant le canonificateur "simple" et le sélecteur "test"  
$mail->sign(Method => "simple", Selector => "test", Private => $priv);
# imprimer la signature
print $mail->signature->as_string;
