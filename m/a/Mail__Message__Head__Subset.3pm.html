NOM

Mail::Message::Head::Subset - informations d'en-tête de message dans un sous-ensemble

HÉRITAGE

Mail::Message::Head::Subset hérite de Mail::Message::Head
Mail::Message::Head::Subset
  est un Mail::Message::Head
  est un Mail::Reporter

SYNTAXE

my $subset = Mail::Message::Head::Subset->new(...)
$subset->isa('Mail::Message::Head')  # vrai
 $subset->guessBodySize               # entier ou undef
 $subset->isDelayed                   # vrai

DESCRIPTION

Certains types de dossiers contiennent un fichier d'index qui liste une ou deux lignes d'informations par message. En particulier lorsque la lecture des lignes d'en-tête est coûteuse, l'index accélère considérablement l'accès. Par exemple, les sujets de tous les messages sont souvent souhaitables, mais attendre qu'un million de messages d'un dossier soient lus peut impliquer un million d'opérations de lecture (IMAP) ou d'ouverture de fichiers (MH).

Lorsque vous accédez à des champs d'en-tête qui ne se trouvent pas dans le sous-ensemble d'en-tête, l'en-tête entier doit être analysé (ce qui peut prendre beaucoup de temps, en fonction du type de dossier).

Mail::Message::Head::Subset(3pm)

INHERITANCE

Mail::Message::Head::Subset is a subclass of Mail::Message::Head::List.

SYNOPSIS

use Mail::Message::Head::Subset;

my $subset = Mail::Message::Head::Subset->new;
$subset->add($header1);
$subset->add($header2);

my $count = @$subset; # number of headers
my $first = $subset->[0]; # first header object

# The following does not work because the class does not implement
# the necessary methods.
# my $headers = $subset->collect('Subject');
# print $subset->as_text;

DESCRIPTION

This class represents a collection of mail headers, where the order of the headers is important. It is an abstraction for all the headers of a mail message, but can also be used to store a specific set of headers.

This implementation is intended to be a base class for other header list classes. For example, Mail::Message::Head::List is a subclass that implements the list interface.

The current implementation is very basic. It does not implement many methods that you might expect from a header list.

OVERLOADED

None.

METHODS

add($header)
Adds a header object to the end of the list.
new()
Creates a new, empty subset.

DETAILS

This class is a starting point for implementing header collections. The primary use case is to provide a structure that can hold a sequence of header objects. More advanced functionality, like searching or formatting, is expected to be implemented in subclasses.

DIAGNOSTICS

The class itself does not produce many errors. When it is used incorrectly (e.g., adding something that is not a header object), Perl's standard error mechanisms will be triggered.

Some methods that are expected but not implemented will raise an error like:

not implemented
The specific method called is not implemented in this class. It is expected to be implemented in a subclass.

Example:

Mail::Message::Head::Subset does not implement the ‘collect’ method.

This usually means that the object you are using is not of the expected class. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
