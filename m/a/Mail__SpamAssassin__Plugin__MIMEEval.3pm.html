DESCRIPTION

Effectue divers tests sur la structure et le corps MIME.

has_check_for_ascii_text_illegal
Ajoute une vérification de capacité pour "if can()" pour check_for_ascii_text_illegal
check_for_ascii_text_illegal
Si une partie MIME prétend être text/plain ou text/plain;charset=us-ascii et que le Content-Transfer-Encoding est 7bit (explicitement ou par défaut), alors nous devrions imposer que le texte réel ne contienne que TAB, NL, ESPACE jusqu'à TILDE, c'est-à-dire tous les caractères 7bit à l'exclusion de NO-WS-CTL (selon RFC-2822).

Tous les MTA grand public gèrent cela correctement.

has_check_abundant_unicode_ratio
Ajoute une vérification de capacité pour "if can()" pour check_abundant_unicode_ratio
check_abundant_unicode_ratio
Une partie MIME prétendant être text/plain et contenant des caractères Unicode doit être encodée en quoted-printable ou base64, ou utiliser un codage de données UTF (typiquement avec un encodage 8bit). Tout message en 7bit ou 8bit contenant des entités (HTML) Unicode ne les rendra pas en Unicode, mais littéralement.

Ainsi, quelques séquences de ce type peuvent apparaître sur une liste de diffusion de développeurs discutant de tels caractères, mais un message avec une forte densité de tels caractères est probablement du spam.

has_check_qp_ratio
Ajoute une vérification de capacité pour "if can()" pour check_qp_ratio
check_qp_ratio
Prend un ratio minimum à utiliser dans eval pour voir s'il y a une probabilité de spam dans le ratio du quoted-printable par rapport aux octets totaux d'un email.
