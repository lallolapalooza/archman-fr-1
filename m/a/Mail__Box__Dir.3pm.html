Nom

Mail::Box::Dir - gérer des dossiers avec un fichier par message.

Héritage

Mail::Box::Dir
  est un Mail::Box
  est un Mail::Reporter
Mail::Box::Dir est étendu par
  Mail::Box::MH
  Mail::Box::Maildir

Syntaxe

Ne pas instancier cet objet

Description

Cette documentation décrit comment les dossiers de courrier organisent les messages. Actuellement, cet objet est étendu par

  • Mail::Box::MH

    Dossiers MH, représentés par un répertoire contenant des fichiers numérotés séquentiellement.

  • Mail::Box::Maildir

    Dossiers Maildir, qui se trouvent dans un répertoire avec des sous-répertoires nommés "tmp", "new" et "cur". Chacun de ces répertoires peut contenir des fichiers dont les noms sont des combinaisons d'un horodatage numérique et de certains indicateurs d'état.

  • Mail::Box::Netzwert

    Ce type de dossier a été spécialement développé pour Netzwert AG, optimisé pour fonctionner sur un réseau de serveurs avec des dossiers sur NFS. Le code n'est pas disponible publiquement (pour l'instant).

DIAGNOSTICS

Attention : Les modifications ne sont pas écrites dans le dossier en lecture seule $self.
Vous avez ouvert le dossier en lecture seule -- ce qui est la valeur par défaut définie par new(access) --, effectué des modifications, et vous souhaitez maintenant le fermer. Définissez close(force) si vous voulez outrepasser le mode d'accès, ou fermez le dossier avec close(write) défini à "NEVER". Causé par close()
Erreur : Copie échouée pour un message.
Pour une raison quelconque, par exemple disque plein, suppression par un processus externe, ou protection en lecture, il est impossible de copier l'un des messages. La copie se poursuivra pour les autres messages. Causé par copyTo()
Erreur : Le dossier de destination $name n'est pas inscriptible.
Le dossier vers lequel les messages sont copiés n'a pas été ouvert avec un accès en écriture (voir new(access)). Ceci n'a aucun rapport avec la permission d'écriture sur le dossier, qui est contrôlée par votre système d'exploitation. Causé par copyTo()
Attention : Messages différents avec l'id $msgid
L'id du message est découvert plus d'une fois dans le même dossier, mais le contenu du message semble être différent. Ceci ne devrait pas être possible : chaque message doit être unique. Causé par messageId()
Erreur : Le dossier $name est ouvert en lecture seule
Vous ne pouvez pas écrire dans ce dossier à moins de l'avoir ouvert en écriture ou pour ajout avec new(access), ou si l'option "force" est définie à "true". Causé par write()
Erreur : Le dossier $name n'a pas été supprimé : pas inscriptible.
Le dossier doit être ouvert en écriture via new(access), sinon sa suppression sera refusée. Ainsi, vous pouvez avoir un accès en écriture selon le système d'exploitation, mais cela ne signifie pas automatiquement que cette méthode "delete" vous le permet. La remarque inverse est également valide. Causé par delete()
Attention : Messages différents avec l'id $msgid
L'id du message est découvert plus d'une fois dans le même dossier, mais le contenu du message semble être différent. Ceci ne devrait pas être possible : chaque message doit être unique. Causé par messageId()
Erreur : Période de temps invalide '$timespan' spécifiée.
La chaîne ne suit pas les règles strictes de la syntaxe de période de temps autorisée comme paramètre. Causé par timespan2seconds()
Attention : L'id du message '$msgid' ne contient pas de domaine.
Conformément aux RFC, les ids de message doivent contenir une partie aléatoire unique, puis un "@", puis un nom de domaine. Ceci est fait pour éviter la création de deux messages avec le même id. L'avertissement apparaît lorsque le "@" est manquant dans la chaîne. Causé par messageId()
Erreur : Période de temps invalide '$timespan' spécifiée.
La chaîne ne suit pas les règles strictes de la syntaxe de période de temps autorisée comme paramètre. Causé par timespan2seconds()

Avertissement : Pas de répertoire $name pour le dossier de $class
Lancé par new()
Erreur : Le package $package n'implémente pas $method.
Erreur fatale : le package spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où elle devrait l'être. Ce message signifie que d'autres classes apparentées implémentent cette méthode, mais que la classe en question ne le fait pas. Vous devriez probablement enquêter à ce sujet et peut-être informer l'auteur du package. Lancé par notImplemented()
Erreur : Impossible de créer le sous-dossier $name de $folder.
La copie inclut les sous-dossiers, mais pour une raison quelconque, il n'a pas été possible d'en copier un. La copie se poursuivra pour tous les autres sous-dossiers. Lancé par copyTo()
Erreur : Écriture du dossier $name a échoué
Pour une raison quelconque (vous avez probablement reçu d'autres messages d'erreur concernant ce problème), il est impossible d'écrire dans le dossier, bien que vous devriez le pouvoir car des modifications ont été apportées. Lancé par write()
