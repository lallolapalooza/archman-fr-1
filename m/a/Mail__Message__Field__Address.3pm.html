NOM

Mail::Message::Field::Address - Une adresse e-mail

HÉRÉDITÉ

Mail::Message::Field::Address
  est un Mail::Identity
  est un User::Identity::Item

SYNOPSIS

my $addr = Mail::Message::Field::Address->new(...);
my $ui   = User::Identity->new(...);
my $addr = Mail::Message::Field::Address->coerce($ui);
my $mi   = Mail::Identity->new(...);
my $addr = Mail::Message::Field::Address->coerce($mi);
print $addr->address;
print $addr->fullName;   # potentiellement unicode !
print $addr->domain;

DESCRIPTION

De nombreux champs d'en-tête peuvent contenir des adresses e-mail. Chaque adresse e-mail peut être représentée par un objet de cette classe. Ces objets géreront l'interprétation et le codage/décodage des jeux de caractères pour vous.

Étendu de "DESCRIPTION" dans Mail::Identity.

SURCHARGE

surcharge: "" transformation en chaîne
Lorsque l'objet est utilisé dans un contexte de chaîne, il retournera la représentation codée de l'adresse e-mail, tout comme le fait string().
surcharge: booléen vrai/faux
L'objet utilisé comme booléen retournera toujours "vrai"
surcharge: cmp comparaison de chaînes
Deux objets d'adresse sont identiques lorsque leurs adresses e-mail sont identiques.

MÉTHODES

Étendu de "METHODES" dans Mail::Identity.

Constructeurs

Étendu de "Constructors" dans Mail::Identity.

$obj->coerce( <CHAÎNE|$objet>, %options )
Tente de contraindre le $objet en un "Mail::Message::Field::Address". Dans le cas d'une "CHAÎNE", elle est interprétée comme une adresse e-mail.

Les %options sont transmises à la création de l'objet et remplacent les valeurs trouvées dans le $objet. Le résultat peut être "undef" ou un objet nouvellement créé. Si le $objet est déjà du bon type, il est retourné sans modification.

Le $objet peut actuellement être un Mail::Address, un Mail::Identity, ou un User::Identity. Dans le cas de ce dernier, une des adresses de l'utilisateur est choisie au hasard.

$class->new( [$nom], %options )
Hérité, voir "Constructors" dans Mail::Identity
$obj->parse(CHAÎNE)
Analyse la chaîne pour une adresse. On ne sait jamais si une ou plusieurs adresses sont spécifiées sur une ligne (souvent les applications se trompent), par conséquent, la "CHAÎNE" est d'abord analysée pour autant d'adresses que possible, puis celle qui est choisie l'est au hasard.

Accès au contenu

DIAGNOSTICS

Erreur: impossible de contraindre $type en Mail::Message::Field::Address
Lorsque des adresses sont spécifiées pour être incluses dans des champs d'en-tête, elles peuvent d'abord être contraintes en objets Mail::Message::Field::Address. Ce que vous spécifiez n'est pas accepté comme spécification d'adresse. Il peut s'agir d'une erreur interne. Causé par coerce()
Erreur: impossible de charger le module de collection pour $type ($class) : $err
Soit le $type spécifié n'existe pas, soit ce module nommé $class renvoie des erreurs de compilation. Si le type tel qu'indiqué dans l'avertissement n'est pas le nom d'un paquet, vous avez spécifié un surnom qui n'était pas défini. Peut-être avez-vous oublié le 'require' du paquet qui définit le surnom. Causé par addCollection()

NAME

Mail::Message::Field::Address - represent an address field

INHERITANCE

Mail::Message::Field::Address isa Mail::Message::Field isa Mail::Message isa MIME::Entity isa Email::Abstract isa Object::SubClass isa Exporter

SYNOPSIS

    use Mail::Message::Field::Address;

    my $field = Mail::Message::Field::Address->new(
        'From' => 'Jeroen '
    );
    print $field->as_string;
    # From: Jeroen <jeroen@xs4all.nl>

    my $addresses = $field->addresses;
    print $addresses->[0]->format;
    # Jeroen <jeroen@xs4all.nl>

DESCRIPTION

The abstract base class for all message fields. This class is extended by specific field implementations like Mail::Message::Field::From, Mail::Message::Field::To, etc.

OVERLOADED

stringifies to the field value

METHODS

addresses

Returns the list of addresses found in this field. This is an array reference to objects of class Mail::Message::Address.

DIAGNOSTICS

This class does not add any new diagnostics.
