NOM

Mail::Message::Convert::MimeEntity - traduire Mail::Message en MIME::Entity vv

HERITAGE

Mail::Message::Convert::MimeEntity
  est un Mail::Message::Convert
  est un Mail::Reporter

SYNOPIS

use Mail::Message::Convert::MimeEntity;
my $convert = Mail::Message::Convert::MimeEntity->new;
my Mail::Message $msg    = Mail::Message->new;
my MIME::Entity  $entity = $convert->export($msg);
my MIME::Entity  $entity = MIME::Entity->new;
my Mail::Message $msg    = $convert->from($entity);
use Mail::Box::Manager;
my $mgr     = Mail::Box::Manager->new;
my $folder  = $mgr->open(folder => 'Outbox');
$folder->addMessage($entity);

DESCRIPTION

Le MIME::Entity étend le message Mail::Internet avec des multiparts et plus de méthodes. Les objets Mail::Message sont plus flexibles quant à la façon dont les parties du message sont stockées et utilisent des objets header et body séparés.

Conversion

Étendu de "Conversion" dans Mail::Message::Convert.

$obj->export( $message, [$parser] )
Retourne un nouvel objet message MIME::Entity basé sur les informations du $message, qui est un objet Mail::Message.

Vous pourriez vouloir fournir votre propre $parser, qui est un objet MIME::Parser, pour modifier les drapeaux du parseur. Sans objet $parser, un est créé pour vous, avec tous les paramètres par défaut.

Si "undef" est passé, à la place d'un $message, alors une liste vide est retournée. Lorsque l'analyse échoue, MIME::Parser lève une exception.

» exemple:

my $convert = Mail::Message::Convert::MimeEntity->new;
my Mail::Message $msg  = Mail::Message->new;
my MIME::Entity  $copy = $convert->export($msg);
$obj->from($mime_object)
Retourne un nouvel objet Mail::Message basé sur les informations de MIME::Entity spécifié. Si la conversion échoue, "undef" est retourné. Si "undef" est passé à la place d'un OBJET, alors une liste vide est retournée.

» exemple:

my $convert = Mail::Message::Convert::MimeEntity->new;
my MIME::Entity  $msg  = MIME::Entity->new;
my Mail::Message $copy = $convert->from($msg);
$obj->selectedFields($head)
