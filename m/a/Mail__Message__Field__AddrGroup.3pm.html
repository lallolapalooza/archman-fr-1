NOM

Mail::Message::Field::AddrGroup - Groupe d'adresses électroniques

HIÉRARCHIE

Mail::Message::Field::AddrGroup
  hérite de User::Identity::Collection::Emails
  hérite de User::Identity::Collection
  hérite de User::Identity::Item

SYNTAXE

my $g = Mail::Message::Field::AddrGroup->new(name => 'nom');
my $a = Mail::Message::Field::Address->new(...);
$g->addAddress($a);
my $f = Mail::Message::Field::Addresses->new;
$f->addGroup($g);

DESCRIPTION

Un groupe d'adresses électroniques rassemble un ensemble d'adresses électroniques (dans ce cas, ce sont des objets Mail::Message::Field::Address).

Hérite de "DESCRIPTION" dans User::Identity::Collection::Emails.

MÉTHODES

Hérite de "MÉTHODES" dans User::Identity::Collection::Emails.

$obj->string()
Retourne la représentation du groupe d'adresses électroniques sous forme de chaîne. Sans nom, seule une liste d'adresses séparées par des virgules sera retournée. Avec un nom, le nom du groupe sera précédé et un point-virgule sera ajouté. Sans adresses et sans nom, "undef" sera retourné.

ADRESSES ÉLECTRONIQUES

$obj->addAddress(STRING|$address|%options)
Ajoute une adresse électronique à la liste maintenue dans le groupe. C'est un wrapper pour la méthode addRole() qui ajoute de la flexibilité quant à la manière dont les adresses sont spécifiées. Une $address peut être n'importe quoi d'acceptable par Mail::Message::Field::Address::coerce() ou une liste d'options qui créera un tel objet.

Exemple : ajouter une adresse électronique à un groupe d'adresses électroniques

my @data = (full_name => "Myself", address => 'me@tux.org');
$group->addAddress(@data);
my $addr = Mail::Message::Field::Address->new(@data);
$group->addAddress(@data);
my $ma = Mail::Address->new(...);
$group->addAddress($ma);
$obj->addresses()
Retourne toutes les adresses définies dans ce groupe. Les adresses sont triées par ordre alphabétique pour permettre des tests automatiques : les rôles sont stockés dans une table de hachage, donc l'ordre par défaut est imprévisible.

Exemple : obtenir toutes les adresses d'un groupe

my @addrs = $group->addresses;
my @addrs = map $_->address, $self->roles; # idem
