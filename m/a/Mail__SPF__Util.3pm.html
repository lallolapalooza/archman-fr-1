Mail::SPF::Util(3) Documentation Perl fournie par l'utilisateur Mail::SPF::Util(3)

NOM

Mail::SPF::Util - Classe utilitaire de Mail::SPF

VERSION

version 3.20250505

SYNOPSIS

use Mail::SPF::Util;
$hostname = Mail::SPF::Util->hostname;
$ipv6_address_v4mapped =
    Mail::SPF::Util->ipv4_address_to_ipv6($ipv4_address);
$ipv4_address =
    Mail::SPF::Util->ipv6_address_to_ipv4($ipv6_address_v4mapped);
$is_v4mapped =
    Mail::SPF::Util->ipv6_address_is_ipv4_mapped($ipv6_address);
$ip_address_string  = Mail::SPF::Util->ip_address_to_string($ip_address);
$reverse_name       = Mail::SPF::Util->ip_address_reverse($ip_address);
$validated_domain = Mail::SPF::Util->valid_domain_for_ip_address(
    $spf_server, $request,
    $ip_address, $domain,
    $find_best_match,       # vaut false par défaut
    $accept_any_domain      # vaut false par défaut
);
$sanitized_string = Mail::SPF::Util->sanitize_string($string);

DESCRIPTION

Mail::SPF::Util est la classe utilitaire de Mail::SPF.

Méthodes de classe

Les méthodes de classe suivantes sont fournies :

hostname : retourne chaîne
Retourne le nom de domaine complet (FQDN) de l'hôte local.
ipv4_address_to_ipv6($ipv4_address) : retourne NetAddr::IP ; lance Mail::SPF::EInvalidOptionValue
Convertit l'adresse IPv4 NetAddr::IP spécifiée en une adresse IPv6 mappée IPv4. Lance une exception Mail::SPF::EInvalidOptionValue si l'adresse IP spécifiée n'est pas une adresse IPv4.
ipv6_address_to_ipv4($ipv6_address) : retourne NetAddr::IP ; lance Mail::SPF::EInvalidOptionValue
Convertit l'adresse IPv6 mappée IPv4 NetAddr::IP spécifiée en une adresse IPv4 correcte. Lance une exception Mail::SPF::EInvalidOptionValue si l'adresse IP spécifiée n'est pas une adresse IPv6 mappée IPv4.
ipv6_address_is_ipv4_mapped($ipv6_address) : retourne booléen
Retourne vrai si l'adresse IPv6 NetAddr::IP spécifiée est une adresse mappée IPv4, faux sinon.
ip_address_to_string($ip_address) : retourne chaîne ; lance Mail::SPF::EInvalidOptionValue
Retourne l'adresse IPv4 ou IPv6 NetAddr::IP donnée, formatée de manière compacte en une chaîne. Pour les adresses IPv4, cela est équivalent à appeler la méthode "addr" de NetAddr::IP. Pour les adresses IPv6, cela est équivalent à appeler la méthode "short" de NetAddr::IP. Lance une exception Mail::SPF::EInvalidOptionValue si l'objet spécifié n'est pas un objet d'adresse IPv4 ou IPv6 NetAddr::IP.
ip_address_reverse($ip_address) : retourne chaîne ; lance Mail::SPF::EInvalidOptionValue
Retourne la notation inverse "in-addr.arpa."/"ip6.arpa." de l'adresse IPv4 ou IPv6 NetAddr::IP donnée. Lance une exception Mail::SPF::EInvalidOptionValue si l'objet spécifié n'est pas un objet d'adresse IPv4 ou IPv6 NetAddr::IP.
valid_domain_for_ip_address($server, $request, $ip_address, $domain, $find_best_match = false, $accept_any_domain = false) : retourne chaîne ou undef
Trouve un nom de domaine valide pour l'adresse IP NetAddr::IP donnée qui correspond au domaine donné ou à un sous-domaine de celui-ci. Un nom de domaine est valide pour l'adresse IP donnée si l'adresse IP est mappée en inverse vers ce nom de domaine dans le DNS, et si le nom de domaine est à son tour mappé en avant vers l'adresse IP. Utilise les objets Mail::SPF::Server et Mail::SPF::Request donnés pour effectuer les recherches DNS. Retourne le nom de domaine validé.

Si $find_best_match est vrai, le nom de domaine qui correspond le mieux au nom de domaine donné est sélectionné, en privilégiant les correspondances directes par rapport aux correspondances de sous-domaines. Vaut faux par défaut.

Si $accept_any_domain est vrai, tous les noms de domaine sont considérés comme acceptables, même s'ils diffèrent complètement du nom de domaine donné (qui est alors effectivement inutilisé, sauf si une meilleure correspondance est demandée). Vaut faux par défaut.

sanitize_string($string) : retourne chaîne ou undef
Remplace tous les caractères non imprimables ou non ASCII dans une chaîne par leur représentation échappée hexadécimale (par exemple, "\x00").
