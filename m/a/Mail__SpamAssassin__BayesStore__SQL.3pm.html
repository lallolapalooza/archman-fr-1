NOM

Mail::SpamAssassin::BayesStore::SQL - Implémentation du module de stockage bayésien basé sur SQL

DESCRIPTION

Ce module implémente un module de stockage bayésien basé sur SQL. Il prend en charge SQLite et d'autres serveurs SQL standard.

N'utilisez pas celui-ci pour MySQL/MariaDB ou PgSQL, ceux-ci ont leurs propres modules spécifiques.

MÉTHODES

new

classe publique (Mail::SpamAssassin::BayesStore::SQL) new (Mail::Spamassassin::Plugin::Bayes $bayes)

Description : Cette méthode crée une nouvelle instance de la classe Mail::SpamAssassin::BayesStore::SQL. Elle attend une instance de Mail::SpamAssassin:Bayes qui est transmise à l'objet parent de Mail::SpamAssassin::BayesStore.

Cette méthode établit la connexion à la base de données et détermine l'utilisateur à utiliser dans les requêtes.

token_expiration

méthode publique (Integer, Integer, Integer, Integer) token_expiration(\% $opts, Integer $newdelta, @ @vars)

Description : Cette méthode effectue l'expiration des jetons en se basant sur le $newdelta et les @vars passés.

sync_due

méthode publique (Boolean) sync_due ()

Description : Cette méthode détermine si une synchronisation de la base de données est actuellement nécessaire.

Elle n'est pas utilisée dans les implémentations basées sur SQL.

seen_get

méthode publique (String) seen_get (string $msgid)

Description : Cette méthode récupère la valeur stockée pour $msgid. La valeur retournée est la chaîne stockée ('s' pour spam et 'h' pour ham) ou undef si $msgid n'est pas trouvée.

seen_put

méthode publique (Boolean) seen_put (string $msgid, char $flag)

Description : Cette méthode enregistre $msgid comme le type donné par $flag. $flag est l'une des deux valeurs : 's' pour spam et 'h' pour ham.

seen_delete

méthode publique (Boolean) seen_delete (string $msgid)

Description : Cette méthode supprime $msgid de la base de données.

get_storage_variables

méthode publique (@) get_storage_variables ()

Description : Cette méthode récupère les différentes variables administratives utilisées par le processus Bayes et la base de données.

Les valeurs retournées dans le tableau sont dans l'ordre suivant :

0 : base du compte de scan

1 : nombre de spams

2 : nombre de ham

3 : nombre de jetons dans la base de données

4 : dernier atime d'expiration

5 : plus ancien atime dans la base de données

6 : valeur de version de la base de données

7 : dernière synchronisation du journal

8 : dernier delta de atime

9 : dernier nombre de réduction d'expiration

10 : atime le plus récent dans la base de données

dump_db_toks

méthode publique () dump_db_toks (String $template, String $regex, Array @vars)

Description : Cette méthode parcourt tous les jetons, calcule la probabilité pour chaque jeton, puis imprime le résultat selon le jeton spécifié.

set_last_expire

méthode publique (Boolean) set_last_expire (Integer $time)

Description : Cette méthode définit l'heure de la dernière expiration.

get_running_expire_tok

méthode publique (String $time) get_running_expire_tok ()

Description : Cette méthode détermine si une expiration est en cours d'exécution et retourne la dernière heure où elle a été définie.

set_running_expire_tok

remove_running_expire_tok

méthode publique (Boolean) remove_running_expire_tok ()

Description : Cette méthode supprime la ligne dans la base de données qui indique qu'une expiration est actuellement en cours d'exécution.

tok_get

méthode publique (Integer, Integer, Integer) tok_get (String $token)

Description : Cette méthode récupère un jeton spécifié ($token) de la base de données et renvoie son nombre de spams, son nombre de ham et son heure de dernier accès.

NOM

Mail::SpamAssassin::BayesStore::SQL

DESCRIPTION

Ce module fournit une interface pour interagir avec une base de données SQL de type Bayes, utilisée dans le système SpamAssassin.

MÉTHODES

Ce module inclut des méthodes pour manipuler la base de données SQL de Bayes.

Méthodes privées

Ce module inclut des méthodes privées pour les opérations internes de la base de données SQL.

_connect_db

méthode privée (booléen) _connect_db ()

Cette méthode établit la connexion à la base de données SQL.

_get_db_version

méthode privée (entier) _get_db_version ()

Récupère la version actuelle de la base de données à partir des tables globales spécialisées.

_initialize_db

méthode privée (booléen) _initialize_db ()

Vérifie si les variables bayésiennes d'un utilisateur ont été initialisées. Si ce n'est pas le cas, l'initialisation est effectuée.

_put_token

méthode privée (booléen) _put_token (chaîne $token, entier $spam_count, entier $ham_count, chaîne $atime)

Cette méthode effectue l'opération d'insertion ou de mise à jour d'un token dans la base de données.

_put_tokens

méthode privée (booléen) _put_tokens (\% $tokens,
entier $spam_count,
entier $ham_count, chaîne $atime)

Cette méthode effectue l'opération d'insertion ou de mise à jour de plusieurs tokens dans la base de données.

_get_oldest_token_age

méthode privée (entier) _get_oldest_token_age ()

Cette méthode trouve l'âge du token le plus ancien dans la base de données.

L'utilisation de min(atime) en SQL est inefficace, mais c'est le moyen le plus rapide d'obtenir l'âge du token le plus ancien après une expiration massive. Elle ne doit être appelée que lors du processus d'expiration.

_get_num_hapaxes

méthode privée (entier) _get_num_hapaxes ()

Cette méthode obtient le nombre total d'hapax (spam_count + ham_count == 1) dans la base de données de tokens pour un utilisateur.

_get_num_lowfreq

méthode privée (entier) _get_num_lowfreq ()

Cette méthode obtient le nombre total de tokens de faible fréquence (spam_count < 8 et ham_count < 8) dans la base de données de tokens pour un utilisateur.

_token_select_string

méthode privée (chaîne) _token_select_string

Cette méthode renvoie la chaîne qui sera utilisée dans les requêtes SELECT pour représenter la colonne des tokens.

La valeur par défaut consiste à utiliser la fonction SUBSTR pour aligner les tokens sur 5 caractères.
