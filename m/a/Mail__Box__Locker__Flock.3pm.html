NOM

Mail::Box::Locker::Flock - verrouiller une boîte aux lettres en utilisant le verrouillage du noyau

HIÉRARCHIE

Mail::Box::Locker::Flock
  est un Mail::Box::Locker
  est un Mail::Reporter

SYNTAXE

Voir l'interface de Mail::Box::Locker générique

DESCRIPTION

L'objet « ::Flock » verrouille la boîte aux lettres en créant un verrou exclusif sur un fichier du système de fichiers, en utilisant les fonctions de verrouillage du noyau « flock ». Ce verrou est créé sur un fichier de gestion séparé de la boîte aux lettres, ce n'est donc pas le gestionnaire qui est lu.

Le verrouillage de fichiers ne fonctionne pas dans certaines situations, par exemple sur des systèmes d'exploitation qui ne prennent pas en charge « flock ».

DIAGNOSTICS

Attention : Boîte aux lettres $boite déjà verrouillée
La boîte aux lettres $boite est déjà verrouillée, mais vous essayez de la verrouiller à nouveau. Le comportement de deux verrous dépend du système d'exploitation, vous ne devriez donc pas essayer. Le second verrou est ignoré (mais le verrou n'est pas libéré).
Erreur : le paquet $package n'implémente pas $method.
Erreur de type : le paquet spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où elle le devrait. Ce message signifie que d'autres classes apparentées implémentent cette méthode, mais cette classe particulière ne le fait pas. Vous devriez enquêter à ce sujet et probablement en informer l'auteur du paquet. Généré par la méthode notImplemented()
Erreur : impossible de vérifier le verrouillage du fichier $nomfichier pour $boite : $!
Pour vérifier si le fichier $nomfichier est ouvert pour verrouiller la boîte aux lettres $boite, il doit être ouvert. Apparemment, cela échoue, ce qui ne signifie pas que la boîte aux lettres est verrouillée ni qu'elle est déverrouillée. Généré par la méthode isLocked()
Erreur : impossible d'ouvrir le fichier de verrouillage $fichier pour $boite : $!
Pour verrouiller la boîte aux lettres $boite avec le système de verrouillage « flock », elle doit être ouverte, ce qui échoue pour la raison spécifiée. Généré par la méthode lock()
Erreur : impossible d'obtenir un verrou sur $fichier pour $boite : $!
Vous avez essayé de verrouiller la boîte aux lettres $boite avec « flock », mais vous n'avez pas réussi à obtenir un verrou. Le code d'erreur reçu du système d'exploitation indique que vous ne réussirez jamais à obtenir un verrou, il n'est donc pas nécessaire de réessayer. Généré par la méthode lock()
