NOM

Mail::Message::TransferEnc::Base64 - Encode/décode les corps de message en base64

HÉRÉDITÉ

Mail::Message::TransferEnc::Base64
  est un Mail::Message::TransferEnc
  est un Mail::Reporter

SYNOPSIS

my Mail::Message $msg = ...;
my $decoded = $msg->decoded;
my $encoded = $msg->encode(transfer => 'base64');

DESCRIPTION

Encode ou décode les corps de message avec base64. Le protocole électronique et les agents utilisateurs ne peuvent pas gérer les données binaires. Par conséquent, les données binaires - mais même parfois les données non binaires - sont encodées en ASCII, ce qui est transportable.

Base64 regroupe les bits des octets et les mappe sur des caractères. Les données contiennent des octets de 8 bits (un octet). Ceux-ci sont regroupés en blocs de 6 bits, pointant dans un tableau de caractères contenant "[A-Za-z0-9+/]". De cette façon, trois octets de données deviennent 4 octets base64. Les données encodées seront suivies par des caractères '=' pour s'aligner sur quatre octets.

DIAGNOSTICS

Attention : Longueur de ligne Base64 non complétée sur 4.
Lors du décodage de base64 des données dans un corps de message, une chaîne a été trouvée qui n'était pas complétée sur un multiple de quatre octets. Ceci est illégal, et par conséquent ces données sont ignorées. Lancé par decode()
Erreur : Le décodeur pour le codage de transfert $type ne fonctionne pas : $@
La compilation du codage de transfert requis a entraîné des erreurs, ce qui signifie que le décodeur ne peut pas être utilisé. Lancé par create()
Attention : Aucun décodeur pour le codage de transfert $type.
Un décodeur pour le type de codage de transfert spécifié n'est pas implémenté. Lancé par create()
Erreur : Le paquetage $package n'implémente pas $method.
Erreur fatale : le paquetage spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où il le devrait. Ce message signifie que d'autres classes apparentées implémentent cette méthode, alors que la classe en question ne le fait pas. Vous devriez probablement enquêter sur cela et informer l'auteur du paquetage. Lancé par notImplemented()

    NAME

    DESCRIPTION

    This class implements the Base64 transfer encoding as defined in RFC 1521. It is used internally by the Mail::Message::Transfer module.

    This class should not be used directly by applications. Instead, applications should use the Mail::Message::Transfer module.

    This class does not export any methods. The methods are called by Mail::Message::Transfer.
