NOM

Mail::SpamAssassin::Pyzor - Filtrage de spam Pyzor en Perl

DESCRIPTION

Cette distribution contient des implémentations Perl de parties de Pyzor http://pyzor.org, un outil utilisé dans le filtrage des e-mails de spam. Elle est destinée à être utilisée avec Mail::SpamAssassin mais peut être utile dans d'autres contextes.

Consultez les modules suivants pour plus d'informations sur les outils spécifiques inclus dans la distribution :

  • Mail::SpamAssassin::Pyzor::Client
  • Mail::SpamAssassin::Pyzor::Digest
