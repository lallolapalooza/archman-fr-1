NOM

Mail::SpamAssassin::Util - fonctions utilitaires

DESCRIPTION

Une classe générale pour les fonctions utilitaires. Veuillez l'utiliser pour les fonctions qui sont autonomes, sans nécessiter un objet $self, en particulier les fonctions de portabilité.

NOTE : Les fonctions de ce module sont considérées comme privées. Leur API peut changer à tout moment, et il est attendu qu'elles ne soient utilisées que par d'autres modules Mail::SpamAssassin. (TODO : nous devrions probablement revoir cela si cela est utile pour le développement de plugins.)

NOTE : Les fonctions utilitaires ne doivent pas modifier les variables globales telles que $_, $1, $2, ... $/, etc., sauf si elles sont explicitement documentées. Si ces variables sont utilisées par ces fonctions, elles doivent être localisées.

$module = first_available_module (@module_list)
Retourne le nom du premier module qui peut être chargé avec succès avec "require" à partir de la liste. Retourne "undef" si aucun n'est disponible.

Ceci est utilisé à la place de "AnyDBM_File" comme suit :

my $module = Mail::SpamAssassin::Util::first_available_module
                      (qw(DB_File GDBM_File NDBM_File SDBM_File));
tie %hash, $module, $path, [... args];

Notez que "SDBM_File" est garanti d'être présent, car il est fourni avec Perl.

touch_file(file, { arguments });
Touchez ou créez un fichier.

Arguments possibles :

create_exclusive => 1
Crée un nouveau fichier vide en toute sécurité, uniquement s'il n'existait pas auparavant

my ($filepath, $filehandle) = secure_tmpfile();
Génère un nom de fichier pour un fichier temporaire, l'ouvre exclusivement et de manière sécurisée, et retourne un descripteur de fichier vers le fichier ouvert (ouvert en O_RDWR).

S'il ne parvient pas à ouvrir un fichier après 20 tentatives, il retourne "undef".

my ($dirpath) = secure_tmpdir();
Génère un répertoire pour les fichiers temporaires. Le crée de manière sécurisée et retourne le chemin d'accès au répertoire.

S'il ne parvient pas à créer un répertoire après 20 tentatives, il retourne "undef".
