NOM

Mail::Message::Head::ResentGroup - champs d'en-tête suivant la livraison du message

HÉRITAGE

Mail::Message::Head::ResentGroup
  est un Mail::Message::Head::FieldGroup
  est un Mail::Reporter

SYNOPSIS

use Mail::Message::Head::ResentGroup;
my $rg = Mail::Message::Head::ResentGroup->new(head => $head,
             From => 'me@home.nl', To => 'You@tux.aq');
$head->addResentGroup($rg);
my $rg = $head->addResentGroup(From => 'me');
my @from = $rg->From;
my @rgs = $head->resentGroups;
$rg[2]->delete if @rgs > 2;

DESCRIPTION

Un groupe de réexpédition est un ensemble de champs d'en-tête qui décrivent une étape intermédiaire dans le transport du message. Les groupes de réexpédition n'ont RIEN à voir avec l'activité de l'utilisateur ; il n'y a aucune relation avec le sens "de l'utilisateur" de création de messages de réponse, de transfert ou de renvoi !

Étendu de "DESCRIPTION" dans Mail::Message::Head::FieldGroup.

NOM

Mail::Message::Head::ResentGroup - groupe de champs pour les en-têtes de message resent

HÉRITAGE

Mail::Message::Head::ResentGroup hérite de Mail::Message::Head::FieldGroup et implémente Mail::Reporter.

SYNOPSIS

  use Mail::Message::Head::ResentGroup;

  my $rg = Mail::Message::Head::ResentGroup->new(head => $head);
  $rg->set(To => 'fish@tux.aq');
  $msg->addResentGroup($rg);

DESCRIPTION

Ce groupe de champs contient les informations sur l'en-tête resent. Il hérite de la fonctionnalité de gestion des champs de Mail::Message::Head::FieldGroup et ajoute des informations spécifiques aux champs resent.

Les champs qui sont définis par défaut dans un nouveau ResentGroup sont :

Resent-From
Pour qui ce message a été renvoyé. Défaut: l'expéditeur du message original.
Resent-Sender
L'adresse de l'expéditeur, par exemple dans le cas d'un agent de relais.
Resent-To
Le destinataire principal du renvoi.
Resent-Cc
Destinataire secondaire en copie carbone du renvoi.
Resent-Bcc
Destinataire caché en copie carbone du renvoi.
Resent-Date
La date à laquelle le message a été renvoyé.
Resent-Message-ID
Un identifiant unique pour ce message renvoyé.
Resent-Reply-To
L'adresse à laquelle les réponses doivent être envoyées.
Resent-Subject
Le sujet du message renvoyé.
Resent-Trace
Informations sur le chemin emprunté par le message renvoyé.
Received
Informations sur le système qui a reçu le message renvoyé.

Notez que les champs "Resent-Bcc" ne sont pas transmis aux destinataires externes, car ils sont destinés à rester confidentiels.

MÉTHODES

$obj->set( <$field, $value> | $object )
Définit un champ $field à une (nouvelle) valeur $value. Les noms de champs qui ne commencent pas par 'Resent-*' mais qui le nécessitent auront ce préfixe ajouté. Il est également possible de spécifier un champ de message entièrement préparé $object. Dans tous les cas, un champ $object est retourné.

» exemple:

my $rg = Mail::Message::Head::ResentGroup->new;
$rg->set(To => 'fish@tux.aq');
$msg->addResentGroup($rg);
$msg->send;
$msg->bounce(To => 'fish@tux.aq')->send;   # identique
my $rg = Mail::Message::Head::ResentGroup->new(To => 'fish@tux.aq');

DIAGNOSTICS

Erreur: En-tête de message requis pour la création de ResentGroup.
Il est requis de savoir à quel en-tête le groupe resent est créé. Utilisez l'option "head". Peut-être devriez-vous utiliser Mail::Message::Head::Complete::addResentGroup() avec DATA, qui organisera les initialisations correctes pour vous. Appel par new()
Erreur: Le package $package n'implémente pas $method.
Erreur fatale: le package spécifique (ou l'une de ses superclasses) n'implémente pas cette méthode là où il le devrait. Ce message signifie que d'autres classes liées implémentent cette méthode, mais pas la classe en question. Vous devriez probablement enquêter et peut-être informer l'auteur du package. Appel par notImplemented()
