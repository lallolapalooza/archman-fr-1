val add : key -> 'a -> 'a t -> 'a t

add cle donnee m renvoie une map contenant les mêmes associations que m , plus une association de cle à donnee . Si cle était déjà associée dans m à une valeur qui est physiquement égale à donnee , m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m ). Sinon, l'association précédente de cle dans m disparaît.

Avant4.03 L'égalité physique n'était pas garantie.

val add_to_list : key -> 'a -> 'a list t -> 'a list t

add_to_list cle donnee m est m avec cle associée à l tel que l est donnee :: Map.find cle m si cle était associée dans m et [donnee] sinon.

val update : key -> ('a option -> 'a option) -> 'a t -> 'a t

update cle f m renvoie une map contenant les mêmes associations que m , sauf pour l'association de cle . En fonction de la valeur de y où y est f (find_opt cle m) , l'association de cle est ajoutée, supprimée ou mise à jour. Si y est None , l'association est supprimée si elle existe ; sinon, si y est Some z alors cle est associée à z dans la map résultante. Si cle était déjà associée dans m à une valeur physiquement égale à z , m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m ).

val remove : key -> 'a t -> 'a t

remove x m renvoie une map contenant les mêmes associations que m , sauf pour x qui n'est plus associé dans la map retournée. Si x n'était pas dans m , m est retournée inchangée (le résultat de la fonction est alors physiquement égal à m ).

Avant4.03 L'égalité physique n'était pas garantie.

val merge : (key -> 'a option -> 'b option -> 'c option) -> 'a t -> 'b t -> 'c t

merge f m1 m2 calcule une map dont les clés sont un sous-ensemble des clés de m1 et de m2 . La présence de chaque association, et la valeur correspondante, est déterminée par la fonction f . En termes d'opération find_opt , on a find_opt x (merge f m1 m2) = f x (find_opt x m1) (find_opt x m2) pour toute clé x , à condition que f x None None = None .

Depuis 3.12

val union : (key -> 'a -> 'a -> 'a option) -> 'a t -> 'a t -> 'a t

union f m1 m2 calcule une map dont les clés sont un sous-ensemble des clés de m1 et de m2 . Lorsque la même association est définie dans les deux arguments, la fonction f est utilisée pour les combiner. C'est un cas particulier de merge : union f m1 m2 est équivalent à merge f' m1 m2 , où

- f' _key None None = None

- f' _key (Some v) None = Some v

- f' _key None (Some v) = Some v

- f' key (Some v1) (Some v2) = f key v1 v2

Recherche

val find : key -> 'a t -> 'a

find x m retourne la valeur actuelle de x dans m , ou lève Not_found si aucune association pour x n'existe.

val find_opt : key -> 'a t -> 'a option

find_opt x m retourne Some v si la valeur actuelle de x dans m est v , ou None si aucune association pour x n'existe.

Depuis 4.05

val find_first : (key -> bool) -> 'a t -> key * 'a

find_first f m , où f est une fonction monotone croissante, retourne l'association de m avec la plus petite clé k telle que f k , ou lève Not_found si aucune clé de ce type n'existe.

Par exemple, find_first (fun k -> Ord.compare k x >= 0) m retournera la première association k, v de m où Ord.compare k x >= 0 (intuitivement : k >= x ), ou lèvera Not_found si x est plus grand que n'importe quel élément de m .

Depuis 4.05

val find_first_opt : (key -> bool) -> 'a t -> (key * 'a) option

find_first_opt f m , où f est une fonction monotone croissante, retourne une option contenant l'association de m avec la plus petite clé k telle que f k , ou None si aucune clé de ce type n'existe.
