Mail::SpamAssassin::PersistentAddrList(3) Documentation Perl fournie par l'utilisateur Mail::SpamAssassin::PersistentAddrList(3)

NOM

Mail::SpamAssassin::PersistentAddrList - classe de base pour les listes d'adresses persistantes

SYNOPIS

my $factory = PersistentAddrListSubclass->new();
$spamtest->set_persistent_addr_list_factory ($factory);
... appel aux classes SpamAssassin...

SpamAssassin appellera :

my $addrlist = $factory->new_checker($spamtest);
$entry = $addrlist->get_addr_entry ($addr);
...

DESCRIPTION

Toutes les implémentations de listes d'adresses persistantes, utilisées par le code auto-welcomelist pour suivre les adresses e-mail connues comme sûres, utilisent celle-ci comme classe de base.

Voir "Mail::SpamAssassin::DBBasedAddrList" pour un exemple.

MÉTHODES

$factory = PersistentAddrListSubclass->new();
Ceci crée un objet fabrique, que SpamAssassin appellera pour créer un nouvel objet vérificateur pour la liste d'adresses persistante.
mon $addrlist = $factory->new_checker();
Crée un nouvel objet vérificateur de liste d'adresses à partir de la fabrique. Appelée par les classes SpamAssassin.
$entry = $addrlist->get_addr_entry ($addr);
Étant donnée une adresse e-mail $addr, retourne un objet entrée avec les détails de cette adresse.

L'objet entrée est une référence vers une table de hachage, qui doit contenir au moins deux clés : "count", qui est le nombre de fois où cette adresse a été rencontrée auparavant ; et "totscore", qui est la somme de tous les scores des messages associés à cette adresse. À partir de ces deux champs, un score moyen sera calculé, et le score du message actuel sera régressé vers ce score moyen de message.

La table de hachage peut contenir d'autres données que votre backend a besoin de stocker, sous d'autres clés.

La méthode ne doit jamais retourner "undef", ni une table de hachage qui ne contient pas de clé "count" et de clé "totscore".

$entry = $addrlist->add_score($entry, $score);
Cette méthode doit ajouter le score donné à la base de données de la liste de bienvenue pour l'entrée donnée, puis retourner la nouvelle entrée.
$entry = $addrlist->remove_entry ($entry);
Cette méthode doit supprimer l'entrée donnée de la base de données de la liste de bienvenue.
$entry = $addrlist->finish ();
Nettoie, si nécessaire. Appelée par SpamAssassin lorsqu'il a fini de vérifier ou d'ajouter à la base de données de la liste de bienvenue automatique.
