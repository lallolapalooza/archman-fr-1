Mail::SpamAssassin::Plugin::ExtractText(3) Documentation Perl contribuée par l'utilisateur Mail::SpamAssassin::Plugin::ExtractText(3)

NOM

ExtractText - extrait le texte des documents.

SYNOPIS

loadplugin Mail::SpamAssassin::Plugin::ExtractText

ifplugin Mail::SpamAssassin::Plugin::ExtractText

extracttext_external  pdftotext  /usr/bin/pdftotext -nopgbrk -layout -enc UTF-8 {} -
extracttext_use       pdftotext  .pdf application/pdf
# http://docx2txt.sourceforge.net
extracttext_external  docx2txt   /usr/bin/docx2txt {} -
extracttext_use       docx2txt   .docx application/docx
extracttext_external  antiword   /usr/bin/antiword -t -w 0 -m UTF-8.txt {}
extracttext_use       antiword   .doc application/(?:vnd\.?)?ms-?word.*
extracttext_external  unrtf      /usr/bin/unrtf --nopict {}
extracttext_use       unrtf      .doc .rtf application/rtf text/rtf
extracttext_external  odt2txt    /usr/bin/odt2txt --encoding=UTF-8 {}
extracttext_use       odt2txt    .odt .ott application/.*?opendocument.*text
extracttext_use       odt2txt    .sdw .stw application/(?:x-)?soffice application/(?:x-)?starwriter
extracttext_external  tesseract  {OMP_THREAD_LIMIT=1} /usr/bin/tesseract -c page_separator= {} -
extracttext_use       tesseract  .jpg .png .bmp .tif .tiff image/(?:jpeg|png|x-ms-bmp|tiff)
# Décodeur QR-code
extracttext_external  zbar       /usr/bin/zbarimg -q -D {}
extracttext_use       zbar       .jpg .png .pdf image/(?:jpeg|png) application/pdf
add_header   all          ExtractText-Flags _EXTRACTTEXTFLAGS_
header       PDF_NO_TEXT  X-ExtractText-Flags =~ /\bpdftotext_NoText\b/
describe     PDF_NO_TEXT  PDF sans texte
score        PDF_NO_TEXT  0.001
header       DOC_NO_TEXT  X-ExtractText-Flags =~ /\b(?:antiword|openxml|unrtf|odt2txt)_NoText\b/
describe     DOC_NO_TEXT  Document sans texte
score        DOC_NO_TEXT  0.001
header       EXTRACTTEXT  exists:X-ExtractText-Flags
describe     EXTRACTTEXT  Email traité par le plugin extracttext
score        EXTRACTTEXT  0.001

endif

DESCRIPTION

Ce module utilise des outils externes pour extraire le texte des parties de message, puis définit ce texte comme partie rendue. Les outils externes doivent produire du texte brut, pas du HTML ou d'autres formats non textuels.

La manière d'extraire le texte est entièrement configurable et basée sur le type de partie MIME et le nom du fichier.

CONFIGURATION

Toutes les lignes de configuration dans les fichiers user_prefs seront ignorées.

extracttext_maxparts (défaut : 10)
Configure le nombre maximum de parties MIME à analyser, une valeur de 0 signifie que toutes les parties MIME seront analysées.
extracttext_timeout (défaut : 5 10)
Configure le délai d'attente en secondes pour les vérifications des outils externes, par pièce jointe.

Le second argument spécifie le temps total maximum pour toutes les vérifications.

Outils

extracttext_use
Spécifie quel outil utiliser pour quelles parties de message.

La syntaxe générale est

extracttext_use "nom" "spécificateurs"

nom
le nom interne d'un outil.
spécificateurs
Extension de fichier et expressions régulières pour les noms de fichiers et les types MIME. Les expressions régulières sont ancrées au début et à la fin.

Exemples

extracttext_use  antiword  .doc application/(?:vnd\.?)?ms-?word.*
extracttext_use  openxml   .docx .dotx .dotm application/(?:vnd\.?)openxml.*?word.*
extracttext_use  openxml   .doc .dot application/(?:vnd\.?)?ms-?word.*
extracttext_use  unrtf     .doc .rtf application/rtf text/rtf
extracttext_external
Définit un outil externe. L'outil doit lire un document sur l'entrée standard ou à partir d'un fichier et écrire le texte sur la sortie standard.

Le mot-clé spécial "{}" sera substitué au moment de l'exécution par le nom de fichier temporaire à analyser par l'outil externe.

Les variables d'environnement peuvent être définies avec "{CLE=VALEUR}", ces chaînes seront supprimées de la ligne de commande.

Il est requis que la ligne de commande utilisée produise le résultat directement sur STDOUT.

La syntaxe générale est

extracttext_external "nom" "commande" "paramètres"

nom
Le nom interne de cet outil.
commande
Le chemin complet vers la commande externe à exécuter.
paramètres
Paramètres pour la commande externe. Le nom du fichier temporaire contenant le document sera automatiquement ajouté comme dernier paramètre.

Exemples

extracttext_external  antiword  /usr/bin/antiword -t -w 0 -m UTF-8.txt {} -
extracttext_external  unrtf     /usr/bin/unrtf --nopict {}
extracttext_external  odt2txt   /usr/bin/odt2txt --encoding=UTF-8 {}

Métadonnées

Le plugin ajoute des pseudo-en-têtes au message. Ces en-têtes sont vus par le système bayésien et peuvent être utilisés dans les règles normales de SpamAssassin.

Les en-têtes sont également disponibles en tant que tags de modèle comme indiqué ci-dessous.

Exemple

Les en-têtes d'exemple fictifs ci-dessous sont basés sur un message contenant ceci :

1 Un PDF parfaitement normal.
2 Un document OpenXML avec un document Word à l'intérieur. Aucun des deux documents Office ne contient de texte.

En-têtes

X-ExtractText-Chars
Tag : _EXTRACTTEXTCHARS_

Contient un décompte des caractères qui ont été extraits.

X-ExtractText-Chars : 10970

X-ExtractText-Words
Tag : _EXTRACTTEXTWORDS_

Contient un décompte des « mots » qui ont été extraits.

X-ExtractText-Chars : 1599

X-ExtractText-Tools
Tag : _EXTRACTTEXTTOOLS_

Contient les chaînes d'outils utilisées pour l'extraction.

X-ExtractText-Tools : pdftotext openxml_antiword

X-ExtractText-Types
Tag : _EXTRACTTEXTTYPES_

Contient les chaînes de types MIME pour les parties trouvées lors de l'extraction.

X-ExtractText-Types : application/pdf ; application/vnd.openxmlformats-officedocument.wordprocessingml.document, application/ms-word

X-ExtractText-Extensions
Tag : _EXTRACTTEXTEXTENSIONS_

Contient les chaînes d'extensions de fichiers canonisées pour les parties trouvées lors de l'extraction.

X-ExtractText-Extensions : pdf docx

X-ExtractText-Flags
Tag : _EXTRACTTEXTFLAGS_

Contient des notes du plugin.

X-ExtractText-Flags : openxml_NoText

X-ExtractText-Uris
Tag : _EXTRACTTEXTURIS_

Contient les URI extraits du plugin.

X-ExtractText-Uris : https://spamassassin.apache.org

Règles

Exemple :

header    PDF_NO_TEXT  X-ExtractText-Flags =~ /\bpdftotext_Notext\b/
describe  PDF_NO_TEXT  PDF sans texte
