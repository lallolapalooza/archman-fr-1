MrmRegisterClass(3) MrmRegisterClass(appel de bibliothèque)

NOM

MrmRegisterClass — Sauvegarde les informations nécessaires à MRM pour accéder à la fonction de création de widget pour les widgets définis par l'utilisateur

SYNTAXE

#include <Mrm/MrmPublic.h>
Cardinal MrmRegisterClass(
MrmType class_code,
String class_name,
String create_name,
Widget (*create_proc) (),
WidgetClass class_record);

DESCRIPTION

La fonction MrmRegisterClass permet à MRM d'accéder aux classes de widgets définies par l'utilisateur. Cette fonction enregistre les informations nécessaires à MRM pour créer des widgets de cette classe. Vous devez appeler MrmRegisterClass avant de récupérer des widgets de classe définie par l'utilisateur.

MrmRegisterClass sauvegarde les informations nécessaires pour accéder à la fonction de création de widget et pour convertir les types des listes d'arguments en utilisant les informations des bases de données MRM.

code_classe
Cet argument est ignoré ; il est présent pour la compatibilité avec les versions précédentes.
nom_classe
Cet argument est ignoré ; il est présent pour la compatibilité avec les versions précédentes.
nom_creation
Spécifie le nom sensible à la casse de la fonction de création de widget de bas niveau pour la classe. Un exemple de la boîte à outils Motif est XmCreateLabel. Les arguments sont parent_widget, name, override_arglist et override_argcount.
Pour les widgets définis par l'utilisateur, nom_creation est la procédure de création dans l'UIL qui définit ce widget.
proc_creation
Spécifie l'adresse de la fonction de création que vous avez nommée dans nom_creation.
enregistrement_classe
Spécifie un pointeur vers l'enregistrement de la classe.

VALEUR DE RETOUR

Cette fonction retourne l'une des constantes de retour de statut suivantes :

MrmSUCCESS
La fonction s'est exécutée avec succès.
MrmFAILURE
La fonction a échoué.
