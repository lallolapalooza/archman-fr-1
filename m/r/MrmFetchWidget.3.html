NOM

MrmFetchWidget — Récupère et crée un widget d'application indexé (nommé UIL) et ses enfants

SYNTAXE

#include <Mrm/MrmPublic.h>
Cardinal MrmFetchWidget(
MrmHierarchy hierarchy_id,
String index,
Widget parent_widget,
Widget *widget,
MrmType *class);

DESCRIPTION

La fonction MrmFetchWidget récupère et crée un widget d'application indexé et ses enfants. Le widget d'application indexé est tout widget nommé dans UIL. Dans les opérations de récupération, la sous-arborescence du widget récupéré est également récupérée et créée. Ce widget ne doit pas apparaître comme enfant d'un widget au sein de sa propre sous-arborescence. MrmFetchWidget n'exécute pas XtManageChild pour le widget nouvellement créé.

Tous les widgets récupérés par un appel à MrmFetchWidget ne sont pas gérés au moment de leurs rappels de création.

hierarchy_id
Spécifie l'ID de la hiérarchie UID qui contient la définition de l'interface. La valeur de hierarchy_id a été retournée lors d'un appel précédent à MrmOpenHierarchyPerDisplay.
index
Spécifie le nom UIL du widget à récupérer.
parent_widget
Spécifie l'ID du widget parent.
widget
Retourne l'ID du widget créé.
class
Cet argument doit être défini sur un pointeur réel ; il ne peut pas s'agir d'un pointeur NULL. MrmFetchWidget définit cet argument sur une valeur dépendant de l'implémentation.

Une application peut récupérer n'importe quel widget nommé dans la hiérarchie UID en utilisant MrmFetchWidget. MrmFetchWidget peut être appelée à tout moment pour récupérer un widget qui n'a pas été récupéré au démarrage de l'application. MrmFetchWidget peut être utilisée pour différer la récupération des widgets contextuels jusqu'à ce qu'ils soient référencés pour la première fois (vraisemblablement dans un rappel), puis pour les récupérer une seule fois.

MrmFetchWidget peut également créer plusieurs instances d'un widget (et de sa sous-arborescence). Dans ce cas, la définition UID sert de modèle ; une définition de widget peut être récupérée un nombre quelconque de fois. Une application peut utiliser ce modèle pour créer plusieurs instances d'un widget, par exemple, dans une boîte de dialogue ou un menu.

L'index (nom UIL) qui identifie le widget doit être connu de l'application.

RETOUR

Cette fonction retourne l'une des constantes de retour d'état suivantes :

MrmSUCCESS
La fonction s'est exécutée avec succès.
MrmBAD_HIERARCHY
L'ID de la hiérarchie était invalide.
MrmNOT_FOUND
Le widget n'a pas été trouvé dans la hiérarchie UID.
MrmFAILURE
La fonction a échoué.

VOIR AUSSI

MrmOpenHierarchyPerDisplay(3), MrmFetchWidgetOverride(3).
