NOM

MrmInitialize — Prépare une application à utiliser les installations de récupération de widgets MRM

SYNTAXE

void MrmInitialize(void)

DESCRIPTION

La fonction MrmInitialize doit être appelée pour préparer une application à utiliser les installations de récupération de widgets MRM. Vous devez appeler cette fonction avant de récupérer un widget. Cependant, il est de bonne pratique de programmation d'appeler MrmInitialize avant d'effectuer toute opération MRM.

MrmInitialize initialise les structures de données internes dont MRM a besoin pour effectuer avec succès la conversion de type des arguments et pour accéder avec succès aux installations de création de widgets. Une application doit appeler MrmInitialize avant d'utiliser d'autres fonctions MRM.
