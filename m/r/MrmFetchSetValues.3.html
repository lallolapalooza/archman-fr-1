MrmFetchSetValues(appel de bibliothèque) MrmFetchSetValues(appel de bibliothèque)

NOM

MrmFetchSetValues — Récupère les valeurs à définir à partir des littéraux stockés dans les fichiers UID

SYNTAXE

#include <Mrm/MrmPublic.h>
Cardinal MrmFetchSetValues(
MrmHierarchy hierarchy_id,
Widget widget,
ArgList args,
Cardinal num_args);

DESCRIPTION

La fonction MrmFetchSetValues est similaire à XtSetValues, à la différence près que les valeurs à définir sont définies par les valeurs nommées UIL qui sont stockées dans la hiérarchie UID. MrmFetchSetValues récupère les valeurs à définir à partir des littéraux stockés dans les fichiers UID.

hierarchy_id
Spécifie l'ID de la hiérarchie UID qui contient le littéral spécifié. La valeur de hierarchy_id a été retournée lors d'un appel précédent à MrmOpenHierarchyPerDisplay.
widget
Spécifie le widget qui est modifié.
args
Spécifie une liste d'arguments qui identifie les arguments du widget à modifier ainsi que l'index (nom UIL) du littéral qui définit la valeur pour cet argument. La partie nom de chaque argument (args[n].name) doit commencer par la chaîne XmN suivie du nom qui identifie de manière unique cette balise d'attribut. Par exemple, XmNwidth est le nom d'attribut associé à l'argument cœur width. La partie valeur (args[n].value) doit être une chaîne qui donne l'index (nom UIL) du littéral. Vous devez définir tous les littéraux en UIL comme des valeurs exportées.
num_args
Spécifie le nombre d'entrées dans args.

Cette fonction définit les valeurs sur un widget, en évaluant les valeurs comme des références publiques de ressources littérales résolubles à partir d'une hiérarchie UID. Chaque littéral est récupéré de la hiérarchie, et sa valeur est modifiée et convertie si nécessaire. Cette valeur est ensuite placée dans la liste d'arguments et utilisée comme valeur réelle pour un appel à XtSetValues. MrmFetchSetValues permet de modifier un widget après sa création en utilisant les valeurs des fichiers UID, de la même manière que les valeurs de création sont utilisées dans MrmFetchWidget.

Comme dans MrmFetchWidget, chaque argument dont la valeur peut être évaluée à partir de la hiérarchie UID est défini dans le widget. Les valeurs qui ne sont pas trouvées ou les valeurs pour lesquelles des erreurs de conversion se produisent ne sont pas modifiées.

Chaque entrée de la liste d'arguments identifie un argument à modifier dans le widget. La partie nom identifie la balise, qui commence par XmN. La partie valeur doit être une chaîne dont la valeur est l'index du littéral. Ainsi, le code suivant modifierait la ressource de libellé du widget pour qu'elle ait la valeur du littéral accédé par l'index OK_button_label dans la hiérarchie :

args[n].name = XmNlabel;
args[n].value = "OK_button_label";

VALEUR DE RETOUR

Cette fonction retourne l'une des constantes de retour de statut suivantes :

MrmSUCCESS
La fonction s'est exécutée avec succès.
MrmPARTIAL_SUCCESS
Au moins un littéral a été récupéré avec succès.
MrmBAD_HIERARCHY
L'ID de la hiérarchie était invalide.
MrmFAILURE
La fonction a échoué.

VOIR AUSSI

MrmOpenHierarchyPerDisplay(3), XtSetValues(3).
