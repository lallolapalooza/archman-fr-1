MrmRegisterNames(appel de bibliothèque) MrmRegisterNames(appel de bibliothèque)

NOM

MrmRegisterNames — Enregistre les valeurs associées aux noms référencés dans UIL (par exemple, les noms de fonctions de rappel UIL ou les noms d'identifiants UIL)

SYNTAXE

#include <Mrm/MrmPublic.h>
Cardinal MrmRegisterNames(
MrmRegisterArglist register_list,
MrmCount register_count);

DESCRIPTION

La fonction MrmRegisterNames enregistre un vecteur de noms et de valeurs associées pour l'accès dans MRM. Les valeurs peuvent être des fonctions de rappel, des pointeurs vers des données définies par l'utilisateur, ou toute autre valeur. Les informations fournies sont utilisées pour résoudre les références symboliques apparaissant dans les fichiers UID à leurs valeurs d'exécution. Pour les fonctions de rappel, ces informations fournissent l'adresse de procédure requise par le Motif Toolkit. Pour les noms utilisés comme identifiants dans UIL, ces informations fournissent toute la correspondance d'exécution dont l'application a besoin.

Cette fonction est similaire à MrmRegisterNamesInHierarchy, sauf que la portée des noms enregistrés par MrmRegisterNamesInHierarchy est limitée à la hiérarchie spécifiée dans l'appel à cette fonction, tandis que les noms enregistrés par MrmRegisterNames ont une portée globale. Lorsque MRM recherche un nom, il essaie d'abord de trouver le nom parmi ceux enregistrés pour la hiérarchie donnée. Si cette recherche échoue, il essaie de trouver le nom parmi ceux enregistrés globalement.

register_list
Spécifie une liste de paires nom/valeur pour les noms à enregistrer. Chaque nom est une chaîne ASCII terminée par NULL, sensible à la casse. Chaque valeur est une quantité de 32 bits, interprétée comme une adresse de procédure si le nom est une fonction de rappel, et non interprétée autrement.
register_count
Spécifie le nombre d'entrées dans register_list.

Les noms de la liste sont sensibles à la casse. La liste peut être ordonnée ou non ordonnée.

Les fonctions de rappel enregistrées via MrmRegisterNames peuvent être des fonctions de rappel régulières ou des fonctions de rappel de création. Les fonctions de rappel régulières ont des déclarations déterminées par le Motif Toolkit et les exigences de l'utilisateur. Les fonctions de rappel de création ont le même format que toute autre fonction de rappel :

void CallBackProc(
Widget *widget_id,
Opaque tag,
XmAnyCallbackStruct *callback_data);
widget_id
Spécifie l'identifiant du widget associé au widget effectuant le rappel (comme dans toute fonction de rappel).
tag
Spécifie la valeur du tag (comme dans toute fonction de rappel).
callback_data
Spécifie une structure de données spécifique au widget. Cette structure de données comporte au minimum deux membres : event et reason. Le membre reason est toujours défini sur MrmCR_CREATE.

Notez que le nom du widget et son parent sont disponibles à partir de l'enregistrement du widget accessible via widget_id.

RETOUR

Cette fonction renvoie l'une des constantes de retour de statut suivantes :

MrmSUCCESS
La fonction s'est exécutée avec succès.
MrmFAILURE
La fonction a échoué.
