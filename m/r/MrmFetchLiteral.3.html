NOM

MrmFetchLiteral — Récupère une valeur littérale d'un fichier UID

SYNTAXE

#include <Mrm/MrmPublic.h>
Cardinal MrmFetchLiteral(
MrmHierarchy hierarchy_id,
String index,
Display *display,
XtPointer *value,
MrmCode *type);

DESCRIPTION

La fonction MrmFetchLiteral lit et renvoie la valeur et le type d'une valeur littérale (valeur nommée) qui est stockée comme ressource publique dans un seul fichier UID. Cette fonction renvoie un pointeur vers la valeur de la valeur littérale. Par exemple, un entier est toujours renvoyé comme un pointeur vers un entier, et une chaîne de caractères est toujours renvoyée comme un pointeur vers une chaîne de caractères.

Les applications ne doivent pas utiliser MrmFetchLiteral pour récupérer des valeurs littérales d'icônes ou de couleurs. Si cela est tenté, MrmFetchLiteral renvoie une erreur.

hierarchy_id
Spécifie l'identifiant de la hiérarchie UID qui contient la valeur littérale spécifiée. La valeur de hierarchy_id a été renvoyée lors d'un appel précédent à MrmOpenHierarchyPerDisplay.
index
Spécifie le nom UIL de la valeur littérale (pixmap) à récupérer. Vous devez définir ce nom dans UIL comme une valeur exportée.
display
Spécifie l'affichage utilisé pour la pixmap. L'argument display spécifie la connexion au serveur X. Pour plus d'informations sur la structure Display, consultez la fonction Xlib XOpenDisplay.
value
Renvoie l'identifiant de la valeur de la valeur littérale nommée. La fonction alloue de l'espace pour la valeur renvoyée. L'application est responsable de la gestion de l'espace alloué en appelant la fonction de désallocation appropriée. Par exemple, si l'identifiant renvoyé symbolise une pixmap, alors l'application peut récupérer l'espace alloué en appelant XmDestroyPixmap.
type
Renvoie le type de données de la valeur littérale nommée. Les types sont définis dans le fichier d'inclusion Mrm/MrmPublic.h.

RETOUR

Cette fonction renvoie l'une des constantes de retour d'état suivantes :

MrmSUCCESS
La fonction s'est exécutée avec succès.
MrmBAD_HIERARCHY
L'identifiant de la hiérarchie était invalide.
MrmNOT_FOUND
La valeur littérale n'a pas été trouvée dans le fichier UIL.
MrmWRONG_TYPE
L'appelant a essayé de récupérer une valeur littérale d'un type non pris en charge par cette fonction.
MrmFAILURE
La fonction a échoué.

VOIR AUSSI

MrmFetchBitmapLiteral(3), MrmOpenHierarchyPerDisplay(3), MrmFetchIconLiteral(3), MrmFetchColorLiteral(3), et XOpenDisplay(3).
