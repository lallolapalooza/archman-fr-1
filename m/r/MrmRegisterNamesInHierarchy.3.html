MrmRegisterNamesInHierarchy(appel de bibliothèque) MrmRegisterNamesInHierarchy(appel de bibliothèque)

NOM

MrmRegisterNamesInHierarchy — Enregistre les valeurs associées aux noms référencés dans UIL au sein d'une seule hiérarchie (par exemple, noms de fonctions de rappel UIL ou noms d'identifiants UIL)

SYNTAXE

#include <Mrm/MrmPublic.h>
Cardinal MrmRegisterNamesInHierarchy(
MrmHierarchy hierarchy_id,
MrmRegisterArglist register_list,
MrmCount register_count);

DESCRIPTION

La fonction MrmRegisterNamesInHierarchy enregistre un vecteur de noms et de valeurs associées pour un accès dans MRM. Les valeurs peuvent être des fonctions de rappel, des pointeurs vers des données définies par l'utilisateur, ou toute autre valeur. Les informations fournies sont utilisées pour résoudre les références symboliques apparaissant dans les fichiers UID vers leurs valeurs d'exécution. Pour les rappels, ces informations fournissent l'adresse de procédure requise par le toolkit Motif. Pour les noms utilisés comme identifiants dans UIL, ces informations fournissent toute mise en correspondance d'exécution dont l'application a besoin.

Cette fonction est similaire à MrmRegisterNames, sauf que la portée des noms enregistrés par MrmRegisterNamesInHierarchy est limitée à la hiérarchie spécifiée par hierarchy_id, alors que les noms enregistrés par MrmRegisterNames ont une portée globale. Lorsque MRM recherche un nom, il essaie d'abord de trouver le nom parmi ceux enregistrés pour la hiérarchie donnée. Si cette recherche échoue, il essaie de trouver le nom parmi ceux enregistrés globalement.

hierarchy_id
Spécifie la hiérarchie à laquelle les noms doivent être associés.
register_list
Spécifie une liste de paires nom/valeur pour les noms à enregistrer. Chaque nom est une chaîne ASCII sensible à la casse et terminée par NULL. Chaque valeur est une quantité de 32 bits, interprétée comme une adresse de procédure si le nom est une fonction de rappel, et non interprétée sinon.
register_count
Spécifie le nombre d'entrées dans register_list.

Les noms de la liste sont sensibles à la casse. La liste peut être ordonnée ou non ordonnée.

Les fonctions de rappel enregistrées via MrmRegisterNamesInHierarchy peuvent être des rappels réguliers ou de création. Les rappels réguliers ont des déclarations déterminées par le toolkit Motif et les exigences de l'utilisateur. Les rappels de création ont le même format que tout autre rappel :

void CallBackProc(
Widget *widget_id,
Opaque tag,
XmAnyCallbackStruct *callback_data);
widget_id
Spécifie l'identifiant du widget associé au widget effectuant le rappel (comme dans toute fonction de rappel).
tag
Spécifie la valeur de la balise (comme dans toute fonction de rappel).
callback_data
Spécifie une structure de données spécifique au widget. Cette structure de données possède un minimum de deux membres : event et reason. Le membre reason est toujours défini à MrmCR_CREATE.

Notez que le nom du widget et le parent sont disponibles à partir de l'enregistrement du widget accessible via widget_id.

VALEUR DE RETOUR

Cette fonction retourne l'une des constantes de retour de statut suivantes :

MrmSUCCESS
La fonction s'est exécutée avec succès.
MrmFAILURE
La fonction a échoué.
