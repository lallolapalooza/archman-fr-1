DESCRIPTION

La bibliothèque libmaxminddb fournit des fonctions pour travailler avec les fichiers MaxMind DB. Voir https://maxmind.github.io/MaxMind-DB/ pour la spécification du format MaxMind DB. La base de données et les résultats sont tous représentés par différentes structures de données. Les bases de données sont ouvertes en appelant MMDB_open(). Vous pouvez rechercher des adresses IP sous forme de chaîne de caractères avec MMDB_lookup_string() ou sous forme de pointeur vers une structure sockaddr avec MMDB_lookup_sockaddr().

Si la recherche trouve l'adresse IP dans la base de données, elle retourne une structure MMDB_lookup_result_s. Si cette structure indique que la base de données a des données pour l'IP, il existe un certain nombre de fonctions qui peuvent être utilisées pour récupérer ces données. Celles-ci incluent MMDB_get_value() et MMDB_get_entry_data_list(). Voir la documentation de la fonction ci-dessous pour plus de détails.

Lorsque vous avez terminé avec le descripteur de base de données, vous devez appeler MMDB_close().

Toutes les fonctions, structures et macros publiquement visibles commencent par "MMDB_".

STRUCTURES DE DONNÉES

Toutes les structures de données exportées par l'en-tête maxminddb.h de cette bibliothèque sont typées sous la forme typedef struct foo_s { ... } foo_s de sorte que vous puissiez vous y référer sans le préfixe struct.

Cette bibliothèque fournit les structures de données suivantes :

MMDB_s

C'est le descripteur d'un fichier MaxMind DB. Nous ne documentons que certains des champs de cette structure destinés à un usage public. Tous les autres champs sont sujets à modification et sont destinés uniquement à un usage interne.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - les indicateurs avec lesquels cette base de données a été ouverte. Voir la documentation de MMDB_open() pour plus de détails.
  • const char *filename - le nom du fichier qui a été ouvert, tel que passé à MMDB_open().
  • MMDB_metadata_s metadata - les métadonnées de la base de données.

MMDB_metadata_s et MMDB_description_s

Cette structure peut être récupérée à partir de la structure MMDB_s. Elle contient les métadonnées lues à partir du fichier de base de données. Notez qu'il peut être plus pratique d'accéder à ces métadonnées en appelant MMDB_get_metadata_as_entry_data_list() à la place.

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Ces structures devraient être largement auto-explicatives.

Le membre ip_version devrait toujours être 4 ou 6. Le membre binary_format_major_version devrait toujours être 2.

Il n'est pas obligatoire que les métadonnées de la base de données incluent des langues ou des descriptions, donc le count pour ces parties des métadonnées peut être zéro. Tous les autres champs de MMDB_metadata_s devraient être renseignés.

MMDB_lookup_result_s

Cette structure est retournée comme résultat de la recherche d'une adresse IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si le membre found_entry est faux, alors les autres membres de cette structure ne contiennent pas de valeurs significatives. Vérifiez toujours que found_entry est vrai en premier.

Le membre entry est utilisé pour rechercher les données associées à l'adresse IP.

Le membre netmask vous indique à quel sous-réseau appartient l'adresse IP dans cette base de données. Par exemple, si vous recherchez l'adresse 1.1.1.1 dans une base de données IPv4 et que le netmask retourné est 16, alors l'adresse fait partie du sous-réseau 1.1.0.0/16.

Si la base de données est une base de données IPv6, le masque de réseau retourné est toujours une longueur de préfixe IPv6 (de 0 à 128), même si cette base de données contient *également* des réseaux IPv4. Si vous recherchez une adresse IPv4 et souhaitez convertir le masque de réseau en une valeur de masque de réseau IPv4, vous pouvez simplement soustraire 96 de la valeur.

MMDB_result_s

Vous n'avez pas vraiment besoin de fouiller dans cette structure. Vous l'obtiendrez à partir d'une structure MMDB_lookup_result_s et la passerez à diverses fonctions.

MMDB_entry_data_s

Cette structure est utilisée pour retourner une seule entrée de section de données pour une IP. Ces entrées peuvent à leur tour pointer vers d'autres entrées, comme c'est le cas pour les cartes et les tableaux. Certains membres de cette structure ne sont pas documentés car ils sont réservés à un usage interne.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t ou uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

Le membre has_data est vrai si des données ont été trouvées pour une recherche donnée. Voir MMDB_get_value() pour plus de détails. Si ce membre est faux, alors aucune des autres valeurs de la structure n'est significative.

Mantén toda la estructura del archivo.

Si un miembro es poblado, debes examinar el miembro type. El miembro pointer de la unión no debe nunca ser poblado en ningún dato devuelto por la API. Los punteros deben ser resueltos internamente.

El miembro data_size es solo relevante para los datos de tipo utf8_string y bytes. utf8_string no está terminado con NULL y data_size debe usarse para determinar su longitud.

El miembro type puede compararse con uno de los macros MMDB_DATA_TYPE_*.

Entiers 128 bits

El manejo de datos de tipo uint128 depende de cómo tu plataforma soporta enteros de 128 bits, si lo hace o no. Con GCC 4.4 y 4.5 podemos escribir unsigned int __attribute__ ((__mode__ (TI))). Con versiones más recientes de GCC (4.6+) y Clang (3.2+) podemos simplemente escribir "unsigned __int128".

Para trabajar alrededor de estas diferencias, esta librería define un tipo mmdb_uint128_t. Este tipo está definido en el encabezado maxminddb.h para que puedas usarlo en tu código propio.

Con compiladores más antiguos, no podemos usar un entero, por lo que usamos un array de 16 bytes de uint8_t. Esto es el dato directo de la base de datos.

Esta librería proporciona una macro pública MMDB_UINT128_IS_BYTE_ARRAY. Si esta es verdadera (1), los valores de uint128 se devuelven como un array de bytes, si no, como un entero mmdb_uint128_t.

Macros de Tipo de Dato

Esta librería proporciona una macro para cada tipo de dato definido por la especificación de MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

También hay algunos tipos que son únicamente para uso interno:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

Si ves uno de estos en los datos devueltos, algo ha estado muy mal. La base de datos está dañada o fue generada incorrectamente o hay un error en el código de libmaxminddb.

Valores de Puntero y MMDB_close()

Los miembros utf8_string, bytes y (posiblemente) el miembro uint128 de esta estructura son todos punteros directamente a la sección de datos de la base de datos. Esto puede ser un bloque de memoria calloc o mmap. En cualquier caso, estos punteros se vuelven inválidos después de llamarse a MMDB_close().

Si necesitas referirte a estos datos después de ese tiempo, debes copiar los datos con una función adecuada (strdup, memcpy, etc.).

MMDB_entry_data_list_s

Esta estructura encapsula una lista enlazada de estructuras MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

Esta estructura te permite examinar datos de mapa o array mediante iteración sobre la lista enlazada.

MMDB_search_node_s

Esta estructura encapsula los dos registros de un nodo de búsqueda. Esto es realmente útil si quieres escribir código que itera sobre todo el árbol de búsqueda en lugar de buscar un IP específico.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

Los tipos de registro serán uno de los siguientes valores:

  • MMDB_RECORD_TYPE_SEARCH_NODE - El registro apunta al siguiente nodo de búsqueda.
  • MMDB_RECORD_TYPE_EMPTY - El registro es un marcador de posición que indica que no hay datos para el IP. La búsqueda debe terminar aquí.
  • MMDB_RECORD_TYPE_DATA - El registro contiene datos en la sección de datos de la base de datos. Usa el registro cuando busques los datos del registro.
  • MMDB_RECORD_TYPE_INVALID - El registro es inválido. La razón puede ser un nodo inválido buscado o la base de datos dañada.

El MMDB_entry_s del registro es válido solo si el tipo es MMDB_RECORD_TYPE_DATA. El uso de un registro de otros tipos genera un error o datos inválidos.

CÓDIGOS DE ESTADO

Esta librería devuelve (o popula) códigos de estado para muchas funciones. Estos códigos de estado son:

  • MMDB_SUCCESS - todo funcionó.
  • MMDB_FILE_OPEN_ERROR - hubo un error al abrir el archivo MaxMind DB.
  • MMDB_IO_ERROR - una operación de entrada/salida falló. Verifica errno para más detalles.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - al buscar un IP en el árbol de búsqueda se obtuvo un resultado imposible. La base de datos está dañada o fue generada incorrectamente o hay un error en el código de libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - algo en la base de datos está mal. Esto incluye claves de metadatos faltantes o valores imposibles (como ip_version = 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - los metadatos de la base de datos indican que su versión principal no es 2. Esta librería solo puede manejar la versión principal 2.
  • MMDB_OUT_OF_MEMORY_ERROR - una llamada a la asignación de memoria falló (malloc, etc.).
  • MMDB_INVALID_DATA_ERROR - un campo de datos contiene datos inválidos. Por ejemplo, un campo uint16 afirma ser más de 2 bytes. La base de datos probablemente está dañada o fue generada incorrectamente.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - el camino de búsqueda pasado a MMDB_get_value, MMDB_vget_value, o MMDB_aget_value contiene un desplazamiento de array mayor que LONG_MAX o menor que LONG_MIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - el camino de búsqueda pasado a MMDB_get_value, MMDB_vget_value, o MMDB_aget_value no coincide con la estructura de datos de la entrada. Pueden ocurrir varias razones. El camino de búsqueda podría incluir una clave no presente en un mapa. El camino de búsqueda podría incluir un índice de array mayor que un array o menor que el desplazamiento mínimo desde el final de un array. Puede ocurrir también cuando el camino espera encontrar un mapa o array donde ninguno exista.

Todos los códigos de estado deben tratarse como valores de tipo int.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

Esta función toma un código de estado y devuelve una cadena en inglés explicando el estado.

FUNCIONES

Esta librería proporciona las siguientes funciones exportadas:

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

Esta función abre un manejador para un archivo MaxMind DB. El valor de retorno es un código de estado como se define anteriormente. Debes verificar el valor de retorno de esta llamada.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

El filename debe codificarse como UTF-8 en Windows.

La estructura MMDB_s que pasas puede estar en la pila o reservada en la memoria heap. Sin embargo, si la apertura es exitosa, contendrá datos reservados en la memoria heap, por lo que debes cerrarla con MMDB_close(). Si el código de estado no es MMDB_SUCCESS, esta librería se asegurará de que toda la memoria reservada se libere antes de devolver.

Los flags actuales son:

•
MMDB_MODE_MMAP - abre el archivo con mmap().

Puedes pasar 0 como valor de flags para abrir el archivo con los flags por defecto. Sin embargo, estos valores pueden cambiar en futuras versiones. El valor por defecto es MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Esta librería libera cualquier memoria reservada o mmap'd que esté asociada con la estructura MMDB_s. No libera la memoria de la base de datos.

y alloué pour la structure elle-même ! Si vous avez alloué la structure à partir du tas, vous êtes responsable de sa libération.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

Cette fonction recherche une adresse IP passée sous forme de chaîne de caractères se terminant par un caractère nul. En interne, elle appelle getaddrinfo() pour résoudre l'adresse sous forme binaire. Elle appelle ensuite MMDB_lookup_sockaddr() pour rechercher l'adresse dans la base de données. Si vous avez déjà résolu une adresse, vous pouvez appeler directement MMDB_lookup_sockaddr(), plutôt que de résoudre l'adresse deux fois.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Cette fonction retourne toujours une structure MMDB_lookup_result_s, mais vous devez également vérifier les paramètres gai_error et mmdb_error. Si l'un de ces paramètres indique une erreur, la structure retournée est dénuée de sens.

En l'absence d'erreur, vous devez toujours vous assurer que le membre found_entry du résultat retourné est vrai. Si ce n'est pas le cas, cela signifie que l'adresse IP n'a pas d'entrée dans la base de données.

Cette fonction fonctionnera avec les adresses IPv4 même lorsque la base de données contient des données pour les adresses IPv4 et IPv6. L'adresse IPv4 sera recherchée sous la forme '::xxx.xxx.xxx.xxx' plutôt que d'être remappée dans le bloc ::ffff:xxx.xxx.xxx.xxx alloué pour les adresses IPv6 mappées IPv4.

Si vous passez une adresse IPv6 à une base de données ne contenant que des données IPv4, le membre found_entry sera faux, mais le statut mmdb_error sera toujours MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

Cette fonction recherche une adresse IP qui a déjà été résolue par getaddrinfo().

Outre le fait de ne pas appeler getaddrinfo() elle-même, cette fonction est identique à la fonction MMDB_lookup_string().

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Fonctions de recherche de données

Il existe trois fonctions pour rechercher les données associées à une adresse IP.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Les trois fonctions permettent trois styles d'appel légèrement différents, mais elles font toutes la même chose.

Le premier paramètre est une valeur MMDB_entry_s. Dans la plupart des cas, il proviendra de la valeur MMDB_lookup_result_s retournée par MMDB_lookup_string() ou MMDB_lookup_sockaddr().

Le second paramètre est une référence à une structure MMDB_entry_data_s. Elle sera remplie avec les données recherchées, si elles sont trouvées. Si rien n'est trouvé, le membre has_data de cette structure sera faux. Si has_data est vrai, vous pouvez examiner le membre data_type.

Le dernier paramètre est un chemin de recherche. Le chemin se compose d'un ensemble de chaînes représentant soit des clés de mappe (par exemple, "city"), soit des index de tableau (par exemple, "0", "1", "-1") à utiliser dans la recherche.

Les index de tableau négatifs seront traités comme un décalage par rapport à la fin du tableau. Par exemple, "-1" fait référence au dernier élément du tableau.

Le chemin de recherche vous permet de naviguer dans une structure de données complexe. Par exemple, étant donné ces données :

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Nous pourrions rechercher le nom anglais avec ce code :

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

Si nous voulions trouver la première ville, le chemin de recherche serait "cities", "0". Si vous ne fournissez aucun chemin de recherche, vous obtiendrez l'entrée correspondant à la mappe de niveau supérieur. Le chemin de recherche doit toujours se terminer par NULL, quelle que soit la fonction appelée.

La fonction MMDB_get_value prend un nombre variable d'arguments. Tous les arguments après le pointeur de structure MMDB_entry_data_s * constituent le chemin de recherche. Le dernier argument doit être NULL.

La fonction MMDB_vget_value accepte une va_list comme chemin de recherche. Le dernier élément récupéré par va_arg() doit être NULL.

Enfin, la fonction MMDB_aget_value accepte un tableau de chaînes comme chemin de recherche. Le dernier membre de ce tableau doit être NULL.

Si vous souhaitez obtenir toutes les données d'entrée en une seule fois, vous pouvez appeler MMDB_get_entry_data_list() à la place.

Pour chacune des trois fonctions, la valeur de retour est un code de statut tel que défini ci-dessus.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

Cette fonction permet d'obtenir toutes les données d'une structure de données complexe en une seule fois, au lieu de rechercher chaque élément à l'aide d'appels répétés à MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// enregistrer ceci pour pouvoir libérer ces données plus tard
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

Il vous appartient d'interpréter la structure de données entry_data_list. La liste est chaînée dans un parcours en profondeur. Utilisons cette structure comme exemple :

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

La liste sera composée des éléments suivants :

1.
MAP - mappe de niveau supérieur
2.
UTF8_STRING - clé "names"
3.
MAP - mappe pour la clé "names"
4.
UTF8_STRING - clé "en"
5.
UTF8_STRING - valeur pour la clé "en"
6.
UTF8_STRING - clé "de"
7.
UTF8_STRING - valeur pour la clé "de"
8.
UTF8_STRING - clé "cities"
9.
ARRAY - valeur pour la clé "cities"
10.
UTF8_STRING - array[0]
11.
UTF8_STRING - array[1]

La valeur de retour de la fonction est un code de statut tel que défini ci-dessus.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(
    MMDB_entry_data_list_s *const entry_data_list);

Les fonctions MMDB_get_entry_data_list() et MMDB_get_metadata_as_entry_data_list() alloueront la structure de liste chaînée à partir du tas. Appelez cette fonction pour libérer la structure MMDB_entry_data_list_s.

MMDB_get_metadata_as_entry_data_list()

int MMDB_get_metadata_as_entry_data_list(
    MMDB_s *const mmdb,
    MMDB_entry_data_list_s **const entry_data_list);

Cette fonction permet de récupérer les métadonnées de la base de données sous forme de liste chaînée de structures MMDB_entry_data_list_s. Cela peut être une manière plus pratique de gérer les métadonnées que d'utiliser directement la structure des métadonnées.

    MMDB_entry_data_list_s *entry_data_list, *first;
    int status =
        MMDB_get_metadata_as_entry_data_list(&mmdb, &entry_data_list);
    if (MMDB_SUCCESS != status) { ... }
    first = entry_data_list;
    ... // faire quelque chose avec les données
    MMDB_free_entry_data_list(first);

La valeur de retour de la fonction est un code de statut tel que défini ci-dessus.

MMDB_dump_entry_data_list()

int MMDB_dump_entry_data_list(
    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

Cette fonction prend une liste chaînée de structures MMDB_entry_data_list_s et la stringifie vers le stream donné. Le paramètre indent est le niveau d'indentation de départ pour la sortie générée. Il est incrémenté pour les structures de données imbriquées (mappes, tableaux, etc.).

Le stream doit être un descripteur de fichier (stdout, etc.). Si votre plateforme fournit quelque chose comme open_memstream() de GNU, vous pouvez l'utiliser pour capturer la sortie sous forme de chaîne.

La sortie est formatée dans un style proche du JSON, mais les valeurs sont marquées avec leur type de données (sauf pour les mappes et les tableaux qui sont affichés avec "{}" et "[]" respectivement).

libmaxminddb(3) — archlinux

NAME

libmaxminddb - MaxMind DB file access library

SYNOPSIS

    #include <maxminddb.h>
    MMDB_s mmdb;
    int status = MMDB_open("database.mmdb", MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) { ... }
    ...
    MMDB_lookup_result_s result = MMDB_lookup_string(&mmdb, "1.1.1.1", NULL, NULL);
    if (result.found_entry) { ... }
    ...
    MMDB_close(&mmdb);

DESCRIPTION

The MaxMind DB file format is a binary database format that stores tree-like data. It is designed for fast lookups of geographical location data from IP addresses.

This library provides functions to open MaxMind DB files, perform lookups, and retrieve data. It supports different memory mapping modes for opening files, which can affect performance and memory usage.

The library also provides functions for inspecting the database structure and iterating through its nodes, which can be useful for debugging and understanding the database content.

DATA STRUCTURES

MMDB_s
Represents an opened MaxMind DB file. Contains file handle, mode, and database metadata.
MMDB_lookup_result_s
Represents the result of an IP address lookup. Contains a flag indicating if an entry was found, and if so, the entry data and node number.
MMDB_entry_data_list_s
Represents a list of entry data items. Each item contains the data type, data itself, and a pointer to the next item in the list.
MMDB_search_node_s
Represents a node in the MaxMind DB search tree. Contains the node's type and value(s).

STATUS CODES

The following status codes are returned by libmaxminddb functions:

MMDB_SUCCESS
Operation completed successfully.
MMDB_STARTING_ERROR
An error occurred during initialization.
MMDB_INVALID_FILE_ERROR
The specified file is not a valid MaxMind DB file.
MMDB_CORRUPT_FILE_ERROR
The MaxMind DB file is corrupted.
MMDB_INVALID_MODE_ERROR
An invalid mode was specified for opening the database.
MMDB_FILE_NOT_FOUND_ERROR
The specified database file could not be found.
MMDB_IO_ERROR
An I/O error occurred while accessing the database file.
MMDB_OUT_OF_MEMORY_ERROR
Not enough memory is available.
MMDB_SOCKET_ERROR
An error occurred related to network sockets.
MMDB_NULL_POINTER_ERROR
A NULL pointer was passed to a function where it is not allowed.
MMDB_INVALID_DATA_ERROR
The data read from the database is invalid.
MMDB_INVALID_RETURN_VALUE_ERROR
A function returned an unexpected value.
MMDB_NOT_IMPLEMENTED_ERROR
The requested feature is not implemented.
MMDB_METADATA_ERROR
Error related to database metadata.
MMDB_CRITERIA_ERROR
An error related to search criteria.
MMDB_INVALID_NODE_NUMBER_ERROR
The provided node number is invalid.
MMDB_KEY_NOT_FOUND_ERROR
The specified key was not found in the database entry.

FUNCTIONS

MMDB_open()

int MMDB_open(
    const char *filename,
    MMDB_mode_e mode,
    MMDB_s *mmdb);

Opens a MaxMind DB file for reading. The mode parameter specifies how the file should be accessed:

MMDB_MODE_MMAP
Use memory mapping (mmap). This is generally the fastest mode.
MMDB_MODE_FILE
Read the entire file into memory. Suitable for smaller databases or when mmap is not available or desired.
MMDB_MODE_LOAD_DB
Load the database into memory, copying data from the file. Similar to MMDB_MODE_FILE but may offer different performance characteristics.

The function returns a status code. MMDB_SUCCESS on success, or an error code defined above.

MMDB_close()

void MMDB_close(MMDB_s *mmdb);

Closes an opened MaxMind DB file and releases any associated resources.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    const MMDB_s *mmdb,
    const char *ip_address,
    int *gai_error,
    int *mmdb_error);

Looks up an IP address in the MaxMind DB database. The ip_address should be a string representation of an IPv4 or IPv6 address.

If provided, gai_error will be populated with the error code from getaddrinfo if it fails. If provided, mmdb_error will be populated with the MaxMind DB library's error code.

Returns an MMDB_lookup_result_s structure. If result.found_entry is true, the lookup was successful and result.entry contains the data for the IP address.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    const MMDB_s *mmdb,
    const struct sockaddr *addr,
    int *mmdb_error);

Looks up an IP address represented by a sockaddr structure in the MaxMind DB database.

If provided, mmdb_error will be populated with the MaxMind DB library's error code.

Returns an MMDB_lookup_result_s structure. If result.found_entry is true, the lookup was successful and result.entry contains the data for the IP address.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    const MMDB_entry_s *entry,
    MMDB_entry_data_list_s **entry_data_list);

Retrieves the data associated with a database entry as a linked list of MMDB_entry_data_s structures.

The entry_data_list parameter is a pointer to a pointer that will be populated with the head of the linked list. The caller is responsible for freeing this list using MMDB_free_entry_data_list().

Returns MMDB_SUCCESS on success, or an error code.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(MMDB_entry_data_list_s *entry_data_list);

Frees the memory allocated for an entry data list obtained from MMDB_get_entry_data_list().

MMDB_dump_entry_data_list()

void MMDB_dump_entry_data_list(
    FILE *file,
    const MMDB_entry_data_list_s *entry_data_list,
    int indent);

Dumps the content of an entry data list to a file pointer (e.g., stdout) in a human-readable format. The indent parameter specifies the indentation level.

The formatting of the output is intended for displaying data to users and for debugging purposes. It may change in future releases, so you should not rely on the specific formatting produced by this function.

The return value of the function is a status code as defined above.

MMDB_read_node()

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

This reads a specific node in the search tree. The third argument is a reference to an MMDB_search_node_s structure that will be populated by this function.

The return value is a status code. If you pass a node_number that is greater than the number of nodes in the database, this function will return MMDB_INVALID_NODE_NUMBER_ERROR, otherwise it will return MMDB_SUCCESS.

The first node in the search tree is always node 0. If you wanted to iterate over the whole search tree, you would start by reading node 0 and then following the the records that make up this node, based on the type of each record. If the type is MMDB_RECORD_TYPE_SEARCH_NODE then the record contains an integer for the next node to look up.

MMDB_lib_version()

const char *MMDB_lib_version(void)

This function returns the library version as a string, something like "2.0.0".

EXEMPLE

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
