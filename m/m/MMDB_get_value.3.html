DESCRIPTION

La bibliothèque libmaxminddb fournit des fonctions pour travailler avec des fichiers MaxMind DB. Consultez la spécification du format MaxMind DB sur https://maxmind.github.io/MaxMind-DB/. Les bases de données et les résultats sont représentés par différentes structures. Les bases de données sont ouvertes en appelant MMDB_open(). Vous pouvez rechercher des adresses IP sous forme de chaînes de caractères avec MMDB_lookup_string() ou sous forme de pointeurs vers des structures sockaddr avec MMDB_lookup_sockaddr().

Si la recherche trouve l'adresse IP dans la base de données, elle renvoie une structure MMDB_lookup_result_s. Si cette structure indique que la base de données contient des données pour l'adresse IP, plusieurs fonctions peuvent être utilisées pour récupérer ces données. Celles-ci incluent MMDB_get_value() et MMDB_get_entry_data_list(). Consultez la documentation des fonctions ci-dessous pour plus de détails.

Lorsque vous avez terminé de manipuler la base de données, appelez MMDB_close().

Toutes les fonctions, structures et macros publiques commencent par MMDB_.

STRUCTURES DE DONNÉES

Toutes les structures exportées par la bibliothèque maxminddb.h sont définies comme typedef struct foo_s { ... } foo_s, vous pouvez donc y faire référence sans le préfixe struct.

Cette bibliothèque fournit les structures suivantes :

MMDB_s

Ceci est la poignée d'un fichier MaxMind DB. Nous ne documentons que certains champs de cette structure destinés à un usage public. Tous les autres champs sont sujets à modification et sont destinés à un usage interne uniquement.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - les drapeaux avec lesquels cette base de données a été ouverte. Consultez la documentation de MMDB_open() pour plus de détails.
  • const char *filename - le nom du fichier qui a été ouvert, tel que passé à MMDB_open().
  • MMDB_metadata_s metadata - les métadonnées de la base de données.

MMDB_metadata_s et MMDB_description_s

Cette structure peut être obtenue à partir de la structure MMDB_s. Elle contient les métadonnées lues à partir d'un fichier de base de données. Notez qu'il peut être plus pratique d'accéder à ces métadonnées en appelant MMDB_get_metadata_as_entry_data_list().

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Ces structures devraient être principalement auto-explicatives.

Le membre ip_version doit toujours être 4 ou 6. Le membre binary_format_major_version doit toujours être 2.

Il n'y a aucune exigence spécifique concernant les métadonnées de la base de données qui incluent des langues ou des descriptions, de sorte que les valeurs count de ces éléments de métadonnées peuvent être nulles. Tous les autres membres de MMDB_metadata_s doivent être renseignés.

MMDB_lookup_result_s

Cette structure est renvoyée comme résultat de la recherche d'une adresse IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si le membre found_entry est faux, les autres membres de cette structure ne contiennent pas de valeurs significatives. Vérifiez toujours que found_entry est vrai en premier.

Le membre entry est utilisé pour rechercher les données associées à l'adresse IP.

Le membre netmask indique à quel sous-réseau l'adresse IP appartient dans cette base de données. Par exemple, si vous recherchez l'adresse 1.1.1.1 dans une base de données IPv4 et que la valeur renvoyée est 16, alors l'adresse appartient au sous-réseau 1.1.0.0/16.

Si la base de données est une base de données IPv6, la valeur renvoyée pour netmask est toujours une longueur de préfixe IPv6 (de 0 à 128), même si cette base de données contient également des réseaux IPv4. Si vous recherchez une adresse IPv4 et que vous souhaitez convertir le masque réseau en une valeur de sous-réseau IPv4, soustrayez simplement 96 de la valeur.

MMDB_result_s

Vous n'avez pas besoin de rechercher dans cette structure. Vous obtiendrez cette structure à partir d'une structure MMDB_lookup_result_s et la transmettrez à diverses fonctions.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

Cette fonction recherche une adresse IP passée sous forme de chaîne de caractères terminée par un octet nul. En interne, elle appelle getaddrinfo() pour résoudre l'adresse en forme binaire. Elle appelle ensuite MMDB_lookup_sockaddr() pour rechercher l'adresse dans la base de données. Si vous avez déjà résolu une adresse, vous pouvez appeler MMDB_lookup_sockaddr() directement, plutôt que de résoudre l'adresse deux fois.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Cette fonction retourne toujours une structure MMDB_lookup_result_s, mais vous devez également vérifier les paramètres gai_error et mmdb_error. Si l'un d'eux indique une erreur, la structure retournée n'est pas significative.

Si aucune erreur ne s'est produite, vous devez toujours vous assurer que le membre found_entry dans le résultat retourné est vrai. Sinon, cela signifie que l'adresse IP n'a pas d'entrée dans la base de données.

Cette fonction fonctionnera avec les adresses IPv4 même lorsque la base de données contient des données pour les adresses IPv4 et IPv6. L'adresse IPv4 sera recherchée sous la forme '::xxx.xxx.xxx.xxx' plutôt que d'être mappée dans le bloc ::ffff:xxx.xxx.xxx.xxx réservé aux adresses IPv6 mappées IPv4.

Si vous passez une adresse IPv6 à une base de données ne contenant que des données IPv4, le membre found_entry sera faux, mais le statut mmdb_error sera toujours MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

Cette fonction recherche une adresse IP qui a déjà été résolue par getaddrinfo().

À part le fait de ne pas appeler getaddrinfo() elle-même, cette fonction est identique à la fonction MMDB_lookup_string().

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Fonctions de recherche de données

Il existe trois fonctions pour rechercher les données associées à une adresse IP.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Les trois fonctions permettent trois styles d'appel légèrement différents, mais elles font toutes la même chose.

Le premier paramètre est une valeur MMDB_entry_s. Dans la plupart des cas, elle proviendra de la valeur MMDB_lookup_result_s retournée par MMDB_lookup_string() ou MMDB_lookup_sockaddr().

Le second paramètre est une référence à une structure MMDB_entry_data_s. Elle sera remplie avec les données recherchées, si elles sont trouvées. Si rien n'est trouvé, le membre has_data de cette structure sera faux. Si has_data est vrai, vous pouvez regarder le membre data_type.

Le dernier paramètre est un chemin de recherche. Le chemin se compose d'un ensemble de chaînes représentant soit des clés de carte (par exemple, "city"), soit des index de tableau (par exemple, "0", "1", "-1") à utiliser dans la recherche.

Les index de tableau négatifs seront traités comme un décalage par rapport à la fin du tableau. Par exemple, "-1" fait référence au dernier élément du tableau.

Le chemin de recherche vous permet de naviguer dans une structure de données complexe. Par exemple, étant donné ces données :

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Nous pourrions rechercher le nom anglais avec ce code :

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

Si nous voulions trouver la première ville, le chemin de recherche serait "cities", "0". Si vous ne fournissez aucun chemin de recherche, vous obtiendrez l'entrée qui correspond à la carte de niveau supérieur. Le chemin de recherche doit toujours se terminer par NULL, quelle que soit la fonction que vous appelez.

La fonction MMDB_get_value accepte un nombre variable d'arguments. Tous les arguments après le pointeur de structure MMDB_entry_data_s * constituent le chemin de recherche. Le dernier argument doit être NULL.

La fonction MMDB_vget_value accepte une va_list comme chemin de recherche. Le dernier élément récupéré par va_arg() doit être NULL.

Enfin, la fonction MMDB_aget_value accepte un tableau de chaînes comme chemin de recherche. Le dernier membre de ce tableau doit être NULL.

Si vous souhaitez obtenir toutes les données d'entrée en une seule fois, vous pouvez appeler MMDB_get_entry_data_list() à la place.

Pour chacune des trois fonctions, la valeur de retour est un code de statut tel que défini ci-dessus.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

Cette fonction vous permet d'obtenir toutes les données d'une structure de données complexe en une seule fois, plutôt que de rechercher chaque élément en appelant de manière répétée MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// enregistrer ceci pour pouvoir libérer ces données plus tard
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

Il vous appartient d'interpréter la structure de données entry_data_list. La liste est chaînée selon un parcours en profondeur. Utilisons cette structure comme exemple :

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

La liste sera composée des éléments suivants :

1.
MAP - carte de niveau supérieur
2.
UTF8_STRING - clé "names"
3.
MAP - carte pour la clé "names"
4.
UTF8_STRING - clé "en"
5.
UTF8_STRING - valeur pour la clé "en"
6.
UTF8_STRING - clé "de"
7.
UTF8_STRING - valeur pour la clé "de"
8.
UTF8_STRING - clé "cities"
9.
ARRAY - valeur pour la clé "cities"
10.
UTF8_STRING - tableau[0]
11.
UTF8_STRING - tableau[1]

La valeur de retour de la fonction est un code de statut tel que défini ci-dessus.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(

Les fonctions MMDB_get_entry_data_list() et MMDB_get_metadata_as_entry_data_list() alloueront la structure de liste chaînée depuis le tas. Appelez cette fonction pour libérer la structure MMDB_entry_data_list_s.

MMDB_get_metadata_as_entry_data_list()

int MMDB_get_metadata_as_entry_data_list(
    MMDB_s *const mmdb,

Cette fonction vous permet de récupérer les métadonnées de la base de données sous forme de liste chaînée de structures MMDB_entry_data_list_s. Cela peut être une manière plus pratique de gérer les métadonnées qu'en utilisant directement la structure des métadonnées.

    MMDB_entry_data_list_s *entry_data_list, *first;
    int status =
        MMDB_get_metadata_as_entry_data_list(&mmdb, &entry_data_list);
    if (MMDB_SUCCESS != status) { ... }
    first = entry_data_list;
    ... // faire quelque chose avec les données
    MMDB_free_entry_data_list(first);

La valeur de retour de la fonction est un code de statut tel que défini ci-dessus.

MMDB_dump_entry_data_list()

int MMDB_dump_entry_data_list(
    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

Cette fonction prend une liste chaînée de structures MMDB_entry_data_list_s et la transforme en chaîne de caractères vers le stream donné. Le paramètre indent est le niveau d'indentation de départ pour la sortie générée. Il est incrémenté pour les structures de données imbriquées (cartes, tableaux, etc.).

Le stream doit être un descripteur de fichier (stdout, etc.). Si votre plateforme fournit quelque chose comme open_memstream() de GNU, vous pouvez l'utiliser pour capturer la sortie sous forme de chaîne.

La sortie est formatée d'une manière similaire à JSON, mais les valeurs sont marquées avec leur type de données (sauf pour les cartes et les tableaux qui sont affichés respectivement avec "{}" et "[]").

Le format de sortie spécifique peut changer dans les futures versions.

MMDB - Une Bibliothèque pour Lire les Fichiers de Base de Données GeoIP

NOM

MMDB - Une Bibliothèque pour Lire les Fichiers de Base de Données GeoIP

SYN

MMDB_open(3), MMDB_close(3), MMDB_strerror(3), MMDB_get_value(3), MMDB_get_entry_data_list(3), MMDB_dump_entry_data_list(3), MMDB_lookup(3)

DESCRIPTION

MMDB est une bibliothèque pour lire les fichiers de base de données GeoIP. Elle fournit une interface simple pour accéder aux données de géolocalisation. La bibliothèque prend en charge diverses opérations telles que l'ouverture d'une base de données, la recherche d'adresses IP et la récupération des données d'entrée.

STRUCTURES_DE_DONNÉES

Les structures de données suivantes sont utilisées par MMDB :

  • MMDB_s - Un handle pour la base de données MMDB.
  • MMDB_search_node_s - Une structure représentant un nœud dans l'arbre de recherche.
  • MMDB_entry_data_list_s - Une liste de données d'entrée.
  • MMDB_lookup_result_s - Un résultat d'une opération de recherche.

CODES_STATUT

Voici les codes de statut renvoyés par les fonctions MMDB :

  • MMDB_SUCCESS - Succès.
  • MMDB_INVALID_NODE_NUMBER_ERROR - Numéro de nœud invalide.
  • MMDB_IO_ERROR - Erreur d'E/S.
  • MMDB_LOOKUP_ERROR - Erreur de recherche.
  • MMDB_LOOKUP_SUCCESS - Recherche réussie.

FONCTIONS

Les fonctions suivantes sont disponibles dans MMDB :

  • MMDB_open(3) - Ouvre une base de données MMDB.
  • MMDB_close(3) - Ferme une base de données MMDB.
  • MMDB_strerror(3) - Renvoie une description d'une erreur.
  • MMDB_get_value(3) - Récupère une valeur d'une base de données.
  • MMDB_get_entry_data_list(3) - Récupère les données d'entrée.
  • MMDB_dump_entry_data_list(3) - Affiche les données d'entrée.
  • MMDB_lookup(3) - Recherche une adresse IP.

EXEMPLE

Voici un exemple d'utilisation de MMDB :

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
