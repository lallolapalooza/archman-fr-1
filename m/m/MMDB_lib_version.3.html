DESCRIPTION

La bibliothèque libmaxminddb fournit des fonctions pour travailler avec les fichiers MaxMind DB. Voir https://maxmind.github.io/MaxMind-DB/ pour la spécification du format MaxMind DB. Les bases de données et les résultats sont représentés par différentes structures de données. Les bases de données sont ouvertes en appelant MMDB_open(). Vous pouvez rechercher des adresses IP sous forme de chaîne de caractères avec MMDB_lookup_string() ou sous forme de pointeur vers une structure sockaddr avec MMDB_lookup_sockaddr().

Si la recherche trouve l'adresse IP dans la base de données, elle retourne une structure MMDB_lookup_result_s. Si cette structure indique que la base de données a des données pour l'IP, il existe un certain nombre de fonctions qui peuvent être utilisées pour récupérer ces données. Celles-ci incluent MMDB_get_value() et MMDB_get_entry_data_list(). Voir la documentation des fonctions ci-dessous pour plus de détails.

Lorsque vous avez terminé avec le descripteur de base de données, vous devez appeler MMDB_close().

Toutes les fonctions, structures et macros visibles publiquement commencent par "MMDB_".

STRUCTURES DE DONNÉES

Toutes les structures de données exportées par l'en-tête maxminddb.h de cette bibliothèque sont typées sous la forme typedef struct foo_s { ... } foo_s de sorte que vous puissiez y faire référence sans le préfixe struct.

Cette bibliothèque fournit les structures de données suivantes :

MMDB_s

C'est le descripteur d'un fichier MaxMind DB. Nous ne documentons que certains des champs de cette structure destinés à un usage public. Tous les autres champs sont susceptibles d'être modifiés et sont destinés uniquement à un usage interne.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - les indicateurs avec lesquels cette base de données a été ouverte. Voir la documentation de MMDB_open() pour plus de détails.
  • const char *filename - le nom du fichier qui a été ouvert, tel que passé à MMDB_open().
  • MMDB_metadata_s metadata - les métadonnées de la base de données.

MMDB_metadata_s et MMDB_description_s

Cette structure peut être récupérée à partir de la structure MMDB_s. Elle contient les métadonnées lues à partir du fichier de base de données. Notez qu'il peut être plus pratique pour vous d'accéder à ces métadonnées en appelant plutôt MMDB_get_metadata_as_entry_data_list().

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Ces structures devraient être largement auto-explicatives.

Le membre ip_version devrait toujours être 4 ou 6. Le binary_format_major_version devrait toujours être 2.

Il n'est pas requis que les métadonnées de la base de données incluent des langues ou des descriptions, donc le count pour ces parties des métadonnées peut être zéro. Tous les autres champs de MMDB_metadata_s devraient être remplis.

MMDB_lookup_result_s

Cette structure est retournée comme résultat de la recherche d'une adresse IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si le membre found_entry est faux, alors les autres membres de cette structure ne contiennent pas de valeurs significatives. Vérifiez toujours que found_entry est vrai en premier.

Le membre entry est utilisé pour rechercher les données associées à l'adresse IP.

Le membre netmask vous indique à quel sous-réseau l'adresse IP appartient dans cette base de données. Par exemple, si vous recherchez l'adresse 1.1.1.1 dans une base de données IPv4 et que le netmask retourné est 16, alors l'adresse fait partie du sous-réseau 1.1.0.0/16.

Si la base de données est une base de données IPv6, le masque de réseau retourné est toujours une longueur de préfixe IPv6 (de 0 à 128), même si cette base de données contient *également* des réseaux IPv4. Si vous recherchez une adresse IPv4 et que vous souhaitez convertir le masque de réseau en une valeur de masque de réseau IPv4, vous pouvez simplement soustraire 96 de la valeur.

MMDB_result_s

Vous n'avez pas vraiment besoin de fouiller dans cette structure. Vous l'obtiendrez à partir d'une structure MMDB_lookup_result_s et la passerez à diverses fonctions.

MMDB_entry_data_s

Cette structure est utilisée pour retourner une seule entrée de section de données pour une IP. Ces entrées peuvent à leur tour pointer vers d'autres entrées, comme c'est le cas pour des éléments tels que les cartes et les tableaux. Certains membres de cette structure ne sont pas documentés car ils sont uniquement destinés à un usage interne.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t or uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

Le membre has_data est vrai si des données ont été trouvées pour une recherche donnée. Voir MMDB_get_value() pour plus de détails. Si ce membre est faux, alors aucune des autres valeurs de la structure n'est significative.

L'union au début de la structure définit les données réelles. Pour déterminer quel membre de l'union

MMDB_entry_data_list_s

Cette structure est utilisée pour contenir une liste d'entrées de données retournées par MMDB_get_entry_data_list(). Chaque nœud de la liste contient une MMDB_entry_data_s et un pointeur vers le nœud suivant.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

Cette structure est utilisée pour représenter des données complexes comme des tableaux ou des cartes.

MMDB_search_node_s

Cette structure est utilisée par MMDB_read_node() pour retourner les informations d'un nœud de recherche de la base de données.

typedef struct MMDB_search_node_s {
    uint32_t node_in_tree;
    uint32_t left_child_in_tree;
    uint32_t right_child_in_tree;
    uint32_t ip_address_bits;
    uint8_t record_in_tree;
    uint32_t data_size;
    uint32_t data_type;
} MMDB_search_node_s;

Les champs de cette structure sont principalement destinés à un usage interne.

FONCTIONS

MMDB_open()

Ouvre un fichier MaxMind DB.

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

Les drapeaux disponibles sont :

MMDB_NON_FLUSH_FILE_MODE
Ne ferme pas le fichier lorsqu'il est écrit. Utile si vous avez besoin de plusieurs descripteurs de fichier ou si vous voulez lire le fichier plus tard.
MMDB_MEMORY_MODE
Charge tout le fichier MaxMind DB en mémoire. Les recherches seront plus rapides, mais cela consommera plus de mémoire.
MMDB_RANDOM_ACCESS_MODE
Ouvre le fichier en mode accès aléatoire. C'est le mode par défaut si aucun autre mode n'est spécifié.

Retourne 0 en cas de succès, ou un code d'erreur MaxMind DB en cas d'échec.

MMDB_close()

Ferme un fichier MaxMind DB et libère toutes les ressources associées.

void MMDB_close(MMDB_s *const mmdb);

MMDB_lookup_string()

Recherche une adresse IP représentée par une chaîne de caractères.

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

ipstr est la chaîne représentant l'adresse IP (par exemple, "192.168.1.1" ou "2001:db8::1"). gai_error est un pointeur vers un entier qui contiendra le code d'erreur de getaddrinfo s'il y en a un. mmdb_error est un pointeur vers un entier qui contiendra le code d'erreur libmaxminddb s'il y en a un.

Retourne une structure MMDB_lookup_result_s. Si la recherche échoue, le champ found_entry de la structure sera faux.

MMDB_lookup_sockaddr()

Recherche une adresse IP représentée par une structure sockaddr.

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

sockaddr est un pointeur vers la structure sockaddr. mmdb_error est un pointeur vers un entier qui contiendra le code d'erreur libmaxminddb s'il y en a un.

Retourne une structure MMDB_lookup_result_s. Si la recherche échoue, le champ found_entry de la structure sera faux.

MMDB_get_value()

Récupère la valeur d'une entrée dans la base de données. Cette fonction utilise le mécanisme des arguments variables pour spécifier le chemin vers la valeur souhaitée.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);

start est le point de départ de la recherche (généralement l'entrée retournée par une recherche réussie). entry_data est un pointeur vers une structure MMDB_entry_data_s où la valeur sera stockée. Les arguments variables (...) spécifient le chemin sous forme de chaînes de caractères terminées par NULL.

Retourne 0 en cas de succès, ou un code d'erreur MaxMind DB en cas d'échec.

Exemple : MMDB_get_value(result.entry, &entry_data, "city", "names", "en", NULL);

MMDB_vget_value()

Similaire à MMDB_get_value(), mais prend une liste d'arguments variable (va_list) pour spécifier le chemin.

int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);

MMDB_aget_value()

Similaire à MMDB_get_value(), mais prend un tableau de chaînes de caractères terminées par NULL pour spécifier le chemin.

int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

MMDB_get_entry_data_list()

Récupère toutes les données d'une entrée sous forme de liste chaînée d'entrées de données.

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

start est le point de départ de la recherche. entry_data_list est un pointeur vers un pointeur qui contiendra l'adresse de la première entrée de la liste chaînée.

Retourne 0 en cas de succès, ou un code d'erreur MaxMind DB en cas d'échec.

MMDB_free_entry_data_list()

Libère la mémoire allouée pour une liste d'entrées de données.

void MMDB_free_entry_data_list(
    MMDB_entry_data_list_s *const entry_data_list);

MMDB_get_metadata_as_entry_data_list()

Récupère les métadonnées de la base de données sous forme de liste d'entrées de données.

int MMDB_get_metadata_as_entry_data_list(
    MMDB_s *const mmdb,
    MMDB_entry_data_list_s **const entry_data_list);

Retourne 0 en cas de succès, ou un code d'erreur MaxMind DB en cas d'échec.

MMDB_dump_entry_data_list()

Imprime une liste d'entrées de données dans un flux spécifié (par exemple, stdout).

int MMDB_dump_entry_data_list(
    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

stream est le pointeur de fichier dans lequel imprimer. entry_data_list est la liste d'entrées à imprimer. indent spécifie le niveau d'indentation.

Retourne 0 en cas de succès, ou un code d'erreur MaxMind DB en cas d'échec.

MMDB_read_node()

Lit les informations d'un nœud spécifique de l'arbre de la base de données.

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

node_number est le numéro du nœud à lire. node est un pointeur vers une structure MMDB_search_node_s où les informations du nœud seront stockées.

Retourne 0 en cas de succès, ou un code d'erreur MaxMind DB en cas d'échec.

MMDB_lib_version()

Retourne la chaîne de version de la bibliothèque libmaxminddb.

const char *MMDB_lib_version(void);

MMDB_strerror()

Retourne une chaîne de caractères représentant un code d'erreur MaxMind DB.

const char *MMDB_strerror(int error_code);

CODES D'ERREUR

Les fonctions de libmaxminddb retournent les codes d'erreur suivants :

MMDB_SUCCESS
Succès.
MMDB_ERROR_MMDB
Erreur générique MaxMind DB.
MMDB_ERROR_FILE_OPEN
Erreur lors de l'ouverture du fichier.
MMDB_ERROR_INVALID_DATA_STRUCTURE
Structure de données invalide dans le fichier MaxMind DB.
MMDB_ERROR_INVALID_METADATA
Métadonnées invalides dans le fichier MaxMind DB.
MMDB_ERROR_INVALID_IP_ADDRESS
Adresse IP invalide.
MMDB_ERROR_INVALID_SEARCH_NODE
Nœud de recherche invalide.
MMDB_ERROR_LOOKUP_FAILED
Échec de la recherche.
MMDB_ERROR_INVALID_KEY_IN_RECORD
Clé invalide dans l'enregistrement.
MMDB_ERROR_socket
Erreur liée aux sockets.
MMDB_ERROR_no_such_domain
Domaine inexistant.

EXEMPLE

#include <stdio.h>
#include <stdlib.h>
#include <maxminddb.h>
int main() {
    MMDB_s mmdb;
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result;
    const char *db_path = "GeoLite2-City.mmdb"; // Remplacez par le chemin de votre fichier DB
    const char *ip_address = "8.8.8.8";
    int lookup_error;
    MMDB_entry_data_s city_entry, country_entry;
    // Ouvrir la base de données
    lookup_error = MMDB_open(db_path, MMDB_DEFAULT_MODE, &mmdb);
    if (lookup_error != MMDB_SUCCESS) {
        fprintf(stderr, "Erreur à l'ouverture de %s - %s\n", db_path, MMDB_strerror(lookup_error));
        return 1;
    }
    // Rechercher l'adresse IP
    result = MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (result.found_entry) {
        // Récupérer les données de la ville (en français)
        if (MMDB_get_value(&result.entry, &city_entry, "city", "names", "fr", NULL) == 0 && city_entry.has_data) {
            printf("Ville : %s\n", city_entry.utf8_string);
        } else if (MMDB_get_value(&result.entry, &city_entry, "city", NULL) == 0 && city_entry.has_data) {
             printf("Ville (par défaut) : %s\n", city_entry.utf8_string);
        }
        // Récupérer les données du pays (en anglais)
        if (MMDB_get_value(&result.entry, &country_entry, "country", "names", "en", NULL) == 0 && country_entry.has_data) {
            printf("Pays : %s\n", country_entry.utf8_string);
        } else if (MMDB_get_value(&result.entry, &country_entry, "country", NULL) == 0 && country_entry.has_data) {
            printf("Pays (par défaut) : %s\n", country_entry.utf8_string);
        }
        // Libérer les données récupérées
        MMDB_free_entry_data_list(city_entry.list);
        MMDB_free_entry_data_list(country_entry.list);
    } else {
        fprintf(stderr, "Aucune entrée trouvée pour %s\n", ip_address);
        if (gai_error != 0) {
            fprintf(stderr, "Erreur getaddrinfo: %d\n", gai_error);
        }
        if (mmdb_error != 0) {
            fprintf(stderr, "Erreur MaxMindDB: %s\n", MMDB_strerror(mmdb_error));
        }
    }
    // Fermer la base de données
    MMDB_close(&mmdb);
    return 0;
}

Le membre data_size n'est pertinent que pour les données de type utf8_string et bytes. utf8_string n'est pas terminé par un caractère nul et data_size *doit* être utilisé pour déterminer sa longueur.

Le membre type peut être comparé à l'une des macros MMDB_DATA_TYPE_*.

Entiers 128 bits

La gestion des données uint128 dépend de la manière dont votre plateforme prend en charge les entiers 128 bits, si tant est qu'elle le fasse. Avec GCC 4.4 et 4.5, nous pouvons écrire unsigned int __attribute__ ((__mode__ (TI))). Avec les versions plus récentes de GCC (4.6+) et clang (3.2+), nous pouvons simplement écrire "unsigned __int128".

Afin de contourner ces différences, cette bibliothèque définit un type mmdb_uint128_t. Ce type est défini dans l'en-tête maxminddb.h afin que vous puissiez l'utiliser dans votre propre code.

Avec les compilateurs plus anciens, nous ne pouvons pas utiliser un entier, nous utilisons donc plutôt un tableau de 16 octets de valeurs uint8_t. Ce sont les données brutes de la base de données.

Cette bibliothèque fournit une macro publique MMDB_UINT128_IS_BYTE_ARRAY. Si elle est vraie (1), alors les valeurs uint128 sont renvoyées sous forme de tableau d'octets, si elle est fausse, elles sont renvoyées sous forme d'entier mmdb_uint128_t.

Macros de type de données

Cette bibliothèque fournit une macro pour chaque type de données défini par la spécification MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

Il existe également quelques types réservés à un usage interne :

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

Si vous voyez l'un de ceux-ci dans les données renvoyées, c'est que quelque chose s'est très mal passé. La base de données est endommagée ou a été générée incorrectement, ou il y a un bug dans le code de libmaxminddb.

Valeurs de pointeur et MMDB_close()

Les membres utf8_string, bytes et (peut-être) uint128 de cette structure sont tous des pointeurs directs dans la section des données de la base de données. Il peut s'agir d'un bloc mémoire alloué avec calloc ou mmap. Dans les deux cas, ces pointeurs deviendront invalides après l'appel de MMDB_close().

Si vous devez faire référence à ces données après cette date, vous devriez copier les données avec une fonction appropriée (strdup, memcpy, etc.).

MMDB_entry_data_list_s

Cette structure encapsule une liste chaînée de structures MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

Cette structure vous permet de consulter l'ensemble des données de type map ou array en parcourant la liste chaînée.

MMDB_search_node_s

Cette structure encapsule les deux enregistrements d'un nœud de recherche. Ceci n'est vraiment utile que si vous souhaitez écrire du code qui parcourt l'intégralité de l'arbre de recherche au lieu de rechercher une adresse IP spécifique.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

Les deux types d'enregistrement prendront l'une des valeurs suivantes :

  • MMDB_RECORD_TYPE_SEARCH_NODE - L'enregistrement pointe vers le nœud de recherche suivant.
  • MMDB_RECORD_TYPE_EMPTY - L'enregistrement est un espace réservé qui indique qu'il n'y a pas de données pour l'adresse IP. La recherche doit se terminer ici.
  • MMDB_RECORD_TYPE_DATA - L'enregistrement contient des données dans la section de données de la base de données. Utilisez l'entrée de l'enregistrement lors de la recherche des données pour l'enregistrement.
  • MMDB_RECORD_TYPE_INVALID - L'enregistrement est invalide. Soit un nœud invalide a été recherché, soit la base de données est corrompue.

Le MMDB_entry_s pour l'enregistrement n'est valide que si le type est MMDB_RECORD_TYPE_DATA. Les tentatives d'utilisation d'une entrée pour d'autres types d'enregistrements entraîneront une erreur ou des données invalides.

Codes de statut

Cette bibliothèque renvoie (ou remplit) des codes de statut pour de nombreuses fonctions. Ces codes de statut sont :

  • MMDB_SUCCESS - tout a fonctionné
  • MMDB_FILE_OPEN_ERROR - une erreur s'est produite lors de la tentative d'ouverture du fichier MaxMind DB.
  • MMDB_IO_ERROR - une opération d'E/S a échoué. Vérifiez errno pour plus de détails.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - la recherche d'une adresse IP dans l'arbre de recherche a donné un résultat impossible. La base de données est endommagée ou a été générée incorrectement, ou il y a un bug dans le code de libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - quelque chose dans la base de données est incorrect. Cela inclut les clés de métadonnées manquantes ainsi que les valeurs impossibles (comme un ip_version de 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - Les métadonnées de la base de données indiquent que sa version majeure n'est pas 2. Cette bibliothèque ne peut gérer que la version majeure 2.
  • MMDB_OUT_OF_MEMORY_ERROR - un appel d'allocation de mémoire (malloc, etc.) a échoué.
  • MMDB_INVALID_DATA_ERROR - une entrée dans la section des données contient des données invalides. Par exemple, un champ uint16 prétend avoir plus de 2 octets de longueur. La base de données est probablement endommagée ou a été générée incorrectement.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - Le chemin de recherche passé à MMDB_get_value, MMDB_vget_value ou MMDB_aget_value contient un décalage de tableau supérieur à LONGMAX ou inférieur à LONGMIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - Le chemin de recherche passé à MMDB_get_value,MMDB_vget_value, ou MMDB_aget_value ne correspond pas à la structure de données de l'entrée. Il existe un certain nombre de raisons pour lesquelles cela peut se produire. Le chemin de recherche pourrait inclure une clé non présente dans un map. Le chemin de recherche pourrait inclure un index de tableau supérieur à un tableau existant ou inférieur à l'offset minimum par rapport à la fin d'un tableau. Cela peut également se produire lorsque le chemin s'attend à trouver un map ou un tableau là où il n'y en a aucun.

Tous les codes de statut doivent être traités comme des valeurs int.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

Cette fonction prend un code de statut et renvoie une chaîne de caractères anglaise expliquant le statut.

Fonctions

Cette bibliothèque fournit les fonctions exportées suivantes :

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

Cette fonction ouvre un handle vers un fichier MaxMind DB. Sa valeur de retour est un code de statut tel que défini ci-dessus. Vérifiez toujours la valeur de retour de cet appel.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

filename doit être encodé en UTF-8 sur Windows.

La structure MMDB_s que vous passez peut être sur la pile ou allouée depuis le tas. Cependant, si l'ouverture réussit, elle contiendra des données allouées par le tas, vous devrez donc la fermer avec MMDB_close(). Si le statut renvoyé n'est pas MMDB_SUCCESS, cette bibliothèque s'assure que toute la mémoire allouée est libérée avant de retourner.

Les drapeaux actuellement fournis sont :

•
MMDB_MODE_MMAP - ouvre la base de données avec mmap().

Passer d'autres valeurs pour flags peut conduire à des résultats imprévisibles. À l'avenir, nous pourrons ajouter des drapeaux supplémentaires que vous pourrez combiner avec le mode par opération OU bit à bit, ainsi que des modes supplémentaires.

Vous pouvez également passer 0 comme valeur de flags, auquel cas la base de données sera ouverte avec les drapeaux par défaut. Cependant, ces valeurs par défaut peuvent changer dans les futures versions. La valeur par défaut actuelle est MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Cela libère toute mémoire allouée ou mappée en mémoire qui est détenue par la structure MMDB_s. *Cela ne libère pas la mémoire al

situé pour la structure elle-même ! Si vous avez alloué la structure à partir du tas, vous êtes responsable de sa libération.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

Cette fonction recherche une adresse IP passée sous forme de chaîne de caractères terminée par un caractère nul. En interne, elle appelle getaddrinfo() pour résoudre l'adresse en forme binaire. Elle appelle ensuite MMDB_lookup_sockaddr() pour rechercher l'adresse dans la base de données. Si vous avez déjà résolu une adresse, vous pouvez appeler MMDB_lookup_sockaddr() directement, plutôt que de résoudre l'adresse deux fois.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Cette fonction retourne toujours une structure MMDB_lookup_result_s, mais vous devez également vérifier les paramètres gai_error et mmdb_error. Si l'un d'eux indique une erreur, la structure retournée est dénuée de sens.

Si aucune erreur ne s'est produite, vous devez toujours vous assurer que le membre found_entry du résultat retourné est vrai. Si ce n'est pas le cas, cela signifie que l'adresse IP n'a pas d'entrée dans la base de données.

Cette fonction fonctionnera avec les adresses IPv4 même lorsque la base de données contient des données pour les adresses IPv4 et IPv6. L'adresse IPv4 sera recherchée sous la forme '::xxx.xxx.xxx.xxx' plutôt que d'être re-mappée dans le bloc ::ffff:xxx.xxx.xxx.xxx alloué aux adresses IPv6 mappées IPv4.

Si vous passez une adresse IPv6 à une base de données ne contenant que des données IPv4, le membre found_entry sera faux, mais le statut mmdb_error sera toujours MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

Cette fonction recherche une adresse IP qui a déjà été résolue par getaddrinfo().

En dehors du fait qu'elle n'appelle pas getaddrinfo() elle-même, cette fonction est identique à la fonction MMDB_lookup_string().

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Fonctions de recherche de données

Il existe trois fonctions pour rechercher des données associées à une adresse IP.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Les trois fonctions permettent trois styles d'appel légèrement différents, mais elles font toutes la même chose.

Le premier paramètre est une valeur MMDB_entry_s. Dans la plupart des cas, elle proviendra de la valeur MMDB_lookup_result_s retournée par MMDB_lookup_string() ou MMDB_lookup_sockaddr().

Le second paramètre est une référence à une structure MMDB_entry_data_s. Elle sera remplie avec les données recherchées, si elles sont trouvées. Si rien n'est trouvé, le membre has_data de cette structure sera faux. Si has_data est vrai, vous pouvez examiner le membre data_type.

Le dernier paramètre est un chemin de recherche. Le chemin se compose d'un ensemble de chaînes représentant soit des clés de mappage (par exemple, "city"), soit des indices de tableau (par exemple, "0", "1", "-1") à utiliser dans la recherche.

Les indices de tableau négatifs seront traités comme un décalage par rapport à la fin du tableau. Par exemple, "-1" fait référence au dernier élément du tableau.

Le chemin de recherche vous permet de naviguer dans une structure de données complexe. Par exemple, étant donné ces données :

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Nous pourrions rechercher le nom anglais avec ce code :

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

Si nous voulions trouver la première ville, le chemin de recherche serait "cities", "0". Si vous ne fournissez aucun chemin de recherche, vous obtiendrez l'entrée qui correspond à la carte de niveau supérieur. Le chemin de recherche doit toujours se terminer par NULL, quelle que soit la fonction que vous appelez.

La fonction MMDB_get_value accepte un nombre variable d'arguments. Tous les arguments après le pointeur de structure MMDB_entry_data_s * constituent le chemin de recherche. Le dernier argument doit être NULL.

La fonction MMDB_vget_value accepte une va_list comme chemin de recherche. Le dernier élément récupéré par va_arg() doit être NULL.

Enfin, la fonction MMDB_aget_value accepte un tableau de chaînes de caractères comme chemin de recherche. Le dernier membre de ce tableau doit être NULL.

Si vous souhaitez obtenir toutes les données d'entrée en une seule fois, vous pouvez appeler MMDB_get_entry_data_list() à la place.

Pour chacune des trois fonctions, la valeur de retour est un code de statut tel que défini ci-dessus.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

Cette fonction vous permet d'obtenir toutes les données d'une structure de données complexe en une seule fois, plutôt que de rechercher chaque élément en appelant répétitivement MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// sauvegarder ceci pour pouvoir libérer ces données plus tard
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

Il vous appartient d'interpréter la structure de données entry_data_list. La liste est liée dans un parcours en profondeur. Utilisons cette structure comme exemple :

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

La liste se composera des éléments suivants :

1.
MAP - carte de niveau supérieur
2.
UTF8_STRING - clé "names"
3.
MAP - carte pour la clé "names"
4.
UTF8_STRING - clé "en"
5.
UTF8_STRING - valeur pour la clé "en"
6.
UTF8_STRING - clé "de"
7.
UTF8_STRING - valeur pour la clé "de"
8.
UTF8_STRING - clé "cities"
9.
ARRAY - valeur pour la clé "cities"
10.
UTF8_STRING - array[0]
11.
UTF8_STRING - array[1]

La valeur de retour de la fonction est un code de statut tel que défini ci-dessus.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(
    MMDB_entry_data_list_s *const entry_data_list);

Les fonctions MMDB_get_entry_data_list() et MMDB_get_metadata_as_entry_data_list() alloueront la structure de liste chaînée à partir du tas. Appelez cette fonction pour libérer la structure MMDB_entry_data_list_s.

MMDB_get_metadata_as_entry_data_list()

int MMDB_get_metadata_as_entry_data_list(
    MMDB_s *const mmdb,
    MMDB_entry_data_list_s **const entry_data_list);

Cette fonction vous permet de récupérer les métadonnées de la base de données sous forme de liste chaînée de structures MMDB_entry_data_list_s. Cela peut être une manière plus pratique de traiter les métadonnées que d'utiliser directement la structure de métadonnées.

    MMDB_entry_data_list_s *entry_data_list, *first;
    int status =
        MMDB_get_metadata_as_entry_data_list(&mmdb, &entry_data_list);
    if (MMDB_SUCCESS != status) { ... }
    first = entry_data_list;
    ... // faire quelque chose avec les données
    MMDB_free_entry_data_list(first);

La valeur de retour de la fonction est un code de statut tel que défini ci-dessus.

MMDB_dump_entry_data_list()

int MMDB_dump_entry_data_list(
    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

Cette fonction prend une liste chaînée de structures MMDB_entry_data_list_s et la convertit en chaîne de caractères vers le stream donné. Le paramètre indent est le niveau d'indentation de départ pour la sortie générée. Il est incrémenté pour les structures de données imbriquées (cartes, tableaux, etc.).

Le stream doit être un descripteur de fichier (stdout, etc.). Si votre plateforme fournit quelque chose comme open_memstream() de GNU, vous pouvez l'utiliser pour capturer la sortie sous forme de chaîne de caractères.

La sortie est formatée d'une manière proche du JSON, mais les valeurs sont marquées avec leur type de données (sauf pour les cartes et les tableaux qui sont affichés avec "{}" et "[]" respectivement).

Le format de sortie spécifique peut changer dans les futures

relâcher, donc vous ne devriez pas vous fier au formatage spécifique produit par cette fonction. Elle est destinée à être utilisée pour afficher des données aux utilisateurs de manière lisible et à des fins de débogage.

La valeur de retour de la fonction est un code d'état tel que défini ci-dessus.

MMDB_read_node()

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

Cette fonction lit un nœud spécifique dans l'arbre de recherche. Le troisième argument est une référence à une structure MMDB_search_node_s qui sera remplie par cette fonction.

La valeur de retour est un code d'état. Si vous passez un node_number supérieur au nombre de nœuds dans la base de données, cette fonction renverra MMDB_INVALID_NODE_NUMBER_ERROR, sinon elle renverra MMDB_SUCCESS.

Le premier nœud de l'arbre de recherche est toujours le nœud 0. Si vous souhaitiez parcourir l'ensemble de l'arbre de recherche, vous commenceriez par lire le nœud 0, puis vous suivriez les enregistrements qui composent ce nœud, en fonction du type de chaque enregistrement. Si le type est MMDB_RECORD_TYPE_SEARCH_NODE, l'enregistrement contient un entier indiquant le nœud suivant à rechercher.

MMDB_lib_version()

const char *MMDB_lib_version(void)

Cette fonction renvoie la version de la bibliothèque sous forme de chaîne de caractères, quelque chose comme "2.0.0".

EXEMPLE

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Impossible d'ouvrir %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    Erreur d'E/S : %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Erreur de getaddrinfo pour %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Erreur de libmaxminddb : %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Erreur lors de la recherche des données d'entrée - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  Aucune entrée trouvée pour cette adresse IP (%s)\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
