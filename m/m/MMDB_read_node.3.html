DESCRIPTION

La bibliothèque libmaxminddb fournit des fonctions pour travailler avec les fichiers MaxMind DB. Voir https://maxmind.github.io/MaxMind-DB/ pour la spécification du format MaxMind DB. La base de données et les résultats sont représentés par différentes structures de données. Les bases de données sont ouvertes en appelant MMDB_open(). Vous pouvez rechercher des adresses IP sous forme de chaîne de caractères avec MMDB_lookup_string() ou sous forme de pointeur vers une structure sockaddr avec MMDB_lookup_sockaddr().

Si la recherche trouve l'adresse IP dans la base de données, elle renvoie une structure MMDB_lookup_result_s. Si cette structure indique que la base de données contient des données pour l'IP, il existe plusieurs fonctions qui peuvent être utilisées pour récupérer ces données. Celles-ci incluent MMDB_get_value() et MMDB_get_entry_data_list(). Voir la documentation de la fonction ci-dessous pour plus de détails.

Lorsque vous avez terminé avec le descripteur de la base de données, vous devez appeler MMDB_close().

Toutes les fonctions, structures et macros publiquement visibles commencent par "MMDB_".

STRUCTURES DE DONNÉES

Toutes les structures de données exportées par l'en-tête maxminddb.h de cette bibliothèque sont typées sous la forme typedef struct foo_s { ... } foo_s, vous pouvez donc y faire référence sans le préfixe struct.

Cette bibliothèque fournit les structures de données suivantes :

MMDB_s

Ceci est le descripteur d'un fichier MaxMind DB. Nous ne documentons que certains champs de cette structure destinés à un usage public. Tous les autres champs sont susceptibles d'être modifiés et sont uniquement destinés à un usage interne.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - les indicateurs avec lesquels cette base de données a été ouverte. Voir la documentation de MMDB_open() pour plus de détails.
  • const char *filename - le nom du fichier qui a été ouvert, tel que passé à MMDB_open().
  • MMDB_metadata_s metadata - les métadonnées de la base de données.

MMDB_metadata_s et MMDB_description_s

Cette structure peut être récupérée à partir de la structure MMDB_s. Elle contient les métadonnées lues depuis le fichier de base de données. Notez qu'il peut être plus pratique d'accéder à ces métadonnées en appelant plutôt MMDB_get_metadata_as_entry_data_list().

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Ces structures devraient être globalement auto-explicatives.

Le membre ip_version devrait toujours être 4 ou 6. Le membre binary_format_major_version devrait toujours être 2.

Il n'est pas obligatoire que les métadonnées de la base de données incluent des langues ou des descriptions, donc le count pour ces parties des métadonnées peut être zéro. Tous les autres champs de MMDB_metadata_s devraient être renseignés.

MMDB_lookup_result_s

Cette structure est renvoyée comme résultat de la recherche d'une adresse IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si le membre found_entry est faux, alors les autres membres de cette structure ne contiennent pas de valeurs significatives. Vérifiez toujours d'abord que found_entry est vrai.

Le membre entry est utilisé pour rechercher les données associées à l'adresse IP.

Le membre netmask vous indique à quel sous-réseau appartient l'adresse IP dans cette base de données. Par exemple, si vous recherchez l'adresse 1.1.1.1 dans une base de données IPv4 et que le netmask renvoyé est 16, alors l'adresse fait partie du sous-réseau 1.1.0.0/16.

Si la base de données est une base de données IPv6, le masque de réseau renvoyé est toujours une longueur de préfixe IPv6 (de 0 à 128), même si cette base de données contient *également* des réseaux IPv4. Si vous recherchez une adresse IPv4 et que vous souhaitez convertir le masque de réseau en une valeur de masque de réseau IPv4, vous pouvez simplement soustraire 96 de la valeur.

MMDB_result_s

Vous n'avez pas vraiment besoin d'explorer cette structure en détail. Vous l'obtiendrez d'une structure MMDB_lookup_result_s et la passerez à diverses fonctions.

MMDB_entry_data_s

Cette structure est utilisée pour renvoyer une seule entrée de données pour une IP. Ces entrées peuvent à leur tour pointer vers d'autres entrées, comme c'est le cas pour les cartes et les tableaux. Certains membres de cette structure ne sont pas documentés car ils sont uniquement destinés à un usage interne.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t or uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

MMDB_entry_data_list_s

Cette structure est utilisée pour représenter une liste d'entrées de données. Vous pouvez accéder aux éléments de cette liste en suivant le pointeur next.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

Utilisez MMDB_free_entry_data_list() pour libérer la mémoire allouée pour une liste d'entrées de données.

MMDB_search_node_s

Cette structure est utilisée par la fonction MMDB_read_node() pour renvoyer des informations sur un nœud spécifique dans la structure de données interne de la base de données.

typedef struct MMDB_search_node_s {
    uint32_t number;
    bool is_ipv4;
    uint32_t prefix_len;
    uint32_t children[2];
    MMDB_entry_s entry;
} MMDB_search_node_s;

number : Le numéro du nœud.

is_ipv4 : Vrai si le nœud représente un réseau IPv4.

prefix_len : La longueur du préfixe réseau représenté par ce nœud.

children[2] : Les numéros des nœuds enfants (gauche et droite).

entry : L'entrée de données associée à ce nœud.

FONCTIONS

MMDB_open()

Ouvre un fichier MaxMind DB spécifié par filename. flags peut être une combinaison de:

MMDB_START_READING_FROM_FIRST_NODE
Pour commencer la lecture à partir du premier nœud. Sinon, la lecture commence à partir du nœud 0.
MMDB_CASE_INSENSITIVE_LOOKUP
Pour effectuer des recherches insensibles à la casse.

Le descripteur de la base de données est renvoyé dans la structure points par mmdb. Renvoie MMDB_SUCCESS en cas de succès, ou un code d'erreur MaxMind DB en cas d'échec.

MMDB_close()

Ferme un descripteur de base de données ouvert précédemment par MMDB_open() et libère toutes les ressources associées.

MMDB_lookup_string()

Recherche une adresse IP représentée par la chaîne ipstr dans la base de données MaxMind DB pointée par mmdb. Les erreurs potentielles de résolution de nom d'hôte sont renvoyées dans gai_error, et les erreurs spécifiques à MaxMind DB sont renvoyées dans mmdb_error. Renvoie une structure MMDB_lookup_result_s contenant le résultat de la recherche.

MMDB_lookup_sockaddr()

Recherche une adresse IP représentée par la structure sockaddr pointée par sockaddr dans la base de données MaxMind DB pointée par mmdb. Les erreurs spécifiques à MaxMind DB sont renvoyées dans mmdb_error. Renvoie une structure MMDB_lookup_result_s contenant le résultat de la recherche.

MMDB_get_value()

Récupère la valeur d'une entrée dans la base de données MaxMind DB. start est un pointeur vers une structure MMDB_entry_s (généralement obtenue à partir d'un résultat de recherche). entry_data est un pointeur vers une structure MMDB_entry_data_s où le résultat sera stocké. Les arguments de suivi de points (les trois points dans la syntaxe) sont une liste de chaînes de caractères représentant le chemin d'accès aux données souhaitées dans la structure imbriquée de la base de données. Par exemple, pour obtenir la valeur de {"country": {"iso_code"}}, vous appelleriez MMDB_get_value(entry, &data, "country", "iso_code", NULL). Renvoie MMDB_SUCCESS en cas de succès.

MMDB_vget_value()

Version de MMDB_get_value() qui accepte une liste d'arguments variable (va_list) pour le chemin d'accès.

MMDB_aget_value()

Version de MMDB_get_value() qui accepte un tableau de chaînes de caractères (const char *const *const path) pour le chemin d'accès. Le tableau doit être terminé par un pointeur NULL.

MMDB_get_entry_data_list()

Récupère toutes les données associées à une entrée sous forme de liste chaînée de structures MMDB_entry_data_list_s. start est un pointeur vers une structure MMDB_entry_s. entry_data_list est un pointeur vers un pointeur où l'adresse de la première structure de la liste sera stockée. Renvoie MMDB_SUCCESS en cas de succès.

MMDB_free_entry_data_list()

Libère la mémoire allouée pour une liste d'entrées de données créée par MMDB_get_entry_data_list().

MMDB_get_metadata_as_entry_data_list()

Récupère les métadonnées de la base de données sous forme de liste chaînée de structures MMDB_entry_data_list_s. mmdb est un pointeur vers le descripteur de la base de données. entry_data_list est un pointeur vers un pointeur où l'adresse de la première structure de la liste sera stockée. Renvoie MMDB_SUCCESS en cas de succès.

MMDB_dump_entry_data_list()

Imprime le contenu d'une liste d'entrées de données dans un flux spécifié par stream. entry_data_list est un pointeur vers la liste d'entrées à imprimer. indent spécifie le niveau d'indentation pour l'affichage.

MMDB_read_node()

Lit un nœud spécifique de la structure de données interne de la base de données. mmdb est un pointeur vers le descripteur de la base de données. node_number est le numéro du nœud à lire. node est un pointeur vers une structure MMDB_search_node_s où les informations du nœud seront stockées. Renvoie MMDB_SUCCESS en cas de succès.

MMDB_lib_version()

Renvoie une chaîne de caractères indiquant la version de la bibliothèque libmaxminddb.

MMDB_strerror()

Traduit un code d'erreur MaxMind DB spécifié par error_code en une chaîne de caractères lisible par l'homme.

EXEMPLES

Voici un exemple simple d'utilisation de libmaxminddb pour rechercher une adresse IP :

#include <stdio.h>
#include <stdlib.h>
#include <maxminddb.h>

int main(int argc, char **argv) {
    MMDB_s mmdb;
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result;

    if (argc != 3) {
        fprintf(stderr, "Usage: %s <database_file> <ip_address>\n", argv[0]);
        return 1;
    }

    const char *filename = argv[1];
    const char *ipstr = argv[2];

    int status = MMDB_open(filename, 0, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "Failed to open MaxMind DB file: %s\n", filename);
        return 1;
    }

    result = MMDB_lookup_string(mmdb, ipstr, &gai_error, &mmdb_error);

    if (result.found_entry) {
        MMDB_entry_data_s entry_data;
        status = MMDB_get_value(&result.entry, &entry_data, "country", "iso_code", NULL);
        if (MMDB_SUCCESS == status && entry_data.has_data) {
            printf("Country ISO Code: %s\n", entry_data.utf8_string);
        } else {
            printf("Could not retrieve country ISO code for %s\n", ipstr);
        }
    } else {
        fprintf(stderr, "IP address %s not found in database\n", ipstr);
    }

    MMDB_close(&mmdb);
    return 0;
}

ERREURS

Les codes d'erreur possibles renvoyés par les fonctions libmaxminddb sont définis dans maxminddb.h et incluent:

MMDB_SUCCESS
Opération réussie.
MMDB_FILE_NOT_FOUND
Le fichier de base de données spécifié n'a pas été trouvé.
MMDB_INVALID_FILE_STRUCTURE
La structure du fichier MaxMind DB est invalide.
MMDB_OUT_OF_MEMORY
Échec de l'allocation de mémoire.
MMDB_INVALID_DATA_TYPE
Type de données invalide trouvé dans la base de données.
MMDB_INVALID_DATA_LOOKUP
Erreur lors de la recherche de données.

Mantén toda la estructura del archivo.

Cuando estés trabajando con el type member, debes ver el pointer member de la unión. El pointer member de la unión nunca debe ser poblado en ningún dato devuelto por la API. Los pointers deben resolverse internamente.

El data_size member es solo relevante para los datos de tipo utf8_string y bytes. El utf8_string no es terminado con NULL y data_size debe usarse para determinar su longitud.

El type member puede compararse con uno de los macros MMDB_DATA_TYPE_*.

Entiers 128 bits

El manejo de datos de tipo uint128 depende de cómo tu plataforma soporta los enteros de 128 bits, si lo hace o no. Con GCC 4.4 y 4.5 podemos escribir unsigned int __attribute__ ((__mode__ (TI))). Con versiones más recientes de GCC (4.6+) y clang (3.2+) podemos simplemente escribir "unsigned __int128".

Para trabajar alrededor de estas diferencias, esta librería define un tipo mmdb_uint128_t. Este tipo está definido en el archivo maxminddb.h para que puedas usarlo en tu código propio.

Con compiladores antiguos, no podemos usar un entero, así que usamos un array de 16 bytes de uint8_t. Esto es el dato raw de la base de datos.

Esta librería proporciona un macro público MMDB_UINT128_IS_BYTE_ARRAY. Si este es verdadero (1), los valores de uint128 se devuelven como un array de bytes, si es falso, se devuelven como un entero mmdb_uint128_t.

Macros de tipo de datos

Esta librería proporciona un macro para cada tipo de datos definido por la especificación de MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

También hay algunos tipos que se usan únicamente internamente:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

Si ves uno de estos en los datos devueltos, algo ha ido muy mal. La base de datos está dañada o fue generada incorrectamente o hay un bug en el código de libmaxminddb.

Valores Puntero y MMDB_close()

Los utf8_string, bytes y (posiblemente) el miembro uint128 de esta estructura son todos punteros directamente hacia la sección de datos de la base de datos. Esto puede ser un bloque calloc o un bloque mmap. En cualquier caso, estos punteros se vuelven inválidos después de que se llame a MMDB_close().

Si necesitas referirte a este dato después de ese tiempo, debes copiar los datos con una función adecuada (strdup, memcpy, etc.).

MMDB_entry_data_list_s

Esta estructura encapsula una lista enlazada de estructuras MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {  
    MMDB_entry_data_s entry_data;  
    struct MMDB_entry_data_list_s *next;  
} MMDB_entry_data_list_s;

Esta estructura te permite ver datos enteros de mapa o array mediante iteración sobre la lista enlazada.

MMDB_search_node_s

Esta estructura encapsula los dos registros de un nodo de búsqueda. Esta es realmente útil si quieres escribir código que itera sobre el árbol de búsqueda completo en lugar de buscar un IP específico.

typedef struct MMDB_search_node_s {  
    uint64_t left_record;  
    uint64_t right_record;  
    uint8_t left_record_type;  
    uint8_t right_record_type;  
    MMDB_entry_s left_record_entry;  
    MMDB_entry_s right_record_entry;  
} MMDB_search_node_s;

Los dos tipos de registro tomarán uno de los siguientes valores:

  • MMDB_RECORD_TYPE_SEARCH_NODE - El registro apunta al siguiente nodo de búsqueda.
  • MMDB_RECORD_TYPE_EMPTY - El registro es un placeholder que indica que no hay datos para el IP. La búsqueda debe finalizar aquí.
  • MMDB_RECORD_TYPE_DATA - El registro contiene datos en la sección de datos de la base de datos. Usa el registro cuando busques los datos para el registro.
  • MMDB_RECORD_TYPE_INVALID - El registro es inválido. Esto puede ser debido a un nodo inválido o a una base de datos dañada.

El MMDB_entry_s del registro solo es válido si el tipo es MMDB_RECORD_TYPE_DATA. El uso de un registro para otros tipos de registro dará un error o datos inválidos.

CÓDIGOS DE ESTADO

Esta librería devuelve (o pobla) códigos de estado para muchas funciones. Estos códigos de estado son:

  • MMDB_SUCCESS - todo funcionó.
  • MMDB_FILE_OPEN_ERROR - hubo un error al abrir el archivo MaxMind DB.
  • MMDB_IO_ERROR - una operación de entrada/salida falló. Verifica errno para más detalles.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - al buscar un IP en el árbol de búsqueda se obtuvo un resultado imposible. La base de datos está dañada o fue generada incorrectamente o hay un bug en el código de libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - algo en la base de datos está mal. Esto incluye claves de metadatos ausentes o valores imposibles (como un ip_version de 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - la metadata de la base de datos indica que su versión mayor es 2. Esta librería solo puede manejar la versión 2.
  • MMDB_OUT_OF_MEMORY_ERROR - un llamado a una asignación de memoria (como malloc) falló.
  • MMDB_INVALID_DATA_ERROR - un campo de la sección de datos contiene datos inválidos. Por ejemplo, un campo uint16 dice ser más largo que 2 bytes. La base de datos podría estar dañada o haber sido generada incorrectamente.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - el camino de búsqueda pasado a MMDB_get_value, MMDB_vget_value o MMDB_aget_value contiene un desplazamiento de array mayor que LONG_MAX o menor que LONG_MIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - el camino de búsqueda pasado a MMDB_get_value, MMDB_vget_value o MMDB_aget_value no coincide con la estructura de datos de la entrada. Hay varias razones por las que esto puede ocurrir. El camino de búsqueda puede incluir un clave no en un mapa. El camino de búsqueda puede incluir un índice de array mayor que un array o menor que el desplazamiento mínimo desde el final de un array. También puede ocurrir cuando el camino espera encontrar un mapa o array donde ninguno exista.

Todos los códigos de estado deben tratarse como valores int.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

Esta función toma un código de estado y devuelve una cadena en inglés explicando el estado.

FUNCIONES

Esta librería proporciona las siguientes funciones exportadas:

MMDB_open()

int MMDB_open(  
    const char *const filename,  
    uint32_t flags,  
    MMDB_s *const mmdb);

Esta función abre una conexión a un archivo MaxMind DB. El valor devuelto es un código de estado como definido anteriormente. Debes verificar el valor devuelto de esta llamada.

MMDB_s mmdb;  
int status =  
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);  
if (MMDB_SUCCESS != status) { ... }  
...  
MMDB_close(&mmdb);

El filename debe codificarse como UTF-8 en Windows.

La estructura MMDB_s que pasas puede estar en la pila o reservada en la memoria heap. Sin embargo, si la apertura es exitosa, contendrá datos reservados en la memoria heap, así que debes cerrarla con MMDB_close(). Si el estado devuelto no es MMDB_SUCCESS, esta librería asegura que se libere toda la memoria reservada antes de devolver.

Los flags actualmente proporcionados son:

•
MMDB_MODE_MMAP - abre el archivo con mmap().

Pasar otros valores para flags puede dar resultados impredecibles. En el futuro, podríamos añadir otros flags que puedas unir con el modo, así como otros modos.

También puedes pasar 0 como valor de flags en el que el archivo se abrirá con los flags por defecto. Sin embargo, estos valores pueden cambiar en futuras actualizaciones. El valor por defecto actual es MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Esta librería libera cualquier memoria reservada o mmap'd que se haya obtenido del MMDB_s estructura. No libera la memoria de la memoria de la estructura MMDB_s.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

Cette fonction recherche une adresse IP passée sous forme de chaîne de caractères se terminant par null. Elle appelle en interne getaddrinfo() pour résoudre l'adresse sous forme binaire. Ensuite, elle appelle MMDB_lookup_sockaddr() pour rechercher l'adresse dans la base de données. Si vous avez déjà résolu une adresse, vous pouvez appeler directement MMDB_lookup_sockaddr() sans avoir à résoudre l'adresse deux fois.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Cette fonction retourne toujours une structure MMDB_lookup_result_s, mais vous devez également vérifier les paramètres gai_error et mmdb_error. Si l'un deux indique une erreur, la structure retournée sera inutile.

Si aucune erreur ne s'est produite, vous devez quand même vous assurer que le membre found_entry de la structure retournée est vrai. Si ce n'est pas le cas, cela signifie que l'adresse IP n'a pas d'entrée dans la base de données.

Cette fonction fonctionne avec les adresses IPv4 même lorsque la base de données contient des données pour IPv4 et IPv6. L'adresse IPv4 sera recherchée comme '::xxx.xxx.xxx.xxx' au lieu d'être remappée vers le bloc ::ffff:xxx.xxx.xxx.xxx réservé aux adresses IPv6 mappées IPv4.

Si vous passez une adresse IPv6 à une base de données qui ne contient que des données IPv4, le membre found_entry sera faux, mais le statut mmdb_error sera toujours MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

Cette fonction recherche une adresse IP qui a déjà été résolue à l'aide de getaddrinfo().

Sauf si vous n'appelez pas getaddrinfo() vous-même, cette fonction est identique à la fonction MMDB_lookup_string().

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Fonctions de recherche de données

Il existe trois fonctions pour rechercher des données associées à une adresse IP.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Les trois fonctions permettent trois styles d'appel légèrement différents, mais elles effectuent toutes la même tâche.

Le premier paramètre est une valeur MMDB_entry_s. Dans la plupart des cas, cette valeur proviendra de la structure MMDB_lookup_result_s retournée par MMDB_lookup_string() ou MMDB_lookup_sockaddr().

Le second paramètre est une référence à une structure MMDB_entry_data_s. Cette structure sera remplie avec les données recherchées, si des données sont trouvées. Si aucune donnée n'est trouvée, le membre has_data de cette structure sera faux. Si has_data est vrai, vous pouvez examiner le membre data_type.

Le dernier paramètre est un chemin de recherche. Le chemin consiste en une série de chaînes de caractères représentant des clés de map (par exemple, "city") ou des indices de tableau (par exemple, "0", "1", "-1") à utiliser dans la recherche.

Les indices négatifs dans le tableau sont traités comme un décalage par rapport à la fin du tableau. Par exemple, "-1" fait référence au dernier élément du tableau.

Le chemin de recherche permet de naviguer dans une structure complexe. Par exemple, étant donné ces données :

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Vous pourriez rechercher le nom en anglais avec ce code :

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

Si vous souhaitez trouver la première ville, le chemin de recherche serait "cities", "0". Si vous ne fournissez pas de chemin de recherche, vous obtiendrez l'entrée correspondant au niveau supérieur de la map. Le chemin de recherche doit toujours se terminer par NULL, quelle que soit la fonction que vous utilisez.

La fonction MMDB_get_value accepte un nombre variable d'arguments. Tous les arguments après le pointeur MMDB_entry_data_s * constituent le chemin de recherche. Le dernier argument doit être NULL.

La fonction MMDB_vget_value accepte un va_list comme chemin de recherche. Le dernier élément récupéré via va_arg() doit être NULL.

Enfin, la fonction MMDB_aget_value accepte un tableau de chaînes de caractères comme chemin de recherche. Le dernier élément du tableau doit être NULL.

Si vous souhaitez obtenir toutes les données d'une entrée en même temps, vous pouvez appeler MMDB_get_entry_data_list().

Pour chacune des trois fonctions, la valeur de retour est un code d'état tel que défini ci-dessus.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

Cette fonction vous permet d'obtenir toutes les données d'une structure complexe en une seule fois, au lieu de rechercher chaque partie par des appels répétés à MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// sauvegarder cette structure afin de pouvoir la libérer plus tard
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

Il s'agit de parcourir la structure entry_data_list. La liste est chaînée lors d'un parcours en profondeur. Utilisons cette structure comme exemple :

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

La liste sera composée des éléments suivants :

1.
MAP - map du niveau supérieur
2.
UTF8_STRING - clé "names"
3.
MAP - map de la clé "names"
4.
UTF8_STRING - clé "en"
5.
UTF8_STRING - valeur de la clé "en"
6.
UTF8_STRING - clé "de"
7.
UTF8_STRING - valeur de la clé "de"
8.
UTF8_STRING - clé "cities"
9.
ARRAY - valeur de la clé "cities"
10.
UTF8_STRING - array[0]
11.
UTF8_STRING - array[1]

La valeur de retour de la fonction est un code d'état tel que défini ci-dessus.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(
    MMDB_entry_data_list_s *const entry_data_list);

Les fonctions MMDB_get_entry_data_list() et MMDB_get_metadata_as_entry_data_list() allouent la structure chaînée sur le tas. Appelez cette fonction pour libérer la structure MMDB_entry_data_list_s.

MMDB_get_metadata_as_entry_data_list()

int MMDB_get_metadata_as_entry_data_list(
    MMDB_s *const mmdb,
    MMDB_entry_data_list_s **const entry_data_list);

Cette fonction permet de récupérer les métadonnées de la base de données sous forme de liste de structures MMDB_entry_data_list_s. Cela peut être une manière plus pratique de gérer les métadonnées que d'utiliser directement la structure de métadonnées.

    MMDB_entry_data_list_s *entry_data_list, *first;
    int status =
        MMDB_get_metadata_as_entry_data_list(&mmdb, &entry_data_list);
    if (MMDB_SUCCESS != status) { ... }
    first = entry_data_list;
    ... // faire quelque chose avec les données
    MMDB_free_entry_data_list(first);

La valeur de retour de la fonction est un code d'état tel que défini ci-dessus.

MMDB_dump_entry_data_list()

int MMDB_dump_entry_data_list(
    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

Cette fonction prend une liste chaînée de structures MMDB_entry_data_list_s et la sérialise dans le flux donné stream. Le paramètre indent est le niveau d'indentation initial pour la sortie générée. Il est incrémenté pour les structures imbriquées (maps, tableaux, etc.).

Le stream doit être un descripteur de fichier (stdout, etc.). Si votre plateforme propose quelque chose comme open_memstream() de GNU, vous pouvez l'utiliser pour capturer la sortie sous forme de chaîne.

La sortie est formatée de manière similaire à JSON, mais les valeurs sont marquées avec leur type de données (sauf pour les maps et les tableaux, qui sont affichés comme "{}" et "[]" respectivement).

Le format spécifique de la sortie peut changer dans les futures versions.

NOM

MMDB_read_node()

SYNTAXIS

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

DESCRIPTION

Cette fonction lit un nœud spécifique dans l'arbre de recherche. Le troisième argument est une référence à une structure MMDB_search_node_s qui sera remplie par cette fonction.

STRUCTURES DE DONNÉES

La structure MMDB_search_node_s contient des informations sur le nœud actuel.

CODES D'ÉTAT

La valeur de retour est un code d'état tel que défini ci-dessus.

FONCTIONS

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

Cette fonction lit un nœud spécifique dans l'arbre de recherche. Le troisième argument est une référence à une structure MMDB_search_node_s qui sera remplie par cette fonction.

La valeur de retour est un code d'état. Si un node_number supérieur au nombre de nœuds dans la base de données est passé, cette fonction retournera MMDB_INVALID_NODE_NUMBER_ERROR, sinon elle retournera MMDB_SUCCESS.

Le premier nœud de l'arbre de recherche est toujours le nœud 0. Si vous souhaitez parcourir l'intégralité de l'arbre de recherche, vous commenceriez par lire le nœud 0, puis suivriez les entrées qui composent ce nœud, en fonction du type de chaque entrée. Si le type est MMDB_RECORD_TYPE_SEARCH_NODE, l'entrée contient un entier pour le nœud suivant à rechercher.

MMDB_lib_version()

const char *MMDB_lib_version(void)

Cette fonction renvoie la version de la bibliothèque sous forme de chaîne, par exemple "2.0.0".

EXEMPLE

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
