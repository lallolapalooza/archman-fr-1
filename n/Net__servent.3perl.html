Net::servent(3perl) Manuel du programmeur Perl Net::servent(3perl)

NOM

Net::servent - Interface par nom aux fonctions intégrées de Perl getserv*()

SYNOPIS

use Net::servent;
my $s = getservbyname(shift || 'ftp') || die "aucun service";
printf "le port pour %s est %s, les alias sont %s\n",
   $s->name, $s->port, "@{$s->aliases}";
use Net::servent qw(:FIELDS);
getservbyname(shift || 'ftp') || die "aucun service";
print "le port pour $s_name est $s_port, les alias sont @s_aliases\n";

DESCRIPTION

Les exportations par défaut de ce module remplacent les fonctions de base getservent(), getservbyname() et getnetbyport(), en les remplaçant par des versions qui retournent des objets "Net::servent". Elles prennent des arguments seconds par défaut de "tcp". Cet objet possède des méthodes qui retournent le nom de champ de structure de nom similaire de la structure C servent de netdb.h ; à savoir name, aliases, port et proto. La méthode aliases retourne une référence de tableau, les autres des scalaires.

Vous pouvez également importer tous les champs de structure directement dans votre espace de noms en tant que variables régulières à l'aide de la balise d'importation :FIELDS. (Notez que cela remplace toujours vos fonctions de base.) Accédez à ces champs en tant que variables nommées avec un préfixe "s_". Ainsi, "$serv_obj->name()" correspond à $s_name si vous importez les champs. Les références de tableau sont disponibles en tant que variables de tableau régulières, donc par exemple "@{ $serv_obj->aliases()}" serait simplement @s_aliases.

La fonction getserv() est une simple façade qui transmet un argument numérique à getservbyport(), et le reste à getservbyname().

Pour accéder à cette fonctionnalité sans les remplacements de base, passez à "use" une liste d'importation vide, puis accédez aux fonctions de fonctions avec leurs noms qualifiés complets. D'autre part, les fonctions intégrées sont toujours disponibles via le pseudo-paquet "CORE::".

EXEMPLES

use Net::servent qw(:FIELDS);
while (@ARGV) {
    my ($service, $proto) = ((split m!/!, shift), 'tcp');
    my $valet = getserv($service, $proto);
    unless ($valet) {
        warn "$0: Pas de service: $service/$proto\n"
        next;
    }
    printf "le service $service/$proto est le port %d\n", $valet->port;
    print "les alias sont @s_aliases\n" if @s_aliases;
}

NOTE

Bien que cette classe soit actuellement implémentée à l'aide du module Class::Struct pour créer une classe de type struct, vous ne devriez pas vous y fier.
