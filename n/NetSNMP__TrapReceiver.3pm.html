NOM

NetSNMP::TrapReceiver - Gestion des pièges en Perl pour snmptrapd de Net-SNMP

SYNTAXE

Placez les lignes suivantes dans votre fichier snmptrapd.conf :

perl NetSNMP::TrapReceiver::register("trapOID", \&myfunc);

RÉSUMÉ

Le module NetSNMP::TrapReceiver est utilisé pour enregistrer des fonctions Perl dans le processus snmptrapd de Net-SNMP. Net-SNMP doit avoir été configuré au préalable avec --enable-embedded-perl. L'enregistrement des fonctions se fait via le fichier de configuration snmptrapd.conf. Ce module ne peut pas être utilisé dans un script Perl normal pour recevoir des pièges. Il est uniquement destiné à être utilisé en tant qu'élément intégré dans le démon snmptrapd.

DESCRIPTION

Dans le fichier de configuration snmptrapd.conf, le mot-clé "perl" peut être utilisé pour appeler n'importe quelle expression Perl. Avec cette capacité, vous pouvez utiliser le module NetSNMP::TrapReceiver pour enregistrer des fonctions qui seront appelées chaque fois qu'une notification (un piège ou une interrogation) est reçue. Les fonctions enregistrées sont appelées avec deux arguments. Le premier est une référence à un hash contenant des informations sur la façon dont le piège a été reçu (quelle version du protocole SNMP a été utilisée, d'où il provenait, quel nom d'utilisateur ou de communauté a été utilisé pour l'envoyer, etc.). Le second argument est une référence à un tableau contenant les variables bindings (OID et informations de valeur) qui définissent la notification elle-même. Chaque variable est à son tour une référence à un tableau de quatre valeurs : un objet NetSNMP::OID, une représentation string de la valeur associée, le type numérique de la valeur (voir NetSNMP::ASN pour plus de détails sur les informations de typage SNMP), et la valeur brute du piège, codée selon son type. Les types entiers de 64 bits sont renvoyés sous forme de strings, les types entiers comme des entiers, les chaînes comme des chaînes, les identifiants d'objets comme des objets NetSNMP::OID, et tout autre type comme des undefs.

Les fonctions enregistrées doivent renvoyer l'une des valeurs suivantes :

NETSNMPTRAPD_HANDLER_OK
Le piège a été traité avec succès, mais permettez au démon snmptrapd de vérifier d'autres gestionnaires appropriés.
NETSNMPTRAPD_HANDLER_FAIL
Le traitement du piège a échoué, mais permettez au démon snmptrapd de vérifier d'autres gestionnaires appropriés.
NETSNMPTRAPD_HANDLER_BREAK
Arrête l'évaluation des gestionnaires pour ce piège spécifique, mais permettez au démon snmptrapd d'appliquer les gestionnaires globaux.
NETSNMPTRAPD_HANDLER_FINISH
Arrête la recherche d'autres gestionnaires appropriés.

Si une fonction de gestionnaire ne renvoie pas une valeur valide, voire rien, elle est considérée comme renvoyant NETSNMPTRAPD_HANDLER_OK.

Les fonctions sont enregistrées à l'aide de la fonction NetSNMP::TrapReceiver::register, qui prend deux arguments. Le premier est une chaîne décrivant la notification que vous souhaitez enregistrer (comme "linkUp" ou "MyMIB::MyTrap" ou ".1.3.6.1.4.1.2021...."). Deux mots-clés spéciaux peuvent être utilisés à la place d'un OID : "default" et "all". Le mot-clé "default" indique que votre gestionnaire sera appelé si aucun autre gestionnaire n'est appelé. Le mot-clé "all" indique que le gestionnaire doit être appelé chaque fois qu'une notification est reçue.

EXEMPLE

À titre d'exemple, placez le code suivant dans un fichier (disons /usr/local/share/snmp/mytrapd.pl) :

#!/usr/bin/perl
sub my_receiver {
    print "********** PERL HAS RECEIVED A TRAP:\n";
    # Imprimer les informations du PDU (une référence à un hash)
    print "PDU INFO:\n";
    foreach my $k(keys(%{$_[0]})) {
      if ($k eq "securityEngineID" || $k eq "contextEngineID") {
        printf "  %-30s 0x%s\n", $k, unpack('h*', $_[0]{$k});
      }
      else {
        printf "  %-30s %s\n", $k, $_[0]{$k};
      }
    }
    # Imprimer les variables bindings :
    print "VARBINDS:\n";
    foreach my $x (@{$_[1]}) {
        printf "  %-30s type=%-2d value=%s\n", $x->[0], $x->[2], $x->[1];
    }
}
NetSNMP::TrapReceiver::register("all", \&my_receiver) ||
  warn "failed to register our perl trap handler\n";
print STDERR "Loaded the example perl snmptrapd handler\n";

Ensuite, placez la ligne suivante dans votre fichier snmptrapd.conf :

perl do /usr/local/share/snmp/mytrapd.pl

Démarrez snmptrapd (en tant que root, et les options suivantes le maintiennent au premier plan et le consignent dans stderr) :

snmptrapd -f -Le

Vous devriez voir le démarrage et le message final du script Perl précédemment affiché :

Loaded the perl snmptrapd handler
2004-02-11 10:08:45 NET-SNMP version 5.2 Started.

Ensuite, si vous envoyez un piège factice à vous-même en utilisant la commande d'exemple suivante :

snmptrap -v 2c -c mycommunity localhost 0 linkUp ifIndex.1 i 1 \
    ifAdminStatus.1 i up ifOperStatus.1 i up ifDescr s eth0

Vous devriez voir la sortie suivante apparaître depuis snmptrapd à mesure que votre code Perl s'exécute :

********** PERL HAS RECEIVED A TRAP:
PDU INFO:
  notificationtype               TRAP
  receivedfrom                   127.0.0.1
  version                        1
  errorstatus                    0
  messageid                      0
  community                      mycommunity
  transactionid                  2
  errorindex                     0
  requestid                      765160220
VARBINDS:
  sysUpTimeInstance              type=67 value=0:0:00:00.00

  ifAdminStatus.1                type=2  value=1
  ifOperStatus.1                 type=2  value=1

Passage d'arguments

Si vous avez besoin de passer des arguments à votre script, vous le ferez par l'une des deux méthodes suivantes :

Utilisation de sous-routines

Vous pouvez définir une sous-routine dans le fichier ou faire en sorte que le fichier lui-même fasse quelque chose. Par exemple, dans le fichier si vous placez :

sub foo {
   print $_[0];
}

et ensuite placez ces lignes dans le fichier snmptrapd.conf :

perl do /path/to/script
perl foo("hello world");
perl foo("now I am passing something different");

Cela exécutera la fonction foo deux fois, et imprimera les résultats sur la console où snmptrapd a été démarré.

Utilisation de variables

Ou vous pourriez toujours définir une variable au préalable :

perl $myVariable = 42;
perl do /path/to/script

Et le script recherchera et utilisera la valeur de $myVariable dans le script.

EXPORTATION

Cependant, aucun d'entre eux n'est exporté par défaut.
