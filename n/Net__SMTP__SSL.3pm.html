NOM

Net::SMTP::SSL - Support SSL pour Net::SMTP

SYNTAXE

use Net::SMTP::SSL;

my $smtps = Net::SMTP::SSL->new("example.com", Port => 465);

OBSOLÈTE

Hé! Lisez ceci!

Depuis Net::SMTP v1.28 (2014-10-08), Net::SMTP lui-même prend en charge le protocole SMTP sur SSL, ainsi que STARTTLS. Utilisez Net::SMTP, pas Net::SMTP::SSL.

DESCRIPTION

Implémente la même API que Net::SMTP, mais utilise IO::Socket::SSL pour ses opérations réseau. En raison de la nature de la méthode "new" de "Net::SMTP", elle n'est pas remplacée pour utiliser un port par défaut pour le service SMTPS. Peut-être que les versions futures seront intelligentes comme ça. Le port 465 est généralement celui que vous voulez, et ce n'est pas une corvée de le spécifier.

Pour la documentation de l'interface, veuillez consulter Net::SMTP.

VOIR AUSSI
