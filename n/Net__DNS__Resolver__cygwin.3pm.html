NOM

Net::DNS::Resolver::cygwin - Classe de résolveur Cygwin

SYNTAXE

use Net::DNS::Resolver;

DESCRIPTION

Cette classe implémente les parties spécifiques à l'OS de "Net::DNS::Resolver".

Aucune partie utilisable par l'utilisateur à l'intérieur, voir Net::DNS::Resolver pour tous vos besoins de résolution.
