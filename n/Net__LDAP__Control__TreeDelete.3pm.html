NOM

Net::LDAP::Control::TreeDelete - Objet de contrôle de suppression d'arbre LDAPv3

SYNOPIS

use Net::LDAP;
use Net::LDAP::Control::TreeDelete;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$treedel = Net::LDAP::Control::TreeDelete->new( critical => 1 );
$msg = $ldap->delete( 'o=University of Michigan,c=US',
                      control  => [ $treedel ] );
die "erreur : ",$msg->code(),": ",$msg->error()  if ($msg->code());

DESCRIPTION

"Net::LDAP::Control::TreeDelete" fournit une interface pour la création et la manipulation d'objets représentant le contrôle "TreeDelete" tel que décrit dans draft-armijo-ldap-treedelete-02.txt https://tools.ietf.org/html/draft-armijo-ldap-treedelete-02

Il permet au client de supprimer un sous-arbre entier.

Le contrôle est approprié pour les opérations de suppression LDAP [RFC4511] uniquement, et inapproprié pour toutes les autres opérations.

Sa criticité peut être VRAIE ou FAUSSE; il n'a pas de valeur.

Il n'y a pas de contrôle de réponse correspondant.

ARGUMENTS DU CONSTRUCTEUR

Étant donné que le contrôle "TreeDelete" n'a pas de valeurs, seuls les arguments du constructeur décrits dans Net::LDAP::Control sont pris en charge

METHODES

Comme il n'y a pas de valeurs supplémentaires dans le contrôle, seules les méthodes de Net::LDAP::Control sont disponibles pour les objets "Net::LDAP::Control::TreeDelete".
