Net::SSL - support pour Secure Sockets Layer

MÉTHODES

new
Crée un nouvel objet "Net::SSL".
configure
Configure un socket "Net::SSL" pour fonctionner.
configure_certs
Configure un fichier de certificat à utiliser pour communiquer sur le socket.
connect
die_with_error
get_cipher
get_lwp_object
Remonte la pile d'appels et recherche quelque chose béni dans le namespace "LWP::UserAgent" et le retourne. Légèrement obsolète.
get_peer_certificate
Obtient le certificat du pair à partir de l'objet sous-jacent "Crypt::SSLeay::Conn".
get_peer_verify
get_shared_ciphers
getchunk
Tente de lire jusqu'à 32 Ko de données depuis le socket. Retourne "undef" si rien n'a été lu, sinon retourne les données sous forme de scalaire.
pending
Fournit un accès à l'attribut "pending" d'OpenSSL sur l'objet de connexion SSL.
getline
Lit un caractère à la fois jusqu'à ce qu'une nouvelle ligne soit rencontrée, et retourne la ligne, y compris la nouvelle ligne. Très inefficace.
print
Concatène les paramètres d'entrée et les écrit sur le socket. N'honore pas $, ni $/. Retourne le nombre d'octets écrits.
printf
Effectue un "sprintf" des paramètres d'entrée (donc, le premier paramètre doit être le format), et écrit le résultat sur le socket. Retourne le nombre d'octets écrits.
proxy
Retourne le nom d'hôte d'un serveur proxy https, tel que spécifié par la variable d'environnement "HTTPS_PROXY".
proxy_connect_helper
Aide à établir une connexion via un proxy.
read
Effectue une lecture sur le socket et retourne le résultat.
ssl_context
sysread
Est un alias de "read".
timeout
Retourne la valeur du délai d'attente du socket telle que définie par la classe implémentée ou 60 secondes par défaut.
blocking
Retourne une valeur booléenne indiquant si le socket sous-jacent est en mode bloquant. Par défaut, les sockets Net::SSL sont en mode bloquant. 
$sock->blocking(0); # passe en mode non bloquant

Cette méthode appelle simplement la méthode sous-jacente "blocking" de l'objet IO::Socket.

write
Écrit les paramètres passés (donc, une liste) sur le socket. Retourne le nombre d'octets écrits.
syswrite
Est un alias de "write".
accept
Pas encore implémenté. Mourra si appelé.
getc
Pas encore implémenté. Mourra si appelé.
getlines
Pas encore implémenté. Mourra si appelé.
ungetc
Pas encore implémenté. Mourra si appelé.
send_useragent_to_proxy
Par défaut (depuis la version 2.80 de "Net::SSL" dans la distribution 0.54 de Crypt::SSLeay), la chaîne d'agent utilisateur n'est plus envoyée au proxy (mais continuera d'être envoyée à l'hôte distant).

Le comportement précédent était d'un bénéfice marginal et pouvait causer des erreurs fatales dans certains scénarios (voir le bug CPAN #4759) et ne se produit donc plus par défaut.

Pour rétablir le comportement précédent, appelez "Net::SSL::send_useragent_to_proxy" avec une valeur vraie (généralement 1).

DIAGNOSTICS

"pas de port donné pour le serveur proxy <proxy>"

Un proxy a été spécifié pour configurer un socket, mais aucun numéro de port n'a été donné. Assurez-vous que le proxy est spécifié comme une paire hôte:port, tel que "proxy.example.com:8086".

"configure certs échoué : <contenu de $@> ; <contenu de $!>"
"connexion proxy échouée : <contenu de $@> ; <contenu de $!>"
"connexion échouée : <contenu de $@> ; <contenu de $!>"

Pendant connect().

VOIR AUSSI

IO::Socket::INET
"Net::SSL" est implémenté en héritant de "IO::Socket::INET", donc les méthodes non spécifiquement redéfinies sont définies par ce paquet.

Un paquet qui fournit une interface de niveau Perl à la bibliothèque couche de sockets sécurisés "openssl".
