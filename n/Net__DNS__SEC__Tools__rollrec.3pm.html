NOM

Net::DNS::SEC::Tools::rollrec - Manipuler un fichier rollrec de DNSSEC-Tools.

SYNOPSIS

use Net::DNS::SEC::Tools::rollrec;
rollrec_lock();
rollrec_read("localhost.rollrec");
$valid = rollrec_current();
$rrinfo = rollrec_info();
@rrnames = rollrec_names();
$flag = rollrec_exists("example.com");
$rrec = rollrec_fullrec("example.com");
%rrhash = %$rrec;
$zname = $rrhash{"maxttl"};
$val = rollrec_recval("example.com","zonefile");
rollrec_add("roll","example.com",\%rollfields);
rollrec_add("skip","example.com",\%rollfields);
rollrec_del("example.com");
rollrec_rename("example.com","subdom.example.com");
rollrec_type("example.com","roll");
rollrec_type("example.com","skip");
rollrec_setval("example.com","zonefile","db.example.com");
rollrec_delfield("example.com","directory");
rollrec_settime("example.com");
rollrec_settime("example.com",0);
@rollrecfields = rollrec_fields();
$default_file = rollrec_default();
$count = rollrec_merge("primary.rrf", "new0.rrf", "new1.rrf");
@retvals = rollrec_split("new-rollrec.rrf", @rollrec_list);
%zgroups = rollrec_zonegroups();
@zgroup = rollrec_zonegroup($zonegroupname);
@zgcmds = rollrec_zonegroup_cmds();
rollrec_write();
rollrec_close();
rollrec_discard();
rollrec_unlock();

DESCRIPTION

Le module Net::DNS::SEC::Tools::rollrec manipule le contenu d'un fichier rollrec de DNSSEC-Tools. Les fichiers rollrec décrivent le statut d'un processus de rollover de zone, tel qu'effectué par les programmes DNSSEC-Tools. Des interfaces de module existent pour rechercher des enregistrements rollrec, créer de nouveaux enregistrements et modifier des enregistrements existants.

Un fichier rollrec est organisé en ensembles d'enregistrements rollrec. Les rollrec décrivent l'état d'une opération de rollover. Un rollrec se compose d'un ensemble d'entrées clé/valeur. L'exemple suivant est un rollrec :

roll "example"
    zonename                "example.com"
    zonefile                "/etc/dnssec-tools/zones/db.example.com"
    keyrec                  "/etc/dnssec-tools/keyrec/example.keyrec"
    zonegroup               "example zones"
    directory               "/etc/dnssec-tools/dir-example.com"
    kskphase                "0"
    zskphase                "2"
    maxttl                  "86400"
    administrator           "bob@bobhost.example.com"
    phasestart              "Wed Mar 09 21:49:22 2005"
    display                 "0"
    loglevel                "info"
    rollrec_rollsecs        "1115923362"
    rollrec_rolldate        "Tue Mar 09 19:12:54 2005"
    curerrors               0
    maxerrors               5
    # optional records:
    istrustanchor           "yes"
    holddowntime            "8W"

De plus, les commandes à exécuter au démarrage peuvent être définies en utilisant le jeton "cmd", comme montré dans l'exemple suivant.

cmd "rollzsk example.com"

Utilisez cette fonctionnalité avec prudence et seulement si vous comprenez le fonctionnement interne de rollerd et exactement ce qui sera fait par la commande spécifiée.

La première étape pour utiliser ce module doit être de lire le fichier rollrec. L'interface rollrec_read() lit le fichier et le parse en un format interne. Les enregistrements du fichier sont copiés dans une table de hachage (pour une référence facile par les routines de rollrec.pm) et dans un tableau (pour préserver le formatage et les commentaires).

Après lecture du fichier, le contenu est référencé à l'aide de rollrec_fullrec() et rollrec_recval(). Les interfaces rollrec_add(), rollrec_setval() et rollrec_settime() sont utilisées pour modifier le contenu d'un enregistrement rollrec.

Si le fichier rollrec a été modifié, il doit être explicitement écrit, sinon les changements ne seront pas sauvegardés. rollrec_write() sauvegarde le nouveau contenu sur le disque. rollrec_close() sauvegarde le fichier et ferme le descripteur de fichier Perl vers le fichier rollrec. Si un fichier rollrec ne doit plus être ouvert, mais que le contenu ne doit pas être sauvegardé, rollrec_discard() supprime les données, ferme le fichier et le descripteur de fichier, sans sauvegarder les données modifiées.

Lors de la lecture d'un fichier rollrec, les lignes vides consécutives sont réduites à une seule ligne vide. Comme les entrées rollrec sont ajoutées et supprimées, les fichiers fusionnés et les fichiers divisés, il est possible que des blocs de lignes vides consécutives s'agrandissent. Cette réduction des lignes vides empêchera ces blocs de s'agrandir excessivement.

Il existe un rollrec spécial appelé le rollrec d'informations. Il contient des informations sur le fichier rollrec, telles que la version des rollrec stockés dans le fichier. Il n'est accessible que via l'interface rollrec_info(), et l'interface rollrec_current() indiquera si le numéro de version du fichier est à jour.

VERROUILLAGE ROLLREC

Ce module inclut des interfaces pour synchroniser l'accès aux fichiers rollrec. Cette synchronisation est très simple et repose sur le verrouillage et le déverrouillage d'un seul fichier de verrouillage pour tous les fichiers rollrec.

Le verrouillage rollrec n'est pas requis avant d'utiliser ce module, mais il est recommandé. L'utilisation attendue de ces facilités suit ce modèle :

rollrec_lock() || die "impossible de verrouiller le fichier rollrec\n";
rollrec_read();
... effectuer d'autres opérations rollrec ...
rollrec_close();
rollrec_unlock();

La synchronisation est effectuée de cette manière en raison de la façon dont la fonctionnalité du module est implémentée, ainsi que pour offrir de la flexibilité aux utilisateurs du module. Cela fournit également une distinction claire dans le code des appelants quant à l'endroit et au moment où le verrouillage rollrec est effectué.

Cette méthode de synchronisation présente l'inconvénient d'avoir un seul fichier de verrouillage comme goulot d'étranglement pour tout accès aux fichiers rollrec. Cependant, cela réduit la complexité des interfaces de verrouillage et diminue le nombre potentiel de fichiers de verrouillage requis.

L'utilisation d'un seul fichier de synchronisation peut ne pas être pratique dans les installations de grande taille. Si tel est le cas, cela sera revu.

INTERFACES ROLLREC

Les interfaces du module rollrec.pm sont données ci-dessous.

rollrec_add(rollrec_type,rollrec_name,fields)
Cette routine ajoute un nouveau rollrec au fichier rollrec et à la représentation interne du contenu du fichier. Le rollrec est ajouté à la fois à la table de hachage %rollrecs et au tableau @rollreclines. Les entrées ne sont ajoutées que si elles sont définies pour les rollrecs.

rollrec_type est le type du rollrec. Ce doit être "roll" ou "skip". rollrec_name est le nom du rollrec. fields est une référence à une table de hachage qui contient les champs clé/valeur du rollrec. Les clés de la table de hachage sont toujours converties en minuscules, mais les valeurs des entrées restent telles quelles.

Les champs d'horodatage sont ajoutés à la fin du rollrec. Ces champs ont les clés rollrec_gensecs et rollrec_gendate.

Une ligne vide est ajoutée après la dernière ligne du nouveau rollrec. Le fichier rollrec n'est pas écrit après rollrec_add(), bien qu'il soit marqué en interne comme ayant été modifié.

rollrec_close()
Cette interface sauvegarde la version interne du fichier rollrec (ouvert avec rollrec_read()) et ferme le descripteur de fichier.
rollrec_current()
Cette routine renvoie une valeur booléenne indiquant si ce rollrec ouvert est à jour, tel que défini par le numéro de version dans le rollrec d'informations. Les versions 0, 1 et 2 sont considérées comme équivalentes.

Les valeurs de retour sont :

1 rollrec est
actuel
0 rollrec est obsolète
0 rollrec a une version invalide

La dernière condition ne devrait jamais arriver et on pourrait argumenter qu'une valeur d'échec devrait être retournée. Cependant, une fonction booléenne simple à deux valeurs était désirée, pas une fonction à trois valeurs.

rollrec_del(rollrec_name)
Cette routine supprime un rollrec de l'ensemble des rollrecs chargés en mémoire par le module rollrec.pm. Le rollrec est supprimé de la table de hachage %rollrecs et du tableau @rollreclines.

Le fichier rollrec n'est pas écrit après rollrec_del(), bien que la collection des rollrecs soit marquée intérieurement comme modifiée.

Seul le rollrec lui-même est supprimé. Tous les commentaires associés et les lignes vides qui l'entourent sont laissés intacts.

Les valeurs de retour sont :

 0 suppression réussie du rollrec
-1 nom inconnu
rollrec_delfield(rollrec_name,field)
Supprime le champ donné du rollrec spécifié. Le fichier n'est pas écrit après la mise à jour de la valeur, mais le drapeau interne de modification du fichier est défini. La valeur est sauvegardée dans %rollrecs et dans @rollreclines.

Valeurs de retour :

0 - échec (rollrec non trouvé ou rollrec ne contient pas le champ)
1 - succès
rollrec_discard()
Cette routine supprime un fichier rollrec de l'utilisation par un programme. Les données stockées intérieurement sont supprimées et le descripteur de fichier rollrec est fermé. Cependant, les données modifiées ne sont pas sauvegardées avant la fermeture du descripteur de fichier. Ainsi, les données modifiées et nouvelles seront perdues.
rollrec_exists(rollrec_name)
Cette routine retourne un drapeau booléen indiquant si le rollrec nommé dans rollrec_name existe.
rollrec_fullrec(rollrec_name)
rollrec_fullrec() retourne une référence au rollrec spécifié dans rollrec_name.
rollrec_info()
rollrec_info() retourne une référence au rollrec d'info donné dans le fichier actuel. Cette interface est la seule façon pour un programme appelant de récupérer cette information.
rollrec_lock()
rollrec_lock() verrouille le fichier de verrouillage rollrec. Un verrou exclusif est demandé, donc l'exécution sera suspendue jusqu'à ce que le verrou soit disponible. Si le fichier de synchronisation rollrec n'existe pas, il sera créé. Si le processus ne peut pas créer le fichier de synchronisation, une erreur sera retournée. Le succès ou l'échec est retourné.
rollrec_merge(target_rollrec_file, rollrec_file1, ... rollrec_fileN)
Cette interface fusionne les fichiers rollrec spécifiés. Elle lit chaque fichier et les analyse en une table de hachage rollrec et un tableau de contenu de fichier. La fusion résultante est écrite dans le fichier nommé par target_rollrec_file. Si un autre rollrec est déjà ouvert, il est sauvegardé et fermé avant d'ouvrir le nouveau rollrec.

Si target_rollrec_file est un fichier rollrec existant, son contenu sera fusionné avec les autres fichiers passés à rollrec_merge(). Si le fichier n'existe pas, rollrec_merge() le créera et fusionnera les fichiers restants dedans.

Le rollrec d'info peut affecter le fonctionnement de la fusion. Si target_rollrec_file n'existe pas ou est vide, alors un simple rollrec d'info sera ajouté au fichier. Aucune partie des rollrecs d'info ne sera fusionnée dans celui de target_rollrec_file.

Si le fichier existe mais n'a pas de rollrec d'info, alors le rollrec d'info de la source est copié dans la cible. Les rollrecs d'info des fichiers doivent avoir la même version ou les versions doivent toutes être inférieures à la version de target_rollrec_file.

En cas de succès, rollrec_merge() retourne le nombre de rollrecs lus du fichier.

Valeurs de retour en cas d'échec :

-1 aucun fichier rollrec n'a été fourni à rollrec_merge
-2 impossible de créer le fichier rollrec cible
-3 impossible de lire le premier fichier rollrec
-4 une erreur s'est produite lors de la lecture des noms de rollrec
-5 les fichiers rollrec ont été dupliqués dans la liste des fichiers rollrec
rollrec_names()
Cette routine retourne une liste des noms de rollrec du fichier. Le nom du rollrec d'info n'est pas inclus dans cette liste.
rollrec_read(rollrec_file)
Cette interface lit le fichier rollrec spécifié et l'analyse en une table de hachage rollrec et un tableau de contenu de fichier. rollrec_read() doit être appelée avant toute autre appel à rollrec.pm. Si un autre rollrec est déjà ouvert, il est sauvegardé et fermé avant d'ouvrir le nouveau rollrec.

rollrec_read() tente d'ouvrir le fichier rollrec en lecture et écriture. Si cela échoue, alors il tente d'ouvrir le fichier en lecture seule.

rollrec_read() est une façade pour rollrec_readfile(). Elle configure les données sauvegardées du module en préparation de la lecture d'un nouveau fichier rollrec. Ces actions de maintenance ne sont pas effectuées par rollrec_readfile().

En cas de succès, rollrec_read() retourne le nombre de rollrecs lus du fichier.

Valeurs de retour en cas d'échec :

-1 le fichier rollrec spécifié n'existe pas
-2 impossible d'ouvrir le fichier rollrec
-3 noms de rollrec dupliqués dans le fichier
rollrec_readfile(rollrec_file_handle,mergeflag)
Cette interface lit le descripteur de fichier spécifié d'un fichier rollrec et analyse le contenu du fichier en une table de hachage rollrec et un tableau de contenu de fichier. La table de hachage et le tableau de contenu de fichier ne sont pas vidés avant d'y ajouter des données.

L'argument mergeflag indique si l'appel fusionnera un fichier rollrec avec un rollrec précédemment lu ou s'il lira un nouveau fichier rollrec.

En cas de succès, rollrec_read() retourne zéro.

Valeurs de retour en cas d'échec :

-1 noms de rollrec dupliqués dans le fichier
rollrec_rectype(rollrec_name,rectype)
Définit le type de l'enregistrement rollrec spécifié. Le fichier n'est pas écrit après la mise à jour de la valeur, mais le drapeau interne de modification du fichier est défini. La valeur est sauvegardée dans %rollrecs et dans @rollreclines.

rollrec_name est le nom du rollrec qui sera modifié. rectype est le nouveau type du rollrec, qui doit être soit "roll", soit "skip".

Valeurs de retour :

0 - échec (type d'enregistrement invalide ou rollrec non trouvé)
1 - succès
rollrec_recval(rollrec_name,rollrec_field)
Cette routine retourne la valeur d'un champ spécifié dans un rollrec donné. rollrec_name est le nom du rollrec particulier à consulter. rollrec_field est le nom du champ dans ce rollrec.

Par exemple, le fichier rollrec actuel contient le rollrec suivant.

roll        "example.com"
            zonefile        "db.example.com"

L'appel :

rollrec_recval("example.com","zonefile")

retournera la valeur "db.example.com".

rollrec_rename(old_rollrec_name,new_rollrec_name)
Cette routine renomme le rollrec nommé par old_rollrec_name en new_rollrec_name. L'effet réel est de changer le nom dans la ligne roll ou skip en new_rollrec_name. Le nom est changé uniquement dans la version interne du fichier rollrec. Le fichier lui-même n'est pas modifié, mais doit être sauvegardé en appelant soit rollrec_write(), rollrec_save(), ou rollrec_saveas().

old_rollrec_name doit être le nom d'un rollrec existant. Inversement, new_rollrec_name ne doit pas nommer un rollrec existant.

Valeurs de retour :

  0 - succès
-1 - old_rollrec_name était nul ou vide
-2 - new_rollrec_name était nul ou vide
-3 - old_rollrec_name n'est pas un rollrec existant
-4 - new_rollrec_name est déjà un rollrec
-5 - erreur interne qui ne devrait jamais se produire
rollrec_settime(rollrec_name,val)
Définit l'horodatage de début de phase dans le rollrec spécifié par rollrec_name à l'heure actuelle. Si le paramètre optionnel val est donné et qu'il est zéro, alors l'horodatage de début de phase est défini à une valeur nulle.

Le fichier n'est pas écrit après la mise à jour de la valeur.

rollrec_setval(rollrec_name,field,value)
Définit la valeur d'une paire nom/champ dans un rollrec spécifié. Le fichier n'est pas écrit après la mise à jour de la valeur, mais le drapeau interne de modification du fichier est défini. La valeur est sauvegardée d dans les deux %rollrecs et dans @rollreclines.

rollrec_name est le nom du rollrec qui sera modifié. Si le rollrec nommé n'existe pas, il sera créé en tant que rollrec de type "roll". field est le champ rollrec qui sera modifié. value est la nouvelle valeur pour le champ.

rollrec_split(new_rollrec_file,rollrec_names)
Déplace un ensemble d'entrées rollrec du fichier rollrec actuel vers un nouveau fichier. Les entrées rollrec déplacées sont retirées à la fois du fichier actuel et des données internes du module représentant ce fichier.

Le paramètre new_rollrec_file contient le nom du nouveau fichier rollrec. Si ce fichier n'existe pas, il sera créé. S'il existe déjà, les entrées rollrec seront ajoutées à ce fichier.

rollrec_names est une liste d'entrées rollrec qui seront déplacées du fichier actuel vers le fichier nommé dans new_rollrec_file. Si certains des noms rollrec fournis sont invalides, les noms valides seront déplacés vers le nouveau fichier et les noms invalides seront retournés sous forme de liste à l'appelant.

Seules les entrées rollrec elles-mêmes seront déplacées vers le nouveau fichier rollrec. Tous les commentaires associés resteront dans le fichier rollrec actuel.

La division des rollrec devient intéressante avec l'ajout du rollrec info. Si le fichier new_rollrec_file n'existe pas, le rollrec info du fichier rollrec source est copié dans le fichier cible. Si le fichier existe mais n'a pas de rollrec info, alors le rollrec info de la source est copié dans la cible. Si le fichier cible existe et possède un rollrec info, alors les deux fichiers doivent avoir des numéros de version correspondants.

En cas de succès, le nombre d'entrées rollrec déplacées est renvoyé. Les erreurs sont indiquées ci-dessous.

Valeurs de retour en cas d'échec :
-1 - aucun fichier rollrec cible donné dans new_rollrec_file
-2 - aucun nom de rollrec donné dans rollrec_names
-3 - aucun des noms de rollrec donnés ne correspond à des rollrecs existants
-4 - impossible d'ouvrir new_rollrec_file
-5 - des noms de rollrec invalides ont été spécifiés dans rollrec_names,
suivis de la liste des mauvais noms
-6 - le rollrec info de la cible a une version antérieure à l'actuelle
-7 - le rollrec info de la cible a une version ultérieure (non définie)
à l'actuelle
-8 - le rollrec info de la cible existe sans numéro de version

rollrec_unlock()
rollrec_unlock() déverrouille le fichier de synchronisation rollrec.
rollrec_write()
Cette interface enregistre la version interne du fichier rollrec (ouvert avec rollrec_read()). Elle ne ferme pas le descripteur de fichier. Par mesure d'efficacité, un drapeau de modification interne est vérifié avant de réécrire le fichier. Si le programme n'a pas modifié le contenu du fichier rollrec, celui-ci n'est pas réécrit.

rollrec_write() acquiert un verrou exclusif sur le fichier rollrec pendant l'écriture.

rollrec_zonegroup($zonegroupname)
Cette interface renvoie une liste des zones du groupe de zones (nommé par $zonegroupname) défini dans le fichier rollrec actuel. Null est renvoyé s'il n'y a pas de zones dans le groupe de zones.

Bien que ce terme utilise le mot "zone", il fait en réalité référence au nom des entrées rollrec. Pour une entrée rollrec particulière, le nom de rollrec est généralement le même que le nom de la zone, mais ce n'est pas une obligation.

rollrec_zonegroup_cmds()
Cette interface renvoie une liste des commandes rollctl dont le comportement change lorsqu'elles sont utilisées avec l'option -group.
rollrec_zonegroups()
Cette interface renvoie une table de hachage des groupes de zones définis dans le fichier rollrec actuel. La clé de hachage est le nom du groupe de zones ; la valeur de hachage est le nombre de zones dans le groupe de zones. Null est renvoyé s'il n'y a pas de groupes de zones dans le fichier rollrec.

Bien que ce terme utilise le mot "zone", il fait en réalité référence au nom des entrées rollrec. Pour une entrée rollrec particulière, le nom de rollrec est généralement le même que le nom de la zone, mais ce n'est pas une obligation.

INTERFACES INTERNES DE ROLLREC

Les interfaces décrites dans cette section sont destinées à un usage interne par le module rollrec.pm. Cependant, il existe des situations où des entités externes peuvent en avoir besoin. Utilisez avec prudence, car une mauvaise utilisation pourrait entraîner la corruption ou la perte des fichiers rollrec.

rollrec_init()
Cette routine initialise les données internes de rollrec. Les modifications en attente seront perdues. Un descripteur de fichier rollrec ouvert restera ouvert, bien que les données ne soient plus conservées en interne. Un nouveau fichier rollrec doit être lu pour pouvoir à nouveau utiliser les interfaces rollrec.pm.
rollrec_default()
Cette routine renvoie le nom du fichier rollrec par défaut.

INTERFACES DE DÉBOGAGE DE ROLLREC

Les interfaces suivantes affichent des informations sur le fichier rollrec actuellement analysé. Elles sont destinées à être utilisées pour le débogage et les tests, mais peuvent être utiles à d'autres moments.

rollrec_dump_hash()
Cette routine imprime le fichier rollrec tel qu'il est stocké en interne dans une table de hachage. Les rollrec sont imprimés par ordre alphabétique, avec les champs triés par ordre alphabétique pour chaque rollrec. Les nouveaux rollrec et les champs rollrec sont triés par ordre alphabétique avec les rollrec et les champs actuels. Les commentaires du fichier rollrec ne sont pas inclus avec la table de hachage.
rollrec_dump_array()
Cette routine imprime le fichier rollrec tel qu'il est stocké en interne dans un tableau. Les rollrec sont imprimés dans l'ordre donné dans le fichier, avec les champs ordonnés de la même manière. Les nouveaux rollrec sont ajoutés à la fin du tableau. Les champs rollrec ajoutés aux rollrec existants sont ajoutés au début de l'entrée rollrec. Les commentaires et les espaces blancs verticaux sont préservés tels qu'ils sont donnés dans le fichier rollrec.
