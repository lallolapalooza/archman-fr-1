NOM

Net::Dropbox::API - Une interface pour l'API Dropbox

VERSION

Version 1.9.8

SYNOPIS

L'API Dropbox est une API basée sur OAuth. J'essaie d'abstraire autant que possible, donc vous ne devriez pas avoir besoin d'en savoir trop à ce sujet. Voici comment cela fonctionne :

use Net::Dropbox::API;
my $box = Net::Dropbox::API->new({key => 'CLE', secret => 'SECRET'});
my $login_link = $box->login;  # l'utilisateur doit cliquer sur ce lien et se connecter
$box->auth;                    # les clés oauth sont échangées
my $info = $box->account_info; # et voici nos informations de compte

Voir les exemples pour un client web Mojolicious fonctionnel utilisant l'API Dropbox.

Vous pouvez trouver la documentation de l'API Dropbox à l'adresse https://www.dropbox.com/developers/web_docs

FONCTIONS

login

Ceci configure la poignée de main OAuth initiale et renvoie l'URL de connexion. Cette URL doit être cliquée par l'utilisateur qui doit ensuite accepter l'application sur dropbox.

Dropbox redirige ensuite vers l'URL de rappel définie avec "$self->callback_url". Si l'utilisateur a déjà accepté l'application, la redirection peut se produire sans que l'utilisateur ne clique sur rien.

auth

La méthode `auth` échange le jeton de requête initial contre un jeton d'accès dont nous avons besoin pour un accès ultérieur à l'API. Cette méthode ne doit être appelée qu'une seule fois après la connexion.

account_info

`account_info` interroge les informations de l'utilisateur depuis dropbox.

list

liste tous les fichiers dans le chemin défini :

$data = $box->list();           # niveau supérieur
$data = $box->list( "/Photos" ); # dossier

Les données renvoyées sont une référence à un hachage contenant divers champs renvoyés par Dropbox, y compris une valeur "hash", qui peut être utilisée plus tard pour vérifier si les données Dropbox sous un dossier spécifié ont changé depuis le dernier appel.

Pour cela, list() accepte un argument optionnel 'hash' :

$data = $box->list({ hash => "ce9ccbfb8f255f234c93adcfef33b5a6" },
                   "/Photos");

Ceci renverra soit

{ http_response_code => 304 }

auquel cas rien n'a changé depuis le dernier appel, soit

{ http_response_code => 200,
  # ... divers autres champs
}

s'il y a eu des modifications.

copy

copie un dossier
copy($from, $to)

move

déplace un dossier
move($from, $to)

mkdir

crée un dossier
mkdir($path)

delete

supprime un dossier
delete($path)

view

crée un lien protégé par cookie pour que l'utilisateur puisse le consulter.
view($path)

metadata

crée un lien protégé par cookie pour que l'utilisateur puisse le consulter.
metadata($path)

putfile

télécharge un fichier sur dropbox

getfile

obtient un fichier de dropbox

debug

Définissez ceci sur une valeur non fausse pour imprimer des informations de débogage sur STDOUT.
debug(1)

API INTERNE

_talk

`_talk` gère l'accès aux ressources restreintes. Vous ne devriez normalement pas avoir besoin d'y accéder directement.

nonce

Génère un nonce différent pour chaque requête.

NOM

Net::Dropbox::API - API REST de Dropbox pour Perl

SYNOPSIS


                    use Net::Dropbox::API;

                    my $dropbox = Net::Dropbox::API->new(
                        client_id     => 'YOUR_CLIENT_ID',
                        client_secret => 'YOUR_CLIENT_SECRET',
                        access_token  => 'YOUR_ACCESS_TOKEN', # Optional, if you have one
                    );

                    # Get user info
                    my $user_info = $dropbox->get_account_info;
                    print Dumper($user_info);

                    # List files in a folder
                    my $files = $dropbox->get_files('/Apps/MyApp');
                    print Dumper($files);

                    # Upload a file
                    $dropbox->put_file('local/path/to/file.txt', '/dropbox/path/file.txt');

                    # Download a file
                    $dropbox->get_file('/dropbox/path/file.txt', 'local/path/to/downloaded_file.txt');

DESCRIPTION

Ce module fournit une interface Perl pour l'API REST de Dropbox.

MÉTHODES

Les méthodes disponibles correspondent aux points d'accès de l'API REST de Dropbox. Voir la documentation officielle de l'API Dropbox pour une description détaillée de chaque point d'accès.

  • new(...) : Crée une nouvelle instance de l'API.
  • get_account_info(...) : Récupère des informations sur le compte de l'utilisateur.
  • get_files($path) : Liste les fichiers et dossiers dans un chemin donné.
  • put_file($local_path, $dropbox_path) : Charge un fichier vers Dropbox.
  • get_file($dropbox_path, $local_path) : Télécharge un fichier depuis Dropbox.
  • ... et d'autres méthodes pour interagir avec l'API Dropbox.
