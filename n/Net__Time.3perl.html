NOM

Net::Time - interface client réseau pour l'heure et le jour

SYNOPIS

use Net::Time qw(inet_time inet_daytime);
print inet_time();          # utilise l'hôte par défaut de Net::Config
print inet_time('localhost');
print inet_time('localhost', 'tcp');
print inet_daytime();       # utilise l'hôte par défaut de Net::Config
print inet_daytime('localhost');
print inet_daytime('localhost', 'tcp');

DESCRIPTION

"Net::Time" fournit des sous-programmes qui obtiennent l'heure sur une machine distante.

Fonctions

"inet_time([$hôte[, $protocole[, $délai]]])"
Obtient l'heure sur $hôte, ou un hôte par défaut si $hôte n'est pas fourni ou défini, en utilisant le protocole défini dans le RFC868. L'argument optionnel $protocole doit définir le protocole à utiliser, soit "tcp" soit "udp". Le résultat sera une valeur temporelle dans les mêmes unités que celles renvoyées par time() ou undef en cas d'échec.
"inet_daytime([$hôte[, $protocole[, $délai]]])"
Obtient l'heure sur $hôte, ou un hôte par défaut si $hôte n'est pas fourni ou défini, en utilisant le protocole défini dans le RFC867. L'argument optionnel $protocole doit définir le protocole à utiliser, soit "tcp" soit "udp". Le résultat sera une chaîne ASCII ou undef en cas d'échec.
