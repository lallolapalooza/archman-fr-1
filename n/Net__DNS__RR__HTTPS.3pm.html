NOM

Net::DNS::RR::HTTPS - Enregistrement de ressource DNS HTTPS

SYNOPIS

use Net::DNS;
$rr = Net::DNS::RR->new('name HTTPS SvcPriority TargetName alpn=h3-29,h3-28,h3-27,h2 ...');

DESCRIPTION

Enregistrement de ressource DNS HTTPS

La classe HTTPS est dérivée de la classe Net::DNS::RR::SVCB et hérite de toutes ses propriétés.

Veuillez consulter la documentation de Net::DNS::RR::SVCB pour plus de détails.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités non documentées du paquet ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.
