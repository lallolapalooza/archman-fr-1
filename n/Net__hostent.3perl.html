Net::hostent(3perl) Guide du programmeur Perl Net::hostent(3perl)

NOM

Net::hostent - Interface par nom aux fonctions internes de Perl gethost*()

SYNTAXE

use Net::hostent;

DESCRIPTION

Les exportations par défaut de ce module remplacent les fonctions internes gethostbyname() et gethostbyaddr(), en les remplaçant par des versions qui renvoient des objets "Net::hostent". Cet objet possède des méthodes qui renvoient le nom du champ de structure de manière similaire de la structure hostent de C provenant de netdb.h ; à savoir name, aliases, addrtype, length et addr_list. Les méthodes aliases et addr_list renvoient une référence de tableau, les autres des scalaires. La méthode addr est équivalente à l'élément zéro de la référence de tableau addr_list.

Vous pouvez également importer tous les champs de structure directement dans votre espace de noms en tant que variables normales à l'aide de la balise d'importation :FIELDS. (Notez que cela remplace toujours vos fonctions principales.) Accédez à ces champs en tant que variables nommées avec un "h_" préfixé. Ainsi, "$host_obj->name()" correspond à $h_name si vous importez les champs. Les références de tableau sont disponibles en tant que variables de tableau normales, donc par exemple "@{ $host_obj->aliases() }" serait simplement @h_aliases.

La fonction gethost() est un simple front-end qui transmet un argument numérique à gethostbyaddr() via Socket::inet_aton, et le reste à gethostbyname().

Pour accéder à cette fonctionnalité sans les remplacements principaux, passez une liste d'importation vide à "use", puis accédez aux fonctions avec leurs noms qualifiés complets. D'un autre côté, les fonctions intégrées sont toujours disponibles via le pseudo-paquet "CORE::".

EXEMPLES

use Net::hostent;
use Socket;
@ARGV = ('netscape.com') unless @ARGV;
for $host ( @ARGV ) {
   unless ($h = gethost($host)) {
       warn "$0: no such host: $host\n";
       next;
   }
   printf "\n%s is %s%s\n", 
           $host, 
           lc($h->name) eq lc($host) ? "" : "*really* ",
           $h->name;
   print "\talternatives are ", join(", ", @{$h->aliases}), "\n"
               if @{$h->aliases};     
   if ( @{$h->addr_list} > 1 ) { 
       my $i;
       for $addr ( @{$h->addr_list} ) {
           printf "\taddr #%d is [%s]\n", $i++, inet_ntoa($addr);
       } 
   } else {
       printf "\taddress is [%s]\n", inet_ntoa($h->addr);
   } 
   if ($h = gethostbyaddr($h->addr)) {
       if (lc($h->name) ne lc($host)) {
           printf "\tThat addr reverses to host %s!\n", $h->name;
           $host = $h->name;
           redo;
       } 
   }
}

NOTE

Bien que cette classe soit actuellement implémentée en utilisant le module Class::Struct pour construire une classe de type struct, vous ne devriez pas vous y fier.
