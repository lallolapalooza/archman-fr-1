NOM

NetAddr::IP::UtilPP -- fonctions Perl pures pour NetAddr::IP::Util

SYNTAXE

use NetAddr::IP::UtilPP qw(
      hasbits
      shiftleft
      addconst
      add128
      sub128
      notcontiguous
      ipv4to6
      mask4to6
      ipanyto6
      maskanyto6
      ipv6to4
      bin2bcd
      bcd2bin
);
use NetAddr::IP::UtilPP qw(:all)
$rv = hasbits($bits128);
$bitsX2 = shiftleft($bits128,$n);
$carry = addconst($ipv6naddr,$signed_32con);
($carry,$ipv6naddr)=addconst($ipv6naddr,$signed_32con);
$carry = add128($ipv6naddr1,$ipv6naddr2);
($carry,$ipv6naddr)=add128($ipv6naddr1,$ipv6naddr2);
$carry = sub128($ipv6naddr1,$ipv6naddr2);
($spurious,$cidr) = notcontiguous($mask128);
($carry,$ipv6naddr)=sub128($ipv6naddr1,$ipv6naddr2);
$ipv6naddr = ipv4to6($netaddr);
$ipv6naddr = mask4to6($netaddr);
$ipv6naddr = ipanyto6($netaddr);
$ipv6naddr = maskanyto6($netaddr);
$netaddr = ipv6to4($pv6naddr);
$bcdtext = bin2bcd($bits128);
$bits128 = bcd2bin($bcdtxt);

DESCRIPTION

NetAddr::IP::UtilPP fournit des fonctions Perl pures pour NetAddr::IP::Util

  • $rv = hasbits($bits128);

    Cette fonction retourne vrai s'il y a des bits à 1 dans la chaîne de 128 bits et faux si tous les bits sont à zéro.

    c'est-à-dire  si (hasbits($bits128)) {
        &do_something;
      }
ou    si (hasbits($bits128 & $mask128) {
        &do_something;
      }

    Ceci permet l'implémentation de fonctions logiques de la forme :

          si ($bits128 & $mask128) {
          ...
entrée :        chaîne IPv6 de 128 bits
retourne :      vrai si des bits sont présents
  • $bitsXn = shiftleft($bits128,$n); 
    entrée :        variable de chaîne de 128 bits,
              nombre de décalages [facultatif]
retourne :      bits décalés de n
NOTE : les bits d'entrée sont retournés
      si $n n'est pas spécifié
  • addconst($ipv6naddr,$signed_32con);

    Ajoute une constante signée à une chaîne de 128 bits.

    entrée :        chaîne IPv6 de 128 bits,
              entier signé de 32 bits
retourne :  scalaire      retenue
          tableau       (retenue, résultat)
  • add128($ipv6naddr1,$ipv6naddr2);

    Ajoute deux variables de chaînes de 128 bits.

    entrée :        variable de chaîne de 128 bits 1,
              variable de chaîne de 128 bits 2
retourne :  scalaire      retenue
          tableau       (retenue, résultat)
  • sub128($ipv6naddr1,$ipv6naddr2);

    Soustraire deux variables de chaînes de 128 bits.

    entrée :        variable de chaîne de 128 bits 1,
              variable de chaîne de 128 bits 2
retourne :  scalaire      retenue
          tableau       (retenue, résultat)

    Note : La retenue de cette opération est le résultat de l'ajout du complément à un de ARG2 +1 à ARG1. Ce n'est logiquement PAS un emprunt.

    c'est-à-dire    si ARG1 >= ARG2 alors retenue = 1
ou      si ARG1  < ARG2 alors retenue = 0
  • ($spurious,$cidr) = notcontiguous($mask128);

    Cette fonction compte les positions de bits restantes dans le masque lorsque les '0' les plus à droite sont supprimés.

    entrée :  masque réseau de 128 bits
retourne vrai s'il y a des bits zéro
            disparates restants dans le
            masque, faux si le masque est
            contigu de uns,
        masque réseau CIDR de 128 bits
  • $ipv6naddr = ipv4to6($netaddr);

    Convertit une adresse réseau ipv4 en une adresse réseau ipv6.

    entrée :        adresse réseau de 32 bits
retourne :      adresse réseau de 128 bits
  • $ipv6naddr = mask4to6($netaddr);

    Convertit une adresse réseau/masque ipv4 en un masque réseau ipv6.

    entrée :        adresse réseau/masque de 32 bits
retourne :      adresse réseau/masque de 128 bits

    NOTE : retourne les 96 bits supérieurs comme des uns

  • $ipv6naddr = ipanyto6($netaddr);

    Similaire à ipv4to6 sauf que cette fonction prend une entrée IPv4 ou IPv6 et retourne toujours une adresse réseau IPv6 de 128 bits.

    entrée :        adresse réseau de 32 ou 128 bits
retourne :      adresse réseau de 128 bits
  • $ipv6naddr = maskanyto6($netaddr);

    Similaire à mask4to6 sauf que cette fonction prend un masque réseau IPv4 ou IPv6 et retourne toujours un masque réseau IPv6 de 128 bits.

    entrée :        masque réseau de 32 ou 128 bits
retourne :      masque réseau de 128 bits
  • $netaddr = ipv6to4($pv6naddr);

    Tronque les 96 bits supérieurs d'une adresse de 128 bits et retourne les 32 bits inférieurs. Retourne une adresse IPv4 telle que retournée par inet_aton.

    entrée :        adresse réseau de 128 bits
retourne :      adresse réseau inet_aton de 32 bits
  • $bcdtext = bin2bcd($bits128);

    Convertit une chaîne binaire de 128 bits en chiffres décimaux codés en binaire (BCD).

    entrée :        variable de chaîne de 128 bits
retourne :      chaîne de chiffres décimaux codés en binaire
  • $bits128 = bcd2bin($bcdtxt);

    Convertit une chaîne décimale codée en binaire en variable de chaîne de 128 bits

    entrée :        chaîne de chiffres décimaux codés en binaire
retourne :      variable de chaîne de 128 bits
