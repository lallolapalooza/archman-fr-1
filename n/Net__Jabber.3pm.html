Net::Jabber(3) Documentation Perl fournie par l'utilisateur Net::Jabber(3)

NOM

Net::Jabber - Bibliothèque Perl Jabber

SYNOPSIS

Net::Jabber offre à l'utilisateur Perl un accès au protocole de messagerie instantanée Jabber.
Pour plus d'informations sur Jabber, visitez :
  http://www.jabber.org

DESCRIPTION

Net::Jabber est un outil pratique à utiliser pour tout script Perl qui souhaite utiliser le protocole de messagerie instantanée Jabber. Bien qu'il ne s'agisse pas d'un client en soi, il fournit toutes les fonctions de support nécessaires pour rendre un client CGI ou un client Perl en ligne de commande réalisable et facile à utiliser. Net::Jabber est un wrapper autour du reste des paquets officiels Net::Jabber::xxxxxx.
Il existe des scripts d'exemple dans le répertoire example qui vous fournissent des exemples de programmes Jabber très simples.
NOTE : Le parseur fourni par XML::Stream::Parser, comme la plupart des parseurs Perl, est synchrone. Si vous êtes au milieu de l'analyse d'un paquet et que vous appelez un rappel défini par l'utilisateur, le Parseur est bloqué jusqu'à ce que votre rappel soit terminé. Cela signifie que vous ne pouvez pas traiter un paquet, en envoyer un autre et attendre une réponse à ce paquet. Il n'arrivera jamais jusqu'à vous. Le threading pourrait résoudre ce problème, mais au moment de la rédaction, le threading en Perl n'est pas encore tout à fait au point. Ce problème sera revu à l'avenir.

EXEMPLES

Pour un client :
  use Net::Jabber;
  my $client = new Net::Jabber::Client();
Pour un composant :
  use Net::Jabber;
  my $component = new Net::Jabber::Component();

MÉTHODES

Le module Net::Jabber ne définit aucune méthode que vous appellerez directement dans votre code. Au lieu de cela, vous instancierez des objets qui appellent des fonctions de ce module pour effectuer le travail. Les trois objets principaux avec lesquels vous travaillerez sont les modules Message, Presence et IQ. Chacun correspond à son équivalent Jabber et vous permet d'obtenir et de définir toutes les parties de ces paquets.

PAQUETS

Pour plus d'informations sur chacun de ces paquets, veuillez consulter la page de manuel correspondante.

Net::Jabber::Client

Ce paquet contient le code nécessaire pour communiquer avec un serveur Jabber : connexion, attente de messages, envoi de messages et déconnexion. Il utilise XML::Stream pour lire le flux du serveur et, en fonction du type de balise rencontrée, appelle une fonction pour traiter la balise.

Net::Jabber::Component

Ce paquet contient le code nécessaire pour écrire un composant serveur. Un composant est un programme qui gère la communication entre un serveur Jabber et un programme ou un paquet de communication externe (IRC, talk, email, etc.). Avec ce module, vous pouvez écrire un composant complet en quelques lignes de Perl. Il utilise XML::Stream pour communiquer avec son serveur hôte et, en fonction du type de balise rencontrée, appelle une fonction pour traiter la balise.

Net::Jabber::Protocol

Une collection de fonctions de haut niveau que Client et Component utilisent pour se faciliter la vie par héritage.

Net::Jabber::JID

Les identifiants Jabber sont composés de trois parties : l'identifiant utilisateur, le serveur et la ressource. Ce module vous donne accès à ces composants sans avoir à analyser la chaîne vous-même.

Net::Jabber::Message

Tout ce qui est nécessaire pour créer et lire un <message/> reçu du serveur.

Net::Jabber::Presence

Tout ce qui est nécessaire pour créer et lire un <presence/> reçu du serveur.

Net::Jabber::IQ

IQ est un wrapper autour d'un certain nombre de modules qui fournissent un support pour les différents espaces de noms Info/Query que Jabber reconnaît.

Net::Jabber::Stanza

Ce module représente un stanza nommé qui est utilisé pour étendre un <message/>, une <presence/> et un <iq/>. En fin de compte, chaque espace de noms est documenté dans un JEP d'une sorte ou d'une autre. http://jabber.org/jeps/
La page de manuel de Net::Jabber::Stanza contient une liste de tous les espaces de noms pris en charge, et les méthodes prises en charge par les objets qui représentent ces espaces de noms.

Net::Jabber::Namespaces

Jabber permet à n'importe quel stanza d'être étendu par n'importe quel bloc XML. Ce module contient tous les éléments internes pour définir les extensions Jabber définies par les JEPs. La documentation de ce module explique plus en détail comment ajouter votre propre espace de noms personnalisé et le faire prendre en charge.
