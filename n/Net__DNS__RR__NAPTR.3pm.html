NOM

Net::DNS::RR::NAPTR - Enregistrement de ressource NAPTR DNS

SYNOPIS

use Net::DNS;
$rr = Net::DNS::RR->new('nom NAPTR ( ordre préférence
                flags service expression_régulière remplacement )');

DESCRIPTION

Enregistrements de ressource (resource records) NAPTR (Naming Authority Pointer) DNS.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées des méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités de paquet non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

ordre

$ordre = $rr->order;
$rr->order( $ordre );

Un entier non signé de 16 bits spécifiant l'ordre dans lequel les enregistrements NAPTR doivent être traités pour assurer le bon ordonnancement des règles. Les nombres faibles sont traités avant les nombres élevés.

préférence

$préférence = $rr->preference;
$rr->preference( $préférence );

Un entier non signé de 16 bits qui spécifie l'ordre dans lequel les enregistrements NAPTR avec des valeurs "ordre" égales doivent être traités, les nombres faibles étant traités avant les nombres élevés.

flags

$flags = $rr->flags;
$rr->flags( $flags );

Une chaîne contenant des drapeaux pour contrôler les aspects de la réécriture et de l'interprétation des champs de l'enregistrement. Les drapeaux sont des caractères uniques de l'ensemble [A-Z0-9].

service

$service = $rr->service;
$rr->service( $service );

Spécifie le(s) service(s) disponible(s) le long de ce chemin de réécriture. Il peut également spécifier le protocole utilisé pour communiquer avec le service.

expression_régulière

$expression_régulière = $rr->regexp;
$rr->regexp;

Une chaîne contenant une expression de substitution qui est appliquée à la chaîne originale détenue par le client afin de construire le nom de domaine suivant à rechercher.

remplacement

$remplacement = $rr->replacement;
$rr->replacement( $remplacement );

Le prochain NOM à interroger pour les enregistrements NAPTR, SRV ou d'adresse en fonction de la valeur du champ flags.
