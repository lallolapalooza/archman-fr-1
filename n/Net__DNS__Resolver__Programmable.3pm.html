NOM

Net::DNS::Resolver::Programmable - classe de résolveur DNS programmable pour l'émulation hors ligne du DNS

SYNTAXE

use Net::DNS::Resolver::Programmable;
use Net::DNS::RR;

my $resolver = Net::DNS::Resolver::Programmable->new(
    records         => {
        'example.com'     => [
            Net::DNS::RR->new('example.com.     NS  ns.example.org.'),
            Net::DNS::RR->new('example.com.     A   192.168.0.1')
        ],
        'ns.example.org'  => [
            Net::DNS::RR->new('ns.example.org.  A   192.168.1.1')
        ]
    },

    resolver_code   => sub {
        my ($domain, $rr_type, $class) = @_;
        ...
        return ($result, $aa, @rrs);
    }
);

DESCRIPTION

Net::DNS::Resolver::Programmable est une classe descendante de Net::DNS::Resolver qui permet d'émuler un DNS virtuel au lieu de requérir le vrai DNS. Un ensemble d'enregistrements DNS statiques peut être fourni, ou du code arbitraire peut être spécifié comme moyen de récupérer des enregistrements DNS, ou même de les générer à la volée.

Constructeur

Le constructeur suivant est fourni :

new(%options): retourne Net::DNS::Resolver::Programmable
Crée un nouvel objet résolveur DNS programmé.

%options est une liste de paires clé/valeur représentant toutes les options suivantes :

records
Une référence à une table associant des tableaux contenant un ensemble statique d'objets Net::DNS::RR. Les clés de la table doivent être des noms de domaine entièrement qualifiés (en minuscules, sans points finaux), et les entrées elles-mêmes doivent être des tableaux d'objets RR relatifs à ces noms de domaine. Par exemple : 
records => {
    'example.com'     => [
        Net::DNS::RR->new('example.com.     NS  ns.example.org.'),
        Net::DNS::RR->new('example.com.     A   192.168.0.1')
    ],
    'www.example.com' => [
        Net::DNS::RR->new('www.example.com. A   192.168.0.2')
    ],
    'ns.example.org'  => [
        Net::DNS::RR->new('ns.example.org.  A   192.168.1.1')
    ]
}

Si cette option est spécifiée, le résolveur récupère les RR demandés depuis cette structure de données.

resolver_code
Une référence de code utilisée comme rappel pour récupérer dynamiquement les RR demandés.

Le code doit prendre les paramètres de requête suivants comme arguments : le domaine, le type de RR et la classe.

Il doit retourner une liste composée de : le RCODE de la réponse (par nom, tel que retourné par Net::DNS::Header->rcode), le drapeau "aa" (réponse faisant autorité) (booléen, utiliser undef si cela ne vous importe pas), et les objets Net::DNS::RR de réponse. Si une chaîne d'erreur est retournée au lieu d'un RCODE valide, un objet Net::DNS::Packet n'est pas construit mais une condition d'erreur pour le résolveur est signalée à la place.

Par exemple :

resolver_code => sub {
    my ($domain, $rr_type, $class) = @_;
    ...
    return ($result, $aa, @rrs);
}

Si à la fois cette option et l'option "records" sont spécifiées, alors les enregistrements programmés statiquement sont utilisés en plus de ceux qui sont retournés par le code de résolveur configuré.

defnames
dnsrch
domain
searchlist
debug
Ces options Net::DNS::Resolver sont également significatives avec Net::DNS::Resolver::Programmable. Voir Net::DNS::Resolver pour leurs descriptions.

Méthodes d'instance

Les méthodes d'instance suivantes de Net::DNS::Resolver sont également supportées par Net::DNS::Resolver::Programmable :

search: retourne Net::DNS::Packet
query: retourne Net::DNS::Packet
send: retourne Net::DNS::Packet
Effectue une requête DNS hors ligne, en utilisant les RR DNS programmés statiquement et/ou le code de résolveur dynamique configuré. Voir les options "records" et "resolver_code" du constructeur "new". Voir les descriptions de search, query et send pour les détails sur la syntaxe d'appel de ces méthodes.
print
string: retourne chaîne
searchlist: retourne liste de chaîne
defnames: retourne booléen
dnsrch: retourne booléen
debug: retourne booléen
errorstring: retourne chaîne
answerfrom: retourne chaîne
answersize: retourne entier
Voir "MÉTHODES" dans Net::DNS::Resolver.

Actuellement, les méthodes suivantes de Net::DNS::Resolver ne sont pas supportées : axfr, axfr_start, axfr_next, nameservers, port, srcport, srcaddr, bgsend, bgread, bgisready, tsig, retrans, retry, recurse, usevc, tcp_timeout, udp_timeout, persistent_tcp, persistent_udp, igntc, dnssec, cdflag, udppacketsize. Les effets de l'utilisation de ces méthodes sur les objets Net::DNS::Resolver::Programmable sont indéfinis.
