NOM

Net::DNS::SEC::libcrypto - Interface Perl vers libcrypto d'OpenSSL

DESCRIPTION

Extension XS Perl fournissant un accès à la bibliothèque libcrypto d'OpenSSL sur laquelle sont basés les composants cryptographiques de Net::DNS::SEC.
