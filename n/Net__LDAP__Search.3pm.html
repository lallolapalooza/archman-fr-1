Net::LDAP::Search(3) Documentation Perl fournie par l'utilisateur Net::LDAP::Search(3)

NOM

Net::LDAP::Search - Objet retourné par la méthode de recherche de Net::LDAP

SYNTAXE

use Net::LDAP;
$mesg = $ldap->search( @search_args );
@entries = $mesg->entries;

DESCRIPTION

Un objet Net::LDAP::Search est retourné par la méthode search d'un objet Net::LDAP. C'est un objet conteneur qui contient les résultats de la recherche.

MÉTHODES

Net::LDAP::Search hérite de Net::LDAP::Message, et supporte donc toutes les méthodes définies dans Net::LDAP::Message.

as_struct ( )
Retourne une référence vers une HASH, où les clés sont les DN des résultats et les valeurs sont des références HASH. Ces HASH de second niveau contiennent les attributs de telle sorte que les clés sont les noms d'attributs, en minuscules, et les valeurs sont des références vers un ARRAY contenant les valeurs.

Cette méthode bloquera jusqu'à ce que toute la requête de recherche soit terminée.

count ( )
Retourne le nombre d'entrées retournées par le serveur.

Cette méthode bloquera jusqu'à ce que toute la requête de recherche soit terminée.

entry ( INDEX )
Retourne la N-ième entrée (indice zéro), qui sera un objet Net::LDAP::Entry. Si INDEX est supérieur ou égal au nombre total d'entrées retournées, alors "undef" sera retourné.

Cette méthode bloquera jusqu'à ce que la requête de recherche ait retourné suffisamment d'entrées.

entries ( )
Retourne un tableau d'objets Net::LDAP::Entry qui ont été retournés par le serveur.

Cette méthode bloquera jusqu'à ce que toute la requête de recherche soit terminée.

pop_entry ( )
Retire une entrée de la liste interne d'objets Net::LDAP::Entry pour cette recherche. S'il n'y a plus d'entrées, alors "undef" est retourné.

Cet appel bloquera si la liste est vide, jusqu'à ce que le serveur retourne une autre entrée.

references ( )
Retourne une liste de références que le serveur a retournées. Ce sera une liste d'objets Net::LDAP::Reference.
sorted ( )
Retourne une liste d'objets Net::LDAP::Entry, triée par leurs DN.

Le tri est effectué côté client en utilisant l'opérateur de tri alphanumérique Perl "cmp".

sorted ( ATTR, ... )
Retourne une liste d'objets Net::LDAP::Entry, triée par les attributs spécifiés. Les attributs sont comparés dans l'ordre spécifié, chacun n'étant comparé que si tous les attributs précédents sont égaux.

Le tri est effectué côté client en utilisant l'opérateur de tri alphanumérique Perl "cmp".

shift_entry ( )
Supprime une entrée du début de la liste interne d'objets Net::LDAP::Entry pour cette recherche. S'il n'y a plus d'entrées, alors "undef" est retourné.

Cet appel bloquera si la liste est vide, jusqu'à ce que le serveur retourne une autre entrée.

VOIR AUSSI

Net::LDAP, Net::LDAP::Message, Net::LDAP::Entry, Net::LDAP::Reference
