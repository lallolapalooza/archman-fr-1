NOM

Net::DNS::RR::KX - enregistrement de ressource DNS KX

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name KX preference exchange');

DESCRIPTION

Enregistrement de délégation d'échange de clés DNS (KX)

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées par les méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités de package non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

preference

$preference = $rr->preference;
$rr->preference( $preference );

Un entier de 16 bits qui spécifie la préférence accordée à cet enregistrement parmi d'autres au même propriétaire. Les valeurs inférieures sont préférées.

exchange

$exchange = $rr->exchange;
$rr->exchange( $exchange );

Un nom de domaine qui spécifie un hôte disposé à agir en tant qu'échangeur de clés pour le nom propriétaire.
