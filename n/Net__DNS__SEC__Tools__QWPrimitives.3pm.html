NOM

Net::DNS::SEC::Tools::QWPrimitives - Primitives QWizard pour DNSSEC-Tools

SYNOPSIS

use Net::DNS::SEC::Tools::QWPrimitives;
use Getopt::Long::GUI;
our @guiargs;
DTGetOptions(  ...,
               ['GUI:nootherargs',1],
               ['GUI:otherprimaries',dnssec_tools_get_qwprimitives()],
               ['GUI:submodules','getzonefiles','getzonenames'],
            );

DESCRIPTION

QWizard est un kit de construction d'interface graphique dynamique. Il affiche une série de questions, puis récupère et agit sur les réponses. Ce module fournit un accès à QWizard pour le logiciel DNSSEC-Tools.

En particulier, dnssec_tools_get_qwprimitives() renvoie un ensemble d'écrans primaires pour demander un ensemble de fichiers de zone suivis d'un ensemble de noms de domaine pour ces fichiers de zone. Ceux-ci sont ensuite poussés dans le tableau @guiargs qui doit être traité comme le tableau ARGV final à traiter.
