NOM

Net::LDAP::Schema - Charger et manipuler un schéma LDAP v3

SYNTAXE

use Net::LDAP;
use Net::LDAP::Schema;
#
# Lire le schéma depuis le serveur
#
$ldap = Net::LDAP->new ( $server );
$ldap->bind ( );
$schema = $ldap->schema ( );
#
# Charger depuis LDIF
#
$schema = Net::LDAP::Schema->new;
$schema->parse ( "schema.ldif" ) or die $schema->error;

DESCRIPTION

"Net::LDAP::Schema" fournit un moyen de charger un schéma LDAP et de rechercher des informations sur les classes d'objets, les attributs et les syntaxes pris en charge.

MÉTHODES

Lorsqu'une méthode est indiquée comme prenant le nom ou l'OID d'un élément de schéma (qui peut être une classe d'objet, un attribut ou une syntaxe), alors un nom ou un OID (sous forme d'identifiant d'objet, en format chaîne numérique, par exemple 2.5.4.0) peut être fourni en majuscules ou sous forme de chaîne brute.

Chaque élément renvoyé du schéma (par exemple, une définition d'attribut) est renvoyé dans un HASH. Les clés de ce HASH sont des versions en minuscules des clés lues à partir du serveur. Renvoie une liste de tous les types demandés dans le schéma.
attribute ( NAME )
ditcontentrule ( NAME )
ditstructurerule ( NAME )
matchingrule ( NAME )
matchingruleuse ( NAME )
nameform ( NAME )
objectclass ( NAME )
syntax ( NAME )
Renvoie une référence à un HASH, ou "undef" si l'élément de schéma n'existe pas. "NAME" peut être un nom ou un OID.
dump ( )
Imprime les informations du schéma au format de sortie standard.
dump ( FILENAME )
Imprime les informations du schéma dans un fichier.
error ( )
Renvoie la dernière erreur lors de l'analyse du schéma.
may ( OBJECTCLASS )
Renvoie une liste de HASHs indiquant les attributs qui sont optionnels dans la classe.
must ( OBJECTCLASS )
Renvoie une liste de HASHs indiquant les attributs qui sont obligatoires dans la classe.
parse ( MESG )
parse ( ENTRY )
parse ( FILENAME )
Accepte un argument qui peut être un objet de résultat de recherche LDAP, un objet "Net::LDAP::Entry" ou le nom d'un fichier contenant une représentation LDIF du schéma.

Si l'argument est le résultat d'une recherche LDAP, "Net::LDAP::Schema" analyse le schéma à partir de la première entrée renvoyée.

Renvoie vrai en cas de succès et "undef" en cas d'erreur.

superclass ( NAME )
Renvoie la liste des noms des classes sœurs immédiates.
attribute_syntax ( NAME )
Renvoie la syntaxe réelle en tenant compte des super-types d'attributs.
matchingrule_for_attribute ( NAME, RULE )
Renvoie la règle réelle en tenant compte des super-types d'attributs, étant donné une règle de correspondance ("equality", "substr", etc.).
