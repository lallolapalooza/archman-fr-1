NOM

Net::HTTPS - Connexion HTTP bas niveau sur SSL/TLS (client)

VERSION

version 6.24

DESCRIPTION

Le module "Net::HTTPS" est un client HTTP bas niveau sur SSL/TLS. Son interface est identique à celle de "Net::HTTP", mais le constructeur accepte des paramètres supplémentaires tels qu'acceptés par IO::Socket::SSL. L'objet "Net::HTTPS" est également un objet "IO::Socket::SSL", ce qui lui permet d'hériter de méthodes supplémentaires de cette classe parente.

Pour des raisons historiques, ce module prend également en charge l'utilisation de "Net::SSL" (de la distribution Crypt-SSLeay) comme pilote SSL et classe parente. Cette base est sélectionnée automatiquement si elle est disponible et que "IO::Socket::SSL" ne l'est pas. Vous pouvez également forcer l'implémentation à utiliser en définissant $Net::HTTPS::SSL_SOCKET_CLASS avant de charger ce module. Si cette variable n'est pas définie, elle est initialisée à partir de la variable d'environnement "PERL_NET_HTTPS_SSL_SOCKET_CLASS".

ENVIRONNEMENT

Vous pouvez définir la variable d'environnement "PERL_NET_HTTPS_SSL_SOCKET_CLASS" avec le nom de l'implémentation SSL de base (et la classe parente de Net::HTTPS) à utiliser. La valeur par défaut est "IO::Socket::SSL". Actuellement, la seule autre valeur prise en charge est "Net::SSL".

VOIR AUSSI

Net::HTTP, IO::Socket::SSL
