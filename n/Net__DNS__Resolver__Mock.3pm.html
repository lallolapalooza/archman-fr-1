NOM

Net::DNS::Resolver::Mock - Simule un objet Résolveur DNS pour les tests

DESCRIPTION

Une sous-classe de Net::DNS::Resolver qui analyse un fichier de zone pour sa source de données. Principalement destiné à être utilisé dans les tests.

SYNOPSIS

use Net::DNS::Resolver::Mock;
my $Resolver = Net::DNS::Resolver::Mock-new();
$Resolver->zonefile_read( $FileName );
# ou
$Resolver->zonefile_parse( $String );

MÉTHODES PUBLIQUES

zonefile_read ( $FileName )
Lit le fichier spécifié pour les données de zone
zonefile_parse ( $String )
Lit les données de zone à partir de la chaîne fournie
die_on ( $Name, $Type, $Error )
Se termine avec $Error pour une requête de $Name et $Type
enable_debug ()
Une fois activé, le résolveur écrira toutes les recherches reçues sur STDERR et elles seront disponibles via les méthodes suivantes
disble_debug ()
Désactive le débogage
clear_debug ()
Efface la liste de débogage
get_debug ()
Retourne une liste d'entrées de débogage

DÉPENDANCES

Net::DNS::Resolver
Net::DNS::Packet
Net::DNS::Question
Net::DNS::ZoneFile
