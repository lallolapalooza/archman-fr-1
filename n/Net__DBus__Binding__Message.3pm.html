NOM

Net::DBus::Binding::Message - Classe de base pour les messages

SYNTAXE

Envoi d'un message

my $msg = new Net::DBus::Binding::Message::Signal;
my $iterator = $msg->iterator;
$iterator->append_byte(132);
$iterator->append_int32(14241);
$connection->send($msg);

DESCRIPTION

Fournit une classe de base pour les différents types de messages qui peuvent être envoyés/reçus. Les instances de cette classe ne sont jamais instanciées directement, mais plutôt un des quatre sous-types Net::DBus::Binding::Message::Signal, Net::DBus::Binding::Message::MethodCall, Net::DBus::Binding::Message::MethodReturn, Net::DBus::Binding::Message::Error devrait être utilisé.

CONSTANTES

Les constantes suivantes sont définies dans ce module. Elles ne sont pas exportées dans l'espace de noms de l'appelant et doivent donc être référencées avec leurs noms de paquet complètement qualifiés.

TYPE_ARRAY
Constante représentant la valeur de signature associée au type de données tableau.
TYPE_BOOLEAN
Constante représentant la valeur de signature associée au type de données booléen.
TYPE_BYTE
Constante représentant la valeur de signature associée au type de données octet.
TYPE_DICT_ENTRY
Constante représentant la valeur de signature associée au type de données entrée de dictionnaire.
TYPE_DOUBLE
Constante représentant la valeur de signature associée au type de données virgule flottante de double précision IEEE.
TYPE_INT16
Constante représentant la valeur de signature associée au type de données entier signé 16 bits.
TYPE_INT32
Constante représentant la valeur de signature associée au type de données entier signé 32 bits.
TYPE_INT64
Constante représentant la valeur de signature associée au type de données entier signé 64 bits.
TYPE_OBJECT_PATH
Constante représentant la valeur de signature associée au type de données chemin d'objet.
TYPE_STRING
Constante représentant la valeur de signature associée au type de données chaîne UTF-8.
TYPE_SIGNATURE
Constante représentant la valeur de signature associée au type de données signature.
TYPE_STRUCT
Constante représentant la valeur de signature associée au type de données structure.
TYPE_UINT16
Constante représentant la valeur de signature associée au type de données entier non signé 16 bits.
TYPE_UINT32
Constante représentant la valeur de signature associée au type de données entier non signé 32 bits.
TYPE_UINT64
Constante représentant la valeur de signature associée au type de données entier non signé 64 bits.
TYPE_VARIANT
Constante représentant la valeur de signature associée au type de données variant.
TYPE_UNIX_FD
Constante représentant la valeur de signature associée au type de données descripteur de fichier unix.

MÉTHODES

mon $msg = Net::DBus::Binding::Message->new(message => $rawmessage);
Crée un nouvel objet message, l'initialisant avec l'objet message C sous-jacent donné par l'objet "message". Ce constructeur est destiné à un usage interne uniquement, se référer plutôt à l'un des quatre sous-types de cette classe pour les types de messages spécifiques.
mon $type = $msg->get_type
Récupère le code de type de ce message. La valeur retournée correspond à l'une des quatre constantes "Net::DBus::Binding::Message::MESSAGE_TYPE_*".
mon $interface = $msg->get_interface
Récupère le nom de l'interface ciblée par ce message, éventuellement une chaîne vide s'il n'y a pas d'interface applicable pour ce message.
mon $path = $msg->get_path
Récupère le chemin d'objet associé au message, éventuellement une chaîne vide s'il n'y a pas d'objet applicable pour ce message.
mon $name = $msg->get_destination
Récupère le nom de bus unique ou connu destiné à être le destinataire du message. Retourne éventuellement une chaîne vide si le message est diffusé à tous les clients.
mon $name = $msg->get_sender
Récupère le nom unique du client envoyant le message.
mon $serial = $msg->get_serial
Récupère le numéro de série unique de ce message. Le numéro est garanti unique tant que la connexion sur laquelle le message a été envoyé reste ouverte. Peut retourner zéro, si le message n'a pas encore été envoyé.
mon $name = $msg->get_member
Pour les appels de méthode, récupère le nom de la méthode à invoquer, tandis que pour les signaux, récupère le nom du signal.
mon $sig = $msg->get_signature
Récupère une chaîne représentant la signature de type des valeurs incluses dans le corps du message.
$msg->set_sender($name)
Définit le nom du client envoyant le message. Le nom doit être le nom unique du client.
$msg->set_destination($name)
Définit le nom du destinataire prévu du message. Ceci est généralement utilisé pour les signaux afin de les faire passer de la diffusion à la monodiffusion.
mon $iterator = $msg->iterator;
Récupère un itérateur qui peut être utilisé pour lire ou écrire les champs du message. L'objet retourné est une instance de la classe "Net::DBus::Binding::Iterator".
$boolean = $msg->get_no_reply()
Obtient le drapeau indiquant si le message attend une réponse.
$msg->set_no_reply($boolean)
Active/désactive le drapeau indiquant si le message attend une réponse. Tous les messages d'appel de méthode attendent une réponse par défaut. En activant/désactivant ce drapeau, la latence de communication est réduite en supprimant le besoin pour le client d'attendre.
mon @values = $msg->get_args_list
Désérialise toutes les valeurs dans le corps du message, en utilisant la signature du message pour identifier les types de données. Les valeurs sont retournées sous forme de liste.
$msg->append_args_list(@values)
Ajoute un ensemble de valeurs au corps du message. Les valeurs seront encodées comme une chaîne, une liste ou un dictionnaire, selon leur type de données Perl. Pour des besoins de typage de données plus spécifiques, l'objet Net::DBus::Binding::Iterator devrait être utilisé à la place.
