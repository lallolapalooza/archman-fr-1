NOM

Net::Server::MultiType - Personnalité de Net::Server

SYNOPSIS

use base qw(Net::Server::MultiType);
sub process_request {
    #...code...
}
my @types = qw(PreFork Fork Single);
Net::Server::MultiType->run(server_type => \@types);

DESCRIPTION

Veuillez lire d'abord le pod de Net::Server. Ce module est une personnalité, ou une extension, ou une sous-classe du module Net::Server.

Cette personnalité est conçue pour permettre une utilisation facile de plusieurs personnalités Net::Server. Étant donné une liste de types de serveur, Net::Server::MultiType en chargera un à la fois jusqu'à ce qu'il en trouve un qui est installé sur le système. Il ajoute ensuite ce paquet à son tableau @ISA, héritant ainsi des méthodes de cette personnalité.

ARGUMENTS

En plus des arguments de ligne de commande de la classe de base Net::Server, Net::Server::MultiType contient un autre paramètre configurable.

Clé               Valeur            Défaut
server_type       'server_type'    'Single'
server_type
Peut être appelé plusieurs fois pour construire un tableau de types de serveur possibles. Lors de l'exécution, Net::Server::MultiType trouvera le premier disponible et héritera ensuite des méthodes de cette personnalité.

FICHIER DE CONFIGURATION

"Net::Server::MultiType" permet l'utilisation d'un fichier de configuration pour lire les paramètres du serveur. Le format de ce fichier de configuration est de simples paires clé-valeur. Les commentaires et les espaces blancs sont ignorés.

#-------------- fichier test.conf --------------
### informations multi-type
### essayer PreFork d'abord, puis passer à Single
server_type PreFork
server_type Single
### informations serveur
min_servers   20
max_servers   80
spare_servers 10
max_requests  1000
### utilisateur et groupe à devenir
user        quelqu'un
group       toutlemonde
### journalisation ?
log_file    /var/log/server.log
log_level   3
pid_file    /tmp/server.pid
### contrôle d'accès
allow       .+\.(net|com)
allow       domain\.com
deny        a.+
### mettre le processus en arrière-plan ?
background  1
### ports à lier
host        127.0.0.1
port        localhost:20204
port        20205
### recherches inversées ?
# reverse_lookups on
#-------------- fichier test.conf --------------
