NOM

Net::XMPP::Stanza - Module de Stanza XMPP

SYNTAXE

Net::XMPP::Stanza est un paquet privé qui sert de base à toutes les stanzas XMPP générées par Net::XMPP.

DESCRIPTION

Ce module ne doit pas être utilisé directement. Vous devriez utiliser soit Net::XMPP::IQ, Net::XMPP::Message, Net::XMPP::Presence, soit un autre paquet qui hérite de Net::XMPP::Stanza.

Cela dit, c'est ici que sont documentées toutes les fonctions des espaces de noms (namespaces).

Les espaces de noms actuellement supportés sont :

jabber:iq:auth
jabber:iq:privacy
jabber:iq:register
jabber:iq:roster
urn:ietf:params:xml:ns:xmpp-bind
urn:ietf:params:xml:ns:xmpp-session

Pour plus d'informations sur ce que sont ces espaces de noms, visitez http://www.jabber.org et parcourez le Guide du Programmeur Jabber.

Les tableaux suivants peuvent être lus comme suit :

ny:private:ns
Nom                           Type     Get  Set  Supprimer  Défini  Ajouter
==========================  ========  ===  ===  ======  =======  ===
Foo                         scalaire  X    X     X        X
Bar                         enfant                                X
Bars                        enfant   X
Test                        maître    X    X

Dans l'espace de noms my:private:ns, il y a les fonctions suivantes :

GetFoo(), SetFoo(), RemoveFoo(), DefinedFoo()
AddBar()
GetBars(), DefinedBars()
GetTest(), SetMaster()

J'espère que le fonctionnement est évident. Sinon, obtenez de l'aide et je travaillerai à l'ajout de plus de documentation.
