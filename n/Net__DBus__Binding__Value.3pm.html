NOM

Net::DBus::Binding::Value - Valeur de données fortement typée

SYNOPIS

# Importer les fonctions pratiques
use Net::DBus qw(:typing);
# Appeler une méthode en passant un int32
$object->doit(dint32("3"));

DESCRIPTION

Ce module fournit un simple wrapper autour d'une valeur Perl brute, associant un type DBus explicite à la valeur. Ceci est utilisé dans les cas où un client communique avec un serveur qui ne fournit pas de données d'introspection, mais pour lequel les types de données de base ne sont pas suffisants. Cette classe ne doit pas être utilisée directement, mais plutôt les fonctions pratiques de Net::DBus doivent être appelées.

MÉTHODES

mon $valeur = Net::DBus::Binding::Value->new($type, $valeur);
Crée un wrapper pour la valeur Perl $valeur en la marquant comme ayant le type de données dbus $type. Il n'est pas nécessaire d'appeler cette méthode directement, mais plutôt les méthodes de typage de données de l'objet Net::DBus devraient être utilisées.
mon $brut = $valeur->value
Retourne la valeur Perl brute encapsulée par cet objet.
mon $type = $valeur->type
Retourne le type de données dbus auquel cette valeur est marquée.
