NOM

Net::DNS::RR::RT - enregistrement de ressource RT DNS

SYNOPIS

use Net::DNS;
$rr = Net::DNS::RR->new('nom RT préférence intermédiaire');

DESCRIPTION

Classe pour les enregistrements de ressource Route Through (RT) DNS.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées des méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités de paquet non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

préférence

$préférence = $rr->préférence;
$rr->préférence( $préférence );

Un entier de 16 bits représentant la préférence de la route. Des nombres plus petits indiquent des routes plus préférées.

intermédiaire

$intermédiaire = $rr->intermédiaire;
$rr->intermédiaire( $intermédiaire );

Le nom de domaine d'un hôte qui servira d'intermédiaire pour atteindre l'hôte spécifié par le nom du propriétaire. Les RR DNS associés à l'hôte intermédiaire doivent inclure au moins un enregistrement A, X25 ou ISDN.
