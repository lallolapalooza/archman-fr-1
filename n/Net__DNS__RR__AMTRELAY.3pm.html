NOM

Net::DNS::RR::AMTRELAY - Enregistrement de ressource DNS AMTRELAY

SYNOPIS

use Net::DNS;
$rr = Net::DNS::RR->new('owner AMTRELAY precedence Dbit relaytype relay');

DESCRIPTION

Enregistrement de ressource AMTRELAY conçu pour permettre la découverte inverse de passerelles AMT par IP (DRIAD), un mécanisme permettant aux passerelles AMT de découvrir des relais AMT capables de transférer du trafic multicast à partir d'une adresse IP source connue.

AMT (Automatic Multicast Tunneling) est défini dans la RFC7450 et fournit une méthode pour transporter le trafic multicast sur un tunnel unicast afin de traverser des segments réseau qui ne sont pas capables de multicast.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées des méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités non documentées du package ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner la terminaison du programme ou d'autres comportements imprévisibles.

precedence

$precedence = $rr->precedence;
$rr->precedence( $precedence );

Entier de 8 bits qui indique la priorité relative au sein du RRset. Les relais listés dans les enregistrements AMTRELAY avec une priorité plus faible doivent être tentés en premier.

Dbit, Discovery Optionnelle

$Dbit = $rr->Dbit;
$rr->Dbit(1);

Champ booléen qui indique que la passerelle PEUT envoyer un message de requête AMT directement à l'adresse du relais découvert sans d'abord envoyer un message de découverte AMT.

relaytype

$relaytype = $rr->relaytype;

Le champ type relaytype indique le format des informations stockées dans le champ relay.

Les valeurs suivantes sont définies :

0 : Le champ relay est vide (0 octets).

1 : Le champ relay contient une adresse IPv4 de 4 octets.

2 : Le champ relay contient une adresse IPv6 de 16 octets.

3 : Le champ relay contient un nom de domaine encodé.

relay

$relay = $rr->relay;
$rr->relay( $relay );

Le champ relay est l'adresse ou le nom de domaine du relais AMT. Il est formaté selon le champ relaytype.
