NOM

Net::IDN::UTS46 - Traitement de compatibilité Unicode IDNA (UTS #46)

SYNTAXE

use Net::IDN:: ':all';
my $a = uts46_to_ascii("müller.example.org");
my $b = Net::IDN::UTS46::to_unicode('EXAMPLE.XN--11B5BS3A9AJ6G');

$domain =~ m/\P{Net::IDN::UTS46::IsDisallowed} and die 'oops';

DESCRIPTION

Ce module implémente la norme technique Unicode #46 (Traitement de compatibilité Unicode IDNA). UTS #46 est une variante des noms de domaine internationalisés (IDN), qui vise à être compatible avec les noms de domaine enregistrés sous IDNA2003 ou IDNA2008.

Vous devriez utiliser ce module si vous souhaitez une implémentation exacte de la spécification UTS #46.

Cependant, si vous souhaitez simplement convertir des noms de domaine et que cela ne vous dérange pas quelle norme est utilisée en interne, vous devriez utiliser Net::IDN::Encode à la place.

FONCTIONS

Par défaut, ce module n'exporte aucune sous-routine. Vous pouvez utiliser le tag ":all" pour tout importer.

Vous pouvez omettre le préfixe 'uts46_' lors de l'accès aux fonctions avec un nom de module complètement qualifié (par exemple, vous pouvez accéder à "uts46_to_unicode" comme "Net::IDN::UTS46::uts46_to_unicode" ou "Net::IDN::UTS46::to_unicode").

Les fonctions suivantes sont disponibles :

uts46_to_ascii( $domaine, %param )
Implémente la fonction "ToASCII" de UTS #46, section 4.2. Elle convertit un nom de domaine en ASCII et génère une exception en cas d'entrée invalide.

Cette fonction prend les paramètres optionnels suivants (%param) :

AllowUnassigned
(booléen) S'il est défini à une valeur vraie, les points de code non assignés dans le label sont autorisés. Ceci est une extension par rapport à UTS #46.

La valeur par défaut est false.

UseSTD3ASCIIRules
(booléen) S'il est défini à une valeur vraie, vérifie la conformité du label à la syntaxe STD 3 (RFC 1123) pour les parties du nom d'hôte.

La valeur par défaut est true.

TransitionalProcessing
(booléen) S'il est défini à true, la conversion sera compatible avec IDNA2003. Cela n'affecte que quatre caractères : 'ß' (U+00DF), 'ς' (U+03C2), ZWJ (U+200D) et ZWNJ (U+200C). Généralement, vous voudrez le définir à false.

La valeur par défaut est false.

Cette fonction prend les paramètres optionnels suivants (%param) :

AllowUnassigned
voir ci-dessus.
UseSTD3ASCIIRules
voir ci-dessus.
TransitionalProcessing
(booléen) S'il est fourni, ce paramètre doit être false. La spécification UTS #46 ne définit pas de traitement transitionnel pour ToUnicode.

PROPRIÉTÉS DES CARACTÈRES UNICODE

Ce module définit également les propriétés de caractères listées ci-dessous.

Chaque caractère a exactement l'une des propriétés suivantes :

"\p{Net::IDN::UTS46::IsValid}"
Le point de code est valide et non modifié (c'est-à-dire un caractère de déviation) dans UTS #46.
"\p{Net::IDN::UTS46::IsIgnored}"
Le point de code est supprimé (c'est-à-dire mappé à une chaîne vide) dans UTS #46.
"\p{Net::IDN::UTS46::IsMapped}"
Le point de code est remplacé par une autre chaîne dans UTS #46.
"\p{Net::IDN::UTS46::IsDeviation}"
Le point de code est soit mappé, soit valide, selon que le traitement est transitionnel ou non.
"\p{Net::IDN::UTS46::IsDisallowed}"
Le point de code n'est pas autorisé dans UTS #46.
"\p{Net::IDN::UTS46::IsDisallowedSTD3Ignored}"
Le point de code n'est pas autorisé dans UTS #46 si "UseSTDASCIIRules" sont utilisés, mais serait ignoré sinon.
"\p{Net::IDN::UTS46::IsDisallowedSTD3Mapped}"
Le point de code n'est pas autorisé dans UTS #46 si "UseSTDASCIIRules" sont utilisés, mais serait mappé sinon.
