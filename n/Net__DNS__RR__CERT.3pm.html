NOM

Net::DNS::RR::CERT - Enregistrement de ressource DNS CERT

SYNOPIS

use Net::DNS;
$rr = Net::DNS::RR->new('name IN CERT certtype keytag algorithm cert');

DESCRIPTION

Classe pour les enregistrements de ressource DNS de certificat (CERT).

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités non documentées du paquet ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

certtype

$certtype = $rr->certtype;

Retourne le code certtype pour le certificat (sous forme numérique).

keytag

$keytag = $rr->keytag;
$rr->keytag( $keytag );

Retourne la clé d'identification (key tag) pour la clé publique dans le certificat.

algorithm

$algorithm = $rr->algorithm;

Retourne l'algorithme utilisé par le certificat (sous forme numérique).

certificate

certbin

$certbin = $rr->certbin;
$rr->certbin( $certbin );

Représentation binaire du certificat.

cert

$cert = $rr->cert;
$rr->cert( $cert );

Représentation Base64 du certificat.
