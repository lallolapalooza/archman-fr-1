Net::LDAP::Extension::Refresh(3) Documentation Perl fournie par l'utilisateur Net::LDAP::Extension::Refresh(3)

NOM

Net::LDAP::Extension::Refresh - Objet d'extension LDAPv3 Refresh (RFC 2589)

SYNTAXE

use Net::LDAP;
use Net::LDAP::Extension::Refresh;
$ldap = Net::LDAP->new('localhost');
$ldap->bind('cn=admin,dc=example,dc=com', password => 'password');
$mesg = $ldap->refresh(entryName => 'cn=dynamic,dc=example,dc=com',
       requestTtl => 100);
die "erreur :", $mesg->code(), ": ", $mesg->error()  if ($mesg->code());
print "TTL changé à ", $mesg->get_ttl(), "\n";

DESCRIPTION

"Net::LDAP::Extension::Refresh" implémente l'opération étendue LDAPv3 "Refresh" telle que décrite dans la RFC 2589.

Elle n'implémente aucun objet par elle-même mais étend l'objet Net::LDAP par une autre méthode :

MÉTHODES

refresh ( OPTIONS )
Envoie une opération de rafraîchissement pour un objet.

OPTIONS est une liste de paires clé/valeur. Les clés suivantes sont reconnues :

entryName
Cette option contient l'objet à rafraîchir. Elle doit être un DN.
requestTtl
Cette option contient la durée de vie (TTL) en secondes demandée. Le serveur peut choisir de définir une autre valeur comme indiqué dans la RFC 2589.
get_ttl ( )
Retourne la TTL définie par le serveur lors de l'appel précédent à "refresh".

Cette méthode est une méthode de l'objet de réponse Net::LDAP::Message retourné en réponse à refresh() dans le cas où l'appel à refresh() a réussi.
