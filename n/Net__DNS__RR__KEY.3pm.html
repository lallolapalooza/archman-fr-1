NOM

Net::DNS::RR::KEY - enregistrement de ressource DNS KEY

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new('name KEY flags protocol algorithm publickey');

DESCRIPTION

Enregistrement de ressource DNS KEY.

Ceci est un clone de l'enregistrement DNSKEY et hérite de toutes les propriétés de la classe Net::DNS::RR::DNSKEY.

Veuillez consulter la documentation de Net::DNS::RR::DNSKEY pour les détails.
