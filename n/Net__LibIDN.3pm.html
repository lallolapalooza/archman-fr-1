NOM

Net::LibIDN - Interfaces Perl pour GNU Libidn

SYNOPIS

use Net::LibIDN ':all';
idn_to_ascii("Räksmörgås.Josefßon.ORG") eq
  idn_to_ascii(idn_to_unicode("xn--rksmrgs-5wao1o.josefsson.org"));
idn_prep_name("LibÜDN") eq "libüdn";
idn_punycode_encode("kistenmöhre") eq
  idn_punycode_encode(idn_punycode_decode("kistenmhre-kcb"));
my $errpos;
tld_check("mèrle.se", $errpos) eq undef;
  $errpos == 1;
tld_get("mainbase.mars") eq "mars";
my $hashref = Net::LibIDN::tld_get_table("de");
print "$hashref->{version}\n";
foreach (@{$hashref->{valid}})
{
  print "Plage Unicode de ".$_->{start}." à ".$_->{end}."\n";
}

DESCRIPTION

Fournit des interfaces pour GNU Libidn, une bibliothèque C pour la gestion des noms de domaine internationalisés selon IDNA (RFC 3490), d'une manière très inspirée par PHP-IDN de Turbo Fredriksson.

Fonctions

Net::LibIDN::idn_to_ascii($hostname_clair, [$charset, [$flags]]);
Convertit $hostname_clair, qui peut contenir des caractères en dehors de la plage autorisée dans les noms DNS, en ACE IDNA. Si $charset est spécifié, traite la chaîne comme étant encodée dans ce jeu de caractères, sinon suppose qu'elle est encodée en ISO-8859-1. Si le drapeau IDNA_ALLOW_UNASSIGNED est défini dans $flags, accepte également les caractères Unicode non assignés, si IDNA_USE_STD3_ASCII_RULES est défini, accepte uniquement les caractères alphanumériques ASCII avec trait d'union (LDH). Les drapeaux peuvent être combinés avec ||. Retourne le résultat de la conversion ou undef en cas d'erreur.
Net::LibIDN::idn_to_unicode($idn_hostname, [$charset, [$flags]]);
Convertit le nom d'hôte ASCII $idn_hostname, qui peut être encodé en ACE IDNA, en sa forme décodée dans $charset ou ISO-8859-1. Les drapeaux sont interprétés comme ci-dessus. Retourne le résultat de la conversion ou undef en cas d'erreur.
Net::LibIDN::idn_punycode_encode($string, [$charset]);
Encode $string en "punycode" (RFC 3492). Si $charset est présent, traite $string comme étant dans $charset, sinon utilise ISO-8859-1. Retourne le résultat de la conversion ou undef en cas d'erreur.
Net::LibIDN::idn_punycode_decode($string, [$charset]);
Décode $string depuis "punycode" (RFC 3492). Si $charset est présent, le résultat est converti en $charset, sinon il est converti en ISO-8859-1. Retourne le résultat de la conversion ou undef en cas d'erreur.
Net::LibIDN::idn_prep_name($string, [$charset]);
Net::LibIDN::idn_prep_kerberos5($string, [$charset]);
Net::LibIDN::idn_prep_node($string, [$charset]);
Net::LibIDN::idn_prep_resource($string, [$charset]);
Net::LibIDN::idn_prep_plain($string, [$charset]);
Net::LibIDN::idn_prep_trace($string, [$charset]);
Net::LibIDN::idn_prep_sasl($string, [$charset]);
Net::LibIDN::idn_prep_iscsi($string, [$charset]);
Effectue le "stringprep" (RFC 3454) sur $string selon le profil nommé (par exemple, *_name -> "nameprep" (RFC 3491)). Si $charset est présent, convertit depuis et vers ce jeu de caractères avant et après l'opération respectivement. Retourne la chaîne résultante, ou undef en cas d'erreur.
Net::LibIDN::tdl_check($string, $errpos, [$charset, [$tld]]);
Vérifie si $string est conforme aux restrictions sur les ensembles de caractères valides définis par les autorités TLD dans le monde. Traite $string comme un nom d'hôte si $tld n'est pas présent, déterminant le TLD à partir du nom d'hôte. Si $tld est présent, utilise les restrictions définies par les responsables du TLD $tld. $charset peut être utilisé pour spécifier le jeu de caractères dans lequel se trouve $string. Si un caractère invalide est détecté, retourne 0 et la position basée sur 0 du caractère fautif dans $errpos. En cas d'autres conditions d'échec, $errpos n'est pas modifié et undef est retourné. Si $string est conforme aux restrictions TLD, 1 est retourné.
Net::LibIDN::tld_get($hostname);
Retourne le domaine de premier niveau (top-level domain) de $hostname, ou undef en cas d'erreur ou si aucun domaine de premier niveau n'a été trouvé.
Net::LibIDN::tld_get_table($tld);
Récupère une référence de hachage contenant les informations de restriction TLD pour le TLD donné $tld, ou undef si $tld n'est pas trouvé. La référence de hachage contient les champs suivants :
  • $h->{name} ... nom du TLD
  • $h->{version} ... chaîne de version de cette table de restrictions
  • $h->{nvalid} ... nombre d'intervalles Unicode
  • $h->{valid} ... [ {start => nombre, end => nombre}, ...] ... intervalles Unicode

Limitations

Il n'y a actuellement aucun support pour les capacités Unicode de Perl (man perlunicode). Toutes les chaînes d'entrée sont supposées être des chaînes d'octets, toutes les chaînes de sortie sont générées comme des chaînes d'octets. Par conséquent, si vous avez besoin des fonctionnalités Unicode de Perl, vous devrez convertir vos chaînes manuellement. Par exemple :

use Encode;

use Data::Dumper;

print Dumper(Net::LibIDN::idn_to_unicode('xn--uro-j50a.com', 'utf-8'));

print Dumper(decode('utf-8', Net::LibIDN::idn_to_unicode('xn--uro-j50a.com', 'utf-8')));

NAME

Net::LibIDN - Perl interface to GNU IDN Library

SYNOPSIS

    use Net::LibIDN;
    my $idn = Net::LibIDN->new();
    my $ascii = $idn->toAscii("bücher.de");
    my $unicode = $idn->toUnicode("xn--bcher-kva.de");

DESCRIPTION

The Net::LibIDN module provides a Perl interface to the GNU IDN Library (libidn). Libidn is an implementation of the Internationalizing Domain Names in Applications (IDNA) standard, which allows domain names to contain non-ASCII characters.

The primary functions provided are:

toAscii(unicode_string)
Converts a Unicode domain name string to its Punycode ASCII representation. Returns undef on error.
toUnicode(ascii_string)
Converts a Punycode ASCII domain name string back to its Unicode representation. Returns undef on error.

The module also provides access to some of libidn's configuration options, such as setting the transliteration mode.
