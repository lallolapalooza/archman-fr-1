NOM

Net::Jabber::Dialback::Verify - Module de vérification Jabber Dialback

SYNTAXE

Net::Jabber::Dialback::Verify est un complément au module Net::Jabber::Dialback.
Il fournit à l'utilisateur une interface simple pour définir et récupérer toutes
les parties d'une vérification Jabber Dialback.

DESCRIPTION

Pour initialiser le Dialback avec un <db:*/> Jabber, vous devez lui passer
la table de hachage de XML::Stream. Par exemple :
  my $dialback = new Net::Jabber::Dialback::Verify(%hash);
Il y a eu un changement dans l'ancienne façon de gérer les rappels.
Vous n'avez plus à faire cela vous-même, un objet NJ::Dialback::Verify
est passé à la fonction de rappel pour le message. De plus,
le premier argument des fonctions de rappel est l'identifiant de session
provenant de XML::Streams. Il y a certains cas où vous pourriez avoir besoin de
cette information, comme si vous avez créé un client qui se connecte à deux
serveurs à la fois, ou pour écrire un mini serveur.
  use Net::Jabber qw(Server);
  sub dialbackVerify {
    my ($sid,$Verify) = @_;
    .
    .
    .
  }
Vous avez maintenant accès à toutes les fonctions de récupération disponibles.
Pour créer un nouveau dialback à envoyer au serveur :
  use Net::Jabber qw(Server);
  $Verify = new Net::Jabber::Dialback::Verify();
Vous pouvez maintenant appeler les fonctions de création ci-dessous pour
remplir la balise avant de l'envoyer.
Pour plus d'informations sur le format de tableau passé au rappel, veuillez
lire la documentation de Net::Jabber::Client.

Fonctions de récupération

$to         = $Verify->GetTo();
$from       = $Verify->GetFrom();
$type       = $Verify->GetType();
$id         = $Verify->GetID();
$data       = $Verify->GetData();
$str        = $Verify->GetXML();
@dialback   = $Verify->GetTree();

Fonctions de création

$Verify->SetVerify(from=>"jabber.org",
                   to=>"jabber.com",
                   id=>id,
                   data=>key);
$Verify->SetTo("jabber.org");
$Verify->SetFrom("jabber.com");
$Verify->SetType("valid");
$Verify->SetID(id);
$Verify->SetData(key);

Fonctions de test

$test = $Verify->DefinedTo();
$test = $Verify->DefinedFrom();
$test = $Verify->DefinedType();
$test = $Verify->DefinedID();

MÉTHODES

Fonctions de récupération

GetTo() -  renvoie une chaîne avec le serveur auquel le <db:verify/> est
           envoyé.
GetFrom() -  renvoie une chaîne avec le serveur dont le <db:verify/> est
             envoyé.
GetType() - renvoie une chaîne avec le type de <db:verify/> que c'est.
GetID() - renvoie une chaîne avec l'identifiant de <db:verify/> que c'est.
GetData() - renvoie une chaîne avec les cdata du <db:verify/>.
GetXML() - renvoie la chaîne XML qui représente le <db:verify/>.
           Ceci est utilisé par la fonction Send() dans Server.pm pour envoyer
           cet objet comme un Jabber Dialback Verify.
GetTree() - renvoie un tableau qui contient la balise <db:verify/>
            au format XML::Parser::Tree.

Fonctions de création

SetVerify(to=>chaîne,   - définit plusieurs champs dans le <db:verify/>
          from=>chaîne,   en une seule fois. C'est une action cumulative
          type=>chaîne,   et d'écrasement. Si vous définissez
          id=>chaîne,     l'attribut "from" deux fois, le second
          data=>chaîne)   paramètre est celui qui est utilisé. Si vous définissez
                          le type, puis que vous définissez les données,
                          alors les deux seront dans la balise <db:verify/>.
                          Pour les paramètres valides, lisez les fonctions
                          Set spécifiques ci-dessous.
SetTo(chaîne) - définit l'attribut to.
SetFrom(chaîne) - définit l'attribut from.
SetType(chaîne) - définit l'attribut type. Paramètres valides :
                  valid
                  invalid
SetID(chaîne) - définit l'attribut id.
SetData(chaîne) - définit les cdata du <db:verify/>.

Fonctions de test

DefinedTo() - renvoie 1 si l'attribut to est défini dans le
              <db:verify/>, 0 sinon.
DefinedFrom() - renvoie 1 si l'attribut from est défini dans le
                <db:verify/>, 0 sinon.
DefinedType() - renvoie 1 si l'attribut type est défini dans le
                <db:verify/>, 0 sinon.
DefinedID() - renvoie 1 si l'attribut id est défini dans le
                <db:verify/>, 0 sinon.
