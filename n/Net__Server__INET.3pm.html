NOM

Net::Server::INET - Personnalité de Net::Server

SYNTAXE

use base qw(Net::Server::INET);
sub process_request {
    #...code...
}
Net::Server::INET->run();

DESCRIPTION

Veuillez lire d'abord le pod sur Net::Server. Ce module est une personnalité, ou une extension, ou une sous-classe du module Net::Server.

Cette personnalité est destinée à être utilisée avec inetd. Elle n'offre aucune méthode au-delà de la classe de base Net::Server. Ce module fonctionne en surchargeant les méthodes pre_bind, bind, accept, et post_accept pour laisser tout le traitement de socket être effectué par inetd.
