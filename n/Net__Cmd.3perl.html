NOM

Net::Cmd - Classe de commandes réseau (telle qu'utilisée par FTP, SMTP, etc.)

SYNOPSIS

use Net::Cmd;
@ISA = qw(Net::Cmd);

DESCRIPTION

"Net::Cmd" est une collection de méthodes qui peuvent être héritées par une sous-classe de "IO::Socket::INET". Ces méthodes implémentent la fonctionnalité requise pour un protocole basé sur des commandes, par exemple FTP et SMTP.

Si votre sous-classe n'hérite pas également de "IO::Socket::INET" ou similaire (par exemple "IO::Socket::IP", "IO::Socket::INET6" ou "IO::Socket::SSL"), vous devez fournir vous-même les méthodes suivantes par d'autres moyens : close() et timeout().

Méthodes publiques

Ces méthodes fournissent une interface utilisateur à l'objet "Net::Cmd".

debug($level)
Définit le niveau d'informations de débogage pour cet objet. Si $level n'est pas spécifié, l'état actuel est renvoyé. Sinon, l'état est modifié à $level et l'état précédent est renvoyé.

Différents paquets peuvent implémenter différents niveaux de débogage, mais une valeur non nulle entraîne l'envoi de copies de toutes les commandes et réponses également sur STDERR.

Si $level est "undef", le niveau de débogage sera défini au niveau de débogage par défaut pour la classe.

Cette méthode peut également être appelée comme méthode *statique* pour définir/obtenir le niveau de débogage par défaut pour une classe donnée.

message()
Renvoie le message texte renvoyé par la dernière commande. Dans un contexte scalaire, il renvoie une seule chaîne, dans un contexte de liste, il renvoie chaque ligne comme un élément distinct. (Voir « RÉPONSES PSEUDO » ci-dessous.)
code()
Renvoie le code à 3 chiffres de la dernière commande. Si une commande est en attente, la valeur 0 est renvoyée. (Voir « RÉPONSES PSEUDO » ci-dessous.)
ok()
Renvoie une valeur non nulle si la dernière valeur de code était supérieure à zéro et inférieure à 400. Ceci est vrai pour la plupart des serveurs de commandes. Les serveurs pour lesquels cela n'est pas vrai peuvent remplacer cette méthode.
status()
Renvoie le chiffre le plus significatif du code de statut actuel. Si une commande est en attente, "CMD_PENDING" est renvoyé.
datasend($data)
Envoie des données au serveur distant, en convertissant LF en CRLF. Toute ligne commençant par un '.' sera préfixée par un autre '.'. $data peut être un tableau ou une référence vers un tableau. Les $data passés doivent être encodés par l'appelant en octets de l'encodage requis, par exemple en utilisant la fonction encode() du module Encode.
dataend()
Termine l'envoi de données au serveur distant. Ceci est fait en s'assurant que les données déjà envoyées se terminent par CRLF, puis en envoyant '.CRLF' pour terminer la transmission. Une fois ces données envoyées, "dataend" appelle "response" et renvoie vrai si "response" renvoie CMD_OK.

Méthodes protégées

Ces méthodes ne sont pas destinées à être appelées par l'utilisateur, mais utilisées ou remplacées par une sous-classe de "Net::Cmd".

"debug_print($dir, $text)"
Imprime les informations de débogage. $dir désigne la direction, *vrai* signifiant que les données sont envoyées au serveur. Appelle "debug_text" avant d'imprimer sur STDERR.
"debug_text($dir, $text)"
Cette méthode est appelée pour imprimer les informations de débogage. $text est le texte envoyé. La méthode doit renvoyer le texte à imprimer.

Ceci est principalement destiné à l'utilisation de modules tels que FTP où les mots de passe sont envoyés, mais nous ne voulons pas les afficher dans les informations de débogage.

"command($cmd[, $args, ... ])"
Envoie une commande au serveur de commandes. Tous les arguments sont d'abord joints avec un espace et CRLF est ajouté, cette chaîne est ensuite envoyée au serveur de commandes.

Renvoie undef en cas d'échec.

unsupported()
Définit le code de statut à 580 et le texte de réponse à 'Commande non prise en charge'. Renvoie zéro.
response()
Obtient une réponse du serveur. En cas de succès, le chiffre le plus significatif du code de statut est renvoyé. En cas d'échec, de délai d'attente, etc., *CMD_ERROR* est renvoyé.
parse_response($text)
Cette méthode est appelée par "response" comme méthode avec un argument. Elle doit renvoyer un tableau de 2 valeurs, le code de statut à 3 chiffres et un indicateur qui est vrai lorsque cela fait partie d'une réponse multiligne et que cette ligne n'est pas la dernière.
getline()
Récupère une ligne, délimitée par CRLF, du serveur distant. Renvoie *undef* en cas d'échec.

NOTE : Si vous utilisez cette méthode pour une raison quelconque, n'oubliez pas d'ajouter des appels "debug_print" dans votre méthode.

ungetline($text)
Remet une ligne de texte du serveur.
rawdatasend($data)
Envoie des données au serveur distant sans effectuer de conversions. $data est un scalaire. Comme pour datasend(), les $data passés doivent être encodés par l'appelant en octets de l'encodage requis, par exemple en utilisant la fonction encode() du module Encode.
read_until_dot()
Lit les données du serveur distant jusqu'à ce qu'une ligne constituée d'un simple '.'. Toutes les lignes commençant par '..' auront l'un des '.' supprimé.

Renvoie une référence vers une liste contenant les lignes, ou *undef* en cas d'échec.

tied_fh()
Renvoie un descripteur de fichier lié à l'objet Net::Cmd. Après avoir émis une commande, vous pouvez lire à partir de ce descripteur de fichier en utilisant read() ou <>. Le descripteur de fichier renverra EOF lorsque le point final sera rencontré. De même, vous pouvez écrire sur le descripteur de fichier pour envoyer des données au serveur après avoir émis une commande qui attend des données à écrire.

Voir les modules Net::POP3 et Net::SMTP pour des exemples de cela.

NOM

Net::Cmd

SYNOPSIS

use Net::Cmd;

DESCRIPTION

Net::Cmd est un module Perl qui fournit une interface simple et flexible pour exécuter des commandes et interagir avec des services réseau. Il permet aux utilisateurs d'envoyer des commandes à des serveurs distants, de gérer les réponses et de traiter divers types d'erreurs avec élégance.

EXPORTATIONS

Les symboles suivants sont, ou peuvent être, exportés par ce module :

Exportations par défaut
"CMD_INFO", "CMD_OK", "CMD_MORE", "CMD_REJECT", "CMD_ERROR", "CMD_PENDING".

(Ceux-ci correspondent aux résultats possibles de response() et status().)

Exportations optionnelles
Aucune.
Tags d'exportation
Aucun.
