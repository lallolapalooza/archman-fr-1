NOM

Net::DNS::SEC::Tools::defaults - valeurs par défaut de DNSSEC-Tools.

SYNOPSIS

use Net::DNS::SEC::Tools::defaults;
%defs = dnssec_tools_alldefaults();
$defalg = dnssec_tools_default("algorithm");
$cz_path = dnssec_tools_default("zonecheck");
$ksklife = dnssec_tools_default("ksklife");
@default_names = dnssec_tools_defnames();

DESCRIPTION

Ce module maintient un ensemble de valeurs par défaut utilisées par les programmes DNSSEC-Tools. Cela permet de centraliser ces valeurs en un seul endroit et d'éviter leur répétition entre plusieurs programmes.

INTERFACES

dnssec_tools_alldefaults()
Cette interface renvoie une copie de toutes les valeurs par défaut de DNSSEC-Tools sous forme de table de hachage.
dnssec_tools_default(default)
Cette interface renvoie la valeur d'une valeur par défaut de DNSSEC-Tools. L'interface reçoit default, qui est le nom d'une valeur par défaut à rechercher. La valeur de la valeur par défaut est renvoyée à l'appelant.
dnssec_tools_defnames()
Cette interface renvoie le nom de toutes les valeurs par défaut de DNSSEC-Tools. Aucune valeur par défaut n'est renvoyée, mais les noms des valeurs par défaut renvoyés par dnssec_tools_defnames() peuvent ensuite être passés à dnssec_tools_default().

CHAMPS PAR DÉFAUT

Voici les valeurs par défaut définies pour DNSSEC-Tools.

admin-email
Cette valeur par défaut stocke l'adresse électronique par défaut de l'administrateur de DNSSEC-Tools.
archivedir
Cette valeur par défaut stocke le répertoire par défaut dans lequel les clés seront archivées.
algorithm
Cette valeur par défaut stocke l'algorithme de chiffrement par défaut.
enddate
Cette valeur par défaut stocke la durée de vie de la zone en secondes par défaut.
entropy_msg
Cette valeur par défaut indique si zonesigner doit afficher un message d'entropie.
keygen
Cette valeur par défaut stocke le chemin d'accès au programme de génération de clés.
keygen-opts
Cette valeur par défaut stocke un ensemble d'options pour le programme de génération de clés.
kskcount
Cette valeur par défaut stocke le nombre par défaut de clés KSK à générer par une zone.
ksklength
Cette valeur par défaut stocke la longueur par défaut d'une clé KSK.
ksklife
Cette valeur par défaut stocke la durée de vie par défaut d'une clé KSK. Elle est uniquement utilisée pour déterminer quand vous devez changer la clé KSK. Les clés d'autres types n'ont pas de concept de durée de vie. Elle est mesurée en secondes.
lifespan-max
Cette valeur par défaut est la durée de vie maximale d'une clé.
lifespan-min
Cette valeur par défaut est la durée de vie minimale d'une clé.
log_tz
Cette valeur par défaut est le fuseau horaire à utiliser pour les horodatages des messages de journal.
mailer-server
Le serveur de messagerie qui sera contacté par dt_adminmail(). Ceci est passé à Mail::Send.
mailer-type
Le type de programme d'envoi de courrier qui sera contacté par dt_adminmail(). Ceci est passé à Mail::Mailer (via Mail::Send). Toute valeur reconnue par Mail::Mailer peut être utilisée ici.
prog_ksk1 ... prog_ksk7
Ces valeurs par défaut stockent les commandes par défaut à exécuter par rollerd pour chaque phase de rotation de KSK. Le default indique que le traitement normal des phases doit être effectué. Plusieurs commandes séparées par "!" peuvent être incluses. Le default peut être combiné avec d'autres commandes.
prog_normal
Ces valeurs par défaut stockent les commandes par défaut à exécuter par rollerd lorsqu'une zone n'est pas en état de rotation. Le default indique que le traitement normal des phases doit être effectué. Plusieurs commandes séparées par "!" peuvent être incluses. Le default peut être combiné avec d'autres commandes.
prog_zsk1 ... prog_zsk7
Ces valeurs par défaut stockent les commandes par défaut à exécuter par rollerd pour chaque phase de rotation de ZSK. Le default indique que le traitement normal des phases doit être effectué. Plusieurs commandes séparées par "!" peuvent être incluses. Le default peut être combiné avec d'autres commandes.
random
Cette valeur par défaut stocke le périphérique générateur de nombres aléatoires par défaut.
revperiod
Cette valeur par défaut stocke la période par défaut de révocation d'une clé KSK. C'est la période minimale pendant laquelle une clé révoquée doit rester dans l'ensemble signé pour être correctement observée par les résolveurs. Elle est mesurée en secondes.
rndc
Cette valeur par défaut est le chemin d'accès par défaut au programme rndc de BIND.
roll_loadzone
Cette valeur indique si rollerd doit faire recharger ses zones par le démon.
roll_logfile
Cette valeur est le chemin d'accès au fichier journal de rollerd.
roll_loglevel
Cette valeur est le niveau de journalisation par défaut pour rollerd.
roll_sleeptime
Cette valeur stocke le temps par défaut utilisé par le démon rollerd lors de la rotation.
savekeys
Cette valeur indique si les clés doivent être supprimées lorsqu'elles ne sont plus utilisées.
tacontact
Ceci n'est qu'un espace réservé pour les informations de contact. Il n'y a pas de valeur par défaut utile pour cela.
tadnsvalconffile
Cette valeur spécifie le chemin de configuration de dnsval.
tanamedconffile
Cette valeur spécifie le chemin de configuration de named.
taresolvconf
Cette valeur spécifie le chemin vers le fichier de configuration DNS resolv.conf.
tasleeptime
Cette valeur stocke la valeur par défaut du temps pendant lequel le démon doit dormir.
tasmtpserver
Cette valeur spécifie le nom du serveur SMTP.
tatmpdir
Cette valeur spécifie l'emplacement du répertoire temporaire de trustman.
usegui
Cette valeur indique si l'interface graphique de DNSSEC-Tools doit être utilisée pour la saisie des options.
zone_errors
Cette valeur stocke le nombre maximum d'erreurs consécutives qu'une zone peut avoir avant d'être changée en une zone de type skip.
