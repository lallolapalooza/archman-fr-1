NOM

Net::DNS::SEC::Keyset - Classe objet pour les jeux de clés DNSSEC

SYNOPSIS

use Net::DNS::SEC::Keyset;

DESCRIPTION

Un jeu de clés est une unité "administrative" utilisée pour la maintenance DNSSEC.

Cette classe fournit des interfaces pour créer, lire et écrire des jeux de clés.

Des méthodes d'objet sont fournies pour extraire les enregistrements DNSKEY, RRSIG et DS.

Notez que cette classe est encore en développement. Les attributs et méthodes sont sujets à changement.

new (à partir d'un fichier)

$keyset = Net::DNS::SEC::Keyset->new( $filename );
$keyset = Net::DNS::SEC::Keyset->new( $filename, $directory );
die Net::DNS::SEC::Keyset->keyset_err unless $keyset;

Méthode constructeur qui lit le fichier de jeu de clés spécifié et retourne un objet jeu de clés.

Le deuxième argument optionnel spécifie le répertoire de base du nom de fichier.

Définit keyset_err et retourne undef en cas d'échec.

new (avec les clés de signature)

$keyset = Net::DNS::SEC::Keyset->new( [@keyrr], $privatekeypath );
die Net::DNS::SEC::Keyset->keyset_err unless $keyset;

Crée un objet jeu de clés à partir des clés fournies via la référence à un tableau d'objets Net::DNS::RR::DNSKEY.

La méthode créera et signera elle-même l'ensemble du jeu de clés. Les clés privées générées par l'outil dnssec-keygen de BIND sont supposées se trouver dans le répertoire courant ou, si spécifié, dans le répertoire indiqué par $privatekeypath.

Définit keyset_err et retourne undef en cas d'échec.

new (à partir d'ensembles d'enregistrements clé et signature)

$keyset = Net::DNS::Keyset->new( [@keyrr], [@sigrr] );
die Net::DNS::SEC::Keyset->keyset_err unless $keyset;

Crée un objet jeu de clés à partir des clés fournies via les références à des tableaux d'objets Net::DNS::RR::DNSKEY et Net::DNS::RR::RRSIG.

Définit keyset_err et retourne undef en cas d'échec.

new (à partir d'un paquet)

$resolver = Net::DNS::Resolver->new;
$resolver->dnssec(1);

$reply = $res->send ( "example.com", "DNSKEY" );
$keyset = Net::DNS::SEC::Keyset->new( $reply );
die Net::DNS::SEC::Keyset->keyset_err unless $keyset;

Crée un objet jeu de clés à partir d'un Net::DNS::Packet qui contient la réponse à une requête pour les enregistrements de clés à l'apex de la zone.

C'est la méthode que vous devriez utiliser pour récupérer automatiquement les clés.

Définit keyset_err et retourne undef en cas d'échec.

keys

@keyrr = $keyset->keys;

Retourne un tableau d'objets Net::DNS::RR::DNSKEY.

sigs

@sigrr = $keyset->sigs;

Retourne un tableau d'objets Net::DNS::RR::RRSIG.

extract_ds

@ds = $keyset->extract_ds();        # SHA-1 par défaut
@ds = $keyset->extract_ds( digtype => 'SHA-256' );
die Net::DNS::SEC::Keyset->keyset_err unless @ds;

Extrait les enregistrements DS du jeu de clés. Notez que le jeu de clés sera vérifié pendant l'extraction. Toutes les clés devront avoir une auto-signature valide.

La méthode définit keyset_err si la vérification échoue.

verify

@keytags = $keyset->verify();
die Net::DNS::SEC::Keyset->keyset_err unless @keytags;
$keyset->verify( $keytag ) || die $keyset->keyset_err;

Si aucun argument n'est donné :

  • Vérifie si toutes les signatures présentes vérifient le jeu de clés.
  • Vérifie s'il existe des DNSKEY avec le drapeau SEP défini, il y a au moins un RRSIG créé à l'aide de cette clé.
  • Vérifie que s'il n'y a pas de DNSKEY avec le drapeau SEP défini, il y a au moins un RRSIG créé avec l'une des clés du jeu de clés.

Si un argument est fourni, il doit s'agir de la balise de clé numérique de la clé dans le jeu de clés qui sera vérifiée à l'aide du RRSIG correspondant.

La méthode retourne une liste de balises de clés des clés vérifiées dans le jeu de clés.

La méthode définit keyset_err et retourne une liste vide si la vérification échoue.

keyset_err

$keyset_err = Net::DNS::SEC::Keyset->keyset_err;

Retourne la chaîne d'erreur du jeu de clés.

string

$string = $keyset->string;

Retourne une représentation sous forme de chaîne du jeu de clés.

print

$keyset->print;             # similaire à print( $keyset->string )

Imprime le jeu de clés.

writekeyset

$keyset->writekeyset;
$keyset->writekeyset( $path );
$keyset->writekeyset( $prefix );
$keyset->writekeyset( $prefix, $path );

Écrit le jeu de clés dans un fichier nommé "keyset-<domaine>." dans le répertoire de travail courant ou dans le répertoire défini par l'argument optionnel $path.

L'argument optionnel $prefix spécifie le préfixe qui sera ajouté au nom de domaine pour former le nom du fichier du jeu de clés.
