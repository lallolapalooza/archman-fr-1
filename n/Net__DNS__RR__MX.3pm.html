NOM

Net::DNS::RR::MX - enregistrement de ressource DNS MX

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name MX preference exchange');

DESCRIPTION

Enregistrement de ressource (RR) DNS Mail Exchanger (MX)

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées par les méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités de package non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner la terminaison du programme ou d'autres comportements imprévisibles.

préférence

$preference = $rr->preference;
$rr->preference( $preference );

Un entier de 16 bits qui spécifie la préférence accordée à ce RR parmi d'autres au même propriétaire. Les valeurs inférieures sont préférées.

échange

$exchange = $rr->exchange;
$rr->exchange( $exchange );

Un nom de domaine qui spécifie un hôte disposé à agir comme échangeur de courrier pour le nom du propriétaire.
