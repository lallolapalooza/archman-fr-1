NOM

Net::DBus::RemoteService - Accéder aux services fournis sur le bus

SYNTAXE

my $bus = Net::DBus->find;
my $service = $bus->get_service("org.freedesktop.DBus");
my $object = $service->get_object("/org/freedesktop/DBus");
foreach (@{$object->ListNames}) {
  print "$_\n";
}

DESCRIPTION

Cet objet fournit un handle vers un service distant sur le bus. À partir de ce handle, il est possible d'accéder aux objets associés au service. Si un service n'est pas en cours d'exécution, une tentative sera faite pour l'activer lors du premier appel de méthode sur l'un de ses objets.

MÉTHODES

my $service = Net::DBus::RemoteService->new($bus, $owner, $service_name);
Crée un nouveau handle pour un service distant. Le paramètre $bus est une instance de Net::DBus, $owner est le nom du client fournissant le service, tandis que $service_name est le nom bien connu du service sur le bus. Les noms de service se composent de deux jetons ou plus, séparés par des points. Les jetons comprennent les lettres a-z, A-Z, 0-9 et _, par exemple "org.freedesktop.DBus". Il n'est généralement pas nécessaire d'appeler ce constructeur ; utilisez plutôt la méthode "get_service" sur Net::DBus. Celle-ci met en cache les handles vers les services distants, éliminant ainsi la récupération répétée des données d'introspection.
my $bus = $service->get_bus;
Récupère un handle pour le bus auquel ce service est attaché. L'objet renvoyé sera une instance de Net::DBus.
my $service_name = $service->get_service_name
Récupère le nom du service distant tel que connu du bus.
my $owner_name = $service->get_owner_name;
Récupère le nom du client qui possédait le service au moment de la connexion.
my $object = $service->get_object($object_path[, $interface]); =item my $object = $service->get_object($object_path, \%params);
Récupère un handle vers l'objet distant fourni par le service avec le nom de $object_path. Si le paramètre facultatif $interface est fourni, l'objet sera immédiatement converti vers l'interface désignée. NB : il n'est nécessaire de convertir un objet vers une interface spécifique que s'il existe plusieurs interfaces sur l'objet fournissant des méthodes du même nom, ou si l'objet distant ne prend pas en charge l'introspection. L'objet renvoyé sera une instance de Net::DBus::RemoteObject.

Une forme alternative de la méthode est disponible, passant une référence de hachage de paramètres supplémentaires. Les clés valides dans le hachage sont "interface" spécifiant le nom de l'interface vers laquelle convertir, et "timeout" spécifiant un délai d'attente en millisecondes.

my $timeout = $service->timeout(60 * 1000);
Définit ou récupère la valeur du délai d'attente qui sera utilisée pour les requêtes DBus appartenant à ce service. La valeur est en millisecondes. Si le délai d'attente d'un service est indéfini, alors le délai d'attente par défaut du bus s'appliquera.
