NOM

Net::DNS - Interface Perl pour le Système de Noms de Domaine (DNS)

SYNOPSIS

use Net::DNS;
my $resolver = Net::DNS::Resolver->new(...);
my $response = $resolver->send(...);

DESCRIPTION

Net::DNS est une collection de modules Perl qui sert d'interface pour la résolution des noms de domaine (DNS). Il permet au programmeur d'effectuer des requêtes DNS qui dépassent les capacités de gethostbyname et gethostbyaddr.

Le programmeur doit être familiarisé avec la structure d'un paquet DNS et le format de présentation des fichiers de zone décrit dans la RFC1035.

Objets Résolveur

Un objet résolveur est une instance de la classe Net::DNS::Resolver. Un programme peut avoir plusieurs objets résolveur, chacun conservant son propre état, tel que les serveurs de noms à interroger, si une résolution récursive est souhaitée, etc.

Objets Paquet

Les objets résolveur de Net::DNS retournent des objets de type Net::DNS::Packet. Un objet paquet possède cinq sections :

  • header, représenté par un objet Net::DNS::Header
  • question, une liste de zéro ou un objet Net::DNS::Question
  • answer, une liste d'objets Net::DNS::RR
  • authority, une liste d'objets Net::DNS::RR
  • additional, une liste d'objets Net::DNS::RR

Objets Mise à jour

Net::DNS::Update est une sous-classe de Net::DNS::Packet utile pour créer des requêtes de mise à jour dynamique.

Objet En-tête

L'objet Net::DNS::Header médie l'accès aux données d'en-tête trouvées dans le Net::DNS::Packet correspondant.

Objet Question

L'objet Net::DNS::Question représente le contenu de la section de question du paquet DNS.

Objets RR

Net::DNS::RR est la classe de base pour les enregistrements DNS (RR) dans les sections de réponse, d'autorité et additionnelles d'un paquet DNS.

Il ne faut pas supposer que les objets RR seront du type demandé. Avant d'appeler une méthode quelconque, le type de l'objet RR doit être vérifié.

MÉTHODES

Net::DNS exporte des méthodes et des fonctions utilitaires pour supporter les mises à jour DNS, la gestion du numéro de séquence de zone et les requêtes DNS simples.

version

use Net::DNS;
print Net::DNS->version, "\n";

Retourne la version de Net::DNS.

rr

# Utiliser un résolveur par défaut -- ne permet pas d'obtenir une chaîne d'erreur.
use Net::DNS;
my @rr = rr("example.com");
my @rr = rr("example.com", "AAAA");
my @rr = rr("example.com", "AAAA", "IN");
# Utiliser votre propre objet résolveur.
my $res = Net::DNS::Resolver->new;
my @rr  = rr($res, "example.com" ... );
my ($ptr) = rr("2001:DB8::dead:beef");

La méthode rr() fournit une requête RR simple pour les scénarios où la flexibilité complète de Net::DNS n'est pas nécessaire.

Retourne une liste d'objets Net::DNS::RR pour le nom spécifié ou une liste vide si la requête a échoué ou si aucun enregistrement n'a été trouvé.

Voir "EXEMPLES" pour des exemples plus complets.

mx

# Utiliser un résolveur par défaut -- ne permet pas d'obtenir une chaîne d'erreur.
use Net::DNS;
my @mx = mx("example.com");
# Utiliser votre propre objet résolveur.
my $res = Net::DNS::Resolver->new;
my @mx  = mx($res, "example.com");

Retourne une liste d'objets Net::DNS::RR::MX représentant les entrées MX pour le nom spécifié. La liste est triée par préférence. Retourne une liste vide si la requête a échoué ou si aucune entrée MX n'a été trouvée.

Cette méthode ne consulte pas les enregistrements d'adresse ; elle résout uniquement les MX.

Support de Mise à jour DNS Dynamique

Le module Net::DNS fournit des fonctions utilitaires qui supportent les requêtes de mise à jour DNS dynamique.

$update = Net::DNS::Update->new( 'example.com' );
$update->push( prereq => nxrrset('example.com. AAAA') );
$update->push( update => rr_add('example.com. 86400 AAAA 2001::DB8::F00') );

yxrrset

Utilisez cette méthode pour ajouter un prérequis "l'ensemble d'enregistrements existe" à un paquet de mise à jour dynamique. Il existe deux formes, indépendantes de la valeur et dépendantes de la valeur :

# L'ensemble d'enregistrements existe (indépendant de la valeur)
$update->push( pre => yxrrset("host.example.com AAAA") );

Signification : Au moins un RR avec le nom et le type spécifiés doit exister.

# L'ensemble d'enregistrements existe (dépendant de la valeur)
$update->push( pre => yxrrset("host.example.com AAAA 2001:DB8::1") );

Signification : Au moins un RR avec le nom et le type spécifiés et avec des données correspondantes doit exister.

Retourne un objet Net::DNS::RR ou "undef" si l'objet ne peut pas être créé.

nxrrset

Utilisez cette méthode pour ajouter un prérequis "l'ensemble d'enregistrements n'existe pas" à un paquet de mise à jour dynamique.

$update->push( pre => nxrrset("host.example.com AAAA") );

Signification : Aucun RR avec le nom et le type spécifiés ne peut exister.

Retourne un objet Net::DNS::RR ou "undef" si l'objet ne peut pas être créé.

yxdomain

Utilisez cette méthode pour ajouter un prérequis "domaine en cours d'utilisation" à un paquet de mise à jour dynamique.

$update->push( pre => yxdomain("host.example.com") );

Signification : Au moins un RR avec le nom spécifié doit exister.

Retourne un objet Net::DNS::RR ou "undef" si l'objet ne peut pas être créé.

nxdomain

Utilisez cette méthode pour ajouter un prérequis "domaine non utilisé" à un paquet de mise à jour dynamique.

$update->push( pre => nxdomain("host.example.com") );

Signification : Aucun RR avec le nom spécifié ne peut exister.

Retourne un objet Net::DNS::RR ou "undef" si l'objet ne peut pas être créé.

rr_add

Utilisez cette méthode pour ajouter des RR à une zone.

$update->push( update => rr_add("host.example.com AAAA 2001:DB8::c001:a1e") );

Signification : Ajoute ce RR à la zone.

Les RR créés par cette méthode doivent être ajoutés à la section "update" d'un paquet de mise à jour dynamique. Le TTL par défaut est de 86400 secondes (24 heures) s'il n'est pas spécifié.

Retourne un objet Net::DNS::RR ou "undef" si l'objet ne peut pas être créé.

rr_del

Utilisez cette méthode pour supprimer des RR d'une zone. Il existe trois formes : supprimer tous les RRsets, supprimer un RRset et supprimer un RR spécifique.

# Supprimer tous les RRsets.
$update->push( update => rr_del("host.example.com") );

Signification : Supprime tous les RR avec le nom spécifié.

# Supprimer un RRset.
$update->push( update => rr_del("host.example.com AAAA") );

Signification : Supprime tous les RR avec le nom et le type spécifiés.

# Supprimer un RR spécifique.
$update->push( update => rr_del("host.example.com AAAA 2001:DB8::dead:beef") );

Signification : Supprime le RR qui correspond à l'argument spécifié.

Les RR créés par cette méthode doivent être ajoutés à la section "update" d'un paquet de mise à jour dynamique.

Retourne un objet Net::DNS::RR ou "undef" si l'objet ne peut pas être créé.

EXEMPLES

Les brefs exemples suivants illustrent certaines des fonctionnalités de Net::DNS. La documentation des modules individuels et les scripts de démonstration inclus dans la distribution fournissent des exemples plus complets.

Voir Net::DNS::Update pour un exemple de réalisation de mises à jour dynamiques.

Recherche des adresses hôtes.

use Net::DNS;
my $res   = Net::DNS::Resolver->new;
my $reply = $res->search( "www.example.com", "AAAA" );
die "la requête a échoué: ", $res->errorstring unless $reply;
foreach my $rr ( $reply->answer ) {
        print $rr->address, "\n" if $rr->can("address");
}

Trouver les serveurs de noms d'un domaine.

use Net::DNS;
my $res   = Net::DNS::Resolver->new;
my $reply = $res->query( "example.com", "NS");
die "la requête a échoué: ", $res->errorstring unless $reply;
foreach $rr ( grep {$_->type eq "NS"} $reply->answer ) {
        print $rr->nsdname, "\n";
}

Trouver les enregistrements MX d'un domaine.

use Net::DNS;
my $name = "example.com";
my $res  = Net::DNS::Resolver->new;
my @mx   = mx( $res, $name );
foreach $rr (@mx) {
        print $rr->preference, "\t", $rr->exchange, "\n";
}

Afficher l'enregistrement SOA du domaine au format de fichier de zone.

use Net::DNS;
my $res   = Net::DNS::Resolver->new;
my $reply = $res->query( "example.com", "SOA" );
die "la requête a échoué: ", $res->errorstring unless $reply;
foreach my $rr ( $reply->answer ) {
        $rr->print;
}

Effectuer un transfert de zone et afficher tous les enregistrements.

use Net::DNS;
my $res  = Net::DNS::Resolver->new(
        nameservers => ["a.iana-servers.net", "b.iana-servers.net"],
        tcp_timeout => 20
        );
my @zone = $res->axfr("example.com");
warn $res->errorstring if $res->errorstring;
foreach $rr (@zone) {
        $rr->print;
}

Effectuer une requête en arrière-plan et afficher la réponse.

use Net::DNS;
my $res    = Net::DNS::Resolver->new;
$res->udp_timeout(10);
$res->tcp_timeout(20);
my $socket = $res->bgsend( "www.example.com", "AAAA" );
while ( $res->bgbusy($socket) ) {
        # faire du travail ici en attendant la réponse
        # ...et encore un peu ici
}
my $packet = $res->bgread($socket);
die "la requête a échoué: ", $res->errorstring unless $packet;
$packet->print;
