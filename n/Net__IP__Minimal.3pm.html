Net::IP::Minimal(3) Documentation Perl fournie par l'utilisateur Net::IP::Minimal(3)

NOM

Net::IP::Minimal - Fonctions minimales de Net::IP

VERSION

version 0.06

SYNTAXE

use Net::IP::Minimal qw[:PROC];
my $ip = '172.16.0.216';
ip_is_ipv4( $ip ) and print "$ip est IPv4";
$ip = 'dead:beef:89ab:cdef:0123:4567:89ab:cdef';
ip_is_ipv6( $ip ) and print "$ip est IPv6";
print ip_get_version( $ip );

DESCRIPTION

Net::IP est très complet en fonctionnalités, mais j'ai constaté que je n'utilisais que trois de ses fonctions et qu'il consommait pas mal de mémoire https://rt.cpan.org/Public/Bug/Display.html?id=24525.

Ce module ne fournit que le nombre minimal de fonctions que j'utilise dans mes modules.

FONCTIONS

Comme pour Net::IP, ces fonctions ne sont pas exportées par défaut. Vous pouvez les importer explicitement ou utiliser ":PROC" pour toutes les importer.

"ip_get_version"
Essayer de deviner la version IP d'une adresse IP. 
Paramètres  : Adresse IP
Retourne : 4, 6, undef (impossible de déterminer)

"$version = ip_get_version ($ip)"

"ip_is_ipv4"
Vérifier si une adresse IP est de type 4. 
Paramètres  : Adresse IP
Retourne : 1 (oui) ou 0 (non)

"ip_is_ipv4($ip) and print "$ip est IPv4";"

"ip_is_ipv6"
Vérifier si une adresse IP est de type 6. 
Paramètres            : Adresse IP
Retourne           : 1 (oui) ou 0 (non)

"ip_is_ipv6($ip) and print "$ip est IPv6";"
