NOM

Net::DNS::RR::OPENPGPKEY - Enregistrement de ressource DNS OPENPGPKEY

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name OPENPGPKEY key');

DESCRIPTION

Classe pour les enregistrements de ressources Clé OpenPGP (OPENPGPKEY).

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités de paquet non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

key

$key = $rr->key;
$rr->key( $key );

Représentation encodée en Base64 du matériel de clé publique OpenPGP.

keybin

$keybin = $rr->keybin;
$rr->keybin( $keybin );

Matériel de clé publique OpenPGP consistant en une seule clé publique OpenPGP transférable au format RFC4880.
