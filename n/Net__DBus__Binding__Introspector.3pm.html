NOM

Net::DBus::Binding::Introspector - Gestionnaire de données d'introspection d'objet

SYNOPIS

# Créer un objet qui sera peuplé avec les informations d'un document XML contenant des données d'introspection.
my $ins = Net::DBus::Binding::Introspector->new(xml => $data);
# Créer un objet, définir les données d'introspection par programme
my $ins = Net::DBus::Binding::Introspector->new(object_path => $object->get_object_path);
$ins->add_method("FaireQuelqueChose", ["string"], [], "org.example.MonObjet");
$ins->add_method("TesterQuelqueChose", ["int32"], [], "org.example.MonObjet");

DESCRIPTION

Cette classe est responsable de la gestion des données d'introspection et de la réponse aux requêtes les concernant. Elle n'est pas destinée aux utilisateurs des applications, qui devraient consulter l'API de plus haut niveau dans Net::DBus::Exporter.

MÉTHODES

my $ins = Net::DBus::Binding::Introspector->new(object_path => $object_path, xml => $xml);
Crée un nouveau gestionnaire de données d'introspection pour l'objet enregistré à la route spécifiée par le paramètre "object_path". Le paramètre optionnel "xml" peut être utilisé pour pré-charger le gestionnaire avec des métadonnées d'introspection à partir d'un document XML.
$ins->add_interface($name)
Enregistre l'objet comme fournissant une interface nommée $name
my $bool = $ins->has_interface($name)
Retourne une valeur vraie si l'objet est enregistré comme fournissant une interface nommée $name ; sinon retourne faux.
my @interfaces = $ins->has_method($name, [$interface])
Retourne une liste de toutes les interfaces fournies par l'objet qui contiennent une méthode nommée $name. Cela peut être une liste vide. Le paramètre optionnel $interface peut limiter la vérification à cette seule interface.
my $boolean = $ins->is_method_allowed($name[, $interface])
Vérifie si l'appelant distant est autorisé à invoquer la méthode $name sur l'objet associé à cet introspector. Si cet objet a l'exportation stricte activée, seules les méthodes explicitement exportées seront autorisées. Le paramètre optionnel $interface peut limiter la vérification à cette seule interface. Retourne une valeur non nulle si la méthode doit être autorisée.
my @interfaces = $ins->has_signal($name)
Retourne une liste de toutes les interfaces fournies par l'objet qui contiennent un signal nommé $name. Cela peut être une liste vide.
my @interfaces = $ins->has_property($name)
Retourne une liste de toutes les interfaces fournies par l'objet qui contiennent une propriété nommée $name. Cela peut être une liste vide. Le paramètre optionnel $interface peut limiter la vérification à cette seule interface.
$ins->add_method($name, $params, $returns, $interface, $attributes, $paramnames, $returnnames);
Enregistre l'objet comme fournissant une méthode nommée $name qui accepte des paramètres dont les types sont déclarés par $params et retourne des valeurs dont les types sont déclarés par $returns. La méthode sera étendue à l'interface nommée par $interface. Le paramètre $attributes est un dictionnaire d'annotations de méthode. Les paramètres $paramnames et $returnames sont une liste de noms d'arguments et de valeurs retournées.
$ins->add_signal($name, $params, $interface, $attributes);
Enregistre l'objet comme fournissant un signal nommé $name avec des paramètres dont les types sont déclarés par $params. Le signal sera étendu à l'interface nommée par $interface. Le paramètre $attributes est un dictionnaire d'annotations de signal.
$ins->add_property($name, $type, $access, $interface, $attributes);
Enregistre l'objet comme fournissant une propriété nommée $name avec un type de $type. Le paramètre $access peut être l'un de "read", "write" ou "readwrite". La propriété sera étendue à l'interface nommée par $interface. Le paramètre $attributes est un dictionnaire d'annotations.
my $boolean = $ins->is_method_deprecated($name, $interface)
Retourne une valeur vraie si la méthode nommée $name dans l'interface $interface est marquée comme obsolète
my $boolean = $ins->is_signal_deprecated($name, $interface)
Retourne une valeur vraie si le signal nommé $name dans l'interface $interface est marqué comme obsolète
my $boolean = $ins->is_property_deprecated($name, $interface)
Retourne une valeur vraie si la propriété nommée $name dans l'interface $interface est marquée comme obsolète
my $boolean = $ins->does_method_reply($name, $interface)
Retourne une valeur vraie si la méthode nommée $name dans l'interface $interface renvoie une réponse. Retourne faux sinon.
my $boolean = $ins->method_has_strict_exceptions($name, $interface)
Retourne vrai si la méthode nommée $name dans l'interface $interface a la propriété strict_exceptions ; c'est-à-dire que toute exception autre qu'un objet Net::DBus::Error ne doit pas être capturée et doit remonter la pile.
my @names = $ins->list_interfaces
Retourne une liste de toutes les interfaces enregistrées comme étant fournies par l'objet.
my @names = $ins->list_methods($interface)
Retourne une liste de toutes les méthodes enregistrées comme étant fournies par l'objet, au sein de l'interface $interface.
my @names = $ins->list_signals($interface)
Retourne une liste de tous les signaux enregistrés comme étant fournis par l'objet, au sein de l'interface $interface.
my @names = $ins->list_properties($interface)
Retourne une liste de toutes les propriétés enregistrées comme étant fournies par l'objet, au sein de l'interface $interface.
my @paths = $self->list_children;
Retourne une liste de chemins d'objet représentant les enfants de ce nœud.
my $path = $ins->get_object_path
Retourne le chemin de l'objet associé à ces données d'introspection.
my @types = $ins->get_method_params($interface, $name)
Retourne une liste de types de données déclarés pour les paramètres de la méthode nommée $name au sein de l'interface $interface.
my @types = $ins->get_method_param_names($interface, $name)
Retourne une liste de noms déclarés pour les paramètres de la méthode nommée $name au sein de l'interface $interface.
my @types = $ins->get_method_returns($interface, $name)
Retourne une liste de types de données déclarés pour les valeurs de retour de la méthode nommée $name au sein de l'interface $interface.
my @types = $ins->get

_method_return_names($interface, $name)
Retourne une liste des noms déclarés pour les valeurs de retour de la méthode appelée $name dans l'interface $interface.
my @types = $ins->get_signal_params($interface, $name)
Retourne une liste des types de données déclarés pour les valeurs associées au signal appelé $name dans l'interface $interface.
my @types = $ins->get_signal_param_names($interface, $name)
Retourne une liste des noms déclarés pour les valeurs associées au signal appelé $name dans l'interface $interface.
my $type = $ins->get_property_type($interface, $name)
Retourne le type de données déclaré pour la propriété appelée $name dans l'interface $interface.
my $bool = $ins->is_property_readable($interface, $name);
Retourne une valeur vraie si la propriété appelée $name dans l'interface $interface peut être lue.
my $bool = $ins->is_property_writable($interface, $name);
Retourne une valeur vraie si la propriété appelée $name dans l'interface $interface peut être écrite.
my $xml = $ins->format([$obj])
Retourne une chaîne contenant un document XML représentant l'état des données d'introspection. Le paramètre optionnel $obj peut être une instance de Net::DBus::Object pour inclure des informations spécifiques à l'objet dans le XML (par exemple, les nœuds enfants).
my $xml_fragment = $ins->to_xml
Retourne une chaîne contenant un fragment XML représentant l'état des données d'introspection. C'est essentiellement la même chose que la méthode "format", mais sans la déclaration de type document.
$type = $ins->to_xml_type($type)
Prend une représentation textuelle d'un type de données et retourne la représentation compacte utilisée dans les données d'introspection XML.
$ins->encode($message, $type, $name, $direction, @args)
Ajoute un ensemble de valeurs <@args> à un objet message $message. Le paramètre $type est soit "signal", soit "method", et $direction est soit "params", soit "returns". Les données d'introspection seront interrogées pour obtenir les types de données déclarés et le marshalling des arguments en conséquence.
my @args = $ins->decode($message, $type, $name, $direction)
Désérialise le contenu d'un objet message $message. Le paramètre $type est soit "signal", soit "method", et $direction est soit "params", soit "returns". Les données d'introspection seront interrogées pour obtenir les types de données déclarés et les arguments désérialisés en conséquence.
