Net::LDAP::Control::SortResult(3) Documentation Perl fournie par l'utilisateur Net::LDAP::Control::SortResult(3)

NOM

Net::LDAP::Control::SortResult - objet de contrôle de résultat de tri côté serveur (SSS)

SYNTAXE

use Net::LDAP::Control::Sort;
use Net::LDAP::Constant qw(LDAP_CONTROL_SORTRESULT);
use Net::LDAP::Util qw(ldap_error_name);
$sort = Net::LDAP::Control::Sort->new(
  order => "cn -age"
);
$mesg = $ldap->search( @args, control => [ $sort ]);
($resp) = $mesg->control( LDAP_CONTROL_SORTRESULT );
if ($resp) {
  if ($resp->result) {
    my $attr = $resp->attr;
    print "Problème de tri, ",ldap_error_name($resp->result);
    print " ($attr)"  if $attr;
    print "\n";
  }
  else {
    print "Les résultats sont triés\n";
  }
}
else {
  print "Le serveur ne prend pas en charge le tri\n";
}

DESCRIPTION

"Net::LDAP::Control::SortResult" est une sous-classe de Net::LDAP::Control. Elle fournit une classe pour manipuler le contrôle de requête de tri LDAP 1.2.840.113556.1.4.474 tel que défini dans la RFC-2891.

Un contrôle de résultat de tri sera renvoyé par le serveur en réponse à une recherche avec un contrôle de tri côté serveur. Si aucun contrôle de résultat de tri n'est renvoyé, l'utilisateur peut supposer que le serveur ne prend pas en charge le tri et que les résultats ne sont pas triés.

ARGUMENTS DU CONSTRUCTEUR

attr
Si "result" indique qu'il y a eu un problème de tri et que ce problème était dû à l'un des attributs spécifiés dans le contrôle de tri. "attr" est défini sur le nom de l'attribut causant le problème.
result
C'est le code de résultat qui décrit si l'opération de tri a réussi. Ce sera l'un des codes de résultat décrits ci-dessous.

MÉTHODES

Comme avec Net::LDAP::Control, chaque argument du constructeur décrit ci-dessus est également disponible sous forme de méthode sur l'objet, qui renverra la valeur actuelle de l'attribut si elle est appelée sans argument, et définira une nouvelle valeur pour l'attribut si elle est appelée avec un argument.

CODES DE RÉSULTAT

Les résultats possibles d'une requête de tri sont listés ci-dessous. Voir Net::LDAP::Constant pour une définition de chacun.

LDAP_SUCCESS
LDAP_OPERATIONS_ERROR
LDAP_TIMELIMIT_EXCEEDED
LDAP_STRONG_AUTH_REQUIRED
LDAP_ADMIN_LIMIT_EXCEEDED
LDAP_NO_SUCH_ATTRIBUTE
LDAP_INAPPROPRIATE_MATCHING
LDAP_INSUFFICIENT_ACCESS
LDAP_BUSY
LDAP_UNWILLING_TO_PERFORM
LDAP_OTHER

VOIR AUSSI

Net::LDAP, Net::LDAP::Control::Sort, Net::LDAP::Control, http://ww.ietf.org/rfc/rfc2891.txt
