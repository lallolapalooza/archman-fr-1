NOM

Net::DNS::RR::TLSA - enregistrement de ressource TLSA DNS

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name TLSA usage selector matchingtype certificate');

DESCRIPTION

L'enregistrement de ressource DNS TLSA (Transport Layer Security Authentication) est utilisé pour associer un certificat ou une clé publique TLS au nom de domaine où l'enregistrement est trouvé, formant une "association de certificat TLSA". La sémantique de la manière dont l'enregistrement TLSA est interprété est décrite dans la RFC6698.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées des méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités non documentées du paquet ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

usage

$usage = $rr->usage;
$rr->usage( $usage );

Valeur entière sur 8 bits qui spécifie l'association fournie qui sera utilisée pour faire correspondre le certificat présenté lors de la négociation TLS.

selector

$selector = $rr->selector;
$rr->selector( $selector );

Valeur entière sur 8 bits qui spécifie quelle partie du certificat TLS présenté par le serveur sera mise en correspondance avec les données d'association.

matchingtype

$matchingtype = $rr->matchingtype;
$rr->matchingtype( $matchingtype );

Valeur entière sur 8 bits qui spécifie comment l'association de certificat est présentée.

certificate

cert

$cert = $rr->cert;
$rr->cert( $cert );

Représentation hexadécimale des données du certificat.

certbin

$certbin = $rr->certbin;
$rr->certbin( $certbin );

Représentation binaire des données du certificat.

babble

print $rr->babble;

La méthode babble() renvoie la représentation 'BubbleBabble' du digest si le paquet Digest::BubbleBabble est disponible, sinon une chaîne vide est renvoyée.

BubbleBabble représente un digest de message sous forme d'une chaîne de mots plausibles, afin de faciliter la vérification du digest. Les "mots" ne sont pas nécessairement de vrais mots, mais ils ressemblent davantage à des mots qu'une chaîne de caractères hexadécimaux.

La chaîne 'BubbleBabble' est ajoutée comme commentaire lors de l'appel de la méthode string.
