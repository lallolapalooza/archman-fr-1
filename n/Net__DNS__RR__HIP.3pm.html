NOM

Net::DNS::RR::HIP - Enregistrement de ressource HIP (Host Identity Protocol) DNS

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name IN HIP algorithm hit key servers');

DESCRIPTION

Classe pour les enregistrements de ressource HIP (Host Identity Protocol) DNS.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées par les méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités non documentées du package ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner la terminaison du programme ou d'autres comportements imprévisibles.

algorithm

$algorithm = $rr->algorithm;
$rr->algorithm( $algorithm );

Le champ PK algorithm indique l'algorithme cryptographique de la clé publique et le format du champ de clé publique implicite. Les valeurs sont celles définies pour le type d'algorithme IPSECKEY [RFC4025].

hit

$hit = $rr->hit;
$rr->hit( $hit );

La représentation hexadécimale de l'étiquette d'identité de l'hôte.

hitbin

$hitbin = $rr->hitbin;
$rr->hitbin( $hitbin );

La représentation binaire de l'étiquette d'identité de l'hôte.

key

$key = $rr->key;
$rr->key( $key );

La représentation MIME Base64 de la clé publique.

keybin

$keybin = $rr->keybin;
$rr->keybin( $keybin );

La représentation binaire de la clé publique.

servers

@servers = $rr->servers;

Liste optionnelle des noms de domaine des serveurs de rendez-vous.
