Net::Jabber::Log(3) Documentation Perl fournie par l'utilisateur Net::Jabber::Log(3)

NOM

Net::Jabber::Log - Module de journalisation Jabber

SYNTAXE

Net::Jabber::Log est un compagnon du module Net::Jabber.
Il fournit à l'utilisateur une interface simple pour définir et récupérer toutes
les parties d'un journal Jabber.

DESCRIPTION

Pour initialiser le journal avec un <log/> Jabber, vous devez lui passer le
tableau d'arbre XML::Parser. Par exemple :
  my $log = new Net::Jabber::Log(@tree);
Il y a eu un changement par rapport à l'ancienne méthode de gestion des rappels.
Vous n'avez plus besoin de faire ce qui précède, un objet Net::Jabber::Log est passé
à la fonction de rappel pour le journal :
  use Net::Jabber;
  sub log {
    my ($Log) = @_;
    .
    .
    .
  }
Vous avez maintenant accès à toutes les fonctions de récupération disponibles.
Pour créer un nouveau journal à envoyer au serveur :
  use Net::Jabber;
  $Log = new Net::Jabber::Log();
Maintenant, vous pouvez appeler les fonctions de création ci-dessous pour peupler la balise avant
de l'envoyer.
Pour plus d'informations sur le format du tableau passé au rappel
veuillez lire la documentation de Net::Jabber::Client.

Fonctions de récupération

$from       = $Log->GetFrom();
$fromJID    = $Log->GetFrom("jid");
$type       = $Log->GetType();
$data       = $Log->GetData();
$str        = $Log->GetXML();
@log        = $Log->GetTree();

Fonctions de création

$Log->SetLog(type=>"error",
             from=>"users.jabber.org",
             data=>"La lune est pleine... Je ne peux plus courir.");
$Log->SetFrom("foo.jabber.org");
$Log->SetType("warn");
$Log->SetData("Je ne trouve pas de fichier de configuration. Utilisation des valeurs par défaut.");

Fonctions de test

$test = $Log->DefinedFrom();
$test = $Log->DefinedType();

MÉTHODES

Fonctions de récupération

GetFrom()      - renvoie soit une chaîne avec l'identifiant Jabber,
GetFrom("jid")    soit un objet Net::Jabber::JID de la personne qui
                  a envoyé le <log/>. Pour obtenir l'objet JID,
                  définissez la chaîne sur "jid", sinon laissez vide pour la
                  chaîne texte.
GetType() - renvoie une chaîne avec le type de <log/>.
GetData() - renvoie une chaîne avec le cdata du <log/>.
GetXML() - renvoie la chaîne XML qui représente le <log/>.
           Ceci est utilisé par la fonction Send() dans Client.pm pour envoyer
           cet objet comme un journal Jabber.
GetTree() - renvoie un tableau contenant la balise <log/>
            au format d'arbre XML::Parser.

Fonctions de création

SetLog(from=>chaîne|JID, - définit plusieurs champs dans le <log/>
       type=>chaîne,       en même temps. Ceci est une action cumulative
       data=>chaîne)       et d'écrasement. Si vous définissez
                           l'attribut "from" deux fois, le second
                           paramètre est celui utilisé. Si vous définissez
                           le type, puis définissez les données
                           alors les deux seront dans la balise <log/>
                           . Pour les réglages valides, lisez
                           les fonctions Set spécifiques ci-dessous.
SetFrom(chaîne) - définit l'attribut from. Vous pouvez soit passer une chaîne
SetFrom(JID)      soit un objet JID. Ils doivent être des identifiants Jabber valides
                  sinon le serveur renverra un journal d'erreur.
                  (c.-à-d. jabber:bob@jabber.org/Silent Bob, etc...)
SetType(chaîne) - définit l'attribut type. Les réglages valides sont :
                  notice     journalisation générale
                  warn       avertissement
                  alert      erreur critique (peut toujours s'exécuter mais pas
                             correctement)
                  error      erreur fatale (ne peut plus s'exécuter)
SetData(chaîne) - définit le cdata du <log/>.

Fonctions de test

DefinedFrom() - renvoie 1 si l'attribut from est défini dans le
                <log/>, 0 sinon.
DefinedType() - renvoie 1 si l'attribut type est défini dans le
                <log/>, 0 sinon.
