NOM

Net::Jabber::Dialback::Result - Module de résultat de Dialback Jabber

SYNOPIS

Net::Jabber::Dialback::Result est un compagnon du module Net::Jabber::Dialback. Il offre à l'utilisateur une interface simple pour définir et récupérer toutes les parties d'un résultat de Dialback Jabber.

DESCRIPTION

Pour initialiser le Résultat avec un <db:*/> Jabber, vous devez lui passer le hash XML::Stream. Par exemple :
  my $dialback = new Net::Jabber::Dialback::Result(%hash);
Il y a eu un changement dans l'ancienne manière de gérer les rappels. Vous n'avez plus à faire cela vous-même, un objet NJ::Dialback::Result est passé à la fonction de rappel pour le message. De plus, le premier argument des fonctions de rappel est l'identifiant de session de XML::Streams. Il y a certains cas où vous pourriez vouloir ces informations, comme si vous aviez créé un Client qui se connecte à deux serveurs simultanément, ou pour écrire un mini serveur.
  use Net::Jabber qw(Server);
  sub dialbackResult {
    my ($sid,$Result) = @_;
    .
    .
    .
  }
Vous avez maintenant accès à toutes les fonctions de récupération disponibles.
Pour créer un nouveau dialback à envoyer au serveur :
  use Net::Jabber qw(Server);
  $Result = new Net::Jabber::Dialback::Result();
Vous pouvez maintenant appeler les fonctions de création ci-dessous pour peupler la balise avant de l'envoyer.
Pour plus d'informations sur le format du tableau passé au rappel, veuillez lire la documentation de Net::Jabber::Client.

Fonctions de récupération

$to         = $Result->GetTo();
$from       = $Result->GetFrom();
$type       = $Result->GetType();
$data       = $Result->GetData();
$str        = $Result->GetXML();
@dialback   = $Result->GetTree();

Fonctions de création

$Result->SetResult(from=>"jabber.org",
                   to=>"jabber.com",
                   data=>key);
$Result->SetTo("jabber.org");
$Result->SetFrom("jabber.com");
$Result->SetType("valid");
$Result->SetData(key);

Fonctions de test

$test = $Result->DefinedTo();
$test = $Result->DefinedFrom();
$test = $Result->DefinedType();

MÉTHODES

Fonctions de récupération

GetTo() -  retourne une chaîne avec le serveur auquel le <db:result/> est envoyé.
GetFrom() -  retourne une chaîne avec le serveur d'où provient le <db:result/>.
GetType() - retourne une chaîne avec le type de <db:result/>.
GetData() - retourne une chaîne avec le cdata du <db:result/>.
GetXML() - retourne la chaîne XML qui représente le <db:result/>.
           Ceci est utilisé par la fonction Send() dans Server.pm pour envoyer
           cet objet comme un résultat de Dialback Jabber.
GetTree() - retourne un tableau qui contient la balise <db:result/>
            au format XML::Parser::Tree.

Fonctions de création

SetResult(to=>chaîne,   - définit plusieurs champs dans le <db:result/>
          from=>chaîne,   en même temps. Ceci est une action cumulative
          type=>chaîne,   et d'écrasement. Si vous définissez
          data=>chaîne)   l'attribut "from" deux fois, le second
                          paramètre est celui qui est utilisé. Si vous définissez
                          le type, puis que vous définissez les données,
                          alors les deux seront dans la balise <db:result/>.
                          Pour les paramètres valides, lisez les
                          fonctions Set spécifiques ci-dessous.
SetTo(chaîne) - définit l'attribut to.
SetFrom(chaîne) - définit l'attribut from.
SetType(chaîne) - définit l'attribut type. Les paramètres valides sont :
                  valid
                  invalid
SetData(chaîne) - définit le cdata du <db:result/>.

Fonctions de test

DefinedTo() - retourne 1 si l'attribut to est défini dans le
              <db:result/>, 0 sinon.
DefinedFrom() - retourne 1 si l'attribut from est défini dans le
                <db:result/>, 0 sinon.
DefinedType() - retourne 1 si l'attribut type est défini dans le
                <db:result/>, 0 sinon.
