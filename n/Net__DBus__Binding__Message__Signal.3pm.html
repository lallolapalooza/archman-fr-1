NOM

Net::DBus::Binding::Message::Signal - un message encodant un signal

SYNTAXE

use Net::DBus::Binding::Message::Signal;
my $signal = Net::DBus::Binding::Message::Signal->new(
    object_path => "/org/example/myobject",
    interface => "org.example.myobject",
    signal_name => "foo_changed");
$connection->send($signal);

DESCRIPTION

Ce module fait partie des API de bas niveau de liaison DBus, et ne doit pas être utilisé par le code d'application. Aucune garantie n'est faite concernant la stabilité des API sous l'espace de noms "Net::DBus::Binding::" entre les différentes versions.

Ce module fournit un constructeur pratique pour créer un message représentant un signal.

MÉTHODES

mon $signal = Net::DBus::Binding::Message::Signal->new( object_path => $path, interface => $interface, signal_name => $name);
Crée un nouveau message, représentant un signal [à émettre] par l'objet situé sous le chemin donné par le paramètre "object_path". Le nom du signal est donné par le paramètre "signal_name", et est délimité à l'interface donnée par le paramètre "interface".
