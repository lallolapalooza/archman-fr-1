NOM

Net::DNS::RR::SOA - Enregistrement de ressource SOA DNS

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new('name SOA mname rname 0 14400 3600 1814400 3600');

DESCRIPTION

Classe pour les enregistrements de ressource Start of Authority (SOA) DNS.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées des méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités non documentées du package ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

mname

$mname = $rr->mname;
$rr->mname( $mname );

Le nom de domaine du serveur de noms qui était la source originale ou primaire des données pour cette zone.

rname

$rname = $rr->rname;
$rr->rname( $rname );

La boîte aux lettres qui identifie la personne responsable de la maintenance de cette zone.

serial

$serial = $rr->serial;
$serial = $rr->serial(valeur);

Numéro de version non signé sur 32 bits de la copie originale de la zone. Les transferts de zone préservent cette valeur.

RFC1982 définit un ordre partiel strict (irréflexif) pour les numéros de série des zones. Le numéro de série sera incrémenté à moins que la valeur de remplacement n'satisfasse la contrainte d'ordre.

refresh

$refresh = $rr->refresh;
$rr->refresh( $refresh );

Un intervalle de temps de 32 bits avant que la zone ne doive être rafraîchie.

retry

$retry = $rr->retry;
$rr->retry( $retry );

Un intervalle de temps de 32 bits qui devrait s'écouler avant qu'une tentative de rafraîchissement échouée ne soit retry.

expire

$expire = $rr->expire;
$rr->expire( $expire );

Une valeur de temps de 32 bits qui spécifie la limite supérieure de l'intervalle de temps qui peut s'écouler avant que la zone ne soit plus autoritaire.

minimum

$minimum = $rr->minimum;
$rr->minimum( $minimum );

Le champ TTL minimum non signé sur 32 bits qui devrait être exporté avec tout enregistrement de cette zone.

Gestion des numéros de série de zone

La logique interne de la méthode serial() offre un support pour plusieurs politiques de numérotation de série de zone largement utilisées.

Strictement Séquentiel

$successeur = $soa->serial( SÉQUENTIEL );

Le numéro de série existant est incrémenté modulo 2**32 car la valeur renvoyée par la fonction auxiliaire SEQUENTIAL() ne peut jamais satisfaire la contrainte d'ordre des numéros de série.

Encodé par Date

$successeur = $soa->serial( AAAAMMDDxx );

La valeur de 32 bits renvoyée par la fonction auxiliaire AAAAMMDDxx() sera utilisée si elle satisfait la contrainte d'ordre, sinon le numéro de série sera incrémenté comme ci-dessus.

Les incréments de numéro de série doivent être limités à 100 par jour pour que les informations de date restent utiles.

Encodé par Heure

$successeur = $soa->serial( UNIXTIME );

La valeur de 32 bits renvoyée par la fonction auxiliaire UNIXTIME() sera utilisée si elle satisfait la contrainte d'ordre, sinon le numéro de série existant sera incrémenté comme ci-dessus.
