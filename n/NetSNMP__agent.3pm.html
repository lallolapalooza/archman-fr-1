agent(3) Documentation des contributions Perl pour le module NetSNMP agent(3)

NAME

NetSNMP::agent - extension Perl pour l'agent SNMP.

SYNOPSIS

use NetSNMP::agent;
my $agent = new NetSNMP::agent('Name' => 'my_agent_name');

DESCRIPTION

Ce module implémente un ensemble d'APIs pour faire agir un agent SNMP comme un agent SNMP, un sous-agent (utilisant le protocole AgentX), ou même des fonctions d'APIs Perl embarquées directement à l'intérieur du démon traditionnel de l'agent SNMP.

Voir aussi le guide sur l'API C générale de Net-SNMP, que ce module implémente en Perl, et un guide spécifique pour Perl à :

http://www.net-snmp.org/tutorial-5/toolkit/

EXAMPLES

Exemple de sous-agent

use NetSNMP::agent (':all');
use NetSNMP::ASN qw(ASN_OCTET_STR);
my $value = "hello world";
sub myhandler {
    my ($handler, $registration_info, $request_info, $requests) = @_;
    my $request;
    for($request = $requests; $request; $request = $request->next()) {
        my $oid = $request->getOID();
        if ($request_info->getMode() == MODE_GET) {
            # ... généralement, vous calculez la valeur à partir de l'OID
            if ($oid == new NetSNMP::OID(".1.3.6.1.4.1.8072.9999.9999.7375.1.0")) {
                $request->setValue(ASN_OCTET_STR, $value);
            }
        } elsif ($request_info->getMode() == MODE_GETNEXT) {
            # ... généralement, vous calculez la valeur à partir de l'OID
            if ($oid < new NetSNMP::OID(".1.3.6.1.4.1.8072.9999.9999.7375.1.0")) {
                $request->setOID(".1.3.6.1.4.1.8072.9999.9999.7375.1.0");
                $request->setValue(ASN_OCTET_STR, $value);
            }
        } elsif ($request_info->getMode() == MODE_SET_RESERVE1) {
            if ($oid != new NetSNMP::OID(".1.3.6.1.4.1.8072.9999.9999.7375.1.0")) {  # faites une vérification d'erreur ici
                $request->setError($request_info, SNMP_ERR_NOSUCHNAME);
            }
        } elsif ($request_info->getMode() == MODE_SET_ACTION) {
            # ... (ou utilisez la valeur)
            $value = $request->getValue();
        }
    }
}
my $agent = new NetSNMP::agent(
                        # fait lire à l'agent un fichier my_agent_name.conf
                        'Name' => "my_agent_name",
                        'AgentX' => 1
                        );
$agent->register("my_agent_name", ".1.3.6.1.4.1.8072.9999.9999.7375",
                 \&myhandler);
my $running = 1;
while($running) {
        $agent->agent_check_and_process(1);
}
$agent->shutdown();

Exemple d'agent embarqué

# placez ceci dans un fichier .pl, puis dans votre snmpd.conf placez :
#    perl do '/path/to/file.pl';
use NetSNMP::agent;
my $agent;
sub myhandler {
    my ($handler, $registration_info, $request_info, $requests) = @_;
    # ...
}
$agent = new NetSNMP::agent(
                        'Name' => 'my_agent_name'
                        );
$agent->register("my_agent_name", ".1.3.6.1.4.1.8072.9999.9999.7375",
                 \&myhandler);
$agent->main_loop();

CONSTRUCTEUR

new ( OPTIONS )
    C'est le constructeur pour un objet NetSNMP::agent.
   Les options possibles sont :
    Name    - Nom de l'agent (optionnel, défaut 'perl')
              (L'agent SNMP de la librairie lira un fichier NAME.conf basé sur cet argument.)
    AgentX  - En faire un sous-agent (0 = faux, 1 = vrai)
              (L'agent maître Net-SNMP doit être lancé d'abord)
    Ports   - Ports sur lesquels l'agent écoutera (Ex: 'udp:161,tcp:161')
Exemple :
    $agent = new NetSNMP::agent(
                             'Name' => 'my_agent_name',
                             'AgentX' => 1
                             );

MÉTHODES

register (NAME, OID, \&handler_routine )
    Enregistre le callback du handler avec l'OID donné.
    $agent->register();
    Retourne un code de 0 en cas de succès.
agent_check_and_process ( Blocking )
    Exécute une itération de la boucle principale.
    Blocking - appel bloquant ou non bloquant. 1 = vrai, 0 = faux.
    $agent->agent_check_and_process(1);
main_loop ()
    Exécute l'agent en boucle. Ne retourne pas.
shutdown ()
    Ferme l'agent ou le sous-agent de manière propre.
    $agent->shutdown();

CALLBACKS DU HANDLER

handler ( HANDLER, REGISTRATION_INFO, REQUEST_INFO, REQUESTS )
    Le handler est appelé avec les paramètres suivants :
    HANDLER                 - FIXME
    REGISTRATION_INFO       - quels sont les significations correctes de ces éléments ?
    REQUEST_INFO            -
    REQUESTS                -
Exemple de handler :
    sub myhandler {
        my ($handler, $reg_info, $request_info, $requests) = @_;
        # ...
    }

La sous-routine handler sera appelée lorsqu'une requête SNMP arrive à l'agent pour un OID enregistré. La sous-routine se voit passer 4 arguments : $handler, $registration_info, $request_info, $requests. Ceux-ci correspondent aux arguments passés à la version C de la même API. Ils devraient être des objets fonctionnels "suffisants" pour le moment. Note : ce ne sont pas des objets complètement complets mais des fonctions "suffisantes" pour le moment.

Fonctions de l'objet $request_info

getMode ()
    Retourne le mode de la requête. Voir la section MODES pour la liste des modes valides.
    $mode = $request->getMode();

Fonctions de l'objet $registration_info

getRootOID ()
    Retourne un objet NetSNMP::OID décrivant l'emplacement d'enregistrement que le handler obtient (dans le cas d'un enregistrement d'un seul OID sur plusieurs handlers, ce qui devrait être rare).
    $root_oid = $request->getRootOID();

Fonctions de l'objet $request

next ()
    Retourne la requête suivante dans la liste ou undef s'il n'y a pas de requête suivante.
    $request = $request->next();
getOID ()
    Retourne l'OID de la requête (un objet NetSNMP::OID).
    $oid = $request->getOID();
setOID (new NetSNMP::OID("someoid"))
    Définit l'OID de la requête à une valeur donnée. Ceci ne devrait généralement être fait que lors du traitement des requêtes GETNEXT.
    $request->setOID(new NetSNMP::OID("someoid"));
getValue ()
    Retourne la valeur de la requête. Utilisé dans l'exemple lors de la définition des valeurs.
    $value = $request->getValue();
    FIXME : Comment obtenir le type de la valeur ? Est-il même disponible ? [Wes : non, pas encore.]
setValue ( TYPE, DATA )
    Définit la donnée à retourner au démon.
    Retourne 1 en cas de succès, 0 en cas d'erreur.
    TYPE - Type de la donnée. Voir NetSNMP::ASN pour les types valides.
    DATA - La donnée à retourner.
    $ret = $request->setValue(ASN_OCTET_STR, "test");
setError ( REQUEST_INFO, ERROR_CODE )
    Définit le code d'erreur donné pour la requête.
    Voir la section ERROR CODES pour la liste des codes valides.
    $request->setError($request_info, SNMP_ERR_NOTWRITABLE);
getProcessed ()
    Le drapeau traité indique qu'une requête n'a pas besoin d'être traitée car quelqu'un (un handler supérieur) l'a déjà traitée.
    $processed = $request->getProcessed();
setProcessed ( PROCESSED )
    Définit le drapeau traité dans la requête. Généralement, vous ne devriez pas avoir à le définir vous-même.
    PROCESSED - 0 = faux, 1 = vrai
    $request->setProcessed(1);
getDelegated ()
    Si vous pouvez traiter une requête en arrière-plan ou plus tard (par exemple, vous attendez un fichier ouvert, du trafic réseau, ou ...), le drapeau délégué peut être défini sur la requête. Lorsque la requête sera traitée plus tard, le drapeau devra être défini sur 0 afin que l'agent sache qu'il peut renvoyer la requête originale au gestionnaire. Ceci n'a pas été testé en Perl, mais nous espérons que cela fonctionnera.
    $delegated = $request->getDelegated();
setDelegated ( DELEGATED )
    Définit le drapeau délégué.
    DELEGATED - 0 = faux, 1 = vrai
    $request->setDelegated(1);
getRepeat ()
    Le drapeau de répétition indique qu'une opération getbulk est en cours et indique combien de réponses doivent être retournées. Généralement, si vous ne vous êtes pas enregistré pour gérer directement le support de getbulk, vous n'en aurez pas besoin.
    $repeat = $request->getRepeat();

NetSNMP::agent(3pm) — Perl documentation

NAME

NetSNMP::agent — Access the Net-SNMP agent's internal API.

SYNOPSIS

 use NetSNMP::agent;
 use NetSNMP::OID;
 use NetSNMP::ASN;
 use Socket;

 # ... Agent setup code ...

 sub my_handler {
  my ($request) = @_;
  # ... handler code ...
 }

 # Register the handler for a specific OID
 NetSNMP::agent::register_handler(
  oid => '1.3.6.1.4.1.32285.1.1.1.1.1', # Example OID
  handler => \&my_handler,
 );

 # ... Agent run code ...

DESCRIPTION

This module provides an interface to the internal Net-SNMP agent's API, allowing Perl scripts to act as SNMP agents or subagents.

EXAMPLES

This module is typically used in conjunction with the snmpd.conf(5) directive perlModule.

 perlModule NetSNMP::agent

And within the snmpd.conf file:

 perl "my_module.pl"

Where my_module.pl is a Perl script that uses this module.

CONSTRUCTOR

The NetSNMP::agent module does not have a public constructor. It is loaded and used by the Net-SNMP agent.

METHODS

The following methods are available for manipulating SNMP requests within a handler callback.

$request->getRequestType()
Returns the type of the SNMP request. This will be one of the MODES constants (e.g. MODE_GET, MODE_SET_ACTION).
$request->getOid()
Returns the NetSNMP::OID object for the current OID being processed.
$request->getNextOid()
Returns the NetSNMP::OID object for the next OID in a GETNEXT or GETBULK request.
$request->setNextOid( NEXT_OID )
Sets the NetSNMP::OID object for the next OID in a GETNEXT or GETBULK request. This is typically used when you want to control the iteration of OIDs for GETBULK requests.
$request->getVarbind()
Returns the NetSNMP::Varbind object for the current OID being processed.
$request->setVarbind( VARBIND )
Sets the NetSNMP::Varbind object for the current OID. This is used to set the value for GET requests or to confirm the value for SET requests.
$request->getValue()
Returns the value of the current variable bind. The type of the returned value depends on the ASN type of the variable bind.
$request->setValue( VALUE )
Sets the value of the current variable bind. The VALUE should be an appropriate Perl representation of the ASN type.
$request->getRepeat()
Gets the repeat count for a GETBULK request. This indicates how many variable bindings the agent should attempt to retrieve.
$request->setRepeat( REPEAT )
Sets the repeat count for a GETBULK request. This is used to limit the number of variable bindings returned by the agent.
$request->getSourceIp()
Gets the IPv4 address of the device making the request to the handler.
$request->getDestIp()
Gets the IPv4 address of the destination that the request was sent to.

HANDLER CALLBACKS

Handlers registered with register_handler receive a single argument, a NetSNMP::agent::Request object, which represents the SNMP request.

The handler is responsible for processing the request and either returning a value (for GET requests) or performing an action (for SET requests).

The handler should return one of the ERROR_CODES constants to indicate the result of the operation.

 sub my_handler {
  my ($request) = @_;

  my $mode = $request->getRequestType();

  if ($mode == MODE_GET) {
   my $oid = $request->getOid();

   if ($oid == NetSNMP::OID->new('1.3.6.1.4.1.32285.1.1.1.1.1.1')) {
    # Handle GET for a specific OID
    my $value = "Hello, World!";
    $request->setValue($value);
    return SNMP_ERR_NOERROR;
   }
  } elsif ($mode == MODE_SET_ACTION) {
   my $oid = $request->getOid();
   my $value = $request->getValue();

   if ($oid == NetSNMP::OID->new('1.3.6.1.4.1.32285.1.1.1.1.1.2')) {
    # Handle SET for a specific OID
    print "Received value '$value' for OID $oid\n";
    # Perform actions based on the value
    return SNMP_ERR_NOERROR;
   }
  }

  # If the handler doesn't recognize the OID or mode, return an error
  return SNMP_ERR_NOSUCHNAME;
 }

For GETBULK requests, the handler may need to use getRepeat and setRepeat to manage the number of variable bindings returned.

 sub bulk_handler {
  my ($request) = @_;

  my $repeat = $request->getRepeat();
  my $next_oid = $request->getNextOid(); # Starting OID for bulk

  my $counter = 0;
  while ($counter < $repeat) {
   # Generate or retrieve the next OID and value
   my $current_oid = NetSNMP::OID->new("1.3.6.1.4.1.32285.1.1.1.1.1." . ($counter + 1));
   my $current_value = "Bulk value " . ($counter + 1);

   # Set the varbind for the current OID
   my $varbind = NetSNMP::Varbind->new(oid => $current_oid, value => $current_value);
   $request->setVarbind($varbind);

   $counter++;

   # If we've reached the end of available data, break
   last if ($counter >= 10); # Example limit
  }

  # If we didn't fulfill the full repeat count, indicate end of data
  if ($counter < $repeat) {
   # This might require specific handling depending on the agent's needs
   # For now, we just indicate success with the number of items provided
  }

  return SNMP_ERR_NOERROR;
 }

You can also use the getSourceIp and getDestIp methods to get information about the requesting client.

 use Socket;
 my $source_ip_addr = $request->getSourceIp();
 my $source_ip_str = inet_ntoa($source_ip_addr);
 print "Request from: $source_ip_str\n";

 my $dest_ip_addr = $request->getDestIp();
 my $dest_ip_str = inet_ntoa($dest_ip_addr);
 print "Request to: $dest_ip_str\n";

For SET requests, you will typically need to implement the different SET modes:

 sub set_handler {
  my ($request) = @_;
  my $mode = $request->getRequestType();
  my $oid = $request->getOid();

  if ($mode == MODE_SET_RESERVE1) {
   # Check if the incoming value is valid
   my $value = $request->getValue();
   if (looks_like_number($value) && $value > 0) {
    # Store the value temporarily
    $temp_values{$oid} = $value;
    return SNMP_ERR_NOERROR;
   } else {
    return SNMP_ERR_BADVALUE;
   }
  } elsif ($mode == MODE_SET_ACTION) {
   # Perform the actual action (e.g., update configuration)
   my $value = $temp_values{$oid};
   # ... update configuration with $value ...
   delete $temp_values{$oid}; # Clean up temporary storage
   return SNMP_ERR_NOERROR;
  } elsif ($mode == MODE_SET_COMMIT) {
   # Commit the changes if everything is okay
   return SNMP_ERR_NOERROR;
  } elsif ($mode == MODE_SET_UNDO) {
   # Undo the changes if a commit failed or rollback is needed
   # ... revert changes ...
   delete $temp_values{$oid}; # Clean up temporary storage
   return SNMP_ERR_NOERROR;
  } elsif ($mode == MODE_SET_FREE) {
   # Free any resources allocated
   delete $temp_values{$oid};
   return SNMP_ERR_NOERROR;
  }
  # ... other modes like MODE_SET_RESERVE2 if needed

  return SNMP_ERR_GENERR; # Default error
 }
