NOM

Net::XMPP - Bibliothèque Perl pour le protocole XMPP

RÉSUMÉ

Net::XMPP offre un accès pratique à tout script Perl qui souhaite utiliser le protocole XMPP de messagerie instantanée. Bien qu'il ne s'agisse pas d'un client en soi, il offre toutes les fonctionnalités nécessaires pour créer facilement un client CGI ou un client en ligne de commande Perl. Net::XMPP est un wrapper autour des autres paquets Net::XMPP::xxxxxx.

Il existe des exemples de scripts dans le répertoire des exemples qui fournissent des exemples de programmes XMPP très simples.

NOTE : L'analyseur fourni par XML::Stream::Parser, ainsi que de nombreux analyseurs Perl, est synchrone. Si vous êtes en train d'analyser un paquet et que vous appelez un rappel défini par l'utilisateur, l'analyseur se bloque jusqu'à ce que le rappel soit terminé. Cela signifie que vous ne pouvez pas opérer sur un paquet, en envoyer un autre et attendre une réponse à ce paquet. Vous n'atteindrez jamais cette partie. Le threading pourrait résoudre ce problème, mais jusqu'à présent, le threading en Perl n'est pas assez stable. Ce problème sera revu à l'avenir.

MÉTHODES

Le module Net::XMPP ne définit aucune méthode que vous pouvez appeler directement dans votre code. Au lieu de cela, il instancie des objets qui appellent des fonctions de ce module pour effectuer des travaux. Les trois classes principales avec lesquelles vous travaillerez sont les modules Message, Presence et IQ. Chacun correspond à l'équivalent Jabber et permet d'obtenir et de modifier toutes les parties de ces paquets.

Il existe quelques fonctions qui sont les mêmes pour tous les objets :

Fonctions de récupération

GetXML
Renvoie la chaîne XML représentant les données contenues dans l'objet. 
$xml  = $obj->GetXML();
GetChild
Renvoie une liste d'objets Net::XMPP::Stanza représentant tous les stanzas dans l'objet qui ont un espace de noms spécifié. Si vous spécifiez un espace de noms, seuls les stanzas avec ce XMLNS seront renvoyés. 
@xObj = $obj->GetChild();
@xObj = $obj->GetChild("my:namespace");
GetTag
Renvoie le nom du nœud racine du paquet.
GetTree
Renvoie l'objet XML::Stream::Node contenant les données. Voir XML::Stream::Node pour les méthodes que vous pouvez appeler sur cet objet.

Fonctions de création

NewChild
NewChild(namespace)
NewChild(namespace,tag)

Crée un objet Net::XMPP::Stanza avec l'espace de noms spécifié et le nœud racine correspondant à l'espace de noms. Optionnellement, vous pouvez spécifier un autre nœud racine si le défaut n'est pas souhaité, ou si l'espace de noms exige qu'un soit spécifié.

$xObj = $obj->NewChild("my:namespace");
$xObj = $obj->NewChild("my:namespace","foo");

c.-à-d. <foo xmlns='my:namespace'...></foo>

InsertRawXML
InsertRawXML(string)

Écrit la chaîne spécifiée sous forme de XML directement dans le paquet sur lequel vous avez appelé cette fonction.

$message->InsertRawXML("<foo></foo>")
  <message...>...<foo></foo></message>
$x = $message->NewChild(..);
$x->InsertRawXML("test");
$query = $iq->GetChild(..);
$query->InsertRawXML("test");
ClearRawXML
ClearRawXML()

Supprime le XML brut du paquet.

Fonctions de suppression

RemoveChild
RemoveChild()
RemoveChild(namespace)

Supprime tous les éléments enfants de l'espace de noms de l'objet. Si un espace de noms est spécifié, seuls les éléments enfants portant cet espace de noms sont supprimés.

Fonctions de test

DefinedChild
DefinedChild()
DefinedChild(namespace)

Renvoie 1 s'il existe des espaces de noms connus dans le paquet qui ont des stanzas, sinon renvoie 0. Optionnellement, vous pouvez spécifier un espace de noms et déterminer s'il existe des stanzas avec cet espace de noms.

$test = $obj->DefinedChild();
$test = $obj->DefinedChild("my:namespace");

PAQUETS

Pour plus d'informations sur chacun de ces paquets, veuillez consulter la page man correspondante.

Net::XMPP::Client

Ce paquet contient le code nécessaire pour communiquer avec un serveur XMPP : se connecter, attendre les messages, envoyer des messages et se déconnecter. Il utilisera XML::Stream pour lire le flux du serveur et appellera une fonction en fonction du type de balise qu'il rencontre.

Net::XMPP::Protocol

Un ensemble de fonctions de haut niveau qui facilitent la vie du client. Ces fonctions sont héritées par le client.

Net::XMPP::JID

Les identifiants XMPP sont composés de trois parties : l'utilisateur, le serveur et la ressource. Ce module vous donne accès à ces parties sans avoir à analyser la chaîne vous-même.

Net::XMPP::Message

Tout ce qui est nécessaire pour créer et lire un message <message/> reçu du serveur.

Net::XMPP::Presence

Tout ce qui est nécessaire pour créer et lire un message <presence/> reçu du serveur.

Net::XMPP::IQ

IQ est un wrapper pour un certain nombre de modules qui fournissent un support pour les divers espaces de noms Info/Query que XMPP reconnaît.

Net::XMPP::Stanza

Ce module représente un stanza d'espace de noms utilisé pour étendre un <message/>, <presence/> et <iq/>. La page man du module Net::XMPP::Stanza contient une liste de tous les espaces de noms pris en charge et des méthodes disponibles sur les objets représentant ces espaces de noms.

Net::XMPP::Namespaces

XMPP permet d'ajouter n'importe quel stanza à n'importe quelle partie de XML. Ce module contient tous les éléments internes pour définir les extensions XMPP basées sur l'IETF. La documentation de ce module explique davantage comment ajouter votre propre espace de noms personnalisé et le faire prendre en charge.
