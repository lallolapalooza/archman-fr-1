NOM

Net::DNS::Text - Représentation textuelle DNS

SYNOPIS

use Net::DNS::Text;
$objet = Net::DNS::Text->new('exemple');
$chaine = $objet->string;
$objet = Net::DNS::Text->decode( \$donnees, $decalage );
( $objet, $suivant ) = Net::DNS::Text->decode( \$donnees, $decalage );
$donnees = $objet->encode;
$texte = $objet->value;

DESCRIPTION

Le module "Net::DNS::Text" implémente une classe d'objets texte avec des méthodes de classe et d'instance associées.

Chaque instance d'objet texte a une identité fixe tout au long de sa durée de vie.

MÉTHODES

new

$objet = Net::DNS::Text->new('exemple');

Crée un objet texte qui encapsule une composante de chaîne de caractères unique d'un enregistrement de ressource.

Des caractères arbitraires mono-octet peuvent être représentés par \ suivi de exactement trois chiffres décimaux. De tels caractères sont dépourvus de tout sens spécial.

Un caractère précédé de \ représente lui-même, sans aucune interprétation spéciale.

decode

$objet = Net::DNS::Text->decode( \$buffer, $decalage );
( $objet, $suivant ) = Net::DNS::Text->decode( \$buffer, $decalage );

Crée un objet texte qui représente les données décodées au décalage indiqué dans le tampon de données.

La liste d'arguments se compose d'une référence à un scalaire contenant les données au format fil et le décalage des données texte.

La valeur de décalage retournée indique le début de l'élément suivant dans le tampon de données.

encode

$donnees = $objet->encode;

Retourne la représentation encodée au format fil de l'objet texte, adaptée à une inclusion dans un tampon de paquet DNS.

raw

$donnees = $objet->raw;

Retourne la représentation encodée au format fil de l'objet texte sans le champ de longueur explicite.

value

$valeur = $texte->value;

Représentation sous forme de chaîne de caractères de l'objet texte.

string

$chaine = $texte->string;

Représentation du fichier de zone RFC1035 conditionnellement mise entre guillemets de l'objet texte.

unicode

$chaine = $texte->unicode;

Représentation Unicode conditionnellement mise entre guillemets de l'objet texte.
