NOM

Net::DBus::Test::MockMessage - Créer un objet message factice lors des tests

SYNOPSIS

Envoyer un message

my $msg = new Net::DBus::Test::MockMessage;
my $iterator = $msg->iterator;
$iterator->append_byte(132);
$iterator->append_int32(14241);
$connection->send($msg);

DESCRIPTION

Ce module fournit un équivalent "mock" à la classe Net::DBus::Binding::Message. Il s'agit essentiellement d'un objet message factice entièrement en Perl, qui fournit le même contrat que l'objet réel. Il est utilisé en interne par les API de test.

MÉTHODES

my $call = Net::DBus::Test::MockMessage->new_method_call( service_name => $service, object_path => $object, interface => $interface, method_name => $name);
Crée un message représentant un appel sur l'objet situé au chemin "object_path" dans le client qui possède le nom bien connu donné par "service_name". La méthode à invoquer porte le nom "method_name" dans l'interface spécifiée par le paramètre "interface".
my $msg = Net::DBus::Test::MockMessage->new_method_return( replyto => $method_call);
Crée un message représentant la réponse à l'appel de méthode passé comme paramètre "replyto".
my $signal = Net::DBus::Test::MockMessage->new_signal( object_path => $path, interface => $interface, signal_name => $name);
Crée un nouveau message, représentant un signal émis par l'objet situé au chemin donné par le paramètre "object_path". Le nom du signal est donné par le paramètre "signal_name", et il est défini dans l'interface donnée par le paramètre "interface".
my $msg = Net::DBus::Test::MockMessage->new_error( replyto => $method_call, name => $name, description => $description);
Crée un nouveau message, représentant une erreur qui s'est produite lors du traitement de l'appel de méthode objet passé comme paramètre "replyto". Le paramètre "name" est le nom formel de l'erreur, tandis que le paramètre "description" est un court texte donnant des informations plus spécifiques sur l'erreur.
my $type = $msg->get_type
Obtient le code de type de ce message. La valeur retournée correspond à l'une des quatre constantes "Net::DBus::Test::MockMessage::MESSAGE_TYPE_*".
my $name = $msg->get_error_name
Renvoie le nom formel de l'erreur, tel que passé précédemment par le paramètre "name" dans le constructeur.
my $interface = $msg->get_interface
Obtient le nom de l'interface auquel ce message est destiné, qui peut être une chaîne vide s'il n'y a pas d'interface applicable pour ce message.
my $path = $msg->get_path
Obtient le chemin de l'objet associé au message, qui peut être une chaîne vide s'il n'y a pas d'objet applicable pour ce message.
my $name = $msg->get_destination
Obtient le nom unique ou le nom bien connu du client destinataire du message. Peut renvoyer une chaîne vide si le message est diffusé à tous les clients.
my $name = $msg->get_sender
Renvoie le nom unique du client qui envoie le message.
my $serial = $msg->get_serial
Obtient le numéro de série unique de ce message. Le numéro est unique pendant la durée de vie de la connexion sur laquelle le message a été envoyé. Peut renvoyer zéro si le message n'a pas encore été envoyé.
my $name = $msg->get_member
Pour les appels de méthode, obtient le nom de la méthode à invoquer, tandis que pour les signaux, obtient le nom du signal.
$msg->set_sender($name)
Définit le nom du client qui envoie le message. Le nom doit être le nom unique du client.
$msg->set_destination($name)
Définit le nom du destinataire du message. Ceci est généralement utilisé pour les signaux afin de passer de la diffusion à l'unicast.
my $iterator = $msg->iterator;
Obtient un itérateur qui peut être utilisé pour lire ou écrire les champs du message. L'objet retourné est une instance de la classe "Net::DBus::Binding::Iterator".
$boolean = $msg->get_no_reply()
Obtient le drapeau indiquant si le message attend une réponse à être envoyée.
$msg->set_no_reply($boolean)
Définit le drapeau indiquant si le message attend une réponse à être envoyée. Tous les messages d'appel de méthode attendent une réponse par défaut. L'activation de ce drapeau réduit la latence de communication en évitant au client d'attendre.
my @values = $msg->get_args_list
Désérialise toutes les valeurs dans le corps du message, en utilisant le type de données identifié par le message de type. Les valeurs sont retournées sous forme de liste.
$msg->append_args_list(@values)
Ajoute un ensemble de valeurs à la partie message. Les valeurs sont encodées en tant que chaîne, liste ou dictionnaire en fonction de leur type de données Perl. Pour des besoins de typage de données plus spécifiques, l'objet "Net::DBus::Binding::Iterator" doit être utilisé à la place.
my $sig = $msg->get_signature
Obtient une chaîne représentant la signature de type des valeurs stockées dans le corps du message.
