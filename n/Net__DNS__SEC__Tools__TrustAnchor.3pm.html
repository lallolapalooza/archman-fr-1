NOM

Net::DNS::SEC::Tools::TrustAnchor

SYNOPSIS

Ceci est une classe de base pour plusieurs types de dépôts d'ancres de confiance qui savent comment lire, écrire et modifier les dépôts d'ancres de confiance.

Ce paquet sert à la fois d'enveloppe API autour d'un ensemble d'ancres de confiance et de classe de base pour les paquets qui ont besoin de lire/écrire des ensembles d'ancres de confiance dans différents formats.

Les ancres de confiance peuvent être soit des enregistrements DNSKEY, soit des références DS.

API

API d'utilisation définie par ce module ou ses sous-modules.

Notez que :

use Net::DNS::SEC::Tools::TrustAnchor;

est censé avoir importé certaines des routines de l'API mentionnées ci-dessous.

$tar = new Net::DNS::SEC::Tools::TrustAnchor();

Initialise une nouvelle collection d'ancres de confiance.

$module = load_module("type");

Tente de charger dynamiquement une sous-classe de lecteur/scripteur d'ancres de confiance de Net::DNS::SEC::Tools::TrustAnchor nommée « Type » et en retourne une instance.

Toutes les sous-classes sont censées contenir un nom de classe en lettre majuscule unique suivi de lettres minuscules. Tout module nommé différemment échouera au chargement à l'aide de cette routine.

$module = parse_component("type:file");

Ceci analyse une spécification de type et de fichier composée d'un type séparé par un deux-points (« : ») suivi du chemin d'accès au nom de fichier. Il chargera ensuite le module de type à l'aide de la routine load_module() et retournera le type, le fichier et les options supplémentaires.

XXX : le support de l'analyse des options n'est pas encore terminé et modifiera probablement la spécification du format type:fichier ; c'est-à-dire que la spécification du format type:fichier changera probablement à l'avenir et devrait être considérée comme un support de niveau alpha.

$tar = $module->read($location, $options);

Lit une TAR donnée à partir d'une référence $location et retourne une copie bénie de l'objet Net::DNS::SEC::Tools::TrustAnchor contenant toutes les données.

Cette fonction peut être remplacée par une sous-classe.

$tar = $module->read($location, $options);

Lit une TAR donnée à partir d'une référence $location et retourne une table de hachage non bénie du contenu. La fonction read() s'enroule simplement autour de cela et la bénit après son retour.

Les sous-modules doivent remplacer cette fonction (et/ou la fonction read()) s'ils s'attendent à ce que le module prenne en charge le chargement.

$tar->merge(@others)

Fusionne le tableau @other d'ancres de confiance dans la propre liste d'ancres de confiance de l'objet $tar.
