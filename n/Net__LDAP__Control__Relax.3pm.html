Net::LDAP::Control::Relax(3) Documentation Perl fournie par l'utilisateur Net::LDAP::Control::Relax(3)

NOM

Net::LDAP::Control::Relax - objet de contrôle LDAPv3 Relax

SYNTAXE

use Net::LDAP;
use Net::LDAP::Control::Relax;
$ldap = Net::LDAP->new( "ldap.mondomaine.eg" );
$relax = Net::LDAP::Control::Relax->new();
$msg = $ldap->modify( 'dc=sous,dc=mondomaine,dc=eg",
                      changes => [
                        replace => { modifyTimestamp => '19700101000000Z' } ],
                      control  => [ $relax ] );
die "erreur: ",$msg->code(),": ",$msg->error()  if ($msg->code());

DESCRIPTION

"Net::LDAP::Control::Relax" fournit une interface pour la création et la manipulation d'objets qui représentent le contrôle "Relax" tel que décrit dans draft-zeilenga-ldap-relax-03.txt

Le contrôle, qui n'a pas de contrôle de réponse correspondant, est approprié pour toutes les requêtes de mise à jour LDAP, y compris l'ajout, la suppression, la modification et moddn.

La présence du contrôle Relax dans une requête de mise à jour LDAP indique que le serveur relâche temporairement les contraintes du modèle X.500 pendant l'exécution de la mise à jour du répertoire.

Il n'a pas de valeur et sa criticité est toujours définie sur "TRUE".

ARGUMENTS DU CONSTRUCTEUR

Comme le contrôle "Relax" n'a pas de valeurs, seuls les arguments du constructeur décrits dans Net::LDAP::Control sont pris en charge.

MÉTHODES

Comme il n'y a pas de valeurs supplémentaires dans le contrôle, seules les méthodes de Net::LDAP::Control sont disponibles pour les objets "Net::LDAP::Control::Relax".
