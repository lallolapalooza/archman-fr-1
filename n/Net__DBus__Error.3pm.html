NOM

Net::DBus::Error - Détails des erreurs pour l'invocation de méthode distante

SYNTAXE

package Music::Player::UnknownFormat;
use base qw(Net::DBus::Error);
# Définit un type d'erreur pour le type d'encodage de piste inconnu
# pour un service de lecteur de musique
sub new {
    my $proto = shift;
    my $class = ref($proto) || $proto;
    my $self = $class->SUPER::new(name => "org.example.music.UnknownFormat",
                                  message => "Format d'encodage de piste inconnu");
}
package Music::Player::Engine;
...coupé...
# Lit soit des pistes musicales mp3, soit ogg, sinon
# lance une erreur
sub play {
    my $self = shift;
    my $url = shift;
    if ($url =~ /\.(mp3|ogg)$/) {
        ...lit la piste
    } else {
       die Music::Player::UnknownFormat->new();
    }
}

DESCRIPTION

Cet objet permet une gestion d'erreurs fortement typée. Normalement, un service appellerait simplement

die "un message texte quelconque"

Lors du retour de la condition d'erreur au client DBus appelant, le message est associé à un code d'erreur générique ou à "org.freedesktop.DBus.Failed". Bien que cela suffise pour de nombreuses applications, il est parfois souhaitable de pouvoir intercepter et gérer des conditions d'erreur spécifiques. Pour de tels scénarios, le service doit créer des sous-classes de l'objet "Net::DBus::Error" en fournissant un nom d'erreur personnalisé. Ce nom d'erreur est alors renvoyé au client au lieu du code générique "org.freedesktop.DBus.Failed".

MÉTHODES

my $error = Net::DBus::Error->new(name => $error_name, message => $description);
Crée un nouvel objet d'erreur dont le nom est donné par le paramètre "name", et dont le texte descriptif long est fourni par le paramètre "message". Le paramètre "name" a certaines règles de formatage qui doivent être respectées. Il ne doit contenir que les lettres 'a'-'Z', '0'-'9', '-', '_' et '.'. Il doit y avoir au moins deux composants séparés par un '.'. Par exemple, un nom valide est 'org.example.Music.UnknownFormat'.
$error->name
Retourne le nom d'erreur DBus associé à l'objet.
$error->message
Retourne le texte/message descriptif associé à la condition d'erreur.
$error->stringify
Formate l'erreur sous forme de chaîne de caractères de manière appropriée pour l'affichage / la journalisation / la présentation à l'utilisateur, etc.
