NOM

Net::DNS::RR::PX — Enregistrement de ressource DNS PX

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nom PX préférence map822 mapx400');

DESCRIPTION

Classe pour les enregistrements de ressource DNS X.400 Mail Mapping Information (PX).

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées des méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités de paquet non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

préférence

$preference = $rr->preference;
$rr->preference( $preference );

Un entier de 16 bits qui spécifie la préférence accordée à cet enregistrement parmi d'autres au même propriétaire. Les valeurs inférieures sont préférées.

map822

$map822 = $rr->map822;
$rr->map822( $map822 );

Un élément de nom de domaine contenant <rfc822-domain>, la partie RFC822 du MIXER Conformant Global Address Mapping.

mapx400

$mapx400 = $rr->mapx400;
$rr->mapx400( $mapx400 );

Un élément <domain-name> contenant la valeur de <x400-in-domain-syntax> dérivée de la partie X.400 du MIXER Conformant Global Address Mapping.
