NAME

Net::DNS::Header — En-tête d'un paquet DNS

SYNOPSIS

use Net::DNS;
$packet = Net::DNS::Packet->new();
$header = $packet->header;

DESCRIPTION

« Net::DNS::Header » représente la partie en-tête d'un paquet DNS.

MÉTHODES

$packet->header

$packet = Net::DNS::Packet->new();
$header = $packet->header;

Les objets Net::DNS::Header sont retournés par la méthode header() de Net::DNS::Packet, et contiennent un pointeur opaque vers l'objet Packet parent.

Les objets d'en-tête peuvent être assignés à des variables locales appropriées. Ils ne devraient jamais être stockés dans des variables globales ou des structures de données persistantes.

string

print $packet->header->string;

Retourne une représentation sous forme de chaîne de l'en-tête du paquet.

print

$packet->header->print;

Affiche la représentation sous forme de chaîne de l'en-tête du paquet.

id

print "query id = ", $packet->header->id, "\n";
$packet->header->id(1234);

Obtient ou définit le numéro d'identification de la requête.

opcode

print "query opcode = ", $packet->header->opcode, "\n";
$packet->header->opcode("UPDATE");

Obtient ou définit l'opcode de la requête (le but de la requête).

rcode

print "query response code = ", $packet->header->rcode, "\n";
$packet->header->rcode("SERVFAIL");

Obtient ou définit le code de réponse de la requête (le statut de la requête).

qr

print "query response flag = ", $packet->header->qr, "\n";
$packet->header->qr(0);

Obtient ou définit le drapeau de réponse de la requête.

aa

print "response is ", $packet->header->aa ? "authoritative" : "non-authoritative", "\n";
$packet->header->aa(0);

Obtient ou définit le drapeau de réponse faisant autorité.

tc

print "packet is ", $packet->header->tc ? "truncated" : "not truncated", "\n";
$packet->header->tc(0);

Obtient ou définit le drapeau de paquet tronqué.

rd

print "recursion was ", $packet->header->rd ? "desired" : "not desired", "\n";
$packet->header->rd(0);

Obtient ou définit le drapeau de récursion demandée.

ra

print "recursion is ", $packet->header->ra ? "available" : "not available", "\n";
$packet->header->ra(0);

Obtient ou définit le drapeau de récursion disponible.

z

Bits non assignés, doit toujours être 0.

ad

print "The response has ", $packet->header->ad ? "been verified" : "not been verified", "\n";
$packet->header->ad(0);

Pertinent dans le contexte de DNSSEC.

(Le bit AD est seulement mis dans une réponse où les signatures ont été vérifiées ou le serveur est faisant autorité pour les données et est autorisé à mettre le bit selon la politique.)

cd

print "checking was ", $packet->header->cd ? "not desired" : "desired", "\n";
$packet->header->cd(0);

Obtient ou définit le drapeau checking disabled.

qdcount, zocount

print "Nombre d'enregistrements de requête : ", $packet->header->qdcount, "\n";

Retourne le nombre d'enregistrements dans la section de requête du paquet. Dans les paquets de mise à jour dynamique, ce champ est connu sous le nom de zocount et fait référence au nombre de RR dans la section de zone.

ancount, prcount

print "Nombre d'enregistrements de réponse : ", $packet->header->ancount, "\n";

Retourne le nombre d'enregistrements dans la section de réponse du paquet, ce qui peut différer du nombre réel dans les paquets corrompus. Dans les paquets de mise à jour dynamique, ce champ est connu sous le nom de prcount et fait référence au nombre de RR dans la section de requête.

nscount, upcount

print "Nombre d'enregistrements d'autorité : ", $packet->header->nscount, "\n";

Retourne le nombre d'enregistrements dans la section d'autorité du paquet, ce qui peut différer du nombre réel dans les paquets corrompus. Dans les paquets de mise à jour dynamique, ce champ est connu sous le nom de upcount et fait référence au nombre de RR dans la section de mise à jour.

arcount, adcount

print "Nombre d'enregistrements supplémentaires : ", $packet->header->arcount, "\n";

Retourne le nombre d'enregistrements dans la section des enregistrements supplémentaires du paquet, ce qui peut différer du nombre réel dans les paquets corrompus. Dans les paquets de mise à jour dynamique, ce champ est connu sous le nom de adcount.

Extensions du protocole EDNS

do, co

print "DNSSEC_OK flag was ", $packet->header->do ? "not set" : "set", "\n";
$packet->header->do(1);

Obtient ou définit le drapeau EDNS.

Codes de réponse EDNS

Les codes de réponse EDNS sont gérés de manière transparente par $packet->header->rcode().

Taille du paquet UDP

$udp_max = $packet->edns->UDPsize;

EDNS fournit un mécanisme pour annoncer la taille maximale de paquet UDP qui peut être construite par la pile réseau locale.

edns

$header  = $packet->header;
$version = $header->edns->version;
@options = $header->edns->options;
$option  = $header->edns->option(n);
$udp_max = $packet->edns->UDPsize;

Fonction utilitaire qui donne accès à l'extension EDNS du RR OPT.
