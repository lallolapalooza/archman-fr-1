NOM

Net::Netrc - Interface orientée objet au fichier netrc de l'utilisateur

SYNOPSIS

use Net::Netrc;
$mach = Net::Netrc->lookup('une.machine');
$login = $mach->login;
($login, $password, $account) = $mach->lpa;

DESCRIPTION

"Net::Netrc" est une classe implémentant une interface simple au fichier .netrc utilisé par le programme ftp.

"Net::Netrc" implémente également des contrôles de sécurité, comme le programme ftp. Ces contrôles sont : premièrement, le fichier .netrc doit appartenir à l'utilisateur, et deuxièmement, les permissions de propriété doivent être telles que seul le propriétaire ait accès en lecture et en écriture. Si ces conditions ne sont pas remplies, un avertissement est affiché et le fichier .netrc n'est pas lu.

Le fichier .netrc

Le fichier .netrc contient des informations de connexion et d'initialisation utilisées par le processus d'auto-connexion. Il réside dans le répertoire personnel de l'utilisateur. Les jetons suivants sont reconnus ; ils peuvent être séparés par des espaces, des tabulations ou des retours à la ligne :

machine nom
Identifie le nom d'une machine distante. Le processus d'auto-connexion recherche dans le fichier .netrc un jeton de machine qui correspond à la machine distante spécifiée. Une fois qu'une correspondance est établie, les jetons .netrc suivants sont traités, s'arrêtant à la fin du fichier ou lorsqu'un autre jeton de machine ou un jeton par défaut est rencontré.
default
C'est la même chose que le nom de machine, sauf que default correspond à n'importe quel nom. Il ne peut y avoir qu'un seul jeton default, et il doit être après tous les jetons machine. Ceci est normalement utilisé comme suit : 
default login anonymous password user@site

ce qui donne à l'utilisateur une connexion anonyme automatique aux machines non spécifiées dans .netrc.

login nom
Identifie un utilisateur sur la machine distante. Si ce jeton est présent, le processus d'auto-connexion initiera une connexion en utilisant le nom spécifié.
password chaîne
Fournit un mot de passe. Si ce jeton est présent, le processus d'auto-connexion fournira la chaîne spécifiée si le serveur distant exige un mot de passe dans le cadre du processus de connexion.
account chaîne
Fournit un mot de passe de compte supplémentaire. Si ce jeton est présent, le processus d'auto-connexion fournira la chaîne spécifiée si le serveur distant exige un mot de passe de compte supplémentaire.
macdef nom
Définit une macro. "Net::Netrc" analyse uniquement ce champ pour être compatible avec ftp.

Méthodes de classe

Le constructeur d'un objet "Net::Netrc" n'est pas appelé new car il ne crée pas réellement un nouvel objet. Mais il est appelé "lookup" car c'est essentiellement ce qu'il fait.

"lookup($machine[, $login])"
Recherche et renvoie une référence à l'entrée pour $machine. Si $login est donné, alors l'entrée renvoyée aura le login donné. Si $login n'est pas donné, alors la première entrée du fichier .netrc pour $machine sera renvoyée.

Si une entrée correspondante ne peut pas être trouvée et qu'une entrée par défaut existe, alors une référence à l'entrée par défaut est renvoyée.

S'il n'y a pas d'entrée correspondante trouvée et qu'il n'y a pas de défaut défini, ou si aucun fichier .netrc n'est trouvé, alors "undef" est renvoyé.

Méthodes d'objet

login()
Renvoie l'identifiant de connexion pour l'entrée netrc
password()
Renvoie le mot de passe pour l'entrée netrc
account()
Renvoie les informations de compte pour l'entrée netrc
lpa()
Renvoie une liste d'informations de connexion, de mot de passe et de compte pour l'entrée netrc
