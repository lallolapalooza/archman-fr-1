NOM

Net::XMPP::Connection - Module de connexion XMPP

SYNOPIS

Net::XMPP::Connection est un paquet privé qui sert de base à tout ce qui
souhaite ouvrir une connexion socket vers un serveur.

DESCRIPTION

Ce module n'est pas destiné à être utilisé directement. Vous devriez utiliser
soit Net::XMPP::Client, soit un autre paquet qui hérite de
Net::XMPP::Connection.
