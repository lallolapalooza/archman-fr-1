NOM

Net::LDAP::Intermediate - Classe de base des objets de réponse intermédiaire LDAPv3

SYNTAXE

use Net::LDAP::Intermediate;

DESCRIPTION

"Net::LDAP::Intermediate" est une classe de base pour les objets de réponse intermédiaire LDAPv3.

CONSTRUCTEURS

new ( ARGUMENTS )
ARGUMENTS est une liste de paires nom/valeur, les arguments valides sont :
responseName
Une représentation décimale pointée d'un IDENTIFIANT D'OBJET qui identifie de manière unique la réponse intermédiaire. Cela évite les conflits entre les noms de réponse intermédiaires.
responseValue
Informations optionnelles associées à la réponse intermédiaire. Son format est spécifique à la réponse intermédiaire particulière.
from_asn ( ASN )
ASN est une référence HASH, normalement extraite d'un PDU. Elle contiendra un élément "responseName" et optionnellement un élément "responseValue". Au retour, ASN sera « blessé » dans un paquet. Si "responseName" est un OID enregistré, alors ASN sera « blessé » dans le paquet enregistré, sinon ASN sera « blessé » dans Net::LDAP::Intermediate.

Ce constructeur est utilisé en interne par Net::LDAP et suppose que la HASH passée contient une réponse intermédiaire valide. Il doit être utilisé avec prudence.

MÉTHODES

En plus des méthodes listées ci-dessous, chacun des paramètres nommés de "new" est également disponible sous forme de méthode. "responseName" retournera l'OID de l'objet de réponse intermédiaire. "responseValue" sont des méthodes de définition/obtention et retourneront la valeur actuelle pour chaque attribut si appelées sans arguments, mais peuvent également être appelées avec des arguments pour définir de nouvelles valeurs.

error ()
S'il y a eu une erreur, renvoie une description de l'erreur, sinon renvoie "undef"
init ()
"init" sera appelé comme dernière étape dans les deux constructeurs. Ce qu'il fait dépendra de la sous-classe. Il doit toujours renvoyer l'objet.
register ( OID )
"register" est fourni pour les implémenteurs de sous-classes. Il doit être appelé comme méthode de classe sur une sous-classe de Net::LDAP::Intermediate avec l'OID que la classe gérera. Net::LDAP::Intermediate se souviendra de cette paire classe et OID et l'utilisera dans les situations suivantes.
  • "new" est appelé comme méthode de classe sur le paquet Net::LDAP::Intermediate et l'OID est passé comme responseName. L'objet retourné sera « blessé » dans le paquet qui a enregistré l' OID.
  • "new" est appelé comme méthode de classe sur un paquet enregistré et le "responseName" n'est pas spécifié. Le "responseName" sera défini sur l'OID enregistré par ce paquet.
  • "from_asn" est appelé pour construire un objet à partir d'ASN. L'objet retourné sera « blessé » dans le paquet qui a été enregistré pour gérer l'OID dans l'ASN.
( to_asn )
Retourne une structure appropriée pour être passée à Convert::ASN1 pour l'encodage. Cette méthode sera appelée par Net::LDAP lorsque la réponse intermédiaire sera utilisée.

L'implémentation de base de cette méthode appellera la méthode "responseValue" sans arguments pour permettre à une sous-classe d'encoder sa valeur. Les sous-classes ne devraient pas avoir besoin de remplacer cette méthode.

valid ()
Retourne vrai si l'objet est valide et peut être encodé. L'implémentation par défaut de cette méthode est de retourner VRAI s'il n'y a pas d'erreur, mais les sous-classes peuvent la remplacer.
