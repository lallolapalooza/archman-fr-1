NOM

Net::LDAP::Control::DontUseCopy - Objet de contrôle LDAPv3 Don't Use Copy

SYNOPSIS

use Net::LDAP;
use Net::LDAP::Control::DontUseCopy;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$nocopy = Net::LDAP::Control::DontUseCopy->new( critical => 1 );
$msg = $ldap->search( base => 'o=University of Michigan,c=US',
                      filter => '(cn=Barbara Jensen)'
                      control  => [ $nocopy ] );
die "erreur: ",$msg->code(),": ",$msg->error()  if ($msg->code());

DESCRIPTION

"Net::LDAP::Control::DontUseCopy" fournit une interface pour la création et la manipulation d'objets représentant le contrôle "DontUseCopy" tel que décrit par la RFC 6171.

Il permet au client de spécifier que les informations copiées ne doivent pas être utilisées pour fournir le service.

Le contrôle est approprié pour les opérations de recherche et de comparaison LDAP [RFC4511] et inapproprié pour toutes les autres opérations.

Sa criticité doit être VRAI ; il n'a pas de valeur.

Il n'y a pas de contrôle de réponse correspondant.

ARGUMENTS DU CONSTRUCTEUR

Comme le contrôle "DontUseCopy" n'a pas de valeurs, seuls les arguments du constructeur décrits dans Net::LDAP::Control sont pris en charge.

METHODES

Comme il n'y a pas de valeurs supplémentaires dans le contrôle, seules les méthodes de Net::LDAP::Control sont disponibles pour les objets "Net::LDAP::Control::DontUseCopy".

VOIR AUSSI
