NOM

Net::DNS::RR::RRSIG - enregistrement de ressource RRSIG DNS

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new('name RRSIG typecovered algorithm labels
                        orgttl sigexpiration siginception
                        keytag signame signature');
use Net::DNS::SEC;
$sigrr = Net::DNS::RR::RRSIG->create(
                        \@rrset, $keypath,
                        sigex => 20241230010101,
                        sigin => 20241201010101
                        );
$sigrr->verify( \@rrset, $keyrr ) || die $sigrr->vrfyerrstr;

DESCRIPTION

Classe pour les enregistrements de ressource de signature numérique DNS (RRSIG).

En plus des méthodes régulières héritées de Net::DNS::RR, la classe contient une méthode pour signer des RRsets en utilisant des clés privées (create) et une méthode pour vérifier les signatures sur les RRsets (verify).

L'enregistrement RRSIG est une implémentation de la RFC4034. Voir Net::DNS::RR::SIG pour une implémentation de SIG0 (RFC2931).

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités de paquet non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner une terminaison de programme ou d'autres comportements imprévisibles.

typecovered

$typecovered = $rr->typecovered;

Le champ typecovered identifie le type du RRset couvert par cet enregistrement RRSIG.

algorithm

$algorithm = $rr->algorithm;

Le champ du numéro d'algorithme identifie l'algorithme cryptographique utilisé pour créer la signature.

algorithm() peut également être appelée en tant que méthode de classe ou fonction simple pour effectuer la traduction des codes mnémotechniques et numériques.

labels

$labels = $rr->labels;
$rr->labels( $labels );

Le champ labels spécifie le nombre d'étiquettes dans le nom du propriétaire de l'enregistrement RRSIG d'origine.

orgttl

$orgttl = $rr->orgttl;
$rr->orgttl( $orgttl );

Le champ TTL d'origine spécifie le TTL du RRset couvert tel qu'il apparaît dans la zone faisant autorité.

sigexpiration et siginception times

sigex sigin sigval

$expiration = $rr->sigexpiration;
$expiration = $rr->sigexpiration( $value );
$inception = $rr->siginception;
$inception = $rr->siginception( $value );

Les champs signature expiration et inception spécifient un intervalle de temps de validité pour la signature.

La valeur peut être spécifiée par une chaîne de caractères au format 'aaaammjjhhmmss' ou par une valeur time() de Perl.

Les valeurs de retour sont à double valeur, fournissant soit une valeur chaîne, soit une valeur numérique time() de Perl.

keytag

$keytag = $rr->keytag;
$rr->keytag( $keytag );

Le champ keytag contient la valeur de l'étiquette de clé de l'enregistrement DNSKEY qui valide cette signature.

signame

$signame = $rr->signame;
$rr->signame( $signame );

La valeur du champ signer name identifie le nom du propriétaire de l'enregistrement DNSKEY que le validateur est censé utiliser pour valider cette signature.

signature

sig

$sig = $rr->sig;
$rr->sig( $sig );

Le champ Signature contient la signature cryptographique qui couvre les RDATA RRSIG (à l'exclusion du champ Signature) et le RRset spécifié par le nom du propriétaire RRSIG, la classe RRSIG et les champs de type couvert RRSIG.

sigbin

$sigbin = $rr->sigbin;
$rr->sigbin( $sigbin );

Représentation binaire de la signature cryptographique.

create

Crée une signature sur un ensemble de RR.

use Net::DNS::SEC;
$keypath = '/home/olaf/keys/Kbla.foo.+001+60114.private';
$sigrr = Net::DNS::RR::RRSIG->create( \@rrsetref, $keypath );
$sigrr = Net::DNS::RR::RRSIG->create(
                        \@rrsetref, $keypath,
                        sigex => 20241230010101,
                        sigin => 20241201010101
                        );
$sigrr->print;
# Alternativement utiliser Net::DNS::SEC::Private
$private = Net::DNS::SEC::Private->new($keypath);
$sigrr= Net::DNS::RR::RRSIG->create( \@rrsetref, $private );

create() est un constructeur alternatif pour un objet RR RRSIG.

Cette méthode renvoie un RRSIG avec la signature sur le rrset sujet (un tableau de RRs) créée avec la clé privée stockée dans le fichier de clé.

Le premier argument est une référence à un tableau qui contient le rrset à signer.

Le second argument est une chaîne de caractères qui spécifie le chemin d'accès à un fichier contenant la clé privée telle que générée par dnssec-keygen.

Les arguments restants optionnels sont constitués de paires ( nom => valeur ) comme suit :

sigex   => 20241230010101,      # expiration de la signature
sigin   => 20241201010101,      # inception de la signature
sigval  => 30,                  # fenêtre de validité (jours)
ttl     => 3600

Les valeurs sigin et sigex peuvent être spécifiées comme valeurs de temps Perl ou comme une chaîne de caractères au format 'aaaammjjhhmmss'. La valeur par défaut pour sigin est l'heure de la signature.

L'argument sigval spécifie la fenêtre de validité de la signature en jours ( sigex = sigin + sigval ).

Par défaut, la signature est valide pendant 30 jours.

Par défaut, le TTL correspond au rrset qui est présenté pour signature.

verify

$verify = $sigrr->verify( $rrsetref, $keyrr );
$verify = $sigrr->verify( $rrsetref, [$keyrr, $keyrr2, $keyrr3] );

$rrsetref contient une référence à un tableau d'objets RR et la méthode vérifie le rrset par rapport à la signature contenue dans l'objet $sigrr lui-même en utilisant la clé publique dans $keyrr.

Le second argument peut être soit un objet Net::DNS::RR::KEYRR, soit une référence à un tableau de tels objets. La vérification réussira dès que l'une des clés du tableau mènera à une validation positive.

Renvoie 0 en cas d'erreur et définit $sig->vrfyerrstr

vrfyerrstr

$verify = $sigrr->verify( $rrsetref, $keyrr );
print $sigrr->vrfyerrstr unless $verify;
$sigrr->verify( $rrsetref, $keyrr ) || die $sigrr->vrfyerrstr;

GÉNÉRATION DE CLÉS

Les fichiers de clés privées et les enregistrements DNSKEY publics correspondants sont plus commodément générés en utilisant dnssec-keygen, un programme qui fait partie de la distribution ISC BIND.

dnssec-keygen -a 10 -b 2048 rsa.example.
dnssec-keygen -a 13 -f ksk ecdsa.example.
dnssec-keygen -a 13        ecdsa.example.

Ne modifiez pas le nom du fichier de clé privée. La méthode create utilise le nom de fichier tel que généré par dnssec-keygen pour déterminer le propriétaire de la clé, l'algorithme et l'identifiant de clé (keytag).

REMARQUES

Le code n'est pas optimisé pour la vitesse. Il n'est probablement pas adapté à une utilisation pour la signature de grandes zones.

Si ce code est toujours présent en 2100 (une année non bissextile), vous devrez vérifier la gestion correcte des heures après le 28 février.
