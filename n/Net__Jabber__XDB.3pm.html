NAME

Net::Jabber::XDB - Bibliothèque Jabber XDB

SYNOPSIS

Net::Jabber::XDB est un compagnon du module Net::Jabber. Il permet aux utilisateurs une interface simple pour définir et récupérer toutes les parties d'un XDB Jabber.

DESCRIPTION

Net::Jabber::XDB diffère des autres modules Net::Jabber::* en ce que l'espace de noms des données est divisé en plus de sous-modules sous XDB. Pour spécifier chaque module, voir la documentation de chaque module Net::Jabber::Data:*. Pour voir la liste des espaces de noms et modules disponibles, voir Net::Jabber::Data. Pour initialiser le XDB avec un xdb Jabber, vous devez lui passer le tableau d'arbre XML::Parser. Par exemple :

my $xdb = new Net::Jabber::XDB(@tree);

Il y a un changement dans l'ancienne façon de gérer les callbacks. Vous n'avez plus à faire ce qui précède, un objet Net::Jabber::XDB est passé à la fonction de rappel pour le xdb :

use Net::Jabber qw(Component);
sub xdb {
    my ($XDB) = @_;
    .
    .
    .
}

Maintenant, vous avez accès à toutes les fonctions de récupération disponibles. Pour créer un nouveau xdb à envoyer au serveur :

use Net::Jabber;
$XDB = new Net::Jabber::XDB();
$XDBType = $XDB->NewData( type );
$XDBType->SetXXXXX("yyyyy");

Vous pouvez maintenant appeler les fonctions de création pour le XDB, et pour les données sur le nouvel objet Data lui-même. Voir ci-dessous pour les fonctions xdb, et dans chaque module de données pour ces fonctions.

Pour plus d'informations sur le format de tableau passé à la fonction de rappel, veuillez lire la documentation de Net::Jabber::Client.

MÉTHODES

Fonctions de récupération

GetTo()      - renvoie une chaîne avec l'identifiant Jabber, ou un objet Net::Jabber::JID pour la personne à qui est destiné le xdb. Pour obtenir l'objet JID, définissez la chaîne sur « jid », sinon, laissez vide pour la chaîne de texte.
GetTo("jid")   - renvoie une chaîne avec l'identifiant Jabber, ou un objet Net::Jabber::JID pour la personne qui envoie le xdb. Pour obtenir l'objet JID, définissez la chaîne sur « jid », sinon, laissez vide pour la chaîne de texte.
GetType() - renvoie une chaîne avec le type de xdb. $type = $XDB->GetType();
GetID() - renvoie un entier avec l'identifiant du xdb. $id = $XDB->GetID();
GetAction() - renvoie une chaîne avec l'action du xdb. $action = $XDB->GetAction();
GetMatch() - renvoie une chaîne avec le critère de correspondance du xdb. $match = $XDB->GetMatch();
GetError() - renvoie une chaîne avec la description de l'erreur. $error = $XDB->GetError();
GetErrorCode() - renvoie une chaîne avec le code d'erreur. $errorCode = $XDB->GetErrorCode();
GetData() - renvoie un objet Net::Jabber::Data contenant les données dans le data du xdb. $dataTag = $XDB->GetData();
GetDataXMLNS() - renvoie une chaîne avec l'espace de noms des données pour ce xdb, s'il existe. $xmlns = $XDB->GetDataXMLNS();

Fonctions de création

SetXDB(to=>string|JID,    - définit plusieurs champs dans le xdb en une seule fois. C'est une action cumulative et écrasante. Si vous définissez l'attribut « to » deux fois, le second réglage sera utilisé. Si vous définissez l'état et le critère de correspondance, puis que vous définissez la priorité, les deux seront inclus dans le xdb avec le code d'erreur. Pour définir des valeurs valides, lisez les fonctions Set spécifiques ci-dessous.
SetXDB(type=>"get",
         to=>"bob@jabber.org",
         data=>"info");
SetXDB(to=>"bob@jabber.org",
        errorcode=>403,
        error=>"Permission Denied");
SetTo(string) - définit l'attribut to. Vous pouvez passer une chaîne ou un objet JID. Ce doivent être des identifiants Jabber valides, sinon le serveur renverra un message d'erreur. (ex. jabber:bob@jabber.org, etc...)
$XDB->SetTo("bob@jabber.org");
SetFrom(string) - définit l'attribut from. Vous pouvez passer une chaîne ou un objet JID. Ce doivent être des identifiants Jabber valides, sinon le serveur renverra un message d'erreur. (ex. jabber:bob@jabber.org, etc...)
$XDB->SetFrom("me@jabber.org");
SetType(string) - définit l'attribut type. Les réglages valides sont :
get      demande d'informations
set      définition d'informations
result   résultats d'une demande
error    une erreur s'est produite
$XDB->SetType("set");
SetAction(string) - définit le code d'erreur du xdb.
$XDB->SetAction("foo");
SetMatch(string) - définit le code d'erreur du xdb.
$XDB->SetMatch("foo");
SetErrorCode(string) - définit le code d'erreur du xdb.
$XDB->SetErrorCode(403);
SetError(string) - définit la chaîne d'erreur du xdb.
$XDB->SetError("Permission Denied");
NewData(string) - crée un objet Net::Jabber::Data avec l'espace de noms dans la chaîne. Pour que cette fonction fonctionne avec un espace de noms personnalisé, vous devez définir et enregistrer cet espace de noms avec le module XDB. Pour plus d'informations, lisez la documentation de Net::Jabber::Data.
$dataObj = $XDB->NewData("jabber:xdb:auth");
$dataObj = $XDB->NewData("jabber:xdb:roster");
Reply(hash) - crée un nouvel objet XDB et remplit les champs to/from. Si vous spécifiez un hachage identique à celui de SetXDB, ces valeurs écraseront les valeurs de Reply.
$xdbReply = $XDB->Reply();
$xdbReply = $XDB->Reply(type=>"result");

Fonctions de test

DefinedTo() - renvoie 1 si l'attribut to est défini dans le xdb, 0 sinon.
$test = $XDB->DefinedTo();
DefinedFrom() - renvoie 1 si l'attribut from est défini dans le xdb, 0 sinon.
$test = $XDB->DefinedFrom();
DefinedID() - renvoie 1 si l'attribut id est défini dans le xdb, 0 sinon.
$test = $XDB->DefinedID();
DefinedType() - renvoie 1 si l'attribut type est défini dans le xdb, 0 sinon.
$test = $XDB->DefinedType();
DefinedAction() - renvoie 1 si l'attribut action est défini dans le xdb, 0 sinon.
$test = $XDB->DefinedAction();
DefinedMatch() - renvoie 1 si l'attribut match est défini dans le xdb, 0 sinon.
$test = $XDB->DefinedMatch();
DefinedError() - renvoie 1 si l' erreur est définie dans le xdb, 0 sinon.
$test = $XDB->DefinedError();
DefinedErrorCode() - renvoie 1 si l'attribut code est défini dans l' erreur, 0 sinon.
$test = $XDB->DefinedErrorCode();
