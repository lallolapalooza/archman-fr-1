Net::XMPP::IQ(3pm) Documentation contribuée par Perl Net::XMPP::IQ(3pm)

Nom

Net::XMPP::IQ - Module de requête d'information XMPP

SYNTAXE

Net::XMPP::IQ est un module compagnon de Net::XMPP. Il fournit une interface simple pour configurer et récupérer toutes les parties d'une requête XMPP IQ.

DESCRIPTION

Net::XMPP::IQ diffère des autres modules Net::XMPP en ce que l'espace de noms de la requête est divisé en un sous-module sous IQ. Pour les spécifications sur chaque module, veuillez consulter la documentation du module Net::XMPP::Namespaces. Un objet Net::XMPP::IQ est passé à la fonction de rappel pour le message. De plus, le premier argument des fonctions de rappel est l'ID de session de XML::Stream. Il y a quelques cas où vous pourriez vouloir cette information, par exemple, si vous avez créé un client qui se connecte à deux serveurs simultanément, ou pour créer un mini-serveur. 

use Net::XMPP;
sub iq {
    my ($sid,$IQ) = @_;
    .
    .
    my $reply = $IQ->Reply();
    my $replyQuery->GetQuery();
    .
}
Vous avez maintenant accès à toutes les fonctions de récupération disponibles. Pour créer une nouvelle IQ à envoyer au serveur : 
use Net::XMPP;
$IQ = Net::XMPP::IQ->new();
$IQType = $IQ->NewChild( type );
$IQType->SetXXXXX("yyyyy");
Vous pouvez maintenant appeler les fonctions de création pour l'IQ, et pour le <query/> sur le nouvel objet de requête. Voir ci-dessous pour les fonctions <iq/> et sur chaque module de requête pour ces fonctions.

MÉTHODES

Fonctions générales

Reply(%args) - Crée une réponse <iq/> avec les champs 'to' et 'from' correctement renseignés, et un objet de requête déjà ajouté. Les %args que vous passez sont transmis à SetIQ() et remplacent les paramètres de l'IQ que Reply définit.

Fonctions de récupération

GetTo()      - renvoie une chaîne avec le JID, ou un objet Net::XMPP::JID pour le destinataire de <iq/>. Pour obtenir le JID, définissez la chaîne sur "jid", sinon utilisez la chaîne texte.
GetTo("jid")    Objet Net::XMPP::JID pour lequel recevoir <iq/>. Pour obtenir le JID, définissez la chaîne sur "jid", sinon utilisez la chaîne texte.
$to    = $IQ->GetTo();
$toJID = $IQ->GetTo("jid");
GetFrom()      - renvoie une chaîne avec le JID, ou un objet Net::XMPP::JID pour l'expéditeur de <iq/>. Pour obtenir le JID, définissez la chaîne sur "jid", sinon utilisez la chaîne texte.
$from    = $IQ->GetFrom();
$fromJID = $IQ->GetFrom("jid");
GetType() - renvoie une chaîne avec le type <iq/> actuel.
$type = $IQ->GetType();
GetID() - renvoie un entier avec l'ID de <iq/>.
$id = $IQ->GetID();
GetError() - renvoie une chaîne avec la description textuelle de l'erreur.
$error = $IQ->GetError();
GetErrorCode() - renvoie une chaîne avec le code de l'erreur.
$errorCode = $IQ->GetErrorCode();
GetQuery() - renvoie un objet Net::XMPP::Stanza contenant les données de la requête de <iq/>. Essentiellement, renvoie le premier enfant de <iq/>.
$query = $IQ->GetQuery();
GetQueryXMLNS() - renvoie une chaîne avec l'espace de noms de la requête pour cet <iq/>, s'il existe.
$xmlns = $IQ->GetQueryXMLNS();

Fonctions de création

SetIQ(to=>string|JID,    - définit plusieurs champs dans <iq/> en une fois. C'est une action cumulative et d'écrasement. Si vous définissez le "to" deux fois, le deuxième réglage est utilisé. Si vous définissez le statut et l'erreur, puis que vous définissez la priorité, les deux seront inclus dans <iq/>.
errorcode=>string,      - utilisé. Si vous définissez le statut et l'erreur, puis que vous définissez la priorité, les deux seront inclus dans <iq/>.
error=>string)          - définit la chaîne d'erreur de <iq/>.
$IQ->SetIQ(type=>"get",
                                      to=>"bob\@jabber.org");
                           $IQ->SetIQ(to=>"bob\@jabber.org",
                                      errorcode=>403,
                                      error=>"Permission Denied");
SetTo(string) - définit l'attribut 'to'. Vous pouvez passer une chaîne ou un objet JID. Ce doivent être des identifiants Jabber valides ou le serveur renverra un message d'erreur. (ex. bob@jabber.org, etc...)
$IQ->SetTo("bob\@jabber.org");
SetFrom(string) - définit l'attribut 'from'. Vous pouvez passer une chaîne ou un objet JID. Ce doivent être des identifiants JID valides ou le serveur renverra un message d'erreur. (ex. bob@jabber.org, etc...)
$IQ->SetFrom("me\@jabber.org");
SetType(string) - définit l'attribut 'type'. Les valeurs valides sont :
                  get      demande des informations
                  set      définit des informations
                  result   résultats d'un get
                  error    une erreur s'est produite
$IQ->SetType("set");
SetErrorCode(string) - définit le code d'erreur de <iq/>.
$IQ->SetErrorCode(403);
SetError(string) - définit la chaîne d'erreur de <iq/>.
$IQ->SetError("Permission Denied");
NewChild(string) - crée un objet Net::XMPP::Stanza avec l'espace de noms dans la chaîne. Pour que cette fonction fonctionne avec un espace de noms personnalisé, vous devez définir et enregistrer cet espace de noms avec le module IQ. Plus d'informations, veuillez lire la documentation du module Net::XMPP::Stanza.
$queryObj = $IQ->NewChild("jabber:iq:auth");
$queryObj = $IQ->NewChild("jabber:iq:roster");
Reply(hash) - crée un nouvel objet IQ et peuple les champs 'to'/'from'. Si vous spécifiez un hash égal à celui de SetIQ, ces valeurs remplacent celles de Reply.
$iqReply = $IQ->Reply();
$iqReply = $IQ->Reply(type=>"result");

Fonctions de suppression

RemoveTo() - supprime l'attribut 'to' de <iq/>.
$IQ->RemoveTo();
RemoveFrom() - supprime l'attribut 'from' de <iq/>.
$IQ->RemoveFrom();
RemoveID() - supprime l'attribut 'id' de <iq/>.
$IQ->RemoveID();
RemoveType() - supprime l'attribut 'type' de <iq/>.
$IQ->RemoveType();
RemoveError() - supprime l'<error/> de <iq/>.
$IQ->RemoveError();
RemoveErrorCode() - supprime l'attribut 'code' de <error/> dans <iq/>.
$IQ->RemoveErrorCode();

Fonctions de test

DefinedTo() - renvoie 1 si l'attribut 'to' est défini dans <iq/>, 0 sinon.
$test = $IQ->DefinedTo();
DefinedFrom() - renvoie 1 si l'attribut 'from' est défini dans <iq/>, 0 sinon.
$test = $IQ->DefinedFrom();
DefinedID() - renvoie 1 si l'attribut 'id' est défini dans <iq/>, 0 sinon.
$test = $IQ->DefinedID();
DefinedType() - renvoie 1 si l'attribut 'type' est défini dans <iq/>, 0 sinon.
$test = $IQ->DefinedType();
DefinedError() - renvoie 1 si <error/> est défini dans <iq/>, 0 sinon.
$test = $IQ->DefinedError();
DefinedErrorCode() - renvoie 1 si l'attribut 'code' est défini dans <error/>, 0 sinon.
$test = $IQ->DefinedErrorCode();
DefinedQuery() - renvoie 1 s'il y a au moins un enfant nommé dans l'objet.
