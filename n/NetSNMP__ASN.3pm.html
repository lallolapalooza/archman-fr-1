NOM

NetSNMP::ASN - Extension Perl pour les types ASN.1 SNMP

SYNTAXE

use NetSNMP::ASN qw(:all);
my $asn_int = ASN_INTEGER;

DESCRIPTION

Le module NetSNMP::ASN fournit les types ASN.1 pour SNMP.
