NOM

Net::DNS::SEC::Private - Objet de clé privée DNSSEC

SYNOPIS

use Net::DNS::SEC::Private;
$private = Net::DNS::SEC::Private->new( $keypath );
$private = Net::DNS::SEC::Private->new(
    'algorithm'  => '13',
    'keytag'     => '26512',
    'privatekey' => 'h/mc+iq9VDUbNAjQgi8S8JzlEX29IALchwJmNM3QYKk=',
    'signame'    => 'example.com.'
    );

DESCRIPTION

Classe représentant les clés privées lues à partir d'un fichier de clé généré par BIND dnssec-keygen. La classe est écrite pour être utilisée uniquement dans le contexte de la méthode create de Net::DNS::RR::RRSIG. Cette classe n'est pas conçue pour interagir avec d'autres systèmes.

MÉTHODES

new (depuis un fichier de clé privée)

$keypath = '/home/foo/Kexample.com.+013+26512.private';
$private = Net::DNS::SEC::Private->new( $keypath );

L'argument est le chemin complet vers un fichier de clé privée généré par l'outil BIND dnssec-keygen. Notez que le nom de fichier contient des informations sur l'algorithme et le keytag.

new (depuis des paramètres de clé privée)

$private = Net::DNS::SEC::Private->new(
    'algorithm'  => '13',
    'keytag'     => '26512',
    'privatekey' => 'h/mc+iq9VDUbNAjQgi8S8JzlEX29IALchwJmNM3QYKk=',
    'signame'    => 'example.com.'
    );

Les arguments définissent les paramètres de la clé privée sous forme de paires (nom, valeur). La représentation du nom et des données est identique à celle utilisée dans un fichier de clé privée BIND.

private_key_format

$format = $private->private_key_format;

Retourne une chaîne qui identifie le format du fichier de clé privée.

algorithm, keytag, signame

$algorithm = $private->algorithm;
$keytag    = $private->keytag;
$signame   = $private->signame;

Retourne l'attribut correspondant déterminé à partir du nom de fichier.

Private key attributes

$attribute = $private->attribute;

Retourne la valeur telle qu'elle apparaît dans le fichier de clé privée. Les noms d'attributs correspondent à la balise dans le fichier de clé, modifiés pour former un nom de sous-routine Perl acceptable.

created, publish, activate

$created  = $private->created;
$publish  = $private->publish;
$activate = $private->activate;

Retourne une chaîne qui représente une date sous la forme 20141212123456. Retourne une valeur indéfinie pour les formats de clé plus anciens que v1.3.
