Net::LDAP::Extra::eDirectory(3) Documentation Perl fournie par l'utilisateur Net::LDAP::Extra::eDirectory(3)

NOM

Net::LDAP::Extra::eDirectory -- extensions pour Novell eDirectory

SYNTAXE

use Net::LDAP::Extra qw(eDirectory);
$ldap = Net::LDAP->new( ... );
...
if ($ldap->is_eDirectory)
  my $mesg $ldap->list_replicas($server_dn);
  print "Réplicas sur $server_dn\n* " . join("\n* ", $mesg->replicas) . "\n"
    if (!$mesg->code);
}

DESCRIPTION

Net::LDAP::Extra::eDirectory fournit des fonctions / extensions LDAP spécifiques à Novell eDirectory.

Pour ce faire, il fournit les méthodes suivantes :

MÉTHODES

is_eDirectory ( )
Indique si le serveur LDAP interrogé est un serveur Novell eDirectory.

La vérification étant effectuée en interrogeant le DSE racine du répertoire, elle fonctionne sans être liée au répertoire.

Contrairement aux autres méthodes Net::LDAP, cette méthode renvoie TRUE / FALSE respectivement undef en cas d'erreur.

list_replicas ( SERVER_DN, OPTIONS )
Interroge les réplicas sur le serveur donné SERVER_DN.

En cas de succès, l'objet Net::LDAP::Message résultant prend en charge la méthode "replicas" qui renvoie la liste des réplicas sur SERVER_DN.

get_replica_info ( SERVER_DN, REPLICA_DN, OPTIONS )
Interroge les informations de REPLICA_DN sur SERVER_DN.

En cas de succès, l'objet Net::LDAP::Message résultant prend en charge la méthode "replica_info" qui renvoie un hash contenant des informations sur REPLICA_DN.

trigger_backlinker ( OPTIONS )
Déclenche le processus BackLinker, qui résout les références externes pour s'assurer qu'elles pointent vers des entrées réelles.
trigger_janitor ( OPTIONS )
Déclenche le processus Janitor, qui vérifie la connectivité de tous les serveurs de la base de données.
trigger_limber ( OPTIONS )
Déclenche le processus Limber, qui vérifie le nom du serveur, l'adresse ipx interne et la connectivité de l'arbre de toutes les réplicas.
trigger_skulker ( OPTIONS )
Déclenche le processus Skulker, qui vérifie l'état de synchronisation de chaque serveur de l'anneau de réplication.
trigger_schemasync ( OPTIONS )
Déclenche SchemaSync.
trigger_partitionpurge ( OPTIONS )
Déclenche PartitionPurge.
refresh_ldap_server ( OPTIONS )
Déclenche le rafraîchissement du service NLDAP.
