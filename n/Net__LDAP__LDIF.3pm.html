Net::LDAP::LDIF(3) Documentation Perl fournie par l'utilisateur Net::LDAP::LDIF(3)

NOM

Net::LDAP::LDIF - Lecture et écriture LDIF

SYNOPSIS

use Net::LDAP::LDIF;
$ldif = Net::LDAP::LDIF->new( "fichier.ldif", "r", onerror => 'undef' );
while ( not $ldif->eof ( ) ) {
  $entry = $ldif->read_entry ( );
  if ( $ldif->error ( ) ) {
    print "Message d'erreur : ", $ldif->error ( ), "\n";
    print "Lignes d'erreur :\n", $ldif->error_lines ( ), "\n";
  } else {
    # faire quelque chose
  }
}
$ldif->done ( );

DESCRIPTION

Net::LDAP::LDIF fournit un moyen de convertir entre les objets Net::LDAP::Entry et les entrées LDAP représentées dans les fichiers au format LDIF. La lecture et l'écriture sont supportées et peuvent manipuler des entrées uniques ou des listes d'entrées.

Comme lors de la lecture d'un fichier entier en mémoire avec Perl normalement, prenez en compte la possibilité d'utilisation de la mémoire lors du chargement d'un fichier LDIF d'un seul coup.

FONCTIONNALITÉS SPÉCIALES

Par défaut, Net::LDAP::LDIF prend en charge la lecture des valeurs d'attributs à partir d'URL de type "file://".

Lorsque le package du module LWP de Gisle Aas est installé, Net::LDAP::LDIF l'utilise pour prendre également en charge la lecture des données à partir des types d'URL pris en charge par ces modules ; notamment les ressources "http://", "https://" et "ftp://". Cette fonctionnalité étendue est détectée dynamiquement à l'exécution.

CONSTRUCTEUR

new ( FICHIER [[, MODE ], OPTIONS ] )
Ouvre le fichier avec le mode donné.

"FICHIER" peut être le nom d'un fichier ou d'un descripteur de fichier déjà ouvert. Si "FICHIER" commence ou se termine par "|", alors "FICHIER" sera passé directement à "open".

"MODE" peut être l'un des modes autorisés par la fonction open() de Perl, potentiellement étendu par des couches PerlIO comme décrit dans perlopentut. Alternativement, il peut s'agir de l'un des indicateurs de mode "r", "r+", "w", "w+", "a", "a+" connus de la fonction fopen() de C, qui sont mappés à leurs équivalents Perl. Si "MODE" est omis, il est par défaut "r" pour la lecture.

"OPTIONS" est une liste de paires nom/valeur, reconnaissant :

encode => 'none' | 'canonical' | 'base64'
Certaines valeurs de DN dans LDIF ne peuvent pas être écrites telles quelles et doivent être encodées d'une manière ou d'une autre :
'none'
Par défaut.
'canonical'
Voir "canonical_dn" dans Net::LDAP::Util.
'base64'
Utilise base64.
onerror => 'die' | 'warn' | 'undef'
Spécifie ce qui se passe lorsqu'une erreur est détectée.
'die'
"Net::LDAP::LDIF" provoquera un croak avec un message approprié.
'warn'
"Net::LDAP::LDIF" affichera un avertissement avec un message approprié.
'undef'
"Net::LDAP::LDIF" affichera un avertissement avec un message approprié si "-w" est actif. La méthode appelée retournera "undef".

Notez que cette valeur est la chaîne 'undef', et non la valeur "undef".

change => 1
Écrit les modifications d'entrée dans le fichier LDIF au lieu des entrées elles-mêmes. C'est-à-dire qu'il écrit les opérations LDAP agissant sur les entrées dans le fichier au lieu du contenu des entrées.
lowercase => 1
Convertit les noms d'attributs en minuscules lors de l'écriture.
sort => 1
Trie les noms d'attributs lors de l'écriture des entrées selon la règle : objetclass d'abord, puis tous les autres attributs triés par ordre alphabétique
version => '1'
Définit la version LDIF à écrire dans le fichier LDIF résultant.

Selon RFC 2849, la seule valeur légale pour cette option est actuellement 1.

Lorsque cette option est définie, Net::LDAP::LDIF essaie de respecter plus strictement la spécification LDIF dans RFC2489 à quelques endroits.

La valeur par défaut est undef, ce qui signifie qu'aucune information de version n'est écrite dans le fichier LDIF.

wrap => 78
Nombre de colonnes où le retour à la ligne doit se produire.

La valeur par défaut est 78. La définir à 40 ou moins désactive le retour à la ligne.

raw => REGEX
Utilise REGEX pour désigner les noms des attributs qui doivent être considérés comme binaires lors de la lecture.

Lorsque cette option est donnée, Net::LDAP convertit toutes les valeurs des attributs ne correspondant pas à cette REGEX en chaînes UTF-8 Perl afin que les opérateurs Perl réguliers (correspondance de motifs, ...) puissent fonctionner comme prévu, même sur des chaînes avec des caractères internationaux.

Si cette option n'est pas donnée, les valeurs d'attributs sont traitées comme des chaînes d'octets.

Exemple : raw => qr/(?i:^jpegPhoto|;binary)/

MÉTHODES

read_entry ( )
Lit une entrée du fichier et la retourne sous forme d'objet "Net::LDAP::Entry".

En mode scalaire, l'objet "Net::LDAP::Entry" est retourné seul, tandis qu'en mode liste, une liste est retournée comprenant l'objet "Net::LDAP::Entry" comme premier élément, suivi de tous les objets "Net::LDAP::Control" qui faisaient partie de l'entrée LDIF. Voir RFC 2849 pour plus de détails.

eof ( )
Retourne vrai lorsque la fin du fichier est atteinte.
write_entry ( ENTRY [, OPTIONS ], ... )
Écrit des entrées dans le fichier LDIF.

Les arguments acceptés sont une liste d'entrées, éventuellement entrecoupées d'options appartenant à l'entrée précédente.

Pour chaque entrée, "OPTIONS" est une liste de paires clé-valeur, reconnaissant :

control => CONTROL
control => [ CONTROL, ... ]
Voir "CONTROLS" dans Net::LDAP.
write_version ( )
Si la version de l'objet est définie, cette méthode permet d'écrire explicitement la version avant qu'une entrée ne soit écrite.

Si elle n'est pas appelée explicitement, elle est appelée automatiquement lors de l'écriture de la première entrée.

version ( [ VERSION ] )
Si elle est appelée sans arguments, elle retourne la version du fichier LDIF ou undef si aucune version n'a été définie. Si elle est appelée avec un argument, elle définit la version LDIF à VERSION.

Selon RFC 2849, la seule valeur légale pour VERSION est actuellement 1.

handle ( )
Retourne le descripteur de fichier à partir duquel l'objet "Net::LDAP::LDIF" lit ou écrit.
done ( )
Cette méthode sig

NAME

Net::LDAP::LDIF - Manipulate LDIF files

SYNOPSIS

    use Net::LDAP;
    use Net::LDAP::LDIF;

    my $dir = Net::LDAP::LDIF->new('/path/to/file.ldif', mode => \<, onerror => \&warn);
    while (my $entry = $dir->read) {
        # ... process entry ...
    }
    $dir->done;

    my $dir = Net::LDAP::LDIF->new('/path/to/file.ldif', mode => \>);
    $dir->write($entry);
    # ...
    $dir->done;

DESCRIPTION

The Net::LDAP::LDIF module provides a means to read and write LDIF files. An LDIF file is a text-based format for representing LDAP entries and changes.

The module implements the LDIF format as described in RFC 2849.

SPECIAL FEATURES

The module can be used to read and write LDIF files.

The module can also be used to read and write LDIF data that is not contained within a file.

CONSTRUCTOR

new ( [attributes] )
Creates a new Net::LDAP::LDIF object.

The following attributes may be passed to the constructor:

file => $file
The path to the LDIF file to be read or written. If this attribute is not specified then the object will not be associated with a file.
mode => $mode
The mode in which to open the file. The default is read mode (<). See open(2) for a list of available modes.
onerror => $callback
The callback to be called when an error is encountered. The callback will be passed a Net::LDAP::LDIF object as its only argument. The default behaviour is to croak.
version => $version
The version of the LDIF standard to use. The default is version 1.

METHODS

read (
Reads the next entry from the LDIF file. Returns a "Net::LDAP::Entry" object, or undef if end of file is reached or an error occurred.
write ( $entry )
Writes the given $entry to the LDIF file.
done ( )
Closes the LDIF file. This method is called automatically via DESTROY when the object goes out of scope.
error ( )
Returns error message if error was found.
error_lines ( )
Returns lines that resulted in error.
current_entry ( )
Returns the current "Net::LDAP::Entry" object.
current_lines ( )
Returns the lines that generated the current "Net::LDAP::Entry" object.
next_lines ( )
Returns the lines that will generate the next "Net::LDAP::Entry" object.
