NOM

Net::LDAP::RFC - Liste des RFCs associées

SYNTAXE

none

DESCRIPTION

Le protocole LDAP est défini dans les RFCs suivantes

Spécification principale LDAP

RFC-4510 Lightweight Directory Access Protocol (LDAP): Technical Specification Framework

http://www.ietf.org/rfc/rfc4510.txt

Le protocole d'accès aux annuaires léger (LDAP) est un protocole Internet pour accéder aux services d'annuaires distribués qui fonctionnent selon des modèles de données et de services X.500. Ce document fournit une vue d'ensemble de la spécification technique de LDAP.

RFC-4511 Lightweight Directory Access Protocol (LDAP): The Protocol

http://www.ietf.org/rfc/rfc4511.txt

Ce document décrit les éléments du protocole, ses sémantiques et les codages des Protocoles d'Accès aux Annuaires Légers (LDAP). LDAP fournit un accès aux services d'annuaires distribués qui fonctionnent selon des modèles de données et de services X.500. Ces éléments de protocole sont basés sur ceux décrits dans le protocole d'accès aux annuaires X.500 (DAP).

RFC-4512 Lightweight Directory Access Protocol (LDAP): Directory Information Models

http://www.ietf.org/rfc/rfc4512.txt

Le protocole d'accès aux annuaires léger (LDAP) est un protocole Internet pour accéder aux services d'annuaires distribués qui fonctionnent selon des modèles de données et de services X.500. Ce document décrit les modèles d'information d'annuaire X.500, tels qu'ils sont utilisés dans LDAP.

RFC-4513 Lightweight Directory Access Protocol (LDAP): Authentication Methods and Security Mechanisms

http://www.ietf.org/rfc/rfc4513.txt

Ce document décrit les méthodes d'authentification et les mécanismes de sécurité du protocole d'accès aux annuaires léger (LDAP). Ce document détaille la configuration de la couche de sécurité de transport (TLS) en utilisant l'opération StartTLS.

Ce document détaille la méthode d'authentification simple Bind incluant les mécanismes anonyme, non authentifié et nom/mot de passe, ainsi que la méthode d'authentification SASL Bind incluant le mécanisme EXTERNAL.

Ce document discute des différents états d'authentification et d'autorisation qu'une session peut traverser vers un serveur LDAP et des actions qui déclenchent ces changements d'état.

RFC-4514 Lightweight Directory Access Protocol (LDAP): String Representation of Distinguished Names

http://www.ietf.org/rfc/rfc4514.txt

Le répertoire X.500 utilise des noms distincts (DN) comme clés primaires dans les enregistrements du répertoire. Ce document définit la représentation en chaîne de caractères utilisée dans le protocole d'accès aux annuaires léger (LDAP) pour transférer les noms distincts. La représentation en chaîne de caractères est conçue pour fournir une représentation propre des noms distincts courants, mais peut représenter tout nom distinct.

RFC-4515 Lightweight Directory Access Protocol (LDAP): String Representation of Search Filters

http://www.ietf.org/rfc/rfc4515.txt

Les filtres de recherche LDAP sont transmis sur le protocole LDAP en utilisant une représentation binaire appropriée pour une utilisation sur le réseau. Ce document définit une représentation en chaîne de caractères lisible pour les filtres de recherche LDAP, appropriée pour une utilisation dans les URL LDAP (RFC 4516) et d'autres applications.

RFC-4516 Lightweight Directory Access Protocol (LDAP): Uniform Resource Locator

http://www.ietf.org/rfc/rfc4516.txt

Ce document décrit un format pour un Localisateur de Ressources Uniforme (URL) du protocole d'accès aux annuaires léger (LDAP). Un URL LDAP décrit une opération de recherche LDAP qui est utilisée pour récupérer des informations d'un annuaire LDAP, ou, dans le contexte d'une référence LDAP, un URL LDAP décrit un service où une opération LDAP peut être poursuivie.

RFC-4517 Lightweight Directory Access Protocol (LDAP): Syntaxes and Matching Rules

http://www.ietf.org/rfc/rfc4517.txt

Chaque attribut stocké dans un annuaire LDAP, dont les valeurs peuvent être transférées via le protocole LDAP, a une syntaxe définie qui restreint la structure et le format de ses valeurs. Les sémantiques de comparaison des valeurs d'une syntaxe ne font pas partie de la définition de la syntaxe, mais sont fournies par des règles de comparaison séparées. Les règles de comparaison spécifient un argument, une valeur de comparaison, qui a également une syntaxe définie. Ce document définit une base de syntaxes et de règles de comparaison pour définir les attributs dans les annuaires LDAP.

RFC-4518 Lightweight Directory Access Protocol (LDAP): Internationalized String Preparation

http://www.ietf.org/rfc/rfc4518.txt

Les normes techniques précédentes du protocole d'accès aux annuaires léger (LDAP) ne définissaient pas précisément comment la comparaison des chaînes de caractères devait être effectuée. Cela a conduit à des problèmes d'utilisabilité et d'interopérabilité. Ce document définit des algorithmes de préparation de chaînes de caractères basés sur les règles de comparaison de chaînes de caractères définies pour une utilisation dans LDAP.

RFC-4519 Lightweight Directory Access Protocol (LDAP): Schema for User Applications

http://www.ietf.org/rfc/rfc4519.txt

Ce document fait partie intégrante de la norme technique du protocole d'accès aux annuaires léger (LDAP). Il fournit une spécification technique des types d'attributs et des classes d'objets destinés à être utilisés par les clients d'annuaires LDAP pour de nombreux services d'annuaires, tels que les annuaires d'adresses. Ces objets sont largement utilisés comme base de schéma dans de nombreux annuaires LDAP. Ce document ne couvre pas les attributs utilisés pour l'administration des serveurs d'annuaires, ni n'inclut les objets définis pour des utilisations spécifiques dans d'autres documents.

Autres RFCs liées à LDAP - Standards proposés

RFC-6171 The Lightweight Directory Access Protocol (LDAP) Don't Use Copy Control

http://www.ietf.org/rfc/rfc6171.txt

Ce document définit le contrôle d'extension "Don't Use Copy" du protocole d'accès aux annuaires léger (LDAP) qui permet à un client de spécifier que les informations copiées ne doivent pas être utilisées pour fournir des services. Cette extension est basée sur l'option de contrôle de service "don'tUseCopy" de la norme X.511.

RFC-5020 The Lightweight Directory Access Protocol (LDAP) entryDN Operational Attribute

http://www.ietf.org/rfc/rfc5020.txt

Ce document décrit l'attribut 'entryDN' du protocole d'accès aux annuaires léger (LDAP) X.500. L'attribut fournit une copie du nom distinct de l'entrée du répertoire à utiliser dans les assertions de valeurs d'attributs.

RFC-4792 Encoding Instructions for the Generic String Encoding Rules (GSER)

http://www.ietf.org/rfc/rfc4792.txt

La notation d'arbre symbolique (ASN.1) définit un cadre général pour annoter des types dans une spécification ASN.1 avec des instructions d'encodage qui modifient la manière dont les valeurs de ces types sont encodées selon les règles d'encodage ASN.1. Ce document définit la notation de prise en charge des instructions d'encodage applicables aux règles d'encodage de chaînes génériques (GSER), et en particulier définit une instruction d'encodage pour fournir une représentation traitable par machine pour la déclaration d'un type GSER ChoiceOfStrings.

RFC-4532 Lightweight Directory Access Protocol (LDAP) Who am I? Operation

http://www.ietf.org/rfc/rfc4532.txt

Cette spécification fournit un mécanisme pour le client du protocole d'accès aux annuaires léger (LDAP).

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

RFC-4530 Lightweight Directory Access Protocol (LDAP) entryUUID Operational Attribute

http://www.ietf.org/rfc/rfc4530.txt

Ce document décrit l'attribut opérationnel 'entryUUID' de LDAP/X.500 et ses règles de correspondance et de syntaxe associées. L'attribut contient un identifiant universellement unique (UUID) attribué par le serveur à l'entité de l'objet. Les clients du répertoire peuvent utiliser cet attribut pour différencier les objets identifiés par un nom d'entité ou pour localiser un objet après un renommage.

RFC-4528 Lightweight Directory Access Protocol (LDAP) Assertion Control

http://www.ietf.org/rfc/rfc4528.txt

Ce document définit la commande de contrôle d'assertion LDAP (Lightweight Directory Access Protocol), qui permet à un client de spécifier qu'une opération de répertoire ne doit être traitée que si une assertion appliquée à l'entrée cible de l'opération est vraie. Il peut être utilisé pour construire des opérations conditionnelles telles que "tester et définir", "tester et effacer" et autres.

RFC-4527 Lightweight Directory Access Protocol (LDAP) Read Entry Controls

http://www.ietf.org/rfc/rfc4527.txt

Ce document spécifie une extension du protocole d'accès aux annuaires (LDAP) pour permettre au client de lire l'entrée cible d'une opération de mise à jour. Le client peut demander à lire l'entrée avant et/ou après l'application des modifications. Ces lectures sont effectuées dans le cadre atomique de l'opération de mise à jour.

RFC-4526 Lightweight Directory Access Protocol (LDAP) Absolute True and False Filters

http://www.ietf.org/rfc/rfc4526.txt

Ce document étend le protocole d'accès aux annuaires (LDAP) pour prendre en charge les filtres booléens absolus "vrai" et "faux" basés sur des capacités similaires trouvées dans les systèmes d'annuaires X.500. Le document étend également la représentation textuelle de la chaîne de recherche LDAP pour prendre en charge ces filtres.

RFC-4524 COSINE LDAP/X.500 Schema

http://www.ietf.org/rfc/rfc4524.txt

Ce document fournit une collection d'éléments de schéma à utiliser avec le protocole d'accès aux annuaires (LDAP) du projet COSINE et le projet pilote Internet X.500.

RFC-4523 Lightweight Directory Access Protocol (LDAP) Schema Definitions for X.509 Certificates

http://www.ietf.org/rfc/rfc4523.txt

Ce document décrit le schéma pour représenter les certificats X.509, les informations de sécurité X.521 et les éléments associés dans les annuaires accessibles via le protocole d'accès aux annuaires (LDAP). Les définitions de schéma pour ces éléments X.509 et X.521 sont remplacées par les définitions fournies dans les RFC 2252 et 2256.

RFC-4522 Lightweight Directory Access Protocol (LDAP): The Binary Encoding Option

http://www.ietf.org/rfc/rfc4522.txt

Chaque attribut stocké dans un annuaire d'accès aux annuaires (LDAP) a une syntaxe définie (c'est-à-dire un type de données). Une définition de syntaxe spécifie comment les valeurs d'attribut conformes à la syntaxe sont normalement représentées lorsqu'elles sont transférées dans les opérations LDAP. Cette représentation est appelée l'encodage LDAP spécifique pour la distinguer d'autres méthodes d'encodage des valeurs d'attribut. Ce document définit une option d'attribut, l'option binaire, qui peut être utilisée pour spécifier que les valeurs associées doivent être encodées selon les règles d'encodage de base (BER) utilisées dans les annuaires X.500.

RFC-4370 Lightweight Directory Access Protocol (LDAP) Proxied Authorization Control

http://www.ietf.org/rfc/rfc4370.txt

Ce document définit la commande de contrôle d'autorisation proxy LDAP (Lightweight Directory Access Protocol). La commande de contrôle d'autorisation proxy permet à un client de demander qu'une opération soit traitée sous une identité d'autorisation fournie au lieu de l'identité d'autorisation actuelle associée à la connexion.

RFC-4104 Policy Core Extension Lightweight Directory Access Protocol Schema (PCELS)

http://www.ietf.org/rfc/rfc4104.txt

Ce document définit plusieurs modifications et extensions du schéma de protocole d'accès aux annuaires (LDAP) du protocole d'informations du noyau de politique (RFC 3703) basées sur les extensions définies par le modèle d'informations du noyau de politique (PCIM) (RFC 3460). Ces modifications et extensions consistent en de nouvelles classes d'objets et types d'attributs LDAP. Certains des éléments de schéma définis dans ce document réimplémentent des concepts existants selon leur nouvelle sémantique introduite par le RFC 3460. Les autres éléments de schéma implémentent de nouveaux concepts non couverts par le RFC 3703. Ce document met à jour le RFC 3703.

RFC-3928 Lightweight Directory Access Protocol (LDAP) Client Update Protocol (LCUP)

http://www.ietf.org/rfc/rfc3928.txt

Ce document définit le protocole de mise à jour client LDAP (LCUP). Le protocole est destiné à permettre à un client LDAP de se synchroniser avec le contenu d'un arbre d'annuaire (DIT) stocké dans un serveur LDAP et d'être informé des modifications apportées à ce contenu.

RFC-3909 Lightweight Directory Access Protocol (LDAP) Cancel Operation

http://www.ietf.org/rfc/rfc3909.txt

Ce document décrit une opération d'annulation (ou abandon) d'une opération en attente dans le protocole d'accès aux annuaires (LDAP) en tant qu'extension. Bien que différente de l'opération d'abandon dans LDAP, mais similaire à l'opération d'abandon dans le protocole d'accès aux annuaires X.511 (DAP), cette opération a une réponse qui indique le résultat de son exécution.

RFC-3876 Returning Matched Values with the Lightweight Directory Access Protocol version 3 (LDAPv3)

http://www.ietf.org/rfc/rfc3876.txt

Ce document décrit une commande pour le protocole d'accès aux annuaires LDAP version 3 qui est utilisée pour renvoyer un sous-ensemble de valeurs d'attribut d'une entrée. Plus précisément, seulement les valeurs qui correspondent à un filtre de "retour de valeurs". Sans prise en charge de cette commande, un client doit récupérer toutes les valeurs d'un attribut et localiser les valeurs spécifiques localement.

RFC-3866 Language Tags and Ranges in the Lightweight Directory Access Protocol (LDAP)

http://www.ietf.org/rfc/rfc3866.txt

Il est souvent souhaitable d'indiquer la langue naturelle associée aux valeurs stockées dans un annuaire et de pouvoir interroger l'annuaire pour des valeurs répondant aux besoins linguistiques de l'utilisateur. Ce document détaille l'utilisation des étiquettes et des plages de langues dans le protocole d'accès aux annuaires LDAP (LDAP).

RFC-3727 ASN.1 Module Definition for the LDAP and X.500 Component Matching Rules

http://www.ietf.org/rfc/rfc3727.txt

Ce document met à jour la spécification des règles de correspondance des annuaires d'accès aux annuaires (LDAP) et X.500 (RFC 3687) en rassemblant les définitions de notation de syntaxe abstraite (ASN.1) des règles de correspondance de composants dans un module ASN.1 correctement identifié, afin que d'autres documents puissent faire référence aux définitions des règles de correspondance de composants à partir de leurs propres modules ASN.1.

RFC-3703 Policy Core Lightweight Directory Access Protocol (LDAP) Schema

http://www.ietf.org/rfc/rfc3703.txt

Ce document définit un mappage du modèle d'informations du noyau de politique vers un format pouvant être implémenté dans un annuaire utilisant le protocole d'accès aux annuaires (LDAP) comme protocole d'accès. Ce modèle définit deux hiérarchies de classes d'objets : les classes structurelles représentant les informations pour représenter et contrôler les données de politique selon le RFC 3060, et les classes de relation indiquant comment les instances des classes structurelles sont liées entre elles. Des classes sont également ajoutées au schéma LDAP pour améliorer les performances des interactions d'un client avec un serveur LDAP lorsque le client récupère de grandes quantités d'informations relatives à la politique. Ces classes existent uniquement pour optimiser les requêtes LDAP : il n'y a pas de classes dans le modèle d'informations qui leur correspondent.

RFC-3698 Lightweight Directory Access Protocol (LDAP): Additional Matching Rules

http://www.ietf.org/rfc/rfc3698.txt

Ce document fournit une collection de règles de correspondance à utiliser avec le protocole d'accès aux annuaires (LDAP). Comme ces règles de correspondance sont de simples adaptations de règles de correspondance spécifiées pour être utilisées avec l'annuaire X.500, la plupart d'entre elles sont déjà largement utilisées.

RFC-3687 Lightweight Directory Access Protocol (LDAP) and X.500 Component Matching Rules

http://www.ietf.org/rfc/rfc3687.txt

Les syntaxes d'attributs dans un annuaire d'accès aux annuaires (LDAP) ou dans un annuaire X.500 vont des types de données simples, tels que les chaînes de caractères, les entiers ou les booléens, aux types de données structurés complexes, tels que les syntaxes d'attributs opérationnels des schémas d'annuaires X.500. Les règles de correspondance définies pour les syntaxes complexes ne fournissent généralement que la capacité de correspondance la plus immédiatement utile. Ce document définit des règles de correspondance génériques qui peuvent correspondre à n'importe quelle partie sélectionnée d'une valeur d'attribut de n'importe quelle syntaxe arbitrairement complexe.

RFC-3672 Subentries in the Lightweight Directory Access Protocol (LDAP)

http://www.ietf.org/rfc/rfc3672.txt

Dans les annuaires X.500, les sous-entrées sont des entrées spéciales utilisées pour stocker des informations associées à un sous-arbre ou à un raffinement du sous-arbre. Ce document adapte les mécanismes de sous-entrées de X.500 pour une utilisation avec le protocole d'accès aux annuaires (LDAP).

RFC-5805 Protocole LDAP de transactions

http://www.ietf.org/rfc/rfc5805.txt

Les opérations de mise à jour du protocole LDAP, telles que l'ajout, la suppression ou la modification, ont des propriétés ACID (Atomicité, Cohérence, Isolation, Durabilité). Chacune de ces opérations agit sur un environnement. Il est souhaitable de mettre à jour plusieurs environnements en un seul ensemble d'interactions, une transaction. Les transactions sont nécessaires pour prendre en charge plusieurs applications, y compris la mise à disposition de ressources. Ce document étend le LDAP pour prendre en charge les transactions.

RFC-4533 Opérations de synchronisation de contenu LDAP

http://www.ietf.org/rfc/rfc4533.txt

Ce document décrit l'opération de synchronisation de contenu du protocole LDAP. L'opération permet à un client de maintenir une copie d'un fragment de l'arborescence d'informations du répertoire (DIT). Elle prend en charge à la fois l'attente de modifications et l'écoute des modifications. L'opération est définie comme une extension de l'opération de recherche LDAP.

RFC-4531 Opération "Turn" du protocole LDAP

http://www.ietf.org/rfc/rfc4531.txt

Ce document décrit une opération d'extension du protocole LDAP pour inverser (ou "tourner") les rôles du client et du serveur pour les interactions suivantes dans le protocole, ou pour permettre à chaque partie d'agir en tant que client et serveur par rapport à l'autre.

RFC-3663 Données d'administration de domaine dans le protocole LDAP

http://www.ietf.org/rfc/rfc3663.txt

Les données d'enregistrement de domaine ont été rendues publiques via Nicname/Whois à des fins administratives. Ce document décrit le service de renforcement du protocole LDAP, un service expérimental utilisant LDAP et des types bien connus pour afficher les données d'administration de domaine.

RFC-3088 Service de référence du répertoire LDAP - Un service expérimental

http://www.ietf.org/rfc/rfc3088.txt

Le projet OpenLDAP exploite un service de référence LDAP expérimental connu sous le nom de "OpenLDAP Root Service". Le système automatisé génère des références basées sur les informations de localisation publiées dans les enregistrements DNS SRV (enregistrements de localisation de service dans le système de noms). Ce document décrit ce service.

RFC-2657 Client LDAPv2 vs. le Mesh d'index

http://www.ietf.org/rfc/rfc2657.txt

Les clients LDAPv2 implémentés selon la RFC 1777 n'ont aucune notion de références. L'intégration entre de tels clients et le Mesh d'index, tel que défini par le protocole d'indexation commun, dépend fortement des références et nécessite donc une gestion spéciale. Ce document définit une manière possible de le faire.

RFC-2649 Opérations dirigées avec S/MIME

http://www.ietf.org/rfc/rfc2649.txt

Ce document définit un mécanisme LDAPv3 pour signer les opérations de répertoire afin de créer un journal sécurisé des modifications apportées à chaque entrée du répertoire. Les signatures du client et du serveur sont prises en charge. Une classe d'objet est également définie pour récupérer ultérieurement ces entrées. Ce document spécifie les contrôles LDAPv3 qui permettent cette fonctionnalité. Il définit également un schéma LDAPv3 qui permet la navigation ultérieure des informations du journal.

RFC-2307 Une stratégie pour utiliser LDAP comme service d'information réseau

http://www.ietf.org/rfc/rfc2307.txt

Ce document décrit un mécanisme expérimental pour mapper des entités liées à TCP/IP et au système UNIX sur des entrées X.500 afin qu'elles puissent être résolues via LDAP. Un ensemble de types d'attributs et de classes d'objets est proposé, ainsi que des directives spécifiques pour leur interprétation. L'objectif est d'aider à la mise en œuvre de LDAP en tant que service de noms organisationnel. Aucune solution proposée n'est incluse comme normes Internet. draft-wahl-ldap-adminaddr -- Adresse d'administrateur d'attribut

Les organisations qui gèrent plusieurs serveurs de répertoire ont besoin d'une capacité pour les administrateurs de déterminer qui est responsable d'un serveur donné.
