Net::LDAP::Control::NoOp(3) Documentation Perl fournie par l'utilisateur Net::LDAP::Control::NoOp(3)

NOM

Net::LDAP::Control::NoOp - Objet de contrôle de suppression d'arbre LDAPv3

SYNOPIS

use Net::LDAP;
use Net::LDAP::Control::NoOp;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$noop = Net::LDAP::Control::NoOp->new();
$msg = $ldap->modify( 'cn=Barbara Jensen, o=University of Michigan, c=US',
                      control  => [ $noop ] );
die "erreur: ",$msg->code(),": ",$msg->error()  if ($msg->code());

DESCRIPTION

"Net::LDAP::Control::NoOp" fournit une interface pour la création et la manipulation d'objets qui représentent le contrôle "No-Op" tel que décrit dans draft-zeilenga-ldap-noop-01.txt https://tools.ietf.org/html/draft-zeilenga-ldap-noop-01.

Le contrôle, qui n'a pas de contrôle de réponse correspondant, est approprié pour toutes les requêtes de mise à jour LDAP, y compris l'ajout, la suppression, la modification et la modification de nom (moddn).

Sa criticité est toujours "TRUE" ; il n'a pas de valeur.

La présence du contrôle "No-Op" dans un message de requête d'opération désactive l'effet normal de l'opération ; c'est-à-dire que le serveur effectuera tous les traitements nécessaires pour exécuter l'opération mais ne mettra pas réellement à jour l'annuaire.

ARGUMENTS DU CONSTRUCTEUR

Comme le contrôle "NoOp" n'a pas de valeurs, seuls les arguments du constructeur décrits dans Net::LDAP::Control sont supportés.

METHODES

Comme il n'y a pas de valeurs supplémentaires dans le contrôle, seules les méthodes de Net::LDAP::Control sont disponibles pour les objets de "Net::LDAP::Control::NoOp".
