NOM

Net::DBus::Object - Implémenter des objets à exporter sur le bus

SYNTAXE

# Connexion d'un objet au bus, sous un service
package main;
use Net::DBus;
# Connexion au bus
my $bus = Net::DBus->find;
# Acquisition d'un service 'org.demo.Hello'
my $service = $bus->export_service("org.demo.Hello");
# Exportation de notre objet au sein du service
my $object = Demo::HelloWorld->new($service);
....reste du programme...
# Définir un nouveau paquet pour l'objet que nous allons
# exporter
package Demo::HelloWorld;
# Spécifier l'interface principale fournie par notre objet
use Net::DBus::Exporter qw(org.example.demo.Greeter);
# Nous allons être un objet DBus
use base qw(Net::DBus::Object);
# Exporter un signal 'Greeting' prenant un paramètre string
dbus_signal("Greeting", ["string"]);
# Exporter 'Hello' comme une méthode acceptant un seul paramètre string
# et retournant une seule valeur string
dbus_method("Hello", ["string"], ["string"]);
sub new {
    my $class = shift;
    my $service = shift;
    my $self = $class->SUPER::new($service, "/org/demo/HelloWorld");
    bless $self, $class;
    return $self;
}
sub Hello {
  my $self = shift;
  my $name = shift;
  $self->emit_signal("Greeting", "Hello $name");
  return "Said hello to $name";
}
# Exporter 'Goodbye' comme une méthode acceptant un seul paramètre string
# et retournant une seule valeur string, mais la placer
# dans l'interface 'org.exaple.demo.Farewell'
dbus_method("Goodbye", ["string"], ["string"], "org.example.demo.Farewell");
sub Goodbye {
  my $self = shift;
  my $name = shift;
  $self->emit_signal("Greeting", "Goodbye $name");
  return "Said goodbye to $name";
}

DESCRIPTION

Ceci est la base pour implémenter des objets qui sont directement exportés sur le bus. Les méthodes implémentées dans une sous-classe sont mappées aux méthodes sur le bus. En utilisant cette classe, une application lie directement la fonctionnalité RPC à son modèle objet. Les applications peuvent donc préférer utiliser la classe "Net::DBus::ProxyObject" qui permet de maintenir la fonctionnalité RPC séparément du modèle objet principal, en faisant un proxy des appels de méthode RPC.

MÉTHODES

mon $objet = Net::DBus::Object->new($service, $chemin)
Ceci crée un nouvel objet DBus avec un chemin de $chemin enregistré au sein du service $service. Le paramètre $chemin devrait être une chaîne de caractères conforme aux exigences habituelles de DBus pour les chemins d'objets, tandis que le paramètre $service devrait être une instance de Net::DBus::Service. Ce dernier est typiquement obtenu en appelant la méthode "export_service" sur l'objet Net::DBus.
mon $objet = Net::DBus::Object->new($objetparent, $souschemin)
Ceci crée un nouvel objet enfant DBus avec un chemin de $souschemin relatif à son parent $objetparent. Le paramètre $souschemin devrait être une chaîne de caractères conforme aux exigences habituelles de DBus pour les chemins d'objets, tandis que le paramètre $objetparent devrait être une instance de Net::DBus::BaseObject ou une sous-classe.
