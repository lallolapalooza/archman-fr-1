NOM

Net::OAuth::ConsumerRequest - Une Requête Consommateur OAuth

NOTE

Les Requêtes Consommateur sont une extension proposée pour OAuth, donc d'autres implémentations OAuth peuvent les supporter ou non.

VOIR AUSSI

Brouillon de l'extension Requête Consommateur :

http://oauth.googlecode.com/svn/spec/ext/consumer_request/1.0/drafts/1/spec.html
