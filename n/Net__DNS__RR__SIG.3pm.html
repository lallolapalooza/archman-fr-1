NOM

Net::DNS::RR::SIG - enregistrement de ressource DNS SIG

SYNOPIS

use Net::DNS;
$rr = Net::DNS::RR->new('nom SIG typecouvert algorithme étiquettes
                        ttl d'expiration sig sig
                        clé nom de signature signature');
use Net::DNS::SEC;
$sigrr = Net::DNS::RR::SIG->create(
                        $chaîne, $chemin_clé,
                        sigval => 10    # minutes
                        );
$sigrr->verify( $chaîne, $keyrr ) || die $sigrr->vrfyerrstr;
$sigrr->verify( $paquet, $keyrr ) || die $sigrr->vrfyerrstr;

DESCRIPTION

Classe pour les enregistrements de ressource de signature numérique DNS (SIG).

En plus des méthodes régulières héritées de Net::DNS::RR, la classe contient une méthode pour signer des paquets et des chaînes de données scalaires en utilisant des clés privées (create) et une méthode pour vérifier les signatures.

L'enregistrement SIG est une implémentation de la RFC2931. Voir Net::DNS::RR::RRSIG pour une implémentation de la RFC4034.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées des méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités non documentées du package ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

algorithme

$algorithme = $rr->algorithm;

Le champ du numéro d'algorithme identifie l'algorithme cryptographique utilisé pour créer la signature.

algorithm() peut également être appelé en tant que méthode de classe ou fonction simple pour effectuer la traduction des codes mnémoniques et numériques.

heure d'expiration et heure d'inception de la signature

sigex sigin sigval

$expiration = $rr->sigexpiration;
$expiration = $rr->sigexpiration( $valeur );
$inception = $rr->siginception;
$inception = $rr->siginception( $valeur );

Les champs d'expiration et d'inception de la signature spécifient un intervalle de temps de validité pour la signature.

La valeur peut être spécifiée par une chaîne de caractères au format 'aaaammjjhhmmss' ou une valeur time() de Perl.

Les valeurs de retour sont doubles, fournissant soit une valeur de chaîne, soit une valeur numérique Perl time().

tag de la clé

$tag_de_la_clé = $rr->keytag;
$rr->keytag( $tag_de_la_clé );

Le champ tag_de_la_clé contient la valeur du tag de clé de l'enregistrement KEY RR qui valide cette signature.

nom de signature

$nom_de_signature = $rr->signame;
$rr->signame( $nom_de_signature );

Le nom du signataire identifie le nom du propriétaire de l'enregistrement KEY RR que le validateur est censé utiliser pour valider cette signature.

signature

sig

$sig = $rr->sig;
$rr->sig( $sig );

Le champ Signature contient la signature cryptographique qui couvre les RDATA SIG (à l'exclusion du champ Signature) et les données sujettes.

sigbin

$sigbin = $rr->sigbin;
$rr->sigbin( $sigbin );

Représentation binaire de la signature cryptographique.

créer

Crée une signature sur des données scalaires.

use Net::DNS::SEC;
$chemin_clé = '/home/olaf/keys/Kbla.foo.+001+60114.private';
$sigrr = Net::DNS::RR::SIG->create( $données, $chemin_clé );
$sigrr = Net::DNS::RR::SIG->create(
                        $données, $chemin_clé,
                        sigval => 10
                        );
$sigrr->print;
# Alternativement, utiliser Net::DNS::SEC::Private
$privé = Net::DNS::SEC::Private->new($chemin_clé);
$sigrr= Net::DNS::RR::SIG->create( $données, $privé );

create() est un constructeur alternatif pour un objet SIG RR.

Cette méthode renvoie un SIG avec la signature sur les données créée avec la clé privée stockée dans le fichier clé.

Le premier argument est un scalaire qui contient les données à signer.

Le deuxième argument est une chaîne qui spécifie le chemin d'accès à un fichier contenant la clé privée telle que générée à l'aide de dnssec-keygen, un programme fourni avec la distribution ISC BIND.

Les arguments restants optionnels consistent en paires ( nom => valeur ) comme suit :

sigin  => 20241201010101,       # inception de la signature
sigex  => 20241201011101,       # expiration de la signature
sigval => 10,                   # fenêtre de validité (minutes)

Les valeurs sigin et sigex peuvent être spécifiées comme valeurs de temps Perl ou comme une chaîne au format 'aaaammjjhhmmss'. La valeur par défaut pour sigin est le moment de la signature.

L'argument sigval spécifie la fenêtre de validité de la signature en minutes ( sigex = sigin + sigval ).

Par défaut, la signature est valide pendant 10 minutes.

vérifier

$vérification = $sigrr->verify( $données, $keyrr );
$vérification = $sigrr->verify( $données, [$keyrr, $keyrr2, $keyrr3] );

La méthode verify() effectue la vérification SIG0 des données spécifiées par rapport à la signature contenue dans l'objet $sigrr lui-même en utilisant la clé publique dans $keyrr.

Si une référence à un Net::DNS::Packet est fournie, la méthode effectue une vérification SIG0 sur les données du paquet.

Le deuxième argument peut être soit un objet Net::DNS::RR::KEYRR, soit une référence à un tableau de tels objets. La vérification réussira dès qu'une des clés du tableau entraînera une validation positive.

Retourne faux en cas d'erreur et définit $sig->vrfyerrstr

vrfyerrstr

$sig0 = $paquet->sigrr || die 'non signé';
print $sig0->vrfyerrstr unless $sig0->verify( $paquet, $keyrr );
$sigrr->verify( $paquet, $keyrr ) || die $sigrr->vrfyerrstr;

GÉNÉRATION DE CLÉS

Les fichiers de clés privées et les enregistrements DNSKEY publics correspondants sont générés de manière plus pratique à l'aide de dnssec-keygen, un programme fourni avec la distribution ISC BIND.

dnssec-keygen -a 10 -b 2048 rsa.example.
dnssec-keygen -a 13 -f ksk  ecdsa.example.
dnssec-keygen -a 13         ecdsa.example.

Ne modifiez pas le nom du fichier de clé privée. La méthode create utilise le nom de fichier tel que généré par dnssec-keygen pour déterminer le propriétaire de la clé, l'algorithme et l'ID de clé (tag_de_la_clé).
