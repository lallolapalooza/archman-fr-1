Paquet: perl-ldap

Licences: GPL

Net::LDAP::RootDSE(3) Documentation Perl contribuée par l'utilisateur Net::LDAP::RootDSE(3)

NOM

Net::LDAP::RootDSE - Un objet LDAP RootDSE

SYNOPSIS

my $dse = $ldap->root_dse();
# obtenir les Contextes de nommage
my @contexts = $dse->get_value('namingContexts');
# obtenir les versions LDAP supportées en tant que référence de tableau
my $versions = $dse->get_value('supportedLDAPVersion', asref => 1);

DESCRIPTION

Méthodes

get_value
"get_value" est identique à "get_value" dans Net::LDAP::Entry
supported_extension ( OID_LIST )
Retourne vrai si le serveur supporte tous les OID d'extension spécifiés
supported_feature ( OID_LIST )
Retourne vrai si le serveur supporte tous les OID de fonctionnalité spécifiés
supported_version ( VERSION_LIST )
Retourne vrai si le serveur supporte toutes les versions spécifiées
supported_control ( OID_LIST )
Retourne vrai si le serveur supporte tous les OID de contrôle spécifiés
supported_sasl_mechanism ( SASL_MECH_LIST )
Retourne vrai si le serveur supporte tous les noms de mécanisme SASL spécifiés

VOIR AUSSI

Net::LDAP, Net::LDAP::Entry
