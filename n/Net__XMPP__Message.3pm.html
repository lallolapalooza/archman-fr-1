NOM

Net::XMPP::Message - Module de Message XMPP

SYNOPIS

Net::XMPP::Message est un complément au module Net::XMPP.
Il offre à l'utilisateur une interface simple pour définir et récupérer toutes
les parties d'un Message XMPP.

DESCRIPTION

Un objet Net::XMPP::Message est passé à la fonction de rappel pour le message.
De plus, le premier argument des fonctions de rappel est l'identifiant de session
provenant de XML::Stream. Il peut y avoir des cas où vous souhaitez ces
informations, comme si vous avez créé un Client qui se connecte à deux serveurs
en même temps, ou pour écrire un mini serveur.
  use Net::XMPP;
  sub message {
    my ($sid,$Mess) = @_;
    .
    .
    .
  }
Vous avez maintenant accès à toutes les fonctions de récupération disponibles.
Pour créer un nouveau message à envoyer au serveur :
  use Net::XMPP;
  $Mess = Net::XMPP::Message->new();
Vous pouvez maintenant appeler les fonctions de création ci-dessous pour remplir la balise
avant de l'envoyer.

MÉTHODES

Fonctions de récupération

GetTo()      - retourne la valeur de l'attribut to='' du
GetTo("jid")   <message/>. Si vous spécifiez "jid" comme argument,
               un objet Net::XMPP::JID est retourné et
               vous pouvez facilement analyser les parties du JID.
               $to    = $Mess->GetTo();
               $toJID = $Mess->GetTo("jid");
GetFrom()      - retourne la valeur de l'attribut from='' du
GetFrom("jid")   <message/>. Si vous spécifiez "jid" comme argument,
                 un objet Net::XMPP::JID est retourné et
                 vous pouvez facilement analyser les parties du JID.
                 $from    = $Mess->GetFrom();
                 $fromJID = $Mess->GetFrom("jid");
GetType() - retourne l'attribut type='' du <message/>. Chaque
            message est d'un des quatre types :
              normal        message normal (par défaut si le type est vide)
              chat          conversation individuelle
              groupchat     conversation de groupe
              headline      titre d'actualité
              error         message d'erreur
            $type = $Mess->GetType();
GetSubject() - retourne les données de la balise <subject/>.
               $subject = $Mess->GetSubject();
GetBody() - retourne les données de la balise <body/>.
            $body = $Mess->GetBody();
GetThread() - retourne les données de la balise <thread/>.
              $thread = $Mess->GetThread();
GetError() - retourne une chaîne avec les données de la balise <error/>.
             $error = $Mess->GetError();
GetErrorCode() - retourne une chaîne avec l'attribut code='' du
                 <error/>.
                 $errCode = $Mess->GetErrorCode();
GetTimeStamp() - retourne une chaîne représentant le moment où cet
                 objet message a été créé (et probablement reçu)
                 pour l'envoi au client. S'il y a une balise
                 jabber:x:delay, alors cette heure est utilisée pour montrer
                 quand le message a été envoyé.
                 $date = $Mess->GetTimeStamp();

Fonctions de création

SetMessage(to=>chaîne|JID,    - définit plusieurs champs dans le <message/>
           from=>chaîne|JID,    en une seule fois. C'est une action cumulative
           type=>chaîne,        et écrasante. Si vous définissez
           subject=>chaîne,     l'attribut "to" deux fois, le deuxième
           body=>chaîne,        paramètre est celui utilisé. Si vous définissez
           thread=>chaîne,      le sujet, puis le corps,
           errorcode=>chaîne,   alors les deux seront dans la balise <message/>.
           error=>chaîne)       Pour des paramètres valides, lisez les
                                fonctions Set spécifiques ci-dessous.
                          $Mess->SetMessage(TO=>"bob\@jabber.org",
                                            Subject=>"Déjeuner",
                                            BoDy=>"Allons déjeuner !");
                          $Mess->SetMessage(to=>"bob\@jabber.org",
                                            from=>"jabber.org",
                                            errorcode=>404,
                                            error=>"Non trouvé");
SetTo(chaîne) - définit l'attribut to=''. Vous pouvez passer
SetTo(JID)      une chaîne ou un objet JID. Ils doivent être des JIDs valides
                sinon le serveur renverra un message d'erreur.
                (par ex. bob@jabber.org/Travail)
                $Mess->SetTo("test\@jabber.org");
SetFrom(chaîne) - définit l'attribut from=''. Vous pouvez passer
SetFrom(JID)      une chaîne ou un objet JID. Ils doivent être des JIDs valides
                  sinon le serveur renverra un message d'erreur. (par ex.
                  jabber:bob@jabber.org/Travail) Ce champ n'est pas
                  obligatoire si vous écrivez un Client car le
                  serveur y placera le JID de votre connexion
                  pour éviter le spam.
                  $Mess->SetFrom("moi\@jabber.org");
SetType(chaîne) - définit l'attribut type. Les paramètres valides sont :
                    normal         message normal (par défaut si vide)
                    chat           message style conversation un à un
                    groupchat      message de salle de discussion multi-personnes
                    headline       titre d'actualité, cours de bourse, etc.
                    error          message d'erreur
                  $Mess->SetType("groupchat");
SetSubject(chaîne) - définit le sujet du <message/>.
                     $Mess->SetSubject("Ceci est un test");
SetBody(chaîne) - définit le corps du <message/>.
                  $Mess->SetBody("Être ou ne pas être...");
SetThread(chaîne) - définit le fil de discussion du <message/>. Vous devriez
                    copier ceci du message auquel vous répondez afin
                    que le fil de discussion soit maintenu.
                    $Mess->SetThread("AE912B3");
SetErrorCode(chaîne) - définit le code d'erreur du <message/>.
                       $Mess->SetErrorCode(403);
SetError(chaîne) - définit la chaîne d'erreur du <message/>.
                   $Mess->SetError("Permission refusée");
Reply(hash) - crée un nouvel objet Message et remplit les
              champs to/from, et le sujet en ajoutant "re: " devant.
              Si vous spécifiez une hash comme avec
              SetMessage, alors ces valeurs remplaceront les
              valeurs de Reply.
              $Reply = $Mess->Reply();
              $Reply = $Mess->Reply(type=>"chat");

Fonctions de suppression

RemoveTo() - supprime l'attribut to du <message/>.
             $Mess->RemoveTo();
RemoveFrom() - supprime l'attribut from du <message/>.
               $Mess->RemoveFrom();
RemoveType() - supprime l'attribut type du <message/>.
               $Mess->RemoveType();
RemoveSubject() - supprime l'élément <subject/> du
                  <message/>.
                  $Mess->RemoveSubject();
RemoveBody() - supprime l'élément <body/> du
               <message/>.
               $Mess->RemoveBody();
RemoveThread() - supprime l'élément <thread/> du <message/>.
                 $Mess->RemoveThread();
RemoveError() - supprime l'élément <error/> du <message/>.
                $Mess->RemoveError();
RemoveErrorCode() - supprime l'attribut code de l'élément <error/>
                    dans le <message/>.
                    $Mess->RemoveErrorCode();
