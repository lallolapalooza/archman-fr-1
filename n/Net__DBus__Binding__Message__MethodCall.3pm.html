NOM

Net::DBus::Binding::Message::MethodCall - un message encodant un appel de méthode

DESCRIPTION

Ce module fait partie des API de liaison DBus de bas niveau, et ne devrait pas être utilisé par le code applicatif. Aucune garantie n'est faite concernant la stabilité des API sous l'espace de noms "Net::DBus::Binding::" entre les versions.

Ce module fournit un constructeur pratique pour créer un message représentant un appel de méthode.

MÉTHODES

mon $appel = Net::DBus::Binding::Message::MethodCall->new( nom_service => $service, chemin_objet => $objet, interface => $interface, nom_methode => $nom);
Crée un message représentant un appel sur l'objet situé au chemin "chemin_objet" au sein du client possédant le nom bien connu donné par "nom_service". La méthode à invoquer a le nom "nom_methode" au sein de l'interface spécifiée par le paramètre "interface".
