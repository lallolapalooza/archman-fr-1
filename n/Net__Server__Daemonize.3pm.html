NOM

Net::Server::Daemonize - Utilitaires de fork et de daemonisation sécurisés

SYNOPSIS

use Net::Server::Daemonize qw(daemonize);
daemonize(
  'nobody',                 # Utilisateur
  'nobody',                 # Groupe
  '/var/state/mydaemon.pid' # Chemin du fichier PID - facultatif
);

DESCRIPTION

Ce module est destiné à vous permettre de daemoniser simplement et en toute sécurité votre serveur sur les systèmes supportant le module POSIX. Cela signifie que votre script Perl s'exécute en arrière-plan, et son ID de processus est stocké dans un fichier afin que vous puissiez facilement l'arrêter plus tard.

FONCTIONS EXPORTÉES

daemonize
Routine principale. Les arguments sont l'utilisateur (ou l'ID utilisateur), le groupe (ou l'ID groupe ou une liste d'ID groupe séparés par des espaces), et pid_file (chemin du fichier). Cette routine vérifie le fichier PID, effectue un fork sécurisé, crée le fichier PID (en stockant le PID dans le fichier), devient un autre utilisateur et groupe, ferme STDIN, STDOUT et STDERR, se sépare du groupe de processus (devient chef de session), et installe $SIG{INT} pour supprimer le fichier PID. En d'autres termes, daemonise. Toutes les erreurs entraînent un die. Depuis la version 0.89, le fichier PID est facultatif.
safe_fork
Bloque SIGINT pendant le fork. Aucun argument. Renvoie le PID de l'enfant forké. Toutes les erreurs entraînent un die.
set_user
Devient un autre utilisateur et groupe. Les arguments sont l'utilisateur (ou l'ID utilisateur) et le groupe (ou l'ID groupe ou une liste d'ID groupe séparés par des espaces).
set_uid
Devient un autre utilisateur. L'argument est l'utilisateur (ou l'ID utilisateur). Toutes les erreurs entraînent un die.
set_gid
Devient un autre groupe. Les arguments sont les groupes (ou les ID groupe ou une liste d'ID groupe séparés par des espaces ou des ID groupe). Toutes les erreurs entraînent un die.
get_uid
Trouve l'ID utilisateur. L'argument est l'utilisateur (l'ID utilisateur renvoie l'ID utilisateur). Renvoie l'ID utilisateur. Toutes les erreurs entraînent un die.
get_gid
Trouve les ID groupe. Les arguments sont les groupes ou une liste de groupes séparés par des espaces. Toutes les erreurs entraînent un die.
is_root_user
Détermine si le processus s'exécute en tant que root. Renvoie 1 ou undef.
check_pid_file
Les arguments sont pid_file (chemin complet du fichier PID). Vérifie l'existence du fichier PID. Si le fichier existe, l'ouvre et détermine si le processus qui l'a créé est toujours en cours d'exécution. Ceci est fait d'abord en vérifiant un système de fichiers /proc et ensuite en utilisant une commande "ps" (syntaxe BSD). (Si aucune de ces options n'existe, on suppose que le processus s'est terminé) Si le processus est toujours en cours d'exécution, il est abandonné. Sinon, renvoie vrai. Toutes les erreurs entraînent un die.
create_pid_file.
Les arguments sont pid_file (chemin complet du fichier PID). Appelle check_pid_file. Si elle réussit (aucun fichier PID n'existe), crée un fichier PID et stocke $$ dans le fichier.
unlink_pid_file
Fait exactement cela.
