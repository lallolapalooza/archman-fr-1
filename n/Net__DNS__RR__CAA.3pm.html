NOM

Net::DNS::RR::CAA - Enregistrement de ressource DNS CAA

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new('nom EN CAA drapeaux etiquette valeur');

DESCRIPTION

Classe pour les enregistrements de ressource DNS d'Autorisation d'Autorité de Certification (CAA).

METHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées des méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités non documentées du paquet ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

drapeaux

$drapeaux = $rr->drapeaux;
$rr->drapeaux( $drapeaux );

Nombre non signé de 8 bits représentant des drapeaux booléens.

critique
$rr->critique(1);
if ( $rr->critique ) {
        ...
}

Drapeau critique de l'émetteur.

etiquette

$etiquette = $rr->etiquette;
$rr->etiquette( $etiquette );

Identifiant de propriété qui peut contenir les caractères a-z, A-Z et 0-9. Le champ etiquette ne doit pas contenir d'autres caractères. La correspondance des étiquettes n'est pas sensible à la casse.

valeur

$valeur = $rr->valeur;
$rr->valeur( $valeur );

Une séquence d'octets représentant la valeur de la propriété. Les valeurs de propriété sont encodées comme des valeurs binaires et peuvent employer des sous-formats.
