Net::DNS::ZoneFile(3) Documentation soumise par Perl Net::DNS::ZoneFile(3)

NOM

Net::DNS::ZoneFile - Fichier de zone DNS

SYNOPSIS

use Net::DNS::ZoneFile;
$zonefile = Net::DNS::ZoneFile->new( 'named.example' );
while ( $rr = $zonefile->read ) {
        $rr->print;
}
@zone = $zonefile->read;

DESCRIPTION

Chaque objet Net::DNS::ZoneFile représente un fichier de zone DNS ainsi que tous les fichiers inclus référencés par la directive $INCLUDE. La syntaxe des fichiers de zone est définie par la RFC1035.

Un programme peut avoir plusieurs objets de fichier de zone DNS, chacun conservant ses propres informations d'état d'analyseur.

L'analyseur supporte à la fois la directive $TTL définie par la RFC2308 et l'extension de syntaxe BIND $GENERATE.

Toutes les RR dans un fichier de zone doivent être de la même classe, qui peut être spécifiée pour la première RR trouvée et sera automatiquement propagée à toutes les suivantes.

MÉTHODES

new

$zonefile = Net::DNS::ZoneFile->new( 'filename', ['example.com'] );
$handle   = IO::File->new( 'filename', '<:encoding(ISO8859-7)' );
$zonefile = Net::DNS::ZoneFile->new( $handle, ['example.com'] );

Le constructeur new() renvoie un objet Net::DNS::ZoneFile représentant le fichier de zone spécifié dans la liste d'arguments.

Le fichier spécifié ou le handle est ouvert en lecture et est fermé lorsque les données sont épuisées ou lorsque les références à l'objet ZoneFile n'existent plus.

L'argument optionnel second spécifie le $ORIGIN pour le fichier de zone.

Les fichiers de zone sont supposés être encodés en UTF-8 si possible.

Des codages alternatifs peuvent être spécifiés indirectement en créant un handle avec la couche de codage souhaitée, qui est ensuite passé comme argument à new(). Le codage spécifié est propagé aux fichiers inclus via des directives $INCLUDE.

read

$rr = $zonefile->read;
@rr = $zonefile->read;

Lorsqu'il est appelé dans un contexte scalaire, read() renvoie un objet Net::DNS::RR représentant la prochaine RR de zone trouvée dans le fichier de zone, ou undefined si la fin des données est atteinte.

Lorsqu'il est appelé dans un contexte de liste, read() renvoie une liste d'objets Net::DNS::RR dans l'ordre où ils apparaissent dans le fichier de zone.

Les commentaires et les lignes vides sont silencieusement ignorés.

Les directives $INCLUDE, $ORIGIN, $TTL et $GENERATE sont traitées de manière transparente.

name

$filename = $zonefile->name;

Renvoie le nom du fichier de zone actuel. Les directives $INCLUDE intégrées peuvent faire en sorte que ce nom diffère de l'argument fourni lors de la création de l'objet.

line

$line = $zonefile->line;

Renvoie le numéro de la dernière ligne lue à partir du fichier de zone actuel.

origin

$origin = $zonefile->origin;

Renvoie le nom de domaine complet de l'origine dans le fichier de zone actuel.

ttl

$ttl = $zonefile->ttl;

Renvoie le TTL par défaut défini par la directive $TTL.

COMPATIBILITÉ AVEC Net::DNS::ZoneFile 1.04

Les programmes qui dépendaient de l'ancienne distribution CPAN de Net::DNS::ZoneFile 1.04 continueront de fonctionner avec peu de différences en utilisant l'interface de compatibilité décrite ci-dessous. Le nouveau code doit utiliser l'interface orientée objet.

use Net::DNS::ZoneFile;
$listref = Net::DNS::ZoneFile->read( $filename );
$listref = Net::DNS::ZoneFile->read( $filename, $include_dir );
$listref = Net::DNS::ZoneFile->readfh( $filehandle );
$listref = Net::DNS::ZoneFile->readfh( $filehandle, $include_dir );
$listref = Net::DNS::ZoneFile->parse( $string );
$listref = Net::DNS::ZoneFile->parse( $string, $include_dir );
$listref = Net::DNS::ZoneFile->parse( \$string );
$listref = Net::DNS::ZoneFile->parse( \$string, $include_dir );
$_->print for @$listref;

Le second argument optionnel spécifie le répertoire par défaut pour les fichiers inclus. Le répertoire de travail courant est utilisé par défaut.

Bien que non disponible dans l'implémentation d'origine, la liste des RR peut être obtenue directement en appelant n'importe quelle méthode dans un contexte de liste.

@rr = Net::DNS::ZoneFile->read( $filename, $include_dir );

En cas d'erreur lors de l'analyse, un résultat partiel est retourné.

read

$listref = Net::DNS::ZoneFile->read( $filename );
$listref = Net::DNS::ZoneFile->read( $filename, $include_dir );

read() analyse le contenu du fichier spécifié et renvoie une référence à la liste des objets Net::DNS::RR. La valeur renvoyée est undefined en cas d'erreur lors de l'analyse.

readfh

$listref = Net::DNS::ZoneFile->readfh( $filehandle );
$listref = Net::DNS::ZoneFile->readfh( $filehandle, $include_dir );

readfh() analyse les données du handle de fichier spécifié et renvoie une référence à la liste des objets Net::DNS::RR. La valeur renvoyée est undefined en cas d'erreur lors de l'analyse.

parse

$listref = Net::DNS::ZoneFile->parse( $string );
$listref = Net::DNS::ZoneFile->parse( $string, $include_dir );
$listref = Net::DNS::ZoneFile->parse( \$string );
$listref = Net::DNS::ZoneFile->parse( \$string, $include_dir );

parse() interprète le texte dans l'argument chaîne et renvoie une référence à la liste des objets Net::DNS::RR. La valeur renvoyée est undefined en cas d'erreur lors de l'analyse.

NOMBRE

Net::DNS::ZoneFile - análisis de registros de zona DNS

SINTAXIS

use Net::DNS::ZoneFile;

$zonefile = new Net::DNS::ZoneFile $filename;
$zonefile = new Net::DNS::ZoneFile \%hash;

$zonefile->read();
$zonefile->parse();

@records = $zonefile->records();
@records = $zonefile->records($name);

@rrset = $zonefile->rrset($name, $type);

$count = $zonefile->error_count();
$errors = $zonefile->errors();

DESCRIPCIÓN

Net::DNS::ZoneFile es una clase de interfaz de línea de comandos para el módulo Net::DNS. El módulo Net::DNS es una biblioteca de interfaz de programación de aplicaciones (API) que puede utilizarse para buscar registros DNS. Net::DNS puede ser utilizado para consultar servidores DNS y para analizar registros de zona DNS.

El módulo Net::DNS::ZoneFile se puede utilizar para analizar registros de zona DNS. Los registros de zona DNS son archivos que contienen información sobre un dominio DNS. La información contenida en los registros de zona DNS se utiliza para direccionar el tráfico de red a los servidores DNS correctos.

El módulo Net::DNS::ZoneFile se puede utilizar para leer y analizar registros de zona DNS. El módulo también puede utilizarse para obtener registros DNS de un servidor DNS.

MÉTODOS

new Name filename
Crea un nuevo objeto Net::DNS::ZoneFile. El argumento filename es el nombre del archivo de registro de zona que se va a analizar.
new \%hash
Crea un nuevo objeto Net::DNS::ZoneFile. El argumento %hash es una tabla hash que contiene los datos del registro de zona.
read()
Lee el registro de zona del archivo.
parse()
Analiza el registro de zona.
records()
Devuelve una lista de todos los registros del registro de zona.
records($name)
Devuelve una lista de todos los registros del registro de zona que coinciden con el nombre dado.
rrset($name, $type)
Devuelve un conjunto de registros (rrset) para el nombre y tipo dados.
error_count()
Devuelve el número de errores encontrados al analizar el registro de zona.
errors()
Devuelve una lista de errores encontrados al analizar el registro de zona.

COMPATIBILIDAD CON Net::DNS::ZoneFile 1.04

Este módulo es compatible con Net::DNS::ZoneFile 1.04. El módulo Net::DNS::ZoneFile 1.04 se puede descargar de CPAN.
