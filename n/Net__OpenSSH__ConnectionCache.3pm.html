NOM

Net::OpenSSH::ConnectionCache - cache et réutilise les connexions SSH de manière transparente

SYNOPIS

use Net::OpenSSH;
use Net::OpenSSH::ConnectionCache;
for (1..10) {
  my $ssh = Net::OpenSSH->new($host);
  $ssh->system("$cmd $_");
}

DESCRIPTION

Ce module installe un hook $Net::OpenSSH::FACTORY implémentant un schéma de mise en cache des connexions SSH.

$Net::OpenSSH::ConnectionCache::MAX_SIZE contrôle la taille du cache. Une fois autant de connexions allouées, le module essaiera d'en libérer avant d'en allouer une nouvelle.

La fonction "clean_cache" fait que le module oublie (et ferme) toutes les connexions mises en cache :

Net::OpenSSH::ConnectionCache::clean_cache();
