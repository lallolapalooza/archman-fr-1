Net::Server::SIG(3) Documentation Perl Contribuée par l'Utilisateur Net::Server::SIG(3)

NOM

Net::Server::SIG - adpf - Gestion des signaux plus sûre

SYNOPSIS

use Net::Server::SIG qw(register_sig check_sigs);
use IO::Select ();
use POSIX qw(WNOHANG);
my $select = IO::Select->new();
register_sig(PIPE => 'IGNORE',
             HUP  => 'DEFAULT',
             USR1 => sub { print "I got a SIG $_[0]\n"; },
             USR2 => sub { print "I got a SIG $_[0]\n"; },
             CHLD => sub { 1 while waitpid(-1, WNOHANG) > 0; },
             );
# ajouter des descripteurs au select
$select->add(\*STDIN);
# boucler indéfiniment pour rester en vie
while (1) {
    # utiliser un timeout pour voir si des signaux nous ont été passés
    # pendant que nous traitions un autre signal
    my @fh = $select->can_read(10);
    my $key;
    my $val;
    # c'est le gestionnaire pour sûr (fonctionne aussi sous non sûr)
    if (check_sigs()) {
      # ou my @sigs = check_sigs();
      next unless @fh;
    }
    my $handle = $fh[@fh];
    # faire quelque chose avec le descripteur
}

DESCRIPTION

Les signaux avant Perl 5.7 étaient non sûrs. Depuis, les signaux ont été implémentés selon un algorithme plus sûr. Net::Server::SIG assure la compatibilité ascendante tout en fonctionnant de manière fiable avec les versions plus récentes.

En utilisant une propriété de la fonction select(), Net::Server::SIG tente de résoudre le problème de l'insécurité. Si un processus est bloqué sur select(), tout signal interrompra le select. En utilisant ce concept, Net::Server::SIG effectue le moins de travail possible (changer un bit de 0 à 1). Et dépend du traitement réel des signaux qui doit avoir lieu immédiatement après l'appel select via la fonction "check_sigs". Voir l'exemple ci-dessus et aussi le script sigtest.pl situé dans le répertoire examples de cette distribution.

FONCTIONS

"register_sig($SIG => \&code_ref)"
Prend des paires clé/valeur où la clé est le nom du signal et l'argument est soit une référence de code, soit les mots 'DEFAULT' ou 'IGNORE'. La fonction register_sig doit être utilisée en conjonction avec check_sigs et avec un appel de fonction select() bloquant - sinon, vous verrez le signal enregistré disparaître mystérieusement.
unregister_sig($SIG)
Prend le nom d'un signal comme argument. Appelle register_sig avec ce nom de signal et 'DEFAULT' comme arguments (identique à register_sig(SIG,'DEFAULT')).
check_sigs()
Vérifie si des signaux enregistrés se sont produits. Si c'est le cas, elle exécutera la référence de code enregistrée pour ce signal. La valeur de retour est un tableau contenant tous les noms de SIGNAL qui se sont produits.
sig_is_registered($SIG)
Prend un nom de signal et renvoie toute référence de code enregistrée pour ce signal.
