NOM

Net::DNS::RR::EUI64 - Enregistrement de ressource DNS EUI64

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new('name IN EUI64 address');
$rr = Net::DNS::RR->new(
                name    => 'example.com',
                type    => 'EUI64',
                address => '00-00-5e-ef-10-00-00-2a'
                );

DESCRIPTION

Enregistrements de ressource DNS pour les Identifiants Uniques Étendus (EUI64) de 64 bits.

L'enregistrement de ressource EUI64 est utilisé pour représenter les Identifiants Uniques Étendus de l'IEEE utilisés dans divers réseaux de couche 2, comme Ethernet.

Les adresses EUI64 NE DEVRAIENT PAS être publiées dans le DNS public. Le RFC7043 décrit des implications potentielles graves pour la vie privée résultant de la publication indiscriminée d'adresses de couche de liaison dans le DNS.
