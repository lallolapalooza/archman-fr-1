NOM

Net::Server::Proto::UDP - Protocole UDP pour Net::Server.

SYNOPIS

Voir Net::Server::Proto.

DESCRIPTION

Module de protocole pour Net::Server. Ce module implémente le type de socket SOCK_DGRAM sous INET (également connu sous le nom d'UDP). Voir Net::Server::Proto.

PARAMÈTRES

Les paramètres suivants peuvent être spécifiés en plus des paramètres de ligne de commande normaux pour un Net::Server. Voir Net::Server pour plus d'informations sur la lecture des arguments.

udp_recv_len
Spécifie le nombre d'octets à lire depuis le handle de connexion UDP. Les données seront lues dans $self->{'server'}->{'udp_data'}. La valeur par défaut est 4096. Voir IO::Socket::INET et recv.
udp_recv_flags
Voir recv. La valeur par défaut est 0.
udp_broadcast
La valeur par défaut est undef.

LISTE RAPIDE DES PARAMÈTRES

Clé               Valeur                   Défaut
## Paramètres du protocole UDP
udp_recv_len      \d+                      4096
udp_recv_flags    \d+                      0
udp_broadcast     bool                     undef

MÉTHODES INTERNES

"object"
Retourne un objet avec des paramètres appropriés pour la création éventuelle d'un objet IO::Socket::INET écoutant sur UDP.
"connect"
Appelé lors de la liaison effective du port. Gère les paramètres par défaut avant d'appeler la méthode parente.
