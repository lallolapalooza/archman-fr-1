Net::Server::Proto::TCP(3) Documentation Perl fournie par l'utilisateur Net::Server::Proto::TCP(3)

NOM

Net::Server::Proto::TCP - Protocole TCP de Net::Server.

SYNOPSIS

Voir Net::Server::Proto.

DESCRIPTION

Module de protocole pour Net::Server. Ce module implémente le type de socket SOCK_STREAM sous INET (également connu sous le nom de TCP). Voir Net::Server::Proto.

PARAMÈTRES

Il n'y a pas de paramètres supplémentaires qui peuvent être spécifiés. Voir Net::Server pour plus d'informations sur la lecture des arguments.

MÉTHODES INTERNES

"object"
Retourne un objet avec des paramètres appropriés pour la création éventuelle d'un objet IO::Socket::INET écoutant sur UDP.
"log_connect"
Appelée avant de lier le socket pour fournir des informations utiles aux journaux.
"connect"
Appelée lors de la liaison effective du port. Gère les paramètres par défaut avant d'appeler la méthode parente.
"reconnect"
Appelée à la place de la méthode connect lors d'un signal hup du serveur.
"accept"
Substitution de la classe parente pour s'assurer que les paramètres nécessaires sont transmis aux sockets clients.
"poll_cb"
Permet une interface compatible PSGI lors d'un serveur HTTP.
"read_until"
Prend une expression régulière, lit depuis le socket jusqu'à ce que l'expression régulière soit trouvée.
"hup_string"
Retourne un identifiant unique qui peut être passé au processus ré-exécuté lors d'un HUP.
"show"
Dumper basique des propriétés stockées dans le glob.
"AUTOLOAD"
Gère les méthodes d'accesseur.

LICENCE

Distribué sous les mêmes termes que Net::Server
