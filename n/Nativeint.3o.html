Module Nativeint
: sig end

Entiers natifs du processeur.

Ce module fournit des opérations sur le type nativeint d'entiers signés de 32 bits (sur les plateformes 32 bits) ou d'entiers signés de 64 bits (sur les plateformes 64 bits). Ce type d'entier a exactement la même largeur qu'un type pointeur dans le compilateur C. Toutes les opérations arithmétiques sur nativeint sont effectuées modulo 2^32 ou 2^64 selon la taille du mot de l'architecture.

Remarque sur les performances : les valeurs de type nativeint occupent plus d'espace mémoire que les valeurs de type int , et les opérations arithmétiques sur nativeint sont généralement plus lentes que celles sur int . N'utilisez nativeint que lorsque l'application nécessite la précision supplémentaire par rapport au type int .

Les littéraux pour les entiers natifs sont suffixés par n :

     let zero: nativeint = 0n
     let one: nativeint = 1n
     let m_one: nativeint = -1n

val zero : nativeint

L'entier natif 0.

val one : nativeint

L'entier natif 1.

val minus_one : nativeint

L'entier natif -1.

val neg : nativeint -> nativeint

Négation unaire.

val add : nativeint -> nativeint -> nativeint

Addition.

val sub : nativeint -> nativeint -> nativeint

Soustraction.

val mul : nativeint -> nativeint -> nativeint

Multiplication.

val div : nativeint -> nativeint -> nativeint

Division entière. Cette division arrondit le quotient réel de ses arguments vers zéro, comme spécifié pour (/) .

Lève Division_by_zero si le deuxième argument est zéro.

val unsigned_div : nativeint -> nativeint -> nativeint

Identique à Nativeint.div , sauf que les arguments et le résultat sont interprétés comme des entiers natifs non signés.

Depuis 4.08

val rem : nativeint -> nativeint -> nativeint

Reste de la division entière. Si y est différent de zéro, le résultat de Nativeint.rem x y satisfait les propriétés suivantes : Nativeint.zero <= Nativeint.rem x y < Nativeint.abs y et x = Nativeint.add (Nativeint.mul (Nativeint.div x y) y)
(Nativeint.rem x y) . Si y = 0 , Nativeint.rem x y lève Division_by_zero .

val unsigned_rem : nativeint -> nativeint -> nativeint

Identique à Nativeint.rem , sauf que les arguments et le résultat sont interprétés comme des entiers natifs non signés.

Depuis 4.08

val succ : nativeint -> nativeint

Successeur. Nativeint.succ x est Nativeint.add x Nativeint.one .

val pred : nativeint -> nativeint

Prédécesseur. Nativeint.pred x est Nativeint.sub x Nativeint.one .

val abs : nativeint -> nativeint

abs x est la valeur absolue de x . Sur min_int c'est min_int lui-même et reste donc négatif.

val size : int

La taille en bits d'un entier natif. C'est 32 sur une plateforme 32 bits et 64 sur une plateforme 64 bits.

val max_int : nativeint

Le plus grand entier natif représentable, soit 2^31 - 1 sur une plateforme 32 bits, soit 2^63 - 1 sur une plateforme 64 bits.

val min_int : nativeint

Le plus petit entier natif représentable, soit -2^31 sur une plateforme 32 bits, soit -2^63 sur une plateforme 64 bits.

val logand : nativeint -> nativeint -> nativeint

ET logique bit à bit.

val logor : nativeint -> nativeint -> nativeint

OU logique bit à bit.

val logxor : nativeint -> nativeint -> nativeint

OU exclusif logique bit à bit.

val lognot : nativeint -> nativeint

Négation logique bit à bit.

val shift_left : nativeint -> int -> nativeint

Nativeint.shift_left x y décale x vers la gauche de y bits. Le résultat n'est pas spécifié si y < 0 ou y >= bitsize , où bitsize est 32 sur une plateforme 32 bits et 64 sur une plateforme 64 bits.

val shift_right : nativeint -> int -> nativeint

Nativeint.shift_right x y décale x vers la droite de y bits. C'est un décalage arithmétique : le bit de signe de x est répliqué et inséré dans les bits libérés. Le résultat n'est pas spécifié si y < 0 ou y >= bitsize .

val shift_right_logical : nativeint -> int -> nativeint

Nativeint.shift_right_logical x y décale x vers la droite de y bits. C'est un décalage logique : des zéros sont insérés dans les bits libérés, quel que soit le signe de x . Le résultat n'est pas spécifié si y < 0 ou y >= bitsize .

val of_int : int -> nativeint

Convertit l'entier donné (type int ) en un entier natif (type nativeint ).

val to_int : nativeint -> int

Convertit l'entier natif donné (type nativeint ) en un entier (type int ). Le bit de poids fort est perdu lors de la conversion.

val unsigned_to_int : nativeint -> int option

Identique à Nativeint.to_int , mais interprète l'argument comme un entier non signé. Retourne None si la valeur non signée de l'argument ne peut pas tenir dans un int .

Depuis 4.08

val of_float : float -> nativeint

Convertit le nombre à virgule flottante donné en un entier natif, en ignorant la partie fractionnaire (troncature vers zéro). Si le nombre à virgule flottante tronqué est en dehors de l'intervalle [ Nativeint.min_int , Nativeint.max_int ], aucune exception n'est levée, et un entier non spécifié et dépendant de la plateforme est retourné.

val to_float : nativeint -> float

Convertit l'entier natif donné en un nombre à virgule flottante.

val of_int32 : int32 -> nativeint

Convertit l'entier 32 bits donné (type int32 ) en un entier natif.

val to_int32 : nativeint -> int32

Convertit l'entier natif donné en un entier 32 bits (type int32 ). Sur les plateformes 64 bits, l'entier natif 64 bits est pris modulo 2^32, c'est-à-dire que les 32 bits supérieurs sont perdus. Sur les plateformes 32 bits, la conversion est exacte.

val of_string : string -> nativeint

Convertit la chaîne donnée en un entier natif. La chaîne est lue en décimal (par défaut, ou si la chaîne commence par 0u ) ou en hexadécimal, octal ou binaire si la chaîne commence par 0x , 0o ou 0b respectivement.

Le préfixe 0u lit l'entrée comme un entier non signé dans l'intervalle [0, 2*Nativeint.max_int+1] . Si l'entrée dépasse Nativeint.max_int , elle est convertie en l'entier signé Int64.min_int + input - Nativeint.max_int - 1 .

Lève Failure si la chaîne donnée n'est pas une représentation valide d'un entier, ou si l'entier représenté dépasse la plage des entiers représentables dans le type nativeint .

val of_string_opt : string -> nativeint option

Identique à of_string , mais retourne None au lieu de lever une exception.

Depuis 4.05

val to_string : nativeint -> string

Retourne la représentation sous forme de chaîne de son argument, en décimal.

type t = nativeint

Un alias pour le type des entiers natifs.

val compare : t -> t -> int

La fonction de comparaison pour les entiers natifs, avec la même spécification que compare . Avec le type t , cette fonction compare permet de passer le module Nativeint en argument aux functors Set.Make et Map.Make .

val unsigned_compare : t -> t -> int

Identique à Nativeint.compare , sauf que les arguments sont des entiers

NAME

Nativeint — unsigned native integers

Module

Nativeint

Documentation

This module provides functions for manipulating unsigned native integers.

Native integers are integers that have the same size as pointers on the target machine. They are represented as unsigned integers. Unsigned native integers are interpreted as native integers.

Since 4.08

val equal : t -> t -> bool

The equal function for native ints.

Since 4.03

val min : t -> t -> t

Return the smaller of the two arguments.

Since 4.13

val max : t -> t -> t

Return the greater of the two arguments.

Since 4.13

val seeded_hash : int -> t -> int

A seeded hash function for native ints, with the same output value as Hashtbl.seeded_hash . This function allows this module to be passed as argument to the functor Hashtbl.MakeSeeded .

Since 5.1

val hash : t -> int

An unseeded hash function for native ints, with the same output value as Hashtbl.hash . This function allows this module to be passed as argument to the functor Hashtbl.Make .

Since 5.1
