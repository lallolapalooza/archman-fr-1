NOM

Net::DNS::SEC::Tools::rolllog - Interfaces de journalisation pour DNSSEC-Tools.

SYNOPSIS

use Net::DNS::SEC::Tools::rolllog;
@levels = rolllog_levels();
$curlevel = rolllog_level();
$oldlevel = rolllog_level("info");
$oldlevel = rolllog_level(LOG_ERR,1);
$curlogfile = rolllog_file();
$oldlogfile = rolllog_file("-");
$oldlogfile = rolllog_file("/var/log/roll.log",1);
$loglevelstr = rolllog_str(8)
$loglevelstr = rolllog_str("info")
$ret = rolllog_num("info");
$bool = rolllog_validlevel($newlevel);
$bool = rolllog_validlevel(8);
$curtz = rolllog_gettz();
$oldtz = rolllog_settz('local');
rolllog_log(LOG_INFO,"example.com","zone is valid");

DESCRIPTION

Le module Net::DNS::SEC::Tools::rolllog fournit des interfaces de journalisation pour les programmes de rollover. Ces interfaces permettent d'enregistrer les messages de journalisation. rollerd doit être en cours d'exécution, car il est responsable de la mise à jour du fichier journal.

Chaque message de journal est affecté d'un niveau de journalisation particulier. Les niveaux de journalisation valides sont :

texte      numérique  signification
----       -------  -----------
tmi           1     Le niveau le plus élevé - tous les messages
                    de journal sont enregistrés.
expire        3     Un compte à rebours détaillé de l'expiration de la zone
                    est donné.
info          4     De nombreux messages informatifs sont enregistrés.
phase         6     La phase de rollover actuelle de chaque zone
                    est donnée.
err           8     Les erreurs sont enregistrées.
fatal         9     Les erreurs fatales sont enregistrées.

Les niveaux incluent tous les niveaux numériquement supérieurs. Par exemple, si le niveau de journalisation est réglé sur phase, les messages err et fatal seront également enregistrés.

INTERFACES DE JOURNALISATION

rolllog_file(newfile,useflag)
Cette routine définit et récupère le fichier journal pour rollerd. L'argument newfile spécifie le nouveau fichier journal à définir. Si newfile existe, il doit s'agir d'un fichier ordinaire.

L'argument useflag est une valeur booléenne qui indique s'il faut afficher un message descriptif si un fichier journal invalide est fourni. Si useflag est vrai, le message est affiché et le processus se termine ; sinon, aucun message n'est affiché. Pour toute condition d'erreur, une chaîne vide est retournée.

rolllog_gettz()
Cette routine retourne le sélecteur de fuseau horaire actuellement utilisé. Cette valeur peut être 'gmt' (pour l'heure de Greenwich) ou 'local' (pour l'heure locale de l'hôte).
rolllog_level(newlevel,useflag)
Cette routine définit et récupère le niveau de journalisation pour rollerd. L'argument newlevel spécifie le nouveau niveau de journalisation à définir. newlevel peut être fourni sous forme textuelle ou numérique.

L'argument useflag est une valeur booléenne qui indique s'il faut afficher un message descriptif et quitter si un niveau de journalisation invalide est fourni. Si useflag est vrai, le message est affiché et le processus se termine ; sinon, -1 est retourné.

Si elle est appelée sans arguments, le niveau de journalisation actuel est retourné. En fait, le niveau actuel est toujours retourné sauf en cas d'erreur. -1 est retourné en cas d'erreur.

rolllog_levels()
Cette routine retourne un tableau contenant les formes textuelles des niveaux de journalisation configurables par l'utilisateur. Les niveaux sont retournés dans l'ordre, du plus verbeux au moins verbeux.
rolllog_log(level,group,message)
L'interface rolllog_log() écrit un message dans le fichier journal. Les messages de journal ont le format suivant : 
horodatage: groupe: message

L'argument level est le niveau de journalisation du message. Il ne sera écrit dans le fichier journal que si le niveau de journalisation actuel est numériquement égal ou inférieur à level.

group permet d'associer des messages ensemble. Il est actuellement utilisé par rollerd pour regrouper les messages par zone à laquelle le message s'applique.

L'argument message est le message de journal lui-même. Les sauts de ligne finaux sont supprimés.

rolllog_num(loglevel)
Cette routine traduit un niveau de journal textuel (fourni dans loglevel) dans le niveau de journal numérique associé. Le niveau de journal numérique est retourné à l'appelant.

Si loglevel est un niveau de journal invalide, -1 est retourné.

rolllog_settz(tzsel)
Cette routine définit le fuseau horaire à utiliser pour les horodatages dans les messages écrits dans le journal. Cette valeur tzsel peut être 'gmt' (heure de Greenwich) ou 'local' (heure locale de l'hôte). tzsel peut être en majuscules ou minuscules ; la valeur sera convertie en minuscules. Si aucune valeur n'est passée, le défaut sera utilisé.

Le sélecteur de fuseau horaire actuel est retourné. Si un sélecteur invalide est fourni, une valeur indéfinie est retournée.

rolllog_str(loglevel)
Cette routine traduit un niveau de journal (fourni dans loglevel) dans le niveau de journal textuel associé. Le niveau de journal textuel est retourné à l'appelant.

Si loglevel est une chaîne de caractères textuelle, elle est vérifiée pour s'assurer qu'il s'agit d'un niveau de journal valide. La casse est sans importance lors de la vérification de loglevel.

Si loglevel est numérique, il doit se situer dans la plage valide des niveaux de journal. undef est retourné si loglevel est invalide.

rolllog_validlevel(level)
Cette interface retourne une valeur booléenne indiquant si le niveau de journalisation donné est valide.

L'argument level est le niveau de journalisation à valider. Il peut s'agir d'une valeur numérique ou textuelle.
