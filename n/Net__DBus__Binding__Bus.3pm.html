NOM

Net::DBus::Binding::Bus - Gère une instance de bus de messages bien connue

SYNOPSIS

use Net::DBus::Binding::Bus;
# Obtenir un gestionnaire du bus système
my $bus = Net::DBus::Binding::Bus->new(type => &Net::DBus::Binding::Bus::SYSTEM);

DESCRIPTION

Ceci est une spécialisation du module Net::DBus::Binding::Connection fournissant un constructeur pratique pour se connecter à l'un des types de bus bien connus. Il n'y a aucune raison d'utiliser ce module directement, récupérez plutôt un gestionnaire du bus avec les méthodes "session" ou "system" dans Net::DBus.

MÉTHODES

my $bus = Net::DBus::Binding::Bus->new(type => $type);
my $bus = Net::DBus::Binding::Bus->new(address => $addr);
Ouvre une connexion à un bus de messages, soit un type de bus bien connu spécifié en utilisant le paramètre "type", soit un bus arbitraire spécifié en utilisant le paramètre "address". Si le paramètre "private" est défini sur une valeur vraie, une connexion privée au bus est obtenue. L'appelant doit explicitement déconnecter cette instance de bus avant de libérer la dernière instance de l'objet.
$bus->request_name($service_name)
Envoie une requête au bus pour enregistrer le nom bien connu spécifié dans le paramètre $service_name. Si un autre client possède déjà le nom, l'enregistrement sera mis en file d'attente, en attendant la sortie de l'autre client.
my $name = $bus->get_unique_name
Retourne le nom unique par lequel la connexion de ce processus au bus est connue. Les noms uniques ne sont jamais réutilisés pendant toute la durée de vie du démon de bus.
$bus->add_match($rule)
Enregistre une règle de correspondance de signaux auprès du contrôleur de bus, permettant de router des signaux diffusés correspondants vers ce client.
$bus->remove_match($rule)
Désenregistre une règle de correspondance de signaux auprès du contrôleur de bus, empêchant le routage d'autres signaux diffusés vers ce client.
