NS_GET_USERNS(2const) NS_GET_USERNS(2const)

NOM

NS_GET_USERNS, NS_GET_PARENT - découvrir les relations entre espaces de noms

SYNOPIS

#include <linux/nsfs.h>  /* Définition des constantes NS_GET_* */
                                #include <sys/ioctl.h>
int ioctl(int fd, unsigned long op);

DESCRIPTION

Les opérations ioctl(2) suivantes sont fournies pour permettre la découverte des relations entre espaces de noms (voir user_namespaces(7) et pid_namespaces(7)).

Dans tous les cas, fd fait référence à un fichier /proc/pid/ns/*. Les deux opérations renvoient un nouveau descripteur de fichier en cas de succès.

NS_GET_USERNS
Renvoie un descripteur de fichier faisant référence à l'espace de noms utilisateur auquel l'espace de noms indiqué par fd fait référence. Si l'espace de noms indiqué par fd est l'espace de noms utilisateur initial, alors un descripteur de fichier faisant référence à l'espace de noms utilisateur de l'appelant est renvoyé.
NS_GET_PARENT
Renvoie un descripteur de fichier faisant référence à l'espace de noms parent de l'espace de noms indiqué par fd. Cette opération n'est valide que pour les espaces de noms hiérarchiques (c'est-à-dire les espaces de noms PID et utilisateur). Pour les espaces de noms utilisateur, NS_GET_PARENT est équivalent à NS_GET_USERNS.

Le nouveau descripteur de fichier renvoyé par ces opérations est ouvert avec les drapeaux O_RDONLY et O_CLOEXEC (close-on-exec ; voir fcntl(2)).

L'application de fstat(2) sur le descripteur de fichier renvoyé, donne une structure stat dont st_dev (périphérique résident) et st_ino (numéro d'inode) sont utilisés ensemble pour identifier l'espace de noms utilisateur/parent. Ce numéro d'inode peut correspondre au numéro d'inode d'un autre fichier /proc/pid/ns/{pid,user} pour déterminer s'il s'agit de l'espace de noms utilisateur/parent.

VALEUR RENVOYÉE

Un descripteur de fichier est renvoyé en cas de succès. En cas d'erreur, -1 est renvoyé et errno est définie pour indiquer l'erreur.

ERREURS

EPERM
L'espace de noms demandé est en dehors de la portée de l'espace de noms de l'appelant. Cela peut se produire, par exemple, si l'espace de noms utilisateur référencé est un ancêtre de l'espace de noms actuel de l'appelant. Cela peut également se produire lors de la tentative d'obtention du parent de l'espace de noms utilisateur initial ou de l'espace de noms PID initial.
ENOTTY
L'opération n'est pas prise en charge sur ce noyau.

De plus, l'opération NS_GET_PARENT peut échouer avec l'erreur suivante :

EINVAL
fd fait référence à un espace de noms non hiérarchique.

NORMES

Linux.

HISTORIQUE

NS_GET_USERNS
Linux 4.9.
NS_GET_PARENT
Linux 4.9.

EXEMPLES

L'exemple présenté utilise les opérations ioctl(2) décrites ci-dessus pour effectuer une découverte simple des relations entre espaces de noms. Les sessions de shell suivantes montrent plusieurs exemples d'utilisation de ce programme.

Tenter d'obtenir le parent de l'espace de noms utilisateur initial échoue, car il n'a pas de parent :

$ ./ns_show /proc/self/ns/user p

Créer un processus qui se trouve dans un nouvel espace de noms utilisateur et UTS, et montrer que le nouvel espace de noms UTS est associé au nouvel espace de noms utilisateur :

$ unshare -Uu sleep 1000 &

$ ./ns_show /proc/23235/ns/uts u

Ensuite, montrer que le parent du nouvel espace de noms utilisateur dans l'exemple ci-dessus est l'espace de noms utilisateur initial :

$ readlink /proc/self/ns/user

Démarrer un shell dans un nouvel espace de noms utilisateur et montrer que depuis ce shell, vous ne pouvez pas découvrir l'espace de noms utilisateur parent. De même, l'espace de noms UTS (associé à l'espace de noms utilisateur initial) ne peut pas être découvert.

$ PS1="sh2$ " unshare -U bash
$ ./ns_show /proc/self/ns/user p
$ ./ns_show /proc/self/ns/uts u

Code source du programme

/* ns_show.c
           Sous licence GNU General Public License v2 ou ultérieure.
       */
#include <errno.h>
#include <fcntl.h>
#include <linux/nsfs.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/ioctl.h>
#include <sys/stat.h>
#include <sys/sysmacros.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int          fd, userns_fd, parent_fd;
    struct stat  sb;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s /proc/[pid]/ns/[file] [p|u]\n", argv[0]);
        fprintf(stderr, "\nAffiche le résultat d'une ou des deux opérations NS_GET_USERNS (u) ou NS_GET_PARENT (p) pour le fichier spécifié dans /proc/[pid]/ns/[file]. Si ni 'p' ni 'u' n'est spécifié, la valeur par défaut est NS_GET_USERNS.\n");
        exit(EXIT_FAILURE);
    }
    /* Obtenir un descripteur de fichier pour le fichier 'ns' spécifié dans argv[1]. */
    fd = open(argv[1], O_RDONLY);
    if (fd == -1) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    /* Obtenir un descripteur de fichier pour l'espace de noms utilisateur, puis obtenir et afficher le numéro d'inode de cet espace de noms. */
    if (argc < 3 || strchr(argv[2], 'u')) {
        userns_fd = ioctl(fd, NS_GET_USERNS);
        if (userns_fd == -1) {
            if (errno == EPERM)
                printf("L'espace de noms utilisateur référencé est hors de portée de votre espace de noms\n");
            else
                perror("ioctl-NS_GET_USERNS");
            exit(EXIT_FAILURE);
        }
        if (fstat(userns_fd, &sb) == -1) {
            perror("fstat-userns");
            exit(EXIT_FAILURE);
        }
        printf("Le numéro de périphérique/inode de l'espace de noms utilisateur est : [%x,%x] / %ju\n", major(sb.st_dev), minor(sb.st_dev), (uintmax_t) sb.st_ino);
        close(userns_fd);
    }
    /* Obtenir un descripteur de fichier pour l'espace de noms parent, puis obtenir et afficher le numéro d'inode de cet espace de noms. */
    if (argc > 2 && strchr(argv[2], 'p')) {
        parent_fd = ioctl(fd, NS_GET_PARENT);
        if (parent_fd == -1) {
            if (errno == EINVAL)
                printf("Impossible d'obtenir l'espace de noms parent d'un espace de noms non hiérarchique\n");
            else if (errno == EPERM)
                printf("L'espace de noms parent est hors de portée de votre espace de noms\n");
            else
                perror("ioctl-NS_GET_PARENT");
            exit(EXIT_FAILURE);
        }
        if (fstat(parent_fd, &sb) == -1) {
            perror("fstat-parentns");
            exit(EXIT_FAILURE);
        }
        printf("Le numéro de périphérique/inode de l'espace de noms parent est : [%x,%x] / %ju\n", major(sb.st_dev), minor(sb.st_dev), (uintmax_t) sb.st_ino);
        close(parent_fd);
    }
    exit(EXIT_SUCCESS);
}
