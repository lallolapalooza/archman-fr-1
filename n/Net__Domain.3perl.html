NOM

Net::Domain - Tenter d'évaluer le nom d'hôte Internet et le domaine actuels

SYNOPIS

use Net::Domain qw(hostname hostfqdn hostdomain domainname);

DESCRIPTION

Utilise diverses méthodes pour tenter de trouver le nom de domaine pleinement qualifié (FQDN) de l'hôte actuel. À partir de cela, détermine le nom d'hôte et le domaine d'hôte.

Chacune des fonctions retournera undef si le FQDN ne peut pas être déterminé.

Fonctions

hostfqdn()
Identifie et retourne le FQDN de l'hôte actuel.
domainname()
Un alias pour hostfqdn().
hostname()
Retourne la plus petite partie du FQDN qui peut être utilisée pour identifier l'hôte.
hostdomain()
Retourne le reste du FQDN après que le nom d'hôte ait été supprimé.
