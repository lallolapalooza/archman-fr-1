NOM

Net::LDAP::Control::Paged - objet de contrôle de résultats paginés LDAPv3

SYNOPIS

use Net::LDAP;
use Net::LDAP::Control::Paged;
use Net::LDAP::Constant qw( LDAP_CONTROL_PAGED );
$ldap = Net::LDAP->new( "ldap.mondomaine.eg" );
$page = Net::LDAP::Control::Paged->new( size => 100 );
@args = ( base     => "cn=subnets,cn=sites,cn=configuration,$BASE_DN",
          scope    => "subtree",
          filter   => "(objectClass=subnet)",
          callback => \&process_entry, # Appel de ce sous-programme pour chaque entrée
          control  => [ $page ],
);
my $cookie;
while (1) {
  # Effectuer la recherche
  my $mesg = $ldap->search( @args );
  # Continuer uniquement en cas de LDAP_SUCCESS
  $mesg->code  and last;
  # Obtenir le cookie du contrôle paginé
  my($resp)  = $mesg->control( LDAP_CONTROL_PAGED )  or last;
  $cookie    = $resp->cookie;
  # Continuer uniquement si le cookie n'est pas vide (= nous n'avons pas terminé)
  last  if (!defined($cookie) || !length($cookie));
  # Définir le cookie dans le contrôle paginé
  $page->cookie($cookie);
}
if (defined($cookie) && length($cookie)) {
  # Nous avons eu une sortie anormale, donc informons le serveur que nous ne voulons plus rien
  $page->cookie($cookie);
  $page->size(0);
  $ldap->search( @args );
}

DESCRIPTION

"Net::LDAP::Control::Paged" fournit une interface pour la création et la manipulation d'objets représentant le "pagedResultsControl" tel que décrit par la RFC 2696.

Le contrôle est autorisé uniquement sur les requêtes de recherche LDAP ("search" dans Net::LDAP). Sur les autres opérations, il sera - selon la valeur du paramètre "critical" - soit ignoré, soit entraînera des erreurs.

ARGUMENTS DU CONSTRUCTEUR

En plus des arguments du constructeur décrits dans Net::LDAP::Control, les suivants sont fournis.

cookie
La valeur à utiliser comme cookie. Elle n'est normalement pas définie lors de la création d'un objet, mais est définie à partir de la valeur du cookie renvoyée par le serveur. Cela associe une recherche à une recherche précédente, afin que le serveur sache renvoyer la page d'entrées suivant les entrées qu'il a renvoyées la fois précédente.
size
La taille de page requise. C'est le nombre maximum d'entrées que le serveur renverra à la requête de recherche.

MÉTHODES

Comme pour Net::LDAP::Control, chaque argument du constructeur décrit ci-dessus est également disponible comme méthode sur l'objet qui renverra la valeur actuelle de l'attribut s'il est appelé sans argument, et définira une nouvelle valeur pour l'attribut s'il est appelé avec un argument.
