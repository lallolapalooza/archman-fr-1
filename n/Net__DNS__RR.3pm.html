Net::DNS::RR(3) Documentation soumise par les utilisateurs Perl Net::DNS::RR(3)

NOM

Net::DNS::RR - Classe de base pour les enregistrements de noms (RR) DNS

SYNOPHIS

use Net::DNS;
$rr = Net::DNS::RR->new('example.com IN AAAA 2001:DB8::1');
$rr = Net::DNS::RR->new(
                owner   => 'example.com',
                type    => 'AAAA',
                address => '2001:DB8::1'
                );

DESCRIPTION

Net::DNS::RR est la classe de base pour les objets d'enregistrement de noms (RR) DNS. Voir aussi les pages de manuel pour chaque type spécifique de RR.

MÉTHODES

ATTENTION !!! Ne supposez pas que les objets RR que vous recevez d'une requête sont d'un type particulier. Vous devez toujours vérifier le type d'objet avant d'appeler une méthode quelconque. Si vous appelez une méthode inconnue, vous recevrez un message d'erreur et le programme se terminera.

new (depuis une chaîne)

$aaaa   = Net::DNS::RR->new('host.example.com. 86400 AAAA 2001:DB8::1');
$mx     = Net::DNS::RR->new('example.com. 7200 MX 10 mailhost.example.com.');
$cname  = Net::DNS::RR->new('www.example.com 300 IN CNAME host.example.com');
$txt    = Net::DNS::RR->new('txt.example.com 3600 HS TXT "text data"');

Retourne un objet RR du type approprié, ou un objet Net::DNS::RR si le type n'est pas implémenté. Les valeurs des attributs sont extraites de la chaîne fournie par l'utilisateur. La syntaxe des arguments suit la spécification RFC1035 pour les fichiers de zone et est compatible avec le résultat renvoyé par la méthode string.

Le propriétaire et le type de RR sont obligatoires ; tout le reste est facultatif. Omettre les champs facultatifs est utile pour créer les sections de données vides nécessaires à certaines opérations de mise à jour dynamique. Voir la page de manuel Net::DNS::Update pour des exemples supplémentaires.

Tous les noms sont interprétés comme des noms de domaine entièrement qualifiés. Le point final (.) est facultatif.

new (depuis une table de hachage)

$rr = Net::DNS::RR->new(%hash);
$rr = Net::DNS::RR->new(
                owner   => 'host.example.com',
                ttl     => 86400,
                class   => 'IN',
                type    => 'AAAA',
                address => '2001:DB8::1'
                );

$rr = Net::DNS::RR->new(
                owner   => 'txt.example.com',
                type    => 'TXT',
                txtdata => [ 'one', 'two' ]
                );

Retourne un objet RR du type approprié, ou un objet Net::DNS::RR si le type n'est pas implémenté. Consultez les pages de manuel correspondantes pour l'utilisation des attributs spécifiques au type.

Le propriétaire et le type de RR sont obligatoires ; tout le reste est facultatif. Omettre les attributs facultatifs est utile pour créer les sections de données vides nécessaires à certaines opérations de mise à jour dynamique.

decode

( $rr, $next ) = Net::DNS::RR->decode( \$data, $offset, @opaque );

Décode un enregistrement de nom (RR) à l'emplacement spécifié dans un paquet DNS.

L'argument se compose d'une référence au tampon contenant les données du paquet et d'un décalage indiquant où commence l'enregistrement de nom (RR). Tous les arguments restants sont transmis comme données opaques aux décodeurs descendants et ne font pas partie de l'interface publique.

Retourne un objet "Net::DNS::RR" et le décalage du prochain enregistrement dans le paquet.

Une exception est levée si le tampon de données contient des données insuffisantes ou corrompues.

encode

$data = $rr->encode( $offset, @opaque );

Retourne la représentation binaire "Net::DNS::RR" appropriée pour inclusion dans un tampon de paquet DNS.

Le décalage indique l'emplacement souhaité dans les données du paquet où le "Net::DNS::RR" doit être stocké.

Tous les arguments restants sont des données opaques qui sont transmises intactes aux encodeurs descendants.

canonical

$data = $rr->canonical;

Retourne la représentation binaire "Net::DNS::RR" appropriée pour la validation des signatures DNSSEC.

L'absence d'un argument d'association indique aux encodeurs descendants que la forme non compressée du nom de domaine intégré doit être utilisée.

print

$rr->print;

Imprime l'enregistrement de nom (RR) sur le flux de sortie actuel. Appelle la méthode string pour obtenir la représentation formatée du RR.

string

print $rr->string, "\n";

Retourne une représentation sous forme de chaîne du RR suivant le format de fichier de zone exigé par RFC1035. Tous les noms de domaine sont interprétés comme des noms entièrement qualifiés avec un point final. Ceci diffère des méthodes d'attributs RR, qui omettent le point final.

plain

$plain = $rr->plain;

Retourne une représentation simplifiée sur une seule ligne du RR. Cela facilite l'interaction avec des programmes tels que nsupdate qui possèdent des analyseurs rudimentaires.

token

@token = $rr->token;

Retourne une liste de jetons représentant la chaîne de fichier de zone.

generic

$generic = $rr->generic;

Retourne la représentation générique du RR définie dans RFC3597. Ceci facilite la création de fichiers de zone avec des RR non reconnus par les anciens serveurs et les logiciels de provisionnement.

nom du propriétaire

$name = $rr->owner;

Retourne le nom du propriétaire de l'enregistrement.

type

$type = $rr->type;

Retourne le type de l'enregistrement.

classe

$class = $rr->class;

Classe de l'enregistrement de nom (RR).

ttl

$ttl = $rr->ttl;
$ttl = $rr->ttl(3600);

Durée de vie de l'enregistrement de nom (RR) en secondes.

rdata

$rr = Net::DNS::RR->new( type => NULL, rdata => 'arbitrary' );

Section de données du RR lorsqu'elle est considérée comme des octets non compressés.

rdstring

$rdstring = $rr->rdstring;

Retourne une représentation sous forme de chaîne des données spécifiques au RR.

rdlength

$rdlength = $rr->rdlength;

Retourne la longueur non compressée des données spécifiques au RR.

Tri de tableaux de RR

Le tri des tableaux de RR s'effectue à l'aide de Net::DNS::rrsort(), voir la documentation de Net::DNS. Ce paquet fournit des méthodes de classe pour définir la fonction de comparaison utilisée pour un RR particulier selon ses attributs.

set_rrsort_func

my $function = sub {    ## tri numérique ascendant
        $Net::DNS::a->{'preference'} <=> $Net::DNS::b->{'preference'};
        };
Net::DNS::RR::MX->set_rrsort_func( 'preference', $function );
Net::DNS::RR::MX->set_rrsort_func( 'default_sort', $function );

set_rrsort_func() doit être appelé en tant que méthode de classe. Le premier argument est le nom de l'attribut sur lequel le tri sera effectué. Si vous spécifiez « default_sort », alors cet algorithme de tri sera utilisé lorsque get_rrsort_func() sera appelé sans argument d'attribut RR.

Le deuxième argument est une référence à une fonction de comparaison qui utilise les variables globales $a et $b.

Net::DNS::RR::MX(3pm)

NAME

Net::DNS::RR::MX - Resource Record Man-in-the-Middle

SYNOPSIS

    use Net::DNS;
    
    my $mx = Net::DNS::RR::MX->new(
        name => 'example.com.',
        type => 'MX',
        ttl => 3600,
        preference => 10,
        exchange => 'mail.example.com.'
    );
    
    print $mx->string();

DESCRIPTION

The MX (Mail eXchanger) Resource Record type is used to specify mail servers for a domain name.

Net::DNS::RR::MX is a subclass of Net::DNS::RR.

METHODS

exchange
Get or set the mail server name (the value of the exchange field).
preference
Get or set the preference value (the value of the preference field). Lower numbers indicate higher preference.

Sorting of RR arrays

Net::DNS::RR::MX implements a sort method based on the preference field. It sorts in ascending order of preference.

The following example shows how to sort an array of MX RRs:

    use Net::DNS;
    
    my $mx_rr1 = Net::DNS::RR::MX->new(
        name => 'example.com.',
        type => 'MX',
        ttl => 3600,
        preference => 20,
        exchange => 'mail2.example.com.'
    );
    my $mx_rr2 = Net::DNS::RR::MX->new(
        name => 'example.com.',
        type => 'MX',
        ttl => 3600,
        preference => 10,
        exchange => 'mail1.example.com.'
    );
    
    my @mx_array = ($mx_rr1, $mx_rr2);
    
    # Sort the MX records by preference
    Net::DNS::RR::MX->set_rrsort_func( \&sort_mx );
    @mx_array = Net::DNS::RR::MX->rr_sort(\@mx_array);
    
    # The sorted array will be: [$mx_rr2, $mx_rr1]
    
    sub sort_mx {
        my ($a, $b) = @_;
        return $a->preference() <=> $b->preference();
    }

The set_rrsort_func() method is inherited from Net::DNS::RR.

The sorting function should take two arguments, $a and $b, which will contain references to objects of the class for which the set_rrsort_func() was called.

The sorting function will only be applied to Net::DNS::RR::MX objects.

The above sorting function is the one implemented in MX.

get_rrsort_func

$function = Net::DNS::RR::MX->get_rrsort_func('preference');
$function = Net::DNS::RR::MX->get_rrsort_func();

get_rrsort_func() returns a reference to the comparator function.
