NOM

Net::DNS::RR::EUI48 - enregistrement de ressource DNS EUI48

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name IN EUI48 address');
$rr = Net::DNS::RR->new(
                name    => 'example.com',
                type    => 'EUI48',
                address => '00-00-5e-00-53-2a'
                );

DESCRIPTION

Enregistrements de ressource DNS pour les Identifiants Uniques Étendus (EUI48) sur 48 bits.

L'enregistrement de ressource EUI48 est utilisé pour représenter les Identifiants Uniques Étendus IEEE utilisés dans divers réseaux de couche 2, comme Ethernet.

Les adresses EUI48 NE DEVRAIENT PAS être publiées dans le DNS public. La RFC7043 décrit des implications potentielles graves pour la vie privée résultant de la publication indiscriminée d'adresses de couche liaison dans le DNS.
