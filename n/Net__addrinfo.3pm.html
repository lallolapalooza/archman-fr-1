NOM

Net::addrinfo - interface vers getaddrinfo(3) POSIX et constantes, structures et fonctions associées.

SYNOPHIS

use Net::addrinfo;
my $ainfo = getaddrinfo("www.marzot.net");

DESCRIPTION

Ce module Perl est conçu pour implémenter et exporter des fonctionnalités liées à l'appel système POSIX getaddrinfo(3). L'objet de données Net::addrinfo est fourni avec des fonctions d'accès aux champs, nommées de manière similaire à la définition de la structure de données C dans netdb.h. Les appels getaddrinfo(3), gai_strerror(3), et les constantes associées sont exportés.

La routine getaddrinfo() imite la fonction documentée par POSIX (voir la page de manuel système getaddrinfo(3)).

En cas de succès, getaddrinfo() retournera un tableau d'objets de données Net::addrinfo.

En contexte scalaire, getaddrinfo() retournera le premier élément du tableau Net::addrinfo.

En cas d'erreur, un code d'erreur numérique est retourné.

Le code d'erreur peut être passé à gai_strerror() pour obtenir une représentation textuelle de l'erreur.

De nouveaux objets Net::addrinfo peuvent être créés avec le constructeur du package et n'importe quel nombre (ou aucun) de champs peuvent être spécifiés.

flags => entier scalaire
family => entier scalaire (par ex. AF_INET,m AF_INET6, etc.)
socktype => entier scalaire (par ex. SOCK_DGRAM, SOCK_STREAM, etc.)
protocol => entier scalaire (par ex. IPPROTO_UDP, IPPROTO_TCP, etc.)
addrlen => entier scalaire (peut être calculé par length($self->addr))
addr => octets empaquetés (par ex. $self->addr(inet_aton("192.168.1.1"))); )

Les drapeaux peuvent être définis dans la structure afin qu'elle puisse être utilisée comme paramètre 'hint' pour la fonction getaddrinfo(). Voir la liste des constantes acceptables exportées dans @AI_FLAGS.

(Note : un champ scalaire entier spécial, 'val_status', est fourni pour supporter les résultats addrinfo sensibles à DNSSEC (voir Net::DNS::SEC::Validator))

EXEMPLES

use Net::addrinfo;
use Socket qw(:all);
my $hint = new Net::addrinfo(flags => AI_CANONNAME,
                             family => AF_INET, 
                             socktype => SOCK_DGRAM);
my (@ainfo) = getaddrinfo("www.marzot.net", "http", $hint);
foreach $ainfo (@ainfo) {
   if (ref $ainfo eq 'Net::addrinfo') {
      print $ainfo->stringify(), "\n";
      print "addr = ", inet_ntoa($ainfo->addr), "\n";
      ...
      connect(SH, $ainfo->addr);
    } else {
       print "Error($ainfo):", gai_strerror($ainfo), "\n";
    }
}

NOTE

Il ne faut pas se fier à la représentation interne de cette classe.
