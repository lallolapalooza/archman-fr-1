Net::DNS::Question(3) Documentation Perl fournie par l'utilisateur Net::DNS::Question(3)

NOM

Net::DNS::Question - enregistrement de question DNS

SYNTAXE

use Net::DNS::Question;
$question = Net::DNS::Question->new('example.com', 'AAAA', 'IN');

DESCRIPTION

Un objet Net::DNS::Question représente un enregistrement dans la section de question d'un paquet DNS.

MÉTHODES

new

$question = Net::DNS::Question->new('example.com', 'AAAA', 'IN');
$question = Net::DNS::Question->new('example.com', 'A', 'IN');
$question = Net::DNS::Question->new('example.com');
$question = Net::DNS::Question->new('2001::DB8::dead:beef', 'PTR', 'IN');
$question = Net::DNS::Question->new('2001::DB8::dead:beef');

Crée un objet question à partir du domaine, du type et de la classe passés en arguments. Un ou deux des arguments type et class peuvent être omis et prendront les valeurs par défaut indiquées ci-dessus.

La notation d'adresse/préfixe IP RFC4291 et RFC4632 est prise en charge pour les requêtes dans les espaces de noms in-addr.arpa et ip6.arpa.

decode

$question = Net::DNS::Question->decode(\$data, $offset);
($question, $offset) = Net::DNS::Question->decode(\$data, $offset);

Décode l'enregistrement de question à l'emplacement spécifié dans un paquet DNS au format binaire. Le premier argument est une référence vers le tampon contenant les données du paquet. Le second argument est le décalage du début de l'enregistrement de question.

Retourne un objet Net::DNS::Question et le décalage de l'emplacement suivant dans le paquet.

Une exception est levée si l'objet ne peut pas être créé (par exemple, données corrompues ou insuffisantes).

encode

$data = $question->encode( $offset, $hash );

Retourne le Net::DNS::Question au format binaire approprié pour l'inclusion dans un tampon de paquet DNS.

Les arguments optionnels sont le décalage dans les données du paquet où le Net::DNS::Question doit être stocké et une référence à une table de hachage utilisée pour indexer les noms compressés dans le paquet.

string

print "string = ", $question->string, "\n";

Retourne une représentation sous forme de chaîne de l'enregistrement de question.

print

$object->print;

Imprime l'enregistrement sur la sortie standard. Appelle la méthode string() pour obtenir la représentation sous forme de chaîne.

name

$name = $question->name;

Nom de domaine internationalisé correspondant à l'attribut qname.

Le décodage des noms de domaine non ASCII est coûteux en calcul et indésirable pour les noms susceptibles d'être utilisés pour construire d'autres requêtes.

Lorsqu'il est nécessaire de communiquer avec des humains, le nom de domaine 'propre' doit être extrait d'un paquet de requête ou de réponse.

$query = Net::DNS::Packet->new( $example, 'SOA' );
$reply = $resolver->send($query) or die;
($question) = $reply->question;
$name = $question->name;

qname, zname

$qname = $question->qname;
$zname = $question->zname;

Nom de domaine pleinement qualifié dans le format requis pour une requête transmise à un serveur de noms. Dans les paquets de mise à jour dynamique, cet attribut est connu sous le nom de zname() et fait référence au nom de la zone.

qtype, ztype, type

$qtype = $question->type;
$qtype = $question->qtype;
$ztype = $question->ztype;

Retourne l'attribut de type de question. Dans les paquets de mise à jour dynamique, cet attribut est connu sous le nom de ztype() et fait référence au type de zone.

qclass, zclass, class

$qclass = $question->class;
$qclass = $question->qclass;
$zclass = $question->zclass;

Retourne l'attribut de classe de question. Dans les paquets de mise à jour dynamique, cet attribut est connu sous le nom de zclass() et fait référence à la classe de zone.
