NOM

Net::LDAP::Filter - représentation des filtres LDAP

SYNOPIS

use Net::LDAP::Filter;
$filtre = Net::LDAP::Filter->new( $chaine_filtre );

DESCRIPTION

L'objet Net::LDAP::Filter vous permet de manipuler directement les filtres LDAP sans vous soucier de leur représentation textuelle et de tous les mécanismes d'échappement associés.

CONSTRUCTEUR

new ( [ FILTRE ] )
Crée un nouvel objet. Si FILTRE est fourni, il est analysé.

MÉTHODES

parse ( FILTRE )
Analyse FILTRE, mettant à jour l'objet pour le représenter.
as_string
Retourne le filtre sous forme de texte.
print ( [ FH ] )
Imprime la représentation textuelle du filtre sur FH, ou sur le descripteur de fichier de sortie actuellement sélectionné si FH n'est pas fourni.
negate ( )
Néga/inverse logiquement l'objet filtre de sorte qu'il corresponde à l'ensemble opposé d'entrées par rapport à l'original.

Au lieu de simplement nier la forme textuelle en l'entourant de l'opérateur not, la négation est effectuée en appliquant récursivement la loi de De Morgan.

Voici un exemple :

(|(&(cn=A)(cn=B))(|(!(cn=C))(cn=D)))

est nié en

(&(|(!(cn=A))(!(cn=B)))(&(cn=C)(!(cn=D))))

SYNTAXE DU FILTRE

Ci-dessous se trouve la syntaxe d'un filtre donnée dans la RFC 4515 http://www.ietf.org/rfc/rfc4515.txt

filter       = "(" filtercomp ")"
filtercomp   = and / or / not / item
and          = "&" filterlist
or           = "|" filterlist
not          = "!" filter
filterlist   = 1*filter
item         = simple / present / substring / extensible
simple       = attr filtertype value
filtertype   = equal / approx / greater / less
equal        = "="
approx       = "~="
greater      = ">="
less         = "<="
extensible   = attr [":dn"] [":" matchingrule] ":=" value
               / [":dn"] ":" matchingrule ":=" value
present      = attr "=*"
substring    = attr "=" [initial] any [final]
initial      = value
any          = "*" *(value "*")
final        = value
attr         = AttributeDescription from Section 4.1.4 of RFC 4511
matchingrule = MatchingRuleId from Section 4.1.8 of RFC 4511
value        = AttributeValue from Section 4.1.5 of RFC 4511
Special Character encodings
---------------------------
   *               \2a, \*
   (               \28, \(
   )               \29, \)
   \               \5c, \\
   NUL             \00
