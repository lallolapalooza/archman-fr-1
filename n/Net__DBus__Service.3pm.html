Net__DBus__Service(3pm)

Net::DBus::Service(3) Documentation Perl fournie par la communauté Net::DBus::Service(3)

NOM

Net::DBus::Service - Fournir un service sur le bus pour que les clients puissent l'utiliser

SYNTAXE

package main;
use Net::DBus;
# Se connecter au bus
my $bus = Net::DBus->find;
# Acquérir un service 'org.demo.Hello'
my $service = $bus->export_service("org.demo.Hello");
# Exporter notre objet dans le service
my $object = Demo::HelloWorld->new($service);
....reste du programme...

DESCRIPTION

Ce module représente un service qui est exporté sur le bus de messages. Une fois qu'un service a été exporté, il est possible de créer et d'exporter des objets sur le bus.

MÉTHODES

my $service = Net::DBus::Service->new($bus, $name);
Crée un nouveau service, en se connectant au bus fourni dans le paramètre $bus, qui doit être une instance de l'objet Net::DBus. Le paramètre $name est le nom qualifié du service. Il n'est généralement pas nécessaire d'utiliser ce constructeur, car les services peuvent être créés via la méthode "export_service" sur l'objet Net::DBus.

Lorsque $name n'est pas spécifié ou est "undef", le handle retourné pour le service est identifié uniquement par le nom unique de la connexion du client au bus.

my $bus = $service->get_bus;
Récupère l'objet Net::DBus auquel ce service est attaché.
my $name = $service->get_service_name
Récupère le nom qualifié par lequel ce service est connu sur le bus.
