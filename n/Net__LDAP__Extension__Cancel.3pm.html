Net::LDAP::Extension::Cancel(3) Documentation Perl fournie par l'utilisateur Net::LDAP::Extension::Cancel(3)

NOM

Net::LDAP::Extension::Cancel - Opération de l'extension LDAP Annuler

SYNTAXE

use Net::LDAP;
use Net::LDAP::Constant qw(LDAP_SUCCESS LDAP_CANCELED)
use Net::LDAP::Extension::Cancel;
$ldap = Net::LDAP->new( 'ldap.mydomain.eg' );
$ldap->bind('cn=Joe User,cn=People,dc=example,dc=com',
            password => 'secret');
$search = $ldap->search(
                       base     => 'c=US',
                       filter   => '(&(sn=Barr) (o=Texas Instruments))',
                       callback => \&process_entry, # Appel de cette sous-routine pour chaque entrée
                     );
$mesg = $ldap->cancel($search);
die "erreur :", $mesg->code(), ": ", $mesg->error()
  if ($mesg->code() != LDAP_CANCELED && mesg->code() != LDAP_SUCCESS);

DESCRIPTION

"Net::LDAP::Extension::Cancel" implémente l'opération étendue LDAPv3 "Cancel" décrite dans la RFC 3909.

L'opération étendue "Cancel" est très similaire à l'opération standard "Abandon" et a la même signature d'appel. Contrairement à l'opération "Abandon", elle a une réponse qui indique son résultat.

Elle n'implémente aucun objet par elle-même mais étend l'objet Net::LDAP avec une autre méthode :

MÉTHODES

annuler ( OPÉRATION, OPTIONS )
Annule une opération en cours. "OPÉRATION" peut être un nombre ou un objet qui est une sous-classe de Net::LDAP::Message, retourné par un appel de méthode précédent.

OPTIONS est une liste de paires clé/valeur. Les clés suivantes sont reconnues :

contrôle => CONTRÔLE
contrôle => [ CONTRÔLE, .. ]
Contrôle(s) à passer à l'opération.

VOIR AUSSI

Net::LDAP, Net::LDAP::Extension
