NOM

Net::DNS::RR::NSEC3 - Enregistrement de ressource DNS NSEC3

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new('name NSEC3 algorithm flags iterations salt hnxtname');

DESCRIPTION

Classe pour les enregistrements de ressources DNS NSEC3.

L'enregistrement de ressource DNS NSEC3 (RR) fournit une dénégation d'existence authentifiée pour les ensembles de ressources DNS.

L'enregistrement NSEC3 RR liste les types de ressources présents sur le nom d'origine de l'enregistrement NSEC3. Il comprend le nom de propriétaire haché suivant dans l'ordre de hachage de la zone. L'ensemble complet des enregistrements NSEC3 RR dans une zone indique quels RRsets existent pour le nom d'origine de l'enregistrement et forment une chaîne de noms hachés dans la zone.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, hormis les méthodes spécifiques définies dans ce paquet.

L'utilisation de fonctionnalités non documentées du paquet ou l'accès direct aux structures internes est déconseillé et pourrait entraîner l'arrêt du programme ou des comportements imprévus.

algorithm

$algorithm = $rr->algorithm;
$rr->algorithm( $algorithm );

Le champ algorithme de 8 bits est représenté sous forme d'entier décimal non signé, mais peut être spécifié en utilisant simplement le nom de l'algorithme.

algorithm() peut également être appelé en tant que méthode de classe ou fonction simple pour effectuer la traduction entre mnémoniques et numériques.

flags

$flags = $rr->flags;
$rr->flags( $flags );

Le champ Flags est représenté sous forme d'entier décimal non signé qui est interprété comme huit valeurs booléennes concaténées.

optout
$rr->optout(1);
if ( $rr->optout ) {
        ...
}

Indicateur Opt Out booléen.

iterations

$iterations = $rr->iterations;
$rr->iterations( $iterations );

Le champ Iterations est représenté sous forme d'entier décimal non signé. La valeur est comprise entre 0 et 65535 inclus.

salt

$salt = $rr->salt;
$rr->salt( $salt );

Le champ Salt est représenté sous forme d'une séquence continue de chiffres hexadécimaux. Un signe moins (-) (sans guillemets) sous forme de chaîne est utilisé pour indiquer que le champ salt est absent.

saltbin

$saltbin = $rr->saltbin;
$rr->saltbin( $saltbin );

Le champ Salt sous forme de séquence d'octets.

hnxtname

$hnxtname = $rr->hnxtname;
$rr->hnxtname( $hnxtname );

Le Nom de Propriétaire Haché Suivant indique le nœud suivant qui a des données faisant autorité ou qui contient un point de délégation NS RRset.

typelist

@typelist = $rr->typelist;
$typelist = $rr->typelist;
$rr->typelist( @typelist );

typelist() identifie les types de RRset qui existent sur le nom de domaine correspondant à l'enregistrement NSEC3. Lors d'un appel en contexte scalaire, la liste est interpolée dans une chaîne.

typemap

$exists = $rr->typemap($rrtype);

typemap() renvoie une valeur booléenne vraie si le type de RR spécifié apparaît dans la bitmap des types de l'enregistrement NSEC3.

match

$matched = $rr->match( 'example.foo' );

match() renvoie une valeur booléenne vraie si le hachage du nom de domaine argument correspond au nom de propriétaire haché de l'enregistrement NSEC3.

covers

$covered = $rr->covers( 'example.foo' );

covers() renvoie une valeur booléenne vraie si le hachage du nom de domaine argument, ou un ascendant de ce nom, se situe entre le nom de propriétaire et le nom de propriétaire haché suivant de l'enregistrement NSEC3.

encloser, nextcloser, wildcard

$encloser = $rr->encloser( 'example.foo' );
print "encloser: $encloser\n" if $encloser;

encloser() renvoie le nom d'un encloser prouvable du nom de requête argument obtenu à partir de l'enregistrement NSEC3.

nextcloser() renvoie le nom du prochain closer, qui est un nom d'étiquette plus long que le closer le plus proche. Ceci n'est valide qu'après que encloser() ait renvoyé un nom de domaine valide.

wildcard() renvoie le nom wildcard non développé à partir duquel le nom du prochain closer aurait pu être synthétisé. Ceci n'est valide qu'après que encloser() ait renvoyé un nom de domaine valide.
