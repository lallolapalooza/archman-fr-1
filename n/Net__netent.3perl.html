Net::netent(3perl) Guide du programmeur Perl Net::netent(3perl)

NOM

Net::netent - interface par nom aux fonctions intégrées de Perl getnet*()

SYNOPIS

use Net::netent qw(:FIELDS);
getnetbyname("loopback")               or die "mauvais net";
printf "%s est %08X\n", $n_name, $n_net;
use Net::netent;
$n = getnetbyname("loopback")          or die "mauvais net";
{ # il doit y avoir une meilleure façon, non ?
    @bytes = unpack("C4", pack("N", $n->net));
    shift @bytes while @bytes && $bytes[0] == 0;
}
printf "%s est %08X [%d.%d.%d.%d]\n", $n->name, $n->net, @bytes;

DESCRIPTION

Par défaut, ce module remplace les fonctions intégrées getnetbyname() et getnetbyaddr() de Perl par des versions qui renvoient des objets "Net::netent". Cet objet possède des méthodes qui renvoient les champs de structure nommés de manière similaire de la structure C netent de netdb.h ; à savoir name, aliases, addrtype, et net. La méthode aliases renvoie une référence de tableau, les autres des scalaires.

Vous pouvez également importer tous les champs de structure directement dans votre espace de noms sous forme de variables ordinaires à l'aide de la balise d'importation :FIELDS. (Notez que cela remplace toujours vos fonctions principales.) Accédez à ces champs en tant que variables précédées de "n_". Ainsi, "$net_obj->name()" correspond à $n_name si vous importez les champs. Les références de tableau sont disponibles sous forme de variables de tableau ordinaires, donc par exemple "@{ $net_obj->aliases() }" serait simplement @n_aliases.

La fonction getnet() est un simple frontal qui transmet un argument numérique à getnetbyaddr(), et le reste à getnetbyname().

Pour accéder à cette fonctionnalité sans les substitutions principales, passez une liste d'importation vide à "use", puis accédez aux fonctions avec leurs noms qualifiés complets. D'autre part, les fonctions intégrées sont toujours disponibles via le pseudo-paquet "CORE::".

EXEMPLES

Les fonctions getnet() font ceci dans le cœur de Perl :

sv_setiv(sv, (I32)nent->n_net);

Les fonctions gethost() font ceci dans le cœur de Perl :

sv_setpvn(sv, hent->h_addr, len);

Cela signifie que l'adresse est renvoyée en binaire pour les fonctions d'hôte, et sous forme d'entier Perl ordinaire pour les fonctions réseau. Cela semble être un bug, mais voici comment le gérer :

use strict;
use Socket;
use Net::netent;
@ARGV = ('loopback') unless @ARGV;
my($n, $net);
for $net ( @ARGV ) {
    unless ($n = getnetbyname($net)) {
       warn "$0: no such net: $net\n";
       next;
    }
    printf "\n%s is %s%s\n", 
           $net, 
           lc($n->name) eq lc($net) ? "" : "*really* ",
           $n->name;
    print "\taliases are ", join(", ", @{$n->aliases}), "\n"
               if @{$n->aliases};     
    # c'est stupide ; d'abord, pourquoi ce n'est pas en binaire ?
    # ensuite, pourquoi passer par ces circonvolutions
    # pour que cela ressemble à quelque chose ?
    {
       my @a = unpack("C4", pack("N", $n->net));
       shift @a while @a && $a[0] == 0;
       printf "\taddr is %s [%d.%d.%d.%d]\n", $n->net, @a;
    }
    if ($n = getnetbyaddr($n->net)) {
       if (lc($n->name) ne lc($net)) {
           printf "\tThat addr reverses to net %s!\n", $n->name;
           $net = $n->name;
           redo;
       } 
    }
}

NOTE

Bien que cette classe soit actuellement implémentée à l'aide du module Class::Struct pour construire une classe de type structure, vous ne devriez pas vous y fier.
