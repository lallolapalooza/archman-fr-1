NAME

Net::SMTP - Client pour le protocole de transfert de courrier électronique (SMTP)

SYNOPSIS

use Net::SMTP;
# Constructeur
$smtp = Net::SMTP->new('mailhost');
$smtp = Net:: SMTP->new('mailhost', Timeout => 60);

DESCRIPTION

Ce module implémente une interface client pour le protocole SMTP et ESMTP, permettant à un programme Perl d'interagir avec des serveurs SMTP. Cette documentation suppose que vous êtes familiarisé avec les concepts de base du protocole SMTP tels que décrits dans la RFC2821. Avec le module IO::Socket::SSL installé, il fournit également un support implicite et explicite de chiffrement TLS, c'est-à-dire SMTPS ou SMTP+STARTTLS.

La classe Net::SMTP est une sous-classe de Net::Cmd et (selon disponibilité) de IO::Socket::IP, IO::Socket::INET6 ou IO::Socket::INET.

Méthodes de Classe

"new([$host][, %options])"
C'est le constructeur pour un objet Net::SMTP. $host est le nom d'hôte distant auquel une connexion SMTP est requise.
En cas d'échec, "undef" sera retourné et $@ contiendra la raison de l'échec.
$host est optionnel. S'il n'est pas spécifié, il peut être passé comme option "Host" décrite ci-dessous.
Si ni l'un ni l'autre n'est spécifié, la valeur de "SMTP_Hosts" dans "Net::Config" sera utilisée.
%options est passé sous forme de hachage de paires clé-valeur. Les options possibles sont :

Hi - SMTP requiert que vous vous identifiiez. Cette option spécifie une chaîne de caractères qui est passée comme votre domaine de messagerie. Si elle n'est pas spécifiée, localhost.localdomain sera utilisé.

SendHello - Si c'est faux, la commande EHLO (ou HELO) qui est normalement envoyée lors de la construction de l'objet ne sera pas envoyée. Dans ce cas, la commande devrait être envoyée manuellement en appelant hello().

Host - L'hôte SMTP auquel se connecter. Peut être un scalaire unique (nom d'hôte[:port]), tel que défini pour l'option "PeerAddr" dans IO::Socket::INET, ou une référence à un tableau avec des hôtes à essayer dans l'ordre. La méthode host() retournera la valeur utilisée pour se connecter à l'hôte. Format - "PeerHost" de la méthode new IO::Socket::INET.

Port - le port auquel se connecter. Par défaut, il s'agit de 25 pour SMTP sans SSL et 465 pour SSL immédiat.

SSL - Si la connexion doit être initiée avec SSL, au lieu d'être mise à jour plus tard avec "starttls". Vous pouvez utiliser les arguments SSL tels que documentés dans IO::Socket::SSL, mais il utilisera généralement les bons arguments déjà.

LocalAddr et LocalPort - ces paramètres sont passés directement à IO::Socket pour permettre de lier le socket à un port local spécifique.

Domain - ce paramètre est passé directement à IO::Socket et permet de forcer les connexions IPv4 même si IO::Socket::IP est utilisé comme superclasse. Alternativement, vous pouvez utiliser Family.

Timeout - le temps maximum en secondes pour attendre une réponse du serveur SMTP (par défaut : 120)

ExactAddresses - s'il est vrai, toutes les $address doivent être conformes à "addr-spec" dans RFC2822. S'il n'est pas spécifié, ou s'il est faux, Net::SMTP tentera d'extraire l'adresse de la valeur fournie.

Debug - active la sortie de débogage

Exemple :

$smtp = Net:: SMTP->new('mailhost',
                       Hello => 'my.mail.domain',
                       Timeout => 30,
                       Debug   => 1,
                      );
# identique
$smtp = Net:: SMTP->new(
                       Host => 'mailhost',
                       Hello => 'my.mail.domain',
                       Timeout => 30,
                       Debug   => 1,
                      );
# identique avec SSL direct
$smtp = Net:: SMTP->new('mailhost',
                       Hello => 'my.mail.domain',
                       Timeout => 30,
                       Debug   => 1,
                       SSL     => 1,
                      );
# Connexion au serveur par défaut de Net::config
$smtp = Net:: SMTP->new(
                       Hello => 'my.mail.domain',
                       Timeout => 30,
                      );

Méthodes d'Objet

Sauf indication contraire, toutes les méthodes retournent une valeur vraie ou fausse, vraie indiquant que l'opération a réussi. Lorsqu'une méthode indique qu'elle renvoie une valeur, undef ou une liste vide sera retourné en cas d'échec. "Net::SMTP" hérite de "Net::Cmd", donc les méthodes définies dans "Net::Cmd" peuvent être utilisées pour envoyer des commandes supplémentaires aux serveurs SMTP en plus de celles documentées ici.

banner()
Retourne le message de bannière auquel le serveur a répondu lors de l'établissement de la connexion initiale.
domain()
Retourne le domaine que le serveur SMTP a identifié comme tel lors de la connexion.
hello($domain)
Indique au serveur SMTP quel domaine de messagerie vous utilisez est $domain en utilisant la commande EHLO (ou HELO si EHLO échoue). En tant que méthode d'objet, cette méthode est automatiquement appelée lors de la création de l'objet Net::SMTP, elle ne devrait donc pas être appelée manuellement par l'utilisateur.
host()
Retourne la valeur utilisée par le constructeur et passée à IO::Socket::INET, pour se connecter à l'hôte.
etrn($domain)
Demande à exécuter une file d'attente pour le domaine donné.
starttls(%sslargs)
Met à jour une connexion SMTP existante vers SSL. Vous pouvez utiliser les arguments SSL tels que documentés dans IO::Socket::SSL, mais il utilisera généralement les bons arguments déjà.
"auth($username, $password)"
auth($sasl)
Tente une authentification SASL. Nécessite le module Authen::SASL. La première forme construit un nouvel objet Authen::SASL en utilisant le nom d'utilisateur et le mot de passe fournis ; la seconde forme utilise l'objet Authen::SASL donné.
"mail($address[, %options])"
send($address)
send_or_mail($address)
send_and_mail($address)
Envoie la commande MAIL appropriée au serveur, SEND, SOML ou SAML. $address est l'adresse de l'expéditeur. Cela initiera l'envoi d'un message. La méthode "recipient" doit être appelée pour chaque adresse à laquelle le message est adressé.

La méthode "mail" peut prendre des paramètres supplémentaires ESMTP, qui sont passés sous forme de hachage comme paires clé-valeur. Les options possibles sont :

Size        => <bytes>
Return      => "FULL" | "HDRS"
Bits        => "7" | "8" | "binary"
Transaction => <ADDRESS>
Envelope    => <ENVID>     # xtext-encode son argument
ENVID       => <ENVID>     # similaire à Envelope, mais attend un argument encodé
XVERP       => 1
AUTH        => <submitter> # adresse encodée selon RFC 2554

Les paramètres Return et Envelope sont utilisés pour DSN (Delivery Status Notification).

L'adresse du soumissionnaire dans l'option AUTH est attendue dans un format requis par RFC 2554, dans un format cité RFC2821 et encodé xtext.
