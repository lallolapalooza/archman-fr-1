NOM

Net::Jabber::Server - Bibliothèque de serveur Jabber

SYNOPIS

Net::Jabber::Server est un module qui fournit aux développeurs un accès facile
au développement d'applications nécessitant un serveur Jabber embarqué.

DESCRIPTION

Server.pm cherche à fournir suffisamment d'API de haut niveau et d'automatisation des
API de bas niveau pour que la création et le lancement d'un serveur Jabber
en Perl soient triviaux. Pour ceux qui souhaitent travailler avec le bas niveau, vous
pouvez aussi le faire, mais ces fonctions sont couvertes dans la documentation de
chaque module.
Net::Jabber::Server fournit des fonctions pour exécuter un serveur Jabber complet qui
accepte les connexions entrantes et livre les paquets aux serveurs Jabber externes.
Vous pouvez utiliser toutes ou aucune des fonctions, il n'y a aucune obligation.
Pour plus d'informations sur la manière dont Net::Jabber est écrit, veuillez consulter
l'aide de Net::Jabber lui-même.
Pour une liste complète des fonctions de haut niveau disponibles, veuillez consulter
Net::Jabber::Protocol.

Fonctions de base

use Net::Jabber qw(Server);
$Server = new Net::Jabber::Server();
$Server->Start();
$Server->Start(jabberxml=>"custom_jabber.xml",
               hostname=>"foobar.net");
%status = $Server->Process();
%status = $Server->Process(5);

$Server->Stop();

METHODES

Fonctions de base

new(debuglevel=>0|1|2, - crée l'objet Server. debugfile
    debugfile=>string,   doit être défini sur le chemin du journal de
    debugtime=>0|1)      débogage à écrire. S'il est défini sur "stdout",
                         le débogage ira là-bas. debuglevel contrôle le
                         montant du débogage. Pour plus d'informations sur les
                         paramètres valides pour debuglevel, debugfile et debugtime,
                         voir Net::Jabber::Debug.
Start(hostname=>string, - démarre le serveur en écoutant sur les
      jaberxml=>string)   ports appropriés. hostname est un moyen rapide
                          de dire au serveur le nom d'hôte sur lequel
                          écouter. jabberxml définit le chemin d'un fichier
                          de configuration jabberd différent (par défaut
                          est "./jabber.xml").
Process(integer) - prend la période de temps d'attente comme argument. S'il n'y a pas
                   de temps d'attente spécifié, la fonction se bloque jusqu'à ce qu'un
                   paquet soit reçu. Sinon, elle attend ce nombre de secondes puis
                   sort, permettant à votre programme de continuer à faire des choses utiles.
                   NOTE : Ceci est important pour les interfaces graphiques. Vous avez
                   besoin de laisser du temps pour traiter les commandes de l'interface
                   graphique, même si vous attendez des paquets. Les valeurs de retour
                   possibles pour chaque entrée de hachage sont les suivantes, et ce qu'elles signifient :
                       1   - Statut OK, données reçues.
                       0   - Statut OK, aucune donnée reçue.
                     undef - Statut non OK, arrêter le traitement.

                   IMPORTANT : Vous devez vérifier la sortie de chaque Process.
                   Si vous obtenez un undef, la connexion a échoué et vous devez vous
                   comporter en conséquence.
Stop() - arrête le serveur et ferme tous les sous-programmes.
