NOM

Net::LDAP::Control::ManageDsaIT - Objet de contrôle LDAPv3 ManageDsaIT

SYNTAXE

use Net::LDAP;
use Net::LDAP::Control::ManageDsaIT;
$ldap = Net::LDAP->new( "ldap.mondomaine.eg" );
$manage = Net::LDAP::Control::ManageDsaIT->new( critical => 1 );
$msg = $ldap->modify( 'dc=sous,dc=mondomaine,dc=eg",
                      changes => [
                        delete => { ref => 'ldap://ldap2/dc=sous,dc=mondom,dc=eg' },
                        add => { ref => 'ldap://ldap3/dc=sous,dc=mondom,dc=eg' } ],
                      control  => [ $manage ] );
die "erreur: " . $msg->code() . ": " . $msg->error() if ($msg->code());

DESCRIPTION

"Net::LDAP::Control::ManageDsaIT" fournit une interface pour la création et la manipulation d'objets qui représentent le contrôle "ManageDsaIT" tel que décrit par la RFC 3296.

Il permet la manipulation des références et d'autres objets spéciaux en tant qu'entrées normales.

Le contrôle est approprié pour les requêtes de recherche, de comparaison et toutes les requêtes de mise à jour LDAP, y compris ajouter, supprimer, modifier et modifierDN (renommer) [RFC4511].

Sa criticité peut être VRAIE ou FAUSSE ; il n'a pas de valeur.

ARGUMENTS DU CONSTRUCTEUR

Comme le contrôle "ManageDsaIT" ne possède pas de valeurs, seuls les arguments du constructeur décrits dans Net::LDAP::Control sont pris en charge.

MÉTHODES

Comme il n'y a pas de valeurs supplémentaires dans le contrôle, seules les méthodes de Net::LDAP::Control sont disponibles pour les objets de "Net::LDAP::Control::ManageDsaIT".
