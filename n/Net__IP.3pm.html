Net::IP - Extension Perl pour manipuler les adresses IPv4/IPv6

SYNTAXE

use Net::IP;

my $ip = new Net::IP ('193.0.1/24') or die (Net::IP::Error());
print ("IP  : ".$ip->ip()."\n");
print ("Sho : ".$ip->short()."\n");
print ("Bin : ".$ip->binip()."\n");
print ("Int : ".$ip->intip()."\n");
print ("Mask: ".$ip->mask()."\n");
print ("Last: ".$ip->last_ip()."\n");
print ("Len : ".$ip->prefixlen()."\n");
print ("Size: ".$ip->size()."\n");
print ("Type: ".$ip->iptype()."\n");
print ("Rev:  ".$ip->reverse_ip()."\n");

DESCRIPTION

Ce module fournit des fonctions pour travailler avec les adresses IPv4/IPv6. Le module peut être utilisé comme une classe, permettant à l'utilisateur de créer des objets IP, qui peuvent être des adresses IP individuelles, des préfixes ou des plages d'adresses. Il existe également une forme procédurale pour accéder à la plupart des fonctions. La plupart des sous-routines peuvent prendre des adresses IPv4 et IPv6 de manière transparente.

INTERFACE ORIENTÉE OBJET

Création d'objet

Un objet Net::IP peut être créé à partir d'une adresse IP unique :

$ip = new Net::IP ('193.0.1.46') || die ...

Ou à partir d'un préfixe sans classe (un préfixe /24 est équivalent à une classe C) :

$ip = new Net::IP ('195.114.80/24') || die ...

Ou à partir d'une plage d'adresses :

$ip = new Net::IP ('20.34.101.207 - 201.3.9.99') || die ...

Ou à partir d'une adresse IP plus un nombre :

$ip = new Net::IP ('20.34.10.0 + 255') || die ...

La méthode new() accepte les adresses IPv4 et IPv6 :

$ip = new Net::IP ('dead:beef::/32') || die ...

Optionnellement, la méthode peut recevoir la version de l'adresse. Sinon, elle tente de deviner la version (voir _is_ipv4() et _is_ipv6()).

$ip = new Net::IP ('195/8',4); # Classe A

MÉTHODES D'OBJET

La plupart de ces méthodes sont des interfaces frontales pour les fonctions réelles, qui utilisent une interface procédurale. La plupart des fonctions retournent undef en cas d'erreur, et une valeur vraie en cas de succès. Une description détaillée de l'interface procédurale est fournie ci-dessous.

set

Définit une adresse IP dans un objet IP existant. Cette fonction a la même fonctionnalité que la méthode new(), mais réutilise un objet existant pour stocker la nouvelle adresse IP.

"$ip->set('130.23.1/24',4);"

Comme la méthode new(), la méthode set() accepte deux arguments - une chaîne utilisée pour construire une adresse IP, un préfixe ou une plage, et optionnellement la version de l'adresse considérée.

Retourne un objet IP en cas de succès, et undef en cas d'erreur.

error

Retourne la chaîne d'erreur de l'objet courant. Cette chaîne est définie lorsque l'une des méthodes produit une erreur. Une fonction globale Error() au niveau de la classe est également disponible.

"warn ($ip->error());"

errno

Retourne le numéro d'erreur de l'objet courant. Le numéro d'erreur est défini lorsqu'une des méthodes produit une erreur. Une variable globale $ERRNO est également définie en cas d'erreur.

"warn ($ip->errno());"

ip

Retourne l'adresse IP (ou la première adresse d'un préfixe ou d'une plage) en format dotted-decimal sous forme de chaîne.

"print ($ip->ip());"

binip

Retourne l'adresse IP sous forme d'une chaîne binaire de 0 et de 1.

"print ($ip->binip());"

prefixlen

Retourne la longueur en bits du préfixe actuel.

"print ($ip->prefixlen());"

version

Retourne la version de l'objet IP actuel (4 ou 6).

"print ($ip->version());"

size

Retourne le nombre d'adresses IP dans le préfixe ou la plage actuelle. L'utilisation de cette fonction nécessite Math::BigInt.

"print ($ip->size());"

binmask

Retourne le masque binaire du préfixe actuel, si applicable.

"print ($ip->binmask());"

mask

Retourne le masque en format dotted-decimal du préfixe actuel.

"print ($ip->mask());"

prefix

Retourne le préfixe complet (IP + longueur de préfixe) en format dotted-decimal (normalisé).

"print ($ip->prefix());"

print

Imprime l'objet IP (IP/préfixe ou premier - dernier)

"print ($ip->print());"

intip

Convertit l'adresse IP en format entier et la retourne comme un objet Math::BigInt.

"print ($ip->intip());"

hexip

Retourne l'adresse IP en format hexadécimal.

"print ($ip->hexip());"

hexmask

Retourne le masque en format hexadécimal.

"print ($ip->hexmask());"

short

Retourne l'adresse IP en format court : IPv4 : 194.5/16 ; IPv6 : ab32:f000::

"print ($ip->short());"

iptype

Retourne le type d'IP - cela décrit le type d'une IP (Public, Privé, Réservé, etc.). Voir l'interface procédurale ip_iptype pour plus de détails.

"print ($ip->iptype());"

reverse_ip

Retourne l'adresse inverse d'une adresse donnée (format in.addr).

"print ($ip->reverse_ip());"

last_ip

Retourne la dernière adresse IP d'un préfixe/plage en format dotted-decimal.

"print ($ip->last_ip());"

last_bin

Retourne la dernière adresse IP d'un préfixe/plage en format binaire.

"print ($ip->last_bin());"

last_int

Retourne la dernière adresse IP d'un préfixe/plage en format entier.

"print ($ip->last_int());"

find_prefixes

Cette fonction trouve tous les préfixes qui peuvent exister entre les deux adresses d'une plage. La fonction retourne une liste de préfixes.

"@list = $ip->find_prefixes($other_ip));"

INTERFACE PROCÉDURALE

Ces fonctions effectuent le travail réel dans le module. Comme les méthodes OO, la plupart d'entre elles retournent undef en cas d'échec. Pour accéder aux codes d'erreur et aux chaînes de caractères, au lieu d'utiliser $ip->error() et $ip->errno(), utilisez les fonctions globales Error() et Errno().

Les fonctions de l'interface procédurale ne sont pas exportées par défaut. Pour les importer, vous devez modifier l'instruction use du module :

"use Net::IP qw(:PROC);"

Erreur

Renvoie la chaîne d'erreur correspondant à la dernière erreur générée dans le module. Elle est également utile pour l'interface OO, car si la méthode new() échoue, nous ne pouvons pas appeler $ip->error() et devons utiliser Error().

warn Error();

Errno

Renvoie un code d'erreur numérique correspondant à la chaîne d'erreur renvoyée par Error().

ip_iptobin

Transforme une adresse IP en une chaîne binaire.

Paramètres : adresse IP, version IP

"$binip = ip_iptobin ($ip,6);"

ip_bintoip

Transforme une chaîne binaire en une adresse IP.

Paramètres : chaîne binaire, version IP

"$ip = ip_bintoip ($binip,6);"

ip_bintoint

Transforme une chaîne binaire en un BigInt.

Paramètres : chaîne binaire

"$bigint = new Math::BigInt (ip_bintoint ($binip));"

ip_inttobin

Transforme un BigInt en une chaîne binaire. Note : désactive les avertissements ("-w"). Ceci est nécessaire car Math::BigInt n'est pas compatible.

Paramètres : BigInt, version IP

"$binip = ip_inttobin ($bigint);"

ip_get_version

Tente de deviner la version IP d'une adresse IP.

Paramètres : adresse IP

"$version = ip_get_version ($ip)"

ip_is_ipv4

Vérifie si une adresse IP est de type 4.

Paramètres : adresse IP

"ip_is_ipv4 ($ip) and print "$ip est IPv4";"

ip_is_ipv6

Vérifie si une adresse IP est de type 6.

Paramètres : adresse IP

"ip_is_ipv6 ($ip) and print "$ip est IPv6";"

ip_expand_address

Développe une adresse IP en notation compacte.

Paramètres : adresse IP, version IP

"$ip = ip_expand_address ($ip,4);"

ip_get_mask

Obtient le masque IP à partir de la longueur du préfixe.

Paramètres : longueur du préfixe, version IP

"$mask = ip_get_mask ($len,6);"

ip_last_address_bin

Renvoie la dernière adresse binaire d'un préfixe.

Paramètres : adresse binaire, longueur du préfixe, version IP

"$lastbin = ip_last_address_bin ($ip,$len,6);"

ip_splitprefix

Sépare un préfixe en adresse IP et longueur de préfixe. Si une IP simple est passée, ne renvoie que l'adresse.

Paramètres : préfixe

"($ip,$len) = ip_splitprefix ($prefix)"

ip_prefix_to_range

Obtient une plage d'adresses IP à partir d'un préfixe.

Paramètres : préfixe, version IP

"($ip1,$ip2) = ip_prefix_to_range ($prefix,6);"

ip_bincomp

Comparaison binaire de deux adresses IP. L'opérateur prend un opérande et une adresse IP comme arguments. Renvoie une valeur booléenne.

"ip_bincomp ($ip1,'lt',$ip2) == 1 or do {}"

ip_binadd

Additionne deux adresses binaires.

Paramètres : adresse binaire, adresse binaire

"$binip = ip_binadd ($bin1,$bin2);"

ip_get_prefix_length

Obtient la longueur du préfixe pour une plage de 2 adresses IP.

Paramètres : adresse binaire, adresse binaire

"$len = ip_get_prefix_length ($ip1,$ip2);"

ip_range_to_prefix

Renvoie tous les préfixes entre deux adresses IP.

Paramètres : adresse IP (format binaire), adresse IP (format binaire), version IP

Les préfixes renvoyés sont au format q.q.q.q/nn.

"@prefix = ip_range_to_prefix ($ip1,$ip2,6);"

ip_compress_v4_prefix

Compresse un préfixe IPv4.

Paramètres : adresse IP, longueur du préfixe

"$ip = ip_compress_v4_prefix ($ip, $len);"

ip_compress_address

Compresse une adresse IPv6. Ne renvoie l'adresse que si elle est IPv4.

Paramètres : adresse IP, version IP

"$ip = ip_compress_adress ($ip, $version);"

ip_is_overlap

Vérifie si deux plages d'adresses IP se chevauchent.

Paramètres : quatre adresses binaires (début plage1, fin plage1, début plage2, fin plage2), version IP

"(ip_is_overlap($rb1,$re1,$rb2,$re2,4) eq $IP_A_IN_B_OVERLAP) and do {};"

ip_get_embedded_ipv4

Obtient un IPv4 intégré dans une adresse IP.

ip_check_mask

Vérifier la validité d'un masque binaire

Params  : Mask
Returns : 1 ou undef (invalide)

"ip_check_mask($binmask) or do {};"

Vérifie si le masque ne contient que des 1 suivis de 0.

ip_aggregate

Agréger deux plages d'IP binaires

Params  : 1ère plage (1ère IP, dernière IP), dernière plage (1ère IP, dernière IP), version IP
Returns : préfixe ou undef (invalide)

"$prefix = ip_aggregate ($bip1,$eip1,$bip2,$eip2) || die ..."

ip_iptypev4

Retourne le type d'une adresse IPv4

Params:  IP binaire
Returns: type selon le tableau suivant ou undef (invalide)

Voir RFC 5735 et RFC 6598

Bloc                                               Référence ------------------------------------------------------------------- 0.0.0.0/8                                                Ce réseau Réseaux privés                    RFC 1122 PRIVÉ 10.0.0.0/8                                                RFC 1918

RÉSUMÉ

La valeur par défaut est 6)

Retourne : type (voir ip_iptypev4 et ip_iptypev6 pour les détails) ou indéfini (invalide)

ip_check_prefix ($ip,$len,$ipv) ou faire rien {};

DESCRIPTION

Vérifie la validité d'un préfixe

Paramètres : IP binaire, longueur du préfixe, version IP
Retourne : 1 ou indéfini (invalide)

Vérifie si la partie variable d'un préfixe ne contient que des 0, et si la longueur est correcte.

ip_check_prefix ($ip,$len,$ipv) ou faire rien {};

Paramètres : IP, longueur du préfixe, version IP
Retourne : 1 ou indéfini (invalide)

MÉTHODES D'OBJET

Paramètres : IP, longueur du préfixe, version IP
Retourne : 1 ou indéfini (invalide)

INTERFACE PROCÉDURALE

Obtient le nom inverse d'un préfixe

Paramètres : IP, longueur du préfixe, version IP
Retourne : Nom inverse ou indéfini (erreur)

ip_reverse ($ip);

NORMALISATION IP

Normalise les données vers une plage/un préfixe d'adresses IP

Paramètres : Chaîne de données (IP seule, plage, préfixe)
Retourne : ip1, ip2 (si plage/préfixe) ou indéfini (erreur)

($ip1,$ip2) = ip_normalize ($data);

AUTORITÉ IP

Retourne les informations d'autorité d'une IP

Paramètres : IP, version
Retourne : Informations d'autorité (RI pour RIPE, AR pour ARIN, etc.)

ip_auth ($ip,4);

Remarque : IPv4 uniquement

BOGUES

La bibliothèque Math::BigInt est requise pour les fonctions qui utilisent des entiers. Ce sont ip_inttobin, ip_bintoint et la méthode size. Dans une version future, Math::BigInt sera facultatif.
