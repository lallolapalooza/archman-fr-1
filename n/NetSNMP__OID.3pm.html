NOM

NetSNMP::OID - Extension Perl pour la manipulation des OID

SYNOPIS

use NetSNMP::OID;
my $oid = new NetSNMP::OID('sysContact.0');
if ($oid < new NetSNMP::OID('ifTable')) {
    do_something();
}
my @numarray = $oid->to_array();
# ajout d'oid
$oid = new NetSNMP::OID('.1.3');
$oid += ".6.1";
# -> .1.3.6.1
# ajout d'index sous forme de chaînes
$oid2 = $oid + "\"wes\"";
# -> .1.3.6.1.3.119.101.115
$oid3 = $oid + "\'wes\'";
# -> .1.3.6.1.119.101.115
$len = $oid3->length();
# -> 7
# récupération des index d'un oid :
$arrayref = $tableoid->get_indexes()

DESCRIPTION

Le module NetSNMP::OID est un simple wrapper autour d'un OID net-snmp basé sur C (qui est un tableau d'entiers non signés). L'OID est stocké en interne sous forme de tableau C d'entiers pour des raisons de vitesse lors des comparaisons, etc.

Les opérateurs logiques d'expression standard (<, >, ==, ...) sont surchargés de manière à ce que des comparaisons lexicographiques puissent être effectuées avec eux.

L'opérateur + est surchargé pour vous permettre d'ajouter des éléments à la fin d'un OID, comme des segments d'index d'une table, par exemple.

EXPORT
