NOM

Net::protoent - interface par nom aux fonctions intégrées de Perl getproto*()

SYNOPSIS

use Net::protoent;
my $p = getprotobyname(shift || 'tcp') || die "pas de proto";
printf "le proto pour %s est %d, les alias sont %s\n",
   $p->name, $p->proto, "@{$p->aliases}";
use Net::protoent qw(:FIELDS);
getprotobyname(shift || 'tcp') || die "pas de proto";
print "le proto pour $p_name est $p_proto, les alias sont @p_aliases\n";

DESCRIPTION

Par défaut, ce module surcharge les fonctions de base getprotoent(), getprotobyname() et getnetbyport(), en les remplaçant par des versions qui retournent des objets "Net::protoent". Elles prennent des arguments par défaut de "tcp". Cet objet possède des méthodes qui retournent le nom du champ de structure correspondant du protoent de C de netdb.h ; à savoir name, aliases et proto. La méthode aliases retourne une référence de tableau, les autres des scalaires.

Vous pouvez également importer tous les champs de structure directement dans votre espace de noms sous forme de variables régulières en utilisant la balise d'importation :FIELDS. (Notez que cela surcharge toujours vos fonctions de base.) Accédez à ces champs sous forme de variables nommées avec un préfixe "p_". Ainsi, "$proto_obj->name()" correspond à $p_name si vous importez les champs. Les références de tableau sont disponibles sous forme de variables de tableau régulières, donc par exemple "@{ $proto_obj->aliases() }" serait simplement @p_aliases.

La fonction getproto() est une simple interface qui transmet un argument numérique à getprotobyport(), et les autres à getprotobyname().

Pour accéder à cette fonctionnalité sans les surcharges de base, passez une liste d'importation vide à "use", puis accédez aux fonctions avec leurs noms complets qualifiés. D'autre part, les fonctions intégrées sont toujours disponibles via le pseudo-paquet "CORE::".

NOTE

Bien que cette classe soit actuellement implémentée à l'aide du module Class::Struct pour construire une classe de type struct, vous ne devriez pas vous y fier.
