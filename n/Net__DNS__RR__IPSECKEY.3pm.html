NOM

Net::DNS::RR::IPSECKEY - Enregistrement de ressource IPSECKEY DNS

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nom IPSECKEY priorite typ_passerelle algorithme passerelle cle');

DESCRIPTION

Enregistrements de ressource DNS de stockage de clé IPsec (IPSECKEY).

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées par les méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités de package non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

priorite

$priorite = $rr->priorite;
$rr->priorite( $priorite );

Il s'agit d'une priorité de 8 bits pour cet enregistrement. Les passerelles listées dans les enregistrements IPSECKEY avec une priorité plus faible doivent être tentées en premier.

typ_passerelle

$typ_passerelle = $rr->typ_passerelle;

Le champ du type de passerelle indique le format des informations stockées dans le champ passerelle.

algorithme

$algorithme = $rr->algorithme;
$rr->algorithme( $algorithme );

Le champ du type d'algorithme identifie l'algorithme cryptographique des clés publiques et détermine le format du champ de clé publique.

passerelle

$passerelle = $rr->passerelle;
$rr->passerelle( $passerelle );

Le champ passerelle indique une passerelle vers laquelle un tunnel IPsec peut être créé afin d'atteindre l'entité nommée par cet enregistrement de ressource.

cle_publique

cle

$cle = $rr->cle;
$rr->cle( $cle );

Représentation Base64 du bloc de clé publique optionnel pour l'enregistrement de ressource.

cle_binaire

$cle_binaire = $rr->cle_binaire;
$rr->cle_binaire( $cle_binaire );

Représentation binaire du bloc de clé publique pour l'enregistrement de ressource.
