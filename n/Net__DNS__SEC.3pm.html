NOM

Net::DNS::SEC - Extensions DNSSEC pour Net::DNS

SYNTAXE

use Net::DNS::SEC;

DESCRIPTION

Net::DNS::SEC est installé comme une extension à une installation existante de Net::DNS fournissant des paquets pour supporter DNSSEC tel que spécifié dans les RFC4033, RFC4034, RFC4035 et documents associés.

Il fournit également le support pour SIG0, utile pour les mises à jour dynamiques.

Implémente des fonctions de génération et de vérification de signatures cryptographiques utilisant les algorithmes RSA, DSA, ECDSA et de courbes d'Edwards.

Les fonctionnalités étendues sont rendues disponibles en remplaçant Net::DNS par Net::DNS::SEC dans la déclaration use.

FONCTIONS UTILITAIRES

algorithme

$mnemonique = algorithme( 5 );
$numerique  = algorithme( 'RSA-SHA1' );
print "mnemonique de l'algorithme\t", $mnemonique, "\n";
print "numéro de l'algorithme:\t",  $numerique,  "\n";

algorithme() fournit des conversions entre un code numérique d'algorithme et la mnemonique correspondante.

type_digestion

$mnemonique = type_digestion( 2 );
$numerique  = type_digestion( 'SHA-256' );
print "mnemonique du type de digestion\t", $mnemonique, "\n";
print "numéro du type de digestion:\t",  $numerique,  "\n";

type_digestion() fournit des conversions entre un numéro de type de digestion et la mnemonique correspondante.

difference_cles

@resultat = difference_cles( \@a, \@b );

Remplit @resultat avec toutes les clés du tableau @a qui ne sont pas dans le tableau @b.
