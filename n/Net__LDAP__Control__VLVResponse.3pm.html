NOM

Net::LDAP::Control::VLVResponse -- réponse du serveur de vue à liste virtuelle LDAPv3

SYNOPSIS

Voir Net::LDAP::Control::VLV

DESCRIPTION

"Net::LDAP::Control::VLVResponse" est une sous-classe de Net::LDAP::Control. Elle fournit une classe pour manipuler le contrôle de réponse de vue à liste virtuelle LDAP ""

Si le serveur supporte les vues à liste virtuelle, alors la réponse d'une opération de recherche inclura un contrôle VLVResponse.

ARGUMENTS DU CONSTRUCTEUR

En plus des arguments du constructeur décrits dans Net::LDAP::Control, les suivants sont fournis.

contenu
Une estimation du nombre d'entrées dans la liste complète. Cette valeur devrait être utilisée dans tout contrôle de vue à liste virtuelle subséquent utilisant la même liste.
contexte
Une valeur arbitraire utilisée pour associer les requêtes subséquentes à la requête pour laquelle ce contrôle est une réponse. Cette valeur devrait être copiée par le client dans le contrôle de vue à liste virtuelle pour toute recherche subséquente utilisant la même liste.
resultat
Un code de résultat indiquant le résultat de la requête de vue à liste virtuelle. Cela peut être n'importe lequel des codes listés ci-dessous.
cible
Le décalage de la liste de l'entrée cible.

METHODES

Comme avec Net::LDAP::Control, chaque argument du constructeur décrit ci-dessus est également disponible comme méthode sur l'objet qui retournera la valeur actuelle de l'attribut s'il est appelé sans argument, et définira une nouvelle valeur pour l'attribut s'il est appelé avec un argument.

CODES DE RESULTAT

Les résultats possibles d'une requête de tri sont listés ci-dessous. Voir Net::LDAP::Constant pour une définition de chacun.

LDAP_SUCCESS
LDAP_OPERATIONS_ERROR
LDAP_TIMELIMIT_EXCEEDED
LDAP_ADMIN_LIMIT_EXCEEDED
LDAP_INSUFFICIENT_ACCESS
LDAP_BUSY
LDAP_UNWILLING_TO_PERFORM
LDAP_OTHER
LDAP_SORT_CONTROL_MISSING
LDAP_INDEX_RANGE_ERROR
