NOM

Net::DNS::SEC::Tools::BootStrap - Chargement optionnel de modules Perl

SYNOPSIS

use Net::DNS::SEC::Tools::BootStrap;
dnssec_tools_load_mods(
   PerlModule => 'Texte d’aide/erreur supplémentaire'
);

DESCRIPTION

Le paquet DNSSEC-Tools nécessite un certain nombre de modules Perl qui ne sont utilisés que par certains des outils. Ce module aide à déterminer à l'exécution, plutôt qu'à l'installation, si les bons outils sont disponibles sur le système. Si un module ne parvient pas à être chargé, dnssec_tools_load_mods() affichera un message d'erreur et appellera exit(). Le message d'erreur décrit comment installer un module via CPAN.

Les arguments de dnssec_tools_load_mods() sont donnés par paires. Chaque paire est un module à essayer de charger (et d'importer) et un message d'erreur supplémentaire. Si le module ne parvient pas à être chargé, le message d'erreur supplémentaire sera affiché avec le message d'installation via CPAN. Si le message d'erreur est la chaîne "noerror", alors aucun message d'erreur ne sera affiché avant que la fonction ne se termine.

CAVEATS

Le module tentera d'importer toutes les sous-routines exportées du module dans l'espace de noms main. Cela signifie que le module BootStrap.pm est susceptible de ne pas être utile pour importer des symboles dans d'autres modules. Les solutions de contournement pour cela sont :

- importer les symboles manuellement
dnssec_tools_load_mods(
   PerlModule => 'Texte d’aide/erreur supplémentaire'
);
import PerlModule qw(func1 func2);
func1(arg1, arg2);
- appeler le nom de fonction entièrement qualifié
dnssec_tools_load_mods(
   PerlModule => 'Texte d’aide/erreur supplémentaire'
);
PerlModule::func1(arg1, arg2);
