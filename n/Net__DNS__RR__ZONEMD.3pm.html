Net::DNS::RR::ZONEMD(3) Documentation Perl fournie par l'utilisateur Net::DNS::RR::ZONEMD(3)

NOM

Net::DNS::RR::ZONEMD - enregistrement de ressource ZONEMD DNS

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new("example.com. ZONEMD 2018031500 1 1
        FEBE3D4CE2EC2FFA4BA99D46CD69D6D29711E55217057BEE
        7EB1A7B641A47BA7FED2DD5B97AE499FAFA4F22C6BD647DE");

DESCRIPTION

Classe pour les enregistrements de ressource Zone Message Digest (ZONEMD) DNS.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités non documentées du paquet ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner la terminaison du programme ou d'autres comportements imprévisibles.

serial

$serial = $rr->serial;
$rr->serial( $serial );

Numéro de série de la zone, entier non signé 32 bits.

scheme

$scheme = $rr->scheme;
$rr->scheme( $scheme );

Le champ `scheme` est un entier non signé 8 bits qui identifie les méthodes par lesquelles les données sont collectées et présentées en entrée de la fonction de hachage.

algorithm

$algorithm = $rr->algorithm;
$rr->algorithm( $algorithm );

Le champ `algorithm` est un entier non signé 8 bits qui identifie l'algorithme de hachage cryptographique utilisé pour construire le digest.

digest

$digest = $rr->digest;
$rr->digest( $digest );

Représentation hexadécimale du digest sur le contenu de la zone.

digestbin

$digestbin = $rr->digestbin;
$rr->digestbin( $digestbin );

Représentation binaire du digest sur le contenu de la zone.
