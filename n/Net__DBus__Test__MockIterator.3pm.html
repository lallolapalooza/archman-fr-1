NOM

Net::DBus::Test::MockIterator - Itérateur sur un message mock

SYNTAXE

Créer un nouveau message

my $msg = new Net::DBus::Test::MockMessage
my $iterator = $msg->iterator;
$iterator->append_boolean(1);
$iterator->append_byte(123);

Lire depuis un message

my $msg = ...obtenir depuis quelque part...
my $iter = $msg->iterator();
my $i = 0;
while ($iter->has_next()) {
  $iter->next();
  $i++;
  if ($i == 1) {
     my $val = $iter->get_boolean();
  } elsif ($i == 2) {
     my $val = $iter->get_byte();
  }
}

DESCRIPTION

Ce module fournit un contrepartie mock à l'objet Net::DBus::Binding::Iterator, capable d'itérer sur des objets de message mock. Les instances de ce module ne sont pas créées directement, mais sont obtenues via la méthode "iterator" du module Net::DBus::Test::MockMessage.

MÉTHODES

$res = $iter->has_next()
Détermine s'il y a d'autres champs dans l'itérateur de message à lire. Retourne une valeur positive s'il y a plus de champs, zéro sinon.
$success = $iter->next()
Avance l'itérateur vers le champ de message suivant. Retourne une valeur positive si le pointeur actuel a été avancé avec succès, zéro sinon.
my $val = $iter->get_boolean()
$iter->append_boolean($val);
Lit ou écrit une valeur booléenne depuis/vers l'itérateur de message.
my $val = $iter->get_byte()
$iter->append_byte($val);
Lit ou écrit une valeur d'un seul octet depuis/vers l'itérateur de message.
my $val = $iter->get_string()
$iter->append_string($val);
Lit ou écrit une valeur de chaîne UTF-8 depuis/vers l'itérateur de message.
my $val = $iter->get_object_path()
$iter->append_object_path($val);
Lit ou écrit une valeur de chemin d'objet UTF-8, dont le contenu est un chemin valide, depuis/vers l'itérateur de message.
my $val = $iter->get_signature()
$iter->append_signature($val);
Lit ou écrit une valeur de signature UTF-8, dont le contenu est une signature valide, depuis/vers l'itérateur de message.
my $val = $iter->get_int16()
$iter->append_int16($val);
Lit ou écrit une valeur signée de 16 bits depuis/vers l'itérateur de message.
my $val = $iter->get_uint16()
$iter->append_uint16($val);
Lit ou écrit une valeur non signée de 16 bits depuis/vers l'itérateur de message.
my $val = $iter->get_int32()
$iter->append_int32($val);
Lit ou écrit une valeur signée de 32 bits depuis/vers l'itérateur de message.
my $val = $iter->get_uint32()
$iter->append_uint32($val);
Lit ou écrit une valeur non signée de 32 bits depuis/vers l'itérateur de message.
my $val = $iter->get_int64()
$iter->append_int64($val);
Lit ou écrit une valeur signée de 64 bits depuis/vers l'itérateur de message. Une erreur sera levée si cette compilation de Perl ne supporte pas les entiers 64 bits.
my $val = $iter->get_uint64()
$iter->append_uint64($val);
Lit ou écrit une valeur non signée de 64 bits depuis/vers l'itérateur de message. Une erreur sera levée si cette compilation de Perl ne supporte pas les entiers 64 bits.
my $val = $iter->get_double()
$iter->append_double($val);
Lit ou écrit une valeur à virgule flottante double précision depuis/vers l'itérateur de message.
my $val = $iter->get_unix_fd()
$iter->append_unix_fd($val);
Lit ou écrit une valeur de descripteur de fichier Unix depuis/vers l'itérateur de message.
my $value = $iter->get()
my $value = $iter->get($type);
Récupère la valeur actuelle pointée par cet itérateur. Si le paramètre optionnel $type est fourni, le type de câble sera comparé au type souhaité et un avertissement sera émis s'ils ne correspondent pas. La valeur $type doit être l'une des constantes "Net::DBus::Binding::Message::TYPE*".
my $hashref = $iter->get_dict()
Si l'itérateur actuel pointe vers une valeur de type dictionnaire, il désérialise et retourne la valeur sous forme de référence de hachage.
my $hashref = $iter->get_array()
Si l'itérateur actuel pointe vers une valeur de type tableau, il désérialise et retourne la valeur sous forme de référence de tableau.
my $hashref = $iter->get_variant()
Si l'itérateur actuel pointe vers une valeur de type variant, il désérialise et retourne la valeur contenue dans le variant.
my $hashref = $iter->get_struct()
Si l'itérateur actuel pointe vers une valeur de type structure, il désérialise et retourne la valeur sous forme de référence de tableau. Les valeurs dans le tableau correspondent aux membres de la structure.
$iter->append($value)
$iter->append($value, $type)
Ajoute une valeur au message associé à cet itérateur. La valeur est sérialisée selon les règles suivantes.

Si le $value est un objet de type Net::DBus::Binding::Value, le type de données embarqué est utilisé.

Si le paramètre $type est fourni, il est pris comme la représentation du type. Le type doit être l'une des constantes "Net::DBus::Binding::Message::TYPE_*".

Autrement, le type est choisi selon les types de données Perl : chaîne, dictionnaire ou tableau.

my $type = $iter->guess_type($value)
Donne une meilleure estimation du type de données sur la forme de câble pour sérialiser $value. Si la valeur est une référence de hachage, le type de dictionnaire est retourné; si c'est une référence de tableau, le type de tableau; sinon, le type de chaîne.
my $sig = $iter->format_signature($type)
Construit une chaîne de signature correspondant à une représentation de type de données.
$iter->append_array($value, $type)
Ajoute un tableau de valeurs au message. Le paramètre $value doit être une référence à un tableau, dont les éléments ont le même type spécifié par le paramètre $type.
$iter->append_struct($value, $type)
Ajoute une structure au message. Le paramètre $value doit être une référence à un tableau, dont les éléments correspondent aux membres de la structure. Le paramètre $type spécifie le type de chaque membre de la structure.
$iter->append_dict($value, $type)
Ajoute un dictionnaire au message. Le paramètre $value doit être une référence à un hachage. Le paramètre $type spécifie le type de clé et de valeur du hachage.
$iter->append_variant($value)
Ajoute une valeur au message, encodée comme un type variant. La valeur $value peut être de n'importe quel type, mais le variant sera encodé comme une chaîne, un dictionnaire ou un tableau selon les règles de la méthode "guess_type".
my $type = $iter->get_arg_type
Récupère le code de type de valeur pointé par cet itérateur. Le code retourné correspond à l'une des constantes "Net::DBus::Binding::Message::TYPE_*".

NOM

Net::DBus::Test::MockIterator - Un iterador de mensajes de prueba para Net::DBus.

SYNOPIS

  use Net::DBus::Test::MockIterator;

  my $iter = Net::DBus::Test::MockIterator->new( [ 'foo', 123, 'bar' ] );
  my $type = $iter->get_element_type;
  my $val = $iter->get_basic;

  ...

DESCRIPTION

Esta clase proporciona una implementación de prueba de la clase Net::DBus::Binding::Iterator. Se inicializa con una lista de elementos de prueba que puede recorrer y devolver.

MÉTHODES

my $type = $iter->get_element_type
Si el iterador apunta a un array, devuelve el código de tipo de elementos de array. El código devuelto corresponderá a una de las constantes "Net::DBus::Binding::Message::TYPE_*"

BOGUES

No reproduce completamente la API de Net::DBus::Binding::Iterator, pero lo suficiente para que las bindings de nivel superior funcionen en un escenario de prueba.
