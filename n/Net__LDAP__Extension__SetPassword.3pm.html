NOM

Net::LDAP::Extension::SetPassword - Objet d'extension de modification de mot de passe LDAPv3

SYNTAXE

use Net::LDAP;
use Net::LDAP::Extension::SetPassword;
$ldap = Net::LDAP->new( "ldap.mondomaine.eg" );
$ldap->bind('cn=Joe User,cn=People,dc=mondomaine,dc=eg",
            password => 'ancienMotDePasse');
$mesg = $ldap->set_password( oldpasswd => 'ancienMotDePasse' );
die "erreur: ", $mesg->code(), ": ", $mesg->error()  if ($mesg->code());
print "mot de passe changé en", $mesg->gen_password() , "\n";

DESCRIPTION

"Net::LDAP::Extension::SetPassword" implémente l'opération étendue LDAPv3 "Modify Password" telle que décrite dans la RFC 3062.

Elle n'implémente aucun objet par elle-même mais étend l'objet Net::LDAP par une autre méthode :

MÉTHODES

set_password ( OPTIONS )
Définit le mot de passe d'un utilisateur.

OPTIONS est une liste de paires clé/valeur. Les clés suivantes sont reconnues :

user
Si présente, cette option contient la représentation en chaîne d'octets de l'utilisateur associé à la requête. Selon la manière dont les utilisateurs sont identifiés dans le répertoire, cette chaîne peut être ou ne pas être un DN selon la RFC 4514.

Si cette option est absente, la requête agit sur le mot de passe de l'utilisateur actuellement associé à la session LDAP.

oldpasswd
Cette option, si elle est présente, doit contenir le mot de passe actuel de l'utilisateur pour lequel cette opération est effectuée.

Il dépend de l'implémentation du serveur dans quelles circonstances cette option est autorisée à être absente.

newpasswd
Si présente, cette option contient le mot de passe souhaité pour l'utilisateur pour lequel l'opération est effectuée.

Selon l'implémentation du serveur, cette option peut être requise par le serveur LDAP.

gen_password ( )
Retourne le mot de passe généré par le serveur en réponse à l'appel set_password() lorsque applicable. Le serveur ne générera pas de nouveau mot de passe si "newpasswd" a été passé à set_password().

Cette méthode est une méthode de l'objet de réponse Net::LDAP::Message retourné en réponse à set_password() en cas de succès de l'appel set_password().

Par cette méthode, l'appelant peut interroger la valeur du mot de passe s'il n'a pas appelé set_password() avec l'option "newpasswd".
