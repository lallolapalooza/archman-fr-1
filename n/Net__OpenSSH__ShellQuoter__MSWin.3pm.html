NOM

Net::OpenSSH::ShellQuoter::MSWin - Citer pour Win32::CreateProcess

DESCRIPTION

Ce quoteur est destiné à l'interaction avec des serveurs SSH exécutant sous Windows qui utilisent l'appel système "Win32::CreateProcess" pour lancer la commande demandée.

Étant donné que "Win32::CreateProcess" n'effectue pas d'expansion de caractères génériques, le quoting de glob cite simplement tout.
