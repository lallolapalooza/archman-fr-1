NOM

Net::DNS::RR::CSYNC - enregistrement de ressource CSYNC DNS

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name CSYNC SOAserial flags typelist');

DESCRIPTION

Classe pour les enregistrements de ressource CSYNC DNSSEC.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités de paquet non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

SOAserial

soaserial

$soaserial = $rr->soaserial;
$rr->soaserial( $soaserial );

Le champ SOA Serial contient une copie du numéro de série SOA de 32 bits de la zone enfant.

flags

$flags = $rr->flags;
$rr->flags( $flags );

Le champ flags contient 16 bits de drapeaux booléens qui définissent les opérations qui affectent le traitement de l'enregistrement CSYNC.

immediate
$rr->immediate(1);
if ( $rr->immediate ) {
        ...
}

S'il n'est pas défini, un agent parental ne doit pas traiter l'enregistrement CSYNC avant que l'administrateur de la zone n'approuve l'opération par un mécanisme hors bande.

soaminimum
$rr->soaminimum(1);
if ( $rr->soaminimum ) {
        ...
}

S'il est défini, un agent parental interrogeant les serveurs autoritaires enfants ne doit pas agir sur les données des zones annonçant un numéro de série SOA inférieur à la valeur SOAserial.

typelist

@typelist = $rr->typelist;
$typelist = $rr->typelist;

La liste de types indique les types d'enregistrements à traiter par l'agent parental. Lorsqu'elle est appelée dans un contexte scalaire, la liste est interpolée en une chaîne.
