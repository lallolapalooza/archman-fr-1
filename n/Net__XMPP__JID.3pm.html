NOM

Net::XMPP::JID - Module JID XMPP

SYNOPIS

Net::XMPP::JID est un compagnon du module Net::XMPP. Il fournit à l'utilisateur une interface simple pour définir et récupérer toutes les parties d'un Jabber ID (identifiant utilisateur sur un serveur).

DESCRIPTION

Pour initialiser le JID, vous devez lui passer la chaîne qui représente le jid du paquet XML. Dans les modules XMPP, cela est fait automatiquement et l'objet JID est retourné au lieu d'une chaîne. Par exemple, dans la fonction de rappel pour l'objet XMPP foo :

use Net::XMPP;
sub foo {
  my $foo = Net::XMPP::Foo->new(@_);
  my $from = $foo->GetFrom();
  my $JID = Net::XMPP::JID->new($from);
  .
  .
  .
}

Vous avez maintenant accès à toutes les fonctions de récupération disponibles.

Pour créer un nouveau JID à envoyer au serveur :

use Net::XMPP;
$JID = Net::XMPP::JID->new();

Maintenant, vous pouvez appeler les fonctions de création ci-dessous pour remplir la balise avant de l'envoyer.

Fonctions de récupération

$userid   = $JID->GetUserID();
$server   = $JID->GetServer();
$resource = $JID->GetResource();
$JID      = $JID->GetJID();
$fullJID  = $JID->GetJID("full");
$baseJID  = $JID->GetJID("base");

Fonctions de création

$JID->SetJID(userid=>"bob",
             server=>"jabber.org",
             resource=>"Work");
$JID->SetJID('blue@moon.org/Home');
$JID->SetUserID("foo");
$JID->SetServer("bar.net");
$JID->SetResource("Foo Bar");

MÉTHODES

Fonctions de récupération

GetUserID
GetUserID()

retourne une chaîne avec l'identifiant utilisateur du JID. Si la chaîne est une adresse (bob%jabber.org), la fonction la retournera sous forme d'adresse (bob@jabber.org).

GetServer
GetServer()

retourne une chaîne avec le serveur du JID.

GerResource
GetResource()

retourne une chaîne avec la ressource du JID.

GetJID
  GetJID()      
  GetJID("full")
  GetJID("base")
retourne une chaîne qui représente le JID stocké
à l'intérieur.  Si la chaîne "full" est spécifiée,
alors vous obtenez le JID complet, y compris la
Ressource, qui devrait être utilisée pour l'envoi
au serveur.  Si la chaîne "base" est spécifiée,
alors vous obtiendrez simplement user@server,
ou le JID de base.

Fonctions de création

SetJID
SetJID(userid=>string,  
       server=>string,  
       resource=>string)
SetJID(string)

définit plusieurs champs dans le jid en une seule fois. Ceci est une action cumulative et de substitution. Si vous définissez l'attribut "userid" deux fois, le second réglage est celui qui est utilisé. Si vous définissez le serveur, puis que vous définissez la ressource, alors les deux seront dans le jid. Si tout ce que vous passez est une chaîne, alors cette chaîne est utilisée comme JID. Pour des paramètres valides, lisez les fonctions Set spécifiques ci-dessous.

SetUserID
SetUserID(string)

définit l'identifiant utilisateur. Doit être un identifiant utilisateur valide, sinon le serveur se plaindra si vous essayez d'utiliser ce JID pour parler au serveur. Si la chaîne est une adresse, elle sera convertie en forme % appropriée pour être utilisée comme identifiant utilisateur.

SerServer
SetServer(string)

définit le serveur. Doit être un hôte valide sur le réseau, sinon le serveur ne pourra pas lui parler.

SetResource
SetResource(string)

définit la ressource de l'identifiant utilisateur à contacter.
