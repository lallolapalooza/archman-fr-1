NOM

Net::Server::Proto::UNIXDGRAM - Protocole UNIXDGRAM de Net::Server.

SYNTAXE

Voir Net::Server::Proto.

DESCRIPTION

Module de protocole pour Net::Server. Ce module implémente le type de socket UNIX SOCK_DGRAM. Voir Net::Server::Proto.

Tous les sockets créés lors du démarrage seront modifiés (chown) pour appartenir à l'utilisateur et au groupe spécifiés dans les arguments de démarrage.

PARAMETRES

Les paramètres suivants peuvent être spécifiés en plus des paramètres de ligne de commande normaux pour un Net::Server. Voir Net::Server pour plus d'informations sur la lecture des arguments.

udp_recv_len
Spécifie le nombre d'octets à lire depuis le descripteur de connexion SOCK_DGRAM. Les données seront lues dans $self->{'server'}->{'udp_data'}. La valeur par défaut est 4096. Voir IO::Socket::INET et recv.
udp_recv_flags
Voir recv. La valeur par défaut est 0.
