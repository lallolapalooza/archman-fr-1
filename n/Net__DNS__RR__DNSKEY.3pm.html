NOM

Net::DNS::RR::DNSKEY - Enregistrement de ressource DNSKEY DNSSEC

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new('name DNSKEY flags protocol algorithm publickey');

DESCRIPTION

Classe pour les enregistrements de ressource DNSSEC Key (DNSKEY).

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées par les méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités non documentées du package ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

flags

$flags = $rr->flags;
$rr->flags( $flags );

Nombre de 16 bits non signé représentant les indicateurs booléens.

zone
$rr->zone(1);
if ( $rr->zone ) {
        ...
}

Indicateur booléen ZONE.

revoke
$rr->revoke(1);
if ( $rr->revoke ) {
        ...
}

Indicateur booléen REVOKE.

sep
$rr->sep(1);
if ( $rr->sep ) {
        ...
}

Indicateur booléen Secure Entry Point (SEP).

protocol

$protocol = $rr->protocol;
$rr->protocol( $protocol );

Le numéro de protocole de 8 bits. Ce champ DOIT avoir la valeur 3.

algorithm

$algorithm = $rr->algorithm;
$rr->algorithm( $algorithm );

Le numéro d'algorithme de 8 bits décrit l'algorithme de clé publique.

algorithm() peut également être appelé comme méthode de classe ou fonction simple pour effectuer la traduction des codes mnémoniques et numériques.

publickey

key

$key = $rr->key;
$rr->key( $key );

Représentation Base64 du matériel de clé publique.

keybin

$keybin = $rr->keybin;
$rr->keybin( $keybin );

Chaîne d'octets opaque représentant le matériel de clé publique.

privatekeyname

$privatekeyname = $rr->privatekeyname;

Retourne le nom de la clé privée tel qu'il serait généré par le programme BIND dnssec-keygen. Le format de ce nom étant :

K<fqdn>+<algorithm>+<keyid>.private

signame

$signame = $rr->signame;

Retourne le nom canonique du signataire de la clé privée.

keylength

Retourne la longueur (en bits) du module calculée à partir du texte de la clé.

keytag

print "keytag = ", $rr->keytag, "\n";

Retourne le tag de clé numérique de 16 bits de la clé. (RFC2535 4.1.6)
