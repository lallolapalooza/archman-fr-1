NOM

Net::DNS::RR::DELEG - enregistrement de ressource DELEG DNS

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('zone DELEG server-ip4=192.0.2.1 ...');
$rr = Net::DNS::RR->new('zone DELEG server-ip6=2001:db8::53 ...');
$rr = Net::DNS::RR->new('zone DELEG server-name=nameserver.example ...');
$rr = Net::DNS::RR->new('zone DELEG include-name=devolved.example');

DESCRIPTION

L'ensemble d'enregistrements de ressources DELEG DNS, où qu'il apparaisse, annonce les serveurs de noms faisant autorité et les paramètres de transport à utiliser pour résoudre les requêtes pour les données au nom du propriétaire ou à tout subordonné de celui-ci.

L'ensemble d'enregistrements DELEG est une donnée faisant autorité dans la zone délégante. Un ensemble d'enregistrements DELEG ne doit pas apparaître à l'apex d'une zone déléguée.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées des méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités non documentées du package ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

server_ip4

eg.example. DELEG server-ip4=192.0.2.1,...
@ip = $rr->server_ip4;

Définit ou récupère une liste d'adresses IP.

server_ip6

eg.example. DELEG server-ip6=2001:db8::53,...
@ip = $rr->server_ip6;

Définit ou récupère une liste d'adresses IP.

server_name

eg.example. DELEG server-name=nameserver.example.
$nameserver = $rr->server_name;

Spécifie le nom de domaine du serveur de noms.

Retourne le nom de domaine du serveur de noms ou la valeur indéfinie si non spécifié.

include_name

eg.example. DELEG include-name=devolved.example.
$destination = $rr->include_name;

Spécifie l'emplacement d'une configuration de serveur de noms dévolue.

Retourne le nom de domaine de destination ou la valeur indéfinie si non spécifié.
