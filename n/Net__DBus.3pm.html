Net::DBus(3) Documentation Perl fournie par l'utilisateur Net::DBus(3)

NOM

Net::DBus - Extension Perl pour le système de messages DBus

SYNOPSIS

####### Connexion au bus ###########
use Net::DBus;
# Trouver le bus le plus approprié
my $bus = Net::DBus->find;
# ... ou choisir explicitement le bus de session
my $bus = Net::DBus->session;
# .... ou choisir explicitement le bus système
my $bus = Net::DBus->system
######## Accès aux services distants #########
# Obtenir une poignée pour le service HAL
my $hal = $bus->get_service("org.freedesktop.Hal");
# Obtenir le gestionnaire de périphériques
my $manager = $hal->get_object("/org/freedesktop/Hal/Manager",
                               "org.freedesktop.Hal.Manager");
# Lister les périphériques
foreach my $dev (@{$manager->GetAllDevices}) {
    print $dev, "\n";
}
######### Fourniture de services ##############
# Enregistrer un service connu sous le nom de 'org.example.Jukebox'
my $service = $bus->export_service("org.example.Jukebox");

DESCRIPTION

Net::DBus fournit une API Perl pour le système de messages DBus. L'interface Perl DBus fonctionne actuellement contre la version de développement 0.32 de DBus, mais devrait également fonctionner avec les versions ultérieures, à condition que les changements d'API n'aient pas été trop drastiques.

Les utilisateurs de ce paquet sont généralement soit des fournisseurs de services, auquel cas les modules Net::DBus::Service et Net::DBus::Object sont les plus pertinents, soit des consommateurs clients, auquel cas Net::DBus::RemoteService et Net::DBus::RemoteObject sont les plus pertinents.

MÉTHODES

my $bus = Net::DBus->find(%params);
Recherche le bus le plus approprié pour se connecter et renvoie une connexion vers celui-ci. L'heuristique utilisée pour la recherche est : 
- Si DBUS_STARTER_BUS_TYPE est défini sur 'session', se connecter
  au bus de session
- Sinon, si DBUS_STARTER_BUS_TYPE est défini sur 'system', se connecter
  au bus système
- Sinon, si DBUS_SESSION_BUS_ADDRESS est défini, se connecter
  au bus de session
- Sinon, se connecter au bus système

La table de hachage optionnelle "params" peut être utilisée pour spécifier des options de connexion. La seule option prise en charge pour le moment est "nomainloop" qui empêche le bus d'être automatiquement attaché à la boucle d'événements principale de Net::DBus::Reactor.

my $bus = Net::DBus->system(%params);
Renvoie une poignée pour le bus de messages système. Notez que le bus de messages système est verrouillé par défaut, donc à moins que des règles de contrôle d'accès appropriées ne soient ajoutées dans /etc/dbus/system.d/, une application peut accéder aux services, mais ne pourra pas exporter de services.

La table de hachage optionnelle "params" peut être utilisée pour spécifier les options suivantes :

nomainloop
Si vrai, empêche le bus d'être automatiquement attaché à la boucle d'événements principale de Net::DBus::Reactor.
private
Si vrai, le socket ouvert est privé ; tout socket existant sera ignoré et toute tentative future d'ouvrir le même bus renverra un socket existant différent ou en ouvrira un nouveau.
my $bus = Net::DBus->session(%params);
Renvoie une poignée pour le bus de messages de session.

La table de hachage optionnelle "params" peut être utilisée pour spécifier les options suivantes :

nomainloop
Si vrai, empêche le bus d'être automatiquement attaché à la boucle d'événements principale de Net::DBus::Reactor.
private
Si vrai, le socket ouvert est privé ; tout socket existant sera ignoré et toute tentative future d'ouvrir le même bus renverra un socket existant différent ou en ouvrira un nouveau.
my $bus = Net::DBus->test(%params);
Renvoie une poignée pour un bus virtuel destiné aux tests unitaires. Ce bus ne fait aucune connexion réseau, mais possède un pipeline de messages en mémoire. Consultez Net::DBus::Test::MockConnection pour plus de détails sur l'utilisation de ce bus spécial.
my $bus = Net::DBus->new($address, %params);
Renvoie une connexion à un bus de messages spécifique. Le paramètre $address doit contenir l'adresse du bus de messages auquel se connecter. Une adresse d'exemple pour un bus de session pourrait ressembler à "unix:abstract=/tmp/dbus-PBFyyuUiVb,guid=191e0a43c3efc222e0818be556d67500", tandis qu'une pour un bus système ressemblerait à "unix:/var/run/dbus/system_bus_socket". La table de hachage optionnelle "params" peut être utilisée pour spécifier des options de connexion. La seule option prise en charge pour le moment est "nomainloop", qui empêche le bus d'être automatiquement attaché à la boucle d'événements principale de Net::DBus::Reactor.
my $connection = $bus->get_connection;
Renvoie une poignée pour l'objet de connexion sous-jacent de bas niveau associé à ce bus. L'objet renvoyé sera une instance de la classe Net::DBus::Binding::Bus. Cette méthode n'est pas destinée à être utilisée par (la plupart !) des développeurs d'applications, donc si vous ne comprenez pas à quoi elle sert, vous n'avez pas besoin de l'appeler !
my $service = $bus->get_service($name);
Récupère une poignée pour le service distant identifié par le nom du service $name. L'objet renvoyé sera une instance de la classe Net::DBus::RemoteService.
my $service = $bus->export_service($name);
Enregistre un service auprès du bus, renvoyant une poignée vers le service. L'objet renvoyé est une instance de la classe Net::DBus::Service.

Lorsque $name n'est pas spécifié ou est "undef", la poignée renvoyée vers le service est identifiée uniquement par le nom unique de la connexion du client au bus.

my $object = $bus->get_bus_object;
Récupère une poignée vers l'objet bus, "/org/freedesktop/DBus", fourni par le service "org.freedesktop.DBus". L'objet renvoyé est une instance de Net::DBus::RemoteObject.
my $name = $bus->get_unique_name;
Récupère le nom unique de la connexion de ce client au bus.
my $name = $bus->get_service_owner($service);
Récupère le nom unique du client sur le bus qui possède le service nommé par le paramètre $service.
my $timeout = $bus->timeout(60 * 1000);
Définit ou récupère la valeur de délai d'attente qui sera utilisée pour les requêtes DBus appartenant à cette connexion de bus. Le délai d'attente doit être spécifié en millisecondes, la valeur par défaut étant de 60 secondes.

MÉTHODES DE TYPAGE DE DONNÉES

Ces méthodes ne sont généralement pas utilisées, car la plupart des services fournissent des données d'introspection pour informer les clients de leurs exigences en matière de typage de données. Si les données d'introspection sont incomplètes, cependant, il peut être nécessaire pour un client de marquer les valeurs avec des types de données spécifiques. Dans ce cas, les méthodes suivantes peuvent être utilisées. Elles ne sont cependant pas exportées par défaut et doivent donc être demandées lors de l'importation en spécifiant 'use Net::DBus qw(:typing)'

$typed_value = dbus_int16($value);
Marque une valeur comme étant un entier signé de 16 bits.
$typed_value = dbus_uint16($value);
Marque une valeur comme étant un entier non signé de 16 bits.
$typed_value = dbus_int32($value);
Marque une valeur comme étant un entier signé de 32 bits.
$typed_value = dbus_uint32($value);
Marque une valeur comme étant un entier non signé de 32 bits.
$typed_value = dbus_int64($value);
Marque une valeur comme étant un entier signé de 64 bits.
$typed_value = dbus_uint64($value);
Marque une valeur comme étant un entier non signé de 64 bits.
$typed_value = dbus_double($value);
Marquer une valeur comme étant un flottant de précision double IEEE.
$typed_value = dbus_byte($value);
Marquer une valeur comme étant un entier non signé de 8 bits.
$typed_value = dbus_string($value);
Marquer une valeur comme étant une chaîne UTF-8. Ce n'est généralement pas nécessaire, car 'string' est le type par défaut pour toute valeur scalaire Perl.
$typed_value = dbus_signature($value);
Marquer une valeur comme étant une chaîne UTF-8 dont le contenu est une signature de type valide.
$typed_value = dbus_object_path($value);
Marquer une valeur comme étant un chemin d'objet UTF-8. Ce n'est généralement pas nécessaire, car 'object_path' est le type par défaut pour toute valeur Perl.
$typed_value = dbus_boolean($value);
Marquer une valeur comme étant une valeur booléenne.
$typed_value = dbus_array($value);
Marquer une valeur comme étant un tableau.
$typed_value = dbus_struct($value);
Marquer une valeur comme étant une structure.
$typed_value = dbus_dict($value);
Marquer une valeur comme étant un dictionnaire.
$typed_value = dbus_variant($value);
Marquer une valeur comme étant une variante.
$typed_value = dbus_unix_fd($value);
Marquer une valeur comme étant un descripteur de fichier Unix.
