DESCRIPTION

NetAddr::IP::InetBase fournit une suite de fonctions de conversion réseau écrites en pur Perl pour convertir les adresses IPv4 et IPv6 au format d'adresse réseau et au format texte.

Les fonctions IPv6 prennent en charge tous les formats rfc1884.

c'est-à-dire  x:x:x:x:x:x:x:x:x
      x:x:x:x:x:x:x:d.d.d.d
      ::x:x:x
      ::x:d.d.d.d
et ainsi de suite...
  • $dotquad = inet_ntoa($netaddr);

    Convertit une adresse réseau IPv4 packagée en une adresse IP point-quad.

    entrée :        adresse réseau packagée
retourne :      adresse IP, c'est-à-dire 10.4.12.123
  • $netaddr = inet_aton($dotquad);

    Convertit une adresse IP point-quad en une adresse réseau IPv4 packagée.

    entrée :        adresse IP, c'est-à-dire 192.5.16.32
retourne :      adresse réseau packagée
  • $ipv6addr = ipv6_aton($ipv6_text);

    Prend une adresse IPv6 de la forme décrite dans le rfc1884 et retourne une chaîne binaire RDATA de 128 bits.

    entrée :        texte IPv6
retourne :      chaîne RDATA de 128 bits
  • $ipv6text = ipv6_ntoa($ipv6naddr);

    Convertit une adresse IPv6 binaire de 128 bits en une représentation texte compressée rfc 1884.

    entrée :        chaîne RDATA de 128 bits
retourne :      texte IPv6
  • $hex_text = ipv6_n2x($ipv6addr);

    Prend une chaîne RDATA IPv6 et retourne une adresse hexadécimale IPv6 à 8 segments.

    entrée :        chaîne RDATA de 128 bits
retourne :      x:x:x:x:x:x:x:x
Remarque : cette fonction NE compresse PAS les chaînes
adjacentes de 0:0:0:0 au format ::
  • $dec_text = ipv6_n2d($ipv6addr);

    Prend une chaîne RDATA IPv6 et retourne une adresse IPv6 mixte hexadécimale - décimale avec les 6 blocs les plus hauts en hexadécimal et les 32 bits inférieurs en représentation point-quad.

    entrée :        chaîne RDATA de 128 bits
retourne :      x:x:x:x:x:x:d.d.d.d
Remarque : cette fonction NE compresse PAS les chaînes
adjacentes de 0:0:0:0 au format ::
  • $ipv6naddr = inet_any2n($dotquad or $ipv6_text);

    Cette fonction convertit une adresse IPv4 ou IPv6 textuelle sous n'importe quelle notation standard en une adresse chaîne IPv6 de 128 bits. Elle préfixe toute adresse point-quad (si trouvée) avec '::' et la passe à ipv6_aton.

    entrée :        point-quad ou adresse rfc1844
retourne :      chaîne IPv6 de 128 bits
  • $dotquad or $hex_text = inet_n2dx($ipv6naddr);

    Cette fonction fait le travail correctement et retourne le texte pour une adresse IPv4 point-quad ou une adresse IPv6 en notation hexadécimale.

    entrée :        chaîne IPv6 de 128 bits
retourne :      ddd.ddd.ddd.ddd
          ou  x:x:x:x:x:x:x:x
Remarque : cette fonction NE compresse PAS les chaînes
adjacentes de 0:0:0:0 au format ::
  • $dotquad or $dec_text = inet_n2ad($ipv6naddr);

    Cette fonction fait le travail correctement et retourne le texte pour une adresse IPv4 point-quad ou une adresse IPv6 en notation hex/décimale.

    entrée :        chaîne IPv6 de 128 bits
retourne :      ddd.ddd.ddd.ddd
          ou  x:x:x:x:x:x:ddd.ddd.ddd.dd
Remarque : cette fonction NE compresse PAS les chaînes
adjacentes de 0:0:0:0 au format ::
  • $netaddr = inet_pton($AF_family,$text_addr);

    Cette fonction prend une adresse IP au format texte IPv4 ou IPv6 et la convertit en format binaire. Le type de conversion d'adresse IP est contrôlé par l'argument FAMILY.

    NOTE : inet_pton, inet_ntop et AF_INET6 proviennent de la bibliothèque Socket6 s'ils sont présents sur cet hôte.

  • $text_addr = inet_ntop($AF_family,$netaddr);

    Cette fonction prend une adresse IP au format binaire et la convertit en format texte. Le type de conversion d'adresse IP est contrôlé par l'argument FAMILY.

    NOTE : inet_ntop retourne TOUJOURS des caractères en minuscules.

    NOTE : inet_pton, inet_ntop et AF_INET6 proviennent de la bibliothèque Socket6 s'ils sont présents sur cet hôte.

  • $hex_text = packzeros($hex_text);

    Cette fonction optimise et formate une adresse hexadécimale IPv6 rfc 1884 pour réduire le nombre de longues chaînes de bits zéro comme spécifié dans le rfc 1884, 2.2 (2) en substituant :: pour la première occurrence de la plus longue chaîne de zéros dans l'adresse.

  • $ipv6naddr = ipv4to6($netaddr);

    Convertit une adresse réseau IPv4 en une adresse réseau IPv6.

    entrée :        adresse réseau 32 bits
retourne :      adresse réseau 128 bits
  • $rv = isIPv4($bits128);

    Cette fonction retourne vrai s'il n'y a pas de bits activés dans la partie IPv6 de la chaîne de 128 bits et faux sinon.

    c'est-à-dire  l'adresse doit être de la forme - ::d.d.d.d

    Remarque : il s'agit d'une vieille adresse IPv6 compatible IPV4, obsolète.

  • $rv = isNewIPv4($bits128);

    Cette fonction retourne vrai si la chaîne IPv6 de 128 bits est de la forme

    ::ffff:d.d.d.d
  • $rv = isAnyIPv4($bits128);

    Cette fonction retourne vrai si la chaîne de bits IPv6 est de la forme

    ::d.d.d.d       ou      ::ffff:d.d.d.d
  • NetAddr::IP::InetBase::lower();

    Retourne les chaînes IPv6 en minuscules. C'est le comportement par défaut.

  • NetAddr::IP::InetBase::upper();

    Retourne les chaînes IPv6 en majuscules.

    Le comportement par défaut peut être réglé sur majuscules lors du chargement du module en invoquant le TAG :upper. c'est-à-dire

    use NetAddr::IP::InetBase qw( :upper );
  • $constant = AF_INET;

    Cette fonction retourne la valeur système pour AF_INET.

  • $constant = AF_INET6;

    AF_INET6 est parfois présent dans la bibliothèque Socket et toujours présent dans la bibliothèque Socket6. Lorsque la bibliothèque Socket ne contient pas AF_INET6 et que Socket6 n'est pas présent, une valeur de substitution est "devinée" en fonction du système d'exploitation sous-jacent de l'hôte. Voir fake_AF_INET6 ci-dessous.

    NOTE : inet_pton, inet_ntop et AF_INET6 proviennent de la bibliothèque Socket6 s'ils sont présents sur cet hôte.

  • $trueif = fake_AF_INET6;

    Cette fonction retourne FAUX si AF_INET6 est fourni par Socket ou Socket6. Sinon, elle retourne la meilleure valeur estimée en fonction du nom du système d'exploitation de l'hôte.

NetAddr::IP::InetBase(3pm)

NAME

NetAddr::IP::InetBase - Base class for IPv4 and IPv6 address handling.

SYNOPSIS

  use NetAddr::IP::InetBase;
  my $obj = NetAddr::IP::InetBase->new;
  # ... methods are inherited by NetAddr::IP and NetAddr::IP::Lite

INSTALLATION

This module is part of the NetAddr-IP distribution.

  perl -MNetAddr::IP::InetBase -e "use NetAddr::IP::InetBase"

DESCRIPTION

This is the base class for handling IP address objects. It is not intended to be used directly but serves as the foundation for NetAddr::IP(3) and NetAddr::IP::Lite(3).

It provides the basic methods for IP address manipulation including conversion between text and binary formats. The methods that are intended to be part of the public interface are defined here, but are intended to be called via the derived classes.

The following methods are available:

  • The constructors are inherited.

  • The following methods are intended for internal use and are not documented here.

  • The following methods are inherited by derived classes:

    • $obj->addr(): Returns the IP address as a decimal string.

    • $obj->bits(): Returns the number of bits in the address (32 or 128).

    • $obj->family(): Returns the address family (AF_INET or AF_INET6).

    • $obj->host(): Returns the IP address as a hostname or a filled IP.
