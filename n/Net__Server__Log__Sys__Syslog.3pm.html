Net::Server::Log::Sys::Syslog(3) Documentation Perl fournie par l'utilisateur Net::Server::Log::Sys::Syslog(3)

NOM

Net::Server::Log::Sys::Syslog - journaliser via Syslog

SYNTAXE

use base qw(Net::Server::PreFork);
__PACKAGE__->run(
    log_file => 'Sys::Syslog',
    syslog_ident => 'myapp',
);

DESCRIPTION

Ce module fournit la journalisation via Sys::Syslog au système Net::Server.

CONFIGURATION

fichier_journal
Pour commencer à utiliser la journalisation Sys::Syslog, définissez simplement le paramètre de configuration log_file de Net::Server sur "Sys::Syslog".

Si le nom magique "Sys::Syslog" est utilisé, toute la journalisation se fera via le module Sys::Syslog. Si syslog est utilisé, les paramètres "syslog_logsock", "syslog_ident", "syslog_logopt" et "syslog_facility" peuvent également être définis.

syslog_logsock
Disponible uniquement si "log_file" est égal à "Sys::Syslog". Peut être unix, inet, native, console, stream, udp, ou tcp, ou un arrayref des types à essayer. La valeur par défaut est "unix" si la version de Sys::Syslog est < 0.15 - sinon, la valeur par défaut est de ne pas appeler setlogsock.

Voir Sys::Syslog.

syslog_ident
Disponible uniquement si "log_file" est égal à "Sys::Syslog". Identifiant à préfixer aux entrées syslog. La valeur par défaut est "net_server". Voir Sys::Syslog.
syslog_logopt
Disponible uniquement si "log_file" est égal à "Sys::Syslog". Peut être zéro ou plusieurs des options "pid", "cons", "ndelay", "nowait". La valeur par défaut est "pid". Voir Sys::Syslog.
syslog_facility
Disponible uniquement si "log_file" est égal à "Sys::Syslog". Voir Sys::Syslog et syslog. La valeur par défaut est "daemon".

ARGUMENTS PAR DEFAUT POUR Net::Server

Les arguments suivants sont disponibles dans les modules "Net::Server" ou "Net::Server::Single" par défaut. (D'autres personnalités peuvent utiliser des paramètres supplémentaires et peuvent facultativement ne pas utiliser les paramètres de la classe de base.)

Clé               Valeur                   Défaut
## paramètres syslog (si log_file eq Sys::Syslog)
syslog_logsock    (native|unix|inet|udp
                   |tcp|stream|console)    unix (sur Sys::Syslog < 0.15)
syslog_ident      "identité"               "net_server"
syslog_logopt     (cons|ndelay|nowait|pid) pid
syslog_facility   \w+                      daemon

METHODES

"initialize"
Cette méthode est appelée lors de la méthode initialize_logging de Net::Server. Elle retourne une seule référence de code qui sera stockée sous la propriété log_function de l'objet Net::Server. Cette référence de code prend les arguments log_level et message et appelle le système log4perl initialisé.
"handle_log_error"
Cette méthode est appelée si la fonction log échoue pour une raison quelconque. Elle reçoit l'objet Net::Server, l'erreur survenue lors de la journalisation et un arrayref contenant le niveau de journalisation et le message. En retour, elle appelle la méthode héritée Net::Server::handle_syslog_error.
