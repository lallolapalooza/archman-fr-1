NOM

Net::CIDR::Lite - Extension Perl pour la fusion d'adresses CIDR IPv4 ou IPv6

SYNOPSIS

use Net::CIDR::Lite;
my $cidr = Net::CIDR::Lite->new;
$cidr->add($cidr_address);
@cidr_list = $cidr->list;
@ip_ranges = $cidr->list_range;

DESCRIPTION

Alternative plus rapide à Net::CIDR lors de la fusion d'un grand nombre de plages d'adresses CIDR. Fonctionne pour les adresses IPv4 et IPv6.

MÉTHODES

new()
$cidr = Net::CIDR::Lite->new
$cidr = Net::CIDR::Lite->new(@args)

Crée un objet pour représenter une liste de plages d'adresses CIDR. Aucun format spécifique n'est encore défini ; une fois qu'une méthode `add` est appelée avec un format IPv4 ou IPv6, seul ce format pourra être ajouté pour cet objet `cidr`. Tous les arguments fournis sont passés à add_any() (voir ci-dessous).

add()
$cidr->add($cidr_address)

Ajoute une plage d'adresses CIDR à la liste.

add_range()
$cidr->add_range($ip_range)

Ajoute une plage d'adresses IP séparées par un tiret à la liste.

add_cidr()
$cidr1->add_cidr($cidr2)

Ajoute les plages d'adresses d'un objet à un autre objet.

add_ip()
$cidr->add_ip($ip_address)

Ajoute une seule adresse IP à la liste.

add_any()
$cidr->add_any($cidr_or_range_or_address);

Détermine le format de la plage ou de l'adresse IP unique et appelle add(), add_range(), add_cidr() ou add_ip() selon le cas.

$cidr->clean()
$cidr->clean;

Si vous allez appeler la méthode `list` plus d'une fois sur les mêmes données, pour une performance optimale, vous pouvez appeler cette méthode pour purger les nœuds nuls dans les plages qui se chevauchent de la liste. Les nœuds frontières dans les plages contiguës sont automatiquement purgés lors de l'appel à add(). Utile uniquement lorsque les plages se chevauchent ou lorsque des plages contiguës sont ajoutées dans le désordre.

$cidr->list()
@cidr_list = $cidr->list;
$list_ref  = $cidr->list;

Renvoie une liste des adresses CIDR fusionnées. Renvoie un tableau si appelé dans un contexte de tableau, une référence de tableau sinon.

$cidr->list_range()
@cidr_list = $cidr->list_range;
$list_ref  = $cidr->list_range;

Renvoie une liste des adresses fusionnées, mais au format de plage séparée par un tiret. Renvoie un tableau si appelé dans un contexte de tableau, une référence de tableau sinon.

$cidr->list_short_range()
@cidr_list = $cidr->list_short_range;
$list_ref  = $cidr->list_short_range;

Renvoie une liste des sous-réseaux C fusionnés, au format court de plage séparée par un tiret. Renvoie un tableau si appelé dans un contexte de tableau, une référence de tableau sinon.

Exemple :

1.1.1.1-2
1.1.1.5-7
1.1.1.254-255
1.1.2.0-2
1.1.3.5
1.1.3.7
$cidr->find()
$found = $cidr->find($ip);

Renvoie vrai si l'adresse IP est trouvée dans la plage CIDR. Faux sinon. Pas extrêmement efficace, c'est O(n*log(n)) pour trier les plages dans l'objet `cidr` et O(n) pour parcourir les plages dans l'objet `cidr`. Le tri est mis en cache lors du premier appel et utilisé lors des appels ultérieurs, mais si d'autres adresses sont ajoutées à l'objet `cidr`, prep_find() doit être appelée sur l'objet `cidr`.

$cidr->bin_find()
Identique à find(), mais force une recherche binaire. Voir aussi `prep_find`.
$cidr->prep_find()
$cidr->prep_find($num);

Met en cache le résultat du tri des adresses IP. Est appelé implicitement lors du premier appel à `find`, mais doit être explicitement appelé si d'autres adresses sont ajoutées à l'objet `cidr`. find() effectuera une recherche binaire si le nombre de plages est supérieur ou égal à $num (par défaut 20).

$cidr->spanner()
$spanner = $cidr1->spanner($label1, $cidr2, $label2, ...);

Crée un objet `spanner` pour déterminer si plusieurs adresses IP se trouvent dans plusieurs plages d'adresses étiquetées. Peut également être appelé comme suit (avec ou sans arguments) :

Net::CIDR::Lite::Span->new($cidr1, $label1, $cidr2, $label2, ...);
$spanner->add()
$spanner->add($cidr1, $label1, $cidr2, $label2,...);

Ajoute des plages d'adresses étiquetées à l'objet `spanner`. La 'plage d'adresses' peut être un objet Net::CIDR::Lite, une plage d'adresses CIDR unique, une plage d'adresses IP unique séparée par un tiret, ou une seule adresse IP.

$spanner->find()
$href = $spanner->find(@ip_addresses);

Recherche dans quelle(s) plage(s) se trouvent les adresses IP et renvoie une table de correspondance des résultats, avec les clés étant les adresses IP, et la valeur une référence de hachage indiquant dans quelles plages d'adresses IP se trouve l'adresse.

$spanner->bin_find()
Identique à find(), mais force une recherche binaire. Voir aussi `prep_find`.
$spanner->prep_find()
$spanner->prep_find($num);

Appelé implicitement la première fois que `$spanner->find(..)` est appelé, doit être rappelé si d'autres objets `cidr` sont ajoutés à l'objet `spanner`. Effectuera une recherche binaire si le ratio du nombre d'adresses IP sur le nombre de plages est inférieur à $num pour cent (par défaut 4).

$spanner->clean()
$clean_address = $spanner->clean($ip_address);

Valide et renvoie une version nettoyée d'une adresse IP (qui est ce que vous trouverez comme clé dans le résultat de `$spanner->find(..)` , pas nécessairement ce à quoi ressemblait l'argument d'origine). Par exemple, supprime les zéros non nécessaires en tête, supprime les blocs nuls des adresses IPv6, etc.

CAVEATS

Entrée de mauvaise qualité/sortie de mauvaise qualité. Ce module effectue des validations, mais peut-être pas suffisamment pour répondre à vos besoins.
