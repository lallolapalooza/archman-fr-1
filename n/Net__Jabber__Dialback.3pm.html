NOM

Net::Jabber::Dialback - Module Dialback Jabber

SYNOPSIS

Net::Jabber::Dialback est un complément au module Net::Jabber::Server.
Il fournit à l'utilisateur une interface simple pour définir et récupérer
toutes les parties d'un Dialback de serveur Jabber.

DESCRIPTION

Pour initialiser le Dialback avec un Jabber <db:*/>, vous devez lui passer
le hash XML::Stream. Par exemple :
  my $dialback = new Net::Jabber::Dialback(%hash);
Vous avez maintenant accès à toutes les fonctions de récupération disponibles.
Pour créer un nouveau message à envoyer au serveur :
  use Net::Jabber qw(Server);
  $DB = new Net::Jabber::Dialback("verify");
  $DB = new Net::Jabber::Dialback("result");
Veuillez consulter la documentation spécifique pour Net::Jabber::Dialback::Result
et Net::Jabber::Dialback::Verify.
Pour plus d'informations sur le format de tableau passé au
CallBack, veuillez lire la documentation de Net::Jabber::Client.
