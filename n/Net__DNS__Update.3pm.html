NAME

Net::DNS::Update - Paquet de mise à jour dynamique DNS

SYNOPSIS

use Net::DNS;
$update = Net::DNS::Update->new( 'example.com' );
$update = Net::DNS::Update->new( 'example.com', 'IN' );
$update = Net::DNS::Update->new( 'example.com', 'IN' );

Retourne un objet Net::DNS::Update adapté pour effectuer une mise à jour DNS dynamique. En particulier, il crée un paquet avec l'opcode de zone défini sur UPDATE et le type d'enregistrement SOA (selon RFC 2136, Section 2.3).

Les développeurs doivent utiliser la méthode push() pour ajouter des RR aux sections prérequis et mise à jour avant d'effectuer la mise à jour.

Les arguments sont le nom de la zone et le type de classe. Le nom et la classe peuvent être indéfinis ou omis et les domaines par défaut seront utilisés selon la configuration du résolveur et IN respectivement.

DESCRIPTION

Net::DNS::Update est une sous-classe de Net::DNS::Packet destinée à être utilisée pour effectuer des mises à jour DNS dynamiques.

Les développeurs doivent se référer à la RFC 2136 pour la sémantique des mises à jour dynamiques.

MÉTHODES

new

$update = Net::DNS::Update->new;
$update = Net::DNS::Update->new( 'example.com' );
$update = Net::DNS::Update->new( 'example.com', 'IN' );

Retourne un objet Net::DNS::Update adapté pour effectuer une mise à jour DNS dynamique. En particulier, il crée un paquet avec l'opcode de zone défini sur UPDATE et le type d'enregistrement SOA (selon RFC 2136, Section 2.3).

Les programmes doivent utiliser la méthode push() pour ajouter des RR aux sections prérequis et mise à jour avant d'effectuer la mise à jour.

Les arguments sont le nom de la zone et le type de classe. Le nom et la classe peuvent être indéfinis ou omis et les domaines par défaut seront utilisés selon la configuration du résolveur et IN respectivement.

push

$ancount = $update->push( prereq => $rr );
$nscount = $update->push( update => $rr );
$arcount = $update->push( additional => $rr );
$nscount = $update->push( update => $rr1, $rr2, $rr3 );
$nscount = $update->push( update => @rr );

Ajoute des RR à la section spécifiée du paquet de mise à jour.

Retourne le nombre d'enregistrements de ressources dans la section spécifiée.

Les noms de section peuvent être abrégés aux trois premiers caractères.

unique_push

$ancount = $update->unique_push( prereq => $rr );
$nscount = $update->unique_push( update => $rr );
$arcount = $update->unique_push( additional => $rr );
$nscount = $update->unique_push( update => $rr1, $rr2, $rr3 );
$nscount = $update->unique_push( update => @rr );

Ajoute des RR à la section spécifiée du paquet de mise à jour, à condition que les RR ne soient pas déjà présents dans la même section.

Retourne le nombre d'enregistrements de ressources dans la section spécifiée.

Les noms de section peuvent être abrégés aux trois premiers caractères.

EXEMPLES

Le premier exemple montre un programme complet. Les exemples suivants ne montrent que la création du paquet de mise à jour.

Bien que les exemples soient présentés en utilisant le format chaîne de RR, la forme (nom => valeur) peut également être utilisée.

Ajouter un nouvel hôte

#!/usr/bin/perl
use Net::DNS;
# Créer le paquet de mise à jour.
my $update = Net::DNS::Update->new('example.com');
# Prérequis : aucun enregistrement d'adresse pour le nom.
$update->push( pre => nxrrset('host.example.com. A') );
$update->push( pre => nxrrset('host.example.com. AAAA') );
# Ajouter deux enregistrements d'adresse pour le nom.
$update->push( update => rr_add('host.example.com. 86400 A 192.0.2.1') );
$update->push( update => rr_add('host.example.com. 86400 AAAA 2001:DB8::1') );
# Envoyer la mise à jour au serveur DNS principal de la zone.
my $resolver = Net::DNS::Resolver->new();
$resolver->nameservers('DNSprimary.example.com');
my $reply = $resolver->send($update);
# Est-ce que ça a fonctionné ?
if ($reply) {
        print 'Update RCODE: ', $reply->header->rcode, "\n";
} else {
        print 'Mise à jour échouée : ', $resolver->errorstring, "\n";
}

Ajouter un enregistrement MX pour un nom qui existe déjà

my $update = Net::DNS::Update->new('example.com');
$update->push( prereq => yxdomain('example.com') );
$update->push( update => rr_add('example.com MX 10 mailhost.example.com') );

Ajouter un enregistrement TXT pour un nom qui n'existe pas

my $update = Net::DNS::Update->new('example.com');
$update->push( prereq => nxdomain('info.example.com') );
$update->push( update => rr_add('info.example.com TXT "yabba dabba doo"') );

Supprimer tous les enregistrements A pour un nom

my $update = Net::DNS::Update->new('example.com');
$update->push( prereq => yxrrset('host.example.com A') );
$update->push( update => rr_del('host.example.com A') );

Supprimer tous les RR pour un nom

my $update = Net::DNS::Update->new('example.com');
$update->push( prereq => yxdomain('byebye.example.com') );
$update->push( update => rr_del('byebye.example.com') );

Effectuer une mise à jour DNS signée à l'aide d'une clé générée par BIND tsig-keygen

my $update = Net::DNS::Update->new('example.com');
$update->push( update => rr_add('host.example.com AAAA 2001:DB8::1') );
$update->sign_tsig( $key_file );
my $reply = $resolver->send( $update );
$reply->verify( $update ) || die $reply->verifyerr;

Signature de la mise à jour DNS à l'aide d'un enregistrement TSIG personnalisé

$update->sign_tsig( $key_file, fudge => 60 );

Une autre façon de signer une mise à jour DNS

use Net::DNS::RR::TSIG;
my $tsig = create Net::DNS::RR::TSIG( $key_file );
$tsig->fudge(60);
my $update = Net::DNS::Update->new('example.com');
$update->push( update     => rr_add('host.example.com AAAA 2001:DB8::1') );
$update->push( additional => $tsig );
