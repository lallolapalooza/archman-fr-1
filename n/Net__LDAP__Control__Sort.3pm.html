NOM

Net::LDAP::Control::Sort - Objet de contrôle de tri côté serveur (SSS)

SYNOPSIS

use Net::LDAP::Control::Sort;
use Net::LDAP::Constant qw(LDAP_CONTROL_SORTRESULT);
$sort = Net::LDAP::Control::Sort->new(
  order => "cn -phone"
);
$mesg = $ldap->search( @args, control => [ $sort ]);
($resp) = $mesg->control( LDAP_CONTROL_SORTRESULT );
print "Les résultats sont triés\n"  if $resp and !$resp->result;

DESCRIPTION

"Net::LDAP::Control::Sort" est une sous-classe de Net::LDAP::Control. Elle fournit une classe pour manipuler le contrôle de requête LDAP Server Side Sort (SSS) 1.2.840.113556.1.4.473 tel que défini dans la RFC-2891.

Si le serveur supporte le tri, alors la réponse d'une opération de recherche inclura un contrôle de résultat de tri. Ce contrôle est géré par Net::LDAP::Control::SortResult.

ARGUMENTS DU CONSTRUCTEUR

order
Une chaîne qui définit comment les entrées peuvent être triées. Elle se compose de plusieurs directives, séparées par des espaces. Chaque directive décrit comment trier les entrées en utilisant un seul attribut. Si deux entrées ont des attributs identiques, alors la directive suivante dans la liste est utilisée.

Chaque directive spécifie un ordre de tri comme suit :

-type_attribut:règle_de_tri

Le signe "-" initial est optionnel et, s'il est présent, indique que l'ordre de tri doit être inversé. "type_attribut" est le nom de l'attribut par lequel trier. "règle_de_tri" est optionnel et indique la règle à utiliser pour le tri, et doit être valide pour le "type_attribut" donné.

Un type_attribut ne devrait apparaître qu'une seule fois dans la liste de tri.

Exemples

"cn"         trier par cn en utilisant la règle de tri par défaut pour l'attribut cn
"-cn"        trier par cn en utilisant l'inverse de la règle de tri par défaut
"age cn"     trier d'abord par âge, puis par cn en utilisant les règles de tri par défaut
"cn:1.2.3.4" trier par cn en utilisant la règle de tri définie comme 1.2.3.4

MÉTHODES

Comme avec Net::LDAP::Control, chaque argument du constructeur décrit ci-dessus est également disponible sous forme de méthode sur l'objet qui renverra la valeur actuelle de l'attribut s'il est appelé sans argument, et définira une nouvelle valeur pour l'attribut s'il est appelé avec un argument.
