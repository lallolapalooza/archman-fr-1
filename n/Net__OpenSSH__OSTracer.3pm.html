NOM

Net::OpenSSH::OSTracer - tracer le processus maître ssh au niveau du système d'exploitation

SYNOPSIS

use Net::OpenSSH;
$Net::OpenSSH::debug |= 512;
Net::OpenSSH->new($host)->system("echo hello world");
system "less /tmp/net_openssh_master.*.strace";

DESCRIPTION

Ceci est un module d'aide de Net::OpenSSH qui vous permet de tracer le processus maître "ssh" au niveau du système d'exploitation en utilisant l'utilitaire approprié disponible sur votre système (par exemple, "strace", "truss", "ktruss", "tusc", etc.).

Cette fonctionnalité peut être utilisée pour déboguer vos programmes ou pour signaler des bugs sur le module.

Elle est activée en réglant le drapeau 512 dans la variable $Net::OpenSSH::debug :

$Net::OpenSSH::debug |= 512;

Par défaut, les fichiers de sortie du traceur sont enregistrés sous le nom "/tmp/net_openssh_master.$pid.$tracer_type".

De plus, la sortie envoyée par le traceur vers stdout/stderr est enregistrée sous le nom "/tmp/net_openssh_master.$pid.txt".

Le module peut être configuré via les variables globales suivantes :

$Net::OpenSSH::OSTracer::type
Par défaut, le module décide quel traceur utiliser en fonction du nom du système d'exploitation. Cette variable permet de sélectionner un traceur différent.

Les types actuellement acceptés sont : "strace" (Linux), "ktrace" (*BSD), "tusc" (HP-UX) et "truss" (Solaris et AIX).

$Net::OpenSSH::OSTracer::cmd
Commande à exécuter pour tracer le processus "ssh".

Par défaut, elle est déduite du type de traceur sélectionné.

$Net::OpenSSH::OSTracer::output
Nom de base du fichier de destination. Le PID du processus "ssh" et le type de traceur seront ajoutés.
$Net::OpenSSH::OSTracer::sudo
Cette variable peut être utilisée pour demander que le traceur soit exécuté avec "sudo" (certains systèmes d'exploitation, comme par exemple Ubuntu, ne permettent pas de joindre des traceurs, même à vos propres processus, à moins de le faire en tant que root).

La variable doit être définie avec le chemin du binaire "sudo". Par exemple :

$Net::OpenSSH::OSTracer::sudo = '/usr/bin/sudo';

Si vous avez besoin de passer un mot de passe à "sudo", définissez la variable d'environnement "SUDO_ASKPASS". Par exemple :

SUDO_ASKPASS=/usr/bin/ssh-askpass
$Net::OpenSSH::OSTracer::delay
Cette variable peut être utilisée pour retarder l'exécution de "ssh" afin que le traceur puisse attacher le processus en premier. Ceci est particulièrement utile lorsque vous utilisez "sudo" avec un mot de passe.

BOGUES

Ce module n'a pas été testé sur tous les systèmes d'exploitation qu'il prétend supporter.

Si vous trouvez un problème, signalez-le, s'il vous plaît !
