NOM

Net::POP3 - Classe client du protocole Post Office Protocol 3 (RFC1939)

SYNOPSIS

use Net::POP3;
# Constructeurs
$pop = Net::POP3->new('pop3host');
$pop = Net::POP3->new('pop3host', Timeout => 60);
$pop = Net::POP3->new('pop3host', SSL => 1, Timeout => 60);
if ($pop->login($username, $password) > 0) {
  my $msgnums = $pop->list; # hachage des msgnum => taille
  foreach my $msgnum (keys %$msgnums) {
    my $msg = $pop->get($msgnum);
    print @$msg;
    $pop->delete($msgnum);
  }
}
$pop->quit;

DESCRIPTION

Ce module implémente une interface client pour le protocole POP3, permettant à une application perl5 de communiquer avec des serveurs POP3. Cette documentation suppose que vous êtes familier avec le protocole POP3 décrit dans la RFC1939. Avec IO::Socket::SSL installé, il fournit également un support pour le chiffrement TLS implicite et explicite, c'est-à-dire POP3S ou POP3+STARTTLS.

Un nouvel objet Net::POP3 doit être créé avec la méthode new. Une fois cela fait, toutes les commandes POP3 sont accessibles via des appels de méthode sur l'objet.

La classe Net::POP3 est une sous-classe de Net::Cmd et (selon disponibilité) de IO::Socket::IP, IO::Socket::INET6 ou IO::Socket::INET.

Méthodes de classe

"new([$h%C3%B4te][, %options])"
Ceci est le constructeur pour un nouvel objet Net::POP3. $h%C3%B4te est le nom de l'hôte distant auquel une connexion POP3 est requise.

$h%C3%B4te est optionnel. Si $h%C3%B4te n'est pas fourni, il peut être passé comme option "Host" décrite ci-dessous. Si aucun des deux n'est fourni, alors les "POP3_Hosts" spécifiés dans "Net::Config" seront utilisés.

%options sont passées sous forme de clé-valeur. Les options possibles sont :

Host - Hôte POP3 auquel se connecter. Il peut s'agir d'un scalaire simple, tel que défini pour l'option "PeerAddr" dans IO::Socket::INET, ou d'une référence à un tableau avec des hôtes à essayer tour à tour. La méthode "host" retournera la valeur qui a été utilisée pour se connecter à l'hôte.

Port - Port auquel se connecter. Défaut - 110 pour POP3 standard et 995 pour POP3s (SSL direct).

SSL - Si la connexion doit être établie dès le début avec SSL, contrairement à une mise à niveau ultérieure avec "starttls". Vous pouvez utiliser les arguments SSL tels que documentés dans IO::Socket::SSL, mais il utilisera généralement déjà les bons arguments.

LocalAddr et LocalPort - Ces paramètres sont passés directement à IO::Socket pour permettre de lier le socket à une adresse et un port locaux spécifiques. Pour la compatibilité avec les anciennes versions, ResvPort peut être utilisé à la place de LocalPort.

Domain - Ce paramètre est passé directement à IO::Socket et permet d'imposer des connexions IPv4 même si IO::Socket::IP est utilisé comme classe parente. Alternativement, Family peut être utilisé.

Timeout - Temps maximum, en secondes, pour attendre une réponse du serveur POP3 (défaut : 120)

Debug - Activer les informations de débogage

Méthodes d'objet

Sauf indication contraire, toutes les méthodes retournent une valeur vraie ou fausse, où vrai signifie que l'opération a réussi. Lorsqu'une méthode indique qu'elle retourne une valeur, un échec sera retourné comme undef ou une liste vide.

"Net::POP3" hérite de "Net::Cmd", ainsi les méthodes définies dans "Net::Cmd" peuvent être utilisées pour envoyer des commandes au serveur POP3 distant en plus des méthodes documentées ici.

host()
Retourne la valeur utilisée par le constructeur, et passée à IO::Socket::INET, pour se connecter à l'hôte.
"auth($nom_utilisateur, $mot_de_passe)"
Tente l'authentification SASL.
user($utilisateur)
Envoie la commande USER.
pass($mot_de_passe)
Envoie la commande PASS. Retourne le nombre de messages dans la boîte aux lettres.
"login([$utilisateur[, $mot_de_passe]])"
Envoie les commandes USER et PASS. Si $mot_de_passe n'est pas fourni, "Net::POP3" utilise "Net::Netrc" pour rechercher le mot de passe en utilisant l'hôte et le nom d'utilisateur. Si le nom d'utilisateur n'est pas spécifié, le nom d'utilisateur courant sera utilisé.

Retourne le nombre de messages dans la boîte aux lettres. Cependant, s'il n'y a pas de messages sur le serveur, la chaîne "0E0" sera retournée. Cela donnera une valeur vraie dans un contexte booléen, mais zéro dans un contexte numérique.

S'il y a eu une erreur lors de l'authentification de l'utilisateur, undef sera retourné.

starttls(%sslargs)
Met à niveau la connexion normale existante vers SSL. Vous pouvez utiliser les arguments SSL tels que documentés dans IO::Socket::SSL, mais il utilisera généralement déjà les bons arguments.
"apop([$utilisateur[, $mot_de_passe]])"
Authentifie auprès du serveur en s'identifiant comme $utilisateur avec le mot de passe $mot_de_passe. Similaire à "login", mais le mot de passe n'est pas envoyé en clair.

Pour utiliser cette méthode, vous devez avoir installé le module Digest::MD5 ou MD5, sinon cette méthode retournera undef.

banner()
Retourne la bannière de connexion du serveur
capa()
Retourne une référence à un hachage des capacités du serveur. APOP est ajouté comme capacité pseudo. Notez que je n'ai pas réussi à trouver une liste des valeurs de capacité standard, et certaines semblent avoir plusieurs mots et d'autres non. Nous faisons une tentative de les analyser intelligemment, mais cela pourrait ne pas être correct.
capabilities()
Identique à capa, mais utilise uniquement un cache de la dernière fois que nous avons interrogé le serveur, afin d'éviter de le demander plus d'une fois.
"top($num_msg[, $nb_lignes])"
Récupère l'en-tête et les $nb_lignes premières lignes du corps du message $num_msg. Retourne une référence à un tableau contenant les lignes de texte lues depuis le serveur.
list([$num_msg])
Si appelée avec un argument, "list" retourne la taille du message en octets.

Si appelée sans argument, une référence à un hachage est retournée. Les clés seront les $num_msg de tous les messages non supprimés et les valeurs seront leur taille en octets.

"get($num_msg[, $fh])"
Récupère le message $num_msg de la boîte aux lettres distante. Si $fh n'est pas fourni, get retourne une référence à un tableau contenant les lignes de texte lues depuis le serveur. Si $fh est fourni, les lignes retournées par le serveur sont imprimées dans le descripteur de fichier $fh.
getfh($num_msg)
Comme pour get(), mais retourne un descripteur de fichier lié. La lecture depuis ce descripteur de fichier retourne le message demandé. Le descripteur de fichier retournera EOF à la fin du message et ne devra pas être réutilisé.
last()
Retourne le plus grand $num_msg de tous les messages accédés.
popstat()
Retourne une liste de deux éléments. Ce sont le nombre d'éléments non supprimés et la taille de la boîte aux lettres en octets.
ping($utilisateur)
Retourne une liste de deux éléments. Ce sont le nombre de nouveaux messages et le nombre total de messages pour $utilisateur.

Net::POP3(3pm)

NAME

Net::POP3 ― POP3 client.

SYNOPSIS

    use Net::POP3;

    my $pop = Net::POP3->new('mail.example.com');
    unless ($pop) {
        die "Could not connect to mail.example.com: $@";
    }

    $pop->user('your_username');
    $pop->pass('your_password');

    # Get a list of messages and their sizes
    my ($msgs, $octets) = $pop->list;

    # Retrieve the first message
    my $msg = $pop->get(1);

    # Retrieve all messages
    my %msgs = $pop->getall;

    # Mark message 2 for deletion
    $pop->delete(2);

    # Reset the server state (undo deletions)
    $pop->reset;

    # Quit and remove deleted messages
    $pop->quit;

    # Or disconnect without deleting
    # $pop->disconnect;

DESCRIPTION

The Net::POP3 module provides a client interface to the POP3 protocol. It allows you to connect to a POP3 server, retrieve mail messages, and manage them.

new($host, $port, $arg)

Constructs a new Net::POP3 object. Connects to the POP3 server specified by $host on the given $port (defaulting to 110). $arg can be used to pass arguments to the underlying IO::Socket::INET constructor. Returns a reference to the Net::POP3 object on success, or undef on failure.

user($user)

Sets the username for authentication.

pass($pass)

Sets the password for authentication.

login()

Performs the login using the previously set username and password.

apop($user, $uniqueid)

Performs APOP authentication.

stat()

Returns the number of messages in the mailbox and the total number of octets.

list($msgnum)

If $msgnum is given, returns the message number and its size in octets. If $msgnum is not given, returns a list of all message numbers and their sizes.

uidl($msgnum)

If $msgnum is given, returns the unique identifier for that message. If $msgnum is not given, returns a reference to a hash where the keys are the message numbers and the values are the unique identifiers.

get($msgnum)

Retrieves the message specified by $msgnum. Returns a reference to an array of strings, where each string is a line from the message.

getall()

Retrieves all messages from the mailbox. Returns a hash where keys are message numbers and values are references to arrays of strings (the message content).

top($msgnum, $n)

Retrieves the headers and the first $n lines of the message specified by $msgnum.

dele($msgnum)

Marks message $msgnum for deletion from the remote mailbox. All messages marked for deletion will be removed from the remote mailbox when the server connection is closed.

reset()

Resets the status of the remote POP3 server. This includes resetting the status of all messages to not be deleted.

quit()

Quits and closes the connection to the remote POP3 server. Any messages marked as deleted will be deleted from the remote mailbox.

disconnect()

Closes the connection to the remote POP3 server without deleting any messages.

can_inet6()

Returns whether we can use IPv6.

can_ssl()

Returns whether we can use SSL.

uidl($msgnum)
If $msgnum is given, returns the unique identifier for that message. If $msgnum is not given, returns a reference to a hash where the keys are the message numbers and the values are the unique identifiers.
delete($msgnum)
Mark message $msgnum to be deleted from the remote mailbox. All messages that are marked to be deleted will be removed from the remote mailbox when the server connection closed.
reset()
Reset the status of the remote POP3 server. This includes resetting the status of all messages to not be deleted.
quit()
Quit and close the connection to the remote POP3 server. Any messages marked as deleted will be deleted from the remote mailbox.
can_inet6()
Returns whether we can use IPv6.
can_ssl()
Returns whether we can use SSL.

Notes

If a "Net::POP3" object goes out of scope before "quit" method is called then the "reset" method will called before the connection is closed. This means that any messages marked to be deleted will not be.
