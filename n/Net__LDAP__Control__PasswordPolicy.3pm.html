Net::LDAP::Control::PasswordPolicy(3) Documentation Perl fournie par l'utilisateur Net::LDAP::Control::PasswordPolicy(3)

NOM

Net::LDAP::Control::PasswordPolicy - Objet de contrôle de politique de mot de passe LDAPv3

SYNOPSIS

use Net::LDAP;
use Net::LDAP::Control::PasswordPolicy;
use Net::LDAP::Constant qw( LDAP_CONTROL_PASSWORDPOLICY );
$ldap = Net::LDAP->new( "ldap.example.com" );
$pp = Net::LDAP::Control::PasswordPolicy->new;
$mesg = $ldap->bind( "cn=Bob Smith,dc=example,dc=com",
                     password => "secret",
                     control => [ $pp ] );
# Obtenir la réponse de la politique de mot de passe
my($resp)  = $mesg->control( LDAP_CONTROL_PASSWORDPOLICY );
if (defined($resp)) {
  my $v = $resp->pp_error;
  print "Erreur de politique de mot de passe $v\n"  if defined $v;
  $v = $resp->time_before_expiration;
  print "Le mot de passe expire dans $v seconde(s)\n"  if defined $v;
}

DESCRIPTION

"Net::LDAP::Control::PasswordPolicy" fournit une interface pour la création et la manipulation d'objets qui représentent les "PasswordPolicyRequest" et "PasswordPolicyResponse" tels que décrits par draft-behera-password-policy-09.

Ce contrôle peut être passé à la plupart des opérations, y compris la liaison (bind).

ARGUMENTS DU CONSTRUCTEUR

Il n'y a pas d'arguments de constructeur autres que ceux fournis par Net::LDAP::Control.

MÉTHODES

time_before_expiration
Si défini, c'est une valeur entière indiquant le temps restant en secondes avant que le mot de passe du compte n'expire.
grace_authentications_remaining
Si défini, c'est une valeur entière indiquant le nombre de requêtes d'authentification autorisées avant que le compte ne soit verrouillé.
pp_error
Si défini, il contient un code d'erreur plus détaillé pour le compte. Voir Net::LDAP::Constant pour les définitions de chacun. Les valeurs peuvent inclure :
LDAP_PP_PASSWORD_EXPIRED
LDAP_PP_ACCOUNT_LOCKED
LDAP_PP_CHANGE_AFTER_RESET
LDAP_PP_PASSWORD_MOD_NOT_ALLOWED
LDAP_PP_MUST_SUPPLY_OLD_PASSWORD
LDAP_PP_INSUFFICIENT_PASSWORD_QUALITY
LDAP_PP_PASSWORD_TOO_SHORT
LDAP_PP_PASSWORD_TOO_YOUNG
LDAP_PP_PASSWORD_IN_HISTORY

VOIR AUSSI

Net::LDAP, Net::LDAP::Control, Net::LDAP::Constant, draft-behera-ldap-password-policy-09.txt
