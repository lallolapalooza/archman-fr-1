NAME

Objet de roster XMPP

SYNOPSIS

Net::XMPP::Roster est un module qui fournit une interface facile à utiliser pour interagir avec le roster d'un utilisateur. Il permet des fonctions de haut niveau pour interroger, mettre à jour et gérer le roster d'un utilisateur.

DESCRIPTION

L'objet roster vise à fournir une interface facile à utiliser pour interagir avec le roster d'un utilisateur. Lorsque vous l'instanciez, il s'enregistre automatiquement auprès de la connexion pour recevoir les paquets corrects ainsi que pour continuer à surveiller toutes les modifications du roster et les paquets de présence.

Fonctions de base

my $Client = Net::XMPP::Client->new(...);
my $Roster = Net::XMPP::Roster->new(connection=>$Client);
  ou
my $Roster = $Client->Roster();
$Roster->clear();
if ($Roster->exists('bob@jabber.org')) { ... }
if ($Roster->exists(Net::XMPP::JID)) { ... }
if ($Roster->groupExists("Friends")) { ... }
my @groups = $Roster->groups();
my @jids    = $Roster->jids();
my @friends = $Roster->jids("group","Friends");
my @unfiled = $Roster->jids("nogroup");
if ($Roster->online('bob@jabber.org')) { ... }
if ($Roster->online(Net::XMPP::JID)) { ... }
my %hash = $Roster->query('bob@jabber.org');
my %hash = $Roster->query(Net::XMPP::JID);
my $name = $Roster->query('bob@jabber.org',"name");
my $ask  = $Roster->query(Net::XMPP::JID,"ask");
my $resource = $Roster->resource('bob@jabber.org');
my $resource = $Roster->resource(Net::XMPP::JID);
my %hash = $Roster->resourceQuery('bob@jabber.org',"Home");
my %hash = $Roster->resourceQuery(Net::XMPP::JID,"Club");
my $show   = $Roster->resourceQuery('bob@jabber.org',"Home","show");
my $status = $Roster->resourceQuery(Net::XMPP::JID,"Work","status");
my @resource = $Roster->resources('bob@jabber.org');
my @resource = $Roster->resources(Net::XMPP::JID);
$Roster->resourceStore('bob@jabber.org',"Home","gpgkey",key);
$Roster->resourceStore(Net::XMPP::JID,"logged on","2004/04/07 ...");
$Roster->store('bob@jabber.org',"avatar",avatar);
$Roster->store(Net::XMPP::JID,"display_name","Bob");

Fonctions avancées

Ces fonctions ne sont nécessaires que si vous souhaitez contrôler manuellement le roster.

$Roster->add('bob@jabber.org',
             name=>"Bob",
             groups=>["Friends"]
            );
$Roster->add(Net::XMPP::JID);
$Roster->addResource('bob@jabber.org',
                     "Home",
                     show=>"dnd",
                     status=>"Working"
                    );
$Roster->addResource(Net::XMPP::JID,"Work");
$Roster->remove('bob@jabber.org');
$Roster->remove(Net::XMPP::JID);
$Roster->removeResource('bob@jabber.org',"Home");
$Roster->removeResource(Net::XMPP::JID,"Work");
$Roster->handler(Net::XMPP::IQ);
$Roster->handler(Net::XMPP::Presence);

MÉTHODES

Fonctions de base

new
new(connection=>object)

Crée et initialise l'objet roster. L'objet de connexion est nécessaire pour que le roster puisse interagir avec l'objet de connexion principal. Il doit s'agir d'un objet qui hérite de Net::XMPP::Connection.

clear
clear()

Supprime tout de la base de données.

exists
exists(jid)

Retourne 1 si le JID existe dans la base de données, sinon undef. Le jid peut être une chaîne ou un objet Net::XMPP::JID.

groupExists
groupExists(group)

Retourne 1 si le groupe existe dans la base de données, sinon undef.

groups
groups()

Retourne une liste de tous les groupes du roster.

jids
jids([type, [group]])

Retourne une liste de tous les JID correspondants. Les types valides sont :

all     - renvoie tous les JID du roster. (par défaut)
nogroup - renvoie tous les JID qui ne sont dans aucun groupe.
group   - renvoie tous les JID du groupe spécifié.
online
online(jid)

Retourne 1 si le JID est en ligne, sinon undef. Le jid peut être une chaîne ou un objet Net::XMPP::JID.

query
query(jid, [key])

Retourne une table de hachage représentant toutes les informations de la base de données pour ce JID. Le jid peut être une chaîne ou un objet Net::XMPP::JID. Si vous spécifiez une clé, seule la valeur pour cette clé sera retournée.

resource
resource(jid)

Retourne la chaîne représentant la ressource avec la priorité la plus élevée pour le JID. Le jid peut être une chaîne ou un objet Net::XMPP::JID.

resourceQuery
resourceQuery(jid,     
              resource,
              [key])

Retourne une table de hachage représentant toutes les informations de ressource de ce JID dans la base de données. Le jid peut être une chaîne ou un objet Net::XMPP::JID. Si vous spécifiez une clé, seule la valeur pour cette clé sera retournée.

resources
resources(jid)

Retourne la liste des ressources pour le JID, par ordre de priorité décroissante. Le jid peut être une chaîne ou un objet Net::XMPP::JID.

resourceStore
resourceStore(jid,     
              resource,
              key,     
              value)

Stocke la valeur spécifiée dans la base de données sous la clé donnée pour la ressource de ce JID. Le jid peut être une chaîne ou un objet Net::XMPP::JID.

store
store(jid, key, value)

Stocke la valeur spécifiée dans la base de données sous la clé donnée pour ce JID. Le jid peut être une chaîne ou un objet Net::XMPP::JID.

Fonctions avancées

add(jid, - Ajoute le JID au roster manuellement avec les options de demande, spécifiées dans l'élément du roster. Ceci ne gère pas la souscription des autres utilisateurs, il manipule simplement l'objet roster. Le jid peut être une chaîne ou un objet Net::XMPP::JID.

addResource(jid, - Ajoute la ressource au JID dans le roster avec les options de présence spécifiées. Ceci ne gère pas la souscription des autres utilisateurs, il manipule simplement l'objet roster. Le jid peut être une chaîne ou un objet Net::XMPP::JID.

remove(jid) - Supprime toutes les références au JID de l'objet roster. Le jid peut être une chaîne ou un objet Net::XMPP::JID.

removeResource(jid, - Supprime la ressource du JID dans le roster. Le jid peut être une chaîne ou un objet Net::XMPP::JID.

handler(packet) - Prend un paquet de type Net::XMPP::IQ ou Net::XMPP::Presence et le parse selon les règles de l'objet roster. Remarque : cela ne consomme du temps CPU que si vous lui passez des paquets non liés au roster.
