NOM

Net::DBus::Tutorial - tutoriels sur les API Perl DBus

DESCRIPTION

Cette section inclut des tutoriels sur les API Perl DBus. Les sujets actuels incluent la fourniture d'un service, en exportant des objets vers le bus, et l'accès à un service, en appelant des objets sur le bus.

Net::DBus::Tutorial::ExportingObjects
Ce tutoriel explique comment fournir un service au bus en exportant des objets. Les sujets abordés incluent les bases de la création d'objets et de méthodes, l'émission de signaux, l'exportation de propriétés, l'enregistrement de services pour l'activation automatique.
Net::DBus::Tutorial::UsingObjects
Ce tutoriel explique comment utiliser un service fourni sur le bus par une autre application. Les sujets abordés incluent les bases de l'appel de méthodes sur des objets distants, l'appel explicite de méthodes dans des interfaces particulières, l'écoute de signaux.

NB Ce tutoriel n'est pas encore écrit.
