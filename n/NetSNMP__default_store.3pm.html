NetSNMP__default_store(3pm)

Paquet: net-snmp

Licences: BSD

default_store(3) Documentation Perl fournie par l'utilisateur default_store(3)

NOM

NetSNMP::default_store - Extension Perl pour le stockage global des données Net-SNMP

SYNTAXE

use NetSNMP::default_store qw(:all);
$port = netsnmp_ds_get_int(NETSNMP_DS_LIBRARY_ID, DS_LIB_DEFAULT_PORT);
netsnmp_ds_set_int(NETSNMP_DS_LIBRARY_ID, DS_LIB_DEFAULT_PORT, 161);

DESCRIPTION

Ce module est une enveloppe autour des routines de stockage par défaut de net-snmp. Voir la page man default_store de net-snmp pour des détails sur ce que font les diverses fonctions et les valeurs qui peuvent être définies/récupérées.

EXPORTATION

Aucune par défaut.
