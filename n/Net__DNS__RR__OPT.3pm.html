NOM

Net::DNS::RR::OPT - enregistrement de ressource DNS OPT

SYNOPIS

use Net::DNS;
my $packet = Net::DNS::Packet->new( ... );
$packet->header->do(1);         # indicateur d'en-tête étendu 
$packet->edns->UDPsize(1232);   # taille de la charge utile UDP
$packet->edns->option( 'NSID' => {'OPTION-DATA' => 'rawbytes'} );
$packet->edns->option( 'DAU'  => [8, 10, 13, 14, 15, 16] );
$packet->edns->option( 'TCP-KEEPALIVE' => 200 );
$packet->edns->option( 'EXTENDED-ERROR' => {'INFO-CODE' => 123} );
$packet->edns->option( '65023' => {'BASE16' => '076578616d706c6500'} );
$packet->edns->print;
;; {    "EDNS-VERSION": 0,
;;      "FLAGS":        32768,
;;      "RCODE":        0,
;;      "UDPSIZE":      1232,
;;      "OPTIONS":      [
;;              {"NSID": "7261776279746573"},
;;              {"DAU": [ 8, 10, 13, 14, 15, 16 ]},
;;              {"TCP-KEEPALIVE": {"TIMEOUT": 200}},
;;              {"EXTENDED-ERROR": {"INFO-CODE": 123, "EXTRA-TEXT": ""}},
;;              {"65023": {"BASE16": "076578616d706c6500"}} ]
;;      }

DESCRIPTION

Pseudo enregistrement de ressource OPT EDNS.

L'enregistrement OPT prend en charge les extensions de protocole EDNS et n'est pas destiné à être créé, accédé ou modifié directement par des applications utilisateur.

Toutes les fonctionnalités EDNS sont effectuées indirectement par des opérations sur les objets retournés par les méthodes créatrices $packet->header et $packet->edns. Les mécanismes sous-jacents sont, ou devraient être, entièrement cachés à l'utilisateur.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités de paquet non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner la terminaison du programme ou un autre comportement imprévisible.

version

$version = $packet->edns->version;

La version d'EDNS prise en charge par cet enregistrement OPT.

UDPsize

$size = $packet->edns->UDPsize;
$packet->edns->UDPsize($size);

UDPsize() annonce la taille maximale (octets) du paquet UDP qui peut être réassemblé dans la pile réseau de l'hôte d'origine.

rcode

$extended_rcode = $packet->header->rcode;

Le RCODE étendu de 12 bits. Les 8 bits les plus significatifs sont obtenus de l'enregistrement OPT. Les 4 bits les moins significatifs résident dans l'en-tête du paquet.

flags

$do = $packet->header->do;
$packet->header->do(1);
$edns_flags = $packet->edns->flags;

Champ de 16 bits contenant les indicateurs d'en-tête étendus EDNS.

options

my @options = $packet->edns->options;

Lorsqu'elle est appelée dans un contexte de liste, options() renvoie une liste de codes d'options trouvés dans l'enregistrement OPT.

option

my $octets = $packet->edns->option('COOKIE');
my $base16 = unpack 'H*', $octets;

Lorsqu'elle est appelée dans un contexte scalaire avec un seul argument, option() renvoie la valeur de l'option spécifiée sous forme de chaîne d'octets non interprétée. La méthode renvoie undef si l'option est absente.

$packet->edns->option( 'COOKIE' => {'OPTION-DATA' => $octets} );
$packet->edns->option( '10'     => {'BASE16' => $base16} );

Une option peut être ajoutée ou remplacée en fournissant la paire (nom, valeur). L'option est supprimée si la valeur est indéfinie.

my ($structure) = $packet->edns->option("DAU");
my $array       = $$structure{"DAU"};
my @algorithms  = @$array;
my ($structure) = $packet->edns->option(15);
my $table       = $$structure{"EXTENDED-ERROR"};
my $info_code   = $$table{'INFO-CODE'};
my $extra_text  = $$table{'EXTRA-TEXT'};

Lorsqu'elle est appelée dans un contexte de liste avec un seul argument, option() renvoie une représentation structurée de l'option spécifiée.

Des formes similaires de syntaxe de tableau ou de hachage peuvent être utilisées pour construire la valeur de l'option :

$packet->edns->option( 'DAU' => [8, 10, 13, 14, 15, 16] );
$packet->edns->option( 'EXTENDED-ERROR' => {
                                'INFO-CODE'  => 123,
                                'EXTRA-TEXT' => ""
                                } );
