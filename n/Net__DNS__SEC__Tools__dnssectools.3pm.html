NOM

Net::DNS::SEC::Tools::dnssectools - Routines générales pour le package DNSSEC-Tools.

SYNOPSIS

use Net::DNS::SEC::Tools::dnssectools;
dt_adminmail($sujet,$corps_msg,$destinataire);
$chemin_zone = dt_cmdpath('zonesigner');
$type_fichier = dt_findtype($chemin);
$secondes = dt_parse_duration("0w3d1h10m20s")
$rrset = dt_parse_zonefile(file => 'example.com');

DESCRIPTION

Le module dnssectools fournit un ensemble de méthodes générales pour l'utilisation des utilitaires DNSSEC-Tools.

INTERFACES

Les interfaces du module dnssectools sont données ci-dessous.

dt_adminmail(sujet,corps_msg,destinataire)
Cette routine envoie par courrier électronique un message à l'utilisateur administratif listé dans le fichier de configuration DNSSEC-Tools.

dt_adminmail() nécessite deux paramètres, tous deux scalaires. Le paramètre sujet est le sujet du message électronique. Le paramètre corps_msg est le corps du message électronique.

Un troisième paramètre, destinataire, peut être donné pour spécifier le destinataire du message. S'il n'est pas donné, alors le destinataire sera pris de l'enregistrement admin-email du fichier de configuration DNSSEC-Tools. Si destinataire est "nomail", alors aucun message ne sera envoyé et le succès sera retourné.

Valeurs de retour :

1 - le message a été créé et envoyé.
0 - un destinataire invalide a été spécifié.

Elle s'appuie sur les paramètres de configuration dnssec-tools.conf suivants :

admin-email
L'adresse e-mail d'où doit provenir le courrier.
mailer-type
Doit être l'un des suivants : sendmail, smtp, qmail. Cette option n'est pas obligatoire et tentera par défaut d'envoyer le courrier via sendmail et qmail. Si mailer-server est défini mais mailer-type ne l'est pas, alors mailer-type prendra par défaut
mailer-server
Le serveur, si admin-mail est défini sur smtp, vers lequel le courrier doit être livré.
dt_cmdpath(commande)
Cette routine retourne le chemin vers une commande DNSSEC-Tools spécifiée. commande doit être uniquement le nom, sans aucun répertoire de tête. Le nom de la commande est vérifié pour s'assurer qu'il s'agit d'une commande valide de DNSEC-Tools.

Valeurs de retour :

Le chemin absolu vers la commande est retourné si la commande
est valide.
Null est retourné si la commande n'est pas valide.
dt_filetype(chemin)
Cette routine retourne le type du fichier nommé dans chemin. Les enregistrements rollrec et keyrec qu'il contient sont comptés et une détermination de type est effectuée.

Valeurs de retour :

"keyrec" - Au moins un enregistrement keyrec a été trouvé et aucun
            enregistrement rollrec n'a été trouvé.
"rollrec" - Au moins un enregistrement rollrec a été trouvé et
            aucun enregistrement keyrec n'a été trouvé.
"mixed" -   Au moins un enregistrement rollrec et au moins un
            enregistrement keyrec ont été trouvés.
            Ceci est très probablement un fichier erroné.
"unknown" - Aucun enregistrement rollrec ni keyrec
            n'a été trouvé.
"nofile"  - Le fichier spécifié n'existe pas.
dt_parse_duration(chaine)
Cette routine traduit une durée donnée au format "1w2d3h4m5s" et retourne le nombre équivalent de secondes, ou undef si la durée a un format invalide.
dt_parse_zonefile(options)
Cette routine analyse un fichier de zone donné en utilisant l'analyseur de fichier de zone configuré et retourne une référence de tableau contenant les RR.

L'analyseur de zone à utiliser dépend du réglage de la valeur de configuration zonefile-parser. Si ce n'est pas défini, alors l'analyseur de zone Net::DNS::ZoneFile sera utilisé (option obsolète : c'est le seul analyseur actuellement pris en charge).
