IPv4Addr(3) Documentation Perl fournie par l'utilisateur IPv4Addr(3)

NOM

Net::IPv4Addr - Extension Perl pour la manipulation des adresses IPv4.

SYNOPSIS

use Net::IPv4Addr qw( :all );
my ($ip,$cidr) = ipv4_parse( "127.0.0.1/24" );
my ($ip,$cidr) = ipv4_parse( "192.168.100.10 / 255.255.255.0" );
my ($net,$msk) = ipv4_network( "192.168.100.30" );
my $broadcast  = ipv4_broadcast( "192.168.100.30/26" );
if ( ipv4_in_network( "192.168.100.0", $her_ip ) ) {
  print "Bienvenue !";
}
etc.

DESCRIPTION

Net::IPv4Addr fournit des fonctions pour l'analyse des adresses IPv4, aussi bien dans le format traditionnel adresse/masque réseau que dans le nouveau format CIDR. Il existe également des méthodes pour calculer l'adresse réseau et l'adresse de diffusion, ainsi que pour vérifier si une adresse donnée appartient à un réseau spécifique.

ADRESSES

Toutes les fonctions de Net::IPv4Addr acceptent les adresses dans de nombreux formats. L'analyse est très libérale.

Toutes ces adresses seraient acceptées :

127.0.0.1
192.168.001.010/24
192.168.10.10/255.255.255.0
192.168.30.10 / 21
10.0.0.0 / 255.0.0.0
255.255.0.0

Celles-ci ne le seraient pas par contre :

272.135.234.0
192.168/16

La plupart des fonctions acceptent l'adresse et le masque réseau ou la longueur du masque dans le même scalaire ou comme valeurs séparées. C'est-à-dire soit

my($ip,$masklength) = ipv4_parse($cidr_str);
my($ip,$masklength) = ipv4_parse($ip_str,$msk_str);

UTILISATION

Aucune fonction n'est exportée par défaut. Utilisez soit la balise ":all" pour les importer toutes, soit importez explicitement celles dont vous avez besoin.

FONCTIONS

ipv4_parse
my ($ip,$msklen) = ipv4_parse($cidr_str);
my $cidr = ipv4_parse($ip_str,$msk_str);
my ($ip) = ipv4_parse($ip_str,$msk_str);

Analyse une adresse IPv4 et dans un contexte scalaire, renvoie l'adresse au format CIDR, et dans un contexte de tableau, renvoie l'adresse et la longueur du masque.

Si les paramètres ne contiennent pas de masque réseau ou de longueur de masque, dans un contexte scalaire, seule l'adresse IPv4 est renvoyée, et dans un contexte de tableau, la longueur du masque est indéfinie.

Si la fonction ne parvient pas à analyser son entrée, elle plante. Interceptez-la en utilisant "eval" si cela ne vous convient pas.

ipv4_network
my $cidr = ipv4_network($ip_str);
my $cidr = ipv4_network($cidr_str);
my ($net,$msk) = ipv4_network( $net_str, $msk_str);

Dans un contexte scalaire, cette fonction renvoie le réseau au format CIDR dans lequel se trouve l'adresse. Dans un contexte de tableau, elle renvoie l'adresse réseau et sa longueur de masque sous forme d'un tableau à deux éléments. Si l'entrée est un hôte sans masque réseau ou longueur de masque, le masque réseau par défaut est supposé.

Encore une fois, la fonction plante si l'entrée est invalide.

ipv4_broadcast
my ($broadcast) = ipv4_broadcast($ip_str);
my $broadcast   = ipv4_broadcast($ip_str,$msk_str);

Cette fonction renvoie l'adresse de diffusion. Si l'entrée ne contient pas de masque réseau ou de longueur de masque, le masque réseau par défaut est supposé.

Cette fonction plante si l'entrée est invalide.

ipv4_network
my $cidr = ipv4_network($net_str);
my $cidr = ipv4_network($cidr_sstr);
my ($net,$msk) = ipv4_network( $ip_str, $mask_str);

Dans un contexte scalaire, cette fonction renvoie le réseau au format CIDR dans lequel se trouve l'adresse. Dans un contexte de tableau, elle renvoie l'adresse réseau et sa longueur de masque sous forme d'un tableau à deux éléments. Si l'entrée est un hôte sans masque réseau ou longueur de masque, le masque réseau par défaut est supposé.

Encore une fois, la fonction plante si l'entrée est invalide.

ipv4_in_network
print "Oui" if ipv4_in_network( $cidr_str1, $cidr_str2);
print "Oui" if ipv4_in_network( $ip_str1, $mask_str1, $cidr_str2 );
print "Oui" if ipv4_in_network( $ip1, $mask1, $ip2, $msk2 );

Cette fonction vérifie si le second réseau est contenu dans le premier et implémente les sémantiques suivantes :

Si net1 ou net2 est une adresse magique (0.0.0.0 ou 255.255.255.255)
alors cette fonction renvoie vrai.
Si net1 est un hôte, net2 sera dans le même net seulement s'il
est le même hôte.
Si net2 est un hôte, il ne sera contenu dans net1 que s'il
fait partie de net1.
Si net2 est seulement une partie de net1, seulement s'il est
entièrement contenu dans net1.

Interceptez les entrées invalides avec "eval" ou autrement.

ipv4_checkip
if ($ip = ipv4_checkip($str) ) {
    # Faire quelque chose
}

Renvoie l'adresse IPv4 dans la chaîne ou undef si l'entrée ne contient pas une adresse IPv4 valide.

ipv4_cidr2msk
my $netmask = ipv4_cidr2msk( $cidr );

Renvoie le masque réseau correspondant à la longueur de masque donnée en entrée. Comme d'habitude, plante s'il n'aime pas votre entrée (dans ce cas un nombre entre 0 et 32).

ipv4_msk2cidr
my $masklen = ipv4_msk2cidr( $msk );

Renvoie la longueur de masque du masque réseau en entrée. Comme d'habitude, plante s'il n'aime pas votre entrée.
