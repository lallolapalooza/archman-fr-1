NOM

Net::DNS::RR::SSHFP - enregistrement de ressource SSHFP DNS

SYNOPIS

use Net::DNS;
$rr = Net::DNS::RR->new('name SSHFP algorithm fptype fp');

DESCRIPTION

Enregistrements de ressource DNS Fingerprint SSH (SSHFP).

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités de paquet non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner une terminaison du programme ou d'autres comportements imprévisibles.

algorithm

$algorithm = $rr->algorithm;
$rr->algorithm( $algorithm );

Le numéro d'algorithme de 8 bits décrit l'algorithme utilisé pour construire la clé publique.

fptype

$fptype = $rr->fptype;
$rr->fptype( $fptype );

Le numéro de type d'empreinte de 8 bits décrit l'algorithme de résumé de message utilisé pour calculer l'empreinte de la clé publique.

fingerprint

fp

$fp = $rr->fp;
$rr->fp( $fp );

Représentation hexadécimale du résumé de l'empreinte.

fpbin

$fpbin = $rr->fpbin;
$rr->fpbin( $fpbin );

Retourne une chaîne d'octets opaque représentant le résumé de l'empreinte.

babble

print $rr->babble;

La méthode babble() retourne la représentation 'BabbleBubble' de l'empreinte si le paquet Digest::BubbleBabble est disponible, sinon une chaîne vide est retournée.

Bubble babble représente un résumé de message sous forme d'une chaîne de mots "réels", pour rendre l'empreinte plus facile à mémoriser. Les "mots" ne sont pas nécessairement des mots réels, mais ils ressemblent davantage à des mots qu'une chaîne de caractères hexadécimaux.

Le hachage par bulles est utilisé par la suite SSH2 (et par conséquent par Net::SSH::Perl, l'implémentation Perl de SSH) pour afficher des empreintes de clé faciles à retenir.

La chaîne 'BubbleBabble' est ajoutée en commentaire lorsque la méthode de chaîne est appelée.
