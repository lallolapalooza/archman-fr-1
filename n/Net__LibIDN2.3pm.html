NOM

Net::LibIDN2 - Bindings Perl pour la bibliothèque GNU Libidn2

SYNOPSIS

use Net::LibIDN2 ':all';
use Encode;
idn2_lookup_u8(Encode::encode_utf8("m\N{U+00FC}\N{U+00DF}li.de"))
  eq 'xn--mli-5ka8l.de';
idn2_register_u8(
  Encode::encode_utf8("m\N{U+00FC}\N{U+00DF}li"),
  "xn--mli-5ka8l"
) eq 'xn--mli-5ka8l';
Encode::decode_utf8(idn2_to_unicode_88("xn--mli-5ka8l.de"))
  eq "m\N{U+00FC}\N{U+00DF}li.de"

DESCRIPTION

Fournit des bindings pour la bibliothèque GNU Libidn2, une bibliothèque C pour la gestion des domaines internationaux basée sur IDNA 2008, Punycode et TR46.

FONCTIONS

Net::LibIDN2::idn2_lookup_u8($src, [$flags, [$rc]]);
Nom alternatif idn2_to_ascii_8.

Effectue la conversion de la chaîne de domaine $src au format ASCII en utilisant le processus IDNA2008, comme décrit dans la section 5 de la RFC 5891. Notez que la chaîne d'entrée doit être encodée en UTF-8 et être sous forme NFC.

Passez IDN2_NFC_INPUT dans $flags pour convertir la chaîne d'entrée en NFC avant tout autre traitement. IDN2_TRANSITIONAL et IDN2_NONTRANSITIONAL impliquent déjà IDN2_NFC_INPUT.

Passez IDN2_ALABEL_ROUNDTRIP dans les flags pour convertir toute A-label en U-label et effectuer des vérifications supplémentaires. Ce comportement est le défaut si une version de libidn2 supérieure ou égale à 2.2 est utilisée. Pour le désactiver, passez IDN2_NO_ALABEL_ROUNDTRIP.

Passez IDN2_TRANSITIONAL pour activer le traitement TR46 transitionnel et IDN2_NONTRANSITIONAL pour activer le traitement TR46 non transitionnel.

Plusieurs flags peuvent être spécifiés en combinant des bits, par exemple IDN2_NFC_INPUT | IDN2_ALABEL_ROUNDTRIP.

Si vous êtes lié à une version de libidn2 supérieure à 2.0.3, IDN2_USE_STD3_ASCII_RULES est désactivé par défaut. Auparavant, il supprimait les caractères non standards des chaînes de domaine comme _443._tcp.example.com ou les IP 1.2.3.4/24 fournies aux fonctions libidn2. C'était un comportement inattendu pour les applications passant de libidn2, et il a donc été désactivé par défaut. Pour le réactiver, utilisez IDN2_USE_STD3_ASCII_RULES.

En cas d'erreur, renvoie undef. Si une variable scalaire est fournie dans $rc, renvoie le code de résultat interne de la bibliothèque C libidn2.

Net::LibIDN2::idn2_lookup_ul($src, [$flags, [$rc]]);
Nom alternatif idn2_to_ascii_l.

Similaire à la fonction idn2_lookup_u8, mais $src est supposé être encodé dans le jeu de caractères par défaut de la locale et est transcrit en UTF-8 et en forme NFC avant que le résultat ne soit renvoyé.

Net::LibIDN2::idn2_register_u8($ulabel, [$alabel, [$flags, [$rc]]]);
Effectue la conversion de la chaîne d'étiquette de domaine $ulabel et $alabel en utilisant le processus IDNA2008, comme décrit dans la section 4 de la RFC 5891. Notez que la chaîne d'entrée $ulabel doit être encodée en UTF-8 et être sous forme NFC.

Passez IDN2_NFC_INPUT dans $flags pour convertir la chaîne d'entrée $ulabel en NFC avant tout autre traitement.

Il est recommandé de fournir à la fois $ulabel et $alabel pour une vérification d'erreur plus précise, bien que la fourniture d'un seul des deux fonctionne. La fourniture de $alabel seul est meilleure que la fourniture de $ulabel seul. Voir la section 4 de la RFC 5891 pour plus d'informations.

En cas d'erreur, renvoie undef. Si une variable scalaire est fournie dans $rc, renvoie le code de résultat interne de la bibliothèque C libidn2.

Net::LibIDN2::idn2_register_ul($ulabel, [$alabel, [$flags, [$rc]]]);
Similaire à la fonction idn2_register_u8, mais $ulabel est supposé être encodé dans le jeu de caractères par défaut de la locale et est transcrit en UTF-8 et en forme NFC avant que le résultat ne soit renvoyé.
Net::LibIDN2::idn2_to_unicode_88($input, [$flags, [$rc]]);
Convertit un encodage ACE potentiel d'une chaîne de domaine en UTF-8 en une chaîne UTF-8 (décodage punycode).

En cas d'erreur, renvoie undef. Si une variable scalaire est fournie dans $rc, renvoie le code de résultat interne de la bibliothèque C libidn2.

Net::LibIDN2::idn2_to_unicode_8l($input, [$flags, [$rc]]);
Similaire à la fonction idn2_to_unicode_88, mais la valeur renvoyée est encodée dans le jeu de caractères par défaut de la locale.
Net::LibIDN2::idn2_to_unicode_ll($input, [$flags, [$rc]]);
Similaire à la fonction idn2_to_unicode_8l, mais $input est supposé être encodé dans le jeu de caractères par défaut de la locale.
Net::LibIDN2::idn2_strerror($rc);
Convertit le code d'erreur interne de la bibliothèque libidn2 $rc en une chaîne de texte lisible par l'utilisateur.
Net::LibIDN2::idn2_strerror_name($rc);
Convertit le code d'erreur interne de la bibliothèque libidn2 $rc en une chaîne correspondant aux noms des variables d'en-tête internes comme IDN2_MALLOC.
Net::LibIDN2::idn2_check_version([$req_version])
Vérifie si la version de la bibliothèque C IDN2 est au moins celle spécifiée dans le paramètre $req_version et renvoie la version réelle de la bibliothèque C ou undef si la condition n'est pas remplie. Si aucun paramètre n'est passé, renvoie seulement la chaîne de version.

Voir IDN2_VERSION pour une chaîne appropriée en tant que $req_version, qui correspond à la version du fichier d'en-tête idn2.h au moment de la compilation de ce module Perl. Normalement, ces deux numéros de version sont les mêmes, mais si vous avez compilé ce module avec une ancienne version de libidn2 puis l'exécutez avec une version plus récente, ils seront différents.

CONSTANTES

IDN2_VERSION
Un symbole de précompilation décrivant le numéro de version du fichier d'en-tête C au moment de la compilation de ce module Perl. Utilisé avec idn2_check_version() pour vérifier la cohérence entre le fichier d'en-tête et la bibliothèque d'exécution.
IDN2_VERSION_NUMBER
Un symbole de précompilation décrivant le numéro hexadécimal de la version du fichier d'en-tête C au moment de la compilation de ce module Perl. Par exemple, lorsque la version du fichier d'en-tête est 1.2.4711, ce symbole aura la valeur 0x01021267.
