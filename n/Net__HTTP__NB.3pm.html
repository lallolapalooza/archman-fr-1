Net::HTTP::NB(3) Documentation Perl fournie par l'utilisateur Net::HTTP::NB(3)

NOM

Net::HTTP::NB - Client HTTP non bloquant

VERSION

version 6.24

SYNOPSIS

use Net::HTTP::NB;
my $s = Net::HTTP::NB->new(Host => "www.perl.com") || die $@;
$s->write_request(GET => "/");
use IO::Select;
my $sel = IO::Select->new($s);
READ_HEADER: {
   die "Timeout de l'en-tête" unless $sel->can_read(10);
   my($code, $mess, %h) = $s->read_response_headers;
   redo READ_HEADER unless $code;
}
while (1) {
   die "Timeout du corps" unless $sel->can_read(10);
   my $buf;
   my $n = $s->read_entity_body($buf, 1024);
   last unless $n;
   print $buf;
}

DESCRIPTION

Même interface que "Net::HTTP", mais ne tentera jamais plusieurs lectures lorsque les méthodes read_response_headers() ou read_entity_body() sont invoquées. Cela permet de multiplexer plusieurs Net::HTTP::NB en utilisant select sans risque de blocage.

Si read_response_headers() n'a pas vu suffisamment de données pour compléter les en-têtes, une liste vide est retournée.

Si read_entity_body() n'a pas vu de nouvelles données d'entité dans sa lecture, la valeur -1 est retournée.
