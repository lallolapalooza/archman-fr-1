NOM

Net::LDAP::Extension::WhoAmI - Opération LDAP "Qui suis-je ?"

SYNTAXE

use Net::LDAP;
use Net::LDAP::Extension::WhoAmI;
$ldap = Net::LDAP->new( "ldap.mondomaine.eg" );
$ldap->bind('cn=Joe User,cn=People,dc=example,dc=com",
            password => 'secret');
$mesg = $ldap->who_am_i();
die "erreur : ", $mesg->code(), ": ", $mesg->error()  if ($mesg->code());
print "vous êtes lié avec authzId ", $mesg->response(), "\n";

DESCRIPTION

"Net::LDAP::Extension::WhoAmI" implémente l'opération étendue LDAPv3 "Qui suis-je ?" telle que décrite dans la RFC 4532.

Elle n'implémente aucun objet par elle-même, mais étend l'objet Net::LDAP avec une méthode supplémentaire :

MÉTHODES

who_am_i
Obtient l'identité d'autorisation que le serveur a associée à l'utilisateur ou à l'entité applicative.

VOIR AUSSI

Net::LDAP, Net::LDAP::Extension
