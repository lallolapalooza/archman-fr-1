NOM

Net::DBus::BaseObject - classe de base pour exporter des objets vers le bus

SYNTAXE

# Soyons un objet DBus
use base qw(Net::DBus::BaseObject);
# Exporter un signal 'Greeting' avec un paramètre de type chaîne
dbus_signal("Greeting", ["string"]);
# Exporter 'Hello' comme méthode acceptant un paramètre de type chaîne
# et retournant une valeur de type chaîne
dbus_method("Hello", ["string"], ["string"]);
sub new {
    my $class = shift;
    my $service = shift;
    my $self = $class->SUPER::new($service, "/org/demo/HelloWorld");
    bless $self, $class;
    return $self;
}
sub _dispatch_object {
    my $self = shift;
    my $connection = shift;
    my $message = shift;
    if (....$message se réfère à une méthode de l'objet... ) {
       ... traiter les interfaces/méthodes de cet objet...
       return $reply;
    }
}

DESCRIPTION

Ceci est la base de tous les objets qui sont exportés vers le bus de messages. Elle fournit le support de base pour l'introspection de type nécessaire aux objets exportés vers le bus. Lorsque l'on hérite de cette classe, la méthode "_dispatch" doit être implémentée pour gérer le traitement des messages entrants. Le module Net::DBus::Exporter est utilisé pour déclarer quelles méthodes (et signaux) sont exportées vers le bus.

Tous les paquets qui héritent de cette classe auront automatiquement l'interface "org.freedesktop.DBus.Introspectable" enregistrée avec Net::DBus::Exporter, et la méthode "Introspect" au sein de celle-ci exportée.

Les développeurs d'applications utiliseront rarement cette classe directement, préférant plutôt Net::DBus::Object ou "Net::DBus::ProxyObject" qui sont des choix courants. Cette classe ne sera utilisée que si l'on souhaite écrire une nouvelle approche pour la dispatcher des appels de méthode entrants.

MÉTHODES

my $objet = Net::DBus::BaseObject->new($service, $path)
Ceci crée un nouvel objet DBus avec un chemin de $path enregistré au sein du service $service. Le paramètre $path doit être une chaîne respectant les exigences normales des chemins d'objets sur DBus, tandis que le paramètre $service doit être un objet de type Net::DBus::Service. Ce dernier est typiquement obtenu en appelant la méthode "export_service" sur l'objet Net::DBus.
my $objet = Net::DBus::BaseObject->new($parentobj, $subpath)
Ceci crée un nouvel objet enfant avec un chemin de $subpath relatif à son parent $parentobj. Le paramètre $subpath doit être une chaîne respectant les exigences normales des chemins d'objets sur DBus, tandis que le paramètre $parentobj doit être un objet de type Net::DBus::BaseObject.
$objet->disconnect()
Cette méthode déconnecte l'objet du bus, ainsi il ne recevra plus de messages envoyés par d'autres clients. Tout objet enfant sera également déconnecté récursivement. Après qu'un objet ait été déconnecté, il est possible que Perl puisse le récupérer comme garbage. Cela permettra également de connecter un nouvel objet au même chemin.
my $bool = $objet->is_connected
Retourne une valeur vraie si l'objet est connecté au bus et peut donc être accédé par des clients distants. Retourne faux si l'objet est déconnecté et est donc prêt pour la récupération de garbage. Tous les objets commencent dans un état connecté et ne passeront à l'état déconnecté que si la méthode "disconnect" est appelée.
my $service = $objet->get_service
Obtient l'objet Net::DBus::Service sur lequel cet objet est exporté.
my $path = $objet->get_object_path
Obtient le chemin sous lequel cet objet est exporté.
$objet->emit_signal_in($name, $interface, $client, @args);
Émet un signal depuis l'objet nommé $name. Si le paramètre $interface est défini, le signal sera souscrit au sein de cette interface. Si le paramètre $client est défini, le signal sera envoyé en unicast à ce client sur le bus. Les types du signal et les types des arguments @args doivent avoir été enregistrés auprès de Net::DBus::Exporter via l'appel de la fonction "dbus_signal".
$self->emit_signal_to($name, $client, @args);
Émet un signal depuis l'objet nommé $name. Les types du signal et les types des arguments @args doivent avoir été enregistrés auprès de Net::DBus::Exporter via l'appel de la fonction "dbus_signal". Le signal ne sera envoyé qu'au client spécifié par le paramètre $client.
$self->emit_signal($name, @args);
Émet un signal depuis l'objet nommé $name. Les types du signal et les types des arguments @args doivent avoir été enregistrés auprès de Net::DBus::Exporter via l'appel de la fonction "dbus_signal". Le signal sera envoyé à tous les clients sur le bus.
$objet->connect_to_signal_in($name, $interface, $coderef);
Connecte un callback à un signal émis par l'objet. Le paramètre $name est le nom du signal au sein de l'objet, et $coderef est une référence à une sous-routine anonyme. Lorsque le signal $name est émis par l'objet distant, la sous-routine $coderef sera appelée et les paramètres du signal lui seront passés. Le paramètre $interface est utilisé pour spécifier l'interface explicite à laquelle le signal est connecté.
$objet->connect_to_signal($name, $coderef);
Connecte un callback à un signal émis par l'objet. Le paramètre $name est le nom du signal au sein de l'objet, et $coderef est une référence à une sous-routine anonyme. Lorsque le signal $name est émis par l'objet distant, la sous-routine $coderef sera appelée et les paramètres du signal lui seront passés.
$reply = $objet->_dispatch_object($connection, $message);
La méthode "_dispatch_object" est utilisée pour gérer la dispatcher des méthodes implémentées par l'objet. L'implémentation par défaut est un NOP et doit être surchargée par les classes dérivées. Si le $message peut être traité, une autre instance de "Net::DBus::Binding::Message" sera retournée pour la réponse. Si "undef" est retourné, une erreur générique sera renvoyée à l'appelant.
$currvalue = $objet->_dispatch_property($name); =item $objet->_dispatch_property($name, $newvalue);
La méthode "_dispatch_property" est utilisée pour gérer la dispatcher de la lecture et de l'écriture des propriétés. Le paramètre $name est le nom de la propriété accédée. Si $newvalue est fourni, la propriété est mise à jour, sinon la valeur actuelle est retournée. L'implémentation par défaut lèvera une erreur, elle doit donc être surchargée dans les classes dérivées.
