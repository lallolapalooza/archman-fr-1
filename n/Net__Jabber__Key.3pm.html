NOM

Net::Jabber::Key - Bibliothèque de clés Jabber

SYNOPSIS

Net::Jabber::Key est un module qui fournit aux développeurs un accès facile
à la génération, à la mise en cache et à la comparaison de clés.

DESCRIPTION

Key.pm est un module d'aide pour Net::Jabber::Transport. Lorsque le
Transport communique avec un Client, il envoie une clé et s'attend à recevoir
cette clé du Client. Ce module fournit une API pour générer, mettre en cache,
puis comparer la clé envoyée par le Client.

Fonctions de base

$Key = new Net::Jabber::Key();
$key = $Key->Generate();
$key = $Key->Create("bob\@jabber.org");
$test = $Key->Compare("bob\@jabber.org","une clé");

MÉTHODES

Fonctions de base

new(debug=>chaîne,       - crée l'objet Key. debug doit
    debugfh=>FileHandle,   être défini sur le chemin du journal
    debuglevel=>entier)   de débogage. S'il est défini sur "stdout" 
                           alors le débogage ira là-bas. Vous pouvez également
                           spécifier un descripteur de fichier déjà existant
                           et l'utiliser. debuglevel contrôle la quantité
                           de débogage. 0 est aucune, 1 est normale, 2 est tout.
Generate() - renvoie une clé sous forme de Digest SHA1 basée sur l'heure
             actuelle et le PID.
Create(cacheString) - génère une clé et la met en cache avec la clé
                      de cacheString. Create renvoie la clé.
Compare(cacheString, - compare la clé stockée dans le cache sous
        keyString)     cacheString avec keyString. Renvoie 1 si elles correspondent,
                       et 0 sinon.
