NOM

Net::XMPP::Debug - Module de débogage XMPP

SYNOPSIS

Net::XMPP::Debug est un module qui offre aux développeurs un accès facile à la journalisation des informations de débogage.

DESCRIPTION

Debug est un module d'aide pour les modules Net::XMPP. Il fournit aux modules Net::XMPP un objet pour contrôler où, comment et quoi est journalisé.

Fonctions de base

$Debug = Net::XMPP::Debug->new();
$Debug->Init(
       level  => 2,
       file   => "stdout",
       header =>"MonScript");
$Debug->Log0("Connexion établie");

MÉTHODES

Fonctions de base

new
new(hash)

crée l'objet Debug. L'argument hash est passé à la fonction Init. Voir la description de cette fonction ci-dessous pour les paramètres valides.

Init
Init(
     level      => entier,
     file       => chaîne,
     header     => chaîne,
     setdefault => 0|1,
     usedefault => 0|1,
     time       => 0|1)

initialise l'objet de débogage.

Le paramètre level détermine le niveau maximum des messages de débogage à enregistrer :

0 - Sortie de niveau de base (par défaut)
1 - Appels d'API de haut niveau
2 - Appels d'API de bas niveau
...
N - Ce que vous voulez....

Le paramètre file détermine où va le journal de débogage. Vous pouvez spécifier un chemin vers un fichier, ou "stdout" (par défaut). "stdout" indique à Debug d'envoyer toutes les informations de débogage envoyées à cet objet vers la sortie standard.

header est une chaîne de caractères qui sera ajoutée au début de chaque entrée de journal. Cela permet de savoir plus facilement ce qui a généré l'entrée du journal (par défaut "Debug").

setdefault enregistre le descripteur de fichier actuel et le rend disponible pour d'autres objets Debug. Pour utiliser le paramètre par défaut, mettez usedefault à 1.

Le paramètre time spécifie s'il faut ajouter ou non un horodatage au début de chaque ligne enregistrée.

LogN
LogN(tableau)

Enregistre les éléments du tableau au niveau de débogage N correspondant. Si vous passez une référence à un tableau ou à une hash, ils seront imprimés de manière lisible. (c'est-à-dire... Log0, Log2, Log100, etc...)

EXEMPLE

$Debug = Net::XMPP:Debug->new(level=>2,
                             header=>"Exemple");
$Debug->Log0("test");
$Debug->Log2("test niveau 2");
$hash{a} = "atest";
$hash{b} = "btest";
$Debug->Log1("test hash", \%hash);

Vous obtiendriez le journal suivant :

Exemple: test
Exemple: test niveau 2
Exemple: test hash { a=>"atest" b=>"btest" }

Si vous aviez défini le niveau à 1 au lieu de 2, vous obtiendriez :

Exemple: test
Exemple: test hash { a=>"atest" b=>"btest" }
