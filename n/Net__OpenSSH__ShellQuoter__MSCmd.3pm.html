NOM

Net::OpenSSH::ShellQuoter::MSCmd - Quoteur pour Windows cmd.exe

DESCRIPTION

Ce quoteur est destiné à l'interaction avec des serveurs SSH s'exécutant sous Windows qui invoquent les commandes demandées via le shell "cmd.exe".

Comme "cmd.exe" n'effectue pas l'expansion des jokers (sous Windows, cette tâche est laissée à la commande finale), le quoting de glob quote tout.

Certains serveurs Windows utilisent "Win32::CreateProcess" pour exécuter le shell "cmd.exe" qui exécute la commande demandée. Dans ce cas, les quoteurs "MSCmd" et "MSWin" doivent être chaînés (et d'ailleurs, l'ordre compte) :

$ssh = Net::OpenSSH->new(...,
                         remote_shell => 'MSCmd,MSWin');

En fait, "cmd.exe" peut ne pas nécessiter de quoting du tout lorsque la commande demandée est une commande intégrée (par exemple, "echo").
