NOM

Net::DBus::Callback - un rappel pour recevoir des événements de réacteur

SYNOPSIS

use Net::DBus::Callback;
# Supposons que nous ayons un objet 'terminal' qui a une méthode
# à invoquer chaque fois qu'il y a une entrée sur son terminal.
#
# Pour créer un rappel afin d'invoquer cette méthode, on pourrait utiliser
my $cb = Net::DBus::Callback->new(object => $terminal,
                                  method => "handle_stdio");
# Quoi que ce soit qui surveille le canal stdio, invoquerait alors
# le rappel, peut-être en passant un paramètre avec
# des données 'intéressantes', comme le nombre d'octets disponibles
$cb->invoke($nbytes)
#... ce qui résulte en un appel à
#  $terminal->handle_stdio($nbytes)

DESCRIPTION

Ce module fournit un conteneur simple pour stocker les détails d'un rappel à invoquer ultérieurement. Il est utilisé lors de l'enregistrement pour recevoir des événements de la classe Net::DBus::Reactor. NB l'utilisation de ce module dans le code applicatif n'est plus nécessaire et il reste purement pour la compatibilité ascendante. Vous pouvez plutôt simplement passer une référence de code de sous-routine dans n'importe quel endroit où un rappel est souhaité.

MÉTHODES

my $cb = Net::DBus::Callback->new(method => $name, [args => \@args])
Crée un nouvel objet rappel, pour invoquer une simple fonction. Le paramètre "method" doit être le nom complet de la fonction à invoquer, y compris le nom du paquet. Le paramètre optionnel "args" est une référence de tableau de paramètres à passer au rappel, en plus de ceux passés à la méthode "invoke".
my $cb = Net::DBus::Callback->new(object => $object, method => $name, [args => \@args])
Crée un nouvel objet rappel, pour invoquer une méthode sur un objet. Le paramètre "method" doit être le nom de la méthode à invoquer, tandis que le paramètre "object" doit être un objet béni sur lequel la méthode sera invoquée. Le paramètre optionnel "args" est une référence de tableau de paramètres à passer au rappel, en plus de ceux passés à la méthode "invoke".
$cb->invoke(@args)
Invoque le rappel. La liste d'arguments passée au rappel est une combinaison des arguments fournis dans le constructeur du rappel, suivie des arguments fournis dans la méthode "invoke".
