NOM

Net::Server::Proto::SSLEAY - Gestionnaire de protocole SSL personnalisé pour Net::Server basé sur Net::SSLeay.

SYNTAXE

Voir Net::Server::Proto.

use base qw(Net::Server::HTTP);
main->run(
    proto => 'ssleay',
    SSL_key_file  => "/chemin/vers/mon/fichier.key",
    SSL_cert_file => "/chemin/vers/mon/fichier.crt",
);
# OU
sub SSL_key_file  { "/chemin/vers/mon/fichier.key" }
sub SSL_cert_file { "/chemin/vers/mon/fichier.crt" }
main->run(proto => 'ssleay');
# OU
main->run(
    port => [443, 8443, "80/tcp"],  # se connecter à deux ports ssleay et un port tcp
    proto => "ssleay",    # utiliser ssleay par défaut
    ipv  => "*",          # se connecter aux interfaces IPv4 et IPv6
    SSL_key_file  => "/chemin/vers/mon/fichier.key",
    SSL_cert_file => "/chemin/vers/mon/fichier.crt",
);
# OU
main->run(port => [{
    port  => "443",
    proto => "ssleay",
    # ipv => 4, # par défaut - uniquement IPv4
    SSL_key_file  => "/chemin/vers/mon/fichier.key",
    SSL_cert_file => "/chemin/vers/mon/fichier.crt",
}, {
    port  => "8443",
    proto => "ssleay",
    ipv   => "*", # IPv4 et IPv6
    SSL_key_file  => "/chemin/vers/mon/fichier2.key", # clé séparée
    SSL_cert_file => "/chemin/vers/mon/fichier2.crt", # certificat séparé
}]);

DESCRIPTION

Ce module a été utilisé de manière fiable pour recevoir des millions de requêtes sur une seule machine par jour. Si quelqu'un a des succès ou des idées d'amélioration sous SSLEAY, veuillez envoyer un e-mail à <paul@seamons.com>.

Module de protocole pour Net::Server. Ce module implémente une couche de socket sécurisée sur TCP (également connue sous le nom de SSL). Voir Net::Server::Proto.

Si vous avez besoin de plus de personnalisation de la couche SSL, vous pourriez envisager d'utiliser SSL plutôt que SSLEAY car il utilise le vénérable (assez) IO::Socket::SSL.

PARAMÈTRES

Actuellement, il existe une prise en charge des éléments suivants :

"SSL_cert_file"
Chemin complet du fichier de certificat à utiliser pour ce serveur. Doit être au format PEM.
"SSL_key_file"
Chemin complet du fichier de clé à utiliser pour ce serveur. Doit être au format PEM.
"SSL_max_getline_length"
Utilisé pendant getline pour ne lire que jusqu'à ce que ce nombre d'octets soit trouvé. La valeur par défaut est indéfinie, ce qui signifie illimitée.
"SSL_error_callback"
Doit être une référence de code qui sera appelée chaque fois que des conditions d'erreur sont rencontrées. Elle transmet un message source et un tableau des erreurs.

MÉTHODES

Ce module implémente la plupart des opérations courantes sur les descripteurs de fichiers. Il existe cependant quelques ajouts :

"read_until"
Prend des octets et fait correspondre qr. Si les octets sont définis, il lira jusqu'à ce que ce nombre d'octets soit trouvé. Si la correspondance qr est définie, il lira jusqu'à ce que le tampon corresponde à ce qr. Si les deux sont indéfinis, il lira jusqu'à ce qu'il n'y ait plus rien à lire.
"error"
Si une erreur s'est produite lors de l'écriture, cette méthode retournera cette erreur.

BOGUES
