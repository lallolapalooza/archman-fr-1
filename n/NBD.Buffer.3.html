Tampon persistant utilisé dans les appels AIO.

type t = (char, Stdlib.Bigarray.int8_unsigned_elt, Stdlib.Bigarray.c_layout) Stdlib.Bigarray.Array1.t

Un tampon qui persiste entre les appels, utilisé dans NBD.aio_pread , NBD.aio_pwrite et similaires.

Dans libnbd ≤ 1.18, il s'agissait d'un type implémenté spécialement. C'était inefficace car la copie zéro n'était pas possible.

Dans libnbd ≥ 1.20, il s'agit simplement d'un alias pour un Bigarray, vous pouvez donc utiliser directement les fonctions de Bigarray.Array1 si vous préférez. Cela permet également la copie zéro.

Ce type est compatible avec les bibliothèques bigstring et bigstringaf.

val alloc : int -> t

Alloue un tampon non initialisé. Le paramètre est la taille en octets.

Dans libnbd ≥ 1.20, il s'agit d'un alias pour Bigarray.Array1.create .

val to_bytes : t -> bytes

Copie le tampon vers un objet bytes OCaml.

Dans libnbd ≥ 1.20, vous pouvez lire directement dans le bigarray pour éviter la copie si vous le souhaitez.

val to_string : t -> string

Identique à NBD.Buffer.to_bytes mais renvoie une string à la place.

val of_bytes : bytes -> t

Copie un objet bytes OCaml vers un tampon nouvellement alloué.

Dans libnbd ≥ 1.20, vous pouvez écrire directement dans le bigarray pour éviter la copie si vous le souhaitez.

val of_string : string -> t

Identique à NBD.Buffer.of_bytes mais prend une string à la place.

val size : t -> int

Retourne la taille du tampon.

Dans libnbd ≥ 1.20, il s'agit d'un alias pour Bigarray.Array1.dim .
