NOM

Net::DBus::ProxyObject - Implémente des objets à exporter vers le bus

SYNOPSIS

# Connexion d'un objet au bus, sous un service
package main;
use Net::DBus;
# Connexion au bus
my $bus = Net::DBus->find;
# Création de l'instance de l'objet de notre application
my $object = Demo::HelloWorld->new()
# Acquisition d'un service 'org.demo.Hello'
my $service = $bus->export_service("org.demo.Hello");
# Enfin, exportation de l'objet vers le bus
my $proxy = Demo::HelloWorld::DBus->new($object);
....reste du programme...
# Définition d'un nouveau paquet pour l'objet que nous allons
# exporter
package Demo::HelloWorld;
sub new {
    my $class = shift;
    my $service = shift;
    my $self = {};
    $self->{sighandler} = undef;
    bless $self, $class;
    return $self;
}
sub sighandler {
    my $self = shift;
    my $callback = shift;
    $self->[sighandler} = $callback;
}
sub Hello {
  my $self = shift;
  my $name = shift;
  &{$self->{sighandler}}("Greeting", "Hello $name");
  return "Said hello to $name";
}
sub Goodbye {
  my $self = shift;
  my $name = shift;
  &{$self->{sighandler}}("Greeting", "Goodbye $name");
  return "Said goodbye to $name";
}
# Définition d'un nouveau paquet pour l'objet que nous allons
# exporter
package Demo::HelloWorld::DBus;
# Spécification de l'interface principale fournie par notre objet
use Net::DBus::Exporter qw(org.example.demo.Greeter);
# Nous allons être un objet DBus
use base qw(Net::DBus::ProxyObject);
# Exportation d'un signal 'Greeting' acceptant un paramètre de type chaîne (string)
dbus_signal("Greeting", ["string"]);
# Exportation de 'Hello' comme une méthode acceptant un seul paramètre de type chaîne (string)
# et retournant une seule valeur de type chaîne (string)
dbus_method("Hello", ["string"], ["string"]);
sub new {
    my $class = shift;
    my $service = shift;
    my $impl = shfit;
    my $self = $class->SUPER::new($service, "/org/demo/HelloWorld", $impl);
    bless $self, $class;
    $self->sighandler(sub {
        my $signame = shift;
        my $arg = shift;
        $self->emit_signal($signame, $arg);
    });
    return $self;
}
# Exportation de 'Goodbye' comme une méthode acceptant un seul paramètre de type chaîne (string)
# et retournant une seule valeur de type chaîne (string), mais la placer
# dans l'interface 'org.exaple.demo.Farewell'
dbus_method("Goodbye", ["string"], ["string"], "org.example.demo.Farewell");

DESCRIPTION

Ceci est la base pour la création d'un proxy entre un objet du bus et un objet de l'application. Il permet de maintenir le modèle objet de l'application séparé du modèle objet RPC. L'objet proxy transmettra les appels de méthode du bus à l'objet d'implémentation. L'objet proxy peut également enregistrer des callbacks sur l'objet de l'application, qu'il pourra utiliser pour émettre ensuite des signaux sur le bus.

MÉTHODES

my $object = Net::DBus::ProxyObject->new($service, $path, $impl)
Ceci crée un nouvel objet DBus avec un chemin de $path enregistré au sein du service $service. Le paramètre $path devrait être une chaîne respectant les exigences habituelles de DBus pour les chemins d'objet, tandis que le paramètre $service devrait être une instance de Net::DBus::Service. Cette dernière est typiquement obtenue en appelant la méthode "export_service" sur l'objet Net::DBus. Le paramètre $impl est l'objet de l'application qui implémentera les méthodes exportées vers le bus.
my $object = Net::DBus::ProxyObject->new($parentobj, $subpath, $impl)
Ceci crée un nouvel objet enfant DBus avec un chemin de $subpath relatif à son parent $parentobj. Le paramètre $subpath devrait être une chaîne respectant les exigences habituelles de DBus pour les chemins d'objet, tandis que le paramètre $parentobj devrait être une instance de Net::DBus::BaseObject ou une sous-classe. Le paramètre $impl est l'objet de l'application qui implémentera les méthodes exportées vers le bus.
