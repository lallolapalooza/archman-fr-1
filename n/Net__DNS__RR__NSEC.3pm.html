NOM

Net::DNS::RR::NSEC - enregistrement de ressource DNS NSEC

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new( 'name NSEC nxtdname typelist' );

DESCRIPTION

Classe pour les enregistrements de ressource DNSSEC NSEC.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées des méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités de paquet non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

nxtdname

$nxtdname = $rr->nxtdname;
$rr->nxtdname( $nxtdname );

Le champ Next Domain contient le nom de propriétaire suivant (dans l'ordre canonique de la zone) qui possède des données faisant autorité ou contient un point de délégation de jeu d'enregistrements NS.

typelist

@typelist = $rr->typelist;
$typelist = $rr->typelist;

typelist() identifie les types de jeux d'enregistrements qui existent au nom de propriétaire de l'enregistrement NSEC. Lorsqu'elle est appelée en contexte scalaire, la liste est interpolée dans une chaîne.

typemap

$exists = $rr->typemap($rrtype);

typemap() renvoie une valeur booléenne vraie si le type d'enregistrement spécifié se trouve dans le bitmap de types de l'enregistrement NSEC.

match

$matched = $rr->match( 'example.foo' );

match() renvoie une valeur booléenne vraie si la forme canonique de l'argument de nom correspond au nom de propriétaire canonique de l'enregistrement NSEC.

covers

$covered = $rr->covers( 'example.foo' );

covers() renvoie une valeur booléenne vraie si la forme canonique du nom, ou l'un de ses ancêtres, se situe entre le nom de propriétaire et le champ nxtdname de l'enregistrement NSEC.

encloser, nextcloser, wildcard

$encloser = $rr->encloser( 'example.foo' );
print "encloser: $encloser\n" if $encloser;

encloser() renvoie le nom d'un enclosant prouvable du nom de requête argument obtenu à partir de l'enregistrement NSEC.

nextcloser() renvoie le nom le plus proche suivant, qui est un étiquette plus long que l'enclosant le plus proche. Ceci n'est valide qu'après que encloser() ait renvoyé un nom de domaine valide.

wildcard() renvoie le nom wildcard non développé à partir duquel le nom le plus proche suivant a éventuellement été synthétisé. Ceci n'est valide qu'après que encloser() ait renvoyé un nom de domaine valide.
