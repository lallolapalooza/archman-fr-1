INSTALLATION

Décompressez l'archive de distribution dans un répertoire approprié et tapez :

perl Makefile.PL
make
make test
make install

Par défaut, NetAddr::IP::Util installe ses fonctions principales compilées à l'aide des extensions XS de Perl pour construire une bibliothèque 'C'. Si vous n'avez pas de compilateur 'C' disponible ou si vous souhaitez la version Pure Perl plus lente pour une autre raison, tapez :

perl Makefile.PL -noxs
make
make test
make install

DESCRIPTION

NetAddr::IP::Util fournit une suite d'outils pour manipuler et convertir des adresses IPv4 et IPv6 en un contexte de 128 bits et de retour en texte. Les chaînes peuvent être manipulées avec les opérateurs logiques de Perl :

et     &
ou      |
xor     ^
        ~       complément

de la même manière que les chaînes 'vec'.

Les fonctions IPv6 prennent en charge tous les formats rfc1884.

c.-à.-d.  x:x:x:x:x:x:x:x:x
      x:x:x:x:x:x:x:d.d.d.d
      ::x:x:x
      ::x:d.d.d.d
et ainsi de suite...
  • $dotquad = inet_ntoa($netaddr);

    Convertit une adresse réseau IPv4 packagée en une adresse IP point-quadrilatère.

    entrée :        adresse réseau packagée
renvoie :      adresse IP, c.-à.-d. 10.4.12.123
  • $netaddr = inet_aton($dotquad);

    Convertit une adresse IP point-quadrilatère en une adresse réseau packagée IPv4.

    entrée :        adresse IP, c.-à.-d. 192.5.16.32
renvoie :      adresse réseau packagée
  • $ipv6addr = ipv6_aton($ipv6_text);

    Prend une adresse IPv6 de la forme décrite dans rfc1884 et renvoie une chaîne RDATA binaire de 128 bits.

    entrée :        texte IPv6
renvoie :      chaîne RDATA de 128 bits
  • $ipv6_text = ipv6_ntoa($ipv6naddr);

    Convertit une adresse IPv6 binaire de 128 bits en une représentation textuelle compressée rfc 1884.

    entrée :        chaîne RDATA de 128 bits
renvoie :      texte IPv6
  • $hex_text = ipv6_n2x($ipv6addr);

    Prend une chaîne RDATA IPv6 et renvoie une adresse hexadécimale IPv6 à 8 segments.

    entrée :        chaîne RDATA de 128 bits
renvoie :      x:x:x:x:x:x:x:x
  • $dec_text = ipv6_n2d($ipv6addr);

    Prend une chaîne RDATA IPv6 et renvoie une adresse IPv6 mixte hexadécimale - décimale avec les 6 morceaux supérieurs en hexadécimal et les 32 bits inférieurs en représentation point-quadrilatère.

    entrée :        chaîne RDATA de 128 bits
renvoie :      x:x:x:x:x:x:d.d.d.d
  • $ipv6naddr = inet_any2n($dotquad or $ipv6_text);

    Cette fonction convertit une adresse IPv4 ou IPv6 textuelle dans un format quelconque en une adresse chaîne IPv6 de 128 bits. Elle préfixe toute adresse point-quadrilatère (si trouvée) avec '::' et la passe à ipv6_aton.

    entrée :        point-quadrilatère ou adresse rfc1844
renvoie :      chaîne IPv6 de 128 bits
  • $rv = hasbits($bits128);

    Cette fonction renvoie vrai s'il y a des bits à un présents dans la chaîne de 128 bits et faux si tous les bits sont à zéro.

    c.-à.-d.  if (hasbits($bits128)) {
        &do_something;
      }
ou    if (hasbits($bits128 & $mask128) {
        &do_something;
      }

    Cela permet l'implémentation de fonctions logiques de la forme :

          if ($bits128 & $mask128) {
          ...
entrée :        chaîne IPv6 de 128 bits
renvoie :      vrai si des bits sont présents
  • $ipv6naddr = inet_4map6($netaddr or $ipv6naddr

    Cette fonction renvoie une adresse réseau ipV6 avec les 80 premiers bits mis à zéro et les 16 bits suivants mis à un, tandis que les 32 derniers bits sont remplis avec l'adresse ipV4.

    entrée :        adresse réseau ipV4
          ou  adresse réseau ipV6
renvoie :      adresse réseau ipV6
renvoie : undef en cas d'erreur

    Une adresse réseau ipV6 doit être dans l'un des deux espaces d'adresses mappées ipV4 compatibles. c.-à.-d.

    ::ffff::d.d.d.d    ou    ::d.d.d.d
  • $rv = isIPv4($bits128);

    Cette fonction renvoie vrai s'il n'y a pas de bits à un présents dans la partie IPv6 de la chaîne de 128 bits et faux sinon.

    c.-à.-d.  l'adresse doit être de la forme - ::d.d.d.d

    Note : il s'agit d'une adresse IPv6 compatible ipV4 ancienne et dépréciée.

  • $rv = isNewIPv4($bits128);

    Cette fonction renvoie vrai si la chaîne IPv6 de 128 bits est de la forme

    ::ffff::d.d.d.d
  • $rv = isAnyIPv4($bits128);

    Cette fonction renvoie vrai si la chaîne de bits IPv6 est de la forme

    ::d.d.d.d       ou      ::ffff::d.d.d.d
  • $dotquad ou $hex_text = inet_n2dx($ipv6naddr);

    Cette fonction fait ce qu'il faut et renvoie le texte d'une adresse IPv4 point-quadrilatère ou d'une adresse IPv6 en notation hexadécimale.

    entrée :        chaîne IPv6 de 128 bits
renvoie :      ddd.ddd.ddd.ddd
          ou  x:x:x:x:x:x:x:x
  • $dotquad ou $dec_text = inet_n2ad($ipv6naddr);

    Cette fonction fait ce qu'il faut et renvoie le texte d'une adresse IPv4 point-quadrilatère ou d'une adresse IPv6 en notation hexadécimale::décimale.

    entrée :        chaîne IPv6 de 128 bits
renvoie :      ddd.ddd.ddd.ddd
          ou  x:x:x:x:x:x:ddd.ddd.ddd.dd
  • $netaddr = inet_pton($AF_family,$hex_text);

    Cette fonction prend une adresse IP au format texte IPv4 ou IPv6 et la convertit en format binaire. Le type de conversion d'adresse IP est contrôlé par l'argument FAMILY.

NetAddr::IP::Util(3pm)

NAME

NetAddr::IP::Util - Utility functions for NetAddr::IP

SYNOPSIS

  use NetAddr::IP::Util;
  # ... functions ...

DESCRIPTION

This module provides various utility functions that are used by NetAddr::IP and NetAddr::IP::Lite. They are not intended for direct use by end-users.

  • $inet_addr = inet_aton(STRING);

    Convert a dotted quad IP address string into a 32 bit packed binary string. Also converts IPv6 hex addresses to a 128 bit packed binary string.

    input:      dotted quad IP address string
returns:    32 bit packed binary string
  • $ip_string = inet_ntoa(PACKED_ADDR);

    Convert a 32 bit packed binary string into a dotted quad IP address string. Also converts 128 bit packed binary strings into IPv6 hex addresses.

    input:      32 or 128 bit packed binary string
returns:    IP address string
  • $ipv6naddr = ipv6_aton(STRING);

    Convert an IPv6 hex string into a 128 bit packed binary string.

    input:      IPv6 hex string
returns:    128 bit packed binary string
  • $ipv6_string = ipv6_ntoa(PACKED_ADDR);

    Convert a 128 bit packed binary string into an IPv6 hex string.

    input:      128 bit packed binary string
returns:    IPv6 hex string
  • $ipv6_hex = ipv6_n2x(PACKED_ADDR);

    Convert a 128 bit packed binary string into a canonical IPv6 hex address string.

    input:      128 bit packed binary string
returns:    IPv6 hex string
  • $ipv6_dectxt = ipv6_n2d(PACKED_ADDR);

    Convert a 128 bit packed binary string into a standard IPv6 decimal text string.

    input:      128 bit packed binary string
returns:    IPv6 decimal text string
  • $vecaddr = inet_any2n(STRING);

    Convert a text IP address (IPv4 or IPv6) into a 128 bit packed binary string.

    input:      IPv4 or IPv6 text address string
returns:    128 bit packed binary string
  • $hasbits = hasbits(PACKED_ADDR);

    Returns true if the packed address contains any bits that are set to 1.

    input:      packed binary address
returns:    boolean
  • $isIPv4 = isIPv4(PACKED_ADDR);

    Returns true if the packed address is an IPv4 address (i.e., the high 96 bits are zero).

    input:      packed binary address
returns:    boolean
  • $isNewIPv4 = isNewIPv4(PACKED_ADDR);

    Returns true if the packed address is an IPv4 address mapped into IPv6 space (i.e., the high 80 bits are zero and the next 16 bits are set).

    input:      packed binary address
returns:    boolean
  • $isAnyIPv4 = isAnyIPv4(PACKED_ADDR);

    Returns true if the packed address is either an IPv4 address or an IPv4 mapped IPv6 address.

    input:      packed binary address
returns:    boolean
  • $hex_text = inet_n2dx(PACKED_ADDR);

    Convert a 128 bit packed binary string into a canonical IPv6 hex address string.

    input:      128 bit packed binary string
returns:    canonical hex address string
  • $addr_text = inet_n2ad(PACKED_ADDR);

    Convert a 128 bit packed binary string into a standard IPv6 decimal text string.

    input:      128 bit packed binary string
returns:    standard decimal address string
  • $bin_addr = inet_pton(FAMILY, STRING);

    Convert a textual IP address into its binary representation. The type of IP address conversion is controlled by the FAMILY argument.

    input:      AF_INET (for IPv4) or AF_INET6 (for IPv6)
              IP address string
returns:    binary representation of the IP address
  • $text_addr = inet_ntop(FAMILY, BIN_ADDR);

    Convert a binary IP address into its textual representation. The type of IP address conversion is controlled by the FAMILY argument.

    NOTE: inet_ntop ALWAYS returns lowercase characters.

  • $hex_text = packzeros($hex_text);

    This function optimizes and rfc 1884 IPv6 hex address to reduce the number of long strings of zero bits as specified in rfc 1884, 2.2 (2) by substituting :: for the first occurence of the longest string of zeros in the address.

  • $ipv6naddr = ipv4to6($netaddr);

    Convert an ipv4 network address into an IPv6 network address.

    input:        32 bit network address
returns:      128 bit network address
  • $ipv6naddr = mask4to6($netaddr);

    Convert an ipv4 network address/mask into an ipv6 network mask.

    input:        32 bit network/mask address
returns:      128 bit network/mask address

    NOTE: returns the high 96 bits as one's

  • $ipv6naddr = ipanyto6($netaddr);

    Similar to ipv4to6 except that this function takes either an IPv4 or IPv6 input and always returns a 128 bit IPv6 network address.

    input:        32 or 128 bit network address
returns:      128 bit network address
  • $ipv6naddr = maskanyto6($netaddr);

    Similar to mask4to6 except that this function takes either an IPv4 or IPv6 netmask and always returns a 128 bit IPv6 netmask.

    input:        32 or 128 bit network mask
returns:      128 bit network mask
  • $netaddr = ipv6to4($pv6naddr);

    Truncate the upper 96 bits of a 128 bit address and return the lower 32 bits. Returns an IPv4 address as returned by inet_aton.

    input:        128 bit network address
returns:      32 bit inet_aton network address
  • $bitsXn = shiftleft($bits128,$n); 
    input:        128 bit string variable,
              number of shifts [optional]
returns:      bits X n shifts
NOTE: a single shift is performed
      if $n is not specified
  • addconst($ipv6naddr,$signed_32con);

    Add a signed constant to a 128 bit string variable.

    input:        128 bit IPv6 string,
              signed 32 bit integer
returns:  scalar      carry
          array       (carry, result)
  • add128($ipv6naddr1,$ipv6naddr2);

    Add two 128 bit string variables.

    input:        128 bit string var1,
              128 bit string var2
returns:  scalar      carry
          array       (carry, result)
  • sub128($ipv6naddr1,$ipv6naddr2);

    Subtract two 128 bit string variables.

    input:        128 bit string var1,
              128 bit string var2
returns:  scalar      carry
          array       (carry, result)

    Note: The carry from this operation is the result of adding the one's complement of ARG2 +1 to the ARG1. It is logically NOT borrow.

    i.e.    if ARG1 >= ARG2 then carry = 1
or      if ARG1  < ARG2 then carry = 0
  • ($spurious,$cidr) = notcontiguous($mask128);

    This function counts the bit positions remaining in the mask when the rightmost '0's are removed.

    input:  128 bit netmask
returns true if there are spurious
            zero bits remaining in the
            mask, false if the mask is
            contiguous one's,
        128 bit cidr number
  • $bcdtext = bin2bcd($bits128);

    Convert a 128 bit binary string into binary coded decimal text digits.

    input:        128 bit string variable
returns:      string of bcd text digits
  • $bits128 = bcd2bin($bcdtxt);

    Convert a bcd text string to 128 bit string variable

    input:        string of bcd text digits
returns:      128 bit string variable
  • $modetext = mode;

    Returns the operating mode of this module.

    input:          none
returns:        "Pure Perl"
           or   "CC XS"
  • ($name,$aliases,$addrtype,$length,@addrs)=naip_gethostbyname(NAME);

    Replacement for Perl's gethostbyname if Socket6 is available

    In ARRAY context, returns a list of five elements, the hostname or NAME, a space separated list of C_NAMES, AF family, length of the address structure, and an array of one or more netaddr's

    In SCALAR context, returns the first netaddr.

    This function ALWAYS returns an IPv6 address, even on IPv4 only systems. IPv4 addresses are mapped into IPv6 space in the form:

    ::FFFF:FFFF:d.d.d.d

    This is NOT the expected result from Perl's gethostbyname2. It is instead equivalent to:

    On an IPv4 only system:
  $ipv6naddr = ipv4to6 scalar ( gethostbyname( name ));
On a system with Socket6 and a working gethostbyname2:
  $ipv6naddr = gethostbyname2( name, AF_INET6 );
and if that fails, the IPv4 conversion above.

    For a gethostbyname2 emulator that behave like Socket6, see: Net::DNS::Dig

  • $trueif = havegethostbyname2();

    This function returns TRUE if Socket6 has a functioning gethostbyname2, otherwise it returns FALSE. See the comments above about the behavior of naip_gethostbyname.

  • NetAddr::IP::Util::lower();

    Return IPv6 strings in lowercase.

  • NetAddr::IP::Util::upper();

    Return IPv6 strings in uppercase. This is the default.

EXAMPLES

# convert any textual IP address into a 128 bit vector
#
sub text2vec {
  my($anyIP,$anyMask) = @_;
# not IPv4 bit mask
  my $notiv4 = ipv6_aton('FFFF:FFFF:FFFF:FFFF:FFFF:FFFF::');
  my $vecip   = inet_any2n($anyIP);
  my $mask    = inet_any2n($anyMask);
# extend mask bits for IPv4
  my $bits = 128;     # default
  unless (hasbits($mask & $notiv4)) {
    $mask |= $notiv4;
    $bits = 32;
  }
  return ($vecip, $mask, $bits);
}

# return network and broadcast addresses from IP and Mask
#
sub netbroad {
  my($nip) = shift;
  my $notmask = ~ $nip->{mask};
  my $bcast   = $nip->{addr} | $notmask;
  my $network = $nip->{addr} & $nip->{mask};
  return ($network, $broadcast);
}
# check if address is within a network
#
sub within {
  my($nip,$net) = @_;
  my $addr = $nip->{addr}
  my($nw,$bc) = netbroad($net);
# arg1 >= arg2, sub128 returns true
  return (sub128($addr,$nw) && sub128($bc,$addr))
      ? 1 : 0;
}
# truely hard way to do $ip++
# add a constant, wrapping at netblock boundaries
# to subtract the constant, negate it before calling
# 'addwrap' since 'addconst' will extend the sign bits
#
sub addwrap {
  my($nip,$const) = @_;
  my $addr    = $nip->{addr};
  my $mask    = $nip->{mask};
  my $bits    = $nip->{bits};
  my $notmask = ~ $mask;
  my $hibits  = $addr & $mask;
  $addr = addconst($addr,$const);
  my $wraponly = $addr & $notmask;
  my $newip = {
      addr    => $hibits | $wraponly,
      mask    => $mask,
      bits    => $bits,
  };
  # bless $newip as appropriate
  return $newip;
}
