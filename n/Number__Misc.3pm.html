Number__Misc(3pm)

Paquet: perl-number-misc

Licences: PerlArtistic, GPL

Number::Misc(3) Documentation Perl fournie par la communauté Number::Misc(3)

NOM

Number::Misc - utilitaires pratiques pour les nombres

SYNOPIS

use Number::Misc ':all';
is_numeric('x');        # faux
to_number('3,000');     # 3000
commafie('3000');       # 3,000
zero_pad(2, 10);        # 0000000002
rand_in_range(3, 10);   # un nombre aléatoire de 3 à 10, inclus
is_even(3)              # vrai
is_odd(4);              # vrai

DESCRIPTION

Number::Misc fournit quelques utilitaires pratiques divers pour la gestion des nombres. Ces utilitaires gèrent le traitement des nombres sous forme de chaînes, la détermination des propriétés de base des nombres, ou la sélection d'un nombre aléatoire dans une plage.

INSTALLATION

Number::Misc peut être installé avec la routine habituelle :

perl Makefile.PL
make
make test
make install

FONCTIONS

is_numeric

Renvoie vrai si le scalaire donné est un nombre. Une valeur indéfinie renvoie faux. Un "nombre" est défini comme étant constitué uniquement de chiffres (c'est-à-dire les caractères 0-9), avec au plus un point décimal, et au plus un signe moins ou plus unique en préfixe.

is_numeric('3');       # vrai
is_numeric('-3');      # vrai
is_numeric('+3');      # vrai
is_numeric('0003');    # vrai
is_numeric('0.003');   # vrai
is_numeric('0.00.3');  # faux
is_numeric('3,003');   # faux
is_numeric('  3');     # faux
is_numeric(undef);     # faux
option : convertible
Si vous voulez tester si la chaîne pourrait être un nombre si elle était traitée par to_number(), utilisez l'option convertible. 
is_numeric('3,003',  convertible=>1);  # vrai
is_numeric('  3',    convertible=>1);  # vrai
is_numeric('0.00.3', convertible=>1);  # faux

to_number

Convertit une chaîne en nombre en supprimant les virgules et les espaces. Si la chaîne ne peut pas être convertie, renvoie undef. Quelques exemples :

to_number(' 3 ');       # renvoie 3
to_number(' 3,000 ');   # renvoie 3000
to_number('whatever');  # renvoie undef
option : always_number
Si la chaîne ne peut pas être convertie en nombre, renvoie 0 au lieu de undef. Par exemple, cet appel : 
to_number('whatever', always_number=>1)

renvoie 0.

commafie

Convertit un nombre en une chaîne représentant le même nombre mais avec des virgules

commafie(2000);     #  2,000
commafie(-2000);    # -1,000
commafie(2000.33);  #  2,000.33
commafie(100);      #    100

option : sep

L'option "sep" vous permet de définir ce qui sera utilisé comme séparateur au lieu d'une virgule. Par exemple, si vous voulez utiliser ":" au lieu de ",", vous le feriez comme suit :

commafie('2000', sep=>':');

ce qui donnerait :

2:000

zero_pad

Ajoute des zéros en préfixe au nombre pour qu'il atteigne une longueur spécifiée. Le premier paramètre est le nombre, le second est la longueur cible. Si la longueur du nombre est égale ou supérieure à la longueur donnée, rien n'est modifié.

zero_pad(2, 3);   # 002
zero_pad(2, 10);  # 0000000002
zero_pad(444, 2); # 444

rand_in_range

Étant données les bornes inférieure et supérieure, renvoie un nombre aléatoire supérieur ou égal à la borne inférieure et inférieur ou égal à la borne supérieure. Ne fonctionne que sur les entiers.

rand_in_range(3, 10);   # un nombre aléatoire de 3 à 10, inclus
rand_in_range(-1, 10);  # un nombre aléatoire de -1 à 10, inclus

is_even / is_odd

"is_even" renvoie vrai si le nombre est pair. "is_odd" renvoie vrai si le nombre est impair. Les non-nombres et les décimaux renvoient undef.
