NOM

Net::DNS::RR::HINFO - Enregistrement de ressource HINFO DNS

SYNOPIS

use Net::DNS;
$rr = Net::DNS::RR->new('name HINFO cpu os');

DESCRIPTION

Classe pour les enregistrements de ressource HINFO (Hardware Information) DNS.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités non documentées du paquet ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

cpu

$cpu = $rr->cpu;
$rr->cpu( $cpu );

Retourne le type de CPU pour cet enregistrement de ressource.

os

$os = $rr->os;
$rr->os( $os );

Retourne le type de système d'exploitation pour cet enregistrement de ressource.
