NOM

Net::DNS::RR::NSEC3PARAM - enregistrement de ressource NSEC3PARAM DNS

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nom NSEC3PARAM algorithme drapeaux itérations sel');

DESCRIPTION

Classe pour les enregistrements de ressource NSEC3PARAM DNSSEC.

L'enregistrement NSEC3PARAM contient les paramètres NSEC3 (algorithme de hachage, drapeaux, itérations et sel) nécessaires pour calculer les noms de propriétaires hachés.

La présence d'un enregistrement NSEC3PARAM à l'apex d'une zone indique que les paramètres spécifiés peuvent être utilisés par les serveurs autoritaires pour choisir un ensemble approprié d'enregistrements NSEC3 pour les réponses négatives.

L'enregistrement NSEC3PARAM n'est pas utilisé par les validateurs ou les résolveurs.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées par les méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités non documentées du package ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner la terminaison du programme ou d'autres comportements imprévisibles.

algorithme

$algorithme = $rr->algorithme;
$rr->algorithme( $algorithme );

Le champ algorithme de 8 bits est représenté sous forme d'un entier décimal non signé.

drapeaux

$drapeaux = $rr->drapeaux;
$rr->drapeaux( $drapeaux );

Le champ Drapeaux est un entier décimal non signé interprété comme huit valeurs booléennes concaténées.

itérations

$itérations = $rr->itérations;
$rr->itérations( $itérations );

Le champ Itérations est représenté sous forme d'un entier décimal non signé. La valeur est comprise entre 0 et 65535, inclus.

sel

$sel = $rr->sel;
$rr->sel( $sel );

Le champ Sel est représenté comme une séquence contiguë de chiffres hexadécimaux. Un "-" (non cité) est utilisé dans le format chaîne pour indiquer que le champ sel est absent.

selbin

$selbin = $rr->selbin;
$rr->selbin( $selbin );

Le champ Sel sous forme d'une séquence d'octets.
