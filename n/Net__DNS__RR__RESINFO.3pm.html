NOM

Net::DNS::RR::RESINFO - Enregistrement de ressource DNS RESINFO

SYNOPSIS

use Net::DNS;
my $cible = 'resolver.example.net';
my $resolveur = Net::DNS::Resolver->new(
                        nameserver => $cible,
                        recurse    => 0
                        );
$resolveur->send( $cible, 'RESINFO' )->print;
;; SECTION HEADER
;;      id = 46638
;;      qr = 1  aa = 1  tc = 0  rd = 0  opcode = QUERY
;;      ra = 0  z  = 0  ad = 0  cd = 0  rcode  = NOERROR
;;      do = 0  co = 0
;;      qdcount = 1     ancount = 1
;; SECTION QUESTION (1 enregistrement)
;; resolver.example.net.        IN      RESINFO
;; SECTION RÉPONSE (1 enregistrement)
resolver.example.net.   7200    IN      RESINFO (
        qnamemin exterr=15-17
        infourl=https://resolver.example.com/guide )
;; SECTION AUTORITÉ (0 enregistrements)
;; SECTION ADDITIONNEL (0 enregistrements)

DESCRIPTION

Classe pour les enregistrements de ressource d'informations du résolveur DNS (RESINFO).

RESINFO est un clone de la classe Net::DNS::RR::TXT.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités non documentées du paquet ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

txtdata

$string = $rr->txtdata;
@list    = $rr->txtdata;

Lorsqu'elle est appelée dans un contexte scalaire, $rr->txtdata() retourne les propriétés du résolveur sous forme d'une seule chaîne, les éléments étant séparés par un seul espace.

Dans un contexte de liste, $rr->txtdata() retourne une liste des éléments textuels.
