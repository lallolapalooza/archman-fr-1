Paquet: perl-number-compare

Number::Compare(3) Documentation Perl fournie par l'utilisateur Number::Compare(3)

NOM

Number::Compare - comparaisons numériques

SYNTAXE

Number::Compare->new(">1Ki")->test(1025); # est-ce que 1025 > 1024
my $c = Number::Compare->new(">1M");
$c->(1_200_000);                          # invocation légèrement plus concise

DESCRIPTION

Number::Compare compile une comparaison simple en une sous-routine anonyme, que vous pouvez appeler avec une valeur à tester.

Cela serait très inutile si Number::Compare ne comprenait pas les magnitudes.

La valeur cible peut utiliser les magnitudes de kilo-octets ("k", "ki"), méga-octets ("m", "mi"), ou giga-octets ("g", "gi"). Ceux suffixés par un "i" utilisent la version appropriée 2**n conformément à la norme IEC : http://physics.nist.gov/cuu/Units/binary.html

MÉTHODES

->new( $test )

Retourne un nouvel objet qui compare le test spécifié.

->test( $valeur )

Une version longue de $compare->( $valeur ). Précède l'implémentation de référence de sous-routine bénie.

->parse_to_perl( $test )

Retourne un fragment de code Perl équivalent au test.
