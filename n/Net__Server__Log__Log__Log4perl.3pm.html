NOM

Net::Server::Log::Log::Log4perl - journalisation via Log4perl

SYNOPSIS

use base qw(Net::Server::PreFork);
__PACKAGE__->run(
    log_file => 'Log::Log4perl',
    log4perl_conf => '/chemin/vers/mon/log4perl.conf',
    log4perl_logger => 'myapp',
);

DESCRIPTION

Ce module fournit une journalisation de style Log::Log4perl au système Net::Server.

CONFIGURATION

log_file
Pour commencer à utiliser la journalisation Log::Log4perl, définissez simplement le paramètre de configuration Net::Server log_file à "Log::Log4perl".

Si le nom magique "Log::Log4perl" est utilisé, toutes les journaux seront dirigés vers le système Log4perl. S'il est utilisé, les paramètres "log4perl_conf", "log4perl_poll", "log4perl_logger" peuvent également être définis.

log4perl_conf
Disponible uniquement si "log_file" est égal à "Log::Log4perl". C'est le nom du fichier de configuration log4perl - voir Log::Log4perl. Si ce n'est pas défini, le programme se terminera au démarrage. Si le fichier n'est pas lisible, le programme se terminera.
log4perl_poll
S'il est défini avec une valeur, il sera initialisé avec Log::Log4perl::init_and_watch avec cette valeur de sondage. Cela peut aussi être la chaîne "HUP" pour relire le log4perl_conf lorsqu'un signal HUP est reçu. S'il est défini à 0, aucun sondage n'est effectué. Voir Log::Log4perl pour plus de détails.
log4perl_logger
C'est le nom de la facilité. Par défaut, "Net::Server".

ARGUMENTS PAR DÉFAUT POUR Net::Server

Les arguments suivants sont disponibles dans les modules "Net::Server" ou "Net::Server::Single" par défaut. (D'autres personnalités peuvent utiliser des paramètres supplémentaires et peuvent éventuellement ne pas utiliser les paramètres de la classe de base.)

Clé               Valeur                   Défaut
## paramètres log4perl (si log_file eq Log::Log4perl)
log4perl_conf     "nom_de_fichier"           se terminera si non défini
log4perl_poll     nombre ou HUP            0 (pas de sondage)
log4perl_logger   "nom"                   "Net::Server"

MÉTHODES

"initialize"
Cette méthode est appelée pendant la méthode initialize_logging de Net::Server. Elle renvoie une référence de code unique qui sera stockée sous la propriété log_function de l'objet Net::Server. Cette référence de code prend log_level et message comme arguments et appelle le système log4perl initialisé.
