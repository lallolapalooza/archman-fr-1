NOM

Net::LDAP::Control::PreRead - Objet de contrôle Pre-Read LDAPv3

SYNTAXE

use Net::LDAP;
use Net::LDAP::Control::PreRead;
use Net::LDAP::Constant qw( LDAP_CONTROL_PREREAD LDAP_SUCCESS );
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$preread = Net::LDAP::Control::PreRead->new( attrs => [ qw/givenName/ ] );
my $mesg = $ldap->modify( "cn=Barbara Jensen, o=University of Michigan, c=US",
                          replace => { givenName => "Babs" },
                          control => $preread );
if ($mesg->code eq LDAP_SUCCESS) {
  my ($previous) = $mesg->control( LDAP_CONTROL_PREREAD );
  my $entry = $previous ? $previous->entry() : undef;
  if ($entry) {
    print "givenName changed from '" .
          join("', '", $entry->get_value(givenName") .
          "' to 'Babs'\n");
  }
}

DESCRIPTION

"Net::LDAP::Control::PreRead" fournit une interface pour la création et la manipulation d'objets représentant les "Contrôles Pre-Read" tels que décrits par la RFC 4527.

Dans les opérations de modification, le "contrôle de requête Pre-Read" indique au serveur qu'une copie de l'entrée originale avant la mise à jour doit être renvoyée. Après l'achèvement réussi de l'opération, le "contrôle de réponse Pre-Read" correspondant permet de récupérer la valeur originale depuis la réponse du serveur.

Un cas d'utilisation de ce contrôle peut être d'obtenir les valeurs remplacées ou supprimées d'attributs modifiés, ou une copie de l'entrée en cours de suppression.

ARGUMENTS DE CONSTRUCTEUR

En plus des arguments du constructeur décrits dans Net::LDAP::Control, les suivants sont fournis.

attrs => [ ATTRIBUT, ... ]
Une liste d'attributs à retourner dans l'entrée renvoyée dans le contrôle de réponse.

Si absent, tous les attributs sont renvoyés.

Les attributs opérationnels peuvent être inclus dans la liste en les demandant explicitement ou en utilisant la fonctionnalité spéciale "+" (à condition que le serveur supporte cette fonctionnalité).

MÉTHODES

Comme avec Net::LDAP::Control, chaque argument du constructeur décrit ci-dessus est également disponible en tant que méthode sur l'objet, qui retournera la valeur actuelle de l'attribut si appelée sans argument, et définira une nouvelle valeur pour l'attribut si appelée avec un argument.

En plus de ces méthodes, le contrôle supporte également la méthode suivante :

entry ()
Retourne l'entrée du contrôle de réponse dans le message de réponse à la requête LDAP qui contenait le contrôle de requête.

Le résultat est soit un objet Net::LDAP::Entry, soit undefined.
