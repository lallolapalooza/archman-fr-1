NOM

Net::DNS::RR::L64 - Enregistrement de ressource L64 DNS

SYNOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name IN L64 preference locator64');
$rr = Net::DNS::RR->new(
                name       => 'example.com',
                type       => 'L64',
                preference => 10,
                locator64  => '2001:0DB8:1140:1000'
                );

DESCRIPTION

Classe pour les enregistrements de ressource L64 (Locator 64-bit) DNS.

L'enregistrement de ressource L64 est utilisé pour conserver les valeurs Locator 64 bits pour les nœuds compatibles ILNPv6.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées par les méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités de package non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner la terminaison du programme ou d'autres comportements imprévisibles.

preference

$preference = $rr->preference;
$rr->preference( $preference );

Un entier non signé de 16 bits en ordre d'octets réseau qui indique la préférence relative pour cet enregistrement L64 parmi les autres enregistrements L64 associés à ce nom propriétaire. Les valeurs inférieures sont préférées aux valeurs supérieures.

locator64

$locator64 = $rr->locator64;

Le champ Locator64 est un entier non signé de 64 bits en ordre d'octets réseau qui a la même syntaxe et sémantique qu'un préfixe de routage IPv6 de 64 bits.
