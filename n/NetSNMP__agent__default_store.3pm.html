NOM

NetSNMP::agent::default_store - Extension Perl pour le stockage par défaut de l'agent Net-SNMP

SYNTAXE

use NetSNMP::agent::default_store qw(:all);

DESCRIPTION

Le module NetSNMP::agent::default_store définit les variables de stockage par défaut spécifiques à l'agent Net-SNMP.

EXPORT

Aucun par défaut.
