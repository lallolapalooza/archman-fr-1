NOM

Net::LDAP::Message - Message de réponse du serveur LDAP

SYNTAXE

use Net::LDAP;

DESCRIPTION

Net::LDAP::Message est une classe de base pour les objets retournés par les méthodes abandon, add, bind, compare, delete, modify, moddn, search et unbind de Net::LDAP.

La sous-classe Net::LDAP::Search retournée par search définit également de nombreuses méthodes.

Si l'objet Net::LDAP est en mode asynchrone, toutes ces méthodes, sauf "done" et "mesg_id", entraîneront une attente jusqu'à ce que la requête soit terminée.

MÉTHODES

code ( )
La valeur du code dans le message de résultat du serveur. Normalement, pour un succès, zéro sera retourné. Des constantes pour les codes de résultat peuvent être importées du module Net::LDAP ou Net::LDAP::Constant.
control ( [ OID, ... ] )
Retourne la liste des contrôles qui ont été retournés par le serveur. Si un ou plusieurs OID sont donnés en arguments, retourne seulement les contrôles des OID donnés.
dn ( )
Le DN dans le message de résultat du serveur.
done ( )
Retourne *vrai* si la requête est terminée.
error ( )
Retourne le message d'erreur dans le message de résultat du serveur. Si le serveur n'a pas inclus de message d'erreur, alors le résultat de ldap_error_desc avec le code d'erreur du message de résultat.
error_name ( )
Retourne le nom du code d'erreur dans le message de résultat du serveur. Voir ldap_error_name pour une description détaillée de la valeur de retour.
error_text ( )
Retourne la courte description textuelle du code d'erreur dans le message de résultat du serveur. Voir ldap_error_text pour une description détaillée de la valeur de retour.
error_desc ( )
Retourne une longue description textuelle du code d'erreur dans le message de résultat du serveur. Voir ldap_error_desc pour une description détaillée de la valeur de retour.
is_error ( )
Retourne *vrai* si le code de résultat est considéré comme une erreur pour l'opération.
mesg_id ( )
L'ID du message de la requête envoyée au serveur.
referrals ( )
Retourne une liste de renvois provenant du message de résultat.
server_error ( )
Le message d'erreur retourné par le serveur, ou "undef" si le serveur n'a pas fourni de message.
sync ( )
Attend que le serveur termine la requête.

VOIR AUSSI

Net::LDAP, Net::LDAP::Search, Net::LDAP::Constant, Net::LDAP::Util
