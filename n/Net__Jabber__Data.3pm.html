Net::Jabber::Data(3) Documentation Perl contribuée par les utilisateurs Net::Jabber::Data(3)

NOM

Net::Jabber::Data - Bibliothèque de données Jabber

SYNOPIS

Net::Jabber::Data est un module complémentaire à Net::Jabber::XDB. Il fournit à l'utilisateur une interface simple pour définir et récupérer toutes les parties d'une donnée Jabber XDB.

DESCRIPTION

Net::Jabber::Data diffère des autres modules en ce que son comportement et les fonctions disponibles sont basés sur l'espace de noms XML qui y est défini. La liste actuelle des espaces de noms pris en charge est :
  jabber:iq:auth
  jabber:iq:auth:0k
  jabber:iq:register
  jabber:iq:roster
Pour plus d'informations sur l'utilité de ces espaces de noms, visitez 
http://www.jabber.org et parcourez le Guide du programmeur Jabber.
Chacun de ces espaces de noms fournit à Net::Jabber::Data les fonctions
pour accéder aux données. En utilisant la fonction AUTOLOAD, les fonctions
pour chaque espace de noms sont utilisées lorsque cet espace de noms est actif.
Pour accéder à un objet Data, vous devez créer un objet XDB et utiliser les
fonctions d'accès disponibles là-bas pour accéder aux données. Pour initialiser
XDB avec un <xdb/> Jabber, vous devez lui passer la table de hachage XML::Stream du module Net::Jabber::Client.
  my $xdb = new Net::Jabber::XDB(%hash);
Il y a eu un changement par rapport à l'ancienne manière de gérer les rappels.
Vous n'avez plus besoin de faire cela vous-même, un objet Net::Jabber::XDB
est passé à la fonction de rappel pour le message. De plus, le premier argument
aux fonctions de rappel est l'identifiant de session de XML::Streams. Il y a des
cas où vous pourriez avoir besoin de ces informations, par exemple si vous avez
créé un Client qui se connecte à deux serveurs à la fois, ou pour écrire un mini
serveur.
  use Net::Jabber qw(Client);
  sub xdbCB {
    my ($sid,$XDB) = @_;
    my $data = $XDB->GetData();
    .
    .
    .
  }
Vous avez maintenant accès à toutes les fonctions de récupération disponibles
pour cet espace de noms.
Pour créer un nouveau xdb à envoyer au serveur :
  use Net::Jabber;
  my $xdb = new Net::Jabber::XDB();
  $data = $xdb->NewData("jabber:iq:auth");
Maintenant, vous pouvez appeler les fonctions de création pour les données, telles que définies dans les
espaces de noms appropriés. Voir ci-dessous pour les fonctions générales de <data/>, et
dans chaque module de données pour ces fonctions.
Pour plus d'informations sur le format de tableau passé au
CallBack, veuillez lire la documentation de Net::Jabber::Client.

MÉTHODES

Fonctions de récupération

GetXMLNS() - renvoie une chaîne avec l'espace de noms des données que
             le <xdb/> contient.
             $xmlns  = $XDB->GetXMLNS();
GetData() - comme le comportement de ce module dépend de l'espace de
             noms, un objet Data peut contenir des objets Data.
             Ceci permet de réutiliser le code en faisant en sorte que les enfants
             se comportent de la même manière. Il est fort probable que cette
             fonction ne sera jamais appelée.
             @data = GetData()

Fonctions de création

SetXMLNS(string) - définit le xmlns des <data/> à la chaîne.
                   $data->SetXMLNS("jabber:xdb:roster");

Afin de faciliter la maintenance de ce document, je ne vais pas entrer dans le détail de chacune de ces fonctions. Je vais plutôt présenter les fonctions dans une liste avec un type dans la première colonne pour montrer ce qu'elles retournent ou prennent comme arguments. Voici la liste des types que j'utiliserai :

string  - juste une chaîne
array   - tableau de chaînes
flag    - cela signifie que l'enfant spécifié existe dans le
          XML <child/> et agit comme un indicateur.  get retournera
          0 ou 1.
JID     - soit une chaîne, soit un objet Net::Jabber::JID.
objects - crée de nouveaux objets, ou renvoie un tableau d'objets.
special - il s'agit d'un cas spécial de fonction. Généralement,
          en appelant simplement Set() sans arguments, il prendra
          une valeur par défaut spéciale, comme l'OS ou l'heure.
          Parfois, cela modifiera la valeur que vous définissez, comme
          dans jabber:xdb:version SetVersion(), la fonction
          ajoute la version de Net::Jabber à la chaîne
          juste à des fins publicitaires. =)
master  - ceci décrit une fonction qui se comporte comme la
          fonction SetMessage() dans Net::Jabber::Message.
          Elle prend une table de hachage et définit toutes les valeurs définies,
          et Set renvoie une table de hachage avec les valeurs qui
          sont définies dans l'objet.

ESPACES DE NOMS PERSONNALISÉS

Une partie de la flexibilité de ce module est que vous pouvez définir votre propre
espace de noms. Pour plus d'informations à ce sujet, veuillez lire la page de manuel
Net::Jabber::Namespaces.
