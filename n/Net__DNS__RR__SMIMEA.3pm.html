NOM

Net::DNS::RR::SMIMEA - Enregistrement de ressource DNS SMIMEA

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new('name SMIMEA usage selector matchingtype certificate');

DESCRIPTION

L'enregistrement de ressource DNS SMIMEA (RR) est utilisé pour associer un certificat d'entité finale ou une clé publique à l'adresse e-mail associée, formant ainsi une "association de certificat SMIMEA". La sémantique de l'interprétation de l'enregistrement SMIMEA est décrite dans la RFC6698.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées des méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités non documentées du package ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

usage

$usage = $rr->usage;
$rr->usage( $usage );

Valeur entière de 8 bits qui spécifie l'association fournie qui sera utilisée pour faire correspondre le certificat.

selector

$selector = $rr->selector;
$rr->selector( $selector );

Valeur entière de 8 bits qui spécifie quelle partie du certificat présenté par le serveur sera mise en correspondance avec les données d'association.

matchingtype

$matchingtype = $rr->matchingtype;
$rr->matchingtype( $matchingtype );

Valeur entière de 8 bits qui spécifie comment l'association de certificat est présentée.

certificate

cert

$cert = $rr->cert;
$rr->cert( $cert );

Représentation hexadécimale des données du certificat.

certbin

$certbin = $rr->certbin;
$rr->certbin( $certbin );

Représentation binaire des données du certificat.

babble

print $rr->babble;

La méthode babble() renvoie la représentation 'BubbleBabble' du résumé si le package Digest::BubbleBabble est disponible, sinon une chaîne vide est retournée.

BubbleBabble représente un résumé de message sous forme d'une chaîne de mots plausibles, pour faciliter la vérification du résumé. Les "mots" ne sont pas nécessairement des mots réels, mais ils ressemblent davantage à des mots qu'à une chaîne de caractères hexadécimaux.

La chaîne 'BubbleBabble' est ajoutée comme commentaire lorsque la méthode de chaîne est appelée.
