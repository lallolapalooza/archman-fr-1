NOM

Net::DNS::SEC::Tools::conf - Routines de configuration DNSSEC-Tools.

SYNOPSIS

use Net::DNS::SEC::Tools::conf;
%dtconf = parseconfig();
%dtconf = parseconfig("localzone.keyrec");
cmdcheck(\%options_hashref);
$conferrs = dt_confcheck();
$prefixdir = getprefixdir();
$confdir = getconfdir();
$conffile = getconffile();
setconffile("dt-local.conf");
$statedir = getlocalstatedir();
$statedir = makelocalstatedir();
$statesub = makelocalstatedir("logs/zones");
$packed = runpacked();
erraction(ERR_MSG);
err("impossible d'ouvrir le fichier keyrec",1);

DESCRIPTION

Les routines de ce module effectuent des opérations de configuration. Certaines routines accèdent au fichier de configuration DNSSEC-Tools, tandis que d'autres valident l'environnement d'exécution.

Les outils DNSSEC disposent d'un fichier de configuration pour les valeurs couramment utilisées. Ces valeurs sont les valeurs par défaut pour une variété d'éléments, tels que l'algorithme de chiffrement et la longueur de la clé de chiffrement. Le module Net::DNS::SEC::Tools::conf fournit des méthodes pour accéder aux données de configuration de ce fichier.

dnssec-tools.conf est le nom de fichier du fichier de configuration des outils DNSSEC. Le chemin complet dépend de la façon dont DNSSEC-Tools a été configuré ; voir la section DIRECTORIES pour le chemin complet. Les chemins requis par conf.pm sont définis lors de la configuration de DNSSEC-Tools.

Le fichier de configuration des outils DNSSEC se compose d'un ensemble d'entrées de valeurs de configuration, avec une seule entrée par ligne. Chaque entrée a le format "mot-clé valeur". Lors de l'analyse, la ligne est décomposée en jetons, les jetons étant séparés par des espaces et des tabulations. Le premier jeton de la ligne est considéré comme le mot-clé. Tous les autres jetons de cette ligne sont concaténés en une seule chaîne, un espace séparant chaque jeton. La chaîne non tokenisée est ajoutée à une table de hachage, le mot-clé étant la clé de la valeur.

Les commentaires peuvent être inclus en les faisant précéder des caractères de commentaire '#' ou ';'. Ces commentaires peuvent occuper une ligne entière ou suivre une entrée de configuration. Si un commentaire partage une ligne avec une entrée, la tokenisation de la valeur s'arrête juste avant le caractère de commentaire.

Un exemple de fichier de configuration suit :

# Entrées de configuration d'exemple.
algorithm       rsasha1     # Algorithme de chiffrement.
ksk_length      2048        ; Longueur de clé KSK.

Un autre aspect de la configuration de DNSSEC-Tools est l'action d'erreur utilisée par les modules Perl de DNSSEC-Tools. L'action dicte si une condition d'erreur donnera seulement un retour d'erreur, affichera un message d'erreur sur STDERR, ou affichera un message d'erreur et quittera. Les interfaces erraction() et err() sont utilisées pour ces opérations.

INTERFACES

dt_confcheck(errflag)
Cette routine effectue un certain nombre de vérifications de configuration pour s'assurer que l'environnement est suffisant pour supporter la configuration de DNSSEC-Tools. Si errflag est 0, les vérifications sont effectuées silencieusement ; sinon, des messages d'erreur seront affichés.

Les vérifications sont :

* Le répertoire sysconf de dnssec-tools existe.
* Le répertoire sysconf de dnssec-tools est un répertoire.
* Le répertoire de dnssec-tools existe.
* Le répertoire de dnssec-tools est un répertoire.
* Le fichier de configuration de dnssec-tools existe.
* Le fichier de configuration de dnssec-tools est un fichier régulier.
* Le fichier de configuration de dnssec-tools n'est pas vide.
* Le nom du répertoire d'état local n'excède pas 75 caractères (pour permettre le socket de commande rollmgr.)
* Le répertoire d'état local est un répertoire.
* Le répertoire d'état local peut être créé si nécessaire.
* Le sous-répertoire dnssec-tools du répertoire d'état local
  peut être créé si nécessaire, ou est inscriptible s'il existe déjà.
* Le sous-répertoire run du répertoire d'état local
  peut être créé si nécessaire, ou est inscriptible s'il existe déjà.

Valeurs de retour :

0       aucune erreur n'a été trouvée
>0      un certain nombre de vérifications de configuration ont échoué
parseconfig()
Cette routine lit et analyse le fichier de configuration des outils DNSSEC du système. Les contenus analysés sont placés dans une table de hachage, qui est retournée à l'appelant.
parseconfig(conffile)
Cette routine lit et analyse un fichier de configuration des outils DNSSEC spécifié par l'appelant. Les contenus analysés sont placés dans une table de hachage, qui est retournée à l'appelant. La routine retourne silencieusement si le fichier de configuration n'existe pas.
cmdcheck(\%options_hashref)
Cette routine garantit que les commandes nécessaires sont disponibles et exécutables. Si l'une des commandes n'existe pas ou n'est pas exécutable, un message d'erreur sera affiché et le processus se terminera. Si tout va bien, tout continuera silencieusement.

Les clés de commandes actuellement vérifiées sont zonecheck, keygen et zonesign. Les chemins d'accès à ces commandes se trouvent dans la table de hachage des options donnée, référencée par %options_hashref. Si la table de hachage ne contient pas d'entrée pour l'une de ces commandes, elle n'est pas vérifiée.

Si cette routine est appelée depuis un script PAR-packed, elle recherchera les commandes dans le répertoire du package. Elle définira également leurs modes de fichier à 0755, car PAR semble ignorer les modes de fichier lors de l'empaquetage des programmes.

getconfdir()
Cette routine retourne le nom du répertoire de configuration de DNSSEC-Tools.
getconffile()
Cette routine retourne le nom du fichier de configuration de DNSSEC-Tools.
setconffile()
Cette routine définit le nom du fichier de configuration de DNSSEC-Tools.

Valeurs de retour :
1 retourné en cas de succès
0 retourné si le fichier de configuration spécifié n'existe pas
ou n'est pas un fichier régulier

getprefixdir()
Cette routine retourne le nom du répertoire préfixe de DNSSEC-Tools.
getlocalstatedir()
Cette routine retourne le nom du répertoire d'état local.
runpacked()
Cette routine retourne une valeur booléenne indiquant si la commande exécutée provient d'un script PAR-packed.
makelocalstatedir(subdir)
Cette routine crée le répertoire d'état local et retourne son nom. Le répertoire n'est créé que s'il n'existe pas déjà.

Si le sous-répertoire optionnel subdir est spécifié, alors ce répertoire est créé dans le répertoire d'état local. Dans ce cas, le chemin de subdir est retourné. subdir peut comprendre plusieurs répertoires intermédiaires, ainsi que le répertoire terminal. Par exemple, makelocalstatedir("logs/zones/errors") créera la hiérarchie logs/zones/errors dans le répertoire d'état local.

makelocalstatedir(subdir) utilise le module File::Path, qui est disponible sur toutes les versions modernes de Perl.

Une chaîne vide est retournée en cas d'erreurs. Les erreurs suivantes peuvent être rencontrées :

* I<File::Path> n'a pas pu être chargé
* Impossible de créer le répertoire d'état local
* Impossible de créer un composant de I<subdir>
* Le chemin complet (répertoire d'état local et I<subdir>) existe déjà
  et n'est pas un répertoire
boolconvert(config-value)
Cette routine convertit les valeurs de configuration en valeurs booléennes appropriées. Les conversions de texte suivantes sont effectuées : 
1 - 'true', 't', 'yes', 'y'
0 - 'false', 'f', 'no', 'n'

Toutes les autres valeurs textuelles sont converties en 0.

Les valeurs positives sont converties en 1. Les valeurs négatives sont converties en 0.

ERR_SILENT          Ne pas imprimer de message d'erreur, ne pas quitter.

err("message d'erreur",code_sortie)
L'interface err() est utilisée par les modules Perl DNSSEC-Tools pour signaler une erreur et quitter, en fonction de l'action d'erreur.

Le premier argument est un message d'erreur à imprimer -- si l'action d'erreur autorise l'impression de messages d'erreur.

Le deuxième argument est un code de sortie -- si l'action d'erreur exige que le processus quitte.

RÉPERTOIRES

Les répertoires par défaut pour cette installation sont :

prefix                         : /usr
sysconf                        : /etc
localstatedir                  : /usr/var
DNSSEC-Tools configuration file: /etc/dnssec-tools

Ceux-ci peuvent être remplacés en utilisant les variables d'environnement suivantes :

prefix                         : DT_PREFIX
sysconf                        : DT_SYSCONFDIR
localstatedir                  : DT_STATEDIR
