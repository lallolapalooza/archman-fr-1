NOM

Net::DNS::Resolver::Recurse - Résolveur DNS récursif

SYNOPSIS

use Net::DNS::Resolver::Recurse;
my $resolver = new Net::DNS::Resolver::Recurse();
$resolver->hints('198.41.0.4'); # A.ROOT-SERVER.NET.
my $packet = $resolver->send( 'www.rob.com.au.', 'A' );

DESCRIPTION

Ce module résout les requêtes en suivant le chemin de délégation à partir de la racine DNS.

MÉTHODES

Ce module hérite de presque toutes les méthodes de Net::DNS::Resolver. Les méthodes spécifiques supplémentaires au module sont décrites ci-dessous.

hints

Cette méthode spécifie une liste d'adresses IP des serveurs de noms à utiliser pour découvrir les adresses des serveurs de noms racine.

$resolver->hints(@ip);

Si aucun indice n'est fourni, la requête d'amorçage est dirigée vers les serveurs de noms tirés d'une liste intégrée d'adresses IP.

query, search, send

Les méthodes query(), search() et send() produisent le même résultat que leurs homologues dans Net::DNS::Resolver.

$packet = $resolver->send( 'www.example.com.', 'A' );

La récursion côté serveur est supprimée en effaçant le drapeau de récursion dans les paquets de requête, et la résolution de noms récursive est effectuée explicitement.

Les méthodes query() et search() sont héritées de Net::DNS::Resolver et invoquent send() indirectement.

callback

Cette méthode spécifie une référence de code vers une sous-routine, qui est ensuite appelée à chaque étape de la recherche récursive.

Par exemple, pour émuler la fonction "+trace" de dig :

my $coderef = sub {
my $packet = shift;
printf ";; Received %d bytes from %s\n\n",
        $packet->answersize, $packet->answerfrom;
};
$resolver->callback($coderef);

La sous-routine de rappel n'est pas appelée pour les requêtes de raccourcis manquants.
