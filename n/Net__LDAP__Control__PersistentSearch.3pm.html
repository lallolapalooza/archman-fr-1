NOM

Net::LDAP::Control::PersistentSearch - Objet de contrôle de recherche persistante LDAPv3

SYNOPSIS

use Net::LDAP;
use Net::LDAP::Control::PersistentSearch;
$ldap = Net::LDAP->new( "ldap.mondomaine.eg" );
$persist = Net::LDAP::Control::PersistentSearch->new( changeTypes => 15,
                                                      changesOnly => 1,
                                                      returnECs => 1 );
$srch = $ldap->search( base     => "cn=People,dc=mondomaine,dc=eg",
                       filter   => "(objectClass=person)",
                       callback => \&process_entry, # appel pour chaque entrée
                       control  => [ $persist ] );
die "erreur: " . $srch->code() . ": " . $srch->error() if ($srch->code());
sub process_entry {
  my $message = shift;
  my $entry = shift;
  print $entry->dn()."\n";
  # réduire l'utilisation de la mémoire
  $message->pop_entry();
}

DESCRIPTION

"Net::LDAP::Control::PersistentSearch" fournit une interface pour la création et la manipulation d'objets qui représentent le contrôle "PersistentSearch" tel que décrit dans draft-smith-psearch-ldap-03.txt.

ARGUMENTS DU CONSTRUCTEUR

En plus des arguments du constructeur décrits dans Net::LDAP::Control, les suivants sont fournis.

changeTypes
Une valeur entière déterminant les types de modifications à surveiller. C'est le OU bit à bit des valeurs suivantes (qui représentent les opérations LDAP indiquées à côté d'elles) :
1 = add
2 = delete
4 = modify
8 = modDN

Si elle n'est pas fournie, la valeur par défaut est 15, ce qui signifie toutes les modifications.

changesOnly
Une valeur booléenne indiquant si le serveur peut renvoyer les entrées qui correspondent aux critères de recherche.

Si "TRUE", le serveur ne doit pas renvoyer les entrées existantes qui correspondent aux critères de recherche. Les entrées ne sont renvoyées que lorsqu'elles sont modifiées (ajoutées, modifiées, supprimées, ou soumises à une opération modifyDN).

returnECs
Si "TRUE", le serveur doit renvoyer un contrôle de notification de changement d'entrée avec chaque entrée renvoyée comme résultat des modifications.

Voir Net::LDAP::Control::EntryChange pour plus de détails.

MÉTHODES

Comme avec Net::LDAP::Control, chaque argument du constructeur décrit ci-dessus est également disponible sous forme de méthode sur l'objet, qui renverra la valeur actuelle de l'attribut si elle est appelée sans argument, et définira une nouvelle valeur pour l'attribut si elle est appelée avec un argument.

VOIR AUSSI

Net::LDAP, Net::LDAP::Control, Net::LDAP::Control::EntryChange
