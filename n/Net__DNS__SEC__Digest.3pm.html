NOM

Net::DNS::SEC::Digest - Algorithmes de résumé de message

SYNTAXE

require Net::DNS::SEC::Digest;
$objet = Net::DNS::SEC::Digest::SHA->new(256);
$objet->add($texte);
$objet->add($suite);
$resumer = $objet->digest;

DESCRIPTION

Paquet d'interface fournissant l'accès aux implémentations d'algorithmes de résumé de message de la bibliothèque cryptographique OpenSSL.

MÉTHODES

new

require Net::DNS::SEC::Digest;
$objet = Net::DNS::SEC::Digest::SHA->new(256);

Crée et initialise une nouvelle instance d'objet de résumé pour la classe d'algorithme spécifiée.

add

$objet->add($donnees);
$objet->add($suite);

Ajoute les données spécifiées au flux de résumé.

digest

$resumer = $objet->digest;

Retourne une chaîne d'octets contenant le résumé calculé.
