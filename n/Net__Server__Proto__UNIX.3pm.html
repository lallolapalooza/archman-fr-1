NOM

Net::Server::Proto::UNIX - Protocole UNIX pour Net::Server.

SYNOPSIS

Voir Net::Server::Proto.

DESCRIPTION

Module de protocole pour Net::Server. Ce module implémente le type de socket UNIX SOCK_STREAM. Voir Net::Server::Proto.

Tous les sockets créés au démarrage seront chown'és à l'utilisateur et au groupe spécifiés dans les arguments de démarrage.

PARAMÈTRES

Les paramètres suivants peuvent être spécifiés en plus des paramètres de ligne de commande normaux pour un Net::Server. Voir Net::Server pour plus d'informations sur la lecture des arguments.

type_unix
Peut être SOCK_STREAM ou SOCK_DGRAM (par défaut SOCK_STREAM). Ceci peut également être passé sur la ligne de port (voir Net::Server::Proto).

Cependant, cette méthode est dépréciée. Si vous voulez SOCK_STREAM, utilisez simplement le protocole UNIX sans autres arguments. Si vous voulez SOCK_DGRAM, utilisez le nouveau protocole UNIXDGRAM.

MÉTHODES

NS_chemin_unix/NS_type_unix
En plus des méthodes NS_ standards des classes Net::Server::Proto, les types UNIX ont également des appels hérités à NS_chemin_unix et NS_type_unix.

Depuis la version 2.000, NS_chemin_unix est simplement un alias de NS_port. NS_type_unix est maintenant redondant avec NS_proto.

Ces méthodes manquaient entre les versions 2.000 et 2.003 mais ont été rétablies comme passerelles héritées.

LISTE RAPIDE DES PARAMÈTRES

Clé               Valeur                   Défaut
# paramètres de socket UNIX dépréciés
type_unix         (SOCK_STREAM|SOCK_DGRAM) SOCK_STREAM
port              "nom_de_fichier"               undef
# utilisation plus récente
port              "nom_de_fichier / UNIX"
port              "nom_de_fichier / UNIXDGRAM"
