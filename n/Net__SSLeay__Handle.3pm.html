Net::SSLeay::Handle(3) Documentation fournie par l'utilisateur pour Perl Net::SSLeay::Handle(3)

NOM

Net::SSLeay::Handle - Module Perl pour permettre la gestion des sockets SSL (HTTPS) comme des handles standards.

SYNTAXE

use Net::SSLeay::Handle qw/shutdown/;
my ($host, $port) = ("localhost", 443);
tie(*SSL, "Net::SSLeay::Handle", $host, $port);
print SSL "GET / HTTP/1.0\r\n";
shutdown(\*SSL, 1);
print while ();
close SSL;

DESCRIPTION

Net::SSLeay::Handle permet de demander et de recevoir des pages Web HTTPS en utilisant des handles "old school" comme dans :

print SSL "GET / HTTP/1.0\r\n";

et

print while ();

S'il exporte la fonction shutdown, alors le seul code supplémentaire que vous devez ajouter à votre programme est la fonction tie, comme dans :

my $socket;
if ($scheme eq "https") {
    tie(*S2, "Net::SSLeay::Handle", $host, $port);
    $socket = \*S2;
else {
    $socket = Net::SSLeay::Handle->make_socket($host, $port);
}
print $socket $request_headers;
...

FONCTIONS

shutdown
shutdown(\*SOCKET, $mode)

Les appels à la fonction principale shutdown() ne fonctionnent pas avec les sockets créés avec ce module. Cette fonction shutdown doit être capable de distinguer les sockets liés (tied) des sockets non liés et de faire ce qu'il faut.

debug
my $debug = Net::SSLeay::Handle->debug()
Net::SSLeay::Handle->debug(1)

Obtenir/définir le mode de débogage. S'il reçoit un argument supplémentaire, l'option de débogage sera réglée à cette valeur.

make_socket
my $sock = Net::SSLeay::Handle->make_socket($host, $port);

Crée un socket connecté à $host en utilisant $port. Il utilise $Net::SSLeay::proxyhost et $proxyport s'ils sont définis et s'authentifie auprès de ce proxy selon $Net::SSLeay::proxyauth. Il active également le autoflush sur le socket créé.

UTILISATION DE SOCKETS EXISTANTS

L'une des motivations pour écrire ce module était d'éviter de dupliquer le code de création de sockets (ce qui est surtout une affaire de gestion d'erreurs). Les appels à tie() ci-dessus reçoivent un $host et un $port pour faciliter les tests. Si vous avez déjà un socket connecté à la bonne adresse et au bon port, S1, alors vous pouvez faire quelque chose comme :

my $socket \*S1;
if ($scheme eq "https") {
    tie(*S2, "Net::SSLeay::Handle", $socket);
    $socket = \*S2;
}
my $last_sel = select($socket); $| = 1; select($last_sel);
print $socket $request_headers;
...

Note : Autant que je sache, vous devez faire attention aux variables globales dans la fonction tie(). Le premier paramètre doit être un glob (*SOMETHING) et le dernier paramètre doit être une référence à un glob (\*SOMETHING_ELSE) ou un scalaire qui a été assigné à une référence à un glob (comme dans l'exemple ci-dessus).

Les deux globs doivent également être différents. Lorsque j'ai essayé d'utiliser le même glob, j'ai obtenu un core dump.

EXPORT

Cependant, il n'est pas exporté par défaut.

Vous pouvez exporter la fonction shutdown().

Il est suggéré que vous exportiez shutdown() ou que vous utilisiez la fonction entièrement qualifiée Net::SSLeay::Handle::shutdown() pour terminer les sockets SSL. Elle doit être suffisamment intelligente pour distinguer les sockets SSL et non-SSL et faire ce qu'il faut.

EXEMPLES

use Net::SSLeay::Handle qw/shutdown/;
my ($host, $port) = ("localhost", 443);
tie(*SSL, "Net::SSLeay::Handle", $host, $port);
print SSL "GET / HTTP/1.0\r\n";
shutdown(\*SSL, 1);
print while ();
close SSL;

ATTENTION

Lier un handle est un peu délicat (pour moi du moins).

Le premier paramètre à tie() doit être un glob (*SOMETHING) et le dernier paramètre doit être une référence à un glob (\*SOMETHING_ELSE) ou un scalaire qui a été assigné à une référence à un glob (comme dans l'exemple ci-dessus).

Les deux globs doivent également être différents. Lorsque j'ai essayé d'utiliser le même glob, j'ai obtenu un core dump.

J'ai pu associer des attributs aux globs créés par ce module (comme *SSL ci-dessus) en utilisant une table de hachage de tables de hachage, indexée par l'en-tête du fichier.
