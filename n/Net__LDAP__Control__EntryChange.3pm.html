Net::LDAP::Control::EntryChange(3) Documentation Perl fournie par l'utilisateur Net::LDAP::Control::EntryChange(3)

NOM

Net::LDAP::Control::EntryChange - Objet de contrôle de notification de changement d'entrée LDAPv3

SYNOPIS

use Net::LDAP;
use Net::LDAP::Control::PersistentSearch;
use Net::LDAP::Constant qw(LDAP_CONTROL_ENTRYCHANGE);
$ldap = Net::LDAP->new( "ldap.mondomaine.eg" );
$persist = Net::LDAP::Control::PersistentSearch->new( changeTypes => 15,
                                                      changesOnly => 1,
                                                      returnECs => 1 );
$srch = $ldap->search( base     => "cn=People,dc=mondomaine,dc=eg",
                       filter   => "(objectClass=person)",
                       callback => \&process_entry, # appel pour chaque entrée
                       control  => [ $persist ] );
die "erreur: ",$srch->code(),": ",$srch->error()  if ($srch->code());
sub process_entry {
  my $message = shift;
  my $entry = shift;
  my ($control) = $message->control(LDAP_CONTROL_ENTRYCHANGE);
  print $control->changeType()."\t".$entry->dn()."\n";
}

DESCRIPTION

"Net::LDAP::Control::EntryChange" fournit une interface pour la création et la manipulation d'objets qui représentent le contrôle "EntryChangeNotification" tel que décrit dans draft-smith-psearch-ldap-03.txt.

ARGUMENTS DU CONSTRUCTEUR

En plus des arguments du constructeur décrits dans Net::LDAP::Control, les suivants sont fournis.

changeType
Une valeur entière indiquant le type d'opération LDAP que l'entrée a subie. C'est l'une des valeurs suivantes (qui représentent les opérations LDAP indiquées à côté d'elles) :
1 = add
2 = delete
4 = modify
8 = modDN
previousDN
Lorsque changeType est 8 (pour modDN), ce paramètre indique le DN de l'entrée avant l'opération modDN. Dans tous les autres cas, cette valeur n'est pas définie.
changeNumber
C'est le numéro de changement selon <draft-good-ldap-changelog-03.txt> attribué par un serveur pour le changement. Si un serveur prend en charge un journal des changements LDAP, il devrait inclure ce champ.

Normalement, vous n'avez pas besoin de créer vous-même un contrôle "Net::LDAP::Control::EntryChange" car il est fourni par le serveur en réponse à une option avec le contrôle "Net::LDAP::Control::PersistentSearch".

MÉTHODES

Comme pour Net::LDAP::Control, chaque argument du constructeur décrit ci-dessus est également disponible sous forme de méthode sur l'objet, qui retournera la valeur actuelle de l'attribut s'il est appelé sans argument, et définira une nouvelle valeur pour l'attribut s'il est appelé avec un argument.

VOIR AUSSI

Net::LDAP, Net::LDAP::Control, Net::LDAP::Control::PersistentSearch
