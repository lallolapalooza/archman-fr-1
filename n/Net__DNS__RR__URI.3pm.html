NOM

Net::DNS::RR::URI - enregistrement de ressource URI DNS

SYNOPIS

use Net::DNS;
$rr = Net::DNS::RR->new('nom URI priorité poids cible');

DESCRIPTION

Classe pour les enregistrements de ressource DNS (URI).

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités non documentées du paquet ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

priorité

$priorité = $rr->priorité;
$rr->priorité( $priorité );

La priorité de l'URI cible dans cet enregistrement. La plage de ce nombre est de 0 à 65535. Un client DOIT tenter de contacter l'URI avec la priorité la plus basse qu'il puisse atteindre ; la sélection pondérée étant utilisée pour répartir la charge entre les cibles ayant une priorité égale.

poids

$poids = $rr->poids;
$rr->poids( $poids );

Un mécanisme de sélection de serveur. Le champ poids spécifie un poids relatif pour les entrées ayant la même priorité. Les poids plus importants devraient se voir attribuer une probabilité proportionnellement plus élevée d'être sélectionnés. La plage de ce nombre est de 0 à 65535.

cible

$cible = $rr->cible;
$rr->cible( $cible );

L'URI de la cible. La résolution de l'URI est conforme aux définitions du schéma de l'URI.
