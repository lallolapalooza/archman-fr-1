NAME

Net::LDAPS - utiliser LDAP sur une connexion SSL

SYNOPSIS

use Net::LDAPS;
$ldaps = Net::LDAPS->new('monhost.example.com',
                         port => '10000',
                         verify => 'require',
                         capath => '/usr/local/cacerts/');
# autre façon
use Net::LDAP;
$ldaps = Net::LDAP->new('ldaps://monhost.example.com:10000',
                        verify => 'require',
                        capath => '/usr/local/cacerts/');

DESCRIPTION

Communique en utilisant le protocole LDAP avec un serveur d'annuaire via une connexion réseau chiffrée (SSL). Ce mécanisme n'est pas standard mais est largement supporté ; envisagez d'utiliser LDAPv3 avec l'extension TLS standard si possible (de nombreux serveurs ne la supportent pas encore.) Voir "start_tls" dans Net::LDAP.

Toutes les méthodes normales de "Net::LDAP" peuvent être utilisées avec un objet "Net::LDAPS" ; voir Net::LDAP pour plus de détails.

CONSTRUCTEUR

new ( HOST [, OPTIONS ] )
Crée une nouvelle connexion. HOST est le nom d'hôte à contacter. OPTIONS est un ensemble de paires clé/valeur. Voir "new" dans Net::LDAP pour les détails.

VOIR AUSSI

Net::LDAP, IO::Socket::SSL

BOGUES

Vous ne pouvez pas avoir plus d'une connexion LDAPS à la fois, en raison des restrictions dans le code sous-jacent Net::SSLeay.
