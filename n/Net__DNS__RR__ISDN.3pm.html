NOM

Net::DNS::RR::ISDN - Enregistrement de ressource ISDN DNS

SYNOPIS

use Net::DNS;
$rr = Net::DNS::RR->new('name ISDN ISDNaddress sa');

DESCRIPTION

Classe pour les enregistrements de ressource ISDN DNS.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités de paquet non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

ISDNaddress

address

$address = $rr->address;
$rr->address( $address );

L'adresse ISDN est une chaîne de caractères, normalement des chiffres décimaux, commençant par l'indicatif pays E.163 et se terminant par le DDI, le cas échéant.

sa

$sa = $rr->sa;
$rr->sa( $sa );

Le sous-adressage (SA) optionnel est une chaîne de chiffres hexadécimaux.
