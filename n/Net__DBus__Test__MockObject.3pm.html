NOM

Net::DBus::Test::MockObject - Fait semblant d'être un objet du bus pour les tests unitaires

SYNTAXE

use Net::DBus;
use Net::DBus::Test::MockObject;
my $bus = Net::DBus->test
# Faisons semblant de la présence de HAL...
# D'abord, nous devons définir le service
my $service = $bus->export_service("org.freedesktop.Hal");
# Puis créons un objet factice
my $object = Net::DBus::Test::MockObject->new($service,
                                              "/org/freedesktop/Hal/Manager");
# Faisons semblant de la méthode 'GetAllDevices'
$object->seed_action("org.freedesktop.Hal.Manager",
                     "GetAllDevices",
                     reply => {
                       return => [ "/org/freedesktop/Hal/devices/computer_i8042_Aux_Port",
                                   "/org/freedesktop/Hal/devices/computer_i8042_Aux_Port_logicaldev_input",
                                   "/org/freedesktop/Hal/devices/computer_i8042_Kbd_Port",
                                   "/org/freedesktop/Hal/devices/computer_i8042_Kbd_Port_logicaldev_input"
                       ],
                     });
# Maintenant, on peut tester toute classe qui appelle 'GetAllDevices' dans HAL
....stuff de test....

DESCRIPTION

Ceci fournit une alternative à Net::DBus::Object pour permettre de créer rapidement des objets de bus factices, facilitant ainsi la création de tests unitaires pour les services qui pourraient avoir besoin d'appeler des objets fournis par des services tiers sur le bus. Il est généralement utilisé en complément de l'objet Net::DBus::MockBus, pour permettre de tester des services complexes sans avoir à démarrer un vrai bus.

!!!!! ATTENTION !!!

Cet objet et ses API doivent être considérés comme très expérimentaux à ce stade, et aucune garantie quant à la compatibilité future de l'API n'est fournie. Les commentaires et suggestions sur la façon d'améliorer ce framework sont cependant les bienvenus et encouragés.

MÉTHODES

mon $objet = Net::DBus::Test::MockObject->new($service, $path, $interface);
Crée un nouvel objet factice, s'attachant au service défini par le paramètre $service. Ce serait une instance de l'objet Net::DBus::Service. Le paramètre $path définit le chemin de l'objet auquel cet objet factice sera attaché, et $interface définit l'interface qu'il supportera.
mon $service = $objet->get_service
Récupère l'objet Net::DBus::Service au sein duquel cet objet est exporté.
mon $path = $objet->get_object_path
Récupère le chemin sous lequel cet objet est exporté.
mon $msg = $objet->get_last_message
Récupère le dernier message traité par cet objet. L'objet retourné est une instance de Net::DBus::Binding::Message.
mon $sig = $objet->get_last_message_signature
Récupère la signature de type du dernier message traité.
mon $value = $objet->get_last_message_param
Retourne la première valeur fournie en argument du dernier message traité.
mon @values = $objet->get_last_message_param_list
Retourne une liste de toutes les valeurs fournies en arguments du dernier message traité.
$objet->seed_action($interface, $method, %action);
Enregistre une action à effectuer lorsqu'un message correspondant à la méthode $method de l'interface $interface est reçu. Le paramètre %action peut avoir plusieurs clés possibles :
signals
Provoque l'émission d'un signal lors de l'invocation de la méthode. La valeur associée à cette clé doit être une instance de la classe Net::DBus::Binding::Message::Signal.
error
Provoque la génération d'une erreur lors de l'invocation de la méthode. La valeur associée à cette clé doit être une référence de hachage, avec deux éléments. Le premier, "name", donne le nom de l'erreur, et le second, "description", fournit le texte descriptif.
reply
Provoque la génération d'un retour de méthode normal. La valeur associée à cette clé doit être une référence de tableau, dont les éléments sont les valeurs à retourner par la méthode.

BOGUES

Il ne reproduit pas complètement l'API de Net::DBus::Binding::Object, seulement assez pour que les liaisons de haut niveau fonctionnent dans un scénario de test.
