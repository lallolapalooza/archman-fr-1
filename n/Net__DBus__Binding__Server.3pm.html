NOM

Net::DBus::Binding::Server - Un serveur pour accepter les connexions entrantes

SYNTAXE

Création d'un nouveau serveur et acceptation des connexions clients

use Net::DBus::Binding::Server;
my $server = Net::DBus::Binding::Server->new(address => "unix:path=/path/to/socket");
$server->connection_callback(\&new_connection);
sub new_connection {
    my $connection = shift;
    .. travailler avec la nouvelle connexion...
}

Gestion du serveur et des nouvelles connexions dans une boucle d'événements

my $reactor = Net::DBus::Binding::Reactor->new();
$reactor->manage($server);
$reactor->run();
sub new_connection {
    my $connection = shift;
    $reactor->manage($connection);
}

DESCRIPTION

Un serveur pour recevoir les connexions des programmes clients. Les méthodes définies dans ce module correspondent étroitement aux méthodes dbus_server_XXX de l'API C. Pour plus de détails sur leur comportement, la documentation de l'API C peut être utile.

MÉTHODES

mon $server = Net::DBus::Binding::Server->new(address => "unix:path=/path/to/socket");
Crée un nouveau serveur en le liant au socket spécifié par le paramètre "address".
$status = $server->is_connected();
Retourne zéro si le serveur a été déconnecté, sinon une valeur positive est retournée.
$server->disconnect()
Ferme ce serveur au client distant. Cette méthode est appelée automatiquement lors de la collecte des objets inutilisés (c'est-à-dire dans la méthode DESTROY) si le programmeur oublie de déconnecter explicitement.
$server->set_watch_callbacks(\&add_watch, \&remove_watch, \&toggle_watch);
Enregistre un ensemble de rappels pour ajouter, supprimer et mettre à jour les surveillances dans la boucle d'événements de l'application. Chaque paramètre doit être une référence de code, qui sera appelée à chaque invocation avec deux paramètres : l'objet serveur et l'objet surveillance. Si vous utilisez un objet "Net::DBus::Binding::Reactor" comme boucle d'événements de l'application, alors la méthode 'manage' sur cet objet appellera ceci en votre nom.
$server->set_timeout_callbacks(\&add_timeout, \&remove_timeout, \&toggle_timeout);
Enregistre un ensemble de rappels pour ajouter, supprimer et mettre à jour les délais d'attente dans la boucle d'événements de l'application. Chaque paramètre doit être une référence de code, qui sera appelée à chaque invocation avec deux paramètres : l'objet serveur et l'objet délai d'attente. Si vous utilisez un objet "Net::DBus::Binding::Reactor" comme boucle d'événements de l'application, alors la méthode 'manage' sur cet objet appellera ceci en votre nom.
$server->set_connection_callback(\&handler)
Enregistre le gestionnaire à utiliser pour traiter les nouvelles connexions entrantes des clients. La référence de code sera invoquée chaque fois qu'un nouveau client se connectera et recevra un seul paramètre qui est l'objet "Net::DBus::Binding::Connection" représentant le client.
