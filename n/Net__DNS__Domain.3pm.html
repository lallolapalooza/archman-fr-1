NOM

Net::DNS::Domain - Domaines DNS

SYNTAXE

use Net::DNS::Domain;
$domaine = Net::DNS::Domain->new('example.com');
$nom   = $domaine->name;

DESCRIPTION

Le module Net::DNS::Domain implémente une classe d'objets de domaine DNS abstraits avec des méthodes de classe et d'instance associées.

Chaque instance d'objet de domaine représente un seul domaine DNS qui a une identité fixe tout au long de sa durée de vie.

En interne, la représentation principale est une liste (éventuellement vide) de libellés de noms de domaine ASCII, et un lien optionnel vers un objet de domaine d'origine topologiquement plus proche de la racine DNS.

Les coûts de calcul de la conversion des jeux de caractères Unicode sont partiellement atténués par l'utilisation de caches.

MÉTHODES

new

$objet = Net::DNS::Domain->new('example.com');

Crée un objet de domaine qui représente le domaine DNS spécifié par l'argument chaîne de caractères. L'argument consiste en une séquence de libellés délimités par des points.

Un caractère précédé de \ représente lui-même, sans aucune interprétation spéciale.

Des codes arbitraires de 8 bits peuvent être représentés par \ suivi de exactement trois chiffres décimaux. Les points de code de caractère sont ASCII, indépendamment du schéma de codage de caractères utilisé par la plateforme sous-jacente.

Les littéraux de chaîne d'argument doivent être délimités par des guillemets simples pour éviter que les séquences d'échappement ne soient interprétées comme des codes de caractères octaux par le compilateur Perl.

Le format de présentation de la chaîne de caractères suit les conventions pour les fichiers de zone décrites dans la RFC1035.

Les utilisateurs doivent être conscients que les noms de domaine non ASCII seront transcodés en NFC avant l'encodage, ce qui est un processus irréversible.

name

$nom = $domaine->name;

Retourne le nom de domaine sous forme de chaîne de caractères correspondant à l'"interprétation commune" à laquelle la RFC1034, 3.1, paragraphe 9 fait allusion.

Les séquences d'échappement de caractères sont utilisées pour représenter un point à l'intérieur d'un libellé de nom de domaine et le caractère d'échappement lui-même.

Tout point de code non imprimable est représenté en utilisant la séquence d'échappement numérique appropriée.

fqdn

$fqdn = $domaine->fqdn;

Retourne une chaîne de caractères contenant le nom de domaine pleinement qualifié, y compris le point final.

xname

$xname = $domaine->xname;

Interprète un nom étendu contenant des libellés de noms de domaine Unicode encodés en tant qu'étiquettes A Punycode.

Si le décodage n'est pas possible, le nom encodé ACE est retourné.

label

@label = $domaine->label;

Identifie le domaine au moyen d'une liste de libellés de domaine.

string

$chaine = $objet->string;

Retourne une chaîne de caractères contenant le nom de domaine pleinement qualifié tel qu'il apparaît dans un fichier de zone.

Les caractères qui sont reconnus par la syntaxe des fichiers de zone RFC1035 sont représentés par la séquence d'échappement appropriée.

origin

$create = Net::DNS::Domain->origin( $ORIGIN );
$result = &$create( sub{ Net::DNS::RR->new( 'mx MX 10 a' ); } );
$expect = Net::DNS::RR->new( "mx.$ORIGIN. MX 10 a.$ORIGIN." );

Méthode de classe qui retourne une référence à un wrapper de sous-routine qui exécute un constructeur donné dans un contexte à portée dynamique où les noms relatifs deviennent des descendants de l'$ORIGIN spécifié.

BOGUES

La stratégie de codage est conçue pour éviter la création de listes d'arguments et de cadres de pile inutiles. Cela améliore l'efficacité au détriment de la lisibilité du code.

Les fonctionnalités de codage de caractères spécifiques à la plateforme sont compilées conditionnellement dans le code.
