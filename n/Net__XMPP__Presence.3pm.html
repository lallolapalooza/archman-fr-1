NAME

Net::XMPP::Presence - Module de présence XMPP

SYNOPSIS

Net::XMPP::Presence est un module complémentaire au module Net::XMPP. Il permet aux utilisateurs une interface simple pour définir et récupérer toutes les parties d'une présence XMPP.

DESCRIPTION

Un objet Net::XMPP::Presence est passé à la fonction de rappel pour le message. De plus, le premier argument des fonctions de rappel est l'ID de session provenant de XML::Streams. Quelques cas où vous pourriez vouloir ces informations, comme si vous créiez un client qui se connecte à deux serveurs simultanément, ou pour écrire un mini serveur.

use Net::XMPP;
sub presence {
  my ($sid,$Pres) = @_;
  .
  .
  .
}

Vous avez maintenant accès à toutes les fonctions de récupération disponibles.

Pour créer une nouvelle présence à envoyer au serveur :

use Net::XMPP;
$Pres = Net::XMPP::Presence->new();

Vous pouvez maintenant appeler les fonctions de création ci-dessous pour remplir la balise avant de l'envoyer.

MÉTHODES

Fonctions de récupération

GetTo
GetTo()

renvoie la valeur de l'attribut « to » de la balise <presence/>.

GetTo("jid")

Si vous spécifiez « jid » comme argument, un objet Net::XMPP::JID est retourné et vous pouvez facilement analyser les composants du JID.

$to    = $Pres->GetTo();
$toJID = $Pres->GetTo("jid");
GetFrom
GetFrom()

renvoie la valeur de l'attribut « from » de la balise <presence/>.

GetFrom("jid")

Si vous spécifiez « jid » comme argument, un objet Net::XMPP::JID est retourné et vous pouvez facilement analyser les composants du JID.

$from    = $Pres->GetFrom();
$fromJID = $Pres->GetFrom("jid");
GetType
GetType()

renvoie l'attribut type de la balise <presence/>. Chaque présence est de l'un des sept types suivants :

available       disponible pour recevoir des messages ; valeur par défaut : unavailable
unavailable    indisponible pour recevoir quoi que ce soit
subscribe       demande au destinataire de s'abonner à vous
subscribed      indique à l'expéditeur que vous êtes abonné
unsubscribe    demande au destinataire de se désabonner de vous
unsubscribed   indique à l'expéditeur que vous n'êtes pas abonné
probe           sonde
$type = $Pres->GetType();
GetStatus
GetStatus()

renvoie une chaîne avec l'état actuel de la ressource.

$status = $Pres->GetStatus();
GetPriority
GetPriority()

renvoie un entier indiquant la priorité de la ressource. La valeur par défaut est 0 s'il n'y a pas de priorité dans cette présence.

$priority = $Pres->GetPriority();
GetShow
GetShow()

renvoie une chaîne indiquant l'état que le client doit afficher.

$show = $Pres->GetShow();

Fonctions de création

SetPresence
SetPresence(to=>string|JID    
            from=>string|JID, 
            type=>string,     
            status=>string,   
            priority=>integer,
            meta=>string,     
            icon=>string,     
            show=>string,     
            loc=>string)

définit plusieurs champs dans la balise <presence/> en même temps. Il s'agit d'une action d'écriture cumulative et qui écrase les valeurs précédentes. Si vous spécifiez l'attribut « to » deux fois, le deuxième réglage est utilisé. Si vous définissez le statut, puis la priorité, les deux seront présents dans la balise <presence/>. Pour connaître les valeurs valides, consultez les fonctions de réglage spécifiques.

$Pres->SetPresence(TYPE="away", StatuS="Out for lunch");
SetTo
SetTo(string)
SetTo(JID)

définit l'attribut « to ». Vous pouvez passer une chaîne ou un objet JID. Les deux doivent être des JID valides, sinon le serveur renverra un message d'erreur. (par exemple, bob@jabber.org/Silent Bob, etc...)

$Pres->SetTo("bob\@jabber.org");
SetFrom
SetFrom(string)

définit l'attribut « from ». Vous pouvez passer une chaîne ou un objet JID. Les deux doivent être des JID valides, sinon le serveur renverra un message d'erreur. (par exemple, jabber:bob@jabber.org/Work) Ce champ n'est pas obligatoire si vous écrivez un client, car le serveur placera le JID de votre connexion ici pour éviter le spam.

$Pres->SetFrom("jojo\@jabber.org");
SetType
SetType(string)

définit l'attribut type. Les valeurs valides sont :

available      disponible pour recevoir des messages ; valeur par défaut
unavailable    indisponible pour recevoir quoi que ce soit
subscribe      demande au destinataire de s'abonner à vous
subscribed     indique à l'expéditeur que vous êtes abonné
unsubscribe    demande au destinataire de se désabonner de vous
unsubscribed   indique à l'expéditeur que vous n'êtes pas abonné
probe          sonde
$Pres->SetType("unavailable");
SetStatus
SetStatus(string)

définit l'élément status associé à la ressource avec n'importe quelle chaîne que l'utilisateur souhaite.

$Pres->SetStatus("Taking a nap");
SetPriority
SetPriority(integer)

définit la priorité de cette ressource. La ressource avec la priorité la plus élevée dans le compte XMPP recevra les messages.

$Pres->SetPriority(10);
SetShow
SetShow(string)

définit le nom de l'icône ou la chaîne à afficher pour cette ressource.

$Pres->SetShow("away");
Reply
Reply(hash)

crée un nouvel objet Presence et remplit les champs to/from. Si vous spécifiez un hash, les valeurs seront celles spécifiées dans Reply. Exemple : $Reply = $Pres->Reply(); $Reply = $Pres->Reply(type="subscribed");

$Reply = $Pres->Reply();
$Reply = $Pres->Reply(type="subscribed");

NAME

Net::XMPP::Presence – XMPP presence object

SYNOPSIS

  use Net::XMPP::Presence;

  my $Pres = Net::XMPP::Presence->new( $type, $to, $from, $show, $status, $priority );

DESCRIPTION

Represents a <presence/> element, as defined in XMPP RFC 6121.

METHODS

new
Constructor.
DefinedTo
retourne 1 si l'attribut to est défini dans le <presence/>, 0 sinon. 
$test = $Pres->DefinedTo();
DefinedFrom
retourne 1 si l'attribut from est défini dans le <presence/>, 0 sinon. 
$test = $Pres->DefinedFrom();
DefinedType
retourne 1 si l'attribut type est défini dans le <presence/>, 0 sinon. 
$test = $Pres->DefinedType();
DefinedStatus
retourne 1 si <status/> est défini dans le <presence/>, 0 sinon. 
$test = $Pres->DefinedStatus();
DefinedPriority
retourne 1 si <priority/> est défini dans le <presence/>, 0 sinon. 
$test = $Pres->DefinedPriority();
DefinedShow
retourne 1 si <show/> est défini dans le <presence/>, 0 sinon. 
$test = $Pres->DefinedShow();
