NAME

Net::NNTP - Client NNTP (classe)

SYNOPSIS

use Net::NNTP;
$nntp = Net::NNTP->new("some.host.name");
$nntp->quit;
# démarrer avec SSL, par exemple nntps
$nntp = Net::NNTP->new("some.host.name", SSL => 1);
# démarrer en clair puis passer à SSL
$nntp = Net::NNTP->new("some.host.name");
$nntp->starttls;

DESCRIPTION

« Net::NNTP » est une classe qui implémente un client NNTP simple (tel que décrit dans les RFC977 et RFC4642). Avec IO::Socket::SSL installé, il offre également une prise en charge du chiffrement TLS implicite et explicite, c'est-à-dire NNTPS ou NNTP+STARTTLS.

La classe Net::NNTP est une sous-classe de Net::Cmd et (en fonction de la disponibilité) de IO::Socket::IP, IO::Socket::INET6 ou IO::Socket::INET.

Méthodes de classe

"new([$host][, %options])"
Ceci est le constructeur d'un objet Net::NNTP. $host est le nom d'hôte distant auquel se connecter. S'il n'est pas fourni, il peut être transmis sous forme d'option "Host" décrite ci-dessous. Si aucun hôte n'est fourni, "NNTPSERVER" sera d'abord recherché, puis "NEWSHOST", et s'ils ne sont pas trouvés, "news" sera utilisé.

%options sont passées sous forme de paires clé-valeur. Les options possibles incluent :

Host - L'hôte NNTP auquel se connecter. Il peut s'agir d'un simple scalaire, tel que défini pour la paire "PeerAddr" dans IO::Socket::INET, ou d'une référence à un tableau d'hôtes à essayer dans l'ordre. La méthode "host" renverra la valeur utilisée pour se connecter à l'hôte.

Port - Le port auquel se connecter. Par défaut, 119 pour NNTP en clair et 563 pour une connexion SSL immédiate (nntps).

SSL - Si la connexion doit être initiée avec SSL, au lieu de passer à SSL plus tard avec "starttls". Les arguments SSL tels que documentés dans IO::Socket::SSL peuvent être utilisés, mais les arguments corrects seront généralement déjà présents.

Timeout - Temps maximum en secondes pour attendre une réponse du serveur NNTP. Une valeur de zéro provoquera le blocage de toutes les opérations d'E/S. (valeur par défaut : 120)

Debug - Activer l'impression d'informations de débogage sur STDERR.

Reader - Si le serveur distant est INN, la connexion se connectera initialement à innd, par défaut "Net::NNTP" enverra une commande "MODE READER" afin que le serveur distant passe à nnrpd. Si la paire "Reader" est passée avec une valeur de zéro, cette commande ne sera pas envoyée et la connexion restera connectée à innd.

LocalAddr et LocalPort - Ces paramètres sont passés directement à IO::Socket pour permettre l'association du socket à un port local spécifique.

Domain - Ce paramètre est passé directement à IO::Socket et permet de forcer les connexions IPv4 même si IO::Socket::IP est utilisé comme superclasse. Alternativement, Family peut être utilisé.

Méthodes d'objet

Sauf indication contraire, toutes les méthodes renvoient une valeur vraie ou fausse, la valeur vraie indiquant que l'opération a réussi. Lorsqu'une méthode indique qu'elle renvoie une valeur, un échec sera renvoyé sous forme d'undef ou d'une liste vide.

"Net::NNTP" hérite de "Net::Cmd", de sorte que les méthodes définies dans "Net::Cmd" peuvent être utilisées pour envoyer des commandes au serveur NNTP en plus des méthodes documentées ici.

host()
Renvoie la valeur utilisée par le constructeur, et passée à IO::Socket::INET, pour se connecter à l'hôte.
starttls()
Met à niveau la connexion existante en clair vers SSL. Tout argument nécessaire pour SSL doit déjà être fourni dans "new".
"article([{$msgid|$msgnum}[, $fh]])"
Récupère l'en-tête, une ligne vide, puis le corps (texte) de l'article spécifié. Si $fh est spécifié, il est supposé être un descripteur de fichier valide et le résultat y sera imprimé ; en cas de succès, une valeur vraie est renvoyée. Si $fh n'est pas spécifié, la valeur renvoyée, en cas de succès, sera un tableau contenant l'article demandé, chaque entrée du tableau contenant une ligne de l'article.

Si aucun argument n'est passé, l'article courant du groupe actuellement sélectionné est récupéré.

$msgnum est un identifiant numérique d'un article dans le groupe actuel, et il déplace le pointeur vers l'article courant. $msgid est l'identifiant de l'article tel qu'affiché dans l'en-tête de l'article. Le client est censé obtenir le $msgid à partir d'une liste fournie par la commande "newnews", à partir des références contenues dans un autre article, ou à partir de l'identifiant du message dans la réponse à une autre commande.

En cas d'erreur, undef est renvoyé.

La commande "body" ne récupère que le corps de l'article.
La commande "head" ne récupère que les en-têtes de l'article.
Ceux-ci sont similaires à article(), body() et head(), mais au lieu de renvoyer directement les données demandées, ils renvoient un descripteur de fichier ouvert lié via un objet tied.
"nntpstat" est similaire à la commande "article", mais ne renvoie pas de texte. Lorsqu'il est sélectionné par numéro de message dans un groupe, la commande "nntpstat" est utilisée pour définir le pointeur sur l'article actuel sans renvoyer de texte.

L'utilisation de la commande "nntpstat" pour sélectionner par identifiant de message est valide mais de valeur incertaine, car une sélection par identifiant de message ne modifie pas le pointeur sur l'article actuel.

Renvoie l'identifiant de l'article actuel.

"group" ([$group])
Définit et/ou obtient le groupe actuel. Si $group n'est pas spécifié, des informations sur le groupe actuel sont renvoyées.

Dans un contexte scalaire, renvoie le nom du groupe.

Dans un contexte de tableau, la valeur renvoyée est une liste contenant : le nombre d'articles dans le groupe, le numéro du premier article, le numéro du dernier article et le nom du groupe.

"help"
Demande du texte d'aide (résumé des commandes comprises par cette implémentation) du serveur. Renvoie le texte ou undef en cas d'échec.
"ihave" ([$msgid[, $message])
La commande "ihave" informe le serveur que le client possède un article dont l'identifiant est $msgid. Si le serveur souhaite une copie de cet article et que $message a été fourni, il sera envoyé. S'il est spécifié, renvoie vrai si le serveur souhaite l'article et que $message a été envoyé avec succès.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

Si $message n'est pas spécifié, alors le message doit être envoyé en utilisant les méthodes "datasend" et "dataend" de Net::Cmd

$message peut être soit un tableau de lignes, soit une référence à un tableau et doit être encodé par l'appelant en octets de l'encodage requis, par exemple en utilisant la fonction encode() du module Encode.

last()
Définit le "pointeur d'article courant" à l'article précédent du groupe de nouvelles actuel.

Retourne l'identifiant du message de l'article.

date()
Retourne la date sur le serveur distant. Cette date sera au format temporel UNIX (secondes depuis 1970).
postok()
"postok" retournera *vrai* si la réponse initiale du serveur a indiqué qu'il autoriserait la publication.
"authinfo($user, $pass)"
S'authentifie auprès du serveur (en utilisant la forme originale AUTHINFO USER / AUTHINFO PASS, définie dans la RFC2980) avec le nom d'utilisateur et le mot de passe fournis. Veuillez noter que le mot de passe est envoyé en texte clair au serveur. Cette commande ne doit pas être utilisée avec des mots de passe précieux, sauf si la connexion au serveur est protégée d'une manière ou d'une autre.
"authinfo_simple($user, $pass)"
S'authentifie auprès du serveur (en utilisant la forme proposée NNTP V2 AUTHINFO SIMPLE, définie et dépréciée dans la RFC2980) avec le nom d'utilisateur et le mot de passe fournis. Comme avec "authinfo", le mot de passe est envoyé en texte clair.
list()
Obtient des informations sur tous les groupes de nouvelles actifs. Le résultat est une référence à une table de hachage où la clé est un nom de groupe et chaque valeur est une référence à un tableau. Les éléments de ce tableau sont : le dernier numéro d'article dans le groupe, le premier numéro d'article dans le groupe et tous les indicateurs d'information sur le groupe.
"newgroups($since[, $distributions])"
$since est une valeur temporelle et $distributions est soit un modèle de distribution, soit une référence à une liste de modèles de distribution. Le résultat est le même que "list", mais les groupes retournés seront limités à ceux créés après $since et, si spécifié, dans l'une des zones de distribution de $distributions.
"newnews($since[, $groups[, $distributions]])"
$since est une valeur temporelle. $groups est soit un modèle de groupe, soit une référence à une liste de modèles de groupe. $distributions est soit un modèle de distribution, soit une référence à une liste de modèles de distribution.

Retourne une référence à une liste contenant les identifiants de message de toutes les nouvelles publiées après $since, qui se trouvent dans des groupes correspondant à $groups et une distribution correspondant à $distributions.

next()
Définit le "pointeur d'article courant" à l'article suivant du groupe de nouvelles actuel.

Retourne l'identifiant du message de l'article.

post([$message])
Publie un nouvel article sur le serveur de nouvelles. Si $message est spécifié et que la publication est autorisée, le message sera envoyé.

Si $message n'est pas spécifié, alors le message doit être envoyé en utilisant les méthodes "datasend" et "dataend" de Net::Cmd

$message peut être soit un tableau de lignes, soit une référence à un tableau et doit être encodé par l'appelant en octets de l'encodage requis, par exemple en utilisant la fonction encode() du module Encode.

Le message, envoyé via "datasend" ou en tant que paramètre $message, doit être au format décrit par la RFC822 et doit contenir les en-têtes From:, Newsgroups: et Subject:.

postfh()
Publie un nouvel article sur le serveur de nouvelles en utilisant un descripteur de fichier lié. Si la publication est autorisée, cette méthode retournera un descripteur de fichier lié auquel vous pourrez imprimer() le contenu de l'article à publier. Vous devez explicitement fermer() le descripteur de fichier lorsque vous avez terminé la publication de l'article, et la valeur de retour de l'appel close() indiquera si le message a été publié avec succès.
slave()
Indique au serveur distant que je ne suis pas un client utilisateur, mais probablement un autre serveur de nouvelles.
quit()
Quitte le serveur distant et ferme la connexion socket.
can_inet6()
Retourne si nous pouvons utiliser IPv6.
can_ssl()
Retourne si nous pouvons utiliser SSL.

Méthodes d'extension

Ces méthodes utilisent des commandes qui ne font pas partie de la documentation RFC977. Certains serveurs peuvent ne pas toutes les supporter.

newsgroups([$pattern])
Retourne une référence à une table de hachage où les clés sont tous les noms de groupes correspondant à $pattern, ou tous les groupes si aucun modèle n'est spécifié, et chaque valeur contient le texte descriptif du groupe.
distributions()
Retourne une référence à une table de hachage où les clés sont tous les noms de distribution possibles et les valeurs sont les descriptions de distribution.
distribution_patterns()
Retourne une référence à un tableau où chaque élément, lui-même une référence de tableau, se compose des trois champs d'une ligne de la liste distrib.pats maintenue par certains serveurs NNTP, à savoir : un poids, un wildmat et une valeur que le client peut utiliser pour construire un en-tête Distribution.
subscriptions()
Retourne une référence à une liste contenant une liste de groupes recommandés pour qu'un nouvel utilisateur s'y abonne.
overview_fmt()
Retourne une référence à un tableau contenant les noms des champs retournés par "xover".
active_times()
Retourne une référence à une table de hachage où les clés sont les noms de groupes et chaque valeur est une référence à un tableau contenant l'heure de création des groupes et un identifiant, éventuellement une adresse e-mail, du créateur.
active([$pattern])
Similaire à "list" mais seuls les groupes actifs correspondant au modèle sont retournés. $pattern peut être un modèle de groupe.
xgtitle($pattern)
Retourne une référence à une table de hachage où les clés sont tous les noms de groupes correspondant à $pattern et chaque valeur est le texte descriptif du groupe.
"xhdr($header, $message_spec)"
Obtient le champ d'en-tête $header pour tous les messages spécifiés.

La valeur de retour sera une référence à une table de hachage où les clés sont les numéros de message et chaque valeur contient le texte de l'en-tête demandé pour ce message.

xover($message_spec)
La valeur de retour sera une référence à une table de hachage où les clés sont les numéros de message et chaque valeur contient une référence à un tableau contenant les champs de survol pour ce message.

Les noms des champs peuvent être obtenus en appelant "overview_fmt".

xpath($message_id)
Retourne le nom du chemin d'accès au fichier sur le serveur qui contient le message spécifié.
"xpat($header, $pattern, $message_spec)"
Le résultat est le même que "xhdr" sauf que la restriction sera appliquée aux en-têtes dont le texte correspond à $pattern.
xrover($message_spec)
La commande XROVER retourne des informations de référence pour les articles spécifiés.

Retourne une référence à une TABLE DE HACHAGE où les clés sont les numéros de message et les valeurs sont les lignes References : des articles.

listgroup([$group])
Retourne une référence à une liste de tous les messages actifs dans $group, ou dans le groupe actuel si $group n'est pas spécifié.
reader()
Indique au serveur que je suis un lecteur et non un autre serveur.

Ceci est requis par certains serveurs. Par exemple, si vous vous connectez à un serveur INN et que vous avez des permissions de transfert, votre connexion sera connectée au démon de transfert, pas au démon NNTP. L'émission de cette commande fera en sorte que le démon de transfert cède le contrôle au démon NNTP.

Certains serveurs ne comprennent pas cette commande, mais son émission et l'ignorance de la réponse sont sans danger.

Non pris en charge

Les commandes NNTP suivantes ne sont pas prises en charge par le package, et il n'est pas prévu de le faire.

AUTHINFO GENERIC
XTHREAD
XSEARCH
XINDEX

Net::NNTP(3perl)

NAME

Net::NNTP - Perl interface to the NNTP protocol

SYNOPSIS

    use Net::NNTP;

    # Create an object
    $obj = Net::NNTP->new($host, Debug => 1);
    $obj->connect($host);

    # Choose a group
    $obj->group($group);

    # Get article
    ($first, $last) = $obj->newnews($group);
    $obj->help();

    # ... more commands ...

    $obj->quit();

DESCRIPTION

The Net::NNTP module provides an object oriented interface to the NNTP protocol.

The module is used to implement clients for the NNTP protocol. For a full list of commands see the NNTP protocol specification RFC 977.

There are a couple of methods that are worth mentioning here.

$message_spec
A message specification is a range of messages. It can be specified as a single message number or as a list of two numbers, the first and the last message in the group. When the two numbers are equal to the first then the range represents all messages in the group after the first message number.
NOTE
For compatibility reasons only with earlier versions of Net::NNTP a message spec can be passed as a list of two numbers, this is deprecated and a reference to the list should now be passed
$pattern
The "NNTP" protocol uses the "WILDMAT" format for patterns. The WILDMAT format was first developed by Rich Salz based on the format used in the UNIX "find" command to articulate file names. It was developed to provide a uniform mechanism for matching patterns in the same manner that the UNIX shell matches filenames.

Patterns are implicitly anchored at the beginning and end of each string when testing for a match.

There are five pattern matching operations other than a strict one-to-one match between the pattern and the source to be checked for a match.

The first is an asterisk "*" to match any sequence of zero or more characters.

The second is a question mark "?" to match any single character. The third specifies a specific set of characters.

The set is specified as a list of characters, or as a range of characters where the beginning and end of the range are separated by a minus (or dash) character, or as any combination of lists and ranges. The dash can also be included in the set as a character it if is the beginning or end of the set. This set is enclosed in square brackets. The close square bracket "]" may be used in a set if it is the first character in the set.

The fourth operation is the same as the logical not of the third operation and is specified the same way as the third with the addition of a caret character "^" at the beginning of the test string just inside the open square bracket.

The final operation uses the backslash character to invalidate the special meaning of an open square bracket "[", the asterisk, backslash or the question mark. Two backslashes in sequence will result in the evaluation of the backslash as a character with no special meaning.

Examples
"[^]-]"
matches any single character other than a close square bracket or a minus sign/dash.
*bdc
matches any string that ends with the string "bdc" including the string "bdc" (without quotes).
"[0-9a-zA-Z]"
matches any single printable alphanumeric ASCII character.
"a??d"
matches any four character string which begins with a and ends with d.
