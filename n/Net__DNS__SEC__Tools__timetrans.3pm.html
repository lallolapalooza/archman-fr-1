NOM

Net::DNS::SEC::Tools::timetrans - Convertit un nombre entier de secondes en unités textuelles.

SYNTAXE

use Net::DNS::SEC::Tools::timetrans;
$timestring = timetrans(86488);
$timestring = fuzzytimetrans(86488);

DESCRIPTION

L'interface timetrans() dans Net::DNS::SEC::Tools::timetrans convertit un nombre entier de secondes en un nombre équivalent de jours, heures et minutes. Le temps converti est un temps relatif, **pas** un temps absolu. Le temps retourné est exprimé en jours, heures, minutes et secondes, selon ce qui est nécessaire pour exprimer correctement le nombre de secondes.

L'interface fuzzytimetrans() convertit un nombre entier de secondes en un nombre équivalent de semaines **ou** de jours **ou** d'heures **ou** de minutes. L'unité choisie est celle qui est la plus naturelle pour le nombre de secondes. Une décimale de précision est incluse dans le résultat.

INTERFACES

Les interfaces du module Net::DNS::SEC::Tools::timetrans sont présentées ci-dessous.

timetrans()

Cette routine convertit un nombre entier de secondes en un nombre équivalent de jours, heures et minutes. Ce nombre de secondes converti est retourné sous forme de chaîne de caractères. Le nombre de secondes doit être supérieur à zéro, sinon une erreur sera retournée.

Valeurs de retour :

Si un nombre de secondes valide a été donné, le compte converti dans la
    chaîne de caractères appropriée sera retourné.
Une chaîne vide est retournée si aucun nombre de secondes n'a été donné ou si
    le nombre de secondes est inférieur à un.

fuzzytimetrans()

Cette routine convertit un nombre entier de secondes en un nombre équivalent de semaines, jours, heures ou minutes. Ce nombre de secondes converti est retourné sous forme de chaîne de caractères. Le nombre de secondes doit être supérieur à zéro, sinon une erreur sera retournée.

Valeurs de retour :

Si un nombre de secondes valide a été donné, le compte converti dans la
    chaîne de caractères appropriée sera retourné.
Une chaîne vide est retournée si aucun nombre de secondes n'a été donné ou si
    le nombre de secondes est inférieur à un.

EXEMPLES

timetrans(400) retourne 6 minutes, 40 secondes

timetrans(420) retourne 7 minutes

timetrans(888) retourne 14 minutes, 48 secondes

timetrans(86400) retourne 1 jour

timetrans(86488) retourne 1 jour, 28 secondes

timetrans(715000) retourne 8 jours, 6 heures, 36 minutes, 40 secondes

timetrans(720000) retourne 8 jours, 8 heures

fuzzytimetrans(400) retourne 6.7 minutes

fuzzytimetrans(420) retourne 7.0 minutes

fuzzytimetrans(888) retourne 14.8 minutes

fuzzytimetrans(86400) retourne 1.0 jour

fuzzytimetrans(86488) retourne 1.0 jour

fuzzytimetrans(715000) retourne 1.2 semaines

fuzzytimetrans(720000) retourne 1.2 semaines
