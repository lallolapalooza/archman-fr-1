NOM

Net::IPv6Addr - Vérifier et manipuler les adresses IPv6

VERSION

Ce document couvre la version 1.02 de Net::IPv6Addr correspondant au commit git f9065cb7b044da442df16443d65593a5a3fc6baa https://github.com/benkasminbullock/net-ipv6addr/commit/f9065cb7b044da442df16443d65593a5a3fc6baa publié le mer 31 mars 11:11:47 2021 +0900.

SYNOPSIS

use Net::IPv6Addr;
my $addr = "dead:beef:cafe:babe::f0ad";
Net::IPv6Addr::ipv6_parse($addr);
my $x = Net::IPv6Addr->new($addr);
print $x->to_string_preferred(), "\n";

produit la sortie

dead:beef:cafe:babe:0:0:0:f0ad

(Cet exemple est inclus sous le nom de synopsis.pl https://fastapi.metacpan.org/source/BKB/Net-IPv6Addr-1.02/examples/synopsis.pl dans la distribution.)

DESCRIPTION

"Net::IPv6Addr" vérifie si les chaînes contiennent des adresses IPv6 valides et convertit les adresses IPv6 en divers formats.

Toutes les fonctions "new", "is_ipv6" et "ipv6_parse" peuvent traiter les formats suivants :

Forme préférée : x:x:x:x:x:x:x:x
"2001:db8:0:0:0:ff00:42:8329"

C'est la forme décrite comme la "forme préférée" dans la section 2.2 de "RFC1884" et al. Sortie avec "to_string_preferred".

Forme compressée avec double point : x::x etc.
"2001:db8::ff00:42:8329"

C'est le "format de représentation textuelle canonique" de "RFC5952". Sortie avec "to_string_compressed".

Format mixte IPv4/IPv6 : x:x:x:x:x:x:d.d.d.d
"2001:db8:0:0:0:ff00:0.66.131.41"

Sortie avec "to_string_ipv4".

Mixte IPv4/IPv6 avec compression : x::x:d.d.d.d, etc.
"2001:db8::ff00:0.66.131.41"

Sortie avec "to_string_ipv4_compressed".

Grands entiers
Une adresse IPv6 peut être convertie en objet Math::BigInt ou en chaîne de chiffres en utilisant "to_bigint". Les grands entiers peuvent également être saisis avec "from_bigint".
Encodé en Base-85 : [0-9A-Za-z!#$%&()*+;<=>?@^_`{|}~-]{20}
"9R}vSQ9RqiCvG6zn?Zyh"

Cet encodage a été donné dans "RFC1924" comme une blague du premier avril. Sortie avec "to_string_base85".

De plus, les formats suivants peuvent être produits :

Tableaux
Une adresse IPv6 peut être décomposée en ses éléments constitutifs avec "to_array" ou "to_intarray".
Pointeur d'adresse inverse
Une adresse IPv6 peut être traitée en son pointeur d'adresse inverse, tel que défini par "RFC1886", en utilisant "to_string_ip6_int".

MÉTHODES ET FONCTIONS

Les méthodes et fonctions sont listées par ordre alphabétique. Toutes, sauf "new", servent à la fois de méthodes d'objet et de fonctions autonomes.

from_bigint

use Net::IPv6Addr 'from_bigint';
print from_bigint ('12345678901234567890')->to_string_compressed ();

produit la sortie

::ab54:a98c:eb1f:ad2

(Cet exemple est inclus sous le nom de from-bigint.pl https://fastapi.metacpan.org/source/BKB/Net-IPv6Addr-1.02/examples/from-bigint.pl dans la distribution.)

Étant donné une chaîne ou un objet Math::BigInt contenant un nombre, cela le convertit en un objet Net::IPv6Addr.

Paramètres

Une chaîne ou un objet Math::BigInt. Si l'entrée est un scalaire, elle est convertie en un objet Math::BigInt.

Retourne

Un objet Net::IPv6Addr

Notes

Une entrée invalide générera une exception.

Cette fonction a été ajoutée dans la version "0.95".

in_network

use Net::IPv6Addr;
my $obj = Net::IPv6Addr->new ('dead:beef:cafe:babe:dead:beef:cafe:babe');
if ($obj->in_network ('dead:beef:ca0::/21')) {
    print $obj->to_string_compressed, " est dans le réseau.\n";
}

produit la sortie

dead:beef:cafe:babe:dead:beef:cafe:babe est dans le réseau.

(Cet exemple est inclus sous le nom de inet.pl https://fastapi.metacpan.org/source/BKB/Net-IPv6Addr-1.02/examples/inet.pl dans la distribution.)

Paramètres

Utilisé comme méthode d'objet, un réseau et sa taille en bits

my $ok = $x->in_network ("aa:bb:cc:dd::", 64);

Utilisé comme sous-routine, une chaîne d'adresse IPv6 dans n'importe quel format, suivie d'une chaîne d'adresse réseau et de sa taille en bits.

my $addr = 'fd00::54:20c:29fe:fe14:ab4b';
my $ok = Net::IPv6Addr::in_network ($addr, "aa:bb:cc:dd::", 64);

La taille du réseau peut également être indiquée avec la notation / après la chaîne de l'adresse réseau :

my $ok = $x->in_network("aa:bb:cc:dd::/64");

Retourne

Une valeur vraie si l'adresse $x est membre du réseau donné en argument, ou faux sinon.

Notes

Une entrée invalide générera une exception.

Avant la version "0.9", cela ne fonctionnait pas correctement à moins que la taille du réseau ne soit un multiple de seize.

in_network_of_size

use Net::IPv6Addr 'in_network_of_size';
my $obj = in_network_of_size ('dead:beef:cafe:babe:dead:beef:cafe:babe', 42);
print $obj->to_string_compressed ();

produit la sortie

dead:beef:cac0::

(Cet exemple est inclus sous le nom de inos.pl https://fastapi.metacpan.org/source/BKB/Net-IPv6Addr-1.02/examples/inos.pl dans la distribution.)

Étant donné une adresse IPv6 d'entrée $x, cela renvoie les $n bits les plus significatifs de $x sous forme de nouvel objet Net::IPv6Addr.

Paramètres

Utilisé comme méthode d'objet, taille du réseau en bits :

my $obj = $x->in_network_of_size (64);

Utilisé comme sous-routine, une chaîne d'adresse IPv6 dans n'importe quel format et une taille de réseau en bits :

my $obj = in_network_of_size ($addr, 64);

La taille du réseau peut également être indiquée avec la notation "/" :

my $obj = in_network_of_size ("$addr/64");

Retourne

Les $n bits les plus significatifs de $x sous forme de nouvel objet Net::IPv6Addr.

Notes

Une entrée invalide générera une exception.

Avant la version "0.9", cela ne fonctionnait pas correctement à moins que la taille du réseau ne soit un multiple de seize.

ipv6_chkip

my $niok = ipv6_chkip ('dead:beef:cafe:babe::f0ad');

Paramètres

Une chaîne d'adresse IPv6, sans préfixe.

Retourne

Une valeur vraie (une référence de code pour l'analyseur de cet IP) si c'est une adresse valide ; une valeur fausse ("undef") sinon.

ipv6_parse

my ($ni, $pl) = ipv6_parse ('dead:beef:cafe:babe::f0ad');

Paramètres

Soit une chaîne contenant une adresse IPv6 strin

is_ipv6

my $niok = is_ipv6 ('dead:beef:cafe:babe::f0ad');

Paramètres

Identiques à "ipv6_parse".

Retourne

Ceci retourne la valeur de retour de "ipv6_parse", appelée dans un contexte scalaire, si le parsage réussit, sinon retourne "undef". Contrairement à "ipv6_parse", "is_ipv6" ne lève pas d'exception.

new

Crée un objet Net::IPv6Addr à partir d'une chaîne. Internement, l'objet est une référence à un tableau simple avec les huit éléments de l'adresse sous forme d'entiers.

Paramètres

Retourne

Un objet "Net::IPv6Addr" si l'opération réussit.

Notes

Lève une exception si la chaîne n'est pas une adresse valide.

RFCs

Les RFC (Request For Comments, documentation des standards Internet) suivantes contiennent des informations sur IPv6.

Série d'architecture d'adressage

Ce sont toutes le même standard, avec des mises à jour. La plus récente est la version active.

RFC1884 <https://www.rfc-editor.org/rfc/rfc1884.txt>
IPv6 Addressing Architecture - Décembre 1995
RFC2373 <https://www.rfc-editor.org/rfc/rfc2373.txt>
IP Version 6 Addressing Architecture - Juillet 1998
RFC3513 <https://www.rfc-editor.org/rfc/rfc3513.txt>
Internet Protocol Version 6 (IPv6) Addressing Architecture - Avril 2003
RFC4291 <https://www.rfc-editor.org/rfc/rfc4291.txt>
IP Version 6 Addressing Architecture - Février 2006

Autres

RFC1886 <https://www.rfc-editor.org/rfc/rfc1886.txt>
DNS Extensions to support IP version 6 - Décembre 1995
RFC1924 <https://www.rfc-editor.org/rfc/rfc1924.txt>
A Compact Representation of IPv6 Addresses - 1er Avril 1996

C'était une blague du 1er avril.

RFC5952 <https://www.rfc-editor.org/rfc/rfc5952.txt>
A Recommendation for IPv6 Address Text Representation - Août 2010

Ceci contient une "recommandation pour un format de représentation textuelle canonique des adresses IPv6" qui correspond à la sortie de "to_string_compressed" dans ce module.

Les liens mènent aux versions en texte brut en ligne des RFC.

Autres modules CPAN

Il existe un très grand nombre de modules CPAN qui traitent des adresses IPv6. La liste suivante donne tous ceux que je connais qui chevauchent ce module, par ordre alphabétique.

Data::Validate::IP
Ce module utilise Socket pour valider les adresses IP. Il offre un certain nombre de facilités pour les sous-réseaux à usage spécial, comme "is_discard_ipv6", qui ne sont pas offertes dans Net::IPv6Addr.
IPv6::Address
Sa description dit "Une bibliothèque de manipulation d'adresses IPv6 pure Perl. L'accent est mis sur la manipulation des préfixes et des adresses."

Il insiste sur la présence d'un préfixe avec l'adresse IP, donc

my $ipv6 = IPv6::Address->new ('2001:0:0:1:0:0:0:1');

échoue réellement, vous devez utiliser

my $ipv6 = IPv6::Address->new ('2001:0:0:1:0:0:0:1/64');
Net::IP
Gère les IP binaires (chaînes comme '101001'), etc.
Net::IP::Minimal
C'est une version simplifiée de "Net::IP".
Net::IPAddress::Util
C'est une "Représentation de l'adresse IP indépendante de la version". Je n'ai pas essayé ce module.
Net::IPv6Address
Ce module est défectueux et fortement déconseillé.
NetAddr::IP
NetAddr::IP::Lite
Ce sont deux choses dans la même distribution. La documentation est assez rébarbative, mais il y a beaucoup d'utilisateurs du module et des étoiles sur metacpan.
Regexp::IPv6
Ce module consiste en une regex pour valider les IPv6. Comme ce module avait beaucoup plus et de meilleurs tests que Net::IPv6Addr, j'ai inclus les tests et une regex de "Regexp::IPv6" dans ce module. (Voir t/Regexp-IPv6.t https://fastapi.metacpan.org/source/BKB/Net-IPv6Addr-1.02/t/Regexp-IPv6.t) Contrairement à "Net::IPv6Addr", "Regexp::IPv6" interdit "::", "les adresses non spécifiées". Voir la documentation du module pour plus de détails.

Autre

Validateur en ligne
https://www.helpsystems.com/intermapper/ipv6-test-address-validation

HISTORIQUE

Ce module a été initialement écrit par Tony Monroe en 2001 pour simplifier la tâche de maintenance des enregistrements DNS après s'être mis en place avec Freenet6.

En 2017, le module a été adopté par Ben Bullock avec l'aide de Neil Bowers dans le cadre du "CPAN day". Les changements importants apportés au module depuis lors incluent les suivants :

1.02
Dépendance de Net::IPv4Addr supprimée. Ce module souffrait du "bug octal". Ce module n'était utilisé que pour valider les adresses ipv4 et a été facile à supprimer.

Dépendance de Math::Base85 supprimée. Ce module n'est nécessaire que pour prendre en charge la méthode des adresses IPv6 de la blague du 1er avril, donc si l'utilisateur n'a pas déjà Math::Base85, le module désactive maintenant la prise en charge des adresses du 1er avril.

1.0
La vérification des adresses et préfixes en base 85 a été rendue plus stricte en réponse aux plaintes des utilisateurs.
0.95
La méthode "from_bigint" a été ajoutée et la documentation mise à jour pour refléter les normes Internet actuelles.

La restriction sur les entrées d'adresses mixtes supprimée dans "0.92" a également été supprimée dans les routines de sortie "to_string_ipv4" et "to_string_ipv4_compressed".

0.92
Le format valide composé d'un IPv6 compressé mais non nul à six éléments suivi d'un IPv4, tel que "fe80::204:61ff:254.157.241.86", est accepté par le module.
0.9
"in_network" et "in_network_of_size" ont été corrigés pour permettre plus de types de préfixes.
0.8
L'exportation de certaines fonctions a été ajoutée. Avant cela, tout devait être fait en qualifié complet, comme dans "Net::IPv6Addr::to_string_compressed".

NOM

Net::IPv6Addr - Manipulation des adresses IPv6

VERSION

Version 1.100

SYNOPSIS

use Net::IPv6Addr;

my $ip = Net::IPv6Addr->new("2001:db8::1");
print $ip->string(); # Prints "2001:db8::1"

if ($ip->is_ipv6) { ... }

my $mask = Net::IPv6Addr::netmask(64);
my $network = $ip->and($mask);

my $broadcast = $ip->broadcast();

DESCRIPTION

Le module Net::IPv6Addr fournit une interface orientée objet pour la manipulation des adresses IPv6. Il permet de créer, de valider, de manipuler et de comparer des adresses IPv6.

MÉTHODES ET FONCTIONS

Net::IPv6Addr->new( $ip_string )
Crée un nouvel objet Net::IPv6Addr à partir d'une chaîne représentant une adresse IPv6.
$ip->string()
Retourne la représentation sous forme de chaîne de l'adresse IPv6.
$ip->is_ipv6()
Retourne vrai si l'adresse est une adresse IPv6 valide.
Net::IPv6Addr::netmask( $prefix_length )
Retourne un objet Net::IPv6Addr représentant le masque de sous-réseau pour la longueur de préfixe donnée.
$ip->and( $mask )
Effectue une opération ET bit à bit entre l'adresse IP et le masque.
$ip->broadcast()
Retourne l'adresse de diffusion pour le réseau auquel l'adresse IP appartient (nécessite que le masque soit défini).

EXPORTATIONS

Ce module n'exporte rien par défaut.

DÉPENDANCES

Aucune dépendance externe.
