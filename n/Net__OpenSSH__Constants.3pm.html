NOM

Net::OpenSSH::Constants - Définitions des constantes pour Net::OpenSSH

SYNTAXE

use Net::OpenSSH::Constants qw(:error);

DESCRIPTION

Ce module exporte les constantes suivantes :

:error
OSSH_MASTER_FAILED - une erreur s'est produite concernant la connexion SSH maître
OSSH_SLAVE_FAILED - une erreur s'est produite concernant une connexion SSH esclave
OSSH_SLAVE_PIPE_FAILED - impossible de créer un tuyau pour communiquer avec le processus esclave
OSSH_SLAVE_TIMEOUT - délai d'attente du processus esclave dépassé
OSSH_SLAVE_CMD_FAILED - le processus enfant s'est terminé avec un statut non nul
OSSH_SLAVE_SFTP_FAILED - la création du client SFTP a échoué
OSSH_ENCODING_ERROR - une erreur s'est produite concernant l'encodage/décodage des chaînes
