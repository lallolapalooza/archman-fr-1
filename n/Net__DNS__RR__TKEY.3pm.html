NOM

Net::DNS::RR::TKEY - Enregistrement de ressource TKEY DNS

SYNTAXE

use Net::DNS;
$rr = new Net::DNS::RR('example.com IN TKEY ... ');

DESCRIPTION

Classe pour les enregistrements de ressource TSIG Key (TKEY) DNS.

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées des méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités non documentées du package ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

algorithme

$algorithme = $rr->algorithm;
$rr->algorithm( $algorithme );

Le nom de l'algorithme est sous la forme d'un nom de domaine ayant la même signification qu'en [RFC 2845]. L'algorithme détermine comment le matériel de clé secrète convenu en utilisant l'enregistrement TKEY est réellement utilisé pour dériver la clé spécifique à l'algorithme.

inception

$inception = $rr->inception;
$rr->inception( $inception );

Heure exprimée en nombre de secondes non bissextiles modulo 2**32 depuis le début de janvier 1970 GMT.

expiration

$expiration = $rr->expiration;
$rr->expiration( $expiration );

Heure exprimée en nombre de secondes non bissextiles modulo 2**32 depuis le début de janvier 1970 GMT.

mode

$mode = $rr->mode;
$rr->mode( $mode );

Le champ mode spécifie le schéma général d'accord de clé ou le but du message DNS TKEY, tel que défini dans [RFC2930(2.5)].

erreur

$erreur = $rr->error;
$rr->error( $erreur );

Le champ code d'erreur est un RCODE étendu.

clé

$clé = $rr->key;
$rr->key( $clé );

Séquence d'octets représentant les données d'échange de clé. La signification de ces données dépend du mode.

autre

$autre = $rr->other;
$rr->other( $autre );

Contenu non défini dans la spécification [RFC2930] mais qui peut être utilisé dans de futures extensions.
