NOM

Net::DBus::Binding::Iterator - Lecture et écriture des paramètres de message

SYNTAXE

Création d'un nouveau message

my $msg = new Net::DBus::Binding::Message::Signal;
my $iterator = $msg->iterator;
$iterator->append_boolean(1);
$iterator->append_byte(123);

Lecture d'un message

my $msg = ...get it from somewhere...
my $iter = $msg->iterator();
my $i = 0;
while ($iter->has_next()) {
  $iter->next();
  $i++;
  if ($i == 1) {
     my $val = $iter->get_boolean();
  } elsif ($i == 2) {
     my $val = $iter->get_byte();
  }
}

DESCRIPTION

Fournit un itérateur pour lire ou écrire les champs d'un message. Cette librairie fournit une API Perl pour accéder aux méthodes dbus_message_iter_XXX de l'API C. Les types array et dictionary ne sont pas encore pris en charge et il y a des bugs dans la prise en charge de Quad (c'est-à-dire qu'il renvoie toujours -1 !).

MÉTHODES

$res = $iter->has_next()
Vérifie s'il y a d'autres champs dans l'itérateur de message à lire. Renvoie une valeur positive s'il y a d'autres champs, zéro sinon.
$success = $iter->next()
Avance l'itérateur au champ suivant du message. Renvoie une valeur positive si le pointeur actuel a été avancé avec succès, zéro sinon.
my $val = $iter->get_boolean()
$iter->append_boolean($val);
Lit ou écrit une valeur booléenne depuis/vers l'itérateur de message.
my $val = $iter->get_byte()
$iter->append_byte($val);
Lit ou écrit une valeur d'octet depuis/vers l'itérateur de message.
my $val = $iter->get_string()
$iter->append_string($val);
Lit ou écrit une valeur de chaîne de caractères depuis/vers l'itérateur de message (au format UTF-8).
my $val = $iter->get_object_path()
$iter->append_object_path($val);
Lit ou écrit une valeur de chemin d'objet depuis/vers l'itérateur de message (au format UTF-8), dont le contenu est un chemin d'objet valide.
my $val = $iter->get_signature()
$iter->append_signature($val);
Lit ou écrit une valeur de signature de type depuis/vers l'itérateur de message (dont le contenu est une signature de type valide).
my $val = $iter->get_int16()
$iter->append_int16($val);
Lit ou écrit une valeur signée de 16 bits depuis/vers l'itérateur de message.
my $val = $iter->get_uint16()
$iter->append_uint16($val);
Lit ou écrit une valeur non signée de 16 bits depuis/vers l'itérateur de message.
my $val = $iter->get_int32()
$iter->append_int32($val);
Lit ou écrit une valeur signée de 32 bits depuis/vers l'itérateur de message.
my $val = $iter->get_uint32()
$iter->append_uint32($val);
Lit ou écrit une valeur non signée de 32 bits depuis/vers l'itérateur de message.
my $val = $iter->get_int64()
$iter->append_int64($val);
Lit ou écrit une valeur signée de 64 bits depuis/vers l'itérateur de message. Une erreur sera levée si ce compilateur Perl ne prend pas en charge les entiers 64 bits.
my $val = $iter->get_uint64()
$iter->append_uint64($val);
Lit ou écrit une valeur non signée de 64 bits depuis/vers l'itérateur de message. Une erreur sera levée si ce compilateur Perl ne prend pas en charge les entiers 64 bits.
my $val = $iter->get_double()
$iter->append_double($val);
Lit ou écrit une valeur à virgule flottante double précision depuis/vers l'itérateur de message.
my $val = $iter->get_unix_fd()
$iter->append_unix_fd($val);
Lit ou écrit une valeur de descripteur de fichier Unix depuis/vers l'itérateur de message.
my $value = $iter->get()
my $value = $iter->get($type);
Récupère la valeur actuelle pointée par cet itérateur. Si le paramètre optionnel $type est fourni, le type de fil sera comparé au type souhaité et un avertissement sera émis si des différences sont constatées. La valeur $type doit être l'une des constantes "Net::DBus::Binding::Message::TYPE*".
my $hashref = $iter->get_dict()
Si l'itérateur actuel pointe vers une valeur de dictionnaire, il désérialise et renvoie la valeur sous forme de référence de hachage.
my $hashref = $iter->get_array()
Si l'itérateur actuel pointe vers une valeur de tableau, il désérialise et renvoie la valeur sous forme de référence de tableau.
my $hashref = $iter->get_variant()
Si l'itérateur actuel pointe vers une valeur de variant, il désérialise et renvoie la valeur contenue dans le variant.
my $hashref = $iter->get_struct()
Si l'itérateur actuel pointe vers une valeur de structure, il désérialise et renvoie la valeur sous forme de référence de tableau. Les valeurs dans le tableau correspondent aux membres de la structure.
$iter->append($value)
$iter->append($value, $type)
Ajoute une valeur au message associé à cet itérateur. La valeur est sérialisée selon les règles suivantes.

Si $value est un objet de type Net::DBus::Binding::Value, le type de données intégré est utilisé.

Si le paramètre optionnel $type est fourni, il est utilisé comme représentation du type de données. Le type doit être l'une des constantes "Net::DBus::Binding::Message::TYPE_*".

Sinon, le type est choisi en fonction des types de données Perl : chaîne, dictionnaire ou tableau.

my $type = $iter->guess_type($value)
Donne une meilleure estimation du type de données sur le fil pour sérialiser $value. Si la valeur est une référence de hachage, le type de dictionnaire est renvoyé ; si c'est une référence de tableau, le type de tableau est renvoyé ; sinon, le type de chaîne est renvoyé.
my $sig = $iter->format_signature($type)
Étant donné une représentation du type de données, construit une chaîne de signature correspondante.
$iter->append_array($value, $type)
Ajoute un tableau de valeurs au message. Le paramètre $value doit être une référence de tableau, dont les éléments ont le même type de données spécifié par le paramètre $type.
$iter->append_struct($value, $type)
Ajoute une structure au message. Le paramètre $value doit être une référence de tableau, dont les éléments correspondent aux membres de la structure. Le paramètre $type spécifie le type de chaque membre de la structure.
$iter->append_dict($value, $type)
Ajoute un dictionnaire au message. Le paramètre $value doit être une référence de hachage. Le paramètre $type spécifie le type de clé et de valeur du hachage.
$iter->append_variant($value)
Ajoute une valeur au message, encodée en tant que type variant. La valeur $value peut être de n'importe quel type, bien que le variant soit encodé comme une chaîne, un dictionnaire ou un tableau selon les règles de la méthode "guess_type".
my $type = $iter->get_arg_type
Obtient le code de type de la valeur pointée par cet itérateur. Le code renvoyé correspond à l'une des constantes "Net::DBus::Binding::Message::TYPE_*".

NAME

Net::DBus::Binding::Iterator – Provides an iterator for traversing D-Bus messages.

SYNOPSIS

    use Net::DBus::Binding;

    my $iterator = $message->get_iter();
    while ($iterator->next()) {
        # ... process element ...
    }

DESCRIPTION

This class provides a way to iterate over the elements of a D-Bus message. This is generally used when you have a message containing an array, a struct, or a variant.

METHODS

get_element_type
If the iterator points to an array, retrieves the type code of array elements. The returned code will correspond to one of the constants "Net::DBus::Binding::Message::TYPE_*"
