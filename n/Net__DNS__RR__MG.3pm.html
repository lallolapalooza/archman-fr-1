NOM

Net::DNS::RR::MG - Enregistrement de ressource DNS MG

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new('name MG mgmname');

DESCRIPTION

Classe pour les enregistrements de ressource DNS Mail Group (MG).

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées des méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités de paquet non documentées ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

mgmname

$mgmname = $rr->mgmname;
$rr->mgmname( $mgmname );

Un nom de domaine qui spécifie une boîte aux lettres qui est membre du groupe de messagerie spécifié par le nom du propriétaire.
