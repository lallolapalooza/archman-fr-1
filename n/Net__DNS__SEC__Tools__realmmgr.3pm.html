NOM

Net::DNS::SEC::Tools::realmmgr - Communiquer avec le gestionnaire de domaines DNSSEC-Tools.

SYNOPSIS

use Net::DNS::SEC::Tools::realmmgr;
$dir = realmmgr_dir();
$idfile = realmmgr_idfile();
$id = realmmgr_getid();
realmmgr_dropid();
realmmgr_rmid();
realmmgr_cmdint();
$runflag = realmmgr_running();
realmmgr_halt();
realmmgr_channel(1);
($cmd,$data) = realmmgr_getcmd();
$ret = realmmgr_verifycmd($cmd);
realmmgr_sendcmd(CHANNEL_CLOSE,REALMCMD_STARTREALM,"exemple-domaine");
realmmgr_sendcmd(CHANNEL_WAIT,REALMCMD_STARTREALM,"exemple-domaine");
($retcode, $respmsg) = realmmgr_getresp();

DESCRIPTION

Le module Net::DNS::SEC::Tools::realmmgr fournit des méthodes standard et indépendantes de la plateforme pour qu'un programme communique avec le gestionnaire de domaines dtrealms de DNSSEC-Tools. Deux types d'interfaces sont décrits ici : les interfaces générales et les interfaces de communication.

INTERFACES GÉNÉRALES

Les interfaces du module Net::DNS::SEC::Tools::realmmgr sont données ci-dessous.

realmmgr_dir()
Cette routine renvoie le répertoire de dtrealms.
realmmgr_idfile()
Cette routine renvoie le fichier d'identifiants de dtrealms.
realmmgr_getid()
Cette routine renvoie l'ID de processus de dtrealms. Si une valeur non nulle est passée en argument, le fichier d'identifiants restera ouvert et accessible via le descripteur de fichier PIDFILE. Voir la section AVERTISSEMENTS ci-dessous.

Valeurs de retour :

En cas de succès, la première partie du contenu du fichier
(jusqu'à 80 caractères) est renvoyée.
-1 est renvoyé si le fichier d'identifiants n'existe pas.
realmmgr_dropid()
Cette interface garantit qu'une autre instance de dtrealms n'est pas en cours d'exécution, puis crée un fichier d'identifiants pour référence future.

Valeurs de retour :

 1 - le fichier d'identifiants a été créé avec succès pour ce processus
 0 - un autre processus agit déjà comme dtrealms
-1 - impossible de créer le fichier d'identifiants
realmmgr_rmid()
Cette interface supprime le fichier d'identifiants de dtrealms.

Valeurs de retour :

 1 - le fichier d'identifiants a été supprimé avec succès
 0 - aucun fichier d'identifiants n'existe
-1 - le processus appelant n'est pas dtrealms
-2 - impossible de supprimer le fichier d'identifiants
realmmgr_cmdint()
Cette routine informe dtrealms qu'une commande a été envoyée via realmmgr_sendcmd().

Valeurs de retour :

-1 - un ID de processus invalide a été trouvé pour dtrealms
Tout autre valeur indique le nombre de processus qui ont été
signalés.
(Cela ne devrait toujours être que 1.)
realmmgr_running()
Cette routine détermine si dtrealms est en cours d'exécution et renvoie une valeur indiquant le statut.

Valeurs de retour :

 1 - dtrealms est en cours d'exécution.
 0 - Le processus listé dans le fichier d'ID de processus
     de dtrealms n'est pas en cours d'exécution.
-1 - Impossible d'obtenir l'ID de processus de dtrealms.
realmmgr_halt()
Cette routine demande à dtrealms de s'arrêter.

Dans l'implémentation actuelle, le code de retour de la commande kill() est renvoyé.

-1 - un ID de processus invalide a été trouvé pour dtrealms
Tout autre valeur indique le nombre de processus qui ont été
signalés.
(Cela ne devrait toujours être que 1.)

INTERFACES DE COMMUNICATION DTREALMS

realmmgr_channel(serverflag)
Cette interface configure un canal persistant pour la communication avec dtrealms. Si serverflag est vrai, alors le côté serveur du canal est créé. Si serverflag est faux, alors le côté client du canal est créé.

Actuellement, la connexion ne peut être établie qu'avec localhost. Cela pourrait être modifié pour autoriser les connexions à distance si cela s'avère nécessaire.

Valeurs de retour :

 1 - Canal de communication établi avec succès.
 0 - Impossible de se connecter au serveur.
-1 - Impossible de créer un socket Unix.
-2 - Impossible de lier le socket Unix. (serveur uniquement)
-3 - Impossible de modifier les permissions sur le socket Unix. (serveur uniquement)
-4 - Impossible d'écouter sur le socket Unix. (serveur uniquement)
-5 - Le nom du socket était trop long pour un socket Unix.
realmmgr_queuecmd(cmdname, valeur)
Cette interface mémorise en interne une commande et sa valeur facultative pour un traitement ultérieur. Voir realmmgr_getcmd() ci-après pour plus de détails.
realmmgr_getcmd()
realmmgr_getcmd() traite les commandes qui doivent être gérées. Si des commandes sont stockées en interne et mises en file d'attente via la fonction realmmgr_queuecmd(), elles sont traitées en premier. Ensuite, elle récupère une commande envoyée sur le canal de communication de dtrealms par un programme client. La commande et les données de la commande sont envoyées dans chaque message.

La commande et les données de la commande sont renvoyées à l'appelant.

realmmgr_sendcmd(closeflag,cmd,data)
realmmgr_sendcmd() envoie une commande à dtrealms. La commande doit être l'une des commandes du tableau ci-dessous. Cette interface crée un canal de communication vers dtrealms et envoie le message. Le canal n'est pas fermé, au cas où l'appelant souhaiterait recevoir une réponse de dtrealms.

Les commandes disponibles et leurs données requises sont :

commande             données         but
-------              ----            -------
REALMCMD_COMMAND     domaine, commande exécuter une commande dans un domaine
REALMCMD_DISPLAY     1/0             démarrer/arrêter l'affichage graphique
                                     de dtrealms
REALMCMD_GETSTATUS   aucun           actuellement inutilisé
REALMCMD_LOGFILE     nom_fichier_log changer le fichier journal
REALMCMD_LOGLEVEL    niveau_journal  définir un nouveau niveau de journalisation
REALMCMD_LOGMSG      message_journal ajouter un message au journal
REALMCMD_LOGTZ       fuseau_horaire  définir le fuseau horaire pour les messages du journal
REALMCMD_NODISPLAY   0               arrêter l'affichage graphique de dtrealms
REALMCMD_REALMSTATUS aucun           obtenir l'état des domaines
REALMCMD_SHUTDOWN    aucun           arrêter dtrealms et ses domaines
REALMCMD_STARTALL    aucun           démarrer tous les domaines arrêtés
REALMCMD_STOPALL     aucun           arrêter tous les domaines en cours d'exécution
REALMCMD_STARTREALM  nom_domaine     redémarrer un domaine suspendu
REALMCMD_STOPREALM   nom_domaine     arrêter un domaine
REALMCMD_STATUS      aucun           obtenir l'état de dtrealms

Les données ne sont pas vérifiées quant à leur validité par realmmgr_sendcmd() ; la vérification de validité est une responsabilité de dtrealms.

Si l'appelant n'a pas besoin de réponse de dtrealms, alors closeflag doit être défini sur CHANNEL_CLOSE ; si une réponse est requise, alors closeflag doit être CHANNEL_WAIT. Ces valeurs sont des valeurs booléennes, et les constantes ne sont pas obligatoires.

En cas de succès, 1 est renvoyé. Si une commande invalide est donnée, 0 est renvoyé.

realmmgr_getresp()
Après avoir exécuté une commande client envoyée via realmmgr_sendcmd(), dtrealms enverra une réponse au client. realmmgr_getresp() permet au client de récupérer la réponse.

Un code de retour et une chaîne de réponse sont renvoyés, dans cet ordre. Tous deux sont spécifiques à la commande envoyée.

realmmgr_verifycmd(cmd)
Cette routine vérifie si la commande donnée est une commande valide pour dtrealms. Si la commande est valide, elle renvoie 1 ; sinon, elle renvoie 0.

CONSTANTES

Les constantes suivantes sont définies pour une utilisation avec les fonctions de ce module :

CHANNEL_CLOSE
Ferme le canal de communication après l'envoi de la commande.
CHANNEL_WAIT
Attend une réponse du serveur après l'envoi de la commande.
REALMCMD_COMMAND
REALMCMD_DISPLAY
REALMCMD_GETSTATUS
REALMCMD_LOGFILE
REALMCMD_LOGLEVEL
REALMCMD_LOGMSG
REALMCMD_LOGTZ
REALMCMD_NODISPLAY
REALMCMD_REALMSTATUS
REALMCMD_SHUTDOWN
REALMCMD_STARTALL
REALMCMD_STOPALL
REALMCMD_STARTREALM
REALMCMD_STOPREALM
REALMCMD_STATUS
Ce sont les commandes qui peuvent être envoyées à dtrealms.

AVERTISSEMENTS

Lorsque vous utilisez la routine realmmgr_getid(), si vous spécifiez une valeur non nulle comme argument, le fichier d'identifiants sera laissé ouvert et utilisable via le descripteur de fichier PIDFILE. Soyez prudent lorsque vous manipulez directement ce fichier.
