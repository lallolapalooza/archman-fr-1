NOM

Net::DNS::RR::SVCB - Enregistrement de ressource DNS SVCB

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new('nom SVCB  PrioritéSvc NomCible ParamSvc');

DESCRIPTION

Enregistrement de ressource DNS Service Binding (SVCB)

Spécification de la liaison de service et des paramètres via le DNS (enregistrements SVCB et HTTPS)

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base, augmentées par les méthodes spécifiques au type définies dans ce paquet.

L'utilisation de fonctionnalités non documentées du paquet ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner la terminaison du programme ou d'autres comportements imprévisibles.

PrioritéSvc

$rr->PrioritéSvc( $prioritesvc );
$prioritesvc = $rr->PrioritéSvc;

La priorité de cet enregistrement par rapport aux autres dans le RRset (les valeurs plus basses sont préférées). Une valeur de 0 indique le mode alias.')

NomCible

$rr->nomcible( $nomcible );
$ciblesffectif = $rr->nomcible;

Le nom de domaine de la cible de l'alias (pour le mode alias) ou du point de terminaison alternatif (pour le mode service).

Pour les enregistrements SVCB en mode alias, un NomCible de "." indique que le service n'est pas disponible ou n'existe pas.

Pour les enregistrements SVCB en mode service, un NomCible de "." indique que le nom propriétaire de cet enregistrement doit être utilisé comme NomCible effectif.

obligatoire, alpn, no-default-alpn, port, ipv4hint, ech, ipv6hint

$rr = Net::DNS::RR->new( 'svcb.example. SVCB 1 svcb.example. port=1234' );
$rr->port(1234);
$octets = $rr->port();  # 0x04 0xD2
$octets = $rr->key3();

Méthodes de constructeur pour les ParamSvc mnémoniques prescrits par la RFC9460. Lorsqu'elles sont appelées sans arguments, les méthodes retournent la valeur de la clé sous-jacente sous forme de chaîne d'octets non interprétée. Le comportement avec des arguments indéfinis n'est pas spécifié.

cléNN

$clénn = $rr->cléNN;
$rr->cléNN( $clénn );
$rr->cléNN( undef );

Méthodes génériques de constructeur et d'accesseur pour les ParamSvc. L'indice de clé NN est un entier décimal dans la plage 0 .. 65535. L'argument de la méthode est une chaîne de caractères au format de présentation. La valeur retournée est une chaîne d'octets non interprétée. La méthode retourne la valeur indéfinie si la clé n'est pas présente. La clé spécifiée sera supprimée si l'argument est indéfini.
