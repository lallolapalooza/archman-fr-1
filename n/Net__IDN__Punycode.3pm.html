NOM

Net::IDN::Punycode - Encodage Bootstring de l'Unicode pour l'IDNA (RFC 3492)

SYNOPSIS

use Net::IDN::Punycode qw(:all);
$punycode = encode_punycode($unicode);
$unicode  = decode_punycode($punycode);

DESCRIPTION

Ce module implémente l'encodage Punycode, et uniquement l'encodage Punycode.

Ce module n'implémente aucune autre étape nécessaire pour convertir les noms de domaine internationalisés (IDN) vers et depuis l'ASCII. En particulier, il n'effectue aucune préparation de chaîne comme spécifié par Nameprep/IDNA2008/PRECIS et n'ajoute ni ne supprime le préfixe ACE ("xn--"). Ainsi, utilisez Net::IDN::Encode si vous souhaitez convertir des noms de domaine.

Punycode est une instance d'un algorithme plus général appelé Bootstring, qui permet à des chaînes composées d'un petit ensemble de points de code "de base" de représenter de manière unique toute chaîne de points de code tirés d'un ensemble plus large. Punycode est Bootstring avec des valeurs de paramètres particulières appropriées pour l'IDNA.

ATTENTION

Vous pourriez être tenté d'utiliser ce module directement et d'ajouter/supprimer le préfixe ACE ("xn--") dans votre code pour des raisons de performance. Généralement, ce n'est pas une bonne idée. Si vous convertissez des étiquettes de domaine (ou d'autres chaînes) sans préparation adéquate, vous pourriez obtenir un encodage ASCII qui n'est pas interopérable, voire qui pose des problèmes de sécurité en raison d'usurpations.

Même si vous pensez que vos noms de domaine sont valides et déjà mappés à la forme correcte, cela pourrait ne pas être le cas. Par exemple, certains environnements pourraient automatiquement convertir vos noms de domaine parfaitement valides dans une forme de normalisation Unicode différente mais équivalente (par exemple, NFD au lieu de NFC), ce qui casse déjà l'IDNA.

FONCTIONS

Aucune fonction n'est exportée par défaut. Vous pouvez utiliser le tag ":all" ou les importer individuellement.

Les fonctions suivantes sont disponibles :

encode_punycode($input)
Encode $input avec Punycode et retourne le résultat.

Cette fonction lèvera une exception en cas d'entrée invalide ou non encodable.

decode_punycode($input)
Décode $input avec Punycode et retourne le résultat.

Cette fonction lèvera une exception en cas d'entrée invalide.
