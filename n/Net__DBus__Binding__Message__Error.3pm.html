Net::DBus::Binding::Message::Error(3) Documentation Perl fournie par la communauté Net::DBus::Binding::Message::Error(3)

NOM

Net::DBus::Binding::Message::Error - un message encodant une erreur d'appel de méthode

SYNTAXE

use Net::DBus::Binding::Message::Error;
my $error = Net::DBus::Binding::Message::Error->new(
    replyto => $method_call,
    name => "org.example.myobject.FooException",
    description => "Impossible de faire Foo lors de la mise à jour de bar");
$connection->send($error);

DESCRIPTION

Ce module fait partie des API de liaison DBus de bas niveau, et ne devrait pas être utilisé par le code applicatif. Aucune garantie n'est faite concernant la stabilité des API sous le namespace "Net::DBus::Binding::" entre les différentes versions.

Ce module fournit un constructeur pratique pour créer un message représentant une condition d'erreur.

MÉTHODES

my $error = Net::DBus::Binding::Message::Error->new( replyto => $method_call, name => $name, description => $description);
Crée un nouveau message, représentant une erreur survenue lors du traitement de l'objet d'appel de méthode passé en tant que paramètre "replyto". Le paramètre "name" est le nom formel de la condition d'erreur, tandis que la "description" est un court texte donnant des informations plus spécifiques sur l'erreur.
my $name = $error->get_error_name
Retourne le nom formel de l'erreur, tel que précédemment passé via le paramètre "name" dans le constructeur.
