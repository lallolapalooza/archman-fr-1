NOM

Net::DNS::DomainName - Représentation de nom DNS

SYNOPSIS

use Net::DNS::DomainName;
$object = Net::DNS::DomainName->new('example.com');
$name = $object->name;
$data = $object->encode;
( $object, $next ) = Net::DNS::DomainName->decode( \$data, $offset );

DESCRIPTION

Le module Net::DNS::DomainName implémente la représentation concrète des noms de domaine DNS utilisés dans les paquets DNS.

Net::DNS::DomainName définit des méthodes pour l'encodage et le décodage des chaînes d'octets au format filaire. Tout autre comportement est hérité de Net::DNS::Domain.

Les packages Net::DNS::DomainName1035 et Net::DNS::DomainName2535 implémentent des sous-types disjoints de noms de domaine qui fournissent la compression de noms et la canonicalisation spécifiées par les RFC1035 et RFC2535. Ceux-ci sont nécessaires pour répondre aux exigences de compatibilité descendante introduites par la RFC3597.

MÉTHODES

new

$object = Net::DNS::DomainName->new('example.com');

Crée un objet nom de domaine qui identifie le domaine spécifié par la chaîne de caractères argument.

decode

$object = Net::DNS::DomainName->decode( \$buffer, $offset, $hash );
( $object, $next ) = Net::DNS::DomainName->decode( \$buffer, $offset, $hash );

Crée un objet nom de domaine qui représente le nom de domaine DNS identifié par les données au format filaire à l'offset indiqué dans le tampon de données.

La liste des arguments se compose d'une référence à un scalaire contenant les données au format filaire et de l'offset spécifié. La référence optionnelle à une table de hachage offre une efficacité améliorée pour le décodage des noms compressés en exploitant les pointeurs de compression déjà mis en cache.

La valeur d'offset renvoyée indique le début de l'élément suivant dans le tampon de données.

encode

$data = $object->encode;

Retourne la représentation au format filaire du nom de domaine, adaptée à l'inclusion dans un tampon de paquet DNS.

canonical

$data = $object->canonical;

Retourne la représentation canonique au format filaire du nom de domaine telle que définie dans RFC2535(8.1).

Net::DNS::DomainName1035

Net::DNS::DomainName1035 implémente une sous-classe d'objets nom de domaine qui doivent être encodés en utilisant le format filaire compressé défini dans RFC1035.

$data = $object->encode( $offset, $hash );

Les arguments sont l'offset dans les données du paquet où le nom de domaine doit être stocké et une référence à une table de hachage utilisée pour indexer les noms compressés dans le paquet.

Notez que RFC3597 implique que seuls les types d'enregistrements RR définis dans RFC1035(3.3) sont éligibles à la compression des noms de domaine figurant dans le RDATA.

Si la référence de hachage est indéfinie, encode() renvoie la représentation canonique non compressée en minuscules définie dans RFC2535(8.1).

Net::DNS::DomainName2535

Net::DNS::DomainName2535 implémente une sous-classe d'objets nom de domaine qui doivent être encodés en utilisant le format filaire non compressé.

$data = $object->encode( $offset, $hash );

Les arguments sont l'offset dans les données du paquet où le nom de domaine doit être stocké et une référence à une table de hachage utilisée pour indexer les noms déjà encodés dans le paquet.

Si la référence de hachage est indéfinie, encode() renvoie la représentation canonique non compressée en minuscules définie dans RFC2535(8.1).

Notez que RFC3597, et plus tard RFC4034, spécifient que la forme canonique en minuscules doit être utilisée pour les types d'enregistrements RR définis avant RFC3597.
