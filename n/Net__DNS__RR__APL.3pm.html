NOM

Net::DNS::RR::APL - enregistrement de ressource APL DNS

SYNTAXE

use Net::DNS;
$rr = Net::DNS::RR->new('name IN APL aplist');

DESCRIPTION

Enregistrement APL (Address Prefix List) DNS

MÉTHODES

Les méthodes disponibles sont celles héritées de la classe de base augmentées par les méthodes spécifiques au type définies dans ce package.

L'utilisation de fonctionnalités non documentées du package ou l'accès direct aux structures de données internes est déconseillée et pourrait entraîner l'arrêt du programme ou d'autres comportements imprévisibles.

aplist

@aplist = $rr->aplist;

@aplist = $rr->aplist( '1:192.168.32.0/21', '!1:192.168.38.0/28' );

@aplist = $rr->aplist( '1:224.0.0.0/4', '2:FF00:0:0:0:0:0:0:0/8' );

@aplist = $rr->aplist(
                negate  => 1,
                family  => 1,
                address => '192.168.38.0',
                prefix  => 28,
                );

Liste ordonnée, éventuellement vide, d'éléments de préfixe d'adresse. Les éléments supplémentaires, s'ils sont présents, sont ajoutés à la liste existante sans agrégation de préfixe ni réorganisation.

Net::DNS::RR::APL::Item

Chaque élément de la liste de préfixes est un objet Net::DNS::RR::APL::Item qui est inextricablement lié à l'enregistrement APL qui l'a créé.

negate

$rr->negate(1);
if ( $rr->negate ) {
        ...
}

Attribut booléen indiquant que le préfixe est une exclusion de plage d'adresses.

family

$family = $rr->family;
$rr->family( $family );

Discréminateur de famille d'adresses.

prefix

$prefix = $rr->prefix;
$rr->prefix( $prefix );

Nombre de bits composant le préfixe d'adresse.

address

$address = $object->address;

Partie adresse de l'élément de la liste de préfixes.

string

$string = $object->string;

Retourne l'élément de la liste de préfixes sous la forme requise dans les fichiers de zone.
