NOM

Net::LDAPI - utiliser LDAP via un socket de domaine UNIX

SYNOPSIS

use Net::LDAPI;
$ldapi = Net::LDAPI->new('/var/run/ldapi');
# autre façon
use Net::LDAP;
$ldapi = Net::LDAP->new('ldapi://');

DESCRIPTION

Communiquer en utilisant le protocole LDAP à un serveur d'annuaire via un socket de domaine UNIX. Ce mécanisme est non standard, spécifique à UNIX et non largement supporté.

Toutes les méthodes normales de "Net::LDAP" peuvent être utilisées avec un objet "Net::LDAPI" ; voir Net::LDAP pour plus de détails.

CONSTRUCTEUR

new ( [SOCKPATH] )
Crée une nouvelle connexion. SOCKPATH peut être spécifié optionnellement, pour indiquer l'emplacement du socket de domaine UNIX auquel se connecter.

Si SOCKPATH n'est pas donné, la variable d'environnement "LDAPI_SOCK" est évaluée, et si elle n'existe pas, la valeur "/var/run/ldapi" est utilisée.

Voir "new" dans Net::LDAP pour plus de détails.

VOIR AUSSI

Net::LDAP, IO::Socket::UNIX
