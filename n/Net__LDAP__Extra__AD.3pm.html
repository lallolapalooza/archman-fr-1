NOM

Net::LDAP::Extra::AD -- Méthodes pratiques pour AD

SYNTAXE

use Net::LDAP::Extra qw(AD);
$ldap = Net::LDAP->new( ... );
...
if ($ldap->is_AD || $ldap->is_ADAM) {
  $ldap->change_ADpassword($dn, $old_password, $new_password);
}

DESCRIPTION

Net::LDAP::Extra::AD tente d'épargner aux utilisateurs la nécessité de réinventer la roue encore et encore afin d'encoder correctement les chaînes de mots de passe pour qu'elles puissent être utilisées dans les opérations de changement de mot de passe AD.

Pour ce faire, il fournit les méthodes suivantes :

MÉTHODES

is_AD ( )
Indique si le serveur LDAP interrogé est un contrôleur de domaine Active Directory.

Comme la vérification est effectuée en interrogeant le DSE racine de l'annuaire, elle fonctionne sans être authentifiée auprès de l'annuaire.

is_ADAM ( )
Indique si le serveur LDAP interrogé exécute AD LDS (Active Directory Lightweight Directory Services), précédemment connu sous le nom d'ADAM (Active Directory Application Mode).

Comme la vérification est effectuée en interrogeant le DSE racine de l'annuaire, elle fonctionne sans être authentifiée auprès de l'annuaire.

change_ADpassword ( DN, ANCIEN_MOT_DE_PASSE, NOUVEAU_MOT_DE_PASSE )
Change le mot de passe du compte donné par DN de sa valeur précédente ANCIEN_MOT_DE_PASSE à la nouvelle valeur NOUVEAU_MOT_DE_PASSE.

Cette méthode nécessite des connexions cryptées.

reset_ADpassword ( DN, NOUVEAU_MOT_DE_PASSE, OPTIONS )
Réinitialise le mot de passe du compte donné par DN à la valeur donnée dans NOUVEAU_MOT_DE_PASSE. OPTIONS est une liste de paires clé/valeur. Les clés suivantes sont reconnues :
force_change
Si VRAI, l'utilisateur concerné est invité à changer son mot de passe lors de sa prochaine connexion.

Pour que cette méthode fonctionne, l'appelant doit être authentifié auprès d'AD avec des autorisations suffisantes, et la connexion doit être cryptée.
