NOM

Net::LDAP::Control::MatchedValues - Contrôle MatchedValues LDAPv3

SYNOPIS

use Net::LDAP;
use Net::LDAP::Control::MatchedValues;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$mv = Net::LDAP::Control::MatchedValues->new( matchedValues => '((sn=Jensen)(sn=Miller))' );
# retourne les entrées de toutes les personnes dont le prénom est "Babs",
# mais n'affiche le nom ("sn") que s'il est "Jensen" ou "Miller"
my $mesg = $ldap->search( base => "o=University of Michigan, c=US",
                          filter => "(givenName=Babs)",
                          attrs => [ qw/sn/ ],
                          control => $mv );

DESCRIPTION

"Net::LDAP::Control::MatchedValues" fournit une interface pour la création et la manipulation d'objets qui représentent le "MatchedValues Control" tel que décrit par la RFC 3876.

Le "MatchedValues Control", qui n'a de signification qu'avec l'opération de "Recherche", permet au client de spécifier des critères qui restreignent les valeurs des attributs retournés. Il n'a aucun effet sur le nombre d'objets trouvés, mais permet uniquement de restreindre les valeurs des attributs retournés par la recherche à ceux qui correspondent aux critères.

ARGUMENTS DU CONSTRUCTEUR

En plus des arguments du constructeur décrits dans Net::LDAP::Control, les suivants sont fournis.

matchedValues => FILTREDEVALEURSRETOURNÉES
Un filtre donnant les critères auxquels les valeurs d'attributs doivent correspondre.

FILTREDEVALEURSRETOURNÉES est une séquence d'éléments de filtre simples de la forme "( <ATTRSPEC> <OP> <VALEUR> )" entourés d'un ensemble supplémentaire de parenthèses ; par exemple :

((personsAge<=29))
Ne retourne l'âge que s'il est inférieur à 30 ;-)
((cn=*Emergency*)(telephoneNumber=+1*)(telephoneNumber=911))
Ne retourne que les valeurs du nom commun (cn) qui contiennent "Emergency", et les numéros de téléphone d'Amérique du Nord, y compris celui des appels d'urgence.

MÉTHODES

Comme avec Net::LDAP::Control, chaque argument du constructeur décrit ci-dessus est également disponible comme méthode sur l'objet qui retournera la valeur actuelle de l'attribut s'il est appelé sans argument, et définira une nouvelle valeur pour l'attribut s'il est appelé avec un argument.
