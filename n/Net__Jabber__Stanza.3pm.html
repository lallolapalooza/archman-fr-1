NAME

Net::Jabber::Stanza - Module de Stanza Jabber

SYNOPSIS

Net::Jabber::Stanza est un paquet privé qui sert de base à toutes les stanzas Jabber générées par Net::Jabber.

DESCRIPTION

Ce module ne doit pas être utilisé directement. Vous devriez utiliser
soit Net::Jabber::IQ, Net::Jabber::Message, Net::Jabber::Presence, soit
un autre paquet qui hérite de Net::Jabber::Stanza.
Bien que cela soit dit, c'est là que toutes les fonctions des espaces
de noms sont définies. Les espaces actuellement pris en charge sont :
