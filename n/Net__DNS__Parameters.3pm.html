NOM

Net::DNS::Parameters - affectations de paramètres DNS

SYNOPIS

use Net::DNS::Parameters;

DESCRIPTION

Net::DNS::Parameters est un paquet Perl représentant les tables (clé, valeur) d'affectation des paramètres DNS telles qu'enregistrées dans le registre définitif maintenu et publié par l'IANA.

FONCTIONS

classbyname, typebyname, opcodebyname, rcodebyname, ednsoptionbyname, dsotypebyname

Fonctions d'accès qui retournent le code numérique correspondant au mnémonique donné.

classbyval, typebyval, opcodebyval, rcodebyval, ednsoptionbyval, dsotypebyval

Fonctions d'accès qui retournent le mnémonique canonique correspondant au code numérique donné.
