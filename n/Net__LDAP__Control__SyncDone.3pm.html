Net::LDAP::Control::SyncDone(3) Documentation Perl fournie par l'utilisateur Net::LDAP::Control::SyncDone(3)

NOM

Net::LDAP::Control::SyncDone - Objet de contrôle Sync Done LDAPv3

SYNTAXE

Voir Net::LDAP::Control::SyncRequest

DESCRIPTION

"Net::LDAP::Control::SyncDone" fournit une interface pour la création et la manipulation d'objets qui représentent le "Sync Request Control" tel que décrit par la RFC 4533.

ARGUMENTS DU CONSTRUCTEUR

En plus des arguments du constructeur décrits dans Net::LDAP::Control, les suivants sont fournis.

cookie
refreshDeletes

MÉTHODES

Comme avec Net::LDAP::Control, chaque argument du constructeur décrit ci-dessus est également disponible sous forme de méthode sur l'objet qui renverra la valeur actuelle de l'attribut si appelé sans argument, et définira une nouvelle valeur pour l'attribut si appelé avec un argument.

VOIR AUSSI

Net::LDAP, Net::LDAP::Control, Net::LDAP::Control::SyncRequest, Net::LDAP::Control::SyncState, http://www.ietf.org/rfc/rfc4533.txt
