NOM

Net::LDAP::DSML — Un générateur DSML pour Net::LDAP

SYNOPSIS

Pour un enregistrement de répertoire ;
                            use Net::LDAP;
                            use Net::LDAP::DSML;
                            use IO::File;
                            my $server = "localhost";
                            my $file = "testdsml.xml";
                            my $ldap = Net::LDAP->new($server);
                            $ldap->bind();
                            #
                            # Pour l'entrée/sortie de fichier
                            #
                            my $file = "testdsml.xml";
                            my $io = IO::File->new($file, "w")
                                or die ("échec de l'ouverture de $file en tant que gestionnaire de fichier.$!$n");
                            my $dsml = Net::LDAP::DSML->new(output => $io, pretty_print => 1)
                                or die ("erreur lors de la création de l'objet DSML à l'aide d'un fichier de sortie.$n");
                            #      OU
                            #
                            # Pour l'entrée/sortie de fichier
                            #
                            open (IO, ">$file") or die ("échec de l'ouverture de $file.$!$n");
                            my $dsml = Net::LDAP::DSML->new(output => $IO, pretty_print => 1)
                                or die ("erreur lors de la création de l'objet DSML à l'aide d'un fichier de sortie.$n");
                            #      OU
                            #
                            # Pour l'utilisation de tableaux.
                            # Passer une référence à un tableau.
                            #
                            my @data = ();
                            $dsml = Net::LDAP::DSML->new(output => \@data, pretty_print => 1)
                                or die ("erreur lors de la création de l'objet DSML à l'aide d'un tableau de sortie.$n");
                            my $mesg = $ldap->search(
                                base => 'o=airius.com',
                                scope => 'sub',
                                filter => 'ou=accounting',
                                callback => sub {
                                    my ($mesg,$entry) = @_;
                                    $dsml->write_entry($entry)
                                         if (ref $entry eq 'Net::LDAP::Entry');
                                }
                            );
                            die ("erreur lors de l'exécution de la recherche avec $mesg.$n") if $mesg->code();
                            Pour le schéma de répertoire ;
                            Un fichier ou un tableau peut être utilisé pour la sortie, dans l'exemple suivant seul un tableau sera utilisé.
                            my $schema = $ldap->schema();
                            my @data = ();
                            my $dsml = Net::LDAP::DSML->new(output => \@data, pretty_print => 1)
                                 or die ("erreur lors de la création de l'objet DSML à l'aide d'un tableau de sortie.$n");
                            $dsml->write_schema($schema);
                            print ("Impression DSML terminée.$n");

DESCRIPTION

Le Langage de Cadre de Services d'Annuaire (DSML) est la norme XML pour représenter les informations des services d'annuaire en XML.

À ce jour, ce module ne fait qu'écrire des entités d'enregistrement et de schéma DSML. La lecture d'entités DSML est un projet futur.

À terme, ce module sera un producteur et consommateur de niveau 2 complet, permettant à l'utilisateur d'atteindre une conformité DSML complète. Actuellement, ce module a la capacité d'être un producteur de niveau 2. L'utilisateur doit comprendre que son serveur d'annuaire déterminera le niveau de producteur et consommateur qu'il peut atteindre.

Pour déterminer la conformité, il est utile de diviser les documents DSML en quatre types :

1. Documents sans schéma d'annuaire ni références à un schéma externe.
2. Documents sans schéma d'annuaire mais contenant au moins une référence à un schéma externe.
3. Documents contenant uniquement un schéma d'annuaire.
4. Documents contenant à la fois un schéma d'annuaire et des entrées.

Un producteur DSML doit être capable de produire des documents de type 1. Un producteur DSML peut, en outre, produire des documents des types 2 à 4.

Un producteur capable de produire des documents de type 1 est dit producteur de niveau 1. Un producteur capable de produire des documents de tous les quatre types est dit producteur de niveau 2.

CALLBACKS

Le module utilise des callbacks pour améliorer les performances (bien que l'aspect d'amélioration des performances ;) et réduire la consommation mémoire nécessaire à l'analyse de grands documents DSML. Chaque fois qu'une seule entrée ou schéma est traité, l'objet Net::LDAP (soit un objet Entry, soit un objet Schema) est passé à la routine de callback.

CONSTRUCTEUR

new ()
Crée un nouvel objet Net::LDAP::DSML. Il y a deux options pour cette méthode.

"output" est une référence à un gestionnaire de fichier déjà ouvert ou à un tableau.

"pretty_print" est une option qui imprime un saut de ligne à la fin de chaque séquence d'éléments. Cela rend la sortie XML plus facile à lire.

Exemple

my $dsml = Net::LDAP::DSML->new();
Imprime les données XML sur la sortie standard.
my $dsml = Net::LDAP::DSML->new(output => \@array);
my $dsml = Net::LDAP::DSML->new(output => *FILE);
Imprime les données XML dans un fichier ou un tableau.
my $dsml = Net::LDAP::DSML->new(output => \@array, pretty_print => 1);
my $dsml = Net::LDAP::DSML->new(output => *FILE, pretty_print => 1);
Imprime les données XML dans un fichier ou un tableau en style d'impression formatée.

MÉTHODES

start_dsml ()
Démarre un fichier DSML.
end_dsml ()
Termine un fichier DSML.
write_entry (ENTRY )
ENTRY est un objet Net::LDAP::Entry. La méthode write s'occupe d'analyser les données LDAP dans l'objet Entry et de les convertir au format XML DSML.

Exemple

my $entry = $mesg->entry();
$dsml->write_entry($entry);
write_schema (SCHEMA )
SCHEMA est un objet Net::LDAP::Schema. La méthode write_schema s'occupe d'analyser les données LDAP dans l'objet Schema et de les convertir au format XML DSML.

Exemple

my $schema = $ldap->schema();
$dsml->write_schema($schema);
