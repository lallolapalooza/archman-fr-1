NOM

Net::IMAP::Simple - Extension Perl pour la gestion simple de comptes IMAP.

SYNOPIS

use strict;
use warnings;
use Net::IMAP::Simple;
use Email::Simple;
# Créer l'objet
my $imap = Net::IMAP::Simple->new('imap.example.com') ||
   die "Impossible de se connecter à IMAP : $Net::IMAP::Simple::errstr\n";
# Se connecter
if(!$imap->login('user','pass')){
    print STDERR "Échec de la connexion : " . $imap->errstr . "\n";
    exit(64);
}
# Afficher les sujets de tous les messages dans la boîte INBOX
my $nm = $imap->select('INBOX');
for(my $i = 1; $i <= $nm; $i++){
    if($imap->seen($i)){
        print "*";
    } else {
        print " ";
    }
    my $es = Email::Simple->new(join '', @{ $imap->top($i) } );
    printf("[%03d] %s\n", $i, $es->header('Subject'));
}
$imap->quit;

DESCRIPTION

Ce module est une manière simple d'accéder aux comptes IMAP.

MÉTHODE DE CRÉATION D'OBJET

my $imap = Net::IMAP::Simple->new( $server [ :port ]);
# OU
my $imap = Net::IMAP::Simple->new( $server [, option_name => option_value ] );

new

Cette méthode de classe construit un nouvel objet Net::IMAP::Simple. Elle prend un paramètre obligatoire qui est le serveur auquel se connecter, et des paramètres optionnels supplémentaires.

Le paramètre serveur peut spécifier juste le serveur, ou le serveur et le numéro de port. Pour spécifier un port alternatif, séparez-le du serveur avec un deux-points (":"), "example.com:5143".

En cas de succès, un objet est retourné. En cas d'échec, rien n'est retourné et un message d'erreur est défini dans $Net::IMAP::Simple.

Voir "PREAUTH" ci-dessous pour une invocation de nom d'hôte spéciale qui n'utilise pas de Sockets (en interne).

Les options sont fournies sous forme de hash à new() :

port => entier
Attribue le numéro de port (par défaut : 143)
timeout => entier (par défaut : 90)
Délai d'attente de la connexion en secondes.
retry => entier (par défaut : 1)
Tente de réessayer la tentative de connexion (x) fois avant d'abandonner
retry_delay => entier (par défaut : 5)
Attend (x) secondes avant de retenter une tentative de connexion
use_v6 => BOOL
Si défini à vrai, tente d'utiliser des sockets IPv6 plutôt que des sockets IPv4.

Cette option nécessite le module IO::Socket::INET6

use_ssl => BOOL
Si défini à vrai, tente d'utiliser des sockets IO::Socket::SSL plutôt que des sockets standards.

Notez qu'aucune tentative n'est faite pour vérifier la validité du certificat par défaut. C'est une très mauvaise sécurité personnelle, mais cela correspond au comportement précédent de ce module. Veuillez envisager d'utiliser "find_ssl_defaults" ci-dessous.

Cette option nécessite le module IO::Socket::SSL

ssl_version => version
Cela devrait être une ou plusieurs des valeurs suivantes (séparées par un espace) : SSLv3 SSLv2 TLSv1. Si vous spécifiez, par exemple, "SSLv3 SSLv2", alors IO::Socket::SSL tentera une négociation automatique. Au moment de la rédaction, la chaîne par défaut était la négociation automatique v3/v2 -- cela peut avoir changé au moment où vous lirez ceci.

Attention : définir cela activera également "use_ssl".

find_ssl_defaults => []
Recherche dans certains emplacements standard les bibliothèques de certificats CA et, si elles sont trouvées, définit des valeurs par défaut raisonnables dans le style de ce qui suit : 
ssl_options => [ SSL_ca_path => "/etc/ssl/certs/",
    SSL_verify_mode => IO::Socket::SSL::SSL_VERIFY_PEER() ]

Attention : définir cela activera également "use_ssl".

ssl_options => []
Vous pouvez fournir vos propres options IO::Socket::SSL si vous le souhaitez. Elles sont complètement remplacées par "find_ssl_defaults" ci-dessus.
bindaddr => chaîne
Attribue une adresse locale à lier
use_select_cache => BOOL
Active la mise en cache de select() en interne
select_cache_ttl => entier
Le nombre de secondes pendant lesquelles un résultat de mise en cache select est valide avant de réexécuter "$imap->select()".
debug => BOOL | \*HANDLE | warn | file:nom
Active la sortie de débogage. Si "\*HANDLE" est un descripteur de fichier valide, le débogage y sera écrit. S'il s'agit de la chaîne "warn", le débogage sera écrit en utilisant la commande warn. S'il s'agit d'une chaîne de la forme "file:nom", le fichier nommé sera ouvert en mode ajout et les débogages y seront écrits. Sinon, le débogage sera écrit sur "STDOUT"
readline_callback => CODE
Vous pouvez choisir de passer une fonction de rappel pour prétraiter les lignes avant qu'elles ne soient transmises au reste des internes de Net::IMAP::Simple. Cela peut être utile pour animer une roue qui tourne ou modifier le comportement IMAP.

PREAUTH

Plutôt que de passer un numéro de port et d'émettre une connexion, dans certaines situations, il peut être pratique de s'authentifier avec (par exemple) ssh et simplement d'invoquer (par exemple) dovecot manuellement.

Si le nom du serveur commence par "cmd:", alors Net::IMAP::Simple exécutera la commande plutôt que de créer des sockets. Voici une configuration typique :

my $cmd = "ssh -C mailhost dovecot --exec-mail imap";
my $imap = Net::IMAP::Simple->new("cmd:$cmd");
 # $imap->login(); ... pas besoin de cela
my $number_of_messages = $imap->select("INBOX");

MÉTHODES

starttls
$imap->starttls;

Si vous démarrez une session IMAP et souhaitez passer à SSL ultérieurement, vous pouvez utiliser cette fonction pour démarrer TLS. Cette fonction essaiera de "require" IO::Socket::SSL et Net::SSLeay à l'exécution.

login
my $inbox_msgs = $imap->login($user, $passwd);

Cette méthode prend deux paramètres obligatoires, un nom d'utilisateur et un mot de passe. Cette paire est authentifiée auprès du serveur. Si l'authentification réussit, VRAI (1) sera retourné.

Rien n'est retourné en cas d'échec et le gestionnaire d'erreurs errstr() est défini avec le message d'erreur.

status
my $num_messages                     = $imap->status($folder);
my ($unseen, $recent, $num_messages) = $imap->status($folder);

Émet une commande "STATUS". La commande "STATUS" compte les messages sans modifier l'état de la boîte aux lettres nommée (optionnelle). Elle retourne soit le nombre de messages, soit le nombre de messages non lus, de messages récents, et le nombre total de messages.

$folder est un argument optionnel. status() utilisera la boîte aux lettres actuelle ou "INBOX" si l'argument $folder n'est pas fourni.

Cette méthode n'utilise pas de cache.

my $uidnext = $imap->status($folder, qw(uidnext));

my $uidvalidity = $imap->uidnext($folder);

Retourne la valeur de "UIDVALIDITY" pour un dossier. L'argument $folder est optionnel. Ceci est aussi un alias pour l'appel à status comme uidnext() ci-dessus.

my $uid = $imap->uid($msgno);
my @uid = $imap->uid($msg_range); # eg 4:14  ou 15,4,14

Retourne la valeur de "UID" pour un message. Ces identifiants uniques doivent rester constants durant la session et "devraient" rester constants entre les sessions. Chaque fois que l'appel est effectué, les identifiants restent constants par rapport à la valeur de "UIDVALIDITY" ; voir : ci-dessus et RFC3501.

Attention, bien qu'il puisse sembler que @uid devrait contenir les "UID" pour 15, puis 4, puis 14 dans l'exemple ; sur la plupart des serveurs IMAP, les identifiants sont retournés par ordre croissant. Normalement, les numéros de séquence sont maintenus dans l'ordre croissant, donc tout concorde.

my ($uid4, $uid14, $uid15) = $imap->uid("15,4,14"); # attention

Une note finale, ceci retourne la taille du résultat de la recherche, pas l'UID comme vous pourriez vous y attendre :

my $uid_search_result_list_size = $imap->uid('3'); # probablement toujours 1

my $seq = $imap->seq($uids);
my @seq = $imap->seq($uids); # exemple 58888:58900

Similaire à uid() ci-dessus, mais met en correspondance les uid avec les numéros de séquence.

Net::IMAP::Simple

This module is a stripped-down, easy-to-use module for accessing IMAP mailboxes. It's designed to be simple and intuitive.

Methods

get
my $message = $imap->get( $message_number );

my $message = $imap->get(1);
   $message = "$message"; # force stringification

This is not normally necessary.

put
$imap->put( $mailbox_name, $message, @flags ) or warn $imap->errstr;

Save a message to the server under the folder named $mailbox_name. You may optionally specify flags for the mail (e.g. "\Seen", "\Answered"), but they must start with a slash.

If $message is an arrayref, the lines will be printed correctly.

put_with_date
$imap->put_with_date( $mailbox_name, $message, $date, @flags ) or warn $imap->errstr;

Save a message to the server under the folder named $mailbox_name just like the put method above, but supplying a date will set the IMAP server internal date for the message if supported per RFC 3501 Section 6.3.11.

Note when using this with Gmail it expects the date format to be: DD-Mon-YYYY hh:mm:ss tz for example 31-Dec-2016 12:59:59 -0500

msg_flags
my @flags = $imap->msg_flags( $message_number );
my $flags = $imap->msg_flags( $message_number );
# aught to come out roughly the same
print "Flags on message #$message_number: @flags\n";
print "Flags on message #$message_number: $flags\n";

Detecting errors with this member functions is usually desirable. In the scalar context, detecting an error is synonymous with testing for defined.

if( defined( my $flags = $imap->msg_flags($num) ) ) {
    # it has $flags!
} else {
    warn "problem listing flags for message #$num: "
       . $imap->errstr;
}

In list context, you must call waserr() to test for success.

my @flags = $imap->msg_flags($num);
warn "problem listing flags for msg #$num: "
   . $imap->errstr if $imap->waserr;
getfh
my $file = $imap->getfh( $message_number ); print <$file>;

On success this method returns a file handle pointing to the message identified by the required parameter. On failure, nothing is returned and the errstr() error handler is set with the error message.

quit
$imap->quit;
OR
$imap->quit(BOOL);

This method logs out of the IMAP server, expunges the selected mailbox, and closes the connection. No error message will ever be returned from this method.

Optionally if BOOL is TRUE (1) then a hard quit is performed which closes the socket connection. This hard quit will still issue both EXPUNGE and LOGOUT commands however the response is ignored and the socket is closed after issuing the commands.

logout
$imap->logout;

This method is just like the quit method except that it does not have a hard quit option and it does not expunge the mailbox before it hangs up and closes the socket.

last
my $message_number = $imap->last;

This method returns the message number of the last message in the selected mailbox, since the last time the mailbox was selected. On failure, nothing is returned and the errstr() error handler is set with the error message.

delete
print "Gone!" if $imap->delete( $message_number );

This method sets the "\Deleted" flag on the given message (or messages). On success it returns true, false on failure and the errstr() error handler is set with the error message. If the flag was already there, no error is produced. I takes either a message number or "sequence set" as the only argument. Note that messages aren't actually deleted until they are expunged (see expunge_mailbox).

undelete
print "Resurrected!" if $imap->undelete( $message_number );

This method removes the "\Deleted" flag on the given message. On success it returns true, false on failure and the errstr() error handler is set with the error message. If the flag wasn't there, no error is produced.

see
print "You've seen message #$msgno" if $imap->see( $messageno );

This method sets the "\Seen" flag on the given message. On success it returns true, false on failure and the errstr() error handler is set with the error message. If the flag was already there, no error is produced.

unsee
print "You've not seen message #$msgno" if $imap->unsee( $messageno );

This method removes the "\Seen" flag on the given message. On success it returns true, false on failure and the errstr() error handler is set with the error message. If the flag wasn't there, no error is produced.

add_flags

$imap->add_flags( $msgno, qw(\Seen \Deleted) )
     or die $imap->errstr;
sub_flags
unsee above really just calls this function for that flag. 
$imap->sub_flags( $msgno, '\Seen' ) or die $imap->errstr;
mailboxes
my @boxes   = $imap->mailboxes;
my @folders = $imap->mailboxes("Mail/%");
my @lists   = $imap->mailboxes("lists/perl/*", "/Mail/");

This method returns a list of mailboxes. When called with no arguments it recurses from the IMAP root to get all mailboxes. The first optional argument is a mailbox path and the second is the path reference. RFC 3501 section 6.3.8 has more information.

On failure nothing is returned and the errstr() error handler is set with the error message.

mailboxes_subscribed

On failure nothing is returned and the errstr() error handler is set with the error message.

create_mailbox
print "Created" if $imap->create_mailbox( "/Mail/lists/perl/advocacy" );

This method creates the mailbox named in the required argument. Returns true on success, false on failure and the errstr() error handler is set with the error message.

my @expunged = $imap->expunge_mailbox( "/Mail/lists/perl/advocacy" );
die $imap->errstr if $imap->waserr;
my $expunged = $imap->expunge_mailbox( "/Mail/lists/perl/advocacy" )
    or die $imap->errstr;

This method removes all mail marked as deleted in the mailbox named in the required argument. Returns either the number of messages that were expunged, or the indexes of those messages -- which has a questionable usefulness since it tends to return numbers that don't relate to the message numbers marked with the "\Deleted" flags.

If 0 messages were expunged without error, the function will return 0E0 so it will still test true, but also evaluate to 0.

In list context, you must call waserr() to test for success.

MISCELLANEOUS METHODS

copy
print "copied" if $imap->copy( $message_number, $mailbox );

Cette méthode copie le numéro de message (ou le "jeu de séquence") dans la boîte aux lettres actuellement sélectionnée vers le dossier spécifié dans le deuxième argument. Les deux arguments sont obligatoires. En cas de succès, cette méthode retourne vrai. Retourne faux en cas d'échec et le gestionnaire d'erreur errstr() est défini avec le message d'erreur.

Cette méthode est identique à copy() ci-dessus, sauf qu'elle utilise des numéros d'UID au lieu de numéros de séquence.

noop
$imap->noop;

Effectue une opération nulle. Cela peut être nécessaire pour obtenir des mises à jour sur une boîte aux lettres, ou pour s'assurer que le serveur ne ferme pas la connexion en mode inactif. Le RFC 3501 stipule que les délais d'attente du mode inactif des serveurs ne doivent pas être inférieurs à 30 minutes.

errstr
print "Login ERROR: " . $imap->errstr . "\n" if !$imap->login($user, $pass);

Retourne la dernière chaîne d'erreur capturée pour la dernière opération qui a échoué.

waserr
my @flags = $imap->msg_flags(14);
die $imap->errstr if $imap->waserr;

Comme msg_flags() peut éventuellement retourner une liste, il n'est pas vraiment possible de détecter un échec en contexte de liste. Par conséquent, vous devez appeler waserr() si vous souhaitez détecter des erreurs.

Peu de méthodes de Net::IMAP::Simple utilisent waserr(). Celles qui le font le mentionneront.

list2range
Parfois, vous avez une longue liste de numéros de séquence qui sont consécutifs et vous souhaitez vraiment les transformer en une plage de style IMAP. 
my @list  = (5..9, 13..38, 55,56,57);
my $short = $imap->list2range(@list);
# $short contient maintenant : 5:9,13:38,55:57
range2list
Pratiquement l'inverse de "list2range". 
my @list = $imap->range2list("1,3,5:9");
# @list contient (1,3,5,6,7,8,9);

RECHERCHE

search
Cette fonction retourne un tableau de numéros de message (en contexte de liste) ou le nombre de messages correspondants (en contexte scalaire). Elle prend un seul argument : la recherche.

La recherche IMAP peut être un peu déroutante et cette fonction ne fait aucune tentative pour analyser vos recherches. Si vous souhaitez effectuer des recherches manuellement, veuillez consulter le RFC 3501.

Le tri IMAP (voir RFC 5256) est pris en charge via un deuxième argument optionnel. Le RFC exige que le jeu de caractères soit spécifié, ce qui peut être fourni via le troisième argument optionnel (par défaut à UTF-8).

Voici quelques exemples :

my @ids = $imap->search("UNSEEN");
my @ids = $imap->search('SUBJECT "blarg est \"blarg\""');
my @ids = $imap->search('FROM "joe@aol.com"');
my @ids = $imap->search("DELETED");
# exemple du RFC 3501, les termes de recherche sont liés par AND
my @ids = $imap->search('FLAGGED SINCE 1-Feb-1994 NOT FROM "Smith"');
# exemple du RFC 3501, les termes de recherche sont liés par OR
my @ids = $imap->search('OR BODY "blard" SUBJECT "blarg"');
# signalé et ( depuis x ou !de y ) :
my @ids = $imap->search('FLAGGED OR SINCE x NOT FROM "y"');
  # pas de faute de frappe ci-dessus, voir le RFC
# exemple du RFC 5256, trié par sujet et date inversée
my @ids = $imap->search('BODY "zaphod"', 'SUBJECT REVERSE DATE');

Comme ce module est conçu pour être simple, Net::IMAP::Simple dispose de quelques assistants de recherche. Si vous avez besoin de logique booléenne complexe et d'autres choses, vous devrez apprendre la recherche. Si vous avez besoin d'une recherche rapide des messages non lus, voir ci-dessous.

Toutes ces fonctions retournent un tableau de messages ou un compte de messages, exactement comme le fait la fonction de recherche. Certaines prennent des arguments, d'autres non. Elles essaient de comprendre légèrement vos arguments, la mécanique de ceci (le cas échéant) sera mentionnée ci-dessous.
