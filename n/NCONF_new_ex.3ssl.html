NCONF_new_ex(3ssl)

Paquet: openssl

Licences: Apache-2.0

NCONF_NEW_EX(3ssl) OpenSSL NCONF_NEW_EX(3ssl)

NOM

NCONF_new_ex, NCONF_new, NCONF_free, NCONF_default, NCONF_load, NCONF_get0_libctx, NCONF_get_section, NCONF_get_section_names - fonctionnalité pour charger et analyser les fichiers de configuration manuellement

SYNTAXE

#include <openssl/conf.h>
typedef struct {
    char *section;
    char *name;
    char *value;
} CONF_VALUE;
CONF *NCONF_new_ex(OSSL_LIB_CTX *libctx, CONF_METHOD *meth);
CONF *NCONF_new(CONF_METHOD *meth);
void NCONF_free(CONF *conf);
CONF_METHOD *NCONF_default(void);
int NCONF_load(CONF *conf, const char *file, long *eline);
OSSL_LIB_CTX *NCONF_get0_libctx(const CONF *conf);
STACK_OF(CONF_VALUE) *NCONF_get_section(const CONF *conf, const char *name);
STACK_OF(OPENSSL_CSTRING) *NCONF_get_section_names(const CONF *conf);

DESCRIPTION

NCONF_new_ex() crée un nouvel objet CONF dans la mémoire du tas et lui assigne un contexte libctx qui peut être utilisé lors du chargement. Si la table de méthodes meth est définie à NULL, la valeur par défaut de NCONF_default() est utilisée.

NCONF_new() est similaire à NCONF_new_ex() mais définit libctx à NULL.

NCONF_free() libère les données associées à conf puis libère l'objet conf. Si l'argument est NULL, rien n'est fait.

NCONF_load() analyse le fichier nommé filename et ajoute les valeurs trouvées à conf. En cas d'erreur, file et eline indiquent le fichier et la ligne où le chargement a échoué s'ils ne sont pas NULL.

NCONF_default() récupère la table de méthodes par défaut pour le traitement d'un fichier de configuration.

NCONF_get0_libctx() récupère le contexte de bibliothèque associé au paramètre conf.

NCONF_get_section_names() récupère les noms des sections associées à conf sous forme de chaînes STACK_OF(OPENSSL_CSTRING). Les chaînes individuelles sont associées à conf et deviendront invalides après que conf soit libéré. La pile retournée doit être libérée avec sk_OPENSSL_CSTRING_free().

NCONF_get_section() récupère les valeurs de configuration associées à conf de la section de configuration name sous forme de structures STACK_OF(CONF_VALUE). La pile retournée est associée à conf et deviendra invalide après que conf soit libéré. Elle ne doit pas être libérée par l'appelant.

VALEURS DE RETOUR

NCONF_load() retourne 1 en cas de succès ou 0 en cas d'erreur.

NCONF_new_ex() et NCONF_new() retournent un objet CONF nouvellement créé ou NULL en cas d'erreur.

HISTORIQUE

NCONF_new_ex(), NCONF_get0_libctx(), et NCONF_get_section_names() ont été ajoutés dans OpenSSL 3.0.
