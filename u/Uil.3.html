Uil(library call) Uil(library call)

NOM

Uil — Appelle le compilateur UIL depuis une application

SYNTAXE

#include <uil/UilDef.h>

Uil_status_type Uil(
Uil_command_type *command_desc,
Uil_compile_desc_type **compile_desc,
Uil_continue_type (*message_cb) (),
char *message_data,
Uil_continue_type (*status_cb) (),
char *status_data);

DESCRIPTION

La fonction Uil fournit un point d'entrée appelable pour le compilateur UIL. L'interface appelable Uil peut être utilisée pour traiter un fichier source UIL et générer des fichiers UID, ainsi que pour retourner une description détaillée du module source UIL sous la forme d'une table des symboles (arbre d'analyse syntaxique).

command_desc
Spécifie la ligne de commande uil.
compile_desc
Retourne les résultats de la compilation.
message_cb
Spécifie une fonction de rappel qui est appelée lorsque le compilateur rencontre des erreurs dans la source UIL.
message_data
Spécifie des données utilisateur qui sont transmises à la fonction de rappel de message (message_cb). Notez que cet argument n'est pas interprété par UIL et est utilisé exclusivement par l'application appelante.
status_cb
Spécifie une fonction de rappel qui est appelée pour permettre aux applications X de gérer les événements X tels que la mise à jour de l'écran. Cette fonction est appelée à divers points de contrôle, qui sont codés en dur dans le compilateur UIL. L'argument status_update_delay dans command_desc spécifie le nombre de points de contrôle à passer avant que la fonction status_cb ne soit invoquée.
status_data
Spécifie des données utilisateur qui sont transmises à la fonction de rappel de statut (status_cb). Notez que cet argument n'est pas interprété par le compilateur UIL et est utilisé exclusivement par l'application appelante.

Voici les structures de données Uil_command_type et Uil_compile_desc_type :

typedef struct Uil_command_type {
char *source_file;
    /* source unique à compiler */
char *resource_file; /* nom du fichier de sortie */

    /* nombre de répertoires dans include_dir */

    /* répertoire à rechercher pour les fichiers inclus */

    /* produire une liste */
unsigned resource_file_flag: 1;
    /* générer la sortie UID */
unsigned machine_code_flag: 1;
    /* générer du code machine */
unsigned report_info_msg_flag: 1;
    /* rapporter les messages d'information */
unsigned report_warn_msg_flag: 1;
    /* rapporter les avertissements */
unsigned parse_tree_flag: 1;
    /* générer l'arbre d'analyse syntaxique */
unsigned int status_update_delay;
    /* nombre de fois où un point de statut est */
    /* passé avant d'appeler status_cb */
    /* fonction 0 signifie appelée à chaque fois */
char *database;
    /* nom du fichier de base de données */
unsigned database_flag: 1;
    /* lire un nouveau fichier de base de données */

    /* activer les appels à setlocale */

/* tableau de comptes de gravité */
};

Voici une description de la fonction de rappel de message spécifiée par message_cb :

Uil_continue_type (*message_cb) (message_data, message_number, severity, msg_buffer,
src_buffer, ptr_buffer, loc_buffer, message_count)
        char *message_data;
        int message_number;
        int severity;
        char *msg_buffer, *src_buffer;
        char *ptr_buffer, *loc_buffer;
        int message_count[];

Cette fonction spécifie une fonction de rappel que UIL invoque au lieu d'imprimer un message d'erreur lorsque le compilateur rencontre une erreur dans la source UIL. Le rappel doit retourner l'une des valeurs suivantes :

Uil_k_terminate
Terminer le traitement du fichier source
Uil_k_continue
Continuer le traitement du fichier source

Les arguments sont :

message_data
Données fournies par l'application comme argument message_data à la fonction Uil. UIL n'interprète pas ces données ; il les transmet simplement au rappel.
message_number
Un index dans une table de messages d'erreur et de gravités pour usage interne par UIL.
severity
Un entier qui indique la gravité de l'erreur. Les valeurs possibles sont les constantes de statut retournées par la fonction Uil. Voir Valeur de retour pour plus d'informations.
msg_buffer
Une chaîne qui décrit l'erreur.
src_buffer
Une chaîne composée de la ligne source où l'erreur s'est produite. Cette chaîne n'est pas toujours disponible. Dans ce cas, l'argument est NULL.
ptr_buffer
Une chaîne composée d'espaces et d'un caractère imprimable à la position de caractère correspondant à la colonne de la ligne source où l'erreur s'est produite. Cette chaîne peut être imprimée sous la ligne source pour indiquer visuellement la colonne où l'erreur s'est produite. Cette chaîne n'est pas toujours disponible. Dans ce cas, l'argument est NULL.
loc_buffer
Une chaîne identifiant le numéro de ligne et le fichier de la ligne source où l'erreur s'est produite. Ceci n'est pas toujours disponible ; l'argument est alors NULL.
message_count
Un tableau d'entiers contenant le nombre de messages de diagnostic émis jusqu'à présent pour chaque niveau de gravité. Pour connaître le nombre de messages émis pour le niveau de gravité actuel, utilisez l'argument severity comme index dans ce tableau.

Uil_continue_type (*status_cb) (status_data, percent_complete,
        lines_processed, current_file, message_count)
        char *status_data;
        int percent_complete;
        int lines_processed;
        char *current_file;
        int message_count[];

Cette fonction spécifie une fonction de rappel qui est invoquée pour permettre aux applications X de gérer les événements X tels que la mise à jour de l'écran. Le rappel doit retourner l'une des valeurs suivantes :

Uil_k_terminate
Terminer le traitement du fichier source
Uil_k_continue
Continuer le traitement du fichier source

Les arguments sont :

status_data
Données fournies par l'application comme argument status_data à la fonction Uil. UIL n'interprète pas ces données.
n'importe quelle manière ; il le transmet simplement au rappel.
percent_complete
Un entier indiquant quel pourcentage du fichier source actuel a été traité jusqu'à présent.
lines_processed
Un entier indiquant combien de lignes du fichier source actuel ont été lues jusqu'à présent.
current_file
Une chaîne contenant le chemin du fichier source actuel.
message_count
Un tableau d'entiers contenant le nombre de messages de diagnostic émis jusqu'à présent pour chaque niveau de sévérité. Pour trouver le nombre de messages émis pour un niveau de sévérité donné, utilisez le niveau de sévérité comme indice dans ce tableau. Les niveaux de sévérité possibles sont les constantes de statut retournées par la fonction Uil. Voir Valeur de retour pour plus d'informations.

VALEUR DE RETOUR

Cette fonction retourne l'une des constantes de retour de statut suivantes :

Uil_k_success_status
L'opération a réussi.
Uil_k_info_status
L'opération a réussi. Un message informatif est retourné.
Uil_k_warning_status
L'opération a réussi. Un message d'avertissement est retourné.
Uil_k_error_status
L'opération a échoué en raison d'une erreur.
Uil_k_severe_status
L'opération a échoué en raison d'une erreur.
