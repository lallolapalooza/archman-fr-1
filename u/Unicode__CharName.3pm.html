NOM

Unicode::CharName - Rechercher les noms de caractères Unicode

SYNTAXE

use Unicode::CharName qw(uname ublock);
print uname(ord('%')), "\n";
print ublock(0x0300), "\n";

DESCRIPTION

Ce module fournit deux fonctions nommées uname() et ublock(). La fonction uname() renverra le nom du caractère Unicode pour le code donné (un nombre compris entre 0 et 0x10FFFF). Les noms de caractères Unicode sont écrits en lettres ASCII majuscules, et sont des chaînes comme :

LATIN CAPITAL LETTER A
LATIN SMALL LETTER A WITH RING ABOVE
CJK UNIFIED IDEOGRAPH 7C80
HANGUL SYLLABLE PWILH

La fonction ublock() renverra le nom du bloc de caractères Unicode auquel appartient le caractère donné.
