UFFDIO_CONTINUE(2const) UFFDIO_CONTINUE(2const)

NOM

UFFDIO_CONTINUE - résoudre une faute de page mineure

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/userfaultfd.h>  /* Définition des constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_CONTINUE, struct uffdio_continue *argp);
#include <linux/userfaultfd.h>
struct uffdio_continue {
    struct uffdio_range  range;
                     /* Plage pour installer les PTE et continuer */
    __u64   mode;    /* Indicateurs contrôlant le comportement de continue */
    __s64   mapped;  /* Nombre d'octets mappés, ou erreur négative */
};

DESCRIPTION

Résout une faute de page mineure en installant des entrées de table de pages pour des pages existantes dans le cache de pages.

La valeur suivante peut être combinée par OU logique dans mode pour modifier le comportement de l'opération UFFDIO_CONTINUE :

UFFDIO_CONTINUE_MODE_DONTWAKE
Ne pas réveiller le thread qui attend la résolution de la faute de page.

Le champ mapped est utilisé par le noyau pour retourner le nombre d'octets qui ont été effectivement mappés, ou une erreur de la même manière que UFFDIO_COPY. Si la valeur retournée dans le champ mapped ne correspond pas à la valeur spécifiée dans range.len, l'opération échoue avec l'erreur EAGAIN. Le champ mapped est en sortie seule ; il n'est pas lu par l'opération UFFDIO_CONTINUE.

VALEUR RENVOYÉE

Cette opération ioctl(2) renvoie 0 en cas de succès. Dans ce cas, toute la zone a été mappée. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EAGAIN
Le nombre d'octets mappés (c'est-à-dire la valeur renvoyée dans le champ mapped) n'est pas égal à la valeur spécifiée dans le champ range.len.
EEXIST
Une ou plusieurs pages étaient déjà mappées dans la plage donnée.
EFAULT
Aucune page existante n'a pu être trouvée dans le cache de pages pour la plage donnée.
EINVAL
Soit range.start, soit range.len n'était pas un multiple de la taille de page système ; soit range.len était zéro ; soit la plage spécifiée était invalide.
EINVAL
Un indicateur invalide a été spécifié dans le champ mode.
ENOENT
Le processus de faute a modifié sa disposition de mémoire virtuelle simultanément avec une opération UFFDIO_CONTINUE en attente.
ENOMEM
L'allocation de mémoire nécessaire pour configurer les mappages de table de pages a échoué.
ESRCH
Le processus de faute s'est terminé au moment d'une opération UFFDIO_CONTINUE.

NORMES

Linux.

HISTORIQUE

Linux 5.13.

EXEMPLES

Voir userfaultfd(2).
