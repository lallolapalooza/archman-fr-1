NOM

URI::data - URI contenant des données immédiates

SYNTAXE

use URI;
$u = URI->new("data:");
$u->media_type("image/gif");
$u->data(scalar(`cat camel.gif`));
print "$u\n";
open(XV, "|xv -") and print XV $u->data;

DESCRIPTION

La classe "URI::data" prend en charge les objets "URI" appartenant au schéma d'URI data. Le schéma d'URI data est spécifié dans la RFC 2397. Il permet l'inclusion de petits éléments de données sous forme de données "immédiates", comme s'ils avaient été inclus en externe. Exemples :

data:,Perl%20is%20good
data:image/gif;base64,R0lGODdhIAAgAIAAAAAAAPj8+CwAAAAAI
  AAgAAAClYyPqcu9AJyCjtIKc5w5xP14xgeO2tlY3nWcajmZZdeJcG
  Kxrmimms1KMTa1Wg8UROx4MNUq1HrycMjHT9b6xKxaFLM6VRKzI+p
  KS9XtXpcbdun6uWVxJXA8pNPkdkkxhxc21LZHFOgD2KMoQXa2KMWI
  JtnE2KizVUkYJVZZ1nczBxXlFopZBtoJ2diXGdNUymmJdFMAADs=

"URI" objets appartenant au schéma data prennent en charge les méthodes communes (décrites dans URI) et les deux méthodes spécifiques au schéma suivantes :

$uri->media_type( [$nouveau_media_type] )
Peut être utilisé pour obtenir ou définir le type de média spécifié dans l'URI. Si aucun type de média n'est spécifié, alors le type par défaut "text/plain;charset=US-ASCII" est retourné.
$uri->data( [$nouvelles_donnees] )
Peut être utilisé pour obtenir ou définir les données contenues dans l'URI. Les données sont passées sans être échappées (sous forme binaire). La décision de savoir si les données doivent être encodées en base64 dans l'URI est prise automatiquement, en fonction de l'encodage qui produit la chaîne URI la plus courte.
