NOM

URI::smb - Schéma d'URI Samba/CIFS

SYNOPIS

my $uri = URI->new('smb://authdomain;user:password@server/share/path');

DESCRIPTION

Ce module implémente le schéma d'URI (non officiel) "smb:" décrit dans http://www.ubiqx.org/cifs/Appendix-D.html.

SOUS-ROUTINES/METHODES

port_par_défaut

Le port par défaut pour accéder aux serveurs de fichiers Samba/Windows est 445

utilisateur

Obtenir ou définir la partie utilisateur de l'URI (sans le domaine d'authentification)

domaine_authentification

Obtenir ou définir la partie domaine d'authentification de l'URI. Cette valeur n'est disponible que si l'utilisateur est déjà défini.

nom_partage

Méthode d'aide pour obtenir le nom du partage à partir du chemin

DÉPENDANCES

Aucune
