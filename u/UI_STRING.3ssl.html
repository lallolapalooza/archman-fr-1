UI_STRING(3ssl) OpenSSL UI_STRING(3ssl)

NOM

UI_STRING, UI_string_types, UI_get_string_type, UI_get_input_flags, UI_get0_output_string, UI_get0_action_string, UI_get0_result_string, UI_get_result_string_length, UI_get0_test_string, UI_get_result_minsize, UI_get_result_maxsize, UI_set_result, UI_set_result_ex - Analyse de chaînes d'interface utilisateur

SYNOPSIS

#include <openssl/ui.h>
typedef struct ui_string_st UI_STRING;
enum UI_string_types {
    UIT_NONE = 0,
    UIT_PROMPT,                 /* Invite à saisir une chaîne */
    UIT_VERIFY,                 /* Invite à saisir une chaîne et à vérifier */
    UIT_BOOLEAN,                /* Invite à répondre par oui/non */
    UIT_INFO,                   /* Envoyer des informations à l'utilisateur */
    UIT_ERROR                   /* Envoyer un message d'erreur à l'utilisateur */
};
enum UI_string_types UI_get_string_type(UI_STRING *uis);
int UI_get_input_flags(UI_STRING *uis);
const char *UI_get0_output_string(UI_STRING *uis);
const char *UI_get0_action_string(UI_STRING *uis);
const char *UI_get0_result_string(UI_STRING *uis);
int UI_get_result_string_length(UI_STRING *uis);
const char *UI_get0_test_string(UI_STRING *uis);
int UI_get_result_minsize(UI_STRING *uis);
int UI_get_result_maxsize(UI_STRING *uis);
int UI_set_result(UI *ui, UI_STRING *uis, const char *result);
int UI_set_result_ex(UI *ui, UI_STRING *uis, const char *result, int len);

DESCRIPTION

La structure UI_STRING est créée en interne et ajoutée à un objet UI chaque fois que l'une des fonctions UI_add_input_string(), UI_dup_input_string(), UI_add_verify_string(), UI_dup_verify_string(), UI_add_input_boolean(), UI_dup_input_boolean(), UI_add_info_string(), UI_dup_info_string(), UI_add_error_string() ou UI_dup_error_string() est appelée. Pour un utilisateur de UI_METHOD, il n'est pas nécessaire d'en savoir plus. Pour un créateur de UI_METHOD, il est intéressant de récupérer du texte à partir de ces objets UI_STRING ainsi que d'ajouter des résultats à certains d'entre eux.

UI_get_string_type() est utilisée pour récupérer le type de la UI_STRING donnée.

UI_get_input_flags() est utilisée pour récupérer les indicateurs associés à la UI_STRING donnée.

UI_get0_output_string() est utilisée pour récupérer la chaîne réelle à afficher (invite, information, erreur, ...).

UI_get0_action_string() est utilisée pour récupérer la description de l'action associée à une UI_STRING de type UIT_BOOLEAN. Pour tous les autres types de UI_STRING, NULL est renvoyé. Voir UI_add_input_boolean(3).

UI_get0_result_string() et UI_get_result_string_length() sont utilisées pour récupérer le résultat d'une invite et sa longueur. Ceci est uniquement utile pour les chaînes de type UIT_PROMPT et UIT_VERIFY. Pour tous les autres types de UI_STRING, UI_get0_result_string() renvoie NULL et UI_get_result_string_length() renvoie -1.

UI_get0_test_string() est utilisée pour récupérer la chaîne avec laquelle comparer le résultat de l'invite. Ceci est uniquement utile pour les chaînes de type UIT_VERIFY. Pour tous les autres types de UI_STRING, NULL est renvoyé.

UI_get_result_minsize() et UI_get_result_maxsize() sont utilisées pour récupérer la taille minimale et maximale requise du résultat. Ceci est uniquement utile pour les chaînes de type UIT_PROMPT et UIT_VERIFY. Pour tous les autres types de UI_STRING, -1 est renvoyé.

UI_set_result_ex() est utilisée pour définir la valeur du résultat d'une invite et sa longueur. Pour les chaînes d'interface utilisateur de type UIT_PROMPT et UIT_VERIFY, cela définit le résultat récupérable avec UI_get0_result_string() en copiant le contenu de result si sa longueur correspond aux exigences de taille minimale et maximale. Pour les chaînes d'interface utilisateur de type UIT_BOOLEAN, cela définit le premier caractère du résultat récupérable avec UI_get0_result_string() avec le premier caractère ok_char fourni avec UI_add_input_boolean() ou UI_dup_input_boolean() si le result correspondait à l'un d'entre eux, ou le premier des cancel_chars si le result correspondait à l'un d'entre eux, sinon il est défini sur le caractère NUL "\0". Voir UI_add_input_boolean(3) pour plus d'informations sur ok_chars et cancel_chars.

UI_set_result() fait la même chose que UI_set_result_ex(), mais calcule sa longueur en interne. Elle attend que la chaîne se termine par un octet NUL, et est donc utile uniquement avec des chaînes C normales.

VALEUR DE RETOUR

UI_get_string_type() renvoie le type de chaîne d'interface utilisateur.

UI_get_input_flags() renvoie les indicateurs de chaîne d'interface utilisateur.

UI_get0_output_string() renvoie la chaîne de sortie de chaîne d'interface utilisateur.

UI_get0_action_string() renvoie la chaîne de description de l'action pour les chaînes d'interface utilisateur de type UIT_BOOLEAN, NULL pour tout autre type.

UI_get0_result_string() renvoie le tampon de résultat de chaîne d'interface utilisateur pour les chaînes d'interface utilisateur de type UIT_PROMPT et UIT_VERIFY, NULL pour tout autre type.

UI_get_result_string_length() renvoie la longueur du contenu du tampon de résultat de chaîne d'interface utilisateur pour les chaînes d'interface utilisateur de type UIT_PROMPT et UIT_VERIFY, -1 pour tout autre type.

UI_get0_test_string() renvoie la chaîne de description de l'action pour les chaînes d'interface utilisateur de type UIT_VERIFY, NULL pour tout autre type.

UI_get_result_minsize() renvoie la taille minimale de résultat autorisée pour la chaîne d'interface utilisateur pour les chaînes de type UIT_PROMPT et UIT_VERIFY, -1 pour tout autre type.

UI_get_result_maxsize() renvoie la taille minimale de résultat autorisée pour la chaîne d'interface utilisateur pour les chaînes de type UIT_PROMPT et UIT_VERIFY, -1 pour tout autre type.

UI_set_result() renvoie 0 en cas de succès ou lorsque la chaîne d'interface utilisateur est d'un type autre que UIT_PROMPT, UIT_VERIFY ou UIT_BOOLEAN, -1 en cas d'erreur.

Gestionnaire de Paquets Linux

Gestionnaire de Paquets Linux

Un gestionnaire de paquets est une collection d'outils qui automatisent le processus d'installation, de mise à niveau, de configuration et de suppression des logiciels sur un système d'exploitation informatique. Dans le contexte de Linux, les gestionnaires de paquets sont essentiels pour maintenir le système à jour et installer de nouvelles applications.

Fonctionnalités clés :

  • Installation de logiciels : Télécharge et installe des programmes et leurs dépendances.
  • Mise à jour de logiciels : Vérifie les nouvelles versions des paquets installés et les met à jour.
  • Suppression de logiciels : Désinstalle proprement les programmes et leurs fichiers associés.
  • Gestion des dépendances : S'assure que tous les logiciels requis par un programme sont présents et compatibles.
  • Référentiels (Repositories) : Sources centralisées où les paquets sont stockés et organisés.

Exemples populaires de gestionnaires de paquets Linux :

  • APT (Advanced Package Tool) : Utilisé par les distributions basées sur Debian, comme Ubuntu et Linux Mint. Commandes courantes : apt update, apt install , apt remove .
  • DNF (Dandified YUM) : Le successeur de YUM, utilisé par Fedora, CentOS Stream et RHEL. Commandes courantes : dnf check-update, dnf install , dnf remove .
  • Pacman : Utilisé par Arch Linux et ses dérivés. Commandes courantes : pacman -Syu, pacman -S , pacman -R .
  • Zypper : Utilisé par openSUSE. Commandes courantes : zypper refresh, zypper install , zypper remove .

L'utilisation d'un gestionnaire de paquets simplifie grandement la maintenance d'un système Linux et permet aux utilisateurs d'accéder facilement à une vaste bibliothèque de logiciels.

Comprendre le fonctionnement d'un gestionnaire de paquets est fondamental pour tout utilisateur de Linux.
