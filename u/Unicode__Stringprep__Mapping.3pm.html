Unicode::Stringprep::Mapping(3pm) Documentation Perl fournie par l'utilisateur Unicode::Stringprep::Mapping(3pm)

NOM

Unicode::Stringprep::Mapping - Tables de la RFC 3454, Annexe B

SYNTAXE

@Unicode::Stringprep::Mapping::B1     # Annexe B.1
@Unicode::Stringprep::Mapping::B2     # Annexe B.2
@Unicode::Stringprep::Mapping::B3     # Annexe B.3

DESCRIPTION

Les tables sont fournies sous forme de tableaux, qui contiennent des paires d'un point de code Unicode (sous forme d'entier) et d'une chaîne de remplacement (sous forme de chaîne perl UTF8).

Ce module n'exporte rien.
