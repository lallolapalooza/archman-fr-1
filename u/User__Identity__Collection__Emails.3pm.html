NOM

User::Identity::Collection::Emails - une collection de rôles d'e-mail

HÉRÉDITÉ

User::Identity::Collection::Emails
  est un User::Identity::Collection
  est un User::Identity::Item

SYNTAXE

DESCRIPTION

L'objet "User::Identity::Collection::Emails" maintient un ensemble d'objets Mail::Identity, chacun décrivant un rôle que l'utilisateur a dans le trafic d'e-mails.

DIAGNOSTICS

Erreur : $objet n'est pas une collection.
Le premier argument est un objet, mais pas d'une classe qui étend User::Identity::Collection. Lancé par addCollection()
Erreur : Impossible de créer un $type à ajouter à ma collection.
Certaines options sont spécifiées pour créer un objet $type, qui est natif à cette collection. Cependant, pour une raison quelconque, cela a échoué. Lancé par addRole()
Erreur : Impossible de charger le module de collection pour $type ($class).
Soit le $type spécifié n'existe pas, soit le module nommé $class renvoie des erreurs de compilation. Si le type spécifié dans l'avertissement n'est pas le nom d'un paquet, vous avez spécifié un pseudonyme qui n'était pas défini. Peut-être avez-vous oublié d'appeler 'require' pour le paquet qui définit le pseudonyme. Lancé par addCollection()
Erreur : Impossible de renommer $name en $newname : existe déjà
Lancé par renameRole()
Erreur : Impossible de renommer $name en $newname : n'existe pas
Lancé par renameRole()
Erreur : La création d'une collection via $class a échoué.
La classe $class a compilé, mais il n'a pas été possible de créer un objet de cette classe en utilisant les options que vous avez spécifiées. Lancé par addCollection()
Erreur : Je ne sais pas quel type de collection vous voulez ajouter.
Si vous ajoutez une collection, ce doit être soit un objet de collection, soit une liste d'options qui peuvent être utilisées pour créer un objet de collection. Dans ce dernier cas, le type de collection doit être spécifié. Lancé par addCollection()
Avertissement : Pas de collection $name
La collection avec $name n'existe pas et ne peut pas être créée. Lancé par add()
Erreur : Mauvais type de rôle pour $collection : attend un $expect mais a reçu un $type
Chaque $collection regroupe des ensembles de rôles d'un type spécifique ($expect). Vous ne pouvez pas ajouter d'objets d'un $type différent. Lancé par addRole()
