NOM

Unicode::String - Chaîne de caractères Unicode (UTF-16BE)

SYNOPSIS

use Unicode::String qw(utf8 latin1 utf16be);
$u = utf8("chaîne");
$u = latin1("chaîne");
$u = utf16be("\0c\0h\0a\0i\0n\0e");
print $u->utf32be;   # Caractères de 4 octets
print $u->utf16le;   # Caractères de 2 octets + substituts
print $u->utf8;      # Caractères de 1 à 4 octets

DESCRIPTION

Un objet "Unicode::String" représente une séquence de caractères Unicode. Des méthodes sont fournies pour convertir entre divers formats externes (encodages) et des objets "Unicode::String", ainsi que des méthodes pour les manipulations courantes de chaînes.

Les fonctions utf32be(), utf32le(), utf16be(), utf16le(), utf8(), utf7(), latin1(), uhex(), uchr() peuvent être importées du module "Unicode::String" et fonctionneront comme des constructeurs initialisant des chaînes de l'encodage correspondant.

Les objets "Unicode::String" surchargent divers opérateurs, ce qui signifie que dans la plupart des cas, ils peuvent être traités comme des chaînes ordinaires.

Internelement, un objet "Unicode::String" est représenté par une chaîne de nombres de 2 octets en ordre d'octets réseau (big-endian). Cette représentation n'est pas visible via l'API fournie, mais elle peut être utile pour prédire l'efficacité des méthodes proposées.

MÉTHODES

Méthodes de classe

Les méthodes de classe suivantes sont disponibles :

Unicode::String->stringify_as
Unicode::String->stringify_as( $enc )
Cette méthode est utilisée pour spécifier quel encodage sera utilisé lorsque les objets "Unicode::String" sont implicitement convertis en et depuis des chaînes ordinaires.

Si un argument est fourni, il définit l'encodage courant. L'argument doit être l'une des valeurs suivantes : "ucs4", "utf32", "utf32be", "utf32le", "ucs2", "utf16", "utf16be", "utf16le", "utf8", "utf7", "latin1" ou "hex". La valeur par défaut est "utf8".

La méthode stringify_as() renvoie une référence à la fonction d'encodage courante.

$us = Unicode::String->new
$us = Unicode::String->new( $initial_value )
C'est le constructeur d'objet. Sans argument, il crée un objet "Unicode::String" vide. Si un argument $initial_value est donné, il est décodé selon l'encodage spécifié par stringify_as(), UTF-8 par défaut.

En général, il est recommandé d'importer et d'utiliser l'une des fonctions de constructeur spécifiques à l'encodage au lieu d'appeler cette méthode.

Méthodes d'encodage

Ces méthodes obtiennent ou définissent la valeur de l'objet "Unicode::String" en passant des chaînes dans l'encodage correspondant. Si une nouvelle valeur est passée en argument, elle définira la valeur de l'"Unicode::String", et la valeur précédente sera retournée. Si aucun argument n'est passé, la valeur courante est retournée.

Pour illustrer les encodages, nous montrons comment la chaîne échantillon de 2 caractères "µm" (mètre micrométrique) est encodée pour chacun d'eux.

$us->utf32be
$us->utf32be( $newval )
La chaîne passée doit être en encodage UTF-32 avec les octets en ordre big-endian. L'échantillon "µm" est "\0\0\0\xB5\0\0\0m" dans cet encodage.

Les noms alternatifs pour cette méthode sont utf32() et ucs4().

$us->utf32le
$us->utf32le( $newval )
La chaîne passée doit être en encodage UTF-32 avec les octets en ordre little-endian. L'échantillon "µm" est "\xB5\0\0\0m\0\0\0" dans cet encodage.
$us->utf16be
$us->utf16be( $newval )
La chaîne passée doit être en encodage UTF-16 avec les octets en ordre big-endian. L'échantillon "µm" est "\0\xB5\0m" dans cet encodage.

Les noms alternatifs pour cette méthode sont utf16() et ucs2().

Si la chaîne passée à utf16be() commence par le marqueur d'ordre des octets Unicode en little-endian, le résultat est comme si utf16le() avait été appelé.

$us->utf16le
$us->utf16le( $newval )
La chaîne passée doit être en encodage UTF-16 avec les octets en ordre little-endian. L'échantillon "µm" est "\xB5\0m\0" dans cet encodage. C'est l'encodage utilisé par l'API de Microsoft Windows.

Si la chaîne passée à utf16le() commence par le marqueur d'ordre des octets Unicode en big-endian, le résultat est comme si utf16le() avait été appelé.

$us->utf8
$us->utf8( $newval )
La chaîne passée doit être en encodage UTF-8. L'échantillon "µm" est "\xC2\xB5m" dans cet encodage.
$us->utf7
$us->utf7( $newval )
La chaîne passée doit être en encodage UTF-7. L'échantillon "µm" est "+ALU-m" dans cet encodage.

L'encodage UTF-7 n'utilise que des caractères US-ASCII ordinaires pour l'encodage. Cela le rend sûr pour le transport via des protocoles qui dépouillent les 8 bits. Les caractères en dehors de la plage US-ASCII sont encodés en base64 et '+' est utilisé comme caractère d'échappement. L'encodage UTF-7 est décrit dans la RFC 1642.

Si la variable (globale) $Unicode::String::UTF7_OPTIONAL_DIRECT_CHARS est TRUE, alors une plus large gamme de caractères sont encodés tels quels. Elle est même TRUE par défaut. Les caractères affectés par cela sont :

! " # $ % & * ; < = > @ [ ] ^ _ ` { | }
$us->latin1
$us->latin1( $newval )
La chaîne passée doit être en encodage ISO-8859-1. L'échantillon "µm" est "\xB5m" dans cet encodage.

Les caractères en dehors de la plage "\x00" .. "\xFF" sont simplement supprimés de la valeur de retour de la méthode latin1(). Si vous souhaitez un meilleur contrôle sur la correspondance entre Unicode et ISO-8859-1, utilisez la classe "Unicode::Map8". C'est aussi la manière de gérer les autres jeux de caractères 8 bits.

$us->hex
$us->hex( $newval )
La chaîne passée doit être en ASCII pur où chaque caractère Unicode est représenté par la chaîne "U+XXXX" et séparé par un seul espace. Le préfixe "U+" est optionnel lors de la définition de la valeur. L'échantillon "µm" est "U+00b5 U+006d" dans cet encodage.

Opérations sur les chaînes

Les méthodes suivantes sont disponibles :

$us->as_string
Convertit un "Unicode::String" en une chaîne ordinaire selon le réglage de stringify_as(). L'encodage par défaut de stringify_as() est "utf8".
$us->as_num
Convertit un "Unicode::String" en un nombre. Actuellement, seuls les chiffres dans la plage 0x30 .. 0x39 sont reconnus. Il est prévu de prendre en charge à terme tous les caractères de chiffre Unicode.
$us->as_bool
Convertit un "Unicode::String" en une valeur booléenne. Seule la chaîne vide est FAUX. Une chaîne composée uniquement du caractère U+0030 est considérée comme VRAI, même si Perl considère "0" comme FAUX.
$us->repeat( $count )
Renvoie un nouvel objet "Unicode::String" où le contenu de $us est répété $count fois. Cette opération est également surchargée comme suit : 
$us x $count
$us->concat( $other_string )

MÉTHODES

$us->concat( $other_string )
Concatène la chaîne $us et la chaîne $other_string. Si $other_string n'est pas un objet "Unicode::String", il est d'abord passé à la fonction constructeur Unicode::String->new. Cette opération est également surchargée comme suit : 
$us . $other_string
$us->append( $other_string )
Ajoute la chaîne $other_string à la valeur de $us. Si $other_string n'est pas un objet "Unicode::String", il est d'abord passé à la fonction constructeur Unicode::String->new. Cette opération est également surchargée comme suit : 
$us .= $other_string
$us->copy
Retourne une copie de l'objet "Unicode::String" actuel. Cette opération est surchargée par l'opérateur d'affectation.
$us->length
Retourne la longueur de la "Unicode::String". Les paires de substitution sont toujours comptées comme 2.
$us->byteswap
Cette méthode échangera les octets dans la représentation interne de l'objet "Unicode::String".

Unicode réserve le caractère U+FEFF comme marque d'ordre des octets. Cela fonctionne car le caractère échangé, U+FFFE, est réservé pour ne pas être valide. Pour les chaînes ayant la marque d'ordre des octets comme premier caractère, nous pouvons garantir le bon ordre des octets avec le code suivant :

$ustr->byteswap if $ustr->ord == 0xFFFE;
$us->unpack
Retourne une liste d'entiers représentant chacun un code de caractère UCS-2.
$us->pack( @uchr )
Définit la valeur de $us comme une séquence de caractères UCS-2 avec les codes de caractères donnés en paramètre.
$us->ord
Retourne le code du premier caractère de $us. La méthode ord() gère les paires de substitution, ce qui nous donne une plage de résultats de 0x0 .. 0x10FFFF. Si la chaîne $us est vide, undef est retourné.
$us->chr( $code )
Définit la valeur de $us pour être une chaîne contenant le caractère dont le code est $code. L'argument $code doit être un entier dans la plage 0x0 .. 0x10FFFF. Si le code est supérieur à 0xFFFF, une paire de substitution est créée.
$us->name
En contexte scalaire, retourne le nom Unicode officiel du premier caractère de $us. En contexte de tableau, retourne le nom de tous les caractères de $us. Voir également Unicode::CharName.
$us->substr( $offset )
$us->substr( $offset, $length )
$us->substr( $offset, $length, $subst )
Retourne une sous-chaîne de $us. Fonctionne de manière similaire à la fonction intégrée substr().
$us->index( $other )
$us->index( $other, $pos )
Localise la position de $other dans $us, en commençant éventuellement la recherche à la position $pos.
$us->chop
Supprime le dernier caractère de $us et le retourne (en tant qu'objet "Unicode::String").

FONCTIONS

Les fonctions suivantes sont fournies. Aucune d'entre elles n'est exportée par défaut.

byteswap2( $str, ... )
Cette fonction échangera 2 octets par 2 octets dans les chaînes passées en arguments. Si cette fonction est appelée dans un contexte vide, elle modifiera ses arguments sur place. Sinon, les chaînes échangées seront retournées.
byteswap4( $str, ... )
La fonction byteswap4 fonctionne de manière similaire à byteswap2, mais inversera l'ordre de 4 octets par 4 octets.

Fonctions constructeurs pour les différents encodages Unicode. Elles retournent de nouveaux objets "Unicode::String". L'argument fourni doit être encodé de manière correspondante.
( $str )
Construit un nouvel objet "Unicode::String" à partir d'une chaîne de valeurs hexadécimales. Voir la méthode hex() ci-dessus pour la description du format.
( $num )
Construit un nouvel objet "Unicode::String" d'un caractère à partir d'un code de caractère Unicode. Cela fonctionne de manière similaire à la fonction intégrée chr() de Perl.
