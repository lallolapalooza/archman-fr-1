Caractères Unicode.

Depuis 4.03

type t

Le type pour les caractères Unicode.

Une valeur de ce type représente une valeur scalaire Unicode, qui est un entier dans les plages 0x0000 ... 0xD7FF ou 0xE000 ... 0x10FFFF .

val min : t

min est U+0000.

val max : t

max est U+10FFFF.

val bom : t

bom est U+FEFF, le caractère d'ordre des octets (BOM).

Depuis 4.06

val rep : t

rep est U+FFFD, le caractère de remplacement.

Depuis 4.06

val succ : t -> t

succ u est la valeur scalaire suivant u dans l'ensemble des valeurs scalaires Unicode.

Lève Invalid_argument si u est Uchar.max .

val pred : t -> t

pred u est la valeur scalaire précédant u dans l'ensemble des valeurs scalaires Unicode.

Lève Invalid_argument si u est Uchar.min .

val is_valid : int -> bool

is_valid n vaut true si et seulement si n est une valeur scalaire Unicode (c'est-à-dire dans les plages 0x0000 ... 0xD7FF ou 0xE000 ... 0x10FFFF ).

val of_int : int -> t

of_int i est i comme caractère Unicode.

Lève Invalid_argument si i ne satisfait pas Uchar.is_valid .

val to_int : t -> int

to_int u est u comme entier.

val is_char : t -> bool

is_char u vaut true si et seulement si u est un caractère OCaml latin1.

val of_char : char -> t

of_char c est c comme caractère Unicode.

val to_char : t -> char

to_char u est u comme caractère OCaml latin1.

Lève Invalid_argument si u ne satisfait pas Uchar.is_char .

val equal : t -> t -> bool

equal u u' vaut u = u' .

val compare : t -> t -> int

compare u u' vaut Stdlib.compare u u' .

val seeded_hash : int -> t -> int

seeded_hash seed u Une fonction de hachage avec germe dont la valeur de sortie est la même que Hashtbl.seeded_hash . Cette fonction permet de passer ce module en argument au foncteur Hashtbl.MakeSeeded .

Depuis 5.3

val hash : t -> int

Une fonction de hachage sans germe dont la valeur de sortie est la même que Hashtbl.hash . Cette fonction permet de passer ce module en argument au foncteur Hashtbl.Make .

Avant 5.3 L'algorithme de hachage était différent. Utilisez Hashtbl.rebuild pour les tables stockées qui utilisaient cette fonction de hachage

Outils de codage UTF

type utf_decode

Le type pour les résultats de décodage UTF. Les valeurs de ce type représentent le résultat d'une tentative de décodage au format Unicode Transformation Format.

val utf_decode_is_valid : utf_decode -> bool

utf_decode_is_valid d vaut true si et seulement si d représente un décodage valide.

val utf_decode_uchar : utf_decode -> t

utf_decode_uchar d est le caractère Unicode décodé par d si utf_decode_is_valid d vaut true, et Uchar.rep sinon.

val utf_decode_length : utf_decode -> int

utf_decode_length d est le nombre d'éléments de la source qui ont été consommés par le décodage d . Ce nombre est toujours strictement positif et inférieur ou égal à 4 . Le type des éléments sources dépend du décodeur réel ; pour les décodeurs de la bibliothèque standard, cette fonction renvoie toujours une longueur en octets.

val utf_decode : int -> t -> utf_decode

utf_decode n u est un décodage UTF valide pour u qui a consommé n éléments de la source pour le décodage. n doit être positif et inférieur ou égal à 4 (ceci n'est pas vérifié par le module).

val utf_decode_invalid : int -> utf_decode

utf_decode_invalid n est un décodage UTF invalide qui a consommé n éléments de la source pour générer une erreur. n doit être positif et inférieur ou égal à 4 (ceci n'est pas vérifié par le module). Le décodage résultant a Uchar.rep comme caractère Unicode décodé.

val utf_8_decode_length_of_byte : char -> int

utf_8_decode_length_of_byte byte est le nombre d'octets, de 1 à Uchar.max_utf_8_decode_length , qu'un décodage UTF-8 valide commençant par l'octet byte consommerait, ou 0 si byte ne peut pas commencer un décodage valide.

Depuis 5.4

val max_utf_8_decode_length : int

max_utf_8_decode_length vaut 4 , le nombre maximal d'octets qu'un décodage UTF-8 valide ou invalide peut consommer.

Depuis 5.4

val utf_8_byte_length : t -> int

utf_8_byte_length u est le nombre d'octets nécessaires pour encoder u en UTF-8.

val utf_16_byte_length : t -> int

utf_16_byte_length u est le nombre d'octets nécessaires pour encoder u en UTF-16.
