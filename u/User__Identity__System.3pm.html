NOM

User::Identity::System - système physique d'une personne

HERITAGE

User::Identity::System
  est un User::Identity::Item

SYNTAXE

use User::Identity;
use User::Identity::System;
my $moi   = User::Identity->new(...);
my $serveur = User::Identity::System->new(...);
$moi->add(system => $serveur);
# Plus simple
use User::Identity;
my $moi   = User::Identity->new(...);
my $addr = $moi->add(system => ...);

DESCRIPTION

L'objet "User::Identity::System" contient la description de la présence de l'utilisateur sur un système. Les systèmes sont collectés par un objet User::Identity::Collection::Systems.

Presque toutes les méthodes peuvent retourner "undef".

Étends "DESCRIPTION" dans User::Identity::Item.

$classe->new( [$nom], %options )
Crée un nouveau système. Vous pouvez spécifier un nom comme premier argument, ou dans la liste OPTION. Sans nom spécifique, l'organisation est utilisée comme nom. 
-Option     --Défini dans           --Défaut
 description  User::Identity::Item  undef
 hostname                           'localhost'
 location                           undef
 name         User::Identity::Item  <requis>
 os                                 undef
 parent       User::Identity::Item  undef
 password                           undef
 username                           undef
description => CHAÎNE
hostname => DOMAINE
Le nom d'hôte du système décrit. Il est préférable d'utiliser des noms de système complets, pas des abréviations. Par exemple, vous pouvez mieux utiliser "www.tux.aq" que "www" pour éviter toute confusion.
location => NOM_COURT|OBJET
Le NOM_COURT d'un emplacement défini pour le même utilisateur. Vous pouvez également spécifier un objet User::Identity::Location.
name => CHAÎNE
os => CHAÎNE
Le nom du système d'exploitation exécuté sur le serveur. Il est conseillé d'utiliser les noms tels qu'utilisés par la variable $^O de Perl. Voir la page de manuel perlvar pour cette variable, et perlport pour les valeurs possibles.
parent => OBJET
password => CHAÎNE
Le mot de passe à utiliser pour la connexion. Ce mot de passe doit être non encodé : directement utilisable. Attention, stocker des mots de passe non encodés est un risque de sécurité élevé.
username => CHAÎNE
Le nom d'utilisateur à utiliser pour se connecter à cet hôte.

DIAGNOSTICS

Erreur : $objet n'est pas une collection.
Le premier argument est un objet, mais pas d'une classe qui étend User::Identity::Collection. Lancé par addCollection()
Erreur : Impossible de charger le module de collection pour $type ($classe).
Soit le type spécifié $type n'existe pas, soit ce module nommé $classe retourne des erreurs de compilation. Si le type tel qu'indiqué dans l'avertissement n'est pas un nom de paquet, vous avez spécifié un nom court qui n'était pas défini. Peut-être avez-vous oublié le 'require' du paquet qui définit le nom court. Lancé par addCollection()
Erreur : La création d'une collection via $classe a échoué.
La classe $classe a été compilée, mais il n'a pas été possible de créer un objet de cette classe en utilisant les options que vous avez spécifiées. Lancé par addCollection()
Erreur : Je ne sais pas quel type de collection vous voulez ajouter.
Si vous ajoutez une collection, ce doit être soit un objet de collection, soit une liste d'options qui peuvent être utilisées pour créer un objet de collection. Dans ce dernier cas, le type de collection doit être spécifié. Lancé par addCollection()
Avertissement : Pas de collection $nom
La collection avec le nom $nom n'existe pas et ne peut pas être créée. Lancé par add()
