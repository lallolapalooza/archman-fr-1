Module Artifact
: sig end

Artefacts de construction

type t

Métadonnées pour un artefact de compilation unique :

- le nom du module associé à l'artefact

- le chemin du système de fichiers

- le fichier source d'entrée s'il existe

val source_file : t -> Unit_info.filename option

source_file a est le fichier source de a s'il existe.

val prefix : t -> Unit_info.file_prefix

prefix a est le préfixe du nom de fichier de l'artefact de compilation.

val filename : t -> Unit_info.filename

filename u est le chemin du système de fichiers pour un artefact de compilation.

val modname : t -> Unit_info.modname

modname a est le nom du module de l'artefact de compilation.

val from_filename : Unit_info.filename -> t

from_filename filename reconstruit le nom du module lax_modname_from_source filename associé à l'artefact filename.
