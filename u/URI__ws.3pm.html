NOM

URI::ws - Schéma d'URI pour les identifiants WebSocket

SYNTAXE

use URI::ws;
my $uri = URI->new('ws://example.com/');

DESCRIPTION

Ce module implémente le schéma d'URI "ws:" défini dans la RFC 6455 http://tools.ietf.org/html/rfc6455.

SOUS-PROGRAMMES/MÉTHODES

Ce module hérite du comportement de URI::http.
