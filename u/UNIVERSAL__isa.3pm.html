NOM

UNIVERSAL::isa - Tentative de récupération des personnes appelant UNIVERSAL::isa comme une fonction

VERSION

version 1.20171012

SYNTAXE

# depuis le shell
echo 'export PERL5OPT=-MUNIVERSAL::isa' >> /etc/profile
# dans votre programme
use UNIVERSAL::isa;
# activer les avertissements pour toutes les utilisations douteuses de UNIVERSAL::isa
use UNIVERSAL::isa 'verbose';

DESCRIPTION

Chaque fois que vous utilisez "isa" dans UNIVERSAL comme une fonction, un chaton utilisant Test::MockObject meurt. Normalement, les chatons seraient impuissants, mais s'ils utilisent UNIVERSAL::isa (le module dont vous lisez la documentation), les chatons peuvent vivre longtemps et prospérer.

Ce module remplace "UNIVERSAL::isa" par une version qui garantit que, lorsqu'il est appelé comme une fonction sur des objets qui surchargent "isa", "isa" appellera la méthode appropriée sur ces objets.

Dans tous les autres cas, le vrai "UNIVERSAL::isa" est appelé directement.

NOTE : Vous ne devriez utiliser ce module qu'à des fins de débogage. Il ne devrait pas être une dépendance dans le code en cours d'exécution.

FONCTIONS

isa_original

Cette sous-routine contient la définition de "UNIVERSAL::isa" originale, au cas où vous en auriez besoin.

AVERTISSEMENTS

Si le pragma des avertissements lexicaux est disponible, ce module émettra un avertissement pour chaque invocation répréhensible de "UNIVERSAL::isa". Faites taire ces avertissements en disant :

no warnings 'UNIVERSAL::isa';

dans la portée lexicale du code répréhensible.

Après la version 1.00, les avertissements n'apparaissent que lorsque du code répréhensible appelle UNIVERSAL::isa() comme une fonction sur un invocant pour lequel il existe un isa() surchargé. Ce sont de véritables bugs actifs, et vous devriez les corriger plutôt que de vous fier à ce module pour les trouver.

Pour obtenir des avertissements pour toutes les utilisations potentiellement dangereuses de UNIVERSAL::isa() comme une fonction, et non comme une méthode (c'est-à-dire pour toutes les utilisations de la méthode comme une fonction, qui sont des bugs latents, sinon des bugs qui casseront votre code tel qu'il est actuellement), passez le drapeau "verbose" lors de l'utilisation du module. Cela peut générer de nombreux avertissements supplémentaires, mais ils sont plus spécifiques quant à la pratique incorrecte et suggèrent généralement des corrections appropriées.

VOIR AUSSI

Perl::Critic::Policy::BuiltinFunctions::ProhibitUniversalIsa

UNIVERSAL::can pour une autre discussion sur le problème.

Test::MockObject pour un exemple de module qui doit vraiment surcharger isa().

Toute explication décente de la POO pour comprendre pourquoi appeler des méthodes comme des fonctions est une idée incroyablement mauvaise.
