Unicode::Normalize(3perl) Guide de référence des programmeurs Perl Unicode::Normalize(3perl)

NOM

Unicode::Normalize - Formes de normalisation Unicode

SYNTAXE

(1) en utilisant des noms de fonctions exportés par défaut :

use Unicode::Normalize;
$NFD_string  = NFD($string);  # Forme de normalisation D
$NFC_string  = NFC($string);  # Forme de normalisation C
$NFKD_string = NFKD($string); # Forme de normalisation KD
$NFKC_string = NFKC($string); # Forme de normalisation KC

(2) en utilisant des noms de fonctions exportés sur demande :

use Unicode::Normalize 'normalize';
$NFD_string  = normalize('D',  $string);  # Forme de normalisation D
$NFC_string  = normalize('C',  $string);  # Forme de normalisation C
$NFKD_string = normalize('KD', $string);  # Forme de normalisation KD
$NFKC_string = normalize('KC', $string);  # Forme de normalisation KC

DESCRIPTION

Paramètres :

$string est utilisé comme une chaîne de caractères dans le sens sémantique des caractères (voir perlunicode).

$code_point doit être un entier non signé représentant un point de code Unicode.

Note : Entre XSUB et Perl pur, il y a une incompatibilité concernant l'interprétation de $code_point en tant que nombre décimal. XSUB convertit $code_point en un entier non signé, mais Perl pur ne le fait pas. N'utilisez pas de virgule flottante ni de signe négatif dans $code_point.

Formes de normalisation

"$NFD_string = NFD($string)"
Retourne la Forme de Normalisation D (formée par décomposition canonique).
"$NFC_string = NFC($string)"
Retourne la Forme de Normalisation C (formée par décomposition canonique suivie d'une composition canonique).
"$NFKD_string = NFKD($string)"
Retourne la Forme de Normalisation KD (formée par décomposition de compatibilité).
"$NFKC_string = NFKC($string)"
Retourne la Forme de Normalisation KC (formée par décomposition de compatibilité suivie d'une composition **canonique**).
"$FCD_string = FCD($string)"
Si la chaîne donnée est sous forme FCD ("Fast C or D" ; cf. UTN #5), elle retourne la chaîne sans modification ; sinon, elle retourne une chaîne FCD.

Note : FCD n'est pas toujours unique, les formes plurielles peuvent être équivalentes entre elles. FCD() retournera une de ces formes équivalentes.

"$FCC_string = FCC($string)"
Retourne la forme FCC ("Fast C Contiguous" ; cf. UTN #5).

Note : FCC est unique, tout comme les quatre formes de normalisation (NF*).

"$normalized_string = normalize($form_name, $string)"
Retourne la forme de normalisation de $form_name.

Comme $form_name, l'un des noms suivants doit être donné.

'C'  ou 'NFC'  pour la Forme de Normalisation C  (UAX #15)
'D'  ou 'NFD'  pour la Forme de Normalisation D  (UAX #15)
'KC' ou 'NFKC' pour la Forme de Normalisation KC (UAX #15)
'KD' ou 'NFKD' pour la Forme de Normalisation KD (UAX #15)
'FCD'          pour la Forme "Fast C or D"  (UTN #5)
'FCC'          pour la Forme "Fast C Contiguous" (UTN #5)

Décomposition et composition

"$decomposed_string = decompose($string [, $useCompatMapping])"
Retourne la concaténation de la décomposition de chaque caractère de la chaîne.

Si le deuxième paramètre (un booléen) est omis ou faux, la décomposition est canonique ; si le deuxième paramètre (un booléen) est vrai, la décomposition est une décomposition de compatibilité.

La chaîne retournée n'est pas toujours en NFD/NFKD. Une réorganisation peut être nécessaire.

$NFD_string  = reorder(decompose($string));       # équivaut à NFD()
$NFKD_string = reorder(decompose($string, TRUE)); # équivaut à NFKD()
"$reordered_string = reorder($string)"
Retourne le résultat de la réorganisation des caractères combinants selon le comportement d'ordre canonique.

Par exemple, lorsque vous avez une liste de chaînes NFD/NFKD, vous pouvez obtenir la chaîne NFD/NFKD concaténée à partir de celles-ci, en disant

$concat_NFD  = reorder(join '', @NFD_strings);
$concat_NFKD = reorder(join '', @NFKD_strings);
"$composed_string = compose($string)"
Retourne le résultat de la composition canonique sans appliquer de décomposition.

Par exemple, lorsque vous avez une chaîne NFD/NFKD, vous pouvez en obtenir sa chaîne NFC/NFKC, en disant

$NFC_string  = compose($NFD_string);
$NFKC_string = compose($NFKD_string);
"($processed, $unprocessed) = splitOnLastStarter($normalized)"
Retourne deux chaînes : la première, $processed, est la partie avant le dernier démarreur, et la seconde, $unprocessed, est l'autre partie après la première partie. Un démarreur est un caractère ayant une classe de combinaison de zéro (voir UAX #15).

Notez que $processed peut être vide (lorsque $normalized ne contient aucun démarreur ou commence par le dernier démarreur), et alors $unprocessed devrait être égal à la totalité de $normalized.

Lorsque vous avez une chaîne $normalized et une chaîne $unnormalized qui la suit, une simple concaténation est incorrecte :

$concat = $normalized . normalize($form, $unnormalized); # incorrect !

Au lieu de cela, faites comme ceci :

($processed, $unprocessed) = splitOnLastStarter($normalized);
$concat = $processed . normalize($form,$unprocessed.$unnormalized);

splitOnLastStarter() doit être appelée avec un paramètre pré-normalisé $normalized, qui est sous la même forme que $form souhaitée.

Si vous avez un tableau de @string qui doit être concaténé puis normalisé, vous pouvez faire comme ceci :

my $result = "";
my $unproc = "";
foreach my $str (@string) {
    $unproc .= $str;
    my $n = normalize($form, $unproc);
    my($p, $u) = splitOnLastStarter($n);
    $result .= $p;
    $unproc  = $u;
}
$result .= $unproc;
# au lieu de normalize($form, join('', @string))
"$processed = normalize_partial($form, $unprocessed)"
Un wrapper pour la combinaison de normalize() et splitOnLastStarter(). Notez que $unprocessed sera modifié comme effet secondaire.

Si vous avez un tableau de @string qui doit être concaténé puis normalisé, vous pouvez faire comme ceci :

my $result = "";
my $unproc = "";
foreach my $str (@string) {
    $unproc .= $str;
    $result .= normalize_partial($form, $unproc);
}
$result .= $unproc;
# au lieu de normalize($form, join('', @string))
"$processed = NFD_partial($unprocessed)"
Fonctionne comme "normalize_partial('NFD', $unprocessed)". Notez que $unprocessed sera modifié comme effet secondaire.
"$processed = NFC_partial($unprocessed)"
Fonctionne comme "normalize_partial('NFC', $unprocessed)". Notez que $unprocessed sera modifié comme effet secondaire.
"$processed = NFKD_partial($unprocessed)"
Fonctionne comme "normalize_partial('NFKD', $unprocessed)". Notez que $unprocessed sera modifié comme effet secondaire.
"$processed = NFKC_partial($unprocessed)"
Fonctionne comme "normalize_partial('NFKC', $unprocessed)". Notez que $unprocessed sera modifié comme effet secondaire.

Vérification rapide

(voir Annexe 8, UAX #15 ; et lib/unicore/DerivedNormalizationProps.txt)

Les fonctions suivantes vérifient si la chaîne est dans cette forme de normalisation.

Le résultat retourné sera l'un des suivants :

YES     La chaîne est dans cette forme de normalisation.
NO      La chaîne n'est pas dans cette forme de normalisation.
MAYBE   Douteux. Peut-être oui, peut-être non.
"$result = checkNFD($string)"
Retourne vrai (1

DESCRIPTION

This module provides functions to check and normalize Unicode strings according to the Unicode Normalization Forms.

"$result = checkNFD($string)"
Il retourne vrai (1) si "YES" ; faux ("chaîne vide") si "NO".
"$result = checkNFKD($string)"
Il retourne vrai (1) si "YES" ; faux ("chaîne vide") si "NO".
"$result = checkNFC($string)"
Il retourne vrai (1) si "YES" ; faux ("chaîne vide") si "NO" ; "undef" si "MAYBE".
"$result = checkNFKC($string)"
Il retourne vrai (1) si "YES" ; faux ("chaîne vide") si "NO" ; "undef" si "MAYBE".
"$result = checkFCD($string)"
Il retourne vrai (1) si "YES" ; faux ("chaîne vide") si "NO".
"$result = checkFCC($string)"
Il retourne vrai (1) si "YES" ; faux ("chaîne vide") si "NO" ; "undef" si "MAYBE".

Note : Si une chaîne n'est pas en FCD, elle ne doit pas être en FCC. Donc checkFCC($not_FCD_string) devrait retourner "NO".

"$result = check($form_name, $string)"
Il retourne vrai (1) si "YES" ; faux ("chaîne vide") si "NO" ; "undef" si "MAYBE".

Comme $form_name, l'un des noms suivants doit être donné.

'C'  ou 'NFC'  pour la Forme de Normalisation C  (UAX #15)
'D'  ou 'NFD'  pour la Forme de Normalisation D  (UAX #15)
'KC' ou 'NFKC' pour la Forme de Normalisation KC (UAX #15)
'KD' ou 'NFKD' pour la Forme de Normalisation KD (UAX #15)
'FCD'          pour la Forme "Fast C or D"  (UTN #5)
'FCC'          pour la Forme "Fast C Contiguous" (UTN #5)

Note

Dans les cas de NFD, NFKD et FCD, la réponse doit être soit "YES", soit "NO". La réponse "MAYBE" peut être retournée dans les cas de NFC, NFKC et FCC.

Une chaîne "MAYBE" doit contenir au moins un caractère combinant ou similaire. Par exemple, "ACCENT AIGU COMBINANT" a la propriété MAYBE_NFC/MAYBE_NFKC.

Les deux appels "checkNFC("A\N{ACCENT AIGU COMBINANT}")" et "checkNFC("B\N{ACCENT AIGU COMBINANT}")" retourneront "MAYBE". "A\N{ACCENT AIGU COMBINANT}" n'est pas en NFC (son NFC est "\N{LETTR E MAJUSCULE A AVEC ACCENT AIGU}"), tandis que "B\N{ACCENT AIGU COMBINANT}" est en NFC.

Si vous voulez vérifier exactement, comparez la chaîne avec sa version NFC/NFKC/FCC.

if ($string eq NFC($string)) {
    # $string est exactement normalisé en NFC ;
} else {
    # $string n'est pas normalisé en NFC ;
}
if ($string eq NFKC($string)) {
    # $string est exactement normalisé en NFKC ;
} else {
    # $string n'est pas normalisé en NFKC ;
}

Données de caractère

Ces fonctions sont des interfaces pour les données de caractère utilisées en interne. Si vous souhaitez uniquement obtenir les formes de normalisation Unicode, vous n'avez pas besoin de les appeler vous-même.

"$decomposition_canonique = getCanon($code_point)"
Si le caractère est canoniquement décomposable (y compris les syllabes Hangul), il retourne la décomposition canonique (complète) sous forme de chaîne. Sinon, il retourne "undef".

Note : Conformément à la norme Unicode, la décomposition canonique d'un caractère non canoniquement décomposable est la même que le caractère lui-même.

"$decomposition_compatibilite = getCompat($code_point)"
Si le caractère est décomposable par compatibilité (y compris les syllabes Hangul), il retourne la décomposition de compatibilité (complète) sous forme de chaîne. Sinon, il retourne "undef".

Note : Conformément à la norme Unicode, la décomposition de compatibilité d'un caractère non décomposable par compatibilité est la même que le caractère lui-même.

"$point_de_code_composite = getComposite($point_de_code_ici, $point_de_code_suivant)"
Si deux caractères ici et suivant (en tant que points de code) sont composables (y compris les Jamo/syllabes Hangul et les exclusions de composition), il retourne le point de code du composite.

S'ils ne sont pas composables, il retourne "undef".

"$classe_combinatoire = getCombinClass($code_point)"
Il retourne la classe de combinaison (sous forme d'entier) du caractère.
"$peut_etre_compose_avec_caractere_precedent = isComp2nd($code_point)"
Il retourne un booléen indiquant si le caractère du point de code spécifié peut être composé avec le précédent dans une certaine composition (y compris les compositions Hangul, mais excluant les exclusions de composition et les décompositions non-starter).
"$est_une_exclusion = isExclusion($code_point)"
Il retourne un booléen indiquant si le point de code est une exclusion de composition.
"$est_un_singleton = isSingleton($code_point)"
Il retourne un booléen indiquant si le point de code est un singleton.
"$est_une_decomposition_non_starter = isNonStDecomp($code_point)"
Il retourne un booléen indiquant si le point de code a une décomposition non-starter.
"$est_une_exclusion_de_composition_complete = isComp_Ex($code_point)"
Il retourne un booléen de la propriété dérivée Comp_Ex (Full_Composition_Exclusion). Cette propriété est générée à partir des Exclusions de Composition + Singletons + Décompositions Non-Starter.
"$NFD_est_NON = isNFD_NO($code_point)"
Il retourne un booléen de la propriété dérivée NFD_NO (NFD_Quick_Check=No).
"$NFC_est_NON = isNFC_NO($code_point)"
Il retourne un booléen de la propriété dérivée NFC_NO (NFC_Quick_Check=No).
"$NFC_est_PEUTETRE = isNFC_MAYBE($code_point)"
Il retourne un booléen de la propriété dérivée NFC_MAYBE (NFC_Quick_Check=Maybe).
"$NFKD_est_NON = isNFKD_NO($code_point)"
Il retourne un booléen de la propriété dérivée NFKD_NO (NFKD_Quick_Check=No).
"$NFKC_est_NON = isNFKC_NO($code_point)"
Il retourne un booléen de la propriété dérivée NFKC_NO (NFKC_Quick_Check=No).
"$NFKC_est_PEUTETRE = isNFKC_MAYBE($code_point)"
Il retourne un booléen de la propriété dérivée NFKC_MAYBE (NFKC_Quick_Check=Maybe).

EXPORT

"NFC", "NFD", "NFKC", "NFKD" : par défaut.

"normalize" et d'autres fonctions : sur demande.

CAVEATS

Version de Perl vs. version Unicode
Étant donné que ce module fait référence à la base de données Unicode du cœur de Perl dans le répertoire /lib/unicore (ou anciennement /lib/unicode), la version Unicode de la normalisation implémentée par ce module dépend de ce qui a été compilé dans votre Perl. Le tableau suivant liste la version Unicode par défaut qui est fournie avec les différentes versions de Perl. (Il est possible de changer la version Unicode dans n'importe quelle version de Perl pour utiliser une version Unicode antérieure, de sorte que l'on puisse faire utiliser Unicode 3.2 dans n'importe quelle version de Perl à partir de 5.8.0. Lisez $Config{privlib}/unicore/README.perl pour plus de détails.

   5.6.1              3.0.1
   5.7.2              3.1.0
   5.7.3              3.1.1 (normalisation identique à 3.1.0)
   5.8.0              3.2.0

     5.8.7-5.8.8      4.1.0

Correction du mappage de décomposition
Dans les anciennes versions d'Unicode, un petit nombre de caractères (tous étant des idéographes de compatibilité CJK, dans la mesure où ils ont été découverts) peuvent avoir une cartographie de décomposition erronée (voir lib/unicore/NormalizationCorrections.txt). Quoi qu'il en soit, ce module ne fera pas référence à lib/unicore/NormalizationCorrections.txt ni ne fournira une version spécifique de la normalisation. Par conséquent, ce module fonctionnant sur une ancienne version de Perl avec une base de données Unicode plus ancienne peut utiliser la cartographie de décomposition erronée en se conformant aveuglément à la base de données Unicode.
Définition révisée de la composition canonique
Dans Unicode 4.1.0, la définition D2 de la composition canonique (qui affecte NFC et NFKC) a été modifiée (voir le problème de revue publique #29 et le UAX #15 récent). Ce module utilise la définition la plus récente depuis la version 0.07 (31 octobre 2001). Ce module ne supportera pas la normalisation selon l'ancienne définition, même si la version Unicode implémentée par Perl est inférieure à 4.1.0.
