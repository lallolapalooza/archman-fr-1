UI_UTIL_read_pw(3ssl)

Paquet: openssl

Licences: Apache-2.0

UI_UTIL_READ_PW(3ssl) OpenSSL UI_UTIL_READ_PW(3ssl)

NOM

UI_UTIL_read_pw_string, UI_UTIL_read_pw, UI_UTIL_wrap_read_pem_callback - utilitaires d'interface utilisateur

SYNOPSIS

#include <openssl/ui.h>
int UI_UTIL_read_pw_string(char *buf, int length, const char *prompt,
                           int verify);
int UI_UTIL_read_pw(char *buf, char *buff, int size, const char *prompt,
                    int verify);
UI_METHOD *UI_UTIL_wrap_read_pem_callback(pem_password_cb *cb, int rwflag);

DESCRIPTION

UI_UTIL_read_pw_string() demande une phrase de passe, en utilisant prompt comme invite, et la stocke dans buf. La taille maximale autorisée est donnée par length, incluant le caractère NUL terminateur. Si verify est non nul, le mot de passe sera également vérifié.

UI_UTIL_read_pw() fait la même chose que UI_UTIL_read_pw_string(), la différence est que vous pouvez lui donner un tampon externe buff pour la phrase de passe de vérification.

UI_UTIL_wrap_read_pem_callback() peut être utilisée pour créer une UI_METHOD temporaire qui encapsule une fonction de rappel de mot de passe PEM donnée cb. rwflag est utilisé pour spécifier si cette méthode sera utilisée pour la saisie de la phrase de passe sans (0) ou avec (1) vérification. Lorsqu'elle n'est plus utilisée, la méthode retournée doit être libérée avec UI_destroy_method().

NOTES

UI_UTIL_read_pw_string() et UI_UTIL_read_pw() utilisent une UI_METHOD par défaut. Voir UI_get_default_method(3) et ses semblables pour plus d'informations.

Le résultat de la UI_METHOD créée par UI_UTIL_wrap_read_pem_callback() générera des chaînes de mots de passe dans le codage généré par la fonction de rappel de mot de passe donnée. Les fonctions de demande de mot de passe par défaut (outre UI_UTIL_read_pw_string() et UI_UTIL_read_pw(), il y a PEM_def_callback(), EVP_read_pw_string() et EVP_read_pw_string_min()) utilisent toutes la UI_METHOD par défaut.

VALEURS DE RETOUR

UI_UTIL_read_pw_string() et UI_UTIL_read_pw() retournent 0 en cas de succès ou une valeur négative en cas d'erreur.

UI_UTIL_wrap_read_pem_callback() retourne une structure UI_METHOD valide ou NULL si une erreur s'est produite.
