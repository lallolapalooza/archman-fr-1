NOM

UilDumpSymbolTable — Affiche le contenu d'une table de symboles UIL nommée sur la sortie standard

SYNTAXE

#include <uil/UilDef.h>

void UilDumpSymbolTable(
sym_entry_type *root_ptr);

DESCRIPTION

La fonction UilDumpSymbolTable affiche le contenu d'un pointeur de table de symboles UIL sur la sortie standard.

root_ptr
Spécifie un pointeur vers l'entrée racine de la table de symboles. Cette valeur peut être extraite de la partie parse_tree_root de la structure de données Uil_compile_desc_type renvoyée par Uil.

En suivant le lien depuis l'entrée racine, vous pouvez parcourir l'intégralité de l'arbre d'analyse syntaxique. Les entrées de la table de symboles sont au format suivant :

adresse.hex type.symbole données.symbole position.source.précédente position.source enregistrement.modification

où :

adresse.hex
Spécifie l'adresse hexadécimale de cette entrée dans la table de symboles.
type.symbole
Spécifie le type de cette entrée de table de symboles. Parmi les types possibles figurent root, module, value, procedure et widget.
données.symbole
Spécifie les données de l'entrée de table de symboles. Les données varient en fonction du type de l'entrée. Elles contiennent souvent des pointeurs vers d'autres entrées de table de symboles, ou les données réelles pour le type de données.
position.source.précédente
Spécifie le point de terminaison dans le code source de l'élément source précédent.
position.source
Spécifie la plage de positions dans le code source pour ce symbole.

Les structures de données exactes pour chaque type de symbole sont définies dans le fichier d'en-tête UilSymDef.h. Notez que ce fichier est automatiquement inclus lorsqu'une application inclut le fichier UilDef.h.
