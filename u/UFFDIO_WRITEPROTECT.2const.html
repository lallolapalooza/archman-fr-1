UFFDIO_WRITEPROTECT(2const) UFFDIO_WRITEPROTECT(2const)

NOM

UFFDIO_WRITEPROTECT - Protège en écriture ou déprotège en écriture une plage mémoire enregistrée avec userfaultfd

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/userfaultfd.h>  /* Définition des constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_WRITEPROTECT, ...);
#include <linux/userfaultfd.h>
struct uffdio_writeprotect {
    struct uffdio_range  range;  /* Plage pour modifier la permission d'écriture */
    __u64                mode;   /* Mode pour modifier la permission d'écriture */
};

DESCRIPTION

Protège en écriture ou déprotège en écriture une plage mémoire enregistrée avec userfaultfd et le mode UFFDIO_REGISTER_MODE_WP.

Deux bits de mode sont supportés dans cette structure :

UFFDIO_WRITEPROTECT_MODE_WP
Lorsque ce bit de mode est activé, l'appel ioctl sera une opération de protection en écriture sur la plage mémoire spécifiée par range. Sinon, ce sera une opération de déprotection en écriture sur la plage spécifiée, qui peut être utilisée pour résoudre un défaut de page de protection en écriture userfaultfd.
UFFDIO_WRITEPROTECT_MODE_DONTWAKE
Lorsque ce bit de mode est activé, aucun thread attendant la résolution d'un défaut de page ne sera réveillé après l'opération. Ceci ne peut être spécifié que si UFFDIO_WRITEPROTECT_MODE_WP n'est pas spécifié.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
Le champ start ou len de la structure ufdio_range n'était pas un multiple de la taille de page système ; ou len était zéro ; ou la plage spécifiée était invalide d'une autre manière.
EAGAIN
Le processus a été interrompu ; réessayez cet appel.
ENOENT
La plage spécifiée dans range n'est pas valide. Par exemple, l'adresse virtuelle n'existe pas, ou n'a pas été enregistrée avec le mode userfaultfd de protection en écriture.
EFAULT
Un défaut générique a été rencontré pendant le traitement.

NORMES

Linux.

HISTORIQUE

Linux 5.7.

EXEMPLES

Voir userfaultfd(2).

VOIR AUSSI

ioctl(2), ioctl_userfaultfd(2), userfaultfd(2)
