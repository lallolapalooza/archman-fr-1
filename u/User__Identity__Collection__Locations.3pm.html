DIAGNOSTICS

Erreur : $objet n'est pas une collection.
Le premier argument est un objet, mais pas d'une classe qui hérite de User::Identity::Collection. Lancé par addCollection()
Erreur : Impossible de créer un $type pour l'ajouter à ma collection.
Certaines options sont spécifiées pour créer un objet $type, qui est natif à cette collection. Cependant, pour une raison quelconque, cela a échoué. Lancé par addRole()
Erreur : Impossible de charger le module de collection pour $type ($class).
Soit le $type spécifié n'existe pas, soit le module nommé $class renvoie des erreurs de compilation. Si le type tel que spécifié dans l'avertissement n'est pas le nom d'un package, vous avez spécifié un pseudonyme qui n'était pas défini. Peut-être avez-vous oublié le 'require' du package qui définit le pseudonyme. Lancé par addCollection()
Erreur : Impossible de renommer $nom en $nouveau_nom : existe déjà
Lancé par renameRole()
Erreur : Impossible de renommer $nom en $nouveau_nom : n'existe pas
Lancé par renameRole()
Erreur : La création d'une collection via $class a échoué.
La classe $class a été compilée, mais il n'a pas été possible de créer un objet de cette classe en utilisant les options que vous avez spécifiées. Lancé par addCollection()
Erreur : Je ne sais pas quel type de collection vous voulez ajouter.
Si vous ajoutez une collection, elle doit être soit un objet collection, soit une liste d'options qui peuvent être utilisées pour créer un objet collection. Dans ce dernier cas, le type de collection doit être spécifié. Lancé par addCollection()
Avertissement : Aucune collection $nom
La collection avec $nom n'existe pas et ne peut pas être créée. Lancé par add()
Erreur : Type de rôle incorrect pour $collection : requiert un $attendu mais obtenu un $type
Chaque $collection regroupe des ensembles de rôles d'un type spécifique ($attendu). Vous ne pouvez pas ajouter des objets d'un $type différent. Lancé par addRole()

User::Identity::Collection::Locations - a collection of locations This module provides a collection of locations. It is part of the User::Identity module.

This module provides a collection of locations. It is part of the User::Identity module.

NAME

User::Identity::Collection::Locations - a collection of locations

INHERITANCE

This module inherits from User::Identity::Collection.

SYNOPSIS

use User::Identity::Collection::Locations;

my $locations = User::Identity::Collection::Locations->new;

$locations->add( 'home' => '/home/user' );
$locations->add( 'work' => '/mnt/work' );

print $locations->get('home'); # outputs /home/user
print $locations->get('work'); # outputs /mnt/work

DESCRIPTION

This module provides a collection of locations. It is part of the User::Identity module. It inherits from User::Identity::Collection and provides additional methods for working with locations.

OVERLOADED

This module overloads the following operators:

  • %{}: Returns a hash reference of the locations.
  • @{}^: Returns an array reference of the location names.

METHODS

new()
Creates a new User::Identity::Collection::Locations object.
add( name => value )
Adds a location to the collection. name is the name of the location, and value is the path to the location.
get( name )
Returns the path to the location with the given name.
remove( name )
Removes the location with the given name from the collection.
exists( name )
Returns true if a location with the given name exists, false otherwise.
keys()
Returns a list of all location names.
values()
Returns a list of all location paths.
count()
Returns the number of locations in the collection.

DIAGNOSTICS

This module does not provide any specific diagnostics.
