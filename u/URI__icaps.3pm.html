NOM

URI::icaps - Schéma URI pour les identifiants ICAPS

VERSION

Version 5.20

SYNOPSIS

use URI::icaps;
my $uri = URI->new('icaps://icap-proxy.example.com/');

DESCRIPTION

Ce module implémente le schéma URI "icaps:" défini dans la RFC 3507 http://tools.ietf.org/html/rfc3507, pour le protocole Internet Content Adaptation Protocol https://en.wikipedia.org/wiki/Internet_Content_Adaptation_Protocol.

SOUS-ROUTINES/MÉTHODES

Ce module hérite du comportement de URI::icap et surcharge la méthode secure.

secure

retourne 1 car icaps est un protocole sécurisé
