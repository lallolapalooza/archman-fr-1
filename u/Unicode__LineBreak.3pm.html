NOM

Unicode::LineBreak - Algorithme de césure de ligne Unicode UAX #14

SYNOPIS

use Unicode::LineBreak;
$lb = Unicode::LineBreak->new();
$broken = $lb->break($string);

DESCRIPTION

Unicode::LineBreak implémente l'algorithme de césure de ligne décrit dans l'Annexe Unicode Standard #14 [UAX #14]. La propriété informative East_Asian_Width définie par l'Annexe #11 [UAX #11] sera utilisée pour déterminer les positions de césure.

Terminologie

Les termes suivants sont utilisés pour plus de commodité.

Une coupure obligatoire est un comportement de césure de ligne obligatoire défini par des règles de base et appliqué indépendamment des caractères environnants. Une coupure arbitraire est un comportement de césure de ligne autorisé par les règles de base et choisi par l'utilisateur pour être appliqué. Une coupure arbitraire comprend une coupure directe et une coupure indirecte définies par [UAX #14].

Les caractères alphabétiques sont des caractères entre lesquels aucune coupure de ligne n'est généralement autorisée, sauf que d'autres caractères fournissent des opportunités de coupure. Les caractères idéographiques sont des caractères qui permettent généralement des coupures de ligne avant et après eux. [UAX #14] classe la plupart des caractères alphabétiques comme AL et la plupart des caractères idéographiques comme ID (ces termes sont inexacts du point de vue de la grammatologie). Pour plusieurs scripts, les positions de césure ne sont pas évidentes pour chaque caractère, par conséquent, une heuristique basée sur un dictionnaire est utilisée.

Le nombre de colonnes d'une chaîne n'est pas toujours égal au nombre de caractères qu'elle contient : chaque caractère est soit large, soit étroit, soit non espaçable ; ils occupent respectivement 2, 1 ou 0 colonnes. Plusieurs caractères peuvent être à la fois larges et étroits selon les contextes dans lesquels ils sont utilisés. Les caractères peuvent avoir des largeurs plus variées grâce à la personnalisation.

Options

Les méthodes "new" et "config" acceptent les paires suivantes. Certaines d'entre elles affectent le nombre de colonnes ([E]), la segmentation des clusters de graphèmes ([G]) (voir aussi Unicode::GCString) ou le comportement de césure de ligne ([L]).

BreakIndent => "OUI" | "NON"
[L] Autorise toujours une coupure après les ESPACES au début de la ligne, aussi appelée indentation. [UAX #14] ne tient pas compte de cette utilisation des ESPACES. Par défaut : "OUI".

Note : Cette option a été introduite dans la version 1.011.

CharMax => NOMBRE
[L] Nombre maximum possible de caractères par ligne, sans compter les ESPACES finaux et la séquence de nouvelle ligne. Notez que le nombre de caractères ne représente généralement pas la longueur de la ligne. Par défaut : 998. 0 signifie illimité (à partir de la version 2012.01).
ColMin => NOMBRE
[L] Nombre minimum de colonnes que peut inclure une ligne coupée arbitrairement, sans compter les espaces finaux et les séquences de nouvelle ligne. Par défaut : 0.
ColMax => NOMBRE
[L] Nombre maximum de colonnes qu'une ligne peut inclure sans compter les espaces finaux et la séquence de nouvelle ligne. En d'autres termes, la longueur maximale de la ligne. Par défaut : 76.

Voir aussi l'option "Urgent" et "Comportements de césure définis par l'utilisateur".

ComplexBreaking => "OUI" | "NON"
[L] Effectue une césure heuristique dans le contexte complexe de l'Asie du Sud-Est. Par défaut, si la segmentation des mots pour les systèmes d'écriture d'Asie du Sud-Est est activée, c'est "OUI".
Context => CONTEXTE
[E][L] Spécifie le contexte linguistique/régional. Les contextes actuellement disponibles sont "EASTASIAN" et "NONEASTASIAN". Le contexte par défaut est "NONEASTASIAN".

Dans le contexte "EASTASIAN", les caractères avec la propriété East_Asian_Width ambiguë (A) sont traités comme "larges" et ceux avec la classe de césure de ligne AI comme idéographiques (ID).

Dans le contexte "NONEASTASIAN", les caractères avec la propriété East_Asian_Width ambiguë (A) sont traités comme "étroits" et ceux avec la classe de césure de ligne AI comme alphabétiques (AL).

EAWidth => "[" ORD "=>" PROPRIETE "]"
EAWidth => "undef"
[E] Personnalise la classification de la propriété East_Asian_Width. ORD est la valeur scalaire UCS du caractère ou une référence à un tableau de ceux-ci. PROPRIETE est l'une des valeurs de propriété East_Asian_Width et les valeurs étendues (voir "Constantes"). Cette option peut être spécifiée plusieurs fois. Si "undef" est spécifié, toute personnalisation appliquée précédemment sera annulée.

Par défaut, aucune personnalisation n'est disponible. Voir aussi "Personnalisation des propriétés des caractères".

Format => METHODE
[L] Spécifie la méthode de formatage des lignes coupées.
"SIMPLE"
Méthode par défaut. Insère simplement une nouvelle ligne aux positions de césure arbitraires.
"NEWLINE"
Insère ou remplace les séquences de nouvelle ligne par celles spécifiées dans l'option "Newline", supprime les ESPACES précédant les séquences de nouvelle ligne ou la fin du texte. Ajoute ensuite une nouvelle ligne à la fin du texte s'il n'en existe pas.
"TRIM"
Insère une nouvelle ligne aux positions de césure arbitraires. Supprime les ESPACES précédant les séquences de nouvelle ligne.
"undef"
Ne fait rien, même pas insérer de nouvelles lignes.
Référence de sous-routine
Voir "Formatage des lignes".

[L] Traite les syllabes Hangul et les jamos de conjonction comme des caractères alphabétiques (AL). Par défaut : "

PERSONNALISATION

Mise en forme des lignes

Si vous spécifiez une référence de sous-routine comme valeur de l'option "Format", elle doit accepter trois arguments :

$MODIFIÉ = &sousroutine(SOI, ÉVÉNEMENT, STR);

SOI est un objet Unicode::LineBreak, ÉVÉNEMENT est une chaîne qui détermine le contexte dans lequel la sous-routine a été appelée, et STR est un fragment de la chaîne Unicode précédant ou suivant la position de césure.

ÉVÉNEMENT |Quand déclenché      |Valeur de STR
---------------------------------------------------------------------
"sot" |Début du texte       |Fragment de la première ligne
"sop" |Après une césure oblig. |Fragment de la ligne suivante
"sol" |Après une césure arbit. |Fragment au début de la ligne
""    |Juste avant toute     |Ligne complète sans ESPACE de fin
      |césure               |
"eol" |Césure arbitraire    |ESPACEs précédant la position de
      |                     |césure
"eop" |Césure obligatoire   |Saut de ligne et ESPACEs qui le
      |                     |précèdent
"eot" |Fin du texte         |ESPACEs (et saut de ligne) à la fin
      |                     |du texte
---------------------------------------------------------------------

La sous-routine doit retourner le fragment de texte modifié ou peut retourner "undef" pour indiquer qu'aucune modification n'a eu lieu. Notez que les modifications dans le contexte de "sot", "sop" ou "sol" peuvent affecter la décision des positions de césure suivantes, tandis que les autres n'auront pas cet effet.

Note: Les arguments de chaîne sont en fait des séquences de clusters de graphèmes. Voir Unicode::GCString.

Par exemple, le code suivant replie les lignes en supprimant les espaces de fin :

sub fmt {
    if ($_[1] =~ /^eo/) {
        return "\n";
    }
    return undef;
}
my $lb = Unicode::LineBreak->new(Format => \&fmt);
$output = $lb->break($text);

Comportements de césure définis par l'utilisateur

Lorsqu'une ligne générée par une césure arbitraire doit dépasser la mesure de CharMax, ColMax ou ColMin, une césure urgente peut être effectuée sur la chaîne suivante. Si vous spécifiez une référence de sous-routine comme valeur de l'option "Urgent", elle doit accepter deux arguments :

@PORTÉES = &sousroutine(SOI, STR);

SOI est un objet Unicode::LineBreak et STR est une chaîne Unicode à césurer.

La sous-routine doit retourner un tableau de chaînes STR césurées.

Note: L'argument de chaîne est en fait une séquence de clusters de graphèmes. Voir Unicode::GCString.

Par exemple, le code suivant insère un trait d'union dans les noms de plusieurs substances chimiques (comme la Titine) afin qu'ils puissent être pliés :

sub hyphenize {
    return map {$_ =~ s/yl$/yl-/; $_} split /(\w+?yl(?=\w))/, $_[1];
}
my $lb = Unicode::LineBreak->new(Urgent => \&hyphenize);
$output = $lb->break("Methionylthreonylthreonylglutaminylarginyl...");

Si vous spécifiez une référence de tableau [REGEX, SOUSREF] comme valeur de l'option "Prep", la sous-routine doit accepter deux arguments :

@PORTÉES = &sousroutine(SOI, STR);

SOI est un objet Unicode::LineBreak et STR est une chaîne Unicode correspondant à REGEX.

La sous-routine doit retourner un tableau de chaînes STR césurées.

Par exemple, le code suivant césurera les URL HTTP en utilisant la règle de [CMOS].

my $url = qr{http://[\x21-\x7E]+}i;
sub breakurl {
    my $self = shift;
    my $str = shift;
    return split m{(?<=[/]) (?=[^/]) |
                   (?<=[^-.]) (?=[-~.,_?\#%=&]) |
                   (?<=[=&]) (?=.)}x, $str;
}
my $lb = Unicode::LineBreak->new(Prep => [$url, \&breakurl]);
$output = $lb->break($string);

Conservation de l'état

L'objet Unicode::LineBreak peut se comporter comme une référence de hachage. Tous les éléments peuvent être conservés tout au long de sa vie.

    my $str = shift;

        return "\n";
