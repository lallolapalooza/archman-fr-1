NOM

URI::QueryParam - Méthodes de requête supplémentaires pour les URI

SYNOPSIS

use URI;

DESCRIPTION

"URI::QueryParam" fournissait autrefois les méthodes query_form_hash, query_param query_param_append et query_param_delete sur les objets URI. Ces méthodes ont été fusionnées dans URI lui-même, donc ce module est maintenant un no-op (ne fait rien).
