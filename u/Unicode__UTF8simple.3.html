NOM

Unicode::UTF8simple - Conversions de/vers UTF8 depuis/vers des jeux de caractères

SYNTAXE

use Unicode::UTF8simple;

my $uref = new Unicode::UTF8simple;
#convertir une chaîne (ici : schön) en une chaîne d'octets utf8
my $utf8string=$uref->toUTF8("iso-8859-1","schön");
#convertir une chaîne de utf-8 vers un encodage spécifié
my $string=$uref->fromUTF8("iso-8859-1",$utf8string);
#obtenir une liste des encodages supportés :
my @listOfNames=$uref->enclist();
#vérifier si un encodage donné (ici gb2312) est supporté
if ($uref->encsup('gb2312')){ ... }

DESCRIPTION

Fournit la conversion UTF-8 pour les versions de Perl 5.00 et supérieures. Il a été principalement écrit pour être utilisé avec les versions de Perl 5.00 à 5.6.0 car ces versions de Perl ne supportent pas Unicode::MapUTF8 ou Encode.

Unicode::UTF8simple est écrit en Perl pur (pas de code C) et fonctionnera avec n'importe quelle version de Perl 5. Il est juste légèrement plus lent qu'Encode.
