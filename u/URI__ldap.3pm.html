NOM

URI::ldap - Localisateurs de ressources uniformes LDAP

SYNTAXE

use URI;
$uri = URI->new("ldap:$uri_string");
$dn     = $uri->dn;
$filter = $uri->filter;
@attr   = $uri->attributes;
$scope  = $uri->scope;
%extn   = $uri->extensions;

$uri = URI->new("ldap:");  # commence vide
$uri->host("ldap.itd.umich.edu");
$uri->dn("o=University of Michigan,c=US");
$uri->attributes(qw(postalAddress));
$uri->scope('sub');
$uri->filter('(cn=Babs Jensen)');
print $uri->as_string,"\n";

DESCRIPTION

"URI::ldap" fournit une interface pour analyser une URI LDAP en ses composants et pour construire une URI telle que décrite dans la RFC 2255.

MÉTHODES

"URI::ldap" prend en charge toutes les méthodes génériques et serveur définies par URI, plus les suivantes.

Chacune des méthodes suivantes peut être utilisée pour définir ou récupérer la valeur dans l'URI. Les valeurs sont passées sous forme non échappée. Aucune de ces méthodes ne retourne de valeurs indéfinies, mais les éléments sans valeur par défaut peuvent être vides. Si des arguments sont fournis, une nouvelle valeur est définie pour la partie donnée de l'URI.

$uri->dn( [$nouveau_dn] )
Définit ou récupère la partie Distinguished Name (Nom Distingué) de l'URI. Le DN identifie l'objet de base de la recherche LDAP.
$uri->attributes( [@nouveaux_attributs] )
Définit ou récupère la liste des noms d'attributs qui sont retournés par la recherche.
$uri->scope( [$nouveau_scope] )
Définit ou récupère la portée à utiliser pour la recherche. La valeur peut être l'une des suivantes : "base", "one" ou "sub". Si aucune n'est fournie dans l'URI, la valeur par défaut est "base".
$uri->_scope( [$nouveau_scope] )
Identique à scope(), mais ne retourne aucune valeur par défaut.
$uri->filter( [$nouveau_filtre] )
Définit ou récupère le filtre à utiliser pour la recherche. Si aucun n'est fourni dans l'URI, la valeur par défaut est "(objectClass=*)".
$uri->_filter( [$nouveau_filtre] )
Identique à filter(), mais ne retourne aucune valeur par défaut.
$uri->extensions( [$etype => $evalue,...] )
Définit ou récupère les extensions utilisées pour la recherche. La liste fournie doit être sous la forme etype1 => evalue1, etype2 => evalue2,... C'est également sous cette forme que la liste est retournée.
