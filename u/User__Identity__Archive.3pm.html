NOM

User::Identity::Archive - classe de base pour l'archivage des informations utilisateur

HERITAGE

User::Identity::Archive
  est un User::Identity::Item
User::Identity::Archive est étendu par
  User::Identity::Archive::Plain

SYNOPSIS

use User::Identity::Archive::Plain;
my $amis = User::Identity::Archive::Plain->new('amis');
$amis->from(\*FH);
$amis->from('.amis');

DESCRIPTION

Une archive stocke des collections. La manière et l'endroit où cela se fait dépendent du type d'archive. Certains archiveurs peuvent limiter les types de sélections qui peuvent être stockées.

Étendu de "DESCRIPTION" dans User::Identity::Item.

Accès à l'archive

$obj->from($source, %options)
Lit les définitions à partir de la $source spécifiée, qui peut généralement être un pointeur de fichier ou un nom de fichier. La syntaxe utilisée dans la $source d'information dépend de l'archiveur.

Tous les archiveurs n'implémentent pas from(), vous pouvez donc vouloir vérifier avec UNIVERSAL::can() au préalable.

» exemple:

use User::Identity::Archive::Some;
my $a = User::Identity::Archive::Some->new('xyz');
$a->from(\*STDIN) if $a->can('from');

DIAGNOSTICS

Erreur: $objet n'est pas une collection.
Le premier argument est un objet, mais pas d'une classe qui étend User::Identity::Collection. Appel par addCollection()
Erreur: Impossible de charger le module de collection pour $type ($class).
Soit le $type spécifié n'existe pas, soit le module nommé $class renvoie des erreurs de compilation. Si le type tel qu'indiqué dans l'avertissement n'est pas le nom d'un paquet, vous avez spécifié un pseudonyme qui n'était pas défini. Peut-être avez-vous oublié le 'require' du paquet qui définit le pseudonyme. Appel par addCollection()
Erreur: La création d'une collection via $class a échoué.
La $class a compilé, mais il n'a pas été possible de créer un objet de cette classe en utilisant les options que vous avez spécifiées. Appel par addCollection()
Erreur: Ne sait pas quel type de collection vous voulez ajouter.
Si vous ajoutez une collection, ce doit être soit un objet collection, soit une liste d'options qui peuvent être utilisées pour créer un objet collection. Dans ce dernier cas, le type de collection doit être spécifié. Appel par addCollection()
Avertissement: Aucune collection $nom
La collection avec le nom $nom n'existe pas et ne peut pas être créée. Appel par add()
