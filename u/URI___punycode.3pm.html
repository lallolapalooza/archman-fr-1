NOM

URI::_punycode - encode une chaîne Unicode en Punycode

SYNTAXE

use strict;
use warnings;
use utf8;
use URI::_punycode qw(encode_punycode decode_punycode);
# encoder une chaîne unicode
my $punycode = encode_punycode('http://☃.net'); # http://.net-xc8g
$punycode = encode_punycode('bücher'); # bcher-kva
$punycode = encode_punycode('他们为什么不说中文'); # ihqwcrb4cv8a8dqg056pqjye
# décoder une chaîne punycode en chaîne unicode
my $unicode = decode_punycode('http://.net-xc8g'); # http://☃.net
$unicode = decode_punycode('bcher-kva'); # bücher
$unicode = decode_punycode('ihqwcrb4cv8a8dqg056pqjye'); # 他们为什么不说中文

DESCRIPTION

URI::_punycode est un module pour encoder / décoder des chaînes Unicode en Punycode https://tools.ietf.org/html/rfc3492, un encodage efficace de l'Unicode pour l'IDNA https://tools.ietf.org/html/rfc5890.

FONCTIONS

Toutes les fonctions lèvent des exceptions en cas d'échec. Vous pouvez les "capturer" avec Syntax::Keyword::Try ou Try::Tiny. Les fonctions suivantes sont exportées par défaut.

encode_punycode

my $punycode = encode_punycode('http://☃.net');  # http://.net-xc8g
$punycode = encode_punycode('bücher'); # bcher-kva
$punycode = encode_punycode('他们为什么不说中文') # ihqwcrb4cv8a8dqg056pqjye

Prend une chaîne Unicode (variable marquée UTF8) et retourne un encodage Punycode pour celle-ci.

decode_punycode

my $unicode = decode_punycode('http://.net-xc8g'); # http://☃.net
$unicode = decode_punycode('bcher-kva'); # bücher
$unicode = decode_punycode('ihqwcrb4cv8a8dqg056pqjye'); # 他们为什么不说中文

Prend un encodage Punycode et retourne la chaîne Unicode originale.
