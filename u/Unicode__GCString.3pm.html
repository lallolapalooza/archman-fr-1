NOM

Unicode::GCString - Chaîne comme séquence de clusters graphémiques UAX #29

SYNTAXE

use Unicode::GCString;
$gcstring = Unicode::GCString->new($string);

DESCRIPTION

Unicode::GCString traite une chaîne Unicode comme une séquence de clusters graphémiques étendus définis par l'Annexe Standard Unicode #29 [UAX #29].

Un cluster graphémique est une séquence d'un ou plusieurs caractères Unicode composé d'une base graphémique et de terminaisons graphémiques et/ou d'un caractère de « préfixe » optionnel. Il s'approche de ce que les gens considèrent comme un caractère.

Interface publique

Constructeurs

new (CHAÎNE, [CLÉ => VALEUR, ...])
new (CHAÎNE, [QUEBRURELIGNE])
Constructeur. Crée une nouvelle chaîne de clusters graphémiques (objet Unicode::GCString) à partir de la chaîne Unicode CHAÎNE.

Pour les paires CLÉ => VALEUR optionnelles, voir "Options" dans Unicode::LineBreak. Sous la seconde forme, l'objet Unicode::LineBreak QUEBRURELIGNE contrôle les fonctionnalités de césure.

Note: La première forme a été introduite par la version 2012.10.

copy
Constructeur de copie. Crée une copie de la chaîne de clusters graphémiques. La position suivante de la nouvelle chaîne est définie au début.

Tailles

chars
Méthode d'instance. Renvoie le nombre de caractères Unicode que comprend la chaîne de clusters graphémiques, c'est-à-dire sa longueur en tant que chaîne Unicode.
columns
Méthode d'instance. Renvoie le nombre total de colonnes des clusters graphémiques défini par la base de données de caractères intégrée. Pour plus de détails, voir "DESCRIPTION" dans Unicode::LineBreak.
length
Méthode d'instance. Renvoie le nombre de clusters graphémiques contenus dans la chaîne de clusters graphémiques.

Opérations en tant que Chaîne

as_string
"""OBJET"""
Méthode d'instance. Convertit explicitement la chaîne de clusters graphémiques en une chaîne Unicode.
cmp (CHAÎNE)
CHAÎNE "cmp" CHAÎNE
Méthode d'instance. Compare les chaînes. Il n'y a pas d'irrégularités. L'une de chaque CHAÎNE peut être une chaîne Unicode.
concat (CHAÎNE)
CHAÎNE "." CHAÎNE
Méthode d'instance. Concatène les CHAÎNES. L'une de chaque CHAÎNE peut être une chaîne Unicode. Notez que le nombre de colonnes (voir columns()) ou de clusters graphémiques (voir length()) de la chaîne résultante n'est pas toujours égal à la somme des deux chaînes. La position suivante de la nouvelle chaîne est celle définie dans la valeur de gauche.
join ([CHAÎNE, ...])
Méthode d'instance. Joint les CHAÎNES en insérant la chaîne de clusters graphémiques. L'une quelconque des CHAÎNES peut être une chaîne Unicode.
substr (OFFSET, [LONGUEUR, [REMPLACEMENT]])
Méthode d'instance. Renvoie une sous-chaîne de la chaîne de clusters graphémiques. OFFSET et LONGUEUR sont basés sur les clusters graphémiques. Si REMPLACEMENT est spécifié, la sous-chaîne est remplacée par celui-ci. REMPLACEMENT peut être une chaîne Unicode.

Note: Cette méthode ne peut pas retourner la lvalue, contrairement à la fonction intégrée substr().

Opérations en tant que Séquence de Clusters Graphémiques

as_array
"@{"OBJET"}"
as_arrayref
Méthode d'instance. Convertit la chaîne de clusters graphémiques en un tableau de clusters graphémiques.
eos
Méthode d'instance. Teste si la position actuelle est à la fin de la chaîne de clusters graphémiques.
item ([OFFSET])
Méthode d'instance. Renvoie le cluster graphémique de rang OFFSET. Si OFFSET n'est pas spécifié, renvoie le cluster graphémique suivant.
next
"<"OBJET">"
Méthode d'instance, itérative. Renvoie le cluster graphémique suivant et incrémente la position suivante.
pos ([OFFSET])
Méthode d'instance. Si OFFSET est spécifié en option, définit la position suivante par rapport à OFFSET. Renvoie la position suivante de la chaîne de clusters graphémiques.

Divers

lbc
Méthode d'instance. Renvoie la Classe de Césure (Voir Unicode::LineBreak) du premier caractère du premier cluster graphémique.
lbcext
Méthode d'instance. Renvoie la Classe de Césure (Voir Unicode::LineBreak) du dernier terminateur graphémique du dernier cluster graphémique. S'il n'y a pas de terminateurs graphémiques ou si leur classe est CM, la valeur de la dernière base graphémique sera retournée.

MISE EN GARDE

  • Le cluster graphémique ne doit pas être appelé "grapheme" même si Larry le fait.
  • Sur Perl autour de 5.10.1, la conversion implicite d'un objet Unicode::GCString en une chaîne Unicode a parfois perturbé le cache "utf8_mg_pos_cache_update".

    Par exemple, au lieu de faire

    $sub = substr($gcstring, $i, $j);

    faites

    $sub = substr("$gcstring", $i, $j);
$sub = substr($gcstring->as_string, $i, $j);
  • Ce module implémente l'algorithme par défaut pour déterminer les limites des clusters graphémiques. Le mécanisme de personnalisation n'est pas encore pris en charge.

VERSION

Consulter la variable $VERSION.

Changements incompatibles

Release 2013.10
•
La méthode new() peut accepter un argument de chaîne non Unicode. Dans ce cas, il sera décodé en utilisant le jeu de caractères iso-8859-1 (Latin 1). Les méthodes des versions précédentes échoueraient avec des entrées non Unicode.
