UFFDIO_REGISTER(2const) UFFDIO_REGISTER(2const)

NOM

UFFDIO_REGISTER - enregistrer une plage d'adresses mémoire avec l'objet userfaultfd

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/userfaultfd.h>  /* Définition des constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_REGISTER, struct uffdio_register *argp);
#include <linux/userfaultfd.h>
struct uffdio_range {
    __u64  start;   /* Début de la plage */
    __u64  len;     /* Taille de la plage (octets) */
};
struct uffdio_register {
    struct uffdio_range  range;
    __u64                mode;    /* Mode de fonctionnement désiré (entrée) */
    __u64                ioctls;  /* ioctl(2) disponibles (sortie) */
};

DESCRIPTION

Enregistre une plage d'adresses mémoire avec l'objet userfaultfd. Les pages de la plage doivent être « compatibles ». Veuillez vous référer à la liste des modes d'enregistrement ci-dessous pour connaître les systèmes de stockage mémoire compatibles pour chaque mode.

Le champ argp->range définit une plage mémoire commençant à argp->range.start et s'étendant sur argp->range.len octets qui doit être gérée par le userfaultfd.

Le champ argp->mode définit le mode de fonctionnement désiré pour cette région mémoire. Les valeurs suivantes peuvent être combinées par un OU logique (bitwise OR) pour définir le mode userfaultfd pour la plage spécifiée :

UFFDIO_REGISTER_MODE_MISSING
Suivre les fautes de page sur les pages manquantes. Depuis Linux 4.3, seules les plages privées anonymes sont compatibles. Depuis Linux 4.11, les plages hugetlbfs et de mémoire partagée sont également compatibles.
UFFDIO_REGISTER_MODE_WP
Suivre les fautes de page sur les pages protégées en écriture. Depuis Linux 5.7, seules les plages privées anonymes sont compatibles.
UFFDIO_REGISTER_MODE_MINOR
Suivre les fautes de page mineures. Depuis Linux 5.13, seules les plages hugetlbfs sont compatibles. Depuis Linux 5.14, la compatibilité avec les plages shmem a été ajoutée.

Si l'opération réussit, le noyau modifie le champ masque de bits argp->ioctls pour indiquer quelles opérations ioctl(2) sont disponibles pour la plage spécifiée. Ce masque de bits retourné peut contenir les bits suivants :

1 << _UFFDIO_COPY
L'opération UFFDIO_COPY est supportée.
1 << _UFFDIO_WAKE
L'opération UFFDIO_WAKE est supportée.
1 << _UFFDIO_WRITEPROTECT
L'opération UFFDIO_WRITEPROTECT est supportée.
1 << _UFFDIO_ZEROPAGE
L'opération UFFDIO_ZEROPAGE est supportée.
1 << _UFFDIO_CONTINUE
L'opération UFFDIO_CONTINUE est supportée.
1 << _UFFDIO_POISON
L'opération UFFDIO_POISON est supportée.

VALEUR RETOURNEE

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné et errno est définie pour indiquer l'erreur.

ERREURS

EBUSY
Une mise en correspondance dans la plage spécifiée est enregistrée avec un autre objet userfaultfd.
EFAULT
argp fait référence à une adresse qui se trouve en dehors de l'espace d'adressage accessible du processus appelant.
EINVAL
Un bit invalide ou non supporté a été spécifié dans le champ mode ; ou le champ mode était zéro.
EINVAL
Il n'y a pas de mise en correspondance dans la plage d'adresses spécifiée.
EINVAL
range.start ou range.len n'est pas un multiple de la taille de page du système ; ou, range.len est zéro ; ou ces champs sont invalides.
EINVAL
Il existe une mise en correspondance incompatible dans la plage d'adresses spécifiée.

NORMES

Linux.

HISTORIQUE

Linux 4.3.

EXEMPLES

Voir userfaultfd(2).
