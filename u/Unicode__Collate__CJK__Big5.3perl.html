NOM

Unicode::Collate::CJK::Big5 - pondération des idéogrammes unifiés CJK pour Unicode::Collate

SYNOPSIS

use Unicode::Collate;
use Unicode::Collate::CJK::Big5;
my $collator = Unicode::Collate->new(
    overrideCJK => \&Unicode::Collate::CJK::Big5::weightBig5
);

DESCRIPTION

"Unicode::Collate::CJK::Big5" fournit weightBig5(), qui est approprié pour "overrideCJK" de "Unicode::Collate" et permet le réglage des idéogrammes unifiés CJK selon l'ordre big5han de CLDR.
