User::pwent(3perl) Guide de référence du programmeur Perl User::pwent(3perl)

NOM

User::pwent - interface par nom aux fonctions intégrées getpw\*() de Perl

SYNTAXE

use User::pwent;
my $pw = getpwnam('daemon')       || die "Pas d'utilisateur daemon";
if ( $pw->uid == 1 && $pw->dir =~ m#^/(bin|tmp)?\z#s ) {
    print "gid 1 sur le répertoire racine";
}
my $real_shell = $pw->shell || '/bin/sh';
for (my ($fullname, $office, $workphone, $homephone) =
       split /\s*,\s*/, $pw->gecos)
{
   s/&/ucfirst(lc($pw->name))/ge;
}
use User::pwent qw(:FIELDS);
getpwnam('daemon')             || die "Pas d'utilisateur daemon";
if ( $pw_uid == 1 && $pw_dir =~ m#^/(bin|tmp)?\z#s ) {
    print "gid 1 sur le répertoire racine";
}
my $pw = getpw($whoever);
use User::pwent qw/:DEFAULT pw_has/;
if (pw_has(qw[gecos expire quota])) { .... }
if (pw_has("name uid gid passwd"))  { .... }
print "Votre structure pwd contient : ", scalar pw_has(), "\n";

DESCRIPTION

Les exportations par défaut de ce module remplacent les fonctions principales getpwent(), getpwuid() et getpwnam(), en les remplaçant par des versions qui renvoient des objets "User::pwent". Cet objet possède des méthodes qui renvoient le nom du champ de structure correspondant de la structure passwd de C, issue de pwd.h, sans le préfixe "pw_", à savoir "name", "passwd", "uid", "gid", "change", "age", "quota", "comment", "class", "gecos", "dir", "shell", et "expire". Les champs "passwd", "gecos" et "shell" sont marqués comme "tainted" (contaminés) lorsqu'ils sont exécutés en mode tainted.

Vous pouvez également importer tous les champs de la structure directement dans votre espace de noms en tant que variables régulières à l'aide du tag d'importation :FIELDS. (Notez que cela remplace toujours vos fonctions principales.) Accédez à ces champs en tant que variables nommées avec un préfixe "pw_" devant leurs noms de méthode. Ainsi, "$passwd_obj->shell" correspond à $pw_shell si vous importez les champs.

La fonction getpw() est une simple façade qui transfère un argument numérique à getpwuid() et les autres à getpwnam().

Pour accéder à cette fonctionnalité sans les remplacements des fonctions principales, passez une liste d'importation vide à "use", puis accédez aux fonctions avec leurs noms entièrement qualifiés. Les fonctions intégrées sont toujours accessibles via le pseudo-paquet "CORE::".

Spécificités Système

Perl suppose qu'aucune machine n'a jamais plus d'un des champs "change", "age" ou "quota" implémenté, ni plus d'un des champs "comment" ou "class". Certaines machines ne prennent pas en charge "expire", "gecos", ou prétendument, "passwd". Vous pouvez appeler ces méthodes, quelle que soit la machine sur laquelle vous vous trouvez, mais elles renverront "undef" si elles ne sont pas implémentées.

Vous pouvez demander si l'un de ces champs a été implémenté sur le système sur lequel Perl a été compilé en interrogeant la fonction importable "pw_has". Cette fonction renvoie vrai si tous les paramètres sont des champs pris en charge sur la plateforme de compilation, faux si un ou plusieurs ne le sont pas, et génère une exception si vous avez demandé un champ que Perl ne sait jamais fournir. Les paramètres peuvent être dans une chaîne séparée par des espaces, ou en tant qu'arguments séparés. Si vous ne passez aucun paramètre, la fonction renvoie la liste des champs de "struct pwd" pris en charge par la bibliothèque C de votre plateforme de compilation, sous forme de liste en contexte de liste, ou d'une chaîne séparée par des espaces en contexte scalaire. Notez que le fait que votre bibliothèque C possède un champ ne signifie pas nécessairement qu'il est entièrement implémenté sur ce système.

L'interprétation du champ "gecos" varie selon les systèmes, mais il contient traditionnellement 4 champs séparés par des virgules contenant le nom complet de l'utilisateur, l'emplacement du bureau, le numéro de téléphone professionnel et le numéro de téléphone personnel. Un "&" dans le champ gecos doit être remplacé par le nom de connexion de l'utilisateur correctement capitalisé "name". Le champ "shell", s'il est vide, doit être considéré comme étant /bin/sh. Perl ne fait pas cela pour vous. Le "passwd" est un hachage unidirectionnel, pas un texte clair, et ne peut pas être déchiffré sauf par devinette par force brute. Les systèmes sécurisés utilisent un hachage plus sécurisé que DES. Sur les systèmes prenant en charge les systèmes de mots de passe shadow, Perl renvoie automatiquement l'entrée shadow correspondante lorsqu'il est appelé par un utilisateur suffisamment autorisé, même si votre bibliothèque C fournie par le fournisseur était trop myope pour réaliser qu'elle devrait le faire.

Voir passwd(5) et getpwent(3) pour plus de détails.

NOTE

Bien que cette classe soit actuellement implémentée à l'aide du module Class::Struct pour construire une classe de type struct, vous ne devriez pas vous y fier.
