NOM

URI::WithBase - URIs qui se souviennent de leur base

SYNTAXE

$u1 = URI::WithBase->new($str, $base);
$u2 = $u1->abs;
$base = $u1->base;
$u1->base( $new_base )

DESCRIPTION

Ce module fournit la classe "URI::WithBase". Les objets de cette classe sont similaires aux objets "URI", mais peuvent également conserver leur base. La base représente le contexte dans lequel cet URI a été trouvé et peut être utilisée pour absolutiser ou relativiser l'URI. Toutes les méthodes décrites dans URI sont supportées pour les objets "URI::WithBase".

Les méthodes fournies en plus ou modifiées par rapport à celles de "URI" sont :

$uri = URI::WithBase->new($str, [$base])
Le constructeur prend un URI de base optionnel comme deuxième argument. S'il est fourni, cet argument initialise l'attribut de base.
$uri->base( [$new_base] )
Peut être utilisé pour obtenir ou définir la valeur de l'attribut de base. La valeur retournée, qui est l'ancienne valeur, est un objet URI ou "undef".
$uri->abs( [$base_uri] )
L'argument $base_uri est maintenant optionnel car l'objet transporte sa propre base. Un nouvel objet est retourné même si $uri est déjà absolu (alors que les objets URI simples retournent simplement eux-mêmes dans ce cas).
$uri->rel( [$base_uri] )
L'argument $base_uri est maintenant optionnel car l'objet transporte sa propre base. Un nouvel objet est toujours retourné.
