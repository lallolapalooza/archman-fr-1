URI__otpauth(3pm)

Paquet: perl-uri

Licences: PerlArtistic

URI::otpauth(3) Documentation Perl fournie par l'utilisateur URI::otpauth(3)

NOM

URI::otpauth - Schéma URI pour les clés secrètes pour les secrets OTP. Généralement trouvé dans les codes QR

VERSION

Version 5.29

SYNTAXE

use URI;
# URI otpauth à partir d'une URI textuelle
my $uri = URI->new( 'otpauth://totp/Example:alice@google.com?secret=NFZS25DINFZV643VOAZXELLTGNRXEM3UH4&issuer=Example' );
# même URI mais créée à partir d'arguments
my $uri = URI::otpauth->new( type => 'totp', issuer => 'Example', account_name => 'alice@google.com', secret => 'is-this_sup3r-s3cr3t?' );

DESCRIPTION

Ce schéma URI est défini dans https://github.com/google/google-authenticator/wiki/Key-Uri-Format/ :

SOUS-ROUTINES/METHODES

"new"

Crée une nouvelle URI::otpauth. Les arguments disponibles sont listés ci-dessous ;

  • account_name - il peut s'agir du nom du compte (probablement une adresse e-mail) utilisé lors de l'authentification avec ce secret. C'est un champ facultatif.
  • algorithm - il s'agit de la fonction de hachage cryptographique https://en.wikipedia.org/wiki/Cryptographic_hash_function qui doit être utilisée. Les valeurs actuelles sont SHA1 https://en.wikipedia.org/wiki/SHA-1, SHA256 https://en.wikipedia.org/wiki/SHA-2 ou SHA512 https://en.wikipedia.org/wiki/SHA-2. C'est un champ facultatif et il prendra SHA1 par défaut.
  • counter - ceci est requis uniquement lorsque le type est HOTP.
  • digits - ceci détermine la longueur https://github.com/google/google-authenticator/wiki/Key-Uri-Format/#digits du code présenté à l'utilisateur. C'est un champ facultatif et il aura 6 chiffres par défaut.
  • issuer - il peut s'agir de l'application / du système https://github.com/google/google-authenticator/wiki/Key-Uri-Format/#issuer pour lequel ce secret peut être utilisé pour l'authentification. C'est un champ facultatif.
  • label - il s'agit de l'émetteur et du nom du compte https://github.com/google/google-authenticator/wiki/Key-Uri-Format/#label joints par un caractère ":". C'est un champ facultatif.
  • period - il s'agit de la période pendant laquelle le code TOTP est valide https://github.com/google/google-authenticator/wiki/Key-Uri-Format/#counter. C'est un champ facultatif et il sera de 30 secondes par défaut.
  • secret - il s'agit de la clé <https://en.wikipedia.org/wiki/Key_(cryptography)> que l'algorithme TOTP https://en.wikipedia.org/wiki/Time-based_one-time_password/HOTP https://en.wikipedia.org/wiki/HMAC-based_one-time_password utilise pour dériver la valeur. Il s'agit d'une chaîne d'octets arbitraire et doit rester privée. Ce champ est obligatoire.
  • type - il peut s'agir de 'hotp https://en.wikipedia.org/wiki/HMAC-based_one-time_password' ou 'totp https://en.wikipedia.org/wiki/Time-based_one-time_password'. Ce champ sera 'totp' par défaut.

"algorithme"

Obtient ou définit l'algorithme de cette URI otpauth.

"nom_compte"

Obtient ou définit le nom du compte de cette URI otpauth.

"compteur"

Obtient ou définit le compteur de cette URI otpauth.

"chiffres"

Obtient ou définit les chiffres de cette URI otpauth.

"emetteur"

Obtient ou définit l'émetteur de cette URI otpauth.

"etiquette"

Obtient ou définit l'étiquette de cette URI otpauth.

"période"

Obtient ou définit la période de cette URI otpauth.

"secret"

Obtient ou définit le secret de cette URI otpauth.

"type"

Obtient ou définit le type de cette URI otpauth.

my $type = $uri->type('hotp');

CONFIGURATION ET ENVIRONNEMENT

URI::otpauth ne nécessite aucun fichier de configuration ni variable d'environnement.

DÉPENDANCES

URI

DIAGNOSTICS

"secret est un paramètre obligatoire pour URI::otpauth"
Le paramètre secret n'a pas été détecté pour la méthode URI::otpauth->new().

INCOMPATIBILITÉS

Aucune signalée.
