NOM

User::Identity::Location - localisation physique d'une personne

HÉRÉDITÉ

User::Identity::Location
  est un User::Identity::Item

SYNOPSIS

use User::Identity;
use User::Identity::Location;
my $me   = User::Identity->new(...);
my $addr = User::Identity::Location->new(...);
$me->add(location => $addr);
# Plus simple
use User::Identity;
my $me   = User::Identity->new(...);
my $addr = $me->add(location => ...);

DESCRIPTION

L'objet "User::Identity::Location" contient la description d'une localisation physique d'une personne : domicile, travail, voyage. Les localisations sont collectées par un objet User::Identity::Collection::Locations.

Presque toutes les méthodes peuvent retourner "undef". Certaines méthodes produisent une sortie spécifique à la langue ou au pays.

Attributs

Étensions de "Attributs" dans User::Identity::Item.

$obj->city()
La ville où se trouve l'adresse.
$obj->country()
Le pays où se trouve l'adresse. Si le nom du pays n'est pas connu mais qu'un code pays est défini, le nom sera recherché en utilisant Geography::Countries (s'il est installé).
$obj->countryCode()
Chaque pays a une abréviation standard ISO. Spécifiez le pays ou le code pays, et l'autre sera rempli automatiquement.
$obj->description()
Hérité, voir "Attributs" dans User::Identity::Item
$obj->fax()
Un ou plusieurs numéros de fax, comme phone().
$obj->fullAddress()
Crée une adresse à mettre sur un courrier postal, dans le format normal dans le pays de destination. Pour pouvoir faire cela, le code pays doit être connu. Si la ville n'est pas spécifiée ou si aucune rue ou boîte postale n'est fournie, "undef" sera retourné : une adresse incomplète.

» exemple:

print $uil->fullAddress;
print $user->find(location => 'home')->fullAddress;
$obj->name( [$nouveau_nom] )
Hérité, voir "Attributs" dans User::Identity::Item
$obj->organization()
L'organisation (par exemple, entreprise) liée à cette localisation.
$obj->phone()
Un ou plusieurs numéros de téléphone. Veuillez utiliser la notation internationale, qui commence par '+', par exemple "+31-26-12131". En contexte scalaire, seul le premier numéro est retourné. En contexte liste, tous les numéros sont présentés.
$obj->pobox()
Spécification de la boîte postale. Utilisez "B.P. 314", pas simplement 314.
$obj->poboxPostalCode()
Le code postal lié à la boîte postale. Défini par l'option "pobox_pc" de new().
$obj->postalCode()
Le code postal dépend fortement du pays. De plus, la position du code dans la chaîne formatée dépend du pays.
$obj->state()
L'état, important pour certains pays mais certainement pas pour les plus petits. Ne définissez cette valeur que si votre état doit apparaître sur les adresses imprimées.
$obj->street()
Retourne l'adresse de cette localisation. Depuis Perl 5.7.3, vous pouvez utiliser unicode dans les chaînes, alors pourquoi ne pas formater l'adresse joliment ?

User::Identity::Location - Arch manual pages

NAME

User::Identity::Location - location information for a user

INHERITANCE

User::Identity::Location

isa User::Identity

SYNOPSIS

  use User::Identity;

  my $loc = User::Identity::Location->new(
      country  => 'NL',
      province => 'Zuid-Holland',
      city     => 'Leiden',
      street   => 'Burchtpoort',
      number   => 5,
  );

  print $loc->country;     # NL
  print $loc->province;    # Zuid-Holland
  print $loc->city;        # Leiden
  print $loc->street;      # Burchtpoort
  print $loc->number;      # 5

  print $loc->format;      # Burchtpoort 5, 2312 HE Leiden, Zuid-Holland, NL
  print $loc->format(name => 'full'); # Burchtpoort 5, 2312 HE Leiden, Zuid-Holland, NL

DESCRIPTION

This is a subclass of User::Identity to store geographical location information.

METHODS

new()
Constructor for the Location object.
country()

Get or set the country code (e.g. 'NL').

province()

Get or set the province name.

city()

Get or set the city name.

street()

Get or set the street name.

number()

Get or set the street number. Can be a string like "5A".

postalcode()

Get or set the postal code. Note that formats differ widely per country.

format(%options)

Returns a string representation of the location. The name option can be 'full' to include all details, or omitted to only include the most relevant parts.
