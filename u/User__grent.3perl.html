User::grent(3perl) Guide du programmeur Perl User::grent(3perl)

NOM

User::grent - interface par nom aux fonctions intégrées getgr*() de Perl

SYNOPSIS

use User::grent;
my $gr = getgrgid(0) or die "Pas de groupe zéro";
if ( $gr->name eq 'wheel' && @{$gr->members} > 1 ) {
    print "gid zéro nom wheel, avec d'autres membres";
} 
use User::grent qw(:FIELDS);
getgrgid(0) or die "Pas de groupe zéro";
if ( $gr_name eq 'wheel' && @gr_members > 1 ) {
    print "gid zéro nom wheel, avec d'autres membres";
} 
my $gr = getgr($whoever);

DESCRIPTION

Les exportations par défaut de ce module remplacent les fonctions principales getgrent(), getgrgid() et getgrnam(), en les remplaçant par des versions qui renvoient des objets "User::grent". Cet objet possède des méthodes qui renvoient le nom du champ de structure du même nom de la structure passwd de C provenant de grp.h ; à savoir name, passwd, gid et members (pas mem). Les trois premiers renvoient des scalaires, le dernier une référence de tableau.

Vous pouvez également importer tous les champs de structure directement dans votre espace de noms en tant que variables régulières en utilisant la balise d'importation :FIELDS. (Notez que cela remplace toujours vos fonctions principales.) Accédez à ces champs en tant que variables nommées avec un préfixe "gr_". Ainsi, "$group_obj->gid()" correspond à $gr_gid si vous importez les champs. Les références de tableau sont disponibles en tant que variables de tableau régulières, donc "@{ $group_obj->members() }" serait simplement @gr_members.

La fonction getgr() est une simple interface qui transfère un argument numérique à getgrgid() et le reste à getgrnam().

Pour accéder à cette fonctionnalité sans les substitutions principales, passez à "use" une liste d'importation vide, puis accédez aux fonctions avec leurs noms qualifiés complets. D'autre part, les fonctions intégrées sont toujours disponibles via le pseudo-paquet "CORE::".

NOTE

Bien que cette classe soit actuellement implémentée à l'aide du module Class::Struct pour construire une classe de type structure, vous ne devriez pas vous y fier.
