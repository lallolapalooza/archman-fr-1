UFFDIO_COPY(2const) UFFDIO_COPY(2const)

NOM

UFFDIO_COPY - copie atomiquement un bloc de mémoire continu dans la plage enregistrée par userfault

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <linux/userfaultfd.h>  /* Définition des constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_COPY, struct uffdio_copy *argp);
#include <linux/userfaultfd.h>
struct uffdio_copy {
    __u64  dst;   /* Destination de la copie */
    __u64  src;   /* Source de la copie */
    __u64  len;   /* Nombre d'octets à copier */
    __u64  mode;  /* Indicateurs contrôlant le comportement de la copie */
    __s64  copy;  /* Nombre d'octets copiés, ou erreur négativée */
};

DESCRIPTION

Copie atomiquement un bloc de mémoire continu dans la plage enregistrée par userfault et réveille éventuellement le thread bloqué.

La valeur suivante peut être combinée par OU bit à bit dans mode pour changer le comportement de l'opération UFFDIO_COPY :

UFFDIO_COPY_MODE_DONTWAKE
Ne pas réveiller le thread qui attend la résolution du défaut de page.
UFFDIO_COPY_MODE_WP
Copier la page avec une permission en lecture seule. Cela permet à l'utilisateur de piéger la prochaine écriture sur la page, ce qui bloquera et générera un autre message de défaut de page en écriture protégée. Ceci est utilisé uniquement lorsque les modes UFFDIO_REGISTER_MODE_MISSING et UFFDIO_REGISTER_MODE_WP sont activés pour la plage enregistrée.

Le champ copy est utilisé par le noyau pour renvoyer le nombre d'octets effectivement copiés, ou une erreur (une valeur négativée style errno). Le champ copy est uniquement en sortie ; il n'est pas lu par l'opération UFFDIO_COPY.

VALEUR RENVOYÉE

En cas de succès, 0 est renvoyé. Dans ce cas, la zone entière a été copiée.

En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EAGAIN
Le nombre d'octets copiés (c'est-à-dire la valeur renvoyée dans le champ copy) n'est pas égal à la valeur spécifiée dans le champ len.
EINVAL
Soit dst soit len n'était pas un multiple de la taille de page système, soit la plage spécifiée par src et len ou dst et len était invalide.
EINVAL
Un bit invalide a été spécifié dans le champ mode.
ENOENT (depuis Linux 4.11)
Le processus fautif a modifié sa disposition de mémoire virtuelle simultanément à une opération UFFDIO_COPY en attente.
ENOSPC (de Linux 4.11 à Linux 4.13)
Le processus fautif s'est terminé au moment d'une opération UFFDIO_COPY.
ESRCH (depuis Linux 4.13)
Le processus fautif s'est terminé au moment d'une opération UFFDIO_COPY.

NORMES

Linux.

HISTORIQUE

Linux 4.3.

EXEMPLES

Voir userfaultfd(2).

VOIR AUSSI
