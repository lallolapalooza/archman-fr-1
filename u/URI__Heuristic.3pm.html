NOM

URI::Heuristic - Développer des URI par heuristiques

SYNOPSIS

use URI::Heuristic qw(uf_uristr);
$u = uf_uristr("example");          # http://www.example.com
$u = uf_uristr("www.sol.no/sol");   # http://www.sol.no/sol
$u = uf_uristr("aas");              # http://www.aas.no
$u = uf_uristr("ftp.funet.fi");     # ftp://ftp.funet.fi
$u = uf_uristr("/etc/passwd");      # file:/etc/passwd

DESCRIPTION

Ce module fournit des fonctions qui développent des chaînes en de véritables URI absolues en utilisant quelques heuristiques intégrées. Les chaînes qui représentent déjà des URI absolues (c'est-à-dire celles qui commencent par une partie "schéma:") ne sont jamais modifiées et sont retournées telles quelles. L'utilisation principale de ces fonctions est de permettre des URI abrégées, similaires à ce que de nombreux navigateurs web autorisent pour les URI tapées par l'utilisateur.

Les fonctions suivantes sont fournies :

uf_uristr($str)
Tente de transformer la chaîne argument en une chaîne URI absolue correcte. Le préfixe "uf_" signifie "User Friendly" (convivial). Sous MacOS, il suppose que toute chaîne avec un schéma d'URL courant (http, ftp, etc.) est une URL plutôt qu'un chemin local. Ainsi, ne nommez pas vos volumes d'après des schémas d'URL courants et n'attendez pas que uf_uristr() construise des URL file: valides pour vous sur ces volumes, car cela n'arrivera pas.
uf_uri($str)
Fonctionne de la même manière que uf_uristr() mais retourne un objet "URI".

ENVIRONNEMENT

Si la partie nom d'hôte d'une URI ne contient aucun point, des suppositions qualifiées sont faites. Ces suppositions sont régies par les variables d'environnement suivantes :

PAYS
Le code pays à deux lettres (ISO 3166) de votre emplacement. Si le nom de domaine de votre hôte se termine par deux lettres, il est considéré comme le pays par défaut. Voir aussi Locale::Country.
HTTP_ACCEPT_LANGUAGE, LC_ALL, LANG
Si COUNTRY n'est pas défini, ces variables d'environnement standard sont examinées et les informations de pays (pas de langue) éventuellement trouvées y sont utilisées comme pays par défaut.
URL_GUESS_PATTERN
Contient une liste d'expressions d'URL séparées par des espaces à essayer. La chaîne "ACME" est utilisée pour une raison quelconque comme espace réservé pour le nom d'hôte dans l'URL fournie. Exemple : 
URL_GUESS_PATTERN="www.ACME.no www.ACME.se www.ACME.com"
export URL_GUESS_PATTERN

Spécifier URL_GUESS_PATTERN désactive toute règle de supposition basée sur le pays. Une URL_GUESS_PATTERN vide désactive toute supposition impliquant des recherches de noms d'hôtes.
