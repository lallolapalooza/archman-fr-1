NOM

User::Identity::Collection::Systems - une collection de descriptions de système

HÉRITAGE

User::Identity::Collection::Systems
  est un User::Identity::Collection
  est un User::Identity::Item

SYNOPIS

DESCRIPTION

L'objet User::Identity::Collection::Systems maintient un ensemble d'objets User::Identity::System, décrivant chacun une connexion de l'utilisateur sur un système donné.

Étendu la section "DESCRIPTION" dans User::Identity::Collection.

DIAGNOSTICS

Erreur : $objet n'est pas une collection.
Le premier argument est un objet, mais pas d'une classe qui étend User::Identity::Collection. Lancé par addCollection()
Erreur : Impossible de créer un $type à ajouter à ma collection.
Certaines options sont spécifiées pour créer un objet $type, qui est natif à cette collection. Cependant, pour une raison quelconque, cela a échoué. Lancé par addRole()
Erreur : Impossible de charger le module de collection pour $type ($class).
Soit le $type spécifié n'existe pas, soit le module nommé $class renvoie des erreurs de compilation. Si le type tel que spécifié dans l'avertissement n'est pas le nom d'un paquet, vous avez spécifié un surnom qui n'était pas défini. Peut-être avez-vous oublié le 'require' du paquet qui définit le surnom. Lancé par addCollection()
Erreur : Impossible de renommer $nom en $nouveau_nom : existe déjà
Lancé par renameRole()
Erreur : Impossible de renommer $nom en $nouveau_nom : n'existe pas
Lancé par renameRole()
Erreur : La création d'une collection via $class a échoué.
La classe $class a compilé, mais il n'a pas été possible de créer un objet de cette classe en utilisant les options que vous avez spécifiées. Lancé par addCollection()
Erreur : Je ne sais pas quel type de collection vous voulez ajouter.
Si vous ajoutez une collection, il doit s'agir soit d'un objet collection, soit d'une liste d'options pouvant être utilisées pour créer un objet collection. Dans ce dernier cas, le type de collection doit être spécifié. Lancé par addCollection()
Avertissement : Pas de collection $nom
La collection avec le nom $nom n'existe pas et ne peut pas être créée. Lancé par add()
Erreur : Type de rôle incorrect pour $collection : attend un $attendu mais a obtenu un $type
Chaque $collection regroupe des ensembles de rôles d'un type spécifique ($attendu). Vous ne pouvez pas ajouter des objets d'un $type différent. Lancé par addRole()
