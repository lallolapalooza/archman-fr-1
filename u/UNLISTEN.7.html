NOM

UNLISTEN - cesser d'écouter les notifications

SYNTAXE

UNLISTEN { canal | * }

DESCRIPTION

UNLISTEN est utilisé pour supprimer un enregistrement existant pour les événements NOTIFY. UNLISTEN annule tout enregistrement existant de la session PostgreSQL actuelle en tant qu'écouteur sur le canal de notification nommé canal. Le caractère générique spécial * annule tous les enregistrements d'écoute pour la session actuelle.

NOTIFY(7) contient une discussion plus approfondie de l'utilisation de LISTEN et NOTIFY.

PARAMETRES

canal

Nom d'un canal de notification (n'importe quel identifiant).

*

Tous les enregistrements d'écoute actuels pour cette session sont effacés.

NOTES

Vous pouvez demander à ne plus écouter quelque chose que vous n'écoutiez pas ; aucun avertissement ou erreur n'apparaîtra.

À la fin de chaque session, UNLISTEN * est automatiquement exécuté.

Une transaction qui a exécuté UNLISTEN ne peut pas être préparée pour un engagement en deux phases.

EXEMPLES

Pour créer un enregistrement :

LISTEN virtual;
NOTIFY virtual;
Notification asynchrone « virtual » reçue du processus serveur avec le PID 8448.

Une fois UNLISTEN exécuté, les messages NOTIFY ultérieurs seront ignorés :

UNLISTEN virtual;
NOTIFY virtual;
-- aucun événement NOTIFY n'est reçu

COMPATIBILITE

Il n'y a pas de commande UNLISTEN dans la norme SQL.

VOIR AUSSI

LISTEN(7), NOTIFY(7)
