UFFDIO_POISON(2const) UFFDIO_POISON(2const)

NOM

UFFDIO_POISON - marquer une plage d'adresses comme « empoisonnée »

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/userfaultfd.h>  /* Définition des constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_POISON, ...);
#include <linux/userfaultfd.h>
struct uffdio_poison {
	struct uffdio_range  range;
	                  /* Plage dans laquelle installer les marqueurs PTE de poison */
	__u64   mode;     /* Indicateurs contrôlant le comportement du poison */
	__s64   updated;  /* Nombre d'octets empoisonnés, ou erreur négative */
};

DESCRIPTION

Marque une plage d'adresses comme « empoisonnée ». Les accès futurs à ces adresses déclencheront un signal SIGBUS. Contrairement à MADV_HWPOISON, cela fonctionne en installant des entrées de table de pages, plutôt qu'en « empoisonnant vraiment » les pages physiques sous-jacentes. Cela signifie que cela n'affecte que cet espace d'adressage particulier.

La valeur suivante peut être combinée par OR bit à bit dans mode pour modifier le comportement de l'opération UFFDIO_POISON :

UFFDIO_POISON_MODE_DONTWAKE
Ne pas réveiller le thread qui attend la résolution du défaut de page.

Le champ updated est utilisé par le noyau pour retourner le nombre d'octets qui ont été effectivement empoisonnés, ou une erreur de la même manière que UFFDIO_COPY. Si la valeur retournée dans le champ updated ne correspond pas à la valeur spécifiée dans range.len, l'opération échoue avec l'erreur EAGAIN. Le champ updated est en sortie uniquement ; il n'est pas lu par l'opération UFFDIO_POISON.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. Dans ce cas, toute la zone a été empoisonnée.

En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EAGAIN
Le nombre d'octets mappés (c'est-à-dire la valeur retournée dans le champ updated) n'est pas égal à la valeur spécifiée dans le champ range.len.
EINVAL
Soit range.start, soit range.len n'était pas un multiple de la taille de page système ; soit range.len était zéro ; soit la plage spécifiée était invalide.
EINVAL
Un bit invalide a été spécifié dans le champ mode.
EEXIST
Une ou plusieurs pages étaient déjà mappées dans la plage donnée.
ENOENT
Le processus fautif a modifié sa disposition de mémoire virtuelle simultanément avec une opération UFFDIO_POISON en attente.
ENOMEM
L'allocation de mémoire pour les entrées de table de pages a échoué.
ESRCH
Le processus fautif s'est terminé au moment d'une opération UFFDIO_POISON.

NORMES

Linux.

HISTORIQUE

Linux 6.6.

EXEMPLES

Voir userfaultfd(2).
