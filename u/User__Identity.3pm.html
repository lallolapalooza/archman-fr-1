NOM

User::Identity - maintenir des informations sur une personne physique

HERITAGE

User::Identity
  est un User::Identity::Item

SYNOPSIS

use User::Identity;
my $moi = User::Identity->new(
         'john',
  firstname => 'John',
  surname   => 'Doe'
 );
print $moi->fullName  # affiche "John Doe"
print $moi;           # idem

DESCRIPTION

La distribution "User-Identity" est créée pour maintenir un ensemble d'objets informationnels liés à un seul utilisateur. Le module "User::Identity" essaie d'être intelligent en fournissant des valeurs par défaut, des conversions et des combinaisons souvent requises.

Ceci est une version de maintenance pour l'ancienne interface. Lisez https://github.com/markov2/perl5-Mail-Box/wiki/ pour savoir comment passer à la version 4.

Les identités n'implémentent aucun type de stockage et peuvent donc être créées par n'importe quel programme Perl simple ou complexe. De cette façon, il est plus flexible qu'un fichier XML pour stocker les données. Par exemple, vous pouvez décider de stocker les données avec Data::Dumper, Storable, DBI, AddressBook ou autre. Les extensions pour simplifier cette tâche sont encore à développer.

Si vous avez besoin d'autres types d'informations utilisateur, veuillez contacter l'auteur du module.

SURCHARGE

surcharge: "" stringification
Lorsqu'un "User::Identity" est utilisé comme une chaîne de caractères, il est automatiquement traduit en fullName() de l'utilisateur concerné.

» exemple :

my $moi = User::Identity->new(...)
print $moi;          # idem que  print $moi->fullName
print "Je suis $moi\n"; # également stringification

Attributs

Étend "Attributes" dans User::Identity::Item.

$obj->age()
Calculé à partir de la date de naissance jusqu'au moment présent, en tant qu'entier. Le jour de l'anniversaire, le nombre est déjà incrémenté.
$obj->birth()
Retourne la date dans un format standardisé : YYYYMMDD, facile à trier et sélectionner. Cela peut retourner "undef", même si dateOfBirth() contient une valeur, simplement parce que le format n'est pas compris. Le mois ou le jour peuvent contenir '00' pour indiquer que ces valeurs ne sont pas connues.
$obj->charset()
Le jeu de caractères préféré de l'utilisateur, qui par défaut prend la valeur de la variable d'environnement LC_CTYPE.
$obj->courtesy()
Le titre de civilité est utilisé pour s'adresser aux gens de manière très formelle. Les valeurs sont comme "M.", "Mme", "Sir", "Frau", "Heer", "de heer", "mevrouw". Cela fournit souvent un moyen de connaître le genre de la personne à qui l'on s'adresse.
$obj->dateOfBirth()
Retourne la date de naissance, telle que spécifiée lors de l'instanciation.
$obj->description()
Hérité, voir "Attributes" dans User::Identity::Item
$obj->firstname()
Retourne le prénom de l'utilisateur. S'il n'est pas défini explicitement, il est dérivé du surnom, puis capitalisé si nécessaire.
$obj->formalName()
Retourne un nom formel pour l'utilisateur. S'il n'est pas défini comme paramètre d'instanciation (voir new()), il est construit à partir d'autres informations disponibles, ce qui peut résulter en un nom incorrect ou incomplet. Le résultat est construit à partir de "courtesy initials prefix surname title".
$obj->fullName()
Si ceci n'est pas spécifié comme valeur lors de la construction de l'objet, il est deviné en fonction d'autres valeurs connues comme "firstname prefix surname". Si un nom de famille est fourni sans prénom, le surnom est pris comme prénom. Lorsqu'un prénom est fourni sans nom de famille, le surnom est pris comme nom de famille. Si les deux ne sont pas fournis, alors le surnom est utilisé comme nom complet.
$obj->gender()
Retourne le genre spécifié de la personne, tel que spécifié lors de l'instanciation, qui pourrait être comme 'Male', 'm', 'homme', 'man'. Il n'y a pas de comportement intelligent ici : la valeur exacte spécifiée est retournée. Les méthodes isMale(), isFemale() et courtesy() sont intelligentes.
$obj->initials()
Les initiales, qui peuvent être dérivées des premières lettres du prénom.
$obj->isFemale()
Voir isMale() : retourne "true" si nous sommes sûrs que l'utilisateur est une femme.
$obj->isMale()
Retourne "true" si nous sommes sûrs que l'utilisateur est de sexe masculin. Ceci est spécifié comme genre lors de l'instanciation, ou dérivé de la valeur de courtoisie. Les méthodes isMale et isFemale ne sont pas complémentaires : elles peuvent toutes deux retourner "false" pour le même utilisateur, auquel cas le genre est indéterminé.
$obj->language()
Peut contenir une liste ou un seul nom de langue, tel que défini par le RFC. Les exemples sont 'en', 'en-GB', 'nl-BE'. La langue par défaut est 'en' (Anglais).

DIAGNOSTICS

Erreur : $object n'est pas une collection.
Le premier argument est un objet, mais pas d'une classe qui hérite de User::Identity::Collection. Appel par addCollection()
Erreur : Impossible de charger le module de collection pour $type ($class).
Soit le $type spécifié n'existe pas, soit le module nommé $class renvoie des erreurs de compilation. Si le type spécifié dans l'avertissement n'est pas le nom d'un paquet, vous avez spécifié un surnom qui n'était pas défini. Peut-être avez-vous oublié le 'require' du paquet qui définit le surnom. Appel par addCollection()
Erreur : La création d'une collection via $class a échoué.
La $class a été compilée, mais il n'a pas été possible de créer un objet de cette classe en utilisant les options que vous avez spécifiées. Appel par addCollection()
Erreur : Je ne sais pas quel type de collection vous souhaitez ajouter.
Si vous ajoutez une collection, elle doit être soit un objet de collection, soit une liste d'options qui peuvent être utilisées pour créer un objet de collection. Dans ce dernier cas, le type de collection doit être spécifié. Appel par addCollection()
Avertissement : Pas de collection $name
La collection avec $name n'existe pas et ne peut pas être créée. Appel par add()
