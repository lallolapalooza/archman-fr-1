NAME

ioctl_console — oprations on the console tty device

SYNOPSIS

#include <linux/kd.h>

#include <linux/vt.h>

#include <sys/ioctl.h>

int ioctl(int fd, unsigned long request, ...);

DESCRIPTION

The console driver supports a number of ioctl operations. Some of them are specific to the console, others are more general tty operations. The console-specific operations are described below. The fd argument is a file descriptor, typically opened on /dev/tty0 or /dev/console, or any other slave pseudo-terminal device.

PIO_UNISCRNMAP
Charge la table "définissable par l'utilisateur" (quatrième) dans le noyau, qui mappe les octets vers des Unicodes, lesquels sont ensuite traduits en symboles d'écran selon la carte Unicode vers police actuellement chargée. Des Unicodes spéciaux à partir de U+F000 peuvent être utilisés pour mapper directement vers les symboles de police. (Depuis Linux 1.3.1.)
GIO_UNIMAP
Obtient la carte Unicode vers police depuis le noyau. argp pointe vers une

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

où entries pointe vers un tableau de

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Depuis Linux 1.1.92.)
PIO_UNIMAP
Place la carte unicode vers police dans le noyau. argp pointe vers une struct unimapdesc. (Depuis Linux 1.1.92)
PIO_UNIMAPCLR
Efface la table, éventuellement suggère un algorithme de hachage. argp pointe vers une

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 si pas d'avis */
    unsigned short advised_hashstep;  /* 0 si pas d'avis */
    unsigned short advised_hashlevel; /* 0 si pas d'avis */
};

(Depuis Linux 1.1.92.)
KDGKBMODE
Obtient le mode clavier actuel. argp pointe vers un long qui est défini sur l'une des valeurs suivantes :
K_RAW 0x00 /* Mode brut (scancode) */
K_XLATE 0x01 /* Traduire les keycodes en utilisant la keymap */
K_MEDIUMRAW 0x02 /* Mode brut moyen (scancode) */
K_UNICODE 0x03 /* Mode Unicode */
K_OFF 0x04 /* Mode désactivé (depuis Linux 2.6.39) */
KDSKBMODE
Définit le mode clavier actuel. argp est un long égal à l'une des valeurs montrées pour KDGKBMODE.

K_METABIT 0x03 définir le bit de poids fort
K_ESCPREFIX 0x04 préfixe d'échappement
KDSKBMETA
Définit le mode de gestion de la touche méta. argp est un long égal à l'une des valeurs montrées ci-dessus pour KDGKBMETA.
KDGKBENT
Obtient une entrée dans la table de traduction des touches (keycode vers code d'action). argp pointe vers une

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

avec les deux premiers membres remplis : kb_table sélectionne la table des touches (0 <= kb_table < MAX_NR_KEYMAPS), et kb_index est le keycode (0 <= kb_index < NR_KEYS). kb_value est défini sur le code d'action correspondant, ou K_HOLE s'il n'y a pas de telle touche, ou K_NOSUCHMAP si kb_table est invalide.
KDSKBENT
Définit une entrée dans la table de traduction. argp pointe vers une struct kbentry.
KDGKBSENT
Obtient une chaîne de touche de fonction. argp pointe vers une

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string est défini sur la chaîne (terminée par un zéro nul) correspondant au code d'action de la kb_func-ième touche de fonction.
KDSKBSENT
Définit une entrée de chaîne de touche de fonction. argp pointe vers une struct kbsentry.
KDGKBDIACR
Lit la table des caractères accentués du noyau. argp pointe vers une

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

où kb_cnt est le nombre d'entrées dans le tableau, dont chacune est une

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Lit une entrée de la table des keycodes du noyau (scan code vers keycode). argp pointe vers une

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode est défini pour correspondre au scancode donné. (89 <= scancode <= 255 seulement. Pour 1 <= scancode <= 88, keycode==scancode.) (Depuis Linux 1.1.63.)
KDSETKEYCODE
Écrit une entrée de la table des keycodes du noyau. argp pointe vers une struct kbkeycode. (Depuis Linux 1.1.63.)
KDSIGACCEPT
Le processus appelant indique sa volonté d'accepter le signal argp lorsqu'il est généré par la pression d'une combinaison de touches appropriée. (1 <= argp <= NSIG). (Voir spawn_console() dans linux/drivers/char/keyboard.c.)

VALEUR DE RETOUR

En cas de succès, 0 est retourné (sauf indication contraire). En cas d'échec, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
argp est invalide.
