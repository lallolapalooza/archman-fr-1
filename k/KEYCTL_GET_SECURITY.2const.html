KEYCTL_GET_SECURITY(2const) KEYCTL_GET_SECURITY(2const)

NOM

KEYCTL_GET_SECURITY - manipule la facilité de gestion des clés du noyau

BIBLIOTHEQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/keyctl.h>  /* Définition des constantes KEY* */
#include <sys/syscall.h>   /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(size_t n;
             SYS_keyctl, KEYCTL_GET_SECURITY, key_serial_t key,
             char buf[_Nullable n], size_t n);

DESCRIPTION

KEYCTL_GET_SECURITY (depuis Linux 2.6.26)
Obtenir le label de sécurité LSM (Linux Security Module) de la clé spécifiée.

L'ID de la clé dont le label de sécurité doit être récupéré est spécifié dans key. Le label de sécurité (terminé par un octet nul) sera placé dans le tampon pointé par l'argument buf ; la taille du tampon doit être fournie dans n.

Si buf est spécifié comme NULL ou si la taille du tampon spécifiée dans n est trop petite, la taille complète de la chaîne de label de sécurité (y compris l'octet nul de terminaison) est retournée comme résultat de la fonction, et rien n'est copié dans le tampon.

L'appelant doit avoir la permission de vue sur la clé spécifiée.

La chaîne de label de sécurité retournée sera rendue sous une forme appropriée au LSM en vigueur. Par exemple, avec SELinux, elle peut ressembler à :


unconfined_u:unconfined_r:unconfined_t:s0-s0:c0.c1023

Si aucun LSM n'est actuellement en vigueur, alors une chaîne vide est placée dans le tampon.

VALEUR DE RETOUR

En cas de succès, la taille de la chaîne de label de sécurité LSM (y compris l'octet nul de terminaison), indépendamment de la taille du tampon fourni.

En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

VERSIONS

Une enveloppe est fournie dans la bibliothèque libkeyutils : keyctl_get_security(3).

NORMES

Linux.

HISTORIQUE

Linux 2.6.26.

VOIR AUSSI

keyctl(2), keyctl_get_security(3), keyctl_get_security_alloc(3)
