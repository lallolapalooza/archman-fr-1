KEYCTL_RESTRICT_KEYRING(2const) KEYCTL_RESTRICT_KEYRING(2const)

NOM

KEYCTL_RESTRICT_KEYRING - restreindre les clés pouvant être liées à un anneau de clés

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/keyctl.h>  /* Définition des constantes KEY* */
#include <sys/syscall.h>   /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_RESTRICT_KEYRING, key_serial_t keyring,
             const char *_Nullable type, const char *restriction);

DESCRIPTION

Applique une restriction de liaison de clé à l'anneau de clés dont l'ID est fourni dans keyring. L'appelant doit avoir la permission setattr sur la clé. Si type est NULL, toute tentative d'ajout d'une clé à l'anneau de clés est bloquée ; sinon, il contient un pointeur vers une chaîne avec un nom de type de clé et restriction contient un pointeur vers une chaîne qui décrit la restriction spécifique au type. Depuis Linux 4.12, seul le type "asymmetric" a des restrictions définies :

builtin_trusted
N'autorise que les clés signées par une clé liée à l'anneau de clés intégré (".builtin_trusted_keys").
builtin_and_secondary_trusted
N'autorise que les clés signées par une clé liée à l'anneau de clés secondaire (".secondary_trusted_keys") ou, par extension, une clé dans un anneau de clés intégré, car ce dernier est lié au premier.
key_or_keyring:key
key_or_keyring:key:chain
Si key spécifie l'ID d'une clé de type "asymmetric", alors seules les clés signées par cette clé sont autorisées.
Si key spécifie l'ID d'un anneau de clés, alors seules les clés signées par une clé liée à cet anneau de clés sont autorisées.
Si ":chain" est spécifié, les clés signées par des clés liées à l'anneau de clés de destination (c'est-à-dire l'anneau de clés dont l'ID est spécifié dans l'argument keyring) sont également autorisées.

Notez qu'une restriction ne peut être configurée qu'une seule fois pour l'anneau de clés spécifié ; une fois qu'une restriction est définie, elle ne peut pas être remplacée.

VALEUR DE RETOUR

En cas de succès, 0 est retourné.

En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EDEADLK
La restriction d'anneau de clés demandée entraînerait une boucle.
EEXIST
keyring a déjà une restriction définie.
ENOENT
Le type fourni dans l'argument type ne permet pas de définir des restrictions de liaison de clés.
EOPNOTSUPP
type était "asymmetric", et la clé spécifiée dans la spécification de restriction fournie dans restriction a un type autre que "asymmetric" ou "keyring".

VERSIONS

Une enveloppe est fournie dans la bibliothèque libkeyutils : keyctl_restrict_keyring(3).

NORMES

Linux.

HISTORIQUE

Linux 4.12.

VOIR AUSSI

keyctl(2), keyctl_restrict_keyring(3)
