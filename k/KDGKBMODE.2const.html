ioctl_kd(2) Manuel des appels système ioctl_kd(2)

NOM

ioctl_kd - ioctls pour les terminaux console et les consoles virtuelles

SYNTAXE

#include <linux/kd.h>  /* Définition des constantes d'opération */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPTION

Les opérations ioctl(2) suivantes, spécifiques à Linux, sont prises en charge pour les terminaux console et les consoles virtuelles.

KDGETLED
Obtenir l'état des LED. argp pointe vers un char. Les trois bits de poids faible de *argp sont définis à l'état des LED, comme suit :
LED_CAP 0x04 LED de verrouillage Majuscule
LED_NUM 0x02 LED de verrouillage Numérique
LED_SCR 0x01 LED de verrouillage Défilement
KDSETLED
Définir les LED. Les LED sont définies pour correspondre aux trois bits de poids faible de l'entier non signé argp. Cependant, si un bit d'ordre supérieur est défini, les LED reviennent à la normale : affichant l'état des fonctions du clavier de majuscule, numérique et défilement.

Avant Linux 1.1.54, les LED reflétaient simplement l'état des indicateurs correspondants du clavier, et KDGETLED/KDSETLED modifiaient également les indicateurs du clavier. Depuis Linux 1.1.54, les LED peuvent afficher des informations arbitraires, mais par défaut, elles affichent les indicateurs du clavier. Les deux ioctls suivants sont utilisés pour accéder aux indicateurs du clavier.

KDGKBLED
Obtenir les indicateurs du clavier Majuscule, Numérique, Défilement (pas les lumières). argp pointe vers un caractère qui est défini à l'état de l'indicateur. Les trois bits de poids faible (masque 0x7) obtiennent l'état actuel de l'indicateur, et les bits de poids faible de la prochaine nibble (masque 0x70) obtiennent l'état par défaut de l'indicateur. (Depuis Linux 1.1.54.)
KDSKBLED
Définir les indicateurs du clavier Majuscule, Numérique, Défilement (pas les lumières). argp est un entier non signé qui contient l'état souhaité de l'indicateur. Les trois bits de poids faible (masque 0x7) contiennent l'état de l'indicateur, et les bits de poids faible de la prochaine nibble (masque 0x70) contiennent l'état par défaut de l'indicateur. (Depuis Linux 1.1.54.)
KDGKBTYPE
Obtenir le type de clavier. Ceci retourne la valeur KB_101, définie comme 0x02.
KDADDIO
Ajouter un port d'E/S comme valide. Équivalent à ioperm(arg,1,1).
KDDELIO
Supprimer un port d'E/S comme valide. Équivalent à ioperm(arg,1,0).
KDENABIO
Activer l'E/S vers la carte vidéo. Équivalent à ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
Désactiver l'E/S vers la carte vidéo. Équivalent à ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
Définir le mode texte/graphique. argp est un entier non signé contenant l'un des éléments suivants :
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
Obtenir le mode texte/graphique. argp pointe vers un int qui est défini à l'une des valeurs indiquées ci-dessus pour KDSETMODE.
KDMKTONE
Générer un son d'une durée spécifiée. Les 16 bits de poids faible de l'entier non signé argp spécifient la période en cycles d'horloge, et les 16 bits de poids fort donnent la durée en ms. Si la durée est zéro, le son est désactivé. Le contrôle retourne immédiatement. Par exemple, argp = (125<<16) + 0x637 spécifierait le bip normalement associé à une touche Ctrl-G. (Donc, depuis Linux 0.99pl1 ; cassé dans Linux 2.1.49-50.)
KIOCSOUND
Démarrer ou arrêter la génération de son. Les 16 bits de poids faible de argp spécifient la période en cycles d'horloge (c'est-à-dire, argp = 1193180/fréquence). argp = 0 désactive le son. Dans tous les cas, le contrôle retourne immédiatement.
GIO_CMAP
Obtenir la table de couleurs par défaut actuelle du noyau. argp pointe vers un tableau de 48 octets. (Depuis Linux 1.3.3.)
PIO_CMAP
Changer la table de couleurs par défaut en mode texte. argp pointe vers un tableau de 48 octets qui contient, dans l'ordre, les valeurs Rouge, Vert et Bleu pour les 16 couleurs d'écran disponibles : 0 est éteint, et 255 est à pleine intensité. Les couleurs par défaut sont, dans l'ordre : noir, rouge sombre, vert sombre, marron, bleu sombre, violet sombre, cyan sombre, gris clair, gris sombre, rouge vif, vert vif, jaune, bleu vif, violet vif, cyan vif, et blanc. (Depuis Linux 1.3.3.)
GIO_FONT
Récupère la police d'écran de 256 caractères sous forme étendue. argp pointe vers un tableau de 8192 octets. Échoue avec le code d'erreur EINVAL si la police actuellement chargée est une police de 512 caractères, ou si la console n'est pas en mode texte.
GIO_FONTX
Récupère la police d'écran et les informations associées. argp pointe vers une struct consolefontdesc (voir PIO_FONTX). Lors de l'appel, le champ charcount doit être défini au nombre maximum de caractères qui rentreraient dans le tampon pointé par chardata. Au retour, charcount et charheight sont remplis avec les données respectives pour la police actuellement chargée, et le tableau chardata contient les données de la police si la valeur initiale de charcount indiquait que l'espace était suffisant ; sinon, le tampon est intact et errno est défini à ENOMEM. (Depuis Linux 1.3.1.)
PIO_FONT
Définit la police d'écran de 256 caractères. Charge la police dans le générateur de caractères EGA/VGA. argp pointe vers une carte de 8192 octets, avec 32 octets par caractère. Seuls les N premiers sont utilisés pour une police 8xN (0 < N <= 32). Cet appel invalide également le mappage Unicode.
PIO_FONTX
Définit la police d'écran et les informations de rendu associées. argp pointe vers une

struct consolefontdesc {
    unsigned short charcount;  /* caractères dans la police
                                  (256 ou 512) */
    unsigned short charheight; /* lignes de balayage par
                                  caractère (1-32) */
    char          *chardata;   /* données de la police sous
                                  forme étendue */
};

Si nécessaire, l'écran sera redimensionné de manière appropriée, et SIGWINCH sera envoyé aux processus appropriés. Cet appel invalide également le mappage Unicode. (Depuis Linux 1.3.1.)
PIO_FONTRESET
Réinitialise la police d'écran, la taille et le mappage Unicode aux valeurs par défaut du démarrage. argp n'est pas utilisé, mais doit être défini à NULL pour garantir la compatibilité avec les futures versions de Linux. (Depuis Linux 1.3.28.)
GIO_SCRNMAP
Obtenir la carte d'écran du noyau. argp pointe vers une zone de taille E_TABSZ, qui est chargée avec les positions de police utilisées pour afficher chaque caractère. Cet appel est susceptible de retourner des informations inutiles si la police actuellement chargée contient plus de 256 caractères.
GIO_UNISCRNMAP
Obtenir la carte d'écran Unicode complète du noyau. argp pointe vers une zone de taille E_TABSZ*sizeof(unsigned short), qui est chargée avec les Unicodes que représente chaque caractère. Un ensemble spécial d'Unicodes, commençant à U+F000, est utilisé pour représenter les mappages "directement dans la police". (Depuis Linux 1.3.1.)
PIO_SCRNMAP
Charge la table "définissable par l'utilisateur" (la quatrième) dans le noyau, qui mappe les octets en symboles d'écran de console. argp pointe vers une zone de taille E_TABSZ.

SYNTAXE

ioctl(2), ioctl_console(2)

DESCRIPTION

Cette section décrit les fonctions et leurs paramètres.

VALEUR RETOURNÉE

En cas de succès, 0 est retourné (sauf indication contraire). En cas d'échec, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
argp est invalide.

NORMES

Linux.
