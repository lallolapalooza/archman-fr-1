NAME

ioctl_console — console-specific ioctl() requests

SYNOPSIS

#include <linux/kd.h>

#include <linux/vt.h>

#include <linux/major.h>

#include <linux/console.h>

#include <linux/input.h>

#include <linux/major.h>

#include <sys/ioctl.h>

long ioctl(int fd, unsigned long request, ...);

DESCRIPTION

The device /dev/tty[0-9]* or /dev/console represents the current virtual console. These are special devices that allow applications to control various aspects of the console.

The following ioctl() requests are available.

PIO_UNISCRNMAP
Charge la table "définissable par l'utilisateur" (quatrième table) du noyau qui permet de mapper les octets en Unicodes, qui sont ensuite traduits en symboles d'écran selon la table de mappage Unicode-vers-police actuellement chargée. Les Unicodes spéciaux commençant par U+F000 peuvent être utilisés pour mapper directement aux symboles de la police. (Depuis Linux 1.3.1.)
GIO_UNIMAP
Obtenir la table de mappage Unicode-vers-police du noyau. argp pointe vers une

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

où entries pointe vers un tableau de

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Depuis Linux 1.1.92.)
PIO_UNIMAP
Placer la table de mappage Unicode-vers-police dans le noyau. argp pointe vers une struct unimapdesc. (Depuis Linux 1.1.92)
PIO_UNIMAPCLR
Effacer la table, possiblement conseiller l'algorithme de hachage. argp pointe vers une

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 si pas d'avis */
    unsigned short advised_hashstep;  /* 0 si pas d'avis */
    unsigned short advised_hashlevel; /* 0 si pas d'avis */
};

(Depuis Linux 1.1.92.)
KDGKBMODE
Obtenir le mode actuel du clavier. argp pointe vers un long qui est défini à l'une des valeurs suivantes :
K_RAW 0x00 /* Mode brut (scancode) */
K_XLATE 0x01 /* Traduire les codes de touche en utilisant la table de touches */
K_MEDIUMRAW 0x02 /* Mode brut moyen (scancode) */
K_UNICODE 0x03 /* Mode Unicode */
K_OFF 0x04 /* Mode désactivé (depuis Linux 2.6.39) */
KDSKBMODE
Définir le mode actuel du clavier. argp est un long égal à l'une des valeurs indiquées pour KDGKBMODE.
KDGKBMETA
Obtenir le mode de gestion de la touche META. argp pointe vers un long qui est défini à l'une des valeurs suivantes :
K_METABIT 0x03 définir le bit de poids fort
K_ESCPREFIX 0x04 préfixe d'échappement
KDSKBMETA
Définir le mode de gestion de la touche META. argp est un long égal à l'une des valeurs indiquées ci-dessus pour KDGKBMETA.
KDGKBENT
Obtenir une entrée dans la table de traduction des touches (code de touche vers code d'action). argp pointe vers une

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

avec les deux premiers membres remplis : kb_table sélectionne la table de touches (0 <= kb_table < MAX_NR_KEYMAPS), et kb_index est le code de touche (0 <= kb_index < NR_KEYS). kb_value est défini au code d'action correspondant, ou K_HOLE s'il n'y a pas de telle touche, ou K_NOSUCHMAP si kb_table est invalide.
KDSKBENT
Définir une entrée dans la table de traduction. argp pointe vers une struct kbentry.
KDGKBSENT
Obtenir une chaîne de touche de fonction. argp pointe vers une

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string est défini à la chaîne (terminée par un caractère nul) correspondant au code d'action de la touche de fonction kb_func.
KDSKBSENT
Définir une entrée de chaîne de touche de fonction. argp pointe vers une struct kbsentry.
KDGKBDIACR
Lire la table des caractères diacritiques du noyau. argp pointe vers une

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

où kb_cnt est le nombre d'entrées dans le tableau, chacune étant une

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Lire une entrée de la table des codes de touche du noyau (scan code vers code de touche). argp pointe vers une

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode est défini pour correspondre au scancode donné. (Seulement 89 <= scancode <= 255. Pour 1 <= scancode <= 88, keycode==scancode.) (Depuis Linux 1.1.63.)
KDSETKEYCODE
Ecrire une entrée de la table des codes de touche du noyau. argp pointe vers une struct kbkeycode. (Depuis Linux 1.1.63.)
KDSIGACCEPT
Le processus appelant indique sa volonté d'accepter le signal argp lorsqu'il est généré en appuyant sur une combinaison de touches appropriée. (1 <= argp <= NSIG). (Voir spawn_console() dans linux/drivers/char/keyboard.c.)

RETURN VALUE

En cas de succès, 0 est retourné (sauf indication contraire). En cas d'échec, -1 est retourné, et errno est définie pour indiquer l'erreur.

ERRORS

EINVAL
argp est invalide.

STANDARDS

Linux.
