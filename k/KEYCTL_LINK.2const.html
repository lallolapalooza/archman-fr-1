KEYCTL_LINK(2const) KEYCTL_LINK(2const)

NOM

KEYCTL_LINK - lier une clé à un keyring

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/keyctl.h>  /* Définition des constantes KEY* */
#include <sys/syscall.h>   /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_LINK, key_serial_t key,
             key_serial_t keyring);

DESCRIPTION

Crée un lien d'un keyring vers une clé.

La clé à lier est spécifiée par key ; le keyring est spécifié par keyring.

Si une clé du même type et de la même description est déjà liée dans le keyring, alors cette clé est déplacée du keyring.

Avant de créer le lien, le noyau vérifie l'imbrication des keyrings et renvoie les erreurs appropriées si le lien produirait un cycle ou si l'imbrication des keyrings serait trop profonde (La limite sur l'imbrication des keyrings est déterminée par la constante du noyau KEYRING_SEARCH_MAX_DEPTH, définie avec la valeur 6, et est nécessaire pour éviter les dépassements de la pile du noyau lors de la recherche récursive des keyrings).

L'appelant doit avoir la permission link sur la clé ajoutée et la permission write sur le keyring.

VALEUR RETOURNEE

En cas de succès, 0 est retourné.

En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EDEADLK
Le lien demandé résulterait en un cycle.
ELOOP
Le lien demandé dépasserait la profondeur maximale d'imbrication pour les keyrings.
ENFILE (avant Linux 3.13)
Le keyring est plein. (Avant Linux 3.13, l'espace disponible pour stocker les liens de keyring était limité à une seule page mémoire ; depuis Linux 3.13, il n'y a pas de limite fixe.)

VERSIONS

Un wrapper est fourni dans la bibliothèque libkeyutils : keyctl_link(3).

NORMES

Linux.

HISTORIQUE

Linux 2.6.10.

VOIR AUSSI

keyctl(2), keyctl_link(3), KEYCTL_UNLINK(2const)
