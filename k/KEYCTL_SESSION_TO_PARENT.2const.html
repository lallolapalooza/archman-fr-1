KEYCTL_SESSION_TO_PARENT(2const) KEYCTL_SESSION_TO_PARENT(2const)

NOM

KEYCTL_SESSION_TO_PARENT - définir le keyring de session du processus parent

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/keyctl.h>  /* Définition des constantes KEY* */
#include <sys/syscall.h>   /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_SESSION_TO_PARENT);

DESCRIPTION

Remplace le keyring de session auquel le parent du processus appelant est abonné par le keyring de session du processus appelant.

Le keyring sera remplacé dans le processus parent au moment où le parent passera de l'espace noyau à l'espace utilisateur.

Le keyring doit exister et doit accorder à l'appelant la permission de lien. Le processus parent doit être monothread et avoir la même propriété effective que ce processus et ne doit pas être défini-utilisateur-ID ou défini-groupe-ID. L'UID du keyring de session existant du processus parent (s'il en a un), ainsi que l'UID du keyring de session de l'appelant, doivent correspondre à l'UID effectif de l'appelant.

Le fait que ce soit le processus parent qui soit affecté par cette opération permet à un programme tel que le shell de démarrer un processus enfant qui utilise cette opération pour modifier le keyring de session du shell. (C'est ce que fait la commande new_session de keyctl(1).)

VALEUR DE RETOUR

En cas de succès, 0 est retourné.

En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EPERM
Tous les UID (GID) du processus parent ne correspondent pas à l'UID (GID) effectif du processus appelant.
EPERM
L'UID du keyring de session existant du parent ou l'UID du keyring de session de l'appelant ne correspondait pas à l'UID effectif de l'appelant.
EPERM
Le processus parent n'est pas monothread.
EPERM
Le processus parent est init(1) ou un thread noyau.

VERSIONS

Un wrapper est fourni dans la bibliothèque libkeyutils : keyctl_session_to_parent(3).

NORMES

Linux.

HISTORIQUE

Linux 2.6.32.

VOIR AUSSI

keyctl(2), keyctl_session_to_parent(3)
