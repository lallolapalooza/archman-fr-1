Le contenu de la clé est spécifié dans le tampon pointé par payload ; la taille de ce tampon est spécifiée dans n

Le contenu peut être un pointeur nul et la taille du tampon peut être 0 si cela est pris en charge par le type de clé (par exemple, s'il s'agit d'un trousseau de

L'opération peut échouer si les données du contenu sont dans le mauvais format ou sont autrement

L'appelant doit posséder la clé d'autorisation appropriée, et une fois que la clé non instanciée a été instanciée, la clé d'autorisation est révoquée. En d'autres termes, cette opération n'est disponible que depuis un programme de type request-key(8). Voir request_key(2) pour une explication des cl
