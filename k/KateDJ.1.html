NOM

KateDJ - édite et remixe des flux Kate en Ogg

SYNTAXE

KateDJ [-hV]

DESCRIPTION

KateDJ permet d'extraire des pistes Kate intégrées dans un flux Ogg, de les éditer et de reconstruire le flux Ogg après modification des pistes Kate.

KateDJ est un programme GUI simple, donc son utilisation est pilotée par l'interface utilisateur, plutôt que par la ligne de commande.

Voici une description du déroulement habituel du programme :

Sélectionnez « Load Ogg stream » (Charger le flux Ogg) pour sélectionner le fichier Ogg que vous souhaitez remixer.

Sélectionnez « Demux file » (Démuxer le fichier) pour extraire les flux Kate de ce fichier vers un répertoire temporaire. Selon la taille du fichier Ogg, cette étape peut prendre un certain temps. Un message vous indiquera alors où les fichiers temporaires ont été placés. Tous les flux Kate seront décodés en une description textuelle et placés dans ce répertoire temporaire, et une liste de ces flux, avec leur numéro de série, leur langue et leur catégorie, sera affichée dans une liste.

Ces fichiers peuvent ensuite être édités à volonté, soit dans l'éditeur intégré en double-cliquant sur le flux dans la liste fournie, soit avec votre éditeur de texte préféré. Toute modification peut être effectuée, y compris la suppression de certains de ces fichiers, voire l'ajout de nouveaux. Cependant, pour être reconnus, les nouveaux fichiers doivent être nommés selon la même convention de nommage que les fichiers existants.

Une fois les modifications souhaitées effectuées, sélectionnez « Remux file from parts » (Remuxer le fichier à partir des parties) pour tenter de recréer le flux Ogg. Si une erreur se produit (par exemple, erreur de syntaxe dans les fichiers Kate), un message vous en informera. Une fois les erreurs corrigées, sélectionnez à nouveau « Remux file from parts », jusqu'à ce que l'opération réussisse.

L'éditeur intégré peut tester un flux modifié, ce qui le rend plus pratique pour des modifications rapides, tandis que votre éditeur de choix peut être plus puissant pour des modifications complexes.

OPTIONS

-h
Affiche l'aide de la ligne de commande.
-V
Affiche les informations de version.
