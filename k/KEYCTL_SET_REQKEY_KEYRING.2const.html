KEYCTL_SET_REQKEY_KEYRING(2const) KEYCTL_SET_REQKEY_KEYRING(2const)

NOM

KEYCTL_SET_REQKEY_KEYRING - définir le trousseau de clés de destination implicite

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/keyctl.h>  /* Définition des constantes KEY* */
#include <sys/syscall.h>   /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_SET_REQKEY_KEYRING, int op);

DESCRIPTION

Définit le trousseau de clés par défaut auquel les clés demandées implicitement seront liées pour ce thread, et renvoie le réglage précédent. Les demandes de clés implicites sont celles faites par les composants internes du noyau, comme cela peut se produire, par exemple, lors de l'ouverture de fichiers sur un système de fichiers AFS ou NFS. La définition du trousseau de clés par défaut a également un effet lors de la demande d'une clé depuis l'espace utilisateur ; voir request_key(2) pour plus de détails.

L'argument op doit contenir l'une des valeurs suivantes, pour spécifier le nouveau trousseau de clés par défaut :

KEY_REQKEY_DEFL_NO_CHANGE
Ne pas modifier le trousseau de clés par défaut. Ceci peut être utilisé pour découvrir le trousseau de clés par défaut actuel (sans le modifier).
KEY_REQKEY_DEFL_DEFAULT
Ceci sélectionne le comportement par défaut, qui est d'utiliser le trousseau de clés spécifique au thread s'il en existe un, sinon le trousseau de clés spécifique au processus s'il en existe un, sinon le trousseau de clés de session s'il en existe un, sinon le trousseau de clés de session de l'UID, sinon le trousseau de clés de l'utilisateur.
KEY_REQKEY_DEFL_THREAD_KEYRING
Utiliser le trousseau de clés spécifique au thread (thread-keyring(7)) comme nouveau trousseau de clés par défaut.
KEY_REQKEY_DEFL_PROCESS_KEYRING
Utiliser le trousseau de clés spécifique au processus (process-keyring(7)) comme nouveau trousseau de clés par défaut.
KEY_REQKEY_DEFL_SESSION_KEYRING
Utiliser le trousseau de clés de session (session-keyring(7)) comme nouveau trousseau de clés par défaut.
KEY_REQKEY_DEFL_USER_KEYRING
Utiliser le trousseau de clés spécifique à l'UID (user-keyring(7)) comme nouveau trousseau de clés par défaut.
KEY_REQKEY_DEFL_USER_SESSION_KEYRING
Utiliser le trousseau de clés de session spécifique à l'UID (user-session-keyring(7)) comme nouveau trousseau de clés par défaut.
KEY_REQKEY_DEFL_REQUESTOR_KEYRING (depuis Linux 2.6.29)
Utiliser le trousseau de clés du demandeur.

Toutes les autres valeurs sont invalides.

Le réglage contrôlé par cette opération est hérité par l'enfant de fork(2) et préservé à travers execve(2).

VALEUR DE RETOUR

En cas de succès, l'ID du trousseau de clés par défaut précédent auquel les clés demandées implicitement étaient liées (l'une des KEY_REQKEY_DEFL_USER_*).

En cas d'erreur, -1 est renvoyé, et errno est définie pour indiquer l'erreur.

VERSIONS

Une enveloppe est fournie dans la bibliothèque libkeyutils : keyctl_set_reqkey_keyring(3)

NORMES

Linux.

HISTORIQUE

Linux 2.6.13.

VOIR AUSSI

keyctl(2), keyctl_set_reqkey_keyring(3)
