KEYCTL_CHOWN(2const) KEYCTL_CHOWN(2const)

NOM

KEYCTL_CHOWN - changer le propriétaire d'une clé

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/keyctl.h>  /* Définition des constantes KEY* */
#include <sys/syscall.h>   /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_CHOWN, key_serial_t key,
             uid_t uid, gid_t gid);

DESCRIPTION

Change le propriétaire (identifiant utilisateur et groupe) d'une clé.

key contient l'identifiant de la clé. uid contient le nouvel identifiant utilisateur (ou -1 si l'identifiant utilisateur ne doit pas être modifié). gid contient le nouvel identifiant de groupe (ou -1 si l'identifiant de groupe ne doit pas être modifié).

La clé doit accorder à l'appelant la permission setattr.

Pour que l'UID soit modifié, ou pour que le GID soit modifié vers un groupe dont l'appelant n'est pas membre, l'appelant doit posséder la capacité CAP_SYS_ADMIN (voir capabilities(7)).

Si l'UID doit être modifié, le nouvel utilisateur doit avoir un quota suffisant pour accepter la clé. La déduction de quota sera retirée de l'ancien utilisateur au profit du nouvel utilisateur si l'UID est modifié.

VALEUR DE RETOUR

En cas de succès, 0 est retourné.

En cas d'erreur, -1 est retourné et errno est positionné pour indiquer l'erreur.

VERSIONS

Une fonction d'encapsulation est fournie dans la bibliothèque libkeyutils : keyctl_chown(3).

NORMES

Linux.

HISTORIQUE

Linux 2.6.10.

VOIR AUSSI

keyctl(2), keyctl_chown(3)
