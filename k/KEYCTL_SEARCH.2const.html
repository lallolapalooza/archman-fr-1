KEYCTL_SEARCH(2const) KEYCTL_SEARCH(2const)

NOM

KEYCTL_SEARCH - rechercher une clé dans un keyring

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/keyctl.h>  /* Définition des constantes KEY* */
#include <sys/syscall.h>   /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_SEARCH, key_serial_t src,
             char *type, char *desc,
             unsigned long dst);

DESCRIPTION

Recherche une clé dans une arborescence de keyrings, renvoyant son ID et la liant éventuellement à un keyring spécifié.

L'arborescence à rechercher est spécifiée en passant l'ID du keyring racine dans src. La recherche s'effectue en largeur d'abord et de manière récursive.

Les arguments type et desc spécifient la clé à rechercher : type contient le type de clé (une chaîne de caractères terminée par un octet nul, d'une taille maximale de 32 octets, y compris l'octet nul de fin), et desc contient la description de la clé (une chaîne de caractères terminée par un octet nul, d'une taille maximale de 4096 octets, y compris l'octet nul de fin).

Le keyring source doit accorder la permission de recherche à l'appelant. Lors de la recherche récursive, seuls les keyrings qui accordent la permission de recherche à l'appelant seront recherchés. Seules les clés pour lesquelles l'appelant a la permission de recherche peuvent être trouvées.

Si la clé est trouvée, son ID est renvoyé comme résultat de la fonction.

Si la clé est trouvée et que dst est différent de zéro, alors, sous réserve des mêmes contraintes et règles que KEYCTL_LINK(2const), la clé est liée dans le keyring dont l'ID est spécifié dans dst. Si le keyring de destination spécifié dans dst contient déjà un lien vers une clé qui a le même type et la même description, alors ce lien sera remplacé par un lien vers la clé trouvée par cette opération.

Au lieu d'IDs de keyrings valides existants, les keyrings source (src) et destination (dst) peuvent être l'une des IDs de keyring spéciales listées sous KEYCTL_GET_KEYRING_ID(2const).

VALEUR DE RETOUR

En cas de succès, l'ID de la clé qui a été trouvée.

En cas d'erreur, -1 est renvoyé, et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
La taille de la description dans desc (y compris l'octet nul de fin) a dépassé 4096 octets.

VERSIONS

Un wrapper est fourni dans la bibliothèque libkeyutils : keyctl_search(3).

NORMES

Linux.

HISTORIQUE

Linux 2.6.10.

VOIR AUSSI

keyctl(2), keyctl_search(3)
