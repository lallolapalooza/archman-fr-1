KEYCTL_SET_TIMEOUT(2const) KEYCTL_SET_TIMEOUT(2const)

NOM

KEYCTL_SET_TIMEOUT - définir le minuteur d'expiration sur une clé

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/keyctl.h>  /* Définition des constantes KEY* */
#include <sys/syscall.h>   /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_SET_TIMEOUT, key_serial_t key, time_t t);

DESCRIPTION

Définit un délai d'attente sur une clé.

L'identifiant de la clé est spécifié dans key. La valeur du délai d'attente, en secondes à partir du moment actuel, est spécifiée dans t. Le délai d'attente est mesuré par rapport à l'horloge temps réel.

Spécifier la valeur du délai d'attente comme 0 efface tout délai d'attente existant sur la clé.

Le fichier /proc/keys affiche le temps restant avant que chaque clé n'expire. (C'est la seule méthode pour découvrir le délai d'attente sur une clé.)

L'appelant doit avoir la permission setattr sur la clé ou détenir un jeton d'autorisation d'instanciation pour la clé (voir request_key(2)).

La clé et tous les liens vers la clé seront automatiquement nettoyés après l'expiration du délai. Les tentatives ultérieures d'accès à la clé échoueront alors avec l'erreur EKEYEXPIRED.

Cette opération ne peut pas être utilisée pour définir des délais d'attente sur des clés révoquées, expirées ou négativement instanciées.

VALEUR DE RETOUR

En cas de succès, 0 est renvoyé.

En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

VERSIONS

Un wrapper est fourni dans la bibliothèque libkeyutils : keyctl_set_timeout(3).

NORMES

Linux.

HISTORIQUE

Linux 2.6.16.

VOIR AUSSI

keyctl(2), keyctl_set_timeout(3)
