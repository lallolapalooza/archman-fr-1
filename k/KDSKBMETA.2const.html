NAME

KDSKBMETA, KDGKBMETA - gérer le mode de gestion des touches méta du clavier

SYNOPSIS

```c
#include <linux/kd.h>
long ioctl(int fd, KDGKBMETA, long *argp);
long ioctl(int fd, KDSKBMETA, long *argp);
```

DESCRIPTION

Ces appels système permettent de consulter et de modifier la façon dont les touches méta (souvent la touche Alt ou la touche Maj gauche sur certains claviers) sont gérées par le noyau.

L'argument argp pointe vers un entier de type long qui peut prendre l'une des valeurs suivantes :

KDGKBMODE
Récupère le mode actuel du clavier. argp pointe vers un long qui est défini sur l'une des valeurs suivantes :
K_RAW 0x00 /* Mode brut (scancode) */
K_XLATE 0x01 /* Traduction des codes de touches à l'aide de la table des touches */
K_MEDIUMRAW 0x02 /* Mode brut moyen (scancode) */
K_UNICODE 0x03 /* Mode Unicode */
K_OFF 0x04 /* Mode désactivé (depuis Linux 2.6.39) */
KDSKBMODE
Définit le mode actuel du clavier. argp est un long égal à l'une des valeurs indiquées pour KDGKBMODE.
KDGKBMETA
Récupère le mode de gestion des touches méta. argp pointe vers un long qui est défini sur l'une des valeurs suivantes :
K_METABIT 0x03 définit le bit de poids fort
K_ESCPREFIX 0x04 préfixe d'échappement
KDSKBMETA
Définit le mode de gestion des touches méta. argp est un long égal à l'une des valeurs indiquées ci-dessus pour KDGKBMETA.
KDGKBENT
Récupère une entrée dans la table de traduction des touches (code de touche vers code d'action). argp pointe vers une

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

avec les deux premiers membres remplis : kb_table sélectionne la table des touches (0 <= kb_table < MAX_NR_KEYMAPS), et kb_index est le code de touche (0 <= kb_index < NR_KEYS). kb_value est défini sur le code d'action correspondant, ou K_HOLE s'il n'y a pas de telle touche, ou K_NOSUCHMAP si kb_table est invalide.
KDSKBENT
Définit une entrée dans la table de traduction. argp pointe vers une struct kbentry.
KDGKBSENT
Récupère une chaîne de touche de fonction. argp pointe vers une

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string est défini sur la chaîne (terminée par un caractère nul) correspondant au code d'action de la kb_func-ième touche de fonction.
KDSKBSENT
Définit une entrée de chaîne de touche de fonction. argp pointe vers une struct kbsentry.
KDGKBDIACR
Lit la table des accents du noyau. argp pointe vers une

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

où kb_cnt est le nombre d'entrées dans le tableau, chacune étant une

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

PIO_UNISCRNMAP
Charge la table « définissable par l'utilisateur » (quatrième) dans le noyau qui mappe les octets en Unicodes, lesquels sont ensuite traduits en symboles d'écran selon la carte Unicode-vers-police chargée actuellement. Des Unicodes spéciaux commençant à U+F000 peuvent être utilisés pour mapper directement vers les symboles de police. (Depuis Linux 1.3.1.)
GIO_UNIMAP
Obtient la carte Unicode-vers-police du noyau. argp pointe vers une

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

où entries pointe vers un tableau de

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Depuis Linux 1.1.92.)
PIO_UNIMAP
Envoie la carte Unicode-vers-police au noyau. argp pointe vers une struct unimapdesc. (Depuis Linux 1.1.92)
PIO_UNIMAPCLR
Efface la table, éventuellement pour conseiller l'algorithme de hachage. argp pointe vers une

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 si pas d'opinion */
    unsigned short advised_hashstep;  /* 0 si pas d'opinion */
    unsigned short advised_hashlevel; /* 0 si pas d'opinion */
};

(Depuis Linux 1.1.92.)
KDGETKEYCODE
Lit une entrée de la table des codes de touches du noyau (code de scan vers code de touche). argp pointe vers une

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode est défini pour correspondre au scancode donné. (Seulement 89 <= scancode <= 255. Pour 1 <= scancode <= 88, keycode==scancode.) (Depuis Linux 1.1.63.)
KDSETKEYCODE
Écrit une entrée de la table des codes de touches du noyau. argp pointe vers une struct kbkeycode. (Depuis Linux 1.1.63.)
KDSIGACCEPT
Le processus appelant indique sa volonté d'accepter le signal argp lorsqu'il est généré en appuyant sur une combinaison de touches appropriée. (1 <= argp <= NSIG). (Voir spawn_console() dans linux/drivers/char/keyboard.c.)

RETURN VALUE

En cas de succès, 0 est retourné (sauf indication contraire). En cas d'échec, -1 est retourné et errno est défini pour indiquer l'erreur.

ERRORS

EINVAL
argp est invalide.

STANDARDS

Linux.
