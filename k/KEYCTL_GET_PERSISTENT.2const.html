KEYCTL_GET_PERSISTENT(2const) KEYCTL_GET_PERSISTENT(2const)

NOM

KEYCTL_GET_PERSISTENT - obtenir le trousseau persistant d'un utilisateur

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/keyctl.h>  /* Définition des constantes KEY* */
#include <sys/syscall.h>   /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_GET_PERSISTENT, uid_t uid,
             key_serial_t keyring);

DESCRIPTION

Obtient le trousseau persistant (persistent-keyring(7)) pour un utilisateur spécifié et le lie à un trousseau spécifié.

L'identifiant de l'utilisateur est spécifié dans uid. Si la valeur -1 est spécifiée, l'identifiant réel de l'utilisateur appelant est utilisé. L'identifiant du trousseau de destination est spécifié dans keyring.

L'appelant doit avoir la capacité CAP_SETUID dans son espace utilisateur pour pouvoir récupérer le trousseau persistant d'un identifiant d'utilisateur qui ne correspond pas à l'identifiant réel ou effectif de l'appelant.

Si l'appel réussit, un lien vers le trousseau persistant est ajouté au trousseau dont l'identifiant était spécifié dans keyring.

L'appelant doit avoir la permission d' *écriture* sur le trousseau.

Le trousseau persistant sera créé par le noyau s'il n'existe pas encore.

Chaque fois que l'opération KEYCTL_GET_PERSISTENT est effectuée, le trousseau persistant verra son délai d'expiration réinitialisé à la valeur spécifiée dans :


/proc/sys/kernel/keys/persistent_keyring_expiry

Si le délai est atteint, le trousseau persistant sera supprimé et tout ce qu'il épingle pourra être collecté par le garbage collector.

Les trousseaux persistants ont été ajoutés dans Linux 3.13.

VALEUR DE RETOUR

En cas de succès, l'identifiant du trousseau persistant.

En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EPERM
uid a spécifié un UID autre que l'UID réel ou effectif du thread appelant, et l'appelant n'avait pas la capacité CAP_SETUID.

VERSIONS

Une enveloppe est fournie dans la bibliothèque libkeyutils : keyctl_get_persistent(3).

NORMES

Linux.

HISTORIQUE

Linux 3.13.

VOIR AUSSI

keyctl(2), keyctl_get_persistent(3)
