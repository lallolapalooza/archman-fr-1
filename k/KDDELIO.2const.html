NOM

ioctl_console — console I/O control

SYNTAXIS

#include <sys/ioctl.h>
#include <linux/kd.h>
#include <linux/vt.h>
#include <linux/vt_kern.h>
#include <linux/keyboard.h>

long ioctl(int fd, unsigned long request, ...);

DESCRIPTION

The ioctl function can be used to control various aspects of the Linux console. The specific requests detailed below are related to keyboard and console mapping.

PIO_UNISCRNMAP
Charge la table "définissable par l'utilisateur" (quatrième) du noyau qui mappe les octets en Unicodes, lesquels sont ensuite traduits en symboles d'écran conformément à la carte de mappage Unicode vers police actuellement chargée. Des Unicodes spéciaux commençant à U+F000 peuvent être utilisés pour mapper directement vers les symboles de police. (Depuis Linux 1.3.1.)
GIO_UNIMAP
Obtient le mappage Unicode vers police depuis le noyau. argp pointe vers une

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

où entries pointe vers un tableau de

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Depuis Linux 1.1.92.)
PIO_UNIMAP
Place le mappage unicode vers police dans le noyau. argp pointe vers une struct unimapdesc. (Depuis Linux 1.1.92)
PIO_UNIMAPCLR
Efface la table, conseille éventuellement l'algorithme de hachage. argp pointe vers une

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 si pas d'avis */
    unsigned short advised_hashstep;  /* 0 si pas d'avis */
    unsigned short advised_hashlevel; /* 0 si pas d'avis */
};

(Depuis Linux 1.1.92.)
KDGKBMODE
Récupère le mode actuel du clavier. argp pointe vers un long qui est défini à l'une des valeurs suivantes :
K_RAW 0x00 /* Mode brut (scancode) */
K_XLATE 0x01 /* Traduit les keycodes en utilisant la table des touches */
K_MEDIUMRAW 0x02 /* Mode brut moyen (scancode) */
K_UNICODE 0x03 /* Mode Unicode */
K_OFF 0x04 /* Mode désactivé (depuis Linux 2.6.39) */
KDSKBMODE
Définit le mode actuel du clavier. argp est un long égal à l'une des valeurs indiquées pour KDGKBMODE.
KDGKBMETA
Récupère le mode de gestion de la touche meta. argp pointe vers un long qui est défini à l'une des valeurs suivantes :
K_METABIT 0x03 définit le bit d'ordre supérieur
K_ESCPREFIX 0x04 préfixe d'échappement
KDSKBMETA
Définit le mode de gestion de la touche meta. argp est un long égal à l'une des valeurs indiquées ci-dessus pour KDGKBMETA.
KDGKBENT
Récupère une entrée de la table de traduction des touches (keycode vers code d'action). argp pointe vers une

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

avec les deux premiers membres renseignés : kb_table sélectionne la table de touches (0 <= kb_table < MAX_NR_KEYMAPS), et kb_index est le keycode (0 <= kb_index < NR_KEYS). kb_value est défini au code d'action correspondant, ou K_HOLE s'il n'y a pas de telle touche, ou K_NOSUCHMAP si kb_table est invalide.
KDSKBENT
Définit une entrée dans la table de traduction. argp pointe vers une struct kbentry.
KDGKBSENT
Récupère une chaîne de touche fonctionnelle. argp pointe vers une

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string est défini à la chaîne (terminée par null) correspondant au code d'action de la kb_func-ième touche fonctionnelle.
KDSKBSENT
Définit une entrée de chaîne de touche fonctionnelle. argp pointe vers une struct kbsentry.
KDGKBDIACR
Lit la table des caractères diacritiques du noyau. argp pointe vers une

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

où kb_cnt est le nombre d'entrées dans le tableau, chacune étant une

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Lit une entrée de la table des keycodes du noyau (scan code vers keycode). argp pointe vers une

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode est défini pour correspondre au scancode donné. (Seulement 89 <= scancode <= 255. Pour 1 <= scancode <= 88, keycode==scancode.) (Depuis Linux 1.1.63.)
KDSETKEYCODE
Écrit une entrée de la table des keycodes du noyau. argp pointe vers une struct kbkeycode. (Depuis Linux 1.1.63.)
KDSIGACCEPT
Le processus appelant indique sa volonté d'accepter le signal argp lorsqu'il est généré en appuyant sur une combinaison de touches appropriée. (1 <= argp <= NSIG). (Voir spawn_console() dans linux/drivers/char/keyboard.c.)

VALEUR RENVOYÉE

En cas de succès, 0 est renvoyé (sauf indication contraire). En cas d'échec, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
argp est invalide.

STANDARDS

Linux.
