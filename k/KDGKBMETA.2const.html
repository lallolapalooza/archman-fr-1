ioctl_kd(2) Manuel des appels système ioctl_kd(2)

NOM

ioctl_kd - appels système pour le terminal de console et les fenêtres virtuelles

SYNTAXE

#include <linux/kd.h>  /* Définition des constantes d'op */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPTION

Les opérations ioctl(2) spécifiques à Linux suivantes sont supportées pour les terminaux de console et les fenêtres virtuelles.

KDGETLED
Obtenir l'état des LEDs. argp pointe vers un char. Les trois derniers bits de *argp sont définis pour l'état des LEDs, comme suit :
LED_CAP 0x04 LED de verrouillage majuscule
LED_NUM 0x02 LED de verrouillage numérique
LED_SCR 0x01 LED de défilement
KDSETLED
Définir les LEDs. Les LEDs sont définies selon les trois derniers bits de argp (un entier unsigned long). Cependant, si un bit de poids supérieur est défini, les LEDs sont renvoyées à leur état normal : elles affichent l'état des fonctions de clavier verrouillage majuscule, verrouillage numérique et verrouillage défilement.

Avant Linux 1.1.54, les LEDs reflétaient simplement l'état des drapeaux de clavier correspondants, et KDGETLED/KDSETLED changeaient également les drapeaux de clavier. Depuis Linux 1.1.54, les LEDs peuvent afficher des informations arbitraires, mais par défaut, elles affichent les drapeaux de clavier. Les deux appels ioctl suivants sont utilisés pour accéder aux drapeaux de clavier.

KDGKBLED
Obtenir l'état des drapeaux de clavier : verrouillage majuscule, verrouillage numérique, verrouillage défilement (pas les LEDs). argp pointe vers un char qui est défini pour l'état des drapeaux. Les trois bits les moins significatifs (masque 0x7) indiquent l'état actuel des drapeaux, et les bits les moins significatifs du nibble suivant (masque 0x70) indiquent l'état par défaut des drapeaux. (Depuis Linux 1.1.54).
KDSKBLED
Définir les drapeaux de clavier : verrouillage majuscule, verrouillage numérique, verrouillage défilement (pas les LEDs). argp est un entier unsigned long qui a l'état désiré des drapeaux. Les trois bits les moins significatifs (masque 0x7) indiquent l'état des drapeaux, et les bits les moins significatifs du nibble suivant (masque 0x70) indiquent l'état par défaut des drapeaux. (Depuis Linux 1.1.54).
KDGKBTYPE
Obtenir le type de clavier. Ceci retourne la valeur KB_101, définie comme 0x02.
KDADDIO
Ajouter un port d'E/S comme valide. Équivalent à ioperm(arg,1,1).
KDDELIO
Supprimer un port d'E/S comme valide. Équivalent à ioperm(arg,1,0).
KDENABIO
Activer les E/S vers la carte vidéo. Équivalent à ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
Désactiver les E/S vers la carte vidéo. Équivalent à ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
Définir le mode texte/graphique. argp est un entier unsigned contenant l'une des valeurs suivantes :
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
Obtenir le mode texte/graphique. argp pointe vers un int qui est défini avec l'une des valeurs ci-dessus pour KDSETMODE.
KDMKTONE
Générer une tonalité de longueur spécifiée. Les 16 bits de poids faible de l'entier unsigned long dans argp spécifient la durée en cycles d'horloge, et les 16 bits de poids fort donnent la durée en millisecondes. Si la durée est zéro, le son est éteint. Le contrôle retourne immédiatement. Par exemple, argp = (125<<16) + 0x637 spécifie le son normal associé à un ctrl-G. (Donc, depuis Linux 0.99pl1 ; cassé dans Linux 2.1.49-50).
KIOCSOUND
Démarrer ou arrêter la génération de son. Les 16 bits de poids faible de argp spécifient la durée en cycles d'horloge (c'est-à-dire, argp = 1193180/fréquence). argp = 0 arrête le son. Dans tous les cas, le contrôle retourne immédiatement.
GIO_CMAP
Obtenir la carte de couleurs actuelle du noyau. argp pointe vers un tableau de 48 octets. (Depuis Linux 1.3.3).
PIO_CMAP
Changer la carte de couleurs par défaut en mode texte. argp pointe vers un tableau de 48 octets contenant, dans l'ordre, les valeurs rouge, vert et bleu des 16 couleurs disponibles en mode texte : 0 est désactivé, et 255 est l'intensité maximale. Les couleurs par défaut sont : noir, rouge foncé, vert foncé, marron, bleu foncé, marron foncé, cyan foncé, gris clair, gris foncé, rouge vif, vert vif, jaune, bleu vif, bleu clair, cyan vif, blanc. (Depuis Linux 1.3.3).
GIO_FONT
Obtenir la police d'écran 256 caractères sous forme étendue. argp pointe vers un tableau de 8192 octets. Échoue avec une erreur EINVAL si la police actuelle est une police 512 caractères, ou si la console n'est pas en mode texte.
GIO_FONTX
Obtenir la police d'écran et les informations associées. argp pointe vers une struct consolefontdesc (voir PIO_FONTX). Lors de l'appel, le champ charcount doit être défini sur le nombre maximum de caractères pouvant tenir dans le tampon pointé par chardata. Au retour, les champs charcount et charheight sont remplis avec les données respectives pour la police actuelle. Le tableau chardata contient les données de la police si la valeur initiale de charcount indiquait suffisamment d'espace ; sinon, le tampon reste inchangé et errno est défini sur ENOMEM. (Depuis Linux 1.3.1).
PIO_FONT
Définir la police d'écran 256 caractères. Charge la police dans le générateur de caractères EGA/VGA. argp pointe vers une carte de 8192 octets, avec 32 octets par caractère. Seuls les N premiers sont utilisés pour une police 8xN (0 < N <= 32). Cet appel invalide également le mappage Unicode.
PIO_FONTX
Définir la police d'écran et les informations de rendu. argp pointe vers une

struct consolefontdesc {
    unsigned short charcount;  /* caractères dans la police
                                  (256 ou 512) */
    unsigned short charheight; /* lignes de balayage par caractère (1-32) */
    char          *chardata;   /* données de la police sous forme étendue */
};

Si nécessaire, l'écran sera redimensionné en conséquence et le signal SIGWINCH sera envoyé aux processus appropriés. Cet appel invalide également le mappage Unicode. (Depuis Linux 1.3.1).
PIO_FONTRESET
Restaure la police d'écran, la taille et le mappage Unicode aux valeurs par défaut au démarrage. argp n'est pas utilisé, mais doit être défini à NULL pour garantir la compatibilité avec les futures versions de Linux. (Depuis Linux 1.3.28).
GIO_SCRNMAP
Obtenir le mappage d'écran du noyau. argp pointe vers une zone de taille E_TABSZ, qui est chargée avec les emplacements de police utilisés pour afficher chaque caractère. Cet appel peut retourner des informations inutiles si la police actuelle fait plus de 256 caractères.
GIO_UNISCRNMAP
Obtenir le mappage d'écran Unicode complet du noyau. argp pointe vers une zone de taille E_TABSZ*sizeof(unsigned short), qui est chargée avec les Unicodes représentant chaque caractère. Un ensemble spécial d'Unicodes, commençant à U+F000, est utilisé pour représenter les mappages "directement dans la police". (Depuis Linux 1.3.1).
PIO_SCRNMAP
Charge le mappage "utilisé par l'utilisateur" (quatrième) dans le noyau qui mappe les octets aux symboles d'écran en mode console. argp pointe vers une zone de taille E_TABSZ.
