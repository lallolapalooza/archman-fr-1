Un tableau JudyL est l'équivalent d'un tableau de valeurs de la taille
    d'un mot. Une
Valeur est adressée par un
Index
(clé). Le tableau peut être
    creux, et l'
Index
peut être n'importe quel nombre de la taille d'un mot. La mémoire pour
    prendre en charge le tableau est allouée lorsque des paires index/valeur
    sont insérées, et libérée lorsque des paires index/valeur sont supprimées.
    Un tableau JudyL peut aussi être considéré comme un mapper, c'est-à-dire
    "mapper" un mot vers un autre mot/pointeur.
Comme pour un tableau ordinaire, il n'y a pas d'index en double dans un
    tableau JudyL.
La valeur peut être utilisée comme un scalaire, ou un pointeur vers une
    structure ou un bloc de données (ou même un autre tableau Judy).

JudyL Arrays Multi-dimensionnels

Stocker un pointeur vers un autre tableau JudyL dans la Valeur d'un tableau JudyL est un moyen simple de prendre en charge les tableaux multi-dimensionnels dynamiques. Ces tableaux (ou arbres) construits à l'aide de tableaux JudyL sont très rapides et économes en mémoire. (En fait, c'est ainsi que JudySL et JudyHS sont implémentés). Un nombre arbitraire de dimensions peut être réalisé de cette manière. Pour terminer le nombre de dimensions (ou l'arbre), le pointeur Valeur est marqué pour *ne pas* pointer vers un autre tableau Judy. Un drapeau JLAP_INVALID est utilisé dans le ou les bits les moins significatifs du pointeur. Après avoir retiré le drapeau JLAP_INVALID, il est utilisé comme pointeur vers les données de l'utilisateur. Le fichier d'en-tête Judy.h définit JLAP_INVALID. Voir le fragment de code ci-dessous.

Note: La version actuelle de Judy.h a changé ce drapeau de 0x4 à 0x1 pour permettre un appel à malloc() qui ne délivre pas de mémoire sur une limite alignée sur 8 octets (comme les anciennes versions de valgrind).

Le fragment de code d'exemple suivant peut être utilisé pour déterminer si un pointeur pointe ou non vers un autre JudyL :

PValue = (PWord_t)PMultiDimArray;
for (Dim = 0; ;Dim++)
{
   if (PValue == (PWord_t)NULL) goto IndexNotFound;
   /* Avancer à la dimension suivante dans le tableau */
   JLG(PValue, (Pvoid_t)*PValue, Index[Dim]);
   /* Vérifier si le pointeur vers le tampon utilisateur : */
   if (*PValue & JLAP_INVALID)) break;
}
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // masque et conversion.
printf("Le pointeur de l'objet utilisateur est 0x%lx\n", (Word_t) UPointer);
       ...

Note: Cela fonctionne car malloc() garantit de renvoyer un pointeur avec le ou les bits de poids faible == 0x0. Vous devez retirer JLAP_INVALID avant d'utiliser le pointeur.

EXEMPLE

Lire une série de paires index/valeur depuis l'entrée standard, les stocker dans un tableau JudyL, puis les imprimer dans l'ordre trié.

#include <stdio.h>
#include <Judy.h>
Word_t   Index;                     // index du tableau
Word_t   Value;                     // valeur de l'élément du tableau
Word_t * PValue;                    // pointeur vers la valeur de l'élément du tableau
int      Rc_int;                    // code de retour
Pvoid_t  PJLArray = (Pvoid_t) NULL; // initialiser le tableau JudyL
while (scanf("%lu %lu", &Index, &Value))
{
    JLI(PValue, PJLArray, Index);
    If (PValue == PJERR) goto process_malloc_failure;
    *PValue = Value;                 // stocker la nouvelle valeur
}
// Ensuite, visiter tous les index stockés dans l'ordre trié, d'abord croissant,
// puis décroissant, et supprimer chaque index pendant le passage décroissant.
Index = 0;
JLF(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLN(PValue, PJLArray, Index);
}
Index = -1;
JLL(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLD(Rc_int, PJLArray, Index);
    if (Rc_int == JERR) goto process_malloc_failure;
    JLP(PValue, PJLArray, Index);
}
