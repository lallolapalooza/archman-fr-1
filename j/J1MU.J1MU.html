Un tableau Judy est créé simplement en définissant un pointeur nul puis en stockant (insérant) le premier élément dans le tableau sous ce pointeur. La mémoire utilisée par un tableau Judy est presque proportionnelle à la population (nombre d'éléments). Judy a deux interfaces de programmation d'application (API) : une interface de macro C et une interface d'appel de fonction. Parce que les formes de macro sont parfois plus rapides et ont une interface de gestion d'erreur plus simple que les fonctions équivalentes, elles sont la façon préférée d'utiliser les fonctions Judy.
Puisqu'un tableau Judy initial (vide) est représenté par un pointeur nul, il est possible de construire un tableau de tableaux Judy. En d'autres termes,

ERREURS Beaucoup de réflexion (et de temps) a été consacré à rendre la gestion des erreurs dans Judy simple, tout en maintenant la flexibilité et les capacités. La gestion des erreurs est un sujet très ennuyeux même à écrire. Alors lisez cette courte section et utilisez la deuxième méthode recommandée. Elle génère le code le plus rapide, utilise la plus petite quantité de mémoire et vous oblige à écrire du code supplémentaire uniquement pour les fonctions d'insertion/suppression. De plus, elle est compatible avec les deux autres méthodes. Cette méthode est pour le code de production qui peut vouloir gérer les

échecs de malloc() différemment de la méthode par défaut de Ju

Tous les appels d'insertion et de suppression n'appellent pas malloc(), donc ils peuvent réussir même si un appel à malloc() échouerait. 3) Méthode de macro JUDYERROR() spécifiée par

l'utilisateur

La macro JUDYERROR() (dans Judy.h) fournit la flexibilité nécessaire pour gérer les retours d'erreur selon les besoins de votre programme tout en utilisant les macros de tableaux Judy au lieu d'appels de fonctions. Vous pouvez utiliser une macro JUDYERROR() différente pour répondre à vos besoins. L'exemple suivant est une alternative possible à la méthode par défaut. Elle est utilisée pour distinguer entre les deux types d'erreurs (décrits ci-dessus), et tester explicitement pour les erreurs JU_ERRNO_NOMEM restantes possibles dans votre

programme. 
// Ceci est un exemple de l'API de macro Judy pour continuer en cas de manque de mémoire
// et imprimer et exit(1) lorsque toute autre erreur se
produit. 
#ifndef JUDYERROR_NOTEST
#include <stdio.h>  // nécessaire pour
fprintf() 
// Ceci est la macro utilisée par les API de macro Judy pour les codes de retour de -1
: 
#define JUDYERROR(CallerFile, CallerLine, JudyFunc, JudyErrno, JudyErrID) \
{                                                                         \
    if ((JudyErrno) != JU_ERRNO_NOMEM) /* ! un échec de malloc() */       \
    {                                                                     \
        (void) fprintf(stderr, "File '%s', line %d: %s(), "               \
            "JU_ERRNO_* == %d, ID == %d\n",                               \
            CallerFile, CallerLine,                                       \
            JudyFunc, JudyErrno, JudyErrID);                              \
        exit(1);                                                          \
    }                                                                     \
}
#endif // JUDYERROR_NOTEST non défini
Cette macro de gestion d'erreur doit être incluse avant la déclaration #include <Judy.h> dans votre
programme.
