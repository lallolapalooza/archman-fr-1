DESCRIPTIO

N

Une macro équivalente existe pour chaque appel de fonction. Comme les formes de macro sont parfois plus rapides et ont une interface de gestion d'erreurs plus simple que les fonctions équivalentes, elles constituent la méthode préférée pour appeler les fonctions Judy1. Voir Judy1(3) pour plus d'informations. Les définitions des appels de fonctions sont incluses ici pour plus de

complétude.

L'une des difficultés de l'utilisation des appels de fonctions Judy1 réside dans la détermination de savoir s'il faut passer un pointeur ou l'adresse d'un pointeur. Puisque les fonctions qui modifient le tableau Judy1 doivent également modifier le pointeur vers le tableau Judy1, vous devez passer l'adresse du pointeur plutôt que le pointeur lui-même. Cela entraîne souvent des erreurs programmatiques difficiles à déboguer. En pratique, les macros permettent au compilateur de détecter les erreurs de programmation lorsque des pointeurs sont passés au lieu d'adresses de

pointeurs.

Les appels de fonctions Judy1 ont un paramètre supplémentaire au-delà de ceux spécifiés dans les appels de macro. Ce paramètre est soit un pointeur vers une structure d'erreur, soit NULL (auquel cas les informations détaillées sur l'erreur ne sont pas renvoyées)

.

Dans les descriptions suivantes, les fonctions sont décrites en termes de la manière dont les macros les utilisent (uniquement dans le cas de #define JUDYERROR_NOTEST 1). C'est l'utilisation recommandée des macros une fois que votre programme a été entièrement débogué. Lorsque la macro JUDYERROR_NOTEST n'est pas spécifiée, une structure d'erreur est déclarée pour stocker les informations d'erreur renvoyées par les fonctions Judy1 lorsqu'une erreur se

produit.

Judy1PrevEmpty(3)

Judy 1-Array Library Manual

NAME

Judy1PrevEmpty – find the previous empty slot.

SYNOPSIS

#include <Judy.h>

Word_t
Judy1PrevEmpty(PJudy1Array j1a, Judy1Index * index, PJudyError_t perror);

DESCRIPTION

Judy1PrevEmpty() returns the index of the previous slot in the Judy1 array, j1a, that is not set.

If the slot pointed to by index is set, then Judy1PrevEmpty() returns the index of the previous slot that is not set. If no such slot is found, then Judy1PrevEmpty() returns (Word_t) -1.

If the slot pointed to by index is not set, then Judy1PrevEmpty() returns the index pointed to by index.

The slot pointed to by index is decremented.

Judy1PrevEmpty() is used in conjunction with Judy1NextEmpty() to iterate over the unset slots in a Judy1 array.

The caller is responsible for allocating and freeing the Judy1 array j1a. The caller is also responsible for initializing index and perror.

See Judy1New() for details on Judy1 array allocation and Judy1Free() for Judy1 array freeing.

See Judy1ByCount() for details on index and perror.

Example:

int
main(int argc, char **argv)
{
    PJudy1Array j1a;
    Judy1Index index;
    JudyError_t jerr;
    Word_t rc;

    j1a = Judy1New();

    Judy1Set(j1a, 5, &jerr);
    Judy1Set(j1a, 15, &jerr);
    Judy1Set(j1a, 25, &jerr);

    index = 30;
    while ((rc = Judy1PrevEmpty(j1a, &index, &jerr)) != (Word_t) -1) {
        printf("Empty slot: %lu\n", rc);
    }

    Judy1Free(j1a);
    return 0;
}
