DESCRIPTION
Une macro équivalente existe pour chaque appel de fonction. Comme les
    formes de macro sont parfois plus rapides et ont une interface de gestion
    d'erreurs plus simple que les fonctions équivalentes, elles constituent la
    méthode préférée pour appeler les
    fonctions Judy1. Voir
Judy1(3)
pour plus d'informations. Les définit
ions des appels de fonctions sont
incluses ici pour plus de complétude.

L'une des difficultés de l'utilisation des appels de fonctions Judy1 réside dans la détermination de savoir s'il faut passer un pointeur ou l'adresse d'un pointeur. Comme les fonctions qui modifient le tableau Judy1 doivent également modifier le pointeur vers le tableau Judy1, vous devez passer l'adresse du pointeur plutôt que le pointeur lui-même. Cela entraîne souvent des erreurs de programmation difficiles à déboguer. En pratique, les macros permettent au compilateur de détecter les erreurs de programmation lorsque des

pointeurs sont passés au lieu d'adresses de pointeurs.

Les appels de fonctions Judy1 ont un paramètre supplémentaire au-delà de ceux spécifiés dans les appels de macro. Ce paramètre est soit un pointeur vers une structure d'erreur, soit NUL

L

(auquel cas les informations détaillées sur l'erreur ne sont pas retournées)

.

Dans les descriptions suivantes, les fonctions sont décrites en termes de la manière dont les macros les utilisent (uniquement dans le cas de #define JUDYERROR_NOTEST

1

). C'est l'utilisation suggérée des macros lorsque votre programme a été entièrement débogué. Lorsque la macro JUDYERROR_NOTEST n'est pas spécifiée, une structure d'erreur est déclarée pour stocker les informations d'erreur retournées par les fonctions Judy1 lorsqu'une erreur se

produit.

NOM

Judy1Unset

SYNTAXE

Judy1Unset(PJ1Array, Index, JError)

DESCRIPTION

Les définitions de toutes les fonctions Judy, des types Pvoid_t, Pcvoid_t, PPvoid_t, Word_t, JError_t, et PJError_t, des constantes NULL, JU_ERRNO_*, JERR, et PJE0 se trouvent dans le fichier d'en-tête Judy.h (/usr/include/Judy.h). Note : Les appelants doivent définir les tableaux Judy1 comme type Pvoid_t, qui peut être passé par valeur aux fonctions acceptant Pcvoid_t (Pvoid_t constant) et également par adresse aux fonctions acceptant PPvoid_t.
