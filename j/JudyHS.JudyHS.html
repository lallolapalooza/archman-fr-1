JudyHS.JudyHS

Paquet: judy

Licences: LGPL

JudyHS(3) Manuel des fonctions de bibliothèque JudyHS(3)

NOM

Macros JudyHS - Bibliothèque C pour créer et accéder à un tableau dynamique, utilisant un tableau d'octets de Longueur comme Index et un mot comme Valeur.

SYNTAXE

cc [options] fichiers_source -lJudy
#include <Judy.h>
Word_t  * PValue;                           // Élément du tableau JudyHS
int       Rc_int;                           // Indicateur de retour
Word_t    Rc_word;                          // Valeur de retour complète du mot
Pvoid_t   PJHSArray = (Pvoid_t) NULL;       // initialiser le tableau JudyHS
uint8_t * Index;                            // pointeur vers le tableau d'octets
Word_t    Length;                           // nombre d'octets dans Index
JHSI( PValue,  PJHSArray, Index, Length);   // JudyHSIns()
JHSD( Rc_int,  PJHSArray, Index, Length);   // JudyHSDel()
JHSG( PValue,  PJHSArray, Index, Length);   // JudyHSGet()
JHSFA(Rc_word, PJHSArray);                  // JudyHSFreeArray()

DESCRIPTION

Un tableau JudyHS est l'équivalent d'un tableau de pointeurs/valeurs de la taille d'un mot. Un Index est un pointeur vers un tableau d'octets de longueur spécifiée : Longueur. Plutôt que d'utiliser une chaîne terminée par un caractère nul, cette différence avec JudySL(3) permet aux chaînes de contenir tous les bits (spécifiquement le caractère nul). Cette nouvelle addition (mai 2004) aux tableaux Judy est une hybridation utilisant les meilleures capacités du hachage et des méthodes Judy. JudyHS n'a pas de cas de performance médiocre où la connaissance de l'algorithme de hachage peut être utilisée pour dégrader les performances.

Étant donné que JudyHS est basé sur une méthode de hachage, les Index ne sont pas stockés dans un ordre particulier. Par conséquent, les fonctions de recherche de voisins JudyHSFirst(), JudyHSNext(), JudyHSPrev() et JudyHSLast() ne sont pas pratiques. La Longueur de chaque tableau d'octets peut varier de 0 aux limites de malloc() (environ 2 Go).

La caractéristique principale de JudyHS est la vitesse avec scalabilité, mais l'efficacité mémoire est excellente. La vitesse est très compétitive avec les meilleures méthodes de hachage. L'efficacité mémoire est similaire à une liste chaînée des mêmes Index et Valeurs. JudyHS est conçu pour passer de 0 à des milliards d'Index.

Un tableau JudyHS est alloué avec un pointeur NULL

Pvoid_t PJHSArray = (Pvoid_t) NULL;

Étant donné que les formes macro de l'API ont une interface de gestion d'erreurs plus simple que les fonctions équivalentes, elles sont la manière préférée d'utiliser JudyHS.

JHSI(PValue, PJHSArray, Index, Length) // JudyHSIns()

Étant donné un pointeur vers un tableau JudyHS (PJHSArray), insérer une chaîne Index de longueur : Length et une Valeur dans le tableau JudyHS : PJHSArray. Si l'Index est inséré avec succès, la Valeur est initialisée à 0. Si l'Index était déjà présent, la Valeur n'est pas modifiée.

Retourne PValue pointant vers la Valeur. Votre programme devrait utiliser ce pointeur pour lire ou modifier la Valeur, par exemple :

Value = *PValue;
*PValue = 1234;

Note : JHSI() et JHSD peuvent réorganiser le tableau JudyHS. Par conséquent, les pointeurs retournés par les appels précédents à JudyHS deviennent invalides et doivent être réacquis (en utilisant JHSG()).

JHSD(Rc_int, PJHSArray, Index, Length) // JudyHSDel()

Étant donné un pointeur vers un tableau JudyHS (PJHSArray), supprimer l'Index spécifié ainsi que la Valeur du tableau JudyHS.

Retourne Rc_int défini à 1 si supprimé avec succès du tableau. Retourne Rc_int défini à 0 si l'Index n'était pas présent.

JHSG(PValue, PJHSArray, Index, Length) // JudyHSGet()

Étant donné un pointeur vers un tableau JudyHS (PJHSArray), trouver la Valeur associée à l'Index.

Retourne PValue pointant vers la Valeur de l'Index. Retourne PValue défini à NULL si l'Index n'était pas présent.

JHSFA(Rc_word, PJHSArray) // JudyHSFreeArray()

Étant donné un pointeur vers un tableau JudyHS (PJHSArray), libérer l'intégralité du tableau.

Retourne Rc_word défini au nombre d'octets libérés et PJHSArray défini à NULL.

ERREURS : Voir : Judy_3.htm#ERRORS

EXEMPLES

Montrer comment programmer avec les macros JudyHS. Ce programme affichera les lignes dupliquées et leur numéro de ligne depuis stdin.

#include <unistd.h>
#include <stdio.h>
#include <string.h>
#include <Judy.h>
//  Compilé :
//  cc -O PrintDupLines.c -lJudy -o PrintDupLines
#define MAXLINE 1000000                 /* longueur max ligne fgets */
uint8_t   Index[MAXLINE];               // chaîne à vérifier
int     // Utilisation : PrintDupLines < fichier
main()
{
    Pvoid_t   PJArray = (PWord_t)NULL;  // Tableau Judy.
    PWord_t   PValue;                   // Pointeur d'élément du tableau Judy.
    Word_t    Bytes;                    // taille du tableau JudyHS.
    Word_t    LineNumb = 0;             // numéro de ligne actuel
    Word_t    Dups = 0;                 // nombre de lignes dupliquées
    while (fgets(Index, MAXLINE, stdin) != (char *)NULL)
    {
        LineNumb++;                     // numéro de ligne
        // stocker la chaîne dans le tableau
        JHSI(PValue, PJArray, Index, strlen(Index)); 
        if (PValue == PJERR)            // Voir section ERREURS
        {
            fprintf(stderr, "Pas assez de mémoire -- sortie\n");
            exit(1);
        }
        if (*PValue == 0)               // vérifier si c'est un doublon
        {
            Dups++;
            printf("Lignes dupliquées %lu:%lu:%s", *PValue, LineNumb, Index);
        }
        else
        {
            *PValue = LineNumb;         // stocker le numéro de ligne
        }
    }
    printf("%lu Duplicates, libération du tableau JudyHS de %lu Lignes\n", 
                    Dups, LineNumb - Dups);
    JHSFA(Bytes, PJArray);              // libérer le tableau JudyHS
    printf("JudyHSFreeArray() a libéré %lu octets de mémoire\n", Bytes);
    return (0);
}
