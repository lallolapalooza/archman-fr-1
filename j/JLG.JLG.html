DESCRIPTIO

N

Un tableau JudyL est l'équivalent d'un tableau de valeurs de taille mot. Une valeur est adressée par un index (clé). Le tableau peut être creux, et l' index peut être un nombre de taille mot quelconque. La mémoire pour le support du tableau est allouée au fur et à mesure que des paires index/valeur sont insérées, et libérée lorsque des paires index/valeur sont supprimées. Un tableau JudyL peut aussi être considéré comme un mapper, c'est-à-dire "mapper" un mot vers un autre

mot/pointeur.

Comme pour un tableau ordinaire, il n'y a pas d'index dupliqués dans un tableau

JudyL.

La valeur peut être utilisée comme un scalaire, ou un pointeur vers une structure ou un bloc de données (ou même un autre tableau Judy)

.

Un tableau JudyL est alloué avec un pointeur

NULL 
Pvoid_t PJLArray = (Pvoid_t)
NULL;

En utilisant les macros décrites ici, plutôt que les appels de fonction JudyL, la gestion d'erreur par défaut envoie un message vers la sortie d'erreur standard et termine le programme avec exit(1);. Pour d'autres méthodes de gestion d'erreur, voir la section ERREURS. JLI( PValue, PJLArray, Index); // JudyLIns(

JudyL.

Fonctions de recherche
JudyL
JLF(), JLN(), JLL(), JLP() vous permettent de rechercher des index dans le tableau. Vous pouvez rechercher de manière inclusive ou exclusive, dans les sens avant ou arrière. Si succès, Index est retourné défini à l'index trouvé, et PValue est retourné défini à un pointeur vers la valeur de l' index. Si échec, PValue est retourné défini à NULL, et Index ne contient aucune information utile. PValue doit être testé pour non-NULL avant d'utiliser Index, car un échec de
recherche e
st possible.
JLFE(), JLNE(), JLLE(), JLPE() vous permettent de rechercher des index qui ne sont pas présents ("vides") dans le tableau. Vous pouvez rechercher de manière inclusive ou exclusive, dans les sens avant ou arrière. Si succès, Index est retourné défini à un index non présent ("vide"), et Rc_int est retourné défini à 1. Si échec, Rc_int est retourné défini à 0, et Index ne contient aucune information utile. Rc_int doit être vérifié avant d'utiliser Index, car un échec de
recherche e
st possible.

JLF(PValue, PJLArray, Index) // JudyLFirst
()
Recherche (inclusive) du premier index présent qui est égal ou supérieur à l' index passé. (Commencez avec Index = 0 pour trouver le premier index du tableau.) JLF() est typiquement utilisé pour commencer un parcours en ordre trié des index présents dans un tableau
JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext
()
Recherche (exclusive) du prochain index présent qui est supérieur à l' index passé. JLN() est typiquement utilisé pour continuer un parcours en ordre trié des index présents dans un tableau JudyL, ou pour localiser un "voisin" d'un index

inverse.

Tableaux JudyL multidimensionnel

s

Stocker un pointeur vers un autre tableau JudyL dans la Value d'un tableau JudyL est une manière simple de prendre en charge des tableaux multidimensionnels dynamiques. Ces tableaux (ou arbres) construits à l'aide de tableaux JudyL sont très rapides et économiques en mémoire. (En fait, c'est ainsi que JudySL et JudyHS sont implémentés). Un nombre arbitraire de dimensions peut être réalisé de cette manière. Pour terminer le nombre de dimensions (ou l'arbre), le pointeur Value est marqué pour NE PAS pointer vers un autre tableau Judy. Un drapeau JLAP_INVALID est utilisé dans le(s) bit(s) de poids faible du pointeur. Après que le drapeau JLAP_INVALID a été retiré, il est utilisé comme pointeur vers les données de l'utilisateur. Le fichier d'en-tête Judy.h définit JLAP_INVALID. Voir le fragment de code

ci-dessous.

Note : La version actuelle de Judy.h a changé ce drapeau de 0x4 à 0x1 pour permettre à un malloc() qui ne fournit pas de mémoire sur une limite alignée sur 8 octets (comme les anciennes versions de valgrind)

.

Le segment de code d'exemple suivant peut être utilisé pour déterminer si un pointeur pointe vers un autre JudyL ou non

: 
PValue = (PWord_t)
PMultiDimArray; 
for (Dim = 0; ;Dim++)
{
   if (PValue == (PWord_t)NULL) goto
IndexNotFound; 
   /* Avancer vers la dimension suivante dans le tableau */
   JLG(PValue, (Pvoid_t)*PValue, Index[Dim])
; 
   /* Vérifier s'il s'agit d'un pointeur vers le tampon de l'utilisateur : */
   if (*PValue & JLAP_INVALID)) break;
}
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // masquer et convertir.
printf("User object pointer is 0x%lx\n", (Word_t) UPointer);

.

Note : Cela fonctionne parce que malloc() garantit de renvoyer un pointeur dont le(s) bit(s) de poids faible == 0x0. Vous devez retirer JLAP_INVALID avant

d'utiliser
le pointeur.

#include <Judy.
h> 
Word_t   Index;                     // index du tableau

retour

JudyL 
while (scanf("%lu %lu", &Index, &Value))
{
    JLI(PValue, PJLArray, Index);
    If (PValue == PJERR) goto process_malloc_failure;
    *PValue = Value;                 // stocker la nouvelle valeur
}
// Ensuite, visiter tous les indexes stockés en ordre trié, d'abord
// croissant, puis décroissant, et supprimer chaque index lors du passage
//
décroissant.

JLF(PValue, PJLArray, Index);

{
    printf("%lu %lu\n", Index, *PValue));
    JLN(PValue, PJLArray, Index);
} 
Index = -1;
JLL(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue))
; 
    JLD(Rc_int, PJLArray, Index);
    if (Rc_int == JERR) goto process_malloc_failure

    JLP(PValue, PJLArray, Index);
