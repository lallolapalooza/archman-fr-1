JudySL(3) Manuel des fonctions de bibliothèque JudySL(3)

NOM

Macros JudySL - Bibliothèque C pour créer et accéder à un tableau dynamique, en utilisant une chaîne de caractères terminée par un caractère nul comme Index (tableau associatif)

SYNTAXE

cc [options] fichiers_source -lJudy
#include <Judy.h>
#define MAXLINELEN 1000000           // définir la longueur maximale de chaîne
Word_t * PValue;                     // élément du tableau JudySL
uint8_t  Index[MAXLINELEN];          // chaîne
int      Rc_int;                     // valeur de retour
Word_t   Rc_word;                    // valeur de retour complète (mot entier)
Pvoid_t PJSLArray = (Pvoid_t) NULL;  // initialiser le tableau JudySL
JSLI( PValue,  PJSLArray, Index);   // JudySLIns()
JSLD( Rc_int,  PJSLArray, Index);   // JudySLDel()
JSLG( PValue,  PJSLArray, Index);   // JudySLGet()
JSLFA(Rc_word, PJSLArray);          // JudySLFreeArray()
JSLF( PValue,  PJSLArray, Index);   // JudySLFirst()
JSLN( PValue,  PJSLArray, Index);   // JudySLNext()
JSLL( PValue,  PJSLArray, Index);   // JudySLLast()
JSLP( PValue,  PJSLArray, Index);   // JudySLPrev()

DESCRIPTION

Un tableau JudySL est l'équivalent d'un ensemble trié de chaînes de caractères, chacune associée à une Valeur (mot). Une Valeur est adressée par un Index (clé), qui est une chaîne de caractères terminée par un caractère nul de n'importe quelle longueur. La mémoire pour supporter le tableau est allouée au fur et à mesure que les paires index/valeur sont insérées, et libérée au fur et à mesure qu'elles sont supprimées. C'est une forme de tableau associatif, où les éléments du tableau sont également triés lexicographiquement (sensible à la casse) par les index. On pourrait penser à cela comme à

void * JudySLArray["Toto, je ne pense pas que nous soyons plus au Kansas"];

Un tableau JudySL est alloué avec un pointeur NULL

Pvoid_t PJSLArray = (Pvoid_t) NULL;
Comme pour un tableau ordinaire, il n'y a pas d'index (chaînes de caractères) dupliqués dans un tableau JudySL.

En utilisant les macros décrites ici, plutôt que les appels de fonction JudySL, la gestion d'erreur par défaut envoie un message à la sortie d'erreur standard et termine le programme avec exit(1).

JSLI(PValue, PJSLArray, Index) // JudySLIns()

Insère une chaîne Index et une Valeur dans le tableau JudySL PJSLArray. Si l'Index est inséré avec succès, la Valeur est initialisée à 0. Si l'Index était déjà présent, la Valeur n'est pas modifiée.

Retourne un pointeur PValue pointant vers la Valeur de l'Index. Votre programme doit utiliser ce pointeur pour modifier la Valeur, par exemple :

*PValue = 1234;

Note : JSLI() et JSLD réorganisent le tableau JudySL. Par conséquent, les pointeurs retournés par les appels JudySL précédents deviennent invalides et doivent être réacquis.

JSLD(Rc_int, PJSLArray, Index) // JudySLDel()

Supprime la paire Index/Valeur spécifiée (élément du tableau) du tableau JudySL.

Retourne Rc_int mis à 1 si succès. Retourne Rc_int mis à 0 si l'Index n'était pas présent.

JSLG(PValue, PJSLArray, Index) // JudySLGet()

Récupère le pointeur vers la Valeur de l'Index.

Retourne PValue pointant vers la Valeur de l'Index. Retourne PValue mis à NULL si l'Index n'était pas présent.

JSLFA(Rc_word, PJSLArray) // JudySLFreeArray()

Étant donné un pointeur vers un tableau JudySL (PJSLArray), libère l'ensemble du tableau (beaucoup plus rapide que d'utiliser une boucle JSLN(), JSLD()).

Retourne Rc_word mis au nombre d'octets libérés et PJSLArray mis à NULL.

Fonctions de recherche JudySL

Les fonctions de recherche JudySL vous permettent de rechercher des index dans le tableau. Vous pouvez rechercher de manière inclusive ou exclusive, dans les deux sens (avant ou arrière).

En cas de succès, Index est retourné et mis à l'index trouvé, et PValue est retourné et mis à un pointeur vers la Valeur de l'Index. En cas d'échec, PValue est retourné et mis à NULL, et Index ne contient aucune information utile. PValue doit être testé pour être non-NULL avant d'utiliser Index, car un échec de recherche est possible.

Note : Pour prendre en charge tous les retours possibles, le tampon Index doit être au moins aussi grand que la plus grande chaîne stockée dans le tableau.

JSLF(PValue, PJSLArray, Index) // JudySLFirst()

Recherche (inclusivement) le premier index présent qui est égal ou supérieur à la chaîne Index passée. (Commencez avec une chaîne nulle pour trouver le premier index du tableau.) JSLF() est généralement utilisé pour commencer un balayage dans l'ordre trié des index valides d'un tableau JudySL.

uint8_t Index[MAXLINELEN];
strcpy (Index, "");
JSLF(PValue, PJSLArray, Index);

JSLN(PValue, PJSLArray, Index) // JudySLNext()

Recherche (exclusivement) le prochain index présent qui est supérieur à la chaîne Index passée. JSLN() est généralement utilisé pour continuer un balayage dans l'ordre trié des index valides d'un tableau JudySL, ou pour localiser un "voisin" d'un index donné.

JSLL(PValue, PJSLArray, Index) // JudySLLast()

Recherche (inclusivement) le dernier index présent qui est égal ou inférieur à la chaîne Index passée. (Commencez avec une chaîne de valeur maximale pour rechercher le dernier index du tableau, comme une chaîne de longueur maximale de 0xff octets.) JSLL() est généralement utilisé pour commencer un balayage dans l'ordre trié inverse des index valides d'un tableau JudySL.

JSLP(PValue, PJSLArray, Index) // JudySLPrev()

Recherche (exclusivement) l'index précédent présent qui est inférieur à la chaîne Index passée. JSLP() est généralement utilisé pour continuer un balayage dans l'ordre trié inverse des index valides d'un tableau JudySL, ou pour localiser un "voisin" d'un index donné.

EXEMPLE de routine de tri de chaînes

#include <stdio.h>
#include <Judy.h>
#define MAXLINE 1000000                 // longueur max chaîne (ligne)
uint8_t   Index[MAXLINE];               // chaîne à insérer
int     // Utilisation :  JudySort < fichier_à_trier
main()
{
    Pvoid_t   PJArray = (PWord_t)NULL;  // Tableau Judy.
    PWord_t   PValue;                   // Élément du tableau Judy.
    Word_t    Bytes;                    // taille du tableau JudySL.
    while (fgets(Index, MAXLINE, stdin) != (char *)NULL)
    {
        JSLI(PValue, PJArray, Index);   // stocker la chaîne dans le tableau
        if (PValue == PJERR)            // si mémoire insuffisante ?
        {                               // alors faire quelque chose
            printf("Échec de Malloc -- obtenir plus de RAM\n");
            exit(1);
        }
        ++(*PValue);                    // compter les occurrences de la chaîne
    }
    Index[0] = '\0';                    // commencer avec la plus petite chaîne.
    JSLF(PValue, PJArray, Index);       // obtenir la première chaîne
    while (PValue != NULL)
    {
        while ((*PValue)--)             // imprimer les doublons
            printf("%s", Index);
        JSLN(PValue, PJArray, Index);   // obtenir la chaîne suivante
    }
    JSLFA(Bytes, PJArray);              // libérer le tableau
    fprintf(stderr, "Le tableau JudySL a utilisé %lu octets de mémoire\n", Bytes);
    return (0);
}

JudySL(3) - Documentation Arch Linux

NAME

JudySL - Search functions for a Judy array.

SYNOPSIS

#include <JudySL.h>

Word_t JudySLIns( JudySL_t ja, Word_t index, Word_t value, JudySL_t *Returned_ja );
Word_t JudySLGet( JudySL_t ja, Word_t index, Word_t *value );
Word_t JudySLDel( JudySL_t ja, Word_t index, Word_t *value );
Word_t JudySLNext( JudySL_t ja, Word_t index, Word_t *value );
Word_t JudySLPrev( JudySL_t ja, Word_t index, Word_t *value );
Word_t JudySLNxtSrch( JudySL_t ja, Word_t index, Word_t *value );
Word_t JudySLPrvSrch( JudySL_t ja, Word_t index, Word_t *value );
Word_t JudySLGetByValue( JudySL_t ja, Word_t value, Word_t *index );
Word_t JudySLCount( JudySL_t ja );
Word_t JudySLFree( JudySL_t ja );

DESCRIPTION

JudySL is a suite of functions for the efficient storage and retrieval of data. It allows for the creation of associative arrays where data is indexed by an integer value and the data itself is also an integer value. JudySL is optimized for sparse data sets and offers efficient insertion, deletion, and retrieval operations.

JudySL Search Functions

  • JudySLIns( JudySL_t ja, Word_t index, Word_t value, JudySL_t *Returned_ja ): Inserts a value at a given index. If the index already exists, its value is updated. Returns a JudySL error code.
  • JudySLGet( JudySL_t ja, Word_t index, Word_t *value ): Retrieves the value associated with a given index. Returns the JudySL error code.
  • JudySLDel( JudySL_t ja, Word_t index, Word_t *value ): Deletes the entry at a given index. The deleted value is returned in value. Returns the JudySL error code.
  • JudySLNext( JudySL_t ja, Word_t index, Word_t *value ): Retrieves the value associated with the smallest index greater than or equal to the given index. Returns the JudySL error code.
  • JudySLPrev( JudySL_t ja, Word_t index, Word_t *value ): Retrieves the value associated with the largest index less than or equal to the given index. Returns the JudySL error code.
  • JudySLNxtSrch( JudySL_t ja, Word_t index, Word_t *value ): Retrieves the value associated with the smallest index strictly greater than the given index. Returns the JudySL error code.
  • JudySLPrvSrch( JudySL_t ja, Word_t index, Word_t *value ): Retrieves the value associated with the largest index strictly less than the given index. Returns the JudySL error code.
  • JudySLGetByValue( JudySL_t ja, Word_t value, Word_t *index ): Retrieves the index associated with a given value. Note that multiple indices can map to the same value. This function returns one such index. Returns the JudySL error code.
  • JudySLCount( JudySL_t ja ): Returns the number of elements in the JudySL array.
  • JudySLFree( JudySL_t ja ): Frees all memory associated with the JudySL array.

EXAMPLE of a string sort routine

The JudySL library can be used to implement a string sort routine. For example:

#include <JudySL.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// Simple string comparison function
int compareStrings(const void *a, const void *b) {
    return strcmp(*(const char **)a, *(const char **)b);
}

int main() {
    JudySL_t ja = NULL;
    Word_t rc;
    int i, count;
    char *strings[] = {"banana", "apple", "cherry", "date", "fig"};
    int numStrings = sizeof(strings) / sizeof(strings[0]);

    // Insert strings into JudySL array, using their sorted position as index
    qsort(strings, numStrings, sizeof(char *), compareStrings);

    for (i = 0; i < numStrings; ++i) {
        rc = JudySLIns(ja, i, (Word_t)strings[i], &ja);
        if (rc != JudySLNoMemory && rc != JudySLError) {
            // Handle insertion error if necessary
            fprintf(stderr, "JudySLIns error: %lu\n", rc);
            return 1;
        }
    }

    count = JudySLCount(ja);
    printf("Number of strings: %d\n", count);

    // Retrieve and print strings in sorted order
    for (i = 0; i < count; ++i) {
        Word_t value;
        rc = JudySLGet(ja, i, &value);
        if (rc == JudySLOK) {
            printf("Index %d: %s\n", i, (char *)value);
        }
    }

    // Free the JudySL array
    JudySLFree(ja);

    return 0;
}
