JudyLIns(3) Manuel des fonctions de bibliothèque JudyLIns(3)

NOM

Fonctions JudyL - Bibliothèque C pour la création et l'accès à un tableau dynamique de mots, en utilisant n'importe quelle valeur d'un mot comme indice.

Word_t   JudyLMemUsed(   Pcvoid_t  PJLArray);
PPvoid_t JudyLFirst(     Pcvoid_t  PJLArray, Word_t * PIndex, PJError_t PJError);
PPvoid_t JudyLNext(      Pcvoid_t  PJLArray, Word_t * PIndex, PJError_t PJError);
PPvoid_t JudyLLast(      Pcvoid_t  PJLArray, Word_t * PIndex, PJError_t PJError);

int      JudyLPrevEmpty( Pcvoid_t  PJLArray, Word_t * PIndex, PJError_t PJError);

DESCRIPTION

Une forme macroéquivalente existe pour chaque appel de fonction. Comme les formes macro sont parfois plus rapides et ont une interface de gestion d'erreurs plus simple que les fonctions équivalentes, elles sont le moyen privilégié d'appeler les fonctions JudyL. Voir JudyL(3) pour plus d'informations. Les définitions d'appel de fonction sont incluses ici pour plus de complétude.

L'une des difficultés d'utilisation des appels de fonction JudyL réside dans la détermination s'il faut passer un pointeur ou l'adresse d'un pointeur. Étant donné que les fonctions qui modifient le tableau JudyL doivent également modifier le pointeur vers le tableau JudyL, vous devez passer l'adresse du pointeur plutôt que le pointeur lui-même. Cela conduit souvent à des erreurs de programmation difficiles à déboguer. En pratique, les macros permettent au compilateur de détecter les erreurs de programmation lorsque des pointeurs sont passés au lieu d'adresses de pointeurs.

Les appels de fonction JudyL ont un paramètre supplémentaire au-delà de ceux spécifiés dans les appels macro. Ce paramètre est soit un pointeur vers une structure d'erreur, soit NULL (auquel cas les informations d'erreur détaillées ne sont pas retournées).

Dans les descriptions suivantes, les fonctions sont décrites en termes de la manière dont les macros les utilisent (uniquement dans le cas de #define JUDYERROR_NOTEST 1). C'est l'utilisation suggérée des macros une fois que votre programme a été entièrement débogué. Lorsque la macro JUDYERROR_NOTEST n'est pas spécifiée, une structure d'erreur est déclarée pour stocker les informations d'erreur retournées par les fonctions JudyL en cas d'erreur.

Notez la présence de & dans les différentes fonctions.

JudyLIns(3) — Judy Array Library

NAME¶

JudyLIns — insert JudyL array

SYNOPSIS¶

#include <Judy.h>

int JudyLIns(Word_t **JA, Word_t *Key, Word_t *Value);

DESCRIPTION¶

The JudyLIns function inserts a Value into the JudyL array identified by JA. The Key is an integer value to be used as an index into the JudyL array. The Value is a pointer to the value to be stored at that index.

If the index already exists, the Value is overwritten and the old Value is returned in the Value argument. If the index does not exist, the Value is inserted and NULL is returned in the Value argument.

The JA argument is a pointer to a pointer to a JudyL array. This is because the JudyL array may be moved in memory during an insertion. The function will update JA to point to the new array if it is moved.

The Key argument is an integer value. It is passed by value and can be used as an index into the JudyL array.

The Value argument is a pointer to a pointer to a value. This is because the JudyL array stores pointers to values. The function will return a pointer to the value stored at the given index, or NULL if the index does not exist. The caller is responsible for freeing the memory pointed to by the returned value if it is no longer needed.

The return value is the number of elements inserted into the array. This will be 1 if a new element was inserted, or 0 if an existing element was overwritten.

The Value argument can also be passed by value to functions that take Pcvoid_t (constant Pvoid_t), and also by address to functions that take PPvoid_t.

The return type from most JudyL functions is PPvoid_t so that the values stored in the array can be pointers to other objects, which is a typical usage, or cast to a Word_t * when a pointer to a Value is required instead of a pointer to a pointer.
