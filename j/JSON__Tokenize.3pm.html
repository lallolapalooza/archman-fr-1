NOM

JSON::Tokenize - Tokeniser du JSON

SYNOPSIS

use JSON::Tokenize ':all';

my $input = '{"tuttie":["fruity", true, 100]}';
my $token = tokenize_json ($input);
print_tokens ($token, 0);

sub print_tokens
{
    my ($token, $depth) = @_;
    while ($token) {
        my $start = tokenize_start ($token);
        my $end = tokenize_end ($token);
        my $type = tokenize_type ($token);
        print "   " x $depth;
        my $value = substr ($input, $start, $end - $start);
        print "'$value' a le type '$type'.\n";
        my $child = tokenize_child ($token);
        if ($child) {
            print_tokens ($child, $depth+1);
        }
        my $next = tokenize_next ($token);
        $token = $next;
    }
}

Ceci génère la sortie suivante :

'{"tuttie":["fruity", true, 100]}' a le type 'object'.
   '"tuttie"' a le type 'string'.
   ':' a le type 'colon'.
   '["fruity", true, 100]' a le type 'array'.
      '"fruity"' a le type 'string'.
      ',' a le type 'comma'.
      'true' a le type 'literal'.
      ',' a le type 'comma'.
      '100' a le type 'number'.

DESCRIPTION

C'est un module pour tokeniser une chaîne JSON. « Tokeniser » signifie diviser la chaîne en tokens individuels, sans créer de structures Perl. Il utilise le même code sous-jacent que JSON::Parse. La tokenisation peut être utilisée pour des tâches telles que extraire ou rechercher des parties d'une grande structure JSON sans stocker chaque partie de la structure entière en mémoire.

Ce module est une partie expérimentale de JSON::Parse et son interface est susceptible de changer. Les fonctions de tokenisation sont actuellement écrites de manière très primitive.

FONCTIONS

tokenize_child

my $child = tokenize_child ($child);

Parcourir l'arbre des tokens.

tokenize_end

my $end = tokenize_end ($token);

Obtenir la fin du token en tant qu'offset d'octet par rapport au début de la chaîne. Notez qu'il s'agit d'un offset d'octet et non d'un offset de caractère.

tokenize_json

my $token = tokenize_json ($json);

tokenize_next

my $next = tokenize_next ($token);

Parcourir l'arbre des tokens.

tokenize_start

my $start = tokenize_start ($token);

Obtenir le début du token en tant qu'offset d'octet par rapport au début de la chaîne. Notez qu'il s'agit d'un offset d'octet et non d'un offset de caractère.

tokenize_text

my $text = tokenize_text ($json, $token);

Étant donné un token $token de cette analyse et le JSON dans $json, renvoyer le texte correspondant au token. Il s'agit d'une fonction de commodité écrite en Perl qui utilise "tokenize_start" et "tokenize_end" et "substr" pour obtenir la chaîne de $json.

tokenize_type

my $type = tokenize_type ($token);

Obtenir le type du token sous forme de chaîne. Les valeurs de retour possibles sont :

"array",
"initial state",
"invalid",
"literal",
"number",
"object",
"string",
"unicode escape"
