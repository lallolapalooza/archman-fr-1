XS::Boolean(3) Documentation Perl contribuée par l'utilisateur XS::Boolean(3)

NOM

JSON::XS::Boolean - module factice fournissant JSON::XS::Boolean

SYNTAXE

# n'utilisez pas vous-même

DESCRIPTION

Ce module existe uniquement pour fournir la résolution de surcharge pour Storable et des modules similaires. Il n'est nécessaire que pour la compatibilité avec les données sérialisées (par d'autres modules comme Storable) qui ont été décodées par des versions de JSON::XS antérieures à la 3.0.

Depuis la version 3.0, JSON::PP::Boolean l'a remplacé. Le support de JSON::XS::Boolean sera supprimé dans une future version.
