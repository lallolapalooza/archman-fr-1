JHSI(JHSI)

Paquet: judy

Licences: LGPL

JudyHS(3) Manuel des fonctions de bibliothèque JudyHS(3)

NOM

Macros JudyHS - Bibliothèque C pour créer et accéder à un tableau dynamique, en utilisant un tableau d'octets de Length comme Index et un mot comme Value.

SYNOPSIS

cc [flags] fichiers_source -lJudy
#include <Judy.h>
Word_t  * PValue;                           // Élément du tableau JudyHS
int       Rc_int;                           // Indicateur de retour
Word_t    Rc_word;                          // Valeur de retour complète du mot
Pvoid_t   PJHSArray = (Pvoid_t) NULL;       // Initialiser le tableau JudyHS
uint8_t * Index;                            // Pointeur vers le tableau d'octets
Word_t    Length;                           // Nombre d'octets dans Index
JHSI( PValue,  PJHSArray, Index, Length);   // JudyHSIns()
JHSD( Rc_int,  PJHSArray, Index, Length);   // JudyHSDel()
JHSG( PValue,  PJHSArray, Index, Length);   // JudyHSGet()
JHSFA(Rc_word, PJHSArray);                  // JudyHSFreeArray()

DESCRIPTION

Un tableau JudyHS est l'équivalent d'un tableau de pointeurs/valeurs de taille de mot. Un Index est un pointeur vers un tableau d'octets de longueur spécifiée : Length. Plutôt que d'utiliser une chaîne terminée par un caractère nul, cette différence par rapport à JudySL(3) permet aux chaînes de contenir tous les bits (en particulier le caractère nul). Cette nouvelle addition (Mai 2004) aux tableaux Judy est un hybride utilisant les meilleures capacités des méthodes de hachage et de Judy. JudyHS n'a pas de cas de performance médiocre où la connaissance de l'algorithme de hachage peut être utilisée pour dégrader les performances.

Puisque JudyHS est basé sur une méthode de hachage, les Index ne sont pas stockés dans un ordre particulier. Par conséquent, les fonctions de recherche de voisins JudyHSFirst(), JudyHSNext(), JudyHSPrev() et JudyHSLast() ne sont pas pratiques. La Length de chaque tableau d'octets peut aller de 0 aux limites de malloc() (environ 2 Go).

La marque de fabrique de JudyHS est la vitesse avec évolutivité, mais l'efficacité de la mémoire est excellente. La vitesse est très compétitive avec les meilleures méthodes de hachage. L'efficacité de la mémoire est similaire à une liste chaînée des mêmes Index et Valeurs. JudyHS est conçu pour évoluer de 0 à des milliards d'Index.

Un tableau JudyHS est alloué avec un pointeur NULL

Pvoid_t PJHSArray = (Pvoid_t) NULL;

Parce que les formes macroscopiques de l'API ont une interface de gestion des erreurs plus simple que les fonctions équivalentes, elles constituent la manière préférée d'utiliser JudyHS.

JHSI(PValue, PJHSArray, Index, Length) // JudyHSIns()

Étant donné un pointeur vers un tableau JudyHS (PJHSArray), insérez une chaîne Index de longueur : Length et une Value dans le tableau JudyHS : PJHSArray. Si l'Index est inséré avec succès, la Value est initialisée à 0. Si l'Index était déjà présent, la Value n'est pas modifiée.

Retourne PValue pointant vers Value. Votre programme doit utiliser ce pointeur pour lire ou modifier la Value, par exemple :

Value = *PValue;
*PValue = 1234;

Note : JHSI() et JHSD peuvent réorganiser le tableau JudyHS. Par conséquent, les pointeurs retournés par les appels précédents à JudyHS deviennent invalides et doivent être réacquis (en utilisant JHSG()).

JHSD(Rc_int, PJHSArray, Index, Length) // JudyHSDel()

Étant donné un pointeur vers un tableau JudyHS (PJHSArray), supprimez l'Index spécifié ainsi que la Value du tableau JudyHS.

Retourne Rc_int mis à 1 si la suppression du tableau a réussi. Retourne Rc_int mis à 0 si l'Index n'était pas présent.

JHSG(PValue, PJHSArray, Index, Length) // JudyHSGet()

Étant donné un pointeur vers un tableau JudyHS (PJHSArray), trouvez la Value associée à l'Index.

Retourne PValue pointant vers la Value de l'Index. Retourne PValue mis à NULL si l'Index n'était pas présent.

JHSFA(Rc_word, PJHSArray) // JudyHSFreeArray()

Étant donné un pointeur vers un tableau JudyHS (PJHSArray), libère tout le tableau.

Retourne Rc_word égal au nombre d'octets libérés et PJHSArray égal à NULL.

ERREURS : Voir : Judy_3.htm#ERRORS

EXEMPLES

Montre comment programmer avec les macros JudyHS. Ce programme affichera les lignes dupliquées et leur numéro de ligne depuis stdin.

#include <unistd.h>
#include <stdio.h>
#include <string.h>
#include <Judy.h>
//  Compilé :
//  cc -O PrintDupLines.c -lJudy -o PrintDupLines
#define MAXLINE 1000000                 /* longueur max de ligne pour fgets */
uint8_t   Index[MAXLINE];               // chaîne à vérifier
int     // Utilisation : PrintDupLines < fichier
main()
{
    Pvoid_t   PJArray = (PWord_t)NULL;  // Tableau Judy.
    PWord_t   PValue;                   // Pointeur d'élément de tableau Judy.
    Word_t    Bytes;                    // taille du tableau JudyHS.
    Word_t    LineNumb = 0;             // numéro de ligne courant
    Word_t    Dups = 0;                 // nombre de lignes dupliquées
    while (fgets(Index, MAXLINE, stdin) != (char *)NULL)
    {
        LineNumb++;                     // numéro de ligne
        // stocker la chaîne dans le tableau
        JHSI(PValue, PJArray, Index, strlen(Index)); 
        if (PValue == PJERR)            // Voir section ERREURS
        {
            fprintf(stderr, "Pas assez de mémoire -- sortie\n");
            exit(1);
        }
        if (*PValue == 0)               // vérifier si c'est un doublon
        {
            Dups++;
            printf("Lignes dupliquées %lu:%lu:%s", *PValue, LineNumb, Index);
        }
        else
        {
            *PValue = LineNumb;         // stocker le numéro de ligne
        }
    }
    printf("%lu Doublons, libération du tableau JudyHS de %lu Lignes\n", 
                    Dups, LineNumb - Dups);
    JHSFA(Bytes, PJArray);              // libérer le tableau JudyHS
    printf("JudyHSFreeArray() a libéré %lu octets de mémoire\n", Bytes);
    return (0);
}
