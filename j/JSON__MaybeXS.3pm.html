DESCRIPTIO

N

Ce module vérifie d'abord si Cpanel::JSON::XS ou JSON::XS (en version 3.0 au minimum) est déjà chargé, auquel cas il utilise ce module. Sinon, il essaie de charger Cpanel::JSON::XS, puis JSON::XS, puis JSON::PP dans cet ordre, et utilise soit le premier module qu'il trouve, soit lève une

erreur.

Il exporte ensuite les fonctions "encode_json" et "decode_json" du module chargé, ainsi qu'une constante "JSON" qui renvoie le nom de la classe sur laquelle appeler "new"

.

Si vous écrivez du nouveau code plutôt que de remplacer l'utilisation de JSON.pm, vous préférerez peut-être passer les options en arguments du constructeur plutôt que d'appeler des mutateurs ; nous fournissons donc notre propre méthode "new" qu

i le prend
en charge.

EXPORT

S

"encode_json", "decode_json" et "JSON" sont exportés par défaut ; "is_bool" est exporté sur

demande.

Pour n'importer que certains symboles, indiquez-les sur la ligne "use"

: 
use JSON::MaybeXS qw(encode_json decode_json is_bool); # fonctions uniquement
use JSON::MaybeXS qw(JSON); # constante JSON
uniquement

Pour importer tous les symboles sensibles disponibles ("encode_json", "decode_json" et "is_bool"), utilisez ":all

" : 
use JSON::MaybeXS ':
all';

Pour importer tous les symboles, y compris ceux nécessaires aux applications héritées qui utilisent JSON::PP

: 
use JSON::MaybeXS ':
legacy';

Cela importe les symboles "to_json" et "from_json" ainsi que tout ce qui est dans ":all". NOTE : Cela sert à prendre en charge du code hérité qui utilise de manière extensive "to_json" et "from_json" et que vous n'êtes pas encore en mesure de refactoriser. N'UTILISEZ PAS cette balise d'import dans du nouveau code, afin d'éviter les horreurs progressives liées à un support UTF-8 subtilement incorrect. Voir la documentation de JSON pour plus de

détails.

n

Cette fonction est équivalente à l'appel de "JSON()->new->encode($data_structure)". Elle prend une structure de données perl qui est sérialisée en texte JSON sans l'encoder en UTF-8. Vous ne devriez utiliser cette fonction que si vous attendez qu'une autre couche s'occupe de l'encodage UTF-8 du texte JSON

JSO

N

La constante "JSON" renvoie le nom du module d'implémentation sélectionné pour être utilisé comme nom de classe - ainsi

: 
my $json_obj = JSON()->new; # renvoie un objet Cpanel::JSON::XS ou JSON::
PP

et cet objet peut ensuite être utilisé normalement

: 
my $data_structure = $json_obj->decode($json_text); #
etc.

L'utilisation des parenthèses ici est facultative, et sert uniquement d'indice pour le lecteur que cet usage de "JSON" est un appel de sous-programme, et non un no

m de c
lasse.

is_boo

l 
$is_boolean = is_bool($scalar

Renvoie vrai si le scalaire passé représente soit "true" soit "false", deux constantes qui se comportent comme 1 et 0 respectivement et sont utilisées pour représenter les valeurs JSON "true" et "false" en

Perl.

Étant donné qu'il s'agit d'un sous-programme nu dans les différentes classes de backend, il ne peut pas être appelé comme une méthode de classe comme les autres interfaces ; il doit être appelé comme une fonction, sans invocant. Il prend en charge la représentation utilisée dans tous les backends

JSON.

Avec JSON::PP, JSON::XS et Cpanel::JSON::XS, vous devez appeler des mutateurs pour définir des options, comme

: 
my $json = $class->new->utf8(1)->pretty(1)
;

Comme c'est un peu irritant et nettement peu perlish, nous proposons aussi

: 
my $json = JSON::MaybeXS->new(utf8 => 1, pretty => 1)
;

ce qui fonctionne de manière équivalente à ce qui précède (et dans la tradition habituelle acceptera une référence à un hash au lieu d'un hash, si vous le souhaitez)

.

L'objet résultant est béni dans le backend sous-jacent, qui propose (au moins) les méthodes "encode" et "dec

o
de
".

CONVERSION DEPUIS JSON::

Any

JSON::Any était la couche de compatibilité privilégiée au-dessus des différents backends JSON, mais au fil du temps a accumulé beaucoup de code supplémentaire pour gérer les backends hérités (par exemple JSON::Syck) qui ne sont plus nécessaires. Voici un guide approximatif pour traduire ce type de code

:

Changez le code de

: 
use JSON::Any;
my $json = JSON::Any->new->objToJson($data);    # ou to_json($data), ou
Dump($data)

en

: 
use JSON::MaybeXS;
my $json = encode_json($data)
;

Changez le code de

: 
use JSON::Any;
my $data = JSON::Any->new->jsonToObj($json);    # ou from_json($json), ou
Load($json)

en

: 
use JSON::MaybeX
S; my $json = dec
ode_json($data);

AVERTISSEMEN

TS

La méthode new() de ce module est techniquement une fabrique, et non un constructeur, car les objets qu'elle renvoie ne seront PAS> être bénie en classe "JSON::Mayb

eXS".

Si vous utilisez un objet renvoyé par ce module comme attribut Moo(se), ce code de contrainte de type

: 
is 'json' => ( isa => 'JSON::MaybeXS' )
;

ne fera PAS ce que vous attendez. À la place, utilisez soit la constante de classe "JSON" décrite ci-dessus, comme ceci : is 'json' => ( isa => JSON::MaybeXS::JSON() )

; 
Alternativement, vous pouvez utiliser le duck typing
:

use Moose::Util::TypeConstraints 'duck_type'; is 'json' => ( isa => Object , duck_type([qw/ encode decode /]

)); 
INST
ALLA
TION

Au moment de

l'installation,

Makefile.PL essaiera de déterminer si vous disposez d'un compilateur fonctionnel, et donc si vous êtes en mesure d'exécuter du code XS. Si c'est le cas, Cpanel::JSON::XS sera ajouté à la liste des prérequis, sauf si JSON::XS est déjà installé à une version suffisamment élevée. JSON::XS peut également être mis à jour pour résoudre tout problème d'incompatibilité. Comme l'exécution du code XS n'est pas obligatoire et que JSON::PP (qui fait partie du cœur de perl) est utilisé comme backend de repli, ce module peut être utilisé en toute sécurité dans une suite de code qui est fatpacked ou installée dans un environnement à ressources

restreintes.

Vous pouvez également empêcher l'installation de toute dépendance XS en

définissant

"PUREPERL_ONLY=1" dans les options de Makefile.PL (ou dans la variable d'environnement "PERL_MM_OPT"), ou en utilisant les drapeaux "--pp" ou "--pureperl" avec l

e client
cpanminus.
