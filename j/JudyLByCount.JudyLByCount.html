DESCRIPTIO

N

Une macro équivalente existe pour chaque appel de fonction. Comme les formes de macro sont parfois plus rapides et ont une interface de gestion des erreurs plus simple que les fonctions équivalentes, elles constituent la manière privilégiée d'appeler les fonctions JudyL. Voir JudyL(3) pour plus d'informations. Les définitions des appels de fonctions sont incluses ici par souci

d'exhaustivité.

L'une des difficultés lors de l'utilisation des appels de fonctions JudyL réside dans la détermination du fait de passer un pointeur ou l'adresse d'un pointeur. Puisque les fonctions qui modifient le tableau JudyL doivent également modifier le pointeur vers le tableau JudyL, vous devez passer l'adresse du pointeur plutôt que le pointeur lui-même. Cela entraîne souvent des erreurs programmatiques difficiles à déboguer. En pratique, les macros permettent au compilateur de détecter les erreurs de programmation lorsque des pointeurs sont passés au lieu d'adresses de

pointeurs.

Les appels de fonctions JudyL ont un paramètre supplémentaire par rapport à ceux spécifiés dans les appels de macro. Ce paramètre est soit un pointeur vers une structure d'erreur, soit NULL (auquel cas les informations détaillées sur l'erreur ne sont pas renvoyées)

.

Dans les descriptions suivantes, les fonctions sont décrites en termes de la manière dont les macros les utilisent (uniquement dans le cas #define JUDYERROR_NOTEST 1). C'est l'utilisation recommandée des macros une fois que votre programme a été entièrement débogué. Lorsque la macro JUDYERROR_NOTEST n'est pas spécifiée, une structure d'erreur est déclarée pour stocker les informations d'erreur renvoyées par les fonctions JudyL lorsqu'une erreur se

produit.

Les définitions pour toutes les fonctions Judy, les types Pvoid_t, Pcvoid_t, PPvoid_t, Word_t, JError_t, et PJError_t, les constantes NULL, JU_ERRNO_*, JERR, PPJERR, et PJE0, sont fournies dans le fichier d'en-tête Judy.h (/usr/include/Judy.h). Remarque : Les appelants devraient définir les tableaux JudyL comme étant de type Pvoid_t, qui peut être passé par valeur aux fonctions qui prennent Pcvoid_t (constant Pvoid_t), et aussi par adresse aux fonctions qui prennent PPvoid_t

.

Le type de retour de la plupart des fonctions JudyL est PPvoid_t afin que les valeurs stockées dans le tableau puissent être des pointeurs vers d'autres objets, ce qui est une utilisation typique, ou converties en Word_t * lorsqu'un pointeur vers une Value est requis au lieu d'u
