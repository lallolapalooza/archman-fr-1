NOM

jsvc - application pour lancer un démon Java

SYNTAXE


jsvc
[-jvm nom JVM] [-client JVM client] [-server JVM serveur] [-classpath chemin] [-cp chemin] [-java-home répertoire] [-version] [-help] [-?] [-nodetach] [-debug] [-check] [-user utilisateur] [-wait temps d'attente] [-restarts nombre max de redémarrages] [-umask masque] [-stop] [-verbose:class|gc|jni] [-outfile /chemin/complet/vers/fichier] [-errfile /chemin/complet/vers/fichier] [-pidfile /chemin/complet/vers/fichier] [-Dpropriété=valeur] [-Xoption]

DESCRIPTION

jsvc exécute fichier de classe qui implémente une interface Daemon.

OPTIONS

-jvm nom JVM
utilise une machine virtuelle Java spécifique.
-client JVM client
utilise une machine virtuelle Java client.
-server JVM serveur
utilise une machine virtuelle Java serveur.
-cp/ -classpath répertoire et fichiers zip/jar
définit le chemin de recherche pour les classes de service et les ressources
-java-home répertoire
définit le chemin d'installation de votre JDK ou JRE (ou définit la variable d'environnement JAVA_HOME)
-version
affiche la version actuelle de l'environnement Java (pour vérifier la correction de -home et -jvm. Implique -nodetach)
-help
affiche cette page d'aide (implique -nodetach)
-nodetach
ne se détache pas du processus parent et ne devient pas un démon
-debug
affiche de manière verbeuse les informations de débogage
-check
vérifie seulement le service (implique -nodetach)
-stop
arrête le service en utilisant le fichier spécifié dans l'option -pidfile
-wait temps d'attente
attend jusqu'à temps d'attente secondes que le service démarre. temps d'attente doit être un multiple de 10 (min=10)
-restarts nombre max de redémarrages
nombre maximum de redémarrages automatiques -1=infini (par défaut), 0=aucun, 1..(INT_MAX-1)=nombre fixe
-umask masque
définit le masque de création de mode de fichier
-user utilisateur
utilisateur utilisé pour exécuter le démon (par défaut, l'utilisateur actuel)
-verbose[:class|gc|jni]
active la sortie détaillée
-outfile /chemin/complet/vers/fichier
Emplacement pour la sortie standard (par défaut, /dev/null). Utilisez la valeur '&2' pour simuler '1>&2', ou 'SYSLOG' pour envoyer la sortie au journal système.
-errfile /chemin/complet/vers/fichier
Emplacement pour la sortie d'erreur standard (par défaut, /dev/null). Utilisez la valeur '&1' pour simuler '2>&1', ou 'SYSLOG' pour envoyer la sortie au journal système.
-pidfile /chemin/complet/vers/fichier
Emplacement pour le fichier contenant le PID de jsvc (par défaut, /var/run/jsvc.pid)
-D<nom>=<valeur>
définit une propriété système Java
-X<option>
définit une option spécifique à la machine virtuelle
