JudyL(3) Manuel des fonctions de bibliothèque JudyL(3)

NOM

Macros JudyL - Bibliothèque C pour créer et accéder à un tableau dynamique de mots, en utilisant un mot comme index.

SYNTAXE

cc [flags] fichiers_source -lJudy
#include <Judy.h>
int      Rc_int;                          // code de retour - entier
Word_t   Rc_word;                         // code de retour - mot non signé
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // pointeur vers la valeur de retour
Pvoid_t PJLArray = (Pvoid_t) NULL;        // initialiser le tableau JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

DESCRIPTION

Un tableau JudyL est l'équivalent d'un tableau de valeurs de la taille d'un mot. Une Valeur est adressée par un Index (clé). Le tableau peut être éparse, et l'Index peut être n'importe quel nombre de la taille d'un mot. La mémoire nécessaire au support du tableau est allouée au fur et à mesure que les paires index/valeur sont insérées, et libérée au fur et à mesure qu'elles sont supprimées. Un tableau JudyL peut également être considéré comme un mappeur, c'est-à-dire qu'il « mappe » un mot à un autre mot/pointeur.

Comme pour un tableau ordinaire, il n'y a pas d'index dupliqués dans un tableau JudyL.

La valeur peut être utilisée comme un scalaire, ou comme un pointeur vers une structure ou un bloc de données (ou même un autre tableau Judy).

Un tableau JudyL est alloué avec un pointeur NULL

Pvoid_t PJLArray = (Pvoid_t) NULL;

En utilisant les macros décrites ici, plutôt que les appels de fonctions JudyL, la gestion par défaut des erreurs envoie un message à la sortie d'erreur standard et termine le programme avec exit(1);. Pour d'autres méthodes de gestion des erreurs, voir la section ERREURS. JLI( PValue, PJLArray, Index); // JudyLIns()

Étant donné que les formes de macros sont parfois plus rapides et ont une interface de gestion des erreurs plus simple que les fonctions JudyL équivalentes, elles constituent la manière privilégiée d'appeler les fonctions JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
Insère un Index et une Valeur dans le tableau JudyL PJLArray. Si l'Index est inséré avec succès, la Valeur est initialisée à 0. Si l'Index était déjà présent, la Valeur n'est pas modifiée.
Retourne PValue pointant vers la Valeur. Votre programme peut utiliser ce pointeur pour lire ou modifier la Valeur jusqu'à ce que la prochaine appel à JLI() (insertion), JLD() (suppression) ou JLFA() (libération du tableau) soit exécuté sur PJLArray. Exemples :
*PValue = 1234;
Valeur = *PValue;
Retourne PValue défini à PJERR si une erreur malloc() s'est produite. Note : JLI() et JLD() réorganisent le tableau JudyL. Par conséquent, les PValue retournés par les appels précédents à JudyL deviennent invalides et doivent être réacquis.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
Supprime la paire Index/Valeur du tableau JudyL.
Retourne Rc_int défini à 1 si l'opération réussit. Retourne Rc_int défini à 0 si l'Index n'était pas présent. Retourne Rc_int défini à JERR si une erreur malloc() s'est produite.

JLG(PValue, PJLArray, Index) // JudyLGet()
Récupère le pointeur PValue associé à l'Index dans le tableau Judy PJLArray.
Retourne PValue pointant vers la Valeur. Retourne PValue défini à NULL si l'Index n'était pas présent. Retourne PValue défini à PJERR si une erreur malloc() s'est produite.

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
Compte le nombre d'index présents dans le tableau JudyL PJLArray entre Index1 et Index2 (inclus).
Retourne Rc_word défini au compte. Une valeur de retour de 0 peut être valide en tant que compte.
Pour compter tous les index présents dans un tableau JudyL, utilisez :
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
Localise le Nème index présent dans le tableau JudyL PJLArray (Nth = 1 renvoie le premier index présent).
Retourne PValue pointant vers sa Valeur et Index défini à le Nème index s'il est trouvé, sinon retourne PValue défini à NULL (la valeur de Index est indéfinie).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
Étant donné un pointeur vers un tableau JudyL, libère l'intégralité du tableau (beaucoup plus rapide que d'utiliser une boucle JLN(), JLD()).
Retourne Rc_word défini au nombre d'octets libérés et PJLArray défini à NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
Retourne Rc_word défini au nombre d'octets de mémoire malloc()'és par PJLArray. C'est une routine très rapide, et peut être utilisée avant et après un appel JLI() ou JLD() avec peu d'impact sur les performances.

Fonctions de recherche JudyL
JLF(), JLN(), JLL(), JLP() permettent de rechercher des index dans le tableau. Vous pouvez rechercher inclusivement ou exclusivement, dans le sens avant ou arrière. En cas de succès, Index est renvoyé défini à l'index trouvé, et PValue est renvoyé défini à un pointeur vers la Valeur de l'Index. En cas d'échec, PValue est renvoyé défini à NULL, et Index ne contient aucune information utile. PValue doit être testé pour être non-NULL avant d'utiliser Index, car un échec de recherche est possible.
JLFE(), JLNE(), JLLE(), JLPE() permettent de rechercher des index qui ne sont pas présents (« vides ») dans le tableau. Vous pouvez rechercher inclusivement ou exclusivement, dans le sens avant ou arrière. En cas de succès, Index est renvoyé défini à un index non présent (« vide »), et Rc_int est renvoyé défini à 1. En cas d'échec, Rc_int est renvoyé défini à 0, et Index ne contient aucune information utile. Rc_int doit être vérifié avant d'utiliser Index, car un échec de recherche est possible.

JLF(PValue, PJLArray, Index) // JudyLFirst()
Recherche (inclusivement) le premier index présent égal ou supérieur à l'Index passé. (Commencez avec Index = 0 pour trouver le premier index du tableau.) JLF() est généralement utilisé pour commencer un balayage en ordre trié des index présents dans un tableau JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
Recherche (exclusivement) le prochain index présent strictement supérieur à l'Index passé. JLN() est généralement utilisé pour continuer un balayage en ordre trié des index présents dans un tableau JudyL, ou pour localiser un « voisin » d'un index donné.

DESCRIPTION

JudyLLast() - Recherche le plus grand indice qui soit inférieur ou égal à l'indice fourni.

JudyLLastEmpty() - Recherche le premier indice non présent, qui soit supérieur ou égal à l'indice fourni.

JudyLPrev() - Recherche l'indice précédent qui soit inférieur à l'indice fourni.

JudyLPrevEmpty() - Recherche l'indice précédent non présent, qui soit inférieur à l'indice fourni.

JudyLFirstEmpty() - Recherche le premier indice non présent, qui soit supérieur ou égal à l'indice fourni.

JudyLNextEmpty() - Recherche l'indice suivant non présent, qui soit supérieur à l'indice fourni.

JudyLLastEmpty() - Recherche le dernier indice non présent, qui soit inférieur ou égal à l'indice fourni.

JudyLFirstEmpty() - Recherche le premier indice non présent, qui soit inférieur ou égal à l'indice fourni.

JudyLP() - Utilisé pour démarrer une itération d'indices dans l'ordre inverse dans un tableau JudyL.

JudyJ() - Utilisé pour rechercher le plus petit indice qui soit inférieur ou égal à l'indice fourni.

JudyJL() - Utilisé pour rechercher le plus grand indice qui soit inférieur ou égal à l'indice fourni.

JudyJLL() - Utilisé pour rechercher le plus grand indice qui soit inférieur ou égal à l'indice fourni.

JudyJLE() - Utilisé pour rechercher le plus grand indice qui soit inférieur ou égal à l'indice fourni.

JudyJLP() - Utilisé pour continuer une itération d'indices dans l'ordre inverse dans un tableau JudyL, ou pour localiser un "voisin" d'un indice donné.

JudyJLPE() - Utilisé pour rechercher l'indice précédent non présent, qui soit inférieur à l'indice fourni.

JudyJLFE() - Utilisé pour rechercher le premier indice non présent, qui soit supérieur ou égal à l'indice fourni.

JudyJLNE() - Utilisé pour rechercher l'indice suivant non présent, qui soit supérieur à l'indice fourni.

Tableaux JudyL multidimensionnels

Stocker un pointeur vers un autre tableau JudyL dans la valeur d'un tableau JudyL est une méthode simple pour prendre en charge les tableaux multidimensionnels dynamiques. Ces tableaux (ou arbres) construits avec des tableaux JudyL sont très rapides et économes en mémoire. (En fait, c'est ainsi que JudySL et JudyHS sont implémentés). Tout nombre de dimensions peut être réalisé de cette manière. Pour terminer le nombre de dimensions (ou l'arbre), le pointeur de valeur est marqué pour ne pas pointer vers un autre tableau JudyL. Le drapeau JLAP_INVALID est utilisé dans le bit le plus significatif du pointeur. Après avoir retiré le drapeau JLAP_INVALID, il est utilisé comme pointeur vers les données de l'utilisateur. Le fichier Judy.h définit JLAP_INVALID. Voir l'extrait de code ci-dessous.

Note : La nouvelle version de Judy.h a changé ce drapeau de 0x4 à 0x1 pour permettre à malloc() de ne pas renvoyer de mémoire dans une limite alignée de 8 octets (comme dans les anciennes versions de valgrind).

L'exemple de code suivant peut être utilisé pour déterminer si un pointeur pointe vers un autre tableau JudyL :

PValue = (PWord_t) PMultiDimArray;
for (Dim = 0; ;Dim++)
    if (PValue == (PWord_t)NULL) goto IndexNotFound;
    /* Passer à la dimension suivante dans le tableau */
JLG(PValue, (Pvoid_t)*PValue, Index[Dim]);
    /* Vérifier si le pointeur vers le tampon utilisateur : */
if (*PValue & JLAP_INVALID) break;
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // masque et cast.
printf("User object pointer is 0x%lx\n", (Word_t) UPointer);
...

Note : Cela fonctionne car malloc() garantit qu'il renvoie un pointeur avec les bits les plus significatifs == 0x0. Vous devez supprimer JLAP_INVALID avant d'utiliser le pointeur.

ERREURS

EXEMPLE

Lit une série de paires index/valeur depuis l'entrée standard, les stocke dans un tableau JudyL, puis les imprime dans l'ordre trié.

#include <stdio.h>
#include <Judy.h>
Word_t   Index;                     // indice du tableau
Word_t   Value;                     // valeur de l'élément du tableau
Word_t * PValue;                    // pointeur vers la valeur de l'élément du tableau
int      Rc_int;                    // code de retour
Pvoid_t  PJLArray = (Pvoid_t) NULL; // initialiser le tableau JudyL
while (scanf("%lu %lu", &Index, &Value))
    JLI(PValue, PJLArray, Index);
    If (PValue == PJERR) goto process_malloc_failure;
    *PValue = Value;                 // stocker la nouvelle valeur
    // ensuite, visiter tous les indices stockés dans l'ordre croissant, puis décroissant, et supprimer chaque indice pendant le passage décroissant.
Index = 0;
JLF(PValue, PJLArray, Index);
while (PValue != NULL)
    printf("%lu %lu\n", Index, *PValue));
JLN(PValue, PJLArray, Index);
Index = -1;
JLL(PValue, PJLArray, Index);
while (PValue != NULL)
    printf("%lu %lu\n", Index, *PValue));
JLD(Rc_int, PJLArray, Index);
if (Rc_int == JERR) goto process_malloc_failure;
JLP(PValue, PJLArray, Index);
    // ...
