DESCRIPTION

Une macro équivalente existe pour chaque appel de fonction. Comme les formes macro sont parfois plus rapides et ont une interface de gestion des erreurs plus simple que les fonctions équivalentes, elles sont la manière préférée d'appeler les fonctions Judy1. Voir Judy1(3) pour plus d'informations. Les définitions d'appel de fonction sont incluses ici pour complétude.

L'une des difficultés d'utilisation des appels de fonction Judy1 réside dans la détermination s'il faut passer un pointeur ou l'adresse d'un pointeur. Comme les fonctions qui modifient le tableau Judy1 doivent également modifier le pointeur vers le tableau Judy1, vous devez passer l'adresse du pointeur plutôt que le pointeur lui-même. Cela conduit souvent à des erreurs de programmation difficiles à déboguer. En pratique, les macros permettent au compilateur de détecter les erreurs de programmation lorsque des pointeurs au lieu d'adresses de pointeurs sont passés.

Les appels de fonction Judy1 ont un paramètre supplémentaire au-delà de ceux spécifiés dans les appels macro. Ce paramètre est soit un pointeur vers une structure d'erreur, soit NULL (auquel cas les informations détaillées sur l'erreur ne sont pas retournées).

Dans les descriptions suivantes, les fonctions sont décrites en termes de la manière dont les macros les utilisent (uniquement dans le cas de #define JUDYERROR_NOTEST 1). C'est l'utilisation suggérée des macros une fois votre programme entièrement débogué. Lorsque la macro JUDYERROR_NOTEST n'est pas spécifiée, une structure d'erreur est déclarée pour stocker les informations d'erreur retournées par les fonctions Judy1 lorsqu'une erreur se produit.

Remarquez le placement du & dans les différentes fonctions.


Judy1Set(&PJ1Array, Index, &JError)
#define J1S(Rc_int, PJ1Array, Index) \
   Rc_int = Judy1Set(&PJ1Array, Index, PJE0)

Judy1Unset(&PJ1Array, Index, &JError)
#define J1U(Rc_int, PJ1Array, Index) \
   Rc_int = Judy1Unset(&PJ1Array, Index, PJE0)

Judy1Test(PJ1Array, Index, &JError)
#define J1T(Rc_int, PJ1Array, Index) \
   Rc_int = Judy1Test(PJ1Array, Index, PJE0)

Judy1Count(PJ1Array, Index1, Index2, &JError)
#define J1C(Rc_word, PJ1Array, Index1, Index2) \
   Rc_word = Judy1Count(PJ1Array, Index1, Index2, PJE0)
Une valeur de retour de 0 peut être une erreur, valide en tant que compte, ou elle peut indiquer un cas spécial pour un tableau entièrement peuplé (machines 32 bits uniquement). Si nécessaire, le code suivant peut être utilisé pour dissocier ce retour :
JError_t JError;
Rc_word = Judy1Count(PJ1Array, Index1, Index2, &JError);
if (Rc_word == 0)
{
    if (JU_ERRNO(&JError) == JU_ERRNO_NONE)
        printf("La population du tableau Judy1 est == 0\n");
    if (JU_ERRNO(&JError) == JU_ERRNO_FULL)
        printf("La population du tableau Judy1 est == 2^32\n");
    if (JU_ERRNO(&JError) == JU_ERRNO_NULLPPARRAY)
        goto NullArray;
    if (JU_ERRNO(&JError) >  JU_ERRNO_NFMAX)
        goto Null_or_CorruptArray;
}
