DESCRIPTION

Une macro équivalente existe pour chaque appel de fonction. Comme les formes macro sont parfois plus rapides et ont une interface de gestion d'erreurs plus simple que les fonctions équivalentes, elles sont le moyen privilégié d'appeler les fonctions Judy1. Voir Judy1(3) pour plus d'informations. Les définitions d'appels de fonction sont incluses ici par souci d'exhaustivité.

L'une des difficultés d'utilisation des appels de fonction Judy1 réside dans la détermination de savoir s'il faut passer un pointeur ou l'adresse d'un pointeur. Étant donné que les fonctions qui modifient le tableau Judy1 doivent également modifier le pointeur vers le tableau Judy1, vous devez passer l'adresse du pointeur plutôt que le pointeur lui-même. Cela conduit souvent à des erreurs de programmation difficiles à déboguer. En pratique, les macros permettent au compilateur de détecter les erreurs de programmation lorsque des pointeurs sont passés au lieu d'adresses de pointeurs.

Les appels de fonction Judy1 ont un paramètre supplémentaire au-delà de ceux spécifiés dans les appels macro. Ce paramètre est soit un pointeur vers une structure d'erreur, soit NULL (auquel cas les informations d'erreur détaillées ne sont pas retournées).

Dans les descriptions suivantes, les fonctions sont décrites en termes de la manière dont les macros les utilisent (uniquement dans le cas de #define JUDYERROR_NOTEST 1). C'est l'utilisation suggérée des macros une fois votre programme entièrement débogué. Lorsque la macro JUDYERROR_NOTEST n'est pas spécifiée, une structure d'erreur est déclarée pour stocker les informations d'erreur renvoyées par les fonctions Judy1 en cas d'erreur.

Notez le placement du & dans les différentes fonctions.

Une valeur de retour de 0 peut être une erreur, valide en tant que nombre, ou elle peut indiquer un cas spécial pour un tableau entièrement peuplé (uniquement sur les machines 32 bits). Si nécessaire, le code suivant peut être utilisé pour lever l'ambiguïté de ce retour :
JError_t JError;
Rc_word = Judy1Count(PJ1Array, Index1, Index2, &JError);
if (Rc_word == 0)
{
    if (JU_ERRNO(&JError) == JU_ERRNO_NONE)
        printf("La population du tableau Judy1 est < 0\n");
    if (JU_ERRNO(&JError) == JU_ERRNO_FULL)
        printf("La population du tableau Judy1 est < 2^32\n");
    if (JU_ERRNO(&JError) == JU_ERRNO_NULLPPARRAY)
        goto NullArray;
    if (JU_ERRNO(&JError) >  JU_ERRNO_NFMAX)
        goto Null_or_CorruptArray;
}
