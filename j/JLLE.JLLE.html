Paquet: judy

Licences: LGPL

JudyL(3) Manuel des fonctions de bibliothèque JudyL(3)

NOM

Macros JudyL - Bibliothèque C pour créer et accéder à un tableau dynamique de mots, en utilisant un mot comme index.

SYNOPIS

cc [indicateurs] fichiers_source -lJudy
#include <Judy.h>
int      Rc_int;                          // code de retour - entier
Word_t   Rc_word;                         // code de retour - mot non signé
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // pointeur vers la valeur de retour
Pvoid_t PJLArray = (Pvoid_t) NULL;        // initialiser le tableau JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

DESCRIPTION

Un tableau JudyL est l'équivalent d'un tableau de valeurs de taille mot. Une Valeur est adressée par un Index (clé). Le tableau peut être sparse, et l'Index peut être n'importe quel nombre de taille mot. La mémoire pour supporter le tableau est allouée à mesure que les paires index/valeur sont insérées, et libérée à mesure que les paires index/valeur sont supprimées. Un tableau JudyL peut également être considéré comme un mappeur, c'est-à-dire qu'il "mappe" un mot à un autre mot/pointeur.

Comme avec un tableau ordinaire, il n'y a pas d'index dupliqués dans un tableau JudyL.

La valeur peut être utilisée comme un scalaire, ou comme un pointeur vers une structure ou un bloc de données (ou même un autre tableau Judy).

Un tableau JudyL est alloué avec un pointeur NULL

Pvoid_t PJLArray = (Pvoid_t) NULL;

En utilisant les macros décrites ici, plutôt que les appels de fonction JudyL, la gestion d'erreurs par défaut envoie un message à la sortie d'erreur standard et termine le programme avec exit(1);. Pour d'autres méthodes de gestion des erreurs, voir la section ERREURS. JLI( PValue, PJLArray, Index); // JudyLIns()

Parce que les formes de macros sont parfois plus rapides et ont une interface de gestion d'erreurs plus simple que les fonctions JudyL équivalentes, elles sont le moyen privilégié d'appeler les fonctions JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
Insère un Index et une Valeur dans le tableau JudyL PJLArray. Si l'Index est inséré avec succès, la Valeur est initialisée à 0. Si l'Index était déjà présent, la Valeur n'est pas modifiée.
Retourne PValue pointant vers la Valeur. Votre programme peut utiliser ce pointeur pour lire ou modifier la Valeur jusqu'à ce que le prochain appel JLI() (insertion), JLD() (suppression) ou JLFA() (libération de tableau) soit exécuté sur PJLArray. Exemples :
*PValue = 1234;
Valeur = *PValue;
Retourne PValue défini à PJERR si une erreur malloc() s'est produite. Note : JLI() et JLD() réorganisent le tableau JudyL. Par conséquent, PValue retourné par les appels précédents de JudyL devient invalide et doit être réacquis.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
Supprime la paire Index/Valeur du tableau JudyL.
Retourne Rc_int défini à 1 si succès. Retourne Rc_int défini à 0 si l'Index n'était pas présent. Retourne Rc_int défini à JERR si une erreur malloc() s'est produite.

JLG(PValue, PJLArray, Index) // JudyLGet()
Obtient le pointeur PValue associé à l'Index dans le tableau Judy PJLArray.
Retourne PValue pointant vers la Valeur. Retourne PValue défini à NULL si l'Index n'était pas présent. Retourne PValue défini à PJERR si une erreur malloc() s'est produite.

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
Compte le nombre d'index présents dans le tableau JudyL PJLArray entre Index1 et Index2 (inclus).
Retourne Rc_word défini au nombre. Une valeur de retour de 0 peut être valide en tant que compte.
Pour compter tous les index présents dans un tableau JudyL, utilisez :
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
Localise le Nth index présent dans le tableau JudyL PJLArray (Nth = 1 retourne le premier index présent).
Retourne PValue pointant vers sa Valeur et Index défini au Nth index s'il est trouvé, sinon retourne PValue défini à NULL (la valeur de Index est indéfinie).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
Étant donné un pointeur vers un tableau JudyL, libère tout le tableau (beaucoup plus rapide que d'utiliser une boucle JLN(), JLD()).
Retourne Rc_word défini au nombre d'octets libérés et PJLArray défini à NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
Retourne Rc_word défini au nombre d'octets de mémoire malloc()'és par PJLArray. C'est une routine très rapide, et peut être utilisée avant et après un appel JLI() ou JLD() avec peu d'impact sur les performances.

Fonctions de recherche JudyL
JLF(), JLN(), JLL(), JLP() vous permettent de rechercher des index dans le tableau. Vous pouvez rechercher inclusivement ou exclusivement, dans des directions avant ou arrière. En cas de succès, Index est retourné défini à l'index trouvé, et PValue est retourné défini à un pointeur vers la Valeur de l'Index. En cas d'échec, PValue est retourné défini à NULL, et Index ne contient aucune information utile. PValue doit être testé pour non-NULL avant d'utiliser Index, car un échec de recherche est possible.
JLFE(), JLNE(), JLLE(), JLPE() vous permettent de rechercher des index qui ne sont pas présents ("vides") dans le tableau. Vous pouvez rechercher inclusivement ou exclusivement, dans des directions avant ou arrière. En cas de succès, Index est retourné défini à un index non présent ("vide"), et Rc_int est retourné défini à 1. En cas d'échec, Rc_int est retourné défini à 0, et et Index ne contient aucune information utile. Rc_int doit être vérifié avant d'utiliser Index, car un échec de recherche est possible.

JLF(PValue, PJLArray, Index) // JudyLFirst()
Recherche (inclusivement) le premier index présent qui est égal ou supérieur à l'Index passé. (Commencer avec Index = 0 pour trouver le premier index dans le tableau.) JLF() est typiquement utilisé pour *commencer* un balayage en ordre trié des index présents dans un tableau JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
Recherche (exclusivement) le prochain index présent qui est supérieur à l'Index passé. JLN() est typiquement utilisé pour *continuer* un balayage en ordre trié des index présents dans un tableau JudyL, ou pour localiser un "voisin" d'un index donné.

JLLE(JLLE) - JudyL functions

NAME

JLLE, JLL, JLP, JLFE, JLNE, JLPE - JudyL array functions

SYNOPSIS

 #include <Judy.h>

 PWord_t
 JLL(Pvoid_t JudyLArray, Word_t Index);

 PWord_t
 JLP(Pvoid_t JudyLArray, Word_t Index);

 PWord_t
 JLFE(Pvoid_t JudyLArray, Word_t Index);

 PWord_t
 JLNE(Pvoid_t JudyLArray, Word_t Index);

 PWord_t
 JLLE(Pvoid_t JudyLArray, Word_t Index);

 PWord_t
 JLPE(Pvoid_t JudyLArray, Word_t Index);

DESCRIPTION

JudyL arrays are an ordered associative array that stores an arbitrary value at an arbitrary index. The index can be any unsigned integer value. The value can be any pointer to a data type.

Functions are provided to allow random access to the array data as well as sequential access in either ascending or descending order. A JudyL array can be used to implement a sparse array or a simple list.

The JudyL array is a generic C data structure. The JudyL array pointer is passed as the first argument, then the index, and finally the pointer to the value. For a search function, the index is passed, then the array pointer, and finally the pointer to the value.


JLL(PValue, PJLArray, Index) // JudyLLast()
Search (inclusive) for the last index present that is equal to or less than the passed Index. (Start with Index = -1, that is, all ones, to find the last index in the array.) JLL() is typically used to begin a reverse-sorted-order scan of the indexes present in a JudyL array.

JLP(PValue, PJLArray, Index) // JudyLPrev()
Search (exclusive) for the previous index present that is less than the passed Index. JLP() is typically used to continue a reverse-sorted-order scan of the indexes present in a JudyL array, or to locate a "neighbor" of a given index.

JLFE(Rc_int, PJLArray, Index) // JudyLFirstEmpty()
Search (inclusive) for the first index absent that is equal to or greater than the passed Index. (Start with Index = 0 to find the first index absent in the array.)

JLNE(Rc_int, PJLArray, Index) // JudyLNextEmpty()
Search (exclusive) for the next index absent that is greater than the passed Index.

JLLE(Rc_int, PJLArray, Index) // JudyLLastEmpty()
Search (inclusive) for the last index absent that is equal to or less than the passed Index. (Start with Index = -1, that is, all ones, to find the last index absent in the array.)

JLPE(Rc_int, PJLArray, Index) // JudyLPrevEmpty()
Search (exclusive) for the previous index absent that is less than the passed Index.

Multi-dimensional JudyL Arrays

Storing a pointer to another JudyL array in a JudyL array's Value is a simple way to support dynamic multi-dimensional arrays. These arrays (or trees) built using JudyL arrays are very fast and memory efficient. (In fact, that is how JudySL and JudyHS are implemented). An arbitrary number of dimensions can be realized this way. To terminate the number of dimensions (or tree), the Value pointer is marked to NOT point to another Judy array. A JLAP_INVALID flag is used in the least significant bit(s) of the pointer. After the flag JLAP_INVALID is removed, it is used as a pointer to the users data. The Judy.h header file defines JLAP_INVALID. See code fragment below.

Note: The current version of Judy.h changed this flag from 0x4 to 0x1 to allow for a malloc() that does not deliver memory on an 8 byte aligned boundry (such as old versions of valgrind).

The following example code segment can be used to determine whether or not a pointer points to another JudyL:

PValue = (PWord_t)PMultiDimArray;
for (Dim = 0; ;Dim++)
{
   if (PValue == (PWord_t)NULL) goto IndexNotFound;
   /* Advance to next dimension in array */
   JLG(PValue, (Pvoid_t)*PValue, Index[Dim]);
   /* Check if pointer to user buffer: */
   if (*PValue & JLAP_INVALID)) break;
}
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // mask and cast.
printf("User object pointer is 0x%lx\n", (Word_t) UPointer);
       ...

Note: This works because malloc() guarantees to return a pointer with the least bit(s) == 0x0. You must remove JLAP_INVALID before using the pointer.

ERRORS: See: Judy_3.htm#ERRORS

EXAMPLE

Read a series of index/value pairs from the standard input, store in a JudyL array, and then print out in sorted order.

#include <stdio.h>
#include <Judy.h>
Word_t   Index;                     // array index
Word_t   Value;                     // array element value
Word_t * PValue;                    // pointer to array element value
int      Rc_int;                    // return code
Pvoid_t  PJLArray = (Pvoid_t) NULL; // initialize JudyL array
while (scanf("%lu %lu", &Index, &Value))
{
    JLI(PValue, PJLArray, Index);
    If (PValue == PJERR) goto process_malloc_failure;
    *PValue = Value;                 // store new value
}
// Next, visit all the stored indexes in sorted order, first ascending,
// then descending, and delete each index during the descending pass.
Index = 0;
JLF(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLN(PValue, PJLArray, Index);
}
Index = -1;
JLL(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLD(Rc_int, PJLArray, Index);
    if (Rc_int == JERR) goto process_malloc_failure;
    JLP(PValue, PJLArray, Index);
}
