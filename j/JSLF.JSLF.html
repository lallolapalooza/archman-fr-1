Paquet: judy

Licences: LGPL

JudySL(3) Manuel des fonctions de librairie JudySL(3)

NOM

JudySL - Librairie de fonctions pour créer et accéder à un tableau dynamique, en utilisant une chaîne nulle comme Index (tableau associatif)

SYNTAXE

cc [flags] fichiers source -lJudy
#include <Judy.h>
#define MAXLINELEN 1000000           // définition de la longueur maximale de chaîne
Word_t * PValue;                     // valeur de l'élément du tableau JudySL
uint8_t  Index[MAXLINELEN];          // chaîne
int      Rc_int;                     // valeur de retour
Word_t   Rc_word;                    // valeur de retour complète
Pvoid_t PJSLArray = (Pvoid_t) NULL;  // initialiser le tableau JudySL
JSLI( PValue,  PJSLArray, Index);   // JudySLIns()
JSLD( Rc_int,  PJSLArray, Index);   // JudySLDel()
JSLG( PValue,  PJSLArray, Index);   // JudySLGet()
JSLFA(Rc_word, PJSLArray);          // JudySLFreeArray()
JSLF( PValue,  PJSLArray, Index);   // JudySLFirst()
JSLN( PValue,  PJSLArray, Index);   // JudySLNext()
JSLL( PValue,  PJSLArray, Index);   // JudySLLast()
JSLP( PValue,  PJSLArray, Index);   // JudySLPrev()

DESCRIPTION

Un tableau JudySL est équivalent à un ensemble ordonné de chaînes, chacune associée à une Valeur (mot). Une Valeur est accédée par un Index (clé), qui est une chaîne nulle de n'importe quelle longueur. L'espace mémoire nécessaire pour le tableau est alloué au fur et à mesure que les paires index/valeur sont insérées, et libéré lorsque les paires index/valeur sont supprimées. C'est une forme de tableau associatif, où les éléments du tableau sont également triés lexicographiquement (en majuscules). On peut y penser ainsi :

void * JudySLArray["Toto, je ne pense pas que nous soyons plus au Kansas"];

Un tableau JudySL est alloué avec un pointeur NULL

Pvoid_t PJSLArray = (Pvoid_t) NULL;
Comme pour un tableau ordinaire, il n'y a pas d'index dupliqués (chaînes) dans un tableau JudySL.

En utilisant les macros décrites ici, plutôt que les fonctions JudySL, la gestion d'erreurs par défaut envoie un message sur la sortie standard et termine le programme avec exit(1).

JSLI(PValue, PJSLArray, Index) // JudySLIns()

Insère une chaîne Index et une Valeur dans le tableau JudySL PJSLArray. Si l'Index est inséré avec succès, la Valeur est initialisée à 0. Si l'Index existe déjà, la Valeur n'est pas modifiée.

Retourne PValue pointant vers la Valeur de l'Index. Votre programme doit utiliser ce pointeur pour modifier la Valeur, par exemple :

*PValue = 1234;

Note : JSLI() et JSLD réorganisent le tableau JudySL. Par conséquent, les pointeurs retournés par les appels précédents à JudySL ne sont plus valides et doivent être réacquis.

JSLD(Rc_int, PJSLArray, Index) // JudySLDel()

Supprime la paire index/valeur spécifiée (élément du tableau) du tableau JudySL.

Retourne Rc_int avec la valeur 1 si l'opération réussit. Si l'Index n'était pas présent, retourne 0.

JSLG(PValue, PJSLArray, Index) // JudySLGet()

Retourne le pointeur vers la Valeur de l'Index.

Retourne PValue pointant vers la Valeur de l'Index. Si l'Index n'est pas présent, PValue est mis à NULL.

JSLFA(Rc_word, PJSLArray) // JudySLFreeArray()

Étant donné un pointeur vers un tableau JudySL (PJSLArray), libère l'ensemble du tableau (plus rapide que d'utiliser JSLN(), JSLD()).

Retourne Rc_word avec le nombre d'octets libérés et PJSLArray est mis à NULL.

Fonctions de recherche JudySL

Les fonctions de recherche JudySL permettent de rechercher des index dans le tableau. Vous pouvez rechercher inclusivement ou exclusivement, dans les directions avant ou arrière.

En cas de succès, Index est retourné avec la valeur trouvée, et PValue pointe vers la Valeur de l'Index. En cas d'échec, PValue est mis à NULL et Index ne contient aucune information utile. Il faut tester PValue pour s'assurer qu'il n'est pas NULL avant d'utiliser Index, car une recherche peut échouer.

Note : Pour supporter tous les résultats possibles, le buffer Index doit être au moins aussi grand que la chaîne la plus longue dans le tableau.

JSLF(PValue, PJSLArray, Index) // JudySLFirst()

Recherche (inclusivement) le premier index présent qui est égal ou supérieur à l'index passé. (Commencez avec une chaîne vide pour trouver le premier index dans le tableau.) JSLF() est typiquement utilisé pour *commencer* un parcours ordonné des index valides dans un tableau JudySL.

uint8_t Index[MAXLINELEN];
strcpy (Index, "");
JSLF(PValue, PJSLArray, Index);

JSLN(PValue, PJSLArray, Index) // JudySLNext()

Recherche (exclusivement) l'index présent suivant qui est strictement supérieur à l'index passé. JSLN() est typiquement utilisé pour *continuer* un parcours ordonné des index valides dans un tableau JudySL, ou pour trouver un "voisin" d'un index donné.

JSLL(PValue, PJSLArray, Index) // JudySLLast()

Recherche (inclusivement) le dernier index présent qui est égal ou inférieur à l'index passé. (Commencez avec un index maximal pour rechercher le dernier index dans le tableau, par exemple une chaîne d'octets 0xff.) JSLL() est typiquement utilisé pour *commencer* un parcours ordonné inversé des index valides dans un tableau JudySL.

JSLP(PValue, PJSLArray, Index) // JudySLPrev()

Recherche (exclusivement) l'index précédent présent qui est strictement inférieur à l'index passé. JSLP() est typiquement utilisé pour *continuer* un parcours ordonné inversé des index valides dans un tableau JudySL, ou pour trouver un "voisin" d'un index donné.

Exemple d'une routine de tri de chaînes

#include <stdio.h>
#include <Judy.h>
#define MAXLINE 1000000                 // longueur maximale de chaîne (ligne)
uint8_t   Index[MAXLINE];               // chaîne à insérer
int     // Utilisation :  JudySort < fichier_à_trier
main()
{
    Pvoid_t   PJArray = (PWord_t)NULL;  // tableau JudySL.
    PWord_t   PValue;                   // élément du tableau JudySL.
    Word_t    Bytes;                    // taille du tableau JudySL.
    while (fgets(Index, MAXLINE, stdin) != (char *)NULL)
    {
        JSLI(PValue, PJArray, Index);   // insérer chaîne dans le tableau
        if (PValue == PJERR)            // s'il n'y a pas assez de mémoire
        {                               // faire quelque chose
            printf("Échec de malloc -- obtenir plus de RAM\n");
            exit(1);
        }
        ++(*PValue);                    // compter les occurrences de la chaîne
    }
    Index[0] = '\0';                    // commencer avec la chaîne la plus petite.
    JSLF(PValue, PJArray, Index);       // obtenir le premier index
    while (PValue != NULL)
    {
        while ((*PValue)--)             // imprimer les doublons
            printf("%s", Index);
        JSLN(PValue, PJArray, Index);   // obtenir l'index suivant
    }
    JSLFA(Bytes, PJArray);              // libérer le tableau
    fprintf(stderr, "Le tableau JudySL a utilisé %lu octets de mémoire\n", Bytes);
    return (0);
}
    fprintf(stderr, "Le tableau JudySL a utilisé %lu octets de mémoire\n", Bytes);
    return (0);
}
