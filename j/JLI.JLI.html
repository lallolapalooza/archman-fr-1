DESCRIPTIO

N

Un tableau JudyL est l'équivalent d'un tableau de valeurs de la taille d'un mot. Une Valeur est adressée par un Index (clé). Le tableau peut être creux, et l' Index peut être un nombre de n'importe quelle taille de mot. La mémoire nécessaire au tableau est allouée au fur et à mesure que des paires index/valeur sont insérées, et libérée lorsque des paires index/valeur sont supprimées. Un tableau JudyL peut aussi être considéré comme un mapper, c'est-à-dire "mapper" un mot vers un autre

mot/pointeur.

Comme pour un tableau ordinaire, il n'y a pas de doublons d'index dans un tableau

JudyL.

La valeur peut être utilisée comme un scalaire, ou un pointeur vers une structure ou un bloc de données (ou même un autre tableau Judy)

.

Un tableau JudyL est alloué avec un pointeu

Fonctions de recherche
JudyL
JLF(), JLN(), JLL(), JLP() vous permettent de rechercher des index dans le tableau. Vous pouvez rechercher de manière inclusive ou exclusive, dans les sens avant ou arrière. Si réussi, Index est retourné défini à l'index trouvé, et PValue est retourné défini à un pointeur vers la Valeur de Index. Si non réussi, PValue est retourné défini à NULL, et Index ne contient aucune information utile. PValue doit être testé pour non-NULL avant d'utiliser Index, car une échec de
recherche e
st possible.
JLFE(), JLNE(), JLLE(), JLPE() vous permettent de rechercher des index qui ne sont pas présents ("vides") dans le tableau. Vous pouvez rechercher de manière inclusive ou exclusive, dans les sens avant ou arrière. Si réussi, Index est retourné défini à un index non présent ("vide"), et Rc_int est retourné défini à 1. Si non réussi, Rc_int est retourné défini à 0, et Index ne contient aucune information utile. Rc_int doit être vérifié avant d'utiliser Index, car un échec de
recherche e
st possible.

JLF(PValue, PJLArray, Index) // JudyLFirst
()
Recherche (inclusive) du premier index présent qui est égal ou supérieur à l' Index passé. (Commencer avec Index = 0 pour trouver le premier index du tableau.) JLF() est typiquement utilisé pour commencer un parcours en ordre trié des index présents dans un tableau
JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext
()
Recherche (exclusive) du prochain index présent qui est supérieur à l' Index passé. JLN() est typiquement utilisé pour continuer un parcours en ordre trié des index présents dans un tableau JudyL, ou pour localiser un "voisin" d'un index
donné.

JLL(PValue, PJLArray, Index) // JudyLLast()
Recherche (inclusive) du dernier index présent qui est égal ou inférieur à l'index passé Index. (Commencez avec Index = -1, c'est-à-dire tous les uns, pour trouver le dernier index du tableau.) JLL() est typiquement utilisé pour *commencer* un balayage d'index présents dans un tableau JudyL dans l'ordre inverse trié.

JLP(PValue, PJLArray, Index) // JudyLPrev()
Recherche (exclusive) de l'index précédent présent qui est inférieur à l'index passé Index. JLP() est typiquement utilisé pour *continuer* un balayage d'index présents dans un tableau JudyL dans l'ordre inverse trié, ou pour localiser un "voisin" d'un index donné.

JLFE(Rc_int, PJLArray, Index) // JudyLFirstEmpty()
Recherche (inclusive) du premier index absent qui est égal ou supérieur à l'index passé Index. (Commencez avec Index = 0 pour trouver le premier index absent du tableau.)

JLNE(Rc_int, PJLArray, Index) // JudyLNextEmpty()
Recherche (exclusive) du prochain index absent qui est supérieur à l'index passé Index.

JLLE(Rc_int, PJLArray, Index) // JudyLLastEmpty()
Recherche (inclusive) du dernier index absent qui est égal ou inférieur à l'index passé Index. (Commencez avec Index = -1, c'est-à-dire tous les uns, pour trouver le dernier index absent du tableau.)

JLPE(Rc_int, PJLArray, Index) // JudyLPrevEmpty()
Recherche (exclusive) de l'index précédent absent qui est inférieur à l'index passé Index.

Tableaux JudyL multi-dimensionnels

Stocker un pointeur vers un autre tableau JudyL dans la Value d'un tableau JudyL est un moyen simple de prendre en charge les tableaux multi-dimensionnels dynamiques. Ces tableaux (ou arbres) construits à l'aide de tableaux JudyL sont très rapides et économes en mémoire. (En fait, c'est ainsi que JudySL et JudyHS sont implémentés). Un nombre arbitraire de dimensions peut être réalisé de cette manière. Pour terminer le nombre de dimensions (ou d'arbres), le pointeur Value est marqué pour NE PAS pointer vers un autre tableau Judy. Un indicateur JLAP_INVALID est utilisé dans le(s) bit(s) le moins significatif(s) du pointeur. Après avoir supprimé l'indicateur JLAP_INVALID, il est utilisé comme pointeur vers les données de l'utilisateur. Le fichier d'en-tête Judy.h définit JLAP_INVALID. Voir le fragment de code ci-dessous.

Note : La version actuelle de Judy.h a changé cet indicateur de 0x4 à 0x1 pour permettre un malloc() qui ne livre pas la mémoire sur une frontière alignée sur 8 octets (comme les anciennes versions de valgrind).

Le segment de code d'exemple suivant peut être utilisé pour déterminer si un pointeur pointe ou non vers un autre JudyL :

PValue = (PWord_t)PMultiDimArray;
for (Dim = 0; ;Dim++)
{
   if (PValue == (PWord_t)NULL) goto IndexNotFound;
   /* Avancer à la prochaine dimension du tableau */
   JLG(PValue, (Pvoid_t)*PValue, Index[Dim]);
   /* Vérifier s'il s'agit d'un pointeur vers un buffer utilisateur : */
   if (*PValue & JLAP_INVALID)) break;
}
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // masquer et caster.
printf("Le pointeur de l'objet utilisateur est 0x%lx\n", (Word_t) UPointer);
       ...

Note : Cela fonctionne car malloc() garantit de retourner un pointeur avec le(s) bit(s) le(s) moins significatif(s) == 0x0. Vous devez supprimer JLAP_INVALID avant d'utiliser le pointeur.

EXEMPLE

Lire une série de paires index/valeur depuis l'entrée standard, les stocker dans un tableau JudyL, puis les imprimer dans l'ordre trié.

#include <stdio.h>
#include <Judy.h>
Word_t   Index;                     // index du tableau
Word_t   Value;                     // valeur de l'élément du tableau
Word_t * PValue;                    // pointeur vers l'élément du tableau
int      Rc_int;                    // code de retour
Pvoid_t  PJLArray = (Pvoid_t) NULL; // initialiser le tableau JudyL
while (scanf("%lu %lu", &Index, &Value))
{
    JLI(PValue, PJLArray, Index);
    If (PValue == PJERR) goto process_malloc_failure;
    *PValue = Value;                 // stocker la nouvelle valeur
}
// Ensuite, visiter tous les index stockés dans l'ordre trié, d'abord croissant,
// puis décroissant, et supprimer chaque index pendant le passage décroissant.
Index = 0;
JLF(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLN(PValue, PJLArray, Index);
}
Index = -1;
JLL(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLD(Rc_int, PJLArray, Index);
    if (Rc_int == JERR) goto process_malloc_failure;
    JLP(PValue, PJLArray, Index);
}
