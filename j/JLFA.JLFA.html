DESCRIPTION

The Judy array libraries are dynamic, sparse arrays that are extremely fast and memory efficient. They provide an abstract data type that can be used to store values that are indexed by integers or arbitrary pointers.

The functions described in this man page are for the JudyL and Judy1 (integer indexed) Judy arrays.

The Judy array libraries are an order of magnitude faster and more memory efficient than the standard C data structures like hash tables and B-trees. This is because they use a compact, 8-way branching trie-like structure to store data.

The primary functions are:


JLI(PValue, PJLArray, Index) // JudyLInsert()
Insert (or replace) the value at Index in the PJLArray. The value is the value that the PValue pointer points to. The return value is a pointer to the value in the Judy array. This pointer should be dereferenced to store the value. Use PJERR to check for malloc() errors.

JLFA(PValue, PJLArray, Index) // JudyLFirst()
Search (inclusive) for the first index present that is equal to or greater than the passed Index. (Start with Index = 0 to find the first index in the array.)

JLF(PValue, PJLArray, Index) // JudyLFirst()
Search (inclusive) for the first index present that is equal to or greater than the passed Index. (Start with Index = 0 to find the first index in the array.)

JLN(PValue, PJLArray, Index) // JudyLNext()
Search (exclusive) for the next index present that is greater than the passed Index.

JLL(PValue, PJLArray, Index) // JudyLLast()
Search (inclusive) for the last index present that is equal to or less than the passed Index. (Start with Index = -1, that is, all ones, to find the last index in the array.) JLL() is typically used to begin a reverse-sorted-order scan of the indexes present in a JudyL array.

JLP(PValue, PJLArray, Index) // JudyLPrev()
Search (exclusive) for the previous index present that is less than the passed Index. JLP() is typically used to continue a reverse-sorted-order scan of the indexes present in a JudyL array, or to locate a "neighbor" of a given index.

JLFE(Rc_int, PJLArray, Index) // JudyLFirstEmpty()
Search (inclusive) for the first index absent that is equal to or greater than the passed Index. (Start with Index = 0 to find the first index absent in the array.)

JLNE(Rc_int, PJLArray, Index) // JudyLNextEmpty()
Search (exclusive) for the next index absent that is greater than the passed Index.

JLLE(Rc_int, PJLArray, Index) // JudyLLastEmpty()
Search (inclusive) for the last index absent that is equal to or less than the passed Index. (Start with Index = -1, that is, all ones, to find the last index absent in the array.)

JLPE(Rc_int, PJLArray, Index) // JudyLPrevEmpty()
Search (exclusive) for the previous index absent that is less than the passed Index.

Tableaux JudyL Multi-dimensionnels

Stocker un pointeur vers un autre tableau JudyL dans la Valeur d'un tableau JudyL est un moyen simple de supporter les tableaux multi-dimensionnels dynamiques. Ces tableaux (ou arbres) construits en utilisant des tableaux JudyL sont très rapides et économes en mémoire. (En fait, c'est ainsi que JudySL et JudyHS sont implémentés). Un nombre arbitraire de dimensions peut être réalisé de cette façon. Pour terminer le nombre de dimensions (ou d'arbres), le pointeur Valeur est marqué pour NE PAS pointer vers un autre tableau Judy. Un indicateur JLAP_INVALID est utilisé dans le(s) bit(s) de poids faible du pointeur. Après que l'indicateur JLAP_INVALID a été retiré, il est utilisé comme pointeur vers les données de l'utilisateur. Le fichier d'en-tête Judy.h définit JLAP_INVALID. Voir le fragment de code ci-dessous.

Note : La version actuelle de Judy.h a changé cet indicateur de 0x4 à 0x1 pour permettre un malloc() qui ne livre pas de mémoire sur une limite alignée de 8 octets (comme les anciennes versions de valgrind).

Le segment de code d'exemple suivant peut être utilisé pour déterminer si un pointeur pointe ou non vers un autre JudyL :

PValue = (PWord_t)PMultiDimArray;
for (Dim = 0; ;Dim++)
{
   if (PValue == (PWord_t)NULL) goto IndexNotFound;
   /* Avancer vers la dimension suivante dans le tableau */
   JLG(PValue, (Pvoid_t)*PValue, Index[Dim]);
   /* Vérifier si c'est un pointeur vers le tampon utilisateur : */
   if (*PValue & JLAP_INVALID)) break;
}
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // Masquer et caster.
printf("Le pointeur de l'objet utilisateur est 0x%lx\n", (Word_t) UPointer);
       ...

Note : Cela fonctionne car malloc() garantit de renvoyer un pointeur dont le(s) bit(s) de poids faible est == 0x0. Vous devez retirer JLAP_INVALID avant d'utiliser le pointeur.

EXEMPLE

Lire une série de paires index/valeur depuis l'entrée standard, les stocker dans un tableau JudyL, puis les imprimer dans l'ordre trié.

#include <stdio.h>
#include <Judy.h>
Word_t   Index;                     // indice du tableau
Word_t   Value;                     // valeur de l'élément du tableau
Word_t * PValue;                    // pointeur vers la valeur de l'élément du tableau
int      Rc_int;                    // code de retour
Pvoid_t  PJLArray = (Pvoid_t) NULL; // initialiser le tableau JudyL
while (scanf("%lu %lu", &Index, &Value))
{
    JLI(PValue, PJLArray, Index);
    If (PValue == PJERR) goto process_malloc_failure;
    *PValue = Value;                 // stocker la nouvelle valeur
}
// Ensuite, parcourir tous les indices stockés dans l'ordre trié, d'abord croissant,
// puis décroissant, et supprimer chaque indice lors du passage décroissant.
Index = 0;
JLF(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLN(PValue, PJLArray, Index);
}
Index = -1;
JLL(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLD(Rc_int, PJLArray, Index);
    if (Rc_int == JERR) goto process_malloc_failure;
    JLP(PValue, PJLArray, Index);
}
