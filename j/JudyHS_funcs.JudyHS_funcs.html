JudyHS_funcs(3) Manuel des fonctions de bibliothèque JudyHS_funcs(3)

NOM

Fonctions JudyHS - Bibliothèque C pour créer et accéder à un tableau dynamique, en utilisant un tableau d'octets d'une longueur : Longueur comme Index et un mot comme Valeur.

SYNTAXE

PPvoid_t JudyHSIns(PPvoid_t PPJHS, void *Index, Word_t Length, PJError_t PJError);
int      JudyHSDel(PPvoid_t PPJHS, void *Index, Word_t Length, PJError_t PJError);
PPvoid_t JudyHSGet(Pcvoid_t  PJHS, void *Index, Word_t Length, PJError_t PJError);
Word_t   JudyHSFreeArray(PPvoid_t PPJHS, PJError_t PJError);

DESCRIPTION

Un équivalent macro existe pour chaque appel de fonction. Comme les formes de macro sont parfois plus rapides et ont une interface de gestion des erreurs plus simple que les fonctions équivalentes, elles constituent le moyen préféré d'appeler les fonctions JudyHS. Voir JudyHS(3) pour plus d'informations. Les définitions d'appel de fonction sont incluses ici pour plus de complétude.

L'une des difficultés d'utilisation des appels de fonction JudyHS réside dans la détermination s'il faut passer un pointeur ou l'adresse d'un pointeur. Étant donné que les fonctions qui modifient le tableau JudyHS doivent également modifier le pointeur vers le tableau JudyHS, vous devez passer l'adresse du pointeur plutôt que le pointeur lui-même. Cela conduit souvent à des erreurs de programmation difficiles à déboguer. En pratique, les macros permettent au compilateur de détecter les erreurs de programmation lorsque des pointeurs sont passés au lieu d'adresses de pointeurs.

Les appels de fonction JudyHS ont un paramètre supplémentaire au-delà de ceux spécifiés dans les appels macro. Ce paramètre est soit un pointeur vers une structure d'erreur, soit NULL (auquel cas les informations d'erreur ne sont pas retournées -- seulement PJERR dans le paramètre de retour).

Dans les descriptions suivantes, les fonctions sont décrites en termes de la manière dont les macros les utilisent. C'est l'utilisation suggérée des macros après que votre programme a été entièrement débogué. Lorsque la macro JUDYERROR_NOTEST n'est pas spécifiée, une structure d'erreur est déclarée pour stocker les informations d'erreur renvoyées par les fonctions JudyHS en cas d'erreur.

Notez le placement du & dans les différentes fonctions.


JudyHSIns(&PJHS, Index, Longueur, &JError)
#define JHSI(PValue, PJHS, Index) \
   PValue = JudyLIns(&PJHS, Index, PJE0)

JudyHSDel(&PJHS, Index, Longueur, &JError)
#define JHSD(Rc_int, PJHS, Index, Length) \
   Rc_int = JudyHSDel(&PJHS, Index, Length, PJE0)

JudyHSGet(PJHS, Index, Longueur)
#define JHSG(PValue, PJHS, Index, Length) \
   PValue = JudyHSIns(PJHS, Index, Length)

JudyHSFreeArray(&PJHS, &JError)
#define JHSFA(Rc_word, PJHS) \
   Rc_word = JudyHSFreeArray(&PJHS, PJE0)

Les définitions de toutes les fonctions Judy, les types Pvoid_t, Pcvoid_t, PPvoid_t, Word_t, JError_t et PJError_t, les constantes NULL, JU_ERRNO_*, JERR, PPJERR et PJE0 sont fournies dans le fichier d'en-tête Judy.h (/usr/include/Judy.h). Note : les appelants doivent définir les tableaux JudyHS comme type Pvoid_t, qui peut être passé par valeur aux fonctions prenant Pcvoid_t (Pvoid_t constant), et aussi par adresse aux fonctions prenant PPvoid_t.

Le type de retour de la plupart des fonctions JudyHS est PPvoid_t afin que les valeurs stockées dans le tableau puissent être des pointeurs vers d'autres objets, ce qui est un usage typique, ou converties en un Word_t * lorsqu'un pointeur vers une valeur est requis au lieu d'un pointeur vers un pointeur.
