JudySL_funcs.JudySL_funcs

Paquet: judy

Licences: LGPL

JudySL_funcs(3) Manuel des fonctions de bibliothèque JudySL_funcs(3)

NOM

Fonctions JudySL - bibliothèque C pour la création et l'accès à un tableau dynamique, utilisant une chaîne de caractères terminée par un caractère nul comme index (tableau associatif)

SYNOPSIS

PPvoid_t JudySLIns(      PPvoid_t PPJSLArray, const uint8_t * Index, PJError_t PJError);
int      JudySLDel(      PPvoid_t PPJSLArray, const uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLGet(      Pcvoid_t  PJSLArray, const uint8_t * Index, PJError_t PJError);
Word_t   JudySLFreeArray(PPvoid_t PPJSLArray, PJError_t PJError);
PPvoid_t JudySLFirst(    Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLNext(     Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLLast(     Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLPrev(     Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);

DESCRIPTION

Un équivalent macro existe pour chaque appel de fonction. Comme les formes macro sont parfois plus rapides et ont une interface de gestion d'erreurs plus simple que les fonctions équivalentes, elles constituent le moyen privilégié d'appeler les fonctions JudySL. Voir JudySL(3) pour plus d'informations. Les définitions d'appels de fonction sont incluses ici pour la complétude.

L'une des difficultés dans l'utilisation des appels de fonction JudySL réside dans la détermination s'il faut passer un pointeur ou l'adresse d'un pointeur. Étant donné que les fonctions qui modifient le tableau JudySL doivent également modifier le pointeur vers le tableau JudySL, vous devez passer l'adresse du pointeur plutôt que le pointeur lui-même. Cela conduit souvent à des erreurs de programmation difficiles à déboguer. En pratique, les macros permettent au compilateur de détecter les erreurs de programmation lorsque des pointeurs au lieu d'adresses de pointeurs sont passés.

Les appels de fonction JudySL ont un paramètre supplémentaire au-delà de ceux spécifiés dans les appels de macro. Ce paramètre est soit un pointeur vers une structure d'erreur, soit NULL (auquel cas les informations détaillées sur l'erreur ne sont pas retournées).

Dans les descriptions suivantes, les fonctions sont décrites en termes de la manière dont les macros les utilisent (uniquement dans le cas de #define JUDYERROR_NOTEST 1). C'est l'utilisation suggérée des macros une fois que votre programme est entièrement débogué. Lorsque la macro JUDYERROR_NOTEST n'est pas spécifiée, une structure d'erreur est déclarée pour stocker les informations d'erreur retournées par les fonctions JudySL lorsqu'une erreur se produit.

Remarquez le placement du & dans les différentes fonctions.


JudySLIns(&PJSLArray, Index, &JError)
#define JSLI(PValue, PJSLArray, Index) \
   PValue = JudyLIns(&PJSLArray, Index, PJE0)

JudySLDel(&PJSLArray, Index, &JError)
#define JSLD(Rc_int, PJSLArray, Index) \
   Rc_int = JudySLDel(&PJSLArray, Index, PJE0)

JudySLGet(PJSLArray, Index, &JError)
#define JSLG(PValue, PJSLArray, Index) \
   PValue = JudySLIns(PJSLArray, Index, PJE0)

JudySLFreeArray(&PJSLArray, &JError)
#define JSLFA(Rc_word, PJSLArray) \
   Rc_word = JudySLFreeArray(&PJSLArray, PJE0)

JudySLFirst(PJSLArray, Index, &JError)
#define JSLF(PValue, PJSLArray, Index) \
   PValue = JudySLFirst(PJSLArray, Index, PJE0)

JudySLNext(PJSLArray, Index, &JError)
#define JSLN(PValue, PJSLArray, Index) \
   PValue = JudySLNext(PJSLArray, Index, PJE0)

JudySLLast(PJSLArray, Index, &JError)
#define JSLL(PValue, PJSLArray, Index) \
   PValue = JudySLLast(PJSLArray, Index, PJE0)

JudySLPrev(PJSLArray, Index, &JError)
#define JSLP(PValue, PJSLArray, Index) \
   PValue = JudySLPrev(PJSLArray, Index, PJE0)

Les définitions de toutes les fonctions Judy, les types Pvoid_t, Pcvoid_t, PPvoid_t, Word_t , JError_t, et PJError_t, les constantes NULL, JU_ERRNO_*, JERR, PPJERR, et PJE0 sont fournies dans le fichier d'en-tête Judy.h (/usr/include/Judy.h). Note: Les appelants doivent définir les tableaux JudySL comme étant de type Pvoid_t, qui peut être passé par valeur aux fonctions prenant Pcvoid_t (Pvoid_t constant), et également par adresse aux fonctions prenant PPvoid_t.

Le type de retour de la plupart des fonctions JudySL est PPvoid_t afin que les valeurs stockées dans le tableau puissent être des pointeurs vers d'autres objets, ce qui est un usage typique, ou être transtypées en Word_t * lorsqu'un pointeur vers une valeur est requis au lieu d'un pointeur vers un pointeur.
