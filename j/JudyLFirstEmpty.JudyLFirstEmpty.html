DESCRIPTION

Un équivalent macro existe pour chaque appel de fonction. Étant donné que les formes macro sont parfois plus rapides et ont une interface de gestion des erreurs plus simple que les fonctions équivalentes, elles sont le moyen préféré d'appeler les fonctions JudyL. Voir JudyL(3) pour plus d'informations. Les définitions d'appel de fonction sont incluses ici pour plus de complétude.

Une des difficultés d'utilisation des appels de fonction JudyL réside dans la détermination s'il faut passer un pointeur ou l'adresse d'un pointeur. Étant donné que les fonctions qui modifient le tableau JudyL doivent également modifier le pointeur vers le tableau JudyL, vous devez passer l'adresse du pointeur plutôt que le pointeur lui-même. Cela conduit souvent à des erreurs programmatiques difficiles à déboguer. En pratique, les macros permettent au compilateur de détecter les erreurs de programmation lorsque des pointeurs sont passés au lieu d'adresses de pointeurs.

Les appels de fonction JudyL ont un paramètre supplémentaire au-delà de ceux spécifiés dans les appels de macro. Ce paramètre est soit un pointeur vers une structure d'erreur, soit NULL (auquel cas les informations détaillées sur l'erreur ne sont pas retournées).

Dans les descriptions suivantes, les fonctions sont décrites en termes de la manière dont les macros les utilisent (uniquement dans le cas de #define JUDYERROR_NOTEST 1). C'est l'utilisation suggérée des macros une fois votre programme entièrement débogué. Lorsque la macro JUDYERROR_NOTEST n'est pas spécifiée, une structure d'erreur est déclarée pour stocker les informations d'erreur retournées par les fonctions JudyL en cas d'erreur.

Remarquez le placement du & dans les différentes fonctions.

DESCRIPTION

The Judy array library is a low-level interface to Judy sparse arrays. The library is accessed by C programs which include the Judy.h header file.

All Judy functions return a JudyL status code, which is an integer. A return code of 1 indicates success. Any other return code indicates an error. The error codes are:

-1
Insufficient memory.
-2
An assertion failed. Judy is not implemented correctly.
-3
Invalid argument.
-4
The Judy array is corrupted. This can happen if the array is not accessed by only one thread or if array is accessed after it has been freed.
-5
The Judy array is not implemented correctly.

The Judy array stores Pvoid_t which are pointers to void. These can be passed by value to functions that take Pcvoid_t (constant Pvoid_t), and also by address to functions that take PPvoid_t.

The return type from most JudyL functions is PPvoid_t so that the values stored in the array can be pointers to other objects, which is a typical usage, or cast to a Word_t * when a pointer to a Value is required instead of a pointer to a pointer.
