JudyL(3) Manuel des fonctions de bibliothèque JudyL(3)

NOM

Macros JudyL - Bibliothèque C pour créer et accéder à un tableau dynamique de mots, en utilisant un mot comme index.

SYNTAXE

cc [options] fichiers_source -lJudy
#include <Judy.h>
int      Rc_int;                          // code de retour - entier
Word_t   Rc_word;                         // code de retour - mot non signé
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // pointeur vers la valeur de retour
Pvoid_t PJLArray = (Pvoid_t) NULL;        // initialiser le tableau JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

DESCRIPTION

Un tableau JudyL est l'équivalent d'un tableau de valeurs de la taille d'un mot. Une Valeur est adressée par un Index (clé). Le tableau peut être épars, et l'Index peut être n'importe quel nombre de la taille d'un mot. La mémoire pour supporter le tableau est allouée au fur et à mesure que les paires index/valeur sont insérées, et libérée au fur et à mesure que les paires index/valeur sont supprimées. Un tableau JudyL peut également être considéré comme un mapper, c'est-à-dire qu'il "mappe" un mot à un autre mot/pointeur.

Comme pour un tableau ordinaire, il n'y a pas d'index dupliqués dans un tableau JudyL.

La valeur peut être utilisée comme un scalaire, ou un pointeur vers une structure ou un bloc de données (ou même un autre tableau Judy).

Un tableau JudyL est alloué avec un pointeur NULL

Pvoid_t PJLArray = (Pvoid_t) NULL;

En utilisant les macros décrites ici, plutôt que les appels de fonction JudyL, la gestion d'erreur par défaut envoie un message à l'erreur standard et termine le programme avec exit(1);. Pour d'autres méthodes de gestion d'erreur, voir la section ERREURS. JLI( PValue, PJLArray, Index); // JudyLIns()

Parce que les formes macro sont parfois plus rapides et ont une interface de gestion d'erreur plus simple que les fonctions JudyL équivalentes, elles sont la manière préférée d'appeler les fonctions JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
Insère un Index et une Valeur dans le tableau JudyL PJLArray. Si l'Index est inséré avec succès, la Valeur est initialisée à 0. Si l'Index était déjà présent, la Valeur n'est pas modifiée.
Retourne PValue pointant vers la Valeur. Votre programme peut utiliser ce pointeur pour lire ou modifier la Valeur jusqu'à la prochaine exécution de JLI() (insertion), JLD() (suppression) ou JLFA() (libération du tableau) sur PJLArray. Exemples :
*PValue = 1234;
Valeur = *PValue;
Retourne PValue défini à PJERR si une erreur malloc() s'est produite. Remarque : JLI() et JLD() réorganisent le tableau JudyL. Par conséquent, PValue retourné par des appels JudyL précédents devient invalide et doit être réacquis.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
Supprime la paire Index/Valeur du tableau JudyL.
Retourne Rc_int défini à 1 si succès. Retourne Rc_int défini à 0 si l'Index n'était pas présent. Retourne Rc_int défini à JERR si une erreur malloc() s'est produite.

JLG(PValue, PJLArray, Index) // JudyLGet()
Obtient le pointeur PValue associé à l'Index dans le tableau Judy PJLArray.
Retourne PValue pointant vers la Valeur. Retourne PValue défini à NULL si l'Index n'était pas présent. Retourne PValue défini à PJERR si une erreur malloc() s'est produite.

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
Compte le nombre d'index présents dans le tableau JudyL PJLArray entre Index1 et Index2 (inclus).
Retourne Rc_word défini au nombre d'éléments. Une valeur de retour de 0 peut être valide en tant que compte.
Pour compter tous les index présents dans un tableau JudyL, utilisez :
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
Localise le N-ième index présent dans le tableau JudyL PJLArray (N-ième = 1 retourne le premier index présent).
Retourne PValue pointant vers sa Valeur et Index défini à le N-ième index si trouvé, sinon retourne PValue défini à NULL (la valeur de Index est indéfinie).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
Étant donné un pointeur vers un tableau JudyL, libère tout le tableau (beaucoup plus rapide que d'utiliser une boucle JLN(), JLD()).
Retourne Rc_word défini au nombre d'octets libérés et PJLArray défini à NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
Retourne Rc_word défini au nombre d'octets de mémoire malloc()'és par PJLArray. Ceci est une routine très rapide et peut être utilisée avant et après un appel JLI() ou JLD() avec peu d'impact sur les performances.

Fonctions de recherche JudyL
JLF(), JLN(), JLL(), JLP() vous permettent de rechercher des index dans le tableau. Vous pouvez rechercher inclusivement ou exclusivement, dans les directions avant ou arrière. En cas de succès, Index est retourné défini à l'index trouvé, et PValue est retourné défini à un pointeur vers la Valeur de l'Index. En cas d'échec, PValue est retourné défini à NULL, et Index ne contient aucune information utile. PValue doit être testé comme non-NULL avant d'utiliser Index, car un échec de recherche est possible.
JLFE(), JLNE(), JLLE(), JLPE() vous permettent de rechercher des index qui ne sont pas présents ("vides") dans le tableau. Vous pouvez rechercher inclusivement ou exclusivement, dans les directions avant ou arrière. En cas de succès, Index est retourné défini à un index non présent ("vide"), et Rc_int est retourné défini à 1. En cas d'échec, Rc_int est retourné défini à 0, et Index ne contient aucune information utile. Rc_int doit être vérifié avant d'utiliser Index, car un échec de recherche est possible.

JLF(PValue, PJLArray, Index) // JudyLFirst()
Recherche (inclusivement) le premier index présent qui est égal ou supérieur à l'Index passé. (Commencez avec Index = 0 pour trouver le premier index dans le tableau.) JLF() est généralement utilisé pour *commencer* un parcours en ordre trié des index présents dans un tableau JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
Recherche (exclusivement) le prochain index présent qui est supérieur à l'Index passé. JLN() est généralement utilisé pour *continuer* un parcours en ordre trié des index présents dans un tableau JudyL, ou pour localiser un "voisin" d'un index donné.

NOM

JudyL - Tableau JudyL

SYNTAXE

JudyL(PValue, PJLArray, Index) // JudyLPrev()

DESCRIPTION

Les tableaux JudyL sont utilisés pour stocker un pointeur vers la valeur d'un tableau JudyL. Ces tableaux sont efficaces et économes en mémoire, particulièrement lorsqu'il s'agit de données multidimensionnelles dynamiques. Les tableaux JudyL peuvent être utilisés pour créer des arbres ou d'autres structures permettant un accès rapide aux données. Le pointeur Value dans un tableau JudyL est typiquement utilisé pour stocker l'adresse des données, et le drapeau NOT est utilisé pour indiquer que le pointeur ne pointe pas vers un autre tableau JudyL. Le drapeau JLAP_INVALID est stocké dans le(s) bit(s) de poids faible du pointeur. Lorsque le drapeau JLAP_INVALID est retiré, il est utilisé comme pointeur vers les données de l'utilisateur. Le fichier d'en-tête Judy.h définit JLAP_INVALID. Voir fragment de code ci-dessous.

Tableaux JudyL multidimensionnels

Stocker un pointeur vers un autre tableau JudyL dans le champ Value d'un tableau JudyL est un moyen simple de supporter des tableaux multidimensionnels dynamiques. Ces tableaux (ou arbres) construits à l'aide de tableaux JudyL sont très rapides et économes en mémoire. (En fait, c'est ainsi que JudySL et JudyHS sont implémentés). Un nombre arbitraire de dimensions peut être réalisé de cette manière. Pour terminer le nombre de dimensions (ou l'arbre), le pointeur Value est marqué pour NE PAS pointer vers un autre tableau Judy. Un drapeau JLAP_INVALID est utilisé dans le(s) bit(s) de poids faible du pointeur. Après avoir retiré le drapeau JLAP_INVALID, il est utilisé comme pointeur vers les données de l'utilisateur. Le fichier d'en-tête Judy.h définit JLAP_INVALID. Voir fragment de code ci-dessous.

EXEMPLE

Lire une série de paires index/valeur depuis l'entrée standard, les stocker dans un tableau JudyL, puis les imprimer par ordre trié.

#include <stdio.h>
#include <Judy.h>
Word_t   Index;                     // index du tableau
Word_t   Value;                     // valeur de l'élément du tableau
Word_t * PValue;                    // pointeur vers la valeur de l'élément du tableau
int      Rc_int;                    // code de retour
Pvoid_t  PJLArray = (Pvoid_t) NULL; // initialiser le tableau JudyL
while (scanf("%lu %lu", &Index, &Value))
{
    JLI(PValue, PJLArray, Index);
    If (PValue == PJERR) goto process_malloc_failure;
    *PValue = Value;                 // stocker la nouvelle valeur
}
// Ensuite, parcourir tous les index stockés par ordre trié, d'abord croissant,
// puis décroissant, et supprimer chaque index lors du parcours décroissant.
Index = 0;
JLF(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLN(PValue, PJLArray, Index);
}
Index = -1;
JLL(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLD(Rc_int, PJLArray, Index);
    if (Rc_int == JERR) goto process_malloc_failure;
    JLP(PValue, PJLArray, Index);
}
