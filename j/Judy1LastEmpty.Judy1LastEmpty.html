DESCRIPTIO

N

Une macro équivalente existe pour chaque appel de fonction. Comme les formes de macro sont parfois plus rapides et ont une interface de gestion d'erreurs plus simple que les fonctions équivalentes, elles sont la méthode préférée pour appeler les fonctions Judy1. Voir Judy1(3) pour plus d'informations. Les définitions des appels de fonctions sont incluses ici pour plus de

complétude.

L'une des difficultés lors de l'utilisation des appels de fonctions Judy1 réside dans la détermination de savoir s'il faut passer un pointeur ou l'adresse d'un pointeur. Comme les fonctions qui modifient le tableau Judy1 doivent également modifier le pointeur vers le tableau Judy1, vous devez passer l'adresse du pointeur plutôt que le pointeur lui-même. Cela conduit souvent à des erreurs de programmation difficiles à déboguer. En pratique, les macros permettent au compilateur de détecter les erreurs de programmation lorsque des pointeurs sont passés au lieu d'adresses de

pointeurs.

Les appels de fonctions Judy1 ont un paramètre supplémentaire au-delà de ceux spécifiés dans les appels de macro. Ce paramètre est soit un pointeur vers une structure d'erreur, soit NULL (auquel cas les informations d'erreur détaillées ne sont pas renvoyées)

.

Dans les descriptions suivantes, les fonctions sont décrites en termes de la manière dont les macros les utilisent (uniquement dans le cas #define JUDYERROR_NOTEST 1). C'est l'utilisation recommandée des macros lorsque votre programme a été entièrement débogué. Lorsque la macro JUDYERROR_NOTEST n'est pas spécifiée, une structure d'erreur est déclarée pour stocker les informations d'erreur renvoyées par les fonctions Judy1 lorsqu'une erreur se

produit.

Les définitions de toutes les fonctions Judy, les types Pvoid_t, Pcvoid_t, PPvoid_t, Word_t, JError_t, et PJError_t, les constantes NULL, JU_ERRNO_*, JERR, et PJE0, sont fournies dans le fichier d'en-tête Judy.h (/usr/include/Judy.h). Note : Les appelants doivent définir les tableaux Judy1 comme étant de type Pvoid_t, qui peuvent être passés par valeur aux fonctions qui prennent Pcvoid_t (Pvoid_t constant), et aussi par adresse aux fonctions qui prennent PPvoid_t.
