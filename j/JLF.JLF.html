DESCRIPTIO

N

Un tableau JudyL est l'équivalent d'un tableau de valeurs de la taille d'un mot. Un Valeur est adressée par un Index (clé). Le tableau peut être creux, et l' Index peut être un nombre de n'importe quelle taille de mot. La mémoire nécessaire au tableau est allouée au fur et à mesure que des paires index/valeur sont insérées, et libérée lorsque des paires index/valeur sont supprimées. Un tableau JudyL peut aussi être considéré comme un mapper, c'est-à-dire "mapper" un mot vers un autre

mot/pointeur.

Comme dans un tableau ordinaire, il n'y a pas d'index en double dans un tableau

JudyL.

La valeur peut être utilisée comme un scalaire, ou un pointeur vers une structure ou un bloc de données (ou même un autre tableau Judy)

.

Un tableau JudyL est alloué avec un pointeu

r 
Pvoid_t PJLArray = (Pvoid_t)
NULL;

En utilisant les macros décrites ici, plutôt que les appels de fonction JudyL, la gestion d'erreurs par défaut envoie un message vers la sortie d'erreur standard et termine le programme avec exit(1);. Pour d'autres méthodes de gestion d'erreurs, voir la section ERREURS. JLI( PValue, PJLArray, Index); // JudyLIns(

Fonctions de recherche
JudyL
JLF(), JLN(), JLL(), JLP() vous permettent de rechercher des index dans le tableau. Vous pouvez rechercher de manière inclusive ou exclusive, dans les directions avant ou arrière. Si réussi, Index est retourné défini à l'index trouvé, et PValue est retourné défini à un pointeur vers la Valeur de l'Index. Si non réussi, PValue est retourné défini à NULL, et Index ne contient pas d'information utile. PValue doit être testé pour non-NULL avant d'utiliser Index, car un échec de
recherche e
st possible.
JLFE(), JLNE(), JLLE(), JLPE() vous permettent de rechercher des index qui ne sont pas présents ("vides") dans le tableau. Vous pouvez rechercher de manière inclusive ou exclusive, dans les directions avant ou arrière. Si réussi, Index est retourné défini à un index non présent ("vide"), et Rc_int est retourné défini à 1. Si non réussi, Rc_int est retourné défini à 0, et Index ne contient pas d'information utile. Rc_int doit être vérifié avant d'utiliser Index, car un échec de
recherche e
st possible.

Tableaux JudyL multidimensionnel

s

Stocker un pointeur vers un autre tableau JudyL dans la Value d'un tableau JudyL est un moyen simple de prendre en charge des tableaux multidimensionnels dynamiques. Ces tableaux (ou arbres) construits à l'aide de tableaux JudyL sont très rapides et économiques en mémoire. (En fait, c'est ainsi que JudySL et JudyHS sont implémentés). Un nombre arbitraire de dimensions peut être réalisé de cette manière. Pour terminer le nombre de dimensions (ou l'arbre), le pointeur Value est marqué pour NE PAS pointer vers un autre tableau Judy. Un drapeau JLAP_INVALID est utilisé dans le(s) bit(s) de poids faible du pointeur. Après que le drapeau JLAP_INVALID a été retiré, il est utilisé comme pointeur vers les données de l'utilisateur. Le fichier d'en-tête Judy.h définit JLAP_INVALID. Voir le fragment de code

ci-dessous.

Remarque : La version actuelle de Judy.h a changé ce drapeau de 0x4 à 0x1 pour permettre un malloc() qui ne fournit pas de mémoire sur une limite alignée sur 8 octets (comme les anciennes versions de valgrind)

.

Le segment de code d'exemple suivant peut être utilisé pour déterminer si un pointeur pointe vers un autre JudyL ou non

: 
PValue = (PWord_t)
PMultiDimArray; 
for (Dim = 0; ;Dim++)
{
   if (PValue == (PWord_t)NULL) goto
IndexNotFound; 
   /* Avancer vers la dimension suivante du tableau */
   JLG(PValue, (Pvoid_t)*PValue, Index[Dim])
; 
   /* Vérifier s'il s'agit d'un pointeur vers le tampon de l'utilisateur : */
   if (*PValue & JLAP_INVALID)) break;
}
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // masquer et convertir.
printf("User object pointer is 0x%lx\n", (Word_t) UPointer);

Remarque : Cela fonctionne parce que malloc() garantit de renvoyer un pointeur dont le(s) bit(s) de poids faible == 0x0. Vous devez retirer JLAP_INVALID avant

Lire une série de paires index/valeur depuis l'entrée standard, les stocker dans un tableau JudyL, puis les imprimer dans

#include <stdio.h>
#include <Judy.
h> 
Word_t   Index;                     // index du tableau
Word_t   Value;                     // valeur de l'élément du tableau
Word_t * PValue;                    // pointeur vers la valeur de l'élément du tableau
int      Rc_int;                    // code de
retour 
Pvoid_t  PJLArray = (Pvoid_t) NULL; // initialiser le tableau
JudyL 
while (scanf("%lu %lu", &Index, &Value))
{
    JLI(PValue, PJLArray, Index);
    If (PValue == PJERR) goto process_malloc_failure;
    *PValue = Value;                 // stocker la nouvelle valeur
}
// Ensuite, visiter tous les index stockés dans l'ordre, d'abord
// croissant, puis décroissant, et supprimer chaque index lors du passage
décroissant. 
Index = 0;
JLF(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLN(PValue, PJLArray, Index);
} 
Index = -1;
JLL(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue))
; 
    JLD(Rc_int, PJLArray, Index);
    if (Rc_int == JERR) goto process_malloc_failure
; 
    JLP(PValue, PJLArray, Index);
}
