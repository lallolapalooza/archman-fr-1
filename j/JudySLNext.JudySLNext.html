JudySL_funcs(3) Manuel des fonctions JudySL_funcs(3)

NOM

Fonctions JudySL - Bibliothèque de fonctions pour la création et l'accès à un tableau dynamique, en utilisant un indice nul terminé (tableau associatif)

SYNTHAXE

PPvoid_t JudySLIns(      PPvoid_t PPJSLArray, const uint8_t * Index, PJError_t PJError);
int      JudySLDel(      PPvoid_t PPJSLArray, const uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLGet(      Pcvoid_t  PJSLArray, const uint8_t * Index, PJError_t PJError);
Word_t   JudySLFreeArray(PPvoid_t PPJSLArray, PJError_t PJError);
PPvoid_t JudySLFirst(    Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLNext(     Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLLast(     Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLPrev(     Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);

DESCRIPTION

Il existe un équivalent macro pour chaque appel de fonction. Étant donné que les formes macro peuvent être plus rapides et avoir une interface de gestion des erreurs plus simple que les fonctions équivalentes, elles constituent la méthode préférée pour appeler les fonctions JudySL. Voir JudySL(3) pour plus d'informations. Les définitions des fonctions d'appel sont incluses ici pour plus de complétude.

L'une des difficultés lors de l'utilisation des fonctions JudySL est de déterminer s'il faut passer un pointeur ou l'adresse d'un pointeur. Comme les fonctions qui modifient le tableau JudySL doivent également modifier le pointeur vers le tableau JudySL, vous devez passer l'adresse du pointeur, et non le pointeur lui-même. Cela conduit souvent à des erreurs difficiles à déboguer dans le code programmé. En pratique, les macros permettent aux compilateurs de détecter les erreurs de programmation lorsque des pointeurs sont passés au lieu d'adresses de pointeurs.

Les fonctions JudySL ont un paramètre supplémentaire qui n'est pas spécifié dans les appels de macros. Ce paramètre est un pointeur vers une structure d'erreurs ou NULL (auquel cas aucune information détaillée n'est renvoyée).

Dans les descriptions suivantes, les fonctions sont décrites en termes d'utilisation des macros (uniquement dans le cas de #define JUDYERROR_NOTEST 1). C'est l'utilisation recommandée des macros après que le programme a été entièrement débogué. Lorsque la macro JUDYERROR_NOTEST n'est pas spécifiée, une structure d'erreurs est déclarée qui stocke les informations d'erreur renvoyées par les fonctions JudySL lorsqu'une erreur se produit.

Remarque : L'utilisation de & dans différentes fonctions.


JudySLIns(&PJSLArray, Index, &JError)
#define JSLI(PValue, PJSLArray, Index) \
   PValue = JudyLIns(&PJSLArray, Index, PJE0)

JudySLDel(&PJSLArray, Index, &JError)
#define JSLD(Rc_int, PJSLArray, Index) \
   Rc_int = JudySLDel(&PJSLArray, Index, PJE0)

JudySLGet(PJSLArray, Index, &JError)
#define JSLG(PValue, PJSLArray, Index) \
   PValue = JudySLIns(PJSLArray, Index, PJE0)

JudySLFreeArray(&PJSLArray, &JError)
#define JSLFA(Rc_word, PJSLArray) \
   Rc_word = JudySLFreeArray(&PJSLArray, PJE0)

JudySLFirst(PJSLArray, Index, &JError)
#define JSLF(PValue, PJSLArray, Index) \
   PValue = JudySLFirst(PJSLArray, Index, PJE0)

JudySLNext(PJSLArray, Index, &JError)
#define JSLN(PValue, PJSLArray, Index) \
   PValue = JudySLNext(PJSLArray, Index, PJE0)

JudySLLast(PJSLArray, Index, &JError)
#define JSLL(PValue, PJSLArray, Index) \
   PValue = JudySLLast(PJSLArray, Index, PJE0)

JudySLPrev(PJSLArray, Index, &JError)
#define JSLP(PValue, PJSLArray, Index) \
   PValue = JudySLPrev(PJSLArray, Index, PJE0)

Les définitions pour toutes les fonctions Judy, les types Pvoid_t, Pcvoid_t, PPvoid_t, Word_t , JError_t, et PJError_t, ainsi que les constantes NULL, JU_ERRNO_*, JERR, PPJERR, et PJE0 sont fournies dans le fichier d'en-tête Judy.h (/usr/include/Judy.h). Note : Les appelants doivent définir les tableaux JudySL comme type Pvoid_t, qui peut être passé par valeur aux fonctions acceptant Pcvoid_t (valeur Pvoid_t), et également par adresse aux fonctions acceptant PPvoid_t).

Le type de retour de la plupart des fonctions JudySL est PPvoid_t, de sorte que les valeurs stockées dans le tableau puissent être des pointeurs vers d'autres objets, ce qui est une utilisation typique, ou elles peuvent être converties en Word_t * lorsqu'un pointeur vers une valeur est requis plutôt qu'un pointeur vers un pointeur.
