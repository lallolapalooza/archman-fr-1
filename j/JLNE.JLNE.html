NOM

JudyL - Fonction de bibliothèque pour créer et initialiser un tableau dynamique de mots, utilisant un mot comme index.

SYNOPIS

cc [options] fichiers_source -lJudy
#include <Judy.h>
int      Rc_int;                          // code de retour - entier
Word_t   Rc_word;                         // code de retour - mot entier
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // pointeur vers la valeur retournée
Pvoid_t PJLArray = (Pvoid_t) NULL;        // initialise le tableau JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

DESCRIPTION

Un tableau JudyL est équivalent à un tableau de valeurs de taille mot. Une Valeur est accédée par un Index (clé). Le tableau peut être épars, et l'Index peut être n'importe quel nombre de taille mot. L'espace mémoire requis pour le tableau est alloué au fur et à mesure que les paires index/valeur sont insérées, et est libéré lorsqu'elles sont supprimées. Un tableau JudyL peut aussi être vu comme un mapper, c'est-à-dire « mapper » un mot à un autre mot/indicateur.

Comme pour un tableau ordinaire, il n'y a pas d'index dupliqués dans un tableau JudyL.

La valeur peut être utilisée comme un scalaire, ou comme un pointeur vers une structure ou un bloc de données (ou même un autre tableau JudyL).

Le tableau JudyL est alloué avec un pointeur NULL.

Pvoid_t PJLArray = (Pvoid_t) NULL;

En utilisant les macros décrites ici, plutôt que les fonctions JudyL, la gestion des erreurs par défaut envoie un message à stderr et termine le programme avec exit(1);. Pour d'autres méthodes de gestion des erreurs, voir la section ERREURS. JLI( PValue, PJLArray, Index); // JudyLIns()

Étant donné que les formulaires de macros sont souvent plus rapides et ont une interface de gestion des erreurs plus simple que les fonctions JudyL équivalentes, ils constituent la méthode préférée pour appeler les fonctions JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
Insertion d'un Index et d'une Valeur dans le tableau JudyL PJLArray. Si l'Index est inséré avec succès, la Valeur est initialisée à 0. Si l'Index existait déjà, la Valeur n'est pas modifiée.
Retourne un PValue pointant vers la Valeur. Votre programme peut utiliser ce pointeur pour lire ou modifier la Valeur jusqu'à ce que le prochain JLI() (insertion), JLD() (suppression) ou JLFA() (libération de tableau) sur PJLArray soit exécuté. Exemples :
*PValue = 1234;
Retourne PValue pointant vers PJERR en cas d'échec de malloc(). Note : JLI() et JLD() réorganisent le tableau JudyL. Par conséquent, le PValue retourné par les appels précédents à JudyL devient invalide et doit être réacquis.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
Supprime la paire Index/Valeur du tableau JudyL.
Retourne Rc_int à 1 en cas de succès. Retourne Rc_int à 0 si l'Index n'existait pas. Retourne Rc_int à JERR en cas d'échec de malloc().

JLG(PValue, PJLArray, Index) // JudyLGet()
Retourne le pointeur PValue associé à l'Index dans le tableau JudyL PJLArray.
Retourne PValue pointant vers la Valeur. Retourne PValue à NULL si l'Index n'existait pas. Retourne PValue à PJERR en cas d'échec de malloc().

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
Compte le nombre d'index présents dans le tableau JudyL PJLArray entre Index1 et Index2 (inclus).
Retourne Rc_word comme nombre d'index. Une valeur de retour de 0 peut être valide comme comptage.
Pour compter tous les index dans un tableau JudyL, utilisez :
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
Localise le Nème index présent dans le tableau JudyL PJLArray (Nth = 1 retourne le premier index présent).
Retourne PValue pointant vers sa Valeur et Index défini au Nème index s'il est trouvé, sinon retourne PValue à NULL (la valeur de Index est indéfinie).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
Étant donné un pointeur vers un tableau JudyL, libère le tableau entier (plus rapide que d'utiliser JLN(), JLD() dans une boucle).
Retourne Rc_word comme nombre d'octets libérés et PJLArray à NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
Retourne Rc_word comme nombre d'octets mémoire malloc() utilisés par PJLArray. Il s'agit d'une routine très rapide, et elle peut être utilisée avant et après un appel à JLI() ou JLD() avec peu d'impact sur les performances.

Fonctions de recherche JudyL
JLF(), JLN(), JLL(), JLP() permettent de rechercher des index dans le tableau. Vous pouvez rechercher inclusivement ou exclusivement dans les directions avant ou arrière. En cas de succès, Index est retourné avec la valeur trouvée, et PValue pointe vers un indicateur de la valeur de l'Index de la Valeur. En cas d'échec, PValue est retourné à NULL, et Index ne contient aucune information utile. PValue doit être vérifié comme étant non NULL avant d'utiliser Index, car un échec de recherche est possible.
JLFE(), JLNE(), JLLE(), JLPE() permettent de rechercher des index inexistants (« vides ») dans le tableau. Vous pouvez rechercher inclusivement ou exclusivement dans les directions avant ou arrière. En cas de succès, Index est retourné avec un index inexistant (« vide »), et Rc_int est retourné à 1. En cas d'échec, Rc_int est retourné à 0, et Index ne contient aucune information utile. Rc_int doit être vérifié avant d'utiliser Index, car un échec de recherche est possible.

JLF(PValue, PJLArray, Index) // JudyLFirst()
Recherche (inclusivement) le premier index présent qui est égal ou supérieur à l'index donné. (Commencez avec Index = 0 pour trouver le premier index dans le tableau.) JLF() est typiquement utilisé pour commencer un balayage dans l'ordre croissant des index présents dans un tableau JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
Recherche (exclusivement) le prochain index présent qui est supérieur à l'index donné. JLN() est typiquement utilisé pour continuer un balayage dans l'ordre croissant des index présents dans un tableau JudyL, ou pour localiser un « voisin » d'un index donné.

JLL(PValue, PJLArray, Index) // JudyLLast()
Recherche (inclusivement) le dernier index présent qui est égal ou inférieur à l'index donné. (Commencez avec Index = 0 pour trouver le dernier index dans le tableau.) JLL() est typiquement utilisé pour commencer un balayage dans l'ordre décroissant des index présents dans un tableau JudyL.

JLP(PValue, PJLArray, Index) // JudyLPrev()
Recherche (exclusivement) l'index précédent présent qui est inférieur à l'index donné. JLP() est typiquement utilisé pour localiser un « voisin » d'un index donné.

Tableaux JudyL multidimensionnels

Stocker un pointeur vers un autre tableau JudyL dans la valeur d'un tableau JudyL est une méthode simple pour prendre en charge des tableaux JudyL multidimensionnels dynamiques. Ces tableaux (ou arbres) construits à partir de tableaux JudyL sont très rapides et efficaces en mémoire. (C'est d'ailleurs ainsi que JudySL et JudyHS sont implémentés). N'importe quel nombre de dimensions peut être réalisé de cette manière. Pour terminer le nombre de dimensions (ou l'arbre), le pointeur de valeur est marqué pour ne pas pointer vers un autre tableau JudyL. Le JLAP_INVALID est utilisé dans le bit le moins significatif d'un tel pointeur. Après avoir retiré le JLAP_INVALID, il est utilisé comme pointeur vers les données de l'utilisateur. Le fichier Judy.h définit JLAP_INVALID. Voir le fragment de code ci-dessous.

Remarque: le changement actuel dans le fichier Judy.h de ce drapeau de 0x4 à 0x1 permet un malloc() qui ne renvoie pas de mémoire alignée sur une limite de 8 octets (comme dans les anciennes versions de valgrind).

L'exemple de code suivant peut être utilisé pour déterminer si un pointeur pointe vers un autre tableau JudyL:

PValue = (PWord_t) PMultiDimArray;
for (Dim = 0; ;Dim++)
   if (PValue == (PWord_t)NULL) goto IndexNotFound;
   /* Aller à la dimension suivante du tableau */
   JLG(PValue, (Pvoid_t)*PValue, Index[Dim]);
   /* Vérifier si le pointeur pointe vers un buffer utilisateur */
   if (*PValue & JLAP_INVALID) break;
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // masque et conversion.
printf("Pointeur objet utilisateur est 0x%lx\n", (Word_t) UPointer);

Remarque: cela fonctionne car malloc() garantit de retourner un pointeur avec les bits les moins significatifs == 0x0. Vous devez supprimer JLAP_INVALID avant d'utiliser le pointeur.

ERREURS

EXEMPLE

Lit une série de paires index/valeur à partir de l'entrée standard, les stocke dans un tableau JudyL, puis les imprime dans l'ordre trié.

#include <stdio.h>
#include <Judy.h>
Word_t   Index;                     // indice du tableau
Word_t   Value;                     // valeur de l'élément du tableau
Word_t * PValue;                    // pointeur vers la valeur de l'élément du tableau
int      Rc_int;                    // code de retour
Pvoid_t  PJLArray = (Pvoid_t) NULL; // initialiser le tableau JudyL
while (scanf("%lu %lu", &Index, &Value))
    JLI(PValue, PJLArray, Index);
    if (PValue == PJERR) goto process_malloc_failure;
    *PValue = Value;                 // stocker la nouvelle valeur
    JLF(PValue, PJLArray, Index);
    while (PValue != NULL)
        printf("%lu %lu\n", Index, *PValue));
        JLN(PValue, PJLArray, Index);
    JLL(PValue, PJLArray, Index);
    while (PValue != NULL)
        printf("%lu %lu\n", Index, *PValue));
        JLD(Rc_int, PJLArray, Index);
        if (Rc_int == JERR) goto process_malloc_failure;
        JLP(PValue, PJLArray, Index);
