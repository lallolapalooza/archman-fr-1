DESCRIPTIO

N

Un tableau Judy1 est l'équivalent d'un tableau de bits ou d'une carte de bits. Un bit est adressé par un Index (clé). Le tableau peut être creux, et l' Index peut être n'importe quelle Valeur de la taille d'un mot. Si un index est présent, il représente un bit défini (un bit défini représente un index présent). Si un index est absent, il représente un bit non défini (un bit non défini représente un index absent)

.

Un tableau Judy1 est alloué avec un pointeur

NULL 
Pvoid_t PJ1Array = (Pvoid_t) NULL;
La mémoire
nécessaire au support du tableau est allouée lorsque les bits sont définis, et libérée lorsque les bits sont non définis. Si le pointeur Judy1 (PJ1Array) est NULL, tous les bits sont non définis (et le tableau Judy1 ne nécessite aucune mémoire).

Comme pour un tableau ordinaire, un tableau Judy1 ne contient pas d'index en

double.

En utilisant les macros décrites ici, plutôt que les appels de fonction Judy1, la gestion d'erreur par défaut envoie un message vers la sortie d'erreur standard et termine le programme avec exit(1). Pour d'autres méthodes de gestion d'erreur, voir la section ERREURS

.

Parce que les formes de macro sont parfois plus rapides et ont une interface de gestion d'erreur plus simple que les fonctions équivalentes, elles sont la manière préférée d'appeler les fonctions

Judy1.

Fonctions de recherche
Judy1
Les fonctions de recherche Judy1 vous permettent de rechercher des bits définis ou non définis dans le tableau. Vous pouvez rechercher inclusivement ou exclusivement, dans les sens direct ou inverse. Toutes les fonctions de recherche utilisent une séquence d'appel similaire. Rc_int est retourné défini à 1 pour une recherche réussie et l' Index trouvé est retourné. Rc_int est retourné défini à 0 pour une recherche infructueuse, et Index ne contient aucune information utile. Le code de retour Rc_int doit être vérifié avant d'utiliser l' Index retourné, car un échec de recherche est
possible.

()

Judy1.
