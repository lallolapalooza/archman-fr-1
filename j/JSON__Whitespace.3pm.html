NOM

JSON::Whitespace - Modifier l'espace blanc insignifiant du JSON

SYNOPSIS

use JSON::Whitespace ':all';

my $in = <<EOF;
{
            "animals":{
                    "kingkong":"🦍"
            },
            "baka":[
                    "ドジ"
            ],
            "fruit":{
                    "grape":"🍇"
            },
            "moons":{
                    "🌑":0
            }
    }
EOF
my $minify = json_minify ($in);
print $minify;

Ceci affiche

{"animals":{"kingkong":"🦍"},"baka":["ドジ"],"fruit":{"grape":"🍇"},"moons":{"🌑":0}}

VERSION

Ce document décrit la version 0.62 de JSON::Whitespace correspondant au commit git d04630086f6c92fea720cba4568faa0cbbdde5a6 https://github.com/benkasminbullock/JSON-Parse/commit/d04630086f6c92fea720cba4568faa0cbbdde5a6 publiée le sam 16 juil. 08:23:13 2022 +0900.

DESCRIPTION

Ce module offre des fonctions pour manipuler la partie "espace blanc insignifiant" d'une chaîne JSON (l'espace blanc qui n'est pas à l'intérieur des chaînes). Selon la spécification JSON, l'espace blanc "insignifiant" comprend l'espace (%x20), la tabulation horizontale (%x09), le saut de ligne ou nouvelle ligne (%x0A) et le retour chariot (%x0D).

FONCTIONS

json_indent

my $indented = json_indent ($json);

Ajoute de l'indentation à $json.

json_minify

my $minified = json_minify ($json);

Supprime tout l'espace blanc, y compris les nouvelles lignes finales, de $json.

VOIR AUSSI

La documentation sur JSON se trouve dans JSON::Parse. JSON::Whitespace est basé sur JSON::Tokenize, qui divise le JSON en jetons sans le convertir en structures Perl.
