JudyL(3) Manuel des fonctions de bibliothèque JudyL(3)

NOM

Macros JudyL - Bibliothèque C pour créer et accéder à un tableau dynamique de mots, en utilisant un mot comme indice.

SYNTAXE

cc [flags] fichiers_source -lJudy
#include <Judy.h>
int      Rc_int;                          // code de retour - entier
Word_t   Rc_word;                         // code de retour - mot non signé
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // pointeur vers la valeur de retour
Pvoid_t PJLArray = (Pvoid_t) NULL;        // initialiser le tableau JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

DESCRIPTION

Un tableau JudyL est l'équivalent d'un tableau de valeurs de taille mot. Une Valeur est adressée par un Indice (clé). Le tableau peut être sparse, et l'Indice peut être n'importe quel nombre de taille mot. La mémoire pour supporter le tableau est allouée au fur et à mesure que les paires indice/valeur sont insérées, et libérée au fur et à mesure qu'elles sont supprimées. Un tableau JudyL peut également être considéré comme un mappeur, c'est-à-dire qu'il "mappe" un mot vers un autre mot/pointeur.

Comme avec un tableau ordinaire, il n'y a pas d'indices dupliqués dans un tableau JudyL.

La valeur peut être utilisée comme un scalaire, ou comme un pointeur vers une structure ou un bloc de données (ou même un autre tableau Judy).

Un tableau JudyL est alloué avec un pointeur NULL

Pvoid_t PJLArray = (Pvoid_t) NULL;

En utilisant les macros décrites ici, plutôt que les appels de fonction JudyL, la gestion d'erreurs par défaut envoie un message à la sortie d'erreur standard et termine le programme avec exit(1);. Pour d'autres méthodes de gestion des erreurs, voir la section ERREURS. JLI( PValue, PJLArray, Index); // JudyLIns()

Étant donné que les formes de macros sont parfois plus rapides et ont une interface de gestion d'erreurs plus simple que les fonctions JudyL équivalentes, elles sont la méthode préférée pour appeler les fonctions JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
Insère un Indice et une Valeur dans le tableau JudyL PJLArray. Si l'Indice est inséré avec succès, la Valeur est initialisée à 0. Si l'Indice était déjà présent, la Valeur n'est pas modifiée.
Retourne PValue pointant vers la Valeur. Votre programme peut utiliser ce pointeur pour lire ou modifier la Valeur jusqu'à ce que le prochain appel JLI() (insertion), JLD() (suppression) ou JLFA() (libération de tableau) soit exécuté sur PJLArray. Exemples :
*PValue = 1234;
Valeur = *PValue;
Retourne PValue défini à PJERR si une erreur malloc() s'est produite. Note : JLI() et JLD() réorganisent le tableau JudyL. Par conséquent, PValue retourné par des appels précédents de JudyL devient invalide et doit être réacquis.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
Supprime la paire Indice/Valeur du tableau JudyL.
Retourne Rc_int défini à 1 si l'opération a réussi. Retourne Rc_int défini à 0 si l'Indice n'était pas présent. Retourne Rc_int défini à JERR si une erreur malloc() s'est produite.

JLG(PValue, PJLArray, Index) // JudyLGet()
Récupère le pointeur PValue associé à l'Indice dans le tableau Judy PJLArray.
Retourne PValue pointant vers la Valeur. Retourne PValue défini à NULL si l'Indice n'était pas présent. Retourne PValue défini à PJERR si une erreur malloc() s'est produite.

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
Compte le nombre d'indices présents dans le tableau JudyL PJLArray entre Index1 et Index2 (inclus).
Retourne Rc_word défini au nombre. Une valeur de retour de 0 peut être valide en tant que compte.
Pour compter tous les indices présents dans un tableau JudyL, utilisez :
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
Localise le N-ième indice présent dans le tableau JudyL PJLArray (Nth = 1 retourne le premier indice présent).
Retourne PValue pointant vers sa Valeur et Index défini au N-ième indice s'il est trouvé, sinon retourne PValue défini à NULL (la valeur de Index est indéfinie).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
Étant donné un pointeur vers un tableau JudyL, libère l'ensemble du tableau (beaucoup plus rapide que d'utiliser une boucle JLN(), JLD()).
Retourne Rc_word défini au nombre d'octets libérés et PJLArray défini à NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
Retourne Rc_word défini au nombre d'octets mémoire malloc()'és par PJLArray. C'est une routine très rapide, et peut être utilisée avant et après un appel JLI() ou JLD() avec peu d'impact sur les performances.

Fonctions de recherche JudyL
JLF(), JLN(), JLL(), JLP() permettent de rechercher des indices dans le tableau. Vous pouvez rechercher de manière inclusive ou exclusive, dans les directions avant ou arrière. En cas de succès, Index est retourné défini à l'indice trouvé, et PValue est retourné défini à un pointeur vers la Valeur de l'Indice. En cas d'échec, PValue est retourné défini à NULL, et Index ne contient aucune information utile. PValue doit être testé pour s'assurer qu'il n'est pas NULL avant d'utiliser Index, car un échec de recherche est possible.
JLFE(), JLNE(), JLLE(), JLPE() permettent de rechercher des indices qui ne sont pas présents ("vides") dans le tableau. Vous pouvez rechercher de manière inclusive ou exclusive, dans les directions avant ou arrière. En cas de succès, Index est retourné défini à un indice non présent ("vide"), et Rc_int est retourné défini à 1. En cas d'échec, Rc_int est retourné défini à 0, et Index ne contient aucune information utile. Rc_int doit être vérifié avant d'utiliser Index, car un échec de recherche est possible.

JLF(PValue, PJLArray, Index) // JudyLFirst()
Recherche (inclusive) le premier indice présent égal ou supérieur à l'Index passé. (Commencez avec Index = 0 pour trouver le premier indice du tableau.) JLF() est généralement utilisé pour *commencer* un balayage par ordre trié des indices présents dans un tableau JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
Recherche (exclusive) le prochain indice présent supérieur à l'Index passé. JLN() est généralement utilisé pour *continuer* un balayage par ordre trié des indices présents dans un tableau JudyL, ou pour localiser un "voisin" d'un indice donné.

NOM

JudyLLast(), JudyLPrev(), JudyLLastEmpty(), JudyLNextEmpty(), JudyLFirstEmpty(), JudyLPrevEmpty(), JudyLP(), JudyJ(), JudyJL(), JudyJLP(), JudyJLE(), JudyJPE()

SYNOPIS

JudyLLast(PValue, PJLArray, Index) // JudyLPrev()

JudyLPrev(PValue, PJLArray, Index) // JudyLLastEmpty()

JudyLFirstEmpty(PValue, PJLArray, Index) // JudyLNextEmpty()

JudyLPrevEmpty(PValue, PJLArray, Index) // JudyJLP()

JudyJ(PValue, PJLArray, Index) // JudyJLE()

JudyJLP(PValue, PJLArray, Index) // JudyJPE()

JudyJLE(PValue, PJLArray, Index) // JudyJLP()

JudyJPE(PValue, PJLArray, Index) // JudyJ()

DESCRIPTION

JudyLLast() recherche (inclusivement) le dernier index présent qui est égal ou inférieur à l'Index passé. (Commencer avec Index = -1, c'est-à-dire tous les uns, pour trouver le dernier index dans le tableau.) JudyLLastEmpty() est typiquement utilisé pour commencer un parcours des index présents dans un tableau JudyL dans l'ordre inverse trié. JudyLPrev() est typiquement utilisé pour continuer un parcours des index présents dans un tableau JudyL dans l'ordre inverse trié, ou pour localiser un "voisin" d'un index donné. JudyLFirstEmpty() recherche (inclusivement) le premier index absent qui est égal ou supérieur à l'Index passé. (Commencer avec Index = 0 pour trouver le premier index absent dans le tableau.) JudyLNextEmpty() recherche (exclusivement) le prochain index absent qui est supérieur à l'Index passé. JudyLPrevEmpty() recherche (exclusivement) l'index absent précédent qui est inférieur à l'Index passé.

Tableaux JudyL Multi-dimensionnels

Stocker un pointeur vers un autre tableau JudyL dans la Valeur d'un tableau JudyL est un moyen simple de supporter des tableaux multi-dimensionnels dynamiques. Ces tableaux (ou arbres) construits en utilisant des tableaux JudyL sont très rapides et économes en mémoire. (En fait, c'est ainsi que JudySL et JudyHS sont implémentés). Un nombre arbitraire de dimensions peut être réalisé de cette manière. Pour terminer le nombre de dimensions (ou l'arbre), le pointeur Valeur est marqué pour NE PAS pointer vers un autre tableau Judy. Un indicateur JLAP_INVALID est utilisé dans le(s) bit(s) le moins significatif(s) du pointeur. Après que l'indicateur JLAP_INVALID soit retiré, il est utilisé comme un pointeur vers les données de l'utilisateur. Le fichier d'en-tête Judy.h définit JLAP_INVALID. Voir le fragment de code ci-dessous.

Note: La version actuelle de Judy.h a changé cet indicateur de 0x4 à 0x1 pour permettre un malloc() qui ne délivre pas de mémoire sur une limite alignée de 8 octets (comme les anciennes versions de valgrind).

Le segment de code d'exemple suivant peut être utilisé pour déterminer si un pointeur pointe ou non vers un autre JudyL :

PValue = (PWord_t)PMultiDimArray;
for (Dim = 0; ;Dim++)
{
   if (PValue == (PWord_t)NULL) goto IndexNotFound;
   /* Avancer à la prochaine dimension dans le tableau */
   JLG(PValue, (Pvoid_t)*PValue, Index[Dim]);
   /* Vérifier si le pointeur vers le tampon utilisateur : */
   if (*PValue & JLAP_INVALID)) break;
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // masquer et caster.
printf("Le pointeur de l'objet utilisateur est 0x%lx\n", (Word_t) UPointer);

Note: Cela fonctionne car malloc() garantit de retourner un pointeur avec le(s) bit(s) le moins significatif(s) == 0x0. Vous devez retirer JLAP_INVALID avant d'utiliser le pointeur.

ERREURS

EXEMPLE

Lire une série de paires index/valeur depuis l'entrée standard, les stocker dans un tableau JudyL, puis les imprimer par ordre trié.

#include <stdio.h>
#include <Judy.h>
Word_t   Index;                     // index du tableau
Word_t   Value;                     // valeur de l'élément du tableau
Word_t * PValue;                    // pointeur vers la valeur de l'élément du tableau
int      Rc_int;                    // code de retour
Pvoid_t  PJLArray = (Pvoid_t) NULL; // initialiser le tableau JudyL
while (scanf("%lu %lu", &Index, &Value))
{
JLI(PValue, PJLArray, Index);
If (PValue == PJERR) goto process_malloc_failure;
*PValue = Value;                 // stocker la nouvelle valeur
}
Index = 0;
JLF(PValue, PJLArray, Index);
while (PValue != NULL)
{
printf("%lu %lu\n", Index, *PValue));
JLN(PValue, PJLArray, Index);
}
Index = -1;
JLL(PValue, PJLArray, Index);
while (PValue != NULL)
{
printf("%lu %lu\n", Index, *PValue));
JLD(Rc_int, PJLArray, Index);
if (Rc_int == JERR) goto process_malloc_failure;
JLP(PValue, PJLArray, Index);
}
