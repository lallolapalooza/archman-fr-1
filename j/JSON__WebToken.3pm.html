JSON::WebToken(3pm) Documentation Perl contribuée par les utilisateurs JSON::WebToken(3pm)

NOM

JSON::WebToken - implémentation de JSON Web Token (JWT)

SYNOPSIS

use Test::More;
use JSON;
use JSON::WebToken;
my $claims = {
    iss => 'joe',
    exp => 1300819380,
    'http://example.com/is_root' => JSON::true,
};
my $secret = 'secret';
my $jwt = encode_jwt $claims, $secret;
my $got = decode_jwt $jwt, $secret;
is_deeply $got, $claims;
done_testing;

DESCRIPTION

JSON::WebToken est une implémentation de JSON Web Token (JWT) pour Perl

CE MODULE EST À NIVEAU D'INTERFACE ALPHA.

MÉTHODES

encode($claims [, $secret, $algorithm, $extra_headers ]) : String

Cette méthode encode un JWT à partir d'une référence de hachage.

my $jwt = JSON::WebToken->encode({
    iss => 'joe',
    exp => 1300819380,
    'http://example.com/is_root' => JSON::true,
}, 'secret');
# $jwt = join '.',
#     'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9',
#     'eyJleHAiOjEzMDA4MTkzODAsImh0dHA6Ly9leGFtcGxlLmNvbS9pc19yb290Ijp0cnVlLCJpc3MiOiJqb2UifQ'
#     '4ldFxjibgJGz_uaIRCIq89b5ipR-sbI2Uq7B2WNEDs0'

L'algorithme de chiffrement par défaut est "HS256". Vous pouvez changer l'algorithme comme suit :

my $pricate_key_string = '...';
my $public_key_string  = '...';
my $jwt = JSON::WebToken->encode({
    iss => 'joe',
    exp => 1300819380,
    'http://example.com/is_root' => JSON::true,
}, $pricate_key_string, 'RS256');
my $claims = JSON::WebToken->decode($jwt, $public_key_string);

Lorsque vous utilisez l'algorithme RS256, RS384 ou RS512, nous avons besoin de Crypt::OpenSSL::RSA.

Si vous souhaitez créer un "JWT en clair", vous devez spécifier "none" pour l'algorithme.

my $jwt = JSON::WebToken->encode({
    iss => 'joe',
    exp => 1300819380,
    'http://example.com/is_root' => JSON::true,
}, '', 'none');
# $jwt = join '.',
#     'eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0',
#     'eyJleHAiOjEzMDA4MTkzODAsImh0dHA6Ly9leGFtcGxlLmNvbS9pc19yb290Ijp0cnVlLCJpc3MiOiJqb2UifQ',
#     ''

decode($jwt [, $secret, $verify_signature, $accepted_algorithms ]) : HASH

Cette méthode décode une référence de hachage à partir d'une chaîne JWT.

my $claims = JSON::WebToken->decode($jwt, $secret, 1, ["RS256"]);

Tout algorithme de signature (sauf "none") est acceptable par défaut, vous devriez donc le vérifier avec le paramètre $accepted_algorithms .

add_signing_algorithm($algorithm, $class)

Cette méthode ajoute un algorithme de signature.

# resolve JSON::WebToken::Crypt::MYALG
JSON::WebToken->add_signing_algorithm('MYALGXXX'   => 'MYALG');
# resolve Some::Class::Algorithm
JSON::WebToken->add_signing_algorithm('SOMEALGXXX' => '+Some::Class::Algorithm');

VOIR AUSSI JSON::WebToken::Crypt::HMAC ou JSON::WebToken::Crypt::RAS.

FONCTIONS

encode_jwt($claims [, $secret, $algorithm, $extra_headers ]) : String

Identique à la méthode encode() .

decode_jwt($jwt [, $secret, $verify_signature, $accepted_algorithms ]) : Hash

Identique à la méthode decode() .

CODES D'ERREUR

JSON::WebToken::Exception sera levée avec le code suivant.

ERROR_JWT_INVALID_PARAMETER

Lorsque certains arguments de méthode ne sont pas valides.

ERROR_JWT_MISSING_SECRET

Lorsque le secret est requis. ("alg != "none"")

ERROR_JWT_INVALID_SEGMENT_COUNT

Lorsque le nombre de segments du JWT n'est pas compris entre 2 et 4.

ERROR_JWT_INVALID_SEGMENT_ENCODING

Lorsque chaque segment du JWT n'est pas encodé en base64url.

ERROR_JWT_UNWANTED_SIGNATURE

Lorsque "alg == "none"" mais qu'un segment de signature a été trouvé.

ERROR_JWT_INVALID_SIGNATURE

Lorsque la signature du JWT est invalide.

ERROR_JWT_NOT_SUPPORTED_SIGNING_ALGORITHM

Lorsque l'algorithme de signature donné n'est pas pris en charge.

ERROR_JWT_UNACCEPTABLE_ALGORITHM

Lorsque l'algorithme de signature donné n'est pas inclus dans acceptable_algorithms.
