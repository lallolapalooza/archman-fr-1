JudySL(3) Manuel des fonctions de bibliothèque JudySL(3)

NOM

Macros JudySL - Bibliothèque C pour créer et accéder à un tableau dynamique, en utilisant une chaîne de caractères terminée par un caractère nul comme Index (tableau associatif)

SYNOPSIS

cc [flags] fichiers_source -lJudy
#include <Judy.h>
#define MAXLINELEN 1000000           // définir la longueur maximale de la chaîne
Word_t * PValue;                     // élément du tableau JudySL
uint8_t  Index[MAXLINELEN];          // chaîne
int      Rc_int;                     // valeur de retour
Word_t   Rc_word;                    // retour complet du mot
Pvoid_t PJSLArray = (Pvoid_t) NULL;  // initialiser le tableau JudySL
JSLI( PValue,  PJSLArray, Index);   // JudySLIns()
JSLD( Rc_int,  PJSLArray, Index);   // JudySLDel()
JSLG( PValue,  PJSLArray, Index);   // JudySLGet()
JSLFA(Rc_word, PJSLArray);          // JudySLFreeArray()
JSLF( PValue,  PJSLArray, Index);   // JudySLFirst()
JSLN( PValue,  PJSLArray, Index);   // JudySLNext()
JSLL( PValue,  PJSLArray, Index);   // JudySLLast()
JSLP( PValue,  PJSLArray, Index);   // JudySLPrev()

DESCRIPTION

Un tableau JudySL est l'équivalent d'un ensemble trié de chaînes de caractères, chacune associée à une Value (mot). Une Value est adressée par un Index (clé), qui est une chaîne de caractères terminée par un caractère nul de longueur quelconque. La mémoire pour supporter le tableau est allouée lorsque des paires index/valeur sont insérées, et libérée lorsque des paires index/valeur sont supprimées. C'est une forme de tableau associatif, où les éléments du tableau sont également triés lexicographiquement (sensible à la casse) par les index. Cela pourrait être considéré comme

void * JudySLArray["Toto, je ne pense pas que nous soyons au Kansas anymore"];

Un tableau JudySL est alloué avec un pointeur NULL

Pvoid_t PJSLArray = (Pvoid_t) NULL;
Comme avec un tableau ordinaire, il n'y a pas d'index (chaînes) dupliqués dans un tableau JudySL.

En utilisant les macros décrites ici, plutôt que les appels de fonction JudySL, la gestion d'erreur par défaut envoie un message à la sortie d'erreur standard et termine le programme avec exit(1).

JSLI(PValue, PJSLArray, Index) // JudySLIns()

Insère une chaîne Index et une Value dans le tableau JudySL PJSLArray. Si l'Index est inséré avec succès, la Value est initialisée à 0. Si l'Index était déjà présent, la Value n'est pas modifiée.

Retourne PValue pointant vers la Value de l'Index. Votre programme doit utiliser ce pointeur pour modifier la Value, par exemple :

*PValue = 1234;

Note : JSLI() et JSLD réorganisent le tableau JudySL. Par conséquent, les pointeurs retournés par les appels JudySL précédents deviennent invalides et doivent être réacquis.

JSLD(Rc_int, PJSLArray, Index) // JudySLDel()

Supprime la paire Index/Value spécifiée (élément du tableau) du tableau JudySL.

Retourne Rc_int mis à 1 si succès. tableau et qu'il a été précédemment inséré. Retourne Rc_int mis à 0 si l'Index n'était pas présent.

JSLG(PValue, PJSLArray, Index) // JudySLGet()

Obtient le pointeur vers la Value de l'Index.

Retourne PValue pointant vers la Value de l'Index. Retourne PValue mis à NULL si l'Index n'était pas présent.

JSLFA(Rc_word, PJSLArray) // JudySLFreeArray()

Étant donné un pointeur vers un tableau JudySL (PJSLArray), libère l'ensemble du tableau (beaucoup plus rapide que d'utiliser une boucle JSLN(), JSLD()).

Retourne Rc_word égal au nombre d'octets libérés et PJSLArray mis à NULL.

Fonctions de recherche JudySL

Les fonctions de recherche JudySL vous permettent de rechercher des index dans le tableau. Vous pouvez rechercher de manière inclusive ou exclusive, dans les deux sens.

En cas de succès, Index est retourné avec l'index trouvé, et PValue est retourné avec un pointeur vers la Value de l'Index. En cas d'échec, PValue est retourné mis à NULL, et Index ne contient aucune information utile. PValue doit être testé pour être non-NULL avant d'utiliser Index, car une défaillance de recherche est possible.

Note : Pour prendre en charge tous les retours possibles, le tampon Index doit être au moins aussi grand que la plus grande chaîne stockée dans le tableau.

JSLF(PValue, PJSLArray, Index) // JudySLFirst()

Recherche (inclusivement) le premier index présent qui est égal ou supérieur à la chaîne Index passée. (Commencez avec une chaîne nulle pour trouver le premier index dans le tableau.) JSLF() est généralement utilisé pour commencer une analyse par ordre trié des index valides dans un tableau JudySL.

uint8_t Index[MAXLINELEN];
strcpy (Index, "");
JSLF(PValue, PJSLArray, Index);

JSLN(PValue, PJSLArray, Index) // JudySLNext()

Recherche (exclusivement) le prochain index présent qui est supérieur à la chaîne Index passée. JSLN() est généralement utilisé pour continuer une analyse par ordre trié des index valides dans un tableau JudySL, ou pour localiser un "voisin" d'un index donné.

JSLL(PValue, PJSLArray, Index) // JudySLLast()

Recherche (inclusivement) le dernier index présent qui est égal ou inférieur à la chaîne Index passée. (Commencez avec une chaîne de valeur maximale pour rechercher le dernier index dans le tableau, comme une chaîne de longueur maximale de 0xff octets.) JSLL() est généralement utilisé pour commencer une analyse par ordre trié inverse des index valides dans un tableau JudySL.

JSLP(PValue, PJSLArray, Index) // JudySLPrev()

Recherche (exclusivement) l'index précédent présent qui est inférieur à la chaîne Index passée. JSLP() est généralement utilisé pour continuer une analyse par ordre trié inverse des index valides dans un tableau JudySL, ou pour localiser un "voisin" d'un index donné.

EXEMPLE de routine de tri de chaînes

#include <stdio.h>
#include <Judy.h>
#define MAXLINE 1000000                 // longueur max chaîne (ligne)
uint8_t   Index[MAXLINE];               // chaîne à insérer
int     // Usage:  JudySort < fichier_à_trier
main()
{
    Pvoid_t   PJArray = (PWord_t)NULL;  // Tableau Judy.
    PWord_t   PValue;                   // Élément du tableau Judy.
    Word_t    Bytes;                    // taille du tableau JudySL.
    while (fgets(Index, MAXLINE, stdin) != (char *)NULL)
    {
        JSLI(PValue, PJArray, Index);   // stocker la chaîne dans le tableau
        if (PValue == PJERR)            // s'il n'y a plus de mémoire ?
        {                               // alors faire quelque chose
            printf("Échec du malloc -- obtenir plus de RAM\n");
            exit(1);
        }
        ++(*PValue);                    // compter les occurrences de la chaîne
    }
    Index[0] = '\0';                    // commencer avec la plus petite chaîne.
    JSLF(PValue, PJArray, Index);       // obtenir la première chaîne
    while (PValue != NULL)
    {
        while ((*PValue)--)             // imprimer les doublons
            printf("%s", Index);
        JSLN(PValue, PJArray, Index);   // obtenir la chaîne suivante
    }
    JSLFA(Bytes, PJArray);              // libérer le tableau
    fprintf(stderr, "Le tableau JudySL a utilisé %lu octets de mémoire\n", Bytes);
    return (0);
}
