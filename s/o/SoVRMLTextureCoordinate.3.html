VRML texture coordinates node

Detailed Description

This node defines texture coordinate values for use with SoVRMLTexture2 nodes. The texture coordinates are specified as a list of 2D vectors. Each vector represents a point on the texture map. The texture coordinates are usually specified in conjunction with the vertices of a geometry node, such as SoVRMLIndexedFaceSet. The first texture coordinate in the list is applied to the first vertex of the geometry node, the second texture coordinate to the second vertex, and so on. If the number of texture coordinates is less than the number of vertices, the texture coordinates are repeated in a cycle. If there are no texture coordinates specified, then no texturing is applied.

DESCRIPTION Détaillée

Ce nœud définit les valeurs de coordonnées de texture à utiliser avec les nœuds SoVRMLTexture2. Les coordonnées de texture sont spécifiées sous forme de liste de vecteurs 2D. Chaque vecteur représente un point sur la carte de texture. Les coordonnées de texture sont généralement spécifiées en conjonction avec les sommets d'un nœud de géométrie, tel que SoVRMLIndexedFaceSet. La première coordonnée de texture de la liste est appliquée au premier sommet du nœud de géométrie, la deuxième coordonnée de texture au deuxième sommet, et ainsi de suite. Si le nombre de coordonnées de texture est inférieur au nombre de sommets, les coordonnées de texture sont répétées en cycle. S'il n'y a pas de coordonnées de texture spécifiées, aucune texturation n'est appliquée.
