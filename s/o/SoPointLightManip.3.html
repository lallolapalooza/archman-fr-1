Description détaillée

La classe SoPointLightManip est utilisée pour manipuler les nœuds de type lumière ponctuelle.

Un manipulateur est utilisé en remplaçant le nœud que vous souhaitez éditer dans la scène par le manipulateur. Des "draggers" sont utilisés pour manipuler le nœud. Lorsque la manipulation est terminée, le nœud est replacé dans la scène, remplaçant le manipulateur.

Detailed Description

A point light source manipulator.

This class is inherited from SoPointLight and adds interaction capabilities. It uses a dragger to allow the user to move the light source interactively.

The dragger used is a 3D arrow, which lets the user drag the light source around in the scene.

◆◆copyContents()

protected void coin::SoPointLightManip  copyContents (const SoFieldContainer * from, SbBool copyconnections)

Makes a deep copy of all data of from into this instance, except external scene graph references if copyconnections is FALSE.

This is the method that should be overridden by extension node / engine / dragger / whatever subclasses which need to account for internal data that are not handled automatically.

For copying nodes from application code, you should not invoke this function directly, but rather call the SoNode::copy() function:

SoNode * mynewnode = templatenode->copy();

The same also goes for engines.

Make sure that when you override the copyContents() method in your extension class that you also make it call upwards to its parent superclass in the inheritance hierarchy, as copyContents() in for instance SoNode and SoFieldContainer does important work. It should go something like this:

void
MyCoinExtensionNode::copyContents(const SoFieldContainer * from,
SbBool copyconnections)
{
// let parent superclasses do their thing (copy fields, copy
// instance name, etc.)
SoNode::copyContents(from, copyconnections);
// [..then copy internal data..]
}

SYNOPSIS

#include <Inventor/manips/SoPointLightManip.h>

DESCRIPTION

SoPointLightManip is the default point light manipulator. It allows you to interactively manipulate a point light source using a manipulator.

This class provides an interface for manipulating a point light in a 3D scene. It inherits from SoLightManip and overrides certain virtual methods to provide specific behavior for point lights.
