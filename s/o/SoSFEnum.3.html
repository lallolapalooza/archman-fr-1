Description détaillée

La classe SoSFEnum est un conteneur pour une valeur énumérée.

Ce champ est utilisé lorsque des nœuds, des moteurs ou d'autres conteneurs de champs doivent stocker une valeur particulière parmi un ensemble énuméré.

Une instance de ce type de champ stocke sa valeur dans le fichier sous forme de nom symbolique, plutôt que sous forme de valeur entière réelle.

Les instances de SoSFEnum sont initialisées au niveau de l'instance, généralement dans le constructeur du conteneur de champ avec les macros SO_NODE_DEFINE_ENUM_VALUE(enumtype, symbolvalue) et SO_NODE_SET_SF_ENUM_TYPE(enumfield, enumtype) pour les nœuds, ou pour les moteurs ; SO_ENGINE_DEFINE_ENUM_VALUE() et SO_ENGINE_SET_SF_ENUM_TYPE().

Exemple d'initialisation depuis le constructeur de la classe SoCone :

SO_NODE_DEFINE_ENUM_VALUE(Part, SIDES);
SO_NODE_DEFINE_ENUM_VALUE(Part, BOTTOM);
SO_NODE_DEFINE_ENUM_VALUE(Part, ALL);
SO_NODE_SET_SF_ENUM_TYPE(parts, Part);
