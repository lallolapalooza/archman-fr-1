SoFile est un conteneur de nœuds pour un autre fichier modèle. Ce nœud offre un moyen de diviser vos modèles en un ensemble de modèles "composants" à inclure dans des fichiers "maîtres" plus grands. Il suffit de fournir le nom du fichier modèle à inclure dans le champ SoFile::name, et il sera automatiquement chargé et ses nœuds insérés dans le graphe de scène à l'emplacement du nœud SoFile. Vous pouvez également définir manuellement le champ SoFile::name. Une telle action déclenchera alors automatiquement une opération de lecture qui importera le nom de fichier que vous avez défini dans le champ. : 
File {
    name <Fichier indéfini>
}

NAME

SoFile - File Node

SYNOPSIS

#include <Inventor/nodes/SoFile.h>

Herencia:

SoNode {
  SoSFString name
}

Descripción detallada

El nodo SoFile lee (inserta) el contenido de un archivo de escena de OpenInventor en el gráfico de escena en la ubicación del nodo SoFile. El contenido del archivo se convierte en un subgrafo de nodos que se inserta inmediatamente después del nodo SoFile.

El campo name contiene el nombre del archivo que se va a leer. El nombre del archivo puede ser absoluto o relativo.

El nodo SoFile es un nodo de "hoja" en el sentido de que no tiene hijos. Su propósito es puramente la inserción de contenido de archivo.

Nota: El nodo SoFile solo se puede utilizar para leer archivos y no se puede utilizar para escribir contenido en un archivo.

Por defecto, el campo name está vacío. Si el campo name se establece en un nombre de archivo no vacío, el nodo SoFile intentará leer el archivo especificado. Si la lectura es exitosa, el contenido del archivo se insertará en el gráfico de escena en la ubicación del nodo SoFile, y el nodo SoFile en sí mismo se eliminará del gráfico de escena. Si la lectura falla (por ejemplo, el archivo no existe o tiene un formato incorrecto), el nodo SoFile permanece en el gráfico de escena y no se inserta ningún contenido.

El nodo SoFile también está equipado con funcionalidades de búsqueda y conteo de primitivas que se heredan de SoNode.

void SoFile::copyContents (const SoFieldContainer * from, SbBool copyconnections) [virtual]

Crea una copia profunda de todos los datos de from en esta instancia, a menos que copyconnections sea FALSE, en que caso se excluirán las referencias externas al gráfico de escena.

Este es el método que debe sobrescribirse por nodos de extensión, motor, dragger, etc., que deben considerar datos internos que no se manejan automáticamente.

Para copiar nodos desde código de aplicación, no se debe invocar directamente este método, sino más bien la función SoNode::copy():

SoNode * mynewnode = templatenode->copy();

El mismo también se aplica para los motores.

Asegúrese de que cuando sobrescriba el método copyContents() en su clase de extensión, también lo llame hacia arriba en la jerarquía de herencia, como copyContents() en por ejemplo SoNode y SoFieldContainer realiza trabajo importante. Debe ir algo así:

void
MyCoinExtensionNode::copyContents(const SoFieldContainer * from,
                                  SbBool copyconnections)
{
  // dejan a los superclases hacer su trabajo (copiar campos, copiar
  // nombre de instancia, etc.)
  SoNode::copyContents(from, copyconnections);
  // [..luego copiar datos internos..]
}
