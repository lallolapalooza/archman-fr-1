Description

Un champ de champ de plusieurs valeurs qui contient des vecteurs à 4 éléments (SbVec4s).

Il s'agit de champs de champs, il contient donc des valeurs multiples. Les champs de champs multiples sont généralement utilisés pour stocker des listes d'éléments graphiques, des listes de sommets, etc.

Ce champ prend en charge le partage de données d'application via une méthode setValuesPointer(). Voir la documentation de SoMField pour des informations sur l'utilisation de cette fonction.

Voir aussi

SbVec4s, SoSFVec4s Soyez conscient que cette classe est une extension pour Coin, et qu'elle n'est pas disponible dans l'API originale SGI Open Inventor v2.1.

Depuis

Coin 2.5
