Description Détaillée

La classe SoTextureCoordinatePlane génère des coordonnées de texture projetées sur un plan.

SoTextureCoordinatePlane est utilisée pour générer des coordonnées de texture projetées sur un plan de texture. Les coordonnées de texture s, t et r sont calculées comme la distance de l'origine au point projeté, dans les directions respectives. Le plan de texture est spécifié par deux vecteurs de direction, donnés comme SoTextureCoordinatePlane::directionS et SoTextureCoordinatePlane::directionT dans les coordonnées de l'objet. SoTextureCoordinatePlane::directionR est utilisé pour générer la troisième coordonnée, et peut être utilisé pour générer des coordonnées de texture pour les textures 3D. Pour les textures 2D, vous pouvez laisser ce champ tel quel.

La longueur du vecteur détermine l'intervalle de répétition de la texture par unité de longueur.

Un exemple d'utilisation simple :

SoSeparator *root = new SoSeparator;
root->ref();
// l'image de texture
SoTexture2 *tex = new SoTexture2;
tex->filename.setValue("foo.png");
root->addChild(tex);
// le plan de texture
SoTextureCoordinatePlane *texPlane = new SoTextureCoordinatePlane;
texPlane->directionS.setValue(SbVec3f(1,0,0));
texPlane->directionT.setValue(SbVec3f(0,1,0));
root->addChild(texPlane);
// ajouter un cube simple
SoCube * c = new SoCube;
c->width.setValue(1.0);
c->height.setValue(1.0)
c->depth.setValue(1.0);
root->addChild(new SoCube);

Ici, nous projetons une texture sur un cube. La coordonnée de texture du plan est spécifiée par directionS = (1,0,0) et directionT = (0,1,0), ce qui signifie qu'elle est parallèle à la face avant du cube. La définir, par exemple, sur directionS = (0,1,0) et directionT = (-1,0,0) fera tourner la texture de 90 degrés dans le sens antihoraire. Les définir sur ((2,0,0), (0,2,0)) entraînera la répétition de la texture deux fois par unité, de sorte qu'elle apparaîtra quatre fois sur la face 1x1.

Notez : lorsque vous transformez le cube, la transformation affectera également la texture - elle sera transformée avec le reste du monde, mais semblera "fixée" à l'objet. Si vous voulez changer la position de la texture sur l'objet, vous devez insérer un nœud SoTexture2Transform avant le plan de coordonnées de texture. Par exemple, dans l'exemple ci-dessus, comme le cube est centré dans son système de coordonnées, le coin inférieur gauche de la texture semble être au milieu de la face. Pour déplacer l'origine de la texture pour qu'elle corresponde au coin inférieur gauche de la face, insérez :

SoTexture2Transform * tf = new SoTexture2Transform;
tf->translation.setValue(-0.5,-0.5);
root->addChild(tf);

avant d'ajouter le plan de coordonnées de texture.

FORMAT DES FICHIERS/VALEURS PAR DÉFAUT :

TextureCoordinatePlane {
    directionS 1 0 0
    directionT 0 1 0
}
