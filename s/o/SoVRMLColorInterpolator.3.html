Description Détaillée

La classe SoVRMLColorInterpolator est utilisée pour interpoler des valeurs de couleur.

La documentation détaillée de la classe est prise littéralement de la norme VRML97 (ISO/IEC 14772-1:1997). Elle est la propriété du Consortium Web3D et est utilisée avec sa permission :

ColorInterpolator {
  eventIn      SFFloat set_fraction        # (-inf, inf)
  exposedField MFFloat key           []    # (-inf, inf)
  exposedField MFColor keyValue      []    # [0,1]
  eventOut     SFColor value_changed
}

Ce nœud interpole entre un ensemble de valeurs MFColor clés pour produire un événement SFColor (RGB) value_changed. Le nombre de couleurs dans le champ keyValue doit être égal au nombre de keyframes dans le champ key. Les champs keyValue et value_changed sont définis dans l'espace colorimétrique RVB. Une interpolation linéaire est effectuée en utilisant la valeur de set_fraction comme entrée dans l'espace colorimétrique HSV (voir http://www.web3d.org/documents/specifications/14772/V2.0/part1/bibliography.html#[FOLE pour une description des espaces colorimétriques RVB et HSV). Les résultats sont indéfinis lors de l'interpolation entre deux clés consécutives avec des couleurs complémentaires.

4.6.8, Nœuds d'interpolation (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.8), contient une discussion détaillée sur les interpolateurs.

NAME

SoVRMLColorInterpolator — node for interpolating colors

SYNOPSIS

Input Fields

SoVRMLColorInterpolator::keyValue

Output Fields

SoVRMLColorInterpolator::value_changed

Inheritance

SoNode > SoVRMLNode > SoVRMLInterpolatorNode > SoVRMLColorInterpolator

Detailed Description

This node defines a color interpolator. It interpolates between colors defined in the keyValue field.

The node takes one or more SoSFTime values from the set_fraction input event, converts them into a normalized value between 0.0 and 1.0 (based on the SoVRMLInterpolatorNode::startTime and SoVRMLInterpolatorNode::stopTime fields) and uses this normalized value to select a color from the keyValue field. The selected color is then sent out through the value_changed eventOut.

The keyValue field should contain a list of SoMFColor values. The interpolator will select one of these colors based on the normalized time value. If the normalized time is 0.0, the first color is selected. If it is 1.0, the last color is selected. Values in between will result in interpolation between the nearest colors.

The SoVRMLColorInterpolator node is part of the VRML 2.0 standard.
