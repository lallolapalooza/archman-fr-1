DESCRIPTION DETAILEE

La classe SoSFBool est un conteneur pour une valeur SbBool.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker une valeur booléenne marche/arrêt ou VRAI/FAUX, comme par exemple le champ "on" des classes de nœuds SoPointLight, SoSpotLight et SoDirectionalLight.
