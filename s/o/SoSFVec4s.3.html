Description détaillée

La classe SoSFVec4s est un conteneur pour un vecteur SbVec4s.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker un seul vecteur à quatre éléments.

Voir aussi

SbVec4s, SoMFVec4s Attention, cette classe est une extension pour Coin, et elle n'est pas disponible dans l'API originale Open Inventor v2.1 de SGI.

Depuis

Coin 2.5

Description

This is a single-valued field that contains a 4-component vector of short integers. This field is defined in the Coin library.

The vector components are accessed using the indices 0, 1, 2, and 3, corresponding to the x, y, z, and w components respectively.

SoSFVec4s is part of the Coin 3D scene graph library.
