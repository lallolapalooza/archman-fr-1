Description Détaillée

La classe SoTextureCubeMap est utilisée pour mapper une carte cubique sur les nœuds de forme subséquents.

Les nœuds de forme dans la portée des nœuds SoTextureCubeMap dans le graphe de scène (c'est-à-dire en dessous du même SoSeparator et à droite du SoTextureCubeMap) auront la texture appliquée selon les caractéristiques individuelles de chaque type de forme. Voir la documentation des divers types de formes (SoFaceSet, SoCube, SoSphere, etc.) pour des informations spécifiques sur la manière dont les textures seront appliquées.

FORMAT DE FICHIER / VALEURS PAR DÉFAUT :

TextureCubeMap {
    filenames [  ]
    imagePosX 0 0 0
    imageNegX 0 0 0
    imagePosY 0 0 0
    imageNegY 0 0 0
    imagePosZ 0 0 0
    imageNegZ 0 0 0
    wrapS REPEAT
    wrapT REPEAT
    model MODULATE
    blendColor 0 0 0
}

Documentation des Énumérations Membres

enum SoTextureCubeMap::Model

Modèle de mappage de texture, pour décider comment "fusionner" la carte de texture avec l'objet sur lequel elle est mappée.

Énumérateur

MODULATE
La couleur de la texture est multipliée par la couleur du polygone. Le résultat sera ombré selon Phong (si le modèle de lumière est PHONG).
DECAL
L'image de la texture écrase l'ombrage du polygone. Les pixels texturés ne seront pas ombrés selon Phong. Comportement indéfini pour les textures en niveaux de gris et en niveaux de gris-alpha.
BLEND
Ce modèle est normalement utilisé avec des textures monochromes (c'est-à-dire des textures avec une ou deux composantes). La première composante, l'intensité, est alors utilisée pour mélanger la couleur ombrée du polygone et la SoTextureCubeMap::blendColor.
REPLACE
L'image de la texture écrase l'ombrage du polygone. Les pixels texturés ne seront pas ombrés selon Phong. Prend en charge les textures en niveaux de gris et en niveaux de gris-alpha. Cette fonctionnalité nécessite OpenGL 1.1. MODULATE sera utilisé si la version d'OpenGL < 1.1 est détectée.

Veuillez noter que l'utilisation de ce modèle de texture rendra vos fichiers Inventor incompatibles avec les anciennes versions de Coin et d'Inventor. Vous avez besoin de Coin >= 2.2 ou TGS Inventor 4.0 pour charger des fichiers Inventor qui utilisent le modèle de texture REPLACE.

enum SoTextureCubeMap::Wrap

Énumération des stratégies d'enroulement qui peuvent être utilisées lorsque la carte de texture ne couvre pas toute l'étendue de la géométrie.

Énumérateur

REPEAT
Répéter la texture lorsque la coordonnée n'est pas comprise entre 0 et 1.
CLAMP
Limiter la coordonnée entre 0 et 1.

SoSFEnum SoTextureCubeMap::wrapS

Stratégie d'enroulement pour la coordonnée S lorsque la carte de texture est plus étroite que l'objet sur lequel elle est appliquée.

La valeur par défaut est SoTextureCubeMap::REPEAT.

SoSFEnum SoTextureCubeMap::wrapT

Stratégie d'enroulement pour la coordonnée T lorsque la carte de texture est plus courte que l'objet sur lequel elle est appliquée.

La valeur par défaut est SoTextureCubeMap::REPEAT.

SoSFEnum SoTextureCubeMap::model

Modèle de mappage de texture pour la manière dont la carte de texture est "fusionnée" avec les primitives polygonales auxquelles elle est appliquée. La valeur par défaut est SoTextureCubeMap::MODULATE.

SoSFColor SoTextureCubeMap::blendColor

Couleur de mélange. Utilisée lorsque SoTextureCubeMap::model est SoTextureCubeMap::BLEND.

La valeur de couleur par défaut est [0, 0, 0], noir, ce qui signifie qu'aucune contribution au mélange n'est apportée.
