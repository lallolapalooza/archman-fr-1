Description Détaillée

La classe SoTextureCombine est un nœud pour définir des fonctions de combinaison de textures.

Ce nœud est une représentation plus ou moins exacte de l'extension OpenGL ARB_texture_env_combine (incluse dans OpenGL dans OpenGL v1.3). Voir http://oss.sgi.com/projects/ogl-sample/registry/ARB/texture_env_combine.txt pour plus d'informations sur cette extension.

Fondamentalement, ce nœud permet de spécifier jusqu'à trois sources et une fonction pour combiner ces sources. De plus, il est possible d'appliquer des opérateurs simples aux sources. Dans la documentation ci-dessous, les sources seront appelées Arg0, Arg1 et Arg2, comme dans la spécification ARB_texture_env_mode.

Il est possible de spécifier à la fois une opération de couleur et une opération alpha.

Ce nœud a de nombreux champs, mais il suffit généralement de définir un seul ou très peu d'entre eux. L'opérateur sélectionné décide quelles valeurs vous devez définir. Un exemple courant est l'ajout d'une carte de lumière à la géométrie texturée. Une carte de lumière peut ressembler à ceci :

DESCRIPTION

Ce nœud implémente la combinaison de textures telle que définie par l'extension multitexturing de OpenGL.

Le nœud `SoTextureCombine` est utilisé pour spécifier comment les couleurs et les valeurs alpha de plusieurs textures et d'autres sources sont combinées pour produire la couleur finale d'une primitive. Le mécanisme est similaire aux fonctions de combinaison de textures de OpenGL, mais il est structuré pour permettre la spécification de jusqu'à trois opérandes et une opération pour la couleur (RGB) et l'alpha (A) séparément.

Le nœud permet de définir les sources pour la couleur et l'alpha, les opérandes pour ces sources, et l'opération de combinaison à appliquer. Il prend également en charge des facteurs d'échelle pour les résultats RGB et Alpha, ainsi qu'une couleur constante qui peut être utilisée comme source.

Champs

rgbSource
Spécifie la source des couleurs RGB pour la combinaison. Il peut s'agir de la couleur de la texture, de la couleur primaire, d'une couleur constante ou de la sortie de l'unité de texture précédente.
alphaSource
Spécifie la source des valeurs alpha pour la combinaison.
rgbOperand
Spécifie l'opérande à utiliser pour la composante couleur (RGB). Les options incluent la couleur source ou un moins la couleur source.
alphaOperand
Spécifie l'opérande à utiliser pour la composante alpha (A). Les options incluent la valeur alpha source ou un moins la valeur alpha source.
rgbOperation
Spécifie l'opération de combinaison à appliquer aux entrées RGB. Les opérations disponibles incluent REPLACE, MODULATE, ADD, SUBTRACT, INTERPOLATE, et DOT3.
alphaOperation
Spécifie l'opération de combinaison à appliquer aux entrées alpha.
rgbScale
Facteur d'échelle pour le résultat de la combinaison couleur RGB. Les valeurs supportées sont 1, 2 et 4.
alphaScale
Facteur d'échelle pour le résultat de la combinaison alpha. Les valeurs supportées sont 1, 2 et 4.
constantColor
La couleur constante à utiliser lorsque `CONSTANT` est spécifié comme source.

SoType SoTextureCombine::getClassTypeId (void ) [static]

SoTextureCombine::rgbSource

Les sources de couleur. Ce champ est vide par défaut, mais vous pouvez insérer jusqu'à trois valeurs [Arg0, Arg1, Arg2]. Lorsque le champ contient moins de trois valeurs, les valeurs par défaut [TEXTURE, PREVIOUS, CONSTANT] seront utilisées pour les valeurs manquantes.

Pour l'unité de texture 0, PREVIOUS correspond à PRIMARY_COLOR.

SoTextureCombine::alphaSource

Les sources alpha. Ce champ est vide par défaut, mais vous pouvez insérer jusqu'à trois valeurs [Arg0, Arg1, Arg2]. Lorsque le champ contient moins de trois valeurs, les valeurs par défaut [TEXTURE, PREVIOUS, CONSTANT] seront utilisées pour les valeurs manquantes.

Pour l'unité de texture 0, PREVIOUS correspond à PRIMARY_COLOR.

SoTextureCombine::rgbOperand

Les opérandes couleur. Ce champ est vide par défaut, mais vous pouvez insérer jusqu'à trois valeurs. Lorsque le champ contient moins de trois valeurs, les valeurs par défaut [SRC_COLOR, SRC_COLOR, SRC_COLOR] seront utilisées pour les valeurs manquantes.

SoTextureCombine::alphaOperand

Les opérandes alpha. Ce champ est vide par défaut, mais vous pouvez insérer jusqu'à trois valeurs. Lorsque le champ contient moins de trois valeurs, les valeurs par défaut [SRC_ALPHA, SRC_ALPHA, SRC_ALPHA] seront utilisées pour les valeurs manquantes. Veuillez noter que seuls SRC_ALPHA et ONE_MINUS_SRC_ALPHA sont des opérandes valides pour les opérations alpha.

SoTextureCombine::rgbOperation

L'opération couleur. La valeur par défaut est MODULATE.

SoTextureCombine::alphaOperation

L'opération alpha. La valeur par défaut est MODULATE.

SoTextureCombine::rgbScale

Met à l'échelle le résultat couleur par cette valeur. Les valeurs supportées sont 1, 2 et 4.

SoTextureCombine::alphaScale

Met à l'échelle le résultat alpha par cette valeur. Les valeurs supportées sont 1, 2 et 4.

SoTextureCombine::constantColor

La couleur constante (lorsque CONSTANT est utilisée comme source). La valeur par défaut est (1,1,1,1).
