Detailed Description

The VRML97 SoVRMLImageTexture node represents an image texture. It defines the texture map to be used for texturing geometry.

The texture image is specified by a URL. The VRML browser or application is responsible for loading the image from the URL. If the URL points to a local file, the image is loaded immediately. If the URL points to a remote file, the application may choose to load it immediately or delay loading until the image is first needed (see setDelayFetchURL()).

An optional description string can be provided, which is usually ignored by the browser but can be used by applications for other purposes.

The SoVRMLImageTexture node is equivalent to the VRML97 ImageTexture node. See the VRML97 specification for details.
