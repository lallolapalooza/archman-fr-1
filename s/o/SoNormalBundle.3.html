Description détaillée

La classe SoNormalBundle simplifie la gestion des normales.

Cette classe n'est actuellement pas utilisée dans Coin mais est fournie pour la compatibilité API.

SoNormalBundle — une classe de faisceau pour les outils de rendu de SoQt et de SoWin.

SYNOPSIS

#include <Inventor/nodes/SoNormalBundle.h>

Classe héritée de : SoNode

Classes connues qui utilisent SoNormalBundle : SoNodekits

Description Détaillée

Une classe de faisceau pour les outils de rendu de SoQt et de SoWin. L'utilisation la plus courante de SoNormalBundle est de créer une primitive de type "mesh" (grille) et de faire en sorte qu'elle possède des normales pour l'éclairage. La classe SoNormalBundle est un faisceau de nœuds qui, lorsqu'ils sont utilisés avec des classes de nœuds de primitive (comme SoIndexedFaceSet), fournissent des normales pour l'éclairage.
