Description Détaillée

La classe SoError est la classe de base pour toutes les classes de gestion d'erreurs.

Le gestionnaire d'erreurs par défaut se contente d'imprimer les messages sur le flux de sortie d'erreur standard, mais cela peut être remplacé par les applications clientes.

La possibilité de remplacer le gestionnaire d'erreurs par défaut est utile lorsque vous souhaitez collecter les messages d'erreur, par exemple lors de l'importation de modèles, afin de les présenter à l'utilisateur d'une manière personnalisée (par exemple, dans une fenêtre de message graphique).

La classe SoError n'est pas conçue pour être utilisée seule ; elle n'est utilisée que par ses sous-classes à l'intérieur de la bibliothèque Coin.

NAME

SoError - Base class for all errors in Coin.

SYNOPSIS

#include <Inventor/errors/SoError.h>

Inheritance diagram of SoError.

+-- SoError
    +-- SoDebugError
    +-- SoMemoryError
    +-- SoReadError

Detailed Description

This is the base class for all errors in Coin. It provides methods for setting and retrieving error information, such as a debug string and a callback function to handle the error. Concrete error classes (like SoReadError) inherit from this class.

The error handling mechanism in Coin is as follows:

  1. An error occurs.
  2. An appropriate SoError subclass is instantiated.
  3. The error is reported by calling SoError::post().
  4. SoError::post() calls the handleError() method.
  5. handleError() checks if a user-defined error handler has been registered using SoError::setHandler().
  6. If a handler is registered, it is called with the error object.
  7. If no handler is registered, or if the handler returns FALSE, the default error handling (e.g., printing to stderr) is performed.

static void SoError::setHandler (SoError::HandlerFunc handler, void *handler_data) [static]

Sets a global error handler function and associated data.

The handler function will be called whenever an error is posted. It receives the error object and the handler_data as arguments. The handler function should return TRUE if it has handled the error and no further action is needed, or FALSE if the default error handling should still be performed.

To remove the handler, call this method with NULL for both arguments.

Posts the error. This method is usually called internally by error-generating functions.
