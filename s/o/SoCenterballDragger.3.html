Description détaillée

La classe SoCenterballDragger est un dragger que vous pouvez faire pivoter et translater.

Voici à quoi ressemble le dragger avec sa géométrie par défaut à l'état inactif :

Pour la rotation, cliquez sur les « bandes » de la sphère pour contraindre la rotation à s'effectuer autour du vecteur normal du disque, ou n'importe où ailleurs sur la sphère (invisible) pour une rotation libre.

La translation s'effectue en cliquant et en faisant glisser l'un des quatre marqueurs fléchés. Maintenez SHIFT enfoncé pour contraindre la translation à un seul axe au lieu d'un plan.

Lors de la translation, au lieu de modifier la partie translation de la matrice de mouvement, un champ center est mis à jour, et la géométrie est déplacée à l'aide d'un nœud de transformation interne.

Voici un exemple d'utilisation simple, sous la forme d'un graphe de scène dans un fichier iv :

#Inventor V2.1 ascii
Separator {
   # Le dragger, décalé un peu par rapport à la géométrie à clipper,
   # afin de ne pas perturber l'interface utilisateur.
   Separator {
      Translation { translation -4 0 0 }
      DEF cbdragger CenterballDragger { }
   }
   # Le sous-graphe du plan de clipping.
   TransformSeparator {
      # Connecter les transformations à celles du dragger.
      Rotation { rotation 0 0 1 0 = USE cbdragger . rotation }
      Translation { translation 0 0 0 = USE cbdragger . center }
      # Utiliser un simple jeux de lignes comme indicateur pour montrer comment
      # le plan de clipping est situé dans l'espace.
      Coordinate3 {
         point [
          0 2 2, 0 2 -2,
          0 -2 2, 0 -2 -2,
          0 2 -2, 0 -2 -2,
          0 2 2, 0 -2 2
       ]
      }
      LineSet { numVertices [ 2, 2, 2, 2 ] }
      ClipPlane { }
   }
   # Ensuite vient la géométrie qui est clippée. Pour cet
   # exemple, nous utilisons une simple sphère.
   Sphere { }
}

La figure ci-dessus montre le graphe de scène d'exemple dans une vue avec la croix la plus proche sur le centreball dragger sélectionnée. Le déplacement du dragger déplace alors le plan de clipping associé sur la géométrie (la sphère dans ce cas).
