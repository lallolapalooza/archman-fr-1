Description détaillée

La classe SoIndexedTriangleStripSet conserve les données pour le rendu et la représentation des bandes de triangles.

Utilisez des nœuds de ce type comme moyen efficace de dessiner des triangles qui sont enchaînés.

Pour plus d'informations, consultez la documentation du nœud SoTriangleStripSet.

Pour rendre plusieurs bandes dans le même nœud, il suffit de séparer les indices de coordonnées par -1. Pour plus d'informations sur les formes indexées, consultez la documentation de SoIndexedShape et SoIndexedFaceSet.

Exemple de graphe de scène :

#Inventor V2.1 ascii
Separator {
   Coordinate3 {
      point [
       -2 1 0, -1 -1 0, 0 1 0, 1 -1 0, 2 1 0, # première bande, z==0
       -2 1 5, -1 -1 5, 0 1 5, 1 -1 5, 2 1 5  # deuxième bande, z==5
      ]
   }
   IndexedTriangleStripSet {
      coordIndex [
       0, 1, 2, 3, 4, -1,
       5, 6, 7, 8, 9, -1
      ]
   }
}

FORMAT DE FICHIER/VALEURS PAR DÉFAUT:

IndexedTriangleStripSet {
    vertexProperty NULL
    coordIndex 0
    materialIndex -1
    normalIndex -1
    textureCoordIndex -1
}

La méthode implémente le comportement d'action pour les nœuds de forme pour SoCallbackAction. Elle est appelée depuis SoShape::callback(). (Les sous-classes ne devraient pas surcharger SoNode::callback().)
