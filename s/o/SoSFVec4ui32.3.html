Description détaillée

Le SoSFVec4ui32 est un conteneur pour un vecteur SbVec4ui32.

Ce champ est utilisé là où les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker un vecteur à quatre éléments.

Voir également

SbVec4ui32, SoMFVec4ui32 Note: Cette classe est une extension de Coin et n'est pas disponible dans l'API SGI Open Inventor v2.1 d'origine.

Depuis

Coin 2.5
