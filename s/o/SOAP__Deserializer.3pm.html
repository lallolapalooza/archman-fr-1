SOAP::Deserializer(3) Documentation Perl fournie par la communauté SOAP::Deserializer(3)

NOM

SOAP::Deserializer - le moyen par lequel la boîte à outils gère la conversion du XML en un objet gérable par un développeur

DESCRIPTION

SOAP::Deserializer fournit le moyen par lequel le XML entrant est décodé en une structure de données Perl.

MÉTHODES

contexte
Ceci fournit l'accès au contexte d'appel de "SOAP::Deserializer". Dans un contexte côté client, cela signifie souvent une référence à une instance de SOAP::Lite. Dans un contexte côté serveur, cela signifie une référence à une instance de SOAP::Server.

EXEMPLES

DÉSÉRIALISATION DE XML BRUT EN UN OBJET SOAP::SOM

Un utilitaire utile pour SOAP::Deserializer est de parser des documents ou des fragments XML bruts en un objet SOAP::SOM. Les développeurs SOAP::Lite utilisent cette technique pour écrire des tests unitaires pour le module SOAP::Lite lui-même. C'est beaucoup plus efficace pour tester des aspects de la boîte à outils que de générer des appels client sur le réseau. C'est une façon parfaite pour les développeurs d'écrire des tests unitaires pour leurs types de données personnalisés, par exemple.

Voici un exemple de la façon dont le contenu XML brut peut être interprété en un objet SOAP::SOM en utilisant SOAP::Deserializer:

$xml = <<END_XML;
<foo>
  <person>
    <foo>123</foo>
    <foo>456</foo>
  </person>
  <person>
    <foo>789</foo>
    <foo>012</foo>
  </person>
</foo>
END_XML
my $som = SOAP::Deserializer->deserialize($xml);
