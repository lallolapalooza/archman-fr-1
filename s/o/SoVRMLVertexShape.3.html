SoNormalCache * SoVRMLVertexShape::generateAndReadLockNormalCache (SoState *const state) [protected]

Méthode utilitaire qui peut être utilisée par les sous-classes pour renvoyer ou créer un cache de normales. Si le cache actuel n'est pas valide, elle prend en charge le déréférencement de l'ancien cache et l'empilement et dépilement de l'état pour créer des dépendances d'éléments lors de la création du nouveau cache.

Lors du retour de cette méthode, le cache de normales sera verrouillé en lecture, et l'appelant devra appeler readUnlockNormalCache() lorsque les normales dans le cache ne seront plus nécessaires.

Cette fonction est une extension pour Coin et n'est pas disponible dans l'API originale SGI Open Inventor v2.1.

void SoVRMLVertexShape::readLockNormalCache (void ) [protected]

Verrouille en lecture le cache de normales. Cette méthode doit être appelée avant de récupérer le cache de normales (en utilisant getNormalCache()). Lorsque les normales mises en cache ne sont plus nécessaires, readUnlockNormalCache() doit être appelé.

Il est également possible d'utiliser generateAndReadLockNormalCache().

Cette fonction est une extension pour Coin et n'est pas disponible dans l'API originale SGI Open Inventor v2.1.
