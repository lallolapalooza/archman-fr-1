Detailed Description

This class is a kit for constructing scenes graph nodes that represent light sources. Light nodes are used to illuminate the scene graph.

The default kit definition contains the following.

  • Lights on the SoLight class interface.

  • The actual light node itself.

The following light node types are supported by default:

  • SoDirectionalLight

  • SoPointLight

  • SoSpotLight

See also SoNodeKit.

Description détaillée

Cette classe est un kit pour la construction de graphes de scène représentant des sources lumineuses. Les noeuds de lumière sont utilisés pour éclairer le graphe de scène.

La définition du kit par défaut contient ce qui suit.

  • Lumières sur l'interface de la classe SoLight.

  • Le noeud de lumière réel lui-même.

Les types de noeuds de lumière suivants sont pris en charge par défaut :

  • SoDirectionalLight

  • SoPointLight

  • SoSpotLight

Voir aussi SoNodeKit.
