Description Détaillée

La classe SoPrimitiveVertex représente un sommet d'un primitif généré.

Les objets de type SoPrimitiveVertex sont construits lorsque des données de primitifs sont générées, principalement lors d'un parcours de type SoCallbackAction. Selon le contexte, le sommet peut représenter un point 3D unique, l'un des deux sommets d'une ligne, ou l'un des trois sommets d'un triangle.
