Description Détaillée

La classe SoLocateHighlight met en évidence la géométrie sous le curseur.

Remarque : ce nœud est censé dessiner dans le buffer frontal. Cependant, dans Coin, nous dessinons toujours dans le buffer arrière, provoquant un redessin de la scène chaque fois qu'un état de mise en évidence change.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT:

LocateHighlight {
    renderCaching AUTO
    boundingBoxCaching AUTO
    renderCulling AUTO
    pickCulling AUTO
    color 0.3 0.3 0.3
    style EMISSIVE
    mode AUTO
}

Documentation des Énumérations de Membres

enum SoLocateHighlight::Modes

Type d'énumération pour les modes de comportement.

Énumérateur

AUTO
Mise en évidence lorsque le curseur de la souris se trouve sur le contenu du nœud.
ON
Toujours mettre en évidence.
OFF
Ne jamais mettre en évidence.

enum SoLocateHighlight::Styles

Type d'énumération pour les styles de mise en évidence.

Énumérateur

EMISSIVE
Mise en évidence à l'aide de la couleur émissive en remplacement.
EMISSIVE_DIFFUSE
Mise en évidence à l'aide de la couleur émissive et diffuse en remplacement.

Description


This node is used to draw a highlight around objects in the scene
    graph. The highlight can be controlled using the fields color, style,
    and mode.


The highlight is drawn by traversing the scene graph and applying
    a highlight effect to the nodes that are within the path of the highlight.
    The highlight effect can be customized by setting the color, style,
    and mode fields.


The highlight is only drawn when the node is part of a path that
    is being highlighted. This is typically done by an application that is
    tracking the mouse cursor or some other interaction event.






Member Enumeration Documentation




enum SoLocateHighlight::HighlightStyle


This enum defines the different highlight styles that can be used.




OVERLAY


Draw the highlight as an overlay on top of the object.


EMISSIVE


Draw the highlight as an emissive component of the object's material.


WIREFRAME


Draw the highlight as a wireframe around the object.


BOUNDINGBOX


Draw the highlight as a bounding box around the object.








enum SoLocateHighlight::HighlightMode


This enum defines the different highlight modes that can be used.




AUTO


Automatically determine the highlight mode based on the scene graph.


MANUAL


Manually control the highlight mode.

void   SoLocateHighlight::GLRenderBelowPath (SoGLRenderAction * action)   [virtual]


SGI Open Inventor v2.1 obsoleted support for
    SoGLRenderAction::addMethod(). Instead, GLRender() might be
    called directly, and to optimize traversal, the SoSeparator node
    calls GLRenderBelowPath whenever the path code is BELOW_PATH or NO_PATH
    (path code is guaranteed not to change). To be compatible with SGI's
    Inventor (and thereby also TGS') we have chosen to follow their
    implementation in this respect.


SoSeparator::GLRenderBelowPath() does not traverse its
    children using SoChildList::traverse(), but calls
    GLRenderBelowPath() directly for all its children.
