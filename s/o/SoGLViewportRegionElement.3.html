Detailed Description

This element is used to store the current OpenGL viewport region.

It is used by the rendering engine to correctly set the OpenGL viewport parameters when rendering a scene.

The element is automatically managed by the scenegraph traversal. You typically don't need to interact with it directly, but it can be useful for debugging or for advanced rendering techniques.

Description détaillée

Cet élément est utilisé pour stocker la région de la fenêtre d'affichage OpenGL actuelle.

Il est utilisé par le moteur de rendu pour définir correctement les paramètres de la fenêtre d'affichage OpenGL lors du rendu d'une scène.

L'élément est géré automatiquement par le parcours du graphe de scène. Vous n'avez généralement pas besoin d'interagir directement avec lui, mais il peut être utile pour le débogage ou pour des techniques de rendu avancées.
