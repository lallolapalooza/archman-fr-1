Description Détaillée

La classe SoMaterialBinding est un nœud permettant de définir comment les matériaux sont mappés sur les formes.

La liaison de matériaux spécifiée dans les nœuds de ce type décide comment les valeurs de matériaux des nœuds SoMaterial sont mappées sur les nœuds de forme géométrique intégrés.

La signification exacte d'une liaison dépend du type de forme particulier auquel un matériau ou un ensemble de matériaux est appliqué.

Voici un exemple d'utilisation très simple :

#Inventor V2.1 ascii
Separator {
   Coordinate3 {
      point [ 0 0 0, 1 0 0, 1 1 0 ]
   }
   Material {
      diffuseColor [ 1 0 0, 1 1 0, 0 0 1 ]
   }
   MaterialBinding {
      value PER_VERTEX_INDEXED
   }
   IndexedFaceSet {
      coordIndex [ 0, 1, 2, -1 ]
      materialIndex [ 0, 1, 0 ]
   }
}

Avec SoMaterialBinding::value défini sur PER_VERTEX_INDEXED ci-dessus, les indices de matériaux seront pris dans le champ SoIndexedFaceSet::materialIndex lors du rendu.

Si SoMaterialBinding::value était défini sur PER_VERTEX_INDEXED comme ci-dessus, et que SoIndexedFaceSet::materialIndex était indéfini ou vide, les indices seraient implicitement pris dans le champ SoIndexedFaceSet::coordIndex.

Si SoMaterialBinding::value est défini sur PER_VERTEX, les couleurs seront récupérées de manière monotone croissante à partir du champ SoMaterial::diffuseColor, en commençant à l'indice 0.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

MaterialBinding {
    value OVERALL
}

Documentation Énumération Membres

enum SoMaterialBinding::Binding

Énumération des types de liaison de matériaux disponibles.

Énumérateur

OVERALL
Applique le même matériau à la forme complète.
PER_PART
Récupère un nouveau matériau du pool de valeurs de matériaux pour chaque partie de la forme, où la définition d'une partie dépend du type de forme.

Les matériaux sont récupérés à partir de l'indice 0 et suivants, en incrémentant l'indice dans le pool de matériaux de 1 pour chaque nouvelle partie dans l'ordre défini par le type de forme particulier.

Note d'importante portabilité : il était précédemment autorisé avec la bibliothèque SGI Inventor de fournir trop peu de couleurs par rapport au nombre de parties des formes ultérieures dans le graphe de scène. La coloration cyclait alors à travers les couleurs disponibles.

Depuis SGI Open Inventor v2.1, cela a été interdit ; il faut fournir suffisamment de couleurs pour toutes les parties, sinon le comportement sera non spécifié (il est probable que cela provoque un crash, en fait). Notez que le livre Inventor Mentor contient une description du comportement *ancien* et *invalide* dans le Chapitre 5, section "Binding Nodes" (milieu de la page 128 de la 10ème impression).

PER_PART_INDEXED
Récupère un nouveau matériau du pool de valeurs de matériaux pour chaque partie de la forme, où la définition d'une partie dépend du type de forme.

Les matériaux sont récupérés par les valeurs d'indice définies par la forme.

PER_FACE
Récupère un nouveau matériau du pool de valeurs de matériaux pour chaque face polygonale de la forme.

Les matériaux sont récupérés à partir de l'indice 0 et suivants, en incrémentant l'indice dans le pool de matériaux de 1 pour chaque nouvelle face du nœud de forme.

Notez que les faces individuelles après tessellation de formes complexes (comme les nœuds SoCylinder) ne sont *pas* considérées comme des entités séparées, et donc cette liaison sera traitée de la même manière que SoMaterialBinding::PER_PART pour celles-ci.

PER_FACE_INDEXED
Récupère un nouveau matériau du pool de valeurs de matériaux pour chaque face polygonale de la forme.

Les matériaux sont récupérés par les valeurs d'indice définies par la forme.

Notez que les faces individuelles après tessellation de formes complexes (comme les nœuds SoCylinder) ne sont *pas* considérées comme des entités séparées, et donc cette liaison sera traitée de la même manière que SoMaterialBinding::PER_PART_INDEXED pour celles-ci.

PER_VERTEX
Récupère un nouveau matériau du pool de valeurs de matériaux pour chaque vertex* de polygone, ligne ou point de la forme.

Les matériaux sont récupérés à partir de l'indice 0 et suivants, en incrémentant l'indice dans le pool de matériaux de 1 pour chaque nouveau vertex du nœud de forme.

PER_VERTEX_INDEXED
Récupère un nouveau matériau du pool de valeurs de matériaux pour chaque vertex* de polygone, ligne ou point de la forme.

Les matériaux sont récupérés par les valeurs d'indice définies par la forme.

DEFAULT
Obsolète. N'utilisez pas cette valeur.
NONE
Obsolète. N'utilisez pas cette valeur.
