Description détaillée

La classe SoSFBox2s est un conteneur pour un vecteur SbBox2s.

Ce champ est utilisé lorsque des nœuds, des moteurs ou d'autres conteneurs de champs ont besoin de stocker une boîte.

Notez que cette classe est une extension pour Coin, et elle n'est pas disponible dans l'API originale d'Open Inventor v2.1.
Depuis

Coin 2.5
