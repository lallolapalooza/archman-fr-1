Description détaillée

La classe SoMaterialBundle simplifie la gestion des matériaux.

Chaque nœud de forme doit créer (sur la pile) une instance de cette classe et appeler sendFirst() avant d'envoyer quoi que ce soit à GL. Pendant le rendu, send() doit être utilisé pour envoyer les valeurs de matériau à GL.

Documentation fonctions membres

void SoMaterialBundle::setUpMultiple (void )

Non utilisé actuellement. Il est uniquement fourni pour la conformité OIV.

void SoMaterialBundle::sendFirst (void )

Envoie les valeurs de matériau initiales à GL. Doit être effectué une fois dans tous les nœuds de géométrie avant le début du rendu.

void SoMaterialBundle::forceSend (const int index)

Enverra le matériau à GL même si index est égal à l'index courant.

Fourni pour la compatibilité avec l'API SGI Open Inventor v2.1.

SbBool SoMaterialBundle::isColorOnly (void ) const

Retourne TRUE si le modèle d'éclairage courant est BASE_COLOR.

void SoMaterialBundle::send (const int index, const SbBool betweenbeginend)

Envoie les valeurs de matériau avec l'index index à GL. Testera si l'index courant est égal à index avant d'envoyer.

betweenbeginend doit être TRUE si votre programme se trouve entre un glBegin() et un glEnd() (il est illégal de changer le stipple de polygones entre un glBegin() et un glEnd()).
