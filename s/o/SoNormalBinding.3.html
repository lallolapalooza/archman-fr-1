Description Détaillée

La classe SoNormalBinding est un nœud permettant de spécifier les liaisons de normales.

Utilisez les nœuds de ce type pour spécifier comment mapper les vecteurs normaux des nœuds SoNormal dans le graphe de scène aux nœuds de forme.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

NormalBinding {
    value PER_VERTEX_INDEXED
}

Documentation des Énumérations des Membres

enum SoNormalBinding::Binding

Énumération des types de mappages disponibles. Voir la documentation du nœud SoMaterialBinding pour une explication des différentes valeurs.

Notez que SoNormalBinding::DEFAULT et SoNormalBinding::NONE ont été obsolètes et sont tous deux mappés à SoNormalBinding::PER_VERTEX_INDEXED.

Énumérateur

PER_PART
Obtient une nouvelle normale du pool de valeurs normales pour chaque partie de la forme, où la définition d'une partie dépend du type de forme.

Les normales sont récupérées à partir de l'index 0 et suivants, incrémentant l'index dans le pool de normales de 1 pour chaque nouvelle partie dans l'ordre défini par le type de forme particulier.

Note de portabilité importante : il était auparavant autorisé avec la bibliothèque SGI Inventor de fournir trop peu de couleurs par rapport au nombre de parties des formes suivantes dans le graphe de scène. La coloration cyclait alors à travers les couleurs disponibles.

Depuis SGI Open Inventor v2.1, cela a été interdit, bien que -- assez de normales pour toutes les parties doivent être fournies, sinon le comportement sera indéterminé (il est probable qu'il provoque un crash, en fait). Notez que le livre Inventor Mentor contient une description de l'ancien comportement *invalide* dans le chapitre 5, section "Binding Nodes" (au milieu de la page 128 de la 10ème impression).

PER_PART_INDEXED
Obtient une nouvelle normale du pool de valeurs normales pour chaque partie de la forme, où la définition d'une partie dépend du type de forme.

Les normales sont récupérées par les paramètres d'index de la forme.

PER_FACE
Obtient une nouvelle normale du pool de valeurs normales pour chaque face* de polygone de la forme.

Les normales sont récupérées à partir de l'index 0 et suivants, incrémentant l'index dans le pool de normales de 1 pour chaque nouvelle face du nœud de forme.

Notez que les faces individuelles après tessellation de formes complexes (comme les nœuds SoCylinder) ne sont pas considérées comme des entités distinctes, et donc cette liaison sera traitée de la même manière que SoNormalBinding::PER_PART pour celles-ci.

PER_FACE_INDEXED
Obtient une nouvelle normale du pool de valeurs normales pour chaque face* de polygone de la forme.

Les normales sont récupérées par les paramètres d'index de la forme.

Notez que les faces individuelles après tessellation de formes complexes (comme les nœuds SoCylinder) ne sont pas considérées comme des entités distinctes, et donc cette liaison sera traitée de la même manière que SoNormalBinding::PER_PART_INDEXED pour celles-ci.

PER_VERTEX
Obtient une nouvelle normale du pool de valeurs normales pour chaque vértice* de polygone, ligne ou point de la forme.

Les normales sont récupérées à partir de l'index 0 et suivants, incrémentant l'index dans le pool de normales de 1 pour chaque nouveau vértice du nœud de forme.

PER_VERTEX_INDEXED
Obtient une nouvelle normale du pool de valeurs normales pour chaque vértice* de polygone, ligne ou point de la forme.

Les normales sont récupérées par les paramètres d'index de la forme.

DEFAULT
Obsolète. N'utilisez pas cette valeur.
NONE
Obsolète. N'utilisez pas cette valeur.
