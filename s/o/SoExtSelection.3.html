Description détaillée

La classe SoExtSelection peut être utilisée pour une fonctionnalité de sélection étendue.

Cette classe vous permet de sélectionner de la géométrie en spécifiant un lasso (un polygone) ou un rectangle à l'écran. Lorsque des objets sont sélectionnés, vous recevez les mêmes callbacks que pour le nœud SoSelection.

L'interface de programmation d'application de cette classe est quelque peu complexe, en raison de sa fonctionnalité non triviale. Pour voir un exemple d'utilisation *étendu* du nœud SoExtSelection, nous vous conseillons de consulter l'application d'exemple "extselection" dans le répertoire "nodes/" du dépôt Mercurial de SoGuiExamples. Des informations supplémentaires et des liens pour télécharger et compiler ce module devraient être disponibles sur github.com/coin3d/soguiexamples.

Cette classe de nœud est une extension par rapport à l'API originale d'Inventor SGI v2.1. Elle est basée sur l'API d'Inventor de VSG (anciennement TGS) SoExtSelection, et nous visons à être entièrement compatibles avec ce nœud afin de permettre aux utilisateurs de passer de l'utilisation d'Inventor Coin à VSG. Veuillez nous contacter si vous trouvez des divergences entre SoExtSelection de Coin et SoExtSelection de VSG.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

ExtSelection {
    renderCaching AUTO
    boundingBoxCaching AUTO
    renderCulling AUTO
    pickCulling AUTO
    policy SHIFT
    lassoType NOLASSO
    lassoPolicy FULL_BBOX
    lassoMode ALL_SHAPES
}

enum SoExtSelection::LassoType

Enum pour le type de lasso de sélection.

Énumérateur

NOLASSO
Fait en sorte que ce nœud se comporte comme un nœud SoSelection normal.
LASSO
Sélectionne les objets à l'aide d'un lasso. Les sélections peuvent être interrompues par l'utilisateur final en appuyant sur la touche FIN du clavier.
RECTANGLE
Sélectionne les objets à l'aide d'un rectangle. Les sélections peuvent être interrompues par l'utilisateur final en appuyant sur la touche FIN du clavier.

enum SoExtSelection::LassoPolicy

Enum pour spécifier comment les objets sont sélectionnés.

Énumérateur

FULL_BBOX
La boîte englobante entière doit être à l'intérieur du lasso/rectangle.
PART_BBOX
Une partie de la boîte englobante doit intersecter le lasso/rectangle.
FULL
Toutes les primitives doivent être entièrement à l'intérieur du lasso/rectangle.
PART
Une primitive doit intersecter le lasso/rectangle.

enum SoExtSelection::LassoMode

Enum pour spécifier le mode de sélection.

Énumérateur

ALL_SHAPES
Toutes les primitives à l'intérieur du lasso/rectangle seront sélectionnées.
VISIBLE_SHAPES
Toutes les primitives *visibles* à l'intérieur du lasso/rectangle seront sélectionnées.

Spécifie si les plans de superposition doivent être utilisés pour rendre le lasso.

Cette méthode a été obsolète dans Coin, car la plupart des cartes graphiques ne prennent pas en charge le rendu de superposition. Description

Ce nœud est utilisé pour réaliser des sélections dans une scène.

Il utilise un lasso ou un rectangle pour délimiter la zone de sélection.

Le comportement de sélection peut être personnalisé à l'aide des callbacks fournis par ce nœud.

void SoExtSelection::GLRenderBelowPath (SoGLRenderAction * action) [virtual]

SGI Open Inventor v2.1 a rendu obsolète le support de SoGLRenderAction::addMethod(). Au lieu de cela, GLRender() peut être appelé directement, et pour optimiser le parcours, le nœud SoSeparator appelle GLRenderBelowPath chaque fois que le code de chemin est BELOW_PATH ou NO_PATH (le code de chemin est garanti de ne pas changer). Pour être compatible avec Inventor de SGI (et par conséquent aussi avec celui de TGS), nous avons choisi de suivre leur implémentation à cet égard.

SoSeparator::GLRenderBelowPath() ne parcourt pas ses enfants à l'aide de SoChildList::traverse(), mais appelle GLRenderBelowPath() directement pour tous ses enfants.

void SoExtSelection::setLassoFilterCallback (SoLassoSelectionFilterCB * f, void * userdata = NULL, const SbBool callonlyifselectable = TRUE)

Le callback de filtrage de sélection par lasso est appelé lorsqu'un nœud est sur le point d'être sélectionné, et permet au programmeur de l'application de retourner un nouveau chemin à utiliser lors de la sélection. Le nouveau chemin retourné ne doit pas être référencé. SoExtSelection le référencera et le déréférencera.

Pour annuler la sélection, retournez NULL depuis le callback.

Si callonlyifselectable est TRUE, le callback ne sera invoqué que lorsque le chemin vers le nouveau nœud passera par le nœud SoExtSelection.

Cette méthode est spécifique à Coin et ne fait pas partie de TGS OIV.

void SoExtSelection::setTriangleFilterCallback (SoExtSelectionTriangleCB * func, void * userdata = NULL)

Définit le callback qui sera appelé pour chaque triangle à l'intérieur du lasso/rectangle lors de la sélection.

Le callback doit retourner FALSE s'il souhaite continuer à être invoqué. Lorsque le callback retourne TRUE, l'objet/la forme est sélectionné(e) et aucun autre callback ne sera invoqué pour cet objet.

Documentation des données membres

SoSFEnum SoExtSelection::lassoType

Champ pour le type de lasso. La valeur par défaut est SoExtSelection::NOLASSO.

Les sélections de type SoExtSelection::RECTANGLE ou SoExtSelection::LASSO peuvent être annulées par l'utilisateur en appuyant sur la touche FIN (END) du clavier.

SoSFEnum SoExtSelection::lassoPolicy

Champ pour la politique de lasso. La valeur par défaut est FULL_BBOX.

SoSFEnum SoExtSelection::lassoMode

Champ pour le mode de lasso. La valeur par défaut est ALL_SHAPES.

Définissez ce champ sur VISIBLE_SHAPES pour que seules les primitives visibles depuis le point de vue actuel soient sélectionnées.
