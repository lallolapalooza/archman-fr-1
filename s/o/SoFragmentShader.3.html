Description Détaillée

La classe SoFragmentShader est utilisée pour configurer les programmes de shaders de fragments.

Voir Shaders dans Coin pour plus d'informations sur la configuration d'un graphe de scène avec des shaders.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

FragmentShader {
  isActive TRUE
  sourceType FILENAME
  sourceProgram ""
  parameter []
}
