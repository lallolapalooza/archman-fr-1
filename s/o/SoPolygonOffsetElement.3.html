NAME #

SoPolygonOffsetElement — element that controls polygon offset

SYNOPSIS # 

#include <Inventor/nodes/SoPolygonOffsetElement.h>

enum SoPolygonOffsetElement::Style {
    FILLED,
    LINE,
    POINT
};

class SoPolygonOffsetElement : public SoReplacedElement

    
                   protected: virtual void  setElt(float factor, float units, Style styles, SbBool on)
                   protected: Style  style
                   protected: SbBool  active
                   protected: float  offsetfactor
                   protected: float  offsetunits
    
  

    

    

     

      DESCRIPTION
      
       #
      
     

     

      This element controls the polygon offset rendering state. Polygon offset
      is used to render surfaces in order to avoid z-fighting. Z-fighting is
      an artifact that occurs when two polygons are very close to each other
      in depth, causing flickering and visual glitches.
     

     

      Polygon offset works by adding a small offset to the depth value of each
      fragment when rendering. The offset is calculated based on the polygon's
      slope and a specified units value.
     

     

      The element has the following parameters:
     

     
    
      
  • 
       
    
        factor: A float value that scales the polygon's slope.
       
    
      
    • 
      
  • 
       
    
        units: A float value that is multiplied by the smallest representable value on the screen.
       
    
      
    • 
      
  • 
       
    
        styles: A bitmask specifying which primitives (fill, line, point) the offset should apply to.
       
    
      
    • 
      
  • 
       
    
        on: A boolean indicating whether polygon offset is enabled.
       
    
      
    • 
     

     

      When polygon offset is enabled, the depth value for each fragment is
      adjusted by the following formula:
     

     
depth = z + factor * ε + units * slope


     

      where
     

     
    
      
  • 
       
    
        z is the original depth value of the fragment.
       
    
      
    • 
      
  • 
       
    
        factor is the slope-scaled depth offset.
       
    
      
    • 
      
  • 
       
    
        ε is an implementation-specific small value that ensures fragments at the same depth are offset.
       
    
      
    • 
      
  • 
       
    
        units is the constant depth offset.
       
    
      
    • 
      
  • 
       
    
        slope is the partial derivative of depth with respect to window coordinates (i.e., the polygon's slope).
       
    
      
    • 
     

     

      The styles parameter can be a combination of
      FILLED, LINE, and
      POINT to enable polygon offset for different
      primitive types.

       SoPolygonOffsetElement::Style
       
        #
       
      

      

       Enumerates the different polygon primitive types for which polygon offset
       can be enabled.
      

      

       

        FILLED

        Polygon offset applies to line segments.

        Polygon offset applies to points.
