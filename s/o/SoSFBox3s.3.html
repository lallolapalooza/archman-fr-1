Description Détaillée

La classe SoSFBox3s est un conteneur pour un vecteur SbBox3s.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs ont besoin de stocker une boîte.

Veuillez noter que cette classe est une extension pour Coin et n'est pas disponible dans l'API originale d'Open Inventor v2.1 de SGI.

Detailed Description

This field is used to store a 3D bounding box, defined by two 3D vectors of short coordinates: the minimum corner and the maximum corner.

The coordinate values are limited to the range of short integers.
