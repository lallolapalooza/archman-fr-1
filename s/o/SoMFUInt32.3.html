Description détaillée

La classe SoMFUInt32 est un conteneur pour les entiers non signés de 32 bits.

Ce champ est utilisé lorsque les nœuds, moteurs ou autres conteneurs de champs doivent stocker un groupe de plusieurs valeurs entières non signées de 32 bits.

Ce champ prend en charge le partage de données d'application via une méthode setValuesPointer(). Voir la documentation de SoMField pour des informations sur l'utilisation de cette fonction.

Description Détaillée

Champ de champs d'entiers non signés 32 bits.

Ce type de champ est utilisé pour contenir un tableau d'entiers non signés 32 bits. La taille du tableau peut être comprise entre zéro et un nombre quelconque, bien que la plupart des champs de champs de valeurs limitent la taille à 1. Consultez la documentation de la classe de base SoMField pour les méthodes qui vous permettent de manipuler la taille et le contenu de ce champ.

Les constructeurs initialisent le champ. Le premier est un champ vide. Le deuxième est un champ d'une seule valeur, initialisé à value. Le troisième est une copie d'un autre champ. Le quatrième est un champ de taille size, initialisé à partir du tableau value.

Le destructeur est virtuel.
