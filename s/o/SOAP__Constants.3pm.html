SOAP::Constants(3) Documentation Perl fournie par l'utilisateur SOAP::Constants(3)

NOM

SOAP::Constants - SOAP::Lite fournit plusieurs variables pour permettre aux programmeurs et aux utilisateurs de modifier le comportement de SOAP::Lite de manière spécifique.

DESCRIPTION

Un certain nombre de valeurs « constantes » sont fournies par le biais de cet espace de noms. Les valeurs ne sont pas des constantes au sens le plus strict du terme ; le but des valeurs détaillées ici est de permettre à l'application de les modifier si elle souhaite altérer le comportement spécifique gouverné.

CONSTANTES

$NE_PAS_UTILISER_XML_PARSEUR

Le paquet SOAP::Lite tente de localiser et d'utiliser le paquet XML::Parser, en se rabattant sur un analyseur interne en pur Perl en son absence. Ce paquet est un analyseur rapide, basé sur l'analyseur Expat développé par James Clark. Si l'application définit cette valeur à 1, aucune tentative ne sera faite pour localiser ou utiliser XML::Parser. Il y a plusieurs raisons pour lesquelles vous pourriez choisir de faire cela. Si le paquet ne sera jamais disponible, il n'y a aucune raison d'effectuer le test. La définition de ce paramètre est moins coûteuse en temps que le test du paquet. De plus, le code XML::Parser est lié aux bibliothèques Expat pour le langage C. Dans certains environnements, cela pourrait poser un problème lorsqu'il est mélangé avec d'autres applications qui peuvent être liées à une version différente des mêmes bibliothèques. C'était le cas autrefois avec certaines combinaisons d'Apache, mod_perl et XML::Parser.

$NE_PAS_UTILISER_CHARSET

À moins que ce paramètre ne soit défini à 1, les en-têtes Content-Type sortants incluront la spécification du jeu de caractères utilisé pour l'encodage du message lui-même. Cependant, tous les points d'extrémité (client ou serveur) ne pourront pas correctement traiter ces données dans l'en-tête de contenu. Si vous traitez avec un point d'extrémité qui s'attend à faire une examen plus littéral de l'en-tête dans son ensemble (par opposition à une analyse complète), ce paramètre peut s'avérer utile.

$NE_PAS_VERIFIER_CONTENT_TYPE

Le type de contenu lui-même pour un message SOAP est plutôt clairement défini, et dans la plupart des cas, une application n'aurait aucune raison de désactiver le test de cet en-tête. Cela étant dit, le type de contenu pour SOAP 1.2 n'est encore qu'un brouillon recommandé, et des points d'extrémité mal codés pourraient envoyer des messages valides avec des en-têtes Content-Type invalides. Bien que la chose « juste » à faire serait de rejeter de tels messages, ce n'est pas toujours une option. La définition de ce paramètre à 1 permet à la boîte à outils d'ignorer le test du type de contenu.

$PATCH_HTTP_KEEPALIVE

Le module de transport HTTP de SOAP::Lite tente de fournir un simple patch à LWP::Protocol pour activer HTTP Keep Alive. Par défaut, ce patch est désactivé. Si vous souhaitez activer le patch expérimental, modifiez la constante comme suit :

$SOAP::Constants::PATCH_HTTP_KEEPALIVE = 1;
