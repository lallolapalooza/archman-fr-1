Description Détaillée

La classe SoJackDragger est un dragger que vous pouvez traduire, faire pivoter et mettre à l'échelle.

Voici à quoi ressemble le dragger avec sa géométrie par défaut à l'état inactif :

La translation est effectuée avec ce dragger en sélectionnant la boîte plate transparente (translation "x-z") ou la partie centrale solide de l'axe (translation "y"). Maintenez la touche MAJ enfoncée tout en translatant en x-z pour vous contraindre à l'un des axes principaux.

Des opérations d'échelle uniformes peuvent être effectuées en faisant glisser l'un des 6 cubes. Des opérations d'échelle non uniformes ne peuvent pas être effectuées avec ce dragger.

Les rotations sont déclenchées en cliquant et en faisant glisser les parties linéaires des 3 "axes" principaux de la géométrie du dragger.

NB : La manière de faire pivoter le dragger peut être un peu intuitive pour l'utilisateur final. Si le dragger doit être utilisé tel quel, une bonne documentation doit être ajoutée à votre application. Une autre solution consiste à modifier la géométrie pour augmenter l'affordance du dragger. Voir la documentation de SoDragger sur la façon de modifier la géométrie d'un dragger.

Une "prise de vue d'action" du SoJackDragger utilisé dans un SoClipPlaneManip :

Le nom "Jack dragger" provient probablement du fait que ce dragger a été implémenté par SGI pour interagir avec un modèle de type "jack-in-the-box" à l'époque de l'historique d'Inventor.

Pour plus de commodité pour le programmeur, ce dragger est entièrement encapsulé dans des instances de la classe SoJackManip. Le manipulateur SoClipPlaneManip utilise également ce dragger, pour contrôler un nœud SoClipPlane.

void SoJackDragger::setDefaultOnNonWritingFields (void ) [protected], [virtual]

(Note : cette méthode n'est généralement pas d'intérêt pour le développeur d'applications qui ne souhaite pas étendre la bibliothèque avec de nouveaux kits de nœuds ou classes de dragger. Si c'est le cas, voir les informations dans la documentation de la classe SoBaseKit.)

Ceci est une méthode virtuelle, et le code qu'elle contient doit appeler SoField::setDefault() avec l'argument TRUE pour les champs qui ne doivent pas être écrits lors de l'exportation du graphique.

Cela est généralement fait lorsque :

1.
la valeur du champ est NULL et le champ est NULL par défaut
2.
c'est un nœud de type SoGroup ou SoSeparator sans enfants
3.
c'est un nœud de type liste et il a un conteneur SoGroup ou SoSeparator sans enfants
4.
c'est un nœud non-feuille de type SoGroup et tous les champs sont à leurs valeurs par défaut

Les héritiers doivent surcharger cette méthode pour effectuer une configuration supplémentaire pour les nouveaux champs membres. Ils doivent se rappeler d'appeler la méthode setDefaultOnNonWritingFields() de leur héritage vers le haut.

Ce champ est continuellement mis à jour pour contenir la rotation du vecteur de direction actuel du dragger.

SoSFVec3f SoJackDragger::translation

Est continuellement mis à jour pour contenir la translation actuelle depuis l'origine locale du dragger.

Le développeur d'applications qui applique ce dragger doit connecter les champs pertinents de la scène à ce champ afin qu'il suive le dragger.

SoSFVec3f SoJackDragger::scaleFactor

Est continuellement mis à jour pour contenir le vecteur d'échelle actuel le long des axes X, Y et Z.

Seul un mise à l'échelle uniforme est possible avec le SoJackDragger, par conséquent les trois composantes du vecteur seront maintenues égales.
