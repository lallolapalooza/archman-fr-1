Detailed Description

La classe SoVRMLInterpolator est une classe abstraite de base pour tous les noeuds interpolateurs dans la spécification VRML97. Les interpolateurs sont utilisés pour générer des valeurs interpolées au fil du temps, généralement en réponse à des événements de chronométrage. Les classes dérivées fournissent des types spécifiques d'interpolation pour des types de données tels que les couleurs, les coordonnées, les flottants, les vecteurs, etc.

Les interpolateurs VRML97 se composent de trois champs principaux :

  • key : Un tableau de valeurs flottantes qui spécifie les moments où les valeurs fournies dans le champ value doivent être atteintes. Ces valeurs doivent être comprises entre 0.0 et 1.0, inclusivement, et doivent être triées par ordre croissant.
  • value : Un tableau de valeurs dont le type dépend de l'interpolateur spécifique. Ce tableau contient les valeurs cibles qui seront interpolées.
  • value_changed : Un champ d'événement de sortie qui émet la valeur interpolée lorsque le temps change.

Chaque interpolateur implémente sa propre logique d'interpolation basée sur les valeurs fournies dans les champs key et value. Lorsque la chronologie de la scène progresse, l'interpolateur calcule la valeur actuelle en fonction de sa position par rapport aux clés et émet cette valeur via le champ value_changed.
