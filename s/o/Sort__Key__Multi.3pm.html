NOM

Sort::Key::Multi - tris simples à clés multiples

SYNOPSIS

use Sort::Key::Multi qw(sikeysort);
my @data = qw(foo0 foo1 bar34 bar0 bar34 bar33 doz4)
my @sisorted = sikeysort { /(\w+)(\d+)/} @data;

DESCRIPTION

Sort::Key::Multi crée des sous-programmes de tri à clés multiples et les exporte dans le paquet appelant.

Les noms des trieurs sont de la forme "xxxkeysort" ou "xxxkeysort_inplace", où "xxx" détermine le nombre et les types des clés comme suit :

+ "i" indique une clé entière, "u" indique une clé entière non signée, "n" indique une clé numérique, "s" indique une clé de chaîne de caractères et "l" indique une clé de chaîne de caractères qui respecte la configuration de l'ordre local.

+ Les caractères de type peuvent être précédés par "r" pour indiquer l'ordre inverse.

+ Un nombre suivant un caractère de type indique que le type de clé doit être répété autant de fois (par exemple "i3" est équivalent à "iii" et "rs2" est équivalent à "rsrs").

+ Les tirets bas ("_") peuvent être utilisés librement entre les indicateurs de type.

Par exemple :

use Key::Sort::Multi qw(iirskeysort
                        i2rskeysort
                        i_i_rs__keysort
                        i2rs_keysort);

exporte dans le paquet appelant quatre fonctions de tri identiques qui prennent deux clés entières triées en ordre croissant et une clé de chaîne de caractères triée en ordre décroissant.

Les trieurs générés prennent comme premier argument un sous-programme qui est utilisé pour extraire les clés des valeurs qui sont passées dans $_, par exemple :

my @data = qw(1.3.foo 1.3.bar 2.3.bar 1.4.bar 1.7.foo);
my @s = i2rs_keysort { split /\./, $_ } @data;

VOIR AUSSI

Pour un générateur de trieurs à clés multiples plus général, voir Sort::Key::Maker.
