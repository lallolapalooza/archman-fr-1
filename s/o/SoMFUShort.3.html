Description Détaillée

La classe SoMFUShort contient des valeurs entières non signées de type short.

Ce champ supporte l'échange de données applicatives via la méthode setValuesPointer(). Pour obtenir des informations sur l'utilisation de cette méthode, consultez la documentation de SoMField.

Ce champ est utilisé là où les nœuds, les moteurs ou d'autres conteneurs de champs ont besoin de stocker un groupe de valeurs de type unsigned short.
