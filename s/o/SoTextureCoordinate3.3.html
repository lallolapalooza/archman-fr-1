Descripción Detallada

La clase SoTextureCoordinate3 contiene un conjunto de coordenadas para el mapeo de texturas 2D.

Cuando se encuentra un nodo de este tipo durante el recorrido, las coordenadas que contiene se colocarán en la pila de estado. Algunos nodos de forma pueden utilizar estas coordenadas para controlar explícita y detalladamente cómo se mapean las texturas 3D.

(Si no se utilizan texturas 3D sin ningún SoTextureCoordinate3 en el árbol de escena precedente a un nodo de forma, los tipos de forma tienen valores por defecto. Por lo tanto, SoTextureCoordinate3 son útiles solo si no estás satisfecho con el mapeo por defecto.)

Nota: Un nodo SoTextureCoordinate3 reemplazará las coordenadas ya existentes en el estado (si las hubiera).

Tener en cuenta que esta clase es una extensión de Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Documentación Datos Miembro

SoMFVec3f SoTextureCoordinate3::point

El conjunto de coordenadas de textura 3D. El valor por defecto del campo es un conjunto vacío.

Las coordenadas de textura se especifican generalmente en coordenadas normalizadas, es decir, en el rango [0, 1]. Las coordenadas fuera del rango [0, 1] pueden usarse para repetir la textura sobre una superficie.
