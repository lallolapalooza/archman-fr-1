Description Détaillée

La classe SoVRMLElevationGrid représente une grille d'élévation.

La documentation détaillée de la classe est prise verbatim de la norme VRML97 (ISO/IEC 14772-1:1997). Elle appartient au Consortium The Web3D Consortium et est utilisée avec sa permission :

ElevationGrid {  
  eventIn      MFFloat  set_height  
  exposedField SFNode   color             NULL  
  exposedField SFNode   normal            NULL  
  exposedField SFNode   texCoord          NULL  
  field        MFFloat  height            []      # (-inf,inf)  
  field        SFBool   ccw               TRUE  
  field        SFBool   colorPerVertex    TRUE  
  field        SFFloat  creaseAngle       0       # [0,inf]  
  field        SFBool   normalPerVertex   TRUE  
  field        SFBool   solid             TRUE  
  field        SFInt32  xDimension        0       # [0,inf)  
  field        SFFloat  xSpacing          1.0     # (0,inf)  
  field        SFInt32  zDimension        0       # [0,inf)  
  field        SFFloat  zSpacing          1.0     # (0,inf)  
}

Le nœud ElevationGrid spécifie une grille uniforme de coupe dans le plan Y=0 du système de coordonnées local. La géométrie de ce nœud est celle d'une grille rectangulaire de hauteur variable dans le plan Y=0. La géométrie du nœud est une grille rectangulaire uniforme avec une hauteur variable dans le plan Y=0 du système de coordonnées local.

ElevationGrid Node

ElevationGrid Node

L'ElevationGrid permet de créer un objet de grille tridimensionnel dont la hauteur est définie par une matrice de valeurs scalaires qui spécifient la hauteur d'une surface au-dessus de chaque point de la grille.

Les champs xDimension et zDimension indiquent le nombre d'éléments de la matrice de hauteurs de la grille dans les directions X et Z. Les deux champs xDimension et zDimension doivent être supérieurs ou égaux à zéro. Si l'un des champs xDimension ou zDimension est inférieur à deux, l'ElevationGrid ne contient aucun quadrilatère. Les emplacements des sommets pour les rectangles sont définis par le champ height et les champs xSpacing et zSpacing :

•
Le champ height est une matrice de xDimension par zDimension de valeurs scalaires représentant la hauteur au-dessus de la grille pour chaque sommet.
•
Les champs xSpacing et zSpacing indiquent la distance entre les sommets dans les directions X et Z respectivement, et doivent être supérieurs à zéro.

Ainsi, le sommet correspondant au point P[i, j] sur la grille est placé à :

  P[i,j].x = xSpacing × i
  P[i,j].y = height[ i + j × xDimension]
  P[i,j].z = zSpacing × j
  où 0 <= i < xDimension et 0 <= j < zDimension, et
  P[0,0] est à une hauteur de height[0] unités au-dessus/en dessous de
  l'origine du système de coordonnées local.

L'événement set_height (eventIn) permet de modifier le champ MFFloat height pour supporter les nœuds ElevationGrid animés.

Le champ color spécifie les couleurs par sommet ou par quadrilatère pour le nœud ElevationGrid, en fonction de la valeur de colorPerVertex. Si le champ color est NULL, le nœud ElevationGrid est rendu avec les attributs généraux du nœud Shape qui l'entoure (voir 4.14, Modèle d'éclairage).

Le champ colorPerVertex détermine si les couleurs spécifiées dans le champ color sont appliquées à chaque sommet ou à chaque quadrilatère du nœud ElevationGrid. Si colorPerVertex est FALSE et que le champ color n'est pas NULL, le champ color doit spécifier un nœud Color contenant au moins (xDimension-1)×(zDimension-1) couleurs ; une pour chaque quadrilatère, ordonnée comme suit :

  QuadColor[i,j] = Color[ i + j × (xDimension-1)]
  où 0 <= i < xDimension-1 et 0 <= j < zDimension-1, et
  QuadColor[i,j] est la couleur du quadrilatère défini par
  height[i+j×xDimension], height[(i+1)+j×xDimension],
  height[(i+1)+(j+1)×xDimension] et height[i+(j+1)×xDimension]

Si colorPerVertex est TRUE et que le champ color n'est pas NULL, le champ color doit spécifier un nœud Color contenant au moins xDimension × zDimension couleurs ; une pour chaque sommet, ordonnée comme suit :

  VertexColor[i,j] = Color[ i + j × xDimension]
  où 0 <= i < xDimension et 0 <= j < zDimension, et
  VertexColor[i,j] est la couleur du sommet défini par
  height[i+j×xDimension]

Le champ normal spécifie les normales par sommet ou par quadrilatère pour le nœud ElevationGrid. Si le champ normal est NULL, le navigateur génère automatiquement les normales, en utilisant le champ creaseAngle pour déterminer si et comment les normales sont lissées sur la surface (voir 4.6.3.5, Champ creaseAngle).

Le champ normalPerVertex détermine si les normales sont appliquées à chaque sommet ou à chaque quadrilatère du nœud ElevationGrid en fonction de la valeur de normalPerVertex. Si normalPerVertex est FALSE et que le nœud normal n'est pas NULL, le champ normal doit spécifier un nœud Normal contenant au moins (xDimension-1)×(zDimension-1) normales ; une pour chaque quadrilatère, ordonnée comme suit :

  QuadNormal[i,j] = Normal[ i + j × (xDimension-1)]
  où 0 <= i < xDimension-1 et 0 <= j < zDimension-1, et
  QuadNormal[i,j] est la normale du quadrilatère
  défini par height[i+j×xDimension], height[(i+1)+j×xDimension],
  height[(i+1)+(j+1)×xDimension] et height[i+(j+1)×xDimension]

Si normalPerVertex est TRUE et que le champ normal n'est pas NULL, le champ normal doit spécifier un nœud Normal contenant au moins xDimension × zDimension normales ; une pour chaque sommet, ordonnée comme suit :

  VertexNormal[i,j] = Normal[ i + j × xDimension]
  où 0 <= i < xDimension et 0 <= j < zDimension, et
  VertexNormal[i,j] est la normale du sommet défini par
  height[i+j×xDimension]

Le champ texCoord spécifie les coordonnées de texture par sommet pour le nœud ElevationGrid. Si texCoord est NULL, des coordonnées de texture par défaut sont appliquées à la géométrie. Les coordonnées de texture par défaut vont de (0,0) au premier sommet à (1,1) au dernier sommet. La coordonnée de texture S est alignée avec l'axe X positif, et la coordonnée de texture T avec l'axe Z positif. Si texCoord n'est pas NULL, il doit spécifier un nœud TextureCoordinate contenant au moins (xDimension)×(zDimension) coordonnées de texture ; une pour chaque sommet, ordonnée comme suit :

  VertexTexCoord[i,j] = TextureCoordinate[ i + j × xDimension]
  où 0 <= i < xDimension et 0 <= j < zDimension, et
  VertexTexCoord[i,j] est la coordonnée de texture du sommet
  défini par height[i+j×xDimension]

Les champs ccw, solid et creaseAngle sont décrits dans la section 4.6.3, Formes et géométrie. Par défaut, les quadrilatères sont définis avec un ordonnancement dans le sens inverse des aiguilles d'une montre. Par conséquent, la composante Y de la normale est positive. Définir le champ ccw à FALSE inverse la direction de la normale. L'élimination des faces arrière est activée lorsque le champ solid est TRUE.
