Voici la traduction du contenu en français, en conservant la structure du fichier : La classe SoVRMLTransform est un nœud de groupement qui définit une transformation pour ses enfants. Le document de classe détaillé est repris mot pour mot de la spécification VRML97 (ISO/IEC 14772-1:1997). Il est la propriété du Web3D Consortium et est utilisé avec la permission du Consortium : Transform { eventIn MFNode addChildren eventIn MFNode removeChildren exposedField SFVec3f center 0 0 0 # (-inf,inf) exposedField MFNode children [] exposedField SFRotation rotation 0 0 1 0 # [-1,1],(-inf,inf) exposedField SFVec3f scale 1 1 1 # (0,inf) exposedField SFRotation scaleOrientation 0 0 1 0 # [-1,1],(-inf,inf) exposedField SFVec3f translation 0 0 0 # (-inf,inf) field SFVec3f bboxCenter 0 0 0 # (-inf,inf) field SFVec3f bboxSize -1 -1 -1 # (0,inf) ou -1,-1,-1 } Le nœud Transform est un nœud de groupement qui définit un système de coordonnées pour ses enfants qui est relatif aux systèmes de coordonnées de ses ancêtres. Voir 4.4.4, hiérarchie de transformation (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.4.4)./a>), et 4.4.5, Unités standard et système de coordonnées (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.4.5), pour une description des systèmes de coordonnées et des transformations.

4.6.5, Groupement et nœuds enfants (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.5), fournit une description des champs et des eventIns children, addChildren et removeChildren.

Les champs bboxCenter et bboxSize spécifient une boîte englobante qui contient les enfants du nœud Transform. Il s'agit d'un indice qui peut être utilisé à des fins d'optimisation. Les résultats sont indéfinis si la boîte englobante spécifiée est plus petite que la boîte englobante réelle des enfants à tout moment. Une valeur par défaut pour bboxSize, (-1, -1, -1), implique que la boîte englobante n'est pas spécifiée et, si nécessaire, sera calculée par le navigateur. La boîte englobante doit être suffisamment grande à tout moment pour englober l'union des boîtes englobantes des enfants du groupe ; elle ne doit pas inclure de transformations effectuées par le groupe lui-même (c'est-à-dire que la boîte englobante est définie dans le système de coordonnées local des enfants). Les résultats sont indéfinis si la boîte englobante spécifiée est plus petite que la véritable boîte englobante du groupe. Une description des champs bboxCenter et bboxSize est fournie dans 4.6.4, Boîtes englobantes (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.4).

Les champs translation, rotation, scale, scaleOrientation et center définissent une transformation géométrique 3D composée de (dans l'ordre) :

  • une mise à l'échelle (éventuellement) non uniforme autour d'un point arbitraire ;
  • une rotation autour d'un point et d'un axe arbitraires ;
  • une translation.

Le champ center spécifie un décalage de translation par rapport à l'origine du système de coordonnées local (0,0,0). Le champ rotation spécifie une rotation du système de coordonnées. Le champ scale spécifie une mise à l'échelle non uniforme du système de coordonnées. Les valeurs de scale doivent être supérieures à zéro. Le scaleOrientation spécifie une rotation du système de coordonnées avant la mise à l'échelle (pour spécifier des mises à l'échelle dans des orientations arbitraires). Le scaleOrientation s'applique uniquement à l'opération de mise à l'échelle. Le champ translation spécifie une translation du système de coordonnées.

Étant donné un point 3D P et un nœud Transform, P est transformé en point P' dans le système de coordonnées de son parent par une série de transformations intermédiaires. En notation de transformation matricielle, où C (center), SR (scaleOrientation), T (translation), R (rotation) et S (scale) sont les matrices de transformation équivalentes,

P' = T × C × R × SR × S × -SR × -C × P

Le nœud Transform suivant :

Transform {
  center           C
  rotation         R
  scale            S
  scaleOrientation SR
  translation      T
  children         [...]
}

est équivalent à la séquence imbriquée de :

Transform {
  translation T
  children Transform {
    translation C
    children Transform {
      rotation R
      children Transform {
        rotation SR
        children Transform {
          scale S
          children Transform {
            rotation -SR
            children Transform {
              translation -C
              children [...]
            }
          }
        }
      }
    }
  }
}

Detailed Description

The VRML transform node.

This node defines a transformation (translation, rotation, scale) for its children.
