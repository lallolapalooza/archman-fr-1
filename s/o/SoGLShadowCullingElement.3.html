This element controls shadow culling for OpenGL rendering.

Member Function Documentation

static void enable (SoState * state, int32_t enable)

Enables or disables shadow culling.

When enable is non-zero, shadow culling is enabled. When it is zero, shadow culling is disabled.

static int32_t get (SoState * state)

Returns the current shadow culling state.

Returns non-zero if shadow culling is enabled, and zero otherwise.

void init (SoState * state)

This method is called when the element is pushed onto the state stack.

It should initialize the element's data from the previous top element on the stack, if appropriate.

Reimplemented from SoInt32Element.

void push (SoState * state)

This method is called when the state is pushed, and the depth of the current element is less than the state depth.

Override this method if your element needs to copy data from the previous top of stack. The push() method is called on the new element, and the previous element can be found using SoElement::getNextInStack().

Reimplemented from SoElement.

void pop (SoState * state, const SoElement * prevTopElement)

This method is called when the state is popped, and the depth of the element is bigger than the current state depth. pop() is called on the new top of stack, and a pointer to the previous top of stack is passed in prevTopElement.

Override this method if you need to copy some state information from the previous top of stack.

Reimplemented from SoElement.
