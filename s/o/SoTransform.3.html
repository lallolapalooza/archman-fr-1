Documentation de la classe SoTransform.

La classe SoTransform est le type de nœud de transformation "polyvalent".

Comme SoMatrixTransform, les nœuds de ce type offrent au développeur d'applications une flexibilité maximale lors de la spécification des transformations géométriques dans un arbre de scène. Si vous souhaitez définir et maintenir les composantes de la matrice de transformation dans des entités distinctes, ce type de nœud est cependant préféré.

L'ordre des opérations est le suivant : d'abord la mise à l'échelle, puis la rotation, puis le déplacement.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

Transform {
    translation 0 0 0
    rotation 0 0 1  0
    scaleFactor 1 1 1
    scaleOrientation 0 0 1  0
    center 0 0 0
}

Detailed Description

This is a base class for all nodes that define a transformation. It defines the common fields and methods for transformations. The specific transformation fields (translation, rotation, scale, center, etc.) are defined in derived classes. This class also defines the action methods that are used to apply the transformation to the scene graph.

The SoTransform node provides basic functionality for manipulating transformations, such as applying matrix multiplications and calculating transformation matrices. It also defines virtual methods for actions like rendering, bounding box calculation, and picking, which are reimplemented by derived classes.

SoSFRotation SoTransform::rotation

The rotation part of the transformation.

Note that there is one very common mistake that is easy to make when setting the value of a an SoSFRotation field, and that is to inadvertently use the wrong SbRotation constructor. This example should clarify the problem:

mytransformnode->rotation.setValue(0, 0, 1, 1.5707963f);

The programmer clearly tries to set a PI/2 rotation around the Z-axis, but this will fail, as the SbRotation constructor invoked above is the one that takes as arguments the 4 floats of a quaternion. What the programmer almost certainly wanted to do was to use the SbRotation constructor that takes a rotation vector and a rotation angle, which is invoked like this:

mytransformnode->rotation.setValue(SbVec3f(0, 0, 1), 1.5707963f);
