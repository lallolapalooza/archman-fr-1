Description détaillée

La classe SoVRMLPointLight est utilisée pour représenter une lumière ponctuelle.

La documentation détaillée de la classe est reprise verbatim du standard VRML97 (ISO/IEC 14772-1:1997). Elle est la propriété du Consortium Web3D et est utilisée avec leur permission:

PointLight {
  exposedField SFFloat ambientIntensity  0       # [0,1]
  exposedField SFVec3f attenuation       1 0 0   # [0, inf)
  exposedField SFColor color             1 1 1   # [0,1]
  exposedField SFFloat intensity         1       # [0,1]
  exposedField SFVec3f location          0 0 0   # (-inf, inf)
  exposedField SFBool  on                TRUE
  exposedField SFFloat radius            100     # [0, inf)
}

Le nœud PointLight spécifie une source de lumière ponctuelle dans le système de coordonnées local. Une source de lumière ponctuelle émet de la lumière uniformément dans toutes les directions; c'est-à-dire qu'elle est omnidirectionnelle. Les nœuds PointLight sont spécifiés dans le système de coordonnées local et sont affectés par les transformations de leurs ancêtres. La section 4.6.6, Source de lumière (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.6), contient une description détaillée des champs ambientIntensity, color et intensity.

Un nœud PointLight éclaire la géométrie dans un rayon de mètres de son emplacement. Le *radius* et l'*location* sont tous deux affectés par les transformations des ancêtres (les mises à l'échelle affectent *radius* et les transformations affectent *location*).

Le champ *radius* doit être supérieur ou égal à zéro. L'éclairage provenant des nœuds PointLight diminue avec la distance selon les trois coefficients d'atténuation. Le facteur d'atténuation est 1 / max(attenuation[0] + attenuation[1] * r + attenuation[2] * r2, 1), où r est la distance entre la source lumineuse et la surface éclairée. La valeur par défaut est aucune atténuation. Une valeur d'atténuation de (0, 0, 0) est identique à (1, 0, 0). Les valeurs d'atténuation doivent être supérieures ou égales à zéro. Une description détaillée des équations d'éclairage VRML se trouve dans la section 4.14, Modèle d'éclairage (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.14)).
