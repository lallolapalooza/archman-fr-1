DESCRIPTION

Le nœud SoWWWInline est un nœud de scène de bas niveau utilisé pour inclure des données depuis une URL. Il est typiquement utilisé par des nœuds de niveau supérieur tels que SoWWWAnchor pour inclure des scènes externes.

Il possède un champ url qui doit être défini avec l'URL du fichier à inclure. Quand le chargement de la scène est terminé, les enfants du nœud SoWWWInline sont définis avec le contenu du fichier.

La classe SoWWWInline essaie de faire correspondre le type du fichier avec un type de nœud Coin. Si le fichier est un fichier SGI Inventor (format texte ou binaire), il sera lu par le chargeur de fichier standard. S'il s'agit d'un fichier VRML, il sera lu par le chargeur de fichier VRML. Pour des types de fichiers non reconnus, le nœud SoWWWInline tentera d'utiliser un chargeur de fichier enregistré par l'utilisateur (voir la fonction statique SoInput::registerURL()).

Si l'URL pointe vers un document de scène complexe, par exemple, un fichier VRML, le contenu sera inclus dans la scène.

Pour un fichier de scène qui contient plusieurs entrées (comme dans un fichier VRML), seule la première entrée sera incluse.

L'inclusion de fichiers est effectuée de manière asynchrone. L'application peut vérifier l'état du chargement avec isURLDataRequested() et isURLDataHere().

La méthode requestURLData() est utilisée pour déclencher le chargement du fichier. Normalement, cela se fait automatiquement quand un nœud SoWWWInline est ajouté à la scène.

La méthode setChildData() est utilisée par le système d'E/S pour définir les enfants du nœud après le chargement du fichier.

Le comportement de la visibilité de la boîte englobante est contrôlé par les fonctions statiques setBoundingBoxVisibility() et getBoundingBoxVisibility(). Si elle est réglée à ALWAYS, la boîte englobante sera toujours dessinée. Si elle est réglée à UNTIL_LOADED, elle sera dessinée uniquement tant que les données de l'URL ne sont pas complètement chargées. Si elle est réglée à NEVER, la boîte englobante ne sera jamais dessinée.

La boîte englobante peut également être dessinée dans une couleur spécifique en utilisant setBoundingBoxColor().

Le champ url est un champ de chaîne de caractères qui contient l'URL du fichier à télécharger. Par défaut, il est vide.

Detailed_Description

Le nœud SoWWWInline est utilisé pour inclure des données à partir d'une URL.

Si l'URL n'est pas un fichier local, l'application est responsable de fournir une fonction de rappel pour récupérer les données de l'URL.

Tant qu'aucune donnée n'a été importée, la représentation du graphe de scène du nœud sera celle d'une boîte englobante contenant la géométrie que nous nous attendons à récupérer de l'URL. L'application est naturellement responsable de spécifier les dimensions attendues de la géométrie.

Si FetchURLCallBack n'est pas défini, le alternateRep sera rendu à la place.

FILE_FORMAT/DEFAULTS:

WWWInline {
    name "<Undefined file>"
    bboxCenter 0 0 0
    bboxSize 0 0 0
    alternateRep NULL
}

enum SoWWWInline::BboxVisibility

Utilisé pour énumérer les stratégies de rendu de la boîte englobante.

Enumerator

NEVER
Ne jamais rendre la boîte englobante.
UNTIL_LOADED
Rendre la boîte englobante jusqu'à ce que les enfants soient chargés.
ALWAYS
Toujours rendre la boîte englobante, même lorsque les enfants sont chargés.
