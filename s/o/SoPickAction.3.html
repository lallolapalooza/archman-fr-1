Description détaillée

La classe SoPickAction est la classe de base pour les actions de sélection.

La base de toutes les fonctionnalités d'interaction que Coin fournit au programmeur d'application réside dans les actions de sélection. Les draggers, manipulateurs, nœuds SoSelection, etc., utilisent tous les fonctionnalités fournies par les actions de sélection pour sélectionner et manipuler la géométrie de la scène de diverses manières.

Cette classe n'est pas censée être utilisée directement par le programmeur d'application, car elle sert davantage de placeholder pour l'interface commune des opérations de sélection. Elle ne contient aucun code réel pour effectuer des sélections dans le graphe de scène.

Coin fournit une action de sélection entièrement fonctionnelle que le programmeur d'application peut utiliser via la classe SoRayPickAction (qui hérite de la classe SoPickAction).

void SoPickAction::beginTraversal (SoNode * node) [protected], [virtual]

Cette méthode virtuelle est appelée depuis SoAction::apply(), et constitue le point d'entrée pour le parcours réel de l'arbre de scène.

Elle peut être redéfinie pour initialiser l'action au début du parcours, pour des initialisations spécifiques dans les sous-classes de SoAction.

La méthode par défaut appelle simplement traverse(), qui doit être implémentée par toute redéfinition de cette méthode (ou appeler SoAction::beginTraversal()) pour déclencher le parcours de l'arbre de scène.
