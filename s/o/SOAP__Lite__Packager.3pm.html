SOAP::Lite::Packager(3) Documentation Perl Contribuée par l'Utilisateur SOAP::Lite::Packager(3)

NOM

SOAP::Lite::Packager - cette classe est une classe abstraite qui permet plusieurs types d'agents d'empaquetage tels que MIME et DIME.

DESCRIPTION

La classe SOAP::Lite::Packager est responsable de la gestion d'un ensemble de « parties ». Les parties sont des informations supplémentaires, des documents supplémentaires, ou pratiquement tout ce qui doit être associé à l'enveloppe/charge utile SOAP. Le packager prendra ensuite ces parties et les encodera/décodera ou les « empaquètera »/« désempaquètera » au fur et à mesure qu'elles entrent et sortent sur le fil.

MÉTHODES

new
Instancie une nouvelle instance de SOAP::Lite::Packager.
parts
Contient un tableau de parties. Le contenu de ce tableau et ses types dépendent entièrement du Packager utilisé. Par exemple, lors de l'utilisation de MIME, le contenu de ce tableau est constitué d'entités MIME.
push_part
Ajoute une partie à l'ensemble de parties gérées par l'instance actuelle de SOAP::Lite::Packager.
parser
Retourne le parseur utilisé pour analyser les pièces jointes à partir d'un flux de données.
headers_http
Ceci est un point d'accroche pour la couche HTTP. Il fournit un moyen pour un packager d'ajouter et/ou de modifier les en-têtes HTTP dans une requête/réponse. Par exemple, la plupart des couches d'empaquetage devront remplacer le Content-Type (par exemple, multipart/related, ou application/dime).

MÉTHODES ABSTRAITES

Si vous souhaitez implémenter votre propre SOAP::Lite::Packager, les méthodes ci-dessous doivent être implémentées par vous selon les exigences d'entrée et de sortie prescrites.

package()
La sous-routine "package" prend en entrée l'enveloppe SOAP sous forme de chaîne/SCALAR. Celle-ci servira de contenu à la partie racine. Le packager encapsule ensuite l'enveloppe avec les parties contenues dans "parts" et retourne l'enveloppe correctement encapsulée sous forme de chaîne/SCALAR.
unpackage()
La sous-routine "unpackage" prend en entrée des données brutes qui doivent être analysées en un ensemble de parties. Elle est responsable de l'extraction de l'enveloppe des données d'entrée et de la population de "parts" avec un ARRAY de parties extraites des données d'entrée. Elle retourne ensuite l'enveloppe SOAP sous forme de chaîne/SCALAR afin que SOAP::Lite puisse l'analyser.

FORMATS D'EMPAQUETAGE SUPPORTÉS

SOAP::Lite::Packager::MIME

"SOAP::Lite::Packager::MIME" utilise MIME::Tools pour fournir la capacité d'envoyer et de recevoir des requêtes et des réponses formatées Multipart/Related et Multipart/Form-Data.

MÉTHODES MIME

Les méthodes suivantes sont utilisées lors de la composition d'un message au format MIME.

transfer_encoding
La valeur de l'en-tête MIME Content-Transfer-Encoding de la partie racine. Par défaut : 8bit.
env_id
La valeur de l'en-tête MIME Content-Id de la partie racine. Par défaut : <main_envelope>.
env_location
La valeur de l'en-tête MIME Content-Location de la partie racine. Par défaut : /main_envelope.
env_type
La valeur de l'en-tête MIME Content-Type de la partie racine. Par défaut : text/xml.

OPTIMISATION DU PARSEUR MIME

L'utilisation de pièces jointes peut souvent entraîner une forte consommation de ressources système, selon la configuration de votre parseur MIME. Par exemple, vous pouvez indiquer au parseur de stocker les pièces jointes en mémoire, ou d'utiliser des fichiers temporaires. L'une ou l'autre option peut affecter les performances, l'utilisation du disque et/ou la fiabilité. Par conséquent, vous devriez consulter l'URL suivante pour des techniques d'optimisation et des compromis :

http://search.cpan.org/dist/MIME-tools/lib/MIME/Parser.pm#OPTIMIZING_YOUR_PARSER

Pour modifier les options de configuration du parseur, consultez l'exemple de code suivant, qui montre d'ailleurs comment minimiser l'utilisation de la mémoire :

my $packager = SOAP::Lite::Packager::MIME->new;
# $packager->parser->decode_headers(1); # pas de différence
# $packager->parser->extract_nested_messages(1); # pas de différence
$packager->parser->output_to_core(0); # beaucoup moins de mémoire
$packager->parser->tmp_to_core(0); # beaucoup moins de mémoire
$packager->parser->tmp_recycling(0); # favorise une collecte de garbage plus rapide
$packager->parser->use_inner_files(1); # pas de différence
my $client = SOAP::Lite->uri($NS)->proxy($URL)->packager($packager);
$client->someMethod();

EXEMPLE CÔTÉ CLIENT

L'exemple de code suivant montre comment utiliser des pièces jointes dans le contexte d'un client SOAP::Lite.

#!/usr/bin/perl
use SOAP::Lite;
use MIME::Entity;
my $ent = build MIME::Entity
  Type        => "text/plain",
  Path        => "attachment.txt",
  Filename    => "attachment.txt",
  Disposition => "attachment";
$NS = "urn:Majordojo:TemperatureService";
$HOST = "http://localhost/cgi-bin/soaplite.cgi";
my $client = SOAP::Lite
  ->packager(SOAP::Lite::Packager::MIME->new)
  ->parts([ $ent ])
  ->uri($NS)
  ->proxy($HOST);
$response = $client->c2f(SOAP::Data->name("temperature" => '100'));
print $response->valueof('//c2fResponse/foo');

EXEMPLE CÔTÉ SERVEUR

Le code suivant montre comment utiliser des pièces jointes dans le contexte d'un script CGI. Il montre comment lire les pièces jointes entrantes et renvoyer des pièces jointes au client.

#!/usr/bin/perl -w
use SOAP::Transport::HTTP;
use MIME::Entity;
SOAP::Transport::HTTP::CGI
  ->packager(SOAP::Lite::Packager::MIME->new)
  ->dispatch_with({'urn:Majordojo:TemperatureService' => 'TemperatureService'})
  ->handle;
BEGIN {
  package TemperatureService;
  use vars qw(@ISA);
  @ISA = qw(Exporter SOAP::Server::Parameters);
  use SOAP::Lite;
  sub c2f {
    my $self = shift;
    my $envelope = pop;
    my $temp = $envelope->dataof("//c2f/temperature");
    use MIME::Entity;
    my $ent = build MIME::Entity
      Type        => "text/plain",
      Path        => "printenv",
      Filename    => "printenv",
      Disposition => "attachment";
    # lire les pièces jointes
    foreach my $part (@{$envelope->parts}) {
      print STDERR "soaplite.cgi: attachment found! (".ref($part).")\n";
      print STDERR "soaplite.cgi: contents => ".$part->stringify."\n";
    }
    # envoyer les pièces jointes
    return SOAP::Data->name('convertedTemp' => (((9/5)*($temp->value)) + 32)),
      $ent;
  }
}

NOM

SOAP::Lite::Packager - Un gestionnaire de paquets pour SOAP::Lite.

DESCRIPTION

Le module SOAP::Lite::Packager est une classe de base abstraite pour tous les les gestionnaires de paquets de SOAP::Lite. Les gestionnaires de paquets sont utilisés pour sérialiser et désérialiser les types de données Perl en et depuis les documents SOAP (qui sont généralement XML).

La classe définit une interface que tous les gestionnaires de paquets doivent implémenter. Ces interfaces comprennent des méthodes pour l'encodage et le décodage des données, ainsi que pour la gestion des types de données SOAP.

Les gestionnaires de paquets sont choisis en fonction du type de données qui doit être encodé ou décodé. Par exemple, le gestionnaire de paquets XML standard sera utilisé pour la plupart des types de données Perl standard, tandis que des gestionnaires de paquets personnalisés peuvent être utilisés pour des types de données plus complexes ou spécifiques.

MÉTHODES

Le module SOAP::Lite::Packager définit plusieurs méthodes qui doivent être implémentées par ses sous-classes. Ces méthodes sont essentielles pour le bon fonctionnement de l'encodage et du décodage des données SOAP.

  • register($type, $packager) : Enregistre un gestionnaire de paquets pour un type de données donné.
  • unregister($type) : Supprime l'enregistrement d'un gestionnaire de paquets pour un type de données.
  • can_encode($type) : Vérifie si le gestionnaire de paquets peut encoder un type de données donné.
  • can_decode($type) : Vérifie si le gestionnaire de paquets peut décoder un type de données donné.
  • encode($value, $type) : Encode une valeur Perl en une représentation SOAP.
  • decode($value, $type) : Décode une représentation SOAP en une valeur Perl.

MÉTHODES ABSTRAITES

Les méthodes suivantes sont considérées comme abstraites et doivent être implémentées par toute sous-classe concrète de SOAP::Lite::Packager.

  • uri() : Retourne l'URI du namespace XML pour ce gestionnaire de paquets.
  • type() : Retourne le nom du type SOAP géré par ce gestionnaire de paquets.
  • pack($value) : Sépare une valeur Perl en sa structure de données de base et son type.
  • unpack($value) : Transforme une valeur Perl décomposée en son type SOAP d'origine.

FORMATS DE PAQUET SUPPORTÉS

Le module SOAP::Lite::Packager lui-même ne prend pas en charge de formats de paquet spécifiques, car il s'agit d'une classe de base abstraite. Cependant, les sous-classes concrètes implémentent la prise en charge de divers formats de sérialisation, notamment :

  • XML (format par défaut pour les documents SOAP)
  • JSON
  • D'autres formats peuvent être pris en charge par des gestionnaires de paquets personnalisés.
