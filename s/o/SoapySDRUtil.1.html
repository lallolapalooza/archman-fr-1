SOAPYSDRUTIL(1) Manuel des commandes générales SOAPYSDRUTIL(1)

NOM

SoapySDRUtil - interroger et modifier les informations des modules de SoapySDR

SYNTAXE

SoapySDRUtil [OPTIONS]

DESCRIPTION

SoapySDRUtil est une application en ligne de commande qui fournit des utilitaires de diagnostic de base pour SoapySDR en affichant des informations d'installation, les modules disponibles, les périphériques découverts et les tests sur les périphériques instanciés.

OPTIONS

--info
Affiche des informations générales sur la bibliothèque, liste tous les modules de support matériel trouvés et les usines disponibles.
--find[="SPEC"]
Découvre les périphériques disponibles, restreint à ceux correspondant à SPEC s'il est donné. Si aucun périphérique correspondant n'est trouvé, le programme se terminera avec le statut de sortie 1.
--make[="SPEC"]
Ouvre et ferme le périphérique correspondant à SPEC si possible. Si SPEC n'est pas donné, le premier périphérique découvert est ouvert.
--probe[="SPEC"]
Affiche des informations détaillées sur tous les périphériques ou sur les périphériques correspondant à SPEC s'il est donné.
--check=NOM
Vérifie et affiche si le module pilote nommé NOM est présent. S'il n'est pas trouvé, le programme se terminera avec le statut de sortie 1.

ACCUEIL

SoapySDRUtil fait partie du projet SoapySDR.

AUTEURS

La bibliothèque SoapySDR, y compris SoapySDRUtil, a été principalement écrite par Josh Blum.
