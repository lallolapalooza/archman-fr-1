Description détaillée

La classe SoDelayQueueSensor est la classe de base abstraite pour les capteurs de priorité.

Les capteurs de file d'attente retardée sont déclenchés lorsque divers événements non liés aux événements temps se produisent. Voir la documentation des sous-types pour connaître les types d'événements qui peuvent être surveillés par les types de capteurs intégrés.

Les valeurs de priorité peuvent être utilisées pour réorganiser les événements en fonction de leur importance, de sorte que les capteurs soient déclenchés dans l'ordre souhaité.

La file d'attente des capteurs retardés (c'est-à-dire les instances de sous-classes de SoDelayQueueSensor) est traitée dès que le système temporel est inactif, ou s'il est continuellement occupé, elle est traitée dans un délai fixe.

Ce délai est par défaut de 1/12 de seconde, mais peut être contrôlé via l'interface SoSensorManager::setDelaySensorTimeout().

void SoDelayQueueSensor::setPriority (uint32_t pri)

Définit la priorité du capteur dans la file d'attente d'exécution. Lorsque les capteurs sont traités, les capteurs à haute priorité sont déclenchés avant ceux à basse priorité.

Note : Un nombre plus bas signifie une priorité plus élevée. Un capteur avec une priorité de 5 sera déclenché avant un capteur avec une priorité de 6.

Les capteurs avec une priorité de 0 ont une signification spéciale dans Coin/Inventor. Ils sont appelés capteurs immédiats et sont déclenchés immédiatement après la fin de la chaîne de notification actuelle. Ils doivent être utilisés avec précaution, car ils peuvent entraîner une performance négative si quelque chose est fait à l'intérieur du rappel du capteur.

Ce réglage n'affecte pas les invocations de SoDataSensor avec le rappel de suppression, qui sont toujours immédiates.

void SoDelayQueueSensor::schedule (void ) [virtuel]

Place le capteur dans la file d'attente retardée globale. Cela signifie qu'il sera déclenché lorsque le processeur sera inactif, ou lorsqu'un délai d'attente de la file d'attente retardée spécifié sera atteint.
