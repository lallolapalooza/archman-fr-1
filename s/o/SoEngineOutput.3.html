Description détaillée

La classe SoEngineOutput représente les sorties des instances SoEngine.

SoEngineOutput fournit des méthodes pour gérer facilement les connexions établies entre les objets SoEngine et les objets SoField.

void SoEngineOutput::removeConnection (SoField * f)

Supprime f de la liste des connexions de cette sortie.

Décrémente le compteur de références du moteur conteneur de 1. Si le compteur de références atteint zéro (ce qui se produira si c'était la dernière connexion et que le programmeur de l'application n'a pas explicitement fait ref sur le moteur), le moteur conteneur sera désalloué.

void SoEngineOutput::touchSlaves (SoNotList * nl, SbBool donotify)

Met à jour tous les champs esclaves connectés à cette sortie.

nl est la liste de notification, qui est une liste d'événements survenus.

donotify indique s'il faut notifier les esclaves. Si c'est faux, la valeur du champ esclave sera mise à jour, mais aucune notification ne sera envoyée.

Ceci est utilisé par les moteurs pour mettre à jour leurs sorties.

void SoEngineOutput::touchSlaves (SoNotList * nl, SbBool donotify)

Notifie les champs connectés à ce moteur que la valeur de la sortie a changé.

Si donotify est TRUE, propage la notification aux champs. Sinon, marque les champs comme "sales" pour une ré-évaluation.

Note : Cette méthode ne fait pas partie de l'API originale d'Open Inventor.
