NOMBRE

SoVRMLFontStyle - nodo para definir el estilo de fuente del texto

HERENCIA

`SoNode : SoFieldContainer : SoBase`

SINTAXIS

`SoVRMLFontStyle {`
`field MFString family "SERIF"`
`field SFBool horizontal TRUE`
`field MFString justify "BEGIN"`
`field SFString language ""`
`field SFBool leftToRight TRUE`
`field SFFloat size 1.0`
`field SFFloat spacing 1.0`
`field SFString style "PLAIN"`
`field SFBool topToBottom TRUE`
`}`

DESCRIPCIÓN

El nodo SoVRMLFontStyle define el estilo de fuente actual, la familia de fuente, el tamaño, el espaciado y las propiedades de justificación y dirección para los nodos de texto.

Este nodo es parte de la especificación VRML97 y se utiliza para controlar la apariencia del texto renderizado.

ATRIBUTOS PÚBLICOS


SoSFFloat size

Tamaño nominal de los glifos de fuente en unidades locales. Debe ser mayor que 0.

SoMFString family

Familia(s) de fuente preferida(s). Los valores predeterminados son "SERIF", "SANS", "TYPEWRITER".

SoMFString style

Estilo de fuente. Los valores posibles son "PLAIN", "BOLD", "ITALIC", "BOLDITALIC".

SoSFBool horizontal

Si TRUE, el texto se avanza horizontalmente. Si FALSE, el texto se avanza verticalmente.

SoSFBool leftToRight

Si TRUE, el texto se avanza de izquierda a derecha (o de arriba a abajo si horizontal es FALSE). Si FALSE, el texto se avanza de derecha a izquierda (o de abajo a arriba si horizontal es FALSE).

SoSFBool topToBottom

Si TRUE, las líneas de texto se apilan de arriba a abajo (o de izquierda a derecha si horizontal es FALSE). Si FALSE, las líneas de texto se apilan de abajo a arriba (o de derecha a izquierda si horizontal es FALSE).

SoSFString language

Especifica el idioma del texto, utilizado para la selección de fuentes y el comportamiento de escritura. El valor predeterminado es una cadena vacía.

SoMFString justify

Especifica la alineación del texto. Puede contener uno o dos valores: el primero para la alineación principal y el segundo para la alineación secundaria. Los valores posibles son "FIRST", "BEGIN", "MIDDLE", "END". El valor predeterminado es "BEGIN".

SoSFFloat spacing

Factor de espaciado entre líneas de texto. Determina la distancia entre líneas. Debe ser no negativo.

DESCRIPCIÓN DETALLADA

La clase SoVRMLFontStyle se utiliza para definir el estilo de fuente actual.

Nota importante: actualmente, la implementación del nodo SoVRMLText no está completa, y algunas de las características mencionadas en el documento pueden no funcionar aún.

La documentación detallada de la clase se tomó literalmente del estándar VRML97 (ISO/IEC 14772-1:1997). Es propiedad del Consorcio Web3D y se utiliza por permiso del Consorcio:

FontStyle { 
  field MFString family       "SERIF"
  field SFBool   horizontal   TRUE
  field MFString justify      "BEGIN"
  field SFString language     ""
  field SFBool   leftToRight  TRUE
  field SFFloat  size         1.0          # (0,)
  field SFFloat  spacing      1.0          # [0,)
  field SFString style        "PLAIN"
  field SFBool   topToBottom  TRUE
}

Introducción

El nodo FontStyle define la altura nominal, la familia y el estilo usados para los nodos Text, así como la dirección de las cadenas de texto y cualquier técnica de renderizado específica para texto no inglés. Para una descripción del nodo Text, véase SoVRMLText.

El campo size especifica la altura nominal, en el sistema de coordenadas locales de los nodos Text, de los glifos renderizados y determina el espaciado entre líneas de texto. Los valores del campo size deben ser mayores que cero.

El campo spacing determina el espaciado entre líneas de texto consecutivas. La distancia entre la base de cada línea de texto es (spacing * size) en la dirección adecuada (dependiendo de otros campos descritos abajo). Los efectos de los campos size y spacing se muestran en la figura 6.7 (spacing mayor que 1.0). Los valores del campo spacing deben ser no negativos.

Descripción de la familia de fuente y estilo

Las atribuciones de fuente se definen con los campos family y style. El navegador debe mappear las atribuciones especificadas a una fuente adecuada y disponible, como se describe a continuación.

El campo family contiene un valor MFString caso sensible que especifica una secuencia de nombres de familia de fuente en orden de preferencia. El navegador debe buscar en el valor MFString para encontrar la primera nombre de familia de fuente que corresponde a una familia de fuente soportada. Si ninguno de los valores de cadena coincide con una familia de fuente soportada, se utilizará por defecto la familia de fuente "SERIF". Todos los navegadores deben soportar al menos "SERIF" (la familia de fuente por defecto) para una fuente de tipo serifa como Times Roman; "SANS" para una fuente de tipo sin serifa como Helvetica; y "TYPEWRITER" para una fuente de tipo tipográfico como Courier. Un valor vacío de familia es idéntico a ["SERIF"].

El campo style especifica un valor SFString caso sensible que puede ser "PLAIN" (por defecto) para tipo plano estándar; "BOLD" para tipo negativo; "ITALIC" para tipo cursivo; o "BOLDITALIC" para tipo bolo y cursivo. Un valor vacío de estilo ("") es idéntico a "PLAIN".

Dirección y justificación

Los campos horizontal, leftToRight y topToBottom indican la dirección del texto. El campo horizontal indica si el texto se avanza horizontalmente en su dirección principal (horizontal = TRUE, por defecto) o verticalmente en su dirección principal (horizontal = FALSE). Los campos leftToRight y topToBottom indican la dirección de avance del texto en los ejes principales (caracteres dentro de una sola cadena) y secundarios (secuencias de strings). La dirección principal y la secundaria se determinan por el campo horizontal.

Para texto horizontal (horizontal = TRUE), los caracteres en cada línea de texto avanzan en el sentido positivo del eje X si leftToRight es TRUE o en el sentido negativo del eje X si leftToRight es FALSE. Los caracteres se avanzan según su anchura natural. Cada línea de caracteres se avanza en el sentido negativo del eje Y si topToBottom es TRUE o en el sentido positivo del eje Y si topToBottom es FALSE. Las líneas se avanzan por la cantidad de size * spacing.

Para texto vertical (horizontal = FALSE), los caracteres en cada línea de texto avanzan en el sentido negativo del eje Y si topToBottom es TRUE o en el sentido positivo del eje Y si topToBottom es FALSE. Los caracteres se avanzan según su altura natural. Cada línea de caracteres se avanza en el sentido positivo del eje X si leftToRight es TRUE o en el sentido negativo del eje X si leftToRight es FALSE. Las líneas se avanzan por la cantidad de size * spacing.

El campo justify determina la alineación de la layout de texto anterior en relación con el origen del sistema de coordenadas de objeto. El campo justify es un MFString que puede contener 2 valores. El primer valor especifica la alineación a lo largo del eje principal y el segundo valor especifica la alineación a lo largo del eje secundario, como determinado por el campo horizontal. Un valor vacío de justify ("") es equivalente al valor por defecto. Si el segundo string, alineación secundaria, no se especifica, la alineación secundaria por defecto es "FIRST". Por lo tanto, los valores de justify de "", "BEGIN" y ["BEGIN" "FIRST"] son equivalentes.

La alineación principal es el eje X cuando horizontal es TRUE y el eje Y cuando horizontal es FALSE. La alineación secundaria es el eje Y cuando horizontal es TRUE y el eje X cuando horizontal es FALSE. Los valores posibles para cada enumerante de la campo justify son "FIRST", "BEGIN", "MIDDLE" y "END". Para la alineación principal, cada línea de texto se posiciona individualmente según el enumerante de alineación principal. Para la alineación secundaria, el bloque de texto representando todas las líneas juntas se posiciona según el enumerante de alineación secundaria. Las tablas 6.2-6.5 en http://www.web3d.org/documents/specifications/14772/V2.0/part1/nodesRef.html#Table6.2 describen la relación entre los valores de justificación y la alineación resultante.

Se recomienda que los navegadores VRML proporcionen acceso a una gran variedad de familias de fuentes y estilos. El campo language se proporciona para ayudar a los navegadores a seleccionar la fuente correcta para renderizar texto en diferentes idiomas. Los navegadores VRML deben usar el campo language para seleccionar la fuente apropiada. Si el navegador no puede encontrar una fuente que coincida con el código de idioma especificado, se debe usar el campo family para seleccionar la fuente.

#include <Inventor/VRMLnodes/SoVRMLFontStyle.h>

Inheritance:
SoVRMLFontStyle : public SoNode

Description Détaillée

Le nœud SoVRMLFontStyle est utilisé pour spécifier la police de caractères, la taille et le style du texte affiché dans une scène VRML. Il affecte tous les nœuds de texte subséquents dans la hiérarchie de la scène, tels que SoVRMLText.

Les attributs clés de SoVRMLFontStyle incluent :

  • fontName : Le nom de la police de caractères (par exemple, "Times", "Helvetica", "Courier").
  • fontStyle : Le style de la police (par exemple, "PLAIN", "BOLD", "ITALIC", "BOLDITALIC").
  • fontSize : La taille de la police en unités de scène.
  • justify : L'alignement du texte (par exemple, "BEGIN", "MIDDLE", "END").
  • leftToRight : Indique si le texte doit être rendu de gauche à droite (vrai) ou de droite à gauche (faux).
  • topToBottom : Indique si le texte doit être rendu de haut en bas (vrai) ou de bas en haut (faux).
