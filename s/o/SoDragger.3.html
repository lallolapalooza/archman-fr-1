Description détaillée

La classe SoDragger est la classe de base pour tous les draggers.

Les draggers sont un mécanisme utilisé pour permettre aux utilisateurs finaux de votre code applicatif d'interagir avec des éléments en 3D, en mettant à l'échelle, en faisant pivoter ou en traduisant de la géométrie ou d'autres instances dans la scène (comme des caméras ou des sources de lumière).

Pour une introduction et un tutoriel très approfondis sur les classes de draggers et les concepts généraux, nous vous conseillons de consulter The Inventor Mentor, ISBN 0-201-62495-8, chapitre 15.

C'est la superclasse commune à toutes les classes de draggers.

Elle détient la matrice de mouvement actuelle et offre de nombreuses méthodes pratiques à partir desquelles construire pour ses sous-classes -- c'est-à-dire les classes de draggers non abstraites à utiliser comme nœuds dans votre graphe de scène.

La matrice de mouvement est utilisée pour modifier la matrice de modèle pendant le parcours, et c'est un mécanisme de dragger courant -- tous les draggers devraient la mettre à jour pendant le glissement.

Un certain nombre de classes de draggers Coin ont des classes enveloppantes pratiques intégrées, appelées *manipulateurs*. Voir par exemple la paire SoTrackballDragger / SoTrackballManip.

La classe de manipulateur correspondante pour toute classe de dragger a fondamentalement deux ajouts pratiques à la fonctionnalité du dragger autonome : 1) elle rend l'échange du dragger dans et hors du graphe de scène très simple (ce qui est souvent fait pour les draggers dans les interfaces utilisateur 3D), 2) elle enveloppe le dragger avec des nœuds SoSurroundScale et SoAntiSquish le cas échéant, de sorte que la géométrie du dragger s'adapte automatiquement pour correspondre à la géométrie qu'elle influence.

Cette dernière fonctionnalité peut également être reproduite d'une manière assez simple en dehors du contexte d'un manipulateur, comme on peut le voir dans l'exemple d'utilisation de la documentation de la classe SoSurroundScale.

L'apparence des draggers peut être modifiée soit en utilisant la méthode SoDragger::setPart() (voir l'exemple d'utilisation ci-dessous), soit en configurant des fichiers externes au format Inventor à partir desquels les parties géométriques sont lues. Cette dernière méthode peut être réalisée en définissant la variable d'environnement SO_DRAGGER_DIR pour pointer vers un répertoire contenant des fichiers de géométrie de remplacement. Le nom des nouveaux fichiers et le nom des nœuds / sous-graphes avec les géométries de remplacement doivent suivre un schéma rigide. Nous vous conseillons de regarder dans le répertoire de code source de Coin, Coin/data/draggerDefaults/, pour voir comment les fichiers de géométrie de remplacement doivent être nommés. Définir SO_DRAGGER_DIR vers ce répertoire et modifier les fichiers qui s'y trouvent offre un moyen pratique de jouer avec de nouveaux arrangements de géométrie de dragger.

Comme mentionné ci-dessus, SoDragger::setPart() peut être utilisé pour modifier l'apparence d'un dragger en changeant sa géométrie par défaut. Une technique courante consiste par exemple à l'utiliser pour n'utiliser que des *parties* d'un dragger, en remplaçant / désactivant la géométrie avec laquelle vous ne voulez pas que l'utilisateur final interagisse. L'exemple de code suivant montre comment supprimer la fonctionnalité de translation du SoTransformBoxDragger :

#include <Inventor/Qt/SoQt.h>
#include <Inventor/Qt/viewers/SoQtExaminerViewer.h>
#include <Inventor/draggers/SoTransformBoxDragger.h>
#include <Inventor/nodes/SoSeparator.h>
int
main(int argc, char ** argv)
{
  QWidget * window = SoQt::init(argv[0]);
  SoTransformBoxDragger * dragger = new SoTransformBoxDragger;
  SbString str;
  for (int i = 1; i <= 6; i++) {
    str.sprintf("translator%d.translator", i);
    dragger->setPart(str.getString(), new SoSeparator);
  }
  SoQtExaminerViewer * viewer = new SoQtExaminerViewer(window);
  viewer->setSceneGraph(dragger);
  viewer->show();
  SoQt::show(window);
  SoQt::mainLoop();
  delete viewer;
  return 0;
}

Documentation de l'énumération des membres

enum SoDragger::ProjectorFrontSetting

Stocke divers réglages pour les projecteurs, qui peuvent affecter les glisseurs basés sur des formes cylindriques et sphériques. Indique si le glissement doit être basé sur la face avant ou la face arrière de la sphère / du cylindre, ou si le point sélectionné devrait décider de cela.

Énumérateurs

FRONT
Utilise toujours la face avant du projecteur.
BACK
Utilise toujours la face arrière du projecteur.
USE_PICK
Utilise le point sélectionné pour décider s'il s'agit de la face avant ou arrière du projecteur.
