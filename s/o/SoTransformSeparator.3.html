Ce nœud fonctionne de manière similaire au nœud SoSeparator, sauf qu'il ne stocke et ne restaure que la matrice de transformation du modèle actuel. D'autres réglages d'apparence, tels que les matériaux, les textures, les caméras, les lumières, etc., affecteront les parties restantes de la hiérarchie de la scène après la traversée, de même que dans le nœud SoGroup.

SoTransformSeparator - Separator node that applies transformations to its children

    virtual void        audioRender (SoAudioRenderAction * action)

Detailed Description

This node is similar to SoSeparator, but it also manages transformations. Transformations applied to this node are locally stored and applied to all of its children. This is useful for applying transformations to groups of objects.

In addition, this node affects the way SoGetMatrixAction works. When an SoGetMatrixAction is applied to a scene graph containing an SoTransformSeparator, the action will retrieve the transformation matrix that is currently active at that point in the scene graph traversal. This matrix is then accumulated with the matrix stored in the SoGetMatrixAction.

This node is recommended for use when you want to apply transformations to a group of nodes, as it provides a clean way to scope transformations and ensures that the transformations are correctly handled by actions such as SoGetMatrixAction.
