Description Détaillée

La classe SoNonIndexedShape est la superclasse de toutes les formes basées sur des sommets non indexées.

Elle contient le champ (maintenant obsolète) startIndex et une méthode pratique pour calculer la boîte englobante.

NOM

SoNonIndexedShape - Non-indexed shape node

VUE D'ASPECT

                SoNode
                     |
                     +--SoShape
                          |
                          +--SoVertexShape
                               |
                               +--SoNonIndexedShape

DESCRIPTION

This class is an abstract base class for shapes that are not indexed. That is, all primitives are defined by sequences of vertices, and there is no separate index list.

The subclasses of this class must reimplement the virtual draw() method, and provide the list of vertices.

void SoNonIndexedShape::computeCoordBBox (SoAction * action, int numVertices, SbBox3f & box, SbVec3f & center) [protected]

Cette méthode est fournie comme un moyen pratique pour les sous-classes de cette classe de trouver leur boîte englobante et leur centre.

La boîte englobante retournée englobera tous les sommets de startIndex jusqu'à startIndex + numVertices. Si numVertices est inférieur à zéro, *tous* les sommets de l'élément coordonnée actuel ou du nœud de propriété de sommet seront utilisés dans le calcul.

Le point de center sera calculé comme la moyenne de tous les sommets dans la boîte englobante.

void SoNonIndexedShape::fixNumVerticesPointers (SoState * state, const int32_t *& start, const int32_t *& end, int32_t * dummyarray) const [protected]

Méthode utilitaire qui peut ajuster les pointeurs start et end, qui devraient pointer au début et à la fin du tableau numVertices lors de l'appel à cette méthode. Ceci prend en compte le cas où numVertices contient un seul -1, et que toutes les coordonnées dans l'état (ou dans le champ vertexProperty) devraient être rendues comme une primitive.

dummyarray devrait être un tableau temporaire, avec de la place pour un entier.

Ne fait pas partie de l'API OIV.
