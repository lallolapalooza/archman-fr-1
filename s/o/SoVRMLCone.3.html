Description Détaillée

La classe SoVRMLCone est utilisée pour représenter un objet Cône.

La documentation détaillée de la classe est extraite verbatim de la norme VRML97 (ISO/IEC 14772-1:1997). Elle est copyright du Web3D Consortium et est utilisée avec l'autorisation du Consortium :

Cone {
  field     SFFloat   bottomRadius 1        # (0, inf)
  field     SFFloat   height       2        # (0, inf)
  field     SFBool    side         TRUE
  field     SFBool    bottom       TRUE
}

Le nœud Cone spécifie un cône centré dans le système de coordonnées local et dont l'axe central est aligné avec l'axe Y local. Le champ bottomRadius spécifie le rayon de la base du cône, et le champ height spécifie la hauteur du cône depuis le centre de la base jusqu'à l'apex. Par défaut, le cône a un rayon de 1.0 à la base et une hauteur de 2.0, avec son apex à y = height/2 et sa base à y = -height/2. Les champs bottomRadius et height doivent être supérieurs à zéro. La figure 6.3 illustre le nœud Cone.


Figure 6.3

Le champ side spécifie si les côtés du cône sont créés et le champ bottom spécifie si la base du cône est créée. Une valeur TRUE spécifie que cette partie du cône existe, tandis qu'une valeur FALSE spécifie que cette partie n'existe pas (non rendue ou non éligible pour les tests de collision ou de capteur). Lorsqu'une texture est appliquée aux côtés du cône, la texture s'enroule dans le sens antihoraire (depuis le dessus) en commençant par l'arrière du cône. La texture a une couture verticale à l'arrière dans le plan X=0, de

la **SoVRMLCone** affecte les coordonnées de texture du cône.

La géométrie du cône n'exige que des faces extérieures. Vue de l'intérieur, les résultats sont indéfinis.
