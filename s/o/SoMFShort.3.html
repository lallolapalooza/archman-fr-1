Description détaillée

La classe SoMFShort est un conteneur de valeurs entières courtes.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker un groupe de plusieurs valeurs entières courtes.

Ce champ prend en charge l'échange de données d'application via une méthode setValuesPointer(). Pour plus d'informations sur l'utilisation de cette méthode, consultez la documentation de SoMField.

Detailed Description

This class is the inventor field class for an array of short integers. Short integers are integers that typically occupy 16 bits.

This field class is used for fields that store multiple short integers. For example, SoNode::setField() and SoNode::getField() methods use this field class.

For an explanation of the other methods in this class, please refer to the documentation for the base class SoMField.
