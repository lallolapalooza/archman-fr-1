Description détaillée

La classe SoSFVec4us contient un vecteur SbVec4us.

Ce champ est utilisé lorsque les nœuds, moteurs ou autres conteneurs de champs doivent stocker un vecteur à quatre éléments.

Voir aussi

SbVec4us, SoMFVec4us Remarque : cette classe est une extension de Coin, et n'est pas disponible dans l'API originale d'Open Inventor v2.1 de SGI.

Depuis

Coin 2.5
