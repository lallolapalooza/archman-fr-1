Description Détaillée

La classe SoSceneManager fournit l'interface principale entre le graphe de scène et la boîte à outils GUI.

La classe de zone de rendu de la boîte à outils GUI que vous utilisez utilise cette classe comme interface avec le graphe de scène. La gestion des événements et la fourniture de "crochets" pour effectuer le rendu sont les fonctions principales de la classe.

Une instance de la bibliothèque Coin dans une application contiendra généralement un seul objet SoSceneManager. Le pointeur de cet objet est stocké dans la classe de rendu GUI.

void SoSceneManager::render (const SbBool clearwindow = TRUE, const SbBool clearzbuffer = TRUE) [virtual]

Rend le graphe de scène.

Si clearwindow est TRUE, efface le tampon de rendu avant le dessin. Si clearzbuffer est TRUE, efface les valeurs du tampon de profondeur avant le rendu. Ces deux arguments devraient normalement être TRUE, mais ils peuvent être mis à FALSE pour optimiser des cas spéciaux (par exemple, lors du rendu en mode fil de fer, un tampon de profondeur n'est pas nécessaire).

void SoSceneManager::render (SoGLRenderAction * action, const SbBool initmatrices = TRUE, const SbBool clearwindow = TRUE, const SbBool clearzbuffer = TRUE) [virtual]

Méthode de rendu utilisée pour un rendu thread-safe.

Comme un seul thread peut utiliser une SoGLRenderAction, cette méthode vous permet de fournir votre propre SoGLRenderAction spécifique au thread pour le rendu de la scène.

Si initmatrices est TRUE, les matrices de modèle et de projection OpenGL seront initialisées à des matrices identité avant d'appliquer l'action.

Si clearwindow est TRUE, efface le tampon de rendu avant le dessin. Si clearzbuffer est TRUE, efface les valeurs du tampon de profondeur avant le rendu.

Cette fonction est une extension pour Coin et n'est pas disponible dans l'API originale SGI Open Inventor v2.1.
