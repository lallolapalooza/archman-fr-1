Description détaillée

La classe SoDetail est la classe parente pour toutes les classes stockant des informations détaillées sur des formes particulières.

Les informations détaillées sur les formes sont utilisées dans le cadre des actions de sélection dans Coin. Elles contiennent généralement les informations pertinentes sur la partie spécifique de la forme qu'un rayon de sélection a intersectée.

virtual SoType SoDetail::getTypeId (void ) const [pure virtual]

Retourne l'identification de type d'un détail dérivé d'une classe héritant de SoDetail. Ceci est utilisé pour le contrôle de type à l'exécution et la conversion "vers le bas".

Exemple d'utilisation :

void fuhbear(SoDetail * detail)
{
  if (detail->getTypeId() == SoFaceDetail::getClassTypeId()) {
    // conversion vers le bas sûre, le type est connu
    SoFaceDetail * facedetail = (SoFaceDetail *)detail;
  }
  return; // ignorer si ce n'est pas un SoFaceDetail
}

Pour les programmeurs d'applications souhaitant étendre la bibliothèque avec de nouvelles classes de détails : cette méthode doit être remplacée dans toutes les sous-classes. Ceci est généralement fait dans le cadre de la mise en place du système de types complet pour les classes d'extension, ce qui est généralement accompli en utilisant les macros prédéfinies disponibles via Inventor/nodes/SoSubDetail.h : SO_DETAIL_SOURCE et SO_DETAIL_INIT_CLASS.

Implémenté dans SoConeDetail, SoCubeDetail, SoCylinderDetail, SoFaceDetail, SoLineDetail, SoNodeKitDetail, SoPointDetail, et SoTextDetail.
