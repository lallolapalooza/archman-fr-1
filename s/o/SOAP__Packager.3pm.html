SOAP::Packager(3) Documentation Perl fournie par l'utilisateur SOAP::Packager(3)

NOM

SOAP::Packager - cette classe est une classe abstraite qui permet plusieurs types d'agents de packaging tels que MIME et DIME.

DESCRIPTION

La classe SOAP::Packager est responsable de la gestion d'un ensemble de « parties ». Les parties sont des informations supplémentaires, des documents additionnels, ou pratiquement tout ce qui doit être associé à l'Enveloppe SOAP/charge utile. Le packager prendra ensuite ces parties et les encodera/décodera, ou les « packagera »/« dépackagera » au fur et à mesure de leur transit sur le réseau.

MÉTHODES

new
Instancie une nouvelle instance de SOAP::Packager.
parts
Contient un tableau de parties. Le contenu de ce tableau et leurs types dépendent entièrement du Packager utilisé. Par exemple, lors de l'utilisation de MIME, le contenu de ce tableau est constitué d'entités MIME.
push_part
Ajoute une partie à l'ensemble des parties gérées par l'instance actuelle de SOAP::Packager.
parser
Retourne le parseur utilisé pour analyser les pièces jointes à partir d'un flux de données.
headers_http
Ceci est un point d'accroche dans la couche HTTP. Il offre un moyen à un packager d'ajouter et/ou de modifier les en-têtes HTTP dans une requête/réponse. Par exemple, la plupart des couches de packaging devront remplacer le Content-Type (par exemple, multipart/related, ou application/dime).

MÉTHODES ABSTRAITES

Si vous souhaitez implémenter votre propre SOAP::Packager, vous devrez implémenter les méthodes ci-dessous selon les exigences d'entrée et de sortie prescrites.

package()
La sous-routine "package" prend en entrée l'enveloppe SOAP sous forme de chaîne/SCALAR. Ceci servira de contenu à la partie racine. Le packager encapsule ensuite l'enveloppe avec les parties contenues dans "parts" et retourne l'enveloppe correctement encapsulée sous forme de chaîne/SCALAR.
unpackage()
La sous-routine "unpackage" prend en entrée des données brutes qui doivent être analysées en un ensemble de parties. Elle est responsable de l'extraction de l'enveloppe à partir de l'entrée, et de la population de "parts" avec un TABLEAU de parties extraites de l'entrée. Elle retourne ensuite l'enveloppe SOAP sous forme de chaîne/SCALAR afin que SOAP::Lite puisse l'analyser.

FORMATS DE PACKAGING SUPPORTÉS

SOAP::Packager::MIME

"SOAP::Packager::MIME" utilise MIME::Tools pour fournir la capacité d'envoyer et de recevoir des requêtes et des réponses formatées en Multipart/Related et Multipart/Form-Data.

MÉTHODES MIME

Les méthodes suivantes sont utilisées lors de la composition d'un message formaté MIME.

transfer_encoding
La valeur de l'en-tête MIME Content-Transfer-Encoding de la partie racine. La valeur par défaut est : 8bit.
env_id
La valeur de l'en-tête MIME Content-Id de la partie racine. La valeur par défaut est : <main_envelope>.
env_location
La valeur de l'en-tête MIME Content-Location de la partie racine. La valeur par défaut est : /main_envelope.
env_type
La valeur de l'en-tête MIME Content-Type de la partie racine. La valeur par défaut est : text/xml.

OPTIMISATION DU PARSEUR MIME

L'utilisation de pièces jointes peut souvent entraîner une forte consommation des ressources système en fonction de la configuration de votre parseur MIME. Par exemple, vous pouvez indiquer au parseur de stocker les pièces jointes en mémoire, ou d'utiliser des fichiers temporaires. L'une ou l'autre méthode peut affecter les performances, l'utilisation du disque et/ou la fiabilité. Par conséquent, vous devriez consulter l'URL suivante pour des techniques d'optimisation et des compromis :

http://search.cpan.org/dist/MIME-tools/lib/MIME/Parser.pm#OPTIMIZING_YOUR_PARSER

Pour modifier les options de configuration du parseur, consultez l'exemple de code suivant, qui montre d'ailleurs comment minimiser l'utilisation de la mémoire :

my $packager = SOAP::Packager::MIME->new;
# $packager->parser->decode_headers(1); # pas de différence
# $packager->parser->extract_nested_messages(1); # pas de différence
$packager->parser->output_to_core(0); # beaucoup moins de mémoire
$packager->parser->tmp_to_core(0); # beaucoup moins de mémoire
$packager->parser->tmp_recycling(0); # favorise une collecte de garbage plus rapide
$packager->parser->use_inner_files(1); # pas de différence
my $client = SOAP::Lite->uri($NS)->proxy($URL)->packager($packager);
$client->someMethod();

EXEMPLE CÔTÉ CLIENT

L'exemple de code suivant montre comment utiliser des pièces jointes dans le contexte d'un client SOAP::Lite.

#!/usr/bin/perl
use SOAP::Lite;
use MIME::Entity;
my $ent = build MIME::Entity
  Type        => "text/plain",
  Path        => "attachment.txt",
  Filename    => "attachment.txt",
  Disposition => "attachment";
my $NS = "urn:Majordojo:TemperatureService";
my $HOST = "http://localhost/cgi-bin/soaplite.cgi";
my $client = SOAP::Lite
  ->packager(SOAP::Packager::MIME->new)
  ->parts([ $ent ])
  ->uri($NS)
  ->proxy($HOST);
my $response = $client->c2f(SOAP::Data->name("temperature" => '100'));
print $response->valueof('//c2fResponse/foo');

EXEMPLE CÔTÉ SERVEUR

Le code suivant montre comment utiliser des pièces jointes dans le contexte d'un script CGI. Il montre comment lire les pièces jointes entrantes et comment renvoyer des pièces jointes au client.

#!/usr/bin/perl -w
use SOAP::Transport::HTTP;
use MIME::Entity;
SOAP::Transport::HTTP::CGI
  ->packager(SOAP::Packager::MIME->new)
  ->dispatch_with({'urn:Majordojo:TemperatureService' => 'TemperatureService'})
  ->handle;
BEGIN {
  package TemperatureService;
  use vars qw(@ISA);
  @ISA = qw(Exporter SOAP::Server::Parameters);
  use SOAP::Lite;
  sub c2f {
    my $self = shift;
    my $envelope = pop;
    my $temp = $envelope->dataof("//c2f/temperature");
    use MIME::Entity;
    my $ent = build MIME::Entity
      Type        => "text/plain",
      Path        => "printenv",
      Filename    => "printenv",
      Disposition => "attachment";
    # lire les pièces jointes
    foreach my $part (@{$envelope->parts}) {
      print STDERR "soaplite.cgi: attachment found! (".ref($part).")\n";
      print STDERR "soaplite.cgi: contents => ".$part->stringify."\n";
    }
    # envoyer les pièces jointes
    return SOAP::Data->name('convertedTemp' => (((9/5)*($temp->value)) + 32)),
      $ent;
  }
}
