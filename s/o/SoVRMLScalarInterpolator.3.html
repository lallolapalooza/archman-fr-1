Description Détaillée

La classe SoVRMLScalarInterpolator est utilisée pour interpoler des valeurs scalaires.

Interpolateur scalaire {
  eventIn SFFloat set_fraction         # (-inf, inf)
  field MFFloat key           []     # (-inf, inf)
  field MFFloat keyValue      []     # (-inf, inf)
  eventOut SFFloat value_changed
}

Ce nœud interpole linéairement entre une liste de valeurs SFFloat. Cet interpolateur convient à tout paramètre défini en utilisant une seule valeur flottante. Les exemples incluent la largeur, le rayon et l'intensité de champs. La cléValue doit contenir exactement autant de nombres qu'il y a de keyframes dans la cléField. Une discussion plus détaillée sur les interpolateurs est disponible dans la section 4.6.8, nœuds d'interpolation (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.8).
