Description

La classe SoTexture3Transform est utilisée pour définir des transformations de textures 3D.

Les textures appliquées aux formes de la scène peuvent être transformées en "préfixant" dans l'état avec des instances de ce type de nœud. Des translations, rotations et mises à l'échelle en 3D sont possibles.

Les paramètres par défaut des champs de ce nœud correspondent à une "transformation nulle", c'est-à-dire aucune transformation.

Notez que cette classe est une extension pour Coin et n'est pas disponible dans l'API originale SGI Open Inventor v2.1.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

Texture3Transform {
    translation 0 0 0
    rotation 0 0 1  0
    scaleFactor 1 1 1
    scaleOrientation 0 0 1  0
    center 0 0 0
}

Detailed Description

This node defines a 3D texture transformation. A 3D texture transformation is a sequence of translation, rotation and scaling applied to texture coordinates.

It is useful for applying the same texture transformation to several objects, or for storing a texture transformation into a separator node. A 3D texture transformation can be applied by using a SoTexture3Transform node within a SoTexture3TransformSeparator node.

To use this node, simply insert it into the scene graph. When the scene graph is traversed, the node will apply the defined transformation to the texture coordinates used by subsequent texture nodes.

The transformation is defined by the following members:

  • translation
  • scaleFactor
  • scaleOrientation
  • center

The order of operations is: scale, then rotate, then translate. The center field is used to define the origin for scale and rotation operations.
