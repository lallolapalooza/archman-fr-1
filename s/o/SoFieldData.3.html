Description détaillée

La classe SoFieldData est un conteneur pour un ensemble prototype de champs.

Cette classe est instanciée une fois pour chaque classe d'objets qui utilise des champs et qui doit pouvoir les importer et les exporter.

Chaque champ d'une classe est stocké avec le nom qu'il a reçu dans sa classe "propriétaire" et un décalage de pointeur vers l'instance dynamique du champ lui-même.

Les ensembles d'énumérations sont stockés avec des paires (nom, valeur), afin de permettre de référencer, lire et sauvegarder les champs de type énuméré par leur nom.

Il est peu probable que les programmeurs d'applications aient besoin d'utiliser directement les méthodes de cette classe.

void SoFieldData::addField (SoFieldContainer * base, const char * name, const SoField * field)

Ajoute un nouveau champ à notre liste interne.

Le nom sera stocké avec un décalage de pointeur entre base et field, qui sera valide pour toutes les instances du type de classe de base.

void SoFieldData::overlay (SoFieldContainer * to, const SoFieldContainer * from, SbBool copyconnections) const

Copie les champs du conteneur from vers le conteneur to. Si copyconnections est TRUE, nous copierons également le champ de connexions from a établi.

Si vous trouvez la signature de la méthode un peu étrange, vous avez raison. Elle aurait dû être une méthode statique (le propriétaire de cette instance de la méthode n'est pas du tout utilisé, en raison de la manière dont la représentation interne des listes de modèles de champs est stockée), mais pour des raisons inconnues, il s'agit d'une méthode dynamique dans Open Inventor. Donc aussi dans Coin, pour maintenir la compatibilité.

int SoFieldData::getIndex (const SoFieldContainer * fc, const SoField * field) const

Retourne l'index interne du field dans fc. Si field ne fait pas partie de fc, retourne -1.

void SoFieldData::addEnumValue (const char * enumname, const char * valuename, int value)

Ajoute soit un nouvel ensemble d'énumérations (avec un membre initial), soit un nouveau membre de valeur à un ensemble d'énumérations existant.

Retourne les noms et les valeurs de l'entrée d'énumération avec le enumname. Le nombre de paires (nom, valeur) disponibles dans l'énumération est retourné dans num.
