Description détaillée

Calculateur général pour les flottants et les vecteurs flottants 3D.

Le SoCalculator utilise les valeurs des champs d'entrée (qui sont soit des valeurs flottantes uniques, soit des vecteurs) comme variables dans les expressions du moteur de forme libre et place les résultats sur les champs de sortie.

Le moteur dispose de seize champs d'entrée ; huit entrées scalaires (a, b, c, d, e, f, g et h), et huit entrées vectorielles (A, B, C, D, E, F, G et H).

Il existe huit champs de sortie ; quatre sorties scalaires (oa, ob, oc et od), et quatre sorties vectorielles (oA, oB, oC et oD).

La syntaxe de l'expression est très similaire à C/C++, avec un ensemble très limité de mots-clés et de fonctions.

Un exemple :

oa = a * (0.5 + b) / c

Multipliera la valeur de a par la valeur de b plus 0.5, divisera ce résultat par c, et placera le résultat dans oa. Comme il s'agit d'un moteur, l'expression ne sera évaluée que lorsque quelqu'un tentera de lire la valeur de oa, et non à chaque fois qu'une entrée sera modifiée.

Toutes les entrées sont des champs multiples, et s'il y a plusieurs valeurs dans une entrée, l'expression sera évaluée une fois pour chaque valeur du champ d'entrée, et la sortie créera autant de valeurs qu'il y aura de valeurs dans le champ d'entrée.

S'il y a plus d'un champ d'entrée, et que les champs d'entrée n'ont pas le même nombre de valeurs, le moteur créera autant de valeurs de sortie que le champ d'entrée ayant le plus grand nombre de valeurs. Lorsque l'indice dépasse les limites pour un autre champ d'entrée, la dernière valeur du champ sera utilisée.

Les expressions vectorielles sont similaires aux expressions scalaires. Un exemple :

oA = A + vec3f(1.0, 0.0, 0.0) * B

Prendra le vecteur A, ajoutera la valeur de B multipliée par (1,0,0), et placera le résultat dans oA.

En plus des opérations arithmétiques régulières, la syntaxe SoCalculator inclut également quelques fonctions.

Fonctions scalaires :

  • cos(x) - fonction cosinus (x en radians)
  • sin(x) - fonction sinus
  • tan(x) - fonction tangente
  • acos(x) - fonction arc cosinus
  • asin(x) - fonction arc sinus
  • atan(x) - fonction arc tangente
  • atan2(y, x) - fonction arc tangente à deux variables (y, x).
  • cosh(x) - fonction cosinus hyperbolique
  • sinh(x) - fonction sinus hyperbolique
  • tanh(x) - fonction tangente hyperbolique
  • sqrt(x) - fonction racine carrée
  • pow(x,y) - x élevé à la puissance y
  • exp(x) - e élevé à la puissance x
  • log(x) - logarithme népérien de x
  • log10() - logarithme en base 10 de x
  • ceil(x) - arrondit x à l'entier supérieur le plus proche
  • floor(x) - arrondit x à l'entier inférieur le plus proche
  • fabs(x) - valeur absolue
  • fmod(x, y) - reste de la division de x par y
  • rand(x) - valeur pseudo-aléatoire entre 0 et 1

Fonctions vectorielles :

  • cross(x, y) - produit vectoriel de x et y
  • dot(x,y) - produit scalaire de x et y (renvoie une valeur scalaire)
  • length(x) - longueur de x (renvoie une valeur scalaire)
  • normalize(x) - renvoie la version normalisée de x
  • x[y] - accède aux composantes de x (y doit être une valeur scalaire dans l'intervalle [0,2])

Il existe également quelques constantes nommées qui peuvent être utilisées :

  • MAXFLOAT
  • MINFLOAT
  • M_E
  • M_LOG2E
  • M_LOG10E
  • M_LN2
  • M_PI
  • M_SQRT2 - sqrt(2)
  • M_SQRT1_2 - sqrt(1/2)

Le seul flux de contrôle disponible est l'opérateur ?. Un exemple :

oa = (a > b) ? (a * 0.5) : (b * c)

(Les parenthèses ne sont pas nécessaires, elles sont là juste pour rendre l'exemple plus facile à lire)

En plus des opérateurs de comparaison standard (<, >, <=, >=, ==, !=), vous pouvez également utiliser && (ET) et || (OU) pour combiner des expressions, et l'opérateur unaire ! (NON).

Une dernière chose qui mérite d'être mentionnée sont les variables temporaires. Il existe seize variables temporaires qui peuvent être utilisées dans les expressions. ta, tb, tc, td, te, tf, tg, et th sont des variables scalaires, et tA, tB, tC, tD, tE, tF, tG, et tH sont des variables vectorielles. Elles sont généralement utilisées lorsque plusieurs expressions doivent être évaluées dans l'ordre.

Un exemple avec trois expressions :

ta = a * b; tb = c + d; tc = e - f
tA = vec3f(ta, tb, tc) + A
oA = tA * B

L'exemple montre simplement comment les variables temporaires peuvent être utilisées pour rendre vos expressions plus faciles à lire. Veuillez noter qu'il est possible d'avoir plusieurs instructions dans une seule expression. Vous les séparez simplement avec des points-virgules.

Voici un exemple simple de la façon dont un moteur SoCalculator peut être utilisé dans un fichier .iv :

DEF mycamera PerspectiveCamera {
  orientation 1 0 0 1.57
}
DEF headlight DirectionalLight {
  intensity 0.8
  direction 0 0 1
}
Separator {
  # Render a cube not affected by lighting
  LightModel { model BASE_COLOR }
  BaseColor { rgb = Calculator {
                      a = USE headlight . intensity
                      expression [ "oA = vec3f( a, a, a)" ]
                    } . oA }
  Cube {}
}

Dans l'exemple, la couleur du Cube est une fonction de l'intensité de la Lumière Directionnelle, même si le Cube est rendu sans éclairage en raison du LightModel BASE_COLOR.
