Detalles de la descripción

Sección 5

Documentación de enumeraciones de miembros

enum SoOneShot::Flags

Hay dos marcos disponibles: RETRIGGERABLE causará al motor para reiniciar en 0 si el campo SoOneShot::trigger se activa durante una ejecución (de lo contrario, el trigger se ignora durante las ejecuciones).

HOLD_FINAL hará que los salidas del motor conserven sus valores después de una ejecución, en lugar de resetearlas.

Description Détaillée

La clase SoOneShot es un temporizador que se ejecuta durante un tiempo configurable y luego se detiene.

Documentation des énumérations membres

Énumération SoOneShot::Flags

Il existe deux drapeaux disponibles : RETRIGGERABLE fera que le moteur redémarre à 0 si le champ SoOneShot::trigger est activé pendant une exécution (sinon, le déclencheur est ignoré pendant les exécutions).

HOLD_FINAL fera que les sorties du moteur conservent leurs valeurs après une exécution, au lieu d'être réinitialisées.
