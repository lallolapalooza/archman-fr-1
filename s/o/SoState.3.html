Description Détaillée

La classe SoState gère les données d'état de parcours du graphe de scène Coin.

La classe SoState est utilisée par les actions dérivées de la classe SoAction. Elle gère l'état du graphe de scène sous forme de piles d'éléments (c'est-à-dire d'instances de classes dérivées de SoElement).

Pour plus d'informations sur le fonctionnement interne des états de parcours dans Coin, nous recommandons le livre The Inventor Toolmaker (ISBN 0-201-62493-1), également disponible dans la bibliothèque en ligne de SGI. Recherchez "Toolmaker".

Documentation Constructeur & Destructeur

SoState::SoState (SoAction * leAction, const SoTypeList & elementsHabilites)

Le constructeur. L'argument leAction est l'objet action dont fait partie l'état, et l'argument elementsHabilites est une SoTypeList des éléments qui sont habilités pour cette action.

Le constructeur empile un élément par défaut sur les index de toutes les piles d'éléments habilités. SoElement::push() n'est pas appelé sur les éléments initiaux dans les piles SoState, mais SoElement::init() l'est.

SoState::~SoState (void )

Le destructeur.

Notez que lors de la destruction, les événements en attente causés par l'évaluation paresseuse ne seront pas exécutés.

Documentation Fonctions Membre

SoAction * SoState::getAction (void ) const

Cette méthode renvoie le pointeur vers l'instance d'action donnée au constructeur.

SoElement * SoState::getElement (const int stackindex)

Cette méthode renvoie une instance modifiable de l'élément au sommet de la pile avec l'index de pile donné. En raison de la programmation paresseuse, cette fonction peut nécessiter un certain travail, donc SoState::getConstElement() devrait être utilisé à la place dans la mesure du possible.

const SoElement * SoState::getConstElement (const int stackIndex) const [inline]

Cette méthode renvoie un pointeur vers l'élément supérieur de la pile d'éléments donnée. L'élément est en lecture seule et ne doit en aucun cas être modifié sous peine de conséquences imprévues.

Notez que cette fonction lèvera une assertion si l'élément avec l'identité de pile donnée n'est pas actuellement dans la pile d'état. Pour vérifier si un élément est présent dans la pile, utilisez SoState::isElementEnabled().

void SoState::push (void )

Cette méthode empile l'état d'un niveau vers le bas. Cela sauvegarde l'état afin qu'il puisse être modifié puis restauré à cet état en appelant SoState::pop().

Le mécanisme d'empilement et de dépilement est effectué paresseusement pour des raisons d'efficacité (évite beaucoup d'allocations mémoire et de copies). Ce n'est que lorsqu'un élément d'état va réellement être modifié que cet élément sera réellement empilé.

void SoState::pop (void )

Cette méthode dépile l'état pour le restaurer à un état précédent. Les dépilements sont effectués avec empressement mais le code est très optimisé, il n'y a donc pas lieu de s'inquiéter de l'efficacité.

void SoState::print (FILE *const file = stdout) const

Cette méthode est uniquement à des fins de débogage.

SbBool SoState::isElementEnabled (const int stackindex) const [inline]

Cette méthode renvoie TRUE si l'élément avec l'index de pile d'élément donné est habilité, et FALSE sinon.

int SoState::getDepth (void ) const

Cette méthode renvoie la profondeur actuelle de la pile d'état.

La profondeur est "virtuelle", pas nécessairement physique.

Contrôle si un cache est ouvert.

SbBool SoState::isCacheOpen (void ) const [inline]

Renvoie si un cache est ouvert.
