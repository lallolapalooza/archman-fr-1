Description détaillée

La classe SoBlinker est un nœud de commutation cyclique.

Ce nœud de commutation fait cycler ses enfants SoBlinker::speed fois par seconde. Si le nœud n'a qu'un seul enfant, il sera activé et désactivé. Le cyclage peut être désactivé à l'aide du champ SoBlinker::on, et le nœud se comporte alors comme un nœud SoSwitch normal.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

Blinker {
    whichChild -1
    speed 1
    on TRUE
}
