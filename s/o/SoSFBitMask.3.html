Description Détaillée

La classe SoSFBitMask est un conteneur pour un ensemble d'indicateurs binaires.

Ce champ est utilisé lorsque les nœuds, moteurs ou autres conteneurs de champs doivent stocker un ensemble particulier d'indicateurs binaires à partir d'un ensemble énuméré.

Un champ de ce type stocke sa valeur dans le fichier en utilisant les noms symboliques, plutôt que le masque binaire réel. Si plus d'un bit est défini dans la valeur lors de l'exportation, les bits sont écrits comme suit : "(NOM_DU_BIT|NOM_DU_BIT|NOM_DU_BIT|...)".

Les instances de SoSFBitMask sont dérivées des instances de SoSFEnum et sont initialisées de la même manière en utilisant exactement les mêmes macros liées aux champs énumérés.
