Description détaillée

La classe SoAudioRenderAction rend les parties audio de la hiérarchie de scènes.

En appliquant cette méthode sur un nœud racine pour une hiérarchie de scènes, un chemin ou une liste de chemins rendra tous les nœuds liés au son contenus dans cette instance vers le SoAudioDevice actuel.

Description

The SoAudioRenderAction is a traversal action that is used to render audio nodes in a scene graph. It traverses the scene graph and calls the appropriate methods on audio nodes to generate audio output.

The action starts by calling beginTraversal() on the root node of the scene graph. This method can be overridden to perform any initialization that needs to be done before the traversal begins.

The action then traverses the scene graph, visiting each node and calling its GLRender() or audioRender() method, depending on the type of node.

The action ends by calling endTraversal() on the root node of the scene graph. This method can be overridden to perform any cleanup that needs to be done after the traversal has completed.

Member Function Documentation

virtual void SoAudioRenderAction::beginTraversal (SoNode * node) [protected], [virtual]

This virtual method is called from SoAction::apply(), and is the entry point for the actual scene graph traversal.

It can be overridden to initialize the action at traversal start, for specific initializations in the action subclasses inheriting SoAction.

Default method just calls traverse(), which any overridden implementation of the method must do too (or call SoAction::beginTraversal()) to trigger the scene graph traversal.
