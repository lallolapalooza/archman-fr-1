NOM

Sort::Key::Natural - tri naturel rapide

SYNOPSIS

use Sort::Key::Natural qw(natsort);
my @data = qw(foo1 foo23 foo6 bar12 bar1
              foo bar2 bar-45 foomatic b-a-r-45);
my @sorted = natsort @data;
print "@sorted\n";
# imprime:
#   b-a-r-45 bar1 bar2 bar12 bar-45 foo foo1 foo6 foo23 foomatic
use Sort::Key::Natural qw(natkeysort);
my @objects = (...);
my @sorted = natkeysort { $_->get_id } @objects;

DESCRIPTION

Ce module étend la famille des modules Sort::Key pour supporter le tri naturel.

Dans le tri naturel, les chaînes sont divisées en parties aux frontières des mots et des nombres, et les parties résultantes sont comparées ainsi :

  • Les chaînes numériques sont comparées numériquement
  • Les chaînes alphabétiques sont comparées lexicographiquement
  • Les chaînes numériques précèdent toujours les chaînes alphabétiques

Les espaces, symboles et caractères non imprimables sont considérés uniquement pour diviser la chaîne en ses parties, mais pas pour le tri. Par exemple, "foo-bar-42" est divisé en trois parties "foo", "bar" et 42, et les tirets sont ensuite ignorés.

Note : le tri est sensible à la casse. Pour effectuer un tri insensible à la casse, vous devez explicitement convertir les clés :

my @sorted = natkeysort { lc $_ } @data

De plus, une fois ce module chargé, le nouveau type "natural" (ou "nat") sera disponible dans Sort::Key::Maker. Par exemple :

use Sort::Key::Natural;
use Sort::Key::Maker i_rnat_keysort => qw(integer -natural);

crée un trieur multi-clés "i_rnat_keysort" qui accepte deux clés, la première à comparer comme un entier et la seconde en ordre décroissant.

Il existe également des fonctions de tri naturel alternatives qui reconnaissent les nombres à virgule flottante. Elles utilisent le type de clé "natwf" (raccourci pour "natural_with_floats").

FONCTIONS

Les fonctions importables de ce module sont :

natsort @data
renvoie les éléments de @data triés en ordre naturel.
rnatsort @data
renvoie les éléments de @data triés en ordre naturel décroissant.
natkeysort { CALC_KEY($_) } @data
renvoie les éléments de @array triés naturellement selon les clés obtenues en appliquant "CALC_KEY".
rnatkeysort { CALC_KEY($_) } @data
est similaire à "natkeysort" mais trie les éléments en ordre décroissant.
natsort_inplace @data
rnatsort_inplace @data
natkeysort_inplace { CALC_KEY($_) } @data
rnatkeysort_inplace { CALC_KEY($_) } @data
ces fonctions sont respectivement similaires à "natsort", "rnatsort", "natsortkey" et "rnatsortkey", mais elles trient la liste @data en place.
$key = mkkey_natural $string
étant donné $string, renvoie une clé qui peut être comparée lexicographiquement avec une autre clé obtenue de la même manière, donnant le même ordre que la comparaison des chaînes originales en tri naturel.
natwfsort @data
rnatwfsort @data
natwfkeysort { CALC_KEY($_) } @data
rnatwfkeysort { CALC_KEY($_) } @data
natwfsort_inplace @data
rnatwfsort_inplace @data
natwfkeysort_inplace { CALC_KEY($_) } @data
rnatwfkeysort_inplace { CALC_KEY($_) } @data
mkkey_natural_with_floats $key
cette série de fonctions est similaire à leur homologue s/natwf/nat/ mais elles respectent les nombres à virgule flottante dans les chaînes.

Dans ce contexte, un nombre à virgule flottante est une chaîne qui correspond au motif régulier "/[+\-]?\d+(\.\d*)?/". Note : les nombres sans partie entière (comme ".2" ou "-.12") ne sont pas reconnus.

Notez également que les nombres sans partie entière (comme ".2" ou "-.12") ne sont pas pris en charge.

VOIR AUSSI

Sort::Key, Sort::Key::Maker.

D'autres modules offrant une fonctionnalité similaire incluent Sort::Naturally.
