Description Détaillée

La classe SoTexture2Transform est utilisée pour définir des transformations de textures 2D.

Les textures appliquées aux formes dans la scène peuvent être transformées en ajoutant en préfixe dans l'état des instances de ce type de nœud. Les translations, rotations et mises à l'échelle en 2D peuvent toutes être effectuées.

Les paramètres par défaut des champs de ce nœud correspondent à une "transformation nulle", c'est-à-dire aucune transformation.

FORMAT DE FICHIER/PAR DEFAUT :

Texture2Transform {
    translation 0 0
    rotation 0
    scaleFactor 1 1
    center 0 0
}
