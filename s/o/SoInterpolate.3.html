Le SoInterpolate est la classe de base pour tous les moteurs d'interpolation.

Les interpolateurs sont utilisés pour interpoler linéairement entre deux valeurs.

Chez Coin, nous avons choisi d'implémenter tous les interpolateurs dans des fichiers séparés. Si vous souhaitez être compatible avec OIV lors de la programmation, incluez SoInterpolate.h et non les fichiers d'interpolateur dont vous avez besoin.

Documentation Donnees Membre

SoSFFloat SoInterpolate::alpha

La valeur qui indique dans quelle mesure nous interpolons de la première valeur à la seconde. Une valeur égale à 0 donne un résultat égal à la première valeur, une valeur égale à 1 donne la seconde valeur, et toute valeur intermédiaire donne une interpolation "pondérée" entre les deux valeurs.

SoEngineOutput SoInterpolate::output

Valeurs interpolées des entrées. Le type du résultat sera le même que le type des entrées de chaque sous-classe non abstraite héritant de SoInterpolate.
