Description détaillée

La classe SoFieldSensor détecte les changements dans un champ.

Elle attache un champ à un capteur de ce type pour le surveiller, vous permettant ainsi d'agir sur les changements de champ.

Un SoFieldSensor peut agir en tant que callback de suppression de manière autonome et ne nécessite pas de notification basée sur le temps.

Documentation des fonctions membres

void SoFieldSensor::attach (SoField * field)

Attache un capteur à un champ. Chaque fois que la valeur du champ change, le capteur sera déclenché et appellera la fonction de rappel.

Un capteur de champ ne peut être attaché qu'à un seul champ à la fois. Lorsque cette méthode est appelée plusieurs fois, chaque appel ultérieur remplacera le champ que le capteur surveille par le nouveau field.

Lorsque le champ donné est supprimé, le capteur est automatiquement détaché.

void SoFieldSensor::detach (void )

Détache le capteur d'un champ. Tant qu'un SoFieldSensor est détaché, il n'appellera jamais sa fonction de rappel.
