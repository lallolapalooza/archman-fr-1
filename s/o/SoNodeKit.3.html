Description détaillée

La classe SoNodeKit est utilisée pour initialiser les classes du nodekit.

La seule fonction de SoNodeKit est d'être un simple espace réservé pour le code d'initialisation de haut niveau de toutes les classes liées aux nodekits.

Documentation des fonctions membres

void SoNodeKit::init (void ) [statique]

Initialise le système nodekit.

Notez que cette méthode n'est *pas* appelée implicitement depuis SoDB::init(). En fait, cette méthode appelle elle-même SoDB::init() pour s'assurer que toutes les classes sous-jacentes aux classes nodekit ont été initialisées.

Cette méthode est également appelée depuis SoInteraction::init(), car la fonctionnalité d'interaction dans Coin dépend des classes nodekit.
