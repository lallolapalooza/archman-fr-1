Description détaillée

La classe SoToVRMLAction construit un nouveau graphe de scène n'utilisant que des nœuds VRML 1.0.

Cette action est utilisée pour convertir un graphe de scène de nœuds VRML2/VRML97 en un nouveau graphe de scène utilisant uniquement des nœuds compatibles VRML1.

Une limitation actuelle de cette action est que les nœuds spécifiques à Inventor / Coin (c'est-à-dire les nœuds ni compatibles VRML1 ni VRML97) ne sont pas convertis, ils sont simplement ignorés.

DESCRIPTION

Cette classe est une implémentation de SoAction qui convertit une graphique de scène Open Inventor en une graphique de scène VRML.

L'action construit une nouvelle graphique de scène en parcourant la graphique de scène d'origine. Les informations collectées pendant le parcours sont utilisées pour construire la nouvelle graphique de scène VRML. L'utilisateur peut contrôler le processus de conversion à l'aide des méthodes setter fournies par cette classe.

L'action est implémentée en utilisant le système de parcours de SoAction. Les méthodes virtuelles comme beginTraversal(), endTraversal(), doAction(), etc. peuvent être surécrites pour personnaliser le comportement de l'action.

Cette classe est utilisée pour générer des fichiers VRML à partir de graphiques de scène Open Inventor. Par exemple, elle peut être utilisée pour exporter des modèles 3D créés dans Open Inventor dans un format compatible VRML.

void SoToVRMLAction::apply (SoPath * path) [virtual]

Applique l'action aux parties de la graphique définies par path.

Note : Un SoPath contiendra également tous les nœuds qui peuvent influencer, par exemple, les nœuds géométriques sur le chemin. Par conséquent, l'application d'un SoGLRenderAction à un SoPath rendra ce chemin comme prévu dans la vue, où les matériaux, textures et autres paramètres d'apparence seront gérés correctement.

Si le path se termine par un nœud SoGroup, l'action parcourra également les enfants du nœud final.

void SoToVRMLAction::apply (const SoPathList & pathlist, SbBool obeysrules = FALSE) [virtual]

Applique l'action aux graphiques définies par pathlist. Si obeysrules est TRUE, pathlist doit satisfaire les quatre conditions suivantes (ce qui est le cas pour les listes de chemins renvoyées par les actions de recherche pour les nœuds non-groupe et les listes de chemins renvoyées par les actions de sélection) :

Tous les chemins doivent commencer au même nœud tête. Tous les chemins doivent être triés dans l'ordre de parcours. Les chemins doivent être uniques. Aucun chemin ne peut continuer à travers le point final d'un autre chemin.

void SoToVRMLAction::beginTraversal (SoNode * node) [protected], [virtual]

Cette méthode virtuelle est appelée depuis SoAction::apply(), et constitue le point d'entrée pour le parcours réel de la graphique de scène.

Elle peut être surécrite pour initialiser l'action au début du parcours, pour des initialisations spécifiques dans les sous-classes de SoAction.

La méthode par défaut appelle simplement traverse(), ce que toute implémentation surécrite de la méthode doit également faire (ou appeler SoAction::beginTraversal()) pour déclencher le parcours de la graphique de scène.
