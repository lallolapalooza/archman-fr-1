Description détaillée

La classe SoPickedPoint est utilisée pour spécifier les points sélectionnés.

Elle contient diverses informations sur le point sélectionné, telles que la position, la normale, la coordonnée de texture et l'index du matériau dans le matériau courant. Elle peut également contenir des informations de détail (une sous-classe de SoDetail) pour chaque nœud du chemin sélectionné.

Detailed Description

This class stores information about a primitive that has been picked.

The information includes the detail, which is an instance of a subclass of SoDetail, and the node that owns the primitive that was picked.

The material index is also stored, which might be useful for assigning different materials to primitives.

A pointer to a SoPickedPoint object is passed to the traversal methods of actions that can perform picking, such as SoRayPickAction.
