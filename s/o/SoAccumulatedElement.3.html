Description Détaillée

La classe SoAccumulatedElement est une classe abstraite pour stocker un état accumulé.

C'est la super-classe des éléments où les nouvelles données d'élément s'accumulent avec les anciennes données.

L'élément stocke des identifiants de nœud pour tous les nœuds accumulés pendant le parcours pour l'état actuel. Ces identifiants sont utilisés pour déterminer quand invalider les caches.

Detailed Description

This element is the base class for elements that accumulate node ids. Accumulated elements are used for managing state that is common for a node and all its descendants. The accumulated elements are pushed onto the state when the corresponding node is visited, and they are popped off the state when the traversal exits the node. The previous element can be found using SoElement::getNextInStack().
