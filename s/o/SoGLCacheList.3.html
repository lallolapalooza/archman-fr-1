Documentation Fonction Membre

SbBool SoGLCacheList::call (SoGLRenderAction * action)

Teste la validité d'un cache et l'exécute. Renvoie TRUE si un cache valide a pu être trouvé, FALSE sinon. Notez que lorsqu'un cache valide est trouvé, il est exécuté avant de sortir de cette méthode.

void SoGLCacheList::open (SoGLRenderAction * action, SbBool autocache = TRUE)

Commence l'enregistrement d'un nouveau cache. N'oubliez pas d'appeler close() lorsque vous avez terminé l'enregistrement du cache.
