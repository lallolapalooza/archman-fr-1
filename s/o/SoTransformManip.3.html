SoTransformManip

Modifica un nodo de transformación.

Este manipulador permite la modificación interactiva de un nodo de transformación.

Los manipuladores son nodos especiales que se utilizan para interactuar con los gráficos de escena. Cuando se añade un manipulador a un gráfico de escena, generalmente se añade como un sustituto de un nodo existente (por ejemplo, un nodo de transformación) o como un nodo separado en un gráfico de escena de manipulación. Los manipuladores utilizan un SoDragger para recibir la entrada del usuario.

El SoTransformManip es la clase base para todos los manipuladores de transformación interactiva. Las subclases incluyen SoScaleManip, SoRotateManip, SoTranslateManip, SoTrackballManip, SoExamineViewer, SoCamera, SoDirectionalLight, SoEventCallback, SoFieldSwitch, SoGradientBackground, SoInfo, SoNode, SoNodeKitPath, SoNodeOperation, SoNodeOutput, SoNodeSensor, SoNodeStack, SoNodeTexture, SoNodeValue, SoNodeVar, SoPath, SoPattern, SoPerfGraph, SoPointLight, SoRenderMaterial, SoRenderStyle, SoScene, SoScript, SoShape, SoShadowGroup, SoSpotLight, SoStereo, SoSwitch, SoText2, SoText3, SoTexture2, SoTexture3, SoTextureCube, SoTextureLOD, SoTextureMovie, SoTextureScale, SoTextureText, SoTextureTransform, SoTextureUnit, SoTextureUnitState, SoTransform, SoTransformBox, SoTransformGizmo, SoTransformManip, SoTransformStyle, SoViewer, y SoVRML.

Consulte también SoDragger, SoNode, SoNodeKitPath, SoPath, SoSeparator, SoSwitch, SoTransformation, SoTransformBox, SoTransformGizmo, SoTransformStyle.

Métodos

En adición a los campos heredados de la clase SoNode, los siguientes campos están disponibles:

El manipulador de transformación tiene una lista de campos de transformación que controla. Por defecto, es sólo la matriz de transformación del manipulador. Los manipuladores de transformación específicos pueden añadir otros campos de transformación a esta lista. Por ejemplo, un SoScaleManip añade el campo de escala.

SbBool SoTransformManip::attach (const SoNode * ) [virtual]

Adjunta este manipulador a un nodo en el gráfico de escena. El nodo debe ser una instancia de una clase de nodo derivada de SoTransform.

El manipulador copiará automáticamente los datos de campo del nodo, para que inicialmente afecte el estado de forma similar al nodo.

Devuelve TRUE si la operación es exitosa, y FALSE si el nodo dado no puede ser adjuntado por este manipulador.

void SoTransformManip::copyContents (const SoFieldContainer * from, SbBool copyconnections) [protected], [virtual]

Hace una copia profunda de todos los datos de from a este instancio, excepto si copyconnections es FALSE, en que caso se excluirán referencias externas al gráfico de escena.

Esta es la función que debería ser sobreescrita por nodos extendidos / motor / dragger / cualquier otra subclase que necesiten gestionar datos internos no gestionados automáticamente.

Para copiar nodos desde código de aplicación, no invocar esta función directamente, sino utilizar la función SoNode::copy():

SoNode * mynewnode = templatenode->copy();

El mismo también se aplica para motores.

Asegúrate de que cuando sobreescapas el método copyContents() en tu clase extendida, también lo llames hacia arriba en la jerarquía de herencia, como copyContents() en por ejemplo SoNode y SoFieldContainer. Deberías algo así:

void
MyCoinExtensionNode::copyContents(const SoFieldContainer * from,
                                  SbBool copyconnections)
{
  // delega las tareas de los superclases (copiar campos, copiar nombre de instancia, etc.)
  SoNode::copyContents(from, copyconnections);
  // [..luego copia los datos internos..]
}

Detalles de la descripción

Esta clase es una clase base abstracta para manipuladores de transformación. Estos manipuladores se utilizan para manipular un nodo de transformación (por ejemplo, SoTransform, SoScaleTransform, SoRotationTransform). Implementa la funcionalidad común para los manipuladores de transformación, como la creación de SoFieldSensor para la rotación, la traslación, la escala y los campos de orientación de escala.

Se supone que las clases derivadas tienen los campos de transformación necesarios para manipular y que estos se les asignarán en el constructor. Por ejemplo, SoScaleManip asigna su campo de escala al campo de escala del manipulador de transformaciones y SoRotationManip asigna su campo de rotación al campo de rotación del manipulador de transformaciones.
