NOM

SoShaderParameterArray2f - La classe SoShaderParameterArray2f est utilisée pour définir un tableau bidimensionnel de nombres à virgule flottante comme paramètre de shader.

SYNOPSIS

#include <Inventor/nodes/SoShaderParameter.h>

Description Détaillée

La classe SoShaderParameterArray2f est utilisée pour définir un tableau à deux dimensions de nombres à virgule flottante comme paramètre de shader.
