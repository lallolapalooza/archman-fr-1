Detailed Description

This element is used to override the texture settings of scene graph nodes. It is typically used by the default texture override settings to override the texture settings of primitive shapes.

The element maintains a list of overridden texture nodes. When this element is enabled, any texture settings that are encountered in the scene graph will be ignored, and the overridden texture settings will be used instead.

The element has a single field, on, which is a boolean value that indicates whether texture overriding is currently enabled.
