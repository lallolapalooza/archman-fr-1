Description détaillée

Le SoOverrideElement maintient une liste d'éléments substituables et une liste d'éléments qui doivent être substitués.

Seuls certains éléments peuvent être substitués.

La documentation restante de la classe décrit un cas unique et spécial :

Une requête courante pour une fonctionnalité consiste à substituer uniquement la transparence de l'ensemble du graphe de scène, ou de parties du graphe de scène.

Dans l'Inventor original de SGI, c'est presque impossible, car l'API a été conçue pour ne permettre que de substituer tous les champs ou aucun des champs d'un nœud. Ainsi, appeler SoNode::setOverride() sur un nœud SoMaterial entraînera la substitution de tous les paramètres matériels de ce nœud par tous les paramètres matériels plus loin dans le graphe de scène, et il n'y a aucun moyen de substituer uniquement les paramètres de transparence.

Dans Coin, nous avons ajouté une petite astuce pour surmonter ce problème, car il s'agit d'une requête de fonctionnalité très courante : pour avoir des paramètres de substitution de transparence séparés, définissez la variable d'environnement COIN_SEPARATE_DIFFUSE_TRANSPARENCY_OVERRIDE à "1" pour activer cette astuce.

(Notez cependant que cela ne fonctionnera pas lorsque le nœud SoPackedColor ou SoVertexProperty est utilisé pour spécifier la couleur diffuse et la transparence -- uniquement avec le nœud SoMaterial.)

Voici un exemple complet et autonome qui montre comment y parvenir :

#include <Inventor/Qt/SoQt.h>
#include <Inventor/Qt/viewers/SoQtExaminerViewer.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/nodes/SoMaterial.h>
// *************************************************************************
const char * scene = "#Inventor V2.1 asci\n"
"\n"
"Separator {"
"   Cone { }"
"   Translation { translation 1 0 5 }"
""
"   DEF OVERRIDEMATERIAL Material { transparency 0.5 }"
""
"   DEF OBJMATERIAL Material {"
"      diffuseColor 0.5 0 0"
"      transparency 0"
"   }"
"   Sphere { }"
"}"
;
int
main(int argc, char ** argv)
{
  QWidget * window = SoQt::init(argv[0]);
  (void)coin_setenv("COIN_SEPARATE_DIFFUSE_TRANSPARENCY_OVERRIDE", "1", TRUE);
  SoInput * in = new SoInput;
  in->setBuffer(scene, strlen(scene));
  SoSeparator * root = SoDB::readAll(in);
  assert(root);
  delete in;
  root->ref();
  SoMaterial * overridemat = (SoMaterial *)
    SoBase::getNamedBase("OVERRIDEMATERIAL", SoMaterial::getClassTypeId());
  assert(overridemat);
  overridemat->diffuseColor.setIgnored(TRUE);
  overridemat->setOverride(TRUE);
  SoQtExaminerViewer * viewer = new SoQtExaminerViewer(window);
  viewer->setSceneGraph(root);
  viewer->show();
  SoQt::show(window);
  SoQt::mainLoop();
  delete viewer;
  root->unref();
  return 0;
}

Detailed Description

This element allows rendering state to be overridden. When an override is set, the rendering state is updated to match the node that set the override, regardless of the rendering state that existed before.

This element is not intended to be used directly by application programmers. It is used internally by the Coin rendering engine.
