Description Détaillée

La classe SoRenderManager est utilisée pour contrôler le rendu d'un graphe de scène.

Vous pouvez utiliser cette classe pour configurer des choses comme les plans de découpage, le mode de rendu, le rendu stéréo et la couleur de fond. Dans les versions antérieures de Coin/Inventor, cela était configuré dans les kits d'outils d'interface graphique, ce qui rendait très difficile la création d'une nouvelle visionneuse Coin pour un autre kit d'outils d'interface graphique. Avec cette nouvelle classe, il suffit de créer une instance SoRenderManager par visionneuse/vue.

Cette classe ne gère pas les événements pour le graphe de scène/la visionneuse. Pour cela, vous pouvez utiliser la classe SoEventManager.

Depuis

Coin 3.0

Documentation des Énumérations Membre

enum SoRenderManager::RenderMode

Définit la manière dont les primitives sont rendues.

Énumérateur

AS_IS
Rendre les primitives telles qu'elles sont décrites dans le graphe de scène.
WIREFRAME
Rendre les polygones en mode filaire.
POINTS
Rendre uniquement les sommets des polygones et des lignes.
WIREFRAME_OVERLAY
Rendre une superposition filaire en plus du mode AS_IS.
HIDDEN_LINE
Comme WIREFRAME, mais écarte les lignes qui ne seraient normalement pas affichées en raison de l'écrêtage géométrique.
BOUNDING_BOX
Afficher uniquement la boîte englobante de chaque objet.
SHADED_HIDDEN_LINES
Rendre les lignes cachées en pointillés avec des lignes visibles pleines en utilisant une approche de rendu en trois passes.

enum SoRenderManager::StereoMode

Gère la manière dont le rendu stéréo est effectué.

MONO
Rendu mono (pas de rendu stéréo).
ANAGLYPH
Rendu stéréo anaglyphe (lunettes rouge/cyan).
SEPARATE_OUTPUT
Rendu stéréo avec sortie séparée (par exemple, deux moniteurs ou deux cartes graphiques).
QUAD_BUFFER
Identique à SEPARATE_OUTPUT.
INTERLEAVED_ROWS
Rendu stéréo entrelacé par lignes.
INTERLEAVED_COLUMNS
Rendu stéréo entrelacé par colonnes.

enum SoRenderManager::BufferType

Spécifie si le double tampon est activé.

Énumérateur

BUFFER_SINGLE
Utiliser un seul tampon.
BUFFER_DOUBLE
Utiliser un double tampon.

enum SoRenderManager::AutoClippingStrategy

Stratégies pour le découpage automatique des plans proche et lointain.

Énumérateur

NO_AUTO_CLIPPING
Pas de découpage automatique.
FIXED_NEAR_PLANE
Utiliser une valeur fixe pour le plan proche.
VARIABLE_NEAR_PLANE
Ajuster dynamiquement la valeur du plan proche.

Énumérateur

MONO
Pas de rendu stéréoscopique
ANAGLYPH
Le rendu anaglyphe est utilisé pour fournir un effet 3D stéréoscopique, lorsqu'il est visualisé avec des lunettes 3D. L'image est composée de deux couches de couleur qui se superposent, et apparaît en 3 dimensions lorsqu'elle est visualisée à travers des filtres colorés correspondants (lunettes).
SEPARATE_OUTPUT
Envoyer la sortie vers des tampons séparés.
QUAD_BUFFER
Identique à SEPARATE_OUTPUT, SEPARATE_OUTPUT est plus couramment connu sous le nom de QUAD_BUFFER, lorsqu'on utilise également le double buffering.
INTERLEAVED_ROWS
Rendre chaque deuxième ligne comme image gauche et droite. Si rendu avec un projecteur polarisé, des filtres polarisés peuvent être utilisés pour donner un effet 3D.
INTERLEAVED_COLUMNS
Rendre chaque deuxième colonne comme image gauche et droite. Si rendu avec un projecteur polarisé, des filtres polarisés peuvent être utilisés pour donner un effet 3D.

enum SoRenderManager::BufferType

Énumérateur

BUFFER_SINGLE

BUFFER_DOUBLE

enum SoRenderManager::AutoClippingStrategy

Stratégie pour ajuster le plan de clipping proche/lointain de la caméra

Énumérateur

NO_AUTO_CLIPPING
Désactiver le clipping automatique. L'utilisateur doit définir les valeurs correctes dans la caméra.
FIXED_NEAR_PLANE
Garder le plan proche à une distance fixe de la caméra. Le plan lointain est toujours défini à la fin de la boîte englobante.
VARIABLE_NEAR_PLANE
Ajustement variable du plan proche par rapport à la caméra.

SoRenderManager::Superimposition * SoRenderManager::addSuperimposition (SoNode * scene, uint32_t flags = Superimposition::AUTOREDRAW | Superimposition::ZBUFFERON | Superimposition::CLEARZBUFFER)

Ajoute une superposition pour ce graphe de scène. Une superposition peut être soit une scène rendue en arrière-plan, soit une scène rendue à l'avant du graphe de scène actuel.

C'est utile, par exemple, si vous voulez ajouter un dégradé ou une image en arrière-plan, et pour avoir des informations HUD au premier plan.

Veuillez noter que si vous utilisez des superpositions, l'antialiasing multipasse doit être géré dans le gestionnaire de rendu, et non dans SoGLRenderAction, de sorte que les fonctionnalités de mise à jour des passes dans SoGLRenderAction seront désactivées.
