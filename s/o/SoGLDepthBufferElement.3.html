Description Détaillée

Le SoGLDepthBufferElement contrôle le buffer de profondeur d'OpenGL.

Vous devez noter que cette classe est une extension pour Coin, et n'est pas disponible dans l'API originale d'Open Inventor de SGI v2.1.

Depuis Coin 3.0

Coin 3.0
