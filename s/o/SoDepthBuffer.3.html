Description Détaillée

La classe SoDepthBuffer est un nœud utilisé pour contrôler le tampon de profondeur GL.

Avec ce nœud, vous pouvez contrôler les propriétés liées au tampon de profondeur OpenGL de diverses manières.

  • vous pouvez activer et désactiver le test du tampon de profondeur pendant le rendu,
  • vous pouvez activer et désactiver l'écriture dans le tampon de profondeur pendant le rendu,
  • vous pouvez définir la fonction utilisée pour le test du tampon de profondeur, et
  • vous pouvez définir la plage de valeurs utilisée dans le tampon de profondeur.

Le réglage de la plage de valeurs est utile si vous avez besoin de segmenter le monde 3D en différents segments avec différentes résolutions de tampon de profondeur pour obtenir une distribution de résolution de tampon de profondeur plus optimale que ce qu'une plage de valeurs de tampon de profondeur uniforme peut vous donner.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

DepthBuffer {
    test TRUE
    write TRUE
    function LESS
    range 0 1
}

Notez que cette classe est une extension pour Coin et n'est pas disponible dans l'API originale Open Inventor v2.1 de SGI.

Documentation de l'énumération des membres

enum SoDepthBuffer::DepthWriteFunction

Énumération pour les différentes fonctions de profondeur.

Énumérateur

NEVER
Ne passe jamais.
ALWAYS
Passe toujours.
LESS
Passe si la valeur de profondeur entrante est inférieure à la valeur de profondeur stockée.
LEQUAL
Passe si la valeur de profondeur entrante est inférieure ou égale à la valeur de profondeur stockée.
EQUAL
Passe si la valeur de profondeur entrante est égale à la valeur de profondeur stockée.
GEQUAL
Passe si la valeur de profondeur entrante est supérieure ou égale à la valeur de profondeur stockée.
GREATER
Passe si la valeur de profondeur entrante est supérieure à la valeur de profondeur stockée.
NOTEQUAL
Passe si la valeur de profondeur entrante est différente de la valeur de profondeur stockée.
