NOM

SoapySDRServer - fournir l'accès aux périphériques SoapySDR locaux sur le réseau

SYNTAXE

SoapySDRServer [OPTIONS]

DESCRIPTION

SoapySDRServer est un serveur qui exporte tous les périphériques SoapySDR localement disponibles sur le réseau. De l'autre côté, un module SoapyRemote pour SoapySDR se connecte à ce serveur et fournit les modules du serveur localement.

OPTIONS

--bind[=IP[:PORT]]
Lancer le serveur. Si aucun argument IP n'est donné, se lier au port par défaut 55132 sur toutes les adresses réseau locales. IP est l'adresse IPv4 ou IPv6 à laquelle se lier. Si l'une des valeurs spéciales "0.0.0.0" ou "[::]" est donnée pour IP, elle se liera à toutes les adresses locales. PORT est un numéro de port optionnel à utiliser à la place du port par défaut.
--help
Afficher l'aide et quitter.

PAGE D'ACCUEIL

SoapySDRServer fait partie du projet SoapyRemote.

AUTEURS
