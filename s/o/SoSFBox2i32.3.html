Description détaillée

La classe SoSFBox2i32 est un conteneur pour un vecteur SbBox2i32.

Ce champ est utilisé lorsque des nœuds, des moteurs ou d'autres conteneurs de champs doivent stocker une boîte.

Sachez que cette classe est une extension pour Coin, et qu'elle n'est pas disponible dans l'API originale Open Inventor v2.1 de SGI.
Depuis

Coin 2.5

Detailed Description

This class represents a single field containing a box defined by two 2D integer vectors.

Use setValue() or setValue() to set the box value, and getValue() to get it.
