Description détaillée

La classe SoDebugError est le mécanisme interne de passage de messages de débogage.

Cette classe sert essentiellement deux objectifs :

1) C'est l'interface de message par laquelle les conditions d'erreur et d'avertissement sont transmises au programmeur qui utilise l'API de la bibliothèque Coin pour construire des applications. Ces messages sont générés lorsque les méthodes de l'API sont utilisées de manière incorrecte, ou si des actions sur la bibliothèque l'ont amenée à un état incohérent. Les programmeurs Coin devraient alors être capables de retracer rapidement les erreurs dans leur code d'application.

Pour que ce service soit disponible, la bibliothèque Coin doit être compilée avec des informations de débogage. Pour les versions de production, la majeure partie de ce « filet de sécurité du programmeur » est supprimée pour gagner en vitesse et utiliser un minimum d'espace (construire la bibliothèque la plus petite possible).

2) Les programmeurs d'applications Coin peuvent appeler les méthodes SoDebugError dans leur propre code comme moyen pratique de déboguer le code de leur application, remplaçant les cascades habituelles d'appels fprintf().

Coin prend en charge une variable d'environnement pour définir des points d'arrêt conditionnels. La variable d'environnement COIN_DEBUG_BREAK peut être définie avec un nombre quelconque de fonctions sous forme de liste séparée par des virgules ou des espaces. Les noms de fonctions doivent être donnés sous la forme « classname::functionname » (c'est-à-dire sans type de retour, parenthèses ou types/noms d'arguments). Si un message de débogage est publié à partir de l'une de ces fonctions, votre programme s'arrêtera (en utilisant assert(0)).

Cela peut être utile si vous souhaitez obtenir des core-dumps ou entrer dans un débogueur chaque fois, par exemple, qu'un avertissement ou une erreur est publié à partir d'une fonction (par exemple, « SbVec3f::normalize »). Cette fonctionnalité n'est activée que dans la version de débogage de Coin.

Documentation des fonctions membres

void SoDebugError::setHandlerCallback (SoErrorCB *const function, void *const data) [static]

Cette méthode définit le rappel de gestion des erreurs pour les messages publiés via cette classe.

Notez que cela ne remplacera pas le gestionnaire de messages d'erreur/débogage pour les sous-classes, celles-ci devront être remplacées en appelant la méthode setHandlerCallback() de la sous-classe.

Detailed Description

This class is used for generating debugging messages. It inherits from SoError and provides convenience functions for posting messages with different severity levels.

Member Enumeration Documentation

This class does not have any member enumerations.
