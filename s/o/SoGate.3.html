Description Détaillée

La classe SoGate est utilisée pour copier sélectivement des valeurs d'une entrée à une sortie.

Ce moteur transférera les valeurs du champ SoGate::input au champ SoGate::output lorsque le champ SoGate::enable est à TRUE.

Notez que le champ de sortie de ce moteur dévie un peu du mécanisme de sortie "standard" de la majorité des classes de moteurs : SoGate::output n'est pas une instance permanente de SoEngineOutput, mais un *pointeur* vers une instance de SoEngineOutput. La raison en est qu'il est nécessaire d'allouer dynamiquement le champ de sortie pour qu'il corresponde à ce à quoi SoGate::input est connecté, car le type de SoGate::output doit toujours être le même que le type de SoGate::input.

Le format de fichier pour ce champ est un peu spécial. Notez la spécification du type en tête, qui n'est pas nécessaire pour la plupart des autres types de champs :

Gate {
  type <multivaluefieldtype>
  [...fields...]
}

virtual SoType SoGate::getTypeId (void ) const [virtual]

Retourne l'identification de type d'un objet dérivé d'une classe héritant de SoBase. Ceci est utilisé pour la vérification de type à l'exécution et le transtypage "vers le bas". Exemple d'utilisation :

void foo(SoNode * node)
{
  if (node->getTypeId() == SoFile::getClassTypeId()) {
    SoFile * filenode = (SoFile *)node;  // transtypage vers le bas sans risque, connaît le type
  }
}

Pour les programmeurs d'applications souhaitant étendre la bibliothèque avec de nouveaux nœuds, moteurs, nodekits, draggers ou autres : cette méthode doit être remplacée dans *toutes* les sous-classes. Ceci est généralement fait dans le cadre de la mise en place du système de types complet pour les classes d'extension, ce qui est généralement accompli en utilisant les macros prédéfinies disponibles via par exemple Inventor/nodes/SoSubNode.h (SO_NODE_INIT_CLASS et SO_NODE_CONSTRUCTOR pour les classes de nœuds), Inventor/engines/SoSubEngine.h (pour les classes de moteurs) et ainsi de suite.

Pour plus d'informations sur l'écriture d'extensions Coin, veuillez consulter la documentation de la classe des superclasses de niveau supérieur pour les divers groupes de classes.

SoSFBool SoGate::enable

Définit si le transfert de l'entrée au champ de sortie doit être effectué ou non.

SoSFTrigger SoGate::trigger

Copie les valeurs actuelles du champ d'entrée vers le champ de sortie.

SoMField* SoGate::input

Le champ d'entrée multivalué que nous allons transférer vers la sortie lorsque SoGate::enable est TRUE.

SoEngineOutput* SoGate::output

(SoMField) C'est la sortie de champ contenant les valeurs de SoGate::input.

Le type du champ correspondra bien sûr au type du champ d'entrée.
