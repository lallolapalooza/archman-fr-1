NAME

SoDirectionalLightDragger - La classe SoDirectionalLightDragger fournit une géométrie interactive pour manipuler une source de lumière directionnelle.

DESCRIPTION
SoDirectionalLightDragger est un SoDragger qui crée une géométrie pour manipuler une source de lumière directionnelle. La géométrie du dragger est un grand cercle avec des flèches pointant vers le centre. Le cercle permet de faire pivoter la lumière et les flèches permettent d'incliner la lumière.

UTILISATION
Pour créer une instance de cette classe, vous devez utiliser un SoNodeKitInventorKit et un SoDirectionalLightKit. Voici comment utiliser ce dragger:

Exemple
Le code suivant crée une lumière directionnelle et la manipule avec un dragger:

    // Create a scene with a directional light
    SoNodekitInventorKit *scene = new SoNodekitInventorKit;
    SoDirectionalLightKit *lightKit = new SoDirectionalLightKit;
    scene->addChildren(lightKit);
    
    // Create a dragger for the directional light
    SoDirectionalLightDragger *dragger = new SoDirectionalLightDragger;
    scene->addChildren(dragger);
    
    // Connect the dragger to the light
    dragger->connect(lightKit);
    
    // Add the scene to the viewer
    viewer->addChildren(scene);

Description détaillée

La classe SoDirectionalLightDragger fournit une géométrie interactive pour la manipulation d'une source lumineuse directionnelle.

Voici à quoi ressemble le dragger avec sa géométrie par défaut à l'état inactif :

Ce dragger est particulièrement utile pour définir les champs d'un nœud SoDirectionalLight, car il fournit une géométrie avec laquelle l'utilisateur peut interagir pour un vecteur directionnel.

L'image suivante est un exemple d'action, avec la lumière directionnelle en rouge et la tête de la caméra éclairée sur la droite.

Pour plus de commodité, ce dragger inclut également par défaut la géométrie d'interaction pour placer le dragger lui-même. (SoDirectionalLight n'a pas de champ de position, donc cela était strictement non nécessaire.)

La bibliothèque Coin inclut également une classe de manipulateur, SoDirectionalLightManip, qui encapsule les fonctionnalités fournies par cette classe dans les mécanismes nécessaires pour la relier aux instances de nœuds SoDirectionalLight dans un graphe de scène.

DESCRIPTION

Ce manipulateur permet à l'utilisateur de contrôler la direction d'une lumière directionnelle. L'orientation de la lumière est contrôlée en manipulant le manipulateur dans l'espace 3D. La direction de la lumière est représentée par un vecteur pointant depuis l'origine du manipulateur. La rotation du manipulateur contrôle la direction de la lumière.

Ce manipulateur est généralement utilisé en conjonction avec un nœud SoDirectionalLight ou un manipulateur SoDirectionalLightManip.

Ceci est généralement fait lorsque :

1.
la valeur du champ est NULL et la partie est NULL par défaut
2.
c'est un nœud feuille SoGroup ou SoSeparator sans enfants
3.
c'est une partie de liste feuille sans enfants et un conteneur SoGroup ou SoSeparator
4.
c'est une partie non feuille et qu'elle est de type SoGroup et que tous les champs sont à leurs valeurs par défaut

Les sous-classes devraient généralement la redéfinir pour faire des réglages supplémentaires pour les nouveaux champs membres. Depuis la sous-classe, n'oubliez pas d'appeler "vers le haut" la méthode setDefaultOnNonWritingFields() de votre superclasse.

SoSFRotation SoDirectionalLightDragger::rotation

Ce champ est continuellement mis à jour pour contenir la rotation du vecteur de direction actuel. Le programmeur d'application le connectera généralement au champ de rotation d'un nœud SoDirectionalLight (sauf s'il utilise la classe SoDirectionalLightManip, où cela est géré automatiquement).
