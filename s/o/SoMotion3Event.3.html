Description détaillée

La classe SoMotion3Event contient des informations sur les événements de mouvement 3D.

Les événements Motion3 sont générés par des périphériques capables de "mouvement 3D", par exemple un périphérique Spaceball. Les instances de cette classe contiennent des informations sur les translations et rotations de ces périphériques dans les 3 dimensions.
