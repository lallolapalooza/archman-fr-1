Description détaillée

Cette classe est un conteneur pour les SbVec4i32.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker un tableau de vecteurs à quatre éléments.

Ce champ prend en charge l'échange de données d'application via la méthode setValuesPointer(). Consultez la documentation de SoMField pour savoir comment utiliser cette méthode.

Voir aussi

SbVec4i32, SoSFVec4i32 Remarque : Cette classe est une extension de Coin, et n'est pas disponible dans l'API originale de SGI Open Inventor v2.1.

Depuis

Coin 2.5
