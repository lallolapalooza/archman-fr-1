Description détaillée

La classe SoSFPlane contient une valeur de type SbPlane.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champ doivent stocker une définition unique d'un plan 3D.

Les champs de ce type stockent leur valeur dans le fichier sous la forme d'un vecteur normal et d'un décalage par rapport à l'origine : « v0 v1 v2 offset ».
