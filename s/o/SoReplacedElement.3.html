Description Détaillée

La classe SoReplacedElement est une superclasse d'élément abstraite.

C'est la superclasse de tous les éléments où les nouvelles données d'élément *remplacent* les anciennes données, et où les données que l'élément stocke ne sont pas juste une simple valeur flottante ou entière.

En dehors de cette différence conceptuelle avec sa superclasse, la classe SoReplacedElement surcharge également la méthode getElement() par défaut pour inclure une référence de nœud. Cette référence est utilisée pour récupérer le numéro d'identification unique du nœud qui a modifié l'élément en dernier.

Les valeurs identifiantes des nœuds dans le graphe de scène sont mises à jour lors de *tout* type de modification d'un nœud, donc cette technique joue un rôle important dans la construction, la validation et la destruction des caches internes du graphe de scène.

Detailed Description

Represents an element that may have been replaced by a SoNode in the scene graph. It is intended to be used for the implementation of the SoGLMaterial and SoGLTexture elements (and, more generally, for SoGL elements that are associated with nodes).

The main purpose of SoReplacedElement is to enable better scene graph traversal caching. In the Coin scenegraph traversal system, elements are organized in a stack for each traversal state. When a node is traversed, it may push its own copy of an element onto the stack, replacing the previous element of the same type. In order to optimize caching, we need to know if the new element that was pushed is actually identical to the previous element. If it is, then the cached results of the traversal from that point on can be reused.

The matches() and copyMatchInfo() methods are used to determine if two elements are identical. The matches() method takes another element as an argument and returns TRUE if it is identical to the current element. The copyMatchInfo() method creates a new element that contains the information needed by matches() to perform its check. The node identifier is used to track which node replaced the original element, which is useful for the element's caching mechanisms.

This function overloads SoElement::getElement() with an extra node parameter, to let us set the SoReplacedElement::nodeId in the element instance before returning.
