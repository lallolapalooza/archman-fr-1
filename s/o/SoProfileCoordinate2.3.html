Description détaillée

La classe SoProfileCoordinate2 est un nœud spécifiant un ensemble de coordonnées 2D pour des profils.

Utilisez des nœuds de ce type pour fournir des coordonnées aux profils.

Notez qu'un nœud SoProfileCoordinate2 *remplacera* les coordonnées de profil déjà présentes dans l'état (le cas échéant).

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

ProfileCoordinate2 {
    point 0 0
}
