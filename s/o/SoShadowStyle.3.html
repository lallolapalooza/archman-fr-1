    DESCRIPTION

    The SoShadowStyle node specifies how shadows are rendered for the shapes that follow it in the scene graph. It can enable or disable shadow casting and/or shadow receiving.

    MEMBER FUNCTIONS

    Member methods

    void finish(void)

    Sets the shadow type to the default value (CAST_AND_RECEIVE).
    void setShadowType(ShadowType)
    Sets the shadow type. Possible values are OFF, CAST, RECEIVE, and CAST_AND_RECEIVE.
    ShadowType getShadowType(void) const
    Returns the current shadow type.

    CLASS MEMBERS

    Member Data Documentation

    SoSFEnum shadowType
    Specifies the shadow type. The possible values are:
    • SoShadowStyle::OFF: Shadows are disabled.
    • SoShadowStyle::CAST: Shapes cast shadows but do not receive them.
    • SoShadowStyle::RECEIVE: Shapes receive shadows but do not cast them.
    • SoShadowStyle::CAST_AND_RECEIVE: Shapes cast and receive shadows.
    The default value is SoShadowStyle::CAST_AND_RECEIVE.
