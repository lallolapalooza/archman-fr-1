Description Détaillée

La classe SoElapsedTime est un moteur source de temps contrôlable.

La fonctionnalité supplémentaire fournie par ce moteur par rapport à la simple connexion au champ global realTime est la capacité de contrôler la vitesse de la source de temps plus une logique pour la réinitialiser, l'arrêter et la redémarrer.

Exemple d'utilisation simple, combiné avec SoComposeRotation :

#Inventor V2.1 ascii
Separator {
   Transform {
      rotation =
      ComposeRotation { axis 0 1 0  angle =
         ElapsedTime { }.timeOut
      }.rotation
   }
   Cube { }
}

Documentation Données Membre

SoSFTime SoElapsedTime::timeIn

Valeur de temps d'entrée. Connecté par défaut au champ global realTime.

SoSFFloat SoElapsedTime::speed

Décide de la vitesse à laquelle le minuteur doit fonctionner, mesurée par rapport au "temps réel" du champ timeIn. La valeur par défaut est 1.0.

Une valeur négative fait aller le temps en arrière.

SoSFBool SoElapsedTime::on

Active et désactive le minuteur. Redémarrera à la même position.

SoSFBool SoElapsedTime::pause

Active et désactive le minuteur. Redémarrera à la position qu'il aurait eue s'il n'avait pas été mis en pause (c'est-à-dire qu'il ne "perd pas de temps").

SoSFTrigger SoElapsedTime::reset

Redémarre le minuteur à 0.

(SoSFTime) Valeur de temps de sortie. Commence à 0.
