Description détaillée

La classe SoNodeList est un conteneur pour les pointeurs vers des objets SoNode.

Comme cette classe hérite de SoBaseList, les référencements et dé-référencements seront effectués par défaut sur les objets lors de append(), remove(), insert(), etc.
