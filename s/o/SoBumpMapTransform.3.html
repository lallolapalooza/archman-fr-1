Detailed Description

The SoBumpMapTransform class is used to define 2D bump map transformations.

Bump maps applied to shapes in the scene can be transformed by "prefixing" in the state with instances of this node type. Translations, rotations and scaling in 2D can all be done.

The default settings of this node's fields equals a "nulltransform", i.e. no transformation.

FILE FORMAT/DEFAULTS:

BumpMapTransform {
    translation 0 0
    rotation 0
    scaleFactor 1 1
    center 0 0
}

Since

Coin 2.2
