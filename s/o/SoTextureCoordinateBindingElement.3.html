NAME

SoTextureCoordinateBindingElement — Element for texture coordinate binding information

SYNOPSIS

Inherits from SoElement.

class SoTextureCoordinateBindingElement : public SoElement
{
    // ...
};

Detailed Description

This element stores the current texture coordinate binding.

The texture coordinate binding determines how texture coordinates are generated or interpreted for the subsequent geometry.

It can be set to:

  • SoTextureCoordinateBindingElement::NONE: No texture coordinates are generated or used.
  • SoTextureCoordinateBindingElement::PER_VERTEX: Texture coordinates are provided per vertex.
  • SoTextureCoordinateBindingElement::PER_PART: Texture coordinates are provided per part (e.g., per face of a cube).
  • SoTextureCoordinateBindingElement::PER_FACE: Texture coordinates are provided per face.
  • SoTextureCoordinateBindingElement::PER_POINT: Texture coordinates are provided per point (for point primitives).
  • SoTextureCoordinateBindingElement::PER_LINE: Texture coordinates are provided per line segment.
  • SoTextureCoordinateBindingElement::PER_POLYLINE: Texture coordinates are provided per polyline.
  • SoTextureCoordinateBindingElement::PER_TRIANGLE: Texture coordinates are provided per triangle.
  • SoTextureCoordinateBindingElement::PER_QUAD: Texture coordinates are provided per quad.
  • SoTextureCoordinateBindingElement::OBJECT_LINEAR: Texture coordinates are generated using object-linear mapping.
  • SoTextureCoordinateBindingElement::EMBEDDED: Texture coordinates are embedded within the geometry data.
