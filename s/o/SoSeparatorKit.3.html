Description

Ce kit représente un nœud SoSeparator. Il est dérivé de SoBaseKit. Les kits vous permettent de construire et de gérer des scènes composées de nœuds de manière plus structurée.

Un SoSeparator est utilisé pour isoler une partie d'un graphe de scène. Cela signifie que les transformations, les états et les matériaux appliqués avant le séparateur ne s'appliqueront pas après, et inversement.

Le kit SoSeparatorKit expose les mêmes champs que le nœud SoSeparator, permettant ainsi de contrôler son comportement.

Documentation des énumérations des membres

Les champs SoSFEnum exposés par ce kit correspondent aux mêmes énumérations que celles définies dans la classe SoSeparator. Voici un rappel de leur signification:

SoSFEnum SoSeparatorKit::renderCaching

Contrôle la mise en cache du rendu pour ce séparateur. Les valeurs possibles sont :

SoSeparator::AUTO_CASE
(par défaut) La mise en cache est activée si le séparateur ne contient pas de nœuds qui pourraient la rendre invalide (par exemple, des nœuds de transformation dynamiques).
SoSeparator::ENABLE
La mise en cache est toujours activée.
SoSeparator::DISABLE
La mise en cache est toujours désactivée.

SoSFEnum SoSeparatorKit::boundingBoxCaching

Contrôle la mise en cache de la boîte englobante pour ce séparateur. Les valeurs possibles sont les mêmes que pour renderCaching.

SoSFEnum SoSeparatorKit::renderCulling

Contrôle le "culling" de rendu pour ce séparateur. Le culling est une optimisation qui consiste à ne pas rendre les parties de la scène qui ne sont pas visibles. Les valeurs possibles sont :

SoSeparator::AUTO_CASE
(par défaut) Le culling est activé si le séparateur ne contient pas de nœuds qui pourraient le rendre invalide (par exemple, des nœuds qui modifient l'espace de coordonnées, comme des transformations non linéaires).
SoSeparator::ENABLE
Le culling est toujours activé.
SoSeparator::DISABLE
Le culling est toujours désactivé.

SoSFEnum SoSeparatorKit::pickCulling

Contrôle le "culling" de sélection pour ce séparateur. Le culling de sélection permet d'optimiser le processus de sélection en évitant de tester les objets qui ne sont pas dans le champ de vision de la sélection. Les valeurs possibles sont les mêmes que pour renderCulling.

void SoSeparatorKit::setDefaultOnNonWritingFields (void ) [protected], [virtual]

(Soyez conscient que cette méthode est peu susceptible d'intéresser le programmeur d'application qui ne souhaite pas étendre la bibliothèque avec de nouveaux kits de nœuds ou draggers personnalisés. Si vous êtes en train d'écrire des extensions, consultez les informations dans la documentation de la classe SoBaseKit.)

C'est une méthode virtuelle, et le code qu'elle contient devrait appeler SoField::setDefault() avec l'argument TRUE sur les champs de partie qui ne doivent pas être écrits lors des opérations d'exportation du graphe de scène.

Ceci est généralement fait lorsque :

1.
la valeur du champ est NULL et la partie est NULL par défaut
2.
il s'agit d'un nœud SoGroup ou SoSeparator feuille sans enfants
3.
il s'agit d'une partie de liste feuille sans enfants et d'un conteneur SoGroup ou SoSeparator
4.
il s'agit d'une partie non feuille et qu'elle est de type SoGroup et que tous les champs sont à leurs valeurs par défaut

Les sous-classes devraient généralement la redéfinir pour faire des réglages supplémentaires pour les nouveaux champs membres. Depuis la sous-classe, n'oubliez pas d'appeler "vers le haut" la méthode setDefaultOnNonWritingFields() de votre super-classe.
