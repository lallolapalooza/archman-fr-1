Description détaillée

La classe SoAuditorList est utilisée pour suivre les auditeurs de certaines classes d'objets.

Cette classe est principalement destinée à un usage interne (par SoBase) et il ne devrait pas être nécessaire de la connaître pour une utilisation "ordinaire" de Coin.
