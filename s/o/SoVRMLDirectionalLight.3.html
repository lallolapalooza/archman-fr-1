Aperçu

La classe SoVRMLDirectionalLight est un type de nœud pour spécifier des sources de lumière directionnelles.

La documentation détaillée de la classe est tirée littéralement de la norme VRML97 (ISO/IEC 14772-1:1997). Elle appartient au Web3D Consortium et est utilisée avec la permission du Conseil :

DirectionalLight {
  exposedField SFFloat ambientIntensity  0        # [0,1]
  exposedField SFColor color             1 1 1    # [0,1]
  exposedField SFVec3f direction         0 0 -1   # (-inf,inf)
  exposedField SFFloat intensity         1        # [0,1]
  exposedField SFBool  on                TRUE
}

Le nœud DirectionalLight définit une source de lumière directionnelle qui éclaire les rayons parallèles à un vecteur tridimensionnel donné. Une description des champs ambientIntensity, color, intensity et on se trouve dans la section 4.6.6, Sources de lumière (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.6).

Le champ direction spécifie le vecteur de direction de l'éclairage provenant de la source lumineuse dans le système de coordonnées local. La lumière est émise sous forme de rayons parallèles provenant d'une distance infinie. Une source de lumière directionnelle n'éclaire que les objets de son groupe parent. La lumière peut éclairer tout ce qui se trouve dans ce système de coordonnées, y compris tous les enfants et leurs descendants de son groupe parent. Les transformations cumulées des nœuds parents affectent la lumière. Les nœuds de type DirectionalLight ne s'atténuent pas avec la distance. Une description précise des équations d'éclairage VRML se trouve dans la section 4.14, Modèle d'éclairage (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.14).
