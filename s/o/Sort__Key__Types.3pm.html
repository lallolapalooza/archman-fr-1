Sort::Key::Types - gère les types de données Sort::Key

SYNOPSIS

use Sort::Key::Types qw(register_type);
register_type(Color => sub { $_->R, $_->G, $_->B }, qw(int, int, int));
# vous feriez mieux
# d'utiliser Sort::Key::Register ...

DESCRIPTION

La famille de modules Sort::Key peut être étendue pour supporter de nouveaux types de clés en utilisant ce module (ou le plus convivial Sort::Key::Register).

FONCTIONS

Les fonctions suivantes sont fournies :

Sort::Key::register_type($name, \&gensubkeys, @subkeystypes)
enregistre un nouveau type de données nommé $name définissant comment le convertir en une clé multiple.

&gensubkeys doit convertir l'objet de type $name passé sur $_ en une liste de valeurs composant la clé multiple.

@subkeystypes est la liste des types pour les clés multiples générées.

Par exemple :

Sort::Key::Types::register_type
               'Person',
               sub { $_->surname,
                     $_->name,
                     $_->middlename },
               qw(str str str);
Sort::Key::Types::register_type
               'Color',
               sub { $_->R, $_->G, $_->B },
               qw(int int int);

Une fois qu'un type de données a été enregistré, il peut être utilisé de la même manière que les types nativement supportés, même pour définir de nouveaux types, c'est-à-dire :

Sort::Key::Types::register_type
               'Family',
               sub { $_->father, $_->mother },
               qw(Person Person);

VOIR AUSSI

Sort::Key, Sort::Key::Merger, Sort::Key::Register.
