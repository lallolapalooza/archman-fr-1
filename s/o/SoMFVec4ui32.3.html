DESCRIPTION DÉTAILLÉE

La classe SoMFVec4ui32 est un conteneur pour les vecteurs SbVec4ui32.

Ce champ est utilisé lorsque les nœuds, moteurs ou autres conteneurs de champs doivent stocker un tableau de vecteurs à quatre éléments.

Ce champ prend en charge le partage de données d'application via une méthode setValuesPointer(). Voir la documentation de SoMField pour plus d'informations sur l'utilisation de cette fonction.

Voir aussi

SbVec4ui32, SoSFVec4ui32 Notez que cette classe est une extension pour Coin et n'est pas disponible dans l'API originale SGI Open Inventor v2.1.

Depuis

Coin 2.5
