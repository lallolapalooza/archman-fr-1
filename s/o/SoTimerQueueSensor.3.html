Description détaillée

La classe SoTimerQueueSensor est la classe de base abstraite pour les capteurs qui se déclenchent à des événements de minuteur spécifiques.

Les capteurs de minuteur se déclenchent à des moments précis.

Cette classe est une superclasse abstraite qui regroupe l'interface commune des diverses classes de capteurs non abstraites. Consultez la documentation des sous-classes pour savoir comment spécifier les temps de base, les intervalles, le style de déclenchement du minuteur, les déclenchements répétés, etc.

Note : Les capteurs de minuteur Coin ne doivent en aucun cas être considérés comme étant à « temps réel fixe ». Autrement dit, vous ne pouvez pas vous attendre à ce qu'un minuteur se déclenche exactement au moment où il a été configuré. Des retards dans le déclenchement peuvent être causés par d'autres activités dans Coin, une tâche suspendue ou une forte charge d'autres applications sur le système. Ces cas peuvent entraîner un retard dans le traitement des files d'attente de capteurs (de SoQt / SoWin / SoXt / etc.) et donc causer des retards dans le déclenchement des capteurs de minuteur.

Sur les systèmes modernes, un minuteur se déclenche généralement dans les quelques millisecondes suivant son heure désignée, cependant.

Si un capteur de minuteur ne peut pas se déclencher au moment exact où il est prévu, il se déclenchera à la première occasion après que le temps prévu soit passé.

Voici un exemple d'utilisation simple. Il s'agit d'un exemple autonome qui montre uniquement comment configurer un capteur de minuteur répété avec un rappel :

#include <Inventor/Xt/SoXt.h>
#include <Inventor/sensors/SoTimerSensor.h>
#include <cstdio>
static void
timeSensorCallback(void * data, SoSensor * sensor)
{
  SbTime time = SbTime::getTimeOfDay();
  SbString string = time.format("%S.%i");
  (void)printf("%s\n", string.getString());
}
int
main(int argc, char ** argv)
 { 
  SoXt::init("test");
  SoTimerSensor * timeSensor = new SoTimerSensor;
  timeSensor->setFunction(timeSensorCallback);
  timeSensor->setBaseTime(SbTime::getTimeOfDay());
  timeSensor->setInterval(1.0f);
  timeSensor->schedule();
  SoXt::mainLoop();
  return 0;
}
