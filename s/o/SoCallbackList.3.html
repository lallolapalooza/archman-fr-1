Description Détaillée

La SoCallbackList est un conteneur pour les pointeurs de fonctions de rappel.

Cette liste stocke les pointeurs de fonctions de rappel (ainsi que des données supplémentaires spécifiées par l'utilisateur à passer aux rappels) et fournit une méthode pour déclencher les fonctions de rappel.

Documentation Fonctions Membre

void SoCallbackList::addCallback (SoCallbackListCB * f, void * userdata = NULL)

Ajoute la fonction de rappel f à la liste. Elle recevra userdata lors de son invocation.

void SoCallbackList::removeCallback (SoCallbackListCB * f, void * userdata = NULL)

Supprime le rappel f de la liste.

void SoCallbackList::clearCallbacks (void )

Supprime tous les rappels de la liste.

int SoCallbackList::getNumCallbacks (void ) const

Retourne le nombre de fonctions de rappel.

void SoCallbackList::invokeCallbacks (void * callbackdata)

Invoque toutes les fonctions de rappel, en passant userdata et callbackdata comme premier et deuxième arguments, respectivement.

Tous les rappels enregistrés au moment où la méthode est invoquée seront déclenchés, même si le code d'un rappel en supprime un autre.

Il est sûr pour un rappel de se supprimer lui-même ou tout autre rappel pendant son exécution.
