Description détaillée

La classe SoProfile est la superclasse abstraite pour les définitions de profil.

Les sous-classes de SoProfile spécifient les profils pour le texte 3D extrudé et les données de surface NURBS.

Documentation des énumérations de membres

enum SoProfile::Profile

Énumération des différentes options pour joindre plusieurs profils.

Énumérateur

START_FIRST
Remplace l'état actuel du profil par ce profil uniquement.
START_NEW
Ajoute ce profil comme un nouveau profil à l'état.
ADD_TO_CURRENT
Ajoute les indices de ce nœud au dernier profil.
