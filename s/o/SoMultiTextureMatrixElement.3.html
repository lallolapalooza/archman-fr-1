Description Détaillée

La classe SoMultiTextureMatrixElement est utilisée pour gérer la pile de matrices de texture pour les unités de texture > 0.

La matrice de texture est utilisée pour transformer les coordonnées de texture avant qu'elles ne soient utilisées pour mapper des textures sur les polygones.

void SoMultiTextureMatrixElement::push (SoState * state) [virtual]

Cette méthode est appelée chaque fois qu'un nouvel élément est requis dans l'une des piles. Cela se produit lorsqu'un élément modifiable est demandé, en utilisant SoState::getElement() ou indirectement SoElement::getElement(), et que la profondeur de l'élément courant est inférieure à la profondeur de l'état.

Redéfinissez cette méthode si votre élément doit copier des données depuis le sommet précédent de la pile. La méthode push() est appelée sur le nouvel élément, et l'élément précédent peut être trouvé en utilisant SoElement::getNextInStack().
