NAME

SoScaleUniformDragger

uniform scaling dragger

SYNOPSIS

Inherits from SoDragger.

  Actions:
    none
  Events:
    none

    SoSFVec3f    scaleFactor

Detailed Description

A uniform scaling dragger. This dragger provides a simple interface for scaling objects uniformly along all axes. The dragger is rendered as a set of three orthogonal arrows, and the scale factor is determined by the distance the user drags the mouse away from the dragger's center.

This dragger inherits from SoDragger, so it has fields for position, orientation, and scale. The dragger's position and orientation are determined by the node's transform fields, and the dragger's scale is determined by its own scale factor field. The dragger itself is drawn relative to its own transform, and the scaling is applied to the geometry that is being dragged.

The scaleFactor field is an SoSFVec3f that is continuously updated to contain the current vector of scaling along the X, Y, and Z axes. When the dragger is manipulated, the scaleFactor field is updated to reflect the new scaling. Applications can read this field to get the current scaling of the object being dragged.

The dragger's transformation is applied to the geometry that is being dragged. The dragger's transformation is composed of the translation, rotation, and scale fields inherited from SoDragger. The dragger's own transformation is applied first, and then the scaling specified by the scaleFactor field is applied.
