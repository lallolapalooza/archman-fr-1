NOM

SOAP::Transport::LOOPBACK - Backend de transport de test en boucle (Client uniquement)

DESCRIPTION

SOAP::Transport::LOOPBACK est un backend de transport de test pour SOAP::Lite.

Il renvoie simplement la requête XML comme réponse, permettant ainsi de tester la pile applicative complète des applications clientes, du frontend jusqu'à la couche de transport, sans réellement envoyer de données sur le réseau.

L'utilisation de ce backend de transport est déclenchée en définissant une URL loopback://.

L'envoi de requêtes via ce backend de transport réussit toujours avec les états suivants :

status: 200 OK
code: 200
message: OK
