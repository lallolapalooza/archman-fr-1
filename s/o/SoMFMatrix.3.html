Detailed Description

A multi-value field that holds SbMatrix objects.

Use the count and operator[] methods to access the values.

Use the setValues, set1Value, addValue, insertValue, removeValue, removeValues and replaceValue methods to modify the field's values.

Use the getValues method to obtain a pointer to the array of values.
