Description détaillée

La classe SoVertexProperty collecte les fonctionnalités de divers nœuds d'apparence.

Au lieu de lire les données de la pile d'état courante de la traversée du graphe de scène, les nœuds héritant de SoVertexShape peuvent être configurés avec un nœud SoVertexProperty dans le champ SoVertexShape::vertexProperty. Les coordonnées, normales, coordonnées de texture et informations de matériau/couleur seront alors récupérées du nœud SoVertexProperty de la forme de sommet au lieu de la pile d'état.

Le nœud SoVertexProperty fournit des champs pour dupliquer les fonctionnalités de tous ces autres types de nœuds : SoCoordinate3, SoTextureCoordinate2, SoTextureCoordinate3, SoNormal, SoPackedColor, SoMaterialBinding et SoNormalBinding.

Le nœud SoVertexProperty a été introduit assez tard dans la conception de l'API Inventor par SGI. L'idée derrière était de fournir un moyen de spécifier les données nécessaires pour les nœuds dérivés de formes de sommets, ce qui serait plus efficace à manipuler que de récupérer les données depuis la pile d'état de traversée.

En pratique, l'effet n'est pas du tout très perceptible. Étant donné que l'utilisation des nœuds SoVertexProperty dans le champ SoVertexShape::vertexProperty rompt quelque peu avec la conception de base de l'API Open Inventor (les données SoVertexProperty ne sont pas poussées dans la pile d'état de traversée), vous pourriez être mieux servi d'un point de vue conception en utilisant les mécanismes habituels, c'est-à-dire en configurant les nœuds individuels que SoVertexProperty "collecte".

L'un des inconvénients sera, par exemple, qu'il n'est pas possible de partager des *parties* du nœud SoVertexProperty entre plusieurs formes, ce qui peut être fait facilement lors de la configuration de nœuds individuels changeant l'état dans le graphe de scène.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

VertexProperty {
    vertex [  ]
    normal [  ]
    texCoord [  ]
    orderedRGBA [  ]
    texCoord3 [  ]
    normalBinding PER_VERTEX_INDEXED
    materialBinding OVERALL
}

SoMFInt32 SoVertexProperty::textureUnit

L'unité (les unités) de texture pour les coordonnées de texture. Par défaut, ce champ contient une valeur, 0, et les coordonnées de texture sont alors envoyées à l'unité de texture 0. Il est possible de fournir plusieurs valeurs dans ce champ, et les coordonnées de texture dans texCoord ou texCoord3 seront alors réparties dans ces unités. Les premières coordonnées (totalnum/numunits) seront envoyées à la première unité spécifiée, les suivantes (totalnum/numunits) seront envoyées à la deuxième unité de ce champ, etc.

Voir aussi

SoTextureCoordinate2, SoTextureUnit
