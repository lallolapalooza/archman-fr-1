Description

Cet élément de graphe de scène stocke la valeur du créneau courant.

Le créneau est une propriété des objets de maillage lissé (par exemple, SoNurbsSurface, SoIndexedNurbsCurve, SoText3, etc.). Lorsque la valeur du créneau est réglée sur 0, les bords du maillage sont calculés automatiquement comme pour une normale de bords usuelle. Lorsque la valeur est supérieure à 0, elle représente l'angle maximal entre deux normales de faces adjacentes qui formeront un bord dans le maillage lissé. Par exemple, une valeur de 30 degrés signifie que deux faces adjacentes avec une différence d'angle de normale inférieure à 30 degrés seront lissées ensemble. Si la différence est supérieure, un bord dur sera créé.

Il s'agit d'un élément d'état, ce qui signifie qu'il contient une valeur qui est fournie aux nœuds enfants du graphe de scène. Les éléments permettent de modifier le comportement de rendu des nœuds.

Il est généralement préférable de modifier les éléments d'état via des nœuds de surcharge (comme SoMaterialBinding), car cela rend le graphe de scène plus portable.

Pour un usage direct, vous pouvez utiliser les méthodes set() et get() de l'élément.

La classe SoCreaseAngleElement hérite de SoElement.
