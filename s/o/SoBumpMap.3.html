Description détaillée

La classe SoBumpMap est utilisée pour mapper une texture de relief sur des formes consécutives.

La classe SoBumpMap prend en charge deux types de textures. Si l'image est une image à trois composantes (RVB), elle est traitée comme une carte normale, où la composante rouge de l'image correspond à la composante X de la normale, la verte à Y et la bleue à Z. Voir http://www.paulsprojects.net/tutorials/simplebump/simplebump.html pour une introduction intéressante sur le bump mapping et les cartes normales.

Si l'image est une carte en niveaux de gris, elle est traitée comme une carte de hauteur et est automatiquement convertie en carte normale.

Pour que le bump mapping fonctionne avec des nœuds d'extension dans Coin, la méthode SoShape::generatePrimitives() doit être correctement implémentée pour la forme. Ceci est nécessaire car les coordonnées de l'espace tangent doivent être calculées pour chaque sommet de la forme. Tous les nœuds de forme qui font partie de Coin en standard satisfont à cette exigence.

Le bump mapping dans Coin nécessite OpenGL 1.3, ou les extensions OpenGL suivantes : GL_ARB_multitexture, GL_ARB_texture_cube_map, GL_ARB_texture_env_combine et GL_ARB_texture_env_dot3 (ou les extensions EXT correspondantes). Si le système d'exécution ne satisfait pas ces exigences, Coin affichera un avertissement et le bump map sera ignoré.

L'utilisation de GL_ARB_vertex_program et GL_ARB_fragment_program est nécessaire pour afficher un éclairage spéculaire sur les bosses. Si ces extensions ne sont pas disponibles, les bosses seront rendues avec un éclairage diffus uniquement.

Les objets avec bump mapping seront rendus en plusieurs passes de rendu. Une passe supplémentaire par source de lumière pour les bosses diffuses, et deux passes supplémentaires par source de lumière pour les bosses diffuses et spéculaires. Vous pouvez désactiver l'éclairage spéculaire sur les bosses en définissant specularColor sur (0.0, 0.0, 0.0).

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

BumpMap {
    filename ""
    image 0 0 0
    wrapS REPEAT
    wrapT REPEAT
}

Documentation des énumérations des membres

Énumération SoBumpMap::Wrap

Énumération des stratégies de répétition qui peuvent être utilisées lorsque la texture de relief ne couvre pas toute la portée de la géométrie.

Les énumérateurs

REPEAT
Répéter la texture de relief lorsque la coordonnée n'est pas comprise entre 0 et 1.
CLAMP
Limiter la coordonnée entre 0 et 1.
