Voir Shaders dans Coin pour plus d'informations sur la façon de configurer une scène graphique avec des shaders.

DESCRIPTION DÉTAILLÉE

La méthode readInstance_ est principalement destinée à un usage interne lors des opérations d'importation de fichiers.

Elle lit la définition d'une instance à partir du flux d'entrée in. L'état du flux d'entrée pointe vers le début d'une représentation sérialisée / persistante d'une instance de ce type de classe.

TRUE ou FALSE est retourné, selon que l'instanciation et la configuration du nouvel objet de ce type de classe se sont bien déroulées ou non. Le processus d'importation doit être robuste et gérer les flux d'entrée corrompus en retournant FALSE.

flags est utilisé en interne lors de l'importation binaire lors de la lecture de nœuds d'extension utilisateur, de nœuds de groupe ou de moteurs.

Réimplémenté à partir de SoNode.
