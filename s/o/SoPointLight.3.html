Description Détaillée

La classe SoPointLight est un type de nœud pour les sources lumineuses.

Les lumières ponctuelles émettent de la lumière de manière égale dans toutes les directions à partir d'un emplacement 3D spécifié.

Voir la documentation de la classe parente pour des informations importantes concernant les sources lumineuses en général.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

PointLight {
    on TRUE
    intensity 1
    color 1 1 1
    location 0 0 1
}
