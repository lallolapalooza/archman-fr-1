NOM

Sort::Key::Maker - créateur de tri multi-clés

SYNOPSIS

# créer une fonction qui trie les chaînes par longueur :
use Sort::Key::Maker sort_by_length => sub { length $_},  qw(integer);
# créer une fonction de tri multi-clés ;
# la première clé est un entier trié par ordre décroissant,
# la deuxième clé est une chaîne dans l'ordre par défaut (croissant) :
use Sort::Key::Maker ri_s_keysort => qw(-integer string);
# quelques données exemples...
my @foo = qw(foo bar t too tood mama);
# et maintenant, utilisez les fonctions de tri précédemment créées :
# obtenir les valeurs de @foo triées par longueur :
my @sorted = sort_by_length @foo;
# trier @foo en place par sa longueur puis par sa valeur :
ri_s_keysort_inplace { length $_, $_ } @foo;

DESCRIPTION

Sort::Key::Maker est un module pragmatique qui fournit une interface facile à utiliser pour la fonctionnalité de tri multi-clés de Sort::Key.

Il crée des fonctions de tri multi-clés à la volée pour toute combinaison de types de clés et les exporte vers le package appelant.

Les types de clés acceptés nativement sont :

string, str, locale, loc, integer, int,
unsigned_integer, uint, number, num

et le support pour d'autres types peut être ajouté via Sort::Key::Register (ou aussi via Sort::Key::register_type()).

UTILISATION

use Sort::Key::Maker foo_sort => @keys;
exporte deux sous-routines vers le package appelant : "foo_sort (&@)" et "foo_sort_inplace (&\@)".

Ces deux sous-routines nécessitent une référence de sous-routine comme premier argument, puis respectivement, la liste à trier ou un tableau.

Par exemple :

use Sort::Key::Maker bar_sort => qw(int int str);
@bar=qw(doo tomo 45s tio);
@sorted = bar_sort { unpack "CCs", $_ } @bar;
# ou trier @bar en place
bar_sort_inplace { unpack "CCs", $_ } @bar;
use Sort::Key::Maker foo_sort => \&genmultikey, @keys;
lorsque le premier argument après le nom du trieur est une référence à une sous-routine, il est utilisé comme fonction d'extraction multi-clés. Les fonctions de tri générées n'en nécessitent pas ni n'en acceptent, c'est-à-dire : 
use Sort::Key::Maker sort_by_length => sub { length $_ }, 'int';
my @sorted = sort_by_length qw(foo goo h mama picasso);

VOIR AUSSI

Sort::Key, Sort::Key::Register.

Sort::Maker également disponible sur CPAN fournit une fonctionnalité similaire.
