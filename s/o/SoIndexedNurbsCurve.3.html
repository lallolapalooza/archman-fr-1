Descripción Detallada

La clase SoIndexedNurbsCurve es un nodo para representar curvas suaves.

Explicar NURBS está más allá del alcance de este documento. Si no está familiarizado con los principios de representación de curvas y superficies en la visualización 3D, le recomendamos buscar un buen libro sobre el tema.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

IndexedNurbsCurve {
    numControlPoints 0
    coordIndex 0
    knotVector 0
}

Description détaillée

Ce nœud représente une courbe NURBS utilisant des indices dans le champ coordIndex pour référencer les points de contrôle contenus dans le champ numControlPoints. Le champ knotVector définit les points nodaux de la courbe.

protected virtual SoDetail * SoIndexedNurbsCurve::createLineSegmentDetail (SoRayPickAction * action, const SoPrimitiveVertex * v1, const SoPrimitiveVertex * v2, SoPickedPoint * pp)

Crée un détail de ligne pour un SoPickedPoint. Cette méthode ne sera appelée qu'en interne, lorsque generatePrimitives() est utilisé pour la sélection (SoShape::rayPick() n'est pas outrepassé).

Cette méthode retourne NULL dans Open Inventor, et les sous-classes devront outrepasser cette méthode pour créer des détails pour un SoPickedPoint.

Ce n'est pas nécessaire avec Coin. Bien sûr, si vous choisissez de l'outrepasser, cela fonctionnera de la même manière qu'Open Inventor.

Pour que cela fonctionne, vous devez fournir un détail de face ou de ligne lors de la génération des primitives. Si vous fournissez NULL pour l'argument de détail dans SoShape::beginShape(), vous devrez outrepasser cette méthode.
