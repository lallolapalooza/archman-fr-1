SoLight est la classe de base pour les nœuds de lumière émettrice. Ce type de classe est abstrait et ne fournit pas en soi de source lumineuse pour la scène, vous devez utiliser l'une de ses sous-classes. Quelques points importants concernant les sources lumineuses dans Coin : premièrement, plus vous avez de lumières dans votre scène, plus le rendu sera lent. L'impact sur la vitesse de rendu dépend fortement du matériel de rendu et/ou du sous-système de rendu logiciel (c'est-à-dire de l'optimisation avec laquelle vous ou vos utilisateurs exécutez OpenGL), mais il peut être sévère. Un autre problème important est que les moteurs de rendu OpenGL ont généralement un nombre maximal fixe de sources lumineuses qui peuvent être présentes simultanément dans l'état. Si vous atteignez le nombre maximum, d'autres sources lumineuses seront ignorées. Le nombre maximum de sources lumineuses pour OpenGL peut être trouvé en utilisant : 
#include <Inventor/elements/SoGLLightIdElement.h>
#include <Inventor/nodes/SoSubNodeP.h>
// ...[snip]...
int nrlights = SoGLLightIdElement::getMaxGLSources();
Si vous utilisez judicieusement vos sources lumineuses, vous pouvez vous débrouiller avec plus de lumières dans un arbre de scène que le maximum disponible du système de rendu. En effet, les sources lumineuses sont stilisées dans l'état de parcours, comme d'autres données d'apparence. Ainsi, si vous placez des sources lumineuses sous des nœuds SoSeparator, elles seront dépilées et perdues pour le reste de la géométrie de l'arbre de scène après avoir été parcourues par un SoSeparator.

Documentation Données Membre

SoSFBool SoLight::on

Indique si la source lumineuse doit être activée ou désactivée. Le drapeau on est TRUE par défaut.

SoSFFloat SoLight::intensity

Intensité de la source lumineuse. Ceci détermine dans quelle mesure la source lumineuse affecte les couleurs, etc., de la géométrie de la scène. La plage valide est de 0.0 (aucune) à 1.0 (maximum). La valeur par défaut est 1.0.

SoSFColor SoLight::color

Couleur de la source lumineuse. La valeur par défaut est une source lumineuse blanche complète.
