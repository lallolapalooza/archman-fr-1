Description Détaillée

La classe SoVRMLInline est utilisée pour insérer des fichiers VRML dans une scène.

La documentation détaillée de la classe est tirée verbatim de la norme VRML97 (ISO/IEC 14772-1:1997). Elle est la propriété du Web3D Consortium et est utilisée avec leur permission :

Inline {
  exposedField MFString url        []
  field        SFVec3f  bboxCenter 0 0 0     # (-,)
  field        SFVec3f  bboxSize   -1 -1 -1  # (0,) ou -1,-1,-1
}

Le nœud Inline est un nœud de regroupement qui lit les données de ses enfants à partir d'un emplacement sur le World Wide Web. Le moment exact où les enfants sont lus et affichés n'est pas défini (par exemple, les enfants peuvent être lus après que la boîte englobante du nœud Inline soit visiblement dans le champ de vision). Le champ url spécifie l'URL contenant les enfants. Un nœud Inline avec une URL vide ne fait rien.

Chaque URL spécifiée doit faire référence à un fichier VRML valide contenant une liste de nœuds enfants, de prototypes et de routes de niveau supérieur, tels que décrits dans la section 4.6.5, Regroupement et nœuds enfants.

Les résultats sont indéfinis si l'URL fait référence à un fichier non-VRML ou si le fichier VRML contient des nœuds non-enfants au niveau supérieur.

Si plusieurs URLs sont spécifiées, le navigateur peut afficher une URL de fichier VRML de préférence inférieure pendant qu'il récupère, ou s'il ne parvient pas à récupérer, afficher une URL de fichier VRML de préférence supérieure. Les détails concernant le champ url et l'ordre de préférence se trouvent dans la section 4.5, VRML et le World Wide Web (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.5).

Les résultats sont indéfinis si le contenu de l'URL change après avoir été chargé.

Les champs bboxCenter et bboxSize spécifient une boîte englobante qui contient les enfants du nœud Inline. C'est un indice qui peut être utilisé pour l'optimisation. Les résultats sont indéfinis si la boîte englobante spécifiée est plus petite que la boîte englobante réelle des enfants à tout moment. Une valeur par défaut de bboxSize (-1, -1, -1) implique que la boîte englobante n'est pas spécifiée et sera calculée par le navigateur. Une description des champs bboxCenter et bboxSize se trouve dans la section 4.6.4, Boîtes englobantes (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.4).

SoVRMLInline(3)

                

                    
NAME

                    
SoVRMLInline — The VRML inline node

                

                

                    
SYNOPSIS

                    
#include <Inventor/VRMLnodes/SoVRMLInline.h>

                    
Inherits from SoNode.

                    
class SoVRMLInline

                    
public slots: void setURL(const char *url); void appendURL(const char *url);

                    
public: SoVRMLInline(); ~SoVRMLInline(); void addURL(const char *url); void setLoop(SbBool loop); SbBool getLoop() const; static SoType getClassTypeId(); virtual SoType getTypeId() const;

                

                

                    
Detailed Description

                    
The SoVRMLInline node is used to reference external VRML files. It allows you to build complex scenes by composing smaller, reusable parts. When the scene graph is traversed, the SoVRMLInline node will load and insert the contents of the specified URL(s) into the scene.

                    
The node supports multiple URLs, in which case the viewer will try to load them in the order they are specified. The first one successfully loaded will be used.

                    
The setLoop() method is used to control whether animations within the inlined file should loop.
