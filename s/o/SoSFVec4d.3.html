Description Détaillée

La classe SoSFVec4d est un conteneur pour un vecteur SbVec4d.

Ce champ est utilisé là où les nœuds, les moteurs ou d'autres conteneurs de champs ont besoin de stocker un seul vecteur à quatre éléments.

Voir aussi

SbVec4d, SoMFVec4d Notez que cette classe est une extension pour Coin, et qu'elle n'est pas disponible dans l'API originale d'Open Inventor v2.1 de SGI.

Depuis

Coin 2.5
