Description détaillée

La classe SoSFVec2i32 est un conteneur pour un vecteur SbVec2i32.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker un seul vecteur à deux éléments.

Voir aussi

SbVec2i32, SoMFVec2i32 Notez que cette classe est une extension pour Coin, et qu'elle n'est pas disponible dans l'API originale d'Open Inventor v2.1 de SGI.

Depuis

Coin 2.5

SoSFVec2i32 — Field class for a 2-component integer vector

DESCRIPTION

This field class is used to store a 2-component vector of 32-bit signed integers. It is often used for storing coordinates or vectors in 2D space.
