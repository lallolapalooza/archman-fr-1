Description détaillée

La classe SoColorIndex est utilisée pour spécifier des indices de couleur pour les formes suivantes.

Ce nœud ne doit être utilisé qu'en mode index de couleur OpenGL, et uniquement lorsque le modèle d'éclairage actuel est défini sur SoLightModel::BASE_COLOR.

Le mode index de couleur OpenGL est un mode où les couleurs des pixels individuels sont extraites d'une table de correspondance des couleurs ("CLUT"). La chose habituelle à faire est de configurer une toile en mode couleur vraie RGBA.

Une utilisation courante des toiles OpenGL en mode index de couleur est de les utiliser dans les plans de superposition (qui sont généralement limités à seulement 2 ou 4 couleurs disponibles), si cela est pris en charge par le matériel et/ou le pilote OpenGL.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

ColorIndex {
    index 1
}
