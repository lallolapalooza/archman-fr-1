Description Détaillée

La classe SoClipPlaneManip est utilisée pour manipuler des plans de découpe.

Un manipulateur est utilisé en remplaçant le nœud que vous voulez éditer dans le graphe par le manipulateur. Des "draggers" sont utilisés pour manipuler le nœud. Lorsque la manipulation est terminée, le nœud est remis dans le graphe, remplaçant le manipulateur.

Un SoJackDragger est utilisé par les instances de cette classe de manipulateur comme dragger par défaut lors de la manipulation de nœuds SoClipPlane. Voir la documentation de SoJackDragger pour les détails sur la façon de contrôler le manipulateur.

Une "capture d'écran" du SoClipPlaneManip :

Ce manipulateur est une extension par rapport à l'API originale SGI Inventor v2.1. En plus d'être une extension Coin, il est également présent dans l'implémentation TGS Inventor (avec la même API).

Veuillez noter que ce manipulateur est un peu différent des autres manipulateurs, car il ne mettra pas automatiquement à l'échelle et ne traduira pas le dragger pour entourer la géométrie. La fonction setValue() doit être utilisée pour initialiser le manipulateur/dragger. Ci-dessous, vous trouverez un exemple de code qui charge un fichier Inventor et ajoute un manipulateur de plan de découpe.

#include <Inventor/Qt/SoQt.h>
#include <Inventor/Qt/viewers/SoQtExaminerViewer.h>
#include <Inventor/SoDB.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/actions/SoGetBoundingBoxAction.h>
#include <Inventor/SoInput.h>
#include <Inventor/manips/SoClipPlaneManip.h>
#include <cassert>
// *************************************************************************
int
main(int argc, char ** argv)
{
  assert(argc >= 2);
  QWidget * window = SoQt::init(argv[0]);
  SoQtExaminerViewer * ex = new SoQtExaminerViewer( window );
  ex->setBackgroundColor(SbColor(0.1f, 0.3f, 0.5f));
  SoInput input;
  SbBool ok = input.openFile(argv[1]);
  if (!ok) {
    fprintf(stderr,"Unable to open file.\n");
    return -1;
  }
  SoSeparator * root = SoDB::readAll(&input); 
  if (!root) {
    fprintf(stderr,"Unable to read file.\n");
    return -1;
  }
  root->ref();
  SoGetBoundingBoxAction ba(ex->getViewportRegion());
  ba.apply(root);
  SbBox3f box = ba.getBoundingBox();
  SoClipPlaneManip * manip = new SoClipPlaneManip;
  manip->setValue(box, SbVec3f(1.0f, 0.0f, 0.0f), 1.02f);
  root->insertChild(manip, 0);
  ex->setSceneGraph(root);
  ex->show();
  SoQt::show( window );
  SoQt::mainLoop();
  delete ex;
  root->unref();
  return 0;
}

void SoClipPlaneManip::copyContents (const SoFieldContainer * from, SbBool copyconnections) [protected], [virtual]

Effectue une copie profonde de toutes les données de from vers cet instancié, à l'exception des références externes à l'arborescence de scène si copyconnections est faux.

C'est la méthode qui doit être surécrite par les nœuds étendus / moteurs / draggers / toute autre classe qui nécessite la gestion de données internes non automatisées.

Pour copier des nœuds à partir du code de l'application, n'appelez pas directement cette méthode, mais appelez la méthode SoNode::copy() :

SoNode * mynewnode = templatenode->copy();

Il en va de même pour les moteurs.

Assurez-vous que lorsque vous surécrivez la méthode copyContents() dans votre classe étendue, vous l'appelez également de manière appropriée dans la hiérarchie des superclasses, car copyContents() par exemple dans SoNode et SoFieldContainer effectue des tâches importantes. Cela devrait ressembler à ceci :

void
MyCoinExtensionNode::copyContents(const SoFieldContainer * from,
                                  SbBool copyconnections)
{
  // déléguer aux superclasses (copier les champs, le nom de l'instance, etc.)
  SoNode::copyContents(from, copyconnections);
  // [..puis copier les données internes..]
}
