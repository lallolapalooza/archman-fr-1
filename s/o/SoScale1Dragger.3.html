Description détaillée

La classe SoScale1Dragger fournit un mécanisme pour que l'utilisateur final puisse mettre à l'échelle dans une dimension.

Voici comment le dragger apparaît avec sa géométrie par défaut dans son état inactif :

Utilisez ce dragger pour permettre à l'utilisatrice de votre application de mettre à l'échelle le long de l'axe X. (Utilisez un nœud de transformation devant le dragger pour le positionner et le réorienter afin de mettre à l'échelle n'importe quel vecteur.)

Detailed Description

This is the 1D scale dragger. It allows the user to scale an object along a single axis. It is used internally by the SoScale2Dragger and SoScale3Dragger classes.

The dragger consists of a single axis, a handle at the end of the axis, and a slider. When the mouse pointer is over the handle, it turns red. When the mouse button is pressed and the pointer is over the handle, the dragger enters the scale mode. In this mode, the handle follows the mouse pointer, and the object is scaled accordingly.

The scale factor is stored in the scaleFactor field. For the SoScale1Dragger, only the X component of this field is used, and it is updated continuously as the user drags the mouse. The Y and Z components will always be equal to 1 (i.e. no scaling).
