NAME

SoTextureScalePolicy — policy for scaling textures based on complexity

SYNOPSIS

#include <Coin/SoTextureScalePolicy.h>

  private:

Detailed Description

This node controls how textures are scaled based on the current complexity and the user's preferences. It can be used to either scale textures up or down depending on the complexity, or to control the quality of the scaling algorithm.

The node has two main fields:

  • policy: Determines how the scaling decision is made.
  • quality: Influences the quality of the scaling algorithm.

Member Data Documentation

SoSFEnum SoTextureScalePolicy::policy

The policy setting. Default value is USE_TEXTURE_QUALITY.

USE_TEXTURE_QUALITY means that SoComplexity::textureQuality will be used to decide if the texture should be scaled up or down. SoComplexity::textureQuality >= 0.7 means scale up, while < 0.7 means scale down. Textures smaller than 256 pixels are never scaled down since you lose too much information.

SoSFFloat SoTextureScalePolicy::quality

The texture scale/resize quality. Default value is 0.5.

This field can be used to force Coin to use a lower quality (but much faster) image resize function. Currently, if you set this field to a value < 0.5, a low quality resize function will be used, otherwise a high quality (but slow) function will be used.

Description détaillée

Ce nœud contrôle comment les textures sont mises à l'échelle en fonction de la complexité actuelle et des préférences de l'utilisateur. Il peut être utilisé soit pour agrandir ou réduire les textures en fonction de la complexité, soit pour contrôler la qualité de l'algorithme de mise à l'échelle.

Le nœud a deux champs principaux :

  • policy : Détermine comment la décision de mise à l'échelle est prise.
  • quality : Influence la qualité de l'algorithme de mise à l'échelle.

Documentation des données membres

SoSFEnum SoTextureScalePolicy::policy

Le réglage de la politique. La valeur par défaut est USE_TEXTURE_QUALITY.

USE_TEXTURE_QUALITY signifie que SoComplexity::textureQuality sera utilisé pour décider si la texture doit être agrandie ou réduite. SoComplexity::textureQuality >= 0.7 signifie agrandir, tandis que < 0.7 signifie réduire. Les textures plus petites que 256 pixels ne sont jamais réduites car trop d'informations sont perdues.

SoSFFloat SoTextureScalePolicy::quality

La qualité de mise à l'échelle/redimensionnement de la texture. La valeur par défaut est 0.5.

Ce champ peut être utilisé pour forcer Coin à utiliser une fonction de redimensionnement d'image de moindre qualité (mais beaucoup plus rapide). Actuellement, si vous définissez ce champ à une valeur < 0.5, une fonction de redimensionnement de basse qualité sera utilisée, sinon une fonction de haute qualité (mais lente) sera utilisée.
