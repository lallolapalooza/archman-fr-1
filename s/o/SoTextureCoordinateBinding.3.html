Description Détaillée

La classe SoTextureCoordinateBinding indique comment les coordonnées de texture doivent être liées aux formes.

SoTextureCoordinateBinding lie les coordonnées actuelles aux formes subséquentes en utilisant une liaison par sommet ou par sommet indexé.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

TextureCoordinateBinding {
    value PER_VERTEX_INDEXED
}

Documentation des Énumérations Membres

enum SoTextureCoordinateBinding::Binding

Les types de liaison disponibles pour le champ SoTextureCoordinateBinding::value.

Énumérateur

PER_VERTEX
Obtient une nouvelle coordonnée de texture à partir du pool de coordonnées de texture pour chaque sommet de la forme.

Les coordonnées de texture sont récupérées à partir de l'indice 0 et des suivants, en incrémentant l'indice dans le pool de coordonnées de texture de 1 pour chaque nouveau sommet du nœud de forme.

PER_VERTEX_INDEXED
Obtient une nouvelle coordonnée de texture à partir du pool de coordonnées de texture pour chaque sommet de la forme.

Les coordonnées de texture sont récupérées par les valeurs d'indice définies par la forme.

DEFAULT
Valeur obsolète, à ne pas utiliser.

Detailed Description

This node defines how texture coordinates are bound to geometry. Texture coordinates are used to map a 2D texture image onto a 3D object.

The value field specifies the binding type.

The default value is PER_VERTEX_INDEXED, which means that texture coordinates are provided per vertex index. Other options are:

  • PER_VERTEX: Texture coordinates are provided per vertex.
  • PER_FACE: Texture coordinates are provided per face.
  • PER_PART: Texture coordinates are provided per part (e.g., per triangle in a triangle mesh).
  • PER_INSTANCE: Texture coordinates are provided per instance of a primitive (e.g., per cube in an instanced cube primitive).

This node should be inserted into the scene graph before any shape nodes that are to be textured. Subsequent shape nodes will use the binding specified by this node.
