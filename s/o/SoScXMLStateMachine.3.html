Description détaillée

Niveau d'intégration pour l'utilisation des événements Coin avec les machines d'état basées sur SCXML.

Cette classe fait partie de l'intégration des types Coin avec le sous-système SCXML. SoScXMLStateMachines ajoute des fonctionnalités pratiques pour l'utilisation des machines d'état SCXML conjointement avec les événements Coin.

Depuis

Coin 3.0
