NAME

SoMFVec3i32

field container for vectors with three signed 32-bit integers

Description

This class is a container for an array of 3-element vectors of signed 32-bit integers. It is used for fields that need to store multiple vectors.

This field is used where nodes, engines or other field containers need to store an array of vectors with three elements.

This field supports application data sharing through a setValuesPointer() method. See SoMField documentation for information on how to use this function.

See also

SbVec3i32, SoSFVec3i32 Be aware that this class is an extension for Coin, and it is not available in the original SGI Open Inventor v2.1 API.

Since

Coin 2.5
