Description

A SoMFVec4f is a field that holds an array of SbVec4f vectors. Each vector is composed of four floating-point values (x, y, z, w).

The standard SbVec4f class is used to hold the vector data. Vectors can be set and retrieved using the standard methods defined in SoMField.

As SoMFVec4f is an inherited field type, it can be used within nodes, engines or other field containers.

This field supports application data sharing through a setValuesPointer() method. See SoMField documentation for information on how to use this function.

See also

SbVec4f, SoSFVec4f
