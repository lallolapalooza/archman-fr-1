Sort::Key(3) Manuel des paquets contribués Perl Sort::Key(3)

NOM

Sort::Key - la manière la plus rapide de trier n'importe quoi en Perl

SYNOPIS

use Sort::Key qw(keysort nkeysort ikeysort);
@by_name = keysort { $_->{surname} $_->{name} } @people;
# trier par clé numérique :
@by_age = nkeysort { $_->{age} } @people;
# trier par clé entière :
@by_sons = ikeysort { $_->{sons} } @people;

DESCRIPTION

Sort::Key offre un certain nombre de fonctions pour trier des listes de valeurs selon une clé calculée.

Il est plus rapide (généralement beaucoup plus rapide) et utilise moins de mémoire que d'autres alternatives implémentées autour de la fonction sort (ST, GRT, etc.).

La fonction de tri multi-clés est également fournie via les modules complémentaires Sort::Key::Multi, Sort::Key::Maker et Sort::Key::Register.

FONCTIONS

Ce module fournit un grand nombre de sous-routines de tri, mais toutes sont des variations de "keysort" :

@sorted = keysort { CALC_KEY($_) } @data

qui est conceptuellement équivalent à

@sorted = sort { CALC_KEY($a) cmp CALC_KEY($b) } @data

où CALC_KEY($_) peut être n'importe quelle expression pour extraire la clé de $_ (pas seulement un appel de sous-routine).

Par exemple, certaines variations sont "nkeysort" qui effectue des comparaisons numériques, "rkeysort" qui trie les données en ordre décroissant, "ikeysort" et "ukeysort" qui sont des versions optimisées de "nkeysort" qui peuvent être utilisées lorsque les clés sont des entiers ou des entiers non négatifs, etc.

Des versions en place de tri sont également fournies. Par exemple :

keysort_inplace { CALC_KEY($_) } @data

équivalent à

@data = keysort { CALC_KEY($_) } @data

mais étant (un peu) plus rapide et utilisant moins de mémoire.

La liste complète des sous-routines qui peuvent être importées de ce module est la suivante :

keysort { CALC_KEY } @array
renvoie les éléments triés de @array selon la clé calculée en appliquant "{ CALC_KEY }" à ceux-ci.
nkeysort { CALC_KEY } @array
similaire à "keysort" mais compare les clés numériquement au lieu de chaînes de caractères.
rnkeysort { CALC_KEY } @array
fonctionne comme "nkeysort", en comparant les clés en ordre décroissant (ou numérique).
ikeysort { CALC_KEY } @array
fonctionne comme "keysort" mais compare les clés comme des entiers (32 bits ou plus, sans vérification de dépassement).
rikeysort { CALC_KEY } @array
fonctionne comme "ikeysort", mais en ordre décroissant (ou numérique).
ukeysort { CALC_KEY } @array
fonctionne comme "keysort" mais compare les clés comme des entiers non négatifs (32 bits ou plus).
rukeysort { CALC_KEY } @array
fonctionne comme "ukeysort", mais en ordre décroissant (ou numérique).
keysort_inplace { CALC_KEY } @array
nkeysort_inplace { CALC_KEY } @array
ikeysort_inplace { CALC_KEY } @array
ukeysort_inplace { CALC_KEY } @array
rkeysort_inplace { CALC_KEY } @array
rnkeysort_inplace { CALC_KEY } @array
rikeysort_inplace { CALC_KEY } @array
rukeysort_inplace { CALC_KEY } @array
fonctionnent comme les fonctions "keysort" correspondantes mais trient l'array sur place.
rsort @array
nsort @array
rnsort @array
isort @array
risort @array
usort @array
rusort @array
rsort_inplace @array
nsort_inplace @array
rnsort_inplace @array
isort_inplace @array
risort_inplace @array
usort_inplace @array
rusort_inplace @array
sont des versions simplifiées de leurs frères "keysort". Ils utilisent leurs propres valeurs comme clés de tri.
par exemple, c'est équivalent :
@sorted = nsort @foo;
@sorted = nkeysort { $_ } @foo;
@sorted = sort { $a <=> $b } @foo;
multikeysorter(@types)
multikeysorter_inplace(@types)
multikeysorter(\&genkeys, @types)
multikeysorter_inplace(\&genkeys, @types)
sont l'interface de bas niveau pour la fonctionnalité de tri multi-clés (normalement, vous devriez utiliser Sort::Key::Maker et Sort::Key::Register ou Sort::Key::Multi).
prend une liste de descriptions de clés et renvoie une référence à une sous-routine de tri multi-clés.
les types acceptés par défaut sont :
string, str, locale, loc, integer, int,
unsigned_integer, uint, number, num
et ils supportent le support additionnel de types via la sous-routine register_type disponible dans Sort::Key::Types ou l'interface plus conviviale de Sort::Key::Register.
les types peuvent être précédés d'un signe moins pour indiquer un tri décroissant.
si le premier argument est une référence de sous-routine, elle est utilisée comme premier argument.

Sort::Key::Multi(3pm) - Perl manual page

NAME

Sort::Key::Multi - Multi-key sorting.

SYNOPSIS

    use Sort::Key::Multi;
    my $sorter = multikeysorter(
        sub {shift->{'priority'}},
        sub {shift->{'timestamp'}},
        sub {shift->{'name'}},
    );
    my @sorted = sort $sorter @unsorted;

DESCRIPTION

This module exports the multikeysorter function.

It allows you to create a sort subroutine which can sort based on multiple keys.

The keys can be given in two forms:

A subroutine reference:
This subroutine must receive one argument (the item to be sorted) and return the value for that key.
A string:
This is used when you want to sort by a specific datatype. You can provide one of the datatypes known to the Sort::Key::Register module. Currently supported types are:
"int"
Sorts numerically.
"str"
Sorts alphabetically using the current locale.
"locale"
Sorts alphabetically using the current locale. Same as "str".
"natural"
Sorts naturally (e.g., 'file10.txt' comes after 'file2.txt').
"ipv4"
Sorts IP addresses numerically.
"datetime"
Sorts date/time strings.
"oid"
Sorts OID strings.

The keys are applied in the order they are provided.

The multikeysorter function returns a subroutine reference which you can use directly in Perl's sort function.

The sorting is stable, meaning that if two items compare as equal according to the specified keys, their original relative order is preserved.

If the first argument is a subroutine reference, it will be used to extract the keys. If it is a string, it will be interpreted as a datatype, and the following arguments will be interpreted as the list of keys.

If you call multikeysorter with only string arguments, the generated sorter expects the first argument of the generated subroutine to be a subroutine that extracts the keys.

Example:

    my $sorter1 = multikeysorter(sub {length $_, $_}, qw(int str));
    my @sorted1 = &$sorter1(qw(foo fo o of oof));
    my $sorter2 = multikeysorter(qw(int str));
    my @sorted2 = &$sorter2(sub {length $_, $_}, qw(foo fo o of oof));

SEE ALSO

perl sort function, integer, locale.

Companion modules Sort::Key::Multi, Sort::Key::Register, Sort::Key::Maker and Sort::Key::Natural.

Sort::Key::IPv4, Sort::Key::DateTime and Sort::Key::OID modules add support for additional datatypes to Sort::Key.

Sort::Key::External allows to sort huge lists that do not fit in the available memory.

Other interesting Perl sorting modules are Sort::Maker, Sort::Naturally and Sort::External.
