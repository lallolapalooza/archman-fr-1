Description détaillée

La classe SoGeoSeparator est utilisée pour géoréférencer un arbre de scène.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

GeoSeparator {
  geoSystem ["GD", "WE"]
  geoCoords 0 0 0
}

Ce nœud spécifie un système de coordonnées géographiques absolues pour ses enfants. Lors du rendu (ou lors de l'application d'autres actions), Coin ajoutera une transformation qui convertit la géométrie dans le système de coordonnées SoGeoOrigin. Tous les objets seront tournés de manière à ce que l'axe Z local pointe vers le haut depuis le sol (à l'emplacement spécifié par la géolocalisation), l'axe Y pointe vers le pôle Nord et l'axe X est trouvé en utilisant la règle de la main droite.
