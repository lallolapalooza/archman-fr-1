Description Détaillée

La classe SoMFDouble contient des valeurs à virgule flottante double précision.

Ce champ est utilisé lorsque des nœuds, des moteurs ou d'autres conteneurs de champs doivent stocker un groupe de plusieurs valeurs à virgule flottante.

Ce champ prend en charge l'échange de données d'application via la fonction setValuesPointer(). Consultez la documentation de SoMField pour savoir comment utiliser cette fonction.

Detailed Description

Este campo es un campo de doble precisión de punto flotante que puede contener cero, uno o más valores. Si el campo contiene más de un valor, los valores se almacenan como un arreglo de doubles.

Este campo se utiliza para representar campos de doble precisión que tienen un tamaño variable. Por ejemplo, un campo de normal podría ser un SoMFDouble que contenga tres valores para cada normal (x, y, z).

El campo SoMFDouble se puede inicializar de varias maneras:

  • Con el constructor predeterminado: SoMFDouble myField;. Esto crea un campo vacío.
  • Con el constructor de copia: SoMFDouble myField(otherField);. Esto crea un nuevo campo que es una copia del campo existente.
  • Con un solo valor: SoMFDouble myField(3.14);. Esto crea un campo con un solo valor.
  • Con un arreglo de valores: double values[] = {1.0, 2.0, 3.0}; SoMFDouble myField(values, 3);. Esto crea un campo con los valores especificados.

Los valores del campo SoMFDouble se pueden acceder y modificar utilizando los siguientes métodos:

  • getNumValues(): Devuelve el número de valores en el campo.
  • getValues(): Devuelve un puntero al arreglo de valores.
  • setValues(): Establece los valores del campo.
  • getValue(): Devuelve el valor en el índice especificado.
  • set1Value(): Establece el valor en el índice especificado.
  • appendValue(): Agrega un valor al final del campo.
  • insertValue(): Inserta un valor en el índice especificado.
  • deleteValue(): Elimina el valor en el índice especificado.
  • startEditing(): Inicia una sesión de edición para el campo. Esto debe llamarse antes de realizar múltiples modificaciones en el campo.
  • finishEditing(): Finaliza una sesión de edición para el campo. Esto debe llamarse después de realizar múltiples modificaciones en el campo.

El campo SoMFDouble también hereda los siguientes métodos de la clase SoMField:

  • addValue(): Agrega un nuevo valor al final del campo.
  • deleteValue(): Elimina un valor del campo.
  • editValue(): Devuelve un puntero al valor en el índice especificado, permitiendo su modificación.
  • findValue(): Busca un valor en el campo y devuelve su índice.
  • getValue(): Devuelve un puntero al valor en el índice especificado.
  • insertValue(): Inserta un nuevo valor en el índice especificado.
  • move(): Mueve un valor del índice from al índice to.
  • getNumValues(): Devuelve el número de valores en el campo.
  • removeValue(): Elimina un valor del campo.
  • setValues(): Establece un conjunto de valores en el campo.
  • startEditing(): Indica que el campo está a punto de ser editado.

Y los siguientes métodos de la clase SoField:

  • getTypeId(): Devuelve el tipo de identificador del campo.
  • copyField(): Crea una copia del campo.
  • isCopy(): Devuelve TRUE si el campo es una copia de otro campo.
  • read(): Lee el campo desde un archivo de entrada.
  • write(): Escribe el campo en un archivo de salida.
  • operator=(): Asigna el valor de otro campo al campo actual.
  • operator!=(): Compara si dos campos son diferentes.
  • operator==(): Compara si dos campos son iguales.
