Description Détaillée

La classe SoPathList est un conteneur pour les pointeurs vers des objets de type SoPath.

Comme cette classe hérite de SoBaseList, le référencement et le déréférencement seront effectués par défaut sur les objets lors de append(), remove(), insert(), etc.
