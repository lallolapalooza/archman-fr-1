Description Détaillée

La classe SoSFBox3f contient un vecteur SbBox3f.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker un cube.

Vous devriez noter que cette classe est une extension de Coin et n'est pas disponible dans l'API originale SGI Open Inventor v2.1.

Cependant:
Coin 2.0
