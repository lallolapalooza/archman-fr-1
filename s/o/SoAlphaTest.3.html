Description détaillée

La classe SoAlphaTest est un nœud utilisé pour contrôler la fonction de test alpha de GL.

Avec ce nœud, vous pouvez contrôler la fonction de test alpha d'OpenGL. La fonction de test alpha vous permet de rejeter des fragments en fonction de leur valeur alpha. Par exemple, si vous définissez la fonction sur GREATER et la valeur sur 0.5, seuls les fragments ayant une valeur alpha supérieure à 0.5 seront rendus.

Le test alpha est généralement utilisé lors du rendu de textures où tous les pixels sont soit complètement opaques, soit complètement transparents. Les problèmes de tri de transparence sont évités lorsque le test alpha est utilisé à la place du mélange, car le test de profondeur peut toujours être activé et aucun tri ni rendu différé n'est nécessaire.

Pour activer le test alpha au lieu du mélange de transparence, insérez un nœud TransparencyType avec la valeur = NONE, et un nœud AlphaTest avec function défini sur GREATER et value défini sur, par exemple, 0.01.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

AlphaTest {
    function NONE
    value 0.5
}

Soyez conscient que cette classe est une extension pour Coin, et elle n'est pas disponible dans l'API originale d'Open Inventor v2.1 de SGI.

Documentation des énumérations membres

enum SoAlphaTest::Function

Énumération pour les différentes fonctions alpha.

Énumérateur

NONE
Aucun test alpha n'est effectué.
NEVER
Ne passe jamais.
ALWAYS
Passe toujours.
LESS
Passe si la valeur alpha entrante est inférieure à la valeur alpha stockée.
LEQUAL
Passe si la valeur alpha entrante est inférieure ou égale à la valeur alpha stockée.
EQUAL
Passe si la valeur alpha entrante est égale à la valeur alpha stockée.
GEQUAL
Passe si la valeur alpha entrante est supérieure ou égale à la valeur alpha stockée.
GREATER
Passe si la valeur alpha entrante est supérieure à la valeur alpha stockée.
NOTEQUAL
Passe si la valeur alpha entrante est différente de la valeur alpha stockée.
