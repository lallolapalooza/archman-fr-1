Detailed Description

This node defines and manages a GLSL shader program. It is used to attach and detach SoShader nodes, and to link the shader program and activate it.

The actual shader code is contained in SoShader nodes, which are attached to this node using the attachShader() method.

After attaching all desired shaders, the program must be linked by calling link(). This compiles the shaders and links them into a program object. If linking fails, an error message is printed to stderr.

The program can be enabled using enable() and disabled using disable(). When enabled, subsequent rendering operations will use this shader program.

A callback can be registered using setEnableCallback() to be notified when the shader program is enabled or disabled.

See also: SoShader, SoGLRenderAction.

void SoShaderProgram::disable()

Disables this shader program. After this call, subsequent rendering will use the default fixed-function pipeline or any previously enabled shader program.

This method is called automatically by SoGLRenderAction when the traversal exits the subgraph that caused the program to be enabled.

void SoShaderProgram::enable()

Enables this shader program. Subsequent rendering operations will use this program.

This method is called automatically by SoGLRenderAction when it enters the subgraph where this node is located.

void SoShaderProgram::link()

Links the attached shaders into a program object. This compiles the shaders and checks for errors. If linking fails, an error message will be printed to stderr.

This method should be called after all shader objects have been attached and before the program is enabled.
