La classe SoTranslate2Dragger fournit un mécanisme pour que l'utilisateur final puisse traduire dans un plan.

Voici à quoi ressemble le dragger avec sa géométrie par défaut à l'état inactif :

Utilisez ce dragger pour permettre à l'utilisateur final de votre application de traduire simultanément sur l'axe X et l'axe Y, c'est-à-dire librement dans un plan 3D. (Utilisez un nœud de transformation devant le dragger pour le positionner et le réorienter afin de traduire dans n'importe quel plan.)

En appuyant sur la touche MAJUSCULE, l'utilisateur final peut temporairement contraindre le dragger à un seul des deux axes.

Voir aussi

SoTranslate1Dragger, SoDragPointDragger

SoSFVec3f SoTranslate2Dragger::translation

Est continuellement mis à jour pour contenir la translation actuelle depuis la position d'origine locale du dragger. Seules les deux premières composantes (les valeurs X et Y) peuvent être modifiées par l'utilisateur final.

Le programmeur d'application utilisant ce dragger dans son code devrait connecter les champs de nœuds pertinents de la scène à ce champ pour le faire suivre le dragger.
