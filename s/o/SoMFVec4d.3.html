NOM

SoMFVec4d: classe pour stocker des tableaux de vecteurs à quatre éléments.

SYNOPIS

class SoMFVec4d : public SoMField

Description détaillée

Cette classe fournit un moyen de stocker des tableaux de vecteurs à quatre éléments. Elle prend en charge le partage de données d'application via la méthode setValuesPointer(). Voir la documentation de SoMField pour des informations sur la façon d'utiliser cette fonction.

Voir aussi

SbVec4d, SoSFVec4d Notez que cette classe est une extension pour Coin et n'est pas disponible dans l'API originale d'Open Inventor v2.1 de SGI.

Depuis

Coin 2.5
