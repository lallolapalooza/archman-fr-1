La classe SoVRMLIndexedFaceSet est utilisée pour représenter une forme 3D générique.

La documentation détaillée de la classe est tirée verbatim de la norme VRML97 (ISO/IEC 14772-1:1997). Elle est la propriété du Consortium The Web3D et est utilisée avec sa permission :

IndexedFaceSet {
  eventIn       MFInt32 set_colorIndex
  eventIn       MFInt32 set_coordIndex
  eventIn       MFInt32 set_normalIndex
  eventIn       MFInt32 set_texCoordIndex
  exposedField  SFNode  color             NULL
  exposedField  SFNode  coord             NULL
  exposedField  SFNode  normal            NULL
  exposedField  SFNode  texCoord          NULL
  field         SFBool  ccw               TRUE
  field         MFInt32 colorIndex        []        # [-1,)
  field         SFBool  colorPerVertex    TRUE
  field         SFBool  convex            TRUE
  field         MFInt32 coordIndex        []        # [-1,)
  field         SFFloat creaseAngle       0         # [0,)
  field         MFInt32 normalIndex       []        # [-1,)
  field         SFBool  normalPerVertex   TRUE
  field         SFBool  solid             TRUE
  field         MFInt32 texCoordIndex     []        # [-1,)
}

Le nœud IndexedFaceSet représente une forme 3D construite à partir de sommets listés dans le champ coord. Le champ coord contient un nœud Coordinate qui définit les sommets 3D référencés par le champ coordIndex. IndexedFaceSet utilise les indices de son champ coordIndex pour spécifier les faces polygonales en indexant les sommets dans le nœud Coordinate. Un indice de -1 indique que la face actuelle est terminée et que la suivante commence. La dernière face peut être (mais n'est pas obligée d'être) suivie d'un indice -1. Si l'indice le plus élevé dans le champ coordIndex est N, le nœud Coordinate doit contenir N+1 coordonnées (indexées de 0 à N). Chaque face d'IndexedFaceSet doit avoir :

  • au moins trois sommets non coïncidents ;
  • des sommets qui définissent un polygone plan ;
  • des sommets qui définissent un polygone non auto-intersectant.

Sinon, les résultats sont indéfinis.

Le nœud IndexedFaceSet est spécifié dans le système de coordonnées local et est affecté par les transformations de ses ancêtres.

Detailed Description

The VRML97 IndexedFaceSet node defines a list of polygons. Polygons are specified by the coordIndex field, which contains indices into the coord field. Indices are grouped into polygons by the sentinel value -1.

The polygons are drawn with the current material binding and texture mapping. Default normals are generated if the SoNormal node is not present or the normal binding is not set.

The ccw, solid, and convex fields control how the polygons are drawn.

The creaseAngle field controls how normals are generated. If the angle between two adjacent polygon normals is less than the creaseAngle, then the normal is shared between the two polygons. Otherwise, the normal is split. A value of 0.0 (the default) means that all normals are split, and a value of PI (or greater) means that all normals are shared.

The coord and coordIndex fields are inherited from SoVRMLVertexShape.
