Description Détaillée

La classe SoDrawStyle spécifie les propriétés de rendu courantes pour les formes.

Utilisez les nœuds SoDrawStyle pour influencer la manière dont les nœuds de forme qui les suivent dans le graphe de scène seront rendus. Ce type de nœud possède des champs pour aider à décider comment certains aspects des formes basées sur des points, des formes basées sur des lignes et des primitives de forme remplies sont rendus.

Exemple d'utilisation simple de la structure du graphe de scène :

#Inventor V2.1 ascii
Separator {
   Sphere { }
   Translation { translation 4 0 0 }
   DrawStyle { style LINES  lineWidth 2 }
   Sphere { }
   Translation { translation 4 0 0 }
   DrawStyle { style POINTS  pointSize 2 }
   Sphere { }
}

FORMAT DE FICHIER/VALEURS PAR DÉFAUT:

DrawStyle {
    style FILLED
    pointSize 0
    lineWidth 0
    linePattern 0xffff
    linePatternScaleFactor 1
}

SoDrawStyle — style for drawing primitives

Field list:

  SoSFUShort              pointSize
  SoSFFloat               lineWidth
  SoSFUShort              linePattern
  SoSFInt32               linePatternScaleFactor

Detailed Description

This node defines how geometric primitives should be rendered. It can affect the appearance of points, lines and faces.

The fields pointSize, lineWidth, linePattern, and linePatternScaleFactor can be used to control the appearance of points and lines.

The default node traversal does not render anything and the styles specified by this node are therefore ignored. To make use of this node, you must insert a scene graph node that is capable of rendering primitives, e.g. SoPoints, SoLineSet, SoQuadMesh, etc.

In addition, the node's attribute must be passed down to the rendering primitives. This is normally done by inheriting from SoStyle, and then inserting this node into the scene graph.

Member Enumeration Documentation

enum SoDrawStyle::style

Defines the geometric primitive type, which can be used to draw points, lines, and polygons.

Note: The enum values correspond to the OpenGL primitive types.

enum SoDrawStyle::vertexStyle

This enum defines the primitive type, which can be used to draw points, lines, and polygons. The difference to the style enum is that this enum also includes the value NONE, which implies that the vertex styling is disabled.

enum SoDrawStyle::faceStyle

Defines the style of the faces of a geometric primitive. The possible values are:

NONE
No face is drawn.
POINTS
The vertices of the face are drawn as points.
LINES
The edges of the face are drawn as lines.
FILL
The face is filled.

enum SoDrawStyle::what

This enum is used internally to specify which part of the primitive styling should be affected.

typedef enum SoDrawStyle::style SoDrawStyle::pointStyle

This is an alias for the style enum, used when specifying the drawing style for points.

typedef enum SoDrawStyle::style SoDrawStyle::lineStyle

This is an alias for the style enum, used when specifying the drawing style for lines.

Member Data Documentation

SoSFUShort SoDrawStyle::pointSize

Size in screen pixels of points when setting the SoDrawStyle::style to SoDrawStyle::POINTS.

The valid range of point size settings varies according to which OpenGL implementation is used. For the purpose of not trying to set illegal values, the application programmer should at runtime check the valid range. How this can be accomplished is described in the class documentation of SoGLPointSizeElement.

Default value is 0.0f, which is a "tag" value which tells the rendering library to use the default setting.

SoSFFloat SoDrawStyle::lineWidth

Width in screen pixels of SoLineSet and SoIndexedLineSet lines, and also of geometry border lines if setting the SoDrawStyle::style to SoDrawStyle::LINES.

The valid range of line width settings varies according to which OpenGL implementation is used. For the purpose of not trying to set illegal values, the application programmer should at runtime check the valid range. How this can be accomplished is described in the class documentation of SoGLLineWidthElement.

Default value is 0.0f, which is a "tag" value which tells the rendering library to use the default setting.

SoSFUShort SoDrawStyle::linePattern

Pattern as a bitmask used when drawing lines. Default is 0xffff (no "holes").

SoSFInt32 SoDrawStyle::linePatternScaleFactor

Multiplier for the bitmask in linePattern (range 1 - 256). Default is 1.
