Description Détaillée

L'élément SoDepthBufferElement contrôle les paramètres du tampon de profondeur.

Soyez conscient que cette classe est une extension pour Coin et qu'elle n'est pas disponible dans l'API originale Open Inventor v2.1 de SGI.
Depuis

Coin 3.0
