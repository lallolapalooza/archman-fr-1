Description Détaillée

Le nœud SoAnnotation dessine toute sa géométrie enfant par dessus les autres géométries.

Ce nœud de type groupe utilise le rendu retardé en combinaison avec la désactivation du tampon z pour permettre à ses enfants de rendre leur géométrie transparente par-dessus les autres géométries dans la scène.

Comme le tampon z doit être désactivé, la géométrie des enfants ne sera pas triée de l'arrière vers l'avant, mais plutôt dans l'ordre où elle apparaît dans le graphe de scène.

FORMAT DE FICHIER / VALEURS PAR DÉFAUT :

Annotation {
    renderCaching AUTO
    boundingBoxCaching AUTO
    renderCulling AUTO
    pickCulling AUTO
}

void SoAnnotation::GLRenderBelowPath(SoGLRenderAction *action) [virtual]

SGI Open Inventor v2.1 a déprécié le support de SoGLRenderAction::addMethod(). À la place, on peut appeler directement GLRender() et, pour optimiser le parcours, le nœud SoSeparator appelle GLRenderBelowPath() lorsque le chemin de rendu est BELOW_PATH ou NO_PATH (le chemin de rendu est garanti de ne pas changer). Pour être compatible avec SGI's Inventor (et donc aussi TGS'), nous avons choisi de suivre leur implémentation à cet égard.

SoSeparator::GLRenderBelowPath() ne parcourt pas les enfants en utilisant SoChildList::traverse(), mais appelle directement GLRenderBelowPath() pour tous ses enfants.
