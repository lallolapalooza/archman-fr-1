Description détaillée

La classe SoLocation2Event contient des informations sur les événements de mouvement 2D.

Les événements de localisation 2D sont générés par des périphériques capables de 2D, par exemple des périphériques pointeurs — typiquement une souris d'ordinateur. Les instances de cette classe contiennent des informations sur la position du pointeur sur la zone de rendu.

SoLocation2Event ne contient aucune information nouvelle par rapport à sa classe parente, son seul but est de permettre de spécifier le type de l'événement pour les récepteurs d'objets d'événement dans le graphe de scène.
