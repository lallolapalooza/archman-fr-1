SoMultiTextureCoordinateElement::CoordType SoMultiTextureCoordinateElement::getType (SoState *const state, const int unit = 0) [static]

Cette méthode est utilisée par les formes. Trois valeurs de retour sont possibles.

DEFAULT signifie que les formes doivent générer leurs propres coordonnées de texture.

EXPLICIT signifie que des coordonnées de texture discrètes sont stockées et doivent être récupérées avec get2(), get3() ou get4().

FUNCTION signifie que get(point, normal) doit être utilisé pour générer les coordonnées de texture.

const SbVec4f & SoMultiTextureCoordinateElement::get (const int unit, const SbVec3f & point, const SbVec3f & normal) const

Cette méthode retourne les coordonnées de texture pour le point et la normale donnés. La coordonnée est retournée sous forme de vecteur 4D où les coordonnées r et q peuvent être définies à 0 et 1 respectivement, selon la dimension des coordonnées de texture utilisée.

void SoMultiTextureCoordinateElement::push (SoState * state) [virtual]

Cette méthode est appelée chaque fois qu'un nouvel élément est requis dans l'une des piles. Cela se produit lorsqu'un élément modifiable est demandé, en utilisant SoState::getElement() ou indirectement SoElement::getElement(), et que la profondeur de l'élément courant est inférieure à la profondeur de l'état.

Redéfinissez cette méthode si votre élément a besoin de copier des données de l'élément précédent au sommet de la pile. La méthode push() est appelée sur le nouvel élément, et l'élément précédent peut être trouvé en utilisant SoElement::getNextInStack().
