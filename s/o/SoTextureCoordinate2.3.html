Description Détaillée

La classe SoTextureCoordinate2 contient un ensemble de coordonnées pour le mappage des textures 2D.

Lors de la rencontre d'un nœud de ce type pendant le parcours, les coordonnées qu'il contient seront placées sur la pile d'état. Certains nœuds de forme (par exemple, SoIndexedFaceSet, parmi beaucoup d'autres) peuvent alors utiliser ces coordonnées pour un contrôle explicite et détaillé de la manière dont les textures sont mappées à leurs surfaces.

(Si le mappage de texture est utilisé sans aucun nœud SoTextureCoordinate2 dans le graphe de scène menant à un nœud de forme, tous les types de formes ont des valeurs par défaut. Les nœuds SoTextureCoordinate2 ne sont donc nécessaires que si vous n'êtes pas satisfait du mappage par défaut.)

Notez qu'un nœud SoTextureCoordinate2 *remplacera* les coordonnées déjà présentes dans l'état (le cas échéant).

Voici un exemple très simple (en format de fichier de graphe de scène Inventor - son mappage vers le code source est direct) qui montre comment configurer deux polygones quadratiques, l'un mappé 1:1 à la texture, l'autre utilisant seulement le quart supérieur gauche de la texture :

Separator {
   Texture2 {
      image 6 8 3
      0x00ff0000 0x00ff0000 0x000000ff 0x000000ff 0x00ff00ff 0x00ff00ff
      0x00ff0000 0x00ff0000 0x000000ff 0x000000ff 0x00ff00ff 0x00ff00ff
      0x00ff0000 0x00ff0000 0x000000ff 0x000000ff 0x00ff00ff 0x00ff00ff
      0x0000ff00 0x0000ff00 0x0000ffff 0x0000ffff 0x0000ff00 0x0000ff00
      0x0000ff00 0x0000ff00 0x0000ffff 0x0000ffff 0x0000ff00 0x0000ff00
      0x00ffff00 0x00ffff00 0x000000ff 0x000000ff 0x00ffffff 0x00ffffff
      0x00ffff00 0x00ffff00 0x000000ff 0x000000ff 0x00ffffff 0x00ffffff
      0x00ffff00 0x00ffff00 0x000000ff 0x000000ff 0x00ffffff 0x00ffffff
   }
   Coordinate3 { point [ -1 -1 0, 1 -1 0, 1 1 0, -1 1 0 ] }
   # Mappage "1:1" à l'apparence réelle de la texture. (Notez que Y va
   # du bas vers le haut, contrairement à la manière courante de spécifier les données bitmap
   # du haut vers le bas.)
   TextureCoordinate2 { point [ 0 1, 1 1, 1 0, 0 0 ] }
   IndexedFaceSet {
      coordIndex [ 0, 1, 2, 3, -1 ]
      textureCoordIndex [ 0, 1, 2, 3, -1 ]
   }
   Translation { translation +4 0 0 }
   # Coin supérieur gauche.
   TextureCoordinate2 { point [ 0 0.5, 0.5 0.5, 0.5 0, 0 0 ] }
   IndexedFaceSet {
      coordIndex [ 0, 1, 2, 3, -1 ]
      textureCoordIndex [ 0, 1, 2, 3, -1 ]
   }
}

Documentation des Données Membres

L'ensemble des coordonnées de texture 2D. La valeur par défaut du champ est un ensemble vide.

Les coordonnées de texture sont généralement spécifiées dans des coordonnées normalisées, c'est-à-dire dans la plage [0, 1]. (0, 0) est le coin inférieur gauche, tandis que (1, 1) est le coin supérieur droit de l'image de texture. Des coordonnées en dehors de la plage [0, 1] peuvent être utilisées pour répéter la texture sur une surface.
