Description détaillée

La classe SoFullPath permet d'examiner les enfants cachés dans les chemins.

Le SoPath permet un accès uniquement depuis le nœud de tête jusqu'au premier nœud avec des enfants cachés, mais pas au-delà.

Comme la classe SoFullPath hérite de SoPath et ne contient aucune donnée privée, vous pouvez convertir des instances de SoPath en type SoFullPath. Cela vous permettra d'examiner les enfants cachés.

(En fait, vous ne devriez pas créer d'instances de cette classe. C'est juste une interface "étendue" vers la classe héritée SoPath.)

NOM

SoFullPath - Une sous-classe de SoPath qui représente un chemin contenant uniquement des composantes qui ne sont pas cachées.

Description détaillée

Cette classe étend SoPath pour gérer spécifiquement les chemins qui ne contiennent que des composantes non cachées. Cela signifie que lors de la traversée du graphe de scène, les nœuds cachés sont complètement ignorés.

Le but principal de cette classe est de fournir une représentation de chemin qui simplifie certaines opérations en excluant les nœuds cachés du calcul du chemin.
