Description détaillée

La classe SoSFName est un conteneur pour un SbName.

Ce champ est utilisé lorsque les nœuds, moteurs ou autres conteneurs de champs ont besoin de stocker une seule chaîne de nom.

Les champs de ce type stockent leur valeur dans le fichier sous forme de la chaîne de nom entre guillemets.
