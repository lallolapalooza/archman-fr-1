Description Détaillée

La classe SoComplexity est un type de nœud utilisé pour définir le compromis entre la qualité et la performance.

En insérant des nœuds SoComplexity dans le graphe de scène, vous pouvez contrôler la précision avec laquelle les formes complexes sont rendues et la qualité du mappage de texture utilisé pour la géométrie dans la scène.

Les nœuds de forme comme SoCone, SoSphere, SoCylinder et d'autres, seront rendus avec moins de polygones et donc amélioreront les performances, si la valeur de complexité de l'état de parcours est réglée sur une valeur inférieure.

En utilisant le champ SoComplexity::type, vous pouvez également choisir de rendre le graphe de scène (ou des parties de celui-ci) uniquement sous forme de boîtes englobantes filaires. Cela améliorera considérablement les performances de rendu et pourra parfois être utilisé dans des situations particulières où la réactivité est plus importante que l'apparence.

Le mappage de texture peut être effectué d'une manière coûteuse mais esthétique, ou d'une manière rapide qui n'est pas aussi attrayante en modifiant la valeur du champ SoComplexity::textureQuality. En réglant le champ SoComplexity::textureQuality sur une valeur de 0.0, vous pouvez également désactiver complètement le mappage de texture.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

Complexity {
    type OBJECT_SPACE
    value 0.5
    textureQuality 0.5
}

enum SoComplexity::Type

Les valeurs disponibles pour le champ SoComplexity::type.

Énumérateur

OBJECT_SPACE
Utilise la valeur SoComplexity::value dans les calculs basés sur la taille de la géométrie dans l'espace monde 3D.
SCREEN_SPACE
Utilise la valeur SoComplexity::value dans les calculs basés sur la taille de la géométrie lorsqu'elle est projetée sur la zone de rendu. C'est souvent un bon moyen de s'assurer que les objets sont rendus avec la plus faible complexité possible tout en conservant leur apparence pour l'utilisateur.

Rend la géométrie supplémentaire dans le graphe de scène uniquement sous forme de boîtes englobantes pour un rendu super rapide.

Documentation des membres de données

SoSFEnum SoComplexity::type

Définit le type de rendu. La valeur par défaut est SoComplexity::OBJECT_SPACE.

SoSFFloat SoComplexity::value

Valeur de complexité, plage valide de 0.0 (apparence la plus médiocre, meilleures performances) à 1.0 (meilleure apparence, rendu plus lent). Valeur par défaut pour le champ est 0.5.

Note : Sans aucun nœud SoComplexity dans l'arborescence de la scène, la géométrie sera rendue comme si un nœud SoComplexity était présent avec SoComplexity::value défini sur 1.0.

SoSFFloat SoComplexity::textureQuality

Définit la valeur de qualité pour le mappage de textures. La plage valide est de 0.0 (carte de texture désactivée, le rendu sera beaucoup plus rapide sur presque tous les systèmes) à 1.0 (meilleure qualité, le rendu peut être lent).

La même valeur pour ce champ sur différentes plates-formes peut produire des résultats différents, en fonction de la qualité du matériel de rendu sous-jacent.

Note : Ce champ influe sur le comportement du nœud SoTexture2, et non sur les nœuds de forme. Une conséquence importante est que le programmeur d'applications doit être conscient de la nécessité d'insérer ses nœuds SoComplexity avant les nœuds SoTexture2 dans l'arborescence de la scène afin qu'ils aient un effet sur les formes texturées.
