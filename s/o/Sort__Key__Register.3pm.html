Sort::Key::Register(3) Documentation Perl Contribuée par l'Utilisateur Sort::Key::Register(3)

NOM

Sort::Key::Register - dire à Sort::Key comment trier de nouveaux types de données.

SYNOPSIS

use Sort::Key::Register Person =>
    sub { $_->surname, $_->name },
    qw(string string);
use Sort::Key::Register 'Color::Component' => 'integer';
use Sort::Key::Register Color =>
    sub { $_->R, $_->G, $_->B },
    ('Color::Component') x 3;

DESCRIPTION

Sort::Key::Register permet d'enregistrer de nouveaux types de données auprès de Sort::Key afin qu'ils puissent être triés comme des types supportés nativement.

Il fonctionne comme un module pragma et n'exporte aucune fonction, toutes ses fonctionnalités sont fournies via "use" :

use Sort::Key::Register ...

Pour éviter les collisions entre modules enregistrant des types du même nom, vous devriez les qualifier avec le nom du paquet.

use Sort::Key::Register 'MyPkg::foo' => sub { $_ }, '-int';
# ou en utilisant __PACKAGE__:
use Sort::Key::Register __PACKAGE__, sub { $_ }, '-int';

UTILISATION

use Sort::Key::Register $name => \&multikeygen, @keytypes;
enregistre le type $name.

&multikeygen est la fonction d'extraction multi-clés pour le type et @keytypes sont les types des clés extraites.

use Sort::Key::Register $name => $keytype;
ce 'use' est utile pour les types simples qui sont triés comme un autre type déjà enregistré, éventuellement en changeant la direction du tri (croissant ou décroissant).
