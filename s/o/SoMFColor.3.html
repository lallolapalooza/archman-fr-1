Description détaillée

La classe SoMFColor est un conteneur pour les valeurs SbColor.

Ce champ est utilisé lorsque les nœuds, moteurs ou autres conteneurs de champs doivent stocker plusieurs valeurs de couleur (c'est-à-dire des triplets "Rouge Vert Bleu").

Ce champ prend en charge le partage de données d'application via la méthode setValuesPointer(). Voir la documentation de SoMField pour savoir comment utiliser cette fonction.

Voir aussi

SbColor, SoSFColor
