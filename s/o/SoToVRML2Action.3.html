Description détaillée

La classe SoToVRML2Action construit un nouveau graphe de scène, en utilisant uniquement des nœuds VRML97/VRML2.

Cette action est utilisée pour convertir un graphe de scène de nœuds VRML1/Coin en un nouveau graphe de scène utilisant uniquement des nœuds VRML97/VRML2.

En raison des différences fondamentales entre VRML1/Coin et VRML2 (ce dernier n'ayant pas réellement d'état de parcours), le nouveau graphe de scène sera généralement un peu plus volumineux. Pour minimiser cet effet, l'action tente de réutiliser les nœuds lorsque cela est possible.

Les nœuds VRML1 seront convertis en leurs nœuds VRML2 équivalents, tandis que les nœuds Coin sans équivalent VRML2 sont convertis en IndexedFaceSet. Si le DrawStyle est POINTS, toute la géométrie sera construite en utilisant PointSet ; si c'est LINES, IndexedLineSet est utilisé.

Voici un exemple d'utilisation de base de cette action, sous la forme d'un programme complet et autonome :

#include <Inventor/SoDB.h>
#include <Inventor/SoInteraction.h>
#include <Inventor/SoInput.h>
#include <Inventor/SoOutput.h>
#include <Inventor/actions/SoWriteAction.h>
#include <Inventor/actions/SoToVRML2Action.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/VRMLnodes/SoVRMLGroup.h>
int
main(int argc, char *argv[])
{
  SoDB::init();
  SoInteraction::init();
  SoInput in;
  in.openFile(argv[1]);
  printf("Lecture...\n");
  SoSeparator *root = SoDB::readAll(&in);
  if (root) {
    root->ref();
    SbString hdr = in.getHeader();
    in.closeFile();
    printf("Conversion...\n");
    SoToVRML2Action tovrml2;
    tovrml2.apply(root);
    SoVRMLGroup *newroot = tovrml2.getVRML2SceneGraph();
    newroot->ref();
    root->unref();
    printf("Écriture...\n")
; SoOutput out; out.openFile("out.wrl"); out.setHeaderString("#VRML V2.0 utf8"); SoWriteAction wra(&out); wra.apply(newroot); out.closeFile(); newroot->unref(); } return 0; }

Note : si le support de VRML97 n'est pas présent dans la bibliothèque Coin, cette action ne fait rien et getVRML2SceneGraph retourne toujours NULL.

void SoToVRML2Action::apply (SoPath * path) [virtual]

Applique l'action aux parties du graphe définies par path.

Notez qu'un SoPath contiendra également tous les nœuds qui peuvent influencer, par exemple, les nœuds de géométrie dans le chemin. Ainsi, par exemple, appliquer un SoGLRenderAction sur un SoPath rendra ce chemin comme prévu dans la vue, où la géométrie recevra correctement ses matériaux, textures et autres paramètres d'apparence.

Si le path se termine par un nœud SoGroup, l'action traversera également les enfants du nœud terminal.

void SoToVRML2Action::apply (const SoPathList & pathlist, SbBool obeysrules = FALSE) [virtual]

Applique l'action aux graphes définis par pathlist. Si obeysrules est défini sur TRUE, pathlist doit respecter les quatre conditions suivantes (ce qui est le cas pour les listes de chemins renvoyées par les actions de recherche de nœuds non-groupes et les listes de chemins renvoyées par les actions de sélection) :

Tous les chemins doivent commencer au même nœud de tête. Tous les chemins doivent être triés dans l'ordre de parcours. Les chemins doivent être uniques. Aucun chemin ne peut continuer à travers le point final d'un autre chemin.

void SoToVRML2Action::beginTraversal (SoNode * node) [protected], [virtual]

Cette méthode virtuelle est appelée par SoAction::apply(), et est le point d'entrée pour la traversée réelle du graphe de scène.

Elle peut être surchargée pour initialiser l'action au début de la traversée, pour des initialisations spécifiques dans les sous-classes d'action héritant de SoAction.

La méthode par défaut appelle simplement traverse(), ce que toute implémentation surchargée de la méthode doit également faire (ou appeler SoAction::beginTraversal()) pour déclencher la traversée du graphe de scène.
