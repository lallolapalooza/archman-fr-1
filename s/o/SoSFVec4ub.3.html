Description détaillée

Le SoSFVec4ub est un conteneur pour un vecteur SbVec4ub.

Cette propriété est utilisée lorsque les nœuds, moteurs ou autres conteneurs de champs doivent stocker un vecteur à quatre éléments.

Voir aussi

SbVec4ub, SoMFVec4ub Note: cette classe est une extension pour Coin, et n'est pas disponible dans l'API originale SGI Open Inventor v2.1.

Depuis

Coin 2.5
