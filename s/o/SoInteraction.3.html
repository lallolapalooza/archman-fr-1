Description Détaillée

La classe SoInteraction s'occupe de l'initialisation des classes internes.

SoInteraction est présente dans le seul but de fournir une interface aux méthodes d'initialisation des classes de Coin qui sont liées d'une manière ou d'une autre à l'interaction utilisateur, comme les draggers et les manipulateurs.

Il est peu probable que le programmeur d'application ait besoin de s'inquiéter de cette classe, car SoInteraction::init() est appelée par les méthodes d'initialisation spécifiques à l'interface graphique.

Documentation des Fonctions Membres

void SoInteraction::init (void ) [static]

Appelle la méthode initClass() de ces classes : SoAntiSquish, SoSelection, SoExtSelection, SoSurroundScale, SoInteractionKit, SoDragger, SoClipPlaneManip, SoDirectionalLightManip, SoPointLightManip, SoSpotLightManip, SoTransformManip, SoCenterballManip, SoHandleBoxManip, SoJackManip, SoTabBoxManip, SoTrackballManip, SoTransformBoxManip, SoTransformerManip.

Notez que cette méthode appelle SoDB::init() et SoNodeKit::init() pour s'assurer que toutes les classes dont dépend la fonctionnalité d'interaction ont été initialisées.

Les programmeurs d'applications ne devraient généralement pas avoir à invoquer cette méthode directement à partir du code de l'application, car elle est appelée indirectement à partir des fonctions init() des bibliothèques de liaison d'interface graphique. Seulement si vous utilisez votre propre liaison d'interface graphique (et non l'une des bibliothèques SoQt, SoGtk, SoXt, SoWin, Sc21 etc. de Kongsberg Oil & Gas Technologies) devez-vous explicitement appeler SoInteraction::init().
