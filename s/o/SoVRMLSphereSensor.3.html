Description Détaillée

La classe SoVRMLSphereSensor mappe le mouvement du pointeur en rotations sur une sphère.

La documentation détaillée de la classe est extraite textuellement de la norme VRML97 (ISO/IEC 14772-1:1997). Elle est protégée par le droit d'auteur du Web3D Consortium, et est utilisée avec la permission du Consortium:

SphereSensor {
  exposedField SFBool     autoOffset        TRUE
  exposedField SFBool     enabled           TRUE
  exposedField SFRotation offset            0 1 0 0  # [-1,1],(-,)
  eventOut     SFBool     isActive
  eventOut     SFRotation rotation_changed
  eventOut     SFVec3f    trackPoint_changed
}

Le nœud SphereSensor mappe le mouvement du périphérique de pointage en rotation sphérique autour de l'origine du système de coordonnées local. Le nœud SphereSensor utilise la géométrie descendante du nœud parent pour déterminer s'il est susceptible de générer des événements.

Le champ exposé enabled active et désactive le nœud SphereSensor. Si enabled est TRUE, le capteur réagit de manière appropriée aux événements utilisateur. Si enabled est FALSE, le capteur ne suit pas les entrées utilisateur et n'envoie pas d'événements. Si enabled reçoit un événement FALSE et que isActive est TRUE, le capteur devient désactivé et inactif, et génère un événement isActive FALSE. Si enabled reçoit un événement TRUE, le capteur est activé et prêt pour une activation par l'utilisateur.

Le nœud SphereSensor génère des événements lorsque le périphérique de pointage est activé alors que le pointeur indique des nœuds de géométrie descendants du groupe parent du capteur. Voir 4.6.7.5, Activation et manipulation des capteurs (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.7.5), pour les détails sur l'utilisation du périphérique de pointage pour activer le SphereSensor.

Lors de l'activation du périphérique de pointage (par exemple, bouton de la souris enfoncé) sur la géométrie du capteur, un événement isActive TRUE est envoyé. Le vecteur défini par le point d'intersection initial sur la géométrie du SphereSensor et l'origine locale détermine le rayon de la sphère qui est utilisé pour mapper le mouvement ultérieur du périphérique de pointage lors du glissement. La sphère virtuelle définie par ce rayon et l'origine locale au moment de l'activation est utilisée pour interpréter le mouvement ultérieur du périphérique de pointage et n'est pas affectée par les changements apportés au système de coordonnées du capteur tant que le capteur est actif.

Pour chaque position du palpeur, un événement rotation_changed est envoyé, qui correspond à la somme de la rotation relative par rapport au point d'intersection d'origine plus la valeur de décalage. Les événements trackPoint_changed reflètent la position de glissement non limitée sur la surface de cette sphère. Lorsque le périphérique de pointage est désactivé et que autoOffset est TRUE, offset est défini sur la dernière valeur de rotation_changed et un événement offset_changed est généré. Voir 4.6.7.4, Capteurs de glissement (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.7.4), pour plus de détails.

Lorsque le capteur génère un événement isActive TRUE, il capture tous les événements de mouvement ultérieurs du périphérique de pointage jusqu'à ce qu'il soit relâché et génère un événement isActive FALSE (les autres capteurs de périphérique de pointage ne généreront pas d'événements pendant ce temps). Le mouvement du périphérique de pointage lorsque isActive est TRUE est appelé un "glissement". Si un périphérique de pointage 2D est utilisé, les événements isActive refléteront généralement l'état du bouton principal associé au périphérique (c'est-à-dire, isActive est TRUE lorsque le bouton principal est enfoncé et FALSE lorsqu'il est relâché). Si un périphérique de pointage 3D (par exemple, une baguette) est utilisé, les événements isActive refléteront généralement si le pointeur se trouve à l'intérieur (ou en contact avec) la géométrie du capteur.

Pendant que le périphérique de pointage est activé, les événements trackPoint_changed et rotation_changed sont produits. Les événements trackPoint_changed représentent les points d'intersection non limités sur la surface de la sphère invisible. Si le périphérique de pointage est déplacé hors de la sphère pendant qu'il est activé, les navigateurs peuvent interpréter cela de diverses manières (par exemple, limiter toutes les valeurs à la sphère ou continuer à faire pivoter le point à mesure qu'il s'éloigne de la sphère).

Chaque mouvement du périphérique de pointage pendant que isActive est TRUE génère des événements trackPoint_changed et rotation_changed. Des informations supplémentaires sur ce comportement se trouvent dans 4.6.7.3 (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.7.3), Capteurs de périphérique de pointage, 4.6.7.4, Capteurs de glissement (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.7.4), pour plus de détails.

L'événement isActive est envoyé lorsque le périphérique de pointage est activé et que le capteur est prêt à recevoir des événements. L'événement est généré lorsque le périphérique de pointage est activé et que le capteur est prêt à recevoir des événements. L'événement est généré lorsque le périphérique de pointage est activé et que le capteur est prêt à recevoir des événements.

NAME

SoVRMLSphereSensor — sensor node for interactive sphere manipulation

SYNOPSIS

#include <Inventor/VRMLnodes/SoVRMLSphereSensor.h>

Inherits from SoVRMLDragSensor.

Detailed Description

The SoVRMLSphereSensor is a sensor node that allows the user to interactively rotate an object around a sphere. The sensor is activated when the user clicks on the object associated with the sensor and drags the mouse. The interaction is based on the user's mouse movements relative to the sphere defined by the sensor's position and orientation.

The sensor generates events that can be used to update the rotation of the object. The actual behavior and interpretation of the sensor's output depend on how it is connected to other nodes in the scene graph.

For more details on how sensors work in VRML, refer to the specification section on Sensors: (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.7), and 4.6.7.5, Activating and manipulating sensors (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.7.5).
