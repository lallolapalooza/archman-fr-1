Description détaillée

La classe SoOutput est une abstraction d'un flux de sortie.

SoOutput offre la capacité d'écrire des types de base dans un fichier ou un tampon mémoire, soit en format ASCII, soit en format binaire.

Voir aussi

SoInput, SoWriteAction

Documentation des énumérations de membres

enum SoOutput::Stage

Énumère les étapes possibles d'une opération d'écriture (l'écriture peut nécessiter plusieurs passes).

Voir aussi

setStage(), getStage()

Énumérateur

COUNT_REFS
N'écrit pas, compte simplement les références internes dans le graphe de scène.
WRITE
Signifie que l'exportation réelle des données doit avoir lieu pendant cette passe.

enum SoOutput::Annotations

Les valeurs de cette énumération sont utilisées à des fins de débogage pour annoter la sortie d'une opération d'écriture.

Énumérateur

ADDRESSES
Annote la sortie avec des informations d'adresse de pointeur.
REF_COUNTS
Annote la sortie avec les comptes de références des objets écrits.

SbBool SoOutput::setCompression (const SbName & compmethod, const float level = 0.5f)

Définit la méthode et le niveau de compression utilisés lors de l'écriture du fichier. compmethod est la bibliothèque/méthode de compression à utiliser lors de la compression. level est le niveau de compression, où 0.0 signifie aucune compression et 1.0 signifie compression maximale.

Actuellement, BZIP2 et GZIP sont les seules méthodes de compression prises en charge, et vous devez compiler Coin avec le support zlib et bzip2 pour les activer.

Fournissez compmethod = NONE ou level = 0.0 si vous souhaitez désactiver la compression. La compression est désactivée par défaut.

Veuillez noter qu'il n'est pas possible de compresser lors de l'écriture dans un tampon mémoire.

Cette méthode retournera TRUE si la méthode de compression sélectionnée est disponible. Si elle n'est pas disponible, FALSE sera retourné et la compression sera désactivée.

void SoOutput::setBuffer (void * bufPointer, size_t initSize, SoOutputReallocCB * reallocFunc, int32_t offset = 0) [virtual]

Configure un tampon mémoire de taille initSize pour l'écriture. L'écriture commencera à bufPointer + offset.

Si le tampon est rempli, reallocFunc est appelé pour obtenir plus de mémoire. Si reallocFunc retourne NULL, l'écriture ultérieure est désactivée.

Note importante : rappelez-vous que le tampon mémoire résultant après les opérations d'écriture peut se trouver ailleurs en mémoire que sur bufPointer si reallocFunc est défini. Il est conseillé de prendre l'habitude d'utiliser toujours getBuffer() pour récupérer le pointeur du tampon mémoire après les opérations d'écriture.

Voici un exemple d'utilisation complet et autonome qui montre comment écrire un graphe de scène dans un tampon mémoire :

#include <Inventor/SoDB.h>
#include <Inventor/actions/SoWriteAction.h>
#include <Inventor/nodes/SoCone.h>
#include <Inventor/nodes/SoSeparator.h>
static char * buffer;
static size_t buffer_size = 0;
static void *
buffer_realloc(void * bufptr, size_t size)
{
  buffer = (char *)realloc(bufptr, size);
  buffer_size = size;
  return buffer;
}
static SbString
buffer_writeaction(SoNode * root)
{
  SoOutput out;
  buffer = (char *)malloc(1024);
  buffer_size = 1024;
  out.setBuffer(buffer, buffer_size, buffer_realloc);
  SoWriteAction wa(&out);
  wa.apply(root);
  SbString s(buffer);
  free(buffer);
  return s;
}
int
main(int argc, char ** argv)
{
  SoDB::init();
  SoSeparator * root = new SoSeparator;
  root->ref();
  root->addChild(new SoCone);
  SbString s = buffer_writeaction(root);
  (void)fprintf(stdout, "%s\n", s.getString());
  root->unref();
  return 0;
}
