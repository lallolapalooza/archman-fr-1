Description détaillée

La classe SoMFVec2b est un conteneur pour les vecteurs SbVec2b.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker un tableau de vecteurs à deux éléments.

NAME

SoMFVec2b - field class holding an array of 2-component, 8-bit vectors.

SYNOPSIS

#include <Inventor/fields/SoMFVec2b.h>

Detailed Description

This field supports application data sharing through a setValuesPointer() method. See SoMField documentation for information on how to use this function.

See also

SbVec2b, SoSFVec2b Be aware that this class is an extension for Coin, and it is not available in the original SGI Open Inventor v2.1 API.

Since

Coin 2.5
