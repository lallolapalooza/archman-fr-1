Description Détaillée

La classe SoWWWAnchor ajoute des callbacks d'URL à la géométrie mise en surbrillance.

En plus de la mise en surbrillance de la géométrie sous le curseur, le programmeur d'application peut définir des callbacks. Il est possible de définir un callback pour la sélection, le callback de récupération (fetch callback), et un callback pour la mise en surbrillance.

#Inventor V2.1 ascii
WWWAnchor {
   name "https://github.com/coin3d/coin/egg.iv"
   description "Easter Egg"
   Separator {
      Transform { scaleFactor 0.8 1.2 0.8 }
      Sphere { }
   }
}

FORMAT DE FICHIER / VALEURS PAR DÉFAUT :

WWWAnchor {
    renderCaching AUTO
    boundingBoxCaching AUTO
    renderCulling AUTO
    pickCulling AUTO
    color 0.3 0.3 0.3
    style EMISSIVE
    mode AUTO
    name "<URL indéfinie>"
    description ""
    map NONE
}
