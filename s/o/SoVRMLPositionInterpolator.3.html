NAME

SoVRMLPositionInterpolator — le nœud interpolateur de position Vrml

SYNOPSIS

#include <Inventor/VRMLnodes/SoVRMLPositionInterpolator.h>

SoVRMLPositionInterpolator {
  MFVec3f        key   [ ]
  MFFloat        value [ ]
  SFVec3f        defaultValue  0 0 0
}

Detailed Description

Ce nœud fait partie des éléments de la bibliothèque d'éléments de développement Inventor de SGI et permet d'interpoler une position dans un espace 3D.

Il utilise des informations fournies dans les champs key et value pour créer une fonction d'interpolation. L'argument key définit les valeurs de temps auxquel les positions sont spécifiées, et l'argument value contient les positions correspondantes.

L'interpolation est effectuée en utilisant des courbes de Bézier cubiques.

Member Data Documentation

Le nœud possède les champs suivants :

MFVec3f key [ ]
Une liste de valeurs temporelles (normalisées entre 0.0 et 1.0) qui spécifient les points dans le temps où les positions sont définies.
MFFloat value [ ]
Une liste de positions 3D qui correspondent aux valeurs de temps dans le champ key.
SFVec3f defaultValue 0 0 0
La valeur par défaut de la position, utilisée si aucun autre calcul n'est possible.

Chaque fois que l'interpolateur a calculé une nouvelle valeur.
