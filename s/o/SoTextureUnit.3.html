Description Détaillée

La classe SoTextureUnit est un nœud permettant de définir l'unité de texture active.

Lorsqu'un nœud SoTextureUnit est inséré dans le graphe de scène, toutes les nœuds de texture subséquents (SoTexture2, SoTextureCoordinate2, SoTextureCoordinate3, SoTexture2Transform, SoTexture3Transform, SoTextureCoordinateEnvironment, SoTextureCoordinatePlane et SoComplexity) affecteront l'unité de texture définie dans le champ `unit`.

Voir le module SoGuiExample pour un exemple d'utilisation de ce nœud.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

TextureUnit {
    unit 0
    mappingMethod IMAGE_MAPPING
}

Depuis

Coin 2.2
