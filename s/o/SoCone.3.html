Description Détaillée

La classe SoCone permet de rendre des formes de cônes.

Insère une forme de cône dans le graphe de scène. Le cône est rendu avec les paramètres de matériau, de texture et de style de rendu actuels (si présents, sinon les paramètres par défaut sont utilisés).

Le nœud de classe SoCone est fourni comme une abstraction pratique pour le programmeur d'application afin d'utiliser des formes "complexes" de ce type sans avoir à effectuer elle-même la tessellation en polygones ni d'autres programmations de bas niveau.

Un cône est visualisé par le système de rendu sous-jacent en tessellant d'abord le cône conceptuel en un ensemble de polygones. Pour contrôler le compromis entre une apparence visuelle du cône aussi correcte que possible et un rendu rapide, utilisez un nœud SoComplexity pour influencer le nombre de polygones générés à partir du processus de tessellation. (Plus la valeur de complexité est élevée, plus le nombre de polygones générés est important, et plus les côtés du cône auront l'air "arrondis".) Réglez le champ SoComplexity::value sur ce qui vous semble être un bon compromis entre correction et vitesse pour votre application particulière.

FORMAT DE FICHIER / VALEURS PAR DÉFAUT :

Cone {
    bottomRadius 1
    height 2
    parts (SIDES | BOTTOM)
}

void SoCone::computeBBox (SoAction * action, SbBox3f & box, SbVec3f & center) [protégé], [virtuel]

Implémenté par les sous-classes de SoShape pour informer la super-classe SoShape de la taille exacte et du centre pondéré de la boîte englobante de la forme.

La boîte englobante et le point central doivent être calculés et retournés dans le système de coordonnées local.

La méthode implémente le comportement d'action pour les nœuds de forme pour SoGetBoundingBoxAction. Elle est appelée depuis SoShape::getBoundingBox(). (Les sous-classes ne doivent pas remplacer SoNode::getBoundingBox().)
