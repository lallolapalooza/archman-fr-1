Description détaillée

La classe SoTimerSensor est un capteur qui se déclenchera à intervalles réguliers.

Utilisez les capteurs de cette classe lorsque vous souhaitez exécuter un travail répétitif à un intervalle spécifique, sans avoir à reprogrammer explicitement le capteur (c'est-à-dire que SoTimerSensor se reprogramme automatiquement après son déclenchement).

Les instances de SoTimerSensor sont couramment utilisées pour déclencher des mises à jour d'animation à un taux d'images constant.

Documentation des fonctions membres

void SoTimerSensor::setBaseTime (const SbTime & baseref)

Définit l'heure de déclenchement de base.

Si vous utilisez cette méthode, les heures de déclenchement seront par intervalles à partir de la valeur donnée.

Sans heure de déclenchement explicitement définie, le prochain déclenchement après un déclenchement précédent sera à l'heure actuelle plus l'intervalle. Notez que cela entraînera une dérive du minuteur.

void SoTimerSensor::schedule (void ) [virtual]

Réimplémente la fonction virtuelle schedule() pour pouvoir définir l'heure de base, si elle n'a pas été définie par l'utilisateur.

Si une heure de base n'a pas été définie, l'heure de base sera égale à l'heure actuelle.
