Description détaillée

La classe SoMFFloat est un conteneur pour des valeurs en virgule flottante.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker un groupe de plusieurs valeurs en virgule flottante.

Ce champ prend en charge le partage de données d'application via une méthode setValuesPointer(). Voir la documentation de SoMField pour plus d'informations sur l'utilisation de cette fonction.
