Description détaillée

SoElement est la classe de base abstraite pour tous les éléments.

Ceci est la classe de base pour toutes les classes d'éléments dans Coin.

void SoElement::push (SoState * state) [virtual]

This method is called every time a new element is required in one of the stacks. This happens when a writable element is requested, using SoState::getElement() or indirectly SoElement::getElement(), and the depth of the current element is less than the state depth.

Override this method if your element needs to copy data from the previous top of stack. The push() method is called on the new element, and the previous element can be found using SoElement::getNextInStack().

void SoElement::pop (SoState * state, const SoElement * prevTopElement) [virtual]

This method is called when the state is popped, and the depth of the element is bigger than the current state depth. pop() is called on the new top of stack, and a pointer to the previous top of stack is passed in prevTopElement.

Override this method if you need to copy some state information from the previous top of stack.

void SoElement::push (SoState * state) [virtual]

Cette méthode est appelée à chaque fois qu'un nouvel élément est requis dans l'une des piles. Cela se produit lorsqu'un élément inscriptible est demandé, en utilisant SoState::getElement() ou indirectement SoElement::getElement(), et que la profondeur de l'élément courant est inférieure à la profondeur de l'état.

Remplacez cette méthode si votre élément doit copier des données de l'élément précédent au sommet de la pile. La méthode push() est appelée sur le nouvel élément, et l'élément précédent peut être trouvé en utilisant SoElement::getNextInStack().

void SoElement::pop (SoState * state, const SoElement * prevTopElement) [virtual]

Cette méthode est appelée lorsque l'état est dépilé, et que la profondeur de l'élément est supérieure à la profondeur de l'état courant. pop() est appelée sur le nouvel élément au sommet de la pile, et un pointeur vers l'élément précédent au sommet de la pile est passé dans prevTopElement.

Remplacez cette méthode si vous avez besoin de copier certaines informations d'état de l'élément précédent au sommet de la pile.

const SoElement * SoElement::getConstElement (SoState *const state, const int stackIndex) const [inline], [static], [protected]

This method returns a reference to the top element of the class with stack index stackIndex. The returned element is non-mutable.

(Don't try to be clever and cast away the constness -- if the returned instance is modified, strange, hard to find and generally wonderful bugs will most likely start to happen.)

If no instance can be returned, NULL is returned.
