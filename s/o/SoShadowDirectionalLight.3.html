Description Détaillée

La classe SoShadowDirectionalLight est un nœud pour la mise en place d'une lumière directionnelle qui projette des ombres.

Les lumières directionnelles affectent généralement tout, mais comme il n'est pas toujours possible d'utiliser une seule carte d'ombre pour l'ensemble du graphe de scène. Ce nœud possède des fonctionnalités supplémentaires pour contourner ce problème.

Il calcule l'intersection entre le volume de vue actuel et soit la boîte englobante de la scène, soit la boîte englobante fournie dans ce nœud. Les ombres ne sont calculées que pour ce volume. Cela signifie que vous obtiendrez des ombres plus détaillées lorsque vous zoomez sur des éléments du graphe de scène.

De plus, vous pouvez définir la distance maximale à partir de la caméra qui sera ombrée. Considérez ceci comme un nouveau plan lointain pour la caméra qui n'affecte que les ombres.

Comme avec SoShadowSpotLight, il est possible d'optimiser davantage en définissant votre propre graphe de scène émetteur d'ombres dans le champ shadowMapScene.

Le graphe de scène d'exemple ci-dessous démontre comment vous pouvez utiliser ce nœud pour créer des ombres sur un grand nombre d'objets, tout en obtenant une précision décente lors du zoom. Pour réduire davantage le volume couvert par la carte d'ombre, vous pouvez définir maxShadowDistance sur une valeur > 0. C'est la distance à partir de la caméra où les ombres seront visibles.

DirectionalLight {
   direction 0 0 -1
   intensity 0.2
}
ShadowGroup {
  quality 1 # pour obtenir un éclairage par pixel
  precision 1
  ShadowDirectionalLight {
    direction 1 1 -1
    intensity 0.8
    # activer ceci pour réduire la distance de vue des ombres
    # maxShadowDistance 200
  }
  # 900 cubes espacés sur une assez grande zone
  Array {
    origin CENTER
    numElements1 30
    numElements2 30
    numElements3 1
    separation1 20 0 0
    separation2 0 20 0
    separation3 0 0 0
    Material { diffuseColor 1 0 0 specularColor 1 1 1 }
    Cube { width 4 height 4 depth 4 }
  }
  # un échiquier
  Coordinate3 { point [ -400 -400 -3, 400 -400 -3, 400 400 -3, -400 400 -3 ] }
  Material { specularColor 1 1 1 shininess 0.9 }
  Complexity { textureQuality 0.1 }
  Texture2 { image 2 2 3 0xffffff 0x225588 0x225588 0xffffff }
  Texture2Transform { scaleFactor 20 20 }
  FaceSet { numVertices 4 }
}
