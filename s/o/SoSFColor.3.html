Description Détaillée

La classe SoSFColor est un conteneur pour une valeur SbColor.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker une seule valeur de couleur (c'est-à-dire Rouge + Vert + Bleu).

Les champs de ce type stockent leur valeur dans un fichier sous forme de triple composant "R G B", où chaque composant de couleur est compris entre 0,0 et 1,0.
