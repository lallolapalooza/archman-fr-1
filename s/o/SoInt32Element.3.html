Description détaillée

La classe SoInt32Element est la classe de base pour les éléments qui stockent simplement un entier de 32 bits.

C'est la superclasse des éléments où les nouvelles données d'élément *remplacent* les anciennes données, et où les données que l'élément stocke sont une simple valeur entière de 32 bits.

Cet élément est comme une version légère et pratique de SoReplacedElement. Il diffère de SoReplacedElement dans le fait que les méthodes set() et get() sont déjà implémentées, puisqu'il est connu que les sous-classes contiendront toujours une seule valeur entière de 32 bits.
