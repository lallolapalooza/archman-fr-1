Description détaillée

Ce noeud permet de spécifier un shader de géométrie pour l'OpenGL.

Il est particulièrement utile pour la génération de primitives géométriques à la volée, en transformant les primitives d'entrée (par exemple, des lignes ou des triangles) en différentes primitives de sortie (par exemple, des triangles, des lignes ou des points).

Ce noeud hérite de la classe SoShaderObject, elle fournit donc des fonctionnalités pour gérer le code source du shader, les uniformes, les attributs, etc.

Pour activer ce shader, il doit être ajouté à un objet SoShaderProgram.

Les propriétés spécifiques aux shaders de géométrie sont :

  • inputType : Définit le type de primitives géométriques en entrée du shader.
  • outputType : Définit le type de primitives géométriques générées par le shader.
  • maxEmit : Spécifie le nombre maximum de sommets que le shader peut émettre.

Le code source du shader doit être chargé via le champ «source« de la classe parente SoShaderObject. Le langage utilisé est généralement GLSL (OpenGL Shading Language).

Voici un exemple simplifié de la structure d'un shader de géométrie en GLSL:

#version 150

// Déclarer le type d'entrée et de sortie
layout(triangles) in;
layout(triangle_strip, max_vertices = 4) out;

uniform mat4 modelViewProjectionMatrix;

void main() {
    // Émettre des sommets pour former une primitive de sortie
    gl_Position = gl_PositionIn[0] * modelViewProjectionMatrix;
    EmitVertex();

    gl_Position = gl_PositionIn[1] * modelViewProjectionMatrix;
    EmitVertex();

    gl_Position = gl_PositionIn[2] * modelViewProjectionMatrix;
    EmitVertex();

    EndPrimitive();
}

Dans cet exemple :

  • layout(triangles) in;
    définit que le shader reçoit des triangles en entrée.
  • layout(triangle_strip, max_vertices = 4) out;
    définit que le shader génère une bande de triangles et que chaque appel au shader peut émettre au maximum 4 sommets.
  • gl_PositionIn
    est une variable intégrée contenant les positions des sommets d'entrée.
  • EmitVertex()
    envoie un sommet à la primitive de sortie.
  • EndPrimitive()
    termine la primitive de sortie courante.

Ce noeud est utile pour des effets graphiques avancés, tels que la génération de géométrie procédurale, la création de stéréoscopie, ou la décomposition de primitives complexes.

Il est également possible de surcharger la méthode «generateGeometry« pour générer des primitives géométriques à la volée.

Réimplémenté de SoShaderObject.

SbBool SoGeometryShader::isSupported (SourceType sourceType) [static]

Retourne une valeur booléenne indiquant si le type de source demandé est supporté par le pilote OpenGL ou non.

Attention : Pour obtenir une réponse correcte, un contexte OpenGL valide doit être disponible.

Documentation des données membres

SoSFEnum SoGeometryShader::inputType

Le type de géométrie utilisé comme entrée pour le shader. La valeur par défaut est TRIANGLES_IN.

SoSFEnum SoGeometryShader::outputType

Le type de géométrie généré à partir du shader. La valeur par défaut est TRIANGLE_FAN_OUT.

SoSFInt32 SoGeometryShader::maxEmit

Le nombre maximum de sommets émis par le shader. La valeur par défaut est 8. Ceci correspond à l'énumération GL_GEOMETRY_VERTICES_OUT_EXT.
