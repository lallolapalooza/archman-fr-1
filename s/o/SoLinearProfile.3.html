NAME

SoLinearProfile — linear profile node

INTRODUCTION

SoLinearProfile is a node that defines a linear profile for an object.

SYNOPSIS

#include <Inventor/nodes/SoLinearProfile.h>
                         Inherits from SoProfile.
                    
                         All the members of class 
                         SoProfile
                         are inherited, as well as the following members:
                    
                        // Methods inherited
                        public:
                            void                apply(SoState *state)
                        protected:
                            virtual ~SoLinearProfile()
                        private:
                            // Unimplemented

DESCRIPTION

This node defines a linear profile. A linear profile is a profile where the color varies linearly between two points.

The profile is defined by a list of control points. Each control point is a pair of (parameter, value). The parameter is a value between 0 and 1, and the value is the color at that parameter.

The color at any given parameter is interpolated linearly between the two closest control points.

The following methods are available:

  • SoLinearProfile(): Constructor.
  • ~SoLinearProfile(): Destructor.
  • addControlPoint(float parameter, SbColor value): Adds a control point to the profile.
  • removeControlPoint(int index): Removes the control point at the given index.
  • getControlPoint(int index): Returns the control point at the given index.
  • getNumControlPoints(): Returns the number of control points in the profile.

EXAMPLE

                        // Create a new linear profile
                        SoLinearProfile *profile = new SoLinearProfile;

                        // Add some control points
                        profile->addControlPoint(0.0, SbColor(1.0, 0.0, 0.0)); // Red at 0
                        profile->addControlPoint(0.5, SbColor(0.0, 1.0, 0.0)); // Green at 0.5
                        profile->addControlPoint(1.0, SbColor(0.0, 0.0, 1.0)); // Blue at 1

                        // Apply the profile to the current state
                        profile->apply(myState);

NOM

SoLinearProfile(3) — nœud de profil linéaire

INTRODUCTION

SoLinearProfile est un nœud qui définit un profil linéaire pour un objet.

SYNTAXE

#include <Inventor/nodes/SoLinearProfile.h>
                         Hérite de SoProfile.
                    
                         Tous les membres de la classe 
                         SoProfile
                         sont hérités, ainsi que les membres suivants :
                    
                        // Méthodes héritées
                        public:
                            void                apply(SoState *state)
                        protected:
                            virtual ~SoLinearProfile()
                        private:
                            // Non implémenté

DESCRIPTION

Ce nœud définit un profil linéaire. Un profil linéaire est un profil où la couleur varie linéairement entre deux points.

Le profil est défini par une liste de points de contrôle. Chaque point de contrôle est une paire (paramètre, valeur). Le paramètre est une valeur comprise entre 0 et 1, et la valeur est la couleur à ce paramètre.

La couleur à n'importe quel paramètre donné est interpolée linéairement entre les deux points de contrôle les plus proches.

Les méthodes suivantes sont disponibles :

  • SoLinearProfile() : Constructeur.
  • ~SoLinearProfile() : Destructeur.
  • addControlPoint(float parameter, SbColor value) : Ajoute un point de contrôle au profil.
  • removeControlPoint(int index) : Supprime le point de contrôle à l'index donné.
  • getControlPoint(int index) : Retourne le point de contrôle à l'index donné.
  • getNumControlPoints() : Retourne le nombre de points de contrôle dans le profil.

EXEMPLE

                        // Créer un nouveau profil linéaire
                        SoLinearProfile *profile = new SoLinearProfile;

                        // Ajouter quelques points de contrôle
                        profile->addControlPoint(0.0, SbColor(1.0, 0.0, 0.0)); // Rouge à 0
                        profile->addControlPoint(0.5, SbColor(0.0, 1.0, 0.0)); // Vert à 0.5
                        profile->addControlPoint(1.0, SbColor(0.0, 0.0, 1.0)); // Bleu à 1

                        // Appliquer le profil à l'état actuel
                        profile->apply(myState);
