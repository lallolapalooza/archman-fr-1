Description Détaillée

La classe SoDragPointDragger fournit des mécanismes pour déplacer un point dans l'espace 3D.

Voici à quoi ressemble le dragger avec sa géométrie par défaut à l'état inactif :

Ce dragger est pratique à utiliser lorsqu'il est souhaitable que l'utilisateur final interagisse avec des points en les positionnant librement dans l'espace 3D.

Le dragger se compose d'une partie pour le mouvement 2D dans un plan (similaire au SoTranslate2Dragger) et d'une autre partie sur l'axe normal au plan.

Tant que le dragger est inactif (c'est-à-dire que l'utilisateur ne saisit et/ou ne fait pas glisser ses parties), les touches CTRL du clavier peuvent être utilisées pour changer l'orientation de la partie plan 2D et de la partie axe normal, de sorte que la partie axe normal pointe le long d'un des autres axes principaux. Ceci est fait en plaçant le pointeur de la souris sur la géométrie du dragger et en appuyant puis en relâchant une touche CTRL.

Detailed Description


This is a dragger widget that allows the user to manipulate a
    translation vector. When the user picks the dragger (by clicking the mouse
    button down on it), it moves in conjunction with the mouse. When the user
    releases the mouse button, the dragger remains in place.


The dragger is drawn as a sphere with a line extending from the
    center of the sphere to the point where the user is currently dragging the
    mouse. The line indicates the direction and magnitude of the translation.


The dragger has one public field, translation, which is an
    `SoSFVec3f`. This field is continuously updated to contain the current
    translation from the dragger's local origin. The application programmer
    can connect this field to relevant node fields in the scene graph to make
    them follow the dragger.
