Description Détaillée

La classe SoSurroundScale est utilisée pour adapter automatiquement la géométrie afin qu'elle entoure d'autres géométries.

Ce nœud calcule une transformation (une translation et une mise à l'échelle) qui, lors de la traversée du nœud, sera ajoutée à la matrice de modèle actuelle, faisant en sorte qu'un cube par défaut placé directement à droite de ce nœud dans le graphe entoure la géométrie à droite de la branche de conteneur sur laquelle ce nœud se trouve. Le conteneur est spécifié par le champ SoSurroundScale::numNodesUpToContainer.

Lors du calcul de la boîte englobante à entourer, l'action de boîte englobante sera appliquée au nœud conteneur, et les calculs de boîte englobante seront réinitialisés après avoir traversé le nœud spécifié par le champ SoSurroundScale::numNodesUpToReset.

On peut considérer le nœud conteneur comme suit : il existe un chemin depuis le nœud racine jusqu'au nœud SoSurroundScale. Ce chemin contient un certain nombre de nœuds. numNodesUpToContainer est le nombre de nœuds dans le chemin depuis le nœud SoSurroundScale vers le nœud racine. Après avoir compté numNodesUpToContainer depuis le nœud SoSurroundScale, vous aurez atteint le nœud conteneur. Le nœud conteneur est le nœud de départ à partir duquel la boîte englobante est calculée. Tous les nœuds inférieurs au nœud de départ feront partie de la boîte englobante, sauf s'ils sont plus proches du nœud SoSurroundScale que numNodesUpToReset.

Pour s'assurer que le(s) nœud(s) qui doivent être mis à l'échelle par le nœud SoSurroundScale ne font pas partie de la boîte englobante, numNodesUpToReset est utilisé. C'est également le nombre de nœuds en amont du nœud SoSurroundScale vers le nœud racine. La signification de numNodesUpToReset est que les nœuds plus proches du SoSurroundNode que le nœud à la position numNodesUpToReset ne doivent pas être utilisés pour les calculs de boîte englobante.

Voici un exemple complet et autonome qui configure un SoTrackballDragger (connecté à un cube) et utilise un nœud SoSurroundScale pour qu'il s'adapte automatiquement à la taille du cube élevé et le translate d'un décalage sur un côté du cube :

#include <Inventor/Qt/SoQt.h>
#include <Inventor/Qt/viewers/SoQtExaminerViewer.h>
#include <Inventor/draggers/SoTrackballDragger.h>
#include <Inventor/nodes/SoAntiSquish.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/nodes/SoCube.h>
#include <Inventor/nodes/SoSurroundScale.h>
#include <Inventor/nodes/SoRotation.h>
#include <Inventor/nodes/SoTranslation.h>
int
main(int argc, char **argv)
{
  QWidget * window = SoQt::init(argv[0]);
  if (window == NULL) exit(1);
  SoSeparator * root = new SoSeparator;
  root->ref();
  SoSeparator * surroundsep = new SoSeparator;
  root->addChild(surroundsep);
  SoTranslation * translation = new SoTranslation;
  translation->translation = SbVec3f(12, 0, 0);
  surroundsep->addChild(translation);
  SoSurroundScale * ss = new SoSurroundScale;
  ss->numNodesUpToReset = 1;
  ss->numNodesUpToContainer = 2;
  surroundsep->addChild(ss);
  SoAntiSquish * antisquish = new SoAntiSquish;
  antisquish->sizing = SoAntiSquish::BIGGEST_DIMENSION;
  surroundsep->addChild(antisquish);
  SoTrackballDragger * dragger = new SoTrackballDragger;
  surroundsep->addChild(dragger);
  SoRotation * rotation = new SoRotation;
  rotation->rotation.connectFrom(& dragger->rotation);
  root->addChild(rotation);
  SoCube * cube = new SoCube;
  cube->height = 10.0f;
  root->addChild(cube);
  SoQtExaminerViewer * viewer = new SoQtExaminerViewer(window);
  viewer->setSceneGraph(root);
  viewer->setViewing(FALSE);
  viewer->setDecoration(FALSE);
  viewer->show();
  SoQt::show(window);
  SoQt::mainLoop();
  delete viewer;
  root->unref();
  return 0;
}

Il pourrait être plus facile de comprendre comment le nœud SoSurroundScale fonctionne dans l'exemple ci-dessus en regardant le graphe de scène réel :

#Inventor V2.1 ascii
Separator {
   Separator {
      Translation {
         translation 12 0 0
      }
      SurroundScale {
         numNodesUpToContainer 2
         numNodesUpToReset 1
      }
      AntiSquish {
         sizing BIGGEST_DIMENSION
      }
      DEF mydragger TrackballDragger {
      }
   }
   Rotation {
      rotation 0 0 1  0 =
      USE mydragger . rotation
   }
   Cube {
      height 10
   }
}

Ce nœud est utilisé en interne par les manipulateurs pour leur permettre de mettre à l'échelle la géométrie du dragger afin qu'elle corresponde à la géométrie du graphe de scène qu'il modifie, comme démontré ci-dessus (mais en dehors du contexte d'un manipulateur).

Il est également généralement utile pour les programmeurs d'applications qui souhaitent qu'une pièce de géométrie spécifique entoure d'autres géométries d'une étendue inconnue ou changeante.

Les nœuds SoSurroundScale dans le graphe de scène sont souvent associés à des nœuds SoAntiSquish pour obtenir une mise à l'échelle uniforme le long des trois axes principaux, comme cela a également été fait dans l'exemple ci-dessus.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

SurroundScale {
    numNodesUpToContainer 0
    numNodesUpToReset 0
}
