Descripción Detallada

La clase SoRotationXYZ es un tipo de nodo para especificar la rotación alrededor de un eje particular.

Los desarrolladores de aplicaciones pueden usar nodos de este tipo en lugar de los nodos SoRotation para simplicidad y claridad si la rotación ocurre solo alrededor de un eje particular.

Los nodos SoRotationXYZ también son más simples y eficientes que los nodos SoRotation cuando se conectan a ángulos de rotación para propósitos de animación.

Détails de description

Ce nœud est un nœud de transformation qui spécifie une rotation autour d'un des trois axes X, Y ou Z.

Il utilise un champ SoSFEnum pour spécifier l'axe et un champ SoSFFloat pour spécifier l'angle de rotation.

La rotation est spécifiée en utilisant la convention de la main droite, où un angle positif fait tourner dans le sens antihoraire autour de l'axe spécifié.

Utilisez ce nœud lorsque vous souhaitez appliquer une rotation autour d'un axe spécifique (X, Y ou Z) dans votre scène 3D.

Documentation d'énumération des membres

L'énumération SoRotationXYZType définit les axes possibles pour la rotation :

SoRotationXYZ::X
Rotation autour de l'axe X.
SoRotationXYZ::Y
Rotation autour de l'axe Y.
SoRotationXYZ::Z
Rotation autour de l'axe Z.
