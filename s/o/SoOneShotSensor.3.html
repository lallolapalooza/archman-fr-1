Description Détaillée

La classe SoOneShotSensor est un capteur qui se déclenchera une seule fois.

Étant donné que SoOneShotSensor est une sous-classe de SoDelayQueueSensor, elle se déclenchera dès que le système d'exécution sera inactif, ou si le système est continuellement occupé, elle se déclenchera dans un délai fixe (par défaut 1/12ème de seconde, voir SoSensorManager::setDelaySensorTimeout()).
