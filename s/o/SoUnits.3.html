Description détaillée

La classe SoUnits est un nœud pour définir les types d'unités.

Bien que Coin ne se soucie pas des unités que vous utilisez dans votre graphe de scène en soi, il y a un avantage à utiliser des nœuds SoUnits : vous avez un moyen de diviser votre graphe de scène en différentes parties « conceptuelles ».

Lorsqu'ils rencontrent des nœuds SoUnit, les méthodes d'action de parcours s'assurent que la géométrie suivante est mise à l'échelle en conséquence.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT:

Units {
    units METERS
}

Detailed Description

¶

This node is used to set the unit system for subsequent geometry nodes. Any geometry node which is rendered after this node will use the unit system defined by this node. This is useful for making sure that geometry is displayed with the correct scale.

The unit system is specified using the units field.

SoUnits is a scene graph node that affects the rendering and picking of geometry by defining the units of measurement for the scene. It acts as a state-setting node, influencing subsequent nodes in the scene graph traversal until another SoUnits node is encountered or the traversal ends.
