Description détaillée

La classe SoSFBox3d est un conteneur pour un vecteur SbBox3d.

Ce champ est utilisé là où les nœuds, les moteurs ou d'autres conteneurs de champs ont besoin de stocker une boîte.

Vous devez noter que cette classe est une extension de Coin, et n'est pas disponible dans l'API originale SGI Open Inventor v2.1.

Depuis
Coin 2.5
