void SoBoundingBoxCache::setHasLinesOrPoints (SoState * state) [static]

Définit le drapeau retourné par SoBoundingBoxCache::hasLinesOrPoints() à TRUE pour tous les caches de boîte englobante ouverts.

La raison pour laquelle les caches de boîte englobante conservent un drapeau lignes ou points est d'indiquer aux programmes clients si les formes qu'ils contiennent comportent l'une de ces primitives - ou sont rendues avec ces primitives. La raison pour laquelle il est important de le savoir pour le code client est qu'il pourrait avoir besoin d'ajouter une marge "epsilon" à la boîte englobante calculée pour compenser les effets d'anti-aliasing dans le rendu, par exemple.

Cette méthode est une méthode statique de la classe. Lorsqu'elle est appelée, elle parcourt la pile d'état et définit le drapeau pour toutes les instances ouvertes de SoBoundingBoxCache dans les nœuds de type SoShape utilisant des lignes ou des points.
