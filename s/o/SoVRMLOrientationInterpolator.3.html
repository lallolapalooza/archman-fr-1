Description Détaillée

La classe SoVRMLOrientationInterpolator est utilisée pour interpoler des orientations.

La documentation détaillée de la classe est tirée verbatim de la norme VRML97 (ISO/IEC 14772-1:1997). Elle est la propriété du Web3D Consortium, et est utilisée avec la permission du Consortium :

OrientationInterpolator {
  eventIn      SFFloat    set_fraction      # (-,)
  exposedField MFFloat    key           []  # (-,)
  exposedField MFRotation keyValue      []  # [-1,1],(-,)
  eventOut     SFRotation value_changed
}

Le nœud OrientationInterpolator interpole entre une liste de valeurs d'orientation spécifiées dans le champ keyValue. Ces rotations sont absolues dans l'espace objet et donc non cumulatives. Le champ keyValue doit contenir exactement autant de rotations que le champ key contient de keyframes. Une orientation représente la position finale d'un objet après l'application d'une rotation. Un OrientationInterpolator interpole entre deux orientations en calculant le chemin le plus court sur la sphère unitaire entre les deux orientations. L'interpolation est linéaire en longueur d'arc le long de ce chemin. Les résultats sont indéfinis si les deux orientations sont diamétralement opposées. Si deux valeurs keyValue consécutives existent telles que la longueur d'arc entre elles est supérieure à $\pi$, l'interpolation se fera sur le complément d'arc. Par exemple, l'interpolation entre les orientations (0, 1, 0, 0) et (0, 1, 0, 5.0) est équivalente à la rotation entre les orientations (0, 1, 0, 2) et (0, 1, 0, 5.0). Une discussion plus détaillée des interpolateurs est contenue dans la section 4.6.8, Nœuds Interpolator (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.8).
