Description Détaillée

La classe SoAntiSquish est utilisée pour réinitialiser à une mise à l'échelle uniforme.

Lors de sa traversée, ce nœud remplace le vecteur d'échelle de la matrice par des valeurs uniformes, basées sur l'une des stratégies de SoAntiSquish::Sizing.

Ce nœud est utilisé par exemple par les manipulateurs pour conserver la forme de leurs géométries de glisser-déposer lorsqu'elles sont configurées dans l'influence d'un nœud SoSurroundScale (qui peut produire des vecteurs d'échelle non uniformes dans la matrice de transformation d'état actuel).

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

AntiSquish {
    recalcAlways TRUE
    sizing AVERAGE_DIMENSION
}

Voir aussi

SoSurroundScale pour un exemple d'utilisation.

Documentation des Énumérations de Membres

enum SoAntiSquish::Sizing

Différentes stratégies pour "décompresser" une mise à l'échelle non uniforme. Les valeurs sont utilisées par le champ SoAntiSquish::sizing.

Énumérateur

X
Le facteur d'échelle de l'axe X est utilisé.
Y
Le facteur d'échelle de l'axe Y est utilisé.
Z
Le facteur d'échelle de l'axe Z est utilisé.
AVERAGE_DIMENSION
La valeur moyenne des facteurs d'échelle est utilisée.
BIGGEST_DIMENSION
Le plus grand de tous les facteurs d'échelle est utilisé.
SMALLEST_DIMENSION
Le plus petit de tous les facteurs d'échelle est utilisé.
LONGEST_DIAGONAL
Un cube unité est transformé par la matrice de transformation d'état actuelle. Le facteur d'échelle est défini sur la valeur de sa diagonale la plus longue.

Detailed Description

This node is used to counteract the effect of scaling transformations. When a scene graph is scaled, its geometry might appear squished along one or more axes. This node automatically applies an inverse scaling transformation to the scene graph to undo the squishing effect.

The unsquishing transformation is computed based on the average of the scaling factors of the transformation matrix. The sizing field controls how the unsquishing is performed. The recalcAlways field controls whether the unsquishing parameters are recalculated automatically for each traversal.

Member Enumeration Documentation

enum
Sizing { AVERAGE_DIMENSION, MAX_DIMENSION, MIN_DIMENSION }

This enumeration defines the strategies for calculating the unsquishing transformation.

AVERAGE_DIMENSION
Unsquishes based on the average of the scaling factors.
MAX_DIMENSION
Unsquishes based on the maximum scaling factor.
MIN_DIMENSION
Unsquishes based on the minimum scaling factor.

Member Data Documentation

SoSFEnum SoAntiSquish::sizing

The current "unsquish" strategy. Default value is SoAntiSquish::AVERAGE_DIMENSION.

SoSFBool SoAntiSquish::recalcAlways

Whether to automatically have the unsquishing parameters recalculated for every traversal. Default value is TRUE.

You can set this to FALSE and manually invoke SoAntiSquish::recalc() if you need closer control of the geometry influenced by this node.
