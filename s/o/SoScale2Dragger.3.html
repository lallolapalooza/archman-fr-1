Detailed Description

This class implements a 2D scale dragger. That is, it is a dragger that responds to mouse events by scaling the scene graph along the X and Y axes. It is represented by a small widget in the scene and works much like the standard scale dragger, except that it only operates in 2D.

Note that draggers are not reference counted. They are automatically destroyed when their reference count goes to 0.
