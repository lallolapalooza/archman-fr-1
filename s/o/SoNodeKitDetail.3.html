Description détaillée

La classe SoNodeKitDetail n'est pas encore documentée.

Lors de l'exécution d'une action de sélection et d'une collision avec un kit de nœuds, le kit de nœuds génère un objet SoNodeKitDetail qui contient des informations sur la partie spécifique du kit de nœuds touchée par le rayon de sélection.

NOM

SoNodeKitDetail - Classe de détail pour les kits de nœuds.

SYNTAXE

#include <Inventor/details/SoNodeKitDetail.h>

Classe héritée de SoDetail.

DESCRIPTION

La classe SoNodeKitDetail est une classe de détail utilisée par les kits de nœuds dans le toolkit Open Inventor. Elle fournit des informations spécifiques sur un détail au sein d'une hiérarchie de kits de nœuds.

Cette classe est généralement utilisée en interne par Open Inventor pour gérer les interactions et la sélection dans des scènes construites à l'aide de kits de nœuds.
