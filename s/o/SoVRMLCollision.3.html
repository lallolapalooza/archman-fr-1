Description détaillée

La classe SoVRMLCollision est utilisée pour la détection de collisions avec l'avatar.

La documentation détaillée de la classe est extraite verbatim de la norme VRML97 (ISO/IEC 14772-1:1997). Elle est protégée par copyright par The Web3D Consortium, et est utilisée avec la permission du Consortium :

Collision {
  eventIn      MFNode   addChildren
  eventIn      MFNode   removeChildren
  exposedField MFNode   children        []
  exposedField SFBool   collide         TRUE
  field        SFVec3f  bboxCenter      0 0 0      # (-,)
  field        SFVec3f  bboxSize        -1 -1 -1   # (0,) ou -1,-1,-1
  field        SFNode   proxy           NULL
  eventOut     SFTime   collideTime
}

Le nœud Collision est un nœud de groupement qui spécifie les propriétés de détection de collision pour ses enfants (et leurs descendants), spécifie des objets substituts qui remplacent ses enfants lors de la détection de collision, et envoie des événements signalant qu'une collision s'est produite entre l'avatar et la géométrie du nœud Collision ou son substitut. Par défaut, tous les nœuds géométriques de la scène sont susceptibles de collision avec le spectateur, à l'exception de IndexedLineSet, PointSet et Text. Les navigateurs doivent détecter les collisions géométriques entre l'avatar (voir SoVRMLNavigationInfo) et la géométrie de la scène et empêcher l'avatar de 'pénétrer' dans la géométrie. Voir 4.13.4, Détection de collision et suivi du terrain (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.13.4), pour des informations générales sur la détection de collision.

S'il n'y a pas de nœuds Collision spécifiés dans un fichier VRML, les navigateurs doivent détecter les collisions entre l'avatar et tous les objets pendant la navigation.

La sous-clause 4.6.5, Nœuds de groupement et enfants (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.5), contient une description des champs et événements d'entrée children, addChildren et removeChildren.

Le champ collide du nœud Collision active et désactive la détection de collision. Si collide est défini sur FALSE, les enfants ne seront pas susceptibles de collision pendant la navigation.

SYNTAXE

Description détaillée

Le nœud de collision SoVRMLCollision contient un nœud de collision qui n'est pas examiné pour la collision, même s'il est dessiné. Cela inclut tout nœud de collision descendant qui a le champ collide réglé sur TRUE (c'est-à-dire, régler collide sur FALSE désactive la collision pour chaque nœud descendant).
