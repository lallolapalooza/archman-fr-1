SoVectorizeAction est la classe de base pour la vectorisation de graphiques de scène Coin. SoVectorizeAction parcourt le graphique de scène et convertit toute la géométrie prise en charge en données vectorisées. Les sous-classes peuvent ensuite utiliser ces données pour produire des fichiers vectorisés dans différents formats. Géométrie actuellement prise en charge : - Triangles (les polygones seront tessellés) - Segments de ligne - Points (peuvent être rendus comme des cercles ou des carrés) - Texte 2D - Texte 3D (sera converti en triangles) - Images (depuis les nœuds SoImage) La géométrie sera rendue selon le modèle d'éclairage d'OpenGL, de sorte que les lumières et les matériaux affecteront la géométrie de manière similaire à un visualiseur Coin standard. Note : la transparence ou le mappage de textures ne sont pas encore pris en charge. Since Coin 2.1 TGS fournit la prise en charge de la copie de fichiers en tant qu'extension distincte pour TGS Inventor.

Detailed Description

This class is an abstract base class for vectorization actions. A vectorization action traverses a scene graph and converts the visited nodes into vector graphics data. The actual vector graphics format is determined by the specific subclass of SoVectorizeAction that is used.

This class defines the common interface for all vectorization actions, including methods for enabling/disabling lighting, converting pixel units to world units, and printing the header, footer, background, and individual items of the vector graphics output.

Subclasses of SoVectorizeAction must implement the pure virtual methods printHeader(), printItem(), and provide implementations for printFooter(), printBackground(), and printViewport() as needed.

The SoVectorizeAction class also provides methods for accessing the BSP tree used for storing triangle and line vertices, and for retrieving the rotated viewport start position and size.

Description détaillée

Cette classe est une classe de base abstraite pour les actions de vectorisation. Une action de vectorisation parcourt un graphe de scène et convertit les nœuds visités en données graphiques vectorielles. Le format graphique vectoriel réel est déterminé par la sous-classe spécifique de SoVectorizeAction qui est utilisée.

Cette classe définit l'interface commune pour toutes les actions de vectorisation, y compris les méthodes pour activer/désactiver l'éclairage, convertir les unités de pixels en unités mondiales, et imprimer l'en-tête, le pied de page, l'arrière-plan, et les éléments individuels de la sortie graphique vectorielle.

Les sous-classes de SoVectorizeAction doivent implémenter les méthodes virtuelles pures printHeader(), printItem(), et fournir des implémentations pour printFooter(), printBackground(), et printViewport() au besoin.

La classe SoVectorizeAction fournit également des méthodes pour accéder à l'arbre BSP utilisé pour stocker les sommets de triangles et de lignes, et pour récupérer la position de départ et la taille du viewport rotatif.
