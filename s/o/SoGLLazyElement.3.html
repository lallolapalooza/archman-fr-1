Description Détaillée

La classe SoGLLazyElement est conçue pour optimiser le rendu GL.

Ceci est simplement une implémentation d'encapsulation pour la compatibilité. Elle devrait (espérons-le) fonctionner de la même manière que la classe Inventor.

void SoGLLazyElement::push (SoState * state) [virtuel]

Cette méthode est appelée chaque fois qu'un nouvel élément est requis dans l'une des piles. Cela se produit lorsqu'un élément accessible en écriture est demandé, en utilisant SoState::getElement() ou indirectement SoElement::getElement(), et que la profondeur de l'élément courant est inférieure à la profondeur de l'état.

Réimplémentez cette méthode si votre élément a besoin de copier des données depuis le sommet précédent de la pile. La méthode push() est appelée sur le nouvel élément, et l'élément précédent peut être trouvé en utilisant SoElement::getNextInStack().

Réimplémenté de SoLazyElement.

void SoGLLazyElement::pop (SoState * state, const SoElement * prevTopElement) [virtuel]

Cette méthode est appelée lorsque l'état est dépilé, et que la profondeur de l'élément est supérieure à la profondeur de l'état courant. pop() est appelé sur le nouveau sommet de la pile, et un pointeur vers le sommet précédent de la pile est passé dans prevTopElement.

Réimplémentez cette méthode si vous avez besoin de copier des informations d'état du sommet précédent de la pile.

Detailed Description

The SoGLLazyElement class is the OpenGL lazy element for caching GL state.

This element caches material state, lighting model parameters, vertex ordering and backface culling settings. The OpenGL state is restored when the element is removed from the state.

The GL state is managed by the SoGLLazyElement::GLState structure.

This element is used by the SoGLRenderAction.
