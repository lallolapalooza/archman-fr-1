Description détaillée

La classe SoIntersectionDetectionAction sert à détecter les primitives qui s'intersectent dans une scène.

Notez que seules les collisions entre la géométrie réelle de la scène sont détectées, donc le contenu de certains nœuds spéciaux tels que SoText2 et SoImage (qui se projettent en graphiques bitmap projetés sur l'écran, et non en polygones réels) ne sera pas pris en compte pour la détection de collisions.

Notez également que la classe SoIntersectionDetectionAction n'est pas un composant haute performance dans Coin. Son utilisation de manière continue sur des graphes de scène complexes est vouée à être un tueur de performance.

Voici un exemple d'utilisation simple pour cette classe. Il a été écrit comme un framework autonome configuré pour le profilage et l'optimisation de SoIntersectionDetectionAction. Il teste l'intersection de toutes les formes les unes avec les autres pour le fichier chargé.

#include <cstdlib>
#include <Inventor/SbTime.h>
#include <Inventor/SoDB.h>
#include <Inventor/SoInteraction.h>
#include <Inventor/collision/SoIntersectionDetectionAction.h>
#include <Inventor/errors/SoDebugError.h>
#include <Inventor/nodekits/SoNodeKit.h>
#include <Inventor/nodes/SoSeparator.h>
static SoIntersectionDetectionAction::Resp
intersectionCB(void * closure,
               const SoIntersectingPrimitive * pr1,
               const SoIntersectingPrimitive * pr2)
{
  (void)fprintf(stdout, "intersection hit!\n");
  return SoIntersectionDetectionAction::NEXT_PRIMITIVE;
}
int
main(int argc, char ** argv)
{
  SoDB::init();
  SoNodeKit::init();
  SoInteraction::init();
  if (argc != 2) {
    (void)fprintf(stderr, "\n\tUsage: testapp <filename.iv>\n\n");
    exit(1);
  }
  SoInput in;
  SbBool ok = in.openFile(argv[1]);
  assert(ok);
  SoSeparator * root = SoDB::readAll(&in);
  assert(root);
  root->ref();
  SoIntersectionDetectionAction ida;
  ida.addIntersectionCallback(intersectionCB, NULL);
  ida.setManipsEnabled(FAL
SE); ida.setDraggersEnabled(FALSE); ida.setIntersectionDetectionEpsilon(10.0f); SbTime starttime = SbTime::getTimeOfDay(); SoDebugError::postInfo("main", "SoIntersectionDetectionAction::apply"); ida.apply(root); SoDebugError::postInfo("main", "apply() done after %f seconds.", (SbTime::getTimeOfDay() - starttime).getValue()); root->unref(); return 0; }

void SoIntersectionDetectionAction::setIntersectionEpsilon (float epsilon) [static]

Définit la valeur epsilon globale de la distance de détection d'intersection.

Ceci fait en sorte que les primitives situées à une distance epsilon soient considérées comme s'intersectant.

Ceci affectera tous les objets d'action de détection d'intersection en cours d'utilisation qui n'ont pas de valeur définie localement.

La valeur epsilon est une valeur dans l'espace monde.

Soyez conscient que l'augmentation de la valeur epsilon peut *augmenter dramatiquement* le nombre de tests d'intersection de primitives effectués pour déterminer les intersections. L'augmentation de la valeur epsilon peut donc provoquer de sérieux ralentissements dans le temps d'exécution des vérifications d'intersection.

void SoIntersectionDetectionAction::setFilterCallback (SoIntersectionFilterCB * cb, void * closure = NULL) [virtual]

Ce callback est appelé lorsque deux formes sont trouvées comme ayant des boîtes englobantes qui s'intersectent, et qu'elles sont sur le point d'être testées pour une intersection réelle entre leurs primitives.

Lorsque des valeurs d'epsilon d'intersection sont utilisées, le test d'intersection des boîtes englobantes est effectué de manière approximative et déclenchera le callback de filtre sur les boîtes qui sont plus éloignées les unes des autres que la longueur epsilon.

Si le callback retourne TRUE, le test d'intersection sera effectué. Si le callback retourne FALSE, le test d'intersection sera ignoré.

L'API n'autorise qu'un seul callback de filtre.

void SoIntersectionDetectionAction::addIntersectionCallback (SoIntersectionCB * cb, void * closure = NULL) [virtual]

Ajoute un callback à appeler lorsque deux primitives qui s'intersectent sont trouvées dans la scène.

Si le callback retourne ABORT, la détection d'intersection est abandonnée. Si le callback retourne NEXT_SHAPE, la détection d'intersection entre ces deux formes est abandonnée et l'action continue de tester d'autres formes. Si le callback retourne NEXT_PRIMITIVE, le test de détection d'intersection continue de tester les autres primitives dans ces deux formes.
