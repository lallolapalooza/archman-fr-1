Description détaillée

La classe SoVectorOutput est utilisée pour définir un fichier de sortie vectoriel.

SoVectorizeAction créera une instance de SoVectorOutput qui écrira sur la sortie standard par défaut. SoVectorizeAction::getOutput() peut être utilisé pour récupérer cette sortie, et l'utilisateur voudra probablement définir un fichier pour la sortie.

Depuis

Coin 2.1

TGS fournit le support HardCopy comme une extension séparée pour TGS Inventor.
