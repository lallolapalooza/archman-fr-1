Détails de la description

La classe SoSFTime contient une valeur de type SbTime.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker une représentation unique du temps.

Un champ de ce type stocke sa valeur dans un fichier sous forme de nombre à virgule flottante.

Voir aussi SoMFTime
