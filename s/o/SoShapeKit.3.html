void SoShapeKit::setDefaultOnNonWritingFields (void ) [protected], [virtual]

(Attention, cette méthode est peu susceptible d'intéresser le programmeur d'application qui ne souhaite pas étendre la bibliothèque avec de nouveaux kits de nœuds ou draggers. Si vous êtes effectivement en train d'écrire des extensions, consultez les informations dans la documentation de la classe SoBaseKit.)

Ceci est une méthode virtuelle, et le code qu'elle contient devrait appeler SoField::setDefault() avec l'argument TRUE sur les champs de pièces qui ne doivent pas être écrits lors des opérations d'exportation de graphiques de scène.

Ceci est généralement fait quand :

1.
la valeur du champ est NULL et la pièce est NULL par défaut
2.
c'est un nœud SoGroup ou SoSeparator terminal sans enfants
3.
c'est une pièce de liste terminale sans enfants et un conteneur SoGroup ou SoSeparator
4.
c'est une pièce non terminale et qu'elle est de type SoGroup et que tous les champs sont à leurs valeurs par défaut

Les sous-classes devraient généralement la redéfinir pour effectuer des paramètres supplémentaires pour les nouveaux champs membres. Depuis la sous-classe, n'oubliez pas d'appeler "vers le haut" la méthode setDefaultOnNonWritingFields() de votre super-classe.
