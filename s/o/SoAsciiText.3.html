Description Détaillée

La classe SoAsciiText rend du texte 3D plat.

Le texte est rendu en utilisant une géométrie de polygones 3D.

La taille de la représentation géométrique textuelle est déterminée à partir du champ SoFont::size d'un nœud SoFont précédent dans le graphe de scène, qui spécifie la taille en coordonnées unité. Cette valeur définit la taille verticale approximative des lettres. La valeur par défaut, si aucun nœud SoFont n'est utilisé, est 10.

La complexité des glyphes est contrôlée par un nœud SoComplexity précédent avec le Type défini sur OBJECT_SPACE. Veuillez noter que la police 3D intégrée par défaut ne sera pas affectée par le nœud SoComplexity.

Ce nœud est différent du nœud SoText2 car il tourne, met à l'échelle, translate, etc., comme les autres géométries de la scène. Il est différent du nœud SoText3 car il rend le texte "plat", c'est-à-dire qu'il n'extrude pas les polices pour leur donner de la profondeur.

Pour avoir une idée intuitive du fonctionnement de SoAsciiText, jetez un œil à ce fichier Inventor d'exemple dans la visionneuse examiner :

#Inventor V2.1 ascii
Separator {
  Font {
    size 10
    name "Arial:Bold Italic"
  }
  BaseColor {
    rgb 1 0 0 #rouge
  }
  AsciiText {
    width [ 0, 1, 50 ]
    justification LEFT #Alignement standard
    string [ "GAUCHE", "GAUCHE", "GAUCHE", "GAUCHE", "GAUCHE GAUCHE" ]
  }
  BaseColor {
    rgb 1 1 0
  }
  Sphere { radius 1.5 }
  Translation {
    translation 0 -50 0
  }
  BaseColor {
    rgb 0 1 0 #vert
  }
  AsciiText {
    width [ 0, 1, 50 ]
    justification RIGHT
    string [ "DROITE", "DROITE", "DROITE", "DROITE", "DROITE DROITE" ]
  }
  BaseColor {
    rgb 0 1 1
  }
  Sphere { radius 1.5 }
  Translation {
    translation 0 -50 0
  }
  BaseColor {
    rgb 0 0 1 #bleu
  }
  AsciiText {
    width [ 0, 1, 50 ]
    justification CENTER
    string [ "CENTRE", "CENTRE", "CENTRE",
"CENTRE", "CENTRE CENTRE" ] } BaseColor { rgb 1 0 1 } Sphere { radius 1.5 } }

Dans examinerviewer, le fichier Inventor ressemble à ceci :

Créera un détail de triangle pour un SoPickedPoint. Cette méthode ne sera appelée qu'en interne, lorsque generatePrimitives() est utilisé pour la sélection (SoShape::rayPick() n'est pas remplacé).

Cette méthode renvoie NULL dans Open Inventor, et les sous-classes devront remplacer cette méthode pour créer des détails pour un SoPickedPoint.

Documentation des données membres

SoMFString SoAsciiText::string

L'ensemble des chaînes à rendre. Chaque chaîne du champ multi-valeur sera rendue sur une ligne distincte.

La valeur par défaut du champ est une seule chaîne vide.

SoSFFloat SoAsciiText::spacing

Espacement vertical entre les lignes de base de deux lignes horizontales consécutives. La valeur par défaut est 1.0, ce qui signifie qu'elle est égale à la taille verticale du caractère le plus haut dans l'alphabet bitmap.

SoSFEnum SoAsciiText::justification

Détermine l'alignement horizontal des chaînes de texte.

Si l'alignement est défini sur SoAsciiText::GAUCHE, le bord gauche de la première chaîne est à l'origine et toutes les chaînes sont alignées sur leurs bords gauches. Si défini sur SoAsciiText::DROITE, le bord droit de la première chaîne est à l'origine et toutes les chaînes sont alignées sur leurs bords droits. Sinon, si défini sur SoAsciiText::CENTRE, le centre de la première chaîne est à l'origine et toutes les chaînes sont alignées sur leurs centres. L'origine est toujours située sur la ligne de base de la première ligne de texte.

La valeur par défaut est SoAsciiText::GAUCHE.

SoMFFloat SoAsciiText::width

Définit la largeur de chaque ligne. Le texte est mis à l'échelle pour être dans les unités spécifiées. La taille des caractères reste la même ; seules les positions X sont mises à l'échelle. Lorsque width <= 0, la valeur de width est ignorée et le texte est rendu normalement. La largeur exacte du texte rendu dépend non seulement du champ width, mais aussi de la largeur maximale des caractères dans la chaîne rendue. La chaîne tentera de rentrer dans la largeur spécifiée, mais si elle ne peut pas le faire, elle utilise le caractère le plus grand de la chaîne comme largeur. Si moins de largeurs sont spécifiées que le nombre de chaînes, les chaînes sans largeurs correspondantes sont rendues avec la largeur par défaut.
