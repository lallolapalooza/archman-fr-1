Description Détaillée

La classe SoVRMLText est utilisée pour représenter du texte dans une scène.

Text { 
  exposedField  MFString string    []
  exposedField  SFNode   fontStyle NULL
  exposedField  MFFloat  length    []      # [0,)
  exposedField  SFFloat  maxExtent 0.0     # [0,)
}

Le nœud Text spécifie un objet de chaîne de texte plat, double face, positionné dans le plan Z=0 du système de coordonnées local en fonction des valeurs définies dans le champ fontStyle (voir SoVRMLFontStyle). Les nœuds Text peuvent contenir plusieurs chaînes de texte spe

cifié à l'aide de l'encodage UTF-8 comme spécifié par ISO 10646-1:1993 (voir <http://www.web3d.org/documents/specifications/14772/V2.0/part1/references.html#[UTF8]>). Les chaînes de texte sont stockées dans l'ordre où les caractères en mode texte doivent être produits, tel que défini par les paramètres du nœud FontStyle.

Les chaînes de texte sont contenues dans le champ `string`. Le champ `fontStyle` contient un nœud FontStyle qui spécifie la taille de la police, la famille et le style de la police, la direction des chaînes de texte, et toute technique de rendu de langue spécifique utilisée pour le texte.

Le champ `maxExtent` limite et compresse toutes les chaînes de texte si la longueur de la chaîne la plus longue est supérieure à l'étendue maximale, mesurée dans le système de coordonnées local. Si la chaîne de texte de longueur maximale est plus courte que `maxExtent`, il n'y a pas de compression. L'étendue maximale est mesurée horizontalement pour le texte horizontal (nœud FontStyle: `horizontal=TRUE`) et verticalement pour le texte vertical (nœud FontStyle: `horizontal=FALSE`). Le champ `maxExtent` doit être supérieur ou égal à zéro.

Le champ `length` contient une valeur MFFloat qui spécifie la longueur de chaque chaîne de texte dans le système de coordonnées local. Si la chaîne est trop courte, elle est étirée (soit en redimensionnant le texte, soit en ajoutant de l'espace entre les caractères). Si la chaîne est trop longue, elle est compressée (soit en redimensionnant le texte, soit en soustrayant de l'espace entre les caractères). Si une valeur de longueur est manquante (par exemple, s'il y a quatre chaînes mais seulement trois valeurs de longueur), les valeurs manquantes sont considérées comme étant 0. Le champ `length` doit être supérieur ou égal à zéro.

Spécifier une valeur de 0 pour les champs `maxExtent` et `length` indique que la chaîne peut avoir n'importe quelle longueur.

void SoVRMLText::computeBBox (SoAction * action, SbBox3f & box, SbVec3f & center) [protégé], [virtuel]

Implémenté par les sous-classes de SoShape pour informer la super-classe SoShape de la taille exacte et du centre de masse de la boîte englobante de la forme.

La boîte englobante et le point central doivent être calculés et renvoyés dans le système de coordonnées local.

La méthode implémente le comportement d'action pour les nœuds de forme pour SoGetBoundingBoxAction. Elle est invoquée depuis SoShape::getBoundingBox(). (Les sous-classes ne devraient pas redéfinir SoNode::getBoundingBox().)

Le paramètre box passé est garanti d'être une boîte vide, tandis que center est indéfini à l'entrée de la fonction.
