Description Détaillée

La classe SoVertexAttributeBinding est un nœud pour configurer la manière dont les attributs de sommet sont mappés aux formes.

Voir aussi

SoVertexAttribute

La liaison de matériau spécifiée dans les nœuds de ce type décide comment les valeurs des attributs de sommet des nœuds SoVertexAttribute sont mappées sur les nœuds de forme géométrique intégrés.

Voici un exemple d'utilisation simple :

#Inventor V2.1 ascii
ShaderProgram {
  shaderObject [
    VertexShader {
      sourceProgram "vertex.glsl"
    }
  ]
}
Coordinate3 {
  point [ 0 0 0, 1 0 0, 1 1 0 ]
}
VertexAttributeBinding { value OVERALL }
VertexAttribute {
  typeName "SoMFVec3f"
  name "color"
  values [ 1.0 0.0 0.0 ]
}
IndexedFaceSet {
  coordIndex [ 0, 1, 2, -1 ]
}

Le shader de sommet (vertex.glsl) :

attribute vec3 color;
void main(void)
{
  gl_Position = ftransform();
  fragcolor = color;
}

Avec SoVertexAttributeBinding::value défini sur PER_VERTEX_INDEXED ci-dessus, les indices d'attributs seront pris du champ SoIndexedFaceSet::coordIndex lors du rendu.

Si SoVertexAttributeBinding::value est défini sur PER_VERTEX, les attributs seront récupérés de manière monotone croissante à partir du champ SoVertexAttribute::value, en commençant à l'indice 0.

Si SoVertexAttributeBinding::value est défini sur OVERALL, la première valeur d'attribut de SoVertexAttribute::value sera envoyée à OpenGL avant le rendu.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

VertexAttributeBinding {
    value PER_VERTEX_INDEXED
}

Documentation de l'énumération des membres

enum SoVertexAttributeBinding::Binding

Énumération des types de liaisons de matériaux disponibles.

Énumérateur

OVERALL
Appliquer le même matériau à la forme complète.
PER_VERTEX
Obtenir un nouveau matériau du pool de valeurs de matériaux pour chaque polygone, ligne ou sommet de point de la forme.

Les attributs sont récupérés à partir de l'indice 0 et suivants, en incrémentant l'indice dans le pool d'attributs de 1 pour chaque nouveau sommet du nœud de forme.

PER_VERTEX_INDEXED
Obtenir un nouvel attribut du pool de valeurs d'attributs pour chaque polygone, ligne ou sommet de point de la forme.

Les attributs sont récupérés par les valeurs d'indice de la forme.

NAME

SoVertexAttributeBinding - node for controlling how vertex attributes are bound to geometry

SYNOPSIS

Nodes

SoVertexAttributeBinding

Fields

Enumerations

SoVertexAttributeBinding::Value { PER_VERTEX_INDEXED, PER_VERTEX, PER_LINE, PER_TRIANGLE, PER_TRIANGLE_STRIP, ALL }

Inheritance

SoNode > SoVertexAttributeBinding

Detailed Description

This node is used to control how vertex attributes are bound to geometry. For example, if you have a color array and you want it to apply to each vertex individually, you would use SoVertexAttributeBinding::PER_VERTEX. If you want the same color for an entire primitive (e.g., a triangle), you would use SoVertexAttributeBinding::PER_TRIANGLE.

The binding applies to subsequent geometry nodes in the scene graph.

Member Enumeration Documentation

Value

This enumeration defines the different ways vertex attributes can be bound to geometry.

PER_VERTEX_INDEXED
Vertex attributes are bound per vertex, using an index. This is the default.
PER_VERTEX
Vertex attributes are bound per vertex.
PER_LINE
Vertex attributes are bound per line segment.
PER_TRIANGLE
Vertex attributes are bound per triangle.
PER_TRIANGLE_STRIP
Vertex attributes are bound per triangle strip.
ALL
All vertex attributes are bound to the entire geometry.
