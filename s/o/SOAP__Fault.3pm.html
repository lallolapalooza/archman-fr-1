SOAP::Fault(3) Documentation Perl fournie par l'utilisateur SOAP::Fault(3)

NOM

SOAP::Fault - encapsule les erreurs SOAP avant leur sérialisation ou après leur désérialisation

DESCRIPTION

Cette classe encapsule les erreurs SOAP avant leur sérialisation ou après leur désérialisation. Les méthodes disponibles sont un constructeur et quatre accesseurs. Chaque accesseur crée un objet à la demande, tout comme les autres classes, lorsqu'il est appelé comme méthode statique. Comme les autres accesseurs du package SOAP::Lite, ils retournent l'objet lui-même lors de la définition de l'attribut.

GÉNÉRER UNE ERREUR SOAP

Pour générer une erreur SOAP, il suffit d'émettre une commande Perl `die` du côté serveur, comme vous le feriez normalement. Le processeur SOAP interceptera la commande `die` et renverra une erreur SOAP, en utilisant la chaîne passée à la commande `die` comme chaîne d'erreur (`faultstring`), au client qui effectue l'appel. Si vous avez besoin de plus de contrôle sur l'erreur SOAP renvoyée au client, passez simplement un objet SOAP::Fault à la commande `die` et le processeur SOAP se comportera en conséquence. Par exemple :

die SOAP::Fault->faultcode('Server.Custom') # sera qualifié
               ->faultstring('Morte dans la méthode serveur')
               ->faultdetail(bless {code => 1} => 'BadError')
               ->faultactor('http://www.soaplite.com/custom');

MÉTHODES

new(optionnel données)
$fault = SOAP::Fault->new(faultcode => 'Server');

Crée explicitement un nouvel objet SOAP::Fault. N'importe lequel des quatre attributs représentés ci-après par des méthodes accesseurs peut être passé dans la liste d'arguments avec des valeurs suivant immédiatement leur nom d'attribut.

faultcode(optionnel valeur)
$fault->faultcode('MethodUnknown');

Retourne le code d'erreur actuel ou le définit si une valeur est fournie.

faultstring(optionnel valeur)
$fault->faultstring("Il n'y a pas de $method ici");

Retourne ou définit la chaîne d'erreur.

faultactor(optionnel valeur)
$fault->faultcode($header->actor);

Retourne ou définit l'élément fault-actor. Notez que l'acteur n'est pas toujours requis dans une erreur SOAP.

faultdetail(optionnel valeur)
$fault->faultcode(bless { proxy => $ip }, 'Err');

Retourne ou définit l'élément de détail de l'erreur. Comme l'acteur, ce n'est pas toujours un élément requis. Notez que le contenu du détail de l'erreur dans un message est représenté par des blocs de balises. Ainsi, les valeurs passées à cet accesseur lors de la définition de la valeur sont soit des objets SOAP::Data, soit des références de hachage bénies plus générales.

En plus de ces méthodes, le package SOAP::Fault fournit également `detail` comme alias pour `faultdetail`. Le premier est le nom réel de l'élément avec les erreurs SOAP, mais le nom second est moins ambigu lorsqu'il est considéré avec le reste du package SOAP::Lite. Les objets de cette classe ont également une chaîne de caractères spéciale activée. Si un objet est imprimé ou autrement converti en chaîne, la valeur produite est `faultcode: faultstring`, avec les valeurs des attributs de l'objet.

VOIR AUSSI

SOAP::Data, SOAP::Header, SOAP::SOM
