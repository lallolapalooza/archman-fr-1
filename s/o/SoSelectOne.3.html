Description détaillée

La classe SoSelectOne est utilisée pour sélectionner une valeur parmi un ensemble de valeurs.

Le champ de sortie sera la valeur d'index th du champ d'entrée multivalue.

Note : Ce moteur de sortie diffère légèrement du mécanisme de sortie standard de la plupart des classes de moteur : SoSelectOne::output n'est pas une instance permanente de SoEngineOutput, mais un *pointeur* vers une instance de SoEngineOutput. La raison en est qu'il est nécessaire d'allouer dynamiquement le champ de sortie pour qu'il corresponde à ce à quoi SoSelectOne::input est connecté, car le type de SoSelectOne::output doit toujours être le même que le type de SoSelectOne::input.

Le format de fichier pour ce champ est un peu spécial. Notez la spécification de type qui se trouve au début, qui n'est pas nécessaire pour les types de champs les plus courants :

SelectOne {
  type <multivaluefieldtype>
  [...champs...]
}

Documentation données membre

SoSFInt32 SoSelectOne::index

Index de la valeur du champ d'entrée qui sera placée dans le champ de sortie.

SoMField* SoSelectOne::input

Champ d'entrée multivalue dont nous sélectionnons une seule valeur pour notre sortie.

SoEngineOutput* SoSelectOne::output

C'est le champ de sortie unique qui contient la valeur d'index th de SoSelectOne::input.

Le type du champ s'ajustera naturellement au type du champ d'entrée, c'est-à-dire si SoSelectOne::input est un SoMFFloat, SoSelectOne::output sera un SoSFFloat, etc.
