virtual void SoGLShaderProgramElement::init (SoState * state) [virtual]

Cette fonction initialise le type d'élément dans l'état donné. Elle est appelée lorsque le premier élément de chaque type d'élément activé dans un objet SoState est initialisé.

Réimplémentée depuis SoReplacedElement.

virtual void SoGLShaderProgramElement::push (SoState * state) [virtual]

Cette méthode est appelée chaque fois qu'un nouvel élément est requis dans une des piles. Cela se produit lorsqu'un élément inscriptible est demandé en utilisant SoState::getElement() ou indirectement SoElement::getElement(), et que la profondeur de l'élément actuel est inférieure à la profondeur de l'état.

Si votre élément a besoin de copier des données de l'élément précédent de la pile, surchargez cette fonction. La méthode push() est appelée sur le nouvel élément, et l'élément précédent peut être trouvé en utilisant SoElement::getNextInStack().

Réimplémentée depuis SoElement.

virtual void SoGLShaderProgramElement::pop (SoState * state, const SoElement * prevTopElement) [virtual]

Cette fonction est appelée lorsque l'état est dépilé, et que la profondeur de l'élément est supérieure à la profondeur de l'état actuel. pop() est appelé sur le nouveau sommet de la pile, et un pointeur vers l'élément précédent de la pile est passé dans prevTopElement.

Si vous avez besoin de copier des informations d'état de l'élément précédent dans la pile, surchargez cette fonction.

Réimplémentée depuis SoElement.

virtual SbBool SoGLShaderProgramElement::matches (const SoElement * element) const [virtual]

Cette fonction renvoie TRUE si l'élément correspond à un autre élément (de la même classe), en ce qui concerne la validité du cache.

Si l'élément d'extension du développeur a une fonction matches(), il doit également avoir une fonction copyMatchInfo().

Réimplémentée depuis SoReplacedElement.

virtual SoElement * SoGLShaderProgramElement::copyMatchInfo (void ) const [virtual]

Cette fonction crée une copie de l'élément qui contient suffisamment d'informations pour que la fonction matches() puisse fonctionner.

Elle est utilisée pour aider aux opérations de mise en cache de la hiérarchie de scènes.

Réimplémentée depuis SoReplacedElement.
