Description détaillée

Le moteur SoBoolOperation évalue des expressions de logique booléenne.

Les champs multivalués SoBoolOperation::a et SoBoolOperation::b sont combinés selon les opérations définies dans SoBoolOperation::operation, avec la valeur TRUE ou FALSE résultante définie sur SoBoolOperation::output.

Documentation des énumérations de membres

enum SoBoolOperation::Operation

Énumération des opérateurs logiques booléens disponibles.

Énumérateur

CLEAR
Définit toujours SoBoolOperation::output à FALSE, quelles que soient les valeurs d'entrée.
SET
Définit toujours SoBoolOperation::output à TRUE, quelles que soient les valeurs d'entrée.
A
Résultat de sortie = SoBoolOperation::a
NOT_A
Résultat de sortie = ! SoBoolOperation::a
B
Résultat de sortie = SoBoolOperation::b
NOT_B
Résultat de sortie = ! SoBoolOperation::b
A_OR_B
r = a || b
NOT_A_OR_B
r = !a || b
A_OR_NOT_B
r = a || !b
NOT_A_OR_NOT_B
r = !a || !b
A_AND_B
r = a && b
NOT_A_AND_B
r = !a && b
A_AND_NOT_B
r = a && !b
NOT_A_AND_NOT_B
r = !a && !b
A_EQUALS_B
r = a==b
A_NOT_EQUALS_B
r = ! a==b
