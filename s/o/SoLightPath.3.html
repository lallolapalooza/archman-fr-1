Description détaillée

La classe SoLightPath est une version légère de SoPath.

SoLightPath peut être utilisé si vous n'avez besoin que d'un chemin temporaire, et que vous ne souhaitez pas les frais généraux associés à un SoPath (référence, déréférencement, audit, etc.).

Il est de votre responsabilité de vous assurer que le chemin est valide avant de l'utiliser.
