Description Détaillée

La classe SoClipPlane est un nœud de type pour spécifier des plans de coupe. Un scénario de graphe de scène sans nœuds SoClipPlane utilise six plans de coupe pour définir le frustum de vision : haut, bas, gauche, droite, proche et lointain. Si vous souhaitez des plans supplémentaires pour « couper » la géométrie visible, vous pouvez utiliser des nœuds de ce type. La géométrie à l'arrière d'un plan de coupe sera coupée.

Notez que SoClipPlane est un nœud d'apparence qui modifie l'état, et à ce titre, il n'affirmera ses effets que sous le nœud SoSeparator actuel (car SoSeparator empile l'état lorsqu'il remonte au-dessus de lui), ce qui peut être vu lors du chargement de cet exemple simple dans un visualiseur Coin :

#Inventor V2.1 ascii
Separator {
   ClipPlane { }
   Cube { }
}
Separator {
   Translation { translation -3 0 0 }
   Cube { }
}

Le format de fichier / par défaut :

ClipPlane {
    plane 1 0 0  0
    on TRUE
}

Documentation des Données Membres

SoSFPlane SoClipPlane::plane

Définition du plan de découpe. La géométrie du côté arrière du plan de découpe est tronquée.

Le plan de découpe par défaut a sa normale pointant dans la direction <1,0,0> et coupe à l'origine. (C'est-à-dire que tout dans la direction négative de l'axe X est tronqué.)

SoSFBool SoClipPlane::on

Le plan de découpe doit-il être activé ou désactivé ? La valeur par défaut est TRUE.
