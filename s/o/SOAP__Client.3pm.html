SOAP::Client(3) Documentation Perl fournie par l'utilisateur SOAP::Client(3)

NOM

SOAP::Client - existe purement comme superclasse pour les classes client déclarées par les divers modules de transport de SOAP::Lite.

DESCRIPTION

La classe SOAP::Client existe purement comme superclasse pour les classes client déclarées par les divers modules de transport de SOAP::Lite. Les méthodes qu'elle fournit sont toutes des accesseurs simples ; elles renvoient la valeur actuelle lorsqu'elles sont appelées sans arguments ou définissent la valeur de l'attribut et renvoient la référence de l'objet lorsqu'elles sont appelées avec un argument. Ces attributs incluent :

MÉTHODES

code, message, status
Stocke le code de réponse, le message et le statut de la dernière tentative d'envoi. Pour certains protocoles, comme FTP, la même valeur est utilisée pour les trois en raison du manque de détails plus fins (la valeur par défaut est de garantir que les trois attributs contiennent des données, même si elles sont redondantes). D'autres protocoles (comme HTTP) ont des valeurs distinctes pour chacun.
endpoint
Identifie le point d'extrémité actuel auquel les messages sont envoyés. Cela doit correspondre à la valeur de la méthode de transport de la classe SOAP::Transport, mais la définition de ceci ne se propage pas à l'objet de transport. Il est préférable d'utiliser l'objet de transport (ou le raccourci via l'objet SOAP::Lite lui-même) lors de la définition de ceci.
is_success
Le succès ou l'échec de la dernière transmission est noté ici comme une valeur booléenne.
options
L'attribut options conserve une référence de table de hachage d'options supplémentaires et de leurs valeurs. Actuellement, une seule option est utilisée par l'un des modules de transport :
compress_threshold
La valeur de cette option doit être une valeur numérique. Si elle est définie, et si la bibliothèque Compress::Zlib est disponible, les messages dont la taille en octets dépasse cette valeur seront compressés avant l'envoi. Les deux extrémités de la conversation doivent l'avoir activée.

D'autres options peuvent être définies en utilisant ce mécanisme. Notez que la définition des options à l'aide de cet accesseur nécessite qu'une référence de table de hachage complète soit passée. Pour définir seulement une ou quelques valeurs, envisagez de récupérer la référence de valeur actuelle et de l'utiliser pour définir la ou les clés.
