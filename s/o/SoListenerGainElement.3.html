Description Détaillée

La classe SoListenerGainElement stocke le gain du SoListener lors d'un parcours du graphe de scène.

Ce gain est défini par les nœuds SoListener lors du rendu audio. Le SoListenerGainElement est utilisé lorsque les nœuds SoVRMLSound se rendent.

Soyez conscient que cette classe est une extension pour Coin, et elle n'est pas disponible dans l'API originale SGI Open Inventor v2.1.

Depuis

Coin 2.0
