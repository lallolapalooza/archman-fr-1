Description Détaillée

La classe SoResetTransform est un type de nœud qui permet de "remettre à zéro" l'état lors de la traversée.

SoResetTransform est utile pour définir de la géométrie dans l'arbre de scène qui ne sera pas influencée par les nœuds de transformation précédant sa traversée.

FORMAT DE FICHIER / VALEURS PAR DÉFAUT :

ResetTransform {
    whatToReset TRANSFORM
}

Les différentes options pour ce qui doit être réinitialisé.

Énumérateurs

TRANSFORM
Réinitialise la transformation modèle actuelle.
BBOX
Réinitialise les paramètres de la boîte englobante actuelle.

class SoResetTransform : public SoNode

DESCRIPTION DETAILLEE

SoResetTransform est un nœud qui réinitialise l'état lorsqu'il est rencontré pendant l'itération. Le nœud peut réinitialiser différentes variables d'état en fonction de la valeur de whatToReset.

Documentation des Énumérations des Membres

L'énumération SoResetTransform::whatToReset définit quel état le nœud doit réinitialiser pendant l'itération.

Documentation du Constructeur et du Destructeur

Le constructeur SoResetTransform est initialisé avec la valeur par défaut de whatToReset comme SoResetTransform::TRANSFORM.

Documentation des Fonctions des Membres

La méthode getMatrix accumule la matrice de transformation du nœud dans action.

La méthode pick effectue la logique de SoPickAction sur action.

La méthode getPrimitiveCount calcule le nombre de primitives (triangle, segment, point) et les ajoute aux compteurs de action.

Documentation des Données des Membres

Le membre whatToReset définit quel état le nœud doit réinitialiser pendant l'itération. La valeur par défaut est SoResetTransform::TRANSFORM.
