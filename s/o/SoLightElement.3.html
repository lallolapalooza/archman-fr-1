Detailed Description

This element inherits from SoElement. It maintains a list of all the lights that are currently active in the scene graph.

This element is used by SoGLRender to determine which lights should be enabled when rendering the scene. The list of lights is maintained globally for the entire scene graph, and can be accessed through the static methods.

The element also stores the transformation matrix for each light. This matrix is used to transform the light from the world coordinate system to the view reference coordinate system.

The SoLightElement is automatically pushed onto the state by any node that needs to affect the lighting of the scene. This is typically done by nodes that define lights, such as SoLight nodes.

The element is automatically popped from the state when the scenegraph traversal leaves the scope of the node that pushed it.
