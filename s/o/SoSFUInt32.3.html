Description détaillée

La classe SoSFUInt32 est un conteneur pour une valeur non signée de 32 bits.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker une seule valeur non signée de 32 bits.

Voir aussi

SoMFUInt32
