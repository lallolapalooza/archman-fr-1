void SoNormalGenerator::generate (const float creaseAngle, const int32_t * striplens = NULL, const int numstrips = 0)

Déclenche la génération des normales. Les normales sont générées en utilisant creaseAngle pour trouver les arêtes qui doivent être dégradées et celles qui doivent être dégradées en douceur.

Si des normales sont générées pour des triangles de bandes, striplens et numstrips doivent être spécifiés. Voir src/nodes/SoTriangleStripSet.cpp (generateDefaultNormals()) pour un exemple de la façon d'envoyer des informations sur les bandes à ce générateur. Ce n'est pas trivial, car vous devez savoir comment OpenGL/Coin génère des triangles à partir de bandes.

Detailed Description

This node is used to generate normals for SoNormal nodes. It can be used to automatically calculate normals based on the geometry of the primitives in the scene graph. The generated normals can then be used for lighting calculations.

The SoNormalGenerator node is typically inserted into the scene graph before the geometry nodes (e.g., SoSphere, SoCube, etc.) for which normals are to be generated.
