SoMFVec2s(3) — Coin — The Open Source OpenGL Extension

NAME

SoMFVec2s — multiple value field containing SbVec2s vectors

SYNOPSIS

#include <Inventor/fields/SoMFVec2s.h>

Inherits SoMField.

Inherited in practice by SoField.

See also: SbVec2s, SoSFVec2s

DESCRIPTION

This class is a container for multiple 2D vectors with short integer components. The vectors are stored in an array.

Use setValues() and getValues() to manipulate the vector array.

This field supports application data sharing through a setValuesPointer() method. See SoMField documentation for information on how to use this function.

See also

SbVec2s, SoSFVec2s Be aware that this class is an extension for Coin, and it is not available in the original SGI Open Inventor v2.1 API.

Since

Coin 2.5
