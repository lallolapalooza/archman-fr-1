DESCRIPTION

La classe SoRotor est un nœud utilisé pour animer les rotations.

Insérez ce nœud dans votre hiérarchie pour appliquer une rotation continue à une géométrie. Comme ce nœud hérite du nœud SoRotation, la rotation est limitée autour de l'axe spécifié dans le champ rotation.

La valeur angulaire du champ SoRotation::rotation (hérité par ce nœud) donne la direction de rotation. Si la valeur est supérieure à 0.0, la rotation sera effectuée dans le sens antihoraire, si elle est négative, la rotation sera effectuée dans le sens horaire.

Ne définissez pas la valeur de rotation exactement à 0.0, car les rotations sont traitées en interne sous forme de quaternions, et lors de la conversion d'une valeur d'angle et de rotation vers une représentation en quaternion, les informations sur l'angle « se perdent » s'il n'y a pas de rotation réelle.

Notez également que la rotation commencera à la valeur d'angle donnée.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

Rotor {
    rotation 0 0 1  0
    speed 1
    on TRUE
}
