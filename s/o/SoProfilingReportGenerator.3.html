Description détaillée

Fonctionnalités de génération de rapports pratiques.

Avec cette classe statique, vous pouvez produire de manière pratique un rapport de données de profilage à partir d'un objet SbProfilingData.

Depuis

Coin 3.0

NAME

SoProfilingReportGenerator — Report generator for profiling information.

SYNOPSIS

#include <Inventor/SbProfiler.h>

Detailed Description

The SoProfilingReportGenerator class is a subclass of SoProfilerReportGenerator. It provides a simple, text-based report of profiling information.

This class is typically used to generate a human-readable report of the performance data collected by the Coin profiler.
