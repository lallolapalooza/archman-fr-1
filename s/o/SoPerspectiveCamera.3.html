Description détaillée

La caméra perspicace représente une caméra perspicace.

Elle utilise l'angle vertical (également appelé "champ de vision") pour définir la projection. Pour obtenir le volume de vue utilisé lors du rendu, vous devriez utiliser getViewVolume.

Utilisation:

SbViewVolume vv;
float aspectratio = myviewport.getViewportAspectRatio();
switch (camera->viewportMapping.getValue()) {
case SoCamera::CROP_VIEWPORT_FILL_FRAME:
case SoCamera::CROP_VIEWPORT_LINE_FRAME:
case SoCamera::CROP_VIEWPORT_NO_FRAME:
  vv = camera->getViewVolume(0.0f);
  break;
case SoCamera::ADJUST_CAMERA:
  vv = camera->getViewVolume(aspectratio);
  if (aspectratio < 1.0f) vv.scale(1.0f / aspectratio);
  break;
case SoCamera::LEAVE_ALONE:
  vv = camera->getViewVolume(0.0f);
  break;
default:
  assert(0 && "unknown viewport mapping");
  break;
}

De plus, pour les mappings de viewport CROP, le viewport pourrait être modifié si le ratio d'aspect du viewport n'est pas égal au ratio d'aspect de la caméra. Voir le code source de SoCamera::getView() (méthode privée) pour voir comment cela est fait.

void SoPerspectiveCamera::viewAll (const SbBox3f & box, float slack = 1.1f) [virtual]

void viewAll (const SbBox3f & box, float slack = 1.1f)

Définit la position et l'orientation de la caméra afin que la boîte englobante box soit entièrement visible dans le viewport. Le paramètre slack est un facteur multiplicateur appliqué aux dimensions exactes de la boîte pour laisser un peu d'espace entre le modèle rendu et les bords de la zone de rendu.

Si vous définissez votre propre classe de nœud de caméra, sachez que cette méthode doit *uniquement* définir la position, la distance focale et les plans de clipping proche et lointain de la caméra. Elle ne doit pas définir le champ de vision.

void SoPerspectiveCamera::viewBoundingBox (const SbBox3f & box, float aspect, float slack) [virtual]

void viewBoundingBox (const SbBox3f & box, float aspect, float slack)

Méthode utilitaire pour configurer la définition de la caméra afin qu'elle couvre la boîte englobante donnée avec le ratio d'aspect aspect donné. Multiplie les dimensions exactes par un facteur de slack pour laisser un peu d'espace entre le modèle rendu et les bords de la zone de rendu.

Si vous définissez votre propre classe de nœud de caméra, sachez que cette méthode ne doit pas définir le champ d'orientation de la caméra, seulement la position, la distance focale et les plans de clipping proche et lointain.
