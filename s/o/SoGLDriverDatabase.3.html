Description détaillée

La classe SoGLDriverDatabase est utilisée pour rechercher des caractéristiques endommagées/boguées dans les pilotes OpenGL.

Coin maintiendra une base de données de pilotes où nous avons rencontré des problèmes avec certaines caractéristiques, même si le pilote prétend la supporter. Ceci dans un effort pour éviter les plantages des applications ou des systèmes d'exploitation lorsque Coin tente d'utiliser une caractéristique particulière. En utilisant cette base de données, nous pouvons désactiver cette caractéristique ou trouver une autre façon de la gérer pour les pilotes bogués.

SbBool SoGLDriverDatabase::isSupported (const cc_glglue * context, const SbName & feature) [static]

Fonction utilitaire qui vérifie si feature est supportée pour context. Si feature est une extension OpenGL, elle vérifie si elle est réellement supportée par le pilote, puis appelle SoGLDriverDatabase::isBroken() pour voir si la caractéristique est boguée pour context.

Vérifie si la base de données des pilotes indique que feature est boguée.

Vérifie si la base de données des pilotes indique que feature est lente.

SbBool SoGLDriverDatabase::isFast (const cc_glglue * context, const SbName & feature) [static]

Vérifie si la base de données des pilotes indique que feature est rapide.

SbName SoGLDriverDatabase::getComment (const cc_glglue * context, const SbName & feature) [static]

Obtient le commentaire pour feature dans context, retourne « undefined » s'il n'y a pas d'entrée. Offre une extensibilité à la base de données.
