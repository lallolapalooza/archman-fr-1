La classe SoIndexedLineSet est utilisée pour représenter et rendre les lignes indexées.

C'est l'équivalent indexé de SoLineSet. Les lignes peuvent être spécifiées en utilisant des indices pour les coordonnées, les normales, les matériaux et les coordonnées de texture.

Si les normales ne sont pas spécifiées dans la pile (ou dans le champ vertexProperty), les lignes seront rendues sans éclairage.

Pour plus d'informations sur les ensembles de lignes, voir la documentation de SoLineSet. Pour plus d'informations sur les formes indexées, voir la documentation de SoIndexedShape et SoIndexedFaceSet).

FORMAT DU FICHIER/PAR DÉFAUT :

IndexedLineSet {
    vertexProperty NULL
    coordIndex 0
    materialIndex -1
    normalIndex -1
    textureCoordIndex -1
}
