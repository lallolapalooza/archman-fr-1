Description détaillée

La classe SoVRMLFog est utilisée pour spécifier un brouillard global dans la scène.

La documentation détaillée de la classe est extraite textuellement de la norme VRML97 (ISO/IEC 14772-1:1997). Elle est Copyright The Web3D Consortium, et est utilisée avec la permission du Consortium :

Fog {
  exposedField SFColor  color            1 1 1      # [0,1]
  exposedField SFString fogType          "LINEAR"
  exposedField SFFloat  visibilityRange  0          # [0,inf)
  eventIn      SFBool   set_bind
  eventOut     SFBool   isBound
}

Le nœud Fog fournit un moyen de simuler des effets atmosphériques en mélangeant les objets avec la couleur spécifiée par le champ color en fonction des distances des différents objets par rapport au spectateur. Les distances sont calculées dans l'espace de coordonnées du nœud Fog. Le visibilityRange spécifie la distance en mètres (dans le système de coordonnées local) à laquelle les objets sont totalement masqués par le brouillard. Les objets situés en dehors du visibilityRange du spectateur sont dessinés avec une couleur constante de color. Les objets très proches du spectateur sont très peu mélangés avec la couleur du brouillard.

Une valeur de visibilityRange de 0.0 désactive le nœud Fog. Le visibilityRange est affecté par les transformations d'échelle des parents du nœud Fog ; les translations et les rotations n'ont aucun effet sur le visibilityRange. Les valeurs du champ visibilityRange doivent être comprises dans l'intervalle [0, ).

Étant donné que les nœuds Fog sont des nœuds enfants qui peuvent être liés (voir 4.6.10, Nœuds enfants liés http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.10), une pile de nœuds Fog existe, dans laquelle le nœud Fog le plus en haut de la pile est actuellement actif. Pour empiler un nœud Fog en haut de la pile, une valeur TRUE est envoyée à l'eventIn set_bind. Une fois actif, le nœud Fog est lié à la vue du navigateur. Une valeur FALSE envoyée à set_bind, dépile le nœud Fog de la pile et le délie du spectateur du navigateur. Plus de détails sur la pile de nœuds Fog peuvent être trouvés dans 4.6.10, Nœuds enfants liés (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.10).

Le champ fogType contrôle la quantité de couleur de brouillard qui est mélangée avec l'objet en fonction de la distance. Si fogType est "LINEAR", la quantité de mélange est une fonction linéaire de la distance, résultant en un effet de profondeur. Si fogType est "EXPONENTIAL", une augmentation exponentielle du mélange est utilisée, résultant en une apparence de brouillard plus naturelle. L'effet du brouillard sur les calculs d'éclairage est décrit dans 4.14, Modèle d'éclairage (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.14).
