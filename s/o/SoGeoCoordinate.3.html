Description Détaillée

La classe SoGeoCoordinate est utilisée pour spécifier une liste de coordonnées géographiques.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT:

GeoCoordinate {
  geoSystem ["GD", "WE"]
  point ""
}

Depuis

Coin 2.5
