Description Détaillée

La classe SoActionMethodList contient des pointeurs de fonction pour les méthodes d'action.

Un SoActionMethodList contient un pointeur de fonction par type de nœud. Chaque action contient un SoActioMethodList pour savoir quelles fonctions appeler lors de la traversée du graphe de scène.

Documentation Constructeur & Destructeur

SoActionMethodList::SoActionMethodList (SoActionMethodList *const parentlist)

Le constructeur. L'argument parentlist est la liste de méthodes d'action de l'action parente. Il peut être NULL pour les listes de méthodes d'action qui ne sont pas basées sur l'héritage d'une action parente.
