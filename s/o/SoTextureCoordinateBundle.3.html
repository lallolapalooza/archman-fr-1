Description détaillée

La classe SoTextureCoordinateBundle simplifie la gestion des coordonnées de texture.

Il est peu probable que les programmeurs d'applications aient besoin de savoir comment utiliser cette classe, car elle est principalement destinée à un usage interne.

Documentation du constructeur et du destructeur

SoTextureCoordinateBundle::SoTextureCoordinateBundle (SoAction *const action, const SbBool forRendering, const SbBool setUpDefault = TRUE)

Constructeur avec action étant l'action appliquée au nœud. Le paramètre forRendering doit être TRUE si le bundle doit être utilisé pour envoyer des coordonnées de texture à GL pendant le rendu. Le paramètre setUpDefault doit être TRUE si des coordonnées de texture par défaut doivent être générées.

Destructeur.

Documentation des fonctions membres

SbBool SoTextureCoordinateBundle::needCoordinates (void ) const

Retourne TRUE si des coordonnées de texture sont nécessaires pendant le rendu.

SbBool SoTextureCoordinateBundle::isFunction (void ) const

Retourne TRUE si une fonction de coordonnées de texture doit être utilisée.

const SbVec4f & SoTextureCoordinateBundle::get (const int index)

Retourne les coordonnées de texture à l'index index. Ne doit être utilisé que si SoTextureCoordinateBundle::isFunction() est FALSE.

const SbVec4f & SoTextureCoordinateBundle::get (const SbVec3f & point, const SbVec3f & normal)

Retourne les coordonnées de texture basées sur point et normal. Ne doit être utilisé que si SoTextureCoordinateBundle::isFunction() est TRUE.

void SoTextureCoordinateBundle::send (const int index) const [inline]

Envoie les coordonnées de texture à GL. Ne doit être utilisé que si SoTextureCoordinateBundle::isFunction() est FALSE.

void SoTextureCoordinateBundle::send (const int index, const SbVec3f & point, const SbVec3f & normal) const [inline]

Fonction de commodité qui rendra transparent pour le code de rendu si des coordonnées de texture ordinaires ou des coordonnées de texture fonctionnelles sont utilisées.

SbBool SoTextureCoordinateBundle::needIndices (void ) const

Retourne TRUE si isFunction() est TRUE, mais que les indices de coordonnées de texture sont nécessaires soit par le bump mapping, soit par l'une des autres unités de texture.
