SOAPsh.pl(1p)

Paquet: perl-soap-lite

Licences: GPL-1.0-or-later, Artistic-1.0-Perl

SOAPSH(1) Documentation Perl fournie par l'utilisateur SOAPSH(1)

NOM

SOAPsh.pl - Shell interactif pour les appels SOAP

SYNTAXE

perl SOAPsh.pl http://services.soaplite.com/examples.cgi http://www.soaplite.com/My/Examples
> getStateName(2)
> getStateNames(1,2,3,7)
> getStateList([1,9])
> getStateStruct({a=>1, b=>24})
> Ctrl-D (Ctrl-Z sous Windows)

ou

# tous les paramètres après l'URI seront exécutés comme des méthodes
perl SOAPsh.pl http://soap.4s4c.com/ssss4c/soap.asp http://simon.fell.com/calc doubler([10,20,30])
> Ctrl-D (Ctrl-Z sous Windows)

DESCRIPTION

SOAPsh.pl est un shell pour effectuer des appels SOAP. Il prend deux paramètres : l'endpoint obligatoire et l'URI optionnel (en fait, il vous en informera si vous essayez de le lancer). Des commandes supplémentaires peuvent suivre.

Après cela, vous pourrez exécuter n'importe quelle méthode de SOAP::Lite, comme autotype, readable, encoding, etc. Vous pouvez l'exécuter de la même manière que vous le feriez dans votre script Perl. Vous verrez la sortie de la méthode, le résultat de l'appel SOAP, des informations détaillées sur l'échec SOAP ou l'erreur de transport.

Pour la liste complète des méthodes disponibles, consultez la documentation de SOAP::Lite.

En plus des méthodes de SOAP::Lite, vous pourrez (et c'est beaucoup plus intéressant) exécuter n'importe quelle méthode SOAP que vous connaissez sur le serveur distant et voir les résultats traités. Vous pouvez même activer le débogage (en appelant quelque chose comme : on_debug(sub{print@_})) et voir le code SOAP avec les en-têtes envoyés et reçus.
