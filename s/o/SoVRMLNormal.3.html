DESCRIPTION


The SoVRMLNormal class is used to bind normals to
    geometry.


The detailed class documentation is taken verbatim from the
    VRML97 standard (ISO/IEC 14772-1:1997). It is copyright The Web3D
    Consortium, and is used by permission of the Consortium:


Normal {
  exposedField MFVec3f vector  []   # (-,)
}


This node defines a set of 3D surface normal vectors to be used in
    the vector field of some geometry nodes (e.g., SoVRMLIndexedFaceSet
    and SoVRMLElevationGrid). This node contains one multiple-valued
    field that contains the normal vectors. Normals shall be of unit length.






FIELDS




vector


The normal vectors. Empty by default.
