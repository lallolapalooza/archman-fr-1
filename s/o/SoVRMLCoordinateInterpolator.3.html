Description Détaillée

La classe SoVRMLCoordinateInterpolator est utilisée pour interpoler des coordonnées 3D.

La documentation détaillée de la classe est reprise mot pour mot de la norme VRML97 (ISO/IEC 14772-1:1997). Elle est protégée par les droits d'auteur du Consortium Web3D et est utilisée avec l'autorisation du Consortium :

CoordinateInterpolator {
  eventIn      SFFloat set_fraction        # (-inf, inf)
  exposedField MFFloat key           []    # (-inf, inf)
  exposedField MFVec3f keyValue      []    # (-inf, inf)
  eventOut     MFVec3f value_changed
}

Ce nœud interpole linéairement entre une liste de valeurs MFVec3f. Le nombre de coordonnées dans le champ keyValue doit être un multiple entier du nombre de keyframes dans le champ key. Ce multiple entier définit le nombre de coordonnées qui seront contenues dans les événements value_changed. 4.6.8, Nœuds d'interpolateur (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.8), contient une discussion plus détaillée des interpolateurs.

Description détaillée

La classe SoVRMLCoordinateInterpolator permet d'interpôler entre plusieurs ensembles de coordonnées 3D. Elle est particulièrement utile pour créer des animations où la forme d'un objet change avec le temps.

Cette classe hérite de SoVRMLInterpolatorNode et utilise la spécification VRML pour définir ses champs et son comportement.

Les champs clés incluent :

  • key : Un tableau de valeurs flottantes représentant les clés temporelles.
  • keyValue : Un tableau de tableaux de vecteurs 3D représentant les coordonnées à chaque clé.

Documentation des Fonctions Membres

Les fonctions membres spécifiques à cette classe fournissent des méthodes pour accéder et manipuler les clés et les valeurs d'interpolation. La documentation détaillée des fonctions membres se trouve dans la documentation de la classe SoVRMLInterpolatorNode, dont SoVRMLCoordinateInterpolator hérite.
