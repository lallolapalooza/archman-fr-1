Description détaillée

La classe SoPathSensor détecte les changements de chemins.

Si vous avez besoin de savoir quand un chemin change (c'est-à-dire que des nœuds dans le chemin ont été supprimés, ou que de nouveaux nœuds ont été ajoutés), utilisez ce capteur pour être averti.

Vous pouvez également utiliser ce capteur pour détecter quand un nœud quelconque dans le chemin est modifié.

Un SoPathSensor peut également agir en tant que capteur de suppression indépendant et n'a pas besoin d'une notification basée sur le temps. Le rappel de suppression sera invoqué lorsque l'objet SoPath sera supprimé, et non lorsque vous surveillez un chemin.

Documentation des énumérations des membres

Énumération SoPathSensor::TriggerFilter

Filtre de notification, qui détermine si le capteur doit déclencher sur les changements de chemins, les changements de nœuds dans le chemin, ou les deux.

Énumérateurs

PATH
Déclenche uniquement sur les changements de chemins.
NODES
Déclenche uniquement sur les changements de nœuds. Il peut s'agir de nœuds dans le chemin, ou de nœuds qui affectent les nœuds dans le chemin (nœuds qui mettent à jour l'état et se trouvent à gauche du nœud dans le chemin).
PATH_Y_NODOS
Déclenche sur les changements de chemins et de nœuds.

void SoPathSensor::attach (SoPath * path)

Attache le capteur à un chemin. Chaque fois que le chemin change, le capteur sera déclenché et la fonction de rappel sera invoquée.

Lorsque l'objet SoPath est supprimé, le capteur sera automatiquement détaché.
