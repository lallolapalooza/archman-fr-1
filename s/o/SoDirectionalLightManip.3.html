void SoDirectionalLightManip::copyContents (const SoFieldContainer * from, SbBool copyconnections) [protégé], [virtuel]

Crée une copie profonde de toutes les données de *from* dans cette instance, *sauf* les références externes du graphe de scène si *copyconnections* est FAUX.

C'est la méthode qui doit être surchargée par les sous-classes de nœud d'extension / moteur / dragger / autre qui doivent tenir compte des données internes qui ne sont pas gérées automatiquement.

Pour copier des nœuds depuis le code de l'application, vous ne devez pas appeler cette fonction directement, mais plutôt appeler la fonction SoNode::copy() :

SoNode * mynewnode = templatenode->copy();

Il en va de même pour les moteurs.

Assurez-vous que lorsque vous surchargez la méthode copyContents() dans votre classe d'extension, vous appelez également la superclasse parente dans la hiérarchie d'héritage, car copyContents(), par exemple, dans SoNode et SoFieldContainer effectue un travail important. Cela devrait ressembler à ceci :

void
MyCoinExtensionNode::copyContents(const SoFieldContainer * from,
                                  SbBool copyconnections)
{
  // laissons les superclasses parentes faire leur travail (copier les champs, copier
  // le nom de l'instance, etc.)
  SoNode::copyContents(from, copyconnections);
  // [..puis copions les données internes..]
}
