Description Détaillée

La classe SoRotateDiscDragger permet de faire pivoter une géométrie autour d'un axe unique.

Voici à quoi ressemble le dragger avec sa géométrie par défaut à l'état inactif :

Utilisez une instance de cette classe de dragger dans votre graphe de scène pour permettre aux utilisateurs finaux de votre application de faire pivoter une géométrie autour d'un vecteur d'axe prédéfini en 3D.

La caractéristique spéciale de ce dragger, qui le distingue des autres draggers offrant une rotation autour d'un axe (comme le SoRotateCylindricalDragger), est qu'il fournit une interface pratique pour pivoter autour d'un axe pointant approximativement dans la même direction que la caméra. Ceci est utile pour interagir par exemple avec un bouton de type « volume ».

Pour l'orientation et le positionnement du dragger lui-même, utilisez une sorte de nœud de transformation dans votre graphe de scène, comme d'habitude.
