Description Détaillée

La classe SoVRMLPointSet est utilisée pour représenter un ensemble de points 3D.

La documentation détaillée de la classe est reprise mot pour mot du standard VRML97 (ISO/IEC 14772-1:1997). Elle est protégée par copyright par The Web3D Consortium et utilisée avec la permission du Consortium :

PointSet {
  exposedField  SFNode  color      NULL
  exposedField  SFNode  coord      NULL
}

Le nœud PointSet spécifie un ensemble de points 3D, dans le système de coordonnées local, avec des couleurs associées à chaque point. Le champ coord spécifie un nœud SoVRMLCoordinate (ou une instance d'un nœud Coordinate). Les résultats sont indéfinis si le champ coord spécifie un autre type de nœud. PointSet utilise les coordonnées dans l'ordre. Si le champ coord est NULL, l'ensemble de points est considéré comme vide. Les nœuds PointSet ne sont pas éclairés, pas texturés, et ne participent pas à la détection de collision. La taille de chaque point dépend de l'implémentation. Detailed Description

This node defines a set of points. The points are defined using the Coordinate node's point field. The colors for the points are defined using the Color node's color field. If the Color node is not present, the points are rendered using the current material binding. If the Color node is present, the colors are applied to the points in order. The results are undefined if the Color node specifies any other type of node. Colours shall be applied to each point in order. The results are undefined if the number of values in the Color node is less than the number of values specified in the Coordinate node. If the color field is NULL and there is a SoVRMLMaterial node defined for the SoVRMLAppearance node affecting this PointSet node, the emissiveColor of the Material node shall be used to draw the points. More details on lighting equations can be found in 4.14, Lighting model (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.14).
