Description détaillée

La classe SoMFNode est un conteneur pour des nœuds.

Ce conteneur de champs stocke un tableau de pointeurs vers des nœuds. Il gère la fonctionnalité nécessaire pour traiter les opérations de copie, d'importation et d'exportation.

Notez que les pointeurs de nœuds stockés dans les instances de champs de ce type peuvent être des pointeurs NULL.

void SoMFNode::fixCopy (SbBool copyconnections) [virtual]

Cette méthode est appelée en interne après SoField::copyFrom() lors de la copie de graphes de scène, et doit effectuer les opérations nécessaires pour corriger l'instance de champ après qu'elle ait reçu une nouvelle valeur.

La méthode par défaut dans la classe parente SoField ne fait rien.

Le programmeur d'application n'a normalement pas besoin de considérer cette méthode, sauf s'il construit un type de champ complexe qui contient de nouvelles références à des instances de conteneurs (c'est-à-dire des nœuds ou des moteurs). Il est alors nécessaire de redéfinir cette méthode pour mettre à jour les pointeurs de référence, car ils pourraient avoir été dupliqués pendant l'opération de copie.

virtual void SoMFNode::deleteValues (int start, int numarg = -1) [virtual]

Supprime des éléments de valeur de l'indice start jusqu'à l'indice start + num - 1 inclus.

Les éléments dont les indices sont supérieurs au dernier élément supprimé seront déplacés vers le bas dans le tableau de valeurs.

Si num est égal à -1, supprime à partir de l'indice start jusqu'à la fin du tableau.
