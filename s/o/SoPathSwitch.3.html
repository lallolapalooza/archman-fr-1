void SoPathSwitch::search (SoSearchAction * action) [virtual]

Méthode d'action pour SoSearchAction.

Compare les critères de recherche de action pour voir si ce noeud correspond. La recherche est effectuée en comparant tous les critères définis dans SoSearchAction — si un critère demandé échoue, la recherche n'est pas considérée comme réussie pour le noeud.

void SoPathSwitch::path

Le chemin qui doit correspondre au chemin actuel de l'événement. Un chemin nul ne correspond jamais. Un chemin vide correspond toujours. Le chemin doit remonter (sans inclure) le noeud SoPathSwitch, mais pas nécessairement jusqu'au noeud racine.
