Description détaillée

La classe SoCullElement est utilisée en interne pour l'écrêtage de rendu et de sélection.

L'élément contient tous les plans à l'intérieur desquels la géométrie doit se trouver, et conserve un indicateur binaire pour signaler quels plans doivent être testés.

Cet élément est une extension pour Coin, et n'est pas disponible dans l'Open Inventor original.

Le nombre maximum de plans dans cet élément est de 32, ce qui devrait être plus que suffisant, étant donné que le volume de vue est représenté par 6 plans, et que le nombre maximum de plans de découpage OpenGL est typiquement de 6 ou 8.

Cet élément est conçu pour un écrêtage rapide, et n'effectuera pas un écrêtage de volume de vue optimal ; une boîte pourrait ne pas être écrêtée même si elle est à l'extérieur du volume de vue. L'hypothèse est que le volume de vue est petit par rapport au modèle du monde. L'élément enregistre simplement tous les plans contre lesquels écrêter, et le graphe n'est écrêté que lorsqu'il est complètement à l'extérieur d'un des plans.

SoCullElement n'est actif que pour les actions SoGLRenderAction. Il est possible de l'activer pour SoCallbackAction en le mettant à jour dans un rappel post-caméra, cependant. Faites quelque chose comme ceci :

static SoCallbackAction::Response
camera_cb(void * data, SoCallbackAction * action, const SoNode * node)
{
  SoState * state = action->getState();
  SoCullElement::setViewVolume(state, SoViewVolumeElement::get(state));
  return SoCallbackAction::CONTINUE;
}
[...]
SoCallbackAction cba(myviewport);
cba.addPostCallback(SoCamera::getClassTypeId(), camera_cb, NULL);

Lorsque le volume de vue est défini dans SoCullElement dans le rappel post-caméra, SoCallbackAction effectuera l'écrêtage sur les Séparateurs et autres nœuds de la même manière que SoGLRenderAction.

DESCRIPTION

Cet élément gère le découpage basé sur des plans et un volume de vue.

Il stocke un ensemble de plans de découpage (culling planes). Ces plans peuvent être définis explicitement en utilisant addPlane() ou implicitement en utilisant setViewVolume().

Les méthodes cullBox() et cullTest() peuvent être utilisées pour déterminer si une boîte englobante (bounding box) est à l'extérieur des plans de découpage actifs.

Si cullBox() retourne TRUE, cela signifie que la boîte est en dehors d'au moins un des plans et doit être découpée. Si elle retourne FALSE, cela signifie que la boîte est complètement à l'intérieur de tous les plans de découpage actifs.

La méthode completelyInside() vérifie si le contenu est complètement à l'intérieur des plans de découpage. Il n'est pas nécessaire d'effectuer un test de découpage si c'est le cas.

void SoCullElement::setViewVolume (SoState * state, const SbViewVolume & vv) [static]

Définit le volume de vue courant. En effet, cela ajoute six plans à la liste des plans de découpage. Si un volume de vue a déjà été défini, les anciens plans du volume de vue sont écrasés par les nouveaux. Le volume de vue doit être dans le système de coordonnées du monde.

SbBool SoCullElement::cullBox (SoState * state, const SbBox3f & box, const SbBool transform = TRUE) [static]

Découpe par rapport à la box. Si transform est TRUE, la boîte est supposée être dans l'espace objet et sera transformée dans l'espace monde en utilisant la matrice de modèle. Retourne TRUE si la boîte est à l'extérieur d'un des plans, et met à jour l'élément pour détecter quand la géométrie est complètement à l'intérieur de tous les plans.

SbBool SoCullElement::cullTest (SoState * state, const SbBox3f & box, const SbBool transform = TRUE) [static]

Découpe par rapport à la box. Si transform est TRUE, la boîte est supposée être dans l'espace objet et sera transformée dans l'espace monde en utilisant la matrice de modèle. Retourne TRUE si la boîte est à l'extérieur d'un des plans. Cette méthode ne mettra pas à jour l'état de l'élément, elle effectuera juste un test de découpage contre les plans actifs.
