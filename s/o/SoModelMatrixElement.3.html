Description détaillée

La classe SoModelMatrixElement est utilisée pour gérer la transformation courante.

SoModelMatrixElement contient la matrice objet-vers-monde.

La transformation monde-vers-caméra est stockée dans la classe SoViewingMatrixElement.

Notez qu'une chose qui peut prêter à confusion avec l'API est que SoModelMatrixElement ne contient pas la même matrice que la matrice OpenGL GL_MODELVIEW.

Voir aussi

SoViewingMatrixElement

DESCRIPTION

Cet élément d'état gère la matrice du modèle courante. Cela inclut la matrice des transformations du globe, la matrice des transformations des boîtes englobantes, la matrice des transformations combinées, et des drapeaux pour contrôler le comportement. Les méthodes publiques statiques permettent d'interagir avec cet élément à partir de l'état d'inventaire.

C'est une classe virtuelle qui définit l'interface pour les éléments de matrice de modèle concrets. Les implémentations concrètes (par exemple, SoGLModelMatrixElement) fourniront le comportement réel.
