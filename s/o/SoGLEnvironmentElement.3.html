Description

This class is the OpenGL specific implementation of the environment settings. It is used to set GL attributes like fog, ambient light, etc. When SoEnvironmentElement is used, this element is automatically invoked.

There is no need to use this class directly unless you are writing your own OpenGL rendering module.

The following GL attributes are set by this element:

        Fog, ambient intensity, ambient light color, and attenuation
