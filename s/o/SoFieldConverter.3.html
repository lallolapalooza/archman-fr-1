SoFieldConverter

SYNTAXE

class SoFieldConverter

Description détaillée

La classe SoFieldConverter est la classe abstraite de base pour les convertisseurs de champs.

Lorsqu'on tente de connecter des champs de types différents, la librairie Coin essaie de trouver un convertisseur de champ qui puisse s'insérer entre eux, agissant comme un filtre qui convertit les valeurs du champ principal vers les valeurs correspondant au type du champ secondaire.

S'il existe une possibilité de conversion de type (comme entre un champ de type SoSFFloat et un champ de type SoSFInt32, par exemple, où l'on pourrait faire un type cast simple pour convertir la valeur de l'un à l'autre), un objet dérivé de SoFieldConverter est inséré.

Cette classe est la superclasse abstraite dont tous ces convertisseurs de champ doivent hériter.

La librairie Coin inclut une classe de convertisseur de champ pré-installée qui gère toutes les conversions de champ à champ que nous connaissons. Cela signifie que les développeurs d'applications n'auront probablement pas à se soucier de cette classe, et elle ne sera utile que s'ils étendent la librairie Coin avec leurs propres classes de types de champs. (Cette pratique est considérée comme une utilisation avancée de la bibliothèque.)
