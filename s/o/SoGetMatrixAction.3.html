Description détaillée

La classe SoGetMatrixAction est une action pour accumuler la matrice de transformation d'un sous-graphe.

Cette action permet de calculer et de convertir facilement vers et depuis le système de coordonnées global de votre scène et les coordonnées locales des parties d'un modèle hiérarchique.

Contrairement à la plupart des autres types d'actions, SoGetMatrixAction ne traverse pas les enfants du nœud auquel elle est appliquée -- uniquement le nœud lui-même. Lorsqu'elle est appliquée à des chemins, elle s'arrête au dernier nœud et ne continue pas plus loin avec les enfants du nœud terminal.

Une utilisation typique pour interroger la position, l'orientation et/ou l'échelle dans l'espace monde serait la suivante :

// Obtenir d'abord un SoPath à travers le graphe de scène jusqu'au
// nœud ("mynode") dont vous souhaitez interroger la transformation
// mondiale actuelle.
SoSearchAction * searchaction = new SoSearchAction;
searchaction->setNode(mynode);
searchaction->apply(myscenegraphroot);
SoPath * path = searchaction->getPath();
assert(path != NULL);
// Appliquer ensuite SoGetMatrixAction pour obtenir la matrice de transformation
// complète depuis l'espace monde.
const SbViewportRegion vpr = myviewer->getViewportRegion();
SoGetMatrixAction * getmatrixaction = new SoGetMatrixAction(vpr);
getmatrixaction->apply(path);
SbMatrix transformation = getmatrixaction->getMatrix();
// Et si vous voulez accéder aux composantes de transformation individuelles
// de la matrice :
SbVec3f translation;
SbRotation rotation;
SbVec3f scalevector;
SbRotation scaleorientation;
transformation.getTransform(translation, rotation, scalevector, scaleorientation);

void SoGetMatrixAction::beginTraversal (SoNode * node) [protected], [virtual]

Cette méthode virtuelle est appelée depuis SoAction::apply(), et est le point d'entrée pour le parcours réel du graphe de scène.

Elle peut être redéfinie pour initialiser l'action au début du parcours, pour des initialisations spécifiques dans les sous-classes d'action héritant de SoAction.

La méthode par défaut appelle simplement traverse(), ce que toute implémentation redéfinie de la méthode doit faire également (ou appeler SoAction::beginTraversal()) pour déclencher le parcours du graphe de scène.
