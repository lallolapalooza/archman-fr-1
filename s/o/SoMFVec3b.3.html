NAME

SoMFVec3b

multiple field of SbVec3b vectors

SYNOPSIS

#include <Inventor/fields/SoMFVec3b.h>

Inheritance:
SoField
  SoMField
    SoMFVec3b

Description

The SoMFVec3b field type is used for fields that contain a list of three-component vectors of 8-bit signed integers (i.e. SbVec3b).

The values are stored as arrays of three int8_t components.

As this is a multiple field, it can contain zero or more values. Values are accessed using the standard [...] syntax or via the operator[] methods.

This field supports application data sharing through a setValuesPointer() method. See SoMField documentation for information on how to use this function.

See also

SbVec3b, SoSFVec3b Be aware that this class is an extension for Coin, and it is not available in the original SGI Open Inventor v2.1 API.

Since

Coin 2.5
