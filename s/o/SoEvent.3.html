Description détaillée

La classe SoEvent est la classe de base pour tous les événements Coin.

Coin contient son propre ensemble de classes d'événements, indépendantes du système de fenêtrage sous-jacent.

Lors des événements spécifiques au système, une traduction est effectuée par les classes de périphériques spécifiques à la fenêtre vers l'une des classes d'objets d'événements Coin listées ci-dessous. L'événement est ensuite typiquement envoyé par la zone de rendu à un SoSceneManager qui l'appliquera au graphe de scène via une SoHandleEventAction.

Les événements peuvent être capturés par l'utilisateur en attachant un nœud SoEventCallback au graphe de scène, ou ils peuvent être automatiquement gérés par un dragger ou un manipulateur dans le graphe.

Detailed Description

Cette classe de base définit le comportement général d'un événement.

Les événements sont générés par le système et capturés par le moniteur d'événements de 3D.

Dans la plupart des cas, vous n'utiliserez pas directement cette classe, mais plutôt une de ses sous-classes qui représentent des types d'événements spécifiques.
