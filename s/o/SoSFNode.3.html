Description détaillée

La classe SoSFNode est un conteneur pour un nœud unique.

Ce conteneur de champ stocke un pointeur vers un nœud Coin. Il prend en charge les fonctionnalités nécessaires pour gérer les opérations de copie, d'importation et d'exportation.

Notez que le pointeur de nœud stocké dans une instance de champ de ce type peut être un pointeur NULL.

SoNode, SoMFNode
