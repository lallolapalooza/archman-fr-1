Description Détaillée

La classe SoGLDisplayList stocke et gère les listes d'affichage OpenGL.

Le type TEXTURE_OBJECT n'est pas directement supporté dans Coin. Nous gérons les textures différemment dans une classe plus flexible appelée SoGLImage, qui stocke également certaines informations sur la texture utilisée lors du rendu. Le code ancien qui utilise cet élément ne devrait cependant pas cesser de fonctionner. L'extension d'objet texture ne sera juste pas utilisée, et la texture sera stockée dans une liste d'affichage à la place.
