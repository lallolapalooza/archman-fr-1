Description Détaillée

La classe SoOrthographicCamera définit un nœud de caméra avec rendu orthographique.

Le rendu orthographique ne donnera pas une impression particulièrement réaliste de la scène, mais le rendu non réaliste est utilisé dans les applications pour diverses raisons, par exemple dans la conception assistée par ordinateur.

Une technique simple pour dessiner des graphiques de superposition / HUD (apparaissant souvent en 2D) peut également être mise en œuvre en définissant un "sous-scène" avec une SoOrthographicCamera et la géométrie. Comme démonstration simple de ce concept, chargez ce fichier dans, par exemple, le ViewerViewerViewer :

#Inventor V2.1 ascii
Separator {
   PerspectiveCamera { position 0 0 5 }
   Cone { }
   Separator {
      OrthographicCamera {
         position -0.75 -0.75 2
      }
      BaseColor { rgb 1 1 0 }
      Sphere { radius 0.2 }
   }
}

Avec cette technique, des problèmes de tampon de profondeur peuvent survenir, entraînant le mélange des graphiques de superposition / HUD avec la géométrie "réelle". Si c'est le cas, ce problème peut être résolu en insérant un nœud SoCallback dans la sous-scène, où le callback peut désactiver le tampon de profondeur avec glDisable(GL_DEPTH_TEST).

FORMAT/VALEUR_PAR_DEFAUT :

OrthographicCamera {
    viewportMapping ADJUST_CAMERA
    position 0 0 1
    orientation 0 0 1  0
    nearDistance 1
    farDistance 10
    aspectRatio 1
    focalDistance 5
    height 2
}

SbViewVolume SoOrthographicCamera::getViewVolume (float useaspectratio = 0.0f) const [virtual]

Returns total view volume covered by the camera under the current settings.

This view volume is not adjusted to account for viewport mapping. If you want the same view volume as the one used during rendering, you should use getViewVolume(SbViewportRegion & vp, const SbMatrix & mm), or do something like this:

SbViewVolume vv;
float aspectratio = myviewport.getViewportAspectRatio();
switch (camera->viewportMapping.getValue()) {
case SoCamera::CROP_VIEWPORT_FILL_FRAME:
case SoCamera::CROP_VIEWPORT_LINE_FRAME:
case SoCamera::CROP_VIEWPORT_NO_FRAME:
  vv = camera->getViewVolume(0.0f);
  break;
case SoCamera::ADJUST_CAMERA:
  vv = camera->getViewVolume(aspectratio);
  if (aspectratio < 1.0f) vv.scale(1.0f / aspectratio);
  break;
case SoCamera::LEAVE_ALONE:
  vv = camera->getViewVolume(0.0f);
  break;
default:
  assert(0 && "unknown viewport mapping");
  break;
}

Also, for the CROPPED viewport mappings, the viewport might be changed if the viewport aspect ratio is not equal to the camera aspect ratio. See the SoCamera::getView() source-code (private method) to see how this is done.

Implements SoCamera.

void SoOrthographicCamera::viewBoundingBox (const SbBox3f & box, float aspect, float slack) [virtual]

Convenience method for setting up the camera definition to cover the given bounding box with the given aspect ratio. Multiplies the exact dimensions with a slack factor to have some space between the rendered model and the borders of the rendering area.

If you define your own camera node class, be aware that this method should not set the orientation field of the camera, only the position, focal distance and near and far clipping planes.

Implements SoCamera.
