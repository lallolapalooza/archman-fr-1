La classe SoMFPlane est un conteneur pour les valeurs SbPlane.

Ce champ est utilisé lorsque les nœuds, moteurs ou autres conteneurs de champs doivent stocker plusieurs définitions de plans 3D.

Detailed Description

This class is used to store an array of SbPlane objects.

This is a manifold field.

The methods deleteAllValues() and copyValue() are protected and meant to be used by derived classes only. They are here documented for completeness.

This API member is considered internal to the library, as it is not likely to be of interest to the application programmer.

Creates a new instance of the class type corresponding to the SoType object.
