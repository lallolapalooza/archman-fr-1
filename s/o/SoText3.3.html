Description détaillée

La classe SoText3 rend le texte 3D extrudé.

Elle rend le texte en tant que géométrie 3D.

La taille de la représentation de géométrie textuelle est déterminée par le champ SoFont::size d'un nœud SoFont précédent dans l'arborescence de scène, qui spécifie la taille en coordonnées unitaires. Cette valeur définit la taille approximative des lettres verticalement. La valeur par défaut s'il n'y a pas de nœuds SoFont utilisés est 10.

Cette classe créera une géométrie 3D à partir d'une police de caractères spécifiée par un nœud SoFont précédent. La complexité des glyphes est contrôlée par un nœud SoComplexity précédent avec Type défini sur OBJECT_SPACE. Notez que

h et chaque caractère du texte augmente considérablement le nombre de polygones. Cela rend les nœuds SoText3 les plus adaptés dans les situations où vous avez juste besoin de placer quelques caractères dans votre scène, plutôt que de visualiser des phrases complètes.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

Text3 {
    string ""
    spacing 1
    justification LEFT
    parts FRONT
}

SoDetail * SoText3::createTriangleDetail (SoRayPickAction * action, const SoPrimitiveVertex * v1, const SoPrimitiveVertex * v2, const SoPrimitiveVertex * v3, SoPickedPoint * pp) [protected], [virtual]

Créera un détail de triangle pour un SoPickedPoint. Cette méthode ne sera appelée qu'en interne, lorsque generatePrimitives() est utilisé pour la sélection (SoShape::rayPick() n'est pas réimplémenté).

Cette méthode retourne NULL dans Open Inventor, et les sous-classes devront réimplémenter cette méthode pour créer des détails pour un SoPickedPoint.

Ce n'est pas nécessaire avec Coin. Bien sûr, si vous choisissez de la réimplémenter, elle fonctionnera de la même manière qu'Open Inventor.

Pour que cela fonctionne, vous devez fournir un détail de face ou de ligne lors de la génération des primitives. Si vous fournissez NULL pour l'argument détail dans SoShape::beginShape(), vous devrez réimplémenter cette méthode.

Documentation des données membres

SoMFString SoText3::string

L'ensemble des chaînes à rendre. Chaque chaîne du champ à valeurs multiples sera rendue sur une ligne séparée.

La valeur par défaut du champ est une seule chaîne vide.

SoSFFloat SoText3::spacing

Espacement vertical entre les lignes de base de deux lignes horizontales consécutives. La valeur par défaut est 1.0, ce qui signifie qu'elle est égale à la taille verticale du caractère le plus haut de l'alphabet bitmap.

SoSFEnum SoText3::justification

Détermine l'alignement horizontal des chaînes de texte.

Si justification est définie sur SoText3::LEFT, le bord gauche de la première chaîne est à l'origine et toutes les chaînes sont alignées avec leurs bords gauches. Si elle est définie sur SoText3::RIGHT, le bord droit de la première chaîne est à l'origine et toutes les chaînes sont alignées avec leurs bords droits. Sinon, si elle est définie sur SoText3::CENTER, le centre de la première chaîne est à l'origine et toutes les chaînes sont alignées avec leurs centres. L'origine est toujours située sur la ligne de base de la première ligne de texte.

La valeur par défaut est SoText3::LEFT.

SoSFBitMask SoText3::parts

Parties des caractères. Par défaut, seule la partie avant est affichée.
