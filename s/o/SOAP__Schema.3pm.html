SOAP__Schema(3pm)

Paquet: perl-soap-lite

Licences: GPL-1.0-or-later, Artistic-1.0-Perl

SOAP::Schema(3) Documentation Perl fournie par la communauté SOAP::Schema(3)

NOM

SOAP::Schema - fournit un parapluie pour la manière dont SOAP::Lite gère les schémas de description de services

DESCRIPTION

Cette classe fournit un parapluie pour la manière dont SOAP::Lite gère les schémas de description de services. Actuellement, le seul support présent concerne le WSDL (Web Services Description Language). C'est une autre des classes non généralement conçues pour être directement instanciées par une application, bien que cela soit possible si désiré.

MÉTHODES

new(paires clé/valeur optionnelles)
$schema = SOAP::Schema->new(parse => $schema_uri);

C'est le constructeur de classe. Sans arguments, il crée un objet vide de la classe. Tous les arguments passés sont traités comme des paires clé/valeur dans lesquelles la clé représente l'une des méthodes décrites ici, et la valeur est ce qui est passé lorsque la méthode elle-même est invoquée.

parse(URI de description de service)
$schema->parse('http://schemas.w3.org/soap.wsdl');

Analyse la représentation interne de la description du service avant la génération des routines de stub pour fournir un accès de type méthode aux services distants.

access(URI de description de service)
$schema->access('http://soap.org/service.wsdl');

Charge la description de service spécifiée à partir de l'URL donnée, en utilisant la valeur actuelle de l'accesseur de schéma si aucun n'est fourni. Le contenu complet de l'URL est renvoyé en cas de succès, ou une exception est levée (via "die") en cas d'erreur.

load
$schema->load;

Prend la représentation interne du service et génère des stubs de code pour les méthodes distantes, permettant de les appeler comme des méthodes d'objet locales. Les stubs sont générés pour toutes les fonctions déclarées dans la description WSDL avec cet appel car c'est un cadre de classe suffisant pour permettre la création d'objets de base à utiliser comme handles.

schema
$current_schema = $schema->schema;

Obtient (ou définit) la représentation actuelle du schéma à utiliser par cet objet. La valeur à passer lors de la définition est simplement l'URI du schéma. Celle-ci est passée à d'autres méthodes comme access pour charger le contenu réel.

services
$hashref = $schema->services;

Obtient ou définit les services actuellement stockés sur l'objet. Les services sont conservés sous forme de référence de hachage, dont les clés et les valeurs sont la liste des valeurs renvoyées par l'analyseur WSDL. Les clés représentent les noms des services eux-mêmes (les noms ont été normalisés en identifiants compatibles Perl), avec des valeurs qui sont également des références de hachage vers la représentation interne du service lui-même.

stub
Renvoie le code Perl autogénéré sous forme de chaîne de caractères. Ce code est généré à partir du WSDL fourni par l'appel de la méthode "service". Le code contient une définition de package pour le service appelé. 
my $client = SOAP::Lite->new;
my $code = $client->service($WSDL_URL)->stub;
open FILE,">ServicePackage.pm";
print FILE $code;
close FILE;
cache_dir
Définit/récupère la valeur du répertoire où les stubs générés seront mis en cache. Si "cache_dir" est nul, aucun cache ne sera effectué. 
my $client = SOAP::Lite->new;
my $code = $client->cache_dir("/tmp")->service($WSDL_URL)->stub;

Si "cache_dir" est indéfini, aucun cache n'aura lieu.

cache_ttl
Définit/récupère la valeur du temps de vie (en secondes) pour les fichiers mis en cache. Ceci n'est pertinent que lorsqu'il est utilisé en conjonction avec "cache_dir".

Si "cache_ttl" est défini sur 0, le cache n'expirera jamais. Les fichiers devront être supprimés manuellement pour que le cache soit actualisé.

my $client = SOAP::Lite->new;
my $code = $client->cache_ttl(3600)->cache_dir("/tmp")->service($WSDL_URL)->stub;

Le temps de vie par défaut est de 0.

useragent(LWP::UserAgent)
my $client = SOAP::Lite->new;
$ua = $client->schema->useragent;
$ua->agent("Fubar! 0.1");
my $response = $client->service("http://localhost/some.wsdl")
                      ->someMethod("Foo");

Obtient ou définit l'UserAgent de la classe utilisé pour récupérer les schémas sur le web. Cela permet aux utilisateurs d'avoir un accès direct à l'UserAgent afin qu'ils puissent contrôler les identifiants passés à un serveur distant, ou la configuration spécifique de leur agent HTTP.

SOAP::Schema::WSDL

À l'heure actuelle, la boîte à outils SOAP::Lite ne prend en charge que le chargement des descriptions de services au format WSDL. Cette classe gère l'analyse et le stockage de ces spécifications de services. En règle générale, cette classe devrait être encore moins susceptible d'être utilisée directement par une application car sa présence devrait être complètement abstraite par la classe précédente (SOAP::Schema). Aucune des méthodes n'est définie ici ; la classe est seulement mentionnée à titre de référence.
