Description Détaillée

La classe SoVRMLColor est utilisée pour spécifier plusieurs couleurs pour une seule forme.

La documentation détaillée de la classe est reprise mot pour mot de la norme VRML97 (ISO/IEC 14772-1:1997). Elle est copyright de The Web3D Consortium, et est utilisée avec la permission du Consortium :

Color {
  exposedField MFColor color  []         # [0,1]
}

Ce nœud définit un ensemble de couleurs RVB à utiliser dans les champs d'un autre nœud.

Les nœuds Color sont uniquement utilisés pour spécifier plusieurs couleurs pour une seule forme géométrique, telles que les couleurs des faces ou des sommets d'un IndexedFaceSet. Un nœud Material est utilisé pour spécifier les paramètres globaux de matériau de la géométrie éclairée. Si un nœud Material et un nœud Color sont spécifiés pour une forme géométrique, les couleurs remplaceront la composante diffuse du matériau. Les textures RVB ou RVBA ont la priorité sur les couleurs ; la spécification simultanée d'une texture RVB ou RVBA et d'un nœud Color pour une forme géométrique entraînera l'ignorance du nœud Color. Les détails sur les équations d'éclairage peuvent être trouvés dans la section 4.14, Modèle d'éclairage (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.14).
