Description détaillée

La classe SoRayPickAction effectue des intersections de rayons avec des graphes de scène.

Pour interagir avec la géométrie du graphe de scène, il est nécessaire de pouvoir effectuer des tests d'intersection pour les rayons. Cette fonctionnalité est fournie par la classe SoRayPickAction.

SoRayPickAction peut être utilisé pour passer des rayons arbitraires à travers la scène pour des détections d'intersection, en utilisant la méthode setRay().

DESCRIPTION

Une action qui effectue la détection par rayon sur un graphe de scène. Elle peut être configurée pour utiliser une ligne de détection ou une boîte de vue (point de vue). La détection par rayon peut être effectuée dans l'espace monde ou dans l'espace objet.

Pour effectuer une détection par rayon, vous devez créer une instance de cette classe, la configurer avec une ligne de détection ou une boîte de vue, puis appeler la méthode apply() sur le nœud racine de votre graphe de scène. Une fois que l'action est terminée, vous pouvez utiliser les méthodes getNumPoints(), getPoint() et isBetweenPlanes() pour récupérer les résultats de la détection.

Il est possible de configurer la précision de la détection, les types de nœuds à ignorer et les stratégies de détection à utiliser.

Les informations sur les points détectés sont stockées dans une liste interne de SoPickedPoint. Chaque SoPickedPoint contient des informations sur le point de détection, y compris sa position dans l'espace monde et dans l'espace objet, ainsi que le nœud auquel il appartient.
