Description Détaillée

La classe SoTransformation est la classe de base abstraite pour les nœuds de transformation.

Pour positionner et orienter la géométrie dans l'espace du monde 3D, divers types de nœuds pour les transformations sont utilisés. Ces nœuds héritent tous de la classe de base SoTransformation.

Notez que les transformations seront accumulées à travers le graphe de scène, sauf si elles sont utilisées sous des nœuds SoSeparator, où la pile de matrices de transformation sera poussée et dépilée. Voici un court exemple démontrant ce principe :

#Inventor V2.1 ascii
Separator {
   BaseColor { rgb 1 0 0 }
   Cone { }
   Translation { translation 3 0 0 }
   Separator {
      Rotation { rotation 1 0 0  1.57 }
      BaseColor { rgb 0 1 0 }
      Cone { }
   } # SoSeparator restaure la matrice de transformation ici
   Translation { translation 3 0 0 }
   Rotation { rotation 1 0 0  1.57 }
   BaseColor { rgb 0 0 1 }
   Cone { }
   Translation { translation 3 0 0 }
   # La dernière SoRotation n'était pas dans SoSeparator, donc la prochaine
   # SoRotation s'accumulera avec la précédente.
   Rotation { rotation 1 0 0  1.57 }
   BaseColor { rgb 1 1 0 }
   Cone { }
}
