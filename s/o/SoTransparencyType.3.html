Description détaillée

La classe SoTransparencyType est un nœud permettant de définir le type de transparence pour les formes.

Dans les versions antérieures de Coin/Open Inventor, il n'était possible de définir le mode de transparence qu'à l'échelle globale pour l'ensemble d'un graphique de scène, ce qui pouvait être gênant si des types de transparence différents étaient souhaités pour des formes différentes.

Voici une capture d'écran des différents modes de transparence utilisés dans une seule scène.

Notez que cette classe est une extension de Coin et n'est pas disponible dans l'API originale SGI Open Inventor v2.1.
FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

TransparencyType {
    value SCREEN_DOOR
}
