Description détaillée

La classe SoEventManager gère les événements pour une visionneuse Coin3D.

Elle reçoit les événements Coin (typiquement traduits à partir d'événements d'interface graphique par le binding d'interface graphique utilisé) et les transmet à la machine d'état ou directement au graphe de scène selon le mode de navigation. SoEventManager implémente l'interface d'événement pour le système de navigation Coin3D basé sur ScXML. SoEventManager et SoRenderManager remplacent ensemble SoSceneManager, qui n'est plus qu'une enveloppe autour de ces classes. La classe est utilisée par QuarterWidget dans Quarter (le binding Qt pour Coin3D).

Documentation des énumérations de membres

enum SoEventManager::NavigationState

Définit comment les événements sont gérés.

Énumérateur

NO_NAVIGATION
Transmet les événements uniquement au graphe de scène.
JUST_NAVIGATION
Transmet les événements uniquement aux machines d'état.
MIXED_NAVIGATION
Transmet d'abord les événements au graphe de scène. S'ils ne sont pas gérés, les événements sont transmis aux machines d'état.

void SoEventManager::addSoScXMLStateMachine (SoScXMLStateMachine * sm)

Ajoute un objet machine d'état SCXML au pipeline d'événements de SoEventManager.

Le code appelant est responsable de la suppression de la machine d'état passée après que removeSoScXMLStateMachine() ait été appelée.

(Note : ce comportement a changé entre Coin 3.1 et les versions ultérieures, car SoEventManager détruisait les machines d'état lors de sa propre destruction.)
