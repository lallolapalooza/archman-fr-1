Description Détaillée

La classe SoPickStyle est un nœud pour configurer la façon dont les opérations de sélection sont effectuées.

Par défaut, toute la géométrie d'une scène est disponible pour la sélection. Lorsque vous écrivez des applications interactives, ce n'est généralement pas ce que vous voulez. Pour exclure des parties de l'arbre de scène des opérations de sélection, vous pouvez utiliser SoPickStyle::UNPICKABLE.

Vous pouvez également optimiser les opérations de sélection en utilisant le style SoPickStyle::BOUNDING_BOX.

FORMAT DE FICHIER / VALEUR PAR DÉFAUT :

PickStyle {
    style SHAPE
}

Documentation des énumérations membres

Énumération SoPickStyle::Style

Énumération des stratégies de sélection disponibles.

Énumérateurs

SHAPE
Effectuer des sélections précises, trouver le bon point d'intersection, etc.
BOUNDING_BOX
Comparer uniquement l'intersection de sélection avec les boîtes englobantes des formes. C'est généralement plus rapide que SoPickStyle::SHAPE.
UNPICKABLE
La géométrie suivante dans la scène après ce nœud ne sera pas disponible pour la sélection.
SHAPE_ON_TOP
Effectuer des sélections précises, comme SHAPE, mais placer la forme dans la liste des points sélectionnés avant les autres. Cela n'affecte pas le coordonnée de sélection SoPickedPoint, mais seulement l'ordre de profondeur dans la liste des points sélectionnés.

Cependant

Coin 3.0
BOUNDING_BOX_ON_TOP
Effectuer des sélections par rapport à la boîte englobante de l'objet, comme BOUNDING_BOX, mais placer la forme dans la liste des points sélectionnés avant les autres afin qu'elle apparaisse comme le point le plus proche. Cela n'affecte pas le coordonnée de sélection SoPickedPoint, mais seulement l'ordre de profondeur dans la liste des points sélectionnés.

Cependant

Coin 3.0
SHAPE_FRONTFACES
Effectuer des sélections précises, comme SHAPE, mais supprimer toutes les intersections de faces arrière de la liste. Remarque : cette logique est basée sur le rayon, pas sur la vue.

Le comportement de ce paramètre dépend également des valeurs de SoShapeStyle vertexOrdering et shapeType, qui sont utilisées pour inverser les faces avant en faces arrière et vice-versa, et pour activer ou désactiver l'écrêtage des faces arrière.
