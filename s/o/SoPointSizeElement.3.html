Description détaillée

L'élément SoPointSizeElement modifie le réglage de la taille des points de l'état de rendu.

Les requêtes du graphe de scène pour modifier la taille des points lors du rendu de primitives de points seront effectuées via cet élément.

La classe SoPointSizeElement elle-même n'est qu'une abstraction générique pour les classes So*PointSizeElement sous-jacentes avec du code spécifique pour chaque bibliothèque de rendu en mode immédiat prise en charge.
