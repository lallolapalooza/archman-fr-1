int SoGLCacheContextElement::get (SoState * state) [static]

Retourne l'identifiant du contexte.

Notez que la signature de cette fonction est légèrement incorrecte : la fonction devrait en réalité retourner un uint32_t, comme le fait SoGLRenderAction::getCacheContext(). Elle est conservée ainsi pour des raisons de compatibilité.

La valeur retournée sera toujours un entier positif.

Retourne TRUE si l'extension est supportée pour le contexte actuel. extid doit être un identifiant retourné par getExtId(). Le résultat du test est mis en cache, donc cette méthode est assez rapide et peut être utilisée à l'exécution.

uint32_t SoGLCacheContextElement::getUniqueCacheContext (void ) [static]

Retourne un identifiant de contexte de cache unique, dans l'intervalle [1, ->.

Si vous rendez le même graphe de scène dans deux contextes de cache différents ou identiques, et que vous n'utilisez pas le partage de listes d'affichage et d'objets de texture entre les contextes, l'identifiant du contexte de cache doit être unique pour que le rendu fonctionne.

Cette fonction est une extension pour Coin, et elle n'est pas disponible dans l'API originale Open Inventor v2.1.

void SoGLCacheContextElement::scheduleDeleteCallback (const uint32_t contextid, SoScheduleDeleteCB * cb, void * closure) [static]

Peut être utilisé pour recevoir un rappel la prochaine fois que Coin sait que le contexte (spécifié par contextid) est le contexte OpenGL actuel.

Cette fonction peut être utilisée pour libérer des ressources OpenGL pour un contexte.

Notez que le rappel ne sera invoqué qu'une seule fois, puis retiré de la liste interne des rappels programmés.
