NOM

Socket6 - Partie relative à l'IPv6 des définitions C socket.h et manipulateurs de structures

SYNOPIS

use Socket;
use Socket6;
@res = getaddrinfo('hishost.com', 'daytime', AF_UNSPEC, SOCK_STREAM);
$family = -1;
while (scalar(@res) >= 5) {
    ($family, $socktype, $proto, $saddr, $canonname, @res) = @res;
    ($host, $port) = getnameinfo($saddr, NI_NUMERICHOST | NI_NUMERICSERV);
    print STDERR "Trying to connect to $host port $port...\n";
    socket(Socket_Handle, $family, $socktype, $proto) || next;
    connect(Socket_Handle, $saddr) && last;
    close(Socket_Handle);
    $family = -1;
}
if ($family != -1) {
    print STDERR "connected to $host port $port\n";
} else {
    die "connect attempt failed\n";
}

DESCRIPTION

Ce module fournit des routines de liaison aux diverses fonctions IPv6.

Si vous utilisez le module Socket6, assurez-vous de spécifier "use Socket" ainsi que "use Socket6".

Les fonctions fournies sont :

inet_pton FAMILLE, ADRESSE_TEXTE
Cette fonction prend une adresse IP au format présentation (ou chaîne de caractères)
et la convertit en format numérique (ou binaire).
Le type de conversion d'adresse IP (IPv4 ou IPv6) est contrôlé
par l'argument FAMILLE.
inet_ntop FAMILLE, ADRESSE_BINAIRE
Cette fonction prend une adresse IP au format numérique (ou binaire)
et la convertit en format présentation (ou chaîne de caractères).
Le type de conversion d'adresse IP (IPv4 ou IPv6) est contrôlé
par l'argument FAMILLE.
pack_sockaddr_in6 PORT, ADDR
Cette fonction prend deux arguments : un numéro de port et une structure
d'adresse IPv6 de 16 octets (telle que retournée par inet_pton()).
Elle retourne la structure sockaddr_in6 avec ces arguments empaquetés
dans leurs champs corrects, ainsi que la famille AF_INET6.
Les autres champs ne sont pas définis et leurs valeurs ne doivent pas être
utilisées.
pack_sockaddr_in6_all PORT, FLOWINFO, ADDR, SCOPEID
Cette fonction prend quatre arguments : un numéro de port, une structure
d'adresse IPv6 de 16 octets (telle que retournée par inet_pton),
toutes informations de flux spéciales, et toutes informations de portée
spécifiques.
Elle retourne une structure sockaddr_in6 complète avec ces arguments
empaquetés dans leurs champs corrects, ainsi que la famille AF_INET6.
unpack_sockaddr_in6 NOM
Cette fonction prend une structure sockaddr_in6 (telle que retournée par
pack_sockaddr_in6()) et retourne une liste de deux éléments :
le numéro de port et l'adresse IP de 16 octets.
Cette fonction produira une erreur ('croak') si elle détermine
qu'elle n'a pas reçu une structure IPv6.
unpack_sockaddr_in6_all NOM
Cette fonction prend une structure sockaddr_in6 (telle que retournée par
pack_sockaddr_in6()) et retourne une liste de quatre éléments :
le numéro de port, les informations de flux, l'adresse IP de 16 octets,
et les informations de portée.
Cette fonction produira une erreur ('croak') si elle détermine
qu'elle n'a pas reçu une structure IPv6.
gethostbyname2 NOM_HOTE, FAMILLE
getaddrinfo NOM_NOEUD, NOM_SERVICE, [FAMILLE, TYPE_SOCK, PROTOCOL, FLAGS]
Cette fonction convertit les noms de nœuds en adresses et les noms de services
en numéros de port.
Si l'argument NOM_NOEUD n'est pas une valeur fausse,
alors une recherche nom de nœud vers adresse est effectuée ;
sinon, une recherche nom de service vers numéro de port est effectuée.
Au moins un des arguments NOM_NOEUD et NOM_SERVICE doit avoir une valeur vraie.
Si la recherche réussit, une liste composée de multiples de
cinq éléments est retournée.
Chaque groupe de cinq éléments se compose de la famille d'adresses,
du type de socket, du protocole, de l'adresse IP de 16 octets et du nom
canonique (indéfini si le nom de nœud passé est déjà le nom canonique).
Les arguments FAMILLE, TYPE_SOCK, PROTOCOL et FLAGS sont tous optionnels.
Cette fonction produira une erreur ('croak') si elle détermine
qu'elle n'a pas reçu une structure IPv6.
Si la recherche échoue, la fonction retourne un scalaire unique.
Celui-ci contiendra la version chaîne de caractères de l'erreur en contexte chaîne,
et la valeur numérique en contexte numérique.
getnameinfo NOM, [FLAGS]
Cette fonction prend une structure d'adresse de socket. Si elle réussit, elle
retourne deux chaînes contenant le nom du nœud et le nom du service.
L'argument optionnel FLAGS contrôle le type de recherche effectuée.
Si la recherche échoue, la fonction retourne un scalaire unique.
Celui-ci contiendra la version chaîne de caractères de l'erreur en contexte chaîne,
et la valeur numérique en contexte numérique.
getipnodebyname HOTE, [FAMILLE, FLAGS]
Cette fonction prend un nom de nœud ou une chaîne d'adresse IP
et effectue une recherche sur ce nom (ou une conversion de la chaîne).
Elle retourne une liste de cinq éléments : le nom d'hôte canonique,
la famille d'adresses, la longueur en octets des adresses IP
retournées, une référence à une liste de structures d'adresses IP, et
une référence à une liste d'alias pour le nom d'hôte.
Les arguments FAMILLE et FLAGS sont optionnels.
Note : Cette fonction ne gère pas les identifiants de portée IPv6,
et doit être utilisée avec précaution.
De plus, cette fonction a été dépréciée dans la RFC3493.
La fonction getnameinfo doit être utilisée à la place.
getipnodebyaddr FAMILLE, ADRESSE
Cette fonction prend une famille d'adresses IP et une structure d'adresse IP
et effectue une recherche inversée sur cette adresse.
Elle retourne une liste de cinq éléments : le nom d'hôte canonique,
la famille d'adresses, la longueur en octets des adresses IP
retournées, une référence à une liste de structures d'adresses IP, et
une référence à une liste d'alias pour le nom d'hôte.
Note : Cette fonction ne gère pas les identifiants de portée IPv6,
et doit être utilisée avec précaution.
De plus, cette fonction a été dépréciée dans la RFC3493.
La fonction getaddrinfo doit être utilisée à la place.
gai_strerror NUMERO_ERREUR
Cette fonction retourne une chaîne correspondant au numéro d'erreur
passé en argument.
in6addr_any
Cette fonction retourne l'adresse joker de 16 octets.
in6addr_loopback
Cette fonction retourne l'adresse de bouclage (loopback) de 16 octets.
