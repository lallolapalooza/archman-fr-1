Description détaillée

La classe SoTranslate1Dragger fournit un mécanisme pour que l'utilisateur final puisse traduire sur un axe.

Voici à quoi ressemble le dragger avec sa géométrie par défaut à l'état inactif :

Utilisez ce dragger pour permettre à l'utilisateur final de votre application de traduire sur l'axe X, c'est-à-dire de se déplacer librement sur une ligne. (Utilisez un nœud de transformation devant le dragger pour le positionner et le réorienter afin de traduire sur n'importe quelle ligne.)

Voir aussi

SoTranslate2Dragger, SoDragPointDragger

SoSFVec3f SoTranslate1Dragger::translation
