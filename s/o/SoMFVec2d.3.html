Detailed Description

This field holds an array of SbVec2d vectors.

This field supports application data sharing through a setValuesPointer() method. See SoMField documentation for information on how to use this function.

See also

SbVec2d, SoSFVec2d Be aware that this class is an extension for Coin, and it is not available in the original SGI Open Inventor v2.1 API.

Since

Coin 2.5
