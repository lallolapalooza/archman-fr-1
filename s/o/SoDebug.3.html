Description détaillée

La classe SoDebug est une petite collection de fonctions liées au débogage.

Documentation des fonctions membres

const char * SoDebug::GetEnv (const char * var) [statique]

Ceci est un wrapper portable pour getenv.

coin_getenv()

void SoDebug::RTPrintf (const char * formatstr, ...) [statique]

Impression en temps réel conçue pour être utilisée lorsque l'utilisation de printf() standard causerait des problèmes de synchronisation.

NON IMPLÉMENTÉ. Actuellement, il se contente de transmettre à printf().

void SoDebug::NamePtr (const char * name, void * ptr) [statique]

Associe un nom à un pointeur arbitraire. Vous pouvez récupérer le nom du pointeur plus tard avec PtrName().

const char * SoDebug::PtrName (void * ptr) [statique]

Retourne le nom défini sur un pointeur avec NamePtr(). Si aucun nom n'a été défini, "<non nommé>" est retourné.
