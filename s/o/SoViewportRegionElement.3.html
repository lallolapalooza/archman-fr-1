NAME

SoViewportRegionElement - Element that stores the current viewport region.

SYNOPSIS

SbViewportRegion

SoViewportRegionElement::viewportRegion

[protected]

Detailed Description

This element is used to store the current viewport region. The viewport region is defined by the bounding box of the viewport. This element is automatically handled by the traversal system.
