Description détaillée

La classe SoTranslation est un type de nœud pour spécifier les translations de géométrie.

Pour simplement translater une géométrie dans un graphe de scène, vous pouvez utiliser ce type de nœud.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT :

Translation {
    translation 0 0 0
}
