Description détaillée

La classe SoReadError est utilisée pendant les opérations d'importation de modèles.

Pendant l'importation de fichiers de modèle, cette classe sera utilisée pour afficher tout message d'erreur ou d'avertissement.

Selon votre application, il peut être judicieux de définir vos propres gestionnaires de rappels pour SoReadError.

void SoReadError::setHandlerCallback (SoErrorCB *const function, void *const data) [static]

Cette méthode définit le gestionnaire de rappel pour les messages publiés via cette classe.

Note : Ceci ne remplacera pas le gestionnaire d'erreurs/messages de débogage pour les descendants, ceux-ci devront être remplacés en appelant la méthode correspondante de la classe descendante.

void SoReadError::post (const SoInput *const in, const char *const format, ...) [static]

Méthode utilisée par le code d'importation pour publier des messages d'erreur ou d'avertissement pour les fichiers de modèle qui ne sont pas entièrement compatibles avec le schéma de format.

Les messages sont envoyés avec des informations sur le numéro de ligne, la position dans le fichier, etc.
