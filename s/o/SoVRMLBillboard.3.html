Description Détaillée

La classe SoVRMLBillboard est utilisée pour faire pivoter la géométrie vers le point de vue.

La documentation détaillée de la classe SoVRMLBillboard est tirée verbatim de la norme VRML97 (ISO/IEC 14772-1:1997). Elle est la propriété du Web3D Consortium et est utilisée avec la permission du Conseil:

Billboard {  
eventIn      MFNode   addChildren  
eventIn      MFNode   removeChildren  
exposedField SFVec3f  axisOfRotation 0 1 0     # (-inf, inf)  
exposedField MFNode   children       []  
field        SFVec3f  bboxCenter     0 0 0     # (-inf, inf)  
field        SFVec3f  bboxSize       -1 -1 -1  # (0, inf) ou -1,-1,-1  
}

Le nœud Billboard est un nœud de groupement qui modifie son propre système de coordonnées afin que l'axe des coordonnées local du Billboard soit dirigé vers l'observateur. Le nœud Billboard a des enfants qui peuvent être d'autres nœuds enfants. Le champ axisOfRotation spécifie quel axe sera utilisé pour effectuer la rotation. Cet axe est défini dans le système de coordonnées local. Lorsque le champ axisOfRotation n'est pas (0, 0, 0), les étapes suivantes décrivent comment faire pivoter le billboard vers l'observateur:

•
a. Calcule le vecteur allant de l'origine du nœud Billboard à la position de l'observateur. Ce vecteur est appelé le vecteur billboard-vers-observateur.
•
b. Calcule le plan défini par l'axe axisOfRotation et le vecteur billboard-vers-observateur.
•
c. Fait pivoter l'axe Z local du billboard vers le plan de b., en effectuant une rotation autour de l'axe axisOfRotation.

Lorsque le champ axisOfRotation est défini sur (0, 0, 0), le cas spécial d'alignement de l'observateur est indiqué. Dans ce cas, l'objet sera pivoté de manière à ce que l'axe Y local du billboard soit parallèle à l'axe Y de l'observateur. Ce cas spécial est distingué en définissant l'axe axisOfRotation sur (0, 0, 0). Les étapes suivantes décrivent comment aligner l'axe Y du billboard sur l'axe Y de l'observateur:

•
d. Calcule le vecteur billboard-vers-observateur.
•
e. Fait pivoter l'axe Z du billboard de manière à ce qu'il soit colinéaire avec le vecteur billboard-vers-observateur et pointe vers la position de l'observateur.
•
f. Fait pivoter l'axe Y du billboard de manière à ce qu'il soit parallèle et orienté dans la même direction que l'axe Y de l'observateur.

Si l'axe axisOfRotation et le vecteur billboard-vers-observateur sont coïncidents, le plan ne peut pas être établi et la rotation résultante du billboard est indéfinie. Par exemple, si l'axe axisOfRotation est défini sur (0,1,0) (axe Y) et que l'observateur se déplace au-dessus du billboard et s'en approche directement le long de l'axe Y, les résultats sont indéfinis. Plusieurs instances de nœuds Billboard (DEF/USE) fonctionnent comme prévu : chaque instance est pivotée dans son propre système de coordonnées pour faire face à l'observateur. La sous-clause 4.6.5, Nœuds de groupement et enfants (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.5), décrit les champs et événements addChildren et removeChildren. Les champs bboxCenter et bboxSize spécifient une boîte englobante qui contient les nœuds enfants du Billboard. C'est un indicateur qui peut être utilisé pour l'optimisation. Les résultats sont indéfinis si la boîte englobante spécifiée est plus petite que la boîte englobante réelle des enfants à tout moment. La valeur par défaut de bboxSize est (-1,-1,-1), ce qui implique que la boîte englobante n'est pas spécifiée et doit être calculée par le navigateur si nécessaire. Une description de cela

NAME

SoVRMLBillboard -- VRML97 Billboard node

SYNOPSIS

Inherits SoVRMLParent.

Nodes:

    SoVRMLBillboard {
        field SoSFVec3f    axisOfRotation       0 1 0
        field SoSFVec3f    bboxCenter           0 0 0
        field SoSFVec3f    bboxSize             -1 -1 -1
        field SoSFNode     addChildren
        field SoSFNode     removeChildren
        field SoMFNode     children             []
    }

DESCRIPTION

The SoVRMLBillboard node is a grouping node that makes its children always face the viewer.

In VRML97, the behaviour of the Billboard node is defined by its children's geometry and the viewer's camera position. The node ensures that the geometry contained within it always rotates around the Y-axis (0, 1, 0) so that it is facing the viewpoint. If the axisOfRotation field is set to a non-zero vector, rotation will be around this axis instead of the Y-axis.

The bboxCenter and bboxSize fields specify the bounding box for the node. This is used for optimizing traversals.

VRML97 specification:

The VRML97 specification defines the Billboard node in section 4.6.3. The full specification is available at http://www.web3d.org/documents/specifications/14772/V2.0/part1/nodesRef.html#Billboard.

The fields bboxCenter and bboxSize fields is contained in 4.6.4, Bounding boxes (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.4),

The rest of this class documentation is not from the VRML97 standards documentation, but was written specifically for the Coin3D API documentation.


The following example VRML scene is a simple illustration of how SoVRMLBillboard::axisOfRotation constrains rotation around the given vector:

#VRML V2.0 utf8
Transform {
   translation -2 0 0
   children [
      Billboard {
        children [ Box { } ]
      }
   ]
}
Transform {
   translation 2 0 0
   children [
      Billboard {
        axisOfRotation 0 1 0
        children [ Box { } ]
      }
   ]
}
Transform {
   translation 0 -2 0
   children [ Box { size 10 0.1 10 } ]
}
