Description détaillée

La classe SoSFString est un conteneur pour un SbString.

Ce champ est utilisé lorsque les nœuds, les moteurs ou d'autres conteneurs de champs doivent stocker une chaîne unique.

Les champs de ce type stockent leur valeur dans le fichier sous la forme d'une chaîne entre guillemets.

Voir aussi : SoMFString
