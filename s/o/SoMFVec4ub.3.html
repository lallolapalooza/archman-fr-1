NOM

SoMFVec4ub - Un champ de vecteur de 4 octets non signés.

SYNTAX

Inherits SoMField.

See also SoSFVec4ub.

DESCRIPTION

Ce champ permet de stocker un tableau de vecteurs de quatre éléments.

Ce champ prend en charge le partage de données d'application par le biais de la méthode setValues(). Voir la documentation de SoMField pour plus d'informations sur l'utilisation de cette fonction.

Voir aussi

SbVec4ub, SoSFVec4ub Soyez conscient que cette classe est une extension pour Coin, et qu'elle n'est pas disponible dans l'API originale d'Open Inventor v2.1 de SGI.

Coin 2.5
