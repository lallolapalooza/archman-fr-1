Detailed Description

This class is an abstract base class for the shape hints elements. It defines the interface for all concrete shape hints elements.

Shape hints are used to optimize the traversal of scenegraphs containing shapes. For example, if all shapes in a subgraph are solid (as opposed to transparent), the traversal code can disable certain optimizations that are only applicable to transparent objects.

The elements derived from this class store the following pieces of state information:

  • Vertex ordering: Whether vertices of primitives are ordered clockwise or counter-clockwise.
  • Shape type: Whether primitives are simple (e.g. triangles, quadrilaterals) or complex (e.g. polygons).
  • Face type: Whether primitives are solid, partially transparent, or fully transparent.

The default values for these hints are:

  • Vertex ordering: CCW (counter-clockwise).
  • Shape type: UNKNOWN.
  • Face type: SOLID.

The methods getVertexOrdering, getShapeType, and getFaceType can be used to query the current shape hints from the traversal state.

The methods getContourRepetition and getContourRepetition are also available, but they are intended for internal use by the 3D rendering engine.
