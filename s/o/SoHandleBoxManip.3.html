Detailed Description

This manipulator is a combination of SoTranslateSphereManip, SoRotateCylinderManip and SoScaleBoxManip. It displays a box with handles on each corner and on each face. Handles on corners allow for scaling and rotation, while handles on faces allow for translation. The manipulator's transform is updated to reflect the user interactions.

This is a good general-purpose manipulator for interactively manipulating a translation, rotation, and scale transform.

The manipulator is implemented using a SoSeparator node. The geometry of the manipulator is rendered using a SoNodeKit, which is accessible via the SoHandleBoxManip.h include file.

To use the manipulator, you typically add it to a scene graph and connect its callbackList field to a list of callback functions that are invoked when the manipulator is interacted with.

Example:

    // Create the manipulator
    SoHandleBoxManip *handleBox = new SoHandleBoxManip();

    // Add it to the scene graph
    root->addChild(handleBox);

    // Connect a callback to update the scene
    handleBox->callbackList.addCallback(myUpdateFunction);

The myUpdateFunction would then be responsible for applying the transform from the manipulator to the object being manipulated.

SoHandleBoxManip - manipulateur pour une transformation de translation/rotation/échelle

Description détaillée

Ce manipulateur est une combinaison de SoTranslateSphereManip, SoRotateCylinderManip et SoScaleBoxManip. Il affiche une boîte avec des poignées à chaque coin et sur chaque face. Les poignées aux coins permettent la mise à l'échelle et la rotation, tandis que les poignées sur les faces permettent la translation. La transformation du manipulateur est mise à jour pour refléter les interactions de l'utilisateur.

C'est un manipulateur polyvalent pour manipuler interactivement une transformation de translation, de rotation et de mise à l'échelle.

Le manipulateur est implémenté en utilisant un nœud SoSeparator. La géométrie du manipulateur est rendue à l'aide d'un SoNodeKit, accessible via le fichier d'inclusion SoHandleBoxManip.h.

Pour utiliser le manipulateur, vous l'ajoutez généralement à un graphe de scène et connectez son champ callbackList à une liste de fonctions de rappel qui sont appelées lorsque le manipulateur est utilisé.

Exemple:

    // Créer le manipulateur
    SoHandleBoxManip *handleBox = new SoHandleBoxManip();

    // L'ajouter au graphe de scène
    root->addChild(handleBox);

    // Connecter une fonction de rappel pour mettre à jour la scène
    handleBox->callbackList.addCallback(myUpdateFunction);

La fonction myUpdateFunction serait alors responsable de l'application de la transformation du manipulateur à l'objet manipulé.
