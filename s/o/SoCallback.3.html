Description détaillée

La classe SoCallback est un type de nœud qui fournit un moyen d'établir des chaînes de rappels dans le graphe de scène.

L'insertion de nœuds SoCallback dans un graphe de scène permet aux développeurs d'applications de configurer des fonctions qui seront exécutées à certains points lors de la traversée.

La fonction de rappel sera exécutée lors de la traversée de toute action. Ainsi, si vous souhaitez exécuter votre code uniquement lors d'actions spécifiques, vous devez vérifier le type de l'action dans les arguments de la fonction de rappel.

Format de fichier/par défaut :

Callback {}

void SoCallback::setCallback (SoCallbackCB * function, void * userdata = NULL)

Définit la fonction à appeler lors de la traversée de ce nœud. La donnée utilisateur (userdata) sera passée comme premier argument de la fonction de rappel. Définir function à NULL supprime la fonction de rappel précédemment définie.

Si vous souhaitez un rappel uniquement pour une action spécifique, vous devez (dans votre fonction de rappel) vous souvenir de vérifier le type d'action qui a déclenché le rappel, par exemple comme ceci :

void mycallback(void * userdata, SoAction * action)
{
  if (action->isOfType(SoGLRenderAction::getClassTypeId())) {
    // faire quelque chose de spécifique au rendu avec GL ici.
  }
}

Remarque : Les nœuds SoCallback sous un Separator peuvent être mis en cache. Les nœuds mis en cache ne sont pas traversés et les rappels ne sont pas reçus. Si vous souhaitez vous assurer que votre rappel s'exécute à chaque fois que le graphe de scène est rendu, vous devez invalider le cache dans votre rappel :

void mycallback(void * userdata, SoAction * action)
{
  if (action->isOfType(SoGLRenderAction::getClassTypeId())) {
    SoCacheElement::invalidate(action->getState());
  }
}

Si vous souhaitez invalider tous les caches (par exemple, également le cache de la boîte englobante), vous pouvez le faire dans votre rappel :

void mycallback(void * userdata, SoAction * action)
{
  SoState * state = action->getState();
  if (state->isElementEnabled(SoCacheElement::getClassStackIndex())) {
    SoCacheElement::invalidate(state);
  }
}

Méthode d'action pour SoCallbackAction.

Elle met uniquement à jour l'état en fonction de la façon dont le nœud se comporte pour l'action de rendu, permettant au développeur d'utiliser SoCallbackAction pour extraire des informations du graphe de scène.

void SoCallback::GLRender (SoGLRenderAction * action) [virtual]

Méthode d'action pour SoGLRenderAction.

Celle-ci est appelée lors des traversées de rendu. Les nœuds qui influencent l'état de rendu ou qui souhaitent lancer des primitives de géométrie en OpenGL doivent redéfinir cette méthode.

void SoCallback::getBoundingBox (SoGetBoundingBoxAction * action) [virtual]

Méthode d'action pour SoGetBoundingBoxAction.

Calcule la boîte englobante et les coordonnées centrales pour le nœud et modifie les valeurs de l'action pour inclure la boîte englobante de ce nœud et pour déplacer le point central vers celui de ce nœud.

Les nœuds qui influencent la manière dont les nœuds de géométrie calculent leur boîte englobante peuvent également redéfinir cette méthode.

void SoCallback::copyContents (const SoFieldContainer * from, SbBool copyconnections) [protected], [virtual]

Makes a deep copy of all data of from into this instance, except external scene graph references if copyconnections is FALSE.

This is the method that should be overridden by extension node / engine / dragger / whatever subclasses which need to account for internal data that are not handled automatically.

For copying nodes from application code, you should not invoke this function directly, but rather call the SoNode::copy() function:

SoNode * mynewnode = templatenode->copy();

The same also goes for engines.

Make sure that when you override the copyContents() method in your extension class that you also make it call upwards to its parent superclass in the inheritance hierarchy, as copyContents() in for instance SoNode and SoFieldContainer does important work. It should go something like this:

void
MyCoinExtensionNode::copyContents(const SoFieldContainer * from,
                                  SbBool copyconnections)
{
  // let parent superclasses do their thing (copy fields, copy
  // instance name, etc.)
  SoNode::copyContents(from, copyconnections);
  // [..then copy internal data..]
}

Reimplemented from SoNode.
