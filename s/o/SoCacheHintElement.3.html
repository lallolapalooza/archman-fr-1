Detailed Description

This class is used to influence the caching behavior of 3D scenes. It allows the application to provide hints to the rendering engine about how it should optimize rendering, for example, by specifying whether a node or subgraph is likely to change or remain static.

By setting the cache hint, an application can potentially improve rendering performance by enabling the engine to reuse cached rendering results when appropriate.

Description détaillée

Cette classe est utilisée pour influencer le comportement de mise en cache des scènes 3D. Elle permet à l'application de fournir des indications au moteur de rendu sur la manière d'optimiser le rendu, par exemple, en spécifiant si un nœud ou un sous-graphe est susceptible de changer ou de rester statique.

En définissant l'indice de cache, une application peut potentiellement améliorer les performances de rendu en permettant au moteur de réutiliser les résultats de rendu mis en cache lorsque cela est approprié.
