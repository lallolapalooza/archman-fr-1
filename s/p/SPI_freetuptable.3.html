NOM

SPI_freetuptable - libérer un ensemble de lignes créé par SPI_execute ou une fonction similaire

SYNTAXE

void SPI_freetuptable(SPITupleTable * tuptable)

DESCRIPTION

SPI_freetuptable libère un ensemble de lignes créé par une fonction d'exécution de commande SPI précédente, telle que SPI_execute. Par conséquent, cette fonction est souvent appelée avec la variable globale SPI_tuptable comme argument.

Cette fonction est utile si une fonction C utilisant SPI doit exécuter plusieurs commandes et ne souhaite pas conserver les résultats des commandes précédentes jusqu'à la fin. Notez que tous les ensembles de lignes non libérés seront de toute façon libérés à SPI_finish. De plus, si une sous-transaction est démarrée puis annulée lors de l'exécution d'une fonction C utilisant SPI, SPI libère automatiquement tous les ensembles de lignes créés pendant l'exécution de la sous-transaction.

À partir de PostgreSQL 9.3, SPI_freetuptable contient une logique de protection pour éviter les demandes de suppression en double pour le même ensemble de lignes. Dans les versions précédentes, les suppressions en double entraînaient des plantages.

ARGUMENTS

SPITupleTable * tuptable

pointeur vers l'ensemble de lignes à libérer, ou NULL pour ne rien faire
