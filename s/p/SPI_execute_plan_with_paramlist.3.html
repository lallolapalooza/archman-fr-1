NOM

SPI_execute_plan_with_paramlist - exécuter une instruction préparée par SPI_prepare

SYNTAXE

int SPI_execute_plan_with_paramlist(SPIPlanPtr plan,
                                    ParamListInfo params,
                                    bool read_only,
                                    long count)

DESCRIPTION

SPI_execute_plan_with_paramlist exécute une instruction préparée par SPI_prepare. Cette fonction est équivalente à SPI_execute_plan, sauf que les informations sur les valeurs des paramètres à passer à la requête sont présentées différemment. La représentation ParamListInfo peut être pratique pour passer des valeurs qui sont déjà disponibles dans ce format. Elle prend également en charge l'utilisation d'ensembles de paramètres dynamiques via les fonctions de rappel spécifiées dans ParamListInfo.

Cette fonction est maintenant dépréciée en faveur de SPI_execute_plan_extended.

ARGUMENTS

SPIPlanPtr plan

instruction préparée (renvoyée par SPI_prepare)

ParamListInfo params

structure de données contenant les types et valeurs des paramètres ; NULL si aucun

bool read_only

vrai pour une exécution en lecture seule

long count

nombre maximal de lignes à renvoyer, ou 0 pour aucune limite

VALEUR DE RETOUR

La valeur de retour est la même qu'pour SPI_execute_plan.

SPI_processed et SPI_tuptable sont définis comme dans SPI_execute_plan en cas de succès.
