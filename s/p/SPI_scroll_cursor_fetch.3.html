SPI_SCROLL_CURSOR_FETCH(3) Documentation PostgreSQL 18.1 SPI_SCROLL_CURSOR_FETCH(3)

NOM

SPI_scroll_cursor_fetch - récupérer quelques lignes d'un curseur

SYNTAXE

void SPI_scroll_cursor_fetch(Portal portal, FetchDirection direction,
                             long count)

DESCRIPTION

SPI_scroll_cursor_fetch récupère quelques lignes d'un curseur. Ceci est équivalent à la commande SQL FETCH.

ARGUMENTS

Portal portal

portail contenant le curseur

FetchDirection direction

l'un de FETCH_FORWARD, FETCH_BACKWARD, FETCH_ABSOLUTE ou FETCH_RELATIVE

long count

nombre de lignes à récupérer pour FETCH_FORWARD ou FETCH_BACKWARD ; numéro de ligne absolu à récupérer pour FETCH_ABSOLUTE ; ou numéro de ligne relatif à récupérer pour FETCH_RELATIVE

VALEUR DE RETOUR

SPI_processed et SPI_tuptable sont définis comme dans SPI_execute en cas de succès.

NOTES

Voir la commande SQL FETCH(7) pour les détails de l'interprétation des paramètres direction et count.

Les directions autres que FETCH_FORWARD peuvent échouer si le plan du curseur n'a pas été créé avec l'option CURSOR_OPT_SCROLL.
