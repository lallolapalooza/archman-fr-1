NOM

SPI_fname - déterminer le nom de colonne pour le numéro de colonne spécifié

SYNOPIS

char * SPI_fname(TupleDesc rowdesc, int colnumber)

DESCRIPTION

SPI_fname renvoie une copie du nom de colonne pour la colonne spécifiée. (Vous pouvez utiliser pfree pour libérer la copie du nom lorsque vous n'en avez plus besoin.)

ARGUMENTS

TupleDesc rowdesc

description de la ligne d'entrée

int colnumber

numéro de colonne (commence à 1)

VALEUR DE RETOUR

Le nom de la colonne ; NULL si colnumber est hors plage. SPI_result défini sur SPI_ERROR_NOATTRIBUTE en cas d'erreur.
