Specio::Constraint::Structurable(3) Documentation Perl fournie par l'utilisateur Specio::Constraint::Structurable(3)

NOM

Specio::Constraint::Structurable - Une classe qui représente des contraintes structurables

VERSION

version 0.53

SYNOPSIS

my $tuple = t('Tuple');
my $tuple_of_str_int = $tuple->parameterize( of => [ t('Str'), t('Int') ] );

DESCRIPTION

Cette classe implémente l'API pour les types structurables tels que "Dict", "Map"< et "Tuple".

API

Cette classe implémente la même API que Specio::Constraint::Simple, avec quelques ajouts.

Specio::Constraint::Structurable->new(...)

Le constructeur de cette classe accepte deux paramètres supplémentaires :

  • parameterization_args_builder

    Il s'agit d'une sous-routine qui prend les valeurs passées à "of" et renvoie une table de hachage d'arguments nommés. Ces arguments seront ensuite passés à "structured_constraint_generator" ou "structured_inline_generator".

    Cela doit également effectuer une vérification des arguments pour s'assurer que les arguments passés sont valides. Par exemple, le type "Tuple" transforme le référence tableau passée à "of" en une table de hachage, en vérifiant au passage que l'appelant n'a pas fait de choses comme imbriquer des éléments optionnels et obligatoires ou mélanger des éléments optionnels et slurpy ensemble dans la définition.

    Ce paramètre est requis.

  • name_builder

    Il s'agit d'une sous-routine appelée pour générer un nom pour le type structuré lors de sa création. Elle sera appelée comme méthode sur l'objet "Specio::Constraint::Structurable". Elle recevra la table de hachage des arguments renvoyée par le "parameterization_args_builder".

    Ce paramètre est requis.

  • structured_constraint_generator

    Il s'agit d'une sous-routine qui génère une nouvelle sous-routine de contrainte lorsque le type est structuré.

    Elle sera appelée comme méthode sur le type et recevra la table de hachage des arguments renvoyée par le "parameterization_args_builder".

    Ce paramètre est mutuellement exclusif avec le paramètre "structured_inline_generator".

    Ce paramètre ou le paramètre "structured_inline_generator" est requis.

  • structured_inline_generator

    Il s'agit d'une sous-routine qui génère une nouvelle sous-routine de générateur en ligne lorsque le type est structuré.

    Elle sera appelée comme méthode sur l'objet Specio::Constraint::Structured lorsque cet objet doit générer une contrainte en ligne. Elle recevra le paramètre de type comme premier argument et le nom de la variable sous forme de chaîne comme second.

    Les arguments restants seront la table de hachage des paramètres renvoyée par le "parameterization_args_builder".

    Cela semble probablement assez confus, donc regarder les exemples dans le code de Specio::Library::Structured::* peut être utile.

    Ce paramètre est mutuellement exclusif avec le paramètre "structured_constraint_generator".

    Ce paramètre ou le paramètre "structured_constraint_generator" est requis.

$type->parameterize(...)

Cette méthode prend deux arguments. L'argument "of" doit être un objet qui implémente le rôle Specio::Constraint::Role::Interface, et il est requis.

L'autre argument, "declared_at", est optionnel. S'il n'est pas donné, un nouvel objet Specio::DeclaredAt est créé en utilisant une profondeur de pile d'appels de 1.

Cette méthode renvoie un nouvel objet Specio::Constraint::Structured.
