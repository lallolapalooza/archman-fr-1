NOM

SPI_register_relation - rendre une relation nommée éphémère disponible par son nom dans les requêtes SPI

SYNTAXE

int SPI_register_relation(EphemeralNamedRelation enr)

DESCRIPTION

SPI_register_relation rend une relation nommée éphémère, avec les informations associées, disponible pour les requêtes planifiées et exécutées via la connexion SPI actuelle.

ARGUMENTS

EphemeralNamedRelation enr

l'entrée du registre de la relation nommée éphémère

VALEUR DE RETOUR

Si l'exécution de la commande a réussi, la valeur non négative suivante sera retournée :

SPI_OK_REL_REGISTER

si la relation a été enregistrée avec succès par son nom

En cas d'erreur, l'une des valeurs négatives suivantes est retournée :

SPI_ERROR_ARGUMENT

si enr est NULL ou si son champ name est NULL

SPI_ERROR_UNCONNECTED

si appelé depuis une fonction C non connectée

SPI_ERROR_REL_DUPLICATE

si le nom spécifié dans le champ name de enr est déjà enregistré pour cette connexion
