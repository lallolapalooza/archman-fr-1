Specio::PartialDump(3) Documentation Perl fournie par l'utilisateur Specio::PartialDump(3)

NOM

Specio::PartialDump - Une copie partiellement éviscérée de Devel::PartialDump sans prérequis

VERSION

version 0.53

SYNOPSIS

use Specio::PartialDump qw( partial_dump );
partial_dump( { foo => 42 } );
partial_dump(qw( a b c d e f g ));
partial_dump( foo => 42, bar => [ 1, 2, 3 ], );

DESCRIPTION

Ceci est une copie de Devel::PartialDump avec tous les éléments OO et les prérequis supprimés. Vous pourriez vouloir utiliser ce module dans votre propre code pour générer des messages bien formatés lorsque une contrainte de type échoue.

Ce module exporte optionnellement une sous-routine, "partial_dump". Cette sous-routine accepte n'importe quel nombre d'arguments. Si elle reçoit plus d'un argument, elle supposera qu'on lui a donné soit une liste de paires clé/valeur (pour construire une table de hachage) soit une liste de valeurs (pour construire un tableau) et les affichera de manière appropriée. Les objets et les références sont transformés en chaînes de manière cohérente.
