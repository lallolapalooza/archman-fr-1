NOM

SPI_repalloc - réallouer de la mémoire dans le contexte de l'exécuteur supérieur

SYNOPSIS

void * SPI_repalloc(void * pointer, Size size)

DESCRIPTION

SPI_repalloc change la taille d'un segment de mémoire précédemment alloué à l'aide de SPI_palloc.

Cette fonction n'est plus différente de la simple fonction repalloc. Elle est conservée uniquement pour la compatibilité descendante du code existant.

ARGUMENTS

void * pointer

pointeur vers le stockage existant à modifier

Size size

taille en octets du stockage à allouer

VALEUR DE RETOUR

pointeur vers un nouvel espace de stockage de la taille spécifiée avec le contenu copié de la zone existante
