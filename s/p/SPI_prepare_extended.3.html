NOM

SPI_prepare_extended - prépare une instruction, sans l'exécuter encore

SYNOPSIS

SPIPlanPtr SPI_prepare_extended(const char * command,
                                const SPIPrepareOptions * options)

DESCRIPTION

SPI_prepare_extended crée et retourne une instruction préparée pour la commande spécifiée, mais n'exécute pas la commande. Cette fonction est équivalente à SPI_prepare, avec l'ajout que l'appelant peut spécifier des options pour contrôler l'analyse des références de paramètres externes, ainsi que d'autres aspects de l'analyse et de la planification des requêtes.

ARGUMENTS

const char * command

chaîne de commande

const SPIPrepareOptions * options

structure contenant des arguments optionnels

Les appelants doivent toujours initialiser à zéro toute la structure options, puis remplir les champs qu'ils souhaitent définir. Cela assure la compatibilité ascendante du code, car tous les champs ajoutés à la structure dans le futur seront définis pour se comporter de manière rétrocompatible s'ils sont à zéro. Les champs options actuellement disponibles sont :

ParserSetupHook parserSetup

fonction d'installation du hook d'analyseur

void * parserSetupArg

argument de passage pour parserSetup

RawParseMode parseMode

mode pour l'analyse brute ; RAW_PARSE_DEFAULT (zéro) produit le comportement par défaut

int cursorOptions

masque de bits entier des options de curseur ; zéro produit le comportement par défaut

VALEUR DE RETOUR

SPI_prepare_extended a les mêmes conventions de retour que SPI_prepare.
