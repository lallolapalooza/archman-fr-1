SPI_CURSOR_FIND(3) Documentation PostgreSQL 18.1 SPI_CURSOR_FIND(3)

NOM

SPI_cursor_find - trouver un curseur existant par son nom

SYNTAXE

Portal SPI_cursor_find(const char * name)

DESCRIPTION

SPI_cursor_find trouve un portail (portal) existant par son nom. Ceci est principalement utile pour résoudre un nom de curseur renvoyé sous forme de texte par une autre fonction.

ARGUMENTS

const char * name

nom du portail

VALEUR DE RETOUR

pointeur vers le portail portant le nom spécifié, ou NULL si aucun n'a été trouvé

NOTES

Attention, cette fonction peut renvoyer un objet Portal qui n'a pas de propriétés similaires à celles d'un curseur ; par exemple, il pourrait ne pas renvoyer de tuples. Si vous passez simplement le pointeur Portal à d'autres fonctions SPI, celles-ci peuvent se défendre contre de tels cas, mais la prudence est de mise lors de l'inspection directe du Portal.
