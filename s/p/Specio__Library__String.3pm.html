NOM

Specio::Library::String - Implémente des objets de contrainte de type pour certains types de chaînes courantes

VERSION

version 0.53

DESCRIPTION

Cette bibliothèque fournit des types de chaînes supplémentaires pour des cas courants.

NonEmptyStr

Une chaîne qui contient au moins un caractère.

SimpleStr

Une chaîne de 255 caractères ou moins, sans caractères d'espacement vertical.

NonEmptySimpleStr

Une chaîne non vide de 255 caractères ou moins, sans caractères d'espacement vertical.
