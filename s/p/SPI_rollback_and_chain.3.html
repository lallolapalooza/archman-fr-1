NOM

SPI_rollback, SPI_rollback_and_chain - annuler la transaction en cours

SYNTAXE

void SPI_rollback(void)
void SPI_rollback_and_chain(void)

DESCRIPTION

SPI_rollback annule la transaction en cours. Cela équivaut approximativement à exécuter la commande SQL ROLLBACK. Après l'annulation de la transaction, une nouvelle transaction est automatiquement démarrée en utilisant les caractéristiques par défaut de la transaction, afin que l'appelant puisse continuer à utiliser les fonctionnalités SPI.

SPI_rollback_and_chain est identique, mais la nouvelle transaction est démarrée avec les mêmes caractéristiques de transaction que celle qui vient de se terminer, comme avec la commande SQL ROLLBACK AND CHAIN.

Ces fonctions ne peuvent être exécutées que si la connexion SPI a été définie comme non atomique dans l'appel à SPI_connect_ext.
