NOM

SPI_is_cursor_plan - retourne vrai si une instruction préparée par SPI_prepare peut être utilisée avec SPI_cursor_open

SYNTAXE

bool SPI_is_cursor_plan(SPIPlanPtr plan)

DESCRIPTION

SPI_is_cursor_plan retourne vrai si une instruction préparée par SPI_prepare peut être passée comme argument à SPI_cursor_open, ou faux si ce n'est pas le cas. Les critères sont que le plan représente une seule commande et que cette commande retourne des tuples à l'appelant ; par exemple, SELECT est autorisé sauf s'il contient une clause INTO, et UPDATE est autorisé seulement s'il contient une clause RETURNING.

ARGUMENTS

SPIPlanPtr plan

instruction préparée (retournée par SPI_prepare)

VALEUR DE RETOUR

true ou false pour indiquer si le plan peut produire un curseur ou non, avec SPI_result mis à zéro. S'il n'est pas possible de déterminer la réponse (par exemple, si le plan est NULL ou invalide, ou s'il est appelé sans être connecté à SPI), alors SPI_result est mis à un code d'erreur approprié et false est retourné.
