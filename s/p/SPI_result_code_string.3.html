SPI_RESULT_CODE_STRING(3) Documentation PostgreSQL 18.1 SPI_RESULT_CODE_STRING(3)

NOM

SPI_result_code_string - retourne un code d'erreur sous forme de chaîne

SYNTAXE

const char * SPI_result_code_string(int code);

DESCRIPTION

SPI_result_code_string retourne une représentation sous forme de chaîne du code de résultat retourné par diverses fonctions SPI ou stocké dans SPI_result.

ARGUMENTS

int code

code de résultat

VALEUR DE RETOUR

Une représentation sous forme de chaîne du code de résultat.
