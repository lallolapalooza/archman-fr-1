SPI_PREPARE_CURSOR(3) Documentation PostgreSQL 18.1 SPI_PREPARE_CURSOR(3)

NOM

SPI_prepare_cursor - préparer une instruction, sans l'exécuter pour l'instant

SYNOPSIS

SPIPlanPtr SPI_prepare_cursor(const char * command, int nargs,
                              Oid * argtypes, int cursorOptions)

DESCRIPTION

SPI_prepare_cursor est identique à SPI_prepare, à l'exception près qu'elle permet également de spécifier le paramètre « options de curseur » de l'optimiseur. Il s'agit d'un masque de bits qui prend les valeurs indiquées dans nodes/parsenodes.h pour le champ options de DeclareCursorStmt. SPI_prepare prend toujours les options de curseur à zéro.

Cette fonction est maintenant obsolète en faveur de SPI_prepare_extended.

ARGUMENTS

const char * command

chaîne de commande

int nargs

nombre de paramètres d'entrée ($1, $2, etc.)

Oid * argtypes

pointeur vers un tableau contenant les OID des types de données des paramètres

int cursorOptions

masque de bits entier des options de curseur ; zéro produit le comportement par défaut

VALEUR DE RETOUR

SPI_prepare_cursor a les mêmes conventions de retour que SPI_prepare.

NOTES

Les bits utiles à définir dans cursorOptions incluent CURSOR_OPT_SCROLL, CURSOR_OPT_NO_SCROLL, CURSOR_OPT_FAST_PLAN, CURSOR_OPT_GENERIC_PLAN et CURSOR_OPT_CUSTOM_PLAN. Notez en particulier que CURSOR_OPT_HOLD est ignoré.
