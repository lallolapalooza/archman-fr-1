Specio__DeclaredAt(3pm)

Specio::DeclaredAt(3pm) Documentation Perl fournie par l'utilisateur Specio::DeclaredAt(3pm)

NOM

Specio::DeclaredAt - Une classe pour représenter où un type ou une coercition a été déclaré(e)

VERSION

version 0.53

SYNOPSIS

my $declared = Specio::DeclaredAt->new_from_caller(1);
print $declared->description;

DESCRIPTION

Cette classe fournit un wrapper léger autour de certaines valeurs de retour de la fonction intégrée de Perl "caller". Elle est utilisée en interne pour identifier où les types et les coercitions sont déclarés, ce qui est utile lors de la génération de messages d'erreur.

API

Cette classe fournit les méthodes suivantes.

Specio::DeclaredAt->new_from_caller($profondeur)

Étant donné une profondeur de pile d'appels, cette méthode renvoie un nouvel objet "Specio::DeclaredAt".

$declared_at->package, $declared_at->filename, $declared_at->line

Renvoie les informations de la pile d'appels enregistrées lors de la création de l'objet. Ces valeurs sont toujours renseignées.

$declared_at->subroutine

Renvoie la sous-routine de la pile d'appels. Il peut s'agir d'un "udnef"

$declared_at->has_subroutine

Renvoie vrai s'il y a un nom de sous-routine associé à cet objet.

$declared_at->description

Combine toutes les informations en une seule chaîne comme "déclaré dans le paquet Foo::Bar (.../Foo/Bar.pm) à la ligne 42 dans la sous-routine nommée blah".
