Specio::Library::Perl(3) Documentation Perl Contribuée par les Utilisateurs Specio::Library::Perl(3)

NOM

Specio::Library::Perl - Implémente des objets de contrainte de type pour certaines choses courantes du langage Perl

VERSION

version 0.53

DESCRIPTION

Cette bibliothèque fournit des types de chaînes de caractères supplémentaires pour des cas courants.

PackageName

Un nom de paquet valide. Contrairement à la contrainte "ClassName" de la bibliothèque Specio::Library::Builtins, ce paquet n'a pas besoin d'être chargé.

Ce type autorise les caractères Unicode.

ModuleName

Identique à "PackageName".

DistName

Un nom de distribution valide comme "DBD-Pg". En gros, c'est la même chose qu'un nom de paquet où les doubles deux-points sont remplacés par des tirets. Notez qu'il existe des noms de distribution historiques qui ne correspondent pas à ce modèle, comme "CGI.pm".

Ce type autorise les caractères Unicode.

Identifier

Un identifiant est quelque chose qui pourrait être utilisé comme nom de symbole ou autre identifiant (descripteur de fichier, descripteur de répertoire, nom de sous-routine, nom de format ou étiquette). C'est ce que vous mettez après le sigil (signe dollar, signe arobase, signe pourcent) dans un nom de variable. Généralement, c'est un ensemble de caractères alphanumériques ne commençant pas par un chiffre.

Ce type autorise les caractères Unicode.

SafeIdentifier

C'est exactement comme un "Identifier", mais il exclut les variables d'un seul caractère, le trait de soulignement ("_"), "a" et "b", car ce sont des variables spéciales pour l'interpréteur Perl.

LaxVersionStr et StrictVersionStr

Les chaînes de caractères de version laxistes et strictes utilisent les méthodes is_lax et is_strict de "version" pour vérifier si la chaîne donnée serait une version laxiste ou stricte valide. version::Internals couvre les détails, mais en gros : les versions laxistes sont tout ce que vous pouvez faire, et les strictes omettent plusieurs utilisations à éviter.
