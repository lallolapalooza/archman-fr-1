NOM

Specio::Library::Builtins - Implémente des objets de contrainte de type pour les types intégrés de Perl

VERSION

version 0.53

DESCRIPTION

Cette bibliothèque fournit un ensemble de types parallèles à ceux fournis par Moose.

Les types sont dans la hiérarchie suivante

Item
    Bool
    Maybe (de `a)
    Undef
    Defined
        Value
            Str
                Num
                    Int
                ClassName
        Ref
            ScalarRef (de `a)
            ArrayRef (de `a)
            HashRef (de `a)
            CodeRef
            RegexpRef
            GlobRef
            FileHandle
            Object

Item

Accepte toute valeur

Bool

Accepte une non-référence qui est "undef", une chaîne vide, 0, ou 1. Elle accepte également tout objet qui surcharge la booléification.

Maybe (de `a)

Un type paramétrable qui accepte "undef" ou le type "`a". S'il n'est pas paramétré, ce type acceptera n'importe quelle valeur.

Undef

N'accepte que "undef".

Value

Accepte toute valeur non-référence.

Str

Accepte toute valeur non-référence ou un objet qui surcharge la conversion en chaîne.

Num

Accepte presque les mêmes valeurs que "Scalar::Util::looks_like_number", mais n'accepte pas les nombres avec des espaces avant ou après, les infinis, ou NaN. Accepte également un objet qui surcharge la conversion numérique.

Int

Accepte toute valeur entière, ou un objet qui surcharge la conversion numérique et qui se numifie en un entier.

ClassName

Accepte toute valeur qui réussit "Str", où la chaîne est un paquet chargé.

Ref

Accepte toute référence.

ScalarRef (de `a)

Accepte une référence scalaire ou un objet qui surcharge le déréférencement scalaire. Si paramétrée, la valeur déréférencée doit être de type "`a".

ArrayRef (de `a)

Accepte une référence de tableau ou un objet qui surcharge le déréférencement de tableau. Si paramétrée, les valeurs dans le tableau doivent être de type "`a".

HashRef (de `a)

Accepte une référence de hachage ou un objet qui surcharge le déréférencement de hachage. Si paramétrée, les valeurs dans le hachage doivent être de type "`a".

CodeRef

Accepte une référence de code (sub) ou un objet qui surcharge le déréférencement de code.

RegexpRef

Accepte un objet regex créé par "qr//" ou un objet qui surcharge l'interpolation regex.

GlobRef

Accepte une référence glob ou un objet qui surcharge le déréférencement glob.

FileHandle

Accepte une référence glob qui est un descripteur de fichier ouvert, tout objet "IO::Handle" ou sous-classe, ou un objet qui surcharge le déréférencement glob et renvoie une référence glob qui est un descripteur de fichier ouvert.

Object

Accepte tout objet béni.
