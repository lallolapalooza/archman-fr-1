NOM

Specio::Constraint::Intersection - Une classe pour les contraintes d'intersection

VERSION

version 0.53

SYNOPSIS

my $type = Specio::Constraint::Untion->new(...);

DESCRIPTION

Ceci est une classe de contrainte de type spécialisée pour les intersections, qui permettra une valeur qui correspond à chacun de plusieurs types distincts.

API

Cette classe fournit toutes les mêmes méthodes que Specio::Constraint::Simple, avec quelques différences :

Specio::Constraint::Intersection->new( ... )

Le paramètre "parent" est ignoré s'il est passé, car il est toujours "undef".

Les paramètres "inline_generator" et "constraint" sont également ignorés. Cette classe fournit sa propre sous-routine de génération en ligne par défaut.

Enfin, cette classe requiert un paramètre supplémentaire, "of". Il doit s'agir d'un tableau de références vers des objets de type.

$union->of

Retourne une référence de tableau des types individuels qui composent cette intersection.

ROLES

Cette classe implémente les rôles Specio::Constraint::Role::Interface et Specio::Role::Inlinable.
