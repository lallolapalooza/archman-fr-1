SPI_execute_plan(3)

Paquet: postgresql

Licences: PostgreSQL

SPI_EXECUTE_PLAN(3) Documentation PostgreSQL 18.1 SPI_EXECUTE_PLAN(3)

NOM

SPI_execute_plan - exécute une requête préparée par SPI_prepare

SYNTAXE

int SPI_execute_plan(SPIPlanPtr plan, Datum * values, const char * nulls,
                     bool read_only, long count)

DESCRIPTION

SPI_execute_plan exécute une requête préparée par SPI_prepare ou l'une de ses variantes. read_only et count ont la même interprétation que dans SPI_execute.

ARGUMENTS

SPIPlanPtr plan

requête préparée (retournée par SPI_prepare)

Datum * values

Un tableau des valeurs de paramètres réelles. Doit avoir la même longueur que le nombre d'arguments de la requête.

const char * nulls

Un tableau décrivant quels paramètres sont NULL. Doit avoir la même longueur que le nombre d'arguments de la requête.

Si nulls est NULL alors SPI_execute_plan suppose qu'aucun paramètre n'est NULL. Autrement, chaque entrée du tableau nulls devrait être ' ' si la valeur du paramètre correspondant est non-NULL, ou 'n' si la valeur du paramètre correspondant est NULL. (Dans ce dernier cas, la valeur réelle dans l'entrée values correspondante n'a pas d'importance.) Notez que nulls n'est pas une chaîne de caractères, juste un tableau : il n'a pas besoin d'un terminateur '\0'.

bool read_only

true pour une exécution en lecture seule

long count

nombre maximum de lignes à retourner, ou 0 pour aucune limite

VALEUR DE RETOUR

La valeur de retour est la même que pour SPI_execute, avec les résultats d'erreur (négatifs) supplémentaires possibles suivants :

SPI_ERROR_ARGUMENT

si plan est NULL ou invalide, ou count est inférieur à 0

SPI_ERROR_PARAM

si values est NULL et plan a été préparé avec des paramètres

SPI_processed et SPI_tuptable sont définis comme dans SPI_execute en cas de succès.
