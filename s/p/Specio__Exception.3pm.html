Specio::Exception(3) Documentation Perl fournie par la communauté Specio::Exception(3)

NOM

Specio::Exception - Une classe d'exception pour les échecs de contraintes de type

VERSION

version 0.53

SYNOPSIS

use Try::Tiny;
try {
    $type->validate_or_die($value);
}
catch {
    if ( $_->isa('Specio::Exception') ) {
        print $_->message, "\n";
        print $_->type->name, "\n";
        print $_->value, "\n";
    }
};

DESCRIPTION

Cette classe d'exception est levée par Specio lorsqu'une vérification de type échoue. Elle émule l'API de Throwable::Error, mais n'utilise pas ce module afin d'éviter d'ajouter une dépendance sur Moo.

API

Cette classe fournit les méthodes suivantes :

$exception->message

Le message d'erreur associé à l'exception.

$exception->stack_trace

Un objet Devel::StackTrace pour l'exception.

$exception->type

L'objet de contrainte de type contre lequel la valeur a échoué.

$exception->value

La valeur qui n'a pas satisfait la vérification de type.

$exception->as_string

L'exception sous forme de chaîne de caractères. Cela inclut la méthode et la trace de la pile.

OVERLOADING

Cette classe surcharge la stringification pour appeler la méthode "as_string".
