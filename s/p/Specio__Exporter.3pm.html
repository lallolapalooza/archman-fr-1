NOM

Specio::Exporter - Classe de base pour les bibliothèques de types

VERSION

version 0.53

SYNOPSIS

package MyApp::Type::Library;
use parent 'Specio::Exporter';
use Specio::Declare;
declare( ... );
# plus de types ici
package MyApp::Foo;
use MyApp::Type::Library

DESCRIPTION

Hériter de ce paquet fait de votre paquet un exportateur de types. Par défaut, les types définis dans un paquet ne sont jamais visibles en dehors du paquet. Lorsque vous héritez de ce paquet, tous les types que vous définissez en interne deviennent disponibles par exportation.

Les types exportés sont disponibles via la sous-routine "t" du paquet importateur.

Par défaut, les types que votre paquet importe ne sont pas ré-exportés :

package MyApp::Type::Library;
use parent 'Specio::Exporter';
use Specio::Declare;
use Specio::Library::Builtins;

Dans ce cas, les types fournis par Specio::Library::Builtins ne sont pas exportés vers les paquets qui font "use MyApp::Type::Library".

Vous pouvez explicitement demander la ré-exportation de types :

package MyApp::Type::Library;
use parent 'Specio::Exporter';
use Specio::Declare;
use Specio::Library::Builtins -reexport;

Dans ce cas, les paquets qui font "use MyApp::Type::Library" recevront tous les types de Specio::Library::Builtins ainsi que tous les types définis dans "MyApp::Type::Library".

EXPORTATIONS ADDITIONNELLES

Si vous souhaitez exporter des sous-routines supplémentaires depuis un paquet dont le parent est "Specio::Exporter", définissez une sous-routine nommée "_also_export". Cette sous-routine doit retourner une liste de sous-routines définies dans votre paquet qui doivent également être exportées. Ces sous-routines seront exportées inconditionnellement vers tout paquet qui utilise votre paquet.

COMBINER DES BIBLIOTHÈQUES AVEC Specio::Subs

Vous pouvez combiner le chargement de bibliothèques avec la génération de sous-routines à l'aide de Specio::Subs en utilisant "_also_export" et "Specio::Subs::subs_installed_into" :

package My::Library;
use My::Library::Internal -reexport;
use Specio::Library::Builtins -reexport;
use Specio::Subs qw( My::Library::Internal Specio::Library::Builtins );
sub _also_export {
    return Specio::Subs::subs_installed_into(__PACKAGE__);
}
