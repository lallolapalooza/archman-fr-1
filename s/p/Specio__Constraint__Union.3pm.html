NOM

Specio::Constraint::Union - Une classe pour les contraintes d'union

VERSION

version 0.53

SYNTAXE

my $type = Specio::Constraint::Untion->new(...);

DESCRIPTION

Ceci est une classe spécialisée de contrainte de type pour les unions, qui permettra une valeur correspondant à l'un quelconque de plusieurs types distincts.

API

Cette classe fournit toutes les mêmes méthodes que Specio::Constraint::Simple, avec quelques différences :

Specio::Constraint::Union->new( ... )

Le paramètre "parent" est ignoré s'il est passé, car il est toujours "undef".

Les paramètres "inline_generator" et "constraint" sont également ignorés. Cette classe fournit sa propre référence de sous-routine de génération en ligne par défaut.

Enfin, cette classe nécessite un paramètre supplémentaire, "of". Il doit s'agir d'un tableau de références d'objets de type.

$union->of

Retourne une référence de tableau des types individuels qui composent cette union.

ROLES

Cette classe utilise les rôles Specio::Constraint::Role::Interface et Specio::Role::Inlinable.
