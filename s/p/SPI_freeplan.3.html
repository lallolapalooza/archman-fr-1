SPI_FREEPLAN(3) Documentation PostgreSQL 18.1 SPI_FREEPLAN(3)

NOM

SPI_freeplan - libérer une instruction préparée précédemment sauvegardée

SYNOPSIS

int SPI_freeplan(SPIPlanPtr plan)

DESCRIPTION

SPI_freeplan libère une instruction préparée précédemment renvoyée par SPI_prepare ou sauvegardée par SPI_keepplan ou SPI_saveplan.

ARGUMENTS

SPIPlanPtr plan

pointeur vers l'instruction à libérer

VALEUR DE RETOUR

0 en cas de succès ; SPI_ERROR_ARGUMENT si plan est NULL ou invalide
