NOM

SPI_saveplan - sauvegarder une instruction préparée

SYNTAXE

SPIPlanPtr SPI_saveplan(SPIPlanPtr plan)

DESCRIPTION

SPI_saveplan copie une instruction passée (préparée par SPI_prepare) dans une mémoire qui ne sera ni libérée par SPI_finish, ni par le gestionnaire de transactions, et renvoie un pointeur vers l'instruction copiée. Cela vous donne la possibilité de réutiliser des instructions préparées lors des invocations ultérieures de votre fonction C dans la session actuelle.

ARGUMENTS

SPIPlanPtr plan

l'instruction préparée à sauvegarder

VALEUR DE RETOUR

Pointeur vers l'instruction copiée ; ou NULL en cas d'échec. En cas d'erreur, SPI_result est défini comme suit :

SPI_ERROR_ARGUMENT

si plan est NULL ou invalide

SPI_ERROR_UNCONNECTED

si appelé depuis une fonction C non connectée

NOTES

L'instruction passée à l'origine n'est pas libérée, vous pourriez donc souhaiter exécuter SPI_freeplan dessus pour éviter les fuites de mémoire jusqu'à SPI_finish.

Dans la plupart des cas, SPI_keepplan est préférable à cette fonction, car elle obtient des résultats largement similaires sans avoir besoin de copier physiquement les structures de données de l'instruction préparée.
