SPI_EXECP(3) Documentation PostgreSQL 18.1 SPI_EXECP(3)

NOM

SPI_execp - exécuter une instruction en mode lecture/écriture

SYNTAXE

int SPI_execp(SPIPlanPtr plan, Datum * values, const char * nulls, long count)

DESCRIPTION

SPI_execp est identique à SPI_execute_plan, le paramètre read_only de ce dernier étant toujours considéré comme faux.

ARGUMENTS

SPIPlanPtr plan

planification préparée (renvoyée par SPI_prepare)

Datum * values

Un tableau des valeurs de paramètres réelles. Doit avoir la même longueur que le nombre d'arguments de l'instruction.

const char * nulls

Un tableau décrivant quels paramètres sont nuls. Doit avoir la même longueur que le nombre d'arguments de l'instruction.

Si nulls est NULL, alors SPI_execp suppose qu'aucun paramètre n'est nul. Sinon, chaque entrée du tableau nulls doit être ' ' si la valeur du paramètre correspondant n'est pas nulle, ou 'n' si la valeur du paramètre correspondant est nulle. (Dans ce dernier cas, la valeur réelle dans l'entrée values correspondante n'a pas d'importance.) Notez que nulls n'est pas une chaîne de caractères texte, juste un tableau : il n'a pas besoin d'un terminateur '\0'.

long count

nombre maximum de lignes à renvoyer, ou 0 pour aucune limite

VALEUR DE RETOUR

Voir SPI_execute_plan.

SPI_processed et SPI_tuptable sont définis comme dans SPI_execute en cas de succès.
