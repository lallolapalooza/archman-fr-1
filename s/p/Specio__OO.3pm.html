NOM

Specio::OO - Une réimplémentation pathétiquement médiocre de Moo(se)

VERSION

version 0.53

DESCRIPTION

Specio ne peut pas dépendre de Moo ou Moose, donc ce module fournit une réimplémentation épouvantable d'une petite partie de leurs fonctionnalités.

SUPPORT

Les bugs peuvent être soumis à https://github.com/houseabsolute/Specio/issues.

SOURCE

Le dépôt de code source de Specio peut être trouvé à https://github.com/houseabsolute/Specio.
