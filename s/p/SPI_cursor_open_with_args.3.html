SPI_CURSOR_OPEN_WITH_ARGS(3) Documentation PostgreSQL 18.1 SPI_CURSOR_OPEN_WITH_ARGS(3)

NOM

SPI_cursor_open_with_args - configurer un curseur en utilisant une requête et des paramètres

SYNTAXE

Portal SPI_cursor_open_with_args(const char *name,
                                 const char *command,
                                 int nargs, Oid *argtypes,
                                 Datum *values, const char *nulls,
                                 bool read_only, int cursorOptions)

DESCRIPTION

SPI_cursor_open_with_args configure un curseur (en interne, un portail) qui exécutera la requête spécifiée. La plupart des paramètres ont la même signification que les paramètres correspondants de SPI_prepare_cursor et SPI_cursor_open.

Pour une exécution de requête unique, cette fonction doit être préférée à SPI_prepare_cursor suivi de SPI_cursor_open. Si la même commande doit être exécutée avec de nombreux paramètres différents, l'une ou l'autre méthode peut être plus rapide, en fonction du coût de la replanification par rapport à l'avantage des plans personnalisés.

Les données de paramètres passées seront copiées dans le portail du curseur, elles peuvent donc être libérées tant que le curseur existe.

Cette fonction est maintenant dépréciée au profit de SPI_cursor_parse_open, qui fournit une fonctionnalité équivalente en utilisant une API plus moderne pour gérer les paramètres de requête.

ARGUMENTS

const char * name

nom du portail, ou NULL pour laisser le système sélectionner un nom

const char * command

chaîne de commande

int nargs

nombre de paramètres d'entrée ($1, $2, etc.)

Oid * argtypes

un tableau de longueur nargs, contenant les OID des types de données des paramètres

Datum * values

un tableau de longueur nargs, contenant les valeurs réelles des paramètres

const char * nulls

un tableau de longueur nargs, décrivant quels paramètres sont nuls

Si nulls est NULL alors SPI_cursor_open_with_args suppose qu'aucun paramètre n'est nul. Sinon, chaque entrée du tableau nulls doit être ' ' si la valeur du paramètre correspondant n'est pas nulle, ou 'n' si la valeur du paramètre correspondant est nulle. (Dans ce dernier cas, la valeur réelle dans l'entrée values correspondante n'a pas d'importance.) Notez que nulls n'est pas une chaîne de caractères, juste un tableau : il n'a pas besoin d'un terminateur '\0'.

bool read_only

true pour une exécution en lecture seule

int cursorOptions

masque de bits entier des options du curseur ; zéro produit le comportement par défaut

VALEUR DE RETOUR

Pointeur vers le portail contenant le curseur. Notez qu'il n'y a pas de convention de retour d'erreur ; toute erreur sera signalée via elog.
