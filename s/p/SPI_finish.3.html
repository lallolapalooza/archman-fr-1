NOM

SPI_finish - déconnecter une fonction C du gestionnaire SPI

SYNTAXE

int SPI_finish(void)

DESCRIPTION

SPI_finish ferme une connexion existante au gestionnaire SPI. Vous devez appeler cette fonction après avoir terminé les opérations SPI nécessaires lors de l'invocation actuelle de votre fonction C. Vous n'avez cependant pas à vous soucier de cela si vous annulez la transaction via elog(ERROR). Dans ce cas, SPI se nettoiera automatiquement.

VALEUR DE RETOUR

SPI_OK_FINISH

si correctement déconnecté

SPI_ERROR_UNCONNECTED

si appelée depuis une fonction C non connectée
