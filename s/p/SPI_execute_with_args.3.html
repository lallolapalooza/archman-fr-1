SPI_EXECUTE_WITH_ARGS(3) Documentation PostgreSQL 18.1 SPI_EXECUTE_WITH_ARGS(3)

NOM

SPI_execute_with_args - exécuter une commande avec des paramètres hors ligne

SYNTAXE

int SPI_execute_with_args(const char *command,
                          int nargs, Oid *argtypes,
                          Datum *values, const char *nulls,
                          bool read_only, long count)

DESCRIPTION

SPI_execute_with_args exécute une commande qui peut contenir des références à des paramètres fournis extérieurement. Le texte de la commande fait référence à un paramètre sous la forme $n, et l'appel spécifie les types de données et les valeurs pour chaque symbole de ce type. read_only et count ont la même interprétation qu'en SPI_execute.

L'avantage principal de cette routine par rapport à SPI_execute est que les valeurs de données peuvent être insérées dans la commande sans nécessiter de guillemets/d'échappements fastidieux, et donc avec beaucoup moins de risques d'attaques par injection SQL.

Des résultats similaires peuvent être obtenus avec SPI_prepare suivi de SPI_execute_plan ; cependant, lors de l'utilisation de cette fonction, le plan de requête est toujours personnalisé aux valeurs de paramètres spécifiques fournies. Pour l'exécution de requêtes une seule fois, cette fonction devrait être préférée. Si la même commande doit être exécutée avec de nombreux paramètres différents, l'une ou l'autre méthode peut être plus rapide, en fonction du coût de la replanification par rapport à l'avantage des plans personnalisés.

ARGUMENTS

const char * command

chaîne de commande

int nargs

nombre de paramètres d'entrée ($1, $2, etc.)

Oid * argtypes

un tableau de longueur nargs, contenant les OID des types de données des paramètres

Datum * values

un tableau de longueur nargs, contenant les valeurs de paramètres réelles

const char * nulls

un tableau de longueur nargs, décrivant quels paramètres sont nuls

Si nulls est NULL, SPI_execute_with_args suppose qu'aucun paramètre n'est nul. Sinon, chaque entrée du tableau nulls doit être ' ' si la valeur du paramètre correspondant n'est pas nulle, ou 'n' si la valeur du paramètre correspondant est nulle. (Dans ce dernier cas, la valeur réelle dans l'entrée values correspondante n'a pas d'importance.) Notez que nulls n'est pas une chaîne de caractères, juste un tableau : il n'a pas besoin d'un terminateur '\0'.

bool read_only

true pour une exécution en lecture seule

long count

nombre maximum de lignes à retourner, ou 0 pour aucune limite

VALEUR DE RETOUR

La valeur de retour est la même que pour SPI_execute.

SPI_processed et SPI_tuptable sont définis comme en SPI_execute en cas de succès.
