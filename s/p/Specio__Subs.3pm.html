Specio::Subs(3) Documentation Perl fournie par l'utilisateur Specio::Subs(3)

NOM

Specio::Subs - Créer des sous-programmes de validation et de coercition à partir de types Specio

VERSION

version 0.53

SYNTAXE

use Specio::Subs qw( Specio::Library::Builtins Specio::Library::Perl My::Lib );
if ( is_PackageName($var) ) { ... }
assert_Str($var);
my $person1 = to_Person($var);
my $person2 = force_Person($var);

DESCRIPTION

Ce module génère un ensemble de sous-programmes utiles de validation et de coercition pour tous les types définis dans une ou plusieurs bibliothèques.

Pour l'utiliser, importez simplement "Specio::Subs" en passant une liste d'un ou plusieurs noms de bibliothèques. Ce module chargera ces bibliothèques au besoin.

Si l'un des types de l'une des bibliothèques a un nom qui ne fonctionne pas comme partie d'un nom de sous-programme Perl, ce module lèvera une exception.

Si vous avez Sub::Util ou Sub::Name installé, l'un d'eux sera utilisé pour nommer les sous-programmes générés.

"EXPORTATIONS"

Les sous-programmes suivants sont créés dans le package d'importation :

est_$type($valeur)

Ce sous-programme retourne un booléen indiquant si la $valeur est valide pour le type.

assert_$type($valeur)

Ce sous-programme meurt si la $valeur n'est pas valide pour le type.

vers_$type($valeur)

Ce sous-programme tente de coercer la $valeur dans le type donné. S'il ne peut pas être coercé, il retourne la $valeur d'origine.

Ceci n'est créé que si le type a des coercions.

force_$type($valeur)

Ce sous-programme tente de coercer la $valeur dans le type donné, et meurt s'il ne peut pas le faire.

Ceci n'est créé que si le type a des coercions.

API ADDITIONNELLE

Ce module a un sous-programme nommé "subs_installed_into". Il n'est pas exporté mais peut être appelé par son nom entièrement qualifié. Il accepte un seul argument, un nom de package. Il retourne une liste de sous-programmes qu'il a générés et installés dans le package donné, le cas échéant.

Ceci existe pour faciliter l'écriture d'une bibliothèque de types qui combine d'autres bibliothèques et génère des sous-programmes d'aide à exporter en une seule fois.

Voir la documentation de Specio::Exporter pour plus de détails.
