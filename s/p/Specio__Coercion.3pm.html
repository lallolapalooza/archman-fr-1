Specio::Coercion(3) Documentation Perl fournie par l'utilisateur Specio::Coercion(3)

NOM

Specio::Coercion - Une classe représentant une coercition d'un type à un autre

VERSION

version 0.53

SYNOPSIS

my $coercion = $type->coercion_from_type('Int');
my $new_value = $coercion->coerce_value(42);
if ( $coercion->can_be_inlined() ) {
    my $code = $coercion->inline_coercion('$_[0]');
}

DESCRIPTION

Cette classe représente une coercition d'un type à un autre. Interneent, une coercition est un morceau de code qui prend une valeur d'un type et retourne une nouvelle valeur d'un autre type. Par exemple, une coercition de c<Num> vers "Int" pourrait arrondir un nombre à l'entier le plus proche et retourner cet entier.

Les coercions peuvent être implémentées soit comme une simple référence à une sous-routine, soit comme un générateur de sous-routine inline. L'utilisation d'un générateur inline est plus rapide mais plus complexe.

API

Cette classe fournit les méthodes suivantes.

Specio::Coercion->new( ... )

Cette méthode crée un nouvel objet de coercition. Elle accepte les paramètres nommés suivants :

  • from => $type

    Le type de départ de cette coercition. Le type doit être un objet qui implémente l'interface Specio::Constraint::Role::Interface.

    Ce paramètre est obligatoire.

  • to => $type

    Le type de destination de cette coercition. Le type doit être un objet qui implémente l'interface Specio::Constraint::Role::Interface.

    Ce paramètre est obligatoire.

  • coercion => sub { ... }

    Une référence à une sous-routine qui implémente la coercition. Celle-ci sera appelée comme une méthode sur l'objet et recevra un seul argument, la valeur à coercer.

    Elle doit retourner la nouvelle valeur.

    Ce paramètre est mutuellement exclusif avec "inline_generator".

    Obligatoire : Soit ce paramètre, soit le paramètre "inline_generator".

    Vous pouvez également passer cette option avec la clé "using" dans la liste des paramètres.

  • inline_generator => sub { ... }

    Ce doit être une référence à une sous-routine qui retourne une chaîne de caractères à un seul terme. Ce code ne doit pas se terminer par un point-virgule. Ce code doit implémenter la coercition.

    Le générateur sera appelé comme une méthode sur l'objet de coercition avec un seul argument. L'argument est le nom de la variable à होणार, quelque chose comme '$_[0]' ou '$var'.

    Ce paramètre est mutuellement exclusif avec "coercion".

    Obligatoire : Soit ce paramètre, soit le paramètre "coercion".

    Vous pouvez également passer cette option avec la clé "inline" dans la liste des paramètres.

  • inline_environment => {}

    Ce doit être une map de noms de variables (avec sigils) et de valeurs pour cette variable. Les valeurs doivent être des références aux valeurs des variables.

    Cet environnement sera utilisé lorsque la coercition sera compilée dans le cadre d'une sous-routine. Les variables nommées seront capturées sous forme de fermeture de calcul dans la sous-routine générée, en utilisant Eval::Closure.

    Il est très rare de devoir définir ceci dans le constructeur. Il est plus probable qu'une sous-classe spéciale de coercition ait besoin de fournir des valeurs qu'elle génère en interne.

    Ce paramètre a par défaut une map vide.

  • declared_at => $declared_at

    Ce paramètre doit être un objet de type Specio::DeclaredAt.

    Ce paramètre est obligatoire.

$coercion->from(), $coercion->to(), $coercion->declared_at()

Ces méthodes sont des accesseurs en lecture pour les attributs correspondants.

$coercion->description

Ceci retourne une chaîne décrivant la coercition. Elle inclut le nom du type de départ et de destination et où elle a été déclarée, vous donnant quelque chose comme 'coercion de Foo vers Bar déclarée dans le package My::Lib' (lib/My/Lib.pm) à la ligne 42'.

$coercion->coerce($value)

Étant donné une valeur du type de destination droit, retourne une nouvelle valeur du type de destination gauche.

Cette méthode ne vérifie pas réellement que les types des valeurs données ou retournées sont corrects.

$coercion->inline_coercion($var)

Étant donné un nom de variable comme '$_[0]', retourne une chaîne de caractères avec le code pour la coercition.

Note : cette méthode sera appelée si la coercition n'a pas de générateur inline.

$coercion->can_be_inlined()

Retourne vrai si la coercition a un générateur inline et si la contrainte concernée peut être mise en ligne. Ceci existe principalement pour le bénéfice de la méthode inline_coercion_and_check() de l'objet de contrainte de type.

$coercion->inline_environment()

Retourne une map définissant les variables qui doivent être capturées sous forme de fermeture lors de la mise en ligne de la coercition. Les clés sont les noms complets des variables comme '$foo' ou '@bar'. Les valeurs sont des références aux valeurs de type correspondant.

$coercion->clone()

Retourne un clone de cet objet.

$coercion->clone_with_new_to($new_to_type)

Retourne un clone de la coercition, en remplaçant le type de destination par un nouveau. Ceci est destiné à être utilisé lorsque le type de destination lui-même est cloné dans le cadre de l'importation de ce type. Vous devez vous assurer que le nouveau clone de la coercition a également le nouveau type.

ROLES

Cette classe implémente le rôle Specio::Role::Inlinable.
