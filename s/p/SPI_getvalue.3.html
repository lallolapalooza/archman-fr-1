NOM

SPI_getvalue - retourne la valeur sous forme de chaîne de caractères de la colonne spécifiée

SYNTAXE

char * SPI_getvalue(HeapTuple row, TupleDesc rowdesc, int colnumber)

DESCRIPTION

SPI_getvalue retourne la représentation sous forme de chaîne de caractères de la valeur de la colonne spécifiée.

Le résultat est retourné dans une mémoire allouée à l'aide de palloc. (Vous pouvez utiliser pfree pour libérer la mémoire lorsque vous n'en avez plus besoin.)

ARGUMENTS

HeapTuple row

ligne d'entrée à examiner

TupleDesc rowdesc

description de la ligne d'entrée

int colnumber

numéro de colonne (le comptage commence à 1)

VALEUR DE RETOUR

La valeur de la colonne, ou NULL si la colonne est nulle, colnumber est hors limites (SPI_result est défini sur SPI_ERROR_NOATTRIBUTE), ou aucune fonction de sortie n'est disponible (SPI_result est défini sur SPI_ERROR_NOOUTFUNC).
