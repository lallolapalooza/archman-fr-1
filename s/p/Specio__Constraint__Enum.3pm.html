NOM

Specio::Constraint::Enum - Une classe pour les contraintes qui exigent une chaîne correspondant à l'une des valeurs d'un ensemble

VERSION

version 0.53

SYNOPIS

my $type = Specio::Constraint::Enum->new(...);
print $_, "\n" pour @{ $type->values };

DESCRIPTION

Il s'agit d'une classe de contrainte de type spécialisée pour les types qui exigent une chaîne correspondant à l'une des valeurs d'une liste.

API

Cette classe fournit toutes les mêmes méthodes que Specio::Constraint::Simple, avec quelques différences :

Specio::Constraint::Enum->new( ... )

Le paramètre "parent" est ignoré s'il est passé, car il est toujours défini sur le type "Str".

Les paramètres "inline_generator" et "constraint" sont également ignorés. Cette classe fournit sa propre référence de sous-routine de génération inline par défaut.

Enfin, cette classe nécessite un paramètre supplémentaire, "values". Il doit s'agir d'un tableau de chaînes valides pour le type.

$enum->values

Retourne une référence de tableau des valeurs valides pour le type.

ROLES

Cette classe implémente les rôles Specio::Constraint::Role::Interface et Specio::Role::Inlinable.
