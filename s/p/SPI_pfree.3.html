NOM

SPI_pfree - libérer de la mémoire dans le contexte de l'exécuteur supérieur

SYNTAXE

void SPI_pfree(void * pointeur)

DESCRIPTION

SPI_pfree libère la mémoire précédemment allouée à l'aide de SPI_palloc ou SPI_repalloc.

Cette fonction n'est plus différente de la simple fonction pfree. Elle est conservée uniquement pour la compatibilité descendante avec le code existant.

ARGUMENTS

void * pointeur

pointeur vers le stockage existant à libérer
