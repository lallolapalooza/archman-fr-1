NOM

SPI_connect, SPI_connect_ext - connecter une fonction C au gestionnaire SPI

SYNOPIS

int SPI_connect(void)
int SPI_connect_ext(int options)

DESCRIPTION

SPI_connect ouvre une connexion d'une invocation de fonction C au gestionnaire SPI. Vous devez appeler cette fonction si vous souhaitez exécuter des commandes via SPI. Certaines fonctions utilitaires SPI peuvent être appelées depuis des fonctions C non connectées.

SPI_connect_ext fait de même mais possède un argument qui permet de passer des indicateurs d'options. Actuellement, les valeurs d'options suivantes sont disponibles :

SPI_OPT_NONATOMIC

Définit la connexion SPI comme non atomique, ce qui signifie que les appels de contrôle de transaction (SPI_commit, SPI_rollback) sont autorisés. Sinon, l'appel de ces fonctions entraînera une erreur immédiate.

SPI_connect() est équivalent à SPI_connect_ext(0).

VALEUR DE RETOUR

SPI_OK_CONNECT

en cas de succès

Le fait que ces fonctions retournent un int et non un void est historique. Tous les cas d'échec sont signalés via ereport ou elog. (Dans les versions antérieures à PostgreSQL v10, certains échecs, mais pas tous, étaient signalés avec une valeur de résultat SPI_ERROR_CONNECT.)
