NOM

SPI_commit, SPI_commit_and_chain - valider la transaction courante

SYNTAXE

void SPI_commit(void)
void SPI_commit_and_chain(void)

DESCRIPTION

SPI_commit valide la transaction courante. Cela équivaut approximativement à exécuter la commande SQL COMMIT. Une fois la transaction validée, une nouvelle transaction est automatiquement démarrée avec les caractéristiques de transaction par défaut, de sorte que l'appelant puisse continuer à utiliser les fonctions SPI. En cas d'échec lors de la validation, la transaction courante est annulée et une nouvelle transaction est démarrée, après quoi l'erreur est levée comme d'habitude.

SPI_commit_and_chain est identique, mais la nouvelle transaction est démarrée avec les mêmes caractéristiques de transaction que celle qui vient de se terminer, comme avec la commande SQL COMMIT AND CHAIN.

Ces fonctions ne peuvent être exécutées que si la connexion SPI a été définie comme non atomique dans l'appel à SPI_connect_ext.
