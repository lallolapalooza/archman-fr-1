NOM

Specio::Constraint::Structured - Une classe qui représente des contraintes structurées

VERSION

version 0.53

SYNOPSIS

my $tuple = t('Tuple');
my $tuple_of_str_int = $tuple->parameterize( of => [ t('Str'), t('Int') ] );
my $parent = $tuple_of_str_int->parent; # retourne Tuple
my $parameters = $arrayref_of_int->parameters; # retourne { of => [ t('Str'), t('Int') ] }

DESCRIPTION

Cette classe implémente l'API pour les types structurés.

API

Cette classe implémente la même API que Specio::Constraint::Simple, avec quelques ajouts.

Specio::Constraint::Structured->new(...)

Le constructeur de cette classe accepte deux paramètres supplémentaires :

  • parent

    Doit être l'objet Specio::Constraint::Structurable à partir duquel cet objet a été créé.

    Ce paramètre est requis.

  • parameters

    C'est le hashref des paramètres pour le type structuré. Ce sont les paramètres retournés par le "parameterization_args_builder" du type "Structurable". La forme exacte de ce hashref variera pour chaque type structuré.

    Ce paramètre est requis.

$type->parameters

Retourne le hashref qui a été passé au constructeur.
