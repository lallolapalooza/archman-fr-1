SPI_MODIFYTUPLE(3) Documentation PostgreSQL 18.1 SPI_MODIFYTUPLE(3)

NOM

SPI_modifytuple - crée une ligne en remplaçant des champs sélectionnés d'une ligne donnée

SYNTAXE

HeapTuple SPI_modifytuple(Relation rel, HeapTuple row, int ncols,
                          int * colnum, Datum * values, const char * nulls)

DESCRIPTION

SPI_modifytuple crée une nouvelle ligne en substituant de nouvelles valeurs à des colonnes sélectionnées, en copiant les colonnes de la ligne originale aux autres positions. La ligne d'entrée n'est pas modifiée. La nouvelle ligne est retournée dans le contexte de l'exécuteur supérieur.

Cette fonction ne peut être utilisée que lorsque l'on est connecté à SPI. Sinon, elle retourne NULL et définit SPI_result sur SPI_ERROR_UNCONNECTED.

ARGUMENTS

Relation rel

Utilisé uniquement comme source du descripteur de ligne pour la ligne. (Passer une relation plutôt qu'un descripteur de ligne est un défaut de conception.)

HeapTuple row

ligne à modifier

int ncols

nombre de colonnes à changer

int * colnum

un tableau de longueur ncols, contenant les numéros des colonnes à changer (les numéros de colonne commencent à 1)

Datum * values

un tableau de longueur ncols, contenant les nouvelles valeurs pour les colonnes spécifiées

const char * nulls

un tableau de longueur ncols, décrivant quelles nouvelles valeurs sont nulles.

Si nulls est NULL, alors SPI_modifytuple suppose qu'aucune nouvelle valeur n'est nulle. Sinon, chaque entrée du tableau nulls doit être ' ' si la nouvelle valeur correspondante est non nulle, ou 'n' si la nouvelle valeur correspondante est nulle. (Dans ce dernier cas, la valeur réelle dans l'entrée values correspondante n'a pas d'importance.) Notez que nulls n'est pas une chaîne de caractères, juste un tableau : il n'a pas besoin d'un terminateur '\0'.

VALEUR DE RETOUR

nouvelle ligne avec modifications, allouée dans le contexte de l'exécuteur supérieur, ou NULL en cas d'erreur (voir SPI_result pour une indication d'erreur)

En cas d'erreur, SPI_result est défini comme suit :

SPI_ERROR_ARGUMENT

si rel est NULL, ou si row est NULL, ou si ncols est inférieur ou égal à 0, ou si colnum est NULL, ou si values est NULL.

SPI_ERROR_NOATTRIBUTE

si colnum contient un numéro de colonne invalide (inférieur ou égal à 0 ou supérieur au nombre de colonnes dans row)

SPI_ERROR_UNCONNECTED

si SPI n'est pas actif
