SPI_START_TRANSACTION(3) Documentation PostgreSQL 18.1 SPI_START_TRANSACTION(3)

NOM

SPI_start_transaction - fonction obsolète

SYNTAXE

void SPI_start_transaction(void)

DESCRIPTION

SPI_start_transaction ne fait rien et existe uniquement pour la compatibilité du code avec les versions antérieures de PostgreSQL. Elle était auparavant requise après l'appel de SPI_commit ou SPI_rollback, mais maintenant ces fonctions démarrent une nouvelle transaction automatiquement.
