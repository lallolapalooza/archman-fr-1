NOM

SPI_cursor_open_with_paramlist - configurer un curseur à l'aide de paramètres

SYNTAXE

Portal SPI_cursor_open_with_paramlist(const char *name,
                                      SPIPlanPtr plan,
                                      ParamListInfo params,
                                      bool read_only)

DESCRIPTION

SPI_cursor_open_with_paramlist configure un curseur (interne, un portail) qui exécutera une requête préparée par SPI_prepare. Cette fonction est équivalente à SPI_cursor_open à la différence que les informations sur les valeurs des paramètres à passer à la requête sont présentées différemment. La représentation ParamListInfo peut être pratique pour passer des valeurs déjà disponibles sous ce format. Elle prend également en charge l'utilisation de jeux de paramètres dynamiques via des fonctions de rappel spécifiées dans ParamListInfo.

Les données de paramètres fournies seront copiées dans le portail du curseur, elles pourront donc être libérées tant que le curseur existe.

ARGUMENTS

const char * name

nom du portail, ou NULL pour laisser le système choisir un nom

SPIPlanPtr plan

requête préparée (retournée par SPI_prepare)

ParamListInfo params

structure de données contenant les types et valeurs des paramètres ; NULL si aucun

bool read_only

true pour une exécution en lecture seule

VALEUR DE RETOUR

Pointeur vers le portail contenant le curseur. Notez qu'il n'y a pas de convention de retour d'erreur ; toute erreur sera signalée via elog.
