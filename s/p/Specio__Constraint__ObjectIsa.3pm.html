NOM

Specio::Constraint::ObjectIsa - Une classe pour les contraintes qui exigent un objet héritant d'une classe spécifique

VERSION

version 0.53

SYNTAXE

my $type = Specio::Constraint::ObjectIsa->new(...);
print $type->class;

DESCRIPTION

Ceci est une classe de contrainte de type spécialisée pour les types qui exigent un objet héritant d'une classe spécifique.

API

Cette classe fournit toutes les méthodes de Specio::Constraint::Simple, avec quelques différences :

Specio::Constraint::ObjectIsa->new( ... )

Le paramètre "parent" est ignoré s'il est passé, car il est toujours défini sur le type "Defined".

Les paramètres "inline_generator" et "constraint" sont également ignorés. Cette classe fournit sa propre référence de sous-routine de génération en ligne par défaut.

Cette classe surcharge le générateur de message par défaut "message_generator" si aucun n'est fourni.

Enfin, cette classe requiert un paramètre supplémentaire, "class". Il doit s'agir d'un seul nom de classe.

$object_isa->class

Retourne le nom de la classe passé au constructeur.

ROLES

Cette classe implémente les rôles Specio::Constraint::Role::IsaType, Specio::Constraint::Role::Interface, et Specio::Role::Inlinable.
