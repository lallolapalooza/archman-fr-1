SSL_CTX_sess_number(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_SESS_NUMBER(3ssl) OpenSSL SSL_CTX_SESS_NUMBER(3ssl)

NOM

SSL_CTX_sess_number, SSL_CTX_sess_connect, SSL_CTX_sess_connect_good, SSL_CTX_sess_connect_renegotiate, SSL_CTX_sess_accept, SSL_CTX_sess_accept_good, SSL_CTX_sess_accept_renegotiate, SSL_CTX_sess_hits, SSL_CTX_sess_cb_hits, SSL_CTX_sess_misses, SSL_CTX_sess_timeouts, SSL_CTX_sess_cache_full - obtenir des statistiques sur le cache de sessions

SYNOPIS

#include <openssl/ssl.h>
long SSL_CTX_sess_number(SSL_CTX *ctx);
long SSL_CTX_sess_connect(SSL_CTX *ctx);
long SSL_CTX_sess_connect_good(SSL_CTX *ctx);
long SSL_CTX_sess_connect_renegotiate(SSL_CTX *ctx);
long SSL_CTX_sess_accept(SSL_CTX *ctx);
long SSL_CTX_sess_accept_good(SSL_CTX *ctx);
long SSL_CTX_sess_accept_renegotiate(SSL_CTX *ctx);
long SSL_CTX_sess_hits(SSL_CTX *ctx);
long SSL_CTX_sess_cb_hits(SSL_CTX *ctx);
long SSL_CTX_sess_misses(SSL_CTX *ctx);
long SSL_CTX_sess_timeouts(SSL_CTX *ctx);
long SSL_CTX_sess_cache_full(SSL_CTX *ctx);

DESCRIPTION

SSL_CTX_sess_number() retourne le nombre actuel de sessions dans le cache de sessions interne.

SSL_CTX_sess_connect() retourne le nombre de négociations SSL/TLS démarrées en mode client.

SSL_CTX_sess_connect_good() retourne le nombre de sessions SSL/TLS établies avec succès en mode client.

SSL_CTX_sess_connect_renegotiate() retourne le nombre de re-négociations démarrées en mode client.

SSL_CTX_sess_accept() retourne le nombre de négociations SSL/TLS démarrées en mode serveur.

SSL_CTX_sess_accept_good() retourne le nombre de sessions SSL/TLS établies avec succès en mode serveur.

SSL_CTX_sess_accept_renegotiate() retourne le nombre de re-négociations démarrées en mode serveur.

SSL_CTX_sess_hits() retourne le nombre de sessions réutilisées avec succès. En mode client, une session définie avec SSL_set_session(3) et réutilisée avec succès est comptée comme un succès. En mode serveur, une session récupérée avec succès depuis le cache interne ou externe est comptée comme un succès.

SSL_CTX_sess_cb_hits() retourne le nombre de sessions récupérées avec succès depuis le cache de sessions externe en mode serveur.

SSL_CTX_sess_misses() retourne le nombre de sessions proposées par les clients qui n'ont pas été trouvées dans le cache de sessions interne en mode serveur.

SSL_CTX_sess_timeouts() retourne le nombre de sessions proposées par les clients et trouvées dans le cache de sessions interne ou externe en mode serveur, mais qui étaient invalides en raison d'un délai d'expiration. Ces sessions ne sont pas incluses dans le décompte de SSL_CTX_sess_hits().

SSL_CTX_sess_cache_full() retourne le nombre de sessions qui ont été supprimées car la taille maximale du cache de sessions a été dépassée.

VALEURS DE RETOUR

Les fonctions retournent les valeurs indiquées dans la section DESCRIPTION.
