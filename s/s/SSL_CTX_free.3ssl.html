NOM

SSL_CTX_free - libérer un objet SSL_CTX alloué

SYNTAXE

#include <openssl/ssl.h>
void SSL_CTX_free(SSL_CTX *ctx);

DESCRIPTION

SSL_CTX_free() décrémente le compteur de références de ctx, et supprime l'objet SSL_CTX pointé par ctx et libère la mémoire allouée si le compteur de références a atteint 0.

Il appelle également les procédures de libération() pour les éléments indirectement affectés, si applicable : le cache de sessions, la liste des chiffrements, la liste des CA clients, les certificats et les clés.

Si ctx est NULL, rien n'est fait.

AVERTISSEMENTS

Si une fonction de rappel de suppression de session est définie (SSL_CTX_sess_set_remove_cb()), cette fonction de rappel sera appelée pour chaque session libérée du cache de sessions de ctx. Cela implique que toutes les sessions correspondantes d'un cache de sessions externe sont également supprimées. Si ce n'est pas souhaité, l'utilisateur devrait explicitement désactiver la fonction de rappel en appelant SSL_CTX_sess_set_remove_cb(ctx, NULL) avant d'appeler SSL_CTX_free().

VALEURS DE RETOUR

SSL_CTX_free() ne fournit aucune information diagnostique.

VOIR AUSSI

SSL_CTX_new(3), ssl(7), SSL_CTX_sess_set_get_cb(3)
