NOM

SSL_get0_peer_scts - obtenir les SCTs reçus

SYNTAXE

#include <openssl/ssl.h>
const STACK_OF(SCT) *SSL_get0_peer_scts(SSL *s);

DESCRIPTION

SSL_get0_peer_scts() retourne les timestamps de certificat signés (SCTs) qui ont été reçus. Si c'est la première fois que cette fonction est appelée pour une instance SSL donnée, elle examinera les extensions TLS, la réponse OCSP et le certificat du pair pour les SCTs. Les appels futurs retourneront les mêmes SCTs.

RESTRICTIONS

Si aucun rappel de validation de transparence de certificat n'a été défini (en utilisant SSL_CTX_set_ct_validation_callback ou SSL_set_ct_validation_callback), cette fonction n'est pas garantie de retourner tous les SCTs que le pair est capable d'envoyer.

VALEURS DE RETOUR

SSL_get0_peer_scts() retourne une liste des SCTs trouvés, ou NULL en cas d'erreur.

VOIR AUSSI

ssl(7), SSL_CTX_set_ct_validation_callback(3)
