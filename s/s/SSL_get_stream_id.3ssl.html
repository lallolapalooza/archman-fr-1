SSL_get_stream_id(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_GET_STREAM_ID(3ssl) OpenSSL SSL_GET_STREAM_ID(3ssl)

NOM

SSL_get_stream_id, SSL_get_stream_type, SSL_STREAM_TYPE_NONE, SSL_STREAM_TYPE_READ, SSL_STREAM_TYPE_WRITE, SSL_STREAM_TYPE_BIDI, SSL_is_stream_local - obtenir des informations sur l'ID et le type de flux QUIC

SYNTAXE

#include <openssl/ssl.h>
uint64_t SSL_get_stream_id(SSL *ssl);
#define SSL_STREAM_TYPE_NONE
#define SSL_STREAM_TYPE_BIDI
#define SSL_STREAM_TYPE_READ
#define SSL_STREAM_TYPE_WRITE
int SSL_get_stream_type(SSL *ssl);
int SSL_is_stream_local(SSL *ssl);

DESCRIPTION

La fonction SSL_get_stream_id() renvoie l'ID de flux QUIC pour un objet SSL de flux QUIC, ou pour un objet SSL de connexion QUIC qui a un flux par défaut attaché.

La fonction SSL_get_stream_type() identifie quelles opérations peuvent être effectuées sur le flux, et renvoie l'une des valeurs suivantes :

SSL_STREAM_TYPE_NONE
L'objet SSL est un objet SSL de connexion QUIC sans flux par défaut attaché.
SSL_STREAM_TYPE_BIDI
L'objet SSL est un objet SSL non-QUIC, ou est un objet de flux QUIC (ou un objet SSL de connexion QUIC avec un flux par défaut attaché), et ce flux est un flux QUIC bidirectionnel.
SSL_STREAM_TYPE_READ
L'objet SSL est un objet de flux QUIC (ou un objet SSL de connexion QUIC avec un flux par défaut attaché), et ce flux est un flux QUIC unidirectionnel qui a été initié par le pair distant ; par conséquent, il peut être lu, mais pas écrit.
SSL_STREAM_TYPE_WRITE
L'objet SSL est un objet de flux QUIC (ou un objet SSL de connexion QUIC avec un flux par défaut attaché), et ce flux est un flux QUIC unidirectionnel qui a été initié par l'application locale ; par conséquent, il peut être écrit, mais pas lu.

La fonction SSL_is_stream_local() détermine si un flux a été créé localement.

NOTES

Bien que QUICv1 attribue une signification spécifique aux deux bits de poids faible d'un ID de flux QUIC, les ID de flux QUIC dans les futures versions de QUIC ne sont pas tenus d'avoir les mêmes sémantiques. Ne déterminez pas les propriétés du flux en utilisant ces bits. Utilisez plutôt SSL_get_stream_type() pour déterminer le type de flux et SSL_get_stream_is_local() pour déterminer l'initiateur du flux.

La fonction SSL_get_stream_type() identifie le type d'un flux QUIC en fonction de son identité, et n'indique pas si une opération peut actuellement être effectuée avec succès sur un flux. Par exemple, vous pouvez initier localement un flux unidirectionnel, y écrire, puis conclure le flux en utilisant SSL_stream_conclude(3), ce qui signifie qu'il ne peut plus être écrit, mais SSL_get_stream_type() renverrait toujours SSL_STREAM_TYPE_WRITE. La valeur renvoyée par SSL_get_stream_type() ne varie pas sur la durée de vie d'un flux.

VALEURS DE RETOUR

SSL_get_stream_id() renvoie un ID de flux QUIC, ou UINT64_MAX si appelée sur un objet SSL qui n'est pas un objet SSL QUIC, ou si appelée sur un objet SSL de connexion QUIC sans flux par défaut attaché. Notez que les ID de flux QUIC valides sont toujours inférieurs à 2^62.

SSL_get_stream_type() renvoie l'une des valeurs SSL_STREAM_TYPE.

SSL_is_stream_local() renvoie 1 si appelée sur un objet SSL de flux QUIC qui représente un flux qui a été initié localement. Elle renvoie 0 si appelée sur un objet SSL de flux QUIC qui représente un flux qui a été initié à distance par un pair, et -1 si appelée sur tout autre type d'objet SSL.

VOIR AUSSI

SSL_new_stream(3), SSL_accept_stream(3)
