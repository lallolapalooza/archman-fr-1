SSL_CTX_set_min_proto_version(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_SET_MIN_PROTO_VERSION(3ssl) OpenSSL SSL_CTX_SET_MIN_PROTO_VERSION(3ssl)

NOM

SSL_CTX_set_min_proto_version, SSL_CTX_set_max_proto_version, SSL_CTX_get_min_proto_version, SSL_CTX_get_max_proto_version, SSL_set_min_proto_version, SSL_set_max_proto_version, SSL_get_min_proto_version, SSL_get_max_proto_version - Obtenir et définir la version minimale et maximale de protocole prise en charge

SYNOPIS

#include <openssl/ssl.h>
int SSL_CTX_set_min_proto_version(SSL_CTX *ctx, int version);
int SSL_CTX_set_max_proto_version(SSL_CTX *ctx, int version);
int SSL_CTX_get_min_proto_version(SSL_CTX *ctx);
int SSL_CTX_get_max_proto_version(SSL_CTX *ctx);
int SSL_set_min_proto_version(SSL *ssl, int version);
int SSL_set_max_proto_version(SSL *ssl, int version);
int SSL_get_min_proto_version(SSL *ssl);
int SSL_get_max_proto_version(SSL *ssl);

DESCRIPTION

Les fonctions obtiennent ou définissent les versions minimales et maximales de protocole prises en charge pour le ctx ou ssl. Cela fonctionne en combinaison avec les options définies via SSL_CTX_set_options(3) qui permettent également de désactiver des versions spécifiques de protocole. Utilisez ces fonctions plutôt que de désactiver des versions spécifiques de protocole.

Définir la version minimale ou maximale à 0 (par défaut) activera les versions de protocole jusqu'à la version la plus basse, ou jusqu'à la version la plus haute prise en charge par la bibliothèque, respectivement. Les versions prises en charge peuvent être contrôlées par la configuration du système.

Les fonctions d'obtention retournent 0 si ctx ou ssl ont été configurés pour utiliser automatiquement la version la plus basse ou la plus haute prise en charge par la bibliothèque.

Les versions actuellement prises en charge sont SSL3_VERSION, TLS1_VERSION, TLS1_1_VERSION, TLS1_2_VERSION, TLS1_3_VERSION pour TLS et DTLS1_VERSION, DTLS1_2_VERSION pour DTLS.

Dans la version actuelle d'OpenSSL, seul QUICv1 est pris en charge en conjonction avec TLSv1.3. L'appel de ces fonctions sur un objet QUIC n'a aucun effet.

VALEURS DE RETOUR

Ces fonctions de définition retournent 1 en cas de succès et 0 en cas d'échec. Les fonctions d'obtention retournent la version configurée ou 0 pour la configuration automatique de la version la plus basse ou la plus haute du protocole, respectivement.

NOTES

Toutes ces fonctions sont implémentées à l'aide de macros.

VOIR AUSSI

ssl(7), SSL_CTX_set_options(3), SSL_CONF_cmd(3)

HISTORIQUE

Les fonctions de définition ont été ajoutées dans OpenSSL 1.1.0. Les fonctions d'obtention ont été ajoutées dans OpenSSL 1.1.1.
