SSL_CTX_flush_sessions(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_FLUSH_SESSIONS(3ssl) OpenSSL SSL_CTX_FLUSH_SESSIONS(3ssl)

NOM

SSL_CTX_flush_sessions_ex, SSL_CTX_flush_sessions - supprimer les sessions expirées

SYNTAXE

#include <openssl/ssl.h>
void SSL_CTX_flush_sessions_ex(SSL_CTX *ctx, time_t tm);

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.4, et peuvent être masquées entièrement en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

void SSL_CTX_flush_sessions(SSL_CTX *ctx, long tm);

DESCRIPTION

SSL_CTX_flush_sessions_ex() déclenche une analyse du cache de sessions de ctx pour supprimer les sessions expirées à l'heure tm.

SSL_CTX_flush_sessions() est une ancienne variante de la fonction qui n'est pas compatible Y2038 en raison de l'utilisation du type de données long au lieu de time_t.

NOTES

Si activé, le cache de sessions interne collectera toutes les sessions établies jusqu'au nombre maximum spécifié (voir SSL_CTX_sess_set_cache_size()). Comme les sessions ne seront pas réutilisées une fois expirées, elles devraient être retirées du cache pour économiser des ressources. Cela peut soit être fait automatiquement chaque fois que 255 nouvelles sessions ont été établies (voir SSL_CTX_set_session_cache_mode(3)) soit manuellement en appelant SSL_CTX_flush_sessions_ex().

Le paramètre tm spécifie le temps qui devrait être utilisé pour le test d'expiration, dans la plupart des cas le temps actuel donné par time(0) sera utilisé.

SSL_CTX_flush_sessions_ex() ne vérifiera que les sessions stockées dans le cache interne. Lorsqu'une session est trouvée et supprimée, le remove_session_cb est cependant appelé pour synchroniser avec le cache externe (voir SSL_CTX_sess_set_get_cb(3)).

VALEURS DE RETOUR

SSL_CTX_flush_sessions_ex() ne retourne aucune valeur.

VOIR AUSSI

ssl(7), SSL_CTX_set_session_cache_mode(3), SSL_CTX_set_timeout(3), SSL_CTX_sess_set_get_cb(3)

HISTORIQUE

SSL_CTX_flush_sessions_ex() a été ajouté dans OpenSSL 3.4.
