SSL_SESSION_get0_cipher(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_SESSION_GET0_CIPHER(3ssl) OpenSSL SSL_SESSION_GET0_CIPHER(3ssl)

NOM

SSL_SESSION_get0_cipher, SSL_SESSION_set_cipher - définir et récupérer le chiffrement SSL associé à une session

SYNOPIS

#include <openssl/ssl.h>
const SSL_CIPHER *SSL_SESSION_get0_cipher(const SSL_SESSION *s);
int SSL_SESSION_set_cipher(SSL_SESSION *s, const SSL_CIPHER *cipher);

DESCRIPTION

SSL_SESSION_get0_cipher() récupère le chiffrement utilisé par la connexion lors de la création de la session, ou NULL s'il ne peut pas être déterminé.

La valeur retournée est un pointeur vers un objet géré à l'intérieur de s et ne doit pas être libérée.

SSL_SESSION_set_cipher() peut être utilisé pour définir la suite de chiffrement associée à SSL_SESSION s à cipher. Par exemple, cela pourrait être utilisé pour configurer une session basée sur PSK (voir SSL_CTX_set_psk_use_session_callback(3)).

VALEUR DE RETOUR

SSL_SESSION_get0_cipher() retourne le SSL_CIPHER associé au SSL_SESSION ou NULL s'il ne peut pas être déterminé.

SSL_SESSION_set_cipher() retourne 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI

ssl(7), d2i_SSL_SESSION(3), SSL_SESSION_get_time(3), SSL_SESSION_get0_hostname(3), SSL_SESSION_free(3), SSL_CTX_set_psk_use_session_callback(3)

HISTORIQUE

La fonction SSL_SESSION_get0_cipher() a été ajoutée dans OpenSSL 1.1.0. La fonction SSL_SESSION_set_cipher() a été ajoutée dans OpenSSL 1.1.1.
