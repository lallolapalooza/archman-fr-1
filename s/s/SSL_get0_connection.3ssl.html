Paquet: openssl

SSL_GET0_CONNECTION(3ssl) OpenSSL SSL_GET0_CONNECTION(3ssl)

NOM

SSL_get0_connection, SSL_is_connection - obtenir un objet SSL de connexion QUIC à partir d'un objet SSL de flux QUIC

SYNTAXE

#include <openssl/ssl.h>
SSL *SSL_get0_connection(SSL *ssl);
int SSL_is_connection(SSL *ssl);

DESCRIPTION

La fonction SSL_get0_connection(), lorsqu'elle est appelée sur un objet SSL de flux QUIC, renvoie l'objet SSL de connexion QUIC auquel appartient l'objet SSL de flux QUIC.

Lorsqu'elle est appelée sur un objet SSL de connexion QUIC, elle renvoie le même objet.

Lorsqu'elle est appelée sur un objet non-QUIC, elle renvoie le même objet qui lui a été passé.

SSL_is_connection() renvoie 1 pour les objets SSL de connexion QUIC et pour les objets SSL non-QUIC, mais renvoie 0 pour les objets SSL de flux QUIC.

VALEUR DE RETOUR

SSL_get0_connection() renvoie l'objet SSL de connexion QUIC (pour un objet SSL de flux QUIC) et sinon renvoie le même objet SSL passé. Il renvoie toujours une valeur non nulle.

SSL_is_connection() renvoie 1 si l'objet SSL n'est pas un objet SSL de flux QUIC et 0 sinon.

VOIR AUSSI

SSL_new(3), SSL_new_stream(3), SSL_accept_stream(3)

HISTORIQUE

Ces fonctions ont été ajoutées dans OpenSSL 3.2.
