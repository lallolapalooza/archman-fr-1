SSL_CTX_set_ssl_version(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_SET_SSL_VERSION(3ssl) OpenSSL SSL_CTX_SET_SSL_VERSION(3ssl)

NOM

SSL_CTX_set_ssl_version, SSL_CTX_get_ssl_method, SSL_set_ssl_method, SSL_get_ssl_method - choisir une nouvelle méthode TLS/SSL

SYNTAXE

#include <openssl/ssl.h>
int SSL_CTX_set_ssl_version(SSL_CTX *ctx, const SSL_METHOD *method);
const SSL_METHOD *SSL_CTX_get_ssl_method(const SSL_CTX *ctx);
int SSL_set_ssl_method(SSL *s, const SSL_METHOD *method);
const SSL_METHOD *SSL_get_ssl_method(const SSL *ssl);

DESCRIPTION

SSL_CTX_set_ssl_version() définit une nouvelle méthode TLS/SSL par défaut method pour les objets SSL nouvellement créés à partir de ce ctx. La plupart de la configuration attachée à l'objet SSL_CTX est conservée, à l'exception des chiffrements TLS configurés, qui sont réinitialisés aux valeurs par défaut. Les objets SSL déjà créés à partir de ce SSL_CTX avec SSL_new(3) ne sont pas affectés, sauf lorsque SSL_clear(3) est appelé, comme décrit ci-dessous.

SSL_CTX_get_ssl_method() renvoie la méthode SSL_METHOD qui a été utilisée pour construire le SSL_CTX.

SSL_set_ssl_method() définit une nouvelle méthode TLS/SSL method pour un objet ssl particulier. Elle peut être réinitialisée lorsque SSL_clear() est appelé.

SSL_get_ssl_method() renvoie un pointeur vers la méthode TLS/SSL définie dans ssl.

NOTES

Les choix de method disponibles sont décrits dans SSL_CTX_new(3).

Lorsque SSL_clear(3) est appelé et qu'aucune session n'est connectée à un objet SSL, la méthode de l'objet SSL est réinitialisée à la méthode actuellement définie dans l'objet SSL_CTX correspondant.

SSL_CTX_set_version() a des sémantiques inhabituelles et aucun cas d'utilisation clair ; il serait généralement préférable de créer un nouvel objet SSL_CTX plutôt que d'essayer de réutiliser un objet existant de cette manière. Son utilisation est considérée comme obsolète.

SSL_set_ssl_method() ne peut pas être utilisé pour changer un objet SSL non-QUIC en objet SSL QUIC ou vice versa, ni pour changer un objet SSL QUIC d'une méthode QUIC à une autre.

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent survenir pour SSL_CTX_set_ssl_version() et SSL_set_ssl_method() :

0
Le nouveau choix a échoué, vérifiez la pile d'erreurs pour connaître la raison.
1
L'opération a réussi.

SSL_CTX_get_ssl_method() et SSL_get_ssl_method() renvoient toujours des pointeurs non-NULL.

VOIR AUSSI
