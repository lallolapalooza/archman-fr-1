SSL_SESSION_has_ticket(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_SESSION_HAS_TICKET(3ssl) OpenSSL SSL_SESSION_HAS_TICKET(3ssl)

NOM

SSL_SESSION_get0_ticket, SSL_SESSION_has_ticket, SSL_SESSION_get_ticket_lifetime_hint - obtenir des détails sur le ticket associé à une session

SYNTAXE

#include <openssl/ssl.h>
int SSL_SESSION_has_ticket(const SSL_SESSION *s);
unsigned long SSL_SESSION_get_ticket_lifetime_hint(const SSL_SESSION *s);
void SSL_SESSION_get0_ticket(const SSL_SESSION *s, const unsigned char **tick,
                             size_t *len);

DESCRIPTION

SSL_SESSION_has_ticket() renvoie 1 s'il y a un Ticket de Session associé à cette session, et 0 sinon.

SSL_SESSION_get_ticket_lifetime_hint renvoie l'indice de durée de vie en secondes associé au ticket de session.

SSL_SESSION_get0_ticket obtient un pointeur vers le ticket associé à une session. La longueur du ticket est écrite dans *len. Si tick n'est pas NULL, un pointeur vers le ticket est écrit dans *tick. Le pointeur n'est valide que pendant l'utilisation de la connexion. La session (et par conséquent le pointeur du ticket) peut également cesser d'être valide à la suite d'un appel à SSL_CTX_flush_sessions().

VALEURS DE RETOUR

SSL_SESSION_has_ticket() renvoie 1 si le ticket de session existe ou 0 sinon.

SSL_SESSION_get_ticket_lifetime_hint() renvoie le nombre de secondes.

VOIR AUSSI

ssl(7), d2i_SSL_SESSION(3), SSL_SESSION_get_time(3), SSL_SESSION_free(3)

HISTORIQUE

Les fonctions SSL_SESSION_has_ticket(), SSL_SESSION_get_ticket_lifetime_hint() et SSL_SESSION_get0_ticket() ont été ajoutées dans OpenSSL 1.1.0.
