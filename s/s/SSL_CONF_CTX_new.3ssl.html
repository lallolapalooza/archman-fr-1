SSL_CONF_CTX_NEW(3ssl) OpenSSL SSL_CONF_CTX_NEW(3ssl)

NOM

SSL_CONF_CTX_new, SSL_CONF_CTX_free - Fonctions d'allocation de configuration SSL

SYNTAXE

#include <openssl/ssl.h>
SSL_CONF_CTX *SSL_CONF_CTX_new(void);
void SSL_CONF_CTX_free(SSL_CONF_CTX *cctx);

DESCRIPTION

La fonction SSL_CONF_CTX_new() alloue et initialise une structure SSL_CONF_CTX à utiliser avec les fonctions SSL_CONF.

La fonction SSL_CONF_CTX_free() libère le contexte cctx. Si cctx est NULL, rien n'est fait.

VALEURS DE RETOUR

SSL_CONF_CTX_new() retourne soit la structure SSL_CONF_CTX nouvellement allouée, soit NULL en cas d'erreur.

SSL_CONF_CTX_free() ne retourne aucune valeur.

VOIR AUSSI

ssl(7), SSL_CONF_CTX_set_flags(3), SSL_CONF_CTX_set_ssl_ctx(3), SSL_CONF_CTX_set1_prefix(3), SSL_CONF_cmd(3), SSL_CONF_cmd_argv(3)

HISTORIQUE

Ces fonctions ont été ajoutées dans OpenSSL 1.0.2.
