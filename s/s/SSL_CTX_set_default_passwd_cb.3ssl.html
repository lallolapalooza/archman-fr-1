SSL_CTX_set_default_passwd_cb(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_SET_DEFAULT_PASSWD_CB(3ssl) OpenSSL SSL_CTX_SET_DEFAULT_PASSWD_CB(3ssl)

NOM

SSL_CTX_set_default_passwd_cb, SSL_CTX_set_default_passwd_cb_userdata, SSL_CTX_get_default_passwd_cb, SSL_CTX_get_default_passwd_cb_userdata, SSL_set_default_passwd_cb, SSL_set_default_passwd_cb_userdata, SSL_get_default_passwd_cb, SSL_get_default_passwd_cb_userdata - définir ou obtenir la fonction de rappel pour la gestion des fichiers PEM chiffrés

SYNTAXE

#include <openssl/ssl.h>
void SSL_CTX_set_default_passwd_cb(SSL_CTX *ctx, pem_password_cb *cb);
void SSL_CTX_set_default_passwd_cb_userdata(SSL_CTX *ctx, void *u);
pem_password_cb *SSL_CTX_get_default_passwd_cb(SSL_CTX *ctx);
void *SSL_CTX_get_default_passwd_cb_userdata(SSL_CTX *ctx);
void SSL_set_default_passwd_cb(SSL *s, pem_password_cb *cb);
void SSL_set_default_passwd_cb_userdata(SSL *s, void *u);
pem_password_cb *SSL_get_default_passwd_cb(SSL *s);
void *SSL_get_default_passwd_cb_userdata(SSL *s);

DESCRIPTION

SSL_CTX_set_default_passwd_cb() définit la fonction de rappel par défaut appelée lors du chargement/stockage d'un certificat PEM avec chiffrement.

SSL_CTX_set_default_passwd_cb_userdata() définit un pointeur vers des données utilisateur, u, qui seront fournies à la fonction de rappel du mot de passe lors de son invocation.

SSL_CTX_get_default_passwd_cb() renvoie un pointeur de fonction vers la fonction de rappel du mot de passe actuellement définie dans ctx. Si aucune fonction de rappel n'a été explicitement définie, un pointeur NULL est renvoyé.

SSL_CTX_get_default_passwd_cb_userdata() renvoie un pointeur vers les données utilisateur actuellement définies dans ctx. Si aucune donnée utilisateur n'a été explicitement définie, un pointeur NULL est renvoyé.

SSL_set_default_passwd_cb(), SSL_set_default_passwd_cb_userdata(), SSL_get_default_passwd_cb() et SSL_get_default_passwd_cb_userdata() remplissent la même fonction que leurs homologues SSL_CTX, mais en utilisant un objet SSL.

La fonction de rappel du mot de passe, qui doit être fournie par l'application, renvoie le mot de passe à utiliser lors du déchiffrement. Lors de l'invocation, un pointeur vers des données utilisateur est fourni. La fonction doit stocker le mot de passe dans le tampon fourni buf qui a une taille de size. La longueur réelle du mot de passe doit être renvoyée à la fonction appelante. rwflag indique si la fonction de rappel est utilisée pour la lecture/déchiffrement (rwflag=0) ou l'écriture/chiffrement (rwflag=1). Pour plus de détails, voir pem_password_cb(3).

NOTES

Lors du chargement ou du stockage de clés privées, un mot de passe peut être fourni pour protéger la clé privée. La manière dont ce mot de passe peut être fourni peut dépendre de l'application. Si une seule clé privée est gérée, il peut être pratique que la fonction de rappel gère le dialogue du mot de passe de manière interactive. Si plusieurs clés doivent être gérées, il peut être pratique de demander le mot de passe une fois, puis de le garder en mémoire et de l'utiliser plusieurs fois. Dans ce dernier cas, le mot de passe pourrait être stocké dans le stockage des données utilisateur et la fonction de rappel ne ferait que renvoyer le mot de passe déjà stocké.

Lors de la demande interactive du mot de passe, la fonction de rappel peut utiliser rwflag pour vérifier si un élément doit être chiffré (rwflag=1). Dans ce cas, le dialogue du mot de passe peut demander le même mot de passe deux fois pour comparaison afin de détecter les fautes de frappe, ce qui rendrait le déchiffrement impossible.

D'autres éléments dans le format PEM (certificats) peuvent également être chiffrés, mais ce n'est pas courant, car les informations de certificat sont considérées comme publiques.

VALEURURS DE RETOUR

Ces fonctions ne fournissent aucune information diagnostique.

EXEMPLES

L'exemple suivant renvoie le mot de passe fourni en tant que données utilisateur à la fonction appelante. Le mot de passe est considéré comme une chaîne terminée par '\0'. Si le mot de passe ne rentre pas dans le tampon, le mot de passe est tronqué.

int my_cb(char *buf, int size, int rwflag, void *u)
{
    strncpy(buf, (char *)u, size);
    buf[size - 1] = '\0';
    return strlen(buf);
}
