SSL_library_init(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_LIBRARY_INIT(3ssl) OpenSSL SSL_LIBRARY_INIT(3ssl)

NOM

SSL_library_init, OpenSSL_add_ssl_algorithms - initialiser la bibliothèque SSL en enregistrant les algorithmes

SYNTAXE

#include <openssl/ssl.h>
int SSL_library_init(void);
int OpenSSL_add_ssl_algorithms(void);

DESCRIPTION

SSL_library_init() enregistre les chiffrements et les digests SSL/TLS disponibles.

OpenSSL_add_ssl_algorithms() est un synonyme de SSL_library_init() et est implémenté comme une macro.

NOTES

SSL_library_init() doit être appelée avant toute autre action. SSL_library_init() n'est pas réentrant.

AVERTISSEMENTS

SSL_library_init() ajoute les chiffrements et les digests utilisés directement et indirectement par SSL/TLS.

VALEURS DE RETOUR

SSL_library_init() retourne toujours "1", il est donc sûr d'ignorer la valeur de retour.

VOIR AUSSI

ssl(7), RAND_add(3)

HISTORIQUE

Les fonctions SSL_library_init() et OpenSSL_add_ssl_algorithms() ont été dépréciées dans OpenSSL 1.1.0 au profit de OPENSSL_init_ssl().
