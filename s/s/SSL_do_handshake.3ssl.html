NOM

SSL_do_handshake - effectuer une négociation TLS/SSL

SYNTAXE

#include <openssl/ssl.h>
int SSL_do_handshake(SSL *ssl);

DESCRIPTION

SSL_do_handshake() attendra qu'une négociation SSL/TLS ait lieu. Si la connexion est en mode client, la négociation sera démarrée. Les routines de négociation devront peut-être être définies à l'avance à l'aide de SSL_set_connect_state(3) ou SSL_set_accept_state(3).

NOTES

Le comportement de SSL_do_handshake() dépend du BIO sous-jacent.

Si le BIO sous-jacent est bloquant, SSL_do_handshake() ne retournera qu'une fois la négociation terminée ou qu'une erreur se soit produite.

Si le BIO sous-jacent est non bloquant, SSL_do_handshake() retournera également lorsque le BIO sous-jacent n'a pas pu satisfaire les besoins de SSL_do_handshake() pour continuer la négociation. Dans ce cas, un appel à SSL_get_error() avec la valeur de retour de SSL_do_handshake() donnera SSL_ERROR_WANT_READ ou SSL_ERROR_WANT_WRITE. Le processus appelant doit alors répéter l'appel après avoir pris les mesures appropriées pour satisfaire les besoins de SSL_do_handshake(). L'action dépend du BIO sous-jacent. Lors de l'utilisation d'un socket non bloquant, rien n'est à faire, mais select() peut être utilisé pour vérifier la condition requise. Lors de l'utilisation d'un BIO de mise en tampon, comme une paire BIO, les données doivent être écrites dans ou retirées du BIO avant de pouvoir continuer.

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent survenir :

0
La négociation TLS/SSL n'a pas abouti mais a été arrêtée de manière contrôlée et selon les spécifications du protocole TLS/SSL. Appelez SSL_get_error() avec la valeur de retour ret pour connaître la raison.
1
La négociation TLS/SSL s'est terminée avec succès, une connexion TLS/SSL a été établie.
<0
La négociation TLS/SSL n'a pas abouti car une erreur fatale s'est produite au niveau du protocole ou une défaillance de connexion s'est produite. L'arrêt n'était pas propre. Cela peut également se produire si une action est nécessaire pour continuer l'opération pour les BIO non bloquants. Appelez SSL_get_error() avec la valeur de retour ret pour connaître la raison.
