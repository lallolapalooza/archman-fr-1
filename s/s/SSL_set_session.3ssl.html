NOM

SSL_set_session - définir une session TLS/SSL à utiliser lors de la connexion TLS/SSL

SYNTAXE

#include <openssl/ssl.h>
int SSL_set_session(SSL *ssl, SSL_SESSION *session);

DESCRIPTION

SSL_set_session() définit session à utiliser lors de l'établissement de la connexion TLS/SSL. SSL_set_session() est uniquement utile pour les clients TLS/SSL. Lorsque la session est définie, le compteur de références de session est incrémenté de 1. Si la session n'est pas réutilisée, le compteur de références est décrémenté à nouveau lors de SSL_connect(). La réutilisation de la session peut être vérifiée à l'aide de l'appel SSL_session_reused(3).

S'il y a déjà une session définie dans ssl (parce qu'elle a été définie précédemment avec SSL_set_session() ou parce que le même ssl a déjà été utilisé pour une connexion), SSL_SESSION_free() sera appelée pour cette session. Il en va de même lorsque session est un pointeur NULL. Si cette ancienne session est toujours ouverte, elle est considérée comme défectueuse et sera retirée du cache de sessions (si utilisé). Une session est considérée comme ouverte si SSL_shutdown(3) n'a pas été appelée pour la connexion (ou du moins si SSL_set_shutdown(3) a été utilisée pour définir l'état SSL_SENT_SHUTDOWN).

NOTES

Les objets SSL_SESSION conservent des informations de liaison internes sur la liste du cache de sessions, lorsqu'ils sont insérés dans le cache de sessions d'un objet SSL_CTX. Un objet SSL_SESSION, quel que soit son compteur de références, ne doit donc être utilisé qu'avec un seul objet SSL_CTX (et les objets SSL créés à partir de cet objet SSL_CTX).

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent survenir :

0
L'opération a échoué ; vérifiez la pile d'erreurs pour en connaître la raison.
1
L'opération a réussi.
