NOM

SSL_SESSION_get_compress_id - obtenir des détails sur la compression associée à une session

SYNTAXE

#include <openssl/ssl.h>
unsigned int SSL_SESSION_get_compress_id(const SSL_SESSION *s);

DESCRIPTION

Si la compression a été négociée pour une session ssl, SSL_SESSION_get_compress_id() retournera l'identifiant de la méthode de compression, ou 0 sinon. La seule méthode de compression supportée nativement est zlib, qui a un identifiant de 1.

VALEURS DE RETOUR

SSL_SESSION_get_compress_id() retourne l'identifiant de la méthode de compression ou 0 si aucune.
