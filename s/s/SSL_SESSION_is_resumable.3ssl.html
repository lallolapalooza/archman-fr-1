NOM

SSL_SESSION_is_resumable - déterminer si un objet SSL_SESSION peut être utilisé pour la reprise

SYNTAXE

#include <openssl/ssl.h>
int SSL_SESSION_is_resumable(const SSL_SESSION *s);

DESCRIPTION

SSL_SESSION_is_resumable() détermine si un objet SSL_SESSION peut être utilisé pour reprendre une session ou non. Retourne 1 s'il le peut, 0 sinon. Notez que tenter de reprendre avec une session non résumable entraînera une négociation complète.

VALEURS DE RETOUR

SSL_SESSION_is_resumable() retourne 1 si la session est résumable ou 0 sinon.

VOIR AUSSI

ssl(7), SSL_get_session(3), SSL_CTX_sess_set_new_cb(3)

HISTORIQUE

La fonction SSL_SESSION_is_resumable() a été ajoutée dans OpenSSL 1.1.1.
