SSL_SESSION_print(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_SESSION_PRINT(3ssl) OpenSSL SSL_SESSION_PRINT(3ssl)

NOM

SSL_SESSION_print, SSL_SESSION_print_fp, SSL_SESSION_print_keylog - affiche des informations sur une session

SYNTAXE

#include <openssl/ssl.h>
int SSL_SESSION_print(BIO *fp, const SSL_SESSION *ses);
int SSL_SESSION_print_fp(FILE *fp, const SSL_SESSION *ses);
int SSL_SESSION_print_keylog(BIO *bp, const SSL_SESSION *x);

DESCRIPTION

SSL_SESSION_print() affiche des informations sommaires sur la session fournie dans ses à la BIO fp.

SSL_SESSION_print_fp() fait la même chose que SSL_SESSION_print(), sauf qu'elle affiche les informations au fichier FILE fp.

SSL_SESSION_print_keylog() affiche les informations de session à la BIO <bp> fournie, au format NSS keylog.

VALEURS DE RETOUR

SSL_SESSION_print(), SSL_SESSION_print_fp() et SSL_SESSION_print_keylog retournent 1 en cas de succès ou 0 en cas d'erreur.
