SSL_SESSION_get_protocol_version(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_SESSION_GET_PROTOCOL_VERSION(3ssl) OpenSSL SSL_SESSION_GET_PROTOCOL_VERSION(3ssl)

NOM

SSL_SESSION_get_protocol_version, SSL_SESSION_set_protocol_version - obtenir et définir la version du protocole de session

SYNTAXE

#include <openssl/ssl.h>
int SSL_SESSION_get_protocol_version(const SSL_SESSION *s);
int SSL_SESSION_set_protocol_version(SSL_SESSION *s, int version);

DESCRIPTION

SSL_SESSION_get_protocol_version() retourne le numéro de version du protocole utilisé par la session s.

SSL_SESSION_set_protocol_version() définit la version du protocole associée à l'objet SSL_SESSION s à la valeur version. Cette valeur doit être une constante de version telle que TLS1_3_VERSION, etc. Par exemple, cela pourrait être utilisé pour configurer une session basée sur PSK (voir SSL_CTX_set_psk_use_session_callback(3)).

VALEURS DE RETOUR

SSL_SESSION_get_protocol_version() retourne un nombre indiquant la version du protocole utilisée pour la session ; ce nombre correspond aux constantes par exemple TLS1_VERSION, TLS1_2_VERSION ou TLS1_3_VERSION.

Notez que la fonction SSL_SESSION_get_protocol_version() n'effectue **pas** de vérification de nullité sur le pointeur de session fourni s.

SSL_SESSION_set_protocol_version() retourne 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI

ssl(7), SSL_CTX_set_psk_use_session_callback(3)

HISTORIQUE

La fonction SSL_SESSION_get_protocol_version() a été ajoutée dans OpenSSL 1.1.0. La fonction SSL_SESSION_set_protocol_version() a été ajoutée dans OpenSSL 1.1.1.
