SSL_get_peer_cert_chain(3ssl)

Licences: Apache-2.0

SSL_GET_PEER_CERT_CHAIN(3ssl) OpenSSL SSL_GET_PEER_CERT_CHAIN(3ssl)

NOM

SSL_get_peer_cert_chain, SSL_get0_verified_chain - obtenir la chaîne de certificats X509 du pair

SYNTAXE

#include <openssl/ssl.h>
STACK_OF(X509) *SSL_get_peer_cert_chain(const SSL *ssl);
STACK_OF(X509) *SSL_get0_verified_chain(const SSL *ssl);

DESCRIPTION

SSL_get_peer_cert_chain() renvoie un pointeur vers une STACK_OF(X509) de certificats formant la chaîne de certificats envoyée par le pair. Si appelée du côté client, la pile contient également le certificat du pair ; si appelée du côté serveur, le certificat du pair doit être obtenu séparément en utilisant SSL_get_peer_certificate(3). Si le pair n'a pas présenté de certificat, NULL est renvoyé.

NOTE : SSL_get_peer_cert_chain() renvoie la chaîne du pair telle qu'elle a été envoyée par le pair : elle ne se compose que des certificats que le pair a envoyés (dans l'ordre où le pair les a envoyés), ce n'est **pas** une chaîne vérifiée.

SSL_get0_verified_chain() renvoie la chaîne de certificats **vérifiée** du pair, y compris le certificat de l'entité finale du pair. Elle doit être appelée après qu'une session a été établie avec succès. Si la vérification du pair n'a pas réussi (comme l'indique le fait que SSL_get_verify_result() ne renvoie pas X509_V_OK), la chaîne peut être incomplète ou invalide.

NOTES

Si la session est reprise, les pairs n'envoient pas de certificats, donc un pointeur NULL est renvoyé par ces fonctions. Les applications peuvent appeler SSL_session_reused() pour déterminer si une session est reprise.

Le compteur de références de chaque certificat dans l'objet STACK_OF(X509) renvoyé n'est pas incrémenté et la pile renvoyée peut être invalidée par renégociation. Si les applications souhaitent utiliser indéfiniment des certificats de la chaîne renvoyée, elles doivent augmenter les compteurs de références en utilisant X509_up_ref() ou obtenir une copie de toute la chaîne avec X509_chain_up_ref().

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent se produire :

NULL
Aucun certificat n'a été présenté par le pair, aucune connexion n'a été établie, ou la chaîne de certificats n'est plus disponible lorsqu'une session est reprise.
Pointeur vers une STACK_OF(X509)
La valeur de retour pointe vers la chaîne de certificats présentée par le pair.
