NOM

SSL_clear - réinitialiser un objet SSL pour permettre une autre connexion

SYNTAXE

#include <openssl/ssl.h>
int SSL_clear(SSL *ssl);

DESCRIPTION

Réinitialise ssl pour permettre une autre connexion. Tous les réglages (méthode, chiffrements, BIOs) sont conservés.

NOTES

SSL_clear est utilisé pour préparer un objet SSL pour une nouvelle connexion. Bien que tous les réglages soient conservés, un effet secondaire est la gestion de la session SSL actuelle. Si une session est toujours ouverte, elle est considérée comme invalide et sera retirée du cache de sessions, comme requis par RFC2246. Une session est considérée comme ouverte si SSL_shutdown(3) n'a pas été appelée pour la connexion ou si au moins SSL_set_shutdown(3) a été utilisé pour définir l'état SSL_SENT_SHUTDOWN.

Si une session a été fermée proprement, l'objet session sera conservé et tous les réglages correspondants. Cela signifie explicitement que, par exemple, la méthode spéciale utilisée pendant la session sera conservée pour la prochaine négociation. Ainsi, si la session était une session TLSv1, un objet client SSL utilisera une méthode client TLSv1 pour la prochaine négociation et un objet serveur SSL utilisera une méthode serveur TLSv1, même si des méthodes TLS_*_methods ont été choisies au démarrage. Cela pourrait entraîner des échecs de connexion (voir SSL_new(3)) pour une description des propriétés des méthodes.

Cette fonction n'est pas prise en charge sur les objets SSL QUIC et renvoie un échec si elle est appelée sur un tel objet.

AVERTISSEMENTS

SSL_clear() réinitialise l'objet SSL pour permettre une autre connexion. L'opération de réinitialisation conserve cependant plusieurs réglages des dernières sessions (certains de ces réglages ont été effectués automatiquement lors de la dernière négociation). Elle n'a de sens que pour une nouvelle connexion avec exactement le même pair qui partage ces réglages, et peut échouer si ce pair change ses réglages entre les connexions. Utilisez plutôt la séquence SSL_get_session(3) ; SSL_new(3) ; SSL_set_session(3) ; SSL_free(3) pour éviter de tels échecs (ou simplement SSL_free(3) ; SSL_new(3) si la réutilisation de session n'est pas souhaitée).

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent se produire :

0
L'opération SSL_clear() n'a pas pu être effectuée. Vérifiez la pile d'erreurs pour connaître la raison.
1
L'opération SSL_clear() a réussi.
