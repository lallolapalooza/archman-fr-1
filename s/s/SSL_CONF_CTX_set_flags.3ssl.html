SSL_CONF_CTX_SET_FLAGS(3ssl) OpenSSL SSL_CONF_CTX_SET_FLAGS(3ssl)

NOM

SSL_CONF_CTX_set_flags, SSL_CONF_CTX_clear_flags - Définir ou effacer les indicateurs du contexte de configuration SSL

SYNTAXE

#include <openssl/ssl.h>
unsigned int SSL_CONF_CTX_set_flags(SSL_CONF_CTX *cctx, unsigned int flags);
unsigned int SSL_CONF_CTX_clear_flags(SSL_CONF_CTX *cctx, unsigned int flags);

DESCRIPTION

La fonction SSL_CONF_CTX_set_flags() définit les flags dans le contexte cctx.

La fonction SSL_CONF_CTX_clear_flags() efface les flags dans le contexte cctx.

NOTES

Les indicateurs définis affectent le comportement des appels ultérieurs à SSL_CONF_cmd() ou SSL_CONF_argv().

Actuellement, les valeurs de flags suivantes sont reconnues :

SSL_CONF_FLAG_CMDLINE, SSL_CONF_FLAG_FILE
reconnaissent les options destinées à une utilisation en ligne de commande ou dans un fichier de configuration. Au moins un de ces indicateurs doit être défini.
SSL_CONF_FLAG_CLIENT, SSL_CONF_FLAG_SERVER
reconnaissent les options destinées à une utilisation par des clients ou des serveurs SSL/TLS. Un ou les deux de ces indicateurs doivent être définis.
SSL_CONF_FLAG_CERTIFICATE
reconnaissent les options de certificat et de clé privée.
SSL_CONF_FLAG_REQUIRE_PRIVATE
Si cette option est définie, alors si une clé privée n'est pas spécifiée pour un certificat, OpenSSL tentera de charger une clé privée depuis le fichier du certificat lors de l'appel à SSL_CONF_CTX_finish(). Si une clé ne peut pas être chargée depuis le fichier du certificat, une erreur se produit.
SSL_CONF_FLAG_SHOW_ERRORS
indiquent les erreurs relatives aux options non reconnues ou aux arguments manquants dans la file d'attente d'erreurs. Si cette option n'est pas définie, de telles erreurs ne sont reflétées que dans les valeurs de retour de SSL_CONF_set_cmd() ou SSL_CONF_set_argv().

VALEURS DE RETOUR

SSL_CONF_CTX_set_flags() et SSL_CONF_CTX_clear_flags() renvoient la nouvelle valeur des indicateurs après avoir défini ou effacé les indicateurs.

VOIR AUSSI

HISTORIQUE
