NOM

SSL_free_buffers, SSL_alloc_buffers - gérer les tampons de la structure SSL

SYNTAXE

#include <openssl/ssl.h>
int SSL_free_buffers(SSL *ssl);
int SSL_alloc_buffers(SSL *ssl);

DESCRIPTION

SSL_free_buffers() libère les tampons de lecture et d'écriture du ssl donné. SSL_alloc_buffers() alloue les tampons de lecture et d'écriture du ssl donné.

Le mode SSL_MODE_RELEASE_BUFFERS libère les tampons de lecture ou d'écriture chaque fois que les tampons ont été vidés. Ces fonctions permettent aux applications de contrôler manuellement quand les tampons sont libérés et alloués.

Après avoir libéré les tampons, ceux-ci sont automatiquement réalloués lors d'une nouvelle lecture ou écriture. La fonction SSL_alloc_buffers() n'a pas besoin d'être appelée, mais peut être utilisée pour s'assurer que les tampons sont pré-alloués. Cela peut être utilisé pour éviter les allocations lors du traitement des données ou avec CRYPTO_set_mem_functions() pour contrôler où et comment les tampons sont alloués.

Ces fonctions ne font rien lorsqu'elles sont utilisées avec des objets SSL QUIC. Pour QUIC, SSL_free_buffers() échoue toujours, et SSL_alloc_buffers() réussit toujours.

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent survenir :

0 (Échec)
La fonction SSL_free_buffers() retourne 0 lorsqu'il y a des données en attente à lire ou à écrire. La fonction SSL_alloc_buffers() retourne 0 en cas d'échec d'allocation.
1 (Succès)
La fonction SSL_free_buffers() retourne 1 si les tampons ont été libérés. Cette valeur est également retournée si les tampons avaient été libérés avant d'appeler SSL_free_buffers(). La fonction SSL_alloc_buffers() retourne 1 si les tampons ont été alloués. Cette valeur est également retournée si les tampons avaient été alloués avant d'appeler SSL_alloc_buffers().
