SSL_set_incoming_stream_policy(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_SET_INCOMING_STREAM_POLICY(3ssl) OpenSSL SSL_SET_INCOMING_STREAM_POLICY(3ssl)

NOM

SSL_set_incoming_stream_policy, SSL_INCOMING_STREAM_POLICY_AUTO, SSL_INCOMING_STREAM_POLICY_ACCEPT, SSL_INCOMING_STREAM_POLICY_REJECT - gérer la politique des flux entrants QUIC

SYNTAXE

#include <openssl/ssl.h>
#define SSL_INCOMING_STREAM_POLICY_AUTO
#define SSL_INCOMING_STREAM_POLICY_ACCEPT
#define SSL_INCOMING_STREAM_POLICY_REJECT
int SSL_set_incoming_stream_policy(SSL *conn, int policy,
                                          uint64_t app_error_code);

DESCRIPTION

SSL_set_incoming_stream_policy() modifie la politique des flux entrants pour une connexion QUIC. Selon la politique configurée, OpenSSL QUIC peut rejeter automatiquement les flux entrants initiés par le pair. Ceci est destiné à garantir que les applications héritées utilisant une opération à flux unique avec le flux par défaut sur un objet SSL de connexion QUIC ne reçoivent pas de flux initiés à distance par un pair qu'elles ne sont pas préparées à gérer.

app_error_code est un code d'erreur d'application qui sera utilisé dans toutes les trames QUIC STOP_SENDING ou RESET_STREAM générées pour implémenter la politique. Le code d'erreur d'application par défaut est 0.

Les valeurs valides pour policy sont :

SSL_INCOMING_STREAM_POLICY_AUTO
C'est le réglage par défaut. Les flux entrants sont acceptés selon les règles suivantes :
  • Si le mode de flux par défaut (configuré via SSL_set_default_stream_mode(3)) est réglé sur SSL_DEFAULT_STREAM_MODE_AUTO_BIDI (le défaut) ou SSL_DEFAULT_STREAM_MODE_AUTO_UNI, le flux entrant est rejeté.
  • Sinon (lorsque le mode de flux par défaut est SSL_DEFAULT_STREAM_MODE_NONE), l'application est supposée être consciente des flux, et le flux entrant est accepté.
SSL_INCOMING_STREAM_POLICY_ACCEPT
Accepte toujours les flux entrants, permettant leur mise en file d'attente via SSL_accept_stream(3).
SSL_INCOMING_STREAM_POLICY_REJECT
Rejette toujours les flux entrants.

Lorsqu'un flux entrant est rejeté, il l'est immédiatement et il n'est pas possible d'y accéder via SSL_accept_stream(3). Le flux est rejeté à l'aide des trames QUIC STOP_SENDING et RESET_STREAM le cas échéant.

VALEUR DE RETOUR

Retourne 1 en cas de succès et 0 en cas d'échec.

Cette fonction échoue si elle est appelée sur un objet SSL de flux QUIC, ou sur un objet SSL non-QUIC.

VOIR AUSSI

SSL_set_default_stream_mode(3), SSL_accept_stream(3)

HISTORIQUE

SSL_set_incoming_stream_policy() a été ajoutée dans OpenSSL 3.2.
