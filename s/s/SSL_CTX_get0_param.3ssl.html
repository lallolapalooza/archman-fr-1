SSL_CTX_get0_param(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_GET0_PARAM(3ssl) OpenSSL SSL_CTX_GET0_PARAM(3ssl)

NOM

SSL_CTX_get0_param, SSL_get0_param, SSL_CTX_set1_param, SSL_set1_param, SSL_CTX_set_purpose, SSL_CTX_set_trust, SSL_set_purpose, SSL_set_trust - obtenir et définir les paramètres de vérification

SYNTAXE

#include <openssl/ssl.h>
X509_VERIFY_PARAM *SSL_CTX_get0_param(SSL_CTX *ctx);
X509_VERIFY_PARAM *SSL_get0_param(SSL *ssl);
int SSL_CTX_set1_param(SSL_CTX *ctx, X509_VERIFY_PARAM *vpm);
int SSL_set1_param(SSL *ssl, X509_VERIFY_PARAM *vpm);
int SSL_CTX_set_purpose(SSL_CTX *ctx, int purpose);
int SSL_set_purpose(SSL *ssl, int purpose);
int SSL_CTX_set_trust(SSL_CTX *ctx, int trust);
int SSL_set_trust(SSL *ssl, int trust);

DESCRIPTION

SSL_CTX_get0_param() et SSL_get0_param() récupèrent un pointeur interne vers les paramètres de vérification pour ctx ou ssl respectivement. Le pointeur retourné ne doit pas être libéré par l'application appelante.

SSL_CTX_set1_param() et SSL_set1_param() définissent les paramètres de vérification à vpm pour ctx ou ssl.

Les fonctions SSL_CTX_set_purpose() et SSL_set_purpose() sont des raccourcis qui définissent le paramètre `purpose` sur l'objet des paramètres de vérification. Ces fonctions sont équivalentes à l'appel direct de X509_VERIFY_PARAM_set_purpose().

Les fonctions SSL_CTX_set_trust() et SSL_set_trust() sont de même des raccourcis qui définissent le paramètre `trust` sur l'objet des paramètres de vérification. Ces fonctions sont équivalentes à l'appel direct de X509_VERIFY_PARAM_set_trust().

NOTES

Généralement, les paramètres sont récupérés à partir d'une structure SSL_CTX ou SSL à l'aide de SSL_CTX_get0_param() ou SSL_get0_param() et une application les modifie pour répondre à ses besoins : par exemple, pour ajouter une vérification de nom d'hôte.

VALEURS DE RETOUR

SSL_CTX_get0_param() et SSL_get0_param() retournent un pointeur vers une structure X509_VERIFY_PARAM.

SSL_CTX_set1_param(), SSL_set1_param(), SSL_CTX_set_purpose(), SSL_set_purpose(), SSL_CTX_set_trust() et SSL_set_trust() retournent 1 en cas de succès et 0 en cas d'échec.

EXEMPLES

Vérifier que le nom d'hôte correspond à "www.foo.com" dans le certificat pair :

X509_VERIFY_PARAM *vpm = SSL_get0_param(ssl);
X509_VERIFY_PARAM_set1_host(vpm, "www.foo.com", 0);

VOIR AUSSI

ssl(7), X509_VERIFY_PARAM_set_flags(3)

HISTORIQUE

Ces fonctions ont été ajoutées dans OpenSSL 1.0.2.
