SSL_STREAM_RESET(3ssl) OpenSSL SSL_STREAM_RESET(3ssl)

NOM

SSL_stream_reset - réinitialiser un flux QUIC

SYNTAXE

#include <openssl/ssl.h>
typedef struct ssl_stream_reset_args_st {
    uint64_t quic_error_code;
} SSL_STREAM_RESET_ARGS;
int SSL_stream_reset(SSL *ssl,
                     const SSL_STREAM_RESET_ARGS *args,
                     size_t args_len);

DESCRIPTION

La fonction SSL_stream_reset() réinitialise la partie émission d'un flux QUIC lorsqu'elle est appelée sur un objet SSL de flux QUIC, ou sur un objet SSL de connexion QUIC avec un flux par défaut attaché.

Si args n'est pas NULL, args_len doit être défini sur sizeof(*args).

quic_error_code est un code d'erreur spécifié par l'application, qui doit être compris dans l'intervalle [0, 2**62-1]. Si args est NULL, une valeur de 0 est utilisée.

La réinitialisation d'un flux indique à une application que la partie émission du flux se termine anormalement. Lorsqu'un flux est réinitialisé, l'implémentation ne garantit pas que les données déjà passées à SSL_write(3) seront reçues par le pair, et les données déjà passées à SSL_write(3) mais pas encore transmises peuvent être discardées ou non. Par conséquent, vous ne devriez réinitialiser un flux que lorsque les informations transmises sur le flux n'ont plus d'importance, par exemple en cas d'erreur.

Cette fonction ne peut pas être appelée sur un flux unidirectionnel initié par le pair, car seul le côté émission d'un flux peut initier une réinitialisation de flux.

Il est également possible de déclencher une réinitialisation de flux en appelant SSL_free(3) ; voir la documentation de SSL_free(3) pour les détails.

La partie réception du flux (pour les flux bidirectionnels) continue de fonctionner normalement.

NOTES

Cette fonction correspond à l'image QUIC RESET_STREAM.

VALEURS DE RETOUR

Retourne 1 en cas de succès et 0 en cas d'échec.

Cette fonction échoue si elle est appelée sur un objet SSL de connexion QUIC sans flux par défaut attaché, ou sur un objet SSL non-QUIC.

Après le premier appel réussi à cette fonction pour un flux donné, les appels ultérieurs réussissent mais sont ignorés. Le code d'erreur de l'application utilisé est celui passé lors du premier appel réussi à cette fonction.

VOIR AUSSI

SSL_free(3)

HISTORIQUE

SSL_stream_reset() a été ajouté dans OpenSSL 3.2.
