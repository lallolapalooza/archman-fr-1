Licences: Apache-2.0

SSL_CTX_SET_CERT_STORE(3ssl) OpenSSL SSL_CTX_SET_CERT_STORE(3ssl)

NOM

SSL_CTX_set_cert_store, SSL_CTX_set1_cert_store, SSL_CTX_get_cert_store - manipuler le stockage de vérification des certificats X509

SYNTAXE

#include <openssl/ssl.h>
void SSL_CTX_set_cert_store(SSL_CTX *ctx, X509_STORE *store);
void SSL_CTX_set1_cert_store(SSL_CTX *ctx, X509_STORE *store);
X509_STORE *SSL_CTX_get_cert_store(const SSL_CTX *ctx);

DESCRIPTION

SSL_CTX_set_cert_store() définit/remplace le stockage de vérification de certificat de ctx par store. Si un autre objet X509_STORE est actuellement défini dans ctx, il sera libéré avec X509_STORE_free(). SSL_CTX_set_cert_store() prendra la propriété de store, c'est-à-dire que l'appel à X509_STORE_free(store) n'est plus nécessaire.

SSL_CTX_set1_cert_store() définit/remplace le stockage de vérification de certificat de ctx par store. Le compteur de références de store est incrémenté. Si un autre objet X509_STORE est actuellement défini dans ctx, il sera libéré avec X509_STORE_free().

SSL_CTX_get_cert_store() retourne un pointeur vers le stockage de vérification de certificat actuel. ctx **ne doit pas** être NUL.

NOTES

Afin de vérifier les certificats présentés par le pair, les certificats CA de confiance doivent être accessibles. Ces certificats CA sont mis à disposition via des méthodes de recherche, gérées à l'intérieur de X509_STORE. À partir de X509_STORE, le X509_STORE_CTX utilisé lors de la vérification des certificats est créé.

Généralement, le stockage des certificats de confiance est géré indirectement via l'utilisation de SSL_CTX_load_verify_locations(3). En utilisant les fonctions SSL_CTX_set_cert_store() et SSL_CTX_get_cert_store(), il est possible de manipuler l'objet X509_STORE au-delà de l'appel à SSL_CTX_load_verify_locations(3).

Actuellement, aucune documentation détaillée sur l'utilisation de l'objet X509_STORE n'est disponible. Tous les membres de X509_STORE ne sont pas utilisés lorsque la vérification a lieu. Ainsi, par exemple, verify_callback() sera remplacé par verify_callback() défini via la famille de fonctions SSL_CTX_set_verify(3). Ce document doit donc être mis à jour lorsque la documentation sur l'objet X509_STORE et sa gestion devient disponible.

SSL_CTX_set_cert_store() n'incrémente pas le compteur de références de store, il ne doit donc pas être utilisé pour affecter un X509_STORE appartenant à un autre SSL_CTX.

Pour partager des X509_STORE entre deux SSL_CTXs, utilisez SSL_CTX_get_cert_store() pour obtenir le X509_STORE du premier SSL_CTX, puis utilisez SSL_CTX_set1_cert_store() pour l'affecter au second SSL_CTX et incrémenter le compteur de références du X509_STORE.

RESTRICTIONS

La structure X509_STORE utilisée par un SSL_CTX sert à vérifier les certificats des pairs et à construire des chaînes de certificats, elle est également partagée par chaque structure SSL enfant. Les applications souhaitant un contrôle plus fin peuvent utiliser des fonctions comme SSL_CTX_set1_verify_cert_store() à la place.

VALEURS DE RETOUR

SSL_CTX_set_cert_store() ne retourne aucune sortie diagnostique.

SSL_CTX_set1_cert_store() ne retourne aucune sortie diagnostique.

SSL_CTX_get_cert_store() retourne le réglage actuel.

VOIR AUSSI

ssl(7), SSL_CTX_load_verify_locations(3), SSL_CTX_set_verify(3)
