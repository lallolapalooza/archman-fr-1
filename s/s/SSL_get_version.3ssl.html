SSL_get_version(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_GET_VERSION(3ssl) OpenSSL SSL_GET_VERSION(3ssl)

NOM

SSL_client_version, SSL_get_version, SSL_is_dtls, SSL_is_tls, SSL_is_quic, SSL_version - obtenir les informations de protocole d'une connexion

SYNTAXE

#include <openssl/ssl.h>
int SSL_client_version(const SSL *s);
const char *SSL_get_version(const SSL *ssl);
int SSL_is_dtls(const SSL *ssl);
int SSL_is_tls(const SSL *ssl);
int SSL_is_quic(const SSL *ssl);
int SSL_version(const SSL *s);

DESCRIPTION

Pour les protocoles SSL, TLS et DTLS, SSL_client_version() renvoie la version numérique du protocole annoncée par le client dans le champ legacy_version du ClientHello lors de l'initiation de la connexion. Notez que, pour TLS, cette valeur n'indiquera jamais une version supérieure à TLSv1.2, même si TLSv1.3 est négocié par la suite. Pour les connexions QUIC, elle renvoie OSSL_QUIC1_VERSION.

SSL_get_version() renvoie le nom du protocole utilisé pour la connexion. SSL_version() renvoie la version numérique du protocole utilisée pour la connexion. Ils ne doivent être appelés qu'après la fin de la négociation initiale. Avant cela, les résultats renvoyés par ces fonctions peuvent ne pas être fiables.

SSL_is_dtls() renvoie 1 si la connexion utilise DTLS ou 0 si ce n'est pas le cas.

SSL_is_tls() renvoie 1 si la connexion utilise SSL/TLS ou 0 si ce n'est pas le cas.

SSL_is_quic() renvoie 1 si la connexion utilise QUIC ou 0 si ce n'est pas le cas.

VALEURS DE RETOUR

SSL_get_version() renvoie l'une des chaînes suivantes :

SSLv3
La connexion utilise le protocole SSLv3.
TLSv1
La connexion utilise le protocole TLSv1.0.
TLSv1.1
La connexion utilise le protocole TLSv1.1.
TLSv1.2
La connexion utilise le protocole TLSv1.2.
TLSv1.3
La connexion utilise le protocole TLSv1.3.
DTLSv0.9
La connexion utilise un protocole DTLS pré-standardisation obsolète
DTLSv1
La connexion utilise le protocole DTLSv1
DTLSv1.2
La connexion utilise le protocole DTLSv1.2
QUICv1
La connexion utilise le protocole QUICv1.
inconnu
Indique une version de protocole inconnue.

SSL_version() et SSL_client_version() renvoient un entier qui peut inclure l'un des éléments suivants :

SSL3_VERSION
La connexion utilise le protocole SSLv3.
TLS1_VERSION
La connexion utilise le protocole TLSv1.0.
TLS1_1_VERSION
La connexion utilise le protocole TLSv1.1.
TLS1_2_VERSION
La connexion utilise le protocole TLSv1.2.
TLS1_3_VERSION
La connexion utilise le protocole TLSv1.3 (jamais renvoyé pour SSL_client_version()).
DTLS1_BAD_VER
La connexion utilise un protocole DTLS pré-standardisation obsolète
DTLS1_VERSION
La connexion utilise le protocole DTLSv1
DTLS1_2_VERSION
La connexion utilise le protocole DTLSv1.2
OSSL_QUIC1_VERSION
La connexion utilise le protocole QUICv1.

VOIR AUSSI

ssl(7)

HISTORIQUE

La fonction SSL_is_dtls() a été ajoutée dans OpenSSL 1.1.0. Les fonctions SSL_is_tls() et SSL_is_quic() ont été ajoutées dans OpenSSL 3.2.
