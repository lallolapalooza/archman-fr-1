NOM

SSL_CONF_cmd_argv - Traitement des commandes de configuration SSL par ligne de commande

SYNOPSIS

#include <openssl/ssl.h>
int SSL_CONF_cmd_argv(SSL_CONF_CTX *cctx, int *pargc, char ***pargv);

DESCRIPTION

La fonction SSL_CONF_cmd_argv() traite au maximum deux arguments de ligne de commande à partir de pargv et pargc. Les valeurs de pargv et pargc sont mises à jour pour refléter le nombre d'options de commande traitées. L'argument pargc peut être défini sur NULL s'il n'est pas utilisé.

VALEURS DE RETOUR

SSL_CONF_cmd_argv() retourne le nombre d'arguments de commande traités : 0, 1, 2 ou un code d'erreur négatif.

Si -2 est retourné, un argument pour une commande est manquant.

Si -1 est retourné, la commande est reconnue mais n'a pas pu être traitée en raison d'une erreur : par exemple, une erreur de syntaxe dans l'argument.

VOIR AUSSI

ssl(7), SSL_CONF_CTX_new(3), SSL_CONF_CTX_set_flags(3), SSL_CONF_CTX_set1_prefix(3), SSL_CONF_CTX_set_ssl_ctx(3), SSL_CONF_cmd(3)
