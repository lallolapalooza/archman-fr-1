SSL_get_all_async_fds(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_GET_ALL_ASYNC_FDS(3ssl) OpenSSL SSL_GET_ALL_ASYNC_FDS(3ssl)

NOM

SSL_waiting_for_async, SSL_get_all_async_fds, SSL_get_changed_async_fds - gérer les opérations asynchrones

SYNTAXE

#include <openssl/async.h>
#include <openssl/ssl.h>
int SSL_waiting_for_async(SSL *s);
int SSL_get_all_async_fds(SSL *s, OSSL_ASYNC_FD *fd, size_t *numfds);
int SSL_get_changed_async_fds(SSL *s, OSSL_ASYNC_FD *addfd, size_t *numaddfds,
                              OSSL_ASYNC_FD *delfd, size_t *numdelfds);

DESCRIPTION

SSL_waiting_for_async() détermine si une connexion SSL est actuellement en attente d'opérations asynchrones pour se terminer (voir le mode SSL_MODE_ASYNC dans SSL_CTX_set_mode(3)).

SSL_get_all_async_fds() renvoie une liste de descripteurs de fichiers qui peuvent être utilisés dans un appel à select() ou poll() pour déterminer si l'opération asynchrone actuelle s'est terminée ou non. Une opération terminée entraînera l'apparition de données comme "prêtes à être lues" sur le descripteur de fichier (aucune donnée réelle ne doit être lue à partir du descripteur de fichier). Cette fonction ne doit être appelée que si l'objet SSL attend actuellement la fin des travaux asynchrones (c'est-à-dire si SSL_ERROR_WANT_ASYNC a été reçu - voir SSL_get_error(3)). Généralement, la liste ne contiendra qu'un seul descripteur de fichier. Cependant, si plusieurs moteurs capables d'asynchronisme sont utilisés, il est possible d'en avoir plus d'un. Le nombre de descripteurs de fichiers renvoyés est stocké dans *numfds et les descripteurs de fichiers eux-mêmes sont dans *fds. Le paramètre fds peut être NULL auquel cas aucun descripteur de fichier n'est renvoyé mais *numfds est toujours rempli. Il incombe à l'appelant de s'assurer qu'une mémoire suffisante est allouée à *fds, donc cette fonction est généralement appelée deux fois (une fois avec un paramètre fds NULL et une fois sans).

SSL_get_changed_async_fds() renvoie une liste des descripteurs de fichiers asynchrones qui ont été ajoutés et une liste de ceux qui ont été supprimés depuis la dernière réception de SSL_ERROR_WANT_ASYNC (ou depuis la création de l'objet SSL si aucun SSL_ERROR_WANT_ASYNC n'a été reçu). Similairement à SSL_get_all_async_fds(), il incombe à l'appelant de s'assurer que *addfd et *delfd disposent de suffisamment de mémoire allouée, bien qu'ils puissent être NULL. Le nombre de descripteurs ajoutés et le nombre de descripteurs supprimés sont stockés respectivement dans *numaddfds et *numdelfds.

VALEURS DE RETOUR

SSL_waiting_for_async() renverra 1 si l'opération SSL actuelle attend la fin d'une opération asynchrone et 0 sinon.

SSL_get_all_async_fds() et SSL_get_changed_async_fds() renvoient 1 en cas de succès ou 0 en cas d'erreur.

NOTES

Sur les plateformes Windows, l'en-tête <openssl/async.h> dépend de certains types traditionnellement mis à disposition en incluant <windows.h>. Le développeur de l'application est susceptible d'avoir besoin de contrôler quand ce dernier est inclus, généralement comme l'un des premiers en-têtes inclus. Par conséquent, il est de la responsabilité du développeur de l'application d'inclure <windows.h> avant <openssl/async.h>.

VOIR AUSSI

ssl(7), SSL_get_error(3), SSL_CTX_set_mode(3)

HISTORIQUE

Les fonctions SSL_waiting_for_async(), SSL_get_all_async_fds() et SSL_get_changed_async_fds() ont été ajoutées dans OpenSSL 1.1.0.
