NOM

SSL_set_blocking_mode, SSL_get_blocking_mode - configurer le mode bloquant pour un objet SSL QUIC

SYNTAXE

#include <openssl/ssl.h>
int SSL_set_blocking_mode(SSL *s, int blocking);
int SSL_get_blocking_mode(SSL *s);

DESCRIPTION

SSL_set_blocking_mode() peut être utilisée pour activer ou désactiver le mode bloquant sur un objet SSL QUIC. Par défaut, le blocage est activé, à moins que l'objet SSL ne soit configuré pour utiliser un BIO de lecture ou d'écriture sous-jacent qui ne peut pas fournir de descripteur de sondage (voir BIO_get_rpoll_descriptor(3)), car le mode bloquant ne peut pas être pris en charge dans ce cas.

Pour activer le mode bloquant, appelez SSL_set_blocking_mode() avec blocking défini sur 1 ; pour le désactiver, appelez SSL_set_blocking_mode() avec blocking défini sur 0.

Pour récupérer le mode bloquant actuel, appelez SSL_get_blocking_mode().

Le mode bloquant signifie que les appels tels que SSL_read() et SSL_write() bloqueront jusqu'à ce que l'opération demandée puisse être effectuée. En mode non bloquant, ces appels échoueront si l'opération demandée ne peut pas être effectuée immédiatement ; voir SSL_get_error(3).

Ces fonctions ne sont applicables qu'aux objets SSL de connexion QUIC. D'autres types d'objets SSL, comme ceux pour TLS, fonctionnent automatiquement en mode bloquant ou non bloquant en fonction de si les BIO de lecture et d'écriture réseau sous-jacents fournis à l'objet SSL sont eux-mêmes configurés en mode non bloquant.

Lorsqu'un objet SSL de connexion QUIC est utilisé en mode non bloquant, une application est responsable de s'assurer que l'objet SSL est régulièrement mis à jour ; voir SSL_handle_events(3).

Le mode bloquant est désactivé automatiquement si l'application fournit à un objet SSL de connexion QUIC un BIO réseau qui ne peut pas prendre en charge le mode bloquant. Pour réactiver le mode bloquant dans ce cas, une application doit définir un BIO réseau qui peut prendre en charge le mode bloquant et appeler explicitement SSL_set_blocking_mode().

VALEURS DE RETOUR

SSL_set_blocking_mode() renvoie 1 en cas de succès et 0 en cas d'échec. La fonction échoue si elle est appelée sur un objet SSL qui ne représente pas une connexion QUIC, ou si le mode bloquant ne peut pas être utilisé pour la connexion donnée.

SSL_get_blocking_mode() renvoie 1 si le blocage est actuellement activé. Il renvoie -1 si appelé sur un objet SSL non pris en charge.

VOIR AUSSI

SSL_handle_events(3), SSL_poll(3), openssl-quic(7), openssl-quic-concurrency(7), ssl(7)

HISTORIQUE

Les fonctions SSL_set_blocking_mode() et SSL_get_blocking_mode() ont été ajoutées dans OpenSSL 3.2.
