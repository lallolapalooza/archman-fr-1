NOM

SSL_set_shutdown, SSL_get_shutdown - manipuler l'état de fermeture d'une connexion SSL

SYNOPSIS

#include <openssl/ssl.h>
void SSL_set_shutdown(SSL *ssl, int mode);
int SSL_get_shutdown(const SSL *ssl);

DESCRIPTION

SSL_set_shutdown() définit l'état de fermeture de ssl à mode.

SSL_get_shutdown() renvoie le mode de fermeture de ssl.

NOTES

L'état de fermeture d'une connexion ssl est un masque de bits de :

0
Aucun réglage de fermeture pour le moment.
SSL_SENT_SHUTDOWN
Une alerte de fermeture close_notify a été envoyée au pair, la connexion est considérée comme fermée et la session est fermée et correcte.
SSL_RECEIVED_SHUTDOWN
Une alerte de fermeture a été reçue du pair, soit un close_notify normal, soit une erreur fatale.

SSL_SENT_SHUTDOWN et SSL_RECEIVED_SHUTDOWN peuvent être définis en même temps.

L'état de fermeture de la connexion est utilisé pour déterminer l'état de la session ssl. Si la session est toujours ouverte lors de l'appel de SSL_clear(3) ou SSL_free(3), elle est considérée comme mauvaise et supprimée conformément à la RFC2246. La condition réelle pour une session correctement fermée est SSL_SENT_SHUTDOWN (selon la RFC TLS, il est acceptable de seulement envoyer l'alerte close_notify sans attendre la réponse du pair, lorsque la connexion sous-jacente est fermée). SSL_set_shutdown() peut être utilisée pour définir cet état sans envoyer d'alerte de fermeture au pair (voir SSL_shutdown(3)).

Si un close_notify a été reçu, SSL_RECEIVED_SHUTDOWN sera défini. Pour définir SSL_SENT_SHUTDOWN, l'application doit cependant toujours appeler SSL_shutdown(3) ou SSL_set_shutdown() elle-même.

SSL_set_shutdown() n'est pas prise en charge pour les objets SSL QUIC.

VALEURS DE RETOUR

SSL_set_shutdown() ne renvoie pas d'informations diagnostiques.

SSL_get_shutdown() renvoie l'état de fermeture actuel tel que défini ou basé sur l'état réel de la connexion.

SSL_get_shutdown() renvoie 0 si appelé sur un objet SSL de flux QUIC. S'il est appelé sur un objet SSL de connexion QUIC, il renvoie une valeur avec SSL_SENT_SHUTDOWN définie si CONNECTION_CLOSE a été envoyée au pair et il renvoie une valeur avec SSL_RECEIVED_SHUTDOWN définie si CONNECTION_CLOSE a été reçue du pair ou si la connexion QUIC est complètement terminée pour d'autres raisons.
