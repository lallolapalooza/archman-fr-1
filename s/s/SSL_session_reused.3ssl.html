NOM

SSL_session_reused - interroger si une session réutilisée a été négociée pendant l'établissement de la connexion

SYNTAXE

#include <openssl/ssl.h>
int SSL_session_reused(const SSL *ssl);

DESCRIPTION

Interroge si une session réutilisée a été négociée pendant l'établissement de la connexion.

NOTES

Pendant la négociation, un client peut proposer de réutiliser une session. Le serveur recherche alors la session dans son cache. Si le client et le serveur se mettent d'accord sur la session, elle sera réutilisée et un drapeau sera activé qui pourra être interrogé par l'application.

VALEUR DE RETOUR

Les valeurs de retour suivantes peuvent apparaître :

0
Une nouvelle session a été négociée.
1
Une session a été réutilisée.

VOIR AUSSI

ssl(7), SSL_set_session(3), SSL_CTX_set_session_cache_mode(3)
