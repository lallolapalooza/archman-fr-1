SSL_CTX_set_keylog_callback(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_SET_KEYLOG_CALLBACK(3ssl) OpenSSL SSL_CTX_SET_KEYLOG_CALLBACK(3ssl)

NOM

SSL_CTX_set_keylog_callback, SSL_CTX_get_keylog_callback, SSL_CTX_keylog_cb_func - enregistrement du matériel clé TLS

SYNOPIS

#include <openssl/ssl.h>
typedef void (*SSL_CTX_keylog_cb_func)(const SSL *ssl, const char *line);
void SSL_CTX_set_keylog_callback(SSL_CTX *ctx, SSL_CTX_keylog_cb_func cb);
SSL_CTX_keylog_cb_func SSL_CTX_get_keylog_callback(const SSL_CTX *ctx);

DESCRIPTION

SSL_CTX_set_keylog_callback() définit la fonction de rappel pour l'enregistrement des clés TLS. Cette fonction de rappel est appelée chaque fois qu'un matériel clé TLS est généré ou reçu, afin de permettre aux applications de stocker ce matériel de chiffrement à des fins de débogage.

SSL_CTX_get_keylog_callback() récupère la fonction de rappel d'enregistrement des clés TLS précédemment définie. Si aucune fonction de rappel n'a été définie, elle retourne NULL. Lorsqu'il n'y a pas de fonction de rappel d'enregistrement des clés, ou si SSL_CTX_set_keylog_callback est appelée avec NULL comme valeur de cb, aucun enregistrement du matériel clé ne sera effectué.

La fonction de rappel d'enregistrement des clés est appelée avec deux éléments : l'objet ssl associé à la connexion, et line, une chaîne contenant le matériel clé au format utilisé par NSS pour sa sortie de débogage SSLKEYLOGFILE. Pour recréer ce fichier, la fonction de rappel d'enregistrement des clés doit enregistrer line, suivi d'un retour à la ligne. line sera toujours une chaîne terminée par NUL.

VALEUR DE RETOUR

SSL_CTX_get_keylog_callback() retourne un pointeur vers SSL_CTX_keylog_cb_func ou NULL si la fonction de rappel n'est pas définie.
