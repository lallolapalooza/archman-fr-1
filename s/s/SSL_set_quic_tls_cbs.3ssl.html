SSL_set_quic_tls_cbs(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_SET_QUIC_TLS_CBS(3ssl) OpenSSL SSL_SET_QUIC_TLS_CBS(3ssl)

NOM

OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_SEND, OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RECV_RCD, OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RELEASE_RCD, OSSL_FUNC_SSL_QUIC_TLS_YIELD_SECRET, OSSL_FUNC_SSL_QUIC_TLS_GOT_TRANSPORT_PARAMS, OSSL_FUNC_SSL_QUIC_TLS_ALERT, SSL_set_quic_tls_cbs, SSL_set_quic_tls_transport_params, SSL_set_quic_tls_early_data_enabled - Utilisation de l'implémentation TLS d'OpenSSL pour une implémentation QUIC tierce

SYNOPIS

#include <openssl/ssl.h>
/* Callbacks disponibles via une table OSSL_DISPATCH */
/* Fonction id : OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_SEND */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_SEND)(SSL *s,
                                                     const unsigned char *buf,
                                                     size_t buf_len,
                                                     size_t *consumed,
                                                     void *arg);
/* Fonction id : OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RECV_RCD */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RECV_RCD)(SSL *s,
                                                   const unsigned char **buf,
                                                   size_t *bytes_read,
                                                   void *arg);
/* Fonction id : OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RELEASE_RCD */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RELEASE_RCD)(SSL *,
                                                            size_t bytes_read,
                                                            void *arg);
/* Fonction id : OSSL_FUNC_SSL_QUIC_TLS_YIELD_SECRET */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_YIELD_SECRET)(SSL *s,
                                                   uint32_t prot_level,
                                                   int direction,
                                                   const unsigned char *secret,
                                                   size_t secret_len,
                                                   void *arg);
/* Fonction id : OSSL_FUNC_SSL_QUIC_TLS_GOT_TRANSPORT_PARAMS */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_GOT_TRANSPORT_PARAMS)(SSL *s,
                                                   const unsigned char *params,
                                                   size_t params_len,
                                                   void *arg);
/* Fonction id : OSSL_FUNC_SSL_QUIC_TLS_ALERT */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_ALERT)(SSL *s,
                                               unsigned char alert_code,
                                               void *arg);
int SSL_set_quic_tls_cbs(SSL *s, const OSSL_DISPATCH *qtdis, void *arg);
int SSL_set_quic_tls_transport_params(SSL *s,
                                      const unsigned char *params,
                                      size_t params_len);
int SSL_set_quic_tls_early_data_enabled(SSL *s, int enabled);

DESCRIPTION

SSL_set_quic_tls_cbs() peut être utilisé pour remplacer la couche d'enregistrement standard par une couche personnalisée pour une utilisation par une implémentation QUIC tierce. Pour l'objet s donné, un ensemble de callbacks est fourni dans une table OSSL_DISPATCH via qtdis. Le paramètre arg est passé comme argument lors de l'appel des diverses callbacks.

Une table OSSL_DISPATCH doit consister en un tableau d'entrées OSSL_DISPATCH où chaque entrée est un identifiant de fonction et un pointeur vers une fonction. Le tableau doit être terminé par une entrée vide (c'est-à-dire un identifiant de fonction 0 et un pointeur vers une fonction NULL).

L'appel à la fonction SSL_set_quic_tls_cbs() désactivera l'option SSL_OP_ENABLE_MIDDLEBOX_COMPAT (si elle est configurée). Voir SSL_set_options(3). De plus, la version minimale de TLS sera définie à TLS1_3_VERSION. Il est erroné d'appeler cette fonction avec un objet SSL autre que de type TLS.

La fonction de callback OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_SEND (identifiant de fonction OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_SEND) est appelée lorsqu'il faut envoyer des données CRYPTO à l'homologue. Les données à envoyer sont fournies dans le tampon buf de longueur buf_len. La fonction peut choisir de consommer moins de données que celles fournies dans le tampon. En cas de succès de la callback, le paramètre consumed doit être rempli avec la quantité de données que la callback a consommée. Cela doit être inférieur ou égal à la valeur dans buf_len. Les données CRYPTO sont envoyées en utilisant le niveau de cryptage le plus récent établi via la fonction de callback OSSL_FUNC_SSL_QUIC_TLS_YIELD_SECRET (si elle a été appelée).

La fonction de callback OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RECV_RCD (identifiant de fonction OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RECV_RCD) est utilisée pour recevoir des données CRYPTO de l'homologue. Lorsque OpenSSL souhaite lire des données de l'homologue, cette callback est appelée. La callback doit remplir *buf avec un pointeur vers un tampon contenant des données CRYPTO reçues de l'homologue. La longueur du tampon doit être renseignée dans *bytes_read. Le tampon doit rester valide jusqu'à ce qu'OpenSSL appelle la fonction de callback OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RELEASE_RCD. Les données CRYPTO sont supposées avoir été déchiffrées en utilisant le niveau de protection le plus récent établi via la fonction de callback OSSL_FUNC_SSL_QUIC_TLS_YIELD_SECRET (si elle a été appelée).

La fonction de callback OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RELEASE_RCD (identifiant de fonction OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RELEASE_RCD) est appelée lorsque les données précédemment lues via la fonction de callback OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RECV_RCD ne sont plus nécessaires. L'argument bytes_read est toujours égal à la taille du tampon précédemment fourni dans la callback OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RECV_RCD. Un seul enregistrement sera lu par OpenSSL à la fois.

La fonction de callback OSSL_FUNC_SSL_QUIC_TLS_YIELD_SECRET (identifiant de fonction OSSL_FUNC_SSL_QUIC_TLS_YIELD_SECRET) est appelée lorsqu'un nouveau secret a été établi. L'argument prot_level identifie le niveau de protection TLS et sera l'un de OSSL_RECORD_PROTECTION_LEVEL_NONE, OSSL_RECORD_PROTECTION_LEVEL_EARLY, OSSL_RECORD_PROTECTION_LEVEL_HANDSHAKE ou OSSL_RECORD_PROTECTION_LEVEL_APPLICATION. La valeur direction sera 0 (pour le secret de lecture) ou 1 (pour le secret d'écriture). Le secret lui-même se trouvera dans le tampon pointé par secret et la taille du tampon sera secret_len.

La fonction de callback OSSL_FUNC_SSL_QUIC_TLS_GOT_TRANSPORT_PARAMS (identifiant de fonction OSSL_FUNC_SSL_QUIC_TLS_GOT_TRANSPORT_PARAMS) est appelée lorsque les paramètres de transport de l'homologue ont été reçus. Les paramètres sont stockés dans le tampon params de longueur params_len.

La fonction de callback OSSL_FUNC_SSL_QUIC_TLS_ALERT (identifiant de fonction OSSL_FUNC_SSL_QUIC_TLS_ALERT) est appelée lorsqu'OpenSSL tente d'envoyer une alerte à l'homologue. Le code d'alerte est fourni dans alert_code.

La fonction SSL_set_quic_tls_transport_params() est utilisée pour définir les paramètres de transport à envoyer par ce point d'extrémité. Les paramètres se trouvent dans le tampon params de longueur params_len. Le tampon contenant les paramètres doit rester valide jusqu'à ce que les paramètres aient été envoyés. Cette fonction doit avoir été appelée avant l'envoi des paramètres. Pour un client, cela se produira avant le début de la connexion. Pour un serveur, cela peut se produire lors de l'appel à got_transport_params_cb.

La fonction SSL_set_quic_tls_early_data_enabled() est utilisée pour activer la fonctionnalité 0-RTT pour une implémentation QUIC tierce.

VALEURS DE RETOUR

Ces fonctions renvoient 1 en cas de succès et 0 en cas d'échec.

Toutes les callbacks doivent également retourner 1 en cas de succès et 0 en cas d'échec. Une réponse d'échec est fatale pour la connexion.

EXEMPLES

Un appel à SSL_set_quic_tls_cbs() pourrait ressembler à ceci, étant donné les définitions appropriées des fonctions de callback :

const OSSL_DISPATCH qtdis[] = {
    {OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_SEND, (void (*)(void))crypto_send_cb},
    {OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RECV_RCD,
        (void (*)(void))crypto_recv_rcd_cb},
    {OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RELEASE_RCD,
        (void (*)(void))crypto_release_rcd_cb},
    {OSSL_FUNC_SSL_QUIC_TLS_YIELD_SECRET,
        (void (*)(void))yield_secret_cb},
    {OSSL_FUNC_SSL_QUIC_TLS_GOT_TRANSPORT_PARAMS,
        (void (*)(void))got_transport_params_cb},
    {OSSL_FUNC_SSL_QUIC_TLS_ALERT, (void (*)(void))alert_cb},
    {0, NULL}
 };
if (!SSL_set_quic_tls_cbs(ssl, qtdis, NULL))
    goto err;

HISTORIQUE

Ces fonctions ont été ajoutées dans OpenSSL 3.5.
