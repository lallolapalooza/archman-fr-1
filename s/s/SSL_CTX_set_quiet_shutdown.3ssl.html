SSL_CTX_set_quiet_shutdown(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_SET_QUIET_SHUTDOWN(3ssl) OpenSSL SSL_CTX_SET_QUIET_SHUTDOWN(3ssl)

NOM

SSL_CTX_set_quiet_shutdown, SSL_CTX_get_quiet_shutdown, SSL_set_quiet_shutdown, SSL_get_quiet_shutdown - manipuler le comportement de fermeture

SYNTAXE

#include <openssl/ssl.h>
void SSL_CTX_set_quiet_shutdown(SSL_CTX *ctx, int mode);
int SSL_CTX_get_quiet_shutdown(const SSL_CTX *ctx);
void SSL_set_quiet_shutdown(SSL *ssl, int mode);
int SSL_get_quiet_shutdown(const SSL *ssl);

DESCRIPTION

SSL_CTX_set_quiet_shutdown() définit l'indicateur de "fermeture silencieuse" pour ctx à mode. Les objets SSL créés à partir de ctx héritent du mode valide au moment où SSL_new(3) est appelé. mode peut être 0 ou 1.

SSL_CTX_get_quiet_shutdown() retourne le réglage de "fermeture silencieuse" de ctx.

SSL_set_quiet_shutdown() définit l'indicateur de "fermeture silencieuse" pour ssl à mode. Le réglage reste valide jusqu'à ce que ssl soit supprimé avec SSL_free(3) ou que SSL_set_quiet_shutdown() soit appelé à nouveau. Il n'est pas modifié lorsque SSL_clear(3) est appelé. mode peut être 0 ou 1.

SSL_get_quiet_shutdown() retourne le réglage de "fermeture silencieuse" de ssl.

Ces fonctions ne sont pas prises en charge pour les objets SSL QUIC. SSL_set_quiet_shutdown() n'a aucun effet si elle est appelée sur un objet SSL QUIC.

NOTES

Normalement, lorsqu'une connexion SSL est terminée, les parties doivent envoyer des messages d'alerte close_notify en utilisant SSL_shutdown(3) pour une fermeture propre.

Lorsqu'on définit l'indicateur de "fermeture silencieuse" à 1, SSL_shutdown(3) définit les indicateurs internes à SSL_SENT_SHUTDOWN|SSL_RECEIVED_SHUTDOWN. (SSL_shutdown(3) se comporte alors comme SSL_set_shutdown(3) appelé avec SSL_SENT_SHUTDOWN|SSL_RECEIVED_SHUTDOWN.) La session est donc considérée comme fermée, mais aucune alerte close_notify n'est envoyée à l'homologue. Ce comportement viole la norme TLS.

Par défaut, le comportement est une fermeture normale, comme décrit par la norme TLS.

VALEURS DE RETOUR

SSL_CTX_set_quiet_shutdown() et SSL_set_quiet_shutdown() ne retournent pas d'informations de diagnostic.

SSL_CTX_get_quiet_shutdown() et SSL_get_quiet_shutdown() retournent le réglage actuel.
