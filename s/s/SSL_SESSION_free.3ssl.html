SSL_SESSION_free(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_SESSION_FREE(3ssl) OpenSSL SSL_SESSION_FREE(3ssl)

NOM

SSL_SESSION_new, SSL_SESSION_dup, SSL_SESSION_up_ref, SSL_SESSION_free - créer, libérer et gérer les structures SSL_SESSION

SYNTAXE

#include <openssl/ssl.h>
SSL_SESSION *SSL_SESSION_new(void);
SSL_SESSION *SSL_SESSION_dup(const SSL_SESSION *src);
int SSL_SESSION_up_ref(SSL_SESSION *ses);
void SSL_SESSION_free(SSL_SESSION *session);

DESCRIPTION

SSL_SESSION_new() crée une nouvelle structure SSL_SESSION et renvoie un pointeur vers celle-ci.

SSL_SESSION_dup() crée une nouvelle structure SSL_SESSION qui est une copie de src. La copie n'est pas détenue par un cache auquel src aurait pu appartenir.

SSL_SESSION_up_ref() incrémente le compteur de références sur la structure SSL_SESSION donnée.

SSL_SESSION_free() décrémente le compteur de références de session et supprime la structure SSL_SESSION pointée par session ainsi que la mémoire allouée, si le compteur de références a atteint 0. Si session est NULL, rien n'est fait.

NOTES

Les objets SSL_SESSION sont alloués lorsqu'une opération de négociation TLS/SSL est terminée avec succès. Selon les paramètres, voir SSL_CTX_set_session_cache_mode(3), les objets SSL_SESSION sont référencés en interne par le SSL_CTX et liés à son cache de sessions. Les objets SSL peuvent utiliser l'objet SSL_SESSION ; comme une session peut être réutilisée, plusieurs objets SSL peuvent utiliser un même objet SSL_SESSION en même temps. Il est donc crucial de maintenir le compteur de références (informations d'utilisation) correct et de ne pas supprimer un objet SSL_SESSION qui est encore utilisé, car cela pourrait entraîner des pannes de programme dues à des pointeurs invalides. Ces pannes peuvent aussi apparaître avec un délai, par exemple lorsqu'un objet SSL_SESSION a été complètement libéré car le compteur de références est incorrectement tombé à 0, mais qu'il est toujours référencé dans le cache de sessions interne et que la liste du cache est traitée lors d'une opération de SSL_CTX_flush_sessions(3).

SSL_SESSION_free() ne doit être appelée que pour les objets SSL_SESSION pour lesquels le compteur de références a été explicitement incrémenté (par exemple, en appelant SSL_get1_session(), voir SSL_get_session(3)) ou lorsque l'objet SSL_SESSION a été généré en dehors d'une opération de négociation TLS, par exemple, en utilisant d2i_SSL_SESSION(3). Il ne doit pas être appelé sur d'autres objets SSL_SESSION, car cela entraînerait des compteurs de références incorrects et donc des pannes de programme.

VALEURS DE RETOUR

SSL_SESSION_new renvoie un pointeur vers la structure SSL_SESSION nouvellement allouée ou NULL en cas d'erreur.

SSL_SESSION_dup renvoie un pointeur vers la nouvelle copie ou NULL en cas d'erreur.

SSL_SESSION_up_ref renvoie 1 en cas de succès ou 0 en cas d'erreur.

VOIR AUSSI

ssl(7), SSL_get_session(3), SSL_CTX_set_session_cache_mode(3), SSL_CTX_flush_sessions(3), d2i_SSL_SESSION(3)

HISTORIQUE

La fonction SSL_SESSION_dup() a été ajoutée dans OpenSSL 1.1.1.
