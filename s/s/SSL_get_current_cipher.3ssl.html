SSL_get_current_cipher(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_GET_CURRENT_CIPHER(3ssl) OpenSSL SSL_GET_CURRENT_CIPHER(3ssl)

NOM

SSL_get_current_cipher, SSL_get_cipher_name, SSL_get_cipher, SSL_get_cipher_bits, SSL_get_cipher_version, SSL_get_pending_cipher - obtenir le chiffrement SSL_CIPHER d'une connexion

SYNTAXE

#include <openssl/ssl.h>
const SSL_CIPHER *SSL_get_current_cipher(const SSL *ssl);
const SSL_CIPHER *SSL_get_pending_cipher(const SSL *ssl);
const char *SSL_get_cipher_name(const SSL *s);
const char *SSL_get_cipher(const SSL *s);
int SSL_get_cipher_bits(const SSL *s, int *np);
const char *SSL_get_cipher_version(const SSL *s);

DESCRIPTION

SSL_get_current_cipher() retourne un pointeur vers un objet SSL_CIPHER contenant la description du chiffrement réellement utilisé pour une connexion établie avec l'objet ssl. ssl NE DOIT PAS être NULL. Voir SSL_CIPHER_get_name(3) pour plus de détails.

SSL_get_cipher_name() obtient le nom du chiffrement actuellement utilisé. SSL_get_cipher() est identique à SSL_get_cipher_name(). SSL_get_cipher_bits() est une macro pour obtenir le nombre de bits secrets/algorithmiques utilisés et SSL_get_cipher_version() retourne le nom du protocole.

SSL_get_pending_cipher() retourne un pointeur vers un objet SSL_CIPHER contenant la description du chiffrement (le cas échéant) qui a été négocié pour une utilisation future sur la connexion établie avec l'objet ssl, mais qui n'est pas encore utilisé. Cela peut arriver pendant le traitement de la négociation (handshake), lorsque le flux de contrôle peut être retourné à l'application via l'une des plusieurs méthodes de rappel (callback). La séquence interne de traitement de la négociation et de l'invocation des rappels n'est pas garantie d'être stable d'une version à l'autre, et à l'heure actuelle seul le rappel défini par SSL_CTX_set_alpn_select_cb() est garanti de retourner une valeur non NULL. D'autres rappels pourront être ajoutés à cette liste au fil du temps.

VALEURS DE RETOUR

SSL_get_current_cipher() retourne le chiffrement réellement utilisé, ou NULL si aucune session n'a été établie.

SSL_get_pending_cipher() retourne le chiffrement à utiliser lors du prochain changement de suite de chiffrement, ou NULL si aucun chiffrement de ce type n'est connu.

NOTES

SSL_get_cipher, SSL_get_cipher_bits, SSL_get_cipher_version, et SSL_get_cipher_name sont implémentés comme des macros.

VOIR AUSSI

ssl(7), SSL_CIPHER_get_name(3)
