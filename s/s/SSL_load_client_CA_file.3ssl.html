SSL_load_client_CA_file(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_LOAD_CLIENT_CA_FILE(3ssl) OpenSSL SSL_LOAD_CLIENT_CA_FILE(3ssl)

NOM

SSL_load_client_CA_file_ex, SSL_load_client_CA_file, SSL_add_file_cert_subjects_to_stack, SSL_add_dir_cert_subjects_to_stack, SSL_add_store_cert_subjects_to_stack - charger les noms de certificats

SYNTAXE

#include <openssl/ssl.h>
STACK_OF(X509_NAME) *SSL_load_client_CA_file_ex(const char *file,
                                                OSSL_LIB_CTX *libctx,
                                                const char *propq);
STACK_OF(X509_NAME) *SSL_load_client_CA_file(const char *file);
int SSL_add_file_cert_subjects_to_stack(STACK_OF(X509_NAME) *stack,
                                        const char *file);
int SSL_add_dir_cert_subjects_to_stack(STACK_OF(X509_NAME) *stack,
                                       const char *dir);
int SSL_add_store_cert_subjects_to_stack(STACK_OF(X509_NAME) *stack,
                                         const char *store);

DESCRIPTION

SSL_load_client_CA_file_ex() lit les certificats du fichier file et retourne un STACK_OF(X509_NAME) contenant les noms des sujets trouvés. Le contexte de bibliothèque libctx et la requête de propriétés propq sont utilisés lors de la récupération des algorithmes auprès des fournisseurs.

SSL_load_client_CA_file() est similaire à SSL_load_client_CA_file_ex() mais utilise NULL pour le contexte de bibliothèque libctx et la requête de propriétés propq.

SSL_add_file_cert_subjects_to_stack() lit les certificats du fichier file et ajoute leur nom de sujet à la pile stack déjà existante.

SSL_add_dir_cert_subjects_to_stack() lit les certificats de chaque fichier dans le répertoire dir et ajoute leur nom de sujet à la pile stack déjà existante.

SSL_add_store_cert_subjects_to_stack() charge les certificats à partir de l'URI du magasin store et ajoute leur nom de sujet à la pile stack déjà existante.

NOTES

SSL_load_client_CA_file() lit un fichier de certificats au format PEM et extrait les X509_NAMES des certificats trouvés. Bien que le nom suggère une utilisation spécifique en tant que fonction de support pour SSL_CTX_set_client_CA_list(3), elle n'est pas limitée aux certificats d'autorité de certification (CA).

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent survenir pour SSL_load_client_CA_file_ex() et SSL_load_client_CA_file() :

NULL
L'opération a échoué, consultez la pile d'erreurs pour connaître la raison.
Pointeur vers STACK_OF(X509_NAME)
Pointeur vers les noms des sujets des certificats lus avec succès.

Les valeurs de retour suivantes peuvent survenir pour SSL_add_file_cert_subjects_to_stack(), SSL_add_dir_cert_subjects_to_stack() et SSL_add_store_cert_subjects_to_stack() :

0 (Échec)
L'opération a échoué.
1 (Succès)
L'opération a réussi.

EXEMPLES

Charger les noms des CA à partir d'un fichier et les utiliser comme liste de CA clients :

SSL_CTX *ctx;
STACK_OF(X509_NAME) *cert_names;
...
cert_names = SSL_load_client_CA_file("/chemin/vers/CAfile.pem");
if (cert_names != NULL)
    SSL_CTX_set_client_CA_list(ctx, cert_names);
else
    /* erreur */
...

VOIR AUSSI

ssl(7), ossl_store(7), SSL_CTX_set_client_CA_list(3)

HISTORIQUE

SSL_load_client_CA_file_ex() et SSL_add_store_cert_subjects_to_stack() ont été ajoutés dans OpenSSL 3.0.
