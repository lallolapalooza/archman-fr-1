SSL_CTX_set_cipher_list(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_set_cipher_list(3ssl) OpenSSL SSL_CTX_set_cipher_list(3ssl)

NOM

SSL_CTX_set_cipher_list, SSL_set_cipher_list, SSL_CTX_set_ciphersuites, SSL_set_ciphersuites, OSSL_default_cipher_list, OSSL_default_ciphersuites - choisir une liste de chiffrements disponibles

SYNTAXIS

#include <openssl/ssl.h>
int SSL_CTX_set_cipher_list(SSL_CTX *ctx, const char *str);
int SSL_set_cipher_list(SSL *ssl, const char *str);
int SSL_CTX_set_ciphersuites(SSL_CTX *ctx, const char *str);
int SSL_set_ciphersuites(SSL *s, const char *str);
const char *OSSL_default_cipher_list(void);
const char *OSSL_default_ciphersuites(void);

DESCRIPTION

SSL_CTX_set_cipher_list() définit la liste des chiffrements disponibles (TLSv1.2 et versions antérieures) pour ctx en utilisant la chaîne de contrôle str. Le format de la chaîne est décrit dans openssl-ciphers(1). La liste des chiffrements est héritée par tous les objets ssl créés à partir de ctx. Cette fonction n'affecte pas les suites de chiffrements TLSv1.3. Utilisez SSL_CTX_set_ciphersuites() pour les configurer. ctx DOIT être non nul.

SSL_set_cipher_list() définit la liste des chiffrements (TLSv1.2 et versions antérieures) uniquement pour ssl.

SSL_CTX_set_ciphersuites() est utilisé pour configurer les suites de chiffrements TLSv1.3 pour ctx. Il s'agit d'une liste de suites de chiffrements TLSv1.3 séparées par des deux-points (":") dans l'ordre de préférence. Les noms valides de suites de chiffrements TLSv1.3 sont :

TLS_AES_128_GCM_SHA256
TLS_AES_256_GCM_SHA384
TLS_CHACHA20_POLY1305_SHA256
TLS_AES_128_CCM_SHA256
TLS_AES_128_CCM_8_SHA256
TLS_SHA384_SHA384 - intégrité seule
TLS_SHA256_SHA256 - intégrité seule

Une liste vide est autorisée. La valeur par défaut pour cette configuration est :

"TLS_AES_256_GCM_SHA384:TLS_CHACHA20_POLY1305_SHA256:TLS_AES_128_GCM_SHA256"

SSL_set_ciphersuites() est identique à SSL_CTX_set_ciphersuites() sauf qu'il configure les suites de chiffrements pour ssl.

OSSL_default_cipher_list() renvoie la chaîne par défaut des chiffrements pour TLSv1.2 (et versions antérieures). OSSL_default_ciphersuites() renvoie la chaîne par défaut des suites de chiffrements pour les suites de chiffrements TLSv1.3.

NOTES

La chaîne de contrôle str pour SSL_CTX_set_cipher_list(), SSL_set_cipher_list(), SSL_CTX_set_ciphersuites() et SSL_set_ciphersuites() doit être universellement utilisable et ne pas dépendre des détails de la configuration de la bibliothèque (chiffrements compilés). Par conséquent, il n'y a pas de vérification de syntaxe. Les éléments non reconnus, car les chiffrements ne sont pas compilés ou sont mal orthographiés, sont ignorés. L'échec n'est signalé que si aucun chiffrement ne peut être sélectionné.

Il convient de noter que l'inclusion d'un chiffrement dans la liste est une condition nécessaire. Côté client, l'inclusion dans la liste est également suffisante, à moins que le niveau de sécurité n'exclue ledit chiffrement. Côté serveur, des restrictions supplémentaires s'appliquent. Tous les chiffrements ont des exigences supplémentaires. Les chiffrements ADH ne nécessitent pas de certificat, mais des paramètres DH doivent avoir été configurés. Tous les autres chiffrements nécessitent un certificat et une clé correspondants.

Un chiffrement RSA ne peut être choisi que lorsqu'un certificat RSA est disponible. Les chiffrements RSA utilisant DHE nécessitent un certificat et une clé, ainsi que des paramètres DH (voir SSL_CTX_set_tmp_dh_callback(3)).

Un chiffrement DSA ne peut être choisi que lorsqu'un certificat DSA est disponible. Les chiffrements DSA utilisent toujours l'échange de clés DH et nécessitent donc des paramètres DH (voir SSL_CTX_set_tmp_dh_callback(3)).

Si ces exigences ne sont pas satisfaites pour un chiffrement de la liste (par exemple, un client ne prend en charge que les chiffrements RSA d'exportation avec une longueur de clé asymétrique de 512 bits et le serveur n'est pas configuré pour utiliser des clés RSA temporaires), l'erreur « no shared cipher » (SSL_R_NO_SHARED_CIPHER) est générée et le handshake échoue.

OSSL_default_cipher_list() et OSSL_default_ciphersuites() remplacent respectivement SSL_DEFAULT_CIPHER_LIST et SSL_DEFAULT_CIPHERSUITES. Les listes de chiffrements définies sont obsolètes depuis la version 3.0.

VALEURS DE RETOUR

SSL_CTX_set_cipher_list() et SSL_set_cipher_list() renvoient 1 si au moins un chiffrement peut être sélectionné et 0 en cas d'échec complet.

SSL_CTX_set_ciphersuites() et SSL_set_ciphersuites() renvoient 1 si la liste de suites de chiffrements demandée a été configurée, et 0 dans le cas contraire.

VOIR AUSSI

ssl(7), SSL_get_ciphers(3), SSL_CTX_use_certificate(3), SSL_CTX_set_tmp_dh_callback(3), openssl-ciphers(1)

HISTORIQUE

OSSL_default_cipher_list() et OSSL_default_ciphersuites() sont nouveaux dans la version 3.0.
