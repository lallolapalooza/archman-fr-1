SSL_CTX_set_tmp_ecdh(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_SET_TMP_ECDH(3ssl) OpenSSL SSL_CTX_SET_TMP_ECDH(3ssl)

NOM

SSL_CTX_set_tmp_ecdh, SSL_set_tmp_ecdh, SSL_CTX_set_ecdh_auto, SSL_set_ecdh_auto - gérer les clés ECDH pour l'échange de clés éphémères

SYNTAXE

#include <openssl/ssl.h>
long SSL_CTX_set_tmp_ecdh(SSL_CTX *ctx, const EC_KEY *ecdh);
long SSL_set_tmp_ecdh(SSL *ssl, const EC_KEY *ecdh);
long SSL_CTX_set_ecdh_auto(SSL_CTX *ctx, int state);
long SSL_set_ecdh_auto(SSL *ssl, int state);

DESCRIPTION

SSL_CTX_set_tmp_ecdh() définit les paramètres ECDH à utiliser comme étant ecdh. La clé est héritée par tous les objets ssl créés à partir de ctx. Cette macro est dépréciée en faveur de SSL_CTX_set1_groups(3).

SSL_set_tmp_ecdh() définit les paramètres uniquement pour ssl. Cette macro est dépréciée en faveur de SSL_set1_groups(3).

SSL_CTX_set_ecdh_auto() et SSL_set_ecdh_auto() sont dépréciées et n'ont aucun effet.

VALEURS DE RETOUR

SSL_CTX_set_tmp_ecdh() et SSL_set_tmp_ecdh() renvoient 1 en cas de succès et 0 en cas d'échec.

VOIR AUSSI

ssl(7), SSL_CTX_set1_curves(3), SSL_CTX_set_cipher_list(3), SSL_CTX_set_options(3), SSL_CTX_set_tmp_dh_callback(3), openssl-ciphers(1), openssl-ecparam(1)
