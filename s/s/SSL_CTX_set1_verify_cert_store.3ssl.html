SSL_CTX_set1_verify_cert_store(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_SET1_VERIFY_CERT_STORE(3ssl) OpenSSL SSL_CTX_SET1_VERIFY_CERT_STORE(3ssl)

NOM

SSL_CTX_set0_verify_cert_store, SSL_CTX_set1_verify_cert_store, SSL_CTX_set0_chain_cert_store, SSL_CTX_set1_chain_cert_store, SSL_set0_verify_cert_store, SSL_set1_verify_cert_store, SSL_set0_chain_cert_store, SSL_set1_chain_cert_store, SSL_CTX_get0_verify_cert_store, SSL_CTX_get0_chain_cert_store, SSL_get0_verify_cert_store, SSL_get0_chain_cert_store - définir le magasin de certificats de vérification ou de chaîne

SYNTAXE

#include <openssl/ssl.h>
int SSL_CTX_set0_verify_cert_store(SSL_CTX *ctx, X509_STORE *st);
int SSL_CTX_set1_verify_cert_store(SSL_CTX *ctx, X509_STORE *st);
int SSL_CTX_set0_chain_cert_store(SSL_CTX *ctx, X509_STORE *st);
int SSL_CTX_set1_chain_cert_store(SSL_CTX *ctx, X509_STORE *st);
int SSL_CTX_get0_verify_cert_store(SSL_CTX *ctx, X509_STORE **st);
int SSL_CTX_get0_chain_cert_store(SSL_CTX *ctx, X509_STORE **st);
int SSL_set0_verify_cert_store(SSL *ctx, X509_STORE *st);
int SSL_set1_verify_cert_store(SSL *ctx, X509_STORE *st);
int SSL_set0_chain_cert_store(SSL *ctx, X509_STORE *st);
int SSL_set1_chain_cert_store(SSL *ctx, X509_STORE *st);
int SSL_get0_verify_cert_store(SSL *ctx, X509_STORE **st);
int SSL_get0_chain_cert_store(SSL *ctx, X509_STORE **st);

DESCRIPTION

SSL_CTX_set0_verify_cert_store() et SSL_CTX_set1_verify_cert_store() définissent le magasin de certificats utilisé pour la vérification des certificats à st.

SSL_CTX_set0_chain_cert_store() et SSL_CTX_set1_chain_cert_store() définissent le magasin de certificats utilisé pour la construction de la chaîne de certificats à st.

SSL_set0_verify_cert_store(), SSL_set1_verify_cert_store(), SSL_set0_chain_cert_store() et SSL_set1_chain_cert_store() sont similaires sauf qu'elles s'appliquent à la structure SSL ssl.

SSL_CTX_get0_verify_chain_store(), SSL_get0_verify_chain_store(), SSL_CTX_get0_chain_cert_store() et SSL_get0_chain_cert_store() récupèrent les objets définis précédemment via les appels ci-dessus. Un pointeur vers l'objet (ou NULL si aucun objet de ce type n'a été défini) est écrit dans *st.

Toutes ces fonctions sont implémentées comme des macros. Celles qui contiennent un 1 incrémentent le compteur de références du magasin fourni, il doit donc être libéré à un moment donné après l'opération. Celles qui contiennent un 0 n'incrémentent pas les compteurs de références et le magasin fourni NE DOIT PAS être libéré après l'opération.

NOTES

Les pointeurs de magasins associés à une structure SSL_CTX sont copiés dans toutes les structures SSL lorsque SSL_new() est appelée. En conséquence, les structures SSL ne seront pas affectées si le pointeur de magasin du SSL_CTX parent est défini sur une nouvelle valeur.

Le magasin de vérification est utilisé pour vérifier la chaîne de certificats envoyée par le pair : un client SSL/TLS utilisera le magasin de vérification pour vérifier la chaîne de certificats du serveur, et un serveur SSL/TLS l'utilisera pour vérifier toute chaîne de certificats client.

Le magasin de chaîne est utilisé pour construire la chaîne de certificats. Les détails du processus de construction et de vérification de la chaîne sont décrits dans "Construction du chemin de certification" dans openssl-verification-options(1) et "Validation du chemin de certification" dans openssl-verification-options(1).

Si le mode SSL_MODE_NO_AUTO_CHAIN est défini ou si une chaîne de certificats est déjà configurée (par exemple en utilisant des fonctions telles que SSL_CTX_add1_chain_cert(3) ou SSL_CTX_add_extra_chain_cert(3)) alors la construction automatique de chaîne est désactivée.

Si le mode SSL_MODE_NO_AUTO_CHAIN est défini, alors la construction automatique de chaîne est désactivée.

Si le magasin de chaîne ou de vérification n'est pas défini, alors le magasin associé au SSL_CTX parent est utilisé à la place pour conserver la compatibilité avec les versions précédentes d'OpenSSL.

VALEURS DE RETOUR

Toutes ces fonctions renvoient 1 en cas de succès et 0 en cas d'échec.
