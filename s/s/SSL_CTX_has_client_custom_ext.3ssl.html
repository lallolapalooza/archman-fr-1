NOM

SSL_CTX_has_client_custom_ext - vérifie si un gestionnaire existe pour un type d'extension client particulier

SYNTAXE

#include <openssl/ssl.h>
int SSL_CTX_has_client_custom_ext(const SSL_CTX *ctx, unsigned int ext_type);

DESCRIPTION

SSL_CTX_has_client_custom_ext() vérifie si un gestionnaire a été défini pour une extension client de type ext_type en utilisant SSL_CTX_add_client_custom_ext().

VALEURS DE RETOUR

Renvoie 1 si un gestionnaire a été défini, 0 sinon.

VOIR AUSSI

ssl(7), SSL_CTX_add_client_custom_ext(3)
