SSL_set_session_secret_cb(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_SET_SESSION_SECRET_CB(3ssl) OpenSSL SSL_SET_SESSION_SECRET_CB(3ssl)

NOM

SSL_set_session_secret_cb, tls_session_secret_cb_fn - définir le rappel pour le secret de session

SYNTAXE

#include <openssl/ssl.h>
typedef int (*tls_session_secret_cb_fn)(SSL *s, void *secret, int *secret_len,
                                        STACK_OF(SSL_CIPHER) *peer_ciphers,
                                        const SSL_CIPHER **cipher, void *arg);
int SSL_set_session_secret_cb(SSL *s,
                              tls_session_secret_cb_fn session_secret_cb,
                              void *arg);

DESCRIPTION

SSL_set_session_secret_cb() définit le rappel de secret de session à utiliser (session_secret_cb), et un argument optionnel (arg) à passer à ce rappel lorsqu'il est appelé. Ceci n'est utile que pour une implémentation d'EAP-FAST (RFC4851). La présence du rappel modifie également la machine d'état TLS interne d'OpenSSL pour correspondre au comportement TLS modifié tel que décrit dans RFC4851. Par conséquent, ce rappel ne doit pas être utilisé sauf lors de l'implémentation d'EAP-FAST.

Le rappel est censé définir le secret maître à utiliser en remplissant les données pointées par *secret. La taille du tampon de secret est initialement disponible dans *secret_len et peut être mise à jour par le rappel (mais ne doit pas être supérieure à la valeur initiale).

Côté serveur, l'ensemble des ciphersuites offertes par le pair est fourni dans la pile peer_ciphers. Le rappel peut éventuellement sélectionner la ciphersuite préférée en la définissant dans *cipher.

Côté client, la pile peer_ciphers sera toujours NULL. Le rappel peut spécifier la méthode préférée dans *cipher et celle-ci sera associée à la SSL_SESSION - mais cela n'affecte pas la ciphersuite sélectionnée par le serveur.

Le rappel reçoit également un argument supplémentaire dans arg qui est l'argument qui a été fourni à l'appel original de SSL_set_session_secret_cb().

VALEURS DE RETOUR

SSL_set_session_secret_cb() retourne 1 en cas de succès et 0 en cas d'échec.

Si le rappel retourne 1, cela indique qu'il a défini avec succès le secret. Une valeur de retour de 0 indique que le secret n'a pas été défini. Côté client, cela entraînera l'abandon immédiat de la négociation.

VOIR AUSSI

ssl(7), SSL_get_session(3)
