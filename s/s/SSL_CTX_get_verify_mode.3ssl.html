SSL_CTX_get_verify_mode(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_GET_VERIFY_MODE(3ssl) OpenSSL SSL_CTX_GET_VERIFY_MODE(3ssl)

NOM

SSL_CTX_get_verify_mode, SSL_get_verify_mode, SSL_CTX_get_verify_depth, SSL_get_verify_depth, SSL_get_verify_callback, SSL_CTX_get_verify_callback - obtenir les paramètres de vérification actuellement définis

SYNTAXE

#include <openssl/ssl.h>
int SSL_CTX_get_verify_mode(const SSL_CTX *ctx);
int SSL_get_verify_mode(const SSL *ssl);
int SSL_CTX_get_verify_depth(const SSL_CTX *ctx);
int SSL_get_verify_depth(const SSL *ssl);
int (*SSL_CTX_get_verify_callback(const SSL_CTX *ctx))(int, X509_STORE_CTX *);
int (*SSL_get_verify_callback(const SSL *ssl))(int, X509_STORE_CTX *);

DESCRIPTION

SSL_CTX_get_verify_mode() retourne le mode de vérification actuellement défini dans ctx.

SSL_get_verify_mode() retourne le mode de vérification actuellement défini dans ssl.

SSL_CTX_get_verify_depth() retourne la limite de profondeur de vérification actuellement définie dans ctx. Si aucune limite n'a été explicitement définie, -1 est retourné et la valeur par défaut sera utilisée.

SSL_get_verify_depth() retourne la limite de profondeur de vérification actuellement définie dans ssl. Si aucune limite n'a été explicitement définie, -1 est retourné et la valeur par défaut sera utilisée.

SSL_CTX_get_verify_callback() retourne un pointeur de fonction vers la fonction de rappel de vérification actuellement définie dans ctx. Si aucune fonction de rappel n'a été explicitement définie, le pointeur NULL est retourné et la fonction de rappel par défaut sera utilisée.

SSL_get_verify_callback() retourne un pointeur de fonction vers la fonction de rappel de vérification actuellement définie dans ssl. Si aucune fonction de rappel n'a été explicitement définie, le pointeur NULL est retourné et la fonction de rappel par défaut sera utilisée.
