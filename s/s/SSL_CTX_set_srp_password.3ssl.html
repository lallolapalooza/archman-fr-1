SSL_CTX_set_srp_password(3ssl)

NOM

SSL_CTX_set_srp_username, SSL_CTX_set_srp_password, SSL_CTX_set_srp_strength, SSL_CTX_set_srp_cb_arg, SSL_CTX_set_srp_username_callback, SSL_CTX_set_srp_client_pwd_callback, SSL_CTX_set_srp_verify_param_callback, SSL_set_srp_server_param, SSL_set_srp_server_param_pw, SSL_get_srp_g, SSL_get_srp_N, SSL_get_srp_username, SSL_get_srp_userinfo - Opérations de contrôle SRP

SYNTAXE

#include <openssl/ssl.h>

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

int SSL_CTX_set_srp_username(SSL_CTX *ctx, char *name);
int SSL_CTX_set_srp_password(SSL_CTX *ctx, char *password);
int SSL_CTX_set_srp_strength(SSL_CTX *ctx, int strength);
int SSL_CTX_set_srp_cb_arg(SSL_CTX *ctx, void *arg);
int SSL_CTX_set_srp_username_callback(SSL_CTX *ctx,
                                      int (*cb) (SSL *s, int *ad, void *arg));
int SSL_CTX_set_srp_client_pwd_callback(SSL_CTX *ctx,
                                        char *(*cb) (SSL *s, void *arg));
int SSL_CTX_set_srp_verify_param_callback(SSL_CTX *ctx,
                                          int (*cb) (SSL *s, void *arg));
int SSL_set_srp_server_param(SSL *s, const BIGNUM *N, const BIGNUM *g,
                             BIGNUM *sa, BIGNUM *v, char *info);
int SSL_set_srp_server_param_pw(SSL *s, const char *user, const char *pass,
                                const char *grp);
BIGNUM *SSL_get_srp_g(SSL *s);
BIGNUM *SSL_get_srp_N(SSL *s);
char *SSL_get_srp_username(SSL *s);
char *SSL_get_srp_userinfo(SSL *s);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Il n'y a pas de fonctions de remplacement disponibles pour le moment.

Ces fonctions donnent accès aux paramètres SRP (Secure Remote Password), un mécanisme d'authentification alternatif pour TLS. SRP permet l'utilisation de noms d'utilisateur et de mots de passe sur des canaux non chiffrés sans révéler le mot de passe à un espion. SRP fournit également un secret partagé à la fin de la séquence d'authentification qui peut être utilisé pour générer des clés de chiffrement.

Le protocole SRP, version 3 est spécifié dans la RFC 2945. SRP version 6 est décrit dans la RFC 5054 avec des applications à l'authentification TLS.

La fonction SSL_CTX_set_srp_username() définit le nom d'utilisateur SRP pour ctx. Elle doit être appelée côté client avant de créer une connexion au serveur. La longueur de name doit être inférieure ou égale à 255 caractères.

La fonction SSL_CTX_set_srp_password() définit le mot de passe SRP pour ctx. Elle peut être appelée côté client avant de créer une connexion au serveur. Elle annule l'effet de SSL_CTX_set_srp_client_pwd_callback().

La fonction SSL_CTX_set_srp_strength() définit la force SRP pour ctx. Il s'agit de la longueur minimale du nombre premier SRP en bits. Si elle n'est pas spécifiée, 1024 est utilisé. Si elle n'est pas satisfaite par l'échange de clés du serveur, la connexion sera rejetée.

La fonction SSL_CTX_set_srp_cb_arg() définit un paramètre supplémentaire qui sera passé à toutes les callbacks suivantes en tant qu'argument arg.

La fonction SSL_CTX_set_srp_username_callback() définit la callback côté serveur qui est appelée lorsqu'un nom d'utilisateur SRP est trouvé dans un ClientHello. Les paramètres de la callback sont la connexion SSL s, un indicateur d'erreur inscriptible ad et l'argument supplémentaire arg défini par SSL_CTX_set_srp_cb_arg(). Cette callback doit configurer le serveur pour l'échange de clés en appelant SSL_set_srp_server_param() avec les paramètres appropriés pour le nom d'utilisateur reçu. Le nom d'utilisateur peut être obtenu en appelant SSL_get_srp_username(). Voir SRP_VBASE_init(3) pour analyser le fichier de vérificateurs créé par openssl-srp(1) ou SRP_create_verifier(3) pour le générer. La callback doit retourner SSL_ERROR_NONE pour poursuivre l'échange de clés du serveur, SSL3_AL_FATAL pour une erreur fatale ou toute valeur < 0 pour une erreur retentable. En cas de SSL3_AL_FATAL, l'indicateur d'alerte donné par *al sera renvoyé. Par défaut, ce sera SSL_AD_UNKNOWN_PSK_IDENTITY.

La fonction SSL_CTX_set_srp_client_pwd_callback() définit la callback du mot de passe client côté client. Les paramètres de la callback sont la connexion SSL s et l'argument supplémentaire arg défini par SSL_CTX_set_srp_cb_arg(). La callback sera appelée dans le cadre de la génération des secrets client. Elle doit retourner le mot de passe client sous forme textuelle ou NULL pour abandonner la connexion. La mémoire résultante sera libérée par la bibliothèque dans le cadre de la résolution de la callback. Elle annule l'effet de SSL_CTX_set_srp_password().

La fonction SSL_CTX_set_srp_verify_param_callback() définit la callback de vérification des paramètres gN SRP côté client. Elle permet au client d'effectuer une vérification personnalisée lors de la réception des paramètres SRP proposés par le serveur. Les paramètres de la callback sont la connexion SSL s et l'argument supplémentaire arg défini par SSL_CTX_set_srp_cb_arg(). La callback doit retourner une valeur positive pour accepter les paramètres du serveur. Retourner 0 ou une valeur négative abandonnera la connexion. Les paramètres du serveur peuvent être obtenus en appelant SSL_get_srp_N() et SSL_get_srp_g(). Des vérifications de cohérence sont déjà effectuées par la bibliothèque après le handshake (B % N non nul, vérification par rapport au paramètre de force) et ne sont pas nécessaires. Si aucune callback n'est définie, les paramètres g et N seront vérifiés par rapport aux valeurs connues de la RFC 5054.

La fonction SSL_set_srp_server_param() définit tous les paramètres SRP pour la connexion s. N et g sont les paramètres du groupe SRP, sa est le sel utilisateur, v est le vérificateur de mot de passe et info sont les informations facultatives de l'utilisateur.

La fonction SSL_set_srp_server_param_pw() définit tous les paramètres SRP pour la connexion s en générant un sel aléatoire et un vérificateur de mot de passe. user est le nom d'utilisateur, pass est le mot de passe et grp est l'identifiant des paramètres du groupe SRP pour SRP_get_default_gN(3).

La fonction SSL_get_srp_g() retourne le générateur du groupe SRP pour s, ou du CTX SSL sous-jacent s'il est NULL.

La fonction SSL_get_srp_N() retourne le nombre premier SRP pour s, ou du CTX SSL sous-jacent s'il est NULL.

La fonction SSL_get_srp_username() retourne le nom d'utilisateur SRP pour s, ou du CTX SSL sous-jacent s'il est NULL.

La fonction SSL_get_srp_userinfo() retourne les informations utilisateur SRP pour s, ou du CTX SSL sous-jacent s'il est NULL.

VALEURS DE RETOUR

Toutes les fonctions SSL_CTX_set_* retournent 1 en cas de succès et 0 en cas d'échec.

SSL_set_srp_server_param() retourne 1 en cas de succès et -1 en cas d'échec.

Les fonctions SSL_get_SRP_* retournent un pointeur vers les données demandées ; la mémoire appartient à la bibliothèque et ne doit pas être libérée par l'appelant.

EXEMPLES

Configuration des paramètres SRP côté client :

#include <openssl/ssl.h>
const char *username = "username";
const char *password = "password";
SSL_CTX *ctx = SSL_CTX_new(TLS_client_method());
if (!ctx)
    /* Erreur */
if (!SSL_CTX_set_srp_username(ctx, username))
    /* Erreur */
if (!SSL_CTX_set_srp_password(ctx, password))
    /* Erreur */

Configuration du serveur SRP avec un fichier de vérificateurs :

#include <openssl/srp.h>
#include <openssl/ssl.h>
const char *srpvfile = "password.srpv";
int srpServerCallback(SSL *s, int *ad, void *arg)
{
    SRP_VBASE *srpData = (SRP_VBASE*) arg;
    char *username = SSL_get_srp_username(s);
    SRP_user_pwd *user_pwd = SRP_VBASE_get1_by_user(srpData, username);
    if (!user_pwd)
        /* Erreur */
        return SSL3_AL_FATAL;
    if (SSL_set_srp_server_param(s, user_pwd->N, user_pwd->g,
        user_pwd->s, user_pwd->v, user_pwd->info) < 0)
        /* Erreur */
    SRP_user_pwd_free(user_pwd);
    return SSL_ERROR_NONE;
}
SSL_CTX *ctx = SSL_CTX_new(TLS_server_method());
if (!ctx)
    /* Erreur */
/*
 * seedKey doit contenir une séquence terminée par NUL
 * d'octets aléatoires non NUL
 */
const char *seedKey;
SRP_VBASE *srpData = SRP_VBASE_new(seedKey);
if (SRP_VBASE_init(srpData, (char*) srpvfile) != SRP_NO_ERROR)
   /* Erreur */
SSL_CTX_set_srp_cb_arg(ctx, srpData);
SSL_CTX_set_srp_username_callback(ctx, srpServerCallback);
