SSL_CTX_set_record_padding_callback(3ssl)

SSL_CTX_SET_RECORD_PADDING_CALLBACK(3ssl) OpenSSL SSL_CTX_SET_RECORD_PADDING_CALLBACK(3ssl)

NOM

SSL_CTX_set_record_padding_callback, SSL_set_record_padding_callback, SSL_CTX_set_record_padding_callback_arg, SSL_set_record_padding_callback_arg, SSL_CTX_get_record_padding_callback_arg, SSL_get_record_padding_callback_arg, SSL_CTX_set_block_padding, SSL_CTX_set_block_padding_ex, SSL_set_block_padding, SSL_set_block_padding_ex - installer une fonction de rappel pour spécifier le remplissage des enregistrements TLS 1.3

SYNTAXE

#include <openssl/ssl.h>
void SSL_CTX_set_record_padding_callback(SSL_CTX *ctx, size_t (*cb)(SSL *s, int type, size_t len, void *arg));
int SSL_set_record_padding_callback(SSL *ssl, size_t (*cb)(SSL *s, int type, size_t len, void *arg));
void SSL_CTX_set_record_padding_callback_arg(SSL_CTX *ctx, void *arg);
void *SSL_CTX_get_record_padding_callback_arg(const SSL_CTX *ctx);
void SSL_set_record_padding_callback_arg(SSL *ssl, void *arg);
void *SSL_get_record_padding_callback_arg(const SSL *ssl);
int SSL_CTX_set_block_padding(SSL_CTX *ctx, size_t block_size);
int SSL_set_block_padding(SSL *ssl, size_t block_size);
int SSL_CTX_set_block_padding_ex(SSL_CTX *ctx, size_t app_block_size, size_t hs_block_size);
int SSL_set_block_padding_ex(SSL *ssl, size_t app_block_size, size_t hs_block_size);

DESCRIPTION

SSL_CTX_set_record_padding_callback() ou SSL_set_record_padding_callback() peut être utilisé pour affecter une fonction de rappel cb pour spécifier le remplissage des enregistrements TLS 1.3. La valeur définie dans ctx est copiée vers un nouveau SSL par SSL_new(). Le TLS noyau (Kernel TLS) n'est pas possible si la fonction de rappel de remplissage d'enregistrement est définie, et la fonction de rappel ne peut pas être définie si le TLS noyau est déjà configuré pour l'objet SSL courant.

SSL_CTX_set_record_padding_callback_arg() et SSL_set_record_padding_callback_arg() affectent une valeur arg qui est passée à la fonction de rappel lorsqu'elle est invoquée. La valeur définie dans ctx est copiée vers un nouveau SSL par SSL_new().

SSL_CTX_get_record_padding_callback_arg() et SSL_get_record_padding_callback_arg() récupèrent la valeur arg qui est passée à la fonction de rappel.

SSL_CTX_set_block_padding() et SSL_set_block_padding() remplissent l'enregistrement pour qu'il soit un multiple de block_size. Une block_size de 0 ou 1 désactive le remplissage par blocs. La limite de block_size est SSL3_RT_MAX_PLAIN_LENGTH.

SSL_CTX_set_block_padding_ex() et SSL_set_block_padding_ex() font de même, mais permettent à l'appelant de spécifier séparément la taille du bloc de remplissage à appliquer aux messages de handshake et de données d'application.

La fonction de rappel est appelée pour chaque enregistrement avant le chiffrement. Le paramètre type est le type d'enregistrement TLS en cours de traitement ; il peut s'agir de SSL3_RT_APPLICATION_DATA, SSL3_RT_HANDSHAKE, ou SSL3_RT_ALERT. Le paramètre len est la longueur en clair actuelle de l'enregistrement avant chiffrement. Le paramètre arg est la valeur définie via SSL_CTX_set_record_padding_callback_arg() ou SSL_set_record_padding_callback_arg().

Ces fonctions ne peuvent pas être utilisées avec des objets SSL QUIC. SSL_set_record_padding_callback() et SSL_set_block_padding() échouent si elles sont appelées sur un objet SSL QUIC.

VALEURS DE RETOUR

Les fonctions SSL_CTX_get_record_padding_callback_arg() et SSL_get_record_padding_callback_arg() retournent la valeur arg définie dans les fonctions de définition correspondantes.

Les fonctions SSL_CTX_set_block_padding() et SSL_set_block_padding() retournent 1 en cas de succès ou 0 si block_size est trop grande.

La fonction cb retourne le nombre d'octets de remplissage à ajouter à l'enregistrement. Un retour de 0 indique qu'aucun remplissage ne sera ajouté. Une valeur de retour qui fait que l'enregistrement dépasse la taille maximale d'enregistrement (SSL3_RT_MAX_PLAIN_LENGTH) remplira jusqu'à la taille maximale d'enregistrement.

La fonction SSL_CTX_get_record_padding_callback_arg() retourne 1 en cas de succès ou 0 si la fonction de rappel n'est pas définie parce que le TLS noyau est configuré pour l'objet SSL.

NOTES

Le comportement par défaut est de n'ajouter aucun remplissage à l'enregistrement.

Une fonction de rappel de remplissage fournie par l'utilisateur outrepassera le comportement défini par SSL_set_block_padding() ou SSL_CTX_set_block_padding(). Définir la fonction de rappel fournie par l'utilisateur sur NULL rétablira le comportement de remplissage par blocs configuré.

Ces fonctions s'appliquent uniquement aux enregistrements TLS 1.3 en cours d'écriture.

Les octets de remplissage ne sont pas ajoutés en temps constant.

VOIR AUSSI

ssl(7), SSL_new(3)

HISTORIQUE

L'API de remplissage d'enregistrements a été ajoutée pour le support de TLS 1.3 dans OpenSSL 1.1.1.

Le type de retour de la fonction SSL_CTX_set_record_padding_callback() a été changé en int dans OpenSSL 3.0.

Les fonctions SSL_set_block_padding_ex() et SSL_CTX_set_block_padding_ex() ont été ajoutées dans OpenSSL 3.4.
