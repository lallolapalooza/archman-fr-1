SSL_CTX_set_timeout(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_SET_TIMEOUT(3ssl) OpenSSL SSL_CTX_SET_TIMEOUT(3ssl)

NOM

SSL_CTX_set_timeout, SSL_CTX_get_timeout - manipuler les valeurs de délai d'attente pour la mise en cache de session

SYNTAXE

#include <openssl/ssl.h>
long SSL_CTX_set_timeout(SSL_CTX *ctx, long t);
long SSL_CTX_get_timeout(SSL_CTX *ctx);

DESCRIPTION

SSL_CTX_set_timeout() définit le délai d'attente pour les sessions nouvellement créées pour ctx à t. La valeur du délai d'attente t doit être exprimée en secondes.

SSL_CTX_get_timeout() renvoie la valeur de délai d'attente actuellement définie pour ctx.

NOTES

Chaque fois qu'une nouvelle session est créée, elle se voit attribuer une durée de vie maximale. Cette durée de vie est spécifiée en stockant l'heure de création de la session et la valeur de délai d'attente valide à ce moment-là. Si l'heure réelle est postérieure à l'heure de création plus le délai d'attente, la session n'est pas réutilisée.

En raison de cette implémentation, toutes les sessions se comportent conformément à la valeur de délai d'attente valide au moment de la négociation de la session. Les modifications de la valeur de délai d'attente n'affectent pas les sessions déjà établies.

L'heure d'expiration d'une session individuelle peut être modifiée à l'aide de la famille de fonctions SSL_SESSION_get_time(3).

Les sessions expirées sont supprimées du cache de sessions interne, chaque fois que SSL_CTX_flush_sessions(3) est appelé, soit directement par l'application, soit automatiquement (voir SSL_CTX_set_session_cache_mode(3))

La valeur par défaut pour le délai d'attente des sessions est déterminée par protocole, voir SSL_get_default_timeout(3). Tous les protocoles actuellement pris en charge ont la même valeur de délai d'attente par défaut de 300 secondes.

Cette valeur de délai d'attente est utilisée comme indice de durée de vie du ticket pour les tickets de session sans état. Elle est également utilisée comme valeur de délai d'attente dans le ticket lui-même.

Pour TLSv1.3, la RFC8446 limite la transmission de cette valeur à 1 semaine (604800 secondes).

Pour TLSv1.2, les tickets générés lors d'une poignée de main initiale utilisent la valeur telle que spécifiée. Les tickets générés lors d'une reprise de poignée de main ont une valeur de 0 pour l'indice de durée de vie du ticket.

VALEURS DE RETOUR

SSL_CTX_set_timeout() renvoie la valeur de délai d'attente précédemment définie.

SSL_CTX_get_timeout() renvoie la valeur de délai d'attente actuellement définie.
