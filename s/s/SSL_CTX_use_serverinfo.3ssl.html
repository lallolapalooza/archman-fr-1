SSL_CTX_use_serverinfo(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_USE_SERVERINFO(3ssl) OpenSSL SSL_CTX_USE_SERVERINFO(3ssl)

NOM

SSL_CTX_use_serverinfo_ex, SSL_CTX_use_serverinfo, SSL_CTX_use_serverinfo_file - utiliser l'extension serverinfo

SYNTAXE

#include <openssl/ssl.h>
int SSL_CTX_use_serverinfo_ex(SSL_CTX *ctx, unsigned int version,
                              const unsigned char *serverinfo,
                              size_t serverinfo_length);
int SSL_CTX_use_serverinfo(SSL_CTX *ctx, const unsigned char *serverinfo,
                           size_t serverinfo_length);
int SSL_CTX_use_serverinfo_file(SSL_CTX *ctx, const char *file);

DESCRIPTION

Ces fonctions chargent les extensions TLS "serverinfo" dans le SSL_CTX. Une extension "serverinfo" est retournée en réponse à un ClientHello Extension vide.

SSL_CTX_use_serverinfo_ex() charge une ou plusieurs extensions serverinfo depuis un tableau d'octets dans ctx. Le paramètre version spécifie le format du tableau d'octets fourni dans *serverinfo qui est de longueur serverinfo_length.

Si version est SSL_SERVERINFOV2, alors les extensions dans le tableau doivent consister en un contexte de 4 octets, un Type d'Extension de 2 octets, une longueur de 2 octets, puis des octets de données d'extension correspondant à la longueur. Les valeurs de contexte et de type ont la même signification que pour SSL_CTX_add_custom_ext(3). Si serverinfo est chargé pour des extensions à ajouter à un message de Certificat, alors l'extension sera ajoutée uniquement pour le premier certificat dans le message (qui est toujours le certificat d'extrémité).

Si version est SSL_SERVERINFOV1, alors les extensions dans le tableau doivent consister en un Type d'Extension de 2 octets, une longueur de 2 octets, puis des octets de données d'extension correspondant à la longueur. La valeur de type a la même signification que pour SSL_CTX_add_custom_ext(3). La valeur de contexte par défaut suivante sera utilisée dans ce cas :

SSL_EXT_TLS_1_2_AND_BELOW_ONLY | SSL_EXT_CLIENT_HELLO
| SSL_EXT_TLS_1_2_SERVER_HELLO | SSL_EXT_IGNORE_ON_RESUMPTION

SSL_CTX_use_serverinfo() fait la même chose que SSL_CTX_use_serverinfo_ex() sauf qu'il n'y a pas de paramètre version, donc une version par défaut de SSL_SERVERINFOV1 est utilisée à la place.

SSL_CTX_use_serverinfo_file() charge une ou plusieurs extensions serverinfo depuis file dans ctx. Les extensions doivent être au format PEM. Chaque extension doit être dans un format tel que décrit ci-dessus pour SSL_CTX_use_serverinfo_ex(). Chaque nom d'extension PEM doit commencer par la phrase "BEGIN SERVERINFOV2 FOR " pour les données SSL_SERVERINFOV2 ou "BEGIN SERVERINFO FOR " pour les données SSL_SERVERINFOV1.

Si plus d'un certificat (RSA/DSA) est installé en utilisant SSL_CTX_use_certificate(), l'extension serverinfo sera chargée dans le dernier certificat installé. Si par exemple le dernier élément était un certificat RSA, les données de l'extension serverinfo chargées seront chargées pour ce certificat. Pour utiliser l'extension serverinfo pour plusieurs certificats, SSL_CTX_use_serverinfo() doit être appelé plusieurs fois, une fois après chaque chargement de certificat via un appel à SSL_CTX_use_certificate().

VALEURS DE RETOUR

En cas de succès, les fonctions retournent 1. En cas d'échec, les fonctions retournent 0. Consultez la pile d'erreurs pour connaître la raison.
