NOM

SSL_set_retry_verify - indiquer que la vérification du certificat doit être réessayée

SYNTAXE

#include <openssl/ssl.h>
int SSL_set_retry_verify(SSL *ssl);

DESCRIPTION

SSL_set_retry_verify() doit être appelée depuis la fonction de rappel de vérification du certificat sur un client lorsque l'application souhaite indiquer que la négociation doit être suspendue et que le contrôle doit être retourné à l'application. SSL_want_retry_verify(3) retournera 1 en conséquence jusqu'à ce que la négociation soit reprise par l'application, réessayant ainsi l'étape de vérification.

Veuillez vous référer à SSL_CTX_set_cert_verify_callback(3) pour plus de détails.

NOTES

L'effet de l'appel de SSL_set_retry_verify() en dehors de la fonction de rappel de vérification du certificat côté client est indéfini.

VALEURS DE RETOUR

SSL_set_retry verify() retourne 1 en cas de succès, 0 sinon.

EXEMPLES

L'extrait de code suivant montre comment obtenir l'objet SSL associé à X509_STORE_CTX pour appeler la fonction SSL_set_retry_verify() :

int idx = SSL_get_ex_data_X509_STORE_CTX_idx();
SSL *ssl;
/* cela ne devrait pas arriver mais vérifions quand même */
if (idx < 0
    || (ssl = X509_STORE_CTX_get_ex_data(ctx, idx)) == NULL)
    return 0;
if (/* nous devons retenter la vérification du callback */)
    return SSL_set_retry_verify(ssl);
/* faire le traitement normal du callback de vérification */

VOIR AUSSI

ssl(7), SSL_connect(3), SSL_CTX_set_cert_verify_callback(3), SSL_want_retry_verify(3)

HISTORIQUE

SSL_set_retry_verify() a été ajoutée dans OpenSSL 3.0.2 pour remplacer la gestion rétrocompatible incompatible d'une valeur de retour négative du rappel de vérification.
