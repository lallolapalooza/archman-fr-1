NAME

SSL_dup, SSL_new, SSL_up_ref - créer une structure SSL pour une connexion

SYNOPSIS

#include <openssl/ssl.h>
SSL *SSL_dup(SSL *s);
SSL *SSL_new(SSL_CTX *ctx);
int SSL_up_ref(SSL *s);

DESCRIPTION

SSL_new() crée une nouvelle structure SSL qui est nécessaire pour stocker les données d'une connexion TLS/SSL. La nouvelle structure hérite des configurations du contexte ctx : méthode de connexion, options, configurations de vérification, configurations de délai d'attente. Une structure SSL est incrémentée en référence. La création d'une structure SSL pour la première fois incrémente le compteur de références. Sa libération (en utilisant SSL_free) décrémente le compteur. Lorsque le compteur de références tombe à zéro, toute la mémoire ou les ressources allouées à la structure SSL sont libérées.

SSL_up_ref() incrémente le compteur de références pour une structure SSL existante.

La fonction SSL_dup() crée et renvoie une nouvelle structure SSL à partir du même contexte SSL_CTX qui a été utilisé pour créer s. De plus, elle duplique un sous-ensemble des configurations dans s vers le nouvel objet structure SSL.

Pour que SSL_dup() fonctionne, la connexion doit être dans son état initial et le handshake TLS/SSL ne doit PAS avoir encore commencé. Pour les connexions qui ne sont pas dans leur état initial, SSL_dup() se contente d'incrémenter un compteur de références interne et renvoie le même handle. Il est possible d'utiliser SSL_clear(3) pour réutiliser un handle qui n'est pas dans son état initial, mais cela doit être évité. À la place, vous pouvez sauvegarder et restaurer l'état de la session, si vous le souhaitez, et construire un nouveau handle pour chaque connexion.

Les sous-ensembles des configurations dans s qui sont dupliqués sont :

toutes les données de session si configurées (y compris le contexte session_id)
toutes les configurations tmp_dh définies par SSL_set_tmp_dh(3), SSL_set_tmp_dh_callback(3), ou SSL_set_dh_auto(3)
tout certificat configuré, clé privée ou chaîne de certificats
tous les algorithmes de signature configurés, ou algorithmes de signature client
toutes les configurations DANE
toutes les options configurées avec SSL_set_options(3)
tous les modes configurés avec SSL_set_mode(3)
toutes les configurations de protocole minimum ou maximum configurées avec SSL_set_min_proto_version(3) ou SSL_set_max_proto_version(3) (Note : Uniquement à partir d'OpenSSL 1.1.1h et versions ultérieures)
tous les modes de vérification, callbacks ou profondeurs configurés avec SSL_set_verify(3) ou SSL_set_verify_depth(3) ou tout paramètre de vérification X509 configuré
tous les callbacks de message ou callbacks d'information configurés avec SSL_set_msg_callback(3) ou SSL_set_info_callback(3)
tous les callbacks de mot de passe par défaut configurés avec SSL_set_default_passwd_cb(3)
tous les callbacks de génération de session_id configurés avec SSL_set_generate_session_id(3)
toutes les listes de chiffreurs configurées
état initial (serveur) ou connexion (client)
la valeur maximale de la liste de certificats configurée avec SSL_set_max_cert_list(3)
la valeur read_ahead configurée avec SSL_set_read_ahead(3)
les données spécifiques à l'application configurées avec SSL_set_ex_data(3)
toutes les listes CA ou listes CA client configurées avec SSL_set0_CA_list(3), SSL_set0_client_CA_list() ou des fonctions similaires
toutes les configurations de niveau de sécurité ou callbacks
toutes les données serverinfo configurées
toutes les configurations PSK d'identité
toutes les extensions personnalisées configurées
tous les types de certificats client configurés avec SSL_set1_client_certificate_types(3)

SSL_dup() n'est pas supporté sur les objets SSL QUIC et renvoie NULL s'il est appelé sur un tel objet.

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent se produire :

NULL
La création d'une structure SSL a échoué. Vérifiez la pile d'erreurs pour trouver la raison.
Pointeur vers une structure SSL
La valeur renvoyée pointe vers une structure SSL allouée.

SSL_up_ref() renvoie 1 en cas de succès et 0 en cas d'échec.
