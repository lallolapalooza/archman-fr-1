NOM

SSL_set_connect_state, SSL_set_accept_state, SSL_is_server - fonctions pour manipuler et examiner le mode client ou serveur d'un objet SSL

SYNOPIS

#include <openssl/ssl.h>
void SSL_set_connect_state(SSL *ssl);
void SSL_set_accept_state(SSL *ssl);
int SSL_is_server(const SSL *ssl);

DESCRIPTION

SSL_set_connect_state() configure ssl pour fonctionner en mode client.

SSL_set_accept_state() configure ssl pour fonctionner en mode serveur.

SSL_is_server() vérifie si ssl fonctionne en mode serveur.

NOTES

Lorsque l'objet SSL_CTX a été créé avec SSL_CTX_new(3), il lui a été assigné une méthode client dédiée, une méthode serveur dédiée, ou une méthode générique, qui peut être utilisée pour les connexions client et serveur. (La méthode peut avoir été modifiée avec SSL_CTX_set_ssl_version(3) ou SSL_set_ssl_method(3).)

Lors du début d'une nouvelle négociation, le moteur SSL doit savoir s'il doit appeler les routines de connexion (client) ou d'acceptation (serveur). Même si cela peut être clair d'après la méthode choisie, si le mode client ou serveur a été demandé, les routines de négociation doivent être explicitement configurées.

Lorsque vous utilisez les routines SSL_connect(3) ou SSL_accept(3), les routines de négociation correctes sont automatiquement configurées. Lors de l'exécution d'une négociation transparente à l'aide de SSL_write_ex(3), SSL_write(3), SSL_read_ex(3), ou SSL_read(3), les routines de négociation doivent être explicitement configurées à l'avance en utilisant soit SSL_set_connect_state(), soit SSL_set_accept_state().

Si SSL_is_server() est appelée avant que SSL_set_connect_state() ou SSL_set_accept_state() ne soit appelée (automatiquement ou explicitement), le résultat dépend de la méthode utilisée lors de la création de SSL_CTX avec SSL_CTX_new(3). Si une méthode générique ou une méthode serveur dédiée a été passée à SSL_CTX_new(3), SSL_is_server() renvoie 1 ; sinon, elle renvoie 0.

VALEURS DE RETOUR

SSL_set_connect_state() et SSL_set_accept_state() ne renvoient pas d'informations diagnostiques.

SSL_is_server() renvoie 1 si ssl fonctionne en mode serveur ou 0 pour le mode client.
