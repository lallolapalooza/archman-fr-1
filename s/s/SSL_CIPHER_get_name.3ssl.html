SSL_CIPHER_get_name(3ssl)

Licences: Apache-2.0

SSL_CIPHER_get_name(3ssl) OpenSSL SSL_CIPHER_get_name(3ssl)

NAME

SSL_CIPHER_get_name, SSL_CIPHER_standard_name, OPENSSL_cipher_name, SSL_CIPHER_get_bits, SSL_CIPHER_get_version, SSL_CIPHER_description, SSL_CIPHER_get_cipher_nid, SSL_CIPHER_get_digest_nid, SSL_CIPHER_get_handshake_digest, SSL_CIPHER_get_kx_nid, SSL_CIPHER_get_auth_nid, SSL_CIPHER_is_aead, SSL_CIPHER_find, SSL_CIPHER_get_id, SSL_CIPHER_get_protocol_id - obtenir les propriétés de SSL_CIPHER

SYNOPSIS

#include <openssl/ssl.h>
const char *SSL_CIPHER_get_name(const SSL_CIPHER *cipher);
const char *SSL_CIPHER_standard_name(const SSL_CIPHER *cipher);
const char *OPENSSL_cipher_name(const char *stdname);
int SSL_CIPHER_get_bits(const SSL_CIPHER *cipher, int *alg_bits);
const char *SSL_CIPHER_get_version(const SSL_CIPHER *cipher);
char *SSL_CIPHER_description(const SSL_CIPHER *cipher, char *buf, int size);
int SSL_CIPHER_get_cipher_nid(const SSL_CIPHER *c);
int SSL_CIPHER_get_digest_nid(const SSL_CIPHER *c);
const EVP_MD *SSL_CIPHER_get_handshake_digest(const SSL_CIPHER *c);
int SSL_CIPHER_get_kx_nid(const SSL_CIPHER *c);
int SSL_CIPHER_get_auth_nid(const SSL_CIPHER *c);
int SSL_CIPHER_is_aead(const SSL_CIPHER *c);
const SSL_CIPHER *SSL_CIPHER_find(SSL *ssl, const unsigned char *ptr);
uint32_t SSL_CIPHER_get_id(const SSL_CIPHER *c);
uint16_t SSL_CIPHER_get_protocol_id(const SSL_CIPHER *c);

DESCRIPTION

SSL_CIPHER_get_name() renvoie un pointeur vers le nom de cipher. Si cipher est NULL, elle renvoie "(NONE)".

SSL_CIPHER_standard_name() renvoie un pointeur vers le nom standard RFC de cipher. Si cipher est NULL, elle renvoie "(NONE)". Si cipher n'a pas de nom standard, elle renvoie NULL. Si cipher a été défini à la fois dans SSLv3 et TLS, elle renvoie le nom TLS.

OPENSSL_cipher_name() renvoie un pointeur vers le nom OpenSSL de stdname. Si stdname est NULL, ou n'a pas de nom OpenSSL correspondant, elle renvoie "(NONE)". Si les deux existent, stdname devrait être le nom TLS, pas le nom SSLv3.

SSL_CIPHER_get_bits() renvoie le nombre de bits secrets utilisés par cipher. Si cipher est NULL, elle renvoie 0.

SSL_CIPHER_get_version() renvoie une chaîne indiquant la version SSL/TLS qui a introduit pour la première fois le chiffrement. Elle renvoie "(NONE)" si cipher est NULL.

SSL_CIPHER_get_cipher_nid() renvoie le NID du chiffrement correspondant à c. S'il n'y a pas de chiffrement (par exemple, pour les suites de chiffrement sans chiffrement), elle renvoie NID_undef.

SSL_CIPHER_get_digest_nid() renvoie le NID de l'algorithme de hachage utilisé par c lors de l'encodage/décodage des enregistrements. S'il n'y a pas de hachage (par exemple, pour les suites de chiffrement AEAD), elle renvoie NID_undef.

SSL_CIPHER_get_handshake_digest() renvoie un EVP_MD pour le hachage utilisé pendant l'échange de clés dans la connexion SSL/TLS lors de l'utilisation du chiffrement c. Note : cela peut être différent du hachage utilisé pour calculer le MAC des enregistrements chiffrés.

SSL_CIPHER_get_kx_nid() renvoie le NID de la méthode d'échange de clés correspondant à c. S'il n'y a pas d'échange de clés, elle renvoie NID_undef. Si n'importe quel algorithme d'échange de clés approprié peut être utilisé (comme dans les suites de chiffrement TLS 1.3), elle renvoie NID_kx_any. Exemples (non exhaustifs) :

NID_kx_rsa
NID_kx_ecdhe
NID_kx_dhe
NID_kx_psk

SSL_CIPHER_get_auth_nid() renvoie le NID de la méthode d'authentification correspondant à c. S'il n'y a pas d'authentification, elle renvoie NID_undef. Si n'importe quel algorithme d'authentification approprié peut être utilisé (comme dans les suites de chiffrement TLS 1.3), elle renvoie NID_auth_any. Exemples (non exhaustifs) :

NID_auth_rsa
NID_auth_ecdsa
NID_auth_psk

SSL_CIPHER_is_aead() renvoie 1 si le chiffrement c est AEAD (par exemple, GCM ou ChaCha20/Poly1305), et 0 sinon.

SSL_CIPHER_find() renvoie une structure SSL_CIPHER qui a l'identifiant du chiffrement stocké dans ptr. Le paramètre ptr est un tableau de deux éléments de char, qui stocke l'identifiant de chiffrement TLS (tel qu'attribué par l'IANA) dans l'ordre des octets réseau. Ce paramètre est généralement obtenu d'un paquet TLS à l'aide de fonctions telles que SSL_client_hello_get0_ciphers(3). SSL_CIPHER_find() renvoie NULL si une erreur se produit ou si le chiffrement n'est pas trouvé.

SSL_CIPHER_get_id() renvoie l'identifiant spécifique à OpenSSL du chiffrement c. Cet identifiant n'est pas le même que l'identifiant spécifique à l'IANA.

SSL_CIPHER_get_protocol_id() renvoie l'identifiant de deux octets utilisé dans le protocole TLS pour le chiffrement c.

SSL_CIPHER_description() renvoie une description textuelle du chiffrement utilisé dans le tampon buf de longueur len. Si buf est fourni, il doit être d'au moins 128 octets. Si buf est NULL, il est alloué en utilisant OPENSSL_malloc(). Si le tampon fourni est trop petit ou si l'allocation échoue, elle renvoie NULL.

La chaîne renvoyée par SSL_CIPHER_description() se compose de plusieurs champs séparés par des espaces :

<ciphername>
Représentation textuelle du nom du chiffrement.
<protocol version>
La version minimale du protocole que la suite de chiffrement prend en charge, par exemple TLSv1.2. Note : ce n'est pas toujours la même que la version du protocole à laquelle la suite de chiffrement a été initialement introduite car certaines suites de chiffrement sont rétrocompatibles.
Kx=<key exchange>
Méthode d'échange de clés, telle que RSA, ECDHE, etc.
Au=<authentication>
Méthode d'authentification, telle que RSA, None, etc. None est la représentation des chiffrements anonymes.
Enc=<symmetric encryption method>
Méthode de chiffrement symétrique, avec le nombre de bits secrets, telle que AESGCM(128).
Mac=<message authentication code>
Algorithme de hachage, tel que SHA256.

Quelques exemples de sortie de SSL_CIPHER_description() :

ECDHE-RSA-AES256-GCM-SHA256 TLSv1.2 Kx=ECDH     Au=RSA  Enc=AESGCM(256) Mac=AEAD
RSA-PSK-AES256-CBC-SHA384 TLSv1.0 Kx=RSAPSK   Au=RSA  Enc=AES(256)  Mac=SHA384

VALEURS DE RETOUR

SSL_CIPHER_get_name(), SSL_CIPHER_standard_name(), OPENSSL_cipher_name(), SSL_CIPHER_get_version() et SSL_CIPHER_description() renvoient la valeur correspondante sous forme de chaîne terminée par un caractère nul pour un chiffrement donné ou "(NONE)" si le chiffrement n'est pas trouvé.

SSL_CIPHER_get_bits() renvoie un entier positif représentant le nombre de bits secrets ou 0 si une erreur se produit.

SSL_CIPHER_get_cipher_nid(), SSL_CIPHER_get_digest_nid(), SSL_CIPHER_get_kx_nid() et SSL_CIPHER_get_auth_nid() renvoient la valeur NID ou NID_undef si une erreur se produit.

SSL_CIPHER_get_handshake_digest() renvoie une structure EVP_MD valide ou NULL si une erreur se produit.

SSL_CIPHER_is_aead() renvoie 1 si le chiffrement est AEAD ou 0 sinon.

SSL_CIPHER_find() renvoie une structure SSL_CIPHER valide ou NULL si une erreur se produit.

SSL_CIPHER_get_id() renvoie un entier de 4 octets représentant l'identifiant spécifique à OpenSSL.

SSL_CIPHER_get_protocol_id() renvoie un entier de 2 octets représentant l'identifiant spécifique du protocole TLS.

VOIR AUSSI

ssl(7), SSL_get_current_cipher(3), SSL_get_ciphers(3), openssl-ciphers(1)

HISTORIQUE

La fonction SSL_CIPHER_get_version() a été mise à jour pour toujours renvoyer la chaîne correcte dans OpenSSL 1.1.0.

La fonction SSL_CIPHER_description() a été modifiée pour renvoyer NULL en cas d'erreur, au lieu d'une chaîne fixe, dans OpenSSL 1.1.0.

La fonction SSL_CIPHER_get_handshake_digest() a été ajoutée dans OpenSSL 1.1.1.

La fonction SSL_CIPHER_standard_name() est devenue globalement disponible dans OpenSSL 1.1.1.
