SSL_SESSION_set1_id(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_SESSION_SET1_ID(3ssl) OpenSSL SSL_SESSION_SET1_ID(3ssl)

NOM

SSL_SESSION_get_id, SSL_SESSION_set1_id - obtenir et définir l'ID de session SSL

SYNTAXE

#include <openssl/ssl.h>
const unsigned char *SSL_SESSION_get_id(const SSL_SESSION *s,
                                        unsigned int *len);
int SSL_SESSION_set1_id(SSL_SESSION *s, const unsigned char *sid,
                        unsigned int sid_len);

DESCRIPTION

SSL_SESSION_get_id() retourne un pointeur vers la valeur interne de l'ID de session pour la session s. La longueur de l'ID en octets est stockée dans *len. La longueur peut être de 0. L'appelant ne doit pas libérer le pointeur retourné directement.

SSL_SESSION_set1_id() définit l'ID de session pour la session SSL/TLS ssl à sid d'une longueur de sid_len.

VALEURS DE RETOUR

SSL_SESSION_get_id() retourne un pointeur vers la valeur de l'ID de session. SSL_SESSION_set1_id() retourne 1 en cas de succès et 0 en cas d'échec, par exemple si la longueur de l'ID de session fournie dépasse SSL_MAX_SSL_SESSION_ID_LENGTH.

VOIR AUSSI

ssl(7)

HISTORIQUE

La fonction SSL_SESSION_set1_id() a été ajoutée dans OpenSSL 1.1.0.
