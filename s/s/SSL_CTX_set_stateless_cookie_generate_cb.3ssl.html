NOM

SSL_CTX_set_stateless_cookie_generate_cb, SSL_CTX_set_stateless_cookie_verify_cb, SSL_CTX_set_cookie_generate_cb, SSL_CTX_set_cookie_verify_cb - Fonctions de rappel pour les cookies TLS1.3 sans état

SYNTAXE

#include <openssl/ssl.h>
void SSL_CTX_set_stateless_cookie_generate_cb(
    SSL_CTX *ctx,
    int (*gen_stateless_cookie_cb) (SSL *ssl,
                                    unsigned char *cookie,
                                    size_t *cookie_len));
void SSL_CTX_set_stateless_cookie_verify_cb(
    SSL_CTX *ctx,
    int (*verify_stateless_cookie_cb) (SSL *ssl,
                                       const unsigned char *cookie,
                                       size_t cookie_len));
void SSL_CTX_set_cookie_generate_cb(SSL_CTX *ctx,
                                    int (*app_gen_cookie_cb) (SSL *ssl,
                                                              unsigned char
                                                              *cookie,
                                                              unsigned int
                                                              *cookie_len));
void SSL_CTX_set_cookie_verify_cb(SSL_CTX *ctx,
                                  int (*app_verify_cookie_cb) (SSL *ssl,
                                                               const unsigned
                                                               char *cookie,
                                                               unsigned int
                                                               cookie_len));

DESCRIPTION

SSL_CTX_set_stateless_cookie_generate_cb() définit la fonction de rappel utilisée par SSL_stateless(3) pour générer la partie contrôlée par l'application du cookie fourni aux clients dans le HelloRetryRequest transmis en réponse à un ClientHello avec un cookie manquant ou invalide. gen_stateless_cookie_cb() doit écrire au maximum SSL_COOKIE_LENGTH octets dans cookie, et doit écrire le nombre d'octets écrits dans cookie_len. Si un cookie ne peut pas être généré, une valeur de retour nulle peut être utilisée pour abandonner la négociation.

SSL_CTX_set_stateless_cookie_verify_cb() définit la fonction de rappel utilisée par SSL_stateless(3) pour déterminer si la partie contrôlée par l'application d'un cookie ClientHello est valide. Les données du cookie sont pointées par cookie et ont la longueur cookie_len. Une valeur de retour non nulle de verify_stateless_cookie_cb() indique que le cookie est valide. L'intégrité du cookie entier, y compris la partie contrôlée par l'application, est automatiquement vérifiée par HMAC avant que verify_stateless_cookie_cb() ne soit appelée.

SSL_CTX_set_cookie_generate_cb() définit la fonction de rappel utilisée par DTLSv1_listen(3) pour générer le cookie fourni aux clients dans le HelloVerifyRequest transmis en réponse à un ClientHello avec un cookie manquant ou invalide. app_gen_cookie_cb() doit écrire au maximum DTLS1_COOKIE_LENGTH octets dans cookie, et doit écrire le nombre d'octets écrits dans cookie_len. Si un cookie ne peut pas être généré, une valeur de retour nulle peut être utilisée pour abandonner la négociation.

SSL_CTX_set_cookie_verify_cb() définit la fonction de rappel utilisée par DTLSv1_listen(3) pour déterminer si le cookie dans un ClientHello est valide. Les données du cookie sont pointées par cookie et ont la longueur cookie_len. Une valeur de retour non nulle de app_verify_cookie_cb() communique que le cookie est valide. L'intégrité du cookie n'est pas vérifiée par OpenSSL. Ceci est de la responsabilité de l'application.

VALEURS DE RETOUR

Aucune des fonctions ne retourne de valeur.

VOIR AUSSI

ssl(7), SSL_stateless(3), DTLSv1_listen(3)

HISTORIQUE

SSL_CTX_set_stateless_cookie_generate_cb() et SSL_CTX_set_stateless_cookie_verify_cb() ont été ajoutées dans OpenSSL 1.1.1.
