NOM

SSL_SESSION_get0_id_context, SSL_SESSION_set1_id_context - obtenir et définir le contexte d'ID SSL associé à une session

SYNTAXE

#include <openssl/ssl.h>
const unsigned char *SSL_SESSION_get0_id_context(const SSL_SESSION *s,
                                                 unsigned int *len);
int SSL_SESSION_set1_id_context(SSL_SESSION *s, const unsigned char *sid_ctx,
                               unsigned int sid_ctx_len);

DESCRIPTION

Voir SSL_CTX_set_session_id_context(3) pour plus de détails sur les contextes d'ID de session.

SSL_SESSION_get0_id_context() renvoie le contexte d'ID associé à la session SSL/TLS s. La longueur du contexte d'ID est écrite dans *len si len n'est pas NULL.

La valeur renvoyée est un pointeur vers un objet maintenu dans s et ne doit pas être libérée.

SSL_SESSION_set1_id_context() prend une copie du contexte d'ID fourni dans sid_ctx et l'associe à la session s. La longueur du contexte d'ID est donnée par sid_ctx_len, qui ne doit pas dépasser SSL_MAX_SID_CTX_LENGTH octets.

VALEURS DE RETOUR

SSL_SESSION_set1_id_context() renvoie 1 en cas de succès ou 0 en cas d'erreur.

VOIR AUSSI

ssl(7), SSL_set_session_id_context(3)

HISTORIQUE

La fonction SSL_SESSION_get0_id_context() a été ajoutée dans OpenSSL 1.1.0.
