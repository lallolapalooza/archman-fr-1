SSL_CTX_config(3ssl)

Paquet: openssl

Licences: Apache-2.0

SSL_CTX_CONFIG(3ssl) OpenSSL SSL_CTX_CONFIG(3ssl)

NOM

SSL_CTX_config, SSL_config - configurer la structure SSL_CTX ou SSL

SYNTAXE

#include <openssl/ssl.h>
int SSL_CTX_config(SSL_CTX *ctx, const char *name);
int SSL_config(SSL *s, const char *name);

DESCRIPTION

Les fonctions SSL_CTX_config() et SSL_config() configurent une structure SSL_CTX ou SSL en utilisant le nom de configuration name.

En appelant SSL_CTX_config() ou SSL_config(), une application peut effectuer de nombreuses tâches complexes basées sur le contenu du fichier de configuration : simplifiant grandement le code de configuration de l'application. Un certain degré d'anticipation des évolutions peut également être atteint : une application peut prendre en charge automatiquement les fonctionnalités de configuration des nouvelles versions d'OpenSSL.

Un fichier de configuration doit avoir été préalablement chargé, par exemple en utilisant CONF_modules_load_file(). Voir config(5) pour les détails de la syntaxe du fichier de configuration.

VALEURS DE RETOUR

SSL_CTX_config() et SSL_config() retournent 1 en cas de succès ou 0 si une erreur s'est produite.

EXEMPLES

Si le fichier "config.cnf" contient ce qui suit :

testapp = test_sect
[test_sect]
# liste des modules de configuration
ssl_conf = ssl_sect
[ssl_sect]
server = server_section
[server_section]
RSA.Certificate = server-rsa.pem
ECDSA.Certificate = server-ecdsa.pem
Ciphers = ALL:!RC4

Une application pourrait appeler :

if (CONF_modules_load_file("config.cnf", "testapp", 0) <= 0) {
    fprintf(stderr, "Erreur lors du traitement du fichier de configuration\n");
    goto err;
}
ctx = SSL_CTX_new(TLS_server_method());
if (SSL_CTX_config(ctx, "server") == 0) {
    fprintf(stderr, "Erreur lors de la configuration du serveur.\n");
    goto err;
}

Dans cet exemple, deux certificats et la liste des chiffrements sont configurés sans nécessiter de code d'application supplémentaire.

VOIR AUSSI

ssl(7), config(5), SSL_CONF_cmd(3), CONF_modules_load_file(3)

HISTORIQUE

Les fonctions SSL_CTX_config() et SSL_config() ont été ajoutées dans OpenSSL 1.1.0.
