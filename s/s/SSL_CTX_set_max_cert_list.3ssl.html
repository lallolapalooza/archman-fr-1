SSL_CTX_SET_MAX_CERT_LIST(3ssl) OpenSSL SSL_CTX_SET_MAX_CERT_LIST(3ssl)

NOM

SSL_CTX_set_max_cert_list, SSL_CTX_get_max_cert_list, SSL_set_max_cert_list, SSL_get_max_cert_list - manipuler la taille autorisée pour la chaîne de certificats du pair

SYNTAXE

#include <openssl/ssl.h>
long SSL_CTX_set_max_cert_list(SSL_CTX *ctx, long size);
long SSL_CTX_get_max_cert_list(SSL_CTX *ctx);
long SSL_set_max_cert_list(SSL *ssl, long size);
long SSL_get_max_cert_list(SSL *ctx);

DESCRIPTION

SSL_CTX_set_max_cert_list() définit la taille maximale autorisée pour la chaîne de certificats du pair pour tous les objets SSL créés à partir de ctx à <taille> octets. Les objets SSL héritent du réglage valide pour ctx au moment où SSL_new(3) est appelé.

SSL_CTX_get_max_cert_list() renvoie la taille maximale actuellement définie pour ctx.

SSL_set_max_cert_list() définit la taille maximale autorisée pour la chaîne de certificats du pair pour ssl à <taille> octets. Ce réglage reste valide jusqu'à ce qu'une nouvelle valeur soit définie.

SSL_get_max_cert_list() renvoie la taille maximale actuellement définie pour ssl.

NOTES

Pendant le processus de négociation, le pair peut envoyer une chaîne de certificats. Le standard TLS/SSL ne donne aucune taille maximale pour la chaîne de certificats. La bibliothèque OpenSSL gère les données entrantes par un tampon alloué dynamiquement. Afin d'éviter que ce tampon ne croisse sans limite en raison de données reçues d'un pair défectueux ou malveillant, une taille maximale pour la chaîne de certificats est définie.

La valeur par défaut pour la taille maximale de la chaîne de certificats est de 100 Ko (30 Ko sur la plateforme DOS 16 bits). Cela devrait être suffisant pour les chaînes de certificats habituelles (la longueur maximale par défaut de la chaîne d'OpenSSL est de 10, voir SSL_CTX_set_verify(3), et les certificats sans extensions spéciales ont une taille typique de 1-2 Ko).

Pour des applications spéciales, il peut être nécessaire d'étendre la taille maximale de la chaîne de certificats autorisée à être envoyée par le pair, voir par exemple les travaux sur le "Profil de certificat proxy Internet X.509 Public Key Infrastructure" et le "Protocole de délégation TLS" sur http://www.ietf.org/ et http://www.globus.org/.

Dans des conditions normales, il ne devrait jamais être nécessaire de définir une valeur inférieure à la valeur par défaut, car le tampon est géré dynamiquement et n'utilise que la mémoire réellement requise par les données envoyées par le pair.

Si la taille maximale autorisée de la chaîne de certificats est dépassée, la négociation échouera avec une erreur SSL_R_EXCESSIVE_MESSAGE_SIZE.

VALEURS DE RETOUR

SSL_CTX_set_max_cert_list() et SSL_set_max_cert_list() renvoient la valeur précédemment définie.

SSL_CTX_get_max_cert_list() et SSL_get_max_cert_list() renvoient la valeur actuellement définie.
