DESCRIPTION

En plus des noms d'erreurs que les programmes utilisateur définissent, D-Bus connaît un certain nombre de noms d'erreurs génériques et standardisés listés ci-dessous.

En plus de cette liste, dans sd-bus, l'espace de noms d'erreur spécial "System.Error." est utilisé pour mapper les erreurs système Linux arbitraires (telles que définies par errno(3)) vers les erreurs D-Bus et vice versa. Par exemple, l'erreur EUCLEAN est mappée vers "System.Error.EUCLEAN" et inversement.

SD_BUS_ERROR_FAILED

Une indication d'erreur générique. Voir le message d'erreur pour plus de détails. Ce nom d'erreur doit être évité, au profit d'un nom d'erreur plus expressif.

Ajouté dans la version 223.

DESCRIPTION

The structure sd_bus_error is used to represent errors that occur during communication over D-Bus. It contains a name (a string) and a message (a string). The name usually follows the reverse-DNS format, e.g. org.freedesktop.DBus.Error.ServiceUnknown. The message provides a human-readable description of the error.

The constants SD_BUS_ERROR_* define standard error names that are commonly used. These constants are defined in the header file sd-bus.h.

SD_BUS_ERROR_NULL

Represents an unset error.

SD_BUS_ERROR_ACCESS_DENIED

Access to the requested operation is denied.

SD_BUS_ERROR_AUTH_FAILED

Authentication failed.

SD_BUS_ERROR_LIMIT_EXCEEDED

A limit was exceeded, e.g. too many file descriptors.

SD_BUS_ERROR_NOT_SUPPORTED

The requested operation is not supported.

SD_BUS_ERROR_SERVICE_UNKNOWN

The requested service is unknown.

SD_BUS_ERROR_NAME_OWNER_LOST

The owner of the requested bus name has lost ownership.

SD_BUS_ERROR_CANCELLED

The operation was cancelled.

SD_BUS_ERROR_TIMEOUT

The operation timed out.

SD_BUS_ERROR_FILE_NOT_FOUND

The requested file was not found.

SD_BUS_ERROR_NO_SUCH_UNIT

The requested unit was not found.

SD_BUS_ERROR_NOT_PERMITTED

The operation is not permitted.

SD_BUS_ERROR_READ_ONLY_PROPERTY

A write operation was attempted on a read-only property.

SD_BUS_ERROR_UNIX_PROCESS_ID_UNKNOWN

The requested PID is not known.

Added in version 223.

SD_BUS_ERROR_INVALID_SIGNATURE

The specified message signature is not valid.

Added in version 223.

SD_BUS_ERROR_INCONSISTENT_MESSAGE

The passed message does not validate correctly.

Added in version 223.

SD_BUS_ERROR_MATCH_RULE_NOT_FOUND

The specified match rule does not exist.

Added in version 223.

SD_BUS_ERROR_MATCH_RULE_INVALID

The specified match rule is invalid.

Added in version 223.

SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED

Access to the requested operation is not permitted. However, it might be available after interactive authentication. This is usually returned by method calls supporting a framework for additional interactive authorization, when interactive authorization was not enabled with the sd_bus_message_set_allow_interactive_authorization(3) for the method call message.

Added in version 223.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
