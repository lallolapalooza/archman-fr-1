DESCRIPTION

En plus des noms d'erreur définis par l'utilisateur, D-Bus connaît un certain nombre de noms d'erreur standard et généraux qui sont énumérés ci-dessous.

En plus de cette liste, dans sd-bus, l'espace d'erreur spécial « System.Error. » est utilisé pour mapper les erreurs du système Linux (telles que définies par errno(3)) vers des erreurs D-Bus et vice versa. Par exemple, l'erreur EUCLEAN est mappée à « System.Error.EUCLEAN » et vice versa.

SD_BUS_ERROR_FAILED

Un indicateur d'erreur général. Pour plus de détails, voir le message d'erreur. Ce nom d'erreur doit être évité, préférez un nom d'erreur plus expressif.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_MEMORY

Un échec d'allocation mémoire, et l'opération demandée n'a pas pu être complétée.

Ajouté dans la version 223.

SD_BUS_ERROR_SERVICE_UNKNOWN

Le service que vous essayez d'activer n'est pas disponible.

Ajouté dans la version 223.

SD_BUS_ERROR_NAME_HAS_NO_OWNER

Le nom du service que vous essayez d'activer n'a pas de propriétaire.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_REPLY

Aucune réponse n'a été reçue pour un message. Cette erreur est généralement générée après une expiration de délai.

Ajouté dans la version 223.

SD_BUS_ERROR_IO_ERROR

Une erreur générale d'entrée/sortie, par exemple lors de l'accès à un socket ou à un contexte d'E/S.

Ajouté dans la version 223.

SD_BUS_ERROR_BAD_ADDRESS

La chaîne d'adresse du bus spécifiée est mal formée.

Ajouté dans la version 223.

SD_BUS_ERROR_NOT_SUPPORTED

L'opération demandée n'est pas supportée sur le système local.

Ajouté dans la version 223.

SD_BUS_ERROR_LIMITS_EXCEEDED

Une limite de ressources a été atteinte.

Ajouté dans la version 223.

Ajouté dans la version 223.

DESCRIPTION

En plus des noms d'erreur définis par l'utilisateur, D-Bus connaît un certain nombre de noms d'erreur standard et généraux qui sont énumérés ci-dessous.

En plus de cette liste, dans sd-bus, l'espace d'erreur spécial « System.Error. » est utilisé pour mapper les erreurs du système Linux (telles que définies par errno(3)) vers des erreurs D-Bus et vice versa. Par exemple, l'erreur EUCLEAN est mappée à « System.Error.EUCLEAN » et vice versa.

Un indicateur d'erreur général. Pour plus de détails, voir le message d'erreur. Ce nom d'erreur doit être évité, préférez un nom d'erreur plus expressif.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme non sûr pour les threads multiples. Cela signifie que le code appelant ces fonctions ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'appeler setenv() qu'à un stade précoce du programme, lorsqu'aucun autre thread n'a encore été démarré.
