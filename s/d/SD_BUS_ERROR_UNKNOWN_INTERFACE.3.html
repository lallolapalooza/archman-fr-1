DESCRIPTION

En plus des noms d'erreurs définis par les programmes utilisateurs, D-Bus connaît un certain nombre de noms d'erreurs génériques et standardisés qui sont listés ci-dessous.

En plus de cette liste, dans sd-bus, l'espace de noms spécial d'erreurs "System.Error." est utilisé pour mapper les erreurs système Linux arbitraires (telles que définies par errno(3)) aux erreurs D-Bus et vice versa. Par exemple, l'erreur EUCLEAN est mappée à "System.Error.EUCLEAN" et vice versa.

SD_BUS_ERROR_FAILED

Une indication d'erreur générique. Voir le message d'erreur pour plus de détails. Ce nom d'erreur doit être évité, au profit d'un nom d'erreur plus expressif.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_MEMORY

Une allocation mémoire a échoué et l'opération demandée n'a pas pu être complétée.

Ajouté dans la version 223.

Le service bus contacté est inconnu et ne peut pas être activé.

Ajouté dans la version 223.

SD_BUS_ERROR_NAME_HAS_NO_OWNER

Le nom du service bus spécifié n'a actuellement aucun propriétaire.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_REPLY

Un message n'a pas reçu de réponse. Cette erreur est généralement générée après un délai d'attente.

Ajouté dans la version 223.

SD_BUS_ERROR_IO_ERROR

Erreur générique d'entrée/sortie, par exemple lors de l'accès à un socket ou à un autre contexte d'E/S.

Ajouté dans la version 223.

SD_BUS_ERROR_BAD_ADDRESS

Ajouté dans la version 223.

SD_BUS_ERROR_TIMEOUT

SD_BUS_ERROR_NO_NETWORK

Ajouté dans la version 223.

#include <systemd/sd-bus.h>

/* Standard D-Bus error conditions */
extern const char * const SD_BUS_ERROR_UNKNOWN_INTERFACE;
extern const char * const SD_BUS_ERROR_UNKNOWN_MEMBER;
extern const char * const SD_BUS_ERROR_UNKNOWN_PROPERTY;
extern const char * const SD_BUS_ERROR_UNIX_PROCESS_ID_UNKNOWN;

extern const char * const SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED;

/* Error structure */
struct sd_bus_error {
    const char *name;
    const char *message;
};

void sd_bus_error_free(struct sd_bus_error *e);
int sd_bus_error_has_name(const struct sd_bus_error *e, const char *name);

DESCRIPTION

The library provides several string constants for common error conditions.

SD_BUS_ERROR_UNKNOWN_INTERFACE

The specified interface is unknown.

Added in version 223.

SD_BUS_ERROR_UNKNOWN_MEMBER

The specified member (method or signal) is unknown.

Added in version 223.

SD_BUS_ERROR_UNKNOWN_PROPERTY

An operation was requested on a read-only property.

Added in version 223.

SD_BUS_ERROR_UNIX_PROCESS_ID_UNKNOWN

The requested PID is not known.

Added in version 223.

SD_BUS_ERROR_INVALID_SIGNATURE

The specified message signature is not valid.

Added in version 223.

SD_BUS_ERROR_INCONSISTENT_MESSAGE

The passed message does not validate correctly.

Added in version 223.

SD_BUS_ERROR_MATCH_RULE_NOT_FOUND

The specified match rule does not exist.

Added in version 223.

SD_BUS_ERROR_MATCH_RULE_INVALID

The specified match rule is invalid.

Added in version 223.

SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED

Access to the requested operation is not permitted. However, it might be available after interactive authentication. This is usually returned by method calls supporting a framework for additional interactive authorization, when interactive authorization was not enabled with the sd_bus_message_set_allow_interactive_authorization(3) for the method call message.

Added in version 223.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
