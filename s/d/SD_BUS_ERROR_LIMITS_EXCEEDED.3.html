DESCRIPTION

En plus des noms d'erreurs définis par les programmes utilisateurs, D-Bus connaît un certain nombre de noms d'erreurs standard et génériques qui sont listés ci-dessous.

En plus de cette liste, dans sd-bus, l'espace d'erreur spécial « System.Error » est utilisé pour mapper les erreurs système Linux (telles que définies dans errno(3)) vers les erreurs D-Bus et vice versa. Par exemple, l'erreur EUCLEAN est mappée à « System.Error.EUCLEAN » et vice versa.

SD_BUS_ERROR_FAILED

Une indication d'erreur générique. Pour plus de détails, voir le message d'erreur. Cette chaîne d'erreur devrait être évitée, en utilisant plutôt un nom d'erreur plus expressif.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_MEMORY

Un échec d'allocation de mémoire, et l'opération demandée n'a pas pu être complétée.

Ajouté dans la version 223.

SD_BUS_ERROR_SERVICE_UNKNOWN

Le service de bus contacté n'est pas connu et ne peut pas être activé.

Ajouté dans la version 223.

SD_BUS_ERROR_NAME_HAS_NO_OWNER

Le nom du service de bus n'a actuellement pas de propriétaire.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_REPLY

Aucune réponse n'a été reçue pour un message. Cette erreur est généralement générée après un délai d'attente.

Ajouté dans la version 223.

SD_BUS_ERROR_IO_ERROR

Erreur d'entrée/sortie générique, par exemple lors de l'accès à un socket ou à un contexte d'E/S.

Ajouté dans la version 223.

SD_BUS_ERROR_BAD_ADDRESS

La chaîne d'adresse de bus D-Bus spécifiée est mal formée.

Ajouté dans la version 223.

SD_BUS_ERROR_NOT_SUPPORTED

L'opération demandée n'est pas prise en charge sur le système local.

Ajouté dans la version 223.

SD_BUS_ERROR_LIMITS_EXCEEDED

Une limite de ressources a été atteinte.

Ajouté dans la version 223.

SD_BUS_ERROR_ACCESS_DENIED

L'accès à une ressource a été restreint en raison de restrictions de sécurité.

Ajouté dans la version 223.

SD_BUS_ERROR_AUTH_FAILED

L'authentification n'a pas abouti.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_SERVER

Impossible de se connecter au serveur spécifié.

Ajouté dans la version 223.

SD_BUS_ERROR_TIMEOUT

Une opération a expiré. Remarque : les appels de méthode qui expirent génèrent SD_BUS_ERROR_NO_REPLY.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_NETWORK

Aucun réseau disponible pour effectuer l'opération réseau demandée.

Ajouté dans la version 223.

SD_BUS_ERROR_ADDRESS_IN_USE

L'adresse réseau spécifiée est déjà en cours d'écoute.

Ajouté dans la version 223.

SD_BUS_ERROR_DISCONNECTED

La connexion a été terminée.

Ajouté dans la version 223.

SD_BUS_ERROR_INVALID_ARGS

Des arguments invalides ont été spécifiés.

Ajouté dans la version 223.

SD_BUS_ERROR_FILE_NOT_FOUND

Le fichier demandé n'a pas été trouvé.

Ajouté dans la version 223.

SD_BUS_ERROR_FILE_EXISTS

Le fichier demandé existe déjà.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_METHOD

La méthode demandée n'existe pas dans l'interface sélectionnée.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_OBJECT

L'objet demandé n'existe pas dans l'interface sélectionnée.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_INTERFACE

L'interface demandée n'existe pas dans l'objet sélectionné.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_PROPERTY

La propriété demandée n'existe pas dans l'interface sélectionnée.

Ajouté dans la version 223.

Ajouté dans la version 223.

sd-bus.h — constants for systemd D-Bus API

NAME

sd_bus_error, SD_BUS_ERROR_UNEXPECTED_NULL, SD_BUS_ERROR_UNIX_PROCESS_ID_UNKNOWN, SD_BUS_ERROR_INVALID_SIGNATURE, SD_BUS_ERROR_INCONSISTENT_MESSAGE, SD_BUS_ERROR_MATCH_RULE_NOT_FOUND, SD_BUS_ERROR_MATCH_RULE_INVALID, SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED - constants for systemd D-Bus API

SYNOPSIS

All constants are defined in <systemd/sd-bus.h>.

The following error codes are defined:

SD_BUS_ERROR_UNEXPECTED_NULL

An unexpected NULL pointer was passed to a function.

Added in version 223.

SD_BUS_ERROR_UNIX_PROCESS_ID_UNKNOWN

The requested PID is not known.

Added in version 223.

SD_BUS_ERROR_INVALID_SIGNATURE

The specified message signature is not valid.

Added in version 223.

SD_BUS_ERROR_INCONSISTENT_MESSAGE

The passed message does not validate correctly.

Added in version 223.

SD_BUS_ERROR_MATCH_RULE_NOT_FOUND

The specified match rule does not exist.

Added in version 223.

SD_BUS_ERROR_MATCH_RULE_INVALID

The specified match rule is invalid.

Added in version 223.

SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED

Access to the requested operation is not permitted. However, it might be available after interactive authentication. This is usually returned by method calls supporting a framework for additional interactive authorization, when interactive authorization was not enabled with the sd_bus_message_set_allow_interactive_authorization(3) for the method call message.

Added in version 223.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
