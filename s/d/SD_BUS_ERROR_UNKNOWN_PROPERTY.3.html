DESCRIPTION

En plus des noms d'erreur définis par les programmes utilisateurs, D-Bus connaît un certain nombre de noms d'erreur génériques et standardisés listés ci-dessous.

En plus de cette liste, dans sd-bus, l'espace de noms d'erreur spécial "System.Error." est utilisé pour mapper des erreurs système Linux arbitraires (telles que définies par errno(3)) vers et depuis des erreurs D-Bus. Par exemple, l'erreur EUCLEAN est mappée à "System.Error.EUCLEAN" et inversement.

SD_BUS_ERROR_FAILED

Une indication d'erreur générique. Voir le message d'erreur pour plus de détails. Ce nom d'erreur doit être évité au profit d'un nom d'erreur plus expressif.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_MEMORY

Une allocation de mémoire a échoué et l'opération demandée n'a pas pu être complétée.

Ajouté dans la version 223.

SD_BUS_ERROR_SERVICE_UNKNOWN

Le service bus contacté est inconnu et ne peut pas être activé.

Ajouté dans la version 223.

SD_BUS_ERROR_NAME_HAS_NO_OWNER

Le nom du service bus spécifié n'a actuellement pas de propriétaire.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_REPLY

Un message n'a pas reçu de réponse. Cette erreur est généralement générée après un délai d'attente.

Ajouté dans la version 223.

SD_BUS_ERROR_IO_ERROR

Erreur générique d'entrée/sortie, par exemple lors de l'accès à une socket ou à un autre contexte d'E/S.

Ajouté dans la version 223.

SD_BUS_ERROR_BAD_ADDRESS

La chaîne d'adresse de bus D-Bus spécifiée est mal formée.

Ajouté dans la version 223.

SD_BUS_ERROR_NOT_SUPPORTED

L'opération demandée n'est pas supportée sur le système local.

Ajouté dans la version 223.

SD_BUS_ERROR_LIMITS_EXCEEDED

Une ressource limitée a été épuisée.

Ajouté dans la version 223.

SD_BUS_ERROR_ACCESS_DENIED

L'accès à une ressource a été refusé en raison de restrictions de sécurité.

Ajouté dans la version 223.

SD_BUS_ERROR_AUTH_FAILED

L'authentification n'a pas pu s'achever avec succès.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_SERVER

Impossible de se connecter au serveur spécifié.

Ajouté dans la version 223.

SD_BUS_ERROR_TIMEOUT

Une opération a expiré. Notez que les appels de méthode qui timeout génèrent un SD_BUS_ERROR_NO_REPLY.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_NETWORK

Aucun réseau disponible pour exécuter l'opération réseau demandée.

Ajouté dans la version 223.

SD_BUS_ERROR_ADDRESS_IN_USE

L'adresse réseau spécifiée est déjà en cours d'écoute.

Ajouté dans la version 223.

SD_BUS_ERROR_DISCONNECTED

La connexion a été terminée.

Ajouté dans la version 223.

SD_BUS_ERROR_INVALID_ARGS

Un ou plusieurs arguments invalides ont été passés.

Ajouté dans la version 223.

SD_BUS_ERROR_FILE_NOT_FOUND

Le fichier demandé n'a pas pu être trouvé.

Ajouté dans la version 223.

SD_BUS_ERROR_FILE_EXISTS

Le fichier demandé existe déjà.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_METHOD

La méthode demandée n'existe pas dans l'interface sélectionnée.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_OBJECT

L'objet demandé n'existe pas dans le service sélectionné.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_INTERFACE

L'interface demandée n'existe pas sur l'objet sélectionné.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_PROPERTY

La propriété demandée n'existe pas dans l'interface sélectionnée.

Ajouté dans la version 223.
