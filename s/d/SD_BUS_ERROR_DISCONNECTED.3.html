DESCRIPTION

En plus des noms d'erreurs que les programmes utilisateur définissent, D-Bus connaît un certain nombre de noms d'erreurs génériques et standardisés qui sont listés ci-dessous.

En plus de cette liste, dans sd-bus, l'espace de noms d'erreur spécial "System.Error." est utilisé pour mapper des erreurs système Linux arbitraires (telles que définies par errno(3)) vers et depuis des erreurs D-Bus. Par exemple, l'erreur EUCLEAN est mappée à "System.Error.EUCLEAN" et vice versa.

SD_BUS_ERROR_FAILED

Une indication d'erreur générique. Voir le message d'erreur pour plus de détails. Ce nom d'erreur doit être évité, au profit d'un nom d'erreur plus expressif.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_MEMORY

Une allocation de mémoire a échoué et l'opération demandée n'a pas pu être réalisée.

Ajouté dans la version 223.

SD_BUS_ERROR_SERVICE_UNKNOWN

Le service bus contacté est inconnu et ne peut pas être activé.

Ajouté dans la version 223.

SD_BUS_ERROR_NAME_HAS_NO_OWNER

Le nom de service bus spécifié n'a actuellement aucun propriétaire.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_REPLY

Un message n'a pas reçu de réponse. Cette erreur est généralement générée après un délai d'attente.

Ajouté dans la version 223.

SD_BUS_ERROR_IO_ERROR

Erreur générique d'entrée/sortie, par exemple lors de l'accès à un socket ou à un autre contexte d'E/S.

Ajouté dans la version 223.

SD_BUS_ERROR_BAD_ADDRESS

La chaîne d'adresse de bus D-Bus spécifiée est mal formée.

Ajouté dans la version 223.

SD_BUS_ERROR_NOT_SUPPORTED

L'opération demandée n'est pas prise en charge sur le système local.

Ajouté dans la version 223.

SD_BUS_ERROR_LIMITS_EXCEEDED

Une ressource limitée a été épuisée.

Ajouté dans la version 223.

SD_BUS_ERROR_ACCESS_DENIED

L'accès à une ressource a été refusé en raison de restrictions de sécurité.

Ajouté dans la version 223.

SD_BUS_ERROR_AUTH_FAILED

L'authentification n'a pas abouti.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_SERVER

Impossible de se connecter au serveur spécifié.

Ajouté dans la version 223.

SD_BUS_ERROR_TIMEOUT

Une opération a expiré. Notez que les appels de méthode qui atteignent le délai d'attente génèrent un SD_BUS_ERROR_NO_REPLY.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_NETWORK

Aucun réseau disponible pour effectuer l'opération réseau demandée.

Ajouté dans la version 223.

SD_BUS_ERROR_ADDRESS_IN_USE

L'adresse réseau spécifiée est déjà utilisée en écoute.

Ajouté dans la version 223.

SD_BUS_ERROR_DISCONNECTED

La connexion a été terminée.

Ajouté dans la version 223.

SD_BUS_ERROR_INVALID_ARGS

Un ou plusieurs arguments invalides ont été passés.

Ajouté dans la version 223.

SD_BUS_ERROR_FILE_NOT_FOUND

Le fichier demandé n'a pas pu être trouvé.

Ajouté dans la version 223.

SD_BUS_ERROR_FILE_EXISTS

Le fichier demandé existe déjà.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_METHOD

La méthode demandée n'existe pas dans l'interface sélectionnée.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_OBJECT

L'objet demandé n'existe pas dans le service sélectionné.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_INTERFACE

L'interface demandée n'existe pas sur l'objet sélectionné.

Ajouté dans la version 223.

Ajouté dans la version 223.

SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED

Access to the requested operation is not permitted. However, it might be available after interactive authentication. This is usually returned by method calls supporting a framework for additional interactive authorization, when interactive authorization was not enabled with the sd_bus_message_set_allow_interactive_authorization(3) for the method call message.

Added in version 223.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'effectuer les appels à setenv() qu'à une phase précoce du programme, lorsque aucun autre thread n'a été démarré.
