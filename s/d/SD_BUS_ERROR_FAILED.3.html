DESCRIPTION

En plus des noms d'erreurs définis par les programmes utilisateurs, D-Bus connaît un certain nombre de noms d'erreurs générales standard listés ci-dessous.

En plus de cette liste, dans sd-bus, l'espace de noms spécial "System.Error" est utilisé pour mapper les erreurs du système Linux (telles que définies par errno(3)) vers les erreurs D-Bus et vice-versa. Par exemple, l'erreur EUCLEAN est mappée vers "System.Error.EUCLEAN" et vice-versa.

SD_BUS_ERROR_FAILED

Un indicateur d'erreur général. Pour plus de détails, voir le message d'erreur. Ce nom d'erreur devrait être évité au profit d'un nom d'erreur plus expressif.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_MEMORY

Un échec d'allocation de mémoire, et l'opération demandée n'a pu être complétée.

Ajouté dans la version 223.

SD_BUS_ERROR_SERVICE_UNKNOWN

Le service bus contacté est inconnu et ne peut être activé.

Ajouté dans la version 223.

SD_BUS_ERROR_NAME_HAS_NO_OWNER

Le nom du service spécifié n'a actuellement pas de propriétaire.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_REPLY

Un message n'a pas reçu de réponse. Cette erreur est généralement générée après un timeout.

Ajouté dans la version 223.

SD_BUS_ERROR_IO_ERROR

Une erreur générale d'entrée/sortie, par exemple lors de l'accès à un socket ou à un contexte d'E/S.

Ajouté dans la version 223.

SD_BUS_ERROR_BAD_ADDRESS

La chaîne d'adresse bus spécifiée est malformée.

Ajouté dans la version 223.

SD_BUS_ERROR_NOT_SUPPORTED

L'opération demandée n'est pas supportée sur le système local.

Ajouté dans la version 223.

SD_BUS_ERROR_LIMITS_EXCEEDED

Une ressource limitée a été épuisée.

Ajouté dans la version 223.

SD_BUS_ERROR_ACCESS_DENIED

L'accès à une ressource a été refusé en raison de restrictions de sécurité.

Ajouté dans la version 223.

SD_BUS_ERROR_AUTH_FAILED

L'authentification n'a pas pu être effectuée correctement.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_SERVER

Impossible de se connecter au serveur spécifié.

Ajouté dans la version 223.

SD_BUS_ERROR_TIMEOUT

Une opération a expiré. Remarque : les appels de méthode qui expirent génèrent un SD_BUS_ERROR_NO_REPLY.

Ajouté dans la version 223.

SD_BUS_ERROR_NO_NETWORK

Aucun réseau n'est disponible pour effectuer l'opération réseau demandée.

Ajouté dans la version 223.

SD_BUS_ERROR_ADDRESS_IN_USE

L'adresse réseau spécifiée est déjà utilisée en écoute.

Ajouté dans la version 223.

SD_BUS_ERROR_DISCONNECTED

La connexion a été terminée.

Ajouté dans la version 223.

SD_BUS_ERROR_INVALID_ARGS

Ajouté dans la version 223.

Ajouté dans la version 223.

SD_BUS_ERROR_FILE_EXISTS

Ajouté dans la version 223.

Ajouté dans la version 223.

NOTES

Les fonctions décrites ici sont disponibles en tant que bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'appeler setenv() que dès le début du programme, lorsqu'aucun autre thread n'a été démarré.
