Squirrel(3pm) Documentation Perl contribuée par l'utilisateur Squirrel(3pm)

NOM

Squirrel - Utiliser Souris, sauf si Élan est déjà chargé. (OBSOLÈTE)

SYNTAXE

use Squirrel;
has goggles => (
    is => "rw", 
);

OBSOLESCENCE

"Squirrel" est obsolète. "Any::Moose" fournit la même fonctionnalité, mais en mieux. :)

DESCRIPTION

Moose et Squirrel sont LES MEILLEURS AMIS, mais si Moose n'est pas là, Squirrel traînera aussi avec Mouse.

Lorsque votre propre code ne se soucie pas vraiment d'utiliser Moose ou Mouse, vous pouvez utiliser l'un ou l'autre, et laisser vos utilisateurs décider pour vous.

Cela vous permet de fonctionner avec des dépendances minimales et d'avoir un démarrage plus rapide, mais si Moose est déjà utilisé, vous bénéficiez de tous les avantages de son utilisation (transfomabilité, introspection, plus d'opportunités de réutilisation du code, etc.).

VOIR AUSSI

Any::Moose
