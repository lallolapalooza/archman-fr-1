Paquet: perl-shell-guess

Shell::Guess(3) Documentation Perl fournie par l'utilisateur Shell::Guess(3)

NOM

Shell::Guess - Faire une estimation éclairée du shell utilisé

VERSION

version 0.10

SYNOPSIS

deviner le shell qui a appelé le script Perl :

use Shell::Guess;
my $shell = Shell::Guess->running_shell;
if($shell->is_c) {
  print "setenv FOO bar\n";
} elsif($shell->is_bourne) {
  print "export FOO=bar\n";
}

deviner le shell de connexion de l'utilisateur actuel :

use Shell::Guess;
my $shell = Shell::Guess->login_shell;
print $shell->name, "\n";

deviner le shell de connexion d'un utilisateur arbitraire :

use Shell::Guess;
my $shell = Shell::Guess->login_shell('bob');
print $shell->name, "\n";

DESCRIPTION

Shell::Guess tente de manière assez agressive de déterminer le shell utilisé par l'utilisateur, soit le shell qui a directement exécuté le script Perl (le shell "en cours d'exécution"), soit le shell de connexion de l'utilisateur (le shell de "connexion"). Pour ce faire, il utilise divers moyens à sa disposition, en fonction de la plateforme sur laquelle il s'exécute.

  • getpwent

    Sur les systèmes UNIX avec getpwent, cela peut être utilisé pour déterminer le shell de connexion.

  • dscl

    Sous Mac OS X, getpwent ne fournit généralement aucune information utile, donc la commande dscl est utilisée à la place.

  • systèmes de fichiers proc

    Sur les systèmes UNIX avec un système de fichiers proc (comme Linux), Shell::Guess tentera de l'utiliser pour déterminer le shell en cours d'exécution.

  • ps

    Sur les systèmes UNIX sans système de fichiers proc, Shell::Guess utilisera la commande ps pour déterminer le shell en cours d'exécution.

  • Win32::Getppid et Win32::Process::List

    Sous Windows, si ces modules sont installés, ils seront utilisés pour déterminer le shell en cours d'exécution. Cette méthode peut différencier PowerShell, "command.com" et "cmd.exe".

  • ComSpec

    Si la méthode ci-dessus n'est pas concluante, la variable d'environnement ComSpec sera consultée pour différencier entre "command.com" et "cmd.exe" (PowerShell ne peut pas être détecté de cette manière).

  • valeurs par défaut raisonnables

    Si le shell en cours d'exécution ou de connexion ne peut pas être déterminé autrement, une valeur par défaut raisonnable pour votre plateforme sera utilisée comme solution de repli. Sous OpenVMS, il s'agit de dcl, sous Windows 95/98 et MS-DOS, il s'agit de command.com, et sous Windows NT/2000/XP/Vista/7, il s'agit de cmd.exe. Les plateformes UNIX se rabattent sur le shell Bourne.

L'objectif de ce module est de permettre à un développeur Perl d'écrire un script qui génère des configurations de shell pour le shell appelant afin qu'elles puissent être réimportées dans le shell appelant en utilisant "eval" et des backticks ou "source". Par exemple, si votre script ressemble à ceci :

#!/usr/bin/perl
use Shell::Guess;
my $shell = Shell::Guess->running_shell;
if($shell->is_bourne) {
  print "export FOO=bar\n";
} else($shell->is_c) {
  print "setenv FOO bar\n";
} else {
  die "Je ne supporte pas le shell ", $shell->name, "\n";
}

Vous pouvez ensuite importer FOO dans votre shell bash ou c shell comme ceci :

% eval `perl script.pl`

ou, vous pouvez écrire la sortie dans un fichier de configuration et le sourcer :

% perl script.pl > foo.sh
% source foo.sh

Shell::Config::Generate fournit une interface portable pour générer de telles configurations de shell et est conçu pour fonctionner avec ce module.

MÉTHODES DE CLASSE

Ces méthodes de classe retournent une instance de Shell::Guess, qui peut ensuite être interrogée par les méthodes d'instance de la section suivante.

running_shell

my $shell = Shell::Guess->running_shell;

Retourne une instance de Shell::Guess basée sur le shell qui a directement démarré le script Perl actuel. Si le shell en cours d'exécution ne peut pas être déterminé, il retournera le shell de connexion.

login_shell

my $shell = Shell::Guess->login_shell;
my $shell = Shell::Guess->login_shell( $username )

Retourne une instance de Shell::Guess pour l'utilisateur donné. Si aucun nom d'utilisateur n'est spécifié, l'utilisateur actuel sera utilisé. Si aucun shell ne peut être deviné, une solution de repli raisonnable sera choisie en fonction de votre plateforme.

bash_shell

my $shell = Shell::Guess->bash_shell;

Retourne une instance de Shell::Guess pour bash.

Les méthodes d'instance suivantes retourneront :

  • $shell->name = bash
  • $shell->is_bash = 1
  • $shell->is_bourne = 1
  • $shell->is_unix = 1
  • $shell->default_location = /bin/bash

Toutes les autres méthodes d'instance retourneront false.

bourne_shell

my $shell = Shell::Guess->bourne_shell;

Retourne une instance de Shell::Guess pour le shell Bourne.

Les méthodes d'instance suivantes retourneront :

  • $shell->name = bourne
  • $shell->is_bourne = 1
  • $shell->is_unix = 1
  • $shell->default_location = /bin/sh

Toutes les autres méthodes d'instance retourneront false.

c_shell

my $shell = Shell::Guess->c_shell;

Retourne une instance de Shell::Guess pour le shell c.

Les méthodes d'instance suivantes retourneront :

  • $shell->name = c
  • $shell->is_c = 1
  • $shell->is_unix = 1
  • $shell->default_location = /bin/csh

Toutes les autres méthodes d'instance retourneront false.

cmd_shell

my $shell = Shell::Guess->cmd_shell;

Retourne une instance de Shell::Guess pour le shell cmd de Windows NT (cmd.exe).

Les méthodes d'instance suivantes retourneront :

  • $shell->name = cmd
  • $shell->is_cmd = 1
  • $shell->is_win32 = 1
  • $shell->default_location = C:\Windows\system32\cmd.exe

Toutes les autres méthodes d'instance retourneront false.

command_shell

my $shell = Shell::Guess->command_shell;

Retourne une instance de Shell::Guess pour le shell de commande de Windows 95 (command.com).

Les méthodes d'instance suivantes retourneront :

  • $shell->name = command
  • $shell->is_command = 1
  • $shell->is_win32 = 1
  • $shell->default_location = C:\Windows\system32\command.com

Toutes les autres méthodes d'instance retourneront false.

dcl_shell

my $shell = Shell::Guess->dcl_shell;

Retourne une instance de Shell::Guess pour le shell dcl d'OpenVMS.

Les méthodes d'instance suivantes retourneront :

  • $shell->name = dcl
  • $shell->is_dcl = 1
  • $shell->is_vms = 1

Toutes les autres méthodes d'instance retourneront false.

fish_shell

my $shell = Shell::Guess->fish_shell;

Retourne une instance de Shell::Guess pour le shell fish.

La méthode d'instance suivante

Mantén toda la estructura del archivo.
