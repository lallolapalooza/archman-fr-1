Shell::Command(3) Documentation Perl fournie par l'utilisateur Shell::Command(3)

NOM

Shell::Command - Fonctions multiplateformes émulant des commandes shell courantes

SYNTAXE

use Shell::Command;
mv $ancien_fichier, $nouveau_fichier;
cp $ancien_fichier, $nouveau_fichier;
touch @fichiers;

DESCRIPTION

Wrapper léger autour de "ExtUtils::Command". Voir ExtUtils::Command pour une description des commandes disponibles.
