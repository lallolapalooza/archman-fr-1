NOM

Shell — Classe de widget Shell

SYNOPSIS

#include <Xm/Xm.h>
#include <X11/Shell.h>

DESCRIPTION

Shell est un widget de niveau supérieur (avec un seul enfant géré) qui encapsule l'interaction avec le gestionnaire de fenêtres.

Au moment où l'enfant du shell est géré, la largeur de l'enfant est utilisée pour les deux widgets si le shell n'est pas réalisé et si aucune largeur n'a été spécifiée pour le shell. Sinon, la largeur du shell est utilisée pour les deux widgets. Les mêmes relations s'appliquent à la hauteur du shell et de son enfant.

Classes

Shell hérite du comportement et des ressources de Composite et Core.

Le pointeur de classe est shellWidgetClass.

Le nom de la classe est Shell.

Nouvelles ressources

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources des classes héritées pour définir les attributs de ce widget. Pour référencer une ressource par son nom ou sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les tirets bas entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie à l'aide de XtSetValues (S), récupérée à l'aide de XtGetValues (G), ou si elle n'est pas applicable (N/A).

XmNallowShellResize
Spécifie que si cette ressource est False, l'instance de widget Shell renvoie XtGeometryNo à toutes les requêtes de géométrie de ses enfants. Toutes les fonctions de création de boîte de dialogue pratiques de Motif remplacent cette valeur par défaut et définissent XmNallowShellResize à True.
XmNcreatePopupChildProc
Spécifie le pointeur vers une fonction qui est appelée lorsque l'instance de widget Shell est affichée par XtPopup. La fonction crée le widget enfant lorsque le shell est affiché au lieu de lorsque l'application démarre. Cela peut être utilisé si l'enfant doit être reconfiguré chaque fois que le shell est affiché. La fonction prend un argument, le shell popup, et ne renvoie aucun résultat. Elle est appelée après les callbacks popup spécifiés par XmNpopupCallback.
XmNgeometry
Spécifie la géométrie souhaitée pour l'instance de widget. Cette ressource n'est examinée que lorsque l'instance de widget n'est pas réalisée et que le nombre de ses enfants gérés est modifié. Elle est utilisée pour modifier les valeurs des ressources XmNx, XmNy, XmNwidth et XmNheight. Lorsque XtGetValues est appelée sur cette ressource, la valeur renvoyée est un pointeur vers la valeur de ressource réelle et ne doit pas être libérée. De plus, cette ressource n'est pas copiée à la création ni par XtSetValues. L'application doit s'assurer que la chaîne reste valide jusqu'à ce que le shell soit réalisé.
XmNoverrideRedirect
Si True, spécifie que l'instance de widget est une fenêtre temporaire qui doit être ignorée par le gestionnaire de fenêtres. Les applications et les utilisateurs ne doivent normalement pas modifier cette ressource.
XmNpopdownCallback
Spécifie une liste de callbacks qui est appelée lorsque l'instance de widget est masquée par XtPopdown.
XmNpopupCallback
Spécifie une liste de callbacks qui est appelée lorsque l'instance de widget est affichée par XtPopup. Le deuxième argument de XtPopup doit être XtGrabNone.
