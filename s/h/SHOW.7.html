SHOW(7) Documentation PostgreSQL 18.1 SHOW(7)

NOM

SHOW - afficher la valeur d'un paramètre d'exécution

SYNTAXE

SHOW nom
SHOW ALL

DESCRIPTION

SHOW affiche le réglage courant des paramètres d'exécution. Ces variables peuvent être définies à l'aide de l'instruction SET, en modifiant le fichier de configuration postgresql.conf, via la variable d'environnement PGOPTIONS (lors de l'utilisation de libpq ou d'une application basée sur libpq), ou via les options de ligne de commande lors du démarrage du serveur postgres. Voir le Chapitre 19 pour plus de détails.

PARAMETRES

nom

Le nom d'un paramètre d'exécution. Les paramètres disponibles sont documentés dans le Chapitre 19 et sur la page de référence de SET(7). De plus, il existe quelques paramètres qui peuvent être affichés mais pas définis :

SERVER_VERSION

Affiche le numéro de version du serveur.

SERVER_ENCODING

Affiche l'encodage du jeu de caractères côté serveur. À l'heure actuelle, ce paramètre peut être affiché mais pas défini, car l'encodage est déterminé au moment de la création de la base de données.

IS_SUPERUSER

Vrai si le rôle actuel possède les privilèges de superutilisateur.

ALL

Affiche les valeurs de tous les paramètres de configuration, avec leurs descriptions.

NOTES

La fonction current_setting produit une sortie équivalente ; voir la Section 9.28.1. De plus, la vue système pg_settings produit les mêmes informations.

EXEMPLES

Afficher le réglage courant du paramètre DateStyle :

SHOW DateStyle;
 DateStyle
-----------
 ISO, MDY
(1 row)

Afficher le réglage courant du paramètre geqo :

SHOW geqo;
 geqo
------
 on
(1 row)

Afficher tous les réglages :

SHOW ALL;
            name         | setting |                description
-------------------------+---------+-------------------------------------------------
 allow_system_table_mods | off     | Permet les modifications de la structure de ...
    .
    .
    .
 xmloption               | content | Définit si les données XML dans l'analyse implicite ...
 zero_damaged_pages      | off     | Continue le traitement après les en-têtes de page endommagés.
(196 rows)

COMPATIBILITE

La commande SHOW est une extension PostgreSQL.
