void ScXMLEvaluator::clearTemporaryVariables (void ) [virtual]

Ne fait rien - redéfini dans les classes dérivées.

L'intention de cette fonction est de nettoyer les variables temporaires qui n'ont de portée que pour un seul événement traité par la machine à états scxml.
