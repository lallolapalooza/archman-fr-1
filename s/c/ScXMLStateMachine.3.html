int ScXMLStateMachine::getNumActiveStates (void ) const [virtual]

Cette méthode retourne l'événement courant pendant le traitement d'un événement, et NULL lorsqu'aucun événement n'est traité.

Le traitement des événements est, dans des cas spéciaux, effectué avec NULL comme événement courant, par exemple lors de l'initialisation de la machine d'état.

Retourne le nombre d'états actifs dans la machine d'état. Ce nombre devrait actuellement être de 1, mais à l'avenir, lorsque <parallel> sera implémenté, il pourra être supérieur.
