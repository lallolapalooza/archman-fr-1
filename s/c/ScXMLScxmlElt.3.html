Description détaillée

implémente l'élément SCXML <scxml>.

Un objet de ce type représente l'élément racine <scxml> d'un document. Il possède les attributs suivants :

  • initial
  • name
  • xmlns
  • version [REQUIS] doit contenir "1.0"
  • profile
  • exmode - "lax" ou "strict"

L'élément <scxml> peut avoir des éléments enfants des types suivants :

  • initial - zéro ou un élément de ce type, selon que l'attribut "initial" est défini ou non (l'un des deux doit être défini, et un seul), mais uniquement lorsque l'élément <scxml> est l'élément racine et non une référence externe d'un autre document.
  • state - zéro ou plusieurs éléments
  • parallel - zéro ou plusieurs éléments
  • final - zéro ou plusieurs éléments
  • datamodel - zéro ou un si le module data model est activé

Detailed Description

SCXML representation of the <scxml> element.

The <scxml> element is the root element of a SCXML document. It may contain any number of <state>, <final>, <transition>, <script>, <data>, <raise>, <log>, <send>, <if>, <elseif>, <else>, <datamodel> and <parallel> elements.

The ScXMLScxmlElt class represents the root element of a SCXML document.
