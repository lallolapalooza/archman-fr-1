Description détaillée

l'élément SCXML <data>.

L'élément SCXML <data> sert à stocker des variables. Il doit être contenu dans un élément <datamodel>. Les éléments <data> ne sont fonctionnels que dans les machines d'états dont le profil a une implémentation du Module de Données. Le profil "minimum" ne l'a pas, mais le profil "x-coin" le fait.

Les attributs suivants sont acceptés :

  • ID
  • src - non supporté
  • expr

L'attribut ID est requis et spécifie le nom de la variable. Le nom de la variable doit être unique pour toute la spécification de la machine d'états SCXML.

L'attribut src n'est pas supporté.

L'attribut expr spécifie la valeur de la variable. L'attribut est évalué en fonction du profil utilisé par la machine d'états.

La valeur de la variable <data> peut être modifiée à travers l'utilisation des éléments <assign>, et leurs valeurs peuvent être transmises à d'autres systèmes à travers l'utilisation de l'élément <send> dans le Module de Communication Externe.

Coin 4.0

SbBool ScXMLDataElt::handleXMLAttributes (void ) [virtual]

Cette méthode est appelée lorsque le lecteur XML a défini tous les attributs XML sur l'objet, et que l'objet doit les gérer et indiquer si les valeurs étaient correctes ou si une erreur de lecture doit être générée.

Retourne

TRUE si les attributs sont corrects, et FALSE en cas d'erreur.

L'implémentation de la classe de base ne fait rien et retourne simplement TRUE.
