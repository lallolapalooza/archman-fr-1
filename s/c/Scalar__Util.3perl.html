Scalar::Util(3perl) Manuel de référence du développeur Perl Scalar::Util(3perl)

NOM

Scalar::Util - Une sélection d'utilitaires généraux pour les scalaires

SYNTAXE

use Scalar::Util qw(blessed dualvar isdual readonly refaddr reftype
                    tainted weaken isweak isvstring looks_like_number
                    set_prototype);
                    # et d'autres utilitaires utiles listés ci-dessous

DESCRIPTION

« Scalar::Util » contient une sélection de sous-routines qu'il serait utile d'avoir dans le cœur de Perl, mais dont l'usage ne serait pas suffisant pour justifier l'inclusion d'un mot-clé, et dont la taille serait si faible que les rendre des extensions individuelles serait inefficace.

Par défaut, « Scalar::Util » n'exporte aucune sous-routine.

Fonctions « builtin » du cœur de Perl

Bon nombre des fonctions de ce module ont servi d'inspiration pour de nouvelles fonctionnalités expérimentales dans les versions récentes de Perl. Depuis diverses versions de développement, à commencer par la 5.35.7, des fonctions équivalentes à nombre de ces utilitaires sont disponibles dans le package « builtin:: ».

use Scalar::Util qw(blessed);
$class = blessed $obj;
$class = builtin::blessed $obj;  # équivalent

Pour plus d'informations, consultez la documentation sur builtin.

FONCTIONS POUR LES RÉFÉRENCES

Les fonctions suivantes effectuent une activité utile sur les valeurs de référence.

blessed

my $pkg = blessed( $ref );

Si $ref est une référence bénéficiée, le nom du paquet auquel elle est bénéficiée est retourné. Sinon, « undef » est retourné.

$scalar = «foo»;
$class  = blessed $scalar;           # undef
$ref    = [];
$class  = blessed $ref;              # undef
$obj    = bless [], «Foo»;
$class  = blessed $obj;              # «Foo»

Faites attention lorsque vous utilisez cette fonction uniquement comme test de vérité (comme dans « if(blessed $ref)... »), car le nom de paquet « 0 » est défini mais faux.

« Depuis la version Perl 5.35.7 » une fonction équivalente est disponible sous le nom « builtin::blessed ».

refaddr

my $addr = refaddr( $ref );

Si $ref est une référence, l'adresse mémoire interne de la valeur référencée est retournée sous forme d'entier simple. Sinon, « undef » est retourné.

$addr = refaddr «string»;           # undef
$addr = refaddr \$var;              # exemple 12345678
$addr = refaddr [];                 # exemple 23456784
$obj  = bless {}, «Foo»;
$addr = refaddr $obj;               # exemple 88123488

« Depuis la version Perl 5.35.7 » une fonction équivalente est disponible sous le nom « builtin::refaddr ».

reftype

my $type = reftype( $ref );

Si $ref est une référence, le type de base de la variable référencée est retourné sous forme de chaîne (par exemple, « ARRAY » ou « HASH »). Sinon, « undef » est retourné.

$type = reftype «string»;           # undef
$type = reftype \$var;              # SCALAR
$type = reftype [];                 # ARRAY
$obj  = bless {}, «Foo»;
$type = reftype $obj;               # HASH

Remarque : Pour des raisons internes, toutes les expressions régulières précompilées (« qr/.../ ») sont des références bénéficiées ; par conséquent, « ref() » retourne le nom du paquet « Regexp » dans ces cas, mais « reftype() » retourne le type de structure C de « REGEXP » en majuscules.

« Depuis la version Perl 5.35.7 » une fonction équivalente est disponible sous le nom « builtin::reftype ».

weaken

weaken( $ref );

La valeur lvaleur $ref est transformée en une référence faible. Cela signifie qu'elle ne maintiendra pas de compteur de références sur l'objet qu'elle référence. De plus, lorsque le compteur de références de l'objet atteindra zéro, la référence sera définie à « undef ».

Cette fonction modifie la valeur lvaleur passée comme argument et ne retourne aucune valeur. Elle est utile pour conserver des copies de références, mais sans vouloir empêcher la destruction normale de l'objet.

{
  my $var;
  $ref = \$var;
  weaken($ref);                     # Rendre $ref une référence faible
}
# $ref est maintenant undef

Remarque : Si vous copiez un scalaire contenant une référence faible, la copie sera une référence forte.

my $var;
my $foo = \$var;
weaken($foo);                       # Rendre $foo une référence faible
my $bar = $foo;                     # $bar est maintenant une référence forte

Ceci peut être moins évident dans d'autres contextes, comme dans « grep() », par exemple, lors du filtrage de références faibles vers des objets qui pourraient déjà avoir été détruits :

@object = grep { defined } @object;

Ceci retirera effectivement toutes les références vers des objets détruits, mais les références restantes vers des objets resteront fortes, provoquant le fait que les objets restants ne seront jamais détruits car une référence forte existera toujours dans la liste @object.

« Depuis la version Perl 5.35.7 » une fonction équivalente est disponible sous le nom « builtin::weaken ».

unweaken

unweaken( $ref );

« Depuis la version 1.36. »

La valeur lvaleur « REF » est transformée d'une référence faible en une référence normale (forte). Cette fonction modifie la valeur lvaleur passée comme argument et ne retourne aucune valeur. Elle annule l'action effectuée par « weaken ».

Cette fonction est un peu plus propre et plus pratique que le code alternatif équivalent :

my $tmp = $REF;
undef $REF;
$REF = $tmp;

(car en particulier, affecter une référence faible à elle-même ne suffit pas pour la dés-affaiblir ; « $REF = $REF » ne fonctionne pas).

« Depuis la version Perl 5.35.7 » une fonction équivalente est disponible sous le nom « builtin::unweaken ».

isweak

my $weak = isweak( $ref );

Retourne vrai si $ref est une référence faible.

$ref  = \$foo;
$weak = isweak($ref);               # faux
weaken($ref);
$weak = isweak($ref);               # vrai

NOTE : La copie d'une référence faible crée une référence normale et forte.

$copy = $ref;
$weak = isweak($copy);              # faux

« Depuis la version Perl 5.35.7 » une fonction équivalente est disponible sous le nom « builtin::is_weak ».

AUTRES FONCTIONS

dualvar

my $var = dualvar( $num, $string );

Retourne un scalaire ayant la valeur $num dans un contexte numérique et la valeur $string dans un contexte de chaîne.

$foo = dualvar 10, «Hello»;
$num = $foo + 2;                    # 12
$str = $foo . « world»;             # Hello world

isdual

my $dual = isdual( $var );

« Depuis la version 1.26. »

Si $var est un scalaire qui possède à la fois une valeur numérique et une valeur de chaîne, le résultat est vrai.

$foo = dualvar 86, «Nix»;
$dual = isdual($foo);               # vrai

Remarque : Un scalaire peut être amené à avoir à la fois une valeur de chaîne et une valeur numérique grâce à des opérations standard :

$foo = «10»;
$dual = isdual($foo

La variable $! est couramment à double valeur, bien qu'elle soit également magique d'autres manières :

$! = 1;
$dual = isdual($!);                 # vrai
print("$!\n");                      # "Operation not permitted"

ATTENTION : Cette fonction n'est pas aussi utile qu'il y paraît. Les valeurs doubles ne sont pas un concept distinct en Perl, mais une construction interne standard de toutes les valeurs scalaires. Presque toute valeur pourrait être considérée comme une valeur double par cette fonction au cours d'opérations normales.

isvstring

my $vstring = isvstring( $var );

Si $var est un scalaire codé comme une chaîne v, le résultat est vrai.

$vs   = v49.46.48;
$fmt  = isvstring($vs) ? "%vd" : "%s"; # vrai
printf($fmt,$vs);

looks_like_number

my $isnum = looks_like_number( $var );

Renvoie vrai si Perl considère que $var est un nombre. Voir "looks_like_number" dans perlapi.

openhandle

my $fh = openhandle( $fh );

Renvoie $fh lui-même si $fh peut être utilisé comme descripteur de fichier et est ouvert, ou s'il s'agit d'un descripteur lié. Sinon, "undef" est renvoyé.

$fh = openhandle(*STDIN);           # \*STDIN
$fh = openhandle(\*STDIN);          # \*STDIN
$fh = openhandle(*NOTOPEN);         # undef
$fh = openhandle("scalar");         # undef

readonly

my $ro = readonly( $var );

Renvoie vrai si $var est en lecture seule.

sub foo { readonly($_[0]) }
$readonly = foo($bar);              # faux
$readonly = foo(0);                 # vrai

set_prototype

my $code = set_prototype( $code, $prototype );

Définit le prototype de la fonction donnée par la référence $code, ou le supprime si $prototype est "undef". Renvoie la référence $code elle-même.

set_prototype \&foo, '$$';

tainted

my $t = tainted( $var );

Renvoie vrai si $var est entaché.

$taint = tainted("constant");       # faux
$taint = tainted($ENV{PWD});        # vrai si exécuté avec -T

DIAGNOSTICS

L'utilisation du module peut générer l'une des erreurs suivantes lors de l'importation.

Les chaînes V ne sont pas implémentées dans cette version de Perl
La version de Perl que vous utilisez n'implémente pas les chaînes V. Pour utiliser "isvstring", vous devrez utiliser une version plus récente de Perl.

BUGS CONNUS
