SbBool ScXMLAnchorElt::handleXMLAttributes (void ) [virtual]

Cette méthode est appelée lorsque le lecteur de fichier a défini tous les attributs XML sur l'objet, et souhaite que l'objet les gère et rapporte si les valeurs étaient correctes ou si une erreur de lecture doit être produite.

Retourne

TRUE si les attributs sont corrects, et FALSE en cas d'erreur.

Cette implémentation de classe de base ne fait rien et retourne simplement TRUE.
