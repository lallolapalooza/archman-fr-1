DESCRIPTION_DETAILLEE

Définit l'attribut XML 'src' pour l'élément SCXML <state>.

Retourne l'attribut XML 'src' pour cet élément SCXML <state>.

Définit l'attribut XML 'initial' pour l'élément SCXML <state>. Si cette valeur est définie, l'état ne doit pas contenir d'élément <initial>, et vice versa.

Lorsqu'elle est définie, cette valeur doit être la valeur d'un identifiant descendant d'un état enfant.

Retourne l'attribut XML 'initial' pour l'élément SCXML <state>.

Cette méthode est appelée lorsque le lecteur de fichier a défini tous les attributs XML sur l'objet, et souhaite que l'objet les gère et signale si les valeurs étaient correctes ou si une erreur de lecture doit être produite.

Cette implémentation de classe de base ne fait rien et retourne simplement TRUE.

Réimplémenté depuis ScXMLAbstractStateElt.

Cette fonction doit être réimplémentée pour parcourir les éléments enfants.
