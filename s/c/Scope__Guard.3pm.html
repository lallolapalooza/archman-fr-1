NOM

Scope::Guard - gestion des ressources dans la portée lexicale

SYNTAXE

my $guard = guard { ... };
  # ou
my $guard = scope_guard \&handler;
  # ou
my $guard = Scope::Guard->new(sub { ... });
$guard->dismiss(); # désactiver le gestionnaire

DESCRIPTION

Ce module fournit un moyen pratique d'effectuer le nettoyage ou d'autres formes de gestion des ressources à la fin d'une portée. Il est particulièrement utile lorsqu'il s'agit d'exceptions : le constructeur "Scope::Guard" prend une référence à une sous-routine qui est garantie d'être appelée même si le fil d'exécution est interrompu prématurément. Cela permet effectivement de faire des "promesses" de portée lexicale qui sont automatiquement honorées par le ramasse-miettes de Perl.

Pour plus d'informations, voir : http://www.drdobbs.com/cpp/184403758

MÉTHODES

new

my $guard = Scope::Guard->new(sub { ... });
  # ou
my $guard = Scope::Guard->new(\&handler);

La méthode "new" crée un nouvel objet "Scope::Guard" qui appelle le gestionnaire fourni lorsque sa méthode "DESTROY" est appelée, généralement à la fin de la portée.

dismiss

$guard->dismiss();
  # ou
$guard->dismiss(1);

"dismiss" détache le gestionnaire de l'objet "Scope::Guard". Cela révoque la "promesse" d'appeler le gestionnaire lorsque l'objet est détruit.

Le gestionnaire peut être réactivé en appelant :

$guard->dismiss(0);

EXPORTATIONS

guard

"guard" prend un bloc et retourne un nouvel objet "Scope::Guard". Il peut être utilisé comme raccourci pour :

Scope::Guard->new(...)

par exemple :

my $guard = guard { ... };

Note : appeler "guard" de manière anonyme, c'est-à-dire dans un contexte vide, lèvera une exception. Ceci parce que les gardes anonymes sont détruits immédiatement (plutôt qu'à la fin de la portée), ce qui n'est probablement pas le comportement souhaité.

scope_guard

"scope_guard" est identique à "guard", mais il prend une référence de code plutôt qu'un bloc. par exemple :

my $guard = scope_guard \&handler;

ou :

my $guard = scope_guard sub { ... };

ou :

my $guard = scope_guard $handler;

Comme avec "guard", appeler "scope_guard" dans un contexte vide lèvera une exception.
