type in_channel

La notion de canal d'entrée pour le module Scanf : ces canaux fournissent toute la machinerie nécessaire pour lire à partir de toute source de caractères, y compris une valeur in_channel . Une valeur Scanf.Scanning.in_channel est également appelée un canal d'entrée formaté ou équivalemment un tampon de balayage. Le type Scanf.Scanning.scanbuf ci-dessous est un alias pour Scanning.in_channel . Notez qu'un Scanning.in_channel n'est pas thread-safe : une utilisation concurrente peut produire des valeurs arbitraires ou des exceptions.

Depuis 3.12

type scanbuf = in_channel

Le type des tampons de balayage. Un tampon de balayage est la source à partir de laquelle une fonction d'entrée formatée obtient les caractères. Le tampon de balayage contient l'état actuel du balayage, plus une fonction pour obtenir le prochain caractère de l'entrée, et un tampon de jeton pour stocker la chaîne correspondante jusqu'à présent.

Note : une action de balayage peut souvent nécessiter d'examiner un caractère à l'avance ; lorsque ce caractère d'anticipation n'appartient pas au jeton lu, il est stocké dans le tampon de balayage et devient le prochain caractère à lire.

val stdin : in_channel

La notion d'entrée standard pour le module Scanf. Scanning.stdin est le canal d'entrée formaté Scanf.Scanning.in_channel attaché à stdin.

Note : dans le système interactif, lorsque l'entrée est lue depuis stdin , le caractère de nouvelle ligne qui déclenche l'évaluation fait partie de l'entrée ; par conséquent, les spécifications de balayage doivent correctement ignorer ce caractère de nouvelle ligne supplémentaire (par exemple, ajoutez simplement un '\n' comme dernier caractère de la chaîne de format).

val open_in : file_name -> in_channel

Scanning.open_in fname renvoie un canal d'entrée formaté Scanf.Scanning.in_channel pour la lecture bufferisée en mode texte du fichier fname.

Note : open_in renvoie un canal d'entrée formaté qui lit efficacement les caractères par gros blocs ; en revanche, from_channel ci-dessous renvoie des canaux d'entrée formatés qui doivent lire un caractère à la fois, entraînant un taux de balayage beaucoup plus lent.

val from_string : string -> in_channel

Scanning.from_string s renvoie un canal d'entrée formaté Scanf.Scanning.in_channel qui lit depuis la chaîne donnée. La lecture commence au premier caractère de la chaîne. La condition de fin d'entrée est définie lorsque la fin de la chaîne est atteinte.

val from_function : (unit -> char) -> in_channel

Scanning.from_function f renvoie un canal d'entrée formaté Scanf.Scanning.in_channel avec la fonction donnée comme méthode de lecture.

Lorsque le balayage a besoin d'un caractère supplémentaire, la fonction donnée est appelée.

Lorsque la fonction n'a plus de caractère à fournir, elle doit signaler une condition de fin d'entrée en levant l'exception End_of_file.

val from_channel : in_channel -> in_channel

Scanning.from_channel ic renvoie un canal d'entrée formaté Scanf.Scanning.in_channel qui lit à partir du canal d'entrée régulier in_channel ic fourni. La lecture commence à la position de lecture actuelle de ic.

val end_of_input : in_channel -> bool

Scanning.end_of_input ic teste la condition de fin d'entrée du canal d'entrée formaté Scanf.Scanning.in_channel donné.

val beginning_of_input : in_channel -> bool

Scanning.beginning_of_input ic teste la condition de début d'entrée du canal d'entrée formaté Scanf.Scanning.in_channel donné.

val name_of_input : in_channel -> string

Scanning.name_of_input ic renvoie le nom de la source de caractères du canal d'entrée formaté Scanf.Scanning.in_channel donné.
