ARGUMENTS

display
Spécifie la connexion au serveur X.
screen_number
Spécifie le numéro d'écran approprié sur le serveur hôte.
count_return
Retourne le nombre de profondeurs.

DESCRIPTION

La macro AllPlanes renvoie une valeur avec tous les bits à 1, appropriée pour être utilisée comme argument d'une procédure.

La macro BlackPixel renvoie la valeur du pixel noir pour l'écran spécifié.

La macro WhitePixel renvoie la valeur du pixel blanc pour l'écran spécifié.

La macro ConnectionNumber renvoie le numéro de connexion pour l'écran spécifié.

La macro DefaultColormap renvoie l'ID de la palette de couleurs par défaut pour l'écran spécifié.

La macro DefaultDepth renvoie la profondeur (nombre de plans) de la fenêtre racine par défaut pour l'écran spécifié.

La fonction XListDepths renvoie le tableau des profondeurs disponibles sur l'écran spécifié. Si le numéro d'écran spécifié est valide et qu'il y a suffisamment de mémoire pour le tableau, XListDepths définit count_return au nombre de profondeurs disponibles. Sinon, elle ne définit pas count_return et renvoie NULL. Pour libérer la mémoire du tableau des profondeurs, utilisez XFree.

La macro DefaultGC renvoie le GC par défaut pour la fenêtre racine de l'écran spécifié.

La macro DefaultRootWindow renvoie la fenêtre racine de l'écran par défaut.

La macro DefaultScreenOfDisplay renvoie l'écran de l'affichage spécifié.

La macro DefaultScreen renvoie le numéro d'écran par défaut référencé dans la routine XOpenDisplay.

La macro DefaultVisual renvoie le type visuel par défaut pour l'écran spécifié.

La macro DisplayCells renvoie le nombre d'entrées dans la palette de couleurs par défaut.

La macro DisplayPlanes renvoie la profondeur de la fenêtre racine de l'écran spécifié.

La macro DisplayString renvoie la chaîne qui a été passée à XOpenDisplay lors de l'ouverture de l'affichage actuel.

La fonction XMaxRequestSize renvoie la taille de requête maximale (en unités de 4 octets) supportée par le serveur sans utiliser d'encodage de protocole étendu. Les requêtes individuelles au serveur peuvent être plus grandes que cette taille, à moins que le serveur ne supporte un encodage de protocole étendu. Le protocole garantit une taille d'au moins 4096 unités (16384 octets). Xlib divise automatiquement les données en plusieurs requêtes de protocole lorsque nécessaire pour les fonctions suivantes : XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles, et XPutImage.

La fonction XExtendedMaxRequestSize renvoie 0 si l'affichage spécifié ne supporte pas d'encodage de protocole étendu ; sinon, elle renvoie la taille de requête maximale (en unités de 4 octets) supportée par le serveur en utilisant l'encodage de protocole étendu. Les fonctions Xlib XDrawLines, XDrawArcs, XFillPolygon, XChangeProperty, XSetClipRectangles, et XSetRegion utiliseront l'encodage de protocole étendu si le serveur le supporte. L'utilisation de l'encodage de protocole étendu dans d'autres fonctions Xlib (par exemple, XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles, XPutImage) est permise mais non obligatoire ; une implémentation Xlib peut choisir de diviser les données en plusieurs requêtes plus petites.

La macro LastKnownRequestProcessed extrait le numéro de série complet qui a été traité par le serveur Xlib pour la dernière requête connue.

La macro NextRequest extrait le numéro de série complet qui sera utilisé pour la prochaine requête.

La macro ProtocolVersion renvoie le numéro de version majeure (11) du protocole X associé à l'affichage connecté.

La macro ProtocolRevision renvoie le numéro de révision mineure de la version du serveur X.

La macro QLength renvoie la longueur de la file d'attente des événements pour l'affichage connecté.

La macro RootWindow renvoie la fenêtre racine.

La macro ScreenCount renvoie le nombre d'écrans disponibles.

La macro ScreenOfDisplay renvoie un pointeur vers l'écran de l'affichage spécifié.

La macro ServerVendor renvoie un pointeur vers une chaîne terminée par un caractère nul qui fournit des identifiants du propriétaire de l'implémentation du serveur X.

La macro VendorRelease renvoie un numéro lié à la version de diffusion du serveur X.

ScreenCount - Compte le nombre d’écrans.

SYNTAX

int ScreenCount();

ARGUMENTS

DESCRIPTION

La fonction ScreenCount renvoie le nombre d’écrans actuellement connectés au système.
