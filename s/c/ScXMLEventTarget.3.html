Description Détaillée

classe de base pour les cibles d'événements pour la communication événementielle inter-systèmes

Cette classe gère la communication inter-systèmes entre les systèmes SCXML et les systèmes destinés à communiquer avec de tels systèmes. Elle gère également la file d'attente des événements externes pour de tels systèmes (les systèmes peuvent également avoir des files d'attente d'événements internes).

Depuis

Coin 3.1

virtual const ScXMLEvent * ScXMLEventTarget::getCurrentEvent (void ) const [inline], [virtual]

Cette méthode retourne l'événement actuel pendant le traitement des événements, et NULL lorsqu'aucun événement n'est en cours de traitement.

Le traitement des événements est effectué dans des cas spéciaux avec NULL comme événement actuel, comme par exemple lors de l'initialisation de la machine d'états.

void ScXMLEventTarget::queueEvent (const ScXMLEvent * event) [virtual]

Met en file d'attente un événement ScXMLEvent. L'événement est copié, et peut être supprimé dès que la fonction retourne.

void ScXMLEventTarget::queueEvent (const SbName & eventid) [virtual]

Met en file d'attente un événement ScXMLEvent ayant l'identifiant eventid donné comme nom d'événement.

void ScXMLEventTarget::setCurrentEvent (const ScXMLEvent * event) [protected], [virtual]

Définit un pointeur pour l'événement qui est 'actuel' pendant le traitement des événements. Ceci est une méthode interne, et la mise à jour de l'événement actuel doit être gérée automatiquement.

SbBool ScXMLEventTarget::processOneEvent (const ScXMLEvent * event) [protected], [virtual]

Cette fonction traite un événement. L'implémentation de la classe de base ne fait rien.

Réimplémenté dans ScXMLStateMachine, SoScXMLDollyTarget, SoScXMLFlightControlTarget, SoScXMLMiscTarget, SoScXMLMotionTarget, SoScXMLPanTarget, SoScXMLRotateTarget, SoScXMLSeekTarget, SoScXMLSpinTarget et SoScXMLZoomTarget.
