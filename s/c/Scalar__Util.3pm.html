Scalar::Util(3) Documentation Perl contributeur Scalar::Util(3)

NOM

Scalar::Util - Une sélection de sous-programmes scalaires génériques

SYNTAXE

use Scalar::Util qw(blessed dualvar isdual readonly refaddr reftype
                    tainted weaken isweak isvstring looks_like_number
                    set_prototype);
                    # et autres utilitaires utiles qui apparaissent ci-dessous

DESCRIPTION

"Scalar::Util" contient une sélection de sous-programmes que les gens ont exprimé qu'il serait utile d'avoir dans le noyau de Perl, mais dont l'utilisation ne serait pas suffisamment élevée pour justifier de lui attribuer un mot-clé, et dont la taille serait si petite qu'il serait inefficace d'en faire une extension individuelle.

Par défaut, "Scalar::Util" n'exporte aucune sous-routine.

Fonctions « natives » du cœur de Perl

Beaucoup des fonctions de ce module ont servi d'inspiration pour une nouvelle fonction expérimentale dans les versions récentes de Perl. Depuis plusieurs versions de développement, à commencer par la 5.35.7, des fonctions équivalentes à plusieurs de ces utilitaires sont disponibles dans le module "builtin::".

use Scalar::Util qw(blessed);
$class = blessed $obj;
$class = builtin::blessed $obj;  # équivalent

Pour plus d'informations, voir la documentation sur "builtin".

FONCTIONS POUR LES RÉFÉRENCES

Les fonctions suivantes effectuent une activité utile avec des valeurs de référence.

blessed

my $pkg = blessed( $ref );

Si $ref est une référence « blessée » (associée à une classe), le nom de la classe à laquelle elle est associée est retourné. Sinon, "undef" est retourné.

$scalar = "foo";
$class  = blessed $scalar;           # undef
$ref    = [];
$class  = blessed $ref;              # undef
$obj    = bless [], "Foo";
$class  = blessed $obj;              # "Foo"

Soyez prudent en utilisant cette fonction simplement comme un test booléen (comme dans "if(blessed $ref)...") car le nom de classe "0" est défini mais est faux.

Depuis la version 5.35.7 de Perl, une fonction équivalente est disponible en tant que "builtin::blessed".

refaddr

my $addr = refaddr( $ref );

Si $ref est une référence, l'adresse mémoire interne de la valeur référencée est retournée sous forme d'entier simple. Sinon, "undef" est retourné.

$addr = refaddr "string";           # undef
$addr = refaddr \$var;              # exemple 12345678
$addr = refaddr [];                 # exemple 23456784
$obj  = bless {}, "Foo";
$addr = refaddr $obj;               # exemple 88123488

Depuis la version 5.35.7 de Perl, une fonction équivalente est disponible en tant que "builtin::refaddr".

reftype

my $type = reftype( $ref );

Si $ref est une référence, le type de variable de base en Perl est retourné sous forme de chaîne (comme "ARRAY" ou "HASH"). Sinon, "undef" est retourné.

$type = reftype "string";           # undef
$type = reftype \$var;              # SCALAR
$type = reftype [];                 # ARRAY
$obj  = bless {}, "Foo";
$type = reftype $obj;               # HASH

Note : Pour des raisons internes, toutes les expressions régulières précompilées ("qr/.../") sont des références « blessées » ; par conséquent, ref() retourne le nom de classe "Regexp" mais reftype() retourne le type de structure C de "REGEXP" en majuscules.

Depuis la version 5.35.7 de Perl, une fonction équivalente est disponible en tant que "builtin::reftype".

weaken

weaken( $ref );

La référence lvaleur $ref est transformée en une référence faible. Cela signifie qu'elle ne maintiendra pas un comptage de références sur l'objet qu'elle référence. De plus, lorsque le comptage de références de l'objet atteindra zéro, la référence sera définie sur undef. Cette fonction modifie la référence lvaleur passée en paramètre et ne retourne aucune valeur.

Ceci est utile pour conserver des copies de références, mais sans vouloir empêcher l'objet d'être détruit au moment habituel.

{
  my $var;
  $ref = \$var;
  weaken($ref);                     # Rendre $ref une référence faible
}
# $ref est maintenant undef

Note : Si vous copiez une référence faible, la copie deviendra une référence normale.

my $var;
my $foo = \$var;
weaken($foo);                       # Rendre $foo une référence faible
my $bar = $foo;                     # $bar est maintenant une référence normale

Cela peut être moins évident dans d'autres situations, comme avec grep(), par exemple, lorsque l'on filtre une liste de références faibles vers des objets qui auraient déjà pu être détruits :

@object = grep { defined } @object;

Cela supprime en fait toutes les références vers des objets détruits, mais les références restantes vers des objets resteront des références normales, empêchant ainsi les objets restants de jamais être détruits car il y aura toujours une référence normale dans le tableau @object.

Depuis la version 5.35.7 de Perl, une fonction équivalente est disponible en tant que "builtin::weaken".

unweaken

unweaken( $ref );

Depuis la version 1.36.

La référence lvaleur "REF" est transformée d'une référence faible en une référence normale (c'est-à-dire qu'elle n'est plus une référence faible). Cette fonction modifie la référence lvaleur passée en paramètre et ne retourne aucune valeur. Elle annule l'effet de l'action effectuée par « weaken ».

Cette fonction est légèrement plus propre et plus pratique que le code équivalent qui serait utilisé autrement :

my $tmp = $REF;
undef $REF;
$REF = $tmp;

(par exemple, assigner simplement une référence faible à elle-même ne fonctionne pas pour l'annuler ; "$REF = $REF" ne fonctionne pas).

Depuis la version 5.35.7 de Perl, une fonction équivalente est disponible en tant que "builtin::unweaken".

isweak

my $weak = isweak( $ref );

Retourne vrai si $ref est une référence faible.

$ref  = \$foo;
$weak = isweak($ref);               # faux
weaken($ref);
$weak = isweak($ref);               # vrai

NOTE : La copie d'une référence faible crée une référence normale et forte.

$copy = $ref;
$weak = isweak($copy);              # faux

Depuis la version 5.35.7 de Perl, une fonction équivalente est disponible en tant que "builtin::is_weak".

AUTRES FONCTIONS

dualvar

my $var = dualvar( $num, $string );

Retourne un scalaire qui a la valeur $num dans un contexte numérique et la valeur $string dans un contexte de chaîne.

$foo = dualvar 10, "Hello";
$num = $foo + 2;                    # 12
$str = $foo . " world";             # Hello world

isdual

my $dual = isdual( $var );

Depuis la version 1.26.

Si $var est un scalaire qui possède à la fois des valeurs numériques et de chaîne, le résultat est vrai.

$foo = dualvar 86, "Nix";
$dual = isdual($foo);               # vrai

Note : Il est possible de créer un scalaire qui a à la fois un contenu de chaîne et numérique via des opérations standard :

$foo = "10";
$dual = isdual($foo);

# faux $bar = $foo + 0; $dual = isdual($foo); # vrai

Le $! est communément à double valeur, bien qu'il soit aussi magique à d'autres égards :

$! = 1;
$dual = isdual($!);                 # vrai
print("$!\n");                      # "Opération non autorisée"

ATTENTION : Cette fonction n'est pas aussi utile qu'elle le paraît. Les valeurs doubles ne sont pas un concept distinct en Perl, mais sont un constructeur standard de toutes les valeurs scalaires. Presque n'importe quelle valeur pourrait être considérée comme une valeur double pendant les opérations normales.

isvstring

my $vstring = isvstring( $var );

Si $var est un scalaire encodé comme une chaîne de caractères (vstring), le résultat est vrai.

$vs   = v49.46.48;
$fmt  = isvstring($vs) ? "%vd" : "%s"; # vrai
printf($fmt,$vs);

looks_like_number

my $isnum = looks_like_number( $var );

Retourne vrai si perl pense que $var est un nombre. Voir "looks_like_number" dans perlapi.

openhandle

my $fh = openhandle( $fh );

Retourne $fh si $fh peut être utilisé comme une poignée de fichier et est ouvert, ou s'il s'agit d'une poignée liée. Sinon, retourne "undef".

$fh = openhandle(*STDIN);           # \*STDIN
$fh = openhandle(\*STDIN);          # \*STDIN
$fh = openhandle(*NOTOPEN);         # undef
$fh = openhandle("scalar");         # undef

readonly

my $ro = readonly( $var );

Retourne vrai si $var est en lecture seule.

sub foo { readonly($_[0]) }
$readonly = foo($bar);              # faux
$readonly = foo(0);                 # vrai

set_prototype

my $code = set_prototype( $code, $prototype );

Définit le prototype de la fonction donnée par la référence $code, ou le supprime si $prototype est "undef". Retourne la référence $code elle-même.

set_prototype \&foo, '$$';

tainted

my $t = tainted( $var );

Retourne vrai si $var est marqué (tainted).

$taint = tainted("constant");       # faux
$taint = tainted($ENV{PWD});        # vrai si exécuté sous -T

DIAGNOSTICS

L'utilisation du module peut entraîner l'une des erreurs suivantes lors de l'importation.

Les chaînes de caractères (Vstrings) ne sont pas implémentées dans cette version de perl
La version de perl que vous utilisez n'implémente pas les chaînes de caractères (Vstrings). Pour utiliser "isvstring", vous aurez besoin d'une version plus récente de perl.

BUGS CONNUS

Il y a un bug dans perl5.6.0 avec les UV supérieurs ou égaux à 1<<31. Cela se manifestera par l'échec des tests 8 et 9 de dualvar.t.
