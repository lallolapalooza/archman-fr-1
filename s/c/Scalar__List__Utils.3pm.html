Scalar::List::Utils(3) Documentation Perl fournie par l'utilisateur Scalar::List::Utils(3)

NOM

Scalar::List::Utils - Une distribution de sous-programmes utilitaires généraux

SYNTAXE

use Scalar::Util qw(blessed);
use List::Util qw(any);

DESCRIPTION

"Scalar::List::Utils" ne fait rien en soi. Il est regroupé avec plusieurs modules utiles.

MODULES

List::Util

List::Util contient une sélection de sous-programmes utiles pour opérer sur des listes de valeurs.

Scalar::Util

Scalar::Util contient une sélection de sous-programmes utiles pour interroger ou manipuler des valeurs scalaires.

Sub::Util

Sub::Util contient une sélection de sous-programmes utiles pour interroger ou manipuler des références de sous-programmes.
