Paquet: openssl

Licences: Apache-2.0

SCT_VALIDATE(3ssl) OpenSSL SCT_VALIDATE(3ssl)

NOM

SCT_validate, SCT_LIST_validate, SCT_get_validation_status - vérifie la validité des Signed Certificate Timestamps (SCTs)

SYNOPSIS

#include <openssl/ct.h>
typedef enum {
    SCT_VALIDATION_STATUS_NOT_SET,
    SCT_VALIDATION_STATUS_UNKNOWN_LOG,
    SCT_VALIDATION_STATUS_VALID,
    SCT_VALIDATION_STATUS_INVALID,
    SCT_VALIDATION_STATUS_UNVERIFIED,
    SCT_VALIDATION_STATUS_UNKNOWN_VERSION
} sct_validation_status_t;
int SCT_validate(SCT *sct, const CT_POLICY_EVAL_CTX *ctx);
int SCT_LIST_validate(const STACK_OF(SCT) *scts, CT_POLICY_EVAL_CTX *ctx);
sct_validation_status_t SCT_get_validation_status(const SCT *sct);

DESCRIPTION

SCT_validate() vérifie qu'un SCT est valide et valide sa signature. SCT_LIST_validate() effectue les mêmes vérifications sur une pile entière de SCTs. Le résultat des vérifications de validation peut être obtenu en passant le SCT à SCT_get_validation_status().

Un CT_POLICY_EVAL_CTX doit être fourni, qui spécifie :

  • Le certificat pour lequel le SCT a été émis.

    L'absence de fourniture du certificat entraînera un statut de validation SCT_VALIDATION_STATUS_UNVERIFIED.

  • L'émetteur de ce certificat.

    Ceci n'est requis que si le SCT a été émis pour un pré-certificat (voir RFC 6962). Si cela est requis mais non fourni, le statut de validation sera SCT_VALIDATION_STATUS_UNVERIFIED.

  • Un CTLOG_STORE qui contient le journal CT ayant émis ce SCT.

    Si le SCT a été émis par un journal qui ne se trouve pas dans ce CTLOG_STORE, le statut de validation sera SCT_VALIDATION_STATUS_UNKNOWN_LOG.

Si le SCT est d'une version non prise en charge (seule la v1 est actuellement prise en charge), le statut de validation sera SCT_VALIDATION_STATUS_UNKNOWN_VERSION.

Si la signature du SCT est incorrecte, son horodatage est dans le futur (par rapport à l'heure dans CT_POLICY_EVAL_CTX), ou s'il est autrement invalide, le statut de validation sera SCT_VALIDATION_STATUS_INVALID.

Si toutes les vérifications réussissent, le statut de validation sera SCT_VALIDATION_STATUS_VALID.

NOTES

Une valeur de retour de 0 de SCT_LIST_validate() ne doit pas être interprétée comme un échec. Au minimum, un seul SCT valide peut fournir une confiance suffisante qu'un certificat a été enregistré publiquement.

VALEUR DE RETOUR

SCT_validate() renvoie un entier négatif en cas d'erreur interne, 0 si le SCT échoue à la validation, ou 1 si le SCT réussit la validation.

SCT_LIST_validate() renvoie un entier négatif en cas d'erreur interne, 0 si l'un des SCTs échoue à la validation, ou 1 s'ils réussissent tous la validation.

SCT_get_validation_status() renvoie le statut de validation du SCT. Si SCT_validate() ou SCT_LIST_validate() n'ont pas reçu ce SCT, la valeur renvoyée sera SCT_VALIDATION_STATUS_NOT_SET.
