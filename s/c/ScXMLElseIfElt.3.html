Description Détaillée

Implémente l'élément SCXML <elseif>.

L'élément <elseif> peut avoir l'attribut "cond" et aucun enfant. L'élément <elseif> est un élément de séparation pour l'élément contenu dans <if>. Il peut être utilisé uniquement à l'intérieur d'éléments <if>.

Depuis

Coin 3.1
