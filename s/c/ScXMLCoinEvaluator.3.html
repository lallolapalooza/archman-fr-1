Description détaillée

implémente l'évaluateur pour le profil personnalisé nommé "x-coin".

Le profil x-coin étend le profil minimum avec l'interprétation des données, les opérateurs logiques, les expressions arithmétiques et certaines fonctionnalités pratiques du modèle de données comme l'accès au graphe de scène et le stockage temporaire des variables.
