SbBool ScXMLIfElt::handleXMLAttributes (void ) [virtual]

Cette méthode est appelée lorsque le lecteur de fichier a défini tous les attributs XML sur l'objet, et demande à l'objet de les gérer et de rapporter si les valeurs étaient correctes ou si une erreur de lecture doit être générée.

Retourne

TRUE si les attributs sont corrects, et FALSE en cas d'erreur.

Cette implémentation de classe de base ne fait rien et retourne simplement TRUE.
