SbBool ScXMLParamElt::handleXMLAttributes (void ) [virtual]

Cette fonction est appelée lorsque le lecteur de fichier a défini tous les attributs XML sur l'objet, et souhaite que l'objet les gère et signale si les valeurs étaient correctes ou si une erreur de lecture doit être produite.

Retourne TRUE si les attributs sont corrects, et FALSE en cas d'erreur.

Cette implémentation de base retourne TRUE et ne fait rien.
