NOM

SCT_print, SCT_LIST_print, SCT_validation_status_string - Affiche les Timestamps de Certificat Signés (SCT) de manière lisible par l'homme

SYNTAXE

#include <openssl/ct.h>
void SCT_print(const SCT *sct, BIO *out, int indent, const CTLOG_STORE *logs);
void SCT_LIST_print(const STACK_OF(SCT) *sct_list, BIO *out, int indent,
                    const char *separator, const CTLOG_STORE *logs);
const char *SCT_validation_status_string(const SCT *sct);

DESCRIPTION

SCT_print() affiche un unique Timestamp de Certificat Signé (SCT) dans un BIO dans un format lisible par l'homme. SCT_LIST_print() affiche une liste entière de SCT de manière similaire. Un séparateur peut être spécifié pour délimiter chaque SCT dans la sortie.

La sortie peut être indentée par un nombre spécifié d'espaces. Si un CTLOG_STORE est fourni, il sera utilisé pour afficher la description du journal CT qui a émis chaque SCT (si ce journal est dans le CTLOG_STORE). Alternativement, NULL peut être passé comme paramètre CTLOG_STORE pour désactiver cette fonctionnalité.

SCT_validation_status_string() retournera le statut de validation d'un SCT sous forme de chaîne lisible par l'homme. Appelez SCT_validate() ou SCT_LIST_validate() au préalable afin de définir d'abord le statut de validation d'un SCT.

VALEUR DE RETOUR

SCT_validation_status_string() retourne une chaîne terminée par un NUL représentant le statut de validation d'un objet SCT.

VOIR AUSSI

ct(7), bio(7), CTLOG_STORE_new(3), SCT_validate(3)

HISTORIQUE

Ces fonctions ont été ajoutées dans OpenSSL 1.1.0.
