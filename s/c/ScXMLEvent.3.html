void ScXMLEvent::setEventName (const SbName & namearg) [virtual]

Cette méthode est utilisée pour définir une chaîne qui identifiera cet événement particulier, ayant cet état particulier, et peut être utilisée pour la correspondance d'événements dans les descriptions SCXML.

La chaîne doit, conformément à la spécification, être un ensemble de jetons composés de caractères alphanumériques, séparés par des points (.). Cette limitation n'est pas appliquée par cette implémentation.
