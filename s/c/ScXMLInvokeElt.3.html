Description détaillée

implémente l'élément <invoke> de SCXML.

Note importante pour les utilisateurs de SCXML dans l'implémentation Coin 3.0 de l'élément <invoke> : La première implémentation SCXML dans Coin était basée sur une version préliminaire du standard de 2007, et l'interprétation de cet élément était incorrecte sur certains aspects qui ont été clarifiés dans des révisions ultérieures du standard. L'implémentation SCXML a été rapidement développée, avec une contrainte de temps où les capacités de scripting ne pouvaient pas être obtenues, et le système de navigation (le but principal de l'implémentation du système SCXML) devait être intégré quelque part. Cela a été fait à ce moment-là dans l'élément <invoke>.

Pour l'implémentation actuelle, le code de navigation a été déplacé de la base sur <invoke> à un service communiqué via l'élément <send> pour être plus compatible avec le standard. Et pour rendre cela encore plus ridicule, cette approche sera probablement abandonnée dans un avenir pas trop lointain, remplacée par une approche de scripting pure, intégrée et en ligne. Cependant, ces deux approches devraient pouvoir coexister pendant un certain temps, donc suivre la direction actuelle d'implémentation de votre système de navigation personnalisé devrait être beaucoup plus sûr que de le faire avec l'approche mal dirigée de <invoke>.

Depuis

Coin 3.0
