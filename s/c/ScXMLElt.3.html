Description détaillée

classe de base pour tous les éléments SCXML.

Ceci est une classe de base commune pour toutes les classes d'éléments SCXML. Elle gagne des attributs XML généraux, possède des utilitaires pour vérifier la contenance des documents et fournit certains hooks d'infrastructure.

Depuis

Coin 3.1
