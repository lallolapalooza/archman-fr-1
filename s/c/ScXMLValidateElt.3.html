SbBool ScXMLValidateElt::handleXMLAttributes (void ) [virtual]

Cette méthode est appelée lorsque le lecteur de fichier a défini tous les attributs XML sur l'objet, et souhaite que l'objet les gère et signale si les valeurs étaient correctes ou si une erreur de lecture devait être émise.

Retourne

TRUE si les attributs sont corrects, et FALSE en cas d'erreur.

Cette implémentation de classe de base fait la même chose et retourne TRUE.
