NOM

SGMLS::Refs - Gestion des références croisées

SYNTAXE

use SGMLS::Refs;

Pour créer un nouvel objet gestionnaire de références en utilisant le fichier "foo.refs" :

my $refs = new SGMLS::Refs("foo.refs");

Pour créer un nouvel objet gestionnaire de références en utilisant le fichier "foo.refs" et enregistrer les modifications dans le fichier "foo.log" :

my $refs = new SGMLS::Refs("foo.refs","foo.log");

Pour enregistrer une référence :

$refs->put("titre du document",$title);

Pour récupérer une référence :

$title = $refs->get("titre du document");

Pour retourner le nombre de références modifiées depuis le dernier exécution :

$num = $refs->changed;

Pour afficher un avertissement de type LaTeX si des références ont été modifiées :

$refs->warn;

DESCRIPTION

Cette bibliothèque peut être utilisée conjointement avec le package SGMLS pour suivre les références croisées d'une exécution à l'autre, comme les fichiers ".aux" de LaTeX. Chaque gestionnaire de références est un objet qui lit puis réécrit un fichier source perl, dont le nom est fourni par l'appelant.

Exemple :

# Démarrer le gestionnaire de références avant l'analyse.
sgml('start', sub { $refs = new SGMLS::Refs("foo.refs"); });
# Avertir de toute référence modifiée à la fin.
sgml('end', sub { $refs->warn; });
# Rechercher le titre de la dernière analyse, si disponible.
sgml('<div>', sub { 
  my $element = shift;
  my $id = $element->attribute(ID)->value;
  my $title = $refs->get("title:$id") || "[titre indisponible]";
  $current_div_id = $id;
  output "\\section{$title}\n\n";
});
# Sauvegarder le titre pour la prochaine analyse.
sgml('<head>', sub { push_output('string'); });
sgml('</head>', sub {
  my $title = pop_output();
  my $id = $current_div_id;
  $refs->put("title:$id",$title);
});
