SGMLS::Output(3) Documentation Perl fournie par l'utilisateur SGMLS::Output(3)

NOM

SGMLS::Output - Procédures de sortie basées sur une pile

SYNOPIS

use SGMLS::Output;

Pour imprimer une chaîne vers la destination de sortie actuelle :

output($data);

Pour empiler un nouveau niveau de sortie vers le descripteur de fichier DATA :

push_output('handle',DATA);

Pour empiler un nouveau niveau de sortie vers le fichier « foo.data » (qui sera ouvert et fermé automatiquement) :

push_output('file','foo.data');

Pour empiler un nouveau niveau de sortie vers un tuyau vers la commande shell « sort » :

push_output('pipe','sort');

Pour empiler un nouveau niveau de sortie en *ajoutant* au fichier « foo.data » :

push_output('append','foo.data');

Pour empiler un nouveau niveau de sortie vers une chaîne vide :

push_output('string');

Pour empiler un nouveau niveau de sortie en ajoutant à la chaîne « David est » :

push_output('string',"David est ");

Pour empiler un nouveau niveau de sortie vers le Grand Au-delà :

push_output('nul');

Pour revenir au niveau de sortie précédent :

pop_output();

Pour revenir au niveau de sortie précédent, en retournant le contenu d'une chaîne de sortie :

$data = pop_output();

DESCRIPTION

Cette bibliothèque permet une sortie rediectionnable et basée sur une pile vers des fichiers, des tuyaux, des descripteurs, des chaînes ou nul. Elle est particulièrement utile pour des packages comme SGMLS, car les gestionnaires d'éléments SGML individuels peuvent changer temporairement et restaurer la destination de sortie par défaut. Elle est également particulièrement utile pour capturer le contenu d'un élément (et de ses sous-éléments) dans une chaîne.

Exemple :

sgmls('<title>', sub{ push_output('string'); });
sgmls('</title>', sub{ $title = pop_output(); });

Entre les deux, tout ce qui est envoyé à output (comme CDATA) sera accumulé dans la chaîne retournée par pop_output().

Exemple :

sgmls('<tei.header>', sub { push_output('nul'); });
sgmls('</tei.header>', sub { pop_output(); });

Toute la sortie sera ignorée jusqu'à la fin de l'en-tête.
