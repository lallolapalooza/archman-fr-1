Safe::Isa(3) Documentation Perl contribuée par l'utilisateur Safe::Isa(3)

NOM

Safe::Isa - Appelle isa, can, does et DOES en toute sécurité sur des éléments qui ne sont peut-être pas des objets

SYNTAXE

use strict;
use warnings;

{ package Foo; sub new { bless({}, $_[0]) } }
{ package Bar; our @ISA = qw(Foo); sub bar { 1 } }

my $foo = Foo->new;
my $bar = Bar->new;
my $blam = [ 42 ];

# Utilisation basique de isa -

$foo->isa('Foo');  # vrai
$bar->isa('Foo');  # vrai
$blam->isa('Foo'); # BOUM

$foo->can('bar');  # faux
$bar->can('bar');  # vrai
$blam->can('bar'); # BOUM

# Utilisation de Safe::Isa -

use Safe::Isa;

$foo->$_isa('Foo');  # vrai
$bar->$_isa('Foo');  # vrai
$blam->$_isa('Foo'); # faux, pas de BOUM aujourd'hui

$foo->$_can('bar');  # faux
$bar->$_can('bar');  # vrai
$blam->$_can('bar'); # faux, pas de BOUM aujourd'hui

De même :

$maybe_an_object->$_does('RoleName'); # vrai ou faux, pas de BOUM aujourd'hui
$maybe_an_object->$_DOES('RoleName'); # vrai ou faux, pas de BOUM aujourd'hui

Et juste au cas où nous aurions manqué une ou deux méthodes :

$maybe_an_object->$_call_if_object(name => @args);
$maybe_an_object->$_call_if_can(name => @args);

Ou pour réutiliser un exemple précédent à des fins d'explication :

$foo->$_call_if_object(isa => 'Foo');  # vrai
$bar->$_call_if_object(isa => 'Foo');  # vrai
$blam->$_call_if_object(isa => 'Foo'); # faux, pas de BOUM aujourd'hui

DESCRIPTION

Combien de fois vous êtes-vous retrouvé à écrire :

if ($obj->isa('Something')) {

et peu de temps après, à maudire et à changer en :

if (Scalar::Util::blessed($obj) and $obj->isa('Something')) {

Exactement. C'est pourquoi ce module existe.

Puisque perl nous permet de fournir une référence de sous-routine ou un nom de méthode à l'opérateur -> lorsqu'il est utilisé comme appel de méthode, et qu'une sous-routine ne nécessite pas que l'invocant soit effectivement un objet, nous pouvons créer des versions sûres de isa, can et similaires en utilisant une référence de sous-routine qui tente uniquement d'appeler la méthode si elle est utilisée sur un objet. Donc :

my $isa_Foo = $maybe_an_object->$_call_if_object(isa => 'Foo');

est équivalent à

my $isa_Foo = do {
  if (Scalar::Util::blessed($maybe_an_object)) {
    $maybe_an_object->isa('Foo');
  } else {
    undef;
  }
};

Notez que nous ne gérons pas les noms de classe, car beaucoup de choses sont des noms de classe valides que vous pourriez ne pas vouloir traiter comme tels (comme par exemple "Matt") - la fonction "is_module_name" de Module::Runtime est un bon moyen de vérifier quelque chose sur lequel vous pourriez être capable d'appeler des méthodes si vous souhaitez le faire.

Nous veillons à ce que le contexte scalaire/liste soit préservé pour la méthode qui est finalement appelée.

EXPORT

$_isa

$maybe_an_object->$_isa('Foo');

Si appelée sur un objet, appelle "isa" sur celui-ci et renvoie le résultat, sinon ne renvoie rien.

$_can

$maybe_an_object->$_can('Foo');

Si appelée sur un objet, appelle "can" sur celui-ci et renvoie le résultat, sinon ne renvoie rien.

$_does

$maybe_an_object->$_does('Foo');

Si appelée sur un objet, appelle "does" sur celui-ci et renvoie le résultat, sinon ne renvoie rien. Si la méthode "does" n'existe pas, renvoie rien plutôt que d'échouer.

$_DOES

$maybe_an_object->$_DOES('Foo');

Si appelée sur un objet, appelle "DOES" sur celui-ci et renvoie le résultat, sinon ne renvoie rien. Sur les versions de perl antérieures à 5.10.0, la méthode intégrée "DOES" n'existe pas. Si la méthode n'existe pas, cela se rabattra sur l'appel de "isa" tout comme la méthode "DOES" intégrée.

$_call_if_object

$maybe_an_object->$_call_if_object(method_name => @args);

Si appelée sur un objet, appelle "method_name" sur celui-ci et renvoie le résultat, sinon ne renvoie rien.

$_call_if_can

$maybe_an_object->$_call_if_can(name => @args);

Si appelée sur un objet, appelle "can" sur celui-ci ; si cela renvoie vrai, alors appelle "method_name" sur celui-ci et renvoie le résultat ; si une condition est fausse, renvoie rien.
