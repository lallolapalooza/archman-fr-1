NOM

SAVEPOINT - définir un nouveau point de sauvegarde dans la transaction courante

SYNTAXE

SAVEPOINT nom_point_sauvegarde

DESCRIPTION

SAVEPOINT établit un nouveau point de sauvegarde dans la transaction courante.

Un point de sauvegarde est une marque spéciale à l'intérieur d'une transaction qui permet d'annuler toutes les commandes exécutées après son établissement, restaurant l'état de la transaction à ce qu'il était au moment du point de sauvegarde.

PARAMETRES

nom_point_sauvegarde

Le nom à donner au nouveau point de sauvegarde. Si des points de sauvegarde portant le même nom existent déjà, ils deviendront inaccessibles jusqu'à ce que les points de sauvegarde plus récents de même nom soient libérés.

NOTES

Utilisez ROLLBACK TO pour revenir à un point de sauvegarde. Utilisez RELEASE SAVEPOINT pour détruire un point de sauvegarde, en conservant les effets des commandes exécutées après son établissement.

Les points de sauvegarde ne peuvent être établis qu'à l'intérieur d'un bloc de transaction. Plusieurs points de sauvegarde peuvent être définis au sein d'une transaction.

EXEMPLES

Pour établir un point de sauvegarde et annuler plus tard les effets de toutes les commandes exécutées après son établissement :

BEGIN;
    INSERT INTO table1 VALUES (1);
    SAVEPOINT mon_point_sauvegarde;
    INSERT INTO table1 VALUES (2);
    ROLLBACK TO SAVEPOINT mon_point_sauvegarde;
    INSERT INTO table1 VALUES (3);
COMMIT;

La transaction ci-dessus insérera les valeurs 1 et 3, mais pas 2.

Pour établir et détruire plus tard un point de sauvegarde :

BEGIN;
    INSERT INTO table1 VALUES (3);
    SAVEPOINT mon_point_sauvegarde;
    INSERT INTO table1 VALUES (4);
    RELEASE SAVEPOINT mon_point_sauvegarde;
COMMIT;

La transaction ci-dessus insérera les valeurs 3 et 4.

Pour utiliser un nom de point de sauvegarde unique :

BEGIN;
    INSERT INTO table1 VALUES (1);
    SAVEPOINT mon_point_sauvegarde;
    INSERT INTO table1 VALUES (2);
    SAVEPOINT mon_point_sauvegarde;
    INSERT INTO table1 VALUES (3);
    -- annuler jusqu'au second point de sauvegarde
    ROLLBACK TO SAVEPOINT mon_point_sauvegarde;
    SELECT * FROM table1;               -- affiche les lignes 1 et 2
    -- libérer le second point de sauvegarde
    RELEASE SAVEPOINT mon_point_sauvegarde;
    -- annuler jusqu'au premier point de sauvegarde
    ROLLBACK TO SAVEPOINT mon_point_sauvegarde;
    SELECT * FROM table1;               -- affiche uniquement la ligne 1
COMMIT;

La transaction ci-dessus montre que la ligne 3 est annulée d'abord, puis la ligne 2.

COMPATIBILITÉ

SQL exige qu'un point de sauvegarde soit détruit automatiquement lorsqu'un autre point de sauvegarde portant le même nom est établi. Dans PostgreSQL, l'ancien point de sauvegarde est conservé, bien que seul le plus récent soit utilisé lors d'une annulation ou d'une libération. (Libérer le point de sauvegarde le plus récent avec RELEASE SAVEPOINT rendra l'ancien à nouveau accessible à ROLLBACK TO SAVEPOINT et RELEASE SAVEPOINT.) Sinon, SAVEPOINT est entièrement conforme à SQL.
