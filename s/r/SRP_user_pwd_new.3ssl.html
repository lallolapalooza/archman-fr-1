SRP_user_pwd_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

SRP_USER_PWD_NEW(3ssl) OpenSSL SRP_USER_PWD_NEW(3ssl)

NOM

SRP_user_pwd_new, SRP_user_pwd_free, SRP_user_pwd_set1_ids, SRP_user_pwd_set_gN, SRP_user_pwd_set0_sv - Fonctions pour créer un enregistrement d'informations de vérificateur utilisateur SRP

SYNTAXE

#include <openssl/srp.h>

Les fonctions suivantes sont obsolètes depuis OpenSSL 3.0, et peuvent être complètement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

SRP_user_pwd *SRP_user_pwd_new(void);
void SRP_user_pwd_free(SRP_user_pwd *user_pwd);
int SRP_user_pwd_set1_ids(SRP_user_pwd *user_pwd, const char *id, const char *info);
void SRP_user_pwd_set_gN(SRP_user_pwd *user_pwd, const BIGNUM *g, const BIGNUM *N);
int SRP_user_pwd_set0_sv(SRP_user_pwd *user_pwd, BIGNUM *s, BIGNUM *v);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont obsolètes. Il n'y a pas de fonctions de remplacement disponibles pour le moment.

La fonction SRP_user_pwd_new() alloue une structure pour stocker un enregistrement de vérificateur utilisateur.

La fonction SRP_user_pwd_free() libère la structure user_pwd. Si user_pwd est NULL, rien n'est fait.

La fonction SRP_user_pwd_set1_ids() définit le nom d'utilisateur à id et les informations facultatives de l'utilisateur à info pour user_pwd. La bibliothèque alloue de nouvelles copies de id et info, l'appelant conserve la propriété de la mémoire d'origine.

La fonction SRP_user_pwd_set0_sv() définit le sel utilisateur à s et le vérificateur à v pour user_pwd. La bibliothèque prend possession des valeurs, elles ne doivent pas être libérées par l'appelant.

La fonction SRP_user_pwd_set_gN() définit les paramètres du groupe SRP pour user_pwd. La mémoire n'est pas libérée par SRP_user_pwd_free(), l'appelant doit s'assurer qu'elle est libérée une fois qu'elle n'est plus utilisée.

VALEURS DE RETOUR

SRP_user_pwd_set1_ids() retourne 1 en cas de succès et 0 en cas d'échec ou si id était NULL.

SRP_user_pwd_set0_sv() retourne 1 si s et v ne sont pas NULL, 0 sinon.

VOIR AUSSI

openssl-srp(1), SRP_create_verifier(3), SRP_VBASE_new(3), SSL_CTX_set_srp_password(3)

HISTORIQUE

Ces fonctions ont été rendues publiques dans OpenSSL 3.0 et sont obsolètes.
