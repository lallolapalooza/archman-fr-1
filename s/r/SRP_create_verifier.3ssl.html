SRP_create_verifier(3ssl)

NOM

SRP_create_verifier_ex, SRP_create_verifier, SRP_create_verifier_BN_ex, SRP_create_verifier_BN, SRP_check_known_gN_param, SRP_get_default_gN - Primitives d'authentification SRP

SYNTAXE

#include <openssl/srp.h>

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7).

int SRP_create_verifier_BN_ex(const char *user, const char *pass, BIGNUM **salt,
                              BIGNUM **verifier, const BIGNUM *N,
                              const BIGNUM *g, OSSL_LIB_CTX *libctx,
                              const char *propq);
char *SRP_create_verifier_BN(const char *user, const char *pass, BIGNUM **salt,
                             BIGNUM **verifier, const BIGNUM *N, const BIGNUM *g);
char *SRP_create_verifier_ex(const char *user, const char *pass, char **salt,
                             char **verifier, const char *N, const char *g,
                             OSSL_LIB_CTX *libctx, const char *propq);
char *SRP_create_verifier(const char *user, const char *pass, char **salt,
                          char **verifier, const char *N, const char *g);
char *SRP_check_known_gN_param(const BIGNUM *g, const BIGNUM *N);
SRP_gN *SRP_get_default_gN(const char *id);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Il n'y a pas de fonctions de remplacement disponibles pour le moment.

La fonction SRP_create_verifier_BN_ex() crée un vérificateur de mot de passe SRP à partir des paramètres fournis tels que définis dans la section 2.4 de la RFC 5054 en utilisant le contexte de bibliothèque libctx et la chaîne de requête de propriété propq. Tous les algorithmes cryptographiques qui doivent être récupérés utiliseront libctx et propq. Voir "ALGORITHM FETCHING" dans crypto(7).

SRP_create_verifier_BN() est identique à SRP_create_verifier_BN_ex(), sauf que le contexte de bibliothèque et la chaîne de requête de propriété par défaut sont utilisés.

En cas de succès, *verifier pointera vers un BIGNUM nouvellement alloué contenant le vérificateur et (si un sel n'a pas été fourni) *salt sera rempli avec un BIGNUM nouvellement alloué contenant un sel aléatoire. Si *salt n'est pas NULL, alors le sel fourni est utilisé à la place. L'appelant est responsable de libérer les BIGNUMs *salt et *verifier alloués (utiliser BN_free(3)).

La fonction SRP_create_verifier() est similaire à SRP_create_verifier_BN(), mais tous les paramètres numériques sont dans un encodage base64 non standard, originellement conçu pour la compatibilité avec libsrp. Ceci est principalement présent pour des raisons de compatibilité historique et son utilisation est déconseillée. Il est possible de passer NULL comme N et un identifiant de groupe SRP comme g à la place pour charger les valeurs gN appropriées (voir SRP_get_default_gN()). Si N et g sont tous deux NULL, les paramètres du groupe SRP de 8192 bits sont utilisés. L'appelant est responsable de libérer *salt et *verifier (utiliser OPENSSL_free(3)).

La fonction SRP_check_known_gN_param() vérifie que g et N sont des paramètres de groupe SRP valides de la RFC 5054 annexe A.

La fonction SRP_get_default_gN() renvoie les paramètres gN pour la taille de groupe SRP id de la RFC 5054. Les identifiants connus sont "1024", "1536", "2048", "3072", "4096", "6144" et "8192".

VALEURS DE RETOUR

SRP_create_verifier_BN_ex() et SRP_create_verifier_BN() renvoient 1 en cas de succès et 0 en cas d'échec.

SRP_create_verifier_ex() et SRP_create_verifier() renvoient NULL en cas d'échec et une valeur non-NULL en cas de succès : "*" si N n'est pas NULL, l'identifiant de groupe sélectionné sinon. Cette valeur ne doit pas être libérée.

SRP_check_known_gN_param() renvoie la représentation textuelle de l'identifiant de groupe (c'est-à-dire la taille en bits de la prime) ou NULL si les arguments ne sont pas des paramètres de groupe SRP valides. Cette valeur ne doit pas être libérée.

SRP_get_default_gN() renvoie NULL si id n'est pas une taille de groupe valide, ou les paramètres du groupe de 8192 bits si id est NULL.

EXEMPLES

Générer et stocker un vérificateur de mot de passe de 8192 bits (gestion des erreurs omise pour plus de clarté) :

#include <openssl/bn.h>
#include <openssl/srp.h>
const char *username = "username";
const char *password = "password";
SRP_VBASE *srpData = SRP_VBASE_new(NULL);
SRP_gN *gN = SRP_get_default_gN("8192");
BIGNUM *salt = NULL, *verifier = NULL;
SRP_create_verifier_BN_ex(username, password, &salt, &verifier, gN->N, gN->g,
                          NULL, NULL);
SRP_user_pwd *pwd = SRP_user_pwd_new();
SRP_user_pwd_set1_ids(pwd, username, NULL);
SRP_user_pwd_set0_sv(pwd, salt, verifier);
SRP_user_pwd_set_gN(pwd, gN->g, gN->N);
SRP_VBASE_add0_user(srpData, pwd);
