Files de priorité polymorphes

Les foncteurs suivants, plus complexes, créent des files polymorphes de type 'a t , tout comme d'autres conteneurs polymorphes (listes, tableaux...). Ils nécessitent une notion d'"éléments polymorphes" 'a
elt qui peuvent être comparés sans dépendre des valeurs de 'a.

Un scénario d'utilisation est lorsque l'utilisateur souhaite passer les priorités séparément de la valeur stockée dans la file. Ceci est fait en utilisant des paires priorité * 'a comme éléments.

      module Prio : OrderedType = ...
      module PrioQueue = Pqueue.MakeMinPoly(struct
        type 'a t = Prio.t * 'a
        let compare (p1, _) (p2, _) = Prio.compare p1 p2
      end)
      (* par exemple, nous avons maintenant : *)
      PrioQueue.add: 'a PrioQueue.t -> Prio.t * 'a -> unit
      PrioQueue.min_elt: 'a PrioQueue.t -> (Prio.t * 'a) option
