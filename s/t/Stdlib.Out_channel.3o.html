type t = out_channel

Le type de canal de sortie.

type open_flag = open_flag =
| Open_read (* ouvrir en lecture seule.
*)
| Open_write (* ouvrir en écriture seule.
*)
| Open_append (* ouvrir en mode ajout : toujours écrire à la fin du fichier.
*)
| Open_create (* créer le fichier s'il n'existe pas.
*)
| Open_truncate (* vider le fichier s'il existe déjà.
*)
| Open_exclusive (* échouer si Open_create et le fichier existe déjà.
*)
| Open_binary (* ouvrir en mode binaire (pas de conversion).
*)
| Open_text (* ouvrir en mode texte (peut effectuer des conversions).
*)
| Open_nonblock (* ouvrir en mode non bloquant.
*)

Modes d'ouverture pour Out_channel.open_gen .

val stdout : t

La sortie standard du processus.

val stderr : t

La sortie d'erreur standard du processus.

val open_bin : string -> t

Ouvre le fichier nommé par la chaîne donnée en écriture, et renvoie un nouveau canal de sortie sur ce fichier, positionné au début du fichier. Le fichier est vidé à longueur zéro s'il existe déjà. Il est créé s'il n'existe pas.

val open_text : string -> t

Identique à Out_channel.open_bin , mais le fichier est ouvert en mode texte, de sorte que la conversion des fins de ligne est effectuée lors des écritures. Sur les systèmes d'exploitation qui ne font pas de distinction entre le mode texte et le mode binaire, cette fonction se comporte comme Out_channel.open_bin .

val open_gen : open_flag list -> int -> string -> t

Ouvre le fichier nommé par la chaîne donnée en écriture, comme décrit ci-dessus. L'argument mode supplémentaire spécifie le mode d'ouverture. L'argument perm supplémentaire spécifie les permissions du fichier, au cas où le fichier devrait être créé. Out_channel.open_text et Out_channel.open_bin sont des cas spéciaux de cette fonction.

val with_open_bin : string -> (t -> 'a) -> 'a

Ouvre un canal oc dans le fichier fn et renvoie f
oc. Après que f ait renvoyé une valeur ou levé une exception, oc est garanti d'être fermé.

val with_open_text : string -> (t -> 'a) -> 'a

Comme Out_channel.with_open_bin , mais le canal est ouvert en mode texte (voir Out_channel.open_text ).

val with_open_gen : open_flag list -> int -> string -> (t -> 'a) -> 'a

Comme Out_channel.with_open_bin , mais vous pouvez spécifier le mode d'ouverture et les permissions du fichier, au cas où le fichier devrait être créé (voir Out_channel.open_gen ).

val close : t -> unit

Ferme le canal donné, vidant toutes les opérations d'écriture en mémoire tampon. Les fonctions d'écriture lèvent une exception Sys_error lorsqu'elles sont appliquées à un canal fermé, à l'exception de Out_channel.close et Out_channel.flush , qui ne font rien lorsqu'elles sont appliquées à un canal déjà fermé. Notez que Out_channel.close peut lever Sys_error si le système d'exploitation signale une erreur lors de la fermeture ou du vidage.

val close_noerr : t -> unit

Identique à Out_channel.close , mais ignore toutes les erreurs.

Sortie

val output_char : t -> char -> unit

Écrit le caractère dans le canal de sortie donné.

val output_byte : t -> int -> unit

Écrit un entier de 8 bits (comme le caractère ayant ce code) dans le canal de sortie donné. L'entier donné est pris modulo 256.

val output_string : t -> string -> unit

Écrit la chaîne dans le canal de sortie donné.

val output_bytes : t -> bytes -> unit

Écrit la séquence d'octets dans le canal de sortie donné.

Sortie avancée

val output : t -> bytes -> int -> int -> unit

output oc buf pos len écrit len caractères de la séquence d'octets buf , en commençant à l'offset pos , dans le canal de sortie oc .

Lève Invalid_argument si pos et len ne désignent pas une plage valide de buf .

val output_substring : t -> string -> int -> int -> unit

Identique à Out_channel.output mais prend une chaîne comme argument au lieu d'une séquence d'octets.

val output_bigarray : t -> ('a, Bigarray.int8_unsigned_elt, Bigarray.c_layout) Bigarray.Array1.t -> int -> int -> unit

Identique à Out_channel.output mais utilise les données d'un bigarray.

Depuis 5.2

Vidage

val flush : t -> unit

Vide le tampon associé au canal de sortie donné, effectuant toutes les écritures en attente sur ce canal. Les programmes interactifs doivent faire attention à vider la sortie standard et la sortie d'erreur au bon moment.

val flush_all : unit -> unit

Vide tous les canaux de sortie ouverts ; ignore les erreurs.

Positionnement

val seek : t -> int64 -> unit

seek chan pos définit la position d'écriture actuelle de chan à pos . Cela ne fonctionne que pour les fichiers réguliers. Sur les fichiers d'autres types (tels que les terminaux, les pipes et les sockets), le comportement est indéterminé.

val pos : t -> int64

Renvoie la position d'écriture actuelle pour le canal donné. Ne fonctionne pas sur les canaux ouverts avec le drapeau Open_append (résultats indéterminés).

Pour les fichiers ouverts en mode texte sous Windows, la position renvoyée est approximative (en raison de la conversion des fins de ligne). En particulier, sauvegarder la position actuelle avec Out_channel.pos , puis revenir à cette position avec Out_channel.seek ne fonctionne pas. Pour que ce langage de programmation soit cohérent et portable, le fichier doit être ouvert en mode binaire.

Attributs

val length : t -> int64

Renvoie la taille (nombre de caractères) du fichier régulier sur lequel le canal a été ouvert. Si le canal a été ouvert sur un fichier qui n'est pas régulier, le résultat est imprécis.

val set_binary_mode : t -> bool -> unit

set_binary_mode oc true met le canal oc en mode binaire : aucune conversion n'est effectuée pendant la sortie.

set_binary_mode oc false met le canal oc en mode texte : en fonction du système d'exploitation, certaines conversions peuvent être effectuées pendant la sortie. Par exemple, sous Windows, les fins de ligne seront converties de \n en \r\n .

Cette fonction n'a aucun effet sur les systèmes d'exploitation qui ne font pas de distinction entre le mode texte et le mode binaire.

val is_binary_mode : t -> bool

is_binary_mode oc renvoie si le canal oc est en mode binaire (voir Out_channel.set_binary_mode ).

Depuis 5.2

val set_buffered : t -> bool -> unit

set_buffered oc true met le canal oc en mode bufferisé. Dans ce mode, la sortie des données dans oc sera mise en tampon jusqu'à ce que Out_channel.flush ou Out_channel.flush_all soit appelé, moment auquel elle sera envoyée à la sortie.

set_buffered oc false met le canal oc en mode non bufferisé. Dans ce mode, les données de sortie dans oc seront immédiatement envoyées à la sortie.

Tous les canaux sont ouverts en mode bufferisé par défaut.

val is_buffered : t -> bool

is_buffered oc renvoie si le canal oc est bufferisé (voir Out_channel.set_buffered ).

val isatty : t -> bool

isatty oc renvoie true si oc référence un terminal ou une console, false sinon.

Depuis 5.1

Exemples

Écrire le contenu d'un fichier :

      let write_file file s =
        Out_channel.with_open_bin file
          (fun oc -> Out_channel.output_string oc s))
