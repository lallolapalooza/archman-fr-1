String__CRC32(3pm)

Paquet: perl-string-crc32

Licences: GPL, PerlArtistic

CRC32(3) Documentation Perl fournie par l'utilisateur CRC32(3)

NOM

String::CRC32 - Interface Perl pour la génération de somme de contrôle CRC (Cyclic Redundancy Check)

SYNTAXE

use String::CRC32;

$crc = crc32("une chaîne");
$crc = crc32("une chaîne", valeur_init);
$chaine = "une chaîne";
$crc = crc32($chaine);
printf "%08x\n", $crc;
open my $fh, '<', 'chemin/vers/quelque.fichier' or die $!;
binmode $fh;
$crc = crc32($fh);
close $fh;

DESCRIPTION

Le module CRC32 calcule des sommes CRC de 32 bits sous forme d'entiers. Il génère les mêmes valeurs CRC que ZMODEM, PKZIP, PICCHECK et bien d'autres.

Malgré son nom, ce module est capable de calculer la somme de contrôle des fichiers ainsi que des chaînes de caractères.

EXEMPLES

$crc = crc32("une chaîne");

donne le même résultat que

$crc = crc32(" chaîne", crc32("une"));

Ceci est utile pour la vérification ultérieure de sommes CRC de sous-chaînes.

Vous pouvez même vérifier des fichiers :

open my $fh, '<', 'chemin/vers/quelque.fichier' or die $!;
binmode $fh;
$crc = crc32($fh);
close $fh;

Une valeur d'initialisation peut également avoir été fournie dans l'exemple ci-dessus.
