TAILQ_HEAD

Les macros définies ici définissent et opèrent sur quatre types de structures de données qui peuvent être utilisées en C et en C++ :

  1. Liste
  2. Liste doublement chaînée
  3. File d'attente de liste doublement chaînée
  4. File d'attente de liste
Les quatre structures prennent en charge la fonctionnalité suivante :
  1. Insertion d'un nouvel élément au début de la liste.
  2. Insertion d'un nouvel élément après n'importe quel élément de la liste.
  3. Suppression d'un élément au début de la liste en temps constant (O(1)).
  4. Parcours avant dans la liste.
  5. Échange du contenu de deux listes.
Les listes simplement chaînées sont les plus simples des quatre structures et ne prennent en charge que la fonctionnalité mentionnée ci-dessus. Les listes simplement chaînées sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une pile LIFO (Last-In, First-Out). Les listes simplement chaînées ajoutent la fonctionnalité suivante :
  1. Suppression de n'importe quel élément de la liste en temps O(n).
  2. Concaténation de deux listes en temps O(n).
Les files d'attente de listes simplement chaînées ajoutent la fonctionnalité suivante :
  1. Les éléments peuvent être ajoutés à la fin d'une liste.
  2. Suppression de n'importe quel élément de la liste en temps O(n).
  3. Elles peuvent être concaténées.
Cependant :
  1. Toute insertion dans une liste doit spécifier le début de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un.
  3. La taille du code est environ 15 % plus grande et les opérations sont environ 20 % plus lentes que les listes simplement chaînées.
Les files d'attente de listes simplement chaînées sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une file d'attente FIFO (First-In, First-Out). De plus, les structures de données doublement chaînées (listes et files d'attente) permettent également :
  1. Insertion d'un nouvel élément avant n'importe quel élément de la liste.
  2. Suppression de n'importe quel élément de la liste en temps O(1).
Cependant :
  1. Chaque élément nécessite deux pointeurs au lieu d'un.
  2. La taille du code et le temps d'exécution des opérations (à l'exception de la suppression) sont environ le double de ceux des structures simplement chaînées.
Les listes sont les plus simples des structures doublement chaînées. Elles ajoutent la fonctionnalité suivante par rapport à celles mentionnées ci-dessus :
  1. Concaténation de deux listes en temps O(n).
  2. Elles peuvent être parcourues en sens inverse.
Cependant :
  1. Pour parcourir en sens inverse, il faut spécifier l'élément à partir duquel commencer le parcours et la liste dans laquelle il se trouve.
Les files d'attente ajoutent la fonctionnalité suivante :
  1. Les éléments peuvent être ajoutés à la fin d'une liste.
  2. Elles peuvent être parcourues en sens inverse, de la fin au début.
  3. Elles peuvent être concaténées.
Cependant :
  1. Toute insertion et suppression dans une liste doit spécifier le début de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un.
  3. La taille du code est environ 15 % plus grande et les opérations sont environ 20 % plus lentes que les listes simplement chaînées.
Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur. La structure doit contenir un champ nommé NAME de type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY ou TAILQ_ENTRY. Dans les définitions de macros, CLASSTYPE est le nom d'une classe définie par l'utilisateur. La classe doit contenir un champ nommé NAME de type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY ou TAILQ_CLASS_ENTRY. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant les macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD ou TAILQ_CLASS_HEAD. Voir les exemples ci-dessous pour une explication plus détaillée de l'utilisation de ces macros.

LISTES SIMPLEMENT CHAÎNÉES

Une liste simplement chaînée est dirigée par une structure définie à l'aide de la macro SLIST_HEAD. Cette structure contient un seul pointeur vers l'élément principal de la liste. Les éléments sont simplement chaînés pour minimiser l'espace et la surcharge de gestion des pointeurs, bien que le temps de suppression des éléments arbitraires soit O(n). De nouveaux éléments peuvent être ajoutés à la liste après un élément existant ou au début de la liste. Une structure SLIST_HEAD est déclarée comme suit :

SLIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir et TYPE est le type des éléments de la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro SLIST_HEAD_INITIALIZER évalue un initialiseur pour la liste head.

La macro SLIST_CONCAT concaténera la liste dirigée par head2 à la fin de la liste dirigée par head1, effaçant tous les éléments de la première. Son utilisation doit être évitée, car elle parcourt toute la liste head1. Une file d'attente de liste simplement chaînée devrait être utilisée si cette macro est nécessaire dans des chemins de code à utilisation intensive ou si des listes longues doivent être traitées.

La macro SLIST_EMPTY évalue à vrai s'il n'y a aucun élément dans la liste.

La macro SLIST_ENTRY déclare une structure qui relie les éléments de la liste.

La macro SLIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro SLIST_FOREACH parcourt la liste référencée par head dans le sens avant, affectant chaque élément dans l'ordre à var.

La macro SLIST_FOREACH_FROM se comporte de manière identique à SLIST_FOREACH lorsque var est NULL, dans ce cas elle traite var comme un élément précédemment trouvé dans la liste référencée par head et commence la boucle à partir de var au lieu du premier élément de la liste référencée par head.

La macro SLIST_FOREACH_SAFE parcourt la liste référencée par head dans le sens avant, affectant chaque élément dans l'ordre à var. Cependant, contrairement à SLIST_FOREACH(), ici il est permis de supprimer var ainsi que de le libérer dans la boucle sans interférer avec la trajectoire de parcours.

La macro SLIST_FOREACH_FROM_SAFE se comporte de manière identique à SLIST_FOREACH_SAFE lorsque var est NULL, dans ce cas elle traite var comme un élément précédemment trouvé dans la liste référencée par head et commence la boucle à partir de var au lieu du premier élément de la liste référencée par head.

La macro SLIST_INIT initialise la liste référencée par head.

La macro SLIST_INSERT_HEAD insère le nouvel élément elm au début de la liste.

La macro SLIST_INSERT_AFTER insère le nouvel élément elm après l'élément <

SLIST

La macro SLIST_EMPTY devuelve verdadero si la lista está vacía.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista, o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista dirigida por head en dirección hacia adelante, asignando cada elemento a var.

La macro SLIST_FOREACH_FROM se comporta de manera idéntica a SLIST_FOREACH cuando var es NULL; de lo contrario, trata var como un elemento encontrado previamente en la lista y comienza el ciclo desde var en lugar del primer elemento de la lista dirigida por head.

La macro SLIST_FOREACH_SAFE recorre la lista dirigida por head en dirección hacia adelante, asignando cada elemento a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí se permite eliminar var y liberar su contenido dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta de manera idéntica a SLIST_FOREACH_SAFE cuando var es NULL; de lo contrario, trata var como un elemento encontrado previamente en la lista y comienza el ciclo desde var en lugar del primer elemento de la lista dirigida por head.

La macro SLIST_HEAD declara una estructura que contiene un puntero al primer elemento de la lista.

La macro SLIST_HEAD_INITIALIZER evalúa como inicializador para la lista head.

La macro SLIST_INIT inicializa la lista dirigida por head.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_TAIL inserta el nuevo elemento elm al final de la lista.

La macro SLIST_NEXT devuelve el siguiente elemento de la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento después de elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre toda la lista.

La macro SLIST_REMOVE_HEAD elimina el elemento elm del principio de la lista. Para una eficiencia óptima, los elementos que se van a eliminar del principio de la lista deben usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Su uso debe evitarse, ya que recorre toda la lista. Si es necesario usar esta macro en rutas de código de alta concurrencia o para operar sobre listas largas, se debe utilizar una lista doblemente enlazada.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

SINGLY-LINKED LIST EXAMPLE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Singly-linked List head. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Singly-linked List. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Initialize the list. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Deletion. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Deletion from the head. */
free(n3);
					/* Forward traversal. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Safe forward traversal. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* List Deletion. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

SINGLY-LINKED TAIL QUEUES

Une queue de fin liée singulièrement est dirigée par une structure définie au moyen de la macro STAILQ_HEAD. Cette structure contient une paire de pointeurs, un vers le premier élément de la queue de fin et un autre vers le dernier élément de la queue de fin. Les éléments sont liés singulièrement afin de minimiser la surcharge d'espace et de manipulation de pointeurs, bien que le coût soit de O(n) pour la suppression d'éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la queue de fin après un élément existant, au début de la queue de fin ou à la fin de la queue de fin. Une structure STAILQ_HEAD est déclarée comme suit :

STAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir et TYPE est le type des éléments à lier dans la queue de fin. Un pointeur vers la tête de la queue de fin peut être déclaré ultérieurement comme :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro STAILQ_HEAD_INITIALIZER évalue comme un initialiseur pour la queue de fin head.

La macro STAILQ_CONCAT concatène la queue de fin dirigée par head2 à la fin de la queue de fin dirigée par head1, supprimant tous les éléments de la première queue de fin.

La macro STAILQ_EMPTY évalue comme vrai s'il n'y a pas d'éléments dans la queue de fin.

La macro STAILQ_ENTRY déclare une structure qui relie les éléments de la queue de fin.

La macro STAILQ_FIRST retourne le premier élément de la queue de fin ou NULL si la queue de fin est vide.

La macro STAILQ_FOREACH parcourt la queue de fin dirigée par head dans le sens avant, assignant chaque élément à var.

La macro STAILQ_FOREACH_FROM se comporte de manière identique à STAILQ_FOREACH lorsque var est NULL, sinon elle traite var comme un élément trouvé précédemment dans la queue de fin et commence le cycle à partir de var au lieu du premier élément de la queue de fin dirigée par head.

La macro STAILQ_FOREACH_SAFE parcourt la queue de fin dirigée par head dans le sens avant, assignant chaque élément à var. Cependant, contrairement à STAILQ_FOREACH(), elle permet de supprimer var et de libérer son contenu à l'intérieur du cycle en toute sécurité sans interférer avec le parcours.

La macro STAILQ_FOREACH_FROM_SAFE se comporte de manière identique à STAILQ_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément trouvé précédemment dans la queue de fin et commence le cycle à partir de var au lieu du premier élément de la queue de fin dirigée par head.

La macro STAILQ_INIT initialise la queue de fin dirigée par head.

La macro STAILQ_INSERT_HEAD insère le nouvel élément elm au début de la queue de fin.

La macro STAILQ_INSERT_TAIL insère le nouvel élément elm à la fin de la queue de fin.

La macro STAILQ_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro STAILQ_LAST retourne le dernier élément de la queue de fin. Si la queue de fin est vide, la valeur retournée est NULL.

La macro STAILQ_NEXT retourne l'élément suivant dans la queue de fin, ou NULL s'il s'agit du dernier.

La macro STAILQ_REMOVE_AFTER supprime l'élément suivant elm de la queue de fin. Bien qu'elle ne parcoure pas toute la queue de fin, cette macro est différente de STAILQ_REMOVE.

La macro STAILQ_REMOVE_HEAD supprime l'élément en tête de la queue de fin. Pour une efficacité optimale, les éléments à supprimer du début de la queue de fin doivent utiliser explicitement cette macro au lieu de la macro générique STAILQ_REMOVE.

La macro STAILQ_REMOVE supprime l'élément elm de la queue de fin. Son utilisation doit être évitée car elle parcourt toute la liste. Si cette macro doit être utilisée dans des chemins de code très fréquentés ou pour opérer sur de longues queues de fin, une queue de fin doublement liée devrait être utilisée.

La macro STAILQ_SWAP échange le contenu de head1 et head2.

SINGLY-LINKED TAIL QUEUE EXAMPLE

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Singly-linked tail queue head. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* Tail queue. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Initialize the queue. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insert at the tail. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Deletion. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Deletion from the head. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Forward traversal. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Safe forward traversal. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* TailQ Deletion. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Faster TailQ Deletion. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTS

Une liste est dirigée par une structure définie au moyen de la macro LIST_HEAD. Cette structure contient un pointeur unique vers le premier élément de la liste. Les éléments sont doublement liés afin que n'importe quel élément puisse être supprimé sans parcourir toute la liste. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un élément existant ou au début de la liste. Une structure LIST_HEAD est déclarée comme suit :

LIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir et TYPE est le type des éléments à lier dans la liste. Un pointeur vers la tête de la liste peut être déclaré ultérieurement comme :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro LIST_HEAD_INITIALIZER évalue comme un initialiseur pour la liste head.

La macro LIST_CONCAT concatène la liste dirigée par head2 à la fin de la liste dirigée par head1, supprimant tous les éléments de la première liste. Son utilisation doit être évitée car elle parcourt toute la liste dirigée par head1. Si cette macro doit être utilisée dans des chemins de code très fréquentés ou pour opérer sur de longues listes, une liste doublement liée devrait être utilisée.

La macro LIST_EMPTY évalue comme vrai s'il n'y a pas d'éléments dans la liste.

La macro LIST_ENTRY déclare une structure qui relie les éléments de la liste.

La macro LIST_FIRST retourne le premier élément de la liste ou NULL si la liste est vide.

La macro LIST_FOREACH parcourt la liste dirigée par head dans le sens avant, assignant chaque élément à var.

La macro LIST_FOREACH_FROM se comporte de manière identique à LIST_FOREACH lorsque var est NULL; de lo contrario, trata var como un elemento encontrado previamente en la lista y comienza el ciclo desde var en lugar del primer elemento de la lista dirigida por head.

La macro LIST_FOREACH_SAFE parcourt la liste dirigée par head dans le sens avant, assignant chaque élément à var. Cependant, contrairement à LIST_FOREACH(), elle permet de supprimer var et de libérer son contenu à l'intérieur du cycle en toute sécurité sans interférer avec le parcours.

La macro LIST_FOREACH_FROM_SAFE se comporte de manière identique à LIST_FOREACH_SAFE lorsque var est NULL; de lo contrario, trata var como un elemento encontrado previamente en la lista y comienza el ciclo desde var en lugar del primer elemento de la lista dirigida por head.

La macro LIST_INIT initialise la liste dirigée par head.

La macro LIST_INSERT_HEAD insère le nouvel élément elm au début de la liste.

La macro LIST_INSERT_TAIL insère le nouvel élément elm à la fin de la liste.

La macro LIST_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro LIST_LAST retourne le dernier élément de la liste. Si la liste est vide, la valeur retournée est NULL.

La macro LIST_NEXT retourne l'élément suivant dans la liste, ou NULL s'il s'agit du dernier.

La macro LIST_REMOVE_AFTER supprime l'élément suivant elm de la liste. Bien qu'elle ne parcourt pas toute la liste, cette macro est différente de LIST_REMOVE.

La macro LIST_REMOVE_HEAD supprime l'élément en tête de la liste. Pour une efficacité optimale, les éléments à supprimer du début de la liste doivent utiliser explicitement cette macro au lieu de la macro générique LIST_REMOVE.

La macro LIST_REMOVE supprime l'élément elm de la liste. Son utilisation doit être évitée car elle parcourt toute la liste. Si cette macro doit être utilisée dans des chemins de code très fréquentés ou pour opérer sur de longues listes, une liste doublement liée devrait être utilisée.

La macro LIST_SWAP échange le contenu de head1 et head2.

LISTS

A list is headed by a structure defined by the LIST_HEAD macro. This structure contains a pointer to the first element in the list. The elements are singly linked so that an arbitrary element may be removed without traversing the list. New elements can be added to the list before or after an existing element, or at the head of the list. A LIST_HEAD structure is declared as follows:

LIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro LIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro LIST_EMPTY evaluates to true if there are no items on the list.

The macro LIST_ENTRY declares a structure that connects the elements in the list.

The macro LIST_FIRST returns the first item on the list or NULL if the list is empty.

The macro LIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro LIST_FOREACH_FROM behaves identically to LIST_FOREACH when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike LIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro LIST_FOREACH_FROM_SAFE behaves identically to LIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_INIT initializes the list referenced by head.

The macro LIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro LIST_INSERT_AFTER inserts the new element elm after the element listelm.

The macro LIST_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro LIST_NEXT returns the next element in the list, or NULL if this is the last.

The macro LIST_PREV returns the previous element in the list, or NULL if this is the first. List head must contain element elm.

The macro LIST_REMOVE removes the element elm from the list.

The macro LIST_SWAP swaps the contents of head1 and head2.

LIST EXAMPLE

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* List head. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* List. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Initialize the list. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Insert before. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Deletion. */
free(n2);
					/* Forward traversal. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Safe forward traversal. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* List Deletion. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);
}

n1 = LIST_FIRST(&head);			/* Faster List Deletion. */
while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
LIST_INIT(&head);

TAIL QUEUES

A tail queue is headed by a structure defined by the TAILQ_HEAD macro. This structure contains a pair of pointers, one to the first element in the tail queue and the other to the last element in the tail queue. The elements are doubly linked so that an arbitrary element can be removed without traversing the tail queue. New elements can be added to the tail queue after an existing element, before an existing element, at the head of the tail queue, or at the end of the tail queue. A TAILQ_HEAD structure is declared as follows:

TAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the tail queue. A pointer to the head of the tail queue can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro TAILQ_HEAD_INITIALIZER evaluates to an initializer for the tail queue head.

The macro TAILQ_CONCAT concatenates the tail queue headed by head2 onto the end of the one headed by head1 removing all entries from the former.

The macro TAILQ_EMPTY evaluates to true if there are no items on the tail queue.

The macro TAILQ_ENTRY declares a structure that connects the elements in the tail queue.

The macro TAILQ_FIRST returns the first item on the tail queue or NULL if the tail queue is empty.

The macro TAILQ_FOREACH traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var. var is set to NULL if the loop completes normally, or if there were no elements.

The macro TAILQ_FOREACH_FROM behaves identically to TAILQ_FOREACH when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE traverses the tail queue referenced by head in the reverse direction, assigning each element in turn to var.

The macro TAILQ_FOREACH_REVERSE_FROM behaves identically to TAILQ_FOREACH_REVERSE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macros TAILQ_FOREACH_SAFE and TAILQ_FOREACH_REVERSE_SAFE traverse the list referenced by head in the forward or reverse direction respectively, assigning each element in turn to var. However, unlike their unsafe counterparts, TAILQ_FOREACH and TAILQ_FOREACH_REVERSE make it possible to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro TAILQ_FOREACH_FROM_SAFE behaves identically to TAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE_FROM_SAFE behaves identically to TAILQ_FOREACH_REVERSE_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macro TAILQ_INIT initializes the tail queue referenced by head.

The macro TAILQ_INSERT_HEAD inserts the new element elm at the head of the tail queue.

The macro TAILQ_INSERT_TAIL inserts the new element elm at the end of the tail queue.

The macro TAILQ_INSERT_AFTER inserts the new element elm after the element listelm.

The macro TAILQ_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro TAILQ_LAST returns the last item on the tail queue. If the tail queue is empty the return value is NULL.

The macro TAILQ_NEXT returns the next item on the tail queue, or NULL if this item is the last.

The macro TAILQ_PREV returns the previous item on the tail queue, or NULL if this item is the first. Note that this macro is only valid when elm is not the first element in the queue.

The macro TAILQ_REMOVE removes the element elm from the tail queue.

The macro TAILQ_SWAP swaps the contents of head1 and head2.

DIAGNOSTICS

Lors du débogage de queue(3), il peut être utile de tracer les changements de file d'attente. Pour activer le traçage, définissez la macro QUEUE_MACRO_DEBUG_TRACE au moment de la compilation.

Il peut également être utile de corrompre les pointeurs qui ont été détachés d'une file d'attente, pour détecter l'utilisation après suppression. Pour activer la corruption des pointeurs, définissez la macro QUEUE_MACRO_DEBUG_TRASH au moment de la compilation. La macro QMD_IS_TRASHED(void *ptr) renvoie vrai si ptr a été corrompu par l'option QUEUE_MACRO_DEBUG_TRASH.
