STAILQ_FIRST(3)

STAILQ(3) Manuel de fonctions standard C STAILQ(3)

NOM

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, - implémentation de file de pointeurs simple

void STAILQ_CONCAT(STAILQ_HEAD *head1, STAILQ_HEAD *head2);

Note: Des macros identiques préfixées par SIMPLEQ au lieu de STAILQ existent; voir VERSIONS.

DESCRIPTION

Ces macros définissent et manipulent une file de pointeurs simple.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro STAILQ_HEAD().

Création

Une file de pointeurs simple est dirigée par une structure définie par la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément dans la file de pointeurs et l'autre vers le dernier élément dans la file de pointeurs. Les éléments sont liés de manière simplement chaînée pour minimiser l'espace et la surcharge de manipulation des pointeurs, bien que le temps de suppression des éléments arbitraires soit O(n). De nouveaux éléments peuvent être ajoutés à la file de pointeurs après un élément existant, au début de la file de pointeurs ou à la fin de la file de pointeurs. Une structure STAILQ_HEAD est déclarée ainsi :


STAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments qui sont liés à la file de pointeurs. Une adresse de pointeur vers la tête de la file de pointeurs peut ensuite être déclarée comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont choisis par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui relie les éléments de la file de pointeurs.

STAILQ_HEAD_INITIALIZER() évalue un initialiseur pour la file de pointeurs head.

STAILQ_INIT() initialise la file de pointeurs référencée par head.

STAILQ_EMPTY() renvoie vrai si la file de pointeurs ne contient aucun élément.

Insertion

STAILQ_INSERT_HEAD() insère le nouvel élément elm au début de la file de pointeurs.

STAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file de pointeurs.

STAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

STAILQ_FIRST() renvoie le premier élément de la file de pointeurs ou NULL si la file est vide.

STAILQ_NEXT() renvoie l'élément suivant de la file de pointeurs, ou NULL s'il s'agit du dernier.

STAILQ_FOREACH() parcourt la file de pointeurs référencée par head dans le sens avant, attribuant chaque élément à var.

Suppression

STAILQ_REMOVE() supprime l'élément elm de la file de pointeurs.

STAILQ_REMOVE_HEAD() supprime l'élément au début de la file de pointeurs. Pour une efficacité optimale, les éléments supprimés du début de la file de pointeurs devraient utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE().

Autres mécanismes

STAILQ_CONCAT() concatène la file de pointeurs dirigée par head2 à la file de pointeurs dirigée par head1, vidant la première.

VALEUR DE RETOUR

STAILQ_EMPTY() renvoie une valeur non nulle si la file est vide, et zéro si elle contient au moins un élément.

STAILQ_FIRST() et STAILQ_NEXT() renvoient respectivement un pointeur vers la structure de type TYPE.

STAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la file head.

VERSIONS

Certains systèmes BSD proposent SIMPLEQ à la place de STAILQ. Ils sont identiques, mais pour des raisons historiques, ils ont été nommés différemment sur différents systèmes BSD. STAILQ est originaire de FreeBSD, et SIMPLEQ de NetBSD. Pour des raisons de compatibilité, certains systèmes proposent les deux ensembles de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques, à l'exception du fait que l'équivalent SIMPLEQ de STAILQ_CONCAT n'est pas présent.

PROBLÈMES

STAILQ_FOREACH() n'autorise pas la suppression ou la libération de var à l'intérieur de la boucle, car cela pourrait interférer avec le parcours. STAILQ_FOREACH_SAFE(), qui est présent sur les systèmes BSD mais pas sur glibc, résout cette limitation en permettant à var d'être retiré de la liste et libéré à l'intérieur de la boucle sans interférer avec le parcours.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File de pointeurs simple */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* File de pointeurs simple */
    STAILQ_INIT(&head);                     /* Initialise la file */
    n1 = malloc(sizeof(struct entry));      /* Insertion en tête */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion en queue */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression de la tête */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
}

BIBLIOTHÈQUE

STAILQ

SYNTAXE

/* Parcours avant */
STAILQ_FOREACH(np, &head, entries)
    printf("%i\n", np->data);

/* Suppression de TailQ */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
    n2 = STAILQ_NEXT(n1, entries);
    free(n1);
    n1 = n2;
}
STAILQ_INIT(&head);
exit(EXIT_SUCCESS);

DESCRIPTION

Le code effectue un parcours avant de la structure STAILQ, imprimant la valeur de data de chaque nœud. De plus, il supprime les nœuds de la structure de manière itérative et initialise la structure.

VALEUR DE RETOUR

La valeur de retour est NULL en cas d'erreur.
