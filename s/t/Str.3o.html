Expressions régulières et traitement de chaînes de caractères de haut niveau

Expressions régulières

La bibliothèque Str fournit des expressions régulières sur des séquences d'octets. Elle est, en général, impropre à la correspondance de caractères Unicode.

type regexp

Le type des expressions régulières compilées.

val regexp : string -> regexp

Compile une expression régulière. Les constructions suivantes sont reconnues :

- . Correspond à n'importe quel caractère sauf le saut de ligne.

- * (post-fixe) Correspond à l'expression précédente zéro, une ou plusieurs fois.

- + (post-fixe) Correspond à l'expression précédente une ou plusieurs fois.

- ? (post-fixe) Correspond à l'expression précédente une fois ou pas du tout.

- [..] Ensemble de caractères. Les plages sont dénotées avec - , comme dans [a-z] . Un ^ initial, comme dans [^0-9] , complète l'ensemble. Pour inclure un caractère ] dans un ensemble, faites-en le premier caractère de l'ensemble. Pour inclure un caractère - dans un ensemble, faites-en le premier ou le dernier caractère de l'ensemble.

- ^ Correspond au début de ligne : soit au début de la chaîne correspondante, soit juste après un caractère '\n'.

- $ Correspond à la fin de ligne : soit à la fin de la chaîne correspondante, soit juste avant un caractère '\n'.

- \| (infixe) Alternative entre deux expressions.

- \(..\) Groupement et nommage de l'expression englobée.

- \1 Le texte correspondant à la première expression \(...\) ( \2 pour la deuxième expression, et ainsi de suite jusqu'à \9 ).

- \b Correspond aux limites de mots.

- \ Met en échappement les caractères spéciaux. Les caractères spéciaux sont $^\.*+?[] .

Dans les expressions régulières, vous utiliserez souvent des caractères antislash ; il est plus facile d'utiliser une chaîne littérale entre guillemets {|...|} pour éviter d'avoir à échapper les antislashs.

Par exemple, l'expression suivante :

let r = Str.regexp {|hello \([A-Za-z]+\)|} in
      Str.replace_first r {|\1|} "hello world"
renvoie la chaîne "world" .

Si vous voulez une expression régulière qui corresponde à un antislash littéral, vous devez le doubler : Str.regexp {|\\|} .

Vous pouvez également utiliser des littéraux de chaîne classiques "..." , mais vous devrez échapper les antislashs. L'exemple ci-dessus peut être réécrit avec un littéral de chaîne classique comme :

let r = Str.regexp "hello \\([A-Za-z]+\\)" in
      Str.replace_first r "\\1" "hello world"

Et l'expression régulière pour faire correspondre un antislash devient un quadruple antislash : Str.regexp "\\\\" .

val regexp_case_fold : string -> regexp

Identique à regexp , mais l'expression compilée fera correspondre le texte de manière insensible à la casse : les lettres majuscules et minuscules seront considérées comme équivalentes.

val quote : string -> string

Str.quote s renvoie une chaîne d'expression régulière qui correspond exactement à s et rien d'autre.

val regexp_string : string -> regexp

Str.regexp_string s renvoie une expression régulière qui correspond exactement à s et rien d'autre.

val regexp_string_case_fold : string -> regexp

Str.regexp_string_case_fold est similaire à Str.regexp_string , mais l'expression régulière correspond de manière insensible à la casse.

Correspondance et recherche de chaînes

val string_match : regexp -> string -> int -> bool

string_match r s start teste si une sous-chaîne de s qui commence à la position start correspond à l'expression régulière r . Le premier caractère d'une chaîne a la position 0 , comme d'habitude.

val search_forward : regexp -> string -> int -> int

search_forward r s start recherche dans la chaîne s une sous-chaîne correspondant à l'expression régulière r . La recherche commence à la position start et progresse vers la fin de la chaîne. Renvoie la position du premier caractère de la sous-chaîne correspondante.

Lève Not_found si aucune sous-chaîne ne correspond.

val search_backward : regexp -> string -> int -> int

search_backward r s last recherche dans la chaîne s une sous-chaîne correspondant à l'expression régulière r . La recherche considère d'abord les sous-chaînes qui commencent à la position last et progresse vers le début de la chaîne. Renvoie la position du premier caractère de la sous-chaîne correspondante.

Lève Not_found si aucune sous-chaîne ne correspond.

val string_partial_match : regexp -> string -> int -> bool

Similaire à Str.string_match , mais renvoie également vrai si la chaîne d'argument est un préfixe d'une chaîne qui correspond. Cela inclut le cas d'une correspondance complète réelle.

val matched_string : string -> string

matched_string s renvoie la sous-chaîne de s qui a été mise en correspondance par le dernier appel à l'une des fonctions de correspondance ou de recherche suivantes :

- Str.string_match

- Str.search_forward

- Str.search_backward

- Str.string_partial_match

- Str.global_substitute

- Str.substitute_first

à condition qu'aucun des appels de fonctions suivants n'ait été effectué entre-temps :

- Str.global_replace

- Str.replace_first

- Str.split

- Str.bounded_split

- Str.split_delim

- Str.bounded_split_delim

- Str.full_split

- Str.bounded_full_split

Note : dans le cas de global_substitute et substitute_first , un appel à matched_string n'est valide qu'à l'intérieur de l'argument subst , et non après le retour de global_substitute ou substitute_first .

L'utilisateur doit s'assurer que le paramètre s est la même chaîne qui a été passée à la fonction de correspondance ou de recherche.

val match_beginning : unit -> int

match_beginning() renvoie la position du premier caractère de la sous-chaîne qui a été mise en correspondance par le dernier appel à une fonction de correspondance ou de recherche (voir Str.matched_string pour les détails).

val match_end : unit -> int

match_end() renvoie la position du caractère suivant le dernier caractère de la sous-chaîne qui a été mise en correspondance par le dernier appel à une fonction de correspondance ou de recherche (voir Str.matched_string pour les détails).

val matched_group : int -> string -> string

matched_group n s renvoie la sous-chaîne de s qui a été mise en correspondance par le n -ième groupe \(...\) de l'expression régulière qui a été mise en correspondance par le dernier appel à une fonction de correspondance ou de recherche (voir Str.matched_string pour les détails). Lorsque n vaut 0 , elle renvoie la sous-chaîne mise en correspondance par l'expression régulière entière. L'utilisateur doit s'assurer que le paramètre s est la même chaîne qui a été passée à la fonction de correspondance ou de recherche.

Lève Not_found si le n -ième groupe de l'expression régulière n'a pas été mis en correspondance. Cela peut se produire avec des groupes à l'intérieur d'alternatives \| , d'options ? ou de répétitions * . Par exemple, la chaîne vide correspondra à \(a\)* , mais matched_group 1 "" lèvera Not_found car le premier groupe lui-même n'a pas été mis en correspondance.

val group_beginning : int -> int

group_beginning n renvoie la position du premier caractère de la sous-chaîne qui a été mise en correspondance par le n -ième groupe de l'expression régulière qui a été mise en correspondance par le dernier appel à une fonction de correspondance ou de recherche (voir Str.matched_string pour les détails).

Lève Not_found si le n -ième groupe de l'expression régulière n'a pas été mis en correspondance.

Lève Invalid_argument s'il y a moins de n groupes dans l'expression régulière.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

val group_end : int -> int

group_end n retourne la position du caractère suivant le dernier caractère de la sous-chaîne qui a été correspondant par le n ème groupe de l'expression régulière qui a été correspondant par le dernier appel à une fonction de correspondance ou de recherche (voir Str.matched_string pour plus de détails).

Raises Not_found si le n ème groupe de l'expression régulière n'a pas été correspondant.

Raises Invalid_argument s'il y a moins de n groupes dans l'expression régulière.

Remplacement

val global_replace : regexp -> string -> string -> string

global_replace regexp templ s retourne une chaîne identique à s , sauf que toutes les sous-chaînes de s qui correspondent à regexp ont été remplacées par templ . Le modèle de remplacement templ peut contenir \1 , \2 , etc. ; ces séquences seront remplacées par le texte correspondant au groupe correspondant dans l'expression régulière. \0 représente le texte correspondant à l'expression régulière entière.

val replace_first : regexp -> string -> string -> string

Identique à Str.global_replace , sauf que seule la première sous-chaîne correspondant à l'expression régulière est remplacée.

val global_substitute : regexp -> (string -> string) -> string -> string

global_substitute regexp subst s retourne une chaîne identique à s , sauf que toutes les sous-chaînes de s qui correspondent à regexp ont été remplacées par le résultat de la fonction subst . La fonction subst est appelée une fois pour chaque sous-chaîne correspondante, et reçoit s (le texte entier) comme argument.

val substitute_first : regexp -> (string -> string) -> string -> string

Identique à Str.global_substitute , sauf que seule la première sous-chaîne correspondant à l'expression régulière est remplacée.

val replace_matched : string -> string -> string

replace_matched repl s retourne le texte de remplacement repl dans lequel \1 , \2 , etc. ont été remplacés par le texte correspondant aux groupes correspondants dans l'expression régulière qui a été correspondant par le dernier appel à une fonction de correspondance ou de recherche (voir Str.matched_string pour plus de détails). s doit être la même chaîne qui a été passée à la fonction de correspondance ou de recherche.

Division

val split : regexp -> string -> string list

split r s divise s en sous-chaînes, en prenant comme délimiteurs les sous-chaînes qui correspondent à r , et retourne la liste des sous-chaînes. Par exemple, split (regexp "[ \t]+") s divise s en mots séparés par des blancs. Une occurrence du délimiteur au début ou à la fin de la chaîne est ignorée.

val bounded_split : regexp -> string -> int -> string list

Identique à Str.split , mais divise en au plus n sous-chaînes, où n est le paramètre entier supplémentaire.

val split_delim : regexp -> string -> string list

Identique à Str.split mais les occurrences du délimiteur au début et à la fin de la chaîne sont reconnues et retournées sous forme de chaînes vides dans le résultat. Par exemple, split_delim (regexp " ") " abc " retourne [""; "abc"; ""] , tandis que split avec les mêmes arguments retourne ["abc"] .

val bounded_split_delim : regexp -> string -> int -> string list

Identique à Str.bounded_split , mais les occurrences du délimiteur au début et à la fin de la chaîne sont reconnues et retournées sous forme de chaînes vides dans le résultat.

type split_result =
| Text of string
| Delim of string

val full_split : regexp -> string -> split_result list

Identique à Str.split_delim , mais retourne également les délimiteurs ainsi que les sous-chaînes contenues entre les délimiteurs. Les premiers sont étiquetés Delim dans la liste de résultats ; les seconds sont étiquetés Text . Par exemple, full_split (regexp "[{}]") "{ab}" retourne [Delim "{"; Text "ab"; Delim "}"] .

val bounded_full_split : regexp -> string -> int -> split_result list

Identique à Str.bounded_split_delim , mais retourne les délimiteurs ainsi que les sous-chaînes contenues entre les délimiteurs. Les premiers sont étiquetés Delim dans la liste de résultats ; les seconds sont étiquetés Text .

Extraction de sous-chaînes

val string_before : string -> int -> string

string_before s n retourne la sous-chaîne de tous les caractères de s qui précèdent la position n (excluant le caractère à la position n ).

val string_after : string -> int -> string

string_after s n retourne la sous-chaîne de tous les caractères de s qui suivent la position n (incluant le caractère à la position n ).

val first_chars : string -> int -> string

first_chars s n retourne les n premiers caractères de s . C'est la même fonction que Str.string_before .

val last_chars : string -> int -> string

last_chars s n retourne les n derniers caractères de s .
