Module Type

Témoin d'égalité de types

type (_, _) eq =
| Equal : ('a, 'a) eq

Le but de eq est de représenter des égalités de types qui ne sont pas autrement connues par le vérificateur de types (par exemple, parce qu'elles dépendent de données dynamiques).

Une valeur de type (a, b) eq représente le fait que les types a et b sont égaux.

Si l'on possède une valeur eq : (a, b) Type.eq qui prouve que les types a et b sont égaux, on peut l'utiliser pour convertir une valeur de type a en une valeur de type b en effectuant une correspondance de motifs sur Equal :

      let cast (type a) (type b) (Equal : (a, b) Type.eq) (a : a) : b = a

À l'exécution, cette fonction retourne simplement son second argument sans modification.

Identificateurs de types

module Id : sig end

Identificateurs de types.

Un identificateur de type est une valeur qui désigne un type. Étant donnés deux identificateurs de types, ils peuvent être testés avec Type.Id.provably_equal pour prouver qu'ils désignent le même type. Notez que :

-Des identificateurs inégaux n'impliquent pas des types inégaux : un même type peut être désigné par plusieurs identificateurs.

-Les identificateurs de types peuvent être sérialisés (marshalled), mais ils obtiennent une nouvelle identité distincte lors de la désérialisation, donc les égalités sont perdues.

Voir un exemple de Type.Id d'utilisation.
