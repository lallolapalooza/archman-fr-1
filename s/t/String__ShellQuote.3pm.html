NOM

String::ShellQuote - échappe les chaînes pour les passer à travers le shell

SYNTAXE

$string = shell_quote @liste;
$string = shell_quote_best_effort @liste;
$string = shell_comment_quote $string;

DESCRIPTION

Ce module contient quelques fonctions utiles pour échapper des chaînes qui vont passer par le shell ou un objet similaire à un shell.

shell_quote [chaîne]...
shell_quote échappe les chaînes afin qu'elles puissent être passées à travers le shell. Chaque chaîne est échappée de telle sorte que le shell la transmettra comme un seul argument et sans interprétation supplémentaire. Si aucune chaîne n'est fournie, une chaîne vide est renvoyée.

Si une chaîne ne peut pas être échappée en toute sécurité, shell_quote croakera.

shell_quote_best_effort [chaîne]...
C'est similaire à shell_quote, sauf que si la chaîne ne peut pas être échappée en toute sécurité, elle fait de son mieux et renvoie le résultat, au lieu de mourir.
shell_comment_quote [chaîne]
shell_comment_quote échappe la chaîne afin qu'elle puisse être incluse en toute sécurité dans un commentaire de style shell (l'algorithme actuel consiste à placer un caractère dièse après tout retour à la ligne dans la chaîne).

Cette routine pourrait être modifiée pour accepter plusieurs arguments de chaîne à l'avenir. Je ne l'ai pas encore fait car je ne sais pas si les chaînes doivent être jointes avec des blancs ($") ou rien ($,). Exprimez votre vote dès aujourd'hui ! Assurez-vous de justifier votre réponse.

EXEMPLES

$cmd = 'fuser 2>/dev/null ' . shell_quote @fichiers;
@pids = split ' ', `$cmd`;
print CFG "# Configuré par : ",
            shell_comment_quote($ENV{LOGNAME}), "\n";

BOGUES

Seul l'échappement pour le shell Bourne est pris en charge. J'aimerais en ajouter pour d'autres shells (en particulier cmd.exe), mais je ne les connais pas. Ce serait d'une grande aide si quelqu'un fournissait les détails.
