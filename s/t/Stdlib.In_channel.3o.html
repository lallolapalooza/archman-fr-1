Modes d'ouverture pour In_channel.open_gen.

val stdin : t

L'entrée standard du processus.

val open_bin : string -> t

Ouvre le fichier nommé pour lecture, et retourne un nouveau canal d'entrée sur ce fichier, positionné au début du fichier.

val open_text : string -> t

Est dans le même style que In_channel.open_bin, mais ouvre le fichier en mode texte, ce qui implique que le nouveau texte est converti lors de la lecture. Sur les systèmes d'exploitation qui ne distinguent pas le mode texte du mode binaire, cette fonction se comporte comme In_channel.open_bin.

val open_gen : open_flag list -> int -> string -> t

Ouvre le fichier nommé pour lecture, comme décrit ci-dessus. Les arguments supplémentaires mode et perm spécifient le mode d'ouverture et les permissions du fichier. In_channel.open_text et In_channel.open_bin sont des cas particuliers de cette fonction.

val with_open_bin : string -> (t -> 'a) -> 'a

Ouvre un canal ic sur le fichier fn et retourne f (ic). Après que f ait retourné une valeur ou levé une exception, le canal ic est garanti d'être fermé.

val with_open_text : string -> (t -> 'a) -> 'a

Est similaire à In_channel.with_open_bin, mais le canal est ouvert en mode texte (voir In_channel.open_text).

val with_open_gen : open_flag list -> int -> string -> (t -> 'a) -> 'a

Est similaire à In_channel.with_open_bin, mais peut spécifier le mode d'ouverture et les permissions du fichier, dans le cas où le fichier doit être créé (voir In_channel.open_gen).

val close : t -> unit

Ferme le canal donné. Les fonctions de lecture lèvent une exception Sys_error lorsqu'elles sont appliquées à un canal d'entrée fermé, à l'exception de In_channel.close, qui ne fait rien lorsqu'elle est appliquée à un canal déjà fermé.

val close_noerr : t -> unit

Est identique à In_channel.close, mais ignore toutes les erreurs.

Entrée

val input_char : t -> char option

Lit un caractère du canal d'entrée donné. Retourne None si plus aucun caractère n'est disponible.

val input_byte : t -> int option

Est identique à In_channel.input_char, mais retourne l'entier 8 bits représentant le caractère. Retourne None si la fin du fichier a été atteinte.

val input_line : t -> string option

input_line ic lit des caractères du canal ic jusqu'à un caractère de nouvelle ligne ou la fin du fichier. Retourne la chaîne de caractères lus, sans le caractère de nouvelle ligne (s'il existe). Retourne None si la fin du fichier a été atteinte. En particulier, ce sera le cas si la dernière ligne d'entrée est vide.

Une nouvelle ligne est le caractère \n, sauf si le fichier est ouvert en mode texte et que Sys.win32 est true, auquel cas c'est la séquence de caractères \r\n.

val really_input_string : t -> int -> string option

really_input_string ic len lit len caractères du canal ic et retourne une nouvelle chaîne contenant ces caractères. Retourne None si la fin du fichier a été atteinte avant d'avoir lu len caractères.

Si le même canal est lu simultanément par plusieurs threads, la chaîne retournée ne garantit pas qu'elle contienne des caractères d'entrée consécutifs.

val input_all : t -> string

input_all ic lit toutes les données restantes du canal ic.

Si le même canal est lu simultanément par plusieurs threads, la chaîne retournée ne garantit pas qu'elle contienne des caractères d'entrée consécutifs.

val input_lines : t -> string list

input_lines ic lit des lignes en utilisant In_channel.input_line jusqu'à la fin du fichier. Retourne une liste de toutes les lignes lues, dans l'ordre où elles ont été lues. Les caractères de nouvelle ligne qui terminent les lignes ne sont pas inclus dans les chaînes retournées. Les lignes vides produisent des chaînes vides.

Entrée avancée

val input : t -> bytes -> int -> int -> int

input ic buf pos len lit jusqu'à len caractères du canal ic, les stockant dans la séquence d'octets buf, en commençant à la position pos. Retourne le nombre de caractères lus, entre 0 et len (inclus). Un retour de 0 indique que la fin du fichier a été atteinte.

Utilisez In_channel.really_input pour lire exactement len caractères.

Raises Invalid_argument si pos et len ne désignent pas un intervalle valide de buf.

val input_bigarray : t -> ('a, Bigarray.int8_unsigned_elt, Bigarray.c_layout) Bigarray.Array1.t -> int -> int -> int

Est identique à In_channel.input, mais lit les données dans un bigarray.

val really_input : t -> bytes -> int -> int -> unit option

really_input ic buf pos len lit len caractères du canal ic, les stockant dans la séquence d'octets buf, en commençant à la position pos. Retourne None si la fin du fichier a été atteinte avant d'avoir lu len caractères.

Si le même canal est lu simultanément par plusieurs threads, les octets lus par really_input ne sont pas garantis d'être consécutifs.

Raises Invalid_argument si pos et len ne désignent pas un intervalle valide de buf.

val really_input_bigarray : t -> ('a, Bigarray.int8_unsigned_elt, Bigarray.c_layout) Bigarray.Array1.t -> int -> int -> unit option

Est identique à In_channel.really_input, mais lit les données dans un bigarray.

Depuis 5.2

val fold_lines : ('acc -> string -> 'acc) -> 'acc -> t -> 'acc

fold_lines f init ic lit des lignes du canal ic en utilisant In_channel.input_line jusqu'à la fin du fichier, et passe chaque ligne à la fonction f dans le style d'un fold. Plus précisément, si les lignes lues sont l1, ..., lN, fold_lines f init ic calcule f (... (f (f init l1) l2) ...) lN. Si f n'a pas d'effets de bord, ceci est équivalent à List.fold_left f init (In_channel.input_lines ic), mais est plus efficace car il ne construit pas la liste de toutes les lignes lues.

Attributs

val length : t -> int64

Retourne la taille (nombre de caractères) du fichier régulier sur lequel le canal donné est ouvert. Si le canal est ouvert sur un fichier qui n'est pas un fichier régulier, le résultat n'a pas de sens. La taille retournée ne prend pas en compte les traductions de fin de ligne qui peuvent être effectuées lors de la lecture depuis un canal ouvert en mode texte.

val set_binary_mode : t -> bool -> unit

set_binary_mode ic true règle le canal ic en mode binaire  : aucune traduction n'a lieu pendant l'entrée.

set_binary_mode ic false règle le canal ic en mode texte  : selon le système d'exploitation, certaines traductions peuvent avoir lieu pendant l'entrée. Par exemple, sous Windows, les fins de ligne seront traduites de \r\n en \n.

Cette fonction n'a aucun effet sur les systèmes d'exploitation qui ne font pas de distinction entre le mode texte et le mode binaire.

val is_binary_mode : t -> bool

is_binary_mode ic retourne si le canal ic est en mode binaire (voir In_channel.set_binary_mode).

val isatty : t -> bool

isatty ic vaut true si ic fait référence à un terminal ou à une fenêtre de console, false sinon.
