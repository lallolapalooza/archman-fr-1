Description

Ces macros définissent et opèrent sur des files de listes chaînées simples.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée avec la macro STAILQ_HEAD().

Création

Une file de liste chaînée simple est dirigée par une structure définie avec la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont simplement chaînés pour minimiser l'espace et la surcharge de gestion des pointeurs, mais avec un coût de O(n) pour la suppression d'éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, en tête de file, ou en fin de file. Une structure STAILQ_HEAD est déclarée comme suit :


STAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir et struct TYPE est le type des éléments à chaîner dans la file. Un pointeur vers la tête de la file peut être déclaré plus tard comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui relie les éléments de la file.

STAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file head.

STAILQ_INIT() initialise la file référencée par head.

STAILQ_EMPTY() évalue à vrai si la file ne contient aucun élément.

Insertion

STAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de file.

STAILQ_INSERT_TAIL() insère le nouvel élément elm en fin de file.

STAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

STAILQ_FIRST() retourne le premier élément de la file ou NULL si la file est vide.

STAILQ_NEXT() retourne l'élément suivant de la file, ou NULL si cet élément est le dernier.

STAILQ_FOREACH() parcourt la file référencée par head dans la direction avant, attribuant chaque élément à var à tour de rôle.

Suppression

STAILQ_REMOVE() supprime l'élément elm de la file.

STAILQ_REMOVE_HEAD() supprime l'élément en tête de file. Pour une efficacité optimale, les éléments supprimés de la tête de file devraient utiliser explicitement cette macro plutôt que la macro générale STAILQ_REMOVE().

Autres fonctionnalités

STAILQ_CONCAT() concaténera la file dirigée par head2 à la fin de la file dirigée par head1, vidant la première.

Valeur de retour

STAILQ_EMPTY() retourne non zéro si la file est vide, et zéro si elle contient au moins un élément.

STAILQ_FIRST() et STAILQ_NEXT() retournent un pointeur vers la première ou la suivante structure TYPE, respectivement.

STAILQ_HEAD_INITIALIZER() retourne un initialiseur qui peut être assigné à la file head.

Versions

Certains systèmes BSD proposent SIMPLEQ à la place de STAILQ. Ils sont identiques, mais pour des raisons historiques, ils ont été nommés différemment sur les différents systèmes BSD. STAILQ vient de FreeBSD, et SIMPLEQ de NetBSD. Pour des raisons de compatibilité, certains systèmes offrent les deux ensembles de macros. glibc propose à la fois STAILQ et SIMPLEQ, qui sont identiques à l'exception que l'équivalent SIMPLEQ de STAILQ_CONCAT est omis.

Bugs

STAILQ_FOREACH() ne permet pas de supprimer ou de libérer var à l'intérieur de la boucle, car cela pourrait interférer avec le parcours. STAILQ_FOREACH_SAFE(), présent sur les systèmes BSD mais pas sur glibc, corrige cette limitation en permettant à var d'être supprimé de la liste et libéré dans la boucle sans interférer avec le parcours.

Normes

BSD.

Historique

4.4BSD.

Exemples

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File de liste chaînée simple */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Tête de file de liste chaînée simple */
    STAILQ_INIT(&head);                     /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insérer en tête */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insérer en fin */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression de la tête */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }

NOM

STAILQ_FOREACH

BIBLIOTHÈQUE

STAILQ

SYNTAXIS

STAILQ_FOREACH(np, &head, entries) printf("%i\n", np->data); n1 = STAILQ_FIRST(&head); while (n1 != NULL) n2 = STAILQ_NEXT(n1, entries); free(n1); n1 = n2; STAILQ_INIT(&head); exit(EXIT_SUCCESS);

DESCRIPTION

Parcourt la liste des entrées vers l'avant.

VALEUR DE RETOUR

Ne retourne aucune valeur.
