Module Stack
: sig end

Piles (dernier entré, premier sorti).

Ce module implémente des piles (LIFO), avec modification en place.

Alert accès_non_synchronisé. Les accès non synchronisés aux piles sont une erreur de programmation.

Accès non synchronisés

Les accès non synchronisés à une pile peuvent entraîner un état invalide de la file. Ainsi, les accès concurrents aux piles doivent être synchronisés (par exemple avec un Mutex.t ).

type !'a t

Le type des piles contenant des éléments de type 'a .

exception Empty

Levée lorsque Stack.pop ou Stack.top est appliqué à une pile vide.

val create : unit -> 'a t

Retourne une nouvelle pile, initialement vide.

val push : 'a -> 'a t -> unit

push x s ajoute l'élément x au sommet de la pile s .

val pop : 'a t -> 'a

pop s retire et retourne l'élément au sommet de la pile s , ou lève Stack.Empty si la pile est vide.

val pop_opt : 'a t -> 'a option

pop_opt s retire et retourne l'élément au sommet de la pile s , ou retourne None si la pile est vide.

val clear : 'a t -> unit

Supprime tous les éléments d'une pile.

val copy : 'a t -> 'a t

Retourne une copie de la pile donnée.

val is_empty : 'a t -> bool

Retourne true si la pile donnée est vide, false sinon.

val length : 'a t -> int

Retourne le nombre d'éléments dans une pile. Complexité temporelle O(1)

val iter : ('a -> unit) -> 'a t -> unit

iter f s applique f successivement à tous les éléments de s , de l'élément au sommet de la pile à l'élément à la base de la pile. La pile elle-même n'est pas modifiée.

val fold : ('acc -> 'a -> 'acc) -> 'acc -> 'a t -> 'acc

fold f accu s est équivalent à (f (... (f (f accu x1) x2) ...) xn) où x1 est le sommet de la pile, x2 le deuxième élément, et xn l'élément de base. La pile n'est pas modifiée.
