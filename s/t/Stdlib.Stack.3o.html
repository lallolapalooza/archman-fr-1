Module Stack
: (module Stdlib__Stack)

Accès non synchronisés

Les accès non synchronisés à une pile peuvent entraîner un état de file invalide. Par conséquent, les accès concurrents aux piles doivent être synchronisés (par exemple avec un Mutex.t ).

type !'a t

Le type des piles contenant des éléments de type 'a .

exception Empty

Levée lorsque Stack.pop ou Stack.top est appliqué à une pile vide.

val create : unit -> 'a t

Retourne une nouvelle pile, initialement vide.

val push : 'a -> 'a t -> unit

push x s ajoute l'élément x en haut de la pile s .

val pop : 'a t -> 'a

pop s supprime et retourne l'élément supérieur de la pile s , ou lève Stack.Empty si la pile est vide.

val pop_opt : 'a t -> 'a option

pop_opt s supprime et retourne l'élément supérieur de la pile s , ou retourne None si la pile est vide.

val drop : 'a t -> unit

drop s supprime l'élément supérieur de la pile s , ou lève Stack.Empty si la pile est vide.

Depuis 5.1

val top : 'a t -> 'a

top s retourne l'élément supérieur de la pile s , ou lève Stack.Empty si la pile est vide.

val top_opt : 'a t -> 'a option

top_opt s retourne l'élément supérieur de la pile s , ou None si la pile est vide.

Depuis 4.08

val clear : 'a t -> unit

Supprime tous les éléments d'une pile.

val copy : 'a t -> 'a t

Retourne une copie de la pile donnée.

val is_empty : 'a t -> bool

Retourne true si la pile donnée est vide, false sinon.

val length : 'a t -> int

Retourne le nombre d'éléments dans une pile. Complexité temporelle O(1)

val iter : ('a -> unit) -> 'a t -> unit

iter f s applique f tour à tour à tous les éléments de s , de l'élément en haut de la pile à l'élément en bas de la pile. La pile elle-même n'est pas modifiée.

val fold : ('acc -> 'a -> 'acc) -> 'acc -> 'a t -> 'acc

fold f accu s est (f (... (f (f accu x1) x2) ...) xn) où x1 est le sommet de la pile, x2 le deuxième élément, et xn l'élément du bas. La pile n'est pas modifiée.
