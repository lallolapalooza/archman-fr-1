Un alias pour le type des listes.

valeur length : list 'a -> int

Retourne la longueur (nombre d'éléments) de la liste donnée.

valeur compare_lengths : list 'a -> list 'b -> int

Compare les longueurs de deux listes. compare_lengths l1 l2 est équivalent à compare (length l1) (length l2), sauf que le calcul s'arrête après avoir atteint la fin de la liste la plus courte.

Depuis 4.05

valeur compare_length_with : list 'a -> int -> int

Compare la longueur d'une liste avec un entier. compare_length_with l len est équivalent à compare (length l) len, sauf que le calcul s'arrête après un maximum de len itérations sur la liste.

Depuis 4.05

valeur is_empty : list 'a -> bool

is_empty l est vrai si et seulement si l n'a aucun élément. C'est équivalent à compare_length_with l 0 = 0.

valeur append : list 'a -> list 'a -> list 'a

append l0 l1 ajoute l1 à l0. Fonction équivalente à l'opérateur infixe @.

Depuis 5.1 cette valeur est récursive terminale.

valeur rev_append : list 'a -> list 'a -> list 'a

rev_append l1 l2 inverse l1 et le concatène avec l2. C'est équivalent à (List.rev l1) @ l2.

valeur concat : list 'a list -> list 'a

Concatène une liste de listes. Les éléments de l'entrée sont tous concaténés (dans le même ordre) pour produire le résultat. N'est pas récursive terminale (longueur de l'entrée + longueur de la sous-liste la plus longue).

valeur flatten : list 'a list -> list 'a

Est équivalent à List.concat. N'est pas récursive terminale (longueur de l'entrée + longueur de la sous-liste la plus longue).

Comparaison

valeur equal : ('a -> 'a -> bool) -> list 'a -> list 'a -> bool

equal eq [a1; ...; an] [b1; ...; bm] est vrai lorsque les deux listes d'entrée ont la même longueur, et que pour chaque paire d'éléments ai et bi à la même position, on a eq ai bi.

Note : eq peut être appelé même si les listes ont des longueurs différentes. Si vous savez que votre fonction d'égalité est coûteuse, vous pourriez vouloir vérifier List.compare_lengths en premier.

Depuis 4.12

valeur compare : ('a -> 'a -> int) -> list 'a -> list 'a -> int

compare cmp [a1; ...; an] [b1; ...; bm] effectue une comparaison lexicographique des deux listes d'entrée, en utilisant une interface similaire à compare :

- a1 :: l1 est inférieur à a2 :: l2 (résultat négatif) si a1 est inférieur à a2, ou s'ils sont égaux (résultat 0) et que l1 est inférieur à l2

- la liste vide [] est inférieure aux listes non vides

Note : cmp est appelé même si les listes ont des longueurs différentes.

Itérateurs

valeur iter : ('a -> unit) -> list 'a -> unit

iter f [a1; ...; an] applique la fonction f à chaque élément de la liste [a1; ...; an]. C'est équivalent à f a1; f a2; ...; f an.

valeur iteri : (int -> 'a -> unit) -> list 'a -> unit

Est équivalent à List.iter, mais la fonction est appliquée à l'index de l'élément comme premier argument (en commençant par 0), et à l'élément comme deuxième argument.

valeur map : ('a -> 'b) -> list 'a -> list 'b

map f [a1; ...; an] applique la fonction f à chaque élément de la liste [a1; ...; an] et construit la liste [f a1; ...; f an] avec les résultats de f.

valeur mapi : (int -> 'a -> 'b) -> list 'a -> list 'b

Est équivalent à List.map, mais la fonction est appliquée à l'index de l'élément comme premier argument (en commençant par 0), et à l'élément comme deuxième argument.

Scan de liste

val for_all : ('a -> bool) -> 'a list -> bool

for_all f [a1; ...; an] vérifie si tous les éléments de la liste satisfont le prédicat f . C'est-à-dire, il retourne (f a1) && (f a2) && ... && (f an) pour une liste non vide et true si la liste est vide.

val exists : ('a -> bool) -> 'a list -> bool

exists f [a1; ...; an] vérifie si au moins un élément de la liste satisfait le prédicat f . C'est-à-dire, il retourne (f a1) || (f a2) || ... || (f an) pour une liste non vide et false si la liste est vide.

val for_all2 : ('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Identique à List.for_all , mais pour un prédicat à deux arguments.

Lève Invalid_argument si les deux listes ont des longueurs différentes.

val exists2 : ('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Identique à List.exists , mais pour un prédicat à deux arguments.

Lève Invalid_argument si les deux listes ont des longueurs différentes.

val mem : 'a -> 'a list -> bool

mem a set est vrai si et seulement si a est égal à un élément de set .

val memq : 'a -> 'a list -> bool

Identique à List.mem , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les éléments de la liste.

Recherche dans une liste

val find : ('a -> bool) -> 'a list -> 'a

find f l retourne le premier élément de la liste l qui satisfait le prédicat f .

Lève Not_found s'il n'y a pas de valeur satisfaisant f dans la liste l .

val find_opt : ('a -> bool) -> 'a list -> 'a option

find f l retourne le premier élément de la liste l qui satisfait le prédicat f . Retourne None s'il n'y a pas de valeur satisfaisant f dans la liste l .

find_index f xs retourne Some i , où i est l'indice du premier élément de la liste xs qui satisfait f x , s'il existe un tel élément.

Manipulation de liste

val take : int -> 'a list -> 'a list

take n l retourne le préfixe de l de longueur n , ou une copie de l si n > length l . C'est la liste vide si n est négatif.

Avertissement. Dans la version 5.3 uniquement, cette fonction lève Invalid_argument pour les valeurs négatives de n .

Depuis 5.3

val drop : int -> 'a list -> 'a list

drop n l retourne le suffixe de l après n éléments, ou [] si n > length l . C'est l si n est négatif.

Avertissement. Dans la version 5.3 uniquement, cette fonction lève Invalid_argument pour les valeurs négatives de n .

Depuis 5.3

val take_while : ('a -> bool) -> 'a list -> 'a list

take_while p l est le plus long préfixe (éventuellement vide) de l ne contenant que des éléments satisfaisant p .

Depuis 5.3

val drop_while : ('a -> bool) -> 'a list -> 'a list

drop_while p l est le plus long suffixe (éventuellement vide) de l commençant au premier élément ne satisfaisant pas p .

Depuis 5.3

val partition : ('a -> bool) -> 'a list -> 'a list * 'a list

partition f l retourne une paire de listes (l1, l2) , où l1 est la liste de tous les éléments de l qui satisfont le prédicat f , et l2 est la liste de tous les éléments de l qui ne satisfont pas f . L'ordre des éléments dans la liste d'entrée est préservé.

val partition_map : ('a -> ('b, 'c) Either.t) -> 'a list -> 'b list * 'c list

partition_map f l retourne une paire de listes (l1, l2) telle que, pour chaque élément x de la liste d'entrée l :

-si f x est Left y1 , alors y1 est dans l1 , et

-si f x est Right y2 , alors y2 est dans l2 .

Les éléments de sortie sont inclus dans l1 et l2 dans le même ordre relatif que les éléments d'entrée correspondants dans l .

En particulier, partition_map (fun x -> if f x then Left x else Right x) l est équivalent à partition f l .

Listes d'association

val assoc : 'a -> ('a * 'b) list -> 'b

assoc a l l retourne la valeur associée à la clé a dans la liste de paires l . C'est-à-dire, assoc a [ ...; (a,b); ...] = b si (a,b) est la première association de a dans la liste l .

Lève Not_found s'il n'y a pas de valeur associée à a dans la liste l .

val assoc_opt : 'a -> ('a * 'b) list -> 'b option

assoc_opt a l l retourne la valeur associée à la clé a dans la liste de paires l . C'est-à-dire, assoc_opt a [ ...; (a,b); ...] = Some b si (a,b) est la première association de a dans la liste l . Retourne None s'il n'y a pas de valeur associée à a dans la liste l .

Depuis 4.05

Identique à List.assoc , mais retourne simplement true si une association existe, et false si aucune association n'existe pour la clé donnée.

remove_assoc a l retourne la liste de paires l sans la première paire avec la clé a , le cas échéant. Pas récursif terminal.

Listes de paires

val split : ('a * 'b) list -> 'a list * 'b list

Transforme une liste de paires en une paire de listes : split [(a1,b1); ...; (an,bn)] est ([a1; ...; an], [b1; ...; bn]) . Pas récursif terminal.

val combine : 'a list -> 'b list -> ('a * 'b) list

Transforme une paire de listes en une liste de paires : combine [a1; ...; an] [b1; ...; bn] est [(a1,b1); ...; (an,bn)] .

Lève Invalid_argument si les deux listes ont des longueurs différentes. Pas récursif terminal.
