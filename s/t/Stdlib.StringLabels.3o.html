Chaînes de caractères

type t = string

Le type pour les chaînes de caractères.

val make : int -> char -> string

make n c est une chaîne de longueur n avec chaque indice contenant le caractère c .

Lève Invalid_argument si n < 0 ou n > Sys.max_string_length .

val init : int -> f:(int -> char) -> string

init n ~f est une chaîne de longueur n avec l'indice i contenant le caractère f i (appelé dans l'ordre croissant des indices).

Depuis 4.02

Lève Invalid_argument si n < 0 ou n > Sys.max_string_length .

val empty : string

La chaîne vide.

Depuis 4.13

val length : string -> int

length s est la longueur (nombre d'octets/caractères) de s .

val get : string -> int -> char

get s i est le caractère à l'indice i dans s . Ceci est identique à l'écriture s.[i] .

Lève Invalid_argument si i n'est pas un indice de s .

Extraction de sous-chaînes

val sub : string -> pos:int -> len:int -> string

sub s ~pos ~len est une chaîne de longueur len , contenant la sous-chaîne de s qui commence à la position pos et a la longueur len .

Lève Invalid_argument si pos et len ne désignent pas une sous-chaîne valide de s .

val split_on_char : sep:char -> string -> string list

split_on_char ~sep s est la liste de toutes les sous-chaînes (éventuellement vides) de s qui sont délimitées par le caractère sep . Si s est vide, le résultat est la liste singleton [""] .

Le résultat de la fonction est spécifié par les invariants suivants :

-La liste n'est pas vide.

-La concaténation de ses éléments en utilisant sep comme séparateur renvoie une chaîne égale à l'entrée ( concat (make 1 sep)
(split_on_char sep s) = s ).

-Aucune chaîne dans le résultat ne contient le caractère sep .

Depuis 4.00

val escaped : string -> string

escaped s est s avec les caractères spéciaux représentés par des séquences d'échappement, suivant les conventions lexicales d'OCaml.

Tous les caractères en dehors de la plage imprimable US-ASCII [0x20;0x7E] sont échappés, ainsi que la barre oblique inverse (0x2F) et les guillemets doubles (0x22).

La fonction Scanf.unescaped est une inverse gauche de escaped , c'est-à-dire Scanf.unescaped (escaped s) = s pour toute chaîne s (sauf si escaped s échoue).

Lève Invalid_argument si le résultat est plus long que Sys.max_string_length octets.

Vérification orthographique

val edit_distance : ?limit:int -> t -> t -> int

edit_distance s0 s1 est le nombre d'éditions de caractères uniques (comprises comme insertion, suppression, substitution, transposition) nécessaires pour transformer s0 en s1.

Si limit est fourni, la fonction retourne avec limit dès qu'il est déterminé que s0 et s1 ont une distance d'au moins limit. C'est plus rapide si vous avez une limite fixe, par exemple pour la correction orthographique.

La fonction suppose que les chaînes sont encodées en UTF-8 et utilise Uchar.t pour la notion de caractère. Les erreurs de décodage sont remplacées par Uchar.rep. La normalisation des chaînes en NFC donne de meilleurs résultats.

Note. Ceci implémente la distance d'alignement optimal de chaînes (OSA), plus simple, pas la distance de Damerau-Levenshtein. Avec cette fonction, "ca" et "abc" ont une distance de 3 et non 2.

Depuis 5.4

val spellcheck : ?max_dist:(string -> int) -> ((string -> unit) -> unit) -> string -> string list

spellcheck iter_dict s sont les chaînes énumérées par l'itérateur iter_dict dont la StringLabels.edit_distance par rapport à s est la plus petite et inférieure ou égale à max_dist s. Si plusieurs corrections sont retournées, leur ordre est celui trouvé dans iter_dict. La valeur par défaut de max_dist s est :

- 0 si s contient 0 à 2 caractères Unicode.

- 1 si s contient 3 à 4 caractères Unicode.

- 2 sinon.

Si votre dictionnaire est une liste l, un iter_dict approprié est donné par (fun yield -> List.iter yield l).

Toutes les chaînes sont supposées être encodées en UTF-8, les erreurs de décodage sont remplacées par des caractères Uchar.rep.

Décodage binaire d'entiers

Les fonctions de cette section décodent des entiers à partir de chaînes en binaire.

Toutes les fonctions suivantes lèvent Invalid_argument si les caractères nécessaires à l'indice i pour décoder l'entier ne sont pas disponibles.

L'encodage little-endian (resp. big-endian) signifie que les octets de poids faible (resp. de poids fort) sont stockés en premier. Big-endian est aussi connu sous le nom d'ordre des octets réseau. L'encodage native-endian est soit little-endian soit big-endian selon Sys.big_endian.

Les entiers 32 bits et 64 bits sont représentés par les types int32 et int64, qui peuvent être interprétés comme des nombres signés ou non signés.

Les entiers 8 bits et 16 bits sont représentés par le type int, qui a plus de bits que l'encodage binaire. Ces bits supplémentaires sont étendus en signe (ou étendus avec des zéros) pour les fonctions qui décodent des entiers de 8 bits ou 16 bits et les représentent avec des valeurs int.

Since 4.05

val blit : src:string -> src_pos:int -> dst:string -> dst_pos:int -> len:int -> unit

blit ~src ~src_pos ~dst ~dst_pos ~len copies len characters from string src starting at index src_pos to string dst starting at index dst_pos.

The destination string dst must be large enough.

The source and destination strings must not overlap.

Raises Invalid_argument if len is negative, or if src_pos and len do not specify a valid substring in src , or if dst_pos and len do not specify a valid substring in dst .

val unsafe_blit : src:string -> src_pos:int -> dst:string -> dst_pos:int -> len:int -> unit

Same as StringLabels.blit , but without checking that the arguments are valid.
