NOM

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);
STAILQ_HEAD STAILQ_HEAD_INITIALIZER(STAILQ_HEAD head);
void STAILQ_INIT(STAILQ_HEAD *head);
int STAILQ_EMPTY(STAILQ_HEAD *head);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
struct TYPE *STAILQ_FIRST(STAILQ_HEAD *head);
struct TYPE *STAILQ_NEXT(struct TYPE *elm, STAILQ_ENTRY NAME);
STAILQ_FOREACH(struct TYPE *var, STAILQ_HEAD *head, STAILQ_ENTRY NAME);
void STAILQ_REMOVE(STAILQ_HEAD *head, struct TYPE *elm, TYPE,
                         STAILQ_ENTRY NAME);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *head,
                         STAILQ_ENTRY NAME);
void STAILQ_CONCAT(STAILQ_HEAD *head1, STAILQ_HEAD *head2);

Note: Il existe des macros identiques préfixées par SIMPLEQ au lieu de STAILQ ; voir VERSIONS.

DESCRIPTION

Ces macros définissent et opèrent sur des files en chaîne unique avec ajout à la fin.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro STAILQ_HEAD().

Création

Une file en chaîne unique avec ajout à la fin est dirigée par une structure définie par la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont chaînés de manière unique pour une surcharge minimale d'espace et de manipulation de pointeurs, au dépens d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, en tête de la file, ou à la fin de la file. Une structure STAILQ_HEAD est déclarée comme suit :


STAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à chaîner dans la file. Un pointeur vers la tête de la file peut ensuite être déclaré comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui relie les éléments de la file.

STAILQ_HEAD_INITIALIZER() est évaluée comme un initialiseur pour la file head.

STAILQ_INIT() initialise la file référencée par head.

STAILQ_EMPTY() est évaluée comme vraie s'il n'y a aucun élément dans la file.

Insertion

STAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de la file.

STAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file.

STAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

STAILQ_FIRST() renvoie le premier élément de la file ou NULL si la file est vide.

STAILQ_NEXT() renvoie le prochain élément de la file, ou NULL si cet élément est le dernier.

STAILQ_FOREACH() parcourt la file référencée par head dans le sens avant, assignant chaque élément à tour de rôle à var.

Suppression

STAILQ_REMOVE() supprime l'élément elm de la file.

STAILQ_REMOVE_HEAD() supprime l'élément en tête de la file. Pour une efficacité optimale, les éléments supprimés de la tête de la file devraient utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE().

Autres fonctionnalités

STAILQ_CONCAT() concatène la file dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première.

VALEUR DE RETOUR

STAILQ_EMPTY() renvoie une valeur non nulle si la file est vide, et zéro si la file contient au moins une entrée.

STAILQ_FIRST() et STAILQ_NEXT() renvoient un pointeur vers la structure TYPE première ou suivante, respectivement.

STAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la file head.

VERSIONS

Certains BSD fournissent SIMPLEQ au lieu de STAILQ. Ils sont identiques, mais pour des raisons historiques, ils ont été nommés différemment sur différents BSD. STAILQ est originaire de FreeBSD, et SIMPLEQ est originaire de NetBSD. Pour des raisons de compatibilité, certains systèmes fournissent les deux ensembles de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques à l'exception d'un équivalent SIMPLEQ manquant à STAILQ_CONCAT().

BUGS

STAILQ_FOREACH() ne permet pas que var soit supprimé ou libéré dans la boucle, car cela interférerait avec le parcours. STAILQ_FOREACH_SAFE(), qui est présent sur les BSD mais absent de glibc, corrige cette limitation en permettant à var d'être supprimé en toute sécurité de la liste et libéré à partir de la boucle sans interférer avec le parcours.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File en chaîne unique avec ajout à la fin */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Tête de file en chaîne unique avec ajout à la fin
                                               */
    STAILQ_INIT(&head);                     /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insérer en tête */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insérer à la fin */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression de la tête */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }

    NAME

    STAILQ_REMOVE_HEAD, STAILQ_REMOVE_HEAD_TAIL, STAILQ_TAIL — supprimez le premier élément d'une queue de liste doublement chaînée

    LIBRARY

    Bibliothèque C standard (libc, -lc)

    SYNOPSIS

    #include <sys/queue.h>

    <type> *
STAILQ_REMOVE_HEAD(STAILQ_HEAD *headp, <type> *elm);

    <type> *
STAILQ_REMOVE_HEAD_TAIL(STAILQ_HEAD *headp, <type> *elm);

    <type> *
STAILQ_TAIL(STAILQ_HEAD *headp);

    DESCRIPTION

    Les macros STAILQ_REMOVE_HEAD et STAILQ_REMOVE_HEAD_TAIL suppriment le premier élément d'une queue dont le pointeur vers la tête est headp. L'élément supprimé doit être stocké dans la variable elm avant l'appel. Ces macros retournent un pointeur vers l'élément supprimé.

    STAILQ_REMOVE_HEAD supprime le premier élément de la queue. Si la queue devient vide, le pointeur stqh_first est mis à NULL.

    STAILQ_REMOVE_HEAD_TAIL est identique à STAILQ_REMOVE_HEAD, à l'exception du fait que si la queue devient vide après la suppression, le pointeur stqh_last est également mis à NULL.

    La macro STAILQ_TAIL retourne un pointeur vers le dernier élément de la queue dont le pointeur vers la tête est headp, sans supprimer l'élément.

    RETURN VALUE

    Les macros STAILQ_REMOVE_HEAD et STAILQ_REMOVE_HEAD_TAIL retournent un pointeur vers l'élément supprimé.

    La macro STAILQ_TAIL retourne un pointeur vers le dernier élément de la queue, ou NULL si la queue est vide.

    VERSIONS

    Ces macros sont disponibles dans la bibliothèque C standard depuis FreeBSD 3.0.

    BUGS

    L'utilisation incorrecte de ces macros, par exemple en passant un pointeur NULL ou un pointeur vers un élément qui n'appartient pas à la queue, peut entraîner un comportement indéfini.

    STANDARDS

    Les macros de liste chaînée sont une fonctionnalité de BSD. Elles ne sont pas standardisées par ANSI/ISO C.

    HISTORY

    Les macros de liste chaînée sont apparues dans la version 2.2 de BSD.

    EXAMPLES

    Voici un exemple d'utilisation de STAILQ_REMOVE_HEAD pour supprimer tous les éléments d'une queue:

    /* Initialisation de la queue */
STAILQ_HEAD(my_list, entry) head;
STAILQ_INIT(&head);
/* ... ajout d'éléments à la queue ... */
/* Parcours avant */
struct entry *np;
STAILQ_FOREACH(np, &head, entries)
    printf("%i\n", np->data);
/* Suppression dans la queue */
struct entry *n1, *n2;
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
    n2 = STAILQ_NEXT(n1, entries);
    free(n1);
    n1 = n2;
}
STAILQ_INIT(&head);
exit(EXIT_SUCCESS);
}
