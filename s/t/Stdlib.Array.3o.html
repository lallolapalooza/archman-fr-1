type 'a t = 'a array

Un alias pour le type des tableaux.

val length : 'a array -> int

Retourne la longueur (nombre d'éléments) du tableau donné.

val get : 'a array -> int -> 'a

get a n retourne l'élément numéro n du tableau a. Le premier élément est numéro 0. Le dernier élément est numéro length a - 1. On peut aussi écrire a.(n) au lieu de get a n.

Raises Invalid_argument si n est hors de l'intervalle 0 à length a - 1.

val set : 'a array -> int -> 'a -> unit

set a n x modifie le tableau a en remplaçant l'élément numéro n par x. On peut aussi écrire a.(n) <- x au lieu de set a n x.

Raises Invalid_argument si n est hors de l'intervalle 0 à length a - 1.

val make : int -> 'a -> 'a array

make n x retourne un nouveau tableau de longueur n, initialisé avec x. Tous les éléments de ce nouveau tableau sont initialement physiquement égaux à x (au sens de l'opérateur ==). Par conséquent, si x est mutable, il est partagé entre tous les éléments du tableau. Modifier x par l'intermédiaire d'un des éléments du tableau modifiera tous les autres éléments simultanément.

Raises Invalid_argument si n < 0 ou n > Sys.max_array_length. Si la valeur de x est un nombre flottant, la taille maximale est seulement Sys.max_array_length / 2.

val create_float : int -> float array

create_float n retourne un nouveau tableau de flottants de longueur n, avec des données non initialisées.

Depuis 4.03

val init : int -> (int -> 'a) -> 'a array

init n f retourne un nouveau tableau de longueur n, avec l'élément numéro i initialisé par le résultat de f i. Autrement dit, init n f tabule les résultats de f appliqué en ordre aux entiers 0 à n-1.

Raises Invalid_argument si n < 0 ou n > Sys.max_array_length. Si le type de retour de f est float, la taille maximale est seulement Sys.max_array_length / 2.

val make_matrix : int -> int -> 'a -> 'a array array

make_matrix dimx dimy e retourne un tableau à deux dimensions (un tableau de tableaux) de dimensions dimx et dimy. Tous les éléments de cette nouvelle matrice sont initialement physiquement égaux à e. L'élément ( x,y ) d'une matrice m est accédé par la notation m.(x).(y).

Raises Invalid_argument si dimx ou dimy est négatif ou supérieur à Sys.max_array_length. Si la valeur de e est un nombre flottant, la taille maximale est seulement Sys.max_array_length / 2.

val init_matrix : int -> int -> (int -> int -> 'a) -> 'a array array

init_matrix dimx dimy f retourne un tableau à deux dimensions (un tableau de tableaux) de dimensions dimx et dimy, où l'élément à la position ( x,y ) est initialisé par f x y. L'élément ( x,y ) d'une matrice m est accédé par la notation m.(x).(y).

Depuis 5.2

Raises Invalid_argument si dimx ou dimy est négatif ou supérieur à Sys.max_array_length. Si le type de retour de f est float, la taille maximale est seulement Sys.max_array_length / 2.

val append : 'a array -> 'a array -> 'a array

append v1 v2 retourne un nouveau tableau contenant la concaténation des tableaux v1 et v2.

Raises Invalid_argument si length v1 + length v2 > Sys.max_array_length.

val concat : 'a array list -> 'a array

C'est la même chose que Array.append, mais en concaténant une liste de tableaux.

val sub : 'a array -> int -> int -> 'a array

sub a pos len retourne un nouveau tableau de longueur len, contenant les éléments numéro pos à pos + len - 1 du tableau a.

Raises Invalid_argument si pos et len ne désignent pas un sous-tableau valide de a ; c'est-à-dire si pos < 0 ou len < 0 ou pos + len > length a.

val copy : 'a array -> 'a array

copy a retourne une copie de a, c'est-à-dire un nouveau tableau contenant les mêmes éléments que a.

val fill : 'a array -> int -> int -> 'a -> unit

fill a pos len x modifie le tableau a en stockant x dans les éléments numéro pos à pos + len - 1.

Raises Invalid_argument si pos et len ne désignent pas un sous-tableau valide de a.

val blit : 'a array -> int -> 'a array -> int -> int -> unit

blit src src_pos dst dst_pos len copie len éléments depuis src, en commençant à l'élément numéro src_pos, vers dst, en commençant à l'élément numéro dst_pos. Fonctionne correctement même si src et dst sont le même tableau, et si les blocs source et destination se chevauchent.

Raises Invalid_argument si src_pos et len ne désignent pas un sous-tableau valide de src, ou si dst_pos et len ne désignent pas un sous-tableau valide de dst.

val to_list : 'a array -> 'a list

to_list a retourne la liste de tous les éléments de a.

val of_list : 'a list -> 'a array

of_list l retourne un nouveau tableau contenant les éléments de l.

Raises Invalid_argument si la longueur de l est supérieure à Sys.max_array_length.

Comparaison

val equal : ('a -> 'a -> bool) -> 'a array -> 'a array -> bool

equal eq a b est true si et seulement si a et b ont la même longueur n et pour tout i dans [ 0 ; n-1 ], eq a.(i) b.(i) est true.

Depuis 5.4

val compare : ('a -> 'a -> int) -> 'a array -> 'a array -> int

compare cmp a b compare a et b selon l'ordre lexicographique court, c'est-à-dire que les tableaux plus courts sont plus petits, et les tableaux de même longueur sont comparés dans l'ordre lexicographique en utilisant cmp pour comparer les éléments.

Itérateurs

val iter : ('a -> unit) -> 'a array -> unit

iter f a applique la fonction f à tous les éléments de a. C'est équivalent à f a.(0); f a.(1); ...; f a.(length a - 1); ().

val iteri : (int -> 'a -> unit) -> 'a array -> unit

C'est la même chose que Array.iter, mais la fonction est appliquée à l'indice de l'élément comme premier argument et à l'élément comme second argument.

val map : ('a -> 'b) -> 'a array -> 'b array

map f a applique la fonction f à tous les éléments de a et construit un tableau avec les résultats de f appliqué à chaque élément de a : [| f a.(0); f a.(1); ...; f a.(length a - 1) |].

val map_inplace : ('a -> 'a) -

, mais la fonction est appliquée à l'indice de l'élément comme premier argument, et à l'élément lui-même comme second argument.

val fold_left : ('acc -> 'a -> 'acc) -> 'acc -> 'a array -> 'acc

fold_left f init a calcule f (... (f (f init a.(0)) a.(1)) ...) a.(n-1) , où n est la longueur du tableau a .

val fold_left_map : ('acc -> 'a -> 'acc * 'b) -> 'acc -> 'a array -> 'acc * 'b array

fold_left_map est une combinaison de Array.fold_left et Array.map qui propage un accumulateur à travers les appels à f.

Depuis 4.13

val fold_right : ('a -> 'acc -> 'acc) -> 'a array -> 'acc -> 'acc

fold_right f a init calcule f a.(0) (f a.(1) ( ... (f a.(n-1) init) ...)) , où n est la longueur du tableau a .

Balayage des tableaux

val for_all : ('a -> bool) -> 'a array -> bool

for_all f [|a1; ...; an|] vérifie si tous les éléments du tableau satisfont le prédicat f. C'est-à-dire, il retourne (f a1) && (f a2) && ... && (f an).

Depuis 4.03

val exists : ('a -> bool) -> 'a array -> bool

exists f [|a1; ...; an|] vérifie si au moins un élément du tableau satisfait le prédicat f. C'est-à-dire, il retourne (f a1) || (f a2) || ... || (f an).

Depuis 4.03

Identique à Array.for_all, mais pour un prédicat à deux arguments.

Depuis 4.11

val exists2 : ('a -> 'b -> bool) -> 'a array -> 'b array -> bool

Identique à Array.exists, mais pour un prédicat à deux arguments.

Depuis 4.11

Lève Invalid_argument si les deux tableaux ont des longueurs différentes.

val mem : 'a -> 'a array -> bool

mem a set est vrai si et seulement si a est structurellement égal à un élément de set (c'est-à-dire qu'il existe un x dans set tel que compare a x = 0).

Depuis 4.03

val memq : 'a -> 'a array -> bool

Identique à Array.mem, mais utilise l'égalité physique plutôt que l'égalité structurelle pour comparer les éléments du tableau.

val find_opt : ('a -> bool) -> 'a array -> 'a option

find_opt f a retourne le premier élément du tableau a qui satisfait le prédicat f, ou None s'il n'y a pas de valeur qui satisfasse f dans le tableau a.

find_index f a retourne Some i, où i est l'indice du premier élément du tableau a qui satisfait f x, s'il existe un tel élément.

Il retourne None s'il n'existe pas un tel élément.

find_map f a applique f aux éléments de a dans l'ordre, et retourne le premier résultat de la forme Some v, ou None si aucun n'existe.

Tri et mélange

val sort : ('a -> 'a -> int) -> 'a array -> unit

Trie un tableau par ordre croissant selon une fonction de comparaison. La fonction de comparaison doit retourner 0 si ses arguments sont égaux, un entier positif si le premier est plus grand, et un entier négatif si le premier est plus petit (voir ci-dessous pour une spécification complète). Par exemple, compare est une fonction de comparaison appropriée. Après avoir appelé sort, le tableau est trié en place par ordre croissant. sort est garanti de s'exécuter en espace tas constant et en espace pile (au plus) logarithmique.

L'implémentation actuelle utilise le tri par tas (Heap Sort). Il s'exécute en espace pile constant.

Spécification de la fonction de comparaison : Soit a le tableau et cmp la fonction de comparaison. Les conditions suivantes doivent être vraies pour tous les x, y, z dans a :

- cmp x y > 0 si et seulement si cmp y x < 0

- si cmp x y >= 0 et cmp y z >= 0 alors cmp x z >= 0

Lorsque sort retourne, a contient les mêmes éléments qu'auparavant, réordonnés de telle sorte que pour tous les indices i et j valides de a :

- cmp a.(i) a.(j) >= 0 si i >= j

val stable_sort : ('a -> 'a -> int) -> 'a array -> unit

Identique à Array.sort, mais l'algorithme de tri est stable (c'est-à-dire que les éléments qui se comparent comme égaux conservent leur ordre d'origine) et n'est pas garanti de s'exécuter en espace tas constant.

L'implémentation actuelle utilise le tri par fusion (Merge Sort). Il utilise un tableau temporaire de longueur n/2, où n est la longueur du tableau. Il est généralement plus rapide que l'implémentation actuelle de Array.sort.

val fast_sort : ('a -> 'a -> int) -> 'a array -> unit

Identique à Array.sort ou Array.stable_sort, selon ce qui est le plus rapide sur des entrées typiques.

val shuffle : rand:(int -> int) -> 'a array -> unit

shuffle rand a permute aléatoirement les éléments de a en utilisant rand pour l'aléatoire. La distribution des permutations est uniforme.

rand doit être tel qu'un appel à rand n retourne un nombre aléatoire uniformément distribué dans l'intervalle [ 0 ; n-1 ]. Random.int peut être utilisé pour cela (n'oubliez pas d'appeler Random.self_init le générateur).

Sécurité des tableaux et concurrence

Il faut être prudent lors de l'accès simultané à des tableaux à partir de plusieurs domaines : l'accès à un tableau ne fera jamais planter un programme, mais des accès non synchronisés pourraient produire des résultats surprenants (non séquentiellement cohérents).

Atomicité

Toute opération sur tableau qui accède à plus d'un élément de tableau n'est pas atomique. Cela inclut l'itération, le balayage, le tri, la division et la combinaison de tableaux.

Par exemple, considérons le programme suivant :

let size = 100_000_000
let a = Array.make size 1
let d1 = Domain.spawn (fun () ->
   Array.iteri (fun i x -> a.(i) <- x + 1) a
)
let d2 = Domain.spawn (fun () ->
  Array.iteri (fun i x -> a.(i) <- 2 * x + 1) a
)
let () = Domain.join d1; Domain.join d2

Après l'exécution de ce code, chaque champ du tableau a est soit 2, 3, 4 ou 5. Si l'atomicité est requise, alors l'utilisateur doit implémenter sa propre synchronisation (par exemple, en utilisant Mutex.t).

Courses de données

Si deux domaines n'accèdent qu'à des parties disjointes du tableau, alors le comportement observé est équivalent à un entrelacement séquentiel des opérations des deux domaines.

Une course de données se produit lorsque deux domaines accèdent au même élément de tableau sans synchronisation et qu'au moins un des accès est une écriture. En l'absence de courses de données, le comportement observé est équivalent à un entrelacement séquentiel des opérations provenant de domaines différents.

Dans la mesure du possible, les courses de données doivent être évitées en utilisant la synchronisation

Tableaux de float

Les tableaux de flottants présentent deux observations supplémentaires en présence de compétitions de données.

Premièrement, l'opération de copie peut copier un tableau octet par octet. Les compétitions de données entre une telle opération de copie et une autre peuvent produire des valeurs surprenantes en raison du déchirement (tearing) : les écritures partielles entrelacées avec des opérations d'autres domaines peuvent créer des valeurs flottantes qui n'existeraient pas avec une exécution séquentielle.

Par exemple, à la fin de

let zeros = Array.make size 0.
let max_floats = Array.make size Float.max_float
let res = Array.copy zeros
let d1 = Domain.spawn (fun () -> Array.blit zeros 0 res 0 size)
let d2 = Domain.spawn (fun () -> Array.blit max_floats 0 res 0 size)
let () = Domain.join d1; Domain.join d2
le tableau res pourrait contenir des valeurs autres que 0. ou max_float .

Deuxièmement, sur les architectures 32 bits, l'obtention ou la définition d'un champ implique deux accès mémoire distincts. En présence de compétitions de données, l'utilisateur pourrait observer du déchirement dans n'importe quelle opération.
