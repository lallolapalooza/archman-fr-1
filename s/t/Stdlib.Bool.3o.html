Booléens

type t = bool =
| false
| true

Le type des booléens (valeurs de vérité).

Les constructeurs false et true sont inclus ici afin qu'ils aient des chemins d'accès, mais ils ne sont pas destinés à être utilisés dans des types de données définis par l'utilisateur.

val not : bool -> bool

not b est la négation booléenne de b.

val (&&) : bool -> bool -> bool

e0 && e1 est la conjonction booléenne paresseuse des expressions e0 et e1. Si e0 s'évalue à false, e1 n'est pas évaluée. Opérateur associatif à droite avec une priorité de niveau 3/11.

val (||) : bool -> bool -> bool

e0 || e1 est la disjonction booléenne paresseuse des expressions e0 et e1. Si e0 s'évalue à true, e1 n'est pas évaluée. Opérateur associatif à droite avec une priorité de niveau 2/11.

val logand : bool -> bool -> bool

logand b1 b2 est true si et seulement si b1 et b2 sont tous deux true.

val logor : bool -> bool -> bool

logor b1 b2 est true si et seulement si soit b1 soit b2 est true.

val logxor : bool -> bool -> bool

logxor b1 b2 est true si exactement un parmi b1 et b2 est true.

Prédicats et comparaisons

val equal : bool -> bool -> bool

equal b0 b1 est true si et seulement si b0 et b1 sont tous deux true ou tous deux false.

val compare : bool -> bool -> int

compare b0 b1 est un ordre total sur les valeurs booléennes. false est plus petit que true.

Conversion

val to_int : bool -> int

to_int b est 0 si b est false et 1 si b est true.

val to_float : bool -> float

to_float b est 0. si b est false et 1. si b est true.

val to_string : bool -> string

to_string b est "true" si b est true et "false" si b est false.

val seeded_hash : int -> bool -> int

Une fonction de hachage amorcée pour les booléens, avec la même valeur de sortie que Hashtbl.seeded_hash. Cette fonction permet de passer ce module comme argument au foncteur Hashtbl.MakeSeeded.

Depuis 5.1

val hash : bool -> int

Une fonction de hachage non amorcée pour les booléens, avec la même valeur de sortie que Hashtbl.hash. Cette fonction permet de passer ce module comme argument au foncteur Hashtbl.Make.

Depuis 5.1
