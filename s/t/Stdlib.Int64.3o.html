val rem : int64 -> int64 -> int64

Reste entier. Si y n'est pas zéro, le résultat de Int64.rem x y satisfait la propriété suivante : x = Int64.add (Int64.mul (Int64.div x y) y) (Int64.rem x y). Si y = 0, Int64.rem x y lève Division_by_zero.

val unsigned_rem : int64 -> int64 -> int64

val shift_left : int64 -> int -> int64

Décale x vers la gauche de y bits. Le résultat n'est pas défini si y < 0 ou y >= 64.

val shift_right : int64 -> int -> int64

Décale x vers la droite de y bits. C'est un décalage arithmétique : le bit de signe de x est répété et inséré dans les bits vides. Le résultat n'est pas défini si y < 0 ou y >= 64.

val shift_right_logical : int64 -> int -> int64

Décale x vers la droite de y bits. C'est un décalage logique : des zéros sont insérés dans les bits vides, quel que soit le signe de x. Le résultat n'est pas défini si y < 0 ou y >= 64.

val of_int : int -> int64

Convertit un entier donné (type int) en un entier 64 bits (type int64).

val to_int : int64 -> int

Convertit un entier 64 bits (type int64) en un entier (type int). Sur les plateformes 64 bits, l'entier 64 bits est pris modulo 2^63, c'est-à-dire que le bit le plus significatif est perdu lors de la conversion. Sur les plateformes 32 bits, l'entier 64 bits est pris modulo 2^31, c'est-à-dire que les 33 bits de poids fort sont perdus lors de la conversion.

val unsigned_to_int : int64 -> int option

Identique à Int64.to_int, mais interprète l'argument comme un entier non signé. Renvoie None si la valeur non signée de l'argument ne peut pas tenir dans un int.

Depuis 4.08

val of_float : float -> int64

Convertit un nombre flottant donné en un entier 64 bits, en ignorant la partie fractionnaire (arrondi vers zéro). Si le nombre flottant tronqué est hors de la plage [ Int64.min_int, Int64.max_int ], aucune exception n'est levée et un entier indéfini est renvoyé, dépendant du système.

val to_float : int64 -> float

Convertit un entier 64 bits (type int64) en un nombre flottant.

val of_int32 : int32 -> int64

Convertit un entier 32 bits (type int32) en un entier 64 bits (type int64).

val to_int32 : int64 -> int32

Convertit un entier 64 bits (type int64) en un entier 32 bits (type int32). L'entier 64 bits est pris modulo 2^32, c'est-à-dire que les 32 bits de poids fort sont perdus lors de la conversion.

val of_nativeint : nativeint -> int64

Convertit un entier natif (type nativeint) en un entier 64 bits (type int64).

val to_nativeint : int64 -> nativeint

Convertit un entier 64 bits (type int64) en un entier natif. Sur les plateformes 32 bits, l'entier 64 bits est pris modulo 2^32. Sur les plateformes 64 bits, la conversion est exacte.

val of_string : string -> int64

Convertit une chaîne donnée en un entier 64 bits. La chaîne est lue en décimal (par défaut, ou si la chaîne commence par 0u), ou en hexadécimal, octal ou binaire si la chaîne commence par 0x, 0o ou 0b respectivement.

Le préfixe 0u lit la valeur comme un entier non signé dans la plage [ 0, 2*Int64.max_int+1 ]. Si la valeur dépasse Int64.max_int, elle est convertie en l'entier Int64.min_int + input - Int64.max_int - 1.

Le caractère _ (trait d'union) peut apparaître n'importe où dans la chaîne et est ignoré.

Failure est levée si la chaîne donnée n'est pas une représentation valide d'un entier ou si l'entier représenté dépasse la plage des entiers représentables dans le type int64.

val of_string_opt : string -> int64 option

Identique à of_string, mais renvoie None au lieu de lever une exception.

Depuis 4.05

val to_string : int64 -> string

Renvoie la représentation en chaîne de son argument, en décimal.

val bits_of_float : float -> int64

Renvoie la représentation interne du nombre flottant donné selon le format IEEE 754 de 'double' (format de bits de flottant double). Le bit 63 représente le signe du nombre flottant ; les bits 62 à 52 représentent l'exposant (biaisé) ; les bits 51 à 0 représentent la mantisse.

val float_of_bits : int64 -> float

Renvoie le nombre flottant dont la représentation interne, selon le format IEEE 754 de 'double' (format de bits de flottant double), est la valeur int64 donnée.
