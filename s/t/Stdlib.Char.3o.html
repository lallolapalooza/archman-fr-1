Caractères

type t = char

Un alias pour le type des caractères.

val code : char -> int

Retourne le code entier de l'argument.

val chr : int -> char

Retourne le caractère ayant le code entier donné.

Lève Invalid_argument si l'argument est en dehors de l'intervalle [ 0x00 ; 0xFF ].

val escaped : char -> string

Retourne une chaîne de caractères représentant le caractère donné, avec les caractères spéciaux échappés selon les conventions lexicales d'OCaml. Tous les caractères en dehors de la plage des caractères imprimables ASCII [ 0x20 ; 0x7E ] sont échappés, ainsi que la barre oblique inverse, les guillemets doubles et simples.

Prédicats et comparaisons

Voir aussi le module Char.Ascii.

val compare : t -> t -> int

La fonction de comparaison pour les caractères, avec la même spécification que compare . Avec le type t , cette fonction compare permet de passer le module Char en argument aux foncteurs Set.Make et Map.Make .

val equal : t -> t -> bool

La fonction d'égalité pour les caractères.

Depuis 4.03

Caractères ASCII

module Ascii : sig end

Support de l'ensemble des caractères ASCII.

Ces fonctions donnent un sens aux entiers [ 0x00 ; 0x7F ] de l'ensemble des caractères ASCII.

Étant donné que l'encodage UTF-8 de Unicode a la même sémantique d'encodage et de caractères (U+0000 à U+001F) pour ces octets, les fonctions peuvent être utilisées sans risque sur des éléments de valeurs de type string et bytes encodées en UTF-8. Cependant, les fonctions ne traitent que des questions liées à l'ASCII. Par exemple, la notion d'espace blanc Unicode est beaucoup plus large que l'espace blanc ASCII déterminé par Char.Ascii.is_white.

Une fonction de hachage amorcée pour les caractères, avec la même valeur de sortie que Hashtbl.seeded_hash . Cette fonction permet de passer ce module en argument au foncteur Hashtbl.MakeSeeded .

val hash : t -> int

Une fonction de hachage non amorcée pour les caractères, avec la même valeur de sortie que Hashtbl.hash . Cette fonction permet de passer ce module en argument au foncteur Hashtbl.Make .
