NOM

XStandards - Normes et spécifications du système X Window

DESCRIPTION

L'objectif principal du X Consortium était de promouvoir la coopération au sein de l'industrie informatique dans la création d'interfaces logicielles standard à toutes les couches de l'environnement du système X Window. Le X Consortium a produit des normes - des documents qui définissaient les protocoles réseau, les interfaces de programmation et d'autres aspects de l'environnement X. Ces normes continuent d'exister dans les versions de la Fondation X.Org. La Fondation X.Org produit également des spécifications. Comme les normes du système X Window, ce sont des documents qui définissent les protocoles réseau, les interfaces de programmation et d'autres aspects de l'environnement X. Sous l'égide de The Open Group, les normes du système X Window, les spécifications de la Fondation X.Org et d'autres spécifications sont la base de portions des diverses spécifications CAE de The Open Group.

Le statut de diverses normes, spécifications et logiciels dans la distribution X11R7.0 est expliqué ci-dessous.

NON NORMES

La distribution X11R7.0 contient des implémentations d'exemple, pas des implémentations de référence. Bien qu'une grande partie du code soit considérée comme correcte, il faut supposer que le code est erroné partout où il entre en conflit avec la spécification.

Les seules normes du système X Window sont celles énumérées ci-dessus. Aucun autre document, fichier d'inclusion ou logiciel dans X11R7.0 n'a de statut spécial au sein du système X Window. Par exemple, aucun des éléments suivants n'est une norme : interfaces internes du serveur d'exemple ; l'extension MIT-SHM ; l'ensemble de widgets Athena ; la bibliothèque Xmu ; la bibliothèque Xau ; la base de données RGB ; la base de données de locales X ; les polices distribuées avec X11R7.0 ; les applications distribuées avec X11R7.0 ; les fichiers d'inclusion <X11/XWDFile.h>
