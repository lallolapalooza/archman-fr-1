Fonctions de base

val init : int -> unit

Initialise le générateur de domaine courant, en utilisant l'argument comme graine. La même graine produit toujours la même séquence de nombres.

val full_init : int array -> unit

Identique à Random.init, mais prend plus de données comme graine.

val self_init : unit -> unit

Initialise le générateur de domaine courant avec une graine aléatoire choisie de manière dépendante du système. Si un générateur de nombres aléatoires sécurisé est disponible sur la machine, il est utilisé pour fournir une graine très aléatoire. Sinon, une graine moins aléatoire est calculée à partir de paramètres système (heure actuelle, identifiant de processus, état local).

val bits : unit -> int

Retourne 30 bits aléatoires dans un entier non signé.

val int : int -> int

Random.int bound retourne un entier aléatoire entre 0 (inclus) et bound (exclus). bound doit être supérieur à 0 et inférieur à 2^30.

Si bound <= 0 ou bound >= 2^30, une exception Invalid_argument est levée.

val full_int : int -> int

Random.full_int bound retourne un entier aléatoire entre 0 (inclus) et bound (exclus). bound peut être n'importe quel nombre positif.

Si bound < 2^31, Random.full_int bound retourne une sortie identique sur des systèmes avec des tailles d'entiers différentes.

Si bound < 2^30, Random.full_int bound est identique à Random.int bound.

Si bound >= 2^30 (sur des systèmes 64 bits ou dans des environnements non standard comme JavaScript), Random.full_int retourne une valeur tandis que Random.int lève une exception Invalid_argument.

Depuis 4.13

Si bound <= 0, une exception Invalid_argument est levée.

val int_in_range : min:int -> max:int -> int

Random.int_in_range ~min ~max retourne un entier aléatoire entre min (inclus) et max (inclus). min et max peuvent être négatifs ; min doit être inférieur ou égal à max.

Si les deux bornes tiennent dans 32 bits (c'est-à-dire -2^31 <= min et max < 2^31), Random.int_in_range retourne une sortie identique sur des systèmes avec des tailles d'entiers différentes.

Depuis 5.2

Si min > max, une exception Invalid_argument est levée.

val int32 : Int32.t -> Int32.t

Random.int32 bound retourne un entier aléatoire entre 0 (inclus) et bound (exclus). bound doit être supérieur à 0.

Si bound <= 0, une exception Invalid_argument est levée.

val int32_in_range : min:Int32.t -> max:Int32.t -> Int32.t

Random.int32_in_range ~min ~max retourne un entier aléatoire entre min (inclus) et max (inclus). min et max peuvent être négatifs ; min doit être inférieur ou égal à max.

Depuis 5.2

Si min > max, une exception Invalid_argument est levée.

val nativeint : Nativeint.t -> Nativeint.t

Random.nativeint bound retourne un entier aléatoire entre 0 (inclus) et bound (exclus). bound doit être supérieur à 0.

Si bound <= 0, une exception Invalid_argument est levée.

val nativeint_in_range : min:nativeint -> max:nativeint -> nativeint

Random.nativeint_in_range ~min ~max retourne un entier aléatoire entre min (inclus) et max (inclus). min et max peuvent être négatifs ; min doit être inférieur ou égal à max.

Depuis 5.2

Si min > max, une exception Invalid_argument est levée.

val int64 : Int64.t -> Int64.t

Random.int64 bound retourne un entier aléatoire entre 0 (inclus) et bound (exclus). bound doit être supérieur à 0.

Si bound <= 0, une exception Invalid_argument est levée.

val int64_in_range : min:Int64.t -> max:Int64.t -> Int64.t

Random.int64_in_range ~min ~max retourne un entier aléatoire entre min (inclus) et max (inclus). min et max peuvent être négatifs ; min doit être inférieur ou égal à max.

Depuis 5.2

Si min > max, une exception Invalid_argument est levée.

val float : float -> float

Random.float bound retourne un nombre flottant aléatoire entre 0 et bound (inclus). Si bound est négatif, le résultat est négatif ou nul. Si bound est 0, le résultat est 0.

val bool : unit -> bool

Random.bool () retourne true ou false avec une probabilité de 0.5 chacun.

val bits32 : unit -> Int32.t

Random.bits32 () retourne 32 bits aléatoires sous forme d'entier entre Int32.min_int et Int32.max_int.

Depuis 4.14

val bits64 : unit -> Int64.t

Random.bits64 () retourne 64 bits aléatoires sous forme d'entier entre Int64.min_int et Int64.max_int.

Depuis 4.14

val nativebits : unit -> Nativeint.t

Random.nativebits () retourne 32 ou 64 bits aléatoires (selon la largeur des bits du système) sous forme d'entier entre Nativeint.min_int et Nativeint.max_int.

Depuis 4.14

Fonctions avancées

Les fonctions du module Random.State manipulent explicitement l'état actuel du générateur aléatoire. Cela permet d'utiliser un ou plusieurs générateurs PRNG déterministes, même dans un programme multi-threadé, sans interférence avec d'autres parties du programme.

module State : sig end

val get_state : unit -> State.t

get_state() retourne une copie fraîche de l'état actuel du générateur de domaine courant (qui est utilisé par les fonctions de base).

val set_state : State.t -> unit

set_state s met à jour l'état actuel du générateur de domaine courant (utilisé par les fonctions de base) en copiant l'état s en lui.

val split : unit -> State.t

Extrait un nouvel état PRNG de l'état actuel du générateur de domaine courant utilisé par les fonctions par défaut. (L'état du générateur de domaine courant est modifié.) Voir Random.State.split.

Depuis 5.0
