Un alias pour le type des listes.

val length : 'a list -> int

Retourne la longueur (nombre d'éléments) de la liste donnée.

val compare_lengths : 'a list -> 'b list -> int

Compare les longueurs de deux listes. compare_lengths l1 l2 est équivalent à compare (length l1) (length l2) , sauf que le calcul s'arrête après avoir atteint la fin de la plus courte des deux listes.

Depuis 4.05

val compare_length_with : 'a list -> len:int -> int

Compare la longueur d'une liste à un entier. compare_length_with l len est équivalent à compare (length l) len , sauf que le calcul s'arrête après au plus len itérations sur la liste.

Depuis 4.05

val is_empty : 'a list -> bool

is_empty l est vrai si et seulement si l n'a pas d'éléments. C'est équivalent à compare_length_with l 0 = 0 .

val append : 'a list -> 'a list -> 'a list

append l0 l1 ajoute l1 à la fin de l0 . Même fonction que l'opérateur infixe @ .

Depuis 5.1 cette fonction est récursive terminale.

val rev_append : 'a list -> 'a list -> 'a list

rev_append l1 l2 inverse l1 et la concatène avec l2 . C'est équivalent à ( ListLabels.rev l1) @ l2 .

val concat : 'a list list -> 'a list

Concatène une liste de listes. Les éléments de l'argument sont tous concaténés ensemble (dans le même ordre) pour donner le résultat. N'est pas récursive terminale (longueur de l'argument + longueur de la plus longue sous-liste).

val flatten : 'a list list -> 'a list

Identique à ListLabels.concat . N'est pas récursive terminale (longueur de l'argument + longueur de la plus longue sous-liste).

Comparaison

val equal : eq:('a -> 'a -> bool) -> 'a list -> 'a list -> bool

equal eq [a1; ...; an] [b1; ..; bm] est vrai quand les deux listes d'entrée ont la même longueur, et que pour chaque paire d'éléments ai , bi à la même position, on a eq ai bi .

Note : la fonction eq peut être appelée même si les listes ont des longueurs différentes. Si vous savez que votre fonction d'égalité est coûteuse, vous pourriez vouloir vérifier ListLabels.compare_lengths d'abord.

Depuis 4.12

val compare : cmp:('a -> 'a -> int) -> 'a list -> 'a list -> int

compare cmp [a1; ...; an] [b1; ...; bm] effectue une comparaison lexicographique des deux listes d'entrée, en utilisant la même interface 'a -> 'a -> int que compare :

- a1 :: l1 est plus petit que a2 :: l2 (résultat négatif) si a1 est plus petit que a2 , ou s'ils sont égaux (résultat 0) et l1 est plus petit que l2

- la liste vide [] est strictement plus petite que les listes non vides

Note : la fonction cmp sera appelée même si les listes ont des longueurs différentes.

Analyse de liste

val for_all : f:('a -> bool) -> 'a list -> bool

for_all ~f [a1; ...; an] vérifie si tous les éléments de la liste satisfont le prédicat f. C'est-à-dire, il renvoie (f a1) && (f a2) && ... && (f an) pour une liste non vide et true si la liste est vide.

val exists : f:('a -> bool) -> 'a list -> bool

exists ~f [a1; ...; an] vérifie si au moins un élément de la liste satisfait le prédicat f. C'est-à-dire, il renvoie (f a1) || (f a2) || ... || (f an) pour une liste non vide et false si la liste est vide.

val for_all2 : f:('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Identique à ListLabels.for_all, mais pour un prédicat à deux arguments.

Lève Invalid_argument si les deux listes ont des longueurs différentes.

val exists2 : f:('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Identique à ListLabels.exists, mais pour un prédicat à deux arguments.

Lève Invalid_argument si les deux listes ont des longueurs différentes.

val mem : 'a -> set:'a list -> bool

mem a ~set est vrai si et seulement si a est égal à un élément de set.

val memq : 'a -> set:'a list -> bool

Identique à ListLabels.mem, mais utilise l'égalité physique plutôt que l'égalité structurelle pour comparer les éléments de la liste.

Manipulation de liste

val take : int -> 'a list -> 'a list

take n l renvoie le préfixe de l de longueur n, ou une copie de l si n > length l. C'est la liste vide si n est négatif.

Attention. Uniquement dans la version 5.3, cette fonction lève Invalid_argument pour les valeurs négatives de n.

Depuis 5.3

val drop : int -> 'a list -> 'a list

drop n l renvoie la partie finale de l après n éléments, ou [] si n > length l. C'est l si n est négatif.

Attention. Uniquement dans la version 5.3, cette fonction lève Invalid_argument pour les valeurs négatives de n.

Depuis 5.3

val take_while : f:('a -> bool) -> 'a list -> 'a list

take_while p l est le plus long préfixe (éventuellement vide) de l qui ne contient que des éléments satisfaisant p.

Depuis 5.3

val drop_while : f:('a -> bool) -> 'a list -> 'a list

drop_while p l est le plus long suffixe (éventuellement vide) de l commençant par le premier élément ne satisfaisant pas p.

Depuis 5.3

val partition : f:('a -> bool) -> 'a list -> 'a list * 'a list

partition ~f l renvoie une paire de listes (l1, l2), où l1 est la liste de tous les éléments de l qui satisfont le prédicat f, et l2 est la liste de tous les éléments de l qui ne satisfont pas f. L'ordre des éléments dans la liste d'entrée est préservé.

val partition_map : f:('a -> ('b, 'c) Either.t) -> 'a list -> 'b list * 'c list

partition_map f l renvoie une paire de listes (l1, l2) telle que, pour chaque élément x de la liste d'entrée l :

- si f x est Left y1, alors y1 est dans l1, et

- si f x est Right y2, alors y2 est dans l2.

Les éléments de sortie sont inclus dans l1 et l2 dans le même ordre que les éléments correspondants dans l.

En particulier, partition_map (fun x -> if f x then Left x else Right x) l est équivalent à partition f l.

Listes d'association

val assoc : 'a -> ('a * 'b) list -> 'b

assoc a l l renvoie la valeur associée à la clé a dans la liste de paires l. C'est-à-dire, assoc a [ ...; (a,b); ...] = b si (a,b) est la première occurrence de a dans la liste l.

Lève Not_found si aucune valeur n'est associée à a dans la liste l.

val assoc_opt : 'a -> ('a * 'b) list -> 'b option

assoc_opt a l l renvoie la valeur associée à la clé a dans la liste de paires l. C'est-à-dire, assoc_opt a [ ...; (a,b); ...] = Some b si (a,b) est la première occurrence de a dans la liste l. Renvoie None si aucune valeur n'est associée à a dans la liste l.

Listes de paires

val split : ('a * 'b) list -> 'a list * 'b list

Transforme une liste de paires en une paire de listes : split [(a1,b1); ...; (an,bn)] devient ([a1; ...; an], [b1; ...; bn]). Ce n'est pas une récursion terminale.

val combine : 'a list -> 'b list -> ('a * 'b) list

Transforme une paire de listes en une liste de paires : combine [a1; ...; an] [b1; ...; bn] devient [(a1,b1); ...; (an,bn)].

Lève Invalid_argument si les deux listes ont des longueurs différentes. Ce n'est pas une récursion terminale.

Sorting functions

val sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Sort a list in increasing order according to a comparison function. The comparison function must return 0 if its arguments compare as equal, a positive integer if the first is greater, and a negative integer if the first is smaller (see Array.sort for a complete specification). For example, compare is a suitable comparison function. The resulting list is sorted in increasing order. ListLabels.sort is guaranteed to run in constant heap space (in addition to the size of the result list) and logarithmic stack space.

The current implementation uses Merge Sort. It runs in constant heap space and logarithmic stack space.

val stable_sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort , but the sorting algorithm is guaranteed to be stable (i.e. elements that compare equal are kept in their original order).

The current implementation uses Merge Sort. It runs in constant heap space and logarithmic stack space.

val fast_sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort or ListLabels.stable_sort , whichever is faster on typical input.

val sort_uniq : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort , but also remove duplicates: if multiple elements compare equal, keep only the first.

Before5.4 the element kept was not necessarily the first one.

Since 4.03

val merge : cmp:('a -> 'a -> int) -> 'a list -> 'a list -> 'a list

Merge two lists: Assuming that l1 and l2 are sorted according to the comparison function cmp , merge ~cmp l1 l2 will return a sorted list containing all the elements of l1 and l2 . If several elements compare equal, the elements of l1 will be before the elements of l2 . Not tail-recursive (sum of the lengths of the arguments).
