Comparaison physique

val phys_equal : 'a -> 'a -> bool

phys_equal e1 e2 teste l'égalité physique de e1 et e2. Sur les types mutables tels que les références, les tableaux, les séquences d'octets, les enregistrements avec des champs mutables et les objets avec des variables d'instance mutables, phys_equal e1 e2 est vrai si et seulement si une modification physique de e1 affecte également e2. Sur les types non mutables, le comportement de phys_equal est dépendant de l'implémentation ; cependant, il est garanti que phys_equal e1 e2 implique compare e1 e2 = 0.

Comparaison polymorphique

val equal : 'a -> 'a -> bool

equal e1 e2 teste l'égalité structurelle de e1 et e2. Les structures mutables (par exemple, les références et les tableaux) sont égales si et seulement si leur contenu actuel est structurellement égal, même si les deux objets mutables ne sont pas le même objet physique. L'égalité entre valeurs fonctionnelles lève Invalid_argument. L'égalité entre structures de données cycliques peut ne pas se terminer.

val compare : 'a -> 'a -> int

compare x y renvoie 0 si x est égal à y, un entier négatif si x est inférieur à y, et un entier positif si x est supérieur à y. L'ordre implémenté par compare est compatible avec les prédicats de comparaison (=), (<) et (>), ainsi qu'avec la fonction equal définie ci-dessus, avec une différence dans le traitement de la valeur flottante nan. À savoir, les prédicats de comparaison traitent nan comme différent de toute autre valeur flottante, y compris elle-même ; tandis que compare traite nan comme égal à elle-même et inférieur à toute autre valeur flottante. Ce traitement de nan assure que compare définit une relation d'ordre total.

compare appliqué à des valeurs fonctionnelles peut lever Invalid_argument. compare appliqué à des structures cycliques peut ne pas se terminer.

La fonction compare peut être utilisée comme fonction de comparaison requise par les foncteurs Set.Make et Map.Make, ainsi que par les fonctions List.sort et Array.sort.

val min : 'a -> 'a -> 'a

Retourne le plus petit des deux arguments. Le résultat n'est pas spécifié si l'un des arguments contient la valeur flottante nan.

val max : 'a -> 'a -> 'a

Retourne le plus grand des deux arguments. Le résultat n'est pas spécifié si l'un des arguments contient la valeur flottante nan.
