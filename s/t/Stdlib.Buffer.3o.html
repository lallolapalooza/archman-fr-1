Accès non synchronisés

Les accès non synchronisés à un buffer peuvent entraîner un état invalide du buffer. Par conséquent, les opérations concurrentes sur un buffer doivent être synchronisées (par exemple, avec un Mutex.t).

type t

Le type abstrait des buffers.

val create : int -> t

create n renvoie un nouveau buffer, initialement vide. Le paramètre n est la taille initiale de la séquence d'octets contenant le contenu du buffer. Cette séquence d'octets est automatiquement réallouée lorsque plus de n caractères sont stockés dans le buffer, mais est ramenée à n caractères lorsque reset est exécuté. Pour des performances optimales, n doit être du même ordre de grandeur que le nombre de caractères que l'on s'attend à stocker dans le buffer (par exemple, 80 pour un buffer qui stocke une ligne de sortie). Rien de mal ne se produira si le buffer dépasse cette limite, bien qu'en cas de doute, prenez n = 16 par exemple. Si n n'est pas compris entre 1 et Sys.max_string_length, il est ramené à cet intervalle.

val contents : t -> string

Renvoie une copie du contenu actuel du buffer. Le buffer lui-même n'est pas modifié.

val to_bytes : t -> bytes

Renvoie une copie du contenu actuel du buffer. Le buffer lui-même n'est pas modifié.

Since 4.02

val sub : t -> int -> int -> string

Buffer.sub b off len renvoie une copie de len octets du contenu actuel du buffer b, commençant à la position off.

Raises Invalid_argument si off et len ne désignent pas un intervalle valide de b.

val blit : t -> int -> bytes -> int -> int -> unit

Buffer.blit src srcoff dst dstoff len copie len caractères du contenu actuel du buffer src, commençant à srcoff, vers dst, commençant à dstoff.

Since 3.11.2

Raises Invalid_argument si srcoff et len ne désignent pas un intervalle valide de src, ou si dstoff et len ne désignent pas un intervalle valide de dst.

val nth : t -> int -> char

Récupère le n-ième caractère du buffer.

Raises Invalid_argument si l'indice est hors limites.

val length : t -> int

Renvoie le nombre de caractères actuellement contenus dans le buffer.

val clear : t -> unit

Vide le buffer.

val reset : t -> unit

Vide le buffer et libère la séquence d'octets interne contenant le contenu du buffer, la remplaçant par la séquence d'octets initiale de longueur n allouée par Buffer.create n. Pour les buffers longs qui ont pu croître de manière significative, reset permet une reprise plus rapide de l'espace utilisé par le buffer.

val output_buffer : out_channel -> t -> unit

output_buffer oc b écrit le contenu actuel du buffer b sur le canal de sortie oc.

val truncate : t -> int -> unit

truncate b len réduit la longueur de b à len. Note: la séquence d'octets interne n'est pas tronquée.

Since 4.05

Raises Invalid_argument si len < 0 ou len > length b.

Ajout

Note: toutes les opérations add_* peuvent lever Failure si la séquence d'octets interne du buffer doit croître au-delà de Sys.max_string_length.

val add_substitute : t -> (string -> string) -> string -> unit

add_substitute b f s ajoute la chaîne modèle s à la fin du buffer b avec substitution. Le processus de substitution recherche les références de variables dans le modèle et substitue chaque référence de variable par sa valeur, obtenue en appliquant le mappage f au nom de la variable. Dans la chaîne modèle, une référence de variable est un caractère non échappé $ immédiatement suivi d'un nom de variable, qui est l'un des suivants :

- une séquence non vide de caractères alphanumériques ou _

- une séquence arbitraire de caractères enfermée entre une paire de parenthèses ou de crochets. Un caractère $ échappé est un $ qui suit immédiatement un caractère d'échappement ; les deux caractères forment ensemble un $ plat.

val add_buffer : t -> t -> unit

add_buffer b1 b2 ajoute le contenu actuel du buffer b2 à la fin du buffer b1. b2 n'est pas modifié.

val add_channel : t -> in_channel -> int -> unit

add_channel b ic n lit jusqu'à n caractères du canal d'entrée ic et les ajoute à la fin du buffer b.

Raises End_of_file si le canal contient moins de n caractères. Dans ce cas, les caractères sont toujours ajoutés au buffer, évitant ainsi la perte de données.

Raises Invalid_argument si len < 0 ou len > Sys.max_string_length.

NAME

Buffer — binary integer encoding into a buffer.

Module

Buffer

Documentation

The functions in this section append binary encodings of integers to buffers.

Little-endian (resp. big-endian) encoding means that least (resp. most) significant bytes are stored first. Big-endian is also known as network byte order. Native-endian encoding is either little-endian or big-endian depending on Sys.big_endian .

32-bit and 64-bit integers are represented by the int32 and int64 types, which can be interpreted either as signed or unsigned numbers.

8-bit and 16-bit integers are represented by the int type, which has more bits than the binary encoding. Functions that encode these values truncate their inputs to their least significant bytes.
