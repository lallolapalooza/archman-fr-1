Module Array
: (module ArrayLabels)

type 'a t = 'a array

Un alias pour le type des tableaux.

val length : 'a array -> int

Retourne la longueur (nombre d'éléments) du tableau donné.

val get : 'a array -> int -> 'a

get a n retourne le n-ième élément du tableau a. Le premier élément est l'indice 0. Le dernier élément est l'indice length a - 1. On peut aussi écrire a.(n) à la place de get a n.

Raises Invalid_argument si n est hors de l'intervalle 0 à length a - 1.

val set : 'a array -> int -> 'a -> unit

set a n x modifie le tableau a en remplaçant le n-ième élément par x. On peut aussi écrire a.(n) <- x à la place de set a n x.

Raises Invalid_argument si n est hors de l'intervalle 0 à length a - 1.

val make : int -> 'a -> 'a array

make n x retourne un nouveau tableau de longueur n, initialisé avec x. Tous les éléments de ce nouveau tableau sont initialement physiquement égaux à x (au sens de la relation =). Par conséquent, si x est mutable, il est partagé entre tous les éléments du tableau, et modifier x via un des éléments du tableau modifiera tous les autres éléments simultanément.

Raises Invalid_argument si n < 0 ou n > Sys.max_array_length. Si la valeur de x est un nombre flottant, la taille maximale n'est que de Sys.max_array_length / 2.

val create_float : int -> float array

create_float n retourne un nouveau tableau de flottants de longueur n dont les données ne sont pas initialisées.

Since 4.03

val init : int -> f:(int -> 'a) -> 'a array

init n ~f retourne un nouveau tableau de longueur n, avec l'élément d'indice i initialisé au résultat de f i. Autrement dit, init n ~f construit un tableau à partir des résultats de f appliqués en ordre aux entiers 0 à n-1.

Raises Invalid_argument si n < 0 ou n > Sys.max_array_length. Si le type de retour de f est float, la taille maximale n'est que de Sys.max_array_length / 2.

val make_matrix : dimx:int -> dimy:int -> 'a -> 'a array array

make_matrix ~dimx ~dimy e retourne un tableau à deux dimensions (un tableau de tableaux) avec la première dimension dimx et la deuxième dimension dimy. Tous les éléments de cette nouvelle matrice sont initialement physiquement égaux à e. L'élément ( x,y ) d'une matrice m est accédé par la notation m.(x).(y).

Raises Invalid_argument si dimx ou dimy est négatif ou supérieur à Sys.max_array_length. Si la valeur de e est un nombre flottant, la taille maximale n'est que de Sys.max_array_length / 2.

val init_matrix : dimx:int -> dimy:int -> f:(int -> int -> 'a) -> 'a array array

init_matrix ~dimx ~dimy ~f retourne un tableau à deux dimensions (un tableau de tableaux) avec la première dimension dimx et la deuxième dimension dimy, où l'élément à l'indice ( x,y ) est initialisé par f x y. L'élément ( x,y ) d'une matrice m est accédé par la notation m.(x).(y).

Since 5.2

Raises Invalid_argument si dimx ou dimy est négatif ou supérieur à Sys.max_array_length. Si le type de retour de f est float, la taille maximale n'est que de Sys.max_array_length / 2.

val append : 'a array -> 'a array -> 'a array

append v1 v2 retourne un nouveau tableau contenant la concaténation des tableaux v1 et v2.

Raises Invalid_argument si length v1 + length v2 > Sys.max_array_length.

val concat : 'a array list -> 'a array

À peu près la même chose que ArrayLabels.append, mais concatène une liste de tableaux.

val sub : 'a array -> pos:int -> len:int -> 'a array

sub a ~pos ~len retourne un nouveau tableau de longueur len, contenant les éléments d'indice pos à pos + len - 1 du tableau a.

Raises Invalid_argument si pos et len ne désignent pas un sous-tableau valide de a ; c'est-à-dire, si pos < 0 ou len < 0 ou pos + len > length a.

val copy : 'a array -> 'a array

copy a retourne une copie de a, c'est-à-dire un nouveau tableau contenant les mêmes éléments que a.

val fill : 'a array -> pos:int -> len:int -> 'a -> unit

fill a ~pos ~len x modifie le tableau a en stockant x dans les éléments d'indice pos à pos + len - 1.

Raises Invalid_argument si pos et len ne désignent pas un sous-tableau valide de a.

val blit : src:'a array -> src_pos:int -> dst:'a array -> dst_pos:int -> len:int -> unit

blit ~src ~src_pos ~dst ~dst_pos ~len copie len éléments du tableau src, en commençant par l'élément d'indice src_pos, vers le tableau dst, en commençant par l'élément d'indice dst_pos. Fonctionne correctement même si src et dst sont le même tableau, et si les blocs source et destination se chevauchent.

Raises Invalid_argument si src_pos et len ne désignent pas un sous-tableau valide de src, ou si dst_pos et len ne désignent pas un sous-tableau valide de dst.

val to_list : 'a array -> 'a list

to_list a retourne la liste de tous les éléments de a.

val of_list : 'a list -> 'a array

of_list l retourne un nouveau tableau contenant les éléments de l.

Raises Invalid_argument si la longueur de l est supérieure à Sys.max_array_length.

COMPARAISON

val equal : eq:('a -> 'a -> bool) -> 'a array -> 'a array -> bool

equal eq a b est true si et seulement si a et b ont la même longueur n et pour tout i dans [ 0 ; n-1 ], eq a.(i) b.(i) est true.

Since 5.4

val compare : cmp:('a -> 'a -> int) -> 'a array -> 'a array -> int

compare cmp a b compare a et b selon l'ordre lexicographique court, c'est-à-dire que les tableaux plus courts sont plus petits, et les tableaux de même longueur sont comparés en utilisant cmp pour comparer leurs éléments.

Since 5.4

ITÉRATEURS

val iter : f:('a -> unit) -> 'a array -> unit

iter ~f a applique la fonction f à tous les éléments de a. C'est équivalent à f a.(0); f a.(1); ...; f a.(length a - 1); ().

val iteri : f:(int -> 'a -> unit) -> 'a array -> unit

C'est la même chose que ArrayLabels.iter, mais la fonction est appliquée à l'indice de l'élément comme premier argument et à l'élément lui-même comme second argument.

val map : f:('a -> 'b) -> 'a array -> 'b array

map ~f a applique la fonction f à tous les éléments de a et construit un tableau avec les résultats de f appliqués à chaque élément de a : [| f a.(0); f a.(1); ...; f a.(length a - 1) |].

val map_inplace : f:('a -> 'a) -> 'a array -> unit

map_inplace ~f a applique la fonction f à tous les éléments de a et met à jour leurs valeurs sur place.

Since 5.1

val mapi : f:(int -> 'a -> 'b) -> 'a array -> 'b array

C'est la même chose que ArrayLabels.map, mais la fonction est appliquée à l'indice de l'élément comme premier argument et à l'élément lui-même comme second argument.

Itérateurs sur deux tableaux

val iter2 : f:('a -> 'b -> unit) -> 'a array -> 'b array -> unit

iter2 ~f a b applique la fonction f à tous les éléments de a et b .

Since 4.05

Raises Invalid_argument si les tableaux n'ont pas la même taille.

val map2 : f:('a -> 'b -> 'c) -> 'a array -> 'b array -> 'c array

map2 ~f a b applique la fonction f à tous les éléments de a et b , et construit un tableau avec les résultats de f : [| f a.(0) b.(0); ...; f a.(length a - 1) b.(length b - 1)|] .

Since 4.05

Raises Invalid_argument si les tableaux n'ont pas la même taille.

Balayage de tableaux

val for_all : f:('a -> bool) -> 'a array -> bool

for_all ~f [|a1; ...; an|] vérifie si tous les éléments du tableau satisfont le prédicat f . Autrement dit, il retourne (f a1) && (f a2) && ... && (f an) .

Since 4.03

val exists : f:('a -> bool) -> 'a array -> bool

exists ~f [|a1; ...; an|] vérifie si au moins un élément du tableau satisfait le prédicat f . Autrement dit, il retourne (f a1) || (f a2) || ... || (f an) .

Since 4.03

val for_all2 : f:('a -> 'b -> bool) -> 'a array -> 'b array -> bool

Identique à ArrayLabels.for_all , mais pour un prédicat à deux arguments.

Since 4.11

Raises Invalid_argument si les deux tableaux ont des longueurs différentes.

val exists2 : f:('a -> 'b -> bool) -> 'a array -> 'b array -> bool

Identique à ArrayLabels.exists , mais pour un prédicat à deux arguments.

Since 4.11

Raises Invalid_argument si les deux tableaux ont des longueurs différentes.

val mem : 'a -> set:'a array -> bool

mem a ~set est vrai si et seulement si a est structurellement égal à un élément de set (c'est-à-dire, il existe un x dans set tel que compare a x = 0 ).

Since 4.03

val memq : 'a -> set:'a array -> bool

Identique à ArrayLabels.mem , mais utilise l'égalité physique plutôt que l'égalité structurelle pour comparer les éléments des tableaux.

Since 4.03

val find_opt : f:('a -> bool) -> 'a array -> 'a option

find_opt ~f a retourne le premier élément du tableau a qui satisfait le prédicat f , ou None si aucun élément ne satisfait f dans a .

Since 4.13

val find_index : f:('a -> bool) -> 'a array -> int option

find_index ~f a retourne Some i , où i est l'indice du premier élément du tableau a qui satisfait f x , s'il existe un tel élément.

Il retourne None si un tel élément n'existe pas.

Since 5.1

val find_map : f:('a -> 'b option) -> 'a array -> 'b option

find_map ~f a applique f aux éléments de a dans l'ordre, et retourne le premier résultat de la forme Some v , ou None s'il n'y a pas de tels résultats.

Since 4.13

val find_mapi : f:(int -> 'a -> 'b option) -> 'a array -> 'b option

Identique à find_map , mais le prédicat est appliqué à l'indice de l'élément comme premier argument (en commençant par 0), et à l'élément comme deuxième argument.

Since 5.1

Tableaux de paires

val split : ('a * 'b) array -> 'a array * 'b array

split [|(a1,b1); ...; (an,bn)|] est ([|a1; ...; an|], [|b1; ...; bn|]) .

Since 4.13

val combine : 'a array -> 'b array -> ('a * 'b) array

combine [|a1; ...; an|] [|b1; ...; bn|] est [|(a1,b1); ...; (an,bn)|] . Lève Invalid_argument si les deux tableaux ont des longueurs différentes.

Since 4.13

Tri et mélanges

val sort : cmp:('a -> 'a -> int) -> 'a array -> unit

Trie un tableau par ordre croissant selon une fonction de comparaison. La fonction de comparaison doit retourner 0 si ses arguments sont égaux, un nombre positif si le premier est plus grand, et un nombre négatif si le premier est plus petit (voir la spécification complète ci-dessous). Par exemple, compare est une fonction de comparaison appropriée. Après avoir appelé sort, le tableau est trié sur place.

Since 4.00

val sort_uniq : cmp:('a -> 'a -> int) -> 'a array -> unit

Trie un tableau et lève Invalid_argument si le tableau contient des éléments dupliqués. La fonction de comparaison doit être réflexive (c'est-à-dire que cmp x x = 0 pour tout x).

Since 4.07

val reverse_sort : cmp:('a -> 'a -> int) -> 'a array -> unit

Trie un tableau par ordre décroissant selon une fonction de comparaison.

Since 4.08

val stable_sort : cmp:('a -> 'a -> int) -> 'a array -> unit

Similaire à sort, mais garantit la stabilité du tri. Cela signifie que les éléments qui sont égaux selon la fonction de comparaison conservent leur ordre relatif d'origine.

Since 4.01

val stable_sort_uniq : cmp:('a -> 'a -> int) -> 'a array -> unit

Similaire à sort_uniq, mais garantit la stabilité du tri.

Since 4.07

val nth_element : cmp:('a -> 'a -> int) -> k:int -> 'a array -> unit

Réorganise un tableau de telle sorte que l'élément à l'indice k soit l'élément qui serait à cet indice si le tableau était trié. Tous les éléments avant l'indice k sont inférieurs ou égaux à l'élément à l'indice k, et tous les éléments après l'indice k sont supérieurs ou égaux à l'élément à l'indice k. L'ordre des éléments avant et après l'indice k n'est pas garanti.

Since 4.08

val shuffle : random_state:Random.State.t -> 'a array -> unit

Mélange aléatoirement un tableau sur place, en utilisant le générateur de nombres aléatoires fourni par random_state.

Since 4.09

Tableaux de flottants

Les tableaux de flottants présentent deux mises en garde supplémentaires en présence de courses de données.

Premièrement, l'opération de copie peut copier un tableau octet par octet. Les courses de données entre une telle opération de copie et une autre opération peuvent produire des valeurs surprenantes dues à la déchirure (tearing) : les écritures partielles entrelacées avec d'autres opérations peuvent créer des valeurs flottantes qui n'existeraient pas avec une exécution séquentielle.

Par exemple, à la fin de

let zeros = Array.make size 0.
let max_floats = Array.make size Float.max_float
let res = Array.copy zeros
let d1 = Domain.spawn (fun () -> Array.blit zeros 0 res 0 size)
let d2 = Domain.spawn (fun () -> Array.blit max_floats 0 res 0 size)
let () = Domain.join d1; Domain.join d2
le tableau res peut contenir des valeurs qui ne sont ni 0. ni max_float.

Deuxièmement, sur les architectures 32 bits, l'obtention ou la définition d'un champ implique deux accès mémoire distincts. En présence de courses de données, l'utilisateur peut observer une déchirure sur toute opération.
