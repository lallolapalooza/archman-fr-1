NAME

String::Util — fonctions de traitement de chaînes

DESCRIPTION

String::Util fournit une collection de petites fonctions pratiques pour traiter les chaînes de caractères de diverses manières.

INSTALLATION

cpanm String::Util

UTILISATION

Aucune fonction n'est exportée par défaut, elles doivent être spécifiées :

use String::Util qw(trim eqq contains)

alternativement, vous pouvez utiliser ":all" pour exporter toutes les fonctions

use String::Util qw(:all)

FONCTIONS

collapse($string)

collapse() condense tous les espaces blancs dans la chaîne en espaces simples. Il supprime également tous les espaces au début et à la fin. Une entrée indéfinie produit une sortie indéfinie.

$var = collapse("  Hello     world!    "); # "Hello world!"

hascontent($scalar), nocontent($scalar)

hascontent() renvoie vrai si l'argument donné est défini et contient autre chose que des espaces. Une valeur indéfinie renvoie faux. Une chaîne vide renvoie faux. Une valeur ne contenant que des espaces (espaces, tabulations, sauts de ligne, retour arrière) renvoie faux. Une chaîne contenant d'autres caractères (y compris le zéro) renvoie vrai.

nocontent() renvoie la négation de hascontent().

$var = hascontent("");  # Faux
$var = hascontent(" "); # Faux
$var = hascontent("a"); # Vrai
$var = nocontent("");   # Vrai
$var = nocontent("a");  # Faux

trim($string), ltrim($string), rtrim($string)

Renvoie la chaîne avec tous les espaces au début et à la fin supprimés.

$var = trim(" my string  "); # "my string"

ltrim() supprime uniquement les espaces de début.

rtrim() supprime uniquement les espaces de fin.

nospace($string)

Supprime tous les caractères d'espacement de la chaîne donnée. Cela inclut les espaces entre les mots.

$var = nospace("  Hello World!   "); # "HelloWorld!"

htmlesc($string)

Met en forme une chaîne pour une sortie HTML littérale. Une valeur indéfinie est renvoyée sous forme de chaîne vide.

htmlesc() est très similaire à CGI.pm escapeHTML(). Il existe cependant quelques différences. htmlesc() convertit une valeur indéfinie en une chaîne vide, tandis que escapeHTML() renvoie les indéfinis comme indéfinis.

jsquote($string)

Échappe et cite une chaîne pour une utilisation en JavaScript. Échappe les apostrophes et encadre la chaîne d'apostrophes. Renvoie la chaîne modifiée.

unquote($string)

Si la chaîne donnée commence et se termine par des guillemets, ils sont supprimés. Reconnaît les guillemets simples et doubles. La valeur doit commencer et se terminer par le même type de guillemets, sinon aucune modification n'est apportée à la valeur. Une entrée indéfinie produit une sortie indéfinie. Exemples :

unquote(q|'Hendrix'|);   # Hendrix
unquote(q|"Hendrix"|);   # Hendrix
unquote(q|Hendrix|);     # Hendrix
unquote(q|"Hendrix'|);   # "Hendrix'
unquote(q|O'Sullivan|);  # O'Sullivan

option: accolades

Si l'option accolades est vraie, les accolades comme [] et {} sont également supprimées. Exemples :

unquote(q|[Janis]|, braces=>1);  # Janis
unquote(q|{Janis}|, braces=>1);  # Janis
unquote(q|(Janis)|, braces=>1);  # Janis

repeat($string, $count)

Renvoie la chaîne donnée répétée le nombre de fois spécifié. La commande suivante affiche "Fred" trois fois :

print repeat('Fred', 3), "\n";

Remarque : repeat() a été créé il y a un certain temps sur la base d'une mauvaise compréhension du fonctionnement de l'opérateur 'x' en Perl. La commande suivante utilisant "x" fait exactement la même chose que la précédente.

print 'Fred' x 3, "\n";

Utilisez ce que vous préférez.

eqq($scalar1, $scalar2)

Renvoie vrai si les deux valeurs données sont égales. Renvoie également vrai si les deux sont "undef". Si une seule est "undef" ou si les deux sont définies mais différentes, renvoie faux. Voici quelques exemples et ce qu'ils renvoient :

$var = eqq('x', 'x');     # Vrai
$var = eqq('x', undef);   # Faux
$var = eqq(undef, undef); # Vrai

neqq($scalar1, $scalar2)

L'inverse de "eqq", renvoie vrai si les deux valeurs sont *non* égales. Voici quelques exemples et ce qu'ils renvoient.

$var = neqq('x', 'x');     # Faux
$var = neqq('x', undef);   # Vrai
$var = neqq(undef, undef); # Faux

ords($string)

Renvoie la chaîne représentée par les valeurs ASCII de chaque caractère.

$var = ords('Hendrix'); # {72}{101}{110}{100}{114}{105}{120}

options

  • convert_spaces=>[true|false]

    Si convert_spaces est vrai (ce qui est la valeur par défaut), les espaces sont convertis en leurs valeurs correspondantes. Par exemple, ce code :

    $var = ords('a b', convert_spaces=>1); # {97}{32}{98}

    Ce code renvoie la même chose :

    $var = ords('a b');                    # {97}{32}{98}

    Si convert_spaces est faux, les espaces sont simplement renvoyés comme des espaces. Par exemple, ce code :

    ords('a b', convert_spaces=>0);        # {97} {98}
  • alpha_nums

    Si l'option alpha_nums est fausse, les caractères 0-9, a-z et A-Z ne sont pas convertis. Par exemple, ce code :

    $var = ords('a=b', alpha_nums=>0); # a{61}b

deords($string)

Prend la sortie de ords() et renvoie la chaîne d'origine qui l'a générée.

$var = deords('{72}{101}{110}{100}{114}{105}{120}'); # 'Hendrix'

contains($string, $substring)

Vérifie si la chaîne contient la sous-chaîne.

$var = contains("Hello world", "Hello");   # vrai
$var = contains("Hello world", "llo wor"); # vrai
$var = contains("Hello world", "");        # vrai
$var = contains("Hello world", "QQQ");     # faux
$var = contains(undef, "QQQ");             # faux
$var = contains("Hello world", undef);     # faux
# Fonctionne aussi avec grep
@arr = grep { contains("cat") } @input;

startswith($string, $substring)

Vérifie si la chaîne commence par les caractères de la sous-chaîne.

$var = startswith("Hello world", "Hello"); # vrai
$var = startswith("Hello world", "H");     # vrai
$var = startswith("Hello world", "");      # vrai
$var = startswith("Hello world", "Q");     # faux
$var = startswith(undef, "Q");
