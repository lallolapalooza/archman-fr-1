Module Parsing
: (module Stdlib__Parsing)

val symbol_start : unit -> int

symbol_start et Parsing.symbol_end ne doivent être appelés que dans la partie action d'une règle de grammaire. Ils retournent le décalage de la chaîne qui correspond au membre gauche de la règle : symbol_start() retourne le décalage du premier caractère ; symbol_end() retourne le décalage après le dernier caractère. Le premier caractère d'un fichier est au décalage 0.

val symbol_end : unit -> int

Voir Parsing.symbol_start.

val rhs_start : int -> int

Identique à Parsing.symbol_start et Parsing.symbol_end, mais retourne le décalage de la chaîne correspondant au n-ième élément du côté droit de la règle, où n est le paramètre entier de rhs_start et rhs_end. n vaut 1 pour le premier élément (le plus à gauche).

val rhs_end : int -> int

Voir Parsing.rhs_start.

val symbol_start_pos : unit -> Lexing.position

Identique à symbol_start, mais retourne une position au lieu d'un décalage.

val symbol_end_pos : unit -> Lexing.position

Identique à symbol_end, mais retourne une position au lieu d'un décalage.

val rhs_start_pos : int -> Lexing.position

Identique à rhs_start, mais retourne une position au lieu d'un décalage.

val rhs_end_pos : int -> Lexing.position

Identique à rhs_end, mais retourne une position au lieu d'un décalage.

val clear_parser : unit -> unit

Vide la pile de l'analyseur. Appelez-la juste après qu'une fonction d'analyse ait retourné, pour supprimer tous les pointeurs de la pile de l'analyseur vers des structures qui ont été construites par des actions sémantiques pendant l'analyse. Ceci est facultatif, mais réduit les besoins en mémoire des programmes.

exception Parse_error

Levée lorsqu'un analyseur rencontre une erreur de syntaxe. Peut également être levée depuis la partie action d'une règle de grammaire, pour initier la récupération d'erreur.

val set_trace : bool -> bool

Contrôle le support de débogage pour les analyseurs générés par ocamlyacc. Après Parsing.set_trace true, l'automate de pile qui exécute les analyseurs imprime une trace de ses actions (lecture d'un jeton, décalage d'un état, réduction par une règle) sur la sortie standard. Parsing.set_trace false désactive cette trace de débogage. La valeur booléenne retournée est l'état précédent du drapeau de trace.
