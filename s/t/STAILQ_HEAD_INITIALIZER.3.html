STAILQ(3) Manuel des fonctions C standard STAILQ(3)

NOM

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, - implémentation d'une file à queue liée simple

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/queue.h>
STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);
STAILQ_HEAD STAILQ_HEAD_INITIALIZER(STAILQ_HEAD head);
void STAILQ_INIT(STAILQ_HEAD *head);
int STAILQ_EMPTY(STAILQ_HEAD *head);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
struct TYPE *STAILQ_FIRST(STAILQ_HEAD *head);
struct TYPE *STAILQ_NEXT(struct TYPE *elm, STAILQ_ENTRY NAME);
STAILQ_FOREACH(struct TYPE *var, STAILQ_HEAD *head, STAILQ_ENTRY NAME);
void STAILQ_REMOVE(STAILQ_HEAD *head, struct TYPE *elm, TYPE,
                         STAILQ_ENTRY NAME);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *head,
                         STAILQ_ENTRY NAME);
void STAILQ_CONCAT(STAILQ_HEAD *head1, STAILQ_HEAD *head2);

Note : Des macros identiques commençant par SIMPLEQ au lieu de STAILQ existent ; voir VERSIONS.

DESCRIPTION

Ces macros définissent et opèrent sur des files à queue liées simples.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée à l'aide de la macro STAILQ_HEAD().

Création

Une file à queue liée simple est dirigée par une structure définie par la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont liés de manière simple pour minimiser l'espace et la surcharge de manipulation des pointeurs, au détriment d'une surcharge en O(n) pour supprimer des éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, en tête de file, ou à la fin de la file. Une structure STAILQ_HEAD est déclarée comme suit :


STAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments liés dans la file. Un pointeur vers la tête de file peut ensuite être déclaré comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont choisissables par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui relie les éléments de la file.

STAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file head.

STAILQ_INIT() initialise la file référencée par head.

STAILQ_EMPTY() renvoie vrai si aucun élément n'est dans la file.

Insertion

STAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de file.

STAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file.

STAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

STAILQ_FIRST() renvoie le premier élément de la file ou NULL si la file est vide.

STAILQ_NEXT() renvoie l'élément suivant dans la file, ou NULL si c'est le dernier.

STAILQ_FOREACH() parcourt la file référencée par head dans l'ordre, assignant chaque élément à var par ordre.

Suppression

STAILQ_REMOVE() supprime l'élément elm de la file.

STAILQ_REMOVE_HEAD() supprime l'élément en tête de file. Pour une efficacité optimale, les éléments supprimés de la tête de file devraient utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE().

Autres_fonctions

STAILQ_CONCAT() concatène la file à queue liée dirigée par head2 à la fin de la file à queue liée dirigée par head1, vidant la première.

VALEUR_DE_RETOUR

STAILQ_EMPTY() renvoie une valeur non nulle si la file est vide, et zéro si elle contient au moins un élément.

STAILQ_FIRST() et STAILQ_NEXT() renvoient un pointeur vers la première ou la suivante structure TYPE, respectivement.

STAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la file head.

VERSIONS

Certaines BSDs offrent SIMPLEQ au lieu de STAILQ. Elles sont identiques, mais pour des raisons historiques, elles ont été nommées différemment dans différentes BSDs. STAILQ provient de FreeBSD, et SIMPLEQ de NetBSD. Pour des raisons de compatibilité, certains systèmes offrent les deux séries de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques à l'exception de l'absence d'équivalent SIMPLEQ pour STAILQ_CONCAT().

PROBLÈMES

STAILQ_FOREACH() ne permet pas de supprimer ou libérer var à l'intérieur de la boucle, car cela pourrait interférer avec le parcours. STAILQ_FOREACH_SAFE(), présent dans les BSDs mais pas dans glibc, résout cette limitation en permettant à var d'être supprimé en toute sécurité de la liste et libéré à l'intérieur de la boucle sans interférer avec le parcours.

NORMES

BSD.

HISTORIQUE

4.4BSD.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File à queue liée simple */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Tête de file à queue liée simple */
    STAILQ_INIT(&head);                     /* Initialise la file */
    n1 = malloc(sizeof(struct entry));      /* Insertion en tête */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion à la queue */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression de la tête */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;

NOM

STAILQ - Implémentation de file d'attente

BIBLIOTHÈQUE

STAILQ

SYNTAXE

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>

#include <libstailq.h>

DESCRIPTION

Le STAILQ est une implémentation de file d'attente qui prend en charge la traversée avant et arrière. Il utilise une structure de liste chaînée pour gérer la file d'attente, permettant des opérations d'insertion et de suppression efficaces.

VALEUR DE RETOUR

La fonction STAILQ_EMPTY renvoie 1 si la file d'attente est vide, et 0 sinon.

VERSIONS

La fonction STAILQ est disponible dans les versions suivantes :

  • 6.16-1

BOGUES

Les bogues suivants ont été signalés :

  • Problème avec STAILQ_EMPTY dans certaines conditions.
  • Gestion incorrecte des opérations sur liste chaînée dans certains cas.

NORMES

L'implémentation STAILQ suit les normes suivantes :

  • BSD-3-Clause

  • BSD-4-Clause-UC
  • GPL-1.0-or-later

  • GPL-2.0-or-later

HISTORIQUE

L'implémentation STAILQ a l'historique suivant :

  • Version 6.16-1 : Version initiale.

EXEMPLES

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>

#include <libstailq.h>

int main() {
    STAILQ_HEAD *head = STAILQ_HEAD_INITIALIZER(&head, entries);
    STAILQ_FOREACH(np, &head, entries) {
        printf("%i\n", np->data);
    }

    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
