STAILQ(3) Manuel des fonctions de bibliothèque STAILQ(3)

NOM

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_ENTRY, STAILQ_FIRST, STAILQ_FOREACH, STAILQ_HEAD, STAILQ_HEAD_INITIALIZER, STAILQ_INIT, STAILQ_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_NEXT, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, - implémentation d'une file d'attente liée simple

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/queue.h>
STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);
STAILQ_HEAD STAILQ_HEAD_INITIALIZER(STAILQ_HEAD head);
void STAILQ_INIT(STAILQ_HEAD *head);
int STAILQ_EMPTY(STAILQ_HEAD *head);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
struct TYPE *STAILQ_FIRST(STAILQ_HEAD *head);
struct TYPE *STAILQ_NEXT(struct TYPE *elm, STAILQ_ENTRY NAME);
STAILQ_FOREACH(struct TYPE *var, STAILQ_HEAD *head, STAILQ_ENTRY NAME);
void STAILQ_REMOVE(STAILQ_HEAD *head, struct TYPE *elm, TYPE,
                         STAILQ_ENTRY NAME);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *head,
                         STAILQ_ENTRY NAME);
void STAILQ_CONCAT(STAILQ_HEAD *head1, STAILQ_HEAD *head2);

Note : Des macros identiques préfixées par SIMPLEQ au lieu de STAILQ existent ; voir VERSIONS.

DESCRIPTION

Ces macros définissent et opèrent sur des files d'attente liées simples.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro STAILQ_HEAD().

Création

Une file d'attente liée simple est dirigée par une structure définie par la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, un vers le premier élément de la file d'attente et l'autre vers le dernier élément de la file d'attente. Les éléments sont liés de manière simple pour un minimum d'espace et de manipulation de pointeurs au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file d'attente après un élément existant, en tête de la file d'attente, ou à la fin de la file d'attente. Une structure STAILQ_HEAD est déclarée comme suit :


STAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à lier dans la file d'attente. Un pointeur vers la tête de la file d'attente peut ensuite être déclaré comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui relie les éléments de la file d'attente.

STAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file d'attente head.

STAILQ_INIT() initialise la file d'attente référencée par head.

STAILQ_EMPTY() évalue à vrai s'il n'y a pas d'éléments dans la file d'attente.

Insertion

STAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de la file d'attente.

STAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file d'attente.

STAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

STAILQ_FIRST() renvoie le premier élément de la file d'attente ou NULL si la file d'attente est vide.

STAILQ_NEXT() renvoie l'élément suivant dans la file d'attente, ou NULL si cet élément est le dernier.

STAILQ_FOREACH() parcourt la file d'attente référencée par head dans le sens avant, en attribuant chaque élément à tour de rôle à var.

Suppression

STAILQ_REMOVE() supprime l'élément elm de la file d'attente.

STAILQ_REMOVE_HEAD() supprime l'élément en tête de la file d'attente. Pour une efficacité optimale, les éléments retirés de la tête de la file d'attente devraient utiliser cette macro explicitement plutôt que la macro générique STAILQ_REMOVE().

Autres fonctionnalités

STAILQ_CONCAT() concatène la file d'attente dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première.

VALEUR DE RETOUR

STAILQ_EMPTY() renvoie une valeur non nulle si la file est vide, et zéro si la file contient au moins une entrée.

STAILQ_FIRST() et STAILQ_NEXT() renvoient un pointeur vers la structure TYPE première ou suivante, respectivement.

STAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la file head.

VERSIONS

Certains BSD fournissent SIMPLEQ au lieu de STAILQ. Ils sont identiques, mais pour des raisons historiques, ils ont été nommés différemment sur les différents BSD. STAILQ est originaire de FreeBSD, et SIMPLEQ de NetBSD. Pour des raisons de compatibilité, certains systèmes fournissent les deux ensembles de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques, sauf pour un équivalent SIMPLEQ manquant à STAILQ_CONCAT().

BOGUES

STAILQ_FOREACH() ne permet pas de supprimer ou de libérer var dans la boucle, car cela interférerait avec le parcours. STAILQ_FOREACH_SAFE(), qui est présent sur les BSD mais pas dans glibc, corrige cette limitation en permettant de supprimer var en toute sécurité de la liste et de le libérer depuis la boucle sans interférer avec le parcours.

NORMES

BSD.

HISTORIQUE

4.4BSD.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File d'attente liée simple */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Tête de file d'attente liée simple
                                               */
    STAILQ_INIT(&head);                     /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insérer en tête */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insérer à la fin */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression de la tête */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }

NAME

STAILQ_INSERT_AFTER, STAILQ_INSERT_BEFORE, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_REMOVE — manipulation de listes chaînées de taille fixe

LIBRARY

La bibliothèque C standard (libc)

SYNOPSIS

#include <sys/queue.h>

        (liste)
        (elt)
        (np)
        (entries)
        (head)
        (n1)
        (n2)

        STAILQ_INSERT_HEAD(head, np, entries);
        STAILQ_INSERT_TAIL(head, np, entries);
        STAILQ_INSERT_AFTER(head, elt, np, entries);
        STAILQ_INSERT_BEFORE(head, elt, np, entries);
        STAILQ_REMOVE_HEAD(head, np, entries);
        STAILQ_REMOVE_TAIL(head, np, entries);
        STAILQ_REMOVE(head, np, entries);
        STAILQ_CONCAT(head1, head2, entries);
        STAILQ_SWAP(head1, head2, type);

DESCRIPTION

Ces macros implémentent des listes chaînées simples. Une liste chaînée simple est une liste chaînée où chaque nœud ne contient qu'un pointeur vers le nœud suivant. La liste est chaînée dans un seul sens.

Les listes chaînées simples sont implémentées à l'aide de deux structures principales :

struct staq_head
Tient la tête de la liste chaînée. Elle est généralement déclarée comme suit :
STAILQ_HEAD(my_list, entry);
struct my_list my_list_head;
struct staq_entry
Représente un nœud dans la liste chaînée. Il contient un pointeur stqh_next qui pointe vers le nœud suivant dans la liste.

Les macros sont les suivantes :

STAILQ_HEAD
Déclare une structure de tête de liste chaînée simple. La première macro est le nom de la nouvelle structure de liste. La seconde macro est le nom de la structure des entrées de la liste.
STAILQ_HEAD_INITIALIZER
Initialise une tête de liste chaînée simple. L'expression peut être utilisée pour initialiser statiquement une tête de liste chaînée simple.
STAILQ_INIT
Initialise une tête de liste chaînée simple.
STAILQ_INSERT_HEAD
Insère np au début de la liste head.
STAILQ_INSERT_TAIL
Insère np à la fin de la liste head.
STAILQ_INSERT_AFTER
Insère np après elt dans la liste head.
STAILQ_INSERT_BEFORE
Insère np avant elt dans la liste head.
STAILQ_REMOVE_HEAD
Supprime la première entrée de la liste head et la place dans np.
STAILQ_REMOVE_TAIL
Supprime la dernière entrée de la liste head et la place dans np.
STAILQ_REMOVE
Supprime l'entrée np de la liste head.
STAILQ_CONCAT
Concatène la liste head2 à la fin de la liste head1. La liste head2 sera vide après l'opération.
STAILQ_SWAP
Échange les listes head1 et head2. type est le nom de la structure de la tête de liste.
STAILQ_FIRST
Renvoie la première entrée de la liste head, ou NULL si la liste est vide.
STAILQ_NEXT
Renvoie la prochaine entrée de la liste après np, ou NULL si np est la dernière entrée.
STAILQ_EMPTY
Renvoie vrai si la liste head est vide, faux sinon.
STAILQ_FOREACH
Parcourt chaque entrée de la liste head. np est un pointeur vers l'entrée actuelle. Le champ entries est le nom du champ de membre de la structure d'entrée qui pointe vers le prochain élément.
STAILQ_FOREACH_SAFE
Similaire à STAILQ_FOREACH, mais permet de supprimer des éléments en toute sécurité pendant la boucle. next est une variable temporaire qui stocke le pointeur vers l'élément suivant avant l'itération.

RETURN VALUE

STAILQ_FIRST renvoie la première entrée de la liste, ou NULL si la liste est vide.

STAILQ_NEXT renvoie la prochaine entrée de la liste, ou NULL si l'entrée actuelle est la dernière.

STAILQ_EMPTY renvoie vrai si la liste est vide, faux sinon.

VERSIONS

Ces macros sont disponibles dans la plupart des implémentations BSD et sont portées sur d'autres systèmes d'exploitation.

BUGS

Aucun bug connu.

STANDARDS

Ces macros sont basées sur les listes chaînées BSD. Elles ne font pas partie d'un standard ANSI/ISO.

HISTORY

Les macros de liste chaînée ont été introduites dans BSD. Les macros STAILQ_* ont été ajoutées plus tard pour gérer les listes chaînées simples.

EXAMPLES

Voici un exemple d'utilisation des macros STAILQ_* pour créer, remplir et parcourir une liste chaînée simple :

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    STAILQ_ENTRY(node) entries;
};

STAILQ_HEAD(my_list, node);

int
main(void) {
    struct my_list head;
    struct node *np, *n1, *n2;

    STAILQ_INIT(&head);

    /* Insérer des éléments au début */
    np = malloc(sizeof(struct node));
    np->data = 1;
    STAILQ_INSERT_HEAD(&head, np, entries);

    np = malloc(sizeof(struct node));
    np->data = 2;
    STAILQ_INSERT_HEAD(&head, np, entries);

    /* Insérer un élément à la fin */
    np = malloc(sizeof(struct node));
    np->data = 3;
    STAILQ_INSERT_TAIL(&head, np, entries);

    /* Insérer un élément après un autre */
    np = malloc(sizeof(struct node));
    np->data = 4;
    STAILQ_INSERT_AFTER(&head, head.stqh_first, np, entries); /* Insérer après le premier élément (qui est 2) */

    /* Parcourir la liste */
    printf("Forward traversal:\n");
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);

    /* Supprimer tous les éléments de la liste */
    printf("\nTailQ deletion:\n");
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
