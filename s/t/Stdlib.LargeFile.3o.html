Module LargeFile
: sig end

Opérations sur les fichiers volumineux. Ce sous-module fournit des variantes 64 bits des fonctions de canal qui manipulent les positions et les tailles de fichiers. En représentant les positions et les tailles par des entiers 64 bits (type int64 ) au lieu d'entiers ordinaires (type int ), ces fonctions alternatives permettent d'opérer sur des fichiers dont la taille est supérieure à max_int .

val seek_out : out_channel -> int64 -> unit

val pos_out : out_channel -> int64

val out_channel_length : out_channel -> int64

val seek_in : in_channel -> int64 -> unit

val pos_in : in_channel -> int64

val in_channel_length : in_channel -> int64
