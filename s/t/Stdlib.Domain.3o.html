Module Domain
: (module Stdlib__Domain)

Alerte instable. L'interface Domain peut changer de manière incompatible à l'avenir.

type !'a t

Un domaine de type 'a t s'exécute indépendamment, produisant éventuellement un résultat de type 'a, ou une exception.

val spawn : (unit -> 'a) -> 'a t

spawn f crée un nouveau domaine qui s'exécute en parallèle avec le domaine actuel.

Lève Failure si le programme manque de ressources pour créer un autre domaine.

val join : 'a t -> 'a

join d bloque jusqu'à ce que le domaine d se termine. Si d produit une valeur, celle-ci est retournée par join d. Si d lève une exception non capturée, celle-ci est relancée par join d.

type id = private int

Les domaines ont des identifiants entiers uniques.

val get_id : 'a t -> id

get_id d retourne l'identifiant du domaine d.

val self : unit -> id

self () est l'identifiant du domaine en cours d'exécution.

val before_first_spawn : (unit -> unit) -> unit

before_first_spawn f enregistre f pour être appelé avant que le premier domaine ne soit lancé par le programme. Les fonctions enregistrées avec before_first_spawn sont appelées sur le domaine principal (initial). Les fonctions enregistrées avec before_first_spawn sont appelées dans l'ordre « premier arrivé, premier servi » : la fonction la plus ancienne ajoutée avec before_first_spawn est appelée en premier.

Lève Invalid_argument si le programme a déjà lancé un domaine.

val at_exit : (unit -> unit) -> unit

at_exit f enregistre f pour être appelé lorsque le domaine actuel se termine. Notez que les rappels at_exit sont locaux au domaine et ne s'appliquent qu'au domaine appelant. Les fonctions enregistrées sont appelées dans l'ordre « dernier arrivé, premier sorti » : la fonction la plus récemment ajoutée avec at_exit est appelée en premier. Un exemple :

let temp_file_key = Domain.DLS.new_key (fun _ ->
  let tmp = snd (Filename.open_temp_file "" "") in
  Domain.at_exit (fun () -> close_out_noerr tmp);
  tmp)

L'extrait ci-dessus crée une clé qui, lorsqu'elle est récupérée pour la première fois, ouvrira un fichier temporaire et enregistrera un rappel at_exit pour le fermer, garantissant ainsi que le descripteur ne sera pas divulgué au cas où le domaine actuel se terminerait.

val cpu_relax : unit -> unit

En cas d'attente active, appeler cpu_relax () entre les itérations améliorera les performances sur certaines architectures CPU.

val is_main_domain : unit -> bool

is_main_domain () retourne vrai si appelé depuis le domaine initial.

val recommended_domain_count : unit -> int

Le nombre maximum recommandé de domaines qui devraient s'exécuter simultanément (y compris les domaines déjà en cours d'exécution).

La valeur retournée est au moins 1.

val self_index : unit -> int

L'indice du domaine actuel. C'est un entier unique parmi les domaines en cours d'exécution, dans l'intervalle 0; N-1 où N est le nombre maximal de domaines exécutés simultanément jusqu'à présent.

L'indice d'un domaine terminé peut être réutilisé pour un nouveau domaine. Utilisez (Domain.self () :> int) à la place pour un identifiant unique parmi tous les domaines jamais créés par le programme.
