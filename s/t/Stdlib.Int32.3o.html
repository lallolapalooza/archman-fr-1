val rem : int32 -> int32 -> int32

Reste de la division entière. Si y n'est pas zéro, le résultat de Int32.rem x y satisfait la propriété suivante : x = Int32.add (Int32.mul (Int32.div x y) y) (Int32.rem x y) . Si y = 0 , Int32.rem x y lève Division_by_zero .

val shift_left : int32 -> int -> int32

Int32.shift_left x y décale x vers la gauche de y bits. Le résultat est indéterminé si y < 0 ou y >= 32 .

val shift_right : int32 -> int -> int32

Int32.shift_right x y décale x vers la droite de y bits. C'est un décalage arithmétique : le bit de signe de x est répété et inséré dans les bits libérés. Le résultat est indéterminé si y < 0 ou y >= 32 .

val shift_right_logical : int32 -> int -> int32

Int32.shift_right_logical x y décale x vers la droite de y bits. C'est un décalage logique : des zéros sont insérés dans les bits libérés indépendamment du signe de x . Le résultat est indéterminé si y < 0 ou y >= 32 .

val of_int : int -> int32

Convertit l'entier donné (type int ) en un entier 32 bits (type int32 ). Sur les plateformes 64 bits, l'argument est pris modulo 2^32.

val to_int : int32 -> int

Convertit l'entier 32 bits donné (type int32 ) en un entier (type int ). Sur les plateformes 32 bits, l'entier 32 bits est pris modulo 2^31, c'est-à-dire que le bit de poids fort est perdu lors de la conversion. Sur les plateformes 64 bits, la conversion est exacte.

val unsigned_to_int : int32 -> int option

Identique à Int32.to_int , mais interprète l'argument comme un entier non signé. Renvoie None si la valeur non signée de l'argument ne peut pas tenir dans un int .

Depuis 4.08

val of_float : float -> int32

Convertit le nombre à virgule flottante donné en un entier 32 bits, en ignorant la partie fractionnaire (troncature vers zéro). Si le nombre à virgule flottante tronqué est en dehors de l'intervalle [ Int32.min_int , Int32.max_int ], aucune exception n'est levée, et un entier indéterminé et dépendant de la plateforme est renvoyé.

val to_float : int32 -> float

Convertit l'entier 32 bits donné en un nombre à virgule flottante.

val of_string : string -> int32

Convertit la chaîne donnée en un entier 32 bits. La chaîne est lue en décimal (par défaut, ou si la chaîne commence par 0u ) ou en hexadécimal, octal ou binaire si la chaîne commence par 0x , 0o ou 0b respectivement.

Le préfixe 0u lit l'entrée comme un entier non signé dans l'intervalle [0, 2*Int32.max_int+1] . Si l'entrée dépasse Int32.max_int elle est convertie en l'entier signé Int32.min_int + input - Int32.max_int - 1 .

Le caractère _ (souligné) peut apparaître n'importe où dans la chaîne et est ignoré.

Lève Failure si la chaîne donnée n'est pas une représentation valide d'un entier, ou si l'entier représenté dépasse la plage des entiers représentables dans le type int32 .

val of_string_opt : string -> int32 option

Identique à of_string , mais renvoie None au lieu de lever une exception.

val to_string : int32 -> string

val bits_of_float : float -> int32

Renvoie la représentation interne du flottant donné selon la mise en page des bits du format 'simple précision' IEEE 754. Le bit 31 du résultat représente le signe du flottant ; les bits 30 à 23 représentent l'exposant (biaisé) ; les bits 22 à 0 représentent la mantisse.

val float_of_bits : int32 -> float

Renvoie le nombre à virgule flottante dont la représentation interne, selon la mise en page des bits du format 'simple précision' IEEE 754, est l'entier 32 bits donné.

NOM

Stdlib.Int32 - Entiers 32 bits signés.

Module

Stdlib.Int32

Documentation

Ce module fournit des opérations sur les entiers 32 bits signés.

Les valeurs de type int32 sont des entiers 32 bits signés.

Les fonctions suivantes sont disponibles :

  • compare : int32 -> int32 -> int : Compare deux entiers 32 bits. Retourne un entier négatif si le premier est plus petit que le second, zéro s'ils sont égaux, et un entier positif si le premier est plus grand que le second.
  • equal : int32 -> int32 -> bool : Vérifie si deux entiers 32 bits sont égaux.
  • to_int : int32 -> int : Convertit un entier 32 bits en un entier natif. La valeur peut être tronquée si elle ne rentre pas dans la taille d'un entier natif.
  • of_int : int -> int32 : Convertit un entier natif en un entier 32 bits. La valeur peut être tronquée si elle ne rentre pas dans la taille d'un entier 32 bits.
  • to_int64 : int32 -> int64 : Convertit un entier 32 bits en un entier 64 bits.
  • of_int64 : int64 -> int32 : Convertit un entier 64 bits en un entier 32 bits. La valeur peut être tronquée si elle ne rentre pas dans la taille d'un entier 32 bits.
  • succ : int32 -> int32 : Incrémente un entier 32 bits.
  • pred : int32 -> int32 : Décrémente un entier 32 bits.
  • add : int32 -> int32 -> int32 : Additionne deux entiers 32 bits. Gère le dépassement de capacité en tronquant le résultat.
  • sub : int32 -> int32 -> int32 : Soustrait deux entiers 32 bits. Gère le dépassement de capacité en tronquant le résultat.
  • mul : int32 -> int32 -> int32 : Multiplie deux entiers 32 bits. Gère le dépassement de capacité en tronquant le résultat.
  • div : int32 -> int32 -> int32 : Divise deux entiers 32 bits. Lève une exception Division_by_zero si le diviseur est zéro.
  • rem : int32 -> int32 -> int32 : Calcule le reste de la division euclidienne de deux entiers 32 bits. Lève une exception Division_by_zero si le diviseur est zéro.
  • neg : int32 -> int32 : Négative un entier 32 bits. Gère le cas particulier de min_int.
  • abs : int32 -> int32 : Calcule la valeur absolue d'un entier 32 bits. Lève une exception Not_a_number si l'entrée est min_int.
  • min_int : int32 : La plus petite valeur possible pour un entier 32 bits.
  • max_int : int32 : La plus grande valeur possible pour un entier 32 bits.
  • logand : int32 -> int32 -> int32 : Opération ET bit à bit.
  • logor : int32 -> int32 -> int32 : Opération OU bit à bit.
  • logxor : int32 -> int32 -> int32 : Opération OU exclusif bit à bit.
  • logsl : int32 -> int -> int32 : Décalage à gauche. Le nombre de bits à décaler doit être compris entre 0 et 31.
  • logsr : int32 -> int -> int32 : Décalage à droite logique. Le nombre de bits à décaler doit être compris entre 0 et 31.
  • logarsl : int32 -> int -> int32 : Décalage à droite arithmétique. Le nombre de bits à décaler doit être compris entre 0 et 31.
  • shift_left : int32 -> int -> int32 : Alias pour logsl.
  • shift_right : int32 -> int -> int32 : Alias pour logsr.
  • shift_right_logical : int32 -> int -> int32 : Alias pour logsr.
  • of_string : string -> int32 : Convertit une chaîne de caractères représentant un entier 32 bits en un entier 32 bits. Lève une exception Failure si la chaîne n'est pas valide.
  • to_string : int32 -> string : Convertit un entier 32 bits en sa représentation sous forme de chaîne de caractères.
  • format : string -> int32 -> string : Formate un entier 32 bits selon une chaîne de format (similaire à Printf.sprintf).
