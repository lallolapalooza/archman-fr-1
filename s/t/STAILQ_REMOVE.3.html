Note : Des macros identiques préfixées par SIMPLEQ au lieu de STAILQ existent ; voir VERSIONS.

DESCRIPTION

Ces macros définissent et opèrent sur des files à queue singulièrement chaînées.

Dans les définitions de macro, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NOM. L'argument NOMENQUEUE est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro STAILQ_HEAD().

Création

Une file à queue singulièrement chaînée est dirigée par une structure définie par la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, un vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont chaînés de manière singulière pour une utilisation minimale de l'espace et une manipulation des pointeurs au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, en tête de la file, ou à la fin de la file. Une structure STAILQ_HEAD est déclarée comme suit :


STAILQ_HEAD(NOMENQUEUE, TYPE) enqueue;

où struct NOMENQUEUE est la structure à définir, et struct TYPE est le type des éléments à lier dans la file. Un pointeur vers la tête de la file peut plus tard être déclaré comme suit :


struct NOMENQUEUE *enqueup;

(Les noms enqueue et enqueup sont sélectionnables par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui connecte les éléments dans la file.

STAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file enqueue.

STAILQ_INIT() initialise la file référencée par enqueue.

STAILQ_EMPTY() évalue à vrai s'il n'y a pas d'éléments dans la file.

Insertion

STAILQ_INSERT_HEAD() insère le nouvel élément elt en tête de la file.

STAILQ_INSERT_TAIL() insère le nouvel élément elt à la fin de la file.

STAILQ_INSERT_AFTER() insère le nouvel élément elt après l'élément eltliste.

Parcours

STAILQ_FIRST() renvoie le premier élément de la file ou NULL si la file est vide.

STAILQ_NEXT() renvoie le prochain élément de la file, ou NULL si cet élément est le dernier.

STAILQ_FOREACH() parcourt la file référencée par enqueue dans la direction avant, assignant chaque élément à tour de rôle à var.

Suppression

STAILQ_REMOVE() supprime l'élément elt de la file.

STAILQ_REMOVE_HEAD() supprime l'élément en tête de la file. Pour une efficacité optimale, les éléments retirés de la tête de la file doivent utiliser cette macro explicitement plutôt que la macro générique STAILQ_REMOVE().

Autres fonctionnalités

STAILQ_CONCAT() concatène la file dirigée par enqueue2 à la fin de celle dirigée par enqueue1, supprimant toutes les entrées de la première.

VALEUR DE RETOUR

STAILQ_EMPTY() renvoie non nul si la file est vide, et zéro si la file contient au moins une entrée.

STAILQ_FIRST(), et STAILQ_NEXT() renvoient un pointeur vers la structure TYPE première ou suivante, respectivement.

STAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la file enqueue.

VERSIONS

Certains BSD fournissent SIMPLEQ au lieu de STAILQ. Ils sont identiques, mais pour des raisons historiques, ils ont été nommés différemment sur différents systèmes BSD. STAILQ provient de FreeBSD, et SIMPLEQ de NetBSD. Pour des raisons de compatibilité, certains systèmes fournissent les deux ensembles de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques à l'exception d'un équivalent SIMPLEQ manquant à STAILQ_CONCAT().

BOGUES

STAILQ_FOREACH() ne permet pas de supprimer ou de libérer var dans la boucle, car cela interférerait avec le parcours. STAILQ_FOREACH_SAFE(), qui est présent sur les BSD mais n'est pas présent dans glibc, corrige cette limitation en permettant à var d'être supprimé en toute sécurité de la liste et libéré depuis la boucle sans interférer avec le parcours.

NORMES

BSD.

HISTORIQUE

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File à queue singulièrement chaînée */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Tête de file à queue singulièrement chaînée */
    STAILQ_INIT(&head);                     /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insérer en tête */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insérer à la queue */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression de la tête */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }

NOM

STAILQ_FOREACH

BIBLIOTHEQUE

STAILQ

SYNTAXE

STAILQ_FOREACH(np, &head, entries) printf("%i\n", np->data);

DESCRIPTION

Parcourt la liste dans l'ordre direct.

VALEUR DE RETOUR

Aucune.

VERSIONS

Prend en charge les versions 1.0 et ultérieures.

BOGUES

Aucun.

NORMES

Basé sur les normes du projet man-pages Linux.

HISTORIQUE

Première version : 2025-09-21.

EXEMPLES

Exemple 1 : Parcours direct

    /* Parcours direct */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);

Exemple 2 : Suppression de TailQ

    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
