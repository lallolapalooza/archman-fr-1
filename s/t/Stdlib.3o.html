Module Stdlib
: sig end

La bibliothèque standard OCaml.

Ce module est ouvert automatiquement au début de chaque compilation. Tous les composants de ce module peuvent être référencés par leur nom court, sans avoir besoin de les préfixer par Stdlib.

En particulier, il fournit les opérations de base sur les types intégrés (nombres, booléens, séquences d'octets, chaînes, exceptions, références, listes, tableaux, canaux d'entrée/sortie, ...) et les modules.

Exceptions

val raise : exn -> 'a

Lance la valeur d'exception donnée.

val raise_notrace : exn -> 'a

Une version plus rapide de raise qui n'enregistre pas le retour sur pile (backtrace).

Depuis 4.02

val invalid_arg : string -> 'a

Lance l'exception Invalid_argument avec la chaîne donnée.

val failwith : string -> 'a

Lance l'exception Failure avec la chaîne donnée.

exception Exit

L'exception Exit n'est levée par aucune fonction de la bibliothèque. Elle est fournie pour être utilisée dans vos programmes.

exception Match_failure of (string * int * int)

L'exception levée lorsqu'aucun des cas d'un pattern matching ne correspond. Les arguments sont l'emplacement du mot-clé match dans le code source (nom de fichier, numéro de ligne, numéro de colonne).

exception Assert_failure of (string * int * int)

L'exception levée lorsqu'une assertion échoue. Les arguments sont l'emplacement du mot-clé assert dans le code source (nom de fichier, numéro de ligne, numéro de colonne).

exception Invalid_argument of string

L'exception levée par les fonctions de bibliothèque pour indiquer que les arguments fournis ne sont pas valides. La chaîne donne des informations au programmeur. En règle générale, cette exception ne doit pas être interceptée, car elle signale une erreur de programmation et le code doit être modifié pour ne pas la provoquer.

exception Failure of string

L'exception levée par les fonctions de bibliothèque pour indiquer qu'elles sont indéfinies pour les arguments donnés. La chaîne est destinée à fournir des informations au programmeur ; ne faites pas de pattern matching sur la chaîne littérale, car elle pourrait changer dans de futures versions (utilisez Failure à la place).

exception Not_found

L'exception levée par les fonctions de recherche lorsque l'objet désiré ne peut pas être trouvé.

exception Out_of_memory

L'exception levée par le garbage collector lorsqu'il n'y a pas assez de mémoire pour terminer l'opération. (Non fiable pour les allocations dans le tas mineur).

exception Stack_overflow

L'exception levée par l'interpréteur de bytecode lorsque la pile d'évaluation atteint sa taille maximale. Cela indique généralement une récursion infinie ou trop profonde dans le programme utilisateur.

Avant 4.10, elle n'était pas entièrement implémentée par le compilateur natif.

exception Sys_error of string

L'exception levée par les fonctions d'entrée/sortie pour signaler une erreur du système d'exploitation. La chaîne est destinée à fournir des informations au programmeur ; ne faites pas de pattern matching sur la chaîne littérale, car elle pourrait changer dans de futures versions (utilisez Sys_error à la place).

exception End_of_file

L'exception levée par les fonctions d'entrée pour indiquer que la fin du fichier a été atteinte.

exception Division_by_zero

L'exception levée par les opérations de division entière et de reste lorsque le deuxième argument est zéro.

exception Sys_blocked_io

Un cas particulier de Sys_error qui est levé lorsqu'aucun I/O n'est possible sur un canal d'I/O non bloquant.

exception Undefined_recursive_module of (string * int * int)

L'exception levée lors de l'évaluation d'une définition de module récursive mal fondée. Les arguments sont l'emplacement de la définition dans le code source (nom de fichier, numéro de ligne, numéro de colonne).

val (/) : int -> int -> int

Division entière. La division entière arrondit le quotient réel de ses arguments vers zéro. Plus précisément, si x >= 0 et y > 0, x / y est le plus grand entier inférieur ou égal au quotient réel de x par y. De plus, (- x) / y = x / (- y) = - (x / y). Opérateur associatif à gauche, voir Ocaml_operators pour plus d'informations.

Lève Division_by_zero si le deuxième argument est 0.

val (mod) : int -> int -> int

Reste de la division entière. Si y n'est pas nul, le résultat de x mod y satisfait les propriétés suivantes : x = (x / y) * y + x mod y et abs(x mod y) <= abs(y) - 1. Si y = 0, x mod y lève Division_by_zero. Notez que x mod y est négatif seulement si x < 0. Opérateur associatif à gauche, voir Ocaml_operators pour plus d'informations.

Lève Division_by_zero si y est zéro.

Arithmétique à virgule flottante

Les nombres à virgule flottante d'OCaml suivent la norme IEEE 754, utilisant des nombres en simple précision (64 bits). Les opérations à virgule flottante ne lèvent jamais d'exception en cas de dépassement, sous-dépassement, division par zéro, etc. À la place, des nombres spéciaux IEEE sont retournés comme il convient, tels que infinity pour 1.0 /. 0.0, neg_infinity pour -1.0 /. 0.0, et nan ('not a number') pour 0.0 /. 0.0. Ces nombres spéciaux se propagent ensuite dans les calculs à virgule flottante comme attendu : par exemple, 1.0 /. infinity est 0.0, les opérations arithmétiques de base ( +. , -. , *. , /. ) avec nan comme argument retournent nan, ...

val nan : float

val string_of_int : int -> string

Retourne la représentation en chaîne de caractères d'un entier, en décimal.

val int_of_string_opt : string -> int option

Convertit la chaîne donnée en un entier. La chaîne est lue en décimal (par défaut, ou si la chaîne commence par 0u ), en hexadécimal (si elle commence par 0x ou 0X ), en octal (si elle commence par 0o ou 0O ), ou en binaire (si elle commence par 0b ou 0B ).

Le préfixe 0u lit l'entrée comme un entier non signé dans la plage [0, 2*max_int+1] . Si l'entrée dépasse max_int , elle est convertie en l'entier signé min_int + input - max_int - 1 .

Le caractère _ (souligné) peut apparaître n'importe où dans la chaîne et est ignoré.

Retourne None si la chaîne donnée n'est pas une représentation valide d'un entier, ou si l'entier représenté dépasse la plage des entiers représentables dans le type int .

Depuis 4.05

val int_of_string : string -> int

val string_of_float : float -> string

Retourne une représentation en chaîne de caractères d'un nombre à virgule flottante.

Cette conversion peut entraîner une perte de précision. Pour un plus grand contrôle sur la manière dont le nombre est imprimé, voir Printf .

val float_of_string_opt : string -> float option

Convertit la chaîne donnée en un float. La chaîne est lue en décimal (par défaut) ou en hexadécimal (marquée par 0x ou 0X ).

Le format des nombres décimaux à virgule flottante est [-] dd.ddd (e|E) [+|-] dd , où d représente un chiffre décimal.

Le format des nombres hexadécimaux à virgule flottante est [-] 0(x|X) hh.hhh (p|P) [+|-] dd , où h représente un chiffre hexadécimal et d un chiffre décimal.

Dans les deux cas, au moins l'une des parties entière et fractionnaire doit être donnée ; la partie exposant est facultative.

Le caractère _ (souligné) peut apparaître n'importe où dans la chaîne et est ignoré.

Selon les plateformes d'exécution, d'autres représentations de nombres à virgule flottante peuvent être acceptées, mais il ne faut pas s'y fier.

Retourne None si la chaîne donnée n'est pas une représentation valide d'un float.

Depuis 4.05

Opérations sur les chaînes de format

Les chaînes de format sont des chaînes de caractères avec des conventions lexicales spéciales qui définissent la fonctionnalité des fonctions d'entrée/sortie formatées. Les chaînes de format sont utilisées pour lire des données avec les fonctions d'entrée formatées du module Scanf et pour imprimer des données avec les fonctions de sortie formatées des modules Printf et Format.

Les chaînes de format sont constituées de trois types d'entités :

-spécifications de conversion, introduites par le caractère spécial '%' suivi d'un ou plusieurs caractères spécifiant quel type d'argument lire ou imprimer,

-indications de formatage, introduites par le caractère spécial '@' suivi d'un ou plusieurs caractères spécifiant comment lire ou imprimer l'argument,

-caractères littéraux qui sont des caractères ordinaires avec des conventions lexicales usuelles. Les caractères littéraux spécifient des chaînes littérales à lire dans l'entrée ou à imprimer dans la sortie.

Il existe une règle lexicale supplémentaire pour échapper les caractères spéciaux '%' et '@' dans les chaînes de format : si un caractère spécial suit un caractère '%' , il est traité comme un caractère littéral. Autrement dit, "%%" est considéré comme un '%' littéral et "%@" comme un '@' littéral.

NOM

Stdlib - format strings and program termination

MODULE

Cette section décrit les modules Scanf, Printf et Format , qui fournissent des fonctionnalités pour la lecture et l'écriture formatées de données.

Pour plus d'informations sur les spécifications de conversion et les indications de format disponibles, veuillez consulter la documentation des modules Scanf, Printf et Format .

Les chaînes de caractères de format ont un type général et hautement polymorphique ('a, 'b, 'c, 'd, 'e, 'f) format6 . Les deux types simplifiés, format et format4 ci-dessous, sont inclus pour la compatibilité avec les versions antérieures d'OCaml.

La signification des paramètres de type des chaînes de caractères de format est la suivante:

- 'a est le type des paramètres des fonctions de sortie formatée (style printf); 'a est le type des valeurs lues par les fonctions d'entrée formatée (style scanf).

- 'b est le type source d'entrée pour les fonctions d'entrée formatée et le type de destination de sortie pour les fonctions de sortie formatée. Pour les fonctions style printf du module Printf, 'b est typiquement out_channel ; pour les fonctions style printf du module Format, 'b est typiquement Format.formatter ; pour les fonctions style scanf du module Scanf, 'b est typiquement Scanf.Scanning.in_channel .

Le type 'b est également le type du premier argument donné aux fonctions d'impression définies par l'utilisateur pour %a et %t, et de l'argument passé aux fonctions style kprintf ou aux fonctions style kscanf.

- 'c est le type du résultat des fonctions d'impression %a et %t, et aussi le type de l'argument passé au premier argument des fonctions style kprintf ou aux fonctions style kscanf.

- 'd est le type des paramètres des fonctions style scanf.

- 'e est le type de la fonction réceptrice des fonctions style scanf.

- 'f est le type du résultat final d'une invocation de fonction d'entrée/sortie formatée : pour les fonctions style printf, c'est typiquement unit ; pour les fonctions style scanf, c'est typiquement le type du résultat de la fonction réceptrice.

Terminaison du programme

val exit : int -> 'a

Termine le processus, en renvoyant le code d'état donné au système d'exploitation : généralement 0 pour aucune erreur, et un petit nombre positif pour indiquer une erreur. Tous les canaux de sortie ouverts sont vidés avec flush_all . Les callbacks enregistrés avec Domain.at_exit sont appelés après ceux enregistrés avec at_exit .

Un exit 0 implicite est effectué chaque fois qu'un programme se termine normalement. Un exit 2 implicite est effectué si le programme se termine prématurément en raison d'une exception non interceptée.

val at_exit : (unit -> unit) -> unit

Enregistre la fonction donnée pour qu'elle soit exécutée à la fin du programme. Les fonctions enregistrées avec at_exit sont appelées lorsque le programme effectue l'une des actions suivantes:

- exécute exit

- se termine, soit normalement, soit en raison d'une exception non interceptée

- exécute la fonction C caml_shutdown . Les fonctions sont appelées dans l'ordre 'dernier entré, premier sorti' : la fonction la plus récemment enregistrée avec at_exit est appelée en premier.
