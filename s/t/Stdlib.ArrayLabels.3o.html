type 'a t = 'a array

Un alias pour le type des tableaux.

val length : 'a array -> int

Retourne la longueur (nombre d'éléments) du tableau donné.

val get : 'a array -> int -> 'a

get a n retourne l'élément numéro n du tableau a . Le premier élément est numéroté 0. Le dernier élément est numéroté length a - 1 . Vous pouvez aussi écrire a.(n) à la place de get a n .

Lève Invalid_argument si n est en dehors de l'intervalle 0 à (length a - 1) .

val set : 'a array -> int -> 'a -> unit

set a n x modifie le tableau a en place, en remplaçant l'élément numéro n par x . Vous pouvez aussi écrire a.(n) <- x à la place de set a n x .

Lève Invalid_argument si n est en dehors de l'intervalle 0 à length a - 1 .

val make : int -> 'a -> 'a array

make n x retourne un nouveau tableau de longueur n , initialisé avec x . Tous les éléments de ce nouveau tableau sont initialement physiquement égaux à x (au sens du prédicat == ). Par conséquent, si x est mutable, il est partagé entre tous les éléments du tableau, et modifier x via l'une des entrées du tableau modifiera toutes les autres entrées en même temps.

Lève Invalid_argument si n < 0 ou n > Sys.max_array_length . Si la valeur de x est un nombre flottant, la taille maximale n'est que de Sys.max_array_length / 2 .

val create_float : int -> float array

create_float n retourne un nouveau tableau de flottants de longueur n , avec des données non initialisées.

Depuis 4.03

val init : int -> f:(int -> 'a) -> 'a array

init n ~f retourne un nouveau tableau de longueur n , avec l'élément numéro i initialisé avec le résultat de f i . Autrement dit, init n ~f tabule les résultats de f appliqués en ordre aux entiers 0 à n-1 .

Lève Invalid_argument si n < 0 ou n > Sys.max_array_length . Si le type de retour de f est float , la taille maximale n'est que de Sys.max_array_length / 2 .

val make_matrix : dimx:int -> dimy:int -> 'a -> 'a array array

make_matrix ~dimx ~dimy e retourne un tableau bidimensionnel (un tableau de tableaux) avec une première dimension dimx et une seconde dimension dimy . Tous les éléments de cette nouvelle matrice sont initialement physiquement égaux à e . L'élément ( x,y ) d'une matrice m est accédé avec la notation m.(x).(y) .

Lève Invalid_argument si dimx ou dimy est négatif ou supérieur à Sys.max_array_length . Si la valeur de e est un nombre flottant, la taille maximale n'est que de Sys.max_array_length / 2 .

val init_matrix : dimx:int -> dimy:int -> f:(int -> int -> 'a) -> 'a array array

init_matrix ~dimx ~dimy ~f retourne un tableau bidimensionnel (un tableau de tableaux) avec une première dimension dimx et une seconde dimension dimy , où l'élément à l'indice ( x,y ) est initialisé avec f x y . L'élément ( x,y ) d'une matrice m est accédé avec la notation m.(x).(y) .

Depuis 5.2

Lève Invalid_argument si dimx ou dimy est négatif ou supérieur à Sys.max_array_length . Si le type de retour de f est float , la taille maximale n'est que de Sys.max_array_length / 2 .

val append : 'a array -> 'a array -> 'a array

append v1 v2 retourne un nouveau tableau contenant la concaténation des tableaux v1 et v2 .

Lève Invalid_argument si length v1 + length v2 > Sys.max_array_length .

val concat : 'a array list -> 'a array

Identique à ArrayLabels.append , mais concatène une liste de tableaux.

val sub : 'a array -> pos:int -> len:int -> 'a array

sub a ~pos ~len retourne un nouveau tableau de longueur len , contenant les éléments numéro pos à pos + len - 1 du tableau a .

Lève Invalid_argument si pos et len ne désignent pas un sous-tableau valide de a ; c'est-à-dire, si pos < 0 , ou len < 0 , ou pos + len > length a .

val copy : 'a array -> 'a array

copy a retourne une copie de a , c'est-à-dire un nouveau tableau contenant les mêmes éléments que a .

val fill : 'a array -> pos:int -> len:int -> 'a -> unit

fill a ~pos ~len x modifie le tableau a en place, en stockant x dans les éléments numéro pos à pos + len - 1 .

Lève Invalid_argument si pos et len ne désignent pas un sous-tableau valide de a .

val blit : src:'a array -> src_pos:int -> dst:'a array -> dst_pos:int -> len:int -> unit

blit ~src ~src_pos ~dst ~dst_pos ~len copie len éléments du tableau src , en commençant à l'élément numéro src_pos , vers le tableau dst , en commençant à l'élément numéro dst_pos . Fonctionne correctement même si src et dst sont le même tableau, et si les segments source et destination se chevauchent.

Lève Invalid_argument si src_pos et len ne désignent pas un sous-tableau valide de src , ou si dst_pos et len ne désignent pas un sous-tableau valide de dst .

val to_list : 'a array -> 'a list

to_list a retourne la liste de tous les éléments de a .

val of_list : 'a list -> 'a array

of_list l retourne un nouveau tableau contenant les éléments de l .

Lève Invalid_argument si la longueur de l est supérieure à Sys.max_array_length .

COMPARAISON

val equal : eq:('a -> 'a -> bool) -> 'a array -> 'a array -> bool

equal eq a b est true si et seulement si a et b ont la même longueur n et pour tout i dans [ 0 ; n-1 ], eq a.(i) b.(i) est true .

Depuis 5.4

val compare : cmp:('a -> 'a -> int) -> 'a array -> 'a array -> int

compare cmp a b compare a et b selon l'ordre shortlex, c'est-à-dire que les tableaux plus courts sont plus petits et les tableaux de même taille sont comparés dans l'ordre lexicographique en utilisant cmp pour comparer les éléments.

ITERATEURS

val iter : f:('a -> unit) -> 'a array -> unit

iter ~f a applique la fonction f successivement à tous les éléments de a . C'est équivalent à f a.(0); f a.(1); ...; f a.(length a - 1); () .

val iteri : f:(int -> 'a -> unit) -> 'a array -> unit

Identique à ArrayLabels.iter , mais la fonction est appliquée à l'indice de l'élément comme premier argument, et à l'élément lui-même comme second argument.

val map : f:('a -> 'b) -> 'a array -> 'b array

map ~f a applique la fonction f à tous les éléments de a , et construit un tableau avec les résultats retournés par f : [| f a.(0); f a.(1); ...; f a.(length a - 1) |] .

val map_inplace : f:('a -> 'a) -> 'a array -> unit

map_inplace ~f a applique la fonction f à tous les éléments de a , et met à jour leurs valeurs en place.

Depuis 5.1

val mapi : f:(int -> 'a -> 'b) -> 'a array -> 'b array

Identique à ArrayLabels.map , mais la fonction est appliquée à l'indice de l'élément comme premier argument, et à l'élément lui-même comme second argument.

Itérateurs sur deux tableaux

val iter2 : f:('a -> 'b -> unit) -> 'a array -> 'b array -> unit

iter2 ~f a b applique la fonction f à tous les éléments de a et b .

val map2 : f:('a -> 'b -> 'c) -> 'a array -> 'b array -> 'c array

map2 ~f a b applique la fonction f à tous les éléments de a et b , et construit un tableau avec les résultats obtenus par f : [| f a.(0) b.(0); ...; f a.(length a - 1) b.(length b - 1)|] .

Balayage des tableaux

val for_all : f:('a -> bool) -> 'a array -> bool

for_all ~f [|a1; ...; an|] vérifie si tous les éléments du tableau satisfont le prédicat f . Cela signifie qu'il renvoie (f a1) && (f a2) && ... && (f an) .

val exists : f:('a -> bool) -> 'a array -> bool

exists ~f [|a1; ...; an|] vérifie si au moins un élément du tableau satisfait le prédicat f . Cela signifie qu'il renvoie (f a1) || (f a2) || ... || (f an) .

Depuis 4.03

Identique à ArrayLabels.exists , mais pour un prédicat à deux arguments.

Depuis 4.11

val mem : 'a -> set:'a array -> bool

mem a ~set est vrai si et seulement si a est structurellement égal à un élément de set (c'est-à-dire qu'il existe un x dans set tel que compare a x = 0 ).

Depuis 4.03

val memq : 'a -> set:'a array -> bool

Identique à ArrayLabels.mem , mais utilise l'égalité physique plutôt que l'égalité structurelle pour comparer les éléments des tableaux.

val find_opt : f:('a -> bool) -> 'a array -> 'a option

find_opt ~f a renvoie le premier élément du tableau a qui satisfait le prédicat f , ou None s'il n'y a pas de valeur satisfaisant f dans le tableau a .

val find_index : f:('a -> bool) -> 'a array -> int option

find_index ~f a renvoie Some i , où i est l'indice du premier élément du tableau a qui satisfait f x , s'il existe un tel élément.

Renvoie None si un tel élément n'existe pas.

find_map ~f a applique f aux éléments de a dans l'ordre et renvoie le premier résultat de la forme Some v , ou None s'il n'en existe aucun.

Tri et mélange

val sort : cmp:('a -> 'a -> int) -> 'a array -> unit

Trie un tableau par ordre croissant selon une fonction de comparaison. La fonction de comparaison doit renvoyer 0 si ses arguments sont égaux, un nombre positif si le premier est plus grand, et un nombre négatif si le premier est plus petit (voir la spécification complète). Par exemple, compare est une fonction de comparaison appropriée. Après avoir appelé sort , le tableau est trié sur place.

Stdlib.ArrayLabels(3o)

NAME

Stdlib.ArrayLabels - labels for arrays

Module

Module Stdlib.ArrayLabels

Documentation

This module provides functions for creating and accessing arrays. These functions are similar to those in the Stdlib.Array module, but they use label arguments for indexing.

The following functions are provided:

  • make : int -> 'a -> 'a array

    make n x returns a new array of length n the elements of which are initialized to x.

  • init : int -> (int -> 'a) -> 'a array

    init n f returns a new array of length n such that f i is the value at index i.

  • create : int -> 'a array

    create n returns a new array of length n, with uninitialized elements.

  • get : 'a array -> int -> 'a

    get a i returns the element at index i of the array a.

  • set : 'a array -> int -> 'a -> unit

    set a i v is the same as a.(i) <- v.

  • length : 'a array -> int

    Return the length of the given array.

  • blit : 'a array -> int - 'a array - int - int - unit

    blit src src_idx dst dst_idx len copies len elements from the array src starting at index src_idx to the array dst starting at index dst_idx. The source and destination arrays must overlap.

  • copy : 'a array -> 'a array

    Return a copy of the given array.

  • fill : 'a array -> int - int - 'a -> unit

    fill a i len v fills the array a with the value v, from index i of length len.

  • map : ('a -> 'b) -> 'a array -> 'b array

    map f a applies the function f to the elements of the array a, and returns a new array with the results.

  • iter : ('a -> unit) -> 'a array -> unit

    iter f a applies the function f to the elements of the array a.

  • fold_left : ('a -> 'b -> 'a) -> 'a -> 'b array -> 'a

    fold_left f x a, applied to the array a, computes f (... (f (f x a.(0)) a.(1)) ...) a.(n-1).

  • fold_right : ('a -> 'b -> 'b) -> 'a array -> 'b -> 'b

    fold_right f a x, applied to the array a, computes f a.(0) (f a.(1) (... (f a.(n-1) x) ...)).

  • exists : ('a -> bool) -> 'a array -> bool

    exists f a returns true if f returns true for at least one element of a.

  • for_all : ('a -> bool) -> 'a array -> bool

    for_all f a returns true if f returns true for all elements of a.

  • sort : ('a -> 'a -> int) -> 'a array -> unit

    sort f a sorts the array a using the comparison function f. The comparison function should return a negative integer, zero, or a positive integer as the first argument is less than, equal to, or greater than the second.

  • b Binds

    For a more detailed description of the array functions, see the documentation for the Stdlib.Array module.

Data races

If multiple threads or domains access the same array, and at least one of these accesses is a write operation, then there is a data race. In the absence of data races, the observed behaviour is equivalent to some sequential interleaving of the operations from different domains.

Whenever possible, data races should be avoided by using synchronization to mediate the accesses to the array elements.

Indeed, in the presence of data races, programs will not crash but the observed behaviour may not be equivalent to any sequential interleaving of operations from different domains. Nevertheless, even in the presence of data races, a read operation will return the value of some prior write to that location (with a few exceptions for float arrays).

Float arrays

Float arrays have two supplementary caveats in the presence of data races.

First, the blit operation might copy an array byte-by-byte. Data races between such a blit operation and another operation might produce surprising values due to tearing: partial writes interleaved with other operations can create float values that would not exist with a sequential execution.

For instance, at the end of

let zeros = Array.make size 0.
let max_floats = Array.make size Float.max_float
let res = Array.copy zeros
let d1 = Domain.spawn (fun () -> Array.blit zeros 0 res 0 size)
let d2 = Domain.spawn (fun () -> Array.blit max_floats 0 res 0 size)
let () = Domain.join d1; Domain.join d2
the res array might contain values that are neither 0. nor max_float.

Second, on 32-bit architectures, getting or setting a field involves two separate memory accesses. In the presence of data races, the user may observe tearing on any operation.
