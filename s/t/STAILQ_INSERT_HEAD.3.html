STAILQ(3) Manuel des fonctions de bibliothèque STAILQ(3)

NOM

BIBLIOTHEQUE

Bibliothèque C standard (libc, -lc)

SYNOPIS

#include <sys/queue.h>
STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);
STAILQ_HEAD STAILQ_HEAD_INITIALIZER(STAILQ_HEAD head);
void STAILQ_INIT(STAILQ_HEAD *head);
int STAILQ_EMPTY(STAILQ_HEAD *head);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
struct TYPE *STAILQ_FIRST(STAILQ_HEAD *head);
struct TYPE *STAILQ_NEXT(struct TYPE *elm, STAILQ_ENTRY NAME);
STAILQ_FOREACH(struct TYPE *var, STAILQ_HEAD *head, STAILQ_ENTRY NAME);

                         STAILQ_ENTRY NAME);

void STAILQ_CONCAT(STAILQ_HEAD *head1, STAILQ_HEAD *head2);

Note: Des macros identiques préfixées par SIMPLEQ au lieu de STAILQ existent ; voir VERSIONS.

DESCRIPTION

Ces macros définissent et opèrent sur des files à liste chaînée simple se terminant à la queue.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée à l'aide de la macro STAILQ_HEAD().

Création

Une file à liste chaînée simple se terminant à la queue est dirigée par une structure définie par la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, un vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont chaînés simplement pour une surcharge minimale d'espace et de manipulation de pointeurs, au prix d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, à la tête de la file, ou à la fin de la file. Une structure STAILQ_HEAD est déclarée comme suit :


STAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à lier dans la file. Un pointeur vers la tête de la file peut ensuite être déclaré comme :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui relie les éléments de la file.

STAILQ_HEAD_INITIALIZER() est évalué comme un initialiseur pour la file head.

STAILQ_INIT() initialise la file référencée par head.

STAILQ_EMPTY() évalue à vrai s'il n'y a pas d'éléments dans la file.

Insertion

STAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de la file.

STAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file.

STAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

STAILQ_FIRST() renvoie le premier élément de la file ou NULL si la file est vide.

STAILQ_NEXT() renvoie le prochain élément de la file, ou NULL si cet élément est le dernier.

STAILQ_FOREACH() parcourt la file référencée par head dans le sens avant, assignant successivement chaque élément à var.

Suppression

STAILQ_REMOVE() supprime l'élément elm de la file.

STAILQ_REMOVE_HEAD() supprime l'élément en tête de la file. Pour une efficacité optimale, les éléments supprimés de la tête de la file doivent utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE().

Autres fonctionnalités

STAILQ_CONCAT() concatène la file dirigée par head2 à la fin de celle dirigée par head1, retirant toutes les entrées de la première.

VALEUR RENVOYÉE

STAILQ_EMPTY() renvoie non nul si la file est vide, et zéro si la file contient au moins une entrée.

STAILQ_FIRST() et STAILQ_NEXT() renvoient un pointeur vers la première ou la prochaine structure TYPE, respectivement.

STAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la file head.

VERSIONS

Certains systèmes BSD fournissent SIMPLEQ au lieu de STAILQ. Ils sont identiques, mais pour des raisons historiques, ils ont été nommés différemment sur différents systèmes BSD. STAILQ est originaire de FreeBSD, et SIMPLEQ de NetBSD. Pour des raisons de compatibilité, certains systèmes fournissent les deux ensembles de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques à l'exception de l'absence d'équivalent SIMPLEQ à STAILQ_CONCAT().

BOGUES

STAILQ_FOREACH() ne permet pas à var d'être supprimé ou libéré dans la boucle, car cela interférerait avec le parcours. STAILQ_FOREACH_SAFE(), qui est présent sur les systèmes BSD mais pas dans glibc, corrige cette limitation en permettant à var d'être supprimé en toute sécurité de la liste et libéré depuis la boucle sans interférer avec le parcours.

NORMES

BSD.

HISTORIQUE

4.4BSD.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File à liste chaînée simple */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Tête de file à liste chaînée simple */
    STAILQ_INIT(&head);                     /* Initialisation de la file */
    n1 = malloc(sizeof(struct entry));      /* Insertion en tête */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion à la queue */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression de la tête */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }

STAILQ_INSERT_HEAD(3bsd) — Linux manual pages

NAME

STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_CONCAT, STAILQ_FOREACH, STAILQ_FIRST, STAILQ_LAST, STAILQ_NEXT, STAILQ_PREV, STAILQ_REMOVE_HEAD, STAILQ_REMOVE_TAIL, STAILQ_SWAP — macros for manipulating singly linked lists with a public tail pointer

LIBRARY

libbsd , or compatibility libraries.

SYNOPSIS

#include <sys/queue.h>

STAILQ_HEAD(list_name, type);

STAILQ_HEAD_INITIALIZER(list_name);

STAILQ_ENTRY(type);

STAILQ_INIT(head);

STAILQ_INSERT_HEAD(head, elm, field);

STAILQ_INSERT_TAIL(head, elm, field);

STAILQ_INSERT_AFTER(head, listelm, elm, field);

STAILQ_INSERT_BEFORE(head, listelm, elm, field);

STAILQ_REMOVE_HEAD(head, field);

STAILQ_REMOVE_TAIL(head, field);

STAILQ_REMOVE(head, elm, field);

STAILQ_CONCAT(head, nhead);

STAILQ_SWAP(head1, head2, type);

STAILQ_FIRST(head);

STAILQ_LAST(head, type, field);

STAILQ_NEXT(elm, field);

STAILQ_PREV(elm, type, field);

STAILQ_EMPTY(head);

STAILQ_FOREACH(var, head, field);

STAILQ_FOREACH_SAFE(var, head, field, nextvar);

STAILQ_FOREACH_ALL(var, head, field);

STAILQ_FOREACH_ALL_SAFE(var, head, field, nextvar);

DESCRIPTION

These macros provide a facility for defining and manipulating singly linked lists with a public tail pointer. Singly linked lists are useful for implementing stacks, queues, and other simple data structures.

A list is defined using the STAILQ_HEAD macro. The first argument is the name of the list head structure, and the second argument is the name of the structure that defines the list entry. The list entry structure must contain a field of type STAILQ_ENTRY(type). For example:

struct my_entry {
    int data;
    STAILQ_ENTRY(my_entry) next;
};
STAILQ_HEAD(my_list, my_entry);

In this example, struct my_entry is the type of the elements in the list, and struct my_list is the type of the list head.

The STAILQ_ENTRY macro defines the structure that will be embedded within each list element. This structure contains a pointer to the next element in the list.

The following macros operate on the list:

STAILQ_HEAD(list_name, type);
Declares a list head structure named list_name. The elements in the list will be of type type. The type structure must contain a field of type STAILQ_ENTRY(type).
STAILQ_HEAD_INITIALIZER(list_name);
Returns an initializer for an empty list head of type list_name.
STAILQ_ENTRY(type);
Declares a structure suitable for embedding in a list element. The type argument is the name of the structure that will contain this field.
STAILQ_INIT(head);
Initializes an empty list pointed to by head.
STAILQ_INSERT_HEAD(head, elm, field);
Inserts the element elm at the head of the list pointed to by head. The field argument is the name of the STAILQ_ENTRY field within the element structure.
STAILQ_INSERT_TAIL(head, elm, field);
Inserts the element elm at the tail of the list pointed to by head. The field argument is the name of the STAILQ_ENTRY field within the element structure.
STAILQ_INSERT_AFTER(head, listelm, elm, field);
Inserts the element elm after the element listelm in the list pointed to by head. The field argument is the name of the STAILQ_ENTRY field within the element structure.
STAILQ_INSERT_BEFORE(head, listelm, elm, field);
Inserts the element elm before the element listelm in the list pointed to by head. The field argument is the name of the STAILQ_ENTRY field within the element structure.
STAILQ_REMOVE_HEAD(head, field);
Removes the element at the head of the list pointed to by head. Returns a pointer to the removed element. The field argument is the name of the STAILQ_ENTRY field within the element structure.
STAILQ_REMOVE_TAIL(head, field);
Removes the element at the tail of the list pointed to by head. Returns a pointer to the removed element. The field argument is the name of the STAILQ_ENTRY field within the element structure.
STAILQ_REMOVE(head, elm, field);
Removes the element elm from the list pointed to by head. The field argument is the name of the STAILQ_ENTRY field within the element structure.
STAILQ_CONCAT(head, nhead);
Appends the list pointed to by nhead to the end of the list pointed to by head. The nhead list becomes empty.
STAILQ_SWAP(head1, head2, type);
Swaps the contents of the two lists head1 and head2. The type argument is the name of the list head structure.
STAILQ_FIRST(head);
Returns a pointer to the first element in the list pointed to by head, or NULL if the list is empty.
STAILQ_LAST(head, type, field);
Returns a pointer to the last element in the list pointed to by head, or NULL if the list is empty. The type argument is the name of the element structure, and field is the name of the STAILQ_ENTRY field.
STAILQ_NEXT(elm, field);
Returns a pointer to the next element in the list after elm, or NULL if elm is the last element. The field argument is the name of the STAILQ_ENTRY field within the element structure.
STAILQ_PREV(elm, type, field);
Returns a pointer to the previous element in the list before elm, or NULL if elm is the first element. The type argument is the name of the element structure, and field is the name of the STAILQ_ENTRY field.
STAILQ_EMPTY(head);
Returns true if the list pointed to by head is empty, false otherwise.
STAILQ_FOREACH(var, head, field);
Iterates over all elements in the list pointed to by head. In each iteration, var is set to the current element. The field argument is the name of the STAILQ_ENTRY field within the element structure.
STAILQ_FOREACH_SAFE(var, head, field, nextvar);
A safe version of STAILQ_FOREACH that allows removal of elements during iteration. nextvar is used to store the next element before the current element is processed.
STAILQ_FOREACH_ALL(var, head, field);
Similar to STAILQ_FOREACH, but also iterates over elements that are not currently part of any list. This is useful for lists where elements might be temporarily removed and reinserted.
STAILQ_FOREACH_ALL_SAFE(var, head, field, nextvar);
A safe version of STAILQ_FOREACH_ALL that allows removal of elements during iteration.

RETURN VALUE

STAILQ_FIRST, STAILQ_LAST, STAILQ_NEXT, and STAILQ_PREV return pointers to list elements or NULL.

STAILQ_EMPTY returns a boolean value.

STAILQ_REMOVE_HEAD and STAILQ_REMOVE_TAIL return a pointer to the removed element.

VERSIONS

These macros are available in BSD and compatible systems.

BUGS

The STAILQ_PREV macro is inefficient as it requires traversing the list from the beginning to find the previous element.

STANDARDS

These macros are not part of any C standard, but they are widely available in BSD-derived systems.

HISTORY

The singly linked list macros first appeared in 4.4BSD.

EXAMPLES

The following example demonstrates how to use the STAILQ macros to create, populate, and traverse a singly linked list:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    STAILQ_ENTRY(node) entries;
};

STAILQ_HEAD(my_list_head, node);

int
main() {
    struct my_list_head head;
    struct node *np, *n1, *n2;

    STAILQ_INIT(&head);

    // Add elements to the list
    np = malloc(sizeof(*np));
    np->data = 10;
    STAILQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(*np));
    np->data = 20;
    STAILQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(*np));
    np->data = 30;
    STAILQ_INSERT_HEAD(&head, np, entries);

    /* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);

    /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
