Module Option

Options

type 'a t = 'a option =
| None
| Some de 'a

Le type pour les valeurs optionnelles. Soit None soit une valeur Some v .

val none : 'a option

none est None .

val some : 'a -> 'a option

some v est Some v .

val value : 'a option -> default:'a -> 'a

value o ~default est v si o est Some v et default sinon.

val get : 'a option -> 'a

get o est v si o est Some v et lève une exception sinon.

Lève Invalid_argument si o est None .

val bind : 'a option -> ('a -> 'b option) -> 'b option

bind o f est f v si o est Some v et None si o est None .

val join : 'a option option -> 'a option

join oo est Some v si oo est Some (Some v) et None sinon.

val map : ('a -> 'b) -> 'a option -> 'b option

map f o est None si o est None et Some (f v) si o est Some v .

val fold : none:'a -> some:('b -> 'a) -> 'b option -> 'a

fold ~none ~some o est none si o est None et some v si o est Some v .

val iter : ('a -> unit) -> 'a option -> unit

iter f o est f v si o est Some v et () sinon.

Prédicats et comparaisons

val is_none : 'a option -> bool

is_none o est true si et seulement si o est None .

val is_some : 'a option -> bool

is_some o est true si et seulement si o est Some o .

val equal : ('a -> 'a -> bool) -> 'a option -> 'a option -> bool

equal eq o0 o1 est true si et seulement si o0 et o1 sont tous deux None ou s'ils sont Some v0 et Some v1 et que eq v0 v1 est true .

val compare : ('a -> 'a -> int) -> 'a option -> 'a option -> int

compare cmp o0 o1 est un ordre total sur les options utilisant cmp pour comparer les valeurs enveloppées par Some _ . None est plus petit que les valeurs Some _ .

Conversion

val to_result : none:'e -> 'a option -> ('a, 'e) result

to_result ~none o est Ok v si o est Some v et Error none sinon.

val to_list : 'a option -> 'a list

to_list o est [] si o est None et [v] si o est Some v .

val to_seq : 'a option -> 'a Seq.t

to_seq o est o sous forme de séquence. None est la séquence vide et Some v est la séquence singleton contenant v .
