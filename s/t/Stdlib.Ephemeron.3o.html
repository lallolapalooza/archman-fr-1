Module Ephemeron
: (module Stdlib__Ephemeron)

Accès non synchronisés

Les accès non synchronisés à une table de hachage faible peuvent conduire à un état de table de hachage faible invalide. Par conséquent, les accès concurrents à une table de hachage faible doivent être synchronisés (par exemple avec un Mutex.t ).

module type S = sig end

La signature de sortie des foncteurs Ephemeron.K1.Make et Ephemeron.K2.Make . Ces tables de hachage sont faibles sur les clés. Si toutes les clés d'une liaison sont vivantes, la liaison est conservée, mais si l'une des clés de la liaison est morte, la liaison est supprimée.

module type SeededS = sig end

La signature de sortie des foncteurs Ephemeron.K1.MakeSeeded et Ephemeron.K2.MakeSeeded .

module K1 : sig end

Éphémères avec une seule clé.

module K2 : sig end

Éphémères avec deux clés.

module Kn : sig end

Éphémères avec un nombre arbitraire de clés du même type.
