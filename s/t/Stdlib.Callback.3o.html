Module Callback
: (module Stdlib__Callback)

val register : string -> 'a -> unit

Callback.register n v enregistre la valeur v sous le nom n . Le code C peut ultérieurement récupérer un pointeur vers v en appelant caml_named_value(n) .

val register_exception : string -> exn -> unit

Callback.register_exception n exn enregistre l'exception contenue dans la valeur d'exception exn sous le nom n . Le code C peut ultérieurement récupérer un pointeur vers l'exception en appelant caml_named_value(n) . La valeur d'exception ainsi obtenue convient pour être passée comme premier argument à raise_constant ou raise_with_arg .
