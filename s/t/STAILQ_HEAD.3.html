NOM

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPIS

#include <sys/queue.h>
STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);
STAILQ_HEAD STAILQ_HEAD_INITIALIZER(STAILQ_HEAD head);
void STAILQ_INIT(STAILQ_HEAD *head);
int STAILQ_EMPTY(STAILQ_HEAD *head);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
struct TYPE *STAILQ_FIRST(STAILQ_HEAD *head);
struct TYPE *STAILQ_NEXT(struct TYPE *elm, STAILQ_ENTRY NAME);
STAILQ_FOREACH(struct TYPE *var, STAILQ_HEAD *head, STAILQ_ENTRY NAME);
void STAILQ_REMOVE(STAILQ_HEAD *head, struct TYPE *elm, TYPE,
                         STAILQ_ENTRY NAME);

void STAILQ_CONCAT(STAILQ_HEAD *head1, STAILQ_HEAD *head2);

Note : Il existe des macros identiques préfixées par SIMPLEQ au lieu de STAILQ ; voir VERSIONS.

DESCRIPTION

Ces macros définissent et opèrent sur des files à queue chaînée simplement chaînées.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro STAILQ_HEAD().

Création

Une file à queue chaînée simplement chaînée est dirigée par une structure définie par la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file à queue et l'autre vers le dernier élément de la file à queue. Les éléments sont liés simplement pour une surcharge minimale d'espace et de manipulation de pointeurs, au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file à queue après un élément existant, en tête de la file à queue, ou à la fin de la file à queue. Une structure STAILQ_HEAD est déclarée comme suit :


STAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à lier dans la file à queue. Un pointeur vers la tête de la file à queue peut ensuite être déclaré comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui relie les éléments dans la file à queue.

STAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file à queue head.

STAILQ_INIT() initialise la file à queue référencée par head.

STAILQ_EMPTY() renvoie vrai s'il n'y a aucun élément sur la file à queue.

Insertion

STAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de la file à queue.

STAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file à queue.

STAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

STAILQ_FIRST() renvoie le premier élément de la file à queue ou NULL si la file à queue est vide.

STAILQ_NEXT() renvoie l'élément suivant dans la file à queue, ou NULL si cet élément est le dernier.

STAILQ_FOREACH() parcourt la file à queue référencée par head dans le sens avant, en assignant chaque élément à tour de rôle à var.

Suppression

STAILQ_REMOVE() supprime l'élément elm de la file à queue.

STAILQ_REMOVE_HEAD() supprime l'élément en tête de la file à queue. Pour une efficacité optimale, les éléments supprimés de la tête de la file à queue devraient utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE().

Autres fonctionnalités

STAILQ_CONCAT() concatène la file à queue dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première.

VALEUR DE RETOUR

STAILQ_EMPTY() renvoie une valeur non nulle si la file est vide, et zéro si la file contient au moins une entrée.

STAILQ_FIRST() et STAILQ_NEXT() renvoient un pointeur vers la structure TYPE première ou suivante, respectivement.

STAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la tête de la file head.

VERSIONS

Certains BSD fournissent SIMPLEQ au lieu de STAILQ. Ils sont identiques, mais pour des raisons historiques, ils ont été nommés différemment sur différents BSD. STAILQ est originaire de FreeBSD, et SIMPLEQ est originaire de NetBSD. Pour des raisons de compatibilité, certains systèmes fournissent les deux ensembles de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques à l'exception d'un équivalent SIMPLEQ manquant à STAILQ_CONCAT().

BUGS

STAILQ_FOREACH() ne permet pas que var soit supprimé ou libéré dans la boucle, car cela interférerait avec le parcours. STAILQ_FOREACH_SAFE(), qui est présent sur les BSD mais n'est pas présent dans glibc, résout cette limitation en permettant à var d'être en toute sécurité retiré de la liste et libéré depuis la boucle sans interférer avec le parcours.

NORMES

BSD.

HISTORIQUE

4.4BSD.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File à queue chaînée simplement */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Tête de file à queue chaînée simplement */
    STAILQ_INIT(&head);                     /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insérer en tête */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insérer à la fin */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression de la tête */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }

NAME

STAILQ_HEAD, STAILQ_ENTRY, STAILQ_INIT, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_REMOVE_HEAD, STAILQ_REMOVE_TAIL, STAILQ_CONCAT, STAILQ_FOREACH, STAILQ_FOREACH_SAFE, STAILQ_FIRST, STAILQ_LAST, STAILQ_NEXT, STAILQ_EMPTY — singly-linked tail queue macros

LIBRARY

Standard C Library (libc, -lc)

SYNOPSIS

C++
#include <sys/queue.h>

C
#include <sys/queue.h>

/* List head */
STAILQ_HEAD(list_head, struct entry);
/* Entry in the list */
struct entry {
...
STAILQ_ENTRY(entry) entries;
};
/* Initialization */
struct list_head head;
STAILQ_INIT(&head);
/* Insertion */
struct entry *n;
STAILQ_INSERT_HEAD(&head, n, entries);
STAILQ_INSERT_TAIL(&head, n, entries);
/* Removal */
struct entry *n;
STAILQ_REMOVE_HEAD(&head, entries);
STAILQ_REMOVE_TAIL(&head, entries);
/* Concatenation */
struct list_head head1, head2;
STAILQ_CONCAT(&head1, &head2);
/* Traversal */
struct entry *np;
STAILQ_FOREACH(np, &head, entries) { ... }
STAILQ_FOREACH_SAFE(np, &head, entries, nextvar) { ... }
/* Access */
struct entry *n;
n = STAILQ_FIRST(&head);
n = STAILQ_LAST(&head, entry);
n = STAILQ_NEXT(n, entries);
int empty;
empty = STAILQ_EMPTY(&head);

DESCRIPTION

These macros provide a mechanism for manipulating singly-linked queues with tail pointers. A tail queue is a singly-linked list that allows fast insertion and deletion at both the head and the tail of the list. Because the list is singly-linked, deletion at the tail requires a pointer to the last element's predecessor. However, tail queues maintain a pointer to the last element, allowing for constant time insertion and deletion at the tail.

The queue implementation is parametric. The user must define a structure for the list head (using STAILQ_HEAD) and a structure for the list entries (using STAILQ_ENTRY). The STAILQ_ENTRY macro declares a structure containing the necessary pointers for the queue implementation. The first argument to STAILQ_ENTRY is the name of the structure containing the queue entry, and the second argument is the name of the field which will be used for the queue pointers.

The following macros are available:

STAILQ_HEAD(headname, typename);
Declares a structure type named headname that represents the head of a tail queue. The queue is made up of elements of type typename.
STAILQ_ENTRY(typename);
Declares a structure type suitable for embedding in typename structures to use them as elements in a tail queue. The name of the structure declared is formed by concatenating `stailq_` with typename.
STAILQ_INIT(head);
Initializes the tail queue specified by head to be empty.
STAILQ_INSERT_HEAD(head, elm, field);
Inserts the element elm at the head of the tail queue specified by head. The field argument is the name of the tail queue entry field within the element structure.
STAILQ_INSERT_TAIL(head, elm, field);
Inserts the element elm at the tail of the tail queue specified by head. The field argument is the name of the tail queue entry field within the element structure.
STAILQ_REMOVE_HEAD(head, field);
Removes the head element from the tail queue specified by head. The field argument is the name of the tail queue entry field within the element structure.
STAILQ_REMOVE_TAIL(head, field);
Removes the tail element from the tail queue specified by head. The field argument is the name of the tail queue entry field within the element structure.
STAILQ_CONCAT(head1, head2);
Concatenates the tail queue head2 onto the end of the tail queue head1. After the operation, head2 is left empty.
STAILQ_FOREACH(var, head, field);
Iterates over the elements of the tail queue specified by head. In each iteration, the element is assigned to var. The field argument is the name of the tail queue entry field within the element structure.
STAILQ_FOREACH_SAFE(var, head, field, nextvar);
A safe version of STAILQ_FOREACH. It is intended for use when the iteration body may modify the tail queue, specifically when elements might be removed. The nextvar macro variable is used to store the next element before the current element is processed.
STAILQ_FIRST(head);
Returns a pointer to the first element in the tail queue specified by head, or NULL if the queue is empty.
STAILQ_LAST(head, typename);
Returns a pointer to the last element in the tail queue specified by head, or NULL if the queue is empty. The typename argument is the name of the element structure type.
STAILQ_NEXT(elm, field);
Returns a pointer to the next element in the tail queue after the element elm, or NULL if elm is the last element. The field argument is the name of the tail queue entry field within the element structure.
STAILQ_EMPTY(head);
Returns true (a non-zero value) if the tail queue specified by head is empty, and false (a zero value) otherwise.

RETURN VALUE

The STAILQ_FIRST and STAILQ_LAST macros return a pointer to the respective element, or NULL if the queue is empty. The STAILQ_NEXT macro returns a pointer to the next element, or NULL if the current element is the last. The STAILQ_EMPTY macro returns a non-zero value if the queue is empty, and zero otherwise.

VERSIONS

The tail queue macros first appeared in BSD-4.4.

BUGS

The STAILQ_REMOVE_TAIL macro requires a pointer to the structure defining the queue head, not the queue itself. This is a historical artifact.

The STAILQ_LAST macro requires the name of the structure type containing the queue entry as its second argument. This is inconsistent with other macros.

STANDARDS

These macros are compliant with the BSD family of operating systems. They are not part of the POSIX standard.

HISTORY

The tail queue macros first appeared in 4.4BSD-Lite.

EXAMPLES

The following example demonstrates how to use the tail queue macros to implement a simple list of integers:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    STAILQ_ENTRY(node) entries;
};

STAILQ_HEAD(my_list_head, struct node);

int
main(void)
{
    struct my_list_head head;
    struct node *np, *next_np;

    STAILQ_INIT(&head);

    /* Insert elements */
    for (int i = 1; i <= 5; i++) {
        np = malloc(sizeof(struct node));
        if (np == NULL) {
            perror("malloc");
            exit(EXIT_FAILURE);
        }
        np->data = i;
        STAILQ_INSERT_TAIL(&head, np, entries);
    }

    /* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);

    /* TailQ deletion */
    np = STAILQ_FIRST(&head);
    while (np != NULL) {
        next_np = STAILQ_NEXT(np, entries);
        free(np);
        np = next_np;
    }
    STAILQ_INIT(&head);

    exit(EXIT_SUCCESS);
}
