Paquet: postgresql

Licences: PostgreSQL

START TRANSACTION(7) Documentation PostgreSQL 18.1 START TRANSACTION(7)

NOM

START TRANSACTION - démarrer un bloc de transaction

SYNTAXE

START TRANSACTION [ mode_transaction [, ...] ]
où mode_transaction est l'un des suivants :
    NIVEAU D'ISOLATION { SERIALIZABLE | REPEATABLE READ | READ COMMITTED | READ UNCOMMITTED }
    READ WRITE | READ ONLY
    [ NOT ] DEFERRABLE

DESCRIPTION

Cette commande commence un nouveau bloc de transaction. Si le niveau d'isolation, le mode lecture/écriture ou le mode différable est spécifié, la nouvelle transaction a ces caractéristiques, comme si SET TRANSACTION avait été exécutée. C'est la même chose que la commande BEGIN.

PARAMETRES

Voir SET TRANSACTION (SET_TRANSACTION(7)) pour des informations sur la signification des paramètres de cette instruction.

COMPATIBILITE

Dans la norme, il n'est pas nécessaire d'émettre START TRANSACTION pour démarrer un bloc de transaction : toute commande SQL commence implicitement un bloc. Le comportement de PostgreSQL peut être vu comme l'émission implicite d'un COMMIT après chaque commande qui ne suit pas START TRANSACTION (ou BEGIN), et il est donc souvent appelé « autocommit ». D'autres systèmes de bases de données relationnelles peuvent offrir une fonctionnalité d'autocommit comme commodité.

Le mode_transaction DEFERRABLE est une extension du langage PostgreSQL.

La norme SQL exige des virgules entre les modes_transaction successifs, mais pour des raisons historiques, PostgreSQL permet d'omettre les virgules.

Voir également la section compatibilité de SET TRANSACTION (SET_TRANSACTION(7)).

VOIR AUSSI

BEGIN(7), COMMIT(7), ROLLBACK(7), SAVEPOINT(7), SET TRANSACTION (SET_TRANSACTION(7))
