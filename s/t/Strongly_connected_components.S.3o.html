Module type S

module Id : Identifiable.S

type directed_graph = Id.Set.t Id.Map.t

Si (a -> set) appartient à la map, cela signifie qu'il existe des arêtes de a vers chaque élément de set. On suppose qu'aucune arête ne pointe vers un sommet non représenté dans la map.
