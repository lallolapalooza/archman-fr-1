val fma : float -> float -> float -> float

fma x y z retourne x * y + z , en essayant de calculer cette expression avec un seul arrondi, en utilisant soit des instructions matérielles (fournissant une conformité IEEE complète) soit une émulation logicielle. Notez qu'en Cygwin 64 bits, mingw-w64 64 bits et MSVC 2017 et versions antérieures, cette fonction peut être émulée en raison de bogues connus dans les limitations de ces plateformes. Notez : l'émulation de fma étant coûteuse, assurez-vous d'utiliser le support matériel de fma si la performance est requise.

val nan : float

Une valeur spéciale flottante dénotant le résultat d'une opération indéfinie, comme 0.0 / 0.0 . Elle est appelée "pas un nombre". Toute opération flottante avec nan comme argument retourne nan comme résultat, sauf indication contraire dans la norme IEEE 754. En ce qui concerne les comparaisons flottantes, = , < , <= , > et >= retournent false et <> retourne true si l'un ou les deux de ses arguments est nan .

nan est quiet_nan depuis 5.1 ; c'était un NaN signalant auparavant.

val signaling_nan : float

val of_string : string -> float

Convertit une chaîne donnée en un float. La chaîne est lue en décimal (par défaut) ou en hexadécimal (préfixé par 0x ou 0X ). La forme des nombres décimaux flottants est [-] dd.ddd (e|E) [+|-] dd , où d représente un chiffre décimal. La forme des nombres hexadécimaux flottants est [-] 0(x|X) hh.hhh (p|P) [+|-] dd , où h représente un chiffre hexadécimal et d un chiffre décimal. Dans les deux cas, au moins une des parties entière ou fractionnaire doit être définie ; la partie exponentielle est optionnelle. Le caractère _ (underscore) peut apparaître dans la chaîne et est ignoré. Selon les plateformes d'exécution, d'autres représentations de nombres flottants peuvent être acceptées, mais il ne faut pas s'y fier.

**Lève Failure** si la chaîne donnée n'est pas une représentation valide d'un float.

val of_string_opt : string -> float option

Identique à of_string , mais retourne None au lieu de lever une exception.

val to_string : float -> string

Retourne une représentation sous forme de chaîne d'un nombre flottant.

Cette conversion peut entraîner une perte de précision. Pour un meilleur contrôle sur la façon dont le nombre est imprimé, voir Printf .

Cette fonction est un alias de string_of_float .

type fpclass = fpclass =
| FP_normal (* Nombre normal, aucun des suivants *)
| FP_subnormal (* Nombre très proche de 0.0, avec une précision réduite *)
| FP_zero (* Le nombre est 0.0 ou -0.0 *)
| FP_infinite (* Le nombre est un infini positif ou négatif *)
| FP_nan (* Pas un nombre : résultat d'une opération indéfinie *)

Les cinq classes de nombres flottants, déterminées par la fonction Float.classify_float .

val classify_float : float -> fpclass

Retourne la classe du nombre flottant donné : normal, sous-normal, zéro, infini ou pas un nombre.

val hypot : float -> float -> float

hypot x y renvoie sqrt(x *. x +. y *. y) , c'est-à-dire la longueur de l'hypoténuse d'un triangle rectangle de côtés x et y , ou, de manière équivalente, la distance du point (x,y) à l'origine. Si l'un des arguments x ou y est l'infini, renvoie l'infini même si l'autre est nan .

val round : float -> float

round x arrondit x à l'entier le plus proche, avec les demi-entiers (valeurs fractionnaires de 0.5) arrondis à l'opposé de zéro, quelle que soit la direction d'arrondi actuelle. Si x est un entier, +0. , -0. , nan ou infini, x lui-même est renvoyé.

Sur les systèmes mingw-w64 64 bits, cette fonction peut être émulée en raison d'un bug dans la bibliothèque d'exécution C (CRT) sur cette plateforme.

val ceil : float -> float

Arrondir vers le haut à une valeur entière. ceil f renvoie la plus petite valeur entière supérieure ou égale à f . Le résultat est renvoyé sous forme de float.

val floor : float -> float

Arrondir vers le bas à une valeur entière. floor f renvoie la plus grande valeur entière inférieure ou égale à f . Le résultat est renvoyé sous forme de float.

val next_after : float -> float -> float

next_after x y renvoie la prochaine valeur flottante représentable suivant x dans la direction de y . Plus précisément, si y est supérieur (resp. inférieur) à x , elle renvoie le plus petit (resp. le plus grand) nombre représentable supérieur (resp. inférieur) à x . Si x est égal à y , la fonction renvoie y . Si x ou y est nan , un nan est renvoyé. Notez que next_after max_float infinity = infinity et que next_after 0. infinity est le plus petit nombre positif dénormalisé. Si x est le plus petit nombre positif dénormalisé, next_after x 0. = 0.

Depuis 4.08

val copy_sign : float -> float -> float

copy_sign x y renvoie un float dont la valeur absolue est celle de x et dont le signe est celui de y . Si x est nan , renvoie nan . Si y est nan , renvoie soit x , soit -. x , mais sans précision sur lequel.

val sign_bit : float -> bool

sign_bit x est true si et seulement si le bit de signe de x est positionné. Par exemple, sign_bit 1. et signbit 0. sont false tandis que sign_bit (-1.) et sign_bit (-0.) sont true .

Depuis 4.08

val frexp : float -> float * int

frexp f renvoie la paire de la mantisse et de l'exposant de f . Lorsque f est zéro, la mantisse x et l'exposant n de f sont égaux à zéro. Lorsque f est non nul, ils sont définis par f = x *. 2 ** n et 0.5 <= x < 1.0 .

val ldexp : float -> int -> float

ldexp x n renvoie x *. 2 ** n .

val modf : float -> float * float

modf f renvoie la paire de la partie fractionnaire et de la partie entière de f .

type t = float

Un alias pour le type des nombres à virgule flottante.

val compare : t -> t -> int

compare x y renvoie 0 si x est égal à y , un entier négatif si x est inférieur à y , et un entier positif si x est supérieur à y . compare traite nan comme égal à lui-même et inférieur à toute autre valeur flottante. Ce traitement de nan garantit que compare définit une relation d'ordre total.

val equal : t -> t -> bool

La fonction d'égalité pour les nombres à virgule flottante, comparés en utilisant Float.compare .

val min : t -> t -> t

min x y renvoie le minimum de x et y . Elle renvoie nan lorsque x ou y est nan . De plus, min (-0.) (+0.) = -0.
