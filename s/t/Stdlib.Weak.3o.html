Fonctions de bas niveau

type !'a t

Le type des tableaux de pointeurs faibles (tableaux faibles). Un pointeur faible est une valeur que le garbage collector peut effacer lorsque la valeur n'est plus utilisée (via des pointeurs normaux) par le programme. Notez que les fonctions de finalisation sont exécutées avant l'effacement des pointeurs faibles, car les fonctions de finalisation peuvent rendre les valeurs vivantes à nouveau (avant 4.03, les fonctions de finalisation étaient exécutées après).

Un pointeur faible est dit plein s'il pointe vers une valeur, vide si la valeur a été effacée par le GC.

Notes:

- Les entiers ne sont pas alloués et ne peuvent pas être stockés dans des tableaux faibles.

- Les tableaux faibles ne peuvent pas être marshalisés en utilisant output_value ni les fonctions du module Marshal.

val create : int -> 'a t

Weak.create n renvoie un nouveau tableau faible de longueur n. Tous les pointeurs sont initialement vides.

Lève Invalid_argument si n n'est pas compris entre zéro et Obj.Ephemeron.max_ephe_length (bornes incluses).

val length : 'a t -> int

Weak.length ar renvoie la longueur (nombre d'éléments) de ar.

val set : 'a t -> int -> 'a option -> unit

Weak.set ar n (Some el) définit la cellule n de ar pour qu'elle soit un pointeur (plein) vers el ; Weak.set ar n None définit la cellule n de ar comme vide.

Lève Invalid_argument si n n'est pas dans la plage 0 à Weak.length ar - 1.

val get : 'a t -> int -> 'a option

Weak.get ar n renvoie None si la cellule n de ar est vide, Some x (où x est la valeur) si elle est pleine.

Lève Invalid_argument si n n'est pas dans la plage 0 à Weak.length ar - 1.

val get_copy : 'a t -> int -> 'a option

Weak.get_copy ar n renvoie None si la cellule n de ar est vide, Some x (où x est une copie (superficielle) de la valeur) si elle est pleine. En plus des pièges avec les valeurs mutables, la différence intéressante avec get est que get_copy n'empêche pas le GC incrémental d'effacer la valeur dans son cycle courant (get peut retarder l'effacement au prochain cycle de GC).

Lève Invalid_argument si n n'est pas dans la plage 0 à Weak.length ar - 1.

Si l'élément est un bloc personnalisé, il n'est pas copié.

val check : 'a t -> int -> bool

Weak.check ar n renvoie true si la cellule n de ar est pleine, false si elle est vide. Notez que même si Weak.check ar n renvoie true, un appel ultérieur à Weak.get ar n peut renvoyer None.

Lève Invalid_argument si n n'est pas dans la plage 0 à Weak.length ar - 1.

val fill : 'a t -> int -> int -> 'a option -> unit

Weak.fill ar ofs len el remplit avec el tous les pointeurs de ar de ofs à ofs + len - 1.

Lève Invalid_argument si ofs et len ne désignent pas un sous-tableau valide de ar.

val blit : 'a t -> int -> 'a t -> int -> int -> unit

Weak.blit ar1 off1 ar2 off2 len copie len pointeurs faibles de ar1 (en commençant à off1) vers ar2 (en commençant à off2). Fonctionne correctement même si ar1 et ar2 sont identiques.

Lève Invalid_argument si off1 et len ne désignent pas un sous-tableau valide de ar1, ou si off2 et len ne désignent pas un sous-tableau valide de ar2.

Ensembles de hachage faibles

Un ensemble de hachage faible est un ensemble indexé par hachage. Chaque valeur peut disparaître magiquement de l'ensemble lorsqu'elle n'est plus utilisée par le reste du programme. Ceci est normalement utilisé pour partager des structures de données sans induire de fuites de mémoire. Les ensembles de hachage faibles sont définis sur des valeurs d'un module Hashtbl.HashedType; la relation equal et la fonction hash sont prises de ce module. Nous dirons que v est une instance de x si equal x v est true.

La relation equal doit pouvoir fonctionner sur une copie superficielle des valeurs et donner le même résultat qu'avec les valeurs elles-mêmes.

Accès non synchronisés

Les accès non synchronisés aux ensembles de hachage faibles sont une erreur de programmation. Les accès non synchronisés à un ensemble de hachage faible peuvent entraîner un état d'ensemble de hachage faible invalide. Par conséquent, les accès concurrentiels aux ensembles de hachage faibles doivent être synchronisés (par exemple avec un Mutex.t).

module type S = sig end

La signature de sortie du foncteur Weak.Make.

module Make : (H : Hashtbl.HashedType) -> sig end

Foncteur construisant une implémentation de la structure des ensembles de hachage faibles. H.equal ne peut pas être l'égalité physique, car seules des copies superficielles des éléments de l'ensemble lui sont fournies.
