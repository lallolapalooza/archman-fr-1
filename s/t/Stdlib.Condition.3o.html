Module Stdlib.Condition

DOCUMENTATION

Module Condition
: (module Stdlib__Condition)

type t

Le type des variables de condition.

val create : unit -> t

create() crée et retourne une nouvelle variable de condition. Cette variable de condition doit être associée (dans l'esprit du programmeur) à un certain mutex m et à une certaine propriété P de la structure de données protégée par le mutex m .

val wait : t -> Mutex.t -> unit

L'appel wait c m est autorisé uniquement si m est le mutex associé à la variable de condition c , et uniquement si m est actuellement verrouillé. Cet appel déverrouille atomiquement le mutex m et suspend le thread courant sur la variable de condition c . Ce thread peut être réveillé plus tard après que la variable de condition c ait été signalée via Condition.signal ou Condition.broadcast ; cependant, il peut également être réveillé sans raison. Le mutex m est à nouveau verrouillé avant que wait ne retourne. On ne peut pas supposer que la propriété P associée à la variable de condition c est vraie lorsque wait retourne ; il faut explicitement tester si P est vraie après avoir appelé wait .

val signal : t -> unit

signal c réveille l'un des threads en attente sur la variable de condition c , s'il y en a un. S'il n'y en a pas, cet appel n'a aucun effet.

Il est recommandé d'appeler signal c à l'intérieur d'une section critique, c'est-à-dire, tant que le mutex m associé à c est verrouillé.

val broadcast : t -> unit

broadcast c réveille tous les threads en attente sur la variable de condition c . S'il n'y en a pas, cet appel n'a aucun effet.

Il est recommandé d'appeler broadcast c à l'intérieur d'une section critique, c'est-à-dire, tant que le mutex m associé à c est verrouillé.
