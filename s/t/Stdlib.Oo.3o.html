: (module Stdlib__Oo)

val copy : (< .. > as 'a) -> 'a

Oo.copy o renvoie une copie de l'objet o , c'est-à-dire un nouvel objet avec les mêmes méthodes et variables d'instance que o .

Attention accès non synchronisé. Les accès non synchronisés aux objets mutables sont une erreur de programmation.

val id : < .. > -> int

Renvoie un entier identifiant cet objet, unique pour l'exécution courante du programme. Les fonctions de comparaison et de hachage génériques sont basées sur cet entier. Lorsqu'un objet est obtenu par désérialisation, son id est renouvelé et donc différent de l'objet d'origine. Par conséquent, les invariants internes des structures de données telles que les tables de hachage ou les ensembles contenant des objets sont brisés après la désérialisation des structures de données.
