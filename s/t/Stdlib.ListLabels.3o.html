type 'a t = 'a list =
| []
| (::) of 'a * 'a list

Un alias pour le type des listes.

value length : 'a list -> int

Retourne la longueur (nombre d'éléments) de la liste donnée.

value compare_lengths : 'a list -> 'b list -> int

Compare les longueurs de deux listes. compare_lengths l1 l2 est équivalent à compare (length l1) (length l2), sauf que le calcul s'arrête après avoir atteint la fin de la liste la plus courte.

Since 4.05

value compare_length_with : 'a list -> length:int -> int

Compare la longueur d'une liste à un entier. compare_length_with l len est équivalent à compare (length l) len, sauf que le calcul s'arrête après au plus len itérations sur la liste.

Since 4.05

value is_empty : 'a list -> bool

is_empty l est vrai si et seulement si l n'a aucun élément. C'est équivalent à compare_length_with l 0 = 0.

Since 5.1

value cons : 'a -> 'a list -> 'a list

cons x xs est x :: xs.

Since 4.05

value singleton : 'a -> 'a list

singleton x retourne la liste à un élément [x].

Since 5.4

value hd : 'a list -> 'a

Retourne le premier élément de la liste donnée.

Raises Failure si la liste est vide.

value tl : 'a list -> 'a list

Retourne la liste donnée sans son premier élément.

Raises Failure si la liste est vide.

value nth : 'a list -> int -> 'a

Retourne le n-ième élément de la liste donnée. Le premier élément (tête de la liste) est à la position 0.

Raises Failure si la liste est trop courte.

Raises Invalid_argument si n est négatif.

value nth_opt : 'a list -> int -> 'a option

Retourne le n-ième élément de la liste donnée. Le premier élément (tête de la liste) est à la position 0. Retourne None si la liste est trop courte.

Since 4.05

Raises Invalid_argument si n est négatif.

value rev : 'a list -> 'a list

Inverse la liste.

value init : length:int -> f:int -> 'a list

init ~len ~f est [f 0; f 1; ...; f (len-1)], évalué de gauche à droite.

Since 4.06

Raises Invalid_argument si len < 0.

value append : 'a list -> 'a list -> 'a list

append l0 l1 ajoute l1 à l0. C'est la même fonction que l'opérateur infixe @.

Since 5.1 this function is tail-recursive.

value rev_append : 'a list -> 'a list -> 'a list

rev_append l1 l2 inverse l1 et l'ajoute à l2. C'est équivalent à (ListLabels.rev l1) @ l2.

value concat : 'a list list -> 'a list

Concatène une liste de listes. Les éléments de la liste d'entrée sont tous concaténés ensemble (dans le même ordre) pour donner le résultat. N'est pas récursive terminale (longueur de la liste d'entrée + longueur de la plus longue sous-liste).

value flatten : 'a list list -> 'a list

C'est la même chose que ListLabels.concat. N'est pas récursive terminale (longueur de la liste d'entrée + longueur de la plus longue sous-liste).

Comparaison

value equals : eq:('a -> 'a -> bool) -> 'a list -> 'a list -> bool

equals eq [a1; ...; an] [b1; ..; bm] est vrai lorsque les deux listes d'entrée ont la même longueur, et que pour chaque paire d'éléments ai, bi à la même position, on a eq ai bi.

Note : la fonction eq peut être appelée même si les listes ont des longueurs différentes. Si vous savez que votre fonction d'égalité est coûteuse, vous pourriez vouloir vérifier ListLabels.compare_lengths au préalable.

Since 4.12

value compare : cmp:('a -> 'a -> int) -> 'a list -> 'a list -> int

compare cmp [a1; ...; an] [b1; ...; bm] effectue une comparaison lexicographique des deux listes d'entrée, en utilisant la même interface cmp que compare :

- a1 :: l1 est inférieur à a2 :: l2 (résultat négatif) si a1 est inférieur à a2, ou s'ils sont égaux (résultat 0) et que l1 est inférieur à l2.

- la liste vide [] est inférieure aux listes non vides.

Note : la fonction cmp est appelée même si les listes ont des longueurs différentes.

Since 4.12

Itérateurs

value iter : f:('a -> unit) -> 'a list -> unit

iter ~f [a1; ...; an] applique la fonction f à chaque élément de [a1; ...; an]. C'est équivalent à f a1; f a2; ...; f an.

value iteri : f:(int -> 'a -> unit) -> 'a list -> unit

C'est la même chose que ListLabels.iter, mais la fonction est appliquée à la position de l'élément (en commençant par 0) et à l'élément lui-même comme second argument.

Since 4.00

value map : f:('a -> 'b) -> 'a list -> 'b list

map ~f [a1; ...; an] applique la fonction f à chaque élément de [a1; ...; an] et construit la liste [f a1; ...; f an] avec les résultats obtenus de f.

value mapi : f:(int -> 'a -> 'b) -> 'a list -> 'b list

C'est la même chose que ListLabels.map, mais la fonction est appliquée à la position de l'élément (en commençant par 0) et à l'élément lui-même comme second argument.

Since 4.00

value rev_map : f:('a -> 'b) -> 'a list -> 'b list

rev_map ~f l donne le même résultat que ListLabels.rev (ListLabels.map f l), mais est plus efficace.

value filter_map : f:('a -> 'b option) -> 'a list -> 'b list

filter_map ~f l applique f à chaque élément de l, filtre les éléments None et retourne la liste des arguments des éléments Some.

Since 4.08

value concat_map : f:('a -> 'b list) -> 'a list -> 'b list

concat_map ~f l donne le même résultat que ListLabels.concat (ListLabels.map f l), c'est-à-dire l'itérateur de listes. Est récursive terminale.

Since 4.10

value fold_left_map : f:('acc -> 'a -> 'acc * 'b) -> init:'acc -> 'a list -> 'acc * 'b list

fold_left_map est une combinaison de fold_left et map qui passe un accumulateur à travers les appels à f.

Since 4.11

value fold_left : f:('acc -> 'a -> 'acc) -> init:'acc -> 'a list -> 'acc

fold_left ~f ~init [b1; ...; bn] est f (... (f (f init b1) b2) ...) bn.

value fold_right : f:('a -> 'acc -> 'acc) -> 'a list -> init:'acc -> 'acc

fold_right ~f [a1; ...; an] ~init est f a1 (f a2 (... (f an init) ...)). N'est pas récursive terminale.

rev_map2 ~f l1 l2 donne le même résultat que ListLabels.rev ( ListLabels.map2 f l1 l2) , mais est plus efficace.

val fold_left2 : f:('acc -> 'a -> 'b -> 'acc) -> init:'acc -> 'a list -> 'b list -> 'acc

fold_left2 ~f ~init [a1; ...; an] [b1; ...; bn] est f (... (f (f init a1 b1) a2 b2) ...) an bn .

Lève Invalid_argument si les deux listes ont des longueurs différentes.

val fold_right2 : f:('a -> 'b -> 'acc -> 'acc) -> 'a list -> 'b list -> init:'acc -> 'acc

fold_right2 ~f [a1; ...; an] [b1; ...; bn] ~init est f a1 b1 (f a2 b2 (... (f an bn init) ...)) .

Lève Invalid_argument si les deux listes ont des longueurs différentes. Pas récurrent de queue.

Scan de liste

val for_all : f:('a -> bool) -> 'a list -> bool

for_all ~f [a1; ...; an] vérifie si tous les éléments de la liste satisfont le prédicat f . Autrement dit, cela retourne (f a1) && (f a2) && ... && (f an) pour une liste non vide et true si la liste est vide.

val exists : f:('a -> bool) -> 'a list -> bool

exists ~f [a1; ...; an] vérifie si au moins un élément de la liste satisfait le prédicat f . Autrement dit, cela retourne (f a1) || (f a2) || ... || (f an) pour une liste non vide et false si la liste est vide.

val for_all2 : f:('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Identique à ListLabels.for_all , mais pour un prédicat à deux arguments.

Lève Invalid_argument si les deux listes ont des longueurs différentes.

val exists2 : f:('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Identique à ListLabels.exists , mais pour un prédicat à deux arguments.

Lève Invalid_argument si les deux listes ont des longueurs différentes.

val mem : 'a -> set:'a list -> bool

mem a ~set est vrai si et seulement si a est égal à un élément de set .

val memq : 'a -> set:'a list -> bool

Identique à ListLabels.mem , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les éléments de la liste.

Recherche dans une liste

val find : f:('a -> bool) -> 'a list -> 'a

find ~f l retourne le premier élément de la liste l qui satisfait le prédicat f .

Lève Not_found s'il n'y a pas de valeur qui satisfait f dans la liste l .

val find_opt : f:('a -> bool) -> 'a list -> 'a option

find ~f l retourne le premier élément de la liste l qui satisfait le prédicat f . Retourne None s'il n'y a pas de valeur qui satisfait f dans la liste l .

Since 4.05

val find_index : f:('a -> bool) -> 'a list -> int option

find_index ~f xs retourne Some i , où i est l'indice du premier élément de la liste xs qui satisfait f x , s'il existe un tel élément.

Il retourne None s'il n'existe pas un tel élément.

Since 5.1

val find_map : f:('a -> 'b option) -> 'a list -> 'b option

find_map ~f l applique f aux éléments de l dans l'ordre, et retourne le premier résultat de la forme Some v , ou None si aucun n'existe.

Since 4.10

val find_mapi : f:(int -> 'a -> 'b option) -> 'a list -> 'b option

Identique à find_map , mais le prédicat est appliqué à l'indice de l'élément comme premier argument (en comptant à partir de 0), et à l'élément lui-même comme second argument.

Since 5.1

val filter : f:('a -> bool) -> 'a list -> 'a list

filter ~f l retourne tous les éléments de la liste l qui satisfont le prédicat f . L'ordre des éléments dans la liste d'entrée est préservé.

val find_all : f:('a -> bool) -> 'a list -> 'a list

find_all est un autre nom pour ListLabels.filter .

val filteri : f:(int -> 'a -> bool) -> 'a list -> 'a list

Identique à ListLabels.filter , mais le prédicat est appliqué à l'indice de l'élément comme premier argument (en comptant à partir de 0), et à l'élément lui-même comme second argument.

Since 4.11

Manipulation de liste

val take : int -> 'a list -> 'a list

take n l retourne le préfixe de l de longueur n , ou une copie de l si n > length l . C'est la liste vide si n est négatif.

Attention. Dans la version 5.3 uniquement, cette fonction lève Invalid_argument pour les valeurs négatives de n.

Since 5.3

val drop : int -> 'a list -> 'a list

drop n l retourne le suffixe de l après n éléments, ou [] si n > length l . C'est l si n est négatif.

Attention. Dans la version 5.3 uniquement, cette fonction lève Invalid_argument pour les valeurs négatives de n.

Since 5.3

val take_while : f:('a -> bool) -> 'a list -> 'a list

take_while p l est le plus long préfixe (éventuellement vide) de l ne contenant que des éléments satisfaisant p .

Since 5.3

val drop_while : f:('a -> bool) -> 'a list -> 'a list

drop_while p l est le plus long suffixe (éventuellement vide) de l commençant au premier élément qui ne satisfait pas p .

Since 5.3

val partition : f:('a -> bool) -> 'a list -> 'a list * 'a list

partition ~f l retourne une paire de listes (l1, l2) , où l1 est la liste de tous les éléments de l qui satisfont le prédicat f , et l2 est la liste de tous les éléments de l qui ne satisfont pas f . L'ordre des éléments dans la liste d'entrée est préservé.

val partition_map : f:('a -> ('b, 'c) Either.t) -> 'a list -> 'b list * 'c list

partition_map f l retourne une paire de listes (l1, l2) telle que, pour chaque élément x de la liste d'entrée l :

- si f x est Left y1 , alors y1 est dans l1 , et

- si f x est Right y2 , alors y2 est dans l2 .

Les éléments de sortie sont inclus dans l1 et l2 dans le même ordre relatif que les éléments d'entrée correspondants dans l .

En particulier, partition_map (fun x -> if f x then Left x else Right x) l est équivalent à partition f l .

Since 4.12

Listes d'association

val assoc : 'a -> ('a * 'b) list -> 'b

assoc a l retourne la valeur associée à la clé a dans la liste de paires l . Autrement dit, assoc a [ ...; (a,b); ...] = b si (a,b) est la première association de a dans la liste l .

Lève Not_found s'il n'y a pas de valeur associée à a dans la liste l .

val assoc_opt : 'a -> ('a * 'b) list -> 'b option

assoc_opt a l retourne la valeur associée à la clé a dans la liste de paires l . Autrement dit, assoc_opt a [ ...; (a,b); ...] = Some b si (a,b) est la première association de a dans la liste l . Retourne None s'il n'y a pas de valeur associée à a dans la liste l .

Since 4.05

val assq : 'a -> ('a * 'b) list -> 'b

Identique à ListLabels.assoc , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les clés.

val assq_opt : 'a -> ('a * 'b) list -> 'b option

Identique à ListLabels.assoc_opt , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les clés.

Since 4.05

val mem_assoc : 'a -> map:('a * 'b) list -> bool

Identique à ListLabels.assoc , mais retourne simplement true si une association existe, et false si aucune association n'existe pour la clé donnée.

val mem_assq : 'a -> map:('a * 'b) list -> bool

Identique à ListLabels.mem_assoc , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les clés.

val remove_assoc : 'a -> ('a * 'b) list -> ('a * 'b) list

remove_assoc a l retourne la liste de paires l sans la première paire dont la clé est a , le cas échéant. Pas récurrent de queue.

val remove_assq : 'a -> ('a * 'b) list -> ('a * 'b) list

Identique à ListLabels.remove_assoc , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les clés. Pas récurrent de queue.

Listes de paires

val split : ('a * 'b) list -> 'a list * 'b list

Transforme une liste de paires en une paire de listes : split [(a1,b1); ...; (an,bn)] est ([a1; ...; an], [b1; ...; bn]) . Pas récurrent de queue.

val combine : 'a list -> 'b list -> ('a * 'b) list

Transforme une paire de listes en une liste de paires : combine [a1; ...; an] [b1; ...; bn] est [(a1,b1); ...; (an,bn)] .

Lève Invalid_argument si les deux listes ont des longueurs différentes. Pas récurrent de queue.

Stdlib.ListLabels - OCaml Standard Library

NAME

ListLabels - Labeled operations on lists.

Module

ListLabels

Documentation

The functions in the ListLabels module are available by default in the top-level module, so they are globally accessible without opening the module. The module List is an unlabeled version of this module.

val sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Sort a list in increasing order according to a comparison function. The comparison function must return 0 if its arguments compare as equal, a positive integer if the first is greater, and a negative integer if the first is smaller (see Array.sort for a complete specification). For example, compare is a suitable comparison function. The resulting list is sorted in increasing order. ListLabels.sort is guaranteed to run in constant heap space (in addition to the size of the result list) and logarithmic stack space.

The current implementation uses Merge Sort. It runs in constant heap space and logarithmic stack space.

val stable_sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort , but the sorting algorithm is guaranteed to be stable (i.e. elements that compare equal are kept in their original order).

The current implementation uses Merge Sort. It runs in constant heap space and logarithmic stack space.

val fast_sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort or ListLabels.stable_sort , whichever is faster on typical input.

val sort_uniq : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort , but also remove duplicates: if multiple elements compare equal, keep only the first.

Before5.4 the element kept was not necessarily the first one.

Since 4.03

val merge : cmp:('a -> 'a -> int) -> 'a list -> 'a list -> 'a list

Merge two lists: Assuming that l1 and l2 are sorted according to the comparison function cmp , merge ~cmp l1 l2 will return a sorted list containing all the elements of l1 and l2 . If several elements compare equal, the elements of l1 will be before the elements of l2 . Not tail-recursive (sum of the lengths of the arguments).
