DESCRIPTION

Ces macros définissent et manipulent quatre types de structures de données pouvant être utilisées dans du code source C et C++ :

  1. Listes
  2. Listes chaînées simplement
  3. Files à queue chaînées simplement
  4. Files à queue chaînées
Les quatre structures prennent en charge les fonctionnalités suivantes :
  1. Insertion d'une nouvelle entrée en tête de liste.
  2. Insertion d'une nouvelle entrée après n'importe quel élément de la liste.
  3. Suppression d'une entrée en tête de liste en temps O(1).
  4. Parcours avant dans la liste.
  5. Échange du contenu de deux listes.

Les listes chaînées simplement sont les plus simples des quatre structures de données et ne prennent en charge que les fonctionnalités ci-dessus. Les listes chaînées simplement sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une pile (LIFO). Les listes chaînées simplement ajoutent les fonctionnalités suivantes :

  1. Suppression d'une entrée quelconque dans la liste en temps O(n).
  2. Concaténation de deux listes en temps O(n).

Les files à queue chaînées simplement ajoutent les fonctionnalités suivantes :

  1. Les entrées peuvent être ajoutées à la fin d'une liste.
  2. Suppression d'une entrée quelconque dans la liste en temps O(n).
  3. Elles peuvent être concaténées.
Cependant :
  1. Toutes les insertions de liste doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un seul.
  3. La taille du code est environ 15 % plus grande et les opérations sont environ 20 % plus lentes que pour les listes chaînées simplement.

Les files à queue chaînées simplement sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une file d'attente (FIFO).

Tous les types de structures de données doublement chaînées (listes et files à queue) permettent en outre :

  1. Insertion d'une nouvelle entrée avant n'importe quel élément de la liste.
  2. Suppression d'une entrée quelconque dans la liste en temps O(1).
Cependant :
  1. Chaque élément nécessite deux pointeurs au lieu d'un seul.
  2. La taille du code et le temps d'exécution des opérations (à l'exception de la suppression) sont environ le double de ceux des structures de données simplement chaînées.

Les listes chaînées sont les plus simples des structures de données doublement chaînées. Elles ajoutent les fonctionnalités suivantes par rapport à ce qui précède :

  1. Concaténation de deux listes en temps O(n).
  2. Elles peuvent être parcourues en arrière.
Cependant :
  1. Pour parcourir en arrière, une entrée pour commencer le parcours et la liste dans laquelle elle est contenue doivent être spécifiées.

Les files à queue ajoutent les fonctionnalités suivantes :

  1. Les entrées peuvent être ajoutées à la fin d'une liste.
  2. Elles peuvent être parcourues en arrière, de la queue à la tête.
  3. Elles peuvent être concaténées.
Cependant :
  1. Toutes les insertions et suppressions de liste doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un seul.
  3. La taille du code est environ 15 % plus grande et les opérations sont environ 20 % plus lentes que pour les listes chaînées simplement.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur. La structure doit contenir un champ appelé NOM qui est de type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, ou TAILQ_ENTRY. Dans les définitions de macros, CLASSTYPE est le nom d'une classe définie par l'utilisateur. La classe doit contenir un champ appelé NOM qui est de type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, ou TAILQ_CLASS_ENTRY. L'argument NOM_TÊTE est le nom d'une structure définie par l'utilisateur qui doit être déclarée à l'aide des macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, ou TAILQ_CLASS_HEAD. Voir les exemples ci-dessous pour plus d'explications sur l'utilisation de ces macros.

LISTES CHAÎNÉES SIMPLEMENT

Une liste chaînée simplement est dirigée par une structure définie par la macro SLIST_HEAD. Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont chaînés simplement pour un minimum d'espace et de surcharge de manipulation de pointeurs, au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant ou en tête de liste. Une structure SLIST_HEAD est déclarée comme suit :

SLIST_HEAD(NOM_TÊTE, TYPE) tête;

où NOM_TÊTE est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme :

struct NOM_TÊTE *têtep;

(Les noms tête et têtep sont sélectionnables par l'utilisateur.)

La macro SLIST_HEAD_INITIALIZER évalue à un initialiseur pour la liste tête.

La macro SLIST_CONCAT concatène la liste dirigée par tête2 à la fin de celle dirigée par tête1, supprimant toutes les entrées de la première. L'utilisation de cette macro doit être évitée car elle parcourt l'intégralité de la liste tête1. Une file à queue chaînée simplement doit être utilisée si cette macro est nécessaire dans les chemins de code à forte utilisation ou pour opérer sur de longues listes.

La macro SLIST_EMPTY évalue à vrai s'il n'y a pas d'éléments dans la liste.

La macro SLIST_ENTRY déclare une structure qui connecte les éléments de la liste.

La macro SLIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro SLIST_FOREACH parcourt la liste référencée par tête dans le sens avant, assignant chaque élément en tour à var.

La macro SLIST_FOREACH_FROM se comporte identiquement à SLIST_FOREACH lorsque var est NULL, sinon elle traite var comme un élément SLIST trouvé précédemment et commence la boucle à var au lieu du premier élément de la SLIST référencée par tête.

La macro SLIST_FOREACH_SAFE parcourt la liste référencée par tête dans le sens avant, assignant chaque élément en tour à var. Cependant, contrairement à SLIST_FOREACH(), ici il est permis de supprimer var ainsi que de le libérer depuis l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro SLIST_FOREACH_FROM_SAFE se comporte identiquement à SLIST_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément SLIST trouvé précédemment et commence la boucle à var au lieu du premier élément de la SLIST référencée par tête.

La macro SLIST_INIT initialise la liste référencée par tête.

La macro SLIST_INSERT_HEAD insère le nouvel élément elm en tête de la liste.

La macro SLIST_INSERT_AFTER insère le nouvel élément elm après l'élément

SLIST

Une liste chaînée simple est dirigée par une structure définie par la macro SLIST_HEAD. Cette structure contient un pointeur vers le premier élément de la liste. Les éléments sont liés en chaîne simple pour un minimum d'espace et une surcharge de manipulation de pointeur, au prix d'une complexité O(n) pour la suppression d'éléments arbitraires. Les nouveaux éléments peuvent être ajoutés à la liste après un élément existant, ou au début de la liste. Une structure SLIST_HEAD est déclarée comme suit :

SLIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro SLIST_HEAD_INITIALIZER s'évalue à un initialiseur pour la liste head.

La macro SLIST_CONCAT concatène la liste dirigée par head2 à la fin de celle dirigée par head1 en supprimant toutes les entrées de la première.

La macro SLIST_EMPTY s'évalue à vrai s'il n'y a aucun élément dans la liste.

La macro SLIST_ENTRY déclare une structure qui connecte les éléments de la liste.

La macro SLIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro SLIST_FOREACH parcourt la liste référencée par head dans le sens avant, assignant chaque élément tour à tour à var.

La macro SLIST_FOREACH_FROM se comporte identiquement à SLIST_FOREACH lorsque var est NULL, sinon elle traite var comme un élément SLIST trouvé précédemment et commence la boucle à var au lieu du premier élément de la SLIST référencée par head.

La macro SLIST_FOREACH_SAFE parcourt la liste référencée par head dans le sens avant, assignant chaque élément tour à tour à var. Cependant, contrairement à SLIST_FOREACH(), il est permis de supprimer var ainsi que de le libérer depuis l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro SLIST_FOREACH_FROM_SAFE se comporte identiquement à SLIST_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément SLIST trouvé précédemment et commence la boucle à var au lieu du premier élément de la SLIST référencée par head.

La macro SLIST_INIT initialise la liste référencée par head.

La macro SLIST_INSERT_HEAD insère le nouvel élément elm à la tête de la liste.

La macro SLIST_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro SLIST_NEXT renvoie le prochain élément de la liste.

La macro SLIST_REMOVE_AFTER supprime l'élément après elm de la liste. Contrairement à SLIST_REMOVE, cette macro ne parcourt pas toute la liste.

La macro SLIST_REMOVE_HEAD supprime l'élément elm de la tête de la liste. Pour une efficacité optimale, les éléments supprimés de la tête de la liste devraient explicitement utiliser cette macro plutôt que la macro générique SLIST_REMOVE.

La macro SLIST_REMOVE supprime l'élément elm de la liste. L'utilisation de cette macro doit être évitée car elle parcourt toute la liste. Une liste doublement chaînée devrait être utilisée si cette macro est nécessaire dans des chemins de code à forte utilisation ou pour travailler sur de longues listes.

La macro SLIST_SWAP échange le contenu de head1 et head2.

EXEMPLE DE LISTE CHAÎNEE SIMPLE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Tête de liste chaînée simple. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Liste chaînée simple. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Initialise la liste. */

n1 = malloc(sizeof(struct entry));	/* Insertion à la tête. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertion après. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Suppression. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Suppression de la tête. */
free(n3);
					/* Parcours avant. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sécurisé. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Suppression de la liste. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

FILES D'ATTENTE À QUEUE SIMPLE

Une file d'attente à queue simple est dirigée par une structure définie par la macro STAILQ_HEAD. Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file d'attente et l'autre vers le dernier élément de la file d'attente. Les éléments sont liés en chaîne simple pour un minimum d'espace et de surcharge de manipulation de pointeur au prix d'une complexité O(n) pour la suppression d'éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file d'attente après un élément existant, au début de la file d'attente, ou à la fin de la file d'attente. Une structure STAILQ_HEAD est déclarée comme suit :

STAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la file d'attente. Un pointeur vers la tête de la file d'attente peut ensuite être déclaré comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro STAILQ_HEAD_INITIALIZER s'évalue à un initialiseur pour la file d'attente head.

La macro STAILQ_CONCAT concatène la file d'attente dirigée par head2 à la fin de celle dirigée par head1 en supprimant toutes les entrées de la première.

La macro STAILQ_EMPTY s'évalue à vrai s'il n'y a aucun élément dans la file d'attente.

La macro STAILQ_ENTRY déclare une structure qui connecte les éléments dans la file d'attente.

La macro STAILQ_FIRST renvoie le premier élément de la file d'attente ou NULL si la file d'attente est vide.

La macro STAILQ_FOREACH parcourt la file d'attente référencée par head dans le sens avant, assignant chaque élément tour à tour à var.

La macro STAILQ_FOREACH_FROM se comporte identiquement à STAILQ_FOREACH lorsque var est NULL, sinon elle traite var comme un élément STAILQ trouvé précédemment et commence la boucle à var au lieu du premier élément de la STAILQ référencée par head.

La macro STAILQ_FOREACH_SAFE parcourt la file d'attente référencée par head dans le sens avant, assignant chaque élément tour à tour à var. Cependant, contrairement à STAILQ_FOREACH(), il est permis de supprimer var ainsi que de le libérer depuis l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro STAILQ_FOREACH_FROM_SAFE se comporte identiquement à STAILQ_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément STAILQ trouvé précédemment et commence la boucle à var au lieu du premier élément de la STAILQ référencée par head.

La macro STAILQ_INIT initialise la file d'attente référencée par head.

La macro STAILQ_INSERT_HEAD insère le nouvel élément elm à la tête de la file d'attente.

La macro STAILQ_INSERT_TAIL insère le nouvel élément elm à la fin de la file d'attente.

La macro STAILQ_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro STAILQ_LAST renvoie le dernier élément de la file d'attente. Si la file d'attente est vide, la valeur renvoyée est NULL.

La macro STAILQ_NEXT renvoie le prochain élément de la file d'attente, ou NULL si cet élément est le dernier.

La macro STAILQ_REMOVE_AFTER supprime l'élément après elm de la file d'attente. Contrairement à STAILQ_REMOVE, cette macro ne parcourt pas toute la file d'attente.

La macro STAILQ_REMOVE_HEAD supprime l'élément à la tête de la file d'attente. Pour une efficacité optimale, les éléments supprimés de la tête de la file d'attente devraient utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE.

La macro STAILQ_REMOVE supprime l'élément elm de la file d'attente. L'utilisation de cette macro doit être évitée car elle parcourt toute la liste. Une file d'attente doublement chaînée devrait être utilisée si cette macro est nécessaire dans des chemins de code à forte utilisation ou pour opérer sur de longues files d'attente.

La macro STAILQ_SWAP échange le contenu de head1 et head2.

    STAILQ_HEAD_INITIALIZER(head);

	...
	STAILQ_ENTRY(entry) entries;	/* File d'attente à queue. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Initialise la file. */

n1 = malloc(sizeof(struct entry));	/* Insertion à la tête. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insertion à la fin. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertion après. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Suppression. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Suppression de la tête. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Parcours avant. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sécurisé. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Suppression de la file d'attente. */

	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}

	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}

LISTES

Une liste est dirigée par une structure définie par la macro LIST_HEAD. Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont liés en double chaîne de sorte qu'un élément arbitraire puisse être supprimé sans parcourir la liste. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un élément existant, ou au début de la liste. Une structure LIST_HEAD est déclarée comme suit :

LIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro LIST_HEAD_INITIALIZER s'évalue à un initialiseur pour la liste head.

La macro LIST_CONCAT concatène la liste dirigée par head2 à la fin de celle dirigée par head1 en supprimant toutes les entrées de la première. L'utilisation de cette macro doit être évitée car elle parcourt l'intégralité de la liste head1. Une file d'attente devrait être utilisée si cette macro est nécessaire dans des chemins de code à forte utilisation ou pour opérer sur de longues listes.

La macro LIST_EMPTY s'évalue à vrai si aucun élément n'est dans la liste.

La macro LIST_ENTRY déclare une structure qui connecte les éléments dans la liste.

La macro LIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro LIST_FOREACH parcourt la liste référencée par hea

LIST

Une liste est dirigée par une structure définie par la macro LIST_HEAD. La macro LIST_ENTRY déclare une structure qui relie les éléments dans la liste. Les éléments sont doublement liés de sorte qu'un élément arbitraire puisse être supprimé sans parcourir la liste. Les nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un élément existant ou en tête de la liste. Une structure LIST_HEAD est déclarée comme suit:

LIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir et TYPE est le type des éléments à relier dans la liste. Un pointeur vers la tête de la liste peut être déclaré plus tard comme suit:

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro LIST_HEAD_INITIALIZER évalue à un initialiseur pour la liste head.

La macro LIST_EMPTY évalue à vrai s'il n'y a pas d'éléments dans la liste.

La macro LIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro LIST_FOREACH parcourt la liste référencée par head dans la direction avant, assignant chaque élément tour à tour à var.

La macro LIST_FOREACH_FROM se comporte identiquement à LIST_FOREACH lorsque var est NULL, sinon elle traite var comme un élément de LIST précédemment trouvé et commence la boucle à var au lieu du premier élément de la LIST référencée par head.

La macro LIST_FOREACH_SAFE parcourt la liste référencée par head dans la direction avant, assignant chaque élément tour à tour à var. Cependant, contrairement à LIST_FOREACH(), ici il est permis de supprimer var ainsi que de le libérer depuis la boucle en toute sécurité sans interférer avec le parcours.

La macro LIST_FOREACH_FROM_SAFE se comporte identiquement à LIST_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément de LIST précédemment trouvé et commence la boucle à var au lieu du premier élément de la LIST référencée par head.

La macro LIST_INIT initialise la liste référencée par head.

La macro LIST_INSERT_HEAD insère le nouvel élément elm en tête de la liste.

La macro LIST_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro LIST_INSERT_BEFORE insère le nouvel élément elm avant l'élément listelm.

La macro LIST_NEXT renvoie l'élément suivant dans la liste, ou NULL s'il s'agit du dernier.

La macro LIST_PREV renvoie l'élément précédent dans la liste, ou NULL s'il s'agit du premier. La liste head doit contenir l'élément elm.

La macro LIST_REMOVE supprime l'élément elm de la liste.

La macro LIST_SWAP échange le contenu de head1 et head2.

TAIL QUEUES

Une file de queue est dirigée par une structure définie par la macro TAILQ_HEAD. Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file de queue et l'autre vers le dernier élément de la file de queue. Les éléments sont doublement liés de sorte qu'un élément arbitraire puisse être supprimé sans parcourir la file de queue. Les nouveaux éléments peuvent être ajoutés à la file de queue après un élément existant, avant un élément existant, en tête de la file de queue ou à la fin de la file de queue. Une structure TAILQ_HEAD est déclarée comme suit:

TAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à relier dans la file de queue. Un pointeur vers la tête de la file de queue peut être déclaré plus tard comme suit:

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro TAILQ_HEAD_INITIALIZER évalue à un initialiseur pour la file de queue head.

La macro TAILQ_CONCAT concatène la file de queue dirigée par head2 à la fin de celle dirigée par head1, en supprimant toutes les entrées de la première.

La macro TAILQ_EMPTY évalue à vrai s'il n'y a pas d'éléments dans la file de queue.

La macro TAILQ_ENTRY déclare une structure qui relie les éléments dans la file de queue.

La macro TAILQ_FIRST renvoie le premier élément de la file de queue ou NULL si la file de queue est vide.

La macro TAILQ_FOREACH parcourt la file de queue référencée par head dans la direction avant, assignant chaque élément tour à tour à var. var est défini à NULL si la boucle se termine normalement, ou s'il n'y avait aucun élément.

La macro TAILQ_FOREACH_FROM se comporte identiquement à TAILQ_FOREACH lorsque var est NULL, sinon elle traite var comme un élément de TAILQ précédemment trouvé et commence la boucle à var au lieu du premier élément de la TAILQ référencée par head.

La macro TAILQ_FOREACH_REVERSE parcourt la file de queue référencée par head dans la direction inverse, assignant chaque élément tour à tour à var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporte identiquement à TAILQ_FOREACH_REVERSE lorsque var est NULL, sinon elle traite var comme un élément de TAILQ précédemment trouvé et commence la boucle inverse à var au lieu du dernier élément de la TAILQ référencée par head.

Les macros TAILQ_FOREACH_SAFE et TAILQ_FOREACH_REVERSE_SAFE parcourent la liste référencée par head dans la direction avant ou arrière respectivement, assignant chaque élément tour à tour à var. Cependant, contrairement à leurs homologues non sécurisés, TAILQ_FOREACH et TAILQ_FOREACH_REVERSE permettent de supprimer var ainsi que de le libérer depuis la boucle en toute sécurité sans interférer avec le parcours.

La macro TAILQ_FOREACH_FROM_SAFE se comporte identiquement à TAILQ_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément de TAILQ précédemment trouvé et commence la boucle à var au lieu du premier élément de la TAILQ référencée par head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporte identiquement à TAILQ_FOREACH_REVERSE_SAFE lorsque var est NULL, sinon elle traite var comme un élément de TAILQ précédemment trouvé et commence la boucle inverse à var au lieu du dernier élément de la TAILQ référencée par head.

La macro TAILQ_INIT initialise la file de queue référencée par head.

La macro TAILQ_INSERT_HEAD insère le nouvel élément elm en tête de la file de queue.

La macro TAILQ_INSERT_TAIL insère le nouvel élément elm à la fin de la file de queue.

La macro TAILQ_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro TAILQ_INSERT_BEFORE insère le nouvel élément elm avant l'élément listelm.

La macro TAILQ_LAST renvoie le dernier élément de la file de queue. Si la file de queue est vide, la valeur renvoyée est NULL.

La macro TAILQ_NEXT renvoie l'élément suivant de la file de queue, ou NULL si cet élément est le dernier.

La macro TAILQ_PREV renvoie l'élément précédent de la file de queue, ou NULL si cet élément est le premier.

La macro TAILQ_REMOVE supprime l'élément elm de la file de queue.

La macro TAILQ_SWAP échange le contenu de head1 et head2.

NOM

queue(3)

BIBLIOTHÈQUE

libbsd

SYNOPSIS

#include <stdio.h> queue(void *ptr); queue(void *ptr, int len); queue(void *ptr, int len, int type); queue(void *ptr, int len, int type, int flags); queue(void *ptr, int len, int type, int flags, int prio);

DESCRIPTION

Les fonctions queue fournissent un moyen de gérer une file d'éléments de manière plus efficace que les fonctions list standard. Ces fonctions sont particulièrement utiles dans les scénarios où la file doit être accédée ou modifiée d'une manière qui n'est pas prise en charge par les fonctions list.

LISTES SIMPLEMENT CHAÎNÉES

Les fonctions queue prennent en charge la gestion d'une liste simplement chaînée. Chaque élément de la liste est représenté par une struct qui contient un seul pointeur vers l'élément suivant de la liste. Cela permet des opérations d'insertion et de suppression efficaces en tête de liste.

EXEMPLE DE LISTE SIMPLEMENT CHAÎNÉE

L'exemple suivant démontre l'utilisation des fonctions queue pour gérer une liste simplement chaînée :

struct node {
    void *data;
    struct node *next;
};

int main() {
    struct node *n1 = malloc(sizeof(struct node));
    struct node *n2 = malloc(sizeof(struct node));

    n1->data = "Hello";
    n2->data = "World";

    // Ajouter n2 au début de la liste
    queue(n2, 5, 0);

    // Ajouter n1 au début de la liste
    queue(n1, 5, 0);

    // Afficher la liste
    while (n1) {
        printf("%s\n", n1->data);
        n1 = n1->next;
    }

    // Libérer la mémoire
    free(n1);
    free(n2);
    return 0;
}

DIAGNOSTICS

Lors du débogage de queue(3), il peut être utile de tracer les modifications de la file. Pour activer le traçage, définissez la macro QUEUE_MACRO_DEBUG_TRACE au moment de la compilation.

Il peut également être utile de "corrompre" les pointeurs qui ont été désolidarisés d'une file, afin de détecter leur utilisation après leur suppression. Pour activer la corruption des pointeurs, définissez la macro QUEUE_MACRO_DEBUG_TRASH au moment de la compilation. La macro QMD_IS_TRASHED(void *ptr) renvoie vrai si ptr a été corrompu par l'option QUEUE_MACRO_DEBUG_TRASH.
