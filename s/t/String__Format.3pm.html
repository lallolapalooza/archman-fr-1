NOM

String::Format - Capacités de formatage de chaînes similaires à sprintf avec des définitions de format arbitraires

ABSTRAIT

String::Format permet des capacités de formatage de style sprintf avec des définitions de format arbitraires

SYNOPSIS

use String::Format;
my %fruit = (
      'a' => "pommes",
      'b' => "bananes",
      'g' => "pamplemousses",
      'm' => "melons",
      'w' => "pastèques",
);
my $format = "J'aime les %a, les %b, et les %g, mais pas les %m ni les %w.";
print stringf($format, %fruit);

# affiche :
# J'aime les pommes, les bananes, et les pamplemousses, mais pas les melons ni les pastèques.

DESCRIPTION

String::Format vous permet de définir des séquences de format arbitraires de type printf à développer. Ce module serait particulièrement utile dans les fichiers de configuration et les outils de génération de rapports, où les résultats d'une requête doivent être formatés d'une manière particulière. Il s'est inspiré du directive index_format et associées de mutt (voir <URL:http://www.mutt.org/doc/manual/manual-6.html#index_format>).

FONCTIONS

stringf

String::Format exporte une seule fonction appelée stringf. stringf prend deux arguments : une chaîne de format (voir CHAÎNES DE FORMAT, ci-dessous) et une référence à un hash de paires clé => valeur. Ces paires clé => valeur sont celles qui seront développées dans la chaîne de format.

CHAÎNES DE FORMAT

Les chaînes de format doivent correspondre à l'expression régulière suivante :

qr/
   (%             # '%' de début
    (-)?          # aligner à gauche, plutôt qu'à droite
    (\d*)?        # (optionnel) largeur minimale du champ
    (?:\.(\d*))?  # (optionnel) largeur maximale du champ
    ({.*?})?      # (optionnel) contenu à l'intérieur
    (\S)          # caractère de format réel
   )/x;

Si le caractère d'échappement spécifié n'existe pas dans %args, alors la chaîne d'origine est utilisée. Les options d'alignement, de largeur minimale et de largeur maximale fonctionnent identiquement à la manière dont elles sont définies dans sprintf(3) (toute variation est un bug et devrait être signalée).

Notez que la définition de sprintf de Perl est un peu plus libérale que l'expression régulière ci-dessus ; les déviations étaient intentionnelles, et concernent toutes le formatage numérique (les préfixes #, 0 et + ont été spécifiquement omis).

La valeur attachée à la clé peut être une valeur scalaire ou une référence de sous-routine ; s'il s'agit d'une référence de sous-routine, alors tout ce qui se trouve entre '{' et '}' ( $5 dans l'expression régulière ci-dessus) sera passé comme $_[0] à la référence de sous-routine. Cela permet des entrées comme celle-ci :

%args = (
    d => sub { POSIX::strftime($_[0], localtime) },
);

Qui peut être appelée avec cette chaîne de format :

"Il est %{%M:%S}d maintenant, le %{%A, %B %e}d."

Et résulterait (par exemple) :

Il est 17:45 maintenant, le Lundi, Février 4.

Notez que, étant donné que la chaîne est passée intacte à la référence de sous-routine, et que strftime ferait le travail attendu avec ces données, la chaîne de format ci-dessus pourrait être écrite comme :

"Il est %{%M:%S maintenant, le %A, %B %e}d."

Par défaut, les formats 'n', 't', et '%' sont définis comme une nouvelle ligne, une tabulation et '%', respectivement, s'ils ne sont pas déjà définis dans le hashref d'arguments qui lui est passé. Nous pouvons donc ajouter des retours chariot simplement :

"Il est %{%M:%S maintenant, le %A, %B %e}d.%n"

En raison de la façon dont la chaîne est analysée, les "\n" et "\t" normaux deviennent deux caractères chacun, et ne sont pas traités comme une nouvelle ligne et une tabulation. Ceci est un bug.

MÉTHODE FABRIQUE

String::Format supporte également une méthode de classe, nommée stringfactory, qui retournera une référence vers une sous-routine "amorcée". stringfactory doit recevoir une référence à un hash de valeurs ; la sous-routine retournée utilisera ces valeurs comme hash %args.

my $self = Some::Groovy::Package->new($$, $<, $^T);
my %formats = (
      'i' => sub { $self->id      },
      'd' => sub { $self->date    },
      's' => sub { $self->subject },
      'b' => sub { $self->body    },
);
my $index_format = String::Format->stringfactory(\%formats);
print $index_format->($format1);
print $index_format->($format2);

Cette référence de sous-routine peut être assignée à une entrée de table de symboles locale, et appelée normalement, bien sûr :

*reformat = String::Format->stringfactory(\%formats);
my $reformed = reformat($format_string);
