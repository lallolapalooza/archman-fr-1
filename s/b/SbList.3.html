Description détaillée

template<typename Type>

class SbList< Type >"La classe SbList est une classe conteneur générique pour les listes.

SbList est une extension de la bibliothèque Coin par rapport à l'API originale d'Open Inventor. Open Inventor gère la plupart des classes de listes en héritant de la classe SbPList, qui contient un tableau de pointeurs génériques de type void*. En utilisant cette classe basée sur des modèles à la place, nous pouvons partager plus de code et rendre le code de gestion des listes plus sûr en termes de types.

Un soin particulier a été apporté pour s'assurer que les classes de liste qui font partie de l'API Open Inventor restent compatibles avec leurs interfaces d'origine, telles qu'elles sont dérivées de la classe de base SbPList. Mais si vous rencontrez encore des problèmes lors du portage de vos applications Open Inventor, faites-le nous savoir et nous ferons de notre mieux pour les résoudre.

Une caractéristique de cette classe est que les tableaux d'objets de liste grandissent dynamiquement lorsque vous append() plus d'éléments à la liste. La technique de croissance réelle utilisée consiste à doubler la taille de la liste lorsqu'elle devient trop petite.

Il existe également d'autres méthodes utilitaires liées aux tableaux ; par exemple, trouver les index d'éléments, insérer des éléments à n'importe quelle position, supprimer des éléments (et réduire le tableau), copier des tableaux, etc.

template<typename Type> SbList< Type >::SbList (const int sizehint = DEFAULTSIZE) [inline]

Constructeur par défaut.

L'argument sizehint indique le nombre d'éléments que la liste contiendra, de sorte que l'allocation de mémoire puisse être effectuée efficacement.

Note importante : spécifier explicitement une valeur pour sizehint ne signifie *pas* que la liste contiendra initialement ce nombre de valeurs. Après la construction, la liste ne contiendra aucun élément, tout comme pour le constructeur par défaut. Voici un bon exemple de la façon de vous causer des bugs difficiles à trouver :

SbList<SbBool> flags(2); // Supposons que nous n'ayons besoin que de 2 éléments. Notez
                         // que la liste ne contient toujours pas d'éléments.
flags[0] = TRUE;         // Aïe. La liste ne contient toujours pas d'éléments.

Étant donné que ce malentendu conceptuel est si facile à commettre, vous feriez probablement mieux (ou du moins plus sûrement) de laisser l'argument sizehint à sa valeur par défaut en ne le spécifiant pas explicitement.

Cela améliore les performances si vous connaissez la taille totale approximative de la liste à l'avance avant d'ajouter des éléments à la liste, car le nombre de réallocations sera minimisé.

Detailed Description

The SbList class template is a dynamic array-like class. It is capable of growing and shrinking as needed. The elements are stored contiguously in memory, so it behaves much like a C++ array.

The SbList class can be used like a stack by using the push() and pop() methods.

Note: The SbList class uses C++ exception handling. If you compile your application with –fno-exceptions (GCC), SbList will not work. You can work around this by defining the macro COIN_NO_EXCEPTION.
