Description détaillée

La classe SbColor4f contient les composantes rouge, vert, bleu et alpha qui forment une valeur de couleur.

Cette classe est utilisée en interne dans d'autres classes Coin. Elle contient un vecteur à 4 composantes comme position dans le cube RVB avec une valeur de transparence supplémentaire.

Les valeurs rouge, vert et bleu doivent être comprises entre 0.0 et 1.0, où 0.0 représente la plus faible intensité et 1.0 la plus élevée. La valeur de transparence doit également être comprise entre 0.0 et 1.0.

SbColor4f contient des méthodes pour gérer facilement la configuration et la lecture des valeurs de couleur sous forme de valeurs 32 bits compressées ou sous forme HSV.

Note : cette classe ne fait pas partie d'Open Inventor, mais constitue une extension de l'API. Ne l'utilisez pas si vous souhaitez que votre code soit compatible avec Open Inventor.
