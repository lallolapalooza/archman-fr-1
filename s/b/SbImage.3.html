void SbImage::setValue (const SbVec3s & size, const int bytesperpixel, const unsigned char * bytes)

Définit l'image à la taille size et bytesperpixel. Si bytes != NULL, les données sont copiées depuis bytes dans les données de l'image de cette classe. Si bytes == NULL, les données de l'image ne sont pas initialisées.

Les données de l'image seront toujours allouées par multiples de quatre. Cela signifie que si vous définissez une image avec size == (1,1,1) et bytesperpixel == 1, quatre octets seront alloués pour contenir les données. Ceci est principalement fait pour simplifier le code d'exportation dans SoSFImage et normalement vous n'aurez pas à vous soucier de cette caractéristique.

Si la profondeur de l'image (size[2]) est zéro, l'image est considérée comme une image 2D.

SbBool SbImage::readFile (const SbString & filename, const SbString *const * searchdirectories = NULL, const int numdirectories = 0)

Lit les données de l'image depuis filename. Dans Coin, simage est utilisé pour charger les fichiers images, et plusieurs formats de fichiers courants sont supportés. simage peut être téléchargé depuis nos pages web. Si le chargement échoue pour une raison quelconque, cette méthode retourne FALSE, et l'instance est définie comme une image vide. Si le fichier est chargé avec succès, les données de l'image du fichier sont copiées dans cette classe.

Si numdirectories > 0, cette méthode recherchera filename dans tous les répertoires spécifiés dans searchdirectories.

void SbImage::addReadImageCB (SbImageReadImageCB * cb, void * closure) [static]

Add a callback which will be called whenever Coin wants to read an image file. The callback should return TRUE if it was able to successfully read and set the image data, and FALSE otherwise.

The callback(s) will be called before attempting to use simage to load images.

SbString SbImage::searchForFile (const SbString & basename, const SbString *const * dirlist, const int numdirs) [static]

Given a basename for a file and and array of directories to search (in dirlist, of length numdirs), returns the full name of the file found.

In addition to looking at the root of each directory in dirlist, we also look into the subdirectories texture/, textures/, images/, pics/ and pictures/ of each dirlist directory.

If no file matching basename could be found, returns an empty string.
