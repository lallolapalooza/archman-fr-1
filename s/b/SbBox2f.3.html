Description détaillée

La classe SbBox2f est une boîte 2D avec des coordonnées flottantes pour les coins.

Cette classe de boîte est utilisée par de nombreuses autres classes dans Coin pour l'échange et le stockage de données. Elle fournit deux coins de boîte avec des coordonnées flottantes, ce qui est utile entre autres pour représenter les dimensions de l'écran ou de la toile dans des coordonnées normalisées.
