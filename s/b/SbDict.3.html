Description détaillée

La classe SbDict organise un dictionnaire de clés et de valeurs.

Elle utilise le hachage pour insérer et trouver rapidement les entrées dans le dictionnaire. Une entrée consiste en une clé unique et un pointeur générique.

SbDict::SbDict (const int entries = 251)

Constructeur avec entries spécifiant le nombre initial de buckets dans la liste de hachage -- il doit donc être supérieur à 0. Mis à part cela, aucun soin particulier ne doit être pris pour choisir la valeur puisqu'elle est toujours arrondie à la puissance de deux supérieure.

void SbDict::clear (void )

Efface toutes les entrées du dictionnaire.

SbBool SbDict::enter (const Key key, void *const value)

Insère une nouvelle entrée dans le dictionnaire. key doit être un nombre unique, et value sont les données utilisateur génériques.

Si key n'existe pas dans le dictionnaire, une nouvelle entrée est créée et TRUE est retourné. Sinon, les données utilisateur génériques sont modifiées pour devenir value, et FALSE est retourné.

SbBool SbDict::find (const Key key, void *& value) const

Recherche key dans le dictionnaire. Si une entrée avec cette clé existe, TRUE est retourné et la valeur de l'entrée est retournée dans value. Sinon, FALSE est retourné.

void SbDict::makePList (SbPList & keys, SbPList & values)

Crée des listes avec toutes les entrées du dictionnaire.

SbBool SbDict::remove (const Key key)

Supprime l'entrée avec la clé key. TRUE est retourné si une entrée avec cette clé était présente, FALSE sinon.

void SbDict::setHashingFunction (SbDictHashingFunc * func)

Définit une nouvelle fonction de hachage pour ce dictionnaire. La fonction de hachage par défaut retourne simplement la clé.

Si vous trouvez que les éléments entrés dans le dictionnaire semblent créer des clusters dans seulement quelques buckets, vous devriez essayer de définir une fonction de hachage. Si vous utilisez par exemple des chaînes, vous pourriez utiliser la fonction statique SbString::hash() (vous devriez créer une fonction statique qui effectue le cast de SbDict::Key vers char * bien sûr).

Cette fonction ne fait pas partie de l'API OIV.
