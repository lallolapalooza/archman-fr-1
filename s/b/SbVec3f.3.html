Description détaillée

La classe SbVec3f est un vecteur à 3 dimensions avec des coordonnées en virgule flottante.

Cette classe de vecteur est utilisée par de nombreuses autres classes dans Coin. Elle fournit le stockage pour un vecteur à 3 dimensions ainsi que des opérations arithmétiques simples en virgule flottante.

Voir aussi

SbVec2s, SbVec2f, SbVec2d, SbVec3s, SbVec3d, SbVec4f, SbVec4d.

float SbVec3f::normalize (void )

Normalise le vecteur à une longueur unitaire. La valeur renvoyée est la longueur originale du vecteur avant la normalisation.

Si le vecteur est nul, aucune tentative de normalisation ne sera effectuée. Si la bibliothèque Coin a été compilée en mode débogage et que l'environnement de débogage COIN_DEBUG_NORMALIZE est défini, un message d'avertissement sera affiché :

  Coin warning in SbVec3f::normalize(): The length of the vector should be > 0.0f to be able to normalize.

Nous avons rendu Coin capable d'afficher un avertissement lorsqu'une tentative de normalisation d'un vecteur nul est effectuée, car cela semble être le symptôme d'une erreur plus grave quelque part dans le code de Coin, telle qu'une erreur interne, un bug dans le code d'application ou un défaut dans un fichier d'entrée (comme des spécifications de polygones invalides, par exemple).

Si vous rencontrez des bugs ou des problèmes avec votre application ou avec Coin, il peut être judicieux de définir COIN_DEBUG_NORMALIZE=1 et de redémarrer l'application pour voir si vous recevez des avertissements de normalize().

Si cela se produit, vous devriez exécuter l'application dans un débogueur et observer la trace de la pile lorsque l'emplacement de l'avertissement est atteint. Une façon simple d'obtenir un point d'arrêt à l'emplacement de l'avertissement est de définir la variable d'environnement de débogage suivante, qui fera un assert :

  COIN_DEBUG_BREAK="SbVec3f::normalize"

Si vous suspectez fortement un bug interne dans Coin, veuillez signaler la trace à coin-support@coin3d.org et nous enquêterons. L'exemple de code qui déclenche le bug serait également très utile.

Un avertissement pour les développeurs qui portent du code SGI ou TGS Inventor vers Coin : les implémentations d'Inventor sont plus souples dans la détection et l'émission d'avertissements lors de l'utilisation d'APIs incorrectes, et vous pourriez recevoir cet avertissement sans voir aucune indication d'erreur avec SGI/TGS Inventor. Cela ne signifie pas nécessairement qu'il y a un bug dans Coin — il est plus probable que vous receviez un avertissement comme indicateur d'une mauvaise utilisation de l'API ou d'erreurs dans des fichiers d'importation qui n'ont tout simplement pas été détectées ou signalées par ces implémentations d'Inventor.
