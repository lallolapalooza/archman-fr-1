Description détaillée

La classe SbCylinder est une représentation d'un cylindre.

Cette classe est utilisée dans d'autres classes de Coin. Elle contient des données pour représenter un cylindre par un axe et un rayon. Le cylindre n'a pas de valeur de longueur/hauteur, ce qui signifie qu'il est traité comme de longueur infinie.

SbBool SbCylinder::intersect (const SbLine & l, SbVec3f & intersection) const

Trouve le point d'intersection du rayon l avec le cylindre où le rayon entre, et retourne ce point dans intersection.

Si le rayon n'intersecte pas le cylindre, FALSE est retourné, sinon nous retournerons TRUE.

SbBool SbCylinder::intersect (const SbLine & l, SbVec3f & enter, SbVec3f & exit) const

Trouve les points d'intersection du rayon l avec le cylindre et retourne ces points dans enter et exit. Si le rayon ne fait que "frôler" le cylindre, les points enter et exit ont des valeurs égales.

Si le rayon n'intersecte pas le cylindre, FALSE est retourné, sinon nous retournerons TRUE.
