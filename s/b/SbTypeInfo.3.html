Description détaillée

une bibliothèque d'informations de type pour les types Coin et leurs relations.

SbTypeInfo<> permet d'écrire du code générique utilisant les types Coin qui est capable de s'ajuster aux types de paramètres utilisés. Habituellement, vous pourriez y parvenir assez facilement si les Sb-classes étaient des classes de modèles avec des arguments de Type et de Dimension. Cette bibliothèque de types permet de contourner ce manque de généricité en recherchant les relations de types.

Certains types internes de SbTypeInfo<> sont toujours définis. D'autres ne seront définis que si le type d'argument du modèle a certaines caractéristiques.

Type est le type pour lequel la spécialisation SbTypeInfo<> est faite. Il est toujours défini.

ParamType est un type considéré comme efficace pour le transfert de paramètres de fonction. Il est toujours défini.
