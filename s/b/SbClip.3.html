Description détaillée

La classe SbClip est une classe générique de découpe de polygones.

Elle est utilisée en ajoutant d'abord tous les sommets du polygone, puis en découpant par rapport à n'importe quel nombre de plans. Si vous avez besoin de fournir des informations supplémentaires par sommet (par exemple, des coordonnées de texture), vous devez fournir une fonction de rappel (callback) dans le constructeur, et un pointeur vers votre structure de sommet dans addVertex(). Pour chaque nouveau sommet créé, la fonction de rappel est appelée avec la ligne en cours de découpe, y compris les pointeurs vers vos structures de sommet et la position du nouveau sommet (découpé par rapport à un plan donné). Vous devriez alors créer une nouvelle structure de sommet, calculer vos données (par exemple, une nouvelle coordonnée de texture) et retourner un pointeur vers cette structure.

Veuillez noter que cette classe est une extension pour Coin et qu'elle n'est pas disponible dans l'API originale SGI Open Inventor v2.1.

void SbClip::reset (void )

Réinitialise le découpeur. Ceci doit être appelé avant d'ajouter des sommets lorsque l'on réutilise une instance de SbClip.

void SbClip::clip (const SbPlane & plane)

Découpe le polygone par rapport au plane. Cela peut modifier le nombre de sommets dans le polygone. Pour chaque nouveau sommet créé, la fonction de rappel fournie dans le constructeur (si != NULL) est appelée avec la ligne en cours de découpe et le nouveau sommet calculé. La fonction de rappel doit retourner un nouveau pointeur void à stocker par le découpeur.
