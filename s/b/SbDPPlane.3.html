Description détaillée

La classe SbDPPlane représente un plan dans l'espace 3D.

SbDPPlane est utilisé par de nombreuses autres classes dans Coin. Il offre un moyen de représenter un plan, spécifié par un vecteur normal du plan et une distance par rapport à l'origine du système de coordonnées.

Notez que cette classe est une extension pour Coin et n'est pas disponible dans l'API d'origine SGI Open Inventor v2.1.

Depuis

Coin 2.0

Crée une instance de SbDPPlane avec un vecteur normal pointant dans la direction donnée et la distance la plus courte de l'origine du système de coordonnées à un point sur le plan.

Crée une instance de SbDPPlane à partir de trois points situés sur le plan. Assurez-vous que p0, p1 et p2 sont réellement trois points distincts lorsque vous utilisez ce constructeur.

SbDPPlane::SbDPPlane (const SbVec3d & normalref, const SbVec3d & point)

Crée une instance de SbDPPlane à partir d'un vecteur normal et d'un point situés sur le plan.

normal doit être un vecteur non nul.

Documentation des fonctions membres

void SbDPPlane::offset (const double d)

Ajoute le décalage donné d à la distance du plan par rapport à l'origine.

SbBool SbDPPlane::intersect (const SbDPLine & l, SbVec3d & intersection) const

Trouve le point sur la ligne l qui coupe le plan et renvoie ce point dans intersection. Renvoie TRUE s'il y a une intersection, et FALSE si la ligne est parallèle au plan.

Ne pas passer une ligne invalide pour le paramètre l (c'est-à-dire avec un vecteur direction nul).

Renvoie la distance du point au plan. Une valeur positive indique que le point se trouve dans le demi-espace du plan.
