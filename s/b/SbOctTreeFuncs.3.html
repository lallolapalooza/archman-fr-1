Description détaillée

La structure SbOctTreeFuncs est utilisée pour spécifier des fonctions de rappel pour travailler avec des éléments dans un SbOctTree.

La seule fonction pointeur qui *doit* être configurée est insideboxfunc. Les autres fonctions doivent être définies si vous avez l'intention d'utiliser les méthodes de recherche correspondantes dans SbOctTree.
