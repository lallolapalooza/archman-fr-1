Description Détaillée

La classe SbRotation représente une rotation dans l'espace 3D.

SbRotation est largement utilisé dans toute la bibliothèque Coin.

Une SbRotation est stockée en interne sous forme de quaternion pour des raisons de vitesse et de stockage, mais des requêtes peuvent être faites pour obtenir et définir les valeurs d'axe et d'angle pour plus de commodité.

Notez qu'il y a une erreur *très* courante et facile à commettre lors de la définition de la valeur d'une SbRotation, et c'est d'utiliser par inadvertance le mauvais constructeur SbRotation. Cet exemple devrait clarifier le problème :

SbRotation rotation(0, 0, 1, 1.5707963f);

Le programmeur essaie clairement de définir une rotation de PI/2 autour de l'axe Z, mais cela échouera, car le constructeur SbRotation invoqué ci-dessus est celui qui prend comme arguments les 4 flottants d'un quaternion. Ce que le programmeur voulait très probablement faire, c'est utiliser le constructeur SbRotation qui prend un vecteur de rotation et un angle de rotation, qui s'appelle comme ceci :

SbRotation rotation(SbVec3f(0, 0, 1), 1.5707963f);

Un autre problème courant est de définir la valeur de rotation à exactement 0,0, tout en voulant stocker uniquement les informations sur un angle de rotation : les rotations sont gérées en interne comme des quaternions, et lors de la conversion d'un angle et d'une valeur de rotation en une représentation quaternion, les informations sur l'angle "se perdent" s'il n'y a pas de rotation réelle.

SbRotation::SbRotation (void )

Le constructeur par défaut initialise simplement une rotation valide. La valeur réelle n'est pas spécifiée, et vous ne devriez pas vous y fier.

SbRotation::SbRotation (const float q[4])

Construit un nouvel objet SbRotation initialisé avec les composantes de quaternion données.

Le tableau doit être ordonné comme suit :

q[0] = x, q[1] = y, q[2] = z et q[3] = w, où le quaternion est spécifié par q = w + xi + yj + zk.

SbRotation::SbRotation (const float q0, const float q1, const float q2, const float q3)

Construit un nouvel objet SbRotation initialisé avec les composantes de quaternion données.

SbRotation::SbRotation (const SbMatrix & m)

Construit un nouvel objet SbRotation initialisé avec la matrice de rotation donnée.

SbRotation::SbRotation (const SbVec3f & rotateFrom, const SbVec3f & rotateTo)

Construit une rotation qui est la rotation minimale nécessaire pour que le vecteur rotateFrom pointe dans la direction du vecteur rotateTo.

Exemple :

#include <Inventor/SbRotation.h>
#include <Inventor/SbVec3f.h>
#include <cstdio>
int
main(void)
{
  SbVec3f from(10, 0, 0);
  SbVec3f to(0, 10, 0);
  SbRotation rot(from, to);
  SbVec3f axis;
  float angle;
  rot.getValue(axis, angle);
  axis.print(stdout);
  printf("  angle==%f\n", angle);
  return 0;
}
