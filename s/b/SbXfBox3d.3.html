Description détaillée

La classe SbXfBox3d est un cube tridimensionnel avec des coordonnées double précision et une transformation jointe.

Elle stocke deux coins d'un cube avec des coordonnées double précision et une matrice de transformation double précision 4x4.

void SbXfBox3d::extendBy (const SbBox3d & bb)

Ajuste les limites du cube avec le cube bb donné. Le cube donné est supposé être dans l'espace transformé.

Les deux cubes donnés seront combinés de telle sorte que le cube résultant ait le plus petit volume possible. Pour y parvenir, la transformation de ce SbXfBox3f peut être simplifiée avant d'être combinée avec bb.

void SbXfBox3d::extendBy (const SbXfBox3d & bb)

Ajuste les limites du cube avec le cube bb donné.

Le cube donné est supposé être dans l'espace transformé.

Note : Ne garantit pas un résultat optimal lors de l'utilisation pour le calcul d'une boîte englobante, car la matrice de transformation pourrait changer. Voir la documentation de SoGetBoundingBoxAction pour plus de détails.
