Description détaillée

La classe SbVec2f est un vecteur à 2 dimensions avec des coordonnées flottantes.

Cette classe de vecteur est utilisée par de nombreuses autres classes dans Coin. Elle fournit le stockage pour un vecteur à 2 dimensions ainsi que des opérations arithmétiques flottantes simples sur ce vecteur.

Voir aussi

SbVec2s, SbVec2d, SbVec3s, SbVec3f, SbVec3d, SbVec4f, SbVec4d.
