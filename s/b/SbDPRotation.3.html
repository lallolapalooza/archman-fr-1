Description Détaillée

La classe SbDPRotation représente une rotation dans l'espace 3D en utilisant des données de double précision.

SbDPRotation est largement utilisé dans la bibliothèque Coin.

Une SbDPRotation est stockée en interne sous forme de quaternion pour des raisons de vitesse et de stockage, mais des requêtes peuvent être effectuées pour obtenir et définir les valeurs de l'axe et de l'angle pour plus de commodité.

Detailed Description

This class implements the rotation data type based on quaternions.

When you want to represent rotations, you should use this class rather than the SbRotation class. The reason is that SbDPRotation uses double precision floating point numbers for its internal representation, while SbRotation uses single precision. This implies that SbDPRotation provides more accurate results, especially when interpolating between rotations (e.g. using slerp()).

The Coin library handles rotations internally using the SbQuaternion data type, but this class provides a more convenient interface.

SbDPRotation slerp (const SbDPRotation & rot0, const SbDPRotation & rot1, double t) [static]

Interpolates along the shortest path between the two rotation positions (from rot0 to rot1).

Returns the SbDPRotation which will rotate rot0 the given part t of the spherical distance towards rot1, where t=0 will yield rot0 and t=1 will yield rot1.

t should be in the interval [0, 1].
