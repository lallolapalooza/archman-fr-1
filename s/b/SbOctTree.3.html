Description détaillée

La classe SbOctTree définit un octree générique pour des recherches géométriques rapides.

Sachez que cette classe est une extension pour Coin, et qu'elle n'est pas disponible dans l'API originale Open Inventor v2.1 de SGI.

void SbOctTree::findItems (const SbVec3f & pos, SbList< void * > & destarray, const SbBool removeduplicates = TRUE) const

Trouve tous les éléments qui contiennent le point pos. Les éléments sont retournés dans destarray.

Si removeduplicates est TRUE (par défaut), destarray ne contiendra pas d'éléments dupliqués. Ce n'est pas un processus optimisé, donc si vous recherchez la vitesse, vous devriez le définir sur FALSE et faire votre propre post-traitement du tableau d'éléments retournés.

Notez que si la bibliothèque Coin a été compilée en DLL sous Microsoft Windows et que vous utilisez cette méthode à partir du code de l'application, vous devez vous assurer que la DLL Coin et l'exécutable de l'application utilisent la même instance d'une bibliothèque C Run-Time (CRT). Sinon, vous subirez une corruption du tas de mémoire lors de la désallocation des instances retournées, conduisant éventuellement à des plantages mystérieux.
