Description détaillée

La classe SbTesselator est utilisée pour tesséler des polygones en triangles.

SbTesselator est utilisé dans Coin pour diviser des polygones en triangles. Il gère les polygones concaves, effectue une triangulation de Delaunay et évite de générer des triangles qui s'auto-intersectent.

Voici un exemple simple montrant comment tesséler un quad avec les coins en <0, 0, 0>, <1, 0, 0>, <1, 1, 0> et <0, 1, 0>.

// Fonction de rappel pour le tessellateur. Appelée une fois pour chaque
// triangle généré avec les sommets.
static void
tess_cb(void * v0, void * v1, void * v2, void * cbdata)
{
  SbVec3f * vtx0 = (SbVec3f *)v0;
  SbVec3f * vtx1 = (SbVec3f *)v1;
  SbVec3f * vtx2 = (SbVec3f *)v2;
  (void) fprintf(stdout, "triangle: <%f, %f, %f> <%f, %f, %f> <%f, %f, %f>\n",
    (*vtx0)[0], (*vtx0)[1], (*vtx0)[2],
    (*vtx1)[0], (*vtx1)[1], (*vtx1)[2],
    (*vtx2)[0], (*vtx2)[1], (*vtx2)[2]);
  // Faire des choses avec le triangle ici.
}
static SbVec3f vertices[] = {
  SbVec3f(1, 0, 0), SbVec3f(1, 1, 0),
  SbVec3f(0, 1, 0), SbVec3f(0, 0, 0)
};
SbTesselator mytessellator(tess_cb, NULL);
mytessellator.beginPolygon();
for (int i=0; i < 4; i++) {
  mytessellator.addVertex(vertices[i], &vertices[i]);
}
mytessellator.endPolygon();

L'appel à SbTesselator::endPolygon() déclenche le SbTesselator pour qu'il se mette au travail, en appelant la fonction tess_cb() pour chaque triangle qu'il génère.

La raison pour laquelle nous utilisons 2 arguments à SbTesselator::addVertex() et passons des pointeurs void pour les sommets à la fonction de rappel est de rendre possible la gestion de structures plus complexes que les simples coordonnées (comme dans l'exemple ci-dessus), telles que des informations de matériaux, des informations d'éclairage ou tout autre attribut que vos sommets pourraient avoir.

Cette classe ne fait pas partie de l'API originale d'Open Inventor.

Une autre option pour tesséler des polygones est le tessellateur de la bibliothèque GLU. Il possède certaines fonctionnalités qui ne font pas partie de SbTesselator (comme la gestion des coques), mais la bibliothèque GLU est connue pour avoir des bugs dans diverses implémentations et n'effectue pas de triangulation de Delaunay. Si vous préférez cependant utiliser le tessellateur GLU plutôt que celui-ci, cela peut être forcé en définissant une variable d'environnement :

(void) coin_setenv("COIN_PREFER_GLU_TESSELLATOR", "1", 1);

Documentation du constructeur et du destructeur

SbTesselator::SbTesselator (SbTesselatorCB * func = NULL, void * data = NULL)

Initialise un tessellateur. L'argument callback spécifie une fonction qui sera appelée pour chaque triangle retourné par le tessellateur. La fonction de rappel recevra trois pointeurs vers chaque sommet et le pointeur userdata. Les pointeurs de sommet sont spécifiés dans la méthode SbTesselator::addVertex().

Documentation des fonctions membres

void SbTesselator::beginPolygon (SbBool keepVerts = FALSE, const SbVec3f & normal = SbVec3f(0.0f, 0.0f, 0.0f))

Initialise un nouveau polygone.

Vous pouvez définir explicitement la normale du polygone si vous la connaissez. Sinon, elle sera calculée en interne.

Si keepVerts est TRUE, tous les sommets seront inclus dans les triangles retournés, même si cela peut entraîner des triangles sans aire.

void SbTesselator::addVertex (const SbVec3f & v, void * data)

Ajoute un nouveau sommet au polygone. data sera retourné comme un sommet dans la fonction de rappel.

void SbTesselator::endPolygon (void )

Indique au tessellateur de commencer la tessellation. La fonction de rappel spécifiée dans le constructeur (ou définie à l'aide de la méthode SbTesselator::setCallback()) sera appelée pour chaque triangle avant le retour.

void SbTesselator::setCallback (SbTesselatorCB * func, void * data)

Définit la fonction de rappel pour ce tessellateur.
