Description détaillée

La classe SbPlane représente un plan dans l'espace 3D.

SbPlane est utilisé par de nombreuses autres classes dans Coin. Il fournit un moyen de représenter un plan, spécifié par un vecteur normal et une distance par rapport à l'origine du système de coordonnées.

Documentation Constructeur & Destructeur

SbPlane::SbPlane (void)

Un SbPlane instancié avec le constructeur par défaut ne sera pas initialisé.

SbPlane::SbPlane (const SbVec3f & normalref, const float D)

Crée un SbPlane avec un vecteur normal pointant dans la direction donnée et la distance la plus courte à l'origine du système de coordonnées par rapport à un point sur le plan.

normal ne doit pas être un vecteur nul.

SbPlane::SbPlane (const SbVec3f & p0, const SbVec3f & p1, const SbVec3f & p2)

Crée un SbPlane à partir de trois points situés sur le plan. Assurez-vous que p0, p1 et p2 sont trois points distincts et non colinéaires.

SbPlane::SbPlane (const SbVec3f & normalref, const SbVec3f & point)

Crée un SbPlane à partir d'un vecteur normal et d'un point situé sur le plan.

normal ne doit pas être un vecteur nul.

Documentation des fonctions membres

void SbPlane::offset (const float d)

Ajoute le décalage donné d à la distance du plan par rapport à l'origine.

SbBool SbPlane::intersect (const SbLine & l, SbVec3f & intersection) const

Trouve le point sur la ligne l qui intersecte le plan et le retourne dans intersection. Si la ligne est parallèle au plan, nous retournons FALSE, sinon TRUE.

Il ne faut pas passer une ligne invalide pour le paramètre l (c'est-à-dire avec un vecteur directeur nul).

void SbPlane::transform (const SbMatrix & matrix)

Transforme le plan par matrix.

SbBool SbPlane::isInHalfSpace (const SbVec3f & point) const

Vérifie si le point donné se trouve dans le demi-espace du plan dans lequel pointe le vecteur normal du plan.

float SbPlane::getDistance (const SbVec3f & point) const

Retourne la distance du point point au plan. Une valeur positive indique que le point est dans le demi-espace du plan.

Cette méthode est une extension spécifique à Coin par rapport à l'API SGI Inventor d'origine.

const SbVec3f & SbPlane::getNormal (void ) const

Retourne le vecteur normal du plan, qui indique la direction dans laquelle le plan est orienté.

float SbPlane::getDistanceFromOrigin (void ) const

Retourne la distance entre l'origine du système de coordonnées et le point du plan le plus proche de l'origine.

void SbPlane::print (FILE * fp) const

Imprime l'état de cet objet dans le flux de fichier fp. Cela ne fonctionne que dans la version de débogage de la bibliothèque, et la méthode ne fait rien dans une version optimisée.

SbBool SbPlane::intersect (const SbPlane & pl, SbLine & line) const

Intersects ce plan avec pl, et retourne la ligne résultante dans line. Retourne TRUE si une ligne d'intersection peut être trouvée, et FALSE si les plans sont parallèles.

Note : La SbLine résultante doit être considérée comme une ligne qui intersecte la SbLine d'origine, s'étendant à l'infini dans les deux directions.

Cette fonction est une extension de Coin et n'est pas disponible dans l'API SGI Open Inventor v2.1 d'origine.
