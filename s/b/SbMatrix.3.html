Description détaillée

La classe SbMatrix représente une matrice 4x4.

SbMatrix est utilisée par de nombreuses autres classes dans Coin. Elle fournit le stockage d'une matrice 4x4 de valeurs flottantes de précision simple.

Par convention, les matrices dans Coin doivent être configurées en mode d'ordre des colonnes. C'est le même ordre qui est utilisé par exemple dans OpenGL, mais notez que certains livres de géométrie utilisent le mode opposé d'ordre des lignes, ce qui peut désorienter les nouveaux utilisateurs de l'API.

Une autre façon de penser aux matrices d'ordre des colonnes est qu'elles utilisent la multiplication en post-ordre : c'est-à-dire que pour concaténer une transformation d'une seconde matrice avec la matrice actuelle, vous devez multiplier sur le côté droit, c'est-à-dire avec la méthode SbMatrix::multRight().

Si vous avez une matrice en ordre de lignes provenant d'une autre source, elle peut être convertie en ordre de colonnes en la transposant avec SbMatrix::transpose(). Un exemple simple aidera à expliquer cela.

Avec des matrices en ordre de lignes, une matrice de transformation avec position, rotation et échelle ressemble à ceci :

M = T * R * S

Où T est la translation, R est la rotation et S est l'échelle. Ce que cela signifie, c'est que l'échelle est appliquée en premier. La matrice mise à l'échelle est ensuite tournée, et enfin la matrice mise à l'échelle et tournée est translatée. Lorsque des matrices en ordre de colonnes sont utilisées, comme dans Coin, elles sont représentées légèrement différemment ; l'ordre de multiplication est inversé :

M = S * R * T

La transformation est la même que celle de la matrice en ordre de lignes. La différence réside uniquement dans l'ordre de multiplication. Pour comprendre pourquoi il en est ainsi, considérez l'exemple de transformation :

M = T * R * S

Convertir M d'une matrice en ordre de lignes à une matrice en ordre de colonnes se fait comme suit :

M^t = (T * R * S)^t
M^t = ((T * R) * S)^t
M^t = S^t * (T * R)^t
M^t = S^t * R^t * T^t

Tout ce que vous avez à faire est de supprimer les symboles de transposée, et les matrices ont été converties en ordre de colonnes :

M = S * R * T

Ceci a été fait en utilisant la propriété que :

A^t = (B * C)^t = C^t * B^t

La conversion de l'ordre de colonnes à l'ordre de lignes se fait avec la même propriété.

Définit la translation, la rotation et la mise à l'échelle en une seule fois. La matrice résultante est calculée comme suit :

void SbMatrix::setTransform (const SbVec3f & t, const SbRotation & r, const SbVec3f & s, const SbRotation & so)

Définit la translation, la rotation et la mise à l'échelle en une seule fois avec une orientation de mise à l'échelle spécifiée. La matrice résultante est calculée comme suit :

M = Ro^-1 * S * Ro * R * T

où Ro est l'orientation de mise à l'échelle, et S, R et T sont des matrices de mise à l'échelle, de rotation et de translation.

Définit la translation, la rotation et la mise à l'échelle en une seule fois avec une orientation de mise à l'échelle et un point central spécifiés. La matrice résultante est calculée comme suit :

M = -Tc * Ro^-1 * S * Ro * R * T * Tc

où Tc est le point central, Ro est l'orientation de mise à l'échelle, et S, R et T sont des matrices de mise à l'échelle, de rotation et de translation.

void SbMatrix::LUBackSubstitution (int index[4], float b[4]) const

This function does a solve on the "Ax = b" system, given that the matrix is LU-decomposed in advance. First, a forward substitution is done on the lower system (Ly = b), and then a backwards substitution is done on the upper triangular system (Ux = y).

The index[] argument is the one returned from SbMatrix::LUDecomposition(), so see that function for an explanation.

The b[] argument must contain the b vector in "Ax = b" when calling the function. After the function has solved the system, the b[] vector contains the x vector.

BUGS: As is done by Open Inventor, unsolvable x values will not return NaN but 0.

void SbMatrix::multMatrixVec (const SbVec3f & src, SbVec3f & dst) const

Multiply src vector with this matrix and return the result in dst. Multiplication is done with the vector on the right side of the expression, i.e. dst = M * src.

(Be aware that it is more common to use the SbMatrix::multVecMatrix() operation, when doing vector transformations, as SbMatrix instances are by definition in column-order, and uses post-multiplication for common geometry operations.)

See also

multVecMatrix(), multDirMatrix() and multLineMatrix().

void SbMatrix::multVecMatrix (const SbVec3f & src, SbVec3f & dst) const

Multiply src vector with this matrix and return the result in dst. Multiplication is done with the vector on the left side of the expression, i.e. dst = src * M.

It is safe to let src and dst be the same SbVec3f instance.

This method can be used (using the current model matrix) to transform a point from an object coordinate systems to the world coordinate system.

This operation is what you would usually do when transforming vectors, as SbMatrix instances are, by definition, column-order matrices.

See also

multMatrixVec(), multDirMatrix() and multLineMatrix().

void SbMatrix::multDirMatrix (const SbVec3f & src, SbVec3f & dst) const

Multiplies src by the matrix. src is assumed to be a direction vector, and the translation components of the matrix are therefore ignored.

Multiplication is done with the vector on the left side of the expression, i.e. dst = src * M.

See also

multVecMatrix(), multMatrixVec() and multLineMatrix().
