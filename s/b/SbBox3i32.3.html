Description détaillée

La classe SbBox3i32 est une boîte tridimensionnelle avec des coordonnées entières 32 bits.

Cette classe de boîte est utilisée par d'autres classes dans Coin pour l'échange de données. Elle fournit un stockage pour deux coins de boîte avec des coordonnées entières 32 bits, ce qui est utile, entre autres, pour représenter des zones d'écran ou de canevas dans des coordonnées de fenêtre absolues.

Voir aussi

SbBox2f, SbBox2d, SbBox3s, SbBox3f, SbBox3d, SbXfBox3f.
