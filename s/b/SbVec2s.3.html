Description détaillée

La classe SbVec2s est un vecteur à 2 dimensions avec des coordonnées entières courtes.

Cette classe de vecteur est utilisée par de nombreuses autres classes dans Coin. Elle fournit un stockage pour un vecteur en 2 dimensions ainsi que des opérations arithmétiques entières simples.

Detallada Descripción

La clase SbVec2s define un vector de 2 dimensiones cuyos componentes son enteros cortos (signed short).

Los objetos SbVec2s se utilizan para almacenar y manipular vectores 2D, como las coordenadas de un punto en un plano 2D, o un vector direccional.

Los componentes del vector se indexan como 0 (coordenada x) y 1 (coordenada y).
