Description Détaillée

La classe SbVec3s est un vecteur à 3 dimensions avec des coordonnées entières de type short.

Cette classe de vecteur fournit le stockage pour un vecteur à 3 dimensions ainsi que des opérations d'arithmétique entière simples.

Vous devez être conscient que cette classe est une extension de Coin et n'est pas disponible dans l'API originale SGI Open Inventor v2.1.

Voir aussi

SbVec2s, SbVec2f, SbVec2d, SbVec3f, SbVec3d, SbVec4f, SbVec4d.
