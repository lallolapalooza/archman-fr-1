Description Détaillée

La classe SbProjector est la classe de base abstraite des projecteurs.

Les projecteurs sont utilisés dans la bibliothèque Coin pour mapper des coordonnées 2D (généralement issues de la position du curseur de la fenêtre de rendu) à des coordonnées 3D « monde ».

Le mappage de coordonnées 2D à 3D est effectué de manière extensive dans les classes de dragger afin de fournir aux utilisateurs une méthode d'interaction pratique et naturelle avec la géométrie 3D des scènes.

Pour un exemple d'utilisation, voir la documentation de la classe SbSphereSheetProjector.

Le développeur d'une application ne devrait normalement pas avoir à se soucier des classes de projecteurs, sauf en cas de besoins particuliers dans l'application.

virtual SbProjector * SbProjector::copy (void ) const [puro virtual]

Crée et renvoie une copie de ce projecteur. L'appelant doit détruire l'instance nouvelle.

Notez que si la bibliothèque Coin a été compilée en tant que DLL sous Windows et que vous utilisez cette méthode à partir de code d'application, vous devez vous assurer que la DLL de Coin et l'exécutable de l'application utilisent la même instance d'une bibliothèque C Run-Time (CRT). Sinon, vous obtiendrez une corruption de la mémoire du tas lors de la désallocation des instances retournées, ce qui peut éventuellement entraîner des plantages de mémoire inattendus.

SbBool SbProjector::tryProject (const SbVec2f & point, const float epsilon, SbVec3f & result) [puro virtual]

Tente de projeter le point 2D de coordonnées de fenêtre normalisées vers un point 3D. Le mappage sera effectué en fonction du type du projecteur.

Si la projection ne peut pas être effectuée en toute sécurité (par exemple, lorsque la surface de projection ou la ligne est parallèle au volume de vue), cette fonction doit renvoyer FALSE.

L'implémentation par défaut appellera project() et renverra toujours TRUE, mais les classes dérivées peuvent outrepasser ce comportement pour supporter des projections sécurisées.

SbBool SbProjector::verifyProjection (const SbVec3f & projpt) const [protected]

Vérifie si projpt est une projection valide pour le volume de vue actuel. Pour les volumes de vue en perspective, cela est fait en vérifiant que le point de projection est devant le plan de l'œil. Pour les projections orthographiques, cette méthode retourne toujours TRUE.

Cette méthode ne faisait pas partie de l'API Inventor v2.1 et est une extension spécifique à Coin.
