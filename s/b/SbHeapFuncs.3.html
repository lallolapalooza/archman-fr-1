Description Détaillée

La structure SbHeapFuncs est utilisée pour spécifier des fonctions sur les éléments du tas.

Documentation des Membres de Données

float(* SbHeapFuncs::eval_func) (void *)

Le membre eval_func est un pointeur vers une fonction qui doit retourner une valeur de poids pour un élément du tas. Les éléments les plus petits sont extraits en premier du tas.

int(* SbHeapFuncs::get_index_func) (void *)

get_index_func est un pointeur vers une fonction qui doit retourner l'index de l'élément dans le tas. Si vous souhaitez supprimer un élément du tas (autre que le premier élément), ou modifier le poids d'un élément du tas, vous devez fournir les deux fonctions d'index. Chaque élément doit alors stocker son index dans le tas dans ses propres structures de données.

void(* SbHeapFuncs::set_index_func) (void *, int)

set_index_func est utilisée pour définir cette valeur d'index, et sera appelée chaque fois que l'élément est déplacé dans le tas.
