Description Détaillée

La classe SbBox2i32 est un carré 2D avec des coordonnées entières 32 bits.

Cette classe de boîtes est utilisée par d'autres classes dans Coin pour échanger des données. Elle fournit un stockage pour deux sommets d'un carré avec des coordonnées entières 32 bits, ce qui est utile, par exemple, pour représenter des zones de fenêtre absolues dans les coordonnées de l'écran.

Detailed Description

This class defines a 2D bounding box for integer coordinates. It is defined by two points, a minimum point and a maximum point. The minimum point is the lower-left corner and the maximum point is the upper-right corner of the box.

The coordinates are of type int32_t.
