Documentation constructeur & destructeur

SbHeap::SbHeap (const SbHeapFuncs & hFuncs, const int initsize = 1024)

Constructeur. hFuncs spécifie les fonctions pour modifier et retourner des informations sur l'objet tas, initsize spécifie le nombre initial d'éléments alloués. Ce tableau grandira automatiquement lorsque nécessaire, mais si vous savez approximativement combien d'éléments le tas conterra, vous devriez le fournir pour éviter quelques réallocations.
