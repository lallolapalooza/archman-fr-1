Description détaillée

La classe SbPlaneProjector projette des points 2D sur des points 3D dans un plan défini.

La projection 3D des points 2D est contrainte à l'intérieur d'un plan prédéfini.

SbBool SbPlaneProjector::tryProject (const SbVec2f & point, const float epsilon, SbVec3f & result) [virtual]

Tente de projeter le point 2D de l'espace de visualisation normalisé sur un point 3D. Le mappage sera effectué selon le type de projecteur.

Si la projection ne peut pas être effectuée en toute sécurité (par exemple, lorsque le plan de projection ou la ligne est parallèle à la projection de l'espace de visualisation), cette fonction doit retourner FALSE.

L'implémentation par défaut appelle project() et retourne toujours TRUE, mais les classes filles peuvent remplacer ce comportement pour prendre en charge les projections sécurisées.
