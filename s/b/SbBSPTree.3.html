Description détaillée

La classe SbBSPTree fournit un conteneur de partitionnement binaire d'espace.

Cette classe peut être utilisée pour organiser des recherches de points 3D ou de normales dans un ensemble en temps O(log(n)).

Note : SbBSPTree est une extension de l'API originale Open Inventor.

Documentation Constructeur & Destructeur

SbBSPTree::SbBSPTree (const int maxnodepts = 64, const int initsize = 4)

Constructeur avec maxnodepts spécifiant le nombre maximum de points dans un nœud avant qu'il ne doive être divisé, et initsize est le nombre de points initialement alloués dans le tableau de points extensible. Detailed Description

This class provides an implementation of a binary space partitioning (BSP) tree. It is used for efficient spatial queries, such as finding all objects within a given region or finding the closest object to a given point.

The BSP tree is constructed from a set of geometric primitives, which are then recursively partitioned based on a set of splitting planes. This allows for quick elimination of large portions of the scene that do not intersect the query region.

Description Détaillée

Cette classe fournit une implémentation d'arbre de partitionnement spatial binaire (BSP). Elle est utilisée pour des requêtes spatiales efficaces, telles que la recherche de tous les objets dans une région donnée ou la recherche de l'objet le plus proche d'un point donné.

L'arbre BSP est construit à partir d'un ensemble de primitives géométriques, qui sont ensuite récursivement partitionnées sur la base d'un ensemble de plans de division. Cela permet d'éliminer rapidement de larges portions de la scène qui n'intersectent pas la région de requête.
