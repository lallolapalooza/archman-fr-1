Description détaillée

La classe SbSphereSheetProjector projette des points 2D sur des points 3D sur une surface couvrant une forme sphérique.

L'exemple autonome suivant montre comment les coordonnées de l'espace écran sont projetées sur des points 3D lorsqu'une SbSphereSheetProjector est appliquée. Le résultat est affiché comme un SoPointSet dans un fichier Inventor sur la sortie standard :

#include <cstdio>
#include <Inventor/SbLinear.h>
#include <Inventor/projectors/SbSphereSheetProjector.h>
#include <Inventor/SoDB.h>
int
main(void)
{
  SoDB::init();
  const float START = 0.0f;
  const float END = 1.0f;
  const float STEPS = 50.0f;
  const float STEPSIZE = ((END - START) / STEPS);
  SbSphere s(SbVec3f(0, 0, 0), 0.8);
  SbSphereSheetProjector ssp(s, TRUE); // dernier argument est orienttoeye
  SbViewVolume volume;
  volume.ortho(-1, 1, -1, 1, -1, 1);
  ssp.setViewVolume(volume);
  (void)fprintf(stdout, "#Inventor V2.1 ascii\n\n"
                "Separator {\n"
                "  Coordinate3 {\n"
                "    point [\n");
  for (float i=START; i <= END; i += STEPSIZE) {
    for (float j=START; j <= END; j += STEPSIZE) {
      SbVec3f v = ssp.project(SbVec2f(j, i));
      (void)fprintf(stdout, "\t%f %f %f,\n", v[0], v[1], v[2]);
    }
  }
  (void)fprintf(stdout, "      ]\n"
                "    }\n"
                "  DrawStyle { pointSize 2 }\n"
                "  PointSet { }\n"
                "}\n");
  return 0;
}

SbSphereSheetProjector — The SbSphereSheetProjector class is used to implement hyperbolic projections.

Detailed Description

This class implements the hyperbolic projection. This projection is used to simulate moving a viewpoint across a sphere without distortion. The viewpoint is always on a hyperbolic sheet.

The class maintains a viewpoint (the projector's position) on the surface of a virtual sphere, and projects it onto a plane.

The projection is achieved by considering the viewpoint to be on the surface of a sphere, and projecting it onto a plane that is tangent to the sphere at the viewpoint's position. The sheet is defined by the intersection of a hyperbolic paraboloid and the plane.

This projector is useful for implementing actions that involve dragging an object across a curved surface, such as manipulating a 3D sphere.
