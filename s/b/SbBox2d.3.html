Description détaillée

La classe SbBox2d est une boîte 2D avec des coordonnées de coins en double précision.

Cette classe de boîte est utilisée par de nombreuses autres classes dans Coin pour l'échange et le stockage de données. Elle fournit deux coins de boîte avec des coordonnées en double précision, ce qui est utile, entre autres, pour représenter les dimensions d'écran ou de canevas dans des coordonnées normalisées.

Cette classe est une extension de Coin.

Voir aussi

SbBox2s, SbBox2f, SbBox3s, SbBox3f, SbBox3d, SbXfBox3f.

SbBool SbBox2d::findIntersection (const SbVec2d & a, const SbVec2d & b, SbVec2d & ia, SbVec2d & ib) const

Trouve les points d'intersection entre un segment de ligne et la boîte.

Si le segment ne coupe pas la boîte, la fonction retourne Faux. Sinon, elle retourne Vrai et place les points d'intersection dans ia et ib.

Note : La fonction suppose que le segment est défini par les points a et b. Elle retourne les points d'intersection dans l'ordre où ils apparaissent le long du segment.
