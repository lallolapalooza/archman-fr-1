Description détaillée

La classe SbCylinderProjector est la classe de base abstraite pour la projection sur des surfaces cylindriques.

Les projecteurs cylindriques projettent des points 2D sur divers types de surfaces basés sur des formes cylindriques.

DESCRIPTION

Ce projecteur modélise la projection d'un point 3D sur la surface d'un cylindre. Le cylindre lui-même est défini par sa position, son rayon et sa hauteur.

Il peut projeter un point sur la face avant ou arrière du cylindre, et peut également s'orienter vers l'œil.

Ce projecteur est souvent utilisé pour créer des curseurs 3D interactifs.
