Description Détaillée

La classe SbBox2s est une boîte 2D avec des coordonnées entières courtes.

Cette classe de boîte est utilisée par d'autres classes dans Coin pour l'échange de données. Elle fournit un stockage pour deux coins de boîte avec des coordonnées entières courtes, ce qui est utile, entre autres, pour représenter des zones d'écran ou de toile dans des coordonnées de fenêtre absolues.

Nom

SbBox2s - boite 2D avec coordonnées entières.

Description Syntaxique

class SbBox2s

Description Détaillée

C'est une boite 2D définie par deux points. Le premier point est le coin inférieur gauche et le second point est le coin supérieur droit.

Les coordonnées sont de type short.
