Description détaillée

La classe SbViewportRegion est une région de vue dans une fenêtre complète.

La classe SbViewportRegion contient des informations pour représenter une sous-vue au sein d'une fenêtre. Elle stocke des informations sur la position et la taille de la sous-vue, ainsi que la taille de la fenêtre sous-jacente ("complète").

Les méthodes disponibles incluent des requêtes et des manipulations à la fois en coordonnées normalisées et en coordonnées pixel.

Voici un petit exemple montrant comment la région de vue d'une classe de spectateur peut être modifiée, dans un environnement de système Coin et de fenêtre approprié. Cliquez sur 'D' ou 'U' pour déplacer la région de vue de 40 pixels vers le bas ou vers le haut, respectivement. Cliquez sur 'Esc' et utilisez les boutons de souris gauche et milieu pour zoomer, pour voir comment la région est définie, où aucune géométrie 3D en dehors de celle-ci ne sera visible. Cliquez à nouveau sur 'Esc' pour utiliser 'U' et 'D'.

// Copyright (C) par Kongsberg Oil & Gas Technologies. Tous droits réservés.
#include <Inventor/Qt/SoQt.h>
#include <Inventor/Qt/viewers/SoQtExaminerViewer.h>
#include <Inventor/nodes/SoEventCallback.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/nodes/SoCone.h>
#include <Inventor/events/SoKeyboardEvent.h>
// ************************************************************
static void
keypresscbfunc(void * userdata, SoEventCallback * keyboardcb)
{
  SoQtExaminerViewer * viewer = (SoQtExaminerViewer *)userdata;
  const SoEvent * event = keyboardcb->getEvent();
  int shift = 0;
  if (SO_KEY_PRESS_EVENT(event, U)) {
    shift = 40;
    keyboardcb->setHandled();
  }
  else if (SO_KEY_PRESS_EVENT(event, D)) {
    shift = -40;
    keyboardcb->setHandled();
  }
  if (keyboardcb->isHandled()) {
    SbViewportRegion vpr = viewer->getViewportRegion();
    SbVec2s size = vpr.getViewportSizePixels();
    SbVec2s origin = vpr.getViewportOriginPixels();
    origin[1] -= shift;
    vpr.setViewportPixels(origin, size);
    viewer->setViewportRegion(vpr);
  }
}
// ************************************************************
int
main(int argc, char ** argv)
{
  QWidget * window = SoQt::init(argv[0]);
  SoSeparator * root = new SoSeparator;
  root->ref();
  root->addChild(new SoCone);
  SoQtExaminerViewer * viewer = new SoQtExaminerViewer(window);
  SoEventCallback * eventcb = new SoEventCallback;
  eventcb->addEventCallback(SoKeyboardEvent::getClassTypeId(),
                            keypresscbfunc, viewer);
  root->insertChild(eventcb, 0);
  viewer->setViewing(FALSE);
  viewer->setDecoration(FALSE);
  viewer->setSceneGraph(root);
  viewer->show();
  SoQt::show(window);
  SoQt::mainLoop();
  delete viewer;
  root->unref();
  return 0;
}

void SbViewportRegion::scaleWidth (float ratio)

Met à l'échelle la largeur de la région du viewport.

Le facteur d'échelle ne doit pas rendre le viewport plus grand que la fenêtre. Si cela se produit, le viewport sera limité.

La mise à l'échelle sera effectuée autour du point central de la région du viewport, mais si cela provoque le déplacement de l'origine du viewport en dessous de (0,0), les coordonnées de l'origine seront limitées.
