void SbPList::fit (void )

Ajuste le tableau alloué exactement à la taille de la liste, rejetant la mémoire dépensée pour les cellules du tableau pré-allouées inutilisées.

Vous ne devriez normalement pas avoir besoin ou vouloir appeler cette méthode, et elle n'est disponible que pour avoir l'option d'optimiser l'utilisation de la mémoire dans le cas peu probable où vous manipuleriez d'énormes objets SbList dans votre application.

void SbPList::truncate (const int length, const int fit = 0) [inline]

Raccourcit la liste pour contenir length éléments, en supprimant les éléments à partir de l'index length et au-delà.

Si fit est non nul, réduira également la taille interne du tableau alloué. Notez que cela est beaucoup moins efficace que de ne pas réajuster la taille du tableau.

Retourne un pointeur vers un tableau non modifiable des éléments de la liste. start spécifie un index dans le tableau.

L'appelant n'est pas responsable de la libération du tableau, car il ne s'agit que d'un pointeur vers le tableau interne utilisé par la liste.

Detailed Description

Une liste de pointeurs génériques. Chaque élément de la liste est un pointeur `void *`. La classe gère automatiquement le redimensionnement du tableau sous-jacent selon les besoins.
