Description détaillée

La classe SbViewVolume représente un volume de visualisation dans l'espace 3D.

Cette classe contient les informations nécessaires pour stocker un volume de visualisation. Elle dispose de méthodes pour projeter des primitives dans le volume 3D à partir de points 2D dans le plan de projection ou vice versa, pour effectuer des transformations de caméra, des transformations de volume de vue, etc.

void SbViewVolume::projectToScreen (const SbVec3f & src, SbVec3f & dst) const

Projette le point src dans des coordonnées d'écran normalisées dans le plan de projection et place le résultat dans dst.

Il est sûr de laisser src et dst être la même instance SbVec3f.

La coordonnée z de dst est monotone croissante pour les points plus proches du plan lointain. Notez cependant que ce n'est pas une relation linéaire, la coordonnée z de dst est calculée comme suit :

Vue orthogonale : DSTz = (-2 * SRCz - loin - près) / (loin - près), Vue perspective : DSTz = (-SRCz * (loin - près) - 2*loin*près) / (loin - près)

Les coordonnées retournées (dst) sont normalisées pour être dans la plage [0, 1].

SbViewVolume SbViewVolume::narrow (float left, float bottom, float right, float top) const

Retourne une version rétrécie du volume de vue qui se trouve dans les coordonnées normalisées données [0, 1]. Les coordonnées sont considérées comme des points d'angle d'une "fenêtre de vue" normalisée sur le plan de coupe proche. C'est-à-dire :

SbViewVolume view;
view.ortho(0, 100, 0, 100, 0.1, 1000);
view = view.narrow(0.25, 0.5, 0.75, 1.0);

..donnera un volume de vue avec les points d'angle <25, 75> et <50, 100>.

SbViewVolume SbViewVolume::narrow (const SbBox3f & box) const

Retourne une version rétrécie du volume de vue qui se trouve dans les coordonnées normalisées données [0, 1]. Les coordonnées x et y de la boîte sont considérées comme des points d'angle d'une "fenêtre de vue" normalisée sur le plan de coupe proche. Les coordonnées z de la boîte sont utilisées pour ajuster les plans de coupe proches et lointains, et doivent être relatives aux plans de coupe actuels. Une valeur de 1.0 est au niveau du plan proche actuel. Une valeur de 0.0 est au niveau du plan lointain actuel.

Configure le volume de vue comme une boîte rectangulaire pour des projections parallèles orthographiques.

La ligne de mire sera le long de l'axe Z négatif, à travers le centre du plan défini par le point

[(right+left)/2, (top+bottom)/2, 0]

void SbViewVolume::frustum (float left, float right, float bottom, float top, float nearval, float farval)

Configure le tronc de cône pour la projection de perspective. C'est une alternative à perspective() qui vous permet de spécifier n'importe quel type de volume de vue (par exemple, des volumes décentrés). Il a les mêmes arguments et fonctionnalités que la fonction OpenGL correspondante glFrustum().
