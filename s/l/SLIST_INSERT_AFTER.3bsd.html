TAILQ_HEAD

Ces macros définissent et opèrent sur quatre types de structures de données qui peuvent être utilisées dans le code source C et C++ :

  1. Listes
  2. Listes chaînées simples
  3. Files à queue chaînées simples
  4. Files à queue
Les quatre structures prennent en charge les fonctionnalités suivantes :
  1. Insertion d'une nouvelle entrée en tête de liste.
  2. Insertion d'une nouvelle entrée après n'importe quel élément de la liste.
  3. Suppression en O(1) d'une entrée en tête de liste.
  4. Parcours avant de la liste.
  5. Échange du contenu de deux listes.

Les listes chaînées simples sont les plus simples des quatre structures de données et ne prennent en charge que les fonctionnalités ci-dessus. Les listes chaînées simples sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une pile (LIFO). Les listes chaînées simples ajoutent les fonctionnalités suivantes :

  1. Suppression en O(n) de n'importe quelle entrée de la liste.
  2. Concaténation en O(n) de deux listes.

Les files à queue chaînées simples ajoutent les fonctionnalités suivantes :

  1. Les entrées peuvent être ajoutées à la fin d'une liste.
  2. Suppression en O(n) de n'importe quelle entrée de la liste.
  3. Elles peuvent être concaténées.
Cependant :
  1. Toutes les insertions de liste doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un.
  3. La taille du code est environ 15% plus grande et les opérations sont environ 20% plus lentes que pour les listes chaînées simples.

Les files à queue chaînées simples sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une file d'attente (FIFO).

Toutes les structures de données de type doublement chaînées (listes et files à queue) permettent en outre :

  1. Insertion d'une nouvelle entrée avant n'importe quel élément de la liste.
  2. Suppression en O(1) de n'importe quelle entrée de la liste.
Cependant :
  1. Chaque élément nécessite deux pointeurs au lieu d'un.
  2. La taille du code et le temps d'exécution des opérations (à l'exception de la suppression) sont environ le double de ceux des structures de données chaînées simples.

Les listes chaînées sont les plus simples des structures de données doublement chaînées. Elles ajoutent les fonctionnalités suivantes par rapport à ce qui précède :

  1. Concaténation en O(n) de deux listes.
  2. Elles peuvent être parcourues en arrière.
Cependant :
  1. Pour parcourir en arrière, une entrée pour commencer le parcours et la liste dans laquelle elle se trouve doivent être spécifiées.

Les files à queue ajoutent les fonctionnalités suivantes :

  1. Les entrées peuvent être ajoutées à la fin d'une liste.
  2. Elles peuvent être parcourues en arrière, de la queue à la tête.
  3. Elles peuvent être concaténées.
Cependant :
  1. Toutes les insertions et suppressions de liste doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un.
  3. La taille du code est environ 15% plus grande et les opérations sont environ 20% plus lentes que pour les listes chaînées simples.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur. La structure doit contenir un champ nommé NAME qui est de type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, ou TAILQ_ENTRY. Dans les définitions de macros, CLASSTYPE est le nom d'une classe définie par l'utilisateur. La classe doit contenir un champ nommé NAME qui est de type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, ou TAILQ_CLASS_ENTRY. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant les macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, ou TAILQ_CLASS_HEAD. Voir les exemples ci-dessous pour plus d'explications sur l'utilisation de ces macros.

LISTES CHAÎNÉES SIMPLES

Une liste chaînée simple est dirigée par une structure définie par la macro SLIST_HEAD. Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont chaînés simplement pour un minimum d'espace et de surcharge de manipulation de pointeurs au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant ou en tête de liste. Une structure SLIST_HEAD est déclarée comme suit :

SLIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la liste. Un pointeur vers la tête de la liste peut être déclaré ultérieurement comme :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro SLIST_HEAD_INITIALIZER évalue à un initialiseur pour la liste head.

La macro SLIST_CONCAT concatène la liste dirigée par head2 à la fin de celle dirigée par head1, en supprimant toutes les entrées de la première. L'utilisation de cette macro doit être évitée car elle parcourt la totalité de la liste head1. Une file à queue chaînée simple devrait être utilisée si cette macro est nécessaire dans des chemins de code à forte utilisation ou pour opérer sur de longues listes.

La macro SLIST_EMPTY évalue à vrai s'il n'y a aucun élément dans la liste.

La macro SLIST_ENTRY déclare une structure qui relie les éléments de la liste.

La macro SLIST_FIRST retourne le premier élément de la liste ou NULL si la liste est vide.

La macro SLIST_FOREACH parcourt la liste référencée par head dans la direction avant, attribuant chaque élément à tour de rôle à var.

La macro SLIST_FOREACH_FROM se comporte de manière identique à SLIST_FOREACH lorsque var est NULL, sinon elle traite var comme un élément SLIST précédemment trouvé et commence la boucle à var au lieu du premier élément de la SLIST référencée par head.

La macro SLIST_FOREACH_SAFE parcourt la liste référencée par head dans la direction avant, attribuant chaque élément à tour de rôle à var. Cependant, contrairement à SLIST_FOREACH(), il est permis de supprimer var ainsi que de le libérer à l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro SLIST_FOREACH_FROM_SAFE se comporte de manière identique à SLIST_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément SLIST précédemment trouvé et commence la boucle à var au lieu du premier élément de la SLIST référencée par head.

La macro SLIST_INIT initialise la liste référencée par head.

La macro SLIST_INSERT_HEAD insère le nouvel élément elm en tête de liste.

La macro SLIST_INSERT_AFTER insère le nouvel élément elm après l'élément

.

La macro SLIST_NEXT renvoie l'élément suivant dans la liste.

La macro SLIST_REMOVE_AFTER supprime l'élément suivant elm de la liste. Contrairement à SLIST_REMOVE, cette macro ne parcourt pas toute la liste.

La macro SLIST_REMOVE_HEAD supprime l'élément elm de la tête de la liste. Pour une efficacité optimale, les éléments supprimés de la tête de la liste devraient utiliser explicitement cette macro plutôt que la macro générique SLIST_REMOVE.

La macro SLIST_REMOVE supprime l'élément elm de la liste. L'utilisation de cette macro doit être évitée car elle parcourt toute la liste. Une liste doublement chaînée devrait être utilisée si cette macro est nécessaire dans des chemins de code à forte utilisation ou pour opérer sur de longues listes.

La macro SLIST_SWAP échange le contenu de head1 et head2.

EXEMPLE DE LISTE SIMPLEMENT CHAÎNÉE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Tête de liste simplement chaînée. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Liste simplement chaînée. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Initialise la liste. */

n1 = malloc(sizeof(struct entry));	/* Insère à la tête. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insère après. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Suppression. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Suppression de la tête. */
free(n3);
					/* Parcours avant. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sécurisé. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Suppression de liste. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

FILES À QUEUES SIMPLEMENT CHAÎNÉES

Une file à queues simplement chaînée est dirigée par une structure définie par la macro STAILQ_HEAD. Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file à queues et l'autre vers le dernier élément de la file à queues. Les éléments sont chaînés simplement pour un minimum d'espace et de manipulation de pointeurs, au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file à queues après un élément existant, à la tête de la file à queues, ou à la fin de la file à queues. Une structure STAILQ_HEAD est déclarée comme suit :

STAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à chaîner dans la file à queues. Un pointeur vers la tête de la file à queues peut plus tard être déclaré comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro STAILQ_HEAD_INITIALIZER évalue à un initialiseur pour la file à queues head.

La macro STAILQ_CONCAT concatène la file à queues dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première.

La macro STAILQ_EMPTY évalue à vrai s'il n'y a aucun élément dans la file à queues.

La macro STAILQ_ENTRY déclare une structure qui relie les éléments dans la file à queues.

La macro STAILQ_FIRST renvoie le premier élément de la file à queues ou NULL si la file à queues est vide.

La macro STAILQ_FOREACH parcourt la file à queues référencée par head dans le sens avant, assignant chaque élément à tour de rôle à var.

La macro STAILQ_FOREACH_FROM se comporte identiquement à STAILQ_FOREACH lorsque var est NULL, sinon elle traite var comme un élément STAILQ trouvé précédemment et commence la boucle à var au lieu du premier élément de la STAILQ référencée par head.

La macro STAILQ_FOREACH_SAFE parcourt la file à queues référencée par head dans le sens avant, assignant chaque élément à tour de rôle à var. Cependant, contrairement à STAILQ_FOREACH(), il est permis ici de supprimer var ainsi que de le libérer depuis l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro STAILQ_FOREACH_FROM_SAFE se comporte identiquement à STAILQ_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément STAILQ trouvé précédemment et commence la boucle à var au lieu du premier élément de la STAILQ référencée par head.

La macro STAILQ_INIT initialise la file à queues référencée par head.

La macro STAILQ_INSERT_HEAD insère le nouvel élément elm à la tête de la file à queues.

La macro STAILQ_INSERT_TAIL insère le nouvel élément elm à la fin de la file à queues.

La macro STAILQ_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro STAILQ_LAST renvoie le dernier élément de la file à queues. Si la file à queues est vide, la valeur renvoyée est NULL.

La macro STAILQ_NEXT renvoie le prochain élément de la file à queues, ou NULL si cet élément est le dernier.

La macro STAILQ_REMOVE_AFTER supprime l'élément suivant elm de la file à queues. Contrairement à STAILQ_REMOVE, cette macro ne parcourt pas toute la file à queues.

La macro STAILQ_REMOVE_HEAD supprime l'élément à la tête de la file à queues. Pour une efficacité optimale, les éléments supprimés de la tête de la file à queues devraient utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE.

La macro STAILQ_REMOVE supprime l'élément elm de la file à queues. L'utilisation de cette macro devrait être évitée car elle parcourt toute la liste. Une file à queues doublement chaînée devrait être utilisée si cette macro est nécessaire dans des chemins de code à forte utilisation ou pour opérer sur de longues files à queues.

La macro STAILQ_SWAP échange le contenu de head1 et head2.

EXEMPLE DE FILE À QUEUES SIMPLEMENT CHAÎNÉE

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Tête de file à queues simplement chaînée. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* File à queues. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Initialise la file. */

n1 = malloc(sizeof(struct entry));	/* Insère à la tête. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insère à la queue. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insère après. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Suppression. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Suppression de la tête. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Parcours avant. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sécurisé. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Suppression de TailQ. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Suppression de TailQ plus rapide. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTES

Une liste est dirigée par une structure définie par la macro LIST_HEAD. Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont chaînés doublement de manière à ce qu'un élément arbitraire puisse être supprimé sans parcourir la liste. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un élément existant, ou à la tête de la liste. Une structure LIST_HEAD est déclarée comme suit :

LIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à chaîner dans la liste. Un pointeur vers la tête de la liste peut plus tard être déclaré comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro LIST_HEAD_INITIALIZER évalue à un initialiseur pour la liste head.

La macro LIST_CONCAT concatène la liste dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première. L'utilisation de cette macro devrait être évitée car elle parcourt toute la liste head1. Une file à queues devrait être utilisée si cette macro est nécessaire dans des chemins de code à forte utilisation ou pour opérer sur de longues listes.

La macro LIST_EMPTY évalue à vrai s'il n'y a aucun élément dans la liste.

La macro LIST_ENTRY déclare une structure qui relie les éléments dans la liste.

La macro LIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro LIST_FOREACH parcourt la liste référencée par head dans le sens avant, assignant chaque élément à tour de rôle à var.

La macro LIST_FOREACH parcourt la liste référencée par head dans le sens avant, assignant chaque élément à tour de rôle à var.

LIST EXAMPLE

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* Tête de liste. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* Liste. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Initialiser la liste. */

n1 = malloc(sizeof(struct entry));	/* Insérer en tête. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insérer après. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Insérer avant. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Suppression. */
free(n2);
					/* Parcours avant. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Parcours avant sécurisé. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* Suppression de liste. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);
}

n1 = LIST_FIRST(&head);			/* Suppression de liste plus rapide. */
while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}

TAIL QUEUES

Une file de pointeurs est définie par la macro TAILQ_HEAD. Cette structure contient deux pointeurs, l'un vers le premier élément de la file de pointeurs et l'autre vers le dernier élément de la file. Les éléments sont doublement chaînés, ce qui permet de supprimer n'importe quel élément sans parcourir la file. De nouveaux éléments peuvent être ajoutés à la file de pointeurs après un élément existant, avant un élément existant, en tête de file, ou à la fin de la file. Une structure TAILQ_HEAD est déclarée ainsi :

TAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir et TYPE est le type des éléments chaînés dans la file. Une adresse vers la tête de file peut être déclarée ensuite :

struct HEADNAME *headp;

(Les noms head et headp sont choisis par l'utilisateur.)

La macro TAILQ_HEAD_INITIALIZER est évaluée à un initialiseur pour la file de pointeurs head.

La macro TAILQ_CONCAT concatène la file de pointeurs pointée par head2 à la fin de la file de pointeurs pointée par head1, vidant la première.

La macro TAILQ_EMPTY est évaluée à vrai si aucun élément n'est présent dans la file de pointeurs.

La macro TAILQ_ENTRY déclare une structure qui chaîne les éléments de la file de pointeurs.

La macro TAILQ_FIRST renvoie le premier élément de la file de pointeurs, ou NULL si la file est vide.

La macro TAILQ_FOREACH parcourt la file de pointeurs pointée par head dans le sens avant, assignant chaque élément à var. var est mis à NULL si la boucle se termine normalement, ou s'il n'y a pas d'éléments.

La macro TAILQ_FOREACH_FROM se comporte de manière identique à TAILQ_FOREACH lorsque var est NULL, sinon elle traite var comme un élément précédemment trouvé de la file de pointeurs et commence la boucle à var au lieu du premier élément de la file de pointeurs pointée par head.

La macro TAILQ_FOREACH_REVERSE parcourt la file de pointeurs pointée par head dans le sens arrière, assignant chaque élément à var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporte de manière identique à TAILQ_FOREACH_REVERSE lorsque var est NULL, sinon elle traite var comme un élément précédemment trouvé de la file de pointeurs et commence la boucle à var au lieu du dernier élément de la file de pointeurs pointée par head.

Les macros TAILQ_FOREACH_SAFE et TAILQ_FOREACH_REVERSE_SAFE parcourent la liste pointée par head dans le sens avant ou arrière respectivement, assignant chaque élément à var. Cependant, étant des versions sûres, elles permettent la suppression de var et la libération de son contenu à l'intérieur de la boucle sans interférer avec la trajectoire, contrairement à TAILQ_FOREACH et TAILQ_FOREACH_REVERSE.

La macro TAILQ_FOREACH_FROM_SAFE se comporte de manière identique à TAILQ_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément précédemment trouvé de la file de pointeurs et commence la boucle à var au lieu du premier élément de la file de pointeurs pointée par head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporte de manière identique à TAILQ_FOREACH_REVERSE_SAFE lorsque var est NULL, sinon elle traite var comme un élément précédemment trouvé de la file de pointeurs et commence la boucle à var au lieu du dernier élément de la file de pointeurs pointée par head.

La macro TAILQ_INIT initialise la file de pointeurs pointée par head.

La macro TAILQ_INSERT_HEAD insère le nouvel élément elm en tête de la file de pointeurs.

La macro TAILQ_INSERT_TAIL insère le nouvel élément elm à la fin de la file de pointeurs.

La macro TAILQ_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro TAILQ_INSERT_BEFORE insère le nouvel élément elm avant l'élément listelm.

La macro TAILQ_LAST renvoie le dernier élément de la file de pointeurs. Si la file est vide, la valeur renvoyée est NULL.

La macro TAILQ_NEXT renvoie l'élément suivant de la file de pointeurs, ou NULL s'il s'agit du dernier.

La macro TAILQ_PREV renvoie l'élément précédent de la file de pointeurs, ou NULL s'il s'agit du premier.

La macro TAILQ_REMOVE supprime l'élément elm de la file de pointeurs.

La macro TAILQ_SWAP échange les contenus de head1 et head2.

NOM

queue(3)

BIBLIOTHÈQUE

libbsd

SYNOPIS

#include <libbsd.h>

DESCRIPTION

Les fonctions queue fournissent un moyen de gérer des listes d'éléments de manière à permettre une insertion et une suppression efficaces. Ces fonctions sont conçues pour être utilisées de manière similaire à SLIST(3) et SLIST_HEAD(3).

LISTES SIMPLEMENT ENCHAÎNÉES

Les fonctions queue opèrent sur des listes simplement chaînées. Ces listes sont implémentées comme une série de nœuds, chacun contenant un seul pointeur vers le nœud suivant dans la liste. Les fonctions permettent l'insertion et la suppression efficaces d'éléments de la liste.

EXEMPLE DE LISTE SIMPLEMENT ENCHAÎNÉE

struct node {
    struct node *next;
};

int
main(void) {
    struct node *n1 = malloc(sizeof(struct node));
    struct node *n2 = malloc(sizeof(struct node));
    n1->next = n2;
    n2->next = NULL;
    // ...
}

FILES D'ATTENTE AVEC QUEUE SIMPLEMENT ENCHAÎNÉE

Les fonctions queue prennent également en charge les files d'attente avec queue. Une file d'attente avec queue est un type de liste où le dernier élément est la queue. Ces files d'attente sont implémentées comme une série de nœuds, chacun contenant un seul pointeur vers le nœud suivant dans la liste. Les fonctions permettent l'insertion et la suppression efficaces d'éléments à partir de la queue de la file d'attente.

EXEMPLE DE FILE D'ATTENTE AVEC QUEUE SIMPLEMENT ENCHAÎNÉE

struct node {
    struct node *next;
};

int
main(void) {
    struct node *n1 = malloc(sizeof(struct node));
    struct node *n2 = malloc(sizeof(struct node));
    n1->next = n2;
    n2->next = NULL;
    // ...
}

LISTES

Les fonctions queue peuvent être utilisées pour gérer des listes d'éléments de diverses manières. Ces fonctions sont conçues pour être utilisées de manière similaire à SLIST(3) et SLIST_HEAD(3).

EXEMPLE DE LISTE

struct node {
    struct node *next;
};

int
main(void) {
    struct node *n1 = malloc(sizeof(struct node));
    struct node *n2 = malloc(sizeof(struct node));
    n1->next = n2;
    n2->next = NULL;
    // ...
}

FILES D'ATTENTE AVEC QUEUE

Les fonctions queue prennent également en charge les files d'attente avec queue. Une file d'attente avec queue est un type de liste où le dernier élément est la queue. Ces files d'attente sont implémentées comme une série de nœuds, chacun contenant un seul pointeur vers le nœud suivant dans la liste. Les fonctions permettent l'insertion et la suppression efficaces d'éléments à partir de la queue de la file d'attente.

DIAGNOSTICS

Lors du débogage de queue(3), il peut être utile de tracer les modifications de la file d'attente. Pour activer le traçage, définissez la macro QUEUE_MACRO_DEBUG_TRACE au moment de la compilation.

Il peut également être utile de "corrompre" les pointeurs qui ont été désolidarisés d'une file d'attente, pour détecter une utilisation après suppression. Pour activer la corruption des pointeurs, définissez la macro QUEUE_MACRO_DEBUG_TRASH au moment de la compilation. La macro QMD_IS_TRASHED(void *ptr) renvoie vrai si ptr a été corrompu par l'option QUEUE_MACRO_DEBUG_TRASH.
