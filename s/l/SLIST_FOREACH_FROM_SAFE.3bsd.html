DESCRIPTION

Ces macros définissent et opèrent sur quatre types de structures de données qui peuvent être utilisées à la fois en C et en C++ dans le code source :

  1. Liste
  2. Liste doublement chaînée
  3. Liste de file doublement chaînée
  4. Liste de file
Les quatre structures prennent en charge la fonctionnalité suivante :
  1. Insertion d'un nouvel élément en tête de liste.
  2. Insertion d'un nouvel élément après n'importe quel élément de la liste.
  3. Suppression d'un élément en tête de liste en temps constant O(1).
  4. Parcours avant dans la liste.
  5. Échange de contenu entre deux listes.

Les listes simplement chaînées sont les plus simples des quatre structures de données et ne prennent en charge que la fonctionnalité décrite ci-dessus. Les listes simplement chaînées sont idéales pour les applications avec de grandes quantités de données et peu ou pas de suppressions, ou pour implémenter une pile LIFO. Les listes simplement chaînées ajoutent la fonctionnalité suivante :

  1. Suppression de n'importe quel élément de la liste en temps O(n).
  2. Concaténation de deux listes en temps O(n).

Les listes de file doublement chaînées ajoutent la fonctionnalité suivante :

  1. Les éléments peuvent être insérés à la fin d'une liste.
  2. Suppression de n'importe quel élément de la liste en temps O(n).
  3. Elles peuvent être concaténées.
Cependant :
  1. Toutes les insertions dans les listes doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un.
  3. La taille du code est environ 15 % plus grande et les opérations sont environ 20 % plus lentes que pour les listes simplement chaînées.

Les listes de file doublement chaînées sont idéales pour les applications avec de grandes quantités de données et peu ou pas de suppressions, ou pour implémenter une file FIFO.

Les structures de données doublement chaînées (listes et files de listes) ajoutent également :

  1. Insertion d'un nouvel élément avant n'importe quel élément de la liste.
  2. Suppression de n'importe quel élément de la liste en temps O(1).
Cependant :
  1. Chaque élément nécessite deux pointeurs au lieu d'un.
  2. La taille du code et le temps d'exécution des opérations (à l'exception de la suppression) sont environ le double de ceux des structures de liste simplement chaînées.

Les listes sont les plus simples des structures de données doublement chaînées. Elles ajoutent la fonctionnalité suivante par rapport à celles mentionnées précédemment :

  1. Concaténation de deux listes en temps O(n).
  2. Elles peuvent être parcourues en sens inverse.
Cependant :
  1. Pour parcourir en sens inverse, il faut spécifier l'élément qui commence le parcours et la liste dans laquelle il est contenu.

Les files de listes ajoutent la fonctionnalité suivante :

  1. Les éléments peuvent être insérés à la fin d'une liste.
  2. Elles peuvent être parcourues en sens inverse, de la fin vers le début.
  3. Elles peuvent être concaténées.
Cependant :
  1. Les insertions et suppressions dans les listes doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un.
  3. La taille du code est environ 15 % plus grande et les opérations sont environ 20 % plus lentes que pour les listes simplement chaînées.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur. La structure doit contenir un champ nommé NAME de type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY ou TAILQ_ENTRY. Dans les définitions de macros, CLASSTYPE est le nom d'une classe définie par l'utilisateur. La classe doit contenir un champ nommé NAME de type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY ou TAILQ_CLASS_ENTRY. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant les macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD ou TAILQ_CLASS_HEAD. Voir les exemples ci-dessous pour une explication plus détaillée de l'utilisation de ces macros.

SINGLY LINKED LISTS

Une liste simplement chaînée est une structure définie à l'aide de la macro SLIST_HEAD. Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont simplement chaînés pour minimiser l'espace et la surcharge de manipulation des pointeurs, mais avec un coût de O(n) pour supprimer n'importe quel élément arbitraire. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant ou en tête de liste. Une structure SLIST_HEAD est déclarée comme suit :

SLIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir et TYPE est le type des éléments à chaîner dans la liste. Une adresse de pointeur vers la tête de la liste peut être déclarée plus tard comme :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro SLIST_HEAD_INITIALIZER évalue à un initialiseur pour la liste head.

La macro SLIST_CONCAT concaténera la liste dirigée par head2 à la fin de la liste dirigée par head1, vidant tous les éléments de la première. L'utilisation de cette macro doit être évitée car elle parcourt tout le contenu de head1. Une liste de file doublement chaînée doit être utilisée si elle est nécessaire dans des chemins de code fréquemment utilisés ou si des opérations sur de longues listes sont nécessaires.

La macro SLIST_EMPTY évalue à vrai si la liste ne contient aucun élément.

La macro SLIST_ENTRY déclare une structure qui relie les éléments de la liste.

La macro SLIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro SLIST_FOREACH parcourt la liste dirigée par head dans le sens avant, affectant chaque élément à var.

La macro SLIST_FOREACH_FROM se comporte de manière identique à SLIST_FOREACH lorsque var est NULL, sinon elle traite var comme un élément précédemment trouvé dans une liste SLIST et commence la boucle à var au lieu du premier élément de la liste dirigée par head.

La macro SLIST_FOREACH_SAFE parcourt la liste dirigée par head dans le sens avant, affectant chaque élément à var. Cependant, elle est différente de SLIST_FOREACH() car il est permis de supprimer var et de la libérer à l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro SLIST_FOREACH_FROM_SAFE se comporte de manière identique à SLIST_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément précédemment trouvé dans une liste SLIST et commence la boucle à var au lieu du premier élément de la liste dirigée par head.

La macro SLIST_INIT initialise la liste dirigée par head.

La macro SLIST_INSERT_HEAD insère le nouvel élément elm en tête de la liste.

La macro SLIST_INSERT_AFTER insère le nouvel élément elm après l'élément

listelm.

La macro SLIST_NEXT renvoie l'élément suivant dans la liste.

La macro SLIST_REMOVE_AFTER supprime l'élément qui suit elm de la liste. Contrairement à SLIST_REMOVE, cette macro ne parcourt pas toute la liste.

La macro SLIST_REMOVE_HEAD supprime l'élément elm de la tête de la liste. Pour une efficacité optimale, les éléments supprimés de la tête de la liste devraient utiliser explicitement cette macro au lieu de la macro générique SLIST_REMOVE.

La macro SLIST_REMOVE supprime l'élément elm de la liste. L'utilisation de cette macro devrait être évitée car elle parcourt toute la liste. Une liste doublement chaînée devrait être utilisée si cette macro est nécessaire dans des chemins de code à usage intensif ou pour opérer sur de longues listes.

La macro SLIST_SWAP échange le contenu de head1 et head2.

EXEMPLE DE LISTE CHAÎNÉE SIMPLE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Tête de liste chaînée simple. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Liste chaînée simple. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Initialiser la liste. */

n1 = malloc(sizeof(struct entry));	/* Insérer en tête. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insérer après. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Suppression. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Suppression de la tête. */
free(n3);
					/* Parcours avant. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sécurisé. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Suppression de la liste. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

FILES D'ACCUEIL CHAÎNÉES SIMPLES

Une file d'accueil chaînée simple est dirigée par une structure définie par la macro STAILQ_HEAD. Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file d'accueil et l'autre vers le dernier élément de la file d'accueil. Les éléments sont chaînés simplement pour un minimum d'espace et de manipulation de pointeurs, au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file d'accueil après un élément existant, en tête de la file d'accueil, ou à la fin de la file d'accueil. Une structure STAILQ_HEAD est déclarée comme suit :

STAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la file d'accueil. Un pointeur vers la tête de la file d'accueil peut ensuite être déclaré comme :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro STAILQ_HEAD_INITIALIZER s'évalue en un initialiseur pour la file d'accueil head.

La macro STAILQ_CONCAT concatène la file d'accueil dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première.

La macro STAILQ_EMPTY s'évalue à vrai s'il n'y a aucun élément dans la file d'accueil.

La macro STAILQ_ENTRY déclare une structure qui relie les éléments dans la file d'accueil.

La macro STAILQ_FIRST renvoie le premier élément de la file d'accueil ou NULL si la file d'accueil est vide.

La macro STAILQ_FOREACH parcourt la file d'accueil référencée par head dans la direction avant, assignant chaque élément à tour de rôle à var.

La macro STAILQ_FOREACH_FROM se comporte identiquement à STAILQ_FOREACH lorsque var est NULL, sinon elle traite var comme un élément STAILQ trouvé précédemment et commence la boucle à var au lieu du premier élément de la STAILQ référencée par head.

La macro STAILQ_FOREACH_SAFE parcourt la file d'accueil référencée par head dans la direction avant, assignant chaque élément à tour de rôle à var. Cependant, contrairement à STAILQ_FOREACH(), il est permis ici de supprimer var ainsi que de le libérer depuis l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro STAILQ_FOREACH_FROM_SAFE se comporte identiquement à STAILQ_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément STAILQ trouvé précédemment et commence la boucle à var au lieu du premier élément de la STAILQ référencée par head.

La macro STAILQ_INIT initialise la file d'accueil référencée par head.

La macro STAILQ_INSERT_HEAD insère le nouvel élément elm en tête de la file d'accueil.

La macro STAILQ_INSERT_TAIL insère le nouvel élément elm à la fin de la file d'accueil.

La macro STAILQ_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro STAILQ_LAST renvoie le dernier élément de la file d'accueil. Si la file d'accueil est vide, la valeur de retour est NULL.

La macro STAILQ_NEXT renvoie l'élément suivant dans la file d'accueil, ou NULL si cet élément est le dernier.

La macro STAILQ_REMOVE_AFTER supprime l'élément qui suit elm de la file d'accueil. Contrairement à STAILQ_REMOVE, cette macro ne parcourt pas toute la file d'accueil.

La macro STAILQ_REMOVE_HEAD supprime l'élément en tête de la file d'accueil. Pour une efficacité optimale, les éléments supprimés de la tête de la file d'accueil devraient utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE.

La macro STAILQ_REMOVE supprime l'élément elm de la file d'accueil. L'utilisation de cette macro devrait être évitée car elle parcourt toute la liste. Une file d'accueil doublement chaînée devrait être utilisée si cette macro est nécessaire dans des chemins de code à usage intensif ou pour opérer sur de longues files d'accueil.

La macro STAILQ_SWAP échange le contenu de head1 et head2.

EXEMPLE DE FILE D'ACCUEIL CHAÎNÉE SIMPLE

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Tête de file d'accueil chaînée simple. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* File d'accueil. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Initialiser la file. */

n1 = malloc(sizeof(struct entry));	/* Insérer en tête. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insérer à la fin. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insérer après. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Suppression. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Suppression de la tête. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Parcours avant. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sécurisé. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Suppression de la TailQ. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Suppression plus rapide de la TailQ. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTES

Une liste est dirigée par une structure définie par la macro LIST_HEAD. Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont chaînés doublement de sorte qu'un élément arbitraire puisse être supprimé sans parcourir la liste. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un élément existant, ou en tête de la liste. Une structure LIST_HEAD est déclarée comme suit :

LIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro LIST_HEAD_INITIALIZER s'évalue en un initialiseur pour la liste head.

La macro LIST_CONCAT concatène la liste dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première. L'utilisation de cette macro devrait être évitée car elle parcourt l'intégralité de la liste head1. Une file d'accueil devrait être utilisée si cette macro est nécessaire dans des chemins de code à usage intensif ou pour opérer sur de longues listes.

La macro LIST_EMPTY s'évalue à vrai s'il n'y a aucun élément dans la liste.

La macro LIST_ENTRY déclare une structure qui relie les éléments de la liste.

La macro LIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro LIST_FOREACH parcourt la liste référencée par Le macro LIST_FOREACH parcourt la liste référencée par head dans la direction forward, assignant chaque élément dans son ordre à var.

La macro LIST_FOREACH_FROM se comporte de manière identique à LIST_FOREACH lorsque var est NULL, auquel cas var est traité comme un élément précédemment trouvé dans la liste référencée par head et la boucle commence à partir de var au lieu du premier élément de la liste référencée par head.

La macro LIST_FOREACH_SAFE parcourt la liste référencée par head dans la direction forward, assignant chaque élément dans son ordre à var. Cependant, contrairement à LIST_FOREACH(), il est permis de supprimer var et de le libérer en toute sécurité à l'intérieur de la boucle sans interférer avec le parcours.

La macro LIST_FOREACH_FROM_SAFE se comporte de manière identique à LIST_FOREACH_SAFE lorsque var est NULL, auquel cas var est traité comme un élément précédemment trouvé dans la liste référencée par head et la boucle commence à partir de var au lieu du premier élément de la liste référencée par head.

La macro LIST_INIT initialise la liste référencée par head.

La macro LIST_INSERT_HEAD insère le nouvel élément elm en tête de la liste.

La macro LIST_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro LIST_INSERT_BEFORE insère le nouvel élément elm avant l'élément listelm.

La macro LIST_NEXT retourne l'élément suivant dans la liste, ou NULL s'il s'agit du dernier.

La macro LIST_PREV retourne l'élément précédent dans la liste, ou NULL s'il s'agit du premier. La liste head doit contenir l'élément elm.

La macro LIST_REMOVE supprime l'élément elm de la liste.

La macro LIST_SWAP échange le contenu de head1 et head2.

LIST EXEMPLE

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* Tête de liste. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* Liste. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Initialise la liste. */

n1 = malloc(sizeof(struct entry));	/* Insertion en tête. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertion après. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Insertion avant. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Suppression. */
free(n2);
					/* Parcours en avant. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Parcours en avant sécurisé. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* Suppression de liste. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);
}

n1 = LIST_FIRST(&head);			/* Suppression de liste plus rapide. */
while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
LIST_INIT(&head);

QUEUES À POINTE

Une queue à pointe est définie par la macro TAILQ_HEAD. Cette structure contient une paire de pointeurs, l'un vers le premier élément dans la queue à pointe et l'autre vers le dernier élément dans la queue à pointe. Les éléments sont doublement chaînés, ce qui permet de supprimer n'importe quel élément sans parcourir la queue à pointe. Les éléments peuvent être ajoutés à la queue à pointe après un élément existant, avant un élément existant, en tête de la queue à pointe ou en fin de queue à pointe. Une structure TAILQ_HEAD est déclarée comme suit :

TAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir et TYPE est le type des éléments chaînés dans la queue à pointe. Un pointeur vers la tête de la queue à pointe peut être déclaré plus tard comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro TAILQ_HEAD_INITIALIZER évalue à un initialiseur pour la queue à pointe head.

La macro TAILQ_CONCAT concatène la queue à pointe dirigée par head2 à la fin de la queue à pointe dirigée par head1, en supprimant tous les éléments de la première.

La macro TAILQ_EMPTY évalue à vrai si la queue à pointe ne contient aucun élément.

La macro TAILQ_ENTRY déclare une structure qui relie les éléments de la queue à pointe.

La macro TAILQ_FIRST retourne le premier élément de la queue à pointe ou NULL si la queue à pointe est vide.

La macro TAILQ_FOREACH parcourt la queue à pointe référencée par head dans la direction forward, assignant chaque élément dans son ordre à var. var est mis à NULL si la boucle se termine normalement, ou s'il n'y a pas d'éléments.

La macro TAILQ_FOREACH_FROM se comporte de manière identique à TAILQ_FOREACH lorsque var est NULL, auquel cas var est traité comme un élément précédemment trouvé dans la queue à pointe et la boucle commence à partir de var au lieu du premier élément de la queue à pointe référencée par head.

La macro TAILQ_FOREACH_REVERSE parcourt la queue à pointe référencée par head dans la direction inverse, assignant chaque élément dans son ordre à var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporte de manière identique à TAILQ_FOREACH_REVERSE lorsque var est NULL, auquel cas var est traité comme un élément précédemment trouvé dans la queue à pointe et la boucle inverse commence à partir de var au lieu du dernier élément de la queue à pointe référencée par head.

Les macros TAILQ_FOREACH_SAFE et TAILQ_FOREACH_REVERSE_SAFE parcourent la liste référencée par head dans la direction forward ou inverse respectivement, assignant chaque élément dans son ordre à var. Cependant, contrairement à leurs homologues non sécurisés, TAILQ_FOREACH et TAILQ_FOREACH_REVERSE permettent de supprimer var et de le libérer en toute sécurité à l'intérieur de la boucle sans interférer avec le parcours.

La macro TAILQ_FOREACH_FROM_SAFE se comporte de manière identique à TAILQ_FOREACH_SAFE lorsque var est NULL, auquel cas var est traité comme un élément précédemment trouvé dans la queue à pointe et la boucle commence à partir de var au lieu du premier élément de la queue à pointe référencée par head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporte de manière identique à TAILQ_FOREACH_REVERSE_SAFE lorsque var est NULL, auquel cas var est traité comme un élément précédemment trouvé dans la queue à pointe et la boucle inverse commence à partir de var au lieu du dernier élément de la queue à pointe référencée par head.

La macro TAILQ_INIT initialise la queue à pointe référencée par head.

La macro TAILQ_INSERT_HEAD insère le nouvel élément elm en tête de la queue à pointe.

La macro TAILQ_INSERT_TAIL insère le nouvel élément elm à la fin de la queue à pointe.

La macro TAILQ_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro TAILQ_INSERT_BEFORE insère le nouvel élément elm avant l'élément listelm.

La macro TAILQ_LAST retourne le dernier élément de la queue à pointe. Si la queue à pointe est vide, la valeur retournée est NULL.

La macro TAILQ_NEXT retourne l'élément suivant dans la queue à pointe, ou NULL s'il s'agit du dernier.

La macro TAILQ_PREV retourne l'élément précédent dans la queue à pointe, ou NULL s'il s'agit du premier.

La macro TAILQ_REMOVE supprime l'élément elm de la queue à pointe.

La macro TAILQ_SWAP échange le contenu de head1 et head2.

EXEMPLE DE QUEUE À POINTE

TAILQ_HEAD(tailhead, entry) head =
    TAILQ_HEAD_INITIALIZER(head);
struct tailhead *headp;			/* Tête de queue à pointe. */
struct entry {
	...
	TAILQ_ENTRY(entry) entries;	/* Queue à pointe. */
	...
} *n1, *n2, *n3, *np;

TAILQ_INIT(&head);			/* Initialise la queue. */

n1 = malloc(sizeof(struct entry));	/* Insertion en tête. */
TAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insertion en fin. */
TAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertion après. */
TAILQ_INSERT_AFTER(&head, n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Insertion avant. */
TAILQ_INSERT_BEFORE(n2, n3, entries);

TAILQ_REMOVE(&head, n2, entries);	/* Suppression. */
free(n2);
					/* Parcours en avant. */
TAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours en avant sécurisé. */
TAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	TAILQ_REMOVE(&head, np, entries);
	free(np);
}
					/* Parcours en arrière. */
TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
	np-> ...
					/* Suppression de queue à pointe. */
while (!TAILQ_EMPTY(&head)) {
	n1 = TAILQ_FIRST(&head);
	TAILQ_REMOVE(&head, n1, entries);
	free(n1);
}
					/* Suppression de queue à pointe plus rapide. */
n1 = TAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = TAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
TAILQ_INIT(&head);

NOM

queue(3)

BIBLIOTHÈQUE

libbsd

SYNTAXE

TAILQ_INIT(&head);

DESCRIPTION

La fonction queue(3) permet de gérer des listes chaînées de manière simple et efficace.

LISTES SIMPLEMENT CHAÎNÉES

Dans ce type de liste, chaque élément possède un pointeur vers son nœud suivant. L'algorithme repose sur la logique d'une chaîne simple.

EXEMPLE DE LISTE SIMPLEMENT CHAÎNÉE

Exemple d'une liste simplement chaînée :

struct Node {
    void *data;
    struct Node *next;
};

FILES À QUEUES SIMPLEMENT CHAÎNÉES

Dans cette implémentation, un pointeur vers la tête de la liste est utilisé, ce qui permet d'insérer et de supprimer des nœuds efficacement.

EXEMPLE DE FILE À QUEUE SIMPLEMENT CHAÎNÉE

Exemple d'une file à queue simplement chaînée :

struct Node {
    void *data;
    struct Node *next;
};

LISTES

Une liste est un ensemble d'éléments organisés en séquences.

EXEMPLE DE LISTE

Exemple d'une liste :

struct Node {
    void *data;
    struct Node *next;
};

FILES À QUEUES

Une file est une structure de données qui permet d'insérer et de supprimer des éléments par la fin.

EXEMPLE DE FILE À QUEUE

Exemple d'une file à queue chaînée :

struct Node {
    void *data;
    struct Node *next;
};

DIAGNOSTICS

Lors du débogage de queue(3), il peut être utile de tracer les modifications apportées à la file. Pour activer le traçage, définissez la macro QUEUE_MACRO_DEBUG_TRACE lors de la compilation.

Il peut également être utile de mettre au rebut les pointeurs qui ont été retirés d'une file, afin de détecter une utilisation après suppression. Pour activer la mise au rebut des pointeurs, définissez la macro QUEUE_MACRO_DEBUG_TRASH lors de la compilation. La macro QMD_IS_TRASHED(void *ptr) renvoie vrai si ptr a été mis au rebut par l'option QUEUE_MACRO_DEBUG_TRASH.
