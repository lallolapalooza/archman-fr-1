SLIST(3) Manuel des fonctions de bibliothèque SLIST(3)

NOM

SLIST_EMPTY, SLIST_ENTRY, SLIST_FIRST, SLIST_FOREACH, SLIST_HEAD, SLIST_HEAD_INITIALIZER, SLIST_INIT, SLIST_INSERT_AFTER, SLIST_INSERT_HEAD, SLIST_NEXT, SLIST_REMOVE, SLIST_REMOVE_HEAD - implémentation d'une liste simplement chaînée

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <sys/queue.h>
SLIST_ENTRY(TYPE);
SLIST_HEAD(NOMENSETE, TYPE);
SLIST_HEAD NOMENSETE SLIST_HEAD_INITIALIZER(SLIST_HEAD tete);
void SLIST_INIT(SLIST_HEAD *tete);
int SLIST_EMPTY(SLIST_HEAD *tete);
void SLIST_INSERT_HEAD(SLIST_HEAD *tete,
                        struct TYPE *elt, SLIST_ENTRY NOM);
void SLIST_INSERT_AFTER(struct TYPE *eltliste,
                        struct TYPE *elt, SLIST_ENTRY NOM);
struct TYPE *SLIST_FIRST(SLIST_HEAD *tete);
struct TYPE *SLIST_NEXT(struct TYPE *elt, SLIST_ENTRY NOM);
SLIST_FOREACH(struct TYPE *var, SLIST_HEAD *tete, SLIST_ENTRY NOM);
void SLIST_REMOVE(SLIST_HEAD *tete, struct TYPE *elt, TYPE,
                        SLIST_ENTRY NOM);
void SLIST_REMOVE_HEAD(SLIST_HEAD *tete,
                        SLIST_ENTRY NOM);

DESCRIPTION

Ces macros définissent et manipulent des listes simplement chaînées.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type SLIST_ENTRY, nommé NOM. L'argument NOMENSETE est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro SLIST_HEAD().

Création

Une liste simplement chaînée est dirigée par une structure définie par la macro SLIST_HEAD(). Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont chaînés de manière simple pour une surcharge minimale d'espace et de manipulation de pointeurs, au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant ou en tête de liste. Une structure SLIST_HEAD est déclarée comme suit :


SLIST_HEAD(NOMENSETE, TYPE) tete;

où struct NOMENSETE est la structure à définir, et struct TYPE est le type des éléments à lier dans la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme :


struct NOMENSETE *tetep;

(Les noms tete et tetep sont sélectionnables par l'utilisateur.)

SLIST_ENTRY() déclare une structure qui connecte les éléments de la liste.

SLIST_HEAD_INITIALIZER() évalue un initialiseur pour la liste tete.

SLIST_INIT() initialise la liste référencée par tete.

SLIST_EMPTY() évalue à vrai s'il n'y a pas d'éléments dans la liste.

Insertion

SLIST_INSERT_HEAD() insère le nouvel élément elt en tête de la liste.

SLIST_INSERT_AFTER() insère le nouvel élément elt après l'élément eltliste.

Parcours

SLIST_FIRST() renvoie le premier élément de la liste, ou NULL si la liste est vide.

SLIST_NEXT() renvoie l'élément suivant dans la liste.

SLIST_FOREACH() parcourt la liste référencée par tete dans le sens avant, attribuant chaque élément à tour de rôle à var.

Suppression

SLIST_REMOVE() supprime l'élément elt de la liste.

SLIST_REMOVE_HEAD() supprime l'élément elt de la tête de la liste. Pour une efficacité optimale, les éléments supprimés de la tête de la liste doivent utiliser explicitement cette macro plutôt que la macro générique SLIST_REMOVE().

VALEUR DE RETOUR

SLIST_EMPTY() renvoie non nul si la liste est vide, et zéro si la liste contient au moins une entrée.

SLIST_FIRST() et SLIST_NEXT() renvoient un pointeur vers la structure TYPE première ou suivante, respectivement.

SLIST_HEAD_INITIALIZER() renvoie un initialiseur qui peut être affecté à la liste tete.

NORMES

BSD.

HISTORIQUE

4.4BSD.

BOGUES

SLIST_FOREACH() ne permet pas de supprimer ou de libérer var pendant la boucle, car cela interférerait avec le parcours. SLIST_FOREACH_SAFE(), qui est présent sur les BSD mais pas dans glibc, corrige cette limitation en permettant à var d'être supprimé en toute sécurité de la liste et libéré à partir de la boucle sans interférer avec le parcours.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    SLIST_ENTRY(entry) entries;             /* Liste simplement chaînée */
};
SLIST_HEAD(slisthead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct slisthead head;                  /* Tête de liste simplement chaînée */
    SLIST_INIT(&head);                      /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insérer en tête */
    SLIST_INSERT_HEAD(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    SLIST_INSERT_AFTER(n1, n2, entries);
    SLIST_REMOVE(&head, n2, entry, entries);/* Suppression */
    free(n2);
    n3 = SLIST_FIRST(&head);
    SLIST_REMOVE_HEAD(&head, entries);      /* Suppression depuis la tête */
    free(n3);
    for (unsigned int i = 0; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        SLIST_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
                                            /* Parcours avant */
    SLIST_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
    while (!SLIST_EMPTY(&head)) {           /* Suppression de liste */
        n1 = SLIST_FIRST(&head);
        SLIST_REMOVE_HEAD(&head, entries);
        free(n1);
    }
    SLIST_INIT(&head);
    exit(EXIT_SUCCESS);
}
