DESCRIPTION

Ces macros définissent et opèrent sur quatre types de structures de données qui peuvent être utilisées dans le code source C et C++ :

  1. Listes
  2. Listes chaînées simples
  3. Files d'attente chaînées simples
  4. Files d'attente
Les quatre structures supportent la fonctionnalité suivante :
  1. Insertion d'une nouvelle entrée en tête de liste.
  2. Insertion d'une nouvelle entrée après n'importe quel élément de la liste.
  3. Suppression en O(1) d'une entrée de la tête de la liste.
  4. Parcours avant de la liste.
  5. Échange du contenu de deux listes.

Les listes chaînées simples sont les plus simples des quatre structures de données et ne supportent que la fonctionnalité ci-dessus. Les listes chaînées simples sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une file LIFO. Les listes chaînées simples ajoutent la fonctionnalité suivante :

  1. Suppression en O(n) de n'importe quelle entrée de la liste.
  2. Concaténation en O(n) de deux listes.

Les files d'attente chaînées simples ajoutent la fonctionnalité suivante :

  1. Les entrées peuvent être ajoutées à la fin d'une liste.
  2. Suppression en O(n) de n'importe quelle entrée de la liste.
  3. Elles peuvent être concaténées.
Cependant :
  1. Toutes les insertions de liste doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un.
  3. La taille du code est environ 15% plus grande et les opérations sont environ 20% plus lentes que celles des listes chaînées simples.

Les files d'attente chaînées simples sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une file FIFO.

Toutes les structures de données de type doublement chaînées (listes et files d'attente) permettent en plus :

  1. Insertion d'une nouvelle entrée avant n'importe quel élément de la liste.
  2. Suppression en O(1) de n'importe quelle entrée de la liste.
Cependant :
  1. Chaque élément nécessite deux pointeurs au lieu d'un.
  2. La taille du code et le temps d'exécution des opérations (à l'exception de la suppression) sont environ le double de ceux des structures de données chaînées simples.

Les listes chaînées sont les plus simples des structures de données doublement chaînées. Elles ajoutent la fonctionnalité suivante par rapport aux précédentes :

  1. Concaténation en O(n) de deux listes.
  2. Elles peuvent être parcourues en arrière.
Cependant :
  1. Pour parcourir en arrière, une entrée pour commencer le parcours et la liste dans laquelle elle est contenue doivent être spécifiées.

Les files d'attente ajoutent la fonctionnalité suivante :

  1. Les entrées peuvent être ajoutées à la fin d'une liste.
  2. Elles peuvent être parcourues en arrière, de la queue à la tête.
  3. Elles peuvent être concaténées.
Cependant :
  1. Toutes les insertions et suppressions de liste doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un.
  3. La taille du code est environ 15% plus grande et les opérations sont environ 20% plus lentes que celles des listes chaînées simples.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur. La structure doit contenir un champ appelé NOM qui est de type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, ou TAILQ_ENTRY. Dans les définitions de macros, CLASSTYPE est le nom d'une classe définie par l'utilisateur. La classe doit contenir un champ appelé NOM qui est de type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, ou TAILQ_CLASS_ENTRY. L'argument NOMHEAD est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant les macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, ou TAILQ_CLASS_HEAD. Voir les exemples ci-dessous pour plus d'explications sur l'utilisation de ces macros.

LISTES CHAÎNÉES SIMPLES

Une liste chaînée simple est dirigée par une structure définie par la macro SLIST_HEAD. Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont chaînés simplement pour une consommation d'espace minimale et une manipulation de pointeurs à faible coût, au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant ou en tête de liste. Une structure SLIST_HEAD est déclarée comme suit :

SLIST_HEAD(NOMHEAD, TYPE) head;

où NOMHEAD est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme suit :

struct NOMHEAD *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro SLIST_HEAD_INITIALIZER évalue à un initialiseur pour la liste head.

La macro SLIST_CONCAT concatène la liste dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première. L'utilisation de cette macro doit être évitée car elle parcourt la totalité de la liste head1. Une file d'attente chaînée simple devrait être utilisée si cette macro est nécessaire dans des chemins de code à forte utilisation ou pour opérer sur de longues listes.

La macro SLIST_EMPTY évalue à vrai s'il n'y a aucun élément dans la liste.

La macro SLIST_ENTRY déclare une structure qui relie les éléments de la liste.

La macro SLIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro SLIST_FOREACH parcourt la liste référencée par head dans le sens avant, assignant chaque élément tour à tour à var.

La macro SLIST_FOREACH_FROM se comporte identiquement à SLIST_FOREACH lorsque var est NULL, sinon elle traite var comme un élément SLIST trouvé précédemment et commence la boucle à var au lieu du premier élément de la liste SLIST référencée par head.

La macro SLIST_FOREACH_SAFE parcourt la liste référencée par head dans le sens avant, assignant chaque élément tour à tour à var. Cependant, contrairement à SLIST_FOREACH(), ici il est permis de supprimer var ainsi que de le libérer depuis l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro SLIST_FOREACH_FROM_SAFE se comporte identiquement à SLIST_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément SLIST trouvé précédemment et commence la boucle à var au lieu du premier élément de la liste SLIST référencée par head.

La macro SLIST_INIT initialise la liste référencée par head.

La macro SLIST_INSERT_HEAD insère le nouvel élément elm en tête de la liste.

La macro SLIST_INSERT_AFTER insère le nouvel élément elm après l'élément

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Tête de liste simplement chaînée. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Liste simplement chaînée. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Initialisation de la liste. */

n1 = malloc(sizeof(struct entry));	/* Insertion en tête. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertion après. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Suppression. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Suppression de la tête. */
free(n3);
					/* Parcours avant. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sûr. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Suppression de liste. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

FILES DATTENTE SIMPLEMENT CHAÎNÉES

Une file d'attente simplement chaînée est dirigée par une structure définie à l'aide de la macro STAILQ_HEAD. Cette structure contient deux pointeurs, l'un vers le premier élément de la file d'attente et l'autre vers le dernier élément. Les éléments sont chaînés de manière simplement chaînée pour minimiser l'espace et la surcharge de manipulation des pointeurs, bien qu'au prix d'une complexité de O(n) pour la suppression d'éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file d'attente après un élément existant, au début de la file d'attente ou à la fin de la file d'attente. Une structure STAILQ_HEAD est déclarée ainsi :

STAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure qui est définie et TYPE est le type des éléments qui sont chaînés dans la file d'attente. Une adresse de la tête de la file d'attente peut être déclarée plus tard ainsi :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro STAILQ_HEAD_INITIALIZER est évaluée à un initialiseur pour la file d'attente head.

La macro STAILQ_CONCAT concatène la file d'attente dirigée par head2 à la fin de la file d'attente dirigée par head1, vidant la première.

La macro STAILQ_EMPTY est évaluée à vrai si la file d'attente ne contient aucun élément.

La macro STAILQ_ENTRY déclare une structure qui relie les éléments de la file d'attente.

La macro STAILQ_FIRST renvoie le premier élément de la file d'attente ou NULL si la file d'attente est vide.

La macro STAILQ_FOREACH parcourt la file d'attente dirigée par head dans le sens direct, affectant chaque élément à var.

La macro STAILQ_FOREACH_FROM fonctionne de manière identique à STAILQ_FOREACH lorsque var est NULL, sinon elle traite var comme un élément précédemment trouvé dans la file d'attente et commence la boucle à partir de var au lieu du premier élément de la file d'attente dirigée par head.

La macro STAILQ_FOREACH_SAFE parcourt la file d'attente dirigée par head dans le sens direct, affectant chaque élément à var. Cependant, contrairement à STAILQ_FOREACH(), il est permis de supprimer var et de le libérer en même temps en toute sécurité sans interférer avec la traversée.

La macro STAILQ_FOREACH_SAFE fonctionne de manière identique à STAILQ_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément précédemment trouvé dans la file d'attente et commence la boucle à partir de var au lieu du premier élément de la file d'attente dirigée par head.

La macro STAILQ_REMOVE supprime l'élément elm de la file d'attente. Son utilisation doit être évitée, car elle parcourt toute la liste. Une file d'attente doublement chaînée doit être utilisée si cette macro est nécessaire dans des chemins de code fréquemment utilisés ou pour opérer sur de longues listes.

La macro STAILQ_SWAP échange les contenus de head1 et head2.

    STAILQ_HEAD_INITIALIZER(head);

n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Parcours avant. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sûr. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);

while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);

QUEUES À QUEUE

Une queue à queue est dirigée par une structure définie par la macro TAILQ_HEAD. Cette structure contient une paire de pointeurs, l'un vers le premier élément de la queue à queue et l'autre vers le dernier élément de la queue à queue. Les éléments sont doublement liés de sorte qu'un élément arbitraire puisse être supprimé sans parcourir la queue à queue. De nouveaux éléments peuvent être ajoutés à la queue à queue après un élément existant, avant un élément existant, en tête de la queue à queue, ou à la fin de la queue à queue. Une structure TAILQ_HEAD est déclarée comme suit :

TAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la queue à queue. Un pointeur vers la tête de la queue à queue peut ensuite être déclaré comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro TAILQ_HEAD_INITIALIZER évalue à un initialiseur pour la queue à queue head.

La macro TAILQ_CONCAT concatène la queue à queue dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première.

La macro TAILQ_EMPTY évalue à vrai s'il n'y a pas d'éléments dans la queue à queue.

La macro TAILQ_ENTRY déclare une structure qui relie les éléments de la queue à queue.

La macro TAILQ_FIRST retourne le premier élément de la queue à queue ou NULL si la queue à queue est vide.

La macro TAILQ_FOREACH parcourt la queue à queue référencée par head dans la direction avant, assignant chaque élément tour à tour à var. var est défini à NULL si la boucle se termine normalement, ou s'il n'y avait aucun élément.

La macro TAILQ_FOREACH_FROM se comporte identiquement à TAILQ_FOREACH lorsque var est NULL, sinon elle traite var comme un élément TAILQ trouvé précédemment et commence la boucle à var au lieu du premier élément de la TAILQ référencée par head.

La macro TAILQ_FOREACH_REVERSE parcourt la queue à queue référencée par head dans la direction inverse, assignant chaque élément tour à tour à var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporte identiquement à TAILQ_FOREACH_REVERSE lorsque var est NULL, sinon elle traite var comme un élément TAILQ trouvé précédemment et commence la boucle inverse à var au lieu du dernier élément de la TAILQ référencée par head.

Les macros TAILQ_FOREACH_SAFE et TAILQ_FOREACH_REVERSE_SAFE parcourent la liste référencée par head dans la direction avant ou inverse respectivement, assignant chaque élément tour à tour à var. Cependant, contrairement à leurs homologues non sécurisés, TAILQ_FOREACH et TAILQ_FOREACH_REVERSE permettent de supprimer var ainsi que de le libérer depuis l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro TAILQ_FOREACH_FROM_SAFE se comporte identiquement à TAILQ_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément TAILQ trouvé précédemment et commence la boucle à var au lieu du premier élément de la TAILQ référencée par head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporte identiquement à TAILQ_FOREACH_REVERSE_SAFE lorsque var est NULL, sinon elle traite var comme un élément TAILQ trouvé précédemment et commence la boucle inverse à var au lieu du dernier élément de la TAILQ référencée par head.

La macro TAILQ_INIT initialise la queue à queue référencée par head.

La macro TAILQ_INSERT_HEAD insère le nouvel élément elm en tête de la queue à queue.

La macro TAILQ_INSERT_TAIL insère le nouvel élément elm à la fin de la queue à queue.

La macro TAILQ_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro TAILQ_INSERT_BEFORE insère le nouvel élément elm avant l'élément listelm.

La macro TAILQ_LAST retourne le dernier élément de la queue à queue. Si la queue à queue est vide, la valeur retournée est NULL.

La macro TAILQ_NEXT retourne l'élément suivant sur la queue à queue, ou NULL si cet élément est le dernier.

La macro TAILQ_PREV retourne l'élément précédent sur la queue à queue, ou NULL si cet élément est le premier.

La macro TAILQ_REMOVE supprime l'élément elm de la queue à queue.

La macro TAILQ_SWAP échange les contenus de head1 et head2.

DESCRIPTION

These macros provide an implementation of singly-linked lists. Singly-linked lists are implemented using a pair of macros: one to declare the list head and list entry structure, and another to define the list primitives.

A singly-linked list is composed of a sequence of entries. Each entry consists of a pointer to the next entry in the list. The list itself is represented by a pointer to the first entry in the list. The last entry in the list points to NULL.

To use these macros, you must first define a structure which will hold the pointers to the next entry. The macro SLIST_HEAD defines this structure. It takes two arguments, the first one is the name of the structure that will hold the pointers, and the second one is the name of the structure that represents the list entry. For example:

SLIST_HEAD(SLIST_NAME, ENTRY);

This defines two structures: SLIST_NAME, which is the pointer to the first element in the list, and SLIST_NAME_ENTRY, which is the structure that each element in the list will use. The pointer to the next element is called slh_next.

The macros are defined as follows:

Declares a singly-linked list head structure named typename. The list will contain elements of type type. The internal structure member name used for the next pointer is slh_next.
SLIST_HEAD_INITIALIZER(head)
Returns an initializer for an empty list head head. This can be used to initialize a list statically.

SLIST_INSERT_BEFORE(elm, newelm, field)
Inserts the element newelm before the element elm. The list entry structure member name is specified by field.

SLIST_REMOVE(head, elm, field)
Removes the element elm from the list pointed to by head. The list entry structure member name is specified by field.

SINGLY-LINKED LISTS

The SLIST_ macros provide a generic singly-linked list implementation. You declare a list head and entry structures using SLIST_HEAD, and then use the other macros to manipulate the list.

#include <stdlib.h>
#include <sys/queue.h>

    int data;
    SLIST_ENTRY(my_entry) next;
};

SLIST_HEAD(my_list_head, my_entry);

int
main(void)
{

    struct my_entry *entry, *tmp;

    SLIST_INIT(&head);

    /* Add some entries */
    entry = malloc(sizeof(struct my_entry));

    entry->data = 2;
    SLIST_INSERT_HEAD(&head, entry, next);

        printf("Removed entry with data = %d\n", entry->data);
        free(entry);
    }

    return 0;
}

Ces macros fournissent une implémentation de listes simplement chaînées. Les listes simplement chaînées sont implémentées à l'aide d'une paire de macros : une pour déclarer la tête de liste et la structure d'entrée de liste, et une autre pour définir les primitives de la liste.

Une liste simplement chaînée est composée d'une séquence d'entrées. Chaque entrée se compose d'un pointeur vers l'entrée suivante dans la liste. La liste elle-même est représentée par un pointeur vers la première entrée de la liste. La dernière entrée de la liste pointe vers NULL.

Pour utiliser ces macros, vous devez d'abord définir une structure qui contiendra les pointeurs vers l'entrée suivante. La macro SLIST_HEAD définit cette structure. Elle prend deux arguments, le premier est le nom de la structure qui contiendra les pointeurs, et le second est le nom de la structure qui représente l'entrée de liste. Par exemple :

SLIST_HEAD(SLIST_NAME, ENTRY);

Ceci définit deux structures : SLIST_NAME, qui est le pointeur vers le premier élément de la liste, et SLIST_NAME_ENTRY, qui est la structure que chaque élément de la liste utilisera. Le pointeur vers l'élément suivant est appelé slh_next.

Les macros sont définies comme suit :

SLIST_HEAD(typename, type)
Déclare une structure de tête de liste simplement chaînée nommée typename. La liste contiendra des éléments de type type. Le nom du membre de structure interne utilisé pour le pointeur suivant est slh_next.
SLIST_HEAD_INITIALIZER(head)
Retourne un initialiseur pour une tête de liste vide head. Ceci peut être utilisé pour initialiser une liste statiquement.
SLIST_NEXT(elm, field)
Retourne l'élément suivant dans la liste après l'élément elm. Le nom du membre de structure d'entrée de liste est spécifié par field. Il s'agit généralement de slh_next.
SLIST_EMPTY(head)
Retourne vrai si la liste pointée par head est vide, et faux sinon.
SLIST_FOREACH(var, head, field)
Itère sur la liste. La variable de boucle var recevra chaque élément de la liste, en commençant par le premier. Le nom du membre de structure d'entrée de liste est spécifié par field.
SLIST_INIT(head)
Initialise la liste pointée par head pour qu'elle soit vide. Cette macro doit être utilisée pour initialiser des listes dynamiquement.
SLIST_INSERT_HEAD(head, elm, field)
Insère l'élément elm à la tête de la liste pointée par head. Le nom du membre de structure d'entrée de liste est spécifié par field.
SLIST_INSERT_AFTER(elm, newelm, field)
Insère l'élément newelm après l'élément elm. Le nom du membre de structure d'entrée de liste est spécifié par field.
SLIST_INSERT_BEFORE(elm, newelm, field)
Insère l'élément newelm avant l'élément elm. Le nom du membre de structure d'entrée de liste est spécifié par field.
SLIST_REMOVE_HEAD(head, field)
Retire le premier élément de la liste pointée par head. Le nom du membre de structure d'entrée de liste est spécifié par field. L'élément retiré est retourné.
SLIST_REMOVE(head, elm, field)
Retire l'élément elm de la liste pointée par head. Le nom du membre de structure d'entrée de liste est spécifié par field.
SLIST_SWAP(head1, head2, type)
Échange le contenu des deux listes head1 et head2. Le type des structures de liste est spécifié par type.

LISTES SIMPLEMENT CHAÎNÉES

Les macros SLIST_ fournissent une implémentation générique de listes simplement chaînées. Vous déclarez une tête de liste et des structures d'entrée à l'aide de SLIST_HEAD, puis vous utilisez les autres macros pour manipuler la liste.

EXEMPLE DE LISTE SIMPLEMENT CHAÎNÉE

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_entry {
    int data;
    SLIST_ENTRY(my_entry) next;
};

SLIST_HEAD(my_list_head, my_entry);

int
main(void)
{
    struct my_list_head head;
    struct my_entry *entry, *tmp;

    SLIST_INIT(&head);

    /* Ajouter quelques entrées */
    entry = malloc(sizeof(struct my_entry));
    entry->data = 1;
    SLIST_INSERT_HEAD(&head, entry, next);

    entry = malloc(sizeof(struct my_entry));
    entry->data = 2;
    SLIST_INSERT_HEAD(&head, entry, next);

    printf("Contenu de la liste :\n");

        free(entry);
    }

}

DIAGNOSTICS

Lors du débogage de queue(3), il peut être utile de tracer les changements de file. Pour activer le traçage, définissez la macro QUEUE_MACRO_DEBUG_TRACE au moment de la compilation.

Il peut également être utile de "corrompre" les pointeurs qui ont été détachés d'une file, pour détecter une utilisation après suppression. Pour activer la corruption de pointeurs, définissez la macro QUEUE_MACRO_DEBUG_TRASH au moment de la compilation. La macro QMD_IS_TRASHED(void *ptr) renvoie vrai si ptr a été corrompu par l'option QUEUE_MACRO_DEBUG_TRASH.
