SLIST_INSERT_HEAD(3)

SLIST(3) Manuel des fonctions standard (libc) SLIST(3)

NAME

SLIST_EMPTY, SLIST_ENTRY, SLIST_FIRST, SLIST_FOREACH, SLIST_HEAD, SLIST_HEAD_INITIALIZER, SLIST_INIT, SLIST_INSERT_AFTER, SLIST_INSERT_HEAD, SLIST_NEXT, SLIST_REMOVE, SLIST_REMOVE_HEAD - implémentation d'une liste chaînée simple

LIBRARY

Bibliothèque C standard (libc), libc, -lc

SYNOPSIS

#include <sys/queue.h>
SLIST_ENTRY(TYPE);
SLIST_HEAD(HEADNAME, TYPE);
SLIST_HEAD SLIST_HEAD_INITIALIZER(SLIST_HEAD head);
void SLIST_INIT(SLIST_HEAD *head);
int SLIST_EMPTY(SLIST_HEAD *head);
void SLIST_INSERT_HEAD(SLIST_HEAD *head,
                        struct TYPE *elm, SLIST_ENTRY NAME);
void SLIST_INSERT_AFTER(struct TYPE *listelm,
                        struct TYPE *elm, SLIST_ENTRY NAME);
struct TYPE *SLIST_FIRST(SLIST_HEAD *head);
struct TYPE *SLIST_NEXT(struct TYPE *elm, SLIST_ENTRY NAME);
SLIST_FOREACH(struct TYPE *var, SLIST_HEAD *head, SLIST_ENTRY NAME);
void SLIST_REMOVE(SLIST_HEAD *head, struct TYPE *elm, TYPE,
                        SLIST_ENTRY NAME);
void SLIST_REMOVE_HEAD(SLIST_HEAD *head,
                        SLIST_ENTRY NAME);

DESCRIPTION

Ces macros définissent et manipulent des listes simplement chaînées.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur qui doit contenir un champ de type SLIST_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée avec la macro SLIST_HEAD().

Création

Une liste simplement chaînée est dirigée par une structure définie avec la macro SLIST_HEAD(). Cette structure contient un pointeur unique vers le premier élément de la liste. Les éléments sont simplement chaînés pour minimiser l'espace et le surcoût de manipulation des pointeurs, bien que cela implique un coût de O(n) lors de la suppression d'éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant ou en tête de liste. Une structure SLIST_HEAD est déclarée comme suit :


SLIST_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir et struct TYPE est le type des éléments de la liste. Une adresse du pointeur vers la tête de la liste peut être déclarée plus tard comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

SLIST_ENTRY() déclare une structure qui relie les éléments de la liste.

SLIST_HEAD_INITIALIZER() est évalué à un initialiseur pour la liste head.

SLIST_INIT() initialise la liste référencée par head.

SLIST_EMPTY() est évalué à TRUE si la liste est vide, et FALSE sinon.

Insertion

SLIST_INSERT_HEAD() insère le nouvel élément elm en tête de liste.

SLIST_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

SLIST_FIRST() renvoie le premier élément de la liste, ou NULL si la liste est vide.

SLIST_NEXT() renvoie l'élément suivant de la liste.

SLIST_FOREACH() parcourt la liste référencée par head dans le sens forward, en attribuant chaque élément à var.

Suppression

SLIST_REMOVE() supprime l'élément elm de la liste.

SLIST_REMOVE_HEAD() supprime l'élément elm de la tête de liste. Pour une efficacité optimale, les éléments qui sont supprimés de la tête de la liste devraient explicitement utiliser cette macro plutôt que la macro générique SLIST_REMOVE().

VALEUR DE RETOUR

SLIST_EMPTY() renvoie VRAI si la liste est vide, et FAUX sinon.

SLIST_FIRST() et SLIST_NEXT() renvoient un pointeur vers la structure TYPE du premier ou du suivant élément, respectivement.

SLIST_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la liste head.

NORMES

BSD.

HISTORIQUE

4.4BSD.

PROBLÈMES

SLIST_FOREACH() ne permet pas la suppression ou la libération de var à l'intérieur de la boucle, car cela interférerait avec le parcours. SLIST_FOREACH_SAFE(), présent dans les BSDs mais pas dans glibc, corrige cette limitation en permettant à var d'être supprimé de la liste et libéré à l'intérieur de la boucle sans interférer avec le parcours.

EXEMPLE

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    SLIST_ENTRY(entry) entries;             /* Liste simplement chaînée */
};
SLIST_HEAD(slisthead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct slisthead head;                  /* Tête de liste simplement chaînée */
    SLIST_INIT(&head);                      /* Initialiser la liste */
    n1 = malloc(sizeof(struct entry));      /* Insérer en tête */
    SLIST_INSERT_HEAD(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    SLIST_INSERT_AFTER(n1, n2, entries);
    SLIST_REMOVE(&head, n2, entry, entries);/* Supprimer */
    free(n2);
    n3 = SLIST_FIRST(&head);
    SLIST_REMOVE_HEAD(&head, entries);      /* Supprimer de la tête */
    free(n3);
    for (unsigned int i = 0; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        SLIST_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
                                            /* Parcours forward */
    SLIST_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
    while (!SLIST_EMPTY(&head)) {           /* Vidage de la liste */
        n1 = SLIST_FIRST(&head);
        SLIST_REMOVE_HEAD(&head, entries);
        free(n1);
    }
    SLIST_INIT(&head);
    exit(EXIT_SUCCESS);
}
