DESCRIPTION

Ces macros définissent et opèrent sur quatre types de structures de données qui peuvent être utilisées dans du code source C et C++ :

  1. Listes chaînées
  2. Listes chaînées simplement
  3. Files d'attente chaînées simplement
  4. Files d'attente chaînées
Les quatre structures prennent en charge les fonctionnalités suivantes :
  1. Insertion d'une nouvelle entrée en tête de la liste.
  2. Insertion d'une nouvelle entrée après n'importe quel élément de la liste.
  3. Suppression en O(1) d'une entrée en tête de la liste.
  4. Parcours avant dans la liste.
  5. Échange du contenu de deux listes.

Les listes chaînées simplement sont les plus simples des quatre structures de données et ne prennent en charge que les fonctionnalités ci-dessus. Les listes chaînées simplement sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une file LIFO. Les listes chaînées simplement ajoutent les fonctionnalités suivantes :

  1. Suppression en O(n) de n'importe quelle entrée de la liste.
  2. Concaténation en O(n) de deux listes.

Les files d'attente chaînées simplement ajoutent les fonctionnalités suivantes :

  1. Les entrées peuvent être ajoutées à la fin d'une liste.
  2. Suppression en O(n) de n'importe quelle entrée de la liste.
  3. Elles peuvent être concaténées.
Cependant :
  1. Toutes les insertions de liste doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un.
  3. La taille du code est environ 15 % plus grande et les opérations sont environ 20 % plus lentes que pour les listes chaînées simplement.

Les files d'attente chaînées simplement sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une file FIFO.

Tous les types de structures de données doublement chaînées (listes et files d'attente) permettent en outre :

  1. Insertion d'une nouvelle entrée avant n'importe quel élément de la liste.
  2. Suppression en O(1) de n'importe quelle entrée de la liste.
Cependant :
  1. Chaque élément nécessite deux pointeurs au lieu d'un.
  2. La taille du code et le temps d'exécution des opérations (à l'exception de la suppression) sont environ le double de ceux des structures de données simplement chaînées.

Les listes chaînées sont les plus simples des structures de données doublement chaînées. Elles ajoutent les fonctionnalités suivantes par rapport aux précédentes :

  1. Concaténation en O(n) de deux listes.
  2. Elles peuvent être parcourues à l'envers.
Cependant :
  1. Pour parcourir à l'envers, une entrée pour commencer le parcours et la liste dans laquelle elle se trouve doivent être spécifiées.

Les files d'attente ajoutent les fonctionnalités suivantes :

  1. Les entrées peuvent être ajoutées à la fin d'une liste.
  2. Elles peuvent être parcourues à l'envers, de la fin vers le début.
  3. Elles peuvent être concaténées.
Cependant :
  1. Toutes les insertions et suppressions de liste doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs au lieu d'un.
  3. La taille du code est environ 15 % plus grande et les opérations sont environ 20 % plus lentes que pour les listes chaînées simplement.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur. La structure doit contenir un champ appelé NOM qui est de type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, ou TAILQ_ENTRY. Dans les définitions de macros, CLASSTYPE est le nom d'une classe définie par l'utilisateur. La classe doit contenir un champ appelé NOM qui est de type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, ou TAILQ_CLASS_ENTRY. L'argument NOM_DE_TETE est le nom d'une structure définie par l'utilisateur qui doit être déclarée à l'aide des macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, ou TAILQ_CLASS_HEAD. Voir les exemples ci-dessous pour plus d'explications sur la façon dont ces macros sont utilisées.

LISTES CHAÎNEES SIMPLEMENT

Une liste chaînée simplement est dirigée par une structure définie par la macro SLIST_HEAD. Cette structure contient un unique pointeur vers le premier élément de la liste. Les éléments sont chaînés simplement pour minimiser la taille et la surcharge de manipulation des pointeurs au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant ou en tête de liste. Une structure SLIST_HEAD est déclarée comme suit :

SLIST_HEAD(NOM_DE_TETE, TYPE) tête;

où NOM_DE_TETE est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme suit :

struct NOM_DE_TETE *tête_ptr;

(Les noms tête et tête_ptr sont sélectionnables par l'utilisateur.)

La macro SLIST_HEAD_INITIALIZER évalue à un initialiseur pour la liste tête.

La macro SLIST_CONCAT concatène la liste dirigée par tête2 à la fin de celle dirigée par tête1, supprimant toutes les entrées de la première. L'utilisation de cette macro doit être évitée car elle parcourt la totalité de la liste tête1. Une file d'attente chaînée simplement doit être utilisée si cette macro est nécessaire dans des chemins de code à usage intensif ou pour opérer sur de longues listes.

La macro SLIST_EMPTY évalue à vrai s'il n'y a aucun élément dans la liste.

La macro SLIST_ENTRY déclare une structure qui relie les éléments de la liste.

La macro SLIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro SLIST_FOREACH parcourt la liste référencée par tête dans le sens avant, assignant chaque élément successivement à var.

La macro SLIST_FOREACH_FROM se comporte identiquement à SLIST_FOREACH lorsque var est NULL, sinon elle traite var comme un élément SLIST précédemment trouvé et commence la boucle à var au lieu du premier élément de la SLIST référencée par tête.

La macro SLIST_FOREACH_SAFE parcourt la liste référencée par tête dans le sens avant, assignant chaque élément successivement à var. Cependant, contrairement à SLIST_FOREACH() ici, il est permis de supprimer var ainsi que de le libérer à partir de la boucle en toute sécurité sans interférer avec le parcours.

La macro SLIST_FOREACH_FROM_SAFE se comporte identiquement à SLIST_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément SLIST précédemment trouvé et commence la boucle à var au lieu du premier élément de la SLIST référencée par tête.

La macro SLIST_INIT initialise la liste référencée par tête.

La macro SLIST_INSERT_HEAD insère le nouvel élément elm en tête de la liste.

La macro SLIST_INSERT_AFTER insère le nouvel élément elm après l'élément

listelm.

La macro SLIST_NEXT renvoie l'élément suivant dans la liste.

La macro SLIST_REMOVE_AFTER supprime l'élément suivant elm de la liste. Contrairement à SLIST_REMOVE, cette macro ne parcourt pas toute la liste.

La macro SLIST_REMOVE_HEAD supprime l'élément elm du début de la liste. Pour une efficacité optimale, les éléments supprimés du début de la liste doivent utiliser explicitement cette macro au lieu de la macro générique SLIST_REMOVE.

La macro SLIST_REMOVE supprime l'élément elm de la liste. Son utilisation doit être évitée car elle parcourt toute la liste. Une liste doublement chaînée doit être utilisée si nécessaire dans des chemins de code à forte utilisation ou pour opérer sur de longues listes.

La macro SLIST_SWAP échange le contenu de head1 avec celui de head2.

EXEMPLE DE LISTE SIMPLEMENT CHAÎNÉE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Liste simplement chaînée. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Liste simplement chaînée. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Initialiser la liste. */

n1 = malloc(sizeof(struct entry));	/* Insérer au début. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insérer après. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Suppression. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Suppression depuis le début. */
free(n3);
					/* Parcours avant. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sûr. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Vider la liste. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

FILES D'ATTENTE À DOUBLE CHAÎNAGE

Une file d'attente à double chaînée est dirigée par une structure définie à l'aide de la macro STAILQ_HEAD. Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file d'attente et l'autre vers le dernier. Les éléments sont chaînés de manière unique, permettant une surcharge minimale en espace et en manipulation de pointeurs, bien qu'avec un coût de O(n) pour la suppression d'éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file d'attente après un élément existant, au début de la file d'attente ou à la fin de la file d'attente. Une structure STAILQ_HEAD est déclarée comme suit :

STAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir et TYPE est le type des éléments de la file d'attente. Un pointeur vers la tête de la file d'attente peut ensuite être déclaré comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro STAILQ_HEAD_INITIALIZER évalue à un initialiseur pour la file d'attente head.

La macro STAILQ_CONCAT concaténera la file d'attente dirigée par head2 à la file d'attente dirigée par head1, supprimant tous les éléments de la première.

La macro STAILQ_EMPTY renvoie vrai si aucun élément n'est présent dans la file d'attente.

La macro STAILQ_ENTRY déclare une structure qui relie les éléments de la file d'attente.

La macro STAILQ_FIRST renvoie le premier élément de la file d'attente, ou NULL si la file d'attente est vide.

La macro STAILQ_FOREACH parcourt la file d'attente référencée par head dans le sens avant, affectant chaque élément à var.

La macro STAILQ_FOREACH_FROM se comporte de manière identique à STAILQ_FOREACH lorsque var est NULL ; sinon, elle traite var comme un élément précédemment trouvé dans la file d'attente et commence la boucle à var au lieu du premier élément de la file d'attente référencée par head.

La macro STAILQ_FOREACH_SAFE parcourt la file d'attente référencée par head dans le sens avant, affectant chaque élément à var. Cependant, contrairement à STAILQ_FOREACH(), il est ici permis de supprimer var et de le libérer depuis l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro STAILQ_FOREACH_FROM_SAFE se comporte de manière identique à STAILQ_FOREACH_SAFE lorsque var est NULL ; sinon, elle traite var comme un élément précédemment trouvé dans la file d'attente et commence la boucle à var au lieu du premier élément de la file d'attente référencée par head.

La macro STAILQ_INIT initialise la file d'attente référencée par head.

La macro STAILQ_INSERT_HEAD insère le nouvel élément elm au début de la file d'attente.

La macro STAILQ_INSERT_TAIL insère le nouvel élément elm à la fin de la file d'attente.

La macro STAILQ_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro STAILQ_LAST renvoie le dernier élément de la file d'attente. Si la file d'attente est vide, la valeur renvoyée est NULL.

La macro STAILQ_NEXT renvoie l'élément suivant de la file d'attente, ou NULL si c'est le dernier.

La macro STAILQ_REMOVE_AFTER supprime l'élément suivant elm de la file d'attente. Bien qu'elle ne parcourt pas toute la file d'attente, cette macro est différente de STAILQ_REMOVE.

La macro STAILQ_REMOVE_HEAD supprime l'élément au début de la file d'attente. Pour une efficacité optimale, les éléments supprimés du début de la file d'attente doivent utiliser explicitement cette macro au lieu de la macro générique STAILQ_REMOVE.

La macro STAILQ_REMOVE supprime l'élément elm de la file d'attente. Son utilisation doit être évitée car elle parcourt toute la liste. Une file d'attente doublement chaînée doit être utilisée si nécessaire dans des chemins de code à forte utilisation ou pour opérer sur de longues listes.

La macro STAILQ_SWAP échange le contenu de head1 avec celui de head2.

EXEMPLE DE FILE D'ATTENTE À DOUBLE CHAÎNAGE

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Tête de file d'attente à double chaînée. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* File d'attente à double chaînée. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Initialiser la file d'attente. */

n1 = malloc(sizeof(struct entry));	/* Insérer au début. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insérer à la fin. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insérer après. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Suppression. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Suppression depuis le début. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Parcours avant. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sûr. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Vider la file d'attente. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Vidage plus rapide de la file d'attente. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTES

Une liste est dirigée par une structure définie à l'aide de la macro LIST_HEAD. Cette structure contient un unique pointeur vers le premier élément de la liste. Les éléments sont doublement chaînés de sorte qu'un élément arbitraire puisse être supprimé sans parcourir toute la liste. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un élément existant, ou au début de la liste. Une structure LIST_HEAD est déclarée comme suit :

LIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir et TYPE est le type des éléments de la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro LIST_HEAD_INITIALIZER évalue à un initialiseur pour la liste head.

La macro LIST_CONCAT concaténera la liste dirigée par head2 à la liste dirigée par head1, supprimant tous les éléments de la première. Son utilisation doit être évitée car elle parcourt toute la liste dirigée par head1. Une file d'attente à double chaînage doit être utilisée si nécessaire dans des chemins de code à forte utilisation ou pour opérer sur de longues listes.

La macro LIST_EMPTY évalue à vrai si aucun élément n'est présent dans la liste.

La macro LIST_ENTRY déclare une structure qui relie les éléments de la liste.

La macro LIST_FIRST renvoie le premier élément de la liste, ou NULL si la liste est vide.

La macro LIST_FOREACH parcourt la liste dirigée par head dans le sens avant, affectant chaque élément à var.

LISTS

A list is a doubly linked list. It is headed by a structure defined by the LIST_HEAD macro. This structure contains a single pointer to the first element in the list. The elements are doubly linked so that an arbitrary element can be removed without traversing the list. New elements can be added to the list before an existing element, after an existing element, or at the head of the list. A LIST_HEAD structure is declared as follows:

LIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro LIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro LIST_EMPTY evaluates to true if there are no items on the list.

The macro LIST_ENTRY declares a structure that connects the elements in the list.

The macro LIST_FIRST returns the first item on the list or NULL if the list is empty.

The macro LIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro LIST_FOREACH_FROM behaves identically to LIST_FOREACH when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike LIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro LIST_FOREACH_FROM_SAFE behaves identically to LIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_INIT initializes the list referenced by head.

The macro LIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro LIST_INSERT_AFTER inserts the new element elm after the element listelm.

The macro LIST_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro LIST_NEXT returns the next element in the list, or NULL if this is the last.

The macro LIST_PREV returns the previous element in the list, or NULL if this is the first. List head must contain element elm.

The macro LIST_REMOVE removes the element elm from the list.

The macro LIST_SWAP swaps the contents of head1 and head2.

LIST EXAMPLE

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* List head. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* List. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Initialize the list. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Insert before. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Deletion. */
free(n2);
					/* Forward traversal. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Safe forward traversal. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* List Deletion. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);
}

n1 = LIST_FIRST(&head);			/* Faster List Deletion. */
while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
LIST_INIT(&head);

TAIL QUEUES

A tail queue is headed by a structure defined by the TAILQ_HEAD macro. This structure contains a pair of pointers, one to the first element in the tail queue and the other to the last element in the tail queue. The elements are doubly linked so that an arbitrary element can be removed without traversing the tail queue. New elements can be added to the tail queue after an existing element, before an existing element, at the head of the tail queue, or at the end of the tail queue. A TAILQ_HEAD structure is declared as follows:

TAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the tail queue. A pointer to the head of the tail queue can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro TAILQ_HEAD_INITIALIZER evaluates to an initializer for the tail queue head.

The macro TAILQ_CONCAT concatenates the tail queue headed by head2 onto the end of the one headed by head1 removing all entries from the former.

The macro TAILQ_EMPTY evaluates to true if there are no items on the tail queue.

The macro TAILQ_ENTRY declares a structure that connects the elements in the tail queue.

The macro TAILQ_FIRST returns the first item on the tail queue or NULL if the tail queue is empty.

The macro TAILQ_FOREACH traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var. var is set to NULL if the loop completes normally, or if there were no elements.

The macro TAILQ_FOREACH_FROM behaves identically to TAILQ_FOREACH when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE traverses the tail queue referenced by head in the reverse direction, assigning each element in turn to var.

The macro TAILQ_FOREACH_REVERSE_FROM behaves identically to TAILQ_FOREACH_REVERSE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macros TAILQ_FOREACH_SAFE and TAILQ_FOREACH_REVERSE_SAFE traverse the list referenced by head in the forward or reverse direction respectively, assigning each element in turn to var. However, unlike their unsafe counterparts, TAILQ_FOREACH and TAILQ_FOREACH_REVERSE make it possible to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro TAILQ_FOREACH_FROM_SAFE behaves identically to TAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE_FROM_SAFE behaves identically to TAILQ_FOREACH_REVERSE_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macro TAILQ_INIT initializes the tail queue referenced by head.

The macro TAILQ_INSERT_HEAD inserts the new element elm at the head of the tail queue.

The macro TAILQ_INSERT_TAIL inserts the new element elm at the end of the tail queue.

The macro TAILQ_INSERT_AFTER inserts the new element elm after the element listelm.

The macro TAILQ_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro TAILQ_LAST returns the last item on the tail queue. If the tail queue is empty the return value is NULL.

The macro TAILQ_NEXT returns the next item on the tail queue, or NULL if this item is the last.

The macro TAILQ_PREV returns the previous item on the tail queue, or NULL if this item is the first.

The macro TAILQ_REMOVE removes the element elm from the tail queue.

The macro TAILQ_SWAP swaps the contents of head1 and head2.

DIAGNOSTICS

Lors du débogage de queue(3), il peut être utile de tracer les changements de file d'attente. Pour activer le traçage, définissez la macro QUEUE_MACRO_DEBUG_TRACE au moment de la compilation.

Il peut également être utile de corrompre les pointeurs qui ont été désolidarisés d'une file d'attente, pour détecter une utilisation après suppression. Pour activer la corruption des pointeurs, définissez la macro QUEUE_MACRO_DEBUG_TRASH au moment de la compilation. La macro QMD_IS_TRASHED(void *ptr) renvoie vrai si ptr a été corrompu par l'option QUEUE_MACRO_DEBUG_TRASH.
