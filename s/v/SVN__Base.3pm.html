NOM

SVN::Base - Classe de base pour importer des symboles pour les modules svn

SYNTAXE

# Charger les fonctions svn_ra_* dans l'espace de noms SVN::Ra.
package SVN::Ra;
use SVN::Base qw(Ra svn_ra_);
# Charger les accesseurs de structure svn_config_t dans l'espace de noms magique
# fourni par swig, afin que nous puissions l'utiliser retourné par d'autres fonctions
package _p_svn_config_t;
use SVN::Base qw(Core svn_config_);

DESCRIPTION

SVN::Base est un module qui importe les symboles bruts des bindings perl de subversion créés par swig, dans un espace de noms approprié et les rend plus faciles à utiliser.

Il trouvera également les accesseurs pour les membres d'une structure C, créera une fonction d'accès plus simple comme "$data->field()" et "$data->field($new_value)".

Une fois que vous aurez compris la convention des fonctions subversion dans les bindings perl, vous pourrez consulter l'API subversion et les écrire en perl. L'API est disponible dans les fichiers d'en-tête source ou en ligne sur https://subversion.apache.org/docs/api/latest/.

INTERNES

Les bindings perl de swig encapsulent les fonctions brutes dans différents modules perl, par exemple, SVN::_Core, SVN::_Repos. Lors de l'importation, SVN::Base initialise le module demandé s'il n'est pas encore chargé, et itère sur les symboles fournis dans ce module, il place ensuite la fonction avec le préfixe tronqué dans l'espace de noms de l'appelant pour cette importation.

Le troisième paramètre jusqu'au dernier est une liste de suffixes de symboles que vous souhaitez que SVN::Base n'importe pas dans votre espace de noms. Ceci est utile dans les cas où vous pourriez vouloir importer certains symboles différemment de la normale.

AVERTISSEMENTS

SVN::Base considère une fonction comme un accesseur de membre de structure si elle est suffixée par ``_get'' ou ``_set''. Les fonctions réelles avec ces suffixes nécessiteront un traitement supplémentaire.
