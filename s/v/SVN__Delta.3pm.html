NOM

SVN::Delta - Fonctions de delta Subversion

SYNOPSIS

require SVN::Core;
require SVN::Repos;
require SVN::Delta;
# conduite d'un éditeur
my $editor = SVN::Delta::Editor->
    new(SVN::Repos::get_commit_editor($repos, "file://$repospath",
                                      '/', 'root', 'FOO', \&committed));
my $rootbaton = $editor->open_root(0);
my $fbaton = $editor->add_file('filea', $rootbaton,
                               undef, -1);
my $ret = $editor->apply_textdelta($fbaton, undef);
SVN::TxDelta::send_string("CONTENU DU FICHIER A", @$ret);
# implémentation d'un éditeur en perl
SVN::Repos::dir_delta($root1, $path, undef,
                      $root2, $path,
                      SVN::Delta::Editor->new(_debug=>1),
                      1, 1, 0, 1

DESCRIPTION

SVN::Delta encapsule les fonctions liées aux deltas dans Subversion. La plus importante est SVN::Delta::Editor, l'interface pour décrire les deltas d'arborescence. par défaut, SVN::Delta::Editor relaie les appels de méthodes à son membre interne "_editor", qui peut être soit un éditeur en C (tel que celui obtenu via get_commit_editor), soit un autre objet SVN::Delta::Editor.

SVN::Delta::Editor

Conduire des éditeurs

Si vous voulez conduire un éditeur natif (tel que commit_editor obtenu par SVN::Repos::get_commit_editor), créez un objet SVN::Delta::Editor avec la paire éditeur/baton natifs. L'objet sera alors prêt à l'emploi et ses appels de méthodes seront relayés à l'éditeur natif.

Implémenter des éditeurs

Si vous voulez implémenter un éditeur, sous-classez SVN::Delta::Editor et implémentez les callbacks de l'éditeur. voir la section MÉTHODES ci-dessous.

CONSTRUCTEUR - new(...)

new($editor, $editor_baton)
Lien vers l'éditeur natif

Vous pouvez également passer un tableau associatif à new:

_debug
Activer le débogage.
_editor
Un tableau de référence de la paire éditeur/baton ou un autre objet SVN::Delta::Editor avec lequel se lier.

MÉTHODES

Veuillez consulter la section svn_delta.h de l'API Subversion. Les fonctions membres de svn_delta_editor_t peuvent être appelées comme méthodes d'objets SVN::Delta::Editor, avec l'edit_baton omis. Le pool est également facultatif.

Si vous sous-classez, les méthodes prennent exactement les mêmes arguments que les fonctions membres (notez que les void ** sont des données retournées bien que, comme dans toutes les liaisons Perl), avec l'edit_baton omis.

BOGUES

Les fonctions retournant une paire éditeur/baton devraient réellement être typées pour retourner un objet SVN::Delta::Editor.
