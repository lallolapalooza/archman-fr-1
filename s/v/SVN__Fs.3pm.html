NOM

SVN::Fs - Fonctions du système de fichiers Subversion

DESCRIPTION

SVN::Fs encapsule les fonctions de svn_fs.h. L'espace de noms réel pour les objets du système de fichiers est "_p_svn_fs_t".

$fs->set_access($access)
Associe un contexte d'accès à un système de fichiers ouvert.

Cette méthode peut être appelée plusieurs fois sur le même système de fichiers ouvert, afin de modifier le contexte d'accès du système de fichiers pour différentes opérations. $access doit être un objet "_p_svn_fs_access_t", ou undef pour dissocier le contexte d'accès actuel du système de fichiers.

NOM

$_p_svn_fs_t
Objet représentant une entrée de répertoire.

DESCRIPTION

Cette classe représente une entrée de répertoire. Les valeurs de ce type sont retournées comme valeurs dans le hash retourné par $root->dir_entries(). Ce sont des objets similaires à svn_dirent_t, mais contenant moins d'informations.
