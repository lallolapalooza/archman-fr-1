NOM

SVN::Simple::Edit - Une interface simple pour piloter les éditeurs de delta svn

SYNTAXE

my $edit = SVN::Simple::Edit->new
   (_editor => [SVN::Repos::get_commit_editor($repos, "file://$repospath",
                                     '/', 'root', 'FOO', \&committed)],
   );
$edit->open_root($fs->youngest_rev);
$edit->add_directory ('trunk');
$edit->add_file ('trunk/filea');
$edit->modify_file ("trunk/fileb", "content", $checksum);
$edit->delete_entry ("trunk/filec");
$edit->close_edit ();
...
$edit->copy_directory ('branches/a, trunk, 0);

DESCRIPTION

SVN::Simple::Edit encapsule l'éditeur de delta subversion avec une interface conviviale pour Perl, vous permettant ainsi de le piloter facilement pour décrire les modifications apportées à un arbre. Une utilisation courante consiste à encapsuler l'éditeur de commit, vous permettant ainsi d'effectuer facilement des commits vers un dépôt subversion.

Cela signifie également que vous ne pouvez pas fournir l'objet $edit en tant qu'éditeur de delta à d'autres API, et c'est pourquoi ce module est nommé ::Edit au lieu de ::Editor.

Voir SVN::Simple::Editor pour une interface simple implémentant un éditeur de delta.

PARAMÈTRES

pour le constructeur

_editor
L'éditeur qui recevra les appels d'éditeur de delta.
gestionnaire_manquant
Appelé lorsque les répertoires parents ne sont pas encore ouverts, peut être :
\&SVN::Simple::Edit::build_missing
Toujours construire les parents si vous ne les ouvrez pas explicitement.
\&SVN::Simple::Edit::open_missing
Toujours ouvrir les parents si vous ne les créez pas explicitement.
SVN::Simple::Edit::check_missing ([$root])
Vérifier si le chemin existe sur $root. L'ouvrir si c'est le cas, sinon le créer.
racine
La racine par défaut à utiliser par SVN::Simple::Edit::check_missing.
chemin_base
Le chemin de base pour lequel l'objet d'édition est créé afin d'envoyer les appels d'éditeur de delta.
pas_de_fermeture
Ne pas fermer les fichiers ou les répertoires. Cela pourrait permettre des opérations non triées sur les répertoires/fichiers.

MÉTHODES

Note : Ne vous attendez pas à ce que tous les éditeurs fonctionnent avec des opérations qui ne sont pas triées dans l'ordre DFS.

ajouter_repertoire ($chemin)
ouvrir_repertoire ($chemin)
copier_repertoire ($chemin, $depuis, $rev_depuis)
ajouter_fichier ($chemin)
ouvrir_fichier ($chemin)
copier_fichier ($chemin, $depuis, $rev_depuis)
supprimer_entree ($chemin)
modifier_propriete_repertoire ($chemin, $nom_prop, $valeur_prop)
modifier_propriete_fichier ($chemin, $nom_prop, $valeur_prop)
fermer_edition ()
