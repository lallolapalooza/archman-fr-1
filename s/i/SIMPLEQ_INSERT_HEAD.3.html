STAILQ(3) Manuel des fonctions standard STAILQ(3)

NOM

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, - implémentation d'une file à doublement chaînée de pointeurs

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/queue.h>
STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);
STAILQ_HEAD STAILQ_HEAD_INITIALIZER(STAILQ_HEAD head);
void STAILQ_INIT(STAILQ_HEAD *head);
int STAILQ_EMPTY(STAILQ_HEAD *head);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
struct TYPE *STAILQ_FIRST(STAILQ_HEAD *head);
struct TYPE *STAILQ_NEXT(struct TYPE *elm, STAILQ_ENTRY NAME);
STAILQ_FOREACH(struct TYPE *var, STAILQ_HEAD *head, STAILQ_ENTRY NAME);
void STAILQ_REMOVE(STAILQ_HEAD *head, struct TYPE *elm, TYPE,
                         STAILQ_ENTRY NAME);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *head,
                         STAILQ_ENTRY NAME);
void STAILQ_CONCAT(STAILQ_HEAD *head1, STAILQ_HEAD *head2);

Note: Les macros identiques préfixées par SIMPLEQ au lieu de STAILQ existent ; voir VERSIONS.

DESCRIPTION

Ces macros définissent et manipulent une file à doublement chaînée de pointeurs. Elles peuvent être utilisées pour implémenter des structures de données comme des piles ou des files d'attente.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur, qui doit être déclarée en utilisant la macro STAILQ_HEAD().

Création

Une file à doublement chaînée de pointeurs est dirigée par une structure définie avec la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, un vers le premier élément de la file et un vers le dernier élément de la file. Les éléments sont chaînés de manière simple pour minimiser l'espace et la surcharge de manipulation des pointeurs, au détriment d'un temps de O(n) pour supprimer des éléments arbitraires. Les nouveaux éléments peuvent être ajoutés à la file après un élément existant, en tête de la file, ou en queue de la file. Une structure STAILQ_HEAD est déclarée comme suit :


STAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments chaînés dans la file. Une adresse d'un pointeur vers la tête de la file peut être déclarée plus tard comme :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui relie les éléments de la file.

STAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file head.

STAILQ_INIT() initialise la file référencée par head.

STAILQ_EMPTY() renvoie TRUE si la file est vide.

Insertion

STAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de la file.

STAILQ_INSERT_TAIL() insère le nouvel élément elm en queue de la file.

STAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

STAILQ_FIRST() renvoie le premier élément de la file ou NULL si la file est vide.

STAILQ_NEXT() renvoie l'élément suivant dans la file, ou NULL s'il s'agit du dernier.

STAILQ_FOREACH() parcourt la file référencée par head dans le sens forward, en assignant chaque élément à var à tour de rôle.

Suppression

STAILQ_REMOVE() supprime l'élément elm de la file.

STAILQ_REMOVE_HEAD() supprime l'élément en tête de la file. Pour une efficacité optimale, il est recommandé d'utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE() lors de la suppression d'un élément de la tête de la file.

Autres macros

STAILQ_CONCAT() concatène la file à doublement chaînée de pointeurs dirigée par head2 à la fin de la file dirigée par head1, vidant la première.

VALEUR_RETOUR

STAILQ_EMPTY() renvoie une valeur non nulle si la file est vide, et zéro si elle contient au moins un élément.

STAILQ_FIRST() et STAILQ_NEXT() renvoient un pointeur vers la structure TYPE première ou suivante, respectivement.

STAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la tête de la file head.

VERSIONS

Certaines distributions BSD fournissent SIMPLEQ au lieu de STAILQ. Elles sont identiques, mais pour des raisons historiques, elles ont été nommées différemment dans différentes distributions BSD. STAILQ est originaire de FreeBSD et SIMPLEQ de NetBSD. Pour des raisons de compatibilité, certains systèmes fournissent les deux séries de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques à l'exception de l'absence d'équivalent à STAILQ_CONCAT dans SIMPLEQ.

PROBLÈMES

STAILQ_FOREACH() ne permet pas de supprimer ou de libérer var à l'intérieur de la boucle, car cela interférerait avec le parcours. STAILQ_FOREACH_SAFE(), présent dans les distributions BSD mais pas dans glibc, résout cette limite en permettant que var soit retiré de la liste et libéré à l'intérieur de la boucle sans interférer avec le parcours.

NORMES

BSD.

HISTORIQUE

4.4BSD.

EXEMPLE

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File à doublement chaînée de pointeurs */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Tête de file à doublement chaînée
                                               de pointeurs */
    STAILQ_INIT(&head);                     /* Initialise la file */
    n1 = malloc(sizeof(struct entry));      /* Insertion en tête */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion en queue */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression de la tête */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
 
    /* Parcourt la file et libère la mémoire */
    while ((n1 = STAILQ_FIRST(&head)) != NULL) {
        STAILQ_REMOVE_HEAD(&head, entries);
        free(n1);
    }
    return 0;
}
SIMPLEQ_INSERT_HEAD(3) - Arch Linux man pages

NAME

SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_CONCAT, SIMPLEQ_FOREACH, SIMPLEQ_FIRST, SIMPLEQ_LAST, SIMPLEQ_NEXT, SIMPLEQ_PREV, SIMPLEQ_REMOVE_HEAD, SIMPLEQ_REMOVE_TAIL, SIMPLEQ_REMOVE, SIMPLEQ_INIT - délimiteurs de liste simplement chaînée

LIBRARY

Bibliothèque de support de la bibliothèque C (libc, -lc)

SYNOPSIS

#include <sys/queue.h>

 SIMPLEQ_HEAD(simpleq_head_t, elem);

 SIMPLEQ_INSERT_HEAD(struct simpleq_head_t *head, struct elem *elm,
    struct elem entries);
SIMPLEQ_INSERT_TAIL(struct simpleq_head_t *head, struct elem *elm,
    struct elem entries);
SIMPLEQ_CONCAT(struct simpleq_head_t *head1, struct simpleq_head_t *head2,
    struct elem entries);
SIMPLEQ_FOREACH(struct elem *var, struct simpleq_head_t *head,
    struct elem entries);
SIMPLEQ_FIRST(struct simpleq_head_t *head);
SIMPLEQ_LAST(struct simpleq_head_t *head, struct elem entries);
SIMPLEQ_NEXT(struct elem *elm, struct elem entries);
SIMPLEQ_PREV(struct elem *elm, struct elem entries, struct simpleq_head_t *head);
SIMPLEQ_REMOVE_HEAD(struct simpleq_head_t *head, struct elem entries);
SIMPLEQ_REMOVE_TAIL(struct simpleq_head_t *head, struct elem entries);
SIMPLEQ_REMOVE(struct simpleq_head_t *head, struct elem *elm,
    struct elem entries);
SIMPLEQ_INIT(struct simpleq_head_t *head);

DESCRIPTION

Ces macros fournissent une interface pour implémenter des listes simplement chaînées. Une liste simplement chaînée est une structure de données qui permet à un élément de pointer vers le suivant, mais pas vers le précédent.

Les éléments de la liste sont des structures qui doivent contenir un champ de type pointeur (généralement un pointeur vers lui-même) pour stocker le pointeur vers l'élément suivant. Les macros utilisent le nom du membre pour le pointeur suivant, spécifié par le paramètre entries, pour naviguer dans la liste.

Une liste simplement chaînée est définie par une structure qui contient un pointeur vers le premier élément de la liste. Le type de cette structure est défini à l'aide de la macro SIMPLEQ_HEAD.

Voici un exemple typique de définition d'élément et de liste :

struct my_elem {
    int data;
    struct my_elem *next; /* Ce champ sera utilisé par 'entries' */
};

SIMPLEQ_HEAD(my_list_head_t, my_elem);
struct my_list_head_t my_list;

Les macros disponibles sont les suivantes :

SIMPLEQ_HEAD
Déclare le type pour la tête de la liste simplement chaînée. Le premier argument est le nom du nouveau type et le second est le nom du type de structure de l'élément.
SIMPLEQ_INIT
Initialise une liste simplement chaînée vide. La tête de la liste doit être passée en argument.
SIMPLEQ_INSERT_HEAD
Insère un élément au début de la liste. Les arguments sont la tête de la liste, l'élément à insérer et le nom du champ d'entrée de l'élément.
SIMPLEQ_INSERT_TAIL
Insère un élément à la fin de la liste. Les arguments sont la tête de la liste, l'élément à insérer et le nom du champ d'entrée de l'élément.
SIMPLEQ_CONCAT
Concatène deux listes simplement chaînées. La deuxième liste (head2) est ajoutée à la fin de la première liste (head1). Après l'opération, head2 est vide. Les arguments sont les deux têtes de liste et le nom du champ d'entrée de l'élément.
SIMPLEQ_FOREACH
Itère sur tous les éléments de la liste. Le premier argument est une variable qui contiendra le pointeur vers l'élément courant à chaque itération, le second est la tête de la liste et le troisième est le nom du champ d'entrée de l'élément.
SIMPLEQ_FIRST
Retourne un pointeur vers le premier élément de la liste sans le retirer. Si la liste est vide, retourne NULL. L'argument est la tête de la liste.
SIMPLEQ_LAST
Retourne un pointeur vers le dernier élément de la liste sans le retirer. Si la liste est vide, retourne NULL. Les arguments sont la tête de la liste et le nom du champ d'entrée de l'élément.
SIMPLEQ_NEXT
Retourne un pointeur vers l'élément suivant dans la liste. Les arguments sont l'élément courant et le nom du champ d'entrée de l'élément.
SIMPLEQ_PREV
Retourne un pointeur vers l'élément précédent dans la liste. Ceci est une opération coûteuse pour les listes simplement chaînées car elle nécessite de parcourir la liste depuis le début. Les arguments sont l'élément courant, le nom du champ d'entrée de l'élément et la tête de la liste.
SIMPLEQ_REMOVE_HEAD
Retire et retourne le premier élément de la liste. Si la liste est vide, retourne NULL. Les arguments sont la tête de la liste et le nom du champ d'entrée de l'élément.
SIMPLEQ_REMOVE_TAIL
Retire et retourne le dernier élément de la liste. Si la liste est vide, retourne NULL. Les arguments sont la tête de la liste et le nom du champ d'entrée de l'élément.
SIMPLEQ_REMOVE
Retire un élément spécifié de la liste. Les arguments sont la tête de la liste, l'élément à retirer et le nom du champ d'entrée de l'élément.

RETURN VALUE

SIMPLEQ_FIRST, SIMPLEQ_LAST, SIMPLEQ_NEXT, SIMPLEQ_PREV, SIMPLEQ_REMOVE_HEAD, SIMPLEQ_REMOVE_TAIL et SIMPLEQ_REMOVE retournent un pointeur vers l'élément demandé, ou NULL si la liste est vide ou si l'élément n'est pas trouvé (pour SIMPLEQ_REMOVE).

VERSIONS

Ces macros sont disponibles depuis FreeBSD 2.0.

BUGS

SIMPLEQ_PREV est très inefficace car elle doit parcourir la liste depuis le début.

STANDARDS

Ces macros sont conformes à la spécification POSIX.1-2001.

HISTORY

Les macros de liste chaînée sont apparues dans 4.3BSD-Reno.

EXAMPLES

Voici un exemple d'utilisation des macros pour une liste simplement chaînée :

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    struct node entries; /* Le champ pour les chaînes */
};

/* Déclaration du type de liste et de la variable de liste */
SIMPLEQ_HEAD(my_queue_head, node) head;

int
main(void)
{
    struct node *np;
    struct node *n1, *n2;

    /* Initialisation de la liste */
    STAILQ_INIT(&head);

    /* Création et insertion d'éléments */
    np = malloc(sizeof(struct node));
    np->data = 1;
    STAILQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(struct node));
    np->data = 2;
    STAILQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(struct node));
    np->data = 3;
    STAILQ_INSERT_HEAD(&head, np, entries); /* Insère au début */

    /* Parcours avant */
    printf("Contenu de la liste (parcours avant) :\n");
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);

    /* Suppression de tous les éléments */
    printf("\nSuppression des éléments :\n");
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries); /* Récupère le suivant avant de libérer */
        printf("Suppression de %i\n", n1->data);
        free(n1);
        n1 = n2;
    }

    /* Réinitialisation de la liste (pour s'assurer qu'elle est vide) */
    STAILQ_INIT(&head);

    printf("\nListe après suppression.\n");

    return EXIT_SUCCESS;
}
