Bibliothèque C standard (libc, -lc)

SYNTAXE

STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);

                         struct TYPE *elm, STAILQ_ENTRY NAME);

Note: Des macros identiques préfixées par SIMPLEQ au lieu de STAILQ existent ; voir VERSIONS.

DESCRIPTION

Ces macros définissent et opèrent sur des files de queues liées simplement avec ajout en queue.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro STAILQ_HEAD().

Création

Une file de queues liée simplement avec ajout en queue est dirigée par une structure définie par la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file de queues et l'autre vers le dernier élément de la file de queues. Les éléments sont liés simplement pour un minimum d'espace et de manipulation de pointeurs au détriment d'une suppression O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file de queues après un élément existant, en tête de la file de queues, ou à la fin de la file de queues. Une structure STAILQ_HEAD est déclarée comme suit :


STAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à lier dans la file de queues. Un pointeur vers la tête de la file de queues peut plus tard être déclaré comme :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui connecte les éléments de la file de queues.

STAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file de queues head.

STAILQ_INIT() initialise la file de queues référencée par head.

STAILQ_EMPTY() évalue à vrai s'il n'y a aucun élément dans la file de queues.

Insertion

STAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de la file de queues.

STAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file de queues.

STAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

STAILQ_FIRST() renvoie le premier élément de la file de queues ou NULL si la file de queues est vide.

STAILQ_NEXT() renvoie l'élément suivant dans la file de queues, ou NULL si cet élément est le dernier.

STAILQ_FOREACH() parcourt la file de queues référencée par head dans le sens avant, en attribuant successivement chaque élément à var.

Suppression

STAILQ_REMOVE() supprime l'élément elm de la file de queues.

STAILQ_REMOVE_HEAD() supprime l'élément en tête de la file de queues. Pour une efficacité optimale, les éléments supprimés de la tête de la file de queues devraient utiliser cette macro explicitement plutôt que la macro générique STAILQ_REMOVE().

Autres fonctionnalités

STAILQ_CONCAT() concatène la file de queues dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première.

VALEUR DE RETOUR

STAILQ_EMPTY() renvoie une valeur non nulle si la file est vide, et zéro si la file contient au moins une entrée.

STAILQ_FIRST() et STAILQ_NEXT() renvoient un pointeur vers la structure TYPE première ou suivante, respectivement.

STAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la tête de la file head.

VERSIONS

Certains BSD fournissent SIMPLEQ au lieu de STAILQ. Ils sont identiques, mais pour des raisons historiques ils portaient des noms différents sur différents BSDs. STAILQ est originaire de FreeBSD, et SIMPLEQ est originaire de NetBSD. Pour des raisons de compatibilité, certains systèmes fournissent les deux ensembles de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques à l'exception d'un équivalent SIMPLEQ manquant pour STAILQ_CONCAT().

BOGUES

STAILQ_FOREACH() ne permet pas de supprimer ou de libérer var dans la boucle, car cela interférerait avec le parcours. STAILQ_FOREACH_SAFE(), qui est présent sur les BSD mais absent de glibc, corrige cette limitation en permettant à var d'être supprimé en toute sécurité de la liste et libéré à partir de la boucle sans interférer avec le parcours.

HISTORIQUE

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File de queues liée simplement */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Tête de file de queues liée
                                               simplement */
    STAILQ_INIT(&head);                     /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insérer en tête */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insérer en queue */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression depuis la tête */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }

BIBLIOTHÈQUE

SYNTAXE

STAILQ_FOREACH(np, &head, entries)

n1 = STAILQ_FIRST(&head); while (n1 != NULL) { n2 = STAILQ_NEXT(n1, entries); free(n1); n1 = n2; }

STAILQ_INIT(&head); exit(EXIT_SUCCESS);

DESCRIPTION

Itère sur la liste d'entrée de la file double simple.

VALEUR DE RETOUR

Retourne 0 en cas de succès, -1 en cas d'erreur.
