STAILQ(3) Manuel des fonctions standard STAILQ(3)

NAME

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, - implémentation d'une file d'attente simplement chaînée

LIBRARY

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);
STAILQ_HEAD STAILQ_HEAD_INITIALIZER(STAILQ_HEAD head);
void STAILQ_INIT(STAILQ_HEAD *head);
int STAILQ_EMPTY(STAILQ_HEAD *head);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
struct TYPE *STAILQ_FIRST(STAILQ_HEAD *head);
struct TYPE *STAILQ_NEXT(struct TYPE *elm, STAILQ_ENTRY NAME);
STAILQ_FOREACH(struct TYPE *var, STAILQ_HEAD *head, STAILQ_ENTRY NAME);
void STAILQ_REMOVE(STAILQ_HEAD *head, struct TYPE *elm, TYPE,
                         STAILQ_ENTRY NAME);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *head,
                         STAILQ_ENTRY NAME);
void STAILQ_CONCAT(STAILQ_HEAD *head1, STAILQ_HEAD *head2);

Note : Des macros identiques préfixées par SIMPLEQ au lieu de STAILQ existent ; voir VERSIONS.

DESCRIPTION

Ces macros définissent et opèrent sur une file d'attente simplement chaînée.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur, qui doit être déclarée en utilisant la macro STAILQ_HEAD().

Création

Une file d'attente simplement chaînée est dirigée par une structure définie par la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont chaînés simplement, ce qui implique une perte minimale d'espace et une surcharge moindre dans la manipulation des pointeurs. Les éléments peuvent être ajoutés à la file après un élément existant, au début de la file, ou à la fin de la file. Une structure STAILQ_HEAD est déclarée comme suit :


STAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir et struct TYPE est le type des éléments qui sont chaînés dans la file. Un pointeur vers la tête de la file peut ensuite être déclaré comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui relie les éléments de la file.

STAILQ_HEAD_INITIALIZER() est évaluée à un initialiseur pour la file head.

STAILQ_INIT() initialise la file référencée par head.

STAILQ_EMPTY() est évaluée à vrai si la file ne contient aucun élément.

Insertion

STAILQ_INSERT_HEAD() insère l'élément elm au début de la file.

STAILQ_INSERT_TAIL() insère l'élément elm à la fin de la file.

STAILQ_INSERT_AFTER() insère l'élément elm après l'élément listelm.

Parcours

STAILQ_FIRST() renvoie le premier élément de la file ou NULL si la file est vide.

STAILQ_NEXT() renvoie l'élément suivant dans la file, ou NULL s'il s'agit du dernier.

STAILQ_FOREACH() parcourt la file référencée par head dans le sens avant vers arrière, en assignant chaque élément à var.

Suppression

STAILQ_REMOVE() supprime l'élément elm de la file.

STAILQ_REMOVE_HEAD() supprime l'élément situé au début de la file. Pour des performances optimales, les éléments retirés du début de la file devraient utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE().

Autres_composants

STAILQ_CONCAT() concaténera la file d'attente simplement chaînée dirigée par head2 à la fin de la file dirigée par head1, vidant la première.

VALEUR_DE_RETOUR

STAILQ_EMPTY() renvoie non-zéro si la file est vide, et zéro si elle contient au moins un élément.

STAILQ_FIRST() et STAILQ_NEXT() renvoient un pointeur vers la première ou la suivante structure TYPE, respectivement.

STAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la file head.

VERSIONS

Certaines versions de BSD fournissent SIMPLEQ à la place de STAILQ. Elles sont identiques, mais pour des raisons historiques, elles ont été nommées différemment sur différentes versions de BSD. STAILQ provient de FreeBSD, et SIMPLEQ de NetBSD. Pour la compatibilité, certains systèmes fournissent les deux séries de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques, à l'exception de l'absence d'un équivalent SIMPLEQ à STAILQ_CONCAT.

BOGUES

STAILQ_FOREACH() ne permet pas de retirer ou de libérer var à l'intérieur de la boucle, car cela pourrait interférer avec l'itération. STAILQ_FOREACH_SAFE(), qui est présent sur les systèmes BSD mais pas sur glibc, corrige cette limitation en permettant à var d'être retiré de la liste et libéré à l'intérieur de la boucle sans interférer avec l'itération.

NORMES

BSD.

HISTOIRE

4.4BSD.

EXEMPLE

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File d'attente simplement chaînée */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Tête de file d'attente simplement chaînée */
    STAILQ_INIT(&head);                     /* Initialise la file */
    n1 = malloc(sizeof(struct entry));      /* Insertion au début */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion à la fin */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression du début */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }

BIBLIOTHÈQUE

DESCRIPTION

Implémentation d'une file d'attente simple, avec accès par la tête et la queue.

VALEUR RETOURNÉE

La valeur de retour est NULL si la file d'attente ne peut pas être initialisée.
