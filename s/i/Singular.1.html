SINGULAR(1) Commandes utilisateur SINGULAR(1)

NOM

Singular - page de manuel pour Singular version 4.x.x

DESCRIPTION

Singular -- un système algébrique par ordinateur (CAS) pour les calculs polynomiaux.

ESingular : démarre Singular dans emacs.

TSingular : démarre Singular dans un nouveau terminal

SYNTAXE

Singular [options] [fichier1 [fichier2 ...]]

ESingular [options] [fichier1 [fichier2 ...]]

TSingular [options] [fichier1 [fichier2 ...]]

OPTIONS

-b --batch
Exécute en mode batch (nécessite --link/--MPhost/--MPport)
-c --execute=CHAÎNE
Exécute CHAÎNE au démarrage
-d --sdb
Active le débogueur de code source (expérimental)
-e --echo[=VAL]
Définit la valeur de la variable `echo' à (entier) VAL
-h --help
Affiche le message d'aide et quitte
-p --profile
Collecte les données de profilage dans smon.out
-q --quiet
N'affiche pas la bannière de démarrage et les messages de chargement des bibliothèques
-r --random=GRAINE
Initialise le générateur aléatoire avec GRAINE (entier)
-t --no-tty
Ne redéfinit pas les caractéristiques du terminal
-u --user-option=CHAÎNE
Retourne CHAÎNE sur `system("--user-option")'
-v --version
Affiche des informations étendues sur la version et la configuration
--allow-net
Permet de récupérer les pages d'aide (html) sur le net
--browser=NAVI
Affiche l'aide dans NAVI (voir help.cnf)
--cntrlc[=CHAR]
Réponse automatique à la demande CTRL-C
--emacs
Définit les paramètres par défaut pour l'exécution dans emacs
--log=FICHIERLOG
Enregistre toutes les entrées dans FICHIERLOG.*
--no-stdlib
Ne charge pas `standard.lib' au démarrage
--no-rc
N'exécute pas le(s) fichier(s) `.singularrc' au démarrage
--no-warn
N'affiche pas les messages d'avertissement
--no-out
Supprime toute sortie
--no-shell
Mode restreint : interdit les commandes d'évasion du shell et les liens
--min-time=SECS
N'affiche pas les temps inférieurs à SECS (en secondes)
--cpus=#CPUs
Nombre maximal de CPUs à utiliser
--threads=#threads
Nombre maximal de threads à utiliser

--flint-threads=#flintthreads Nombre maximal de threads à utiliser dans la bibliothèque flint

--MPport=PORT
Utilise le numéro de PORT pour les connexions
--MPhost=HOTE
Utilise HOTE pour les connexions
--link=LIEN
Utilise LIEN pour les connexions
--ticks-per-sec=TICKS
Définit l'unité du timer à TICKS par seconde
--dump-versiontuple
Affiche la version-tuple et quitte

Pour plus d'informations, tapez `help;' depuis Singular ou visitez https://www.singular.uni-kl.de ou consultez le manuel de Singular (disponible sous forme d'aide en ligne ou de manuel html).
