Sub::HandlesVia::HandlerLibrary::Bool(3) Documentation Perl fournie par l'utilisateur Sub::HandlesVia::HandlerLibrary::Bool(3)

NOM

Sub::HandlesVia::HandlerLibrary::Bool - bibliothèque de méthodes relatives aux booléens

SYNTAXE

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Bool';
  has attr => (
    is => 'rwp',
    isa => Bool,
    handles_via => 'Bool',
    handles => {
      'my_not' => 'not',
      'my_reset' => 'reset',
      'my_set' => 'set',
      'my_toggle' => 'toggle',
      'my_unset' => 'unset',
    },
  );
}

DESCRIPTION

Ceci est une bibliothèque de méthodes pour Sub::HandlesVia.

MÉTHODES DÉLÉGUABLES

not()

Retourne la valeur opposée du booléen.

my $object = My::Class->new( attr => 1 );
say $object->my_not(); ## ==> false

reset()

Définit le booléen à sa valeur par défaut, ou à faux s'il n'a pas de valeur par défaut.

set()

Définit la valeur du booléen à vrai.

my $object = My::Class->new();
$object->my_set();
say $object->attr; ## ==> true

toggle()

Inverse la valeur de vérité du booléen.

my $object = My::Class->new();
$object->my_toggle();
say $object->attr; ## ==> true
$object->my_toggle();
say $object->attr; ## ==> false

unset()

Définit la valeur du booléen à faux.

my $object = My::Class->new();
$object->my_unset();
say $object->attr; ## ==> false
