NOM

Sub::HandlesVia::Manual::WithClassTiny - utilisation de Sub::HandlesVia avec Class::Tiny

SYNTAXE

package Cuisine;

use Class::Tiny {
  nourritures  => sub { [] },
  boissons => sub { [ 'eau' ] },
};

use Sub::HandlesVia::Declare 'nourritures', Tableau => (
  toutes_nourritures => 'tout',
  ajouter_nourriture   => 'ajouter',
);

use Sub::HandlesVia::Declare 'boissons', Tableau => (
  toutes_boissons => 'tout',
  ajouter_boisson  => 'ajouter',
);

MANUEL

Sub::HandlesVia vous permet de déléguer des méthodes de votre classe aux valeurs des attributs de vos objets.

Conceptuellement, cela vous permet de définir "$objet->ajouter_nombre($n)" comme un raccourci pour "$objet->nombres->ajouter($n)", sauf que "$objet->nombres" est une référence de tableau, et n'a donc pas de méthodes que vous pouvez appeler dessus comme "ajouter".

Quelles méthodes peuvent être déléguées ?

Le deuxième paramètre ("Tableau" dans la syntaxe) indique quelle bibliothèque de méthodes doit être disponible. Les valeurs valides incluent Tableau, Blessed, Bool, Code, Counter, Enum, Hash, Number, Scalar et String.

Une référence de tableau peut être fournie, bien que nombre d'options soient conceptuellement contradictoires.

use Sub::HandlesVia::Declare 'num', [ 'Number', 'Scalar' ] => (
  ...,
);

Délégation à l'exécution

Plutôt que d'utiliser Sub::HandlesVia::Declare qui opère au moment de la compilation, vous pouvez utiliser la fonction "delegations" au moment de l'exécution. Votre choix dépendra largement du style et des préférences personnelles.

package Cuisine;

use Class::Tiny {
  nourritures  => sub { [] },
  boissons => sub { [ 'eau' ] },
};

use Sub::HandlesVia qw( delegations );

delegations(
  attribut     => 'nourritures',
  géré_via  => 'Tableau',
  gère      => {
    toutes_nourritures => 'tout',
    ajouter_nourriture   => 'ajouter',
  },
);

delegations(
  attribut     => 'boissons',
  géré_via  => 'Tableau',
  gère      => {
    toutes_boissons => 'tout',
    ajouter_boisson  => 'ajouter',
  },
);
