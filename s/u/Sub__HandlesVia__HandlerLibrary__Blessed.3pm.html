NOM

Sub::HandlesVia::HandlerLibrary::Blessed - bibliothèque de méthodes liées aux objets

SYNTAXE

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Object';
  use HTTP::Tiny;
  has http_ua => (
    is => 'rwp',
    isa => Object,
    handles_via => 'Blessed',
    handles => {
      'http_get'  => 'get',
      'http_post' => 'post',
    },
    default => sub { HTTP::Tiny->new },
  );
}

DESCRIPTION

C'est une bibliothèque de méthodes pour Sub::HandlesVia.

MÉTHODES DÉLÉGABLES

Contrairement aux autres bibliothèques fournies par Sub::HandlesVia, cette bibliothèque vous permet de déléguer à *n'importe quel* nom de méthode.

Elle suppose que la valeur de l'attribut est un objet béni (blessed) et appelle la méthode correspondante sur cet objet.

Moo, Moose, Mouse, et Mite ont déjà ce type de délégation intégré, mais ce module vous permet d'effectuer la délégation en utilisant Sub::HandlesVia. Cela peut être utile pour Object::Pad et Class::Tiny, qui n'ont pas de fonctionnalité de délégation intégrée.
