NOM

Sub::HandlesVia::Manual::WithMite - utilisation de Sub::HandlesVia avec Mite

SYNOPIS

package MyApp::Kitchen {
  use MyApp::Mite;

  has food => (
    is          => 'ro',
    isa         => 'ArrayRef[Str]',
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}

MANUEL

Sub::HandlesVia vous permet de déléguer des méthodes de votre classe aux valeurs des attributs de vos objets.

Conceptuellement, cela vous permet de définir "$object->push_number($n)" comme un raccourci pour "$object->numbers->push($n)" sauf que "$object->numbers" est une référence tableau, elle n'a donc pas de méthodes appelables dessus comme "push".

Mite 0.009000 et versions ultérieures prennent en charge "handles_via" intégré. Mite coopérera avec Sub::HandlesVia pour implémenter "handles_via" et éviter que votre projet ait une dépendance à Sub::HandlesVia !

Quelles méthodes peuvent être déléguées ?

L'option "handles_via" indique quelle bibliothèque de méthodes doit être disponible. Les valeurs valides incluent Array, Blessed, Bool, Code, Counter, Enum, Hash, Number, Scalar et String.

Une référence tableau peut être fournie pour "handles_via", bien que plusieurs des options soient conceptuellement contradictoires.

handles_via => [ 'Number', 'Scalar' ]

"use Sub::HandlesVia"

Mite déploie beaucoup d'efforts pour éviter que vous ayez besoin de "use Sub::HandlesVia" directement dans vos classes et rôles, et ainsi éviter que vous ayez besoin de l'ajouter comme dépendance.

Cependant, il existe des cas limites qu'il pourrait ne pas gérer. Dans ces cas, vous devriez pouvoir "use SubHandlesVia" dans votre code *après* votre "use MyApp::Mite" et Sub::HandlesVia interviendra et fera fonctionner les choses. Cela ajoute cependant une dépendance à Sub::HandlesVia.

package MyApp::Kitchen {
  use MyApp::Mite;
  use Sub::HandlesVia;

  has food => (
    is          => 'ro',
    isa         => 'ArrayRef[Str]',
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}

Maintenant, Mite ne générera plus les méthodes "add_food" et "find_food" dans votre fichier Kitchen.pm.mite.pm lorsque vous exécuterez "mite compile". Au lieu de cela, Sub::HandlesVia les générera au moment de l'exécution lorsque votre application s'exécutera.
