NOM

Sub::HandlesVia::HandlerLibrary::String - bibliothèque de méthodes liées aux chaînes de caractères

SYNOPSIS

  use Moo;
  use Sub::HandlesVia;

Sub::HandlesVia::HandlerLibrary::String(3pm) — Arch manual pages

NOM

Sub::HandlesVia::HandlerLibrary::String - Les méthodes pour gérer les attributs de type String.

SYNOPSIS

 use Moo;
 use Sub::HandlesVia;
 use Types::Standard qw( Str );

 package My::Class;
 has attr => (
   is => 'ro',
   isa => Str,
   handles_via => 'String',
   handles => {
     my_match => 'match',
     my_prepend => 'prepend',
     my_set => 'set',
     # ...
   },
 );

 my $object = My::Class->new( attr => 'foo' );
 $object->my_set( 'bar' );
 say $object->attr; ## ==> 'bar'
 if ( $object->my_match( '^b.r$' ) ) {
   say 'matched!';
 }

DESCRIPTION

Cette bibliothèque de gestionnaires fournit des méthodes pour gérer des attributs de type String. Les méthodes de base sont déléguées à la méthode du même nom de la bibliothèque String::Elide. Le caractère my est ajouté à toutes les méthodes pour éviter les conflits de noms.

MÉTHODES DÉLÉGUABLES

append( $tail )

Arguments : Str.

Ajoute une autre chaîne au début de la chaîne actuelle et met à jour l'attribut.

 my $object = My::Class->new( attr => 'foo' );
 $object->my_append( 'bar' );
 say $object->attr; ## ==> 'foobar'

begins_with( $head )

Arguments : Str.

Retourne vrai si la chaîne commence par $head.

begins_with_i( $head )

Arguments : Str.

Retourne vrai si la chaîne commence par $head sans tenir compte de la casse.

chomp()

Supprime le retour chariot final s'il y en a un.

 my $object = My::Class->new( attr => "foo\n" );
 $object->my_chomp;
 say $object->attr; ## ==> 'foo'

chop()

Supprime le dernier caractère.

 my $object = My::Class->new( attr => 'foo' );
 $object->my_chop;
 say $object->attr; ## ==> 'fo'

ends_with( $tail )

Arguments : Str.

Retourne vrai si la chaîne se termine par $tail.

ends_with_i( $tail )

Arguments : Str.

Retourne vrai si la chaîne se termine par $tail sans tenir compte de la casse.

length()

Retourne la longueur de la chaîne.

match( $regexp )

Arguments : Str|RegexpRef.

Retourne vrai si la chaîne correspond à l'expression régulière.

 my $object = My::Class->new( attr => 'foo' );
 if ( $object->my_match( '^f..$' ) ) {
   say 'matched!';
 }

match_i( $regexp )

Arguments : Str|RegexpRef.

Retourne vrai si la chaîne correspond à l'expression régulière sans tenir compte de la casse.

 my $object = My::Class->new( attr => 'foo' );
 if ( $object->my_match_i( '^F..$' ) ) {
   say 'matched!';
 }

ne( $str )

Arguments : Str.

Retourne "$object->attr ne $str".

nei( $str )

Arguments : Str.

Retourne "fc($object->attr) ne fc($str)". Utilise "lc" au lieu de "fc" dans les versions de Perl antérieures à 5.16.

prepend( $head )

Arguments : Str.

Ajoute une autre chaîne au début de la chaîne actuelle et met à jour l'attribut.

 my $object = My::Class->new( attr => 'foo' );
 $object->my_prepend( 'bar' );
 say $object->attr; ## ==> 'barfoo'

"replace( $regexp, $replacement )"

Arguments : Str|RegexpRef, Str|CodeRef.

Remplace la première correspondance d'expression régulière dans la chaîne par la chaîne de remplacement.

 my $object = My::Class->new( attr => 'foo' );
 $object->my_replace( 'o' => 'a' );
 say $object->attr; ## ==> 'fao'
 my $object2 = My::Class->new( attr => 'foo' );
 $object2->my_replace( qr/O/i => sub { return 'e' } );
 say $object2->attr; ## ==> 'feo'

"replace_globally( $regexp, $replacement )"

Arguments : Str|RegexpRef, Str|CodeRef.

Remplace toutes les correspondances d'expression régulière dans la chaîne par la chaîne de remplacement.

 my $object = My::Class->new( attr => 'foo' );
 $object->my_replace_globally( 'o' => 'a' );
 say $object->attr; ## ==> 'faa'
 my $object2 = My::Class->new( attr => 'foo' );
 $object2->my_replace_globally( qr/O/i => sub { return 'e' } );
 say $object2->attr; ## ==> 'fee'

reset()

Réinitialise l'attribut à sa valeur par défaut, ou à une chaîne vide s'il n'a pas de valeur par défaut.

set( $value )

Arguments : Str.

Définit la chaîne à une nouvelle valeur.

 my $object = My::Class->new( attr => 'foo' );
 $object->my_set( 'bar' );
 say $object->attr; ## ==> 'bar'

starts_with( $head )

Arguments : Str.

Retourne vrai si la chaîne commence par $head.

starts_with_i( $head )

Arguments : Str.

Retourne vrai si la chaîne commence par $head sans tenir compte de la casse.

"substr( $start, $length?, $replacement? )"

Arguments : Int, Optional[Int], Optional[Str].

Comme "substr" de perlfunc, mais n'est pas une lvalue.

trim()

Comme "trim" de builtin, mais en place.

uc()

Retourne uc($object->attr).

EXEMPLES ÉTENDUS

Utilisation de eq pour Enum

 use strict;
 use warnings;

 package My::Person {
   use Moo;
   use Sub::HandlesVia;
   use Types::Standard qw( Str Enum );

   has name => (
     is => 'ro',
     isa => Str,
     required => 1,
   );

   has status => (
     is => 'rwp',
     isa => Enum[ 'alive', 'dead' ],
     handles_via => 'String',
     handles => {
       is_alive => [ eq  => 'alive' ],
       is_dead  => [ eq  => 'dead' ],
       kill     => [ set => 'dead' ],
     },
     default => 'alive',
   );

   # Note: les modificateurs de méthode fonctionnent sur les méthodes déléguées
   #
   before kill => sub {
     my $self = shift;
     warn "overkill" if $self->is_dead;
   };
 }

 my $bob = My::Person->new( name => 'Robert' );
 say $bob->is_alive; ## ==> true
 say $bob->is_dead;  ## ==> false
 $bob->kill;
 say $bob->is_alive; ## ==> false
 say $bob->is_dead;  ## ==> true

Voir aussi MooX::Enumeration et MooseX::Enumeration.

Correspondance avec une expression régulière "curried"

 use strict;
 use warnings;

 package My::Component {
   use Moo;
   use Sub::HandlesVia;
   use Types::Standard qw( Str Int );

   has id => (
     is => 'ro',
     isa => Int,
     required => 1,
   );

   has name => (
     is => 'ro',
     isa => Str,
     required => 1,
     handles_via => 'String',
     handles => {
       name_is_safe_filename => [ match => qr/\A[A-Za-z0-9]+\z/ ],
       _lc_name => 'lc',
     },
   );

   sub config_filename {
     my $self = shift;
     if ( $self->name_is_safe_filename ) {
       return sprintf( '%s.ini', $self->_lc_name );
     }
     return sprintf( 'component-%d.ini', $self->id );
   }
 }

 my $foo = My::Component->new( id => 42, name => 'Foo' );
 say $foo->config_filename; ## ==> 'foo.ini'

 my $bar4 = My::Component->new( id => 99, name => 'Bar #4' );
 say $bar4->config_filename; ## ==> 'component-99.ini'
