NOM

Sub::Prototype - Définir le prototype d'une sous-routine

VERSION

version 0.03

SYNOPSIS

use Sub::Prototype;
BEGIN {
    my $code = sub { ... };
    set_prototype($code, '&@');
    *main::my_func = $code;
}
my_func { ... } @list;

FONCTIONS

Ce module n'a qu'une seule fonction, qui est également exportée par défaut :

set_prototype(\&coderef, $prototype)

set_prototype(\&some_function, '$$');

Définit le prototype pour "coderef" à $prototype.
