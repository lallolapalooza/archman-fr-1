NOM

Sub::HandlesVia::HandlerLibrary::Scalar - bibliothèque de méthodes liées aux scalaires

SYNOPSIS

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Any';
  has attr => (
    is => 'rwp',
    isa => Any,
    handles_via => 'Scalar',
    handles => {
      'my_get' => 'get',
      'my_make_getter' => 'make_getter',
      'my_make_setter' => 'make_setter',
      'my_scalar_reference' => 'scalar_reference',
      'my_set' => 'set',
      'my_stringify' => 'stringify',
    },
  );
}

DESCRIPTION

Ceci est une bibliothèque de méthodes pour Sub::HandlesVia.

MÉTHODES DÉLÉGUABLES

get()

Obtient la valeur actuelle du scalaire.

make_getter()

Retourne une référence de fonction (coderef) de type getter.

my $object = My::Class->new( attr => 10 );
my $getter = $object->my_make_getter;
$object->_set_attr( 11 );
say $getter->(); ## ==> 11

make_setter()

Retourne une référence de fonction (coderef) de type setter.

my $object = My::Class->new( attr => 10 );
my $setter = $object->my_make_setter;
$setter->( 11 );
say $object->attr; ## ==> 11

scalar_reference()

Retourne une référence scalaire vers l'emplacement de la valeur de l'attribut dans son objet.

my $object = My::Class->new( attr => 10 );
my $ref = $object->my_scalar_reference;
$$ref++;
say $object->attr; ## ==> 11

set( $valeur )

Définit le scalaire à une nouvelle valeur.

stringify()

Obtient la valeur actuelle du scalaire, mais sous forme de chaîne.
