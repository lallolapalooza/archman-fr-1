Sub::Install(3) Documentation Perl fournie par l'utilisateur Sub::Install(3)

NOM

Sub::Install - installe facilement des sous-programmes dans des paquets

VERSION

version 0.929

SYNOPIS

use Sub::Install;
Sub::Install::install_sub({
  code => sub { ... },
  into => $package,
  as   => $subname
});

DESCRIPTION

Ce module rend facile l'installation de sous-programmes dans des paquets sans le désordre disgracieux de "no strict" ou de typeglobs qui traînent là où n'importe qui peut les voir.

VERSION PERL

Cette bibliothèque devrait fonctionner sur des Perl publiés même il y a très longtemps. Elle devrait fonctionner sur n'importe quelle version de Perl publiée au cours des dix dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est faite que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour n'importe quelle raison, et il n'y a aucune promesse que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

FONCTIONS

install_sub

Sub::Install::install_sub({
 code => \&sous_programme,
 into => "Finance::Shady",
 as   => 'launder',
});

Cette routine installe une référence de code donnée dans un paquet en tant que sous-programme normal. Ce qui précède est équivalent à :

no strict 'refs';
*{"Finance::Shady" . '::' . "launder"} = \&sous_programme;

Si "into" n'est pas donné, le sous-programme est installé dans le paquet appelant.

Si "code" n'est pas une référence de code, il est recherché en tant que sous-programme existant dans le paquet nommé dans le paramètre "from". Si "from" n'est pas donné, il sera recherché dans le paquet appelant.

Si "as" n'est pas donné, et si "code" est un nom, "as" sera par défaut "code". Si "as" n'est pas donné, mais si "code" est une référence de code, Sub::Install essaiera de trouver le nom de la référence de code donnée et de l'utiliser comme "as".

Cela signifie que ce code :

Sub::Install::install_sub({
  code => 'twitch',
  from => 'Person::InPain',
  into => 'Person::Teenager',
  as   => 'dance',
});

est la même chose que :

package Person::Teenager;
Sub::Install::install_sub({
  code => Person::InPain->can('twitch'),
  as   => 'dance',
});

reinstall_sub

Cette routine se comporte exactement comme "install_sub", mais n'émet pas d'avertissement si les avertissements sont activés et que la destination est déjà définie.

install_installers

Cette routine est fournie pour permettre la compatibilité de Sub::Install avec Sub::Installer. Elle installe les méthodes "install_sub" et "reinstall_sub" dans le paquet nommé par son argument.

Sub::Install::install_installers('Code::Builder'); # juste pour nous, s'il vous plaît
Code::Builder->install_sub({ name => $code_ref });
Sub::Install::install_installers('UNIVERSAL'); # vous avez de la chance, punk ?
Anything::At::All->install_sub({ name => $code_ref });

Les installateurs installés sont similaires, mais pas identiques, à ceux fournis par Sub::Installer. Ils acceptent un seul hachage comme argument. Les paires clé/valeur sont utilisées comme paramètres "as" et "code" pour la routine "install_sub" détaillée ci-dessus. Le nom du paquet sur lequel la méthode est appelée est utilisé comme paramètre "into".

Contrairement à Sub::Installer, "install_sub" n'évaluera pas de chaînes en code, mais recherchera un code nommé dans le paquet appelant.

EXPORT

Sub::Install exporte "install_sub" et "reinstall_sub" uniquement si elles sont demandées.

exportateur

Sub::Install possède une sous-routine jamais exportée appelée "exporter", qui est utilisée pour implémenter sa routine "import". Elle prend un hachage d'arguments nommés, dont un seul est actuellement reconnu : "exports". Ce doit être un tableau de sous-programmes à proposer à l'exportation.

Cette routine est principalement destinée à la propre consommation de Sub::Install. Considérez plutôt Sub::Exporter.

VOIR AUSSI

Sub::Installer
Ce module est (évidemment) une réaction à Sub::Installer de Damian Conway, qui fait la même chose, mais le fait en mettant ses doigts gras partout dans UNIVERSAL. J'étais vraiment content de l'idée de rendre l'installation des références de code moins laide, mais je n'ai pas pu me résoudre à remplacer la laideur des typeglobs et des strictures relâchées par la laideur des méthodes UNIVERSAL.
Sub::Exporter
C'est un remplacement complet de Exporter.pm, construit sur Sub::Install.
