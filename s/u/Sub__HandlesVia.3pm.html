NOM

Sub::HandlesVia - implémentation alternative de handles_via

SYNOPSIS

package Cuisine {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard qw( ArrayRef Str );

  has nourriture => (
    is          => 'ro',
    isa         => ArrayRef[Str],
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'ajouter_nourriture'    => 'push',
      'trouver_nourriture'   => 'grep',
    },
  );
}
my $cuisine = Cuisine->new;
$cuisine->ajouter_nourriture('Bacon');
$cuisine->ajouter_nourriture('Œufs');
$cuisine->ajouter_nourriture('Saucisses');
$cuisine->ajouter_nourriture('Haricots');

my @nourritures = $cuisine->trouver_nourriture(sub { /^B/i });

DESCRIPTION

Si vous avez utilisé les traits natifs des attributs de Moose, ou MooX::HandlesVia auparavant, vous devriez avoir une idée assez précise de ce que cela fait.

Pourquoi réinventer la roue ? Eh bien, c'est une implémentation qui devrait bien fonctionner avec Moo, Moose, Mouse, et tout autre toolkit OO que vous lui lancerez. Un seul anneau pour les gouverner tous, pour ainsi dire.

Pour plus de détails sur son utilisation, voir le manuel.

Note : comme Sub::HandlesVia doit détecter quel toolkit vous utilisez, et souvent s'il s'agit d'une classe ou d'un rôle, il doit être chargé *après* Moo/Moose/Mouse/etc. Votre "use Moo" ou "use Moose::Role" ou autre doit être *avant* votre "use Sub::HandlesVia".

Veuillez signaler tout bogue à https://github.com/tobyink/p5-sub-handlesvia/issues.

(Il existe des bogues connus pour les types natifs de Moose qui effectuent une coercion.)

Guides d'utilisation avec différents toolkits OO : Sub::HandlesVia::Manual::WithMoo, Sub::HandlesVia::Manual::WithMoose, Sub::HandlesVia::Manual::WithMouse, Sub::HandlesVia::Manual::WithMite, Sub::HandlesVia::Manual::WithClassTiny, Sub::HandlesVia::Manual::WithObjectPad, Sub::HandlesVia::Manual::WithGeneric.

Documentation des méthodes déléguables : Sub::HandlesVia::HandlerLibrary::Array, Sub::HandlesVia::HandlerLibrary::Blessed, Sub::HandlesVia::HandlerLibrary::Bool, Sub::HandlesVia::HandlerLibrary::Code, Sub::HandlesVia::HandlerLibrary::Counter, Sub::HandlesVia::HandlerLibrary::Enum, Sub::HandlesVia::HandlerLibrary::Hash, Sub::HandlesVia::HandlerLibrary::Number, Sub::HandlesVia::HandlerLibrary::Scalar, et Sub::HandlesVia::HandlerLibrary::String.

Autres implémentations du même concept : Moose::Meta::Attribute::Native, MouseX::NativeTraits, et MooX::HandlesVia avec Data::Perl.

Comparaison de ceux-ci : Sub::HandlesVia::Manual::Comparison

Sub::HandlesVia::Declare est une aide pour déclarer les délégations Sub::HandlesVia au moment de la compilation, utile pour Object::Pad et (dans une moindre mesure) Class::Tiny.
