NOM

Sub::Identify - Récupérer les noms des références de code

SYNOPSIS

use Sub::Identify ':all';
my $subname = sub_name( $some_coderef );
my $packagename = stash_name( $some_coderef );
# ou, pour tout obtenir en une fois...
my $fully_qualified_name = sub_fullname( $some_coderef );
defined $subname
    and say "cette référence de code pointe vers la sous-routine $subname dans le paquet $packagename";
my ($file, $line) = get_code_location( $some_coderef );
$file
    and say "cette référence de code est définie à la ligne $line dans le fichier $file";
is_sub_constant( $some_coderef )
    and say "cette référence de code pointe vers une sous-routine constante";

DESCRIPTION

"Sub::Identify" vous permet de récupérer le nom réel des références de code.

Il fournit six fonctions, toutes prenant une référence de code en argument.

"sub_name" retourne le nom de la référence de code passée en argument (ou "__ANON__" s'il s'agit d'une référence de code anonyme), "stash_name" retourne son paquet, et "sub_fullname" retourne la concaténation des deux.

"get_code_info" retourne une liste de deux éléments, le paquet et le nom de la sous-routine (au cas où vous voudriez les deux et seriez préoccupé par la vitesse.)

En cas d'alias de sous-routine, ces fonctions retournent toujours le nom d'origine.

"get_code_location" retourne une liste de deux éléments contenant le nom du fichier et le numéro de ligne où la sous-routine a été définie.

"is_sub_constant" retourne une valeur booléenne indiquant si la sous-routine est une constante ou non.

Version pure-Perl

Par défaut, "Sub::Identify" essaie de charger une implémentation XS des fonctions "get_code_info", "get_code_location" et (pour les versions Perl 5.16.0 et ultérieures) "is_sub_constant", pour des raisons de vitesse ; si cela échoue, ou si la variable d'environnement "PERL_SUB_IDENTIFY_PP" est définie sur une valeur vraie, elle se rabattra sur une implémentation pure Perl, qui utilise le mécanisme d'introspection de Perl, fourni par le module "B".
