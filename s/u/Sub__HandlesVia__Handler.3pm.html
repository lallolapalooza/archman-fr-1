Sub::HandlesVia::Handler(3) Documentation Perl contribuée par l'utilisateur Sub::HandlesVia::Handler(3)

NOM

Sub::HandlesVia::Handler - modèle pour une méthode pouvant être déléguée

DESCRIPTION

Ce module fait partie de l'API interne de Sub::HandlesVia. Il intéresse principalement les personnes qui étendent Sub::HandlesVia.

Ce module fonctionne en conjonction avec Sub::HandlesVia::CodeGenerator et les sous-classes de Sub::HandlesVia::Toolkit pour construire une chaîne de code Perl qui peut être compilée en une méthode à installer dans votre classe.

CONSTRUCTEURS

new( %attributs )

Constructeur standard de type Moose.

"lookup( $methode, $trait )"

Recherche une méthode à partir des bibliothèques de gestionnaires existantes.

my $h = Sub::HandlesVia::Handler->lookup( 'get', 'Array' );

Version curry:

my $h = Sub::HandlesVia::Handler->lookup( [ 'get', 0 ], 'Array' );

Le $trait peut être un alias de tableau de traits possibles.

EXPORT

Rien n'est exporté par défaut.

"handler %attributs"

Raccourci pour le constructeur "new".

use Sub::HandlesVia::Handler 'handler';

my $h = handler( %attr );
# est la même chose que
my $h = Sub::HandlesVia::Handler->new( %attr );

ATTRIBUTS

"nom" Str

Le nom de la fonction vers laquelle la délégation est effectuée.

"est_mutateur" Bool

Indique si ce gestionnaire peut potentiellement modifier la valeur d'un attribut. Par défaut, il tente de le détecter en analysant les modèles.

"modèle" Str

Chaîne de caractères spécialement formatée (voir la section ci-dessous) contenant le code Perl pour implémenter la méthode.

"modèle_lvaleur" Maybe[Str]

Si défini, un raccourci pour l'implémenter lorsque la valeur de la case d'attribut peut être utilisée comme lvaleur.

"args" Maybe[PositiveOrZeroInt]

Le nombre d'arguments attendus par la méthode générée (n'inclut pas la valeur de l'attribut elle-même).

"min_args" et "max_args" Maybe[PositiveOrZeroInt]

Pour les méthodes qui acceptent un nombre variable d'arguments. Si omis, par défaut à "args".

"signature" Maybe[ArrayRef[TypeTiny]]

Une signature pour lesdits arguments.

"usage" Str

Une signature à afficher dans la documentation, comme '$index, $valeur'. Si non fournie, sera générée magiquement à partir de "args", "min_args", et "max_args".

"curry" Maybe[ArrayRef[Item]]

Un alias de tableau d'arguments curry.

"est_enchainable" Bool

Indique s'il faut forcer la méthode générée à être enchaînable.

"pas_de_validation_requise" Bool

Indique s'il faut effectuer moins de validation des données d'entrée.

"défaut_pour_reset" Maybe[Str]

Si ce gestionnaire doit « réinitialiser » la valeur d'un attribut à sa valeur par défaut, et que l'attribut n'a pas de valeur par défaut, cette chaîne de code Perl est évaluée pour fournir une valeur par défaut. Un exemple pourrait être "[]".

"préférer_shift_self" Bool

Indique que ce gestionnaire préférerait que le générateur de code retire $self de @_.

"documentation" Maybe[Str]

Chaîne de caractères pod pour décrire le gestionnaire.

"_exemples" Maybe[CodeRef]

Ce coderef, s'il est appelé avec les paramètres $classe, $attribut, et $methode, générera un exemple de code à insérer dans le pod.

"validation_supplémentaire" Maybe[CodeRef]

Coderef fournissant une API légèrement agaçante. À décrire plus tard.

"autoriser_raccourcis_getters" Bool

Par défaut à vrai. Rarement utile de le remplacer.

MÉTHODES

a_min_args() et a_max_args()

Indique si ce gestionnaire a un nombre minimum ou maximum d'arguments défini.

installer_methode( %args )

Les arguments requis sont "nom_methode" et "generateur_code". Installe la méthode déléguée dans la classe cible (prise du générateur de code).

code_as_string( %args )

Mêmes arguments requis que "install_method", mais retourne le code Perl de la méthode sous forme de chaîne de caractères.

curry( @args )

Pseudo-constructeur.

Crée un nouvel objet Sub::HandlesVia::Handler comme celui-ci, mais avec les arguments donnés "curried" (pré-remplis).

"loose"

Pseudo-constructeur.

Crée un nouvel objet Sub::HandlesVia::Handler comme celui-ci, mais avec une validation d'arguments plus souple.

"chainable"

Pseudo-constructeur.

Crée un nouvel objet Sub::HandlesVia::Handler comme celui-ci, mais chaînable.

FORMAT DU MODÈLE

Le modèle est une chaîne de code Perl, sauf si les éléments spéciaux suivants y sont trouvés, auquel cas ils sont remplacés.

$SELF
L'invocant.
$SLOT
Accès direct au hachage pour l'attribut.
$GET
La valeur actuelle de l'attribut.
@ARG
Tous les arguments supplémentaires passés à la méthode déléguée.

$ARG[$n] fonctionnera également.

"#ARG"
Le nombre d'arguments supplémentaires passés à la méthode déléguée.
$ARG
Le premier élément de @ARG.
$DEFAULT
La valeur par défaut de l'attribut, si elle est connue.
"« EXPR »"
Une expression entre guillemets doubles définit la valeur de l'attribut sur l'expression.

Par exemple, un gestionnaire pour diviser par deux la valeur d'un attribut numérique pourrait être :

'Sub::HandlesVia::Handler'->new(
  name => 'MyNumber:halve',
  args => 0,
  template => '« $GET / 2 »',
  lvalue_template => '$GET /= 2',
);
