NOM

Sub::Name - Renommer (ou renommer à nouveau) une sous-routine

VERSION

version 0.28

SYNOPIS

use Sub::Name;
subname $nom, $ref_sous_routine;
$ref_sous_routine = subname foo => sub { ... };

DESCRIPTION

Ce module n'a qu'une seule fonction, qui est également exportée par défaut :

subname NOM, REF_SOUS_ROUTINE

Attribue un nouveau nom à la sous-routine référencée. Si la spécification du paquet est omise dans le nom, alors le paquet courant est utilisé. La valeur de retour est la sous-routine elle-même.

Le nom n'est utilisé que pour les routines informatives (caller, Carp, etc). Vous ne pourrez pas invoquer la sous-routine par ce nom. Pour le permettre, vous devrez effectuer vous-même une affectation par glob.

Notez que pour les fermetures anonymes (sous-routines qui référencent des lexis déclarées en dehors de la sous-routine elle-même), vous pouvez nommer chaque instance de la fermeture différemment, ce qui peut être très utile pour le débogage.

VOIR AUSSI

  • Sub::Identify - pour obtenir des informations sur les sous-routines
  • Sub::Util - set_subname est une autre implémentation de "subname"
