NOM

Sub::Exporter::Progressive - N'utilisez Sub::Exporter que si vous en avez besoin

VERSION

version 0.001013

SYNOPSIS

package Syntax::Keyword::Gather;
use Sub::Exporter::Progressive -setup => {
  exports => [qw( break gather gathered take )],
  groups => {
    default => [qw( break gather gathered take )],
  },
};
# ailleurs
# utilise Exporter pour la vitesse
use Syntax::Keyword::Gather;
# quelque part ailleurs
# utilise Sub::Exporter pour les fonctionnalités
use Syntax::Keyword::Gather 'gather', take => { -as => 'grab' };

DESCRIPTION

Sub::Exporter est un module incroyablement puissant, mais avec ce pouvoir vient une grande responsabilité, euh, ainsi que quelques pénalités d'exécution. Ce module est un wrapper "Sub::Exporter" qui permettra à vos utilisateurs d'utiliser simplement Exporter si tout ce qu'ils font est de choisir des exportations, mais d'utiliser "Sub::Exporter" si vos utilisateurs essaient d'utiliser les fonctionnalités plus avancées de "Sub::Exporter", comme le renommage des exportations, s'ils essaient de les utiliser.

Notez que ce module exportera les variables de package @EXPORT, @EXPORT_OK et %EXPORT_TAGS pour que "Exporter" puisse fonctionner. De plus, si votre package utilise les fonctionnalités avancées de "Sub::Exporter" comme le currying, ce module n'utilisera que "Sub::Exporter", vous pourriez donc aussi bien l'utiliser directement.
