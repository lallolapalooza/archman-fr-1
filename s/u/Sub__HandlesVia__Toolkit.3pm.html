NOM

Sub::HandlesVia::Toolkit - Intégration avec les frameworks POO pour Sub::HandlesVia

DESCRIPTION

Ce module fait partie de l'API interne de Sub::HandlesVia. Il intéresse principalement les personnes qui étendent Sub::HandlesVia.

Détecte quelle sous-classe de Sub::HandlesVia::Toolkit convient à une classe :

my $toolkit = Sub::HandlesVia->detect_toolkit($class);

Extrait les informations handles_via d'une table de spécification d'attribut "has" :

my $shvdata = $toolkit->clean_spec($class, $attrname, \%spec);

Cela renvoie non seulement les données dont Sub::HandlesVia a besoin, mais nettoie également %spec afin qu'elle puisse être passée à une fonction "has" de type Moose sans générer d'erreurs pour des options non reconnues.

$toolkit->install_delegations($shvdata) if $shvdata;
