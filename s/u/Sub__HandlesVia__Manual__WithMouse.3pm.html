NOM

Sub::HandlesVia::Manual::WithMouse - utilisation de Sub::HandlesVia avec Mouse

SYNOPIS

package Kitchen {
  use Mouse;
  use Sub::HandlesVia;
  use Types::Standard qw( ArrayRef Str );

  has food => (
    is          => 'ro',
    isa         => ArrayRef[Str],
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}

(Si vous avez une souris dans votre cuisine, ce n'est peut-être pas très hygiénique.)

MANUEL

Sub::HandlesVia vous permet de déléguer des méthodes de votre classe aux valeurs des attributs de vos objets.

Conceptuellement, il vous permet de définir "$object->push_number($n)" comme un raccourci pour "$object->numbers->push($n)" sauf que "$object->numbers" est un tableau, donc il n'a pas de méthodes appelables dessus comme "push".

Vous devriez pouvoir utiliser Sub::HandlesVia comme un remplacement direct pour MouseX::NativeTraits, en remplaçant simplement "traits => ['Array']" dans une définition d'attribut par "handles_via => 'Array'".

Utilisation dans les rôles Mouse

Les rôles Mouse ne sont que partiellement pris en charge.

package R1 {
  use Mouse:Role;
}

package R2 {
  use Mouse:Role;
  use Sub::HandlesVia;

  # définir certains attributs avec délégation
}

# Cette classe est cassée.
package C1 {
  use Mouse;
  with 'R1', 'R2';
}

# Cette classe devrait fonctionner.
package C2 {
  use Mouse;
  with 'R1';
  with 'R2';
}

Pour plus de détails, voir https://github.com/tobyink/p5-sub-handlesvia/issues/9.

Les correctifs pour résoudre ce problème sont les bienvenus !

Quelles méthodes peuvent être déléguées ?

L'option "handles_via" indique quelle bibliothèque de méthodes doit être disponible. Les valeurs valides comprennent Array, Blessed, Bool, Code, Counter, Enum, Hash, Number, Scalar, et String.

Un tableau peut être fourni pour "handles_via", bien que plusieurs options soient conceptuellement contradictoires.

handles_via => [ 'Number', 'Scalar' ]

Types natifs Mouse

Bien que la synopsis montre l'utilisation de Types::Standard pour les contraintes de type, les types natifs Mouse devraient également fonctionner correctement.

package Kitchen {
  use Mouse;
  use Sub::HandlesVia;

  has food => (
    is          => 'ro',
    isa         => 'ArrayRef[Str]',
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}

Véritable syntaxe de remplacement direct de MouseX::NativeTraits

Sub::HandlesVia reconnaîtra également la syntaxe de "traits" de style MouseX::NativeTraits. Il interviendra et les gérera avant que MouseX::NativeTraits ne s'en aperçoive !

package Kitchen {
  use Mouse;
  use Sub::HandlesVia;

  has food => (
    is          => 'ro',
    isa         => 'ArrayRef[Str]',
    traits      => ['Array'],
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}
