NOM

Sub::Quote - Génération efficace de sous-programmes via eval de chaînes

SYNTAXE

package Silly;
use Sub::Quote qw(quote_sub unquote_sub quoted_from_sub);
quote_sub 'Silly::kitty', q{ print "meow" };
quote_sub 'Silly::doggy', q{ print "woof" };
my $sound = 0;
quote_sub 'Silly::dagron',
  q{ print ++$sound % 2 ? 'burninate' : 'roar' },
  { '$sound' => \$sound };

Et ailleurs :

Silly->kitty;  # meow
Silly->doggy;  # woof
Silly->dagron; # burninate
Silly->dagron; # roar
Silly->dagron; # burninate

DESCRIPTION

Ce paquet fournit des moyens performants de générer des sous-programmes à partir de chaînes de caractères.

SOUS-PROGRAMMES

quote_sub

my $coderef = quote_sub 'Foo::bar', q{ print $x++ . "\n" }, { '$x' => \0 };

Arguments : ?$nom, $code, ?\%captures, ?\%options

$nom est le sous-programme auquel le coderef sera installé.

$code est une chaîne de caractères qui sera transformée en code.

"\%captures" est un hashref de variables qui seront rendues disponibles au code. Les clés doivent être le nom complet de la variable à rendre disponible, y compris le sigil. Les valeurs doivent être des références aux valeurs. Les variables contiendront des copies des valeurs. Voir la "SYNTAXE" de "Silly::dagron" pour un exemple utilisant les captures.

Exporté par défaut.

options

"no_install"
Booléen. Définissez cette option pour ne pas installer le coderef généré dans le nom du sous-programme passé lors de la déréférencement.
"no_defer"
Booléen. Empêche la génération d'un wrapper Sub::Defer pour le sous-programme cité. Si le sous-programme sera très probablement appelé à un moment donné, définir cette option est une bonne idée. Pour un sous-programme qui sera très probablement intégré, ce n'est pas recommandé.
"package"
Le paquet dans lequel le sous-programme cité sera évalué. S'il n'est pas spécifié, le paquet du sous-programme appelant "quote_sub" sera utilisé.
"hints"
La valeur de $^H à utiliser pour le code en cours d'évaluation. Cela capture les paramètres du pragma strict. S'il n'est pas spécifié, la valeur du code appelant sera utilisée.
"warning_bits"
La valeur de "${^WARNING_BITS}" à utiliser pour le code en cours d'évaluation. Cela capture les avertissements définis. S'il n'est pas spécifié, les avertissements du code appelant seront utilisés.
"hintshash"
La valeur de "%^H" à utiliser pour le code en cours d'évaluation. Cela capture les paramètres de pragma supplémentaires. S'il n'est pas spécifié, la valeur du code appelant sera utilisée si possible (sur perl 5.10+).
"attributes"
Les "Attributs de sous-programme" dans perlsub à appliquer au sous-programme généré. Doit être spécifié comme une référence de tableau. Les attributs seront appliqués au sous-programme généré et au wrapper différé, si l'un est utilisé.
"file"
Le nom de fichier apparent à utiliser pour le code en cours d'évaluation.
"line"
Le numéro de ligne apparent à utiliser pour le code en cours d'évaluation.

unquote_sub

my $coderef = unquote_sub $sub;

Remplace de force un sous-programme par du code réel.

Si $sub n'est pas un sous-programme cité, cette fonction ne fait rien.

Exporté par défaut.

quoted_from_sub

my $data = quoted_from_sub $sub;
my ($name, $code, $captures, $compiled_sub) = @$data;

Retourne les arguments d'origine de quote_sub, plus la version compilée si ce sous-programme a déjà été dé-cité.

Notez que $sub peut être soit la version citée d'origine, soit la version compilée pour plus de commodité.

Exporté par défaut.

inlinify

my $prelude = capture_unroll '$captures', {
  '$x' => 1,
  '$y' => 2,
}, 4;
my $inlined_code = inlinify q{
  my ($x, $y) = @_;
  print $x + $y . "\n";
}, '$x, $y', $prelude;

Prend une chaîne de code, une chaîne d'arguments, une chaîne de code qui agit comme un "prélude", et un Booléen indiquant si les arguments doivent être localisés.

quotify

my $quoted_value = quotify $value;

Cite une seule valeur scalaire (non-référence) pour utilisation dans une chaîne de code. Le résultat doit reproduire la valeur d'origine, y compris les chaînes, undef, les entiers et les nombres à virgule flottante. Les nombres à virgule flottante résultants (y compris les infinis et NaN) doivent être précisément égaux à l'original, si possible. Le format exact du nombre résultant ne doit pas être fiable, car il peut inclure des flottants hexadécimaux ou des expressions mathématiques.

capture_unroll

my $prelude = capture_unroll '$captures', {
  '$x' => 1,
  '$y' => 2,
}, 4;

Arguments : $from, \%captures, $indent

Génère un extrait de code adapté pour être utilisé comme prélude pour "inlinify". $from est une chaîne qui sera utilisée comme hashref dans le code résultant. Les clés de %captures sont les noms des variables et les valeurs sont ignorées. $indent est le nombre d'espaces pour indenter le résultat.

qsub

my $hash = {
 coderef => qsub q{ print "hello"; },
 other   => 5,
};

Arguments : $code

Fonctionne exactement comme "quote_sub", mais inclut un prototype pour n'accepter qu'un seul paramètre. Cela le rend plus facile à inclure dans des structures de hachage ou des listes.

Exporté par défaut.

sanitize_identifier

my $var_name = '$variable_for_' . sanitize_identifier('@name');
quote_sub qq{ print \$${var_name} }, { $var_name => \$value };

Arguments : $identifier

Nettoie une valeur pour qu'elle puisse être utilisée dans un identifiant.

ENVIRONNEMENT

SUB_QUOTE_DEBUG

Provoque la sortie du code vers "STDERR" avant d'être évalué. Plusieurs formats sont supportés :

1
Tous les sous-programmes seront affichés.
"/foo/"
Les sous-programmes seront affichés si leur code correspond à l'expression régulière donnée.
"simple_identifier"
Tout sous-programme portant le nom donné sera affiché.
"Full::identifier"
Un sous-programme correspondant au nom complet sera affiché.
"Package::Name::"
Tout sous-programme dans le paquet donné (y compris les sous-programmes anonymes) sera affiché.

CAVEATS

Une grande partie de ceci n'est que de la génération de code basée sur des chaînes, et par conséquent, quelques avertissements s'appliquent.

retour

Appeler "return" à partir d'un sous-programme cité par "quote_sub" ne fera probablement pas ce que vous attendez. Au lieu de retourner du code que vous avez défini dans "quote_sub", il retournera de la fonction globale dans laquelle il est composé.

Donc, lorsque vous passez :

quote_sub q{  return 1 if $condition; $morecode }

Il pourrait apparaître dans le contexte prévu comme suit :

sub foo {
  <important code a>
  do {
    return 1 if $condition;
    $morecode
  };
  <important code b>
}

Ce qui retournera évidemment de foo, alors que vous vouliez seulement retourner

NAME

Sub::Quote - Subroutines quoting with Lexical Scope Preservation

SYNOPSIS

 use Sub::Quote;

 sub q ($) {
   my $sub_code = shift;
   my $quoted_sub = sub { eval $sub_code };
   bless $quoted_sub, 'Sub::Quote::Sub';
   return $quoted_sub;
 };

 my $var = 10;
 my $sub = q{
   print "Hello from a quoted sub! $var\n";
 };

 $sub->(); # Prints "Hello from a quoted sub! 10"

 my $other_var = 20;
 sub q_anon (&) {
   my $sub_code = shift;
   return eval "(sub { $sub_code })";
 };

 my $anon_sub = q_anon {
   print "Anon sub: $other_var\n";
 };

 $anon_sub->(); # Prints "Anon sub: 20"

DESCRIPTION

The Sub::Quote module provides mechanisms for creating subroutines that preserve the lexical scope in which they were created. This means that variables, pragmas, and other lexical elements available when the quoted subroutine is defined will still be available when the subroutine is executed, even if the subroutine is called from a different context.

The primary interface is the q subroutine, which takes a string containing Perl code and returns a subroutine. This returned subroutine, when executed, will evaluate the provided code string within the original lexical scope.

A secondary interface, q_anon, is also provided. It takes a code string and returns an anonymous subroutine that executes the code string. This is useful for creating closures that capture lexical variables.

SUBROUTINES

q($code_string)
Takes a string containing Perl code and returns a subroutine. When this subroutine is called, it executes the code string. The execution environment (package, lexical variables, pragmas) is preserved from where q was called.
q_anon($code_string)
Similar to q, but returns a standard anonymous subroutine. This is useful for creating closures that capture lexical variables.

ENVIRONMENT

The Sub::Quote module aims to preserve the execution environment of the code that creates the quoted subs. This includes:

  • The current package
  • use strict; and use warnings; pragmas
  • Other lexical pragmas (e.g., use utf8;)
  • Lexical variables in scope

This is achieved by wrapping the provided code string in a block that recreates the original environment before executing the code.

CAVEATS

When inlining Sub::Quote subs, care should be taken that user-defined pragmas won't negatively affect the rest of the code. The module attempts to isolate the environment, but complex interactions might still occur.

The eval function is used internally, which can have performance implications and security concerns if the code_string is not trusted.

Modifying lexical variables captured by a quoted sub may have unexpected side effects if the original scope is still active or accessible.
