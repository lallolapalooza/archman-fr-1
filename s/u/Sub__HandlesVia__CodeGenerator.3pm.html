Sub::HandlesVia::CodeGenerator(3) Documentation Perl Contribuée par l'Utilisateur Sub::HandlesVia::CodeGenerator(3)

NOM

Sub::HandlesVia::CodeGenerator - examine un Handler et génère une chaîne de code Perl pour celui-ci

DESCRIPTION

Ce module fait partie de l'API interne de Sub::HandlesVia. Il intéresse principalement les personnes qui étendent Sub::HandlesVia.

Les toolkits Sub::HandlesVia créent un générateur de code pour chaque attribut qu'ils traitent, et utilisent ce générateur de code pour produire du code Perl pour une ou plusieurs méthodes déléguées.

CONSTRUCTEURS

new( %attributs )

Constructeur standard de type Moose.

ATTRIBUTS

"toolkit" Objet

Le toolkit qui a créé ce générateur de code.

"cible" NomClasse|NomRole

Le package cible pour les méthodes générées.

"package_bac_a_sable" NomClasse|NomRole|Undef

Nom du package à utiliser comme bac à sable ; la valeur par défaut est généralement correcte.

"attribut" Str|ArrayRef

L'attribut auquel on délègue.

"spec_attribut" HashRef

À titre informatif seulement.

"est_methode" Bool

Indique si le code généré doit être des méthodes plutôt que des fonctions. La valeur par défaut est vraie, et la valeur fausse n'est pas réellement testée ou bien définie.

"env" HashRef

Variables qui doivent être fermées (closed over) lors de la compilation des coderefs.

"est_un" Maybe[TypeTiny]

La contrainte de type pour l'attribut.

"coercition" Bool

L'attribut doit-il effectuer une coercition ?

"installateur_methode" CodeRef

Un coderef qui peut être appelé avec $nom_methode et $coderef, installera la méthode. Notez qu'il ne reçoit pas le package dans lequel installer (qui peut être trouvé dans "cible"), donc cela devrait être fermé.

"generateur_pour_soi" CodeRef

Un coderef qui, s'il est appelé, génère une chaîne comme '$_[0]'.

Possède une valeur par défaut raisonnable.

Toutes les méthodes "generateur_pour_XXX" sont appelées comme des méthodes, donc l'objet générateur de code est l'invocant.

"generateur_pour_slot" CodeRef

Un coderef qui, s'il est appelé, génère une chaîne comme '$_[0]{nom_attribut}'.

"generateur_pour_get" CodeRef

Un coderef qui, s'il est appelé, génère une chaîne comme '$_[0]->nom_attribut'.

"generateur_pour_set" CodeRef

Un coderef qui, s'il est appelé avec un paramètre, génère une chaîne comme "\$_[0]->\_set_nom_attribut( $parametre )".

"generateur_pour_defaut_simple" CodeRef

Un coderef qui, s'il est appelé avec un paramètre, génère une chaîne comme 'undef' ou 'q[]' ou '{}'.

Le paramètre est un objet handler, qui offre un attribut "defaut_pour_reinitialisation" qui pourrait potentiellement fournir une solution de secours utile.

"generateur_pour_args" CodeRef

Un coderef qui, s'il est appelé, génère une chaîne comme '@_[1..$#_]'.

Possède une valeur par défaut raisonnable.

"generateur_pour_nb_args" CodeRef

Un coderef qui, s'il est appelé, génère une chaîne comme '$#_'.

Possède une valeur par défaut raisonnable.

"generateur_pour_nb_args" CodeRef

Un coderef qui, s'il est appelé avec un paramètre, génère une chaîne comme "\$_[$parametre + 1]".

Possède une valeur par défaut raisonnable.

"generateur_pour_currying" CodeRef

Un coderef qui, s'il est appelé avec un paramètre, génère une chaîne comme "splice(\@_,1,0,$parametre);".

Possède une valeur par défaut raisonnable.

"generateur_pour_chaine_utilisation" CodeRef

La valeur par défaut est le coderef suivant :

sub {
  @_==3 or die;
  shift;
  my $nom_methode = shift;
  my $entrailles = shift;
  return "\$instance->$nom_methode($entrailles)";
}

"generateur_pour_assertion_type" CodeRef

Appelé comme méthode et reçoit un environnement de compilation hashref, une contrainte de type, et un nom de variable. Génère du code pour affirmer que la valeur de la variable respecte la contrainte de type, avec coercition si applicable.

"generateur_pour_erreur"

Sub::HandlesVia::CodeGenerator(3pm) — Générateur de code pour les gestionnaires

NOM

Sub::HandlesVia::CodeGenerator - Générateur de code pour les gestionnaires

DESCRIPTION

Cette classe est utilisée pour générer le code qui sera exécuté lorsque les méthodes qui manipulent les attributs seront appelées.

Elle est généralement utilisée en interne par Sub::HandlesVia.

Les méthodes de génération de code retournent des chaînes de caractères Perl qui peuvent être compilées et exécutées.

"generator_for_error( $error_message )" CodeRef

Appelé comme une méthode et passé une chaîne Perl qui est une expression évaluant à un message d'erreur. Génère du code pour déclencher l'erreur.

"generator_for_prelude" CodeRef

Par défaut, c'est un coderef retournant la chaîne vide. Peut être utilisé pour générer des instructions supplémentaires qui seront insérées en haut de la méthode en cours de génération. (Typiquement après les vérifications de paramètres, mais avant de faire quoi que ce soit de sérieux.) Cela peut être utilisé pour déverrouiller un attribut en lecture seule, par exemple.

"get_is_lvalue" Bool

Indique si le code généré par "generator_for_get" sera utilisable comme lvalue.

"set_checks_isa" Bool

Indique si le code généré par "generator_for_set" effectuera des vérifications de type.

"set_strictly" Bool

Indique si nous voulons nous assurer que le setter est toujours appelé, et que nous ne devrions pas essayer de le contourner, même si nous avons un getter lvalue.

MÉTHODES

Pour chaque attribut "generator_for_XXX", il existe une méthode correspondante "generate_XXX" pour appeler réellement le coderef, éventuellement en incluant un traitement supplémentaire.

"generate_and_install_method( $method_name, $handler )"

Étant donné un gestionnaire et un nom de méthode, générera un coderef pour le gestionnaire et l'installera dans le package cible.

"generate_coderef_for_handler( $method_name, $handler )"

Comme ci-dessus, mais retourne simplement le coderef plutôt que de l'installer.

"install_method( $method_name, $coderef )"

Installe un coderef dans le package cible avec le nom donné.
