Sub::Info(3) Documentation Perl fournie par l'utilisateur Sub::Info(3)

NOM

Sub::Info - Outil pour inspecter les sous-programmes.

DESCRIPTION

Outil pour inspecter les sous-programmes.

EXPORTATIONS

Toutes les exportations sont optionnelles, vous devez spécifier les sous-programmes à importer.

mon $hr = sub_info(\&code)
mon $hr = sub_info(\&code, @numeros_lignes)
Ceci retourne un hashref avec des informations sur le sous-programme : 
{
    ref        => \&code,
    cobj       => $cobj,
    name       => "Some::Mod::code",
    file       => "Some/Mod.pm",
    package    => "Some::Mod",
    # Note : Celles-ci ont été ajustées sur la base de conjectures.
    start_line => 22,
    end_line   => 42,
    lines      => [22, 42],
    # Ce n'est pas un bug, ces lignes sont différentes !
    all_lines  => [23, 25, ..., 39, 41],
};
$info->{ref} => \&code
C'est le sous-programme original passé à sub_info().
$info->{cobj} => $cobj
C'est la représentation objet C du coderef.
$info->{name} => "Some::Mod::code"
C'est le nom du coderef. Pour les coderefs anonymes, cela peut se terminer par '__ANON__'. Notez également que le paquet 'main' est spécial, et 'main::' peut être omis.
$info->{file} => "Some/Mod.pm"
Le fichier dans lequel le sous-programme a été défini.
$info->{package} => "Some::Mod"
Le paquet dans lequel le sous-programme a été défini.
$info->{start_line} => 22
$info->{end_line} => 42
$info->{lines} => [22, 42]
Ces trois champs sont la ligne de début, la ligne de fin et le tableau contenant les deux, *ajustés*. Il est important de noter que ces lignes ont été ajustées et peuvent ne pas être exactes.

Les lignes sont obtenues en parcourant les ops. Ainsi, la première ligne est la ligne de la première instruction, et la dernière ligne est la ligne de la dernière instruction. Cela signifie que dans les sous-programmes multi-lignes, les lignes sont généralement décalées de 1. Les lignes dans ces clés seront ajustées pour vous si un sous-programme multi-lignes est détecté.

$info->{all_lines} => [23, 25, ..., 39, 41]
C'est un tableau contenant les lignes de chaque instruction du sous-programme. Contrairement aux autres champs de ligne, ceux-ci n'ont pas été ajustés pour vous.
