Sub::Defer(3) Documentation Perl fournie par l'utilisateur Sub::Defer(3)

NOM

Sub::Defer - Différer la génération de sous-routines jusqu'à ce qu'elles soient appelées pour la première fois

SYNTAXE

use Sub::Defer;
my $deferred = defer_sub 'Logger::time_since_first_log' => sub {
   my $t = time;
   sub { time - $t };
};
 Logger->time_since_first_log; # renvoie 0 et se remplace
 Logger->time_since_first_log; # renvoie time - $t

DESCRIPTION

Ces sous-routines fournissent à l'utilisateur un moyen pratique de différer la création de sous-routines et de méthodes jusqu'à ce qu'elles soient appelées pour la première fois.

SOUS-ROUTINES

defer_sub

my $coderef = defer_sub $name => sub { ... }, \%options;

Cette sous-routine renvoie un coderef qui encapsule la sous-routine fournie. Lorsqu'elle est appelée pour la première fois, la sous-routine fournie est appelée et on s'attend à ce qu'elle renvoie elle-même une sous-routine vers laquelle les appels ultérieurs seront redirigés.

Si un nom est fourni, cela installe également la sous-routine sous ce nom. Lors de la levée du différé, la version finale sera réinstallée pour la vitesse.

Exportée par défaut.

Options

Un hachage d'options peut éventuellement être spécifié.

package
Le paquet dans lequel générer la sous-routine. Sera remplacé par une option $name entièrement qualifiée. Si non spécifié, utilisera le paquet de l'appelant par défaut.
attributes
Les "Attributs de sous-routine" dans perlsub à appliquer à la sous-routine générée. Doit être spécifié comme une référence de tableau.

undefer_sub

my $coderef = undefer_sub \&Foo::name;

Si le coderef passé a été différé, cela lèvera le différé. Si le coderef passé n'a pas été différé, il sera simplement renvoyé.

Si cela est confus, consultez l'exemple dans la section "SYNTAXE".

Exportée par défaut.

defer_info

my $data = defer_info $sub;
my ($name, $generator, $options, $undeferred_sub) = @$data;

Renvoie les arguments d'origine à defer_sub, ainsi que la version levée du différé si cette sous-routine a déjà été levée.

Notez que $sub peut être soit la version différée d'origine, soit la version levée du différé pour plus de commodité.

Non exportée par défaut.

undefer_all

undefer_all();

Cela lèvera le différé de toutes les sous-routines différées en une seule fois. Cela peut être très utile dans un environnement de fork où chaque processus enfant devrait lever le différé des mêmes sous-routines. En appelant ceci juste avant de commencer à créer des processus enfants, vous pouvez lever le différé de toutes les sous-routines actuellement différées dans le processus parent afin que les processus enfants n'aient pas à le faire. Notez que cela peut intégrer le comportement de certaines sous-routines dont le comportement était prévu pour être calculé plus tard, elle ne doit donc pas être utilisée au milieu du chargement d'un module ou de la définition d'une classe.

Exportée par défaut.

undefer_package

undefer_package($package);

Cela lèvera le différé de toutes les sous-routines différées dans un paquet.

Non exportée par défaut.
