Sub::HandlesVia::HandlerLibrary::Number(3) Documentation Perl fournie par l'utilisateur Sub::HandlesVia::HandlerLibrary::Number(3)

NOM

Sub::HandlesVia::HandlerLibrary::Number - bibliothèque de méthodes liées aux nombres

SYNOPSIS

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Num';
  has attr => (
    is => 'rwp',
    isa => Num,
    handles_via => 'Number',
    handles => {
      'my_abs' => 'abs',
      'my_add' => 'add',
      'my_ceil' => 'ceil',
      'my_cmp' => 'cmp',
      'my_div' => 'div',
      'my_eq' => 'eq',
      'my_floor' => 'floor',
      'my_ge' => 'ge',
      'my_get' => 'get',
      'my_gt' => 'gt',
      'my_le' => 'le',
      'my_lt' => 'lt',
      'my_mod' => 'mod',
      'my_mul' => 'mul',
      'my_ne' => 'ne',
      'my_set' => 'set',
      'my_sub' => 'sub',
    },
  );
}

DESCRIPTION

Ceci est une bibliothèque de méthodes pour Sub::HandlesVia.

MÉTHODES DÉLÉGUABLES

abs()

Trouve la valeur absolue du nombre courant, met à jour l'attribut.

my $object = My::Class->new( attr => -5 );
$object->my_abs;
say $object->attr; ## ==> 5

add( $addend )

Arguments : Num.

Ajoute un nombre au nombre existant, met à jour l'attribut.

my $object = My::Class->new( attr => 4 );
$object->my_add( 5 );
say $object->attr; ## ==> 9

ceil()

Trouve le plafond du nombre courant, met à jour l'attribut. Similaire à "ceil" de builtin, mais en place.

cmp( $num )

Arguments : Num.

Retourne "$object->attr <=> $num".

div( $divisor )

Arguments : Num.

Divise le nombre existant par un nombre, met à jour l'attribut.

my $object = My::Class->new( attr => 6 );
$object->my_div( 2 );
say $object->attr; ## ==> 3

eq( $num )

Arguments : Num.

Retourne "$object->attr == $num".

floor()

Trouve le plancher du nombre courant, met à jour l'attribut. Similaire à "floor" de builtin, mais en place.

ge( $num )

Arguments : Num.

Retourne "$object->attr >= $num".

get()

Retourne la valeur actuelle du nombre.

my $object = My::Class->new( attr => 4 );
say $object->my_get; ## ==> 4

gt( $num )

Arguments : Num.

Retourne "$object->attr > $num".

le( $num )

Arguments : Num.

Retourne "$object->attr <= $num".

lt( $num )

Arguments : Num.

Retourne "$object->attr < $num".

mod( $divisor )

Arguments : Num.

Trouve le nombre courant modulo un diviseur, met à jour l'attribut.

my $object = My::Class->new( attr => 5 );
$object->my_mod( 2 );
say $object->attr; ## ==> 1

mul( $factor )

Arguments : Num.

Multiplie le nombre existant par un nombre, met à jour l'attribut.

my $object = My::Class->new( attr => 2 );
$object->my_mul( 5 );
say $object->attr; ## ==> 10

ne( $num )

Arguments : Num.

Retourne "$object->attr != $num".

set( $value )

Arguments : Num.

Définit le nombre à une nouvelle valeur.

my $object = My::Class->new( attr => 4 );
$object->my_set( 5 );
say $object->attr; ## ==> 5

sub( $subtrahend )

Arguments : Num.

Soustrait un nombre du nombre existant, met à jour l'attribut.

my $object = My::Class->new( attr => 9 );
$object->my_sub( 6 );
say $object->attr; ## ==> 3
