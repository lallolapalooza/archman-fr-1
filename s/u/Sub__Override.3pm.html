Sub::Override(3) Documentation Perl Contribuée par l'Utilisateur Sub::Override(3)

NOM

Sub::Override - Extension Perl pour outrepasser facilement des sous-routines

VERSION

0.12

SYNOPSIS

use Sub::Override;
sub foo { 'sous-routine originale' };
print foo(); # affiche 'sous-routine originale'
my $override = Sub::Override->new( foo => sub { 'sous-routine outrepassée' } );
print foo(); # affiche 'sous-routine outrepassée'
$override->restore;
print foo(); # affiche 'sous-routine originale'

DESCRIPTION

Le problème

Parfois, des sous-routines doivent être outrepassées. En fait, votre auteur le fait fréquemment pour les tests. En particulier lors des tests, l'utilisation d'un objet mock peut être excessive lorsqu'il s'agit simplement d'outrepasser une petite fonction.

Outrepasser une sous-routine est souvent fait avec une syntaxe similaire à ce qui suit.

{
  local *Some::sub = sub {'comportement quelconque'};
  # faire quelque chose
}
# comportement de sous-routine original restauré

Cela présente quelques problèmes.

{
  local *Get::some_feild = { 'comportement quelconque' };
  # faire quelque chose
}

Dans l'exemple ci-dessus, non seulement nous avons probablement mal orthographié le nom de la sous-routine, mais même s'il y avait eu une sous-routine de ce nom, nous ne l'avons pas outrepassée. Ces deux erreurs peuvent être subtiles à détecter.

De plus, si nous tentons de localiser l'effet en plaçant ce code dans un bloc, toute la construction est fastidieuse.

Hook::LexWrap nous permet également d'outrepasser le comportement des sous-routines, mais je n'arrive jamais à me souvenir de la syntaxe exacte.

Une manière plus facile de remplacer des sous-routines

Au lieu de cela, "Sub::Override" permet au programmeur de simplement nommer la sous-routine à remplacer et de fournir une sous-routine pour la remplacer.

my $override = Sub::Override->new('Some::sub', sub {'nouvelles données'});
# ce qui est équivalent à :
my $override = Sub::Override->new;
$override->replace('Some::sub', sub { 'nouvelles données' });

Vous pouvez remplacer plusieurs sous-routines, si nécessaire :

$override->replace('Some::sub1', sub { 'nouvelles données1' });
$override->replace('Some::sub2', sub { 'nouvelles données2' });
$override->replace('Some::sub3', sub { 'nouvelles données3' });

Si le remplacement de la sous-routine réussit, l'objet est retourné. Cela permet au programmeur de chaîner les appels, si ce style de programmation est préféré :

$override->replace('Some::sub1', sub { 'nouvelles données1' })
         ->replace('Some::sub2', sub { 'nouvelles données2' })
         ->replace('Some::sub3', sub { 'nouvelles données3' });

Si la sous-routine a un prototype, la nouvelle sous-routine doit être déclarée avec le même prototype que l'originale :

$override->replace('Some::sub_with_proto', sub ($$) { ($_[0], $_ [1]) });

Une sous-routine peut être remplacée autant de fois que désiré. Ceci est surtout utile pour tester le comportement du code avec plusieurs conditions.

$override->replace('Some::thing', sub { 0 });
is($object->foo, 'wibble', 'wibble est retourné si Some::thing est faux');
$override->replace('Some::thing', sub { 1 });
is($object->foo, 'puppies', 'des chiots sont retournés si Some::thing est vrai');

Injection d'une sous-routine

Si vous souhaitez injecter une sous-routine dans un paquet, vous pouvez utiliser la méthode inject(). Ceci est identique à replace(), sauf qu'elle exige que la sous-routine n'existe pas :

$override->inject('Some::sub', sub {'nouvelles données'});

Ceci est utile si vous souhaitez ajouter une sous-routine à un paquet qui n'en a pas déjà.

Si vous tentez d'injecter une sous-routine qui existe déjà, une exception sera levée.

$override->inject('Some::sub', sub {'nouvelles données'}); # fonctionne
$override->inject('Some::sub', sub {'nouvelles données'}); # lève une exception

Appeler restore() ou laisser $override sortir de portée supprimera la sous-routine injectée.

$override->inject('Some::sub', sub {'nouvelles données'});
$override->restore('Some::sub'); # supprime la sous-routine injectée

Héritage d'une sous-routine

Similaire à 'inject', 'inherit' vous permettra uniquement de créer une nouvelle sous-routine sur un objet enfant qui hérite de la routine du parent, et qui n'existe pas dans l'enfant :

package Parent;
sub foo {}
sub bar {}
package Child;
use parent 'Parent';
sub foo {}

'Inherit' vous permettra de configurer une nouvelle sous-routine 'Child::bar' car elle est héritée de Parent. Tenter d' 'inherit' 'Child::foo' lèvera une exception car 'foo' existe déjà dans Child. De même, tenter d' 'inherit' une nouvelle sous-routine 'something' dans Child lèvera également une exception car elle n'existe pas dans Parent et ne sera pas héritée par Child.

Enveloppement d'une sous-routine

Il peut arriver que vous souhaitiez remplacer une sous-routine de manière 'conditionnelle' - par exemple, pour outrepasser la sous-routine originale uniquement si certains arguments sont passés. Pour cela, vous pouvez spécifier "wrap" au lieu de "replace". "wrap" est identique à "replace", sauf que la sous-routine originale est passée comme premier argument à votre nouvelle sous-routine. Vous pouvez appeler la sous-routine originale via 'shift->(@_)' :

$override->wrap('Some::sub',
  sub {
    my ($old_sub, @args) = @_;
    return 1 if $args[0];
    return $old_sub->(@args);
  }
);

Restauration des sous-routines

Si l'objet sort de portée, les sous-routines originales sont restaurées. Cependant, si vous avez besoin de restaurer une sous-routine plus tôt, utilisez simplement la méthode restore() :

my $override = Sub::Override->new('Some::sub', sub {'nouvelles données'});
# faire des choses
$override->restore;

Ce qui est en quelque sorte équivalent à :

{
  my $override = Sub::Override->new('Some::sub', sub {'nouvelles données'});
  # faire des choses
}

Si vous avez outrepassé plusieurs sous-routines avec un objet d'outrepassation, vous devrez explicitement nommer la sous-routine que vous souhaitez restaurer :

$override->restore('This::sub');

Notez que restore() restaurera toujours le comportement original de la sous-routine, peu importe le nombre de fois où vous l'avez outrepassée.

Dans quel paquet se trouve la sous-routine ?

Habituellement, vous voulez qualifier complètement la sous-routine en incluant le nom du paquet. Cependant, l'absence de qualification complète du nom de la sous-routine suppose le paquet courant.

package Foo;
use Sub::Override;
sub foo { 23 };
my $override = Sub::Override->new( foo => sub { 42 } ); # suppose Foo::foo
print foo(); # affiche 42
$override->restore;
print foo(); # affiche 23

MÉTHODES

new

my $sub = Sub::Override->new;
my $sub = Sub::Override->new($nom_sous_routine, $ref_sous_routine);

Crée une nouvelle instance de "Sub::Override". Optionnellement, vous pouvez outrepasser une sous-routine lors de la création d'un nouvel objet.

replace

$sub->replace($nom_sous_routine, $corps_sous_routine);

Remplace temporairement une sous-routine par une autre. Retourne l'instance, de sorte que chaîner la méthode est autorisé :

$sub->replace($nom_sous_routine, $corps_sous_routine)
    ->replace($autre_sous_routine, $autre_corps_sous_routine);

Cette méthode va "croak" si la sous-routine à remplacer n'existe pas.

override

my $sub = Sub::Override->new;
$sub->override($nom_sous_routine, $corps_sous_routine);

"override" est un nom alternatif pour "replace". Ce sont la même méthode.

inject

$sub->inject($nom_sub, $corps_sub);

Injecte temporairement une sous-routine dans un package. Retourne l'instance, donc le chaînage de la méthode est autorisé :

$sub->inject($nom_sub, $corps_sub)
    ->inject($autre_sub, $autre_corps);

inherit

$sub->inherit($nom_sub, $corps_sub);

Vérifie que la sous-routine existe dans une classe parente, mais pas dans la classe actuelle, et l'injecte dans la classe actuelle pour hériter de la version du parent.

restore

$sub->restore($nom_sub);

Restaure le comportement précédent de la sous-routine. Cela se produira automatiquement si l'objet "Sub::Override" sort de la portée.

wrap

$sub->wrap($nom_sub, $corps_sub);

Enveloppe temporairement une sous-routine avec une autre sous-routine. La sous-routine originale est passée comme premier argument à la nouvelle sous-routine.

EXPORT

Aucun par défaut.

CAVEATS

Si vous avez besoin de remplacer la même sub plusieurs fois, ne créez pas un nouvel objet "Sub::Override", mais réutilisez toujours celui existant et appelez "replace" dessus. Créer un nouvel objet pour remplacer la même sub entraînera un comportement étrange.

# Ne faites pas ça !
my $sub_premier = Sub::Override->new( 'Foo:bar' => sub { 'premier' } );
my $sub_second = Sub::Override->new( 'Foo::bar' => sub { 'second' } );
# Ne faites pas ça non plus !
my $sub = Sub::Override->new( 'Foo::bar' => sub { 'premier' } );
$sub = Sub::Override->new( 'Foo::bar' => sub { 'second' } );

Ces deux utilisations pourraient entraîner la perte de vos subs, selon l'ordre dans lequel vous les restaurez.

Au lieu de cela, appelez "replace" sur le $sub existant.

my $sub = Sub::Override->new( 'Foo::bar' => sub { 'premier' } );
$sub->replace( 'Foo::bar' => sub { 'second' } );
