Sub::HandlesVia::HandlerLibrary::Counter(3) Documentation Perl fournie par l'utilisateur Sub::HandlesVia::HandlerLibrary::Counter(3)

NOM

Sub::HandlesVia::HandlerLibrary::Counter - bibliothèque de méthodes liées aux compteurs

SYNTAXE

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Int';
  has attr => (
    is => 'rwp',
    isa => Int,
    handles_via => 'Counter',
    handles => {
      'my_dec' => 'dec',
      'my_inc' => 'inc',
      'my_reset' => 'reset',
      'my_set' => 'set',
    },
  );
}

DESCRIPTION

Ceci est une bibliothèque de méthodes pour Sub::HandlesVia.

MÉTHODES DÉLÉGUABLES

dec( $montant? )

Arguments : Optionnel[Int].

Décrémente le compteur de $montant, ou de 1 si aucune valeur n'est donnée.

my $object = My::Class->new( attr => 10 );
$object->my_dec;
$object->my_dec;
say $object->attr; ## ==> 8
$object->my_dec( 5 );
say $object->attr; ## ==> 3

inc( $montant? )

Arguments : Optionnel[Int].

Incrémente le compteur de $montant, ou de 1 si aucune valeur n'est donnée.

my $object = My::Class->new( attr => 0 );
$object->my_inc;
$object->my_inc;
say $object->attr; ## ==> 2
$object->my_inc( 3 );
say $object->attr; ## ==> 5

reset()

Met le compteur à sa valeur par défaut, ou à 0 s'il n'a pas de valeur par défaut.

my $object = My::Class->new( attr => 10 );
$object->my_reset;
say $object->attr; ## ==> 0

set( $valeur )

Arguments : Int.

Définit le compteur à la valeur donnée.

my $object = My::Class->new( attr => 0 );
$object->my_set( 5 );
say $object->attr; ## ==> 5
