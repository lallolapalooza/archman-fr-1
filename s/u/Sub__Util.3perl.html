Sub::Util(3perl) Guide de référence du programmeur Perl Sub::Util(3perl)

NOM

Sub::Util - Une sélection de sous-routines utilitaires pour les sous-programmes et les références CODE

SYNTAXE

use Sub::Util qw( prototype set_prototype subname set_subname );

DESCRIPTION

"Sub::Util" contient une sélection de sous-routines utilitaires qui sont utiles pour opérer sur les sous-programmes et les références CODE.

La raison de l'inclusion dans ce module est que la fonction effectue un travail pour lequel une implémentation XS est essentielle car elle ne peut pas être implémentée en Perl pur, et qui est suffisamment largement utilisé sur CPAN pour que sa popularité justifie son inclusion dans un module de base, ce qu'il est.

FONCTIONS

prototype

my $proto = prototype( $code )

Depuis la version 1.40.

Retourne le prototype de la référence $code donnée, si elle en a un, sous forme de chaîne. Ceci est identique à l'opérateur "CORE::prototype" ; il est inclus ici simplement pour la symétrie et la complétude avec les autres fonctions.

set_prototype

my $code = set_prototype $prototype, $code;

Depuis la version 1.40.

Définit le prototype de la fonction donnée par la référence $code, ou le supprime si $prototype est "undef". Retourne la référence $code elle-même.

Attention : Cette fonction prend les arguments dans un ordre différent de la copie précédente du code de "Scalar::Util". Ceci afin de correspondre à l'ordre de "set_subname", et d'autres ajouts potentiels dans ce fichier. Cet ordre a été choisi car il permet un chaînage simple et soigné d'autres fonctions "Sub::Util::set_*" qui pourraient devenir disponibles, comme :

my $code =
   set_subname   name_here =>
   set_prototype '&@'      =>
   set_attribute ':lvalue' =>
      sub { ...... };

subname

my $name = subname( $code )

Depuis la version 1.40.

Retourne le nom de la référence $code donnée, si elle en a un. Les sous-programmes nommés normaux donneront un nom complètement qualifié composé du paquet et du nom local séparés par "::". Les références de code anonymes donneront "__ANON__" comme nom local. Si le paquet dans lequel le code a été compilé a été supprimé (par exemple en utilisant "delete_package" de Symbol), "__ANON__" sera retourné comme nom de paquet. Si un nom a été défini à l'aide de "set_subname", ce nom sera retourné à la place.

Cette fonction a été inspirée par "sub_fullname" de Sub::Identify. Les autres fonctions que "Sub::Identify" implémente peuvent facilement être émules en utilisant des opérations regexp, comme

sub get_code_info { return (subname $_[0]) =~ m/^(.+)::(.*?)$/ }
sub sub_name      { return (get_code_info $_[0])[0] }
sub stash_name    { return (get_code_info $_[0])[1] }

Utilisateurs de Sub::Name, attention : Cette fonction n'est **pas** la même que "Sub::Name::subname" ; elle retourne le nom existant du sous-programme plutôt que de le changer. Pour définir ou changer un nom, voir plutôt "set_subname".

set_subname

my $code = set_subname $name, $code;

Depuis la version 1.40.

Définit le nom de la fonction donnée par la référence $code. Retourne la référence $code elle-même. Si le $name n'est pas qualifié, le paquet de l'appelant est utilisé pour le qualifier.

Ceci est utile pour appliquer des noms à des références CODE anonymes afin que les traces de pile et situations similaires donnent un nom utile plutôt que le défaut de "__ANON__". Notez que ce nom n'est utilisé que pour cette situation ; "set_subname" ne l'installera pas dans la table des symboles ; vous devrez le faire vous-même si nécessaire.

Cependant, comme le nom n'est pas utilisé par perl sauf comme valeur de retour de "caller", pour les traces de pile ou similaires, il n'y a pas d'exigence réelle que le nom soit syntaxiquement valide en tant que nom de fonction perl. Ceci pourrait être utilisé pour attacher des informations supplémentaires qui pourraient être utiles dans le débogage des traces de pile.

Cette fonction a été copiée de "Sub::Name::subname" et renommée selon la convention de nommage de ce module.
