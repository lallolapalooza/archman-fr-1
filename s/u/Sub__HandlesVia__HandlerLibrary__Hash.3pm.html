Sub::HandlesVia::HandlerLibrary::Hash(3) Documentation Perl Contribuée par l'Utilisateur Sub::HandlesVia::HandlerLibrary::Hash(3)

NOM

Sub::HandlesVia::HandlerLibrary::Hash - bibliothèque de méthodes liées aux hachages

SYNOPSIS

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'HashRef';
  has attr => (
    is => 'rwp',
    isa => HashRef,
    handles_via => 'Hash',
    handles => {
      'my_accessor' => 'accessor',
      'my_all' => 'all',
      'my_clear' => 'clear',
      'my_count' => 'count',
      'my_defined' => 'defined',
      'my_delete' => 'delete',
      'my_delete_where' => 'delete_where',
      'my_elements' => 'elements',
      'my_exists' => 'exists',
      'my_for_each_key' => 'for_each_key',
      'my_for_each_pair' => 'for_each_pair',
      'my_for_each_value' => 'for_each_value',
      'my_get' => 'get',
      'my_is_empty' => 'is_empty',
      'my_keys' => 'keys',
      'my_kv' => 'kv',
      'my_reset' => 'reset',
      'my_set' => 'set',
      'my_shallow_clone' => 'shallow_clone',
      'my_sorted_keys' => 'sorted_keys',
      'my_values' => 'values',
    },
  );
}

DESCRIPTION

Ceci est une bibliothèque de méthodes pour Sub::HandlesVia.

MÉTHODES DÉLÉGUABLES

"accessor( $key, $value? )"

Arguments : Str, Optional[Any].

Agit comme "get" si une clé seule est fournie, ou comme "set" si une clé et une valeur sont fournies.

all()

Renvoie le hachage en contexte liste.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
my %hash = $object->my_all;

clear()

Vide le hachage.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
$object->my_clear;
say exists $object->attr->{foo}; ## ==> faux
say exists $object->attr->{bar}; ## ==> faux

count()

Renvoie le nombre de clés dans le hachage.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
say $object->my_count; ## ==> 2

defined( $key )

Arguments : Str.

Indique si une valeur existe et est définie dans le hachage via sa clé.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
say $object->my_defined( 'foo' ); ## ==> 1

delete( $key )

Supprime une valeur du hachage via sa clé.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
$object->my_delete( 'foo' );
say exists $object->attr->{foo}; ## ==> faux

delete_where( $match )

Arguments : CodeRef|RegexpRef.

Supprime des valeurs du hachage en faisant correspondre les clés à une fonction de rappel ou une expression régulière.

my $object = My::Class->new( attr => { foo => 0, bar => 1, baz => 2 } );
$object->my_delete_where( sub { $_ eq 'foo' or $_ eq 'bar' } );
say Dumper( $object->attr ); ## ==> { baz => 2 }

my $object2 = My::Class->new( attr => { foo => 0, bar => 1, baz => 2 } );
$object2->my_delete_where( qr/^b/ );
say Dumper( $object2->attr ); ## ==> { foo => 0 }

elements()

Renvoie le hachage en contexte liste.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
my %hash = $object->my_elements;

exists( $key )

Arguments : Str.

Indique si une valeur existe dans le hachage via sa clé.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
say $object->my_exists( 'foo' ); ## ==> vrai
say $object->my_exists( 'baz' ); ## ==> faux

for_each_key( $coderef )

Arguments : CodeRef.

Méthode chaînable qui appelle la fonction de rappel pour chaque clé du hachage, en passant uniquement la clé à la fonction de rappel.

for_each_pair( $coderef )

Arguments : CodeRef.

Méthode chaînable qui appelle la fonction de rappel pour chaque clé du hachage, en passant la clé et la valeur à la fonction de rappel.

for_each_value( $coderef )

Arguments : CodeRef.

Méthode chaînable qui appelle la fonction de rappel pour chaque valeur du hachage, en passant uniquement la valeur à la fonction de rappel.

get( $key )

Renvoie une valeur du hachage via sa clé.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
say $object->my_get( 'bar' ); ## ==> 1

is_empty()

Renvoie vrai si et seulement s'il n'y a aucune clé dans le hachage.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
say $object->my_is_empty; ## ==> faux
$object->_set_attr( {} );
say $object->my_is_empty; ## ==> vrai

keys()

Renvoie la liste des clés dans le hachage.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
# affiche 'foo' et 'bar' dans un ordre imprévisible
say for $object->my_keys;

kv()

Renvoie une liste d'arrayrefs, où chaque arrayref est une paire clé-valeur.

reset()

Réinitialise l'attribut à sa valeur par défaut, ou à un hachage vide s'il n'a pas de valeur par défaut.

"set( $key, $value, ... )"

Étant donné une clé et une valeur, ajoute la clé au hachage avec la valeur donnée.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
$object->my_set( bar => 2, baz => 1 );
say $object->attr->{foo}; ## ==> 0
say $object->attr->{baz}; ## ==> 1
say $object->attr->{bar}; ## ==> 2

shallow_clone()

Crée un nouveau hachage avec les mêmes clés et valeurs que l'original.

sorted_keys()

Renvoie une liste triée alphabétiquement des clés dans le hachage.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
# affiche 'bar' puis 'foo'
say for $object->my_sorted_keys;

values()

Renvoie la liste des valeurs dans le hachage.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
# affiche '0' et '1' dans un ordre imprévisible
say for $object->my_values;

Sub::HandlesVia.

Sub::HandlesVia::HandlerLibrary::Hash(3pm)

NOM

Sub::HandlesVia::HandlerLibrary::Hash - Gestionnaire pour les méthodes qui renvoient un Hachage.

SYNTAXE

  use Sub::HandlesVia::HandlerLibrary::Hash;

  package MyPackage;

  sub my_hash_method : HandlesVia(Hash);

  sub other_hash_method : HandlesVia(Hash);

DESCRIPTION

Ce gestionnaire permet à une méthode de renvoyer une référence à un Hachage. Les méthodes qui renvoient des Hachages sont appelées, et le résultat est renvoyé.

Ceci est utile lorsque vous souhaitez qu'une méthode crée ou récupère un Hachage, et que vous souhaitez que cet Hachage soit directement utilisable dans un contexte où des Hachages sont attendus.

METHODES DELEGATABLES

Comme ce gestionnaire renvoie un Hachage, toutes les méthodes accessibles directement sur un Hachage peuvent être appelées sur l'objet résultant.

Par exemple, si my_hash_method renvoie un Hachage, vous pouvez appeler des méthodes de Hachage directement dessus :

  my $obj = MyPackage->new;
  my $value = $obj->my_hash_method->{some_key};

En fait, vous n'avez même pas besoin de l'opérateur flèche dans ce cas:

  my $value = $obj->my_hash_method->{some_key};

Ce qui suit fonctionnera également, car la méthode fetch est appelée sur le Hachage renvoyé:

  my $value = $obj->my_hash_method->fetch('some_key');

BOGUES

Aucun bogues connu.
