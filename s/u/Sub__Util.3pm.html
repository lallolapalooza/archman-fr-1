Sub::Util(3) Documentation Perl fournie par l'utilisateur Sub::Util(3)

NOM

Sub::Util - Une sélection de sous-routines utilitaires pour les sous et références CODE

SYNTAXE

use Sub::Util qw( prototype set_prototype subname set_subname );

DESCRIPTION

"Sub::Util" contient une sélection de sous-routines utilitaires qui sont utiles pour opérer sur les sous et les références CODE.

La raison d'inclure ceci dans ce module est que la fonction effectue un travail pour lequel une implémentation XS est essentielle car elle ne peut pas être implémentée en Perl pur, et qui est suffisamment utilisé sur CPAN pour que sa popularité justifie son inclusion dans un module de base, ce qu'il est.

FONCTIONS

prototype

my $proto = prototype( $code )

Depuis la version 1.40.

Retourne le prototype de la référence $code donnée, si elle en a un, sous forme de chaîne. C'est la même chose que l'opérateur "CORE::prototype" ; il est inclus ici simplement pour la symétrie et la complétude avec les autres fonctions.

set_prototype

my $code = set_prototype $prototype, $code;

Depuis la version 1.40.

Définit le prototype de la fonction donnée par la référence $code, ou le supprime si $prototype est "undef". Retourne la référence $code elle-même.

Attention : Cette fonction prend les arguments dans un ordre différent de la copie précédente du code depuis "Scalar::Util". C'est pour correspondre à l'ordre de "set_subname", et d'autres ajouts potentiels dans ce fichier. Cet ordre a été choisi car il permet un chaînage simple et propre d'autres fonctions "Sub::Util::set_*" qui pourraient devenir disponibles, telles que :

my $code =
   set_subname   name_here =>
   set_prototype '&@'      =>
   set_attribute ':lvalue' =>
      sub { ...... };

subname

my $name = subname( $code )

Depuis la version 1.40.

Retourne le nom de la référence $code donnée, si elle en a un. Les sous-programmes nommés normaux donneront un nom entièrement qualifié composé du paquet et du nom local séparés par "::". Les références de code anonymes donneront "__ANON__" comme nom local. Si le paquet dans lequel le code a été compilé a été supprimé (par exemple, en utilisant "delete_package" de Symbol), "__ANON__" sera retourné comme nom de paquet. Si un nom a été défini en utilisant "set_subname", ce nom sera retourné à la place.

Cette fonction a été inspirée par "sub_fullname" de Sub::Identify. Les autres fonctions que "Sub::Identify" implémente peuvent facilement être émuleées en utilisant des opérations regexp, telles que

sub get_code_info { return (subname $_[0]) =~ m/^(.+)::(.*?)$/ }
sub sub_name      { return (get_code_info $_[0])[0] }
sub stash_name    { return (get_code_info $_[0])[1] }

Attention aux utilisateurs de Sub::Name : Cette fonction n'est **pas** la même que "Sub::Name::subname" ; elle retourne le nom existant du sous plutôt que de le modifier. Pour définir ou modifier un nom, voir plutôt "set_subname".

set_subname

my $code = set_subname $name, $code;

Depuis la version 1.40.

Définit le nom de la fonction donnée par la référence $code. Retourne la référence $code elle-même. Si le $name n'est pas qualifié, le paquet de l'appelant est utilisé pour le qualifier.

Ceci est utile pour appliquer des noms aux références CODE anonymes afin que les traces de pile et situations similaires, aient un nom utile plutôt que le défaut de "__ANON__". Notez que ce nom n'est utilisé que dans ce cas ; "set_subname" ne l'installera pas dans la table des symboles ; vous devrez le faire vous-même si nécessaire.

Cependant, comme le nom n'est pas utilisé par perl sauf comme valeur de retour de "caller", pour les traces de pile ou similaires, il n'y a aucune exigence réelle que le nom soit syntaxiquement valide comme nom de fonction perl. Ceci pourrait être utilisé pour attacher des informations supplémentaires utiles dans le débogage des traces de pile.

Cette fonction a été copiée de "Sub::Name::subname" et renommée selon la convention de nommage de ce module.
