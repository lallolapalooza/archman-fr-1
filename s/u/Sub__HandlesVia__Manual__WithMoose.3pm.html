NOM

Sub::HandlesVia::Manual::WithMoose - utilisation de Sub::HandlesVia avec Moose

SYNOPSIS

package Kitchen {
  use Moose;
  use Sub::HandlesVia;
  use Types::Standard qw( ArrayRef Str );

  has food => (
    is          => 'ro',
    isa         => ArrayRef[Str],
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}

(Si vous avez un élan dans votre cuisine, cela pourrait être un désastre !)

MANUEL

Sub::HandlesVia vous permet de déléguer des méthodes de votre classe aux valeurs des attributs de vos objets.

Conceptuellement, cela vous permet de définir "$object->push_number($n)" comme un raccourci pour "$object->numbers->push($n)", sauf que "$object->numbers" est un arrayref, et n'a donc pas de méthodes appelables dessus comme "push".

Moose possède une fonctionnalité intégrée (traits natifs) qui fournit une version plus limitée de ceci.

Quelles méthodes peuvent être déléguées ?

L'option "handles_via" indique quelle bibliothèque de méthodes doit être disponible. Les valeurs valides incluent Array, Blessed, Bool, Code, Counter, Enum, Hash, Number, Scalar et String.

Un arrayref peut être fourni pour "handles_via", bien que bon nombre des options soient conceptuellement contradictoires.

handles_via => [ 'Number', 'Scalar' ]

Types natifs de Moose

Bien que le synopsis montre l'utilisation de Types::Standard pour les contraintes de type, les types natifs de Moose devraient également fonctionner correctement.

package Kitchen {
  use Moose;
  use Sub::HandlesVia;

  has food => (
    is          => 'ro',
    isa         => 'ArrayRef[Str]',
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}

Syntaxe de remplacement pour les traits natifs de Moose

Sub::HandlesVia reconnaîtra également les traits de style native-traits. Il interviendra et les gérera avant que Moose ne les remarque !

package Kitchen {
  use Moose;
  use Sub::HandlesVia;

  has food => (
    is          => 'ro',
    isa         => 'ArrayRef[Str]',
    traits      => ['Array'],
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}
