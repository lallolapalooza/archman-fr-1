Sub::HandlesVia::HandlerLibrary::Enum(3) Documentation Perl fournie par l'utilisateur Sub::HandlesVia::HandlerLibrary::Enum(3)

NOM

Sub::HandlesVia::HandlerLibrary::Enum - bibliothèque de méthodes liées aux énumérations

SYNTAXE

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Enum';
  has status => (
    is => 'ro',
    isa => Enum[ 'pass', 'fail' ],
    handles_via => 'Enum',
    handles => {
      'is_pass'      => [ is     => 'pass' ],
      'is_fail'      => [ is     => 'fail' ],
      'assign_pass'  => [ assign => 'pass' ],
      'assign_fail'  => [ assign => 'fail' ],
    },
    default => sub { 'fail' },
  );
}

Ou, en utilisant un raccourci :

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Enum';
  has status => (
    is => 'ro',
    isa => Enum[ 'pass', 'fail' ],
    handles_via => 'Enum',
    handles => {
      'is_pass'      => 'is_pass',
      'is_fail'      => 'is_fail',
      'assign_pass'  => 'assign_pass',
      'assign_fail'  => 'assign_fail',
    },
    default => sub { 'fail' },
  );
}

(Sub::HandlesVia::HandlerLibrary::Enum séparera sur "_".)

DESCRIPTION

Il s'agit d'une bibliothèque de méthodes pour Sub::HandlesVia.

MÉTHODES DÉLÉGUABLES

Cela permet une délégation globalement compatible avec MooseX::Enumeration et MooX::Enumeration, même si ce n'est essentiellement qu'un sous-ensemble renommé de Sub::HandlesVia::HandlerLibrary::String de toute façon.

est( $valeur )

Retourne une valeur booléenne indiquant si l'énumération correspond à cette valeur.

my $object = My::Class->new( status => 'pass' );
say $object->is_pass(); ## ==> vrai
say $object->is_fail(); ## ==> faux

assign( $valeur )

Définit l'énumération à la valeur donnée.

my $object = My::Class->new( status => 'pass' );
say $object->is_pass(); ## ==> vrai
say $object->is_fail(); ## ==> faux
$object->assign_fail();
say $object->is_pass(); ## ==> faux
say $object->is_fail(); ## ==> vrai

définit( $valeur )

Un alias pour "assign".

RACCOURCI DE CONTRAINTE DE TYPE

La bibliothèque de gestionnaires Enum permet également un raccourci "enum" dans la spécification de l'attribut.

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  has status => (
    is          => 'ro',
    enum        => [ 'pass', 'fail' ],
    handles_via => 'Enum',
    handles     => {
      'is_pass'      => [ is     => 'pass' ],
      'is_fail'      => [ is     => 'fail' ],
      'assign_pass'  => [ assign => 'pass' ],
      'assign_fail'  => [ assign => 'fail' ],
    },
    default     => sub { 'fail' },
  );
}

CONSTANTES RACCOURCIS

Ce module fournit des constantes raccourcis pour indiquer une liste de délégations.

package My::Class {
  use Moo;
  use Types::Standard qw( Enum );
  use Sub::HandlesVia;
  use Sub::HandlesVia::HandlerLibrary::Enum qw( HandleIs );
  has status => (
    is          => 'ro',
    isa         => Enum[ 'pass', 'fail' ],
    handles_via => 'Enum',
    handles     => HandleIs,
    default     => sub { 'fail' },
  );
}

N'importe lequel de ces raccourcis peut être combiné en utilisant l'opérateur " | ".

has status => (
  is          => 'ro',
  isa         => Enum[ 'pass', 'fail' ],
  handles_via => 'Enum',
  handles     => HandleIs | HandleSet,
  default     => sub { 'fail' },
);

"HandleIs"

Crée des délégations nommées comme "is_pass" et "is_fail".

"HandleNamedIs"

Crée des délégations nommées comme "status_is_pass" et "status_is_fail".

"HandleSet"

Crée des délégations nommées comme "set_pass" et "set_fail".

"HandleNamedSet"

Crée des délégations nommées comme "status_set_pass" et "status_set_fail".
