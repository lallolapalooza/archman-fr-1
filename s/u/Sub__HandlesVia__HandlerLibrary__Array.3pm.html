DESCRIPTION

Ceci est une bibliothèque de méthodes pour Sub::HandlesVia.

MÉTHODES DÉLÉGUABLES

"accessor( $index, $value? )"

Arguments : Int, Optional[Any].

Agit comme "get" si seule l'index est donnée, ou "set" si un index et une valeur sont donnés.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
$object->my_accessor( 1, 'quux' );
say Dumper( $object->attr ); ## ==> [ 'foo', 'quux', 'baz' ]
say $object->my_accessor( 2 ); ## ==> 'baz'

all()

Tous les éléments du tableau, en contexte de liste.

my $object = My::Class->new( attr => [ 'foo', 'bar' ] );
my @list = $object->my_all;
say Dumper( \@list ); ## ==> [ 'foo', 'bar' ]

all_true( $coderef )

Arguments : CodeRef.

Comme List::Util::all().

any( $coderef )

Arguments : CodeRef.

Comme List::Util::any().

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
my $truth  = $object->my_any( sub { /a/ } );
say $truth; ## ==> true

apply( $coderef )

Arguments : CodeRef.

Exécute la coderef (qui devrait modifier $_) sur chaque élément du tableau ; retourne le tableau résultant en contexte de liste.

clear()

Vide le tableau.

my $object = My::Class->new( attr => [ 'foo' ] );
$object->my_clear;
say Dumper( $object->attr ); ## ==> []

count()

Le nombre d'éléments dans le tableau référencé.

my $object = My::Class->new( attr => [ 'foo', 'bar' ] );
say $object->my_count; ## ==> 2

delete( $index )

Arguments : Int.

Supprime l'élément indexé du tableau et le retourne. Les éléments qui le suivent seront "décalés vers le haut".

elements()

Tous les éléments du tableau, en contexte de liste. (Essentiellement la même chose que "all".)

my $object = My::Class->new( attr => [ 'foo', 'bar' ] );
my @list = $object->my_elements;
say Dumper( \@list ); ## ==> [ 'foo', 'bar' ]

first( $coderef )

Arguments : CodeRef.

Comme List::Util::first().

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
my $found  = $object->my_first( sub { /a/ } );
say $found; ## ==> 'bar'

first_index( $coderef )

Arguments : CodeRef.

Comme List::MoreUtils::first_index().

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
my $found  = $object->my_first_index( sub { /z$/ } );
say $found; ## ==> 2

flatten()

Tous les éléments du tableau, en contexte de liste. (Essentiellement la même chose que "all".)

my $object = My::Class->new( attr => [ 'foo', 'bar' ] );
my @list = $object->my_flatten;
say Dumper( \@list ); ## ==> [ 'foo', 'bar' ]

flatten_deep( $depth? )

Arguments : Optional[Int].

Aplatit le tableau référencé en une liste, y compris les tableaux référencés imbriqués. (Potentiel de boucle infinie.)

my $object = My::Class->new( attr => [ 'foo', [ 'bar', [ 'baz' ] ] ] );
say Dumper( [ $object->my_flatten_deep ] ); ## ==> [ 'foo', 'bar', 'baz' ]
my $object2 = My::Class->new( attr => [ 'foo', [ 'bar', [ 'baz' ] ] ] );
say Dumper( [ $object2->my_flatten_deep(1) ] ); ## ==> [ 'foo', 'bar', [ 'baz' ] ]

for_each( $coderef )

Arguments : CodeRef.

Méthode chaînable qui exécute la coderef sur chaque élément du tableau. La coderef recevra deux valeurs : l'élément et son index.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
$object->my_for_each( sub { say "Item $_[1] is $_[0]." } );

for_each_pair( $coderef )

Arguments : CodeRef.

Méthode chaînable qui exécute la coderef sur chaque paire d'éléments du tableau. La coderef recevra les deux éléments.

get( $index )

Arguments : Int.

Retourne un élément unique du tableau par son index.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
say $object->my_get(  0 ); ## ==> 'foo'
say $object->my_get(  1 ); ## ==> 'bar'
say $object->m

y_get( $index )

Arguments: Int.

Returns the element at the given index, or undef if the index is out of bounds.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
say $object->my_get( 0 ); ## ==> 'foo'
say $object->my_get( -1 ); ## ==> 'baz'

grep( $coderef )

Arguments: CodeRef.

Semblable à "grep" de perlfunc.

head( $count )

Arguments: Int.

Retourne les $count premiers éléments du tableau en contexte de liste.

indexed()

Semblable à "indexed" de builtin.

"insert( $index, $value )"

Arguments: Int, Any.

Insère une valeur dans le tableau à l'index donné. Les éléments qui suivent seront "décalés" vers la droite.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
$object->my_insert( 1, 'quux' );
say Dumper( $object->attr ); ## ==> [ 'foo', 'quux', 'bar', 'baz' ]

is_empty()

Indique si le tableau référencé est vide.

my $object = My::Class->new( attr => [ 'foo', 'bar' ] );
say $object->my_is_empty; ## ==> false
$object->_set_attr( [] );
say $object->my_is_empty; ## ==> true

join( $with? )

Arguments: Optional[Str].

Retourne une chaîne qui joint tous les éléments du tableau; si $with est omis, la valeur par défaut est une virgule.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
say $object->my_join;        ## ==> 'foo,bar,baz'
say $object->my_join( '|' ); ## ==> 'foo|bar|baz'

map( $coderef )

Arguments: CodeRef.

Semblable à "map" de perlfunc.

max()

Semblable à List::Util::max().

maxstr()

Semblable à List::Util::maxstr().

min()

Semblable à List::Util::min().

minstr()

Semblable à List::Util::minstr().

"natatime( $n, $callback? )"

Arguments: Int, Optional[CodeRef].

Avec seulement un nombre, retourne un itérateur qui lit ce nombre d'éléments du tableau à la fois. Si un callback est également fourni, il appelle le callback de manière répétée avec ces valeurs.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
my $iter   = $object->my_natatime( 2 );
say Dumper( [ $iter->() ] ); ## ==> [ 'foo', 'bar' ]
say Dumper( [ $iter->() ] ); ## ==> [ 'baz' ]

not_all_true( $coderef )

Arguments: CodeRef.

Semblable à List::Util::notall().

pairfirst( $coderef )

Arguments: CodeRef.

Semblable à List::Util::pairfirst().

pairgrep( $coderef )

Arguments: CodeRef.

Semblable à List::Util::pairgrep().

pairkeys()

Semblable à List::Util::pairkeys().

pairmap( $coderef )

Arguments: CodeRef.

Semblable à List::Util::pairmap().

pairs()

Semblable à List::Util::pairs().

pairvalues()

Semblable à List::Util::pairvalues().

pick_random( $count )

Arguments: Optional[Int].

Si aucun $count n'est donné, retourne un élément aléatoire du tableau. Si $count est donné, crée un nouveau tableau avec ce nombre d'éléments aléatoires du tableau d'origine (ou moins si le tableau d'origine n'est pas assez long) et retourne ce nouveau tableau sous forme de référence de tableau ou de liste selon le contexte.

pop()

Supprime le dernier élément du tableau et le retourne.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
say $object->my_pop; ## ==> 'baz'
say $object->my_pop; ## ==> 'bar'
say Dumper( $object->attr ); ## ==> [ 'foo' ]

"print( $fh?, $with? )"

Arguments: Optional[FileHandle], Optional[Str].

Imprime une chaîne qui joint tous les éléments du tableau; si $fh est omis, la valeur par défaut est STDOUT; si $with est omis, la valeur par défaut est une virgule.

product()

Semblable à List::Util::product().

push( @values )

Ajoute des éléments à la fin du tableau.

my $object = My::Class->new( attr => [ 'foo' ] );
$object->my_push( 'bar', 'baz' );
say Dumper( $object->attr ); ## ==> [ 'foo', 'bar', 'baz' ]

reduce( $coderef )

Arguments: CodeRef.

Semblable à List::Util::reduce().

reductions( $coderef )

Arguments: CodeRef.

Semblable à List::Util::reductions().

reset()

Réinitialise l'attribut à sa valeur par défaut, ou à un tableau vide si aucune valeur par défaut n'est définie.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
$object->my_reset;
say Dumper( $object->attr ); ## ==> []

reverse()

Retourne le tableau inversé en contexte de liste.

sample( $count )

Arguments: Int.

Semblable à List::Util::sample().

"set( $index, $value )"

Arguments: Int, Any.

Définit l'élément à l'index donné à la valeur fournie.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
$object->my_set( 1, 'quux' );
say Dumper( $object->attr ); ## ==> [ 'foo', 'quux', 'baz' ]

shallow_clone()

Crée une nouvelle référence de tableau avec les mêmes éléments que l'original.

shift()

Supprime un élément du début du tableau et le retourne.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
say $object->my_shift; ## ==> 'foo'
say $object->my_shift; ## ==> 'bar'
say Dumper( $object->attr ); ## ==> [ 'baz' ]

shuffle()

Retourne le tableau dans un ordre aléatoire; peut être appelé en contexte de liste ou scalaire et retournera une référence de tableau dans ce dernier cas.

shuffle_in_place()

Réorganise le tableau dans un ordre aléatoire, et modifie l'attribut pour pointer vers le nouvel ordre.

sort( $coderef? )

Arguments: Optional[CodeRef].

Semblable à "sort" de perlfunc.

sort_in_place( $coderef? )

Arguments: Optional[CodeRef].

Semblable à "sort" de perlfunc, mais modifie l'attribut pour pointer vers le tableau nouvellement trié.

"splice( $index, $length, @values )"

Semblable à "splice" de perlfunc.

sum()

Semblable à List::Util::sum0().

Arguments: Int.

NAME

Sub::HandlesVia::HandlerLibrary::Array - Métodos de manejo de arreglos para Sub::HandlesVia

SYNOPSIS

 # En tu paquete:
 package My::Class {
   use Moo;
   use Sub::HandlesVia;

   has attr => (
     is          => 'ro',
     handles_via => 'Array',
     handles     => [qw(
       is_empty
       size
       first
       last
       unshift
       shift
       push
       pop
       clear
       delete_at
       get_at
       set_at
       splice
       uniq
       uniqnum
       uniqstr
       uniq_in_place
       uniqnum_in_place
       uniqstr_in_place
     )],
     default     => sub { [] },
   );
 }

DESCRIPTION

Este módulo proporciona métodos de manejo de arreglos para Sub::HandlesVia.

Permite que los atributos de Moo/Moose sean un arreglo y proporcione delegaciones a métodos de manejo de arreglos estándar, así como a algunos métodos de utilidad.

Todos los métodos delegados devuelven el arrayref subyacente cuando se llaman en contexto escalar, y la lista de elementos cuando se llaman en contexto de lista.

Example

package My::Class {
  use Moo;
  use Sub::HandlesVia;

  has items => (
    is          => 'ro',
    handles_via => 'Array',
    handles     => [qw( clear delete_at get_at is_empty last push pop set_at shift size unshift )],
    default     => sub { [] },
  );
}

my $obj = My::Class->new;

DELEGATABLE METHODS

clear()

Elimina todos los elementos del arreglo.

delete_at( $index )

Elimina el elemento en el índice dado, devolviendo los elementos eliminados.

first()

Devuelve el primer elemento del arreglo.

get_at( $index )

Devuelve el elemento en el índice dado.

is_empty()

Devuelve verdadero si el arreglo está vacío, falso de lo contrario.

last()

Devuelve el último elemento del arreglo.

pop()

Elimina y devuelve el último elemento del arreglo.

push( @values )

Agrega uno o más elementos al final del arreglo.

set_at( $index, $value )

Establece el elemento en el índice dado al valor dado.

shift()

Elimina y devuelve el primer elemento del arreglo.

size()

Devuelve el número de elementos en el arreglo.

splice( $offset, $len, @list )

Elimina y devuelve un trozo de elementos del arreglo, reemplazándolos opcionalmente con nuevos elementos.

tail( $count )

Devuelve los últimos $count elementos de la matriz en contexto de lista.

uniq()

Devuelve la matriz filtrada para eliminar duplicados; puede llamarse en contexto de lista o escalar y devolverá un arrayref en el caso de la segunda.

uniq_in_place()

Fila la matriz para eliminar duplicados, y cambia el atributo para apuntar a la matriz filtrada.

uniqnum()

Devuelve la matriz filtrada para eliminar duplicados numéricamente; puede llamarse en contexto de lista o escalar y devolverá un arrayref en el caso de la segunda.

uniqnum_in_place()

Fila la matriz para eliminar duplicados numéricamente, y cambia el atributo para apuntar a la matriz filtrada.

uniqstr()

Devuelve la matriz filtrada para eliminar duplicados stringwise; puede llamarse en contexto de lista o escalar y devolverá un arrayref en el caso de la segunda.

uniqstr_in_place()

Fila la matriz para eliminar duplicados stringwise, y cambia el atributo para apuntar a la matriz filtrada.

unshift( @values )

Agrega un elemento al inicio de la matriz.

my $object = My::Class->new( attr => [ 'foo' ] );
$object->my_unshift( 'bar', 'baz' );
say Dumper( $object->attr ); ## ==> [ 'bar', 'baz', 'foo' ]

SHORTCUT CONSTANTS

Este módulo proporciona algunas constantes de corto nombre para indicar una lista de delegaciones.

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Sub::HandlesVia::HandlerLibrary::Array qw( HandleQueue );

  has things => (
    is          => 'ro',
    handles_via => 'Array',
    handles     => HandleQueue,
    default     => sub { [] },
  );
}

Estas cortas pueden combinarse utilizando el operador |.

has things => (
  is          => 'ro',
  handles_via => 'Array',
  handles     => HandleQueue | HandleStack,
  default     => sub { [] },
);

"HandleQueue"

Crea delegaciones nombradas como "things_is_empty", "things_size", "things_enqueue", "things_dequeue", y "things_peek".

"HandleStack"

Crea delegaciones nombradas como "things_is_empty", "things_size", "things_push", "things_pop", y "things_peek".

EXTENDED EXAMPLES

Using for_each

use strict;
use warnings;

package My::Plugin {
  use Moo::Role;
  sub initialize {}
  sub finalize {}
}

package My::Processor {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard qw( ArrayRef ConsumerOf );

  has plugins => (
    is => 'ro',
    isa => ArrayRef[ ConsumerOf['My::Plugin'] ],
    handles_via => 'Array',
    handles => {
      add_plugin => 'push',
      plugin_do => 'for_each',
    },
    default => sub { [] },
  );

  sub _do_stuff {
    return;
  }

  sub run_process {
    my ( $self, @args ) = @_;
    $self->plugin_do( sub {
      my $plugin = shift;
      $plugin->initialize( $self, @args );
    } );
    $self->_do_stuff( @args );
    $self->plugin_do( sub {
      my $plugin = shift;
      $plugin->finalize( $self, @args );
    } );
  }
}

my $p = My::Processor->new();

package My::Plugin::Noisy {
  use Moo; with 'My::Plugin';
  sub initialize {
    my ( $self, $processor, @args ) = @_;
    say "initialize @args"; ## ==> 'initialize 1 2 3'
  }
  sub finalize {
    my ( $self, $processor, @args ) = @_;
    say "finalize @args"; ## ==> 'finalize 1 2 3'
  }
}

$p->add_plugin( My::Plugin::Noisy->new );

$p->run_process( 1, 2, 3 );

Job queue using push and shift

use strict;
use warnings;
use Try::Tiny;

package My::JobQueue {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard qw( Bool ArrayRef CodeRef HasMethods is_Object );
  use Try::Tiny;

  has auto_requeue => (
    is => 'ro',
    isa => Bool,
    default => 0,
  );

  has jobs => (
    is => 'ro',
    isa => ArrayRef[ CodeRef | HasMethods['run'] ],
    handles_via => 'Array',
    handles => {
      add_job => 'push',
      _get_job => 'shift',
      is_empty => 'is_empty',
    },
    default => sub { [] },
  );

  sub _handle_failed_job {
    my ( $self, $job ) = @_;
    $self->add_job( $job ) if $self->auto_requeue;
  }

  sub run_jobs {
    my $self = shift;
    while ( not $self->is_empty ) {
      my $job = $self->_get_job;
      try {
        is_Object($job) ? $job->run() : $job->();
      }
      catch {
        $self->_handle_failed_job( $job );
      };
    }
  }
}

my $q = My::JobQueue->new();

my $str = '';
$q->add_job( sub { $str .= 'A' } );
$q->add_job( sub { $str .= 'B' } );
$q->add_job( sub { $str .= 'C' } );

$q->run_jobs;

say $str; ## ==> 'ABC'

# Attempt to push invalid value on the queue
#
try {
  $q->add_job( "jobs cannot be strings" );
}
catch {
  say $q->is_empty;  ## ==> true
};
