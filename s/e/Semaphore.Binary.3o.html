Module Binary
: sig end

type t

Le type des sémaphores binaires.

val make : bool -> t

make b renvoie un nouveau sémaphore binaire. Si b est true , la valeur initiale du sémaphore est 1, signifiant "disponible". Si b est false , la valeur initiale du sémaphore est 0, signifiant "indisponible".

val release : t -> unit

release s met la valeur du sémaphore s à 1, le mettant dans l'état "disponible". Si d'autres threads attendent sur s , l'un d'eux est redémarré.

val acquire : t -> unit

acquire s bloque le thread appelant jusqu'à ce que le sémaphore s ait la valeur 1 (soit disponible), puis le met atomiquement à 0 et revient.

val try_acquire : t -> bool

try_acquire s renvoie immédiatement false si le sémaphore s a la valeur 0. Si s a la valeur 1, sa valeur est atomiquement mise à 0 et try_acquire s renvoie true .
