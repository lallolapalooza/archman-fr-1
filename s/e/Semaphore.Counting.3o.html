Module Counting
: sig end

type t

Le type des sémaphores de comptage.

val make : int -> t

make n renvoie un nouveau sémaphore de comptage, avec la valeur initiale n . La valeur initiale n doit être non négative.

Lève Invalid_argument si n < 0

val release : t -> unit

release s incrémente la valeur du sémaphore s . Si d'autres threads attendent sur s , l'un d'eux est redémarré. Si la valeur actuelle de s est égale à max_int , la valeur du sémaphore reste inchangée et une exception Sys_error est levée pour signaler un dépassement.

Lève Sys_error si la valeur du sémaphore dépasserait max_int

val acquire : t -> unit

acquire s bloque le thread appelant jusqu'à ce que la valeur du sémaphore s ne soit pas zéro, puis décrémente atomiquement la valeur de s et renvoie.

val try_acquire : t -> bool

try_acquire s renvoie immédiatement false si la valeur du sémaphore s est zéro. Sinon, la valeur de s est décrémentée atomiquement et try_acquire s renvoie true .

val get_value : t -> int

get_value s renvoie la valeur actuelle du sémaphore s . La valeur actuelle peut être modifiée à tout moment par des opérations concurrentes de Semaphore.Counting.release et Semaphore.Counting.acquire . Par conséquent, l'opération get_value est sujette à la concurrence, et son résultat ne devrait être utilisé que pour le débogage ou les messages d'information.
