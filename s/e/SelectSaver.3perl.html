NOM

SelectSaver - sauvegarder et restaurer un descripteur de fichier sélectionné

SYNTAXE

use SelectSaver;
{
   my $saver = SelectSaver->new(FICHIER);
   # FICHIER est sélectionné
}
# le descripteur précédent est sélectionné
{
   my $saver = SelectSaver->new;
   # un nouveau descripteur peut être sélectionné, ou pas
}
# le descripteur précédent est sélectionné

DESCRIPTION

Un objet "SelectSaver" contient une référence au descripteur de fichier qui était sélectionné lors de sa création. Si sa méthode "new" reçoit un paramètre supplémentaire, ce paramètre est sélectionné ; sinon, le descripteur de fichier sélectionné reste inchangé.

Lorsqu'un "SelectSaver" est détruit, il re-sélectionne le descripteur de fichier qui était sélectionné lors de sa création.
