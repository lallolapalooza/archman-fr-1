Sets

Le type des éléments du set.

Le type des sets.

val empty : t

Le set vide.

val add : elt -> t -> t

add x s retourne un set contenant tous les éléments de s, plus x. Si x était déjà dans s, s est retourné inchangé (le résultat de la fonction est alors physiquement égal à s).

Avant 4.03 L'égalité physique n'était pas garantie.

val singleton : elt -> t

singleton x retourne le set d'un seul élément contenant uniquement x.

val remove : elt -> t -> t

remove x s retourne un set contenant tous les éléments de s, excepté x. Si x n'était pas dans s, s est retourné inchangé (le résultat de la fonction est alors physiquement égal à s).

Avant 4.03 L'égalité physique n'était pas garantie.

Union de sets.

Intersection de sets.

Vérifie si deux sets sont disjoints.

Éléments

val elements : t -> elt list

Retourne la liste de tous les éléments du set donné. La liste retournée est triée par ordre croissant selon l'ordre Ord.compare, où Ord est l'argument donné à Set.Make.

val min_elt : t -> elt

Retourne le plus petit élément du set donné (par rapport à l'ordre Ord.compare), ou lève Not_found si le set est vide.

val min_elt_opt : t -> elt option

Retourne le plus petit élément du set donné (par rapport à l'ordre Ord.compare), ou None si le set est vide.

Depuis 4.05

val max_elt : t -> elt

Similaire à Set.S.min_elt, mais retourne le plus grand élément du set donné.

val max_elt_opt : t -> elt option

Similaire à Set.S.min_elt_opt, mais retourne le plus grand élément du set donné.

Depuis 4.05

val choose : t -> elt

Retourne un élément du set donné, ou lève Not_found si le set est vide. Quel élément est choisi est indéterminé, mais les éléments égaux seront choisis pour des sets égaux.

val choose_opt : t -> elt option

Retourne un élément du set donné, ou None si le set est vide. Quel élément est choisi est indéterminé, mais les éléments égaux seront choisis pour des sets égaux.

Depuis 4.05

Recherche

val find : elt -> t -> elt

find x s retourne l'élément de s égal à x (selon Ord.compare), ou lève Not_found s'il n'existe pas un tel élément.

Depuis 4.01

val find_opt : elt -> t -> elt option

find_opt x s retourne l'élément de s égal à x (selon Ord.compare), ou None s'il n'existe pas un tel élément.

Depuis 4.05

val find_first : (elt -> bool) -> t -> elt

find_first f s , où f est une fonction monotone croissante, retourne le plus petit élément e de s tel que f e, ou lève Not_found s'il n'existe pas un tel élément.

Par exemple, find_first (fun e -> Ord.compare e x >= 0) s retournera le plus petit élément e de s où Ord.compare e x >= 0 (intuitivement : e >= x ), ou lève Not_found si x est plus grand que n'importe quel élément de s.

Depuis 4.05

val find_first_opt : (elt -> bool) -> t -> elt option

find_first_opt f s , où f est une fonction monotone croissante, retourne un option contenant le plus petit élément e de s tel que f e, ou None s'il n'existe pas un tel élément.

Depuis 4.05

val find_last : (elt -> bool) -> t -> elt

find_last f s , où f est une fonction monotone décroissante, retourne le plus grand élément e de s tel que f e, ou lève Not_found s'il n'existe pas un tel élément.

Depuis 4.05

val find_last_opt : (elt -> bool) -> t -> elt option

find_last_opt f s , où f est une fonction monotone décroissante, retourne un option contenant le plus grand élément e de s tel que f e, ou None s'il n'existe pas un tel élément.

Depuis 4.05

Parcours

val iter : (elt -> unit) -> t -> unit

iter f s applique f à chaque élément de s par ordre croissant selon l'ordre des types d'éléments.

val fold : (elt -> 'acc -> 'acc) -> t -> 'acc -> 'acc

fold f s init calcule (f xN ... (f x2 (f x1 init))...), où x1 ... xN sont les éléments de s par ordre croissant.

Transformation

val map : (elt -> elt) -> t -> t

map f s est le set dont les éléments sont f a0, f a1 ... f aN, où a0, a1 ... aN sont les éléments de s.

Les éléments sont passés à f par ordre croissant selon l'ordre des types d'éléments.

Si aucun élément de s n'est modifié par f, s est retourné inchangé. (Si chaque sortie de f est physiquement égale à son entrée, le set retourné est physiquement égal à s.)

Depuis 4.04

val filter : (elt -> bool) -> t -> t

filter f s retourne le set de tous les éléments de s qui satisfont la prédicat f. Si f satisfait tous les éléments de s, s est retourné inchangé (le résultat de la fonction est alors physiquement égal à s).

Avant 4.03 L'égalité physique n'était pas garantie.

val filter_map : (elt -> elt option) -> t -> t

filter_map f s retourne le set de tous les v tels que f x = Some v pour un élément x de s.

Par exemple,

filter_map (fun n -> if n mod 2 = 0 then Some (n / 2) else None) s
est le set des moitiés des éléments pairs de s.

Si aucun élément de s n'est modifié ou supprimé par f (si f x = Some x pour chaque élément x ), alors s est retourné inchangé : le résultat de la fonction est alors physiquement égal à s.

Depuis 4.11

val partition : (elt -> bool) -> t -> t * t

partition f s retourne une paire de sets (s1, s2), où s1 est le set de tous les éléments de s qui satisfont le prédicat f

Documentation

val filter : (elt -> bool) -> t -> t
filter f s returns a subset of s containing only elements that satisfy f.
val partition : (elt -> bool) -> t -> t * t
partition f s returns a pair of sets (s1, s2), where s1 is the set of elements of s that satisfy f, and s2 is the set of elements of s that do not satisfy f.
val split : elt -> t -> t * bool * t
split x s returns a triple (l, present, r), where l is the set of elements of s that are strictly less than x; r is the set of elements of s that are strictly greater than x; present is false if s contains no element equal to x, or true if s contains an element equal to x.

Prédicats et comparaisons

val is_empty : t -> bool
Teste si un ensemble est vide ou non.
val mem : elt -> t -> bool
mem x s teste si x appartient à l'ensemble s.
val equal : t -> t -> bool
equal s1 s2 teste si les ensembles s1 et s2 sont égaux, c'est-à-dire s'ils contiennent les mêmes éléments.
val compare : t -> t -> int
Ordre total entre les ensembles. Peut être utilisé comme fonction d'ordre pour construire des ensembles d'ensembles.
val subset : t -> t -> bool
subset s1 s2 teste si l'ensemble s1 est un sous-ensemble de l'ensemble s2.
val for_all : (elt -> bool) -> t -> bool
for_all f s vérifie si tous les éléments de l'ensemble satisfont le prédicat f.
val exists : (elt -> bool) -> t -> bool
exists f s vérifie si au moins un élément de l'ensemble satisfait le prédicat f.
