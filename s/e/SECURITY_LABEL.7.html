SECURITY_LABEL(7)

Paquet: postgresql

Licences: PostgreSQL

SECURITY LABEL(7) Documentation PostgreSQL 18.1 SECURITY LABEL(7)

NOM

SECURITY_LABEL - définir ou modifier une étiquette de sécurité appliquée à un objet

SYNTAXE

SECURITY LABEL [ FOR fournisseur ] ON
{
  TABLE nom_objet |
  COLUMN nom_table.nom_colonne |
  AGGREGATE nom_agrégat ( signature_agrégat ) |
  DATABASE nom_objet |
  DOMAIN nom_objet |
  EVENT TRIGGER nom_objet |
  FOREIGN TABLE nom_objet |
  FUNCTION nom_fonction [ ( [ [ mode_arg ] [ nom_arg ] type_arg [, ...] ] ) ] |
  LARGE OBJECT oid_gros_objet |
  MATERIALIZED VIEW nom_objet |
  [ PROCEDURAL ] LANGUAGE nom_objet |
  PROCEDURE nom_procédure [ ( [ [ mode_arg ] [ nom_arg ] type_arg [, ...] ] ) ] |
  PUBLICATION nom_objet |
  ROLE nom_objet |
  ROUTINE nom_routine [ ( [ [ mode_arg ] [ nom_arg ] type_arg [, ...] ] ) ] |
  SCHEMA nom_objet |
  SEQUENCE nom_objet |
  SUBSCRIPTION nom_objet |
  TABLESPACE nom_objet |
  TYPE nom_objet |
  VIEW nom_objet
} IS { littéral_chaîne | NULL }
où signature_agrégat est :
* |
[ mode_arg ] [ nom_arg ] type_arg [ , ... ] |
[ [ mode_arg ] [ nom_arg ] type_arg [ , ... ] ] ORDER BY [ mode_arg ] [ nom_arg ] type_arg [ , ... ]

DESCRIPTION

SECURITY LABEL applique une étiquette de sécurité à un objet de base de données. Un nombre arbitraire d'étiquettes de sécurité, une par fournisseur d'étiquettes, peut être associé à un objet de base de données donné. Les fournisseurs d'étiquettes sont des modules chargeables qui s'enregistrent en utilisant la fonction register_label_provider.


Note

register_label_provider n'est pas une fonction SQL ; elle ne peut être appelée que depuis du code C chargé dans le backend.

Le fournisseur d'étiquettes détermine si une étiquette donnée est valide et s'il est permis d'attribuer cette étiquette à un objet donné. La signification d'une étiquette donnée est également à la discrétion du fournisseur d'étiquettes. PostgreSQL ne place aucune restriction quant à la manière dont un fournisseur d'étiquettes doit interpréter les étiquettes de sécurité ; il fournit simplement un mécanisme pour les stocker. En pratique, cette fonctionnalité est destinée à permettre l'intégration avec des systèmes de contrôle d'accès obligatoire (MAC) basés sur des étiquettes tels que SELinux. Ces systèmes prennent toutes les décisions de contrôle d'accès en fonction des étiquettes d'objets, plutôt que des concepts traditionnels de contrôle d'accès discrétionnaire (DAC) tels que les utilisateurs et les groupes.

Vous devez posséder l'objet de base de données pour utiliser SECURITY LABEL.

PARAMÈTRES

nom_objet
nom_table.nom_colonne
nom_agrégat
nom_fonction
nom_procédure
nom_routine

Le nom de l'objet à étiqueter. Les noms des objets qui résident dans des schémas (tables, fonctions, etc.) peuvent être qualifiés par un schéma.

fournisseur

Le nom du fournisseur auquel cette étiquette doit être associée. Le fournisseur nommé doit être chargé et doit consentir à l'opération d'étiquetage proposée. Si un seul fournisseur est chargé, le nom du fournisseur peut être omis par souci de concision.

mode_arg

Le mode d'un argument de fonction, de procédure ou d'agrégat : IN, OUT, INOUT ou VARIADIC. S'il est omis, la valeur par défaut est IN. Notez que SECURITY LABEL ne tient pas compte des arguments OUT, car seuls les arguments d'entrée sont nécessaires pour identifier la fonction. Il est donc suffisant de lister les arguments IN, INOUT et VARIADIC.

nom_arg

Le nom d'un argument de fonction, de procédure ou d'agrégat. Notez que SECURITY LABEL ne tient pas compte des noms d'arguments, car seuls les types de données des arguments sont nécessaires pour identifier la fonction.

type_arg

Le type de données d'un argument de fonction, de procédure ou d'agrégat.

oid_gros_objet

L'OID du gros objet.

PROCEDURAL

C'est un mot non significatif.

littéral_chaîne

Le nouveau réglage de l'étiquette de sécurité, écrit sous forme de littéral chaîne.

NULL

Écrire NULL pour supprimer l'étiquette de sécurité.

EXEMPLES

L'exemple suivant montre comment l'étiquette de sécurité d'une table pourrait être définie ou modifiée :

SECURITY LABEL FOR selinux ON TABLE mytable IS 'system_u:object_r:sepgsql_table_t:s0';

Pour supprimer l'étiquette :

SECURITY LABEL FOR selinux ON TABLE mytable IS NULL;

COMPATIBILITÉ

Il n'y a pas de commande SECURITY LABEL dans la norme SQL.
