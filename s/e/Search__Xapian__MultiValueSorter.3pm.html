NOM

Search::Xapian::MultiValueSorter - permet de trier par plusieurs valeurs.

DESCRIPTION

Les résultats sont ordonnés par la première valeur. En cas d'égalité, la seconde est utilisée. Si celle-ci est identique pour les deux, la troisième est utilisée, et ainsi de suite.

SYNTAXE

use Search::Xapian;
my $db = new Search::Xapian::Database("/chemin/vers/db");
my $enq = new Search::Xapian::Enquire($db);
my $sorter = new Search::Xapian::MultiValueSorter(1, 3, 5);
$enq->set_sort_by_key($sorter);

MÉTHODES

new [<valeur>...]
Construit et ajoute les valeurs listées.
add <valeur> [<avant>]
Ajoute une autre valeur pour le tri. Par défaut, les valeurs sont triées en avant, sauf si "avant" est spécifié et est faux.
