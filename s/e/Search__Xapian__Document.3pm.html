Search__Xapian__Document(3pm)

Paquet: perl-search-xapian

Licences: PerlArtistic, GPL

Xapian::Document(3) Documentation Perl fournie par l'utilisateur Xapian::Document(3)

NOM

Search::Xapian::Document - Objet Document

DESCRIPTION

Cette classe représente un document dans une base de données Xapian.

MÉTHODES

new
Constructeur de classe.
clone
Retourne un clone de cette classe.
get_value (no_valeur)
Retourne la valeur par le numéro assigné.
add_value <no_valeur> <valeur>
Définit une valeur par numéro de valeur.
remove_value <no_valeur>
Supprime la valeur avec le numéro assigné.
clear_values
Supprime toutes les valeurs définies.
get_data
Retourne toutes les données du document.
set_data <données>
Définit toutes les données du document. Cela peut être n'importe quoi.
add_posting <terme> <position> [<inc_poids>]
Ajoute un terme à la position donnée. inc_poids vaut 1 par défaut.
remove_posting <terme> <position> [<dec_poids>]
Supprime un terme de la position donnée. dec_poids vaut 1 par défaut.
add_term <terme> [<inc_poids>]
Ajoute un terme sans information de position. inc_poids vaut 1 par défaut.
add_boolean_term <terme>
Ajoute un terme destiné au filtrage booléen (sa contribution au poids sera de 0).
remove_term <terme>
Supprime un terme et toutes les occurrences associées.
clear_terms
Supprime tous les termes du document.
termlist_count
Retourne le nombre de termes différents dans le document.
termlist_begin
Itérateur pour les termes de ce document. Retourne un Search::Xapian::TermIterator.
termlist_end
Itérateur de fin équivalent à termlist_begin(). Retourne un Search::Xapian::TermIterator.
values_count
Retourne le nombre de valeurs définies pour ce document.
values_begin
Retourne un Search::Xapian::ValueIterator pointant au début des valeurs de ce document.
values_end
Retourne un Search::Xapian::ValueIterator pointant à la fin des valeurs de ce document.
get_description
Retourne une description de cet objet.
