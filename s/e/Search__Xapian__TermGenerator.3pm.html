NOM

Search::Xapian::TermGenerator - Analyse un morceau de texte et génère des termes.

DESCRIPTION

Ce module prend un morceau de texte et l'analyse pour produire des mots qui sont ensuite utilisés pour générer des termes appropriés à l'indexation. Les termes générés conviennent à une utilisation avec les objets Search::Xapian::Query produits par la classe Search::Xapian::QueryParser.

SYNOPSIS

use Search::Xapian;
my $doc = new Search::Xapian::Document();
my $tg = new Search::Xapian::TermGenerator();
$tg->set_stemmer(new Search::Xapian::Stem("english"));
$tg->set_document($doc);
$tg->index_text("The cat sat on the mat");

MÉTHODES

new
Constructeur de TermGenerator.
set_stemmer <stemmer>
Définit l'objet Search::Xapian::Stem à utiliser pour générer des termes racinisés.
set_stopper <stopper>
Définit l'objet Search::Xapian::Stopper à utiliser pour identifier les mots vides.
set_document <document>
Définit l'objet Search::Xapian::Document dans lequel indexer les termes.
get_document <document>
Récupère l'objet Search::Xapian::Document actuellement défini.
index_text <texte> [<wdf_inc> [<préfixe>]]
Indexe le texte dans la chaîne <texte>. Le paramètre optionnel <wdf_inc> définit l'incrément wdf (par défaut 1). Le paramètre optionnel <préfixe> définit le préfixe de terme à utiliser (par défaut, aucun préfixe).
index_text_without_positions <texte> [<wdf_inc> [<préfixe>]]
Identique à index_text, mais aucune information de position n'est générée. Cela signifie que la base de données sera significativement plus petite, mais que la recherche de phrases et NEAR ne seront pas pris en charge.
increase_termpos [<delta>]
Augmente la position du terme utilisée par index_text de <delta> (par défaut 100).

Cela peut être utilisé pour éviter que les recherches de phrases ne s'étendent sur deux blocs de texte non connectés (par exemple, le titre et le corps du texte).

get_termpos
Récupère la position actuelle du terme.
set_termpos <position_terme>
Définit la position actuelle du terme.
get_description
Retourne une description de cet objet.
