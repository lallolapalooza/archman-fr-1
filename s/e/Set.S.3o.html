Ensembles

type elt

Le type des éléments de l'ensemble.

type t

Le type des ensembles.

val empty : t

L'ensemble vide.

val add : elt -> t -> t

add x s renvoie un ensemble contenant tous les éléments de s , plus x . Si x était déjà dans s , s est retourné inchangé (le résultat de la fonction est alors physiquement égal à s ).

Avant4.03 L'égalité physique n'était pas garantie.

val singleton : elt -> t

singleton x renvoie l'ensemble à un seul élément contenant uniquement x .

val remove : elt -> t -> t

remove x s renvoie un ensemble contenant tous les éléments de s , à l'exception de x . Si x n'était pas dans s , s est retourné inchangé (le résultat de la fonction est alors physiquement égal à s ).

Avant4.03 L'égalité physique n'était pas garantie.

val union : t -> t -> t

Union d'ensembles.

val inter : t -> t -> t

Intersection d'ensembles.

val disjoint : t -> t -> bool

Teste si deux ensembles sont disjoints.

Depuis 4.08

val diff : t -> t -> t

Différence d'ensembles : diff s1 s2 contient les éléments de s1 qui ne sont pas dans s2 .

val cardinal : t -> int

Renvoie le nombre d'éléments d'un ensemble.

Éléments

val elements : t -> elt list

Renvoie la liste de tous les éléments de l'ensemble donné. La liste renvoyée est triée par ordre croissant selon l'ordre Ord.compare , où Ord est l'argument donné à Set.Make.

val min_elt : t -> elt

Renvoie le plus petit élément de l'ensemble donné (selon l'ordre Ord.compare ), ou lève Not_found si l'ensemble est vide.

val min_elt_opt : t -> elt option

Renvoie le plus petit élément de l'ensemble donné (selon l'ordre Ord.compare ), ou None si l'ensemble est vide.

Depuis 4.05

val max_elt : t -> elt

Identique à Set.S.min_elt , mais renvoie le plus grand élément de l'ensemble donné.

val max_elt_opt : t -> elt option

Identique à Set.S.min_elt_opt , mais renvoie le plus grand élément de l'ensemble donné.

Depuis 4.05

val choose : t -> elt

Renvoie un élément de l'ensemble donné, ou lève Not_found si l'ensemble est vide. L'élément choisi n'est pas spécifié, mais des éléments égaux seront choisis pour des ensembles égaux.

val choose_opt : t -> elt option

Renvoie un élément de l'ensemble donné, ou None si l'ensemble est vide. L'élément choisi n'est pas spécifié, mais des éléments égaux seront choisis pour des ensembles égaux.

Depuis 4.05

Recherche

val find : elt -> t -> elt

find x s renvoie l'élément de s égal à x (selon Ord.compare ), ou lève Not_found si aucun élément de ce type n'existe.

Depuis 4.01

val find_opt : elt -> t -> elt option

find_opt x s renvoie l'élément de s égal à x (selon Ord.compare ), ou None si aucun élément de ce type n'existe.

Depuis 4.05

val find_first : (elt -> bool) -> t -> elt

find_first f s , où f est une fonction monotoniquement croissante, renvoie le plus petit élément e de s tel que f e , ou lève Not_found si aucun élément de ce type n'existe.

Par exemple, find_first (fun e -> Ord.compare e x >= 0) s renverra le premier élément e de s tel que Ord.compare e x >= 0 (intuitivement : e >= x ), ou lèvera Not_found si x est plus grand que n'importe quel élément de s.

Depuis 4.05

val find_first_opt : (elt -> bool) -> t -> elt option

find_first_opt f s , où f est une fonction monotoniquement croissante, renvoie une option contenant le plus petit élément e de s tel que f e , ou None si aucun élément de ce type n'existe.

Depuis 4.05

val find_last : (elt -> bool) -> t -> elt

find_last f s , où f est une fonction monotoniquement décroissante, renvoie le plus grand élément e de s tel que f e , ou lève Not_found si aucun élément de ce type n'existe.

Depuis 4.05

val find_last_opt : (elt -> bool) -> t -> elt option

find_last_opt f s , où f est une fonction monotoniquement décroissante, renvoie une option contenant le plus grand élément e de s tel que f e , ou None si aucun élément de ce type n'existe.

Depuis 4.05

Traversées

val iter : (elt -> unit) -> t -> unit

iter f s applique f tour à tour à tous les éléments de s . Les éléments de s sont présentés à f dans l'ordre croissant selon l'ordre sur le type des éléments.

val fold : (elt -> 'acc -> 'acc) -> t -> 'acc -> 'acc

fold f s init calcule (f xN ... (f x2 (f x1 init))...) , où x1 ... xN sont les éléments de s , en ordre croissant.

Transformations

val map : (elt -> elt) -> t -> t

map f s est l'ensemble dont les éléments sont f a0 , f a1 ... f aN , où a0 , a1 ... aN sont les éléments de s .

Les éléments sont passés à f dans l'ordre croissant selon l'ordre sur le type des éléments.

Si aucun élément de s n'est modifié par f , s est retourné inchangé. (Si chaque sortie de f est physiquement égale à son entrée, l'ensemble renvoyé est physiquement égal à s .)

Depuis 4.04

val filter : (elt -> bool) -> t -> t

filter f s renvoie l'ensemble de tous les éléments de s qui satisfont le prédicat f . Si f satisfait tous les éléments de s , s est retourné inchangé (le résultat de la fonction est alors physiquement égal à s ).

Avant4.03 L'égalité physique n'était pas garantie.

val filter_map : (elt -> elt option) -> t -> t

filter_map f s renvoie l'ensemble de tous les v tels que f x = Some v pour un certain élément x de s .

Par exemple,

filter_map (fun n -> if n mod 2 = 0 then Some (n / 2) else None) s
est l'ensemble des moitiés des éléments pairs de s .

Si aucun élément de s n'est modifié ou supprimé par f (si f x = Some x pour chaque élément x ), alors s est retourné inchangé : le résultat de la fonction est alors physiquement égal à s.

Depuis 4.11

val partition : (elt -> bool) -> t -> t * t

partition f s renvoie une paire d'ensembles (s1, s2) , où s1 est l'ensemble de tous les éléments de s qui satisfont le prédicat f , et s2 est l'ensemble de tous les éléments de s qui ne satisfont pas f.

val split : elt -> t -> t * bool * t

split x s renvoie un triple (l, present, r) , où l est l'ensemble des éléments de s strictement inférieurs à x , present est un booléen indiquant si x est présent dans s , et r est l'ensemble des éléments de s strictement supérieurs à x.

Depuis 4.02

Intégration dans une liste

val of_list : elt list -> t

Construit un ensemble à partir d'une liste d'éléments.

val of_list_opt : elt list -> elt option

Construit un ensemble à partir d'une liste d'éléments. Si la liste est vide, renvoie None.

Depuis 4.06

val to_list : t -> elt list

Identique à Set.S.elements.

Exemples

Voici quelques exemples d'utilisation de la bibliothèque Set.

# module IntSet = Set.Make(Int)
# IntSet.elements (IntSet.add 3 (IntSet.add 1 IntSet.empty))
- : int list = [1; 3]
# IntSet.mem 2 (IntSet.add 3 (IntSet.add 1 IntSet.empty))
- : bool = false
# IntSet.union (IntSet.singleton 1) (IntSet.singleton 2)
- : IntSet.t = <set>

Pour plus d'exemples, veuillez consulter la documentation de la bibliothèque Set.

Note : Les chaînes imprimées pour les ensembles (par exemple, <set> ) ne sont pas significatives. Elles indiquent seulement qu'un ensemble de ce type a été créé.

  • Prédicats et comparaisons

    val is_empty : t -> bool

    Teste si un ensemble est vide ou non.

    val mem : elt -> t -> bool

    mem x s teste si x appartient à l'ensemble s.

    val equal : t -> t -> bool

    equal s1 s2 teste si les ensembles s1 et s2 sont égaux, c'est-à-dire qu'ils contiennent les mêmes éléments.

    val compare : t -> t -> int

    Ordre total entre ensembles. Peut être utilisé comme fonction de tri pour des ensembles d'ensembles.

    val subset : t -> t -> bool

    subset s1 s2 teste si l'ensemble s1 est un sous-ensemble de l'ensemble s2.

    val for_all : (elt -> bool) -> t -> bool

    for_all f s vérifie si tous les éléments de l'ensemble satisfont le prédicat f.

    val exists : (elt -> bool) -> t -> bool

    exists f s vérifie si au moins un élément de l'ensemble satisfait le prédicat f.

    Conversion

    val to_list : t -> elt list

    to_list s est Set.S.elements s.

    Since 5.1

    val of_list : elt list -> t

    of_list l crée un ensemble à partir d'une liste d'éléments. C'est généralement plus efficace que d'appliquer add en itérant sur la liste, sauf pour les listes contenant beaucoup d'éléments dupliqués.

    Since 4.02

    val to_seq_from : elt -> t -> elt Seq.t

    to_seq_from x s itère sur un sous-ensemble des éléments de s dans l'ordre croissant, à partir de x ou plus.

    Since 4.07

    val to_seq : t -> elt Seq.t

    Itère sur l'ensemble complet, dans l'ordre croissant.

    Since 4.07

    val to_rev_seq : t -> elt Seq.t

    Itère sur l'ensemble complet, dans l'ordre décroissant.

    Since 4.12

    val add_seq : elt Seq.t -> t -> t

    Ajoute les éléments donnés à l'ensemble, dans l'ordre.

    Since 4.07

    val of_seq : elt Seq.t -> t

    Crée un ensemble à partir des associations données.
