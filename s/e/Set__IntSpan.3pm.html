DESCRIPTION

«Set::IntSpan» gère des ensembles d'entiers. Il est optimisé pour les ensembles contenant de longues séquences de nombres consécutifs. Ceux-ci se rencontrent, par exemple, dans les fichiers .newsrc, qui maintiennent des listes d'articles :

alt.foo: 1-21,28,31
alt.bar: 1-14192,14194,14196-14221

Une séquence de nombres consécutifs est également appelée intervalle.

Les ensembles sont stockés en interne sous forme de tranches codées. Cela permet un stockage compact et des calculs efficaces. En particulier, les opérations d'ensemble peuvent être effectuées directement sur la représentation codée.

«Set::IntSpan» est conçu pour gérer des ensembles finis. Cependant, il peut également représenter certains ensembles infinis, tels que {x | x > n}. Cela permet d'effectuer des opérations liées aux compléments de manière cohérente, sans avoir à se soucier de la valeur réelle de INT_MAX sur votre machine.

INTERVALLS

Un intervalle est une séquence de nombres consécutifs. Un intervalle peut être représenté par une référence à un tableau, sous l'une des 5 formes suivantes :

Formes finies

  Intervalle      Ensemble
[ $n,    $n    ]      { n }
[ $a,    $b    ]      { x | a ≤ x ∧ x ≤ b }

Formes infinies

  Intervalle      Ensemble
[ undef, $b    ]      { x | x ≤ b }
[ $a   , undef ]      { x | x ≥ a }
[ undef, undef ]      L'ensemble de tous les entiers

Certaines fonctions opèrent directement sur les intervalles.

SPÉCIFICATIONS D'ENSEMBLE

De nombreuses fonctions acceptent une spécification d'ensemble. Il existe 4 types de spécifications d'ensemble.

Vide

Si aucune spécification d'ensemble n'est fournie, l'ensemble est supposé vide. Par conséquent,

$set = new Set::IntSpan;

crée un nouvel ensemble vide. De même,

copy $set;

supprime tous les éléments de $set.

Référence d'objet

Si une référence à un objet est transmise, elle est considérée comme un objet de type «Set::IntSpan».

Liste de runs

Si une chaîne de caractères est transmise, elle est considérée comme une liste de runs. Une liste de runs spécifie un ensemble à l'aide d'un format similaire à celui des fichiers .newsrc.

Une liste de runs est une liste séparée par des virgules de runs. Chaque run spécifie un ensemble de nombres consécutifs. L'ensemble est l'union de tous les runs.

Les runs peuvent être écrits sous l'une des 5 formes suivantes.

Formes finies

n
{ n }
a-b
{ x | a ≤ x ∧ x ≤ b }

Formes infinies

(-n
{ x | x ≤ n }
n-)
{ x | x ≥ n }
(-)
L'ensemble de tous les entiers

Formes vides

L'ensemble vide s'écrit de manière cohérente comme '' (la chaîne nulle). Il est également désigné par la forme spéciale '-'.

Contraintes

Les runs dans une liste de runs doivent être disjoints et listés dans l'ordre croissant.

Les caractères valides dans une liste de runs sont 0-9, '(', ')', '-', et ','. L'espace et le trait de soulignement (_) sont ignorés. Les autres caractères ne sont pas autorisés.

Exemples

Liste de runs           Ensemble
"-"               { }
"1"               { 1 }
"1-2"             { 1, 2 }
"-5--1"           { -5, -4, -3, -2, -1 }
"(-)"             les entiers
"(--1"            les entiers négatifs
"1-3, 4, 18-21"   { 1, 2, 3, 4, 18, 19, 20, 21 }

Référence de tableau

Si une référence à un tableau est transmise, les éléments du tableau spécifient les éléments de l'ensemble. Le tableau peut contenir

  • des entiers
  • des intervalles

L'ensemble est l'union de tous les entiers et intervalles du tableau. Les entiers et les intervalles ne sont pas nécessairement disjoints. Ils peuvent être dans n'importe quel ordre.

Exemples

Référence de tableau                         Ensemble
[ ]                               { }
[ 1, 1 ]                          { 1 }
[ 1, 3, 2 ]                       { 1, 2, 3 }
[ 1, [ 5, 8 ], 5, [ 7, 9 ], 2 ]   { 1, 2, 5, 6, 7, 8, 9 }
[ undef, undef ]                  les entiers
[ undef, -1 ]                     les entiers négatifs

ITÉRATEURS

Chaque ensemble a un unique itérateur, qui est partagé par tous les appels à "first", "last", "start", "next".

;, "précédent", et "courant". À tout moment, l'itérateur est soit un élément de l'ensemble, soit "undef".

"premier", "dernier", et "démarrer" définissent l'itérateur ; "suivant" et "précédent" le déplacent ; et "courant" le retournent. Les appels à ces méthodes peuvent être librement entrelacés.

En utilisant "suivant" et "précédent", une seule boucle peut avancer et reculer dans un ensemble. En utilisant "démarrer", une boucle peut itérer sur des portions d'un ensemble infini.

MÉTHODES

Création

$ensemble = "nouveau" "Set::IntSpan" $spéc_ensemble
$ensemble = "nouveau" "Set::IntSpan" @spéc_ensembles
Crée et retourne un objet "Set::IntSpan".

Le contenu initial de l'ensemble est donné par $spéc_ensemble, ou par l'union de tous les @spéc_ensembles.

$ok = "valide" "Set::IntSpan" $liste_courses
Retourne vrai si $liste_courses est une liste de courses valide. Sinon, retourne faux et laisse un message d'erreur dans $@.
$ensemble = "copie" $ensemble $spéc_ensemble
Copie $spéc_ensemble dans $ensemble. Le contenu précédent de $ensemble est perdu. Par commodité, "copie" retourne $ensemble.
$liste_courses = "liste_courses" $ensemble
Retourne une liste de courses qui représente $ensemble. La liste de courses ne contiendra pas d'espaces blancs. $ensemble n'est pas affecté.

Par défaut, l'ensemble vide est formaté comme '-'; une chaîne différente peut être spécifiée dans $Set::IntSpan::Chaine_Vide.

@éléments = "éléments" $ensemble
Retourne un tableau contenant les éléments de $ensemble. Les éléments seront triés par ordre numérique. En contexte scalaire, retourne une référence de tableau. $ensemble n'est pas affecté.
@ensembles = "ensembles" $ensemble
Retourne les courses dans $ensemble, sous forme d'une liste d'objets "Set::IntSpan". Les ensembles de la liste sont en ordre.
@intervalles = "intervalles" $ensemble
Retourne les courses dans $ensemble, sous forme d'une liste de la forme 
([$a1, $b1],
 [$a2, $b2],
 ...
 [$aN, $bN])

Si une course ne contient qu'un seul entier, alors les bornes supérieure et inférieure de l'intervalle correspondant seront égales.

Si l'ensemble n'a pas de borne inférieure, alors $a1 sera "undef". De même, si l'ensemble n'a pas de borne supérieure, alors $bN sera "undef".

Les courses de la liste sont en ordre.

Opérations sur les ensembles

Pour ces opérations, un nouvel objet "Set::IntSpan" est créé et retourné. Les opérandes ne sont pas affectés.

$e_union = "union" $ensemble $spéc_ensemble
Retourne l'ensemble des entiers dans soit $ensemble, soit $spéc_ensemble.
$e_intersection = "intersection" $ensemble $spéc_ensemble
Retourne l'ensemble des entiers dans à la fois $ensemble et $spéc_ensemble.
$e_xor = "xor" $ensemble $spéc_ensemble
Retourne l'ensemble des entiers dans $ensemble ou $spéc_ensemble, mais pas les deux.
$e_diff = "différence" $ensemble $spéc_ensemble
Retourne l'ensemble des entiers dans $ensemble mais pas dans $spéc_ensemble.
$e_complément = "complément" $ensemble
Retourne l'ensemble des entiers qui ne sont pas dans $ensemble.

Mutateurs

À la demande populaire, "Set::IntSpan" propose désormais des formes mutantes des opérations sur ensembles binaires. Ces méthodes modifient l'objet sur lequel elles sont appelées.

$ensemble->"U"($spéc_ensemble)
Fait de $ensemble l'union de $ensemble et de $spéc_ensemble. Retourne $ensemble.
$ensemble->"I"($spéc_ensemble)
Fait de $ensemble l'intersection de $ensemble et de $spéc_ensemble. Retourne $ensemble.
$ensemble->"X"($spéc_ensemble)
Fait de $ensemble la différence symétrique de $ensemble et $spéc_ensemble. Retourne $ensemble.
$ensemble->"D"($spéc_ensemble)
Fait de $ensemble la différence de $ensemble et de $spéc_ensemble. Retourne $ensemble.
$ensemble->"C"
Convertit $ensemble en son propre complément. Retourne $ensemble.

Comparaison

"égal" $ensemble $spéc_ensemble
Retourne vrai si $ensemble et $spéc_ensemble contiennent les mêmes éléments.
"équivalent" $ensemble $spéc_ensemble
Retourne vrai si $ensemble et $spéc_ensemble contiennent le même nombre d'éléments. Tous les ensembles infinis sont équivalents.
"superset" $ensemble $spéc_ensemble
Retourne vrai si $ensemble est un superset de $spéc_ensemble.
"subset" $ensemble $spéc_ensemble
Retourne vrai si $ensemble est un sous-ensemble de $spéc_ensemble.

Cardinalité

$n = "cardinalité" $ensemble
$n = "taille" $ensemble
Retourne le nombre d'éléments dans $ensemble. Retourne -1 pour les ensembles infinis. "taille" est fourni comme alias pour "cardinalité".
"vide" $ensemble
Retourne vrai si $ensemble est vide.
"fini" $ensemble
Retourne vrai si $ensemble est fini.
"neg_inf" $ensemble
Retourne vrai si $ensemble contient {x | x<n} pour un certain n.
"pos_inf" $ensemble
Retourne vrai si $ensemble contient {x | x>n} pour un certain n.
"infini" $ensemble
Retourne vrai si $ensemble est infini.
"universel" $ensemble
Retourne vrai si $ensemble contient tous les entiers.

Appartenance

"membre" $ensemble $n
Retourne vrai si l'entier $n est un membre de $ensemble.
"insérer" $ensemble $n
Insère l'entier $n dans $ensemble. Ne fait rien si $n est déjà membre de $ensemble.
"retirer" $ensemble $n
Retire l'entier $n de $ensemble. Ne fait rien si $n n'est pas membre de $ensemble.

Extrema

"min" $ensemble
Retourne le plus petit élément de $ensemble, ou "undef" s'il n'y en a pas.
"max" $ensemble
Retourne le plus grand élément de $ensemble, ou "undef" s'il n'y en a pas.

Spans

$holes = "holes" $set
Retourne un ensemble contenant tous les trous dans $set, c'est-à-dire tous les entiers qui sont entre les spans de $set.

"holes" est toujours un ensemble fini.

$cover = "cover" $set
Retourne un ensemble composé d'un seul span allant de $set->"min" à $set->"max". C'est la même chose que 
union $set $set->holes
$inset = "inset" $set $n
$smaller = "trim" $set $n
$bigger = "pad" $set $n
"inset" retourne un ensemble construit en retirant $n entiers de chaque extrémité de chaque span de $set. Si $n est négatif, alors -$n entiers sont ajoutés à chaque extrémité de chaque span.

Dans le premier cas, les spans peuvent disparaître de l'ensemble ; dans le second cas, les trous peuvent disparaître.

"trim" est fourni comme synonyme de "inset".

"pad" $set $n est la même chose que "inset" $set -$n.

Iterators

$set->"first"
Définit l'itérateur pour $set au plus petit élément de $set. S'il n'y a pas de plus petit élément, définit l'itérateur à "undef". Retourne l'itérateur.
$set->"last"
Définit l'itérateur pour $set au plus grand élément de $set. S'il n'y a pas de plus grand élément, définit l'itérateur à "undef". Retourne l'itérateur.
$set->"start"($n)
Définit l'itérateur pour $set à $n. Si $n n'est pas un élément de $set, définit l'itérateur à "undef". Retourne l'itérateur.
$set->"next"
Définit l'itérateur pour $set à l'élément suivant de $set. S'il n'y a pas d'élément suivant, définit l'itérateur à "undef". Retourne l'itérateur.

"next" retournera "undef" une seule fois ; le prochain appel à "next" réinitialisera l'itérateur au plus petit élément de $set.

$set->"prev"
Définit l'itérateur pour $set à l'élément précédent de $set. S'il n'y a pas d'élément précédent, définit l'itérateur à "undef". Retourne l'itérateur.

"prev" retournera "undef" une seule fois ; le prochain appel à "prev" réinitialisera l'itérateur au plus grand élément de $set.

$set->"current"
Retourne l'itérateur pour $set.

Indexation

Les éléments d'un ensemble sont conservés par ordre numérique. Ces méthodes indexent l'ensemble en fonction de cet ordre.

$n = $set->"at"($i)
Retourne le $i-ème élément de $set, ou "undef" s'il n'y a pas de $i-ème élément. Les indices négatifs comptent à rebours à partir de la fin de l'ensemble.

Dies si

  • $i est non négatif et $set est "neg_inf"
  • $i est négatif et $set est "pos_inf"
$slice = $set->"slice"($from, $to)
Retourne un objet "Set::IntSpan" contenant les éléments de $set aux indices $from..$to. Les indices négatifs comptent à rebours à partir de la fin de l'ensemble.

Dies si

  • $from est non négatif et $set est "neg_inf"
  • $from est négatif et $set est "pos_inf"
$i = $set->"ord"($n)
L'inverse de "at".

Retourne l'indice $i de l'entier $n dans $set, ou "undef" si $n n'est pas un élément de $set.

Dies si $set est "neg_inf".

$i = $set->"span_ord"($n)
Retourne l'indice $i du span contenant l'entier $n, ou "undef" si $n n'est pas un élément de $set.

Pour récupérer le span contenant $n, écrivez

($set->spans)[$i]

SURCHARGES D'OPÉRATEURS

Par souci de commodité, certains opérateurs sont surchargés sur les objets "Set::IntSpan".

Opérations sur les ensembles

Un opérande doit être un objet "Set::IntSpan". L'autre opérande peut être un objet "Set::IntSpan" ou une spécification d'ensemble.

$u_set =  $set + $set_spec;   # union
$i_set =  $set * $set_spec;   # intersection
$x_set =  $set ^ $set_spec;   # xor
$d_set =  $set - $set_spec;   # différence
$c_set = ~$set;               # complément
$set += $set_spec;            # union
$set *= $set_spec;            # intersection
$set ^= $set_spec;            # xor
$set -= $set_spec;            # différence

Égalité

Les opérations de comparaison de chaînes sont surchargées pour comparer les ensembles en termes d'égalité et de contenance. Un opérande doit être un objet "Set::IntSpan". L'autre opérande peut être un objet "Set::IntSpan" ou une spécification d'ensemble.

$set eq $set_spec             # égal
$set ne $set_spec             # non égal
$set le $set_spec             # sous-ensemble
$set lt $set_spec             # sous-ensemble propre
$set ge $set_spec             # sur-ensemble
$set gt $set_spec             # sur-ensemble propre

Équivalence

Les opérations de comparaison numérique sont surchargées pour comparer les ensembles par cardinalité. Un opérande doit être un objet "Set::IntSpan". L'autre opérande peut être un objet "Set::IntSpan" ou un entier.

$set1 ==  $set2
$set1 !=  $set2
$set1 <=  $set2
$set1 <   $set2
$set1 >=  $set2
$set1 >   $set2
$set1 <=> $set2
$set1 cmp $set2
$set1 ==  $n
$set1 !=  $n
$set1 <=  $n
$set1 <   $n
$set1 >=  $n
$set1 >   $n
$set1 <=> $n
$set1 cmp $n

N.B. L'opérateur "cmp" est surchargé pour comparer les ensembles par cardinalité, et non par contenance. Ceci est fait pour que

sort @sets

trie une liste d'ensembles par cardinalité.

Conversion

Dans un contexte booléen, un objet "Set::IntSpan" s'évalue à vrai s'il n'est pas vide.

Un objet "Set::IntSpan" se convertit en chaîne en sa liste de plages.

DESCRIPTION

Le module "Set::IntSpan" implémente des ensembles d'entiers sous la forme de listes de segments d'entiers.

Une liste de segments est une liste d'intervalles d'entiers disjoints et triés. Par exemple, une liste de segments qui représente l'ensemble {1, 2, 3, 5, 7, 8, 9} est "1-3,5,7-9".

La plupart des opérations sur les ensembles sont implémentées pour les listes de segments, notamment l'union, l'intersection, la différence, la symétrie, la différence, la containedance, la relation d'ordre, etc.

Les ensembles peuvent être finis ou infinis. Les ensembles finis sont représentés par des listes de segments. Les ensembles infinis sont représentés par les ensembles complémentaires de listes de segments.

Les classes suivantes sont fournies:

Set::IntSpan
La classe de base pour les ensembles d'entiers.
Set::IntSpan::Infinite
La classe pour les ensembles infinis.

Méthodes

Les méthodes suivantes sont disponibles:

new Set::IntSpan $string
Crée un nouvel objet Set::IntSpan à partir d'une chaîne représentant une liste de segments. La chaîne peut être vide, ou une liste de nombres séparés par des virgules, ou une liste d'intervalles séparés par des virgules, ou une combinaison des deux. Les espaces blancs sont ignorés. Les valeurs des bornes des intervalles peuvent être infinies (par exemple, "1-" pour les entiers supérieurs ou égaux à 1, "-5" pour les entiers inférieurs ou égaux à 5, et "-" pour tous les entiers).
new Set::IntSpan $integer
Crée un nouvel objet Set::IntSpan contenant un seul entier.
new Set::IntSpan [ $lower, $upper ]
Crée un nouvel objet Set::IntSpan contenant l'intervalle d'entiers inclusif de $lower à $upper. Si $lower est supérieur à $upper, l'ensemble résultant est vide.
new Set::IntSpan [ [ $lower1, $upper1 ], [ $lower2, $upper2 ], ... ]
Crée un nouvel objet Set::IntSpan à partir d'une liste de listes de segments. Les segments sont automatiquement triés et fusionnés pour former la représentation interne.
new Set::IntSpan Set::IntSpan
Crée une copie de l'objet Set::IntSpan donné.
valid $string
Renvoie TRUE si $string est une chaîne valide représentant une liste de segments, FALSE sinon. Ceci est utile pour la gestion des erreurs.
$set->add($integer)
$set->add([$lower, $upper])
$set->add(Set::IntSpan)
Ajoute un entier, un intervalle ou un autre ensemble à $set. Retourne 1 si l'ensemble a été modifié, 0 sinon.
$set->complement
Retourne un nouvel ensemble représentant le complément de $set.
$set->contains($integer)
$set->contains(Set::IntSpan)
Renvoie TRUE si $integer ou Set::IntSpan est contenu dans $set.
$set->cardinality
Retourne le nombre d'éléments dans $set. Peut retourner undef si l'ensemble est infini.
$set->elements
Retourne une liste de tous les entiers dans $set. Peut être très lent ou consommer beaucoup de mémoire pour les grands ensembles. Peut retourner undef si l'ensemble est infini.
$set->empty
Retourne TRUE si $set est vide.
$set->finite
Retourne TRUE si $set est fini.
$set->first
Retourne le plus petit entier dans $set. Retourne undef si l'ensemble est vide ou négativement infini.
$set->last
Retourne le plus grand entier dans $set. Retourne undef si l'ensemble est vide ou positivement infini.
$set->grep { ... } $set
Évalue le BLOCK pour chaque entier dans $set (définissant localement $_ à chaque entier) et retourne un objet "Set::IntSpan" contenant tous les entiers pour lesquels le BLOCK renvoie TRUE.
$set->intersect($other_set)
$set->intersection($other_set)
Retourne un nouvel ensemble représentant l'intersection de $set et de $other_set.
$set->is_empty
Identique à $set->empty.
$set->is_finite
Identique à $set->finite.
$set->is_infinite
Retourne TRUE si $set est infini.

Méthodes avancées

$mapped_set = "grep_set" { ... } $set
Évalue le BLOCK pour chaque entier dans $set (définissant localement $_ à chaque entier) et retourne un objet "Set::IntSpan" contenant tous les entiers pour lesquels le BLOCK renvoie TRUE.

Retourne "undef" si $set est infini.

$mapped_set = "map_set" { ... } $set
Évalue le BLOCK pour chaque entier dans $set (définissant localement $_ à chaque entier) et retourne un objet "Set::IntSpan" contenant tous les entiers retournés comme résultats de toutes ces évaluations.

Évalue le BLOCK en contexte de liste, de sorte que chaque élément de $set peut produire zéro, un ou plusieurs éléments dans l'ensemble retourné. Les éléments peuvent être retournés dans n'importe quel ordre et n'ont pas besoin d'être disjoints.

Retourne "undef" si $set est infini.

$sub_set = "grep_spans" { ... } $set
Évalue le BLOCK pour chaque segment dans $set et retourne un objet "Set::IntSpan" contenant les segments pour lesquels le BLOCK renvoie TRUE.

Dans le BLOCK, $_ est localement défini à un tableau de référence de la forme

[ $lower, $upper ]

où $lower et $upper sont les bornes du segment. Si le segment ne contient qu'un seul entier, alors $lower et $upper seront égaux. Si le segment est illimité, alors les éléments correspondants du tableau seront "undef".

$map_set = "map_spans" { ... } $set
Évalue le BLOCK pour chaque segment dans $set, et retourne un objet "Set::IntSpan" constitué de l'union de tous les segments retournés comme résultats de toutes ces évaluations.

Dans le BLOCK, $_ est localement défini à un tableau de référence de la forme

[ $lower, $upper ]

comme décrit ci-dessus pour "grep_spans". Chaque évaluation de BLOCK doit retourner une liste de segments. Chaque liste retournée peut contenir zéro, un ou plusieurs segments. Les segments peuvent être retournés dans n'importe quel ordre et n'ont pas besoin d'être disjoints. Cependant, pour chaque segment borné, la contrainte

$lower <= $upper

doit être satisfaite.

VARIABLES DE CLASSE

$Set::IntSpan::Empty_String
$Set::IntSpan::Empty_String contient la chaîne qui est retournée lorsque "run_list" est appelé sur l'ensemble vide. $Empty_String est initialement '-'; alternativement, il peut être défini à ''. D'autres valeurs devraient être évitées, pour garantir que "run_list" retourne toujours une liste de segments valide.

"run_list" accède à $Empty_String via une référence stockée dans $set->{"empty_string"}. Les sous-classes qui souhaitent remplacer la valeur de $Empty_String peuvent réassigner cette référence.

$Set::IntSpan::integer
Jusqu'à la version 1.16, "Set::IntSpan" spécifiait "use integer", car il s'agissait d'ensembles d'... vous savez... d'entiers. Depuis 2012, les utilisateurs signalent des newsgroups avec des numéros d'articles supérieurs à 0x7fffffff, ce qui casse "Set::IntSpan" sur les processeurs 32 bits.

La version 1.17 supprime "use integer" par défaut. Cela étend la plage utilisable de "Set::IntSpan" au nombre de bits dans la mantisse de votre représentation flottante. Pour les doubles IEEE 754, cela représente 53 bits, soit environ 9e15.

J'ai benchmarké "Set::IntSpan" sur un Pentium 4, et il semble que "use integer" fournisse un gain de vitesse de 2% à 4%, selon l'application.

Si vous souhaitez récupérer "use integer", que ce soit pour des raisons de performance, ou parce que vous dépendez d'une manière ou d'une autre de sa sémantique, écrivez

BEGIN { $Set::IntSpan::integer = 1 }
use Set::IntSpan;

NOTES

Pièges

Méfiez-vous des formes comme

union $set [1..5];

Cela passe un élément de @set à union, ce qui n'est probablement pas ce que vous voulez. Pour forcer l'interprétation de $set et [1..5] comme arguments séparés, utilisez des formes comme

union $set +[1..5];

ou

$set->union([1..5]);

grep_set et map_set

"grep_set" et "map_set" facilitent la construction d'ensembles pour lesquels la représentation interne utilisée par "Set::IntSpan" n'est pas petite. Considérez:

$billion = new Set::IntSpan '0-1_000_000_000';   # OK
$odd     = grep_set { $_ & 1 } $billion;         # problème
$even    = map_set  { $_ * 2 } $billion;         # double problème

Gestion des erreurs

Il existe deux approches courantes pour la gestion des erreurs : les exceptions et les codes de retour. Il semble y avoir des divergences à ce sujet, "Set::IntSpan" prend donc en charge les deux.

Pour intercepter les exceptions, protégez les appels de méthode avec un eval:

$run_list = <STDIN>;
eval { $set = new Set::IntSpan $run_list };
$@ and print "$@: try again\n";

Pour vérifier les codes de retour, utilisez un appel de méthode approprié pour valider les arguments:

$run_list = <STDIN>;
if (valid Set::IntSpan $run_list)
   { $set = new Set::IntSpan $run_list }
else
   { print "$@ try again\n" }

De même, utilisez "finite" pour protéger les appels à "elements":

finite $set and @elements = elements $set;

Appeler "elements" sur un grand ensemble fini peut générer un message « Out of memory! », qui ne peut pas (facilement) être intercepté. Les applications qui doivent conserver le contrôle après une erreur peuvent utiliser "intersect" pour protéger les appels à "elements":

@elements = elements { intersect $set "-1_000_000 - 1_000_000" };

ou vérifier la taille de $set d'abord:

finite $set and cardinality $set < 2_000_000 and @elements = elements $set;

Limitations

Bien que "Set::IntSpan" puisse représenter certains ensembles infinis, il n'effectue pas d'arithmétique à précision infinie. Par conséquent, les éléments finis sont limités à la plage des entiers de votre machine.

Extensions

Les utilisateurs rapportent que vous pouvez construire des objets Set::IntSpan sur tout ce qui se comporte comme un entier. Par exemple:

$x   = new Math::BigInt ...;
$set = new Set::Intspan [ [ $x, $x+5 ] ];

Je ne documente pas cela comme un comportement pris en charge, car je n'ai pas les ressources pour le tester, mais j'essaierai de ne pas le casser. Si quelqu'un rencontre des problèmes avec, faites-le moi savoir.

Origines

Les ensembles implémentés ici sont basés sur une structure de données Macintosh appelée *région*. Voir Inside Macintosh pour plus d'informations.

"Set::IntSpan" a été initialement écrit pour gérer les listes de segments pour le module "News::Newsrc".

Set::IntSpan - Perl manual page

NAME

Set::IntSpan - A set of integer spans

SYNOPSIS

    use Set::IntSpan;

    $set = Set::IntSpan->new(); # empty set
    $set = Set::IntSpan->new(1, 3, 5); # set of single integers
    $set = Set::IntSpan->new([1, 3, 5]); # same
    $set = Set::IntSpan->new(1, 3..5, 8, 10..12); # set of spans
    $set = Set::IntSpan->new([1, 3..5, 8, 10..12]); # same

    $set2 = Set::IntSpan->new(1..5, 8..10);
    $set->insert(4, 7); # insert single integers or spans
    $set->insert(9..11);
    $set->delete(2, 5..8);

    $set3 = $set + $set2; # union
    $set4 = $set - $set2; # difference
    $set5 = $set * $set2; # intersection

    print $set->as_string(); # "1, 3, 5, 7, 9..12"
    print $set->as_list(); # (1, 3, 5, 7, 9, 10, 11, 12)
    print $set->as_array(); # \@array of integers
    print $set->as_range_array(); # \@array of [min, max] pairs

    if ($set->contains(5)) { ... }
    if ($set->contains(5..7)) { ... }
    if ($set->is_superset($set2)) { ... }
    if ($set->is_disjoint($set2)) { ... }
    print $set->count(); # number of integers in the set
    print $set->min(); # minimum integer in the set
    print $set->max(); # maximum integer in the set
    print $set->first(); # same as min
    print $set->last(); # same as max
    print $set->first_after(6); # smallest integer in set > 6
    print $set->first_before(6); # largest integer in set < 6
    print $set->first_ge(6); # smallest integer in set >= 6
    print $set->first_le(6); # largest integer in set <= 6

    $iterator = $set->iterator();
    while (my $int = $iterator->next()) {
        print "$int ";
    }

    $set = Set::IntSpan->from_string("1, 3, 5, 7, 9..12");
    $set = Set::IntSpan->from_list(1, 3, 5, 7, 9, 10, 11, 12);
    $set = Set::IntSpan->from_array(\@array_of_ints);
    $set = Set::IntSpan->from_range_array(\@array_of_ranges);

    # See perldoc Set::IntSpan::Hash for Set::IntSpan::Hash

EXPORTS

None by default. It exports the functions new, from_string, from_list, from_array, and from_range_array on request.

DESCRIPTION

This module implements sets of integers using a compact representation. It is designed to be efficient in both memory and speed.

A set of integers is represented as a sorted list of disjoint integer spans. A span is a contiguous range of integers.

For example, the set {1, 3, 4, 5, 7, 9, 10, 11, 12} would be represented internally as the list of spans: (1,1), (3,5), (7,7), (9,12).

The module overloads the standard operators +, -, and * to perform union, difference, and intersection respectively. It also provides methods for common set operations.

SPANS

A span is represented as a pair of integers, the minimum and maximum value in the span, inclusive. A single integer n is represented as the span (n,n).

SET SPECIFICATIONS

You can specify a set of integers in several ways:

  • As a list of integers: 1, 3, 5
  • As a list of spans: 1..5, 8, 10..12
  • As a reference to an array of integers: [1, 3, 5]
  • As a reference to an array of spans: [1..5, 8, 10..12]
  • As a string: "1, 3, 5, 7, 9..12"

When creating a new Set::IntSpan object, the constructor will automatically merge overlapping or adjacent spans and sort them.

ITERATORS

The iterator method returns an iterator object that can be used to loop through the integers in the set. The iterator yields integers one by one in ascending order.

NOTES

This module is intended to be efficient. If you only need to store a few integers, a simple array or hash might be more appropriate. This module shines when dealing with large sets of integers, especially when those integers form contiguous spans.

The Set::IntSpan::Hash module provides an alternative implementation that uses a hash of spans, which might be more efficient for very sparse sets.
