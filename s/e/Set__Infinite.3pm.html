NOM

Set::Infinite - Ensembles d'intervalles

SYNOPIS

use Set::Infinite;
$set = Set::Infinite->new(1,2);    # [1..2]
print $set->union(5,6);            # [1..2],[5..6]

DESCRIPTION

Set::Infinite est un module de théorie des ensembles pour les ensembles infinis.

Un ensemble est une collection d'objets. Les objets qui appartiennent à un ensemble sont appelés ses membres, ou "éléments".

Comme objets, nous autorisons (presque) tout : nombres réels, entiers, et objets (comme des dates).

Nous autorisons les ensembles à être infinis.

L'ordre des éléments n'est pas pris en compte. Par exemple, {1,2} = {2,1}.

La répétition des éléments n'est pas prise en compte. Par exemple, {1,2,2} = {1,1,1,2} = {1,2}.

CONSTRUCTEUR

new

Crée un nouvel objet ensemble :

$set = Set::Infinite->new;             # ensemble vide
$set = Set::Infinite->new( 10 );       # élément unique
$set = Set::Infinite->new( 10, 20 );   # intervalle unique
$set = Set::Infinite->new( 
          [ 10, 20 ], [ 50, 70 ] );    # deux intervalles
ensemble vide
$set = Set::Infinite->new;
ensemble avec un unique élément
$set = Set::Infinite->new( 10 );
$set = Set::Infinite->new( [ 10 ] );
ensemble avec une unique plage
$set = Set::Infinite->new( 10, 20 );
$set = Set::Infinite->new( [ 10, 20 ] );
# 10 <= x <= 20
ensemble avec une unique, plage ouverte
$set = Set::Infinite->new(
    {
        a => 10, open_begin => 0,
        b => 20, open_end => 1,
    }
);
# 10 <= x < 20
ensemble avec plusieurs plages
$set = Set::Infinite->new( 10, 20,  100, 200 );
$set = Set::Infinite->new( [ 10, 20 ], [ 100, 200 ] );
$set = Set::Infinite->new(
    {
        a => 10, open_begin => 0,
        b => 20, open_end => 0,
    },
    {
        a => 100, open_begin => 0,
        b => 200, open_end => 0,
    }
);

La méthode new() attend des paramètres *ordonnés*.

Si vous avez des plages désordonnées, vous pouvez construire l'ensemble en utilisant "union" :

@ranges = ( [ 10, 20 ], [ -10, 1 ] );
$set = Set::Infinite->new;
$set = $set->union( @$_ ) for @ranges;

Les structures de données passées à "new" doivent être *immuables*. Donc, ce n'est pas une bonne pratique :

$set = Set::Infinite->new( $object_a, $object_b );
$object_a->set_value( 10 );

Voici la manière recommandée de faire :

$set = Set::Infinite->new( $object_a->clone, $object_b->clone );
$object_a->set_value( 10 );

clone / copie

Crée un nouvel objet et copie les données de l'objet.

ensemble_vide

Crée un ensemble vide.

Si elle est appelée à partir d'un ensemble existant, l'ensemble vide hérite des caractéristiques de "type" et de "densité".

ensemble_universel

Crée un ensemble contenant "tous" les éléments possibles.

Si elle est appelée à partir d'un ensemble existant, l'ensemble universel hérite des caractéristiques de "type" et de "densité".

FONCTIONS ENSEMBLE

union

$set = $set->union($b);

Retourne l'ensemble de tous les éléments des deux ensembles.

Cette fonction se comporte comme une opération "OU".

$set1 = new Set::Infinite( [ 1, 4 ], [ 8, 12 ] );
$set2 = new Set::Infinite( [ 7, 20 ] );
print $set1->union( $set2 );
# sortie : [1..4],[7..20]

intersection

$set = $set->intersection($b);

Retourne l'ensemble des éléments communs aux deux ensembles.

Cette fonction se comporte comme une opération "ET".

$set1 = new Set::Infinite( [ 1, 4 ], [ 8, 12 ] );
$set2 = new Set::Infinite( [ 7, 20 ] );
print $set1->intersection( $set2 );
# sortie : [8..12]

complement

moins

difference

$set = $set->complement;

Retourne l'ensemble de tous les éléments qui n'appartiennent pas à l'ensemble.

$set1 = new Set::Infinite( [ 1, 4 ], [ 8, 12 ] );
print $set1->complement;
# sortie : (-inf..1),(4..8),(12..inf)

La fonction complément peut prendre un paramètre :

$set = $set->minus($b);

Retourne la différence d'ensembles, c'est-à-dire les éléments qui n'appartiennent pas à l'ensemble donné.

$set1 = new Set::Infinite( [ 1, 4 ], [ 8, 12 ] );
$set2 = new Set::Infinite( [ 7, 20 ] );
print $set1->minus( $set2 );
# sortie : [1..4]

difference_symetrique

Retourne un ensemble contenant les éléments qui sont dans l'un ou l'autre ensemble, mais pas dans les deux. C'est la version "ensemble" de "XOR".

METHODES DENSITE

reel

$set1 = $set->real;

Retourne un ensemble avec une densité "0".

entier

$set1 = $set->integer;

Retourne un ensemble avec une densité "1".

FONCTIONS LOGIQUE

intersects

$logic = $set->intersects($b);

contient

$logic = $set->contains($b);

est_vide

est_nul

$logic = $set->is_null;

est_non_vide

Cet ensemble a au moins 1 élément.

est_plage

Cet ensemble a une seule plage ou intervalle.

est_singleton

Cet ensemble a un seul élément.

est_sous_ensemble( $set )

Chaque élément de cet ensemble est un membre de l'ensemble donné.

est_sous_ensemble_propre( $set )

Chaque élément de cet ensemble est un membre de l'ensemble donné. Certains membres de l'ensemble donné ne sont pas des éléments de cet ensemble.

est_disjoint( $set )

L'ensemble donné n'a aucun élément en commun avec cet ensemble.

est_trop_complexe

Parfois, un ensemble peut être trop complexe à énumérer ou à afficher.

Cela se produit avec des ensembles qui représentent des récurrences infinies, comme lorsque vous demandez une quantification sur un ensemble limité par -inf ou inf.

Maintenez toute la structure du fichier.

FONCTIONS DE SET SPÉCIALES

span

$set1 = $set->span;

Renvoie le span du set.

until

Étends un set jusqu'à un autre :

0,5,7 -> until 2,6,10

donne

[0..2), [5..6), [7..10)

start_set

end_set

Ces méthodes font l'inverse de la méthode "until".

Étant donné :

[0..2), [5..6), [7..10)

start_set est :

0,5,7

end_set est :

2,6,10

intersected_spans

$set = $set1->intersected_spans( $set2 );

La méthode renvoie un nouveau set contenant tous les spans qui sont intersectés par le set donné.

Différent de la méthode "intersection", les spans ne sont pas modifiés. Voir le diagramme ci-dessous :

             set1   [....]   [....]   [....]   [....]
             set2      [................]
     intersection      [.]   [....]   [.]
intersected_spans   [....]   [....]   [....]

quantize

quantize( parameters )
    divise les sets en sous-ensembles de taille égale.
    renvoie un set ordonné de sous-ensembles de taille égale.
    exemple :
        $set = Set::Infinite->new([1,3]);
        print join (" ", $set->quantize( quant => 1 ) );
    donne :
        [1..2) [2..3) [3..4)

select

select( parameters )

Sélectionne les spans du set selon leurs positions ordonnées.

Le "select" a un comportement similaire à un "slice" de tableau.

           by       - default=All
           count    - default=Infinity
0  1  2  3  4  5  6  7  8      # set original
0  1  2                        # count => 3
   1              6            # by => [ -2, 1 ]

offset

offset ( parameters )

Déplace les sous-ensembles. Paramètres :

value   - défaut=[0,0]
mode    - défaut='offset'. Valeurs possibles : 'offset', 'begin', 'end'.
unit    - type de valeur. Peut être 'days', 'weeks', 'hours', 'minutes', 'seconds'.

iterate

iterate ( sub { } , @args )

Itère sur les spans du set, en utilisant une sous-routine de rappel. Renvoie l'union de tous les résultats partiels.

L'argument de rappel $_[0] est un span. S'il y a des arguments supplémentaires, ils sont passés au rappel.

Le rappel peut renvoyer un span, un hashref (voir "Set::Infinite::Basic"), un scalaire, un objet ou "undef".

[EXPÉRIMENTAL] "iterate" accepte un paramètre optionnel "backtrack_callback". Le but du "backtrack_callback" est d' *inverser* le fonctionnement de iterate(), dépassant les limites de l'algorithme de retour arrière interne. Le format est :

iterate ( sub { } , backtrack_callback => sub { }, @args )

Le "backtrack_callback" peut renvoyer un span, un hashref, un scalaire, un objet ou "undef".

Par exemple, le snippet suivant ajoute une valeur constante à chaque élément d'un set non borné :

$set1 = $set->iterate(
             sub { $_[0]->min + 54, $_[0]->max + 54 },
          backtrack_callback =>
             sub { $_[0]->min - 54, $_[0]->max - 54 },
          );

first / last

first / last

En contexte scalaire renvoie l'intervalle initial ou final d'un set.

En contexte liste renvoie l'intervalle initial ou final d'un set, et le set restant (la 'queue').

Voir aussi : méthodes "min", "max", "min_a", "max_a".

ATTENTION

  • notation de "span" du constructeur 
    $set = Set::Infinite->new(10,1);

    Sera interprété comme [1..10]

  • notation de "multiple-span" du constructeur 
    $set = Set::Infinite->new(1,2,3,4);

    Sera interprété comme [1..2],[3..4] au lieu de [1,2,3,4]. Vous voudrez probablement ->new([1],[2],[3],[4]) ou ->new(1,4)

  • opérateur "range" du constructeur 
    $set = Set::Infinite->new(1..3);

    Sera interprété comme [1..2],3 au lieu de [1,2,3]. Vous voudrez probablement ->new(1,3) à la place.

INTERNES

L'objet de base *set* sans récurrences est un "Set::Infinite::Basic".

Un *recurrence-set* est représenté par un *nom de méthode*, un ou deux *objets parents* et des paramètres supplémentaires. Le "list" est mis à un tableau vide, et le "too_complex" à 1.

Ceci est une structure qui contient l'union de deux *ensembles complexes* :

{
  too_complex => 1,             # "c'est une récurrence"
  list   => [ ],                # non utilisé
  method => 'union',            # nom de la fonction
  parent => [ $set1, $set2 ],   # "feuilles" dans l'arbre syntaxique
  param  => [ ]                 # paramètres optionnels pour la fonction
}

Ceci est une structure qui contient le complément d'un *ensemble complexe* :

{
  too_complex => 1,             # "c'est une récurrence"
  list   => [ ],                # non utilisé
  method => 'complement',       # nom de la fonction
  parent => $set,               # "feuille" dans l'arbre syntaxique
  param  => [ ]                 # paramètres optionnels pour la fonction
}

NOM

Set::Infinite - Ensemble de valeurs infinies

SYNOPIS

x-tree
  param  => [ ]                 # arguments optionnels pour la fonction

DESCRIPTION

Set::Infinite est un module Perl qui fournit un ensemble de valeurs infinies. Il vous permet de créer et de manipuler des ensembles de taille infinie, ce qui est utile dans les scénarios où vous devez gérer des ensembles de données volumineux ou illimités.

CONSTRUCTEUR

Le constructeur de Set::Infinite est généralement appelé avec une référence de hachage qui spécifie les paramètres initiaux. Les paramètres sont optionnels et peuvent être fournis dans n'importe quel ordre.

FONCTIONS ENSEMBLE

Set::Infinite fournit diverses fonctions pour manipuler des ensembles. Celles-ci incluent des fonctions pour ajouter des éléments, supprimer des éléments, vérifier l'appartenance, et plus encore.

METHODES DENSITE

Les méthodes de densité dans Set::Infinite sont utilisées pour déterminer la densité d'un ensemble, qui fait référence à la proportion d'éléments uniques ou ayant certaines propriétés.

FONCTIONS LOGIQUE

Les fonctions logiques dans Set::Infinite sont utilisées pour effectuer des opérations logiques sur des ensembles, telles que l'union, l'intersection et la différence.

FONCTIONS SCALAIRES

Les fonctions scalaires dans Set::Infinite sont utilisées pour effectuer des opérations sur des éléments individuels d'un ensemble, telles que le comptage d'éléments ou la vérification de l'existence d'un élément.

OPERATEURS SUDERCHARGES

Set::Infinite prend en charge les opérateurs surchargés pour des opérations d'ensemble pratiques, telles que l'ajout, la suppression et la vérification d'éléments.

METHODES CLASSE

Les méthodes de classe dans Set::Infinite sont utilisées pour effectuer des opérations sur l'ensemble entier, telles que la création de nouveaux ensembles ou la modification d'ensembles existants.

FONCTIONS ENSEMBLE SPECIALES

Les fonctions d'ensemble spéciales dans Set::Infinite sont utilisées pour effectuer des opérations uniques sur des ensembles, telles que la génération de séquences infinies ou la vérification de propriétés spécifiques.

FONCTIONS INTERNES

Les fonctions internes dans Set::Infinite sont utilisées pour effectuer des opérations de bas niveau qui ne font pas partie de l'API publique, telles que la gestion des structures de données internes.

CAVEATS

Certains avertissements à considérer lors de l'utilisation de Set::Infinite incluent le potentiel de boucles infinies et la nécessité d'une gestion efficace des données.

INTERNES

Les internes dans Set::Infinite font référence aux structures de données et aux algorithmes internes utilisés pour gérer efficacement les ensembles.
