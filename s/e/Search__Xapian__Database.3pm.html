NOM

Search::Xapian::Database - Objet de base de données de recherche

DESCRIPTION

Cette classe représente une base de données Xapian pour la recherche. Voir Search::Xapian::WritableDatabase pour un objet adapté à l'indexation. Pour effectuer des recherches, cette classe fonctionne avec l'objet Search::Xapian::Query.

MÉTHODES

new <database>
Constructeur de classe. Peut prendre soit un chemin vers une base de données existante, soit une autre classe de base de données comme premier paramètre.
clone
Retourne un clone de cette classe.
add_database
Ajoute une base de données existante (ou un groupe de bases de données) à celles accédées par cet objet.
reopen
Rouvre la ou les bases de données à la ou aux dernières versions disponibles. Elle peut être utilisée soit pour s'assurer que les derniers résultats sont renvoyés, soit pour récupérer d'une erreur Xapian::DatabaseModifiedError.
close
Ferme la base de données. Ceci implique également un commit() sauf si une transaction est en cours.
enquire [<query>]
Retourne un nouvel objet Search::Xapian::Enquire. Tous les paramètres supplémentaires sont transmis à set_query.
get_doccount
Retourne le nombre de documents indexés dans cette base de données.
get_lastdocid
Retourne l'ID du dernier document utilisé.
get_doclength <doc_id>
Retourne la longueur d'un document donné.
get_document <doc_id>
Retourne un objet Search::Xapian::Document pour le document donné.
get_avlength
Obtient la longueur moyenne des documents dans la base de données.
get_termfreq <term>
Obtient le nombre de documents dans la base de données indexés par un terme donné.
term_exists <term>
Retourne vrai si ce terme existe dans la base de données, faux sinon.
get_description
Retourne une description de cet objet.
get_spelling_suggestion
Retourne une suggestion de correction orthographique.
allterms_begin [<prefix>]
Retourne un Search::Xapian::TermIterator itérant sur la liste de termes pour la base de données entière. Si l'argument préfixe optionnel n'est pas vide, seuls les termes commençant par cette chaîne sont retournés.
allterms_end [<prefix>]
Retourne un Search::Xapian::TermIterator pointant vers la fin de la liste de termes correspondant à allterms_begin.
termlist_begin <docid>
Retourne un Search::Xapian::TermIterator pointant vers le début de la liste de termes pour un document donné.
termlist_end <docid>
Retourne un Search::Xapian::TermIterator pointant vers la fin de la liste de termes pour un document donné.
positionlist_begin <docid> <term>
Retourne un Search::Xapian::PositionIterator pointant vers le début de la liste de positions pour un terme donné dans le document donné.
positionlist_end <docid> <term>
Retourne un Search::Xapian::PositionIterator pointant vers la fin de la liste de positions pour un terme donné dans le document donné.
postlist_begin <term>
Retourne un Search::Xapian::PostingIterator pointant vers le début de la liste des occurrences pour un terme donné.
postlist_end <term>
Retourne un Search::Xapian::PostingIterator pointant vers la fin de la liste des occurrences pour un terme donné.
keep_alive
Envoie un "keep-alive" aux bases de données distantes pour éviter qu'elles ne expirent.
get_collection_freq <term>
Obtient le nombre d'éléments indexés par un terme donné.

VOIR AUSSI
