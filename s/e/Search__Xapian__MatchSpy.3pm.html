NOM

Search::Xapian::MatchSpy - classe de base abstraite pour les espions de correspondance.

DESCRIPTION

Ceci est une classe de base abstraite pour les espions de correspondance dans Xapian.

Les sous-classes accumuleront généralement des informations vues pendant la correspondance, afin de calculer des fonctions agrégées, ou d'autres profils des documents correspondants.

MÉTHODES

opérateur() <Document> <poids>
Virtuelle - doit être implémentée dans les classes d'extension. Enregistre un document auprès de l'espion de correspondance.

Ceci est appelé par le moteur de recherche une fois avec chaque document vu par le moteur de recherche pendant le processus de correspondance. Notez que le moteur de recherche ne verra souvent pas tous les documents qui correspondent à la requête, en raison des optimisations qui permettent de sauter les documents de faible poids, et qui permettent de terminer le processus de correspondance plus tôt.

get_description
Retourne une chaîne décrivant cet objet.

Cette implémentation par défaut retourne une réponse générique, afin d'éviter de forcer ceux qui dérivent leurs propres sous-classes MatchSpy à implémenter ceci (ils peuvent ne pas se soucier de ce que get_description() donne pour leur sous-classe).

Réimplémentée dans Xapian::ValueCountMatchSpy.

name
Retourne le nom de cet espion de correspondance.

Ce nom est utilisé par le backend distant. Il est passé avec les paramètres sérialisés au serveur distant afin qu'il sache quelle classe créer. Retournez le nom complet qualifié par l'espace de noms de votre classe ici. Si vous ne voulez pas supporter le backend distant dans votre espion de correspondance, vous pouvez utiliser l'implémentation par défaut qui lève simplement Xapian::UnimplementedError.

Réimplémentée dans Xapian::ValueCountMatchSpy.
