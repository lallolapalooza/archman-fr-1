Set::Infinite::Basic(3) Documentation Perl fournie par l'utilisateur Set::Infinite::Basic(3)

NOM

Set::Infinite::Basic - Ensembles d'intervalles 6 =head1 SYNOPSIS

use Set::Infinite::Basic;
$set = Set::Infinite::Basic->new(1,2);    # [1..2]
print $set->union(5,6);            # [1..2],[5..6]

DESCRIPTION

Set::Infinite::Basic est un module de théorie des ensembles pour les ensembles infinis.

Il fonctionne sur les réels, les entiers et les objets.

Ce module ne prend pas en charge les récurrences. Les récurrences sont implémentées dans Set::Infinite.

MÉTHODES

ensemble_vide

Crée un ensemble vide.

Si appelée depuis un ensemble existant, l'ensemble vide hérite des caractéristiques de "type" et de "densité".

ensemble_universel

Crée un ensemble contenant "tous" les éléments possibles.

Si appelée depuis un ensemble existant, l'ensemble universel hérite des caractéristiques de "type" et de "densité".

jusquà

Étends un ensemble jusqu'à un autre :

0,5,7 -> jusquà 2,6,10

donne

[0..2), [5..6), [7..10)

Note : cette fonction est encore expérimentale.

copie

clone

Crée un nouvel objet à partir des données de l'objet.

Fonctions de mode :

$set = $set->real;
$set = $set->integer;

Fonctions logiques :

$logic = $set->intersects($b);
$logic = $set->contains($b);
$logic = $set->is_null;  # aussi appelé "is_empty"

Fonctions d'ensemble :

$set = $set->union($b);    
$set = $set->intersection($b);
$set = $set->complement;
$set = $set->complement($b);   # peut aussi être appelé "minus" ou "difference"
$set = $set->symmetric_difference( $b );
$set = $set->span;   
    le résultat est (min .. max)

Fonctions scalaires :

$i = $set->min;
$i = $set->max;
$i = $set->size;  
$i = $set->count;  # nombre d'intervalles

Fonctions Perl surchargées :

print    
sort, <=>

Fonctions globales :

    choisit les séparateurs d'intervalles. 
    par défaut sont [ ] ( ) '..' ','.

    retourne un nombre 'Infini'.

    retourne un nombre '-Infini'.

    Itère sur une sous-routine. 
    Retourne l'union des résultats partiels.

CAVEATS

$set = Set::Infinite->new(10,1);
    Sera interprété comme [1..10]
$set = Set::Infinite->new(1,2,3,4);
    Sera interprété comme [1..2],[3..4] au lieu de [1,2,3,4].
    Vous voudrez probablement plutôt ->new([1],[2],[3],[4]),
    ou peut-être ->new(1,4) 
$set = Set::Infinite->new(1..3);
    Sera interprété comme [1..2],3 au lieu de [1,2,3].
    Vous voudrez probablement plutôt ->new(1,3) au lieu de cela.

INTERNES

La représentation interne d'un intervalle est une table de hachage :

{ a =>   début de l'intervalle,
  b =>   fin de l'intervalle,
  open_begin =>   '0' l'intervalle commence à 'a'
                  '1' l'intervalle commence après 'a'
  open_end =>     '0' l'intervalle se termine à 'b'
                  '1' l'intervalle se termine avant 'b'
}

Par exemple, cet ensemble :

[100..200),300,(400..infinity)

est représenté par le tableau de tables de hachage :

list => [
    { a => 100, b => 200, open_begin => 0, open_end => 1 },
    { a => 300, b => 300, open_begin => 0, open_end => 0 },
    { a => 400, b => infinity, open_begin => 0, open_end => 1 },
]

La densité d'un ensemble est stockée dans la variable "tolerance" :

tolerance => 0;  # l'ensemble est composé de nombres réels.
tolerance => 1;  # l'ensemble est composé d'entiers.

La variable "type" stocke la classe des objets qui seront stockés dans l'ensemble.

type => 'DateTime';   # c'est un ensemble d'objets DateTime

La valeur de l'infini est générée par Perl, lorsqu'il trouve un dépassement numérique :

$inf = 100**100**100;
