NOM

Search::Xapian::ValueCountMatchSpy - Classe pour compter les fréquences des valeurs dans les documents correspondants.

SYNOPIS

use Search::Xapian qw(:all);
my $db = Search::Xapian::Database->new( '[RÉPERTOIRE DE BASE DE DONNÉES]' );
my $enq = $db->enquire( '[TERME DE RECHERCHE]' );
my $spy = Search::Xapian::ValueCountMatchSpy->new(0);
$enq->add_matchspy($spy);
my $mset = $enq->get_mset(0, 10, 10000);
print "Espion de correspondance enregistré pour " . $spy->get_total() . " documents\n";
my $end = $spy->values_end();
for (my $it = $spy->values_begin(); $it != $end; $it++) {
  print $it->get_termname() . " - " . $it->get_termfreq();
}

DESCRIPTION

Classe pour compter les fréquences des valeurs dans les documents correspondants. Enveloppe Xapian::ValueCountMatchSpy

MÉTHODES

new
Constructeur. Prend soit aucun paramètre, soit un seul paramètre valueno identifiant le créneau.
get_total
Retourne le nombre total de documents comptabilisés.
values_begin
Obtient un itérateur sur les valeurs vues dans le créneau.
values_end
Itérateur de fin correspondant à values_begin().
top_values_begin <maxvaleurs>
Obtient un itérateur sur les valeurs les plus fréquentes vues dans le créneau.
top_values_end <maxvaleurs>
Itérateur de fin correspondant à top_values_begin().

VOIR AUSSI

Search::Xapian, Search::Xapian::MatchSpy
