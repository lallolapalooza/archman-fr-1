Sys::Hostname::Long(3) Documentation soumise par les utilisateurs Perl Sys::Hostname::Long(3)

NAME

Essayer chaque méthode possible pour obtenir le nom d'hôte complet

SYNOPSIS

use Sys::Hostname::Long;
$host_long = hostname_long;

DESCRIPTION

Comment obtenir le nom d'hôte complet en Perl sur plusieurs systèmes d'exploitation (mac, windows, unix* etc)

DISCUSSION

Ceci est le deuxième lancement de ce code. Il a un meilleur ensemble de tests et des interfaces améliorées, mais il n'arrive toujours pas à obtenir le nom d'hôte complet sur de nombreux systèmes. C'est la raison pour laquelle j'ai écrit ce module, il est difficile d'obtenir le nom d'hôte complet sur chaque système. Sur certains systèmes (par exemple : Linux) cela dépend de l'ordre des entrées dans /etc/hosts.

Pour faciliter les tests, j'ai créé testall.pl qui génère une liste de toutes les méthodes de sortie. Ainsi, même si la logique est incorrecte, il est peut-être possible d'obtenir le nom d'hôte complet.

Essayer plusieurs méthodes pour obtenir le nom d'hôte complet du système. La classe Sys::Hostname est la meilleure et la manière standard d'obtenir le nom d'hôte du système. Cependant, le nom long est manquant.

Remerciements spéciaux à David Sundstrom et Greg Bacon pour le Sys::Hostname original.

LIMITATIONS CONNUES

Unix

La plupart des systèmes Unix ont du mal à déterminer le nom de domaine pleinement qualifié car il doit être correctement configuré quelque part dans le système. Par exemple, dans la plupart des systèmes Linux (Debian, ?), le nom pleinement qualifié doit être la première entrée à côté du numéro IP dans /etc/hosts

192.168.0.1     fred.somwhere.special   fred

Si c'est l'inverse, cela échouera.
