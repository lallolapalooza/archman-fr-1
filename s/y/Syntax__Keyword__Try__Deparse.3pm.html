NOM

"Syntax::Keyword::Try::Deparse" - Support B::Deparse pour Syntax::Keyword::Try

DESCRIPTION

Le chargement de ce module appliquera quelques astuces à B::Deparse qui tentent de fournir un support de décompilation pour le code qui utilise la syntaxe fournie par Syntax::Keyword::Try.

À FAIRE

Gérer correctement les cas de dispatch typés ("catch($var isa CLASS)", "catch($var =~ m/pattern/)")
