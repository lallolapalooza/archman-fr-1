Sys::Virt::Secret(3pm) Documentation Perl fournie par l'utilisateur Sys::Virt::Secret(3pm)

NOM

Sys::Virt::Secret - Représenter & gérer un secret libvirt

DESCRIPTION

Le module "Sys::Virt::Secret" représente un secret géré par le moniteur de machine virtuelle.

MÉTHODES

mon $uuid = $sec->get_uuid()
Retourne une chaîne de 16 octets contenant l'identifiant unique mondial (UUID) brut pour le secret.
mon $uuid = $sec->get_uuid_string()
Retourne une représentation textuelle de l'UUID brut, au format 'XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX'.
mon $type = $sec->get_usage_type()
Retourne le type d'utilisation de ce secret. Le type d'utilisation détermine le format de l'identifiant unique pour ce secret.
mon $id = $sec->get_usage_id()
Retourne l'identifiant de l'objet avec lequel le secret doit être utilisé. Pour les secrets dont le type d'utilisation est 'volume', l'identifiant est le chemin d'accès complet.
mon $xml = $sec->get_xml_description()
Retourne un document XML contenant une description complète de la configuration du secret.
$sec->undefine()
Supprime la configuration associée à un secret précédemment défini avec la méthode "define_secret" dans Sys::Virt.
$bytes = $sec->get_value()
Retourne les octets bruts de la valeur de ce secret, ou undef s'il n'y a pas de valeur stockée avec le secret.
$sec->set_value($bytes)
Définit la valeur du secret à $bytes.

CONSTANTES

Cette section documente les constantes utilisées avec diverses API décrites ci-dessus.

TYPE UTILISATION SECRET

Les constantes suivantes font référence aux différents types d'utilisation :

Sys::Virt::Secret::USAGE_TYPE_NONE
La constante pour les secrets qui ne sont pas affectés à l'utilisation avec un objet particulier.
Sys::Virt::Secret::USAGE_TYPE_VOLUME
La constante pour les secrets qui doivent être utilisés pour le chiffrement de volumes de stockage. L'ID d'utilisation pour les secrets fait référence au chemin d'accès complet du volume.
Sys::Virt::Secret::USAGE_TYPE_CEPH
La constante pour les secrets qui doivent être utilisés pour l'authentification aux volumes de stockage CEPH. L'ID d'utilisation pour les secrets fait référence au nom du serveur.
Sys::Virt::Secret::USAGE_TYPE_ISCSI
La constante pour les secrets qui doivent être utilisés pour l'authentification aux volumes de stockage iSCSI. L'ID d'utilisation pour les secrets fait référence au nom du serveur.
Sys::Virt::Secret::USAGE_TYPE_TLS
La constante pour les secrets qui doivent être utilisés pour l'authentification dans l'environnement TLS. L'ID d'utilisation pour le secret peut être n'importe quel nom. L'UUID du secret sera utilisé par l'hyperviseur pour récupérer la valeur du secret.
Sys::Virt::Secret::USAGE_TYPE_VTPM
La constante pour les secrets qui doivent être utilisés pour chiffrer l'état du TPM virtuel. L'ID d'utilisation pour le secret fait référence au chemin d'accès du TPM. L'UUID du secret sera utilisé par l'hyperviseur pour récupérer la valeur du secret.

FILTRAGE LISTE

Les constantes suivantes sont utilisées pour filtrer les listes d'objets.

Sys::Virt::Secret::LIST_EPHEMERAL
Inclure tous les secrets marqués comme éphémères.
Sys::Virt::Secret::LIST_NO_EPHEMERAL
Inclure tous les secrets non marqués comme éphémères.
Sys::Virt::Secret::LIST_PRIVATE
Inclure tous les secrets marqués comme privés.
Sys::Virt::Secret::LIST_NO_PRIVATE
Inclure tous les secrets non marqués comme privés.

DÉFINITION SECRET

Les constantes suivantes peuvent être utilisées pour contrôler le comportement des opérations de définition de secret.

Sys::Virt::Secret::DEFINE_VALIDATE
Valider le document XML par rapport au schéma XML.

CONSTANTES ID ÉVÉNEMENT

Sys::Virt::Secret::EVENT_ID_LIFECYCLE
Événements de cycle de vie des secrets.
Sys::Virt::Secret::EVENT_ID_VALUE_CHANGED
Événements de changement de valeur de secret.

ÉVÉNEMENTS CHANGEMENT CYCLE DE VIE

Les constantes suivantes permettent d'interpréter les événements de changement de cycle de vie des secrets. Les événements contiennent à la fois un changement d'état et une raison, bien que la raison ne soit actuellement pas utilisée.

Sys::Virt::Secret::EVENT_DEFINED
Indique qu'une configuration persistante a été définie pour le secret.
Sys::Virt::Secret::EVENT_UNDEFINED
La configuration persistante a disparu.
