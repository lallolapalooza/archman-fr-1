NOM

Sys::Virt::Error - Objet d'erreur pour les API libvirt

DESCRIPTION

La classe "Sys::Virt::Error" fournit un encodage des erreurs libvirt. Des instances de cet objet peuvent être émises par pratiquement toutes les API Sys::Virt.

MÉTHODES

$err->stringify
Convertit l'objet en format chaîne de caractères approprié pour l'affichage sur une console afin d'informer un utilisateur de l'erreur.
mon $niveau = $err->level
Retourne le niveau d'erreur brut représenté par cette erreur. Une des CONSTANTES DE NIVEAU D'ERREUR.
mon $code = $err->code
Retourne le code d'erreur brut représenté par cette erreur. Un des CONSTANTES DE CODE D'ERREUR.
mon $provenance = $err->domain
Retourne le domaine d'erreur qui génère cette erreur. Un des CONSTANTES DE DOMAINE D'ERREUR.
mon $msg = $err->message
Retourne un message informatif décrivant la condition d'erreur.
