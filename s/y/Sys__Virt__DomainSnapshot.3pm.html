Sys::Virt::DomainSnapshot(3pm) Documentation Perl fournie par l'utilisateur Sys::Virt::DomainSnapshot(3pm)

NOM

Sys::Virt::DomainSnapshot - Représente & gère un domaine invité libvirt

DESCRIPTION

Le module "Sys::Virt::DomainSnapshot" représente un domaine invité géré par le moniteur de machine virtuelle.

MÉTHODES

mon $str = $domss->get_name()
Retourne le nom du snapshot
mon $xml = $domss->get_xml_description($flags)
Retourne un document XML contenant une description complète de la configuration du snapshot du domaine. Le paramètre $flags accepte les constantes suivantes
Sys::Virt::DomainSnapshot::XML_SECURE
Inclut les informations sensibles à la sécurité dans la sortie XML, telles que les mots de passe.
$domss->delete($flags)
Supprime cet objet snapshot & ses données. Le paramètre optionnel $flags contrôle ce qui doit être supprimé via les constantes "Sys::Virt::DomainSnapshot::DELETE_*".
$domss->revert_to($flags)
Rétablit le domaine à l'état associé à ce snapshot. Le paramètre optionnel $flags contrôle l'état de la VM après le rétablissement via les constantes "Sys::Virt::DomainSnapshot::REVERT_*".
mon $parentss = $domss->get_parent();
Retourne le parent du snapshot, le cas échéant
mon $res = $domss->is_current()
Retourne une valeur vraie si c'est le snapshot actuel. Faux sinon.
mon $res = $domss->has_metadata()
Retourne une valeur vraie si ce snapshot a des métadonnées associées.
mon $count = $domss->num_of_child_snapshots()
Retourne le nombre de snapshots enregistrés qui sont enfants de ce snapshot
mon @names = $domss->list_child_snapshot_names()
Liste les noms de tous les snapshots enregistrés qui sont enfants de ce snapshot. Les noms peuvent être utilisés avec "lookup_snapshot_by_name".
mon @snapshots = $domss->list_child_snapshots()
Retourne une liste de tous les snapshots qui sont enfants de ce snapshot. Les éléments de la liste retournée sont des instances de la classe Sys::Virt::DomainSnapshot. Cette méthode nécessite des appels RPC en O(n), donc la méthode "list_all_children" est recommandée comme alternative plus efficace.
mon @snapshots = $domss->list_all_children($flags)
Retourne une liste de tous les snapshots de domaine qui sont enfants de ce snapshot. Les éléments de la liste retournée sont des instances de la classe Sys::Virt::DomainSnapshot. Le paramètre $flags peut être utilisé pour filtrer la liste des snapshots de domaine retournés.

CONSTANTES

CRÉATION DE SNAPSHOT

Les constantes suivantes sont utiles lors de la création de snapshots

Sys::Virt::DomainSnapshot::CREATE_CURRENT
Définit le snapshot défini comme étant le snapshot actuel
Sys::Virt::DomainSnapshot::CREATE_DISK_ONLY
Prend un snapshot uniquement du disque, pas de l'état mémoire
Sys::Virt::DomainSnapshot::CREATE_HALT
Arrête l'invité après la création du snapshot
Sys::Virt::DomainSnapshot::CREATE_NO_METADATA
N'enregistre aucune métadonnée pour le snapshot
Sys::Virt::DomainSnapshot::CREATE_REDEFINE
Remplace/définit les métadonnées avec le snapshot
Sys::Virt::DomainSnapshot::CREATE_QUIESCE
Rend les disques de l'invité calmes lors de la prise du snapshot
Sys::Virt::DomainSnapshot::CREATE_REUSE_EXT
Réutilise les fichiers de données de snapshot existants (le cas échéant)
Sys::Virt::DomainSnapshot::CREATE_ATOMIC
Crée plusieurs snapshots de disque de manière atomique
Sys::Virt::DomainSnapshot::CREATE_LIVE
Crée un snapshot pendant que l'invité est en cours d'exécution
Sys::Virt::DomainSnapshot::CREATE_VALIDATE
Valide le document XML par rapport au schéma

SUPPRESSION DE SNAPSHOT

Les constantes suivantes sont utiles lors de la suppression de snapshots

Sys::Virt::DomainSnapshot::DELETE_CHILDREN
Supprime récursivement tous les snapshots enfants
Sys::Virt::DomainSnapshot::DELETE_CHILDREN_ONLY
Supprime uniquement les snapshots enfants
Sys::Virt::DomainSnapshot::DELETE_METADATA_ONLY
Supprime uniquement les métadonnées du snapshot

LISTE DE SNAPSHOTS

Les constantes suivantes sont utiles lors de la liste des snapshots

Sys::Virt::DomainSnapshot::LIST_METADATA
Liste uniquement les snapshots qui ont des métadonnées
Sys::Virt::DomainSnapshot::LIST_ROOTS
Liste uniquement les snapshots qui sont des nœuds racines dans l'arbre
Sys::Virt::DomainSnapshot::LIST_DESCENDANTS
Liste uniquement les snapshots qui sont des descendants du snapshot actuel
Sys::Virt::DomainSnapshot::LIST_LEAVES
Liste uniquement les nœuds feuilles dans l'arbre des snapshots
Sys::Virt::DomainSnapshot::LIST_NO_LEAVES
Liste uniquement les nœuds non-feuilles dans l'arbre des snapshots
Sys::Virt::DomainSnapshot::LIST_NO_METADATA
Liste uniquement les snapshots sans métadonnées
Sys::Virt::DomainSnapshot::LIST_ACTIVE
Liste uniquement les snapshots pris pendant que l'invité était en cours d'exécution
Sys::Virt::DomainSnapshot::LIST_INACTIVE
Liste uniquement les snapshots pris pendant que l'invité était inactif
Sys::Virt::DomainSnapshot::LIST_EXTERNAL
Liste uniquement les snapshots stockés dans des images disque externes
Sys::Virt::DomainSnapshot::LIST_INTERNAL
Liste uniquement les snapshots stockés dans des images disque internes

Sys::Virt::DomainSnapshot(3pm)

NAME

Sys::Virt::DomainSnapshot - Interface for managing guest snapshots

DESCRIPTION

This module provides constants for controlling the behaviour of Sys::Virt snapshot operations, such as listing or reverting.

METHODS

There are no methods defined in this module. Constants are used directly.

CONSTANTS

LISTING SNAPSHOTS

The following constants are useful when listing snapshots

Sys::Virt::DomainSnapshot::LIST_DISK_ONLY
Liste uniquement les instantanés pris pendant que l'invité était en cours d'exécution, qui n'incluaient pas l'état de la mémoire.
Sys::Virt::DomainSnapshot::LIST_TOPOLOGICAL
Trie la liste dans l'ordre topologique par rapport aux relations parent/enfant.

SNAPSHOT REVERT

Les constantes suivantes sont utiles lors de la restauration d'instantanés

Sys::Virt::DomainSnapshot::REVERT_PAUSED
Laisse les processeurs de l'invité en pause après la restauration de l'état de l'instantané
Sys::Virt::DomainSnapshot::REVERT_RUNNING
Démarre les processeurs de l'invité après la restauration de l'état de l'instantané
Sys::Virt::DomainSnapshot::REVERT_FORCE
Force la restauration de l'instantané, même si cela est risqué
Sys::Virt::DomainSnapshot::REVERT_RESET_NVRAM
Réinitialise l'état de la mémoire NVRAM du firmware à partir de son modèle d'origine
