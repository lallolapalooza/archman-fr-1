NOM Documentation Perl fournie par l'utilisateur Sys::Virt::NodeDevice(3pm)

NOM

Sys::Virt::NodeDevice - Représenter & gérer un périphérique hôte avec libvirt

DESCRIPTION

Le module "Sys::Virt::NodeDevice" représente un périphérique hôte géré par libvirt. Il existe plusieurs implémentations de périphériques hôtes pour LVM, les répertoires locaux/les fenêtres de fichiers, les systèmes de fichiers réseau, les partitions de disque, iSCSI et SCSI.

MÉTHODES

mon $nom = $dev->get_name()
Retourne une chaîne avec un nom unique local du périphérique
mon $nom_parent = $dev->get_parent()
Retourne une chaîne avec un nom unique local du parent du périphérique, ou undef s'il n'a pas de parent
mon $xml = $dev->get_xml_description($flags=0)
Retourne un document XML contenant une description complète de la configuration du périphérique hôte. Le paramètre optionnel $flags contrôle la génération du document XML, avec une valeur par défaut de 0 s'il n'est pas spécifié. Il peut s'agir d'une ou plusieurs des constantes de type XML DUMP mentionnées plus loin dans ce document.
$dev->reattach()
Re-lie le périphérique hôte aux pilotes matériels du système d'exploitation hôte.
$dev->dettach()
Détache le périphérique hôte du pilote matériel du système d'exploitation hôte.
$dev->reset()
Réinitialise le périphérique hôte. Le périphérique doit être détaché des pilotes du système d'exploitation hôte pour que cela fonctionne.
$dev->create($flags=0)
Démarre un périphérique hôte dont la configuration a été précédemment définie à l'aide de la méthode "define_node_device" dans Sys::Virt. Le paramètre $flags est actuellement inutilisé et se comporte comme 0 par défaut.
$dev->undefine($flags=0)
Supprime un périphérique hôte dont la configuration a été précédemment définie à l'aide de la méthode "define_node_device" dans Sys::Virt. Le paramètre $flags est actuellement inutilisé et se comporte comme 0 par défaut.
$flag = $dev->get_autostart();
Retourne une valeur vraie si le périphérique hôte est configuré pour démarrer automatiquement au démarrage. Retourne faux sinon.
$dev->set_autostart($flag)
Définit l'état du drapeau de démarrage automatique, qui détermine si le périphérique hôte démarrera automatiquement au démarrage du système d'exploitation hôte.
$dev->is_active()
Retourne une valeur vraie si le périphérique hôte est actuellement en cours d'exécution.
$dev->is_persistent()
Retourne une valeur vraie si le périphérique hôte a un fichier de configuration persistant défini.
$dev->destroy()
Détruit le périphérique virtuel, libérant toutes les ressources du système d'exploitation associées.
mon @caps = $dev->list_capabilities()
Retourne une liste de toutes les capacités du périphérique.
$dev->update($xml, $flags=0)
Met à jour la définition d'un périphérique hôte existant avec $xml. Le paramètre $flags peut être utilisé pour contrôler quelle configuration est affectée (voir les drapeaux de mise à jour XML) et se comporte comme 0 par défaut (l'état actuel du périphérique hôte est affecté).

NAME

Sys::Virt::NodeDevice - Interface to libvirt node devices

DESCRIPTION

This class provides a Perl interface to the node device management features of libvirt. It is not intended to be instantiated directly, but rather obtained via the `Sys::Virt::get_node_devices` method.

METHODS

Sys::Virt::NodeDevice->new( $connection, $xml )
Internal constructor for creating a node device object.
node_device->is_active()
Returns true if the node device is currently active on the host.
node_device->set_active( $active )
Activate or deactivate the node device. The behaviour of this depends on the device type and driver capabilities.
node_device->capability()
Returns the capabilities of the node device as a XML document.
node_device->driver()
Returns the name of the driver managing this node device.
node_device->parent()
Returns the parent node device, if any.
node_device->children()
Returns a list of child node devices, if any.
node_device->uri()
Returns the USB or CCW device URI, if applicable.
node_device->managed()
Returns true if the node device is managed by libvirt.
node_device->numa_nodes()
Returns a list of NUMA nodes the device is associated with.
node_device->is_available()
Returns true if the device is available for allocation to guests.
node_device->allocatable()
Returns true if the device is allocatable (can be assigned to guests).
node_device->update_device( $xml, $flags )
Update the configuration of the node device. The value of $flags can be a combination of NODE DEVICE UPDATE flags.
node_device->destroy()
Destroy a node device. This is typically used for transient devices.
node_device->undefine()
Undefine a node device configuration. This is typically used for persistent devices.
node_device->to_xml( $flags )
Dump the configuration of the node device as an XML document. The value of $flags can be a combination of XML DUMP OPTIONS flags.

CONSTANTS

LIST OPTIONS

These constants can be OR-ed together to filter the list of node devices returned by Sys::Virt::get_node_devices.

Sys::Virt::NodeDevice::LIST_ALL
Include all node devices
Sys::Virt::NodeDevice::LIST_PERSISTENT
Include persistent devices
Sys::Virt::NodeDevice::LIST_TRANSIENT
Include transient devices

EVENT ID CONSTANTS

Sys::Virt::NodeDevice::EVENT_ID_LIFECYCLE
Node device lifecycle events
Sys::Virt::NodeDevice::EVENT_ID_UPDATE
Node device config update events

LIFECYCLE CHANGE EVENTS

The following constants allow node device lifecycle change events to be interpreted. The events contain both a state change, and a reason though the reason is currently unused.

Sys::Virt::NodeDevice::EVENT_CREATED
Indicates that a device was created
Sys::Virt::NodeDevice::EVENT_DELETED
Indicates that a device has been deleted
Sys::Virt::NodeDevice::EVENT_DEFINED
Indicates that a device configuration has been created
Sys::Virt::NodeDevice::EVENT_UNDEFINED
Indicates that a device configuration has been deleted

NODE DEVICE CREATION

Sys::Virt::NodeDevice::CREATE_XML_VALIDATE
Validate the XML document against schema

NODE DEVICE DEFINE

Sys::Virt::NodeDevice::DEFINE_XML_VALIDATE
Validate the XML document against schema

NODE DEVICE UPDATE

Sys::Virt::NodeDevice::UPDATE_AFFECT_CURRENT
Affect live if node device is active, config if it's not active
Sys::Virt::NodeDevice::UPDATE_AFFECT_LIVE
Affect live state of node device only
Sys::Virt::NodeDevice::UPDATE_AFFECT_CONFIG
Affect persistent config only

XML DUMP OPTIONS

The following constants are used to control the information included in the XML configuration dump

Sys::Virt::NodeDevice::XML_INACTIVE
Report the persistent inactive configuration for the node device.
