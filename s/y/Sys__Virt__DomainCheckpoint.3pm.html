NOM

Sys::Virt::DomainCheckpoint - Représenter et gérer un point de contrôle de domaine invité libvirt

DESCRIPTION

Le module "Sys::Virt::DomainCheckpoint" représente un point de contrôle de domaine invité géré par le moniteur de machine virtuelle.

MÉTHODES

mon $str = $domchkp->get_name()
Retourne le nom du point de contrôle.
mon $xml = $domchkp->get_xml_description($flags)
Retourne un document XML contenant une description complète de la configuration des points de contrôle du domaine. Le paramètre $flags accepte les constantes suivantes.
Sys::Virt::DomainCheckpoint::XML_SECURE
Inclure les informations sensibles à la sécurité dans le dump XML, telles que les mots de passe.
Sys::Virt::DomainCheckpoint::XML_SIZE
Inclure les informations dynamiques par <disk> taille.
Sys::Virt::DomainCheckpoint::XML_NO_DOMAIN
Supprimer l'élément enfant <domain>.
$domchkp->delete($flags)
Supprime cet objet point de contrôle et ses données. Le paramètre optionnel $flags contrôle ce qui doit être supprimé via les constantes "Sys::Virt::DomainCheckpoint::DELETE_*".
$parentchkp = $domchkp->get_parent();
Retourne le parent du point de contrôle, s'il existe.
mon @checkpoints = $domchkp->list_all_children($flags)
Retourne une liste de tous les points de contrôle de domaine qui sont des enfants de ce point de contrôle. Les éléments de la liste retournée sont des instances de la classe Sys::Virt::DomainCheckpoint. Le paramètre $flags peut être utilisé pour filtrer la liste des points de contrôle de domaine retournés.

CONSTANTES

CRÉATION POINT DE CONTRÔLE

Les constantes suivantes sont utiles lors de la création de points de contrôle.

Sys::Virt::DomainCheckpoint::CREATE_REDEFINE
Remplace/définit les métadonnées avec le point de contrôle.
Sys::Virt::DomainCheckpoint::CREATE_QUIESCE
Met en silence les disques invités lors de la prise du point de contrôle.
Sys::Virt::DomainCheckpoint::CREATE_REDEFINE_VALIDATE
Valide l'état des données du disque.

SUPPRESSION POINT DE CONTRÔLE

Les constantes suivantes sont utiles lors de la suppression de points de contrôle.

Sys::Virt::DomainCheckpoint::DELETE_CHILDREN
Supprime récursivement tous les points de contrôle enfants.
Sys::Virt::DomainCheckpoint::DELETE_CHILDREN_ONLY
Ne supprime que les points de contrôle enfants.
Sys::Virt::DomainCheckpoint::DELETE_METADATA_ONLY
Ne supprime que les métadonnées du point de contrôle.

LISTE POINT DE CONTRÔLE

Les constantes suivantes sont utiles lors de la liste des points de contrôle.

Sys::Virt::DomainCheckpoint::LIST_ROOTS
Ne liste que les points de contrôle qui sont des nœuds racine dans l'arbre.
Sys::Virt::DomainCheckpoint::LIST_DESCENDANTS
Ne liste que les points de contrôle qui sont des descendants du point de contrôle actuel.
Sys::Virt::DomainCheckpoint::LIST_LEAVES
Ne liste que les nœuds feuilles dans l'arbre des points de contrôle.
Sys::Virt::DomainCheckpoint::LIST_NO_LEAVES
Ne liste que les nœuds non-feuilles dans l'arbre des points de contrôle.
Sys::Virt::DomainCheckpoint::LIST_TOPOLOGICAL
Trie la liste par ordre topologique par rapport aux relations parent/enfant.
