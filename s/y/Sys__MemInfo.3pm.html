NOM

Sys::MemInfo - interroger la mémoire physique totale libre et utilisée

SYNTAXE

use Sys::MemInfo qw(totalmem freemem totalswap);
print "mémoire totale : ".(&totalmem / 1024)."\n";
print "mémoire libre :  ".(&freemem / 1024)."\n";
print "swap totale : ".(&totalswap / 1024)."\n";
print "swap libre :  ".(Sys::MemInfo::get("freeswap") / 1024)."\n";

DESCRIPTION

Sys::MemInfo retourne la quantité totale de mémoire physique libre et utilisée en octets dans les variables totalmem et freemem.

La quantité totale de mémoire swap libre et utilisée est également retournée dans les variables totalswap et freeswap.

Ce module a été testé sur Linux 3.13.0, UnixWare 7.1.2, AIX5, OpenBSD 3.8, NetBSD 2.0.2, FreBSD 5.4, HPUX11, Solaris 9, Tru64 5.1, Irix 6.5, Mac OS X 10.2 darwin et Windows XP.

Il devrait fonctionner sur FreeBSD 4 et Windows 9X/ME/NT/200X/Vista.

MÉTHODES

availkeys
Retourne une liste de toutes les clés d'accès (freemem, totalmem, etc.). Ceci est utile pour afficher toutes les informations connues de l'objet en appelant get() sur toutes les clés retournées.
freemem
Retourne la mémoire physique libre en octets.
freeswap
Retourne l'espace swap libre en octets.
get
Retourne la valeur de la clé passée.
totalmem
Retourne la taille totale de la mémoire physique en octets.
totalswap
Retourne la taille totale de l'espace swap en octets.
