NOM

Sys::Virt::EventImpl - Classe parente d'implémentation de boucle d'événements

DESCRIPTION

Le module "Sys::Virt::EventImpl" représente le contrat pour l'intégration de libvirt avec une boucle d'événements. Ce paquet est abstrait et destiné à être sous-classé pour fournir une implémentation réelle.

Ce module est nouveau dans la version 9.5.0. Pour utiliser ce module tout en prenant en charge les versions antérieures à la 9.5.0, vous pouvez envisager le code ci-dessous pour configurer l'héritage.

package YourImpl;
use strict;
use warnings;
BEGIN {
  if (require Sys::Virt::EventImpl) {
     eval "use parent 'Sys::Virt::EventImpl';";
  }
  else {
     eval "use parent 'Sys::Virt::Event';";
  }
}

IMPLÉMENTATION DE BOUCLE D'ÉVÉNEMENTS

Lors de l'implémentation d'une boucle d'événements, l'implémentation doit être une sous-classe de la classe "Sys::Virt::EventImpl". Elle doit remplacer ces fonctions :

ma $watch_id = $self->add_handle( $fd, $events, $callback, $opaque, $ff )
Enregistre $callback pour être invoqué pour $events sur $fd. Utilisez "_run_handle_callback" pour effectuer l'invocation réelle à partir de la boucle d'événements (voir "Aides aux rappels" ci-dessous).

En plus des événements explicitement indiqués par $events, "Sys::Virt::Event::HANDLE_ERROR" et "Sys::Virt::Event::HANDLE_HANGUP" devraient toujours déclencher le rappel.

Retourne un entier positif $watch_id ou -1 en cas d'erreur.

$self->update_handle($watch_id, $events)
Remplace les événements déclenchant actuellement $watch_id par $events.
ma $ret = $self->remove_handle($watch_id)
Supprime $callback du $fd.

Retourne 0 en cas de succès ou -1 en cas d'échec.

IMPORTANT Cela doit également s'assurer que "_free_callback_opaque" est appelé après l'exécution de cette fonction : ne pas le faire empêchera la connexion d'être collectée par le garbage collector.

ma $timer_id = $self->add_timeout($frequency, $callback, $opaque, $ff)
$self->update_timeout($timer_id, $frequency)
Remplace l'intervalle de la minuterie par $frequency.
ma $ret = $self->remove_timeout($timer_id)
Écarte la minuterie.

Retourne 0 en cas de succès ou -1 en cas d'échec.

IMPORTANT Cela doit également s'assurer que "_free_callback_opaque" est appelé après l'exécution de cette fonction : ne pas le faire empêchera la connexion d'être collectée par le garbage collector.

Aide aux rappels

$self->_run_handle_callback($watch_id, $fd, $events, $cb, $opaque)
Une méthode d'aide pour exécuter un rappel en réponse à un ou plusieurs $events sur le descripteur de fichier $fd. Le numéro $watch est l'identifiant unique associé au descripteur de fichier. Les paramètres $cb et $opaque sont le rappel et les données enregistrés pour le descripteur.
$self->_run_timeout_callback($timer_id, $cb, $opaque)
Une méthode d'aide pour exécuter un rappel en réponse à l'expiration d'une minuterie identifiée par $timer. Les paramètres $cb et $opaque sont le rappel et les données enregistrés pour la minuterie.
$self->_free_callback_opaque($ff, $opaque)
Une méthode d'aide pour libérer les données associées à un rappel. Les paramètres $ff et $opaque sont le rappel et les données enregistrés pour le descripteur/la minuterie.

IMPORTANT Cette aide doit être appelée en dehors de tout rappel ; c'est-à-dire après la fin des rappels "remove_handle" ou "remove_timeout".
