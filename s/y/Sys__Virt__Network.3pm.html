NOM

Sys::Virt::Network - Représenter et gérer un réseau virtuel géré par le moniteur virtuel.

DESCRIPTION

Le module "Sys::Virt::Network" représente un réseau virtuel géré par le moniteur virtuel.

MÉTHODES

mon $uuid = $net->get_uuid()
Retourne une chaîne de 16 octets contenant l'identifiant universel unique (UUID) du réseau.
mon $uuid = $net->get_uuid_string()
Retourne une représentation textuelle de l'UUID brut, au format 'XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX'.
mon $name = $net->get_name()
Retourne une chaîne de caractères avec un nom unique localement pour le réseau.
$net->is_active()
Retourne une valeur vraie si le réseau est actif.
$net->is_persistent()
Retourne une valeur vraie si la configuration du réseau possède un fichier persistant défini.
mon $xml = $net->get_xml_description()
Retourne un document XML contenant une description complète de la configuration du réseau.
$net->create()
Démarre un réseau dont la configuration a été préalablement définie à l'aide de la méthode "define_network" dans Sys::Virt.
$net->undefine()
Supprime la configuration associée à un réseau préalablement défini avec la méthode "define_network" dans Sys::Virt. Si le réseau est actif, vous voudrez probablement utiliser les méthodes "shutdown" ou "destroy" à la place.
$net->destroy()
Termine immédiatement la machine et la supprime de la machine virtuelle. Le handle $net est invalide après cet appel et ne doit plus être utilisé.
$net->update($command, $section, $parentIndex, $xml, $flags=0)
Met à jour la configuration du réseau avec $xml. Le paramètre $section, qui doit être l'une des constantes de SECTION XML mentionnées ci-après, indique quel schéma est utilisé dans $xml. Le paramètre $command détermine l'action entreprise. Enfin, le paramètre $flags peut être utilisé pour contrôler quelle configuration est affectée.
$net->get_bridge_name()
Retourne le nom de l'interface bridge associée au réseau virtuel.
$flag = $net->get_autostart();
Retourne une valeur vraie si le réseau virtuel est configuré pour démarrer automatiquement au démarrage du système d'exploitation hôte. Retourne faux sinon.
$net->set_autostart($flag)
Définit l'état du flag de démarrage automatique, qui détermine si le réseau virtuel démarrera automatiquement au démarrage du système d'exploitation hôte.
@leases = $net->get_dhcp_leases($mac=undef, $flags=0)
Obtient une liste de toutes les baux actifs. Si $mac est indéfini, retourne les baux pour tous les VMs, sinon uniquement pour l'adresse MAC correspondante. Le paramètre $flags n'est actuellement pas utilisé et se comporte comme 0.

Les éléments de la liste retournée sont des références de hachages avec les champs suivants :

"iface"
Nom de l'interface réseau
"expirytime"
Secondes depuis l'époque jusqu'au moment où le bail expire
"type"
L'une des constantes de type IP de la classe Sys::Virt
"mac"
Adresse MAC du bail
"iaid"
IAID du client
"ipaddr"
Adresse IP du bail
"prefix"
Préfixe de l'IP du bail
"hostname"
Nom optionnel associé au bail
"clientid"
ID client ou DUID
@port = $net->list_all_ports($flags=0)
Liste toutes les portes réseau associées au réseau. Les éléments de la liste retournée sont des instances de la classe "Sys::Virt::NetworkPort".
$port = $net->create_port($xml, $flags=0)
Crée une nouvelle porte réseau à partir de la description donnée par $xml. Le paramètre $flags peut éventuellement prendre une ou plusieurs des constantes de création de porte réseau. L'instance retournée $port est un objet de classe "Sys::Virt::NetworkPort".
$port = $net->get_port_by_uuid($uuid);
Recherche une porte réseau par UUID ou représentation. L'instance retournée $port est un objet de classe "Sys::Virt::NetworkPort".
mon $str = $net->get_metadata($type, $uri, $flags =0)
Retourne l'élément de métadonnées de type $type associé au réseau. Si $type est "Sys::Virt::Network::METADATA_ELEMENT", le paramètre $uri spécifie l'espace de noms XML à récupérer, sinon $uri doit être "undef". Le paramètre optionnel $flags prend une valeur de FLAG UPDATE XML et se comporte comme 0 par défaut.
$net->set_metadata($type, $val, $key, $uri, $flags=0)
Définit l'élément de métadonnées de type $type pour stocker la valeur $val. Si $type est "Sys::Virt::Network::METADATA_ELEMENT", les paramètres $key et $uri spécifient un espace de noms XML à utiliser, sinon les deux doivent être "undef". Le paramètre optionnel $flags prend une valeur de FLAG UPDATE XML et se comporte comme 0 par défaut.

FILTRAGE DE LISTES

Les constantes suivantes sont utilisées pour filtrer les listes d'objets.

Inclut les réseaux actifs.

Inclut les réseaux inactifs.
Sys::Virt::Network::LIST_AUTOSTART
Inclut les réseaux configurés pour démarrer automatiquement.
Sys::Virt::Network::LIST_NO_AUTOSTART
Inclut les réseaux non configurés pour démarrer automatiquement.
Sys::Virt::Network::LIST_PERSISTENT
Inclut les réseaux persistants.
Sys::Virt::Network::LIST_TRANSIENT
Inclut les réseaux transitoires.

ÉVÉNEMENTS DE CHANGEMENT DE CYCLE DE VIE

Les constantes suivantes permettent d'interpréter les événements de changement de cycle de vie du réseau. Les événements contiennent à la fois un changement d'état et une raison, bien que la raison ne soit actuellement pas utilisée.

Sys::Virt::Network::EVENT_DEFINED
Indique qu'une configuration persistante a été définie pour le réseau.
Sys::Virt::Network::EVENT_STARTED
Le réseau a commencé à fonctionner
Sys::Virt::Network::EVENT_STOPPED
Le réseau a cessé de fonctionner
Sys::Virt::Network::EVENT_UNDEFINED
La configuration persistante a disparu
