NOM

Sys::Virt::NWFilterBinding - Représenter et gérer une liaison de filtre réseau

DESCRIPTION

Le module "Sys::Virt::NWFilterBinding" représente une liaison entre un filtre réseau et un périphérique de port réseau.

MÉTHODES

mon $nom = $liaison->get_port_dev()
Retourne une chaîne avec le nom du périphérique de port réseau auquel la liaison est attachée.
mon $nom = $liaison->get_filter_name()
Retourne une chaîne avec le nom du filtre réseau auquel la liaison est attachée.
mon $xml = $liaison->get_xml_description()
Retourne un document XML contenant une description complète de la configuration du réseau.
$liaison->delete()
Détache le périphérique de port réseau du filtre.

CONSTANTES DE CRÉATION DE LIAISON DE FILTRE RÉSEAU

Lors de la création de liaisons de filtre réseau, zéro ou plusieurs des constantes suivantes peuvent être utilisées :

Sys::Virt::NWFilterBinding::CREATE_VALIDATE
Valide le document XML par rapport au schéma XML.
