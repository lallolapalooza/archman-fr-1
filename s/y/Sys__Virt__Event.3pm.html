NOM

Sys::Virt::Event - Accès à la boucle d'événements

DESCRIPTION

Le module "Sys::Virt::Event" représente le contrat pour l'intégration de libvirt avec une boucle d'événements. Ce paquet est abstrait et destiné à être sous-classé pour fournir une implémentation réelle.

FONCTIONNALITÉ DÉPRÉCIÉE

Les implémentations de boucles d'événements devaient auparavant être des instances de sous-classes de "Sys::Virt::Event". Au lieu de cela, elles doivent maintenant hériter de "Sys::Virt::EventImpl". Pour la compatibilité ascendante avec les versions 9.4 et antérieures, l'héritage de "Sys::Virt::Event" est toujours pris en charge, mais sera supprimé mi-2025.

MÉTHODES

register_default()
Enregistre l'implémentation par défaut de la boucle d'événements libvirt.
run_default()
Exécute une seule itération de l'implémentation par défaut de la boucle d'événements.
register($impl)
Enregistre une implémentation de boucle d'événements. L'implémentation doit être une instance d'une sous-classe du paquet "Sys::Virt::EventImpl". Voir la section "IMPLÉMENTATION DE BOUCLE D'ÉVÉNEMENTS" ci-dessous pour plus d'informations.
my $watch = Sys::Virt::Event::add_handle($fd, $events, $coderef)
Ajoute une surveillance sur le descripteur de fichier $fd pour les événements $events qui est un masque des constantes d'ÉVÉNEMENTS DE FICHIER répertoriées plus loin. Le paramètre $coderef est une sous-routine à invoquer lorsqu'un événement est déclenché. La sous-routine recevra trois paramètres : l'identifiant de la surveillance, le descripteur de fichier et le masque d'événements. Cette méthode renvoie l'identifiant de la surveillance qui peut être utilisé pour mettre à jour ou supprimer la surveillance.
Sys::Virt::Event::update_handle($watch, $events)
Met à jour le masque d'événements pour la surveillance du descripteur de fichier $watch afin d'utiliser les événements $events.
Sys::Virt::Event::remove_handle($watch)
Supprime le masque d'événements pour la surveillance du descripteur de fichier $watch.
my $timer = Sys::Virt::Event::add_timeout($frequency, $coderef, $opaque)
Ajoute un délai pour le déclenchement avec un intervalle de $frequency millisecondes. Le paramètre $coderef est une sous-routine à invoquer lorsqu'un événement est déclenché. La sous-routine recevra un paramètre : l'identifiant du minuteur. Cette méthode renvoie l'identifiant du minuteur qui peut être utilisé pour mettre à jour ou supprimer le minuteur.
Sys::Virt::Event::update_timeout($timer, $frequency)
Met à jour le minuteur $timer pour avoir la fréquence de $frequency millisecondes. Les valeurs 0 et -1 ont une signification spéciale. La valeur 0 demande que le rappel soit invoqué à chaque itération de la boucle d'événements, où -1 arrête l'invocation du rappel.
Sys::Virt::Event::remove_timeout($timer)
Supprime le minuteur $timer.

CONSTANTES

ÉVÉNEMENTS DE FICHIER

Lors de l'intégration avec une boucle d'événements, les constantes suivantes définissent les événements des descripteurs de fichiers.

Sys::Virt::Event::HANDLE_READABLE
Des données sont disponibles pour la lecture sans blocage sur le descripteur de fichier.
Sys::Virt::Event::HANDLE_WRITABLE
Il est possible d'écrire des données sans blocage sur le descripteur de fichier.
Sys::Virt::Event::HANDLE_ERROR
Une erreur s'est produite sur le descripteur de fichier.
Sys::Virt::Event::HANDLE_HANGUP
L'extrémité distante du descripteur de fichier a été fermée.
