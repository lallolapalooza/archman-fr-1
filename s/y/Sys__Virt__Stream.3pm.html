NOM

Sys::Virt::Stream - Représenter et gérer un flux libvirt

DESCRIPTION

Le module "Sys::Virt::Stream" représente un flux géré par le moniteur virtuel.

MÉTHODES

my $st Sys::Virt::Stream->new($conn, $flags);
Créer un nouveau flux, prêt à être utilisé avec une API de flux. Le paramètre optionnel $flags peut être utilisé pour configurer le flux comme non bloquant.
$st->abort()
Arrêter l'I/O sur le flux. Soit cette fonction, soit "finish" doit être appelée sur tout flux qui a été activé.
$st->finish()
Terminer l'I/O sur le flux. Soit cette fonction, soit "abort" doit être appelée sur tout flux qui a été activé.
$rv = $st->recv($data, $nbytes, $flags=0)
Recevoir jusqu'à $nbytes d'octets, en copiant dans $data. Retourne le nombre d'octets lus, ou -3 si un trou est atteint et que $flags contient RECV_STOP_AT_HOLE, ou -2 si l'I/O bloque, ou -1 en cas d'erreur. Le paramètre $flags accepte les drapeaux suivants :
Sys::Virt::Stream::RECV_STOP_AT_HOLE
Si ce drapeau est positionné, la fonction "recv" arrêtera la lecture du flux si elle a atteint un trou. Dans ce cas, -3 sera retourné et "recv_hole" devra être appelé pour obtenir la taille du trou.
$rv = $st->send($data, $nbytes)
Envoyer jusqu'à $nbytes d'octets, en copiant à partir de $data. Retourne le nombre d'octets envoyés, ou -2 si l'I/O bloque, ou -1 en cas d'erreur.
$rv = $st->recv_hole($flags=0)
Déterminer la quantité d'espace vide (en octets) à créer dans le fichier de destination du flux lors du téléchargement ou du transfert de fichiers épars. C'est l'équivalent de "send_hole". Le paramètre optionnel $flags n'est pas utilisé et se comporte comme 0 s'il n'est pas spécifié.
$st->send_hole($length, $flags=0)
Au lieu d'envoyer de l'espace vide du fichier, cette méthodologie indique à la destination du flux de créer $length d'espace vide. Cette méthodologie sera utilisée lors du téléchargement ou du transfert de fichiers épars pour éviter la copie inutile d'espace vide. Le paramètre optionnel $flags n'est pas utilisé et se comporte comme 0 s'il n'est pas spécifié.
$st->recv_all($handler)
Recevoir toutes les données disponibles du flux, en appelant $handler pour traiter les données. Le paramètre $handler doit être une fonction qui attend trois arguments : l'objet flux $st, un scalaire contenant les données reçues, et un compteur d'octets. La fonction doit retourner le nombre d'octets traités, ou -1 en cas d'erreur.
$st->send_all($handler)
Envoyer toutes les données générées par $handler vers le flux. Le paramètre $handler doit être une fonction qui attend trois arguments : l'objet flux $st, un scalaire qui doit être rempli avec des données, et une taille maximale de données souhaitée. La fonction doit retourner le nombre d'octets remplis, 0 en cas de fin de fichier, ou -1 en cas d'erreur.
$st->sparse_recv_all($handler, $hole_handler)
Recevoir toutes les données disponibles du flux épars, en appelant $handler pour traiter les données. Le paramètre $handler doit être une fonction qui attend trois arguments : l'objet flux $st, un scalaire contenant les données reçues, et un compteur d'octets. La fonction doit retourner le nombre d'octets traités, ou -1 en cas d'erreur. Le deuxième argument $hole_handler est une fonction qui attend deux arguments : l'objet flux $st et un scalaire, un nombre décrivant la taille du trou dans le fichier de destination du flux. Le $hole_handler doit retourner un nombre non négatif en cas de succès (généralement 0) et un nombre négatif (généralement -1) en cas d'erreur.
$st->sparse_send_all($handler, $hole_handler, $skip_handler)
Envoyer toutes les données générées par $handler vers le flux. Le paramètre $handler doit être une fonction qui attend trois arguments : l'objet flux $st, un scalaire qui doit être rempli avec des données, et une taille maximale de données souhaitée. La fonction doit retourner le nombre d'octets remplis, 0 en cas de fin de fichier, ou -1 en cas d'erreur. Le deuxième argument $hole_handler est une fonction qui attend un seul argument $st et retourne un tableau de deux éléments ($in_data, $section_len), où $in_data a une valeur zéro ou non nulle si le fichier sous-jacent est dans un trou ou dans un segment de données respectivement. Le $section_len est le nombre d'octets restants dans le segment actuel du fichier sous-jacent. Enfin, le troisième argument $skip_handler est une fonction qui attend deux arguments $st et $length qui déplace le curseur dans le fichier sous-jacent de $length octets. Le $skip_handler doit retourner un nombre non négatif en cas de succès (généralement 0) et un nombre négatif (généralement -1) en cas d'erreur.
$st->add_callback($events, $coderef)
Enregistrer une fonction de rappel à appeler lorsque le flux a un ou plusieurs événements de $events marqués. Le $coderef doit être une sous-routine qui attend deux paramètres, l'objet original $st et le nouveau masque $events.
$st->update_callback($events)
Mettre à jour le masque d'événements pour une fonction de rappel précédemment enregistrée à $events.
$st->remove_callback();
Supprimer une fonction de rappel précédemment enregistrée.

CONSTANTES

Sys::Virt::Stream::NONBLOCK
Créer un flux qui ne bloque pas lors de l'I/O.
Sys::Virt::Stream::EVENT_READABLE
Le flux a des données disponibles pour la lecture sans blocage.
Sys::Virt::Stream::EVENT_WRITABLE
Le flux peut écrire des données sans blocage.
Sys::Virt::Stream::EVENT_ERROR
Une erreur s'est produite sur le flux.
Sys::Virt::Stream::EVENT_HANGUP
Le côté distant du flux s'est fermé.
