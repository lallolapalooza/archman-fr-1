NOM

Sys::Virt::StoragePool - Représenter et gérer un stockage libvirt

DESCRIPTION

Le module « Sys::Virt::StoragePool » représente un stockage libvirt. Il existe plusieurs implémentations de stockages de type LVM, répertoires locaux, systèmes de fichiers réseau, partitions, iSCSI et SCSI.

MÉTHODES

my $uuid = $pool->get_uuid()
Retourne une chaîne de 16 octets contenant l'identifiant unique global (UUID) du stockage.
my $uuid = $pool->get_uuid_string()
Retourne une représentation imprimable de l'UUID au format « XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX ».
my $name = $pool->get_name()
Retourne un nom localement unique du stockage.
$pool->is_active()
Retourne une valeur vraie si le stockage est en cours d'exécution.
$pool->is_persistent()
Retourne une valeur vraie si le stockage a une configuration persistante définie.
my $xml = $pool->get_xml_description()
Retourne un document XML contenant une description complète de la configuration du stockage.
$pool->create()
Crée un stockage dont la configuration a été préalablement définie à l'aide de la méthode "define_storage_pool" dans Sys::Virt.
$pool->undefine()
Supprime la configuration associée à un stockage préalablement défini avec la méthode "define_storage pool" dans Sys::Virt. Si le stockage est en cours d'exécution, vous voudrez probablement utiliser la méthode "destroy" à la place.
$pool->destroy()
Arrête immédiatement le stockage.
$flag = $pool->get_autostart();
Retourne une valeur vraie si le stockage est configuré pour démarrer automatiquement au démarrage. Retourne faux sinon.
$pool->set_autostart($flag)
Définit l'état du drapeau d'autodémarrage, qui détermine si le stockage démarrera automatiquement au démarrage du système d'exploitation hôte.
$pool->refresh([$flags]);
Met à jour l'état du stockage. Souvent, il re-scanne la liste des volumes de stockage. Le paramètre $flags n'est actuellement pas utilisé et est considéré comme 0 par défaut.
$pool->build([$flags]);
Construit le stockage s'il n'existe pas. À titre d'exemple, cela garantira qu'une table de partition existe pour un stockage basé sur disque. Le paramètre $flags permet de contrôler le processus de construction et s'il n'est pas spécifié, il est considéré comme 0.
$pool->delete([$flags]);
Supprime le stockage. Le paramètre $flags permet de supprimer les données de manière optionnelle lors de la suppression et s'il n'est pas spécifié, il est considéré comme 0.
$info = $pool->get_info()
Obtient des informations sur l'état actuel du stockage. L'objet retourné a les clés suivantes.
state
L'état actuel du stockage. Voir les constantes ci-dessous.
capacity
La taille logique totale du stockage.
allocation
La taille physique actuelle du stockage.
available
Espace disponible pour la création de nouveaux volumes. Cela peut être inférieur à la différence entre la capacité et l'allocation s'il existe des contraintes de taille ou des métadonnées pour les volumes.
my $nnames = $pool->num_of_storage_volumes()
Retourne le nombre de volumes en cours d'exécution dans ce stockage. La valeur peut être utilisée comme paramètre "maxnames" de "list_storage_vol_names".
my @volNames = $pool->list_storage_vol_names($maxnames)
Retourne une liste de tous les noms de volumes dans ce stockage. Les noms peuvent être utilisés avec la méthode "get_volume_by_name".
my @vols = $pool->list_volumes()
Retourne une liste de tous les volumes dans le stockage. Les éléments de la liste retournée sont des instances de la classe Sys::Virt::StorageVol. Cette méthode nécessite O(n) appels RPC, il est donc recommandé d'utiliser la méthode "list_all_volumes" comme alternative plus efficace.
my @volumes = $pool->list_all_volumes($flags)
Retourne une liste de tous les volumes associés à ce stockage. Les éléments de la liste retournée sont des instances de la classe Sys::Virt::StorageVol. Le paramètre $flags peut être utilisé pour filtrer la liste des volumes retournés.
my $vol = $pool->get_volume_by_name($name)
Retourne le volume portant le nom $name. L'objet retourné est une instance de la classe Sys::Virt::StorageVol.
my $vol = $pool->create_volume($xml)
Crée un nouveau volume basé sur la description XML fournie dans le paramètre $xml. L'objet retourné est une instance de la classe Sys::Virt::StorageVol. Si le paramètre optionnel "clonevol" est fourni, les données seront copiées à partir du volume source.
my $vol = $pool->clone_volume($xml, $clonevol);
Crée un nouveau volume basé sur la description XML fournie dans le paramètre $xml. L'objet retourné est une instance de la classe Sys::Virt::StorageVol. Le nouveau volume sera rempli avec les données du volume spécifié comme source de clonage.

ÉTATS DE STOCKAGE

Les constantes suivantes sont utiles pour interpréter la valeur de la clé "state" dans l'objet retourné par "get_info"

Sys::Virt::StoragePool::STATE_INACTIVE
Le stockage n'est pas actuellement actif
Sys::Virt::StoragePool::STATE_BUILDING
Le stockage est encore en cours de construction et n'est pas encore prêt à être utilisé.
Sys::Virt::StoragePool::STATE_RUNNING
Le stockage est en cours d'exécution et peut être consulté pour les volumes
Sys::Virt::StoragePool::STATE_DEGRADED
Le stockage est en cours d'exécution, mais son fonctionnement est dégradé en raison d'une défaillance.
Sys::Virt::StoragePool::STATE_INACCESSIBLE
Le stockage n'est actuellement pas accessible

MODES DE SUPPRESSION

Remplir le stockage alloué avec des zéros lors de la suppression

MODES DE CONSTRUCTION

Sys::Virt::StoragePool::BUILD_NEW
Construire un nouveau pool de stockage à partir de ses composants
Sys::Virt::StoragePool::BUILD_RESIZE
Redimensionner un pool de stockage existant en préservant les données si approprié
Sys::Virt::StoragePool::BUILD_REPAIR
Réparer un pool de stockage existant fonctionnant en mode dégradé
Sys::Virt::StoragePool::BUILD_NO_OVERWRITE
Ne pas écraser les données existantes du pool de stockage
Sys::Virt::StoragePool::BUILD_OVERWRITE
Écraser les données existantes du pool de stockage

MODES DE CRÉATION

Lors de la création d'un pool de stockage, celui-ci peut être construit en même temps. Les valeurs suivantes sont donc proches de leurs homologues BUILD.

Sys::Virt::StoragePool::CREATE_NORMAL
Créer simplement le pool de stockage sans le construire.
Sys::Virt::StoragePool::CREATE_WITH_BUILD
Lors de la création d'un nouveau pool de stockage, effectuer également la construction du pool sans aucun drapeau.
Sys::Virt::StoragePool::CREATE_WITH_BUILD_OVERWRITE
Créer le pool et effectuer la construction du pool en utilisant le drapeau BUILD_OVERWRITE. Ceci est mutuellement exclusif avec CREATE_WITH_BUILD_NO_OVERWRITE.
Sys::Virt::StoragePool::CREATE_WITH_BUILD_NO_OVERWRITE
Créer le pool et effectuer la construction du pool en utilisant le drapeau BUILD_NO_OVERWRITE. Ceci est mutuellement exclusif avec CREATE_WITH_BUILD_OVERWRITE.

DOCUMENTS XML

Sys::Virt::StoragePool::XML_INACTIVE

ÉVÉNEMENTS DE CHANGEMENT DE CYCLE DE VIE

Les constantes suivantes permettent d'interpréter les événements de changement de cycle de vie du pool de stockage. Les événements contiennent à la fois un changement d'état et une raison, bien que la raison ne soit actuellement pas utilisée.

Sys::Virt::StoragePool::EVENT_DEFINED
Indique qu'une configuration persistante a été définie pour le pool de stockage
Sys::Virt::StoragePool::EVENT_STARTED
Le pool de stockage a démarré
Sys::Virt::StoragePool::EVENT_STOPPED
Le pool de stockage s'est arrêté
Sys::Virt::StoragePool::EVENT_UNDEFINED
La configuration persistante a disparu
Sys::Virt::StoragePool::EVENT_CREATED
Le stockage sous-jacent a été construit
Sys::Virt::StoragePool::EVENT_DELETED
Le stockage sous-jacent a été libéré
