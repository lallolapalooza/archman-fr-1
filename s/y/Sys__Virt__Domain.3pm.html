NOM

Sys::Virt::Domain - Représenter & gérer un domaine invité libvirt

DESCRIPTION

Le module "Sys::Virt::Domain" représente un domaine invité géré par le moniteur de machine virtuelle.

This module allows you to manage libvirt virtual machine domains.

This class does not export any methods.
