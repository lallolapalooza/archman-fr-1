NOM

Sys::Syscall - accès aux appels système auxquels Perl ne fournit normalement pas d'accès

SYNTAXE

use Sys::Syscall;

DESCRIPTION

Utiliser epoll, sendfile, depuis Perl. Support principalement Linux pour le moment, mais d'autres appels système/OS sont prévus pour l'avenir.

Exportations

Rien par défaut.

Peut exporter : sendfile epoll_ctl epoll_create epoll_wait EPOLLIN EPOLLOUT EPOLLERR EPOLLHUP EPOLL_CTL_ADD EPOLL_CTL_DEL EPOLL_CTL_MOD

Tags d'exportation : :epoll et :sendfile

Fonctions

Support epoll

$ok = epoll_defined()
Retourne vrai si epoll est potentiellement disponible. (l'appelant doit toujours tester avec epoll_create)
$epfd = epoll_create([ $start_size ])
Crée un nouveau descripteur de fichier epoll. Retourne -1 si epoll n'est pas disponible.
$rv = epoll_ctl($epfd, $op, $fd, $events)
Voir la page man pour epoll_ctl
$count = epoll_wait($epfd, $max_events, $timeout, $arrayref)
Voir la page man pour epoll_wait. $arrayref est un référence de tableau à modifier avec les éléments retournés. Les valeurs placées dans $arrayref sont des références de tableaux de [$fd, $state].

Support sendfile

$ok = sendfile_defined()
Retourne vrai si sendfile devrait fonctionner sur ce système d'exploitation.
$sent = sendfile($sock_fd, $file_fd, $max_send)
Envoie jusqu'à $max_send octets de $file_fd à $sock_fd. Retourne les octets réellement envoyés, ou -1 en cas d'erreur.
