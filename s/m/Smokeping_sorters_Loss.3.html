NOM

Smokeping::sorters::Loss - Trier les graphiques par perte

APERÇU

Trouver les graphiques avec la plus grande perte.

DESCRIPTION

Appeler le trieur dans la section des graphiques du fichier de configuration

+ charts
 menu = Charts
 title = Les destinations les plus intéressantes
++ loss
 sorter = Loss(entries=>10)
 title = Les Perdants
 menu = Loss
 format = Paquets perdus %f
