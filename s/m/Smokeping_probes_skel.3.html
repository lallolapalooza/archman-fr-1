NOM

Smokeping::probes::skel - un squelette pour les sondes Smokeping

SYNOPIS

*** Probes ***
+skel
forks = 5
offset = 50%
step = 300
timeout = 15
# Les variables suivantes peuvent être redéfinies dans chaque section cible
/^influx_.+/ = influx_location = Dans le sous-sol
pings = 5
# [...]
*** Targets ***
probe = skel # si cela doit être la sonde par défaut
# [...]
+ mytarget
# probe = skel # si la sonde par défaut est autre chose
host = my.host
/^influx_.+/ = influx_location = Dans le sous-sol
pings = 5

DESCRIPTION

Ceci est un module non fonctionnel destiné à servir de base à la création de nouvelles sondes. Voir le document smokeping_extend pour plus d'informations.

VARIABLES

Variables spécifiques à la sonde supportées :

forks
Exécute ce nombre de processus simultanés au maximum

Exemple de valeur : 5

Valeur par défaut : 5

offset
Si vous exécutez de nombreuses sondes simultanément, vous voudrez peut-être éviter qu'elles n'atteignent votre réseau en même temps. En utilisant le paramètre d'offset spécifique à la sonde, vous pouvez modifier le moment où chaque sonde sera exécutée. L'offset est spécifié en % de l'intervalle total, ou alternativement comme 'random', et l'offset de la section 'General' est utilisé si rien n'est spécifié ici. Notez que cela n'affecte PAS les fichiers rrds eux-mêmes, il s'agit simplement du moment où l'acquisition des données est initiée. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 50%

step
Durée de l'intervalle de base que cette sonde doit utiliser, si elle est différente de celle spécifiée dans la section 'Database'. Notez que le pas (step) dans les fichiers RRD est fixe lorsqu'ils sont générés à l'origine, et si vous modifiez le paramètre step par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 300

timeout
Combien de temps prend un seul 'ping' au maximum

Exemple de valeur : 15

Valeur par défaut : 5

Variables spécifiques à la cible supportées :

/^influx_.+/
Ceci est une balise qui sera envoyée à influxdb et n'a aucun impact sur la mesure de la sonde. Le nom de la balise sera envoyé sans le préfixe "influx_", qui sera remplacé par "tag_" à la place. Les balises peuvent être utilisées pour le filtrage.

Exemple de valeur : influx_location = Dans le sous-sol

pings
Combien de pings doivent être envoyés à chaque cible, si différent de la valeur globale spécifiée dans la section Database. Notez que le nombre de pings dans les fichiers RRD est fixe lorsqu'ils sont générés à l'origine, et si vous modifiez ce paramètre par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre.

Exemple de valeur : 5
