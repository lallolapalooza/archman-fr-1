SMIME_READ_PKCS7(3ssl) OpenSSL SMIME_READ_PKCS7(3ssl)

NOM

SMIME_read_PKCS7_ex, SMIME_read_PKCS7 - analyser un message S/MIME

SYNTAXE

#include <openssl/pkcs7.h>
PKCS7 *SMIME_read_PKCS7_ex(BIO *bio, BIO **bcont, PKCS7 **p7);
PKCS7 *SMIME_read_PKCS7(BIO *in, BIO **bcont);

DESCRIPTION

SMIME_read_PKCS7() analyse un message au format S/MIME.

in est un BIO pour lire le message.

Si la signature en clair est utilisée, le contenu est sauvegardé dans un BIO mémoire qui est écrit dans *bcont, sinon *bcont est mis à NULL.

La structure PKCS#7 analysée est retournée ou NULL si une erreur s'est produite.

SMIME_read_PKCS7_ex() est similaire à SMIME_read_PKCS7() mais peut facultativement fournir un objet PKCS7 p7 précédemment créé. Si p7 est NULL, elle est identique à SMIME_read_PKCS7(). Pour créer un objet p7, utilisez PKCS7_new_ex(3).

NOTES

Si *bcont n'est pas NULL, le message est signé en clair. *bcont peut alors être passé à PKCS7_verify() avec le drapeau PKCS7_DETACHED défini.

Sinon, le type de la structure retournée peut être déterminé en utilisant PKCS7_type_is_enveloped(), etc.

Pour prendre en charge les fonctionnalités futures, si bcont n'est pas NULL, *bcont doit être initialisé à NULL. Par exemple :

BIO *cont = NULL;
PKCS7 *p7;
p7 = SMIME_read_PKCS7(in, &cont);

BOGUES

L'analyseur MIME utilisé par SMIME_read_PKCS7() est quelque peu primitif. Bien qu'il gère la plupart des messages S/MIME, les formats composites plus complexes peuvent ne pas fonctionner.

L'analyseur suppose que la structure PKCS7 est toujours encodée en base64 et ne gérera pas le cas où elle est au format binaire ou utilise un format quoted-printable.

L'utilisation d'un BIO mémoire pour contenir le contenu signé limite la taille des messages qui peuvent être traités en raison de contraintes mémoire : une option de flux en une seule passe devrait être disponible.

VALEUR DE RETOUR

SMIME_read_PKCS7_ex() et SMIME_read_PKCS7() retournent une structure PKCS7 valide ou NULL si une erreur s'est produite. L'erreur peut être obtenue auprès de ERR_get_error(3).

VOIR AUSSI

ERR_get_error(3), SMIME_read_PKCS7(3), PKCS7_sign(3), PKCS7_verify(3), PKCS7_encrypt(3) PKCS7_decrypt(3)

HISTORIQUE

La fonction SMIME_read_PKCS7_ex() a été ajoutée dans OpenSSL 3.0.
