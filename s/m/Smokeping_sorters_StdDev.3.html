NOM

Smokeping::sorters::StdDev - Ordonner les graphiques de cibles par StdDev

APERÇU

Trouver les graphiques avec l'écart-type le plus élevé parmi les pings envoyés à une cible unique. Plus il y a de fumée, plus l'écart-type est élevé.

DESCRIPTION

Appeler le trieur dans la section des graphiques du fichier de configuration

+ charts
 menu = Charts
 title = Les destinations les plus intéressantes
++ stddev
 sorter = StdDev(entries=>4)
 title = Top StdDev
 menu = Écart-type
 format = Écart-type %f
