Paquet: openssl

SMIME_READ_ASN1(3ssl) OpenSSL SMIME_READ_ASN1(3ssl)

NOM

SMIME_read_ASN1_ex, SMIME_read_ASN1 - analyser un message S/MIME

SYNTAXE

#include <openssl/asn1.h>
ASN1_VALUE *SMIME_read_ASN1_ex(BIO *in, int flags, BIO **bcont,
                               const ASN1_ITEM *it, ASN1_VALUE **x,
                               OSSL_LIB_CTX *libctx, const char *propq);
ASN1_VALUE *SMIME_read_ASN1(BIO *in, BIO **bcont, const ASN1_ITEM *it);

DESCRIPTION

SMIME_read_ASN1_ex() analyse un message au format S/MIME.

in est un BIO à partir duquel lire le message. Si l'argument flags contient CMS_BINARY, alors l'entrée est supposée être au format binaire et n'est pas traduite en forme canonique. Si de plus SMIME_ASCIICRLF est défini, alors l'entrée binaire est supposée être suivie des caractères CR et LF, sinon elle est uniquement suivie d'un caractère LF. x peut être utilisé pour fournir optionnellement un objet it ASN1_VALUE précédemment créé (tel que CMS_ContentInfo ou PKCS7), il peut être défini à NULL. Les valeurs valides qui peuvent être utilisées par la structure ASN.1 it sont ASN1_ITEM_rptr(PKCS7) ou ASN1_ITEM_rptr(CMS_ContentInfo). Toutes les recherches d'algorithmes qui se produisent pendant l'opération utiliseront le OSSL_LIB_CTX fourni dans le paramètre libctx, et utiliseront la chaîne de requête de propriété propq. Voir "ALGORITHM FETCHING" dans crypto(7) pour plus de détails sur la recherche d'algorithmes.

Si la signature en clair est utilisée, le contenu est sauvegardé dans un BIO mémoire qui est écrit dans *bcont, sinon *bcont est défini à NULL.

La structure ASN1_VALUE analysée est retournée ou NULL si une erreur s'est produite.

SMIME_read_ASN1() est similaire à SMIME_read_ASN1_ex() mais définit la valeur de x à NULL et la valeur de flags à 0.

NOTES

Les fonctions de plus haut niveau SMIME_read_CMS_ex(3) et SMIME_read_PKCS7_ex(3) devraient être utilisées à la place de SMIME_read_ASN1_ex().

Pour supporter les fonctionnalités futures, si bcont n'est pas NULL, *bcont devrait être initialisé à NULL.

BOGUES

Le parseur MIME utilisé par SMIME_read_ASN1_ex() est quelque peu primitif. Bien qu'il gère la plupart des messages S/MIME, des formats composites plus complexes peuvent ne pas fonctionner.

L'utilisation d'un BIO mémoire pour contenir le contenu signé limite la taille des messages qui peuvent être traités en raison de contraintes de mémoire : une option de flux à passage unique devrait être disponible.

VALEURS DE RETOUR

SMIME_read_ASN1_ex() et SMIME_read_ASN1() retournent une structure ASN1_VALUE valide ou NULL si une erreur s'est produite. L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

ERR_get_error(3), SMIME_read_CMS_ex(3), SMIME_read_PKCS7_ex(3), SMIME_write_ASN1(3), SMIME_write_ASN1_ex(3)

HISTORIQUE

La fonction SMIME_read_ASN1_ex() a été ajoutée dans OpenSSL 3.0.
