NAME

Smokeping::probes::FPing - Sonde FPing pour SmokePing

SYNOPSIS

*** Sondes ***
+FPing
binary = /usr/bin/fping # obligatoire
blazemode = true
hostinterval = 1.5
interface = eth0
mininterval = 0.001
offset = 50%
packetsize = 5000
pings = 20
protocol = 4
sourceaddress = 192.168.0.1
step = 300
timeout = 1.5
tos = 0x20
usestdout = true
# Les variables suivantes peuvent être remplacées dans chaque section de cible
/^influx_.+/ = influx_location = Au sous-sol
# [...]
*** Cibles ***
probe = FPing # si c'est la sonde par défaut
# [...]
+ ma_cible
# probe = FPing # si la sonde par défaut est autre chose
host = mon.hote
/^influx_.+/ = influx_location = Au sous-sol

DESCRIPTION

Intègre FPing comme sonde dans smokeping. La variable binary doit pointer vers votre copie du programme FPing. S'il n'est pas encore installé sur votre système, vous pouvez obtenir une version légèrement améliorée depuis "pub" sur www.smokeping.org.

L'option (optionnelle) packetsize vous permet de configurer la taille des paquets pour les pings envoyés.

Depuis la version 3.3, fping envoie ses statistiques sur stdout. Définissez usestdout à 'true' pour que smokeping lise stdout au lieu de stderr.

En mode blazemode, FPing envoie un ping de plus que celui demandé, et ignore la première valeur RTT retournée car elle est susceptible d'être une valeur aberrante.

La page de manuel FPing dit ceci à ce sujet :

Nombre d'octets de données de ping à envoyer. La taille minimale (normalement 12) laisse de la place pour les données dont fping a besoin pour fonctionner (numéro de séquence, horodatage). La taille des données reçues indiquées comprend l'en-tête IP (normalement 20 octets) et l'en-tête ICMP (8 octets), donc la taille totale minimale est de 40 octets. Par défaut, c'est 56, comme dans ping. Le maximum est la taille théorique maximale d'une datagramme IP (64 Ko), bien que la plupart des systèmes la limitent à un nombre plus petit, dépendant du système.

VARIABLES

Variables spécifiques à la sonde prises en charge :

binary
L'emplacement de votre binaire fping.

Exemple de valeur : /usr/bin/fping

Ce paramètre est obligatoire.

blazemode
Envoyer un ping supplémentaire puis ignorer la première réponse car la première sera forcément une valeur aberrante.

Exemple de valeur : true

hostinterval
Le paramètre "-p" de fping, mais en secondes (éventuellement fractionnaires) plutôt qu'en millisecondes, pour la cohérence avec les autres sondes Smokeping. D'après fping(1) :

Ce paramètre définit le temps que fping attend entre les paquets successifs vers une cible individuelle.

Exemple de valeur : 1.5

interface
Le nom de l'interface réseau sur laquelle effectuer le ping.

Exemple de valeur : eth0

mininterval
Le paramètre "-i" de fping, mais en secondes (probablement fractionnaires) plutôt qu'en millisecondes, pour la cohérence avec les autres sondes Smokeping. D'après fping(1) :

La quantité minimale de temps entre l'envoi d'un paquet ping vers une cible quelconque.

Exemple de valeur : 0.001

Valeur par défaut : 0.01

offset
Si vous exécutez de nombreuses sondes simultanément, vous voudrez peut-être éviter qu'elles n'atteignent votre réseau en même temps. En utilisant le paramètre d'offset spécifique à la sonde, vous pouvez modifier le moment où chaque sonde sera exécutée. L'offset est spécifié en % de l'intervalle total, ou alternativement comme 'random', et l'offset de la section 'General' est utilisé si rien n'est spécifié ici. Notez que cela n'a AUCUNE influence sur les rrds eux-mêmes, il s'agit simplement d'une question de quand l'acquisition des données est initiée. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 50%

packetsize
La taille du paquet ping (dans la plage de 12 à 64000 octets).

Exemple de valeur : 5000

pings
Combien de pings doivent être envoyés à chaque cible, si différent de la valeur globale spécifiée dans la section Database. Notez que le nombre de pings dans les fichiers RRD est fixe lorsqu'ils sont générés à l'origine, et si vous changez ce paramètre par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre.

Exemple de valeur : 20

protocol
Choisir si le ping doit utiliser IPv4 ou IPv6.

Exemple de valeur : 4

sourceaddress
Le paramètre "-S" de fping. D'après fping(1) :

Définir l'adresse source.

Exemple de valeur : 192.168.0.1

step
Durée de l'intervalle de base que cette sonde doit utiliser, si différent de celui spécifié dans la section 'Database'. Notez que le pas dans les fichiers RRD est fixe lorsqu'ils sont générés à l'origine, et si vous changez le paramètre de pas par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 300

timeout
Le paramètre "-t" de fping, mais en secondes (éventuellement fractionnaires) plutôt qu'en millisecondes, pour la cohérence avec les autres sondes Smokeping. Notez que comme Smokeping utilise le mode de 'comptage' (-C) de fping, cela n'affecte apparemment que le dernier ping.

Exemple de valeur : 1.5

tos
Définir le type de service (TOS) des paquets ICMP sortants. Vous avez besoin au minimum de fping-2.4b2_to3-ipv6 pour que cela fonctionne. Trouvez une copie sur www.smokeping.org/pub.

Exemple de valeur : 0x20

usestdout
Écouter la sortie de FPing sur stdout au lieu de stderr... (version 3.3+ envoie ses statistiques sur stdout).

Exemple de valeur : true
