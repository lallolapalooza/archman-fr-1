NOM

Smokeping::probes::Radius - une sonde d'authentification RADIUS pour SmokePing

VUE D'ENSEMBLE

Mesure la latence d'authentification RADIUS pour SmokePing

SYNOPIS

*** Sondes ***
+Radius
forks = 5
offset = 50%
passwordfile = /quelque/part/secret
secretfile = /un/autre/endroit/secret
step = 300
# Les variables suivantes peuvent être remplacées dans chaque section cible
/^influx_.+/ = influx_location = Au sous-sol
allowreject = true
mininterval = 1
nas_ip_address = 10.1.2.3
password = motdepasse-test
pings = 5
port = 1645
secret = secret-test
timeout = 5
username = utilisateur-test # obligatoire
# [...]
*** Cibles ***
probe = Radius # si c'est la sonde par défaut
# [...]
+ ma-cible
# probe = Radius # si la sonde par défaut est autre chose
host = mon.hote
/^influx_.+/ = influx_location = Au sous-sol
allowreject = true
mininterval = 1
nas_ip_address = 10.1.2.3
password = motdepasse-test
pings = 5
port = 1645
secret = secret-test
timeout = 5
username = utilisateur-test # obligatoire

DESCRIPTION

Cette sonde mesure la latence d'authentification RADIUS (RFC 2865) pour SmokePing.

Le nom d'utilisateur à tester est spécifié soit dans la variable `username' spécifique à la sonde, soit dans la variable spécifique à la cible, la variable spécifique à la cible ayant priorité sur celle de la sonde.

Le mot de passe peut être spécifié soit (par ordre de priorité, le dernier remplaçant le précédent) dans la variable `password' spécifique à la sonde, dans un fichier externe, ou dans la variable `password' spécifique à la cible. L'emplacement de ce fichier est indiqué dans la variable `passwordfile' spécifique à la sonde. Voir Smokeping::probes::passwordchecker(3pm) pour le format de ce fichier (résumé : triplets séparés par des deux-points de la forme `<hote>:<nom_utilisateur>:<mot_de_passe>')

Le protocole RADIUS nécessite un secret partagé entre le serveur et le client. Ce secret peut être spécifié soit (par ordre de priorité, le dernier remplaçant le précédent) dans la variable `secret' spécifique à la sonde, dans un fichier externe, ou dans la variable `secret' spécifique à la cible. Ce fichier externe est localisé par la variable `secretfile' spécifique à la sonde, et il doit contenir des paires séparées par des espaces de la forme `<hote> <secret>'. Les commentaires et les lignes blanches sont acceptés.

Si la variable facultative `nas_ip_address' spécifique à la sonde est spécifiée, sa valeur est insérée dans les requêtes d'authentification en tant qu'attribut RADIUS `NAS-IP-Address'.

La sonde essaie d'être respectueuse envers le serveur et n'envoie pas de requêtes d'authentification plus fréquemment qu'une fois toutes les X secondes, où X est la valeur de la variable `min_interval' spécifique à la cible (1 par défaut).

VARIABLES

Variables spécifiques à la sonde supportées :

forks
Exécuter ce nombre de processus concurrents au maximum

Exemple de valeur : 5

Valeur par défaut : 5

offset
Si vous exécutez de nombreuses sondes simultanément, vous pourriez vouloir éviter qu'elles n'atteignent votre réseau en même temps. En utilisant le paramètre d'offset spécifique à la sonde, vous pouvez modifier le moment où chaque sonde sera exécutée. L'offset est spécifié en % de l'intervalle total, ou alternativement comme 'random', et l'offset de la section 'General' est utilisé si rien n'est spécifié ici. Notez que cela n'influence PAS les rrds eux-mêmes, il s'agit simplement de savoir quand l'acquisition des données est initiée. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 50%

passwordfile
Emplacement du fichier contenant les noms d'utilisateur et les mots de passe.

Exemple de valeur : /quelque/part/secret

secretfile
Un fichier contenant les secrets partagés RADIUS pour les cibles. Il doit contenir des paires séparées par des espaces de la forme `<hote> <secret>'. Les commentaires et les lignes blanches sont acceptés.

Exemple de valeur : /un/autre/endroit/secret

step
Durée de l'intervalle de base que cette sonde doit utiliser, si différent de celui spécifié dans la section 'Database'. Notez que l'intervalle des fichiers RRD est fixe lorsqu'ils sont générés à l'origine, et si vous modifiez le paramètre step par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 300

Variables spécifiques à la cible supportées :

/^influx_.+/
Ceci est une étiquette qui sera envoyée à influxdb et n'aura aucun impact sur la mesure de la sonde. Le nom de l'étiquette sera envoyé sans le préfixe "influx_", qui sera remplacé par "tag_" à la place. Les étiquettes peuvent être utilisées pour le filtrage.

Exemple de valeur : influx_location = Au sous-sol

allowreject
Traiter les réponses "reject" comme OK

Exemple de valeur : true

mininterval
L'intervalle minimum entre chaque requête d'authentification envoyée, en secondes (potentiellement fractionnaires).

Valeur par défaut : 1

nas_ip_address
L'attribut RADIUS NAS-IP-Address pour les requêtes d'authentification. Pas nécessaire partout.

Exemple de valeur : 10.1.2.3

password
Le mot de passe de l'utilisateur, s'il n'est pas présent dans le fichier de mots de passe.

Exemple de valeur : motdepasse-test

pings
Combien de pings doivent être envoyés à chaque cible, si différent de la valeur globale spécifiée dans la section Database. Notez que le nombre de pings dans les fichiers RRD est fixe lorsqu'ils sont générés à l'origine, et si vous modifiez ce paramètre par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre.

Exemple de valeur : 5

port
Le port RADIUS à utiliser

Exemple de valeur : 1645

secret
Le secret partagé RADIUS pour la cible, s'il n'est pas présent dans le fichier de secrets.

Exemple de valeur : secret-test

timeout
Timeout en secondes pour les requêtes RADIUS.

Valeur par défaut : 5

username
Le nom d'utilisateur à tester.

Exemple de valeur : utilisateur-test

Ce réglage est obligatoire.

BOGUES
