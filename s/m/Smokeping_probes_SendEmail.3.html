NOM

Smokeping::probes::SendEmail - une sonde Smokeping pour mesurer le temps nécessaire à l'envoi d'un e-mail

SYNOPIS

*** Sondes ***
+SendEmail
bodysize = 1024
forks = 5
from = test@test.com # obligatoire
offset = 50%
step = 300
subject = Test Smokeping
timeout = 15
to = test@test.com # obligatoire
# Les variables suivantes peuvent être redéfinies dans chaque section de cible
/^influx_.+/ = influx_location = Au sous-sol
pings = 5
port = 25
# [...]
*** Cibles ***
probe = SendEmail # si c'est la sonde par défaut
# [...]
+ ma_cible
# probe = SendEmail # si la sonde par défaut est autre chose
host = mon.hote
/^influx_.+/ = influx_location = Au sous-sol
pings = 5
port = 25

DESCRIPTION

Cette sonde envoie réellement un mail à un serveur MX et mesure le temps que cela prend. Vous pouvez choisir l'adresse de l'expéditeur et du destinataire, ainsi que la taille du mail.

VARIABLES

Variables spécifiques à la sonde supportées :

bodysize
Taille du mail à envoyer en octets. Si définie à 0, un contenu de mail par défaut sera utilisé. Notez que les mails contiennent toujours les en-têtes From, To et Subject.

Exemple de valeur : 1024

Valeur par défaut : 0

forks
Exécute ce nombre de processus concurrents au maximum.

Exemple de valeur : 5

Valeur par défaut : 5

from
Adresse e-mail de l'expéditeur.

Exemple de valeur : test@test.com

Ce paramètre est obligatoire.

offset
Si vous exécutez de nombreuses sondes simultanément, vous pourriez vouloir éviter qu'elles n'impactent votre réseau en même temps. En utilisant le paramètre d'offset spécifique à la sonde, vous pouvez modifier le moment où chaque sonde sera exécutée. L'offset est spécifié en pourcentage de l'intervalle total, ou alternativement comme 'random', et l'offset de la section 'General' est utilisé si rien n'est spécifié ici. Notez que cela n'influence PAS les fichiers RRD eux-mêmes, il s'agit simplement de savoir quand l'acquisition des données est initiée. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 50%

step
Durée de l'intervalle de base que cette sonde doit utiliser, si différente de celle spécifiée dans la section 'Database'. Notez que le pas dans les fichiers RRD est fixe lorsqu'ils sont générés à l'origine, et si vous changez le paramètre 'step' par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 300

subject
Objet du mail.

Exemple de valeur : Test Smokeping

Valeur par défaut : Test

timeout
Combien de temps prend un seul 'ping' au maximum.

Exemple de valeur : 15

Valeur par défaut : 5

to
Adresse du destinataire.

Exemple de valeur : test@test.com

Ce paramètre est obligatoire.

Variables spécifiques à la cible supportées :

/^influx_.+/
Ceci est une balise qui sera envoyée à influxdb et n'a aucun impact sur la mesure de la sonde. Le nom de la balise sera envoyé sans le préfixe "influx_", qui sera remplacé par "tag_" à la place. Les balises peuvent être utilisées pour filtrer.

Exemple de valeur : influx_location = Au sous-sol

pings
Combien de pings doivent être envoyés à chaque cible, si différent de la valeur globale spécifiée dans la section Database. Notez que le nombre de pings dans les fichiers RRD est fixe lors de leur génération initiale, et si vous changez ce paramètre par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre.

Exemple de valeur : 5

port
Port du serveur SMTP à atteindre.

Exemple de valeur : 25

Valeur par défaut : 25
