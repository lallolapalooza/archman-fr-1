NOM

Smokeping::matchers::Avgratio - détecter les changements dans la latence médiane moyenne

APERÇU

Le comparateur Avgratio établit une moyenne historique de la latence médiane sur plusieurs tours de mesure. Il compare cette moyenne à une seconde valeur moyenne de latence, également construite sur plusieurs tours de mesure.

DESCRIPTION

Appelez le comparateur avec la séquence suivante :

type = matcher
pattern =  Avgratio(historic=>a,current=>b,comparator=>o,percentage=>p)
historic
Le nombre de valeurs médianes à utiliser pour construire la moyenne 'historique'.
current
Le nombre de valeurs médianes à utiliser pour construire la moyenne 'actuelle'.
comparator
Quel opérateur de comparaison doit être utilisé pour comparer le pourcentage actuel/historique.
percentage
Côté droit de la comparaison.
old <--- historic ---><--- current ---> now

EXEMPLE

Prenez la moyenne de la latence médiane sur 10 échantillons, utilisez-la pour diviser la latence moyenne actuelle construite sur 2 échantillons et vérifiez si elle est supérieure à 150%.

Avgratio(historic=>10,current=>2,comparator=>'>',percentage=>150);
avg(current)/avg(historic) > 150/100

Cela signifie que le comparateur s'activera lorsque la latence moyenne actuelle sera plus de 1,5 fois supérieure à la latence moyenne historique établie sur les 10 derniers tours de mesure.
