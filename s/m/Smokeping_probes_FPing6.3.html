NOM

Smokeping::probes::FPing6 - Sonde FPing6 pour SmokePing

SYNOPIS

*** Sondes ***
+FPing6
binary = /usr/bin/fping6 # obligatoire
blazemode = true
hostinterval = 1.5
interface = eth0
mininterval = 0.001
offset = 50%
packetsize = 5000
pings = 20
protocol = 6
sourceaddress = ::1
step = 300
timeout = 1.5
tos = 0x20
usestdout = true
# Les variables suivantes peuvent être écrasées dans chaque section cible
/^influx_.+/ = influx_location = Au sous-sol
# [...]
*** Cibles ***
probe = FPing6 # si c'est la sonde par défaut
# [...]
+ ma-cible
# probe = FPing6 # si la sonde par défaut est autre chose
host = mon.host
/^influx_.+/ = influx_location = Au sous-sol

DESCRIPTION

Intègre FPing6 comme sonde dans smokeping. Cette sonde est dérivée de FPing ; la seule différence est que l'hôte cible utilisé pour vérifier la sortie de la commande fping est ::1 au lieu de localhost.

VARIABLES

Variables spécifiques à la sonde supportées :

binary
L'emplacement de votre binaire fping.

Exemple de valeur : /usr/bin/fping6

Ce réglage est obligatoire.

blazemode
Envoie un ping supplémentaire puis ignore la première réponse car elle est susceptible d'être une valeur aberrante.

Exemple de valeur : true

hostinterval
Le paramètre "-p" de fping, mais en secondes (éventuellement fractionnaires) plutôt qu'en millisecondes, pour la cohérence avec les autres sondes Smokeping. D'après fping(1) :

Ce paramètre définit le temps que fping attend entre les paquets successifs envoyés à une cible individuelle.

Exemple de valeur : 1.5

interface
Le nom de l'interface réseau sur laquelle effectuer le ping.

Exemple de valeur : eth0

mininterval
Le paramètre "-i" de fping, mais en secondes (probablement fractionnaires) plutôt qu'en millisecondes, pour la cohérence avec les autres sondes Smokeping. D'après fping(1) :

La quantité de temps minimale entre l'envoi d'un paquet ping à n'importe quelle cible.

Exemple de valeur : 0.001

Valeur par défaut : 0.01

offset
Si vous exécutez de nombreuses sondes simultanément, vous pourriez vouloir éviter qu'elles n'atteignent votre réseau en même temps. En utilisant le paramètre offset spécifique à la sonde, vous pouvez modifier le moment où chaque sonde sera exécutée. L'offset est spécifié en % de l'intervalle total, ou alternativement comme 'random', et l'offset de la section 'General' est utilisé si rien n'est spécifié ici. Notez que cela n'influence PAS les fichiers RRD eux-mêmes, il s'agit simplement de savoir quand l'acquisition des données est initiée. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 50%

packetsize
La taille du paquet ping (dans la plage de 12 à 64000 octets).

Exemple de valeur : 5000

pings
Combien de pings doivent être envoyés à chaque cible, si différent de la valeur globale spécifiée dans la section Database. Notez que le nombre de pings dans les fichiers RRD est fixe lors de leur génération initiale, et si vous modifiez ce paramètre par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre.

Exemple de valeur : 20

protocol
Choisir si le ping doit utiliser IPv4 ou IPv6.

Exemple de valeur : 6

Valeur par défaut : 6

sourceaddress
Le paramètre "-S" de fping. D'après fping(1) :

Définit l'adresse source.

Exemple de valeur : ::1

step
Durée de l'intervalle de base que cette sonde doit utiliser, si différent de celui spécifié dans la section 'Database'. Notez que le pas dans les fichiers RRD est fixe lors de leur génération initiale, et si vous modifiez le paramètre step par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 300

timeout
Le paramètre "-t" de fping, mais en secondes (éventuellement fractionnaires) plutôt qu'en millisecondes, pour la cohérence avec les autres sondes Smokeping. Notez que comme Smokeping utilise le mode de comptage de fping ('-C'), cela n'affecte apparemment que le dernier ping.

Exemple de valeur : 1.5

tos
Définit le type de service (TOS) des paquets ICMP sortants. Vous avez besoin d'au moins fping-2.4b2_to3-ipv6 pour que cela fonctionne. Vous pouvez en trouver une copie sur www.smokeping.org/pub.

Exemple de valeur : 0x20

usestdout
Écouter la sortie de FPing sur stdout au lieu de stderr... (la version 3.3+ envoie ses statistiques sur stdout).

Exemple de valeur : true
