NOM

Smokeping::matchers::ConsecutiveLoss - Déclenche/efface des alertes conformément à votre choix de seuil et de valeurs consécutives

DESCRIPTION

Utilisez ce matcher pour déclencher et effacer des alertes selon votre choix de seuil et de valeurs consécutives. Par exemple, vous pouvez déclencher une alerte dès la première occurrence de 50 % de perte de paquets, mais choisir de maintenir l'alerte active tant que la perte de paquets reste inférieure à 10 % pendant 5 mesures consécutives.

Ajoutez le matcher à votre fichier de configuration en utilisant la syntaxe ci-dessous :

type = matcher
edgetrigger = yes
pattern =  ConsecutiveLoss(pctlossraise =>##,stepsraise =>##,pctlossclear =>##,stepsclear =>##)

Remplacez les ## par des entiers de votre choix, voir ci-dessous pour référence :

pctlossraise - Les valeurs de perte égales ou supérieures à ce pourcentage déclencheront une alerte lorsque... stepsraise - ... le nombre de valeurs consécutives aura été collecté

pctlossclear - Les valeurs de perte inférieures à ce pourcentage effaceront une alerte lorsque... stepsclear - ... le nombre de valeurs consécutives aura été collecté

Dans mon environnement, je définis quatre alertes pour des niveaux tels que :

+packetloss_significant_instantalert
type = matcher
pattern = ConsecutiveLoss(pctlossraise =>10,stepsraise =>1,pctlossclear =>3,stepsclear =>3)
comment = Alerte instantanée - Perte de paquet significative détectée (Au moins 10 % sur 1 cycle). L'alerte sera effacée lorsque la perte restera à un maximum de 2 % pendant 3 cycles
priority = 30
+packetloss_major_instantalert
type = matcher
pattern = ConsecutiveLoss(pctlossraise =>25,stepsraise =>1,pctlossclear =>3,stepsclear =>3)
comment = Alerte instantanée - Perte de paquet majeure détectée (Au moins 25 % sur 1 cycle). L'alerte sera effacée lorsque la perte restera à un maximum de 2 % pendant 3 cycles
priority = 20
+packetloss_significant_consecutivealert
type = matcher
pattern = ConsecutiveLoss(pctlossraise =>10,stepsraise =>3,pctlossclear =>3,stepsclear =>5)
comment = Occurrence consécutive de perte de paquet significative détectée (Au moins 10 % sur 3 cycles). L'alerte sera effacée lorsque la perte restera à un maximum de 2 % pendant 5 cycles.
priority = 10
+packetloss_major_consecutivealert
type = matcher
pattern = ConsecutiveLoss(pctlossraise =>25,stepsraise =>3,pctlossclear =>3,stepsclear =>5)
comment = Occurrence consécutive de perte de paquet significative détectée (Au moins 25 % sur 3 cycles). L'alerte sera effacée lorsque la perte restera à un maximum de 2 % pendant 5 cycles.
priority = 5
