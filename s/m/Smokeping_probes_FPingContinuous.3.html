NOM

Smokeping::probes::FPingContinuous - Sonde FPingContinuous pour SmokePing

SYNOPIS

*** Sondes ***
+FPingContinuous
binary = /usr/bin/fping # obligatoire
hostinterval = 1.5
offset = 50%
packetsize = 5000
pings = 20
sourceaddress = 192.168.0.1
step = 300
timeout = 1.5
tos = 0x20
usestdout = false
# Les variables suivantes peuvent être remplacées dans chaque section cible
/^influx_.+/ = influx_location = Au sous-sol
# [...]
*** Cibles ***
probe = FPingContinuous # si ceci doit être la sonde par défaut
# [...]
+ ma_cible
# probe = FPingContinuous # si la sonde par défaut est autre chose
host = my.host
/^influx_.+/ = influx_location = Au sous-sol

DESCRIPTION

Intègre FPingContinuous comme sonde dans smokeping. La variable binary doit pointer vers votre copie du programme FPing. S'il n'est pas encore installé sur votre système, vous pouvez obtenir une version légèrement améliorée de "pub" sur www.smokeping.org.

L'option (facultative) packetsize vous permet de configurer la taille des paquets pour les pings envoyés.

La sortie continue est normalement envoyée sur stdout, mais vous pouvez définir usestdout sur 'false' pour que smokeping lise stderr au lieu de stdout.

La page de manuel de FPing dit ceci à ce sujet :

Nombre d'octets de données ping à envoyer. La taille minimale (normalement 12) laisse de la place pour les données dont fping a besoin pour fonctionner (numéro de séquence, horodatage). La taille des données reçues signalées inclut l'en-tête IP (normalement 20 octets) et l'en-tête ICMP (8 octets), donc la taille totale minimale est de 40 octets. La valeur par défaut est 56, comme pour ping. Le maximum est la taille maximale théorique du datagramme IP (64 Ko), bien que la plupart des systèmes la limitent à un nombre plus petit, dépendant du système.

VARIABLES

Variables spécifiques à la sonde prises en charge :

binary
L'emplacement de votre binaire fping.

Exemple de valeur : /usr/bin/fping

Ce réglage est obligatoire.

hostinterval
Le paramètre "-p" de fping, mais en secondes (potentiellement fractionnaires) plutôt qu'en millisecondes, pour la cohérence avec les autres sondes Smokeping. D'après fping(1) :

Ce paramètre définit le temps que fping attend entre les paquets successifs vers une cible individuelle.

Exemple de valeur : 1.5

offset
Si vous exécutez plusieurs sondes simultanément, vous voudrez peut-être éviter qu'elles n'atteignent votre réseau toutes en même temps. En utilisant le paramètre d'offset spécifique à la sonde, vous pouvez modifier le moment où chaque sonde sera exécutée. L'offset est spécifié en % de l'intervalle total, ou alternativement comme 'random', et l'offset de la section 'General' est utilisé si rien n'est spécifié ici. Notez que cela n'influence PAS les rrds elles-mêmes, il s'agit juste d'une question de quand l'acquisition des données est initiée. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 50%

packetsize
La taille du paquet de ping (dans la plage de 12 à 64000 octets).

Exemple de valeur : 5000

pings
Combien de pings doivent être envoyés à chaque cible, si différent de la valeur globale spécifiée dans la section Database. Notez que le nombre de pings dans les fichiers RRD est fixe lorsqu'ils sont générés à l'origine, et si vous modifiez ce paramètre par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre.

Exemple de valeur : 20

sourceaddress
Le paramètre "-S" de fping. D'après fping(1) :

Définir l'adresse source.

Exemple de valeur : 192.168.0.1

step
Durée de l'intervalle de base que cette sonde doit utiliser, si différent de celui spécifié dans la section 'Database'. Notez que le pas dans les fichiers RRD est fixe lorsqu'ils sont générés à l'origine, et si vous modifiez le paramètre step par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 300

timeout
Le paramètre "-t" de fping, mais en secondes (potentiellement fractionnaires) plutôt qu'en millisecondes, pour la cohérence avec les autres sondes Smokeping. Notez que comme Smokeping utilise le mode de comptage '-C' de fping, cela n'affecte apparemment que le dernier ping.

Exemple de valeur : 1.5

tos
Définir le type de service (TOS) des paquets ICMP sortants. Vous avez besoin d'au moins de fping-2.4b2_to3-ipv6 pour que cela fonctionne. Trouvez une copie sur www.smokeping.org/pub.

Exemple de valeur : 0x20

usestdout
Écouter la sortie FPing sur stdout au lieu de stderr... (la sortie continue est normalement envoyée sur stdout).

Exemple de valeur : false
