NOM

Smokeping::probes::RemoteFPing - Sonde FPing à distance pour SmokePing

SYNOPIS

*** Sondes ***
+RemoteFPing
binary = /usr/bin/ssh # obligatoire
blazemode = true
hostinterval = 1.5
interface = eth0
mininterval = 0.001
offset = 50%
packetsize = 5000
pings = 20
protocol = 4
rbinary = /usr/bin/fping # obligatoire
rhost = mon.pinger.host # obligatoire
rport = 22
ruser = foo
sourceaddress = 192.168.0.1
step = 300
timeout = 1.5
tos = 0x20
usestdout = true
# Les variables suivantes peuvent être remplacées dans chaque section de cible
/^influx_.+/ = influx_location = Au sous-sol
# [...]
*** Cibles ***
probe = RemoteFPing # si cela doit être la sonde par défaut
# [...]
+ ma_cible
# probe = RemoteFPing # si la sonde par défaut est autre chose
host = mon.host
/^influx_.+/ = influx_location = Au sous-sol

DESCRIPTION

Intègre l'exécution à distance de FPing via ssh/rsh dans smokeping. La variable binary doit pointer vers votre copie du programme ssh/rsh. La variable rbinary doit pointer vers votre copie du programme fping à l'extrémité distante.

VARIABLES

Variables spécifiques à la sonde supportées :

binary
Cette variable spécifie le chemin du programme de shell distant (généralement ssh, rsh ou remsh). Tout autre script ou binaire qui peut être appelé comme

binary [ -l ruser ] [ -p rport ] rhost rbinary

peut être utilisé.

Exemple de valeur : /usr/bin/ssh

Ce réglage est obligatoire.

blazemode
Envoie un ping supplémentaire puis ignore la première réponse car la première sera forcément un outlier.

Exemple de valeur : true

hostinterval
Le paramètre fping "-p", mais en secondes (éventuellement fractionnaires) plutôt qu'en millisecondes, pour la cohérence avec les autres sondes Smokeping. De fping(1) :

Ce paramètre définit le temps que fping attend entre les paquets successifs vers une cible individuelle.

Exemple de valeur : 1.5

interface
Le nom de l'interface réseau sur laquelle effectuer le ping.

Exemple de valeur : eth0

mininterval
Le paramètre fping "-i", mais en secondes (probablement fractionnaires) plutôt qu'en millisecondes, pour la cohérence avec les autres sondes Smokeping. De fping(1) :

Le temps minimum entre l'envoi d'un paquet ping à n'importe quelle cible.

Exemple de valeur : 0.001

Valeur par défaut : 0.01

offset
Si vous exécutez de nombreuses sondes simultanément, vous pourriez vouloir éviter qu'elles n'atteignent votre réseau en même temps. En utilisant le paramètre d'offset spécifique à la sonde, vous pouvez changer le moment où chaque sonde sera exécutée. L'offset est spécifié en % de l'intervalle total, ou alternativement comme 'random', et l'offset de la section 'General' est utilisé si rien n'est spécifié ici. Notez que cela n'influence PAS les RRD elles-mêmes, il s'agit juste d'une question de quand l'acquisition de données est initiée. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 50%

packetsize
La taille du paquet ping (dans la plage de 12 à 64000 octets).

Exemple de valeur : 5000

pings
Combien de pings doivent être envoyés à chaque cible, si cela est différent de la valeur globale spécifiée dans la section Base de données. Notez que le nombre de pings dans les fichiers RRD est fixe lorsqu'ils sont générés à l'origine, et si vous changez ce paramètre par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre.

Exemple de valeur : 20

protocol
Choisir si le ping doit utiliser IPv4 ou IPv6.

Exemple de valeur : 4

rbinary
L'emplacement de votre binaire fping.

Exemple de valeur : /usr/bin/fping

Ce réglage est obligatoire.

rhost
L'option rhost spécifie le périphérique distant à partir duquel fping sera lancé.

Exemple de valeur : mon.pinger.host

Ce réglage est obligatoire.

rport
L'option (facultative) rport vous permet de spécifier le port de l'hôte distant.

Exemple de valeur : 22

ruser
L'option (facultative) ruser vous permet de spécifier l'utilisateur distant, s'il est différent de celui qui exécute le démon smokeping.

Exemple de valeur : foo

sourceaddress
Le paramètre fping "-S". De fping(1) :

Définit l'adresse source.

Exemple de valeur : 192.168.0.1

step
Durée de l'intervalle de base que cette sonde doit utiliser, si cela est différent de celui spécifié dans la section 'Base de données'. Notez que le pas dans les fichiers RRD est fixe lors de leur génération initiale, et si vous changez le paramètre de pas par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 300

timeout
Le paramètre fping "-t", mais en secondes (éventuellement fractionnaires) plutôt qu'en millisecondes, pour la cohérence avec les autres sondes Smokeping. Notez qu'étant donné que Smokeping utilise le mode de comptage de fping (-C), cela n'affecte apparemment que le dernier ping.

Exemple de valeur : 1.5

tos
Définit le type de service (TOS) des paquets ICMP sortants. Vous avez besoin d'au moins fping-2.4b2_to3-ipv6 pour que cela fonctionne. Trouvez une copie sur www.smokeping.org/pub.

Exemple de valeur : 0x20

usestdout
Écoute la sortie de FPing sur stdout au lieu de stderr ... (la version 3.3+ envoie ses statistiques sur stdout).

Exemple de valeur : true

NOTES

Il est important de s'assurer que vous pouvez accéder à la machine distante sans invite de mot de passe, sinon cette sonde ne fonctionnera pas correctement. Pour tester, essayez simplement quelque chose comme ceci :

$ ssh foo@HostA.foobar.com fping HostB.barfoo.com

La prochaine chose que vous devriez voir est la sortie de fping.

Les variables rhost, ruser, rport et rbinary étaient auparavant configurées dans la section Cibles de la première cible ou de ses parents. Elles ont été déplacées dans la section Sondes, car les variables ne sont pas vraiment spécifiques aux cibles (toutes les cibles sont mesurées avec les mêmes paramètres). Les sections Cibles ne sont plus reconnues.

BOGUES

Cette fonctionnalité devrait se trouver dans un module générique d'exécution à distance afin qu'elle puisse être utilisée pour les autres sondes également.
