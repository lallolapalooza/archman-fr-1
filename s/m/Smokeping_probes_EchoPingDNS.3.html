NOM

Smokeping::probes::EchoPingDNS - une sonde echoping(1) pour SmokePing

APERÇU

Mesure les temps de réponse DNS pour SmokePing avec le plugin echoping_dns.

SYNOPIS

*** Sondes ***
+EchoPingDNS
binary = /usr/bin/echoping
forks = 5
offset = 50%
step = 300
# Les variables suivantes peuvent être remplacées dans chaque section cible
/^influx_.+/ = influx_location = Dans le sous-sol
dns_request = example.org # obligatoire
dns_tcp = yes
dns_type = AAAA
extraopts = -une-lettre-que-l-auteur-n-a-pas-prevue
ipversion = 4
pings = 5
plugin = /path/to/dns.so
pluginargs = -p argument_specifique_plugin
priority = 6
timeout = 1
tos = 0xa0
waittime = 1
# [...]
*** Cibles ***
probe = EchoPingDNS # si c'est la sonde par défaut
# [...]
+ ma_cible
# probe = EchoPingDNS # si la sonde par défaut est autre chose
host = mon.hote
/^influx_.+/ = influx_location = Dans le sous-sol
dns_request = example.org # obligatoire
dns_tcp = yes
dns_type = AAAA
extraopts = -une-lettre-que-l-auteur-n-a-pas-prevue
ipversion = 4
pings = 5
plugin = /path/to/dns.so
pluginargs = -p argument_specifique_plugin
priority = 6
timeout = 1
tos = 0xa0
waittime = 1

VARIABLES

Variables spécifiques à la sonde prises en charge :

binary
L'emplacement de votre binaire echoping.

Valeur par défaut : /usr/bin/echoping

forks
Exécute ce nombre de processus simultanés au maximum

Exemple de valeur : 5

Valeur par défaut : 5

offset
Si vous exécutez de nombreuses sondes simultanément, vous voudrez peut-être éviter qu'elles ne frappent votre réseau en même temps. En utilisant le paramètre offset spécifique à la sonde, vous pouvez modifier le moment où chaque sonde sera exécutée. L'offset est spécifié en % de l'intervalle total, ou alternativement comme 'random', et l'offset de la section 'General' est utilisé si rien n'est spécifié ici. Notez que cela n'influence PAS les fichiers RRD eux-mêmes, il s'agit simplement de quand l'acquisition des données est initiée. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 50%

step
Durée de l'intervalle de base que cette sonde doit utiliser, s'il est différent de celui spécifié dans la section 'Database'. Notez que le pas dans les fichiers RRD est fixe lorsqu'ils sont générés à l'origine, et si vous modifiez le paramètre step par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 300

Variables spécifiques à la cible prises en charge :

/^influx_.+/
Il s'agit d'une balise qui sera envoyée à influxdb et n'aura aucun impact sur la mesure de la sonde. Le nom de la balise sera envoyé sans le préfixe "influx_", qui sera remplacé par "tag_" à la place. Les balises peuvent être utilisées pour le filtrage.

Exemple de valeur : influx_location = Dans le sous-sol

dns_request
La requête DNS (nom de domaine) à interroger.

Exemple de valeur : example.org

Ce paramètre est obligatoire.

dns_tcp
L'option echoping_dns '--tcp' : utiliser uniquement TCP ('circuit virtuel'). Activé si spécifié avec une valeur autre que 'no' ou '0'.

Exemple de valeur : yes

dns_type
L'option echoping_dns '-t' : type de données demandées (NS, A, SOA etc.)

Exemple de valeur : AAAA

Valeur par défaut : A

extraopts
Toutes les options supplémentaires spécifiées ici seront passées sans modification à echoping(1).

Exemple de valeur : -une-lettre-que-l-auteur-n-a-pas-prevue

ipversion
Le protocole IP utilisé. Les valeurs possibles sont "4" et "6". Passé à echoping(1) sous les options "-4" ou "-6".

Exemple de valeur : 4

pings
Combien de pings doivent être envoyés à chaque cible, s'il est différent de la valeur globale spécifiée dans la section Database. Notez que le nombre de pings dans les fichiers RRD est fixé lors de leur génération initiale, et si vous modifiez ce paramètre par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre.

Exemple de valeur : 5

plugin
Le plugin echoping qui sera utilisé. Voir echoping(1) pour les détails. Il peut s'agir du nom du plugin ou du chemin complet vers l'objet partagé du plugin.

Exemple de valeur : /path/to/dns.so

Valeur par défaut : dns

pluginargs
Tous les arguments supplémentaires nécessaires au plugin echoping spécifié avec la variable pluginname. Ceux-ci sont généralement fournis par la sonde de sous-classe.

Exemple de valeur : -p argument_specifique_plugin

priority
L'option "-p" de echoping(1).

Exemple de valeur : 6

timeout
L'option "-t" de echoping(1).

Exemple de valeur : 1

Valeur par défaut : 5

tos
L'option "-P" de echoping(1).

Exemple de valeur : 0xa0

waittime
L'option "-w" de echoping(1).

Exemple de valeur : 1

AUTEURS

Niko Tyni <ntyni@iki.fi>

NOTES

Les variables fill, size et udp d'EchoPing ne sont pas valides.

Les plugins, y compris echoping_dns, sont disponibles à partir de la version 6 d'echoping.
