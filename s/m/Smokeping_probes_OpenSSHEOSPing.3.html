NOM

Smokeping::probes::OpenSSHEOSPing - Sonde SSH d'Arista EOS pour SmokePing

SYNOPIS

*** Sondes ***
+OpenSSHEOSPing
forks = 5
offset = 50%
packetsize = 100
step = 300
timeout = 15
# Les variables suivantes peuvent être remplacées dans chaque section de cible
/^influx_.+/ = influx_location = Au fond
eospass = password # requis
eosuser = utilisateur # requis
pings = 5
psource = 192.168.2.129
source = 192.168.2.1 # requis
unpriv = 1
# [...]
*** Cibles ***
probe = OpenSSHEOSPing # si c'est la sonde par défaut
# [...]
+ ma_cible
# probe = OpenSSHEOSPing # si la sonde par défaut est différente
host = mon.host
/^influx_.+/ = influx_location = Au fond
eospass = password # requis
eosuser = utilisateur # requis
pings = 5
psource = 192.168.2.129
source = 192.168.2.1 # requis
unpriv = 1

DESCRIPTION

Se connecter à Arista EOS via SSH pour exécuter des commandes ping. Cette sonde utilise la commande "ping" CLI d'Arista EOS. Vous avez la possibilité de spécifier à partir de quelle interface le ping sera initié différemment.

VARIABLES

Variables spécifiques à la sonde :

forks
Le nombre maximum de processus simultanés à exécuter

Exemple de valeur : 5

Valeur par défaut : 5

offset
Si vous exécutez de nombreuses sondes simultanées, vous voudrez peut-être éviter qu'elles ne se connectent toutes à votre réseau en même temps. En utilisant le paramètre d'offset spécifique à la cible, vous pouvez modifier le moment où chaque sonde est exécutée. L'offset est spécifié en % de l'intervalle total, ou alternativement comme 'random', et l'offset de la section 'General' est utilisé si rien n'est spécifié ici. Gardez à l'esprit que cela n'affecte pas les rrds, il s'agit uniquement du moment où la collecte de données est initiée. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 50%

packetsize
Le paramètre (optionnel) packetsize permet de configurer la taille des paquets pour les pings envoyés.

Valeur par défaut : 100

step
L'intervalle de base que cette sonde doit utiliser, s'il est différent de celui spécifié dans la section 'Database'. Gardez à l'esprit que le pas dans les fichiers rrd est fixe à l'original et si vous modifiez le paramètre par la suite, vous devrez supprimer les anciens fichiers ou les convertir. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 300

timeout
Le temps maximum accordé pour un "ping" individuel

Exemple de valeur : 15

Valeur par défaut : 5

Variables spécifiques à la cible :

/^influx_.+/
Ceci est une balise qui est envoyée à influxdb et n'a aucun impact sur le compteur de la sonde. Le nom de la balise est envoyé sans le préfixe 'influx_', qui est remplacé par 'tag_'. Les balises peuvent être utilisées pour filtrer.

Exemple de valeur : influx_location = Au fond

eospass
Le paramètre eospass permet de spécifier le mot de passe de l'utilisateur spécifié avec le paramètre eosuser.

Exemple de valeur : password

Ce réglage est obligatoire.

eosuser
Le paramètre eosuser permet de spécifier un utilisateur ayant la capacité de ping sur l'appareil EOS.

Exemple de valeur : utilisateur

Ce réglage est obligatoire.

pings
Le nombre de pings à envoyer à chaque cible, s'il est différent de la valeur globale spécifiée dans la section 'Database'. Gardez à l'esprit que le nombre de pings dans les fichiers rrd est fixe à l'original et si vous modifiez ce paramètre par la suite, vous devrez supprimer les anciens fichiers ou les convertir.

Exemple de valeur : 5

psource
Le paramètre (optionnel) psource spécifie une adresse IP ou une interface alternative à partir de laquelle vous souhaitez lancer vos pings. Les routeurs peuvent avoir de nombreuses adresses IP et interfaces. Lorsque vous pinguez à partir d'un routeur, vous avez la possibilité de choisir à partir de quelle interface et/ou de quelle adresse IP les pings seront initiés. La spécification d'une IP/interface ne spécifie pas nécessairement l'interface de sortie, mais elle spécifie l'adresse à partir de laquelle les paquets semblent provenir. Si ce paramètre est omis, l'appareil EOS lancera automatiquement le paquet en se basant sur le routage et/ou les métriques du réseau. Si cela n'est pas clair, omettez simplement le paramètre.

Exemple de valeur : 192.168.2.129

source
Le paramètre source spécifie l'appareil EOS qui exécutera les commandes ping. Cette adresse sera utilisée pour la connexion SSH.

Exemple de valeur : 192.168.2.1

Ce réglage est obligatoire.

unpriv
Si le compte est non privilégié, spécifiez le paramètre unpriv. Vous devez également définir pings = 5, car c'est la seule valeur prise en charge, et les valeurs spécifiées pour packetsize ou psource sont ignorées.

Exemple de valeur : 1

NOTES

Configuration EOS

L'appareil EOS doit avoir un utilisateur et un mot de passe configurés, et le serveur SSH doit être actif.

Assurez-vous de vous connecter à l'hôte distant depuis la ligne de commande en tant qu'utilisateur qui exécute smokeping. Lors de la première connexion, ssh vous demandera d'ajouter le nouvel hôte à votre fichier known_hosts. Cela ne se produit pas automatiquement, le script échouera donc jusqu'à ce que la clé de l'appareil EOS soit dans le fichier known_hosts.

Exigences

Ce module nécessite les bibliothèques Perl Net::OpenSSH et IO::Pty.
