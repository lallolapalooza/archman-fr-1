NOM

Smokeping::probes::basevars - Une autre classe de base pour implémenter les sondes SmokePing

APERÇU

Similaire à Smokeping::probes::base, mais prend en charge les variables spécifiques à l'hôte pour la sonde.

SYNTAXE

*** Probes ***
+basevars
offset = 50%
pings = 20
step = 300
# Les variables suivantes peuvent être redéfinies dans chaque section cible
/^influx_.+/ = influx_location = Dans la cave
# [...]
*** Targets ***
probe = basevars # si c'est la sonde par défaut
# [...]
+ mytarget
# probe = basevars # si la sonde par défaut est autre chose
host = my.host
/^influx_.+/ = influx_location = Dans la cave

DESCRIPTION

Fournit la méthode `targets' qui renvoie une liste de hachages. Les hachages contiennent les entrées :

addr
L'adresse de la cible.
vars
Un hachage contenant les variables définies dans la section de configuration correspondante.
tree
L'index unique que `probe::base' utilise pour les cibles.

Il existe également la méthode 'vars' qui renvoie le hachage mentionné ci-dessus correspondant au paramètre d'index 'tree'.

VARIABLES

Variables spécifiques à la sonde prises en charge :

offset
Si vous exécutez de nombreuses sondes simultanément, vous pourriez vouloir éviter qu'elles n'atteignent votre réseau en même temps. En utilisant le paramètre d'offset spécifique à la sonde, vous pouvez modifier le moment où chaque sonde sera exécutée. L'offset est spécifié en % de l'intervalle total, ou alternativement comme 'random', et l'offset de la section 'General' est utilisé si rien n'est spécifié ici. Notez que cela n'influence PAS les fichiers rrds eux-mêmes, il s'agit simplement du moment où l'acquisition des données est initiée. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 50%

pings
Combien de pings doivent être envoyés à chaque cible, si cela diffère de la valeur globale spécifiée dans la section Database. Notez que le nombre de pings dans les fichiers RRD est fixe lors de leur génération initiale, et si vous modifiez ce paramètre par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre.

Exemple de valeur : 20

step
Durée de l'intervalle de base que cette sonde doit utiliser, si cela diffère de celui spécifié dans la section 'Database'. Notez que le pas dans les fichiers RRD est fixe lors de leur génération initiale, et si vous modifiez le paramètre de pas par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 300
