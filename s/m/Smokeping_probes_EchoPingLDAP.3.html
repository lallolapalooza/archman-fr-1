NOM

Smokeping::probes::EchoPingLDAP - un probe echoping(1) pour SmokePing

APERÇU

Mesure des temps de trajet LDAP pour SmokePing avec le plugin echoping_ldap.

SYNOPIS

*** Probes ***
+EchoPingLDAP
binary = /usr/bin/echoping
forks = 5
offset = 50%
step = 300
# Les variables suivantes peuvent être remplacées dans chaque section cible
/^influx_.+/ = influx_location = Dans le sous-sol
extraopts = -lettre-inconnue-de-l-auteur
ipversion = 4
ldap_base = dc=mon,dc=domaine,dc=fr
ldap_request = (objectclass=*)
ldap_scope = one
pings = 5
plugin = /chemin/vers/ldap.so
pluginargs = -p arg_specifique_plugin
priority = 6
timeout = 1
tos = 0xa0
waittime = 1
# [...]
*** Cibles ***
probe = EchoPingLDAP # si ceci doit être le probe par défaut
# [...]
+ ma_cible
# probe = EchoPingLDAP # si le probe par défaut est différent
host = mon.serveur.fr
/^influx_.+/ = influx_location = Dans le sous-sol
extraopts = -lettre-inconnue-de-l-auteur
ipversion = 4
ldap_base = dc=mon,dc=domaine,dc=fr
ldap_request = (objectclass=*)
ldap_scope = one
pings = 5
plugin = /chemin/vers/ldap.so
pluginargs = -p arg_specifique_plugin
priority = 6
timeout = 1
tos = 0xa0
waittime = 1

VARIABLES

Variables spécifiques au probe supportées:

binary
Emplacement de votre exécutable echoping.
forks
Nombre maximum de processus parallèles à exécuter.
offset
Si vous exécutez de nombreux probes en parallèle, vous pourriez vouloir éviter qu'ils ne frappent tous votre réseau au même moment. En utilisant la variable de probe spécifique 'offset', vous pouvez décaler le moment où chaque probe s'exécute. L'offset est spécifié en % de l'intervalle total, ou alternativement comme 'random', et est utilisé comme référence par la section 'General'. Notez que cela n'influence pas les rrds, c'est juste une question de quand l'acquisition des données démarre. (Cette variable s'applique uniquement si la variable 'concurrentprobes' est définie dans la section 'General').
step
Durée de l'intervalle de base que ce probe devrait utiliser, si différente de celle spécifiée dans la section 'Database'. Notez que le step dans les fichiers rrd est fixe lors de leur création et, si vous changez ce paramètre après coup, vous devrez supprimer les anciens fichiers rrd ou les convertir. (Cette variable s'applique uniquement si la variable 'concurrentprobes' est définie dans la section 'General').

Variables spécifiques à la cible supportées:

/^influx_.+/
Ceci est une étiquette envoyée à influxdb et n'affecte pas la mesure du probe. Le nom de l'étiquette est envoyé sans le préfixe 'influx_', qui est remplacé par 'tag_'. Les étiquettes peuvent être utilisées pour le filtrage.
extraopts
Les options supplémentaires spécifiées ici sont transmises sans modification à echoping(1).
ipversion
Le protocole IP utilisé. Les valeurs possibles sont "4" et "6". Transmis à echoping(1) comme "-4" ou "-6".
ldap_base
Option echoping_ldap '-b': base de la recherche.
ldap_request
Option echoping_ldap '-r': requête envoyée au serveur LDAP, en langage de filtre LDAP.
ldap_scope
Option echoping_ldap '-s': étendue de la recherche, "sub", "one" ou "base".
pings
Combien de pings doivent être envoyés à chaque cible, si différent de la valeur globale spécifiée dans la section 'Database'. Notez que le nombre de pings dans les fichiers rrd est fixe lors de leur création et, si vous changez ce paramètre après coup, vous devrez supprimer les anciens fichiers rrd ou les convertir.
plugin
Le plugin echoping à utiliser. Voir echoping(1) pour les détails. Peut être le nom du plugin ou le chemin complet vers la librairie partagée du plugin.
pluginargs
Arguments supplémentaires nécessaires pour le plugin spécifié avec la variable 'pluginname'. Ceux-ci sont généralement fournis par le sous-probe.
priority
L'option '-p' de echoping(1).
timeout
L'option '-t' de echoping(1).
tos
L'option '-P' de echoping(1).
waittime
L'option '-w' de echoping(1).

AUTEURS

Niko Tyni <ntyni@iki.fi>

NOTES

Les valeurs 'fill', 'size' et 'udp' dans le probe ne sont pas valides.

Les plugins, y compris echoping_ldap, sont disponibles depuis les versions 6 d'echoping.
