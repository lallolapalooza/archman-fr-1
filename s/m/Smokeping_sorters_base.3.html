NOM

Smokeping::sorters::base - Classe de base pour l'implémentation des trieurs SmokePing

APERÇU

Les trieurs sont au cœur de la fonctionnalité de graphiques de SmokePing, où les graphiques les plus intéressants sont présentés sur une seule page. Le trieur décide quels graphiques sont considérés comme intéressants.

Chaque trieur doit hériter de la classe de base et fournir ses propres méthodes pour la logique « métier ».

Afin de maintenir des performances décentes, l'activité des trieurs est divisée en deux parties.

La première partie est active pendant que le démon smokeping collecte ses données. Chaque fois que des données sont reçues, le trieur est appelé pour calculer une « valeur » pour les données présentes. À chaque « cycle de requête », ces informations sont stockées dans le répertoire de stockage des trieurs. Chaque processus smokeping stocke ses propres informations. Comme smokeping peut s'exécuter en plusieurs instances simultanément, les données peuvent être réparties sur plusieurs fichiers.

La deuxième partie du trieur est appelée depuis smokeping.cgi. Elle charge toutes les informations du stockage du trieur et les intègre dans un « arbre » unique. Elle appelle ensuite chaque trieur avec les données pré-calculées pour les trier et sélectionner les informations intéressantes.

DESCRIPTION

Chaque trieur doit fournir les méthodes suivantes :

new

La méthode new attend des éléments de hachage comme arguments, par exemple new({x=>'\d+',y=>'\d+'},x=>1,y=>2). La première partie est une règle de syntaxe pour les arguments qu'elle doit attendre et la seconde partie sont les arguments eux-mêmes. La première partie sera fournie par la classe enfant lorsqu'elle appellera la méthode parente.

Desc

Retourne simplement la description de la fonction. Cette méthode doit être remplacée par une classe enfant de la classe de base.

SortTree

Retourne un tableau de « cibles ». Il appartient au trieur de décider combien d'entrées la liste doit contenir. Si la liste est vide, l'entrée entière sera supprimée dans le frontend web.

La méthode donne accès à toutes les cibles du système, ainsi qu'au dernier ensemble de données acquis pour chaque cible.

CalcValues

Détermine la valeur de tri actuelle en utilisant l'entrée suivante.

$info = { uptime => w,
          loss   => x,
          median => y,
          alert  => z, # (0/1)
          pings  => [qw(a b c d)] }

La sortie peut avoir la structure que vous souhaitez. Elle sera retournée à la méthode du trieur pour un traitement ultérieur.
