NOM

Smokeping::sorters::Median - Ordonner les graphiques par médiane

APERÇU

Trouver les graphiques avec le temps de trajet aller-retour (RTT) médian le plus élevé.

DESCRIPTION

Appeler le trieur dans la section des graphiques du fichier de configuration

+ charts
 menu = Charts
 title = Les destinations les plus intéressantes
++ median
 sorter = Median(entries=>10)
 title = Temps de trajet aller-retour médian supérieur
 menu = RTT médian
 format = Temps de trajet aller-retour médian %f secondes
