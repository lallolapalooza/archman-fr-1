NAME

Smokeping::probes::FTPtransfer - sondeur de bande passante intrusive

APERÇU

Cette sonde envoie et récupère des fichiers vers ou depuis un serveur FTP. Elle cartographiera la bande passante que vous pouvez utiliser.

SYNTAXE

*** Sondes ***
+FTPtransfer
destfile = chemin/vers/fichier_destination.xxx
forks = 5
min_interval = 1
mode = get # obligatoire
offset = 50%
passwordfile = /chemin/vers/fichier_secret
srcfile = chemin/vers/fichier_source.pdf # obligatoire
step = 300
timeout = 15 # obligatoire
# Les variables suivantes peuvent être surchargées dans chaque section de destination
/^influx_.+/ = influx_location = Au sous-sol
localaddr = monhote-nat-if
passive = yes
password = motdepasse-secret
pings = 5
port = 3255
timeout = 10
username = utilisateur-test

DESCRIPTION

La sonde utilise le client Perl Net::FTP pour effectuer des tests de performance à l'aide d'un serveur FTP comme cible. Cette sonde est intrusive car elle transfère des données réelles. En utilisant des données réelles, vous avez une chance raisonnable de voir à quel point une connexion est bonne lorsqu'il s'agit de transférer des fichiers réels.

Le mot de passe peut être spécifié soit dans la variable spécifique à la sonde `password`, soit dans un fichier externe, soit dans la variable spécifique à la destination `password`. L'emplacement de ce fichier externe est indiqué dans la variable spécifique à la sonde `passwordfile`. Voir Smokeping::probes::passwordchecker(3pm) pour le format de ce fichier (résumé : triplets de la forme `<hôte>:<utilisateur>:<motdepasse>` séparés par un tiret).

La sonde essaie d'être conviviale envers le serveur et attend au moins X secondes entre le début des transferts de fichiers, où X est la valeur de la variable spécifique à la sonde `min_interval` (1 par défaut).

De nombreuses variables peuvent être spécifiées à la fois dans la sonde et dans la définition de la destination, la variable de destination surchargeant la variable de la sonde.

Si votre transfert prend beaucoup de temps, il peut être utile de définir correctement le timeout et le max_rtt afin que Smokeping n'interrompe pas les transferts et limite la taille du graphique.

VARIABLES

Variables spécifiques à la sonde :

destfile
Normalement, le nom du fichier de destination est le même que le nom du fichier source (sans le chemin). Si vous souhaitez conserver les fichiers dans des répertoires différents, cela ne fonctionne pas et vous devez spécifier `destfile` ainsi.

Exemple de valeur : chemin/vers/fichier_destination.xxx

forks
Autant de processus que possible sont exécutés simultanément.

Exemple de valeur : 5

Valeur par défaut : 5

min_interval
L'intervalle minimum entre chaque session FTP où le fichier est initié.

Valeur par défaut : 1

mode
Le mode FTP peut être en mode `put` ou `get`. Si en mode `put`, il enverra un fichier au serveur FTP. Si en mode `get`, il récupérera un fichier du serveur FTP.

Exemple de valeur : get

Cette valeur est obligatoire.

offset
Si vous exécutez plusieurs sondes simultanément, vous pouvez éviter que toutes se connectent en même temps à partir de votre local. En utilisant le paramètre d'offset de la sonde, vous pouvez modifier le moment où chaque sonde s'exécutera. L'offset est spécifié en pourcentage de l'intervalle total, ou alternativement comme `random`, et l'offset du bloc général sera utilisé si rien n'est spécifié ici. Remarque : cela n'affecte PAS les fichiers RRD, il s'agit uniquement du moment où l'acquisition des données commence. (Cette variable n'est applicable que si la variable `concurrentprobes` est définie dans le bloc général.)

Exemple de valeur : 50%

passwordfile
Emplacement du fichier contenant les utilisateurs et les mots de passe.

Exemple de valeur : /chemin/vers/fichier_secret

srcfile
Nom du fichier source. Si la sonde est en mode `put`, ce fichier doit se trouver sur le périphérique local ; si la sonde est en mode `get`, ce fichier doit se trouver sur le compte FTP distant.

Exemple de valeur : chemin/vers/fichier_source.pdf

Cette valeur est obligatoire.

step
La durée de l'intervalle de base que cette sonde utilisera, si différent de la valeur spécifiée dans le bloc de base. Remarque : la valeur de step dans les fichiers RRD est fixée au moment de leur création, et si vous modifiez ce paramètre ultérieurement, vous devrez supprimer les anciens fichiers RRD ou les convertir. (Cette valeur n'est applicable que si la variable `concurrentprobes` est définie dans le bloc général.)

Exemple de valeur : 300

timeout
Le timeout est le temps maximum autorisé à la sonde pour transférer le fichier. Si la sonde ne parvient pas à terminer le transfert dans le temps spécifié, elle sera terminée et des pertes seront enregistrées.

Comme la sonde FTPtransfer est une sonde intrusive, vous devez vous assurer de ne pas surcharger le lien pendant plus de quelques secondes. Smokeping a une limite fixe de 180 secondes pour tout RTT.

Exemple de valeur : 15

Cette valeur est obligatoire.

Variables spécifiques à la destination :

/^influx_.+/
Il s'agit d'une étiquette qui sera envoyée à influxdb et n'affecte pas la mesure de la sonde. Le nom de l'étiquette est envoyé sans le préfixe `influx_`, qui sera remplacé par `tag_`. Les étiquettes peuvent être utilisées pour le filtrage.

Exemple de valeur : influx_location = Au sous-sol

localaddr
L'adresse locale à utiliser pour les connexions.

Exemple de valeur : monhote-nat-if

passive
Utiliser le protocole FTP passif.

Exemple de valeur : yes

password
Le mot de passe de l'utilisateur, s'il n'est pas présent dans le fichier de mots de passe.

Exemple de valeur : motdepasse-secret

pings
Combien de pings doivent être envoyés à chaque destination, si différent de la valeur globale spécifiée dans le bloc de base. Remarque : le nombre de pings dans les fichiers RRD est fixé au moment de leur création, et si vous modifiez ce paramètre ultérieurement, vous devrez supprimer les anciens fichiers RRD ou les convertir.

Exemple de valeur : 5

port
Un port FTP non standard à utiliser.

Exemple de valeur : 3255

timeout
Le délai d'attente en secondes pour terminer le transfert FTP.

Exemple de valeur : 10

username
Le nom d'utilisateur à tester.

Exemple de valeur : utilisateur-test

BOGUES

Cette sonde a le potentiel de saturer vos liens, ne l'utilisez donc pas à moins de savoir ce que vous faites.

La sonde FTPtransfer mesure la bande passante, mais nous rapportons le nombre de secondes nécessaires pour transférer le fichier 'reference' depuis le serveur. C'est parce que l'idée de Round Trip Time est actuellement au centre de l'application. Une réingénierie serait nécessaire pour la diviser en plugins et la rendre configurable...
