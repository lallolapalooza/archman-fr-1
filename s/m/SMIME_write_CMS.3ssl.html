NOM

SMIME_write_CMS - convertir une structure CMS au format S/MIME

SYNOPIS

#include <openssl/cms.h>
int SMIME_write_CMS(BIO *out, CMS_ContentInfo *cms, BIO *data, int flags);

DESCRIPTION

SMIME_write_CMS() ajoute les en-têtes MIME appropriés à une structure CMS pour produire un message S/MIME.

out est le BIO sur lequel écrire les données. cms est la structure CMS_ContentInfo appropriée. Si le streaming est activé, le contenu doit être fourni dans l'argument data. flags est un ensemble optionnel d'indicateurs.

NOTES

Les indicateurs suivants peuvent être passés dans le paramètre flags.

Si CMS_DETACHED est défini, la signature en clair sera utilisée, cette option n'a de sens que pour SignedData où CMS_DETACHED est également défini lors de l'appel à CMS_sign().

Si l'indicateur CMS_TEXT est défini, des en-têtes MIME de type text/plain sont ajoutés au contenu, cela n'a de sens que si CMS_DETACHED est également défini.

Si l'indicateur CMS_STREAM est défini, le streaming est effectué. Cet indicateur ne doit être défini que si CMS_STREAM a également été défini lors de l'appel précédent à une fonction de création de CMS_ContentInfo.

Si la signature en clair est utilisée et que CMS_STREAM n'est pas défini, les données doivent être lues deux fois : une fois pour calculer la signature dans CMS_sign() et une fois pour afficher le message S/MIME.

En cas de streaming, le contenu est affiché au format BER en utilisant l'encodage construit de longueur indéfinie, sauf dans le cas de données signées avec contenu détaché où le contenu est absent et le format DER est utilisé.

BOGUES

SMIME_write_CMS() encode toujours les structures CMS en base64, il devrait y avoir une option pour désactiver cela.

VALEUR DE RETOUR

SMIME_write_CMS() renvoie 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI

Bien que rien ne soit particulièrement utile ici.
