NOM

Smokeping::probes::EchoPingWhois - une sonde echoping(1) pour SmokePing

APERÇU

Mesure les temps de réponse aller-retour whois pour SmokePing avec le plugin echoping_whois.

SYNTAXE

*** Sondes ***
+EchoPingWhois
binary = /usr/bin/echoping
forks = 5
offset = 50%
step = 300
# Les variables suivantes peuvent être remplacées dans chaque section cible
/^influx_.+/ = influx_location = Dans le sous-sol
extraopts = -une-lettre-a-laquelle-l-auteur-n-a-pas-pense
ipversion = 4
pings = 5
plugin = /path/to/whois.so
pluginargs = -p argument_specifique_au_plugin
priority = 6
timeout = 1
tos = 0xa0
waittime = 1
whois_request = example.org # obligatoire
# [...]
*** Cibles ***
probe = EchoPingWhois # si c'est la sonde par défaut
# [...]
+ mytarget
# probe = EchoPingWhois # si la sonde par défaut est autre chose
host = my.host
/^influx_.+/ = influx_location = Dans le sous-sol
extraopts = -une-lettre-a-laquelle-l-auteur-n-a-pas-pense
ipversion = 4
pings = 5
plugin = /path/to/whois.so
pluginargs = -p argument_specifique_au_plugin
priority = 6
timeout = 1
tos = 0xa0
waittime = 1
whois_request = example.org # obligatoire

VARIABLES

Variables spécifiques à la sonde supportées :

binary
L'emplacement de votre binaire echoping.

Valeur par défaut : /usr/bin/echoping

forks
Exécuter ce nombre de processus concurrents au maximum

Exemple de valeur : 5

Valeur par défaut : 5

offset
Si vous exécutez de nombreuses sondes simultanément, vous pourriez vouloir éviter qu'elles frappent votre réseau toutes en même temps. En utilisant le paramètre d'offset spécifique à la sonde, vous pouvez changer le moment où chaque sonde sera exécutée. L'offset est spécifié en pourcentage de l'intervalle total, ou alternativement comme 'random', et l'offset de la section 'General' est utilisé si rien n'est spécifié ici. Notez que cela n'affecte PAS les fichiers RRD eux-mêmes, il s'agit juste d'une question de quand l'acquisition des données est initiée. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 50%

step
Durée de l'intervalle de base que cette sonde doit utiliser, si elle est différente de celle spécifiée dans la section 'Database'. Notez que le pas dans les fichiers RRD est fixe lors de leur génération initiale, et si vous modifiez le paramètre 'step' par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre. (Cette variable n'est applicable que si la variable 'concurrentprobes' est définie dans la section 'General'.)

Exemple de valeur : 300

Variables spécifiques à la cible supportées :

/^influx_.+/
Ceci est une étiquette qui sera envoyée à influxdb et n'a aucun impact sur la mesure de la sonde. Le nom de l'étiquette sera envoyé sans le préfixe "influx_", qui sera remplacé par "tag_" à la place. Les étiquettes peuvent être utilisées pour le filtrage.

Exemple de valeur : influx_location = Dans le sous-sol

extraopts
Toute option supplémentaire spécifiée ici sera passée sans modification à echoping(1).

Exemple de valeur : -une-lettre-a-laquelle-l-auteur-n-a-pas-pense

ipversion
Le protocole IP utilisé. Les valeurs possibles sont "4" et "6". Transmis à echoping(1) comme les options "-4" ou "-6".

Exemple de valeur : 4

pings
Combien de pings doivent être envoyés à chaque cible, si différent de la valeur globale spécifiée dans la section Database. Notez que le nombre de pings dans les fichiers RRD est fixé lors de leur génération initiale, et si vous modifiez ce paramètre par la suite, vous devrez supprimer les anciens fichiers RRD ou les convertir d'une manière ou d'une autre.

Exemple de valeur : 5

plugin
Le plugin echoping qui sera utilisé. Voir echoping(1) pour les détails. Cela peut être soit le nom du plugin, soit le chemin complet vers la bibliothèque partagée du plugin.

Exemple de valeur : /path/to/whois.so

Valeur par défaut : whois

pluginargs
Tous les arguments supplémentaires nécessaires au plugin echoping spécifié avec la variable pluginname. Ceux-ci sont généralement fournis par la sonde fille.

Exemple de valeur : -p argument_specifique_au_plugin

priority
L'option "-p" de echoping(1).

Exemple de valeur : 6

timeout
L'option "-t" de echoping(1).

Exemple de valeur : 1

Valeur par défaut : 5

tos
L'option "-P" de echoping(1).

Exemple de valeur : 0xa0

waittime
L'option "-w" de echoping(1).

Exemple de valeur : 1

whois_request
La requête au serveur whois (généralement un nom de domaine).

Exemple de valeur : example.org

Ce paramètre est obligatoire.

AUTEURS

Niko Tyni <ntyni@iki.fi>

NOTES

Les variables fill, size et udp de EchoPing ne sont pas valides.

Les plugins, y compris echoping_whois, sont disponibles à partir de la version 6 d'echoping.
