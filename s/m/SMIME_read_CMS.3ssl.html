SMIME_read_CMS(3ssl)

Paquet: openssl

Licences: Apache-2.0

SMIME_READ_CMS(3ssl) OpenSSL SMIME_READ_CMS(3ssl)

NOM

SMIME_read_CMS_ex, SMIME_read_CMS - analyser un message S/MIME

SYNTAXIS

#include <openssl/cms.h>
CMS_ContentInfo *SMIME_read_CMS_ex(BIO *bio, int flags, BIO **bcont,
                                   CMS_ContentInfo **cms);
CMS_ContentInfo *SMIME_read_CMS(BIO *in, BIO **bcont);

DESCRIPTION

SMIME_read_CMS() analyse un message au format S/MIME.

in est un BIO pour lire le message.

Si la signature en texte clair est utilisée, le contenu est sauvegardé dans un bio mémoire qui est écrit dans *bcont, sinon *bcont est mis à NULL.

La structure CMS_ContentInfo analysée est retournée ou NULL si une erreur s'est produite.

SMIME_read_CMS_ex() est similaire à SMIME_read_CMS() mais optionnellement un objet CMS_ContentInfo cms créé précédemment peut être fourni ainsi que des flags. Pour créer un objet cms, utilisez CMS_ContentInfo_new_ex(3). Si l'argument flags contient CMS_BINARY, alors l'entrée est supposée être au format binaire et n'est pas traduite en forme canonique. Si de plus SMIME_ASCIICRLF est défini, alors l'entrée binaire est supposée être suivie des caractères CR et LF, sinon seulement par un caractère LF. Si flags est 0 et cms est NULL, alors c'est identique à SMIME_read_CMS().

NOTES

Si *bcont n'est pas NULL, alors le message est signé en texte clair. *bcont peut alors être passé à CMS_verify() avec le flag CMS_DETACHED défini.

Sinon, le type de la structure retournée peut être déterminé en utilisant CMS_get0_type().

Pour supporter les fonctionnalités futures, si bcont n'est pas NULL, *bcont doit être initialisé à NULL. Par exemple :

BIO *cont = NULL;
CMS_ContentInfo *cms;
cms = SMIME_read_CMS(in, &cont);

BOGUES

L'analyseur MIME utilisé par SMIME_read_CMS() est quelque peu primitif. Bien qu'il gère la plupart des messages S/MIME, les formats composites plus complexes peuvent ne pas fonctionner.

L'analyseur suppose que la structure CMS_ContentInfo est toujours encodée en base64 et ne gérera pas le cas où elle est au format binaire ou utilise le format quoted-printable.

L'utilisation d'un bio mémoire pour contenir le contenu signé limite la taille du message qui peut être traité en raison de contraintes mémoire : une option de flux en une seule passe devrait être disponible.

VALEUR DE RETOUR

SMIME_read_CMS_ex() et SMIME_read_CMS() retournent une structure CMS_ContentInfo valide ou NULL si une erreur s'est produite. L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

ERR_get_error(3), CMS_sign(3), CMS_verify(3), CMS_encrypt(3), CMS_decrypt(3)

HISTORIQUE

La fonction SMIME_read_CMS_ex() a été ajoutée dans OpenSSL 3.0.
