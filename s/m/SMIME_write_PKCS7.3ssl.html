NOM

SMIME_write_PKCS7 - convertir une structure PKCS#7 au format S/MIME

SYNOPSIS

#include <openssl/pkcs7.h>
int SMIME_write_PKCS7(BIO *out, PKCS7 *p7, BIO *data, int flags);

DESCRIPTION

SMIME_write_PKCS7() ajoute les en-têtes MIME appropriés à une structure PKCS#7 pour produire un message S/MIME.

out est le BIO auquel écrire les données. p7 est la structure PKCS7 appropriée. Si le streaming est activé, le contenu doit être fourni dans l'argument data. flags est un ensemble optionnel de drapeaux.

NOTES

Les drapeaux suivants peuvent être passés dans le paramètre flags.

Si PKCS7_DETACHED est défini, la signature en clair sera utilisée ; cette option n'a de sens que pour signedData où PKCS7_DETACHED est également défini lors de l'appel à PKCS7_sign().

Si le drapeau PKCS7_TEXT est défini, des en-têtes MIME pour le type text/plain sont ajoutés au contenu ; cela n'a de sens que si PKCS7_DETACHED est également défini.

Si le drapeau PKCS7_STREAM est défini, le streaming est effectué. Ce drapeau ne doit être défini que si PKCS7_STREAM a également été défini lors de l'appel précédent à PKCS7_sign() ou PKCS7_encrypt().

Si la signature en clair est utilisée et que PKCS7_STREAM n'est pas défini, les données doivent être lues deux fois : une fois pour calculer la signature dans PKCS7_sign() et une fois pour produire le message S/MIME.

Si le streaming est effectué, le contenu est généré au format BER en utilisant un encodage construit de longueur indéfinie, sauf dans le cas des données signées avec contenu détaché où le contenu est absent et le format DER est utilisé.

BOGUES

SMIME_write_PKCS7() encode toujours les structures PKCS#7 en base64 ; il devrait y avoir une option pour désactiver cela.

VALEUR DE RETOUR

SMIME_write_PKCS7() renvoie 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI
