NOM

Smokeping::matchers::Median - Trouver des changements persistants de latence

APERÇU

L'idée derrière ce comparateur est de trouver des changements soutenus dans la latence.

Le comparateur de médiane prend un certain nombre de latences médianes passées. Il divise les latences en deux groupes (anciens et nouveaux) et trouve à nouveau la médiane pour chaque groupe. Si la différence entre les deux médianes est supérieure à une certaine valeur, il y aura une correspondance.

DESCRIPTION

Appelez le comparateur avec la séquence suivante :

type = matcher
pattern =  Median(old=>x,new=>y,diff=>z)

Cela créera un comparateur qui consomme x+y points de données de latence, construit les deux médianes et correspond si la différence entre la latence médiane est supérieure à z secondes.
