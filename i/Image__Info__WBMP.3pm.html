Image__Info__WBMP(3pm)

Image::Info::WBMP(3) Documentation Perl fournie par l'utilisateur Image::Info::WBMP(3)

NOM

Image::Info::WBMP - Prise en charge WBMP pour Image::Info

SYNTAXE

use Image::Info qw(dim);
use Image::Info::WBMP qw(wbmp_image_info);
my $info = wbmp_image_info("image.xpm");
if (my $error = $info->{error}) {
    die "Impossible d'analyser les informations de l'image : $error\n";
}
my($w, $h) = dim($info);

DESCRIPTION

wbmp est un format de fichier sans "magic number", donc l'utilisation de "image_info" ou "image_type" d'Image::Info ne fonctionne pas ici. Au lieu de cela, l'utilisateur doit déterminer le type de fichier lui-même, par exemple en se basant sur l'extension du fichier ou son type MIME, et utiliser la fonction "wbmp_image_info" à la place. La valeur retournée ressemble à celle de "image_info" d'Image::Info et peut être utilisée dans un appel à la fonction "dim".
