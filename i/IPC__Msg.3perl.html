IPC::Msg(3perl) Guide du programmeur Perl IPC::Msg(3perl)

NOM

IPC::Msg - Classe objet pour les messages IPC SysV

SYNOPSIS

use IPC::SysV qw(IPC_PRIVATE S_IRUSR S_IWUSR);
use IPC::Msg;
$msg = IPC::Msg->new(IPC_PRIVATE, S_IRUSR | S_IWUSR);
$msg->snd($msgtype, $msgdata);
$msg->rcv($buf, 256);
$ds = $msg->stat;
$msg->remove;

DESCRIPTION

Une classe fournissant une interface orientée objet aux files de messages IPC SysV.

MÉTHODES

new ( CLÉ , INDICATEURS )
Crée une nouvelle file de messages associée à "CLÉ". Une nouvelle file est créée si
  • "CLÉ" est égale à "IPC_PRIVATE"
  • "CLÉ" n'a pas déjà de file de messages associée, et "INDICATEURS & IPC_CREAT" est vrai.

Lors de la création d'une nouvelle file de messages, "INDICATEURS" est utilisé pour définir les permissions. Faites attention à ne pas définir d'indicateurs que l'implémentation IPC Sys V n'autorise pas : sur certains systèmes, définir les bits d'exécution peut entraîner un échec des opérations.

id
Retourne l'identifiant système de la file de messages.
rcv ( BUF, LONGUEUR [, TYPE [, INDICATEURS ]] )
Lit un message depuis la file. Retourne le type du message lu. Voir msgrcv(2). Le BUF devient contaminé (tainted).
remove
Supprime et détruit la file de messages du système.
set ( STAT )
set ( NOM => VALEUR [, NOM => VALEUR ...] )
"set" définira les valeurs suivantes de la structure "stat" associée à la file de messages. 
uid
gid
mode (uniquement les bits de permission)
qbytes

"set" accepte soit un objet stat, tel que retourné par la méthode "stat", soit une liste de paires nom-valeur.

snd ( TYPE, MSG [, INDICATEURS ] )
Place un message dans la file avec les données de "MSG" et avec le type "TYPE". Voir msgsnd(2).
stat
Retourne un objet de type "IPC::Msg::stat" qui est une sous-classe de "Class::Struct". Il fournit les champs suivants. Pour une description de ces champs, voir la documentation de votre système. 
uid
gid
cuid
cgid
mode
qnum
qbytes
lspid
lrpid
stime
rtime
ctime

VOIR AUSSI

IPC::SysV, Class::Struct
