NOM

IPC::Run3::ProfLogger - écrire des données de profilage dans un fichier journal

SYNTAXE

use IPC::Run3::ProfLogger;
my $logger = IPC::Run3::ProfLogger->new;  ## écrire dans "run3.out"
my $logger = IPC::Run3::ProfLogger->new( Destination => $fn );
$logger->app_call( \@cmd, $time );
$logger->run_exit( \@cmd1, @times1 );
$logger->run_exit( \@cmd1, @times1 );
$logger->app_exit( $time );

DESCRIPTION

Utilisé par IPC::Run3 pour écrire un fichier journal de profilage. Ne génère pas de rapports ni ne maintient de statistiques ; il est conçu pour avoir un overhead minimal.

Son API est compatible avec un sous-ensemble très restreint des autres classes de profilage de IPC::Run.

MÉTHODES

"IPC::Run3::ProfLogger->new( ... )"

"$logger->run_exit( ... )"

"$logger->app_exit( $arg )"

"$logger->app_call( $t, @args)"
