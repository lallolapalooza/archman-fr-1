Entiers sur 32

bits.

Ce module fournit des opérations sur le type int32 des entiers signés sur 32 bits. Contrairement au type intégré int, le type int32 est garanti d'avoir exactement 32 bits de large sur toutes les plateformes. Toutes les opérations arithmétiques sur int32 sont effectuées modulo

2^32.

Avis de performance : les valeurs de type int32 occupent plus d'espace mémoire que les valeurs de type int, et les opérations arithmétiques sur int32 sont généralement plus lentes que celles sur int. Utilisez int32 uniquement si l'application nécessite une arithmétique exacte sur 32

bits.

Les littéraux pour les entiers sur 32 bits sont suffixés par l

: 
      let zero: int32 = 0l
      let one: int32 = 1l
      let m_one: int32 =
-1l

val shift_left : int32 -> int ->

int32

Int32.shift_left x y décale x vers la gauche de y bits. Le résultat est indéfini si y < 0 ou y >=

32.

val shift_right : int32 -> int ->

int32

Int32.shift_right x y décale x vers la droite de y bits. Il s'agit d'un décalage arithmétique : le bit de signe de x est répliqué et inséré dans les bits libérés. Le résultat est indéfini si y < 0 ou y >=

32.

val shift_right_logical : int32 -> int ->

int32

Int32.shift_right_logical x y décale x vers la droite de y bits. Il s'agit d'un décalage logique : des zéros sont insérés dans les bits libérés quel que soit le signe de x. Le résultat est indéfini si y < 0 ou y >=

32.

val of_int : int ->

int32

Convertit l'entier donné (type int) en un entier sur 32 bits (type int32). Sur les plateformes 64 bits, l'argument est pris modulo

2^32.

val to_int : int32 ->

int

Convertit l'entier sur 32 bits donné (type int32) en un entier (type int). Sur les plateformes 32 bits, l'entier sur 32 bits est pris modulo 2^31, c'est-à-dire que le bit de poids fort est perdu lors de la conversion. Sur les plateformes 64 bits, la conversion est

exacte.

val of_float : float ->

int32

Convertit le nombre flottant donné en un entier sur 32 bits, en écartant la partie fractionnaire (troncature vers 0). Si le nombre flottant tronqué est en dehors de l'intervalle [ Int32.min_int, Int32.max_int], aucune exception n'est levée, et un entier indéfini, dépendant de la plateforme, est

renvoyé.

val to_float : int32 ->

float

flottant.

val of_string : string ->

int32

Convertit la chaîne donnée en un entier sur 32 bits. La chaîne est lue en décimal (par défaut, ou si la chaîne commence par 0u) ou en hexadécimal, octal ou binaire si la chaîne commence par 0x, 0o ou 0b respectiv

ement.

Le préfixe 0u lit l'entrée comme un entier non signé dans l'intervalle [0, 2*Int32.max_int+1]. Si l'entrée dépasse Int32.max_int, elle est convertie en l'entier signé Int32.min_int + input - Int32.max_int -

1.

Le caractère _ (tiret bas) peut apparaître n'importe où dans la chaîne et est

ignoré.

Lève Failure si la chaîne donnée n'est pas une représentation valide d'un entier, ou si l'entier représenté dépasse l'intervalle des entiers représentables dans le type int32

.

val of_string_opt : string -> int32

Identique à of_string, mais renvoie None au lieu de lever une
