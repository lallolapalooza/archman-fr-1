Image::Info::XPM(3) Documentation Perl fournie par l'utilisateur Image::Info::XPM(3)

NOM

Image::Info::XPM - Support XPM pour Image::Info

SYNTAXE

use Image::Info qw(image_info dim);
my $info = image_info("image.xpm");
if (my $error = $info->{error}) {
    die "Impossible de parser les informations de l'image : $error\n";
}
my $color = $info->{color_type};
my($w, $h) = dim($info);

DESCRIPTION

Ce module fournit les noms de clés standard à l'exception de Compression, Gamma, Interlace, LastModificationTime, ainsi que :

PaletteCouleur
Référence à un tableau de toutes les couleurs utilisées. Cette clé n'est présente que si "image_info" est appelée comme "image_info($file, PaletteCouleur>=1)".
TailleTableauCouleurs
Le nombre de couleurs utilisées par l'image.
PointActifX
La coordonnée x du point actif de l'image. Défini à -1 s'il n'y a pas de point actif.
PointActifY
La coordonnée y du point actif de l'image. Défini à -1 s'il n'y a pas de point actif.
Histogramme1DLuminance
Référence à un tableau représentant un histogramme de luminance unidimensionnel. Cette clé n'est présente que si "image_info" est appelée comme "image_info($file, Histogramme1DLuminance=>1)". La plage va de 0 à 255, mais l'auto-vivification est utilisée, donc un champ nul est également 0, et le tableau peut ne pas contenir réellement 255 champs.
XPM_CaracteresParPixel
Ceci est typiquement 1 ou 2. Voir Image::Xpm.
XPM_Extension-.*
Extensions XPM (la plus courante est XPMEXT) si présentes.

METHODES

process_file()

$info->process_file($source, $options);

Traite un fichier et définit les champs d'information trouvés dans l'objet $info.

FICHIERS

Ce module nécessite Image::Xpm

$Image::Info::XPM::RGBLIB est défini par défaut à /usr/X11R6/lib/X11/rgb.txt ou un chemin équivalent (voir la fonction "_get_rgb_txt" pour la liste complète), ceci est utilisé pour résoudre les noms de couleurs textuelles en leurs équivalents RVB.

VOIR AUSSI

Image::Info, Image::Xpm

NOTES

Pour plus d'informations sur XPM, voir <ftp://ftp.x.org/contrib/libraries/xpm-README.html>

AVERTISSEMENTS

Bien que le module tente d'être aussi robuste que possible, il se peut qu'il ne reconnaisse pas les XPM plus anciens (versions 1-3). Si c'est le cas, essayez d'insérer /* XPM */ comme première ligne.
