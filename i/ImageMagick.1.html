ImageMagick(1) Manuel des commandes générales ImageMagick(1)

NOM

ImageMagick - une suite logicielle libre pour la création, la modification et l'affichage d'images matricielles.

SYNOPIS

magick [options|fichier-entrée]... fichier-sortie magick-script fichier-script [arguments-script]...

APERÇU

Utilisez ImageMagick® pour créer, éditer, composer ou convertir des images matricielles. Il peut lire et écrire des images dans une variété de formats (plus de 200) y compris PNG, JPEG, GIF, HEIC, TIFF, DPX, EXR, WebP, Postscript, PDF et SVG. Utilisez ImageMagick pour redimensionner, retourner, miroiter, faire pivoter, déformer, ciseler et transformer des images, ajuster les couleurs des images, appliquer divers effets spéciaux, ou dessiner du texte, des lignes, des polygones, des ellipses et des courbes de Bézier.

La fonctionnalité d'ImageMagick est généralement utilisée depuis la ligne de commande. Elle peut également être accessible depuis des programmes écrits dans votre langage préféré en utilisant l'interface correspondante : G2F (Ada), MagickCore (C), MagickWand (C), ChMagick (Ch), ImageMagickObject (COM+), Magick++ (C++), JMagick (Java), JuliaIO (Julia), L-Magick (Lisp), Lua (LuaJIT), NMagick (Neko/haXe), Magick.NET (.NET), PascalMagick (Pascal), ALImageMagick (Delphi), PerlMagick (Perl), MagickWand pour PHP (PHP), IMagick (PHP), PythonMagick (Python), magick (R), RMagick (Ruby), ou TclMagick (Tcl/TK). Avec une interface linguistique, utilisez ImageMagick pour modifier ou créer des images dynamiquement et automatiquement.

ImageMagick utilise plusieurs threads de calcul pour augmenter les performances. Il peut lire, traiter ou écrire des tailles d'images de méga, giga ou téra pixels.

ImageMagick est un logiciel libre distribué sous forme de distribution binaire prête à l'emploi, ou sous forme de code source que vous pouvez utiliser, copier, modifier et distribuer dans des applications ouvertes et propriétaires. Il est distribué sous une licence Apache 2.0 dérivée.

Le processus de développement d'ImageMagick garantit une API et une ABI stables. Avant chaque version d'ImageMagick, nous effectuons une évaluation de sécurité complète qui comprend la détection d'erreurs de mémoire, la détection de courses de données de threads et un fuzzing continu pour aider à prévenir les vulnérabilités de sécurité.

La version actuelle est ImageMagick 7.0.8-11. Elle fonctionne sous Linux, Windows, macOS, iOS, Android OS et autres. Nous continuons à maintenir la version héritée d'ImageMagick, version 6, sur https://legacy.imagemagick.org.

Le site web faisant autorité d'ImageMagick est https://imagemagick.org. Le dépôt de code source faisant autorité est https://github.com/ImageMagick. Nous maintenons un miroir de code source sur https://gitlab.com/ImageMagick.

ImageMagick est une suite d'utilitaires en ligne de commande pour manipuler des images. Vous avez peut-être édité des images à un moment ou à un autre en utilisant des programmes comme GIMP ou Photoshop, qui exposent leur fonctionnalité principalement via une interface utilisateur graphique. Cependant, un programme GUI n'est pas toujours l'outil approprié. Supposons que vous souhaitiez traiter une image dynamiquement à partir d'un script web, ou que vous souhaitiez appliquer les mêmes opérations à de nombreuses images, ou répéter une opération spécifique à différents moments sur la même image ou sur une image différente. Pour ces types d'opérations, un utilitaire en ligne de commande est plus adapté.

Le reste de cette page de manuel est une liste des utilitaires en ligne de commande disponibles et de leurs descriptions courtes. Pour plus de documentation concernant une commande particulière et ses options, consultez la page de manuel correspondante. Si vous vous familiarisez tout juste avec ImageMagick, commencez par le haut de cette liste, le programme magick(1), et progressez. Assurez-vous également de consulter le tutoriel d'Anthony Thyssen sur la façon d'utiliser les utilitaires ImageMagick pour convertir, composer ou éditer des images depuis la ligne de commande.

magick
Lit des images en mémoire, effectue des opérations sur ces images et les écrit dans le même format de fichier image ou dans un autre. L'option "-script" peut être utilisée pour passer du traitement des options de ligne de commande à la lecture des options à partir d'un fichier ou d'un pipeline.
magick-script
Cette commande est similaire à magick(1) mais avec une option "-script" implicite. Elle est utile dans des scripts spéciaux "#!/usr/bin/env magick-script" qui recherchent la commande magick-script(1) n'importe où dans le PATH de l'utilisateur, plutôt que dans un emplacement de commande codé en dur.
convert
Disponible pour la compatibilité descendante avec la version 6 de ImageMagick convert(1). Essentiellement, ce n'est qu'un alias vers une forme restrictive de la commande magick(1), qui devrait être utilisée à la place.
mogrify
Redimensionne une image, floute, rogne, désencre, tramage, dessine, retourne, joint, ré-échantillonne, et bien plus encore. Cette commande écrase le fichier image original, tandis que convert(1) écrit dans un fichier image différent.
identify
Décrit le format et les caractéristiques d'un ou plusieurs fichiers image.
composite
Superpose une image sur une autre.
montage
Crée une image composite en combinant plusieurs images séparées. Les images sont disposées en mosaïque sur l'image composite, éventuellement ornées d'une bordure, d'un cadre, d'un nom d'image, et plus encore.
compare
Annote mathématiquement et visuellement la différence entre une image et sa reconstruction.
stream
Diffuse un ou plusieurs composants de pixels de l'image ou une partie de l'image dans le format de stockage de votre choix. Il écrit les composants de pixels tels qu'ils sont lus de l'image d'entrée, ligne par ligne, rendant stream(1) souhaitable lors du travail avec de grandes images, ou lorsque vous avez besoin de composants de pixels bruts.
display
Affiche une image ou une séquence d'images sur n'importe quel serveur X.
animate
Anime une séquence d'images sur n'importe quel serveur X.
import
Sauvegarde toute fenêtre visible sur n'importe quel serveur X et la sort sous forme de fichier image. Vous pouvez capturer une seule fenêtre, l'écran entier, ou toute portion rectangulaire de celui-ci.
conjure
Interprète et exécute des scripts écrits dans le langage de script Magick (MSL).

Pour plus d'informations sur ImageMagick, pointez votre navigateur vers file:///usr/share/doc/ImageMagick-7/index.html ou https://imagemagick.org/.
