NOM

IO::Pager::Perl - Paginer du texte écran par écran, comme more ou less

SYNOPSIS

use Term:ReadKey; #Optionnel, mais recommandé
use IO::Pager::Perl;
my $t = IO::Pager::Perl->new( rows => 25, cols => 80 );
$t->add_text( $text );
$t->more();

DESCRIPTION

C'est un module pour paginer du texte écran par écran. Il prend en charge les fonctionnalités attendues avec les raccourcis attendus.

IO::Pager::Perl est un fork amélioré de Term::Pager.

UTILISATION

Créer le Paginator

$t = IO::Pager::Perl->new( option => value, ... );

Si aucune option n'est spécifiée, des valeurs par défaut raisonnables seront utilisées. Les options suivantes sont reconnues, et indiquées avec la valeur par défaut :

rows =>25?
Le nombre de lignes sur votre terminal. Le terminal est interrogé directement avec Term::ReadKey si chargé, ou avec "stty" ou "tput". Si ces méthodes échouent, la valeur par défaut est 25.
cols =>80?
Le nombre de colonnes sur votre terminal. Le terminal est interrogé directement avec Term::ReadKey si chargé, ou avec "stty" ou "tput". Si ces méthodes échouent, la valeur par défaut est 80.
speed =>38400?
La vitesse (débit en bauds) de votre terminal. Le terminal est interrogé directement avec Term::ReadKey si chargé, ou avec "stty". Si ces méthodes échouent, la valeur par défaut est raisonnable.
eof =>0
Quitter à la fin du fichier.
fold =>1
Replier les lignes longues avec Text::Wrap.
lineNo =>0
Si vrai, la numérotation des lignes est ajoutée à la sortie.
pause =>0
Si défini, le paginator fera une pause lorsque cette séquence de caractères est rencontrée dans le texte d'entrée. Définir à ^L, c'est-à-dire "\cL", pour imiter le comportement traditionnel de "1" dans more.
raw =>0
Transmettre les caractères de contrôle de l'entrée sans altération au terminal. Par défaut, les caractères autres que la tabulation et le saut de ligne sont convertis en notation avec caret, par exemple ^@ pour le caractère nul ou ^L pour le saut de page.
scrollBar =>0
--scrollbar
Afficher une barre de défilement interactive dans la colonne la plus à droite.
squeeze =>0
Réduire les lignes vides multiples en une seule.
statusCol =>0
Ajouter une colonne avec des marqueurs indiquant quelle ligne correspond à une expression de recherche.
visualBell =>0
Faire clignoter l'écran lors de l'émission d'un bip.

Accesseurs

Il existe des accesseurs pour toutes les propriétés ci-dessus, cependant ceux pour rows, cols, speed, fold et squeeze sont en lecture seule.

# Est-ce que visualBell est défini?
$t->visualBell();
# Activer la numérotation des lignes
$t->lineNo(1);

Ajouter du texte

Vous aurez besoin de texte à paginer. Vous pouvez spécifier le texte en tant que paramètre du constructeur :

text => $text

Ou ajouter du texte plus tard :

$t->add_text( $text );

Si vous souhaitez ajouter du texte en continu au paginator, vous devez configurer votre propre boucle d'événements et indiquer à "more" qu'il doit abandonner le contrôle, par exemple :

eval{
    while( $t->more(RT=>.05) ){
      ...
      $t->add_text("Plus de texte à paginer");
    }
};

Le bloc eval capture l'exception levée lors de la terminaison du paginator afin que votre propre programme puisse continuer. Le paramètre RT indique que vous souhaitez fournir du contenu en temps réel. Cette valeur est également passée à "ReadKey" dans Term::ReadKey comme temps de blocage maximal par pression de touche et doit être comprise entre 0 et 1, les valeurs plus élevées échangeant une meilleure réactivité de l'interface contre de légers retards dans la sortie. Une valeur de -1 peut également être utilisée pour demander des sondages non bloquants, mais ne se comportera probablement pas comme vous l'espériez.

NOTE : Si Term::ReadKey n'est pas chargé mais que RT est vrai, les mises à jour de l'écran ne se produiront qu'à la pression d'une touche.

Callback

Vous pouvez également passer une référence de fonction à l'attribut text du constructeur, qui sera appelée à la fin du fichier ; par conséquent, il n'est pas possible de définir le drapeau eof pour quitter à la fin du fichier si vous le faites.

$t->new( text=>sub{ } ); #eof=>0 est implicite

Alternativement, vous pouvez fournir une référence à un tableau de deux éléments. Le premier est un fragment de texte initial à charger, et le second est le rappel.

# Fibonacci
my($m, $n)=(1,1);
$t->new( text=> ["1\n", sub{ ($m,$n)=($n,$m+$n); return "$n\n"} ] );

Interface utilisateur

Il existe plusieurs signets (marques) spéciaux qui peuvent être utilisés pour la navigation.

^ Début du fichier
$ Fin du fichier
' Emplacement précédent
" Lister les marques créées par l'utilisateur

"add_text" créera automatiquement des marques numériques spéciales lorsqu'il rencontrera une séquence de caractères spéciale, permettant à l'utilisateur de sauter vers des points prédéterminés dans le tampon. Les séquences qui correspondent à l'expression régulière suivante

/\cF\c]\cL\cE \[(\d+)\// # par ex. ^F^]^L^E [3/4]

auront des marques correspondantes à $1 créées qui pointeront vers la ligne du tampon où la séquence apparaît.

PERSONNALISATION

add_func

Il est possible d'étendre les fonctionnalités de IO::Pager::Perl en fournissant à la méthode "add_func" une table de hachage avec des touches de caractère et des valeurs de rappel à invoquer lors de la correspondance d'une pression de touche ; où \c? représente Control-? et \e? représente Alt-? Les mappages existants sont listés ci-dessous, et des descriptions plus longues sont disponibles dans tp.

&close - "q" ou "Q" ou ":q" ou ":Q"
&refresh - "r" ou "C-l" ou "C-R"
&flush_buffer - "R"
&write_buffer - ":w"
&open_file - ":e"

I18N

La "dialog" méthode peut être particulièrement utile lors de l'amélioration du visualiseur. Elle accepte une chaîne à afficher et un délai d'attente facultatif avant que la boîte de dialogue ne soit effacée. Si le délai est absent ou égal à 0, la boîte de dialogue reste affichée jusqu'à ce qu'une touche soit pressée.

my $t = IO::Pager::Perl->new();
$t->add_text("Texte à afficher");
$t->add_func('!'=>\&boo);
$t->more();
sub boo{ my $self = shift; $self->dialog("BOO !", 1); }

Si vous ajoutez des fonctionnalités à votre visualiseur, vous voudrez probablement modifier le contenu de la boîte de dialogue d'aide ou éventuellement la ligne d'état. Utilisez la "I18N" méthode pour remplacer le texte par défaut ou enregistrer du texte pour votre propre interface.

#Obtenir le texte d'aide par défaut
my $help = $t->I18N('help');
#Ligne d'état minimale
$t->I18N('minihelp', "<h> aide");

Les éléments de texte actuellement disponibles pour la personnalisation sont :

404        - boîte de dialogue « texte de recherche non trouvé »
continue   - texte à afficher en bas de la boîte de dialogue d'aide
help       - texte de la boîte de dialogue d'aide, une liste des touches et de leurs fonctions
minihelp   - instructions de base affichées en bas de l'écran
status     - bref message à inclure dans la ligne d'état
top        - invite de début de fichier
bottom     - invite de fin de fichier
searchwrap - message indiquant que le visualiseur est sur le point de faire défiler pour trouver d'autres correspondances

prompt est destiné à partager de courts messages ne justifiant pas une boîte de dialogue, par exemple lors du débogage. Vous devrez appeler la "status" méthode après l'avoir définie pour rafraîchir la ligne d'état de l'affichage, puis vider prompt et appeler "status" à nouveau pour effacer le message.

Évolutivité

Le texte d'aide sera divisé en deux horizontalement sur un caractère nul si le texte est plus large que l'affichage, et affiché dans deux boîtes de dialogue successives.

De même, le texte d'état sera tronqué à un caractère nul pour les affichages étroits.

AVERTISSEMENTS

UN*X

Ce module ne fonctionne actuellement que dans un environnement de type UN*X.

Performances

Par simplicité, l'implémentation actuelle charge entièrement le message à visualiser d'un seul coup ; il n'est donc pas nécessaire de distinguer les contenus pipés des fichiers. Cela peut nécessiter une mémoire importante pour les fichiers volumineux.

Termcap

Ce module utilise Termcap, qui a été déprécié par l'Open Group et pourrait ne plus être pris en charge par votre système d'exploitation très bientôt.

Si l'entrée termcap de votre terminal ancien et ésotérique est incorrecte ou incomplète, ce module peut soit remplir votre écran d'un gribouillis incompréhensible, soit revenir à un mode dépourvu de fonctionnalités.

À terme, la prise en charge de Terminfo pourrait également être ajoutée.

Signaux

IO::Pager::Perl définit un gestionnaire de signal global pour SIGWINCH, c'est le seul moyen pour lui de détecter efficacement et de s'adapter aux changements de taille du terminal. Si vous avez également besoin d'être notifié de ce signal, le gestionnaire déclenchera tout rappel assigné à l'attribut WINCH de la "new" méthode.

WINCH n'est pas disponible sur Windows. Vous devrez rafraîchir manuellement votre écran ^L si vous redimensionnez le terminal sous Windows pour nettoyer le texte ; cependant, cela ne changera pas la taille du visualiseur lui-même.

ENVIRONNEMENT

IO::Pager::Perl vérifie les variables TERM et TERMCAP .
