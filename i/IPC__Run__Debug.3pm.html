IPC::Run::Debug(3) Documentation Perl fournie par l'utilisateur IPC::Run::Debug(3)

NOM

IPC::Run::Debug - routines de débogage pour IPC::Run

SYNTAXE

##
## Utilisation des variables d'environnement
##
## Pour forcer la désactivation du débogage et économiser un peu de CPU et de mémoire
## en optimisant à la compilation toutes les instructions de débogage dans IPC::Run
## (les options debug => ...) à IPC::Run seront ignorées.
export IPCRUNDEBUG=none
## Pour forcer l'activation du débogage (niveaux de 0 à 10)
export IPCRUNDEBUG=basic
## Laisser non défini ou définir à "" pour inclure le support de débogage à la compilation et
## permettre le contrôle à l'exécution à l'aide de l'option debug.

DESCRIPTION

Contrôle le débogage de IPC::Run. Les niveaux de débogage sont maintenant définis à l'aide de mots, mais les nombres présentés sont toujours pris en charge pour des raisons de compatibilité descendante :

0  none         désactivé (spécial, voir ci-dessous)
1  basic        ce qui est exécuté
2  data         ce qui est envoyé/reçu
3  details      ce qui se passe plus en détail
4  gory         beaucoup trop de détails pour la plupart des utilisations
10 all          utilisez ceci lors de la soumission de rapports de bug
   noopts       optimisations interdites en raison de l'héritage de STDIN

Le niveau "none" est spécial lorsque la variable d'environnement IPCRUNDEBUG est définie à cette valeur lors du premier chargement de IPC::Run::Debug : elle empêche le code de débogage d'être compilé dans les modules IPC::Run restants, ce qui permet d'économiser un peu de CPU.

Pour ce faire dans un script, voici une méthode qui permet de la remplacer :

BEGIN {
   unless ( defined $ENV{IPCRUNDEBUG} ) {
      eval 'local $ENV{IPCRUNDEBUG} = "none"; require IPC::Run::Debug"'
         or die $@;
   }
}

Ceci devrait forcer IPC::Run à ne pas être débogable à moins que quelqu'un ne définisse le drapeau IPCRUNDEBUG ; modifiez cette formule pour rechercher dans @ARGV si nécessaire :

BEGIN {
   unless ( grep /^--debug/, @ARGV ) {
      eval 'local $ENV{IPCRUNDEBUG} = "none"; require IPC::Run::Debug"'
      or die $@;
}

Ces deux méthodes n'ont pas été testées.
