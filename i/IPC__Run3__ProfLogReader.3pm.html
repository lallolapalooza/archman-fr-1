NOM

IPC::Run3::ProfLogReader - lire et traiter un fichier ProfLogger

SYNOPIS

use IPC::Run3::ProfLogReader;
my $reader = IPC::Run3::ProfLogReader->new; ## utilise "run3.out"
my $reader = IPC::Run3::ProfLogReader->new( Source => $fn );
my $profiler = IPC::Run3::ProfPP;   ## Par exemple
my $reader   = IPC::Run3::ProfLogReader->new( ..., Handler => $p );
$reader->read;
$eaderr->read_all;

DESCRIPTION

Lit un fichier journal. Utilisez le nom de fichier "-" pour lire depuis STDIN.

MÉTHODES

"IPC::Run3::ProfLogReader->new( ... )"

"$reader->set_handler( $handler )"

"$reader->get_handler()"

"$reader->read()"

"$reader->read_all()"

Cette méthode lit jusqu'à ce qu'il n'y ait plus rien à lire, puis renvoie vrai.
