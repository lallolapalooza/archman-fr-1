NOM

Image::ExifTool::MIEUnits - Documentation des unités MIE

DESCRIPTION

Le format MIE permet de spécifier les unités de mesure entre crochets à la fin d'un nom de balise MIE (par ex. « Volume(m3) »). Ce document décrit les abréviations standard des unités MIE.

SYNTAXE

La chaîne d'unités peut contenir n'importe quels caractères ASCII dans la plage 0x21 ('!') à 0x7d ('}'), à l'exception des caractères de crochets (0x28 et 0x29). Une chaîne vide est autorisée et indique une valeur sans dimension. Les unités standard doivent être utilisées si possible. Dans les unités standard, un souligné ('_') est utilisé pour indiquer un indice, et plusieurs mots peuvent être séparés par un tiret ('-').

Les exposants doivent être positifs et ne nécessitent aucun séparateur (par ex. « m2 » pour les mètres carrés). Des préfixes peuvent être ajoutés aux unités standard (par ex. « cm »), sauf lorsque le nom résultant entre en conflit avec une autre unité standard.

La multiplication est indiquée par '.', et la division par '/'. Les unités réciproques (c'est-à-dire l'inverse multiplicatif) s'obtiennent par division plutôt que par l'utilisation d'exposants négatifs (par ex. « /in », et non « in-1 »). Dans les unités MIE, la multiplication a la priorité sur la division, de sorte que tout ce qui se trouve à droite d'un '/' est au dénominateur. (Voir « EXEMPLES » pour quelques exemples.)

Voici un tableau résumant les caractères spéciaux utilisés dans les chaînes d'unités MIE.

.           multiplication
/           division (utilisée pour les exposants négatifs)
-           séparateur de mots
_           indice
{}          annotation
[]          utilisé pour éviter les conflits de noms si nécessaire
0-9         exponentiation
