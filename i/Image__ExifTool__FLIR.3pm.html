NOM

Image::ExifTool::FLIR - Lire les méta informations FLIR

SYNOPSIS

Ce module est chargé automatiquement par Image::ExifTool lorsque nécessaire.

DESCRIPTION

Ce module contient les définitions pour lire les méta informations des fichiers d'images thermiques de FLIR Systems Inc. (format FFF, FPF et JPEG).
