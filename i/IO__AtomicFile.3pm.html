NOM

IO::AtomicFile - écrire un fichier qui est mis à jour de manière atomique

SYNOPSIS

use strict;
use warnings;
use feature 'say';
use IO::AtomicFile;
# Écrire un fichier temporaire, et l'installer lors de sa fermeture :
my $fh = IO::AtomicFile->open("bar.dat", "w");
$fh->say("Salut !");
$fh->close || die "impossible d'installer le fichier atomique : $!";
# Écrire un fichier temporaire, mais le supprimer avant son installation :
my $fh = IO::AtomicFile->open("bar.dat", "w");
$fh->say("Salut !");
$fh->delete;
# Écrire un fichier temporaire, mais ni l'installer ni le supprimer :
my $fh = IO::AtomicFile->open("bar.dat", "w");
$fh->say("Salut !");
$fh->detach;

DESCRIPTION

Ce module est destiné aux personnes qui ont besoin de mettre à jour des fichiers de manière fiable face à des arrêts de programme inattendus.

Par exemple, vous ne voudrez généralement pas être à mi-chemin dans l'écriture de /etc/passwd et avoir votre programme qui se termine ! Même l'acte d'écrire un seul scalaire dans un handle de fichier n'est *pas* atomique.

Mais ce module vous offre de vraies mises à jour atomiques, via "rename". Lorsque vous ouvrez un fichier /foo/bar.dat via ce module, vous ouvrez en *réalité* un fichier temporaire /foo/bar.dat..TMP, et y écrivez votre sortie. L'acte de fermer ce fichier (soit explicitement via "close", soit implicitement via la destruction de l'objet) provoquera l'appel de "rename"... par conséquent, du point de vue du monde extérieur, le contenu du fichier est mis à jour en un seul quantum de temps.

Pour garantir que les problèmes ne passent pas inaperçus, la méthode "close" appelée par le destructeur lèvera une exception fatale si le "rename" échoue. Le "close" explicite retourne juste "undef".

Vous pouvez également décider à tout moment de supprimer le fichier que vous avez construit.

MÉTHODES

IO::AtomicFile hérite de toutes les méthodes de IO::File et implémente les nouvelles méthodes suivantes.

close

$fh->close();

Cette méthode appelle sa méthode parente "close" dans IO::File puis renomme son fichier temporaire en nom de fichier original.

delete

$fh->delete();

Cette méthode appelle sa méthode parente "close" dans IO::File puis supprime le fichier temporaire.

detach

$fh->detach();

Cette méthode appelle sa méthode parente "close" dans IO::File. Contrairement à "delete" dans IO::AtomicFile, elle ne supprime pas ensuite le fichier temporaire.
