Image::Info::SVG(3) Documentation Perl fournie par l'utilisateur Image::Info::SVG(3)

NOM

Image::Info::SVG - Support SVG pour Image::Info

SYNTAXE

use Image::Info qw(image_info dim);
my $info = image_info("image.svg");
if (my $error = $info->{error}) {
    die "Impossible d'analyser les informations de l'image : $error\n";
}
my $title = $info->{SVG_Title};
my($w, $h) = dim($info);

DESCRIPTION

Ce module fournit les noms de clés standards sauf BitsPerSample, Compression, Gamma, Interlace, LastModificationTime, ainsi que :

ImageDescription
La description de l'image, correspond à <desc>.
SVG_Image
Un scalaire ou une référence à un tableau de scalaires contenant les URI d'images intégrées (JPG ou PNG) dans l'image.
SVG_StandAlone
Si l'image est autonome ou non.
SVG_Title
Le titre de l'image, correspond à <title>
SVG_Version
L'URI de la DTD à laquelle l'image est conforme.

MÉTHODES

process_file()

$info->process_file($source, $options);

Traite un fichier et définit les champs d'information trouvés dans l'objet $info.

FICHIERS

Ce module nécessite soit XML::LibXML::Reader, soit XML::Simple.

COMPATIBILITÉ

Les versions précédentes (jusqu'à Image-Info-1.28) utilisaient XML::Simple comme analyseur sous-jacent. Depuis Image-Info-1.29, l'analyseur par défaut est XML::LibXML::Reader, qui est beaucoup plus rapide, plus efficace en mémoire et ne repose pas sur des expressions régulières pour certains aspects de l'analyse XML. Si, pour une raison quelconque, vous avez besoin de l'ancien analyseur, vous pouvez le forcer en définissant la variable @Image::Info::SVG::PREFER_MODULE le plus tôt possible :

use Image::Info;
@Image::Info::SVG::PREFER_MODULE = qw(Image::Info::SVG::XMLSimple Image::Info::SVG::XMLLibXMLReader);

La variable $Image::Info::SVG::USING_MODULE peut être interrogée pour voir quel analyseur est utilisé (après que Image::Info::SVG ait été requis).

Depuis la version 1.38_50, le traitement des entités XML externes (XXE) n'est plus effectué pour des raisons de sécurité dans les deux backends (Image::Info::SVG::XMLLibXMLReader et Image::Info::SVG::XMLSimple). Le contrôle du comportement de traitement des XXE dans XML::Simple n'est pas vraiment possible (voir https://rt.cpan.org/Ticket/Display.html?id=83794), donc comme solution de contournement, l'analyseur SAX sous-jacent est fixé à XML::SAX::PurePerl qui est incapable de traiter les entités externes - mais c'est malheureusement aussi un analyseur lent.

VOIR AUSSI

Image::Info, XML::LibXML::Reader, XML::Simple, XML::SAX::PurePerl

NOTES

Pour plus d'informations sur SVG, voir http://www.w3.org/Graphics/SVG/
