Cette option peut être utilisée lorsqu'il y a des informations utiles immédiatement après le flux de données compressées, et que vous ne connaissez pas la longueur du flux de données

compressées.

Si l'entrée est un buffer, "trailingData" retournera tout depuis la fin du flux de données compressées jusqu'à la fin du

buffer.

Si l'entrée est une poignée de fichier, "trailingData" retournera les données qui restent dans le buffer d'entrée de la poignée de fichier une fois la fin du flux de données compressées atteinte. Vous pouvez ensuite utiliser la poignée de fichier pour lire le reste du fichier

d'entrée.

Ne vous embêtez pas à utiliser "trailingData" si l'entrée est un nom de

fichier.

Si vous connaissez la longueur du flux de données compressées avant de commencer la décompression, vous pouvez éviter d'avoir à utiliser "trailingData" en définissant l'option "InputLength" d

ans le
constr
ucteur.
