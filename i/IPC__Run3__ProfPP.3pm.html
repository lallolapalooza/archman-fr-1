NOM

IPC::Run3::ProfPP - Génère des rapports à partir des données de profilage d'IPC::Run3

SYNTAXE

DESCRIPTION

Utilisé par IPC::Run3 et/ou run3profpp pour imprimer des rapports de profilage pour les lecteurs humains. Utilisez d'autres classes pour extraire les données d'une autre manière.

Les méthodes de sortie sont en texte brut, remplacez-les (consultez la source pour l'instant) pour fournir d'autres formats.

Cette classe génère des rapports sur chaque appel à run3_exit() et app_exit().

MÉTHODES

"IPC::Run3::ProfPP->new()"

Retourne un nouvel objet de rapport de profil.

"$profpp->handle_app_call()"

"$profpp->handle_app_exit()"

"$profpp->handle_run_exit()"
