NOM

IPC::Run::Win32IO - routines d'aide pour IPC::Run sur les plateformes Win32.

SYNTAXE

use IPC::Run::Win32IO;   # Exporte tout par défaut

DESCRIPTION

IPC::Run doit utiliser des sockets pour rediriger l'E/S des sous-processus afin que la boucle select() fonctionne sous Win32. Cela ne semble fonctionner que sous WinNT et Win2K pour le moment, je ne sais pas si cela fonctionnera jamais sous Win95 ou Win98. Si vous avez de l'expérience dans ce domaine, veuillez me contacter à barries@slaysys.com, merci !.

DESCRIPTION

Une classe IO spécialisée utilisée sous Win32.

SOUS-ROUTINES

poll
Version Windows de IPC::Run::IP::poll.
