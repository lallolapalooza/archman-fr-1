NOM

Image::Info::PPM - Support PPM pour Image::Info

SYNOPIS

use Image::Info qw(image_info dim);
my $info = image_info("image.ppm");
if (my $error = $info->{error}) {
    die "Impossible d'analyser les informations de l'image : $error\n";
}
my($w, $h) = dim($info);

DESCRIPTION

Ce module ajoute le support PPM à Image::Info.

Il est chargé et utilisé automatiquement.

MÉTHODES

process_file()

$info->process_file($source, $options);

Traite un fichier et définit les champs d'informations trouvés dans l'objet $info.
