NOM

Image::ExifTool::PDF - Lire les métadonnées PDF

SYNTAXE

Ce module est chargé automatiquement par Image::ExifTool lorsque nécessaire.

DESCRIPTION

Ce code lit les métadonnées des fichiers PDF (Adobe Portable Document Format). Il prend en charge les flux d'objets introduits dans PDF-1.5 mais seulement avec un ensemble limité d'algorithmes Filter et Predictor, cependant toutes les méthodes de chiffrement standard jusqu'à PDF-2.0 sont prises en charge, y compris AESV2 (AES-128) et AESV3 (AES-256).
