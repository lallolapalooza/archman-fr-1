NOM

Image::ExifTool::MXF - Lire les métadonnées MXF

SYNTAXE

Ce module est utilisé par Image::ExifTool

DESCRIPTION

Ce module contient les définitions requises par Image::ExifTool pour lire les métadonnées des fichiers MXF (Material Exchange Format).
