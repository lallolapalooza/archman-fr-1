NOM

I18N::Collate - comparer des données scalaires 8 bits selon la locale actuelle

SYNTAXE

use I18N::Collate;
setlocale(LC_COLLATE, 'locale-de-votre-choix');
$s1 = I18N::Collate->new("donnees_scalaires_1");
$s2 = I18N::Collate->new("donnees_scalaires_2");

DESCRIPTION

***
ATTENTION : à partir de la version 5.003_06 de Perl,
l'interface I18N::Collate pour comparer des données scalaires 8 bits
selon la locale actuelle
      A ÉTÉ DÉPRÉCIÉE
C'est-à-dire, veuillez ne plus l'utiliser pour de nouvelles applications
et veuillez migrer les anciennes applications car sa
fonctionnalité a été intégrée dans le langage Perl de base dans la
version 5.003_06.
Voir la page de manuel perllocale pour plus d'informations.
***

Ce module vous fournit des objets qui trieront selon votre jeu de caractères national, à condition que la fonction setlocale() POSIX soit supportée sur votre système.

Vous pouvez comparer $s1 et $s2 ci-dessus avec

$s1 le $s2

pour extraire les données elles-mêmes, vous aurez besoin d'un déréférencement : $$s1

Ce module utilise POSIX::setlocale(). La conversion de base du tri est effectuée par strxfrm() qui se termine aux caractères NUL, étant une routine C décente. collate_xfrm() gère les caractères NUL intégrés avec élégance.

Les locales disponibles dépendent de votre système d'exploitation ; essayez si "locale -a" les affiche ou les pages de manuel pour "locale" ou "nlsinfo" ou l'approche directe "ls /usr/lib/nls/loc" ou "ls /usr/lib/nls" ou "ls /usr/lib/locale". Toutes les locales que votre fournisseur supporte ne sont pas nécessairement installées : veuillez consulter la documentation de votre système d'exploitation et éventuellement l'administration de votre système local. Les noms des locales sont probablement quelque chose comme "xx_XX.(ISO)?8859-N" ou "xx_XX.(ISO)?8859N", par exemple "fr_CH.ISO8859-1" est la variante Suisse (CH) du Français (fr), Latin ISO (8859) 1 (-1) qui est le jeu de caractères de l'Europe de l'Ouest.
