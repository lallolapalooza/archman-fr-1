IO::Pipe(3perl) Guide du programmeur Perl IO::Pipe(3perl)

NOM

IO::Pipe - fournit des méthodes d'objet pour les tubes (pipes)

SYNOPIS

use IO::Pipe;
$pipe = IO::Pipe->new();
if($pid = fork()) { # Parent
    $pipe->reader();
    while(<$pipe>) {
        ...
    }
}
elsif(defined $pid) { # Enfant
    $pipe->writer();
    print $pipe ...
}
ou
$pipe = IO::Pipe->new();
$pipe->reader(qw(ls -l));
while(<$pipe>) {
    ...
}

DESCRIPTION

"IO::Pipe" fournit une interface pour créer des tubes (pipes) entre processus.

CONSTRUCTEUR

new ( [LECTEUR, ÉCRIVEUR] )
Crée un "IO::Pipe", qui est une référence à un symbole nouvellement créé (voir le package Symbol). "IO::Pipe::new" prend éventuellement deux arguments, qui doivent être des objets bénis dans "IO::Handle", ou une de ses sous-classes. Ces deux objets seront utilisés pour l'appel système "pipe". Si aucun argument n'est donné, la méthode "handles" est appelée sur le nouvel objet "IO::Pipe".

Ces deux descripteurs sont conservés dans la partie tableau du GLOB jusqu'à ce que "reader" ou "writer" soit appelé.

MÉTHODES

reader ([ARGS])
L'objet est re-béni dans une sous-classe de "IO::Handle", et devient un descripteur à l'extrémité de lecture du tube. Si des "ARGS" sont donnés, alors "fork" est appelé et les "ARGS" sont passés à exec.
writer ([ARGS])
L'objet est re-béni dans une sous-classe de "IO::Handle", et devient un descripteur à l'extrémité d'écriture du tube. Si des "ARGS" sont donnés, alors "fork" est appelé et les "ARGS" sont passés à exec.
handles ()
Cette méthode est appelée lors de la construction par "IO::Pipe::new" sur le nouvel objet "IO::Pipe" créé. Elle retourne un tableau de deux objets bénis dans "IO::Pipe::End", ou une sous-classe de celle-ci.

VOIR AUSSI

IO::Handle
