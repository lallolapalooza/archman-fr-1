Magick(3) Documentation Perl fournie par l'utilisateur Magick(3)

NOM

Image::Magick - interface Perl orientée objet pour ImageMagick pour le quantique par défaut (Q16HDRI). Utilisez-la pour lire, manipuler ou écrire une image ou une séquence d'images depuis un script Perl.

SYNOPIS

use Image::Magick;
$p = new Image::Magick;
$p->Read("imagefile");
$p->Set(attribut => valeur, ...)
($a, ...) = $p->Get("attribut", ...)
$p->routine(parametre => valeur, ...)
$p->Mogrify("Routine", parametre => valeur, ...)
$p->Write("nomdefichier");

DESCRIPTION

Cette extension Perl permet la lecture, la manipulation et l'écriture d'un grand nombre de formats de fichiers image en utilisant la bibliothèque ImageMagick. Elle a été initialement développée pour être utilisée par les scripts CGI pour les pages Web.

Une page Web a été créée pour cette extension. Voir :

file:///usr/share/doc/ImageMagick-7/www/perl-magick.html
https://imagemagick.org/script/perl-magick.php

Si vous rencontrez des problèmes, allez sur

https://imagemagick.org/discourse-server/viewforum.php?f=7
