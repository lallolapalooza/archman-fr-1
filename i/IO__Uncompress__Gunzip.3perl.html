N

Ce module fournit une interface Perl permettant la lecture de fichiers/buffers conformes à la RFC

1952.

Pour écrire des fichiers/buffe

rs RFC 1952, voir le module com
pagnon IO::Compress::Gzip.

Interface

fonctionnelle

Une fonction de haut niveau, "gunzip", est fournie pour effectuer une décompression « en une passe » entre des buffers et/ou des fichiers. Pour un contrôle plus fin du processus de décompression, voir la section « Interface OO »

. 
use IO::Uncompress::Gunzip qw(gunzip $GunzipError) ;
gunzip $input_filename_or_reference => $output_filename_or_reference [,OPTS]
    or die "gunzip failed: $GunzipError\n"
;

L'interface fonctionnelle nécessite Perl 5.005 ou

supérieur.

gunzip $input_filename_or_reference => $output_filename_or_reference [,

OPTS]

"gunzip" attend au moins deux paramètres, $input_filename_or_reference et $output_filename_or_reference, ainsi que zéro ou plusieurs paramètres optionnels (voir « Paramètres optionnels »

Le $input_filename_or_reference paramètr

Retourne les données, s'il y en a, qui sont présentes immédiatement après le flux de données compressées une fois la décompression terminée. Il n'a de sens d'appeler cette méthode qu'une fois la fin du flux de données compressées

Cette option peut être utilisée lorsqu'il y a des informations utiles immédiatement après le flux de données compressées, et que vous ne connaissez pas la longueur du flux de données

compressées.

Si l'entrée est un buffer, "trailingData" retournera tout depuis la fin du flux de données compressées à la fin du

tampon.

Si l'entrée est un filehandle, "trailingData" renverra les données qui restent dans le tampon d'entrée du filehandle une fois la fin du flux de données compressées atteinte. Vous pouvez alors utiliser le filehandle pour lire le reste du fichier

d'entrée.

fichier.
