NOM

IO::Uncompress::Base - Classe de base pour les modules IO::Uncompress

SYNTAXE

use IO::Uncompress::Base ;

DESCRIPTION

Ce module n'est pas destiné à être utilisé directement dans le code applicatif. Son seul but est d'être hérité par les modules IO::Uncompress.

SUPPORT

Les commentaires généraux/questions/rapports de bugs doivent être envoyés à https://github.com/pmqs/IO-Compress/issues (préféré) ou https://rt.cpan.org/Public/Dist/Display.html?Name=IO-Compress.
