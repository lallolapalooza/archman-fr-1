DESCRIPTION

Ce module fournit une interface Perl qui permet la lecture de fichiers/buffers conformes à la RFC 1950.

Pour écrire des fichiers/buffers conformes à la RFC 1950, voir le module compagnon IO::Compress::Deflate.

Interface Fonctionnelle

Une fonction de haut niveau, "inflate", est fournie pour effectuer la décompression « en une seule fois » entre buffers et/ou fichiers. Pour un contrôle plus fin du processus de décompression, voir la section "Interface OO".

use IO::Uncompress::Inflate qw(inflate $InflateError) ;
inflate $input_filename_or_reference => $output_filename_or_reference [,OPTS]
    or die "l'inflation a échoué: $InflateError\n";

L'interface fonctionnelle nécessite Perl5.005 ou une version ultérieure.

inflate $input_filename_or_reference => $output_filename_or_reference [, OPTIONS]

"inflate" attend au moins deux paramètres, $input_filename_or_reference et $output_filename_or_reference, ainsi que zéro ou plusieurs paramètres optionnels (voir "Paramètres Optionnels")

Le paramètre $input_filename_or_reference

Le paramètre $input_filename_or_reference, est utilisé pour définir la source des données compressées.

Il peut prendre l'une des formes suivantes :

Un nom de fichier
Si le paramètre $input_filename_or_reference est un scalaire simple, il est supposé être un nom de fichier. Ce fichier sera ouvert en lecture et les données d'entrée en seront lues.
Un descripteur de fichier
Si le paramètre $input_filename_or_reference est un descripteur de fichier, les données d'entrée en seront lues. La chaîne '-' peut être utilisée comme alias pour l'entrée standard.
Une référence scalaire
Si $input_filename_or_reference est une référence scalaire, les données d'entrée seront lues depuis $$input_filename_or_reference.
Une référence de tableau
Si $input_filename_or_reference est une référence de tableau, chaque élément du tableau doit être un nom de fichier.

Les données d'entrée seront lues de chaque fichier successivement.

Le tableau complet sera parcouru pour s'assurer qu'il ne contient que des noms de fichiers valides avant que toute donnée ne soit décompressée.

Une chaîne de caractères FileGlob d'entrée
Si $input_filename_or_reference est une chaîne délimitée par les caractères '<' et '>', "inflate" supposera qu'il s'agit d'une *chaîne de caractères FileGlob d'entrée*. L'entrée est la liste des fichiers correspondant au fileglob.

Voir File::GlobMapper pour plus de détails.

Si le paramètre $input_filename_or_reference est d'un autre type, "undef" sera retourné.

Le paramètre $output_filename_or_reference

Le paramètre $output_filename_or_reference est utilisé pour contrôler la destination des données décompressées. Ce paramètre peut prendre l'une de ces formes.

Un nom de fichier
Si le paramètre $output_filename_or_reference est un scalaire simple, il est supposé être un nom de fichier. Ce fichier sera ouvert en écriture et les données décompressées y seront écrites.
Un descripteur de fichier
Si le paramètre $output_filename_or_reference est un descripteur de fichier, les données décompressées y seront écrites. La chaîne '-' peut être utilisée comme alias pour la sortie standard.
Une référence scalaire
Si $output_filename_or_reference est une référence scalaire, les données décompressées seront stockées dans $$output_filename_or_reference.
Une référence de tableau
Si $output_filename_or_reference est une référence de tableau, les données décompressées seront ajoutées au tableau.
Un FileGlob de sortie
Si $output_filename_or_reference est une chaîne délimitée par les caractères '<' et '>', "inflate" supposera qu'il s'agit d'une *chaîne de caractères FileGlob de sortie*. La sortie est la liste des fichiers correspondant au fileglob.

Lorsque $output_filename_or_reference est une chaîne fileglob, $input_filename_or_reference doit également être une chaîne fileglob. Tout autre cas est une erreur.

Voir File::GlobMapper pour plus de détails.

Si le paramètre $output_filename_or_reference est d'un autre type, "undef" sera retourné.

Notes

Lorsque $input_filename_or_reference correspond à plusieurs fichiers/buffers compressés et $output_filename_or_reference est un fichier/buffer unique, après décompression, $output_filename_or_reference contiendra une concaténation de toutes les données décompressées de chacun des fichiers/buffers d'entrée.

Paramètres Optionnels

Les paramètres optionnels pour la fonction « une seule fois » "inflate" sont (pour la plupart) identiques à ceux utilisés avec l'interface OO définie dans la section "Options du Constructeur". Les exceptions sont listées ci-dessous.

"AutoClose => 0|1"
Cette option s'applique à tous les flux de données d'entrée ou de sortie de "inflate" qui sont des descripteurs de fichier.

Si "AutoClose" est spécifié, et que sa valeur est vraie, cela entraînera la fermeture de tous les descripteurs de fichiers d'entrée et/ou de sortie une fois que "inflate" aura terminé.

Ce paramètre est défini par défaut à 0.

"BinModeOut => 0|1"
Cette option est maintenant une opération nulle. Tous les fichiers seront écrits en mode binaire.
"Append => 0|1"
Le comportement de cette option dépend du type de flux de données de sortie.
  • Un Buffer

    Si "Append" est activé, toutes les données décompressées seront ajoutées à la fin du buffer de sortie. Sinon, le buffer de sortie sera vidé avant que toute donnée décompressée n'y soit écrite.

  • Un Nom de fichier

    Si "Append" est activé, le fichier sera ouvert en mode ajout. Sinon, le contenu du fichier, s'il y en a, sera tronqué avant que toute donnée décompressée n'y soit écrite.
