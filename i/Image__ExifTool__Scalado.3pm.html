NOM

Image::ExifTool::Scalado - Lire les métadonnées APP4 SCALADO

SYNTAXE

Ce module est chargé automatiquement par Image::ExifTool si nécessaire.

DESCRIPTION

Ce module contient les définitions requises par Image::ExifTool pour lire les métadonnées du segment JPEG APP4 SCALADO.
