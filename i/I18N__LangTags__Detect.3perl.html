I18N::LangTags::Detect(3perl) Guide de référence des programmeurs Perl I18N::LangTags::Detect(3perl)

NOM

I18N::LangTags::Detect - détecter les préférences linguistiques de l'utilisateur

SYNTAXE

use I18N::LangTags::Detect;
my @user_wants = I18N::LangTags::Detect::detect();

DESCRIPTION

C'est un problème courant de vouloir détecter dans quelle(s) langue(s) l'utilisateur préférerait voir la sortie.

FONCTIONS

Ce module définit une fonction publique, I18N::LangTags::Detect::detect(). Cette fonction n'est pas exportée (ni exportable), et elle ne prend aucun paramètre.

En contexte scalaire, la fonction renvoie la balise de langue la plus préférée (ou undef si aucune préférence n'a été détectée).

En contexte de liste (ce qui est généralement ce que vous voulez), la fonction renvoie une liste (éventuellement vide) de balises de langue représentant (la meilleure d'abord) les langues dans lesquelles l'utilisateur accepterait apparemment la sortie. Vous voudrez probablement passer la sortie de ceci à travers I18N::LangTags::implicate_supers_tightly(...) ou I18N::LangTags::implicate_supers(...), comme suit :

my @languages =
  I18N::LangTags::implicate_supers_tightly(
    I18N::LangTags::Detect::detect()
  );

ENVIRONNEMENT

Ce module examine plusieurs variables d'environnement : REQUEST_METHOD, HTTP_ACCEPT_LANGUAGE, LANGUAGE, LC_ALL, LC_MESSAGES, et LANG.

Il utilisera également le module Win32::Locale, s'il est installé et que IGNORE_WIN32_LOCALE n'est pas défini à une valeur vraie dans l'environnement.

VOIR AUSSI

I18N::LangTags, Win32::Locale, Locale::Maketext.

(Le code de base de ce module a commencé comme une routine dans Locale::Maketext ; mais je l'ai déplacé ici une fois que j'ai réalisé qu'il était plus généralement utile.)
