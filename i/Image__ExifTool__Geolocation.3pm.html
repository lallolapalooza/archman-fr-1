NOM

Image::ExifTool::Geolocation - Détermine la géolocalisation à partir des données GPS et vice-versa

SYNOPSIS

Recherche des informations de géolocalisation (ville, région, sous-région, pays, etc.) basées sur des coordonnées GPS d'entrée, ou détermine des coordonnées GPS basées sur un nom de ville, etc.

DESCRIPTION

Ce module contient le code pour convertir les coordonnées GPS en ville, région, sous-région, pays, fuseau horaire, etc. Il utilise une base de données dérivée de geonames.org, modifiée pour réduire sa taille autant que possible.

MÉTHODES

ReadDatabase

Charge la base de données de géolocalisation à partir d'un fichier. Cette méthode est appelée automatiquement lors du chargement de ce module. Par défaut, la base de données est chargée à partir de "Geolocation.dat" dans le même répertoire que ce module, mais un répertoire différent peut être utilisé en définissant $Image::ExifTool::Geolocation::geoDir avant de charger ce module. Le réglage à une chaîne vide évite de charger une base de données. Un avertissement est généré si le fichier ne peut pas être lu.

Image::ExifTool::Geolocation::ReadDatabase($nom_fichier);
Entrées :
0) Nom du fichier de la base de données
Valeur de Retour :
Vrai en cas de succès.

ReadAltNames

Charge la base de données des noms alternatifs. Avant d'appeler cette méthode, la variable de package $altDir peut être définie, sinon AltNames.dat est chargé à partir du même répertoire que Geolocation.dat. Cette méthode est appelée automatiquement par "Geolocate" si l'option GeolocAltNames est utilisée et qu'un nom de ville d'entrée est fourni.

Image::ExifTool::Geolocation::ReadAltNames();
Entrées :
(aucune)
Valeur de Retour :
Vrai en cas de succès. Peut être appelée à plusieurs reprises, mais AltNames.dat n'est chargé qu'au premier appel.

SortDatabase

Trie la base de données dans l'ordre spécifié.

Image::ExifTool::Geolocation::SortDatabase('Ville');
Entrées :
0) Ordre de tri : 'Latitude', 'Ville' ou 'Pays'
Valeur de Retour :
1 en cas de succès, 0 en cas d'échec (ordre de tri spécifié incorrect).

AddEntry

Ajoute une entrée à la base de données de géolocalisation.

Image::ExifTool::Geolocation::AddEntry($ville, $region,
    $sous_region, $code_pays, $pays, $fuseau_horaire,
    $code_caracteristique, $population, $lat, $lon, $noms_alternatifs);
Entrées :
0) Nom de la ville (UTF8)

1) Nom de la région, de l'état ou de la province (UTF8), ou chaîne vide si inconnu

2) Nom de la sous-région (UTF8), ou chaîne vide si inconnu

3) Code pays ISO 3166 à 2 caractères

4) Nom du pays (UTF8), ou chaîne vide pour utiliser la définition existante. Si le nom du pays est fourni pour un code pays déjà présent dans la base de données, alors l'entrée de la base de données est mise à jour avec le nouveau nom du pays.

5) Identifiant du fuseau horaire (par ex. "America/New_York")

6) Code de caractéristique (par ex. "PPL"), ou chaîne vide si inconnu

7) Population de la ville

8) Latitude GPS (degrés flottants signés)

9) Longitude GPS

10) Liste facultative de noms alternatifs pour la ville, séparés par des virgules

Valeur de Retour :
1 en cas de succès, sinon envoie un message d'avertissement à stderr

GetEntry

Obtient une entrée de la base de données de géolocalisation.

my @vals = Image::ExifTool::Geolocation::GetEntry($num,$lang,$sort);
Entrées :
0) Numéro de l'entrée dans la base de données, ou index dans la base de données triée

1) Code de langue facultatif

2) Indicateur facultatif pour traiter le premier argument comme un index dans la base de données triée

Valeurs de Retour des éléments :

0) Nom de la ville, ou undef si l'entrée n'existait pas

1) Nom de la région, ou "" s'il n'y a pas de région

2) Nom de la sous-région, ou "" s'il n'y a pas de sous-région

3) Code pays

4) Nom du pays

5) Fuseau horaire

6) Code de caractéristique

7) Population de la ville

8) Latitude GPS

9) Longitude GPS

10) Type de caractéristique, ou undef

GetAltNames

Obtient les noms alternatifs pour une ville spécifiée.

my $str = Image::ExifTool::Geolocation::GetAltNames($num,$sort);
Entrées :
0) Numéro de l'entrée dans la base de données ou index dans la base de données triée

1) Indicateur facultatif pour traiter le premier argument comme un index dans la base de données triée

Valeur de retour :
Chaîne de noms alternatifs pour cette ville, séparés par des virgules.
Notes :
"ReadAltNames" doit être appelé avant d'appeler cette routine.

Geolocate

Retourne des informations de géolocalisation pour des coordonnées GPS ou un nom de ville spécifiés.

my @rtnInfo = Image::ExifTool::Geolocation::Geolocate($arg,$opts);
Entrées :
0) Argument d'entrée ("lat,lon", "ville", "ville,pays", "ville,région,pays", etc.). Lors de la spécification d'une ville, le nom de la ville doit venir en premier, suivi de zéro ou plusieurs des éléments suivants dans n'importe quel ordre, séparés par des virgules : nom de région, nom de sous-région, code pays et/ou nom de pays. Les expressions régulières au format "/expr/" sont également autorisées, éventuellement précédées de "ci", "re", "sr", "cc" ou "co" pour correspondre spécifiquement au nom de la Ville, de la Région, de la Sous-région, du Code Pays ou du Pays. Deux contrôles spéciaux peuvent être ajoutés à la liste d'arguments : 
'both'   - Lorsque la recherche inclut à la fois le nom et les coordonnées GPS,
           utilise les deux pour déterminer la ville la plus proche correspondant
           aux noms spécifiés au lieu d'utiliser uniquement les données GPS.
'num=##' - Lorsque la recherche inclut des coordonnées GPS, ou lorsqu'une
           seule ville correspond par son nom, renvoie les ## villes les plus
           proches au lieu d'une seule. Les villes renvoyées sont triées de la
           plus proche à la plus éloignée.

Voir https://exiftool.org/geolocation.html#Read pour plus de détails.

1) Référence facultative à une table de hachage d'options :

GeolocMinPop   - Population minimale des villes à prendre en compte dans la recherche.
                 Par défaut 0.
GeolocMaxDist  - Distance maximale (km) pour rechercher des villes lorsqu'une
                 position GPS d'entrée est utilisée.  Par défaut l'infini.
GeolocMulti    - Indicateur pour renvoyer plusieurs villes s'il y a plus d'une
                 correspondance.  Utilisé dans le cas où aucune coordonnée GPS
                 d'entrée n'est fournie.  Par défaut 0.
GeolocFeature  - Liste de codes de caractéristiques séparés par des virgules à inclure
                 dans la recherche, ou à exclure si la liste commence par un tiret (-).
                 Par défaut undef.
GeolocAltNames - Indicateur pour rechercher dans la base de données des noms alternatifs
                 si disponible pour faire correspondre le nom de la ville (voir
                 BASES DE DONNÉES ALTERNATIVES ci-dessous).
                 Par défaut undef.
Valeurs de Retour :
0) Référence à une liste de numéros d'entrées de la base de données pour les villes correspondantes, ou undef si aucune correspondance n'a été trouvée.

1) Référence à une liste de paires distance/cap pour chaque ville correspondante, ou undef si la recherche n'a pas fourni de coordonnées GPS.

BASES DE DONNÉES

ALTERNATIVES

Une version différente de la base de données des villes peut être spécifiée en définissant la variable de paquet $geoDir avant de charger ce module. Ce répertoire doit contenir le fichier Geolocation.dat, et éventuellement un répertoire GeoLang pour les traductions de langue. La variable $geoDir peut être définie à une chaîne vide pour désactiver le chargement d'une base de

données.

Lors de la recherche d'une ville par nom, AltNames.dat est consulté pour fournir des possibilités supplémentaires de correspondance si l'option GeolocAltNames est définie et si une base de données AltNames.dat existe. Le paquet la variable $altDir peut être définie pour spécifier un répertoire différent pour AltNames.dat, sinon le répertoire de Geolocation.da

t est supposé. Les entrées dans AltNames.dat doivent correspondre
à celles de la version actuellement chargée de Geolocation.dat.

AJOUT D'ENTRÉES DE BASE DE DONNÉES DÉFINIES PAR

L'UTILISATEUR

Des entrées définies par l'utilisateur peuvent être créées en les définissant en utilisant la technique suivante avant le chargement du module

Geolocation. 
@Image::ExifTool::UserDefined::Geolocation = (
    # ville, région, sous-région, code pays, pays, fuseau horaire,
    ['Sinemorets','burgas','Obshtina Tsarevo','BG','','Europe/Sofia',
    # code de caractéristique, population, lat, lon
     'PPL',400,42.06115,27.97833],
)
;

De même, des traductions de langue définies par l'utilisateur peuvent être définies, et elles remplaceront toutes les traductions existantes. Les traductions pour la langue par défaut 'en' peuvent également être spécifiées. Voir https://exiftool.org/geolocation.htm

l#Custom pour plus
d'informations.

UTILISATION D'UNE BASE DE DONNÉES

PERSONNALISÉE

Cet exemple montre comment utiliser une base de données personnalisée. Dans cet exemple, le fichier de base de données d'entrée est un fichier texte séparé par des virgules avec des colonnes correspondant aux arguments d'entrée de la méthode

AddEntry. 
$Image::ExifTool::Geolocation::geoDir = '';
require Image::Exif
Tool::Geolocation; open DFILE, "< $filename"; Image::ExifTool:
:Geolocation::AddEntry(split /,/) foreach <DFILE>; close DFILE;
