NOM

IO::Zlib - Interface de style IO:: pour Compress::Zlib

RÉSUMÉ

Avec n'importe quelle version de Perl 5, vous pouvez utiliser l'interface OO de base :

use IO::Zlib;
$fh = new IO::Zlib;
if ($fh->open("file.gz", "rb")) {
    print <$fh>;
    $fh->close;
}
$fh = IO::Zlib->new("file.gz", "wb9");
if (defined $fh) {
    print $fh "bar\n";
    $fh->close;
}
$fh = IO::Zlib->new("file.gz", "rb");
if (defined $fh) {
    print <$fh>;
    undef $fh;       # ferme automatiquement le fichier
}

Avec Perl 5.004, vous pouvez également utiliser l'interface TIEHANDLE pour accéder aux fichiers compressés comme à des fichiers ordinaires :

use IO::Zlib;
tie *FILE, 'IO::Zlib', "file.gz", "wb";
print FILE "line 1\nline2\n";
tie *FILE, 'IO::Zlib', "file.gz", "rb";
while (<FILE>) { print "LINE: ", $_ };

DESCRIPTION

"IO::Zlib" fournit une interface de style IO:: pour Compress::Zlib et donc pour les fichiers compressés gzip/zlib. Elle fournit bon nombre des mêmes méthodes que l'interface IO::Handle.

À partir de la version 1.02 d'IO::Zlib, IO::Zlib peut également utiliser une commande gzip externe. Le comportement par défaut est d'essayer d'utiliser un gzip externe si aucun "Compress::Zlib" ne peut être chargé, sauf si explicitement désactivé par

use IO::Zlib qw(:gzip_external 0);

Si explicitement activé par

use IO::Zlib qw(:gzip_external 1);

alors le gzip externe est utilisé à la place de "Compress::Zlib".

CONSTRUCTEUR

new ( [ARGS] )
Crée un objet "IO::Zlib" . S'il reçoit des paramètres, ceux-ci sont transmis à la méthode "open"; si l'ouverture échoue, l'objet est détruit. Sinon, il est retourné à l'appelant.

MÉTHODES D'OBJET

open ( FILENAME, MODE )
"open" prend deux arguments. Le premier est le nom du fichier à ouvrir et le second est le mode d'ouverture. Le mode peut être n'importe ce qui est acceptable pour Compress::Zlib et par extension n'importe quoi d'acceptable pour zlib (ce qui signifie fondamentalement des chaînes de mode de style POSIX fopen() plus un nombre optionnel pour indiquer le niveau de compression).
opened
Renvoie vrai si l'objet fait actuellement référence à un fichier ouvert.
close
Ferme le fichier associé à l'objet et dissocie le fichier du descripteur. Fait automatiquement lors de la destruction.
getc
Renvoie le caractère suivant du fichier, ou undef s'il n'en reste aucun.
getline
Renvoie la ligne suivante du fichier, ou undef en fin de chaîne. Peut être appelé sans danger dans un contexte de tableau. Ignore actuellement $/ ($INPUT_RECORD_SEPARATOR ou $RS lorsque English est utilisé) et traite les lignes comme délimitées par "\n".
getlines
Récupère toutes les lignes restantes du fichier. La fonction croak() sera appelée si elle est accidentellement utilisée dans un contexte scalaire.
print ( ARGS... )
Affiche ARGS dans le fichier.
read ( BUF, NBYTES, [OFFSET] )
Lit des octets depuis le fichier. Renvoie le nombre d'octets effectivement lus, 0 en fin de fichier, undef en cas d'erreur.
eof
Renvoie vrai si le descripteur est actuellement positionné en fin de fichier ?
seek ( OFFSET, WHENCE )
Se positionne à un endroit donné dans le flux. Pas encore pris en charge.
tell
Renvoie la position actuelle dans le flux, sous forme d'offset numérique. Pas encore pris en charge.
setpos ( POS )
Définit la position actuelle, en utilisant la valeur opaque retournée par getpos(). Pas encore pris en charge.
getpos ( POS )
Renvoie la position actuelle dans la chaîne, sous forme d'objet opaque. Pas encore pris en charge.

UTILISATION DU GZIP EXTERNE

Si le gzip externe est utilisé, les "open"suivants sont utilisés :

open(FH, "gzip -dc $filename |")  # pour les ouvertures en lecture
open(FH, " | gzip > $filename")   # pour les ouvertures en écriture

Vous pouvez modifier les « commandes », par exemple pour coder en dur un chemin absolu, en utilisant par exemple :

use IO::Zlib ':gzip_read_open'  => '/some/where/gunzip -c %s |';
use IO::Zlib ':gzip_write_open' => '| /some/where/gzip.exe > %s';

Le %s est développé pour devenir le nom du fichier ("sprintf" est utilisé, alors soyez prudent pour échapper tous les autres signes "%" ). Les « commandes » sont vérifiées pour leur cohérence - elles doivent contenir le %s, et l'ouverture en lecture doit se terminer par le signe pipe, et l'ouverture en écriture doit commencer par le signe pipe.

MÉTHODES DE CLASSE

has_Compress_Zlib
Renvoie vrai si "Compress::Zlib" est disponible. Notez que cela ne signifie pas que "Compress::Zlib" est utilisé : voir "gzip_external" et gzip_used.
gzip_external
Indéfini si un gzip externe peut être utilisé si "Compress::Zlib" n'est pas disponible (voir "has_Compress_Zlib"), vrai si un gzip externe est explicitement utilisé, faux si un gzip externe ne doit pas être utilisé. Voir "gzip_used".
gzip_used
Vrai si un gzip externe est utilisé, faux sinon.
gzip_read_open
Renvoie la « commande » utilisée pour ouvrir un fichier en lecture à l'aide d'un gzipexterne.
gzip_write_open
Renvoie la « commande » utilisée pour ouvrir un fichier en écriture à l'aide d'un gzipexterne.

Si vous voulez lire des lignes, vous devez lire dans un contexte de liste.
IO::Zlib::gzopen_external: mode '...' is illegal
Utilisez uniquement les modes 'rb' ou 'wb' ou /wb[1-9]/.
IO::Zlib::import: '...' is illegal
Les symboles d'importation connus sont ":gzip_external", ":gzip_read_open", et ":gzip_write_open". Tout le reste n'est pas reconnu.
IO::Zlib::import: ':gzip_external' requires an argument
Le ":gzip_external" nécessite un argument booléen.
IO::Zlib::import: 'gzip_read_open' requires an argument
Le ":gzip_external" nécessite un argument chaîne.
