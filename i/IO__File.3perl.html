IO::File(3perl) Guide du programmeur Perl IO::File(3perl)

NOM

IO::File - fournit des méthodes d'objet pour les descripteurs de fichiers

SYNTAXE

use IO::File;
my $fh = IO::File->new();
if ($fh->open("< fichier")) {
    print <$fh>;
    $fh->close;
}
my $fh = IO::File->new("> fichier");
if (defined $fh) {
    print $fh "bar\n";
    $fh->close;
}
my $fh = IO::File->new("fichier", "r");
if (defined $fh) {
    print <$fh>;
    undef $fh;       # ferme automatiquement le fichier
}
my $fh = IO::File->new("fichier", O_WRONLY|O_APPEND);
if (defined $fh) {
    print $fh "corge\n";
    my $pos = $fh->getpos;
    $fh->setpos($pos);
    undef $fh;       # ferme automatiquement le fichier
}
autoflush STDOUT 1;

DESCRIPTION

"IO::File" hérite de "IO::Handle" et "IO::Seekable". Il étend ces classes avec des méthodes spécifiques aux descripteurs de fichiers.

CONSTRUCTEUR

new ( NOMFICHIER [,MODE [,PERMISSIONS]] )
Crée un objet "IO::File". S'il reçoit des paramètres, ils sont passés à la méthode "open" ; si l'ouverture échoue, l'objet est détruit. Sinon, il est retourné à l'appelant.
new_tmpfile
Crée un objet "IO::File" ouvert en lecture/écriture sur un nouveau fichier temporaire. Sur les systèmes où cela est possible, le fichier temporaire est anonyme (c'est-à-dire qu'il est désélectionné après sa création, mais maintenu ouvert). Si le fichier temporaire ne peut être créé ou ouvert, l'objet "IO::File" est détruit. Sinon, il est retourné à l'appelant.

MÉTHODES

open( NOMFICHIER [,MODE [,PERMISSIONS]] )
open( NOMFICHIER, STRATES_IO )
"open" accepte un, deux ou trois paramètres. Avec un paramètre, il sert simplement de façade à la fonction intégrée "open". Avec deux ou trois paramètres, le premier paramètre est un nom de fichier pouvant contenir des espaces ou d'autres caractères spéciaux, et le second paramètre est le mode d'ouverture, éventuellement suivi d'une valeur de permissions de fichier.

Si "IO::File::open" reçoit une chaîne de mode Perl (">", "+<", etc.) ou une chaîne de mode fopen() ANSI C ("w", "r+", etc.), il utilise l'opérateur Perl de base "open" (mais protège tous les caractères spéciaux).

Si "IO::File::open" reçoit un mode numérique, il transmet ce mode et la valeur optionnelle de permissions à l'opérateur Perl "sysopen". Les permissions par défaut sont 0666.

Si "IO::File::open" reçoit un mode incluant le caractère ":", il transmet les trois arguments à l'opérateur "open" à trois arguments.

Par souci de commodité, "IO::File" exporte les constantes O_XXX du module Fcntl, si ce module est disponible.

NOTE

Certains systèmes d'exploitation peuvent exécuter IO::File::new() ou IO::File::open() sur un répertoire sans erreur. Ce comportement n'est pas portable et n'est pas recommandé. L'utilisation de opendir() et readdir() ou de "IO::Dir" est suggérée à la place.

VOIR AUSSI

perlfunc, "Opérateurs d'E/S" dans perlop, IO::Handle, IO::Seekable, IO::Dir
