Module Map

module T : Map.OrderedType

include Map.S

val of_list : (key * 'a) list -> 'a t

val disjoint_union : ?eq:('a -> 'a -> bool) -> ?print:(Format.formatter -> 'a -> unit) -> 'a t -> 'a t -> 'a t

disjoint_union m1 m2 contient toutes les associations de m1 et m2 . Si une association est présente dans les deux et que la valeur associée n'est pas égale, une Fatal_error est levée.

val union_right : 'a t -> 'a t -> 'a t

union_right m1 m2 contient toutes les associations de m1 et m2 . Si une association est présente dans les deux, celle de m2 est prise.

val union_left : 'a t -> 'a t -> 'a t

union_left m1 m2 = union_right m2 m1

val union_merge : ('a -> 'a -> 'a) -> 'a t -> 'a t -> 'a t
