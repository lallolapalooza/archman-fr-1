Image__Magick__Q16HDRI(3pm)

Paquet: imagemagick

Licences: custom

Q16HDRI(3) Documentation Perl Contribuée par l'Utilisateur Q16HDRI(3)

NOM

Image::Magick::Q16HDRI - interface objet en Perl pour ImageMagick (Q16HDRI). Utilisez-la pour créer, éditer, composer ou convertir des images bitmap depuis un script Perl.

SYNTAXE

use Image::Magick::Q16HDRI;
$p = new Image::Magick::Q16HDRI;
$p->Read("fichier_image");
$p->Set(attribut => valeur, ...)
($a, ...) = $p->Get("attribut", ...)
$p->routine(parametre => valeur, ...)
$p->Mogrify("Routine", parametre => valeur, ...)
$p->Write("nom_de_fichier");

DESCRIPTION

Cette extension Perl permet la lecture, la manipulation et l'écriture d'un grand nombre de formats de fichiers image en utilisant la bibliothèque ImageMagick. Elle a été initialement développée pour être utilisée par des scripts CGI pour les pages Web.

Une page Web a été mise en place pour cette extension. Voir :

https://imagemagick.org/script/perl-magick.php

En cas de problèmes, rendez-vous sur

https://github.com/ImageMagick/ImageMagick/discussions/categories/development
