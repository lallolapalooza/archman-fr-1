NOM

Image::ExifTool::HtmlDump - Extraire des informations en hexadécimal dans une page HTML

SYNTAXE

use Image::ExifTool::HtmlDump;
my $dump = Image::ExifTool::HtmlDump->new;
$dump->Add($start, $size, $comment);
$dump->Print($dumpInfo, $raf, $dataPt, $dataPos, $outfile);

DESCRIPTION

Ce module contient le code utilisé pour générer une représentation hexadécimale des informations dans une page HTML à des fins de débogage. Ce code est appelé lorsque l'option 'HtmlDump' d'ExifTool est utilisée.

Actuellement, seules les informations EXIF/TIFF et JPEG sont extraites.

BOGUES

En raison d'un bogue d'allocation mémoire dans ActivePerl 5.8.x pour Windows, ce code peut s'exécuter extrêmement lentement lors du traitement de fichiers volumineux avec cette version de Perl.

Un navigateur conforme à HTML 4 est nécessaire pour afficher correctement la page HTML générée.
