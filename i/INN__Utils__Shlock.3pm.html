NOM

INN::Utils::Shlock - Enveloppe autour du programme shlock

DESCRIPTION

Ce module Perl enveloppe le programme shlock(8) afin qu'il puisse être facilement utilisé. L'appel à shlock est plus portable que l'utilisation de flock(2) et de sa fonction Perl correspondante, car cette fonction ne fonctionne pas comme prévu sur tous les systèmes existants.

Voir la documentation de shlock(8) pour plus d'informations.

L'utilisation de INN::Utils::Shlock est simple :

use lib '<pathnews>/lib/perl';
use INN::Utils::Shlock;
my $lockfile = "myprogram.LOCK";
# Acquérir un verrou.
INN::Utils::Shlock::lock($lockfile);
# Faire ce que vous voulez. Le verrou empêche les accès concurrents.
# Libérer le verrou.
INN::Utils::Shlock::unlock($lockfile);

Ces deux fonctions retournent 1 en cas de succès, 0 en cas d'échec. Par exemple, le succès du (dé)verrouillage peut être vérifié comme suit :

INN::Utils::Shlock::lock($lockfile)
    or die "impossible de créer le fichier de verrou";

ou :

if (! INN::Utils::Shlock::lock($lockfile, 4)) {
    die "abandon après 4 tentatives de création du fichier de verrou";
}

Au lieu d'appeler "unlock(fichier_verrou)", la fonction "releaselocks()" peut être appelée. Elle supprime tous les verrous restants, ce qui est utile lorsque plusieurs verrous différents sont utilisés. Une autre utilisation possible est de l'appeler dans un bloc de code END :

END {
    # Au cas où nous sortirions, tout en détenant un verrou.
    INN::Utils::Shlock::releaselocks();
}

INTERFACE

lock(fichier_verrou)
Tente de créer un fichier de verrou nommé fichier_verrou.

Cette fonction retourne 1 en cas de succès, 0 en cas d'échec.

lock(fichier_verrou, tentatives)
Tente de créer un fichier de verrou nommé fichier_verrou. En cas d'échec, les tentatives de verrouillage sont répétées toutes les 2 secondes pendant au plus tentatives fois (y compris la première tentative infructueuse).

Cette fonction retourne 1 en cas de succès, 0 en cas d'échec.

lock(fichier_verrou, tentatives, délai)
Tente de créer un fichier de verrou nommé fichier_verrou. En cas d'échec, les tentatives de verrouillage sont répétées toutes les délai secondes pendant au plus tentatives fois (y compris la première tentative infructueuse).

Notez que "lock(fichier_verrou)" est équivalent à "lock(fichier_verrou, 1, 2)".

Cette fonction retourne 1 en cas de succès, 0 en cas d'échec.

releaselocks()
Supprime tous les fichiers de verrou précédemment créés en appelant la fonction "lock(fichier_verrou)".

Cette fonction retourne le nombre de fichiers de verrou supprimés.

unlock(fichier_verrou)
Supprime le fichier nommé fichier_verrou.

Cette fonction retourne 1 en cas de succès, 0 en cas d'échec.
