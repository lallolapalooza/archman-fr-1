NOM

Image::ExifTool::FITS - Lire les métadonnées du système de transport d'images flexible (FITS)

SYNOPSIS

Ce module est utilisé par Image::ExifTool

DESCRIPTION

Ce module contient les définitions requises par Image::ExifTool pour lire les métadonnées des images FITS (Flexible Image Transport System).
