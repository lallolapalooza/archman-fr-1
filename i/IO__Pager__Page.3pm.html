IO::Pager::Page(3) Documentation Perl Contribuée par les utilisateurs IO::Pager::Page(3)

NOM

IO::Pager::Page - Émule IO::Page, redirige STDOUT vers un pager si STDOUT est un TTY

SYNTAXE

Redirige STDOUT vers un pager si STDOUT est un TTY

DESCRIPTION

IO::Pager a été conçu pour décider de manière programmatique s'il faut ou non diriger le descripteur de fichier STDOUT vers un pipe vers le pager spécifié dans la variable d'environnement PAGER ou l'une d'une liste standard de pagers.

UTILISATION

BEGIN {
  use IO::Pager::Page;
  # utiliser d'abord I::P::P, juste au cas où un autre module enverrait de la sortie à STDOUT
}
print<<HEREDOC;
...
Beaucoup de texte plus tard
HEREDOC

Si vous souhaitez éviter le risque d'un problème de Pipe cassé résultant de la sortie prématurée de l'utilisateur du pager, chargez IO::Pager::Page comme suit :

use IO::Pager::Page hush=>1;

VOIR AUSSI

IO::Page, IO::Pager, IO::Pager::Unbuffered, IO::Pager::Buffered
