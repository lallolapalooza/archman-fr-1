NOM

Image::ExifTool::NikonSettings - Lire les paramètres utilisateur Nikon

SYNOPIS

Ce module est chargé automatiquement par Image::ExifTool lorsque requis.

DESCRIPTION

Ce module contient les définitions nécessaires pour lire les paramètres utilisateur des appareils photo Nikon tels que le D6 et le Z7mk2.
