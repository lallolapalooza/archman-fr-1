Image::Info::BMP(3) Documentation Perl fournie par l'utilisateur Image::Info::BMP(3)

NOM

Image::Info::BMP - Support des Bitmap Indépendantes des Périphériques Windows pour Image::Info

SYNTAXE

use Image::Info qw(image_info dim);
my $info = image_info("image.bmp");
if (my $error = $info->{error}) {
    die "Impossible d'analyser les informations de l'image : $error\n";
}
my $color = $info->{color_type};
my($w, $h) = dim($info);

DESCRIPTION

Ce module fournit les noms de clés standard à l'exception de Gamma, Interlace, LastModificationTime, ainsi que :

BMP_ColorsImportant
Spécifie le nombre d'index de couleurs requis pour afficher le bitmap. Si cette valeur est zéro, toutes les couleurs sont requises.
BMP_Origin
Si vrai, le bitmap est un DIB ascendant et son origine est le coin inférieur gauche. Sinon, le bitmap est un DIB descendant et son origine est le coin supérieur gauche.
ColorPalette
Référence vers un tableau de toutes les couleurs utilisées. Cette clé est présente uniquement si "image_info" est appelée comme "image_info($file, ColorPalette=>1)".
ColorTableSize
Le nombre de couleurs utilisées par l'image. Si 0, il s'agit d'une image en couleur réelle. Le nombre de couleurs *disponibles* est 2 ^ BitsPerSample.

MÉTHODES

process_file()

$info->process_file($source, $options);

Traite un fichier et définit les champs d'informations trouvés dans l'objet $info.

DIAGNOSTICS

Inadéquation de taille
L'image peut être correcte, mais la taille du fichier ne correspond pas à la valeur stockée en interne.

BOGUES

L'implémentation actuelle ne fonctionne que sur les architectures little-endian. Par conséquent, des données erronées concernant la compression (y compris file_ext et file_mime_type) peuvent être signalées.
