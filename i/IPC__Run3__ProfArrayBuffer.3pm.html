NOM

IPC::Run3::ProfArrayBuffer - Stocker les événements de profil en RAM dans un tableau

SYNTAXE

DESCRIPTION

MÉTHODES

"IPC::Run3::ProfArrayBuffer->new()"
"$buffer->app_call(@events)"
"$buffer->app_exit(@events)"
"$buffer->run_exit(@events)"
Les trois méthodes ci-dessus ajoutent les événements donnés à la pile d'événements enregistrés.
get_events
Renvoie une liste de tous les événements. Chaque événement est une référence de tableau comme : 
[ "app_call", 1.1, ... ];
