type t

val compare : t -> t -> int

Une fonction d'ordre total sur les éléments de l'ensemble. C'est une fonction à deux arguments f telle que f e1 e2 est zéro si les éléments e1 et e2 sont égaux, f e1 e2 est strictement négatif si e1 est inférieur à e2, et f e1 e2 est strictement positif si e1 est supérieur à e2. Exemple : une fonction d'ordre appropriée est la fonction de comparaison structurelle générique compare.
