IO::Seekable(3perl) Guide du programmeur Perl IO::Seekable(3perl)

NOM

IO::Seekable - Fournit des méthodes de recherche pour les objets d'E/S

SYNOPIS

use IO::Seekable;
package IO::Something;
@ISA = qw(IO::Seekable);

DESCRIPTION

"IO::Seekable" n'a pas de constructeur propre, car il est destiné à être hérité par d'autres objets basés sur "IO::Handle". Il fournit des méthodes qui permettent de rechercher dans les descripteurs de fichiers.

$io->getpos
Retourne une valeur opaque représentant la position actuelle du fichier IO::File, ou "undef" si ce n'est pas possible (par exemple, un flux non recherchable comme un terminal, un tube ou une socket). Si la fonction fgetpos() est disponible dans votre bibliothèque C, elle est utilisée pour implémenter getpos ; sinon, Perl émule getpos en utilisant la fonction ftell() de C.
$io->setpos
Utilise la valeur d'un appel getpos précédent pour revenir à une position précédemment visitée. Retourne « 0 but true » en cas de succès, "undef" en cas d'échec.

Voir perlfunc pour des descriptions complètes de chacune des méthodes "IO::Seekable" prises en charge ci-dessous, qui ne sont que des façades pour les fonctions intégrées correspondantes :

$io->seek ( POS, WHENCE )
Recherche dans le fichier IO::File à la position POS, relative à WHENCE :
WHENCE=0 (SEEK_SET)
POS est une position absolue. (Recherche par rapport au début du fichier)
WHENCE=1 (SEEK_CUR)
POS est un décalage par rapport à la position actuelle. (Recherche par rapport à la position actuelle)
WHENCE=2 (SEEK_END)
POS est un décalage par rapport à la fin du fichier. (Recherche par rapport à la fin)

Les constantes SEEK_* peuvent être importées depuis le module "Fcntl" si vous ne souhaitez pas utiliser les nombres 0, 1 ou 2 dans votre code.

Retourne 1 en cas de succès, 0 sinon.

$io->sysseek( POS, WHENCE )
Similaire à $io->seek, mais définit la position du fichier IO::File directement à l'aide de l'appel système lseek(2). Cela perturbera la plupart des opérateurs d'E/S de Perl, à l'exception de sysread et syswrite (voir perlfunc pour plus de détails).

Retourne la nouvelle position, ou "undef" en cas d'échec. Une position de zéro est retournée sous forme de chaîne "0 but true"

$io->tell
Retourne la position actuelle du fichier IO::File, ou -1 en cas d'erreur.
