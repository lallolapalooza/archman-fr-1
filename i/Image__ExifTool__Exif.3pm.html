NOM

Image::ExifTool::Exif - Lire les métadonnées EXIF/TIFF

SYNOPIS

Ce module est requis par Image::ExifTool.

DESCRIPTION

Ce module contient les routines requises par Image::ExifTool pour le traitement des métadonnées EXIF et TIFF.
