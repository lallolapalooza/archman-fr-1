NOM

Image::ExifTool::CaptureOne - Lire les fichiers Capture One EIP et COS

SYNTHÈSE

Ce module est utilisé par Image::ExifTool

DESCRIPTION

Ce module contient les définitions nécessaires à Image::ExifTool pour extraire les métadonnées des fichiers EIP (Enhanced Image Package) et COS (Capture One Settings) de Capture One.

NOTES

Le format EIP est un fichier ZIP contenant une image (IIQ ou TIFF) et certains fichiers de paramètres (COS).
