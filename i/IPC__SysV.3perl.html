IPC::SysV(3perl) Guide du programmeur Perl IPC::SysV(3perl)

NOM

IPC::SysV - Constantes et appels système SysV IPC

SYNOPSIS

use IPC::SysV qw(IPC_STAT IPC_PRIVATE);

DESCRIPTION

"IPC::SysV" définit et exporte conditionnellement toutes les constantes définies dans les fichiers d'inclusion de votre système qui sont nécessaires aux appels SysV IPC. Les plus courantes incluent :

IPC_CREAT IPC_EXCL IPC_NOWAIT IPC_PRIVATE IPC_RMID IPC_SET IPC_STAT
GETVAL SETVAL GETPID GETNCNT GETZCNT GETALL SETALL
SEM_A SEM_R SEM_UNDO
SHM_RDONLY SHM_RND SHMLBA

et les auxiliaires :

S_IRUSR S_IWUSR S_IRWXU
S_IRGRP S_IWGRP S_IRWXG
S_IROTH S_IWOTH S_IRWXO

mais votre système pourrait en avoir plus.

ftok( PATH )
ftok( PATH, ID )
Retourne une clé basée sur PATH et ID, qui peut être utilisée comme clé pour "msgget", "semget" et "shmget". Voir ftok(3).

Si ID est omis, il vaut par défaut 1. Si un seul caractère est donné pour ID, la valeur numérique de ce caractère est utilisée.

shmat( ID, ADDR, FLAG )
Attache le segment de mémoire partagée identifié par ID à l'espace d'adressage du processus appelant. Voir shmat(2).

ADDR devrait être "undef" à moins que vous ne sachiez vraiment ce que vous faites.

shmdt( ADDR )
Détache le segment de mémoire partagée situé à l'adresse spécifiée par ADDR de l'espace d'adressage du processus appelant. Voir shmdt(2).
memread( ADDR, VAR, POS, SIZE )
Lit SIZE octets à partir d'un segment mémoire à ADDR en commençant à la position POS. VAR doit être une variable qui contiendra les données lues. Retourne vrai en cas de succès, ou faux en cas d'erreur. memread() souille la variable.
memwrite( ADDR, STRING, POS, SIZE )
Écrit SIZE octets depuis STRING vers un segment mémoire à ADDR en commençant à la position POS. Si STRING est trop long, seuls SIZE octets sont utilisés ; si STRING est trop court, des zéros sont écrits pour compléter SIZE octets. Retourne vrai en cas de succès, ou faux en cas d'erreur.

VOIR AUSSI

IPC::Msg, IPC::Semaphore, IPC::SharedMem, ftok(3), shmat(2), shmdt(2)
