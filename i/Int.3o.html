Module Int

Valeurs entières.

Les entiers ont Sys.int_size bits de largeur et utilisent la représentation en complément à deux. Toutes les opérations sont effectuées modulo 2^Sys.int_size. Elles ne provoquent pas d'échec en cas de dépassement.

Depuis 4.08

ENTIERS

type t = int

Le type pour les valeurs entières.

val zero : int

zero est l'entier 0.

val one : int

one est l'entier 1.

val minus_one : int

minus_one est l'entier -1.

val neg : int -> int

neg x est ~-x.

val add : int -> int -> int

add x y est l'addition x + y.

val sub : int -> int -> int

sub x y est la soustraction x - y.

val mul : int -> int -> int

mul x y est la multiplication x * y.

val div : int -> int -> int

div x y est la division x / y. Voir (/) pour les détails.

val rem : int -> int -> int

rem x y est le reste x mod y. Voir (mod) pour les détails.

val succ : int -> int

succ x est add x 1.

val pred : int -> int

pred x est sub x 1.

val abs : int -> int

abs x est la valeur absolue de x. C'est-à-dire x si x est positif et neg x si x est négatif. Attention. Ceci peut être négatif si l'argument est Int.min_int.

val max_int : int

max_int est le plus grand entier représentable, 2 ^ Sys.int_size - 1 -1.

val min_int : int

min_int est le plus petit entier représentable, -2 ^ Sys.int_size - 1.

val logand : int -> int -> int

logand x y est le ET logique bit à bit de x et y.

val logor : int -> int -> int

logor x y est le OU logique bit à bit de x et y.

val logxor : int -> int -> int

logxor x y est le OU exclusif logique bit à bit de x et y.

val lognot : int -> int

lognot x est la négation logique bit à bit de x.

val shift_left : int -> int -> int

shift_left x n décale x vers la gauche de n bits. Le résultat n'est pas spécifié si n < 0 ou n > Sys.int_size.

val shift_right : int -> int -> int

shift_right x n décale x vers la droite de n bits. C'est un décalage arithmétique : le bit de signe de x est répliqué et inséré dans les bits vacants. Le résultat n'est pas spécifié si n < 0 ou n > Sys.int_size.

val shift_right_logical : int -> int -> int

shift_right x n décale x vers la droite de n bits. C'est un décalage logique : des zéros sont insérés dans les bits vacants, indépendamment du signe de x. Le résultat n'est pas spécifié si n < 0 ou n > Sys.int_size.

PRÉDICATS ET COMPARAISONS

val equal : int -> int -> bool

equal x y est vrai si et seulement si x = y.

val compare : int -> int -> int

compare x y est compare x y mais plus efficace.

Retourne le plus petit des deux arguments.

val max : int -> int -> int

CONVERSION

val to_float : int -> float

to_float x est x sous forme de nombre à virgule flottante.

val of_float : float -> int

of_float x tronque x en un entier. Le résultat n'est pas spécifié si l'argument est nan ou sort de la plage des entiers représentables.

val to_string : int -> string

to_string x est la représentation écrite de x en décimal.

val seeded_hash : int -> int -> int

Une fonction de hachage avec germe pour les entiers, avec la même valeur de sortie que Hashtbl.seeded_hash. Cette fonction permet de passer ce module en argument au foncteur Hashtbl.MakeSeeded.

Depuis 5.1

val hash : int -> int

Une fonction de hachage sans germe pour les entiers, avec la même valeur de sortie que Hashtbl.hash. Cette fonction permet de passer ce module en argument au foncteur Hashtbl.Make.
