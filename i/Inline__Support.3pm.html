NOM

Inline-Support - Informations de support pour Inline.pm et les modules associés.

DESCRIPTION

Ce document contient toutes les informations de support les plus récentes pour "Inline.pm" et les modules de support de langage Inline (ILSM) reconnus disponibles sur CPAN.

LANGAGES SUPPORTÉS

Le langage le plus important supporté par Inline est "C". C'est parce que Perl lui-même est écrit en "C". En donnant à vos scripts Perl accès à "C", vous leur donnez en effet accès à toutes les glorieuses entrailles de Perl. (Attention scriptor :-)

À la date de rédaction, Inline supporte également :

  • C++
  • Java
  • Python
  • Tcl
  • Assembly
  • CPR
  • Et même Inline::Foo ! :)

Les projets que j'aimerais le plus voir réalisés en l'an 2001 sont :

  • Fortran
  • Ruby
  • Lisp
  • Guile
  • Bash
  • Perl4

PLATEFORMES SUPPORTÉES

"Inline::C" devrait fonctionner partout où les modules d'extension CPAN (ceux qui utilisent XS) peuvent être installés, en utilisant le format d'installation typique :

perl Makefile.PL
make
make test
make install

Il a été testé sur de nombreuses variantes Unix et Windows.

NOTE : "Inline::C" nécessite Perl 5.005 ou supérieur car "Parse::RecDescent" le requiert. (Quelque chose à voir avec l'opérateur "qr")

Inline a été testé avec succès à un moment ou à un autre sur les plateformes suivantes :

  • Linux
  • Solaris
  • SunOS
  • HPUX
  • AIX
  • FreeBSD
  • OpenBSD
  • BeOS
  • OS X
  • WinNT
  • Win2K
  • WinME
  • Win98
  • Cygwin

Les tests Microsoft méritent une explication plus détaillée. J'ai utilisé les éléments suivants :

  • Windows NT 4.0 (service pack 6)
  • Perl 5.005_03 (build ActiveState 522)
  • MS Visual C++ 6.0
  • L'utilitaire make "nmake" (distribué avec Visual C++)

"Inline::C" récupère toute sa configuration de base (y compris quel utilitaire "make" utiliser) à partir de "Config.pm". Étant donné que votre version MSWin32 de Perl provient probablement d'ActiveState (en tant que distribution binaire), "Config.pm" indiquera que "nmake" est l'utilitaire "make" du système. C'est parce qu'ActiveState utilise Visual C++ pour compiler Perl.

Pour installer "Inline.pm" (ou tout autre module CPAN) sur MSWin32 avec Visual C++, utilisez les commandes suivantes :

perl Makefile.PL
nmake
nmake test
nmake install

Inline a également été rendu compatible avec Mingw32/gcc sur toutes les plateformes Windows. Il s'agit d'un compilateur gratuit pour Windows. Vous devez également utiliser une version de Perl compilée avec ce compilateur.

Le test "Cygwin" a été effectué sur une machine Windows 98 en utilisant le logiciel de couche de portage Unix/Win32 Cygwin de Cygnus. Le binaire "perl" sur cette machine a également été compilé en utilisant la suite d'outils Cygwin ("gcc"). Ce logiciel est disponible gratuitement sur http://sources.redhat.com/cygwin/

Si vous parvenez à faire fonctionner Inline sur une nouvelle plateforme, veuillez m'envoyer un e-mail. Si cela ne fonctionne pas, faites-le moi savoir également et je verrai ce qui peut être fait.
