DESCRIPTIO

N

Ce module fournit une interface Perl permettant d'écrire des données compressées dans des fichiers ou des buffers tel que défini dans la RFC

1952.

Tous les en-têtes gzip définis dans la RFC 1952 peuvent être créés à l'aide de ce

module.

Pour lire des fichiers/buffers

RFC 1952, voir le module com
pagnon IO::Uncompress::Gunzip.

Une fonction de haut niveau, "gzip", est fournie pour effectuer une compression « one-shot » entre des buffers et/ou des fichiers. Pour un contrôle plus fin du processus de compression, voir la section « Interface OO »

.

$GzipError\n";

Paramètres

optionnels

Les paramètres optionnels pour la fonction one-shot "gzip" sont (pour la plupart) identiques à ceux utilisés avec l'interface OO définie dans la section « Options du constructeur ». Les exceptions sont listées

ci-dessous
"AutoClose =>
0|1"
Cette option s'applique à tout flux de données d'entrée ou de sortie à "gzip" qui sont des filehandles.

Si "AutoClose" est spécifié, et que la valeur est vraie, cela entraînera la fermeture de tous les filehandles d'entrée et/ou de sortie une fois que "gzip" sera

terminé.

Ce paramèt

re vaut 0 p
ar défaut.
"BinModeIn =>
0|1"
Cette option est désormais sans effet. Tous les fichiers seront lus en
binmode.
"Append =>
0|1"
Le comportement de cette
option dépend du type du f
lux de données de sortie.
  • Un buffer

    Si "Append" est activé, toutes les données compressées seront ajoutéesà la fin du tampon de sortie. Sinon, le tampon de sortie sera vidé avant que toute donnée compressée ne soit écrite dedans.

  • Un nom de fichier

    Si "Append" est activé, le fichier sera ouvert en mode ajout. Sinon, le contenu du fichier, le cas échéant, sera tronqué avant que toute donnée compressée ne soit écrite dedans.

  • Un descripteur de fichier

    Si "Append" est activé, le descripteur de fichier sera positionné à la fin du fichier via un appel à "seek" avant que toute donnée compressée ne soit écrite dedans. Sinon, le pointeur de fichier ne sera pas déplacé.

Lorsque "Append" est spécifié et défini à vrai, toutes les données compressées seront ajoutées au flux de données de sortie.

Ainsi, lorsque la sortie est un descripteur de fichier, une recherche à la fin du fichier sera effectuée avant d'écrire toute donnée compressée. Si la sortie est un nom de fichier, il sera ouvert en mode ajout. Si la sortie est un tampon, toutes les données compressées seront ajoutées au tampon existant.

Inversement, lorsque "Append" n'est pas spécifié, ou qu'il est présent et défini à faux, le comportement sera le suivant.

Lorsque la sortie est un nom de fichier, le contenu du fichier sera tronqué avant l'écriture de toute donnée compressée. Si la sortie est un descripteur de fichier, sa position ne sera pas modifiée. Si la sortie est un tampon, il sera effacé avant que toute donnée compressée ne soit sortie.

Par défaut, vaut 0.

Exemples Oneshot

Voici quelques exemples qui montrent les capacités du module.

Streaming

Cet exemple de ligne de commande très simple démontre les capacités de streaming du module. Le code lit les données de STDIN, les compresse et écrit les données compressées dans STDOUT.

$ echo hello world | perl -MIO::Compress::Gzip=gzip -e 'gzip \*STDIN => \*STDOUT' >output.gz

Le nom de fichier spécial "-" peut être utilisé comme substitut pour "\*STDIN" et "\*STDOUT", donc ce qui précède peut être réécrit comme suit :

$ echo hello world | perl -MIO::Compress::Gzip=gzip -e 'gzip "-" => "-"' >output.gz

Compression d'un fichier depuis le système de fichiers

Pour lire le contenu du fichier "file1.txt" et écrire les données compressées dans le fichier "file1.txt.gz".

use strict ;
use warnings ;
use IO::Compress::Gzip qw(gzip $GzipError) ;
my $input = "file1.txt";
gzip $input => "$input.gz"
    or die "gzip failed: $GzipError\n";

Lecture à partir d'un descripteur de fichier et écriture dans un tampon en mémoire

Pour lire à partir d'un descripteur de fichier Perl existant, $input, et écrire les données compressées dans un tampon, $buffer.

use strict ;
use warnings ;
use IO::Compress::Gzip qw(gzip $GzipError) ;
use IO::File ;
my $input = IO::File->new( "<file1.txt" )
    or die "Cannot open 'file1.txt': $!\n" ;
my $buffer ;
gzip $input => \$buffer
    or die "gzip failed: $GzipError\n";

Compression de plusieurs fichiers

Pour compresser tous les fichiers du répertoire "/my/home" qui correspondent à "*.txt" et stocker les données compressées dans le même répertoire.

use strict ;
use warnings ;
use IO::Compress::Gzip qw(gzip $GzipError) ;
gzip '</my/home/*.txt>' => '<*.gz>'
    or die "gzip failed: $GzipError\n";

Et si vous voulez compresser chaque fichier un par un, cela fera l'affaire :

use strict ;
use warnings ;
use IO::Compress::Gzip qw(gzip $GzipError) ;
for my $input ( glob "/my/home/*.txt" )
{
    my $output = "$input.gz" ;
    gzip $input => $output
        or die "Error compressing '$input': $GzipError\n";
}

Interface OO

Constructeur

La structure du constructeur pour "IO::Compress::Gzip" est la suivante :

my $z = IO::Compress::Gzip->new( $output [,OPTS] )
    or die "IO::Compress::Gzip failed: $GzipError\n";

Le constructeur prend un paramètre obligatoire, $output, défini ci-dessous, et zéro ou plusieurs "OPTS", définis dans "Options du Constructeur".

Il retourne un objet "IO::Compress::Gzip" en cas de succès et "undef" en cas d'échec. La variable $GzipError contiendra un message d'erreur en cas d'échec.

Si vous utilisez Perl 5.005 ou une version ultérieure, l'objet, $z, retourné par IO::Compress::Gzip peut être utilisé exactement comme un descripteur de fichier IO::File. Cela signifie que toutes les opérations normales de fichier de sortie peuvent être effectuées avec $z. Par exemple, pour écrire dans un fichier/tampon compressé, vous pouvez utiliser l'une de ces formes :

$z->print("hello world\n");
print $z "hello world\n";

Voici un exemple simple d'utilisation de l'interface OO pour créer un fichier de sortie "myfile.gz" et y écrire des données.

my $filename = "myfile.gz";
my $z = IO::Compress::Gzip->new($filename)
    or die "IO::Compress::Gzip failed: $GzipError\n";
$z->print("abcde");
$z->close();

Voir "Exemples" pour plus d'informations.

Le paramètre obligatoire $output est utilisé pour contrôler la destination des données compressées. Ce paramètre peut prendre l'une des formes suivantes.

Un nom de fichier
Si le paramètre $output est un scalaire simple, il est supposé être un nom de fichier. Ce fichier sera ouvert en écriture et les données compressées y seront écrites.
Un descripteur de fichier
Si le paramètre $output est un descripteur de fichier, les données compressées y seront écrites. La chaîne '-' peut être utilisée comme alias pour la sortie standard.
Une référence scalaire
Si $output est une référence scalaire, les données compressées seront stockées dans $$output.

Si le paramètre $output est d'un autre type, "IO::Compress::Gzip"::new retournera undef.

Options du Constructeur

"OPTS" est une combinaison de zéro ou plus des options suivantes :

"AutoClose => 0|1"
Cette option n'est valide que lorsque le paramètre $output est un descripteur de fichier. Si elle est spécifiée et que sa valeur est vraie, le $output sera fermé une fois que la méthode "close" sera appelée ou que l'objet "IO::Compress::Gzip" sera détruit.

Ce paramètre vaut 0 par défaut.

"Append => 0|1"
Ouvre $output en mode ajout.

Le comportement de cette option dépend du type de $output.

  • Un Tampon

    Si $output est un tampon et que "Append" est activé, toutes les données compressées seront ajoutées à la fin de $output. Sinon, $output sera vidé avant que toute donnée ne lui soit écrite.

  • Un Nom de fichier

    Si $output est un nom de fichier et que "Append" est activé, le fichier sera ouvert en mode ajout. Sinon, le contenu du fichier, le cas échéant, sera tronqué avant que toute donnée compressée ne soit écrite dedans.

  • Un Descripteur de fichier

    Si $output est un descripteur de fichier, le pointeur de fichier sera positionné à la fin du fichier via un appel à "seek" avant que toute donnée compressée ne soit écrite dedans. Sinon, le pointeur de fichier ne sera pas déplacé.

Ce paramètre vaut 0 par défaut.

"Merge => 0|1"
Cette option est utilisée pour compresser les données d'entrée et les ajouter à un flux de données compressées existant dans $output. Le résultat final est un flux de données compressées unique stocké dans $output.

Il s'agit d'une erreur fatale d'essayer d'utiliser cette option lorsque $output n'est pas un flux de données RFC 1952.

Il existe un certain nombre d'autres limitations avec l'option "Merge" :

1.
Ce module doit avoir été compilé avec zlib 1.2.1 ou une version ultérieure pour fonctionner. Une erreur fatale sera générée si "Merge" est utilisé avec une version plus ancienne de zlib.
2.
Si $output est un fichier ou un descripteur de fichier, il doit être recherchable (seekable).

Ce paramètre vaut 0 par défaut.

-Level
Définit le niveau de compression utilisé par zlib. La valeur doit être un nombre entre 0 et 9 (0 signifie aucune compression et 9 est la compression maximale), ou l'une des constantes symboliques définies ci-dessous. 
Z_NO_COMPRESSION
Z_BEST_SPEED
Z_BEST_COMPRESSION
Z_DEFAULT_COMPRESSION

La valeur par défaut est Z_DEFAULT_COMPRESSION.

Notez que ces constantes ne sont pas importées par défaut par "IO::Compress::Gzip".

use IO::Compress::Gzip qw(:strategy);
use IO::Compress::Gzip qw(:constants);
use IO::Compress::Gzip qw(:all);
-Strategy
Définit la stratégie utilisée pour ajuster la compression. Utilisez l'une des constantes symboliques définies ci-dessous.

Z_HUFFMAN_ONLY
Z_RLE
Z_FIXED
Z_DEFAULT_STRATEGY

La valeur par défaut est Z_DEFAULT_STRATEGY.

Vide toutes les données compressées en attente puis ferme le fichier/buffer de

Pour la plupart des versions de Perl, cette méthode sera automatiquement invoquée si l'objet IO::Compress::Gzip est détruit (soit explicitement, soit parce que la variable contenant la référence à l'objet sort de sa portée).
