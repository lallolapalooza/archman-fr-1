ImageByteOrder(3)

Paquet: libx11

ImageByteOrder(3) FONCTIONS XLIB ImageByteOrder(3)

NOM

ImageByteOrder, BitmapBitOrder, BitmapPad, BitmapUnit, DisplayHeight, DisplayHeightMM, DisplayWidth, DisplayWidthMM, XListPixmapFormats, XPixmapFormatValues - fonctions et macros de format d'image

SYNTAXE

XPixmapFormatValues *XListPixmapFormats(Display *display, int *count_return);

int ImageByteOrder(Display *display);

int BitmapBitOrder(Display *display);

int BitmapPad(Display *display);

int BitmapUnit(Display *display);

int DisplayHeight(Display *display, int screen_number);

int DisplayHeightMM(Display *display, int screen_number);

int DisplayWidth(Display *display, int screen_number);

int DisplayWidthMM(Display *display, int screen_number);

ARGUMENTS

display
Spécifie la connexion au serveur X.
count_return
Retourne le nombre de formats de pixmap pris en charge par l'affichage.
screen_number
Spécifie le numéro d'écran approprié sur le serveur hôte.

DESCRIPTION

La fonction XListPixmapFormats renvoie un tableau de structures XPixmapFormatValues qui décrivent les types d'images au format Z pris en charge par l'affichage spécifié. Si la mémoire disponible est insuffisante, XListPixmapFormats renvoie NULL. Pour libérer le stockage alloué pour les structures XPixmapFormatValues, utilisez XFree.

La macro ImageByteOrder spécifie l'ordre des octets requis pour les images pour chaque unité de balayage en format XY (bitmap) ou pour chaque valeur de pixel en format Z.

La macro BitmapBitOrder renvoie LSBFirst ou MSBFirst pour indiquer si le bit le plus à gauche de la bitmap telle qu'affichée à l'écran est le bit le moins ou le plus significatif de l'unité.

La macro BitmapPad renvoie le nombre d'octets auquel chaque ligne de balayage doit être complétée.

La macro BitmapUnit renvoie la taille de l'unité de ligne de balayage d'une bitmap en bits.

La macro DisplayHeight renvoie la hauteur de l'écran spécifié en pixels.

La macro DisplayHeightMM renvoie la hauteur de l'écran spécifié en millimètres.

La macro DisplayWidth renvoie la largeur de l'écran en pixels.

La macro DisplayWidthMM renvoie la largeur de l'écran spécifié en millimètres.

STRUCTURES

La structure XPixmapFormatValues fournit une interface aux informations de format de pixmap qui sont renvoyées au moment de la mise en place d'une connexion. Elle contient :

typedef struct {
        int depth;
        int bits_per_pixel;
        int scanline_pad;
} XPixmapFormatValues;
