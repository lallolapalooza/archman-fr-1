NOM

IO::Lines - Interface IO:: pour lire/écrire un tableau de lignes

SYNOPSIS

use IO::Lines;
### Voir IO::ScalarArray pour les détails

DESCRIPTION

Cette classe implémente des objets qui se comportent comme des objets FileHandle (ou IO::Handle), sauf que vous pouvez les utiliser pour écrire dans (ou lire à partir de) un tableau de lignes. Capable de "tiehandle" également.

C'est une sous-classe de IO::ScalarArray dans laquelle le tableau sous-jacent stocke ses données dans un format orienté ligne : c'est-à-dire que chaque élément se termine par un "\n", avec la possible exception du dernier élément. Cela rend getline() beaucoup plus efficace ; si vous prévoyez de faire de la lecture/impression orientée ligne, vous voulez cette classe.

La méthode print() appliquera cette règle, vous pouvez donc imprimer des données arbitraires dans le tableau de lignes : elle scindera les données aux sauts de ligne de manière appropriée.

Voir IO::ScalarArray pour une utilisation complète et des avertissements.
