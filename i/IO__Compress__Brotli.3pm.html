NOM

IO::Compress::Brotli - Écrire des tampons/flux Brotli

SYNTAXE

use IO::Compress::Brotli;
# compresser un tampon
my $encoded = bro $encoded;
# compresser un flux
my $bro = IO::Compress::Brotli->create;
while(have_input()) {
   my $block = get_input_block();
   my $encoded_block = $bro->compress($block);
   handle_output_block($encoded_block);
}
# Il faut finir le flux
handle_output_block($bro->finish());

DESCRIPTION

IO::Compress::Brotli est un module qui compresse des tampons et flux Brotli. Malgré son nom, ce n'est pas une sous-classe de IO::Compress::Base et il n'implémente pas son interface. Ceci sera rectifié dans une future version.

Interface en une seule fois

Si vous avez le tampon entier dans un scalaire Perl, utilisez la fonction bro.

bro($input, $quality, $window)
Prend un tampon non compressé entier en entrée et renvoie les données compressées en utilisant les paramètres de qualité et de fenêtre fournis. Si les paramètres de qualité et de fenêtre ne sont pas fournis, les valeurs par défaut sont utilisées (comme décrit dans l'interface orientée objet).

Exporté par défaut.

Interface de streaming

Si vous souhaitez traiter les données par blocs, utilisez l'interface orientée objet. Les méthodes disponibles sont :

IO::Compress::Brotli->create
Renvoie une instance IO::Compress::Brotli. Veuillez noter qu'une seule instance ne peut pas être utilisée pour décompresser plusieurs flux.
$bro->window($window)
Définit le paramètre de fenêtre sur l'encodeur brotli. La valeur par défaut est BROTLI_DEFAULT_WINDOW (22).
$bro->quality($quality)
Définit le paramètre de qualité sur l'encodeur brotli. La valeur par défaut est BROTLI_DEFAULT_QUALITY (11).
$bro->mode($mode)
Définit le mode de l'encodeur brotli, qui peut être l'un des suivants : "generic", "text" ou "font". La valeur par défaut est "generic".
$bro->compress($block)
Prend un bloc de données non compressées et renvoie un bloc de données compressées. Se termine en cas d'erreur.
$bro->flush()
Vider toute sortie en attente de l'encodeur.
$bro->finish()
Indique à l'encodeur de commencer l'opération de fin et vide toute sortie compressée restante.

Une fois finish appelé, l'encodeur ne peut plus être utilisé pour compresser davantage de contenu.

NOTE : Appeler finish est requis, sinon la sortie pourrait rester non vidée et manquer les marques de terminaison.
