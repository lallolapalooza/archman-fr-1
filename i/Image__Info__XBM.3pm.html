NOM

Image::Info::XBM - Support XBM pour Image::Info

SYNOPSIS

use Image::Info qw(image_info dim);
my $info = image_info("image.xbm");
if (my $error = $info->{error}) {
    die "Impossible de parser les informations de l'image : $error\n";
}
my $color = $info->{color_type};
my($w, $h) = dim($info);

DESCRIPTION

Ce module fournit les noms de clés standards à l'exception de Compression, Gamma, Interlace, LastModificationTime, ainsi que :

HotSpotX
La coordonnée x du point d'accès de l'image. Mis à -1 s'il n'y a pas de point d'accès.
HotSpotY
La coordonnée y du point d'accès de l'image. Mis à -1 s'il n'y a pas de point d'accès.
L1D_Histogram
Référence à un tableau représentant un histogramme de luminance unidimensionnel. Cette clé n'est présente que si "image_info" est appelée comme "image_info($file, L1D_Histogram=>1)". La plage va de 0 à 1.

MÉTHODES

process_file()

$info->process_file($source, $options);

Traite un fichier et définit les champs d'information trouvés dans l'objet $info.

FICHIERS
