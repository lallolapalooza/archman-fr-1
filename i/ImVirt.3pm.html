NOM

ImVirt - détecte plusieurs virtualisations

SYNTAXE

use ImVirt;
print imv_get(IMV_PROB_DEFAULT, imv_detect()),"\n";

DESCRIPTION

Le paquet "ImVirt" essaie de détecter s'il est exécuté dans un conteneur de virtualisation. Au moins les conteneurs suivants devraient être détectés :

ARAnyM
KVM
lguest
LXC
OpenVZ
QEMU
UML
VirtualBox
Virtual PC/Server
VMware
Xen

HEURISTIQUE DE DETECTION

La détection est basée sur une heuristique - vous ne devriez pas faire confiance du tout au résultat.

ImVirt sonde différentes caractéristiques bien connues de différents conteneurs de virtualisation. Toutes les caractéristiques trouvées ou non trouvées sont pondérées par leur importance.

Le résultat de l'heuristique est un arbre pondéré. Les feuilles sont les conteneurs détectés (ou non).

FONCTIONS

Les fonctions suivantes devraient être utilisées pour récupérer les conteneurs de virtualisation détectés :

imv_get($prob) Retourne exactement une chaîne décrivant le conteneur détecté. Si le conteneur détecté a une probabilité de correspondance inférieure à $prob, la chaîne 'Unknown' est retournée.
imv_get_all() Retourne une hash où les clés sont les conteneurs positifs détectés et les valeurs leur probabilité de correspondance correspondante.
imv_get_pos_results() Retourne une liste de tous les résultats possibles qui pourraient être retournés par tous les modules de détection. Les entrées de la liste pourraient être complétées par des données supplémentaires comme des numéros de version, etc.
