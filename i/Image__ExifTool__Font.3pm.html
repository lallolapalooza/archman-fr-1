NOM

Image::ExifTool::Font - Lire les métadonnées des fichiers de polices

SYNTAXE

Ce module est utilisé par Image::ExifTool

DESCRIPTION

Ce module contient les routines requises par Image::ExifTool pour lire les métadonnées de divers formats de fichiers de polices. Les types de fichiers de polices actuellement reconnus sont OTF, TTF, TTC, DFONT, PFA, PFB, PFM, AFM, ACFM et AMFM. De plus, les fichiers de polices WOFF et WOFF2 sont identifiés, mais les métadonnées ne sont actuellement pas extraites de ces formats.
