IO::Socket::INET(3perl) Guide de référence du programmeur Perl IO::Socket::INET(3perl)

NOM

IO::Socket::INET - Interface objet pour les sockets du domaine AF_INET

SYNOPIS

use IO::Socket::INET;

DESCRIPTION

"IO::Socket::INET" fournit une interface objet pour la création et l'utilisation de sockets dans le domaine AF_INET. Il est basé sur l'interface IO::Socket et hérite de toutes les méthodes définies par IO::Socket.

CONSTRUCTEUR

new ( [ARGUMENTS] )
Crée un objet "IO::Socket::INET", qui est une référence à un symbole nouvellement créé (voir le paquet Symbol). "new" accepte éventuellement des arguments, ces arguments sont sous forme de paires clé-valeur.

En plus des paires clé-valeur acceptées par IO::Socket, "IO::Socket::INET" fournit :

PeerAddr    Adresse hôte distante          <nom_hote>[:<port>]
PeerHost    Synonyme de PeerAddr
PeerPort    Port ou service distant        <service>[(<num>)] | <num>
LocalAddr   Adresse de liaison hôte locale   nom_hote[:port]
LocalHost   Synonyme de LocalAddr
LocalPort   Port de liaison hôte locale    <service>[(<num>)] | <num>
Proto       Nom de protocole (ou numéro)    "tcp" | "udp" | ...
Type        Type de socket              SOCK_STREAM | SOCK_DGRAM | ...
Listen      Taille de la file d'attente pour listen
ReuseAddr   Définit SO_REUSEADDR avant bind
Reuse       Définit SO_REUSEADDR avant bind (obsolète,
                                             préférer ReuseAddr)
ReusePort   Définit SO_REUSEPORT avant bind
Broadcast   Définit SO_BROADCAST avant bind
Timeout     Valeur de délai pour diverses opérations
MultiHomed  Essayer toutes les adresses pour les hôtes multi-homed
Blocking    Détermine si la connexion sera en mode bloquant

Si "Listen" est défini, alors un socket d'écoute est créé, sinon si le type de socket, déduit du protocole, est SOCK_STREAM, alors connect() est appelé. Si l'argument "Listen" est donné, mais faux, la taille de la file d'attente sera définie à 5.

Bien que ce ne soit pas illégal, l'utilisation de "MultiHomed" sur un socket qui est en mode non bloquant est d'une utilité limitée. En effet, la première connexion ne renverra jamais une erreur de délai d'attente car l'appel connect ne bloquera pas.

Le "PeerAddr" peut être un nom d'hôte ou l'adresse IP sous la forme "xx.xx.xx.xx". Le "PeerPort" peut être un numéro ou un nom de service symbolique. Le nom de service peut être suivi d'un numéro entre parenthèses qui est utilisé si le service n'est pas connu du système. La spécification "PeerPort" peut également être intégrée dans "PeerAddr" en la faisant précéder d'un ":".

Si "Proto" n'est pas donné et que vous spécifiez un port symbolique "PeerPort", le constructeur essaiera de déduire "Proto" à partir du nom de service. En dernier recours, "Proto" "tcp" est supposé. Le paramètre "Type" sera déduit de "Proto" s'il n'est pas spécifié.

Si le constructeur ne reçoit qu'un seul argument, il est supposé être une spécification "PeerAddr".

Si "Blocking" est défini sur 0, la connexion sera en mode non bloquant. Si non spécifié, il vaut par défaut 1 (mode bloquant).

Exemples :

$sock = IO::Socket::INET->new(PeerAddr => 'www.perl.org',
                              PeerPort => 'http(80)',
                              Proto    => 'tcp');
$sock = IO::Socket::INET->new(PeerAddr => 'localhost:smtp(25)');
$sock = IO::Socket::INET->new(Listen    => 5,
                              LocalAddr => 'localhost',
                              LocalPort => 9000,
                              Proto     => 'tcp');
$sock = IO::Socket::INET->new('127.0.0.1:25');
$sock = IO::Socket::INET->new(
                        PeerPort  => 9999,
                        PeerAddr  => inet_ntoa(INADDR_BROADCAST),
                        Proto     => 'udp',
                        LocalAddr => 'localhost',
                        Broadcast => 1 )
                    or die "Impossible de binder : $IO::Socket::errstr\n";

Si le constructeur échoue, il retournera "undef" et définira la variable paquet $IO::Socket::errstr pour contenir un message d'erreur.

$sock = IO::Socket::INET->new(...)
    or die "Impossible de créer le socket - $IO::Socket::errstr\n";

Pour des raisons de compatibilité, le message d'erreur est également défini dans la variable globale $@, et vous pourriez trouver d'anciens codes qui y regardent à la place.

$sock = IO::Socket::INET->new(...)
    or die "Impossible de créer le socket - $@\n";

MÉTHODES

sockaddr ()
Retourne la partie adresse de la structure sockaddr pour le socket.
sockport ()
Retourne le numéro de port que le socket utilise sur l'hôte local.
sockhost ()
Retourne la partie adresse de la structure sockaddr pour le socket sous forme textuelle xx.xx.xx.xx.
peeraddr ()
Retourne la partie adresse de la structure sockaddr pour le socket sur l'hôte distant.
peerport ()
Retourne le numéro de port pour le socket sur l'hôte distant.
peerhost ()
Retourne la partie adresse de la structure sockaddr pour le socket sur l'hôte distant sous forme textuelle xx.xx.xx.xx.
