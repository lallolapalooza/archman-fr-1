IMPORT FOREIGN SCHEMA(7) Documentation PostgreSQL 18.1 IMPORT FOREIGN SCHEMA(7)

NOM

IMPORT FOREIGN SCHEMA - importer des définitions de table à partir d'un serveur étranger

SYNTAXE

IMPORT FOREIGN SCHEMA schéma_distant
    [ { LIMIT TO | EXCEPT } ( nom_table [, ...] ) ]
    FROM SERVER nom_serveur
    INTO schéma_local
    [ OPTIONS ( option 'valeur' [, ... ] ) ]

DESCRIPTION

IMPORT FOREIGN SCHEMA crée des tables étrangères qui représentent des tables existantes sur un serveur étranger. Les nouvelles tables étrangères appartiendront à l'utilisateur qui exécute la commande et seront créées avec les définitions de colonnes et les options correctes pour correspondre aux tables distantes.

Par défaut, toutes les tables et vues existant dans un schéma particulier sur le serveur étranger sont importées. Optionnellement, la liste des tables peut être limitée à un sous-ensemble spécifié, ou des tables spécifiques peuvent être exclues. Les nouvelles tables étrangères sont toutes créées dans le schéma cible, qui doit déjà exister.

Pour utiliser IMPORT FOREIGN SCHEMA, l'utilisateur doit avoir le privilège USAGE sur le serveur étranger, ainsi que le privilège CREATE sur le schéma cible.

PARAMETRES

schéma_distant

Le schéma distant à importer. La signification exacte d'un schéma distant dépend du wrapper de données étranger utilisé.

LIMIT TO ( nom_table [, ...] )

Importer uniquement les tables étrangères correspondant à l'un des noms de table donnés. Les autres tables existant dans le schéma étranger seront ignorées.

EXCEPT ( nom_table [, ...] )

Exclure les tables étrangères spécifiées de l'importation. Toutes les tables existant dans le schéma étranger seront importées à l'exception de celles listées ici.

nom_serveur

Le serveur étranger à partir duquel importer.

schéma_local

Le schéma dans lequel les tables étrangères importées seront créées.

OPTIONS ( option 'valeur' [, ...] )

Options à utiliser pendant l'importation. Les noms d'options et les valeurs autorisés sont spécifiques à chaque wrapper de données étranger.

EXEMPLES

Importer les définitions de tables du schéma distant foreign_films sur le serveur film_server, en créant les tables étrangères dans le schéma local films :

IMPORT FOREIGN SCHEMA foreign_films
    FROM SERVER film_server INTO films;

Comme ci-dessus, mais importer uniquement les deux tables actors et directors (si elles existent) :

IMPORT FOREIGN SCHEMA foreign_films LIMIT TO (actors, directors)
    FROM SERVER film_server INTO films;

COMPATIBILITE

La commande IMPORT FOREIGN SCHEMA est conforme à la norme SQL, à l'exception de la clause OPTIONS qui est une extension de PostgreSQL.
