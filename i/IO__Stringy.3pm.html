NOM

IO-stringy - E/S sur des objets en mémoire tels que des chaînes et des tableaux

SYNOPSIS

use strict;
use warnings;
use IO::AtomicFile; # Écrit un fichier qui est mis à jour atomiquement
use IO::InnerFile; # Définit un fichier à l'intérieur d'un autre fichier
use IO::Lines; # Descripteur d'E/S pour lire/écrire dans un tableau de lignes
use IO::Scalar; # Descripteur d'E/S pour lire/écrire dans une chaîne
use IO::ScalarArray; # Descripteur d'E/S pour lire/écrire dans un tableau de scalaires
use IO::Wrap; # Enveloppe les anciens descripteurs FH dans une interface OO standard
use IO::WrapTie; # Attache vos descripteurs et conserve une interface OO complète
# ...

DESCRIPTION

Cette boîte à outils fournit principalement des modules pour effectuer des E/S traditionnelles et orientées objet) sur des éléments *autres* que des descripteurs de fichiers normaux ; en particulier, IO::Scalar, IO::ScalarArray et IO::Lines.

Du côté plus traditionnel d'IO::Handle, nous avons IO::AtomicFile qui peut être utilisé pour créer sans douleur des fichiers qui sont mis à jour atomiquement.

Et dans le coin "cela pourrait s'avérer utile", nous avons IO::Wrap, dont la fonction exportée wraphandle() habillera tout ce qui n'est pas un objet béni dans un wrapper de type IO::Handle... vous pouvez donc simplement utiliser la syntaxe OO et arrêter de vous soucier de savoir si l'appelant de votre fonction vous a donné une chaîne, une référence glob ou un descripteur de fichier.
