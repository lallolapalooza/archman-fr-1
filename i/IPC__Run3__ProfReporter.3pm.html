NOM

IPC::Run3::ProfReporter - classe de base pour le traitement des données de profilage

SYNOPSIS

DESCRIPTION

Voir IPC::Run3::ProfPP et pour un exemple de sous-classe.

Cette classe enregistre et accumule simplement les temps ; les sous-classes utilisent des méthodes comme "handle_app_call", "handle_run_exit" et "handle_app_exit" pour émettre des rapports à ce sujet. Les méthodes par défaut pour ces gestionnaires sont des noops.

Si exécutée depuis la ligne de commande, un rapporteur sera créé et exécuté sur chaque fichier journal donné comme paramètre de ligne de commande ou sur run3.out si aucun n'est donné.

Cela permet d'exécuter des rapports comme ceci :

perl -MIPC::Run3::ProfPP -e1
perl -MIPC::Run3::ProfPP -e1 foo.out bar.out

Utilisez "-" pour lire depuis STDIN (le format du fichier journal est destiné à être modérément interrogeable) :

grep "^cvs " run3.out perl -MIPC::Run3::ProfPP -e1 -

Utilisez --app pour afficher uniquement les statistiques au niveau de l'application (c'est-à-dire ne pas émettre de section de rapport pour chaque commande exécutée).

MÉTHODES

"IPC::Run3::ProfReporter->new"
Retourne un nouvel objet de rapport de profil.
"$reporter->handle_app_call( ... )"
"$reporter->handle_app_exit( ... )"
"$reporter->handle_run_exit( ... )"
Ces méthodes sont appelées par les événements gérés (voir ci-dessous).
"$reporter->app_call($cmd, $time)"
"$reporter->app_exit($time)"
"$reporter->run_exit(@times)"
$self->app_call( $time );
my $time = $self->get_app_call_time;

Définit le temps (en secondes flottantes) auquel l'application, run3() ou system() a été appelée ou s'est terminée. Si aucun paramètre de temps n'est passé, utilise la routine de temps d'IPC::Run3.

Utilisez get_...() pour récupérer ces valeurs (et les valeurs _accum, aussi). C'est une méthode distincte pour accélérer légèrement le temps d'exécution des setters.

"$reporter->get_run_count()"
"$reporter->get_app_call_time()"
"$reporter->get_app_exit_time()"
"$reporter->get_app_cmd()"
"$reporter->get_app_time()"
"$reporter->get_app_cumulative_time()"
"$reporter->get_run_call_time()"
"$reporter->get_run_exit_time()"
"$reporter->get_run_time()"
"$reporter->get_run_cumulative_time()"
"$reporter->get_sys_call_time()"
"$reporter->get_sys_exit_time()"
"$reporter->get_sys_time()"
"$reporter->get_sys_cumulative_time()"
"$reporter->get_run_cmd()"
