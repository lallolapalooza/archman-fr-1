IO::Pager::less(3) Documentation Perl contribuée par l'utilisateur IO::Pager::less(3)

NOM

IO::Pager::less - Pas de pager ? Canalise la sortie vers un pager basé sur Perl sur un TTY

SYNOPIS

{
  # Peut être instancié fonctionnellement ou en mode objet, comme les autres sous-classes.
  my $token = new IO::Pager::less;
  $token->print("Pure perl goodness...\n") while 1;
}

DESCRIPTION

IO::Pager::less est un pager simple, extensible, basé sur Perl.

Voir IO::Pager pour les détails des méthodes.

MÉTHODES

Toutes les méthodes sont héritées de IO::Pager ; sauf pour l'instanciation et print.

VOIR AUSSI

IO::Pager, Term::Pager, IO::Pager::Buffered, IO::Pager::Page,
