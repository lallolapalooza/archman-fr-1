Module Int64
: sig end

Entiers sur 64 bits.

Ce module fournit des opérations sur le type int64 des entiers signés sur 64 bits. Contrairement au type intégré int , le type int64 est garanti d'avoir exactement 64 bits de large sur toutes les plateformes. Toutes les opérations arithmétiques sur int64 sont effectuées modulo 2^64

Remarque de performance : les valeurs de type int64 occupent plus d'espace mémoire que les valeurs de type int , et les opérations arithmétiques sur int64 sont généralement plus lentes que celles sur int . Utilisez int64 uniquement lorsque l'application nécessite une arithmétique exacte sur 64 bits.

Les littéraux pour les entiers sur 64 bits sont suffixés par L :

      let zero: int64 = 0L
      let one: int64 = 1L
      let m_one: int64 = -1L

L'entier 64 bits 1.

L'entier 64 bits -1.

Négation unaire.

Addition.

val sub : int64 -> int64 -> int64

Soustraction.

val mul : int64 -> int64 -> int64

Multiplication.

val div : int64 -> int64 -> int64

Division entière.

Lève Division_by_zero si le second argument est zéro. Cette division arrondit le quotient réel de ses arguments vers zéro, comme spécifié pour (/) .

val unsigned_div : int64 -> int64 -> int64

Identique à Int64.div , sauf que les arguments et le résultat sont interprétés comme des entiers non signés sur 64 bits.

Depuis 4.08

val rem : int64 -> int64 -> int64

Reste entier. Si y n'est pas zéro, le résultat de Int64.rem x y satisfait la propriété suivante : x = Int64.add (Int64.mul (Int64.div x y) y) (Int64.rem x y) . Si y = 0 , Int64.rem x y lève Division_by_zero .

val unsigned_rem : int64 -> int64 -> int64

Identique à Int64.rem , sauf que les arguments et le résultat sont interprétés comme des entiers non signés sur 64 bits.

Depuis 4.08

val succ : int64 -> int64

Successeur. Int64.succ x est Int64.add x Int64.one .

val pred : int64 -> int64

Prédécesseur. Int64.pred x est Int64.sub x Int64.one .

val abs : int64 -> int64

abs x est la valeur absolue de x . Sur min_int , c'est min_int lui-même et reste donc négatif.

val max_int : int64

Le plus grand entier 64 bits représentable, 2^63 - 1.

val min_int : int64

Le plus petit entier 64 bits représentable, -2^63.

val logand : int64 -> int64 -> int64

ET logique par bit.

val logor : int64 -> int64 -> int64

OU logique par bit.

val logxor : int64 -> int64 -> int64

OU exclusif logique par bit.

val lognot : int64 -> int64

Négation logique par bit.

val shift_left : int64 -> int -> int64

Int64.shift_left x y décale x vers la gauche de y bits. Le résultat est indéfini si y < 0 ou y >= 64 .

val shift_right : int64 -> int -> int64

Int64.shift_right x y décale x vers la droite de y bits. Ceci est un décalage arithmétique : le bit de signe de x est répliqué et inséré dans les bits libérés. Le résultat est indéfini si y < 0 ou y >= 64 .

val shift_right_logical : int64 -> int -> int64

Int64.shift_right_logical x y décale x vers la droite de y bits. Ceci est un décalage logique : des zéros sont insérés dans les bits libérés quel que soit le signe de x . Le résultat est indéfini si y < 0 ou y >= 64 .

val of_int : int -> int64

Convertit l'entier donné (type int ) en un entier sur 64 bits (type int64 ).

val to_int : int64 -> int

Convertit l'entier 64 bits donné (type int64 ) en un entier (type int ). Sur les plateformes 64 bits, l'entier 64 bits est pris modulo 2^63, c'est-à-dire que le bit de poids fort est perdu lors de la conversion. Sur les plateformes 32 bits, l'entier 64 bits est pris modulo 2^31, c'est-à-dire que les 33 bits de poids fort sont perdus lors de la conversion.

val unsigned_to_int : int64 -> int option

Identique à Int64.to_int , mais interprète l'argument comme un entier non signé. Retourne None si la valeur non signée de l'argument ne peut pas tenir dans un int .

Depuis 4.08

val of_float : float -> int64

Convertit le nombre flottant donné en un entier sur 64 bits, en écartant la partie fractionnaire (troncature vers 0). Si le nombre flottant tronqué est en dehors de l'intervalle [ Int64.min_int , Int64.max_int ], aucune exception n'est levée, et un entier indéfini, dépendant de la plateforme, est retourné.

val to_float : int64 -> float

Convertit l'entier 64 bits donné en un nombre flottant.

val of_int32 : int32 -> int64

Convertit l'entier 32 bits donné (type int32 ) en un entier sur 64 bits (type int64 ).

val to_int32 : int64 -> int32

Convertit l'entier 64 bits donné (type int64 ) en un entier sur 32 bits (type int32 ). L'entier 64 bits est pris modulo 2^32, c'est-à-dire que les 32 bits de poids fort sont perdus lors de la conversion.

val of_nativeint : nativeint -> int64

Convertit l'entier natif donné (type nativeint ) en un entier sur 64 bits (type int64 ).

val to_nativeint : int64 -> nativeint

Convertit l'entier 64 bits donné (type int64 ) en un entier natif. Sur les plateformes 32 bits, l'entier 64 bits est pris modulo 2^32. Sur les plateformes 64 bits, la conversion est exacte.

val of_string : string -> int64

Convertit la chaîne donnée en un entier sur 64 bits. La chaîne est lue en décimal (par défaut, ou si la chaîne commence par 0u ) ou en hexadécimal, octal ou binaire si la chaîne commence par 0x , 0o ou 0b respectivement.

Le 0u préfixe lit l'entrée comme un entier non signé dans l'intervalle [0, 2*Int64.max_int+1] . Si l'entrée dépasse Int64.max_int elle est convertie en l'entier signé Int64.min_int + input - Int64.max_int - 1 .

Le _ (soulignement) peut apparaître n'importe où dans la chaîne et est ignoré.

Lève Failure si la chaîne donnée n'est pas une représentation valide d'un entier, ou si l'entier représenté dépasse l' intervalle des entiers représentables dans le type int64 .

val of_string_opt : string -> int64 option

Identique à of_string , mais retourne None au lieu de lever une exception.

Depuis 4.05

val to_string : int64 -> string

Retourne la représentation sous forme de chaîne de son argument, en décimal.

val bits_of_float : float -> int64

Retourne la représentation interne du flottant donné selon la disposition des bits du 'format double' flottant IEEE 754. Le bit 63 du résultat représente le signe du flottant ; les bits 62 à 52 représentent l'exposant (biaisé) ; les bits 51 à 0 représentent la mantisse.

val float_of_bits : int64 -> float

Retourne le nombre flottant dont la représentation interne, selon la disposition des bits du 'format double' flottant IEEE 754, est le donné int64 .

Identique à Int64.compare , sauf que les arguments sont interprétés comme des entiers 64 bits non signés.
