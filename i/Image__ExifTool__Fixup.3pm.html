NOM

Image::ExifTool::Fixup - Utilitaire pour gérer les corrections de pointeurs

SYNOPSIS

use Image::ExifTool::Fixup;
$fixup = Image::ExifTool::Fixup->new;
# ajouter une nouvelle correction à un pointeur à l'offset spécifié dans les données
$fixup->AddFixup($offset);
# ajouter un nouvel objet Fixup à l'arbre
$fixup->AddFixup($subFixup);
$fixup->{Start} += $shift1;   # décaler les offsets et valeurs des pointeurs
$fixup->{Shift} += $shift2;   # décaler les valeurs des pointeurs uniquement
# appliquer récursivement les corrections aux données spécifiées
$fixup->ApplyFixups(\$data);
$fixup->Dump();               # afficher les informations de débogage
$fixup->IsEmpty();            # retourner vrai s'il n'y a pas d'offsets à corriger

DESCRIPTION

Ce module contient le code permettant de suivre les pointeurs en mémoire et de décaler ces pointeurs comme requis. Il est utilisé par ExifTool pour maintenir les pointeurs dans les répertoires de fichiers image (IFD).

NOTES

Suit les pointeurs avec différents ordres d'octets et s'appuie sur Image::ExifTool::GetByteOrder() pour déterminer l'ordre d'octets actuel lors de l'ajout de nouveaux pointeurs à une correction.

Maintient une liste hiérarchique de corrections de sorte que toute la hiérarchie puisse être décalée par un simple décalage à la base. La hiérarchie est réduite à une liste linéaire lorsque ApplyFixups() est appelé.
