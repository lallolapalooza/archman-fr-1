IO::Dir(3perl) Guide de référence du programmeur Perl IO::Dir(3perl)

NOM

IO::Dir - fournir des méthodes d'objet pour les descripteurs de répertoire

SYNTAXE

use IO::Dir;
my $d = IO::Dir->new(".");
if (defined $d) {
    while (defined($_ = $d->read)) { something($_); }
    $d->rewind;
    while (defined($_ = $d->read)) { something_else($_); }
    undef $d;
}
tie my %dir, 'IO::Dir', ".";
foreach (keys %dir) {
    print $_, " " , $dir{$_}->size,"\n";
}

DESCRIPTION

Le paquet "IO::Dir" fournit deux interfaces aux routines de lecture de répertoire de perl.

La première interface est une approche objet. "IO::Dir" fournit un constructeur d'objet et des méthodes, qui ne sont que des enveloppes autour des routines de lecture de répertoire intégrées de perl.

new ( [ NOM_DIR ] )
"new" est le constructeur pour les objets "IO::Dir". Il accepte un argument optionnel qui, s'il est fourni, sera passé par "new" à "open".

Les méthodes suivantes sont des enveloppes pour les fonctions liées aux répertoires intégrées à perl (le 'dir' final a été supprimé des noms). Voir perlfunc pour les détails de ces fonctions.

open ( NOM_DIR )
read ()
seek ( POS )
tell ()
rewind ()
close ()

"IO::Dir" fournit également une interface pour lire les répertoires via une table de hachage liée (tied hash). La table de hachage liée étend l'interface au-delà des simples routines de lecture de répertoire en utilisant "lstat", du paquet "File::stat", "unlink", "rmdir" et "utime".

tie %hash, 'IO::Dir', NOM_DIR [, OPTIONS ]

Les clés de la table de hachage seront les noms des entrées dans le répertoire. La lecture d'une valeur de la table de hachage sera le résultat de l'appel à "File::stat::lstat". La suppression d'un élément de la table de hachage supprimera le fichier ou le sous-répertoire correspondant, à condition que "DIR_UNLINK" soit inclus dans les "OPTIONS".

L'assignation à une entrée de la table de hachage modifiera les horodatages du fichier. Si le fichier n'existe pas, il sera créé. L'assignation d'un entier unique à un élément de la table de hachage modifiera à la fois les temps d'accès et de modification à cette valeur. Alternativement, une référence à un tableau de deux valeurs peut être passée. Le premier élément du tableau sera utilisé pour définir le temps d'accès et le second élément sera utilisé pour définir le temps de modification.
