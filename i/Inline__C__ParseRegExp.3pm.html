NOM

Inline::C::ParseRegExp - Le nouveau et amélioré analyseur de Inline::C

SYNOPSIS

use Inline C => DATA =>
           USING => ParseRegExp;

DESCRIPTION

Ce module est une version beaucoup plus rapide de l'analyseur Parse::RecDescent de Inline::C. Il est basé sur des expressions régulières à la place.
