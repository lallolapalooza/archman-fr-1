NOM

IO::Socket::UNIX - Interface objet pour les sockets de domaine AF_UNIX

SYNOPIS

use IO::Socket::UNIX;
my $SOCK_PATH = "$ENV{HOME}/unix-domain-socket-test.sock";
# Serveur :
my $server = IO::Socket::UNIX->new(
    Type => SOCK_STREAM(),
    Local => $SOCK_PATH,
    Listen => 1,
);
my $count = 1;
while (my $conn = $server->accept()) {
    $conn->print("Bonjour " . ($count++) . "\n");
}
# Client :
my $client = IO::Socket::UNIX->new(
    Type => SOCK_STREAM(),
    Peer => $SOCK_PATH,
);
# Lisez et écrivez maintenant depuis $client

DESCRIPTION

"IO::Socket::UNIX" fournit une interface objet pour la création et l'utilisation de sockets dans le domaine AF_UNIX. Il est construit sur l'interface IO::Socket et hérite de toutes les méthodes définies par IO::Socket.

CONSTRUCTEUR

new ( [ARGS] )
Crée un objet "IO::Socket::UNIX", qui est une référence vers un symbole nouvellement créé (voir le package Symbol). "new" accepte éventuellement des arguments, ces arguments sont sous forme de paires clé-valeur.

En plus des paires clé-valeur acceptées par IO::Socket, "IO::Socket::UNIX" fournit.

Type        Type de socket (par ex. SOCK_STREAM ou SOCK_DGRAM)
Local       Chemin d'accès au FIFO local
Peer        Chemin d'accès au FIFO pair
Listen      Taille de la file d'attente pour listen

Si le constructeur ne reçoit qu'un seul argument, il est supposé être une spécification de "Peer".

Si l'argument "Listen" est donné, mais faux, la taille de la file d'attente sera définie à 5.

Si le constructeur échoue, il retournera "undef" et définira la variable de package $IO::Socket::errstr pour contenir un message d'erreur.

$sock = IO::Socket::UNIX->new(...)
    or die "Impossible de créer le socket - $IO::Socket::errstr\n";

Pour des raisons de compatibilité, le message d'erreur est aussi placé dans la variable globale $@, et vous pourriez encore trouver d'anciens codes qui regardent ici à la place.

$sock = IO::Socket::UNIX->new(...)
    or die "Impossible de créer le socket - $@\n";

MÉTHODES

hostpath()
Retourne le chemin d'accès au fifo à l'extrémité locale
peerpath()
Retourne le chemin d'accès au fifo à l'extrémité pair
