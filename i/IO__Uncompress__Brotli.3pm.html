NOM

IO::Uncompress::Brotli - Lire des tampons/flux Brotli

SYNTAXE

use IO::Uncompress::Brotli;
# décompresser un tampon (renvoyant au maximum 10 Mo)
my $decoded = unbro $encoded, 10_000_000;
# décompresser un flux
my $bro = IO::Uncompress::Brotli->create;
while(have_input()) {
   my $block = get_input_block();
   my $decoded_block = $bro->decompress($block);
   handle_output_block($decoded_block);
}

DESCRIPTION

IO::Uncompress::Brotli est un module qui décompresse les tampons et les flux Brotli. Malgré son nom, ce n'est pas une sous-classe de IO::Uncompress::Base et il n'implémente pas son interface. Cela sera corrigé dans une future version.

Interface en une seule fois

Si vous avez l'intégralité du tampon dans un scalaire Perl, utilisez la fonction unbro.

unbro($input, $maximum_decoded_size)
Prend un tampon compressé entier en entrée et renvoie les données décompressées. Il alloue un tampon de taille $maximum_decoded_size pour stocker les données décompressées, si ce n'est pas suffisant (ou en cas d'une autre erreur) cette fonction provoquera un croak.

Depuis la version 0.004_002, l'argument $maximum_decoded_size est optionnel. S'il n'est pas fourni, unbro utilise l'interface de streaming décrite dans la section suivante pour décompresser le tampon par blocs d'un mégaoctet. Les blocs décompressés sont concaténés et renvoyés.

Exporté par défaut.

Interface de streaming

Si vous souhaitez traiter les données par blocs, utilisez l'interface orientée objet. Les méthodes disponibles sont :

IO::Uncompress::Brotli->create
Renvoie une instance de IO::Uncompress::Brotli. Veuillez noter qu'une seule instance ne peut pas être utilisée pour décompresser plusieurs flux.
$bro->decompress($block)
Prend un bloc de données compressées et renvoie un bloc de données non compressées. Provoque un croak en cas d'erreur.
