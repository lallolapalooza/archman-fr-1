Module Iarray
: sig end

Opérations sur les tableaux immuables. Ce module reprend l'API de Array , mais omet les fonctions qui supposent la mutabilité ; en plus des fonctions manifestement mutables, il omet copy ainsi que les fonctions make , create_float , et make_matrix qui produisent des tableaux entièrement constants. La seule exception concerne les fonctions de tri, qui sont dotées d'une API de copie pour remplacer l'API sur place.

type 'a t = 'a iarray

Un alias pour le type des tableaux immuables.

val length : 'a iarray -> int

Retourne la longueur (nombre d'éléments) du tableau immuable donné.

val get : 'a iarray -> int -> 'a

get a n retourne l'élément numéro n du tableau immuable a . Le premier élément a le numéro 0. Le dernier élément a le numéro length a - 1 .

Raises Invalid_argument si n est en dehors de l'intervalle 0 à (length a - 1) .

val init : int -> (int -> 'a) -> 'a iarray

init n f retourne un nouveau tableau immuable de longueur n , dont l'élément numéro i est initialisé au résultat de f i . Autrement dit, init n f représente sous forme de tableau les résultats de f appliqués aux entiers 0 à n-1 .

Raises Invalid_argument si n < 0 ou n > Sys.max_array_length . Si le type de retour de f est float , la taille maximale n'est que Sys.max_array_length / 2 .

val append : 'a iarray -> 'a iarray -> 'a iarray

append v1 v2 retourne un nouveau tableau immuable contenant la concaténation des tableaux immuables v1 et v2 .

Raises Invalid_argument si length v1 + length v2 > Sys.max_array_length .

val concat : 'a iarray list -> 'a iarray

Identique à Iarray.append , mais concatène une liste de tableaux immuables.

val sub : 'a iarray -> pos:int -> len:int -> 'a iarray

sub a ~pos ~len retourne un nouveau tableau immuable de longueur len , contenant les éléments numéro pos à pos + len - 1 du tableau immuable a . Ceci crée une copie de la partie sélectionnée du tableau immuable.

Raises Invalid_argument si pos et len ne désignent pas un sous-tableau valide de a ; c'est-à-dire si pos < 0 , ou len < 0 , ou pos + len > length a .

val to_list : 'a iarray -> 'a list

to_list a retourne la liste de tous les éléments de a .

val of_list : 'a list -> 'a iarray

of_list l retourne un nouveau tableau immuable contenant les éléments de l .

Raises Invalid_argument si la longueur de l est supérieure à Sys.max_array_length .

Conversion vers et depuis les tableaux mutables

val to_array : 'a iarray -> 'a array

to_array a retourne une copie mutable du tableau immuable a ; c'est-à-dire un nouveau tableau (mutable) contenant les mêmes éléments que a

val of_array : 'a array -> 'a iarray

of_array ma retourne une copie immuable du tableau mutable ma ; c'est-à-dire un nouveau tableau immuable contenant les mêmes éléments que ma

Comparaison

val equal : ('a -> 'a -> bool) -> 'a iarray -> 'a iarray -> bool

eq [|a1; ...; an|] [|b1; ..; bm|] est vrai lorsque les deux tableaux immuables d'entrée ont la même longueur, et que pour chaque paire d'éléments ai, bi à la même position, on a eq ai bi .

val compare : ('a -> 'a -> int) -> 'a iarray -> 'a iarray -> int

À condition que la fonction cmp définisse un préordre sur les éléments, compare cmp a b compare d'abord a et b par leur longueur, puis, s'ils sont égaux, par leurs éléments selon le préordre lexicographique.

Pour plus de détails sur les fonctions de comparaison, voir Iarray.sort .

Itérateurs

val iter : ('a -> unit) -> 'a iarray -> unit

iter f a applique la fonction f successivement à tous les éléments de a . C'est équivalent à f (get a 0); f (get a 1); ...; f (get a (length a - 1)); () .

val iteri : (int -> 'a -> unit) -> 'a iarray -> unit

Identique à Iarray.iter , mais la fonction est appliquée à l'indice de l'élément comme premier argument, et à l'élément lui-même comme second argument.

val map : ('a -> 'b) -> 'a iarray -> 'b iarray

map f a applique la fonction f à tous les éléments de a , et construit un tableau immuable avec les résultats renvoyés par f : [| f (get a 0); f (get a 1); ...; f (get a (length a - 1)) |] .

val mapi : (int -> 'a -> 'b) -> 'a iarray -> 'b iarray

Identique à Iarray.map , mais la fonction est appliquée à l'indice de l'élément comme premier argument, et à l'élément lui-même comme second argument.

val fold_left : ('a -> 'b -> 'a) -> 'a -> 'b iarray -> 'a

fold_left f init a calcule f (... (f (f init (get a 0)) (get a 1)) ...) (get a n-1) , où n est la longueur du tableau immuable a .

val fold_left_map : ('a -> 'b -> 'a * 'c) -> 'a -> 'b iarray -> 'a * 'c iarray

fold_left_map est une combinaison de Iarray.fold_left et Iarray.map qui fait passer un accumulateur à travers les appels à f .

val fold_right : ('b -> 'a -> 'a) -> 'b iarray -> 'a -> 'a

fold_right f a init calcule f (get a 0) (f (get a 1) ( ... (f (get a (n-1)) init) ...)) , où n est la longueur du tableau immuable a .

Itérateurs sur deux tableaux

val iter2 : ('a -> 'b -> unit) -> 'a iarray -> 'b iarray -> unit

iter2 f a b applique la fonction f à tous les éléments de a et b .

Raises Invalid_argument si les tableaux immuables n'ont pas la même taille.

val map2 : ('a -> 'b -> 'c) -> 'a iarray -> 'b iarray -> 'c iarray

map2 f a b applique la fonction f à tous les éléments de a et b , et construit un tableau immuable avec les résultats renvoyés par f : [| f (get a 0) (get b 0);
...;
f (get a (length a - 1)) (get b (length b - 1))|] .

Raises Invalid_argument si les tableaux immuables n'ont pas la même taille.

Scan de tableaux

val for_all : ('a -> bool) -> 'a iarray -> bool

for_all f [|a1; ...; an|] vérifie si tous les éléments du tableau immuable satisfont le prédicat f . C'est-à-dire, cela retourne (f a1) && (f a2) && ... && (f an) .

val exists : ('a -> bool) -> 'a iarray -> bool

exists f [|a1; ...; an|] vérifie si au moins un élément du tableau immuable satisfait le prédicat f . C'est-à-dire, cela retourne (f a1) || (f a2) || ... || (f an) .

val for_all2 : ('a -> 'b -> bool) -> 'a iarray -> 'b iarray -> bool

Identique à Iarray.for_all , mais pour un prédicat à deux arguments.

Raises Invalid_argument si les deux tableaux immuables ont des longueurs différentes.

val exists2 : ('a -> 'b -> bool) -> 'a iarray -> 'b iarray -> bool

val mem : 'a -> 'a iarray -> bool

mem a set est vrai si et seulement si a est structurellement égal à un élément de l (c'est-à-dire qu'il existe un x dans l tel que compare a x = 0 ).

val memq : 'a -> 'a iarray -> bool

Identique à Iarray.mem , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les éléments du tableau.

val find_opt : ('a -> bool) -> 'a iarray -> 'a option

find_opt f a renvoie le premier élément du tableau immuable a qui satisfait le prédicat f , ou None s'il n'existe aucune valeur satisfaisant f dans le tableau a .

val find_index : ('a -> bool) -> 'a iarray -> int option

find_index f a renvoie Some i , où i est l'index du premier élément du tableau a qui satisfait f x , si un tel élément existe.

Elle renvoie None si un tel élément n'existe pas.

val find_map : ('a -> 'b option) -> 'a iarray -> 'b option

find_map f a applique f aux éléments de a dans l'ordre, et renvoie le premier résultat de la forme Some v , ou None si aucun n'existe.

val find_mapi : (int -> 'a -> 'b option) -> 'a iarray -> 'b option

Identique à find_map , mais le prédicat est appliqué à l'index de l'élément comme premier argument (compté à partir de 0), et à l'élément lui-même comme second argument.

Tableaux de paires

val split : ('a * 'b) iarray -> 'a iarray * 'b iarray

split [|(a1,b1); ...; (an,bn)|] est ([|a1; ...; an|], [|b1; ...; bn|]) .

val combine : 'a iarray -> 'b iarray -> ('a * 'b) iarray

combine [|a1; ...; an|] [|b1; ...; bn|] est [|(a1,b1); ...; (an,bn)|] . Lève Invalid_argument si les deux tableaux immuables ont des longueurs différentes.

Tri

val sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Trie un tableau immuable par ordre croissant selon une fonction de comparaison. La fonction de comparaison doit renvoyer 0 si ses arguments sont considérés comme égaux, un entier positif si le premier est plus grand, et un entier négatif si le premier est plus petit (voir ci-dessous pour une spécification complète). Par exemple, compare est une fonction de comparaison appropriée. Le résultat de l'appel à sort est un nouveau tableau immuable contenant les mêmes éléments que l'original, triés par ordre croissant. En dehors de ce nouveau tableau, sort est garanti de s'exécuter en espace de tas constant et en espace de pile (au plus) logarithmique.

L'implémentation actuelle utilise le tri par tas. Elle s'exécute en espace de pile constant.

Spécification de la fonction de comparaison : Soit a le tableau immuable et cmp la fonction de comparaison. Les conditions suivantes doivent être vraies pour tout x , y , z dans a :

- cmp x y > 0 si et seulement si cmp y x < 0

- si cmp x y >= 0 et cmp y z >= 0 alors cmp x z >= 0

Le résultat de sort , que nous appellerons a' , contient les mêmes éléments que a , réordonnés de telle sorte que pour tout i et j indices valides de a (ou de manière équivalente, de a' ):

- cmp (get a' i) (get a' j) >= 0 si et seulement si i >= j

val stable_sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Identique à Iarray.sort , mais l'algorithme de tri est stable (c'est-à-dire que les éléments considérés comme égaux conservent leur ordre d'origine) et n'est pas garanti de s'exécuter en espace de tas constant.

L'implémentation actuelle utilise le tri fusion. Elle utilise un tableau temporaire de longueur n/2 , où n est la longueur du tableau immuable. Elle est généralement plus rapide que l'implémentation actuelle de Iarray.sort .

val fast_sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Identique à Iarray.sort ou Iarray.stable_sort , selon ce qui est le plus rapide sur des entrées typiques.
