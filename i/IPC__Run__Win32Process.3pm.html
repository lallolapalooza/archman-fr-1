NOM

IPC::Run::Win32Process -- livre des lignes de commande non standard via IPC::Run.

SYNOPSIS

use File::Spec ();
use IPC::Run qw(run);
use IPC::Run::Win32Process ();
use Win32 ();
$find_exe = File::Spec->catfile(Win32::GetFolderPath(Win32::CSIDL_SYSTEM),
                                'find.exe');
run(IPC::Run::Win32Process->new($ENV{COMSPEC}, q{cmd.exe /c echo ""}),
    '|', IPC::Run::Win32Process->new($find_exe, q{find_exe """"""}),
    '>', \$out);

DESCRIPTION

Cette classe facilite l'exécution de programmes Windows qui n'utilisent pas les règles d'analyse de ligne de commande standard https://docs.microsoft.com/en-us/cpp/cpp/main-function-command-line-args#parsing-c-command-line-arguments. Les programmes notables ayant des règles non standard incluent cmd.exe, cscript.exe, et les programmes Cygwin appelés depuis des programmes non-Cygwin. IPC::Run utilisera les deux chaînes, telles quelles, comme arguments lpApplicationName et lpCommandLine de CreateProcessA(). Ceci fournit un contrôle non filtré sur la ligne de commande du processus enfant.

FONCTIONS & MÉTHODES
