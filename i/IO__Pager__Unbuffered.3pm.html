IO::Pager::Unbuffered(3) Documentation Perl Contribuée par l'Utilisateur IO::Pager::Unbuffered(3)

NOM

IO::Pager::Unbuffered - Transmet la sortie à PAGER si la destination est un TTY

SYNOP.

use IO::Pager::Unbuffered;
{
  local $STDOUT = IO::Pager::Unbuffered::open *STDOUT;
  print <<"  HEREDOC" ;
  ...
  Un tas de texte plus tard
  HEREDOC
}
{
  # Vous pouvez aussi utiliser des poignées de fichier scalaires...
  my $token = IO::Pager::Unbuffered::open($FH) or warn($!);
  print $FH "Pas de globs ni de barewords pour nous, merci !\n" while 1;
}
{
  # ...ou une interface objet
  my $token = new IO::Pager::Unbuffered;
  $token->print("OO brillant...\n") while 1;
}

DESCRIPTION

Les sous-classes de IO::Pager sont conçues pour décider programmablement si, oui ou non, il faut rediriger la sortie d'une poignée de fichier vers un programme spécifié dans PAGER ; déterminé et défini par IO::Pager au moment de l'exécution s'il n'est pas encore défini.

Voir IO::Pager pour les détails des méthodes.

MÉTHODES

Toutes les méthodes sont héritées de IO::Pager ; sauf l'instanciation.

AVERTISSEMENTS

Vous voudrez probablement faire quelque chose avec SIGPIPE, par exemple ;

eval {
  local $SIG{PIPE} = sub { die };
  local $STDOUT = IO::Pager::open(*STDOUT);
  while (1) {
    # Faire quelque chose
  }
}
# Faire autre chose
