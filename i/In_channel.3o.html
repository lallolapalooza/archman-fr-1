Module In_channel
: sig end

Canaux d'entrée.

Ce module fournit des fonctions pour travailler avec les canaux d'entrée.

Voir In_channel.examples ci-dessous.

Depuis 4.14

Canaux

type t = in_channel

Le type de canal d'entrée.

type open_flag = open_flag =
| Open_rdonly (* ouverture en lecture seule.
*)
| Open_wronly (* ouverture en écriture seule.
*)
| Open_append (* ouverture en mode ajout : toujours écrire à la fin du fichier.
*)
| Open_creat (* créer le fichier s'il n'existe pas.
*)
| Open_trunc (* vider le fichier s'il existe déjà.
*)
| Open_excl (* échec si Open_creat et que le fichier existe déjà.
*)
| Open_binary (* ouverture en mode binaire (pas de conversion).
*)
| Open_text (* ouverture en mode texte (peut effectuer des conversions).
*)
| Open_nonblock (* ouverture en mode non bloquant.
*)

Modes d'ouverture pour In_channel.open_gen .

val stdin : t

L'entrée standard du processus.

val open_bin : string -> t

Ouvre le fichier nommé en lecture et retourne un nouveau canal d'entrée sur ce fichier, positionné au début du fichier.

val open_text : string -> t

Identique à In_channel.open_bin , mais le fichier est ouvert en mode texte, de sorte que la traduction des sauts de ligne a lieu pendant les lectures. Sur les systèmes d'exploitation qui ne distinguent pas le mode texte du mode binaire, cette fonction se comporte comme In_channel.open_bin .

val open_gen : open_flag list -> int -> string -> t

open_gen mode perm filename ouvre le fichier nommé en lecture, comme décrit ci-dessus. Les arguments supplémentaires mode et perm spécifient le mode d'ouverture et les permissions du fichier. In_channel.open_text et In_channel.open_bin sont des cas particuliers de cette fonction.

val with_open_bin : string -> (t -> 'a) -> 'a

with_open_bin fn f ouvre un canal ic sur le fichier fn et retourne f
ic . Après que f est retourné, soit avec une valeur, soit en levant une exception, ic est garanti d'être fermé.

val with_open_text : string -> (t -> 'a) -> 'a

Comme In_channel.with_open_bin , mais le canal est ouvert en mode texte (voir In_channel.open_text ).

val with_open_gen : open_flag list -> int -> string -> (t -> 'a) -> 'a

Comme In_channel.with_open_bin , mais permet de spécifier le mode d'ouverture et la permission du fichier, au cas où le fichier devrait être créé (voir In_channel.open_gen ).

val close : t -> unit

Ferme le canal donné. Les fonctions d'entrée lèvent une exception Sys_error lorsqu'elles sont appliquées à un canal d'entrée fermé, sauf In_channel.close , qui ne fait rien lorsqu'elle est appliquée à un canal déjà fermé.

val close_noerr : t -> unit

Identique à In_channel.close , mais ignore toutes les erreurs.

Entrée

val input_char : t -> char option

Lit un caractère depuis le canal d'entrée donné. Retourne None s'il n'y a plus de caractères à lire.

val input_byte : t -> int option

Identique à In_channel.input_char , mais retourne l'entier de 8 bits représentant le caractère. Retourne None si la fin du fichier a été atteinte.

val input_line : t -> string option

input_line ic lit des caractères depuis ic jusqu'à un saut de ligne ou la fin du fichier. Retourne la chaîne de tous les caractères lus, sans le saut de ligne (le cas échéant). Retourne None si la fin du fichier a été atteinte. En particulier, ce sera le cas si la dernière ligne d'entrée est vide.

Un saut de ligne est le caractère \n à moins que le fichier ne soit ouvert en mode texte et que Sys.win32 soit true , auquel cas il s'agit de la séquence de caractères \r\n .

val really_input_string : t -> int -> string option

really_input_string ic len lit len caractères depuis le canal ic et les retourne dans une nouvelle chaîne. Retourne None si la fin du fichier est atteinte avant que len caractères n'aient été lus.

Si le même canal est lu concurremment par plusieurs threads, la chaîne retournée n'est pas garantie de contenir des caractères contigus de l'entrée.

val input_all : t -> string

input_all ic lit toutes les données restantes depuis ic .

Si le même canal est lu concurremment par plusieurs threads, la chaîne retournée n'est pas garantie de contenir des caractères contigus de l'entrée.

val input_lines : t -> string list

input_lines ic lit les lignes en utilisant In_channel.input_line jusqu'à ce que la fin du fichier soit atteinte. Elle retourne la liste de toutes les lignes lues, dans l'ordre où elles ont été lues. Les caractères de saut de ligne qui terminent les lignes ne sont pas inclus dans les chaînes retournées. Les lignes vides produisent des chaînes vides.

Entrée avancée

val input : t -> bytes -> int -> int -> int

input ic buf pos len lit jusqu'à len caractères depuis le canal donné ic , les stockant dans la séquence d'octets buf , en commençant à la position pos . Elle retourne le nombre réel de caractères lus, compris entre 0 et len (inclus). Une valeur de retour de 0 signifie que la fin du fichier a été atteinte.

Utilisez In_channel.really_input pour lire exactement len caractères.

Lève Invalid_argument si pos et len ne désignent pas une plage valide de buf .

val input_bigarray : t -> ('a, Bigarray.int8_unsigned_elt, Bigarray.c_layout) Bigarray.Array1.t -> int -> int -> int

Identique à In_channel.input , mais lit les données dans un bigarray.

val really_input : t -> bytes -> int -> int -> unit option

really_input ic buf pos len lit len caractères depuis le canal ic , les stockant dans la séquence d'octets buf , en commençant à la position pos .

Retourne None si la fin du fichier est atteinte avant que len caractères n'aient été lus.

Lève Invalid_argument si pos et len ne désignent pas une plage valide de buf .

Identique à In_channel.really_input , mais lit les données dans un bigarray.

val fold_lines : ('acc -> string -> 'acc) -> 'acc -> t -> 'acc

fold_lines f init ic lit les lignes de ic en utilisant In_channel.input_line jusqu'à ce que la fin du fichier soit atteinte, et passe successivement chaque ligne à la fonction f dans le style d'un pliage (fold). Plus précisément, si les lignes l1, ..., lN sont lues, fold_lines f init ic calcule f (... (f (f init l1) l2) ...) lN . Si f n'a pas d'effets de bord, cela est équivalent à List.fold_left f init (In_channel.input_lines ic) , mais est plus efficace car il ne construit pas la liste de toutes les lignes lues.

Positionnement

val seek : t -> int64 -> unit

seek chan pos définit la position de lecture actuelle à pos pour le canal chan . Cela ne fonctionne que pour les fichiers réguliers. Sur les fichiers d'autres types, le comportement n'est pas spécifié.

val pos : t -> int64

Retourne la position de lecture courante pour le canal donné. Pour les fichiers ouverts en mode texte sous Windows, la position retournée est approximative (en raison de la conversion de fin de ligne) ; en particulier, enregistrer la position courante avec In_channel.pos , puis revenir à cette position en utilisant In_channel.seek ne fonctionnera pas. Pour que cet idiome de programmation fonct

ionne de manière fiable et portable, le f
ichier doit être ouvert en mode binaire.

val length : t ->

int64

Retourne la taille (nombre de caractères) du fichier régulier sur lequel le canal donné est ouvert. Si le canal est ouvert sur un fichier qui n'est pas un fichier régulier, le résultat est sans signification. La taille retournée ne prend pas en compte les traductions de fin de ligne qui peuvent être effectuées lors de la lecture depuis un canal ouvert en mode

texte.

val set_binary_mode : t -> bool ->

unit

set_binary_mode ic true met le canal ic en mode binaire : aucune traduction n'a lieu lors de

l'entrée.

set_binary_mode ic false met le canal ic en mode texte : selon le système d'exploitation, certaines traductions peuvent avoir lieu lors de l'entrée. Par exemple, sous Windows, les fins de ligne seront traduites de \r\n vers \n

.

Cette fonction n'a aucun effet sous les systèmes d'exploitation qui ne distinguent pas entre le mode texte et le mode

binaire.

val is_binary_mode : t ->

bool

is_binary_mode ic retourne si le canal ic est en mode binaire (voir In_channel.set_binary_mode )

.
