Image::Info::GIF(3) Documentation Perl fournie par l'utilisateur Image::Info::GIF(3)

NOM

Image::Info::GIF - Support du format Graphics Interchange Format pour Image::Info

SYNTAXE

use Image::Info qw(image_info dim);
my $info = image_info("image.gif");
if (my $error = $info->{error}) {
    die "Impossible d'analyser les informations de l'image : $error\n";
}
my $color = $info->{color_type};
my($w, $h) = dim($info);

DESCRIPTION

Ce module fournit les noms de clé standard ainsi que

GIF_Loop
L'extension Netscape-2.0 pour la répétition des séquences d'animation est représentée par la clé GIF_Loop pour la première image. La valeur est soit "forever" soit un nombre indiquant le nombre de répétitions.

head1 MÉTHODES

process_file()

$info->process_file($source, $options);

Traite un fichier et définit les champs d'information trouvés dans l'objet $info.
