NOM

IO::String - Émuler l'interface de fichier pour les chaînes en mémoire

SYNOPHIS

use IO::String;
$io = IO::String->new;
$io = IO::String->new($var);
tie *IO, 'IO::String';
# lire des données
<$io>;
$io->getline;
read($io, $buf, 100);
# écrire des données
print $io "chaîne\n";
$io->print(@data);
syswrite($io, $buf, 100);
select $io;
printf "Un texte %s\n", $str;

DESCRIPTION

Le module "IO::String" fournit l'interface "IO::File" pour les chaînes en mémoire. Un objet "IO::String" peut être attaché à une chaîne et permet d'utiliser les opérations de fichier normales pour lire ou écrire des données, ainsi que pour se déplacer à divers endroits de la chaîne. Ceci est utile lorsque vous voulez utiliser un module de bibliothèque qui fournit uniquement une interface pour les descripteurs de fichier sur des données que vous avez dans une variable de chaîne.

Notez que Perl 5.8 et versions ultérieures ont un support intégré pour les fichiers "en mémoire", qui sont configurés en passant une référence au lieu d'un nom de fichier à l'appel open(). La raison d'utiliser ce module est qu'il rend le code rétrocompatible avec les anciennes versions de Perl.

Le module "IO::String" fournit une interface compatible avec "IO::File" telle qu'elle est distribuée avec IO-1.20, mais les méthodes suivantes ne sont pas disponibles : new_from_fd, fdopen, format_write, format_page_number, format_lines_per_page, format_lines_left, format_name, format_top_name.

Les méthodes suivantes sont spécifiques à la classe "IO::String" :

$io = IO::String->new
$io = IO::String->new( $string )
Le constructeur retourne un objet "IO::String" nouvellement créé. Il prend un argument optionnel, qui est la chaîne à lire ou dans laquelle écrire. Si aucun argument $string n'est donné, un tampon interne (initialement vide) est alloué.

L'objet "IO::String" retourné est lié à lui-même. Cela signifie que vous pouvez utiliser la plupart des fonctions d'E/S intégrées de Perl dessus aussi : readline, <>, getc, print, printf, syswrite, sysread, close.

$io->open
$io->open( $string )
Attache un objet IO::String existant à une autre $string, ou alloue un nouveau tampon interne (si aucun argument n'est donné). La position est remise à 0.
$io->string_ref
Retourne une référence vers la chaîne qui est attachée à l'objet "IO::String". Le plus utile lorsque vous laissez "IO::String" créer un tampon interne pour écrire.
$io->pad
$io->pad( $char )
Spécifie le caractère de remplissage à utiliser si la chaîne est étendue par les méthodes seek() ou truncate(). C'est un seul caractère et il vaut par défaut "\0".
$io->pos
$io->pos( $newpos )
Encore une interface pour lire et définir la position actuelle de lecture/écriture dans la chaîne (les méthodes normales getpos/setpos/tell/seek sont également disponibles). La méthode pos() retourne toujours l'ancienne position, et si vous lui passez un argument, elle définit la nouvelle position.

Il y a (délibérément) une différence entre les méthodes setpos() et seek() car seek() étend la chaîne (avec le remplissage spécifié) si vous allez à une position au-delà de la fin, tandis que setpos() se repositionne simplement à la fin. Si truncate() est utilisée pour étendre la chaîne, elle se comporte comme seek().

BOGUES

Dans les versions de Perl < 5.6, l'interface TIEHANDLE était incomplète. Si vous utilisez une telle version de Perl, alors seek(), tell(), eof(), fileno(), binmode() ne feront rien sur un descripteur de fichier "IO::String". Voir perltie pour plus de détails.

VOIR AUSSI

IO::File, IO::Stringy, "open" dans perlfunc
