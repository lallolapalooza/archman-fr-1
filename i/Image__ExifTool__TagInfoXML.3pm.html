NOM

Image::ExifTool::TagInfoXML - Lire/écrire la base de données XML d'informations sur les balises

DESCRIPTION

Ce module est utilisé pour générer une base de données XML à partir de toutes les informations de balises d'ExifTool. La base de données XML peut ensuite être modifiée et utilisée pour régénérer les modules de langue (Image::ExifTool::Lang::*).

MÉTHODES

Écrire

Imprime la base de données complète des informations sur les balises au format XML.

# sauvegarder la liste de toutes les balises
$succès = Image::ExifTool::TagInfoXML::Write('dst.xml');
# lister toutes les balises IPTC dans la console, y compris les Indicateurs
Image::ExifTool::TagInfoXML::Write(undef, 'IPTC', Flags => 1);
# écrire toutes les balises d'appareil photo EXIF dans un fichier
Image::ExifTool::TagInfoXML::Write($fichier_sortie, 'exif:camera');
Entrées :
0) [optionnel] Nom du fichier de sortie, ou undef pour une sortie console. Le fichier de sortie sera écrasé s'il existe déjà.

1) [optionnel] Chaîne de noms de groupes séparés par des deux-points pour spécifier le groupe à imprimer. Un IFD spécifique ne peut pas être donné comme groupe, car les balises EXIF peuvent être écrites dans n'importe quel IFD. Sauvegarde tous les groupes si non spécifié.

2) [optionnel] Hash des valeurs d'options :

Flags   - Défini pour sortir l'attribut 'flags'
NoDesc  - Défini pour supprimer la sortie des descriptions
Lang    - Sélectionner une seule langue pour la sortie
Valeur de retour :
Vrai en cas de succès.
Exemple de sortie XML :
<?xml version='1.0' encoding='UTF-8'?>
<taginfo>
<table name='XMP::dc' g0='XMP' g1='XMP-dc' g2='Other'>
 <desc lang='en'>XMP Dublin Core</desc>
 <tag id='title' name='Title' type='lang-alt' writable='true' g2='Image'>
  <desc lang='en'>Title</desc>
  <desc lang='de'>Titel</desc>
  <desc lang='fr'>Titre</desc>
 </tag>
 ...
</table>
</taginfo>

Les indicateurs (s'ils sont sélectionnés et disponibles) sont formatés comme une liste séparée par des virgules des valeurs possibles suivantes : Avoid, Binary, List, Mandatory, Permanent, Protected, Unknown et Unsafe. Voir la documentation du nom de la balise et lib/Image/ExifTool/README pour une description de ces indicateurs. Pour les balises de liste XMP, le type de liste (Alt, Bag ou Seq) est également affiché comme indicateur si applicable.

GénérerLesModulesDeLangage

Générer tous les modules Image::ExifTool::Lang à partir d'un fichier de base de données XML.

Image::ExifTool::TagInfoXML::BuildLangModules('src.xml');
Entrées :
0) Nom du fichier XML

1) Indicateurs de mise à jour :

0x01 = conserver les numéros de version
0x02 = mettre à jour tous les modules, même s'ils n'ont pas changé
0x04 = mettre à jour à partir de zéro, en ignorant les définitions existantes
0x08 = remplacer les descriptions et valeurs différentes existantes
Valeur de retour :
Nombre de modules mis à jour, ou négatif en cas d'erreur.
