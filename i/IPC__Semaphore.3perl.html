IPC::Semaphore(3perl) Guide du programmeur Perl IPC::Semaphore(3perl)

NOM

IPC::Semaphore - Classe d'objet pour les sémaphores IPC SysV

SYNTAXE

use IPC::SysV qw(IPC_PRIVATE S_IRUSR S_IWUSR IPC_CREAT);
use IPC::Semaphore;
$sem = IPC::Semaphore->new(IPC_PRIVATE, 10, S_IRUSR | S_IWUSR | IPC_CREAT);
$sem->setall( (0) x 10);
@sem = $sem->getall;
$ncnt = $sem->getncnt;
$zcnt = $sem->getzcnt;
$ds = $sem->stat;
$sem->remove;

DESCRIPTION

Une classe fournissant une interface orientée objet pour les sémaphores IPC SysV.

MÉTHODES

new ( CLE , NSEMS , FLAGS )
Crée un nouvel ensemble de sémaphores associé à "CLE". "NSEMS" est le nombre de sémaphores dans l'ensemble. Un nouvel ensemble est créé si
  • "CLE" est égal à "IPC_PRIVATE"
  • "CLE" n'a pas déjà d'identifiant de sémaphore associé, et "FLAGS & IPC_CREAT" est vrai.

Lors de la création d'un nouvel ensemble de sémaphores, "FLAGS" est utilisé pour définir les permissions. Faites attention à ne pas définir de drapeaux que l'implémentation IPC Sys V n'autorise pas : sur certains systèmes, définir des bits d'exécution peut entraîner l'échec des opérations.

getall
Retourne les valeurs de l'ensemble de sémaphores sous forme de tableau.
getncnt ( SEM )
Retourne le nombre de processus en attente que le sémaphore "SEM" devienne supérieur à sa valeur actuelle.
getpid ( SEM )
Retourne l'identifiant du processus qui a effectué la dernière opération sur le sémaphore "SEM".
getval ( SEM )
Retourne la valeur actuelle du sémaphore "SEM".
getzcnt ( SEM )
Retourne le nombre de processus en attente que le sémaphore "SEM" devienne zéro.
id
Retourne l'identifiant système de l'ensemble de sémaphores.
op ( OPLIST )
"OPLIST" est une liste d'opérations à passer à "semop". "OPLIST" est une concaténation de listes plus petites, chacune ayant trois valeurs. La première est le numéro du sémaphore, la seconde est l'opération et la dernière est une valeur de drapeaux. Voir semop(2) pour plus de détails. Par exemple : 
$sem->op(
    0, -1, IPC_NOWAIT,
    1,  1, IPC_NOWAIT
);
remove
Supprime et détruit l'ensemble de sémaphores du système.
set ( STAT )
set ( NOM => VALEUR [, NOM => VALEUR ...] )
"set" définira les valeurs suivantes de la structure "stat" associée à l'ensemble de sémaphores. 
uid
gid
mode (uniquement les bits de permission)

"set" accepte soit un objet stat, tel que retourné par la méthode "stat", soit une liste de paires de nom-valeur.

setall ( VALEURS )
Définit toutes les valeurs de l'ensemble de sémaphores aux valeurs fournies dans la liste "VALEURS". "VALEURS" doit contenir le nombre correct de valeurs.
setval ( N , VALEUR )
Définit la valeur "N"-ième de l'ensemble de sémaphores à "VALEUR".
stat
Retourne un objet de type "IPC::Semaphore::stat" qui est une sous-classe de "Class::Struct". Il fournit les champs suivants. Pour une description de ces champs, consultez la documentation de votre système. 
uid
gid
cuid
cgid
mode
ctime
otime
nsems

VOIR AUSSI

IPC::SysV, Class::Struct, semget(2), semctl(2), semop(2)
