NOM

INN::Config - Exporte toutes les variables dont un script Perl INN pourrait avoir besoin

DESCRIPTION

Ce module Perl configure toutes les variables dont un script Perl INN pourrait avoir besoin. Plus particulièrement, il permet d'utiliser les variables d'inn.conf : elles sont toutes fournies par innconfval, ainsi que la version d'INN (dans la variable $INN::Config::VERSION pour sa forme courte, dans $INN::Config::version pour sa forme complète). D'autres variables utiles sont également fournies (répertoires, fichiers, programmes, masques, paramètres). La liste complète peut être obtenue avec le script suivant qui les affiche :

use lib '<pathnews>/lib/perl';
use INN::Config;
use Data::Dumper;
my ($varname, $value);
foreach my $var (@INN::Config::EXPORT_OK) {
    if ($var =~ /^\$(.*)$/) {
        $varname = "INN::Config::$1";
        $value = Dumper($$varname);
        $value =~ s/^\$VAR1 = //;
        print "\$$varname = $value";
    } elsif ($var =~ /^\@(.*)$/) {
        $varname = "INN::Config::$1";
        $value = Dumper(\@$varname);
        $value =~ s/^\$VAR1 = //;
        print "\@$varname = $value";
    }
}

Un script Perl local nommé innshellvars.pl.local dans pathetc sera chargé, s'il est présent et exécutable, à la fin de l'exécution de ce module. Son utilisation typique est d'ajouter ou de remplacer des variables.

Il vous suffit de déclarer le module au début des scripts :

use lib '<pathnews>/lib/perl';
use INN::Config;

Ensuite, vous pouvez par exemple utiliser :

print $INN::Config::localmaxartsize;

pour afficher la valeur de localmaxartsize telle qu'elle est définie dans inn.conf.

Vous pouvez également spécifier une version lors de l'importation du module. Si vous écrivez :

use INN::Config 2.5.0;

seules les versions d'INN supérieures à 2.5.0 pourront exécuter le script Perl.

Il est également possible d'importer directement les variables dans votre espace de noms si vous spécifiez ce que vous souhaitez importer :

use INN::Config qw($localmaxartsize $pathbin);

Notez qu'un innshellvars.pl hérité est également fourni dans pathnews/lib pour des raisons de compatibilité avec les anciens scripts Perl non livrés avec INN. Il était utilisé par les versions d'INN antérieures à 2.5.0. Les scripts correspondants pour Shell et Tcl sont cependant toujours en usage : innshellvars et innshellvars.tcl. Ils offrent les mêmes capacités que ce module.

HISTORIQUE

innshellvars.pl a été écrit par James Brister <brister@vix.com> pour InterNetNews en 1996. Il a été converti en module Perl INN::Config par Julien Elie en 2007.

VOIR AUSSI

inn.conf(5), innconfval(1), perl(1).
