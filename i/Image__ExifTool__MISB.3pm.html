NOM

Image::ExifTool::MISB - Lire les métadonnées du Motion Industry Standards Board

SYNTAXE

Ce module est utilisé par Image::ExifTool

DESCRIPTION

Ce module contient le code pour extraire les métadonnées au format KLV de STANAG-4609 Motion Industry Standards Board (MISB) à partir de vidéos M2TS.
