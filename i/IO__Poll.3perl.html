NOM

IO::Poll - Interface objet pour l'appel système poll

SYNTAXE

use IO::Poll qw(POLLRDNORM POLLWRNORM POLLIN POLLHUP);
$poll = IO::Poll->new();
$poll->mask($input_handle => POLLIN);
$poll->mask($output_handle => POLLOUT);
$poll->poll($timeout);
$ev = $poll->events($input);

DESCRIPTION

"IO::Poll" est une interface simple pour la routine système poll.

MÉTHODES

mask ( IO [, MASQUE_ÉVÉNEMENT ] )
Si MASQUE_ÉVÉNEMENT est fourni, alors, si MASQUE_ÉVÉNEMENT est non nul, IO est ajouté à la liste des descripteurs de fichiers et le prochain appel à poll vérifiera tout événement spécifié dans MASQUE_ÉVÉNEMENT. Si MASQUE_ÉVÉNEMENT est zéro, alors IO sera retiré de la liste des descripteurs de fichiers.

Si MASQUE_ÉVÉNEMENT n'est pas fourni, alors la valeur de retour sera la valeur actuelle du masque d'événements pour IO.

poll ( [ DÉLAI ] )
Appelle la routine système poll. Si DÉLAI n'est pas spécifié, l'appel sera bloquant. Retourne le nombre de poignées pour lesquelles des événements se sont produits, ou -1 en cas d'erreur.
events ( IO )
Retourne le masque d'événements qui représente les événements qui se sont produits sur IO lors du dernier appel à "poll".
remove ( IO )
Retire IO de la liste des descripteurs de fichiers pour le prochain poll.
handles( [ MASQUE_ÉVÉNEMENT ] )
Retourne une liste de poignées. Si MASQUE_ÉVÉNEMENT n'est pas fourni, une liste de toutes les poignées connues sera retournée. Si MASQUE_ÉVÉNEMENT est fourni, une liste de poignées sera retournée pour lesquelles un des événements spécifiés par MASQUE_ÉVÉNEMENT s'est produit lors du dernier appel à "poll".

VOIR AUSSI

poll(2), IO::Handle, IO::Select
