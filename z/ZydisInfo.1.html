ZYDISINFO(1) Manuel des commandes générales ZYDISINFO(1)

NOM

ZydisInfo - informations détaillées sur l'instruction

SYNTAXE

ZydisInfo mode_machine [largeur_pile] octets_hexadécimaux

DESCRIPTION

ZydisInfo permet de décoder l'assembleur X86 et X86-64 en affichant de nombreuses informations à son sujet.

OPTIONS

ZydisInfo prend en charge quatre modes machine différents

-réel
mode machine réel
-16
mode machine 16 bits
-32
mode machine 32 bits
-64
mode machine 64 bits

Vous pouvez également spécifier la largeur de la pile avec l'une des options suivantes

-16
16 bits
-32
32 bits
-64
64 bits

EXEMPLES

$ ZydisInfo -64 66 3E 65 2E F0 F2 F3 48 01 A4 98 2C 01 00 00
== [    DE BASE ] ==================================================
   MNÉMONIQUE: add [ENC: DEFAULT, MAP: DEFAULT, OPC: 0x01]
     LONGUEUR: 15
        SSZ: 64
       EOSZ: 64
       EASZ: 64
   CATÉGORIE: BINARY
    ISA-SET: I86
    ISA-EXT: BASE
 EXCEPTIONS: AUCUNE
ATTRIBUTS: HAS_MODRM HAS_SIB HAS_REX CPUFLAG_ACCESS ACCEPTS_LOCK
[...plus d'infos...]
