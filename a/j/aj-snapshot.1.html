DESCRIPTIO

N

Aj-snapshot est un petit programme qui peut être utilisé pour créer des instantanés des connexions établies entre les clients JACK et/ou ALSA. Parce que JACK peut fournir à la fois la prise en charge audio et MIDI aux programmes, aj-snapshot peut stocker les deux types de connexions pour JACK. ALSA, d'autre part, ne fournit que des moyens de routage pour les clients MIDI. Si vous appelez aj-snapshot sans aucune option, aj-snapshot stockera toutes les connexions ALSA et JACK actuelles dans FICHIER. Le fichier sera un fichier XML, et vous pouvez utiliser

un éditeur de texte si vous sou
haitez le modifier manuellement.

OPTION

S

-a , --als

a
Stocker ou restaurer uniquement
les connexions MIDI ALSA. Fonc
tionne également en mode démon.

-d , --daemo

n
Exécuter aj-snapshot en mode démon. Aj-snapshot essaiera d'abord de restaurer les connexions à partir du fichier d'instantané spécifié. Ensuite, il attendra que de nouveaux ports soient enregistrés avec ALSA ou JACK. Par défaut, chaque seconde, aj-snapshot vérifiera si de nouveaux ports ont été enregistrés dans ALSA ou JACK. Si c'est le cas, il essaiera de restaurer les connexions à partir de votre fichier d'instantané. Si vous démarrez aj-snapshot en mode démon, vous n'avez pas besoin de spécifier l'indicateur -r,--restore car il est de toute façon
implicite.
Si vous envoyez le signal HUP au démon, le démon rechargera le fichier d'instantané. Cela vous donne la possibilité de déclencher une restauration des connexions. Pour un exemple de la manière de procéder, voir la section EXEMPLES ci-dessous. Lorsque vous combinez le mode démon avec l'option -x,--remove l'envoi du signal HUP au démon effacera toutes les connexions avant la
restauration.
Lorsque le serveur JACK s'arrête (ou plante) pendant qu'aj-snapshot s'exécute en mode démon,
aj-snapshot essaiera de continuer à s'exécuter. Lorsque le serveur JACK est redémarré plus
tard, aj-snapshot se réattachera automatiquement et restaurera vos connexions si nécessaire.

e

xistant, aj-snapshot vous demandera si vous souhaitez écraser ce fichier.
Avec cette option, vous pouvez forcer aj-snapshot à écraser ce fichier.

-p intervalle, --poll=intervall

e
Chaque fois qu'un programme enregistre un port avec ALSA ou JACK, aj-snapshot vérifiera s'il y a des connexions dans le fichier d'instantané qui devraient être restaurées. Par défaut, aj-snapshot vérifiera (interrogera) s'il y a de nouveaux ports chaque seconde (1000 millisecondes). Avec cette option, vous pouvez choisir à quelle fréquence aj-snapshot doit vérifier les nouveaux ports. La valeur de intervalle doit être
spécifiée en
millisecondes.

-r , --restor

e
Lorsque vous spécifiez l'indicateur -r, aj-snapshot essaiera de restaurer toutes les connexions ALSA et JACK à partir de FICHIER. (sans cela, aj-snapshot essaiera de stocker les connexions dans FICHIER). Vous pouvez combiner cette option avec les options -a ou -j, si vous souhaitez restaurer uniq
uement les connex
ions ALSA ou JACK.

-x , --remov

e
L'option -x peut être utilisée lors de la restauration des connexions, ou lors de l'exécution en mode démon. Avec cette option, aj-snapshot supprimera toutes les connexions existantes avant de restaurer le fichier d'instantané. Lorsque vous la combinez avec l'option -a ou -j, seules les connexions du sous-système spécifique (ALSA ou JACK) seront supprimées. Sans l'option -x aj-snapshot essaiera de restaurer les connexions par-dessus les connexions déjà
actives.
Il existe une autre manière d'utiliser l'option -x. Si vous appelez aj-snapshot sans l'argument FICHIER, vous pouvez utiliser l'option -x pour supprimer toutes les connexions ALSA et JACK existantes (sans faire autre chose). Comme précédemment, vous pouvez la combiner avec les options -a ou -j
.

-i nom_client, --ignore=nom_clien

t
Vous pouvez utiliser cette option pour spécifier un ou plusieurs clients qui doivent être ignorés par aj-snapshot. Vous pouvez écrire le nom du client après l'option -i, et vous pouvez utiliser des motifs génériques dans cette chaîne (globbing de shell habituel). Si ce nom contient des espaces, ou d'autres caractères qui ont une signification spéciale pour le shell, vous devriez mettre le nom entre des guillemets simples (le plus sûr) ou doubles. Pour connaître le nom d'un client, vous pourriez enregistrer un instantané et chercher le nom dans le fichier d'instantané. Si vous souhaitez ignorer plusieurs clients, vous devez répéter l'option -i avec différents noms de client
s (le maximum est
de 50 clients).
