ABC2LY(1) Commandes utilisateur ABC2LY(1)

NOM

abc2ly - page man pour abc2ly (LilyPond) 2.24.4

SYNTAXE

abc2ly [OPTION]... FICHIER

DESCRIPTION

abc2ly convertit les fichiers musicaux ABC (voir http://abcnotation.com/abc2mtex/abc.txt) en entrée LilyPond.

OPTIONS

--version
afficher le numéro de version et quitter
-h, --help
afficher cette aide et quitter
-o, --output=FICHIER
écrire la sortie dans FICHIER
-s, --strict
être strict sur le succès
-b, --beams
préserver la notion de barres dans ABC
-q, --quiet
supprimer les messages de progression

SIGNALER LES BOGUES

Signaler les bogues via bug-lilypond@gnu.org

VOIR AUSSI

La documentation complète de abc2ly est maintenue sous forme de manuel Texinfo. Si les programmes info et abc2ly sont correctement installés sur votre site, la commande

info abc2ly

devrait vous donner accès au manuel complet.
