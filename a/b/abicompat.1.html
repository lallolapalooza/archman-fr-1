abicompat - vérifier la compatibilité

ABI

abicompat vérifie qu'une application liée à une bibliothèque partagée donnée est toujours compatible ABI avec une version ultérieure de cette bibliothèque. Si la nouvelle version de la bibliothèque introduit une incompatibilité ABI, alors abicompat indique à l'utilisateur en quoi consiste exactement cette

incompatibilité

VALEURS DE

RETOUR

Le code de sortie de la commande abicompat est soit 0 si l'ABI des binaires comparés sont égales, soit non nul s'ils diffèrent ou si l'outil a rencontré une

erreur.

Dans le dernier cas, le code de sortie est un champ de bits de 8 bits dans lequel chaque bit a une signification

spécifique.

Le premier bit, de valeur 1, nommé ABIDIFF_ERROR signifie qu'il y a eu une

erreur.

Le deuxième bit, de valeur 2, nommé ABIDIFF_USAGE_ERROR signifie qu'il y a eu une erreur dans la manière dont l'utilisateur a invoqué l'outil. Il peut être défini, par exemple, si l'utilisateur a invoqué l'outil avec un commutateur de ligne de commande inconnu, avec un nombre ou un argument incorrect, etc. Si ce bit est défini, alors le bit ABIDIFF_ERROR doit également être

défini.

Le troisième bit, de valeur 4, nommé ABIDIFF_ABI_CHANGE signifie que l'ABI des binaires comparés sont

différentes.

Le quatrième bit, de valeur 8, nommé ABIDIFF_ABI_INCOMPATIBLE_CHANGE signifie que l'ABI des binaires comparés sont différentes de manière incompatible. Si ce bit est défini, alors le bit ABIDIFF_ABI_CHANGE doit également être défini. Si le bit ABIDIFF_ABI_CHANGE est défini et que le bit ABIDIFF_INCOMPATIBLE_CHANGE n'est PAS défini, alors cela signifie que les ABI comparées peuvent ou peuvent ne pas être compatibles. Dans ce cas, un être humain doit examiner les changements d'ABI pour décider s'ils sont compatibles ou

non.

Les bits restants

ne sont pas utilis
és pour le moment.
