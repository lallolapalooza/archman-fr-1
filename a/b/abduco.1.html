ABDUCO(1) Manuel des commandes générales ABDUCO(1)

NOM

abduco - gestionnaire de sessions terminal

SYNTAXE

abduco [-e touche_deconnexion] [-r] [-f] -c nom commande [arguments ...]
abduco [-e touche_deconnexion] [-r] [-f] -n nom commande [arguments ...]
abduco [-e touche_deconnexion] [-r] [-f] [-l] -A nom commande [arguments ...]
abduco [-e touche_deconnexion] [-r] [-l] -a nom

DESCRIPTION

abduco offre un moyen de déconnecter une application donnée de son terminal de contrôle, fournissant ainsi un support d'attachement/détachement de session à peu près similaire à screen(1), tmux(1) ou dtach(1).

Si la commande à exécuter n'est pas spécifiée, la variable d'environnement $ABDUCO_CMD est examinée. Si elle n'est pas définie, dvtm(1) est exécuté.

Toutes les informations relatives aux sessions sont stockées dans les répertoires suivants (le premier qui réussit est utilisé) :

$ABDUCO_SOCKET_DIR/abduco
$HOME/.abduco
$TMPDIR/abduco/$USER
/tmp/abduco/$USER

Cependant, si un nom de session donné représente un chemin relatif ou absolu, il est utilisé tel quel.

Si, pour une raison quelconque, le socket de domaine unix(7) représentant une session est supprimé, l'envoi de SIGUSR1 au processus serveur le recréera.

OPTIONS

Si aucun argument de ligne de commande n'est donné, toutes les sessions actives sont affichées triées par leur date de création respective. Les lignes commençant par un astérisque * indiquent qu'au moins un client est connecté. Un signe plus + indique que la commande s'est terminée sans qu'aucun client ne soit connecté ; attachez-vous pour obtenir son code de sortie.

-v
Affiche les informations de version sur la sortie standard et quitte.
-r
Session en lecture seule, c'est-à-dire que les entrées utilisateur sont ignorées.
-e touche_deconnexion
Définit la touche pour se déconnecter, qui est par défaut CTRL+\ (c'est-à-dire ^\\) pour la touche de déconnexion.
-f
Force la création d'une session lorsqu'il existe déjà une session terminée du même nom, après avoir affiché son code de sortie.
-c
Crée une nouvelle session et s'y attache immédiatement.
-n
Crée une nouvelle session mais ne s'y attache pas.
-A
Tente de se connecter à une session existante. En cas d'échec, crée ladite session et s'y attache immédiatement.
-a
S'attache à une session existante.
-l
S'attache avec la priorité la plus basse, signifiant que ce client sera le dernier à contrôler la taille.

EXEMPLE

Démarrez une nouvelle session (en supposant que dvtm(1) est dans $PATH) avec

abduco -c ma-session

faites votre travail, puis déconnectez-vous en appuyant sur CTRL+\, et reconnectez-vous plus tard avec

abduco -a ma-session
