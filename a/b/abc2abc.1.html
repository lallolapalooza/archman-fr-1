ABC2ABC(1) Manuel des commandes générales ABC2ABC(1)

NOM

abc2abc - un vérificateur/re-formateur/transposeur abc simple

SYNTAXE

abc2abc fichier [ -s ] [ -n ] [ -b ] [ -r ] [ -e ] [ -t demi-tons ] [ -nda ] [ -u ] [ -d ] [ -v ] [ -Vnuméro de voix] [-Pnuméro de voix] [-nokeys] [ -nokeyf] [ -usekey(dièses/bémols)] [-useclef(clé de sol/fa)] [ -OCC ]

DESCRIPTION

abc2abc est un vérificateur/re-formateur/transposeur abc simple. Il vérifie si le fichier donné en ligne de commande respecte la syntaxe de base d'abc.

Si vous voulez vérifier une mélodie abc, il est recommandé d'utiliser abc2midi avec l'option -c. Cela effectue des vérifications supplémentaires qu'abc2abc ne fait pas.

La sortie d'abc2abc va vers la sortie standard. Utilisez la redirection pour l'enregistrer dans un fichier.

OPTIONS

-s
Reorganise l'espacement dans le fichier (ce qui affecte la façon dont les notes sont groupées lorsqu'elles sont imprimées). Cette option ne semble pas fonctionner correctement.
-n X
Reforme le fichier abc avec des sauts de ligne tous les X mesures.
-b
Ne pas faire la vérification des mesures.
-r
Ne pas faire la vérification des répétitions.
-e
Ne pas signaler les erreurs.
-t n
Transpose la mélodie de n demi-tons. Cette fonction fonctionne aussi avec K: none ou l'une des options -nokeys ou -nokeyf. Si une voix est attribuée au canal 10 (canal de batterie) en utilisant une commande %%MIDI channel 10, alors cette voix n'est jamais transposée.
-nda
Convertit les doubles altérations dans les accords de guitare en un autre accord bien que ce ne soit pas strictement correct.
-u
Met à jour la notation ; l'ancienne notation + + pour les accords est remplacée par [] et s s pour les liaisons est remplacé par ().
-OCC
Accepte l'ancienne notation pour les accords. Normalement, elle est désactivée car elle entre en conflit avec la norme projet abc version 2.0 pour les ornements (par exemple, +crescendo(+).
-d
Re-note la mélodie en doublant toutes les longueurs de note. La longueur unitaire spécifiée par la commande de champ L: est divisée par deux (par exemple, L:1/8 devient L:1/16).
-v
Re-note la mélodie en divisant toutes les longueurs de note par deux. La longueur unitaire spécifiée par la commande de champ L: est doublée (par exemple, L:1/8 devient L:1/4).
-ver
Affiche le numéro de version et quitte.
-V X[,Y...]
Pour les fichiers abc multivoix (c'est-à-dire contenant des commandes de champ V:), seules les voix X[,Y,...] sont copiées.
-P X,[,Y...]
Pour les fichiers abc multivoix (c'est-à-dire contenant des commandes de champ V:), toutes les voix sauf X[,Y...] restent identiques. Les voix X,Y... sont modifiées conformément aux autres paramètres d'exécution.
-X n
Pour un fichier contenant plusieurs mélodies, les numéros de référence X: sont renumérotés séquentiellement à partir du numéro n.
-xref n
Seule la mélodie avec X: n est traitée.
-nokeys
Aucune armure ne sera présumée. Au lieu de cela, les dièses et les bécarres seront placés là où ils sont nécessaires.
-nokeyf
Aucune armure ne sera présumée. Au lieu de cela, les bémols et les bécarres seront placés là où ils sont nécessaires.
-usekey sf
Cela forcera abc2abc à sortir les notes dans l'armure keys[sf], où sf spécifie le nombre de bémols (-négatif) ou de dièses (+positif) dans l'armure. C'est un nombre compris entre -5 et +5 inclus.
-useclef
Cela fonctionne uniquement avec l'option -t (transpose) et à condition que le fichier abc n'ait pas déjà une commande de clef dans le champ K:. Il ne prend pas en charge les voix.

* Normalement, abc2abc convertit la notation obsolète des ornements (par exemple, !ppp!) en la norme projet abc version 2.0 (par exemple, +ppp+). Si vous ne souhaitez pas passer à cette norme, incluez le drapeau -OCC.
