Par exemple, si vous connaissez quelques mesures d'un air, vous pouvez utiliser ce programme pour trouver l'air ayant cette séquence et peut-être identifier l'air. Au minimum, abcmatch nécessite deux fichiers. Un fichier modèle appelé match.abc qui contient les mesures que vous recherchez et un grand fichier composé d'une centaine d'airs abc ou plus. Le programme charge automatiquement le fichier match.abc puis parcourt chaque air du grand fichierOPTIONS-v et -c

hm
Fait en sorte que l'algorithme de correspondance ignore la longueur des notes dans une mesure, ainsi E3/2F/D GA2 correspondrait à EFD G2A. L'option ignore le paramètre -r puisqu'il n'est plus

-pitch_
table
Utilisé pour produire un histogramme de hauteur pondéré par les intervalles pour chaque air du fichier. S'il est sauvegardé dans un fichier externe, ce fichier peut être utilisé comme base de données pour trouver des airs ayant des fonctions de densité de probabilité de
hauteur (pdf) similaires.
-
r
Contrôle la manière dont le critère de correspondance traite les petites variations de rythme dans la mélodie. L'option -r doit être suivie d'un nombre qui spécifie la résolution temporelle pour la correspondance. Lorsque le nombre est zéro, cela indique qu'une correspondance parfaite doit être effectuée, ce qui signifie que les longueurs de chaque note dans la mesure doivent correspondre exactement pour être rapportées. Pour des valeurs plus grandes, une correspondance plus souple sera effectuée comme décrit ci-dessous. Les longueurs des notes sont converties en unités temporelles où une noire est normalement assignée une valeur de 24. Par conséquent une croche a une valeur de 12, une double croche a une valeur de 6, une blanche a une valeur de 48, etc. Si vous spécifiez une résolution temporelle de 12, alors les valeurs de hauteur des notes doivent seulement correspondre aux unités de temps qui sont des multiples
d'une croche.
-fixed
n
Fait en sorte que le programme ignore les barres de mesure lors de la correspondance. Cela permet la correspondance de notes entre des airs ayant des signatures rythmiques différentes. n est un nombre qui spécifie le nombre exact de notes à faire correspondre. Par exemple si n vaut 4, le programme pourrait faire correspondre |C E G E| .. avec |C E|G E| Notez que le moteur de correspondance commence toujours au début d'une mesure donnée pour l'air et le
modèle.
-c
on
Spécifie la correspondance de contour. Dans ce cas, le programme utilise la signature de tonalité uniquement pour indiquer les altérations. Le contour de hauteur est calculé à partir de la différence de hauteur ou de l'intervalle entre les notes
adjacentes.

t

unisson et demi-ton 0 seconde mineure à seconde majeure 1 tierce mineure

-tp nom de fichier, numéro
de référence
Remplace n'importe quel air par le modèle match.abc. Lors de l'utilisation de cette fonctionnalité, l'air entier est utilisé comme modèle. Abcmatch ne fait pas correspondre le modèle avec lui-même, et seules les mesures qui correspondent à des mesures dans d'autres airs sont rapportées.

-br

seuil

Exécute le programme en mode bref conçu pour identifier des groupes d'airs partageant des mesures communes. Dans ce mode, le programme compte le nombre de mesures de l'air test qui sont aussi présentes dans match.abc. Si le nombre de mesures communes est supérieur ou égal au seuil, alors le programme rapporte l'air et le nombre de mesures communes. Le programme parcourt tous les airs dans le fichier abc et retourne une liste de tous les airs qui ont plus qu'un nombre spécifique de mesures en commun avec le modèle, match.abc. En pratique, le programme est exécuté à plusieurs reprises par un script. Pour chaque air dans un fichier abc, il crée un fichier modèle appelé match.abc puis exécute abcmatch. Les sorties sont affichées à l'écran sous une forme facile à interpréter. L'utilisateur n'a aucun contrôle sur le critère de correspondance. Le rythme doit correspondre exactement et les notes sont transposées pour s'adapter

à la signature de tonalité. En d'autres termes, le paramètre -r
est indépendant de ce qui est spécifié dans la liste de paramètres.
-pitch_hist ou
-length_hist
Exécute le programme dans un autre mode. Il produit un histogramme de la distribution des notes dans le fichier abc. La hauteur est indiquée en unités midi. Ainsi le do central est 60 et les hauteurs augmentent en unités de demi-tons. Après la hauteur se trouve un décompte du nombre de fois où cette note est
apparue.
-pitch_table ou
-interval_table
Utilisé pour créer une base de données pour une collection d'airs dans un fichier pour une analyse
ultérieure.
