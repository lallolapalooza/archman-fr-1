abuild(1) Manuel des commandes générales abuild(1)

NOM

abuild - construire un apk à partir d'un APKBUILD

SYNOPSIS

abuild [options] [-C DIR] [-P REPODEST] [-s SRCDEST] [-D DESCRIPTION] [cmd] ...

DESCRIPTION

abuild construit un paquet binaire apk à partir d'un APKBUILD(5) en entrée, ainsi que d'autres opérations associées.

OPTIONS

-A

Affiche CARCH et quitte

-c

Active la sortie en couleurs

-C DIR

Change de répertoire vers DIR avant d'exécuter toute commande

-d

Désactive la vérification des dépendances

-D DESCRIPTION

Définit la description de l'APKINDEX (par défaut : $repo $(git describe))

-f

Force la commande spécifiée (ignore les vérifications : apk à jour, arch)

-F

Force l'exécution en tant que root

-h

Affiche cette aide

-k

Conserve les paquets construits, même si l'APKBUILD ou les sources sont plus récents

-K

Conserve les répertoires et fichiers temporaires de construction (srcdir/pkgdir/deps)

-m

Désactive les couleurs (monochrome)

-P REPODEST

Définit REPODEST comme emplacement du dépôt pour les paquets créés

-q

Silencieux

-r

Installe les dépendances manquantes depuis le dépôt système

-s SRCDEST

Définit le répertoire de destination du paquet source à SRCDEST

-v

Verbose : affiche chaque commande au moment de son exécution (très verbeux)

COMMANDES

all

Exécute l'ensemble du processus de construction. C'est la valeur par défaut lorsqu'aucune autre commande n'est spécifiée, et c'est approximativement un alias pour validate builddeps clean fetch unpack prepare mkusers build check rootpkg.

build

Compile et installe le paquet dans $pkgdir.

check

Exécute tous les tests définis concernant le paquet

checksum

Génère les sommes de contrôle à inclure dans l'APKBUILD

clean

Supprime les répertoires temporaires de construction et d'installation

cleancache

Supprime les fichiers téléchargés de $SRCDEST

cleanoldpkg

Supprime les paquets binaires sauf la version actuelle

cleanpkg

Supprime les paquets binaire et source déjà construits

deps

Installe les paquets listés dans makedepends et depends

fetch

Récupère les sources vers $SRCDEST

index

Régénère les index dans $REPODEST

listpkg

Liste les paquets cibles

package

Installe le projet dans

prepare

Applique les correctifs

rootbld

Construit le paquet dans un chroot propre. Nécessite abuild-rootbld.

rootpkg

Exécute 'package', les fonctions de découpage et crée les apks en tant que fakeroot

validate

Validation basique de l'APKBUILD

snapshot

Crée un instantané de $giturl et le téléverse vers $disturl

sourcecheck

Vérifie si le paquet source distant existe en amont

srcpkg

Crée un paquet source

undeps

Désinstalle les paquets listés dans makedepends et depends

unpack

Décompresse les sources vers $srcdir

up2date

Compare les dates de la cible et des sources

ENVIRONNEMENT

APKBUILD

Remplace le chemin vers le fichier APKBUILD .

BOOTSTRAP

Utilisé lors de l'amorçage sans paquets existants en minimisant les dépendances de construction. Ce drapeau n'a un effet que sur quelques paquets sélectionnés.

La valeur nocc omet toute compilation (par ex. : inclut uniquement les en-têtes sources). La valeur nolibc suppose qu'aucune libc n'est disponible.

Cette liste de valeurs n'est pas exhaustive.

CHOST

Génère des paquets pour l'architecture ou le triplet donné.

CTARGET

Génère un compilateur pour l'architecture ou le triplet donné.

PACKAGER

Nom et courriel des paquets au format RFC5322. Ex. : John Doe <john@example.com>.

PACKAGER_PRIVKEY

Chemin vers une clé privée utilisée pour signer les paquets.

REPODEST

Les paquets seront stockés dans $REPODEST/$repo/$arch/$pkgname-$pkgver-r$pkgrel.apk, où $repo est le nom de base du répertoire parent de $startdir.

SOURCE_DATE_EPOCH

Utilise cet horodatage comme référence pour les constructions reproductibles. Voir https://reproducible-builds.org/docs/source-date-epoch/

SUDO_APK

Commande à utiliser pour exécuter apk en tant que root. Par défaut : abuild-apk.

USE_CCACHE

Si défini à une valeur non vide, active la prise en charge de ccache .

USE_COLORS

Si défini à une valeur non vide, affiche une sortie en couleurs en utilisant les séquences d'échappement ANSI.

FICHIERS

/etc/abuild.conf

La configuration est lue depuis ce fichier par défaut.

$HOME/.abuild/abuild.conf

La configuration spécifique à l'utilisateur est lue depuis ce fichier, s'il existe.

EXEMPLES

Mettre à jour les sommes de contrôle pour un APKBUILD :

abuild checksum

Construire un APKBUILD et afficher une sortie en couleurs :

abuild -rc
