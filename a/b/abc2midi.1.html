ABC2MIDI(1) Manuel des commandes générales ABC2MIDI(1)

NOM

abc2midi - convertit un fichier abc en fichier(s) MIDI

SYNTAXE

abc2midi fichier_entree [num_ref] [-c] [-v] [-ver] [-t] [-n limite] [-CS] [-quiet] [-silent] [-Q tempo] [-NFNP] [-NFER] [-NGRA] [-NGUI] [-STFW] [-OCC] [-NCOM] [-HARP] [-BF] [-TT] [-o fichier_sortie] -CSM [nom_de_fichier]

DESCRIPTION


L'action par défaut consiste à écrire un fichier MIDI pour chaque mélodie abc
avec le nom de fichier <base>N.mid, où <base> est la base du nom du fichier
abc et N est le numéro de référence de la mélodie. Si l'option -o
est utilisée, un seul fichier est écrit. Il s'agit de la mélodie
spécifiée par le numéro de référence ou, si aucun numéro de référence
n'est donné, de la première mélodie du fichier.

OPTIONS

num_ref
traite la mélodie avec le numéro de référence num_ref
-c
sélectionne la vérification uniquement
-v n
sélectionne l'option verbeuse où n est le niveau (optionnel)
-ver
affiche le numéro de version et quitte
-t
sélectionne des noms de fichiers dérivés des titres de mélodies
-CS
utilise 2:1 au lieu de 3:1 pour les rythmes cassés
-quiet
Supprime certains avertissements courants.
-silent
Supprime d'autres messages.
-n X
limite la longueur de la base du nom de fichier à X caractères
-Q tempo
définit le tempo par défaut en noires par minute s'il n'a pas été spécifié dans l'en-tête abc.
-NFNP
Ignore toutes les indications de dynamique !f! !ff! etc.
-NFER
Ignore toutes les indications de fermate (par ex. H ou !fermata!).
-NGRA
Ignore toutes les notes d'agrément.
-NGUI
Ignore tous les accords de guitare entre guillemets doubles.
-STFW
Place le texte des paroles dans des pistes MIDI séparées.
-NCOM
Supprime certains commentaires dans le fichier MIDI de sortie.
-OCC
Accepte l'ancienne convention d'accords (par ex. +D2G2+ au lieu de [DG]2).
-BF
Mode BarFly : invoque un modèle de stress si possible.
-HARP
Ornements roulés=roulé sont générés pour le harpiste (même hauteur)
-TT
Modifie l'accord de A = 440 Hz.
-o fichier_sortie
écrit la sortie dans fichier_sortie
-CSM fichier_entree
charge un ensemble de modes de stress personnalisés à partir d'un fichier

FONCTIONNALITÉS

* Les rythmes cassés (>, <), les accords, les n-uplets, les liaisons, les tenues, les notes staccato, les répétitions, les changements de tempo/longueur/signature rythmique sont tous pris en charge.

* R:hornpipe ou r:hornpipe est reconnu et les cadences des notes sont ajustées pour donner un rythme cassé (ab est converti en a>b).

* La plupart des erreurs dans l'entrée abc généreront un message d'erreur approprié dans la sortie et le convertisseur continuera.

* Les commentaires et les champs de texte dans la source abc sont convertis en événements texte dans la sortie MIDI

* Si des accords de guitare sont présents, ils sont utilisés pour générer un accompagnement dans la sortie MIDI.

* S'il y a des signes de répétition non appariés dans l'abc, le programme tente de les corriger. Cependant, il ne tentera pas cela si une description de mélodie multiparte a été utilisée ou si plusieurs voix sont en cours d'utilisation.

* Les fichiers MIDI Karaoké peuvent être générés en utilisant le champ w: pour inclure les paroles.

* Les identifiants de voix non numériques, par ex. V: soprano, tels que proposés pour la nouvelle norme abc, sont acceptés.

* Les silences invisibles spécifiés par x sont traités de la même manière que les silences normaux (z).

* Les décorations peuvent être indiquées en utilisant la notation dépréciée (par ex. !fermata!) ou la notation standard version 2.0 (par ex. +fermata+).

LIMITATIONS

* Aucun champ n'est hérité du champ X: de la mélodie.

EXTENSIONS SYNTAXE ABC

* Il existe quelques extensions à la syntaxe abc de la forme

%%MIDI channel n

Celles-ci contrôlent la sélection des canaux et des programmes, la transposition et diverses autres fonctionnalités d'abc2midi.

Chacune de ces lignes doit apparaître sur une ligne séparée. Toutes sont autorisées à l'intérieur du corps de la mélodie abc. En utilisant celles-ci en combinaison avec la notation de partie, on peut, par exemple, jouer une partie transposée ou dans une tonalité différente.

L'idée derrière cette syntaxe est que d'autres programmes la traiteront comme un commentaire et l'ignoreront.

%%MIDI channel n

sélectionne le canal de mélodie n (dans la plage 1-16).

%%MIDI program [c] n

sélectionne le programme n (dans la plage 0-127) sur le canal c. Si c n'est pas donné, le programme est sélectionné sur le canal de mélodie actuel. La plupart des générateurs de sons modernes suivent la norme General MIDI qui définit le type d'instrument pour chaque numéro de programme.

%%MIDI beat a b c n

contrôle la manière dont les vélocités des notes sont sélectionnées. La première note d'une mesure a la vélocité a. Les autres notes "fortes" ont la vélocité b et toutes les autres ont la vélocité c. a, b et c doivent être dans la plage 0-127. Le paramètre n détermine quelles notes sont "fortes". Si la signature rythmique est x/y, alors chaque note reçoit un numéro de position k = 0, 1, 2 .. x-1 dans chaque mesure. Notez que les unités de n ne sont pas la longueur de la note unitaire. Si k est un multiple de n, alors la note est "forte". Les spécificateurs de volume !ppp! à !fff! sont équivalents à ce qui suit :

!ppp! = %%MIDI beat 30 20 10 1
!pp! = %%MIDI beat 45 35 20 1
!p! = %%MIDI beat 60 50 35 1
!mp! = %%MIDI beat 75 65 50 1
!mf! = %%MIDI beat 90 80 65 1
!f! = %%MIDI beat 105 95 80 1
!ff! = %%MIDI beat 120 110 95 1
!fff! = %%MIDI beat 127 125 110 1

%%MIDI beatmod n

Incrémente (ou décrémente si n est négatif) les vélocités a, b et c décrites ci-dessus. Les instructions !crescendo(! et !crescendo)! sont équivalentes à l'insertion de %%MIDI beatmod 15 partout où elles se produisent. (Alternativement, vous pouvez utiliser !<(! et !<)!.) De même, les instructions !diminuendo(! et !diminuendo)! sont équivalentes à %%MIDI beatmod -15.

%%MIDI deltaloudness n

où n est un petit nombre positif. Par défaut, les instructions de crescendo et diminuendo modifient les variables de battement a, b et c de 15 unités de vélocité. Cette instruction vous permet de définir cette valeur par défaut à n.

%%MIDI nobeataccents

Pour les instruments tels que l'orgue d'église qui n'ont pas de notes de battement fortement accentuées, l'utilisation de ceci forcera l'utilisation de la vélocité 'b' (voir %%MIDI beat) pour chaque note, quelle que soit sa position dans la mesure. Ceci permet d'utiliser la dynamique (ff, f, etc) de la manière habituelle.

%%MIDI beataccents

Retourne à l'accentuation habituelle des notes. (par défaut)

%%MIDI beatstring <chaîne de f, m et p>

Ceci fournit une manière alternative de spécifier où tombent les accents forts et faibles à l'intérieur d'une mesure. 'f' signifie vélocité a (normalement forte), 'm' signifie vélocité b (vélocité moyenne) et 'p' signifie vélocité c (vélocité douce). Par exemple, si la signature rythmique est 7/8 avec des accents sur les première, quatrième et sixième notes de la mesure, nous pourrions utiliser ce qui suit

%%MIDI beatstring fppmpmp

%%MIDI transpose n

transpose la sortie du nombre spécifié de demi-tons. n peut être positif ou négatif.

%%MIDI rtranspose n

Transpose relativement du nombre spécifié de demi-tons. c'est-à-dire %%MIDI transpose a suivi de %%MIDI rtranspose b re

se traduit par une transposition de a+b. %%MIDI transpose b entraînera une transposition de b demi-tons, indépendamment de toute transposition précédente.

%%MIDI c n

spécifie le pitch MIDI qui correspond à c. La valeur par défaut est 60. Ce nombre devrait normalement être un multiple de 12.

%%MIDI grace a/b

définit la fraction de la note suivante que les notes d'ornement occuperont. a doit être compris entre 1 et b-1. Les notes d'ornement peuvent ne pas sonner naturelles dans cette approche, puisque la longueur des notes d'ornement individuelles varie avec la complexité de l'ornement et la longueur de la note suivante. Une approche différente (qui est maintenant par défaut) suppose que les notes d'ornement ont toujours une durée fixe. Pour utiliser l'autre approche, vous spécifieriez,

%%MIDI gracedivider b

où b spécifie en combien de parties diviser la longueur d'unité spécifiée par la commande de champ L:. Par exemple, si b = 4 et L: = 1/8, alors chaque note d'ornement ferait 1/(8*4) ou une double-croche. Le temps serait volé à la note à laquelle les notes d'ornement sont appliquées. Si cette note n'est pas assez longue pour gérer l'ornement, les notes d'ornement se verraient attribuer une durée de 0.

%%MIDI chordname name n1 n2 n3 n4 n5 n6

Définit comment jouer un accord de guitare appelé "name". n1 est généralement 0 et n2, n3 à n6 donnent les pitches des autres notes en demi-tons par rapport à la note fondamentale. Il peut y avoir moins de 6 notes dans l'accord, mais pas plus. Si "name" est déjà défini, cette commande le redéfinit. Contrairement à la plupart des autres commandes, les définitions de chordname restent en vigueur de l'endroit où elles sont définies jusqu'à la fin du fichier abc. L'exemple suivant illustre comment m, 7, m7 et maj7 pourraient être configurés s'ils n'étaient pas déjà définis.

%%MIDI chordname m 0 3 7
%%MIDI chordname 7 0 4 7 10
%%MIDI chordname m7 0 3 7 10
%%MIDI chordname maj7 0 4 7 11

%%MIDI gchord string

configure la manière dont les accords de guitare sont générés. La chaîne est une séquence composée de z, c, f et b pour les silences, les accords, la fondamentale et la fondamentale plus les notes de l'accord respectivement. Cela spécifie comment chaque mesure doit être jouée. Une longueur facultative peut suivre les z, c, f et b, par ex. czf2zf3. Si le fichier abc contient des accords de guitare, alors abc2midi ajoute automatiquement des accords et des fondamentales après avoir rencontré le premier accord de guitare. Il continue d'utiliser cet accord jusqu'à ce qu'un nouvel accord soit spécifié dans le fichier abc. Chaque fois que le champ M: est rencontré dans le fichier abc, une chaîne par défaut appropriée est définie :

Pour un temps 2/4 ou 4/4, la valeur par défaut est équivalente à : %%MIDI gchord fzczfzcz

Pour un temps 3/4, la valeur par défaut est équivalente à : %%MIDI gchord fzczcz

Pour un temps 6/8, la valeur par défaut est équivalente à : %%MIDI gchord fzcfzc

Pour un temps 9/8, la valeur par défaut est équivalente à : %%MIDI gchord fzcfzcfzc

La commande gchord a été étendue pour vous permettre de jouer les notes individuelles composant l'accord de guitare. Cela vous permet de jouer des accords brisés ou des arpèges. Les nouveaux codes g,h,i,j, G,H,I,J font référence aux notes individuelles en partant de la note la plus grave de l'accord (pas nécessairement la fondamentale dans le cas des renversements). Par exemple, pour l'accord de do majeur, g fait référence à C, h fait référence à E et i fait référence à G. Pour une commande gchord telle que,

%%MIDI gchord ghih

Abc2midi arpègera l'accord de guitare de do majeur en CEGE. Les lettres majuscules G, H, I et J font référence aux mêmes notes sauf qu'elles sont transposées d'une octave vers le bas. Notez que pour le premier renversement de l'accord de do majeur (indiqué par "C/E"), E serait la note la plus grave, donc g ferait référence à la note E.

Comme pour les autres codes gchord, vous pouvez ajouter un chiffre indiquant la durée de la note. Les mêmes règles s'appliquent que précédemment. Vous pouvez utiliser n'importe quelle combinaison des codes gchord, (fcbghijGHIJz).

%%MIDI chordprog n

Définit l'instrument MIDI pour les accords à être n. Si la commande inclut la chaîne octave=n où n est un nombre compris entre -2 et 2 inclus, alors cela déplacera le pitch de l'instrument de n octaves. Par exemple %%MIDI chordprog 10 octave=1.)

%%MIDI bassprog n

Définit l'instrument MIDI pour les notes de basse à être n. Si la commande inclut la chaîne octave=n où n est un nombre compris entre -2 et 2 inclus, alors cela déplacera le pitch de l'instrument de n octaves. Par exemple %%MIDI bassprog 10 octave=-1.)

%%MIDI chordvol n

Définit le volume (vélocité) des notes de l'accord à n.

%%MIDI bassvol n

Définit le volume (vélocité) des notes de basse à n. Il n'y a pas de commande melodyvol correspondante car il y a 3 valeurs de vélocité pour la mélodie, définies à l'aide de la commande beat.

%%MIDI gchordon

Active les accords de guitare (ils sont activés par défaut au début d'un morceau).

%%MIDI gchordoff

Désactive les accords de guitare.

%%MIDI droneon

Active un bourdon continu (utilisé dans la musique de cornemuse) composé de deux notes. Par défaut, les notes sont A et A,, jouées sur un basson à une vélocité de 80. Cela peut être configuré par la commande %%MIDI drone décrite ci-dessous.

%%MIDI droneoff

Désactive le bourdon continu.

%%MIDI drone n1 n2 n3 n4 n5

Définit les paramètres du bourdon où n1 est le programme MIDI, n2 et n3 spécifient les pitches MIDI des deux notes de l'accord, et n4 et n5 spécifient les vélocités MIDI des deux notes. Si vous ne définissez pas ces paramètres, ils sont par défaut 70 45 33 80 80. Une valeur de zéro ou moins indique que le réglage de ce paramètre doit être laissé tel quel.

%%MIDI drum string [drum programs] [drum velocities]

Cela configure un motif de batterie. La chaîne détermine quand il y a un temps de batterie et les valeurs de programme de batterie déterminent à quoi ressemble chaque frappe de batterie.

par ex. %%MIDI drum d2zdd 35 38 38 100 50 50

La chaîne peut contenir 'd' pour une frappe de batterie ou 'z' pour un silence. Par défaut, une voix commence sans motif de batterie et '%%MIDI drumon' est nécessaire pour activer la batterie. Le motif de batterie est répété pendant chaque mesure jusqu'à ce que '%%MIDI drumoff' soit rencontré. La commande %%MIDI drum peut être utilisée à l'intérieur d'un morceau pour changer le motif de batterie. Cette commande place les sons de batterie sur le canal 10 et suppose que votre générateur de sons est conforme au standard General Midi - s'il ne l'est pas, vous pourriez entendre des tons au lieu de sons de batterie.

Dans les commandes gchord et drum, la longueur de note standard d'une note unique f, c, z ou d n'est pas définie par la commande L:. Elle est plutôt ajustée pour que toute la chaîne gchord ou la chaîne de batterie tienne exactement dans une mesure. En d'autres termes, la durée de chaque note est divisée par la durée totale de la chaîne. Cela signifie que, par exemple, la chaîne de batterie "dd" est équivalente à la chaîne de batterie "d4d4". Vous ne pouvez actuellement pas spécifier de fractions directement (par ex. C3/2) comme on le fait dans le corps de la musique, mais il est toujours possible d'exprimer des rythmes complexes. Par exemple, pour indiquer un rythme tel que (3ddd d/d/d/d, vous écririez la chaîne "d4d4d4d3d3d3d3".

%%MIDI drumbars n

La ligne %%MIDI drum peut sonner assez monotone si elle est répétée à chaque mesure. Pour contourner ce problème, une nouvelle commande MIDI %%MIDI drumbars n où n est un petit nombre étalera la chaîne de batterie sur n mesures consécutives. Par défaut, drumbars est défini à 1, ce qui maintient la compatibilité avec les fichiers abc existants. Vous devez vous assurer que la chaîne de batterie est divisible de manière égale entre les mesures de drumbars. De plus, l'indication de mesure ne devrait pas changer entre les mesures d'une unité drumbars. (Fichier abc d'exemple dans doc/CHANGES du 24 juin 2008.)

%%MIDI gchordbars n

Cette commande étale la chaîne gchord sur n mesures consécutives tout comme drumbars (ci-dessus). (Un exemple se trouve dans doc/CHANGES du 17 mars 2009.)

Avec la version 1.54 du 4 décembre 2004 d'abc2midi, les notes dans les accords (par ex. [FAc]) ne sont pas jouées au même instant mais sont décalées et raccourcies de 10 unités de temps MIDI. Ainsi, la première note de l'accord (par ex. F) est jouée pour toute la durée indiquée, la deuxième note (par ex. A) commence 10 unités MIDI plus tard et est raccourcie du même montant, et la troisième note commence encore 10 unités MIDI plus tard et est raccourcie de 10 autres unités. Cela introduit une option "expressivo" et évite l'attaque lourde. (Cela ne s'applique pas aux gchords ni aux accords multivoix.) Le montant du décalage et du raccourcissement peut être configuré par la commande MIDI

%%MIDI chordattack n

où n est un petit nombre. Si n est zéro, alors abc2midi devrait se comporter comme dans les versions précédentes. Le délai n est en unités de temps MIDI où il y a 480 unités dans un temps de noire. Le programme peut ne pas fonctionner correctement si n est trop grand et qu'il y a des accords courts.

%%MIDI randomchordattack n

Comme ci-dessus sauf que le délai est une variable aléatoire distribuée uniformément entre 0 et n-1.

%%MIDI trim x/y

où x et y sont deux nombres. Cette commande contrôle l'articulation des notes et des accords en plaçant des silences entre les notes. La longueur de ces silences est déterminée par x/y et la longueur d'unité spécifiée par la commande L:. Ces silences sont produits en raccourcissant les notes du même montant. Si la note est déjà plus courte que l'écart spécifié, alors l'écart est fixé à la moitié de la longueur de la note. La fraction x/y indique une durée de note de la même manière que spécifié dans le fichier abc. La durée réelle est basée sur la longueur d'unité spécifiée par la commande de champ L:. Il est recommandé que x/y soit une fraction proche de zéro. Le raccourcissement des notes est désactivé à l'intérieur des liaisons (slurs) spécifiées par des parenthèses. Vous pouvez désactiver tout raccourcissement des notes en définissant x à 0, par ex. 0/1. Par défaut, le raccourcissement des notes est désactivé au début d'un morceau ou d'une commande de voix.

%%MIDI expand x/y

où x et y sont deux nombres définissant une fraction inférieure à 1. Cette commande contrôle l'articulation des notes et des accords de la manière inverse. Les notes sont allongées de cette fraction pour qu'elles se chevauchent avec le début de la note suivante.

%%MIDI drummap note midipitch

Veuillez consulter abcguide.txt.

%%MIDI ptstress filename

Cette commande charge le fichier filename dans abc2midi, qui contient les paramètres de stress de Phil Taylor, et met abc2midi dans le mode où il applique ces paramètres de stress à chaque note. Ce modèle fonctionne en opposition au modèle de temps (beat) standard, de sorte que les commandes MIDI beat, beatstring, beatmod deviennent inefficaces. Cela signifie aussi que les indications de dynamique !f! !pp! etc. ne fonctionnent plus.

Il y a deux implémentations différentes du modèle de stress. Le modèle 1 modifie l'articulation de la note et prend également le contrôle des paramètres MIDI trim. Pour revenir au modèle standard, mettez la commande %%MIDI beataccents. Le modèle 2 modifie à la fois le début et la fin de chaque note, permettant à un temps musical de s'étendre ou de se contracter dans le temps. Cependant, la longueur d'une mesure musicale devrait être préservée. Notez que si vous utilisez le modèle 2, qui est l'actuel par défaut, vous devez inclure -BF comme l'un des paramètres d'exécution d'abc2midi.

Le modèle divise une mesure en segments égaux. Pour chaque segment, une valeur der La vélocité MIDI est spécifiée et un multiplicateur de durée est spécifié. Si une note tombe dans un segment spécifique, elle prend la vélocité de ce segment et sa durée est modifiée en conséquence. Si la note chevauche plusieurs segments, alors la note prend la moyenne de ces valeurs de segment.

Le fichier d'entrée spécifie le nombre de segments et les multiplicateurs de volume sonore et de durée pour chaque segment. Le fichier a le format suivant. La première valeur est le nombre de segments et chaque ligne spécifie le multiplicateur de vélocité et de durée du segment spécifique. La vélocité est limitée à 127 et la durée est un nombre décimal. Les durées des notes sont modifiées en faisant varier l'écart entre les notes, il n'est donc pas possible de prolonger une note. Cela préserve le tempo régulier de la musique. Le programme met à l'échelle les indications de durée des notes en les divisant par la valeur maximale qui est ici de 1,4.

%%MIDI stressmodel n

où n est 1 ou 2, sélectionne l'implémentation du modèle de stress.


d'autres commandes %%MIDI telles que bendvelocity, bendstring, controlstring ont été introduites récemment et sont décrites dans le fichier abcguide.txt.

COMPATIBILITÉ AVEC LE PROJET DE NORME 2.0

La norme proposée introduit un nouveau champ de copyright en utilisant la syntaxe

%%abc-copyright (c) Copyright John Smith 2003

Abc2midi insère maintenant cela dans le fichier MIDI sous la forme d'une balise métatextuelle de copyright. Des modifications ont été apportées à la fonction event_specific dans store.c pour traiter les informations de copyright. Elles sont également copiées dans la piste Karaoke (si elle est créée) sous la forme d'un champ @T.
