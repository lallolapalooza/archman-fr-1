VALEURS DE

RETOUR

Le code de sortie de la commande abidiff est soit 0 si l'ABI des binaires comparés sont égaux, soit non nul s'ils diffèrent ou si l'outil a rencontré une

erreur.

Dans le dernier cas, le code de sortie est un champ de bits de 8 bits dans lequel chaque bit a une signification

spécifique.

Le premier bit, de valeur 1, nommé ABIDIFF_ERROR signifie qu'il y a eu une

erreur.

Le deuxième bit, de valeur 2, nommé ABIDIFF_USAGE_ERROR signifie qu'il y a eu une erreur dans la manière dont l'utilisateur a invoqué l'outil. Il peut être défini, par exemple, si l'utilisateur a invoqué l'outil avec une option de ligne de commande inconnue, avec un nombre ou un argument incorrect, etc. Si ce bit est défini, alors le bit ABIDIFF_ERROR doit également être

défini.

Le troisième bit, de valeur 4, nommé ABIDIFF_ABI_CHANGE signifie que l'ABI des binaires comparés est

différente.

Le quatrième bit, de valeur 8, nommé ABIDIFF_ABI_INCOMPATIBLE_CHANGE signifie que l'ABI des binaires comparés sont différentes de manière incompatible. Si ce bit est défini, alors le bit ABIDIFF_ABI_CHANGE doit également être défini. Si le ABIDIFF_ABI_CHANGE est défini et que le ABIDIFF_INCOMPATIBLE_CHANGE n'est PAS défini, alors cela signifie que les ABI comparées pourraient être compatibles ou non. Dans ce cas, un être humain doit examiner les changements d'ABI pour décider s'ils sont compatibles ou

non.

Notez qu'à l'heure actuelle, il n'y a que quelques types de changements d'ABI qui entraîneraient la définition du drapeau ABIDIFF_ABI_INCOMPATIBLE_CHANGE. Ces changements d'ABI sont soit

:
  • la suppression du symbole d'une fonction ou d'une variable qui a été définie et
    • exportée.
  • la modification de l'
    • index d'un membre d'
une table de fonction
s virtuelles (pour
les programmes e
t bibliothèques C++).

Avec le temps, lorsque plus de motifs de changement d'ABI seront trouvés pour constituer toujours des changements d'ABI incompatibles, nous adapterons le code pour reconnaître ces cas et définir le ABIDIFF_ABI_INCOMPATIBLE_CHANGE en conséquence. Donc, si vous trouvez de tels motifs, faites-le nous

savoir.

Les bits restants

ne sont pas utilis
és pour le moment.
