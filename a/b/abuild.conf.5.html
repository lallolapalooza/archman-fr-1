abuild.conf(5) Manuel des formats de fichiers abuild.conf(5)

NOM

abuild.conf - fichier de configuration pour abuild

DESCRIPTION

abuild.conf est la configuration du programme abuild(1).

FORMAT

Le fichier de configuration est analysé comme un script shell ; les variables sont définies comme des variables shell normales.

Pour une liste des variables supportées, voir la section ENVIRONNEMENT de la page de manuel de abuild(1).

EXEMPLE

PACKAGER_PRIVKEY="/home/jane/.abuild/jane@example.com-87ac18ca.rsa"
PACKAGER="Jane Doe <jane@example.com>"
USE_COLORS=1
