abump(1) Manuel des commandes générales abump(1)

NOM

abump - incrémente la version du paquet (pkgver) dans un fichier APKBUILD

SYNTAXE

abump [-s CVE-1,...] [-f ISSUE] [-b|--branch] [-k|--keep] NOM_PAQUET-1.2.3

DESCRIPTION

abump met à jour le pkgver dans un fichier APKBUILD, met à jour ses sommes de contrôle, le reconstruit, et enfin crée un nouveau commit avec les modifications résultantes.

abump recherche le paquet spécifié dans les répertoires imbriqués du répertoire de travail actuel, en supposant une structure similaire à celle du dépôt aports.

OPTIONS

-s, --security CVE1,...

Inclut le numéro CVE dans la section de commentaire secfixes.

-f, --fixes ISSUE

Inclut Fixes #ISSUE dans le message de commit. Ceci fermera le problème (issue) en amont lorsque le commit sera fusionné dans la branche principale (master) de aports.

-b, --branch

Crée une branche git à partir de HEAD avant l'opération normale.

-k, --keep

Conserve les paquets existants.

-h, --help

Affiche les informations d'aide et quitte.

ENVIRONNEMENT

APORTSDIR

Force l'opération sur un répertoire alternatif.

EXEMPLES

abump mml-1.0.0
abump glibmm2.68-2.78.0
abump telegram-desktop-4.11.8

VOIR AUSSI

abuild(1), apkgrel(1), newapkbuild(1), APKBUILD(5), apk(8).
