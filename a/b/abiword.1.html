ABIWORD(1) Manuel des commandes générales ABIWORD(1)

NOM

abiword — traitement de texte flexible et multiplateforme

SYNOPIS

abiword [OPTIONS] [FICHIER...]

DESCRIPTION

AbiWord est une application de traitement de texte complète et efficace, adaptée à un large éventail de tâches de traitement de texte, et extensible grâce à une variété de plugins. Il s'intègre avec enchant(1) pour fournir la vérification orthographique.

OPTIONS

-g LxH[+X+Y], --geometry=LxH[+X+Y]
Spécifie la géométrie de la fenêtre au démarrage.
-E PLUGIN, --plugin=PLUGIN
Exécute le plugin spécifié au lieu de l'application principale.
--import-extension=EXT
Importe le fichier donné comme s'il avait l'extension EXT, annulant la détection automatique du type de fichier.
-u PROFIL, --userprofile=PROFIL
Utilise PROFIL pour lire et stocker les paramètres au lieu du profil par défaut dans XDG_CONFIG_HOME/abiword/profile.
-t DEST, --to=DEST
Convertit le fichier donné dans un autre format, en écrivant le résultat dans DEST. Le format de DEST est déterminé par son extension.
Voir aussi --to=FORMAT et --to-name.
-t FORMAT, --to=FORMAT
Convertit le(s) fichier(s) donné(s) dans le format spécifié. Sauf si explicitement spécifié avec --to-name, le nom du fichier d'origine sera utilisé (avec une extension différente, si nécessaire). Voir aussi EXEMPLES.
Les valeurs les plus courantes pour FORMAT incluent :
abw Format XML d'Abiword (zabw pour la compression gzip, bzabw pour la compression bzip2)
dbk DocBook XML
doc Format binaire de Microsoft Word
docx Office Open XML (versions plus récentes de Microsoft Word)
html Hypertext Markup Language
kwd KWord
odt OpenDocument Text
pdf Portable Document Format
rtf Rich Text Format
sxw OpenOffice.org Writer 1.0
txt Texte brut
--to-name=DEST
Uniquement utile en conjonction avec --to=FORMAT. Spécifie où le document converti doit être écrit.
--verbose=NIVEAU
Définit le niveau de verbosité [0-2], 2 donnant la sortie la plus détaillée.
-h, --help
Affiche un court message d'aide et quitte.
--version
Rapporte la version d'AbiWord.

VARIABLES D'ENVIRONNEMENT

HOME
Définit le répertoire personnel de l'utilisateur.
XDG_CONFIG_HOME
Définit le répertoire de base par rapport auquel les fichiers de configuration spécifiques à l'utilisateur doivent être stockés. (Voir la Spécification des répertoires de base XDG pour plus de détails.)

FICHIERS

XDG_CONFIG_HOME/abiword/profile
Le fichier de profil utilisateur par défaut. (Si XDG_CONFIG_HOME n'est pas défini ou est vide, une valeur par défaut égale à HOME/.config sera utilisée.)

EXEMPLES

Pour convertir le document example.abw en RTF :
abiword --to=rtf example.abw
Le fichier résultant sera nommé example.rtf.

Pour imprimer un document :
abiword --to=ps --to-name=fd://1 NOM_FICHIER | lp

SIGNALER LES BOGUES

Signalez les bogues au système de suivi des bogues Bugzilla à l'adresse http://bugzilla.abisource.com.

HISTORIQUE

AbiWord a été lancé en 1998 par AbiSource Inc., une société fondée par SourceGear corporation. Le plan initial était de construire une suite bureautique gratuite nommée AbiSuite, comprenant des applications de traitement de texte, de tableur et de présentation. Comme ils n'avaient pas de produit utilisable lorsque leur capital-risque était épuisé, le code déjà développé (à savoir AbiWord) a été rendu open source. Le développement d'AbiWord a ensuite été repris par des bénévoles et est dirigé par la communauté à ce jour.
