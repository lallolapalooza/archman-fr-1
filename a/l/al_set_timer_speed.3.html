al_set_timer_speed(3) Manuel des fonctions de bibliothèque al_set_timer_speed(3)

NOM

al_set_timer_speed - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
void al_set_timer_speed(ALLEGRO_TIMER *timer, double new_speed_secs)

DESCRIPTION

Définit la vitesse du minuteur, c'est-à-dire la fréquence à laquelle son compteur sera incrémenté lorsqu'il est démarré. Cela peut être fait lorsque le minuteur est démarré ou arrêté. Si le minuteur est en cours d'exécution, il est fait comme si le changement de vitesse s'était produit précisément au dernier tic.

speed_secs a exactement la même signification qu'avec al_create_timer(3).
