NOM

alpm-buildinfo-create-v2 - Créer un fichier BUILDINFO version 2

SYNTAXE

alpm-buildinfo create v2 <--builddate> <--builddir> [--buildenv] [--installed] [--options] <--packager> <--pkgarch> <--pkgbase> <--pkgbuild-sha256sum> <--pkgname> <--pkgver> <--startdir> <--buildtool> <--buildtoolver> [-h|--help] [FICHIER]

DESCRIPTION

Créer un fichier BUILDINFO version 2

OPTIONS

--builddate <DATE_COMPILATION>
Fournir une date de compilation
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_BUILDDATE.
--builddir <REPERTOIRE_COMPILATION>
Fournir un répertoire de compilation
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_BUILDDIR.
--buildenv <ENVIRONNEMENT_COMPILATION>
Fournir un ou plusieurs environnements de compilation
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_BUILDENV.
--installed <INSTALLE>
Fournir un ou plusieurs paquets installés
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_INSTALLED.
--options <OPTIONS>
Fournir une ou plusieurs options
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_OPTIONS.
--packager <CONFECTIONNEUR>
Fournir un confectionneur
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_PACKAGER.
--pkgarch <ARCH_PAQUET>
Fournir une architecture de paquet
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_PKGARCH.
--pkgbase <BASE_PAQUET>
Fournir une base de paquet
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_PKGBASE.
--pkgbuild-sha256sum <SOMME_SHA256_PKGBUILD>
Fournir une somme SHA256 du PKGBUILD
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_PKGBUILD_SHA256SUM.
--pkgname <NOM_PAQUET>
Fournir un nom de paquet
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_PKGNAME.
--pkgver <VERSION_PAQUET>
Fournir une version de paquet
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_PKGVER.
--startdir <REPERTOIRE_DEMARRAGE>
Fournir un répertoire de démarrage
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_STARTDIR.
--buildtool <OUTIL_COMPILATION>
Fournir un outil de compilation
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_BUILDTOOL.
--buildtoolver <VERSION_OUTIL_COMPILATION>
Fournir une version d'outil de compilation
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_BUILDTOOLVER.
-h, --help
Afficher l'aide
[FICHIER] [défaut : .BUILDINFO]
Fournir un fichier d'écriture
Peut aussi être spécifié avec la variable d'environnement BUILDINFO_OUTPUT_FILE.
