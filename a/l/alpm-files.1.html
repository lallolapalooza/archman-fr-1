alpm-files(1) Manuel des commandes générales alpm-files(1)

NOM

alpm-files - Interface en ligne de commande pour interagir avec les données alpm-files.

SYNTAXE

alpm-files [-h|--help] [-V|--version] <sous-commandes>

DESCRIPTION

Interface en ligne de commande pour interagir avec les fichiers alpm-files.

Cette interface en ligne de commande interagit avec le format de fichier alpm-files : https://alpm.archlinux.page/specifications/alpm-files.5.html

OPTIONS

-h, --help
Afficher l'aide (voir un résumé avec '-h')
-V, --version
Afficher la version

SOUS-COMMANDES

alpm-files-create(1)
Créer des données alpm-files à partir d'un répertoire.
alpm-files-format(1)
Lire et valider des données alpm-files et les retourner dans un autre format de fichier.
alpm-files-validate(1)
Valider un fichier alpm-files.
alpm-files-help(1)
Afficher ce message ou l'aide des sous-commandes spécifiés.

VERSION

v0.1.0
