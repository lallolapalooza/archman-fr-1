NOM

al_android_set_apk_fs_interface - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_android.h>
void al_android_set_apk_fs_interface(void)

DESCRIPTION

Cette fonction mettra en place une ALLEGRO_FS_INTERFACE(3) personnalisée qui permet de travailler dans le système de fichiers de l'APK. La racine du système de fichiers est votre répertoire d'assets et il y a un accès en lecture seule à tous les fichiers qu'il contient.

Note : Certaines fonctionnalités comme l'interrogation de la taille ou des attributs des fichiers ne sont pas prises en charge par celle-ci. Vous pouvez toujours utiliser le module PhysFS pour ouvrir le fichier APK (c'est juste un fichier .zip ordinaire) et obtenir des informations plus complètes.
