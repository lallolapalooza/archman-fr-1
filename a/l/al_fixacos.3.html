al_fixacos(3) Manuel des fonctions de bibliothèque al_fixacos(3)

NOM

al_fixacos - API Allegro 5

SYNOPIS

#include <allegro5/allegro.h>
al_fixed al_fixacos(al_fixed x);

DESCRIPTION

Cette fonction calcule le cosinus inverse d'une valeur à l'aide d'une table de correspondance. L'entrée doit être une valeur en virgule fixe. Le cosinus inverse est défini uniquement dans le domaine de -1 à 1. En dehors de cette plage d'entrée, la fonction définira errno d'Allegro sur EDOM et renverra zéro.

Exemple :

al_fixed result;
/* Définit result à l'angle binaire 128. */
result = al_fixacos(al_itofix(-1));

VALEUR DE RETOUR

Renvoie le sinus inverse d'une valeur en virgule fixe, mesuré comme un angle en format binaire virgule fixe, ou zéro si l'entrée était hors plage. Toutes les valeurs de retour de cette fonction seront comprises dans la plage de 0 à 128.
