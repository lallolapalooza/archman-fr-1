(7) Manuel d'informations diverses (7)

NOM

comparison - déclarations de comparaison pour les paquets basés sur ALPM.

DESCRIPTION

Le format comparison est un format de comparaison de versions, utilisé pour représenter des déclarations de comparaison de versions pour les paquets basés sur ALPM dans une expression de comparaison composite. Ce format est utilisé dans les scripts de construction ou les formats de fichiers pour les métadonnées de paquets (par exemple, dans PKGBUILD ou PKGINFO) pour décrire les limites de version pour une relation de paquet.

Une déclaration comparison utilise l'un des opérateurs de comparison suivants pour spécifier une relation de limite de version :

  • < (plus petit que)
  • <= (plus petit ou égal à)
  • = (égal à)
  • >= (plus grand ou égal à)
  • > (plus grand que)

Expressions de comparaison composites

Les expressions de comparaison composites se composent d'un nom-de-paquet-alpm, suivi directement d'un opérateur de comparaison, suivi directement d'une version-de-paquet-alpm.

Expressions de comparaison correspondantes

La correspondance des noms est effectuée sur la base d'une correspondance textuelle complète en utilisant le composant nom-de-paquet-alpm de l'expression de comparaison composite.

La comparaison des versions est effectuée sur la base des composants d'une chaîne de version composite (voir par exemple alpm-epoch, alpm-pkgver et alpm-pkgrel). Comme la version-de-paquet-alpm offre plusieurs formes, cela permet de faire correspondre une variété de scénarios.

Lors de la fourniture de la forme complète ou complète avec epoch du format version-de-paquet-alpm, elle correspond à une seule version spécifique d'une version de paquet. Lors de la fourniture de la forme minimale ou minimale avec epoch du format version-de-paquet-alpm, elle correspond à n'importe quelle version d'une version de paquet.

En fonction de l'opérateur de comparaison, la correspondance donnée avec nom-de-paquet-alpm et version-de-paquet-alpm est étroite (c'est-à-dire =), large avec une borne inférieure (c'est-à-dire >, >=) ou large avec une borne supérieure (c'est-à-dire <, <=).

EXEMPLES

Les expressions de comparaison composites ci-dessous peuvent correspondre à un paquet nommé example dans des versions spécifiques :

"example<1.0.0"

Une version inférieure à ‘1.0.0’ (par exemple ‘0.8.0-1’).

"example<=1.0.0"

Une version inférieure ou égale à ‘1.0.0’ (par exemple ‘0.8.0-1’ ou ‘1.0.0-3’).

"example<=1.0.0-1"

Une version inférieure ou égale à ‘1.0.0-1’ (par exemple ‘0.8.0-1’ ou ‘1.0.0-1’, mais ‘1.0.0-2’ ne fonctionne pas).

"example=1.0.0"

N'importe quelle version ‘1.0.0’ (par exemple ‘1.0.0-1’ ou ‘1.0.0-2’, etc.).

"example=1.0.0-1"

La version ‘1.0.0-1’.

"example=1:1.0.0-1"

La version ‘1:1.0.0-1’.

"example>=1.0.0"

Une version supérieure ou égale à ‘1.0.0’ (par exemple ‘1.0.0-1’ ou ‘1.1.0-1’).

"example>1.0.0"

Une version supérieure à ‘1.0.0’ (par exemple ‘1.1.0-1’ ou ‘1:1.0.0-1’).
