NOM

Alien::Build::rc - Configuration locale d'Alien::Build

VERSION

version 2.84

SYNTAXE

dans votre "~/.alienbuild/rc.pl" :

preload 'Foo::Bar';
postload 'Baz::Frooble';

DESCRIPTION

Alien::Build chargera votre fichier "~/.alienbuild/rc.pl", s'il existe, avant d'exécuter la recette de l'alienfile. Cela vous permet de modifier le comportement des Aliens d'Alien::Build en fonction de vos besoins de configuration locaux. Par exemple, vous pouvez demander une confirmation avant de télécharger du contenu distant ou récupérer depuis un miroir local.
