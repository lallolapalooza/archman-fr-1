al_clear_depth_buffer(3) Manuel des fonctions de bibliothèque al_clear_depth_buffer(3)

NOM

al_clear_depth_buffer - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
void al_clear_depth_buffer(float z)

DESCRIPTION

Efface le tampon de profondeur (limité par le rectangle de découpe) à la valeur donnée. Un tampon de profondeur n'est disponible que s'il a été demandé avec al_set_new_display_option(3) et que l'exigence a pu être satisfaite par l'appel al_create_display(3) créant l'affichage courant. Les opérations impliquant le tampon de profondeur sont également affectées par al_set_render_state(3).

Par exemple, si ALLEGRO_DEPTH_FUNCTION est défini à ALLEGRO_RENDER_LESS, alors une valeur de tampon de profondeur de 1 représente une distance infinie, et est donc une bonne valeur à utiliser lors de l'effacement du tampon de profondeur.
