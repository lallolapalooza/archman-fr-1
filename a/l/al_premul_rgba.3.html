al_premul_rgba(3) Manuel des fonctions de bibliothèque al_premul_rgba(3)

NOM

al_premul_rgba - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
ALLEGRO_COLOR al_premul_rgba(
   unsigned char r, unsigned char g, unsigned char b, unsigned char a)

DESCRIPTION

Ceci est un raccourci pour al_map_rgba(3)(r * a / 255, g * a / 255, b * a / 255, a).

Par défaut, Allegro utilise l'alpha pré-multiplié pour la transparence des bitmaps et des primitives (voir al_load_bitmap_flags(3) pour une discussion sur cette fonctionnalité). Cela signifie que si vous souhaitez teinter un bitmap ou une primitive pour qu'il soit transparent, vous devez multiplier les composantes de couleur par les composantes alpha lorsque vous les passez à cette fonction. Par exemple :

int r = 255;
int g = 0;
int b = 0;
int a = 127;
ALLEGRO_COLOR c = al_premul_rgba(r, g, b, a);
/* Dessine le bitmap teinté en rouge et semi-transparent. */
al_draw_tinted_bitmap(bmp, c, 0, 0, 0);

Cette fonction peut être appelée avant l'initialisation d'Allegro.
