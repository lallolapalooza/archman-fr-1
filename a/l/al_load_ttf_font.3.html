NOM

al_load_ttf_font - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_ttf.h>
ALLEGRO_FONT *al_load_ttf_font(char const *filename, int size, int flags)

DESCRIPTION

Charge une police TrueType à partir d'un fichier en utilisant la bibliothèque FreeType. En citant la FAQ de FreeType, cela signifie la prise en charge de nombreux formats de polices différents :

TrueType, OpenType, Type1, CID, CFF, Windows FON/FNT, X11 PCF, et autres

Le paramètre size détermine la taille à laquelle la police sera rendue, spécifiée en pixels. La taille de police standard est mesurée en unités par EM ; si vous souhaitez plutôt spécifier la taille comme la hauteur totale des glyphes en pixels, passez-la comme une valeur négative.

Remarque : Si vous souhaitez afficher du texte dans plusieurs tailles, chargez la police plusieurs fois avec des paramètres de taille différents.

Les indicateurs suivants sont pris en charge :

•
ALLEGRO_TTF_NO_KERNING - N'utilise aucun crénage même si le fichier de police le prend en charge.
•
ALLEGRO_TTF_MONOCHROME - Charge comme une police monochrome (ce qui signifie qu'aucun anti-crénage de la police n'est effectué).
•
ALLEGRO_TTF_NO_AUTOHINT - Désactive l'Auto Hinter qui est activé par défaut dans les versions plus récentes de FreeType. Depuis : 5.0.6, 5.1.2

VOIR AUSSI
