ALTER_OPERATOR(7)

Paquet: postgresql

Licences: PostgreSQL

ALTER OPERATOR(7) Documentation PostgreSQL 18.1 ALTER OPERATOR(7)

NOM

ALTER_OPERATOR - modifier la définition d'un opérateur

SYNTAXE

ALTER OPERATOR nom ( { type_gauche | NONE } , type_droit )
    OWNER TO { nouvel_proprietaire | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER OPERATOR nom ( { type_gauche | NONE } , type_droit )
    SET SCHEMA nouveau_schema
ALTER OPERATOR nom ( { type_gauche | NONE } , type_droit )
    SET ( {  RESTRICT = { proc_restriction | NONE }
           | JOIN = { proc_jointure | NONE }
           | COMMUTATOR = op_commutateur
           | NEGATOR = op_negateur
           | HASHES
           | MERGES
          } [, ... ] )

DESCRIPTION

ALTER OPERATOR modifie la définition d'un opérateur.

Vous devez être propriétaire de l'opérateur pour utiliser ALTER OPERATOR. Pour modifier le propriétaire, vous devez pouvoir vous déconnecter en tant que rôle du nouvel propriétaire, et ce rôle doit avoir le privilège CREATE sur le schéma de l'opérateur. (Ces restrictions garantissent que la modification du propriétaire n'entraîne rien que vous ne pourriez faire en supprimant et recréant l'opérateur. Cependant, un superutilisateur peut modifier la propriété de n'importe quel opérateur.)

PARAMÈTRES

nom

Le nom (éventuellement qualifié par un schéma) d'un opérateur existant.

type_gauche

Le type de données de l'opérande gauche de l'opérateur ; écrivez NONE si l'opérateur n'a pas d'opérande gauche.

type_droit

Le type de données de l'opérande droit de l'opérateur.

nouvel_proprietaire

Le nouvel propriétaire de l'opérateur.

nouveau_schema

Le nouveau schéma pour l'opérateur.

proc_restriction

La fonction d'estimation de la sélectivité de restriction pour cet opérateur ; écrivez NONE pour supprimer l'estimateur de sélectivité existant.

proc_jointure

La fonction d'estimation de la sélectivité de jointure pour cet opérateur ; écrivez NONE pour supprimer l'estimateur de sélectivité existant.

op_commutateur

Le commutateur de cet opérateur. Ne peut être modifié que si l'opérateur n'a pas de commutateur existant.

op_negateur

Le négateur de cet opérateur. Ne peut être modifié que si l'opérateur n'a pas de négateur existant.

HASHES

Indique que cet opérateur peut supporter une jointure par hachage. Ne peut être activé et non désactivé.

MERGES

Indique que cet opérateur peut supporter une jointure par fusion. Ne peut être activé et non désactivé.

NOTES

Se référer aux sections 36.14 et 36.15 pour plus d'informations.

Comme les commutateurs existent par paires qui sont des commutateurs l'un de l'autre, ALTER OPERATOR SET COMMUTATOR définira également le commutateur de op_commutateur comme étant l'opérateur cible. De même, ALTER OPERATOR SET NEGATOR définira également le négateur de op_negateur comme étant l'opérateur cible. Par conséquent, vous devez posséder l'opérateur commutateur ou négateur ainsi que l'opérateur cible.

EXEMPLES

Changer le propriétaire d'un opérateur personnalisé a @@ b pour le type text :

ALTER OPERATOR @@ (text, text) OWNER TO joe;

Changer les fonctions d'estimation de la sélectivité de restriction et de jointure d'un opérateur personnalisé a && b pour le type int[] :

ALTER OPERATOR && (int[], int[]) SET (RESTRICT = _int_contsel, JOIN = _int_contjoinsel);

Marquer l'opérateur && comme étant son propre commutateur :

ALTER OPERATOR && (int[], int[]) SET (COMMUTATOR = &&);

COMPATIBILITÉ

Il n'y a pas d'instruction ALTER OPERATOR dans la norme SQL.

VOIR AUSSI

CREATE OPERATOR (CREATE_OPERATOR(7)), DROP OPERATOR (DROP_OPERATOR(7))
