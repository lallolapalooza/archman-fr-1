NAME

alacritty-bindings - Alacritty configuration file format

SYNOPSIS

This manual page describes the default key bindings configuration for Alacritty.

MOUSE BINDINGS

By default, Alacritty provides the following mouse bindings:

| Mouse Button | Modifiers | Action         |
|--------------|-----------|----------------|
| Left Click   | (none)    | SelectWord     |
| Left Click   | Shift     | SelectRange    |
| Left Click   | Alt       | SelectLine     |
| Left Click   | Command   | SelectWord     |
| Middle Click | (none)    | Paste          |
| Middle Click | Alt       | SearchWord     |
| Middle Click | Command   | PasteSelection |
| Right Click  | (none)    | ContextMenu    |
| Right Click  | Alt       | Search         |
| Right Click  | Command   | ContextMenu    |

KEY BINDINGS

By default, Alacritty provides the following key bindings:

"W" "Command" "Quit"
"N" "Command" "CreateNewWindow"
"T" "Command" "CreateNewTab"
"F" "Command|Control" "ToggleFullscreen"
"F" "Command" "~Search" "SearchForward"
"B" "Command" "~Search" "SearchBackward"
"]" "Command|Shift" "SelectNextTab"
"[" "Command|Shift" "SelectPreviousTab"
"Tab" "Command" "SelectNextTab"
"Tab" "Command|Shift" "SelectPreviousTab"
"1" "Command" "SelectTab1"
"2" "Command" "SelectTab2"
"3" "Command" "SelectTab3"
"4" "Command" "SelectTab4"
"5" "Command" "SelectTab5"
"6" "Command" "SelectTab6"
"7" "Command" "SelectTab7"
"8" "Command" "SelectTab8"
"9" "Command" "SelectLastTab"
