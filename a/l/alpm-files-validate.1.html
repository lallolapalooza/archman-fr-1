NOM

alpm-files-validate - Valider un fichier alpm-files.

SYNTAXE

alpm-files validate [-i|--input-file] [-h|--help]

DESCRIPTION

Valide un fichier alpm-files.

Si le fichier peut être validé, le programme se termine sans sortie et avec un code de sortie de zéro. Si le fichier ne peut pas être validé, une erreur est émise sur stderr et le programme se termine avec un code de sortie non nul.

OPTIONS

-i, --input-file <FICHIER_ENTREE>
Un fichier d'entrée à lire.

Si aucun fichier n'est fourni, stdin est utilisé à la place.

Peut également être spécifié avec la variable d'environnement ALPM_FILES_VALIDATE_INPUT_FILE.
-h, --help
Affiche l'aide (voir un résumé avec '-h')
alpm-files-validate
