ALLEGRO_PRIM_ATTR(3) Manuel des fonctions de la bibliothèque ALLEGRO_PRIM_ATTR(3)

NOM

ALLEGRO_PRIM_ATTR - API Allegro 5

SYNTAXE

#include <allegro5/allegro_primitives.h>
typedef enum ALLEGRO_PRIM_ATTR

DESCRIPTION

Énumère les types d'attributs de sommet qu'un sommet personnalisé peut avoir.

•
ALLEGRO_PRIM_POSITION - Informations de position, ne peuvent être stockées que dans ALLEGRO_PRIM_SHORT_2, ALLEGRO_PRIM_FLOAT_2 et ALLEGRO_PRIM_FLOAT_3.
•
ALLEGRO_PRIM_COLOR_ATTR - Informations de couleur, stockées dans une ALLEGRO_COLOR(3). Le champ de stockage d'ALLEGRO_VERTEX_ELEMENT est ignoré.
•
ALLEGRO_PRIM_TEX_COORD - Informations de coordonnées de texture, ne peuvent être stockées que dans ALLEGRO_PRIM_FLOAT_2 et ALLEGRO_PRIM_SHORT_2. Ces coordonnées sont normalisées par la largeur et la hauteur de la texture, ce qui signifie que le coin inférieur droit a des coordonnées de texture de (1, 1).
•
ALLEGRO_PRIM_TEX_COORD_PIXEL - Informations de coordonnées de texture, ne peuvent être stockées que dans ALLEGRO_PRIM_FLOAT_2 et ALLEGRO_PRIM_SHORT_2. Ces coordonnées sont mesurées en pixels.
•
ALLEGRO_PRIM_USER_ATTR - Un attribut spécifié par l'utilisateur. Vous pouvez utiliser n'importe quel stockage pour cet attribut. Vous pouvez avoir au maximum ALLEGRO_PRIM_MAX_USER_ATTR (actuellement 10) de ceux-ci que vous pouvez spécifier en ajoutant un index à la valeur d'ALLEGRO_PRIM_USER_ATTR, par exemple, le premier attribut utilisateur est ALLEGRO_PRIM_USER_ATTR + 0, le second est ALLEGRO_PRIM_USER_ATTR + 1 et ainsi de suite.

Pour accéder à ces attributs personnalisés à partir de shaders GLSL, vous devez déclarer des attributs qui suivent cette nomenclature : al_user_attr_# où # est l'index de l'attribut.

Par exemple, pour avoir une position et un vecteur normal pour chaque sommet, vous pourriez le déclarer comme ceci :

ALLEGRO_VERTEX_ELEMENT elements[3] = {
    {ALLEGRO_PRIM_POSITION, ALLEGRO_PRIM_FLOAT_3, 0},
    {ALLEGRO_PRIM_USER_ATTR + 0, ALLEGRO_PRIM_FLOAT_3, 12},
    {0, 0, 0}};

Et ensuite, dans votre shader de sommet, y accéder comme ceci :

attribute vec3 al_pos; // ALLEGRO_PRIM_POSITION
attribute vec3 al_user_attr_0; // ALLEGRO_PRIM_USER_ATTR + 0
varying float light;
const vec3 light_direction = vec3(0, 0, 1);
void main() {
    light = dot(al_user_attr_0, light_direction);
    gl_Position = al_pos;
}

Pour accéder à ces attributs personnalisés à partir de HLSL, vous devez déclarer un paramètre avec les sémantiques suivantes : TEXCOORD{# + 2} où # est l'index de l'attribut. Par exemple, le premier attribut peut être accédé via TEXCOORD2, le deuxième via TEXCOORD3 et ainsi de suite.

Depuis : 5.1.6
