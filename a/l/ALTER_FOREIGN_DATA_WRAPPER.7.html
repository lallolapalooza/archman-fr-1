ALTER FOREIGN DATA WRAPPER(7) Documentation PostgreSQL 18.1 ALTER FOREIGN DATA WRAPPER(7)

NOM

ALTER_FOREIGN_DATA_WRAPPER - modifier la définition d'un wrapper de données étrangères

SYNTAXE

ALTER FOREIGN DATA WRAPPER nom
    [ HANDLER fonction_gestionnaire | NO HANDLER ]
    [ VALIDATOR fonction_validateur | NO VALIDATOR ]
    [ OPTIONS ( [ ADD | SET | DROP ] option ['valeur'] [, ... ]) ]
ALTER FOREIGN DATA WRAPPER nom OWNER TO { nouveau_proprietaire | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER FOREIGN DATA WRAPPER nom RENAME TO nouveau_nom

DESCRIPTION

ALTER FOREIGN DATA WRAPPER modifie la définition d'un wrapper de données étrangères. La première forme de la commande modifie les fonctions de support ou les options génériques du wrapper de données étrangères (au moins une clause est requise). La deuxième forme modifie le propriétaire du wrapper de données étrangères.

Seuls les superutilisateurs peuvent modifier les wrappers de données étrangères. De plus, seuls les superutilisateurs peuvent posséder des wrappers de données étrangères.

PARAMETRES

nom

Le nom d'un wrapper de données étrangères existant.

HANDLER fonction_gestionnaire

Spécifie une nouvelle fonction gestionnaire pour le wrapper de données étrangères.

NO HANDLER

Ceci est utilisé pour spécifier que le wrapper de données étrangères ne devrait plus avoir de fonction gestionnaire.

Notez que les tables étrangères utilisant un wrapper de données étrangères sans gestionnaire ne peuvent pas être accédées.

VALIDATOR fonction_validateur

Spécifie une nouvelle fonction validateur pour le wrapper de données étrangères.

Notez qu'il est possible que des options préexistantes du wrapper de données étrangères, ou des serveurs dépendants, des mappings utilisateur ou des tables étrangères soient invalides selon le nouveau validateur. PostgreSQL ne vérifie pas cela. Il appartient à l'utilisateur de s'assurer que ces options sont correctes avant d'utiliser le wrapper de données étrangères modifié. Cependant, toutes les options spécifiées dans cette commande ALTER FOREIGN DATA WRAPPER seront vérifiées à l'aide du nouveau validateur.

NO VALIDATOR

Ceci est utilisé pour spécifier que le wrapper de données étrangères ne devrait plus avoir de fonction validateur.

OPTIONS ( [ ADD | SET | DROP ] option ['valeur'] [, ... ] )

Modifie les options pour le wrapper de données étrangères. ADD, SET et DROP spécifient l'action à effectuer. ADD est supposé si aucune opération n'est explicitement spécifiée. Les noms d'options doivent être uniques ; les noms et les valeurs sont également validés à l'aide de la fonction validateur du wrapper de données étrangères, le cas échéant.

nouveau_proprietaire

Le nom d'utilisateur du nouveau propriétaire du wrapper de données étrangères.

nouveau_nom

Le nouveau nom pour le wrapper de données étrangères.

EXEMPLES

Modifier le wrapper de données étrangères dbi, ajouter l'option foo, supprimer bar :

ALTER FOREIGN DATA WRAPPER dbi OPTIONS (ADD foo '1', DROP bar);

Modifier le validateur du wrapper de données étrangères dbi en bob.myvalidator :

ALTER FOREIGN DATA WRAPPER dbi VALIDATOR bob.myvalidator;

COMPATIBILITÉ

ALTER FOREIGN DATA WRAPPER est conforme à la norme ISO/IEC 9075-9 (SQL/MED), à l'exception des clauses HANDLER, VALIDATOR, OWNER TO et RENAME qui sont des extensions.

VOIR AUSSI

CREATE FOREIGN DATA WRAPPER (CREATE_FOREIGN_DATA_WRAPPER(7)), DROP FOREIGN DATA WRAPPER (DROP_FOREIGN_DATA_WRAPPER(7))
