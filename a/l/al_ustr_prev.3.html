al_ustr_prev(3) Manuel des fonctions de bibliothèque al_ustr_prev(3)

NOM

al_ustr_prev - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
bool al_ustr_prev(const ALLEGRO_USTR *us, int *pos)

DESCRIPTION

Trouve le décalage en octets du point de code précédent dans la chaîne, avant *pos. *pos n'a pas besoin d'être au début d'un point de code. Renvoie true en cas de succès, et la valeur pointée par pos sera mise à jour vers le décalage trouvé. Sinon, renvoie false si *pos était déjà à la fin de la chaîne, et *pos reste inchangé.

Cette fonction recherche simplement un octet approprié ; elle ne vérifie pas si le décalage trouvé correspond au début d'un point de code valide. Si vous travaillez avec des chaînes UTF-8 potentiellement invalides, elle pourrait ignorer certains octets invalides.
