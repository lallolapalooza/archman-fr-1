NOM

alpm-mtree-validate - Valider un fichier MTREE

SYNTAXE

alpm-mtree validate [-s|--schema] [-h|--help] [FICHIER]

DESCRIPTION

Valider un fichier MTREE

Valide un fichier MTREE selon un schéma. Si le fichier peut être validé, le programme se termine sans sortie et avec un code de retour de 0. Si le fichier ne peut pas être validé, une erreur est émise sur stderr et le programme se termine avec un code de sortie non nul.

OPTIONS

-s, --schema <VERSION>
Fournir la version du schéma MTREE à utiliser.

Si aucune version de schéma n'est fournie, elle sera déduite du fichier lui-même.

Les valeurs valides sont ['1', '2'].

-h, --help
Afficher l'aide (voir un résumé avec '-h')
[FICHIER]
Un fichier optionnel à lire.

Si aucun fichier n'est fourni, l'entrée standard (stdin) est utilisée à la place.
