NOM

package group - regroupement de paquets pour les paquets basés sur ALPM.

DESCRIPTION

Les groupes de paquets décrivent un regroupement arbitraire de paquets basés sur ALPM. Ils sont utilisés dans les scripts de compilation ou les formats de métadonnées de paquets (par exemple, dans PKGBUILD, PKGINFO ou SRCINFO) pour décrire les groupes auxquels un paquet appartient. Les groupes de paquets peuvent être utilisés pour un certain nombre de raisons (par exemple, « un groupe de tous les fournisseurs d'une fonctionnalité », « un groupe de tous les éditeurs de texte ») et aucune directive spécifique n'existe. Les logiciels tels que les gestionnaires de paquets peuvent s'appuyer sur les groupes de paquets pour lister les paquets groupés et les installer ou les désinstaller en bloc.

La valeur est représentée par une chaîne UTF-8 (par exemple, mon-groupe ou mon-autre-groupe). Bien qu'il soit possible d'utiliser une chaîne UTF-8, il est recommandé de limiter la valeur au format nom-de-paquet-alpm. Les gestionnaires de paquets peuvent utiliser un groupe de paquets pour installer un groupe entier de paquets et les noms de groupes contenant des caractères spéciaux ou des espaces peuvent être sources de confusion pour les utilisateurs.

Visibilité des groupes

Les groupes de paquets existent uniquement en tant que métadonnées de paquet et chaque paquet peut appartenir à zéro ou plusieurs d'entre eux. Dans le contexte de la gestion des paquets, les groupes de paquets représentent des identifiants, qui sont visibles dans les dépôts de paquets disponibles, car ils sont définis par leurs membres.

Mises en garde lors de l'installation basée sur les groupes

Les groupes de paquets peuvent être utilisés par les gestionnaires de paquets pour installer en bloc tous les paquets basés sur ALPM qui sont actuellement membres d'un groupe donné. Bien qu'en pratique similaires aux méta-paquets en ce qui concerne l'installation en bloc de paquets, les groupes de paquets ne sont pas des relations de paquets et sont uniquement définis comme un mécanisme de regroupement ! Lorsque des paquets supplémentaires sont ajoutés à un groupe donné, cela n'entraîne pas leur installation automatique, car le logiciel de gestion des paquets évalue simplement les membres d'un groupe lors d'une action d'installation donnée. Outre la réinstallation de tous les membres d'un groupe, il n'existe aucun mécanisme pour rester synchronisé avec les membres actuels d'un groupe de paquets.

EXEMPLES

L'exemple de PKGBUILD suivant définit un paquet qui appartient au groupe mon-groupe. Notez que le paquet créé porte le nom du groupe dans ses métadonnées (voir PKGINFO pour plus de détails).

pkgname=group-example
pkgver=0.1.0
pkgrel=1
pkgdesc="Un exemple de paquet"
arch=(any)
url="https://archlinux.org"
license=('GPL-3.0-or-later')
groups=(my-group)
depends=(bash)
package() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  touch "$pkgdir/usr/share/doc/$pkgname/test.txt"
}
