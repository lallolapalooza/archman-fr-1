NOM

al_get_audio_stream_fragment - API Allegro 5

SYNTAXE

#include <allegro5/allegro_audio.h>
void *al_get_audio_stream_fragment(const ALLEGRO_AUDIO_STREAM *stream)

DESCRIPTION

En utilisant le streaming audio d'Allegro, vous utiliserez cette fonction pour fournir continuellement de nouvelles données d'échantillons à un flux.

Si le flux est prêt pour de nouvelles données, la fonction retournera l'adresse d'un tampon interne à remplir avec des données audio. La longueur et le format du tampon sont spécifiés avec al_create_audio_stream(3) ou peuvent être interrogés avec les différentes fonctions décrites ici. Une fois le tampon rempli, vous devez en informer Allegro en passant le tampon à al_set_audio_stream_fragment(3).

Si le flux n'est pas prêt pour de nouvelles données, la fonction retournera NULL.

Remarque : Si vous écoutez les événements du flux, un événement ALLEGRO_EVENT_AUDIO_STREAM_FRAGMENT(3) sera généré chaque fois qu'un nouveau fragment sera prêt. Cependant, recevoir un événement ne garantit pas que al_get_audio_stream_fragment(3) ne retournera pas NULL, vous devez donc toujours vérifier.
