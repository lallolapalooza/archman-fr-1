ALTER EXTENSION(7) Documentation PostgreSQL 18.1 ALTER EXTENSION(7)

NOM

ALTER_EXTENSION - modifie la définition d'une extension

SYNOPSISSE

ALTER EXTENSION name UPDATE [ TO new_version ]
ALTER EXTENSION name SET SCHEMA new_schema
ALTER EXTENSION name ADD member_object
ALTER EXTENSION name DROP member_object
où member_object est :
  ACCESS METHOD object_name |
  AGGREGATE aggregate_name ( aggregate_signature ) |
  CAST (source_type AS target_type) |
  COLLATION object_name |
  CONVERSION object_name |
  DOMAIN object_name |
  EVENT TRIGGER object_name |
  FOREIGN DATA WRAPPER object_name |
  FOREIGN TABLE object_name |
  FUNCTION function_name [ ( [ [ argmode ] [ argname ] argtype [, ...] ] ) ] |
  MATERIALIZED VIEW object_name |
  OPERATOR operator_name (left_type, right_type) |
  OPERATOR CLASS object_name USING index_method |
  OPERATOR FAMILY object_name USING index_method |
  [ PROCEDURAL ] LANGUAGE object_name |
  PROCEDURE procedure_name [ ( [ [ argmode ] [ argname ] argtype [, ...] ] ) ] |
  ROUTINE routine_name [ ( [ [ argmode ] [ argname ] argtype [, ...] ] ) ] |
  SCHEMA object_name |
  SEQUENCE object_name |
  SERVER object_name |
  TABLE object_name |
  TEXT SEARCH CONFIGURATION object_name |
  TEXT SEARCH DICTIONARY object_name |
  TEXT SEARCH PARSER object_name |
  TEXT SEARCH TEMPLATE object_name |
  TRANSFORM FOR type_name LANGUAGE lang_name |
  TYPE object_name |
  VIEW object_name
et
aggregate_signature est :
* |
[ argmode ] [ argname ] argtype [ , ... ] |
[ [ argmode ] [ argname ] argtype [ , ... ] ] ORDER BY [ argmode ] [ argname ] argtype [ , ... ] DESCRIPTION

DESCRIPTION

ALTER EXTENSION modifie la définition d'une extension installée. Il existe plusieurs sous-formes :

UPDATE

Cette forme met à jour l'extension vers une version plus récente. L'extension doit fournir un script de mise à jour approprié (ou une série de scripts) capable de transformer la version actuellement installée en la version demandée.

SET SCHEMA

Cette forme déplace les objets de l'extension vers un autre schéma. L'extension doit être déplaçable pour que cette commande fonctionne.

ADD member_object

Cette forme ajoute un objet existant à l'extension. C'est principalement utile dans les scripts de mise à jour d'extension. L'objet sera ensuite traité comme un membre de l'extension ; notamment, il ne peut être supprimé qu'en supprimant l'extension.

DROP member_object

Cette forme retire un objet membre de l'extension. C'est principalement utile dans les scripts de mise à jour d'extension. L'objet n'est pas supprimé, seulement dissocié de l'extension.
Voir la section 36.17 pour plus d'informations sur ces opérations.

Vous devez être propriétaire de l'extension pour utiliser ALTER EXTENSION. Les formes ADD/DROP nécessitent également la propriété de l'objet ajouté/supprimé.

PARAMÈTRES

name

Le nom d'une extension installée.

new_version

La nouvelle version souhaitée de l'extension. Cela peut être écrit soit comme un identifiant, soit comme une chaîne littérale. Si non spécifié, ALTER EXTENSION UPDATE tente de mettre à jour vers la version par défaut indiquée dans le fichier de contrôle de l'extension.

new_schema

Le nouveau schéma pour l'extension.

object_name
aggregate_name
function_name
operator_name
procedure_name
routine_name

Le nom d'un objet à ajouter à ou à retirer de l'extension. Les noms de tables, agrégats, domaines, tables étrangères, fonctions, opérateurs, classes d'opérateurs, familles d'opérateurs, procédures, routines, séquences, objets de recherche de texte, types et vues peuvent être qualifiés par un schéma.

source_type

Le nom du type de données source de la conversion.

target_type

Le nom du type de données cible de la conversion.

argmode

Le mode d'un argument de fonction, de procédure ou d'agrégat : IN, OUT, INOUT ou VARIADIC. Si omis, la valeur par défaut est IN. Notez que ALTER EXTENSION ne fait en fait pas attention aux arguments OUT, car seuls les arguments d'entrée sont nécessaires pour déterminer l'identité de la fonction. Il suffit donc de lister les arguments IN, INOUT et VARIADIC.

argname

Le nom d'un argument de fonction, de procédure ou d'agrégat. Notez que ALTER EXTENSION ne fait en fait pas attention aux noms d'arguments, car seuls les types de données des arguments sont nécessaires pour déterminer l'identité de la fonction.

argtype

Le type de données d'un argument de fonction, de procédure ou d'agrégat.

left_type
right_type

Le(s) type(s) de données des arguments de l'opérateur (éventuellement qualifié(s) par un schéma). Écrivez NONE pour l'argument manquant d'un opérateur préfixé.

PROCEDURAL

C'est un mot de remplissage.

type_name

Le nom du type de données de la transformation.

lang_name

Le nom du langage de la transformation.

EXEMPLES

Pour mettre à jour l'extension hstore vers la version 2.0 :

ALTER EXTENSION hstore UPDATE TO '2.0';

Pour changer le schéma de l'extension hstore en utils :

ALTER EXTENSION hstore SET SCHEMA utils;

Pour ajouter une fonction existante à l'extension hstore :

ALTER EXTENSION hstore ADD FUNCTION populate_record(anyelement, hstore);

COMPATIBILITÉ

ALTER EXTENSION est une extension PostgreSQL.

VOIR AUSSI

CREATE EXTENSION (CREATE_EXTENSION(7)), DROP EXTENSION (DROP_EXTENSION(7))
