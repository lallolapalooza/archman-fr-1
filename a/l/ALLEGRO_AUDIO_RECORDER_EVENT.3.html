ALLEGRO_AUDIO_RECORDER_EVENT(3) Manuel des fonctions de bibliothèque ALLEGRO_AUDIO_RECORDER_EVENT(3)

NOM

ALLEGRO_AUDIO_RECORDER_EVENT - API Allegro 5

SYNOPIS

#include <allegro5/allegro_audio.h>
typedef struct ALLEGRO_AUDIO_RECORDER_EVENT ALLEGRO_AUDIO_RECORDER_EVENT;

DESCRIPTION

Structure qui contient les données de l'événement de l'enregistreur audio. Chaque type d'événement contiendra :

•
.source : pointeur vers l'enregistreur audio

Les éléments suivants seront disponibles en fonction du type d'événement :

•
.buffer : pointeur vers le tampon contenant les échantillons audio
•
.samples : nombre d'échantillons (pas d'octets) disponibles

Depuis 5.1.1

VOIR AUSSI

al_get_audio_recorder_event(3)

[API instable] : L'API peut nécessiter une légère refonte.
