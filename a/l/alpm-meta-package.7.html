NOM

meta package - un paquet basé sur ALPM qui définit uniquement des relations de paquets.

DESCRIPTION

Les paquets meta font référence à des paquets basés sur ALPM qui ne fournissent pas de fichiers, mais définissent uniquement des relations de paquets. Ils sont utilisés pour définir les relations de paquets requises d'un scénario ou d'un cas d'utilisation abstrait (par exemple, « paquets pour une installation système minimale » ou « tous les paquets nécessaires pour un environnement de développement spécial »).

Les paquets meta sont gérés comme tout autre paquet basé sur ALPM par un gestionnaire de paquets et nécessitent leurs diverses relations de paquets lors de l'installation. Un suffixe -meta peut être utilisé dans le nom-de-paquet-alpm pour distinguer plus facilement les paquets meta des autres paquets.

EXEMPLES

L'exemple PKGBUILD suivant définit un paquet meta qui, lors de l'installation, installe les paquets bash et gcc-libs :

pkgname=example-meta
pkgver=0.1.0
pkgrel=1
pkgdesc="Un exemple de paquet meta"
arch=(any)
url="https://archlinux.org"
license=('GPL-3.0-or-later')
depends=(
  bash
  gcc-libs
)
