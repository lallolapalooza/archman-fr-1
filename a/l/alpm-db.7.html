NOM

alpm-db - un format de base de données pour décrire l'état des paquets sur un système basé sur le système de gestion de paquets d'Arch Linux Package Management (ALPM).

DESCRIPTION

Les bases de données sur les systèmes basés sur ALPM sont représentées par une structure de répertoire qui contient des fichiers de métadonnées. Le contenu d'une telle base de données décrit l'état de tous les paquets installés. Ici, les fichiers ALPM-MTREE, alpm-db-desc et alpm-db-files fournissent des métadonnées sur des versions spécifiques de paquets actuellement installés.

Les entrées pour les bases de données sont créées à partir de fichiers alpm-package en utilisant des logiciels de gestion de paquets tels que pacman. Les logiciels de gestion de paquets s'appuient sur les structures alpm-db pour la recherche, la résolution des dépendances et la gestion du système.

Le format alpm-db existe en plusieurs versions. Les informations contenues dans ce document concernent la version 9, qui est la version actuelle et qui a été introduite avec la sortie de pacman 4.2.0 le 2014-12-19.

Contenu

Le contenu de la base de données du système dépend du nombre de paquets uniques qu'elle décrit. Chaque paquet ne peut apparaître qu'une seule fois, dans une seule version.

Métadonnées

Les métadonnées d'un paquet sont conservées dans un répertoire de niveau supérieur, nommé d'après le paquet et sa version spécifique. Le nom suit ce schéma :

Un nom-paquet-alpm directement suivi d'un signe -, directement suivi d'une version-paquet-alpm (sous forme *complète* ou *complète avec epoch*), par exemple :

  • example-package-1.0.0-1
  • example-package-1:1.0.0-1

Dans chacun de ces répertoires, un fichier ALPM-MTREE, un fichier alpm-db-desc et un fichier alpm-db-files sont conservés pour décrire un paquet, par exemple :

.
└── example-package-1.0.0-1
    ├── desc
    ├── files
    └── mtree

Version du schéma

La version actuelle du schéma de la base de données du système est codée dans le fichier de version de niveau supérieur ALPM_DB_VERSION. Ce fichier texte ASCII contient une seule ligne avec une chaîne de version numérique, par exemple :

9

Lorsque des changements au format de la base de données du système sont nécessaires, ils sont indiqués en incrémentant la chaîne de version destinée au fichier de version.

Des outils dédiés tels que pacman-db-upgrade sont utilisés pour mettre à niveau le contenu de la base de données du système (par exemple, les fichiers de métadonnées, la structure des répertoires) et éventuellement mettre à jour la version dans ALPM_DB_VERSION.

Création

Les données dans un alpm-db sont dérivées de fichiers alpm-package et créées à l'aide de logiciels de gestion de paquets tels que pacman. Pour les entrées alpm-db-desc, les données PKGINFO du paquet, ainsi que les propriétés du fichier du paquet sont utilisées. Le fichier alpm-repo-files est directement dérivé de la liste des fichiers de données du paquet. Le fichier ALPM-MTREE est une copie du fichier ALPM-MTREE du paquet.

              alpm-db -----------.
              /  |  \             \
             /   |   \             \
alpm-db-files    |    alpm-db-desc  |
    |            |         |        |
    |         ALPM-MTREE   |        |
 Fichiers de données |         |        |
       \         |       PKGINFO   /
        \        |     /          /
         \       |    /          /
          alpm-package-----------

EXEMPLES

Installation d'un paquet sur un système

En supposant un système vide, l'installation d'un paquet example-package en version 1.0.0-1 entraîne l'ajout suivant dans le alpm-db :

.
└── example-package-1.0.0-1
    ├── desc
    ├── files
    └── mtree

Mise à jour d'un paquet existant sur un système

En complément de l'exemple précédent sur l'**installation d'un paquet sur un système**, la mise à jour d'un paquet example-package vers la version 1.1.0-1 entraîne le changement suivant dans le alpm-db :

.
└── example-package-1.1.0-1
    ├── desc
    ├── files
    └── mtree
