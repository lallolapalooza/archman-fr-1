RÉSUM

É

Créez votre plugin

: 
package Alien::Build::Plugin::Type::MyPlugin;

use Alien::Build::Plugin;
use Carp ();

has prop1 => 'default value';
has prop2 => sub { 'default value' };
has prop3 => sub { Carp::croak 'prop3 is a required property' };

sub init
{
  my($self, $meta) = @_;

  my $prop1 = $self->prop1;
  my $prop2 = $self->prop2;
  my $prop3 = $self->prop3;

  $meta->register_hook(sub {
    build => [ '%{make}', '%{make} install' ],
  });
}

Depuis votre

alienfile 
use alienfile;
plugin 'Type::MyPlugin' => (
  prop2 => 'different value',
  prop3 => 'need to provide since it is required',
)
;

N

Ce document décrit la classe de base des plugins Alien::Build. Pour les détails sur la manière d'écrire un plugin, voir Alien::Build::Manual::

PluginAuthor.

Renvoie un identifiant d'instance pour le plugin. Il est calculé à partir de la classe e

t des arguments passés au constructeur du plugin, de sorte que techniquement deux instan
ces avec exactement les mêmes arguments auront le même identifiant d'instance, mais en p
ratique vous ne devriez jamais avoir deux instances avec exactement les mêmes arguments.
