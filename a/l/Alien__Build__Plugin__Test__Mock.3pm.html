DESCRIPTIO

N

Ce plugin est utilisé pour tester les plugins Alien::Build. Habituellement, vous ne voulez tester qu'une ou deux phases dans un alienfile pour votre plugin, mais vous devez quand même avoir un alienfile entièrement formé qui contient toutes les phases requises. Ce plugin vous permet de remplir les autres phases avec les hooks appropriés. C'est généralement mieux que d'utiliser de vrais plugins qui peuvent introduire des dépendances dynamiques

supplémentaires auxquelles vous ne voulez
pas vous fier au moment du test.
