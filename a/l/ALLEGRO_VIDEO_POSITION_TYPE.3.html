ALLEGRO_VIDEO_POSITION_TYPE(3) Manuel des fonctions de bibliothèque ALLEGRO_VIDEO_POSITION_TYPE(3)

NOM

ALLEGRO_VIDEO_POSITION_TYPE - API Allegro 5

SYNTAXE

#include <allegro5/allegro_video.h>
typedef enum ALLEGRO_VIDEO_POSITION_TYPE ALLEGRO_VIDEO_POSITION_TYPE;

DESCRIPTION

Utilisé avec al_get_video_position(3) pour spécifier quelle position récupérer. Si ces valeurs se désynchronisent, l'audio et la vidéo peuvent être désynchronisés dans l'affichage de la vidéo.

•
ALLEGRO_VIDEO_POSITION_ACTUAL - La durée pendant laquelle la vidéo a été jouée. Si la vidéo a de l'audio, cette valeur peut être en avance sur ALLEGRO_VIDEO_POSITION_VIDEO_DECODE lorsque le décodage vidéo prend du retard.
•
ALLEGRO_VIDEO_POSITION_VIDEO_DECODE - La quantité de vidéo qui a été décodée. Cela peut être en retard par rapport aux positions « actuelle » et audio si le décodage est plus lent que le temps réel.
•
ALLEGRO_VIDEO_POSITION_AUDIO_DECODE - La quantité d'audio qui a été décodée. Cela peut être identique à ALLEGRO_VIDEO_POSITION_ACTUAL si le décodage audio pilote la position, ce qui est courant pour maintenir la synchronisation entre l'audio et la vidéo.
