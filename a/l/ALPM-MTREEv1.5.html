(5) Manuel des formats de fichiers (5)

NOM

ALPM-MTREE - Format de description de la hiérarchie des répertoires de paquets.

DESCRIPTION

Le format mtree est un format textuel qui décrit la hiérarchie et les métadonnées des fichiers dans un répertoire.

mtree est un format bien connu qui peut, par exemple, être utilisé pour les instructions d'installation ou pour vérifier les métadonnées des fichiers et la hiérarchie d'un répertoire.

Le format ALPM-MTREE respecte la spécification officielle mtree. Cependant, les fichiers .MTREE utilisés dans le contexte des paquets ALPM n'utilisent qu'un sous-ensemble du format officiel mtree qui a du sens dans le cadre de l'empaquetage.

Propriétés

Les fichiers .MTREE générés par makepkg ne contiennent que les propriétés suivantes :

  • type
  • uid
  • gid
  • mode
  • time
  • size
  • md5
  • sha256
  • link

Les fichiers .MTREE sont utilisés dans le cadre des paquets basés sur ALPM et concernent généralement les fichiers à l'intérieur de ces paquets respectifs. Pour cette raison, tous les chemins fournis dans un ALPM-MTREE doivent être relatifs à la racine du paquet, à l'exception des destinations de liens, qui peuvent également représenter des chemins absolus.

Propriété Type Chemin

Contrairement à tous les types disponibles dans mtree, ALPM-MTREE n'autorise que trois types de fichiers :

  • dir Un répertoire
  • file Un fichier
  • link Un lien symbolique

D'autres types de fichiers ne doivent pas être utilisés, car ils représentent des types spécifiques au matériel ou des types ad hoc qui ne devraient pas être inclus dans un paquet.

Champs Requis par Type de Fichier

ALPM-MTREE exige que des valeurs spécifiques soient définies pour certains types de fichiers, ce que mtree n'impose pas par spécification.

Le type de chemin dir nécessite que les propriétés suivantes soient définies :

  • path
  • uid
  • gid
  • mode
  • time

Le type de chemin file nécessite que les propriétés suivantes soient définies :

  • path
  • uid
  • gid
  • mode
  • size
  • md5_digest
  • sha256_digest
  • time

Le type de chemin link nécessite que les propriétés suivantes soient définies :

  • path
  • uid
  • gid
  • mode
  • link
  • time

Utilisation dans Pacman

Dans Pacman, les fichiers ALPM-MTREE sont uniquement utilisés pour vérifier que les fichiers installés sont identiques aux fichiers d'origine sans avoir à conserver le paquet d'origine. Les fichiers .MTREE sont générés implicitement et inclus lors de la création de paquets via makepkg. Le fichier .MTREE compressé par gzip se trouve à la racine des paquets basés sur ALPM.

Versionnement

Le format ALPM-MTREE existe en plusieurs versions. Les informations contenues dans ce document concernent la version 1, qui est obsolète. Le format ALPM-MTREE version 1 a été introduit avec la sortie de pacman 4.6.0 le 2012-04-30.

EXEMPLES

#mtree
/set type=file uid=0 gid=0 mode=644
./.BUILDINFO time=1696727741.0 size=5574 md5digest=04a85103d4780101c710a297aae33837 sha256digest=708be566788a6a2712bcd40425d93761569ede07371781374edb1f22e2a3eb96
./.PKGINFO time=1696727741.0 size=830 md5digest=bde30355e5b95a86c59afbd149cc28da sha256digest=3aa17bec02b34c157e7c739c62e0e37a9d19f1459d404d7c6f2c14c6008127cd
set mode=755 type=dir
./usr time=1731613789.0
./usr/bin time=1731613789.0
./usr/bin/resolvconf time=1731613789.0 mode=777 type=link link=resolvectl

Génération

Les fichiers mtree d'ALPM sont générés en appelant :

bsdtar \
  --format=mtree \
  --options='!all,use-set,type,uid,gid,mode,time,size,md5,sha256,link' \
  $folder

Utilisations

Dans le contexte d'ALPM et de pacman, le rôle principal du fichier mtree est de fournir un moyen performant d'obtenir les métadonnées des fichiers d'un paquet sans avoir à extraire et lire l'intégralité du paquet.

Ces données sont ensuite utilisées pour vérifier les fichiers installés sur le système cible par rapport aux fichiers d'origine du paquet. Regardez la fonctionnalité de vérification de requête de pacman pour plus de détails.
