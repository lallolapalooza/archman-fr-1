al_use_projection_transform(3) Manuel des fonctions de bibliothèque al_use_projection_transform(3)

NOM

al_use_projection_transform - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
void al_use_projection_transform(const ALLEGRO_TRANSFORM *trans)

DESCRIPTION

Définit la transformation de projection à utiliser pour les opérations de dessin sur le bitmap cible (chaque bitmap conserve sa propre transformation de projection). Chaque opération de dessin après cet appel sera transformée en utilisant cette transformation. Pour revenir au comportement par défaut, appelez cette fonction avec une transformation orthographique comme suit :

ALLEGRO_TRANSFORM trans;
al_identity_transform(&trans);
al_orthographic_transform(&trans, 0, 0, -1.0, al_get_bitmap_width(bitmap),
                          al_get_bitmap_height(bitmap), 1.0);
al_set_target_bitmap(bitmap);
al_use_projection_transform(&trans);

La transformation orthographique ci-dessus est la transformation de projection par défaut.

Cette fonction ne fait rien s'il n'y a pas de bitmap cible. Cette fonction ne fait rien non plus si le bitmap est un bitmap mémoire (c'est-à-dire que les bitmaps mémoire utilisent toujours une transformation orthographique comme dans l'extrait ci-dessus). Notez que la transformation de projection sera réinitialisée par défaut si un bitmap vidéo est converti en bitmap mémoire. De plus, si le bitmap en question est le backbuffer, sa transformation de projection sera réinitialisée par défaut s'il est redimensionné. Enfin, lorsque vous dessinez un bitmap mémoire sur un bitmap vidéo avec une transformation de projection personnalisée, cette transformation sera ignorée (c'est-à-dire que ce sera comme si la transformation de projection du bitmap cible était temporairement réinitialisée par défaut).

Le paramètre est passé par référence en tant qu'optimisation pour éviter les frais généraux de copie de la pile. La référence ne sera pas stockée dans la bibliothèque Allegro, il est donc sûr de passer des références à des variables locales.
