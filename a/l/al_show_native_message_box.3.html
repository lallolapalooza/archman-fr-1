al_show_native_message_box(3) Manuel des fonctions de bibliothèque al_show_native_message_box(3)

NOM

al_show_native_message_box - API Allegro 5

SYNTAXE

#include <allegro5/allegro_native_dialog.h>
int al_show_native_message_box(ALLEGRO_DISPLAY *display,
   char const *title, char const *heading, char const *text,
   char const *buttons, int flags)

DESCRIPTION

Affiche une boîte de message native de l'interface graphique. Ceci peut être utilisé par exemple pour afficher un message d'erreur si la création d'un écran initial échoue. L'écran peut être NULL, sinon l'écran donné est traité comme le parent si possible.

La boîte de message aura un seul bouton « OK » et utilisera le style des boîtes de dialogue informatives habituelles sur le système natif. Si le paramètre buttons n'est pas NULL, vous pouvez spécifier le texte du bouton dans une chaîne de caractères, avec les boutons séparés par une barre verticale (|).

Note : Le paramètre buttons n'est actuellement pas implémenté sous Windows.

Les indicateurs disponibles sont :

ALLEGRO_MESSAGEBOX_WARN
Le message est un avertissement. Cela peut entraîner une icône différente (ou d'autres effets).
ALLEGRO_MESSAGEBOX_ERROR
Le message est une erreur.
ALLEGRO_MESSAGEBOX_QUESTION
Le message est une question.
ALLEGRO_MESSAGEBOX_OK_CANCEL
Affiche un bouton Annuler à côté du bouton « OK ». Ignoré si buttons n'est pas NULL.
ALLEGRO_MESSAGEBOX_YES_NO
Affiche les boutons Oui/Non à la place du bouton « OK ». Ignoré si buttons n'est pas NULL.

al_show_native_message_box(3) peut être appelé sans qu'Allegro soit installé. Ceci est utile pour signaler une erreur lors de l'initialisation d'Allegro lui-même.

Retourne :

•
0 si la fenêtre de dialogue a été fermée sans activer de bouton.
•
1 si le bouton OK ou Oui a été pressé.
•
2 si le bouton Annuler ou Non a été pressé.

Si buttons n'est pas NULL, le numéro du bouton pressé est retourné, en commençant par 1.

Tous les autres paramètres ne doivent pas être NULL.

Si une boîte de message n'a pas pu être créée, cette fonction retourne 0, comme si la fenêtre avait été fermée sans activer de bouton.

Exemple :

int button = al_show_native_message_box(
  display,
  "Avertissement",
  "Êtes-vous sûr ?",
  "Si vous cliquez sur oui, vous confirmez que \"Oui\" "
  "est votre réponse à la question que vous avez "
  "générée par l'action que vous avez entreprise pour ouvrir cette "
  "boîte de message.",
  NULL,
  ALLEGRO_MESSAGEBOX_YES_NO
);
