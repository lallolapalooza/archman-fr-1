ALACARTE(1) Commandes utilisateur ALACARTE(1)

NOM

alacarte - Éditer les menus freedesktop.org

SYNTAXE

alacarte

DESCRIPTION

alacarte est un éditeur graphique pour les menus freedesktop.org utilisés par de nombreux environnements de bureau. Il peut également éditer et créer des fichiers de bureau d'applications.

OPTIONS

alacarte n'accepte aucune option en ligne de commande.

ENVIRONNEMENT

XDG_CONFIG_DIRS

alacarte recherche dans le sous-répertoire menus de ces répertoires les fichiers de menu. L'emplacement par défaut des fichiers de menu est /etc/xdg/menus.

XDG_DATA_DIRS

alacarte recherche dans le sous-répertoire applications de ces répertoires les fichiers de bureau. L'emplacement par défaut des fichiers de bureau est /usr/share/applications.

XDG_CONFIG_HOME

Le sous-répertoire menus de ce répertoire est où alacarte stocke les fichiers de menu modifiés. L'emplacement par défaut des fichiers de menu modifiés est $HOME/.config/menus.

XDG_DATA_HOME

Le sous-répertoire applications de ce répertoire est où alacarte stocke les fichiers de bureau modifiés et nouvellement créés. L'emplacement par défaut de ceux-ci est $HOME/.local/share/applications.

XDG_MENU_PREFIX

alacarte édite les menus définis par le fichier $XDG_MENU_PREFIXapplications.menu. GNOME utilise le fichier de menu gnome-applications.menu.
