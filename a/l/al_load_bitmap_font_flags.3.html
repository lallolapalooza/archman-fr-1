NOM

al_load_bitmap_font_flags - API Allegro 5

SYNTAXE

#include <allegro5/allegro_font.h>
ALLEGRO_FONT *al_load_bitmap_font_flags(const char *fname, int flags)

DESCRIPTION

Identique à al_load_bitmap_font(3) mais prend en plus un paramètre `flags` qui est un champ de bits contenant une combinaison des options suivantes :

ALLEGRO_NO_PREMULTIPLIED_ALPHA
Même signification que pour al_load_bitmap_flags(3).

VOIR AUSSI
