DESCRIPTIO

N

ALTER SEQUENCE modifie les paramètres d'un générateur de séquences existant. Tous les paramètres qui ne sont pas définis spécifiquement dans la commande ALTER SEQUENCE conservent leurs réglages

précédents.

Vous devez être le propriétaire de la séquence pour utiliser ALTER SEQUENCE. Pour modifier le schéma d'une séquence, vous devez également disposer du privilège CREATE sur le nouveau schéma. Pour modifier le propriétaire, vous devez pouvoir exécuter SET ROLE vers le nouveau rôle propriétaire, et ce rôle doit disposer du privilège CR

EATE sur le schéma de la séquence. (Ces restrictions garantissent que la modification du propriétaire ne permet rien que vous ne pourriez p
as faire en supprimant et recréant la séquence. Cependant, un superutilisateur peut modifier la propriété de n'importe quelle séquence.)

PARAMÈTRE

S

no

m
Le nom (éventuellement qualifié par le schéma) de la séquence à
modifier.

IF

EXISTS
Ne pas lever d'erreur si la séquence n'existe pas. Un avertissement est émis dans ce
cas.

type_donnée

s
La clause facultative AS type_données modifie le type de données de la séquence. Les types valides sont smallint, integer et bigint.

La modification du type de données modifie automatiquement les valeurs minimales et maximales de la séquence si et seulement si les valeurs minimales et maximales précédentes étaient la valeur minimale ou

maximale de l'ancien type de données (en d'autres termes, si la séquence avait été créée avec NO MINVALUE ou NO MAXVALUE, implicitement ou explicitement). Sinon, les valeurs minimales et maximales son
t conservées, sauf si de nouvelles valeurs sont fournies dans le cadre de la même commande. Si les valeurs minimale et maximale ne tiennent pas dans le nouveau type de données, une erreur sera générée.

incrémen

t
La clause INCREMENT BY incrément est facultative. Une valeur positive créera une séquence ascendante, une valeur négative une séquence descendante. Si elle n'est pas spécifiée, l'ancienne valeur d'incrément sera
conservée.

valeur_min
NO

MINVALUE
La clause facultative MINVALUE valeur_min détermine la valeur minimale qu'une séquence peut générer. Si NO MINVALUE est spécifié, les valeurs par défaut de 1 et de la valeur minimale du type de données pour les séquences ascendantes et descendantes respectivement seront utilisées. Si aucune des deux options n'est spécifiée, la valeur minimale actuelle sera
conservée.

valeur_max
NO

MAXVALUE
La clause facultative MAXVALUE valeur_max détermine la valeur maximale de la séquence. Si NO MAXVALUE est spécifié, les valeurs par défaut de la valeur maximale du type de données et de -1 pour les séquences ascendantes et descendantes respectivement seront utilisées. Si aucune des deux options n'est spécifiée, la valeur maximale actuelle sera
conservée.

CYCL

E
Le mot-clé facultatif CYCLE peut être utilisé pour permettre à la séquence de repartir du début lorsque le valeur_max ou le valeur_min a été atteint respectivement par une séquence ascendante ou descendante. Si la limite est atteinte, le prochain nombre généré sera le valeur_min ou le valeur_max respec
tivement.

NO

CYCLE
Si le mot-clé facultatif NO CYCLE est spécifié, tout appel à nextval après que la séquence a atteint sa valeur maximale renverra une erreur. Si ni CYCLE ni NO CYCLE ne sont spécifiés, l'ancien comportement de cycle sera
conservé.

dépar

t
La clause facultative START WITH départ modifie la valeur de départ enregistrée de la séquence. Cela n'a aucun effet sur la valeur actuelle de la séquence ; cela définit simplement la valeur que les futures commandes ALTER SEQUENCE RESTART
utiliseront.

redémarrag

e
La clause facultative RESTART [ WITH redémarrage ] modifie la valeur actuelle de la séquence. Cela est similaire à l'appel de la fonction setval avec is_called = false : la valeur spécifiée sera retournée par le prochain appel de nextval. Écrire RESTART sans valeur de redémarrage est équivalent à fournir la valeur de départ qui a été enregistrée par CREATE SEQUENCE ou définie pour la dernière fois par ALTER SEQUENCE START WITH.

Contrairement à un appel à setval, une opération RESTART sur une séquence est transactionnelle et bloque les transactions concurrentes d'obtenir des numéros de la même séquence. Si ce n'est pas le mode de fonctionnement souhaité, setval devrait

être u
tilisé.

cach

e
La clause CACHE cache permet de préallouer les numéros de séquence et de les stocker en mémoire pour un accès plus rapide. La valeur minimale est 1 (une seule valeur peut être générée à la fois, c'est-à-dire aucun cache). Si elle n'est pas spécifiée, l'ancienne valeur de cache sera
conservée.

SET { LOGGED | UNLOGGED

}
Cette forme change la séquence de non journalisée à journalisée ou inversement (voir CREATE SEQUENCE (CREATE_SEQUENCE(7))). Elle ne peut pas être appliquée à une séquence
temporaire.

OWNED BY nom_table.nom_colonne
OWNED BY

NONE
L'option OWNED BY associe la séquence à une colonne de table spécifique, de sorte que si cette colonne (ou sa table entière) est supprimée, la séquence sera également automatiquement supprimée. Si elle est spécifiée, cette association remplace toute association précédemment spécifiée pour la séquence. La table spécifiée doit avoir le même propriétaire et se trouver dans le même schéma que la séquence. Spécifier OWNED BY NONE supprime toute association existante, rendant la séquence « autonome »
.

séquence.

Le nouveau nom de la
séquence.

REMARQUE

S

ALTER SEQUENCE n'affectera pas immédiatement les résultats de nextval dans les backends autres que le courant qui ont préalloué des valeurs de séquence (en cache). Ils utiliseront toutes les valeurs en cache avant de remarquer les paramètres de génération de séquence modifiés. Le backend courant sera affecté

immédiatement.

ALTER SEQUENCE n'affecte pas l'état de currval pour la séquence. (Avant PostgreSQL 8.3, c'était parfois le cas.

)

ALTER SEQUENCE bloque les appels concurrents à nextval, currval, lastval et setval

.

Pour des raisons historiques, ALTER TABLE peut être utilisé avec les séquences aussi ; mais les seules variantes de ALTER TABLE autorisées avec les séquences s

ont équivalentes aux fo
rmes montrées ci-dessus.
