al_draw_filled_polygon_with_holes(3) Manuel des fonctions de bibliothèque al_draw_filled_polygon_with_holes(3)

NOM

al_draw_filled_polygon_with_holes - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_primitives.h>
void al_draw_filled_polygon_with_holes(const float *vertices,
   const int *vertex_counts, ALLEGRO_COLOR color)

DESCRIPTION

Dessine un polygone simple rempli avec zéro ou plusieurs autres polygones simples soustraits de celui-ci - les trous. Les trous ne peuvent pas toucher ou intersecter le contour du polygone rempli.

•
vertices - Tableau entrelacé de coordonnées de sommets (x, y) pour chacun des polygones, y compris les trous.
•
vertex_counts - Nombre de sommets pour chaque polygone. Le nombre de sommets du polygone rempli est donné par vertex_counts[0] et doit être d'au moins trois. Les éléments suivants indiquent le nombre de sommets dans chaque trou. Le tableau doit être terminé par un élément de valeur zéro.
•
color - Couleur du polygone rempli

Lorsque l'axe y pointe vers le bas (ce qui est habituel), les coordonnées du polygone rempli doivent être ordonnées dans le sens anti-horaire. Tous les sommets des trous doivent utiliser l'ordre opposé (horaire avec y vers le bas). Tous les sommets des trous doivent être à l'intérieur du polygone principal et aucun trou ne peut chevaucher le polygone principal.

Par exemple :

float vertices[] = {
      0,   0, // polygone rempli, coin supérieur gauche
      0, 100, // polygone rempli, coin inférieur gauche
    100, 100, // polygone rempli, coin inférieur droit
    100,   0, // polygone rempli, coin supérieur droit
     10,  10, // trou, supérieur gauche
     90,  10, // trou, supérieur droit
     90,  90  // trou, inférieur droit
};
int vertex_counts[] = {
   4, // nombre de sommets pour le polygone rempli
   3, // nombre de sommets pour le trou
   0  // terminateur
};

Il y a 7 sommets : quatre pour un carré extérieur de (0, 0) à (100, 100) dans le sens anti-horaire, et trois autres pour un triangle intérieur dans le sens horaire. Le polygone principal extérieur utilise les sommets 0 à 3 (inclus) et le trou utilise les sommets 4 à 6 (inclus).
