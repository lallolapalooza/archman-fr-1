al_popup_menu(3) Manuel des fonctions de bibliothèque al_popup_menu(3)

NOM

al_popup_menu - API Allegro 5

SYNTAXE

#include <allegro5/allegro_native_dialog.h>
bool al_popup_menu(ALLEGRO_MENU *popup, ALLEGRO_DISPLAY *display)

DESCRIPTION

Affiche un menu contextuel à côté du curseur de la souris. Le menu doit avoir été créé avec al_create_popup_menu(3). Il génère des événements tout comme un menu d'affichage normal. Il est possible que le menu soit annulé sans aucune sélection.

Le paramètre display indique à quelle fenêtre le menu est associé (lors du traitement de l'événement de clic sur le menu), mais n'affecte pas réellement l'emplacement du menu sur l'écran.

Retourne true si le menu contextuel a été affiché.

Note : sous Linux, cette fonction échouera si l'une des touches de la souris est enfoncée. C'est-à-dire qu'elle ne fonctionnera fiablement que si vous la gérez dans les événements ALLEGRO_MOUSE_BUTTON_UP et même dans ce cas, uniquement si cet événement correspond au dernier bouton de souris qui a été pressé.

DEPUIS

5.1.0
