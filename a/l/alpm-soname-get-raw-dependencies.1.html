NOM

alpm-soname-get-raw-dependencies - Obtenir les dépendances brutes sans filtrage par répertoire de recherche

SYNOPSIS

alpm-soname get-raw-dependencies [-o|--output-format] [-v|--verbose]... [-p|--pretty] [-q|--quiet]... [-h|--help] [-V|--version] <PAQUET>

DESCRIPTION

Obtenir les dépendances brutes sans filtrage par répertoire de recherche

OPTIONS

-o, --output-format <FORMAT_SORTIE> [par défaut : plain]
Le format de sortie

Valeurs possibles :

  • plain: Le format de sortie texte brut (ligne par ligne)
  • json: Le format de sortie JSON
-v, --verbose
Augmenter la verbosité de la journalisation
-p, --pretty
Afficher la sortie de manière lisible

N'a aucun effet si le format de sortie ne peut pas être affiché de manière lisible.

-q, --quiet
Diminuer la verbosité de la journalisation
-h, --help
Afficher l'aide (voir un résumé avec '-h')
-V, --version
Afficher la version
<PAQUET>
Le paquet à inspecter
