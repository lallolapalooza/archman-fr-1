al_draw_multiline_text(3) Manuel des fonctions de bibliothèque al_draw_multiline_text(3)

NOM

al_draw_multiline_text - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_font.h>
void al_draw_multiline_text(const ALLEGRO_FONT *font,
     ALLEGRO_COLOR color, float x, float y, float max_width, float line_height,
     int flags, const char *text)

DESCRIPTION

Comme al_draw_text(3), mais cette fonction permet de dessiner plusieurs lignes de texte. Elle fractionnera text en lignes en fonction de son contenu et du paramètre max_width. Les lignes seront ensuite disposées verticalement en fonction du paramètre line_height et dessinées comme si al_draw_text(3) avait été appelée sur chacune d'elles.

Un saut de ligne \n dans text provoquera un saut de ligne “dur” après son apparition dans la chaîne. Le texte après un saut dur sera placé sur une nouvelle ligne. Le retour chariot \r n'est pas pris en charge, ne provoquera pas de saut de ligne et sera probablement affiché comme un carré ou un espace, selon la police.

Le paramètre max_width contrôle la largeur maximale souhaitée des lignes. Cette fonction tentera d'introduire un saut de ligne “doux” après la plus longue série possible de mots qui tient dans max_length lorsqu'elle est dessinée avec la font donnée. Un saut de ligne “doux” peut se produire soit sur un caractère espace, soit sur un caractère tabulation (\t).

Cependant, il est possible que max_width soit trop petite, ou que les mots dans text soient trop longs pour tenir dans max_width lorsqu'ils sont dessinés avec la font. Dans ce cas, le mot trop large sera simplement dessiné entièrement sur une ligne seule. Si vous ne voulez pas que le texte qui dépasse max_width soit visible, utilisez al_set_clipping_rectangle(3) pour le découper et le masquer.

Les lignes dans lesquelles text a été divisé seront chacune dessinées en utilisant les paramètres font, x, color et flags, verticalement à partir de y et avec une distance de line_height entre elles. Si line_height est zéro (0), la valeur retournée par l'appel à al_get_font_line_height(3) sur font sera utilisée par défaut à la place.

Les flags ALLEGRO_ALIGN_LEFT, ALLEGRO_ALIGN_CENTRE, ALLEGRO_ALIGN_RIGHT et ALLEGRO_ALIGN_INTEGER seront respectés par cette fonction.

Si vous souhaitez calculer la taille de ce que cette fonction dessinera sans réellement le dessiner, ou si vous avez besoin d'une disposition complexe et/ou personnalisée, vous pouvez utiliser al_do_multiline_text(3).
