al_orthographic_transform(3) Manuel des fonctions de bibliothèque al_orthographic_transform(3)

NOM

al_orthographic_transform - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
void al_orthographic_transform(ALLEGRO_TRANSFORM *trans,
   float left, float top, float n,
   float right, float bottom, float f)

DESCRIPTION

Combine la transformation donnée avec une transformation orthographique qui mappe le rectangle de l'écran aux coordonnées gauche/haut et droite/bas spécifiées.

near/far est la plage z, les coordonnées en dehors de cette plage seront coupées. Normalement, -1/1 convient car tous les graphiques 2D auront une coordonnée z de 0. Cependant, si vous effectuez par exemple al_draw_rectangle(0, 0, 100, 100) et que vous effectuez une rotation autour de l'axe x (« vers l'écran »), assurez-vous que votre plage z autorise les valeurs de -100 à 100, sinon le rectangle tourné sera coupé.

De plus, si vous utilisez un tampon de profondeur, la plage z décide de la résolution de la profondeur. Par exemple, si vous avez un tampon de profondeur de 16 bits, il n'y a que 65536 valeurs de profondeur discrètes. Ainsi, si votre near/far est défini sur -1000000/1000000, la plupart des positions z ne résulteront pas en des valeurs de profondeur distinctes, ce qui pourrait entraîner des artefacts.

Le résultat de l'application de cette transformation aux coordonnées sera de normaliser les coordonnées visibles dans le cube de -1/-1/-1 à 1/1/1. Une telle transformation est principalement utile pour la passer à al_use_projection_transform(3) - voir cette fonction pour un exemple d'utilisation.

DEPUIS

5.1.3

VOIR AUSSI

al_use_projection_transform(3), al_perspective_transform(3)
