al_set_new_bitmap_samples(3) Manuel des fonctions de bibliothèque al_set_new_bitmap_samples(3)

NOM

al_set_new_bitmap_samples - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
void al_set_new_bitmap_samples(int samples)

DESCRIPTION

Définit les échantillons de multi-échantillonnage utilisés par les bitmap nouvellement créées (sur le thread courant) si elles sont utilisées avec al_set_target_bitmap(3). 0 signifie que le multi-échantillonnage ne sera pas utilisé lors du dessin dans la bitmap, ce qui est le comportement par défaut. 1 signifie que le multi-échantillonnage sera utilisé mais uniquement avec un seul échantillon par pixel (donc, généralement, il n'y aura aucune différence visuelle par rapport à l'absence de multi-échantillonnage).

Note : certaines plateformes ont des restrictions quant au moment où le tampon de multi-échantillonnage d'une bitmap est effectivement réalisé, c'est-à-dire redimensionné pour correspondre aux dimensions réelles de la bitmap. Cela peut ne se produire qu'après un appel à al_set_target_bitmap(3). Donc, par exemple :

al_set_target_bitmap(multisample);
al_clear_to_color(blue);
al_draw_line(0, 0, 100, 100, red, 1);
al_lock_bitmap(multisample, ...)
// ERREUR : le contenu de la bitmap sera indéfini
al_set_target_bitmap(backbuffer);
al_lock_bitmap(multisample, ...)
// CORRECT : à ce stade, le contenu de la bitmap est mis à jour et
// il y aura une ligne anti-aliased dedans.

DEPUIS

5.2.1

[API instable] : Il s'agit d'une fonctionnalité expérimentale et elle ne fonctionne actuellement que pour le backend OpenGL.
