Alien::Build::Plugin::Build::CMake(3) Documentation Perl Contribuée par l'Utilisateur Alien::Build::Plugin::Build::CMake(3)

NOM

Alien::Build::Plugin::Build::CMake - Plugin CMake pour Alien::Build

VERSION

version 2.84

SYNTAXE

use alienfile;

share {
  plugin 'Build::CMake';
  build [
    # c'est l'étape de build par défaut, si vous n'en spécifiez pas.
    [ '%{cmake}',
        @{ meta->prop->{plugin_build_cmake}->{args} },
        # ... mettre des arguments cmake supplémentaires ici ...
        '%{.install.extract}'
    ],
    '%{make}',
    '%{make} install',
  ];
};

DESCRIPTION

Ce plugin aide à construire des projets aliénés qui utilisent "cmake". L'intention est d'en faire un plugin central d'Alien::Build si/quand il deviendra suffisamment stable.

Ce plugin fournit une propriété méta "plugin_build_cmake.args" qui peut changer avec le temps mais qui inclut pour le moment :

-G %{cmake_generator}                          \
-DCMAKE_POSITION_INDEPENDENT_CODE:BOOL=true    \
-DCMAKE_INSTALL_PREFIX:PATH=%{.install.prefix} \
-DCMAKE_INSTALL_LIBDIR:PATH=lib                \
-DCMAKE_MAKE_PROGRAM:PATH=%{make}

Ce plugin supporte les builds hors source via la propriété méta "out_of_source".

MÉTHODES

cmake_generator

Retourne le générateur "cmake" selon le "make" de votre Perl.

is_dmake

Retourne vrai si le "make" de votre Perl semble être "dmake".

ASSISTANTS

cmake

Ce plugin remplace l'assistant par défaut "cmake" par celui qui provient d'Alien::cmake3.

cmake_generator

C'est le générateur "cmake" approprié à utiliser basé sur le make utilisé par votre Perl. C'est souvent "Unix Makefiles". Un endroit où il peut être différent est si votre Perl sous Windows utilise "nmake", qui vient avec Visual C++.

make

Ce plugin *peut* remplacer l'assistant par défaut "make" si le "make" par défaut n'est pas supporté par "cmake". C'est le plus souvent un problème avec les anciennes versions de Strawberry Perl qui utilisaient "dmake". Sur les Perls qui utilisent "dmake", ce plugin recherchera GNU Make dans le PATH, et s'il ne le trouve pas, il se rabattra sur l'utilisation de Alien::gmake.
