al_reconfigure_joysticks(3) Manuel des fonctions de bibliothèque al_reconfigure_joysticks(3)

NOM

al_reconfigure_joysticks - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
bool al_reconfigure_joysticks(void)

DESCRIPTION

Allegro est capable de gérer la connexion et la déconnexion de périphériques joysticks à la volée. Sur les plateformes existantes, la source d'événements joystick générera un événement de type ALLEGRO_EVENT_JOYSTICK_CONFIGURATION lorsqu'un périphérique est branché ou débranché. En réponse, vous devriez appeler al_reconfigure_joysticks(3).

Ensuite, le nombre retourné par al_get_num_joysticks(3) peut être différent, et les handles retournés par al_get_joystick(3) peuvent être différents ou ordonnés différemment.

Tous les handles ALLEGRO_JOYSTICK(3) restent valides, mais les handles des périphériques déconnectés deviennent inactifs : leur état ne sera plus mis à jour, et al_get_joystick(3) ne retournera pas le handle. Les handles des périphériques qui restent connectés continueront de représenter les mêmes périphériques. Les handles précédemment inactifs peuvent redevenir actifs, réutilisés pour représenter de nouveaux périphériques connectés.

Retourne true si la configuration des joysticks a changé, sinon retourne false.

Il est possible que sur certains systèmes, Allegro ne puisse pas générer d'événements ALLEGRO_EVENT_JOYSTICK_CONFIGURATION. Si votre jeu possède un écran de configuration d'entrée ou similaire, vous pourriez vouloir appeler al_reconfigure_joysticks(3) lors de l'entrée dans cet écran.
