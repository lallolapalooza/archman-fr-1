al_build_camera_transform(3) Manuel des fonctions de bibliothèque al_build_camera_transform(3)

NOM

al_build_camera_transform - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
void al_build_camera_transform(ALLEGRO_TRANSFORM *trans,
   float position_x, float position_y, float position_z,
   float look_x, float look_y, float look_z,
   float up_x, float up_y, float up_z)

DESCRIPTION

Construit une transformation qui peut être utilisée pour transformer des coordonnées 3D dans l'espace monde en espace caméra. Cela implique une translation et une rotation. La fonction attend trois triplets de coordonnées : la position de la caméra, la position vers laquelle la caméra regarde, et un vecteur "haut". Le vecteur haut n'a pas besoin d'être de longueur unité et n'a pas non plus besoin d'être perpendiculaire à la direction de vue - il peut généralement juste être la direction "haut" du monde (le plus souvent 0/1/0).

Par exemple :

al_build_camera_transform(&t,
    1, 1, 1,
    5, 5, 5,
    0, 1, 0);

Ceci crée une transformation pour une caméra située en 1/1/1 et regardant vers 5/5/5.

Note : Si les paramètres position et look sont identiques, ou si la direction up est parallèle à la direction de vue, une matrice identité est créée.

Un autre exemple qui recréera simplement la matrice identité :

al_build_camera_transform(&t,
    0, 0, 0,
    0, 0, -1,
    0, 1, 0);

Un exemple où le vecteur haut provoquera une inclinaison (roulement) de la caméra de 45 degrés :

al_build_camera_transform(&t,
    1, 1, 1,
    5, 5, 5,
    1, 1, 0);

Depuis 5.1.9
