al_draw_bitmap(3) Manuel des fonctions de bibliothèque al_draw_bitmap(3)

NOM

al_draw_bitmap - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
void al_draw_bitmap(ALLEGRO_BITMAP *bitmap, float dx, float dy, int flags)

DESCRIPTION

Dessine un bitmap non mis à l'échelle et non pivoté à la position donnée sur le bitmap cible actuel (voir al_set_target_bitmap(3)).

flags peut être une combinaison de :

•
ALLEGRO_FLIP_HORIZONTAL - inverse le bitmap horizontalement (par rapport à l'axe Y)
•
ALLEGRO_FLIP_VERTICAL - inverse le bitmap verticalement (par rapport à l'axe X)

Note : Le bitmap cible actuel doit être différent. Dessiner un bitmap sur lui-même (ou sur une sous-image de lui-même) ou dessiner une sous-image sur son parent (ou une autre sous-image de son parent) n'est pas pris en charge actuellement. Pour copier une partie d'un bitmap dans le même bitmap, utilisez simplement un bitmap temporaire à la place.

Note : Le backbuffer (ou une sous-image de celui-ci) ne peut pas être transformé, mélangé ou teinté. Si vous avez besoin de dessiner le backbuffer, dessinez-le d'abord sur un bitmap temporaire sans transformation active (sauf la translation). Les réglages/paramètres de mélange et de teinte seront ignorés. Cela ne s'applique pas lorsque vous dessinez dans un bitmap mémoire.
