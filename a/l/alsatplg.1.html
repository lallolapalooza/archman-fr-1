ALSATPLG(1) Manuel des commandes générales ALSATPLG(1)

NOM

alsatplg - Compilateur de topologie ALSA

SYNTAXE

alsatplg <options> [commande]

DESCRIPTION

alsatplg (Compilateur de topologie ALSA) est un programme permettant de compiler un fichier de configuration de topologie en un fichier binaire pour les pilotes du noyau.

Les pilotes audio actuels codent généralement des informations de topologie en dur dans les sources du pilote : cela couple étroitement le pilote audio à la carte de développement, rendant le temps nécessaire à la modification d'un pilote pour fonctionner sur différents appareils long. Le pilote est également étroitement couplé à la version du firmware DSP, ce qui signifie qu'il faut prendre des précautions supplémentaires pour maintenir la synchronisation entre le pilote et le firmware. Les nouvelles fonctionnalités du firmware nécessitent également des mises à jour du pilote.

Le projet de topologie ALSA supprime la nécessité de réécrire ou de porter des pilotes audio vers différents appareils ou firmwares : les pilotes ne contiennent aucune donnée de topologie codée en dur, ce qui permet d'utiliser un seul pilote sur différents appareils en mettant à jour les données de topologie à partir du système de fichiers. Les mises à jour du firmware peuvent être poussées sans avoir à mettre à jour les pilotes. Le nouveau firmware n'a qu'à inclure un fichier de topologie mis à jour décrivant la mise à jour.

OPTIONS

Options disponibles :

-h, --help
cette aide
-V, --version
affiche la version de l'utilitaire et les versions des bibliothèques utilisées
-c, --compile FICHIER
fichier de configuration source pour la compilation
-d, --decode FICHIER
fichier de topologie binaire source pour le décodage
-n, --normalize FICHIER
analyse et enregistre le fichier de configuration dans le format normalisé
-u, --dump FICHIER
analyse et enregistre le fichier de configuration dans le format spécifié
-o, --output FICHIER
fichier de sortie
-v, --verbose NIVEAU
définit le niveau de verbosité
-s, --sort
trie les identifiants de configuration (défini pour la normalisation)
-x, --nocheck
enregistre la configuration sans vérification d'intégrité supplémentaire
-z, --dapm-nosort
ne trie pas les éléments du graphe DAPM (comme dans la version 1.2.1-)

FICHIERS

Les fichiers de topologie maîtres pour chaque carte son prise en charge se trouvent dans /usr/share/alsa/topology.

Par exemple, le fichier cas d'utilisation maître pour la carte broadwell se trouve dans /usr/share/alsa/topology/broadwell/broadwell.conf, ce fichier décrit le matériel audio pour le pilote.

Pour plus de détails sur la syntaxe des fichiers UCM, consultez le code source d'alsa-lib :
http://git.alsa-project.org/?p=alsa-lib.git;a=blob;f=src/topology/parser.c
