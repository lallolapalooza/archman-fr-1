al_get_parent_bitmap(3) Manuel des fonctions de bibliothèque al_get_parent_bitmap(3)

NOM

al_get_parent_bitmap - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
ALLEGRO_BITMAP *al_get_parent_bitmap(ALLEGRO_BITMAP *bitmap)

DESCRIPTION

Retourne le bitmap dont ce bitmap est un sous-bitmap. Retourne NULL si ce bitmap n'est pas un sous-bitmap. Cette fonction retourne toujours le bitmap réel, et jamais un sous-bitmap. Cela peut NE PAS correspondre à ce qui a été passé à al_create_sub_bitmap(3). Considérez ce code, par exemple :

ALLEGRO_BITMAP* a = al_create_bitmap(512, 512);
ALLEGRO_BITMAP* b = al_create_sub_bitmap(a, 128, 128, 256, 256);
ALLEGRO_BITMAP* c = al_create_sub_bitmap(b, 64, 64, 128, 128);
ASSERT(al_get_parent_bitmap(b) == a && al_get_parent_bitmap(c) == a);

L'assertion réussira car seul a est un vrai bitmap, et b et c sont tous deux ses sous-bitmaps.

DEPUIS

5.0.6, 5.1.2

VOIR AUSSI

al_create_sub_bitmap(3), al_is_sub_bitmap(3)
