NOM

alpm-pkginfo-format - Analyse un fichier PKGINFO et l'affiche dans un format de fichier différent

SYNTAXE

alpm-pkginfo format [-s|--schema] [-o|--output-format] [-p|--pretty] [-h|--help] [FICHIER]

DESCRIPTION

Analyse un fichier PKGINFO et l'affiche dans un format de fichier différent

Si l'entrée peut être validée selon un schéma connu, le programme écrit les données PKGINFO sur la sortie standard dans un format de fichier différent (facultativement, un chemin de fichier pour écrire peut être fourni) et se termine avec un code de retour de 0. Actuellement, seul JSON est supporté comme format de sortie. Si l'entrée ne peut pas être validée selon un schéma connu, une erreur est émise sur la sortie d'erreur et le programme se termine avec un code de sortie non nul.

OPTIONS

-s, --schema <VERSION>
Fournit la version du schéma PKGINFO à utiliser.

Si aucune version de schéma n'est fournie, elle sera déduite du fichier lui-même.

-o, --output-format <FORMAT_SORTIE> [défaut: json]
Le format de sortie à utiliser

Actuellement, seul "json" (par défaut) est supporté

Valeurs possibles :

•
json : Le format de sortie JSON
-p, --pretty
Imprime la sortie de manière lisible (pretty-print)

N'a aucun effet si le format de sortie ne peut pas être imprimé de manière lisible.

-h, --help
Imprime l'aide (voir un résumé avec '-h')
[FICHIER]
Un chemin de fichier d'entrée optionnel à lire

Si aucun chemin de fichier n'est spécifié, l'entrée standard (stdin) est lue et est censée contenir les données PKGINFO à formater.
