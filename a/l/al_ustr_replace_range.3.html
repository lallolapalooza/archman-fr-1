al_ustr_replace_range(3) Manuel des fonctions de bibliothèque al_ustr_replace_range(3)

NOM

al_ustr_replace_range - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
bool al_ustr_replace_range(ALLEGRO_USTR *us1, int start_pos1, int end_pos1,
   const ALLEGRO_USTR *us2)

DESCRIPTION

Remplace la partie de us1 dans l'intervalle d'octets [start_pos1, end_pos1) par le contenu de us2. start_pos1 ne peut pas être inférieur à 0. Si start_pos1 est après la fin de us1, l'espace entre la fin de la chaîne et start_pos1 sera rempli avec des octets NUL ('\0').

Utilisez al_ustr_offset(3) pour trouver les décalages d'octets.

Retourne vrai en cas de succès, faux en cas d'erreur.
