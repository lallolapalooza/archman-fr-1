al_insert_menu_item(3) Manuel des fonctions de bibliothèque al_insert_menu_item(3)

NOM

al_insert_menu_item - API Allegro 5

SYNTAXE

#include <allegro5/allegro_native_dialog.h>
int al_insert_menu_item(ALLEGRO_MENU *parent, int pos, char const *title,
   uint16_t id, int flags, ALLEGRO_BITMAP *icon, ALLEGRO_MENU *submenu)

DESCRIPTION

Insère un élément de menu à l'endroit spécifié. Voir le texte d'introduction pour une explication détaillée de la façon dont le paramètre pos est interprété.

Le menu parent peut être un menu contextuel ou un menu ordinaire. Pour souligner un caractère dans le title, préfixez-le d'une esperluette.

Les flags peuvent être une combinaison quelconque de :

ALLEGRO_MENU_ITEM_DISABLED
L'élément est « grisé » et ne peut pas être sélectionné.
ALLEGRO_MENU_ITEM_CHECKBOX
L'élément est une case à cocher. Ce drapeau ne peut être défini qu'au moment de la création du menu. Si une case à cocher est cliquée, elle sera automatiquement basculée.
ALLEGRO_MENU_ITEM_CHECKED
L'élément est coché. S'il est défini, ALLEGRO_MENU_ITEM_CHECKBOX sera automatiquement défini aussi.

L'icon n'est pas encore pris en charge.

Le paramètre submenu indique que cet élément contient un menu enfant. Le menu enfant doit avoir été précédemment créé avec al_create_menu, et ne pas être associé à un autre menu.

Retourne l'index auquel l'élément a été inséré (qui peut être différent de ce qui est suggéré par pos), ou -1 en cas d'erreur.

5.1.0
