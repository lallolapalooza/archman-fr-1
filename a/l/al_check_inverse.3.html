al_check_inverse(3) Manuel des fonctions de bibliothèque al_check_inverse(3)

NOM

al_check_inverse - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
int al_check_inverse(const ALLEGRO_TRANSFORM *trans, float tol)

DESCRIPTION

Vérifie si la transformation a un inverse en utilisant la tolérance fournie. La tolérance doit être une petite valeur comprise entre 0 et 1, 1e-7 étant suffisant pour la plupart des applications.

Dans cette fonction, la tolérance spécifie à quel point le déterminant peut être proche de 0 (si le déterminant est 0, la transformation n'a pas d'inverse). Ainsi, plus la tolérance spécifiée est petite, plus les transformations « mauvaises » passeront ce test. L'utilisation d'une tolérance de 1e-7 détectera des erreurs supérieures à 1/1000ème de pixel, mais laissera passer des erreurs plus petites. Cela signifie que si vous transformiez un point par une transformation, puis le transformiez à nouveau par la transformation inverse qui a passé cette vérification, le point résultant devrait être à moins de 1/1000ème de pixel du point d'origine.

Notez que cette vérification est superflue la plupart du temps si vous n'avez jamais touché vous-même les valeurs de la matrice de transformation. La seule chose qui pourrait faire que la transformation n'ait pas d'inverse est si vous appliquez une échelle de 0 (ou très petite) à la transformation ou si vous avez une translation très importante. Tant que l'échelle est confortablement supérieure à 0, la transformation sera inversible.

Paramètres :

•
trans - Transformation à vérifier
•
tol - Tolérance

Retourne : 1 si la transformation est inversible, 0 sinon

Note : Les fonctions d'inversion de transformation d'Allegro fonctionnent correctement uniquement avec les transformations 2D.
