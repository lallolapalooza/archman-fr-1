NOM

alpm-db-desc-create-v1 - Créer un fichier DB desc version 1

SYNTAXE

alpm-db-desc create v1 <--name> <--version> <--base> [--description] [--url] <--arch> <--builddate> <--installdate> <--packager> <--size> [--groups] [--reason] [--license] <--validation> [--replaces] [--depends] [--optdepends] [--conflicts] [--provides] [-h|--help] [SORTIE]

DESCRIPTION

Créer un fichier DB desc version 1

OPTIONS

--name <NOM>
Le nom du paquet
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_NAME.
--version <VERSION>
La version du paquet
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_VERSION.
--base <BASE>
La base du paquet
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_BASE.
--description <DESCRIPTION>
La description du paquet.

Si non fournie, une chaîne vide est utilisée.

Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_DESC.
--url <URL>
L'URL du paquet
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_URL.
--arch <ARCH>
L'architecture du paquet
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_ARCH.
--builddate <BUILDDATE>
La date de construction du paquet
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_BUILDDATE.
--installdate <INSTALLDATE>
La date d'installation du paquet
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_INSTALLDATE.
--packager <PACKAGER>
Le créateur du paquet
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_PACKAGER.
--size <SIZE>
La taille installée
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_SIZE.
--groups <GROUPS>
Les groupes du paquet
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_GROUPS.
--reason <REASON>
La raison d'installation du paquet.

Si non définie, assume une raison d'installation de "0" (installé explicitement).

Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_REASON.
--license <LICENSE>
Les licences du paquet
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_LICENSE.
--validation <VALIDATION>
Les méthodes de validation du paquet
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_VALIDATION.
--replaces <REPLACES>
Les remplacements
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_REPLACES.
--depends <DEPENDS>
Les dépendances
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_DEPENDS.
--optdepends <OPTDEPENDS>
Les dépendances optionnelles
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_OPTDEPENDS.
--conflicts <CONFLICTS>
Les conflits
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_CONFLICTS.
--provides <PROVIDES>
Les fournitures
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_PROVIDES.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
[SORTIE]
Le fichier de sortie
Peut également être spécifié avec la variable d'environnement ALPM_DB_DESC_OUTPUT_FILE.
