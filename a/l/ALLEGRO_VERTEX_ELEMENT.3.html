ALLEGRO_VERTEX_ELEMENT(3) Manuel de fonctions de bibliothèque ALLEGRO_VERTEX_ELEMENT(3)

NOM

ALLEGRO_VERTEX_ELEMENT - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_primitives.h>
typedef struct ALLEGRO_VERTEX_ELEMENT ALLEGRO_VERTEX_ELEMENT;

DESCRIPTION

Une petite structure décrivant un élément spécifique d'un sommet. Par exemple, la position du sommet ou sa couleur. Ces structures sont utilisées par la fonction al_create_vertex_decl(3) pour créer la déclaration de sommet. Pour cela, elles apparaissent généralement dans un tableau. Le dernier élément de ce tableau doit avoir le champ attribut égal à 0, pour signaler qu'il s'agit de la fin du tableau. Voici un exemple de code qui créerait une déclaration décrivant la structure ALLEGRO_VERTEX(3) (passer ceci comme déclaration de sommet à al_draw_prim serait identique à passer NULL) :

/* Sur les compilateurs sans le mot-clé offsetof, vous devez obtenir le
 * décalage avec sizeof et vous assurer de tenir compte du padding.
 */
ALLEGRO_VERTEX_ELEMENT elems[] = {
   {ALLEGRO_PRIM_POSITION, ALLEGRO_PRIM_FLOAT_3, offsetof(ALLEGRO_VERTEX, x)},
   {ALLEGRO_PRIM_TEX_COORD_PIXEL, ALLEGRO_PRIM_FLOAT_2, offsetof(ALLEGRO_VERTEX, u)},
   {ALLEGRO_PRIM_COLOR_ATTR, 0, offsetof(ALLEGRO_VERTEX, color)},
   {0, 0, 0}
};
ALLEGRO_VERTEX_DECL* decl = al_create_vertex_decl(elems, sizeof(ALLEGRO_VERTEX));

Champs :

•
attribut - Un membre de l'énumération ALLEGRO_PRIM_ATTR(3), spécifiant ce que cet attribut signifie
•
stockage - Un membre de l'énumération ALLEGRO_PRIM_STORAGE(3), spécifiant comment cet attribut est stocké
•
decalage - Décalage en octets depuis le début de la structure de sommet personnalisée. La fonction C offsetof est très utile ici.
