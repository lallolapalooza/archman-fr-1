ALTER TEXT SEARCH DICTIONARY(7) Documentation PostgreSQL 18.1 ALTER TEXT SEARCH DICTIONARY(7)

NOM

ALTER_TEXT_SEARCH_DICTIONARY - modifier la définition d'un dictionnaire de recherche textuelle

SYNTAXE

ALTER TEXT SEARCH DICTIONARY nom (
    option [ = valeur ] [, ... ]
)
ALTER TEXT SEARCH DICTIONARY nom RENAME TO nouveau_nom
ALTER TEXT SEARCH DICTIONARY nom OWNER TO { nouveau_proprietaire | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER TEXT SEARCH DICTIONARY nom SET SCHEMA nouveau_schema

DESCRIPTION

ALTER TEXT SEARCH DICTIONARY modifie la définition d'un dictionnaire de recherche textuelle. Vous pouvez changer les options spécifiques au modèle du dictionnaire, ou changer son nom ou son propriétaire.

Vous devez être le propriétaire du dictionnaire pour utiliser ALTER TEXT SEARCH DICTIONARY.

PARAMÈTRES

nom

Le nom (éventuellement qualifié par le schéma) d'un dictionnaire de recherche textuelle existant.

option

Le nom d'une option spécifique au modèle à définir pour ce dictionnaire.

valeur

La nouvelle valeur à utiliser pour une option spécifique au modèle. Si le signe égal et la valeur sont omis, alors toute configuration précédente pour l'option est supprimée du dictionnaire, permettant l'utilisation de la valeur par défaut.

nouveau_nom

Le nouveau nom du dictionnaire de recherche textuelle.

nouveau_proprietaire

Le nouveau propriétaire du dictionnaire de recherche textuelle.

nouveau_schema

Le nouveau schéma pour le dictionnaire de recherche textuelle.

Les options spécifiques au modèle peuvent apparaître dans n'importe quel ordre.

EXEMPLES

La commande d'exemple suivante modifie la liste des mots vides pour un dictionnaire basé sur Snowball. Les autres paramètres restent inchangés.

ALTER TEXT SEARCH DICTIONARY my_dict ( StopWords = newrussian );

La commande d'exemple suivante modifie l'option de langue en dutch et supprime complètement l'option de mots vides.

ALTER TEXT SEARCH DICTIONARY my_dict ( language = dutch, StopWords );

La commande d'exemple suivante « met à jour » la définition du dictionnaire sans rien changer réellement.

ALTER TEXT SEARCH DICTIONARY my_dict ( dummy );

(La raison pour laquelle cela fonctionne est que le code de suppression d'option ne se plaint pas s'il n'y a pas une telle option.) Cette astuce est utile lors de la modification des fichiers de configuration pour le dictionnaire : l'instruction ALTER forcera les sessions de base de données existantes à relire les fichiers de configuration, ce qu'elles ne feraient jamais autrement si elles les avaient lus plus tôt.

COMPATIBILITÉ

Il n'y a pas d'instruction ALTER TEXT SEARCH DICTIONARY dans la norme SQL.

VOIR AUSSI

CREATE TEXT SEARCH DICTIONARY (CREATE_TEXT_SEARCH_DICTIONARY(7)), DROP TEXT SEARCH DICTIONARY (DROP_TEXT_SEARCH_DICTIONARY(7))
