al_join_thread(3) Manuel des fonctions de bibliothèque al_join_thread(3)

NOM

al_join_thread - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
void al_join_thread(ALLEGRO_THREAD *thread, void **ret_value)

DESCRIPTION

Attend que le thread ait terminé son exécution. Ceci appelle implicitement al_set_thread_should_stop(3) en premier.

Si ret_value n'est pas NULL, la valeur retournée par la fonction du thread sera stockée à l'emplacement pointé par ret_value.

VOIR AUSSI

al_set_thread_should_stop(3), al_get_thread_should_stop(3), al_destroy_thread(3).
