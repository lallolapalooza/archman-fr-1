ALLEGRO_VIDEO_EVENT_TYPE(3) Manuel des fonctions de bibliothèque ALLEGRO_VIDEO_EVENT_TYPE(3)

NOM

ALLEGRO_VIDEO_EVENT_TYPE - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_video.h>
enum ALLEGRO_VIDEO_EVENT_TYPE

DESCRIPTION

Événements envoyés par al_get_video_event_source(3).

ALLEGRO_EVENT_VIDEO_FRAME_SHOW

Cet événement est envoyé lorsqu'il est temps d'afficher une nouvelle image. Une fois cet événement reçu, vous pouvez dessiner l'image actuelle (telle que retournée par al_get_video_frame(3)). al_get_video_frame(3) continuera de retourner la même image jusqu'à ce que le prochain ALLEGRO_EVENT_VIDEO_FRAME_SHOW soit envoyé.

user.data1 (ALLEGRO_VIDEO *)
La vidéo qui a généré l'événement.

DEPUIS

5.1.0

ALLEGRO_EVENT_VIDEO_FINISHED

Cet événement est envoyé lorsque la vidéo est terminée. Selon le backend, il peut être possible de se déplacer vers une partie antérieure de la vidéo et de définir la vidéo pour qu'elle continue la lecture.

user.data1 (ALLEGRO_VIDEO *)
La vidéo qui a généré l'événement.

DEPUIS

5.1.0
