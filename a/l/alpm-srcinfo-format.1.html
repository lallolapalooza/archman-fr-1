NOM

alpm-srcinfo-format - Formate un fichier SRCINFO à partir d'un chemin ou de `stdin`

SYNTAXE

alpm-srcinfo format [-s|--schema] [-o|--output-format] [-p|--pretty] [-h|--help] [FICHIER]

DESCRIPTION

Formate un fichier SRCINFO à partir d'un chemin ou de `stdin`.

Si le fichier est valide, le programme affiche les données dans le format de fichier demandé sur stdout et retourne avec un statut de sortie de 0.

OPTIONS

-s, --schema <VERSION>
Fournit la version du schéma SRCINFO à utiliser.

Si aucune version de schéma n'est fournie, elle sera déduite du fichier lui-même.

-o, --output-format <FORMAT_SORTIE> [défaut: srcinfo]
Fournit le format de sortie.

Valeurs possibles :

  • json: Le format de sortie JSON
  • srcinfo: Le format de sortie SRCINFO
-p, --pretty
Affiche la sortie de manière lisible (pretty-print).

Ne s'applique qu'aux formats qui prennent en charge la sortie lisible et est sinon ignoré.

-h, --help
Affiche l'aide (voir un résumé avec '-h')
[FICHIER]
Le fichier à lire.

Si aucun fichier n'est fourni, stdin est utilisé à la place.
