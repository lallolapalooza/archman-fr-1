ALACRITTY(1) Manuel des commandes générales ALACRITTY(1)

NOM

Alacritty - Émulateur de terminal OpenGL rapide et multiplateforme.

SYNTAXE

Alacritty est un émulateur de terminal moderne qui est livré avec des paramètres par défaut raisonnables, mais permet une configuration étendue. En s'intégrant à d'autres applications plutôt qu'en réimplémentant leurs fonctionnalités, il parvient à fournir un ensemble de fonctionnalités flexibles avec de hautes performances.

OPTIONS

-h, --help

Affiche l'aide.

--hold

Reste ouvert après la sortie du processus enfant.

--daemon

Ne lance pas de fenêtre initiale.

--print-events

Affiche tous les événements sur la sortie standard.

-q

Réduit le niveau de verbosité (le niveau minimum est -qq).

--ref-test

Génère un test de référence.

-v

Augmente le niveau de verbosité (le niveau maximum est -vvv).

-V, --version

Affiche les informations sur la version.

PARAMETRES

--class <GENERAL> | <GENERAL>,<INSTANCE>

Définit l'indice de classe de fenêtre sous Linux.

Lorsque seule la classe générale est passée, l'instance sera définie sur la même valeur.

Sur Wayland, la classe générale définit le app_id, tandis que la classe d'instance est ignorée.

Par défaut : Alacritty,Alacritty

-e, --command <COMMANDE>...

Commande et arguments à exécuter (doit être le dernier argument).

--config-file <FICHIER_CONFIG>

Spécifie un fichier de configuration alternatif.

Alacritty ne crée pas le fichier de configuration pour vous, mais il en recherche un aux emplacements suivants sur les systèmes UNIX :

1.
$XDG_CONFIG_HOME/alacritty/alacritty.toml
2.
$XDG_CONFIG_HOME/alacritty.toml
3.
$HOME/.config/alacritty/alacritty.toml
4.
$HOME/.alacritty.toml
5.
/etc/alacritty/alacritty.toml

Sur Windows, le fichier de configuration sera recherché dans :

1.
%APPDATA%\alacritty\alacritty.toml

--embed <PARENT>

ID de la fenêtre X11 dans laquelle intégrer Alacritty (décimal ou hexadécimal avec préfixe 0x).

-o, --option <OPTION>...

Remplace les options du fichier de configuration.

Exemple : alacritty -o 'cursor.style="Beam"'

--socket <SOCKET>

Chemin pour la création du socket IPC.

-T, --title <TITRE>

Définit le titre de la fenêtre.

Par défaut : Alacritty

--working-directory <REPERTOIRE_TRAVAIL>

Démarre le shell dans le répertoire de travail spécifié.

SOUS-COMMANDES

msg

Envoie des messages de socket IPC (voir alacritty-msg(1)).

migrate

Migre le fichier de configuration.

-c, --config-file <FICHIER_CONFIG>

Chemin vers le fichier de configuration.

-d, --dry-run

Affiche uniquement la configuration TOML sur la sortie standard.

-i, --skip-imports

Ne pas récursivement suivre les imports.

--skip-renames

Ne pas déplacer les champs renommés vers leur nouvel emplacement.

-s, --silent

Ne pas afficher sur la sortie standard.

-h, --help

Affiche l'aide.
