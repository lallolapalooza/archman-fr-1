al_free(3) Manuel des fonctions de bibliothèque al_free(3)

NOM

al_free - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
#define al_free(p) \
   (al_free_with_context((p), __LINE__, __FILE__, __func__))

DESCRIPTION

Comme free() dans la bibliothèque C standard, mais l'implémentation peut être substituée.

De plus, sous Windows, un bloc mémoire alloué par une DLL doit être libéré depuis la même DLL. Dans les quelques endroits où une fonction Allegro renvoie un pointeur qui doit être libéré, vous devez utiliser al_free(3) pour la portabilité sous Windows.

Il s'agit d'une macro.

VOIR AUSSI

al_malloc(3), al_free_with_context(3)
