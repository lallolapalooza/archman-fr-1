ALTER MATERIALIZED VIEW(7) Documentation PostgreSQL 18.1 ALTER MATERIALIZED VIEW(7)

NOM

ALTER MATERIALIZED VIEW - modifier la définition d'une vue matérialisée

SYNTAXE

ALTER MATERIALIZED VIEW [ IF EXISTS ] nom
    action [, ... ]
ALTER MATERIALIZED VIEW nom
    [ NO ] DEPENDS ON EXTENSION nom_extension
ALTER MATERIALIZED VIEW [ IF EXISTS ] nom
    RENAME [ COLUMN ] nom_colonne TO nouveau_nom_colonne
ALTER MATERIALIZED VIEW [ IF EXISTS ] nom
    RENAME TO nouveau_nom
ALTER MATERIALIZED VIEW [ IF EXISTS ] nom
    SET SCHEMA nouveau_schema
ALTER MATERIALIZED VIEW ALL IN TABLESPACE nom [ OWNED BY nom_role [, ... ] ]
    SET TABLESPACE nouveau_tablespace [ NOWAIT ]
où action est l'un des éléments suivants :
    ALTER [ COLUMN ] nom_colonne SET STATISTICS entier
    ALTER [ COLUMN ] nom_colonne SET ( option_attribut = valeur [, ... ] )
    ALTER [ COLUMN ] nom_colonne RESET ( option_attribut [, ... ] )
    ALTER [ COLUMN ] nom_colonne SET STORAGE { PLAIN | EXTERNAL | EXTENDED | MAIN | DEFAULT }
    ALTER [ COLUMN ] nom_colonne SET COMPRESSION methode_compression
    CLUSTER ON nom_index
    SET WITHOUT CLUSTER
    SET ACCESS METHOD nouvelle_methode_acces
    SET TABLESPACE nouveau_tablespace
    SET ( parametre_stockage [= valeur] [, ... ] )
    RESET ( parametre_stockage [, ... ] )
    OWNER TO { nouvel_proprietaire | CURRENT_ROLE | CURRENT_USER | SESSION_USER }

DESCRIPTION

ALTER MATERIALIZED VIEW modifie diverses propriétés auxiliaires d'une vue matérialisée existante.

Vous devez posséder la vue matérialisée pour utiliser ALTER MATERIALIZED VIEW. Pour modifier le schéma d'une vue matérialisée, vous devez également avoir le privilège CREATE sur le nouveau schéma. Pour modifier le propriétaire, vous devez pouvoir définir le rôle sur le nouveau rôle propriétaire, et ce rôle doit avoir le privilège CREATE sur le schéma de la vue matérialisée. (Ces restrictions garantissent que la modification du propriétaire n'entraîne rien que vous ne puissiez faire en supprimant et en recréant la vue matérialisée. Cependant, un superutilisateur peut modifier la propriété de n'importe quelle vue de toute façon.)

Les sous-formes et actions disponibles pour ALTER MATERIALIZED VIEW sont un sous-ensemble de ceux disponibles pour ALTER TABLE, et ont la même signification lorsqu'ils sont utilisés pour les vues matérialisées. Voir les descriptions de ALTER TABLE pour plus de détails.

PARAMÈTRES

nom

Le nom (éventuellement qualifié par le schéma) d'une vue matérialisée existante.

nom_colonne

Nom d'une colonne existante.

nom_extension

Le nom de l'extension dont la vue matérialisée doit dépendre (ou ne plus dépendre, si NO est spécifié). Une vue matérialisée marquée comme dépendante d'une extension est automatiquement supprimée lorsque l'extension est supprimée.

nouveau_nom_colonne

Nouveau nom pour une colonne existante.

nouvel_proprietaire

Le nom d'utilisateur du nouveau propriétaire de la vue matérialisée.

nouveau_nom

Le nouveau nom de la vue matérialisée.

nouveau_schema

Le nouveau schéma pour la vue matérialisée.

EXEMPLES

Pour renommer la vue matérialisée foo en bar :

ALTER MATERIALIZED VIEW foo RENAME TO bar;

COMPATIBILITÉ

ALTER MATERIALIZED VIEW est une extension PostgreSQL.

VOIR AUSSI
