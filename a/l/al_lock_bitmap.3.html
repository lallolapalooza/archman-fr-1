al_lock_bitmap(3) Manuel des fonctions de bibliothèque al_lock_bitmap(3)

NOM

al_lock_bitmap - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
ALLEGRO_LOCKED_REGION *al_lock_bitmap(ALLEGRO_BITMAP *bitmap,
   int format, int flags)

DESCRIPTION

Verrouille une image entière pour lecture ou écriture. Si l'image est une image d'écran, elle sera mise à jour depuis la mémoire système après le déverrouillage de l'image (sauf si verrouillée en lecture seule). Retourne NULL si l'image ne peut pas être verrouillée, par exemple si l'image était précédemment verrouillée et non déverrouillée. Cette fonction retourne également NULL si le format est un format compressé.

Les drapeaux sont :

•
ALLEGRO_LOCK_READONLY - La région verrouillée ne sera pas écrite. Cela peut être plus rapide si l'image est une texture vidéo, car elle peut être supprimée après le verrouillage au lieu d'être retransmise à la carte.
•
ALLEGRO_LOCK_WRITEONLY - La région verrouillée ne sera pas lue. Cela peut être plus rapide si l'image est une texture vidéo, car aucune donnée n'a besoin d'être lue depuis la carte vidéo. Vous êtes tenu de remplir tous les pixels avant de déverrouiller à nouveau l'image, alors soyez prudent lorsque vous utilisez ce drapeau.
•
ALLEGRO_LOCK_READWRITE - La région verrouillée peut être écrite et lue. Utilisez ce drapeau si un nombre partiel de pixels doit être écrit, même si la lecture n'est pas nécessaire.

format indique le format de pixel dans lequel le tampon retourné sera. Pour verrouiller dans le même format que celui utilisé par l'image pour stocker ses données en interne, appelez avec al_get_bitmap_format(bitmap) comme format ou utilisez ALLEGRO_PIXEL_FORMAT_ANY. Le verrouillage dans le format natif sera généralement plus rapide. Si le format de l'image est compressé, l'utilisation de ALLEGRO_PIXEL_FORMAT_ANY choisira un format non compressé défini par l'implémentation.

Sur certaines plateformes, Allegro sauvegarde automatiquement le contenu des images vidéo car elles peuvent être perdues occasionnellement (voir la discussion dans la documentation de al_create_bitmap(3)). Si vous recréez complètement le contenu de l'image souvent (par exemple, à chaque image), vous obtiendrez de bien meilleures performances en créant l'image cible avec le drapeau ALLEGRO_NO_PRESERVE_TEXTURE.

Note : Tant qu'une image est verrouillée, vous ne pouvez effectuer aucune opération de dessin sur celle-ci (à l'exception de al_put_pixel(3) et al_put_blended_pixel(3)).
