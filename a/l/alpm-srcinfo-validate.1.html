NOM

alpm-srcinfo-validate - Valide un fichier SRCINFO à partir d'un chemin ou de `stdin`

SYNTAXE

alpm-srcinfo validate [-s|--schema] [-h|--help] [FICHIER]

DESCRIPTION

Valide un fichier SRCINFO à partir d'un chemin ou de `stdin`.

Si le fichier peut être validé, le programme se termine sans aucune sortie et avec un code de retour de 0. Si le fichier ne peut pas être validé, une erreur est émise sur stderr et le programme se termine avec un code de sortie non nul.

OPTIONS

-s, --schema <VERSION>
Fournit la version du schéma SRCINFO à utiliser.

Si aucune version de schéma n'est fournie, elle sera déduite du fichier lui-même.

-h, --help
Affiche l'aide (voir un résumé avec '-h')
[FICHIER]
Un chemin de fichier d'entrée optionnel à lire

Si aucun fichier n'est spécifié, stdin est lu et doit contenir des données PKGINFO à valider.
