ALLEGRO_SHADER_TYPE(3) Manuel des fonctions de bibliothèque ALLEGRO_SHADER_TYPE(3)

NOM

ALLEGRO_SHADER_TYPE - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
typedef enum ALLEGRO_SHADER_TYPE ALLEGRO_SHADER_TYPE;

DESCRIPTION

Utilisé avec al_attach_shader_source(3) et al_attach_shader_source_file(3) pour spécifier comment interpréter la source attachée.

ALLEGRO_VERTEX_SHADER
Un shader de sommets est exécuté pour chaque sommet avec lequel il est utilisé. Le programme produira exactement un sommet à la fois.

Lorsque les graphiques d'Allegro sont utilisés, en plus de tous les sommets des primitives de l'extension primitives, chaque bitmap dessiné consiste également en quatre sommets.

ALLEGRO_PIXEL_SHADER
Un shader de pixels est exécuté pour chaque pixel avec lequel il est utilisé. Le programme produira exactement un pixel à la fois - soit dans le tampon arrière, soit dans le bitmap cible actuel.

Avec les graphiques intégrés d'Allegro, cela signifie que le shader est par exemple appelé pour chaque pixel de destination de la sortie d'un appel à al_draw_bitmap(3).

Un terme plus précis pour shader de pixels serait shader de fragments, car un pixel final dans le bitmap cible n'est pas nécessairement composé d'un seul résultat, mais de plusieurs fragments (par exemple, lorsque l'échantillonnage multiple est utilisé).
