ALLEGRO_GET_EVENT_TYPE(3) Manuel des fonctions de bibliothèque ALLEGRO_GET_EVENT_TYPE(3)

NOM

ALLEGRO_GET_EVENT_TYPE - API Allegro 5

SYNOPIS

#include <allegro5/allegro.h>
#define ALLEGRO_GET_EVENT_TYPE(a, b, c, d)   AL_ID(a, b, c, d)

DESCRIPTION

Crée un identifiant de type d'événement, qui est un entier de 32 bits. Généralement, mais pas nécessairement, il sera créé à partir de quatre codes de caractères de 8 bits, par exemple :

#define MY_EVENT_TYPE   ALLEGRO_GET_EVENT_TYPE('M','I','N','E')

Les ID inférieurs à 1024 sont réservés pour Allegro ou ses modules complémentaires. N'utilisez rien de moins que ALLEGRO_GET_EVENT_TYPE(0, 0, 4, 0).

Vous devriez essayer de rendre vos ID uniques afin qu'ils n'entrent pas en conflit avec d'autres codes tiers que vous pourriez utiliser. Soyez créatif. Numéroter à partir de 1024 n'est pas créatif.

Si vous avez besoin de plusieurs identifiants, vous pouvez les définir comme suit :

#define BASE_EVENT   ALLEGRO_GET_EVENT_TYPE('M','I','N','E')
#define BARK_EVENT   (BASE_EVENT + 0)
#define MEOW_EVENT   (BASE_EVENT + 1)
#define SQUAWK_EVENT (BASE_EVENT + 2)
/* Alternativement */
enum {
   BARK_EVENT = ALLEGRO_GET_EVENT_TYPE('M','I','N','E'),
   MEOW_EVENT,
   SQUAWK_EVENT
};
