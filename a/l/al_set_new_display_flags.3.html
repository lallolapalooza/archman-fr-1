Sous Windows et X11, un affichage plein écran créé avec ce drapeau se comportera différemment d'un affichage créé avec le drapeau ALLEGRO_FULLSCREEN - même si l'affichage ALLEGRO_FULLSCREEN reçoit les dimensions du bureau. La différence exacte dépend de la plateforme, mais certaines choses qui peuvent être différentes sont la façon dont Alt-Tab fonctionne, la vitesse à laquelle vous pouvez basculer entre les modes plein écran/fenêtré ou le comportement des moniteurs supplémentaires lorsque votre affichage est en mode plein
