al_draw_prim(3) Manuel des fonctions de bibliothèque al_draw_prim(3)

NOM

al_draw_prim - API Allegro 5

SYNTAXE

#include <allegro5/allegro_primitives.h>
int al_draw_prim(const void* vtxs, const ALLEGRO_VERTEX_DECL* decl,
   ALLEGRO_BITMAP* texture, int start, int end, int type)

DESCRIPTION

Dessine un sous-ensemble du tableau de sommets passé.

Paramètres :

•
texture - Texture à utiliser, passer NULL pour n'utiliser que des primitives colorées
•
vtxs - Pointeur vers un tableau de sommets
•
decl - Pointeur vers une [déclaration de sommet]al_create_vertex_decl(3). Si défini à NULL, les sommets sont supposés être de type ALLEGRO_VERTEX(3)
•
start - Indice de début du sous-ensemble du tableau de sommets à dessiner
•
end - Indice un après le dernier indice du sous-ensemble du tableau de sommets à dessiner
•
type - Un membre de l'énumération ALLEGRO_PRIM_TYPE(3), spécifiant le type de primitive à dessiner

Retourne : Nombre de primitives dessinées

Par exemple, pour dessiner un triangle texturé, vous pourriez utiliser :

ALLEGRO_COLOR white = al_map_rgb_f(1, 1, 1);
ALLEGRO_VERTEX v[] = {
   {.x = 128, .y = 0, .z = 0, .color = white, .u = 128, .v = 0},
   {.x = 0, .y = 256, .z = 0, .color = white, .u = 0, .v = 256},
   {.x = 256, .y = 256, .z = 0, .color = white, .u = 256, .v = 256}};
al_draw_prim(v, NULL, texture, 0, 3, ALLEGRO_PRIM_TRIANGLE_LIST);

VOIR AUSSI

ALLEGRO_VERTEX(3), ALLEGRO_PRIM_TYPE(3), ALLEGRO_VERTEX_DECL(3), al_draw_indexed_prim(3)
