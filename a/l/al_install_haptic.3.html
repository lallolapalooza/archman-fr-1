al_install_haptic(3) Manuel des fonctions de bibliothèque al_install_haptic(3)

NOM

al_install_haptic - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
bool al_install_haptic(void)

DESCRIPTION

Installe le sous-système de périphériques haptiques (retour de force). Ceci doit être appelé avant d'utiliser toute autre fonction liée aux haptiques. Retourne true si le sous-système haptique a pu être initialisé correctement, false en cas d'erreur.

Pour des raisons de portabilité, vous devriez d'abord ouvrir un écran avant d'appeler al_install_haptic(3). Sur certaines plateformes, comme DirectInput sous Windows, al_install_haptic(3) ne fonctionnera que si au moins un écran actif est disponible. Cet écran doit rester disponible jusqu'à ce que al_uninstall_haptic(3) soit appelé.

Si vous devez fermer et rouvrir votre écran actif, par exemple, vous devriez alors appeler al_uninstall_haptic(3) avant de fermer l'écran, et al_install_haptic(3) après l'avoir ouvert à nouveau.

DEPUIS

5.1.8

[API instable] : Pourrait peut-être être simplifiée en raison du support limité de toutes les fonctionnalités exposées sur toutes les plateformes. Attend les retours des utilisateurs.
