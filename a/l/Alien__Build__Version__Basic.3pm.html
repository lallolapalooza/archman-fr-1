Alien::Build::Version::Basic(3) Documentation Perl fournie par l'utilisateur Alien::Build::Version::Basic(3)

NOM

Alien::Build::Version::Basic - Objet de version très basique pour Alien::Build

VERSION

version 2.84

SYNOPSIS

Interface objet :

use Alien::Build::Version::Basic;

my $version = Alien::Build::Version::Basic->new('1.2.3');
if($version > '1.2.2')  # vrai
{
  ...
}

Interface fonctionnelle :

use Alien::Build::Version::Basic qw( version );

if(version('1.2.3') > version('1.2.2')) # vrai
{
  ...
}

my @sorted = sort map { version($_) } qw( 2.1 1.2.3 1.2.2 );
# sera trié dans l'ordre 1.2.2, 1.2.3, 2.1

DESCRIPTION

Ce module fournit une classe très basique pour comparer des versions. C'est déjà un domaine encombré sur CPAN. Certaines parties d'Alien::Build utilisent déjà Sort::Versions, ce qui est bien pour trier des versions. Parfois, il faut comparer pour voir si des versions correspondent exactement à des *valeurs*, et les meilleures options (comme Sort::Versions sur CPAN) comparent 1.2.3.0 et 1.2.3 comme étant différents. Cette classe compare ces deux comme étant identiques.

Cette classe est aussi très limitée, dans le sens où elle ne fonctionne qu'avec des schémas de versions utilisant des nombres décimaux séparés par des points ou des nombres réels avec un nombre fixe de chiffres. Les versions avec : des tirets, des lettres, des chiffres hexadécimaux, ou quoi que ce soit d'autre ne sont pas supportées.

Cette classe surcharge à la fois "<=>" et "cmp" pour comparer la version de la manière attendue pour les numéros de version. Ainsi, vous pouvez comparer des versions comme des nombres, ou les trier à l'aide de `sort`.

if(version($v1) > version($v2))
{
  ...
}

my @sorted = sort map { version($_) } @unsorted;

Elle surcharge aussi "" pour renvoyer sous forme de chaîne la valeur passée au constructeur.

CONSTRUCTEUR

new

my $version = Alien::Build::Version::Basic->new($valeur);

C'est la forme longue du constructeur, si vous ne voulez rien importer dans votre espace de noms.

version

my $version = version($valeur);

C'est la forme courte du constructeur, si vous êtes sensé. Elle n'est PAS exportée par défaut, vous devrez donc l'importer explicitement.

MÉTHODES

as_string

my $string = $version->as_string;
my $string = "$version";

Retourne la représentation sous forme de chaîne de caractères de l'objet version.

cmp

my $bool = $version->cmp($autre);
my $bool = $version <=> $autre;
my $bool = $version cmp $autre;

Retourne -1, 0 ou 1 tout comme les opérateurs "<=>" et "cmp" classiques. Bien que $version doive être un objet version, $autre peut être soit un objet version, soit une chaîne qui pourrait être utilisée pour créer un objet version valide.

VOIR AUSSI

Sort::Versions
Bonne, surtout si vous devez supporter des versions style rpm (comme "1.2.3-2-b") ou si cela ne vous dérange pas que les zéros finaux (1.2.3 vs 1.2.3.0) soient traités comme des valeurs différentes.
version
Problématique pour des raisons historiques.
