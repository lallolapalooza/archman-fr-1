al_transform_coordinates_3d_projective(3) Manuel des fonctions de la bibliothèque al_transform_coordinates_3d_projective(3)

NOM

al_transform_coordinates_3d_projective - API Allegro 5

SYNOPIS

#include <allegro5/allegro.h>
void al_transform_coordinates_3d_projective(const ALLEGRO_TRANSFORM *trans,
   float *x, float *y, float *z)

DESCRIPTION

Transforme x, y, z en coordonnées homogènes. C'est la même chose que d'utiliser al_transform_coordinates_4d(3) avec la coordonnée w définie à 1, puis de diviser x, y, z par le w résultant. Cela fournira les mêmes coordonnées normalisées qu'Allegro dessinera lorsqu'une transformation projective est activée, comme défini avec al_use_projection_transform(3). Pour obtenir les coordonnées pixel réelles à partir de celles-ci, traduisez et mettez à l'échelle comme suit (w et h seraient les dimensions en pixels du bitmap cible) :

x = w / 2 + x * w / 2
y = h / 2 - y * h / 2

Paramètres :

•
trans - Transformation à utiliser
•
x, y, z - Pointeur vers les coordonnées

Exemple :

ALLEGRO_TRANSFORM t2;
al_copy_transform(&t2, al_get_current_transform());
al_compose_transform(&t2, al_get_current_projection_transform());
ALLEGRO_TRANSFORM t3;
al_identity_transform(&t3);
al_scale_transform(&t3, 0.5, -0.5);
al_translate_transform(&t3, 0.5, 0.5);
al_scale_transform(&t3, al_get_bitmap_width(al_get_target_bitmap()),
                   al_get_bitmap_height(al_get_target_bitmap()));
al_transform_coordinates_3d_projective(&t2, &x, &y, &z);
// x, y contiennent maintenant des coordonnées normalisées
al_transform_coordinates(&t3, &x, &y);
// x, y contiennent maintenant des coordonnées pixel

Depuis 5.2.4
