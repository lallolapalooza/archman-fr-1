Alien::Build::Plugin::Decode::Mojo(3) Documentation Perl fournie par la communauté Alien::Build::Plugin::Decode::Mojo(3)

NOM

Alien::Build::Plugin::Decode::Mojo - Plugin pour extraire les liens depuis le HTML en utilisant Mojo::DOM ou Mojo::DOM58

VERSION

version 2.84

SYNOPSIS

use alienfile;
plugin 'Decode::Mojo';

Forcer l'utilisation de "Decode::Mojo" via le négociateur de téléchargement :

use alienfile 1.68;

configure {
  requires 'Alien::Build::Plugin::Decode::Mojo';
};

plugin 'Download' => (
  ...
  decoder => 'Decode::Mojo',
);

DESCRIPTION

Note : dans la plupart des cas, vous voudrez plutôt utiliser Alien::Build::Plugin::Download::Negotiate. Il choisit le plugin de décodage approprié en fonction de votre plateforme et de votre environnement. Dans certains cas, vous devrez peut-être utiliser ce plugin directement à la place.

Ce plugin décode une liste de fichiers HTML en une liste de candidats pour votre plugin Prefer. Il fonctionne comme Alien::Build::Plugin::Decode::HTML, sauf qu'il utilise soit Mojo::DOM, soit Mojo::DOM58 pour effectuer son travail.

Ce plugin est beaucoup plus léger que le plugin "Decode::HTML" et ne nécessite pas de XS. C'est le plugin de décodage par défaut utilisé par Alien::Build::Plugin::Download::Negotiate s'il détecte que vous avez besoin d'analyser un index HTML.
