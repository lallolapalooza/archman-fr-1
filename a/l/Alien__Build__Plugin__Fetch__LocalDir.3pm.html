NOM

Alien::Build::Plugin::Fetch::LocalDir - Plugin pour récupérer un répertoire local

VERSION

version 2.84

SYNOPSIS

use alienfile;
share {
  start_url 'patch/libfoo-1.00/';
  plugin 'Fetch::LocalDir';
};

DESCRIPTION

Note : dans la plupart des cas, vous voudrez utiliser Alien::Build::Plugin::Download::Negotiate à la place. Il choisit le plugin de récupération approprié en fonction de votre plateforme et de votre environnement. Dans certains cas, vous pourriez avoir besoin d'utiliser ce plugin directement.

Ce plugin de récupération récupère les fichiers à partir du système de fichiers local. Il est principalement utile si vous avez l'intention d'inclure des sources dans votre Alien. Si vous incluez des archives (tarballs), consultez Alien::Build::Plugin::Fetch::Local.

PROPRIÉTÉS

root

Le répertoire à partir duquel l'URL de départ doit être relative. La valeur par défaut est généralement raisonnable.

ssl

Cette propriété est destinée à la compatibilité avec d'autres plugins de récupération, mais n'est pas utilisée.
