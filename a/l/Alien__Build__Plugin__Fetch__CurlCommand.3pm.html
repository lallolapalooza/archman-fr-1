NOM

Alien::Build::Plugin::Fetch::CurlCommand - Plugin pour récupérer des fichiers en utilisant curl

VERSION

version 2.84

SYNOPIS

use alienfile;

share {
  start_url 'https://www.openssl.org/source/';
  plugin 'Fetch::CurlCommand';
};

DESCRIPTION

Ce plugin fournit une méthode de récupération basée sur la commande "curl". Il fonctionne avec d'autres plugins de récupération (c'est-à-dire que le premier qui réussit sera utilisé). La plupart du temps, le meilleur plugin à utiliser sera Alien::Build::Plugin::Download::Negotiate, mais pour un amorçage SSL, il peut être souhaitable d'essayer d'abord "curl".

Protocoles pris en charge : "http", "https"

La prise en charge de "https" nécessite que curl ait été compilé avec le support SSL.

PROPRIÉTÉS

commande_curl

Le chemin complet de la commande "curl". La valeur par défaut est généralement correcte.

ssl

Ignoré par ce plugin. Fourni pour la compatibilité avec certains autres plugins de récupération.

MÉTHODES

protocole_ok

my $bool = $plugin->protocol_ok($protocol);
my $bool = Alien::Build::Plugin::Fetch::CurlCommand->protocol_ok($protocol);
