ALLEGRO_AUDIO_STREAM(3) Manuel des fonctions de bibliothèque ALLEGRO_AUDIO_STREAM(3)

NOM

ALLEGRO_AUDIO_STREAM - API Allegro 5

SYNTAXE

#include <allegro5/allegro_audio.h>
typedef struct ALLEGRO_AUDIO_STREAM ALLEGRO_AUDIO_STREAM;

DESCRIPTION

Un objet ALLEGRO_AUDIO_STREAM est utilisé pour diffuser de l'audio généré en temps réel vers le périphérique sonore. Ceci est réalisé en lisant à partir d'un tampon, qui est divisé en plusieurs fragments. Chaque fois qu'un fragment a fini de jouer, l'utilisateur peut le remplir avec de nouvelles données.

Comme pour les objets ALLEGRO_SAMPLE_INSTANCE(3), les flux stockent les informations nécessaires à la lecture, vous ne pouvez donc pas lire le même flux plusieurs fois simultanément. Les flux doivent également être attachés à un ALLEGRO_MIXER(3), qui, à terme, atteint un objet ALLEGRO_VOICE(3).

Pendant la lecture, vous devez périodiquement remplir les fragments avec de nouvelles données audio. Pour savoir quand un nouveau fragment est prêt à être rempli, vous pouvez soit vérifier directement avec al_get_available_audio_stream_fragments(3), soit écouter les événements du flux.

Vous pouvez enregistrer une source d'événements de flux audio dans une file d'attente d'événements ; voir al_get_audio_stream_event_source(3). Un événement ALLEGRO_EVENT_AUDIO_STREAM_FRAGMENT(3) est généré chaque fois qu'un nouveau fragment est prêt. Lorsque vous recevez un événement, utilisez al_get_audio_stream_fragment(3) pour obtenir un pointeur vers le fragment à remplir. La taille et le format sont déterminés par les paramètres passés à al_create_audio_stream(3).

Si vous tardez à fournir de nouvelles données, le flux sera silencieux jusqu'à ce que de nouvelles données soient fournies. Vous devez appeler al_drain_audio_stream(3) lorsque vous avez fini de fournir des données au flux.

Il est souvent conseillé de pré-remplir le flux audio avec des données avant que les événements ALLEGRO_EVENT_AUDIO_STREAM_FRAGMENT(3) n'arrivent. Voici un extrait qui remplira les tampons du flux avec du silence :

ALLEGRO_AUDIO_STREAM *stream = al_create_audio_stream(num_buffers,
   samples_per_buffer, freq, depth, channel_conf);
void *buf;
while ((buf = al_get_audio_stream_fragment(stream))) {
   al_fill_silence(buf, samples_per_buffer, depth, channel_conf);
   al_set_audio_stream_fragment(stream, buf);
}

Si le flux est créé par al_load_audio_stream(3) ou al_play_audio_stream(3), il générera également un événement ALLEGRO_EVENT_AUDIO_STREAM_FINISHED(3) s'il atteint la fin du fichier et n'est pas configuré pour boucler.
