al_set_shader_int_vector(3) Manuel des fonctions de bibliothèque al_set_shader_int_vector(3)

NOM

al_set_shader_int_vector - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
bool al_set_shader_int_vector(const char *name,
   int num_components, const int *i, int num_elems)

DESCRIPTION

Définit un uniforme de tableau de vecteurs entiers du shader du bitmap cible actuel. Le paramètre `num_components` peut prendre l'une des valeurs 1, 2, 3 ou 4. S'il vaut 1, un tableau de `num_elems` éléments entiers est ajouté. Sinon, chaque élément de tableau ajouté est supposé être un vecteur avec 2, 3 ou 4 composantes.

Par exemple, si vous avez un uniforme GLSL déclaré comme uniform ivec3 flowers[4] ou un uniforme HLSL déclaré comme uniform int3 flowers[4], vous utiliseriez cette fonction depuis votre code comme ceci :

int flowers[4][3] =
{
   {1, 2, 3},
   {4, 5, 6},
   {7, 8, 9},
   {2, 5, 7}
};
al_set_shader_int_vector("flowers", 3, (int*)flowers, 4);

Retourne vrai en cas de succès. Sinon, retourne faux, par exemple si l'uniforme portant ce nom n'existe pas dans le shader.

5.1.0
