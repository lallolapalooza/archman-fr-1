al_lock_sample_id(3) Manuel des fonctions de bibliothèque al_lock_sample_id(3)

NOM

al_lock_sample_id - API Allegro 5

SYNTAXE

#include <allegro5/allegro_audio.h>
ALLEGRO_SAMPLE_INSTANCE* al_lock_sample_id(ALLEGRO_SAMPLE_ID *spl_id)

DESCRIPTION

Verrouille un ALLEGRO_SAMPLE_ID(3), retournant le ALLEGRO_SAMPLE_INSTANCE(3) sous-jacent. Cela vous permet d'ajuster les différentes propriétés de l'instance (comme le volume, le panoramique, etc.) pendant que le son est en lecture.

Cette fonction retournera NULL si le son correspondant à l'identifiant n'est plus en cours de lecture.

Lorsqu'il est verrouillé, ALLEGRO_SAMPLE_ID ne sera pas disponible pour des appels supplémentaires à al_play_sample(3), même si le son s'arrête pendant qu'il est verrouillé. Pour remettre le ALLEGRO_SAMPLE_ID dans le pool pour réutilisation, assurez-vous d'appeler al_unlock_sample_id lorsque vous avez terminé avec l'instance.

VOIR AUSSI

al_play_sample(3), al_unlock_sample_id(3)
