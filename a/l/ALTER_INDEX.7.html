DESCRIPTIO

N

ALTER INDEX modifie la définition d'un index existant. Il existe plusieurs sous-formes décrites ci-dessous. Notez que le niveau de verrou requis peut différer pour chaque sous-forme. Un verrou ACCESS EXCLUSIVE est maintenu sauf mention contraire explicite. Lorsque plusieurs sous-commandes sont listées, le verrou maintenu sera le plus strict requis parmi toutes les

sous-commandes.

RENAM

E
La forme RENAME change le nom de l'index. Si l' index est associé à une contrainte de table (soit UNIQUE, PRIMARY KEY ou EXCLUDE), la contrainte est également renommée. Aucun effet sur les données stockées.

Le renommage d'un inde

x acquiert un verrou S
HARE UPDATE EXCLUSIVE.

SET

TABLESPACE
Cette forme change le tablespace de l'index vers le tablespace spécifié et déplace le ou les fichiers de données associés à l'index vers le nouveau tablespace. Pour changer le tablespace d'un index, vous devez être propriétaire de l'index et disposer du privilège CREATE sur le nouveau tablespace. Tous les index dans la base de données actuelle dans un tablespace peuvent être déplacés en utilisant la forme ALL IN TABLESPACE, qui verrouillera tous les index à déplacer puis déplacera chacun d'eux. Cette forme prend également en charge OWNED BY, qui ne déplacera que les index appartenant aux rôles spécifiés. Si l'option NOWAIT est spécifiée, la commande échouera si elle est incapable d'acquérir immédiatement tous les verrous requis. Notez que les catalogues système ne seront pas déplacés par cette commande, utilisez ALTER DATABASE ou des invocations explicites ALTER INDEX si souhaité. Voir aussi CREATE TABL
ESPACE.

ATTACH PARTITION index_nam

e
Fait que l'index nommé (éventuellement qualifié par schéma) devient attaché à l'index altéré. L'index nommé doit être sur une partition de la table contenant l'index altéré et avoir une définition équivalente. Un index attaché ne peut pas être supprimé par lui-même et sera automatiquement supprimé si son index parent est
supprimé.

DEPENDS ON EXTENSION extension_name
NO DEPENDS ON EXTENSION extension_nam

e
Cette forme marque l'index comme dépendant de l'extension, ou plus dépendant de cette extension si NO est spécifié. Un index qui est marqué comme dépendant d'une extension est automatiquement supprimé lorsque l'extension est
supprimée.

SET ( storage_parameter [= value] [, ... ]

)
Cette forme change un ou plusieurs paramètres de stockage spécifiques à la méthode d'index pour l'index. Voir CREATE INDEX pour les détails sur les paramètres disponibles. Notez que le contenu de l'index ne sera pas modifié immédiatement par cette commande ; en fonction du paramètre, vous pourriez avoir besoin de reconstruire l'index avec REINDEX pour obtenir les effets
désirés.

RESET ( storage_parameter [, ... ]

)
Cette forme réinitialise un ou plusieurs paramètres de stockage spécifiques à la méthode d'index à leurs valeurs par défaut. Comme avec SET, un REINDEX pourrait être nécessaire pour mettre à jour complètement
l'index.

ALTER [ COLUMN ] column_number SET STATISTICS intege

r
Cette forme définit la cible de collecte de statistiques par colonne pour les opérations ANALYZE ultérieures, mais ne peut être utilisée que sur les colonnes d'index définies comme une expression. Comme les expressions n'ont pas de nom unique, nous les référençons en utilisant le numéro ordinal de la colonne d'index. La cible peut être définie dans la plage de 0 à
10000 ; alternativement, définissez-la à -1 pour revenir à l'utilisation de la cible de statistiques par défaut du système (default_statis
tics_target). Pour plus d'informations sur l'utilisation des statistiques par le planificateur de requêtes PostgreSQL, voir la section 14.2.

NOTE

S

Ces opérations sont également possibles en utilisant ALTER TABLE. ALTER INDEX est en fait juste un alias pour les formes de ALTER TABLE qui s'appliquent aux

index.

Il existait autrefois une variante ALTER INDEX OWNER, mais celle-ci est maintenant ignorée (avec un avertissement). Un index ne peut pas avoir un propriétaire différent de celui de sa table. Changer le propriétaire de la table change automatiquement l'index

également.
