alarm(2) Manuel des appels système alarm(2)

NOM

alarm - programmer une alarme pour la livraison d'un signal

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
unsigned int alarm(unsigned int seconds);

DESCRIPTION

La fonction alarm() organise l'envoi d'un signal SIGALRM au processus appelant dans seconds secondes.

Si seconds est zéro, toute alarme en attente est annulée.

Dans tous les cas, toute alarme précédemment programmée est annulée.

VALEUR DE RETOUR

alarm() renvoie le nombre de secondes restantes avant qu'une alarme précédemment programmée ne doive être livrée, ou zéro s'il n'y avait pas d'alarme précédemment programmée.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001, SVr4, 4.3BSD.

NOTES

alarm() et setitimer(2) partagent le même minuteur ; les appels à l'une interféreront avec l'utilisation de l'autre.

Les alarmes créées par alarm() sont préservées lors d'un appel à execve(2) et ne sont pas héritées par les enfants créés via fork(2).

sleep(3) peut être implémenté en utilisant SIGALRM ; mélanger les appels à alarm() et sleep(3) est une mauvaise idée.

Les retards de planification peuvent, comme toujours, entraîner un retard d'une durée arbitraire dans l'exécution du processus.

VOIR AUSSI

gettimeofday(2), pause(2), select(2), setitimer(2), sigaction(2), signal(2), timer_create(2), timerfd_create(2), sleep(3), time(7)
