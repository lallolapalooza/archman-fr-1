RÉSUM

É

Dans votre Build.PL

: 
use Alien::Base::ModuleBuild;

my $builder = Alien::Base::ModuleBuild->new(
  module_name => 'Alien::MyLibrary',

  configure_requires => {
    'Alien::Base::ModuleBuild' => '0.005',
    'Module::Build' => '0.28'
  },
  requires => {
    'Alien::Base' => '0.005',
  },

  alien_name => 'mylibrary', # le nom pkg-config si vous voulez
                             # utiliser pkg-config pour découvrir
                             # la version système de mylibrary

  alien_repository => {
    protocol => 'https',
    host     => 'myhost.org',
    location => '/chemin/vers/les/tarballs',
    pattern  => qr{^mylibrary-([0-9\.]+)\.tar\.gz$},
  },

  # ceci est la valeur par défaut :
  alien_build_commands => [
    "%c --prefix=%s", # %c est une version indépendante de la plateforme de ./configure
    "make",
  ],

  # ceci est la valeur par défaut pour l'installation :
  alien_install_commands => [
    "make install",
  ],

  alien_isolate_dynamic => 1,
)
;

DESCRIPTIO

N

NOTE : Veuillez considérer pour le nouveau développement des Aliens que vous utilisiez Alien::Build et alienfile à la place. Comme ce module, ils fonctionnent avec Alien::Base. Contrairement à ce module, ils sont plus faciles à personnaliser et gèrent un certain nombre de cas particuliers de manière plus efficace. Pour un bon point de départ, veuillez voir Alien::Build::Manual::AlienAuthor. Bien que l'équipe Alien-Base / Alien-Build continuera à maintenir ce module, (nous continuerons à corriger les bogues là où c'est approprié), nous n'ajoutons aucune nouvelle fonctionnalité à ce

module.

Ceci est une sous-classe de Module::Build, qui avec Alien::Base permet la création facile de distributions Alien. Ce module est utilisé pendant l'étape de construction de votre distribution. Lorsqu'il est correctement configuré, il

va
utiliser pkg-config pour trouver et utiliser la version système de la
bibliothèque
télécharger, construire et installer la bibliothèque si le système ne la fournit

alien_check_installed_versio

n

[version 0.

001] 
my $version = $abmb->alien_check_installed_version
;

Cette fonction détermine si la bibliothèque est déjà installée en tant que partie du système d'exploitation, et retourne la version sous forme de chaîne. Si elle ne peut pas être détectée, elle doit retourner une liste

vide.

L'implémentation par défaut repose sur "pkg-config", mais vous voudrez probablement la remplacer par votre propre implémentation si le paquet que vous construisez n'utilise pas "pkg-config

"
.

alien_check_built_versio

n

[version 0.

006] 
my $version = $amb->alien_check_built_version
;

Cette fonction détermine la version de la bibliothèque après qu'elle a été construite à partir des sources. Cette fonction n'est appelée que si la version du système d'exploitation ne peut pas être trouvée et que le paquet est construit avec succès. La version est retournée en cas de succès. Si la version ne peut pas être détectée, elle doit retourner une liste vide. Notez que le fait de ne pas détecter une version est considéré comme un échec et l'action "./Build" correspondante échouera

!

Toute chaîne est valide en tant que version du point de vue d'Alien::Base. La valeur la plus utile serait un nombre ou un décimal pointé que la plupart des développeurs de logiciels reconnaissent et que les outils logiciels peuvent différencier. Dans certains cas, les paquets n'auront pas de numéro de version clair, auquel cas la chaîne "unknown" serait un choix

raisonnable.

L'implémentation par défaut repose sur "pkg-config", et d'autres heuristiques, mais vous voudrez probablement la remplacer par votre propre implémentation si le paquet que vous construisez n'utilise pas "pkg-config"

.

Lorsque cette méthode est appelée, le répertoire de travail courant sera la racine de

construction.

: 
Library looks like it installed, but no version was
determined
