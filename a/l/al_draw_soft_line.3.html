NOM

al_draw_soft_line - API Allegro 5

SYNTAXE

#include <allegro5/allegro_primitives.h>

DESCRIPTION

Dessine une ligne à l'aide du rasteriseur logiciel et de fonctions de pixel fournies par l'utilisateur. Pour comprendre ce que font ces fonctions, consultez l'implémentation des différentes routines de mise en ombrage dans addons/primitives/line_soft.c. La ligne est dessinée de haut en bas.

Paramètres :

•
v1, v2 - Les deux sommets de la ligne
•
state - Un pointeur vers une structure fournie par l'utilisateur, cette structure sera passée à toutes les fonctions de pixel
•
first - Appelée avant de dessiner le premier pixel de la ligne. Elle reçoit les coordonnées de ce pixel, ainsi que les deux sommets ci-dessus. Les sommets passés peuvent avoir été modifiés par le découpage.
•
step - Appelée une fois par pixel. Le deuxième paramètre est réglé à 1 si le pas est un pas mineur, et 0 si ce pas est un pas majeur. Les pas mineurs ne sont effectués que dans la direction x ou y. Les pas majeurs sont effectués dans les deux directions en diagonale. Dans tous les cas, la valeur absolue du changement de coordonnée est au maximum de 1 dans chaque direction.
•
draw - Appelée une fois par pixel. La fonction est censée dessiner le pixel aux coordonnées qui lui sont passées.
