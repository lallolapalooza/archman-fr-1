ALTER_CONVERSION(7)

Paquet: postgresql

Licences: PostgreSQL

ALTER CONVERSION(7) Documentation PostgreSQL 18.1 ALTER CONVERSION(7)

NOM

ALTER_CONVERSION - changer la définition d'une conversion

SYNTAXE

ALTER CONVERSION name RENAME TO new_name
ALTER CONVERSION name OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER CONVERSION name SET SCHEMA new_schema

DESCRIPTION

ALTER CONVERSION modifie la définition d'une conversion.

Vous devez posséder la conversion pour utiliser ALTER CONVERSION. Pour modifier le propriétaire, vous devez pouvoir vous attribuer le rôle du nouveau propriétaire via SET ROLE, et ce rôle doit avoir le privilège CREATE sur le schéma de la conversion. (Ces restrictions garantissent que la modification du propriétaire n'effectue rien que vous ne pourriez faire en supprimant et recréant la conversion. Cependant, un superutilisateur peut modifier la propriété de n'importe quelle conversion.)

PARAMETRES

name

Le nom (éventuellement qualifié par un schéma) d'une conversion existante.

new_name

Le nouveau nom de la conversion.

new_owner

Le nouveau propriétaire de la conversion.

new_schema

Le nouveau schéma pour la conversion.

EXEMPLES

Pour renommer la conversion iso_8859_1_to_utf8 en latin1_to_unicode:

ALTER CONVERSION iso_8859_1_to_utf8 RENAME TO latin1_to_unicode;

Pour changer le propriétaire de la conversion iso_8859_1_to_utf8 en joe:

ALTER CONVERSION iso_8859_1_to_utf8 OWNER TO joe;

COMPATIBILITE

Il n'existe pas d'instruction ALTER CONVERSION dans la norme SQL.

VOIR AUSSI

CREATE CONVERSION (CREATE_CONVERSION(7)), DROP CONVERSION (DROP_CONVERSION(7))
