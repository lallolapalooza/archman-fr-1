Alien::Build::Log(3) Documentation Perl fournie par l'utilisateur Alien::Build::Log(3)

NOM

Alien::Build::Log - Journalisation d'Alien::Build

VERSION

version 2.84

SYNOPIS

Créez votre classe de journalisation personnalisée :

package Alien::Build::Log::MyLog;

use parent qw( Alien::Build::Log );

sub log
{
  my(undef, %opt)  = @_;
  my($package, $filename, $line) = @{ $opt{caller} };
  my $message = $opt{message};

  ...;
}

Remplacez la classe de journalisation :

% env ALIEN_BUILD_LOG=Alien::Build::Log::MyLog cpanm Alien::libfoo

DESCRIPTION

CONSTRUCTEURS

new

my $log = Alien::Build::Log->new;

Crée une instance de la classe de journalisation.

default

my $log = Alien::Build::Log->default;

Retourne l'instance singleton de la classe de journalisation utilisée par Alien::Build.

METHODES

set_log_class

Alien::Build::Log->set_log_class($class);

Définit la classe de journalisation par défaut utilisée par Alien::Build. Cette méthode réinitialisera également l'instance par défaut utilisée par Alien::Build. Si non spécifié, Alien::Build::Log::Default sera utilisé.

log

$log->log(%options);

Méthode remplaçable qui effectue le travail réel de la classe de journalisation. Options :

caller
Références de tableaux contenant le paquet, le fichier et le numéro de ligne où l'appel de journalisation a été effectué.
message
Le message à enregistrer.

ENVIRONNEMENT

ALIEN_BUILD_LOG
La classe de journalisation par défaut utilisée par Alien::Build.
