Alien::Libxml2(3) Documentation Perl contribuée par l'utilisateur Alien::Libxml2(3)

NOM

Alien::Libxml2 - Installer la bibliothèque C libxml2 sur votre système

VERSION

version 0.20

SYNOPSIS

Dans votre Makefile.PL :

use ExtUtils::MakeMaker;
use Alien::Base::Wrapper ();
WriteMakefile(
  Alien::Base::Wrapper->new('Alien::Libxml2')->mm_args2(
    # Arguments MakeMaker
    NAME => 'Mon::XS',
    ...
  ),
);

Dans votre Build.PL :

use Module::Build;
use Alien::Base::Wrapper qw( Alien::Libxml2 !export );
my $builder = Module::Build->new(
  ...
  configure_requires => {
    'Alien::Libxml2' => '0',
    ...
  },
  Alien::Base::Wrapper->mb_args,
  ...
);
$build->create_build_script;

Dans votre script ou module FFI::Platypus :

use FFI::Platypus;
use Alien::Libxml2;
my $ffi = FFI::Platypus->new(
  lib => [ Alien::Libxml2->dynamic_libs ],
);

DESCRIPTION

Ce module fournit "libxml2" pour que d'autres modules l'utilisent.

CAVEATS

Il existait une ancienne version d'Alien::LibXML, mais elle utilise l'ancien Alien::Build::ModuleBuild et l'auteur préfère cette version qui est basée sur le système de fichiers alien plus robuste.

"libxml2" a certaines dépendances optionnelles, notamment "zlib" et "iconv". Pour une installation "share", vous voudrez vous assurer que celles-ci sont installées avant d'installer Alien::Libxml2 si vous souhaitez utiliser les fonctionnalités qui en dépendent.

Pour une installation système, vous devez vous assurer que les paquets de développement pour "libxml2", "zlib" et "iconv" sont installés si "libxml2" a été configuré pour les utiliser, sinon XML::LibXML ne s'installera pas comme prévu. Si les tests de ce module échouent avec un "iconv.h" ou "zlib.h" manquant, c'est probablement la raison.

VOIR AUSSI

Alien::LibXML
Ancienne Alien pour la même bibliothèque.
XML::LibXML
Interface Perl pour "libxml2", qui utilise cette Alien.
