NOM

Alien::Build::Plugin::Probe::Vcpkg - Sonde pour les bibliothèques système en utilisant Vcpkg

VERSION

version 2.84

SYNOPSIS

use alienfile;

plugin 'Probe::Vcpkg' => 'libffi';

DESCRIPTION

Ce plugin de sonde peut être utilisé pour trouver des paquets « système » en utilisant le gestionnaire de paquets "Vcpkg" de Microsoft pour les constructions Visual C++ de Perl. "Vcpkg" est un gestionnaire de paquets pour Visual C++ qui inclut un certain nombre de paquets open source. Bien que "Vcpkg" prenne également en charge Linux et macOS, ce plugin ne prend pas en charge la recherche de paquets "Vcpkg" sur ces plateformes. Pour plus de détails sur "Vcpkg", voir la page du projet github ici :

https://github.com/microsoft/vcpkg

Voici le guide de démarrage rapide pour faire fonctionner Alien::Build avec "Vpkg" :

# installer Vcpkg
C:\> git clone https://github.com/Microsoft/vcpkg.git
C:\> cd vcpkg
C:\vcpkg> .\bootstrap-vcpkg.bat
C:\vcpkg> .\vcpkg integrate install

# mettre à jour PATH pour inclure le répertoire bin
# afin que les fichiers .DLL puissent être trouvés par Perl
C:\vcpkg> path c:\vcpkg\installed\x64-windows\bin;%PATH%

# installer les paquets souhaités
C:\vcpkg> .\vcpkg install libffi

# installer l'alien qui l'utilise
C:\vcpkg> cpanm Alien::FFI

Si vous utilisez une version 32 bits de Perl, substituez "x86-windows" par "x64-windows". Si vous ne souhaitez pas ajouter le répertoire "bin" à "PATH", vous pouvez utiliser "x64-windows-static" à la place, qui fournira des bibliothèques statiques. (Au moment de la rédaction, les bibliothèques statiques pour Windows 32 bits ne sont pas disponibles). Le principal inconvénient de l'utilisation de "x64-windows-static" est que les Aliens nécessitant des bibliothèques dynamiques pour FFI ne pourront pas être installés.

Si vous ne souhaitez pas installer "Vcpkg" pour tout le système (la commande "integrate install" ci-dessus), vous pouvez utiliser la variable d'environnement "PERL_WIN32_VCPKG_ROOT" à la place :

# installer Vcpkg
C:\> git clone https://github.com/Microsoft/vcpkg.git
C:\> cd vcpkg
C:\vcpkg> .\bootstrap-vcpkg.bat
C:\vcpkg> set PERL_WIN32_VCPKG_ROOT=c:\vcpkg

PROPRIÉTÉS

nom

Spécifie le nom du Vcpkg. Cela ne doit pas être utilisé avec la propriété "lib" ci-dessous, choisissez-en une seule. C'est la propriété par défaut, donc ces deux-ci sont équivalents :

plugin 'Probe::Vcpkg' => (name => 'foo');

et

plugin 'Probe::Vcpkg' => 'foo';

lib

Spécifie la liste des bibliothèques qui composent le Vcpkg. Cela ne doit pas être utilisé avec la propriété "name" ci-dessus, choisissez-en une seule. Notez qu'en utilisant cette méthode de détection, le numéro de version du paquet ne sera pas déterminé automatiquement (puisque plusieurs paquets pourraient potentiellement composer la liste des bibliothèques), vous devez donc déterminer le numéro de version par un autre moyen si vous en avez besoin.

Cela doit être une référence de tableau. N'incluez pas l'extension ".lib".

plugin 'Probe::Vcpkg' => (lib => ['foo','bar']);

ffi_name

Spécifie un nom ffi_name alternatif pour trouver les bibliothèques dynamiques.
