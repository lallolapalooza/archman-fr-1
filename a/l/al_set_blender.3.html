al_set_blender(3)

Paquet: allegro

Licences: Zlib, BSD-3-Clause, OFL-1.1, LicenseRef-Custom

al_set_blender(3) Manuel des fonctions de bibliothèque al_set_blender(3)

NOM

al_set_blender - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
void al_set_blender(int op, int src, int dst)

DESCRIPTION

Définit la fonction à utiliser pour le mélange pour le thread courant.

Le mélange signifie que les couleurs source et destination sont combinées lors des opérations de dessin.

Supposons que la couleur source (par exemple, la couleur d'un rectangle à dessiner, ou le pixel d'un bitmap à dessiner) est donnée par ses composantes rouge/vert/bleu/alpha (si le bitmap n'a pas d'alpha, il est toujours supposé être entièrement opaque, donc 255 pour 8 bits ou 1.0 pour un nombre à virgule flottante) : s = s.r, s.g, s.b, s.a. Et cette couleur est dessinée sur une destination, qui a déjà une couleur : d = d.r, d.g, d.b, d.a.

La formule conceptuelle utilisée par Allegro pour dessiner chaque pixel dépend ensuite du paramètre op :

•
ALLEGRO_ADD
   r = d.r * df.r + s.r * sf.r
   g = d.g * df.g + s.g * sf.g
   b = d.b * df.b + s.b * sf.b
   a = d.a * df.a + s.a * sf.a
•
ALLEGRO_DEST_MINUS_SRC
   r = d.r * df.r - s.r * sf.r
   g = d.g * df.g - s.g * sf.g
   b = d.b * df.b - s.b * sf.b
   a = d.a * df.a - s.a * sf.a
•
ALLEGRO_SRC_MINUS_DEST
   r = s.r * sf.r - d.r * df.r
   g = s.g * sf.g - d.g * df.g
   b = s.b * sf.b - d.b * df.b
   a = s.a * sf.a - d.a * df.a

Les valeurs valides pour les facteurs sf et df passés à cette fonction sont les suivantes, où s est la couleur source, d la couleur destination et cc la couleur définie avec al_set_blend_color(3) (blanc par défaut)

•
ALLEGRO_ZERO
   f = 0, 0, 0, 0
•
ALLEGRO_ONE
   f = 1, 1, 1, 1
•
ALLEGRO_ALPHA
   f = s.a, s.a, s.a, s.a
•
ALLEGRO_INVERSE_ALPHA
   f = 1 - s.a, 1 - s.a, 1 - s.a, 1 - s.a
•
ALLEGRO_SRC_COLOR (depuis : 5.0.10, 5.1.0)
   f = s.r, s.g, s.b, s.a
•
ALLEGRO_DEST_COLOR (depuis : 5.0.10, 5.1.8)
   f = d.r, d.g, d.b, d.a
•
ALLEGRO_INVERSE_SRC_COLOR (depuis : 5.0.10, 5.1.0)
   f = 1 - s.r, 1 - s.g, 1 - s.b, 1 - s.a
•
ALLEGRO_INVERSE_DEST_COLOR (depuis : 5.0.10, 5.1.8)
   f = 1 - d.r, 1 - d.g, 1 - d.b, 1 - d.a
•
ALLEGRO_CONST_COLOR (depuis : 5.1.12, non supporté sur OpenGLES 1.0)
   f = cc.r, cc.g, cc.b, cc.a
•
ALLEGRO_INVERSE_CONST_COLOR (depuis : 5.1.12, non supporté sur OpenGLES 1.0)
   f = 1 - cc.r, 1 - cc.g, 1 - cc.b, 1 - cc.a

Exemples de mélange :

Donc, par exemple, pour restaurer le défaut d'utilisation du mélange alpha prémultiplié, vous utiliseriez :

al_set_blender(ALLEGRO_ADD, ALLEGRO_ONE, ALLEGRO_INVERSE_ALPHA);

Comme formule :

r = d.r * (1 - s.a) + s.r * 1
g = d.g * (1 - s.a) + s.g * 1
b = d.b * (1 - s.a) + s.b * 1
a = d.a * (1 - s.a) + s.a * 1

Si vous utilisez l'alpha non prémultiplié, vous pouvez utiliser

al_set_blender(ALLEGRO_ADD, ALLEGRO_ALPHA, ALLEGRO_INVERSE_ALPHA);

Le mélange additif serait obtenu avec

al_set_blender(ALLEGRO_ADD, ALLEGRO_ONE, ALLEGRO_ONE);

Copie de la source vers la destination (y compris l'alpha) sans modification

al_set_blender(ALLEGRO_ADD, ALLEGRO_ONE, ALLEGRO_ZERO);

Multiplication des composantes source et destination

al_set_blender(ALLEGRO_ADD, ALLEGRO_DEST_COLOR, ALLEGRO_ZERO)

Teinte de la source (comme al_draw_tinted_bitmap(3))

al_set_blender(ALLEGRO_ADD, ALLEGRO_CONST_COLOR, ALLEGRO_ONE);
al_set_blend_color(al_map_rgb(0, 96, 255)); /* beau bleu Chrysler */

Moyennage des pixels source et destination

al_set_blender(ALLEGRO_ADD, ALLEGRO_CONST_COLOR, ALLEGRO_CONST_COLOR);
al_set_blend_color(al_map_rgba_f(0.5, 0.5, 0.5, 0.5));

Comme formule :

r = d.r * 0 + s.r * d.r
g = d.g * 0 + s.g * d.g
b = d.b * 0 + s.b * d.b
a = d.a * 0 + s.a * d.a
