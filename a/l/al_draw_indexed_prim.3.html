NOM

al_draw_indexed_prim - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_primitives.h>
int al_draw_indexed_prim(const void* vtxs, const ALLEGRO_VERTEX_DECL* decl,
   ALLEGRO_BITMAP* texture, const int* indices, int num_vtx, int type)

DESCRIPTION

Dessine un sous-ensemble du tableau de sommets passé. Cette fonction utilise un tableau d'indices pour spécifier quels sommets utiliser.

Paramètres :

•
texture - Texture à utiliser, passer NULL pour utiliser uniquement des primitives ombrées par couleur
•
vtxs - Pointeur vers un tableau de sommets
•
decl - Pointeur vers une déclaration de sommet. Si défini sur NULL, les sommets sont supposés être du type ALLEGRO_VERTEX
•
indices - Un tableau d'indices dans le tableau de sommets
•
num_vtx - Nombre d'indices du tableau d'indices que vous souhaitez dessiner
•
type - Un membre de l'énumération ALLEGRO_PRIM_TYPE(3), spécifiant le type de primitive à dessiner

Retourne : Nombre de primitives dessinées

VOIR AUSSI

ALLEGRO_VERTEX(3), ALLEGRO_PRIM_TYPE(3), ALLEGRO_VERTEX_DECL(3), al_draw_prim(3)
