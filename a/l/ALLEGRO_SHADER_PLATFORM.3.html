ALLEGRO_SHADER_PLATFORM(3) Manuel des fonctions de bibliothèque ALLEGRO_SHADER_PLATFORM(3)

NOM

ALLEGRO_SHADER_PLATFORM - API Allegro 5

SYNOPIS

#include <allegro5/allegro.h>
typedef enum ALLEGRO_SHADER_PLATFORM ALLEGRO_SHADER_PLATFORM;

DESCRIPTION

La plateforme sous-jacente sur laquelle est construit ALLEGRO_SHADER(3), qui dicte le langage utilisé pour programmer le shader.

•
ALLEGRO_SHADER_AUTO - Choisir automatiquement une plateforme en fonction des indicateurs d'affichage actuels.
•
ALLEGRO_SHADER_GLSL - OpenGL Shading Language
•
ALLEGRO_SHADER_HLSL - High Level Shader Language (pour Direct3D)
•
ALLEGRO_SHADER_AUTO_MINIMAL - Comme ALLEGRO_SHADER_AUTO, mais choisir une implémentation plus minimale qui peut ne pas supporter le test alpha.
•
ALLEGRO_SHADER_GLSL_MINIMAL - Shader GLSL minimal.
•
ALLEGRO_SHADER_HLSL_MINIMAL - Shader HLSL minimal.
•
ALLEGRO_SHADER_HLSL_SM_3_0 - Shader HLSL utilisant le modèle de shader 3_0.
