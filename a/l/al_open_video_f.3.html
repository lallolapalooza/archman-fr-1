al_open_video_f(3) Manuel des fonctions de bibliothèque al_open_video_f(3)

NOM

al_open_video_f - API Allegro 5

SYNTAXE

#include <allegro5/allegro_video.h>
ALLEGRO_VIDEO* al_open_video_f(ALLEGRO_FILE *fp, const char *ident)

DESCRIPTION

Ouvre un fichier vidéo à partir d'un objet ALLEGRO_FILE* existant en utilisant le système d'interface de fichiers d'Allegro. Cela permet de charger des vidéos à partir de sources personnalisées telles que des flux en mémoire, des systèmes de fichiers virtuels, des archives, ou toute autre source prise en charge par une ALLEGRO_FILE_INTERFACE personnalisée.

Paramètres :

•
file : Un pointeur vers un objet ALLEGRO_FILE. La propriété de ce fichier est transférée à l'objet vidéo ; le fichier sera fermé automatiquement lorsque al_close_video sera appelé.

Retourne : Un pointeur vers un nouvel objet ALLEGRO_VIDEO en cas de succès, ou NULL en cas d'échec.

Remarques :

•
La fonction n'exige **pas** que le fichier soit cherchable ou rembobiné ; elle lit à partir de la position actuelle.
•
Après avoir appelé al_open_video_f, vous ne devez **pas** fermer manuellement le ALLEGRO_FILE ; appelez al_close_video pour libérer toutes les ressources associées.
•
Cette fonction reflète le comportement d'autres variantes _f de l'API Allegro, permettant le streaming vidéo à partir de systèmes de fichiers personnalisés.

Exemple :

ALLEGRO_FILE *f = al_fopen("video.ogv", "rb");
if (f) {
    ALLEGRO_VIDEO *vid = al_open_video_f(f);
    if (vid) {
        float fps = al_get_video_fps(vid);
        // ... utiliser la vidéo ...
        al_close_video(vid); // ferme aussi f
    }
}
