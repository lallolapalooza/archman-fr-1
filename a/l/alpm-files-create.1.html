NOM

alpm-files-create - Crée des données alpm-files à partir d'un répertoire.

SYNTAXE

alpm-files create [-o|--output] [-s|--style] [-h|--help] <RÉPERTOIRE_ENTRÉE>

DESCRIPTION

Crée des données alpm-files à partir d'un répertoire.

Sortie sur stdout par défaut.

OPTIONS

-o, --output <SORTIE>
Un chemin de fichier vers lequel écrire.
Peut également être spécifié avec la variable d'environnement ALPM_FILES_CREATE_OUTPUT.
-s, --style <STYLE> [défaut : db]
Quel style du format alpm-files utiliser.

Valeurs possibles :

  • db : Le style alpm-db-files.
  • repo : Le style alpm-repo-files.
Peut également être spécifié avec la variable d'environnement ALPM_FILES_CREATE_STYLE.
-h, --help
Imprimer l'aide (voir un résumé avec '-h')
<RÉPERTOIRE_ENTRÉE>
Le répertoire à lire.
Peut également être spécifié avec la variable d'environnement ALPM_FILES_CREATE_INPUT_DIR.
