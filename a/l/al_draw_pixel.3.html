al_draw_pixel(3) Manuel des fonctions de bibliothèque al_draw_pixel(3)

NOM

al_draw_pixel - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
void al_draw_pixel(float x, float y, ALLEGRO_COLOR color)

DESCRIPTION

Dessine un seul pixel aux coordonnées x, y. Cette fonction, contrairement à al_put_pixel(3), effectue un mélange et, contrairement à al_put_blended_pixel(3), respecte les transformations (c'est-à-dire que la position du pixel est transformée, mais sa taille n'est pas affectée - il reste un pixel). Cette fonction peut être lente si elle est appelée souvent ; si vous avez besoin de dessiner beaucoup de pixels, envisagez d'utiliser al_draw_prim(3) avec ALLEGRO_PRIM_POINT_LIST du module d'extensions de primitives.

•
x - coordonnée x de destination
•
y - coordonnée y de destination
•
color - couleur du pixel

Remarque : Cette fonction peut ne pas dessiner exactement là où vous vous attendez. Consultez la section sur la sortie précise des pixels dans la documentation du module d'extensions de primitives pour savoir comment contrôler précisément où le pixel est dessiné.

VOIR AUSSI

ALLEGRO_COLOR(3), al_put_pixel(3)
