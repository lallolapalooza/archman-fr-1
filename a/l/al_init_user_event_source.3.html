NOM

al_init_user_event_source - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
void al_init_user_event_source(ALLEGRO_EVENT_SOURCE *src)

DESCRIPTION

Initialise une source d'événements pour émettre des événements utilisateur. L'espace pour la source d'événements doit déjà avoir été alloué.

Une façon possible de créer des sources d'événements personnalisées est de dériver d'autres structures avec ALLEGRO_EVENT_SOURCE en tête, par exemple :

typedef struct THING THING;
struct THING {
    ALLEGRO_EVENT_SOURCE event_source;
    int field1;
    int field2;
    /* etc. */
};
THING *create_thing(void)
{
    THING *thing = malloc(sizeof(THING));
    if (thing) {
        al_init_user_event_source(&thing->event_source);
        thing->field1 = 0;
        thing->field2 = 0;
    }
    return thing;
}

L'avantage ici est que le pointeur THING sera le même que le pointeur ALLEGRO_EVENT_SOURCE. Les événements émis par la source d'événements auront le pointeur de la source d'événements comme champ source, à partir duquel vous pourrez obtenir un pointeur vers un THING par un simple cast (après vous être assuré de vérifier que l'événement est du bon type).

Cependant, ce n'est qu'une technique et vous n'êtes pas obligé de l'utiliser.

La source d'événements utilisateur ne sera jamais détruite automatiquement. Vous devez la détruire manuellement avec al_destroy_user_event_source(3).

VOIR AUSSI
