NOM

alpm-srcinfo-create - Crée un fichier SRCINFO à partir d'un fichier PKGBUILD à un chemin donné

SYNTAXE

alpm-srcinfo create [-o|--output-format] [-p|--pretty] [-h|--help] <FICHIER>

DESCRIPTION

Crée un fichier SRCINFO à partir d'un fichier PKGBUILD situé à un chemin donné.

Si le PKGBUILD peut être créé et validé, le programme se termine sans sortie et avec un code de retour de 0. Si le fichier est manquant ou ne peut pas être validé, une erreur est émise sur stderr et le programme se termine avec un code de sortie non nul.

OPTIONS

-o, --output-format <FORMAT_SORTIE> [par défaut : srcinfo]
Spécifie le format de sortie

Valeurs possibles :

  • json : Le format de sortie JSON
  • srcinfo : Le format de sortie SRCINFO
-p, --pretty
Imprime la sortie de manière lisible.

Ne s'applique qu'aux formats qui prennent en charge la sortie lisible et est sinon ignoré.

-h, --help
Affiche l'aide (voir un résumé avec « -h »)
<FICHIER>
Un chemin de fichier d'entrée optionnel à lire

Si aucun fichier n'est spécifié, l'entrée standard est lue et est censée contenir des données PKGINFO à valider.
