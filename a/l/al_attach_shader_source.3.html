DESCRIPTIO

N

Attache le code source du shader à l'objet shader et le compile. Le passage de NULL supprime le shader sous-jacent (OpenGL ou DirectX). Voir aussi al_attach_shader_source_file(3) si vous préférez obtenir votre source de shader depuis un fichier

externe.

Si vous n'utilisez pas ALLEGRO_PROGRAMMABLE_PIPELINE, les fonctions graphiques d'Allegro n'utiliseront aucune fonction spécifique aux shaders elles-mêmes. Dans le cas d'un système sans pipeline à fonction fixe (comme OpenGL ES 2 ou OpenGL 3 ou 4), cela signifie que les fonctions de dessin d'Allegro ne peuvent pas être

utilisées.
