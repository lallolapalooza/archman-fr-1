NAME

al_play_audio_stream - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_audio.h>
ALLEGRO_AUDIO_STREAM *al_play_audio_stream(const char *filename)

DESCRIPTION

Charge et joue un fichier audio, en le diffusant depuis le disque au besoin. Cette API ne peut lire qu'un seul flux audio à la fois. Cela nécessite qu'un mixeur par défaut soit défini, ce qui est généralement fait via al_reserve_samples(3), mais peut également être fait via al_set_default_mixer(3).

Retourne le flux en cas de succès, NULL en cas d'échec. Vous ne devez pas détruire le flux retourné, il sera automatiquement détruit lorsque l'extension sera arrêtée.

Note: la bibliothèque allegro_audio ne prend en charge aucun format de fichier audio par défaut. Vous devez utiliser l'extension allegro_acodec, ou enregistrer votre propre gestionnaire de format.

VOIR AUSSI

al_play_audio_stream_f(3), al_load_audio_stream(3)

DEPUIS
