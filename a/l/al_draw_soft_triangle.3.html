NOM

al_draw_soft_triangle - API Allegro 5

SYNOPIS

#include <allegro5/allegro_primitives.h>
void al_draw_soft_triangle(
   ALLEGRO_VERTEX* v1, ALLEGRO_VERTEX* v2, ALLEGRO_VERTEX* v3, uintptr_t state,
   void (*init)(uintptr_t, ALLEGRO_VERTEX*, ALLEGRO_VERTEX*, ALLEGRO_VERTEX*),
   void (*first)(uintptr_t, int, int, int, int),
   void (*step)(uintptr_t, int),
   void (*draw)(uintptr_t, int, int, int))

DESCRIPTION

Dessine un triangle à l'aide du rastériseur logiciel et de fonctions de pixel fournies par l'utilisateur. Pour comprendre ce que font ces fonctions, consultez l'implémentation des diverses routines d'ombrage dans addons/primitives/tri_soft.c. Le triangle est dessiné en deux segments, de haut en bas. Les segments sont délimités par le sommet verticalement moyen du triangle. L'un des deux segments peut être absent si deux sommets sont horizontalement colinéaires.

Paramètres :

•
v1, v2, v3 - Les trois sommets du triangle
•
state - Un pointeur vers une structure fournie par l'utilisateur, cette structure sera passée à toutes les fonctions de pixel
•
init - Appelée une fois par appel avant toute opération de dessin. Les trois points qui lui sont passés peuvent être modifiés par découpage.
•
first - Appelée deux fois par appel, une fois par segment de triangle. Elle reçoit 4 paramètres, les deux premiers sont les coordonnées du premier pixel dessiné dans le segment. Les deux derniers sont les pas mineur gauche et majeur gauche, respectivement. Ils représentent les tailles de deux pas effectués par le rastériseur lorsqu'il marche sur le côté gauche du triangle. À partir de là, chaque pas sera classé comme mineur ou majeur, correspondant aux valeurs ci-dessus.
•
step - Appelée une fois par ligne de balayage. Le dernier paramètre est défini à 1 si le pas est un pas mineur, et 0 s'il est un pas majeur.
•
draw - Appelée une fois par ligne de balayage. La fonction doit dessiner la ligne de balayage en commençant par un point spécifié par les deux premiers paramètres (correspondant aux valeurs x et y) et en se déplaçant vers la droite jusqu'à atteindre la valeur du troisième paramètre (la valeur x du point de fin). Toutes les coordonnées sont incluses.
