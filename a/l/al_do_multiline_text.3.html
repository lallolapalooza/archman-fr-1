al_do_multiline_text(3) Manuel des fonctions de bibliothèque al_do_multiline_text(3)

NOM

al_do_multiline_text - API Allegro 5

SYNTAXE

#include <allegro5/allegro_font.h>
void al_do_multiline_text(const ALLEGRO_FONT *font,
   float max_width, const char *text,
   bool (*cb)(int line_num, const char *line, int size, void *extra),
   void *extra)

DESCRIPTION

Cette fonction traite le texte et le divise en lignes comme le ferait al_draw_multiline_text(3), puis appelle la fonction de rappel cb une fois pour chaque ligne. Ceci est utile pour le dessin personnalisé de texte multiligne, ou pour calculer la taille du texte multiligne à l'avance. Voir la documentation de al_draw_multiline_text(3) pour une explication de l'algorithme de division.

Pour chaque ligne dans laquelle cette fonction divise le texte, la fonction de rappel cb sera appelée une fois avec les paramètres suivants :

•
line_num - le numéro de la ligne, commençant à zéro et augmentant
•
line - un pointeur vers le caractère de début de la ligne (voir ci-dessous)
•
size - la taille de la ligne (0 pour les lignes vides)
•
extra - le même pointeur qui a été passé à al_do_multiline_text

Notez que line n'est pas garanti d'être une chaîne NUL-terminée, mais pointera simplement vers un caractère dans text ou vers une chaîne vide dans le cas d'une ligne vide. Si vous avez besoin d'une chaîne NUL-terminée, vous devrez copier line dans un tampon et le terminer par NUL vous-même. Vous devrez également faire votre propre copie si vous avez besoin du contenu de line après le retour de cb, car line n'est pas garanti d'être valide après cela.

Si la fonction de rappel cb renvoie false, al_do_multiline_text s'arrêtera immédiatement, sinon elle continuera sur la ligne suivante.
