al_fputs(3) Manuel des fonctions de bibliothèque al_fputs(3)

NOM

al_fputs - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
int al_fputs(ALLEGRO_FILE *f, char const *p)

DESCRIPTION

Écrit une chaîne de caractères dans un fichier. À part la valeur de retour, ceci est équivalent à :

al_fwrite(f, p, strlen(p));

Paramètres :

•
f - descripteur de fichier vers lequel écrire
•
p - chaîne de caractères à écrire

Retourne un entier non négatif en cas de succès, EOF en cas d'erreur.

Note : en fonction du type de flux et du mode passé à al_fopen(3), les caractères de nouvelle ligne dans la chaîne peuvent ou non être automatiquement traduits en séquences de fin de ligne natives, par exemple CR/LF au lieu de LF.
