ALPM MANUALS

NAME

alpm-state-repo - repository state definition

DESCRIPTION

The repository state file defines the contents of a repository. It is used by pacman(8) to determine which packages are available in a given repository and their metadata.

The file is typically located in the repository's directory or can be referenced by a URL.

FORMAT

The repository state file is a text file with a simple key-value format. Each line represents a package entry.

The following keys are supported:

Name:
The name of the package.
Version:
The version of the package.
Description:
A short description of the package.
Architecture:
The architecture of the package (e.g., x86_64, i686, any).
URL:
The URL to the package's homepage.
Licenses:
The license(s) under which the package is distributed.
Groups:
Groups the package belongs to.
Depends:
Dependencies required by the package.
Optional Depends:
Optional dependencies.
Required By:
Packages that require this package.
Optional Required By:
Packages that optionally require this package.
Conflicts With:
Packages that conflict with this package.
Replaces:
Packages that this package replaces.
Provides:
Virtual packages or functionalities provided by this package.
Maintainer:
The maintainer of the package.
Packager:
The person who packaged the software.
Build Date:
The date the package was built.
Install Size:
The size of the package after installation.
Download Size:
The size of the package file for download.
SHA256Sum:
The SHA256 checksum of the package file.
MD5Sum:
The MD5 checksum of the package file.
Signature:
The signature of the package file.

Package entries are separated by blank lines.

EXAMPLES

Name         : mypackage
Version      : 1.0-1
Architecture : x86_64
URL          : https://example.com/mypackage
Licenses     : GPL2
Groups       : base
Depends      : openssl
Description  : A sample package for demonstration.
Packager     : John Doe <john.doe@example.com>
Build Date   : Mon 01 Jan 2024 12:00:00 AM UTC
Install Size : 10240
Download Size: 5120
SHA256Sum    : a1b2c3d4e5f67890abcdef1234567890abcdef1234567890abcdef1234567890

SEE ALSO

pacman(8)

NOTES

This file format is specific to Arch Linux Package Manager (ALPM). Other package managers may use different formats for their repository metadata.

The repository state file is typically generated by tools like repo-add, which is part of the pacman-contrib package.
