ALTER LARGE OBJECT(7) Documentation PostgreSQL 18.1 ALTER LARGE OBJECT(7)

NOM

ALTER_LARGE_OBJECT - modifier la définition d'un grand objet

SYNTAXE

ALTER LARGE OBJECT oid_grand_objet OWNER TO { nouveau_proprietaire | CURRENT_ROLE | CURRENT_USER | SESSION_USER }

DESCRIPTION

ALTER LARGE OBJECT modifie la définition d'un grand objet.

Vous devez être propriétaire du grand objet pour utiliser ALTER LARGE OBJECT. Pour modifier le propriétaire, vous devez également pouvoir utiliser SET ROLE pour le nouveau rôle propriétaire. (Cependant, un superutilisateur peut modifier n'importe quel grand objet.) Actuellement, la seule fonctionnalité est d'attribuer un nouveau propriétaire, donc les deux restrictions s'appliquent toujours.

PARAMÈTRES

oid_grand_objet

OID du grand objet à modifier

nouveau_proprietaire

Le nouveau propriétaire du grand objet

COMPATIBILITÉ

Il n'existe pas d'instruction ALTER LARGE OBJECT dans la norme SQL.
