al_fixmul(3) Manuel des fonctions de bibliothèque al_fixmul(3)

NOM

al_fixmul - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
al_fixed al_fixmul(al_fixed x, al_fixed y);

DESCRIPTION

Une valeur à virgule fixe peut être multipliée ou divisée par un entier avec les opérateurs * et / normaux. Pour multiplier deux valeurs à virgule fixe, cependant, vous devez utiliser cette fonction.

Si un dépassement de capacité se produit, errno d'Allegro sera défini et la valeur maximale possible sera retournée, mais errno n'est pas effacé si l'opération réussit. Cela signifie que si vous devez tester un dépassement de capacité, vous devriez appeler al_set_errno(0) avant d'appeler al_fixmul(3).

Exemple :

al_fixed result;
/* Ceci mettra 30000 dans `result'. */
result = al_fixmul(al_itofix(10), al_itofix(3000));
/* Mais ceci dépasse la capacité et définit errno. */
result = al_fixmul(al_itofix(100), al_itofix(3000));
assert(!al_get_errno());

VALEUR DE RETOUR

Retourne le résultat écrêté de la multiplication de x par y, en définissant errno d'Allegro à ERANGE s'il y a eu un dépassement de capacité.

VOIR AUSSI

al_fixadd(3), al_fixsub(3), al_fixdiv(3), al_get_errno(3).
