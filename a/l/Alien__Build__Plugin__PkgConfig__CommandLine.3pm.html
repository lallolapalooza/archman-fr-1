Alien::Build::Plugin::PkgConfig::CommandLine(3) Documentation Perl fournie par l'utilisateur Alien::Build::Plugin::PkgConfig::CommandLine(3)

NOM

Alien::Build::Plugin::PkgConfig::CommandLine - Sonder le système et déterminer les propriétés d'une bibliothèque ou d'un outil en utilisant l'interface en ligne de commande de pkg-config

VERSION

version 2.84

SYNTAXE

use alienfile;
plugin 'PkgConfig::CommandLine' => (
  pkg_name => 'libfoo',
);

DESCRIPTION

Note : dans la plupart des cas, vous voudrez utiliser Alien::Build::Plugin::PkgConfig::Negotiate à la place. Il choisit le plugin de récupération approprié en fonction de votre plateforme et de votre environnement. Dans certains cas, vous pourriez avoir besoin d'utiliser ce plugin directement.

Ce plugin fournit les étapes de sondage (Probe) et de collecte (Gather) pour les paquets basés sur pkg-config. Il utilise les meilleurs outils en ligne de commande pour accomplir cette tâche.

PROPRIÉTÉS

pkg_name

Le nom du paquet. S'il s'agit d'une référence de liste, les fichiers .pc avec tous ces noms de paquets doivent être présents. Le premier nom sera le primaire et sera utilisé par défaut une fois installé. Pour les fichiers ".pc" suivants, vous pouvez utiliser la méthode alt de Alien::Base pour récupérer les configurations alternatives une fois que l'Alien est installé.

au_moins_version

La version minimale requise qui est une version acceptable telle que fournie par le système.

version_exacte

La version exacte requise qui est une version acceptable telle que fournie par le système.

max_version

La version maximale requise qui est une version acceptable telle que fournie par le système.

version_minimale

Alias pour "atleast_version" pour la compatibilité descendante.

MÉTHODES

disponible

my $bool = Alien::Build::Plugin::PkgConfig::CommandLine->available;

Retourne vrai si les prérequis nécessaires pour ce plugin sont *déjà* installés.
