NOM

al175 - Pilote pour les modèles d'onduleurs Eltek avec module d'alarme AL175

SYNOPSIS

al175 -h

al175 -a NOM_ONduleur [OPTIONS]


Note

Cette page de manuel documente uniquement les fonctionnalités spécifiques au matériel du pilote al175. Pour des informations sur le pilote de base, voir nutupsdrv(8).

MATÉRIEL SUPPORTÉ

Le pilote al175 est connu pour fonctionner avec les onduleurs suivants :

•Eltek MPSU4000 avec module d'alarme AL175

Il peut également fonctionner avec d'autres onduleurs équipés du module d'alarme AL175, mais ils n'ont pas été testés.

L'AL175 doit être configuré pour fonctionner en mode COMLI. Voir la documentation fournie avec votre matériel pour savoir comment faire.

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote ne prend en charge aucun paramètre supplémentaire dans le fichier ups.conf(5).

COMMANDES INSTANTANÉES

Ce pilote prend en charge quelques commandes supplémentaires (voir upscmd(8)) :

test.battery.start

Démarre un test de batterie.

test.battery.stop

Arrête un test de batterie.

VARIABLES

En plus de l'état, ce pilote lit l'état de l'onduleur dans les variables suivantes :

•ups.test.result
•output.voltage.nominal
•output.current
•battery.voltage.nominal
•battery.current
•battery.temperature
•input.transfer.boost.low

PROBLÈMES CONNUS ET BOGUES

•L'arrêt n'est pas pris en charge. À FAIRE
•Le pilote a été retravaillé pour répondre aux critères de qualité du code du projet, sans tests sur du matériel réel. Certains bogues ont pu s'y glisser.
