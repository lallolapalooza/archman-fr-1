al_save_sample_f(3) Manuel des fonctions de bibliothèque al_save_sample_f(3)

NOM

al_save_sample_f - API Allegro 5

SYNTAXE

#include <allegro5/allegro_audio.h>
bool al_save_sample_f(ALLEGRO_FILE *fp, const char *ident, ALLEGRO_SAMPLE *spl)

DESCRIPTION

Écrit un échantillon dans un flux de fichier ALLEGRO_FILE(3). Actuellement, le format wav est le seul format pris en charge, et l'extension doit être “.wav”.

Retourne vrai en cas de succès, faux en cas d'erreur. Le fichier reste ouvert ensuite.

Note : la bibliothèque allegro_audio ne prend en charge aucun format de fichier audio par défaut. Vous devez utiliser le module complémentaire allegro_acodec, ou enregistrer votre propre gestionnaire de format.

VOIR AUSSI

al_save_sample(3), al_register_sample_saver_f(3), al_init_acodec_addon(3)
