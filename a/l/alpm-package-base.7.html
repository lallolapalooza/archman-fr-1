alpm-package-base(7)

Paquet: alpm-docs

Licences: CC-BY-SA-4.0

(7) Manuel d'informations diverses (7)

NOM

package base - un identifiant qui suit de quelles sources provient un paquet basé sur ALPM.

DESCRIPTION

Le format package base représente un identifiant qui décrit l'origine source de chaque fichier alpm-package. Il est particulièrement utile dans les fichiers alpm-split-package pour suivre les sources à partir desquelles chaque fichier de paquet est construit.

Plus précisément, le format alpm-package-base est utilisé tout au long du cycle de vie de la gestion des paquets :

  • dans les scripts de construction et les fichiers de métadonnées source (c.-à-d. PKGBUILD et SRCINFO)
  • dans les formats de fichiers pour les métadonnées de paquets (c.-à-d. BUILDINFO et PKGINFO)
  • dans les formats de fichiers pour les métadonnées de dépôts (c.-à-d. alpm-repo-desc)
  • et dans les métadonnées d'état du système (c.-à-d. alpm-db-desc).

Format Général

Le nom de l'identifiant pour alpm-package-base peut varier en fonction du contexte. Cependant, les restrictions de valeur pour celui-ci sont les mêmes que celles pour alpm-package-name.

EXEMPLES

Le PKGBUILD d'un paquet nommé example, qui spécifie implicitement son alpm-package-base comme example.

pkgname=example
pkgver=1.0.0
pkgrel=1
pkgdesc="Un paquet exemple"
arch=(any)
url="https://example.org"
license=('CC0-1.0')
package() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "example\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}

Le PKGBUILD d'un paquet nommé example, qui spécifie explicitement son alpm-package-base comme something-else.

pkgname=example
pkgbase=something-else
pkgver=1.0.0
pkgrel=1
pkgdesc="Un paquet exemple"
arch=(any)
url="https://example.org"
license=('CC0-1.0')
package() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "example\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}

Le PKGBUILD d'une configuration de paquet divisé avec les paquets example et other-example qui partagent tous deux le alpm-package-base implicite example.

pkgname=(
  example
  other-example
)
pkgver=1.0.0
pkgrel=1
pkgdesc="Un paquet exemple"
arch=(any)
url="https://example.org"
license=('CC0-1.0')
package_example() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "example\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}
package_other-example() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "other-example\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}

Le PKGBUILD d'une configuration de paquet divisé avec les paquets example1 et example2 qui partagent tous deux le alpm-package-base explicite example.

pkgname=(
  example1
  example2
)
pkgbase=example
pkgver=1.0.0
pkgrel=1
pkgdesc="Un paquet exemple"
arch=(any)
url="https://example.org"
license=('CC0-1.0')
package_example1() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "example1\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}
package_example2() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "example2\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}
