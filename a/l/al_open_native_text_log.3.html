NOM

al_open_native_text_log - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_native_dialog.h>
ALLEGRO_TEXTLOG *al_open_native_text_log(char const *title, int flags)

DESCRIPTION

Ouvre une fenêtre à laquelle vous pouvez ajouter des messages de log avec al_append_native_text_log(3). Cela peut être utile pour le débogage si vous ne voulez pas dépendre d'une console disponible.

Utilisez al_close_native_text_log(3) pour fermer à nouveau la fenêtre.

Les drapeaux disponibles sont :

ALLEGRO_TEXTLOG_NO_CLOSE
Empêche la fenêtre d'avoir un bouton de fermeture. Sinon, si le bouton de fermeture est pressé, un événement est généré ; voir al_get_native_text_log_event_source(3).
ALLEGRO_TEXTLOG_MONOSPACE
Utilise une police à chasse fixe pour afficher le texte.

Retourne NULL s'il y a eu une erreur lors de l'ouverture de la fenêtre, ou si les fenêtres de log texte ne sont pas implémentées sur la plateforme.

Note : Sur Android, les logs peuvent être consultés en utilisant logcat.

VOIR AUSSI

al_append_native_text_log(3), al_close_native_text_log(3)
