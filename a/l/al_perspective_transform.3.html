al_perspective_transform(3) Manuel des fonctions de bibliothèque al_perspective_transform(3)

NOM

al_perspective_transform - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
void al_perspective_transform(ALLEGRO_TRANSFORM *trans,
   float left, float top, float n,
   float right, float bottom, float f)

DESCRIPTION

Comme al_orthographic_transform(3) mais respecte la perspective. Si tout est à une position z de -near, cela ressemblera à une transformation orthographique.

Pour utiliser un champ de vision horizontal spécifique, vous pouvez utiliser la relation :

tan(hfov / 2) = (right - left) / 2 / near

et par conséquent

near = (right - left) / 2 / tan(hfov / 2)

Exemple 1 :

   float w = 800, h = 450; // supposons que notre écran soit de 800 x 450
   float fov = tan(90 * ALLEGRO_PI / 180 / 2); // champ de vision de 90 degrés
   // Notre projection va de 0/0 à w/h avec le paramètre near réglé
   // pour un angle de vue horizontal de 90 degrés.
   ALLEGRO_TRANSFORM projection;
   al_identity_transform(&projection);
   al_perspective_transform(&projection,
    0, 0,
    w / 2 / fov,
    w, h,
    2000);
   al_use_projection_transform(&projection);
   // Régler le z de la caméra à +400 (ce qui correspond exactement à la distance near)
   ALLEGRO_TRANSFORM camera;
   al_build_camera_transform(&camera, 0, 0, 400, 0, 0, 0, 0, 1, 0);
   al_use_transform(&camera);
   // Cela dessinera deux rectangles sur les bords gauche et droit de l'écran
   // et centrés verticalement. La distance x entre eux est de 800 unités,
   // mais la transformation de caméra les déplace de 400 le long de z,
   // donc avec un angle de vue de 90°, les deux sont visibles.
   al_draw_filled_rectangle(0, 200, 50, 250, red;
   al_draw_filled_rectangle(750, 200, 800, 250, red);

Exemple 2 :

   float w = 800, h = 450; // supposons que notre écran soit de 800 x 450
   float fov = tan(90 * ALLEGRO_PI / 180 / 2); // champ de vision de 90 degrés
   float aspect = h / w;
   float zoom = 2; // agrandir x 2
   // Cette projection est très différente de celle du premier exemple.
   // Ici, nous mappons les bords gauche et droit de l'écran à -1 et +1. Et
   // l'axe y va de -1 en bas à +1 en haut, mis à l'échelle par
   // le rapport d'aspect. Nous ajoutons également un paramètre de zoom afin de pouvoir contrôler
   // la partie visible de la scène indépendamment du champ de vision.
   ALLEGRO_TRANSFORM projection;
   al_identity_transform(&projection);
   al_perspective_transform(&projection,
      -1 / zoom, aspect / zoom,
      1 / fov,
      1 / zoom, -aspect / zoom,
      2000);
   al_use_projection_transform(&projection);
   // Déplace tout de -4 dans la direction z.
   ALLEGRO_TRANSFORM camera;
   al_build_camera_transform(&camera, 0, 0, 4, 0, 0, 0, 0, 1, 0);
   al_use_transform(&camera);
   // À une distance z de 4 avec un hfov de 90°, tout serait mis à l'échelle
   // à 25%. Cependant, nous zoomons également 2 fois, donc la mise à l'échelle finale est
   // 50%. Ce rectangle apparaîtra donc avec une taille de 400 x 225 pixels
   // (en supposant que l'écran est de 800 x 450).
   al_draw_filled_rectangle(-1, -1, 1, 1, red);
