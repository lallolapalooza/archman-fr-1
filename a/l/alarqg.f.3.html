sous-programme alarqg (character*3 path, integer nmats, logical, dimension( * ) dotype, integer ntypes, integer nin, integer nout)

ALARQG

Objectif :

!>
!> ALARQG gère les entrées pour le programme de test LAPACK. Il est appelé
!> pour évaluer la ligne d'entrée qui a demandé NMATS types de matrices pour
!> PATH. Le flux de contrôle est le suivant :
!>
!> SI NMATS = NTYPES ALORS
!>    DOTYPE(1:NTYPES) = .VRAI.
!> SINON
!>    Lire la ligne d'entrée suivante pour NMATS types de matrices
!>    Définir DOTYPE(I) = .VRAI. pour chaque type valide I
!> FIN SI
!>

Paramètres

PATH 
!>          PATH est CHARACTER*3
!>          Un nom de chemin LAPACK pour les tests.
!>

NMATS

!>          NMATS est INTEGER
!>          Le nombre de types de matrices à utiliser dans les tests de ce chemin.
!>

DOTYPE

!>          DOTYPE est un tableau LOGICAL, de dimension (NTYPES)
!>          Le vecteur d'indicateurs indiquant si chaque type sera testé.
!>

NTYPES

!>          NTYPES est INTEGER
!>          Le nombre maximum de types de matrices pour ce chemin.
!>

NIN

!>          NIN est INTEGER
!>          Le numéro d'unité pour l'entrée. NIN >= 1.
!>

NOUT

!>          NOUT est INTEGER
!>          Le numéro d'unité pour la sortie. NOUT >= 1.
!>
