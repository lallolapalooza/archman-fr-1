Algorithm::DiffOld(3) Documentation Perl fournie par l'utilisateur Algorithm::DiffOld(3)

NOM

Algorithm::DiffOld - Calcule les différences « intelligentes » entre deux fichiers / listes mais utilise l'ancienne interface (<=0.59).

NOTE

Ceci a été fourni dans le cadre du paquet Algorithm::Diff par Ned Konz. Ce module particulier est UNIQUEMENT pour les personnes qui DOIVENT avoir l'ancienne interface, qui utilise une fonction de comparaison plutôt qu'une fonction de génération de clé.

Étant donné que chaque ligne d'un tableau doit être comparée à chaque ligne de l'autre tableau, cela effectue M*N comparaisons. Cela peut être très lent. Je l'ai chronométré à 18 fois plus longtemps que la version standard d'Algorithm::Diff pour un fichier de 4000 lignes. Cela empirera quadratiquement à mesure que la taille des tableaux augmentera.

SYNTAXE

use Algorithm::DiffOld qw(diff LCS traverse_sequences);
@lcs    = LCS( \@seq1, \@seq2, $fonction_de_comparaison );
$lcsref = LCS( \@seq1, \@seq2, $fonction_de_comparaison );
@diffs = diff( \@seq1, \@seq2, $fonction_de_comparaison );

traverse_sequences( \@seq1, \@seq2,
                   { MATCH => $callback,
                     DISCARD_A => $callback,
                     DISCARD_B => $callback,
                   },
                   $fonction_de_comparaison );

FONCTIONS DE COMPARAISON

Chacune des routines principales devrait recevoir une fonction de comparaison. Si vous n'en passez pas une, utilisez plutôt Algorithm::Diff.

Ces fonctions doivent retourner une valeur vraie lorsque deux éléments doivent être considérés comme égaux.

Par exemple,

@lcs    = LCS( \@seq1, \@seq2, sub { my ($a, $b) = @_; $a eq $b } );

mais si c'est tout ce que vous faites avec votre fonction de comparaison, utilisez simplement Algorithm::Diff et laissez-le faire cela (c'est son comportement par défaut).

Ou :

sub someFunkyComparisonFunction
{
      my ($a, $b) = @_;
      $a =~ m{$b};
}
@diffs = diff( \@lines, \@patterns, \&someFunkyComparisonFunction );

ce qui vous permettrait de faire la différence entre un tableau @lines constitué de lignes de texte et un tableau @patterns constitué d'expressions régulières.

C'est d'ailleurs la raison pour laquelle j'ai écrit cette version -- il n'y a aucun moyen de faire cela avec une fonction de génération de clé comme dans le Algorithm::Diff standard.
