al_create_sample(3) Manuel des fonctions de bibliothèque al_create_sample(3)

NOM

al_create_sample - API Allegro 5

SYNTAXE

#include <allegro5/allegro_audio.h>
ALLEGRO_SAMPLE *al_create_sample(void *buf, unsigned int samples,
   unsigned int freq, ALLEGRO_AUDIO_DEPTH depth,
   ALLEGRO_CHANNEL_CONF chan_conf, bool free_buf)

DESCRIPTION

Crée une structure de données d'échantillon à partir du tampon fourni. Si free_buf est vrai, le tampon sera libéré avec al_free(3) lorsque la structure de données d'échantillon sera détruite. Pour la portabilité (notamment sous Windows), le tampon aurait dû être alloué avec al_malloc(3). Sinon, vous devriez libérer la structure de données d'échantillon vous-même.

Un échantillon auquel il est fait référence par le paramètre samples fait référence à une séquence d'intensités de canaux. Par exemple, si vous créez un échantillon stéréo avec samples défini à 4, alors la disposition des données dans buf sera :

LRLRLRLR

Où L et R sont les intensités des canaux gauche et droit respectivement. Un seul échantillon, alors, fait référence à la paire LR dans cet exemple.

Pour allouer un tampon de la taille correcte, vous pouvez utiliser quelque chose comme ceci :

int sample_size = al_get_channel_count(chan_conf)
                  * al_get_audio_depth_size(depth);
int bytes = samples * sample_size;
void *buffer = al_malloc(bytes);
