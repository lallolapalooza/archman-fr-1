sous-programme alaerh (character*3 path, character*( * ) subnam, integer info, integer infoe, character*( * ) opts, integer m, integer n, integer kl, integer ku, integer n5, integer imat, integer nfail, integer nerrs, integer nout)

ALAERH

Objectif:

!>
!> ALAERH est un gestionnaire d'erreurs pour les routines LAPACK. Il affiche
!> l'en-tête s'il s'agit du premier message d'erreur et affiche le code
!> d'erreur et la forme de récupération, le cas échéant. Les évaluations de
!> caractères dans cette routine peuvent la ralentir, mais elle ne devrait pas
!> être appelée une fois que les routines LAPACK sont entièrement déboguées.
!>

Paramètres

PATH 
!>          PATH est CHARACTER*3
!>          Le nom de chemin LAPACK de la sous-routine SUBNAM.
!>

SUBNAM

!>          SUBNAM est CHARACTER*(*)
!>          Le nom de la sous-routine qui a renvoyé un code d'erreur.
!>

INFO

!>          INFO est INTEGER
!>          Le code d'erreur renvoyé par la routine SUBNAM.
!>

INFOE

!>          INFOE est INTEGER
!>          Le code d'erreur attendu de la routine SUBNAM, si SUBNAM était
!>          sans erreur. Si INFOE = 0, un message d'erreur est affiché, mais
!>          si INFOE.NE.0, nous supposons que seul le code de retour INFO est
!>          incorrect.
!>

OPTS

!>          OPTS est CHARACTER*(*)
!>          Les options de caractères pour la sous-routine SUBNAM, concaténées
!>          en une seule chaîne de caractères. Par exemple, UPLO = 'U',
!>          TRANS = 'T', et DIAG = 'N' pour une routine triangulaire seraient
!>          spécifiés comme OPTS = 'UTN'.
!>

M

!>          M est INTEGER
!>          La dimension de ligne de la matrice.
!>

N

!>          N est INTEGER
!>          La dimension de colonne de la matrice. Accédé uniquement si PATH = xGE ou
!>          xGB.
!>

KL

!>          KL est INTEGER
!>          Le nombre de sous-diagonales de la matrice. Accédé uniquement si
!>          PATH = xGB, xPB, ou xTB. Également utilisé pour NRHS pour PATH = xLS.
!>

KU

!>          KU est INTEGER
!>          Le nombre de super-diagonales de la matrice. Accédé uniquement
!>          si PATH = xGB.
!>

N5

!>          N5 est INTEGER
!>          Un cinquième paramètre entier, peut être la taille de bloc NB ou le
!>          nombre de membres de droite NRHS.
!>

IMAT

!>          IMAT est INTEGER
!>          Le type de matrice.
!>

NFAIL

!>          NFAIL est INTEGER
!>          Le nombre de tests précédents qui n'ont pas atteint le seuil ;
!>          utilisé pour déterminer si l'en-tête doit être affiché.
!>

NERRS

!>          NERRS est INTEGER
!>          À l'entrée, le nombre d'erreurs déjà détectées ; utilisé pour
!>          déterminer si l'en-tête doit être affiché.
!>          À la sortie, NERRS est incrémenté de 1.
!>

NOUT

!>          NOUT est INTEGER
!>          Le numéro d'unité sur lequel les résultats doivent être imprimés.
!>
