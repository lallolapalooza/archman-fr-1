Alien::Build::Interpolate(3) Documentation Perl fournie par l'utilisateur Alien::Build::Interpolate(3)

NOM

Alien::Build::Interpolate - Moteur d'interpolation avancé pour les compilations Alien

VERSION

version 2.84

CONSTRUCTEUR

new

my $intr = Alien::Build::Interpolate->new;

add_helper

$intr->add_helper($name => $code);
$intr->add_helper($name => $code, %requirements);

replace_helper

$intr->replace_helper($name => $code);
$intr->replace_helper($name => $code, %requirements);

has_helper

my $coderef = $intr->has_helper($name);

Utilisé pour découvrir si un assistant existe avec le nom donné. Retourne la référence de code.

execute_helper

my $value = $intr->execute_helper($name);

Ceci évalue l'assistant donné et retourne le résultat.

interpolate

my $string = $intr->interpolate($template, $build);
my $string = $intr->interpolate($template);

Ceci prend un modèle et remplit les valeurs appropriées de tous les assistants utilisés dans le modèle.

[version 2.58]

Si vous passez une instance d'Alien::Build comme deuxième argument, vous pouvez utiliser des propriétés ainsi que des assistants dans le modèle. Exemple :

my $patch = $intr->template("%{.install.patch}/foo-%{.runtime.version}.patch", $build);

requires

my %requires = $intr->requires($template);

Ceci retourne une table (hash) des modules requis pour exécuter le modèle donné. Les clés sont les noms des modules et les valeurs sont les versions. La version sera définie à 0 si toute version est suffisante.

clone

my $intr2 = $intr->clone;

Ceci crée un clone de l'interpolateur.
