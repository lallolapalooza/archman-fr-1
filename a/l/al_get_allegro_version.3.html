al_get_allegro_version(3) Manuel des fonctions de bibliothèque al_get_allegro_version(3)

NOM

al_get_allegro_version - API Allegro 5

SYNOPHIS

#include <allegro5/allegro.h>
uint32_t al_get_allegro_version(void)

DESCRIPTION

Retourne la version (compilée) de la bibliothèque Allegro, regroupée en un seul entier sous forme de groupes de 8 bits selon le format (major << 24) | (minor << 16) | (revision << 8) | release.

Vous pouvez utiliser un code comme celui-ci pour les extraire :

uint32_t version = al_get_allegro_version();
int major = version >> 24;
int minor = (version >> 16) & 255;
int revision = (version >> 8) & 255;
int release = version & 255;

Le numéro de release est 0 pour une version non officielle et 1 ou plus pour une publication officielle. Par exemple, « 5.0.2[1] » serait la (première) publication officielle de la version 5.0.2, tandis que « 5.0.2[0] » serait une compilation d'une version de la branche « 5.0.2 » avant la publication officielle.
