al_join_paths(3) Manuel des fonctions de bibliothèque al_join_paths(3)

NOM

al_join_paths - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
bool al_join_paths(ALLEGRO_PATH *path, const ALLEGRO_PATH *tail)

DESCRIPTION

Concatène deux structures de chemin. La première structure de chemin est modifiée. Si `tail' est un chemin absolu, cette fonction ne fait rien.

Si `tail' est un chemin relatif, tous ses composants de répertoire seront ajoutés à `path'. Le nom de fichier de `tail' remplacera également le nom de fichier de `path', même s'il s'agit uniquement de la chaîne vide.

Le lecteur de `tail' est ignoré.

Retourne vrai si `tail' était un chemin relatif et a donc été concaténé à `path', sinon retourne faux.
