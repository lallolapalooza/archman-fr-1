ALTER_STATISTICS(7)

Paquet: postgresql

Licences: PostgreSQL

ALTER STATISTICS(7) Documentation PostgreSQL 18.1 ALTER STATISTICS(7)

NOM

ALTER_STATISTICS - modifier la définition d'un objet de statistiques étendues

SYNTAXE

ALTER STATISTICS nom OWNER TO { nouveau_proprietaire | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER STATISTICS nom RENAME TO nouveau_nom
ALTER STATISTICS nom SET SCHEMA nouveau_schema
ALTER STATISTICS nom SET STATISTICS { nouvelle_cible | DEFAULT }

DESCRIPTION

ALTER STATISTICS modifie les paramètres d'un objet de statistiques étendu existant. Tous les paramètres non spécifiquement définis dans la commande ALTER STATISTICS conservent leurs réglages précédents.

Vous devez posséder l'objet de statistiques pour utiliser ALTER STATISTICS. Pour changer le schéma d'un objet de statistiques, vous devez également avoir le privilège CREATE sur le nouveau schéma. Pour modifier le propriétaire, vous devez pouvoir exécuter SET ROLE sur le nouveau rôle propriétaire, et ce rôle doit avoir le privilège CREATE sur le schéma de l'objet de statistiques. (Ces restrictions garantissent que la modification du propriétaire ne fait rien que vous ne puissiez faire en supprimant et recréant l'objet de statistiques. Cependant, un superutilisateur peut modifier la propriété de n'importe quel objet de statistiques de toute façon.)

PARAMETRES

nom

Le nom (éventuellement qualifié par un schéma) de l'objet de statistiques à modifier.

nouveau_proprietaire

Le nom d'utilisateur du nouveau propriétaire de l'objet de statistiques.

nouveau_nom

Le nouveau nom pour l'objet de statistiques.

nouveau_schema

Le nouveau schéma pour l'objet de statistiques.

nouvelle_cible

La cible de collecte de statistiques pour cet objet de statistiques pour les opérations ANALYZE ultérieures. La cible peut être réglée dans la plage de 0 à 10000. Réglez-la à DEFAULT pour revenir à l'utilisation de la cible de statistiques par défaut du système (default_statistics_target). (Le réglage à une valeur de -1 est une manière obsolète d'obtenir le même résultat.) Pour plus d'informations sur l'utilisation des statistiques par le planificateur de requêtes PostgreSQL, référez-vous à la Section 14.2.

COMPATIBILITE

Il n'existe pas de commande ALTER STATISTICS dans la norme SQL.

VOIR AUSSI

CREATE STATISTICS (CREATE_STATISTICS(7)), DROP STATISTICS (DROP_STATISTICS(7))
