ALCC(1) Utilitaire aMule ALCC(1)

NOM

alcc - calculatrice de liens eD2k basée sur le texte pour aMule

SYNTAXE

alcc [-p] [-v] <liste_fichiers_entrée>

alcc [-h]

DESCRIPTION

Calcule les liens eD2k de tous les fichiers d'entrée donnés dans la <liste_fichiers_entrée> (Il peut y avoir un ou plusieurs fichiers).

[ -p, --parthashes ]
Calcule et ajoute les hachages de partie aux liens eD2k calculés.
[ -h, --help ]
Affiche une brève description de l'utilisation.
[ -v, --verbose ]
Mode verbeux - affiche également les étapes de calcul.
