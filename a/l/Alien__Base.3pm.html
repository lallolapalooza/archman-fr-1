N

REMARQUE : Alien::Base::ModuleBuild n'est plus inclus avec Alien::Base et a été séparé dans une distribution distincte. Alien::Base::ModuleBuild sera un prérequis pour Alien::Base jusqu'au 1er octobre 2017. Si vous utilisez Alien::Base::ModuleBuild, vous devez vous assurer qu'il est déclaré comme "configure_requires" dans votre "Build.PL". Vous pourriez aussi envisager d'utiliser Alien::Base et alienfile comme alternative plus

moderne.

Alien::Base comprend des classes de base pour aider à la construction de modules "Alien::". Les modules dans l'espace de noms Alien sont utilisés pour localiser et installer (si nécessaire) des bibliothèques externes nécessaires à d'autres modules

Perl.

Ceci est la documentation du module Alien::Base lui-même. Si vous débutez, vous voudrez probablement commencer par l'un de ces documents

Avant d'utiliser directement un Alien basé sur Alien::Base, veuillez considérer les conseils suivants

:

Si vous voulez utiliser un Alien basé sur Alien::Base avec un module XS utilisant ExtUtils::MakeMaker ou Module::Build, il est fortement recommandé d'utiliser Alien::Base::Wrapper plutôt que d'utiliser l'Alien directement, car il gère un certain nombre de cas délicats et évite les pièges courants lors de la tentative d'utilisation directe d'un Alien avec ExtUtils::

MakeMaker.

Dans le même ordre d'idées, si vous voulez utiliser un Alien basé sur Alien::Base avec un module XS utilisant Dist::Zilla, il est fortement recommandé d'utiliser Dist::Zilla::Plugin::AlienBase::Wrapper pour les mêmes

raisons.

Depuis la version 0.28, FFI::CheckLib dispose d'une bonne interface pour travailler avec les Aliens basés sur Alien::Base en mode de repli, ce qui est

recommandé.

Vous ne devriez généralement utiliser directement un Alien basé sur Alien::Base que si vous devez l'intégrer avec un autre système, ou s'il s'agit d'un Alien basé sur un outil que vous n'avez pas besoin de

lier.

ideront dans la bonne direction, mais il est utile de l
