NOM

ALLEGRO_RENDER_STATE - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
typedef enum ALLEGRO_RENDER_STATE {

DESCRIPTION

États de rendu possibles qui peuvent être définis avec al_set_render_state(3) :

ALLEGRO_ALPHA_TEST
Si cette valeur est définie à 1, les valeurs de ALLEGRO_ALPHA_FUNCTION et ALLEGRO_ALPHA_TEST_VALUE définissent une fonction de comparaison qui est effectuée sur la composante alpha de chaque pixel. Le pixel n'est écrit que si elle est évaluée comme vraie. Sinon, aucun traitement ultérieur (comme le test de profondeur ou le mélange) n'est effectué. Cela peut être très utile, par exemple si un tampon de profondeur est utilisé mais que vous ne voulez pas que les pixels entièrement transparents le modifient.
ALLEGRO_ALPHA_FUNCTION
Une de ALLEGRO_RENDER_FUNCTION(3), utilisée uniquement lorsque ALLEGRO_ALPHA_TEST est à 1.
ALLEGRO_ALPHA_TEST_VALUE
Utilisée uniquement lorsque ALLEGRO_ALPHA_TEST est à 1. Doit être une valeur de 0 à 255.
ALLEGRO_WRITE_MASK
Ceci détermine comment le framebuffer et le depthbuffer sont mis à jour à chaque fois qu'un pixel est écrit (dans le cas où les tests alpha et/ou de profondeur sont activés : après que tous les tests activés réussissent). Les valeurs de profondeur ne sont écrites que si ALLEGRO_DEPTH_TEST est à 1, en plus de l'activation du masque d'écriture.
ALLEGRO_DEPTH_TEST
Si cette valeur est définie à 1, compare la valeur de profondeur de tout nouveau pixel écrit avec la valeur de profondeur déjà présente dans le tampon, selon ALLEGRO_DEPTH_FUNCTION. Les primitives Allegro sans coordonnée z explicite écriront une valeur de 0 dans le tampon de profondeur.
ALLEGRO_DEPTH_FUNCTION
Une de ALLEGRO_RENDER_FUNCTION(3), utilisée uniquement lorsque ALLEGRO_DEPTH_TEST est à 1.
