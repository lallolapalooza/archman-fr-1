NOM

alot - MUA de terminal utilisant notmuch mail

SYNTAXE

alot [options ...] [sous-commande]

DESCRIPTION

Alot est un agent utilisateur de messagerie basé sur terminal pour le système de messagerie notmuch. Il présente une interface modulaire et pilotée par invite de commande pour fournir une expérience MUA complète en tant qu'alternative au mode Emacs fourni avec notmuch.

OPTIONS

-r, --read-only
ouvrir la base de données notmuch en mode lecture seule
-c FICHIER, --config=FICHIER
fichier de configuration (par défaut : ~/.config/alot/config)
-n FICHIER, --notmuch-config=FICHIER
fichier de configuration notmuch (par défaut : voir notmuch-config(1))
-C COULEURS, --colour-mode=COULEURS
nombre de couleurs à utiliser sur le terminal ; doit être 1, 16 ou 256 (par défaut : option de configuration colourmode ou 256)
-p CHEMIN, --mailindex-path=CHEMIN
chemin vers l'index notmuch
-d NIVEAU, --debug-level=NIVEAU
niveau de débogage ; doit être l'un de debug, info, warning ou error (par défaut : info)
-l FICHIER, --logfile=FICHIER
fichier journal (par défaut : /dev/null)
-h, --help
afficher l'aide et quitter
-v, --version
afficher les informations de version et quitter

COMMANDES

search
démarrer dans un tampon de recherche en utilisant la chaîne de requête fournie en paramètre (voir notmuch-search-terms(7))
compose
rédiger un nouveau message
bufferlist
démarrer avec seulement un tampon de liste de tampons ouvert
taglist
démarrer avec seulement un tampon de liste d'étiquettes ouvert
namedqueries
démarrer avec la liste des requêtes nommées
pyshell
démarrer le shell python interactif à l'intérieur d'alot

UTILISATION

Les touches fléchées, page-haut/bas, j, k et Espace peuvent être utilisées pour déplacer le focus. Échap annule les invites et Entrée sélectionne. Appuyez sur : à tout moment et tapez des commandes à l'invite.

L'interface affiche un tampon à la fois, vous pouvez utiliser Tab et Maj-Tab pour basculer entre eux, fermer le tampon actuel avec d et les lister tous avec ;.

Le type de tampon ou le mode (affiché en bas à gauche) détermine les commandes d'invite disponibles. Les informations d'utilisation sur n'importe quelle commande peuvent être listées en tapant help VOTRECOMMANDE à l'invite. Les raccourcis clavier pour le mode actuel sont listés en appuyant sur ?.

SIGNALS UNIX

SIGUSR1
Rafraîchit le tampon actuel.
SIGINT
Arrête l'interface utilisateur.
