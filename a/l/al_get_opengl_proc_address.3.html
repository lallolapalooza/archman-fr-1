al_get_opengl_proc_address(3) Manuel des fonctions de bibliothèque al_get_opengl_proc_address(3)

NOM

al_get_opengl_proc_address - API Allegro 5

SYNTAXE

#include <allegro5/allegro_opengl.h>
void *al_get_opengl_proc_address(const char *name)

DESCRIPTION

Utilité pour obtenir l'adresse d'un symbole OpenGL

Exemple :

Comment obtenir la fonction glMultiTexCoord3fARB fournie par l'extension Multitexture d'ARB :

// définir le type de la fonction
ALLEGRO_DEFINE_PROC_TYPE(void, MULTI_TEX_FUNC,
                         (GLenum, GLfloat, GLfloat, GLfloat));
// déclarer le pointeur de fonction
MULTI_TEX_FUNC glMultiTexCoord3fARB;
// obtenir l'adresse de la fonction
glMultiTexCoord3fARB = (MULTI_TEX_FUNC) al_get_opengl_proc_address(
                                                        "glMultiTexCoord3fARB");

Si glMultiTexCoord3fARB n'est pas NULL, alors il peut être utilisé comme s'il avait été défini dans la bibliothèque principale OpenGL.

Note : Sous Windows, les fonctions OpenGL peuvent nécessiter une convention d'appel spéciale, il est donc préférable d'utiliser toujours le macro ALLEGRO_DEFINE_PROC_TYPE lors de la déclaration de types de pointeurs de fonction pour les fonctions OpenGL.

Paramètres :

name - Le nom du symbole auquel vous souhaitez vous lier.

VALEUR DE RETOUR

Un pointeur vers le symbole s'il est disponible ou NULL sinon.
