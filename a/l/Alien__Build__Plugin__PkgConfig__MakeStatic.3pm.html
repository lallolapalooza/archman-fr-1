NOM

Alien::Build::Plugin::PkgConfig::MakeStatic - Convertir les fichiers .pc en statique

VERSION

version 2.84

SYNOPSIS

use alienfile;

plugin 'PkgConfig::MakeStatic' => (
  path => 'lib/pkgconfig/foo.pc',
);

DESCRIPTION

Convertit un fichier ".pc" pour utiliser par défaut le lien statique. C'est un plugin expérimental, à utiliser avec précaution.

PROPRIÉTÉS

path

Le chemin vers le fichier ".pc". S'il n'est pas fourni, tous les fichiers ".pc" dans le répertoire temporaire seront convertis.
