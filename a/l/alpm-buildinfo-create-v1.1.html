NOM

alpm-buildinfo-create-v1 - Créer un fichier BUILDINFO version 1

SYNOPSIS

alpm-buildinfo create v1 <--builddate> <--builddir> [--buildenv] [--installed] [--options] <--packager> <--pkgarch> <--pkgbase> <--pkgbuild-sha256sum> <--pkgname> <--pkgver> [-h|--help] [FICHIER]

DESCRIPTION

Créer un fichier BUILDINFO version 1

OPTIONS

--builddate <DATEBUILD>
Fournir une date de compilation
Peut également être spécifié avec la variable d'environnement BUILDINFO_BUILDDATE.
--builddir <REPERTOIREBUILD>
Fournir un répertoire de compilation
Peut également être spécifié avec la variable d'environnement BUILDINFO_BUILDDIR.
--buildenv <ENVBUILD>
Fournir un ou plusieurs environnements de compilation
Peut également être spécifié avec la variable d'environnement BUILDINFO_BUILDENV.
--installed <INSTALLE>
Fournir un ou plusieurs éléments installés
Peut également être spécifié avec la variable d'environnement BUILDINFO_INSTALLED.
--options <OPTIONS>
Fournir une ou plusieurs options
Peut également être spécifié avec la variable d'environnement BUILDINFO_OPTIONS.
--packager <PACKAGEUR>
Fournir un packageur
Peut également être spécifié avec la variable d'environnement BUILDINFO_PACKAGER.
--pkgarch <PKGARCH>
Fournir une architecture de paquet
Peut également être spécifié avec la variable d'environnement BUILDINFO_PKGARCH.
--pkgbase <PKGBASE>
Fournir une base de paquet
Peut également être spécifié avec la variable d'environnement BUILDINFO_PKGBASE.
--pkgbuild-sha256sum <SHA256SUMPKGBUILD>
Fournir un sha256sum de PKGBUILD
Peut également être spécifié avec la variable d'environnement BUILDINFO_PKGBUILD_SHA256SUM.
--pkgname <PKGNAME>
Fournir un nom de paquet
Peut également être spécifié avec la variable d'environnement BUILDINFO_PKGNAME.
--pkgver <PKGVER>
Fournir une version de paquet
Peut également être spécifié avec la variable d'environnement BUILDINFO_PKGVER.
-h, --help
Afficher l'aide
[FICHIER] [défaut: .BUILDINFO]
Fournir un fichier dans lequel écrire
Peut également être spécifié avec la variable d'environnement BUILDINFO_OUTPUT_FILE.
