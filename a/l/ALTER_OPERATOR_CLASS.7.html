ALTER_OPERATOR_CLASS(7)

Paquet: postgresql

ALTER OPERATOR CLASS(7) Documentation PostgreSQL 18.1 ALTER OPERATOR CLASS(7)

NOM

ALTER_OPERATOR_CLASS - modifier la définition d'une classe d'opérateurs

SYNTAXE

ALTER OPERATOR CLASS nom USING methode_index
    RENAME TO nouveau_nom
ALTER OPERATOR CLASS nom USING methode_index
    OWNER TO { nouvel_proprietaire | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER OPERATOR CLASS nom USING methode_index
    SET SCHEMA nouveau_schema

DESCRIPTION

ALTER OPERATOR CLASS modifie la définition d'une classe d'opérateurs.

Vous devez posséder la classe d'opérateurs pour utiliser ALTER OPERATOR CLASS. Pour modifier le propriétaire, vous devez pouvoir utiliser SET ROLE pour le nouveau rôle propriétaire, et ce rôle doit avoir le privilège CREATE sur le schéma de la classe d'opérateurs. (Ces restrictions garantissent que la modification du propriétaire n'entraîne rien que vous ne pourriez faire en supprimant et recréant la classe d'opérateurs. Cependant, un superutilisateur peut modifier la propriété de n'importe quelle classe d'opérateurs de toute façon.)

PARAMÈTRES

nom

Le nom (éventuellement qualifié par un schéma) d'une classe d'opérateurs existante.

methode_index

Le nom de la méthode d'index pour laquelle cette classe d'opérateurs est destinée.

nouveau_nom

Le nouveau nom de la classe d'opérateurs.

nouvel_proprietaire

Le nouveau propriétaire de la classe d'opérateurs.

nouveau_schema

Le nouveau schéma pour la classe d'opérateurs.

COMPATIBILITÉ

Il n'existe pas d'instruction ALTER OPERATOR CLASS dans la norme SQL.

VOIR AUSSI

CREATE OPERATOR CLASS (CREATE_OPERATOR_CLASS(7)), DROP OPERATOR CLASS (DROP_OPERATOR_CLASS(7)), ALTER OPERATOR FAMILY (ALTER_OPERATOR_FAMILY(7))
