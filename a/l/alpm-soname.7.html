Les chaînes représentant les informations soname peuvent être utilisées dans les alpm-package-relations de type provision et dépendance d'exécution pour permettre des configurations de dépendances de paquets strictes basées sur la compatibilité ABI. Le format alpm-soname existe en plusieurs versions. Les informations de ce document concernent la version 2, qui est la version actuelle, qui remplace alpm-sonamev1 et qui a été introduite avec la sortie de pacman 6.1.0 le 2024-03-04. FORMAT La représentation des informations soname a lieu exclusivement dans des formats de fichiers pouvant contenir des données dynamiques spécifiques à l'environnement de construction,

tels que

PKGINFO . Dans ces fichiers, les données soname sont référencées en utilisant le format suivant, composé de données dérivées de l'emplacement d'un fichier objet partagé ainsi que d'informations encodées en lui : une

chaîne

prefix , suivie directement d'un « : », suivie directement d'un son

(par exemple lib:libexample.so.1 ). Ici, la

prefix lib désigne le nom d'utilisation (défini arbitrairement au niveau de la distribution et utilisé par les outils de construction de

paquets tels que

makepkg ) pour un répertoire de recherche (par exemple /usr/lib ) dans lequel le fichier objet partagé est trouvé. Consultez LIB_DIRS dans makepkg.conf pour savoir comment fonctionnent les affectations de prefix dans makepkg .

Le soname représente les données trouvées dans la section dynamique d'un fichier objet partagé (voir readelf pour plus de détails). Selon que les données soname sont utilisées dans une alpm-package-relation de type provision ou de type dépendance d'exécution , cela fait référence respectivement au

champ

SONAME ou NEEDED dans la section dynamique . UTILISATION Un paquet peut dépendre d'un soname spécifique à l'aide d'une alpm-package-relation de type dépendance d'exécution , si un autre paquet fournit ce soname exact dans sa alpm-package-relation de type provision . Plus précisément, une dépendance soname d'un paquet est basée sur les données soname d'un fichier objet partagé fourni par l'un de ses paquets dépendants. Un outil de construction

de paquets

Si le paquet en cours de construction produit un fichier ELF [2] qui lie dynamiquement contre un objet partagé disponible dans l'environnement de construction, la valeur du champ NEEDED dans la section dynamique du fichier ELF [2] contre lequel la liaison est effectuée est extraite. Si un paquet contenant le fichier objet partagé qui encode les données soname est présent dans l'environnement de construction et que les données PKGINFO du paquet révèlent ce fait dans une alpm-package-relation de type provision (c'est-à-dire provides = lib:libexample.so.1 ), ces données sont utilisées.
