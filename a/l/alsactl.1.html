DESCRIPTIO

N

alsactl est utilisé pour contrôler les paramètres avancés des pilotes de carte son ALSA. Il prend en charge plusieurs cartes son. Si vot

re carte a des fonctionnalités que vous ne semblez pas pouvoir con
trôler depuis une application de mixage, vous êtes au bon endroit.

COMMANDE

S

Introductio

n

L'argument <carte> est facultatif. Si aucune carte son n'est spécifiée, la conf

iguration de toutes les cartes sera
enregistrée, chargée ou surveillée.

store

<carte>

Cette commande enregistre l'état actuel

du pilote pour la carte son sélecti
onnée dans le fichier de configuration.

restore

<carte>

Cette commande charge l'état du pilote pour la carte son sélectio

nnée à partir du fichier de configuration. Si la restauration
échoue (éventuellement en partie), l'action init est appelée.

nrestore

<carte>

Cette commande est comme restore, mais elle notifie également le démon pour qu'il

effectue une nouvelle recherc
he des cartes son disponibles.

init

<carte>

Cette commande essaie d'initialiser tous les périph

ériques à un état par défaut. Si le périphériqu
e n'est pas connu, le code d'erreur 99 est renvoyé.

daemo

n

Cette commande gère l'

enregistrement périod
ique de l'état du son.

rdaemo

n

Cette commande est comme daemon mais restaure l'é

tat du son a
u début.

kill

<cmd>

Cette commande notifie le démon po

ur effectuer l'opération spécifiée
(quit, rescan, save_and_quit).

monitor

<carte>

Cette commande sert à surveiller

les événements reçus depuis le
périphérique de contrôle donné.

info

<carte>

Cette commande affiche les informations géné

périphérique de contrôle donné (carte son).

clean <carte>

[filtre]

Cette commande nettoie les contrôles créés par les

applications.

Les identifiants d'éléments facultatifs sont acceptés comme filtre. Un argument supplémentaire est analysé comme identifiants

Exemple : alsactl clean 0 "name=

S

--lock
Utiliser le verrouillage de fichier pour sérialiser l'accès concurrent au fichier d'état (cette option est la valeur par défaut pour le fichier d'état global)

-L,
--no-lock
Ne pas utiliser le verrouillage de fichier pour sérialiser l'accès concurrent au fichier d'état (y compris le fichier d'état global)
.
-O,
--lock-state-file
Sélectionner le chemin du fichier de verrouillage
d'état.
-F,
--force
Utilisé avec la commande restore. Essayer de restaurer les éléments de contrôle correspondants autant que possible. Cette option est définie comme valeur par défaut
maintenant.
-g,
--ignore
Utilisé avec les commandes store, restore et init. Ne pas afficher 'No soundcards found' et ne pas définir un code de sortie d'erreur lorsque des cartes son ne sont pas
installées.
-P,
--pedantic
Utilisé avec la commande restore. Ne pas restaurer les éléments de contrôle non correspondants. Cette option était le comportement par défaut
ancien.
-I, --no-init-fallb
ack
Ne pas initialiser les cartes si la restauration échoue. Depuis la version 1.0.18, alsactl essaie d'initialiser la carte avec l'opération de restauration comme valeur par défaut. Mais cela peut causer une incompatibilité avec l'ancienne version. L'appelant peut s'attendre à ce que l'état ne soit pas touché si aucun fichier d'état n'existe. Cette option ramène le comportement de restauration à l'ancienne version en supprimant
l'initialisation.
-r,
--runstate
Enregistrer l'état de restauration et d'initialisation dans ce fichier. Le fichier ne contiendra que des erreurs. Les erreurs sont ajoutées avec l'id de la carte son à la fin du
fichier.
-R,
--remove
Supprimer le fichier runstate au
début.
-E, --env
#=#
Définir une variable d'environnement (utile pour l'action init ou vous pouvez surcharger ALSA_CONFIG_PATH pour lire une configuration différente ou optimisée - peut être utile pour les scripts de "boot")
.
-i,
--initfile
Le fichier de configuration pour init. Par défaut, PREFIX/share/alsa/init/00main est
utilisé.
-p,
--period
La période d'enregistrement en secondes pour la commande
daemon.
-e,
--pid-file
Le chemin pour enregistrer le fichier d'id de processus au format HDB UUCP (ASCII)
.
-b,
--background
Exécuter la tâche en
arrière-plan.
-s,
--syslog
Utiliser syslog pour les
messages.
-n,
--nice
Définir la priorité du processus (voir 'man
nice')
-c,
--sched-idle
Définir la politique d'ordonnancement du processus sur idle (SCHED_IDLE)

-D,
--ucm-defaults
Exécuter aussi la section 'defaults' de la configuration UCM. Le comportement standard est d'exécuter seulement la section

-U,
--no-ucm
Ignorer l'init UCM même s'il

FICHIER

S

/var/lib/alsa/asound.state (ou quel que soit le fichier que vous specify avec l'option -f) est utilisé pour stocker les paramètres actuels de vos cartes son. Les paramètres incluent tous les paramètres de mixage de carte son habituels. Plus important encore, alsactl est capable de contrôler d'autres fonctionnalités spécifiques à la carte que les applications de mixage ne connaissent généralement

pas.

Le fichier de configuration est généré automatiquement en exécutant alsactl store. Il peut être nécessaire d'éditer le fichier de configuration à la main pour certaines fonctionnalités de carte son (par ex. activer/désactiver le gain automatique du micro, la sortie numérique, les ports joystick/jeux, certaines options futures de routage MIDI,

etc)
.
