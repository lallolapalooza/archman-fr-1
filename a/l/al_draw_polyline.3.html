al_draw_polyline(3) Manuel des fonctions de bibliothèque al_draw_polyline(3)

NOM

al_draw_polyline - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_primitives.h>
void al_draw_polyline(const float* vertices, int vertex_stride,
   int vertex_count, int join_style, int cap_style,
   ALLEGRO_COLOR color, float thickness, float miter_limit)

DESCRIPTION

Dessine une série de segments de ligne.

•
vertices - Tableau entrelacé de coordonnées de sommets (x, y)
•
vertex_stride - le nombre d'octets entre les paires de sommets (le pas)
•
vertex_count - Nombre de sommets dans le tableau
•
join_style - Membre de ALLEGRO_LINE_JOIN(3) spécifiant comment rendre les jonctions entre les segments de ligne
•
cap_style - Membre de ALLEGRO_LINE_CAP(3) spécifiant comment rendre les extrémités
•
color - Couleur de la ligne
•
thickness - Épaisseur de la ligne, passer <= 0 pour dessiner des lignes fines
•
miter_limit - Paramètre pour le style de jonction en onglet

Le pas est normalement 2 * sizeof(float) mais peut être plus grand si les coordonnées des sommets sont dans un tableau d'un type de structure, par exemple.

struct VertexInfo {
   float x;
   float y;
   int id;
};
void my_draw(struct VertexInfo verts[], int vertex_count, ALLEGRO_COLOR c)
{
   al_draw_polyline((float *)verts, sizeof(VertexInfo), vertex_count,
      ALLEGRO_LINE_JOIN_NONE, ALLEGRO_LINE_CAP_NONE, c, 1.0, 1.0);
}

Le pas peut également être négatif si les sommets sont stockés dans l'ordre inverse.
