alive6(8) IPv6 alive6(8)

NOM

alive6

SYNTAXE

alive6 [-CFHLMPSdlpvV] [-I srcip6] [-i fichier] [-o fichier] [-e opt] [-s port,..] [-a port,..] [-u port,..] [-T tag] [-W TEMPS] interface [adresse-unicast-ou-multicast [routeur-distant]]

OPTIONS

  -i fichier    vérifier les systèmes à partir d'un fichier d'entrée
  -o fichier    écrire les résultats dans un fichier de sortie
  -d             résoudre les adresses IPv6 vivantes par DNS
  -M             énumérer les adresses matérielles (MAC) des adresses d'entrée (lent !)
  -C             énumérer les adresses communes des réseaux d'entrée, -CC pour un scan large
  -4 ipv4/plage  tester divers encodages d'adresses IPv4 par réseau (par ex. 1.2.3.4/24)
  -p             envoyer un paquet ping pour vérifier la vivacité (par défaut)
  -e dst,hop     envoyer des paquets erronés : destination (par défaut), hop-by-hop
  -s port,port,..  paquet TCP-SYN vers des ports pour vérifier la vivacité ou "portscan"
  -a port,port,..  paquet TCP-ACK vers des ports pour vérifier la vivacité
  -u port,port,..  paquet UDP vers des ports pour vérifier la vivacité
  -h             afficher plus d'options de ligne de commande et d'aide (-hh : plus d'options)
L'adresse cible sur la ligne de commande ou dans le fichier d'entrée peut inclure des plages sous la forme
de 2001:db8::1-fff ou 2001:db8::1-2:0-ffff:0-ffff, etc.
