al_lock_bitmap_blocked(3) Manuel des fonctions de bibliothèque al_lock_bitmap_blocked(3)

NOM

al_lock_bitmap_blocked - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
ALLEGRO_LOCKED_REGION *al_lock_bitmap_blocked(ALLEGRO_BITMAP *bitmap,
   int flags)

DESCRIPTION

Similaire à al_lock_bitmap(3), mais permet de verrouiller des bitmaps avec un format de pixel bloqué (c'est-à-dire un format pour lequel al_get_pixel_block_width(3) ou al_get_pixel_block_height(3) ne renvoient pas 1) dans ce format. À cette fin, cette fonction ne permet pas non plus de conversion de format. Pour les formats de bitmap avec une taille de bloc de 1, cette fonction est identique à l'appel de al_lock_bitmap(bmp, al_get_bitmap_format(bmp), flags).

Remarque : Actuellement, il n'existe aucune fonction de dessin qui fonctionne lorsque le bitmap est verrouillé avec un format compressé. al_get_pixel(3) ne fonctionnera pas non plus.

DEPUIS

5.1.9

VOIR AUSSI

al_lock_bitmap(3), al_lock_bitmap_region_blocked(3)
