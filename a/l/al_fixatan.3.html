al_fixatan(3) Manuel des fonctions de bibliothèque al_fixatan(3)

NOM

al_fixatan - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
al_fixed al_fixatan(al_fixed x)

DESCRIPTION

Cette fonction trouve l'arc tangente d'une valeur à l'aide d'une table de correspondance. L'entrée doit être une valeur à virgule fixe. L'arc tangente est la valeur dont la tangente est x.

Exemple :

al_fixed result;
/* Définit result sur un angle binaire de 13. */
result = al_fixatan(al_ftofix(0.326));

VALEUR DE RETOUR

Retourne l'arc tangente d'une valeur à virgule fixe, mesurée comme un angle au format binaire à virgule fixe.
