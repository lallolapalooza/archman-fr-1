NOM

epoch - préfixe de version pour garantir une considération de version plus élevée pour les paquets basés sur ALPM.

DESCRIPTION

Le format epoch est un format de version utilisé comme préfixe pour pkgver dans une chaîne de version composite. Ce format est utilisé dans les scripts de construction ou les formats de fichiers pour la description ou la reproduction des données de paquets afin d'indiquer qu'une version composite doit être considérée comme plus récente qu'une version sans ou avec un composant epoch inférieur. Cela permet aux mainteneurs de paquets de publier des versions déclassées d'un paquet si nécessaire.

La valeur epoch est représentée par un entier non négatif et est considérée comme étant ‘0’ par défaut si elle n'est pas définie.

Lorsqu'il est utilisé dans une chaîne de version composite, epoch est directement suivi d'un signe ‘:’ et du pkgver.

Si deux chaînes de version composites sont triées, elles sont d'abord triées en fonction de leur composant epoch et seulement ensuite en fonction de leur composant pkgver.

En règle générale, la priorité de tri est : epoch > pkgver.

EXEMPLES

Le composant epoch explicite 1 dans la chaîne de version composite de droite l'emporte sur le composant epoch implicite 0 de la chaîne de version composite de gauche. Comme l'epoch a la priorité, 1:0.9.0 est considéré comme “plus récent” que 1.0.0 même si la version amont représentée par le composant pkgver est plus ancienne.

"1.0.0" < "1:0.9.0"

Les chaînes de version composites avec le même composant pkgver sont également triées en fonction de leur composant epoch en premier.

"1:1.0.0" < "2:1.0.0"
