NOM

al_upload_and_play_haptic_effect - API Allegro 5

SYNOPHIS

#include <allegro5/allegro.h>
bool al_upload_and_play_haptic_effect(ALLEGRO_HAPTIC *hap,
   ALLEGRO_HAPTIC_EFFECT *effect, ALLEGRO_HAPTIC_EFFECT_ID *id, int loop)

DESCRIPTION

Téléverse l'effet haptique sur le périphérique et démarre immédiatement sa lecture. Renvoie vrai si le téléversement et la lecture ont réussi, faux si l'un d'eux a échoué.

En cas de retour faux, l'effet haptique sera automatiquement libéré comme si al_release_haptic_effect(3) avait été appelé, il n'est donc pas nécessaire de le rappeler manuellement dans ce cas. Cependant, si vrai est renvoyé, il est nécessaire d'appeler al_release_haptic_effect(3) lorsque l'effet n'est plus nécessaire, afin d'éviter que la quantité d'effets disponibles sur le périphérique haptique ne s'épuise.

DEPUIS

5.1.8

[API instable] : Pourrait peut-être être simplifiée en raison du support limité de toutes les fonctionnalités exposées sur toutes les plateformes. En attente de retours d'utilisateurs.
