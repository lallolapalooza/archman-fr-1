NOM

Alien::Build::Plugin::Download::GitLab - Plugin Alien::Build pour télécharger depuis GitLab

VERSION

version 0.01

SYNOPSIS

use alienfile;

plugin 'Download::GitLab' => (
  gitlab_user    => 'plicease',
  gitlab_project => 'dontpanic',
);

DESCRIPTION

Ce plugin est conçu pour télécharger des actifs depuis une instance GitLab.

PROPRIÉTÉS

gitlab_host

L'hôte à partir duquel télécharger, avec https://gitlab.com par défaut.

gitlab_user

L'utilisateur à partir duquel télécharger.

gitlab_project

Le projet à partir duquel télécharger.

type

Le type d'actif à télécharger. Doit être soit "source" soit "link".

format

Le format attendu de l'actif. Doit être un format que Alien::Build::Plugin::Extract::Negotiate comprend. Par défaut, "tar.gz".

version_from

D'où extraire la version. Doit être soit "tag_name" soit "name". Par défaut, "tag_name".

convert_version

Ceci est une référence de code optionnelle, utilisable pour modifier la version. Par exemple, si les tags ont un préfixe "v", vous pouvez le supprimer comme ceci :

plugin 'Download::GitLab' => (
  gitlab_user     => 'plicease',
  gitlab_project  => 'dontpanic',
  convert_version => sub {
    my $version = shift;
    $version =~ s/^v//;
    return $version;
  },
);

link_name

Pour les types "link", ceci est une expression régulière qui filtre les noms de fichiers des actifs. Par exemple, s'il existe plusieurs formats d'archive, vous pouvez obtenir uniquement le tarball gzippé en définissant ceci à "qr/\.tar\.gz$/".
