Paquet: perl-alien-build

Licences: PerlArtistic

Alien::Build::Plugin::Test(3) Documentation Perl contribuée par l'utilisateur Alien::Build::Plugin::Test(3)

NOM

Alien::Build::Plugin::Test - Sonde les plugins Alien::Build

VERSION

version 2.84

SYNOPIS

use alienfile;
plugin 'Test::Mock' => (
  probe    => 'share',
  download => 1,
  extract  => 1,
  build    => 1,
  gather   => 1,
);

DESCRIPTION

Les plugins de test sont utilisés dans les tests unitaires pour Alien::Build et potentiellement ses plugins.

Alien::Build::Plugin::Test::Mock
Simule les étapes courantes d'un fichier alien.

VOIR AUSSI

Alien::Build, Alien::Build::Plugin
