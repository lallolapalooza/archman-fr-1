alpm-split-package(7)

Paquet: alpm-docs

Licences: CC-BY-SA-4.0

(7) Informations diverses (7)

NOM

split package - un paquet basé sur ALPM qui est construit avec d'autres paquets à partir des mêmes sources.

DESCRIPTION

Les paquets divisés (split packages) font référence à deux paquets ou plus basés sur ALPM qui sont construits à partir des mêmes sources. Ces types de paquets peuvent être créés pour des raisons arbitraires, par exemple :

  • séparer différentes fonctionnalités (par exemple, un paquet fournissant l'interface utilisateur graphique et un autre l'interface utilisateur en ligne de commande d'un projet)
  • isoler une documentation spécifique (par exemple, la documentation développeur n'est pas utile pour tous les utilisateurs)
  • diverses fonctionnalités d'un projet sont optionnelles, sont par exemple fournies sous forme de plugins et peuvent être activées en installant des paquets divisés supplémentaires

Les paquets divisés construits à partir des mêmes sources partagent certaines métadonnées du paquet PKGINFO (c'est-à-dire pkgbase, pkgver, makedepends), tandis que d'autres métadonnées peuvent être définies spécifiquement pour chaque paquet divisé individuel.

Tous les fichiers PKGINFOv2 pour les paquets divisés définissent une valeur xdata de pkgtype=split, indiquant que les métadonnées décrivent un paquet divisé.

Les paquets divisés sont gérés comme tout autre paquet basé sur ALPM par un gestionnaire de paquets et nécessitent leurs diverses relations de paquet lors de l'installation.

EXEMPLES

L'exemple PKGBUILD suivant définit deux paquets divisés, qui partagent example-split comme pkgbase (virtuel - sans aucun paquet réel de ce nom) :

pkgbase=example-split
pkgname=(example-a example-b)
pkgver=0.1.0
pkgrel=1
pkgdesc="Un exemple de paquet divisé"
arch=(any)
url="https://archlinux.org"
license=(GPL-3.0-or-later)
makedepends=(
  meson
)
depends=(
  bash
  gcc-libs
)
package_example-a(){
  pkgdesc+=" - A"
  license+=(LGPL-2.1-or-later)
  depends+=(bash-completions)
}
package_example-b(){
  pkgdesc+=" - B"
  depends=(zsh)
}
