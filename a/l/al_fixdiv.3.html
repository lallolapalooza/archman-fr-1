al_fixdiv(3) Manuel des fonctions de bibliothèque al_fixdiv(3)

NOM

al_fixdiv - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
al_fixed al_fixdiv(al_fixed x, al_fixed y);

DESCRIPTION

Une valeur en point fixe peut être divisée par un entier avec l'opérateur normal /. Cependant, pour diviser deux valeurs en point fixe, vous devez utiliser cette fonction. Si une division par zéro se produit, errno d'Allegro sera défini et la valeur maximale possible sera retournée, mais errno n'est pas effacé si l'opération réussit. Cela signifie que si vous allez tester une division par zéro, vous devriez appeler al_set_errno(0) avant d'appeler al_fixdiv(3).

Exemple :

al_fixed result;
/* Ceci mettra 0.06060 dans `result'. */
result = al_fixdiv(al_itofix(2), al_itofix(33));
/* Ceci mettra 0 dans `result'. */
result = al_fixdiv(0, al_itofix(-30));
/* Définit errno et met -32768 dans `result'. */
result = al_fixdiv(al_itofix(-100), al_itofix(0));
assert(!al_get_errno()); /* Ceci échouera. */

VALEUR DE RETOUR

Retourne le résultat de la division de x par y. Si y est zéro, retourne la valeur fixe maximale possible et définit errno d'Allegro sur ERANGE.

VOIR AUSSI

al_fixadd(3), al_fixsub(3), al_fixmul(3), al_get_errno(3).
