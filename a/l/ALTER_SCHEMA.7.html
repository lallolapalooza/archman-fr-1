ALTER_SCHEMA(7)

Paquet: postgresql

Licences: PostgreSQL

ALTER SCHEMA(7) Documentation PostgreSQL 18.1 ALTER SCHEMA(7)

NOM

ALTER SCHEMA - modifier la définition d'un schéma

SYNTAXE

ALTER SCHEMA nom RENAME TO nouveau_nom
ALTER SCHEMA nom OWNER TO { nouveau_propriétaire | CURRENT_ROLE | CURRENT_USER | SESSION_USER }

DESCRIPTION

ALTER SCHEMA modifie la définition d'un schéma.

Vous devez posséder le schéma pour utiliser ALTER SCHEMA. Pour renommer un schéma, vous devez également avoir le privilège CREATE dans la base de données. Pour modifier le propriétaire, vous devez pouvoir SET ROLE pour le nouveau rôle propriétaire, et ce rôle doit avoir le privilège CREATE pour la base de données. (Notez que les superutilisateurs possèdent tous ces privilèges automatiquement.)

PARAMETRES

nom

Le nom d'un schéma existant.

nouveau_nom

Le nouveau nom du schéma. Le nouveau nom ne peut pas commencer par pg_, car de tels noms sont réservés aux schémas système.

nouveau_propriétaire

Le nouveau propriétaire du schéma.

COMPATIBILITE

Il n'existe pas d'instruction ALTER SCHEMA dans la norme SQL.

VOIR AUSSI

CREATE SCHEMA (CREATE_SCHEMA(7)), DROP SCHEMA (DROP_SCHEMA(7))
