NOM

al_draw_indexed_buffer - API Allegro 5

SYNTAXE

#include <allegro5/allegro_primitives.h>
int al_draw_indexed_buffer(ALLEGRO_VERTEX_BUFFER* vertex_buffer,
   ALLEGRO_BITMAP* texture, ALLEGRO_INDEX_BUFFER* index_buffer,
   int start, int end, int type)

DESCRIPTION

Dessine un sous-ensemble du tampon de sommets fourni. Cette fonction utilise un tampon d'indices pour spécifier quels sommets utiliser. Les deux tampons ne doivent pas être verrouillés. De plus, pour dessiner sur des images mémoire ou avec des textures d'images mémoire, les deux tampons doivent supporter la lecture (c'est-à-dire qu'ils doivent être créés avec ALLEGRO_PRIM_BUFFER_READWRITE).

Paramètres :

•
vertex_buffer - Tampon de sommets à dessiner
•
texture - Texture à utiliser, passer NULL pour n'utiliser que des primitives colorées
•
index_buffer - Tampon d'indices à utiliser
•
start - Indice de départ du sous-ensemble du tampon d'indices à dessiner
•
end - Un indice après le dernier indice du sous-ensemble du tampon d'indices à dessiner
•
type - Un membre de l'énumération ALLEGRO_PRIM_TYPE(3), spécifiant quel type de primitive dessiner. Notez que ALLEGRO_PRIM_LINE_LOOP et ALLEGRO_PRIM_POINT_LIST ne sont pas supportés.

Retourne : Nombre de primitives dessinées
