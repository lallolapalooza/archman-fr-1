NOM

al_grab_font_from_bitmap - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_font.h>
ALLEGRO_FONT *al_grab_font_from_bitmap(ALLEGRO_BITMAP *bmp,
   int ranges_n, const int ranges[])

DESCRIPTION

Crée une nouvelle police à partir d'une image Allegro. Vous pouvez supprimer l'image après le retour de la fonction car la police en contiendra une copie pour elle-même.

Paramètres :

•
bmp : l'image avec les glyphes dessinés dessus
•
n : le nombre de plages Unicode dans l'image.
•
ranges : `n' paires de points unicode de début et de fin pour mapper les glyphes pour chaque plage.

Le format de l'image est comme dans l'exemple suivant, qui contient trois glyphes pour 1, 2 et 3.

.............
. 1 .222.333.
. 1 .  2.  3.
. 1 .222.333.
. 1 .2  .  3.
. 1 .222.333.
.............

Dans l'illustration ci-dessus, le point représente les pixels ayant la couleur d'arrière-plan. Elle est déterminée par la couleur du pixel en haut à gauche de l'image. Il devrait y avoir une bordure d'au moins 1 pixel de cette couleur jusqu'au bord de l'image et entre tous les glyphes.

Chaque glyphe se trouve à l'intérieur d'un rectangle de pixels ne contenant pas la couleur d'arrière-plan. La hauteur de tous les rectangles de glyphes doit être identique, mais la largeur peut varier.

L'emplacement des rectangles n'a pas d'importance, si ce n'est que les glyphes sont balayés de gauche à droite et de haut en bas pour les faire correspondre aux points de code unicode spécifiés.

Les glyphes seront simplement dessinés à l'aide de al_draw_bitmap(3), vous voudrez donc généralement que les rectangles soient remplis de transparence totale et que les glyphes soient dessinés en blanc opaque.

Exemples :

int ranges[] = {32, 126};
al_grab_font_from_bitmap(bitmap, 1, ranges)
int ranges[] = {
    0x0020, 0x007F,  /* ASCII */
    0x00A1, 0x00FF,  /* Latin 1 */
    0x0100, 0x017F,  /* Étendu-A */
    0x20AC, 0x20AC}; /* Euro */
al_grab_font_from_bitmap(bitmap, 4, ranges)

Le premier exemple récupérera les glyphes pour les 95 caractères ASCII imprimables standard, en commençant par le caractère espace (32) et en terminant par le caractère tilde (126). Le second exemple mappera les 96 premiers glyphes trouvés dans l'image à la plage ASCII, les 95 glyphes suivants à Latin 1, les 128 glyphes suivants à Étendu-A, et le dernier glyphe au caractère Euro. (Ce sont juste les caractères trouvés dans la police Allegro 4.)
