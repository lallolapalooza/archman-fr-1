al_play_sample(3) Manuel des fonctions de bibliothèque al_play_sample(3)

NOM

al_play_sample - API Allegro 5

SYNTAXE

#include <allegro5/allegro_audio.h>
bool al_play_sample(ALLEGRO_SAMPLE *spl, float gain, float pan, float speed,
   ALLEGRO_PLAYMODE loop, ALLEGRO_SAMPLE_ID *ret_id)

DESCRIPTION

Joue un échantillon sur une des instances d'échantillon créées par al_reserve_samples(3). Retourne vrai en cas de succès, faux en cas d'échec. La lecture peut échouer car toutes les instances d'échantillons réservées sont actuellement utilisées.

Paramètres :

•
gain - volume relatif auquel l'échantillon est joué ; 1.0 est la normale.
•
pan - 0.0 est centré, -1.0 est à gauche, 1.0 est à droite, ou ALLEGRO_AUDIO_PAN_NONE.
•
speed - vitesse relative à laquelle l'échantillon est joué ; 1.0 est la normale.
•
loop - ALLEGRO_PLAYMODE_ONCE, ALLEGRO_PLAYMODE_LOOP, ou ALLEGRO_PLAYMODE_BIDIR
•
ret_id - si non NULL, la variable vers laquelle pointe ceci sera assignée à un identifiant représentant l'échantillon en cours de lecture. Si al_play_sample(3) retourne faux, alors le contenu de ret_id est invalide et ne doit pas être utilisé comme argument pour d'autres fonctions.
