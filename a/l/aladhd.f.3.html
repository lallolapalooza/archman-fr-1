Documentation de la fonction/sous-programme

sous-programme aladhd (integer iounit, character*3 path)

ALADHD

Objectif :

!>
!> ALADHD imprime les informations d'en-tête pour les chemins de test des routines de pilote.
!>

Paramètres

IOUNIT 
!>          IOUNIT est un ENTIER
!>          Le numéro d'unité auquel les informations d'en-tête doivent être
!>          imprimées.
!>

PATH

!>          PATH est un CARACTERE*3
!>          Le nom du chemin pour lequel les informations d'en-tête doivent être
!>          imprimées. Les chemins actuels sont
!>             _GE: matrices générales
!>             _GB: bande générale
!>             _GT: tridiagonale générale
!>             _PO: définie positive symétrique ou hermitienne
!>             _PS: semi-définie positive symétrique ou hermitienne
!>             _PP: définie positive symétrique ou hermitienne compactée
!>             _PB: bande définie positive symétrique ou hermitienne
!>             _PT: tridiagonale définie positive symétrique ou hermitienne
!>             _SY: symétrique indéfinie,
!>                     avec pivotement partiel (Bunch-Kaufman)
!>             _SR: symétrique indéfinie,
!>                     avec pivotement rook (Bunch-Kaufman borné)
!>             _SK: symétrique indéfinie,
!>                     avec pivotement rook (Bunch-Kaufman borné)
!>                     ( nouveau format de stockage pour les facteurs :
!>                       L et la diagonale de D sont stockées dans A,
!>                       la sous-diagonale de D est stockée dans E )
!>             _SP: symétrique indéfinie compactée,
!>                     avec pivotement partiel (Bunch-Kaufman)
!>             _HA: (complexe) hermitienne ,
!>                     Algorithme d'Assen
!>             _HE: (complexe) hermitienne indéfinie,
!>                     avec pivotement partiel (Bunch-Kaufman)
!>             _HR: (complexe) hermitienne indéfinie,
!>                     avec pivotement rook (Bunch-Kaufman borné)
!>             _HK: (complexe) hermitienne indéfinie,
!>                     avec pivotement rook (Bunch-Kaufman borné)
!>                     ( nouveau format de stockage pour les facteurs :
!>                       L et la diagonale de D sont stockées dans A,
!>                       la sous-diagonale de D est stockée dans E )
!>             _HP: (complexe) hermitienne indéfinie compactée,
!>                     avec pivotement partiel (Bunch-Kaufman)
!>          Le premier caractère doit être S, D, C ou Z (C ou Z uniquement
!>          si complexe).
!>
