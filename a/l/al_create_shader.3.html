al_create_shader(3) Manuel des fonctions de bibliothèque al_create_shader(3)

NOM

al_create_shader - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
ALLEGRO_SHADER *al_create_shader(ALLEGRO_SHADER_PLATFORM platform)

DESCRIPTION

Crée un objet shader.

L'argument platform est l'une des valeurs de ALLEGRO_SHADER_PLATFORM(3) et spécifie le type d'objet shader à créer, ainsi que le langage utilisé pour programmer le shader.

La plateforme de shader doit être compatible avec le type d'affichage que vous utiliserez avec le shader. Par exemple, vous ne pouvez pas créer et utiliser un shader HLSL sur un affichage OpenGL, ni un shader GLSL sur un affichage Direct3D.

La valeur ALLEGRO_SHADER_AUTO choisit automatiquement la plateforme appropriée pour l'affichage actuellement ciblé par le thread appelant ; il doit y avoir un tel affichage. Elle créera un shader GLSL pour un affichage OpenGL, et un shader HLSL pour un affichage Direct3D.

Retourne l'objet shader en cas de succès. Sinon, retourne NULL.
