Paquet: alpm-docs

Licences: CC-BY-SA-4.0

(5) Formats de fichiers (5)

NOM

alpm-install-scriptlet – un script d'installation personnalisé pour les paquets basés sur ALPM.

DESCRIPTION

Un script shell optionnel qui définit des actions personnalisées à effectuer lors de l'installation, de la mise à niveau ou de la suppression d'un paquet.

Les fonctions shell sont exécutées dans la racine (/) du système, donc tous les chemins à l'intérieur doivent être absolus.

Ces fichiers sont situés à la racine des paquets ALPM et sont nommés .INSTALL.

Format général

Un alpm-install-scriptlet peut contenir zéro ou plusieurs fonctions shell spécifiques qui définissent les actions pour différents événements du cycle de vie du paquet. Toutes les fonctions sont facultatives et seules celles nécessaires pour un paquet donné peuvent être incluses.

Le script peut être écrit dans un langage shell qui prend en charge l'option de ligne de commande -c et l'appel de fonctions nommées avec des arguments supplémentaires à partir de l'interface de ligne de commande de l'interpréteur.

Notez que l'interpréteur shell utilisé par le logiciel de gestion des paquets pour exécuter le script est défini globalement (par exemple, par distribution). Aucun shebang n'est utilisé dans le script et la décision sur le shell à utiliser pour l'exécuter n'est pas basée sur les métadonnées d'un paquet, mais est généralement définie au niveau de la distribution ou du système. Cela implique que l'interpréteur shell ne peut pas être modifié par paquet.

Fonctions

Les fonctions disponibles sont listées ci-dessous. Elles acceptent un ou deux arguments qui sont des versions de paquet, fournies sous forme de alpm-package-version.

pre_install

Exécutée avant l'installation d'un paquet, avec la nouvelle version du paquet comme argument.

post_install

Exécutée après l'installation d'un paquet, avec la nouvelle version du paquet comme argument.

pre_upgrade

Exécutée avant la mise à niveau d'un paquet, avec les arguments suivants :

1.
Nouvelle version du paquet
2.
Ancienne version du paquet
post_upgrade

Exécutée après la mise à niveau d'un paquet, avec les arguments suivants :

1.
Nouvelle version du paquet
2.
Ancienne version du paquet
pre_remove

Exécutée avant la suppression d'un paquet, avec l'ancienne version du paquet comme argument.

post_remove

Exécutée après la suppression d'un paquet, avec l'ancienne version du paquet comme argument.

EXEMPLES

Exemple de spécification d'un script d'installation dans le fichier PKGBUILD :

install=example.install

Exemple d'un script example.install de base :

pre_install() {
    echo "Préparation de l'installation du paquet version $1"
}
post_install() {
    echo "Paquet version $1 installé"
}
pre_upgrade() {
    echo "Préparation de la mise à niveau de la version $2 à la version $1"
}
post_upgrade() {
    echo "Mise à niveau de la version $2 à la version $1"
}
pre_remove() {
    echo "Préparation de la suppression du paquet version $1"
}
post_remove() {
    echo "Paquet version $1 supprimé"
}
