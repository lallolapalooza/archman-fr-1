NOM

alpm-db-desc - Outil en ligne de commande pour gérer les fichiers alpm-db-desc

SYNTAXE

alpm-db-desc [-h|--help] [-V|--version] <sous-commandes>

DESCRIPTION

Outil en ligne de commande pour gérer les fichiers alpm-db-desc

OPTIONS

-h, --help
Afficher l'aide
-V, --version
Afficher la version

SOUS-COMMANDES

alpm-db-desc-create(1)
Créer un fichier DB desc selon un schéma
alpm-db-desc-validate(1)
Valider un fichier DB desc selon un schéma
alpm-db-desc-format(1)
Analyser et afficher un fichier DB desc dans un format différent
alpm-db-desc-help(1)
Afficher ce message ou l'aide des sous-commandes données

v0.1.0
