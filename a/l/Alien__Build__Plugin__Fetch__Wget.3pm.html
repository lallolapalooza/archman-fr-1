NOM

Alien::Build::Plugin::Fetch::Wget - Plugin pour récupérer des fichiers en utilisant wget

VERSION

version 2.84

SYNTAXE

use alienfile;

share {
  start_url 'https://www.openssl.org/source/';
  plugin 'Fetch::Wget';
};

DESCRIPTION

AVERTISSEMENT : Ce plugin est quelque peu expérimental pour le moment.

Ce plugin fournit une fonction de récupération basée sur la commande "wget". Il fonctionne avec d'autres plugins de récupération (c'est-à-dire que le premier qui réussit sera utilisé). La plupart du temps, le meilleur plugin à utiliser sera Alien::Build::Plugin::Download::Negotiate, mais pour certains amorçages SSL, il peut être souhaitable d'essayer d'abord "wget".

Protocoles supportés : "http", "https"

PROPRIÉTÉS

commande_wget

Le chemin complet vers la commande "wget". La valeur par défaut est généralement correcte.

ssl

Ignoré par ce plugin. Fourni pour la compatibilité avec certains autres plugins de récupération.
