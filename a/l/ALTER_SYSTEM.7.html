NOM

ALTER SYSTEM - modifier un paramètre de configuration du serveur

SYNTAXE

ALTER SYSTEM SET paramètre_de_configuration { TO | = } { valeur [, ...] | DEFAULT }
ALTER SYSTEM RESET paramètre_de_configuration
ALTER SYSTEM RESET ALL

DESCRIPTION

ALTER SYSTEM est utilisé pour modifier les paramètres de configuration du serveur pour l'ensemble du cluster de bases de données. Il peut être plus pratique que la méthode traditionnelle d'édition manuelle du fichier postgresql.conf. ALTER SYSTEM écrit le réglage du paramètre donné dans le fichier postgresql.auto.conf, qui est lu en plus de postgresql.conf. Définir un paramètre sur DEFAULT, ou utiliser la variante RESET, supprime cette entrée de configuration du fichier postgresql.auto.conf. Utilisez RESET ALL pour supprimer toutes ces entrées de configuration.

Les valeurs définies avec ALTER SYSTEM seront effectives après le prochain rechargement de la configuration du serveur, ou après le prochain redémarrage du serveur dans le cas de paramètres qui ne peuvent être modifiés qu'au démarrage du serveur. Un rechargement de la configuration du serveur peut être commandé en appelant la fonction SQL pg_reload_conf(), en exécutant pg_ctl reload, ou en envoyant un signal SIGHUP au processus serveur principal.

Seuls les superutilisateurs et les utilisateurs ayant le privilège ALTER SYSTEM sur un paramètre peuvent le modifier à l'aide de ALTER SYSTEM. De plus, comme cette commande agit directement sur le système de fichiers et ne peut pas être annulée, elle n'est pas autorisée à l'intérieur d'un bloc de transaction ou d'une fonction.

PARAMETRES

paramètre_de_configuration

Nom d'un paramètre de configuration modifiable. Les paramètres disponibles sont documentés au chapitre 19.

valeur

Nouvelle valeur du paramètre. Les valeurs peuvent être spécifiées comme des constantes de chaîne, des identificateurs, des nombres ou des listes séparées par des virgules de ceux-ci, selon ce qui convient au paramètre particulier. Les valeurs qui ne sont ni des nombres ni des identificateurs valides doivent être mises entre guillemets. DEFAULT peut être écrit pour spécifier la suppression du paramètre et de sa valeur de postgresql.auto.conf.

Pour certains paramètres acceptant des listes, les valeurs entre guillemets produiront une sortie entre guillemets doubles pour préserver les espaces et les virgules ; pour d'autres, des guillemets doubles doivent être utilisés à l'intérieur de chaînes entre guillemets simples pour obtenir cet effet.

NOTES

Cette commande ne peut pas être utilisée pour définir data_directory, allow_alter_system, ni les paramètres qui ne sont pas autorisés dans postgresql.conf (par exemple, les options prédéfinies).

Voir la section 19.1 pour d'autres façons de définir les paramètres.

ALTER SYSTEM peut être désactivé en réglant allow_alter_system sur off, mais ce n'est pas un mécanisme de sécurité (comme expliqué en détail dans la documentation de ce paramètre).

EXEMPLES

Définir le wal_level :

ALTER SYSTEM SET wal_level = replica;

Annuler cela, en restaurant le réglage qui était effectif dans postgresql.conf :

ALTER SYSTEM RESET wal_level;

COMPATIBILITÉ

L'instruction ALTER SYSTEM est une extension de PostgreSQL.
