NOM

allneeded - force le calcul de toutes les polices nécessaires

SYNTAXE

allneeded [-r] fichiers ...

DESCRIPTION

allneeded force le calcul de toutes les polices nécessaires pour prévisualiser un ensemble de fichiers dvi. Spécifiez simplement où le programme doit rechercher les fichiers en ligne de commande. La génération des polices est déclenchée en exécutant dvips(1) sur tous les fichiers dvi accessibles. Par conséquent, les polices sont créées dans la résolution requise par dvips.

Si l'indicateur -r est spécifié, la commande dvired(1) sera utilisée à la place de dvips.

allneeded ne recalcule pas les polices existantes (tant que le mode Metafont ne change pas).

VOIR AUSSI

allec(1), allcm(1), dvips(1), dvired(1).
