alpm-soname-get-provisions(1) Manuel des commandes générales alpm-soname-get-provisions(1)

NOM

alpm-soname get-provisions - Obtenir les provisions

SYNTAXE

alpm-soname get-provisions [-l|--lookup-dir] [-v|--verbose]... [-o|--output-format] [-q|--quiet]... [-p|--pretty] [-h|--help] [-V|--version] <PAQUET>

DESCRIPTION

Obtenir les provisions

OPTIONS

-l, --lookup-dir <REPERTOIRE_RECHERCHE> [par défaut : lib:/usr/lib]
Le répertoire de recherche pour les bibliothèques partagées au format `<préfixe>:<répertoire>
-v, --verbose
Augmenter la verbosité de la journalisation
-o, --output-format <FORMAT_SORTIE> [par défaut : plain]
Le format de sortie

Valeurs possibles :

  • plain : Le format de sortie texte brut (ligne par ligne)
  • json : Le format de sortie JSON
-q, --quiet
Diminuer la verbosité de la journalisation
-p, --pretty
Afficher la sortie de manière lisible

N'a aucun effet si le format de sortie ne peut pas être affiché de manière lisible.

-h, --help
Afficher l'aide (voir un résumé avec « -h »)
-V, --version
Afficher la version
<PAQUET>
Le paquet à inspecter

VERSION

v0.3.0
