NOM

alpm-srcinfo-format-packages - Formate les paquets d'un fichier SRCINFO à partir d'un chemin ou de `stdin`

SYNTAXE

alpm-srcinfo format-packages [-s|--schema] <-a|--architecture> [-o|--output-format] [-p|--pretty] [-h|--help] [FICHIER]

DESCRIPTION

Formate les paquets d'un fichier SRCINFO à partir d'un chemin ou de `stdin`

Lit, valide et affiche tous les paquets du SRCINFO dans leur représentation finale pour une architecture spécifique. Si le fichier est valide, le programme affiche les données dans le format de fichier demandé sur la sortie standard et retourne avec un statut de sortie de 0.

OPTIONS

-s, --schema <VERSION>
Fournit la version du schéma SRCINFO à utiliser.

Si aucune version de schéma n'est fournie, elle sera déduite du fichier lui-même.

-a, --architecture <ARCHITECTURE>
L'architecture sélectionnée qui doit être utilisée pour interpréter le fichier SRCINFO.

Seuls les paquets [divisés] applicables à cette architecture seront retournés.

-o, --output-format <FORMAT_SORTIE> [défaut : json]
Fournit le format de sortie

Valeurs possibles :

•
json : Le format de sortie JSON
-p, --pretty
Affiche la sortie de manière joliment formatée.

Ne s'applique qu'aux formats qui prennent en charge la sortie jolie et est autrement ignoré.

-h, --help
Affiche l'aide (voir un résumé avec '-h')
[FICHIER]
Un chemin de fichier d'entrée optionnel à lire

Si aucun fichier n'est spécifié, stdin est lu et on s'attend à ce qu'il contienne des données PKGINFO à valider.
