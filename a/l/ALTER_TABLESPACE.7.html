ALTER TABLESPACE(7) Documentation PostgreSQL 18.1 ALTER TABLESPACE(7)

NOM

ALTER TABLESPACE - modifier la définition d'un tablespace

SYNOPSIS

ALTER TABLESPACE name RENAME TO new_name
ALTER TABLESPACE name OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER TABLESPACE name SET ( tablespace_option = value [, ... ] )
ALTER TABLESPACE name RESET ( tablespace_option [, ... ] )

DESCRIPTION

ALTER TABLESPACE peut être utilisé pour modifier la définition d'un tablespace.

Vous devez être propriétaire du tablespace pour modifier sa définition. Pour modifier le propriétaire, vous devez également pouvoir utiliser SET ROLE pour le nouveau rôle propriétaire. (Notez que les superutilisateurs disposent de ces privilèges automatiquement.)

PARAMÈTRES

name

Le nom d'un tablespace existant.

new_name

Le nouveau nom du tablespace. Le nouveau nom ne peut pas commencer par pg_, car ces noms sont réservés aux tablespaces système.

new_owner

Le nouveau propriétaire du tablespace.

tablespace_option

Un paramètre de tablespace à définir ou à réinitialiser. Actuellement, les seuls paramètres disponibles sont seq_page_cost, random_page_cost, effective_io_concurrency et maintenance_io_concurrency. La définition de ces valeurs pour un tablespace particulier remplacera l'estimation habituelle du planificateur du coût de lecture des pages à partir des tables de ce tablespace, et le nombre d'E/S concurrente émises, tels qu'établis par les paramètres de configuration du même nom (voir seq_page_cost, random_page_cost, effective_io_concurrency, maintenance_io_concurrency). Cela peut être utile si un tablespace est situé sur un disque plus rapide ou plus lent que le reste du sous-système d'E/S.

EXEMPLES

Renommer le tablespace index_space en fast_raid :

ALTER TABLESPACE index_space RENAME TO fast_raid;

Modifier le propriétaire du tablespace index_space :

ALTER TABLESPACE index_space OWNER TO mary;

COMPATIBILITÉ

Il n'existe pas d'instruction ALTER TABLESPACE dans la norme SQL.

VOIR AUSSI

CREATE TABLESPACE (CREATE_TABLESPACE(7)), DROP TABLESPACE (DROP_TABLESPACE(7))
