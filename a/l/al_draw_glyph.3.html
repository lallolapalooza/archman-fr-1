al_draw_glyph(3) Manuel des fonctions de bibliothèque al_draw_glyph(3)

NOM

al_draw_glyph - API Allegro 5

SYNTAXE

#include <allegro5/allegro_font.h>
void al_draw_glyph(const ALLEGRO_FONT *f, ALLEGRO_COLOR color, float x, float y,
   int codepoint)

DESCRIPTION

Dessine le glyphe correspondant au codepoint dans la couleur donnée, en utilisant la police donnée. Si la police ne possède pas ce glyphe, rien ne sera dessiné.

Pour dessiner une chaîne de caractères de gauche à droite en texte horizontal, vous devrez utiliser al_get_glyph_advance(3) pour déterminer la position de chaque glyphe. Pour dessiner des chaînes dans d'autres directions, comme de haut en bas, utilisez al_get_glyph_dimensions(3) pour déterminer la taille et la position de chaque glyphe.

Si vous devez dessiner de nombreux glyphes en même temps, utilisez al_hold_bitmap_drawing(3) avec vrai comme paramètre, avant de dessiner les glyphes, puis appelez à nouveau al_hold_bitmap_drawing(3) avec faux comme paramètre une fois les glyphes dessinés, afin d'améliorer davantage les performances.

DEPUIS

5.1.12

VOIR AUSSI

al_get_glyph_width(3), al_get_glyph_dimensions(3), al_get_glyph_advance(3).
