NAME

al_set_audio_stream_loop_secs - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_audio.h>
bool al_set_audio_stream_loop_secs(ALLEGRO_AUDIO_STREAM *stream,
   double start, double end)

DESCRIPTION

Définit les points de boucle pour le flux en secondes. Actuellement, cela ne peut être appelé que sur des flux créés avec al_load_audio_stream(3), al_play_audio_stream(3), al_load_audio_stream_f(3) ou al_play_audio_stream_f(3).
