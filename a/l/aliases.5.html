NOM

aliases — fichier d'alias pour smtpd

DESCRIPTION

Cette page de manuel décrit le format du fichier aliases, tel qu'utilisé par smtpd(8). Un alias, dans sa forme la plus simple, est utilisé pour attribuer un nom arbitraire à une adresse e-mail ou à un groupe d'adresses e-mail. Cela offre un moyen pratique d'envoyer des courriers. Par exemple, un alias pourrait faire référence à tous les utilisateurs d'un groupe : les courriers envoyés à cet alias seraient adressés à tous les membres du groupe. Cependant, des alias beaucoup plus complexes peuvent être définis : un alias peut faire référence à d'autres alias, être utilisé pour envoyer un courrier à un fichier au lieu d'une autre personne, ou pour exécuter diverses commandes.

Dans le fichier, le caractère ‘#’ est un délMitteur de commentaire ; tout ce qui est placé après est ignoré. Le fichier consiste en des associations clé/valeur de la forme :

clé: valeur1, valeur2, valeur3, ...

clé est toujours mise en minuscules avant la recherche d'alias afin d'éviter toute ambiguïté. La clé est développée en valeurs correspondantes, qui consistent en un ou plusieurs des éléments suivants :

utilisateur
Un utilisateur sur la machine hôte. L'utilisateur doit avoir une entrée valide dans le fichier de base de données passwd(5).
/chemin/vers/fichier
Ajouter les messages à fichier, spécifié par son chemin d'accès absolu.
|commande
Transférer le message à commande via son entrée standard. La commande est exécutée sous les privilèges du compte non privilégié du démon.
:inclure:/chemin/vers/fichier
Inclure toutes les définitions du fichier fichier comme entrées d'alias. Le format du fichier est identique à celui-ci.
partie_utilisateur@partie_domaine
Une adresse e-mail au format RFC 5322. Si une extension d'adresse est ajoutée à la partie utilisateur, elle est d'abord comparée pour une correspondance exacte. Elle est ensuite supprimée de sorte qu'une adresse telle que utilisateur+ext@exemple.com utilisera uniquement la partie qui précède le ‘+’ comme clé.
erreur:code message
Un code de statut et un message à retourner. Le code doit être à 3 chiffres, commençant par 4XX (TempFail) ou 5XX (PermFail). Le message doit être présent et peut être librement choisi.

FICHIERS

/etc/smtpd/aliases
Fichier aliases par défaut.

VOIR AUSSI

smtpd.conf(5), makemap(8), newaliases(8), smtpd(8)
