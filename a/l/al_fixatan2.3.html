al_fixatan2(3) Manuel des fonctions de bibliothèque al_fixatan2(3)

NOM

al_fixatan2 - API Allegro 5

SYNOPIS

#include <allegro5/allegro.h>
al_fixed al_fixatan2(al_fixed y, al_fixed x)

DESCRIPTION

Il s'agit d'une version en virgule fixe de la routine atan2() de la libc. Elle calcule l'arc tangente de y / x, mais les signes des deux arguments sont utilisés pour déterminer le quadrant du résultat, et x est autorisé à être zéro. Cette fonction est utile pour convertir des coordonnées cartésiennes en coordonnées polaires.

Exemple :

al_fixed result;
/* Définit `result' à l'angle binaire 64. */
result = al_fixatan2(al_itofix(1), 0);
/* Définit `result' à l'angle binaire -109. */
result = al_fixatan2(al_itofix(-1), al_itofix(-2));
/* Fait échouer l'assertion. */
result = al_fixatan2(0, 0);
assert(!al_get_errno());

VALEUR DE RETOUR

Renvoie l'arc tangente de y / x au format d'angle binaire en virgule fixe, de -128 à 128. Si x et y sont tous deux zéro, renvoie zéro et définit errno d'Allegro sur EDOM.
