NOM

Alien::Build::Plugin::Prefer::SortVersions - Plugin pour trier les candidats par ordre décroissant de date

VERSION

version 2.84

SYNOPSIS

use alienfile;

plugin 'Prefer::SortVersions';

DESCRIPTION

Note : dans la plupart des cas, vous voudrez utiliser Alien::Build::Plugin::Download::Negotiate à la place. Il choisit le plugin de récupération approprié en fonction de votre plateforme et de votre environnement. Dans certains cas, vous pourriez avoir besoin d'utiliser ce plugin directement à la place.

Ce plugin Prefer trie les paquets qui ont été récupérés à partir d'un répertoire, soit directement à partir d'un plugin Fetch, soit à partir d'un plugin Decode. Il renvoie une liste avec les éléments triés du plus préférable au moins préférable, et filtre tout candidat indésirable.

Ce plugin met à jour la liste des fichiers pour inclure les versions qui sont extraites, afin qu'elles puissent être utilisées par d'autres plugins, tels que Alien::Build::Plugin::Prefer::BadVersion.

PROPRIÉTÉS

filter

C'est une expression régulière qui vous permet de filtrer les fichiers que vous ne souhaitez pas télécharger. Par exemple, si la liste du répertoire contenait des tarballs et des fichiers readme comme ceci :

foo-1.0.0.tar.gz
foo-1.0.0.readme

Vous pourriez spécifier un filtre de "qr/\.tar\.gz$/" pour vous assurer que seuls les tarballs sont considérés pour le téléchargement.

version

Expression régulière pour extraire la version d'un nom de fichier. L'expression régulière doit stocker le résultat dans $1. La valeur par défaut "qr/([0-9\.]+)/" est souvent raisonnable.
