FBB::Align(3bobcat) Alignement des éléments de tableau FBB::Align(3bobcat)

NOM

FBB::Align - Classe pour aligner les éléments dans les objets Table

SYNOPSIS

#include <bobcat/align>

Option de liaison : -lbobcat

DESCRIPTION

Cette classe définit des objets utilisés par la classe FBB::Table pour définir l'alignement de ses colonnes et/ou de ses éléments.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page manuelle sont définis dans l'espace de noms FBB.

HÉRITE DE

-

TYPEDEF SUPPLÉMENTAIRE

Le type FBB::Manipulator peut être utilisé comme raccourci pour

        std::ios_base &(*)(std::ios_base &)

qui est le prototype des manipulateurs d'entrée/sortie standard comme std::left.

MANIPULATEUR

Le manipulateur suivant (ne faisant pas partie de la FBB::Align, classe mais défini dans l'espace de noms FBB ) peut être spécifié comme Align-argument de constructeur d'objet et peut être stocké dans les objets Align via, par exemple, setManip:

o
FBB::center:

CONSTRUCTEURS

o
Align(Manipulator manip):
Ce constructeur est utilisé pour spécifier un alignement qui, lorsqu'il est inséré dans un Table, est utilisé pour tous les éléments du tableau. Ce type d'alignement général peut être modifié pour des colonnes et/ou des éléments spécifiques en utilisant les constructeurs suivants ;
o
Align(size_t column = 0, Manipulator manip = std::right):
Ce constructeur définit comment le contenu de la colonne `column' d'un objet Table est aligné. Lorsqu'il est utilisé, il est de la responsabilité du programmeur de s'assurer que la colonne du tableau existe (c'est-à-dire que le Table doit avoir un index de colonne column) ;
o
Align(int row, size_t column, Manipulator manip):
Ce constructeur définit l'alignement de l'élément [row][column] d'un objet Table . Avant d'utiliser ce constructeur, l'élément de tableau [row][column] doit avoir été défini. Par exemple, 
    Table tab{  3, Table::ROWWISE };
    tab << "xx00x " << " x01x " << " x02xx" <<
            10 << 11 << 12;
    tab << Align(1, 1, FBB::center);

Les constructeurs de copie et de déplacement (et les opérateurs d'affectation) sont disponibles.
