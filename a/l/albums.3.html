int LIBMTP_Create_New_Album (LIBMTP_mtpdevice_t * device, LIBMTP_album_t *const metadata)

Cette routine crée un nouvel album basé sur les métadonnées fournies. Si le champ `tracks` des métadonnées contient une liste de pistes, ces pistes seront ajoutées à l'album.

Paramètres

device un pointeur vers l'appareil sur lequel créer le nouvel album.
metadata les métadonnées du nouvel album. Si la fonction se termine avec succès, le champ `album_id` de cette structure contiendra le nouvel ID de l'album.
  • `metadata->parent_id` doit être défini sur le parent (par exemple, le dossier) dans lequel stocker cette piste. Comme certains appareils sont un peu pointilleux sur l'emplacement des fichiers, un dossier par défaut sera choisi si libmtp en a détecté un pour le type de fichier actuel et que ce paramètre est défini sur 0. Si c'est 0 et qu'aucun dossier par défaut ne peut être trouvé, le fichier sera stocké dans le dossier racine.
  • `metadata->storage_id` doit être défini sur le stockage souhaité (par exemple, la carte mémoire ou tout ce que votre appareil présente) pour stocker cette piste. Le définir à 0 stockera la piste sur le stockage principal.

Retourne

0 en cas de succès, toute autre valeur signifie un échec.

int LIBMTP_Set_Album_Name (LIBMTP_mtpdevice_t * device, LIBMTP_album_t * album, const char * newname)

Cette fonction renomme un album unique. Cela signifie simplement que la propriété `PTP_OPC_ObjectFileName` est mise à jour, si cela est supporté par l'appareil. Le nom de fichier de l'album doit nominalement se terminer par une extension comme '.alb'.

NOTE : si vous souhaitez modifier les métadonnées que l'appareil affiche concernant une playlist, vous ne devez pas utiliser cette fonction, utilisez plutôt LIBMTP_Update_Album() !

Paramètres

device un pointeur vers l'appareil qui contient le fichier.
album les métadonnées de l'album à renommer. En cas de succès, le membre `name` est mis à jour. Soyez conscient que ce nom peut être différent de `newname` en fonction des restrictions de l'appareil.
newname le nouveau nom de cet objet.

Retourne

0 en cas de succès, toute autre valeur signifie un échec.
