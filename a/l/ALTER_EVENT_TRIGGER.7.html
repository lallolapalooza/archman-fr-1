ALTER EVENT_TRIGGER(7) Documentation PostgreSQL 18.1 ALTER EVENT_TRIGGER(7)

NOM

ALTER_EVENT_TRIGGER - modifier la définition d'un déclencheur d'événement

SYNTAXE

ALTER EVENT TRIGGER nom DISABLE
ALTER EVENT TRIGGER nom ENABLE [ REPLICA | ALWAYS ]
ALTER EVENT TRIGGER nom OWNER TO { nouveau_propriétaire | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER EVENT TRIGGER nom RENAME TO nouveau_nom

DESCRIPTION

ALTER EVENT_TRIGGER modifie les propriétés d'un déclencheur d'événement existant.

Vous devez être superutilisateur pour modifier un déclencheur d'événement.

PARAMÈTRES

nom

Le nom du déclencheur existant à modifier.

nouveau_propriétaire

Le nom de l'utilisateur qui sera le nouveau propriétaire du déclencheur d'événement.

nouveau_nom

Le nouveau nom du déclencheur d'événement.

DISABLE/ENABLE [ REPLICA | ALWAYS ]

Ces formes configurent l'exécution des déclencheurs d'événement. Un déclencheur désactivé est toujours connu du système, mais n'est pas exécuté lorsque son événement déclencheur se produit. Voir également session_replication_role.

COMPATIBILITÉ

Il n'y a pas d'instruction ALTER EVENT TRIGGER dans la norme SQL.

VOIR AUSSI

CREATE EVENT TRIGGER (CREATE_EVENT_TRIGGER(7)), DROP EVENT TRIGGER (DROP_EVENT_TRIGGER(7))
