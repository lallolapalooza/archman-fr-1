ALTER TRIGGER(7) Documentation PostgreSQL 18.1 ALTER TRIGGER(7)

NOM

ALTER_TRIGGER - changer la définition d'un déclencheur

SYNTAXE

ALTER TRIGGER nom ON nom_table RENAME TO nouveau_nom
ALTER TRIGGER nom ON nom_table [ NO ] DEPENDS ON EXTENSION nom_extension

DESCRIPTION

ALTER TRIGGER modifie les propriétés d'un déclencheur existant.

La clause RENAME change le nom du déclencheur spécifié sans modifier autrement la définition du déclencheur. Si la table sur laquelle se trouve le déclencheur est une table partitionnée, les déclencheurs clones correspondants dans les partitions sont également renommés.

La clause DEPENDS ON EXTENSION marque le déclencheur comme dépendant d'une extension, de sorte que si l'extension est supprimée, le déclencheur sera automatiquement supprimé également.

Vous devez être propriétaire de la table sur laquelle le déclencheur agit pour pouvoir modifier ses propriétés.

PARAMETRES

nom

Le nom d'un déclencheur existant à modifier.

nom_table

Le nom de la table sur laquelle ce déclencheur agit.

nouveau_nom

Le nouveau nom du déclencheur.

nom_extension

Le nom de l'extension dont le déclencheur doit dépendre (ou ne plus dépendre, si NO est spécifié). Un déclencheur marqué comme dépendant d'une extension est automatiquement supprimé lorsque l'extension est supprimée.

NOTES

La possibilité d'activer ou de désactiver temporairement un déclencheur est fournie par ALTER TABLE, et non par ALTER TRIGGER, car ALTER TRIGGER n'offre pas de moyen pratique d'exprimer l'option d'activer ou de désactiver tous les déclencheurs d'une table en une seule fois.

EXEMPLES

Pour renommer un déclencheur existant :

ALTER TRIGGER emp_stamp ON emp RENAME TO emp_track_chgs;

Pour marquer un déclencheur comme dépendant d'une extension :

ALTER TRIGGER emp_stamp ON emp DEPENDS ON EXTENSION emplib;

COMPATIBILITE

ALTER TRIGGER est une extension PostgreSQL du standard SQL.

VOIR AUSSI

ALTER TABLE (ALTER_TABLE(7))
