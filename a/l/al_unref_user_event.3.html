al_unref_user_event(3) Manuel des fonctions de bibliothèque al_unref_user_event(3)

NOM

al_unref_user_event - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
void al_unref_user_event(ALLEGRO_USER_EVENT *event)

DESCRIPTION

Diminue le compteur de références d'un événement défini par l'utilisateur. Cela doit être appelé sur tout événement utilisateur obtenu via al_get_next_event(3), al_peek_next_event(3), al_wait_for_event(3), etc. qui est compté par référence. Cette fonction ne fait rien si l'événement n'est pas compté par référence.

VOIR AUSSI

al_emit_user_event(3), ALLEGRO_USER_EVENT(3)
