al_fopen(3) Manuel des fonctions de bibliothèque al_fopen(3)

NOM

al_fopen - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
ALLEGRO_FILE *al_fopen(const char *path, const char *mode)

DESCRIPTION

Crée et ouvre un fichier (réel ou virtuel) étant donné le chemin et le mode. L'interface de fichier actuelle est utilisée pour ouvrir le fichier.

Paramètres :

•
path - chemin du fichier à ouvrir
•
mode - mode d'accès pour ouvrir le fichier (“r”, “w”, etc.)

Selon le type de flux et la chaîne de mode, les fichiers peuvent être ouverts en mode “texte”. La gestion des fins de ligne est particulièrement importante. Par exemple, en utilisant les flux basés sur stdio par défaut sur les plateformes DOS et Windows, où les terminateurs de fin de ligne natifs sont des séquences CR+LF, un appel à al_fgetc(3) peut renvoyer un seul caractère (‘\n’) là où il y avait deux octets (CR+LF) dans le fichier. Lors de l'écriture de ‘\n’, deux octets seraient écrits à la place. (Soit dit en passant, ‘\n’ n'est pas non plus défini comme étant égal à LF.)

Les traductions de fin de ligne peuvent être utiles pour les fichiers texte mais sont désastreuses pour les fichiers binaires. Pour éviter ce comportement, vous devez ouvrir les flux de fichiers en mode binaire en utilisant un argument de mode contenant un “b”, par exemple  “rb”, “wb”.

Retourne un handle de fichier en cas de succès, ou NULL en cas d'erreur.

VOIR AUSSI

al_set_new_file_interface(3), al_fclose(3).
