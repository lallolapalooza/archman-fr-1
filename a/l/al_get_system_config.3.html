NOM

al_get_system_config - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
ALLEGRO_CONFIG *al_get_system_config(void)

DESCRIPTION

Renvoie la structure de configuration du système. La configuration renvoyée ne doit pas être détruite avec al_destroy_config(3). Elle est principalement utilisée pour configurer Allegro et ses extensions. Vous pouvez remplir cette configuration avant que Allegro ne soit installé pour contrôler des éléments tels que les niveaux de journalisation et d'autres fonctionnalités.

Allegro essaiera de remplir cette configuration en chargeant un fichier de configuration à partir de plusieurs emplacements différents, dans cet ordre :

•
Unix uniquement : /etc/allegro5rc
•
Unix uniquement : $HOME/allegro5rc
•
Unix uniquement : $HOME/.allegro5rc
•
allegro5.cfg à côté de l'exécutable

Si plusieurs copies sont trouvées, elles sont fusionnées à l'aide de al_merge_config_into(3).

Le contenu de ce fichier est documenté dans un prototype de allegro5.cfg que vous pouvez trouver dans le répertoire racine des distributions sources d'Allegro. Ils sont également reproduits ci-dessous.

Notez qu'Allegro ne consultera pas ce fichier sauf si vous en faites une copie et la placez à côté de votre exécutable !
