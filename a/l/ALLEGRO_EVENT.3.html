ALLEGRO_EVENT(3) Manuel des fonctions de bibliothèque ALLEGRO_EVENT(3)

NOM

ALLEGRO_EVENT - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
typedef union ALLEGRO_EVENT ALLEGRO_EVENT;

DESCRIPTION

ALLEGRO_EVENT est une union de toutes les structures d'événements intégrées, c'est-à-dire un objet suffisamment grand pour contenir les données de n'importe quel type d'événement. Tous les événements ont les champs suivants en commun :

type (ALLEGRO_EVENT_TYPE)
Indique le type d'événement.
any.source (ALLEGRO_EVENT_SOURCE *)
La source d'événement qui a généré l'événement.
any.timestamp (double)
Quand l'événement a été généré.

En examinant le champ type vous pouvez ensuite accéder aux champs spécifiques au type. Le champ any.source vous indique quelle source d'événement a généré cet événement particulier. Le champ any.timestamp vous indique quand l'événement a été généré. Le temps est référencé au même point de départ que al_get_time(3).

Chaque événement est de l'un des types suivants, avec les champs utilisables indiqués.

ALLEGRO_EVENT_JOYSTICK_AXIS

La valeur d'un axe de manette a changé.

joystick.id (ALLEGRO_JOYSTICK *)
La manette qui a généré l'événement. Cela ne correspond pas à la source d'événement joystick.source.
joystick.stick (int)
Le numéro du stick, en comptant à partir de zéro. Les axes d'une manette sont regroupés en « sticks ».
joystick.axis (int)
Le numéro de l'axe sur le stick, en comptant à partir de zéro.
joystick.pos (float)
La position de l'axe, de -1.0 à +1.0.

ALLEGRO_EVENT_JOYSTICK_BUTTON_DOWN

Un bouton de manette a été pressé.

joystick.id (ALLEGRO_JOYSTICK *)
La manette qui a généré l'événement.
joystick.button (int)
Le bouton qui a été pressé, en comptant à partir de zéro.

ALLEGRO_EVENT_JOYSTICK_BUTTON_UP

Un bouton de manette a été relâché.

joystick.id (ALLEGRO_JOYSTICK *)
La manette qui a généré l'événement.
joystick.button (int)
Le bouton qui a été relâché, en comptant à partir de zéro.

ALLEGRO_EVENT_JOYSTICK_CONFIGURATION

Une manette a été branchée ou débranchée. Voir al_reconfigure_joysticks(3) pour plus de détails.

ALLEGRO_EVENT_KEY_DOWN

Une touche de clavier a été pressée.

keyboard.keycode (int)
Le code correspondant à la touche physique qui a été pressée. Voir la section [Key codes] pour la liste des constantes ALLEGRO_KEY_*.
keyboard.display (ALLEGRO_DISPLAY *)
L'affichage qui avait le focus clavier lorsque l'événement s'est produit.

Note : cet événement concerne les touches physiques pressées sur le clavier. Cherchez les événements ALLEGRO_EVENT_KEY_CHAR pour la saisie de caractères.

ALLEGRO_EVENT_KEY_UP

Une touche de clavier a été relâchée.

keyboard.keycode (int)
Le code correspondant à la touche physique qui a été relâchée. Voir la section [Key codes] pour la liste des constantes ALLEGRO_KEY_*.
keyboard.display (ALLEGRO_DISPLAY *)
L'affichage qui avait le focus clavier lorsque l'événement s'est produit.

ALLEGRO_EVENT_KEY_CHAR

Un caractère a été tapé sur le clavier, ou un caractère a été auto-répété.

keyboard.keycode (int)
Le code correspondant à la touche physique qui a été pressée en dernier. Voir la section [Key codes] pour la liste des constantes ALLEGRO_KEY_*.
keyboard.unichar (int)
Un point de code Unicode (caractère). Cela peut être zéro ou négatif si l'événement a été généré pour un « caractère » non visible, comme une touche de direction ou une touche de fonction. Dans ce cas, vous pouvez agir sur le champ keycode .

Certaines touches spéciales définissent le champ unichar avec leurs valeurs ASCII standard : Tab=9, Return=13, Escape=27. De plus, si vous appuyez sur la touche Control avec A à Z, le champ unichar aura les valeurs 1 à 26. Par exemple, Ctrl-A définira unichar à 1 et Ctrl-H le définira à 8.

Depuis Allegro 5.0.2, il existe certaines incohérences dans le traitement des touches Backspace (8 ou 127) et Delete (127 ou 0) sur différentes plateformes. Celles-ci peuvent être contournées en vérifiant le champ keycode .

keyboard.modifiers (unsigned)
C'est un champ de bits des touches modificateurs qui étaient pressées lorsque l'événement s'est produit. Voir « Keyboard modifier flags » pour les constantes.
keyboard.repeat (bool)
Indique s'il s'agit d'un caractère répété.
keyboard.display (ALLEGRO_DISPLAY *)
L'affichage qui avait le focus clavier lorsque l'événement s'est produit.

Note: dans de nombreuses méthodes de saisie, les caractères ne sont pas saisis un pour un avec les pressions de touches physiques. Plusieurs pressions de touches peuvent se combiner pour générer un seul caractère, par exemple apostrophe + e peut produire « é ». Moins de pressions de touches peuvent aussi générer plus de caractères, par exemple des séquences de macro qui s'étendent en phrases courantes.

ALLEGRO_EVENT_MOUSE_AXES

Une ou plusieurs valeurs d'axes de souris ont changé.

mouse.x (int)
coordonnée x
mouse.y (int)
coordonnée y
mouse.z (int)
coordonnée z. Cela signifie généralement l'axe vertical d'une molette de souris, où le haut est positif et le bas est négatif.
mouse.w (int)
coordonnée w. Cela signifie généralement l'axe horizontal d'une molette de souris.
mouse.dx (int)
Changement de la valeur de la coordonnée x depuis le précédent événement ALLEGRO_EVENT_MOUSE_AXES.
mouse.dy (int)
Changement de la valeur de la coordonnée y depuis le précédent événement ALLEGRO_EVENT_MOUSE_AXES.
mouse.dz (int)
Changement de la valeur de la coordonnée z depuis leious ALLEGRO_EVENT_MOUSE_AXES event.
mouse.dw (int)
Changement de la valeur de la coordonnée w depuis l'événement ALLEGRO_EVENT_MOUSE_AXES précédent.
mouse.pressure (float)
Pression, allant de 0.0 à 1.0.
mouse.display (ALLEGRO_DISPLAY *)
L'affichage qui avait le focus de la souris.

Note : Appeler al_set_mouse_xy(3) entraînera également un changement des valeurs des axes, mais un tel changement est signalé avec des événements ALLEGRO_EVENT_MOUSE_WARPED(3) qui sont identiques à ceux de ALLEGRO_EVENT_MOUSE_AXES(3) sauf pour leur type.

Note : actuellement mouse.display peut être NULL si un événement est généré en réponse à al_set_mouse_axis(3).

ALLEGRO_EVENT_MOUSE_BUTTON_DOWN

Un bouton de la souris a été pressé.

mouse.x (int)
coordonnée x
mouse.y (int)
coordonnée y
mouse.z (int)
coordonnée z
mouse.w (int)
coordonnée w
mouse.button (unsigned)
Le bouton de la souris qui a été pressé, numéroté à partir de 1. Par commodité, les constantes ALLEGRO_MOUSE_BUTTON_LEFT, ALLEGRO_MOUSE_BUTTON_RIGHT, ALLEGRO_MOUSE_BUTTON_MIDDLE sont fournies. Cependant, selon le matériel, il peut y avoir plus ou moins de boutons de souris. Vous pouvez vérifier al_get_mouse_num_buttons(3) si vous voulez en être sûr.
mouse.pressure (float)
Pression, allant de 0.0 à 1.0.
mouse.display (ALLEGRO_DISPLAY *)
L'affichage qui avait le focus de la souris.

ALLEGRO_EVENT_MOUSE_BUTTON_UP

Un bouton de la souris a été relâché.

mouse.x (int)
coordonnée x
mouse.y (int)
coordonnée y
mouse.z (int)
coordonnée z
mouse.w (int)
coordonnée w
mouse.button (unsigned)
Le bouton de la souris qui a été relâché, numéroté à partir de 1. Par commodité, les constantes ALLEGRO_MOUSE_BUTTON_LEFT, ALLEGRO_MOUSE_BUTTON_RIGHT, ALLEGRO_MOUSE_BUTTON_MIDDLE sont fournies. Cependant, selon le matériel, il peut y avoir plus ou moins de boutons de souris. Vous pouvez vérifier al_get_mouse_num_buttons(3) si vous voulez en être sûr.
mouse.pressure (float)
Pression, allant de 0.0 à 1.0.
mouse.display (ALLEGRO_DISPLAY *)
L'affichage qui avait le focus de la souris.

ALLEGRO_EVENT_MOUSE_WARPED

al_set_mouse_xy(3) a été appelé pour déplacer la souris. Cet événement est identique à ALLEGRO_EVENT_MOUSE_AXES(3) autrement.

ALLEGRO_EVENT_MOUSE_LEAVE_DISPLAY

coordonnée x

coordonnée y
mouse.z (int)
coordonnée z
mouse.w (int)
coordonnée w
mouse.display (ALLEGRO_DISPLAY *)

ALLEGRO_EVENT_TOUCH_BEGIN

Le périphérique d'entrée tactile a enregistré un nouveau toucher.

touch.display (ALLEGRO_DISPLAY)
L'affichage qui a été touché.
touch.id (int)
Un identifiant pour ce toucher. Si pris en charge par le périphérique, il restera le même pour les événements provenant du même doigt jusqu'à la fin du toucher.
touch.x (float)
La coordonnée x du toucher en pixels.
touch.y (float)
La coordonnée y du toucher en pixels.
touch.dx (float)
Vitesse de déplacement en pixels dans la direction x.
touch.dy (float)
Vitesse de déplacement en pixels dans la direction y.
touch.primary (bool)
S'il s'agit du seul/premier toucher ou d'un toucher supplémentaire.

T

Lors de l'utilisation de Direct3D, les affichages peuvent entrer dans un état « perdu ». Dans cet état, les appels de dessin sont ignorés, et lors de l'entrée dans l'état, les données de pixels des bitmaps peuvent devenir indéfinies. Allegro fait de son mieux pour préserver le contenu correct des bitmaps (voir le drapeau ALLEGRO_NO_PRESERVE_TEXTURE) et les restaurer lorsque le dispositif est « retrouvé » (voir ALLEGRO_EVENT_DISPLAY_FOUND(3)). Cependant, ceci n'est pas infaillible à 100 % (voir la discussion dans la documentation de al_create_bitmap(3))
