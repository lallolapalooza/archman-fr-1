NOM

al_win_add_window_callback - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_windows.h>
bool al_win_add_window_callback(ALLEGRO_DISPLAY *display,
   bool (*callback)(ALLEGRO_DISPLAY *display, UINT message, WPARAM wparam,
   LPARAM lparam, LRESULT *result, void *userdata), void *userdata)

DESCRIPTION

La fonction de rappel spécifiée interceptera le message de la fenêtre avant qu'Allegro ne le traite. Si la fonction de rappel consomme l'événement, elle doit retourner vrai. Dans ce cas, Allegro ne fera rien avec l'événement.

Optionnellement, vous pouvez utiliser result pour personnaliser ce qu'Allegro retournera en réponse à cet événement. Par défaut, Allegro retourne TRUE.

Le pointeur userdata peut être utilisé pour fournir un contexte supplémentaire à la fonction de rappel.

Les rappels sont exécutés dans le même ordre où ils ont été ajoutés.

Retourne vrai si le rappel a été ajouté.
