Les indices de terminal peuvent être utilisés pour trouver du texte ou des hyperliens dans la partie visible du terminal et les rediriger vers d'autres applications.

Tableau avec tous les indices disponibles.

Chaque indice doit avoir au moins l'un des champs regex ou hyperlinks et soit une action soit une command.

regex = "<chaîne>"
Expression régulière à laquelle chaque ligne sera comparée.

hyperlinks = vrai | faux

Lorsque cette option est définie sur vrai, tous les hyperliens avec la séquence d'échappement OSC 8 seront inclus dans les indices.

post_processing = vrai | faux

Lorsque cette option est définie sur vrai, des heuristiques seront utilisées pour raccourcir la correspondance s'il y a des caractères qui ne font probablement pas partie de l'indice (par exemple, un point final .). Ceci est particulièrement utile pour les URI et ne s'applique qu'aux correspondances regex.

persist = vrai | faux

Lorsque cette option est définie sur vrai, les indices restent persistants après la sélection.

action = "Copy" | "Paste" | "Select" | "MoveViModeCursor"

Copy
Copie le texte de l'indice dans le presse-papiers.
Paste
Colle le texte de l'indice dans le terminal ou lance une recherche.
Select
Sélectionne le texte de l'indice.
MoveViModeCursor
Déplace le curseur du mode vi au début de l'indice.
