NOM

Alien::Build::Plugin::Fetch::NetFTP - Plugin pour récupérer des fichiers via Net::FTP

VERSION

version 2.84

SYNOPSIS

use alienfile;
share {
  start_url 'ftp://ftp.gnu.org/gnu/make';
  plugin 'Fetch::NetFTP';
};

DESCRIPTION

Note : dans la plupart des cas, vous voudrez utiliser Alien::Build::Plugin::Download::Negotiate à la place. Il sélectionne le plugin de téléchargement approprié en fonction de votre plateforme et de votre environnement. Dans certains cas, vous devrez peut-être utiliser ce plugin directement à la place.

Ce plugin de récupération récupère des fichiers et des listes de répertoires via le protocole "ftp" en utilisant Net::FTP.

PROPRIÉTÉS

url

L'URL initiale à récupérer. Il peut s'agir d'un répertoire ou du fichier final.

ssl

Cette propriété est pour la compatibilité avec d'autres plugins de récupération, mais elle n'est pas utilisée.

passive

Si définie sur vrai, essayez le mode passif en PREMIER. Par défaut, il essaiera le mode actif, puis le mode passif.

VOIR AUSSI
