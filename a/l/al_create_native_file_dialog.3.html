al_create_native_file_dialog(3) Manuel des fonctions de bibliothèque al_create_native_file_dialog(3)

NOM

al_create_native_file_dialog - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_native_dialog.h>
ALLEGRO_FILECHOOSER *al_create_native_file_dialog(
   char const *initial_path,
   char const *title,
   char const *patterns,
   int mode)

DESCRIPTION

Crée une nouvelle boîte de dialogue de fichier native. Vous ne devriez avoir qu'une seule boîte de dialogue de ce type ouverte à la fois.

Paramètres :

•
initial_path : Le chemin de recherche et le nom de fichier initiaux. Peut être NULL. Pour commencer avec un nom de fichier vide, la chaîne doit se terminer par un séparateur de répertoire (ce devrait être le cas le plus courant).
•
title : Le titre de la boîte de dialogue.
•
patterns : Une chaîne contenant des ensembles de motifs séparés par des sauts de ligne pour la correspondance. Un motif est soit un motif glob de style shell (par exemple, "*.txt"), soit un type MIME (par exemple, "image/png"). Toutes les plateformes ne prennent pas en charge les deux (et certaines ne prennent même pas en charge les globs), donc une solution portable consiste à spécifier un type MIME et des globs de style simples qu'Allegro utilisera pour correspondre à ce que la plateforme prend en charge (par exemple, faites "image/png;*.png"). Plusieurs motifs sont séparés par un point-virgule. Si la plateforme ne prend pas en charge les motifs, ce paramètre est ignoré. Voici quelques exemples de motifs :
•
"*.txt" – définit un seul filtre, correspondant aux fichiers *.txt.
•
"*.txt;*.md" – comme ci-dessus, mais correspondant à deux types de fichiers.
•
"Fichiers texte (*.txt, *.md) *.txt;*.md" – comme ci-dessus, mais avec une description personnalisée (séparée des motifs par un espace).
•
"Fichiers texte *.txt\nImages PNG image/png;*.png" – définit deux filtres, le second utilisant à la fois un type MIME et une extension.

Remarque : Windows ne prend pas en charge les types MIME. Android ne prend en charge que les types MIME. Au lieu de motifs de fichiers, MacOS prend en charge les extensions, donc la correspondance basée sur le nom de fichier au-delà du type de fichier ne fonctionne pas. Allegro analysera votre motif de fichier pour tenter d'en extraire l'extension. MacOS prend également en charge les types MIME, qui se comportent de manière plus prévisible. MacOS ne prend pas en charge les descriptions détaillées ni les ensembles de motifs multiples, Allegro supprimera les descriptions détaillées et concaténera tous les motifs en une seule liste.

•
mode : 0, ou une combinaison des indicateurs suivants :
ALLEGRO_FILECHOOSER_FILE_MUST_EXIST
Si pris en charge par la boîte de dialogue native, elle n'autorisera pas la saisie de nouveaux noms, mais permettra uniquement la sélection de fichiers existants. Sinon, elle est ignorée.
ALLEGRO_FILECHOOSER_SAVE
Si le système de boîte de dialogue natif dispose d'une boîte de dialogue différente pour la sauvegarde (par exemple, une qui permet de créer de nouveaux répertoires), elle est utilisée. Sinon, elle est ignorée.
ALLEGRO_FILECHOOSER_FOLDER
S'il existe un support pour une boîte de dialogue distincte pour sélectionner un dossier au lieu d'un fichier, elle sera utilisée.
ALLEGRO_FILECHOOSER_PICTURES
Si une boîte de dialogue différente est disponible pour la sélection d'images, elle est utilisée. Sinon, elle est ignorée.
ALLEGRO_FILECHOOSER_SHOW_HIDDEN
Si la plateforme le prend en charge, les fichiers cachés seront également affichés.
ALLEGRO_FILECHOOSER_MULTIPLE
Si pris en charge, permet la sélection de plusieurs fichiers.

Retourne :

Un pointeur vers la boîte de dialogue que vous pouvez passer à al_show_native_file_dialog(3) pour l'afficher, et à partir de laquelle vous pouvez ensuite interroger les résultats à l'aide de al_get_native_file_dialog_count(3) et al_get_native_file_dialog_path(3). Lorsque vous avez terminé, appelez al_destroy_native_file_dialog(3) sur celui-ci.

Si une fenêtre de dialogue n'a pas pu être créée, cette fonction renvoie NULL.
