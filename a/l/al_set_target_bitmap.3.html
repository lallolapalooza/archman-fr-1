al_set_target_bitmap(3) Manuel des fonctions de bibliothèque al_set_target_bitmap(3)

NOM

al_set_target_bitmap - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
void al_set_target_bitmap(ALLEGRO_BITMAP *bitmap)

DESCRIPTION

Cette fonction sélectionne le bitmap vers lequel toutes les opérations de dessin ultérieures dans le thread appelant dessineront. Pour revenir au dessin sur un écran, définissez le backbuffer de l'écran comme bitmap cible, en utilisant al_get_backbuffer(3). Par commodité, vous pouvez également utiliser al_set_target_backbuffer(3).

Chaque bitmap allegro maintient deux matrices de transformation qui lui sont associées pour dessiner sur le bitmap. Il y a une matrice de vue et une matrice de projection. Lorsque vous appelez al_set_target_bitmap, celles-ci seront rendues courantes pour le bitmap, affectant les états globaux OpenGL et DirectX selon le pilote utilisé.

Chaque bitmap vidéo est lié à un écran. Lorsqu'un bitmap vidéo est défini comme bitmap cible, l'écran auquel appartient le bitmap est automatiquement rendu « courant » pour le thread appelant (s'il n'est pas déjà courant). Dessiner ensuite d'autres bitmaps liés au même écran peut être accéléré matériellement.

Un seul écran ne peut pas être courant pour plusieurs threads simultanément. Si vous avez besoin de libérer un écran, afin qu'il ne soit pas courant pour le thread appelant, appelez al_set_target_bitmap(NULL);

Définir un bitmap mémoire comme bitmap cible ne modifiera pas l'écran qui est courant pour le thread appelant.

Sur certaines plateformes, Allegro sauvegarde automatiquement le contenu des bitmaps vidéo car ils peuvent être perdus occasionnellement (voir la discussion dans la documentation de al_create_bitmap(3)). Si vous recréez complètement le contenu du bitmap fréquemment (par exemple, à chaque image), vous obtiendrez de meilleures performances en créant le bitmap cible avec le drapeau ALLEGRO_NO_PRESERVE_TEXTURE.

Note OpenGL :

Les objets de framebuffer (FBO) permettent à OpenGL de dessiner directement sur un bitmap, ce qui est très rapide. Lorsque vous utilisez un écran OpenGL, si toutes les conditions suivantes sont remplies, un FBO sera créé pour être utilisé avec le bitmap :

•
L'extension OpenGL GL_EXT_framebuffer_object est disponible.
•
Le bitmap n'est pas un bitmap mémoire.
•
Le bitmap n'est pas verrouillé actuellement.

Dans Allegro 5.0.0, vous deviez faire attention car un FBO était conservé jusqu'à la destruction du bitmap ou jusqu'à ce que vous appeliez explicitement al_remove_opengl_fbo(3) sur le bitmap, gaspillant ainsi des ressources. Dans les versions plus récentes, les FBO seront libérés automatiquement lorsque le bitmap ne sera plus le bitmap cible, *sauf* si vous avez appelé al_get_opengl_fbo(3) pour récupérer l'ID du FBO.

Dans l'exemple suivant, aucun FBO ne sera créé :

lock = al_lock_bitmap(bitmap);
al_set_target_bitmap(bitmap);
al_put_pixel(x, y, color);
al_unlock_bitmap(bitmap);

Ce qui précède permet d'utiliser al_put_pixel(3) sur un bitmap verrouillé sans créer de FBO.

Dans cet exemple, un FBO est créé cependant :

al_set_target_bitmap(bitmap);
al_draw_line(x1, y1, x2, y2, color, 0);

Une commande OpenGL sera utilisée pour dessiner directement la ligne dans la texture associée au bitmap.
