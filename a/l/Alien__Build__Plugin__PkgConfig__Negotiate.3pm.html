NOM

Alien::Build::Plugin::PkgConfig::Negotiate - Plugin de négociation de configuration de paquet

VERSION

version 2.84

SYNOPSIS

use alienfile;
plugin 'PkgConfig' => (
  pkg_name => 'libfoo',
);

DESCRIPTION

Ce plugin fournit les étapes de sonde (Probe) et de collecte (Gather) pour les paquets basés sur pkg-config. Il choisit le meilleur plugin "PkgConfig" en fonction de votre plateforme et de votre environnement.

PROPRIÉTÉS

pkg_name

Le nom du paquet. Si c'est une référence de liste, alors des fichiers .pc portant tous ces noms de paquets doivent être présents. Le premier nom sera le nom principal et sera utilisé par défaut une fois installé. Pour les fichiers ".pc" suivants, vous pouvez utiliser la méthode alt d'Alien::Base pour récupérer les configurations alternatives une fois l'Alien installé.

atleast_version

La version minimale requise qui est une version acceptable telle que fournie par le système.

exact_version

La version exacte requise qui est une version acceptable telle que fournie par le système.

max_version

La version maximale requise qui est une version acceptable telle que fournie par le système.

minimum_version

Alias pour "atleast_version" pour la compatibilité ascendante.

MÉTHODES

pick

my $name = Alien::Build::Plugin::PkgConfig::Negotiate->pick;

Retourne le nom du plugin négocié.

ENVIRONNEMENT

ALIEN_BUILD_PKG_CONFIG
Si défini, ce plugin sera utilisé à la place de la logique intégrée qui tente de sélectionner automatiquement le meilleur plugin.
