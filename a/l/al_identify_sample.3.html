al_identify_sample(3) Manuel des fonctions de bibliothèque al_identify_sample(3)

NOM

al_identify_sample - API Allegro 5

SYNTAXE

#include <allegro5/allegro_audio.h>
char const *al_identify_sample(char const *filename)

DESCRIPTION

Ceci fonctionne exactement comme al_identify_sample_f(3) mais vous spécifiez le nom du fichier dont vous souhaitez détecter le type et non un descripteur de fichier. L'extension, le cas échéant, du nom de fichier passé n'est pas prise en compte - seul le contenu du fichier l'est.

DEPUIS

5.2.8

VOIR AUSSI

al_init_acodec_addon(3), al_identify_sample_f(3), al_register_sample_identifier(3)
