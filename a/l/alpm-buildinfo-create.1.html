NOM

alpm-buildinfo-create - Créer un fichier BUILDINFO selon un schéma

SYNTAXE

alpm-buildinfo create [-h|--help] <sous-commandes>

DESCRIPTION

Crée un fichier BUILDINFO selon un schéma.

Si l'entrée peut être validée selon le schéma, le programme se termine sans sortie et avec un code de retour de 0. Si l'entrée ne peut pas être validée selon le schéma, une erreur est émise sur stderr et le programme se termine avec un code de sortie non nul.

OPTIONS

-h, --help
Imprimer l'aide (voir un résumé avec '-h')

SOUS-COMMANDES

alpm-buildinfo-create-v1(1)
Créer un fichier BUILDINFO version 1
alpm-buildinfo-create-v2(1)
Créer un fichier BUILDINFO version 2
alpm-buildinfo-create-help(1)
Imprimer ce message ou l'aide de la ou des sous-commandes données
