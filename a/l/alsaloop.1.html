Paquet: alsa-utils

ALSALOOP(1) Manuel des commandes générales ALSALOOP(1)

NOM

alsaloop - boucle PCM en ligne de commande

SYNTAXE

alsaloop [-option] [commande]

DESCRIPTION

alsaloop permet de créer une boucle PCM entre un périphérique de capture PCM et un périphérique de lecture PCM.

alsaloop prend en charge plusieurs cartes son, la synchronisation horloge adaptative, le rééchantillonnage adaptatif du taux à l'aide de la bibliothèque samplerate (si disponible sur le système). De plus, les contrôles du mixeur peuvent être redirigés d'une carte à une autre (par exemple, Master et PCM).

OPTIONS

-h | --help

Affiche les informations d'aide.

-g <fichier> | --config=<fichier>

Utilise le fichier de configuration donné. La syntaxe de ce fichier est simple : une ligne contient les options de ligne de commande pour un travail. Le '#' signifie un commentaire et le reste de la ligne est ignoré. Exemple :


# Première ligne - commentaire, deuxième ligne - premier travail
-C hw:1,0 -P hw:0,0 -t 50000 -T 1
# Troisième ligne - commentaire, quatrième ligne - deuxième travail
-C hw:1,1 -P hw:0,1 -t 40000 -T 2

-d | --daemonize

Démonise le processus principal et utilise syslog pour les messages.

-P <périphérique> | --pdevice=<périphérique>

Utilise le périphérique de lecture spécifié.

-C <périphérique> | --cdevice=<périphérique>

Utilise le périphérique de capture spécifié.

-X <périphérique> | --pctl=<périphérique>

Utilise le périphérique CTL spécifié pour la lecture.

-Y <périphérique> | --cctl=<périphérique>

Utilise le périphérique CTL spécifié pour la capture.

-x <nom_ascii_ctl> | --prateshift=<nom_ascii_ctl>

Spécifie le nom ascii ctl pour le mode de synchronisation playshift (voir la section Exemples).

-l <latence> | --latency=<images>

Latence demandée en images.

-t <usec> | --tlatency=<usec>

Latence demandée en microsecondes (1/1000000sec).

-f <format> | --format=<format>

Spécification du format (généralement S16_LE S32_LE). Utilisez -h pour lister tous les formats. Le format par défaut est S16_LE.

-c <canaux> | --channels=<canaux>

Spécification du nombre de canaux. La valeur par défaut est 2.

-r <taux> | --rate=<taux>

Spécification du taux. La valeur par défaut est 48000 (Hz).

-n | --resample

Autorise le rééchantillonnage du taux à l'aide d'alsa-lib.

-A <convertisseur> | --samplerate=<convertisseur>

Utilise libsamplerate et choisit un convertisseur :


0 ou sincbest - meilleure qualité
1 ou sincmedium - qualité moyenne
2 ou sincfastest - qualité la plus basse
3 ou zerohold - ne pas tenir compte des échantillons
4 ou linear - pire qualité - rééchantillonnage linéaire
5 ou auto - choisit la meilleure méthode

-B <taille> | --buffer=<taille>

Taille du tampon en images.

-E <taille> | --period=<taille>

Taille de la période en images.

-s <secondes> | --seconds=<secondes>

Durée de la boucle en secondes.

-b | --nblock

Mode non bloquant (réveil très précoce du processus). Consomme plus de CPU.

-S <mode> | --sync=<mode>

Spécification du mode de synchronisation pour le flux de capture vers lecture :
0 ou none - ne pas toucher au flux
1 ou simple - ajouter ou supprimer des échantillons pour maintenir
les deux flux synchronisés
2 ou captshift - utiliser le pilote pour le périphérique de capture
(si supporté) pour compenser
le décalage du taux
3 ou playshift - utiliser le pilote pour le périphérique de lecture
(si supporté) pour compenser
le décalage du taux
4 ou samplerate - utiliser la bibliothèque samplerate pour effectuer le
rééchantillonnage du taux
5 ou auto - sélectionne automatiquement la meilleure méthode
dans cet ordre : captshift, playshift,
samplerate, simple

-T <num> | --thread=<num>

Numéro de thread (-1 signifie créer un thread unique). Tous les travaux ayant le même numéro de thread sont exécutés dans un seul thread.

-m <id_mix> | --mixer=<id_mix>

Redirige le contrôle du mixeur de la carte de lecture vers la carte de capture. Le format de id_mix est SRCID(LECTURE)[@DSTID(LECTURE)] :


"name='Master Playback Switch'@name='Another Switch'"
"name='PCM Playback Volume'"

Attributs connus :


name - nom de l'ID de contrôle
index - index de l'ID de contrôle
device - périphérique de l'ID de contrôle
subdevice - sous-périphérique de l'ID de contrôle
iface - interface de l'ID de contrôle
numid - numid de l'ID de contrôle

-O <ossmixid> | --ossmixer=<id_mix_oss>

Redirige le contrôle du mixeur de la couche d'émulation de mixage OSS (carte de capture) vers la couche ALSA (carte de capture). Le format de id_mix_oss est ALSAID[,INDEX]@OSSID :


"Master@VOLUME"
"PCM,1@ALTPCM"

Attributs OSS connus :


VOLUME, BASS, TREBLE, SYNTH, PCM, SPEAKER, LINE, MIC, CD, IMIX, ALTPCM,
RECLEV, IGAIN, OGAIN, LINE1, LINE2, LINE3, DIGITAL1, DIGITAL2, DIGITAL3,
PHONEIN, PHONEOUT, VIDEO, RADIO, MONITOR

-v | --verbose

Mode verbeux. Utilisez plusieurs fois pour augmenter la verbosité.

-U | --xrun

Profilage xrun verbeux.

-W <délai> | --wake=<délai>

Définit le délai de réveil du processus.

EXEMPLES

alsaloop -C hw:0,0 -P hw:1,0 -t 50000
alsaloop -C hw:carte_son,0 -P hw:Loopback,0 -t 50000 -S playshift \
-x iface=PCM,name='PCM Rate Shift 100000',device=1

BOGUES

Aucun connu.
