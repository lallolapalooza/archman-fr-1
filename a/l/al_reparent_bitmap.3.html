al_reparent_bitmap(3) Manuel des fonctions de bibliothèque al_reparent_bitmap(3)

NOM

al_reparent_bitmap - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
void al_reparent_bitmap(ALLEGRO_BITMAP *bitmap, ALLEGRO_BITMAP *parent,
   int x, int y, int w, int h)

DESCRIPTION

Pour un sous-bitmap, change le parent, la position et la taille. Ceci est équivalent à détruire le bitmap et à le recréer avec al_create_sub_bitmap(3) - sauf que le pointeur du bitmap reste le même. Ceci a de nombreuses utilisations, par exemple un lecteur d'animation pourrait renvoyer un seul bitmap qui peut simplement être re-parenté à différentes images d'animation sans avoir à redessiner le contenu. Ou un atlas de sprites pourrait réorganiser ses sprites sans avoir à invalider tous les bitmaps existants.

VOIR AUSSI

al_create_sub_bitmap(3), al_get_parent_bitmap(3)
