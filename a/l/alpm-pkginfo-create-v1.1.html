NOM

alpm-pkginfo-create-v1 - Créer un fichier PKGINFO version 1

SYNTAXE

alpm-pkginfo create v1 <--pkgname> <--pkgbase> <--pkgver> <--pkgdesc> <--url> <--builddate> <--packager> <--size> <--arch> [--license] [--replaces] [--group] [--conflict] [--provides] [--backup] [--depend] [--optdepend] [--makedepend] [--checkdepend] [-h|--help] [FICHIER]

DESCRIPTION

Créer un fichier PKGINFO version 1

OPTIONS

--pkgname <NOMPAQUET>
Le nom du paquet à utiliser dans le PKGINFO

Le nom du paquet doit suivre le format `alpm-package-name` (voir `man 7 alpm-package-name`).

Peut également être spécifié avec la variable d'environnement PKGINFO_PKGNAME.
--pkgbase <BASEPAQUET>
La base du paquet à utiliser dans le PKGINFO

La base du paquet doit suivre le format `alpm-package-name` (voir `man 7 alpm-package-name`).

Peut également être spécifié avec la variable d'environnement PKGINFO_PKGBASE.
--pkgver <VERPAQUET>
La version du paquet à utiliser dans le PKGINFO

La valeur de la version du paquet doit suivre le format `alpm-pkgver` (voir `man 7 alpm-pkgver`).

Peut également être spécifié avec la variable d'environnement PKGINFO_PKGVER.
--pkgdesc <DESCPAQUET>
La description du paquet à utiliser dans le PKGINFO

La valeur doit suivre le format décrit dans le format PKGINFO (voir `man 5 PKGINFO`).

Peut également être spécifié avec la variable d'environnement PKGINFO_PKGDESC.
--url <URL>
Fournir une URL
Peut également être spécifié avec la variable d'environnement PKGINFO_URL.
--builddate <DATECONSTR>
Fournir une date de construction
Peut également être spécifié avec la variable d'environnement PKGINFO_BUILDDATE.
--packager <EMPAQUETEUR>
Fournir un responsable de paquet
Peut également être spécifié avec la variable d'environnement PKGINFO_PACKAGER.
--size <TAILLE>
Fournir une taille
Peut également être spécifié avec la variable d'environnement PKGINFO_SIZE.
--arch <ARCH>
Fournir une architecture
Peut également être spécifié avec la variable d'environnement PKGINFO_ARCH.
--license <LICENCE>
Fournir une ou plusieurs licences
Peut également être spécifié avec la variable d'environnement PKGINFO_LICENSE.
--replaces <REMPLACE>
Fournir un ou plusieurs remplacements
Peut également être spécifié avec la variable d'environnement PKGINFO_REPLACES.
--group <GROUPE>
Fournir un ou plusieurs groupes
Peut également être spécifié avec la variable d'environnement PKGINFO_GROUP.
--conflict <CONFLIT>
Fournir un ou plusieurs conflits
Peut également être spécifié avec la variable d'environnement PKGINFO_CONFLICT.
--provides <FOURNIT>
Fournir un ou plusieurs éléments fournis
Peut également être spécifié avec la variable d'environnement PKGINFO_PROVIDES.
--backup <SAUVEGARDE>
Fournir une ou plusieurs sauvegardes
Peut également être spécifié avec la variable d'environnement PKGINFO_BACKUP.
--depend <DEPENDANCE>
Fournir une ou plusieurs dépendances
Peut également être spécifié avec la variable d'environnement PKGINFO_DEPEND.
--optdepend <DEPENDOPT>
Fournir une ou plusieurs dépendances optionnelles
Peut également être spécifié avec la variable d'environnement PKGINFO_OPTDEPEND.
--makedepend <DEPCONSTR>
Fournir une ou plusieurs dépendances de construction
Peut également être spécifié avec la variable d'environnement PKGINFO_MAKEDEPEND.
--checkdepend <DEPVERIF>
Fournir une ou plusieurs dépendances de vérification
Peut également être spécifié avec la variable d'environnement PKGINFO_CHECKDEPEND.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
[FICHIER] [par défaut: .PKGINFO]
Un fichier personnalisé optionnel dans lequel écrire
Peut également être spécifié avec la variable d'environnement PKGINFO_OUTPUT_FILE.
