DESCRIPTION

L'objectif de l'espace de noms Alien est de fournir des dépendances non-CPAN (appelées dépendances "Alien") pour les modules CPAN. L'historique et l'intention de cette idée sont documentés dans le module Alien, qui est uniquement destiné à la documentation. La distribution "Alien-Build" fournit un framework pour construire des aliens. L'intention est de corriger les bogues et d'améliorer l'interface d'un certain nombre d'outils courants afin que tous les aliens puissent en bénéficier. La distribution est divisée en ces parties :

L'installateur d'Alien (à la configuration / compilation)
Alien::Build et alienfile sont utilisés pour détecter et installer des aliens. Ils sont documentés plus en détail dans Alien::Build::Manual::AlienAuthor.
L'exécution d'Alien (à l'exécution)
Alien::Base est la classe de base pour les aliens dans le système "Alien-Build". Son utilisation par les consommateurs d'Alien est documentée dans Alien::Build::Manual::AlienUser.
Le système de plugins (à la configuration / compilation)
Étant donné que de nombreux paquets sont implémentés à l'aide de différents outils, la logique de détection, de construction et d'installation pour un Alien particulier peut beaucoup varier. Par conséquent, une grande partie d'Alien::Build est implémentée sous forme d'une série de plugins qui héritent de Alien::Build::Plugin. Un aperçu de la création de vos propres plugins est documenté dans Alien::Build::Manual::PluginAuthor.
