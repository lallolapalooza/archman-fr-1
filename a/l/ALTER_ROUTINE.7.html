ALTER_ROUTINE(7)

Paquet: postgresql

Licences: PostgreSQL

ALTER ROUTINE(7) Documentation PostgreSQL 18.1 ALTER ROUTINE(7)

NOM

ALTER_ROUTINE - modifier la définition d'une routine

SYNTAXE

ALTER ROUTINE nom [ ( [ [ mode_arg ] [ nom_arg ] type_arg [, ...] ] ) ]
    action [ ... ] [ RESTRICT ]
ALTER ROUTINE nom [ ( [ [ mode_arg ] [ nom_arg ] type_arg [, ...] ] ) ]
    RENAME TO nouveau_nom
ALTER ROUTINE nom [ ( [ [ mode_arg ] [ nom_arg ] type_arg [, ...] ] ) ]
    OWNER TO { nouvel_proprietaire | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER ROUTINE nom [ ( [ [ mode_arg ] [ nom_arg ] type_arg [, ...] ] ) ]
    SET SCHEMA nouveau_schema
ALTER ROUTINE nom [ ( [ [ mode_arg ] [ nom_arg ] type_arg [, ...] ] ) ]
    [ NO ] DEPENDS ON EXTENSION nom_extension
où action est l'un des éléments suivants :
    IMMUTABLE | STABLE | VOLATILE
    [ NOT ] LEAKPROOF
    [ EXTERNAL ] SECURITY INVOKER | [ EXTERNAL ] SECURITY DEFINER
    PARALLEL { UNSAFE | RESTRICTED | SAFE }
    COST cout_execution
    ROWS lignes_resultat
    SET parametre_configuration { TO | = } { valeur | DEFAULT }
    SET parametre_configuration FROM CURRENT
    RESET parametre_configuration
    RESET ALL

DESCRIPTION

ALTER ROUTINE modifie la définition d'une routine, qui peut être une fonction d'agrégation, une fonction normale, ou une procédure. Voir sous ALTER AGGREGATE (ALTER_AGGREGATE(7)), ALTER FUNCTION (ALTER_FUNCTION(7)), et ALTER PROCEDURE (ALTER_PROCEDURE(7)) pour la description des paramètres, plus d'exemples et de détails.

EXEMPLES

Pour renommer la routine foo de type integer en foobar :

ALTER ROUTINE foo(integer) RENAME TO foobar;

Cette commande fonctionnera indépendamment du fait que foo soit une agrégation, une fonction ou une procédure.

COMPATIBILITE

Cette instruction est partiellement compatible avec l'instruction ALTER ROUTINE de la norme SQL. Voir sous ALTER FUNCTION (ALTER_FUNCTION(7)) et ALTER PROCEDURE (ALTER_PROCEDURE(7)) pour plus de détails. Permettre aux noms de routine de faire référence à des fonctions d'agrégation est une extension PostgreSQL.

VOIR AUSSI

ALTER AGGREGATE (ALTER_AGGREGATE(7)), ALTER FUNCTION (ALTER_FUNCTION(7)), ALTER PROCEDURE (ALTER_PROCEDURE(7)), DROP ROUTINE (DROP_ROUTINE(7))

Notez qu'il n'y a pas de commande CREATE ROUTINE.
