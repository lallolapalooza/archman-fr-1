NOM

version de paquet - versions de paquets pour les paquets basés sur ALPM.

DESCRIPTION

Le format de version de paquet représente les informations de version pour les paquets basés sur ALPM. Ce format est utilisé dans les scripts de construction ou les formats de fichiers pour les métadonnées de paquets (par exemple, dans PKGBUILD, PKGINFO, SRCINFO, alpm-repo-desc, ou alpm-lib-desc) pour décrire les versions de paquets, ou les versions de composants dans le cadre d'une relation de paquet.

La valeur est représentée par une chaîne de version composite, qui peut se composer de plusieurs composants (alpm-epoch, alpm-pkgver, alpm-pkgrel). Diverses formes de chaînes de version composites existent, mais elles ne sont utilisées que dans des contextes spécifiques.

Pleine

La valeur de cette forme se compose d'un alpm-pkgver, directement suivi d'un signe ‘-’, directement suivi d'un alpm-pkgrel (par exemple, 1.0.0-1). Cette forme de version de paquet ALPM est utilisée dans divers scénarios, tels que :

  • noms de fichiers de paquets
  • expressions de relation de paquet
•
replaces, conflict, provides, depend, makedepend et checkdepend dans les fichiers PKGINFO
  • pkgver dans les fichiers BUILDINFO
  • pkgver dans les fichiers PKGINFO
  • dans le cadre de buildtoolver dans les fichiers BUILDINFOv2
  • dans le cadre de installed dans les fichiers BUILDINFO

Pleine avec époque

La valeur de cette forme se compose d'un alpm-epoch, directement suivi d'un signe ‘:’, directement suivi d'un alpm-pkgver, directement suivi d'un signe ‘-’, directement suivi d'un alpm-pkgrel (par exemple, 1:1.0.0-1). Cette forme de version de paquet ALPM est utilisée dans divers scénarios, tels que :

  • noms de fichiers de paquets
  • expressions de relation de paquet
•
replaces, conflict, provides, depend, makedepend et checkdepend dans les fichiers PKGINFO
  • pkgver dans les fichiers BUILDINFO
  • pkgver dans les fichiers PKGINFO
  • dans le cadre de buildtoolver dans les fichiers BUILDINFOv2
  • dans le cadre de installed dans les fichiers BUILDINFO
  • dans le cadre du contenu de alpm-state-repo

Minimale

La valeur de cette forme se compose d'un alpm-pkgver (par exemple, 1.0.0). Cette forme de version de paquet ALPM est utilisée dans divers scénarios, tels que :

•
expressions de relation de paquet
  • replaces, conflicts, provides, depends, makedepends et checkdepends dans les fichiers PKGBUILD
  • replaces, conflict, provides, depend, makedepend et checkdepend dans les fichiers PKGINFO
  • pkgver dans les fichiers PKGBUILD
  • pkgver dans les fichiers SRCINFO
  • dans le cadre de buildtoolver dans les fichiers BUILDINFOv2

Minimale avec époque

La valeur de cette forme se compose d'un alpm-epoch, directement suivi d'un signe ‘:’, directement suivi d'un alpm-pkgver (par exemple, 1:1.0.0). Cette forme de version de paquet ALPM est utilisée dans divers scénarios, tels que :

•
dans le cadre d'expressions de relation de paquet
  • replaces, conflicts, provides, depends, makedepends et checkdepends dans les fichiers PKGBUILD
  • replaces, conflict, provides, depend, makedepend et checkdepend dans les fichiers PKGINFO
  • pkgver dans les fichiers PKGBUILD
  • pkgver dans les fichiers SRCINFO
  • dans le cadre de buildtoolver dans les fichiers BUILDINFOv2

EXEMPLES

"1.0.0-1"

Une version de paquet complète.

"1:1.0.0-1"

Une version de paquet complète avec époque.

"1.0.0"

Une version de paquet minimale.

"1:1.0.0"

Une version de paquet minimale avec époque.
