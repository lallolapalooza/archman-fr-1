NOM

Alien::Build::Plugin::Prefer::BadVersion - Plugin pour filtrer les versions connues comme étant problématiques

VERSION

version 2.84

SYNOPSIS

use alienfile;
plugin 'Prefer::BadVersion' => '1.2.3';

DESCRIPTION

Ce plugin permet de filtrer facilement les versions connues comme étant problématiques des bibliothèques dans une installation partagée. Il n'affecte pas du tout une installation système. Vous avez besoin d'un plugin Prefer qui filtre et trie les fichiers au préalable. Vous pouvez spécifier le filtre de trois manières:

sous forme de chaîne de caractères
Filtre tous les fichiers correspondant à la version donnée. 
use alienfile;
plugin 'Prefer::BadVersion' => '1.2.3';
sous forme de tableau
Filtre tous les fichiers correspondant à l'une des versions données. 
use alienfile;
plugin 'Prefer::BadVersion' => [ '1.2.3', '1.2.4' ];
sous forme de référence de code
Filtre tous les fichiers retournant une valeur vraie. 
use alienfile;
plugin 'Prefer::BadVersion' => sub {
  my($file) = @_;
  $file->{version} eq '1.2.3'; # identique à la version chaîne ci-dessus
};

Ce plugin peut également être utilisé pour filtrer les versions connues comme problématiques d'une bibliothèque sur une seule plateforme. Par exemple, si vous savez que la version 1.2.3 est problématique sous Windows, mais acceptable sur d'autres plateformes :

use alienfile;
plugin 'Prefer::BadVersion' => '1.2.3' if $^O eq 'MSWin32';

PROPRIÉTÉS

filter

Filtre les entrées qui correspondent au filtre.

AVERTISSEMENTS

Si vous utilisez le mode chaîne ou tableau, vous avez besoin d'un plugin Prefer existant qui définisse le numéro de version pour chaque candidat de fichier, tel que Alien::Build::Plugin::Prefer::SortVersions.

À moins que vous ne vouliez exclure la dernière version d'une installation partagée, ce plugin n'est pas vraiment utile. Il n'a aucun effet sur les installations système, ce qui peut ne pas être évident au premier abord.
