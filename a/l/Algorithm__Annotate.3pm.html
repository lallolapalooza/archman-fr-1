NOM

Algorithm::Annotate - représenter une série de modifications sous forme annotée

SYNOPIS

use Algorithm::Annotate;

my $ann = Algorithm::Annotate->new ();

$ann->add ($info1, \@seq1);

$ann->add ($info2, \@seq2); $ann->add ($info3, \@seq3);

$result = $ann->result;

DESCRIPTION

Algorithm::Annotate génère une liste utile pour produire une sortie similaire à "cvs annotate".

À FAIRE

Pourrait analyser la sortie diff et les accumuler pour générer la liste d'annotations.
