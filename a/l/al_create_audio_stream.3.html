al_create_audio_stream(3) Manuel des fonctions de bibliothèque al_create_audio_stream(3)

NOM

al_create_audio_stream - API Allegro 5

SYNOPSIS

#include <allegro5/allegro_audio.h>
ALLEGRO_AUDIO_STREAM *al_create_audio_stream(size_t fragment_count,
   unsigned int frag_samples, unsigned int freq, ALLEGRO_AUDIO_DEPTH depth,
   ALLEGRO_CHANNEL_CONF chan_conf)

DESCRIPTION

Crée un ALLEGRO_AUDIO_STREAM(3). Le flux sera défini pour jouer par défaut. Il alimentera les données audio à partir d'un tampon, qui est divisé en un certain nombre de fragments.

Paramètres :

•
fragment_count - Nombre de fragments à utiliser pour le flux audio. Généralement, deux fragments suffisent - divisant le tampon audio en deux moitiés. Mais cela signifie que le seul moment où de nouvelles données peuvent être fournies est lorsque l'une des moitiés a fini de jouer. En utilisant de nombreux fragments, vous utiliserez généralement moins d'échantillons pour un seul, donc il y aura toujours de (petits) fragments disponibles pour être remplis de nouvelles données.
•
frag_samples - La taille d'un fragment en échantillons. Voir la note et l'explication ci-dessous.
•
freq - La fréquence, en Hertz.
•
depth - Doit être l'une des valeurs listées pour ALLEGRO_AUDIO_DEPTH(3).
•
chan_conf - Doit être l'une des valeurs listées pour ALLEGRO_CHANNEL_CONF(3).

Un échantillon auquel fait référence le paramètre frag_samples fait référence à une séquence d'intensités de canal. Par exemple, si vous créez un flux stéréo avec frag_samples défini sur 4, alors la disposition des données dans le fragment sera :

LRLRLRLR

Où L et R sont les intensités pour les canaux gauche et droit respectivement. Un seul échantillon, alors, fait référence à la paire LR dans cet exemple.

Le choix de fragment_count, frag_samples et freq influence directement le délai audio. Le délai en secondes peut être exprimé comme :

delay = fragment_count * frag_samples / freq

Ceci n'est que le délai dû au streaming d'Allegro, il peut y avoir un délai supplémentaire causé par les pilotes audio et/ou le matériel.

Note : Si vous connaissez la taille du fragment en octets, vous pouvez obtenir la taille en échantillons comme ceci :

sample_size = al_get_channel_count(chan_conf) * al_get_audio_depth_size(depth);
samples = bytes_per_fragment / sample_size;

La taille du tampon complet est :

buffer_size = bytes_per_fragment * fragment_count

Note : Contrairement à de nombreux objets Allegro, les flux audio ne sont pas automatiquement détruits lorsque Allegro est arrêté. Vous devez les détruire manuellement avec al_destroy_audio_stream(3) avant que le système audio ne soit arrêté.
