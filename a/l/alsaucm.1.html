DESCRIPTIO

N

alsaucm (ALSA Use Case Manager) est un programme permettant d'utiliser l'interface de cas d'utilisation ALSA http://www.alsa-project.org/alsa-doc/alsa-lib/group__ucm.html
depuis la ligne de

commande.

Sur les cartes son complexes, la configuration des itinéraires audio n'est pas triviale et les réglages du mixeur peuvent entrer en conflit les uns avec les autres, empêchant la carte son de fonctionner

correctement.

Le gestionnaire de cas d'utilisation ALSA est un mécanisme permettant de contrôler du matériel audio complexe en établissant une relation entre les configurations matérielles et des cas d'utilisation significatifs auxquels l'utilisateur final peut se

référer.

Le gestionnaire de cas d'utilisation peut également être utilisé pour basculer entre les cas d'utilisation lorsque c'est nécessaire, de manière

cohérente.

À un niveau plus bas, le gestionnaire de cas d'utilisation fonctionne en configurant les kcontrols ALSA de la carte son pour modifier le routage audio numérique et analogique du matériel afin de correspondre au cas d'utilisation

demandé.

Les configurations kcontrol du gestionnaire de cas d'utilisation sont stockées dans des fichiers texte faciles à modifier. Un cas d'utilisation audio peut être défini par un verbe et un paramètre d

evice.

Le verbe décrit l'action du cas d'utilisation, c'est-à-dire un appel téléphonique, l'écoute de mus

ique, l'enregistrement d'une conversation, etc. Le device décrit le matériel physique de capture e
t de lecture audio, c'est-à-dire des écouteurs, un combiné téléphonique, un casque Bluetooth, etc.

FICHIER

S

Les fichiers de cas d'utilisation principaux pour chaque carte son prise en charge se trouvent dans /usr/share/alsa/ucm

.

Par exemple, le fichier de cas d'utilisation principal pour la carte Pandaboard se trouve dans /usr/share/alsa/ucm/PandaBoard/PandaBoard.conf, ce fichier liste tous les cas d'utilisation pris en charge, par

exemple 
SectionUseCase."HiFi" {
                File "hifi"
                Comment "Play HiFi quality Music."
}
.
.
.

Chaque cas d'utilisation définit un _verb, qui est décrit dans le fichier spécifié dans la directive File, comme

ci-dessus.

Le verbe HiFi ci-dessus est décrit dans /usr/share/alsa/ucm/PandaBoard/hifi

.

Pour plus de détails sur la syntaxe des fichiers UCM, consultez le code source d'alsa-lib :
http://git.alsa-project

.org/?p=alsa-lib.git;a=
blob;f=src/ucm/parser.c

EXEMPLES

D'UTILISATION

Certaines commandes, comme par exemple list _devices, ne peuvent fonctionner qu'après avoir défini un _verb dans la même exécution, par exemple cette séquence ne fonctionne pas

: 
# alsaucm -c bytcr-r
t5640 set _verb HiFi
# alsaucm -c bytcr-
rt5640 list _devices

Cependant cette commande fonctionne

: 
# alsaucm -n -b -
<<EOM open bytcr-rt
5640 set _verb HiFi
list _devices EOM

Un exemple de définition du device Speaker pour le verbe HiFi de la carte bytcr-r

t5640 : 
# alsaucm -n -b -
<<EOM open bytcr
-rt5640 reset set
_verb HiFi set _e
nadev Speaker EOM
