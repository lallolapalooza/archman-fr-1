al_set_display_menu(3) Manuel des fonctions de bibliothèque al_set_display_menu(3)

NOM

al_set_display_menu - API Allegro 5

SYNTAXE

#include <allegro5/allegro_native_dialog.h>
bool al_set_display_menu(ALLEGRO_DISPLAY *display, ALLEGRO_MENU *menu)

DESCRIPTION

Associe le menu au display et l'affiche. S'il y avait un menu précédemment associé au display, il sera détruit. Si vous ne souhaitez pas que cela se produise, vous devriez d'abord supprimer le menu avec al_remove_display_menu(3).

Si le menu est déjà attaché à un display, il ne sera pas attaché au nouveau display. Si menu est NULL, le menu actuel sera tout de même détruit.

Note : L'attachement d'un menu peut provoquer le redimensionnement de la fenêtre disponible pour votre application ! Vous devriez écouter un événement de redimensionnement, vérifier l'espace perdu, et redimensionner la fenêtre en conséquence si vous souhaitez conserver la taille précédente de votre fenêtre.

Retourne vrai si l'opération réussit.

DEPUIS

5.1.0

VOIR AUSSI

al_create_menu(3), al_remove_display_menu(3)
