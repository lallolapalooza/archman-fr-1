subroutine alahd (iounit, path)
ALAHD

Documentation de la fonction/sous-programme

sous-programme alahd (entier iounit, caractère*3 path)

ALAHD

Objectif :

!>
!> ALAHD imprime les informations d'en-tête pour les différents chemins de test.
!>

Paramètres

IOUNIT 
!>          IOUNIT est un ENTIER
!>          Le numéro de l'unité vers laquelle les informations d'en-tête doivent être
!>          imprimées.
!>

PATH

!>          PATH est un CARACTÈRE*3
!>          Le nom du chemin pour lequel les informations d'en-tête doivent être
!>          imprimées. Les chemins actuels sont
!>             _GE: Matrices générales
!>             _GB: Bande générale
!>             _GT: Tridiagonale générale
!>             _PO: Définie positive symétrique ou hermitienne
!>             _PS: Semi-définie positive symétrique ou hermitienne
!>             _PP: Emballée définie positive symétrique ou hermitienne
!>             _PB: Bande définie positive symétrique ou hermitienne
!>             _PT: Tridiagonale définie positive symétrique ou hermitienne
!>             _SY: Indéfinie symétrique,
!>                     avec pivotement partiel (Bunch-Kaufman)
!>             _SR: Indéfinie symétrique,
!>                     avec pivotement en tour (Bunch-Kaufman borné)
!>             _SK: Indéfinie symétrique,
!>                     avec pivotement en tour (Bunch-Kaufman borné)
!>                     ( nouveau format de stockage pour les facteurs :
!>                       L et la diagonale de D sont stockées dans A,
!>                       la sous-diagonale de D est stockée dans E )
!>             _SP: Emballée indéfinie symétrique,
!>                     avec pivotement partiel (Bunch-Kaufman)
!>             _HA: Hermitienne (complexe),
!>                     avec algorithme d'Aasen
!>             _HE: Hermitienne indéfinie (complexe),
!>                     avec pivotement partiel (Bunch-Kaufman)
!>             _HR: Hermitienne indéfinie (complexe),
!>                     avec pivotement en tour (Bunch-Kaufman borné)
!>             _HK: Hermitienne indéfinie (complexe),
!>                     avec pivotement en tour (Bunch-Kaufman borné)
!>                     ( nouveau format de stockage pour les facteurs :
!>                       L et la diagonale de D sont stockées dans A,
!>                       la sous-diagonale de D est stockée dans E )
!>             _HP: Emballée hermitienne indéfinie (complexe),
!>                     avec pivotement partiel (Bunch-Kaufman)
!>             _TR: Triangulaire
!>             _TP: Triangulaire emballé
!>             _TB: Triangulaire bande
!>             _QR: QR (matrices générales)
!>             _LQ: LQ (matrices générales)
!>             _QL: QL (matrices générales)
!>             _RQ: RQ (matrices générales)
!>             _QP: QR avec pivotement de colonne
!>             _TZ: Trapézoïdale
!>             _LS: Routines pilotes de moindres carrés
!>             _LU: Variantes LU
!>             _CH: Variantes de Cholesky
!>             _QS: Variantes QR
!>             _QT: QRT (matrices générales)
!>             _QX: QRT (matrices triangulaires-pentagonales)
!>             _TS: Routines QR pour matrices longues-minces et courtes-larges
!>             _HH: Reconstruction de Householder pour matrices longues-minces
!>          Le premier caractère doit être S, D, C ou Z (C ou Z uniquement
!>          si complexe).
!>
