NOM

al_create_index_buffer - API Allegro 5

SYNTAXE

#include <allegro5/allegro_primitives.h>
ALLEGRO_INDEX_BUFFER* al_create_index_buffer(int index_size,
    const void* initial_data, int num_indices, int flags)

DESCRIPTION

Crée un tampon d'indices. Peut retourner NULL si le tampon n'a pas pu être créé (par exemple, le système ne prend en charge que les tampons en écriture seule).

Remarque :

Il s'agit d'une fonctionnalité avancée, souvent non prise en charge par les cartes graphiques d'entrée de gamme. Soyez particulièrement attentif à l'échec de cette fonction et prévoyez des solutions de repli pour le rendu ou un message d'erreur agréable pour les utilisateurs disposant de telles cartes d'entrée de gamme.

Paramètres :

•
index_size - Taille de l'indice en octets. Les tailles prises en charge sont 2 pour les entiers courts et 4 pour les entiers.
•
initial_data - Tampon mémoire à copier pour initialiser le tampon d'indices. Peut être NULL, auquel cas le tampon n'est pas initialisé.
•
num_indices - Nombre d'indices que le tampon contiendra.
•
flags - Une combinaison des drapeaux ALLEGRO_PRIM_BUFFER_FLAGS(3) spécifiant comment ce tampon sera créé. Passer 0 équivaut à passer ALLEGRO_PRIM_BUFFER_STATIC.
