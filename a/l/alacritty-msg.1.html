ALACRITTY-MSG(1) Manuel des commandes générales ALACRITTY-MSG(1)

NOM

alacritty-msg - Envoyer des messages à Alacritty.

SYNTAXE

Cette commande communique avec les instances Alacritty en cours d'exécution via un socket, ce qui permet de contrôler Alacritty sans y accéder directement.

OPTIONS

-s, --socket <SOCKET>

Chemin pour la communication par socket IPC.

MESSAGES

create-window

Crée une nouvelle fenêtre dans le même processus Alacritty.

FLAGS

--hold
Reste ouvert après la sortie du processus enfant.

OPTIONS

--working-directory <REPERTOIRE_DE_TRAVAIL>
Démarre le shell dans le répertoire de travail spécifié.

-T, --title <TITRE>

Définit le titre de la fenêtre.

Par défaut : Alacritty

--class <GENERAL> | <GENERAL>,<INSTANCE>

Définit la classe/app_id de la fenêtre sur X11/Wayland.

Par défaut : Alacritty,Alacritty

-o, --option <OPTION>...

Remplace les options du fichier de configuration.

Exemple : alacritty msg create-window -o 'cursor.style="Beam"'

-e, --command <COMMANDE>...

Commande et arguments à exécuter (doit être le dernier argument).

config

Met à jour la configuration Alacritty.

ARGS

<OPTIONS_CONFIG>...
Options du fichier de configuration.

Exemple : alacritty msg config 'cursor.style="Beam"'

FLAGS

-r, --reset
Efface toutes les modifications de configuration d'exécution.

OPTIONS

-w, --window-id <ID_FENETRE>
ID de la fenêtre pour la nouvelle configuration.

Utilisez -1 pour appliquer ce changement à toutes les fenêtres.

Par défaut : $ALACRITTY_WINDOW_ID

get-config

Lit la configuration Alacritty d'exécution.

OPTIONS

-w, --window-id <ID_FENETRE>
ID de la fenêtre pour la demande de configuration.

Utilisez -1 pour obtenir la configuration globale.

Par défaut : $ALACRITTY_WINDOW_ID
