NOM

Alien::Build::Plugin::Build::SearchDep - Ajoute les dépendances au chemin de recherche des bibliothèques et des en-têtes

VERSION

version 2.84

SYNTAXE

use alienfile;
plugin 'Build::SearchDep' => (
  aliens => [qw( Alien::Foo Alien::Bar )],
);

DESCRIPTION

Ce plugin ajoute les autres aliens comme prérequis, et ajoute leur chemin de recherche des en-têtes et des bibliothèques aux variables d'environnement "CFLAGS" et "LDFLAGS", afin que les outils qui les utilisent (comme autoconf) puissent les trouver.

PROPRIETES

aliens

Soit une référence à une liste, soit une référence à un tableau associatif des autres aliens. Si c'est une référence à un tableau associatif, alors les clés sont les noms des classes et les valeurs sont les versions de ces classes.

public_I

Inclut les indicateurs "-I" lors de la définition de la propriété des cflags d'exécution.

public_l

Inclut les indicateurs "-l" lors de la définition de la propriété des libs d'exécution.
