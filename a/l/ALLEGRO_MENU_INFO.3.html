ALLEGRO_MENU_INFO(3) Manuel des fonctions de bibliothèque ALLEGRO_MENU_INFO(3)

NOM

ALLEGRO_MENU_INFO - API Allegro 5

SYNTAXE

#include <allegro5/allegro_native_dialog.h>
typedef struct ALLEGRO_MENU_INFO {

DESCRIPTION

Une structure qui définit comment créer un système de menu complet. Pour les éléments de menu standard, le format suivant est utilisé :

   { légende, id, indicateurs, icône }

Pour les éléments spéciaux, ces macros sont utiles :

ALLEGRO_START_OF_MENU(légende, id)
ALLEGRO_MENU_SEPARATOR
ALLEGRO_END_OF_MENU

Un menu bien défini commencera par ALLEGRO_START_OF_MENU, contiendra un ou plusieurs éléments de menu et se terminera par ALLEGRO_END_OF_MENU. Un menu peut contenir des sous-menus. Un exemple :

ALLEGRO_MENU_INFO menu_info[] = {
   ALLEGRO_START_OF_MENU("&Fichier", 1),
      { "&Ouvrir", 2, 0, NULL },
      ALLEGRO_START_OF_MENU("Ouvrir les &récents...", 3),
         { "Récents 1", 4, 0, NULL },
         { "Récents 2", 5, 0, NULL },
         ALLEGRO_END_OF_MENU,
      ALLEGRO_MENU_SEPARATOR,
      { "Q&uitter", 6, 0, NULL },
      ALLEGRO_END_OF_MENU,
   ALLEGRO_START_OF_MENU("&Aide", 7),
      {"&À propos", 8, 0, NULL },
      ALLEGRO_END_OF_MENU,
   ALLEGRO_END_OF_MENU
};
ALLEGRO_MENU *menu = al_build_menu(menu_info);

Si vous préférez, vous pouvez construire le menu sans la structure en utilisant al_create_menu(3) et al_insert_menu_item(3).
