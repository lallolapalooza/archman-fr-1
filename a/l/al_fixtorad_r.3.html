NOM

al_fixtorad_r - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
const al_fixed al_fixtorad_r = (al_fixed)1608;

DESCRIPTION

Cette constante donne un rapport qui peut être utilisé pour convertir un nombre en virgule fixe au format d'angle binaire en un nombre en virgule fixe en radians.

Exemple :

al_fixed rad_angle, binary_angle;
/* Définir l'angle binaire à 90 degrés. */
binary_angle = 64;
/* Convertir maintenant en radians (environ 1.57). */
rad_angle = al_fixmul(binary_angle, al_fixtorad_r);

VOIR AUSSI

al_fixmul(3), al_radtofix_r(3).
