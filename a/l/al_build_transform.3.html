al_build_transform(3) Manuel des fonctions de bibliothèque al_build_transform(3)

NOM

al_build_transform - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
void al_build_transform(ALLEGRO_TRANSFORM *trans, float x, float y,
   float sx, float sy, float theta)

DESCRIPTION

Construit une transformation à partir de certains paramètres. Cet appel est équivalent à appeler les transformations dans cet ordre : identité, rotation, mise à l'échelle, translation. Cependant, cette méthode est plus rapide que d'appeler réellement ces fonctions.

Paramètres :

•
trans - Transformation à modifier
•
x, y - Translation
•
sx, sy - Mise à l'échelle
•
theta - Angle de rotation en radians

Remarque : cette fonction était auparavant documentée comme étant équivalente à un ordre d'opérations différent (et plus utile) : identité, mise à l'échelle, rotation, translation.
