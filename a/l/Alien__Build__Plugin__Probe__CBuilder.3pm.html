NOM

Alien::Build::Plugin::Probe::CBuilder - Sonde les bibliothèques système en devinant avec ExtUtils::CBuilder

VERSION

version 2.84

SYNOPSIS

use alienfile;
plugin 'Probe::CBuilder' => (
  cflags => '-I/opt/libfoo/include',
  libs   => '-L/opt/libfoo/lib -lfoo',
);

alternativement:

ues alienfile;
plugin 'Probe::CBuilder' => (
  aliens => [ 'Alien::libfoo', 'Alien::libbar' ],
);

DESCRIPTION

Ce plugin sonde les indicateurs du compilateur et de l'éditeur de liens en utilisant ExtUtils::CBuilder. C'est une alternative utile à Alien::Build::Plugin::PkgConfig::Negotiate pour les paquets qui ne fournissent pas de fichier ".pc" de pkg-config, ou pour lorsque ces fichiers ".pc" peuvent ne pas être disponibles. (Par exemple, sur FreeBSD, "libarchive" fait partie intégrante du système d'exploitation, mais n'inclut pas de fichier ".pc" qui est généralement fourni lorsque vous installez le paquet "libarchive" sous Linux).

PROPRIÉTÉS

options

Toute option supplémentaire que vous souhaitez passer au constructeur de ExtUtils::CBuilder.

cflags

Les indicateurs du compilateur.

libs

Les indicateurs de l'éditeur de liens.

program

Le programme à utiliser dans le test.

version

Ceci est une expression régulière pour analyser la version à partir de la sortie du programme de test.

atleast_version

La version minimale requise telle que fournie par le système.

aliens

Liste des aliens à interroger pour obtenir les indicateurs du compilateur et de l'éditeur de liens.

lang

La langue de programmation à utiliser. L'un des choix possibles est "C" ou "C++".
