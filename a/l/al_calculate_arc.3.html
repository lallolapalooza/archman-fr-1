al_calculate_arc(3)

al_calculate_arc(3) Manuel des fonctions de bibliothèque al_calculate_arc(3)

NOM

al_calculate_arc - API Allegro 5

SYNOPIS

#include <allegro5/allegro_primitives.h>
void al_calculate_arc(float* dest, int stride, float cx, float cy,
   float rx, float ry, float start_theta, float delta_theta, float thickness,
   int num_points)

DESCRIPTION

Lorsque thickness <= 0 cette fonction calcule les positions de num_points points espacés régulièrement sur un arc elliptique. Lorsque thickness > 0 cette fonction calcule deux ensembles de points, obtenus comme suit : le premier ensemble est obtenu en prenant les points calculés dans le cas thickness <= 0 et en les décalant de thickness / 2 vers l'extérieur, dans une direction perpendiculaire à la courbe de l'arc. Le second ensemble est le même, mais décalé de thickness / 2 vers l'intérieur par rapport à l'arc. Les deux ensembles de points sont entrelacés dans le buffer de destination (c'est-à-dire que la première paire de points sera colinéaire avec le centre de l'arc, le premier point de la paire sera plus éloigné du centre que le second point ; la paire suivante sera également colinéaire, mais à un angle différent, et ainsi de suite).

Le buffer de destination dest est interprété comme un ensemble de paires de flottants espacés régulièrement, chaque paire contenant les coordonnées du point correspondant sur l'arc. Les deux flottants de la paire sont adjacents, et la distance (en octets) entre les adresses du premier flottant de deux paires successives est stride. Par exemple, si vous avez un tableau compact de flottants sans espace entre les paires, alors stride sera exactement 2 * sizeof(float).

Exemple avec thickness <= 0 :

const int num_points = 4;
float points[num_points][2];
al_calculate_arc(&points[0][0], 2 * sizeof(float), 0, 0, 10, 10, 0, ALLEGRO_PI / 2, 0, num_points);
assert((int)points[0][0] == 10);
assert((int)points[0][1] == 0);
assert((int)points[num_points - 1][0] == 0);
assert((int)points[num_points - 1][1] == 10);

Exemple avec thickness > 0 :

const int num_points = 4;
float points[num_points * 2][2];
al_calculate_arc(&points[0][0], 2 * sizeof(float), 0, 0, 10, 10, 0, ALLEGRO_PI / 2, 2, num_points);
assert((int)points[0][0] == 11);
assert((int)points[0][1] == 0);
assert((int)points[1][0] == 9);
assert((int)points[1][1] == 0);
assert((int)points[(num_points - 1) * 2][0] == 0);
assert((int)points[(num_points - 1) * 2][1] == 11);
assert((int)points[(num_points - 1) * 2 + 1][0] == 0);
assert((int)points[(num_points - 1) * 2 + 1][1] == 9);

Paramètres :

•
dest - Le buffer de destination
•
stride - Distance (en octets) entre le début de paires de points successives
•
cx, cy - Centre de l'arc
•
rx, ry - Rayons de l'arc
•
start_theta - L'angle initial à partir duquel l'arc est calculé en radians
•
delta_theta - L'envergure angulaire de l'arc en radians (passez un nombre négatif pour changer de direction)
•
thickness - L'épaisseur de l'arc
•
num_points - Le nombre de points à calculer
