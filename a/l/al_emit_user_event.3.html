al_emit_user_event(3) Manuel des fonctions de bibliothèque al_emit_user_event(3)

NOM

al_emit_user_event - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
bool al_emit_user_event(ALLEGRO_EVENT_SOURCE *src,
   ALLEGRO_EVENT *event, void (*dtor)(ALLEGRO_USER_EVENT *))

DESCRIPTION

Émettre un événement à partir d'une source d'événements utilisateur. La source d'événements doit avoir été initialisée avec al_init_user_event_source(3). Renvoie false si la source d'événements n'est enregistrée dans aucune file d'attente, par conséquent l'événement n'aurait pas été livré dans aucune file d'attente.

Les événements sont copiés dans et hors des files d'attente d'événements, donc après le retour de cette fonction, la mémoire pointée par event peut être libérée ou réutilisée. Certains champs de l'événement passé peuvent être modifiés par la fonction.

Le comptage de références sera effectué si dtor n'est pas NULL. Chaque fois qu'une copie de l'événement est faite, le compteur de références augmente. Vous devez appeler al_unref_user_event(3) pour diminuer le compteur de références une fois que vous avez terminé avec un événement utilisateur que vous avez reçu de al_get_next_event(3), al_peek_next_event(3), al_wait_for_event(3), etc.

Une fois que le compteur de références tombe à zéro, dtor sera appelé avec une copie de l'événement en tant qu'argument. Il devrait libérer les ressources associées à l'événement, mais pas l'événement lui-même (puisqu'il ne s'agit que d'une copie).

Si dtor est NULL, alors le comptage de références ne sera pas effectué. Il est sûr, mais inutile, d'appeler al_unref_user_event(3) sur des événements utilisateur non comptés en référence.

Vous pouvez utiliser al_emit_user_event pour émettre des événements utilisateur et non utilisateur à partir de votre source d'événements utilisateur. Notez que l'émission d'événements d'entrée ne mettra pas à jour les états correspondants des périphériques d'entrée. Par exemple, vous pouvez émettre un événement de type ALLEGRO_EVENT_KEY_DOWN(3), mais cela ne mettra pas à jour le ALLEGRO_KEYBOARD_STATE(3) renvoyé par al_get_keyboard_state(3).

VOIR AUSSI

ALLEGRO_USER_EVENT(3), al_unref_user_event(3)
