al_upload_haptic_effect(3) Manuel des fonctions de bibliothèque al_upload_haptic_effect(3)

NOM

al_upload_haptic_effect - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
bool al_upload_haptic_effect(ALLEGRO_HAPTIC *hap,
   ALLEGRO_HAPTIC_EFFECT *effect, ALLEGRO_HAPTIC_EFFECT_ID *id)

DESCRIPTION

Charge l'effet haptique sur le périphérique. L'effet haptique doit être rempli complètement et correctement. Vous devez également passer un pointeur vers un ALLEGRO_HAPTIC_EFFECT_ID(3) alloué par l'utilisateur. Cet id peut être utilisé pour contrôler la lecture de l'effet. Renvoie vrai si l'effet a été chargé avec succès, faux sinon.

La fonction al_get_max_haptic_effects(3) renvoie le nombre d'effets pouvant être chargés simultanément sur le périphérique.

Le même effet haptique peut être chargé plusieurs fois, tant que l'on prend soin de passer un ALLEGRO_HAPTIC_EFFECT_ID(3) différent.

DEPUIS

5.1.8

[API instable]: Peut-être pourrait-elle être simplifiée en raison du support limité de toutes les fonctionnalités exposées sur toutes les plateformes. Attend des retours des utilisateurs.
