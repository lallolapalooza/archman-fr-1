NOM

alpm-pkginfo-create - Créer un fichier PKGINFO selon un schéma

SYNTAXE

alpm-pkginfo create [-h|--help] <sous-commandes>

DESCRIPTION

Créer un fichier PKGINFO selon un schéma

Si l'entrée peut être validée selon le schéma, le programme écrit un fichier PKGINFO valide et se termine sans aucune sortie et avec un code de retour de 0. Si l'entrée ne peut pas être validée selon le schéma, une erreur est émise sur stderr et le programme se termine avec un code de sortie non nul.

OPTIONS

-h, --help
Afficher l'aide (voir un résumé avec '-h')

SOUS-COMMANDES

alpm-pkginfo-create-v1(1)
Créer un fichier PKGINFO version 1
alpm-pkginfo-create-v2(1)
Créer un fichier PKGINFO version 2

Afficher ce message ou l'aide des sous-commandes données
