al_read_directory(3) Manuel des fonctions de bibliothèque al_read_directory(3)

NOM

al_read_directory - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
ALLEGRO_FS_ENTRY *al_read_directory(ALLEGRO_FS_ENTRY *e)

DESCRIPTION

Lit le prochain élément du répertoire et retourne une entrée du système de fichiers pour celui-ci.

Retourne NULL s'il n'y a plus d'entrées ou si une erreur survient. Appelez al_destroy_fs_entry(3) sur l'entrée retournée lorsque vous avez fini avec elle.

Cette fonction ignore tous les fichiers ou répertoires nommés . ou .. qui peuvent exister sur certaines plateformes et qui peuvent signifier le répertoire courant et parent.

VOIR AUSSI

al_open_directory(3), al_close_directory(3)
