ALLEGRO_USER_EVENT(3) Manuel des fonctions de bibliothèque ALLEGRO_USER_EVENT(3)

NOM

ALLEGRO_USER_EVENT - API Allegro 5

SYNTAXE

#include <allegro5/allegro.h>
typedef struct ALLEGRO_USER_EVENT ALLEGRO_USER_EVENT;

DESCRIPTION

Une structure d'événement qui peut être émise par des sources d'événements utilisateurs. Ce sont les champs publics :

•
ALLEGRO_EVENT_SOURCE *source;
•
intptr_t data1;
•
intptr_t data2;
•
intptr_t data3;
•
intptr_t data4;

Comme tous les autres types d'événements, cette structure fait partie de l'union ALLEGRO_EVENT. Pour accéder aux champs d'une variable ALLEGRO_EVENT ev, vous utiliseriez :

•
ev.user.source
•
ev.user.data1
•
ev.user.data2
•
ev.user.data3
•
ev.user.data4

Pour créer un nouvel événement utilisateur, vous feriez ceci :

ALLEGRO_EVENT_SOURCE my_event_source;
ALLEGRO_EVENT my_event;
float some_var;
al_init_user_event_source(&my_event_source);
my_event.user.type = ALLEGRO_GET_EVENT_TYPE('M','I','N','E');
my_event.user.data1 = 1;
my_event.user.data2 = &some_var;
al_emit_user_event(&my_event_source, &my_event, NULL);

Les identifiants de type d'événement pour les événements utilisateurs sont attribués par l'utilisateur. Veuillez consulter la documentation de ALLEGRO_GET_EVENT_TYPE(3) pour connaître les règles que vous devriez suivre lors de l'attribution d'identifiants.

VOIR AUSSI

al_emit_user_event(3), ALLEGRO_GET_EVENT_TYPE(3), al_init_user_event_source(3)
