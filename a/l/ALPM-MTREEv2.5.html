(5) Manuel des formats de fichiers (5)

NOM

ALPM-MTREE - Format de description de la hiérarchie des répertoires de paquets.

DESCRIPTION

Le format mtree est un format textuel qui décrit la hiérarchie et les métadonnées des fichiers d'un répertoire.

mtree est un format bien connu qui peut être utilisé, par exemple, pour les instructions d'installation ou pour vérifier les métadonnées des fichiers et la hiérarchie d'un répertoire.

Le format ALPM-MTREE adhère à la spécification officielle mtree. Cependant, les fichiers .MTREE utilisés dans le contexte des paquets ALPM n'utilisent qu'un sous-ensemble du format officiel mtree qui a du sens dans le cadre de l'empaquetage.

Propriétés

Les fichiers .MTREE générés par makepkg ne contiennent que les propriétés suivantes :

  • type
  • uid
  • gid
  • mode
  • time
  • size
  • md5
  • sha256
  • link

De plus, comme les fichiers mtree sont utilisés dans le cadre de l'empaquetage Arch Linux et se rapportent toujours aux fichiers à l'intérieur des paquets Arch Linux. Pour cette raison, tous les chemins dans un ALPM-MTREE doivent être relatifs au paquet, à l'exception des destinations de liens, qui peuvent pointer à l'extérieur d'un paquet.

Propriété Chemin Type

Contrairement à tous les types disponibles dans mtree, ALPM-MTREE n'autorise que trois types de fichiers :

  • dir Un répertoire
  • file Un fichier
  • link Un lien symbolique

Les autres types sont interdits, car ils ne devraient pas être inclus dans le paquet.

Champs Requis par Type de Fichier

ALPM-MTREE requiert que des valeurs spécifiques soient définies pour certains types de fichiers, ce que mtree n'impose pas par spécification.

Le type de chemin dir nécessite que les propriétés suivantes soient définies :

  • path
  • uid
  • gid
  • mode
  • time

Le type de chemin file nécessite que les propriétés suivantes soient définies :

  • path
  • uid
  • gid
  • mode
  • size
  • md5_digest
  • sha256_digest
  • time

Le type de chemin link nécessite que les propriétés suivantes soient définies :

  • path
  • uid
  • gid
  • mode
  • link
  • time

Utilisation dans Pacman

Dans Pacman, les fichiers ALPM-MTREE sont uniquement utilisés pour vérifier que les fichiers installés sont identiques aux fichiers originaux, sans avoir à conserver le paquet original. Les fichiers .MTREE sont générés implicitement et inclus lors de la création de paquets via makepkg. Le fichier .MTREE compressé par gzip est situé à la racine des paquets basés sur ALPM.

Versionnement

Le format ALPM-MTREE existe en plusieurs versions. Les informations contenues dans ce document concernent la version 2, qui est la version actuelle. Elle a été introduite avec la sortie de pacman 6.1.0 le 2024-03-04.

Changements depuis la dernière version

Le champ md5 n'est plus généré, ce qui constitue effectivement un changement non rétrocompatible.

EXEMPLES

#mtree
/set type=file uid=0 gid=0 mode=644
./.BUILDINFO time=1696727741.0 size=5574 sha256digest=708be566788a6a2712bcd40425d93761569ede07371781374edb1f22e2a3eb96
./.PKGINFO time=1696727741.0 size=830 sha256digest=3aa17bec02b34c157e7c739c62e0e37a9d19f1459d404d7c6f2c14c6008127cd
/set mode=755 type=dir
./usr time=1731613789.0
./usr/bin time=1731613789.0
./usr/bin/resolvconf time=1731613789.0 mode=777 type=link link=resolvectl

Génération

Les fichiers mtree d'ALPM sont générés en appelant :

bsdtar \
  --format=mtree \
  --options='!all,use-set,type,uid,gid,mode,time,size,sha256,link' \
  $folder

Utilisations

Dans le contexte d'ALPM et de pacman, le fichier mtree a pour principal objectif de fournir un moyen performant d'obtenir les métadonnées des fichiers d'un paquet sans avoir à extraire et lire le paquet entier.

Ces données sont ensuite utilisées pour vérifier les fichiers installés sur le système cible par rapport aux fichiers originaux du paquet. Consultez la fonctionnalité de vérification des requêtes de pacman pour plus de détails.
