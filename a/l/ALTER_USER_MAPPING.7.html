ALTER USER MAPPING(7) Documentation PostgreSQL 18.1 ALTER USER MAPPING(7)

NOM

ALTER_USER_MAPPING - modifier la définition d'une correspondance utilisateur

SYNTAXE

ALTER USER MAPPING FOR { nom_utilisateur | USER | CURRENT_ROLE | CURRENT_USER | SESSION_USER | PUBLIC }
    SERVER nom_serveur
    OPTIONS ( [ ADD | SET | DROP ] option ['valeur'] [, ... ] )

DESCRIPTION

ALTER USER MAPPING modifie la définition d'une correspondance utilisateur.

Le propriétaire d'un serveur étranger peut modifier les correspondances utilisateur pour ce serveur pour n'importe quel utilisateur. De plus, un utilisateur peut modifier une correspondance utilisateur pour son propre nom d'utilisateur si le privilège USAGE sur le serveur a été accordé à l'utilisateur.

PARAMÈTRES

nom_utilisateur

Nom d'utilisateur de la correspondance. CURRENT_ROLE, CURRENT_USER et USER correspondent au nom de l'utilisateur actuel. PUBLIC est utilisé pour correspondre à tous les noms d'utilisateur présents et futurs dans le système.

nom_serveur

Nom du serveur de la correspondance utilisateur.

OPTIONS ( [ ADD | SET | DROP ] option ['valeur'] [, ... ] )

Modifie les options de la correspondance utilisateur. Les nouvelles options remplacent toutes les options précédemment spécifiées. ADD, SET et DROP spécifient l'action à effectuer. ADD est supposé si aucune opération n'est explicitement spécifiée. Les noms d'options doivent être uniques ; les options sont également validées par le wrapper de données étrangères du serveur.

EXEMPLES

Modifiez le mot de passe pour la correspondance utilisateur bob, serveur foo :

ALTER USER MAPPING FOR bob SERVER foo OPTIONS (SET password 'public');

COMPATIBILITÉ

ALTER USER MAPPING est conforme à la norme ISO/IEC 9075-9 (SQL/MED). Il y a une subtile problème de syntaxe : La norme omet le mot-clé FOR. Étant donné que CREATE USER MAPPING et DROP USER MAPPING utilisent FOR dans des positions analogues, et qu'IBM DB2 (étant l'autre implémentation majeure de SQL/MED) l'exige également pour ALTER USER MAPPING, PostgreSQL diverge de la norme ici dans l'intérêt de la cohérence et de l'interopérabilité.

VOIR AUSSI

CREATE USER MAPPING (CREATE_USER_MAPPING(7)), DROP USER MAPPING (DROP_USER_MAPPING(7))
