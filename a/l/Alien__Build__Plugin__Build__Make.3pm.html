NOM

Alien::Build::Plugin::Build::Make - Plugin Make pour Alien::Build

VERSION

version 2.84

SYNOPSIS

use alienfile;
# Pour une recette qui nécessite GNU Make
plugin 'Build::Make' => 'gmake';

DESCRIPTION

Par défaut, Alien::Build fournit une aide pour le « make » utilisé par Perl et ExtUtils::MakeMaker lui-même. C'est pratique, car c'est le make dont vous pouvez être presque certain de disposer. Malheureusement, il peut s'agir d'un « make » non pris en charge par la bibliothèque ou l'outil que vous essayez d'aliéner. C'est surtout un problème sous Windows, où les « make » pris en charge pendant des années étaient « nmake » de Microsoft et « dmake » de Sun, que de nombreux projets open source n'utilisent pas. Ce plugin modifiera la recette alienfile pour utiliser un « make » différent. Il peut (comme dans le cas de « gmake » / Alien::gmake) télécharger et installer automatiquement une version aliénée de ce « make » s'il n'est pas déjà installé.

Ce plugin ne doit PAS être utilisé avec d'autres plugins qui remplacent l'aide « make », comme Alien::Build::Plugin::Build::CMake, Alien::Build::Plugin::Build::Autoconf, Alien::Build::Plugin::Build::MSYS. Ce plugin est destiné aux projets qui utilisent des makefiles standards d'un type spécifique.

Ce plugin est pour l'instant distribué séparément d'Alien::Build, mais l'intention est qu'il devienne bientôt un plugin principal pour Alien::Build.

PROPRIÉTÉS

type_make

Le type de make requis par la recette alienfile :

dmake
dmake de Sun.
gmake
GNU Make.
nmake
nmake de Microsoft. Il est fourni avec Visual C++.
umake
Tout « make » UNIX. Généralement soit BSD, soit GNU Make.

AIDE

make

%{make}

Ce plugin peut modifier l'aide make utilisée par votre recette alienfile.
