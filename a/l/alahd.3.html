Documentation de la fonction/sous-programme

sous-programme alahd (entier iounit, caractere*3 path)

ALAHD

Objectif :

!>
!> ALAHD imprime les informations d'en-tête pour les différents chemins de test.
!>

Paramètres

IOUNIT 
!>          IOUNIT est ENTIER
!>          Le numéro de l'unité sur laquelle les informations d'en-tête doivent être
!>          imprimées.
!>

PATH

!>          PATH est CARACTERE*3
!>          Le nom du chemin pour lequel les informations d'en-tête doivent être
!>          imprimées. Les chemins actuels sont
!>             _GE: Matrices générales
!>             _GB: Bande générale
!>             _GT: Triangulaire générale
!>             _PO: Définie positive symétrique ou hermitienne
!>             _PS: Semi-définie positive symétrique ou hermitienne
!>             _PP: Emballée définie positive symétrique ou hermitienne
!>             _PB: Bande définie positive symétrique ou hermitienne
!>             _PT: Triangulaire définie positive symétrique ou hermitienne
!>             _SY: Indéfinie symétrique,
!>                     avec pivotement partiel (Bunch-Kaufman)
!>             _SR: Indéfinie symétrique,
!>                     avec pivotement de tour (Bunch-Kaufman borné)
!>             _SK: Indéfinie symétrique,
!>                     avec pivotement de tour (Bunch-Kaufman borné)
!>                     ( nouveau format de stockage pour les facteurs :
!>                       L et la diagonale de D sont stockées dans A,
!>                       la sous-diagonale de D est stockée dans E )
!>             _SP: Emballée indéfinie symétrique,
!>                     avec pivotement partiel (Bunch-Kaufman)
!>             _HA: (complexe) Hermitienne,
!>                     avec algorithme d'Aasen
!>             _HE: (complexe) Indéfinie hermitienne,
!>                     avec pivotement partiel (Bunch-Kaufman)
!>             _HR: (complexe) Indéfinie hermitienne,
!>                     avec pivotement de tour (Bunch-Kaufman borné)
!>             _HK: (complexe) Indéfinie hermitienne,
!>                     avec pivotement de tour (Bunch-Kaufman borné)
!>                     ( nouveau format de stockage pour les facteurs :
!>                       L et la diagonale de D sont stockées dans A,
!>                       la sous-diagonale de D est stockée dans E )
!>             _HP: (complexe) Emballée indéfinie hermitienne,
!>                     avec pivotement partiel (Bunch-Kaufman)
!>             _TR: Triangulaire
!>             _TP: Emballée triangulaire
!>             _TB: Bande triangulaire
!>             _QR: QR (matrices générales)
!>             _LQ: LQ (matrices générales)
!>             _QL: QL (matrices générales)
!>             _RQ: RQ (matrices générales)
!>             _QP: QR avec pivotement de colonnes
!>             _TZ: Trapézoïdale
!>             _LS: Routines de pilote de moindres carrés
!>             _LU: Variantes LU
!>             _CH: Variantes Cholesky
!>             _QS: Variantes QR
!>             _QT: QRT (matrices générales)
!>             _QX: QRT (matrices triangulaires-pentagonales)
!>             _TS: Routines QR pour matrices fines et larges
!>             _HH: Reconstruction de Householder pour matrices fines
!>          Le premier caractère doit être l'un de S, D, C, ou Z (C ou Z uniquement
!>          si complexe).
!>
