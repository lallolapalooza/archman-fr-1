DESCRIPTIO

N

AL est le lien d'assemblage

Mono.

Ce lien est utilisé pour assembler des assemblages à partir d'une collection de modules (fichiers .netmodule), de fichiers de manifeste d'assemblage et de

ressources.

Ne pas confondre avec monolinker, qui est un outil pour réduire la taille des assemblages en fonction du code

utilisé.

Utilisez al pour traiter les as

semblages 1.0, utilisez al2 po
ur traiter les assemblages 2.0.

OPTION

S
@<nomdefichi
er>
Lire le fichier de réponse pour plus
d'options.
-algid:
<id>
Algorithme utilisé pour hacher les fichiers. Le <id> doit être spécifié en
hexadécimal.
-base:<adresse> | -baseaddress:
<adresse>
Adresse de base de la bibliothèque. CETTE FONCTIONALITÉ N'EST PAS
IMPLÉMENTÉE.
-bugreport:
<nomdefichier>
Créer un fichier de « Rapport de bogue ». CETTE FONCTIONALITÉ N'EST PAS
IMPLÉMENTÉE.
-comp:<texte> | -company:
<texte>
Ceci insère le nom de la société dans les métadonnées de l'assemblage. Cela équivaut à ajouter l'attribut [AssemblyCompany ("<texte>")] dans le code source
C#.
-config:<texte> | -configuration:
<texte>
Ceci insère la chaîne de configuration dans les métadonnées de l'assemblage. Cela équivaut à ajouter l'attribut [AssemblyConfiguration ("<texte>")] dans le code source
C#.
-copy:<texte> | -copyright:
<texte>
Ceci insère le message de copyright dans les métadonnées de l'assemblage. Cela équivaut à ajouter l'attribut [AssemblyCopyright ("<texte>")] dans le code source
C#.
-c:<texte> | -culture:
<texte>
Ceci insère la culture prise en charge dans les métadonnées de l'assemblage. Cela équivaut à ajouter l'attribut [AssemblyCulture ("<texte>")] dans le code source
C#.
-delay | -delay+ | -delaysign |
-delaysign+
L'assemblage généré sera signé avec délai. Cela équivaut à ajouter l'attribut [AssemblyDelaySignAttribute (true)] dans le code source
C#.
-delay- |
-delaysign-
L'assemblage généré sera entièrement signé (c'est-à-dire sans signature avec délai). C'est l'option par défaut lors de la signature (-keyfile ou -keyname)
.
-descr:<texte> | -description:
<texte>
Ceci insère une description de l'assemblage dans les métadonnées de l'assemblage. Cela équivaut à ajouter l'attribut [AssemblyDescription ("<texte>")] dans le code source
C#.
-e:<nomdefichier> | -evidence:
<nomdefichier>
Ceci intègre dans l'assemblage le fichier spécifié en tant que preuves de sécurité de
l'assemblage.
-version:
<version>
Version Win32 facultative. Cela remplace la version normale de
l'assemblage.
-flags:
<drapeaux>
Drapeaux de l'assemblage. Les <drapeaux> doivent être spécifiés en
hexadécimal.
-fullpat
hs
Afficher les fichiers en utilisant des noms de fichiers entièrement
qualifiés.
-keyf:<nomdefichier> | -keyfile:
<nomdefichier>
Signer (strongname) l'assemblage de sortie avec la paire de clés présente dans le fichier de clé de nom fort (snk) spécifié. Une paire de clés complète est requise, sauf si l'option de signature avec délai est également spécifiée (-delay+). Cela équivaut à ajouter l'attribut [AssemblyKeyFile ("<texte>")] dans le code source
C#.
-keyn:<texte> | -keyname:
<texte>
Signer (strongname) l'assemblage de sortie avec la paire de clés présente dans le conteneur spécifié. La signature avec délai n'est pas prise en charge lors de l'utilisation de conteneurs de clés. Cela équivaut à ajouter l'attribut [AssemblyKeyName ("<texte>")] dans le code source
C#.
-main:
<méthode>
Spécifie le nom de la méthode du point d'entrée de
l'assemblage.
-nolo
go
Supprimer la bannière de démarrage et le message de
copyright.
-out:
<nomdefichier>
Nom du fichier de sortie pour le manifeste de
l'assemblage.
-prod:<texte> | product:
<texte>
Ceci insère le nom du produit dans les métadonnées de l'assemblage. Cela équivaut à ajouter l'attribut [AssemblyProduct ("<texte>")] dans le code source
C#.
-productv[ersion]:
<texte>
Ceci insère la version du produit dans les métadonnées de l'assemblage. Cela équivaut à ajouter l'attribut [AssemblyInformationalVersion ("<texte>")] dans le code source
C#.
-t[arget]:<cible> |
-target=<cible>
Les <cible>s valides sont : lib | library pour créer une bibliothèque (.dll), exe pour créer un exécutable en mode console (.exe), et win | winexe pour créer un exécutable Windows (.
exe).
-template:
<nomdefichier>
Spécifie un assemblage à partir duquel obtenir les options par
défaut.
-title:
<texte>
Ceci insère un titre d'assemblage dans les métadonnées de l'assemblage. Cela équivaut à ajouter l'attribut [AssemblyTitle ("<texte>")] dans le code source
C#.
-trade:<texte> | -trademark:
<texte>
Ceci insère un message de marque déposée dans les métadonnées de l'assemblage. Cela équivaut à ajouter l'attribut [AssemblyTrademark ("<texte>")] dans le code source
C#.
-v:<version> | -version:
<version>
Ceci insère la version de l'assemblage dans les métadonnées de l'assemblage. Vous pouvez utiliser * pour générer automatiquement les nombres restants. Cela équivaut à ajouter l'attribut [AssemblyVersion ("<texte>")] dans le code source
C#.
-win32icon:
<nomdefichier>
Utiliser cette icône pour la
sortie.
-win32res:
<nomdefichier>
Spécifie le fichier de ressources
Win32.
