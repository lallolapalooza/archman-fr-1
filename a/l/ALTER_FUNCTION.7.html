DESCRIPTIO

N

ALTER FUNCTION modifie la définition d'une

fonction.

Vous devez être propriétaire de la fonction pour utiliser ALTER FUNCTION. Pour modifier le schéma d'une fonction, vous devez également disposer du privilège CREATE sur le nouveau schéma. Pour modifier le propriétaire, vous devez être en mesure d'exécuter SET ROLE vers le nouveau rôle propriétaire, et ce rôle doit disposer du privilège CREAT

E sur le schéma de la fonction. (Ces restrictions garantissent que la modification du propriétaire ne fait rien que vous ne pourriez pas fair
e en supprimant et recréant la fonction. Cependant, un superutilisateur peut modifier la propriété de n'importe quelle fonction de toute façon.)

PARAMÈTRE

S

no

m
Le nom (éventuellement qualifié par un schéma) d'une fonction existante. Si aucune liste d'arguments n'est spécifiée, le nom doit être unique dans son
schéma.

argmod

e
Le mode d'un argument : IN, OUT, INOUT ou VARIADIC. Si omis, la valeur par défaut est IN. Notez que ALTER FUNCTION ne fait en réalité aucun cas des arguments OUT, car seuls les arguments d'entrée sont nécessaires pour déterminer l'identité de la fonction. Il suffit donc de lister les arguments IN, INOUT et
VARIADIC.

argnam

e
Le nom d'un argument. Notez que ALTER FUNCTION ne fait en réalité aucun cas des noms d'arguments, car seuls les types de données des arguments sont nécessaires pour déterminer l'identité de la
fonction.

argtyp

e
Le ou les types de données des arguments de la fonction (éventuellement qualifiés par un schéma), le cas
échéant.

e
Le nouveau nom de la
fonction.

new_owne

r
Le nouveau propriétaire de la fonction. Notez que si la fonction est marquée SECURITY DEFINER, elle s'exécutera par la suite en tant que nouveau
propriétaire.

new_schem

a
Le nouveau schéma de la
fonction.

DEPENDS ON EXTENSION extension_name
NO DEPENDS ON EXTENSION extension_nam

e
Cette forme marque la fonction comme dépendante de l'extension, ou plus dépendante de cette extension si NO est spécifié. Une fonction marquée comme dépendante d'une extension est supprimée lorsque l'extension est supprimée, même si CASCADE n'est pas spécifié. Une fonction peut dépendre de plusieurs extensions et sera supprimée lorsque l'une de ces extensions est
supprimée.

CALLED ON NULL INPUT
RETURNS NULL ON NULL INPUT
STRIC

T
CALLED ON NULL INPUT modifie la fonction pour qu'elle soit invoquée lorsque certains ou tous ses arguments sont nuls. RETURNS NULL ON NULL INPUT ou STRICT modifie la fonction pour qu'elle ne soit pas invoquée si l'un de ses arguments est nul ; à la place, un résultat nul est supposé automatiquement. Voir CREATE FUNCTION (CREATE_FUNCTION(7)) pour plus
d'informations.

Modifie le nombre estimé de lignes renvoyées par une fonction renvoyant un ensemble. Voir CREATE FUNCTION (CREATE_FUNCTION(7)) pour plus

Ajoute ou modifie l'affectation à effectuer à un paramètre de configuration lorsque la fonction est appelée. Si value est DEFAULT ou, de manière équivalente, si RESET est utilisé, le réglage local à la fonction est supprimé, de sorte que la fonction s'exécute avec la valeur présente dans son environnement. Utilisez RESET ALL pour effacer tous les réglages locaux à la fonction. COMPATIBILIT

É

Cette instruction est partiellement compatible avec l'instruction ALTER FUNCTION de la norme SQL. La norme permet de modifier plus de propriétés d'une fonction, mais ne permet pas de renommer une fonction, de faire d'une fonction un security definer, d'attacher des valeur

s de paramètres de configuration à une fonction, ou de modifier le propriétaire, le schéma ou la volatil
ité d'une fonction. La norme exige également le mot-clé RESTRICT, qui est facultatif dans PostgreSQL.
