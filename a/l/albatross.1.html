ALBATROSS(1) Manuel des commandes générales ALBATROSS(1)

NOM

albatross - un outil pour trouver des polices qui contiennent un glyphe donné (Unicode).

SYNTAXE

albatross [options] glyphes...

DESCRIPTION

albatross est un outil en ligne de commande pour trouver des polices qui contiennent un glyphe donné (Unicode). Il s'appuie sur Fontconfig, une bibliothèque pour la configuration et la personnalisation de l'accès aux polices.

Albatross prend une liste de glyphes en entrée. Trois formats sont supportés :

#1
Le glyphe lui-même, par exemple, ß (Eszett). En interne, l'outil le convertit en son point de code Unicode correspondant.
#2
Le glyphe sous forme de point de code Unicode en notation hexadécimale, par exemple, 0xDF. Le préfixe 0x est obligatoire. Notez que l'outil prend la valeur comme insensible à la casse, par exemple, 0xDF est égal à 0xdf (ou toute combinaison de casse).
#3
Le glyphe sous forme de point de code Unicode utilisant la notation d'union multiset, par exemple, U+DF. Le préfixe U+ est obligatoire. Soyez conscient que cette notation attend un U majuscule.

OPTIONS

--show-styles
Afficher les styles de police disponibles.
--detailed
Afficher une liste détaillée des polices.
--ansi-level [n|a16|a256|tc]
Définir le niveau ANSI par défaut.
--border-style [0|1|2|3|4|5|6]
Définir le style de bordure.
--or
Rechercher chaque glyphe séparément.
--version
Afficher la version et quitter.
--help
Afficher un message d'aide et quitter.

BOGUES

Suivi des problèmes à https://gitlab.com/islandoftex/albatross/-/issues.
