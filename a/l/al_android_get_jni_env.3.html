al_android_get_jni_env(3) Manuel des fonctions de bibliothèque al_android_get_jni_env(3)

NOM

al_android_get_jni_env - API Allegro 5

SYNTAXE

#include <allegro5/allegro_android.h>
JNIEnv *al_android_get_jni_env(void)

DESCRIPTION

Retourne l'environnement JNI Android utilisé par Allegro pour appeler du code Java. À titre de commodité, cette fonction le fournit à l'utilisateur, il n'est donc pas nécessaire de l'obtenir vous-même.

Par exemple, si vous avez une méthode Java “void send(String message)” dans votre classe d'activité, vous pourriez l'appeler comme ceci depuis du code C :

JNIEnv * env = al_android_get_jni_env();
jclass class_id = (* env)->GetObjectClass(env, al_android_get_activity());
jmethodID method_id = (* env)->GetMethodID(env, class_id, "send",
    "(Ljava/lang/String;)V");
jstring jdata = (* env)->NewStringUTF(env, "Bonjour Java !");
(* env)->CallVoidMethod(env, al_android_get_activity(), method_id, jdata);
(* env)->DeleteLocalRef(env, jdata);
