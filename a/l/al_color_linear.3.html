al_color_linear(3) Manuel des fonctions de bibliothèque al_color_linear(3)

NOM

al_color_linear - API Allegro 5

SYNTAXE

#include <allegro5/allegro_color.h>
ALLEGRO_COLOR al_color_linear(float r, float g, float b)

DESCRIPTION

Retourne une structure ALLEGRO_COLOR(3) à partir de valeurs sRGB linéaires. Les valeurs RVB d'Allegro sont supposées être en sRGB. La norme sRGB est largement utilisée par divers appareils d'affichage. Elle tient compte d'une correction gamma standard appliquée aux couleurs RVB avant qu'elles ne soient affichées.

La correction gamma signifie que si, par exemple, nous avons une couleur gris moyen spécifiée avec al_map_rgb_f(0,5,0,5,0,5), nous ne voulons pas que le moniteur définisse le pixel à exactement la moitié de l'intensité physique maximale, mais plutôt à une intensité qui semble être deux fois moins lumineuse que le maximum pour la personne qui la regarde. Dans ce cas, ce serait plus proche de 21% de l'intensité maximale plutôt que 50% de l'intensité.

Pour certaines applications, il peut être utile de spécifier une couleur en composantes sRGB linéaires, auquel cas vous pouvez utiliser cette fonction. Par exemple :

ALLEGRO_COLOR gray = al_color_linear(0.216, 0.216, 0.216);
char html[8];
al_color_rgb_to_html(gray.r, gray.g, gray.b, html); // "#808080"
