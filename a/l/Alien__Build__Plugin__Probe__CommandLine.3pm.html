Alien::Build::Plugin::Probe::CommandLine(3) Documentation Perl fournie par l'utilisateur Alien::Build::Plugin::Probe::CommandLine(3)

NOM

Alien::Build::Plugin::Probe::CommandLine - Sonde pour les outils ou commandes déjà disponibles

VERSION

version 2.84

SYNOPSIS

use alienfile;
plugin 'Probe::CommandLine' => (
  command => 'gzip',
  args    => [ '--version' ],
  match   => qr/gzip/,
  version => qr/gzip ([0-9\.]+)/,
);

DESCRIPTION

Ce plugin sonde l'existence du programme de ligne de commande donné.

PROPRIETES

commande

Le nom de la commande.

arguments

Les arguments à passer à la commande.

secondaire

Si vous utilisez un autre plugin de sonde (comme Alien::Build::Plugin::Probe::CBuilder ou Alien::Build::Plugin::PkgConfig::Negotiate) pour détecter l'existence d'une bibliothèque, mais qu'un programme doit également exister, vous devez définir secondaire à une valeur vraie. Par exemple, quand vous avez besoin des deux :

use alienfile;
# nécessite à la fois la bibliothèque liblzma et le programme xz
plugin 'PkgConfig' => 'liblzma';
plugin 'Probe::CommandLine' => (
  command   => 'xz',
  secondary => 1,
);

Quand vous n'avez pas besoin des deux :

use alienfile;
plugin 'Probe::CommandLine' => (
  command   => 'gzip',
  secondary => 0, # par défaut
);

correspondance

Expression régulière à laquelle la sortie du programme doit correspondre.

correspondance_stderr

Expression régulière à laquelle la sortie d'erreur standard du programme doit correspondre.

version

Expression régulière pour extraire la version de la sortie du programme. L'expression régulière doit stocker le numéro de version dans $1.

version_stderr

Expression régulière pour extraire la version de la sortie d'erreur standard du programme. L'expression régulière doit stocker le numéro de version dans $1.

au_moins_version

La version minimale requise telle que fournie par le système.
