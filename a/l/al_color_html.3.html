al_color_html(3) Manuel des fonctions de bibliothèque al_color_html(3)

NOM

al_color_html - API Allegro 5

SYNTAXE

#include <allegro5/allegro_color.h>
ALLEGRO_COLOR al_color_html(char const *string)

DESCRIPTION

Interprète un nombre hexadécimal de style HTML (par ex. #00faff) comme une couleur. Le format accepté est le même que celui de al_color_html_to_rgb(3).

Retourne la couleur interprétée, ou al_map_rgba(0, 0, 0, 0) si la chaîne n'a pas pu être analysée.

Note : le comportement en cas de chaînes invalides est différent de celui d'Allegro 5.0.x.

VOIR AUSSI

al_color_html_to_rgb(3), al_color_rgb_to_html(3)
