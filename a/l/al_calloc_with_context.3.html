NOM

al_calloc_with_context - API Allegro 5

SYNOPSIS

#include <allegro5/allegro.h>
void *al_calloc_with_context(size_t count, size_t n,
   int line, const char *file, const char *func)

DESCRIPTION

Appelle calloc() de la bibliothèque Allegro (ce qui est important sous Windows), sauf si elle est remplacée par al_set_memory_interface(3).

En général, vous devriez utiliser la macro al_calloc(3).
