NOM

Alien::Build::Plugin::Extract::CommandLine - Module pour extraire une archive en utilisant des outils en ligne de commande

VERSION

version 2.84

SYNOPSIS

use alienfile;
plugin 'Extract::CommandLine' => (
  format => 'tar.gz',
);

DESCRIPTION

Note : dans la plupart des cas, vous voudrez utiliser Alien::Build::Plugin::Extract::Negotiate à la place. Il choisit le module Extract approprié en fonction de votre plateforme et de votre environnement. Dans certains cas, vous pourriez avoir besoin d'utiliser ce module directement.

Ce module extrait à partir d'une archive de divers formats en utilisant des outils en ligne de commande.

PROPRIETES

format

Donne un indice sur le format attendu.

gzip_cmd

La commande "gzip", si disponible. "undef" si non disponible.

bzip2_cmd

La commande "bzip2", si disponible. "undef" si non disponible.

xz_cmd

La commande "xz", si disponible. "undef" si non disponible.

tar_cmd

La commande "tar", si disponible. "undef" si non disponible.

unzip_cmd

La commande "unzip", si disponible. "undef" si non disponible.

METHODES

handles

Alien::Build::Plugin::Extract::CommandLine->handles($ext);
$plugin->handles($ext);

Retourne vrai si le module peut gérer l'archive du format donné.

available

Alien::Build::Plugin::Extract::CommandLine->available($ext);

Retourne vrai si le module est disponible pour extraire sans installer quoi que ce soit de nouveau.

VOIR AUSSI
