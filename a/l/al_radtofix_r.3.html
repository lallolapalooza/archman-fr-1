NOM

al_radtofix_r - API Allegro 5

SYNOPIS

#include <allegro5/allegro.h>
const al_fixed al_radtofix_r = (al_fixed)2670177;

DESCRIPTION

Cette constante fournit un rapport qui peut être utilisé pour convertir un nombre à point fixe en radians en un nombre à point fixe en format d'angle binaire.

Exemple:

    al_fixed rad_angle, binary_angle;
    ...
    binary_angle = al_fixmul(rad_angle, radtofix_r);

VOIR AUSSI

al_fixmul(3), al_fixtorad_r(3).
