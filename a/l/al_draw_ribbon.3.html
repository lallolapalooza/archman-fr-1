NOM

al_draw_ribbon - API Allegro 5

SYNTAXE

#include <allegro5/allegro_primitives.h>
void al_draw_ribbon(const float *points, int points_stride, ALLEGRO_COLOR color,
   float thickness, int num_segments)

DESCRIPTION

Dessine un ruban étant donné un tableau de points. Le ruban passera par tous les points fournis. Le tampon de points doit être constitué de doublets de flottants espacés régulièrement, correspondant aux coordonnées x et y des sommets.

Paramètres :

•
points - Un tableau de paires de coordonnées (x et y) pour chaque point
•
points_stride - Distance (en octets) entre les débuts des paires de coordonnées successives dans le tampon de points
•
color - Couleur de la courbe
•
thickness - Épaisseur de la courbe, passer <= 0 pour dessiner une courbe filaire
•
num_segments - Le nombre de segments
