ALTER TEXT SEARCH CONFIGURATION(7) Documentation PostgreSQL 18.1 ALTER TEXT SEARCH CONFIGURATION(7)

NOM

ALTER_TEXT_SEARCH_CONFIGURATION - modifier la définition d'une configuration de recherche textuelle

SYNTAXE

ALTER TEXT SEARCH CONFIGURATION nom
    ADD MAPPING FOR type_jeton [, ... ] WITH nom_dictionnaire [, ... ]
ALTER TEXT SEARCH CONFIGURATION nom
    ALTER MAPPING FOR type_jeton [, ... ] WITH nom_dictionnaire [, ... ]
ALTER TEXT SEARCH CONFIGURATION nom
    ALTER MAPPING REPLACE ancien_dictionnaire WITH nouveau_dictionnaire
ALTER TEXT SEARCH CONFIGURATION nom
    ALTER MAPPING FOR type_jeton [, ... ] REPLACE ancien_dictionnaire WITH nouveau_dictionnaire
ALTER TEXT SEARCH CONFIGURATION nom
    DROP MAPPING [ IF EXISTS ] FOR type_jeton [, ... ]
ALTER TEXT SEARCH CONFIGURATION nom RENAME TO nouveau_nom
ALTER TEXT SEARCH CONFIGURATION nom OWNER TO { nouveau_proprietaire | CURRENT_ROLE | CURRENT_USER | SESSION_USER }

DESCRIPTION

ALTER TEXT SEARCH CONFIGURATION modifie la définition d'une configuration de recherche textuelle. Vous pouvez modifier ses mappages de types de jetons vers des dictionnaires, ou changer le nom ou le propriétaire de la configuration.

Vous devez être le propriétaire de la configuration pour utiliser ALTER TEXT SEARCH CONFIGURATION.

PARAMÈTRES

nom

Le nom (éventuellement qualifié par un schéma) d'une configuration de recherche textuelle existante.

type_jeton

Le nom d'un type de jeton émis par le analyseur de la configuration.

nom_dictionnaire

Le nom d'un dictionnaire de recherche textuelle à consulter pour le(s) type(s) de jeton spécifié(s). Si plusieurs dictionnaires sont listés, ils sont consultés dans l'ordre spécifié.

ancien_dictionnaire

Le nom d'un dictionnaire de recherche textuelle à remplacer dans le mappage.

nouveau_dictionnaire

Le nom d'un dictionnaire de recherche textuelle à substituer à ancien_dictionnaire.

nouveau_nom

Le nouveau nom de la configuration de recherche textuelle.

nouveau_proprietaire

Le nouveau propriétaire de la configuration de recherche textuelle.

La forme ADD MAPPING FOR installe une liste de dictionnaires à consulter pour le(s) type(s) de jeton spécifié(s) ; c'est une erreur s'il existe déjà un mappage pour l'un des types de jetons. La forme ALTER MAPPING FOR fait de même, mais en supprimant d'abord tout mappage existant pour ces types de jetons. Les formes ALTER MAPPING REPLACE substituent nouveau_dictionnaire à ancien_dictionnaire partout où ce dernier apparaît. Ceci est fait uniquement pour les types de jetons spécifiés lorsque FOR apparaît, ou pour tous les mappages de la configuration lorsqu'il n'apparaît pas. La forme DROP MAPPING supprime tous les dictionnaires pour le(s) type(s) de jeton spécifié(s), ce qui fait que les jetons de ces types sont ignorés par la configuration de recherche textuelle. C'est une erreur s'il n'y a pas de mappage pour les types de jetons, sauf si IF EXISTS apparaît.

EXEMPLES

L'exemple suivant remplace le dictionnaire anglais par le dictionnaire suédois partout où 'english' est utilisé dans my_config.

ALTER TEXT SEARCH CONFIGURATION my_config
  ALTER MAPPING REPLACE english WITH swedish;

COMPATIBILITÉ

Il n'y a pas d'instruction ALTER TEXT SEARCH CONFIGURATION dans la norme SQL.

VOIR AUSSI

CREATE TEXT SEARCH CONFIGURATION (CREATE_TEXT_SEARCH_CONFIGURATION(7)), DROP TEXT SEARCH CONFIGURATION (DROP_TEXT_SEARCH_CONFIGURATION(7))
