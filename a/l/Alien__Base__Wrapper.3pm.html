DESCRIPTIO

N

Ce module agit comme une enveloppe autour d'un ou plusieurs modules Alien. Il est conçu pour fonctionner avec les aliens basés sur Alien::Base, mais il devrait fonctionner avec tout Alien qui utilise la même API

essentielle.

Dans le premier exemple (depuis la ligne de commande), cette classe agit comme une enveloppe autour du compilateur et de l'éditeur de liens que Perl est configuré pour utiliser. Elle prend les indicateurs normaux du compilateur et de l'éditeur de liens et ajoute les indicateurs fournis par les Aliens spécifiés, puis exécute la commande. Elle affichera la commande sur la console afin que vous puissiez voir exactement ce qui se

passe.

Dans le deuxième exemple (depuis Makefile.PL non-dynamique), cette classe est utilisée pour générer les arguments appropriés d'ExtUtils::MakeMaker (EUMM) nécessaires pour "WriteMakefile"

.

Dans le troisième exemple (depuis Makefile.PL dynamique), nous faisons une vérification rapide pour voir si l'indicateur simple de l'éditeur de liens "-lfoo" fonctionnera, si c'est le cas nous l'utilisons. Sinon, nous utilisons une enveloppe autour du compilateur et de l'éditeur de liens qui utilisera les indicateurs alien connus au moment de la compilation. Le problème que cette forme tente de résoudre est que les indicateurs du compilateur et de l'éditeur de liens doivent généralement être déterminés au moment de la configuration, lorsqu'une distribution est installée, ce qui signifie que si vous allez utiliser un module Alien, il doit être une prérequis de configuration, même si la bibliothèque est déjà installée et facilement détectée sur le système

d'exploitation.

L'auteur de ce module estime que la troisième forme (depuis Makefile.PL dynamique) est quelque peu inutile. Les modules Ali

en basés sur Alien::Base ont quelques prérequis, mais ils sont bien entretenus et fiables, donc bien qu'il y ait un peti
t coût en termes de dépendances supplémentaires, la fiabilité globale est améliorée grâce à une complexité globale réduite.

WriteMakefil

e 
use Alien::Base::Wrapper qw( WriteMakefile );
WriteMakefile(%args, alien_requires => \%aliens);
WriteMakefile(%args, alien_requires => \@aliens)
;

C'est une enveloppe légère autour de "WriteMakefile" d'ExtUtils::MakeMaker, qui ajoute les aliens donnés aux prérequis de configuration et définit les indicateurs appropriés du compilateur et de l'éditeur de

liens.

Si les aliens sont spécifiés sous forme de référence de hachage, alors les clés sont les noms des modules et les valeurs sont les versions. Pour une liste, ce sont juste les noms des

aliens.

Pour la forme liste, vous pouvez spécifier une version en ajoutant "=version" au nom des Aliens, c'est-à-dire

: 
WriteMakefile(
  alien_requires => [ 'Alien::libfoo=1.23', 'Alien::libbar=4.56' ],
)
;

La forme liste est recommandée si l'ordre des alie

ns est important. Les aliens sont triés dans l
a forme hachage pour la rendre cohérente, mais cel
a peut ne pas être l'ordre que vous souhaitez.
