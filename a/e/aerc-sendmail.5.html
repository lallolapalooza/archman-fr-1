NOM

aerc-sendmail - configuration sendmail pour aerc(1)

SYNOPIS

aerc peut déléguer à sendmail la livraison des messages sortants.

CONFIGURATION

La configuration de base de sendmail peut être effectuée interactivement avec la commande :new-account.

Dans accounts.conf (voir aerc-accounts(5)), les options spécifiques à sendmail suivantes sont disponibles :

outgoing = </chemin/vers/sendmail>

Ceci doit être défini sur le chemin d'accès au binaire sendmail que vous souhaitez utiliser, généralement /usr/sbin/sendmail. aerc l'exécutera avec une liste de destinataires sur la ligne de commande et redirigera le message à livrer vers stdin.
