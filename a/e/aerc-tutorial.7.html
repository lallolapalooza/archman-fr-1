NOM

aerc-tutorial - tutoriel pour aerc(1)

INTRODUCTION

Bienvenue sur aerc ! Ce tutoriel vous guidera dans vos premiers pas avec ce client. Ce tutoriel est une page de manuel - vous pourrez le relire plus tard avec :help tutorial depuis aerc, ou man aerc-tutorial depuis votre terminal.

Tout d'abord, présentons quelques raccourcis clavier de base. Par convention, nous utiliserons <C-p> pour représenter Ctrl+p, ce qui correspond à la convention utilisée pour écrire les raccourcis clavier pour aerc.

<C-p>, <C-n>

Navigue vers l'onglet précédent ou suivant

Essayez de les utiliser maintenant pour passer de votre liste de messages au tutoriel. Dans votre liste de messages, nous utilisons des touches de style vim pour naviguer.

k, j

Fait défiler vers le haut et vers le bas entre les messages

<C-u>, <C-d>

Fait défiler d'une demi-page vers le haut ou vers le bas

g, G

Sélectionne respectivement le premier ou le dernier message

K, J

Permute entre les dossiers dans la barre latérale

<Entrée>

Ouvre le message sélectionné

Vous pouvez également rechercher dans le dossier sélectionné avec /, ou filtrer avec \ . Lors de la recherche, vous pouvez utiliser n et p pour passer au résultat suivant et précédent. Le filtrage masque tout message non correspondant.

LE VISUALISEUR DE MESSAGES

Appuyez sur <Entrée> pour ouvrir un message. Par défaut, le visualiseur de messages affichera votre message à l'aide de less(1). Celui-ci devrait également avoir des raccourcis clavier familiers de style vim pour y naviguer.

Les messages multipartites (messages avec pièces jointes, ou messages avec plusieurs formats alternatifs) affichent un sélecteur de partie en bas du visualiseur de messages.

<C-k>, <C-j>

Navigue entre les parties d'un message multipartite

q

Ferme le visualiseur de messages

Pour afficher les parties de messages HTML, le filtre text/html de votre fichier aerc.conf (qui se trouve probablement dans ~/.config/aerc/) nécessite w3m ainsi que des dépendances optionnelles pour un isolement réseau plus sûr : unshare (de util-linux) ou socksify (de dante-utils).

Vous pouvez également effectuer ici de nombreuses tâches que vous pouviez faire dans la liste des messages, comme répondre aux e-mails, supprimer l'e-mail, ou afficher le message suivant et précédent (J et K).

COMPOSITION DES MESSAGES

Retournez à la liste des messages en appuyant sur q pour fermer le visualiseur de messages. Une fois là, composons un message.

C

Compose un nouveau message

rr

Répondre à tous à un message

rq

Répondre à tous à un message, et pré-remplit l'éditeur avec une version citée du message auquel on répond

Rr

Répond à un message

Rq

Répond à un message, et pré-remplit l'éditeur avec une version citée du message auquel on répond

Pour l'instant, utilisons C pour composer un nouveau message. L'éditeur de messages apparaîtra. Vous devriez voir les lignes À, De, et Objet, ainsi que votre éditeur. Vous pouvez utiliser <Tab> ou <C-j> et <C-k> pour naviguer entre ces champs (la tabulation ne naviguera pas entre les champs une fois que vous entrez dans l'éditeur, mais <C-j> et <C-k> le feront).

Envoyons un e-mail à vous-même. Notez que les en-têtes À et De attendent des adresses RFC 5322, par exemple John Doe <john@example.org>, ou simplement <john@example.org>. Séparez les destinataires multiples par des virgules. Allez-y et remplissez un e-mail, puis fermez l'éditeur.

L'écran de revue des messages s'affiche ensuite. Vous avez maintenant une chance de réviser l'e-mail avant qu'il ne soit envoyé. Appuyez sur y pour envoyer l'e-mail s'il vous semble correct.

Note : lorsque vous utilisez le terminal dans la vue des messages, vous pouvez faire apparaître la ligne de commande ex d'aerc en utilisant <C-x>. : est envoyé à l'éditeur.

UTILISATION DU TERMINAL

aerc est livré avec un terminal intégré, que vous avez déjà utilisé pour visualiser et éditer des e-mails. Nous pouvons également l'utiliser à d'autres fins, comme référencer un dépôt git lors de la revue d'un patch. Depuis la liste des messages, nous pouvons utiliser les raccourcis clavier suivants pour ouvrir un terminal :

<C-t>

Ouvre un nouvel onglet de terminal, exécutant votre shell

$, !

Demande une commande à exécuter, puis ouvre un nouvel onglet de terminal exécutant cette commande

|

Demande une commande à exécuter, puis redirige l'e-mail sélectionné vers cette commande et affiche le résultat dans un nouvel onglet de terminal

Essayez d'appuyer sur $ et de saisir top. Vous pouvez également utiliser la commande :cd pour changer le répertoire de travail d'aerc, et le répertoire dans lequel les nouveaux terminaux s'exécutent. Utilisez :pwd pour le voir à nouveau si vous n'êtes pas sûr de votre emplacement.

NOTES ADDITIONNELLES

COMMANDES

Chaque raccourci clavier est finalement lié à une commande aerc. Vous pouvez également faire apparaître la ligne de commande en appuyant sur :, puis en entrant l'une de ces commandes. Consultez aerc(1) ou :help pour une liste complète des commandes.

FILTRES DE MESSAGES

Lors de l'affichage des messages dans le visualiseur de messages, aerc les transmet d'abord via un filtre de messages. Cela vous permet de décoder les messages dans des formats non textuels, d'ajouter la coloration syntaxique, etc. aerc est livré avec quelques filtres par défaut :

  • Les parties text/plain sont transmises via le filtre intégré colorize qui gère la coloration des URL, des citations et des diffs.
  • text/calendar est traité pour être un texte lisible par l'homme
  • text/html (désactivé par défaut) peut être décommenté pour être transmis via le filtre intégré html.

PERSONNALISATION D'AERC

Aerc est hautement personnalisable. Consultez aerc-config(5) (ou utilisez :help config) pour en savoir plus sur la manière d'ajouter des raccourcis clavier personnalisés, d'installer de nouveaux filtres de messages, de modifier son apparence et son comportement, etc.
