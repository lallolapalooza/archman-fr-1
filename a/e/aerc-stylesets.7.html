CONFIGURATION DU

STYLESET

Le styleset est décrit sous la forme de paires <objet>.<attribut> = <valeur>

.

Par exemple, dans la ligne ci-dessous, la couleur de premier plan de l'objet de style msglist_unread est définie à cornflowerblu

e
msglist_unread.fg = cornflowerblu
e

La configuration permet également l'utilisation

de caractères génériques dans les clés pour
configurer plusieurs objets de style à la fois.

Les styles définis par l'utilisateur peuvent être utilisés pour mettre en forme des chaînes arbitraires dans les go-templates (voir .Style dans aerc-templates(7)). Les styles définis par l'utilisateur doivent être définisd dans la ini [user]. Les styles peuvent être référencés par leur nom (par ex. red.fg est nommé « red »)

.

Exemple

: 
[user]
red.
fg=red

Les styles utilisateur sont superposés aux autres styles appliqués au contexte dans lequel ils sont rendus. Les couleurs du style utilisateur (fg et/ou bg) ne seront efficaces que si le style du contexte n'en définit aucune. Les autres attributs booléens seront fusionnés avec les attributs booléens du style

sous-jacent.

Par exemple, si le style du contexte est

:
fg=red
bold

Et le style en ligne est

:
fg=yellow italic
underline

Le style effectif sera

:
fg=red bo
ld italic
underline

MODIFICATEUR

SELECTED

Le modificateur selected peut être appliqué à n'importe quel objet de style. Le style fourni pour le modificateur selected est appliqué par-dessus l' objet de style auquel il

correspond.

Si vous souhaitez vous assurer que les messages marqués comme lus dans msglist apparaissent en premier plan jaune et arrière-plan noir, vous pouvez le spécifier ainsi

:
msglist_default.selected.fg = yellow

msglist_default.selected.bg = bl

a
ck

Si nous spécifions le modificateur de style global selected en utilisant fnmatch comme ci-dessous

*.selected.reverse = toggl
e

Cela bascule l'interrupteur reverse pour la version selected de tous les objets de

style.

Les objets selected héritent de tous les attributs de leurs équivalents non-selected. Les instructions selected sont analysées après les instructions non-selected

et remplacent effectivement les attribut
s de l' objet de style non-selected.

Certains styles, (actuellement les msglist_* et dirlist_* ) sont appliqués en couches. Si un style diffère de la base (dans ce cas *list_default) alors ce style s'applique, sauf s'il est remplacé par une couche supérieure. STYLES DYNAMIQUES DE LISTE DE

MESSAGES

Tous les styles msglist_* peuvent être définis pour des valeurs spécifiques d'en-tête d'e-mail. La syntaxe est la suivante

:
msglist_<name>.<header>,<header_value>.<attribute> = <attr_value
>

Si <header_value> commence par un tilde ~, il sera interprété comme une expression régulière. Si vous écrivez des expressions régulières qui tentent de correspondre avec . ou . vous devez les envelopper comme ceci ~/<expressi

on>/.

<header>,<header_value> peut être spécifié plusieurs fois pour restreindre les correspondances à plus d'une valeur d'en-tête d'e-mail. Dans ce cas, tous les en-têtes donnés doivent correspondre pour que le style dynamique

s'applique.

Exemples

: 
msglist*.X-Sourcehut-Patchset-Update,APPROVED.fg = green
msglist*.X-Sourcehut-Patchset-Update,NEEDS_REVISION.fg = yellow
msglist*.X-Sourcehut-Patchset
-Update,REJECTED.fg = red "msglist_*.Subject,~^(\[[w-]+]\s*)?\[(RFC )?PATCH.fg" = #ffffaf "msglist_*.Subject,~^(\[[w-]+]\s*)?\[(RFC )?PATCH.selected.
fg" = #ffffaf "msglist_*.From,~^Bob.Subject,~^(\[[w-]+]\s*)?\[(RFC )?PATCH.selected.fg" = #ffffaf "msglist_*.List-ID,~/lists.sr.ht/selected.fg" = blue

Lorsqu'un style dynamique correspond à un en-tête d'e-mail, il sera utilisé en priorité par rapport à son équivalent non dynamique. En supposant le styleset suivant

: 
msglist_marked.fg =
blue msglist_*.Subj
ect,~foobar.fg = red

Un e-mail avec foobar dans son sujet sera coloré en red tout le temps, puisque msglist_* s'applique aussi à msglist_marked

.

Lorsque plusieurs paires <header>,<header_value> sont données, le dernier style qui correspond à tous les motifs donnés sera appliqué. En supposant le styleset suivant

: 
msglist_*.From,~^Bob.Subj
ect,~foobar.fg = red msgli
st_*.From,~^Bob.fg = blue

Un e-mail de Bob avec foobar dans son sujet sera coloré en blue, puisque le second style

correspond auss
i complètement.
