aerc-binds - format du fichier de configuration des raccourcis clavier pour aerc(

1
)

SYNOPSI

S

Le fichier binds.conf est utilisé pour configurer les raccourcis clavier utilisés dans le client interactif aerc. Il est attendu dans votre XDG config home plus aerc, ce qui donne par défaut ~/.config/aerc/binds.conf. Si le fichier n'existe pas, la configuration par défaut intégrée sera installée. Un fichier alternatif peut être spécifié via l'argument de ligne de commande --binds-conf, voir aerc(

1).

Ce fichier est écrit au format ini avec les raccourcis clavier définis comme suit

:
<séquence de touches> = <commande
>

Où <séquence de touches> sont les frappes effectuées (dans l'ordre) pour invoquer ce raccourci, et <commande> spécifie les frappes que aerc simulera lorsque le raccourci est invoqué. Généralement cela est utilisé pour exécuter des commandes, par exemple

:
rq = :reply
-q<Enter>

Appuyer sur r, puis q, simulera la saisie de :reply -q<Enter>, et exécutera :reply -q en conséquence. Il est également possible d'invoquer des raccourcis de manière récursive de façon

similaire.

Vous pouvez configurer différents raccourcis clavier pour différents contextes en les écrivant dans différentes [sections] du

fichie
r ini.

raccourcis clavier pour le composeur, lors de la révision de l'e-mail avant son envoi

Pour personnaliser la description affichée sur l'écran de révision, ajoutez un commentaire (" # ") à la fin du raccourci. Exemple

:
p = :postpone<Enter> # J'y travaillerai plus
tard

L'ordre dans lequel les raccourcis sont définis est préservé sur l'écran de révision. Si un raccourci non par défaut n'est pas annoté, il sera affiché sans aucune

description.

Pour masquer un raccourci de l'écran de révision, annotez-le explicitement avec un commentaire " # -". Exemple

:
<C-e> = :encrypt<Enter>
#
-

[terminal

]
raccourcis clavier pour les onglets de
terminal

Vous pouvez également configurer des raccourcis clavier spécifiques à un compte pour chaque contexte

:

[context:account=NomDuCompte

]
raccourcis clavier pour ce contexte et ce compte, où NomDuCompte est une expression régulière qui correspond au nom de compte que vous avez fourni dans accounts.
conf.

Des raccourcis spécifiques au dossier et au contexte peuvent être configurés pour les listes de messages

:

[messages:folder=NomDuDossier]
[view:folder=NomDuDossier]
[compose:folder=NomDuDossier]
[compose::editor:folder=NomDuDossier]
[compose::review:folder=NomDuDossier

]
les raccourcis clavier sous cette section seront spécifiques au dossier qui correspond à l'expression régulière NomDuDossier. Les raccourcis clavier d'un spécificateur de
dossier auront la priorité su
r les spécificateurs de compte

SPÉCIALES

En plus des séquences de touches définies par l'utilisateur, les options spéciales suivantes sont disponibles dans chaque contexte de raccourci

:

$noinherit = true|fals

e

Par défaut : fa

$ex = <touche

>
Cela peut être défini à une touche qui fera apparaître la saisie de commande dans ce contexte.

Par défaut :

:

$complete = <touche

>
Cela peut être défini à une touche qui déclenchera la complétion de commande dans ce contexte pour les saisies de texte qui la prennent en charge.

Par défaut : <tab

>

Remarque : la complétion automatique de commande est désactivée lors de la simulation de frappes et réactivée à la fin. Lorsque [ui].completion-min-chars est défini à manual (voir aerc-config(5)), il est possible de terminer un raccourci avec la touche de complétion pour afficher explicitement le menu de complétion.
