AEC(1) Manuel des commandes générales AEC(1)

NOM

aec - compresser ou décompresser des fichiers

SYNTAXE

aec [-3] [-b OCTETS] [-d] [-j ÉCHANTILLONS] [-m] [-n BITS] [-N] [-p] [-r BLOCS] [-s] [-t] fichierentree fichierdevenue

DESCRIPTION

Aec effectue une compression et une décompression sans perte avec le codage Golomb-Rice tel que défini dans la norme recommandée 121.0-B-3 du système de données spatiales.

OPTIONS

-3
les échantillons de 24 bits sont stockés en 3 octets
-b OCTETS
taille du tampon interne en octets
-d
décompresser fichierentree ; si l'option -d n'est pas utilisée, alors compresser fichierentree
-j ÉCHANTILLONS
taille du bloc en échantillons
-m
les échantillons sont MSB en premier ; par défaut, c'est LSB en premier
-n BITS
bits par échantillon
-N
désactiver le pré/post-traitement
-p
remplir RSI jusqu'à la frontière d'octet
-r BLOCS
intervalle d'échantillons de référence en blocs
-s
les échantillons sont signés ; par défaut, ils sont non signés
-t
utiliser un ensemble restreint d'options de code
