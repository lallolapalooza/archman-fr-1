COMMANDES

D'EXÉCUTION

Pour exécuter une commande, appuyez sur : pour faire apparaître l'interface de commande. Les commandes peuvent aussi être liées à des touches, voir aerc-binds(5) pour plus de détails. Dans certains contextes, comme l'émulateur de terminal, <c-x> est utilisé pour faire apparaître l'interface de

commande.

Différentes commandes fonctionnent dans différents contextes, en fonction du type d'onglet que vous avez

sélectionné.

Les arguments dynamiques sont développés selon aerc-templates(7) en fonction du contexte. Par exemple, si vous avez un message sélectionné, la commande suivante

: 
:filter -f "{{index (.From | emails) 0}
}
"

Filtrera tous les messages envoyés par le même

expéditeur.

Aerc conserve un historique des commandes, qui peut être parcouru en mode commande. Appuyer sur la touche haut parcourt l'historique en arrière, tandis que appuyer sur la touche bas le parcourt en

avant.

:menu [-c "<shell-cmd>"] [-e] [-b] [-a] [-d] [-t "<titre>"] <aerc-cmd ...>

Ouvre une boîte de dialogue popover exécutant sh -c "<shell-cmd>" (si non spécifié, [general].default-menu-cmd sera utilisé). Lorsque la commande se termine, toutes les lignes imprimées sur sa sortie standard seront ajoutées à <aerc-cmd ...> et exécutées comme une commande aerc standard, à la manière de xargs(1) lorsqu'il est utilisé dans un shell. Un préfixe deux-points (:) est pris en charge pour <aerc-cmd ...> mais n'est pas obligatoire.

:menu peut être utilisé sans programme externe en définissant <shell-cmd> à -. Cela sert également de solution de repli lorsque <shell-cmd> n'a pas été spécifié du tout ou que l'exécutable dans <shell-cmd> n'a pas été trouvé.

-c "<shell-cmd>"

Remplace [general].default-menu-cmd. Voir aerc-config(5) pour plus de détails.

-e : Arrête l'exécution des commandes à la première erreur.

-b : NE PAS lancer la boîte de dialogue popover. Lance les commandes en arrière-plan (PAS dans un terminal virtuel). Utilisez ceci si <shell-cmd> est une application graphique qui n'a pas besoin de terminal.

-t : Remplace le titre de la boîte de dialogue (sinon dérivé de <shell-cmd>)

<shell-cmd> peut être alimenté en texte d'entrée à l'aide des indicateurs suivants :

-a : Tous les noms de comptes, un par ligne. Par exemple :
'<compte>' LF

-d : Tous les noms de répertoires de compte actuels, un par ligne. Par exemple :

'<répertoire>' LF

-ad : Tous les répertoires de tous les comptes, un par ligne. Par exemple :

'<compte>' '<répertoire>' LF

Les guillemets peuvent être ajoutés par aerc lorsque des jetons contiennent des caractères spéciaux. Les guillemets doivent être préservés pour <aerc-cmd ...>.

Exemples :

:menu -adc fzf :cf -a
:menu -c 'fzf --multi' :attach
:menu -dc 'fzf --multi' :cp
:menu -bc 'dmenu -l 20' :cf
:menu -c 'ranger --choosefiles=%f' :attach

Cela peut également être utilisé dans les raccourcis clavier (voir aerc-binds(5)) :

<C-p> = :menu -adc fzf :cf -a<Entrée>

COMMANDES_DE_MESSAGE

Ces commandes sont valides dans tout contexte où un message est sélectionné (par exemple, la liste des messages, le message dans le visualiseur de messages, etc.).

:archive [-m <stratégie>] <schéma>

Déplace le message sélectionné vers les archives. Les schémas disponibles sont :

flat : Aucune structure spéciale, tous les messages dans le répertoire d'archives

year : Les messages sont stockés dans des dossiers par année

month : Les messages sont stockés dans des dossiers par année et sous-dossiers par mois

L'option -m définit la stratégie multi-fichiers. Voir aerc-notmuch(5) pour plus de détails.

:accept [-e|-E] [-s]

Accepte une invitation de réunion iCalendar. Cela ouvre une fenêtre de composition avec une pièce jointe spécialement conçue. L'envoi de l'e-mail informera l'invitant que vous avez accepté et mettra probablement à jour son calendrier également. Cela N'ajoutera PAS la réunion à votre propre calendrier, cela doit être fait comme une étape manuelle séparée (par exemple, en redirigeant la partie text/calendar vers un script approprié).

-e : Force [compose].edit-headers = true pour ce message uniquement.

-E : Force [compose].edit-headers = false pour ce message uniquement.

-s : Saute l'éditeur et va directement à l'écran de revue.

Ouvre le message sélectionné pour être réédité. Les messages ne peuvent être rappelés que depuis le répertoire de report.

-f : Ouvre le message pour être réédité même s'il n'est pas dans le répertoire de report. Aerc mémorise le dossier, donc un appel ultérieur :postpone le sauvegardera à cet endroit.

-E : Force [compose].edit-headers = false pour ce message uniquement.

Les messages rappelés d'origine sont supprimés s'ils sont à nouveau envoyés ou reportés. Dans les deux cas, vous avez une autre copie du message quelque part. Sinon, le message rappelé reste intact. Cela se produit si le message rappelé est écarté après édition. Il peut être supprimé avec :rm s'il n'est pas nécessaire.

Rebondit le message sélectionné ou tous les messages marqués vers les adresses spécifiées, en utilisant éventuellement le compte spécifié.
