NOM

aerc-smtp - Configuration SMTP pour aerc(1)

SYNOPIS

aerc implémente le protocole SMTP tel que spécifié par la RFC 5321.

CONFIGURATION

La configuration SMTP de base peut être effectuée interactivement avec la commande :new-account.

Dans accounts.conf (voir aerc-accounts(5)), les options spécifiques à SMTP suivantes sont disponibles :

outgoing = <schéma>[+<auth>]://<nom_utilisateur>[:<mot_de_passe>]@<nom_hôte>[:<port>]?[<paramètres_oauth2>]

N'oubliez pas que tous les champs doivent être encodés en URL. Le symbole @, lorsqu'il est encodé en URL, est %40.

La valeur de <schéma> peut être :

smtp

SMTP avec STARTTLS

smtp+insecure

SMTP sans STARTTLS

smtps

SMTP avec TLS/SSL

De plus, vous pouvez spécifier un mécanisme d'authentification comme suit :

none

Aucune authentification n'est requise pour utiliser ce serveur SMTP. Vous pouvez omettre le nom d'utilisateur et le mot de passe dans ce cas.

plain

S'authentifier avec un nom d'utilisateur et un mot de passe en utilisant AUTH PLAIN. C'est le comportement par défaut.

login

S'authentifier avec un nom d'utilisateur et un mot de passe en utilisant AUTH LOGIN. C'est un protocole obsolète, mais il est requis par certains fournisseurs de webmail courants.

oauthbearer

SMTP avec TLS/SSL utilisant l'authentification OAUTHBEARER. Voir la documentation dans aerc-imap(5) pour l'utilisation.

xoauth2

SMTP avec TLS/SSL utilisant l'authentification XOAUTH2. Voir la documentation dans aerc-imap(5) pour l'utilisation.

outgoing-cred-cmd = <commande>

Spécifie la commande à exécuter pour obtenir le mot de passe du compte SMTP. Cette commande sera exécutée en utilisant sh -c [commande]. Si un mot de passe est spécifié dans l'option outgoing, le mot de passe aura la priorité sur cette commande.

Exemple :

outgoing-cred-cmd = pass hostname/username

smtp-domain = <domaine>

Nom de domaine local à utiliser dans la commande SMTP HELO/EHLO. Définissez ceci sur un nom de domaine entièrement qualifié si le serveur l'exige comme mesure anti-spam.

Défaut : localhost
