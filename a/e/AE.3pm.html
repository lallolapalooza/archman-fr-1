my $w = AE::signal TERM => sub { ... };
# fin d'un processus fils

   my ($pid, $status) = @_;
   ...
};

my $w = AE::idle sub { ... };

$cv->send; # réveille le recv courant et tous les futurs
$cv->recv; # entre dans la "boucle principale" jusqu'à ce que $cv reçoive ->send

$cv->cb (sub { $_[0]->recv }

DESCRIPTIO

N

Ce module documente la nouvelle API AnyEvent plus

simple.

La raison d'être de la nouvelle API est que l'expérience avec EV montre que cette API « fonctionne » réellement, malgré son manque d'extensibilité, menant à une API plus courte, plus simple et plus

rapide.

Les principales différences avec AnyEvent sont que des appels de fonctions sont utilisés au lieu d'appels de méthodes, et que des arguments nommés ne sont pas

utilisés.

Cela rend les appels aux fonctions de création de watchers vraiment courts, ce qui peut rendre un programme plus lisible malgré l'absence de paramètres nommés. Les appels de fonctions permettent également plus de vérification de types statiques que les appels de méthodes, donc de nombreuses erreurs sont détectées à la compilation avec cette

API.

De plus, certains backends (Perl et EV) sont si rapides que le surcoût de l'appel de méthode est très perceptible (avec EV, il augmente le temps d'exécution de cinq à six fois, avec Perl, le surcoût de l'appel de méthode est d'environ un facteur de deux)

.

Notez que l'API "AE" est une alternative à, et non la version future de, l'API AnyEvent. Les deux API peuvent être utilisées de manière interchangeable et il n'existe aucun plan pour « basculer », donc si vous avez un doute, n'hésitez pas à utiliser l'API AnyEvent dans vos nouveaux

codes.

L'API AE étant complémentaire, tout ce qui est dans l'API AnyEvent n'est pas disponible, et vous devez toujours utiliser AnyEvent pour les fonctionnalités plus avancées. De plus, vous ne devriez pas "use AE" directement, "use AnyEvent" fournira l'espace de noms

AE.

Pour le moment, ces fonctions deviendront plus lentes que leurs équivalents par appel de méthode lors de l'utilisation d'AnyEvent::Strict ou d'AnyEvent::Debug::

wrap.

Crée un watcher de minuterie qui invoque le callback $cb après qu'au moins $after secondes se soient écoulées ($after peut être négatif ou 0).

callback.
