NOM

aerc-maildir - configuration Maildir pour aerc(1)

SYNOPSIS

aerc implémente le format maildir.

CONFIGURATION

La configuration Maildir de base peut être effectuée interactivement avec la commande :new-account.

Les options spécifiques à Maildir suivantes sont disponibles :

check-mail-cmd = <commande>

Commande à exécuter conjointement avec l'option check-mail.

Exemple :

check-mail-cmd = mbsync -a

check-mail-timeout = <durée>

Délai d'attente pour check-mail-cmd. La commande sera arrêtée si elle ne se termine pas dans cet intervalle et une erreur sera affichée. Augmentez par rapport à la valeur par défaut si des erreurs répétées se produisent.

Par défaut : 10s

source = maildir|maildirpp://<chemin>

La source indique le chemin du répertoire contenant vos maildirs plutôt qu'un maildir spécifique.

La partie chemin de l'URL suivant maildir:// doit être soit un chemin absolu préfixé par / soit un chemin relatif à votre répertoire personnel préfixé par ~. Par exemple :

source = maildir:///home/moi/mail

source = maildir://~/mail

Si votre maildir utilise la disposition de répertoire Maildir++, vous pouvez utiliser le schéma maildirpp:// à la place :

source = maildirpp:///home/moi/mail

source = maildirpp://~/mail
