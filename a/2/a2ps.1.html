DESCRIPTIO

N

Convertir les FICHIER(s) ou l'entrée standard en PostScript. Par défaut, la sortie est envoyée à l'imprimante par défaut. Un fichier de sortie peut être spécifié avec -o

.

Les arguments obligatoires des options longues le sont aussi pour les options courtes. Les options longues marquées d'un `*' nécessitent un argument oui/non, les options courtes correspondantes signifient

`oui'.

FICHIER

S

a2ps lit plusieurs fichiers avant les options de la ligne de commande. Dans l'ordre, ils sont

:
1
.
Le fichier de configuration du système (généralement /usr/local/etc/a2ps.cfg) sauf si vous avez défini la variable d'environnement A2PS_CONFIG, auquel cas a2ps lit le fichier vers lequel elle pointe
;
2
.
le fichier de configuration de l'utilisateur ($HOME/.a2ps/a
2psrc)
3
.
le fichier .a2psrc dans le répertoire courant.

Consultez le manuel info

pour plus d'informations
, y compris une d

fichier de configuration.
