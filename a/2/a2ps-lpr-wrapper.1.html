NOM

a2ps-lpr-wrapper — script d'encapsulation lp/lpr pour GNU a2ps sur Debian

SYNOPSIS

a2ps-lpr-wrapper [-d imprimante] [fichiers]

DESCRIPTION

Cette page de manuel documente brièvement la commande a2ps-lpr-wrapper.

a2ps-lpr-wrapper utilise soit lp soit lpr pour envoyer les fichiers à l'imprimante. Il détermine lequel des deux programmes est actuellement installé et ajoute les paramètres appropriés.

OPTIONS

-d imprimante
Imprimante système de destination.
fichiers
Liste des fichiers à imprimer.

VOIR AUSSI

a2ps(1).

Les programmes sont entièrement documentés par la documentation a2ps disponible via le système Info.
