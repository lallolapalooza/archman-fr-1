FBB::A2x(3bobcat) Convertisseur de texte vers X FBB::A2x(3bobcat)

NOM

FBB::A2x - Objets effectuant des conversions d'ascii vers x (n'importe quoi)

SYNTAXE

#include <bobcat/a2x>
Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB::A2x offrent l'équivalent C++ des fonctions standard de conversion de chaînes C++ comme stol, stoul, stod, etc. Ces fonctions de chaîne standard C++ sont extrêmement utiles et devraient probablement être préférées à l'utilisation des membres des objets A2x, mais A2x offre des avantages supplémentaires en ce sens qu'elle généralise ces fonctions à tout type pouvant être extrait d'objets istream.

ESPACE NOM

FBB
Tous les constructeurs, membres et opérateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

std::istringstream

CONSTRUCTEURS

o
A2x() :
Ce constructeur construit un objet A2x vide. Aucune information ne peut être convertie à partir d'un objet A2x ainsi construit.
o
A2x(char const *text) :
Ce constructeur stocke text. Si text représente une valeur textuelle d'un certain type, l'objet A2x peut être utilisé pour initialiser ou affecter cette valeur à une variable de ce type particulier. L'extraction est cependant toujours possible.
o
A2x(std::string const &str) :
Ce constructeur stocke le texte contenu dans str. Si ce texte représente une valeur textuelle d'un certain type, l'objet A2x peut être utilisé pour initialiser ou affecter cette valeur à une variable de ce type particulier. L'extraction est également toujours possible.

Les constructeurs de copie et de déplacement sont disponibles.

FONCTION MEMBRE STATIQUE

o
bool lastFail() :
Ce membre retourne true si la dernière conversion a échoué (c'est-à-dire que le membre fail() de l'objet a retourné true et retourne false sinon). Ce membre permet de vérifier le succès de l'extraction/conversion à l'aide d'objets A2x anonymes. Le membre retourne également true lorsqu'aucune conversion n'a encore été effectuée.
Notez que ce membre retourne la valeur d'un membre statique thread_local : différents threads ne peuvent pas inspecter le statut lastFail d'autres threads.

FONCTION MEMBRE

Tous les membres de la classe istringstream sont disponibles.

o
Type to() :
Ce membre retourne n'importe quel type Type supportant les extractions depuis les i[string]streams. Si l'extraction échoue, le membre good() de l'objet A2x retourne false, et la valeur par défaut de Type est retournée. Cet opérateur a été implémenté comme une fonction membre template. Il existe également un opérateur de conversion de type (voir ci-dessous), mais la variante de fonction membre peut être préférée à l'opérateur de conversion dans les situations où une désambiguïsation explicite est requise (par exemple, dans les cas où une conversion n'a pas de solution de type évidente, comme les insertions directes). Un exemple est fourni dans la section EXEMPLE ci-dessous.

OPERATEURS SURCHARGES

o
operator Type() :
Conversion vers n'importe quel type Type supportant les extractions depuis les istreams. Si l'extraction échoue, le membre good() de l'objet A2x retournera false, et la valeur par défaut de Type sera retournée. Cet opérateur a été implémenté comme un membre template.
o
istream &operator>>(istream &, Type &) :
Extraction vers n'importe quel type Type supportant les extractions depuis les istreams. Si l'extraction échoue, le membre good() de l'objet A2x retournera false, et la valeur par défaut de Type sera retournée (cette facilité est implicite par le fait que cette classe hérite de istringstream, mais il est probablement utile de souligner que l'opération d'extraction est toujours disponible).
o
A2x &operator=(char const *) :
Stocke un nouveau texte dans l'objet A2x, réinitialise les indicateurs d'état à ios::good. Si un pointeur nul est passé, une chaîne vide est stockée.
o
A2x &operator=(std::string const &) :
Stocke le texte contenu dans l'argument std::string dans l'objet A2x, réinitialise les indicateurs d'état à ios::good.

L'opérateur d'affectation surchargé est disponible.

EXEMPLE

    int x = A2x("12");
    A2x a2x("12.50");
    double d;
    d = a2x;
    a2x = "err";
    d = a2x;        // d vaut maintenant 0
    a2x = " a";
    char c = a2x;   // c vaut maintenant 'a'
                    // conversion explicite en `double’
    cout << A2x("12.4").to<double>() << endl;
