NOM

a2j_control - utilitaire pour contrôler le démon a2jmidid

SYNTAXE

a2j_control [OPTIONS]

OPTIONS

start
démarre le démon de pontage a2jmidid
stop
arrête le démon de pontage a2jmidid
status
interroge le statut du pont a2jmidid
exit
désactive le service D-Bus de a2jmidid
