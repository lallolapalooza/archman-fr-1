NOM

acpi_listen - Écouteur d'événements ACPI

SYNTAXE

acpi_listen [options]

DESCRIPTION

acpid est le capteur d'événements ACPI à l'échelle du système. acpi_listen est un outil simple et convivial pour le shell qui se connecte à acpid et écoute les événements. Lorsqu'un événement se produit, acpi_listen l'imprimera sur stdout.

OPTIONS

-c, --count événements
Recevoir jusqu'à un nombre maximum d'événements ACPI, puis quitter.
-s, --socketfile nom_fichier
Cette option change le nom du socket de domaine UNIX que acpid ouvre. La valeur par défaut est /var/run/acpid.socket.
-t, --time secondes
Écouter pendant le temps spécifié en secondes, avant de quitter.
-v, --version
Afficher les informations de version et quitter.
-h, --help
Afficher l'aide et quitter.

FICHIERS

/var/run/acpid.socket

BOGUES

Il n'y a pas de bogues connus. Pour signaler des bogues, voir AUTEURS ci-dessous.
