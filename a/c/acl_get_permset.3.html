ACL_GET_PERMSET(3) Manuel des fonctions de bibliothèque ACL_GET_PERMSET(3)

NOM

acl_get_permset — récupère l'ensemble de permissions d'une entrée ACL

BIBLIOTHÈQUE

Bibliothèque des listes de contrôle d'accès sous Linux (libacl, -lacl).

SYNTAXE

#include <sys/types.h>
#include <sys/acl.h>

int
acl_get_permset(acl_entry_t entry_d, acl_permset_t *permset_p);

DESCRIPTION

La fonction acl_get_permset() retourne dans permset_p un descripteur de l'ensemble de permissions dans l'entrée ACL indiquée par entry_d. Les opérations ultérieures utilisant le descripteur de l'ensemble de permissions retourné agissent sur l'ensemble de permissions au sein de l'entrée ACL.

Tous les descripteurs d'entrée ACL qui font référence à l'entrée visée par entry_d continueront de faire référence à ces entrées.

VALEUR DE RETOUR

La fonction acl_get_permset() retourne la valeur 0 en cas de succès ; sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_get_permset() retourne -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument entry_d n'est pas un descripteur valide pour une entrée ACL.

NORMES

IEEE Std 1003.1e draft 17 (“POSIX.1e”, abandonné)
