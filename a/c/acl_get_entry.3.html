ACL_GET_ENTRY(3) Manuel des fonctions de bibliothèque ACL_GET_ENTRY(3)

NOM

acl_get_entry — obtenir une entrée ACL

BIBLIOTHÈQUE

Bibliothèque de listes de contrôle d'accès Linux (libacl, -lacl).

SYNTAXE

#include <sys/types.h>
#include <sys/acl.h>

int
acl_get_entry(acl_t acl, int entry_id, acl_entry_t *entry_p);

DESCRIPTION

La fonction acl_get_entry() obtient un descripteur pour une entrée ACL tel que spécifié par entry_id dans l'ACL indiquée par l'argument acl. Si la valeur de entry_id est ACL_FIRST_ENTRY, alors la fonction renvoie dans entry_p un descripteur pour la première entrée ACL dans acl. Si la valeur de entry_id est ACL_NEXT_ENTRY, alors la fonction renvoie dans entry_p un descripteur pour la prochaine entrée ACL dans acl.

Si un appel est effectué à acl_get_entry() avec entry_id défini sur ACL_NEXT_ENTRY alors qu'il n'y a pas eu d'appel initial réussi à acl_get_entry(), ou d'appel réussi précédent à acl_get_entry() suite à un appel à acl_calc_mask(), acl_copy_int(), acl_create_entry(), acl_delete_entry(), acl_dup(), acl_from_text(), acl_get_fd(), acl_get_file(), acl_set_fd(), acl_set_file(), ou acl_valid(), alors l'effet n'est pas spécifié.

Les appels à acl_get_entry() ne modifient aucune entrée ACL. Les opérations ultérieures utilisant le descripteur d'entrée ACL renvoyé opèrent sur l'entrée ACL dans la mémoire de travail. L'ordre de toutes les entrées existantes dans l'ACL reste inchangé. Tous les descripteurs d'entrée ACL existants qui font référence à des entrées dans l'ACL continuent de faire référence à ces entrées. Tous les pointeurs ACL existants qui font référence à l'ACL référencée par acl continuent de faire référence à l'ACL.

VALEUR RENVOYÉE

Si la fonction obtient avec succès une entrée ACL, la fonction renvoie la valeur 1. Si l'ACL n'a pas d'entrées ACL, la fonction renvoie la valeur 0. Si la valeur de entry_id est ACL_NEXT_ENTRY et que la dernière entrée ACL de l'ACL a déjà été renvoyée par un appel précédent à acl_get_entry(), la fonction renvoie la valeur 0 jusqu'à ce qu'un appel réussi avec un entry_id de ACL_FIRST_ENTRY soit effectué. Sinon, la valeur -1 est renvoyée et errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_get_entry() renvoie -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument acl_p n'est pas un pointeur valide vers une ACL.

L'argument entry_id n'est ni ACL_NEXT_ENTRY ni ACL_FIRST_ENTRY.

NORMES

IEEE Std 1003.1e brouillon 17 (“POSIX.1e”, abandonné)

VOIR AUSSI
