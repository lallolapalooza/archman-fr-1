acl_error(3)

Paquet: acl

ACL_CHECK(3) Manuel des fonctions de bibliothèque ACL_CHECK(3)

NOM

acl_error — convertir un code d'erreur ACL en message texte

BIBLIOTHÈQUE

Bibliothèque des listes de contrôle d'accès Linux (libacl, -lacl).

SYNTAXE

#include <sys/types.h>
#include <acl/libacl.h>

const char *
acl_error(int code);

DESCRIPTION

La fonction acl_error() convertit un code d'erreur ACL tel que renvoyé par la fonction acl_check() en un message texte décrivant la condition d'erreur. Dans la locale « POSIX », acl_check() renvoie les descriptions suivantes pour les codes d'erreur.

ACL_MULTI_ERROR
« Plusieurs entrées »
ACL_DUPLICATE_ERROR
« Entrées dupliquées »
ACL_MISS_ERROR
« Entrée manquante ou incorrecte »
ACL_ENTRY_ERROR
« Type d'entrée invalide »

VALEUR DE RETOUR

La fonction acl_error() renvoie un message texte si le code d'erreur est reconnu, et une valeur de (const char *)NULL sinon.

NORMES

Il s'agit d'une extension non portable et spécifique à Linux aux fonctions de manipulation des ACL définies dans le projet abandonné IEEE Std 1003.1e draft 17 (« POSIX.1e »).

VOIR AUSSI

acl_check(3), acl_valid(3), acl(5)
