ACYCLIC(1) Manuel des commandes générales ACYCLIC(1)

NOM

acyclic - rendre un graphe orienté acyclique

SYNTAXE

acyclic [ -nv? ] [ -o fichier_sortie ] [ fichier ]

DESCRIPTION

acyclic est un filtre qui prend un graphe orienté en entrée et produit une copie du graphe avec suffisamment d'arêtes inversées pour rendre le graphe acyclique. L'arête inversée hérite de tous les attributs de l'arête originale. L'argument de fichier optionnel spécifie où le graphe d'entrée est stocké ; par défaut, le programme lit depuis stdin.

OPTIONS

Les options suivantes sont prises en charge :

-n
Aucune sortie n'est produite, bien que la valeur de retour indique si le graphe est acyclique ou non.
-v
Affiche des informations indiquant si le fichier est acyclique, contient un cycle ou est non orienté.
-o fichier_sortie
la sortie est écrite dans le fichier spécifié ; par défaut, la sortie est écrite sur stdout.
-?
cette option fait que le programme affiche les informations d'utilisation.

CODES DE RETOUR

acyclic retourne 0 si le graphe est acyclique ; 1 si le graphe contient un cycle ; 2 si le graphe est non orienté ; et 255 en cas d'erreur.

BOGUES

Si le graphe est strict et qu'il existe un cycle de longueur 2, les attributs de l'arête inversée sont perdus.

Certains attributs d'arêtes ne sont pas symétriques, se référant soit au nœud de tête, soit au nœud de queue. Actuellement, il n'existe aucun mécanisme ou convention pour les inverser ou les renommer correctement.
