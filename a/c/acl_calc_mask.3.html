acl_calc_mask(3)

Paquet: acl

Licences: LGPL

ACL_CALC_MASK(3) Manuel des fonctions de bibliothèque ACL_CALC_MASK(3)

NOM

acl_calc_mask — calculer le masque de la classe de groupe de fichiers

BIBLIOTHEQUE

Bibliothèque des listes de contrôle d'accès sous Linux (libacl, -lacl).

SYNTAXE

#include <sys/types.h>
#include <sys/acl.h>

int
acl_calc_mask(acl_t *acl_p);

DESCRIPTION

La fonction acl_calc_mask() calcule et définit les permissions associées à l'entrée ACL_MASK de l'ACL référencée par acl_p. La valeur des nouvelles permissions est l'union des permissions accordées par toutes les entrées de type de balise ACL_GROUP, ACL_GROUP_OBJ ou ACL_USER. Si l'ACL référencée par acl_p contient déjà une entrée ACL_MASK, ses permissions sont écrasées ; si elle ne contient pas d'entrée ACL_MASK, une entrée est ajoutée.

Si l'ACL référencée par acl_p ne contient pas assez d'espace pour la nouvelle entrée ACL, alors un espace de travail supplémentaire peut être alloué. Si l'espace de travail ne peut pas être augmenté à l'emplacement actuel, il peut être déplacé, l'ancien espace de travail est libéré et un pointeur vers le nouvel espace de travail est retourné via acl_p.

L'ordre des entrées existantes dans l'ACL est indéfini après cette fonction.

Tous les descripteurs d'entrée ACL existants qui font référence à des entrées dans l'ACL continuent de faire référence à ces entrées. Tous les pointeurs ACL existants qui font référence à l'ACL référencée par acl_p continuent de faire référence à l'ACL.

VALEUR DE RETOUR

La fonction acl_calc_mask() retourne la valeur 0 en cas de succès ; sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_calc_mask() retourne -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument acl n'est pas un pointeur valide vers une ACL.
[ENOMEM]
La fonction acl_calc_mask() est incapable d'allouer la mémoire nécessaire pour une entrée ACL_MASK.

NORMES

IEEE Std 1003.1e draft 17 (“POSIX.1e”, abandonné)

VOIR AUSSI
