acct(2) Manuel des appels système acct(2)

NOM

acct - activer ou désactiver la comptabilité des processus

BIBLIOTHEQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
int acct(const char *_Nullable path);
Macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

acct():

    Depuis glibc 2.21 :
        _DEFAULT_SOURCE
    Dans glibc 2.19 et 2.10 :
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Jusqu'à et y compris glibc 2.19 :
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPTION

L'appel système acct() active ou désactive la comptabilité des processus. S'il est appelé avec le nom de chemin d'un fichier existant comme argument, la comptabilité est activée et les enregistrements pour chaque processus se terminant sont ajoutés au fichier au fur et à mesure de sa terminaison. Un argument NULL désactive la comptabilité.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné et errno est définie pour indiquer l'erreur.

ERREURS

EACCES
L'autorisation d'écriture est refusée pour le fichier spécifié, ou l'autorisation de recherche est refusée pour l'un des répertoires dans le préfixe du chemin de path (voir aussi path_resolution(7)), ou path n'est pas un fichier ordinaire.
EFAULT
path pointe en dehors de votre espace d'adressage accessible.
EIO
Erreur lors de l'écriture dans le fichier path.
EISDIR
path est un répertoire.
ELOOP
Trop de liens symboliques ont été rencontrés lors de la résolution de path.
ENAMETOOLONG
path était trop long.
ENFILE
La limite globale du système sur le nombre total de fichiers ouverts a été atteinte.
ENOENT
Le path spécifié n'existe pas.
ENOMEM
Manque de mémoire.
ENOSYS
La comptabilité des processus BSD n'a pas été activée lors de la compilation du noyau du système d'exploitation. Le paramètre de configuration du noyau contrôlant cette fonctionnalité est CONFIG_BSD_PROCESS_ACCT.
ENOTDIR
Un composant utilisé comme répertoire dans path n'est effectivement pas un répertoire.
EPERM
Le processus appelant n'a pas les privilèges suffisants pour activer la comptabilité des processus. Sous Linux, la capacité CAP_SYS_PACCT est requise.
EROFS
path fait référence à un fichier sur un système de fichiers en lecture seule.
EUSERS
Il n'y a plus de structures de fichiers libres ou nous avons manqué de mémoire.

NORMES

Aucune.

HISTORIQUE

SVr4, 4.3BSD.

NOTES

Aucune comptabilité n'est produite pour les programmes exécutés lors d'un crash système. En particulier, les processus non terminés ne sont jamais comptabilisés.

La structure des enregistrements écrits dans le fichier de comptabilité est décrite dans acct(5).
