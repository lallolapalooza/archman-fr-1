ACL_GET_TAG_TYPE(3) Manuel des fonctions de bibliothèque ACL_GET_TAG_TYPE(3)

NOM

acl_get_tag_type — obtenir le type d'étiquette d'une entrée ACL

BIBLIOTHÈQUE

Bibliothèque des listes de contrôle d'accès Linux (libacl, -lacl).

SYNTAXE

#include <sys/types.h>
#include <sys/acl.h>

int
acl_get_tag_type(acl_entry_t entry_d, acl_tag_t *tag_type_p);

DESCRIPTION

La fonction acl_get_tag_type() assigne à la valeur pointée par tag_type_p le type d'étiquette pour l'entrée ACL indiquée par l'argument entry_d.

L'argument entry_d et tout autre descripteur d'entrée ACL qui fait référence à des entrées dans la même ACL continuent de faire référence à ces entrées. L'ordre de toutes les entrées existantes dans l'ACL reste inchangé.

VALEUR DE RETOUR

La fonction acl_get_tag_type() retourne la valeur 0 en cas de succès ; sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_get_tag_type() retourne -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument entry_d n'est pas un descripteur valide pour une entrée ACL.

NORMES

IEEE Std 1003.1e draft 17 (“POSIX.1e”, abandonné)
