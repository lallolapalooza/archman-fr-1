ACL_CLEAR_PERMS(3) Manuel des fonctions de bibliothèque ACL_CLEAR_PERMS(3)

NOM

acl_clear_perms — effacer toutes les permissions d'un ensemble de permissions ACL

BIBLIOTHÈQUE

Bibliothèque de listes de contrôle d'accès Linux (libacl, -lacl).

SYNOPIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_clear_perms(acl_permset_t permset_d);

DESCRIPTION

La fonction acl_clear_perms() efface toutes les permissions de l'ensemble de permissions référencé par l'argument permset_d.

Tous les descripteurs existants qui référencent permset_d continueront à référencer cet ensemble de permissions.

VALEUR DE RETOUR

La fonction acl_clear_perms() retourne la valeur 0 en cas de succès ; sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_clear_perms() retourne -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument permset_d n'est pas un descripteur valide pour un ensemble de permissions dans une entrée ACL.

NORMES

IEEE Std 1003.1e draft 17 (“POSIX.1e”, abandonné)
