NOM

accessdb - Affiche le contenu d'une base de données man-db dans un format lisible par l'homme

SYNTAXE

/usr/sbin/accessdb [-d?V] [<fichier-index>]

DESCRIPTION

accessdb affichera les données contenues dans une base de données man-db sous une forme lisible par l'homme. Par défaut, il affichera les données depuis /var/cache/man/index.<type-db>, où <type-db> dépend de la bibliothèque de base de données utilisée.

Fournir un argument à accessdb remplacera cette valeur par défaut.

OPTIONS

-d, --debug
Affiche des informations de débogage.
-?, --help
Affiche un message d'aide et quitte.
--usage
Affiche un court message d'utilisation et quitte.
-V, --version
Affiche les informations de version.
