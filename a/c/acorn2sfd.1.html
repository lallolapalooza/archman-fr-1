NOM

acorn2sfd - crée des fichiers sfd FontForge à partir de polices Acorn RISCOS

SYNTAXE

acorn2sfd [--help] [--includestrokes] [--version] [acorndirs]

DESCRIPTION

acorn2sfd prend une liste de noms de répertoires et tente de convertir les données de police dans chaque répertoire en l'un des fichiers sfd de FontForge.

Les polices Acorn RISCOS consistent en 2 fichiers Outlines et Intmetrics dans un répertoire.

OPTIONS

--help
Fournit une description avec une liste des options disponibles.
--includestrokes
Définit un indicateur pour inclure les tracés.
--version
Affiche la version actuelle.

VOIR AUSSI

fontforge(1) showttf(1) ttf2eps(1)
