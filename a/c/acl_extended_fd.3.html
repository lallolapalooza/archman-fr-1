ACL_EXTENDED_FD(3) Manuel des fonctions de bibliothèque ACL_EXTENDED_FD(3)

NOM

acl_extended_fd — tester des informations dans l'ACL par descripteur de fichier

BIBLIOTHÈQUE

Bibliothèque des listes de contrôle d'accès Linux (libacl, -lacl).

SYNOPSIS

#include <sys/types.h>
#include <acl/libacl.h>

int
acl_extended_fd(int fd);

DESCRIPTION

La fonction acl_extended_fd() retourne 1 si le fichier identifié par l'argument fd est associé à une ACL d'accès étendue. La fonction retourne 0 si le fichier n'a pas d'ACL d'accès étendue.

Une ACL étendue est une ACL contenant des entrées autres que les trois entrées requises de types de balises ACL_USER_OBJ, ACL_GROUP_OBJ et ACL_OTHER. Si le résultat de la fonction acl_extended_fd() pour un objet fichier est 0, alors l'ACL ne définit aucun droit d'accès discrétionnaire autre que ceux déjà définis par les bits de permissions de fichier traditionnels.

L'accès à l'objet fichier peut être restreint davantage par d'autres mécanismes, tels que les schémas de contrôle d'accès obligatoire. L'appel système access(2) peut être utilisé pour vérifier si un type d'accès donné à un objet fichier serait accordé.

VALEUR DE RETOUR

En cas de succès, la fonction acl_extended_fd() retourne 1 si l'objet fichier identifié par fd a une ACL d'accès étendue, et 0 si l'objet fichier identifié par fd n'a pas d'ACL d'accès étendue. Sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_extended_fd() retourne -1 et définit errno à la valeur correspondante :

[EBADF]
L'argument fd n'est pas un descripteur de fichier valide.
[ENOTSUP]
Le système de fichiers sur lequel se trouve le fichier identifié par fd ne prend pas en charge les ACL, ou les ACL sont désactivées.

NORMES

Ceci est une extension non portable et spécifique à Linux aux fonctions de manipulation d'ACL définies dans le projet IEEE Std 1003.1e (-abandonné).

VOIR AUSSI

access(2), acl_get_fd(3), acl(5)
