acl_create_entry(3)

Paquet: acl

Licences: LGPL

ACL_CREATE_ENTRY(3) Manuel des fonctions de bibliothèque ACL_CREATE_ENTRY(3)

NOM

acl_create_entry — crée une nouvelle entrée ACL

BIBLIOTHÈQUE

Bibliothèque de listes de contrôle d'accès Linux (libacl, -lacl).

SYNTAXE

#include <sys/types.h>
#include <sys/acl.h>

int
acl_create_entry(acl_t *acl_p, acl_entry_t *entry_p);

DESCRIPTION

La fonction acl_create_entry() crée une nouvelle entrée ACL dans l'ACL pointée par le contenu de l'argument pointeur acl_p. En cas de succès, la fonction renvoie un descripteur pour la nouvelle entrée ACL via entry_p.

Cette fonction peut entraîner l'allocation de mémoire. L'appelant devrait libérer toute mémoire libérable, lorsque la nouvelle ACL n'est plus requise, en appelant acl_free(3) avec (void*)*acl_p comme argument. Si le stockage de travail de l'ACL ne peut pas être augmenté à l'emplacement actuel, le stockage de travail de l'ACL pointée par acl_p peut être repositionné et le stockage de travail précédent est libéré. Un pointeur vers le nouveau stockage de travail est renvoyé via acl_p.

Les composants de la nouvelle entrée ACL sont initialisés de la manière suivante : le composant du type de balise ACL contient ACL_UNDEFINED_TAG, le composant qualificateur contient ACL_UNDEFINED_ID et l'ensemble des permissions n'a aucune permission activée. Tous les descripteurs d'entrée ACL existants qui font référence à des entrées dans l'ACL continuent de faire référence à ces entrées.

VALEUR DE RETOUR

La fonction acl_create_entry() renvoie la valeur 0 en cas de succès ; sinon, la valeur -1 est renvoyée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_create_entry() renvoie -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument acl_p n'est pas un pointeur valide vers une ACL.
[ENOMEM]
Le stockage de travail de l'ACL nécessite plus de mémoire que ce qui est autorisé par les contraintes de gestion de mémoire matérielles ou imposées par le système.

NORMES

Projet IEEE Std 1003.1e 17 (“POSIX.1e”, abandonné)
