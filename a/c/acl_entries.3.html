ACL_ENTRIES(3) Manuel des fonctions de bibliothèque ACL_ENTRIES(3)

NOM

acl_entries — retourne le nombre d'entrées dans une ACL

BIBLIOTHÈQUE

Bibliothèque de listes de contrôle d'accès Linux (libacl, -lacl).

SYNOPSIS

#include <sys/types.h>
#include <acl/libacl.h>

int
acl_entries(acl_t acl);

DESCRIPTION

La fonction acl_entries() retourne le nombre d'entrées ACL contenues dans l'ACL référencée par l'argument acl.

VALEUR DE RETOUR

La fonction acl_entries() retourne le nombre d'entrées dans acl en cas de succès ; sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes survient, la fonction acl_entries() retourne -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument acl n'est pas un pointeur valide vers une ACL.

NORMES

Il s'agit d'une extension non portable et spécifique à Linux des fonctions de manipulation d'ACL définies dans la version 17 du projet IEEE Std 1003.1e (“POSIX.1e”, abandonné).
