ACL_GET_QUALIFIER(3) Manuel des fonctions de bibliothèque ACL_GET_QUALIFIER(3)

NOM

acl_get_qualifier — récupérer le qualificateur d'une entrée ACL

BIBLIOTHÈQUE

Bibliothèque des listes de contrôle d'accès Linux (libacl, -lacl).

SYNTAXE

#include <sys/types.h>
#include <sys/acl.h>

void *
acl_get_qualifier(acl_entry_t entry_d);

DESCRIPTION

La fonction acl_get_qualifier() récupère le qualificateur de l'entrée ACL indiquée par l'argument entry_d dans l'espace de travail et renvoie un pointeur vers cet espace.

Si la valeur du type de balise dans l'entrée ACL à laquelle se réfère entry_d est ACL_USER, alors la valeur retournée par acl_get_qualifier() est un pointeur vers le type uid_t. Si la valeur du type de balise dans l'entrée ACL à laquelle se réfère entry_d est ACL_GROUP, alors la valeur retournée par acl_get_qualifier() est un pointeur vers le type gid_t. Si le type de balise dans l'entrée ACL à laquelle se réfère entry_d est un type de balise pour lequel un qualificateur n'est pas pris en charge, acl_get_qualifier() renvoie une valeur de (void *)NULL et la fonction échoue. Les opérations ultérieures utilisant le pointeur retourné opèrent sur une copie indépendante du qualificateur dans l'espace de travail, et ne modifieront pas le qualificateur de l'entrée ACL.

Cette fonction peut allouer de la mémoire. L'appelant doit libérer toute mémoire libérable, lorsque le nouveau qualificateur n'est plus requis, en appelant acl_free() avec la valeur void * retournée par acl_get_qualifier() comme argument.

L'argument entry_d et tout autre descripteur d'entrée ACL qui se réfère à des entrées dans l'ACL contenant l'entrée à laquelle se réfère entry_d continuent de se référer à ces entrées. L'ordre de toutes les entrées existantes dans l'ACL contenant l'entrée à laquelle se réfère entry_d reste inchangé.

VALEUR DE RETOUR

En cas de succès, la fonction renvoie un pointeur vers le qualificateur de balise qui a été récupéré dans l'espace de travail ACL. En cas d'erreur, une valeur de (void *)NULL est renvoyée et errno est définie de manière appropriée.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_get_qualifier() renvoie (void *)NULL et définit errno à la valeur correspondante :

[EINVAL]
L'argument entry_d n'est pas un descripteur valide pour une entrée ACL.

La valeur du type de balise dans l'entrée ACL référencée par l'argument entry_d n'est ni ACL_USER ni ACL_GROUP.

[ENOMEM]
La valeur à retourner nécessite plus de mémoire que ce qui est autorisé par les contraintes de gestion de mémoire imposées par le matériel ou le système.

NORMES

Projet IEEE Std 1003.1e 17 (“POSIX.1e”, abandonné)
