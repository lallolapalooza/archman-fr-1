ACL_CHECK(3) Manuel des fonctions de bibliothèque ACL_CHECK(3)

NOM

acl_check — vérifier la validité d'une ACL

BIBLIOTHÈQUE

Bibliothèque des listes de contrôle d'accès Linux (libacl, -lacl).

SYNTAXE

#include <sys/types.h>
#include <acl/libacl.h>

int
acl_check(acl_t acl, int *last);

DESCRIPTION

La fonction acl_check() vérifie la validité de l'ACL référencée par l'argument acl.

Les trois entrées requises ACL_USER_OBJ, ACL_GROUP_OBJ et ACL_OTHER doivent exister exactement une fois dans l'ACL. Si l'ACL contient des entrées ACL_USER ou ACL_GROUP, une entrée ACL_MASK est également requise. L'ACL peut contenir au plus une entrée ACL_MASK.

Les identifiants utilisateur doivent être uniques parmi toutes les entrées de type ACL_USER. Les identifiants de groupe doivent être uniques parmi toutes les entrées de type ACL_GROUP.

Si l'ACL référencée par acl est invalide, acl_check() retourne un code d'erreur positif qui indique le type d'erreur détecté. Les codes d'erreur symboliques suivants sont définis :

ACL_MULTI_ERROR
L'ACL contient plusieurs entrées ayant un type d'étiquette qui ne peut apparaître qu'une seule fois.
ACL_DUPLICATE_ERROR
L'ACL contient plusieurs entrées ACL_USER avec le même ID utilisateur, ou plusieurs entrées ACL_GROUP avec le même ID de groupe.
ACL_MISS_ERROR
Une entrée requise est manquante.
ACL_ENTRY_ERROR
L'ACL contient un type d'étiquette d'entrée invalide.

La fonction acl_error() peut être utilisée pour traduire les codes d'erreur en messages textuels.

De plus, si le pointeur last n'est pas NULL, acl_check() assigne le numéro de l'entrée ACL où l'erreur a été détectée à la valeur pointée par last. Les entrées sont numérotées à partir de zéro, dans l'ordre où elles seraient retournées par la fonction acl_get_entry().

VALEUR DE RETOUR

En cas de succès, la fonction acl_check() retourne 0 si l'ACL référencée par acl est valide, et un code d'erreur positif si l'ACL est invalide. Sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_check() retourne -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument acl n'est pas un pointeur valide vers une ACL.

NORMES

Il s'agit d'une extension non portable, spécifique à Linux, aux fonctions de manipulation d'ACL définies dans le projet abandonné IEEE Std 1003.1e draft 17 (“POSIX.1e”).
