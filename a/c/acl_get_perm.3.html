ACL_GET_PERM(3) Manuel des fonctions de bibliothèque ACL_GET_PERM(3)

NOM

acl_get_perm — tester une permission dans un ensemble de permissions ACL

BIBLIOTHÈQUE

Bibliothèque de listes de contrôle d'accès sous Linux (libacl, -lacl).

SYNOPSIS

#include <sys/types.h>
#include <acl/libacl.h>

int
acl_get_perm(acl_permset_t permset_d, acl_perm_t perm);

DESCRIPTION

La fonction acl_get_perm() teste si la permission spécifiée par l'argument perm (une des valeurs ACL_READ, ACL_WRITE, ACL_EXECUTE) est contenue dans l'ensemble de permissions ACL pointé par l'argument permset_d.

Tous les descripteurs existants qui font référence à permset_d continuent de faire référence à cet ensemble de permissions.

VALEUR DE RETOUR

En cas de succès, la fonction acl_get_perm() retourne 1 si la permission spécifiée par perm est contenue dans l'ensemble de permissions ACL permset_d, et 0 si la permission n'est pas contenue dans l'ensemble de permissions. Sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_get_perm() retourne -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument permset_d n'est pas un descripteur valide pour un ensemble de permissions dans une entrée ACL.

L'argument perm n'est pas une valeur acl_perm_t valide.

NORMES

Il s'agit d'une extension non portable et spécifique à Linux des fonctions de manipulation d'ACL définies dans le projet abandonné IEEE Std 1003.1e draft 17 (“POSIX.1e”).

VOIR AUSSI
