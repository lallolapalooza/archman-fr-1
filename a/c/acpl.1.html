NOM

acpl - compiler une architecture cible définie par décomposition

SYNTAXE

acpl [options] [itfile] [otfile]

DESCRIPTION

Le programme acpl compile un fichier d'architecture cible définie par décomposition itfile de type 'deco 0' en une architecture cible définie par décomposition compilée de type 'deco 1', stockée dans le fichier otfile.

Compiler une architecture définie par décomposition revient à calculer la matrice des distances de tous les sous-domaines possibles, à partir de la matrice des distances de tous les sous-domaines terminaux fournis dans le format 'deco 0'. Comme ce calcul est effectué en interne chaque fois qu'un format 'deco 0' est lu, et qu'il est quadratique en temps, la pré-compilation de l'architecture cible à l'aide de acpl peut faire gagner du temps lorsque l'on calcule de manière répétée des mappages sur une grande architecture cible 'deco 0' définie par décomposition.

Lorsque les bibliothèques appropriées ont été incluses lors de la compilation, acpl peut directement gérer des fichiers compressés, à la fois en entrée et en sortie. Un flux est traité comme compressé chaque fois que son nom est suffixé par une extension de fichier compressé, comme dans 'brol.tgt.bz2' ou '-.gz'. Les formats de compression qui peuvent être pris en charge sont le format bzip2 ('.bz2'), le format gzip ('.gz') et le format lzma ('.lzma').

Étant donné que les fichiers d'architecture cible définis par décomposition ont une taille quadratique par rapport au nombre de sommets cibles, en raison des structures de la matrice des distances, l'utilisation de fichiers compressés pour les stocker peut économiser beaucoup d'espace, en particulier pour les fichiers d'architecture cible compilés.

OPTIONS

-h
Afficher une aide.
-V
Afficher la version du programme et les droits d'auteur.

EXEMPLE

Créer une architecture cible de type cycle-connecté-cube de dimension 4, et la sauvegarder sous le format gzip(1) dans le fichier 'ccc4c.tgt.gz'. Le nom de fichier standard '-' est utilisé afin que la description de l'architecture cible 'deco 0' produite par amk_ccc(1) soit lue depuis l'entrée standard, via le pipe.

    $ amk_ccc 4 | acpl - ccc4c.tgt.gz

VOIR AUSSI

amk_grf(1), amk_ccc(1), atst(1), dgmap(1), gmap(1), gmtst(1).
