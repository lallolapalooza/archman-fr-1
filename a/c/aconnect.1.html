aconnect(1) Manuel des commandes générales aconnect(1)

NOM

aconnect - Gestionnaire de connexion du séquenceur ALSA

SYNTAXE

aconnect [-d] [-options] expéditeur destinataire
aconnect -i|-o [-options]
aconnect -x

DESCRIPTION

aconnect est un utilitaire pour connecter et déconnecter deux ports existants sur le système de séquenceur ALSA. Les ports avec la permission d'abonnement arbitraire, tels que ceux créés par aseqview(1), peuvent être connectés à n'importe quels ports de périphérique (MIDI) à l'aide d'aconnect. Par exemple, pour se connecter du port 64:0 au port 65:0, exécutez comme suit :

% aconnect 64:0 65:0

La connexion est unidirectionnelle, et toutes les données envoyées au port émetteur (64:0) sont redirigées vers le port récepteur (65:0). Lorsqu'un autre port (par exemple, 65:1) est attaché au même port émetteur, les données sont envoyées aux deux ports récepteurs. Pour la déconnexion, utilisez l'option -d.

% aconnect -d 64:0 65:0

L'adresse peut être donnée en utilisant le nom du client.

% aconnect External:0 Emu8000:1

Ensuite, le port 0 du client correspondant à la chaîne « External » est connecté au port 1 du client correspondant à « Emu8000 ».

Une autre fonction d'aconnect est de lister les ports présents selon la condition donnée. Les ports d'entrée, qui peuvent devenir des ports émetteurs, peuvent être listés avec l'option -i.

% aconnect -i
client 0: 'System' [type=kernel]
    0 'Timer           '
    1 'Announce        '
client 64: 'External MIDI-0' [type=kernel]
    0 'MIDI 0-0        '

De même, pour voir les ports de sortie, utilisez l'indicateur -o.

Vous pouvez supprimer toutes les connexions exportées existantes en utilisant l'option -x. Cette fonction est utile pour terminer les pilotes ALSA, car les modules avec des connexions de séquenceur ne peuvent pas être déchargés tant que leurs connexions ne sont pas supprimées.

OPTIONS

GESTION DES CONNEXIONS

-d, --disconnect
Déconnecter l'abonnement donné.
-e, --exclusive
Connecter les ports en mode exclusif. Ni le port émetteur ni le port récepteur ne pourront être connectés par d'autres ports.
-r, --real queue
Convertir les horodatages des paquets d'événements à la valeur actuelle de la file d'attente temps réel donnée. Cette option n'est cependant pas très utile, car le port récepteur doit utiliser (pas nécessairement posséder) la file d'attente spécifiée.
-t, --tick queue
Comme l'option -r, mais les horodatages sont convertis à la valeur actuelle de la file d'attente tick donnée.

LISTER LES PORTS

-i, --input
Lister les ports d'entrée (lisibles) existants. Cette option est exclusive à -o.
-o, --output
Lister les ports de sortie (inscriptibles) existants. Cette option est exclusive à -i.
-a, --all
Lister également les ports inactifs.
-l, --list
Lister l'état actuel des connexions. Les ports connectés et en cours de connexion depuis/vers chaque port sont listés ensemble. L'indicateur de suffixe [ex] signifie que la connexion est exclusive. Les indicateurs de suffixe [real:#] et [tick:#] signifient que la connexion inclut la conversion temps réel et tick sur la file d'attente listée, respectivement.

SUPPRIMER TOUTES LES CONNEXIONS

-x, --removeall
Supprimer toutes les connexions exportées.
