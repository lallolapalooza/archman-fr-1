acl_add_perm(3)

Paquet: acl

Licences: LGPL

ACL_ADD_PERM(3) Manuel des fonctions de bibliothèque ACL_ADD_PERM(3)

NOM

acl_add_perm — ajouter une permission à un ensemble de permissions ACL

BIBLIOTHEQUE

Bibliothèque des listes de contrôle d'accès Linux (libacl, -lacl).

SYNTAXE

#include <sys/types.h>
#include <sys/acl.h>

int
acl_add_perm(acl_permset_t permset_d, acl_perm_t perm);

DESCRIPTION

La fonction acl_add_perm() ajoute la permission contenue dans l'argument perm (l'un de ACL_READ, ACL_WRITE, ACL_EXECUTE) à l'ensemble de permissions référencé par l'argument permset_d. Une tentative d'ajout d'une permission déjà présente dans l'ensemble de permissions n'est pas considérée comme une erreur.

Tous les descripteurs existants qui font référence à permset_d continuent de faire référence à cet ensemble de permissions.

VALEUR DE RETOUR

La fonction acl_add_perm() renvoie la valeur 0 en cas de succès ; sinon, la valeur -1 est renvoyée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_add_perm() renvoie -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument permset_d n'est pas un descripteur valide pour un ensemble de permissions dans une entrée ACL.

L'argument perm ne contient pas une valeur acl_perm_t valide.

NORMES

IEEE Std 1003.1e draft 17 (“POSIX.1e”, abandonné)

VOIR AUSSI
