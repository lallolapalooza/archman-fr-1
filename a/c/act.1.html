NOM

act - Exécute les actions GitHub localement en spécifiant le nom de l'événement (par exemple, push) ou le nom d'une action directement.

SYNTAXE

**act [nom de l'événement à exécuter] [options]

Si aucun nom d'événement n'est passé, il utilisera par défaut "on: push". Si l'action ne gère qu'un seul événement, celui-ci sera utilisé par défaut au lieu de "on: push".

DESCRIPTION

Exécute les actions GitHub localement en spécifiant le nom de l'événement (par exemple, push) ou le nom d'une action directement.

OPTIONS

--action-cache-path="/build/.cache/act" Définit le chemin où les actions sont mises en cache et où les espaces de travail hôtes sont créés.

--action-offline-mode[=false] Si le contenu de l'action existe, il ne sera pas récupéré et téléchargé à nouveau. Si activé, cela désactivera le téléchargement forcé.

-a, --actor="nektos/act" Utilisateur qui a déclenché l'événement.

--artifact-server-addr="162.55.28.166" Définit l'adresse à laquelle le serveur d'artefacts se lie.

--artifact-server-path="" Définit le chemin où le serveur d'artefacts stocke les téléchargements et d'où il récupère les téléchargements. Si non spécifié, le serveur d'artefacts ne démarrera pas.

--artifact-server-port="34567" Définit le port où le serveur d'artefacts écoute.

-b, --bind[=false] Lie le répertoire de travail au conteneur, plutôt que de le copier.

--bug-report[=false] Affiche les informations système pour le rapport de bug.

--cache-server-addr="162.55.28.166" Définit l'adresse à laquelle le serveur de cache se lie.

--cache-server-external-url="" Définit l'URL externe si le serveur de cache est derrière un proxy. Par exemple : https://act-cache-server.example.com. Attention, il ne doit pas y avoir de barre oblique finale.

--cache-server-path="/build/.cache/actcache" Définit le chemin où le serveur de cache stocke les caches.

--cache-server-port=0 Définit le port où le serveur d'artefacts écoute. 0 signifie un port disponible aléatoirement.

--concurrent-jobs=0 Nombre maximum de tâches concurrentes à exécuter. Par défaut, le nombre de CPU disponibles.

--container-architecture="" Architecture qui devrait être utilisée pour exécuter les conteneurs, par exemple : linux/amd64. Si non spécifié, utilisera l'architecture par défaut de l'hôte. Nécessite Docker server API version 1.41+. Ignoré sur les plateformes de serveur Docker antérieures.

--container-cap-add=[] Capacités du noyau à ajouter aux conteneurs de flux de travail (par exemple, --container-cap-add SYS_PTRACE)

--container-cap-drop=[] Capacités du noyau à supprimer des conteneurs de flux de travail (par exemple, --container-cap-drop SYS_PTRACE)

--container-daemon-socket="" URI du socket du moteur Docker (par exemple : unix://~/.docker/run/docker.sock ou - pour désactiver le montage en miroir du socket)

--container-options="" Options de conteneur Docker personnalisées pour le conteneur de tâches sans propriété d'options dans la définition de la tâche.

--defaultbranch="" Le nom de la branche principale.

--detect-event[=false] Utilise le premier type d'événement du flux de travail comme événement qui a déclenché le flux de travail.

-C, --directory="." Répertoire de travail.

-n, --dryrun[=false] Désactive la création de conteneurs, valide uniquement la correction du flux de travail.

--env=[] Variables d'environnement à rendre disponibles aux actions avec une valeur optionnelle (par exemple, --env myenv=foo ou --env myenv).

--env-file=".env" Fichier d'environnement à lire et à utiliser comme variables d'environnement dans les conteneurs.

-e, --eventpath="" Chemin du fichier JSON d'événement.

--github-instance="github.com" Instance GitHub à utiliser. Utilisez ceci uniquement lorsque vous utilisez GitHub Enterprise Server.

-g, --graph[=false] Dessine les flux de travail.

-h, --help[=false] Aide pour act.

--input=[] Entrée d'action à rendre disponible aux actions (par exemple, --input myinput=foo).

--input-file=".input" Fichier d'entrée à lire et à utiliser comme entrée d'action.

--insecure-secrets[=false] NON RECOMMANDÉ ! Ne masque pas les secrets lors de l'affichage des journaux.

-j, --job="" Exécute un identifiant de tâche spécifique.

--json[=false] Affiche les journaux au format json.

-l, --list[=false] Liste les flux de travail.

--list-options[=false] Affiche une structure JSON des options compatibles.

--local-repository=[] Remplace le dépôt et la référence spécifiés par un dossier local (par exemple, https://github.com/test/test@v0=/home/act/test ou test/test@v0=/home/act/test, ce dernier correspond à n'importe quel hôte ou protocole).

--log-prefix-job-id[=false] Affiche l'identifiant de la tâche dans les journaux non-json au lieu du nom complet.

--man-page[=false] Affiche une page man générée sur stdout.

--matrix=[] Spécifie quelle configuration de matrice inclure (par exemple, --matrix java:13

--network="host" Définit un nom de réseau docker. Par défaut, host.

--no-cache-server[=false] Désactive le serveur de cache.

--no-recurse[=false] Indicateur pour désactiver l'exécution des flux de travail depuis les sous-répertoires du chemin spécifié dans l'indicateur '--workflows'/' -W'.

--no-skip-checkout[=false] Utilise actions/checkout au lieu de copier les fichiers locaux dans le conteneur.

-P, --platform=[] Image personnalisée à utiliser par plateforme (par exemple, -P ubuntu-18.04=nektos/act-environments-ubuntu:18.04).

--privileged[=false] Utilise le mode privilégié.

-p, --pull[=true] Télécharge les images docker même si elles sont déjà présentes.

-q, --quiet[=false] Désactive l'affichage des sorties des étapes.

--rebuild[=true] Reconstruit les images docker d'actions locales même si elles sont déjà présentes.

--remote-name="origin" Nom de la télécommande git qui sera utilisée pour récupérer l'URL du dépôt git.

--replace-ghe-action-token-with-github-com="" Si vous utilisez replace-ghe-action-with-github-com et que vous souhaitez utiliser des actions privées sur GitHub, vous devez définir un jeton d'accès personnel.

--replace-ghe-action-with-github-com=[] Si vous utilisez GitHub Enterprise Server et autorisez des actions spécifiées depuis GitHub (github.com), vous pouvez définir les actions sur ceci. (par exemple, --replace-ghe-action-with-github-com =github/super-linter)

-r, --reuse[=false] Ne supprime pas les conteneurs une fois les flux de travail terminés avec succès afin de maintenir l'état entre les exécutions.

--rm[=false] Supprime automatiquement les conteneurs/volumes après l'échec d'un ou plusieurs flux de travail.

-s, --secret=[] Secret à rendre disponible aux actions avec une valeur optionnelle (par exemple, -s mysecret=foo ou -s mysecret).

--secret-file=".secrets" Fichier avec une liste de secrets à lire (par exemple, --secret-file .secrets).

--strict[=false] Utilise un schéma de flux de travail strict.

--use-gitignore[=true] Contrôle si les chemins spécifiés dans .gitignore doivent être copiés dans le conteneur.

--use-new-action-cache[=false] Active l'utilisation du nouveau cache d'actions pour stocker les actions localement.

--userns="" Espace de noms utilisateur à utiliser.

--validate[=false] Valide les flux de travail.

--var=[] Variable à rendre disponible aux actions avec une valeur optionnelle (par exemple, --var myvar=foo ou --var myvar).

--var-file=".vars" Fichier avec une liste de variables à lire (par exemple, --var-file .vars).

-v, --verbose[=false] Sortie verbeuse.

--version[=false] Version de act.

-w, --watch[=false] Surveille le contenu du dépôt local et s'exécute lorsque les fichiers changent.

-W, --workflows="./.github/workflows/" Chemin du ou des fichiers de flux de travail.
