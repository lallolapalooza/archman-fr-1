NOM

ACCERCISER - un explorateur d'accessibilité interactif.

SYNTAXE

accerciser [--version] [--help]

DESCRIPTION

Cette page de manuel documente brièvement accerciser.

accerciser est un explorateur d'accessibilité interactif en Python pour le bureau GNOME. Il utilise AT-SPI pour inspecter et contrôler les widgets, vous permettant de vérifier si une application fournit les bonnes informations aux technologies d'assistance et aux frameworks de test automatisés. Accerciser dispose d'un framework de plugins simple que vous pouvez utiliser pour créer des vues personnalisées des informations d'accessibilité.

OPTIONS

--version Affiche le numéro de version.

-?, --help
Affiche un résumé des options.

CONFIGURATION

La configuration de metacity se trouve sous Préférences->Fenêtres et Préférences->Raccourcis clavier dans le panneau de menu. Une configuration avancée peut être réalisée directement via l'édition gconf (gconf-editor ou gconftool-2).

VOIR AUSSI

Une documentation complète sur accerciser se trouve dans le menu Aide d'accerciser.
