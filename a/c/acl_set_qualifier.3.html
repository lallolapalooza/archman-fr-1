NOM

acl_set_qualifier — définit le qualificateur d'une entrée ACL

BIBLIOTHÈQUE

Bibliothèque des listes de contrôle d'accès Linux (libacl, -lacl).

SYNOPSIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_set_qualifier(acl_entry_t entry_d, const void *qualifier_p);

DESCRIPTION

La fonction acl_set_qualifier() définit le qualificateur de l'entrée ACL indiquée par l'argument entry_d à la valeur référencée par l'argument qualifier_p. Si la valeur du type de balise dans l'entrée ACL référencée par entry_d est ACL_USER, alors la valeur référencée par qualifier_p doit être de type uid_t. Si la valeur du type de balise dans l'entrée ACL référencée par entry_d est ACL_GROUP, alors la valeur référencée par qualifier_p doit être de type gid_t. Si la valeur du type de balise dans l'entrée ACL référencée par entry_d est un type de balise pour lequel un qualificateur n'est pas pris en charge, acl_set_qualifier() renvoie une erreur.

Les descripteurs d'entrée ACL qui font référence à l'entrée référencée par entry_d continuent de faire référence à cette entrée. Cette fonction peut allouer de la mémoire. L'appelant doit libérer toute mémoire libérable, lorsque l'ACL n'est plus requise, en appelant acl_free() avec un pointeur vers l'ACL comme argument.

VALEUR DE RETOUR

La fonction acl_set_qualifier() renvoie la valeur 0 en cas de succès ; sinon, la valeur -1 est renvoyée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_set_qualifier() renvoie -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument entry_d n'est pas un descripteur valide pour une entrée ACL.

La valeur du type de balise dans l'entrée ACL référencée par l'argument entry_d n'est ni ACL_USER ni ACL_GROUP.

La valeur pointée par l'argument qualifier_p n'est pas valide.

[ENOMEM]
La fonction acl_set_qualifier() n'est pas capable d'allouer la mémoire requise pour le qualificateur ACL.

NORMES

IEEE Std 1003.1e draft 17 (“POSIX.1e”, abandonné)
