NOM

Acme::Alien::DontPanic - Module de test pour Alien::Base::ModuleBuild

VERSION

version 2.7200

DESCRIPTION

Alien::Base comprend des classes de base pour aider à la construction de modules "Alien::". Les modules de l'espace de noms Alien sont utilisés pour localiser et installer (si nécessaire) les bibliothèques externes dont d'autres modules Perl ont besoin.

Ce module est un module jouet pour tester l'efficacité du système Alien::Base::ModuleBuild. Ce module est dépendant d'un autre module jouet, Acme::Ford::Prefect, qui a besoin de la bibliothèque libdontpanic pour pouvoir nous donner la "réponse".
