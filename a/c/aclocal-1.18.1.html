ACLOCAL(1) Commandes utilisateur ACLOCAL(1)

NOM

aclocal - Génère aclocal.m4 en analysant configure.ac

SYNOPSIS

aclocal [OPTION]...

DESCRIPTION

Génère 'aclocal.m4' en analysant 'configure.ac' ou 'configure.in'

OPTIONS

--automake-acdir=DIR
répertoire contenant les fichiers m4 fournis par automake
--aclocal-path=CHEMIN
liste de répertoires séparés par des deux-points pour rechercher les fichiers locaux tiers
--system-acdir=DIR
répertoire contenant les fichiers système tiers
--diff[=COMMANDE]
exécute COMMANDE [diff -u] sur les fichiers M4 qui seraient modifiés (implique --install et --dry-run)
--dry-run
fait semblant, mais ne met à jour aucun fichier
--force
met toujours à jour le fichier de sortie
--help
affiche cette aide, puis quitte
-I DIR
ajoute un répertoire à la liste de recherche pour les fichiers .m4
--install
copie les fichiers tiers dans le premier répertoire -I
--output=FICHIER
place la sortie dans FICHIER (par défaut aclocal.m4)
--print-ac-dir
affiche le nom du répertoire contenant les fichiers m4 tiers système, puis quitte
--verbose
ne pas être silencieux
--version
affiche le numéro de version, puis quitte
-W, --warnings=CATEGORIE
rapporte les avertissements tombant dans CATEGORIE, par défaut $WARNINGS

Les catégories d'avertissement sont :

cross
problèmes de compilation croisée
gnu
normes de codage GNU (par défaut dans les modes gnu et gnits)
obsolete
fonctionnalités ou constructions obsolètes (par défaut)
override
redéfinitions par l'utilisateur de règles ou de variables Automake
portability
problèmes de portabilité (par défaut dans les modes gnu et gnits)
portability-recursive
variables Make imbriquées (par défaut avec -Wportability)
extra-portability
problèmes de portabilité supplémentaires liés à des outils obscurs
syntax
constructions syntaxiques douteuses (par défaut)
unsupported
fonctionnalités non prises en charge ou incomplètes (par défaut)

-W comprend aussi :

all
active tous les avertissements
none
désactive tous les avertissements
no-CATEGORIE
désactive les avertissements dans CATEGORIE
error
traite tous les avertissements activés comme des erreurs
