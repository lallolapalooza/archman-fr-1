acct(5) Manuel des formats de fichiers acct(5)

NOM

acct - fichier de comptabilisation des processus

SYNOPSIS

#include <sys/acct.h>

DESCRIPTION

Si le noyau est compilé avec l'option de comptabilisation des processus activée (CONFIG_BSD_PROCESS_ACCT), alors l'appel à acct(2) démarre la comptabilisation des processus, par exemple :


acct("/var/log/pacct");

Lorsque la comptabilisation des processus est activée, le noyau écrit un enregistrement dans le fichier de comptabilisation à chaque fois qu'un processus du système se termine. Cet enregistrement contient des informations sur le processus terminé, et est défini dans <sys/acct.h> comme suit :


#define ACCT_COMM 16
typedef u_int16_t comp_t;
struct acct {
    char ac_flag;           /* Drapeaux de comptabilisation */
    u_int16_t ac_uid;       /* UID de comptabilisation */
    u_int16_t ac_gid;       /* GID de comptabilisation */
    u_int16_t ac_tty;       /* Terminal de contrôle */
    u_int32_t ac_btime;     /* Heure de création du processus
                               (secondes depuis l'Epoch) */
    comp_t    ac_utime;     /* Temps CPU utilisateur */
    comp_t    ac_stime;     /* Temps CPU système */
    comp_t    ac_etime;     /* Temps écoulé */
    comp_t    ac_mem;       /* Utilisation moyenne de la mémoire (ko) */
    comp_t    ac_io;        /* Caractères transférés (inutilisé) */
    comp_t    ac_rw;        /* Blocs lus ou écrits (inutilisé) */
    comp_t    ac_minflt;    /* Défauts de page mineurs */
    comp_t    ac_majflt;    /* Défauts de page majeurs */
    comp_t    ac_swaps;     /* Nombre d'échanges (inutilisé) */
    u_int32_t ac_exitcode;  /* Statut de terminaison du processus
                               (voir wait(2)) */
    char      ac_comm[ACCT_COMM+1];
                            /* Nom de la commande (nom de base de la
                               dernière commande exécutée ; terminé par
                               null) */
    char      ac_pad[X];    /* octets de remplissage */
};
enum {          /* Bits pouvant être définis dans le champ ac_flag */
    AFORK = 0x01,           /* A exécuté fork, mais pas exec */
    ASU   = 0x02,           /* A utilisé les privilèges de superutilisateur */
    ACORE = 0x08,           /* A produit un core dump */
    AXSIG = 0x10            /* Tué par un signal */
};

Le comp_t type de données est une valeur en virgule flottante composée d'un exposant de base 8 sur 3 bits et d'une mantisse sur 13 bits. Une valeur c, de ce type peut être convertie en un entier (long) comme suit :

    v = (c & 0x1fff) << (((c >> 13) & 0x7) * 3);

Les champs ac_utime, ac_stime, et ac_etime mesurent le temps en « horloges » (clock ticks) ; divisez ces valeurs par sysconf(_SC_CLK_TCK) pour les convertir en secondes.

Format de fichier de comptabilisation de version 3

Depuis Linux 2.6.8, une version alternative facultative du fichier de comptabilisation peut être produite si l'option CONFIG_BSD_PROCESS_ACCT_V3 est définie lors de la compilation du noyau. Avec cette option définie, les enregistrements écrits dans le fichier de comptabilisation contiennent des champs supplémentaires, et la largeur des c_uid et ac_gid champs est élargie de 16 à 32 bits (en accord avec la taille accrue des UID et GID dans Linux 2.4 et les versions ultérieures). Les enregistrements sont définis comme suit :


struct acct_v3 {
    char      ac_flag;      /* Drapeaux */
    char      ac_version;   /* Toujours défini à ACCT_VERSION (3) */
    u_int16_t ac_tty;       /* Terminal de contrôle */
    u_int32_t ac_exitcode;  /* Statut de terminaison du processus */
    u_int32_t ac_uid;       /* UID réel */
    u_int32_t ac_gid;       /* GID réel */
    u_int32_t ac_pid;       /* ID de processus */
    u_int32_t ac_ppid;      /* ID du processus parent */
    u_int32_t ac_btime;     /* Heure de création du processus */
    float     ac_etime;     /* Temps écoulé */
    comp_t    ac_utime;     /* Temps CPU utilisateur */
    comp_t    ac_stime;     /* Temps système */
    comp_t    ac_mem;       /* Utilisation moyenne de la mémoire (ko) */
    comp_t    ac_io;        /* Caractères transférés (inutilisé) */
    comp_t    ac_rw;        /* Blocs lus ou écrits
                               (inutilisé) */
    comp_t    ac_minflt;    /* Défauts de page mineurs */
    comp_t    ac_majflt;    /* Défauts de page majeurs */
    comp_t    ac_swaps;     /* Nombre d'échanges (inutilisé) */
    char      ac_comm[ACCT_COMM]; /* Nom de la commande */
};

VERSIONS

Bien qu'il soit présent sur la plupart des systèmes, il n'est pas standardisé, et les détails varient quelque peu d'un système à l'autre.

STANDARDS

Aucune.

HISTORIQUE

glibc 2.6.

La comptabilisation des processus est originaire de BSD.

NOTES

Les enregistrements dans le fichier de comptabilisation sont ordonnés par l'heure de terminaison du processus.

Jusqu'à et y compris Linux 2.6.9, un enregistrement de comptabilisation distinct est écrit pour chaque thread créé à l'aide de la bibliothèque de threads NPTL ; depuis Linux 2.6.10, un seul enregistrement de comptabilisation est écrit pour l'ensemble du processus à la terminaison du dernier thread du processus.

Le /proc/sys/kernel/acct fichier, décrit dans proc(5), définit des paramètres qui contrôlent le comportement de la comptabilisation des processus lorsque l'espace disque est faible.
