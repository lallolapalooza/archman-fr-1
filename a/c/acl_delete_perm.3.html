acl_delete_perm(3)

Paquet: acl

ACL_DELETE_PERM(3) Manuel des fonctions de bibliothèque ACL_DELETE_PERM(3)

NOM

acl_delete_perm — supprimer une permission d'un ensemble de permissions ACL

BIBLIOTHÈQUE

Bibliothèque de listes de contrôle d'accès Linux (libacl, -lacl).

SYNOPSIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_delete_perm(acl_permset_t permset_d, acl_perm_t perm);

DESCRIPTION

La fonction acl_delete_perm() supprime la permission contenue dans l'argument perm (l'un de ACL_READ, ACL_WRITE, ACL_EXECUTE) de l'ensemble de permissions référencé par l'argument permset_d. Une tentative de suppression d'une permission qui n'est pas contenue dans l'ensemble de permissions n'est pas considérée comme une erreur.

Tous les descripteurs existants qui font référence à permset_d continuent de faire référence à cet ensemble de permissions.

VALEUR DE RETOUR

La fonction acl_delete_perm() renvoie la valeur 0 en cas de succès ; sinon, la valeur -1 est renvoyée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_delete_perm() renvoie -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument permset_d n'est pas un descripteur valide pour un ensemble de permissions au sein d'une entrée ACL.

L'argument perm ne contient pas une valeur acl_perm_t valide.

NORMES

IEEE Std 1003.1e draft 17 (“POSIX.1e”, abandonné)

VOIR AUSSI

acl_add_perm(3), acl_clear_perms(3), acl_get_perm(3), acl_get_permset(3), acl_set_permset(3), acl(5)
