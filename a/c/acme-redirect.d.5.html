acme-redirect.d(5) Manuel des formats de fichiers acme-redirect.d(5)

NOM

acme-redirect.d - configuration des certificats acme-redirect

SYNTAXE

/etc/acme-redirect.d/*.conf

DESCRIPTION

Ces fichiers configurent les certificats qui devraient être demandés et renouvelés par acme-redirect.

OPTIONS

name=

Le nom pour identifier ce certificat. Le certificat ne sera pas valide pour ce nom, à moins qu'il ne soit également listé dans dns_names.

dns_names=

La liste des noms pour lesquels ce certificat devrait être valide.

exec=

La liste des commandes qui devraient être exécutées. Vous pouvez l'utiliser pour déclencher le rechargement des certificats.

EXEMPLE

[cert]
name = "example.com"
dns_names = [
    "example.com",
    "www.example.com",
]
exec = [
    "systemctl reload nginx",
]
