NOM

acme-redirect - Petit démon http qui répond aux défis acme et redirige tout le reste vers https

SYNOPSIS

acme-redirect [-v|--verbose] [-c /etc/acme-redirect.conf] [--config-dir /etc/acme-redirect.d] [--acme-email <acme-email>] [--acme-url https://acme-v02.api.letsencrypt.org/directory] [--chall-dir /run/acme-redirect] [--data-dir /var/lib/acme-redirect] <sous-commande>

DESCRIPTION

acme-redirect est un petit serveur http qui implémente le protocole ACME (Automated Certificate Management Environment) et redirige tout le reste vers https. Il peut fonctionner directement sur le port 80 et prend en charge l'émission et le renouvellement automatiques des certificats dès la sortie de la boîte avec une configuration minimale.

DAEMON

Exécute le démon http.

-B <addr-liaison>, --bind-addr <addr-liaison>

L'adresse sur laquelle écouter. Par défaut, [::]:80.

--chroot

Chroot dans le répertoire de défi.

--user <utilisateur>

Se désidentifier de root vers cet utilisateur.

acme-redirect daemon

RENOUVELER

Renouvelle les certificats sur le point d'expirer et exécute les commandes données pour déclencher un rechargement de certificat.

-n, --dry-run

Ne fait rien en réalité, affiche seulement ce qui se passerait.

--force-renew

Renouvelle les certificats même s'ils ne sont pas sur le point d'expirer.

--skip-cleanup

Ne nettoie pas les anciens certificats qui ne sont plus actifs.

--skip-restarts

N'exécute pas les commandes exec configurées.

<certs ...>

Renouvelle uniquement des certificats spécifiques. Si aucun certificat n'est sélectionné explicitement, renouvelle tous les certificats.

acme-redirect renew

STATUT

Affiche les certificats actuellement disponibles et leur statut d'expiration.

acme-redirect status

RENOUVELLEMENT AUTOMATIQUE

Vous pouvez simplement exécuter acme-redirect renew périodiquement. Si vous utilisez systemd, vous pouvez utiliser le timer systemd avec :

systemctl enable --now acme-redirect-renew.timer

VOIR AUSSI

acme-redirect.conf(5), acme-redirect.d(5).
