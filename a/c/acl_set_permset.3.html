acl_set_permset(3)

Paquet: acl

Licences: LGPL

ACL_SET_PERMSET(3) Manuel des fonctions de bibliothèque ACL_SET_PERMSET(3)

NOM

acl_set_permset — définit l'ensemble des permissions dans une entrée ACL

BIBLIOTHÈQUE

Bibliothèque des listes de contrôle d'accès sous Linux (libacl, -lacl).

SYNTAXE

#include <sys/types.h>
#include <sys/acl.h>

int
acl_set_permset(acl_entry_t entry_d, acl_permset_t permset_d);

DESCRIPTION

La fonction acl_set_permset() définit l'ensemble des permissions de l'entrée ACL indiquée par l'argument entry_d aux permissions contenues dans l'argument permset_d.

Tous les descripteurs d'entrée ACL qui font référence à l'entrée contenant l'ensemble des permissions référencé par permset_d continueront à faire référence à ces entrées. Tous les descripteurs d'entrée ACL qui font référence à l'entrée référencée par entry_d continueront à faire référence à cette entrée.

VALEUR RENVOYÉE

La fonction acl_set_permset() renvoie la valeur 0 en cas de succès ; sinon, la valeur -1 est renvoyée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Si l'une des conditions suivantes se produit, la fonction acl_set_permset() renvoie -1 et définit errno à la valeur correspondante :

[EINVAL]
L'argument entry_d n'est pas un descripteur valide pour une entrée ACL.

L'argument permset_d n'est pas un descripteur valide pour un ensemble de permissions au sein d'une entrée ACL.

L'argument permset_d contient des valeurs qui ne sont pas des valeurs acl_permset_t valides.

NORMES

IEEE Std 1003.1e draft 17 (« POSIX.1e », abandonné)
