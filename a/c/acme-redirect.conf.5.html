acme-redirect.conf(5) Manuel des formats de fichiers acme-redirect.conf(5)

NOM

acme-redirect.conf - Fichiers de configuration de acme-redirect

SYNTAXE

/etc/acme-redirect.conf

DESCRIPTION

Ce fichier configure les paramètres généraux de acme-redirect. Pour configurer les certificats, consultez acme-redirect.d(5).

OPTIONS ([acme])

acme_email=

L'adresse e-mail de contact pour que votre fournisseur acme puisse vous joindre. Ils vous notifieront généralement si votre renouvellement automatique ne semble pas fonctionner, ou si le protocole acme va être mis à jour.

acme_url=

Le point d'accès acme à utiliser. La valeur par défaut est la production de LetsEncrypt.

renew_if_days_left=

Renouveler le certificat si le nombre de jours est égal ou inférieur. Vous rencontrerez des problèmes si vous le définissez à moins de 1. La valeur par défaut est 30.

OPTIONS ([system])

exec=

Une liste de hooks globaux de secours qui sont exécutés si la configuration du certificat n'en spécifie aucun. Les hooks sont attendus comme des commandes shell.

exec_extra=

Une liste de hooks globaux qui sont exécutés après le renouvellement de tout certificat et l'exécution de ses hooks. Les hooks sont attendus comme des commandes shell.

EXEMPLE

[acme]
acme_email = "nobody@example.com"
acme_url = "https://acme-staging-v02.api.letsencrypt.org/directory"
renew_if_days_left = 30
[system]
## Hooks par défaut si la configuration du certificat n'en définit aucun
exec = [
    "systemctl reload nginx",
]
## Exécuter ces hooks globalement pour tous les certificats
exec_extra = [
    "systemctl reload dovecot",
]
