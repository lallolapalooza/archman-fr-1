ASEQDUMP(1) Manuel des commandes générales ASEQDUMP(1)

NOM

aseqdump - afficher les événements reçus sur un port du séquenceur ALSA

SYNTAXE

aseqdump [-p client:port,...]

DESCRIPTION

aseqdump est un utilitaire en ligne de commande qui affiche les événements du séquenceur qu'il reçoit sous forme de texte.

Pour arrêter la réception, appuyez sur Ctrl+C.

OPTIONS

-h,--help
Affiche la liste des options.
-V,--version
Affiche la version actuelle.
-l,--list
Affiche une liste des ports d'entrée possibles.
-u,--ump=version
Définit la version MIDI du client. 0 pour le mode hérité, 1 pour le mode UMP MIDI 1.0, et 2 pour le mode UMP MIDI 2.0.
-r,--raw
Supprime la conversion automatique des événements entre les clients UMP et hérité.
-R,--raw-view
Affiche les valeurs brutes telles quelles. Les numéros de canal et les numéros de groupe UMP sont basés sur 0 dans ce mode. C'est le comportement par défaut.
-N,--normalized-view
Affiche les valeurs normalisées pour correspondre au MIDI 1.0. Les numéros de canal et les numéros de groupe UMP sont affichés comme des valeurs basées sur 1, c'est-à-dire que 1 est le plus petit nombre. La vélocité et les valeurs de données sont normalisées entre 0 et 127. Les valeurs pour le MIDI 2.0 sont affichées avec deux décimales (de 0,00 à 127,00). La molette de pitch est également normalisée entre -8192 et 8192.
-P,--percent-view
Affiche les valeurs en pourcentage. Les numéros de canal et les numéros de groupe UMP sont également affichés comme des valeurs basées sur 1 dans ce mode. La vélocité et les données sont normalisées entre 0 et 100%, affichées avec deux décimales. La molette de pitch est également normalisée entre -100% et 100%.
-p,--port=client:port,...
Définit le ou les ports du séquenceur à partir desquels les événements sont reçus.

Un client peut être spécifié par son numéro, son nom, ou un préfixe de son nom. Un port est spécifié par son numéro ; pour le port 0 d'un client, la partie ":0" de la spécification du port peut être omise.
