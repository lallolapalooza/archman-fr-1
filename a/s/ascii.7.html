DESCRIPTIO

ASCII est l'American Standard Code for Information Interchange (code standard américain pour l'échange d'informations). C'est un code sur 7 bits. De nombreux codes sur 8 bits (par ex. ISO/IEC 8859-1) contiennent ASCII dans leur moitié inférieure. L'équivalent international d'ASCII est connu sous le nom d'ISO/IEC

646-IRV.

NOTE

S

Historiqu

e

/etc/ascii (VII) apparaît dans le Manuel du programmeur

UNIX.

Sur les terminaux anciens, le code du trait de soulignement est affiché comme une flèche gauche, appelée backarrow, le caret est affiché comme une flèche vers le haut et la barre verticale a un trou au

milieu.

Les caractères majuscules et minuscules ne diffèrent que d'un seul bit et le caractère ASCII 2 ne diffère du guillemet double que d'un seul bit également. Cela a rendu beaucoup plus facile l'encodage mécanique des caractères ou avec un clavier électronique non basé sur un microcontrôleur, et cette association se trouvait sur les téléscripteurs

anciens.

iée par l'Institut des no
rmes des États-Unis d'
Amérique (USASI) en 1968.
