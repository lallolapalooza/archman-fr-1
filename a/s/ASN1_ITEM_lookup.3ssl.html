NOM

ASN1_ITEM_lookup, ASN1_ITEM_get - rechercher des structures ASN.1

SYNOPSIS

#include <openssl/asn1.h>
const ASN1_ITEM *ASN1_ITEM_lookup(const char *name);
const ASN1_ITEM *ASN1_ITEM_get(size_t i);

DESCRIPTION

ASN1_ITEM_lookup() retourne l'ASN1_ITEM nommé name.

ASN1_ITEM_get() retourne l'ASN1_ITEM avec l'indice i. Cette fonction retourne NULL si l'indice i est hors limites.

VALEUR DE RETOUR

ASN1_ITEM_lookup() et ASN1_ITEM_get() retournent une structure ASN1_ITEM valide ou NULL en cas d'erreur.

VOIR AUSSI
