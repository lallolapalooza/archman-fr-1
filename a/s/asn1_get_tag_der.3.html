NOM

asn1_get_tag_der - fonction API

SYNTAXE

#include <libtasn1.h>

int asn1_get_tag_der(const unsigned char * der, int der_len, unsigned char * cls, int * len, unsigned long * tag);

ARGUMENTS

const unsigned char * der
Données DER à décoder.
int der_len
Longueur des données DER à décoder.
unsigned char * cls
Variable de sortie contenant la classe décodée.
int * len
Variable de sortie contenant la longueur des données TAG DER.
unsigned long * tag
Variable de sortie contenant le tag décodé (peut être NULL).

DESCRIPTION

Décode la classe et le TAG à partir du code DER.

RETOURNE

Retourne ASN1_SUCCESS en cas de succès, ou une erreur.
