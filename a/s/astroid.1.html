astroid - client de messagerie électronique graphique, léger et rapide, de type threads-avec-tags, pour Notmuchastroid [options]Astroid est un agent utilisateur de messagerie électronique (MUA) léger et rapide qui fournit une interface graphique pour rechercher, afficher et composer des courriels, organisés en fils et en étiquettes. Il utilise le backend Notmuch pour des recherches ultra-rapides à travers une grande quantité d'e-mails.-c, --config config Remplace le chemin de configuration par défaut. Veuillez vous référer à la section CONFIGURATION pour plus de détails.

--disable-log Désactive la journalisation.

-h, --help Affiche le message d'aide et quitte.

--log-level level Remplace le niveau de journalisation configuré. Les options de niveau sont : trace, debug (par défaut), info, warn, error et fatal.

--log-stdout Écrit les journaux sur la sortie standard, quelle que soit toute autre configuration de journalisation.

-m, --mailto dest Ouvre la fenêtre de composition, en envoyant à l'URL ou à l'adresse dest.

-n, --new-config Génère un nouveau fichier de configuration et quitte.

--no-auto-poll Désactive l'interrogation automatique.

--refresh revision Met à jour la vue utilisateur d'une instance astroid en cours d'exécution avec les changements détectés dans le répertoire de courrier depuis revision. Vous pouvez obtenir la révision actuelle avec notmuch count --lastmod | cut -f3 (0 rafraîchira tous les index de fils). --{start,stop}-polling peut être utilisé comme alternative, mais pas avec --refresh.

--start-polling Demande à une instance astroid en cours d'exécution de surveiller les changements dans le répertoire de courrier et d'afficher une animation d'interrogation. Il faut appeler --stop-polling à la fin de l'interrogation externe (par exemple, par offlineimap) même en cas d'échec. --refresh peut être utilisé comme alternative, mais pas avec --{start,stop}-polling.

--stop-polling Arrête l'interrogation initiée par --start-polling et met à jour la vue utilisateur avec tous les changements détectés depuis l'exécution de --start-polling.

-t, --test-config Utilise le fichier de configuration de test. N'a de sens qu'à partir de la racine source.

--disable-plugins Désactive tous les plugins.L'emplacement du fichier de configuration est par défaut $XDG_CONFIG_HOME/astroid/config. La méthode préférée pour configurer une nouvelle installation d'astroid est d'utiliser --new-config pour générer un fichier de configuration initial, puis de l'éditer pour qu'il corresponde aux besoins de l'utilisateur. Vous trouverez tous les détails dans la documentation en ligne d'Astroid : https://github.com/astroidmail/astroid/wiki. Si $NOTMUCH_CONFIG est défini, il a la priorité sur la valeur configurée pour la base de données notmuch dans le fichier de configuration.

Vous pouvez personnaliser la vue des fils en plaçant vos propres fichiers HTML et SCSS dans $XDG_CONFIG_HOME/astroid/ui/, comme expliqué sur https://github.com/astroidmail/astroid/wiki/Customizing-the-user-interface.

Si $XDG_CONFIG_HOME n'est pas défini, il est par défaut ~/.config.Astroid est un agent utilisateur de messagerie électronique : tout ce qu'Astroid fournit est une interface graphique à votre courrier électronique (lire, visualiser, écrire, modifier, organiser). Ainsi, Astroid vous permet de lancer des actions qui dépendent des performances d'autres programmes pour récupérer, synchroniser, indexer, rechercher et envoyer réellement votre courrier. Il dépend de Notmuch pour l'indexation et la recherche, mais d'autres actions peuvent être gérées par de nombreux programmes différents :

  • La récupération et la synchronisation de votre courrier entre votre ordinateur local et votre fournisseur de services de messagerie peuvent être gérées par tout programme prenant en charge le format Maildir :
  • OfflineIMAP
  • mbsync
  • Gmailleer
  • ...
  • L'envoi de courrier via votre fournisseur de messagerie peut être géré par tout programme compatible sendmail :
  • msmtp
  • ...
  • L'édition peut être gérée par presque n'importe quel éditeur :
  • vim
  • emacs
  • gedit
  • ...

Bien que tous ces programmes (ou des programmes équivalents) doivent être configurés ; une fois qu'ils le sont, vous ne devriez plus avoir à y penser au-delà de l'utilisation d'astroid. Les options de configuration peuvent être plus ou moins fastidieuses et compliquées, selon le fournisseur de services de messagerie que vous utilisez.Maintenu par Gaute Hope eg@gaute.vetsj.com, assisté par d'autres contributeurs open source.
