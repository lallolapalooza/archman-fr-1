NOM

asn1_dup_node - fonction d'API

SYNOPSIS

#include <libtasn1.h>

asn1_node asn1_dup_node(asn1_node_const src, const char * src_name);

ARGUMENTS

asn1_node_const src
Nœud asn1 source.
const char * src_name
Nom du champ dans le nœud source.

DESCRIPTION

Crée une copie profonde d'une variable asn1_node. Cette fonction renverra une copie exacte de la structure fournie.

RETOURNE

Retourne NULL en cas d'échec.
