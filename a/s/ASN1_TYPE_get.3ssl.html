ASN1_TYPE_GET(3ssl) OpenSSL ASN1_TYPE_GET(3ssl)

NOM

ASN1_TYPE_get, ASN1_TYPE_set, ASN1_TYPE_set1, ASN1_TYPE_cmp, ASN1_TYPE_unpack_sequence, ASN1_TYPE_pack_sequence - Fonctions utilitaires ASN1_TYPE

SYNOPSIS

#include <openssl/asn1.h>
int ASN1_TYPE_get(const ASN1_TYPE *a);
void ASN1_TYPE_set(ASN1_TYPE *a, int type, void *value);
int ASN1_TYPE_set1(ASN1_TYPE *a, int type, const void *value);
int ASN1_TYPE_cmp(const ASN1_TYPE *a, const ASN1_TYPE *b);
void *ASN1_TYPE_unpack_sequence(const ASN1_ITEM *it, const ASN1_TYPE *t);
ASN1_TYPE *ASN1_TYPE_pack_sequence(const ASN1_ITEM *it, void *s,
                                   ASN1_TYPE **t);

DESCRIPTION

Ces fonctions permettent de manipuler une structure ASN1_TYPE. La structure ASN1_TYPE peut contenir n'importe quel type ASN.1 ou type construit comme une SEQUENCE : elle est effectivement équivalente au type ASN.1 ANY.

ASN1_TYPE_get() renvoie le type de a ou 0 en cas d'échec.

ASN1_TYPE_set() définit la valeur de a à type et value. Cette fonction utilise le pointeur value en interne, il ne doit donc **pas** être libéré après l'appel.

ASN1_TYPE_set1() définit la valeur de a à type et une copie de value.

ASN1_TYPE_cmp() compare les types ASN.1 a et b et renvoie 0 s'ils sont identiques et une valeur non nulle sinon.

ASN1_TYPE_unpack_sequence() tente d'analyser la SEQUENCE présente dans t en utilisant la structure ASN.1 it. En cas de succès, elle renvoie un pointeur vers la structure ASN.1 correspondant à it qui doit être libéré par l'appelant. En cas d'échec, elle renvoie NULL.

ASN1_TYPE_pack_sequence() tente d'encoder la structure ASN.1 s correspondant à it dans un ASN1_TYPE. En cas de succès, le ASN1_TYPE encodé est renvoyé. Si t et *t ne sont pas NULL, le type encodé est écrit dans t en écrasant les données existantes. Si t n'est pas NULL mais *t est NULL, le ASN1_TYPE renvoyé est écrit dans *t.

NOTES

Le type et la signification du paramètre value pour ASN1_TYPE_set() et ASN1_TYPE_set1() sont déterminés par le paramètre type. Si type est V_ASN1_NULL, value est ignoré. Si type est V_ASN1_BOOLEAN, le booléen est défini à TRUE si value n'est pas NULL. Si type est V_ASN1_OBJECT, value est une structure ASN1_OBJECT. Sinon, type est une structure ASN1_STRING. Si type correspond à un type primitif (ou un type chaîne) alors le contenu de ASN1_STRING contient les octets de contenu du type. Si type correspond à un type construit ou un type étiqueté (V_ASN1_SEQUENCE, V_ASN1_SET ou V_ASN1_OTHER) alors le ASN1_STRING contient l'encodage ASN.1 complet verbatim (y compris les octets d'étiquette et de longueur).

ASN1_TYPE_cmp() peut ne pas retourner zéro si deux types sont équivalents mais ont des encodages différents. Par exemple, l'unique octet de contenu de la valeur booléenne TRUE sous BER peut avoir n'importe quel encodage non nul, mais ASN1_TYPE_cmp() ne retournera zéro que si les valeurs sont identiques.

Si l'un ou les deux paramètres passés à ASN1_TYPE_cmp() sont NULL, la valeur de retour est non nulle. Techniquement, si les deux paramètres sont NULL, les deux types pourraient être des champs OPTIONNELS absents et donc devraient correspondre, cependant, passer des valeurs NULL pourrait aussi indiquer une erreur de programmation (par exemple, un type non analysable qui renvoie NULL) pour des types qui ne correspondent **pas**. Les applications doivent donc gérer séparément le cas de deux valeurs absentes.

VALEURS DE RETOUR

ASN1_TYPE_get() renvoie le type de l'argument ASN1_TYPE.

ASN1_TYPE_set() ne renvoie pas de valeur.

ASN1_TYPE_set1() renvoie 1 en cas de succès et 0 en cas d'échec.

ASN1_TYPE_cmp() renvoie 0 si les types sont identiques et une valeur non nulle sinon.

ASN1_TYPE_unpack_sequence() renvoie un pointeur vers une structure ASN.1 ou NULL en cas d'échec.

ASN1_TYPE_pack_sequence() renvoie une structure ASN1_TYPE en cas de succès ou NULL en cas d'échec.
