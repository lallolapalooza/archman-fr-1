NOM

asciinema-auth - Authentifier cette CLI avec un compte de serveur asciinema

SYNTAXE

asciinema auth [--server-url] [-q|--quiet] [-h|--help]

DESCRIPTION

S'authentifier auprès d'un serveur asciinema.

Crée un lien de compte utilisateur entre votre CLI locale et un compte de serveur asciinema. Facultatif pour le téléchargement avec la commande upload, obligatoire pour le streaming à distance avec les commandes stream et session.

OPTIONS

--server-url=URL
Spécifier une URL de serveur asciinema personnalisée pour l'authentification avec des serveurs auto-hébergés. Utiliser l'URL de base du serveur (par exemple, https://asciinema.example.com). Peut également être définie via la variable d'environnement ASCIINEMA_SERVER_URL ou l'option de fichier de configuration server.url. Si aucune URL de serveur n'est configurée via cette option, la variable d'environnement ou le fichier de configuration, il vous sera demandé d'en choisir une (par défaut asciinema.org), qui sera enregistrée comme défaut.
-q, --quiet
Supprimer les messages de diagnostic et les indicateurs de progression. Seuls les messages d'erreur seront affichés.
-h, --help
Imprimer l'aide (voir un résumé avec '-h')
