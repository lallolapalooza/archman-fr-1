NOM

asciinema-upload - Téléverser un enregistrement sur un serveur asciinema

SYNOPIS

asciinema upload [--server-url] [-q|--quiet] [-h|--help] <FICHIER>

DESCRIPTION

Téléverse un enregistrement sur un serveur asciinema.

Prend un fichier asciicast local et le téléverse sur un serveur asciinema (soit asciinema.org, soit un serveur auto-hébergé), retournant une URL d'enregistrement qui peut être partagée publiquement.

OPTIONS

--server-url=URL
Spécifie une URL de serveur asciinema personnalisée pour téléverser sur des serveurs auto-hébergés. Utilise l'URL de base du serveur (par exemple, https://asciinema.example.com). Peut également être définie via la variable d'environnement ASCIINEMA_SERVER_URL ou l'option de fichier de configuration server.url. Si aucune URL de serveur n'est configurée via cette option, la variable d'environnement ou le fichier de configuration, il vous sera demandé d'en choisir une (par défaut asciinema.org), qui sera enregistrée comme défaut.
-q, --quiet
Supprime les messages de diagnostic et les indicateurs de progression. Seuls les messages d'erreur seront affichés.
-h, --help
Affiche l'aide (voir un résumé avec '-h')
<FICHIER>
Le chemin vers le fichier d'enregistrement asciicast à téléverser, dans un format asciicast supporté (v1, v2 ou v3)
