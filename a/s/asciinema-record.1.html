--idle-time-limit =SE
CS
Limite le temps d'inactivité maximal enregistré entre les événements du terminal au nombre de secondes spécifié. Les longues pauses (comme lorsque vous vous éloignez du terminal) seront plafonnées à cette durée dans l'enregistrement, rendant la lecture plus agréable. Par exemple, --idle-time-limit 2.0 garantira qu'aucune pause de plus de 2 secondes n'apparaîtra dans l'enregistrement. Notez que cette option n'altère pas les informations de minutage originales (capturées) et intègre plutôt la valeur de limite de temps d'inactivité dans les métadonnées, qui est interprétée par les lecteurs de session au moment de la lecture. Cela permet d'ajuster la limite après l'enregistrement. Peut également être défini via l'option de fichier de configuration session.

--headle
ss
Enregistre en mode headless sans utiliser le terminal pour l'entrée/sortie. C'est utile pour les enregistrements automatisés ou scriptés où vous ne voulez pas qu'asciinema interfère avec la session de terminal actuelle. La commande enregistrée s'exécutera toujours normalement, mais asciinema n'affichera pas sa sortie dans votre terminal. Le mode headless est activé automatiquement lors de l'exécution dans un environnement où un terminal n'est pas
disponible.
--window-size =COLSxRO
WS
Remplace la taille de la fenêtre du terminal utilisée pour la session d'enregistrement. Spécifiez les dimensions sous la forme COLSxROWS (par exemple, 80x24 pour 80 colonnes par 24 lignes). Vous pouvez spécifier uniquement les colonnes (80x) ou uniquement les lignes (x24) pour ne remplacer qu'une seule dimension. C'est utile pour garantir des dimensions d'enregistrement cohérentes quelle que soit la taille actuelle de votre
terminal.
--retu
rn
Fait en sorte que la commande asciinema se termine avec le même code de statut que la session enregistrée. Par défaut, asciinema se termine avec le statut 0, quel que soit ce qui se passe dans la session enregistrée. Avec cette option, si la commande enregistrée se termine avec un statut non nul, asciinema se terminera également avec le même
statut.
