DESCRIPTIO

N

Les modèles de structures de données ASN.1 sont généralement définis dans OpenSSL à l'aide d'une série de macros telles que ASN1_SEQUENCE(), ASN1_SEQUENCE_END(), etc. À la place, des modèles peuvent également être définis entièrement sur la base de fonctions externes. Ces fonctions externes sont appelées pour effectuer des opérations telles que la création d'un nouveau ASN1_VALUE ou la conversion d'un ASN1_VALUE vers ou depuis l'encodage

DER.

La macro IMPLEMENT_EXTERN_ASN1() peut être utilisée pour créer une structure définie de cette manière. Le nom de la structure doit être fourni dans le paramètre sname. Le tag pour la structure (par exemple, généralement V_ASN1_SEQUENCE) doit être fourni dans le paramètre tag. Enfin, un pointeur vers une structure ASN1_EXTERN_FUNCS doit être fourni dans le paramètre f

ptrs.

La structure ASN1_EXTERN_FUNCS possède les entrées

suivantes.
app_da
ta
Un pointeur vers des données arbitraires spécifiques à
l'application.

ew

Renvoie une valeur pos

RN_ASN1().
asn1_ex_cle
ar
Une fonction « clear » responsable de l'effacement de toutes les données dans l' ASN1_VALUE passée dans *pval et de la rendre apte à être réutilisée. Le paramètre it est un pointeur vers l'objet modèle ASN1_ITEM créé via la macro IMPLEMENT_EXTE
RN_ASN1().
asn1_ex_d
2i
Une fonction « d2i » responsable de la conversion des données DER avec le tag tag et la classe class en un ASN1_VALUE. Si *pval n'est pas NULL, alors le ASN_VALUE vers lequel il pointe doit être réutilisé. Sinon, un nouveau ASN1_VALUE doit être alloué et stocké dans *pval. *in pointe vers les données DER à décoder et len est la longueur de ces données. Après le décodage, *in doit être mis à jour pour pointer vers l'octet suivant les données décodées. Si le ASN1_VALUE est considéré comme optionnel dans ce contexte, alors opt sera non nul. Sinon, il sera nul. Le paramètre it est un pointeur vers l'objet modèle ASN1_ITEM créé via la macro IMPLEMENT_EXTERN_ASN1(). Un pointeur vers le contexte ASN1_TLC actuel (qui peut être requis pour d'autres appels de fonctions ASN1) est passé dans le paramètre ctx.

L'entrée asn1_ex_d2i peut être NULL si asn1_ex_d2i_ex a été spécifiée à la

place.

Renvoie <= 0 en cas d'e

rreur ou une valeur pos
itive en cas de succès.
asn1_ex_i
2d
Une fonction « i2d » responsable de la conversion d'un ASN1_VALUE en encodage DER. À l'entrée, *pval contiendra le ASN1_VALUE à encoder. Si un tagage par défaut doit être utilisé, alors tag sera -1 à l'entrée. Sinon, si un tagage implicite doit être utilisé, alors tag et aclass seront le tag et la classe associée.

Si out n'est pas NULL, alors cette fonction doit écrire les données encodées DER dans le tampon dans *out, puis incrémenter *out pour pointer immédiatement après les données qui viennent d'être

écrites.

Si out est NULL, alors aucune donnée ne doit être écrite, mais la longueur doit être calculée et renvoyée comme si elle

l'était.

L'entrée asn1_ex_i2d peut être NULL si asn1_ex_i2d_ex a été spécifiée à la

place.

La valeur de retour doit être négative si une erreur fatale s'est

produite, ou 0 si une erreur non fatale s'est produite. S
inon, elle doit renvoyer la longueur des données encodées.
asn1_ex_pri
nt
Une fonction « print ». out est le BIO vers lequel imprimer la sortie. *pval est le ASN1_VALUE à imprimer. indent est le nombre d'espaces d'indentation à imprimer avant d'imprimer les données. fname est actuellement inutilisé et vaut toujours "". pctx est un pointeur vers le ASN1_PCTX pour l'opération d'impression.

Renvoie 0 en cas d'erreur ou une valeur positive en cas de succès. Si

la valeur de retour est 2, alors un saut de ligne supplémentair
e sera imprimé après les données imprimées par cette fonction.
