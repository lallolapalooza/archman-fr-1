DESCRIPTIO

N

aspell est un programme utilitaire qui se connecte à la bibliothèque Aspell afin qu'il puisse fonctionner comme un remplacement d'ispell -a, comme un correcteur orthographique indépendant, comme un utilitaire de test pour tester les fonctionnalités de la bibliothèque Aspell, et comme un utilitaire pour gérer les dictionnaires utilisés par la

bibliothèque.

La bibliothèque Aspell contient une interface permettant à d'autres programmes d'accéder directement à ses fonctions et réduisant ainsi la tâche complexe de la vérification orthographique à de simples appels de bibliothèque. La bibliothèque par défaut ne contient pas de listes de mots de dictionnaire. Pour ajouter des dictionnaires de langues, veuillez d'abord vérifier votre distribution pour des dictionnaires modifiés, sinon cherchez ici les dictionnaires de langues de base http://aspel

l.net.

Les informations suivantes décrivent les commandes et options utilisées par l'utilitaire

Aspell.

Cette page de manuel est maintenue séparément de la documentation officielle, elle peut donc être obsolète ou incomplète. La documentation officielle est maintenue sous forme de manuel Texinfo. Voir l'entrée `'aspell' dans info pour une docum

CONFIGURATIO

N

Aspell peut accepter des options via des fichiers de configuration globaux ou personnels afin que vous n'ayez pas à les spécifier chaque fois sur la ligne de commande. Le fichier de configuration global par défaut est /etc/aspell.conf ou un autre fichier spécifié par l'option --conf et est vérifié en premier. Le fichier de configuration par utilisateur par défaut ~/.aspell.conf situé dans le répertoire $HOME (ou un autre fichier spécifié par l'option --per-conf) est vérifié ensuite et remplace les options définies dans le fichier de configuration global. Les options spécifiées soit sur la ligne de commande, soit via une variable d'environnement remplacent celles spécifiées par l'un ou l'autre des fichiers de

configuration.

Chaque ligne du fichier de configuration a le format

:
option [value
]

où option est l'une des options standard de la bibliothèque ci-dessus, sans les tirets initiaux. Par exemple, la ligne suivante définira la langue par défaut sur l'allemand de Suisse

:
lang
de_CH

Il peut y avoir un nombre quelconque d'espaces entre l'option et la valeur, mais il ne peut s'agir que d'espaces, c'est-à-dire qu'il n'y a pas de '=' entre le nom de l'option et la valeur. Des commentaires peuvent également être inclus en les faisant précéder d'un '#' car tout ce qui se trouve entre un '#' et une nouvelle ligne est ignoré. Les lignes vides sont également autorisées. Le fichier /etc/aspell.conf est un bon exemple de la manière de définir ces o

ptions et le manuel d'Aspell contien
t des informations plus détaillées.
