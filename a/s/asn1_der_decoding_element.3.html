asn1_der_decoding_element(3) libtasn1 asn1_der_decoding_element(3)

NOM

asn1_der_decoding_element - fonction de l'API

SYNTAXE

#include <libtasn1.h>

int asn1_der_decoding_element(asn1_node * structure, const char * elementName, const void * ider, int len, char * errorDescription);

ARGUMENTS

asn1_node * structure
pointeur vers une structure ASN1
const char * elementName
nom de l'élément à remplir
const void * ider
vecteur contenant le codage DER de toute la structure.
int len
nombre d'octets de *der: der[0]..der[len-1]
char * errorDescription
chaîne terminée par null contenant des détails en cas d'erreur.

DESCRIPTION

Remplit l'élément nommé ELEMENTNAME avec les valeurs d'une chaîne de codage DER. La structure doit juste avoir été créée avec la fonction asn1_create_element(). Le vecteur DER doit contenir la chaîne de codage de toute la STRUCTURE. Si une erreur survient pendant la procédure de décodage, la * STRUCTURE est supprimée et mise à NULL.

Cette fonction est obsolète et pourrait simplement être un alias pour asn1_der_decoding dans les futures versions. Utilisez asn1_der_decoding() à la place.

RETOURNE

ASN1_SUCCESS si le codage DER est OK, ASN1_ELEMENT_NOT_FOUND si ELEMENT est NULL ou elementName == NULL, et ASN1_TAG_ERROR ou ASN1_DER_ERROR si le codage der ne correspond pas à la structure structure (*ELEMENT supprimé).
