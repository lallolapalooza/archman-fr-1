ASN1_STRING_length(3ssl)

Paquet: openssl

Licences: Apache-2.0

ASN1_STRING_LENGTH(3ssl) OpenSSL ASN1_STRING_LENGTH(3ssl)

NOM

ASN1_STRING_dup, ASN1_STRING_cmp, ASN1_STRING_set, ASN1_STRING_length, ASN1_STRING_type, ASN1_STRING_get0_data, ASN1_STRING_data, ASN1_STRING_to_UTF8 - Fonctions utilitaires ASN1_STRING

SYNTAXE

#include <openssl/asn1.h>
int ASN1_STRING_length(ASN1_STRING *x);
const unsigned char *ASN1_STRING_get0_data(const ASN1_STRING *x);
unsigned char *ASN1_STRING_data(ASN1_STRING *x);
ASN1_STRING *ASN1_STRING_dup(const ASN1_STRING *a);
int ASN1_STRING_cmp(ASN1_STRING *a, ASN1_STRING *b);
int ASN1_STRING_set(ASN1_STRING *str, const void *data, int len);
int ASN1_STRING_type(const ASN1_STRING *x);
int ASN1_STRING_to_UTF8(unsigned char **out, const ASN1_STRING *in);

DESCRIPTION

Ces fonctions permettent de manipuler une structure ASN1_STRING.

ASN1_STRING_length() retourne la longueur du contenu de x. x NE DOIT PAS être NULL.

ASN1_STRING_get0_data() retourne un pointeur interne vers les données de x. Comme il s'agit d'un pointeur interne, il ne doit être ni libéré ni modifié d'aucune manière. x NE DOIT PAS être NULL.

ASN1_STRING_data() est similaire à ASN1_STRING_get0_data(), sauf que la valeur retournée n'est pas constante. Cette fonction est obsolète : les applications doivent utiliser ASN1_STRING_get0_data() à la place.

ASN1_STRING_dup() retourne une copie de la structure a.

ASN1_STRING_cmp() compare a et b et retourne 0 si les deux sont identiques. Les types de chaînes et le contenu sont comparés.

ASN1_STRING_set() définit les données de la chaîne str au tampon data d'une longueur len. Les données fournies sont copiées. Si len est -1, la longueur est déterminée par strlen(data).

ASN1_STRING_type() retourne le type de x, en utilisant des constantes standard telles que V_ASN1_OCTET_STRING.

ASN1_STRING_to_UTF8() convertit la chaîne in au format UTF8, les données converties sont allouées dans un tampon dans *out. La longueur de out est retournée ou un code d'erreur négatif. Le tampon *out doit être libéré avec OPENSSL_free().

NOTES

Presque tous les types ASN1 dans OpenSSL sont représentés par une structure ASN1_STRING. D'autres types tels que ASN1_OCTET_STRING sont simplement des typedef vers ASN1_STRING et les fonctions appellent les équivalents ASN1_STRING. ASN1_STRING est également utilisé pour certains types CHOICE qui consistent entièrement en types de chaînes primitives tels que DirectoryString et Time.

Ces fonctions ne doivent pas être utilisées pour examiner ou modifier les types ASN1_INTEGER ou ASN1_ENUMERATED : les fonctions utilitaires INTEGER ou ENUMERATED pertinentes doivent être utilisées à la place.

En général, on ne peut pas supposer que les données retournées par ASN1_STRING_data() soient terminées par un nul ou ne contiennent pas de nuls intégrés. Le format réel des données dépendra du type de chaîne lui-même : par exemple, pour un IA5String, les données seront en ASCII, pour un BMPString, deux octets par caractère au format big-endian, et pour un UTF8String, ce sera au format UTF8.

Une prudence similaire doit être prise pour s'assurer que les données sont dans le bon format lors de l'appel à ASN1_STRING_set().

VALEUR DE RETOUR

ASN1_STRING_length() retourne la longueur du contenu de x.

ASN1_STRING_get0_data() et ASN1_STRING_data() retournent un pointeur interne vers les données de x.

ASN1_STRING_dup() retourne une structure ASN1_STRING valide ou NULL si une erreur s'est produite.

ASN1_STRING_cmp() retourne un entier supérieur, égal ou inférieur à 0, selon que a est supérieur, égal ou inférieur à b.

ASN1_STRING_set() retourne 1 en cas de succès ou 0 en cas d'erreur.

ASN1_STRING_type() retourne le type de x.

ASN1_STRING_to_UTF8() retourne le nombre d'octets dans la chaîne de sortie out ou une valeur négative si une erreur s'est produite.
