ASN1_AUX_CB(3ssl) OpenSSL ASN1_AUX_CB(3ssl)

NOM

ASN1_AUX, ASN1_PRINT_ARG, ASN1_STREAM_ARG, ASN1_aux_cb, ASN1_aux_const_cb - Données auxiliaires ASN.1

SYNOPSIS

#include <openssl/asn1t.h>
struct ASN1_AUX_st {
    void *app_data;
    int flags;
    int ref_offset;             /* Décalage de la valeur de référence */
    int ref_lock;               /* Décalage vers un CRYPTO_RWLOCK */
    ASN1_aux_cb *asn1_cb;
    int enc_offset;             /* Décalage de la structure ASN1_ENCODING */
    ASN1_aux_const_cb *asn1_const_cb; /* pour ASN1_OP_I2D_ et ASN1_OP_PRINT_ */
};
typedef struct ASN1_AUX_st ASN1_AUX;
struct ASN1_PRINT_ARG_st {
    BIO *out;
    int indent;
    const ASN1_PCTX *pctx;
};
typedef struct ASN1_PRINT_ARG_st ASN1_PRINT_ARG;
struct ASN1_STREAM_ARG_st {
    BIO *out;
    BIO *ndef_bio;
    unsigned char **boundary;
};
typedef struct ASN1_STREAM_ARG_st ASN1_STREAM_ARG;
typedef int ASN1_aux_cb(int operation, ASN1_VALUE **in, const ASN1_ITEM *it,
                        void *exarg);
typedef int ASN1_aux_const_cb(int operation, const ASN1_VALUE **in,
                              const ASN1_ITEM *it, void *exarg);

DESCRIPTION

Les structures de données ASN.1 peuvent être associées à un ASN1_AUX objet pour fournir des informations supplémentaires sur la structure ASN.1. Une ASN1_AUX structure est associée à la structure lors de la définition du modèle ASN.1. Par exemple, une ASN1_AUX structure sera associée en utilisant l'une des diverses macros de définition de modèle ASN.1 qui fournissent des informations auxiliaires telles que ASN1_SEQUENCE_enc(), ASN1_SEQUENCE_ref(), ASN1_SEQUENCE_cb_const_cb(), ASN1_SEQUENCE_const_cb(), ASN1_SEQUENCE_cb() ou ASN1_NDEF_SEQUENCE_cb().

Une ASN1_AUX structure contient les informations suivantes.

app_data
Données arbitraires de l'application
flags
Drapeaux indiquant la fonctionnalité auxiliaire prise en charge.

Le ASN1_AFLG_REFCOUNT drapeau indique que les objets prennent en charge le comptage de références.

Le ASN1_AFLG_ENCODING drapeau indique que l'encodage d'origine de l'objet sera enregistré.

Le ASN1_AFLG_BROKEN drapeau est un contournement pour les encodeurs défectueux où la valeur de longueur de la séquence peut être incorrecte. Cela ne devrait généralement pas être utilisé.

Le ASN1_AFLG_CONST_CB drapeau indique que la forme « const » de la ASN1_AUX fonction de rappel devrait être utilisée de préférence à la forme non const.

ref_offset
Si le ASN1_AFLG_REFCOUNT drapeau est défini, cette valeur est supposée être un décalage dans la ASN1_VALUE structure où un CRYPTO_REF_COUNT peut être trouvé aux fins du comptage de références.
ref_lock
Si le ASN1_AFLG_REFCOUNT drapeau est défini, cette valeur est supposée être un décalage dans la ASN1_VALUE structure où un CRYPTO_RWLOCK peut être trouvé aux fins du comptage de références.
asn1_cb
Une fonction de rappel qui sera invoquée à divers moments pendant le traitement de la ASN1_VALUE. Voir ci-dessous pour plus de détails.
enc_offset
Décalage dans l' ASN1_VALUE objet où l'encodage d'origine de l'objet sera enregistré si le ASN1_AFLG_ENCODING drapeau a été défini.
asn1_const_cb
Une fonction de rappel qui sera invoquée à divers moments pendant le traitement de la ASN1_VALUE. Celle-ci est utilisée de préférence à la asn1_cb fonction de rappel si le ASN1_AFLG_CONST_CB drapeau est défini. Voir ci-dessous pour plus de détails.

Pendant le traitement d'un ASN1_VALUE objet, les fonctions de rappel définies via asn1_cb ou asn1_const_cb seront invoquées à la suite de divers événements indiqués via le operation paramètre. La valeur de *in sera l' ASN1_VALUE objet étant traité sur la base du modèle dans it. Un paramètre supplémentaire spécifique à l'opération peut être passé dans exarg. Les opérations actuellement prises en charge sont les suivantes. Les fonctions de rappel devraient retourner une valeur positive en cas de succès ou zéro en cas d'erreur, sauf indication contraire ci-dessous.

ASN1_OP_NEW_PRE
Invoqué lors du traitement d'une structure CHOICE, SEQUENCE ou NDEF_SEQUENCE avant l'allocation d'un ASN1_VALUE objet. La fonction de rappel peut allouer le ASN1_VALUE lui-même et le stocker dans *pval. Si elle le fait, elle devrait retourner 2 depuis la fonction de rappel. En cas d'erreur, elle devrait retourner 0.
ASN1_OP_NEW_POST
Invoqué lors du traitement d'une structure CHOICE, SEQUENCE ou NDEF_SEQUENCE après l'allocation d'un ASN1_VALUE objet. L'objet alloué se trouve dans *pval.
ASN1_OP_FREE_PRE
Invoqué lors du traitement d'une structure CHOICE, SEQUENCE ou NDEF_SEQUENCE juste avant qu'un ASN1_VALUE soit libéré. Si la fonction de rappel a initialement construit le ASN1_VALUE via ASN1_OP_NEW_PRE alors elle devrait le libérer à ce moment et retourner 2 depuis la fonction de rappel. Sinon, elle devrait retourner 1 pour succès ou 0 pour erreur.
ASN1_OP_FREE_POST
Invoqué lors du traitement d'une structure CHOICE, SEQUENCE ou NDEF_SEQUENCE juste après la libération des sous-structures ASN1_VALUE .
ASN1_OP_D2I_PRE
Invoqué lors du traitement d'une structure CHOICE, SEQUENCE ou NDEF_SEQUENCE juste avant une opération « d2i » pour le ASN1_VALUE.
ASN1_OP_D2I_POST
Invoqué lors du traitement d'une structure CHOICE, SEQUENCE ou NDEF_SEQUENCE juste après une opération « d2i » pour le ASN1_VALUE.
ASN1_OP_I2D_PRE
Invoqué lors du traitement d'une structure CHOICE, SEQUENCE ou NDEF_SEQUENCE juste avant une opération « i2d » pour le ASN1_VALUE.
ASN1_OP_I2D_POST
Invoqué lors du traitement d'une structure CHOICE, SEQUENCE ou NDEF_SEQUENCE juste après une opération « i2d » pour le ASN1_VALUE.
ASN1_OP_PRINT_PRE
Invoqué lors du traitement d'une structure SEQUENCE ou NDEF_SEQUENCE juste avant l'impression de la ASN1_VALUE. L' exarg argument sera un pointeur vers une ASN1_PRINT_ARG structure (voir ci-dessous).
ASN1_OP_PRINT_POST
Invoqué lors du traitement d'une structure SEQUENCE ou NDEF_SEQUENCE juste après l'impression de la ASN1_VALUE. L' exarg argument sera un pointeur vers une ASN1_PRINT_ARG structure (voir ci-dessous).
ASN1_OP_STREAM_PRE
Invoqué juste avant la diffusion des données ASN1_VALUE en utilisant un encodage de longueur indéfinie. L' exarg argument sera un pointeur vers une ASN1_STREAM_ARG structure (voir ci-dessous).
ASN1_OP_STREAM_POST
Invoqué juste après la diffusion des données ASN1_VALUE en utilisant un encodage de longueur indéfinie. L' exarg argument sera un pointeur vers une ASN1_STREAM_ARG structure (voir ci-dessous).
ASN1_OP_DETACHED_PRE
Invoqué juste avant le traitement des données ASN1_VALUE comme une valeur « détachée » (comme utilisée dans CMS et PKCS7). L' exarg argument sera un pointeur vers une ASN1_STREAM_ARG structure (voir ci-dessous).
ASN1_OP_DETACHED_POST
Invoqué juste après le traitement des données ASN1_VALUE comme une valeur « détachée »; valeur (comme utilisée dans CMS et PKCS7). Le exarg argument sera un pointeur vers une ASN1_STREAM_ARG structure (voir ci-dessous).
ASN1_OP_DUP_PRE
Invoqué juste avant qu'un ASN1_VALUE ne soit dupliqué via un appel à ASN1_item_dup().
ASN1_OP_DUP_POST
Invoqué juste après qu'un ASN1_VALUE n'ait été dupliqué via un appel à ASN1_item_dup().
ASN1_OP_GET0_LIBCTX
Invoqué afin d'obtenir le OSSL_LIB_CTX associé à un ASN1_VALUE le cas échéant. Un pointeur vers un OSSL_LIB_CTX doit être stocké dans *exarg si une telle valeur existe.
ASN1_OP_GET0_PROPQ
Invoqué afin d'obtenir la chaîne de requête de propriétés associée à un ASN1_VALUE le cas échéant. Un pointeur vers la chaîne de requête de propriétés doit être stocké dans *exarg si une telle valeur existe.

Un objet ASN1_PRINT_ARG est utilisé lors du traitement des opérations de rappel ASN1_OP_PRINT_PRE et ASN1_OP_PRINT_POST . Il contient les informations suivantes.

out
Le BIO utilisé pour imprimer les données.
ndef_bio
Le nombre actuel d'espaces d'indentation qui doivent être utilisés pour imprimer ces données.
pctx
Le contexte pour l'opération ASN1_PCTX .

Un objet ASN1_STREAM_ARG est utilisé lors du traitement des opérations de rappel ASN1_OP_STREAM_PRE, ASN1_OP_STREAM_POST, ASN1_OP_DETACHED_PRE et ASN1_OP_DETACHED_POST . Il contient les informations suivantes.

out
Le BIO vers lequel acheminer les données
ndef_bio
Le BIO avec les filtres ajoutés
boundary
La limite d'E/S de flux.

VALEURS DE RETOUR

Les rappels renvoient 0 en cas d'erreur et une valeur positive en cas de succès. Certaines opérations nécessitent des valeurs de succès positives spécifiques comme indiqué ci-dessus.

VOIR AUSSI

HISTORIQUE

Le ASN1_aux_const_cb() rappel et les types d'opération ASN1_OP_GET0_LIBCTX et ASN1_OP_GET0_PROPQ ont été ajoutés dans OpenSSL 3.0.
