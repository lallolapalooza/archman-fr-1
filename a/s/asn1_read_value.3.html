asn1_read_value(3)

Paquet: libtasn1

asn1_read_value(3) libtasn1 asn1_read_value(3)

NOM

asn1_read_value - fonction API

SYNTAXE

#include <libtasn1.h>

int asn1_read_value(asn1_node_const root, const char * name, void * ivalue, int * len);

ARGUMENTS

asn1_node_const root
pointeur vers une structure.
const char * name
le nom de l'élément à l'intérieur d'une structure que vous souhaitez lire.
void * ivalue
vecteur qui contiendra le contenu de l'élément, doit être un pointeur vers des cellules mémoire déjà allouées (peut être NULL).
int * len
nombre d'octets de *value: value[0]..value[len-1]. Initialement contient la taille de value.

DESCRIPTION

Retourne la valeur d'un élément à l'intérieur d'une structure. Si un élément est OPTIONNEL et que cette fonction retourne ASN1_ELEMENT_NOT_FOUND, cela signifie que cet élément n'était pas présent dans l'encodage DER qui a créé la structure. Le premier élément d'un SEQUENCE_OF ou SET_OF est nommé "?1". Le second "?2" et ainsi de suite. Si le root fourni est un nœud vers un élément de séquence spécifique, alors le mot-clé "?CURRENT" est également acceptable et indique l'élément de séquence actuel de ce nœud.

Notez qu'il peut y avoir des valeurs valides de longueur zéro. Dans ces cas, cette fonction réussira et len sera zéro.

ENTIER

VALUE contiendra un entier en complément à deux.

entier=-1 -> value[0]=0xFF , len=1. entier=1 -> value[0]=0x01 , len=1.

ENUMERATED

Comme ENTIER (mais seulement avec des nombres non négatifs).

BOOLEAN

VALUE sera la chaîne de caractères terminée par null "TRUE" ou "FALSE" et LEN=5 ou LEN=6.

IDENTIFIANT D'OBJET : VALUE sera une chaîne de caractères terminée par null avec chaque nombre séparé par un point (c.-à-d. "1.2.3.543.1").

LEN = strlen(VALUE)+1

UTCTIME

VALUE sera une chaîne de caractères terminée par null dans l'un des formats suivants : "YYMMDDhhmmss+hh'mm'" ou "YYMMDDhhmmss-hh'mm'". LEN=strlen(VALUE)+1.

GENERALIZEDTIME

VALUE sera une chaîne de caractères terminée par null dans le même format que celui utilisé pour définir la valeur.

CHAÎNE OCTET : VALUE contiendra la chaîne octet et LEN sera le nombre d'octets.

GENERALSTRING

VALUE contiendra la chaîne générale et LEN sera le nombre d'octets.

CHAÎNE DE BITS : VALUE contiendra la chaîne de bits organisée par octets et LEN sera le nombre de bits.

CHOICE

Si NAME indique un type CHOICE, VALUE spécifiera l'alternative sélectionnée.

ANY

Si NAME indique un type ANY, VALUE indiquera l'encodage DER de la structure réellement utilisée.

RETOURNE

ASN1_SUCCESS si la valeur est retournée, ASN1_ELEMENT_NOT_FOUND si name n'est pas un élément valide, ASN1_VALUE_NOT_FOUND s'il n'y a pas de valeur pour l'élément sélectionné, et ASN1_MEM_ERROR si le vecteur de valeur n'est pas assez grand pour stocker le résultat, et dans ce cas len contiendra le nombre d'octets nécessaires. Dans le cas où les données stockées sont de longueur nulle, cette fonction peut retourner ASN1_SUCCESS même si len fourni est zéro.
