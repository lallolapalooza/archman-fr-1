asciinema(1) Manuel des commandes générales asciinema(1)

NOM

asciinema - Enregistreur, diffuseur et lecteur de sessions terminal

SYNTAXE

asciinema [-q|--quiet] [-h|--help] [-V|--version] <sous-commandes>

DESCRIPTION

Enregistreur, diffuseur et lecteur de sessions terminal

OPTIONS

-q, --quiet
Supprime les messages de diagnostic et les indicateurs de progression. Seuls les messages d'erreur seront affichés.
-h, --help
Imprime l'aide (voir un résumé avec '-h')
-V, --version
Imprime la version

SOUS-COMMANDES

asciinema-record(1)
Enregistre une session terminal
asciinema-stream(1)
Diffuse une session terminal
asciinema-session(1)
Enregistre et diffuse une session terminal
asciinema-play(1)
Lit une session terminal
asciinema-upload(1)
Téléverse un enregistrement sur un serveur asciinema
asciinema-auth(1)
Authentifie cette CLI avec un compte de serveur asciinema
asciinema-cat(1)
Concatène plusieurs enregistrements
asciinema-convert(1)
Convertit un enregistrement vers un autre format
