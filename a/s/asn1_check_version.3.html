NOM

asn1_check_version - Fonction d'API

SYNTAXE

#include <libtasn1.h>

const char * asn1_check_version(const char * req_version);

ARGUMENTS

const char * req_version
Numéro de version requis, ou NULL.

DESCRIPTION

Vérifie que la version de la bibliothèque est au minimum celle demandée et renvoie la chaîne de version ; renvoie NULL si la condition n'est pas satisfaite. Si un NULL est passé à cette fonction, aucune vérification n'est effectuée, mais la chaîne de version est simplement renvoyée.

Voir ASN1_VERSION pour une chaîne req_version appropriée.

RETOURNE

Chaîne de version de la bibliothèque d'exécution, ou NULL si la bibliothèque d'exécution ne répond pas au numéro de version requis.
