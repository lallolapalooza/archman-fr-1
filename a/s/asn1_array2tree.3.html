NOM

asn1_array2tree - Fonction d'API

SYNTAXE

#include <libtasn1.h>

int asn1_array2tree(const asn1_static_node * array, asn1_node * definitions, char * errorDescription);

ARGUMENTS

const asn1_static_node * array
spécifiez le tableau qui contient les déclarations ASN.1
asn1_node * definitions
retourne le pointeur vers la structure créée par les déclarations ASN.1 du *TABLEAU
char * errorDescription
retourne la description de l'erreur.

DESCRIPTION

Crée les structures nécessaires pour gérer les définitions ASN.1.
array est un vecteur créé par asn1_parser2array().

RETOURNE

ASN1_SUCCESS si la structure a été créée correctement, ASN1_ELEMENT_NOT_EMPTY si * definitions n'est pas NULL, ASN1_IDENTIFIER_NOT_FOUND s'il y a un identifiant dans le fichier qui n'est pas défini (voir errorDescription pour plus d'informations), ASN1_ARRAY_ERROR si le tableau pointé par array est erroné.
