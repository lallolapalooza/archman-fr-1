NOM

asn1_get_length_ber - Fonction API

SYNTAXE

#include <libtasn1.h>

long asn1_get_length_ber(const unsigned char * ber, int ber_len, int * len);

ARGUMENTS

const unsigned char * ber
Données BER à décoder.
int ber_len
Longueur des données BER à décoder.
int * len
Variable de sortie contenant la longueur du champ de longueur BER.

DESCRIPTION

Extrait un champ de longueur des données BER. La différence avec asn1_get_length_der() est que cette fonction retournera une longueur même si la valeur a un encodage indéfini.

RETOURNE

Retourne la valeur de longueur décodée, ou une valeur négative si la valeur était trop grande.
