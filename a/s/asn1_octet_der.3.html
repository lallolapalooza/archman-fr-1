NOM

asn1_octet_der - fonction de l'API

SYNTAXE

#include <libtasn1.h>

void asn1_octet_der(const unsigned char * str, int str_len, unsigned char * der, int * der_len);

ARGUMENTS

const unsigned char * str
les données d'entrée.
int str_len
longueur de STR (str[0]..str[*str_len-1]).
unsigned char * der
chaîne encodée retournée.
int * der_len
nombre d'octets significatifs de DER (der[0]..der[der_len-1]).

DESCRIPTION

Crée un encodage DER longueur-valeur pour les données d'entrée. L'encodage DER des données d'entrée sera placé dans la variable der.

Notez que la balise OCTET STRING n'est pas incluse dans la sortie.

Cette fonction ne retourne aucune valeur car on s'attend à ce que der_len contienne suffisamment d'octets pour stocker la chaîne plus l'encodage DER. La taille de l'encodage DER peut être obtenue en utilisant asn1_length_der().
