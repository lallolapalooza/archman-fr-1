NOM

asdlgen - compilateur du langage de description de syntaxe abstraite (ASDL).

SYNOPSIS

asdlgen COMMANDE [ OPTIONS ] FICHIER ...

où COMMANDE est l'une des suivantes :

help

affiche des informations sur les options disponibles sur la sortie standard.

version

affiche la version de asdlgen sur la sortie standard.

c++ ou cxx

génère du code C++.

sml

génère du code SML.

check

vérifie la correction des spécifications d'entrée, mais ne génère pas de sortie.

DESCRIPTION

Asdlgen lit les fichiers spécifiés, qui doivent contenir des déclarations de modules et de vues ASDL, et produit du code de sérialisation et désérialisation.

OPTIONS

OPTIONS COMMUNES

-n

Ne pas écrire de fichiers de sortie. Écrire plutôt la liste des fichiers qui auraient été écrits sur la sortie standard.

-d DIR, --output-directory=DIR

Spécifie le répertoire de sortie pour placer les fichiers générés. Par défaut, la sortie sera placée dans le même répertoire que le fichier d'entrée à partir duquel elle a été produite.

--gen=NAMES

Spécifie les composants à générer, où NAMES est une liste de noms séparés par des virgules parmi les suivants :
•types — génère les définitions de types à partir de la spécification ASDL.
•memory — génère le sérialiseur mémoire
•file — génère le sérialiseur de fichier
•sexp — génère le sérialiseur S-Expression (SML uniquement).

OPTIONS C++

--base-include=FICHIER

Spécifie le nom du fichier d'en-tête C++ qui définit les types et fonctions ASDL primitifs. La valeur par défaut est asdl/asdl.hxx.

OPTIONS SML

--cm=FICHIER

Génère un fichier CM pour le sérialiseur ; cela définira une bibliothèque CM. Notez que si la spécification ASDL inclut des modules primitifs, ceux-ci seront inclus dans la liste des structures exportées, mais les fichiers source de support devront être ajoutés manuellement au fichier CM.

--mlb=FICHIER

Génère un fichier MLB pour le sérialiseur. Notez que si la spécification ASDL inclut des modules primitifs, ceux-ci seront inclus dans la liste des structures exportées, mais les fichiers source de support devront être ajoutés manuellement au fichier MLB.
