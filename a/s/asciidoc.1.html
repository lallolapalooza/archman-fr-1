NOM

asciidoc - convertit un fichier texte AsciiDoc en HTML ou DocBook

SYNTAXE

asciidoc [OPTIONS] FICHIER

DESCRIPTION

La commande asciidoc(1) traduit le fichier texte AsciiDoc FICHIER en DocBook ou HTML. Si FICHIER est - alors l'entrée standard est utilisée.

OPTIONS

-a, --attribute=ATTRIBUT

Définit ou supprime un attribut de document. ATTRIBUT est formaté comme NOM=VALEUR. Les attributs de ligne de commande ont la priorité sur les attributs du document et des fichiers de configuration. Les formes alternatives acceptables sont NOM (la VALEUR est vide par défaut) ; NOM! (supprime l'attribut NOM) ; NOM=VALEUR@ (ne surcharge pas les attributs du document ou des fichiers de configuration). Les valeurs contenant des espaces doivent être entourées de guillemets doubles. Cette option peut être spécifiée plusieurs fois. Un attribut spécial nommé trace contrôle l'affichage des informations de diagnostic.

-b, --backend=BACKEND

Format de sortie du backend : docbook45, docbook5, xhtml11, html4, html5, slidy, wordpress ou latex (le backend latex est expérimental). Vous pouvez également utiliser les alias de backend html (alias de xhtml11) ou docbook (alias de docbook45). Par défaut, c'est html. L'option --backend est également utilisée pour gérer les plugins de backend (voir COMMANDES DES PLUGINS).

-f, --conf-file=FICHIER_CONF

Utilise le fichier de configuration FICHIER_CONF. Les fichiers de configuration sont traités dans l'ordre de la ligne de commande (après les fichiers de configuration implicites). Cette option peut être spécifiée plusieurs fois.

--doctest

Exécute les doctests Python dans le module asciidoc.

-d, --doctype=DOCTYPE

Type de document : article, manpage ou book. Le type de document book n'est supporté que par les backends docbook. Le type de document par défaut est article.

-c, --dump-conf

Affiche la configuration sur la sortie standard.

--filter=FILTRE

Spécifie le nom d'un filtre à charger (utilisé pour charger les filtres qui ne sont pas auto-chargés). Cette option peut être spécifiée plusieurs fois. L'option --filter est également utilisée pour gérer les plugins de filtres (voir COMMANDES DES PLUGINS).

-h, --help [SUJET]

Affiche l'aide sur le SUJET. --help sujets affichera une liste des sujets d'aide, --help syntaxe résumera la syntaxe AsciiDoc, --help manpage affichera la page man d'AsciiDoc.

-e, --no-conf

Exclut les fichiers de configuration chargés implicitement, à l'exception de ceux dont le nom est similaire au fichier d'entrée (infile.conf et infile-backend.conf).

-s, --no-header-footer

Supprime l'en-tête et le pied de page du document.

-o, --out-file=FICHIER_SORTIE

Écrit la sortie dans le fichier FICHIER_SORTIE. Par défaut, utilise le nom de base du fichier d'entrée avec l'extension du backend. Si l'entrée est stdin, alors le fichier de sortie par défaut est stdout. Si FICHIER_SORTIE est - alors la sortie standard est utilisée.

-n, --section-numbers

Numérote automatiquement les titres des sections HTML. Synonyme de --attribute numbered.

--safe

Active le mode sécurisé. Le mode sécurisé est désactivé par défaut. Le mode sécurisé d'AsciiDoc ignore les sections potentiellement dangereuses dans les fichiers source AsciiDoc.

--theme=THEME

Spécifie un nom de thème. Synonyme de --attribute theme=THEME. L'option --theme est également utilisée pour gérer les plugins de thèmes (voir COMMANDES DES PLUGINS).

-v, --verbose

Affiche de manière détaillée les informations de traitement et les vérifications des fichiers de configuration sur stderr.

--version

Affiche le numéro de version du programme.

COMMANDES DES PLUGINS

Les options --filter, --backend et --theme de la commande asciidoc(1) sont utilisées pour installer, supprimer et lister les plugins de filtres, backends et thèmes AsciiDoc. Syntaxe :

asciidoc OPTION install FICHIER_ZIP [REPERTOIRE_PLUGINS]
asciidoc OPTION remove NOM_PLUGIN [REPERTOIRE_PLUGINS]
asciidoc OPTION list
asciidoc OPTION build FICHIER_ZIP SOURCE_PLUGIN

Où :

OPTION

L'option --filter, --backend ou --theme d'asciidoc(1) spécifiant le type de plugin.

NOM_PLUGIN

Un nom de plugin unique contenant uniquement des caractères alphanumériques ou des traits de soulignement.

FICHIER_ZIP

Un fichier Zip contenant les ressources du plugin, le nom doit commencer par le nom du plugin, par exemple my_filter-1.0.zip pour le filtre my_filter.

REPERTOIRE_PLUGINS

Le répertoire contenant les plugins installés. Chaque plugin est contenu dans son propre sous-répertoire portant le même nom que le plugin. REPERTOIRE_PLUGINS est $HOME/.asciidoc/filters (pour les plugins de filtres), $HOME/.asciidoc/backends (pour les plugins de backend) ou $HOME/.asciidoc/themes (pour les plugins de thèmes) par défaut.

SOURCE_PLUGIN

Le nom d'un répertoire contenant les fichiers source du plugin ou le nom d'un seul fichier source.

Les commandes de plugin effectuent les actions suivantes :

install

Crée un sous-répertoire dans REPERTOIRE_PLUGINS portant le même nom que le plugin, puis extrait FICHIER_ZIP à l'intérieur.

remove

Supprime le sous-répertoire du plugin NOM_PLUGIN et tout son contenu de REPERTOIRE_PLUGINS.

list

Liste les noms et emplacements de tous les plugins de filtre ou de thème installés (y compris les plugins standard installés dans le répertoire de configuration global).

build

Crée un fichier de plugin nommé FICHIER_ZIP contenant les fichiers et sous-répertoires spécifiés par SOURCE_PLUGIN. Les noms de fichiers et de répertoires commençant par un point sont ignorés.

VARIABLES D'ENVIRONNEMENT

SOURCE_DATE_EPOCH

Si la variable d'environnement SOURCE_DATE_EPOCH est définie sur un timestamp UNIX, alors les attributs {docdate}, {doctime}, {localdate} et {localtime} sont calculés dans le fuseau horaire UTC, avec tous les timestamps plus récents que SOURCE_DATE_EPOCH remplacés par SOURCE_DATE_EPOCH. (Ceci aide les logiciels utilisant AsciiDoc à générer des builds reproductibles.)

EXEMPLES

asciidoc nom_fichier_asciidoc.txt

Génère simplement un fichier html à partir de nom_fichier_asciidoc.txt dans le répertoire courant en utilisant asciidoc.

asciidoc -b html5 nom_fichier_asciidoc.txt

Utilise le commutateur -b pour utiliser l'un des backends proposés ou un autre que vous avez installé sur votre ordinateur.

asciidoc -a data-uri -a icons -a toc -a max-width=55em article.txt

Utilise le commutateur -a pour définir des attributs depuis la ligne de commande. AsciiDoc a généré son guide utilisateur HTML autonome contenant CSS, JavaScript et images incorporés à partir du modèle d'article AsciiDoc avec cette commande.

asciidoc -b html5 -d manpage asciidoc.1.txt

Génère la page man asciidoc en utilisant le backend html5.
