NOM

asn1_der_decoding2 - Fonction d'API

SYNTAXE

#include <libtasn1.h>

int asn1_der_decoding2(asn1_node * element, const void * ider, int * max_ider_len, unsigned int flags, char * errorDescription);

ARGUMENTS

asn1_node * element
pointeur vers une structure ASN1.
const void * ider
vecteur contenant l'encodage DER.
int * max_ider_len
pointeur vers un entier donnant l'information sur le nombre maximal d'octets occupés par * ider . La taille réelle de l'encodage DER est retournée via ce pointeur.
unsigned int flags
indicateurs contrôlant le comportement de la fonction.
char * errorDescription
chaîne terminée par null contenant les détails en cas d'erreur.

DESCRIPTION

Remplit la structure * element avec les valeurs d'une chaîne d'encodage DER. La structure doit juste être créée avec la fonction asn1_create_element().

Si l'indicateur ASN1_DECODE_FLAG_ALLOW_PADDING est défini, la fonction ignorera le rembourrage après les données DER décodées. En cas de retour réussi, la valeur de * max_ider_len sera définie au nombre d'octets décodés.

Si l'indicateur ASN1_DECODE_FLAG_STRICT_DER est défini, la fonction ne décodera aucun élément encodé en BER.

RETOUR

ASN1_SUCCESS si l'encodage DER est OK, ASN1_ELEMENT_NOT_FOUND si ELEMENT est NULL, et ASN1_TAG_ERROR ou ASN1_DER_ERROR si l'encodage der ne correspond pas au nom de la structure (* ELEMENT supprimé).
