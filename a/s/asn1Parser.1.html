ASN1PARSER(1) Commandes utilisateur ASN1PARSER(1)

NOM

asn1Parser - Générateur d'arbre syntaxique ASN.1 pour libtasn1

SYNTAXE

asn1Parser [OPTION] FICHIER

DESCRIPTION

Lit FICHIER contenant des définitions ASN.1 et génère un tableau C utilisé avec les fonctions libtasn1.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-c, --check
ne fait que vérifier la syntaxe
-o, --output=FICHIER
fichier de sortie
-n, --name=NOM
nom du tableau
-h, --help
affiche cette aide et quitte
-v, --version
affiche les informations de version et quitte
