assert_perror(3) Manuel des fonctions de bibliothèque assert_perror(3)

NOM

assert_perror - tester errnum et avorter

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <assert.h>
void assert_perror(int errnum);

DESCRIPTION

Si la macro NDEBUG a été définie au moment où <assert.h> a été inclus pour la dernière fois, la macro assert_perror() ne génère aucun code et ne fait donc rien du tout. Sinon, la macro assert_perror() affiche un message d'erreur sur la sortie d'erreur standard et termine le programme en appelant abort(3) si errnum est non nul. Le message contient le nom du fichier, le nom de la fonction et le numéro de ligne de l'appel de macro, ainsi que la sortie de strerror(errnum).

VALEUR DE RETOUR

Aucune valeur n'est retournée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
assert_perror () Thread safety MT-Safe

NORMES

GNU.

BOGUES

Le but des macros assert est d'aider les programmeurs à trouver des bogues dans leurs programmes, des choses qui ne peuvent pas arriver à moins qu'il y ait eu une erreur de codage. Cependant, avec les appels système ou bibliothèque, la situation est assez différente, et les retours d'erreur peuvent se produire, se produiront, et devraient être testés. Pas par un assert, où le test disparaît lorsque NDEBUG est défini, mais par un code de gestion d'erreur approprié. N'utilisez jamais cette macro.

VOIR AUSSI

abort(3), assert(3), exit(3), strerror(3)
