NOM

asn1_find_node - fonction de l'API

SYNTAXE

#include <libtasn1.h>

asn1_node asn1_find_node(asn1_node_const pointeur, const char * nom);

ARGUMENTS

asn1_node_const pointeur
Pointeur d'élément NODE_ASN.
const char * nom
Chaîne terminée par null avec le nom de l'élément à trouver.

DESCRIPTION

Recherche un élément nommé nom en commençant par pointeur. Le nom est composé de différents identifiants séparés par des points. Lorsque * pointeur a un nom, le premier identifiant doit être le nom de * pointeur, sinon il doit être le nom d'un enfant de * pointeur.

RETOURNE

Le résultat de la recherche, ou NULL si non trouvé.
