NOM

asn1_length_der - fonction d'API

SYNTAXE

#include <libtasn1.h>

void asn1_length_der(unsigned long int len, unsigned char * der, int * der_len);

ARGUMENTS

unsigned long int len
valeur à convertir.
unsigned char * der
tampon pour contenir la sortie (peut être NULL).
int * der_len
nombre d'octets significatifs de l'ANS (der[0]..der[der_len-1]).

DESCRIPTION

Crée l'encodage DER de la valeur de longueur fournie. Le tampon der doit avoir suffisamment d'espace pour la sortie. La longueur maximale encodée par cette fonction est ASN1_MAX_LENGTH_SIZE.

Pour connaître la taille de l'encodage DER, utilisez une valeur NULL pour der .
