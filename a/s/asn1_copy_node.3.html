NOM

asn1_copy_node - fonction d'API

SYNTAXE

#include <libtasn1.h>

int asn1_copy_node(asn1_node dst, const char * dst_name, asn1_node_const src, const char * src_name);

ARGUMENTS

asn1_node dst
Nœud asn1 de destination.
const char * dst_name
Nom du champ dans le nœud de destination.
asn1_node_const src
Nœud asn1 source.
const char * src_name
Nom du champ dans le nœud source.

DESCRIPTION

Crée une copie profonde d'une variable asn1_node. Cette fonction nécessite que dst soit développé à l'aide de asn1_create_element().

RETOURNE

Retourne ASN1_SUCCESS en cas de succès.
