ASN1_item_d2i_bio(3ssl)

Paquet: openssl

Licences: Apache-2.0

ASN1_ITEM_D2I_BIO(3ssl) OpenSSL ASN1_ITEM_D2I_BIO(3ssl)

NOM

ASN1_item_d2i_ex, ASN1_item_d2i, ASN1_item_d2i_bio_ex, ASN1_item_d2i_bio, ASN1_item_d2i_fp_ex, ASN1_item_d2i_fp, ASN1_item_i2d_mem_bio, ASN1_item_pack, ASN1_item_unpack_ex, ASN1_item_unpack - décoder et encoder des structures ASN.1 encodées en DER

SYNTAXE

#include <openssl/asn1.h>
ASN1_VALUE *ASN1_item_d2i_ex(ASN1_VALUE **pval, const unsigned char **in,
                             long len, const ASN1_ITEM *it,
                             OSSL_LIB_CTX *libctx, const char *propq);
ASN1_VALUE *ASN1_item_d2i(ASN1_VALUE **pval, const unsigned char **in,
                          long len, const ASN1_ITEM *it);
void *ASN1_item_d2i_bio_ex(const ASN1_ITEM *it, BIO *in, void *x,
                           OSSL_LIB_CTX *libctx, const char *propq);
void *ASN1_item_d2i_bio(const ASN1_ITEM *it, BIO *in, void *x);
void *ASN1_item_d2i_fp_ex(const ASN1_ITEM *it, FILE *in, void *x,
                          OSSL_LIB_CTX *libctx, const char *propq);
void *ASN1_item_d2i_fp(const ASN1_ITEM *it, FILE *in, void *x);
BIO *ASN1_item_i2d_mem_bio(const ASN1_ITEM *it, const ASN1_VALUE *val);
ASN1_STRING *ASN1_item_pack(void *obj, const ASN1_ITEM *it, ASN1_STRING **oct);
void *ASN1_item_unpack(const ASN1_STRING *oct, const ASN1_ITEM *it);
void *ASN1_item_unpack_ex(const ASN1_STRING *oct, const ASN1_ITEM *it,
                         OSSL_LIB_CTX *libctx, const char *propq);

DESCRIPTION

ASN1_item_d2i_ex() décode le contenu des données stockées dans *in d'une longueur len qui doit être une structure ASN.1 encodée en DER, en utilisant le template ASN.1 it. Elle place le résultat dans *pval sauf si pval est NULL. Si *pval n'est pas NULL à l'entrée, la ASN1_VALUE présente sera réutilisée. Sinon, une nouvelle ASN1_VALUE sera allouée. Si des récupérations d'algorithmes sont requises pendant le processus, elles utiliseront le OSSL_LIB_CTX fourni dans le paramètre libctx et la chaîne de requête de propriété propq. Voir "ALGORITHM FETCHING" dans crypto(7) pour plus d'informations sur la récupération d'algorithmes. À la sortie, *in sera mis à jour pour pointer vers le prochain octet dans le tampon après la structure décodée.

ASN1_item_d2i() est identique à ASN1_item_d2i_ex() sauf que le OSSL_LIB_CTX par défaut est utilisé (c'est-à-dire NULL) et avec une chaîne de requête de propriété NULL.

ASN1_item_d2i_bio_ex() décode le contenu de son BIO d'entrée in, qui doit être une structure ASN.1 encodée en DER, en utilisant le template ASN.1 it et place le résultat dans *pval sauf si pval est NULL. Si in est NULL, elle renvoie NULL, sinon un pointeur vers la structure analysée. Si des récupérations d'algorithmes sont requises pendant le processus, elles utiliseront le OSSL_LIB_CTX fourni dans le paramètre libctx et la chaîne de requête de propriété propq. Voir "ALGORITHM FETCHING" dans crypto(7) pour plus d'informations sur la récupération d'algorithmes.

ASN1_item_d2i_bio() est identique à ASN1_item_d2i_bio_ex() sauf que le OSSL_LIB_CTX par défaut est utilisé (c'est-à-dire NULL) et avec une chaîne de requête de propriété NULL.

ASN1_item_d2i_fp_ex() est identique à ASN1_item_d2i_bio_ex() sauf qu'un pointeur FILE est fourni au lieu d'un BIO.

ASN1_item_d2i_fp() est identique à ASN1_item_d2i_fp_ex() sauf que le OSSL_LIB_CTX par défaut est utilisé (c'est-à-dire NULL) et avec une chaîne de requête de propriété NULL.

ASN1_item_i2d_mem_bio() encode la valeur ASN.1 donnée val en utilisant le template ASN.1 it et renvoie le résultat dans un BIO mémoire.

ASN1_item_pack() encode la valeur ASN.1 donnée dans obj en utilisant le template ASN.1 it et renvoie un objet ASN1_STRING. Si *oct passé n'est pas NULL, il est utilisé pour stocker le résultat renvoyé, sinon un nouvel objet ASN1_STRING est créé. Si oct n'est pas NULL et *oct est NULL, le résultat renvoyé est également défini dans *oct. En cas d'erreur, le ASN1_STRING optionnel passé ne sera pas libéré, mais la valeur précédente peut être effacée lorsque ASN1_STRING_set0(*oct, NULL, 0) est appelé en interne.

ASN1_item_unpack() utilise ASN1_item_d2i() pour décoder le ASN1_STRING oct encodé en DER en utilisant le template ASN.1 it.

ASN1_item_unpack_ex() est similaire à ASN1_item_unpack(), mais utilise ASN1_item_d2i_ex() afin que le libctx et le propq puissent être utilisés lors de la récupération d'algorithmes.

VALEURS DE RETOUR

ASN1_item_d2i_bio(), ASN1_item_unpack_ex() et ASN1_item_unpack() renvoient un pointeur vers un ASN1_VALUE ou NULL en cas d'erreur.

ASN1_item_i2d_mem_bio() renvoie un pointeur vers un BIO mémoire ou NULL en cas d'erreur.

ASN1_item_pack() renvoie un pointeur vers un ASN1_STRING ou NULL en cas d'erreur.

HISTORIQUE

Les fonctions ASN1_item_d2i_ex(), ASN1_item_d2i_bio_ex(), ASN1_item_d2i_fp_ex() et ASN1_item_i2d_mem_bio() ont été ajoutées dans OpenSSL 3.0.

La fonction ASN1_item_unpack_ex() a été ajoutée dans OpenSSL 3.2.
