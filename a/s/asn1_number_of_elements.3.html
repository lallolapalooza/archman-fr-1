NOM

asn1_number_of_elements - Fonction API

SYNTAXE

#include <libtasn1.h>

int asn1_number_of_elements(asn1_node_const element, const char * name, int * num);

ARGUMENTS

asn1_node_const element
pointeur vers la racine d'une structure ASN1.
const char * name
le nom d'une sous-structure de ROOT.
int * num
pointeur vers un entier où le résultat sera stocké

DESCRIPTION

Compte le nombre d'éléments d'une sous-structure appelée NAME ayant des noms égaux à « ?1 », « ?2 », etc.

RETOURNE

ASN1_SUCCESS en cas de succès, ASN1_ELEMENT_NOT_FOUND si
name n'est pas connu, ASN1_GENERIC_ERROR si le pointeur num est NULL.
