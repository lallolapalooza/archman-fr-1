NOM

asn1_parser2array - fonction d'API

SYNTAXE

#include <libtasn1.h>

int asn1_parser2array(const char * inputFileName, const char * outputFileName, const char * vectorName, char * error_desc);

ARGUMENTS

const char * inputFileName
spécifier le chemin et le nom du fichier contenant les déclarations ASN.1.
const char * outputFileName
spécifier le chemin et le nom du fichier qui contiendra la définition du vecteur C.
const char * vectorName
spécifier le nom du vecteur C.
char * error_desc
retourne la description de l'erreur ou une chaîne vide en cas de succès.

DESCRIPTION

Fonction qui génère une structure C à partir d'un fichier ASN1. Crée un fichier contenant un vecteur C à utiliser pour gérer les définitions incluses dans le fichier inputFileName. Si inputFileName est "/aa/bb/xx.yy" et outputFileName est NULL, le fichier créé est "/aa/bb/xx_asn1_tab.c". Si vectorName est NULL, le nom du vecteur sera "xx_asn1_tab".

RETOURNE

ASN1_SUCCESS si le fichier a une syntaxe correcte et que tous les identificateurs sont connus, ASN1_FILE_NOT_FOUND si une erreur s'est produite lors de l'ouverture de inputFileName, ASN1_SYNTAX_ERROR si la syntaxe n'est pas correcte, ASN1_IDENTIFIER_NOT_FOUND s'il y a un identificateur dans le fichier qui n'est pas défini, ASN1_NAME_TOO_LONG s'il y a un identificateur dans le fichier avec plus de ASN1_MAX_NAME_SIZE caractères.
