ASCTIME(3P) Manuel du programmeur POSIX ASCTIME(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement de Linux), ou l'interface peut ne pas être implémentée sur Linux.

NOM

asctime, asctime_r — convertir date et heure en chaîne de caractères

SYNOPSIS

#include <time.h>
char *asctime(const struct tm *timeptr);
char *asctime_r(const struct tm *restrict tm, char *restrict buf);

DESCRIPTION

Pour asctime(): La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1-2017 renvoie à la norme ISO C.

La fonction asctime() convertit le temps décomposé dans la structure pointée par timeptr en une chaîne de caractères sous la forme :

Dim Sep 16 01:03:52 1973\n\0

en utilisant l'équivalent de l'algorithme suivant :

char *asctime(const struct tm *timeptr)
{
    static char wday_name[7][3] = {
        "Dim", "Lun", "Mar", "Mer", "Jeu", "Ven", "Sam"
    };
    static char mon_name[12][3] = {
        "Jan", "Fév", "Mar", "Avr", "Mai", "Juin",
        "Juil", "Aoû", "Sep", "Oct", "Nov", "Déc"
    };
    static char result[26];
    sprintf(result, "%.3s %.3s%3d %.2d:%.2d:%.2d %d\n",
        wday_name[timeptr->tm_wday],
        mon_name[timeptr->tm_mon],
        timeptr->tm_mday, timeptr->tm_hour,
        timeptr->tm_min, timeptr->tm_sec,
        1900 + timeptr->tm_year);
    return result;
}

Cependant, le comportement est indéfini si timeptr->tm_wday ou timeptr->tm_mon ne sont pas dans les plages normales telles que définies dans <time.h>, ou si timeptr->tm_year dépasse {INT_MAX}-1990, ou si l'algorithme ci-dessus tentait de générer plus de 26 octets de sortie (y compris le caractère nul de fin).

La structure tm est définie dans l'en-tête <time.h>.

Les fonctions asctime(), ctime(), gmtime() et localtime() renvoient des valeurs dans l'un des deux objets statiques : une structure de temps décomposée et un tableau de type char. L'exécution de l'une des fonctions peut écraser les informations renvoyées dans l'un de ces objets par l'une des autres fonctions.

La fonction asctime() n'est pas nécessairement thread-safe.

La fonction asctime_r() convertit le temps décomposé dans la structure pointée par tm en une chaîne de caractères (de la même forme que celle renvoyée par asctime(), et avec le même comportement indéfini lorsque l'entrée ou la sortie est hors plage) qui est placée dans le tampon fourni par l'utilisateur pointé par buf (qui doit contenir au moins 26 octets) et renvoie ensuite buf.

VALEUR RENVOYÉE

En cas de succès, asctime() renvoie un pointeur vers la chaîne de caractères. Si la fonction échoue, elle renvoie NULL.

En cas de succès, asctime_r() renvoie un pointeur vers une chaîne de caractères contenant la date et l'heure. Cette chaîne est pointée par l'argument buf. Si la fonction échoue, elle renvoie NULL.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

Ces fonctions ne sont incluses que pour la compatibilité avec les anciennes implémentations. Elles ont un comportement indéfini si la chaîne résultante est trop longue, donc leur utilisation doit être découragée. Sur les implémentations qui ne détectent pas le dépassement de la longueur de la chaîne de sortie, il est possible de dépasser les tampons de sortie de telle sorte que les applications échouent, ou des violations de sécurité système possibles. De plus, ces fonctions ne prennent pas en charge les formats de date et d'heure localisés. Pour éviter ces problèmes, les applications doivent utiliser strftime() pour générer des chaînes à partir de temps décomposés.

Les valeurs pour la structure de temps décomposé peuvent être obtenues en appelant gmtime() ou localtime().

La fonction asctime_r() est thread-safe et renvoie les valeurs dans un tampon fourni par l'utilisateur au lieu d'utiliser potentiellement une zone de données statique qui peut être écrasée à chaque appel.

RATIONALE

Les développeurs du standard ont décidé de marquer les fonctions asctime() et asctime_r() comme obsolètes même si asctime() est dans la norme ISO C en raison de la possibilité de dépassement de tampon. La norme ISO C fournit également la fonction strftime() qui peut être utilisée pour éviter ces problèmes.

FUTURES ORIENTATIONS

Ces fonctions peuvent être supprimées dans une future version.

asctime(3) - Manuel Arch Linux

asctime - Convertir une structure tm en chaîne de caractères

SYNTAXE

char *asctime(const struct tm *tm);

char *asctime_r(const struct tm *tm, char *buf);

DESCRIPTION

La fonction asctime() convertit une structure tm, qui contient des informations sur la date et l'heure, en une chaîne de caractères de 26 octets. La chaîne est au format :

Wed Jun 30 21:49:08 1993

La fonction asctime_r() est une version réentrante de asctime(). Elle écrit le résultat dans la chaîne pointée par buf, qui doit avoir une taille d'au moins 26 octets.

VALEUR RENVOYÉE

En cas de succès, asctime() renvoie un pointeur vers la chaîne de caractères. En cas d'échec, elle renvoie NULL. asctime_r() renvoie un pointeur vers buf en cas de succès, et NULL en cas d'erreur.

ERREURS

Aucune erreur spécifique n'est définie pour ces fonctions.

EXEMPLES

#include <stdio.h>
#include <time.h>

int main() {
    time_t t = time(NULL);
    struct tm tm = *localtime(&t);
    char buf[26];

    printf("asctime: %s", asctime(&tm));
    printf("asctime_r: %s", asctime_r(&tm, buf));

    return 0;
}

UTILISATION APPLICATIVE

Ces fonctions sont utiles pour formater la date et l'heure pour l'affichage ou la journalisation.

RATIONALE

Aucune.

ORIENTATIONS FUTURES

Aucune.

VOIR AUSSI
