ASIN(3P) Manuel du programmeur POSIX ASIN(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

asin, asinf, asinl — fonction arc sinus

SYNTAXE

#include <math.h>
double asin(double x);
float asinf(float x);
long double asinl(long double x);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions calculent la valeur principale de l'arc sinus de leur argument x. La valeur de x doit être dans l'intervalle [-1,1].

Une application souhaitant vérifier les situations d'erreur doit initialiser errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno est non nul ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) est non nul, une erreur s'est produite.

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient l'arc sinus de x, dans l'intervalle [-π/2,π/2] radians.

Pour les valeurs finies de x n'appartenant pas à l'intervalle [-1,1], une erreur de domaine se produit, et soit un NaN (si supporté), soit une valeur définie par l'implémentation est retournée.

Si x est NaN, un NaN est retourné.

Si x est ±0, x est retourné.

Si x est ±Inf, une erreur de domaine se produit, et un NaN est retourné.

Si x est sous-normal, une erreur de plage peut se produire
et x devrait être retourné.

Si x n'est pas retourné, asin(), asinf(), et asinl() renvoient une valeur définie par l'implémentation dont la magnitude n'est pas supérieure à DBL_MIN, FLT_MIN, et LDBL_MIN, respectivement.

ERREURS

Ces fonctions échouent si :

Erreur de domaine
L'argument x est fini et n'est pas dans l'intervalle [-1,1], ou est ±Inf.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno est mis à [EDOM]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de virgule flottante invalide est levée.

Ces fonctions peuvent échouer si :

Erreur de plage
La valeur de x est sous-normale.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno est mis à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de virgule flottante de débordement est levée.

USAGE APPLICATION
