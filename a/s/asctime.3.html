ATTENTION

Sécurité des threads

Les quatre fonctions asctime(), ctime(), gmtime() et localtime() renvoient un pointeur vers des données statiques et ne sont donc pas sûres pour les threads. Les versions sûres pour les threads, asctime_r(), ctime_r(), gmtime_r() et localtime_r(), sont spécifiées par SUSv2.

POSIX.1 dit : "Les fonctions asctime(), ctime(), gmtime() et localtime() doivent renvoyer des valeurs dans l'un des deux objets statiques : une structure de temps décomposée et un tableau de type char. L'exécution de l'une des fonctions qui renvoie un pointeur vers l'un de ces types d'objets peut écraser les informations de tout objet du même type pointé par la valeur renvoyée par un appel précédent à l'une d'entre elles." Cela peut se produire dans l'implémentation glibc.

mktime()

(time_t) -1 peut représenter un temps valide (une seconde avant l'Epoch). Pour déterminer si mktime() a échoué, il faut utiliser le champ tm->tm_wday. Voir l'exemple de programme dans EXEMPLES.

La gestion d'un tm_isdst non négatif dans mktime() est mal spécifiée, et passer une valeur incorrecte pour le temps spécifié produit des résultats non spécifiés. Étant donné que mktime() est l'une des rares fonctions qui sait quand l'heure d'été (DST) est en vigueur, fournir une valeur correcte peut être difficile. Une solution consiste à appeler mktime() deux fois, une fois avec tm_isdst défini à zéro, et une fois avec tm_isdst défini à une valeur positive, et à ignorer les résultats de l'appel qui la modifie. Si aucun des appels ne modifie tm_isdst, le temps spécifié se produit probablement pendant une période de retour en arrière où l'heure d'été commence ou se termine, et les deux résultats sont valides mais représentent deux temps différents. Si les deux appels la modifient, cela pourrait indiquer une transition de retour en avant, ou une autre raison pour laquelle le temps spécifié n'existe pas.

La spécification des fuseaux horaires et de l'heure d'été dépend des gouvernements régionaux, change souvent, et peut inclure des discontinuités au-delà de la capacité de mktime à documenter un résultat. Par exemple, un changement dans la définition du fuseau horaire peut entraîner une répétition ou un saut d'une heure sans changement correspondant de l'heure d'été.

Programme source : mktime.c

#include <err.h>
#include <errno.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#define is_signed(T)  ((T) -1 < 1)
static time_t my_mktime(struct tm *tp);
int
main(int argc, char *argv[])
{
    char       **p;
    time_t     t;
    struct tm  tm;
    if (argc != 8) {
        fprintf(stderr, "Usage: %s yyyy mm dd HH MM SS isdst\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    p = &argv[1];
    tm.tm_year  = atoi(*p++) - 1900;
    tm.tm_mon   = atoi(*p++) - 1;
    tm.tm_mday  = atoi(*p++);
    tm.tm_hour  = atoi(*p++);
    tm.tm_min   = atoi(*p++);
    tm.tm_sec   = atoi(*p++);
    tm.tm_isdst = atoi(*p++);
    errno = 0;
    tm.tm_wday = -1;
    t = my_mktime(&tm);
    if (tm.tm_wday == -1)
        err(EXIT_FAILURE, "mktime");
    if (errno == EINVAL || errno == ENOTUNIQ)
        warn("my_mktime");
    if (is_signed(time_t))
        printf("%jd\n", (intmax_t) t);
    else
        printf("%ju\n", (uintmax_t) t);
    exit(EXIT_SUCCESS);
}
static time_t
my_mktime(struct tm *tp)
{
    int            e, isdst;
    time_t         t;
    struct tm      tm;
    unsigned char  wday[sizeof(tp->tm_wday)];
    e = errno;
    tm = *tp;
    isdst = tp->tm_isdst;
    memcpy(wday, &tp->tm_wday, sizeof(wday));
    tp->tm_wday = -1;
    t = mktime(tp);
    if (tp->tm_wday == -1) {
        memcpy(&tp->tm_wday, wday, sizeof(wday));
        return -1;
    }
    if (isdst == -1)
        tm.tm_isdst = tp->tm_isdst;
    if (   tm.tm_sec   != tp->tm_sec
        || tm.tm_min   != tp->tm_min
        || tm.tm_hour  != tp->tm_hour
        || tm.tm_mday  != tp->tm_mday
        || tm.tm_mon   != tp->tm_mon
        || tm.tm_year  != tp->tm_year
        || tm.tm_isdst != tp->tm_isdst)
    {
        errno = EINVAL;
        return t;
    }
    if (isdst != -1)
        goto out;
    tm = *tp;
    tm.tm_isdst = !tm.tm_isdst;
    tm.tm_wday = -1;
    mktime(&tm);
    if (tm.tm_wday == -1)
        goto out;
    if (tm.tm_isdst != tp->tm_isdst) {
        errno = ENOTUNIQ;
        return t;
    }
out:
    errno = e;
    return t;
}

asctime(3)

Bibliothèque C Standard

NOM

asctime - Convertit une structure tm en une chaîne de caractères

SYNTAXE

#include <time.h>

char *asctime(const struct tm *timeptr);
char *asctime_r(const struct tm *timeptr, char *buf);

DESCRIPTION

La fonction asctime() convertit une heure représentée par une structure tm pointée par timeptr en une chaîne de caractères ASCII de 26 octets. Le format de la chaîne est le suivant : « Www Mmm dd hh:mm:ss yyyy\n », où les champs sont définis comme suit :

  • Www : le jour de la semaine (Sun, Mon, ..., Sat)
  • Mmm : le mois (Jan, Feb, ..., Dec)
  • dd : le jour du mois (01-31)
  • hh : l'heure (00-23)
  • mm : les minutes (00-59)
  • ss : les secondes (00-60, 60 étant utilisé pour une seconde intercalaire)
  • yyyy : l'année

La chaîne retournée est stockée dans une zone statique. Il n'est donc pas sûr d'utiliser asctime() dans des programmes multithreadés sans synchronisation appropriée. La fonction asctime_r() est une version réentrante qui écrit le résultat dans la zone mémoire pointée par buf, qui doit être suffisamment grande pour contenir la chaîne de 26 octets plus le caractère nul final.

VALEUR DE RETOUR

En cas de succès, asctime() et asctime_r() retournent un pointeur vers la chaîne de caractères représentant l'heure. En cas d'erreur, elles retournent NULL.

ERREURS

Aucune erreur spécifique n'est définie pour asctime(), mais les valeurs non valides dans la structure tm peuvent entraîner un comportement indéfini.

CONFORMITÉ

POSIX.1-2001, POSIX.1-2008, C89, C99.

HISTORIQUE

La fonction asctime() est apparue dans Version 7 Unix.

MISES EN GARDE

asctime() utilise une zone de stockage statique pour le résultat. Si asctime() est appelée plusieurs fois sans enregistrer le résultat, les appels ultérieurs écraseront le résultat des appels précédents. De plus, si plusieurs threads appellent asctime() simultanément, ils peuvent écraser le résultat de l'autre.

EXEMPLES

L'exemple suivant montre comment utiliser asctime() :

#include <stdio.h>
    #include <time.h>

    int main() {
        time_t t = time(NULL);
        struct tm *tm_info = localtime(&t);
        char *time_str = asctime(tm_info);
        printf("L'heure actuelle est : %s", time_str);
        return 0;
    }
