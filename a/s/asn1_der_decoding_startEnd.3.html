asn1_der_decoding_startEnd(3) libtasn1 asn1_der_decoding_startEnd(3)

NOM

asn1_der_decoding_startEnd - fonction d'API

SYNTAXE

#include <libtasn1.h>

int asn1_der_decoding_startEnd(asn1_node element, const void * ider, int ider_len, const char * name_element, int * start, int * end);

ARGUMENTS

asn1_node element
pointeur vers un élément ASN1
const void * ider
vecteur qui contient l'encodage DER.
int ider_len
nombre d'octets de * ider : ider [0].. ider [len-1]
const char * name_element
un élément de la structure NAME.
int * start
la position du premier octet du décodage de NAME_ELEMENT ( ider [*start])
int * end
la position du dernier octet du décodage de NAME_ELEMENT ( ider [*end])

DESCRIPTION

Trouve le point de début et de fin d'un élément dans une chaîne d'encodage DER. Je veux dire que si vous avez un encodage DER et que vous avez déjà utilisé la fonction asn1_der_decoding() pour remplir une structure, il peut arriver que vous souhaitiez trouver le morceau de chaîne concernant un élément de la structure.

Un exemple est la séquence "tbsCertificate" dans un certificat X509.

Notez que depuis libtasn1 3.7, les paramètres ider et ider_len peuvent être omis, si l'élément est déjà décodé en utilisant asn1_der_decoding().

RETOUR

ASN1_SUCCESS si l'encodage DER est correct, ASN1_ELEMENT_NOT_FOUND si ELEMENT est asn1_node VIDE ou si name_element n'est pas un élément valide, ASN1_TAG_ERROR ou ASN1_DER_ERROR si l'encodage DER ne correspond pas à la structure ELEMENT.
