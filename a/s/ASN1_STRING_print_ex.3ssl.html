ASN1_STRING_print_ex(3ssl)

Paquet: openssl

Licences: Apache-2.0

ASN1_STRING_PRINT_EX(3ssl) OpenSSL ASN1_STRING_PRINT_EX(3ssl)

NOM

ASN1_tag2str, ASN1_STRING_print_ex, ASN1_STRING_print_ex_fp, ASN1_STRING_print - Routines de sortie ASN1_STRING

SYNTAXE

#include <openssl/asn1.h>
int ASN1_STRING_print_ex(BIO *out, const ASN1_STRING *str, unsigned long flags);
int ASN1_STRING_print_ex_fp(FILE *fp, const ASN1_STRING *str, unsigned long flags);
int ASN1_STRING_print(BIO *out, const ASN1_STRING *str);
const char *ASN1_tag2str(int tag);

DESCRIPTION

Ces fonctions affichent une structure ASN1_STRING. ASN1_STRING est utilisée pour représenter tous les types de chaînes ASN1.

ASN1_STRING_print_ex() affiche str dans out, le format est déterminé par les options flags. ASN1_STRING_print_ex_fp() est identique sauf qu'elle affiche dans fp à la place.

ASN1_STRING_print() affiche str dans out mais utilise un format différent de ASN1_STRING_print_ex(). Elle remplace les caractères non imprimables (autres que CR, LF) par '.'.

ASN1_tag2str() retourne un nom lisible par l'homme pour le tag ASN.1 spécifié.

NOTES

ASN1_STRING_print() est une fonction obsolète qui doit être évitée ; utilisez plutôt ASN1_STRING_print_ex().

Bien qu'il existe un grand nombre d'options, ASN1_STRFLGS_RFC2253 est souvent appropriée, ou sur les terminaux UTF8 ASN1_STRFLGS_RFC2253 & ~ASN1_STRFLGS_ESC_MSB.

L'ensemble complet des options supportées pour flags est listé ci-dessous.

Divers caractères peuvent être échappés. Si ASN1_STRFLGS_ESC_2253 est définie, les caractères déterminés par RFC2253 sont échappés. Si ASN1_STRFLGS_ESC_CTRL est définie, les caractères de contrôle sont échappés. Si ASN1_STRFLGS_ESC_MSB est définie, les caractères avec le MSB défini sont échappés : cette option ne doit pas être utilisée si le terminal interprète correctement les séquences UTF8.

L'échappement prend plusieurs formes.

Si le caractère échappé est un caractère de 16 bits, alors la forme "\UXXXX" est utilisée, avec exactement quatre caractères pour la représentation hexadécimale. S'il est de 32 bits, alors "\WXXXXXXXX" est utilisé, avec huit caractères de sa représentation hexadécimale. Ces formes ne seront utilisées que si la conversion UTF8 n'est pas définie (voir ci-dessous).

Les caractères imprimables sont normalement échappés en utilisant le caractère antislash '\'. Si ASN1_STRFLGS_ESC_QUOTE est définie, alors toute la chaîne est entourée de guillemets doubles : c'est sans doute plus lisible que la notation antislash. Les autres caractères utilisent le "\XX", utilisant exactement deux caractères de la représentation hexadécimale.

Si ASN1_STRFLGS_UTF8_CONVERT est définie, alors les caractères sont d'abord convertis au format UTF8. Si le terminal supporte l'affichage des séquences UTF8, alors cette option affichera correctement les caractères multi-octets.

Si ASN1_STRFLGS_IGNORE_TYPE est définie, alors le type de la chaîne n'est pas interprété du tout : tout est supposé être un octet par caractère. Ceci est principalement à des fins de débogage et peut entraîner un affichage confus pour les chaînes multi-caractères.

Si ASN1_STRFLGS_SHOW_TYPE est définie, alors le type de la chaîne lui-même est affiché avant sa valeur (par exemple "BMPSTRING"), ceci utilise en fait ASN1_tag2str().

Le contenu d'une chaîne, au lieu d'être interprété, peut être "dumpé" : ceci affiche simplement la valeur de la chaîne en utilisant la forme #XXXX au format hexadécimal pour chaque octet.

Si ASN1_STRFLGS_DUMP_ALL est définie, alors tout type est dumpé.

Normalement, les types de chaînes non caractères (comme OCTET STRING) sont supposés être un octet par caractère. Si ASN1_STRFLGS_DUMP_UNKNOWN est définie, alors ils seront dumpés à la place.

Lorsqu'un type est dumpé normalement, seuls les octets de contenu sont affichés. Si ASN1_STRFLGS_DUMP_DER est définie, alors l'encodage complet est dumpé à la place (y compris les octets de balise et de longueur).

ASN1_STRFLGS_RFC2253 inclut tous les indicateurs requis par RFC2253. Il est équivalent à :
ASN1_STRFLGS_ESC_2253 | ASN1_STRFLGS_ESC_CTRL | ASN1_STRFLGS_ESC_MSB |
ASN1_STRFLGS_UTF8_CONVERT | ASN1_STRFLGS_DUMP_UNKNOWN ASN1_STRFLGS_DUMP_DER

VALEURS DE RETOUR

ASN1_STRING_print_ex() et ASN1_STRING_print_ex_fp() retournent le nombre de caractères écrits ou -1 si une erreur s'est produite.

ASN1_STRING_print() retourne 1 en cas de succès ou 0 en cas d'erreur.

ASN1_tag2str() retourne un nom lisible par l'homme du tag ASN.1 spécifié.
