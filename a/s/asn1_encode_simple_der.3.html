NOM

asn1_encode_simple_der - fonction d'API

SYNTAXE

#include <libtasn1.h>

int asn1_encode_simple_der(unsigned int etype, const unsigned char * str, unsigned int str_len, unsigned char * tl, unsigned int * tl_len);

ARGUMENTS

unsigned int etype
Le type de la chaîne à encoder (ASN1_ETYPE_)
const unsigned char * str
les données de la chaîne.
unsigned int str_len
la longueur de la chaîne
unsigned char * tl
le tag et la longueur encodés
unsigned int * tl_len
les octets du champ tl

DESCRIPTION

Crée l'encodage DER pour divers types ASN.1 simples tels que les chaînes, etc. Il stocke le tag et la longueur dans tl , qui doit avoir de la place pour au moins ASN1_MAX_TL_SIZE octets. Initialement, tl_len doit contenir la taille de tl .

L'encodage DER complet doit consister en la valeur dans tl ajoutée à la chaîne str fournie.

RETOUR

ASN1_SUCCESS en cas de succès ou une valeur d'erreur.
