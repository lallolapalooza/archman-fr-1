DESCRIPTIO

N

Enregistrer et diffuser simultanément une session de

terminal.

Combine les fonctionnalités des commandes record et stream, vous permettant d'enregistrer une session dans un fichier tout en la diffusant en direct aux

spectateurs.

Appuyez sur <ctrl+d> ou tapez 'exit' pour terminer la session. Appuyez sur <ctrl+\> pour mettre en pause/reprendre la capture de la

session.

Pendant la session, la variable d'envir

onnement ASCIINEMA_SESSION est défi
nie à un identifiant de session unique.

S
-o, --output-file=CHE
MIN
Enregistrer la session dans un fichier au chemin spécifié. Peut être combiné avec la diffusion locale et
distante.

AT
Spécifier le format du fichier de sortie lorsque l'enregistrement est activé avec --output-file. La valeur par défaut est asciicast-v3. Si le chemin du fichier de sortie se termine par .txt, le format txt sera sélectionné automatiquement, sauf si cette option est explicitement spécifiée.

-l, --stream-local=IP:
PORT
Démarrer le serveur HTTP local pour diffuser la session en temps réel. Crée une interface web accessible via un navigateur où les spectateurs peuvent regarder la session de terminal en direct. Spécifiez facultativement l'adresse de liaison sous la forme IP:PORT (par ex., 0.0.0.0:8080 pour autoriser les connexions externes). Si aucune adresse n'est fournie, il écoute sur un port éphémère automatiquement attribué sur 127.0.0.1. Peut être combiné avec la diffusion distante et la sortie
fichier.
-r, --stream-remote=STREAM-ID|WS-
URL
Diffuser la session vers un serveur asciinema distant pour un visionnage public. Cela permet de partager votre session sur le web avec quiconque dispose de l'URL de la diffusion. Vous pouvez fournir soit un identifiant de diffusion d'une configuration de diffusion existante dans le compte de votre serveur asciinema, soit une URL WebSocket directe (ws:// ou wss://) pour des serveurs personnalisés. Omettre la valeur de cette option laisse le serveur asciinema allouer un nouvel identifiant de diffusion automatiquement. Peut être combiné avec la diffusion locale et la sortie
fichier.
-c, --command=COMMAN
DE
Spécifier la commande à exécuter dans la session. Si elle n'est pas fournie, asciinema utilisera votre shell par défaut à partir de la variable d'environnement $SHELL. Il peut s'agir de n'importe quelle commande avec des arguments, par exemple : --command "python script.py" ou --command "bash -l". Peut également être défini via l'option de fichier de configuration session.
command.
-I, --capture-in
put
Activer l'enregistrement de la saisie clavier en plus de la sortie du terminal. Lorsque cette option est activée, à la fois ce que vous tapez et ce qui apparaît à l'écran seront capturés. Notez que les saisies sensibles comme les mots de passe seront également enregistrées lorsque cette option est activée. Si le serveur a l'enregistrement de diffusion activé, la saisie clavier sera incluse dans le fichier d'enregistrement créé côté serveur. Peut également être défini via l'option de fichier de configuration session.
capture_input.
--capture-env=VA
RS
Spécifier quelles variables d'environnement capturer et inclure dans les métadonnées de la session. Fournissez une liste de noms de variables séparés par des virgules, par exemple : --rec-env "USER,SHELL,TERM". Si non spécifié, seule la variable SHELL est capturée par défaut. Si le serveur a l'enregistrement de diffusion activé, ces variables d'environnement seront incluses dans le fichier d'enregistrement créé côté serveur. Peut également être défini via l'option de fichier de configuration session.
capture_env.
-a, --appe
nd
Ajouter la nouvelle session à un fichier d'enregistrement existant au lieu d'en créer un nouveau. Cela vous permet de poursuivre une session d'enregistrement précédente. Le minutage sera ajusté pour maintenir la continuité à partir du point où l'enregistrement précédent s'est terminé. Ne peut pas être utilisé avec --overwrite. Ne s'applique que lorsque --output-file est
spécifié.
--overwri
te
Écraser le fichier de sortie s'il existe déjà. Par défaut, asciinema refusera d'écraser les fichiers existants pour éviter une perte de données accidentelle. Ne peut pas être utilisé avec --append. Ne s'applique que lorsque --output-file est
spécifié.
-t, --title=TIT
RE
Définir un titre descriptif pour la session qui sera stocké dans les métadonnées de l'enregistrement et affiché aux spectateurs de la diffusion (lors d'une diffusion distante avec --remote). Par exemple : --title "Installing Podman on Ubuntu". Si le serveur a l'enregistrement de diffusion activé, le titre sera inclus dans le fichier d'enregistrement créé côté
serveur.
-i, --idle-time-limit=SE
CS
Limiter le temps d'inactivité maximal enregistré entre les événements du terminal au nombre de secondes spécifié. Les longues pauses (comme lorsque vous vous éloignez du terminal) seront plafonnées à cette durée dans l'enregistrement, ce qui rend la lecture plus agréable. Par exemple, --idle-time-limit 2.0 garantira qu'aucune pause de plus de 2 secondes n'apparaîtra dans l'enregistrement. Ne s'applique que lorsque --output-file est spécifié. Notez que cette option ne modifie pas les informations de minutage originales (capturées) et qu'elle intègre plutôt la valeur de limite de temps d'inactivité dans les métadonnées, qui est interprétée par les lecteurs de session au moment de la lecture. Cela permet d'ajuster la limite après l'enregistrement. Peut également être défini via l'option de fichier de configuration session.
idle_time_limit.
--headle
ss
Exécuter la session en mode sans tête sans utiliser le terminal pour l'entrée/sortie. C'est utile pour les sessions automatisées ou scriptées où vous ne voulez pas qu'asciinema interfère avec la session de terminal actuelle. La commande de session s'exécutera toujours normalement et sera enregistrée/diffusée, mais ne sera pas affichée dans votre terminal local. Le mode sans tête est activé automatiquement lors de l'exécution dans un environnement où un terminal n'est pas
disponible.
--window-size=COLSxRO
WS
Remplacer la taille de la fenêtre du terminal utilisée pour la session. Spécifiez les dimensions sous la forme COLSxROWS (par ex., 80x24 pour 80 colonnes sur 24 lignes). Vous pouvez spécifier uniquement les colonnes (80x) ou uniquement les lignes (x24) pour ne remplacer qu'une seule dimension. C'est utile pour garantir des dimensions d'enregistrement cohérentes quelle que soit la taille actuelle de votre
terminal.
--retu
rn
Faire en sorte que la commande asciinema se termine avec le même code de retour que la commande de session. Par défaut, asciinema se termine avec le statut 0 quelle que soit l'issue de la session. Avec cette option, si la commande de session se termine avec un statut non nul, asciinema se terminera également avec ce même
statut.
--log-file=CHE
MIN
Activer la journalisation des événements internes dans un fichier au chemin spécifié. Utile pour déboguer les problèmes d'E/S (erreurs de connexion, déconnexions, erreurs d'écriture de fichier,
etc.).
--server-url=UR
L
Spécifier une URL de serveur asciinema personnalisée pour la diffusion vers des serveurs auto-hébergés. Utilisez l'URL de base du serveur (par ex., le.com'>https://asciinema.example.com). Peut aussi être défini via la variable d'environnement ASCIINEMA_SERVER_URL ou l'option de fichier de configuration server.url. Si aucune URL de serveur n'est configurée via cette option, la variable d'environnement ou le fichier de configuration, il vous sera demandé d'en choisir une (par défaut asciinema.org), qui sera enregistrée comme valeur par
défaut.
