NOM

asn1_expand_any_defined_by - Fonction d'API

SYNOPSIS

#include <libtasn1.h>

int asn1_expand_any_defined_by(asn1_node_const definitions, asn1_node * element);

ARGUMENTS

asn1_node_const definitions
Définitions ASN1
asn1_node * element
pointeur vers une structure ASN1

DESCRIPTION

Développe chaque élément "ANY DEFINED BY" d'une structure créée à partir d'un processus de décodage DER (fonction asn1_der_decoding). L'élément ANY doit être défini par un OBJECT IDENTIFIER. Le type utilisé pour développer l'élément ANY est le premier qui suit la définition de la valeur actuelle de l'OBJECT IDENTIFIER.

RETOURNE

ASN1_SUCCESS si la substitution est OK, ASN1_ERROR_TYPE_ANY si un élément "ANY DEFINED BY" n'a pas pu être développé en raison d'un problème dans l'association OBJECT_ID -> TYPE, ou d'autres codes d'erreur selon le décodage DER.
