NOM

asn1_delete_structure2 - fonction API

SYNTAXE

#include <libtasn1.h>

int asn1_delete_structure2(asn1_node * structure, unsigned int flags);

ARGUMENTS

asn1_node * structure
pointeur vers la structure que vous souhaitez supprimer.
unsigned int flags
indicateurs supplémentaires (voir ASN1_DELETE_FLAG_ZEROIZE)

DESCRIPTION

Supprime la structure * structure. À la fin, * structure est défini sur NULL.

RETOURNE

ASN1_SUCCESS en cas de succès, ASN1_ELEMENT_NOT_FOUND si * structure était NULL.
