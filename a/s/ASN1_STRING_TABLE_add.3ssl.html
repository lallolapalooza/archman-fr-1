ASN1_STRING_TABLE_add(3ssl)

Paquet: openssl

Licences: Apache-2.0

ASN1_STRING_TABLE_ADD(3ssl) OpenSSL ASN1_STRING_TABLE_ADD(3ssl)

NOM

ASN1_STRING_TABLE, ASN1_STRING_TABLE_add, ASN1_STRING_TABLE_get, ASN1_STRING_TABLE_cleanup - Fonctions de manipulation d'ASN1_STRING_TABLE

SYNOPSIS

#include <openssl/asn1.h>
typedef struct asn1_string_table_st ASN1_STRING_TABLE;
int ASN1_STRING_TABLE_add(int nid, long minsize, long maxsize,
                          unsigned long mask, unsigned long flags);
ASN1_STRING_TABLE *ASN1_STRING_TABLE_get(int nid);
void ASN1_STRING_TABLE_cleanup(void);

DESCRIPTION

Types

ASN1_STRING_TABLE est une table qui contient des informations de chaîne (essentiellement taille minimale, taille maximale, type, etc.) pour un objet NID.

Fonctions

ASN1_STRING_TABLE_add() ajoute un nouvel élément ASN1_STRING_TABLE à la table de chaînes ASN1 locale basé sur le nid ainsi que d'autres paramètres.

Si l'élément est déjà dans la table, les champs de ASN1_STRING_TABLE sont mis à jour (en fonction des valeurs de ces paramètres, par exemple, minsize et maxsize >= 0, mask et flags != 0). Si le nid est standard, une copie de ASN1_STRING_TABLE standard est créée et mise à jour avec les autres paramètres.

ASN1_STRING_TABLE_get() recherche un élément ASN1_STRING_TABLE basé sur le nid. Il recherchera d'abord dans la table locale, puis dans la table standard.

ASN1_STRING_TABLE_cleanup() libère tous les éléments ASN1_STRING_TABLE ajoutés par ASN1_STRING_TABLE_add().

VALEURS DE RETOUR

ASN1_STRING_TABLE_add() retourne 1 en cas de succès, 0 en cas d'erreur.

ASN1_STRING_TABLE_get() retourne une structure ASN1_STRING_TABLE valide ou NULL si rien n'est trouvé.

ASN1_STRING_TABLE_cleanup() ne retourne pas de valeur.
