NOM

asn1_print_structure - fonction API

SYNTAXE

#include <libtasn1.h>

void asn1_print_structure(FILE * out, asn1_node_const structure, const char * name, int mode);

ARGUMENTS

FILE * out
pointeur vers le fichier de sortie (par ex. stdout).
asn1_node_const structure
pointeur vers la structure que vous souhaitez parcourir.
const char * name
un élément de la structure
int mode
spécifie la quantité de la structure à imprimer, peut être ASN1_PRINT_NAME, ASN1_PRINT_NAME_TYPE, ASN1_PRINT_NAME_TYPE_VALUE, ou ASN1_PRINT_ALL.

DESCRIPTION

Imprime sur le descripteur de fichier out l'arbre de la structure en commençant par l'élément name dans la structure structure.
