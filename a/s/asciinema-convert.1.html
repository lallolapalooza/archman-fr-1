asciinema-convert(1) Manuel des commandes générales asciinema-convert(1)

NOM

asciinema-convert - Convertir un enregistrement dans un autre format

SYNTAXE

asciinema convert [-f|--output-format] [--overwrite] [-q|--quiet] [-h|--help] <ENTRÉE> <SORTIE>

DESCRIPTION

Convertit un enregistrement dans un autre format.

Transforme les fichiers asciicast entre différents formats (v1, v2, v3) ou les exporte vers d'autres formats comme la sortie de terminal brute ou le texte brut. Permet la lecture à partir de fichiers, d'URL ou de stdin et l'écriture vers des fichiers ou stdout.

OPTIONS

-f, --output-format=FORMAT
Spécifie le format de l'enregistrement converti. Par défaut, il s'agit d'asciicast-v3. Si le chemin du fichier de sortie se termine par .txt, le format txt sera sélectionné automatiquement sauf si cette option est explicitement spécifiée.

Valeurs possibles :

  • asciicast-v3 : Format de session complet, avec horodatage et métadonnées (génération actuelle) - https://docs.asciinema.org/manual/asciicast/v3/
  • asciicast-v2 : Format de session complet, avec horodatage et métadonnées (génération précédente) - https://docs.asciinema.org/manual/asciicast/v2/
  • raw : Sortie de terminal brute, y compris les séquences de contrôle, sans horodatage ni métadonnées
  • txt : Texte brut sans couleurs ni séquences de contrôle, lisible par l'homme
--overwrite
Écrase le fichier de sortie s'il existe déjà. Par défaut, asciinema refuse d'écraser les fichiers existants pour éviter toute perte de données accidentelle. N'a aucun effet lors de l'écriture vers stdout ('-').
-q, --quiet
Supprime les messages de diagnostic et les indicateurs de progression. Seuls les messages d'erreur seront affichés.
-h, --help
Imprime l'aide (voir un résumé avec '-h')
<ENTRÉE>
L'enregistrement source à convertir. Peut être un chemin de fichier local, une URL HTTP(S) pour les fichiers distants, ou '-' pour lire depuis l'entrée standard. Les URL distantes permettent de convertir des enregistrements directement depuis le web sans avoir besoin de les télécharger manuellement. Les formats d'entrée pris en charge incluent asciicast v1, v2 et v3.
<SORTIE>
Le chemin de sortie pour l'enregistrement converti. Peut être un chemin de fichier ou '-' pour écrire vers la sortie standard.

EXTRA

Exemples :


asciinema convert vieux.cast nouveau.cast
Convertit un enregistrement au dernier format asciicast (v3)


asciinema convert demo.cast demo.txt
Exporte un enregistrement sous forme de journal texte brut - le format de sortie est déduit de l'extension .txt


asciinema convert --output-format raw demo.cast demo.txt
Exporte en sortie de terminal brute


asciinema convert -f txt demo.cast -
Exporte en texte brut vers stdout


asciinema convert https://asciinema.org/a/569727 starwars.cast
Télécharge un enregistrement distant et le convertit au dernier format asciicast (v3)
