DESCRIPTIO

N

Diffuser une session de terminal en temps

réel.

Diffuse une session de terminal en direct via le serveur HTTP local (pour une visualisation locale/réseau local) ou un serveur asciinema distant (pour un partage public). Les spectateurs peuvent regarder la session en direct via une interface

web.

Appuyez sur <ctrl+d> ou tapez 'exit' pour terminer la session de diffusion. Appuyez sur <ctrl+\> pour mettre en pause/reprendre la capture de la

session.

Pendant la session, la variable d'envir

onnement ASCIINEMA_SESSION est défi
nie à un identifiant de session unique.

OPTION

S
-l, --local=IP:
PORT
Démarre le serveur HTTP local pour diffuser la session en temps réel. Crée une interface web accessible via un navigateur où les spectateurs peuvent regarder la session de terminal en direct. Spécifiez éventuellement l'adresse de liaison sous la forme IP:PORT (par ex., 0.0.0.0:8080 pour autoriser les connexions externes). Si aucune adresse n'est fournie, il écoute sur un port éphémère attribué automatiquement sur 127.0.
0.1.
-r, --remote=STREAM-ID|WS-
URL
Diffuse la session vers un serveur asciinema distant pour une visualisation publique. Cela permet de partager votre session sur le web avec quiconque possède l'URL du flux. Vous pouvez fournir soit un identifiant de flux (stream ID) d'une configuration de flux existante dans le compte de votre serveur asciinema, soit une URL WebSocket directe (ws:// ou wss://) pour des serveurs personnalisés. Omettre la valeur de cette option laisse le serveur asciinema allouer automatiquement un nouvel identifiant de
flux.
-c, --command=COMMA
ND
Spécifie la commande à exécuter dans la session de diffusion. Si elle n'est pas fournie, asciinema utilisera votre shell par défaut à partir de la variable d'environnement $SHELL. Il peut s'agir de n'importe quelle commande avec des arguments, par exemple : --command "python script.py" ou --command "bash -l". Peut aussi être défini via l'option de fichier de configuration session.
command.
-I, --capture-in
put
Active l'enregistrement de la saisie clavier en plus de la sortie du terminal. Lorsque cette option est activée, à la fois ce que vous tapez et ce qui apparaît à l'écran seront capturés. Notez que les entrées sensibles comme les mots de passe seront également enregistrées lorsque cette option est activée. Si le serveur a l'enregistrement de flux activé, la saisie clavier sera incluse dans le fichier d'enregistrement créé côté serveur. Peut aussi être défini via l'option de fichier de configuration session.
capture_input.
--capture-env=VA
RS
Spécifie quelles variables d'environnement capturer et inclure dans les métadonnées du flux. Fournissez une liste de noms de variables séparés par des virgules, par exemple : --rec-env "USER,SHELL,TERM". Si non spécifié, seule la variable SHELL est capturée par défaut. Si le serveur a l'enregistrement de flux activé, ces variables d'environnement seront incluses dans le fichier d'enregistrement créé côté serveur. Peut aussi être défini via l'option de fichier de configuration session.
capture_env.
-t, --title=TIT
LE
Définit un titre descriptif pour la session de diffusion. Ce titre est affiché aux spectateurs (lors d'une diffusion distante avec --remote). Par exemple : --title "Building a REST API". Si le serveur a l'enregistrement de flux activé, le titre sera inclus dans le fichier d'enregistrement créé côté
serveur.
--headle
ss
Diffuse en mode sans interface (headless) sans utiliser le terminal pour l'entrée/sortie. C'est utile pour une diffusion automatisée ou scriptée où vous ne voulez pas qu'asciinema interfère avec la session de terminal actuelle. La commande diffusée sera toujours exécutée normalement et sera visible pour les spectateurs, mais ne sera pas affichée dans votre terminal local. Le mode headless est activé automatiquement lors de l'exécution dans un environnement où un terminal n'est pas
disponible.
--window-size=COLSxRO
WS
Remplace la taille de la fenêtre du terminal utilisée pour la session de diffusion. Spécifiez les dimensions sous la forme COLSxROWS (par ex., 80x24 pour 80 colonnes par 24 lignes). Vous pouvez spécifier uniquement les colonnes (80x) ou uniquement les lignes (x24) pour ne remplacer qu'une seule dimension. C'est utile pour garantir des dimensions de diffusion constantes quelle que soit la taille actuelle de votre
terminal.
--retu
rn
Fait en sorte que la commande asciinema se termine avec le même code de statut que la session diffusée. Par défaut, asciinema se termine avec le statut 0, quelle que soit la situation dans la session diffusée. Avec cette option, si la commande diffusée se termine avec un statut non nul, asciinema se terminera également avec ce même
statut.
--log-file=PA
TH
Active la journalisation des événements internes dans un fichier au chemin spécifié. Utile pour déboguer les problèmes de diffusion (erreurs de connexion, déconnexions, etc.
).
--server-url=UR
L
Spécifie une URL de serveur asciinema personnalisée pour la diffusion vers des serveurs auto-hébergés. Utilisez l'URL de base du serveur (par ex., https://asciinema.example.com). Peut aussi être défini via la variable d'environnement ASCIINEMA_SERVER_URL ou l'option de fichier de configuration server.url. Si aucune URL de serveur n'est configurée via cette option, la variable d'environnement ou le fichier de configuration, il vous sera demandé d'en choisir une (par défaut asciinema.org), qui sera enregistrée comme valeur par
défaut.
-q, --qui
et
Supprime les messages de diagnostic et les indicateurs de progression. Seuls les messages d'erreur seront
affichés.
-h, --he
lp
Affiche l'
aide (voir
un résumé
avec '-h')
