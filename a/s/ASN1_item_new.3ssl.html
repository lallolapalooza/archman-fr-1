ASN1_item_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

ASN1_ITEM_NEW(3ssl) OpenSSL ASN1_ITEM_NEW(3ssl)

NOM

ASN1_item_new_ex, ASN1_item_new - créer de nouvelles valeurs ASN.1

SYNOPSIS

#include <openssl/asn1.h>
ASN1_VALUE *ASN1_item_new_ex(const ASN1_ITEM *it, OSSL_LIB_CTX *libctx,
                             const char *propq);
ASN1_VALUE *ASN1_item_new(const ASN1_ITEM *it);

DESCRIPTION

ASN1_item_new_ex() crée une nouvelle structure ASN1_VALUE basée sur le modèle ASN1_ITEM fourni dans le paramètre it. Si des recherches d'algorithmes sont requises pendant le processus, elles utiliseront le OSSL_LIB_CTX fourni dans le paramètre libctx et la chaîne de requête de propriétés dans propq. Voir "RECHERCHE D'ALGORITHMES" dans crypto(7) pour plus d'informations sur la recherche d'algorithmes.

ASN1_item_new() est identique à ASN1_item_new_ex(), à l'exception qu'elle utilise le OSSL_LIB_CTX par défaut (c'est-à-dire NULL) et avec une chaîne de requête de propriétés NULL.

VALEUR DE RETOUR

ASN1_item_new_ex() et ASN1_item_new() retournent un pointeur vers la nouvelle ASN1_VALUE créée ou NULL en cas d'erreur.

HISTORIQUE

La fonction ASN1_item_new_ex() a été ajoutée dans OpenSSL 3.0.
