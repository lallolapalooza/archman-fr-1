NOM

asn1_read_node_value - fonction d'API

SYNTAXE

#include <libtasn1.h>

int asn1_read_node_value(asn1_node_const node, asn1_data_node_st * data);

ARGUMENTS

asn1_node_const node
pointeur vers un nœud.
asn1_data_node_st * data
un pointeur vers une structure asn1_data_node_st

DESCRIPTION

Retourne la valeur d'un nœud de données à l'intérieur d'une structure asn1_node. Les données retournées doivent être traitées comme des valeurs constantes.

RETOUR

ASN1_SUCCESS si le nœud existe.
