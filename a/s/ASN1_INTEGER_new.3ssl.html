ASN1_INTEGER_NEW(3ssl) OpenSSL ASN1_INTEGER_NEW(3ssl)

NOM

ASN1_INTEGER_new, ASN1_INTEGER_free - Fonctions d'allocation ASN1_INTEGER

SYNTAXE

#include <openssl/asn1.h>
ASN1_INTEGER *ASN1_INTEGER_new(void);
void ASN1_INTEGER_free(ASN1_INTEGER *a);

DESCRIPTION

ASN1_INTEGER_new() retourne une structure ASN1_INTEGER allouée.

ASN1_INTEGER_free() libère un objet ASN1_INTEGER individuel. Si l'argument est NULL, rien n'est fait.

Structure ASN1_INTEGER représentant le type ASN.1 INTEGER

VALEURS DE RETOUR

ASN1_INTEGER_new() retourne une structure ASN1_INTEGER valide ou NULL si une erreur s'est produite.

ASN1_INTEGER_free() ne retourne pas de valeur.
