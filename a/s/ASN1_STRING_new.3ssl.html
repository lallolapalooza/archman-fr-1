ASN1_STRING_NEW(3ssl) OpenSSL ASN1_STRING_NEW(3ssl)

NOM

ASN1_STRING_new, ASN1_STRING_type_new, ASN1_STRING_free - fonctions d'allocation pour ASN1_STRING

SYNTAXE

#include <openssl/asn1.h>
ASN1_STRING *ASN1_STRING_new(void);
ASN1_STRING *ASN1_STRING_type_new(int type);
void ASN1_STRING_free(ASN1_STRING *a);

DESCRIPTION

ASN1_STRING_new() renvoie une structure ASN1_STRING allouée. Son type est indéfini.

ASN1_STRING_type_new() renvoie une structure ASN1_STRING allouée de type type.

ASN1_STRING_free() libère a. Si a est NULL, rien n'est fait.

NOTES

D'autres types de chaînes appellent les fonctions ASN1_STRING. Par exemple, ASN1_OCTET_STRING_new() appelle ASN1_STRING_type_new(V_ASN1_OCTET_STRING).

VALEURS DE RETOUR

ASN1_STRING_new() et ASN1_STRING_type_new() renvoient une structure ASN1_STRING valide ou NULL en cas d'erreur.

ASN1_STRING_free() ne renvoie pas de valeur.
