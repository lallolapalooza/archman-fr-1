ASN1DECODING(1) Commandes utilisateur ASN1DECODING(1)

NOM

asn1Decoding - Décodeur ASN.1 DER

SYNTAXE

asn1Decoding [OPTION] DEFINITIONS FICHIER_ENCODÉ TYPE_ASN1

DESCRIPTION

Décode les données DER dans le fichier FICHIER_ENCODÉ, pour l'élément TYPE_ASN1 décrit dans le fichier DEFINITIONS, et affiche les structures décodées.

-b, --benchmark
effectue un test de performance sur le décodage
-s, --strict
utilise un décodage DER strict
-t, --no-time-strict
utilise un décodage DER strict, mais pas pour les champs temporels
-h, --help
affiche cette aide et quitte
-v, --version
affiche les informations de version et quitte
