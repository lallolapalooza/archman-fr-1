NOM

aseqnet - connecteurs de séquenceur ALSA sur le réseau

SYNTAXE

aseqnet [hôte_distant]

DESCRIPTION

aseqnet est un client de séquenceur ALSA qui envoie et reçoit des paquets d'événements sur le réseau. Supposons deux hôtes connectés par réseau, hôteA comme serveur et hôteB comme client. Le système de séquenceur ALSA doit être en cours d'exécution sur les deux hôtes. Pour créer le port serveur, exécutez ce qui suit sur hôteA :

hôteA% aseqnet
séquenceur ouvert : 128:0

Ensuite, un client utilisateur 128 avec le port 0 a été ouvert sur hôteA. (Le numéro de client peut varier.) Pour créer le port (réseau-)client, exécutez aseqnet avec le nom d'hôte du serveur :

hôteB% aseqnet hôteA
séquenceur ouvert : 132:0

Maintenant, tous les événements envoyés à hôteA:128:0 sont transférés à hôteB:132:0, et vice versa.

Les ports créés par aseqnet peuvent être connectés de manière arbitraire à d'autres ports de séquenceur via aconnect(1). Par exemple, pour connecter hôteB:132:0 à un périphérique de sortie MIDI 65:0 :

hôteB% aconnect 132:0 65:0

Alors, les événements vers hôteA:128:0 seront livrés à hôteB:65:0. La commande suivante lit un fichier MIDI sur hôteB.

hôteA% pmidi -p 128:0 foo.mid

Plusieurs clients peuvent exister simultanément. Si hôteC est connecté comme client à hôteA, les événements de hôteA sont envoyés à tous les clients réseau connectés, c'est-à-dire hôteB et hôteC. Cependant, une seule connexion est autorisée d'un client à un serveur.

Pour déconnecter le réseau, arrêtez tous les clients avant le serveur avec ctrl-C ou en leur envoyant un signal. Le serveur se quittera automatiquement.

OPTIONS

-p port
Spécifiez le numéro de port TCP ou le nom de service TCP.
-s addr
S'abonner à l'adresse donnée pour la lecture automatique.
-d addr
S'abonner à l'adresse donnée pour l'écriture automatique.
-n nom
Spécifiez le nom midi du processus.
-v
Mode verbeux.

VOIR AUSSI

aconnect(1), pmidi(1)
