NOM

airtun-ng - un créateur d'interface de tunnel virtuelle pour aircrack-ng

SYNTAXE

airtun-ng [options] <nom d'interface>

DESCRIPTION

airtun-ng crée une interface de tunnel virtuelle (atX) pour envoyer des paquets IP arbitraires en utilisant l'injection de paquets ieee802.11 bruts.

OPTIONS

-H, --help
Affiche l'écran d'aide.
-x <pps>
Définit le nombre maximum de paquets par seconde.
-a <BSSID>
Spécifie le BSSID pour l'en-tête ieee802.11. En mode WDS, cela définit le récepteur.
-h <SMAC>
Spécifie l'adresse MAC source pour l'en-tête ieee802.11.
-i <iface>
Définit l'interface de capture.
-r <fichier>
Spécifie un fichier pour lire les trames 802.11.
-y <fichier-PRGA>
Est le nom du fichier qui fournit le flux de clés pour le chiffrement WEP. (Pas de réception, juste la transmission de paquets IP.)
-w <clé-WEP>
Ceci est la clé WEP pour chiffrer/déchiffrer tout trafic passant par le tunnel.
-e <ESSID>
Définit le SSID du réseau cible (à utiliser avec -p).
-p <phrase-de-passe>
Utilise cette phrase de passe WPA pour déchiffrer les paquets (à utiliser avec -a et -e).
-t <tods>
Définit le bit ToDS et FromDS dans l'en-tête ieee802.11. Pour tods=1, le bit ToDS est défini à 1 et FromDS à 0, tandis que tods=0 les définit dans l'autre sens. S'il est défini à 2, il sera tunnelisé dans un WDS/bridge.
-m <masque-réseau>, --netmask <masque-réseau>
Filtre les réseaux en fonction de la combinaison bssid ^ masque réseau. Nécessite -d, utilisé en mode rejeu.
-d <BSSID>, --bssid <BSSID>
Filtre les réseaux en fonction du <BSSID>. Utilisé en mode rejeu.
-f, --repeat
Active le mode rejeu. Toutes les trames lues, filtrées par bssid et masque réseau (si spécifiés), seront rejouées.
-s <transmetteur>
Définit l'adresse MAC du transmetteur pour le mode WDS.
-b
Mode bidirectionnel. Cela permet la communication dans les réseaux du transmetteur ET du récepteur. Ne fonctionne que si vous pouvez voir les deux stations.

EXEMPLES

airtun-ng -a 00:14:22:56:F3:4E -t 0 -y keystream.xor wlan0
