DESCRIPTIO

N

La fonction aio_fsync() effectue de manière asynchrone une opération de synchronisation de fichier, comme spécifié par l'argument op, pour les opérations d'E/S associées au fichier indiqué par le descripteur de fichier aio_fildes de la structure aiocb référencée par l'argument aiocbp et mise en file d'attente au moment de l'appel à aio_fsync(). L'appel de fonction retourne lorsque la requête de synchronisation a été initiée ou mise en file d'attente vers le fichier ou le périphérique (même lorsque les données ne peuvent pas être synchronisées immédiatement)

.

Si op vaut O_DSYNC, toutes les opérations d'E/S actuellement en file d'attente seront complétées comme si par un appel à fdatasync() ; c'est-à-dire, comme défini pour l'achèvement de l'intégrité des données d'E/S

synchronisées.

Si op vaut O_SYNC, toutes les opérations d'E/S actuellement en file d'attente seront complétées comme si par un appel à fsync() ; c'est-à-dire, comme défini pour l'achèvement de l'intégrité du fichier d'E/S synchronisées. Si la fonction aio_fsync() échoue, ou si l'opération mise en file d'attente par aio_fsync() échoue, alors il n'est pas garanti que les opérations d'E/S en attente aient été

complétées.

Si aio_fsync() réussit, alors c'est seulement l'E/S qui a été mise en file d'attente au moment de l'appel à aio_fsync() qui est garantie d'être forcée vers l'état d'achèvement pertinent. L'achèvement de l'E/S ultérieure sur le descripteur de fichier n'est pas garanti d'être complété de manière

synchronisée.

L'argument aiocbp fait référence à un bloc de contrôle d'E/S asynchrone. La valeur aiocbp peut être utilisée comme argument à aio_error() et aio_return() afin de déterminer respectivement le statut d'erreur et le statut de retour de l'opération asynchrone pendant qu'elle se déroule. Lorsque la requête est mise en file d'attente, le statut d'erreur pour l'opération est [EINPROGRESS]. Lorsque toutes les données ont été transférées avec succès, le statut d'erreur sera réinitialisé pour refléter le succès ou l'échec de l'opération. Si l'opération ne se termine pas avec succès, le statut d'erreur pour l'opération sera défini pour indiquer l'erreur. Le aio_sigevent membre détermine la notification asynchrone à survenir comme spécifié dans Section 2.4.1, Génération et livraison de signaux lorsque toutes les opérations ont atteint l'achèvement d'E/S synchronisées. Tous les autres membres de la structure référencée par aiocbp sont ignorés. Si le bloc de contrôle référencé par aiocbp devient une adresse illégale avant l'achèvement de l'E/S asynchrone, alors le comportement est

indéfini.

Si la fonction aio_fsync() échoue ou aiocbp indique une condition d'erreur, il n'est pas g

été transférées avec succès.
