aio_init(3) Manuel des fonctions de bibliothèque aio_init(3)

NOM

aio_init - initialisation des E/S asynchrones

BIBLIOTHÈQUE

Bibliothèque temps réel (librt, -lrt)

SYNTAXE

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <aio.h>
void aio_init(const struct aioinit *init);

DESCRIPTION

La fonction aio_init() spécifique à GNU permet à l'appelant de fournir des indications de réglage à l'implémentation AIO POSIX de glibc. L'utilisation de cette fonction est facultative, mais pour être efficace, elle doit être appelée avant d'employer toute autre fonction de l'API AIO POSIX.

Les informations de réglage sont fournies dans le tampon pointé par l'argument init. Ce tampon est une structure de la forme suivante :


struct aioinit {
    int aio_threads;    /* Nombre maximal de threads */
    int aio_num;        /* Nombre de requêtes simultanées
                           attendues */
    int aio_locks;      /* Non utilisé */
    int aio_usedba;     /* Non utilisé */
    int aio_debug;      /* Non utilisé */
    int aio_numusers;   /* Non utilisé */
    int aio_idle_time;  /* Nombre de secondes avant qu'un thread
                           inactif ne se termine (depuis glibc 2.2) */
    int aio_reserved;
};

Les champs suivants sont utilisés dans la structure aioinit :

aio_threads
Ce champ spécifie le nombre maximal de threads de travail qui peuvent être utilisés par l'implémentation. Si le nombre d'opérations d'E/S en attente dépasse cette limite, les opérations excédentaires seront mises en file d'attente jusqu'à ce qu'un thread de travail devienne libre. Si ce champ est spécifié avec une valeur inférieure à 1, la valeur 1 est utilisée. La valeur par défaut est 20.
aio_num
Ce champ doit spécifier le nombre maximal de requêtes d'E/S simultanées que l'appelant s'attend à mettre en file d'attente. Si une valeur inférieure à 32 est spécifiée pour ce champ, elle est arrondie à 32. La valeur par défaut est 64.
aio_idle_time
Ce champ spécifie la durée en secondes pendant laquelle un thread de travail doit attendre de nouvelles requêtes avant de se terminer, après avoir terminé une requête précédente. La valeur par défaut est 1.

NORMES

GNU.

HISTORIQUE

glibc 2.1.
