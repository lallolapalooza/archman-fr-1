AIRDECLOAK-NG(1) Manuel des commandes générales AIRDECLOAK-NG(1)

NOM

airuncloak-ng - Supprime les trames wep camouflées d'un fichier pcap.

SYNTAXE

airuncloak-ng <options>

DESCRIPTION

airuncloak-ng est un outil qui supprime le camouflage wep d'un fichier pcap. Certains IPS (en fait, un seul) peuvent activement "empêcher" le craquage d'une clé WEP en insérant des leurres (fausses trames wep) dans l'air pour tromper aircrack-ng. Dans certains cas rares, le camouflage échoue et la clé peut être récupérée sans supprimer ces leurres. Dans les cas où la clé ne peut pas être récupérée, utilisez cet outil pour filtrer les leurres.

Le programme fonctionne en lisant le fichier d'entrée et en sélectionnant les paquets d'un réseau spécifique. Chaque paquet sélectionné est placé dans une liste et classifié (le statut par défaut est "inconnu"). Des filtres sont ensuite appliqués (dans l'ordre spécifié par l'utilisateur) sur cette liste. Ils changeront le statut des paquets (inconnu, non camouflé, potentiellement camouflé ou camouflé). L'ordre des filtres est très important car chaque filtre basera son analyse, entre autres choses, sur le statut des paquets, et des ordres différents donneront des résultats différents.

Exigence importante : le fichier pcap doit contenir tous les paquets (y compris les balises et tous les autres paquets "inutiles") pour l'analyse (et si possible, les en-têtes prism/radiotap).

OPTIONS

-h, --help
Affiche l'écran d'aide.
-i <fichier>
Chemin vers le fichier de capture.
--ssid <ESSID>
Essid du réseau (non encore implémenté) à filtrer.
--bssid <BSSID>
BSSID du réseau à filtrer.
--null-packets
Suppose que les paquets nuls peuvent être camouflés.
--disable-base-filter
N'applique pas le filtre de base.
--drop-frag
Supprime les paquets fragmentés.
--filters <filtres>
Applique différents filtres (séparés par une virgule). Voir ci-dessous.

FILTRES

signal
Essaie de filtrer en fonction du signal (en-têtes prism ou radiotap dans le fichier pcap).
duplicate_sn
Supprime tous les numéros de séquence dupliqués pour l'AP et le client (qui sont proches l'un de l'autre).
duplicate_sn_ap
Supprime les numéros de séquence dupliqués uniquement pour l'AP (qui sont proches l'un de l'autre).
duplicate_sn_client
Supprime les numéros de séquence dupliqués uniquement pour le client (qui sont proches l'un de l'autre).
consecutive_sn
Filtre basé sur le fait que les IV devraient être consécutifs (uniquement pour l'AP).
duplicate_iv
Supprime tous les IV dupliqués.
signal_dup_consec_sn
Utilise le signal (si disponible), les numéros de séquence dupliqués et consécutifs (le filtrage est beaucoup plus précis que l'utilisation de tous ces filtres un par un).
