PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

aio_error — récupérer le statut d'erreur d'une opération d'E/S asynchrone

SYNTAXE

#include <aio.h>
int aio_error(const struct aiocb *aiocbp);

DESCRIPTION

La fonction aio_error() renvoie le statut d'erreur associé à la structure aiocb référencée par l'argument aiocbp. Le statut d'erreur d'une opération d'E/S asynchrone est la valeur errno qui serait définie par l'opération correspondante read(), write(), fdatasync(), ou fsync(). Si l'opération n'est pas encore terminée, le statut d'erreur est égal à [EINPROGRESS].

Si la structure aiocb pointée par aiocbp n'est pas associée à une opération qui a été planifiée, les résultats sont indéfinis.

VALEUR DE RETOUR

Si l'opération d'E/S asynchrone s'est terminée avec succès, 0 est renvoyé. Si l'opération asynchrone s'est terminée sans succès, le statut d'erreur, tel que décrit pour read(), write(), fdatasync() et fsync(), est renvoyé. Si l'opération d'E/S asynchrone n'est pas encore terminée, [EINPROGRESS] est renvoyé.

Si la fonction aio_error() échoue, elle renvoie -1 et définit errno pour indiquer l'erreur.

ERREURS

La fonction aio_error() peut échouer si :

EINVAL
L'argument aiocbp ne fait pas référence à une opération asynchrone dont le statut de retour n'a pas encore été récupéré.
