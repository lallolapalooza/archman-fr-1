aio_return(3) Manuel des fonctions de bibliothèque aio_return(3)

NOM

aio_return - obtenir le statut de retour d'une opération d'E/S asynchrones

BIBLIOTHÈQUE

Bibliothèque temps réel (librt, -lrt)

SYNTAXE

#include <aio.h>
ssize_t aio_return(struct aiocb *aiocbp);

DESCRIPTION

La fonction aio_return() retourne le statut de retour final pour la requête d'E/S asynchrones dont le bloc de contrôle est pointé par aiocbp. (Voir aio(7) pour une description de la structure aiocb.)

Cette fonction ne doit être appelée qu'une seule fois pour une requête donnée, après que aio_error(3) ait retourné autre chose que EINPROGRESS.

VALEUR DE RETOUR

Si l'opération d'E/S asynchrones s'est terminée, cette fonction retourne la valeur qui aurait été retournée en cas d'appel synchrone de read(2), write(2), fsync(2), ou fdatasync(2). En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

Si l'opération d'E/S asynchrones n'est pas encore terminée, la valeur de retour et l'effet de aio_return() sont indéfinis.

ERREURS

EINVAL
aiocbp ne pointe pas vers un bloc de contrôle pour une requête d'E/S asynchrones dont le statut de retour n'a pas encore été récupéré.
ENOSYS
aio_return() n'est pas implémenté.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
aio_return () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.1. POSIX.1-2001.

EXEMPLES

Voir aio(7).
