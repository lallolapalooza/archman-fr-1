NOM

airgraph-ng - utilitaire de visualisation 802.11

SYNOPIS

airgraph-ng [options]

DESCRIPTION

airgraph-ng génère des graphiques à partir du fichier CSV généré par Airodump-ng. L'idée est de montrer les relations des clients avec les points d'accès, donc ne soyez pas choqué si vous ne voyez qu'une seule relation car vous n'avez peut-être capturé qu'un seul client.

OPTIONS

-h
Affiche l'écran d'aide.
-i
Fichier CSV d'Airodump-ng
-o
Fichier PNG de sortie.
-g
Choisit le type de graphique. Les types actuels sont [CAPR (Relation Client à Point d'Accès) & CPG (Graphique de sondes communes)].
-a
Affiche les informations sur le programme.

EXEMPLES

airgraph-ng -i dump-01.csv -o dump.png -g CAPR

airgraph-ng -i dump-01.csv -o dump.png -g CPG
