AIRMON-NG(8) Manuel du gestionnaire système AIRMON-NG(8)

NOM

airmon-ng - Script POSIX sh conçu pour activer le mode moniteur sur les cartes sans fil.

SYNTAXE

airmon-ng <start|stop> <interface> [canal] airmon-ng <check> [kill]

DESCRIPTION

airmon-ng Ce script peut être utilisé pour activer le mode moniteur sur les interfaces sans fil. Il peut également être utilisé pour revenir du mode moniteur au mode géré. L'exécution de la commande airmon-ng sans paramètres affichera l'état des interfaces. Il peut également lister/arrêter les programmes qui peuvent interférer avec le fonctionnement de la carte sans fil.

PARAMÈTRES OPTIONNELS

start <interface> [canal]
Active le mode moniteur sur une interface (et spécifie un canal). Note : Madwifi-ng est un cas particulier, 'start' doit être utilisé sur les interfaces wifi et 'stop' sur les interfaces ath.
start <interface> [fréquence]
Active le mode moniteur sur une interface (et spécifie une fréquence en MHz). Note : Madwifi-ng est un cas particulier, 'start' doit être utilisé sur les interfaces wifi et 'stop' sur les interfaces ath.
stop <interface>
Désactive le mode moniteur et revient en mode géré (sauf pour madwifi-ng où il arrête le VAP ath).
check [kill]
Liste tous les programmes potentiels qui pourraient interférer avec la carte sans fil. Si 'kill' est spécifié, il tentera de tous les arrêter.
--verbose
Ce drapeau doit précéder start/stop/check et peut être combiné avec d'autres paramètres ou utilisé seul. Ce drapeau augmentera la verbosité pour fournir des informations utiles supplémentaires qui pourraient ne pas être nécessaires pour une utilisation normale.
--debug
Ce drapeau doit précéder start/stop/check et peut être combiné avec d'autres paramètres ou utilisé seul. Ce drapeau augmentera la verbosité au niveau de débogage pour aider à résoudre les erreurs dans airmon-ng. Utilisez ce drapeau lors de l'ouverture d'un bug, mais utilisez uniquement --verbose lors de la demande de support sur IRC.
--elite
ATTENTION : NE PAS UTILISER : Ce drapeau doit précéder start ou stop et empêchera airmon-ng de supprimer les interfaces. ATTENTION : L'utilisation de ce drapeau entraînera le refus immédiat de tout support de la part de l'équipe aircrack-ng, car ce comportement est connu pour être défectueux. ATTENTION !
