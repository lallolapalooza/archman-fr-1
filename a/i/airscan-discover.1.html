NOM

airscan-discover - Découvrir les scanners compatibles sane-airscan

SYNOPSIS

airscan-discover [options]

DESCRIPTION

airscan-discover est un outil en ligne de commande pour trouver les scanners eSCL et WSD sur un réseau local.

Il utilise Avahi pour découvrir les périphériques DNS-SD et sa propre implémentation de WS-Discovery pour découvrir les périphériques WSD.

En cas de succès, il affiche un fragment du fichier de configuration de sane-airscan, qui peut être directement ajouté à /etc/sane.d/airscan.conf.

OPTIONS

-test-fast ou --test-fast
Mode de découverte rapide (voir ane-airscan(5) pour les détails).
-test-auto ou --test-auto
Sélection automatique du protocole (voir ane-airscan(5) pour les détails).
-d
Afficher les messages de débogage sur la console.
-t
Écrire une trace de protocole très détaillée dans airscan-discover-zeroconf.log et airscan-discover-zeroconf.tar.
-h
Afficher l'écran d'aide.

FICHIERS

airscan-discover-zeroconf.log
Trace du protocole.
airscan-discover-zeroconf.tar
Messages non textuels, le cas échéant, enregistrés ici. Les messages textuels (c'est-à-dire XML) sont inclus directement dans le fichier .log.
