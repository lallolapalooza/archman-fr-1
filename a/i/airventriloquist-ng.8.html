NOM

airventriloquist-ng - Injection de paquets WiFi chiffrés

SYNTAXE

airventriloquist-ng [options]

DESCRIPTION

airventriloquist-ng injecte des paquets sur des réseaux WiFi chiffrés et contourne les systèmes de prévention d'intrusion sans fil.

OPTIONS

--help
Affiche l'écran d'aide.
-i <interface de rejeu>
Interface pour capturer et injecter. Option obligatoire.
-d, --deauth
Envoie des trames de désauthentification actives aux stations chiffrées.
-e <valeur>, --essid <valeur>
ESSID du réseau cible. Pour les SSID contenant des caractères spéciaux, voir https://www.aircrack-ng.org/doku.php?id=faq#how_to_use_spaces_double_quote_and_single_quote_etc_in_ap_names
-p <valeur>, --passphrase <valeur>
Phrase secrète WPA du réseau cible. La phrase secrète doit comporter entre 8 et 63 caractères.
-c, --icmp
Répond à toutes les trames ICMP (Débogage).
-n, --dns
IP vers laquelle résoudre toutes les requêtes DNS.
-s <URL>, --hijack <URL>
URL à rechercher dans les requêtes HTTP lors du détournement de connexions. L'URL peut contenir des caractères joker. Exemple : *jquery*.js*
-r <URL>, --redirect <URL>
URL vers laquelle rediriger les connexions détournées.
-v, --verbose
Sortie détaillée.
