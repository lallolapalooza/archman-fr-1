aio_fsync(3) Manuel des fonctions de bibliothèque aio_fsync(3)

NOM

aio_fsync - synchronisation asynchrone de fichier

BIBLIOTHÈQUE

Bibliothèque temps réel (librt, -lrt)

SYNTAXE

#include <aio.h>
int aio_fsync(int op, struct aiocb *aiocbp);

DESCRIPTION

La fonction aio_fsync() effectue une synchronisation sur toutes les opérations d'E/S asynchrones en attente associées à aiocbp->aio_fildes. (Voir aio(7) pour une description de la structure aiocb.)

Plus précisément, si op est O_SYNC, alors toutes les opérations d'E/S actuellement mises en file d'attente doivent être complétées comme par un appel à fsync(2), et si op est O_DSYNC, cet appel est l'analogue asynchrone de fdatasync(2).

Notez qu'il s'agit uniquement d'une requête ; elle n'attend pas la fin des E/S.

Outre aio_fildes, le seul champ de la structure pointée par aiocbp utilisé par cet appel est le champ aio_sigevent (une structure sigevent, décrite dans sigevent(3type)), qui indique le type de notification asynchrone souhaité à la fin. Tous les autres champs sont ignorés.

VALEUR DE RETOUR

En cas de succès (la requête de synchronisation a été mise en file d'attente avec succès), cette fonction retourne 0. En cas d'erreur, -1 est retourné et errno est définie pour indiquer l'erreur.

ERREURS

EAGAIN
Ressources insuffisantes.
EBADF
aio_fildes n'est pas un descripteur de fichier valide ouvert en écriture.
EINVAL
Les E/S synchronisées ne sont pas supportées pour ce fichier, ou op n'est ni O_SYNC ni O_DSYNC.
ENOSYS
aio_fsync() n'est pas implémentée.
