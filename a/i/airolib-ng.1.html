AIROLIB-NG(1) Manuel des commandes générales AIROLIB-NG(1)

NOM

airolib-ng - gérer et créer des tables de hachages précalculées WPA/WPA2

SYNTAXE

airolib-ng <base de données> <opération> [options]

DESCRIPTION

airolib-ng est un outil de la suite aircrack-ng pour stocker et gérer des listes d'ESSID et de mots de passe, calculer leurs clés maîtres par paire (PMK) et les utiliser dans le craquage WPA/WPA2. Le programme utilise la base de données légère SQLite3 comme mécanisme de stockage, disponible sur la plupart des plateformes. La base de données SQLite3 a été choisie en tenant compte de la disponibilité des plateformes, de la gestion, de la surcharge en mémoire et sur disque.

BASE DE DONNÉES

base de données
C'est le nom du fichier de base de données. Vous pouvez spécifier le chemin complet en option.

OPÉRATION

--stats
Affiche des informations sur la base de données.
--sql <sql>
Exécute une instruction SQL spécifiée.
--clean [all]
Nettoie la base de données des anciennes données inutiles. En spécifiant 'all', il réduira également la taille du fichier si possible et effectuera une vérification d'intégrité.
--batch
Démarre/Redémarre le traitement par lots de toutes les combinaisons d'ESSID et de mots de passe. Pour mettre en pause, appuyez sur Ctrl-C.
--verify [all]
Vérifie un ensemble de PMK choisies aléatoirement. Si 'all' est donné, tous les PMK invalides dans la base de données seront supprimés.
--import [essid|passwd] <fichier>
Importe un fichier plat comme liste d'ESSID ou de mots de passe.
import cowpatty <fichier>
Importe un fichier coWPAtty.
--export cowpatty <essid> <fichier>
Export vers un fichier cowpatty.
