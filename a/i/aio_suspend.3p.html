AIO_SUSPEND(3P) Manuel du programmeur POSIX AIO_SUSPEND(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

aio_suspend — attendre une requête d'E/S asynchrone

SYNOPIS

#include <aio.h>
int aio_suspend(const struct aiocb *const list[], int nent,
    const struct timespec *timeout);

DESCRIPTION

La fonction aio_suspend() suspend le thread appelant jusqu'à ce qu'au moins une des opérations d'E/S asynchrones référencées par l'argument list soit terminée, jusqu'à ce qu'un signal interrompe la fonction, ou, si timeout n'est pas NULL, jusqu'à ce que l'intervalle de temps spécifié par timeout soit écoulé. Si l'une des structures aiocb de la liste correspond à des opérations d'E/S asynchrones terminées (c'est-à-dire que le statut d'erreur de l'opération n'est pas égal à [EINPROGRESS]) au moment de l'appel, la fonction retourne sans suspendre le thread appelant. L'argument list est un tableau de pointeurs vers des blocs de contrôle d'E/S asynchrones. L'argument nent indique le nombre d'éléments dans le tableau. Chaque structure aiocb pointée a été utilisée pour initier une requête d'E/S asynchrone via aio_read(), aio_write(), ou lio_listio(). Ce tableau peut contenir des pointeurs NULL, qui sont ignorés. Si ce tableau contient des pointeurs qui font référence à des structures aiocb qui n'ont pas été utilisées pour soumettre des E/S asynchrones, le comportement est indéfini.

Si l'intervalle de temps indiqué dans la structure timespec pointée par timeout s'écoule avant que les opérations d'E/S référencées par list ne soient terminées, alors aio_suspend() retourne avec une erreur. Si l'option Horloge Monotone est supportée, l'horloge qui doit être utilisée pour mesurer cet intervalle de temps est l'horloge CLOCK_MONOTONIC.

VALEUR DE RETOUR

Si la fonction aio_suspend() retourne après qu'une ou plusieurs opérations d'E/S asynchrones ont été terminées, la fonction retourne zéro. Sinon, la fonction retourne la valeur -1 et définit errno pour indiquer l'erreur.

L'application peut déterminer quelles E/S asynchrones se sont terminées en parcourant le statut d'erreur et de retour associé en utilisant aio_error() et aio_return(), respectivement.

ERREURS

La fonction aio_suspend() échoue si :

EAGAIN
Aucune E/S asynchrone indiquée dans la liste référencée par list n'a été terminée dans l'intervalle de temps indiqué par timeout.
EINTR
Un signal a interrompu la fonction aio_suspend(). Notez que, comme chaque opération d'E/S asynchrone peut potentiellement provoquer un signal à sa fin, ce retour d'erreur peut être causé par la fin de l'une (ou plusieurs) des opérations d'E/S en attente.
