DESCRIPTIO

N

La fonction aio_read() doit lire aiocbp->aio_nbytes depuis le fichier associé à aiocbp->aio_fildes dans le tampon pointé par aiocbp->aio_buf. L'appel de fonction doit retourner lorsque la requête de lecture a été initiée ou mise en file d'attente vers le fichier ou le périphérique (même lorsque les données ne peuvent pas être délivrées immédiatement)

.

Si l'E/S priorisée est prise en charge pour ce fichier, alors l'opération asynchrone doit être soumise à une priorité égale à une priorité de planification de base moins aiocbp->aio_reqprio. Si l'ordonnancement d'exécution des threads n'est pas pris en charge, alors la priorité de planification de base est celle du processus appelant ;
sinon, la priorité de planification de base est celle du thread

appelant.

La valeur aiocbp peut être utilisée comme argument à aio_error() et aio_return() afin de déterminer respectivement le statut d'erreur et le statut de retour de l'opération asynchrone pendant son déroulement. Si une condition d'erreur est rencontrée lors de la mise en file d'attente, l'appel de fonction doit retourner sans avoir initié ou mis en file d'attente la requête. L'opération demandée a lieu à la position absolue dans le fichier telle que donnée par aio_offset, comme si lseek() était appelé immédiatement avant l'opération avec un offset égal à aio_offset et un whence égal à SEEK_SET. Après un appel réussi pour mettre en file d'attente une opération d'E/S asynchrone, la valeur du décalage du fichier pour le fichier est

indéterminée.

Le membre aio_sigevent spécifie la notification qui se produit lorsque la requête est

terminée.

Le champ aiocbp->aio_lio_opcode doit être ignoré par aio_rea

d().

L'argument aiocbp pointe vers une structure aiocb. Si le tampon pointé par aiocbp->aio_buf ou le bloc de contrôle pointé par aiocbp devient une adresse illégale avant l'achèvement de l'E/S asynchrone, alors le comportement est

indéfini.

Des opérations asynchrones simultanées utilisant le même aiocbp produisent des résultats

indéfinis.

Si l'E/S synchronisée est activée sur le fichier associé à aiocbp->aio_fildes, le comportement de cette fonction doit être conforme aux définitions de l'achèvement d'intégrité des données d'E/S synchronisée et de l'achèvement d'intégrité du fichier d'E/S

synchronisée.

Pour toute action système qui modifie l'espace mémoire du processus alors qu'une E/S asynchrone est en attente sur la plage d'adresses en cours de modification, le résultat de cette action est

indéfini.

Pour les fichiers réguliers, aucun transfert de données ne doit avoir lieu au-delà du décalage maximum établi dans la description de fichier ouverte associée à aiocbp->aio_filde

s
.
