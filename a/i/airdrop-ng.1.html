AIRDROP-NG(1) Manuel des commandes générales AIRDROP-NG(1)

NOM

airdrop-ng - Un outil de désauthentification sans fil basé sur des règles

SYNTAXE

airdrop-ng [-i <carte> -t <données> -r <règles>] -d <pilote> -s <sommeil> -p -b -u

DESCRIPTION

airdrop-ng est un programme utilisé pour la désauthentification ciblée et basée sur des règles des utilisateurs. Il peut cibler en fonction de l'adresse MAC, du type de matériel (en utilisant une recherche OUI, c'est-à-dire les appareils de type "APPLE") ou désauthentifier complètement TOUS les utilisateurs. lorcon et pylorcon sont utilisés pour la transmission des paquets de désauthentification.

OPTIONS

-d <pilote> , --driver <pilote>
Pilote pour l'injection. Pilotes supportés :
wlan-ng, hostap, airjack, prism54, madwifing, madwifiold, rtl8180, rt2570, rt2500, rt73, rt61, zd1211rw, bcm43xx, mac80211. Par défaut, c'est mac80211.
-i <carte> , --interface <carte>
Interface de la carte pour l'injection. Par exemple, -i mon0.
-l , --logging
Activer la journalisation dans un fichier. Si aucun chemin de fichier n'est fourni, airdrop-ng journalisera à l'emplacement par défaut.
-r <règles> , --rule <règles>
C'est ce qui distingue airdrop-ng des autres applications de désauthentification. Vous pouvez spécifier quels utilisateurs vous souhaitez expulser, en fonction de l'adresse MAC, de l'OUI, ou expulser tout le monde. Plusieurs règles peuvent être définies. Voir dropRules.conf dans le répertoire testing/, ou le README inclus avec l'installateur.
-s <sommeil> , --sleep <sommeil>
Temps de pause avant d'envoyer le prochain ensemble de paquets.
-t <données> , --dump <données>
Chemin vers le fichier texte au format .CSV d'airodump-ng.
-u , --update
Met à jour la liste OUI et vers la dernière version d'airdrop-ng.
