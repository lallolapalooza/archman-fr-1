AIO_CANCEL(3P) Manuel du programmeur POSIX AIO_CANCEL(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

aio_cancel — annuler une requête d'E/S asynchrones

SYNTAXE

#include <aio.h>
int aio_cancel(int fildes, struct aiocb *aiocbp);

DESCRIPTION

La fonction aio_cancel() tente d'annuler une ou plusieurs requêtes d'E/S asynchrones en cours sur le descripteur de fichier fildes. L'argument aiocbp pointe vers le bloc de contrôle d'E/S asynchrones pour une requête particulière à annuler. Si aiocbp est NULL, alors toutes les requêtes d'E/S asynchrones annulables en cours sur fildes seront annulées.

Une notification asynchrone normale se produira pour les opérations d'E/S asynchrones qui sont annulées avec succès. S'il y a des requêtes qui ne peuvent pas être annulées, alors le processus d'achèvement asynchrone normal aura lieu pour ces requêtes lorsqu'elles seront terminées.

Pour les opérations demandées qui sont annulées avec succès, le statut d'erreur associé sera défini sur [ECANCELED] et le statut de retour sera -1. Pour les opérations demandées qui ne sont pas annulées avec succès, aiocbp ne sera pas modifié par aio_cancel().

Si aiocbp n'est pas NULL, alors si fildes n'a pas la même valeur que le descripteur de fichier avec lequel l'opération asynchrone a été initiée, des résultats indéterminés se produisent.

Les opérations qui sont annulables sont définies par l'implémentation.

VALEUR RENVOYÉE

La fonction aio_cancel() renvoie la valeur AIO_CANCELED si la ou les opérations demandées ont été annulées. La valeur AIO_NOTCANCELED est renvoyée si au moins une des opérations demandées ne peut pas être annulée car elle est en cours. Dans ce cas, l'état des autres opérations, le cas échéant, référencées dans l'appel à aio_cancel() n'est pas indiqué par la valeur renvoyée par aio_cancel(). L'application peut déterminer l'état des choses pour ces opérations en utilisant aio_error(). La valeur AIO_ALLDONE est renvoyée si toutes les opérations sont déjà terminées. Sinon, la fonction renvoie -1 et définit errno pour indiquer l'erreur.

ERREURS

La fonction aio_cancel() échouera si :

EBADF
L'argument fildes n'est pas un descripteur de fichier valide.
