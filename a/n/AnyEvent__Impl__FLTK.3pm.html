NOM

AnyEvent::Impl::FLTK - Adaptateur AnyEvent pour FLTK (Fast Light Toolkit version deux)

SYNTAXE

use AnyEvent;
use FLTK;

# ce module est chargé automatiquement si nécessaire

DESCRIPTION

Ce module fournit une prise en charge transparente d'AnyEvent. Vous n'avez rien à faire pour que FLTK fonctionne avec AnyEvent, si ce n'est de charger FLTK avant de créer le premier watcher AnyEvent.

Cette implémentation ne doit pas être confondue avec AnyEvent::Impl::FLTK de Sanko Robinson. Cette implémentation est complètement défectueuse, et l'auteur est apparemment injoignable.

Dans tous les cas, FLTK souffre des maladies typiques des boîtes à outils GUI, telles que O(n) ou pire pour chaque opération (ajout d'un minuteur, destruction d'un minuteur, etc.), des maladies typiques des interfaces Perl pas bien testées, telles que la corruption de mémoire non aléatoire, et des problèmes typiques des boucles d'événements comme afterthought, tels que les watchers multiples sur le même descripteur de fichier qui se suppriment silencieusement les uns les autres.

Il n'a pas de watchers natifs pour les tâches inactives, les signaux ou les processus enfants, donc tous ceux-ci sont émulés.

VOIR AUSSI
