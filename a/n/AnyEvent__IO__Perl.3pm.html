NOM

AnyEvent::IO::Perl - backend perl pur pour AnyEvent::IO

SYNTAXE

use AnyEvent::IO;

DESCRIPTION

Ceci est le backend perl pur de AnyEvent::IO - il est toujours disponible, mais n'implémente en fait aucune opération d'E/S de manière asynchrone - tout est synchrone.

Pour les programmes simples qui peuvent attendre les E/S, il s'agit probablement de l'implémentation la plus efficace.
