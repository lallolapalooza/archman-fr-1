NOM

AnyEvent::XMPP::Ext::Version - Version du logiciel

SYNOPSIS

use AnyEvent::XMPP::Ext::Version;
my $version = AnyEvent::XMPP::Ext::Version->new;
$version->set_name    ("Mon client");
$version->set_version ("0.3");
$version->set_os      (`uname -a`);
$disco->enable_feature ($version->disco_feature);

DESCRIPTION

Ce module définit une extension pour fournir la capacité de répondre aux requêtes de version logicielle et de demander la version logicielle d'autres entités.

Voir aussi XEP-0092

Cette classe est dérivée de AnyEvent::XMPP::Ext et peut être ajoutée en tant qu'extension aux objets qui implémentent l'interface AnyEvent::XMPP::Extendable ou en dérivent.

MÉTHODES

new (%args)
Crée une nouvelle poignée de version logicielle.
set_name ($nom)
Cette méthode définit la chaîne de caractères du nom du logiciel $nom, la valeur par défaut est "AnyEvent::XMPP".
set_version ($version)
Cette méthode définit la chaîne de caractères de la version logicielle à laquelle il est répondu.

La valeur par défaut est $AnyEvent::XMPP::VERSION.

set_os ($os)
Cette méthode définit la chaîne de caractères du système d'exploitation $os. Si vous passez undef, la chaîne sera supprimée.

La valeur par défaut est aucune chaîne de système d'exploitation.

Vous pourriez vouloir passer quelque chose comme ceci :

$version->set_os (`uname -s -r -m -o`);
request_version ($con, $dest, $cb)
Cette méthode envoie une requête de version à $dest sur la connexion $con.

$cb est la fonction de rappel qui sera appelée si une erreur survient ou si le résultat est reçu. La fonction de rappel sera également appelée après le délai d'attente par défaut pour les IQ de la connexion $con. Le deuxième argument pour la fonction de rappel sera soit undef si aucune erreur ne s'est produite, soit une erreur de type AnyEvent::XMPP::Error::IQ. Le premier argument sera une référence de hachage avec les champs suivants :

jid
Le JID de l'entité à laquelle cette réponse de version appartient.
version
La chaîne de caractères de la version logicielle de l'entité.
name
Le nom du logiciel de l'entité.
os
Le système d'exploitation de l'entité, qui peut être indéfini s'il n'a pas été fourni.

Voici un exemple de la structure de la référence de hachage :

{
   jid     => 'juliet@capulet.com/balcony',
   name    => 'Exodus',
   version => '0.7.0.4',
   os      => 'Windows-XP 5.01.2600',
}
