NOM

AnyEvent::XMPP::Ext::Disco - Gestionnaire de découverte de services pour XEP-0030

SYNOPSIS

use AnyEvent::XMPP::Ext::Disco;
my $con = AnyEvent::XMPP::IM::Connection->new (...);
$con->add_extension (my $disco = AnyEvent::XMPP::Ext::Disco->new);
$disco->request_items ($con, 'romeo@montague.net', undef,
   sub {
      my ($disco, $items, $error) = @_;
      if ($error) { print "ERREUR:" . $error->string . "\n" }
      else {
         ... faire quelque chose avec les $items ...
      }
   }
);

DESCRIPTION

Ce module représente une classe de gestionnaire de découverte de services. Vous créez des instances de cette classe et obtenez un descripteur pour envoyer des requêtes de découverte comme décrit dans XEP-0030.

Il vous permet également de configurer un arbre disco-info/items que d'autres peuvent parcourir et vous permet de publier des informations disco.

Cette classe dérive de AnyEvent::XMPP::Ext et peut être ajoutée comme extension aux objets qui implémentent l'interface AnyEvent::XMPP::Extendable ou en dérivent.

MÉTHODES

new (%args)
Crée un nouveau descripteur disco.
set_identity ($category, $type, $name)
Ceci définit l'identité du nœud d'information racine.

$name est optionnel et peut être indéfini. Notez que $name écrasera tous les noms précédemment définis! Si $name est indéfini, aucun nom précédent n'est écrasé.

Pour une liste d'identités valides, regardez :

http://www.xmpp.org/registrar/disco-categories.html

Les types d'identité valides pour "$category = "client"" peuvent être :

bot
console
handheld
pc
phone
web
unset_identity ($category, $type)
Cette fonction supprime l'identité $category et $type.
enable_feature ($uri)
Cette méthode active la fonctionnalité $uri, où $uri doit être l'une des valeurs de la colonne Nom sur : http://www.xmpp.org/registrar/disco-features.html

Ces fonctionnalités sont activées par défaut :

http://jabber.org/protocol/disco#info
http://jabber.org/protocol/disco#items

Vous pouvez également passer une liste de fonctionnalités que vous souhaitez activer à "enable_feature" !

disable_feature ($uri)
Cette méthode active la fonctionnalité $uri, où $uri doit être l'une des valeurs de la colonne Nom sur : http://www.xmpp.org/registrar/disco-features.html

Vous pouvez également passer une liste de fonctionnalités que vous souhaitez désactiver à "disable_feature" !

request_items ($con, $dest, $node, $cb)
Cette méthode envoie une requête d'éléments à l'entité JID $from. $node est le nœud optionnel vers lequel envoyer la requête, qui peut être indéfini.

$con doit être une instance de AnyEvent::XMPP::Connection ou une de ses sous-classes. Le callback $cb sera appelé lorsque la requête retournera avec 3 arguments : le descripteur disco, un objet AnyEvent::XMPP::Ext::Disco::Items (ou indéfini) et un objet AnyEvent::XMPP::Error::IQ lorsqu'une erreur s'est produite et qu'aucun élément n'a été reçu.

Le délai d'attente de la requête est le délai d'attente IQ de la connexion $con.

$disco->request_items ($con, 'a@b.com', undef, sub {
   my ($disco, $items, $error) = @_;
   die $error->string if $error;
   # faire quelque chose avec les éléments ici ;_)
});
request_info ($con, $dest, $node, $cb)
Cette méthode envoie une requête d'informations à l'entité JID $from. $node est le nœud optionnel vers lequel envoyer la requête, qui peut être indéfini.

$con doit être une instance de AnyEvent::XMPP::Connection ou une de ses sous-classes. Le callback $cb sera appelé lorsque la requête retournera avec 3 arguments : le descripteur disco, un objet AnyEvent::XMPP::Ext::Disco::Info (ou indéfini) et un objet AnyEvent::XMPP::Error::IQ lorsqu'une erreur s'est produite et qu'aucun élément n'a été reçu.

Le délai d'attente de la requête est le délai d'attente IQ de la connexion $con.

$disco->request_info ($con, 'a@b.com', undef, sub {
   my ($disco, $info, $error) = @_;
   die $error->string if $error;
   # faire quelque chose avec les informations ici ;_)
});
