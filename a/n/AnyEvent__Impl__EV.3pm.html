NOM

AnyEvent::Impl::EV - Adaptateur AnyEvent pour EV

SYNOPSIS

use AnyEvent;
use EV;

# ce module est chargé automatiquement selon les besoins

DESCRIPTION

Ce module fournit un support transparent pour AnyEvent. Vous n'avez rien à faire pour que EV fonctionne avec AnyEvent, à part charger EV avant de créer le premier observateur AnyEvent.

EV est la bibliothèque d'événements la plus rapide pour Perl, et la mieux supportée par AnyEvent. La plupart des fonctions de l'API AE sont implémentées comme des alias directs aux fonctions EV, donc utiliser EV via AE est aussi rapide qu'utiliser EV directement.
