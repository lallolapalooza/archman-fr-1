AnyEvent::XMPP::Ext::Ping(3) Documentation Perl fournie par l'utilisateur AnyEvent::XMPP::Ext::Ping(3)

NOM

AnyEvent::XMPP::Ext::Ping - Implémentation de XMPP Ping XEP-0199

SYNTAXE

use AnyEvent::XMPP::Ext::Ping;
my $con = AnyEvent::XMPP::IM::Connection->new (...);
$con->add_extension (my $ping = AnyEvent::XMPP::Ext::Ping->new);
# ceci active le timeout automatique d'une connexion si elle n'a pas répondu
# dans les 120 secondes à un ping avec une réponse
$ping->enable_timeout ($con, 120);
my $cl = AnyEvent::XMPP::Client->new (...);
$cl->add_extension (my $ping = AnyEvent::XMPP::Ext::Ping->new);
# ceci active le timeout automatique des connexions nouvellement créées
$ping->auto_timeout (120);
$ping->ping ($con, 'ping_dest@server.tld', sub {
   my ($time, $error) = @_;
   if ($error) {
      # nous avons eu une erreur
   }
   # $time est un flottant (secondes) du temps aller-retour si vous avez Time::HiRes
});

DESCRIPTION

Cette extension implémente XEP-0199: XMPP Ping. Elle vous permet de définir un minuteur de ping automatique qui déconnectera les connexions mortes (qui n'ont pas répondu à un ping après N secondes). Voir aussi la documentation de la méthode "enable_timeout" ci-dessous.

Elle vous permet également d'envoyer des pings à toute entité XMPP de votre choix et mesurera le temps nécessaire si vous avez Time::HiRes.

MÉTHODES

new (%args)
Crée une nouvelle poignée de ping.
auto_timeout ($timeout)
Cette méthode active le timeout automatique des nouvelles connexions. Elle appelle "enable_timeout" (voir ci-dessous) pour chaque nouvelle connexion qui a été connectée et a émis un événement "stream_ready".

Ceci est utile si vous souhaitez que les connexions qui possèdent cette extension soient automatiquement expirées. Ceci est particulièrement utile avec des modules comme AnyEvent::XMPP::Client (voir aussi la SYNTAXE ci-dessus).

enable_timeout ($con, $timeout)
Ceci active un ping périodique sur la connexion $con. $timeout doit être le nombre de secondes que durent les intervalles de ping.

Si le serveur auquel la connexion est établie via $con n'a pas répondu dans les $timeout secondes, la connexion $con sera déconnectée.

Veuillez noter qu'il existe déjà un mécanisme de timeout de base pour les connexions TCP mortes dans AnyEvent::XMPP::Connection, voir aussi la variable de configuration "whitespace_ping_interval" pour une connexion là-bas. Il dépendra alors des timeouts TCP pour déconnecter la connexion.

Utilisez "enable_timeout" et "auto_timeout" uniquement si vous sentez réellement que vous avez besoin d'un timeout explicite pour vos connexions.

ping ($con, $dest, $cb, $timeout)
Cette méthode envoie une requête ping à $dest via la connexion AnyEvent::XMPP dans $con. Si $dest est indéfini, le ping sera envoyé au serveur connecté. $cb sera appelé soit lorsque le ping expire, qu'une erreur survient, soit lorsque le résultat du ping est reçu. $timeout est un timeout optionnel pour la requête ping, si $timeout n'est pas donné, le timeout IQ par défaut pour la connexion est le timeout pertinent.

Le premier argument de $cb sera les secondes du temps aller-retour pour cette requête (si vous avez Time::HiRes). Si vous n'avez pas Time::HiRes installé, le premier argument sera undef.

Le deuxième argument de $cb sera soit undef si aucune erreur ne s'est produite, soit un objet d'erreur AnyEvent::XMPP::Error::IQ.

ignore_pings ($bool)
Cette méthode est principalement destinée aux tests, elle indique à cette extension d'ignorer toutes les requêtes ping et empêchera toute réponse d'être envoyée.
