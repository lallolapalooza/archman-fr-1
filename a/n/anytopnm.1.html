NOM

anytopnm - convertir un type de fichier image arbitraire en PBM, PGM ou PPM

SYNTAXE

anytopnm [fichier]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

anytopnm convertit l'image d'entrée, qui peut être dans n'importe lequel d'environ 100 formats graphiques, au format PBM, PGM ou PPM, selon la nature de l'image d'entrée, et la génère sur la sortie standard.

Pour déterminer le format de l'entrée, anytopnm utilise le programme file (éventuellement assisté par le fragment de fichier de noms magiques inclus avec Netpbm). Si cela échoue (très peu de formats d'image ont des noms magiques), anytopnm examine l'extension du nom de fichier. Si cela échoue, anytopnm abandonne.

Le type du fichier de sortie dépend de l'image d'entrée.

anytopnm utilise les convertisseurs pour des formats graphiques particuliers qui se trouvent dans le paquet Netpbm, il ne peut donc pas convertir un format que vous ne pourriez pas convertir avec un autre programme Netpbm. Ce que anytopnm ajoute est la capacité de reconnaître le format et de choisir le programme Netpbm approprié pour le convertir. Par exemple, si vous invoquez anytopnm sur un fichier GIF, anytopnm reconnaîtra qu'il s'agit d'un fichier GIF et donc giftopnm sait comment le convertir en PNM, donc anytopnm invoque giftopnm.

anytopnm ne peut pas reconnaître tous les formats d'entrée possibles, vous pourrez donc toujours convertir une image avec un programme Netpbm spécifique lorsque anytopnm échoue à la convertir.

Si file indique que le fichier d'entrée est compressé (via une compression Unix compress, gzip ou bzip), anytopnm le décompresse et procède comme ci-dessus avec le résultat décompressé.

Si file indique que le fichier d'entrée est encodé par uuencode ou btoa, anytopnm le décode et procède comme ci-dessus avec le résultat décodé.

Si fichier est - ou n'est pas donné, anytopnm prend son entrée de l'entrée standard.
