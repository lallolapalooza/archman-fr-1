NOM

AnyEvent::XMPP::Error::IQAuth - Erreur d'authentification IQ

Sous-classe de AnyEvent::XMPP::Error

MÉTHODES

contexte
Cette méthode retourne soit :

"iq_error", ce qui signifie qu'une erreur IQ a été détectée, et qui est accessible via la méthode "iq_error".

Soit : "no_fields", ce qui signifie qu'aucun champ de formulaire n'a été trouvé dans le résultat de l'authentification IQ.
