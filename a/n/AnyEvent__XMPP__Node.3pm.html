NOM

AnyEvent::XMPP::Node - Aide pour l'arbre de nœuds XML pour l'analyseur.

SYNTAXE

use AnyEvent::XMPP::Node;
...

DESCRIPTION

Cette classe représente un nœud XML. AnyEvent::XMPP ne devrait normalement pas nécessiter de manipulation de l'arbre d'analyse, mais cela peut parfois être nécessaire.

Si vous ressentez le besoin de manipuler ces éléments et que vous pensez qu'AnyEvent::XMPP devrait plutôt s'en charger, envoyez-moi un e-mail, une demande de fonctionnalité ou, de préférence, un patch !

Chaque AnyEvent::XMPP::Node a un espace de noms, des attributs, du texte et des nœuds enfants.

Vous pouvez y accéder via les méthodes suivantes :

MÉTHODES

new ($ns, $el, $attrs, $parser)
Crée un nouvel objet AnyEvent::XMPP::Node avec le nom de balise du nœud $el dans l'URI de l'espace de noms $ns et les attributs $attrs. Le $parser doit être l'instance de "AnyEvent::XMPP::Parser" qui a généré ce nœud.
name
Le nom de balise de ce nœud.
namespace
Retourne l'URI de l'espace de noms de ce nœud.
eq ($namespace_or_alias, $name) ou eq ($node)
Retourne vrai si l'élément courant correspond au nom de balise $name dans les espaces de noms référencés par $namespace_or_alias.

Vous pouvez passer soit un alias défini dans AnyEvent::XMPP::Namespaces, soit une URI d'espace de noms dans $namespace_or_alias. Si aucun alias avec le nom $namespace_or_alias n'est trouvé dans AnyEvent::XMPP::Namespaces, il sera interprété comme une URI d'espace de noms.

Le premier argument de eq peut également être une autre instance AnyEvent::XMPP::Node.

eq_ns ($namespace_or_alias) or eq_ns ($node)
Cette méthode retourne vrai si l'espace de noms de cette instance de AnyEvent::XMPP::Node correspond à l'espace de noms décrit par $namespace_or_alias ou à l'espace de noms du $node qui doit être une autre instance d'AnyEvent::XMPP::Node.

Voir "eq" pour la signification de $namespace_or_alias.

attr ($name)
Retourne le contenu de l'attribut $name.
add_node ($node)
Ajoute un sous-nœud au nœud courant.
nodes
Retourne une liste de sous-nœuds.
add_text ($string)
Ajoute des données caractères au nœud courant.
text
Retourne le texte de ce nœud.
find_all (@path)
Cette méthode effectue une descente récursive à travers les sous-nœuds et récupère tous les nœuds qui correspondent au dernier élément de @path.

Les éléments de @path consistent en une référence de tableau vers un tableau avec deux éléments : la clé de l'espace de noms connue par le $parser et le nom de balise recherché.

write_on ($writer)
Cela écrit le nœud courant dans l'objet AnyEvent::XMPP::Writer dans $writer.
as_string ()
Cette méthode retourne la représentation caractère d'origine de cet élément XML (et de ses nœuds enfants). Veuillez noter que la chaîne est une chaîne unicode, ce qui signifie que pour obtenir des octets, utilisez : 
my $octets = encode ('UTF-8', $node->as_string);

Maintenant, vous pouvez faire des prouesses comme celles-ci :

my $libxml = XML::LibXML->new;
my $doc    = $libxml->parse_string (encode ('UTF-8', $node->as_string ()));

(Vous pouvez utiliser votre analyseur XML préféré :)

append_raw ($string)
Cette méthode est appelée par l'analyseur pour stocker les chaînes d'origine de cet élément.
to_sax_events ($handler)
Cette méthode prend tout ce qui peut recevoir des événements SAX. Voir aussi XML::GDOME::SAX::Builder ou XML::Handler::BuildDOM ou XML::LibXML::SAX::Builder.

Avec ceci, vous pouvez convertir ce nœud en n'importe quelle structure de niveau DOM 2 que vous souhaitez :

my $builder = XML::LibXML::SAX::Builder->new;
$node->to_sax_events ($builder);
my $dom = $builder->result;
print "Canonisé : " . $dom->toStringC14N . "\n";
