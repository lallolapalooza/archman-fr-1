ansible-inventory(1) Commandes d'administration système ansible-inventory(1)

NOM

ansible-inventory - Affiche les informations d'inventaire Ansible, par défaut il utilise le format JSON du script d'inventaire

SYNOPSIS

utilisation : ansible-inventory [-h] [--version] [-v] [-i INVENTAIRE] [-l SOUS-ENSEMBLE]
[--flush-cache] [--vault-id VAULT_IDS] [-J | --vault-password-file VAULT_PASSWORD_FILES] [--playbook-dir BASEDIR] [-e EXTRA_VARS] [--list] [--host HÔTE] [--graph] [-y] [--toml] [--vars] [--export] [--output FICHIER_SORTIE] [groupe]

DESCRIPTION

utilisé pour afficher ou exporter l'inventaire configuré tel qu'Ansible le voit

OPTIONS COMMUNES

Le nom d'un groupe dans l'inventaire, pertinent lors de l'utilisation de --graph

--export

Lors de l'utilisation de --list, représente de manière optimisée pour l'export, et non comme une représentation précise de la manière dont Ansible l'a traité

--flush-cache

efface le cache de faits pour chaque hôte de l'inventaire

--graph

crée un graphique de l'inventaire, si un motif est fourni, il doit être un nom de groupe valide. Il ignorera la limite

--host 'HÔTE'

Affiche les informations d'un hôte spécifique, fonctionne comme un script d'inventaire. Il ignorera la limite

--list

Affiche les informations de tous les hôtes, fonctionne comme un script d'inventaire

--output 'FICHIER_SORTIE'

Lors de l'utilisation de --list, envoie l'inventaire vers un fichier au lieu de l'afficher à l'écran

--playbook-dir 'BASEDIR'

Puisque cet outil n'utilise pas de playbooks, utilisez ceci comme répertoire de playbook de substitution. Cela définit le chemin relatif pour de nombreuses fonctionnalités, y compris roles/, group_vars/, etc.

--toml

Utilise le format TOML au lieu du JSON par défaut, ignoré pour --graph

--vars

Ajoute les variables à l'affichage du graphique, ignoré sauf si utilisé avec --graph

--vault-id

l'identité du coffre-fort à utiliser. Cet argument peut être spécifié plusieurs fois.

--vault-password-file, --vault-pass-file

fichier de mot de passe du coffre-fort

--version

affiche le numéro de version du programme, l'emplacement du fichier de configuration, le chemin de recherche des modules configuré, l'emplacement des modules, l'emplacement de l'exécutable, puis quitte

-J, --ask-vault-password, --ask-vault-pass

demande le mot de passe du coffre-fort

-e, --extra-vars

définit des variables supplémentaires sous forme clé=valeur ou YAML/JSON, pour un nom de fichier, préfixez avec @. Cet argument peut être spécifié plusieurs fois.

-h, --help

affiche ce message d'aide et quitte

-i, --inventory, --inventory-file

spécifie le chemin de l'inventaire ou une liste d'hôtes séparés par des virgules. Cet argument peut être spécifié plusieurs fois.

-l 'SOUS-ENSEMBLE', --limit 'SOUS-ENSEMBLE'

limite davantage les hôtes sélectionnés à un motif supplémentaire

-v, --verbose

Fait qu'Ansible affiche plus de messages de débogage. L'ajout de plusieurs -v augmentera la verbosité, les plugins intégrés évaluent actuellement jusqu'à -vvvvvv. Un niveau raisonnable pour commencer est -vvv, le débogage de la connexion peut nécessiter -vvvv. Cet argument peut être spécifié plusieurs fois.

-y, --yaml

Utilise le format YAML au lieu du JSON par défaut, ignoré pour --graph

ARGUMENTS

groupe

Le nom d'un groupe dans l'inventaire, pertinent lors de l'utilisation de --graph

INVENTAIRE

Ansible stocke les hôtes sur lesquels il peut potentiellement opérer dans un inventaire. Cela peut être un fichier YAML, un fichier de type ini, un script, un répertoire, une liste, etc. Pour des options supplémentaires, consultez la documentation sur https://docs.ansible.com/.

ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être spécifiées.

ANSIBLE_INVENTORY -- Remplace les sources d'inventaire ansible par défaut

ANSIBLE_CONFIG -- Spécifie l'emplacement de remplacement pour le fichier de configuration d'ansible

Beaucoup plus sont disponibles pour la plupart des options dans ansible.cfg

Pour une liste complète, consultez https://docs.ansible.com/. ou utilisez la commande ansible-config .

FICHIERS

/etc/ansible/hosts -- Fichier d'inventaire par défaut

/etc/ansible/ansible.cfg -- Fichier de configuration, utilisé s'il est présent

~/.ansible.cfg -- Fichier de configuration utilisateur, remplace la configuration par défaut s'il est présent

./ansible.cfg -- Fichier de configuration local (dans le répertoire de travail courant) supposé être « spécifique au projet » et remplace le reste s'il est présent.

Comme mentionné ci-dessus, la variable d'environnement ANSIBLE_CONFIG remplacera toutes les autres.
