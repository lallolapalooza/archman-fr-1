AnyEvent::XMPP::Ext::Registration(3) Documentation Perl fournie par l'utilisateur AnyEvent::XMPP::Ext::Registration(3)

NOM

AnyEvent::XMPP::Ext::Registration - Gère toutes les tâches d'enregistrement dans la bande

SYNTAXE

my $con = AnyEvent::XMPP::Connection->new (...);
$con->reg_cb (stream_pre_authentication => sub {
   my ($con) = @_;
   my $reg = AnyEvent::XMPP::Ext::Registration->new (connection => $con);
   $reg->send_registration_request (sub {
      my ($reg, $form, $error) = @_;
      if ($error) {
         # gestion d'erreur
      } else {
         my $af = $form->try_fillout_registration ("tester", "secret");
         $reg->submit_form ($af, sub {
            my ($reg, $ok, $error, $form) = @_;
            if ($ok) { # enregistré avec succès !
               $con->authenticate
            } else {   # erreur
               if ($form) { # nous avons reçu un formulaire alternatif !
                  # le remplir et le soumettre à nouveau avec C<submit_form>
               }
            }
         });
      }
   });
   0
});

DESCRIPTION

Ce module gère toutes les tâches d'enregistrement dans la bande qui sont possibles et spécifiées par XEP-0077. C'est principalement une classe d'aide qui facilite certaines tâches telles que la soumission et la récupération d'un formulaire.

MÉTHODES

new (%args)
C'est le constructeur pour un objet d'enregistrement.
connection
Ce doit être un objet AnyEvent::XMPP::Connection (ou une autre sous-classe de celui-ci).

Cet argument est requis.

send_registration_request ($cb)
Cette méthode envoie une requête de formulaire d'inscription. $cb sera appelé lorsque le formulaire sera arrivé ou qu'une erreur se sera produite.

Le premier argument de $cb est toujours $self. Si le formulaire est arrivé, le deuxième argument de $cb sera un objet AnyEvent::XMPP::Ext::RegisterForm. Si une erreur s'est produite, le deuxième argument sera undef et le troisième argument sera un objet AnyEvent::XMPP::Error::Register.

Pour des indices sur la façon dont AnyEvent::XMPP::Ext::RegisterForm devrait être rempli, regardez dans XEP-0077. Soit vous avez des champs de formulaire hérités, des données hors bande ou un formulaire de données.

Voir aussi try_fillout_registration dans AnyEvent::XMPP::Ext::RegisterForm.

send_unregistration_request ($cb)
Cette méthode envoie une requête de désinscription.

Pour la description de la sémantique du rappel dans $cb, veuillez regarder dans la description de la méthode "submit_form" ci-dessous.

send_password_change_request ($username, $password, $cb)
Cette méthode envoie une requête de changement de mot de passe pour l'utilisateur $username avec le nouveau mot de passe $password.

Pour la description de la sémantique du rappel dans $cb, veuillez regarder dans la description de la méthode "submit_form" ci-dessous.

submit_form ($form, $cb)
Cette méthode soumet le $form qui devrait être de type AnyEvent::XMPP::Ext::RegisterForm et devrait être un formulaire de réponse.

$con est la connexion sur laquelle envoyer ce formulaire.

$cb est le rappel qui sera appelé une fois que le formulaire aura été soumis et qu'une erreur ou un succès aura été reçu. Le premier argument du rappel sera l'objet AnyEvent::XMPP::Ext::Registration, le deuxième sera une valeur booléenne qui est vraie lorsque le formulaire a été transmis avec succès et que tout va bien. Si le deuxième argument est faux, alors le troisième argument est un objet AnyEvent::XMPP::Error::Register. Si l'erreur contenait un formulaire de données qui est requis pour réussir la requête, alors le quatrième argument sera un objet AnyEvent::XMPP::Ext::RegisterForm que vous devriez remplir et soumettre à nouveau avec "submit_form".

Pour la sémantique d'un tel formulaire d'erreur, voir aussi XEP-0077.
