NOM

AnyEvent::XMPP::Ext::MUC::Message - Un message de salon

SYNTAXE

DESCRIPTION

Ce message représente un message provenant d'un salon MUC. Il est dérivé de AnyEvent::XMPP::IM::Message. (Vous pouvez utiliser les méthodes de cette classe pour y accéder, par exemple).

Les méthodes telles que "make_reply" retournent également un AnyEvent::XMPP::Ext::MUC::Message.

MÉTHODES

new (%args)
Ce constructeur prend les mêmes arguments que le constructeur pour AnyEvent::XMPP::IM::Message.
room
Retourne le salon de discussion dans le contexte duquel ce message a été envoyé.
send ([$room])
Cette méthode envoie ce message. Si $room est défini, elle définira la connexion de cet objet message avant son envoi.
make_reply ([$msg])
Cette méthode retourne une nouvelle instance de AnyEvent::XMPP::Ext::MUC::Message. L'adresse de destination, la connexion et le type de l'objet message retourné seront définis.

Si $msg est défini et est une instance de AnyEvent::XMPP::Ext::MUC::Message, l'adresse de destination, la connexion et le type de $msg seront modifiés et cette méthode ne retournera pas une nouvelle instance de AnyEvent::XMPP::Ext::MUC::Message.

Si $self est un message de type 'groupchat', l'attribut "to" sera défini sur le JID nu du salon pour la réponse.

from_nick
Cette méthode retourne le pseudonyme de la source de ce message.
is_private
Cette méthode retourne vrai si le message n'était pas adressé au salon, mais en privé à vous.
