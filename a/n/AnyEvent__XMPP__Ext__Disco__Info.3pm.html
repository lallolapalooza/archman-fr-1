AnyEvent::XMPP::Ext::Disco::Info(3) Documentation Perl fournie par l'utilisateur AnyEvent::XMPP::Ext::Disco::Info(3)

NOM

AnyEvent::XMPP::Ext::Disco::Info - Informations de découverte de service

SYNOPSIS

DESCRIPTION

Cette classe représente le résultat d'une requête d'informations de découverte envoyée par un gestionnaire "AnyEvent::XMPP::Ext::Disco".

MÉTHODES

xml_node ()
Retourne l'objet AnyEvent::XMPP::Node de la requête IQ.
jid ()
Retourne le JID auquel ces éléments appartiennent.
node ()
Retourne le nœud auquel ces éléments appartiennent (peut être indéfini).
identities ()
Retourne une liste de hachages contenant les clés suivantes : 
category, type, name, xml_node

"category" est la catégorie de l'identité. "type" est le type de l'identité. "name" est le nom lisible par l'homme de l'identité et peut être indéfini. "xml_node" est l'objet AnyEvent::XMPP::Node du nœud <identity/>.

"category" et "type" peuvent être l'un de ceux définis sur :

http://www.xmpp.org/registrar/disco-categories.html
features ()
Retourne un hachage de paires clé/valeur où la clé est le nom de la fonctionnalité tel qu'énuméré sur : http://www.xmpp.org/registrar/disco-features.html

et la valeur est un objet AnyEvent::XMPP::Node pour le nœud <feature/>.

debug_dump ()
Affiche les informations de cet objet Info sur la sortie standard.
