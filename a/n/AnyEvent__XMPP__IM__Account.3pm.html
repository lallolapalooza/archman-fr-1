NOM

AnyEvent::XMPP::IM::Account - Compte de messagerie instantanée

SYNOPSIS

my $cl = AnyEvent::XMPP::IM::Client->new;
...
my $acc = $cl->get_account ($jid);

DESCRIPTION

Ce module représente une classe pour les comptes de messagerie instantanée. Il est utilisé par AnyEvent::XMPP::Client.

Vous ne pouvez obtenir une instance de cette classe qu'en appelant la méthode "get_account" sur un objet AnyEvent::XMPP::Client.

MÉTHODES

connection ()
Retourne l'objet AnyEvent::XMPP::IM::Connection si ce compte en possède déjà un (undefined sinon).
is_connected ()
Retourne vrai si ce compte est connecté.
jid ()
Retourne soit le JID complet si le compte est connecté, soit le JID nu si ce n'est pas le cas.
bare_jid ()
Retourne toujours le JID nu de ce compte après application de stringprep, vous pouvez donc comparer les JIDs retournés par cette fonction.
nickname ()
Votre pseudonyme pour ce compte.
nickname_for_jid ($jid)
Cette méthode transforme le $jid en pseudonyme. Elle recherche le $jid dans le carnet d'adresses et cherche un pseudonyme. Si aucun pseudonyme n'a pu être trouvé dans le carnet d'adresses, elle retourne la partie nœud pour le $jid.
send_tracked_message ($msg)
Cette méthode envoie l'objet AnyEvent::XMPP::IM::Message dans $msg. L'attribut "to" du message est ajusté par le mécanisme de suivi de conversation.

ÉVÉNEMENTS

Pour ces événements, des rappels peuvent être enregistrés (avec l'interface Object::Event) :

tracked_message_destination => $bare_jid, $full_jid
Cet événement est émis chaque fois que le mécanisme de suivi de message change (ou définit) sa ressource de destination pour le $bare_jid vers $full_jid.
removed
Chaque fois que le compte est supprimé de l'objet AnyEvent::XMPP::Client (par exemple, lors de la déconnexion), cet événement est émis avant sa destruction.
