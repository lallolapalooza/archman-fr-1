AnyEvent::XMPP::Ext::Pubsub(3) Documentation Perl fournie par l'utilisateur AnyEvent::XMPP::Ext::Pubsub(3)

NOM

AnyEvent::XMPP::Ext::Pubsub - Implémente XEP-0060 : Publication-Abonnement

SYNTAXE

my $con = AnyEvent::XMPP::Connection->new (...);
$con->add_extension (my $ps = AnyEvent::XMPP::Ext::Pubsub->new);
...

DESCRIPTION

Ce module implémente toutes les tâches de gestion du mécanisme de publication-abonnement. (partiellement implémenté)

MÉTHODES

new
C'est le constructeur pour un objet pubsub. Il ne prend aucun argument supplémentaire.
delete_node($con, $uri, $cb) $con est la connexion déjà établie, $uri est le nom du nœud à créer $cb est la fonction de rappel
Essaye de supprimer un nœud.
create_node ($con, $uri, $cb) $con est la connexion déjà établie, $uri est le nom du nœud à créer $cb est la fonction de rappel
Essaye de créer un nœud.
subscribe_node($con, $uri, $cb) $con est la connexion déjà établie, $uri est le nom du nœud à créer $cb est la fonction de rappel
Essaye de récupérer des éléments.
unsubscribe_node($con, $uri, $bc)> $con est la connexion déjà établie, $uri est le nom du nœud à créer $cb est la fonction de rappel
Essaye de se désabonner d'un nœud.
publish_item($con, $uri, $create_cb, $cb) $con est la connexion déjà établie, $uri est le nom du nœud à créer $create_cb est la fonction de rappel $cb est la fonction de rappel
Essaye de publier un élément.
retrive_items($con, $uri, $cb) $con est la connexion déjà établie, $uri est le nom du nœud à créer $cb est la fonction de rappel
Essaye de récupérer des éléments.
retrive_item($con, $uri, $id, $cb) $con est la connexion déjà établie, $uri est le nom du nœud à créer $id est l'identifiant de l'entrée à récupérer $cb est la fonction de rappel
Essaye de récupérer un élément.
