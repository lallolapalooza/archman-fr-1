NOM

AnyEvent::XMPP::Extendable - Classe de base extensible

DESCRIPTION

Cette classe fournit un mécanisme pour ajouter des extensions. Veuillez noter que la classe qui hérite de celle-ci doit également hériter de AnyEvent::XMPP::Event !

Veuillez consulter AnyEvent::XMPP::Ext pour plus d'informations sur ce mécanisme.

add_extension ($ext)
Cette méthode étend l'objet courant avec un objet AnyEvent::XMPP::Ext. $ext doit être une instance de AnyEvent::XMPP::Ext.

Fondamentalement, "add_extension" rend l'extension un récepteur d'événements pour tous les événements que l'objet étendu reçoit.

remove_extension ($ext)
Cette méthode supprime l'extension $ext.
