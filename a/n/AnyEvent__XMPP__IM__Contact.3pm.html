NOM

AnyEvent::XMPP::IM::Contact - Contact de liste de contacts de messagerie instantanée

SYNOPSIS

my $con = AnyEvent::XMPP::IM::Connection->new (...);
...
my $ro  = $con->roster;
if (my $c = $ro->get_contact ('test@example.com')) {
   $c->make_message ()->add_body ("Hello there!")->send;
}

DESCRIPTION

Ce module représente une classe pour les objets contact qui peuplent une liste de contacts (AnyEvent::XMPP::IM::Roster).

Il existe deux types de « contacts » qui sont gérés par cette classe. Le premier sont les contacts qui sont sur la liste de contacts de l'utilisateur, et le second sont les contacts qui sont pas sur la liste de contacts de l'utilisateur.

Pour savoir si c'est un contact qui est réellement disponible en tant qu'élément de la liste de contacts de l'utilisateur, vous devriez consulter la méthode "is_on_roster" (voir ci-dessous).

Un autre type spécial de contact est le contact qui représente nous-mêmes et qui est principalement utilisé pour garder une trace de nos propres présences et ressources. Mais notez que même si la méthode "is_me" renvoie vrai, la méthode "is_on_roster" peut aussi renvoir une valeur vraie, dans le cas où nous avons un élément de liste de contacts de nous-mêmes sur la liste (ce qui peut arriver dans de rares cas :).

Vous ne pouvez obtenir une instance de cette classe qu'en appelant la fonction "get_contact" sur un objet liste de contacts.

MÉTHODES

send_update ($cb, %upd)
Cette méthode met à jour un contact. Si la requête est terminée, elle appellera $cb. S'il en résulte une erreur, le premier argument de ce rappel sera un objet AnyEvent::XMPP::Error::IQ.

Le hash %upd doit avoir l'une des clés suivantes et définit quelles parties du contact mettre à jour :

name => $name
Met à jour le nom du contact. $name = '' efface le contact.
add_group => $groups
Ajoute le contact aux groupes dans la référence de tableau $groups.
remove_group => $groups
Retire le contact des groupes dans la référence de tableau $groups.
groups => $groups
Ceci définit les groupes du contact. $groups doit être une référence de tableau des groupes.
send_subscribe ()
Cette méthode envoie une demande d'abonnement à ce contact.
send_subscribed ()
Cette méthode accepte la demande d'abonnement d'un contact.
send_unsubscribe ()
Cette méthode envoie une demande de désabonnement à ce contact.
send_unsubscribed ()
Cette méthode envoie une demande de désabonnement à ce contact qui désabonne notre propre présence de la sienne (il ne recevra plus aucune présence de notre part).
update ($item)
Cette méthode attend un AnyEvent::XMPP::Node dans $item qui doit être un élément de liste de contacts reçu du serveur. La méthode mettra à jour le contact en conséquence et se retournera elle-même.
update_presence ($presence)
Cette méthode met à jour la présence des contacts sur la liste de contacts. $presence doit être un objet AnyEvent::XMPP::Node et doit être un paquet de présence.
get_presence ($jid)
Cette méthode renvoie une présence de ce contact si elle est disponible. La valeur de retour est une instance de AnyEvent::XMPP::IM::Presence ou undef si aucune telle présence n'existe.
get_presences
Renvoie toutes les présences de ce contact sous la forme d'objets AnyEvent::XMPP::IM::Presence.
get_priority_presence
Renvoie la présence avec la priorité la plus élevée.
groups
Renvoie la liste des groupes (chaînes de caractères) auxquels ce contact appartient.
jid
Renvoie le JID nu (bare) de ce contact.
name
Renvoie le (pseudo)nom de ce contact.
is_on_roster ()
Renvoie 1 si c'est un contact qui est officiellement sur la liste de contacts et pas seulement un contact pour lequel nous avons reçu des informations de présence.
is_me
Renvoie une valeur vraie lorsque ce contact représente nous-mêmes et n'est utilisé que pour recevoir les présences de nos propres ressources.
subscription
Renvoie l'état d'abonnement de ce contact, qui peut être l'un des suivants : 
'none', 'to', 'from', 'both'

Si le contact n'est plus sur la liste de contacts, cette méthode renvoie :

'remove'
ask
Renvoie 'subscribe' si nous avons demandé l'abonnement à ce contact.
subscription_pending
Renvoie vrai si ce contact a un abonnement en attente. Cela signifie : le contact doit confirmer l'abonnement.
nickname
Renvoie le pseudo de ce contact (ou, si aucun n'est défini dans la liste de contacts, elle renvoie la partie nœud du JID)
make_message (%args)
Cette méthode renvoie un objet AnyEvent::XMPP::IM::Message avec le champ to défini sur le JID de ce contact.

%args sont des arguments supplémentaires pour le constructeur de message.
