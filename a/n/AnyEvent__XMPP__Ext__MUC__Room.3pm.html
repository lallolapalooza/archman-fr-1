AnyEvent::XMPP::Ext::MUC::Room(3) Documentation Perl contribuée par les utilisateurs AnyEvent::XMPP::Ext::MUC::Room(3)

NOM

AnyEvent::XMPP::Ext::MUC::Room - Classe Room

RÉSUMÉ

DESCRIPTION

Ce module représente un gestionnaire de salle pour un MUC.

MÉTHODES

new (%args)
get_user ($nick)
Cette méthode retourne l'utilisateur avec le $nick dans la salle.
get_me
Cette méthode retourne l'objet AnyEvent::XMPP::Ext::MUC::User de vous-même dans la salle. Elle retournera undef si nous ne sommes plus dans la salle.
get_user_jid ($jid)
Cette méthode vérifie si un utilisateur avec le JID $jid existe dans la salle. Cela signifie que la partie nœud et domaine du JID correspondent au nœud et domaine de la salle, et que la partie ressource du JID correspond à un pseudonyme joint.
get_users
Cette méthode retourne la liste des occupants sous forme d'objets AnyEvent::XMPP::Ext::MUC::User.
make_instant ($cb)
Si vous venez de créer une salle, vous pouvez créer une salle instantanée avec cette méthode au lieu de passer par la configuration de la salle pour une salle réservée.

Si vous voulez créer une salle réservée à la place, n'oubliez pas de désactiver l'argument "create_instant" de la "join_room" méthode de AnyEvent::XMPP::Ext::MUC !

Voir aussi la "request_configuration" méthode ci-dessous pour la configuration de la salle réservée.

$cb est le rappel qui sera appelé lorsque la création de la salle instantanée sera terminée. Si la création est réussie, le premier argument sera cet objet salle ($self), si elle échoue, le premier argument sera undef et le second sera un objet AnyEvent::XMPP::Error::IQ.

request_configuration ($cb)
Cette méthode demande la configuration de la salle. Lorsque le formulaire de configuration ou une erreur arrive $cb sera appelé. Le premier argument du rappel sera un AnyEvent::XMPP::Ext::DataForm avec le formulaire de configuration de la salle ou undef en cas d'erreur. Le second argument sera un objet d'erreur AnyEvent::XMPP::Error::MUC si une erreur s'est produite ou undef si aucune erreur ne s'est produite.

Si vous avez créé un formulaire de réponse, vous pouvez l'envoyer via la "send_configuration" méthode ci-dessous.

Voici un exemple :

$room->request_configuration (sub {
   my ($form, $err) = @_;
   $form or return;
   my $af = AnyEvent::XMPP::Ext::DataForm->new;
   $af->make_answer_form ($form);
   $af->set_field_value ('muc#roomconfig_maxusers', 20);
   $af->clear_empty_fields;
   $roomhdl->send_configuration ($af, sub {
      # ...
   });
});
"send_configuration ($answer_form, $cb)"
Cette méthode envoie le formulaire de réponse à une demande de configuration à la salle. $answer_form doit être un objet AnyEvent::XMPP::Ext::DataForm contenant le formulaire de réponse avec la configuration modifiée.

Le premier argument de $cb sera une valeur vraie si le changement de configuration a réussi. Le second argument de $cb sera un "AnyEvent::XMPP::Error::IQ" objet si le changement de configuration n'a pas réussi.

make_message (%args)
Cette méthode construit un AnyEvent::XMPP::Ext::MUC::Message avec une connexion à cette salle.

%args sont des arguments supplémentaires pour le constructeur de AnyEvent::XMPP::Ext::MUC::Message. L'argument par défaut "to" pour le message est la salle et le "type" sera 'groupchat'.

send_part ($msg, $cb, $timeout)
Cela vous permet de quitter la salle, $msg est un message de départ facultatif et peut être undef si aucun message personnalisé ne doit être généré.

$cb est appelé lorsque nous avons quitté la salle avec succès ou après $timeout secondes. La valeur par défaut pour $timeout est 60.

Le premier argument de l'appel de $cb sera undef si nous avons quitté la salle avec succès, ou une valeur vraie si le délai est dépassé. Même si le délai est dépassé, nous nous considérons comme ayant quitté la salle (et un événement 'leave' est généré).

users
Retourne une liste d'objets AnyEvent::XMPP::Ext::MUC::User qui sont dans cette salle.
jid
Retourne le JID nu de cette salle.
nick_jid
Retourne le JID complet de vous-même dans la salle.
is_connected
Retourne vrai si cette salle est toujours connectée (mais peut-être pas encore jointe).
connection
Si la salle est toujours jointe, cette méthode retournera la connexion sur laquelle la salle est connectée.
is_joined
Retourne vrai si cette salle est toujours jointe (et connectée).
change_nick ($newnick)
Cette méthode vous permet de changer votre pseudonyme dans cette salle.
change_subject ($newsubject)
Cette méthode change le sujet de la salle.
