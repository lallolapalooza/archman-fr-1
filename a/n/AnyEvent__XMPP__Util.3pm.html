simxml ($w, %xmlstruct
)
Cette fonction prend un XML::Writer comme premier argument ($w) et le reste sont des paires clé-valeur : 
simxml ($w,
   defns    => '<xmlnamespace>',
   node     => <node>,
   prefixes => { prefix => namespace, ...
}, );

Où node

est : 
<node> := {
             ns => '<xmlnamespace>',
             name => 'tagname',
             attrs => [ 'name', 'value', 'name2', 'value2', ... ],
             childs => [ <node>, ... ]
          }
        | {
             dns => '<xmlnamespace>',  # ceci définira cet espace de noms comme
                                       # espace de noms par défaut avant de l'utiliser.
             name => 'tagname',
             attrs => [ 'name', 'value', 'name2', 'value2', ... ],
             childs => [ <node>, ... ]
          }
        | sub { my ($w) = @_; ... } # avec $w étant un objet XML::Writer
        |
"textnode"

Notez également que si vous omettez la clé "ns" pour les nœuds, il y a un repli sur l'espace de noms de l'élément parent ou sur le dernier espace de noms par défaut. Cela facilite l'écriture de choses

to_xmpp_time ($sec, $min, $hour, $tz, $secfrac
)
Cette fonction transforme une heure au format de date et heure XMPP. Les significations et les plages de valeurs de $sec, ..., $hour sont expliquées dans la documentation Perl (perldoc) de la fonction intégrée "localtime".

$tz doit être soit "UTC", soit de la forme "[+-]hh:mm", il peut être indéfini et n'apparaîtra alors pas dans la chaîne de

temps.

$secfrac est facultatif et peut être la fraction de

seconde.

Voir au

ssi XE
P-0082.

from_xmpp_datetime
($string)
Cette fonction transforme le $string qui est soit une heure soit une date et heure au format XMPP. Si la chaîne n'était pas dans le bon format, une liste vide est retournée. Sinon, ceci est retourné : 
my ($sec, $min, $hour, $mday, $mon, $year, $tz, $secfrac)
   = from_xmpp_datetime ($string)
;

Pour les plages de valeurs et la sémantique de $sec, ..., $srcfrac veuillez consulter la documentation pour "to_xmpp_dateti

me".

$tz et $secfrac peuvent être

indéfinis.

Si $tz est indéfinie, le fuseau horaire est à considérer comme

UTC.

Si $string contenait seulement une heure $mday, $mon et $year seront

indéfinis.
