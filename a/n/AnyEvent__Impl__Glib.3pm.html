NOM

AnyEvent::Impl::Glib - Adaptateur AnyEvent pour Glib

SYNTAXE

use AnyEvent;
use Glib;

# ce module est chargé automatiquement au besoin

DESCRIPTION

Ce module fournit un support transparent pour AnyEvent. Vous n'avez rien à faire pour que Glib fonctionne avec AnyEvent, à part charger Glib avant de créer le premier watcher AnyEvent.

Glib est probablement la boucle d'événements la plus inefficace qui ait jamais vu le jour : Glib scanne non seulement tous ses watchers (vraiment, TOUS, qu'ils soient liés à l'I/O, à des timers ou autres) lors de chaque itération de boucle, mais le fait aussi plusieurs fois et reconstruit la liste de sondage pour le noyau à chaque fois, dynamiquement même. Heureusement, les versions plus récentes de libglib n'appellent pas malloc/free à chaque invocation de watcher.

Glib impose également certains comportements non documentés, par exemple, vous ne pouvez pas toujours supprimer des watchers enfants actifs, et les conditions dans lesquelles il est valide de le faire ne sont pas documentées. Bien sûr, si vous vous trompez, vous obtenez des messages "GLib-CRITICAL". Cela rend extrêmement difficile l'écriture de programmes glib "corrects", car vous devez étudier le code source pour y parvenir, et espérer que les futures versions ne modifient pas les internes.

AnyEvent implémente les contournements nécessaires, avec un léger coût en performance.

Du côté positif, et le plus important, quand cela fonctionne, Glib fonctionne généralement correctement, pas de problème de ce côté.

Si vous créez de nombreux watchers (plus de deux, par exemple), vous pourriez envisager l'un des modules Glib::EV, EV::Glib ou Glib::Event qui mappent Glib à d'autres boucles d'événements plus efficaces.

Ce module utilise le contexte d'événements Glib par défaut pour tous ses watchers.
