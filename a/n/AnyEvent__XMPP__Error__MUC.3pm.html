AnyEvent::XMPP::Error::MUC(3) Documentation Perl fournie par l'utilisateur AnyEvent::XMPP::Error::MUC(3)

NOM

AnyEvent::XMPP::Error::MUC - Erreur MUC

Sous-classe de AnyEvent::XMPP::Error

MÉTHODES

type
Cette méthode renvoie soit :
join_timeout
Si la jointure de la salle a pris trop de temps.
no_config_form
Si la salle à partir de laquelle nous avons demandé la configuration n'a pas fourni de formulaire de données.
subject_change_forbidden
Si le changement de sujet d'une salle n'est pas autorisé.
message_error
S'il s'agit d'une erreur de message non identifiée.

Si nous avons reçu une erreur de présence, la méthode "presence_error" renvoie un objet AnyEvent::XMPP::Error::Presence avec plus de détails. Cependant, cette classe essaie de fournir un mappage pour vous (le développeur) afin de faciliter la tâche de déterminer quelle erreur signifie quoi. Pour rendre l'identification des erreurs avec XEP-0045 plus claire, j'ai inclus les codes d'erreur et les noms de conditions.

Voici les types les plus descriptifs :

password_required
Entrer dans une salle Informer l'utilisateur qu'un mot de passe est requis.

(Condition : not-authorized, Code : 401)

banned
Entrer dans une salle Informer l'utilisateur qu'il est banni de la salle.

(Condition : forbidden, Code : 403)

room_locked
Entrer dans une salle Informer l'utilisateur que la salle n'existe pas et que quelqu'un est en train de la créer.

(Condition : item-not-found, Code : 404)

room_not_creatable
Entrer dans une salle Informer l'utilisateur que la création de salle est restreinte.

(Condition : not-allowed, Code : 405)

use_reserved_nick
Entrer dans une salle Informer l'utilisateur que le pseudo réservé doit être utilisé.

(Condition : not-acceptable, Code : 406)

not_on_memberlist
Entrer dans une salle Informer l'utilisateur qu'il ne figure pas sur la liste des membres.

(Condition : registration-required, Code : 407)

nickname_in_use
Entrer dans une salle Informer l'utilisateur que le pseudo souhaité pour la salle est déjà utilisé ou enregistré par un autre utilisateur.

(Condition : conflict, Code : 409)

room_full
Entrer dans une salle Informer l'utilisateur que le nombre maximum d'utilisateurs a été atteint.

(Condition : service-unavailable, Code : 503)

La condition et le code sont également disponibles via l'objet AnyEvent::XMPP::Error::Presence renvoyé par "presence_error", voir ci-dessous.

text
Cette méthode renvoie un texte lisible par l'homme s'il est disponible.
presence_error
Renvoie un objet AnyEvent::XMPP::Error::Presence si cette erreur provient d'une telle erreur et non d'une erreur interne.
message_error
Renvoie un objet AnyEvent::XMPP::Error::Message si cette erreur provient d'une telle erreur et non d'une erreur interne.
