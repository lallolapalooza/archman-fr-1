INVENTAIR

E

Ansible stocke les hôtes sur lesquels il peut potentiellement opérer dans un inventaire. Il peut s'agir d'un fichier YAML, d'un fichier de type ini, d'un script, d'un répertoire, d'une liste, etc. Pour des options supplémentaires, consultez la documentation sur https://docs.

ansible
.com/.

ENVIRONNEMEN

T

Les variables d'environnement suivantes peuvent être

spécifiées. ansible(1) — Ansible — Arch Linux

ENVIRONMENT

ANSIBLE_INVENTORY -- Surcharge les sources d'inventaire par défaut d'ansible

ANSIBLE_LIBRARY -- Surcharge le chemin de la bibliothèque de modules d'ansible par défaut

ANSIBLE_CONFIG -- Spécifie l'emplacement de surcharge pour le fichier de configuration d'ansible

Beaucoup d'autres sont disponibles pour la plupart des options dans ansible.cfg

Pour une liste complète, consultez https://docs.ansible.com/. ou utilisez la commande ansible-config.

FILES

/etc/ansible/hosts -- Fichier d'inventaire par défaut

/etc/ansible/ansible.cfg -- Fichier de configuration, utilisé s'il est présent

~/.ansible.cfg -- Fichier de configuration utilisateur, surcharge la configuration par défaut s'il est présent

./ansible.cfg -- Fichier de configuration local (dans le répertoire de travail actuel) supposé être 'spécifique au projet' et surcharge le reste s'il est présent.

Comme mentionné ci-dessus, la variable d'environnement ANSIBLE_CONFIG remplacera toutes les autres.
