NOM

AnyEvent::Impl::Perl - Adaptateur AnyEvent pour la boucle AnyEvent pure Perl

SYNTAXE

use AnyEvent;
use AnyEvent::Loop;
# ce module est chargé automatiquement si nécessaire

DESCRIPTION

Ce module fournit un support transparent pour AnyEvent au cas où aucune autre boucle d'événements ne pourrait être trouvée ou chargée.

Si vous souhaitez utiliser ce module au lieu de charger automatiquement une autre boucle d'événements, vous pouvez simplement charger AnyEvent::Loop avant de créer le premier watcher.

Naturellement, il supporte toutes les fonctionnalités d'AnyEvent.

Voir AnyEvent::Loop pour plus de détails sur les caractéristiques de performance.
