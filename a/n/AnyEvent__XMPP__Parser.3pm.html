NOM

AnyEvent::XMPP::Parser - Analyseur de flux XML (aide pour AnyEvent::XMPP)

SYNOPSIS

use AnyEvent::XMPP::Parser;
...

DESCRIPTION

Ceci est une classe d'aide pour l'analyseur XML XMPP, qui m'aide à gérer le XML XMPP.

Voir aussi AnyEvent::XMPP::Writer pour une discussion des problèmes avec le XML dans XMPP.

MÉTHODES

new
Ceci crée une nouvelle instance de AnyEvent::XMPP::Parser et appelle "init".
set_stanza_cb ($cb)
Définit la fonction de rappel pour les 'strophes XML'.

$cb doit être une référence de code. Le premier argument de la fonction de rappel sera cette instance de AnyEvent::XMPP::Parser et le second sera la racine des strophes, un objet AnyEvent::XMPP::Node.

Si le second argument est indéfini, cela signifie que la fin du flux a été atteinte.

set_error_cb ($cb)
Ceci définit la fonction de rappel d'erreur qui sera appelée lorsque l'analyseur rencontre une erreur de syntaxe. Le premier argument est l'exception et le second sont les données qui ont causé l'erreur.
set_stream_cb ($cb)
Cette méthode définit la fonction de rappel pour la balise de flux. Elle est appelée lorsque la balise <stream> du serveur a été rencontrée. Le premier argument de la fonction de rappel est le nœud AnyEvent::XMPP::Node de la balise d'ouverture du flux.
init
Ces méthodes initialisent (ou réinitialisent) l'analyseur.
cleanup
Ces méthodes suppriment tous les gestionnaires. Utilisez-les pour éviter les références circulaires.
nseq ($namespace, $tagname, $cmptag)
Cette méthode vérifie si le $cmptag correspond au $tagname dans le $namespace.

$cmptag doit provenir de XML::Parser::Expat car il a une magie attachée qui stocke l'espace de noms.

feed ($data)
Cette méthode alimente un bloc de données non analysées dans l'analyseur.
