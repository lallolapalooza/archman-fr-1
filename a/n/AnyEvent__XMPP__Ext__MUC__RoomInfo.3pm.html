NOM

AnyEvent::XMPP::Ext::MUC::RoomInfo - Informations sur la salle

SYNOPIS

DESCRIPTION

Ce module représente les informations de salle pour un MUC.

MÉTHODES

new (%args)
disco_info
Cette méthode retourne l'objet de découverte d'informations AnyEvent::XMPP::Ext::Disco::Info pour la requête disco à partir de laquelle ces informations de salle ont été obtenues.
as_debug_string
Retourne les informations de salle MUC sous forme de chaîne de caractères pour le débogage.
