NOM

AnyDBM_File - fournir un cadre pour plusieurs DBM

NDBM_File, DB_File, GDBM_File, SDBM_File, ODBM_File - diverses implémentations DBM

SYNOPIS

use AnyDBM_File;

DESCRIPTION

Ce module est une "classe de base purement virtuelle" - il n'a rien en propre. Il est simplement là pour hériter de l'un des différents paquets DBM. Il préfère ndbm pour des raisons de compatibilité avec Perl 4, puis Berkeley DB (voir DB_File), GDBM, SDBM (qui est toujours présent - il est fourni avec Perl), et enfin ODBM. De cette façon, les anciens programmes qui utilisaient NDBM via dbmopen() peuvent toujours le faire, mais les nouveaux programmes peuvent réordonner @ISA:

BEGIN { @AnyDBM_File::ISA = qw(DB_File GDBM_File NDBM_File) }
use AnyDBM_File;

Avoir plusieurs implémentations DBM rend trivial la copie de formats de base de données :

use Fcntl; use NDBM_File; use DB_File;
tie %newhash,  'DB_File', $new_filename, O_CREAT|O_RDWR;
tie %oldhash,  'NDBM_File', $old_filename, 1, 0;
%newhash = %oldhash;
