NOM

antspotlight - écran de veille fourmi projecteur

SYNTAXE

antspotlight [--display hôte:écran.numéro] [--window] [--root] [--window-id numéro][--install] [--visual visuel] [--delay microsecondes] [--fps]

DESCRIPTION

Le code antspotlight affiche une seule fourmi projetant une capture d'écran.

OPTIONS

antspotlight accepte les options suivantes :

--window
Dessiner sur une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs valides sont le nom d'une classe visuelle, ou le numéro d'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--fps
Afficher la fréquence d'images actuelle, la charge CPU et le nombre de polygones.
--delay microsecondes
Délai par image.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de la fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1) xscreensaver-settings(1), xscreensaver-getimage(6)
