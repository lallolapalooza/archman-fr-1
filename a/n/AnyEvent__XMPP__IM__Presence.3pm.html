NOM

AnyEvent::XMPP::IM::Presence - Présence XMPP

SYNTAXE

DESCRIPTION

Ce module représente une présence XMPP. Il stocke le JID complet du contact, la valeur du champ show, la valeur du statut et la priorité.

AnyEvent::XMPP::IM::Presence est dérivé de AnyEvent::XMPP::IM::Delayed, utilisez l'interface décrite ci-dessous pour déterminer si cette présence était retardée.

MÉTHODES

jid
Retourne le JID complet de cette présence.
priorité
Retourne la priorité de cette présence.
tous_statuts_lang
Retourne toutes les balises linguistiques des descriptions de statut disponibles. Voir aussi statut.
show
Retourne la valeur du champ show de cette présence, qui est l'une des valeurs suivantes : 
'away', 'chat', 'dnd', 'xa'

ou la chaîne vide si la présence est 'available'.

statut ([$lang])
Retourne la description de la présence. $lang est optionnel et doit être l'une des balises retournées par "tous_statuts_lang".
créer_message (%args)
Retourne un objet AnyEvent::XMPP::IM::Message avec le champ to défini sur le JID complet de cette présence.

%args sont des arguments supplémentaires pour le constructeur du message.
