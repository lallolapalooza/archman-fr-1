NOM

AnyEvent::XMPP::IM::Roster - Liste de contacts de messagerie instantanée pour XMPP

SYNOPSIS

my $con = AnyEvent::XMPP::IM::Connection->new (...);
...
my $ro  = $con->roster;
if (my $c = $ro->get_contact ('test@example.com')) {
   $c->make_message ()->add_body ("Bonjour !")->send;
}

DESCRIPTION

Ce module représente une classe pour les objets roster qui contiennent des informations de contact.

Il gère la liste de contacts d'un JID connecté par une AnyEvent::XMPP::IM::Connection. Il gère également les informations de présence reçues.

Vous obtenez la liste de contacts en appelant la méthode "roster" sur un objet AnyEvent::XMPP::IM::Connection. Il n'y a pas d'autre moyen.

MÉTHODES

is_retrieved
Retourne vrai si cette liste de contacts a été récupérée du serveur ou faux si cette liste de contacts n'a pas encore été récupérée.
new_contact ($jid, $name, $groups, $cb)
Cette méthode envoie une requête de création d'élément de liste de contacts au serveur. $jid est le JID du contact. $name est le surnom du contact, qui peut être undef. $groups doit être une référence de tableau contenant les groupes dans lesquels ce contact doit se trouver.

La fonction de rappel dans $cb sera appelée lorsque la création sera terminée. Le premier argument sera l'objet "AnyEvent::XMPP::IM::Contact" s'il n'y a pas eu d'erreur. Le second argument sera un objet AnyEvent::XMPP::Error::IQ si la requête a entraîné une erreur.

Veuillez noter que le contact que vous recevez dans ce rappel pourrait ne pas encore être sur la liste de contacts ("is_on_roster" retourne toujours une valeur fausse), si le serveur a envoyé la mise à jour de la liste de contacts après le résultat iq de la définition de la liste de contacts, ne vous fiez donc pas au fait que le contact soit sur la liste de contacts.

delete_contact ($jid, $cb)
Cette méthode enverra une requête au serveur pour supprimer ce contact de la liste de contacts. Cela entraînera l'annulation de tous les abonnements.

$cb sera appelé lorsque la requête sera terminée. Le premier argument du rappel pourrait être un objet AnyEvent::XMPP::Error::IQ si la requête a entraîné une erreur.

get_contact ($jid)
Retourne le contact de la liste de contacts avec le JID $jid. (Si $jid n'est pas nu, la partie ressource sera supprimée avant la recherche)

NOTE : Cette méthode retourne également les contacts pour lesquels nous n'avons que la présence. Pour être sûr que le contact est sur la liste de contacts de l'utilisateur, vous devez appeler la méthode "is_on_roster" sur le contact.

La valeur de retour est une instance de AnyEvent::XMPP::IM::Contact.

get_contacts
Retourne les contacts qui sont sur cette liste de contacts sous forme d'objets AnyEvent::XMPP::IM::Contact.

NOTE : Cette méthode ne retourne que les contacts qui ont un élément de liste de contacts. Si vous n'avez pas encore récupéré la liste de contacts, les informations de présence sont toujours stockées mais vous devez obtenir les contacts sans élément de liste de contacts avec la méthode "get_contacts_off_roster". Voir ci-dessous.

get_contacts_off_roster
Retourne les contacts qui ne sont pas sur la liste de contacts mais pour lesquels nous avons reçu une présence. La valeur de retour est une liste d'objets AnyEvent::XMPP::IM::Contact.

Voir également la documentation de la méthode "get_contacts" de AnyEvent::XMPP::IM::Roster ci-dessus.

get_own_contact
Cette méthode retourne un objet AnyEvent::XMPP::IM::Contact qui nous représente. Il sera utilisé pour suivre nos propres présences.
debug_dump
Ceci affiche la liste de contacts et tous ses contacts et leurs présences.
