DESCRIPTIO

N

Antiword est une application qui affiche le texte et les images des documents Microsoft Word.
Un fichier nommé - représente un document Word lu depuis l'entrée standard.
Seuls les documents créés par MS

Word version 2 et version 6 ou u
ltérieures sont pris en charge.

FICHIER

S
Fichiers de correspondance comme 8859-1.
txt

Antiword recherche ses fichiers de correspondance dans trois répertoires, dans l'ordre indiqué :
(1) Le répertoire spécifié par $ANTIWORDHOME
(2) Le répertoire spécifié par $HOME/.antiword
(3) Le répertoire /usr/share/antiw
ord
Le fichier
fontnames

Antiword cherchera son fichier fontname dans les mêmes répertoires que ceux utilisés pour les fichiers de correspondance.
Le fichier fontnames contient la table de traduction des noms de polices utilisés par MS Word vers les noms de polices utilisés par
PostScript.
REMARQUE
:

érence entre un fichier qui n'exi

e peut pas être ouvert en lecture.

ENVIRONNEMEN

T

Antiword utilise la variable d'environnement ``ANTIWORDHOME'' comme premier répertoire où chercher ses fichiers. Antiword utilise la variable d'environnement ``HOME'' pour trouver le répertoire personnel de l'utilisateur. En mode texte, il utilise la variable ``COLUMNS'' pour définir la largeur de la sortie (sauf si elle est remplacée par l'option -w)

.

Antiword utilise les variables d'environnement ``LC_ALL'', ``LC_CTYPE''

et ``LANG'' (dans cet ordre) pour obtenir la locale actuelle et utilise ces
informations pour sélectionner le fichier de correspondance par défaut.
