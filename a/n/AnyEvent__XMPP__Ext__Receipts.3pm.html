AnyEvent::XMPP::Ext::Receipts(3) Documentation Perl fournie par l'utilisateur AnyEvent::XMPP::Ext::Receipts(3)

NOM

AnyEvent::XMPP::Ext::Receipts - reçus de messages XEP-0184

SYNOPSIS

use AnyEvent::XMPP::Ext::Disco;
use AnyEvent::XMPP::Ext::Receipts;
my $disco = AnyEvent::XMPP::Ext::Disco->new();
$xmpp->add_extension($disco);
my $receipts = AnyEvent::XMPP::Ext::Receipts->new(disco => $disco);
$xmpp->add_extension($receipts);
$disco->enable_feature($receipts->disco_feature);

DESCRIPTION

Ce module ajoute la prise en charge des reçus de messages XEP-0184.

Les reçus de messages fournissent un moyen de vérifier que les messages ont bien été reçus par le destinataire, à condition que le client du destinataire le prenne en charge.

Notez que vous devez envoyer des messages avec accusés de réception à des Jabber IDs complets (par exemple, jabber@example.com/android3948128), et non à des Jabber IDs nus (par exemple, jabber@example.com).

MÉTHODES

new (%args)
Crée un nouveau gestionnaire de reçus.

Les clés suivantes peuvent être spécifiées :

disco
Un objet "AnyEvent::XMPP::Ext::Disco" afin de pouvoir déterminer si le destinataire prend en charge les reçus de messages (via la découverte de services).

Ceci est requis.

debug
Si vous passez une valeur qui s'évalue à vrai, des messages de débogage seront affichés sur STDOUT.
auto_resend
Durée en secondes après laquelle les messages seront renvoyés si aucun reçu n'a été reçu. Bien sûr, les messages ne seront renvoyés que si le destinataire est connu pour prendre en charge les reçus de messages.

La valeur par défaut est 30 (secondes).

Définissez à 0 pour désactiver le renvoi automatique.

Voici un exemple avec toutes les clés définies :

my $receipts = AnyEvent::XMPP::Ext::Receipts->new(
    disco => $disco,
    auto_resend => 30,
    debug => 1,
);
