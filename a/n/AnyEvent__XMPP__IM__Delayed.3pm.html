NOM

AnyEvent::XMPP::IM::Delayed - Un stanza "XML" retardé

SYNTAXE

DESCRIPTION

Ce module gère les champs retardés des stanzas et est une superclasse de AnyEvent::XMPP::IM::Message et AnyEvent::XMPP::IM::Presence.

MÉTHODES

new
Le constructeur ne prend aucun argument et crée simplement un nouvel objet de cette classe.
xml_node ()
Retourne l'objet AnyEvent::XMPP::Node pour cette erreur de flux.
fetch_delay_from_node ($node)
$node doit être un AnyEvent::XMPP::Node. Cette méthode essaiera de récupérer les informations de retard à partir de $node. Elle recherchera dans les listes de nœuds enfants les éléments de retard et y définira ses valeurs.
delay_from
Cette méthode retourne soit la source d'origine d'un stanza potentiellement retardé. C'est le JID de l'entité d'origine qui a envoyé le stanza.

Cette méthode retourne undef si ce stanza n'était pas retardé.

Et cette méthode retourne undef si ce stanza n'avait pas de détails sur qui a envoyé le message en premier lieu.

Pour savoir si ce stanza était retardé, utilisez la méthode "delay_stamp".

delay_stamp
Cette méthode retourne le horodatage au format XMPP qui peut être passé à la fonction "from_xmpp_datetime" documentée dans AnyEvent::XMPP::Util.

(Veuillez noter qu'il peut s'agir d'un horodatage nouveau style XEP-0087 ou d'un horodatage hérité de style ancien)

Si le stanza n'était pas retardé, cette méthode retourne undef.

delay_reason
Cette méthode peut retourner une chaîne de caractères lisible par l'homme contenant la raison pour laquelle le stanza a été retardé.

Sera undef si le stanza ne contenait aucun retard.

is_delayed
Si cette méthode retourne une valeur vraie, alors ce stanza était retardé. Sinon, elle retourne undef.
