DESCRIPTIO

N

Ce module gère les chats multi-utilisateurs et fournit de nouveaux événements pour capter les messages de chat multi-utilisateurs. Il intercepte les messages de la connexion afin qu'ils n'interfèrent pas avec vos autres rappels sur la

connexion.

Cette extension nécessite l'exten

sion AnyEvent::XMPP::Ext::Disco
pour la découverte de services.

Cette méthode envoie une découverte d'informations vers $jid, via la connexion $con. $cb est appelé lorsque les informations arrivent ou avec une erreur après le délai d'attente IQ habituel.

join_room ($con, $jid, $nick, %args
)
Cette méthode rejoint une salle.

$con devrait être l'objet AnyEvent::XMPP::IM::Connection qui sera utilisé pour envoyer les stanzas nécessaires. $jid devrait être le JID nu de la salle. $nick devrait être votre surnom souhaité dans la

salle.

Lorsque vous entrez avec succès dans la salle, un événement "enter" est émis. Dans le cas où vous avez créé la salle et qu'elle est verrouillée, un événement "locked" est émis. Veuillez consulter la section "EVENTS" ci-dessous pour plus de détails sur la manière de gérer les salles "locked". (Vous n'aurez pas à vous soucier des salles verrouillées si vous n'avez pas désactivé le drapeau "create_instant" dans %args

Si une erreur s'est produite et que nous n'avons pas pu rejoindre la salle, les deux premiers arguments sont undef et le troisième est un objet AnyEvent::XMPP::Error::MUC signalant

l'erreur.

ÉVÉNEMENT

S

Voici les événements émis par cette extension MUC

:

$room est l'objet AnyEvent::XMPP::Ext::MUC::Room auquel l'événement

appartient.
message => $room, $msg,
$is_echo
Cet événement est émis lorsqu'un message a été reçu de la salle. $msg est un objet AnyEvent::XMPP::Ext::MUC::Message et $is_echo est vrai si le message est un écho.

REMARQUE : Veuillez noter que certaines conférences envoient des messages déjà avant que vous n'ayez terminé de rejoindre une salle. Cela signifie que vous pourriez déjà recevoir un événement "message" pour une salle pour laquelle vous n'avez pas encore reçu l'événement "enter". Cela signifie que des méthodes comme "get_me" pourraient re

nvoyer
undef.
subject_change => $room, $msg,
$is_echo
Cet événement est émis lorsqu'un utilisateur change le sujet de la salle. $msg est un objet AnyEvent::XMPP::Ext::MUC::Message et $is_echo est vrai si le message est un écho.

Le sujet de la salle est le sujet de ce $m

sg
.
subject_change_error => $room,
$error
Si vous n'étiez pas autorisé à changer le sujet ou si une autre erreur s'est produite, vous recevrez cet événement. $error est un objet AnyEvent::XMPP::Error::
MUC.
error => $room,
$error
Cet événement est émis lorsqu'une erreur s'est produite. $error est un objet AnyEvent::XMPP::Error::
MUC.
join_error => $room,
$error
Cet événement est émis lorsqu'une erreur s'est produite lors de la jonction à une salle. $error est un objet AnyEvent::XMPP::Error::
MUC.
locked =>
$room
Cet événement est émis lorsque vous avez désactivé le drapeau 'create_instant' lors de l'appel à "join_room". Cela signifie que vous venez de créer une nouvelle salle, qui est verrouillée. Vous devez la configurer avant qu'elle ne soit déverrouillée et que d'autres puissent y entrer.

Veuillez consulter les méthodes "make_instant", "request_configuration" et "send_configuration" de AnyEvent::XMPP::Ext::MUC::Room pour plus d'informations sur la manière de configurer une

salle.

REMARQUE : Vous ne recevrez pas un autre événement lorsque vous aurez terminé de configurer la salle, vous voudrez donc peut-être appeler ceci sur l'objet "AnyEvent::XMPP::Ext::MUC" lorsque vous aurez terminé de configurer la salle avec

succès : 
$muc->event (enter => $room, $room->get_me)
;

Cela pourrait être utile si vous souhaitez placer des éléments génériques dans vos gestionnaires d'événements "enter"

.

REMARQUE 2 : Si vous n'avez pas désactivé le drapeau "create_instant" de "join_room", vous n'aurez pas à vous soucier d'un événement "locked", car tout sera géré en interne pour vous et vous recevrez un événement "enter" si la salle est fin

alement
configurée.
enter => $room,
$user
Cet événement est émis lorsque nous avons rejoint la salle avec succès. $user est un objet AnyEvent::XMPP::Ext::MUC::User qui est le descripteur d'utilisateur pour
nous-mêmes.
join => $room,
$user
Cet événement est émis lorsqu'un nouvel utilisateur rejoint la salle. $user est l'objet AnyEvent::XMPP::Ext::MUC::User de cet
utilisateur.
nick_change => $room, $user, $oldnick,
$newnick
Cet événement est émis lorsqu'un utilisateur a changé de pseudonyme. $user est l'objet AnyEvent::XMPP::Ext::MUC::User de cet utilisateur. $oldnick est l'ancien pseudonyme et $newnick est le nouveau
pseudonyme.
presence => $room,
$user
Cet événement est émis lorsqu'un utilisateur change son statut de présence (par exemple affiliation ou rôle, ou statut d'absent). $user est l'objet AnyEvent::XMPP::Ext::MUC::User de cet
utilisateur.
part => $room,
$user
Cet événement est émis lorsqu'un utilisateur quitte le canal. $user est le AnyEvent::XMPP::Ext::MUC::User de cet utilisateur, mais veuillez noter que vous ne devriez plus envoyer de messages à cet
utilisateur.
leave => $room,
$user
Cet événement est émis lorsque nous quittons la salle. $user est votre descript
eur AnyEven
t::XMPP::Ext
::MUC::User.
