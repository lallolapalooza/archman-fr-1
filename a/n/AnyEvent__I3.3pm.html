NOM

AnyEvent::I3 - communiquer avec le gestionnaire de fenêtres i3

VERSION

Version 0.19

RÉSUMÉ

Ce module se connecte au gestionnaire de fenêtres i3 en utilisant l'interface IPC basée sur les sockets UNIX qu'il fournit (si activée dans le fichier de configuration). Vous pouvez ensuite vous abonner à des événements ou envoyer des messages et recevoir leurs réponses.

use AnyEvent::I3 qw(:all);
my $i3 = i3();
$i3->connect->recv or die "Error connecting";
say "Connected to i3";
my $workspaces = $i3->message(TYPE_GET_WORKSPACES)->recv;
say "Currently, you use " . @{$workspaces} . " workspaces";

...ou, en utilisant les méthodes de sucre :

use AnyEvent::I3;
my $workspaces = i3->get_workspaces->recv;
say "Currently, you use " . @{$workspaces} . " workspaces";

Un exemple quelque peu plus élaboré qui affiche l'arbre de disposition d'i3 à chaque événement d'espace de travail :

use Data::Dumper;
use AnyEvent;
use AnyEvent::I3;
my $i3 = i3();
$i3->connect->recv or die "Error connecting to i3";
$i3->subscribe({
    workspace => sub {
        $i3->get_tree->cb(sub {
            my ($tree) = @_;
            say "tree: " . Dumper($tree);
        });
    }
})->recv->{success} or die "Error subscribing to events";
AE::cv->recv

EXPORT

$i3 = i3([ $path ]);

Crée un nouvel objet "AnyEvent::I3" et le retourne.

"path" est un chemin optionnel du socket UNIX auquel se connecter. Il est fortement déconseillé de le spécifier, sauf si vous êtes absolument certain d'en avoir besoin. "AnyEvent::I3" le déterminera automatiquement en interrogeant l'instance i3 en cours d'exécution sur le DISPLAY actuel, ce qui est presque toujours ce que vous voulez.

SOUS-PROGRAMMES/MÉTHODES

$i3 = AnyEvent::I3->new([ $path ])

Crée un nouvel objet "AnyEvent::I3" et le retourne.

"path" est un chemin optionnel du socket UNIX auquel se connecter. Il est fortement déconseillé de le spécifier, sauf si vous êtes absolument certain d'en avoir besoin. "AnyEvent::I3" le déterminera automatiquement en interrogeant l'instance i3 en cours d'exécution sur le DISPLAY actuel, ce qui est presque toujours ce que vous voulez.

$i3->connect

Établit la connexion à i3. Retourne un "AnyEvent::CondVar" qui sera déclenché avec un booléen (vrai si la connexion a été établie) dès que la connexion a été établie.

if ($i3->connect->recv) {
    say "Connected to i3";
}

$i3->subscribe(\%callbacks)

S'abonne aux types d'événements donnés. Cette fonction attend une référence de hachage dont la clé est le nom de l'événement et la valeur est un rappel.

my %callbacks = (
    workspace => sub { say "Workspaces changed" }
);
if ($i3->subscribe(\%callbacks)->recv->{success}) {
    say "Successfully subscribed";
}

Le rappel spécial nommé "_error" est appelé lorsque la connexion à i3 est interrompue (probablement à cause d'un plantage, d'une sortie ou d'un redémarrage d'i3). Vous pouvez l'utiliser pour afficher un message approprié et quitter proprement, ou pour tenter de vous reconnecter.

my %callbacks = (
    _error => sub {
        my ($msg) = @_;
        say "I am sorry. I am so sorry: $msg";
        exit 1;
    }
);
$i3->subscribe(\%callbacks)->recv;

$i3->message($type, $content)

Envoie un message du "type" spécifié à i3, contenant éventuellement la structure de données "content" (ou "content", encodé en utf8, si "content" est un scalaire), si spécifié.

my $reply = $i3->message(TYPE_RUN_COMMAND, "reload")->recv;
if ($reply->{success}) {
    say "Configuration successfully reloaded";
}

MÉTHODES DE SUCRE

Ces méthodes visent à rendre vos scripts aussi beaux que possible. Toutes établissent automatiquement une connexion bloquante à i3 (si elle n'existe pas déjà).

get_workspaces

Récupère les espaces de travail actuels depuis i3.

my $ws = i3->get_workspaces->recv;
say Dumper($ws);

get_outputs

Récupère les sorties actuelles depuis i3.

my $outs = i3->get_outputs->recv;
say Dumper($outs);

get_tree

Récupère l'arbre de disposition depuis i3 (>= v4.0).

my $tree = i3->get_tree->recv;
say Dumper($tree);

get_marks

Récupère toutes les marques d'identification des fenêtres depuis i3 (>= v4.1).

my $marks = i3->get_marks->recv;
say Dumper($marks);

get_bar_config

Récupère la configuration de la barre pour l'identifiant de barre spécifique depuis i3 (>= v4.1).

my $config = i3->get_bar_config($id)->recv;
say Dumper($config);

get_version

Récupère la version d'i3 via IPC, avec un repli qui analyse la sortie de i3 --version (pour i3 < v4.3).

my $version = i3->get_version()->recv;
say "major: " . $version->{major} . ", minor = " . $version->{minor};

get_config

Récupère la dernière configuration brute lue depuis i3. Nécessite i3 >= 4.14

send_tick

Envoie un événement tick. Nécessite i3 >= 4.15

sync

Envoie un événement sync i3. Nécessite i3 >= 4.16

command($content)

Fait exécuter la commande donnée par i3

my $reply = i3->command("reload")->recv;
die "command failed" unless $reply->{success};
