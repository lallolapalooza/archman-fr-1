ANTIMICROX(1) Commandes utilisateur ANTIMICROX(1)

NOM

AntiMicroX - mapper des touches clavier et des contrôles de souris sur une manette

SYNTAXE

antimicrox [OPTION] [PROFIL]

DESCRIPTION

AntiMicroX est un programme graphique utilisé pour mapper les boutons de manette au clavier, à la souris, à des scripts et à des macros. Cependant, vous pouvez utiliser ce programme pour contrôler n'importe quelle application de bureau avec une manette.

--tray
lancer le programme uniquement dans la zone système
--no-tray
lancer le programme avec le menu de la zone système désactivé
-h, --help
afficher cette aide et quitter
-v, --version
afficher les informations de version et quitter
--profile <emplacement>
utiliser le profil spécifié comme défaut pour les contrôleurs sélectionnés. Par défaut, tous les contrôleurs.
--profile-controller <valeur>
appliquer le fichier de configuration à un contrôleur spécifique. <valeur> peut être un index, un nom ou un GUID de contrôleur.
--hidden
lancer le programme sans la fenêtre principale
--unload [<valeur>]
décharger le(s) profil(s) actuellement activé(s). La valeur peut être un index, un nom ou un GUID de contrôleur.
--startSet <nombre> [<valeur>]
démarrer les joysticks sur un ensemble spécifique. La valeur peut être un index, un nom ou un GUID de contrôleur.
--next
avancer les options de chargement des profils.
--log-level {debug,info,warn}
activer la journalisation. Défaut : warn
-l, --list
imprimer les informations sur les joysticks détectés par SDL.
--map <valeur>
ouvrir la fenêtre de mappage du contrôleur de jeu du contrôleur sélectionné. La valeur peut être un index ou un GUID du contrôleur.
--eventgen {xtest,uinput}
choisir entre l'utilisation du support XTest et du support uinput pour la génération d'événements. Défaut : xtest.
