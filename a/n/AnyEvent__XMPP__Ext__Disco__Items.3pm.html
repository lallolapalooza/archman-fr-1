NOM

AnyEvent::XMPP::Ext::Disco::Items - Éléments de découverte de services

SYNOPIS

DESCRIPTION

Cette classe représente le résultat d'une requête d'éléments disco envoyée par un gestionnaire "AnyEvent::XMPP::Ext::Disco".

MÉTHODES

xml_node ()
Retourne l'objet AnyEvent::XMPP::Node de la requête IQ.
jid ()
Retourne le JID auquel ces éléments appartiennent.
node ()
Retourne le nœud auquel ces éléments appartiennent (peut être indéfini).
items ()
Retourne une liste de références de hachage contenant les clés suivantes : 
jid, name, node et xml_node

"jid" contient le JID de l'élément. "name" contient le nom de l'élément et peut être indéfini. "node" contient l'ID du nœud de l'élément et peut être indéfini. "xml_node" contient l'objet AnyEvent::XMPP::Node de l'élément pour des analyses ultérieures.

debug_dump ()
Affiche ces éléments sur la sortie standard pour le débogage.
