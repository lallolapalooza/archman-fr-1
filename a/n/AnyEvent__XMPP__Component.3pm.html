NOM

AnyEvent::XMPP::Component - Flux "XML" qui implémente le XEP-0114

SYNOPSIS

use AnyEvent::XMPP::Component;
my $con = AnyEvent::XMPP::Component->new (
             domain => 'chat.jabber.org'
             host   => 'jabber.org',
             port   => 5347,
             secret => 'motdepassepasassezsecurisepourleshackers'
          );
$con->reg_cb (session_ready => sub { ... });
$con->connect;

DESCRIPTION

Ce module représente une connexion XMPP à un serveur qui s'authentifie en tant que composant.

Ce module est une sous-classe de "AnyEvent::XMPP::Connection" et hérite de toutes ses méthodes. Par exemple, "reg_cb" et les routines d'envoi de strophes.

Pour les événements supplémentaires qui peuvent être enregistrés, regardez ci-dessous dans la section ÉVÉNEMENTS.

Veuillez noter que pour les composants, plusieurs fonctionnalités de AnyEvent::XMPP::Connection pourraient n'avoir aucun effet ou pas l'effet désiré. Fondamentalement, vous devriez utiliser AnyEvent::XMPP::Component en tant que composant et gérer uniquement les événements qui traitent des données entrantes. Et n'utiliser que les fonctions qui envoient des strophes.

L'événement "stream_pre_authentication" et la méthode "authenticate" de AnyEvent::XMPP::Connection n'ont aucun effet, car ils gèrent l'authentification SASL ou iq-auth habituelle. Les composants "Jabber" ont un mécanisme d'authentification complètement différent.

Notez également que le support de certains XEP dans AnyEvent::XMPP::Ext est juste pensé pour une utilisation côté client. Si vous manquez de fonctionnalités, n'hésitez pas à demander à l'auteur ou à lui envoyer un patch ! (Voir AnyEvent::XMPP pour les informations de contact).

MÉTHODES

new (%args)
C'est le constructeur. Il prend les mêmes arguments que le constructeur de AnyEvent::XMPP::Connection ainsi que quelques autres :

NOTE : Veuillez noter que certains arguments que AnyEvent::XMPP::Connection prend habituellement n'ont aucun effet lors de l'utilisation de cette classe. (Ce seraient par exemple les arguments 'username', 'password', 'resource' et 'jid'.)

secret => $secret
$secret est le secret qui sera utilisé pour l'authentification auprès du serveur.

ÉVÉNEMENTS

Ces événements supplémentaires peuvent être enregistrés avec "reg_cb" :

NOTE : L'événement "stream_pre_authentication" ne doit *pas* être géré et doit simplement être ignoré. N'y attachez pas de callbacks !

session_ready
Cet événement indique que le composant s'est connecté avec succès et peut maintenant être utilisé pour transmettre des strophes.
