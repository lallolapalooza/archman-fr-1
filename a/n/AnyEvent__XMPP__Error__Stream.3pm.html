NOM

AnyEvent::XMPP::Error::Stream - Erreurs de flux XML

Sous-classe de AnyEvent::XMPP::Error

MÉTHODES

xml_node ()
Retourne l'objet AnyEvent::XMPP::Node pour cette erreur de flux.
name ()
Retourne le nom de l'erreur. Cela peut être undef, l'une des chaînes de caractères suivantes ou une autre chaîne découverte par heuristique (car certains serveurs envoient des erreurs qui ne sont pas dans la RFC).

internal-server-error
invalid-from
invalid-id
invalid-namespace
invalid-xml
not-authorized
policy-violation
remote-connection-failed
resource-constraint
restricted-xml
see-other-host
system-shutdown
undefined-condition
unsupported-stanza-type
unsupported-version
xml-not-well-formed
text ()
La partie erreur lisible par l'homme. Peut être undef si aucune n'a été reçue.
