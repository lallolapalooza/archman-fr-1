NOM

AnyEvent::Impl::Event - Adaptateur AnyEvent pour Event

SYNOPSIS

use AnyEvent;
use Event;

# ce module est chargé automatiquement au besoin

DESCRIPTION

Ce module fournit un support transparent pour AnyEvent. Vous n'avez rien à faire pour que Event fonctionne avec AnyEvent, sauf charger Event avant de créer le premier watcher AnyEvent.

Le module event est raisonnablement efficace et fonctionne généralement correctement, même avec de nombreux watchers, sauf que sa gestion des signaux est intrinsèquement sujette à des courses et nécessite le contournement de l'éveil fréquent.
