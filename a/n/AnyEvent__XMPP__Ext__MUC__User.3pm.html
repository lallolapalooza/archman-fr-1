NOM

AnyEvent::XMPP::Ext::MUC::User - Classe utilisateur

SYNOPIS

DESCRIPTION

Ce module représente un identifiant d'utilisateur (occupant) pour un MUC. Cette classe dérive de AnyEvent::XMPP::Presence car un utilisateur a également une présence dans une salle.

MÉTHODES

new (%args)
nick
Le pseudonyme de l'utilisateur du MUC.
affiliation
L'affiliation de l'utilisateur.
role
Le rôle de l'utilisateur.
room
La salle AnyEvent::XMPP::Ext::MUD::Room dans laquelle cet utilisateur se trouve.
in_room_jid
Le JID local de la salle de l'utilisateur.
real_jid
Le JID réel de l'utilisateur, peut être indéfini si c'est une salle anonyme.
make_message (%args)
Retourne un objet AnyEvent::XMPP::Ext::MUC::Message avec le champ to défini sur le JID complet de cette présence.

%args sont des arguments supplémentaires pour le constructeur du message.

did_create_room
Cette méthode retourne vrai si l'utilisateur a créé une salle.
