--capture

DESCRIPTION Androiddump est un outil extcap qui fournit des interfaces pour capturer à partir d'un appareil Android. Il n'y a que deux prérequis : 1. Vous devez avoir le SDK Android et l'ajouter à votre variable d'environnement PATH. Le PATH doit contenir le répertoire avec des outils comme "adb" et "android". Le SDK Android pour

différentes plateformes
est disponible sur :

https://developer.android.com/sdk/index.

html#Other

2. Vous devez avoir la permission de capturer à partir de l'appareil Android. Certains appareils Android nécessitent une authentification à

l'écran.
Interfaces prises en charge : 1. Logcat Main (binaire [<=Jelly Bean] ou
texte)
2. Logcat System (binaire [<=Jelly Bean] ou
texte)

3. Logcat Events (binaire [<=Jelly Bean] ou

texte)
4. Logcat Radio (binaire [<=Jelly Bean] ou
texte)
5. Logcat Crash (texte ; depuis
Lollipop)
6. Bluetooth Hcidump [<=Jelly
Bean]
7. Bluetooth Bluedroid External Parser
[Kitkat]
8. Bluetooth BtsnoopNet [>
=Lollipop]
9. WiFi/Ethernet tcpdump [nécessite tcpdump sur le
téléphone]
Veuillez noter qu'Androiddump fonctionnera aussi pour FirefoxOS ou d'autres systèmes d'exploitation basés sur
Android.
