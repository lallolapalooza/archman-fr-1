AnyEvent::XMPP::Ext::RegisterForm(3) Documentation Perl fournie par l'utilisateur AnyEvent::XMPP::Ext::RegisterForm(3)

NOM

AnyEvent::XMPP::Ext::RegisterForm - Gestionnaire pour l'enregistrement en bande

SYNTAXE

my $con = AnyEvent::XMPP::Connection->new (...);
...
$con->do_in_band_register (sub {
   my ($form, $error) = @_;
   if ($error) { print "ERREUR: ".$error->string."\n" }
   else {
      if ($form->type eq 'simple') {
         if ($form->has_field ('username') && $form->has_field ('password')) {
            $form->set_field (
               username => 'test',
               password => 'qwerty',
            );
            $form->submit (sub {
               my ($form, $error) = @_;
               if ($error) { print "ERREUR DE SOUMISSION: ".$error->string."\n" }
               else {
                  print "Enregistré avec succès en tant que ".$form->field ('username')."\n"
               }
            });
         } else {
            print "Impossible de remplir le formulaire : " . $form->field ('instructions') ."\n";
         }
      } elsif ($form->type eq 'data_form' {
         my $dform = $form->data_form;
         ... remplir le formulaire $dform (de type AnyEvent::XMPP::DataForm) ...
         $form->submit_data_form ($dform, sub {
            my ($form, $error) = @_;
            if ($error) { print "ERREUR DE SOUMISSION DE FORMULAIRE DE DONNÉES: ".$error->string."\n" }
            else {
               print "Enregistré avec succès en tant que ".$form->field ('username')."\n"
            }
         })
      }
   }
});

DESCRIPTION

Ce module représente un formulaire d'enregistrement en bande qui peut être rempli et soumis.

Vous ne pouvez obtenir une instance de cette classe qu'en la demandant à une connexion AnyEvent::XMPP::Connection en appelant la méthode "request_inband_register_form".

new (%args)
Généralement, le constructeur ne prend aucun argument, sauf si vous souhaitez construire un formulaire de réponse, auquel cas vous appelez le constructeur comme suit :

Si vous avez des champs de formulaire hérités sous forme de hash ref dans $filled_legacy_form :

AnyEvent::XMPP::Ext::RegisterForm (
   legacy_form => $filled_legacy_form,
   answered => 1
);

Si vous avez un formulaire de données dans $answer_data_form :

AnyEvent::XMPP::Ext::RegisterForm (
   legacy_form => $answer_data_form,
   answered => 1
);
try_fillout_registration ($username, $password)
Cette méthode tente de remplir un formulaire reçu de l'autre extrémité. Elle saisit le nom d'utilisateur et le mot de passe et renvoie un nouvel objet AnyEvent::XMPP::Ext::RegisterForm qui est le formulaire de réponse.

NOTE : Cette fonction est juste une heuristique pour remplir un formulaire pour l'enregistrement automatique, mais elle peut échouer si les formulaires sont plus complexes et ont des champs requis que nous ne connaissons pas.

L'enregistrement sans interaction utilisateur n'est théoriquement pas possible car les formulaires peuvent différer d'un serveur à l'autre et nécessiter des informations différentes. Veuillez également consulter XEP-0077.

Notez que si le formulaire est plus compliqué, cette méthode ne fonctionnera pas et il n'est pas garanti que l'enregistrement réussisse.

Appeler cette méthode sur un formulaire de réponse (où "is_answer_form" renvoie vrai) aura un résultat indéfini.

is_answer_form
Cette méthode renverra une valeur vraie si ce formulaire a été renvoyé par, par exemple, "try_fillout_registration" ou représente généralement un formulaire de réponse.
is_already_registered
Cette méthode renvoie vrai si le formulaire reçu contenait simplement les données d'enregistrement actuelles. Essentiellement, cette méthode renvoie vrai lorsque vous êtes déjà enregistré auprès du serveur.
get_legacy_form_fields
Cette méthode renvoie un hash dont les clés sont les champs du formulaire hérité tels que décrits dans le schéma XML de XEP-0077.

Si le formulaire ne contenait que des nœuds, les clés auront une valeur indéfinie.

Si le formulaire contenait également des informations d'enregistrement, dans le cas où "is_already_registered" renvoie une valeur vraie, les valeurs contiendront les chaînes de caractères pour les champs.

get_data_form
Cette méthode renvoie le DataForm AnyEvent::XMPP::Ext::DataForm qui accompagnait la réponse d'enregistrement. Si aucun formulaire de données n'a été fourni par le serveur, cette méthode renvoie undef.
get_oob
Cette méthode renvoie un hash similaire à celui renvoyé par la fonction "url_from_node" dans AnyEvent::XMPP::Ext::OOB. Il contient les données hors bande pour ce formulaire d'enregistrement.
answer_form_to_simxml
Cette méthode renvoie une liste de nœuds "simxml".
