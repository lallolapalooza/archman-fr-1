animate(1) Manuel des commandes générales animate(1)

NOM

animate - anime une image ou une séquence d'images sur n'importe quel serveur X.

SYNTAXE

magick animate [options] fichier-entree

APERÇU

Le programme animate fait partie de la suite d'outils ImageMagick(1). Utilisez-le pour animer une image ou une séquence d'images sur n'importe quel serveur X.

Pour plus d'informations sur la commande animate, pointez votre navigateur vers file:///usr/share/doc/ImageMagick-7/www/animate.html ou https://imagemagick.org/script/animate.php.

DESCRIPTION

Paramètres d'image :
-alpha on, activate, off, deactivate, set, opaque, copy
transparent, extract, background, ou shape
-authenticate valeur déchiffre l'image avec ce mot de passe
-backdrop affiche l'image centrée sur un arrière-plan
-colormap type Partagé ou Privé
-colorspace type espace colorimétrique alternatif de l'image
-decipher filename convertit les pixels chiffrés en pixels clairs
-define format:option
définit une ou plusieurs options de format d'image
-delay centisecondes affiche l'image suivante après une pause
-density géométrie densité horizontale et verticale de l'image
-depth valeur profondeur de l'image
-display serveur affiche l'image sur ce serveur X
-dispose méthode méthode d'élimination de calque
-dither méthode applique la diffusion d'erreur à l'image
-filter type utilise ce filtre lors du redimensionnement d'une image
-format "chaîne" caractéristiques formatées de l'image de sortie
-gamma valeur niveau de correction gamma
-geometry géométrie taille et position préférées de la fenêtre d'image
-gravity type placement de l'arrière-plan horizontal et vertical
-identify identifie le format et les caractéristiques de l'image
-immutable l'image affichée ne peut pas être modifiée
-interlace type type de schéma d'entrelacement d'image
-interpolate méthode méthode d'interpolation des couleurs des pixels
-limit type valeur limite de ressource du cache de pixels
-loop itérations boucle les images puis quitte
-matte stocke le canal alpha si l'image en a un
-map type affiche l'image en utilisant cette Colormap standard
-monitor surveille la progression
-pause secondes pour faire une pause avant de réanimer
-page géométrie taille et position d'une toile d'image (paramètre)
-quantize colorspace réduit les couleurs dans cet espace colorimétrique
-quiet supprime tous les messages d'avertissement
-regard-warnings prête attention aux messages d'avertissement
-remote commande exécute une commande dans un processus d'affichage distant
-repage géométrie taille et position d'une toile d'image (opérateur)
-respect-parentheses les paramètres restent en vigueur jusqu'à la limite des parenthèses
-sampling-factor géométrie
facteur d'échantillonnage horizontal et vertical
-scenes plage plage de scènes d'images
-seed valeur initialise une nouvelle séquence de nombres pseudo-aléatoires
-set attribut valeur définit un attribut d'image
-size géométrie largeur et hauteur de l'image
-support facteur redimensionnement support : > 1.0 est flou, < 1.0 est net
-transparent-color couleur
couleur transparente
-treedepth valeur profondeur de l'arbre de couleurs
-verbose imprime des informations détaillées sur l'image
-visual type affiche l'image en utilisant ce type visuel
-virtual-pixel méthode
méthode d'accès aux pixels virtuels
-window id affiche l'image en arrière-plan de cette fenêtre

Opérateurs d'image :
-channel masque définit le masque de canal de l'image
-colors valeur nombre préféré de couleurs dans l'image
-crop géométrie taille et position préférées de l'image recadrée
-extent géométrie définit la taille de l'image
-extract géométrie extrait une zone de l'image
-monochrome transforme l'image en noir et blanc
-resample géométrie modifie la résolution d'une image
-resize géométrie redimensionne l'image
-rotate degrés applique une rotation Paeth à l'image
-strip supprime tous les profils et commentaires de l'image
-thumbnail géométrie crée une miniature de l'image
-trim rogne les bords de l'image

Opérateurs de séquence d'images :
-coalesce fusionne une séquence d'images
-flatten aplatit une séquence d'images

Options diverses :
-debug events affiche des informations de débogage abondantes
-help imprime les options du programme
-log format format des informations de débogage
-list type imprime une liste d'arguments d'option pris en charge
-version imprime les informations de version

En plus de ceux listés ci-dessus, vous pouvez spécifier ces ressources X standard en tant qu'options de ligne de commande : -background, -bordercolor, -borderwidth, -font, -foreground, -iconGeometry, -iconic, -name, -mattecolor, -shared-memory, ou -title.

Par défaut, le format de l'image `fichier' est déterminé par son numéro magique. Pour spécifier un format d'image particulier, faites précéder le nom de fichier d'un nom de format d'image et de deux-points (par exemple, ps:image) ou spécifiez le type d'image en tant que suffixe du nom de fichier (par exemple, image.ps). Spécifiez `fichier' comme '-' pour l'entrée ou la sortie standard.
