NAME

ansible-vault

gérer les secrets chiffrés par Ansible

SYNOPSIS

ansible-vault [options] [subcommand]

DESCRIPTION

La commande ansible-vault vous permet de stocker des informations sensibles comme les mots de passe et les clés dans des fichiers chiffrés.

Les fichiers chiffrés sont compatibles avec Ansible et peuvent être utilisés comme des variables normales.

Utilisation de ansible-vault :

Pour créer un nouveau fichier chiffré :

ansible-vault create my_secrets.yml

Pour éditer un fichier chiffré existant :

ansible-vault edit my_secrets.yml

Pour recharger les fichiers chiffrés après modification :

ansible-vault rekey my_secrets.yml

Pour effacer un fichier chiffré :

ansible-vault remove my_secrets.yml

Pour afficher le contenu d'un fichier chiffré :

ansible-vault view my_secrets.yml

Pour masquer des variables dans un fichier de configuration :

ansible-vault encrypt_string 'my password' --name 'password'

COMMON OPTIONS

-h, --help

Afficher un message d'aide et quitter.

--version

Afficher la version du programme et quitter.

-v, --verbose

Augmenter la verbosité du logging.

-q, --quiet

Réduire la verbosité du logging.

--vault-password-file ANSWER

Fichier contenant le mot de passe du vault.

--ask-vault-pass

Demander le mot de passe du vault.

ENVIRONMENT

Les variables d'environnement suivantes peuvent être spécifiées.

ANSIBLE_CONFIG -- Spécifier l'emplacement de remplacement du fichier de configuration ansible

Beaucoup d'autres sont disponibles pour la plupart des options dans ansible.cfg

Pour une liste complète, consultez https://docs.ansible.com/. ou utilisez la commande ansible-config.

FILES

/etc/ansible/ansible.cfg -- Fichier de configuration, utilisé s'il est présent

~/.ansible.cfg -- Fichier de configuration utilisateur, remplace la configuration par défaut s'il est présent

./ansible.cfg -- Fichier de configuration local (dans le répertoire de travail courant) est considéré comme 'spécifique au projet' et remplace les autres s'il est présent.

Comme mentionné ci-dessus, la variable d'environnement ANSIBLE_CONFIG remplacera toutes les autres.
