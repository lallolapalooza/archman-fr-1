NOM

AnyEvent::XMPP::TestClient - Client de test XMPP pour les tests

SYNTAXE

DESCRIPTION

Ce module est un module d'aide pour faciliter la tâche de test. Si vous voulez exécuter la suite de tests développeur, vous devez définir la variable d'environnement "NET_XMPP2_TEST" à quelque chose comme ceci :

NET_XMPP2_TEST="test_me@your_xmpp_server.tld:secret_password"

La plupart des tests essaieront de connecter deux comptes, veuillez donc choisir un serveur qui autorise deux connexions depuis la même IP.

Si vous voulez également exécuter les tests MUC (voir AnyEvent::XMPP::Ext::MUC), vous devez également configurer la variable d'environnement "NET_XMPP2_TEST_MUC" pour contenir le domaine d'un service MUC :

NET_XMPP2_TEST_MUC="conference.your_xmpp_server.tld"

Si vous constatez que certains tests échouent et que vous souhaitez en savoir plus sur le flux du protocole, vous pouvez activer la sortie de débogage du protocole en définissant "NET_XMPP2_TEST_DEBUG" à '1' :

NET_XMPP2_TEST_DEBUG=1

(NOTE : Vous ne verrez la sortie que lors de l'exécution d'un seul test)

Si l'un des tests prend plus de temps que le délai d'attente par défaut préconfiguré de 20 secondes dans votre configuration, vous pouvez définir "NET_XMPP2_TEST_TIMEOUT" :

NET_XMPP2_TEST_TIMEOUT=60  # pour un délai d'attente d'une minute

NETTOYAGE

Si les tests se sont mal passés quelque part ou si vous avez interrompu les tests, vous voudrez peut-être supprimer manuellement les comptes du serveur, puis exécuter :

perl t/z_*_unregister.t

TESTS MANUELS

Si vous voulez simplement exécuter un test unique vous-même, il suffit d'exécuter le test d'enregistrement avant de le faire :

perl t/z_00_register.t

Et ensuite, vous pourriez par exemple exécuter :

perl t/z_03_iq_auth.t
