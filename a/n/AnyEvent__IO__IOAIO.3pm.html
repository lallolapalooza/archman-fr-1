NOM

AnyEvent::IO::IOAIO - Backend AnyEvent::IO basé sur IO::AIO

SYNOPSIS

use AnyEvent::IO;

DESCRIPTION

Il s'agit du backend basé sur IO::AIO d'AnyEvent::IO (via AnyEvent::AIO). Toutes les opérations d'E/S qu'il implémente sont effectuées de manière asynchrone.
