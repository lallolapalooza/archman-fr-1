avahi-bookmarks(1) Manuel des commandes générales avahi-bookmarks(1)

NOM

avahi-bookmarks - Service Web affichant les services HTTP annoncés via mDNS/DNS-SD à l'aide du démon Avahi

SYNTAXE

avahi-bookmarks

DESCRIPTION

Un service Web pour lister les services HTTP qui sont annoncés via mDNS/DNS-SD en utilisant le démon Avahi. avahi-bookmarks ouvre un socket TCP sur le port 8080 et attend les connexions HTTP entrantes, renvoyant un site Web dynamique contenant des liens vers tous les services de type _http._tcp sur le réseau local. Pointez votre navigateur vers http://localhost:8080/ pour utiliser avahi-bookmarks.

OPTIONS

-p | --port= PORT
Spécifie un numéro de port TCP sur lequel écouter. Si omis, la valeur par défaut est 8080.
-a | --address= adresse
Spécifie une adresse IP sur laquelle écouter. Si omis, la valeur par défaut est 127.0.0.1. Spécifiez 0.0.0.0 si vous souhaitez autoriser l'accès à distance.
-H | --host-names
Crée des liens pointant vers des noms d'hôtes mDNS au lieu d'adresses IP résolues. Ceci n'est compatible avec votre navigateur que si vous utilisez un module NSS local pour résoudre les noms d'hôtes mDNS (par exemple, nss-mdns). Si -A et -H sont tous deux omis, avahi-bookmarks détecte si le support NSS est disponible localement. Cette option entre en conflit avec -A.
-A | --addresses
Crée des liens pointant vers des adresses IP numériques au lieu de noms d'hôtes mDNS. Ceci interrompra l'accès aux hôtes exécutant des serveurs virtuels. Si -A et -H sont tous deux omis, avahi-bookmarks détecte si le support NSS est disponible localement. Cette option entre en conflit avec -H.
-d | --domain=DOMAINE
Le domaine dans lequel rechercher les services.
-h | --help
Affiche l'aide.
