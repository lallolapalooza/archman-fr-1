windmc lit les définitions de messages à partir d'un fichier d'entrée (.mc) et les traduit en un ensemble de fichiers de sortie. Les fichiers de sortie peuvent être de quatre types

:
"h
"
Un fichier d'en-tête C contenant les définitions de
messages.
"r
c"
Un fichier de ressources compilable par l'outil windre
s.
"bi
n"
Un ou plusieurs fichiers binaires contenant les données de ressources pour une langue de message
spécifique.
"db
g"
Un fichier include C qui ass
ocie les identifiants de mes
sages à leur nom symbolique.

La description exacte de ces différents formats est disponible dans la documentation de

Microsoft.

Lorsque windmc convertit du format "mc" au format "bin", "rc", "h", et éventuellement "dbg", il agit comme le Compil
