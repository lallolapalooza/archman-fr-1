NOM

avahi-dnsconfd.action - Script d'action avahi-dnsconfd

SYNOPSIS

/etc/avahi/avahi-dnsconfd.action

DESCRIPTION

avahi-dnsconfd.action est le script d'action appelé chaque fois qu'un nouveau serveur DNS unicast est trouvé ou supprimé par avahi-dnsconfd. Le script par défaut fourni avec Avahi modifie /etc/resolv.conf pour refléter la configuration modifiée du serveur DNS unicast.

PARAMÈTRES

argv[1] Contient le caractère "+" si le serveur DNS est nouveau, "-" lorsqu'il doit être supprimé de la liste des serveurs DNS.
argv[2] L'adresse IP du serveur DNS.
argv[3] Le numéro d'interface réseau numérique sur lequel ce serveur DNS a été trouvé.
argv[4] Le numéro de protocole numérique sur lequel ce serveur DNS a été trouvé. (généralement 2 pour IPv4 et 10 pour IPv6)

ENVIRONNEMENT

AVAHI_INTERFACE Contient le nom textuel de l'interface correspondant à argv[3]. (par exemple, "eth0")
AVAHI_INTERFACE_DNS_SERVERS Contient une liste de tous les serveurs DNS trouvés par avahi-dnsconfd sur l'interface $AVAHI_INTERFACE, séparés par des espaces.
AVAHI_DNS_SERVERS Contient une liste de tous les serveurs DNS trouvés par avahi-dnsconfd sur toutes les interfaces, séparés par des espaces.
