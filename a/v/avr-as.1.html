--alternate
Commencer en mode macro alternatif.
--compress-debug-sections
Compresse les sections de débogage DWARF en utilisant zlib avec SHF_COMPRESSED de l'ABI ELF. Le fichier objet résultant peut ne pas être compatible avec les anciens éditeurs de liens et utilitaires de fichiers objets. Notez que si la compression rendait une section donnée plus grande, elle n'est pas compressée.
--compress-debug-sections=none
--compress-debug-sections=zlib
--compress-debug-sections=zlib-gnu
--compress-debug-sections=zlib-gabi
--compress-debug-sections=zstd
Ces options contrôlent la manière dont les sections de débogage DWARF sont compressées. --compress-debug-sections=none équivaut à --nocompress-debug-sections. --compress-debug-sections=zlib et --compress-debug-sections=zlib-gabi équivalent à --compress-debug-sections. --compress-debug-sections=zlib-gnu compresse les sections de débogage DWARF en utilisant le format obsolète zlib-gnu. Les sections de débogage sont renommées pour commencer par .zdebug. --compress-debug-sections=zstd compresse les sections de débogage DWARF en utilisant zstd. Notez que si la compression rendait une section plus grande, elle n'est alors ni compressée ni renommée.
--nocompress-debug-sections
Ne pas compresser les sections de débogage DWARF. C'est généralement la valeur par défaut pour toutes les cibles sauf x86/x86_64, mais une option de configuration peut être utilisée pour outrepasser cela.
-D
Activer le débogage dans les backends spécifiques à la cible, si pris en charge. Sinon, ignoré. Même s'il est ignoré, cette option est acceptée pour la compatibilité des scripts avec les appels à d'autres assembleurs.
--debug-prefix-map ancien=nouveau
Lors de l'assemblage de fichiers dans le répertoire ancien, enregistrez les informations de débogage les décrivant comme dans nouveau à la place.
--defsym sym=valeur
Définir le symbole sym à la valeur valeur avant d'assembler le fichier d'entrée. valeur doit être une constante entière. Comme en C, un préfixe 0x indique une valeur hexadécimale et un préfixe 0 indique une valeur octale. La valeur du symbole peut être remplacée dans un fichier source via l'utilisation d'une pseudo-instruction ".set".
--dump-config
Affiche la configuration de l'assembleur puis se termine.
--elf-stt-common=no
--elf-stt-common=yes
Ces options contrôlent si l'assembleur ELF doit générer des symboles communs avec le type "STT_COMMON". La valeur par défaut peut être contrôlée par une option de configuration --enable-elf-stt-common.
--emulation=nom
Si l'assembleur est configuré pour prendre en charge plusieurs configurations cibles différentes, alors cette option peut être utilisée pour sélectionner la forme désirée.
-f
"rapide" --- saute le prétraitement des espaces blancs et des commentaires (suppose que la source est une sortie du compilateur).
-g
--gen-debug
Générer des informations de débogage pour chaque ligne source de l'assembleur en utilisant le format de débogage préféré par la cible. Cela signifie actuellement STABS, ECOFF ou DWARF2. Lorsque le format de débogage est DWARF, une section ".debug_info" et ".debug_line" n'est émise que si le fichier d'assemblage n'en génère pas une lui-même.
--gstabs
Générer des informations de débogage stabs pour chaque ligne de l'assembleur. Cela peut aider au débogage du code assembleur, si le débogueur peut le gérer.
--gstabs+
Générer des informations de débogage stabs pour chaque ligne de l'assembleur, avec des extensions GNU que probablement seul gdb peut gérer, et qui pourraient faire planter ou refuser de lire votre programme à d'autres débogueurs. Cela peut aider au débogage du code assembleur. Actuellement, la seule extension GNU est l'emplacement du répertoire de travail actuel au moment de l'assemblage.
--gdwarf-2
Générer des informations de débogage DWARF2 pour chaque ligne de l'assembleur. Cela peut aider au débogage du code assembleur, si le débogueur peut le gérer. Notez que cette option n'est prise en charge que par certaines cibles, pas toutes.
--gdwarf-3
Cette option est identique à l'option --gdwarf-2, sauf qu'elle permet la possibilité de générer des informations de débogage supplémentaires conformément à la version 3 de la spécification DWARF. Notez que l'activation de cette option ne garantit pas la génération d'informations supplémentaires, le choix de le faire est fait sur une base par cible.
--gdwarf-4
Cette option est identique à l'option --gdwarf-2, sauf qu'elle permet la possibilité de générer des informations de débogage supplémentaires conformément à la version 4 de la spécification DWARF. Notez que l'activation de cette option ne garantit pas la génération d'informations supplémentaires, le choix de le faire est fait sur une base par cible.
--gdwarf-5
Cette option est identique à l'option --gdwarf-2, sauf qu'elle permet la possibilité de générer des informations de débogage supplémentaires conformément à la version 5 de la spécification DWARF. Notez que l'activation de cette option ne garantit pas la génération d'informations supplémentaires, le choix de le faire est fait sur une base par cible.
--gdwarf-sections
Au lieu de créer une section .debug_line, crée une série de sections .debug_line.foo où foo est le nom de la section de code correspondante. Par exemple, une section de code nommée .text.func aura ses informations de numéro de ligne naines placées dans une section nommée .debug_line.text.func. Si la section de code est simplement nommée .text, alors la section de ligne de débogage sera toujours appelée simplement .debug_line sans suffixe.
--gdwarf-cie-version=version
Contrôle quelle version des entrées d'informations communes DWARF (CIE) est produite. Lorsque ce drapeau n'est pas spécifié, la valeur par défaut est la version 1, bien que certaines cibles puissent modifier cette valeur par défaut. D'autres valeurs possibles pour version sont 3 ou 4.
--generate-missing-build-notes=yes
--generate-missing-build-notes=no
Ces options contrôlent si l'assembleur ELF doit générer des notes d'attributs GNU Build si aucune n'est présente dans les sources d'entrée. La valeur par défaut peut être contrôlée par l'option de configuration --enable-generate-build-notes.
--gsframe
--gsframe
