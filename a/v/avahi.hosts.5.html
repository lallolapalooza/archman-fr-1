avahi.hosts(5) Formats de fichier avahi.hosts(5)

NOM

avahi.hosts - fichier de noms d'hôte statiques de avahi-daemon

SYNTAXE

/etc/avahi/hosts

DESCRIPTION

/etc/avahi/hosts est un fichier qui peut être utilisé pour définir des correspondances statiques entre nom d'hôte et adresse IP pour le DNS multicast. Ceci est particulièrement utile lors de la publication de services DNS-SD au nom d'autres hôtes. Voir avahi.service(5) pour plus d'informations.

Le format du fichier est similaire à celui de /etc/hosts : sur chaque ligne, une adresse IP et le nom d'hôte correspondant. Les noms d'hôte doivent être sous forme FQDN, c'est-à-dire avec le suffixe .local ajouté.
