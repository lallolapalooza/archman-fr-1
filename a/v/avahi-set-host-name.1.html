NOM

avahi-set-host-name - Changer le nom d'hôte mDNS

SYNTAXE

avahi-set-host-name nom-hôte

DESCRIPTION

Définit le nom d'hôte mDNS d'un démon Avahi en cours d'exécution. L'effet de cette opération n'est pas persistant lors des redémarrages du démon. Cette opération est généralement privilégiée.

OPTIONS

-v | --verbose
Activer le mode verbeux.
-h | --help
Afficher l'aide.
-V | --version
Afficher les informations de version.

AUTEURS

Les développeurs Avahi <avahi (at) lists (dot) freedesktop (dot) org>; Avahi est disponible sur http://avahi.org/
