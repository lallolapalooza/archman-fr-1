NOM

avahi-autoipd.action - script d'action avahi-autoipd

SYNTAXE

/etc/avahi/avahi-autoipd.action

DESCRIPTION

avahi-autoipd.action est le script d'action appelé chaque fois qu'une adresse IP a été acquise par avahi-autoipd ou qu'il a détecté un conflit d'adresses IP. Le script doit ajouter ou supprimer l'adresse spécifiée de l'interface réseau spécifiée.

PARAMETRES

argv[1] Une chaîne d'événement : l'une des valeurs BIND, CONFLICT, UNBIND ou STOP. Si BIND est passé, une adresse IP a été acquise avec succès et le script doit l'ajouter à l'interface réseau. Si CONFLICT est passé, avahi-autopid a détecté une adresse IP sur le réseau local, le script d'action doit supprimer l'adresse IP configurée. Si UNBIND est passé, l'adresse IP doit également être supprimée de l'interface, car une adresse routable a été configurée sur l'interface par un autre programme. Si STOP est passé, avahi-autoipd est en cours d'arrêt et le script d'action doit supprimer l'adresse IP. En résumé : sur BIND, l'adresse doit être ajoutée à l'interface ; sur CONFLICT, UNBIND ou STOP, elle doit être supprimée.
argv[2] Le nom de l'interface réseau.
argv[3] Une adresse IP de la plage IPv4LL.

AUTEURS

Les développeurs d'Avahi <avahi (at) lists (dot) freedesktop (dot) org> ; Avahi est disponible sur http://avahi.org/
