NOM

avahi-dnsconfd - Démon d'exécution de la configuration DNS unicast à partir de mDNS/DNS-SD

SYNTAXE

avahi-dnsconfd [options]

avahi-dnsconfd --kill

avahi-dnsconfd --refresh

avahi-dnsconfd --check

DESCRIPTION

avahi-dnsconfd se connecte à un avahi-daemon en cours d'exécution et exécute le script /etc/avahi/avahi-dnsconfd.action pour chaque serveur DNS unicast annoncé sur le réseau local. Ceci est utile pour configurer des serveurs DNS unicast de manière similaire à DHCP avec mDNS.

OPTIONS

-D | --daemonize
Se détache après le démarrage et redirige les messages de journalisation vers syslog.
-s | --syslog
Journalise dans syslog au lieu de STDERR. Implicite avec --daemonize.
-k | --kill
Arrête un avahi-dnsconfd déjà en cours d'exécution. (équivalent à l'envoi d'un SIGTERM)
-r | --refresh
Demande à un avahi-dnsconfd déjà en cours d'exécution de rafraîchir les données du serveur DNS. (équivalent à l'envoi d'un SIGHUP)
-c | --check
Retourne 0 comme code de retour si avahi-dnsconfd est déjà en cours d'exécution.
-h | --help
Affiche l'aide
-v | --version
Affiche les informations de version

FICHIERS

/etc/avahi/avahi-dnsconfd.action : le script à exécuter lorsqu'un serveur DNS est trouvé ou supprimé.

SIGNaux

SIGINT, SIGTERM : avahi-dnsconfd s'arrêtera. Ceci est émis en passant --kill à avahi-daemon.

SIGHUP : avahi-dnsconfd rafraîchira les données du serveur DNS.
