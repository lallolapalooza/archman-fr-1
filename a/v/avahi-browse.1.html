avahi-browse(1) Manuel des commandes générales avahi-browse(1)

NOM

avahi-browse - Parcourir les services mDNS/DNS-SD à l'aide du démon Avahi

SYNTAXE

avahi-browse [options] type-de-service

avahi-browse [options] --all

avahi-browse [options] --browse-domains

avahi-browse [options] --dump-db

avahi-browse-domains [options]

DESCRIPTION

Parcourt les services réseau mDNS/DNS-SD et les domaines de parcours à l'aide du démon Avahi.

OPTIONS

Spécifiez un type de service DNS-SD (par exemple _http._tcp) à parcourir sur la ligne de commande, ou -a pour parcourir tous les types de services disponibles. Les éléments qui apparaissent sur le réseau sont précédés de "+", les éléments qui disparaissent sont précédés de "-". Si --resolve est passé, les éléments résolus sont précédés de "=".

-a | --all
Parcourt tous les types de services enregistrés sur le réseau local, pas seulement celui spécifié sur la ligne de commande.
-D | --browse-domains
Parcourt les domaines de parcours au lieu des services. avahi-browse-domains est équivalent à avahi-browse --browse-domains
-d | --domain= DOMAINE
Parcourt dans le domaine spécifié. Si omis, avahi-browse parcourra le domaine de parcours par défaut (généralement : local)
-v | --verbose
Active le mode verbeux.
-t | --terminate
Se termine après avoir affiché une liste plus ou moins complète.
-c | --cache
Se termine après avoir affiché toutes les entrées disponibles dans le cache.
-l | --ignore-local
Ignore les services locaux, n'affiche que les services distants.
-r | --resolve
Résout automatiquement les services trouvés.
-f | --no-fail
Ne pas échouer si le démon n'est pas en cours d'exécution. Au lieu de cela, attendre qu'il apparaisse. S'il se déconnecte, essayer de se reconnecter.
-p | --parsable
Rend la sortie facilement analysable pour une utilisation dans des scripts. Si activé, les champs sont séparés par des points-virgules (;), les noms de service sont échappés. Il est recommandé de combiner ceci avec --no-db-lookup.
-k | --no-db-lookup
Ne pas interroger la base de données des types de services.
-b | --dump-db
Affiche la base de données des types de services (peut être combiné avec -k)
-h | --help
Affiche l'aide.
-V | --version
Affiche les informations de version.
