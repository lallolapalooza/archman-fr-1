NOM

Avidemux — un éditeur vidéo gratuit

SYNOPIS

avidemux [options]

avidemux_gtk [options]

avidemux_cli [options] [fichiers ...]

DESCRIPTION

Avidemux est un éditeur vidéo gratuit conçu pour des tâches simples de coupage, de filtrage et d'encodage. Il prend en charge de nombreux types de fichiers, y compris AVI, MPG (VCD, SVCD), MPEG compatible DVD, MP4 et ASF, en utilisant une variété de codecs. Les tâches peuvent être automatisées à l'aide de projets, d'une file d'attente et de puissantes capacités de script.

Page d'accueil : http://avidemux.sourceforge.net/

SCRIPTS PERSONNALISÉS

Les paramètres d'encodage personnalisés peuvent être créés avec le moteur de script. Effectuez les étapes suivantes :
1. Démarrez avidemux et ouvrez n'importe quel fichier vidéo.
2. Configurez vos propres paramètres d'encodage.
3. Sauvegardez les paramètres sous forme de projet (Fichier -> Enregistrer le projet sous...) avec le suffixe ".js".
4. Quittez avidemux.
5. Ouvrez le fichier projet dans un éditeur simple et supprimez les lignes inutiles.
* Vous avez besoin de la première ligne "//AD" et de la ligne "app = new Avidemux()"
* et des paramètres d'encodage commençant par "app.video.codec(...)".
6. Sauvegardez ce fichier script avec le suffixe ".js" dans le répertoire utilisateur "~/.avidemux/custom".
7. Ce script personnalisé est maintenant disponible dans avidemux sous le menu "Personnalisé".
