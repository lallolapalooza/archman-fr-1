NOM

windres - Compilateur de fichiers de ressources Windows.

SYNTAXE

windres [--target=type] [-o fichier_sortie] [-i fichier_entree] [-l langue] [-J codepage] [-F format] [-D] [--] [fichiers...]

DESCRIPTION

windres est un compilateur pour les fichiers de ressources Windows. Il est utilisé pour compiler des fichiers de ressources (.rc) en fichiers objets (.o) qui peuvent être liés à des programmes Windows.

OPTIONS

--target=type
Spécifie la cible du compilateur. Les valeurs possibles sont pe (Portable Executable, par défaut) et pef (PE fichier). Ce drapeau est utilisé pour spécifier le format du fichier de sortie.
-o fichier_sortie
Spécifie le nom du fichier de sortie. Par défaut, la sortie est écrite sur la sortie standard.
-i fichier_entree
Spécifie le nom du fichier d'entrée. S'il n'est pas spécifié, windres lit depuis l'entrée standard.
-l langue
Spécifie la langue des ressources. La langue est spécifiée sous la forme de deux codes alphabétiques majuscules pour la langue et deux codes alphabétiques majuscules pour le pays (par exemple, ENUS pour l'anglais américain).
-J codepage
Spécifie la codepage à utiliser pour les chaînes de caractères dans le fichier de ressources. La valeur par défaut est 1252 (Europe de l'Ouest).
-F format
Spécifie le format du fichier de ressources. Les valeurs possibles sont coff (COFF, par défaut) et elf (ELF).
-D
Active le débogage du parseur. Ceci est utile pour déboguer les fichiers de ressources complexes.
--
Indique la fin des options. Tout ce qui suit sera traité comme un nom de fichier.
fichiers...
Un ou plusieurs fichiers d'entrée à traiter.
--no-use-temp-file
Utilise popen, pas un fichier temporaire, pour lire la sortie du préprocesseur. C'est le comportement par défaut.
-h
--help
Affiche un résumé de l'utilisation.
-V
--version
Affiche le numéro de version de windres.
--yydebug
Si windres est compilé avec "YYDEBUG" défini comme 1, cela activera le débogage du parseur.
@fichier
Lit les options de ligne de commande depuis le fichier. Les options lues sont insérées à la place de l'option @fichier d'origine. Si le fichier n'existe pas, ou ne peut pas être lu, alors l'option sera traitée littéralement, et ne sera pas supprimée.

Les options dans le fichier sont séparées par des espaces. Un caractère d'espacement peut être inclus dans une option en entourant toute l'option avec des guillemets simples ou doubles. N'importe quel caractère (y compris une barre oblique inversée) peut être inclus en faisant précéder le caractère à inclure par une barre oblique inversée. Le fichier peut lui-même contenir des options @fichier supplémentaires ; toutes ces options seront traitées récursivement.
