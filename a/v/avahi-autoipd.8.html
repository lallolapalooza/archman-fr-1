NOM

avahi-autoipd - démon de configuration d'adresses réseau IPv4LL

SYNTAXE

avahi-autoipd [options] interface

avahi-autoipd --kill interface

avahi-autoipd --refresh interface

avahi-autoipd --check interface

DESCRIPTION

avahi-autoipd implémente IPv4LL, "Dynamic Configuration of IPv4 Link-Local Addresses" (IETF RFC3927), un protocole pour la configuration automatique d'adresses IP de la plage 169.254.0.0/16 locale au lien sans nécessiter de serveur central. Il est principalement destiné à être utilisé dans les réseaux ad hoc qui manquent d'un serveur DHCP.

IPv4LL fait partie de la pile Zeroconf.

avahi-autoipd peut être utilisé comme un allocateur d'adresses autonome ou comme un plugin pour un client DHCP tel que le dhclient d'ISC, où il peut être utilisé comme solution de secours si aucun serveur DHCP n'est trouvé.

Pour permettre la communication entre les hôtes qui n'ont qu'une adresse IPv4LL attribuée et les hôtes qui n'ont qu'une adresse IP routable attribuée, vous pouvez ajouter les routes suivantes aux deux configurations réseau :

route add -net 169.254.0.0 netmask 255.255.0.0 dev eth0 metric 99

route add default dev eth0 metric 99

Voir http://developer.apple.com/qa/qa2004/qa1357.html pour plus d'informations.

OPTIONS

-D | --daemonize
Démoniser après le démarrage. Implique --syslog.
-k | --kill
Arrêter un avahi-autoipd déjà en cours d'exécution sur l'interface réseau spécifiée. (Équivalent à l'envoi d'un SIGTERM)
-r | --refresh
Indiquer à un avahi-autoipd déjà en cours d'exécution de réannoncer l'adresse IP acquise sur l'interface réseau spécifiée. (Équivalent à l'envoi d'un SIGHUP)
-c | --check
Retourner 0 comme code de retour si avahi-autoipd est déjà en cours d'exécution pour l'interface réseau spécifiée.
-s | --syslog
Journaliser dans syslog au lieu de STDERR. Impliqué par --daemonize.
--debug
Activer le mode verbeux.
--no-drop-root
Ne pas abandonner les privilèges root après le démarrage. Nous recommandons de ne pas utiliser cette option.
--no-chroot
Ne pas chroot(2) le démon. Cette option n'est disponible que lorsqu'elle est compilée avec le support de chroot().
-S | --start=
Essayer d'acquérir l'adresse IP spécifiée, qui doit provenir de la plage IPv4LL 169.254.0.0/16.
-w | --wait
Attendre qu'une adresse IP ait été acquise avec succès avant de se détacher. Uniquement valide en combinaison avec --daemonize.
--force-bind
Acquérir une adresse IPv4LL, même si une adresse routable a été configurée sur l'interface.
--no-proc-title
Ne pas modifier le nom du processus pendant l'exécution. Sauf si cette option est spécifiée, avahi-autoipd reflétera son état actuel et l'adresse IP dans le titre du processus.
-h | --help
Afficher l'aide.
-v | --version
Afficher les informations sur la version.

FICHIERS

/etc/avahi/avahi-autoipd.action: le script à exécuter lorsqu'une adresse IP a été acquise ou perdue.

SIGNAUX

SIGINT, SIGTERM: avahi-autoipd s'arrêtera. (Identique à --kill)

SIGHUP: avahi-autoipd réannoncera l'adresse IP acquise. (Identique à --refresh)
