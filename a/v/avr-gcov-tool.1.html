NOM

gcov-tool - outil de traitement hors-ligne des profils gcda

SYNOPSIS

gcov-tool [-v|--version] [-h|--help]

gcov-tool merge [options-de-merge] répertoire1 répertoire2
[-o|--output répertoire]
[-v|--verbose]
[-w|--weight w1,w2]

gcov-tool merge-stream [options-de-merge-stream] [fichier]
[-v|--verbose]
[-w|--weight w1,w2]

gcov-tool rewrite [options-de-rewrite] répertoire
[-n|--normalize valeur_long_long]
[-o|--output répertoire]
[-s|--scale valeur_flottante_ou_fraction_simple]
[-v|--verbose]

gcov-tool overlap [options-de-overlap] répertoire1 répertoire2
[-f|--function]
[-F|--fullname]
[-h|--hotonly]
[-o|--object]
[-t|--hot_threshold] flottant
[-v|--verbose]

DESCRIPTION

gcov-tool est un outil hors-ligne pour traiter les fichiers de profil gcda de gcc. Actuellement, gcov-tool prend en charge les fonctionnalités suivantes :

Actuellement, gcov-tool prend en charge les fonctionnalités suivantes :

  • fusionner deux ensembles de profils avec des poids.
  • lire un flux de profils avec les noms de fichiers associés et le fusionner avec un ensemble de profils avec des poids.
  • lire un ensemble de profils et réécrire le contenu du profil. On peut mettre à l'échelle ou normaliser les valeurs de comptage.

Voici des exemples de cas d'utilisation pour cet outil :

  • Collecter les profils pour différents ensembles d'entrées et utiliser cet outil pour les fusionner. On peut spécifier le poids pour prendre en compte l'importance relative de chaque entrée.
  • Collecter des profils à partir de systèmes cibles sans système de fichiers (environnements autonomes). Fusionner les profils collectés avec les profils présents sur le système hôte. On peut spécifier le poids pour prendre en compte l'importance relative de chaque entrée.
  • Réécrire le profil après avoir supprimé un sous-ensemble des fichiers gcda, tout en maintenant la cohérence de l'histogramme et du résumé.
  • Il peut également être utilisé pour déboguer ou libérer du code libgcov, car l'outil partage la majorité du code avec la bibliothèque d'exécution.

Notez que pour l'opération de fusion, ce profil généré hors-ligne peut contenir des valeurs légèrement différentes de celles du profil fusionné en ligne. Voici une liste des différences typiques :

  • différence d'histogramme : Cet outil hors-ligne recalcule l'histogramme après avoir fusionné les compteurs. L'histogramme résultant est donc précis. La fusion en ligne ne possède pas cette capacité -- l'histogramme est fusionné à partir de deux histogrammes et le résultat est une approximation.
  • différence de somme de contrôle du résumé : La somme de contrôle du résumé utilise une opération CRC32. La valeur dépend de l'ordre de la liste chaînée des objets gcov-info. Cet ordre est différent dans gcov-tool de celui de la fusion en ligne. On s'attend à avoir des sommes de contrôle de résumé différentes. Cela n'a pas vraiment d'importance car le compilateur n'utilise pas cette somme de contrôle nulle part.
  • différence des valeurs des compteurs de profil de valeur : Certaines valeurs de compteurs pour le profil de valeur dépendent de l'exécution, comme les adresses du tas. Il est normal de voir une certaine différence dans ce type de compteurs.

OPTIONS

-h
--help
Afficher l'aide sur l'utilisation de gcov-tool (sur la sortie standard) et quitter sans effectuer aucun traitement supplémentaire.
-v
--version
Afficher le numéro de version de gcov-tool (sur la sortie standard) et quitter sans effectuer aucun traitement supplémentaire.
merge
Fusionner deux répertoires de profils.
-o répertoire
--output répertoire
Définir le répertoire de profil de sortie. Le nom du répertoire de sortie par défaut est merged_profile.
-v
--verbose
Activer le mode verbeux.
-w w1,w2
--weight w1,w2
Définir les poids de fusion de répertoire1 et répertoire2, respectivement. Les poids par défaut sont 1 pour les deux.
merge-stream
Collecter les profils avec les noms de fichiers associés à partir d'un gcfn et gcda flux de données. Lire le flux à partir du fichier spécifié par fichier ou à partir de stdin. Fusionner les profils avec les profils associés dans le système de fichiers hôte. Appliquer les poids optionnels lors de la fusion des profils.

Pour la génération d'un gcfn et gcda flux de données sur le système cible, veuillez consulter les "__gcov_filename_to_gcfn()" et "__gcov_info_to_gcda()" fonctions déclarées dans "#include <gcov.h>".

-v
--verbose
Activer le mode verbeux.
-w w1,w2
--weight w1,w2
Définir les poids de fusion des profils du gcfn et gcda flux de données et des profils associés dans le système de fichiers hôte, respectivement. Les poids par défaut sont 1 pour les deux.
rewrite
Lire le répertoire de profils spécifié et le réécrire dans un nouveau répertoire.
-n valeur_long_long
--normalize <valeur_long_long>
Normaliser le profil. La valeur spécifiée est la valeur de compteur maximale dans le nouveau profil.
-o répertoire
--output répertoire
Définir le répertoire de profil de sortie. Le nom de sortie par défaut est rewrite_profile.
-s valeur_flottante_ou_fraction_simple
--scale valeur_flottante_ou_fraction_simple
Mettre à l'échelle les compteurs du profil. La valeur spécifiée peut être une valeur en virgule flottante, ou une fraction simple, comme 1, 2, 2/3 et 5/3.
-v
--verbose
Activer le mode verbeux.
overlap
Calculer le score de chevauchement entre les deux répertoires de profils spécifiés. Le score de chevauchement est calculé sur la base des profils d'arc. Il est défini comme la somme de min (p1_counter[i] / p1_sum_all, p2_counter[i] / p2_sum_all), pour tous les compteurs d'arc i, où p1_counter[i] et p2_counter[i] sont deux compteurs appariés et p1_sum_all et p2_sum_all sont la somme des valeurs de compteur dans le profil 1 et le profil 2, respectivement.
-f
--function
Afficher le score de chevauchement au niveau des fonctions.
-F
--fullname
Afficher le nom de fichier gcda complet.
-h
--hotonly
Afficher uniquement les informations pour les avr-gcov-tool(1) — Arch Linux

NAME

avr-gcov-tool — Collect and display coverage data from AVRTiny.

SYNOPSIS

avr-gcov-tool [OPTION...] [INPUT]

DESCRIPTION

The avr-gcov-tool is a tool for collecting and displaying code coverage data from AVRTiny devices.

OPTIONS

-b, --branch
Collect branch coverage data.
-c, --counter
Collect counter data.
-f, --function
Collect function coverage data.
-h, --help
Display help information and exit.
-i, --interactive
Interactive mode.
-o, --object
Print object level overlap score.
-t, --hot_threshold float
Set the threshold for hot counter value.
-v, --verbose
Set the verbose mode.
