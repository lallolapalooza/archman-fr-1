DESCRIPTIO

N

GNU nm liste les symboles des fichiers objet objfile.... Si aucun fichier objet n'est listé en argument, nm suppose le fichier a.ou

t.

Pour chaque symbole, nm affiche

:
  • La valeur du symbole, dans la base sélectionnée par les options (voir ci-dessous), ou en hexadécimal par
    • défaut.
  • Le type du symbole. Au moins les types suivants sont utilisés ; d'autres le sont aussi, selon le format du fichier objet. S'il est en minuscule, le symbole est généralement local ; s'il est en majuscule, le symbole est global (externe). Il existe cependant quelques symboles en minuscules qui sont affichés pour des symboles globaux spéciaux ("u", "v" et "w

Si le symbole est défini quelque part, les symboles communs sont traités comme des références indéfinies. Le caractère c en minuscule est utilisé lorsque le symbole se trouve dans une section spéciale pour les petits symboles

global.
"i
"
Pour les fichiers au format PE, cela indique que le symbole se trouve dans une section propre à l'implémentation des DLL.

Pour les fichiers au format ELF, cela indique que le symbole est une fonction indirecte. Il s'agit d'une extension GNU à l'ensemble standard des types de symboles ELF. Cela indique un symbole qui, lorsqu'il est référencé par une relocalisation, ne s'évalue pas à son adresse, mais doit plutôt être invoqué à l'exécution. L'exécution renverra alors la valeur à utiliser dans la

relocalisation.

Le symbole est un objet faible. Lorsqu'un symbole faible défini est lié à un symbole normalement défini, le symbole normalement défini est utilisé sans erreur. Lorsqu'un symbole faible indéfini est lié et que le symbole n'est pas défini, la valeur du symbole faible devient zéro sans erreur. Sur certains systèmes, une majuscule indique qu'une valeur par défaut a été

Lorsqu'un symbole faible défini est lié à un symbole normalement défini, le symbole normalement défini est utilisé sans erreur. Lorsqu'un symbole faible indéfini est lié et que le symbole n'est pas défini, la valeur du symbole est déterminée d'une manière propre au système sans erreur. Sur certains systèmes, une majuscule indique qu'une valeur par défaut a été
spécifiée.

OPTION

S

Les formes longues et courtes des options, montrées ici comme des alternatives, sont

équivalentes.
-

-
o
--print-file-n
ame
Faire précéder chaque symbole par le nom du fichier d'entrée (ou de l'élément d'archive) dans lequel il a été trouvé, plutôt que d'identifier le fichier d'entrée une seule fois, avant tous ses
symboles.
-
a
--debug-sy
ms
Afficher tous les symboles, même ceux réservés au débogueur ; normalement, ceux-ci ne sont pas
listés.
-
B
Identique à --format=bsd (pour la compatibilité avec le nm de
MIPS).
-
C
--demangle[=style
]
Décoder (démangler) les noms de symboles de bas niveau en noms de haut niveau. En plus de supprimer tout underscore initial ajouté par le système, cela rend les noms de fonctions C++ lisibles. Différents compilateurs ont différents styles de mangle. L'argument de style de démangle optionnel peut être utilisé pour choisir un style de démangle approprié pour votre
compilateur.
--no-demang
le
Ne pas démangler les noms de symboles de bas niveau. C'est le comportement par
défaut.
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Active ou désactive une limite sur la quantité de récursion effectuée lors du démêlage des chaînes. Comme les formats de démêlage de noms permettent un niveau de récursion infini, il est possible de créer des chaînes dont le décodage épuisera l'espace de pile disponible sur la machine hôte, provoquant une erreur mémoire. La limite tente d'éviter que cela ne se produise en restreignant la récursion à 2048 niveaux d'imbrication.

Par défaut, cette limite est activée, mais sa désactivation peut être nécessaire afin de démêler des noms réellement complexes. Notez toutefois que si la limite de récursion est désactivée, une exhaustion de la pile est possible et tout rapport de bug concernant un tel événement sera rejeté.

-D
--dynamic
Affiche les symboles dynamiques plutôt que les symboles normaux. Ceci n'est pertinent que pour les objets dynamiques, tels que certains types de bibliothèques partagées.
-f format
--format=format
Utilise le format de sortie format, qui peut être "bsd", "sysv", "posix" ou "just-symbols". Par défaut, c'est "bsd". Seul le premier caractère de format est significatif ; il peut être en majuscule ou en minuscule.
-g
--extern-only
Affiche uniquement les symboles externes.
-h
--help
Affiche un résumé des options de nm et quitte.
--ifunc-chars=CHARS
Lors de l'affichage des symboles de fonctions indirectes GNU, nm utilise par défaut le caractère "i" pour les fonctions indirectes locales et globales. L'option --ifunc-chars permet à l'utilisateur de spécifier une chaîne contenant un ou deux caractères. Le premier caractère sera utilisé pour les symboles de fonctions indirectes globales et le second caractère, s'il est présent, sera utilisé pour les symboles de fonctions indirectes locales.
j
Identique à --format=just-symbols.
-l
--line-numbers
Pour chaque symbole, utilise les informations de débogage pour essayer de trouver un nom de fichier et un numéro de ligne. Pour un symbole défini, recherche le numéro de ligne de l'adresse du symbole. Pour un symbole indéfini, recherche le numéro de ligne d'une entrée de relocalisation qui fait référence au symbole. Si des informations de numéro de ligne peuvent être trouvées, elles sont imprimées après les autres informations du symbole.
--inlines
Lorsque l'option -l est active, si l'adresse appartient à une fonction qui a été intégrée, cette option provoque l'affichage des informations source pour toutes les portées englobantes jusqu'à la première fonction non intégrée. Par exemple, si "main" intègre "callee1" qui intègre "callee2", et que l'adresse provient de "callee2", les informations source pour "callee1" et "main" seront également affichées.
-n
-v
--numeric-sort
Trie les symboles numériquement par leurs adresses, plutôt qu'alphabétiquement par leurs noms.
-p
--no-sort
Ne prend pas la peine de trier les symboles dans un ordre quelconque ; les affiche dans l'ordre où ils sont rencontrés.
-P
--portability
Utilise le format de sortie standard POSIX.2 au lieu du format par défaut. Équivalent à -f posix.
-r
--reverse-sort
Inverse l'ordre du tri (numérique ou alphabétique) ; le dernier arrive en premier.
-S
--print-size
Affiche la valeur et la taille des symboles définis pour le style de sortie "bsd". Cette option n'a aucun effet pour les formats d'objets qui n'enregistrent pas les tailles de symboles, à moins que --size-sort ne soit également utilisé, auquel cas une taille calculée est affichée.
-s
--print-armap
Lors de l'énumération des symboles des membres d'archives, inclut l'index : une table des matières (stockée dans l'archive par ar ou ranlib) indiquant quels modules contiennent des définitions pour quels noms.
-t radix
--radix=radix
Utilise radix comme base pour imprimer les valeurs des symboles. Il doit s'agir de d pour décimal, o pour octal, ou x pour hexadécimal.
-u
--undefined-only
Affiche uniquement les symboles indéfinis (ceux qui sont externes à chaque fichier objet). Par défaut, les symboles définis et indéfinis sont affichés.
-U
--defined-only
Affiche uniquement les symboles définis pour chaque fichier objet. Par défaut, les symboles définis et indéfinis sont affichés.
-V
--version
Affiche le numéro de version de nm et quitte.
-X
Cette option est ignorée pour assurer la compatibilité avec la version AIX de nm. Elle prend un paramètre qui doit être la chaîne 32_64. Le mode par défaut de nm sur AIX correspond à -X 32, qui n'est pas pris en charge par nm GNU.
--plugin name
Charge le plugin nommé name pour ajouter la prise en charge de types cibles supplémentaires. Cette option n'est disponible que si la chaîne d'outils a été compilée avec la prise en charge des plugins activée.

Si --plugin n'est pas fourni, mais que la prise en charge des plugins a été activée, alors nm parcourt les fichiers dans ${libdir}/bfd-plugins par ordre alphabétique et le premier plugin qui revendique l'objet en question est utilisé.

Veuillez noter que ce répertoire de recherche de plugins n'est *pas* celui utilisé par l'option -plugin de ld. Afin de faire utiliser à nm le plugin de l'éditeur de liens, il doit être copié dans le répertoire ${libdir}/bfd-plugins. Pour les compilations basées sur GCC, le plugin de l'éditeur de liens s'appelle liblto_plugin.so.0.0.0. Pour les compilations basées sur Clang, il s'appelle LLVMgold.so. Le plugin GCC est toujours rétrocompatible avec les versions antérieures, il suffit donc de copier le plus récent.

--size-sort
Trie les symboles par taille. Pour les objets ELF, les tailles des symboles sont lues à partir de l'ELF, pour les autres types d'objets, les tailles des symboles sont calculées comme la différence entre la valeur du symbole et la valeur du symbole avec la valeur supérieure suivante. Si le format de sortie "bsd" est utilisé, la taille du symbole est imprimée, plutôt que la valeur, et -S doit être utilisé pour que la taille et la valeur soient imprimées.

Notez que cette option ne fonctionne pas si --undefined-only a été activé car les symboles indéfinis n'ont pas de taille.

--special-syms
Affiche les symboles qui ont une signification spéciale spécifique à la cible. Ces symboles sont généralement utilisés par la cible pour un traitement spécial et ne sont pas normalement utiles lorsqu'ils sont inclus dans les listes de symboles normales. Par exemple, pour les cibles ARM, cette option ignorerait les symboles de mappage utilisés pour marquer les transitions entre le code ARM, le code THUMB et les données.
--synthetic
Inclut les symboles synthétiques dans la sortie. Ce sont des symboles spéciaux créés par l'éditeur de liens à diverses fins. Ils ne sont pas affichés par défaut car ils ne font pas partie du code source original du binaire.
--unicode=[default|invalid|locale|escape|hex|highlight]
Contrôle l'affichage des caractères multibytes encodés en UTF-8 dans les chaînes. Le comportement par défaut (--unicode=default) est de ne leur appliquer aucun traitement spécial. L'option --unicode=locale affiche la séquence dans la locale actuelle, qui peut ou non les supporter. Les options --unicode=hex et --unicode=invalid les affichent sous forme de séquences d'octets hexadécimaux entourées d'accolades ou de crochets.

L'option --unicode=escape les affiche sous forme de séquences d'échappement (\uxxxx) et l'option --unicode=highlight les affiche sous forme de séquences d'échappement mises en évidence en rouge (si le périphérique de sortie le prend en charge). La coloration est destinée à attirer l'attention sur la présence de séquences unicode là où elles pourraient ne pas être attendues.

-W
--no-weak
N'affiche pas les symboles faibles.
--with-symbol-versions
--without-symbol-versions
Active ou désactive l'affichage des informations de version des symboles. La chaîne de version est affichée comme un suffixe du nom du symbole, précédé d'un caractère @. Par exemple, foo@
VER_1. Si la version est la version par défaut à utiliser lors de la résolution des références non versionnées au symbole, elle est affichée comme suffixe précédée de deux caractères @. Par exemple foo@@VER_2. Par défaut, les informations de version des symboles sont affichées.
--target=bfdna
me
Spécifie un format de code objet autre que le format par défaut de votre
système.
@fi
le
Lit les options de la ligne de commande à partir de file. Les options lues sont insérées à la place de l'option originale @file. Si file n'existe pas ou ne peut pas être lu, l'option sera traitée littéralement et ne sera pas supprimée.

Les options dans file sont séparées par des espaces. Un caractère d'espace peut être inclus dans une option en entourant l'option entière de guillemets simples ou doubles. N'importe quel caractère (y compris une barre oblique inverse) peut être inclus en préfixant le caractère à inclure d'une barre oblique inverse. Le fichier peut lui-même contenir des options supplémentaires @file ; de telles opt
