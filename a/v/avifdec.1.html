AVIFDEC(1) Manuel des commandes générales AVIFDEC(1)

NOM

avifdec - décompresse un fichier AVIF vers un fichier image

SYNTAXE

avifdec [options] fichier_entree.avif fichier_sortie.[jpg|jpeg|png|y4m]

avifdec --info fichier_entree.avif

DESCRIPTION

avifdec décompresse un fichier AVIF vers un fichier image. Le format de sortie peut être JPEG, PNG ou YUV4MPEG2 (Y4M).

OPTIONS

-h, --help
Afficher l'aide de syntaxe.
-V, --version
Afficher le numéro de version.
-j, --jobs J
Nombre de tâches (threads de travail), ou `all` pour potentiellement utiliser autant de cœurs que possible. (Défaut : all).
-c, --codec C
Codec à utiliser.

Les valeurs possibles dépendent des codecs activés lors de la compilation (voir --help ou --version pour les codecs disponibles). Le défaut est sélectionné automatiquement parmi les codecs disponibles.

Valeurs possibles :
•
aom
•
dav1d
•
libgav1
-d, --depth D
Profondeur de sortie, 8 ou 16. (PNG uniquement ; pour y4m, la profondeur est conservée, et JPEG est toujours 8 bpc).
-q, --quality Q
Qualité de sortie en 0..100. (JPEG uniquement, défaut : 90).
--png-compress L
Niveau de compression PNG en 0..9 (PNG uniquement ; 0=aucun, 9=max). Défaut : le défaut intégré de libpng.
-u, --upsampling U
Suréchantillonnage de la chrominance (pour 420/422). L'un des choix : `automatic` (défaut), `fastest`, `best`, `nearest`, ou `bilinear`.
-r, --raw-color
Sortir les valeurs RVB brutes au lieu de multiplier par alpha lors de la sauvegarde dans des formats opaques (JPEG uniquement ; non applicable à y4m).
--index I
Lors de la décompression d'une séquence d'images ou d'une image progressive, spécifier l'index de l'image à décompresser, où la première image a l'index 0, ou `all` pour décompresser toutes les images. (Défaut : 0)
--progressive
Activer le traitement AVIF progressif. Si une image progressive est rencontrée et que --progressive est passé, avifdec utilisera --index pour choisir quelle couche décompresser (dans l'ordre progressif).
--no-strict
Désactiver le décodage strict, ce qui désactive les vérifications de validation strictes et les erreurs.
-i, --info
Décompresser toutes les images et afficher toutes les informations de l'image au lieu de les sauvegarder sur disque.
--icc NOMFICHIER
Fournir une charge utile de profil ICC (implique --ignore-icc).
--ignore-icc
Si le fichier d'entrée contient un profil ICC intégré, l'ignorer (inutile si absent).
--size-limit C
Taille maximale de l'image (en pixels totaux) qui doit être tolérée. (Défaut : 268435456).
--dimension-limit C
Dimension maximale de l'image (largeur ou hauteur) qui doit être tolérée. Régler à 0 pour ignorer. (Défaut : 32768).
--
Signaler la fin des options. Tout ce qui suit est interprété comme des noms de fichiers.

EXEMPLES

Décompresser un fichier AVIF en fichier PNG :
$ avifdec input.avif output.png
