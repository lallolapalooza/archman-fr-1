NOM

strip - supprimer les symboles et autres données des fichiers objets

SYNTAXE

strip [-F bfdname |--target=bfdname]
[-I bfdname |--input-target=bfdname]
[-O bfdname |--output-target=bfdname]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nom_symbole|--keep-symbol=nom_symbole]
[-M|--merge-notes][--no-merge-notes]
[-N nom_symbole |--strip-symbol=nom_symbole]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nom_section |--remove-section=nom_section]
[--keep-section=motif_section]
[--remove-relocations=motif_section]
[--strip-section-headers]
[-o fichier] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
fichier_objet...

DESCRIPTION

GNU strip supprime tous les symboles des fichiers objets fichier_objet. La liste des fichiers objets peut inclure des archives. Au moins un fichier objet doit être fourni.

strip modifie les fichiers nommés dans ses arguments, plutôt que d'écrire des copies modifiées sous des noms différents.

OPTIONS

-F bfdname
--target=bfdname
Traiter le fichier_objet original comme un fichier avec le format de code objet bfdname, et le réécrire dans le même format.
--help
Afficher un résumé des options de strip et quitter.
--info
Afficher une liste montrant tous les formats d'architecture et d'objet disponibles.
-I bfdname
--input-target=bfdname
Traiter le fichier_objet original comme un fichier avec le format de code objet bfdname.
-O bfdname
--output-target=bfdname
Remplacer fichier_objet par un fichier dans le format de sortie bfdname.
-R nom_section
--remove-section=nom_section
Supprimer toute section nommée nom_section du fichier de sortie, en plus de toutes les sections qui seraient autrement supprimées. Cette option peut être utilisée plusieurs fois. Notez qu'une utilisation inappropriée de cette option peut rendre le fichier de sortie inutilisable. Le caractère générique * peut être utilisé à la fin de nom_section. Si c'est le cas, toute section commençant par nom_section sera supprimée.

Si le premier caractère de motif_section est le point d'exclamation (!) alors les sections correspondantes ne seront pas supprimées même si une utilisation antérieure de --remove-section sur la même ligne de commande les supprimerait autrement. Par exemple :

--remove-section=.text.* --remove-section=!.text.foo

supprimera toutes les sections correspondant au motif '.text.*', mais ne supprimera pas la section '.text.foo'.

--keep-section=motif_section
Lors de la suppression de sections du fichier de sortie, conserver les sections qui correspondent à motif_section.
--remove-relocations=motif_section
Supprimer les relocations du fichier de sortie pour toute section correspondant à motif_section. Cette option peut être utilisée plusieurs fois. Notez que l'utilisation inappropriée de cette option peut rendre le fichier de sortie inutilisable. Les caractères génériques sont acceptés dans motif_section. Par exemple : 
--remove-relocations=.text.*

supprimera les relocations de toutes les sections correspondant au motif '.text.*'.

Si le premier caractère de motif_section est le point d'exclamation (!) alors les sections correspondantes n'auront pas leurs relocations supprimées, même si une utilisation antérieure de --remove-relocations sur la même ligne de commande entraînerait autrement la suppression des relocations. Par exemple :

--remove-relocations=.text.* --remove-relocations=!.text.foo

supprimera toutes les relocations pour les sections correspondant au motif '.text.*', mais ne supprimera pas les relocations pour la section '.text.foo'.

--strip-section-headers
Supprimer les en-têtes de section. Cette option est spécifique aux fichiers ELF. Implique --strip-all et --merge-notes.
-s
--strip-all
Supprimer tous les symboles.
-g
-S
-d
--strip-debug
Supprimer uniquement les symboles de débogage.
--strip-dwo
Supprimer le contenu de toutes les sections DWARF .dwo, en laissant intactes les sections de débogage restantes et tous les symboles. Voir la description de cette option dans la section objcopy pour plus d'informations.
--strip-unneeded
Supprimer tous les symboles qui ne sont pas nécessaires au traitement des relocations, en plus des symboles et sections de débogage supprimés par --strip-debug.
-K nom_symbole
--keep-symbol=nom_symbole
Lors de la suppression de symboles, conserver le symbole nom_symbole même s'il serait normalement supprimé. Cette option peut être utilisée plusieurs fois.
-M
--merge-notes
--no-merge-notes
Pour les fichiers ELF, tenter (ou ne pas tenter) de réduire la taille des sections de type SHT_NOTE en supprimant les notes dupliquées. Par défaut, cette réduction est tentée à moins que des informations de débogage ou DWO ne soient supprimées.
-N nom_symbole
--strip-symbol=nom_symbole
Supprimer le symbole nom_symbole du fichier source. Cette option peut être utilisée plusieurs fois et peut être combinée avec des options de strip autres que -K.
-o fichier
Placer la sortie dépouillée dans fichier, plutôt que de remplacer le fichier existant. Lorsque cet argument est utilisé, un seul argument fichier_objet peut être spécifié.
-p
--preserve-dates
Conserver les dates d'accès et de modification du fichier.
-D
--enable-deterministic-archives
Fonctionner en mode déterministe. Lors de la copie des membres d'archive et de l'écriture de l'index de l'archive, utiliser zéro pour les UID, GID, horodatages, et utiliser des modes de fichier cohérents pour tous les fichiers.

Si binutils a été configuré avec --enable-deterministic-archives, alors ce mode est activé par défaut. Il peut être désactivé avec l'option -U, ci-dessous.

-U
--disable-deterministic-archives
Ne pas fonctionner en mode déterministe. C'est le mode par
