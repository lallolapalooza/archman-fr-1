DESCRIPTIO

N

Argtable est une bibliothèque ANSI C pour l'analyse des arguments de ligne de commande de style GNU avec un minimum de tracas. Elle permet au programmeur de définir la syntaxe des arguments de son programme directement dans le code source sous forme d'un tableau de structures. La ligne de commande est ensuite analysée selon cette spécification et les valeurs résultantes sont stockées directement dans des variables de programme définies par l'utilisateur où elles sont accessibles au programme

principal.

Cette page manuelle est uniquement à titre de référence. La documentation d'introduction et le code source d'exemple sont généralement installés sous /usr/share/doc/argtable2/ et sont également disponibles sur la page d'accueil d'argtable à l'adresse http://argtable.sourc

eforge.net.

Construction d'une structure de données

arg_<xxx>

Chaque struct arg_<xxx> possède son propre ensemble unique de fonctions constructeurs (définies ci-dessus) qui sont généralement de la forme

: 
struct arg_int* arg_int0("f", "foo", "<int>", "the foo factor")
struct arg_int* arg_int1("f", "foo", "<int>", "the foo factor")
struct arg_int* arg_intn("f", "foo", "<int>", 2, 4, "the foo
factor")

où arg_int0() et arg_int1() sont simplement des formes abrégées de arg_intn(). Elles sont fournies par commodité lors de la définition d'options de ligne de commande qui ont soit zéro ou une occurrence (mincount=0,maxcount=1) soit exactement une occurrence (mincount=1,maxcount=1)

respectivement.

Le paramètre shortopts="f" définit la balise de la forme courte de l'option (par exemple -f). Plusieurs balises alternatives peuvent être définies en les concaténant (par exemple shortopts="abc" définit les options -a, -b et -c comme équivalentes). Spécifiez shortopts=NULL lorsqu'aucune option courte n'est

requise.

Le paramètre longopts="foo" définit la balise de la forme longue de l'option (par exemple --foo). Plusieurs balises alternatives de forme longue peuvent être séparées par des virgules (par exemple longopts="size,limit" définit --size et --limit). N'incluez aucun espace blanc dans la chaîne longopts. Spécifiez longopts=NULL lorsqu'aucune option longue n'est

requise.

Si shortopts et longopts sont tous deux NULL, alors l'option est un argument non

étiqueté.

Le paramètre datatype="<int>" est une chaîne descriptive qui désigne le type de données de l'argument dans les messages d'erreur, comme dans --foo=<int>. Spécifier datatype=NULL indique que le type de données par défaut doit être utilisé. Spécifier datatype="" désactive effectivement l'affichage du type de

données.

Les paramètres mincount=2 et maxcount=3 spécifient le nombre minimum et maximum d'occurrences de l'option sur la ligne de commande. Si l'option de ligne de commande n'apparaît pas le nombre de fois requis, l'analyseur signale une erreur de

syntaxe.

Le paramètre glossary="the foo factor" est une autre chaîne descriptive. Elle n'apparaît que dans la table de glossaire qui est générée automatiquement par la fonction arg_print_glossary (décrite plus tard)

.
-f, --foo=<int> the foo factor

Spécifier une chaîne glossary

NULL fait omettre cette opt
ion de la table de glossaire.

OPTIONS DE LIGNE DE COMMANDE

LITTÉRALES

-x, -y, -z, --help,

--verbose 
struct arg_lit
   {
   struct arg_hdr hdr;  /* en-tête argtable interne */
   int count;           /* nombre d'options de ligne de commande correspondantes */
   }
;

Les options littérales ne prennent aucune valeur d'argument. Après une analyse réussie, count est garanti d'être dans les limites mincount et maxcount spécifiées

à la con
struction.

OPTIONS DE LIGNE DE COMMANDE

ENTIÈRES

-x2, -z 32MB, --size=734kb, --hex 0x7, --binary 0b10011010, --octal

0o123

Argtable accepte les entiers de ligne de commande en décimal (par exemple 123), hexadécimal (par exemple 0xFF12), octal (par exemple 0o123) et binaire (par exemple 0b0101110). Elle accepte également des entiers suffixés par "KB" (x1024), "MB" (x1048576) ou "GB" (x1073741824). Tous les caractères sont insensibles à la

casse 
struct arg_int
   {
   struct arg_hdr hdr;  /* en-tête argtable interne */
   int count;           /* nombre de valeurs retournées dans ival[] */
   int *ival;           /* tableau des valeurs entières analysées */
   }
;

Après une analyse réussie, count est garanti d'être dans les limites mincount et maxcount définies pour l'option à la construction, avec les valeurs appropriées stockées dans le tableau ival. L'analyseur n'acceptera aucune valeur au-delà que la limite.

Indice : Il est légal de définir des valeurs par défaut dans le tableau ival avant d'appeler la fonction arg_parse. Argtable ne modifiera pas les entrées de ival pour lesquelles aucun argument de ligne de commande n'est reçu.

Indice : Les arguments numériques non tagués ne sont pas recommandés car GNU getopt confond les valeurs négatives (par exemple -123) avec des options taguées (par exemple -1 -2 -3). Les arguments tagués (par exemple -x -123, --tag=-123) ne souffrent pas de ce problème.

OPTIONS DE LIGNE DE COMMANDE REAL/DOUBLE

-x2.234, -y 7e-03, -z-3.3E+6, --pi=3.1415, --tolerance 1.0E-6

struct arg_dbl
   {
   struct arg_hdr hdr;  /* en-tête argtable interne */
   int count;           /* nombre de valeurs retournées dans dval[] */
   double *dval;        /* tableau de valeurs double parsées */
   };

Identique à arg_int sauf que les valeurs parsées sont stockées dans dval sous forme de doubles.

OPTIONS DE LIGNE DE COMMANDE CHAINE

-Dmacro, -t mytitle, -m "mon message chaîne", --title="bonjour le monde"

struct arg_str
   {
   struct arg_hdr hdr;  /* en-tête argtable interne */
   int count;           /* nombre de chaînes retournées dans sval[] */
   const char **sval;   /* tableau de pointeurs vers les chaînes d'arguments parsées */
   };

Identique à arg_int sauf que les pointeurs vers les chaînes parsées sont renvoyés dans sval plutôt qu'une copie séparée de la chaîne. En effet, ces pointeurs référencent en fait les buffers de chaîne d'origine stockés dans argv[], donc leur contenu ne doit pas être modifié. Cependant, il est légal d'initialiser les pointeurs de chaîne dans le tableau sval pour référencer des chaînes par défaut fournies par l'utilisateur avant d'appeler arg_parse. Argtable ne modifiera que le contenu de sval lorsqu'il détectera des arguments de ligne de commande correspondants.

OPTIONS DE LIGNE DE COMMANDE EXPRESSION REGULIERE

commit, update, --command=commit, --command=update

struct arg_rex
   {
   struct arg_hdr hdr;  /* en-tête argtable interne */
   int count;           /* nombre de chaînes retournées dans sval[] */
   const char **sval;   /* tableau de pointeurs vers les chaînes d'arguments parsées */
   };

Similaire à arg_str sauf que les valeurs des arguments chaîne ne sont acceptées que si elles correspondent à une expression régulière prédéfinie. Les expressions régulières sont utiles pour faire correspondre des mots-clés de ligne de commande, en particulier si des chaînes insensibles à la casse ou une correspondance de motif sont nécessaires. L'expression régulière est définie par le paramètre pattern passé au constructeur arg_rex et évaluée en utilisant regex. Son comportement peut être contrôlé via des indicateurs regex standard. Ceux-ci sont passés à argtable via le paramètre flags dans le constructeur arg_rex. Cependant, seuls deux des indicateurs regex standard sont pertinents pour argtable, à savoir REG_EXTENDED (utiliser des expressions régulières étendues plutôt que de base) et REG_ICASE (ignorer la casse). Ces indicateurs peuvent être logiquement ORés si désiré. Voir regex(3) pour plus de détails sur la correspondance d'expressions régulières.

Restrictions : Argtable ne prend pas en charge la fonctionnalité arg_rex sur les plateformes Microsoft Windows car les compilateurs Microsoft n'incluent pas le support regex nécessaire en standard.

OPTIONS DE LIGNE DE COMMANDE NOM FICHIER

-o myfile, -Ihome/foo/bar, --input=~/doc/letter.txt, --name a.out

struct arg_file
   {
   struct arg_hdr hdr;      /* en-tête argtable interne */
   int count;               /* nombre de chaînes de noms de fichiers retournées */
   const char **filename;   /* pointeur vers la chaîne de nom de fichier complète */
   const char **basename;   /* pointeur vers le nom de fichier sans le chemin */
   const char **extension;  /* pointeur vers l'extension du nom de fichier */
   };

Similaire à arg_str mais les chaînes d'arguments sont présumées faire référence à des noms de fichiers, donc un analyse supplémentaire est effectuée pour séparer le nom de base et l'extension du nom de fichier (s'ils existent). Les trois tableaux filename[], basename[], extension[] stockent chacun jusqu'à maxcount entrées, et l'entrée i de chacun de ces tableaux fait référence à différentes composantes du même buffer de chaîne.

Par exemple, -o /home/heitmann/mydir/foo.txt serait analysé comme : 

filename[i]  = "/home/heitmann/mydir/foo.txt"
basename[i]  =                      "foo.txt"
extension[i] =                         ".txt"

Si le nom de fichier n'a pas de chemin menant à lui, alors le nom de base est identique au nom de fichier. S'il n'y a pas d'extension identifiée, elle est donnée comme NULL. Les extensions sont considérées comme tout le texte à partir du dernier point dans le nom de fichier.

Indice : Argtable ne traite jamais les noms de fichiers que comme des chaînes et n'essaie jamais de les ouvrir en tant que fichiers ni d'effectuer des recherches de répertoire sur eux.

OPTIONS DE LIGNE DE COMMANDE DATE/HEURE

12/31/04, -d 1982-11-28, --time 23:59

struct arg_date
   {
   struct arg_hdr hdr;  /* en-tête argtable interne */
   const char *format;  /* chaîne de format de date fournie par l'utilisateur qui a été passée au constructeur */
   int count;           /* nombre d'horodatages retournés dans tmval[] */
   struct tm *tmval;    /* tableau d'horodatages */
   };

Accepte une chaîne d'horodatage de la ligne de commande et la convertit au format struct tm en utilisant la fonction système strptime. Le format de l'heure est défini par la chaîne format passée au constructeur arg_date, et est passé directement à strptime. Voir strptime(3) pour plus de détails sur la chaîne de format.

Restrictions : Argtable ne prend pas en charge la fonctionnalité arg_date sous Microsoft Windows car les compilateurs Microsoft n'incluent pas le support strptime nécessaire en standard.

OPTIONS REMARQUE

struct arg_rem
   {
   struct arg_hdr hdr;  /* en-tête argtable interne */
   };

La structure arg_rem est une structure factice dans le sens où elle ne représente pas une option de ligne de commande à analyser. Au lieu de cela, elle fournit un moyen d'inclure des chaînes de datatype et de glossary supplémentaires dans la sortie des fonctions arg_print_syntax, arg_print_syntaxv et arg_print_glossary. En tant que telle, les structures arg_rem peuvent être utilisées dans la table d'arguments pour insérer des lignes de texte supplémentaires dans les descriptions du glossaire ou pour insérer des champs de texte supplémentaires dans la description de la syntaxe.

OPTION FIN-DE-TABLE

struct arg_end
   {
   struct arg_hdr hdr;  /* en-tête argtable interne */
   int count;           /* nombre d'erreurs retournées */
   int *error;          /* tableau de codes d'erreur */
   void **parent;       /* pointeurs vers les options de ligne de commande erronées */
   const char **argval; /* pointeurs vers les valeurs d'arguments de ligne de commande erronées */
   };
Chaque table d'arguments doit avoir une structure arg_end comme dernière entrée.
Elle marque la fin d'une table d'arguments et stocke les codes d'erreur générés par l'analyseur lors du traitement de la table d'arguments.
Le paramètre maxerrors passé au constructeur
arg_end spécifie le nombre maximum d'erreurs que la structure peut stocker.
Toute erreur supplémentaire est rejetée et remplacée par le code d'erreur unique
ARG_ELIMIT qui est ensuite signalé à l'utilisateur par le message "trop d'erreurs".
Une limite maxerrors de 20 est tout à fait raisonnable.
La fonction arg_print_errors affichera les erreurs stockées
dans la structure arg_end dans le même ordre qu'elles se sont produites,
il n'est donc pas nécessaire de comprendre les détails internes de la structure
arg_end.

RÉFÉRENCE FONCTIONS


int arg_nullcheck (void **argtable)

Retourne une valeur non nulle si le tableau argtable[] contient des entrées NULL jusqu'à l'entrée arg_end* de terminaison. Retourne zéro sinon.

int arg_parse (int argc, char **argv, void **argtable)

Analyse les arguments de la ligne de commande dans argv[] en utilisant la syntaxe de ligne de commande spécifiée dans argtable[], en retournant le nombre d'erreurs rencontrées. Les détails des erreurs sont enregistrés dans la structure arg_end de la table d'arguments d'où ils peuvent être affichés ultérieurement avec la fonction arg_print_errors. En cas d'analyse réussie, les structures arg_xxx référencées dans argtable[] contiendront les valeurs des arguments extraites de la ligne de commande.

void arg_print_option (FILE *fp, const char *shortopts, const char *longopts, const char *datatype, const char *suffix)

Cette fonction imprime la syntaxe d'une option, comme -K|--scalar=<int>, où les options courtes, les options longues et le type de données sont tous donnés comme paramètres de cette fonction. Elle est principalement utilisée dans les fonctions errorfn des structures arg_xxx comme moyen d'afficher la syntaxe d'une option dans les messages d'erreur. Cependant, elle peut également être utilisée dans le code utilisateur si désiré. La chaîne suffix est fournie par commodité pour ajouter des nouvelles lignes et autres à la fin de l'affichage et peut être donnée comme NULL si non requise.

void arg_print_syntax (FILE *fp, void **argtable, const char *suffix)

Imprime la syntaxe de ligne de commande de style GNU pour la table d'arguments donnée, comme : [-abcv] [--scalar=<n>] [-o myfile] <file> [<file>]
La chaîne suffix est fournie par commodité pour ajouter des nouvelles lignes et autres à la fin de l'affichage et peut être donnée comme NULL si non requise.

*suffix)

Affiche la forme verbeuse de la syntaxe de la ligne de commande pour la table d'arguments donnée, comme suit : [-a] [-b] [-c] [--scalar=<n>] [-o myfile] [-v|--verbose] <file> [<file>]
La chaîne suffix est fournie par commodité pour ajouter des sauts de ligne, etc. à

la fin de l'affichage et peut être donnée
comme NULL si elle n'est pas requise.

void arg_print_glossary (FILE *fp, void **argtable, const char

*format)

Affiche un tableau de glossaire décrivant chaque option dans la table d'arguments donnée. La chaîne format est passée à printf pour contrôler le formatage de chaque entrée du glossaire. Elle doit avoir exactement deux paramètres de format "%s" comme dans "%-25s %s\n", le premier

est pour la syntaxe de l'option et le second pour sa chaîne de glossaire. Si la chaîne
de glossaire d'une option est NULL, alors cette option est omise de l'affichage du glossaire.

void arg_print_glossary_gnu (FILE *fp, void

**argtable)

Une forme alternative de arg_print_glossary() qui affiche le glossaire en utilisant les conventions de formatage GNU strictes où les o

ptions longues sont alignées verticalement dans une deuxièm
e colonne, et les lignes sont coupées à 80 caractères.

void arg_print_errors (FILE *fp, struct arg_end *end, const char

*progname)

Affiche les détails de toutes les erreurs stockées dans la structure de données end. La chaîne progname est préfixée

à chaque messa
ge d'erreur.
