NOM

dkimverify - Script pour vérifier les messages DKIM sur stdin

VERSION

0.6.0

DESCRIPTION

dkimverify lit un message RFC822 sur l'entrée standard et renvoie un code de sortie 0 si la signature est vérifiée avec succès. Sinon, il renvoie un code de sortie 1.
