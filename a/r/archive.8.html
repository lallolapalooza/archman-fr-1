ARCHIVE(8) Documentation InterNetNews ARCHIVE(8)

NOM

archive - archiveur d'articles Usenet

SYNTAXE

archive [-cfr] [-a archive] [-i index] [-p pattern] [input]

DESCRIPTION

archive crée des copies des fichiers spécifiés sur son entrée standard. Il est normalement exécuté soit comme un flux de canal sous innd, soit par un script avant l'exécution de news.daily.

archive lit le fichier d'entrée input spécifié, ou l'entrée standard si aucun fichier n'est donné. L'entrée est prise comme une séquence de lignes ; les lignes vides et celles commençant par un signe numéro ("#") sont ignorées. Toutes les autres lignes doivent spécifier le jeton d'un article à archiver. Chaque article est récupéré à partir d'un jeton, et le champ d'en-tête Xref est utilisé pour déterminer le fichier cible dans le répertoire d'archives. Vous pouvez limiter les cibles prises du champ d'en-tête Xref avec l'option -p.

Les fichiers sont copiés dans un répertoire au sein du répertoire d'archives, patharchive dans inn.conf (ou un autre répertoire donné avec -a). Par défaut, une hiérarchie imitant le stockage traditionnel d'une file d'attente de news est créée pour les articles donnés ; les répertoires intermédiaires seront créés si nécessaire. Par exemple, si le jeton d'entrée représente l'article 2211 du groupe de news comp.sources.unix, archive stockera par défaut l'article sous :

comp/sources/unix/2211

dans la zone d'archives. Ceci peut être modifié avec les options -c et -f.

OPTIONS

-a archive
Si le drapeau -a est donné, son argument spécifie la racine de la zone d'archives, au lieu de patharchive dans inn.conf.
-c
Si le drapeau -c est donné, les noms de répertoires seront aplatis comme décrit sous l'option -f. Ensuite, de plus, tous les messages seront concaténés dans un seul fichier, en ajoutant à ce fichier s'il existe déjà. Le nom du fichier sera "AAAAJJ", formé à partir de l'heure actuelle lorsque archive est exécuté. En d'autres termes, si un article de comp.sources.unix du 14 décembre 1998 est donné, l'article sera ajouté au fichier : 
comp.sources.unix/199812

dans la zone d'archives.

Les articles seront séparés par une ligne contenant uniquement "-----------".

-f
Si le drapeau -f est utilisé, les noms de répertoires seront aplatis, remplaçant les barres obliques par des points. En d'autres termes, l'article 2211 de comp.sources.unix sera écrit dans : 
comp.sources.unix/2211

dans la zone d'archives.

-i index
Si le drapeau -i est utilisé, archive ajoutera une ligne au fichier index pour chaque article qu'il archive. Cette ligne contiendra le nom du fichier de destination, le champ d'en-tête Message-ID et le champ d'en-tête Subject du message, séparés par des espaces. Si l'un des en-têtes est manquant (ce qui n'est normalement pas possible si l'article a été accepté par innd), il sera remplacé par "<none>". Les en-têtes seront transformés en utilisant les mêmes règles que celles utilisées pour générer les données d'aperçu (dépliés puis avec les tabulations, CR et LF remplacés par des espaces).
-p pattern
Limite les cibles prises du champ d'en-tête Xref aux groupes spécifiés dans pattern. pattern est un motif uwildmat correspondant aux newsgroups que vous souhaitez que archive traite.
-r
Par défaut, archive configure sa sortie d'erreur standard sur pathlog/errlog. Pour supprimer cette redirection, utilisez le drapeau -r.

VALEUR DE RETOUR

Si l'entrée est épuisée, archive se terminera avec un statut zéro. Si une erreur d'E/S se produit, il essaiera de mettre en file d'attente son entrée, en la copiant dans un fichier. S'il n'y avait pas de nom de fichier d'entrée, l'entrée standard sera copiée dans pathoutgoing/archive et le programme se terminera. Si un nom de fichier d'entrée a été donné, un fichier temporaire nommé input.bch (si input est un chemin absolu) ou pathoutgoing/input.bch (si le nom de fichier ne commence pas par une barre oblique) sera créé. Une fois l'entrée copiée, archive essaiera de renommer ce fichier temporaire pour qu'il porte le nom du fichier d'entrée, puis se terminera.

EXEMPLES

Une entrée typique de newsfeeds(5) pour archiver la plupart des newsgroups sources est la suivante :

source-archive!\
    :!*,*sources*,!*wanted*,!*.d\
    :Tc,Wn\
    :<pathbin>/archive -f -i <patharchive>/INDEX

Remplacez <pathbin> et <patharchive> par les chemins appropriés.
