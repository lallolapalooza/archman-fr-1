DESCRIPTION

Ces fonctions permettent de créer, lire et écrire des enregistrements de ressources DNS (RR) dans une structure de données d’analyse DNS. La structure `ares_dns_record_t` contient une liste d’enregistrements RR, divisée en plusieurs sections : answer, authority et additional.

Les enregistrements RR sont manipulés via des pointeurs vers `ares_dns_rr_t`.

Les fonctions `ares_dns_record_rr_add`, `ares_dns_record_rr_get` et `ares_dns_record_rr_del` sont utilisées pour gérer les enregistrements RR dans une section spécifiée d’un enregistrement DNS.

Les fonctions `ares_dns_rr_get_name`, `ares_dns_rr_get_type`, `ares_dns_rr_get_class` et `ares_dns_rr_get_ttl` permettent de récupérer les informations de base d’un enregistrement RR.

Les fonctions `ares_dns_rr_set_*` permettent de définir les différents champs d’un enregistrement RR. Les champs sont identifiés par des clés de type `ares_dns_rr_key_t`, qui correspondent aux différents types d’enregistrements et champs associés. Le type de données attendu pour chaque champ est indiqué dans la description de l’énumération `ares_dns_rr_key_t`.

Les fonctions `ares_dns_rr_get_*` permettent de récupérer la valeur d’un champ spécifique d’un enregistrement RR. Pour les champs binaires ou multiples (comme les enregistrements TXT ou les options), des pointeurs vers les données et leur longueur sont retournés.

Les fonctions de gestion des options (`ares_dns_rr_set_opt`, `ares_dns_rr_del_opt_byid`, `ares_dns_rr_get_opt_cnt`, `ares_dns_rr_get_opt`, `ares_dns_rr_get_opt_byid`) sont utilisées pour manipuler les enregistrements OPT, qui sont couramment utilisés pour EDNS (Extension Mechanisms for DNS).

RETOUR

Les fonctions de retour d’un enregistrement RR retournent des pointeurs vers des structures de données ou des valeurs primitives. Les fonctions de modification retournent `ares_status_t` pour indiquer le succès ou l’échec de l’opération.

DESCRIPTIO

N

La fonction ares_dns_record_rr_cnt(3) renvoie le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section fournie dans le paramètre

sect.

La fonction ares_dns_record_rr_add(3) ajoute une nouvelle entrée d'enregistrement de ressources à l'enregistrement DNS fourni par le paramètre dnsrec. L' enregistrement de ressources résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle appartient l'enregistrement de ressources est spécifiée par le paramètre sect. Le nom de domaine associé à l' enregistrement de ressources est spécifié par le paramètre name, qui ne peut pas être NULL mais peut être une chaîne vide ou ".". Le type d'enregistrement de ressources est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le Time To Live (TTL) dans le paramètre

ttl.

Les fonctions ares_dns_record_rr_get(3) et ares_dns_record_rr_get_const(3) sont utilisées pour récupérer le pointeur de l'enregistrement de ressources à partir de l'enregistrement DNS fourni dans le paramètre dnsrec, pour la section d'enregistrement de ressources fournie dans le paramètre sect, pour l'index spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_rr_cnt(3). La première fonction renvoie un pointeur modifiable vers l'enregistrement de ressources, tandis que la seconde renvoie un pointeur en lecture seule vers l'enregistrement de

ressources.

La fonction ares_dns_record_rr_del(3) est utilisée pour supprimer un enregistrement de ressources de l'enregistrement DNS spécifié dans le paramètre dnsrec. Son utilisation principale est de supprimer un enregistrement ARES_REC_TYPE_OPT lorsqu'il est nécessaire de réessayer une requête sans support EDNS. La section RR DNS est spécifiée via le paramètre sect, et l'index à supprimer est spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_r

r_cnt(3).

La fonction ares_dns_rr_get_name(3) est utilisée pour récupérer le nom de domaine de l'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre

rr.

La fonction ares_dns_rr_get_type(3) est utilisée pour récupérer le type d'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre

rr.

La fonction ares_dns_rr_get_class(3) est utilisée pour récupérer la classe d'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre

rr.

La fonction ares_dns_rr_get_ttl(3) est utilisée pour récupérer le Time to Live (TTL) de la classe d'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre

rr.

La fonction ares_dns_rr_set_addr(3) est utilisée pour définir une adresse IPv4 pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_INADDR. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre

addr.

La fonction ares_dns_rr_set_addr6(3) est utilisée pour définir une adresse IPv6 pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_INADDR6. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre

addr.

La fonction ares_dns_rr_set_str(3) est utilisée pour définir une chaîne pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_STR ou ARES_DATATYPE_NAME. La plupart des chaînes sont limitées à 255 octets, cependant certains enregistrements, comme un enregistrement TXT, peuvent autoriser des chaînes plus longues car ils sont sortis sous forme de chaînes multiples. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre

val.

La fonction ares_dns_rr_set_u8(3) est utilisée pour définir une valeur non signée de 8 bits pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_U8. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre

val.

La fonction ares_dns_rr_set_u16(3) est utilisée pour définir une valeur non signée de 16 bits pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_U16. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre

val.

La fonction ares_dns_rr_set_u32(3) est utilisée pour définir une valeur non signée de 32 bits pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_U32. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre

val.

La fonction ares_dns_rr_set_bin(3) est utilisée pour définir une valeur binaire pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_BIN ou ARES_DATATYPE_BINP. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val. Et la longueur de la valeur associée est fournie dans le paramètre

len.

La fonction ares_dns_rr_add_abin(3) est utilisée pour ajouter une valeur binaire dans le tableau pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val. Et la longueur de la valeur associée est fournie dans le paramètre

len.

La fonction ares_dns_rr_del_abin(3) est utilisée pour supprimer une valeur binaire dans le tableau pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est provides dans le paramètre key, et l'index à supprimer est fourni dans le paramètre

idx.

La fonction ares_dns_rr_set_opt(3) est utilisée pour définir les clés et valeurs d'options/paramètres pour l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr. La clé/paramètre est fourni dans le paramètre key. La valeur d'option/paramètre spécifique à l'enregistrement de ressource est fournie dans le paramètre opt, et il appartient à l'utilisateur de déterminer la valeur appropriée à utiliser. Certaines valeurs connues peuvent être fournies par les énumérations ares_svcb_param_t et ares_opt_param_t. La valeur de l'option est toujours fournie sous forme binaire dans val avec la longueur fournie dans val_len

.

La fonction ares_dns_rr_del_opt_byid(3) est utilisée pour supprimer les clés et valeurs d'options/paramètres pour l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr. La clé/paramètre est fourni dans le paramètre key. La valeur d'option/paramètre spécifique à l'enregistrement de ressource est fournie dans le paramètre opt. Cette fonction retourne ARES_SUCCESS si l'enregistrement est supprimé avec succès, ou ARES_ENOTFOUND si l'enregistrement n'a pas pu être

trouvé.

La fonction ares_dns_rr_get_addr(3) est utilisée pour récupérer l'adresse IPv4 depuis l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_INADDR. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_addr6(3) est utilisée pour récupérer l'adresse IPv6 depuis l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_INADDR6. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_str(3) est utilisée pour récupérer une chaîne depuis l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_STR ou ARES_DATATYPE_NAME. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_u8(3) est utilisée pour récupérer un entier 8 bits depuis l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_U8. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_u16(3) est utilisée pour récupérer un entier 16 bits depuis l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_U16. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_u32(3) est utilisée pour récupérer un entier 32 bits depuis l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_U32. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_bin(3) est utilisée pour récupérer des données binaires depuis l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_BIN ou ARES_DATATYPE_BINP. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre key, et la longueur est stockée dans la variable pointée par len

.

La fonction ares_dns_rr_get_abin_cnt(3) est utilisée pour récupérer le nombre d'éléments du tableau de valeurs binaires stockées depuis l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_abin(3) est utilisée pour récupérer des données binaires depuis le tableau de l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre key, et l'index à récupérer depuis le tableau est fourni par le paramètre idx, et la longueur est stockée dans la variable pointée par len

.

La fonction ares_dns_rr_get_opt_cnt(3) est utilisée pour récupérer le nombre d'options/paramètres associés à l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le key

.

La fonction ares_dns_rr_get_opt(3) est utilisée pour récupérer des données d'option binaires depuis l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_OPT pour l'index spécifié. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre key, l'index à partir duquel récupérer les données d'option est fourni dans le paramètre idx. La valeur est stockée dans la variable pointée par val et la longueur est stockée dans la variable pointée par val_len

.

La fonction ares_dns_rr_get_opt_byid(3) est utilisée pour récupérer des données d'option binaires depuis l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_OPT pour l'identifiant d'option spécifié, s'il existe. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre key, l' identifiant à partir duquel récupérer les données d'option est fourni dans le paramètre opt . La valeur est stockée dans la variable pointée par val et la longueur est stockée dans la variable pointée par val_le

n
.
