NOM

arj-register - Enregistre l'archiveur ARJ

SYNTAXE

arj-register [options] nom_programme

OPTIONS

-arj
Enregistre tous les programmes ARJ pour Linux dans le répertoire courant.
-arj32
Enregistre tous les programmes ARJ32 (fournis par ARJ Software, Inc.) dans le répertoire courant.
