FBB::ArgConfig(3bobcat) Arguments de programme FBB::ArgConfig(3bobcat)

NOM

FBB::ArgConfig - Une classe singleton traitant les arguments de programme

SYNTAXE

#include <bobcat/argconfig>
Option de liaison : -lbobcat

DESCRIPTION

Classe singleton (voir Gamma et al., 1995) construite autour de getopt_long()(3). La classe gère les options courtes et longues de la ligne de commande, ainsi que les fichiers de configuration.

En plus des options de ligne de commande standard, les divers membres option reconnaissent également les options longues comme clés, éventuellement suivies de deux-points et d'une valeur d'option. Par exemple, une option --input filename peut être spécifiée dans le fichier de configuration comme

    input: filename
ou 
    input filename
Les options sans arguments ne devraient probablement pas utiliser les deux-points, bien que cela soit accepté par ConfigArg. Par exemple, pour l'option --verbose, les deux formes sont acceptées : 
verbose
verbose:

ESPACE DE NOMMAGE

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de nommage FBB.

HERITE DE

FBB::Arg,
FBB::ConfigFile

ENUMERATION

L'énumération FBB::ArgConfig::Type est héritée de la classe FBB::Arg. Elle est utilisée pour spécifier si les options longues nécessitent ou non des arguments. Elle définit les valeurs suivantes : None, Required, Optional.

o
None : l'option longue n'utilise pas d'argument ;
o
Required : l'option longue nécessite une valeur d'argument ;
o
Optional : l'option longue peut éventuellement être fournie avec une valeur d'argument ;

Ces valeurs sont utilisées lors de la définition des options longues (comme --version), qui sont définies comme des objets de la classe (imbriquée héritée) FBB::Arg::LongOption (dans le contexte de ArgConfig, c'est identique à FBB::ArgConfig::LongOption.

LA CLASSE IMBRIQUÉE HÉRITÉE FBB::Arg::LongOption

Les options longues sont définies en utilisant des objets de la classe imbriquée FBB::Arg::LongOption. Cette classe fournit les constructeurs suivants :

o
FBB::Arg::LongOption(char const *name, FBB::Arg::Type type = FBB::Arg::None) :
Ce constructeur est utilisé pour définir une option longue pour laquelle aucune option courte correspondante n'est définie. Le paramètre name est le nom de l'option longue (sans spécifier les caractères -- qui ne sont requis que lors de la spécification d'une option longue lors de l'appel d'un programme).
o
FBB::Arg::LongOption(char const *name, int optionChar) :
Ce constructeur est utilisé pour définir une option longue pour laquelle une option courte correspondante est définie. Le paramètre name est le nom de l'option longue (sans spécifier les caractères -- qui ne sont requis que lors de la spécification d'une option longue lors de l'appel d'un programme).

Pour définir les options longues, utilisez la procédure suivante :

o
D'abord, construisez un tableau 
    FBB::Arg::LongOption longOptions[] = { c1, c2, ..., cn };
Où c1, c2, ..., cn sont n invocations de constructeurs des constructeurs FBB::Arg::LongOption()
o
Ensuite, passez longOptions, LongOptions + n comme arguments à un membre Arg::initialize qui prend en charge les options longues.

Les objets de la classe LongOptions sont normalement utilisés en interne par l'objet ArgConfig, mais ils peuvent également être utilisés en dehors de l'objet ArgConfig. Pour cette situation, les membres suivants sont disponibles :

o
std::string const &longName() const :
retourne le nom de l'option longue du LongOption ;
o
int optionChar() const :
retourne le caractère d'option du LongOption (ou l'une des valeurs de l'énumération Arg::Type s'il n'y a pas de caractère d'option associé au LongOption).

CONSTRUCTEURS

Puisque la classe est un Singleton, aucun constructeur public n'est disponible. Au lieu de cela, des membres statiques sont proposés pour initialiser et accéder à l'unique objet ArgConfig.

MEMBRES STATIQUES

Tous les membres initialize initialisent le singleton FBB::ArgConfig, et ne peuvent être appelés qu'une seule fois. Une exception est levée lorsqu'ils sont appelés plusieurs fois. Tous les membres initialize retournent une référence à l'objet singleton ArgConfig initialisé.

Tous les membres initialize définissent les paramètres argc et argv qui sont interprétés comme les paramètres argc et argv de main. Lorsqu'un élément argv pointe vers deux tirets consécutifs (--), cet élément est ignoré, et tous les éléments suivants de argv sont considérés comme des arguments au lieu d'options.

o
FBB::ArgConfig &ArgConfig::initialize(char const *optstring, int argc, char **argv, [std::string const &fname,] Comment cType = KeepComment, SearchCasing sType = SearchCaseSensitive, Indices iType = IgnoreIndices) :
Le paramètre optstring est une chaîne de caractères octets terminée par un zéro (NTBS) commençant éventuellement par un caractère +, mais sinon contenant des caractères d'option. Un ou deux points peuvent être ajoutés aux caractères d'option :
o
un seul deux-points (:) indique que l'option nécessite une valeur d'option.
o
un double deux-points (::) indique que l'option a un argument facultatif. Avec les options courtes, la valeur de l'option est considérée comme absente sauf si elle est attachée à l'option courte (par exemple, -tvaleur). Les options longues acceptant éventuellement des arguments doivent toujours être immédiatement suivies d'un caractère d'affectation (=), immédiatement suivi de la valeur de l'option (qui doit commencer par un caractère non blanc). Par exemple, --valeur= indique une valeur d'option absente, --valeur=texte indique que la valeur de l'option est texte. Si une valeur d'option contient elle-même des espaces, elle doit être entourée de guillemets simples ou doubles (par exemple, -t’cette valeur’, ou --texte=’cette valeur’). Les guillemets environnants ne font pas partie de la valeur de l'option.
Lorsque le premier caractère d'optstring est +, alors toutes les options non spécifiées sont considérées comme des arguments, apparaissant dans la liste finale des arguments à leurs positions d'arguments actuelles. Par exemple, lorsque optstring est +ab et qu'aucune option longue n'est définie, alors appeler 
    prog -a -z -b -yvaleur --long arg1 arg2
entraîne le membre argv retournant un vecteur contenant les éléments -z, -yvaleur, --long, arg1, et arg2. Si le premier caractère d'optstring n'est pas + et qu'une option indéfinie est rencontrée, une exception est levée.
L'argument fname est facultatif. S'il est fourni, un fichier de configuration portant le nom spécifié est ouvert (et doit exister) ; s'il est omis, le ArgConfig est créé sans utiliser de fichier de configuration. Dans ce dernier cas, un fichier de configuration peut être spécifié plus tard en utilisant le membre open hérité de ConfigFile.
Les trois derniers paramètres sont des paramètres de ConfigFile, recevant les valeurs par défaut indiquées. Ce constructeur retourne une référence à l'objet singleton, permettant au code initialisant ArgConfig d'utiliser immédiatement l'objet initialisé.

STATIQUES

Tous les membres publics des classes Arg et ConfigFile sont également pris en charge par la classe ArgConfig. Comme plusieurs Arg::option membres ont été réimplémentés par ArgConfig, tous les membres option sont discutés ci-dessous. Tous les autres membres héritent directement des classes Arg et ConfigFile. Consultez leurs pages de man pour plus de

détails.

configuration.
o
size_t option(std::string const &options) const:
Retourne le nombre total de fois où l'un des caractères spécifiés dans la chaîne `options’ (ou leurs synonymes d'options longues) a été spécifié comme option de ligne de commande ou comme option de fichier de
configuration.
o
size_t option(string *value, int option) const:
Retourne le nombre de fois où l'option fournie (ou son synonyme d'option longue) était présente soit comme option de ligne de commande, soit comme option de fichier de configuration. Si la valeur de retour est non nulle, alors la valeur de la première occurrence de cette option (en vérifiant d'abord les options de ligne de commande ; puis en vérifiant le fichier de configuration) est stockée dans *value, qui reste inchangée si `option’ n'était pas présente. 0 peut être spécifié pour value si l'option n'a pas de valeur ou si la valeur ne doit pas être
stockée.
o
size_t option(size_t idx, string *value, int option) const:
Ce membre se comporte de manière identique au membre Arg::option ayant le prototype identique. Il ne prend pas en compte le fichier de configuration mais considère uniquement les arguments de ligne de commande, retournant le nombre de fois où l'option fournie (ou son synonyme d'option longue) était présente. Si la valeur de retour est non nulle, alors la valeur de la idxème occurrence (décalage basé sur 0) de cette option est stockée dans *value, qui reste inchangée si `option’ n'était pas présente ou si idx est ou dépasse le nombre de spécifications de l'option fournie. 0 peut être spécifié pour value si l'option n'a pas de valeur ou si la valeur ne doit pas être
stockée.
o
size_t option(size_t *idx, string *value, int option) const:
Ce membre se comporte de manière identique au membre Arg::option ayant le prototype identique. EXEMPL

E 
#include <iostream>
#include <string>
#include <bobcat/argconfig>
#include <bobcat/exception>
using namespace std;
using namespace FBB;
ArgConfig::LongOption lo[] =
{
    ArgConfig::LongOption{"option", ’o’},
    ArgConfig::LongOption{"value-option", ’v’}
};
class X
{
    ArgConfig &
    public:
        X();
        void function();
};
X::X()
:
    d_arg(ArgConfig::instance())
{}
void X::function()
{
    if (d_arg.nArgs() == 0)
        throw Exception() << "Provide the name of a config file as 1st arg";
    cout << "Counting " << d_arg.option(’o’) << " instances of -o or "
                                                            "--option\n";
    d_arg.open(d_arg[0]);       // Now open the config file explicitly
                            // (alternatively: use a constructor expecting
                            // a file name)
    cout << "Counting " << d_arg.option(’o’) << " instances of -o or "
                                                            "--option\n";
    string optval;
    size_t count = d_arg.option(&optval, ’v’);
    cout << "Counting " << count <&lt;
                        " instances de -v ou --value-option\n";
    if (count)
        cout << "Option value = " << optval << endl;
}
int main(int argc, char **argv)
try
{
    ArgConfig::initialize("ov:", lo, lo + 2, argc, argv);
    X x;
    x.function();
}
catch (Exception const &err)
{
    cout << "Terminating " << err.what() << endl;
    return 1;
}
