Archive::Tar::File(3perl) Guide de référence des programmeurs Perl Archive::Tar::File(3perl)

NOM

Archive::Tar::File - une sous-classe pour un fichier extrait en mémoire à partir de Archive::Tar

SYNOPSIS

my @items = $tar->get_files;
print $_->name, ' ', $_->size, "\n" for @items;
print $object->get_content;
$object->replace_content('new content');
$object->rename( 'new/full/path/to/file.c' );

DESCRIPTION

Archive::Tar::File fournit une petite couche d'objet pratique pour les fichiers extraits en mémoire. Elle est principalement utilisée en interne dans Archive::Tar pour nettoyer le code, mais il n'y a aucune raison pour que les utilisateurs ne puissent pas utiliser cette API également.

Accesseurs

Beaucoup des méthodes de ce paquet sont des accesseurs pour les différents champs de l'en-tête tar :

name
Le nom du fichier
mode
Le mode du fichier
uid
L'identifiant utilisateur propriétaire du fichier
gid
L'identifiant de groupe propriétaire du fichier
size
Taille du fichier en octets
mtime
Heure de modification. Ajustée à mac-time sur MacOS si nécessaire
chksum
Champ de somme de contrôle pour l'en-tête tar
type
Type de fichier -- numérique, mais comparable aux constantes exportées -- voir la documentation de Archive::Tar
linkname
Si le fichier est un lien symbolique, le fichier vers lequel il pointe
magic
Chaîne magique tar -- inutile pour la plupart des utilisateurs
version
Chaîne de version tar -- inutile pour la plupart des utilisateurs
uname
Le nom d'utilisateur propriétaire du fichier
gname
Le nom de groupe propriétaire du fichier
devmajor
Numéro majeur du périphérique en cas de fichier spécial
devminor
Numéro mineur du périphérique en cas de fichier spécial
prefix
Tout répertoire à préfixer au chemin d'extraction, le cas échéant
raw
En-tête tar brut -- inutile pour la plupart des utilisateurs

Méthodes

Archive::Tar::File->new( file => $path )

Retourne un nouvel objet Archive::Tar::File à partir d'un fichier existant.

Retourne undef en cas d'échec.

Archive::Tar::File->new( data => $path, $data, $opt )

Retourne un nouvel objet Archive::Tar::File à partir de données.

$path définit le nom du fichier (qui n'a pas besoin d'exister), $data le contenu du fichier, et $opt est une référence vers un tableau associatif d'attributs qui peut être utilisé pour remplacer les attributs par défaut (champs dans l'en-tête tar), qui sont décrits ci-dessus dans la section Accesseurs.

Retourne undef en cas d'échec.

Archive::Tar::File->new( chunk => $chunk )

Retourne un nouvel objet Archive::Tar::File à partir d'un morceau d'archive tar brut de 512 octets.

Retourne undef en cas d'échec.

$bool = $file->extract( [ $alternative_name ] )

Extrait cet objet, éventuellement vers un nom alternatif.

Voir "Archive::Tar->extract_file" pour les détails.

Retourne vrai en cas de succès et faux en cas d'échec.

$path = $file->full_path

Retourne le chemin complet depuis l'en-tête tar ; c'est essentiellement une concaténation des champs "prefix" et "name" .

$bool = $file->validate

Effectué par Archive::Tar en interne lors de la lecture du fichier tar : valide l'en-tête par rapport à la somme de contrôle pour s'assurer de l'intégrité du fichier tar.

Retourne vrai en cas de succès, faux en cas d'échec

$bool = $file->has_content

Retourne un booléen pour indiquer si l'objet actuel a un contenu. Certains fichiers spéciaux comme les répertoires et ainsi de suite n'auront jamais de contenu. Cette méthode sert principalement à éviter les avertissements d'utilisation de valeurs non initialisées lors de l'examen du contenu d'un objet.

$content = $file->get_content

Retourne le contenu actuel du fichier en mémoire

$cref = $file->get_content_by_ref

Retourne le contenu actuel du fichier en mémoire sous forme de référence scalaire. Les utilisateurs normaux n'en auront pas besoin, mais cela économisera de la mémoire si vous travaillez avec des fichiers de données très volumineux dans votre archive tar, car cela passera le contenu par référence, plutôt que d'en faire une copie d'abord.

$bool = $file->replace_content( $content )

Remplace le contenu actuel du fichier par le nouveau contenu. Cela n'affecte que l'archive en mémoire, pas la version sur disque jusqu'à ce que vous l'écriviez.

Retourne vrai en cas de succès, faux en cas d'échec.

$bool = $file->rename( $new_name )

Renomme le fichier actuel en $new_name.

Notez que vous devez spécifier un chemin Unix pour $new_name, car selon la norme tar, tous les fichiers dans l'archive doivent être des chemins Unix.

Retourne vrai en cas de succès et faux en cas d'échec.

$bool = $file->chmod( $mode )

Change le mode de $file en $mode. Le mode peut être une chaîne ou un nombre qui est interprété comme octal qu'un 0 initial soit donné ou non.

Retourne vrai en cas de succès et faux en cas d'échec.

$bool = $file->chown( $user [, $group])

Change le propriétaire de $file en $user. Si un $group est donné, il est également modifié. Vous pouvez aussi passer un seul paramètre avec un deux-points séparant l'utilisateur et le groupe comme dans 'root:wheel'.

Retourne vrai en cas de succès et faux en cas d'échec.

Méthodes de commodité

Pour vérifier rapidement le type d'un objet "Archive::Tar::File" , vous pouvez utiliser les méthodes suivantes :

$file->is_file
Retourne vrai si le fichier est de type "file"
$file->is_dir
Retourne vrai si le fichier est de type "dir"
$file->is_hardlink
Retourne vrai si le fichier est de type "hardlink"
$file->is_symlink
Retourne vrai si le fichier est de type "symlink"
$file->is_chardev
Retourne vrai si le fichier est de type "chardev"
$file->is_blockdev
Retourne vrai si le fichier est de type "blockdev"
$file->is_fifo
Retourne vrai si le fichier est de type "fifo"
$file->is_socket
Retourne vrai si le fichier est de type "socket"
$file->is_longlink
Retourne vrai si le fichier est de type "LongLink". Ne devrait pas se produire après un "read"réussi.
$file->is_label
Retourne vrai si le fichier est de type "Label". Ne devrait pas se produireaprès un « read » réussi « read ».
$file->is_unknown
Renvoie vrai si le type de fichier est « unknown »
