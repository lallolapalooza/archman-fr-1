NOM

ares_parse_uri_reply - Analyser une réponse à une requête DNS de type URI

SYNTAXE

#include <ares.h>
int ares_parse_uri_reply(const unsigned char* abuf, int alen,
                         struct ares_uri_reply** uri_out);

DESCRIPTION

La fonction ares_parse_uri_reply(3) analyse la réponse à une requête de type URI en une liste chaînée de struct ares_uri_reply. Les paramètres abuf et alen donnent le contenu de la réponse. Le résultat est stocké dans de la mémoire allouée et un pointeur vers celle-ci est stocké dans la variable pointée par uri_out. Il incombe à l'appelant de libérer la structure uri_out résultante lorsqu'elle n'est plus nécessaire en utilisant la fonction ares_free_data(3).

La structure ares_uri_reply contient les champs suivants :

struct ares_uri_reply {
    struct ares_uri_reply       *next;
    unsigned short              weight;
    unsigned short              priority;
    char                        *uri;
    int                         ttl;
};

VALEURS DE RETOUR

ares_parse_uri_reply peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
La réponse a été analysée avec succès.
ARES_EBADRESP
La réponse était malformée.
ARES_ENODATA
La réponse ne contenait pas de réponse à la requête.
ARES_ENOMEM
La mémoire a été épuisée.
