ares_dns_rec_type_t - Types d'enregistrements DNS gérés par c-ares. Certains types d'enregistrements ne sont peut-être valides que pour les requêtes, et d'autres que pour les réponses

:
ARES_REC_TYPE_A - Adresse de l'hôte
ARES_REC_TYPE_NS - Serveur faisant autorité
ARES_REC_TYPE_CNAME - Nom canonique
ARES_REC_TYPE_SOA - Début de la zone d'autorité
ARES_REC_TYPE_PTR - Pointeur de nom de domaine
ARES_REC_TYPE_HINFO - Informations sur l'hôte
ARES_REC_TYPE_MX - Informations de routage du courrier
ARES_REC_TYPE_TXT - Chaînes de texte
ARES_REC_TYPE_SIG - RFC 2535. RFC 2931. Enregistrement SIG
ARES_REC_TYPE_AAAA - RFC 3596. Adresse Ip6
ARES_REC_TYPE_SRV - RFC 2782. Sélection du serveur
ARES_REC_TYPE_NAPTR - RFC 3403. Pointeur d'autorité de nommage
ARES_REC_TYPE_OPT - RFC 6891. Option EDNS0 (méta-RR). Enregistrement pseudo.
ARES_REC_TYPE_TLSA - RFC 6698. DNS-Based Authentication of Named Entities (DANE) Transport Layer Security (TLS) Protocol: TLSA
ARES_REC_TYPE_SVCB - RFC 9460. Liaison de service à usage général
ARES_REC_TYPE_HTTPS - - RFC 9460. Type de liaison de service à utiliser avec HTTPS
ARES_REC_TYPE_ANY - Correspondance générique. RR de réponse non inclus
ARES_REC_TYPE_URI - RFC 7553. Identifiant de ressource uniforme
ARES_REC_TYPE_CAA - RFC 6844. Certification Authority Authorization
ARES_REC_TYPE_RAW_RR - Utilisé comme indicateur que l'enregistrement RR n'est pas analysé, mais fourni au format binaire

ares_dns_class_t - Classes DNS pour les requêtes et les réponses

:
ARES_CLASS_IN - Internet
ARES_CLASS_CHAOS - CHAOS
ARES_CLASS_HESOID - Hesoid [Dyer 87]
ARES_CLASS_NONE - RFC 2136
ARES_CLASS_ANY - N'importe quelle classe (uniquement pour les requêtes)

ares_dns_opcode_t - Codes d'opération de l'en-tête DNS

:
ARES_OPCODE_QUERY - Requête standard
ARES_OPCODE_IQUERY - Requête inverse. Obsolète
ARES_OPCODE_STATUS - Requête d'état du serveur de noms
ARES_OPCODE_NOTIFY - Notification de changement de zone (RFC 1996)
ARES_OPCODE_UPDATE - Message de mise à jour de zone (RFC 2136)

ares_dns_flags_t - Drapeaux de l'en-tête DNS

:
ARES_FLAG_QR - QR. S'il est défini, c'est une réponse
ARES_FLAG_AA - Réponse faisant autorité. S'il est défini, la réponse fait autorité
ARES_FLAG_TC - Troncature. S'il est défini, c'est une réponse tronquée
ARES_FLAG_RD - Récursion souhaitée. S'il est défini, la récursion est souhaitée
ARES_FLAG_RA - Récursion disponible. S'il est défini, le serveur prend en charge la récursion
ARES_FLAG_AD - RFC 2065. Le bit Authentic Data indique dans une réponse que les données incluses ont été vérifiées par le serveur qui les fournit
ARES_FLAG_CD - RFC 2065. Le bit Checking Disabled indique dans une requête que des données non vérifiées sont acceptables pour le résolveur qui envoie la requête

ares_dns_rcode_t - Codes de réponse DNS du serveur

:
ARES_RCODE_NOERROR - Succès
ARES_RCODE_FORMERR - Erreur de format. Le serveur de noms n'a pas été en mesure d'interpréter la requête
ARES_RCODE_SERVFAIL - Échec du serveur. Le serveur de noms n'a pas été en mesure de traiter cette requête en raison d'un problème avec le serveur de noms
ARES_RCODE_NXDOMAIN - Erreur de nom. Significative uniquement pour les réponses d'un serveur de noms faisant autorité, ce code indique que le nom de domaine référencé dans la requête n'existe pas.
ARES_RCODE_NOTIMP - Non implémenté. Le serveur de noms ne prend pas en charge le type de requête demandé
ARES_RCODE_REFUSED - Refusé. Le serveur de noms refuse d'effectuer l' opération spécifiée pour des raisons de politique.
ARES_RCODE_YXDOMAIN - RFC 2136. Un nom qui ne devrait pas exister, existe bel et bien
ARES_RCODE_YXRRSET - RFC 2136. Un RRset qui ne devrait pas exister, existe bel et bien
ARES_RCODE_NXRRSET - RFC 2136. Un RRset qui devrait exister, n'existe pas
ARES_RCODE_NOTAUTH - RFC 2136. Le serveur ne fait pas autorité pour la zone nommée dans la section Zone.
ARES_RCODE_NOTZONE - RFC 2136. Un nom utilisé dans la section Prerequisite ou Update ne se trouve pas dans la zone indiquée par la section Zone.
ARES_RCODE_DSOTYPEI - RFC 8409. DSO-TYPE Non implémenté
ARES_RCODE_BADSIG - RFC 8945. Échec de la signature TSIG
ARES_RCODE_BADKEY - RFC 8945. Clé non reconnue
ARES_RCODE_BADTIME - RFC 8945. Signature hors de la fenêtre temporelle
ARES_RCODE_BADMODE - RFC 2930. Mode TKEY invalide
ARES_RCODE_BADNAME - RFC 2930. Nom de clé en double
ARES_RCODE_BADALG - RFC 2930. Algorithme non pris en charge
ARES_RCODE_BADTRUNC - RFC 8945. Troncature invalide
ARES_RCODE_BADCOOKIE - RFC 7973. Cookie de serveur invalide ou manquant

ares_dns_parse_flags_t - Drapeaux pour modifier le comportement de ares_dns_parse(3)

:
ARES_DNS_PARSE_AN_BASE_RAW - Analyser la section Answer de la RFC 1035 qui autorise la compression de noms en tant que type RR RAW
ARES_DNS_PARSE_NS_BASE_RAW - Analyser la section Authority de la RFC 1035 qui autorise la compression de noms en tant que type RR RAW
ARES_DNS_PARSE_AR_BASE_RAW - Analyser la section Additional de la RFC 1035 qui autorise la compression de noms en tant que type RR RAW
ARES_DNS_PARSE_AN_EXT_RAW - Analyser la section Answer des RFC ultérieures (sans compression de noms) en tant que type RR RAW
ARES_DNS_PARSE_NS_EXT_RAW - Analyser la section Authority des RFC ultérieures (sans compression de noms) en tant que type RR RAW
ARES_DNS_PARSE_AR_EXT_RAW - Analyser la section Additional des RFC ultérieures (sans compression de noms) en tant que type RR RAW

DESCRIPTIO

N

La fonction ares_dns_record_destroy(3) détruit la mémoire associée à l'enregistrement DNS créé par ares_dns_record_create(3) ou ares_dns_parse(3) et transmis via dnsrec

.

La fonction ares_dns_parse(3) analyse le tampon fourni dans buf avec la longueur fournie dans buf_len. Le paramètre flags peut être un ou plusieurs ares_dns_parse_flags_t, ou zéro si aucun drapeau n'est nécessaire. Les données résultantes de l'enregistrement DNS sructure est stockée dans la variable pointée par dnsrec et doit être détruite à l'aide de ares_dns_record_de

stroy(3).

La fonction ares_dns_write(3) prend une structure d'enregistrement DNS remplie dans dnsrec et écrit un message DNS au format d'octets dans la variable pointée par buf et écrit la longueur du tampon dans la variable pointée par buf_len. Le tampon doit être détruit à l'aide de ares_free_str

ing(3).

La fonction ares_dns_record_create(3) crée une structure d'enregistrement DNS vide dans la variable pointée par dnsrec. Le paramètre id est l'identifiant du message DNS, cependant, si on le transmet à ares_send(3) cet identifiant sera écrasé, il devrait donc généralement valoir 0. Le paramètre flags est un ou plusieurs ares_dns_flags_t. L'opcode est transmis dans le paramètre opcode et devrait généralement être ARES_OPCODE_QUERY. Le code de réponse est principalement destiné aux réponses et est transmis dans le paramètre rcode et est généralement ARES_RCODE_NOERROR

.

La fonction ares_dns_record_duplicate(3) duplique une structure d'enregistrement DNS existante. Cela peut être utile si l'on souhaite enregistrer un résultat tel que récupéré à partir de ares_send_dnsrec(3) ou ares_search_dnsrec(3). La structure à dupliquer est transmise dans le paramètre dnsrec, et la copie dupliquée est renvoyée, ou NULL en cas d'erreur, par exemple en cas de manque de

mémoire.

La fonction ares_dns_record_get_id(3) est utilisée pour récupérer l'identifiant du message DNS à partir de l'enregistrement DNS fourni dans le paramètre dnsrec

.

La fonction ares_dns_record_set_id(3) est utilisée pour définir l'identifiant du message DNS dans le paramètre id à partir de l'enregistrement DNS fourni dans le paramètre dnsrec. Cet identifiant sera écrasé lors du passage de l'enregistrement à c-ares, il existe donc principalement à des fins

externes.

La fonction ares_dns_record_get_flags(3) est utilisée pour récupérer les indicateurs du message DNS à partir de l'enregistrement DNS fourni dans le paramètre dnsrec

.

La fonction ares_dns_record_get_opcode(3) est utilisée pour récupérer les indicateurs du message DNS à partir de l'enregistrement DNS fourni dans le paramètre dnsrec

.

La fonction ares_dns_record_get_rcode(3) est utilisée pour récupérer le code de réponse du message DNS à partir de l'enregistrement DNS fourni dans le paramètre dnsrec

.

La fonction ares_dns_record_query_add(3) est utilisée pour ajouter une question à l'enregistrement DNS fourni dans le paramètre dnsrec. Le nom de domaine spécifié pour la question est fourni dans le paramètre name , ainsi que le type de question dans le paramètre qtype et la classe de question (généralement ARES_CLASS_IN) dans le paramètre qclass

.

La fonction ares_dns_record_query_set_name(3) est utilisée pour modifier le nom de la question dans l'enregistrement DNS fourni dans le paramètre dnsrec . L'index de la requête, qui doit être inférieur à ares_dns_record_query_cnt(3), est fourni dans le paramètre idx . Le nouveau nom de domaine est fourni dans le paramètre name. Il faut faire attention car cela entraînera l'invalidation de tout pointeur name récupéré à partir de ares_dns_Record_query_get(3). Cette fonction est utile si l'on envoie plusieurs requêtes similaires sans recréer l'ensemble de la requête

DNS.

La fonction ares_dns_record_query_set_type(3) est utilisée pour modifier le type de la question dans l'enregistrement DNS fourni dans le paramètre dnsrec . L'index de la requête, qui doit être inférieur à ares_dns_record_query_cnt(3), est fourni dans le paramètre idx . Le nouveau type de requête est fourni dans le paramètre qtype

.

La fonction ares_dns_record_query_cnt(3) est utilisée pour récupérer le nombre de questions DNS dans l'enregistrement DNS fourni dans le paramètre dnsrec

.

La fonction ares_dns_record_query_get(3) est utilisée pour récupérer les détails d'une seule question DNS dans le paramètre dnsrec fourni. L'index fourni dans le paramètre idx doit être inférieur à la valeur renvoyée par ares_dns_record_query_cnt(3). Le nom de la question DNS sera renvoyé dans la variable pointée par le paramètre name , celui-ci peut être fourni comme NULL si le nom n'est pas nécessaire. Ce pointeur sera invalidé par tout appel à ares_dns_record_query_set_name(3). Le type de la question DNS sera renvoyé dans la variable pointée par le paramètre qtype, celui-ci peut être fourni comme NULL si le type n'est pas nécessaire. La classe de la question DNS sera renvoyée dans la variable pointée par le paramètre qclass, celui-ci peut être fourni comm

e NULL si la classe
n'est pas nécessaire.

VALEURS DE

RETOUR

ares_dns_parse(3), ares_dns_write(3), ares_dns_record_create(3), ares_dns_record_query_add(3) et ares_dns_record_query_get(3) renvoient tous un code d'erreur ares_status_t. ARES_SUCCESS est renvoyé en cas de succès, ARES_ENOMEM est renvoyé en cas de manque de mémoire, ARES_EFORMERR est renvoyé en cas d'utilisation

abusive.

ares_dns_record_get_id(3), ares_dns_record_set_id(3), ares_dns_record_get_flags(3), ares_dns_record_get_opcode(3), ares_dns_record_get_rcode(3), et ares_dns_record_query_cnt(3) renvoient tous leurs valeurs de type de données prescrites et en général ne peuvent pas échouer, sauf en cas d'utili

sation abusive, où une valeur 0 peut être renvoyée, cependant 0 peut au
ssi être une valeur de retour valide pour la plupart de ces fonctions.
