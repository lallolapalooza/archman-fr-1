ARDOUR(1) Commandes utilisateur ARDOUR(1)

NOM

Ardour - station de travail audio numérique

SYNTAXE

ardour [ OPTIONS ] [ NOM-SESSION ]

DESCRIPTION

Ardour est un enregistreur sur disque dur multicanal (HDR) et une station de travail audio numérique (DAW).

OPTIONS

-a, --no-announcements
Ne pas contacter le site web pour les annonces
-A, --actions
Afficher tous les noms d'actions de menu possibles
-b, --bindings
Afficher toutes les liaisons de touches actuelles
-B, --bypass-plugins
Contourner tous les plugins d'une session existante
-c, --name <nom>
Utiliser un nom de client backend spécifique, le défaut est ardour
-d, --disable-plugins
Désactiver tous les plugins (mode sans échec)
-D, --debug <options>
Définir des indicateurs de débogage. Utiliser « -D list » pour voir les options disponibles
-h, --help
Afficher ce message
-k, --keybindings <fichier>
Chemin vers le fichier de liaisons de touches à charger
-m, --menus fichier
Utiliser « fichier » pour définir les menus
-n, --no-splash
Ne pas afficher l'écran de démarrage
-N, --new nom-session
Créer une nouvelle session depuis la ligne de commande
-O, --no-hw-optimizations
Désactiver les optimisations spécifiques au matériel
-P, --no-connect-ports
Ne connecter aucun port au démarrage
-S, --sync
Dessiner l'interface graphique de manière synchrone
-T, --template <nom>
Utiliser le modèle donné pour la nouvelle session
-v, --version
Afficher la version et quitter

SIGNALEMENT DES BOGUES

Signaler les bogues à https://tracker.ardour.org
Site web https://ardour.org
