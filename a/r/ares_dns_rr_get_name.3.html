DESCRIPTION

Ces fonctions fournissent des moyens de créer, de lire et de modifier des enregistrements de ressources (RR) DNS au sein d'une structure ares_dns_record_t. Une structure ares_dns_record_t peut contenir plusieurs sections DNS (Réponse, Autorité, Supplémentaire).

Chaque section DNS contient une liste d'enregistrements RR. Les fonctions suivantes permettent d'accéder et de manipuler ces listes et les RR individuels :

  • ares_dns_record_rr_cnt() renvoie le nombre d'enregistrements RR dans une section spécifiée.
  • ares_dns_record_rr_add() ajoute un nouvel enregistrement RR à une section spécifiée. Il prend en arguments le nom du domaine, le type d'enregistrement, la classe et le TTL.
  • ares_dns_record_rr_get() renvoie un pointeur vers un enregistrement RR à un index spécifié dans une section donnée.
  • ares_dns_record_rr_get_const() renvoie un pointeur constant vers un enregistrement RR à un index spécifié dans une section donnée.
  • ares_dns_record_rr_del() supprime un enregistrement RR à un index spécifié dans une section donnée.

Les fonctions suivantes permettent de lire des champs spécifiques d'un enregistrement RR :

  • ares_dns_rr_get_name() renvoie le nom de domaine de l'enregistrement RR.
  • ares_dns_rr_get_type() renvoie le type de l'enregistrement RR.
  • ares_dns_rr_get_class() renvoie la classe de l'enregistrement RR.
  • ares_dns_rr_get_ttl() renvoie la durée de vie (TTL) de l'enregistrement RR.

Les fonctions de la forme ares_dns_rr_set_*() sont utilisées pour définir des valeurs pour les différents champs d'un enregistrement RR. La plupart des enregistrements RR ont plusieurs champs qui peuvent être accédés via la clé ares_dns_rr_key_t. Les types de données pour ces champs sont spécifiés dans les énumérations de la section ENUMERATIONS.

Les fonctions de la forme ares_dns_rr_get_*() sont utilisées pour lire les valeurs des différents champs d'un enregistrement RR.

Les champs de type binaire (par exemple, le champ de données des enregistrements TXT, la signature des enregistrements SIG) sont gérés par ares_dns_rr_set_bin() et ares_dns_rr_get_bin().

Certains types d'enregistrements peuvent avoir plusieurs valeurs pour un même champ (par exemple, plusieurs options dans un enregistrement OPT, ou plusieurs blocs de données dans un enregistrement TXT). Ces champs sont gérés en utilisant les fonctions ares_dns_rr_add_abin(), ares_dns_rr_del_abin(), ares_dns_rr_get_abin_cnt() et ares_dns_rr_get_abin(). Les enregistrements OPT sont gérés de manière similaire avec ares_dns_rr_set_opt(), ares_dns_rr_del_opt_byid(), ares_dns_rr_get_opt_cnt() et ares_dns_rr_get_opt().

Pour plus de détails sur les clés ares_dns_rr_key_t et les types de données associés, veuillez consulter la section ENUMERATIONS.

EXEMPLES

L'exemple suivant montre comment ajouter un enregistrement A à la section de réponse d'un enregistrement DNS et comment ensuite lire son adresse IP.

ares_dns_record_t *dnsrec;
ares_dns_rr_t     *rr;
struct in_addr     addr;
ares_status_t      status;

// ... initialisation de dnsrec ...

// Ajouter un enregistrement A
status = ares_dns_record_rr_add(&rr, dnsrec, ARES_SECTION_ANSWER,
                              "example.com", ARES_REC_A, ARES_CLASS_IN, 3600);
if (status != ARES_SUCCESS) {
    // Gérer l'erreur
    return;
}

// Définir l'adresse IP pour l'enregistrement A
inet_aton("192.0.2.1", &addr);
ares_dns_rr_set_addr(rr, ARES_RR_A_ADDR, &addr);

// Lire l'adresse IP de l'enregistrement A
const struct in_addr *ret_addr;
ret_addr = ares_dns_rr_get_addr(rr, ARES_RR_A_ADDR);
if (ret_addr) {
    // Utiliser l'adresse IP (ret_addr)
}

// ... libération de dnsrec ...

La fonction ares_dns_record_rr_cnt(3) renvoie le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section fournie dans le paramètre sect

.

La fonction ares_dns_record_rr_add(3) ajoute une nouvelle entrée d'enregistrement de ressources à l'enregistrement DNS fourni par le paramètre dnsrec. L'enregistrement de ressources résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle appartient l'enregistrement de ressources est spécifiée par le paramètre sect. Le nom de domaine associé à l'enregistrement de ressources est spécifié par le paramètre name, qui ne peut pas être NULL mais peut être une chaîne vide, ou « . ». Le type d'enregistrement de ressources est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le Time To Live (TTL) dans le paramètre ttl

.

Les fonctions ares_dns_record_rr_get(3) et ares_dns_record_rr_get_const(3) sont utilisées pour récupérer le pointeur de l'enregistrement de ressources à partir de l'enregistrement DNS fourni dans le paramètre dnsrec, pour la section d'enregistrement de ressources fournie dans le paramètre sect, pour l'index spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_rr_cnt(3). La première fonction renvoie un pointeur modifiable vers l'enregistrement de ressources, tandis que la seconde renvoie un pointeur en lecture seule vers l'enregistrement de

ressources.

La fonction ares_dns_record_rr_del(3) est utilisée pour supprimer un enregistrement de ressources de l'enregistrement DNS spécifié dans le paramètre dnsrec. Son utilisation principale est de supprimer un enregistrement ARES_REC_TYPE_OPT lorsqu'il est nécessaire de réessayer une requête sans support EDNS. La section RR DNS est spécifiée via le paramètre sect, et l'index à supprimer est spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_r

r_cnt(3).

La fonction ares_dns_rr_get_name(3) est utilisée pour récupérer le nom de domaine de l'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr

.

La fonction ares_dns_rr_get_type(3) est utilisée pour récupérer le type d'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr

.

La fonction ares_dns_rr_get_class(3) est utilisée pour récupérer la classe d'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr

.

La fonction ares_dns_rr_get_ttl(3) est utilisée pour récupérer le Time to Live (TTL) de la classe d'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr

.

La fonction ares_dns_rr_set_addr(3) est utilisée pour définir une adresse IPv4 pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_INADDR. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre addr

.

La fonction ares_dns_rr_set_addr6(3) est utilisée pour définir une adresse IPv6 pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_INADDR6. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre addr

.

La fonction ares_dns_rr_set_str(3) est utilisée pour définir une chaîne pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_STR ou ARES_DATATYPE_NAME. La plupart des chaînes sont limitées à 255 octets, cependant certains enregistrements, comme un enregistrement TXT, peuvent autoriser des chaînes plus longues car ils sont sortis sous forme de chaînes multiples. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val

.

La fonction ares_dns_rr_set_u8(3) est utilisée pour définir une valeur non signée de 8 bits pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_U8. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val

.

La fonction ares_dns_rr_set_u16(3) est utilisée pour définir une valeur non signée de 16 bits pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_U16. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val

.

La fonction ares_dns_rr_set_u32(3) est utilisée pour définir une valeur non signée de 32 bits pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_U32. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val

.

La fonction ares_dns_rr_set_bin(3) est utilisée pour définir une valeur binaire pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_BIN ou ARES_DATATYPE_BINP. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val. Et la longueur de la valeur associée est fournie dans le paramètre len

.

La fonction ares_dns_rr_add_abin(3) est utilisée pour ajouter une valeur binaire dans le tableau pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val. Et la longueur de la valeur associée est fournie dans le paramètre len

.

La fonction ares_dns_rr_del_abin(3) est utilisée pour supprimer une valeur binaire dans le tableau pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et l'index à supprimer est fourni dans le paramètre idx.

La

fonction ares_dns_rr_set_opt(3) est utilisée pour définir les clés et les valeurs des options/paramètres de l'enregistrement lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement à modifier est fourni dans le paramètre dns_rr. La clé/paramètre est fournie dans le paramètre key. La valeur de l'option/paramètre spécifique à l'enregistrement est fournie dans le paramètre opt, et il appartient à l'utilisateur de déterminer la valeur appropriée à utiliser. Certaines valeurs connues peuvent être fournies par les énumérations ares_svcb_param_t et ares_opt_param_t. La valeur de l'option est toujours fournie sous forme binaire dans val avec la longueur fournie dans val_len. La fonction ares_dns_rr_del_opt_byid(3) est utilisée pour supprimer les clés et les valeurs des options/paramètres de l'enregistrement lorsque le type de données est ARES_DATATYPE_OPT.
