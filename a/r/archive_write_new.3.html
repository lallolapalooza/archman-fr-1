ARCHIVE_WRITE_NEW(3) Manuel des fonctions de bibliothèque ARCHIVE_WRITE_NEW(3)

NOM

archive_write_new — fonctions pour la création d'archives

BIBLIOTHÈQUE

Bibliothèque d'archives en flux (libarchive, -larchive)

SYNTAXE

#include <archive.h>

struct archive *
archive_write_new(void);

DESCRIPTION

Alloue et initialise un objet struct archive adapté à l'écriture d'une archive tar. NULL est retourné en cas d'erreur.

Une description complète de l'objet struct archive se trouve dans la page de manuel d'aperçu de libarchive(3).

VOIR AUSSI

tar(1), archive_write(3), archive_write_set_options(3), libarchive(3), cpio(5), mtree(5), tar(5)
