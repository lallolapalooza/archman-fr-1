ARIA_S3_COPY(1) Commandes utilisateur ARIA_S3_COPY(1)

NOM

aria_s3_copy - Copier une table Aria vers et depuis s3

DESCRIPTION

Utilisation : aria_s3_copy --aws-access-key=# --aws-secret-access-key=# --aws-region=# --op=(from_s3 | to_s3 | delete_from_s3) [OPTIONS] tables[.MAI]

-?, -h, --help
Afficher l'aide et quitter.
-k, --s3-access-key=nom
Identifiant de clé d'accès AWS
-r, -s3-region=nom
Région AWS
-K, -s3-secret-key=nom
Identifiant de clé d'accès secrète AWS
-b, -s3-bucket=nom
Préfixe AWS pour les tables
-h, -s3-host-name=nom
Nom d'hôte du fournisseur S3
-c, -compress
Utiliser la compression
-o, -op=nom
Opération à exécuter. L'un de 'from_s3', 'to_s3' ou 'delete_from_s3'
-d, -database=nom
Base de données pour la table copiée (deuxième préfixe). Si non spécifié, le répertoire du fichier de table est utilisé
-B, -s3-block-size=#
Taille de bloc pour les blocs de données/index dans s3
-L, -s3-protocol-version=nom
Protocole utilisé pour la communication avec S3. L'un de "Auto", "Amazon" ou "Original".
-f, -force
Forcer la copie même si la cible existe
-V, -version
Afficher la version et quitter.
--s3-debug
Afficher le journal de débogage de marias3 sur stdout
-v, --verbose
Être verbeux.

Pour plus d'informations, veuillez consulter la page de la base de connaissances MariaDB https://mariadb.com/kb/en/aria_s3_copy/
