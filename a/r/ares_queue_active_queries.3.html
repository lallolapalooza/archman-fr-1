NOM

ares_queue_wait_empty, ares_queue_active_queries - Fonctions pour vérifier l'état de la file d'attente c-ares

SYNOPSIS

#include <ares.h>
size_t ares_queue_active_queries(const ares_channel_t *channel);
ares_status_t ares_queue_wait_empty(ares_channel_t *channel,
                                    int timeout_ms);

DESCRIPTION

La fonction ares_queue_active_queries(3) récupère le nombre total de requêtes actives en attente de réponse des serveurs. Certaines requêtes c-ares peuvent générer plusieurs requêtes, telles que ares_getaddrinfo(3) lors de l'utilisation de AF_UNSPEC, ce qui se reflétera dans ce nombre. Le paramètre channel doit être défini sur un canal initialisé.

La fonction ares_queue_wait_empty(3) se bloque jusqu'à ce qu'elle soit notifiée qu'il n'y a plus de requêtes dans la file d'attente, ou que le délai spécifié ait expiré. Le paramètre channel doit être défini sur un canal initialisé. Le paramètre timeout_ms est le nombre de millisecondes à attendre que la file d'attente soit vide, ou -1 pour l'infini.

VALEURS DE RETOUR

ares_queue_active_queries(3) retourne le nombre de requêtes actives.

ares_queue_wait_empty(3) peut retourner l'une des valeurs suivantes :

ARES_ENOTIMP
si non compilé avec le support des threads
ARES_ETIMEOUT
si le délai d'attente demandé a expiré
ARES_SUCCESS
lorsque la file d'attente est vide.

DISPONIBILITÉ

Cette fonction a été introduite pour la première fois dans la version 1.27.0 de c-ares et nécessite que la bibliothèque c-ares soit compilée avec le support des threads.

VOIR AUSSI

ares_init_options(3), ares_threadsafety(3)
