NOM

arptables-save — sauvegarde les règles arptables vers la sortie standard (basé sur nft)

SYNTAXE

arptables-save [-M modprobe] [-c]

arptables-save [-V]

DESCRIPTION

arptables-save est utilisé pour exporter le contenu d'une table ARP dans un format facilement analysable vers STDOUT. Utilisez la redirection d'E/S fournie par votre shell pour écrire dans un fichier.

-M, --modprobe programme_modprobe
Spécifie le chemin vers le programme modprobe. Par défaut, arptables-save examinera /proc/sys/kernel/modprobe pour déterminer le chemin de l'exécutable.
-c, --counters
Inclut les valeurs actuelles de tous les compteurs de paquets et d'octets dans la sortie.
-V, --version
Affiche les informations de version et quitte.
