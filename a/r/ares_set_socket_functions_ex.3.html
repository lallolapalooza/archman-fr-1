NAME

ares_set_socket_functions, ares_set_socket_functions_ex - Set socket functions callbacks

SYNOPSIS

#include <ares.h>
typedef void (*ares_socket_create_func)(int domain, int type, int protocol, void *user_data);
typedef int (*ares_socket_close_func)(ares_socket_t fd, void *user_data);

DESCRIPTION

The ares_set_socket_functions() and ares_set_socket_functions_ex() functions allow the caller to provide their own implementations of socket functions. This is useful for testing, or for environments where standard POSIX sockets are not available.

The functions argument is a pointer to a ares_socket_functions_t structure containing pointers to callback functions. See ares_socket_functions_t below.

The channel argument is the c-ares channel handle to set the socket functions for.

The return value is ARES_SUCCESS on success, or an error code otherwise.

If any of the functions in the structure are set to NULL, c-ares will use its own default implementations for those functions.

The user_data argument is passed to all callback functions, and can be used to pass application-specific data.

The ares_set_socket_functions() function sets the following callbacks:

ares_socket_create_func

Creates an endpoint for communication and returns a descriptor. domain, type, and protocol each correspond to the parameters of socket(2). Returns a handle to the newly created socket, or ARES_SOCKET_BAD on error.
ares_socket_close_func

Closes the socket endpoint indicated by fd. See close(2).
ares_socket_connect_func

Initiate a connection to the address indicated by addr on a socket. See connect(2)
ares_socket_recvfrom_func

Receives data from remote socket endpoint, if available. If the addr parameter is not NULL and the connection protocol provides the source address, the callback should fill this in. See recvfrom(2)
ares_socket_sendv_func

Send data, as provided by the iovec array data, to the socket endpoint. See writev(2)
ares_socket_listen_func

Enable a socket to accept incoming connections. See listen(2).
ares_socket_accept_func

Accept an incoming connection. See accept(2).
ares_socket_getsockname_func

Get the local address and port of a socket. See getsockname(2).
ares_socket_setsockopt_func

Set socket options. See setsockopt(2). The option_value parameter is a pointer to the option value, and option_len is the length of the option value. The user_data can be used to interpret special options, such as ARES_SOCKET_OPT_BIND_DEVICE.
ares_socket_bind_func

Assign a name to a socket. This can be used for client connections to bind the source address for packets before connect, or for server connections to bind to an address and port before listening. Currently c-ares only supports client connections. flags from ares_socket_bind_flags_t can be specified. See bind(2).
ares_socket_getnameinfo_func

Convert a socket address structure to a host name and port number. See getnameinfo(2).
ares_socket_getaddrinfo_func

Convert a protocol-independent request into a default set of socket addresses. See getaddrinfo(2).
ares_sockstate_notify_func

Called when the file descriptor is about to be added to or removed from the set of file descriptors c-ares is polling. read_fd is the file descriptor to be checked for reading, and write_fd is the file descriptor to be checked for writing. If read_fd_flag is non-zero, the descriptor is being added for reading. If write_fd_flag is non-zero, the descriptor is being added for writing. If the flag is zero, the descriptor is being removed from the polling set.
ares_sock_tounix_func

Translate a socket to a UNIX domain socket path. This is used when connecting to a DNS server via a UNIX domain socket. See unix(2).
unsigned int (*aif_nametoindex)(const char * ifname, void * user_data)

Optional. Convert an interface name into the interface index. If this callback is not specified, then IPv6 Link-Local DNS servers cannot be used. See if_nametoindex(2).
const char * (*aif_indextoname)(unsigned int ifindex, char * ifname_buf, size_t ifname_buf_len, void * user_data)

Optional. Convert an interface index into the interface name. If this callback is not specified, then IPv6 Link-Local DNS servers cannot be used. ifname_buf must be at least IF_NAMESIZE or IFNAMSIZ in size. See if_indextoname(2).

The ares_set_socket_functions_ex() function is similar to ares_set_socket_functions(), but it also takes a pointer to a ares_socket_functions_ex_t structure which includes an additional callback:

ares_socket_connect_init_func

Optional. Allows initialization of connection-related socket options before initiating a connection. This function is called by ares_connect() before it calls the actual connect function. This can be used to set options such as TCP Fast Open.

The structure provided to ares_set_socket_functions() is not copied and must remain valid for the lifetime of the channel. The structure provided to ares_set_socket_functions_ex() is copied, and does not need to survive past the call.

All callback functions are expected to behave like their system equivalents. On failure, they should set errno(2) (or WSASetLastError(2) on Windows) to an appropriate error code.

It is strongly recommended that all I/O functions behave asynchronously. When they would normally block, they should return an error code of EAGAIN, EWOULDBLOCK, or WSAEWOULDBLOCK.

The following flags can be passed to the callback functions:

ARES_SOCKFUNC_FLAG_NONBLOCKING

Used to indicate that the implementation of the I/O functions is asynchronous.
ARES_SOCKET_OPT_SENDBUF_SIZE

Set the Send Buffer size. Value is a pointer to an int. (SO_SNDBUF).
ARES_SOCKET_OPT_RECVBUF_SIZE

Set the Receive Buffer size. Value is a pointer to an int. (SO_RCVBUF).
ARES_SOCKET_OPT_BIND_DEVICE

Set the network interface to use as the source for communication. Value is a C string. (SO_BINDTODEVICE)
ARES_SOCKET_OPT_TCP_FASTOPEN

Enable TCP Fast Open. Value is a pointer to an ares_bool_t. On some systems this could be a no-op if it is known it is on by default and return success. Other systems may be a no-op if known the system does not support the feature and returns failure with errno set to ENOSYS or WSASetLastError(WSAEOPNOTSUPP);.
ARES_SOCKET_BIND_TCP

Bind is for a TCP connection.
ARES_SOCKET_BIND_CLIENT

Bind is for a client connection, not server.
ARES_SOCKET_CONN_TCP_FASTOPEN

Connect using TCP Fast Open.
