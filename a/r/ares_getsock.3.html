ARES_GETSOCK(3) Manuel des fonctions de bibliothèque ARES_GETSOCK(3)

NOM

ares_getsock - obtenir les descripteurs de socket sur lesquels attendre (obsolète)

SYNTAXE

#include <ares.h>
int ares_getsock(const ares_channel_t *channel, ares_socket_t *socks,
                 int numsocks);

DESCRIPTION

La fonction ares_getsock récupère l'ensemble des descripteurs de socket sur lesquels le programme appelant doit attendre en lecture et/ou en écriture pour le traitement des requêtes de service de noms en attente sur le canal de service de noms identifié par channel. Les descripteurs de socket seront définis dans le tableau de descripteurs de socket pointé par socks. numsocks est la taille du tableau donné en nombre d'entiers.

Cette fonction ne peut retourner des informations que pour un maximum de 16 sockets. Si plus de sockets sont utilisés, elles ne sont tout simplement pas signalées.

VALEURS DE RETOUR

ares_getsock retourne un masque de bits indiquant les actions sur lesquelles attendre sur les différents sockets. Le fichier d'en-tête ares.h fournit ces macros pratiques pour extraire les informations de manière appropriée :

#define ARES_GETSOCK_MAXNUM 16 /* ares_getsock() peut retourner des informations sur
                                  ce nombre de sockets */
#define ARES_GETSOCK_READABLE(bits,num) (bits & (1<< (num)))
#define ARES_GETSOCK_WRITABLE(bits,num) (bits & (1 << ((num) +                                          ARES_GETSOCK_MAXNUM)))

NOTES

Cette fonction a été ajoutée dans c-ares 1.3.1 et dépréciée dans c-ares 1.20.0 en raison de l'implémentation de ARES_OPT_MAX_UDP_QUERIES qui rend probable le dépassement de 16 descripteurs de fichiers.

Il est recommandé d'utiliser ARES_OPT_EVENT_THREAD passé à ares_init_options(3) ou d'utiliser les rappels d'état de socket (ARES_OPT_SOCK_STATE_CB) enregistrés via ares_init_options(3).
