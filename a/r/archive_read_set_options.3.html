archive_read_set_options(3)

Paquet: libarchive

Licences: BSD-2-Clause

ARCHIVE_READ_OPTIONS(3) Manuel des fonctions de bibliothèque ARCHIVE_READ_OPTIONS(3)

NOM

archive_read_set_filter_option, archive_read_set_format_option, archive_read_set_option, archive_read_set_options — fonctions contrôlant les options pour la lecture des archives

BIBLIOTHÈQUE

Bibliothèque d'archives en flux (libarchive, -larchive)

SYNOPSIS

int
archive_read_set_filter_option(struct archive *, const char *module, const char *option, const char *value);

int
archive_read_set_format_option(struct archive *, const char *module, const char *option, const char *value);

int
archive_read_set_option(struct archive *, const char *module, const char *option, const char *value);

int
archive_read_set_options(struct archive *, const char *options);

DESCRIPTION

Ces fonctions fournissent un moyen aux clients libarchive de configurer des modules de lecture spécifiques.

archive_read_set_filter_option(), archive_read_set_format_option()
Spécifie une option qui sera passée aux filtres actuellement enregistrés (y compris les filtres de décompression) ou aux lecteurs de format.

Si option et value sont tous deux NULL, ces fonctions ne feront rien et ARCHIVE_OK sera retourné. Si option est NULL mais value ne l'est pas, ces fonctions ne feront rien et ARCHIVE_FAILED sera retourné.

Si module n'est pas NULL, option et value seront fournis au filtre ou au lecteur nommé module. La valeur de retour sera celle du module. S'il n'y a pas de tel module, ARCHIVE_FAILED sera retourné.

Si module est NULL, option et value seront fournis à chaque module enregistré. Si un module retourne ARCHIVE_FATAL, cette valeur sera retournée immédiatement. Sinon, ARCHIVE_OK sera retourné si un module accepte l'option, et ARCHIVE_FAILED dans tous les autres cas.

archive_read_set_option()
Appelle archive_read_set_format_option(), puis archive_read_set_filter_option(). Si l'une ou l'autre fonction retourne ARCHIVE_FATAL, ARCHIVE_FATAL sera retourné immédiatement. Sinon, la plus grande des deux valeurs sera retournée.
archive_read_set_options()
options est une liste d'options séparées par des virgules. Si options est NULL ou vide, ARCHIVE_OK sera retourné immédiatement.

Appelle archive_read_set_option() avec chaque option à tour de rôle. Si un appel à archive_read_set_option() retourne ARCHIVE_FATAL, ARCHIVE_FATAL sera retourné immédiatement.

Les options individuelles ont l'une des formes suivantes :

option=valeur
La paire option/valeur sera fournie à chaque module. Les modules qui n'acceptent pas une option de ce nom l'ignoreront.
option
L'option sera fournie à chaque module avec la valeur « 1 ».
!option
L'option sera fournie à chaque module avec une valeur NULL.
module:option=valeur, module:option, module:!option
Comme ci-dessus, mais l'option et la valeur correspondantes ne seront fournies qu'aux modules dont le nom correspond à module.
