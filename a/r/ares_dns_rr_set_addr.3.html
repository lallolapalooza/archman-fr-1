DESCRIPTION

La fonction ares_dns_record_rr_cnt(3) retourne le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section fournie dans le paramètre sect.

La fonction ares_dns_record_rr_add(3) ajoute une nouvelle entrée d'enregistrement de ressource à l'enregistrement DNS fourni par le paramètre dnsrec. L'enregistrement de ressource résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle l'enregistrement de ressource appartient est spécifiée par le paramètre sect. Le nom de domaine associé à l'enregistrement de ressource est spécifié par le paramètre name, qui ne peut pas être NULL mais peut être une chaîne vide, ou ".". Le type d'enregistrement de ressource est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le temps de vie (TTL) dans le paramètre ttl.

Les fonctions ares_dns_record_rr_get(3) et ares_dns_record_rr_get_const(3) sont utilisées pour récupérer le pointeur de l'enregistrement de ressource à partir de l'enregistrement DNS fourni dans le paramètre dnsrec, pour la section d'enregistrement de ressource fournie dans le paramètre sect, pour l'index spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_rr_cnt(3). La première retourne un pointeur modifiable vers l'enregistrement de ressource, tandis que la seconde retourne un pointeur en lecture seule vers l'enregistrement de ressource.

La fonction ares_dns_record_rr_del(3) est utilisée pour supprimer un enregistrement de ressource de l'enregistrement DNS spécifié dans le paramètre dnsrec. Son utilisation principale est de supprimer un enregistrement ARES_REC_TYPE_OPT lors de la nécessité de retenter une requête sans prise en charge EDNS. La section RR DNS est spécifiée via le paramètre sect, et l'index à supprimer est spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_rr_cnt(3).

La fonction ares_dns_rr_get_name(3) est utilisée pour récupérer le nom de domaine de l'enregistrement de ressource à partir du pointeur d'enregistrement de ressource fourni dans le paramètre rr.

La fonction ares_dns_rr_get_type(3) est utilisée pour récupérer le type d'enregistrement de ressource à partir du pointeur d'enregistrement de ressource fourni dans le paramètre rr.

La fonction ares_dns_rr_get_class(3) est utilisée pour récupérer la classe d'enregistrement de ressource à partir du pointeur d'enregistrement de ressource fourni dans le paramètre rr.

La fonction ares_dns_rr_get_ttl(3) est utilisée pour récupérer le Temps de Vie (TTL) de la classe d'enregistrement de ressource à partir du pointeur d'enregistrement de ressource fourni dans le paramètre rr.

La fonction ares_dns_rr_set_addr(3) est utilisée pour définir une adresse IPv4 pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_INADDR. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre addr.

La fonction ares_dns_rr_set_addr6(3) est utilisée pour définir une adresse IPv6 pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_INADDR6. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre addr.

La fonction ares_dns_rr_set_str(3) est utilisée pour définir une chaîne de caractères pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_STR ou ARES_DATATYPE_NAME. La plupart des chaînes sont limitées à 255 octets, cependant certains enregistrements, tels qu'un enregistrement TXT, peuvent autoriser des longueurs plus importantes car ils sont affichés sous forme de plusieurs chaînes. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre val.

DESCRIPTION

Les fonctions ares_dns_record_rr_add(3) et ares_dns_record_rr_del(3) sont utilisées pour ajouter et supprimer des enregistrements de ressources (RR) dans un enregistrement DNS donné, respectivement. L'enregistrement DNS à modifier est fourni dans le paramètre dns_record. Le nom de domaine à ajouter/supprimer est fourni dans le paramètre name, le type d'enregistrement est fourni dans le paramètre type et la classe d'enregistrement est fournie dans le paramètre klass. Si l'enregistrement est ajouté, la valeur de l'enregistrement est fournie dans le paramètre value.

Les fonctions ares_dns_rr_get_name(3), ares_dns_rr_get_type(3), ares_dns_rr_get_class(3), et ares_dns_rr_get_ttl(3) sont utilisées pour récupérer respectivement le nom, le type, la classe et le TTL (Time To Live) d'un enregistrement de ressource. L'enregistrement de ressource à partir duquel récupérer est fourni dans le paramètre dns_rr.

Les fonctions ares_dns_rr_set_addr(3) et ares_dns_rr_set_addr6(3) sont utilisées pour définir une adresse IPv4 et IPv6 respectivement dans un enregistrement de ressource lorsque le type de données est ARES_DATATYPE_INADDR et ARES_DATATYPE_INADDR6. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, le nom d'hôte est fourni dans le paramètre name et l'adresse est fournie dans le paramètre addr.

Les fonctions ares_dns_rr_set_str(3), ares_dns_rr_set_u8(3), ares_dns_rr_set_u16(3) et ares_dns_rr_set_u32(3) sont utilisées pour définir respectivement une chaîne de caractères, un entier 8 bits, un entier 16 bits et un entier 32 bits dans un enregistrement de ressource. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr et la valeur est fournie dans le paramètre value.

La fonction ares_dns_rr_set_bin(3) est utilisée pour définir des données binaires dans un enregistrement de ressource lorsque le type de données est ARES_DATATYPE_BIN ou ARES_DATATYPE_BINP. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, et les données binaires sont fournies dans le paramètre value avec la longueur fournie dans value_len.

Les fonctions ares_dns_rr_add_abin(3) et ares_dns_rr_del_abin(3) sont utilisées pour ajouter et supprimer des entrées de données binaires d'un tableau dans un enregistrement de ressource lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr. Pour ajouter, la valeur est fournie dans value avec la longueur dans value_len. Pour supprimer, l'index de l'entrée à supprimer est fourni dans le paramètre idx.

La fonction ares_dns_rr_set_opt(3) est utilisée pour définir des clés et des valeurs d'option/paramètre pour l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr. La clé/paramètre est fournie dans le paramètre key. La valeur d'option/paramètre spécifique à l'enregistrement de ressource est fournie dans le paramètre opt, et il appartient à l'utilisateur de déterminer la valeur appropriée à utiliser. Certaines valeurs connues peuvent être fournies par les énumérations ares_svcb_param_t et ares_opt_param_t. La valeur de l'option est toujours fournie sous forme binaire dans val avec la longueur fournie dans val_len.

La fonction ares_dns_rr_del_opt_byid(3) est utilisée pour supprimer des clés et des valeurs d'option/paramètre pour l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr. La clé/paramètre est fournie dans le paramètre key. La valeur d'option/paramètre spécifique à l'enregistrement de ressource est fournie dans le paramètre opt. Cette fonction retourne ARES_SUCCESS si l'enregistrement est supprimé avec succès, ou ARES_ENOTFOUND si l'enregistrement n'a pas pu être trouvé.

La fonction ares_dns_rr_get_addr(3) est utilisée pour récupérer l'adresse IPv4 de l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_INADDR. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_addr6(3) est utilisée pour récupérer l'adresse IPv6 de l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_INADDR6. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_str(3) est utilisée pour récupérer une chaîne de caractères de l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_STR ou ARES_DATATYPE_NAME. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_u8(3) est utilisée pour récupérer un entier 8 bits de l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_U8. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_u16(3) est utilisée pour récupérer un entier 16 bits de l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_U16. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_u32(3) est utilisée pour récupérer un entier 32 bits de l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_U32. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_bin(3) est utilisée pour récupérer des données binaires de l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_BIN ou ARES_DATATYPE_BINP. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key, et la longueur est stockée dans la variable pointée par len.

La fonction ares_dns_rr_get_abin_cnt(3) est utilisée pour récupérer le nombre d'éléments du tableau de valeurs binaires stockées à partir de l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_abin(3) est utilisée pour récupérer des données binaires du tableau d'enregistrements de ressource lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key, et l'index à partir duquel récupérer dans le tableau est fourni par le paramètre idx, et la longueur est stockée dans la variable pointée par len.

La fonction ares_dns_rr_get_opt_cnt(3) est utilisée pour récupérer le nombre d'options/paramètres associés à l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans key.

La fonction ares_dns_rr_get_opt(3) est utilisée pour récupérer des données d'option binaires de l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_OPT pour l'index spécifié. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key, l'index à partir duquel récupérer les données d'option est fourni dans le paramètre idx. La valeur est stockée dans la variable pointée par val et la longueur est stockée dans la variable pointée par val_len.

La fonction ares_dns_rr_get_opt_byid(3) est utilisée pour récupérer des données d'option binaires de l'enregistrement de ressource lorsque le type de données est ARES_DATATYPE_OPT pour l'identifiant d'option spécifié, s'il existe. L'enregistrement de ressource est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key, l'identifiant à partir duquel récupérer les données d'option est fourni dans le paramètre opt. La valeur est stockée dans la variable pointée par val et la longueur est stockée dans la variable pointée par val_len.

RETURN VALUES

ares_dns_record_rr_cnt(3) et ares_dns_rr_get_opt_cnt(3) retournent les comptes respectifs.

ares_dns_record_rr_add(3), ares_dns_record_rr_del(3), ares_dns_rr_set_addr(3), ares_dns_rr_set_addr6(3), ares_dns_rr_set_str(3), ares_dns_rr_set_u8(3), ares_dns_rr_set_u16(3), ares_dns_rr_set_u32(3), ares_dns_rr_set_bin(3), ares_dns_rr_add_abin(3), ares_dns_rr_del_abin(3), et ares_dns_rr_set_opt(3) retournent tous un code d'erreur ares_status_t. ARES_SUCCESS est retourné en cas de succès, ARES_ENOMEM est retourné en cas de manque de mémoire, ARES_EFORMERR est retourné en cas de mauvaise utilisation.

ares_dns_rr_get_name(3), ares_dns_rr_get_type(3), ares_dns_rr_get_class(3), ares_dns_rr_get_ttl(3), ares_dns_rr_get_addr(3), ares_dns_rr_get_addr6(3), ares_dns_rr_get_str(3), ares_dns_rr_get_u8(3), ares_dns_rr_get_u16(3), ares_dns_rr_get_u32(3), ares_dns_rr_get_bin(3), ares_dns_rr_get_abin_cnt(3), ares_dns_rr_get_abin(3), ares_dns_rr_get_opt(3) retournent leurs valeurs de type de données prescrites et en général ne peuvent pas échouer sauf en cas de mauvaise utilisation, auquel cas un 0 (ou NULL) peut être retourné, cependant 0 peut aussi être une valeur de retour valide pour la plupart de ces fonctions.

ares_dns_record_rr_get(3) et ares_dns_record_rr_get_const(3) retourneront le pointeur d'enregistrement de ressource demandé ou NULL en cas d'échec (mauvaise utilisation).

ares_dns_rr_get_opt_byid(3) retournera ARES_TRUE si l'option a été trouvée, sinon ARES_FALSE si elle n'a pas été trouvée (ou en cas de mauvaise utilisation).
