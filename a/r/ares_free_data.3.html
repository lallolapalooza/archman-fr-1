ARES_FREE_DATA(3) Manuel des fonctions de bibliothèque ARES_FREE_DATA(3)

NOM

ares_free_data - Libérer les données allouées par plusieurs fonctions c-ares

SYNTAXE

#include <ares.h>
void ares_free_data(void *dataptr)

DESCRIPTION

La fonction ares_free_data(3) libère une ou plusieurs structures de données allouées et retournées par plusieurs fonctions c-ares. Spécifiquement, les données retournées par la liste suivante de fonctions doivent être désallouées en utilisant cette fonction.

ares_get_servers(3)
Lorsqu'elle est utilisée pour libérer les données retournées par ares_get_servers(3), cela libérera toute la liste chaînée des structures ares_addr_node retournées par ares_get_servers(3).
ares_parse_srv_reply(3)
Lorsqu'elle est utilisée pour libérer les données retournées par ares_parse_srv_reply(3), cela libérera toute la liste chaînée des structures ares_srv_reply retournées par ares_parse_srv_reply(3), ainsi que tout stockage supplémentaire associé à ces structures.
ares_parse_mx_reply(3)
Lorsqu'elle est utilisée pour libérer les données retournées par ares_parse_mx_reply(3), cela libérera toute la liste chaînée des structures ares_mx_reply retournées par ares_parse_mx_reply(3), ainsi que tout stockage supplémentaire associé à ces structures.
ares_parse_txt_reply(3)
Lorsqu'elle est utilisée pour libérer les données retournées par ares_parse_txt_reply(3), cela libérera toute la liste chaînée des structures ares_txt_reply retournées par ares_parse_txt_reply(3), ainsi que tout stockage supplémentaire associé à ces structures.
ares_parse_soa_reply(3)
Lorsqu'elle est utilisée pour libérer les données retournées par ares_parse_soa_reply(3), cela libérera la structure ares_soa_reply, ainsi que tout stockage supplémentaire associé à cette structure. ares_parse_uri_reply(3) Lorsqu'elle est utilisée pour libérer les données retournées par ares_parse_uri_reply(3), cela libérera la liste des structures ares_uri_reply, ainsi que tout stockage supplémentaire associé à ces structures.

VALEUR DE RETOUR

La fonction ares_free_data(3) ne retourne pas de valeur.

DISPONIBILITÉ

Cette fonction a été introduite pour la première fois dans la version 1.7.0 de c-ares.

VOIR AUSSI

ares_get_servers(3), ares_parse_srv_reply(3), ares_parse_mx_reply(3), ares_parse_txt_reply(3), ares_parse_soa_reply(3)
