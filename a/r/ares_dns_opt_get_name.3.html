ares_dns_datatype_t - Types de données associés à ares_dns_rr_key_t:

ARES_DATATYPE_INADDR - Adresse IPv4 sous forme de struct in_addr *. Utilisez ares_dns_rr_set_addr(3) pour définir et ares_dns_rr_get_addr(3) pour obtenir.
ARES_DATATYPE_INADDR6 - Adresse IPv6 sous forme de struct ares_in6_addr *. Utilisez ares_dns_rr_set_addr6(3) pour définir et ares_dns_rr_get_addr6(3) pour obtenir.
ARES_DATATYPE_U8 - Entier non signé de 8 bits. Utilisez ares_dns_rr_set_u8(3) pour définir et ares_dns_rr_get_u8(3) pour obtenir.
ARES_DATATYPE_U16 - Entier non signé de 16 bits. Utilisez ares_dns_rr_set_u16(3) pour définir et ares_dns_rr_get_u16(3) pour obtenir.
ARES_DATATYPE_U32 - Entier non signé de 32 bits. Utilisez ares_dns_rr_set_u32(3) pour définir et ares_dns_rr_get_u32(3) pour obtenir.
ARES_DATATYPE_NAME - Chaîne terminée par un caractère nul représentant un nom de domaine (série d'étiquettes). Utilisez ares_dns_rr_set_str(3) pour définir et ares_dns_rr_get_str(3) pour obtenir.
ARES_DATATYPE_STR - Chaîne terminée par un caractère nul. Utilisez ares_dns_rr_set_str(3) pour définir et ares_dns_rr_get_str(3) pour obtenir.
ARES_DATATYPE_BIN - Données binaires. Utilisez ares_dns_rr_set_bin(3) pour définir et ares_dns_rr_get_bin(3) pour obtenir.
ARES_DATATYPE_BINP - Officiellement défini comme des données binaires, mais probablement imprimables. Garantit d'avoir un terminateur NULL par commodité (non inclus dans la longueur). Utilisez ares_dns_rr_set_bin(3) pour définir et ares_dns_rr_get_bin(3) pour obtenir.
ARES_DATATYPE_OPT - Tableau d'options. Identifiant de 16 bits, données binaires. Utilisez ares_dns_rr_set_opt(3) pour définir et ares_dns_rr_get_opt(3) pour obtenir.
ARES_DATATYPE_ABINP - Tableau de données binaires, mais probablement imprimables. Garantit d'avoir un terminateur NULL par commodité (non inclus dans la longueur). Utilisez ares_dns_rr_add_abin(3) pour définir et ares_dns_rr_get_abin(3) pour obtenir. Vous pouvez également utiliser ares_dns_rr_set_bin(3) et ares_dns_rr_get_bin(3) si vous souhaitez uniquement des chaînes concaténées.

ares_dns_opt_datatype_t - Types de données associés aux ARES_DATATYPE_OPT paramètres si connus, tels que renvoyés par ares_dns_opt_get_datatype(3):

ARES_OPT_DATATYPE_NONE - Aucune valeur autorisée pour ce paramètre
ARES_OPT_DATATYPE_STR_LIST - Liste de chaînes, chacune préfixée par un octet unique représentant la longueur comme défini par la RFC 1035. Vous pouvez utiliser ares_expand_string(3) jusqu'à ce que le tampon soit consommé.
ARES_OPT_DATATYPE_U8_LIST - Liste d'entiers non signés de 8 bits, concaténés
ARES_OPT_DATATYPE_U16 - Entier non signé de 16 bits dans l'ordre des octets réseau
ARES_OPT_DATATYPE_U16_LIST - Liste d'entiers non signés de 16 bits dans l'ordre des octets réseau, concaténés.
ARES_OPT_DATATYPE_U32 - Entier non signé de 32 bits dans l'ordre des octets réseau
ARES_OPT_DATATYPE_U32_LIST - Liste d'entiers non signés de 16 bits dans l'ordre des octets réseau, concaténés.
ARES_OPT_DATATYPE_INADDR4_LIST - Liste d'adresses IPv4 dans l'ordre des octets réseau, concaténées
ARES_OPT_DATATYPE_INADDR6_LIST - Liste d'adresses IPv6 dans l'ordre des octets réseau, concaténées
ARES_OPT_DATATYPE_BIN - Données binaires
ARES_OPT_DATATYPE_NAME - Format binaire du nom de domaine DNS tel que défini dans la RFC1035, vous pouvez utiliser ares_expand_name(3)

DESCRIPTION

The ares_dns_rec_type_tostr(3) function outputs a human readable DNS record type from its numeric form passed in type.

The ares_dns_class_tostr(3) function outputs a human readable DNS class from its numeric form passed in qclass.

The ares_dns_opcode_tostr(3) function outputs a human readable DNS opcode from its numeric form in opcode.

The ares_dns_rr_key_tostr(3) function outputs a human readable DNS Resource Record parameter name from its numeric form in key.

The ares_dns_section_tostr(3) function outputs a human readable DNS message section from its numeric form in section.

The ares_dns_rcode_tostr(3) function outputs a human readable DNS response code from its numeric form in rcode.

The ares_dns_class_fromstr(3) function outputs the DNS class in numeric from from its string representation in str. The result is stored into the variable pointed to by qclass.

The ares_dns_rec_type_fromstr(3) function outputs the DNS record type in numeric from from its string representation in str. The result is stored into the variable pointed to by qtype.

The ares_dns_rr_get_keys(3) function retrieves a list of parameters that may be set or retrieved for the provided type. The count of returned keys is stored into the variable pointed to by cnt.

The ares_dns_rr_key_datatype(3) function retrieves the associated datatype for an RR parameter specified by key.

The ares_dns_rr_key_to_rec_type(3) function dereferences the provided RR parameter specified by key to the DNS Record Type it belongs.

The ares_dns_opt_get_datatype(3) function is used in association with ares_dns_rr_set_opt(3) and ares_dns_rr_get_opt(3) to retrieve the datatype of an option record contained within an RR as specified in key if it is known. The raw option record identifier is provided by opt.

The ares_dns_opt_get_name(3) function is used in association with ares_dns_rr_set_opt(3) and ares_dns_rr_get_opt(3) to retrieve human readable parameter name of an option record contained within an RR as specified in key if it is known. The raw option record identifier is provided by opt.

RETURN VALUES

ares_dns_rec_type_tostr(3), ares_dns_class_tostr(3), ares_dns_opcode_tostr(3), ares_dns_rr_key_tostr(3), ares_dns_section_tostr(3), ares_dns_rcode_tostr(3), and ares_dns_opt_get_name(3) all return a human printable ASCII string, or NULL on error.

ares_dns_class_fromstr(3) and ares_dns_rec_type_fromstr(3) return ARES_TRUE on successful conversion, otherwise ARES_FALSE.

ares_dns_rr_get_keys(3) returns an array of keys or NULL on failure.

ares_dns_rr_key_datatype(3), ares_dns_rr_key_to_rec_type(3), and ares_dns_opt_get_datatype(3) return their respective integer values, or 0 on failure.

AVAILABILITY

These functions were first introduced in c-ares version 1.22.0.
