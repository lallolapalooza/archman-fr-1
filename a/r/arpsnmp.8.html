ARPSNMP(8) Manuel de l'administrateur système ARPSNMP(8)

NOM

arpsnmp — maintenir la trace des associations d'adresses Ethernet/IP

SYNTAXE

arpsnmp [-dqs] [-D répertoired'arp] [-f fichierdedonnées] [-w watcher@email] [-W expediteur@email] fichier ...

DESCRIPTION

arpsnmp maintient la trace des associations d'adresses Ethernet/IP. Il enregistre l'activité dans le journal système et signale certains changements par e-mail. arpsnmp lit les informations à partir d'un fichier (généralement généré par snmpwalk(3)).

Le format du fichier d'entrée est le même que celui de arp.dat ; l'adresse MAC, l'adresse IP, un horodatage optionnel et un nom d'hôte simple optionnel. Si l'horodatage est manquant, la date actuelle est utilisée.

arpsnmp peut également être utilisé pour fusionner des fichiers. Si la même association adresse Ethernet/adresse IP apparaît dans plus d'un fichier, l'horodatage de la dernière occurrence est enregistré.

L'option -C utilise des adresses Ethernet compactes et rembourrées dans arp.dat, par exemple 0:8:e1:1:2:d6.

L'option -d est utilisée pour activer le débogage. Cela empêche également l'envoi par e-mail des rapports. Au lieu de cela, ils sont envoyés à stderr.

L'option -D est utilisée pour spécifier le répertoire de travail. Par défaut, c'est /usr/local/arpwatch.

L'option -f est utilisée pour définir le nom du fichier de la base de données des adresses Ethernet/IP. Par défaut, c'est arp.dat.

Notez qu'un fichier vide doit être créé avant la première exécution de

L'option -q supprime l'enregistrement ou l'impression des rapports dans stderr.

L'option -s supprime les rapports envoyés par e-mail.

L'option -w est utilisée pour spécifier l'adresse cible des rapports par e-mail. Par défaut, c'est root.

L'option -W est utilisée pour spécifier l'adresse d'expéditeur des rapports par e-mail. Par défaut, c'est root.

L'option -Z utilise des adresses Ethernet rembourrées de zéros dans arp.dat, par exemple 00:08:e1:01:02:d6.

MESSAGES DE RAPPORT

Voir la page de manuel de arpwatch(1) pour plus de détails sur les messages de rapport générés par arpsnmp(1).

FICHIERS

BOGUES

Veuillez envoyer les rapports de bogues à ⟨arpwatch@ee.lbl.gov⟩.

Il n'y a aucun intérêt à alimenter arpsnmp avec le fichier arp.dat.

Des tentatives sont faites pour supprimer les basculements DECnet, mais elles ne sont pas toujours couronnées de succès.
