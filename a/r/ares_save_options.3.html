ares_save_options(3)

ARES_SAVE_OPTIONS(3) Manuel des fonctions de bibliothèque ARES_SAVE_OPTIONS(3)

NOM

ares_save_options - Enregistre les valeurs de configuration obtenues du canal ares initialisé

SYNTAXE

#include <ares.h>
int ares_save_options(const ares_channel_t *channel,
                      struct ares_options *options, int *optmask)

DESCRIPTION

La fonction ares_save_options(3) enregistre les données du canal identifié par channel, dans la structure d'options identifiée par options, et enregistre le masque des options qui sont définies dans le pointeur entier (passé par référence) identifié par optmask.

Les options et le masque d'options résultants peuvent alors être passés directement à ares_init_options. Lorsque les options ne sont plus nécessaires, ares_destroy_options doit être appelée pour libérer toute mémoire associée.

VALEURS DE RETOUR

ares_save_options(3) peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
Les données du canal ont été stockées avec succès
ARES_ENOMEM
La mémoire a été épuisée
ARES_ENODATA
Les données du canal identifiées par channel étaient invalides.

NOTE

Depuis c-ares 1.6.0, la structure ares_options est « verrouillée », ce qui signifie qu'elle ne sera pas étendue pour couvrir de nouvelles fonctions. Cette fonction continuera de fonctionner, mais elle ne pourra retourner que les données de configuration pouvant être représentées dans cette structure de configuration, ce qui peut ne plus être l'ensemble complet des options de configuration. ares_dup(3) n'aura pas cette restriction.

La structure ares_options ne peut pas gérer les serveurs de noms IPv6 potentiels que le canal ares pourrait être configuré pour utiliser. La fonction ares_save_options(3) ne retournera que les serveurs IPv4, le cas échéant. Afin de récupérer tous les serveurs de noms qu'un canal ares pourrait utiliser, la fonction ares_get_servers(3) doit être utilisée à la place.

VOIR AUSSI

ares_destroy_options(3), ares_init_options(3), ares_get_servers(3), ares_dup(3)

DISPONIBILITE

ares_save_options(3) a été ajoutée dans c-ares 1.4.0
