NOM

Archive::Zip::MemberRead - Un wrapper qui permet de lire des membres d'archives Zip comme s'il s'agissait de fichiers.

SYNTAXE

use Archive::Zip;
use Archive::Zip::MemberRead;
$zip = Archive::Zip->new("file.zip");
$fh  = Archive::Zip::MemberRead->new($zip, "subdir/abc.txt");
while (defined($line = $fh->getline()))
{
    print $fh->input_line_number . "#: $line\n";
}
$read = $fh->read($buffer, 32*1024);
print "Lu $read octets comme :$buffer:\n";

DESCRIPTION

Le module Archive::Zip::MemberRead vous permet de lire les données des membres d'archives Zip comme vous lisez des données à partir de fichiers.

MÉTHODES

Archive::Zip::Member::readFileHandle()
Vous pouvez obtenir une "Archive::Zip::MemberRead" à partir d'un membre d'archive en appelant readFileHandle() : 
my $member = $zip->memberNamed('abc/def.c');
my $fh = $member->readFileHandle();
while (defined($line = $fh->getline()))
{
    # ...
}
$fh->close();
Archive::Zip::MemberRead->new($zip, $fileName)
Archive::Zip::MemberRead->new($zip, $member)
Archive::Zip::MemberRead->new($member)
Construit une nouvelle Archive::Zip::MemberRead sur le membre spécifié. 
my $fh = Archive::Zip::MemberRead->new($zip, 'fred.c')
setLineEnd(expr)
Définit le caractère de fin de ligne à utiliser. Il est défini à \n par défaut, sauf sur les systèmes Windows où il est défini à \r\n. Vous n'aurez besoin de le définir que sur les systèmes qui ne sont pas basés sur Windows ou Unix et qui nécessitent une fin de ligne différente de \n. Il s'agit d'une méthode de classe, donc appelez-la comme "Archive::Zip::MemberRead"->setLineEnd($nl)
rewind()
Rembobine une "Archive::Zip::MemberRead" afin que vous puissiez la lire à nouveau à partir du début.
input_record_separator(expr)
Si l'argument est fourni, l'input_record_separator pour cette instance y est défini. Le réglage actuel (qui peut être le global $/) est toujours renvoyé.
input_line_number()
Renvoie le numéro de ligne actuel, mais uniquement si vous utilisez getline(). L'utilisation de read() ne mettra pas à jour le numéro de ligne.
close()
Ferme le descripteur de fichier donné.
buffer_size([ $size ])
Obtient ou définit la taille du tampon utilisé pour les lectures. La valeur par défaut est la taille de bloc utilisée par Archive::Zip.
getline()
Renvoie la ligne suivante du membre actuellement ouvert. N'a de sens que pour les fichiers texte. Une erreur de lecture est considérée comme suffisamment critique pour provoquer une mort. Renvoie undef en fin de fichier (eof). Tous les appels suivants renverraient undef, sauf si un rewind() est appelé. Note : La ligne renvoyée a le séparateur d'enregistrement d'entrée (par défaut : nouvelle ligne) supprimé.
getline( { preserve_line_ending => 1 } )
Renvoie la ligne suivante, y compris la fin de ligne.
read($buffer, $num_bytes_to_read)
Simule un appel système read() normal. Renvoie le nombre d'octets lus. "undef" en cas d'erreur, 0 en fin de fichier (eof), par exemple : 
$fh = Archive::Zip::MemberRead->new($zip, "sreeji/secrets.bin");
while (1)
{
  $read = $fh->read($buffer, 1024);
  die "ERREUR FATALE lors de la lecture de mes secrets !\n" if (!defined($read));
  last if (!$read);
  # Effectuer le traitement.
  ....
 }
