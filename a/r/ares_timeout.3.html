ARES_TIMEOUT(3) Manuel des fonctions de bibliothèque ARES_TIMEOUT(3)

NOM

ares_timeout - retourner le temps maximum d'attente

SYNTAXE

#include <ares.h>
struct timeval *ares_timeout(const ares_channel_t *channel,
                             struct timeval *maxtv,
                             struct timeval *tv)

DESCRIPTION

La fonction ares_timeout(3) détermine le temps maximum pendant lequel l'appelant doit attendre avant d'invoquer ares_process(3) pour traiter les délais d'attente. Le paramètre maxtv spécifie un délai d'attente maximum existant, ou NULL si l'appelant ne souhaite pas appliquer de délai d'attente maximum. Le paramètre tv doit pointer vers un tampon inscriptible de type struct timeval. Il est valide que maxtv et tv aient la même valeur.

Si aucune requête n'a de délai d'attente en attente plus tôt que le délai d'attente maximum donné, ares_timeout(3) retourne la valeur de maxtv ; sinon, ares_timeout(3) stocke la valeur de délai d'attente appropriée dans le tampon pointé par tv et retourne la valeur de tv.

VOIR AUSSI

ares_fds(3), ares_process(3), ares_process_fd(3)
