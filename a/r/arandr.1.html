Nom

arandr - interface graphique pour XRandR 1.2

Syntaxe

arandr [fichier_enregistre]

Description

ARandR est une interface visuelle pour XRandR 1.2 (options par écran), qui offre un contrôle complet sur le positionnement, l'enregistrement et le chargement depuis/vers des scripts shell, et une intégration facile avec d'autres applications.

--version
afficher le numéro de version du programme et quitter
-h, --help
afficher ce message d'aide et quitter
--randr-display=D
Utiliser D comme affichage pour xrandr (mais toujours afficher l'interface graphique sur l'affichage de l'environnement ; par ex. localhost:10.0)
--force-version
Même exécuter avec des versions XRandR non testées
