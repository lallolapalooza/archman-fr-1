argbash(1) Manuel des commandes générales argbash(1)

Nom

argbash - Argbash est un générateur d'analyseur d'arguments pour Bash.

SYNTAXE

argbash [--output OUTPUT] [--in-place] [--type type] [--library] [--strip content] [--check-typos] [--commented] [--search SEARCH]... [--debug DEBUG] [--help] [--version] <input>

DESCRIPTION

Argbash est un générateur de code qui génère généralement une bibliothèque d'analyse d'arguments bash adaptée à votre script. Il vous permet de décrire les arguments que votre script doit accepter, puis vous pouvez générer le code d'analyse bash. Il reste dans votre script par défaut, mais vous pouvez le générer dans un fichier séparé et laisser bash l'inclure dans votre script. Argbash est très simple à utiliser et le code généré est relativement agréable à lire. De plus, les définitions d'arguments restent intégrées au script, donc lorsque vous devez mettre à jour la logique d'analyse, il vous suffit de réexécuter le script argbash sur le script déjà généré.

ARGUMENTS

-o SORTIE, --output SORTIE
Nom du fichier de sortie (utilisez '-' pour la sortie standard). [Défaut : -]
-i, --in-place
Mettre à jour un script bash sur place. [Défaut : désactivé]
-t bash-script|posix-script|manpage|manpage-defs|completion|docopt|excised, --type bash-script|posix-script|manpage|manpage-defs|completion|docopt|excised Type de sortie à générer.
[Défaut : bash-script]

Consultez la documentation pour en savoir plus sur toutes les capacités d'argbash prises en charge.

--library
Indique si le fichier d'entrée est la bibliothèque d'analyse pure. [Défaut : désactivé]

Cette option est dépréciée et équivaut à --strip user-content.

--strip none|user-content|all Détermine ce qu'il faut inclure dans la sortie.
[Défaut : none]

Vous pouvez choisir de supprimer none, ce qui est utile pour les scripts. Si vous supprimez user-content, vous conservez l'en-tête Argbash. Si vous supprimez all, vous n'aurez que le contenu généré dans le résultat.

--check-typos
Vérifie les fautes de frappe potentielles dans les macros argbash. [Défaut : activé]
-c, --commented
Mode commenté - inclure des commentaires explicatifs avec le code d'analyse. [Défaut : désactivé]
-I RECHERCHE, --search RECHERCHE
Répertoires à rechercher pour les scripts enveloppés (le répertoire du modèle sera ajouté à la fin de la liste). [Défaut : "."]
--debug DEBUG
(option développeur) Demande à autom4te de tracer une macro.
-h, --help
Affiche l'aide.
-v, --version
Affiche la version.
