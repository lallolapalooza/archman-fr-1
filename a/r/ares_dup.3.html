NOM

ares_dup - Dupliquer un canal de résolution

SYNOPSIS

#include <ares.h>
int ares_dup(ares_channel_t **dest, const ares_channel_t *source)

DESCRIPTION

La fonction ares_dup(3) duplique un canal de communication existant pour les recherches de noms de service. Si elle renvoie un succès, ares_dup(3) affectera la variable pointée par dest à un descripteur utilisé pour identifier le canal de noms de service. L'appelant doit invoquer ares_destroy(3) sur le descripteur lorsque le canal n'est plus nécessaire.

VOIR AUSSI

ares_destroy(3), ares_init(3), ares_library_init(3)

DISPONIBILITÉ
