ares_library_init_android(3)

Paquet: c-ares

Licences: MIT

ARES_LIBRARY_INIT_ANDROID(3) Manuel des fonctions de bibliothèque ARES_LIBRARY_INIT_ANDROID(3)

NOM

ares_library_init_android - initialisation de la bibliothèque c-ares pour Android

SYNTAXE

#include <ares.h>
int ares_library_init_android(jobject connectivity_manager)
int ares_library_android_initialized();
void ares_library_init_jvm(JavaVM *jvm)

DESCRIPTION

La fonction ares_library_init_android(3) effectue les initialisations nécessaires en interne pour la bibliothèque c-ares lors de son utilisation sur Android. Cela peut avoir lieu à tout moment après ares_library_init(3). Elle doit avoir lieu après ares_library_init_jvm. ares_library_init_android doit être appelée avant que la résolution DNS ne fonctionne sur Android 8 (Oreo) ou plus récent lorsque targetSdkVersion est défini sur 26 ou plus.

À partir d'Android 8 (niveau d'API 26), l'obtention des informations sur les serveurs DNS est devenue plus restrictive et n'est accessible qu'en utilisant le Gestionnaire de connectivité. Il est nécessaire de passer le gestionnaire de connectivité à c-ares via JNI. De plus, la permission ACCESS_NETWORK_STATE doit être présente dans l'application Android.

Les versions d'Android antérieures à 8 n'ont pas besoin d'être initialisées car elles sont moins restrictives. Cependant, il s'agit d'une limitation d'exécution et non de compilation. Une initialisation Android appropriée devrait avoir lieu indépendamment de la version Android ciblée.

La désinitialisation aura lieu via ares_library_cleanup(3).

La fonction ares_library_init_jvm permet à l'appelant d'enregistrer la JVM auprès de c-ares. Elle est destinée à être appelée pendant JNI_OnLoad car vous êtes garanti d'avoir la JVM dans cette fonction. La JVM est requise pour pouvoir utiliser le Gestionnaire de connectivité enregistré à l'aide de ares_library_init_android(3). Elle doit être appelée avant ares_library_init_android(3).

La fonction ares_library_android_initialized peut être utilisée pour vérifier si c-ares a été initialisé pour une utilisation avec Android.

VALEURS DE RETOUR

ARES_SUCCESS sera renvoyé en cas de succès, sinon un code d'erreur sera renvoyé.

GESTION DES THREADS

Ces fonctions d'initialisation ne sont pas thread-safe. Vous devez les appeler une fois le programme démarré, mais cet appel doit être fait avant que le programme ne démarre d'autres threads. Ceci est requis pour éviter des conditions de concurrence potentielles lors de l'initialisation de la bibliothèque, et également parce que ces fonctions pourraient appeler des fonctions d'autres bibliothèques qui ne sont pas thread-safe, et pourraient entrer en conflit avec tout autre thread qui utilise déjà ces autres bibliothèques.

JNI

Accès au Gestionnaire de connectivité via Java :

Enregistrement de ares_library_android_init.

  static JNINativeMethod funcs[] = {
  { "initialize_native",     "(Landroid/net/ConnectivityManager;)I",
    (void *)&ares_library_init_android}
  };
  JNIEXPORT jint JNICALL JNI_OnLoad(JavaVM *vm, void *reserved)
  {
    JNIEnv *env = NULL;
    jclass  cls = NULL;
    jint    res;
    if ((*vm)->GetEnv(vm, (void **)&env, JNI_VERSION_1_6) != JNI_OK)
      return -1;
    cls = (*env)->FindClass(env, JNIT_CLASS);
    if (cls == NULL)
      return -1;
    res = (*env)->RegisterNatives(env, cls, funcs, sizeof(funcs)/sizeof(funcs[0]));
    if (res != 0)
      return -1;
    ares_library_init_jvm(vm);
    return JNI_VERSION_1_6;
  }
Appel de la fonction enregistrée depuis Java : 
  public class MyObject {
    static {
      System.loadLibrary("cares");
    }
    private static native boolean initialize_native(ConnectivityManager
      connectivity_manager);
    public static boolean initialize(Context context) {
      initialize_native((ConnectivityManager)context.getSystemService(Context.CONNECTIVITY_SERVICE));
    }
  }

Initialisation du Gestionnaire de connectivité en JNI directement à l'aide d'un Contexte Android. On suppose que la JVM a déjà été enregistrée via JNI_OnLoad.

  void initialize(jobject android_context)
  {
    jclass obj_cls = jni_get_class(env, "android/content/Context");
    jmethodID obj_mid = jni_get_method_id(env, obj_cls, "getSystemService", "(Ljava/lang/String;)Ljava/lang/Object;");
    jfieldID fid = (*env)->GetStaticFieldID(env, obj_cls, "CONNECTIVITY_SERVICE", "Ljava/lang/String;");
    jstring str = (*env)->GetStaticObjectField(env, obj_cls, fid);
    connectivity_manager = (*env)->CallObjectMethod(env, android_context, obj_mid, str);
    if (connectivity_manager == NULL)
      return;
    ares_library_init_android(connectivity_manager);
  }

DISPONIBILITÉ

Cette fonction a été introduite pour la première fois dans la version 1.15.0 de c-ares.
