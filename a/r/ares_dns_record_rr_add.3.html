3)

The renvoie le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section fournie dans le paramètre sect. La fonction ares_dns_record_rr_add(3)

ajoute

une nouvelle entrée d'enregistrement de ressources à l'enregistrement DNS fourni par le paramètre dnsrec. L'enregistrement de ressources résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle appartient l'enregistrement de ressources est spécifiée par le paramètre sect. Le type d'enregistrement de ressources est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le Time To Live (TTL) dans le paramètre ttl. ares_dns_record_rr_add(3)

ares_dns_record_rr_add - function to add an RR record to a DNS record structure.

Synopsis

#include <ares.h>

int
ares_dns_record_rr_add(ares_dns_record_t *record,
                       ares_dns_record_t *rr);

Description

The ares_dns_record_rr_add function is used to add a Resource Record (RR) structure pointed to by rr to the RR list of the DNS record structure pointed to by record.

The record argument should be a pointer to a valid ares_dns_record_t structure that represents a DNS query response. The rr argument should be a pointer to another valid ares_dns_record_t structure that represents the RR to be added.

The function appends the rr structure to the end of the list of RRs within the record structure.

Note that this function does not create a deep copy of the rr structure. The caller is responsible for managing the memory of both record and rr.

Return Values

Upon successful addition of the RR, the function returns 0.

On failure, it returns a non-zero error code. Possible error codes include:

ARES_ENOTFOUND
The record argument is not a valid DNS record structure or is not initialized properly.
ARES_ENOTIMP
The rr argument is not a valid RR structure or is not initialized properly.
ARES_EREALLOC
Memory allocation failed when trying to extend the RR list.

See Also

ares_dns_record_create(3), ares_dns_record_destroy(3)

Example

    ares_dns_record_t *main_record;
    ares_dns_record_t *rr_to_add;
    int ret;

    /* Assume main_record and rr_to_add are initialized */

    ret = ares_dns_record_rr_add(main_record, rr_to_add);
    if (ret != 0) {
        fprintf(stderr, "Failed to add RR: %d\n", ret);
        /* Handle error */
    }
