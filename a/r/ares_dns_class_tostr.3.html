Licences: MIT

ARES_DNS_MAPPINGS(3) Manuel des fonctions de la bibliothèque ARES_DNS_MAPPINGS(3)

NOM

ares_dns_class_fromstr, ares_dns_class_tostr, ares_dns_datatype_t, ares_dns_opcode_tostr, ares_dns_opt_datatype_t, ares_dns_opt_get_datatype, ares_dns_opt_get_name, ares_dns_rcode_tostr, ares_dns_rec_type_fromstr, ares_dns_rr_get_keys, ares_dns_rr_key_datatype, ares_dns_rr_key_to_rec_type, ares_dns_rr_key_tostr, ares_dns_section_tostr, ares_opt_param_t, ares_svcb_param_t - Fonctions utilitaires pour convertir les identifiants d'enregistrements DNS vers et depuis leurs types respectifs, ainsi que pour identifier les types de données de divers enregistrements.

SYNOPSIS

#include <ares.h>
const char *ares_dns_rec_type_tostr(ares_dns_rec_type_t type);
const char *ares_dns_class_tostr(ares_dns_class_t qclass);
const char *ares_dns_opcode_tostr(ares_dns_opcode_t opcode);
const char *ares_dns_rr_key_tostr(ares_dns_rr_key_t key);
const char *ares_dns_section_tostr(ares_dns_section_t section);
const char *ares_dns_rcode_tostr(ares_dns_rcode_t rcode);
ares_bool_t ares_dns_class_fromstr(ares_dns_class_t *qclass, const char *str);
ares_bool_t ares_dns_rec_type_fromstr(ares_dns_rec_type_t *qtype,
                                      const char *str);
const ares_dns_rr_key_t *ares_dns_rr_get_keys(ares_dns_rec_type_t type,
                                              size_t *cnt);
ares_dns_datatype_t ares_dns_rr_key_datatype(ares_dns_rr_key_t key);
ares_dns_rec_type_t ares_dns_rr_key_to_rec_type(ares_dns_rr_key_t key);
ares_dns_opt_datatype_t ares_dns_opt_get_datatype(ares_dns_rr_key_t key,
                                                  unsigned short opt);
const char *ares_dns_opt_get_name(ares_dns_rr_key_t key, unsigned short opt);

ÉNUMÉRATIONS

ares_dns_datatype_t - Types de données associés à ares_dns_rr_key_t:

ARES_DATATYPE_INADDR - Adresse IPv4 sous forme de struct in_addr *. Utilisez ares_dns_rr_set_addr(3) pour définir et ares_dns_rr_get_addr(3) pour obtenir.
ARES_DATATYPE_INADDR6 - Adresse IPv6 sous forme de struct ares_in6_addr *. Utilisez ares_dns_rr_set_addr6(3) pour définir et ares_dns_rr_get_addr6(3) pour obtenir.
ARES_DATATYPE_U8 - Entier non signé de 8 bits. Utilisez ares_dns_rr_set_u8(3) pour définir et ares_dns_rr_get_u8(3) pour obtenir.
ARES_DATATYPE_U16 - Entier non signé de 16 bits. Utilisez ares_dns_rr_set_u16(3) pour définir et ares_dns_rr_get_u16(3) pour obtenir.
ARES_DATATYPE_U32 - Entier non signé de 32 bits. Utilisez ares_dns_rr_set_u32(3) pour définir et ares_dns_rr_get_u32(3) pour obtenir.
ARES_DATATYPE_NAME - Chaîne terminée par un caractère nul représentant un nom de domaine (série de labels). Utilisez ares_dns_rr_set_str(3) pour définir et ares_dns_rr_get_str(3) pour obtenir.
ARES_DATATYPE_STR - Chaîne terminée par un caractère nul. Utilisez ares_dns_rr_set_str(3) pour définir et ares_dns_rr_get_str(3) pour obtenir.
ARES_DATATYPE_BIN - Données binaires. Utilisez ares_dns_rr_set_bin(3) pour définir et ares_dns_rr_get_bin(3) pour obtenir.
ARES_DATATYPE_BINP - Officiellement défini comme des données binaires, mais probablement imprimable. Garantit d'avoir un terminateur NULL pour plus de commodité (non inclus dans la longueur). Utilisez ares_dns_rr_set_bin(3) pour définir et ares_dns_rr_get_bin(3) pour obtenir.
ARES_DATATYPE_OPT - Tableau d'options. Identifiant de 16 bits, données binaires. Utilisez ares_dns_rr_set_opt(3) pour définir et ares_dns_rr_get_opt(3) pour obtenir.
ARES_DATATYPE_ABINP - Tableau de données binaires, mais probablement imprimable. Garanti d'avoir un terminateur NULL pour plus de commodité (non inclus dans la longueur). Utilisez ares_dns_rr_add_abin(3) pour définir et ares_dns_rr_get_abin(3) pour obtenir. Vous pouvez également utiliser ares_dns_rr_set_bin(3) et ares_dns_rr_get_bin(3) si vous souhaitez uniquement des chaînes concaténées.

ares_dns_opt_datatype_t - Types de données associés aux ARES_DATATYPE_OPT paramètres si connus, tels que renvoyés par ares_dns_opt_get_datatype(3):

ARES_OPT_DATATYPE_NONE - Aucune valeur autorisée pour ce paramètre
ARES_OPT_DATATYPE_STR_LIST - Liste de chaînes, chacune préfixée par un octet unique représentant la longueur telle que définie par la RFC 1035. Vous pouvez utiliser ares_expand_string(3) jusqu'à ce que le tampon soit consommé.
ARES_OPT_DATATYPE_U8_LIST - Liste d'entiers non signés de 8 bits, concaténés
ARES_OPT_DATATYPE_U16 - Entier non signé de 16 bits dans l'ordre des octets réseau
ARES_OPT_DATATYPE_U16_LIST - liste d'entiers non signés de 16 bits dans l'ordre des octets réseau, concaténés.
ARES_OPT_DATATYPE_U32 - Entier non signé de 32 bits dans l'ordre des octets réseau
ARES_OPT_DATATYPE_U32_LIST - liste d'entiers non signés de 16 bits dans l'ordre des octets réseau, concaténés.
ARES_OPT_DATATYPE_INADDR4_LIST - Liste d'adresses IPv4 dans l'ordre des octets réseau, concaténées
ARES_OPT_DATATYPE_INADDR6_LIST - Liste d'adresses IPv6 dans l'ordre des octets réseau, concaténées
ARES_OPT_DATATYPE_BIN - Données binaires
ARES_OPT_DATATYPE_NAME - Format binaire du nom de domaine DNS tel que défini dans la RFC1035, vous pouvez utiliser ares_expand_name(3)

ares_svcb_param_t - Paramètres connus des RR SVCB (et HTTPS) tels que renvoyés par ares_dns_opt_get_datatype(3) avec ARES_RR_SVCB_PARAMS ou ARES_RR_HTTPS_PARAMS:

ARES_SVCB_PARAM_MANDATORY - Clés obligatoires dans ce RR (RFC 9460 Section 8). Type de données : ARES_OPT_DATATYPE_U16_LIST
ARES_SVCB_PARAM_ALPN - Protocoles supplémentaires pris en charge (RFC 9460 Section 7.1). Type de données : ARES_OPT_DATATYPE_STR_LIST
ARES_SVCB_PARAM_NO_DEFAULT_ALPN - Pas de prise en charge du protocole par défaut (RFC 9460 Section 7.1). Type de données : ARES_OPT_DATATYPE_NONE
ARES_SVCB_PARAM_PORT - Port pour le point de terminaison alternatif (RFC 9460 Section 7.2). Type de données : ARES_OPT_DATATYPE_U16
ARES_SVCB_PARAM_IPV4HINT - Indices d'adresses IPv4 (RFC 9460 Section 7.3). Type de données : ARES_OPT_DATATYPE_INADDR4_LIST
ARES_SVCB_PARAM_ECH - RÉSERVÉ (réservé pour Encrypted ClientHello)
ARES_SVCB_PARAM_IPV6HINT - Indices d'adresses IPv6 (RFC 9460 Section 7.3). Type de données : ARES_OPT_DATATYPE_INADDR6_LIST

ares_opt_param_t - Paramètres connus des RR OPT tels que renvoyés par ares_dns_opt_get_datatype(3) avec ARES_RR_OPT_OPTIONS:

ARES_OPT_PARAM_LLQ - RFC 8764. Protocole de requêtes à longue durée de vie (DNS Long-Lived Queries) d'Apple. Type de données : ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_UL - http://files.dns-sd.org/draft-sekar-dns-ul.txt: Update Lease. Type de données : ARES_OPT_DATATYPE_U32
ARES_OPT_PARAM_NSID - RFC 5001. Identification du serveur de noms. Type de données : ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_DAU - RFC 6975. Algorithme DNSSEC compris. Type de données : ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_DHU - RFC 6975. Hachage DS compris. Type de données : ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_N3U - RFC 6975. Hachage NSEC3 compris. Type de données : ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_EDNS_CLIENT_SUBNET - RFC 7871. Sous-réseau du client. Type de données : ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_EDNS_EXPIRE - RFC 7314. Minuteur d'expiration. Type de données : ARES_OPT_DATATYPE_U32
ARES_OPT_PARAM_COOKIE - RFC 7873. Cookies client et serveur. Type de données : ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_EDNS_TCP_KEEPALIVE - RFC 7828. Délai d'attente de maintien de connexion TCP. Type de données : ARES_OPT_DATATYPE_U16
ARES_OPT_PARAM_PADDING - RFC 7830. Remplissage. Type de données : ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_CHAIN - RFC 7901. Requêtes de chaînage. Type de données : ARES_OPT_DATATYPE_NAME
ARES_OPT_PARAM_EDNS_KEY_TAG - RFC 8145. Signalisation des connaissances d'ancrage de confiance dans DNSSEC. Type de données : ARES_OPT_DATATYPE_U16_LIST
ARES_OPT_PARAM_EXTENDED_DNS_ERROR - RFC 8914. Code d'erreur et message étendus. Type de données : ARES_OPT_DATATYPE_BIN

DESCRIPTION

La fonction ares_dns_rec_type_tostr(3)</a> fonction produit un type d'enregistrement DNS lisible par l'homme à partir de sa forme numérique passée dans type.

La ares_dns_class_tostr(3) fonction produit une classe DNS lisible par l'homme à partir de sa forme numérique passée dans qclass.

La ares_dns_opcode_tostr(3) fonction produit un opcode DNS lisible par l'homme à partir de sa forme numérique dans opcode.

La ares_dns_rr_key_tostr(3) fonction produit un nom de paramètre de Resource Record DNS lisible par l'homme à partir de sa forme numérique dans key.

La ares_dns_section_tostr(3) fonction produit une section de message DNS lisible par l'homme à partir de sa forme numérique dans section.

La ares_dns_rcode_tostr(3) fonction produit un code de réponse DNS lisible par l'homme à partir de sa forme numérique dans rcode.

La ares_dns_class_fromstr(3) fonction produit la classe DNS sous forme numérique à partir de sa représentation textuelle dans str. Le résultat est stocké dans la variable pointée par qclass.

La ares_dns_rec_type_fromstr(3) fonction produit le type d'enregistrement DNS sous forme numérique à partir de sa représentation textuelle dans str. Le résultat est stocké dans la variable pointée par qtype.

La ares_dns_rr_get_keys(3) fonction récupère une liste de paramètres qui peuvent être définis ou récupérés pour le typefourni. Le nombre de clés retournées est stocké dans la variable pointée par cnt.

La ares_dns_rr_key_datatype(3) fonction récupère le type de données associé pour un paramètre RR spécifié par key.

La ares_dns_rr_key_to_rec_type(3) fonction déréférence le paramètre RR fourni spécifié par key vers le type d'enregistrement DNS auquel il appartient.

La ares_dns_opt_get_datatype(3) fonction est utilisée en association avec ares_dns_rr_set_opt(3) et ares_dns_rr_get_opt(3) pour récupérer le type de données d'un enregistrement option contenu dans un RR tel que spécifié dans key s'il est connu. L'identifiant brut de l'enregistrement option est fourni par opt.

La ares_dns_opt_get_name(3) fonction est utilisée en association avec ares_dns_rr_set_opt(3) et ares_dns_rr_get_opt(3) pour récupérer le nom de paramètre lisible par l'homme d'un enregistrement option contenu dans un RR tel que spécifié dans key s'il est connu. L'identifiant brut de l'enregistrement option est fourni par opt.

VALEURS DE RETOUR

ares_dns_rec_type_tostr(3), ares_dns_class_tostr(3), ares_dns_opcode_tostr(3), ares_dns_rr_key_tostr(3), ares_dns_section_tostr(3), ares_dns_rcode_tostr(3), et ares_dns_opt_get_name(3) retournent tous une chaîne ASCII imprimable par l'homme, ou NULL en cas d'erreur.

ares_dns_class_fromstr(3) et ares_dns_rec_type_fromstr(3) retournent ARES_TRUE en cas de conversion réussie, sinon ARES_FALSE.

ares_dns_rr_get_keys(3) retourne un tableau de clés ou NULL en cas d'échec.

ares_dns_rr_key_datatype(3), ares_dns_rr_key_to_rec_type(3), et ares_dns_opt_get_datatype(3) retournent leurs valeurs entières respectives, ou 0 en cas d'échec.

DISPONIBILITÉ

Ces fonctions ont été introduites pour la première fois dans la version 1.22.0 de c-ares.
