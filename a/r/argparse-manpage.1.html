ARGPARSE-MANPAGE(1) Manuel Python généré ARGPARSE-MANPAGE(1)

NOM

argparse-manpage

SYNTAXE

argparse-manpage [-h] (--module MODULE | --pyfile PYFILE) (--function FUNCTION | --object OBJECT) [--project-name PROJECT_NAME] [--prog PROG] [--version VERSION] [--description TEXT] [--author [AUTHOR]] [--url URL] [--format {pretty,single-commands-section}] [--output OUTFILE] [--manual-section MANUAL_SECTION] [--manual-title MANUAL_TITLE] [--include FILE] [--manfile FILE]

DESCRIPTION

Construit une page de manuel à partir de l'objet ArgumentParser de Python.

OPTIONS

--module MODULE
recherche l'OBJECT/FONCTION dans le MODULE
--pyfile PYFILE
recherche l'OBJECT/FONCTION dans le FICHIER
--function FUNCTION
appelle la FONCTION du MODULE/FICHIER pour obtenir l'objet ArgumentParser
--object OBJECT
obtient l'objet ArgumentParser à partir de la FONCTION (pour obtenir l'objet argparse) du MODULE ou du FICHIER
--project-name PROJECT_NAME
Nom du projet dont le programme documenté fait partie.
--prog PROG
Remplace %prog dans l'utilisation d'ArgumentParser.
--version VERSION
Version du programme, sera visible dans le pied de page de la page de manuel.
--description TEXT
description du programme, utilisée dans la section NOM, après la partie initiale 'nom - ', voir les pages de manuel man (7) pour plus d'informations
--author [AUTHOR]
Auteur du programme. Peut être spécifié plusieurs fois.
--url URL
Lien vers la page d'accueil du projet
--format {pretty,single-commands-section}
Format de la page de manuel générée. Par défaut 'pretty'.
--output OUTFILE
Fichier de sortie. Par défaut, la sortie standard.
--manual-section MANUAL_SECTION
Section du manuel, par défaut 1. Voir les pages de manuel man (7) pour plus d'informations sur les sections existantes.
--manual-title MANUAL_TITLE
Le titre du manuel, par défaut "Manuel Python généré". Voir les pages de manuel man (7) pour plus d'instructions.
--include FILE
Fichier contenant du matériel supplémentaire pour la page de manuel.
--manfile FILE
Fichier contenant une page de manuel complète.
