ARLATEX(1) Commandes utilisateur ARLATEX(1)

NOM

arlatex - archive un certain nombre de fichiers auxiliaires LaTeX dans un fichier .tex maître

SYNTAXE

arlatex [--outfile=nom_fichier.tex] --document=nom_fichier.tex nom_fichier ...

arlatex --version

arlatex --help

DESCRIPTION

arlatex est un programme d'archivage similaire à shar, tar, zip, etc. Cependant, contrairement à ces autres archiveurs, arlatex est spécifiquement conçu pour être utilisé avec LaTeX. arlatex prend le nom d'un fichier maître .tex et un certain nombre de fichiers auxiliaires utilisés par ce fichier maître (par exemple, des fichiers .tex, .sty, .cls et .eps). À partir de ceux-ci, arlatex génère un seul fichier qui, lorsqu'il est traité par latex, régénère les fichiers auxiliaires et compile le document en un fichier .dvi.

arlatex présente quelques avantages par rapport aux autres programmes d'archivage :

  • Les fichiers .tex produits par arlatex sont au format texte brut. Ils sont donc parfaitement portables et très faciles à envoyer par courriel à des collègues.
  • arlatex n'a besoin que de LaTeX pour fonctionner. Il n'y a aucune dépendance à des outils externes.
  • Il n'y a pas d'étape d'extraction explicite. Lorsque le document généré est traité par latex, il extrait les fichiers auxiliaires et construit le document en une seule étape. L'utilisateur qui exécute latex peut même ne pas remarquer que des fichiers supplémentaires sont produits.

arlatex fonctionne en écrivant un certain nombre de blocs "\begin{filecontents*}" ... "\end{filecontents*}" dans le fichier de sortie, suivis du contenu du fichier maître. (En fait, tous les commentaires LaTeX au début du fichier maître sont déplacés en haut du fichier généré. Cela permet à l'auteur d'attirer l'attention, si désiré, sur le fait que des fichiers auxiliaires seront générés.) L'environnement "filecontents*", qui fait partie de la norme LaTeX2e, écrit son contenu littéralement dans un fichier spécifié.

OPTIONS

--version
Affiche le numéro de version du script arlatex.
--help
Affiche des informations d'utilisation brèves de arlatex.
--document=fichier.tex
Spécifie le document maître. La sortie de arlatex est ce fichier avec tous les autres fichiers nommés sur la ligne de commande préfixés. Notez que "--document" est un paramètre obligatoire ; arlatex s'arrêtera avec un message d'erreur si "--document" n'est pas spécifié.
--outfile=fichier.tex
Spécifie le fichier de sortie. Le fichier de sortie ressemble au document maître, mais avec un certain nombre d'environnements "filecontents*" précédant la ligne "\documentclass". Si "--outfile" n'est pas spécifié, la sortie sera écrite sur la sortie standard.

EXEMPLES

Supposons que vous ayez un article nommé paper.tex qui charge un paquet personnalisé avec "\usepackage{mypackage}". Vous souhaitez soumettre l'article à une conférence, mais vous voulez être absolument sûr que mypackage.sty ne soit pas perdu lors du transfert de votre article d'une personne à l'autre. Voici comment arlatex peut être utile :

arlatex --document=paper.tex mypackage.sty --outfile=paper-submit.tex

Lorsque paper-submit.tex est traité avec latex, il se construit comme l'original paper.tex, sauf qu'il crée en plus un fichier mypackage.sty dans le répertoire courant :

This is TeX, Version 3.14159 (Web2C 7.3.1)
(paper-submit.tex
LaTeX2e <1999/12/01> patch level 1
Babel <v3.6Z> and hyphenation patterns for american, french, german,
ngerman, italian, nohyphenation, loaded.
LaTeX Warning: Writing file `./mypackage.sty'.
(/usr/share/texmf/tex/latex/base/article.cls
Document Class: article 1999/09/10 v1.4a Standard LaTeX document class
(/usr/share/texmf/tex/latex/base/size12.clo)) (mypackage.sty)
                              .
                              .
                              .

Autre exemple, voici comment vous pourriez regrouper tous les fichiers nécessaires pour construire un document volumineux pour la pérénnité :

arlatex --document=thesis.tex abstract.tex introduction.tex
  background.tex approach.tex experiments.tex relatedwork.tex
  conclusions.tex before.eps after.eps fast.eps slow.eps
  podunkUthesis.cls --outfile=thesis-all.tex

À mesure que le nombre de fichiers à archiver augmente, il devient plus fastidieux de lancer arlatex manuellement. Heureusement, l'utilisation de arlatex avec bundledoc est simple. bundledoc trouve tous les fichiers nécessaires pour construire le document, et arlatex les combine en un seul fichier. Les exemples suivants montrent la ligne "bundle:" que vous pourriez utiliser dans un fichier de configuration bundledoc :

Unix:
bundle: (arlatex --document=$BDBASE.tex $BDINPUTS \
  --outfile=$BDBASE-all.tex)
Windows:
bundle: arlatex --document=%BDBASE%.tex %BDINPUTS% \
  --outfile=%BDBASE%-all.tex

Voir la documentation de bundledoc pour plus d'informations.

CAVEATS

arlatex utilise l'environnement "filecontents*" de LaTeX. Il transmet l'option "overwrite" à "filecontents*" pour indiquer que les fichiers existants portant le même nom doivent être écrasés. Soyez averti que la construction du fichier généré écrasera les fichiers utilisés pour le créer.

Il est préférable d'éviter de regrouper des fichiers binaires (par exemple, des graphiques inclus) avec arlatex. Ceux-ci ne s'extraient généralement pas proprement.
