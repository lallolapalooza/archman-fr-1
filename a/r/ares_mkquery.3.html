ARES_MKQUERY(3) Manuel des fonctions de bibliothèque ARES_MKQUERY(3)

NOM

ares_mkquery - Composer un tampon de requête DNS à question unique

SYNTAXE

#include <ares.h>
int ares_mkquery(const char *name, int dnsclass, int type,
                 unsigned short id, int rd, unsigned char **buf,
                 int *buflen)

DESCRIPTION

Cette fonction est dépréciée depuis c-ares 1.10, veuillez utiliser ares_dns_record_create(3) à la place.

La fonction ares_mkquery compose une requête DNS avec une question unique. Le paramètre name donne le nom de la requête sous forme d'une chaîne C terminée par NUL, avec des étiquettes séparées par des points, se terminant éventuellement par un point ; les points et les barres obliques dans une étiquette doivent être échappés par une barre oblique. Les paramètres dnsclass et type donnent la classe et le type de la requête en utilisant les valeurs définies dans <arpa/nameser.h>. Le paramètre id donne un identifiant de 16 bits pour la requête. Le paramètre rd doit être non nul si la récursion est désirée, nul sinon. La requête sera placée dans un tampon alloué, un pointeur vers lequel sera stocké dans la variable pointée par buf, et dont la longueur sera stockée dans la variable pointée par buflen. Il incombe à l'appelant de libérer ce tampon en utilisant ares_free_string(3) lorsqu'il n'est plus nécessaire.

L'utilisation de ares_mkquery(3) est dépréciée, tandis que la fonction est équivalente à ares_create_query(3) avec max_udp_size défini à 0.

VALEURS DE RETOUR

ares_mkquery peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
La construction de la requête DNS a réussi.
ARES_ENOTFOUND
Le nom de requête name fait référence à un nom de domaine .onion. Voir RFC 7686.
ARES_EBADNAME
Le nom de requête name n'a pas pu être encodé comme un nom de domaine, soit parce qu'il contenait une étiquette de longueur nulle, soit parce qu'il contenait une étiquette de plus de 63 caractères.
ARES_ENOMEM
La mémoire a été épuisée.

VOIR AUSSI

ares_expand_name(3), ares_dns_record(3), ares_free_string(3)
