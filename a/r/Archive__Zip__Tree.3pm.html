Archive::Zip::Tree - (OBSOLÈTE) méthodes pour ajouter/extraire des arbres en utilisant Archive::Zip

DESCRIPTION

Ce module est obsolète, car toutes ses méthodes ont été déplacées dans le module principal Archive::Zip.

Il est inclus dans la distribution simplement pour éviter de casser du vieux code.
