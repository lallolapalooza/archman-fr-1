NOM

ares_freeaddrinfo - Libérer une structure addrinfo allouée par les fonctions ares

SYNOPSIS

#include <ares.h>
void ares_freeaddrinfo(struct ares_addrinfo *ai)

DESCRIPTION

La fonction ares_freeaddrinfo libère une struct ares_addrinfo retournée dans result de ares_addrinfo_callback
