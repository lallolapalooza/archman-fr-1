ARCH-REPRO-STATUS(1) Commandes utilisateur ARCH-REPRO-STATUS(1)

NOM

arch-repro-status - vérifier le statut de reproductibilité des paquets Arch Linux

SYNTAXE

arch-repro-status [OPTIONS]

DESCRIPTION

Vérifie le statut de reproductibilité des paquets Arch Linux en utilisant les données d'une instance de rebuilderd telle que reproducible.archlinux.org. Il peut afficher le statut de reproductibilité de :

•
paquets appartenant à un mainteneur individuel (utilise les données de archlinux.org)
•
paquets actuellement installés sur le système (utilise les données de la base de données locale de pacman)

Vous pouvez inspecter les journaux de compilation et diffoscope des paquets en activant le mode interactif avec -i.

OPTIONS :

-q, --quiet
Désactive la journalisation
-v, --verbose
Augmente la verbosité de la journalisation
-a, --all
Vérifie tous les paquets du système
-m, --maintainer <MAINTENEUR>
Définit le nom d'utilisateur du mainteneur [env: MAINTENEUR=]
-r, --rebuilderd <URL>
Définit l'adresse de l'instance rebuilderd [env: REBUILDERD=] [défaut : https://reproducible.archlinux.org]
-b, --dbpath <CHEMIN>
Définit le chemin vers la base de données pacman [env: DBPATH=] [défaut : /var/lib/pacman]
--repos <REPO>
Définit les dépôts à interroger [défaut : core,extra,multilib]
-n, --pkgnames <NOMPAQUET>
Définit la liste de paquets à interroger, séparée par des virgules [env: NOMPAQUET=]
-f, --filter <STATUT>
Définit le filtre pour le statut du paquet [env: FILTER=] [valeurs possibles : GOOD, BAD, UNKWN]
-i, --inspect
Visualise le journal de compilation ou diffoscope du paquet sélectionné interactivement
-p, --pager <PAGER>
Définit le pagineur pour visualiser les fichiers [env: PAGER=] [défaut : less]
-c, --cache-dir <REP>
Définit le répertoire de cache pour les fichiers journaux [env: CACHE_DIR=]
-h, --help
Affiche les informations d'aide
-V, --version
Affiche les informations de version
