DESCRIPTIO

N

L'utilitaire GNU size liste la taille des sections et la taille totale pour chacun des fichiers binaires objfile figurant dans sa liste d'arguments. Par défaut, une ligne de sortie est générée pour chaque fichier ou pour chaque module si le fichier est une

archive.

objfile... sont les fichiers à examiner. Si aucun n'est spécifié, le fichier "a.out" sera utili

sé à
la place.

OPTION

S

Les options en ligne de commande ont les significations suivantes

:

-

-

--format=compatibili
té
En utilisant l'une de ces options, vous pouvez choisir si la sortie de GNU size ressemble à la sortie de System V size (en utilisant -A, ou --format=sysv), ou à celle de Berkeley size (en utilisant -B, ou --format=berkeley). Le format par défaut est celui d'une ligne, similaire à celui de Berkeley. Alternativement, vous pouvez choisir le format de sortie GNU (en utilisant -G, ou --format=gnu), qui est similaire au format de sortie de Berkeley, mais dont les tailles sont calculées différemment.

Voici un exemple du format de sortie Berkeley (par défaut) de size

: 
$ size --format=Berkeley ranlib size
   text    data     bss     dec     hex filename
 294880   81920   11592  388392   5ed28 ranlib
 294880   81920   11888  388688   5ee50
size

La sortie de style Berkeley compte les données en lecture seule dans la colonne "text", et non dans la colonne "data", les colonnes "dec" et "hex" affichent toutes deux la somme des colonnes "text", "data" et "bss" en décimal et en hexadécimal

respectivement.

Le format GNU compte les données en lecture seule dans la colonne "data", et non dans la colonne "text", et n'affiche la somme des colonnes "text", "data" et "bss" qu'une seule fois, dans la colonne "total". L'option --radix peut être utilisée pour changer la base numérique de toutes les colonnes. Voici les mêmes données affichées avec les conventions

GNU : 
$ size --format=GNU ranlib size
      text       data        bss      total filename
    279880      96920      11592     388392 ranlib
    279880      96920      11888     388688
size

Ce sont les mêmes données, mais affichées plus proches des conventions

System V : 
$ size --format=SysV ranlib size
ranlib  :
section         size         addr
.text         294880         8192
.data

.text 294880 8192 .data 81920 303104 .bss 11888 385024 Total 388688

En utilisant l'une de ces options, vous pouvez contrôler si la taille de chaque section est donnée en décimal (-d, ou --radix=10) ; en octal (-o, ou --radix=8) ; ou en hexadécimal (-x, ou --radix=16). Dans --radix=nombre, seules les trois valeurs (8, 10, 16) sont prises en charge. La taille totale est toujours donnée dans deux bases ; décimale et hexadécimale pour la sortie -d ou -x, ou octale et hexadécimale si vous utilisez -o

Lit les options en ligne de commande à partir de file. Les options lues sont insérées à la place de l'option originale @file. Si file n'existe pas ou ne peut pas être lu, l'option sera traitée littéralement et ne sera pas supprimée.

Les options dans file sont séparées par des espaces. Un caractère d'espace peut être inclus dans une option en entourant l'option entière de guillemets simples ou doubles. N'importe quel caractère (y compris une barre oblique inverse) peut être inclus en préfixant le caractère à inclure d'une barre oblique inverse.
