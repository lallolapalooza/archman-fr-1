NOM

ares_expand_name - Développe un nom de domaine encodé en DNS

SYNTAXE

#include <ares.h>
int ares_expand_name(const unsigned char *encoded,
                     const unsigned char *abuf, int alen,
                     char **s, long *enclen)

DESCRIPTION

La fonction ares_expand_name convertit un nom de domaine encodé en DNS en une chaîne C séparée par des points. L'argument encoded indique le début du nom de domaine encodé, et les arguments abuf et alen indiquent le tampon du message contenant le nom (nécessaire pour le traitement des pointeurs d'indirection dans le nom de domaine encodé). Le résultat est placé dans un tampon alloué et terminé par NUL, dont un pointeur est stocké dans la variable pointée par s. La longueur du nom encodé est stockée dans la variable pointée par enclen afin que l'appelant puisse avancer au-delà du nom de domaine encodé pour lire d'autres données dans le message.

Utilisez ares_free_string(3) pour libérer le nom d'hôte alloué.

VALEURS DE RETOUR

ares_expand_name peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
L'expansion du nom encodé a réussi.
ARES_EBADNAME
Le nom de domaine encodé était mal formé et n'a pas pu être développé.
ARES_ENOMEM
La mémoire a été épuisée.

VOIR AUSSI

ares_mkquery(3), ares_free_string(3)
