ares_set_socket_callback(3)

Paquet: c-ares

Licences: MIT

ARES_SET_SOCKET_CALLBACK(3) Manuel des fonctions de bibliothèque ARES_SET_SOCKET_CALLBACK(3)

NOM

ares_set_socket_callback - Définir un rappel pour la création de socket

SYNTAXE

#include <ares.h>
typedef int (*ares_sock_create_callback)(ares_socket_t socket_fd,
                                         int type,
                                         void *userdata)
void ares_set_socket_callback(ares_channel_t *channel,
                              ares_sock_create_callback callback,
                              void *userdata)
cc file.c -lcares

DESCRIPTION

Cette fonction définit un callback dans le handle de canal ares donné. Ce callback sera invoqué après la création du socket et sa connexion au serveur distant. Le callback doit retourner ARES_SUCCESS si tout va bien, ou retourner -1 pour signaler une erreur. Une erreur retournée annulera l'opération ares.

VOIR AUSSI

ares_init_options(3), ares_set_socket_configure_callback(3)
