NOM

arch-rebuild-order - Script de génération d'ordre de reconstruction

SYNTAXE

arch-rebuild-order [OPTION]... [PAQUETS]...

DESCRIPTION

Génère un ordre de reconstruction pour les paquets donnés en utilisant les bases de données synchronisées de pacman.

--d=FICHIER, --dotfile=FICHIER Génère un fichier graphique .dot avec l'ordre de reconstruction des paquets donnés

--dbpath=CHEMIN le chemin vers le répertoire de la base de données de pacman

--repos=REPOS les dépôts à partir desquels récupérer les informations des paquets

--no-reverse-depends n'utilise que les noms de paquets fournis en entrée pour calculer l'ordre de construction, n'étend pas les dépendances inverses (make)

--with-check-depends inclut les checkdependencies dans l'ordre de reconstruction

-V, --version affiche les informations sur la version

-h, --help affiche les informations d'aide

EXEMPLES

Génération d'une image de l'ordre de reconstruction du/des paquet(s) fourni(s) :

$ arch-rebuild-order -d linux-rebuild-order.dot linux

$ dot -Tpng linux-rebuild-order.dot > linux-rebuild-order.png
