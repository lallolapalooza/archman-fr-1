DESCRIPTION

Ces fonctions définissent le format qui sera utilisé pour l'archive.

La bibliothèque peut écrire une variété de formats d'archive courants.

archive_write_set_format()
Définit le format en fonction du code de format (voir archive.h pour la liste complète des codes de format). En particulier, cela peut être utilisé conjointement avec archive_format() pour créer une nouvelle archive avec le même format qu'une archive existante.
archive_write_set_format_by_name()
Définit le format correspondant en fonction du nom commun.
archive_write_set_format_filter_by_ext() archive_write_set_format_filter_by_ext_def()
Définit à la fois les filtres et le format en fonction du nom de fichier de sortie. Extensions prises en charge : .7z, .zip, .jar, .cpio, .iso, .a, .ar, .tar, .tgz, .tar.gz, .tar.bz2, .tar.xz
archive_write_set_format_7zip() archive_write_set_format_ar_bsd() archive_write_set_format_ar_svr4() archive_write_set_format_cpio() archive_write_set_format_cpio_bin() archive_write_set_format_cpio_newc() archive_write_set_format_cpio_odc() archive_write_set_format_cpio_pwb() archive_write_set_format_gnutar() archive_write_set_format_iso9660() archive_write_set_format_mtree() archive_write_set_format_mtree_classic() archive_write_set_format_mtree_default() archive_write_set_format_pax() archive_write_set_format_pax_restricted() archive_write_set_format_raw() archive_write_set_format_shar() archive_write_set_format_shar_dump() archive_write_set_format_ustar() archive_write_set_format_v7tar() archive_write_set_format_warc() archive_write_set_format_xar() archive_write_set_format_zip()
Ces fonctions définissent spécifiquement le format d'archive pour la création d'une archive. Elles sont équivalentes à un appel à archive_write_set_format() avec le code de format approprié.

Les formats disponibles incluent :

7zip
Format 7-Zip (utilisé par 7z et p7zip).
ar
Format d'archive GNU ar.
ar_bsd
Format d'archive BSD ar.
ar_svr4
Format d'archive SVR4 ar.
cpio
Format d'archive cpio (utilisé par mkcpio).
cpio_bin
Format binaire cpio.
cpio_newc
Nouveau format Cpio (SVR4).
cpio_odc
Format cpio ODC.
cpio_pwb
Format cpio PWB.
gnutar
Format d'archive GNU tar.
iso9660
Format ISO9660 CD-ROM.
mtree
Format mtree.
mtree_classic
Format mtree classique.
archive_write_set_format_mtree_default
Format mtree par défaut.
pax
Format d'archive POSIX.1-2001.
pax_restricted
Format d'archive POSIX.1-2001 restreint.
raw
Format brut (aucun format d'archive).
shar
Format Shell Archive.
shar_dump
Format Shell Archive Dump.
ustar
Format d'archive POSIX.
v7tar
Format d'archive V7 tar.
warc
Format WARC (Web ARchive).
xar
Format d'archive extensible.
zip
Format d'archive ZIP.

VALEURS DE RETOUR

Ces fonctions retournent ARCHIVE_OK en cas de succès, ou un code d'erreur en cas d'échec. Les codes d'erreur possibles incluent ARCHIVE_FATAL, ARCHIVE_WARN, ARCHIVE_RETRY.
