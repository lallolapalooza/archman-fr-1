ares_parse_naptr_reply(3)

NOM

ares_parse_naptr_reply - Analyse une réponse à une requête DNS de type NAPTR

SYNTAXE

#include <ares.h>
int ares_parse_naptr_reply(const unsigned char* abuf, int alen,
                           struct ares_naptr_reply** naptr_out);

DESCRIPTION

La fonction ares_parse_naptr_reply analyse la réponse à une requête de type NAPTR en une liste chaînée de structures struct ares_naptr_reply. Les paramètres abuf et alen fournissent le contenu de la réponse. Le résultat est stocké dans une mémoire allouée et un pointeur vers celui-ci est stocké dans la variable pointée par naptr_out. Il incombe à l'appelant de libérer la structure résultante naptr_out lorsqu'elle n'est plus nécessaire, en utilisant la fonction ares_free_data(3).

La structure ares_naptr_reply contient les champs suivants :


struct ares_naptr_reply {
    struct ares_naptr_reply *next;
    unsigned char *flags;
    unsigned char *service;
    unsigned char *regexp;
    char *replacement;
    unsigned short order;
    unsigned short preference;
};

VALEURS DE RETOUR

ares_parse_naptr_reply peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
La réponse a été analysée avec succès.
ARES_EBADRESP
La réponse était mal formatée.
ARES_ENODATA
La réponse ne contenait pas de réponse à la requête.
ARES_ENOMEM
La mémoire a été épuisée.

DISPONIBILITÉ

Cette fonction a été introduite pour la première fois dans c-ares version 1.7.6.
