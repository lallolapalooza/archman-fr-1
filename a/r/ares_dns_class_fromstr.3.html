ares_dns_datatype_t - Types de données associés à ares_dns_rr_k

ey_t :
ARES_DATATYPE_INADDR - Adresse IPv4 sous la forme struct in_addr *. Utilisez ares_dns_rr_set_addr(3) pour définir et ares_dns_rr_get_addr(3) pour obtenir.
ARES_DATATYPE_INADDR6 - Adresse IPv6 sous la forme struct ares_in6_addr *. Utilisez ares_dns_rr_set_addr6(3) pour définir et ares_dns_rr_get_addr6(3) pour obtenir.
ARES_DATATYPE_U8 - Entier non signé sur 8 bits. Utilisez ares_dns_rr_set_u8(3) pour définir et ares_dns_rr_get_u8(3) pour obtenir.
ARES_DATATYPE_U16 - Entier non signé sur 16 bits. Utilisez ares_dns_rr_set_u16(3) pour définir et ares_dns_rr_get_u16(3) pour obtenir.
ARES_DATATYPE_U32 - Entier non signé sur 32 bits. Utilisez ares_dns_rr_set_u32(3) pour définir et ares_dns_rr_get_u32(3) pour obtenir.
ARES_DATATYPE_NAME - Chaîne terminée par un caractère nul représentant un nom de domaine (série d'étiquettes). Utilisez ares_dns_rr_set_str(3) pour définir et ares_dns_rr_get_str(3) pour obtenir.
ARES_DATATYPE_STR - Chaîne terminée par un caractère nul. Utilisez ares_dns_rr_set_str(3) pour définir et ares_dns_rr_get_str(3) pour obtenir.
ARES_DATATYPE_BIN - Données binaires. Utilisez ares_dns_rr_set_bin(3) pour définir et ares_dns_rr_get_bin(3) pour obtenir.
ARES_DATATYPE_BINP - Officiellement défini comme des données binaires, mais probablement imprimable. Garantit d'avoir un terminateur NULL pour plus de commodité (non inclus dans la longueur). Utilisez ares_dns_rr_set_bin(3) pour définir et ares_dns_rr_get_bin(3) pour obtenir.
ARES_DATATYPE_OPT - Tableau d'options. Identifiant sur 16 bits, données binaires. Utilisez ares_dns_rr_set_opt(3) pour définir et ares_dns_rr_get_opt(3) pour obtenir.
ARES_DATATYPE_ABINP - Tableau de données binaires, mais probablement imprimable. Garantit d'avoir un terminateur NULL pour plus de commodité (non inclus dans la longueur). Utilisez ares_dns_rr_add_abin(3) pour définir et ares_dns_rr_get_abin(3) pour obtenir. Vous pouvez également utiliser ares_dns_rr_set_bin(3) et ares_dns_rr_get_bin(3) si vous ne souhaitez que des chaînes concaténées.

:
ARES_OPT_DATATYPE_NONE - Aucune valeur n'est autorisée pour ce paramètre
ARES_OPT_DATATYPE_STR_LIST - Liste de chaînes, chacune préfixée par un octet unique représentant la longueur comme défini par la RFC 1035. Peut utiliser ares_expand_string(3) jusqu'à ce que le tampon soit consommé.
ARES_OPT_DATATYPE_U8_LIST - Liste d'entiers non signés sur 8 bits, concaténés
ARES_OPT_DATATYPE_U16 - Entier non signé sur 16 bits dans l'ordre des octets réseau
ARES_OPT_DATATYPE_U16_LIST - liste d'entiers non signés sur 16 bits dans l'ordre des octets réseau, concaténés.
ARES_OPT_DATATYPE_U32 - Entier non signé sur 32 bits dans l'ordre des octets réseau
ARES_OPT_DATATYPE_U32_LIST - liste d'entiers non signés sur 16 bits dans l'ordre des octets réseau, concaténés.
ARES_OPT_DATATYPE_INADDR4_LIST - Liste d'adresses IPv4 dans l'ordre des octets réseau, concaténées
ARES_OPT_DATATYPE_INADDR6_LIST - Liste d'adresses IPv6 dans l'ordre des octets réseau, concaténées
ARES_OPT_DATATYPE_BIN - Données binaires
ARES_OPT_DATATYPE_NAME - Format binaire du nom de domaine DNS tel que défini dans la RFC 1035, peut utiliser ares_expand_name(3)

DESCRIPTIO

N

La fonction ares_dns_rec_type_tostr(3) produit un type d'enregistrement DNS lisible par l'humain à partir de sa forme numérique passée dans type

.

La fonction ares_dns_class_tostr(3) produit une classe DNS lisible par l'humain à partir de sa forme numérique passée dans qclass

.

La fonction ares_dns_opcode_tostr(3) produit un opcode DNS lisible par l'humain à partir de sa forme numérique dans opcode

.

La fonction ares_dns_rr_key_tostr(3) produit un nom de paramètre d'enregistrement de ressources DNS lisible par l'humain à partir de sa forme numérique dans key

.

La fonction ares_dns_section_tostr(3) produit une section de message DNS lisible par l'humain à partir de sa forme numérique dans section

.

La fonction ares_dns_rcode_tostr(3) produit un code de réponse DNS lisible par l'humain à partir de sa forme numérique dans rcode

.

La fonction ares_dns_class_fromstr(3) produit la classe DNS sous forme numérique à partir de sa représentation textuelle dans str. Le résultat est stocké dans la variable pointée par qclass

.

La fonction ares_dns_rec_type_fromstr(3) produit le type d'enregistrement DNS sous forme numérique à partir de sa représentation textuelle dans str. Le résultat est stocké dans la variable pointée par qtype

.

La fonction ares_dns_rr_get_keys(3) récupère une liste de paramètres qui peuvent être définis ou récupérés pour le type fourni. Le nombre de clés retournées est stocké dans la variable pointée par cnt

.

La fonction ares_dns_rr_key_datatype(3) récupère le type de données associé pour un paramètre RR spécifié par key

.

La fonction ares_dns_rr_key_to_rec_type(3) déréférence le paramètre RR fourni spécifié par key vers le type d'enregistrement DNS auquel il

appartient.

La fonction ares_dns_opt_get_datatype(3) est utilisée en association avec ares_dns_rr_set_opt(3) et ares_dns_rr_get_opt(3) pour récupérer le type de données d'un enregistrement d'option contenu dans un RR tel que spécifié dans key s'il est connu. L'identifiant brut de l'enregistrement d'option est fourni par opt

.

La fonction ares_dns_opt_get_name(3) est utilisée en association avec ares_dns_rr_set_opt(3) et ares_dns_rr_get_opt(3) pour récupérer le nom de paramètre lisible par l'humain d'un enregistrement d'option contenu dans un RR tel que spécifié dans key s'il est connu. L'identifiant brut de l'enregistrement d'option est fourni par op

t
.

VALEURS DE

RETOUR

ares_dns_rec_type_tostr(3), ares_dns_class_tostr(3), ares_dns_opcode_tostr(3), ares_dns_rr_key_tostr(3), ares_dns_section_tostr(3), ares_dns_rcode_tostr(3), et ares_dns_opt_get_name(3) retournent tous une chaîne ASCII imprimable par l'humain, ou NULL en cas

d'erreur.

ares_dns_class_fromstr(3) et ares_dns_rec_type_fromstr(3) retournent ARES_TRUE en cas de conversion réussie, sinon ARES_FALSE

.

ares_dns_rr_get_keys(3) retourne un tableau de clés ou NULL en cas

d'échec.

ares_dns_rr_key_datatype(3), ares_dns_rr_key_to_rec_type(3), et ares_dns_opt_get_datatype(3) retournent leurs vale

urs entières respectives,
ou 0 en cas d'échec.
