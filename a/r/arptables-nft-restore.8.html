NOM

arptables-restore — Restaure les tables ARP (basé sur nft)

SYNTAXE

arptables-restore

DESCRIPTION

arptables-restore est utilisé pour restaurer les tables ARP à partir de données spécifiées sur l'entrée standard (STDIN) ou via un fichier comme premier argument. Utilisez la redirection d'E/S fournie par votre shell pour lire depuis un fichier.

arptables-restore
vide (supprime) tout contenu précédent de la table ARP respective.

AUTEUR

Jesper Dangaard Brouer <brouer@redhat.com>

VOIR AUSSI
