ares_dns_record_rr_cnt(

3)

The renvoie le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section fournie dans le paramètre sect. La fonction ares_dns_record_rr_add(

3)

ajoute une nouvelle entrée d'enregistrement de ressources à l'enregistrement DNS fourni par le paramètre dnsrec. L'enregistrement de ressources résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle appartient l'enregistrement de ressources est spécifiée par le paramètre sect. Le nom de domaine associé à l'enregistrement de ressources est spécifié par le paramètre name, qui ne peut pas être NULL mais peut être une chaîne vide ou ".". Le type d'enregistrement de ressources est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le Time To Live (TTL) dans le paramètre ttl. Les fonctions ares_dns_record_rr_get(3) et ares_dns_record_rr_get_const(

3)

The sont utilisées pour récupérer le pointeur de l'enregistrement de ressources à partir de l'enregistrement DNS fourni dans le paramètre dnsrec, pour la section d'enregistrement de ressources fournie dans le paramètre sect, pour l'index spécifié dans le paramètre idx. L'index doit être inférieur à [[109] ] ares_dns_record_rr_cnt(3). La première fonction renvoie un pointeur modifiable vers l'enregistrement de ressources, tandis que la seconde renvoie un pointeur en lecture seule vers l'enregistrement de ressources. La fonction ares_dns_record_rr_del(3

)

The est utilisée pour supprimer un enregistrement de ressources de l'enregistrement DNS spécifié dans le paramètre dnsrec. Son usage principal est de supprimer un enregistrement ARES_REC_TYPE_OPT lorsqu'il est nécessaire de réessayer une requête sans support EDNS. La section RR DNS est spécifiée via le paramètre sect, et l'index à supprimer est spécifié dans le paramètre idx. L'index doit être inférieur à [[116]] ares_dns_record_rr_cnt(3) . Les types de données pris en charge par les fonctions ci-dessus sont définis dans l'énumération ares_data_type_t.

typedef enum {
        ARES_DATATYPE_NONE,
        ARES_DATATYPE_INADDR,     // IPv4 Address
        ARES_DATATYPE_INADDR6,    // IPv6 Address
        ARES_DATATYPE_STR,        // String
        ARES_DATATYPE_NAME,       // Domain Name String
        ARES_DATATYPE_U8,         // 8-bit Unsigned Integer
        ARES_DATATYPE_U16,        // 16-bit Unsigned Integer
        ARES_DATATYPE_U32,        // 32-bit Unsigned Integer
        ARES_DATATYPE_BIN,        // Binary Data
        ARES_DATATYPE_BINP,       // Pointer to Binary Data
        ARES_DATATYPE_ABIN,       // Array of Binary Data
        ARES_DATATYPE_ABINP,      // Pointer to Array of Binary Data
        ARES_DATATYPE_OPT         // OPT Resource Record
    } ares_data_type_t;

DESCRIPTION

Ces fonctions permettent de créer, modifier, supprimer et interroger des enregistrements DNS au sein d'une structure ares_dns_record_t.

La fonction ares_dns_record_rr_add ajoute un nouvel enregistrement de ressource (RR) à l'objet ares_dns_record_t. Les paramètres name, rr_class, rr_type, ttl, et les données de l'enregistrement (data et data_len) sont utilisés pour créer le nouvel RR.

La fonction ares_dns_record_rr_del supprime un RR de l'objet ares_dns_record_t à l'index spécifié par idx.

Les fonctions ares_dns_record_rr_get et ares_dns_record_rr_get_const retournent respectivement un pointeur vers un RR modifiable ou constant à l'index spécifié par idx.

La fonction ares_dns_record_rr_cnt retourne le nombre d'enregistrements RR dans l'objet ares_dns_record_t.

Les fonctions ares_dns_rr_set_* sont utilisées pour définir les valeurs des différents types de données pour un enregistrement RR donné. Le RR à modifier est fourni dans le paramètre dns_rr. Les types de données pris en charge incluent les adresses IPv4 (ARES_DATATYPE_INADDR), les adresses IPv6 (ARES_DATATYPE_INADDR6), les chaînes de caractères (ARES_DATATYPE_STR), les entiers non signés de 8, 16 et 32 bits (ARES_DATATYPE_U8, ARES_DATATYPE_U16, ARES_DATATYPE_U32) et les données binaires (ARES_DATATYPE_BIN).

Les fonctions ares_dns_rr_add_abin et ares_dns_rr_del_abin sont utilisées pour gérer les tableaux de données binaires (ARES_DATATYPE_ABIN).

La fonction ares_dns_rr_set_opt est utilisée pour définir des clés et des valeurs d'option/paramètre pour un enregistrement RR lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement RR à modifier est fourni dans le paramètre dns_rr. La clé/paramètre est fournie dans le paramètre key. La valeur de l'option/paramètre spécifique à l'enregistrement RR est fournie dans le paramètre opt, et il appartient à l'utilisateur de déterminer la valeur appropriée à utiliser. Certaines valeurs connues peuvent être fournies par les énumérations ares_svcb_param_t et ares_opt_param_t. La valeur de l'option est toujours fournie sous forme binaire dans val avec la longueur fournie dans val_len.

La fonction ares_dns_rr_del_opt est utilisée pour supprimer des clés et des valeurs d'option/paramètre pour un enregistrement RR lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement RR à modifier est fourni dans le paramètre dns_rr. La clé/paramètre est fournie dans le paramètre key. L'index de l'option/paramètre à supprimer est fourni dans le paramètre idx.

La fonction ares_dns_rr_del_opt_byid est utilisée pour supprimer des clés et des valeurs d'option/paramètre pour un enregistrement RR lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement RR à modifier est fourni dans le paramètre dns_rr. L'identifiant de l'option/paramètre à supprimer est fourni dans le paramètre opt. Cette fonction retourne ARES_SUCCESS si l'enregistrement est supprimé avec succès, ou ARES_ENOTFOUND si l'enregistrement n'a pas pu être trouvé.

La fonction ares_dns_rr_get_addr est utilisée pour récupérer l'adresse IPv4 de l'enregistrement RR lorsque le type de données est ARES_DATATYPE_INADDR. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_addr6 est utilisée pour récupérer l'adresse IPv6 de l'enregistrement RR lorsque le type de données est ARES_DATATYPE_INADDR6. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_str est utilisée pour récupérer une chaîne de caractères de l'enregistrement RR lorsque le type de données est ARES_DATATYPE_STR ou ARES_DATATYPE_NAME. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_u8 est utilisée pour récupérer un entier de 8 bits de l'enregistrement RR lorsque le type de données est ARES_DATATYPE_U8. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_u16 est utilisée pour récupérer un entier de 16 bits de l'enregistrement RR lorsque le type de données est ARES_DATATYPE_U16. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_u32 est utilisée pour récupérer un entier de 32 bits de l'enregistrement RR lorsque le type de données est ARES_DATATYPE_U32. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_bin est utilisée pour récupérer des données binaires de l'enregistrement RR lorsque le type de données est ARES_DATATYPE_BIN ou ARES_DATATYPE_BINP. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key, et la longueur est stockée dans la variable pointée par len.

La fonction ares_dns_rr_get_abin_cnt est utilisée pour récupérer le nombre d'éléments dans le tableau de valeurs binaires stockées de l'enregistrement RR lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_abin est utilisée pour récupérer des données binaires du tableau d'enregistrements RR lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key, et l'index à partir duquel récupérer dans le tableau est fourni par le paramètre idx, et la longueur est stockée dans la variable pointée par len.

La fonction ares_dns_rr_get_opt_cnt est utilisée pour récupérer le nombre d'options/paramètres associés à l'enregistrement RR lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key.

La fonction ares_dns_rr_get_opt est utilisée pour récupérer des données binaires d'option de l'enregistrement RR lorsque le type de données est ARES_DATATYPE_OPT pour l'index spécifié. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key, l'index à partir duquel récupérer les données d'option est fourni dans le paramètre idx. La valeur est stockée dans la variable pointée par val et la longueur est stockée dans la variable pointée par val_len.

La fonction ares_dns_rr_get_opt_byid est utilisée pour récupérer des données binaires d'option de l'enregistrement RR lorsque le type de données est ARES_DATATYPE_OPT pour l'identifiant d'option spécifié, s'il existe. L'enregistrement RR est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fournie dans le paramètre key, l'identifiant à partir duquel récupérer les données d'option est fourni dans le paramètre opt. La valeur est stockée dans la variable pointée par val et la longueur est stockée dans la variable pointée par val_len.

VALEURS DE RETOUR

ares_dns_record_rr_cnt et ares_dns_rr_get_opt_cnt retournent les comptes respectifs.

ares_dns_record_rr_add, ares_dns_record_rr_del, ares_dns_rr_set_addr, ares_dns_rr_set_addr6, ares_dns_rr_set_str, ares_dns_rr_set_u8, ares_dns_rr_set_u16, ares_dns_rr_set_u32, ares_dns_rr_set_bin, ares_dns_rr_add_abin, ares_dns_rr_del_abin, et ares_dns_rr_set_opt retournent tous un code d'erreur ares_status_t. ARES_SUCCESS est retourné en cas de succès, ARES_ENOMEM est retourné en cas de manque de mémoire, ARES_EFORMERR est retourné en cas de mauvaise utilisation.

ares_dns_rr_get_name, ares_dns_rr_get_type, ares_dns_rr_get_class, ares_dns_rr_get_ttl, ares_dns_rr_get_addr, ares_dns_rr_get_addr6, ares_dns_rr_get_str, ares_dns_rr_get_u8, ares_dns_rr_get_u16, ares_dns_rr_get_u32, ares_dns_rr_get_bin, ares_dns_rr_get_abin_cnt, ares_dns_rr_get_abin, ares_dns_rr_get_opt retournent tous leurs valeurs de type de données prescrites et en général ne peuvent pas échouer, sauf en cas de mauvaise utilisation, auquel cas un 0 (ou NULL) peut être retourné, cependant 0 peut aussi être une valeur de retour valide pour la plupart de ces fonctions.

ares_dns_record_rr_get et ares_dns_record_rr_get_const retourneront le pointeur d'enregistrement RR demandé ou NULL en cas d'échec (mauvaise utilisation).

ares_dns_rr_get_opt_byid retournera ARES_TRUE si l'option a été trouvée, sinon ARES_FALSE si elle n'a pas été trouvée (ou mauvaise utilisation).
