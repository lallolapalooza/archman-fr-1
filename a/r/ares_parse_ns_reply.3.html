NOM

ares_parse_ns_reply - Analyse une réponse à une requête DNS de type NS en un hostent

SYNTAXE

#include <ares.h>
int ares_parse_ns_reply(const unsigned char *abuf, int alen,
                        struct hostent **host);

DESCRIPTION

La fonction ares_parse_ns_reply analyse la réponse à une requête de type NS en une structure struct hostent. Les paramètres abuf et alen donnent le contenu de la réponse. Le résultat est stocké dans une mémoire allouée et un pointeur vers celle-ci est stocké dans la variable pointée par host. Les serveurs de noms sont stockés dans le champ aliases de la structure host. Il incombe à l'appelant de libérer la structure host résultante en utilisant ares_free_hostent(3) lorsqu'elle n'est plus nécessaire.

VALEURS DE RETOUR

ares_parse_ns_reply peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
La réponse a été analysée avec succès.
ARES_EBADRESP
La réponse était malformée.
ARES_ENODATA
La réponse ne contenait pas de réponse à la requête.
ARES_ENOMEM
La mémoire a été épuisée.
