ares_set_servers(3)

Paquet: c-ares

Licences: MIT

ARES_SET_SERVERS(3) Manuel des fonctions de bibliothèque ARES_SET_SERVERS(3)

NOM

ares_set_servers, ares_set_servers_ports - Initialise la configuration des serveurs de noms pour un canal ares. (obsolète)

SYNOPSIS

#include <ares.h>
int ares_set_servers(ares_channel_t *channel,
                     const struct ares_addr_node *servers)
int ares_set_servers_ports(ares_channel_t *channel,
                           const struct ares_addr_port_node *servers)

DESCRIPTION

La fonction ares_set_servers(3) initialise la configuration des serveurs de noms pour les données du canal identifiées par channel, à partir d'un pointeur servers vers une liste chaînée de structures ares_addr_node contenant les données d'adresse des serveurs de noms.

L'argument pointeur de liste chaînée de serveurs de noms peut être le résultat d'un appel précédent à ares_get_servers(3) ou une liste chaînée de structures ares_addr_node configurée par d'autres moyens.

La fonction ares_set_servers_ports(3) permet également de spécifier les ports UDP et TCP à utiliser pour la communication sur une base par serveur. L'argument liste chaînée fourni peut être le résultat d'un appel précédent à ares_get_servers_ports(3) ou une liste chaînée de structures ares_addr_port_node configurée par d'autres moyens.

Cette fonction remplace tous les serveurs de noms potentiellement configurés précédemment par ceux donnés dans la liste chaînée. Ainsi, afin de configurer un canal avec plus d'un serveur de noms, tous ceux souhaités doivent être spécifiés dans une seule liste. Bien que déconseillé, passer NULL effacera tous les serveurs configurés et rendra le canal inopérant, ce qui peut être avantageux pour la simulation de tests mais peu utile en production.

La fonction ne prend pas possession de l'argument liste chaînée. L'appelant est responsable de la libération de la liste chaînée lorsqu'elle n'est plus nécessaire.

Cette fonction est capable de gérer simultanément des adresses de serveurs de noms IPv4 et IPv6, rendant ares_init_options(3) avec optmask ARES_OPT_SERVERS fonctionnellement obsolète sauf pour l'utilisation de serveurs de noms uniquement IPv4.

Depuis la version v1.22.0, cette fonction peut être appelée sur un canal actif avec des requêtes en cours, auparavant elle renvoyait ARES_ENOTIMP.

VALEURS DE RETOUR

ares_set_servers(3) peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
La configuration des serveurs de noms a été initialisée avec succès.
ARES_ENOMEM
La mémoire disponible du processus a été épuisée.
ARES_ENODATA
Les données du canal identifiées par channel étaient invalides.
ARES_ENOTINITIALIZED
L'initialisation de la bibliothèque c-ares n'a pas encore été effectuée.

VOIR AUSSI

ares_set_servers_csv(3), ares_get_servers(3), ares_init_options(3), ares_dup(3)

NOTES

Fonctions obsolètes depuis c-ares 1.24.0 en raison de l'incapacité à définir toutes les options de serveur disponibles. Utilisez ares_set_servers_csv(3).

DISPONIBILITÉ

ares_set_servers(3) a été ajouté dans c-ares 1.7.1 ; ares_set_servers_ports(3) a été ajouté dans c-ares 1.11.0.
