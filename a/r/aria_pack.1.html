NOM

aria_pack - génère des tables Aria compressées et en lecture seule

SYNOPSIS

aria_pack [OPTIONS] nom_de_fichier...

DESCRIPTION

Compresse une table Aria pour qu'elle prenne beaucoup moins de place. Les clés ne sont pas mises à jour, vous devez exécuter aria_chk -rq sur le fichier d'index (.MAI) par la suite pour mettre à jour les clés. Vous devriez spécifier le fichier .MAI comme argument nom_de_fichier. Pour décompresser une table compressée, exécutez aria_chk -u sur la table.

-b, --backup
Crée une sauvegarde de la table sous le nom nom_table.OLD.
--character-sets-dir=nom
Répertoire où se trouvent les jeux de caractères.
-#, --debug[=nom]
Sortie du journal de débogage. Souvent de la forme 'd:t:o,nom_de_fichier'.
-f, --force
Force la compression de la table même si elle devient plus grande ou si un fichier temporaire existe.
-j, --join=nom
Joint toutes les tables données dans 'nouveau_nom_de_table'. Toutes les tables DOIVENT avoir des schémas identiques.
-?, --help
Affiche cette aide et quitte.
-s, --silent
Soit plus silencieux.
-T, --tmpdir=nom
Utilise le répertoire temporaire pour stocker la table temporaire.
-t, --test
Ne compresse pas la table, seulement teste sa compression.
-v, --verbose
Écrit des informations sur la progression et le résultat de la compression. Utilisez plusieurs -v pour plus de verbosité !
-V, --version
Affiche les informations de version et quitte.
-w, --wait
Attend et réessaie si la table est en cours d'utilisation.

Les options par défaut sont lues à partir des fichiers suivants dans l'ordre spécifié : /etc/my.cnf /etc/mysql/my.cnf ~/.my.cnf

Les groupes suivants sont lus : ariapack

Les options suivantes peuvent être fournies comme premier argument :

--print-defaults
Affiche la liste des arguments du programme et quitte.
--no-defaults
Ne lit pas les options par défaut à partir d'un fichier d'options.
--defaults-file=#
Lit uniquement les options par défaut à partir du fichier # spécifié.
--defaults-extra-file=#
Lit ce fichier après que les fichiers globaux ont été lus.
