NOM

arpspoof - intercepter des paquets sur un LAN commuté

SYNOPSIS

arpspoof [-i interface] [-c propre|hote|les_deux] [-t cible] [-r] hote

DESCRIPTION


arpspoof redirige les paquets d'un hôte cible (ou de tous les hôtes) sur le LAN destinés à un autre hôte sur le LAN en falsifiant des réponses ARP. C'est un moyen extrêmement efficace pour renifler le trafic sur un commutateur.

Le transfert IP du noyau (ou un programme en espace utilisateur qui réalise la même chose, par exemple fragrouter(8)) doit être activé au préalable.

OPTIONS

-i interface
Spécifie l'interface à utiliser.
-c propre|hote|les_deux
Spécifie quelle adresse matérielle utiliser lors de la restauration de la configuration ARP ; lors du nettoyage, les paquets peuvent être envoyés avec la propre adresse ainsi qu'avec l'adresse de l'hôte. L'envoi de paquets avec une fausse adresse matérielle peut perturber la connectivité avec certaines configurations de commutateur/point d'accès/pont, cependant cela fonctionne plus de manière fiable qu'en utilisant la propre adresse, qui est la manière par défaut dont arpspoof nettoie ensuite.
-t cible
Spécifie un hôte particulier à empoisonner par ARP (si non spécifié, tous les hôtes sur le LAN). Répéter pour spécifier plusieurs hôtes.
-r
Empoisonne les deux hôtes (hôte et cible) pour capturer le trafic dans les deux directions. (valide uniquement en conjonction avec -t)
hote
Spécifie l'hôte pour lequel vous souhaitez intercepter les paquets (généralement la passerelle locale).
