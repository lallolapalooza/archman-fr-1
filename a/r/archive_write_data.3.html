ARCHIVE_WRITE_DATA(3) Manuel des fonctions de bibliothèque ARCHIVE_WRITE_DATA(3)

NOM

archive_write_data, archive_write_data_block — fonctions de création d'archives

BIBLIOTHÉQUE

Bibliothèque d'archives en flux (libarchive, -larchive)

SYNOPSIS

#include <archive.h>

la_ssize_t
archive_write_data(struct archive *, const void *, size_t);

la_ssize_t
archive_write_data_block(struct archive *, const void *, size_t size, int64_t offset);

DESCRIPTION

archive_write_data()
Écrit les données correspondant à l'en-tête qui vient d'être écrit.
archive_write_data_block()
Écrit les données correspondant à l'en-tête qui vient d'être écrit. Ceci est similaire à archive_write_data() sauf qu'il effectue une opération de recherche sur le fichier en cours d'écriture à l'offset spécifié avant d'écrire les données. Ceci est utile lors de la restauration de fichiers épars à partir de formats d'archive qui prennent en charge les fichiers épars. Renvoie le nombre d'octets écrits ou -1 en cas d'erreur. (Remarque : Ceci n'est actuellement pas pris en charge pour les descripteurs archive_write, uniquement pour les descripteurs archive_write_disk.

VALEURS DE RETOUR

Cette fonction renvoie le nombre d'octets effectivement écrits, ou un code d'erreur négatif en cas d'erreur.

ERREURS

Les codes d'erreur détaillés et les descriptions textuelles sont disponibles auprès des fonctions archive_errno() et archive_error_string().

BOGUES

Dans libarchive 3.x, cette fonction renvoie parfois zéro en cas de succès au lieu de renvoyer le nombre d'octets écrits. Cela se produit spécifiquement lors de l'écriture vers un descripteur archive_write_disk. Les clients doivent traiter toute valeur inférieure à zéro comme une erreur et considérer toute valeur non négative comme un succès.

VOIR AUSSI

tar(1), archive_write_finish_entry(3), archive_write_set_options(3), libarchive(3), cpio(5), mtree(5), tar(5)
