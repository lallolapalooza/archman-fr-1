ARES_REINIT(3) Manuel des fonctions de bibliothèque ARES_REINIT(3)

NOM

ares_reinit - Réinitialise un canal de résolution à partir de la configuration système.

SYNOPSIS

#include <ares.h>
int ares_reinit(ares_channel_t *channel)

DESCRIPTION

La fonction ares_reinit(3) relit la configuration système et l'applique de manière sûre au canal existant. La configuration système ne remplacera jamais les paramètres fournis par l'utilisateur, tels que ceux fournis via ares_init_options(3) ou ares_set_servers(3).

Toutes les requêtes existantes seront automatiquement replacées si le serveur auquel elles sont actuellement assignées est supprimé de la configuration système.

Cette fonction peut entraîner la création de descripteurs de fichier supplémentaires et la destruction de descripteurs existants si la configuration du serveur a changé.

Elle est thread-safe et lancera un thread d'arrière-plan pour lire la configuration et l'appliquer. Il est crucial que les développeurs utilisent l'option ARES_OPT_SOCK_STATE_CB ou ARES_OPT_EVENT_THREAD afin que les notifications de changements soient alertées. Si vous utilisez ares_getsock(3) ou ares_fds(3), aucune notification n'est possible, ce qui pourrait entraîner un blocage.

VALEURS DE RETOUR

ares_reinit(3) peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
L'initialisation a réussi.
ARES_EFILE
Un fichier de configuration n'a pas pu être lu.
ARES_ENOMEM
La mémoire disponible du processus a été épuisée.

DISPONIBILITÉ

Cette fonction a été introduite pour la première fois dans la version 1.22.0 de c-ares.
