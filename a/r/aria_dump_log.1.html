ARIA_DUMP_LOG(1) Commandes utilisateur ARIA_DUMP_LOG(1)

NOM

aria_dump_log - Affiche le contenu des pages de log d'Aria.

SYNTAXE

aria_dump_log -f fichier OPTIONS

DESCRIPTION

Affiche le contenu des pages de log d'Aria.

-#, --debug[=nom]
Affiche le journal de débogage. Souvent, l'argument est 'd:t:o,nom_fichier'.
-f, --file=nom
Chemin vers le fichier qui sera lu.
-?, --help
Affiche cette aide et quitte.
-o, --offset=#
Commence la lecture du log à partir de ce décalage.
-n, --pages=#
Nombre de pages à lire.
-U, --unit-test
Utilise la table d'enregistrements de tests unitaires (pour les logs créés par les tests unitaires).
-V, --version
Affiche la version et quitte.

Les options par défaut sont lues à partir des fichiers suivants dans l'ordre donné : /etc/my.cnf /etc/mysql/my.cnf ~/.my.cnf

Les groupes suivants sont lus : aria_dump_log

Les options suivantes peuvent être fournies comme premier argument :

--print-defaults
Affiche la liste des arguments du programme et quitte.
--no-defaults
Ne lit pas les options par défaut à partir d'un fichier d'options.
--defaults-file=#
Lit uniquement les options par défaut à partir du fichier # donné.
--defaults-extra-file=#
Lit ce fichier après que les fichiers globaux aient été lus.
