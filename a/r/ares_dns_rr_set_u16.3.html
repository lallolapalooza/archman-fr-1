DESCRIPTION

renvoie le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section fournie dans le paramètre sect. La fonction ares_dns_record_rr_add(3) ajoute

une

nouvelle entrée d'enregistrement de ressources à l'enregistrement DNS fourni par le paramètre dnsrec. L'enregistrement de ressources résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle appartient l'enregistrement de ressources est spécifiée par le paramètre sect. Le nom de domaine associé à l'enregistrement de ressources est spécifié par le paramètre name, qui ne peut pas être NULL mais peut être une chaîne vide ou « . ». Le type d'enregistrement de ressources est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le Time To Live (TTL) dans le paramètre ttl. Les fonctions ares_dns_record_rr_get(3) et ares_dns_record_rr_get_const(

3)

The sont utilisées pour récupérer le pointeur de l'enregistrement de ressources à partir de l'enregistrement DNS fourni dans le paramètre dnsrec, pour la section d'enregistrement de ressources fournie dans le paramètre sect, pour l'index spécifié dans le paramètre idx. L'index doit être inférieur à [[109]] ares_dns_record_rr_cnt(3). La première fonction renvoie un pointeur modifiable vers l'enregistrement de ressources, tandis que la seconde renvoie un pointeur en lecture seule vers l'enregistrement de ressources. La fonction ares_dns_record_rr_del(3)

est

utilisée pour supprimer un enregistrement de ressources de l'enregistrement DNS spécifié dans le paramètre dnsrec. Son utilisation principale est de supprimer un enregistrement ARES_REC_TYPE_OPT lorsqu'il est nécessaire de réessayer une requête sans support EDNS. La section RR DNS est spécifiée via le paramètre sect, et l'index à supprimer est spécifié dans le paramètre idx. L'index doit être inférieur à [[116]] ares_dns_record_rr_cnt(3). La fonction ares_dns_rr_get_addr6(3) est utilisée pour récupérer l'adresse IPv6 depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_INADDR6. L'enregistrement est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_str(3) est utilisée pour récupérer une chaîne depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_STR ou ARES_DATATYPE_NAME. L'enregistrement est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_u8(3) est utilisée pour récupérer un entier 8 bits depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_U8. L'enregistrement est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_u16(3) est utilisée pour récupérer un entier 16 bits depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_U16. L'enregistrement est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_u32(3) est utilisée pour récupérer un entier 32 bits depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_U32. L'enregistrement est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_bin(3) est utilisée pour récupérer des données binaires depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_BIN ou ARES_DATATYPE_BINP. L'enregistrement est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre key, et la longueur est stockée dans la variable pointée par len

.

La fonction ares_dns_rr_get_abin_cnt(3) est utilisée pour récupérer le nombre d'éléments du tableau de valeurs binaires stockées depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre

key.

La fonction ares_dns_rr_get_abin(3) est utilisée pour récupérer des données binaires depuis le tableau de l'enregistrement lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre key, et l'index à récupérer depuis le tableau est fourni par le paramètre idx, et la longueur est stockée dans la variable pointée par len

.

La fonction ares_dns_rr_get_opt_cnt(3) est utilisée pour récupérer le nombre d'options/paramètres associés à l'enregistrement lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le key

.

La fonction ares_dns_rr_get_opt(3) est utilisée pour récupérer des données d'option binaires depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_OPT pour l'index spécifié. L'enregistrement est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre key, l'index à partir duquel récupérer les données d'option est fourni dans le paramètre idx. La valeur est stockée dans la variable pointée par val et la longueur est stockée dans la variable pointée par val_len

.

La fonction ares_dns_rr_get_opt_byid(3) est utilisée pour récupérer des données d'option binaires depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_OPT pour l'identifiant d'option spécifié, s'il existe. L'enregistrement est fourni dans le paramètre dns_rr et la clé/paramètre à récupérer est fourni dans le paramètre key, l' identifiant à partir duquel récupérer les données d'option est fourni dans le paramètre opt . La valeur est stockée dans la variable pointée par val et la longueur est stockée dans la variable pointée par val_le

n
.
