FBB::Arg(3bobcat) Arguments de ligne de commande FBB::Arg(3bobcat)

NOM

FBB::Arg - Une classe singleton pour interagir avec les arguments de ligne de commande

SYNOPSIS

#include <bobcat/arg>
Option de liaison : -lbobcat

DESCRIPTION

Classe singleton (voir Gamma et al., 1995) construite autour de getopt_long()(3). La classe gère les options de ligne de commande courtes et longues,

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HÉRITE DE

-

ÉNUMÉRATION

L'énumération FBB::Arg::Type est définie par la classe FBB::Arg. Elle est utilisée pour spécifier si les options longues nécessitent ou non des arguments. Elle définit les valeurs suivantes : None, Required, Optional.

o
None : l'option longue n'utilise pas d'argument ;
o
Required : l'option longue nécessite une valeur d'argument ;
o
Optional : l'option longue peut éventuellement être fournie avec une valeur d'argument ;

Ces valeurs sont utilisées lors de la définition des options longues (comme --version), qui sont définies comme des objets de la classe (imbriquée) FBB::Arg::LongOption.

LA CLASSE IMBRIQUÉE FBB::Arg::LongOption

Les options longues sont définies à l'aide d'objets de la classe imbriquée FBB::Arg::LongOption. Cette classe fournit les constructeurs suivants :

o
FBB::Arg::LongOption(char const *name, FBB::Arg::Type type = FBB::Arg::None) :
Ce constructeur est utilisé pour définir une option longue pour laquelle aucune option courte correspondante n'est définie. Le paramètre name est le nom de l'option longue (sans spécifier les caractères -- qui ne sont requis que lors de la spécification d'une option longue lors de l'appel d'un programme).
o
FBB::Arg::LongOption(char const *name, int optionChar) :
Ce constructeur est utilisé pour définir une option longue pour laquelle une option courte correspondante est définie. Le paramètre name est le nom de l'option longue (sans spécifier les caractères -- qui ne sont requis que lors de la spécification d'une option longue lors de l'appel d'un programme).

Pour définir des options longues, utilisez la procédure suivante :

o
D'abord, construisez un tableau 
    FBB::Arg::LongOption longOptions[] = { c1, c2, ..., cn };
Où c1, c2, ..., cn sont n invocations de constructeur de FBB::Arg::LongOption()
o
Ensuite, passez longOptions, LongOptions + n comme arguments à un membre Arg::initialize qui prend en charge les options longues.

Les objets de la classe LongOptions sont normalement utilisés en interne par l'objet Arg, mais ils peuvent également être utilisés en dehors de l'objet Arg. Pour cette situation, les membres suivants sont disponibles :

o
std::string const &longName() const :
retourne le nom de l'option longue de LongOption ;
o
int optionChar() const :
retourne le caractère d'option de LongOption (ou l'une des valeurs de l'énumération Arg::Type s'il n'y a pas de caractère d'option associé à LongOption).

CONSTRUCTEURS

Comme la classe Arg est un singleton, il n'y a pas de constructeurs publics. À la place, des membres statiques sont disponibles pour initialiser et accéder à l'unique objet FBB::Arg.

MEMBRES STATIQUES

Tous les membres initialize initialisent le singleton FBB::Arg, et ne peuvent être appelés qu'une seule fois. Une exception est levée lorsqu'ils sont appelés plusieurs fois. Tous les membres initialize retournent une référence à l'objet singleton Arg initialisé.

Tous les membres initialize définissent les paramètres argc et argv qui sont interprétés comme les paramètres argc et argv de main. Lorsqu'un élément argv pointe vers deux tirets consécutifs (--) alors cet élément est ignoré, et tous les éléments suivants de argv sont considérés comme des arguments plutôt que des options.

o
FBB::Arg &Arg::initialize(char const *optstring, int argc, char **argv) :
Le paramètre optstring est une chaîne de caractères terminée par un octet nul (NTBS) commençant éventuellement par un caractère +, mais contenant sinon des caractères d'option. Un ou deux deux-points peuvent être ajoutés aux caractères d'option :
o
un seul deux-points (:) indique que l'option nécessite une valeur d'option.
o
un double deux-points (::) indique que l'option a un argument optionnel. Avec les options courtes, la valeur de l'option est considérée comme absente à moins qu'elle ne soit attachée à l'option courte (par exemple, -tvaleur). Les options longues acceptant éventuellement des arguments doivent toujours être immédiatement suivies d'un caractère d'affectation (=), immédiatement suivi de la valeur de l'option (qui doit commencer par un caractère non blanc). Par exemple, --valeur= indique une valeur d'option absente, --valeur=texte indique que la valeur de l'option est texte. Si une valeur d'option contient elle-même des espaces, elle doit être entourée de guillemets simples ou doubles (par exemple, -t’cette valeur’, ou --texte=’cette valeur’). Les guillemets environnants ne font pas partie de la valeur de l'option.
Lorsque le premier caractère de optstring est + alors toutes les options non spécifiées sont considérées comme des arguments, apparaissant dans la liste finale des arguments à leurs positions d'argument actuelles. Par exemple, lorsque optstring est +ab et qu'aucune option longue n'est définie, alors appeler 
    prog -a -z -b -yvaleur --long arg1 arg2
résulte en ce que le membre argv retourne un vecteur contenant les éléments -z, -yvaleur, --long, arg1, et arg2. Si le premier caractère de optstring n'est pas + et qu'une option non définie est rencontrée alors une exception est levée.
o
FBB::Arg &Arg::initialize(int accept, char const *optstring, int argc, char **argv) :
Agit comme le membre précédent, mais définit en plus le paramètre accept spécifiant un caractère d'option à partir duquel tous les arguments et options suivants sont considérés comme des arguments. Pour ignorer accept, la valeur 0 (pas le caractère ’0’) peut être spécifiée ou des membres initialize peuvent être utilisés qui ne définissent pas de paramètre accept.
Lorsque les arguments contiennent à la fois une option accept et deux tirets consécutifs, le premier est interprété, ce qui entraîne l'interprétation de tous les éléments argv restants comme de simples arguments. Par exemple, lors de la spécification de initialize(’t’, ...) et de l'appel 
    prog un -tdeux -c -- trois
alors le membre argv retourne un vecteur contenant les éléments un, -tdeux, -c, --, et trois (voir également le membre beyondDashes ci-dessous).
o
FBB::Arg &Arg::initialize(char const *optstring, Arg::LongOption const *const begin, Arg::LongOption const *const end, int argc, char **argv) :
Agit comme le premier membre Arg::initialize, mais définit en plus deux paramètres spécifiant la plage d'éléments d'un tableau d'objets Arg::LongOption définissant des options longues. Le paramètre begin pointe
ts au premier élément de la plage, le paramètre end pointe juste au-delà du dernier élément de la plage. Par exemple, après avoir défini 
    FBB::Arg::LongOption longOptions[] = { c1, c2, ..., cn };
les arguments passés à begin et end pourraient être spécifiés comme 
    initialize(..., longOptions, longOptions + size(longOptions)
, ...);
o
FBB::Arg &Arg::initialize(char accept, char const *optstring, LongOption const *const begin, LongOption const *const end, int argc, char **argv)
:
Se comporte comme le membre Arg::initialize précédent, mais définit en plus un paramètre accept tel que défini par le deuxième membre Arg::ini
tialize.
o
FBB::Arg &Arg::instance():
Une fois qu'un membre Arg::initialize a été appelé, ce membre peut être appelé de n'importe où dans le programme (et il peut être appelé plusieurs fois), retournant une référence à l'objet Arg initia
lisé.
S'il est appelé avant qu'un membre Arg::initialize ait é
té appelé, une exception est levée.

NAME

arg — Argument-parsing class

SYNOPSIS

#include <bobcat/arg>
namespace FBB
{
    class Arg
    {
        // ...
        public:
            // ...
            void versionHelp(
                std::ostream &out,
                const std::string &version,
                size_t minArgs);
            // ...
    };
}

DESCRIPTION

The Arg class implements command-line argument parsing.

The versionHelp() member function may be used to implement automatic handling of the --help and --version options. This is particularly useful when these options are specified via the longOptions[] argument of the Arg::initialize function.

When either the --help or --version options are encountered, the versionHelp() function is called:

  • If the option is --help, the usage message obtained from the usage argument, and any available long-option descriptions, will be printed to the out stream. The program then terminates.
  • If the option is --version, the version string specified by the version argument is printed to the out stream. The program then terminates.

The minArgs argument specifies the minimum number of positional arguments that must be present on the command line. If fewer arguments are provided, an exception is thrown.

The nArgs() member function returns the number of positional arguments found on the command line. The beyondDashes() member function returns the number of positional arguments that appear after the optional -- separator.

Typically, minArgs is set to the number of arguments required by the application. For example, if an application requires 3 arguments (e.g. input file, output file, and configuration file), minArgs can be set to 3. If the application should also accept options after the -- separator, add the number of arguments beyond the dashes (obtained by calling nArgs() - beyondDashes()) to the minimum required arguments.

Example:

    arg.versionHelp(usage, version, 2 + arg.nArgs()
                                      - arg.beyondDashes());

The address of the usage() function, the current version and the minimum number of arguments must be specified. Default argument values are provided for the option flags.

EXAMPLE

The following example illustrates defining long options and shows an initialization. It is not a full-fledched example in the sense of a small runnable program.

#include <bobcat/arg>
using namespace FBB;
using namespace std;
namespace   // the anonymous namespace can be used here
{
    Arg::LongOption longOptions[] =
    {
        Arg::LongOption{"debug"},
        Arg::LongOption{"filenames", ’f’},
        Arg::LongOption{"help", ’h’},
        Arg::LongOption{"version", ’v’},
    };
    auto longEnd = longOptions + size(longOptions);
}
int main(int argc, char **argv)
try
{
    Arg &arg = Arg::initialize("df:hv",
                    longOptions, longEnd,
                    argc, argv);
    // code using arg, etc.
}
catch (exception const &err)     // handle exceptions
{
    cerr << err.what() << ’\n’;
    return 1;
}
