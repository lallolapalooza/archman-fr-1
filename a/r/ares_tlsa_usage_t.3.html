DESCRIPTION

La fonction ares_dns_record_rr_cnt(3) renvoie le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section spécifiée par le paramètre sect.

La fonction ares_dns_record_rr_add(3) ajoute une nouvelle entrée d'enregistrement de ressources à l'enregistrement DNS fourni par le paramètre dnsrec. L'enregistrement de ressources résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle l'enregistrement de ressources appartient est spécifiée par le paramètre sect. Le nom de domaine associé à l'enregistrement de ressources est spécifié par le paramètre name, qui ne peut pas être NULL mais peut être une chaîne vide, ou ".". Le type d'enregistrement de ressources est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le Temps de Vie (TTL) dans le paramètre ttl.

Les fonctions ares_dns_record_rr_get(3) et ares_dns_record_rr_get_const(3) sont utilisées pour récupérer le pointeur d'enregistrement de ressources à partir de l'enregistrement DNS fourni dans le paramètre dnsrec, pour la section d'enregistrements de ressources fournie dans le paramètre sect, pour l'index spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_rr_cnt(3). La première renvoie un pointeur modifiable vers l'enregistrement de ressources, tandis que la seconde renvoie un pointeur en lecture seule vers l'enregistrement de ressources.

La fonction ares_dns_record_rr_del(3) est utilisée pour supprimer un enregistrement de ressources de l'enregistrement DNS spécifié dans le paramètre dnsrec. Son utilisation principale est de supprimer un enregistrement de type ARES_REC_TYPE_OPT lors de la nécessité de relancer une requête sans prise en charge EDNS. La section RR DNS est spécifiée via le paramètre sect, et l'index à supprimer est spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_rr_cnt(3).

La fonction ares_dns_rr_get_name(3) est utilisée pour récupérer le nom de domaine de l'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr.

La fonction ares_dns_rr_get_type(3) est utilisée pour récupérer le type d'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr.

La fonction ares_dns_rr_get_class(3) est utilisée pour récupérer la classe d'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr.

La fonction ares_dns_rr_get_ttl(3) est utilisée pour récupérer le Temps de Vie (TTL) de l'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr.

La fonction ares_dns_rr_set_addr(3) est utilisée pour définir une adresse IPv4 pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_INADDR. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre addr.

La fonction ares_dns_rr_set_addr6(3) est utilisée pour définir une adresse IPv6 pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_INADDR6. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre addr.

La fonction ares_dns_rr_set_str(3) est utilisée pour définir une chaîne de caractères pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_STR ou ARES_DATATYPE_NAME. La plupart des chaînes sont limitées à 255 octets, cependant certains enregistrements, comme un enregistrement TXT, peuvent permettre des longueurs plus importantes car ils sont renvoyés sous forme de chaînes multiples. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre val.

La fonction ares_dns_rr_set_u8(3) est utilisée pour définir une valeur non signée de 8 bits pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_U8. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre val.

La fonction ares_dns_rr_set_u16(3) est utilisée pour définir une valeur non signée de 16 bits pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_U16. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre val.

La fonction ares_dns_rr_set_u32(3) est utilisée pour définir une valeur non signée de 32 bits pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_U32. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre val.

La fonction ares_dns_rr_set_bin(3) est utilisée pour définir une valeur binaire pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_BIN ou ARES_DATATYPE_BINP. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre val. Et la longueur associée de la valeur est fournie dans le paramètre len.

La fonction ares_dns_rr_add_abin(3) est utilisée pour ajouter une valeur binaire dans le tableau pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre val. Et la longueur associée de la valeur est fournie dans le paramètre len.

La fonction ares_dns_rr_del_abin(3) est utilisée pour supprimer une valeur binaire du tableau pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournividé dans le clé paramètre, et l'index à supprimer est fourni dans le idx paramètre.

La fonction ares_dns_rr_set_opt(3) est utilisée pour définir les clés et valeurs d'options/paramètres pour l'enregistrement lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement à modifier est fourni dans le dns_rr paramètre. La clé/paramètre est fournie dans le key paramètre. La valeur d'option/paramètre spécifique à l'enregistrement est fournie dans le opt paramètre, et il appartient à l'utilisateur de déterminer la valeur appropriée à utiliser. Certaines valeurs connues peuvent être fournies par les énumérations ares_svcb_param_t et ares_opt_param_t . La valeur de l'option est toujours fournie sous forme binaire dans val avec la longueur fournie dans val_len.

La fonction ares_dns_rr_del_opt_byid(3) est utilisée pour supprimer les clés et valeurs d'options/paramètres pour l'enregistrement lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement à modifier est fourni dans le dns_rr paramètre. La clé/paramètre est fournie dans le key paramètre. La valeur d'option/paramètre spécifique à l'enregistrement est fournie dans le opt paramètre. Cette fonction retourne ARES_SUCCESS si l'enregistrement est supprimé avec succès, ou ARES_ENOTFOUND si l'enregistrement n'a pas pu être trouvé.

La fonction ares_dns_rr_get_addr(3) est utilisée pour récupérer l'adresse IPv4 depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_INADDR. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key paramètre.

La fonction ares_dns_rr_get_addr6(3) est utilisée pour récupérer l'adresse IPv6 depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_INADDR6. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key paramètre.

La fonction ares_dns_rr_get_str(3) est utilisée pour récupérer une chaîne depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_STR ou ARES_DATATYPE_NAME. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key paramètre.

La fonction ares_dns_rr_get_u8(3) est utilisée pour récupérer un entier 8 bits depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_U8. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key paramètre.

La fonction ares_dns_rr_get_u16(3) est utilisée pour récupérer un entier 16 bits depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_U16. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key paramètre.

La fonction ares_dns_rr_get_u32(3) est utilisée pour récupérer un entier 32 bits depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_U32. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key paramètre.

La fonction ares_dns_rr_get_bin(3) est utilisée pour récupérer des données binaires depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_BIN ou ARES_DATATYPE_BINP. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key paramètre, et la longueur est stockée dans la variable pointée par len.

La fonction ares_dns_rr_get_abin_cnt(3) est utilisée pour récupérer le nombre d'éléments du tableau de valeurs binaires stockées depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key paramètre.

La fonction ares_dns_rr_get_abin(3) est utilisée pour récupérer des données binaires depuis le tableau de l'enregistrement lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key paramètre, et l'index à récupérer depuis le tableau est fourni par le idx paramètre, et la longueur est stockée dans la variable pointée par len.

La fonction ares_dns_rr_get_opt_cnt(3) est utilisée pour récupérer le nombre d'options/paramètres associés à l'enregistrement lorsque le type de données est ARES_DATATYPE_OPT. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key.

La fonction ares_dns_rr_get_opt(3) est utilisée pour récupérer des données d'option binaires depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_OPT pour l'index spécifié. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key paramètre, l'index à partir duquel récupérer les données d'option est fourni dans le idx paramètre. La valeur est stockée dans la variable pointée par val et la longueur est stockée dans la variable pointée par val_len.

La fonction ares_dns_rr_get_opt_byid(3) est utilisée pour récupérer des données d'option binaires depuis l'enregistrement lorsque le type de données est ARES_DATATYPE_OPT pour l'identifiant d'option spécifié, s'il existe. L'enregistrement est fourni dans le dns_rr paramètre et la clé/paramètre à récupérer est fournie dans le key paramètre, l' identifiant à partir duquel récupérer les données d'option est fourni dans le opt paramètre. La valeur est stockée dans la variable pointée par val et la longueur est stockée dans la variable pointée par val_len.

VALEURS DE RETOUR

ares_dns_record_rr_cnt(3) et ares_dns_rr_get_opt_cnt(3) retournent les nombres respectifs.

ares_dns_record_rr_add(3), ares_dns_record_rr_del(3), ares_dns_rr_set_addr(3), ares_dns_rr_set_addr6(3), ares_dns_rr_set_str(3), ares_dns_rr_set_u8(3), ares_dns_rr_set_u16(3), ares_dns_rr_set_u32(3), ares_dns_rr_set_bin(3), ares_dns_rr_add_abin(3), ares_dns_rr_del_abin(3), et ares_dns_rr_set_opt(3) retournent tous un code d'erreur ares_status_t . ARES_SUCCESS est retourné en cas de succès, ARES_ENOMEM est retourné en cas de manque de mémoire, ARES_EFORMERR est retourné en cas d'utilisation abusive.

ares_dns_rr_get_name(3), ares_dns_rr_get_type(3), ares_dns_rr_get_class(3), ares_dns_rr_get_ttl(3), ares_dns_rr_get_addr(3), ares_dns_rr_get_addr6(3), ares_dns_rr_get_str(3), ares_dns_rr_get_u8(3), ares_dns_rr_get_u16(3), ares_dns_rr_get_u32(3), ares_dns_rr_get_bin(3), ares_dns_rr_get_abin_cnt(3), ares_dns_rr_get_abin(3), ares_dns_rr_get_opt(3) retournent tous leurs valeurs de type de données prescrites et en général ne peuvent pas échouer sauf en cas d'utilisation abusive, auquel cas 0 (ou NULL) peut être retourné, cependant 0 peut aussi être une valeur de retour valide pour la plupart de ces fonctions.

ares_dns_record_rr_get(3) et ares_dns_record_rr_get_const(3) retourneront le pointeur d'enregistrement demandé ou NULL en cas d'échec (utilisation abusive).

ares_dns_rr_get_opt_byid(3) retournera ARES_TRUE si l'option a été trouvée, sinon ARES_FALSE si elle n'a pas été trouvée (ou utilisation abusive).
