ares_set_server_state_callback(3)

Paquet: c-ares

Licences: MIT

ARES_SET_SERVER_STATE_CALLBACK(3) Manuel des fonctions de bibliothèque ARES_SET_SERVER_STATE_CALLBACK(3)

NOM

ares_set_server_state_callback - Fonction pour définir un rappel d'état de serveur

SYNTAXE

#include <ares.h>
typedef void (*ares_server_state_callback)(const char *server_string,
                                           ares_bool_t success,
                                           int flags,
                                           void *data);
void ares_set_server_state_callback(ares_channel_t *channel,
                                    ares_server_state_callback callback,
                                    void *user_data);

DESCRIPTION

La fonction ares_set_server_state_callback(3) définit une fonction de rappel callback dans le descripteur de canal ares donné channel qui est appelée chaque fois qu'une requête sur le canal se termine. Cela inclut les requêtes réussies et échouées (y compris les erreurs matérielles et les délais d'attente). La fonction de rappel est appelée avec un certain nombre de paramètres décrivant la requête, comme suit.

Le paramètre server_string indique le serveur DNS qui a été utilisé pour la requête, donné sous forme de chaîne de caractères avec le même format retourné par ares_get_servers_csv(3).

Le paramètre success indique si la requête a réussi ou non. Il est défini à ARES_TRUE en cas de succès et à ARES_FALSE en cas d'échec.

Le paramètre flags est un masque de bits indiquant divers aspects de la requête (par exemple, si la requête a utilisé UDP ou TCP). Ceux-ci sont décrits ci-dessous.

Le paramètre data est une référence aux données utilisateur personnalisées user_data qui ont été transmises à ares_set_server_state_callback(3) lors de la définition du rappel d'état du serveur.

Le rappel d'état du serveur peut être utilisé par les applications pour surveiller l'état des serveurs DNS utilisés par un canal ares. Par exemple, il peut être utilisé pour suivre des métriques sur le nombre et les types de requêtes envoyées à chaque serveur ou pour détecter quand un serveur est injoignable ou non sain.

FLAGS

ARES_SERV_STATE_UDP
Indique que la requête a été tentée via UDP.
ARES_SERV_STATE_TCP
Indique que la requête a été tentée via TCP.

DISPONIBILITÉ

Cette fonction a été introduite pour la première fois dans la version 1.29.0 de c-ares.
