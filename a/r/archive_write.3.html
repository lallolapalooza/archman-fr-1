ARCHIVE_WRITE(3) Manuel des fonctions de bibliothèque ARCHIVE_WRITE(3)

NOM

archive_write — fonctions pour la création d'archives

BIBLIOTHÈQUE

Bibliothèque d'archives en flux (libarchive, -larchive)

SYNTAXE

#include <archive.h>

DESCRIPTION

Ces fonctions fournissent une API complète pour la création de fichiers d'archives en flux. Le processus général consiste d'abord à créer l'objet structure archive, à définir les options désirées, à initialiser l'archive, à ajouter des entrées, puis à fermer l'archive et à libérer toutes les ressources.

Créer un objet archive

Voir archive_write_new(3).

Pour écrire une archive, vous devez d'abord obtenir un objet structure archive initialisé à partir de archive_write_new().

Activer les filtres et formats, configurer la taille des blocs et le remplissage

Voir archive_write_filter(3), archive_write_format(3) et archive_write_blocksize(3).

Vous pouvez ensuite modifier cet objet pour les opérations désirées avec les diverses fonctions archive_write_set_XXX(). En particulier, vous devrez invoquer les fonctions appropriées archive_write_add_XXX() et archive_write_set_XXX() pour activer le support de compression et de format correspondant.

Définir les options

Voir archive_write_set_options(3).

Ouvrir l'archive

Voir archive_write_open(3).

Une fois que vous avez préparé l'objet structure archive, vous appelez archive_write_open() pour ouvrir réellement l'archive et la préparer à l'écriture. Il existe plusieurs variantes de cette fonction ; la plus basique attend que vous fournissiez des pointeurs vers plusieurs fonctions capables de fournir des blocs d'octets de l'archive. Il existe des formes pratiques qui vous permettent de spécifier un nom de fichier, un descripteur de fichier, un objet FILE *, ou un bloc de mémoire à partir duquel écrire les données de l'archive.

Produire l'archive

Voir archive_write_header(3) et archive_write_data(3).

Les entrées individuelles de l'archive sont écrites en trois étapes : Vous initialisez d'abord une structure archive_entry avec des informations sur la nouvelle entrée. Au minimum, vous devez définir le nom du chemin de l'entrée et fournir une structure struct stat avec un champ st_mode valide, qui spécifie le type d'objet, et un champ st_size, qui spécifie la taille de la partie données de l'objet.

Libérer les ressources

Voir archive_write_free(3).

Une fois toutes les entrées écrites, utilisez la fonction archive_write_free() pour libérer toutes les ressources.

EXEMPLES

L'esquisse suivante illustre l'utilisation de base de la bibliothèque. Dans cet exemple, les fonctions de rappel ne sont que des enveloppes autour des appels système standard open(2), write(2), et close(2).

#ifdef __linux__
#define	_FILE_OFFSET_BITS 64
#endif
#include <sys/stat.h>
#include <archive.h>
#include <archive_entry.h>
#include <fcntl.h>
#include <stdlib.h>
#include <unistd.h>

struct mydata {
  const char *name;
  int fd;
};

int
myopen(struct archive *a, void *client_data)
{
  struct mydata *mydata = client_data;

  mydata->fd = open(mydata->name, O_WRONLY | O_CREAT, 0644);
  if (mydata->fd >= 0)
    return (ARCHIVE_OK);
  else
    return (ARCHIVE_FATAL);
}

la_ssize_t
mywrite(struct archive *a, void *client_data, const void *buff, size_t n)
{
  struct mydata *mydata = client_data;

  return (write(mydata->fd, buff, n));
}

int
myclose(struct archive *a, void *client_data)
{
  struct mydata *mydata = client_data;

  if (mydata->fd > 0)
    close(mydata->fd);
  return (0);
}

void
write_archive(const char *outname, const char **filename)
{
  struct mydata *mydata = malloc(sizeof(struct mydata));
  struct archive *a;
  struct archive_entry *entry;
  struct stat st;
  char buff[8192];
  int len;
  int fd;

  a = archive_write_new();
  mydata->name = outname;
  /* Définir le format et le filtre de l'archive en fonction de l'extension du fichier de sortie.
   * En cas d'échec, définir le format par défaut. Fonction dépendante de la plateforme.
   * Voir les formats supportés dans archive_write_set_format_filter_by_ext.c */
  if (archive_write_set_format_filter_by_ext(a, outname) != ARCHIVE_OK)  {
    archive_write_add_filter_gzip(a);
    archive_write_set_format_ustar(a);
  }
  archive_write_open(a, mydata, myopen, mywrite, myclose);
  while (*filename) {
    stat(*filename, &st);
    entry = archive_entry_new();
    archive_entry_copy_stat(entry, &st);
    archive_entry_set_pathname(entry, *filename);
    archive_write_header(a, entry);
    if ((fd = open(*filename, O_RDONLY)) != -1) {
      len = read(fd, buff, sizeof(buff));
      while (len > 0) {
        archive_write_data(a, buff, len);
        len = read(fd, buff, sizeof(buff));
      }
      close(fd);
    }
    archive_entry_free(entry);
    filename++;
  }
  archive_write_free(a);
}

int main(int argc, const char **argv)
{
  const char *outname;
  argv++;
  outname = *argv++;
  write_archive(outname, argv);
  return 0;
}

BOGUES

Il existe de nombreux bogues particuliers dans les implémentations historiques de tar qui peuvent amener certains programmes à rejeter les archives écrites par cette bibliothèque. Par exemple, plusieurs implémentations historiques ont calculé les sommes de contrôle d'en-tête de manière incorrecte et rejeteront donc les archives valides ; tar GNU ne prend pas entièrement en charge le format d'échange pax ; certaines anciennes implémentations de tar nécessitaient des terminaisons de champ spécifiques.

Le format d'échange pax par défaut élimine la plupart des limitations historiques de tar et fournit une installation d'attributs clé/valeur générique pour les extensions définies par le fournisseur. Un oubli dans POSIX est l'absence d'un attribut standard pour les grands numéros de périphérique. Cette bibliothèque utilise « SCHILY.devminor » et « SCHILY.devmajor » pour les numéros de périphérique qui dépassent la plage prise en charge par l'en-tête ustar rétrocompatible. Ces clés sont

e compatible avec l'archiveur star de Joerg Schilling. D'autres implémentations peuvent ne pas reconnaître ces clés et ne pourront donc pas restaurer correctement les nœuds de périphérique avec de grands numéros de périphérique à partir des archives créées par cette bibliothèque.
