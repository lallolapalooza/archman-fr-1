DESCRIPTIO

N

Cette commande effectue l'une des plusieurs opérations sur la variable donnée par arrayName. Sauf indication contraire pour les commandes individuelles ci-dessous, arrayName doit être le nom d'une variable de tableau existante. L' argument option détermine l'action effectuée par la commande. Les options autorisées (qui peuvent être abrégées) sont

:
array anymore arrayName
searchId
Renvoie 1 s'il reste des éléments à traiter dans une recherche de tableau, 0 si tous les éléments ont déjà été renvoyés. SearchId indique quelle recherche sur arrayName vérifier, et doit avoir été la valeur de retour d'une invocation précédente de array startsearch. Cette option est particulièrement utile si un tableau a un élément avec un nom vide, car la valeur de retour de array nextelement n'indiquera pas si la recherche est
terminée.
array donesearch arrayName
searchId
Cette commande termine une recherche de tableau et détruit tout l'état associé à cette recherche. SearchId indique quelle recherche sur arrayName détruire, et doit avoir été la valeur de retour d'une invocation précédente de array startsearch. Renvoie une chaîne
vide.
array exists arrayNa
me
Renvoie 1 si arrayName est une variable de tableau, 0 s'il n'y a pas de variable portant ce nom ou si c'est une variable
scalaire.
array get arrayName ?patter
n?
Renvoie une liste contenant des paires d'éléments. Le premier élément de chaque paire est le nom d'un élément dans arrayName et le deuxième élément de chaque paire est la valeur de l'élément du tableau. L'ordre des paires est indéfini. Si pattern n'est pas spécifié, alors tous les éléments du tableau sont inclus dans le résultat. Si pattern est spécifié, alors seuls les éléments dont les noms correspondent à pattern (en utilisant les règles de correspondance de string match) sont inclus. Si arrayName n'est pas le nom d'une variable de tableau, ou si le tableau ne contient aucun élément, une liste vide est renvoyée. Si des traces sur le tableau modifient la liste des éléments, les éléments renvoyés sont ceux qui existent à la fois avant et après l'appel à array g
et.
array names arrayName ?mode? ?patter
n?
Renvoie une liste contenant les noms de tous les éléments du tableau qui correspondent à pattern. Mode peut être l'un de -exact, -glob, ou -regexp. Si spécifié, mode désigne quelles règles de correspondance utiliser pour faire correspondre pattern aux noms des éléments du tableau. Si non spécifié, mode vaut par défaut -glob. Voir la documentation de string match pour des informations sur la correspondance de style glob, et la documentation de regexp pour des informations sur la correspondance regexp. Si pattern est omis, la commande renvoie tous les noms d'éléments du tableau. S'il n'y a pas d'éléments (correspondants) dans le tableau, ou si arrayName n'est pas le nom d'une variable de tableau, une chaîne vide est
renvoyée.
array nextelement arrayName
searchId
Renvoie le nom du prochain élément dans arrayName, ou une chaîne vide si tous les éléments de arrayName ont déjà été renvoyés dans cette recherche. L' argument searchId identifie la recherche, et doit avoir été la valeur de retour d'une commande array startsearch. Avertissement : si des éléments sont ajoutés au ou supprimés du tableau, alors toutes les recherches sont automatiquement terminées comme si array donesearch avait été invoquée ; cela causera l'échec des opérations array nextelement pour ces
recherches.
array set arrayName
list
Définit les valeurs d'un ou plusieurs éléments dans arrayName. list doit avoir une forme similaire à celle renvoyée par array get, consistant en un nombre pair d'éléments. Chaque élément d'indice impair dans list est traité comme un nom d'élément dans arrayName, et l'élément suivant dans list est utilisé comme nouvelle valeur pour cet élément du tableau. Si la variable arrayName n'existe pas déjà et que list est vide, arrayName est créée avec une valeur de tableau
vide.
array size arrayNa
me
Renvoie une chaîne décimale donnant le nombre d'éléments dans le tableau. Si arrayName n'est pas le nom d'un tableau, 0 est
renvoyé.
array startsearch arrayNa
me
Cette commande initialise une recherche élément par élément à travers le tableau donné par arrayName, de sorte que les invocations de la commande array nextelement renverront les noms des éléments individuels dans le tableau. Lorsque la recherche est terminée, la commande array donesearch devrait être invoquée. La valeur de retour est un identifiant de recherche qui doit être utilisé dans les commandes array nextelement et array donesearch ; il permet à plusieurs recherches d'être en cours simultanément pour le même tableau. Actuellement, il est plus efficace et plus facile d'utiliser soit array get ou array names, avec foreach, pour parcourir tous les tableaux sauf les très grands. Voir les exemples ci-dessous pour savoir comment
faire.
array statistics arrayNa
me
Renvoie des statistiques sur la distribution des données dans la table de hachage qui représente le tableau. Ces informations incluent le nombre d'entrées dans la table, le nombre de seaux, et l'utilisation des
seaux.
array unset arrayName ?patter
n?
Annule la définition de tous les éléments du tableau qui correspondent à pattern (en utilisant les règles de correspondance de string match). Si arrayName n'est pas le nom d'une variable de tableau ou s'il n'y a pas d'éléments correspondants dans le tableau, aucune erreur ne sera levée. Si pattern est omis et que arrayName est une variable de tableau, la commande ann
ule la définition de tout le
tableau. La commande ren
voie toujours une chaîne vide.

EXEMPLE

S 
array set colorcount {
    red   1
    green 5
    blue  4
    white 9
}
foreach {color count} [array get colorcount] {
    puts "Color: $color Count: $count"
}
  → Color: blue Count: 4
    Color: white Count: 9
    Color: green Count: 5
    Color: red Count: 1
foreach color [array names colorcount] {
    puts "Color: $color Count: $colorcount($color)"
}
  → Color: blue Count: 4
    Color: white Count: 9
    Color: green Count: 5
    Color: red Count: 1
foreach color [lsort [array names colorcount]] {
    puts "Color: $color Count: $colorcount($color)"
}
  → Color: blue Count: 4
    Color: green Count: 5
    Color: red Count: 1
    Color: white Count: 9
