NOM

arping - envoie une requête ARP à un hôte voisin

SYNTAXE

arping [-AbDfhqUV] [-c nombre] [-w délai] [-i intervalle] [-s source] [-I interface] {destination}

DESCRIPTION

Ping la destination sur le périphérique interface via des paquets ARP, en utilisant l'adresse source source.

arping ne supporte que les adresses IPv4. Pour IPv6, voir ndisc6(8).

OPTIONS

-A

Identique à -U, mais utilise des paquets ARP REPLY au lieu de ARP REQUEST.

-b

Envoie uniquement des diffusions au niveau MAC. Normalement, arping commence par envoyer une diffusion, puis passe en unicast après réception d'une réponse.

-c nombre

Arrête après l'envoi de nombre paquets ARP REQUEST. Avec l'option délai, attend nombre paquets ARP REPLY, ou jusqu'à l'expiration du délai d'attente.

-D

Mode de détection de doublons d'adresses (DAD). Voir RFC2131, 4.4.1. Renvoie 0 si DAD a réussi, c'est-à-dire si aucune réponse n'est reçue.

-f

Termine après la première réponse confirmant que la cible est active.

-I interface

Nom du périphérique réseau sur lequel envoyer les paquets ARP REQUEST.

-h

Affiche la page d'aide et quitte.

-q

Sortie silencieuse. Rien n'est affiché.

-s source

Adresse IP source à utiliser dans les paquets ARP. Si cette option est absente, l'adresse source est :
• En mode DAD (avec l'option -D) définie à 0.0.0.0.
• En mode ARP non sollicité (avec les options -U ou -A) définie à destination.
• Sinon, elle est calculée à partir des tables de routage.

-U

Mode ARP non sollicité pour mettre à jour les caches ARP des voisins. Aucune réponse n'est attendue.

-V

Affiche la version du programme et quitte.

-w délai

Spécifie un délai d'attente, en secondes, avant que arping ne se termine, quel que soit le nombre de paquets envoyés ou reçus. Si des réponses sont reçues, quitte avec le statut 0, sinon le statut 1. Combiné avec l'option nombre, quitte avec le statut 0 si nombre réponses sont reçues avant l'expiration du délai, sinon le statut 1.

-i intervalle

Spécifie un intervalle, en secondes, entre les paquets.

VOIR AUSSI

ndisc6(8), ping(8), clockdiff(8), tracepath(8).

AUTEUR

arping a été écrit par Alexey Kuznetsov <kuznet@ms2.inr.ac.ru>.

SÉCURITÉ

arping nécessite la capacité CAP_NET_RAW pour être exécuté. Il n'est pas recommandé de l'utiliser comme set-uid root, car il permet à l'utilisateur de modifier les caches ARP des hôtes voisins.
