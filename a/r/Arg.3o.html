val parse_expand : (key * spec * doc) list -> anon_fun -> usage_msg -> unit

Identique à Arg.parse , sauf que les arguments Expand sont autorisés et que la référence Arg.current n'est pas mise à jour.

Depuis 4.05

exception Help of string

Levée par Arg.parse_argv lorsque l'utilisateur demande de l'aide.

exception Bad of string

Les fonctions dans spec ou anon_fun peuvent lever Arg.Bad avec un message d'erreur pour rejeter des arguments invalides. Arg.Bad est aussi levée par Arg.parse_argv en cas d' erreur.

val usage : (key * spec * doc) list -> usage_msg -> unit

Arg.usage speclist usage_msg affiche sur l'erreur standard un message d'erreur qui inclut la liste des options valides. C'est le même message que Arg.parse affiche en cas d'erreur. speclist et usage_msg sont les mêmes que pour Arg.parse .

val usage_string : (key * spec * doc) list -> usage_msg -> string

Retourne le message qui aurait été affiché par Arg.usage , si on lui fournit les mêmes paramètres.

val align : ?limit:int -> (key * spec * doc) list -> (key * spec * doc) list

Aligne les chaînes de documentation en insérant des espaces au premier séparateur d'alignement (tabulation ou, si aucune tabulation n'est trouvée, espace), en fonction de la longueur du mot-clé. Utilisez un séparateur d'alignement comme premier caractère d'une chaîne de doc si vous voulez aligner toute la chaîne. Les chaînes de doc correspondant aux arguments Symbol sont alignées sur la ligne suivante.

val current : int ref

Position (dans Sys.argv ) de l'argument en cours de traitement. Vous pouvez changer cette valeur, par exemple pour forcer Arg.parse à ignorer certains arguments. Arg.parse utilise la valeur initiale de Arg.current comme l'index de l'argument 0 (le nom du programme) et commence l'analyse des arguments à l'élément suivant.

val read_arg : string -> string array

Arg.read_arg file lit des arguments de ligne de commande terminés par un saut de ligne à partir du fichier file .

Depuis 4.05

val read_arg0 : string -> string array

Identique à Arg.read_arg mais suppose que les arguments de la ligne de commande sont terminés par un caractère nul.

Depuis 4.05

val write_arg : string -> string array -> unit

Arg.write_arg file args écrit les arguments args terminés par un saut de ligne dans le fichier file . Si l'un des arguments dans args contient un saut de ligne, utilisez Arg.write_arg0 à la place.

Depuis 4.05

val write_arg0 : string -> string array -> unit

Identique à Arg.write_arg mais utilise le caractère nul comme terminateur au lieu du saut de ligne.
