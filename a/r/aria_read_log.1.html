ARIA_READ_LOG(1) Commandes utilisateur ARIA_READ_LOG(1)

NOM

aria_read_log - affiche le contenu du fichier journal d'Aria

SYNTAXE

aria_read_log OPTIONS

DESCRIPTION

Affiche et applique les enregistrements du journal d'une transaction Aria trouvée dans le répertoire courant (pour l'instant)

Note : Aria est compilé sans -DIDENTICAL_PAGES_AFTER_RECOVERY, ce qui signifie que les fichiers de table ne sont pas identiques octet pour octet aux fichiers créés lors d'une exécution normale. Cela devrait être acceptable, sauf pour les scripts de test qui essaient de comparer les fichiers avant et après récupération.

Vous devez utiliser l'une des options -d ou -a

-a, --apply
Appliquer le journal aux tables : modifie les tables ! faites une sauvegarde au préalable ! Affiche beaucoup d'informations si ce n'est pas exécuté avec --silent
--character-sets-dir=nom
Répertoire où se trouvent les jeux de caractères.
-c, --check
si --display-only, vérifie si l'enregistrement est entièrement lisible (pour le débogage)
-#, --debug[=nom]
Sortie du journal de débogage. L'argument est souvent 'd:t:o,nom_de_fichier'.
--force-crash=#
Forcer un crash après # événements de récupération
-?, --help
Afficher cette aide et quitter.
-d, --display-only
afficher des informations brèves lues depuis l'en-tête des enregistrements
-e, --end-lsn=#
Arrêter l'application à ce lsn. Si end-lsn est utilisé, les UNDO ne seront pas appliqués
-h, --aria-log-dir-path=nom
Chemin vers le répertoire où stocker le journal transactionnel
-P, --page-buffer-size=#
La taille du tampon utilisé pour les blocs d'index pour les tables Aria
-o, --start-from-lsn=#
Commencer la lecture du journal à partir de ce lsn
-C, --start-from-checkpoint
Commencer l'application à partir du dernier point de contrôle
-s, --silent
Afficher moins d'informations pendant la phase d'application/annulation
-T, --tables-to-redo=nom
Liste des tables séparées par des virgules sur lesquelles appliquer le REDO. Utilisez ceci si vous ne voulez récupérer que certaines tables
-t, --tmpdir=nom
Chemin pour les fichiers temporaires. Plusieurs chemins peuvent être spécifiés, séparés par un deux-points (:)
--translog-buffer-size=#
La taille du tampon utilisé pour le journal des transactions pour les tables Aria
-u, --undo
Appliquer les enregistrements UNDO aux tables. (désactivé avec --disable-undo) (Activé par défaut ; utilisez --skip-undo pour désactiver.)
-v, --verbose
Afficher plus d'informations pendant la phase d'application/annulation
-V, --version
Afficher la version et quitter.

Les options par défaut sont lues à partir des fichiers suivants dans l'ordre spécifié : /etc/my.cnf /etc/mysql/my.cnf ~/.my.cnf

Les groupes suivants sont lus : aria_read_log

Les options suivantes peuvent être données en premier argument :

--print-defaults
Afficher la liste des arguments du programme et quitter.
--no-defaults
Ne pas lire les options par défaut dans aucun fichier d'options.
--defaults-file=#
Lire uniquement les options par défaut dans le fichier donné #.
--defaults-extra-file=#
Lire ce fichier après la lecture des fichiers globaux.
