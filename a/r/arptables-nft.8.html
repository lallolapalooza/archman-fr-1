ARPTABLES(8) Manuel de l'administrateur système ARPTABLES(8)

NOM

arptables — Administration de la table ARP (basé sur nft)

SYNOPSIS

arptables [-t table] {-A|-D} chaîne spécification-de-règle [options...]

arptables [-t table] -I chaîne [numéro-de-règle] spécification-de-règle

arptables [-t table] -R chaîne numéro-de-règle spécification-de-règle

arptables [-t table] -D chaîne numéro-de-règle

arptables [-t table] {-F|-L|-Z} [chaîne [numéro-de-règle]] [options...]

arptables [-t table] -N chaîne

arptables [-t table] -X [chaîne]

arptables [-t table] -P chaîne politique

arptables [-t table] -E ancien-nom-de-chaîne nouveau-nom-de-chaîne

spécification-de-règle := [correspondances...] [cible]

correspondance := -m nom-de-correspondance [options-de-correspondance]

cible := -j nom-de-cible [options-de-cible]

DESCRIPTION

arptables est un outil d'espace utilisateur, il est utilisé pour configurer et maintenir les tables de règles ARP dans le noyau Linux. Ces règles inspectent les trames ARP qu'elles voient. arptables est analogue à l'outil d'espace utilisateur iptables , mais arptables est moins compliqué.

CHAÎNES

La table du noyau est utilisée pour diviser la fonctionnalité en différents ensembles de règles. Chaque ensemble de règles est appelé une chaîne. Chaque chaîne est une liste ordonnée de règles qui peuvent correspondre à des trames ARP. Si une règle correspond à une trame ARP, alors une spécification de traitement indique quoi faire avec cette trame correspondante. La spécification de traitement est appelée une « cible ». Cependant, si la trame ne correspond pas à la règle actuelle dans la chaîne, alors la règle suivante dans la chaîne est examinée, et ainsi de suite. L'utilisateur peut créer de nouvelles chaînes (définies par l'utilisateur) qui peuvent être utilisées comme « cible » d'une règle.

CIBLES

Une règle de pare-feu spécifie des critères pour une trame ARP et une spécification de traitement de trame appelée une cible. Lorsqu'une trame correspond à une règle, alors la prochaine action effectuée par le noyau est spécifiée par la cible. La cible peut être l'une de ces valeurs : ACCEPT, DROP, CONTINUE, RETURN, une « extension » (voir ci-dessous) ou une chaîne définie par l'utilisateur.

ACCEPT signifie laisser passer la trame. DROP signifie que la trame doit être abandonnée. CONTINUE signifie que la règle suivante doit être vérifiée. Cela peut être utile pour savoir combien de trames passent un certain point dans la chaîne ou pour journaliser ces trames. RETURN signifie arrêter de parcourir cette chaîne et reprendre à la règle suivante dans la chaîne précédente (appelante). Pour les cibles d'extension, veuillez consulter la section EXTENSIONS DE CIBLE de cette page de manuel.

TABLES

Il n'y a qu'une seule table ARP dans le noyau Linux. La table est filter. Vous pouvez omettre l'argument '-t filter' de la commande arptables. L'argument -t doit être le premier argument sur la ligne de commande arptables, s'il est utilisé.

-t, --table

filter, est la seule table et contient deux chaînes intégrées : INPUT (pour les trames destinées à l'hôte) et OUTPUT (pour les trames générées localement).

ARGUMENTS DE LIGNE DE COMMANDE ARPTABLES

Après le premier argument de la ligne de commande arptables, les arguments restants peuvent être divisés en plusieurs groupes différents. Ces groupes sont les commandes, les commandes diverses, les spécifications-de-règles, les extensions-de-correspondance et les extensions-de-surveillance.

COMMANDES

Les arguments de la commande arptables spécifient les actions à effectuer sur la table définie avec l'argument -t. Si vous n'utilisez pas l'argument -t pour nommer une table, les commandes s'appliquent à la table filter par défaut. À l'exception de la -Z commande, une seule commande peut être utilisée sur la ligne de commande à la fois.

-A, --append
Ajoute une règle à la fin de la chaîne sélectionnée.
-D, --delete
Supprime la règle spécifiée de la chaîne sélectionnée. Il y a deux façons d'utiliser cette commande. La première est de spécifier un intervalle de numéros de règles à supprimer, syntaxe : start_nr[:end_nr]. L'utilisation de nombres négatifs est autorisée, pour plus de détails sur l'utilisation de nombres négatifs, voir la commande -I. La deuxième utilisation est de spécifier la règle complète comme elle aurait été spécifiée lorsqu'elle a été ajoutée.
-I, --insert
Insère la règle spécifiée dans la chaîne sélectionnée au numéro de règle spécifié. Si le nombre actuel de règles est égal à N, alors le numéro spécifié peut être compris entre -N et N+1. Pour un nombre positif i, il est vrai que i et i-N-1 spécifient le même endroit dans la chaîne où la règle doit être insérée. Le nombre 0 spécifie l'endroit après la dernière règle dans la chaîne et l'utilisation de ce nombre est donc équivalente à l'utilisation de la commande -A.
-R, --replace
Remplace la règle spécifiée dans la chaîne sélectionnée au numéro de règle spécifié. Si le nombre actuel de règles est égal à N, alors le numéro spécifié peut être compris entre 1 et N. i spécifie l'endroit dans la chaîne où la règle doit être remplacée.
-P, --policy
Définit la politique de la chaîne sur la cible donnée. La politique peut être ACCEPT, DROP ou RETURN.
-F, --flush
Vide la chaîne sélectionnée. Si aucune chaîne n'est sélectionnée, alors toutes les chaînes seront vidées. Le vidage de la chaîne ne change pas la politique de la chaîne, cependant.
-Z, --zero
Met les compteurs de la chaîne sélectionnée à zéro. Si aucune chaîne n'est sélectionnée, tous les compteurs sont mis à zéro. La -Z commande peut être utilisée en conjonction avec la -L commande. Lorsque les deux commandes -Z et -L sont utilisées ensemble de cette manière, les compteurs de règles sont affichés à l'écran avant d'être mis à zéro.
-L, --list
Liste toutes les règles dans la chaîne sélectionnée. Si aucune chaîne n'est sélectionnée, toutes les chaînes sont listées.
-N, --new-chain
Crée une nouvelle chaîne définie par l'utilisateur avec le nom donné. Le nombre de chaînes définies par l'utilisateur est illimité. Un nom de chaîne définie par l'utilisateur a une longueur maximale de 31 caractères.
-X, --delete-chain
Supprime la chaîne définie par l'utilisateur spécifiée. Il ne doit y avoir aucune référence restante à la chaîne spécifiée, sinon arptables refusera de la supprimer. Si aucune chaîne n'est spécifiée, toutes les chaînes définies par l'utilisateur qui ne sont pas référencées seront supprimées.
-E, --rename-chain
Renomme la chaîne spécifiée avec un nouveau nom. En plus de renommer une chaîne définie par l'utilisateur, vous pouvez renommer un nom de chaîne standard avec un nom qui vous convient. Par exemple, si vous préférez PREBRIDGING à PREROUTING, alors vous pouvez utiliser la commande -E pour renommer la chaîne PREROUTING. Si vous renommez l'un des noms de chaîne arptables standard, veuillez vous assurer de mentionner ce fait si vous posez une question sur les arptables listes de diffusion. Il serait judicieux d'utiliser le nom standard dans votre message. Renommer une chaîne arptables standard de cette manière n'a aucun effet sur la structure ou la fonction de la arptables table du noyau.

COMMANDES DIVERSES

-V, --version
Affiche la version du programme arptables en espace utilisateur.
-h, --help
Donne une brève description de la syntaxe de la commande.
-j, --jump cible
La cible de la règle. C'est l'une des following values: ACCEPT, DROP, CONTINUE, RETURN, une extension de cible (voir EXTENSIONS DE CIBLES) ou le nom d'une chaîne définie par l'utilisateur.
-c, --set-counters PKTS BYTES
Cela permet à l'administrateur d'initialiser les compteurs de paquets et d'octets d'une règle (pendant les opérations INSERT, APPEND, REPLACE ).

SPÉCIFICATIONS DE RÈGLES

Les arguments de ligne de commande suivants composent une spécification de règle (telle qu'utilisée dans les commandes d'ajout et de suppression). Un "!" avant la spécification inverse le test pour cette spécification. En dehors de ces spécifications de règles standard, il existe d'autres arguments de ligne de commande intéressants.

-s, --source-ip [!] address[/mask]
La spécification de l'adresse IP source.
-d, --destination-ip [!] address[/mask]
La spécification de l'adresse IP de destination.
--source-mac [!] address[/mask]
L'adresse MAC source. Le masque et l'adresse sont écrits sous forme de 6 nombres hexadécimaux séparés par des deux-points.
--destination-mac [!] address[/mask]
L'adresse MAC de destination. Le masque et l'adresse sont écrits sous forme de 6 nombres hexadécimaux séparés par des deux-points.
-i, --in-interface [!] name
L'interface par laquelle une trame est reçue (pour la chaîne INPUT ). L'option --in-if est un alias pour cette option.
-o, --out-interface [!] name
L'interface par laquelle une trame va être envoyée (pour la chaîne OUTPUT ). L'option --out-if est un alias pour cette option.
-l, --h-length length[/mask]
La longueur matérielle (nombre d'octets)
--opcode code[/mask]
Le code d'opération (2 octets). Les valeurs disponibles sont : 1=Request 2=Reply 3=Request_Reverse 4=Reply_Reverse 5=DRARP_Request 6=DRARP_Reply 7=DRARP_Error 8=InARP_Request 9=ARP_NAK.
--h-type type[/mask]
Le type matériel (2 octets, hexadécimal). Les valeurs disponibles sont : 1=Ethernet.
--proto-type type[/mask]
Le type de protocole (2 octets). Les valeurs disponibles sont : 0x800=IPv4.

EXTENSIONS DE CIBLES

Les extensions arptables sont précompilées dans l'outil en espace utilisateur. Il n'est donc pas nécessaire de les charger explicitement avec une option -m comme dans iptables. Cependant, ces extensions traitent des fonctionnalités prises en charge par des modules noyau supplémentaires.

mangle

--mangle-ip-s IP address
Modifie l'adresse IP source à la valeur donnée.
--mangle-ip-d IP address
Modifie l'adresse IP de destination à la valeur donnée.
--mangle-mac-s MAC address
Modifie l'adresse MAC source à la valeur donnée.
--mangle-mac-d MAC address
Modifie l'adresse MAC de destination à la valeur donnée.
--mangle-target target
Cible de l'opération de modification ARP (DROP, CONTINUE ou ACCEPT — la valeur par défaut est ACCEPT).

CLASSIFY

Ce module vous permet de définir la valeur skb->priority (et ainsi de classer le paquet dans une classe CBQ spécifique).

--set-class major:minor

Définit les valeurs de classe majeure et mineure. Les valeurs sont toujours interprétées comme hexadécimales même si le préfixe 0x n'est pas donné.

MARK

Ce module vous permet de définir la valeur skb->mark (et ainsi de classer le paquet par la marque en u32)

--set-mark mark
Définit la valeur de la marque. Les valeurs sont toujours interprétées comme hexadécimales même si le préfixe 0x n'est pas donné
--and-mark mark
ET binaire de la marque avec les bits.
--or-mark mark
OU binaire de la marque avec les bits.

REMARQUES

Dans cette version basée sur nft de arptables, la prise en charge de la chaîne FORWARD n'a pas été implémentée. Puisque les paquets ARP ne sont "transmis" que par les ponts Linux, le même résultat peut être obtenu en utilisant la chaîne FORWARD dans ebtables.
