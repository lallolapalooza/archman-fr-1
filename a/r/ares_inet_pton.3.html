NOM

ares_inet_pton - convertir une adresse IPv4 ou IPv6 de texte en forme binaire

SYNOPSIS

#include <ares.h>
int ares_inet_pton(int af, const char *src, void *dst);

DESCRIPTION

Ceci est une version portable avec la fonctionnalité identique à inet_pton couramment disponible.

La fonction ares_inet_pton() convertit l'adresse sous sa forme de présentation textuelle standard en sa forme binaire numérique. L'argument af doit spécifier la famille de l'adresse. Les familles d'adresses AF_INET et AF_INET6 doivent être prises en charge. L'argument src pointe vers la chaîne passée en entrée. L'argument dst pointe vers un tampon dans lequel la fonction stocke l'adresse numérique ; celui-ci doit être suffisamment grand pour contenir l'adresse numérique (32 bits pour AF_INET, 128 bits pour AF_INET6).

Elle retourne 1 si l'adresse était valide pour la famille d'adresses spécifiée, ou 0 si l'adresse n'a pas pu être analysée dans la famille d'adresses spécifiée, ou -1 si une erreur système s'est produite (auquel cas errno aura été défini).

VOIR AUSSI

ares_init(3), ares_inet_ntop(3)

DISPONIBILITÉ
