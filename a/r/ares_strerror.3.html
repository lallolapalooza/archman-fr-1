ARES_STRERROR(3) Manuel des fonctions de bibliothèque ARES_STRERROR(3)

NOM

ares_strerror - Obtenir la description d'un code d'erreur de la bibliothèque ares

SYNTAXE

#include <ares.h>
const char *ares_strerror(int code)

DESCRIPTION

La fonction ares_strerror obtient la description du code d'erreur code de la bibliothèque ares, retournant le résultat sous forme de chaîne C terminée par un caractère nul.

NOTES

Cette fonction n'est pas compatible avec ares, elle prend un ensemble différent d'arguments.
