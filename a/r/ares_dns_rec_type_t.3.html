ÉNUMÉRATIONS

ares_dns_rec_type_t - Types d'enregistrements DNS gérés par c-ares. Certains types d'enregistrements peuvent n'être valides que dans les requêtes, et d'autres peuvent n'être valides que dans les réponses :

ARES_REC_TYPE_A - Adresse hôte
ARES_REC_TYPE_NS - Serveur faisant autorité
ARES_REC_TYPE_CNAME - Nom canonique
ARES_REC_TYPE_SOA - Début de la zone d'autorité
ARES_REC_TYPE_PTR - Pointeur vers un nom de domaine
ARES_REC_TYPE_HINFO - Informations sur l'hôte
ARES_REC_TYPE_MX - Informations de routage des courriels
ARES_REC_TYPE_TXT - Chaînes de texte
ARES_REC_TYPE_SIG - RFC 2535. RFC 2931. Enregistrement SIG
ARES_REC_TYPE_AAAA - RFC 3596. Adresse Ip6
ARES_REC_TYPE_SRV - RFC 2782. Sélection de serveur
ARES_REC_TYPE_NAPTR - RFC 3403. Pointeur d'autorité de nommage
ARES_REC_TYPE_OPT - RFC 6891. Option EDNS0 (méta-RR). Enregistrement pseudo.
ARES_REC_TYPE_TLSA - RFC 6698. Authentification basée sur DNS des entités nommées (DANE) Protocole de sécurité de la couche de transport (TLS) : TLSA
ARES_REC_TYPE_SVCB - RFC 9460. Liaison de service à usage général
ARES_REC_TYPE_HTTPS - - RFC 9461. Type de liaison de service à utiliser avec HTTPS
ARES_REC_TYPE_ANY - Correspondance générique. RR de réponse non applicable
ARES_REC_TYPE_URI - RFC 7553. Identificateur de ressource uniforme
ARES_REC_TYPE_CAA - RFC 6844. Autorisation de l'autorité de certification
ARES_REC_TYPE_RAW_RR - Utilisé comme indicateur que l'enregistrement RR n'est pas analysé, mais fourni au format binaire

ares_dns_class_t - Classes DNS pour les requêtes et les réponses :

ARES_CLASS_IN - Internet
ARES_CLASS_CHAOS - CHAOS
ARES_CLASS_HESOID - Hesoid [Dyer 87]
ARES_CLASS_NONE - RFC 2136
ARES_CLASS_ANY - Toute classe (requêtes uniquement)

ares_dns_opcode_t - Opcodes d'en-tête DNS :

ARES_OPCODE_QUERY - Requête standard
ARES_OPCODE_IQUERY - Requête inverse. Obsolète
ARES_OPCODE_STATUS - Requête de statut du serveur de noms
ARES_OPCODE_NOTIFY - Notification de changement de zone (RFC 1996)
ARES_OPCODE_UPDATE - Message de mise à jour de zone (RFC 2136)

ares_dns_flags_t - Indicateurs d'en-tête DNS :

ARES_FLAG_QR - QR. Si défini, est une réponse
ARES_FLAG_AA - Réponse faisant autorité. Si défini, est faisant autorité
ARES_FLAG_TC - Troncation. Si défini, est une réponse tronquée
ARES_FLAG_RD - Récursion désirée. Si défini, la récursion est désirée
ARES_FLAG_RA - Récursion disponible. Si défini, le serveur prend en charge la récursion
ARES_FLAG_AD - RFC 2065. Le bit Authentic Data indique dans une réponse que les données incluses ont été vérifiées par le serveur qui les fournit
ARES_FLAG_CD - RFC 2065. Le bit Checking Disabled indique dans une requête que les données non vérifiées sont acceptables pour le résolveur envoyant la requête

ares_dns_rcode_t - Codes de réponse DNS du serveur :

ARES_RCODE_NOERROR - Succès
ARES_RCODE_FORMERR - Erreur de format. Le serveur de noms n'a pas pu interpréter la requête
ARES_RCODE_SERVFAIL - Échec du serveur. Le serveur de noms n'a pas pu traiter cette requête en raison d'un problème avec le serveur de noms
ARES_RCODE_NXDOMAIN - Erreur de nom. Significatif uniquement pour les réponses d'un serveur de noms faisant autorité, ce code signifie que le nom de domaine référencé dans la requête n'existe pas.
ARES_RCODE_NOTIMP - Non implémenté. Le serveur de noms ne prend pas en charge le type de requête demandé
ARES_RCODE_REFUSED - Refusé. Le serveur de noms refuse d'effectuer l'opération spécifiée pour des raisons de politique.
ARES_RCODE_YXDOMAIN - RFC 2136. Un nom qui ne devrait pas exister, existe
ARES_RCODE_YXRRSET - RFC 2136. Un RRset qui ne devrait pas exister, existe
ARES_RCODE_NXRRSET - RFC 2136. Un RRset qui devrait exister, n'existe pas
ARES_RCODE_NOTAUTH - RFC 2136. Le serveur ne fait pas autorité pour la zone nommée dans la section Zone.
ARES_RCODE_NOTZONE - RFC 2136. Un nom utilisé dans la section Prérequis ou Mise à jour ne se trouve pas dans la zone désignée par la section Zone.
ARES_RCODE_DSOTYPEI - RFC 8409. DSO-TYPE Non implémenté
ARES_RCODE_BADSIG - RFC 8945. Échec de la signature TSIG
ARES_RCODE_BADKEY - RFC 8945. Clé non reconnue
ARES_RCODE_BADTIME - RFC 8945. Signature hors de la fenêtre temporelle
ARES_RCODE_BADMODE - RFC 2930. Mauvais mode TKEY
ARES_RCODE_BADNAME - RFC 2930. Nom de clé dupliqué
ARES_RCODE_BADALG - RFC 2930. Algorithme non pris en charge
ARES_RCODE_BADTRUNC - RFC 8945. Mauvaise troncature
ARES_RCODE_BADCOOKIE - RFC 7973. Cookie serveur invalide/manquant

ares_dns_parse_flags_t - Indicateurs pour modifier le comportement de ares_dns_parse(3) :

ARES_DNS_PARSE_AN_BASE_RAW - Analyser la section Réponse de RFC 1035 qui autorise la compression de nom en tant que type RR RAW
ARES_DNS_PARSE_NS_BASE_RAW - Analyser la section Autorité de RFC 1035 qui autorise la compression de nom en tant que type RR RAW
ARES_DNS_PARSE_AR_BASE_RAW - Analyser la section Supplémentaire de RFC 1035 qui autorise la compression de nom en tant que type RR RAW
ARES_DNS_PARSE_AN_EXT_RAW - Analyser la section Réponse des RFC ultérieurs (sans compression de nom) en tant que type RR RAW
ARES_DNS_PARSE_NS_EXT_RAW - Analyser la section Autorité des RFC ultérieurs (sans compression de nom) en tant que type RR RAW
ARES_DNS_PARSE_AR_EXT_RAW - Analyser la section Supplémentaire des RFC ultérieurs (sans compression de nom) en tant que type RR RAW

DESCRIPTION

La fonction ares_dns_record_destroy(3) détruit la mémoire associée à l'enregistrement DNS créé par ares_dns_record_create(3) ou par ares_dns_parse(3), passé via dnsrec.

DESCRIPTION

The ares_dns_parse(3) function takes a buffer containing a DNS message in wire format and parses it into a DNS record structure pointed to by dnsrec_out. The allocated structure must be destroyed using ares_dns_record_destroy(3).

The returned DNS record structure is stored into the variable pointed to by dnsrec and must be destroyed using ares_dns_record_destroy(3).

The ares_dns_write(3) function takes a populated DNS record structure in dnsrec and writes a DNS message in wire format into the variable pointed to by buf and writes the length of the buffer into the variable pointed to by buf_len. The buffer must be destroyed using ares_free_string(3).

The ares_dns_record_create(3) function creates an empty DNS record structure in the variable pointed to by dnsrec. The id parameter is the DNS message id, however if passing to ares_send(3) this identifier will be overwritten, so should typically be 0. The flags parameter is one or more ares_dns_flags_t. The opcode is passed in the opcode parameter and should typically be ARES_OPCODE_QUERY. The response code is meant mostly for responses and is passed in the rcode parameter and is typically ARES_RCODE_NOERROR.

The ares_dns_record_duplicate(3) function duplicates an existing DNS record structure. This may be useful if needing to save a result as retrieved from ares_send_dnsrec(3) or ares_search_dnsrec(3). The structure to be duplicated is passed in the dnsrec parameter, and the duplicated copy is returned, or NULL on error such as out of memory.

The ares_dns_record_get_id(3) function is used to retrieve the DNS message id from the DNS record provided in the dnsrec parameter.

The ares_dns_record_set_id(3) function is used to set the DNS message id in the id parameter from the DNS record provided in the dnsrec parameter. This id will be overwritten when passing the record to c-ares, so mostly exists for external purposes.

The ares_dns_record_get_flags(3) function is used to retrieve the DNS message flags from the DNS record provided in the dnsrec parameter.

The ares_dns_record_get_opcode(3) function is used to retrieve the DNS message flags from the DNS record provided in the dnsrec parameter.

The ares_dns_record_get_rcode(3) function is used to retrieve the DNS message response code from the DNS record provided in the dnsrec parameter.

The ares_dns_record_query_add(3) function is used to add a question to the DNS record provided in the dnsrec parameter. The domain name specified for the question is provided in the name parameter, along with the question type in the qtype parameter and the question class (typically ARES_CLASS_IN) in the qclass parameter.

The ares_dns_record_query_set_name(3) function is used to modify the question name in the DNS record provided in the dnsrec parameter. The index of the query, which must be less than ares_dns_record_query_cnt(3), is provided in the idx parameter. The new domain name is provided in the name parameter. Care should be taken as this will cause invalidation of any name pointer retrieved from ares_dns_Record_query_get(3). This function is useful if sending multiple similar queries without re-creating the entire DNS query.

The ares_dns_record_query_set_type(3) function is used to modify the question type in the DNS record provided in the dnsrec parameter. The index of the query, which must be less than ares_dns_record_query_cnt(3), is provided in the idx parameter. The new query type is provided in the qtype parameter.

The ares_dns_record_query_cnt(3) function is used to retrieve the number of DNS questions in the DNS record provided in the dnsrec parameter.

The ares_dns_record_query_get(3) function is used to retrieve the details of a single DNS question in the provided dnsrec parameter. The index provided in the idx parameter must be less than the value returned from ares_dns_record_query_cnt(3). The DNS question name will be returned in the variable pointed to by the name parameter, this may be provided as NULL if the name is not needed. This pointer will be invalided by any call to ares_dns_record_query_set_name(3). The DNS question type will be returned in the variable pointed to by the qtype parameter, this may be provided as NULL if the type is not needed. The DNS question class will be returned in the variable pointed to by the qclass parameter, this may be provided as NULL if the class is not needed.

VALEURS DE RETOUR

ares_dns_parse(3), ares_dns_write(3), ares_dns_record_create(3), ares_dns_record_query_add(3), et ares_dns_record_query_get(3) retournent tous un code d'erreur ares_status_t. ARES_SUCCESS est retourné en cas de succès, ARES_ENOMEM est retourné en cas de manque de mémoire, ARES_EFORMERR est retourné en cas d'utilisation incorrecte.

ares_dns_record_get_id(3), ares_dns_record_set_id(3), ares_dns_record_get_flags(3), ares_dns_record_get_opcode(3), ares_dns_record_get_rcode(3), et ares_dns_record_query_cnt(3) retournent tous leurs valeurs de type de données prescrites et ne peuvent généralement pas échouer, sauf en cas d'utilisation incorrecte, auquel cas un 0 peut être retourné, cependant 0 peut également être une valeur de retour valide pour la plupart de ces fonctions.

DISPONIBILITÉ

Ces fonctions ont été introduites pour la première fois dans la version 1.22.0 de c-ares.
