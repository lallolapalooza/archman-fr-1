NOM

Array::Compare - Extension Perl pour comparer des tableaux.

SYNOPSIS

use Array::Compare;
my $comp1 = Array::Compare->new;
$comp->Sep('|');
$comp->Skip({3 => 1, 4 => 1});
$comp->WhiteSpace(0);
$comp->Case(1);
my $comp2 = Array::Compare->new(Sep => '|',
                                WhiteSpace => 0,
                                Case => 1,
                                Skip => {3 => 1, 4 => 1});
my @arr1 = 0 .. 10;
my @arr2 = 0 .. 10;
$comp1->compare(\@arr1, \@arr2);
$comp2->compare(\@arr1, \@arr2);

DESCRIPTION

Si vous avez deux tableaux et que vous voulez savoir s'ils sont identiques ou différents, alors Array::Compare vous sera utile.

Toutes les comparaisons sont effectuées via un objet comparateur. Dans l'utilisation la plus simple, vous pouvez créer et utiliser un objet comparateur comme ceci :

my @arr1 = 0 .. 10;
my @arr2 = 0 .. 10;
my $comp = Array::Compare->new;
if ($comp->compare(\@arr1, \@arr2)) {
  print "Les tableaux sont identiques\n";
} else {
  print "Les tableaux sont différents\n";
}

Remarquez que vous passez des références aux deux tableaux à la méthode de comparaison.

En interne, le comparateur compare les deux tableaux en utilisant "join" pour convertir les deux tableaux en chaînes et en comparant les chaînes avec "eq". Dans les chaînes concaténées, les éléments des tableaux d'origine sont séparés par le caractère "^G" . Cela peut poser problème si vos données de tableau contiennent des caractères "^G" car il est possible que deux tableaux différents soient convertis en la même chaîne.

Pour éviter cela, il est possible de remplacer le caractère séparateur par défaut, soit en passant une alternative à la fonction "new"

my $comp = Array::Compare->new(Sep => '|');

soit en modifiant le séparateur d'un objet comparateur existant

$comp->Sep('|');

En général, vous devriez choisir un caractère séparateur qui n'apparaîtra pas dans vos données.

Vous pouvez également contrôler si les espaces blancs à l'intérieur des éléments des tableaux doivent être considérés comme significatifs lors de la comparaison. Par défaut, tous les espaces blancs sont significatifs. L'alternative consiste à convertir tous les caractères d'espacement consécutifs en un seul espace aux fins de la comparaison. Encore une fois, cela peut être activé lors de la création d'un objet comparateur :

my $comp = Array::Compare->new(WhiteSpace => 0);

ou en modifiant un objet existant :

$comp->WhiteSpace(0);

Vous pouvez également contrôler si la casse des données est significative dans la comparaison. Par défaut, la casse des données est prise en compte. Cela peut être modifié de la manière habituelle lors de la création d'un nouvel objet comparateur :

my $comp = Array::Compare->new(Case => 0);

ou en modifiant un objet existant :

$comp->Case(0);

En plus de la comparaison simple décrite ci-dessus (qui renvoie vrai si les tableaux sont identiques et faux s'ils sont différents) il existe aussi une comparaison complète qui renvoie une liste contenant les index des éléments qui diffèrent entre les deux tableaux. Si les tableaux sont identiques elle renvoie une liste vide. En contexte scalaire, la comparaison complète renvoie la longueur de cette liste (c'est-à-dire le nombre d'éléments qui diffèrent). Vous pouvez accéder à la comparaison complète de deux manières. Premièrement, il y a un attribut "DefFull" . S'il est "vrai" alors une comparaison complète est effectuée chaque fois que la méthode

"compare"
    est appelée.

my $comp = Array::Compare->new(DefFull => 1); $comp->compare(\@arr1, \@arr2); # Comparaison complète $comp->DefFull(0); $comp->compare(\@arr1, \@arr2); # Comparaison simple $comp->DefFull(1); $comp->compare(\@arr1, \@arr2); # Comparaison complète à nouveau

Deuxièmement, vous pouvez accéder directement à la méthode de comparaison complète

$comp->full_compare(\@arr1, \@arr2);

Par symétrie, il existe aussi une méthode directe pour appeler la
    comparaison simple.

$comp->simple_compare(\@arr1, \@arr2); La dernière complication est la possibilité d'ignorer des éléments dans la comparaison. Si vous savez que deux tableaux différeront toujours sur un élément particulier mais que vous voulez comparer les tableaux en ignorant cet élément, vous pouvez le faire avec Array::Compare sans prendre de tranches de tableau. Pour cela, un objet comparateur a un attribut optionnel appelé "Skip"

qui est une référence à un hash. Les clés de ce hash sont les index des éléments du tableau et les valeurs doivent être n'importe quelle valeur vraie pour les éléments qui doivent être ignorés.

Par exemple, si vous voulez comparer deux tableaux, en ignorant les
    valeurs des éléments deux et quatre, vous pouvez faire quelque chose comme ceci :

my %skip = (2 => 1, 4 => 1); my @a = (0, 1, 2, 3, 4, 5); my @b = (0, 1, X, 3, X, 5); my $comp = Array::Compare->new(Skip => \%skip); $comp->compare(\@a, \@b); Cela devrait renvoyervrai

, car nous ignorons explicitement les colonnes qui diffèrent.

Bien sûr, après avoir créé un objet comparateur sans hash de saut, il est possible d'en ajouter un plus tard :

$comp->Skip({1 => 1, 2 => 1});

ou :

my %skip = (1 => 1, 2 => 2); $comp->Skip(\%skip); Pour réinitialiser le comparateur afin qu'il n'ignore plus les éléments, appelez"NoSkip()"

.

$comp->NoSkip();

Vous pouvez également vérifier si un tableau est une permutation de
    un autre, c'est-à-dire s'ils contiennent les mêmes éléments mais dans un ordre différent.

if ($comp->perm(\@a, \@b) { print "Les tableaux sont des permutations\n"; } else { print "Non. Les tableaux sont complètement différents\n"; } Dans ce cas, les valeurs de "WhiteSpace" et "Case" sont toujours utilisées, mais "Skip"

est ignoré pour des raisons, espérons-le, évidentes.

MÉTHODES

new [ %OPTIONS ]

Construit un nouvel objet de comparaison. Prend un hash optionnel contenant diverses options qui contrôlent la manière dont les comparaisons sont effectuées. Toutes les options omises prennent des valeurs par défaut utiles.

Sep
C'est la valeur utilisée pour séparer les champs lorsque le tableau est concaténé en une chaîne. Ce devrait être une valeur qui n'apparaît pas dans vos données. La valeur par défaut est '^G'.
WhiteSpace
Drapeau qui indique si les espaces blancs sont significatifs dans la comparaison. Si cette valeur est fausse, alors tous les caractères d'espacement multiples sont changés en un seul espace avant que la comparaison n'ait lieu. La valeur par défaut est 1 (les espaces blancs sont significatifs).
Case
Drapeau qui indique si la casse des données doit être significative dans la comparaison. La valeur par défaut est 1 (la casse est significative).
Skip
une référence à un hash qui contient les numéros de toutes les colonnes qui doivent être ignorées dans la comparaison. La valeur par défaut est un hash vide (toutes les colonnes sont significatives).
NoSkip
Réinitialise les détails des colonnes ignorées. Il assigne {} à l'attribut "Skip".
DefFull
Drapeau qui indique si la comparaison par défaut est simple (renvoie simplement vrai si les tableaux sont identiques ou faux s'ils ne le sont pas) ou complète (renvoie un tableau contenant les index des colonnes qui diffèrent). La valeur par défaut est 0 (comparaison simple).

compare_len \@ARR1, \@ARR2

Comparaison très simple. Vérifie simplement que les longueurs des tableaux sont identiques.

different_len \@ARR1, \@ARR2

Prend deux tableaux et renvoie vrai s'ils ont des longueurs différentes.

C'est simplement l'inverse de "compare_len" (qui est mal nommé).

compare \@ARR1, \@ARR2

Compare les valeurs de deux tableaux etetourner une donnée indiquant si les tableaux sont identiques. Les valeurs de retour exactes diffèrent selon la méthode de comparaison utilisée. Voir les descriptions de simple_compare et full_compare pour plus de détails.

Utilise la valeur de DefFull pour déterminer quelle routine de comparaison utiliser.

simple_compare \@ARR1, \@ARR2

Compare les valeurs de deux tableaux et retourne un indicateur indiquant si les tableaux sont identiques ou non.

Retourne vrai si les tableaux sont identiques ou faux s'ils diffèrent.

Utilise les valeurs de 'Sep', 'WhiteSpace' et 'Skip' pour influencer la comparaison.

full_compare \@ARR1, \@ARR2

Effectue une comparaison complète entre deux tableaux.

Vérifie chaque colonne individuellement. En contexte scalaire, retourne le nombre de colonnes qui diffèrent (zéro si les tableaux sont identiques). En contexte liste, retourne une liste contenant les index des colonnes qui diffèrent (une liste vide si les tableaux sont identiques).

Utilise les valeurs de 'Sep' et 'WhiteSpace' pour influencer la comparaison.

Remarque : Si les deux tableaux ont des longueurs différentes, cette méthode retourne simplement les index des éléments qui apparaissent dans un tableau mais pas dans l'autre (c'est-à-dire les index du tableau le plus long qui se trouvent au-delà de la fin du tableau le plus court). Cela peut être un peu contre-intuitif.

perm \@ARR1, \@ARR2

Vérifie si un tableau est une permutation de l'autre (c'est-à-dire s'il contient le même ensemble d'éléments, mais dans un ordre différent).

Nous faisons cela en triant les tableaux et en passant des références aux versions triées à simple_compare. Il y a aussi quelques petites modifications à simple_compare car il devrait ignorer le hachage Skip si nous sommes appelés depuis perm.

VOIR AUSSI

Array::Diff - où Array::Compare se concentre sur le fait que deux tableaux sont différents, "Array::Diff" vous indique comment ils sont différents.

Test::Deep - fonctions pour comparer des structures de données arbitraires, en tant que partie d'une suite de tests.

List::Compare - fonctionnalité similaire, mais encore avec plus d'options.

Algorithm::Diff - l'implémentation sous-jacente de l'algorithme de diff. Si vous avez Algorithm::Diff::XS installé, celui-ci sera utilisé.

YAML::Diff - trouver la différence entre deux documents YAML.

HTML::Differences - trouver la différence entre deux documents HTML. Cela utilise une approche plus raisonnable que HTML::Diff.

XML::Diff - trouver la différence entre deux documents XML.

Hash::Diff - trouver les différences entre deux hachages Perl.

Data::Diff - trouver la différence entre deux structures de données arbitraires.

Text::Diff - peut trouver la différence entre deux entrées, qui peuvent être des structures de données ou des noms de fichiers.
