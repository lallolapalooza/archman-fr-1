arch-audit(1) Manuel des commandes générales arch-audit(1)

NOM

arch-audit - Un utilitaire similaire à pkg-audit pour Arch Linux.

SYNTAXE

arch-audit [OPTION]...

DESCRIPTION

Un utilitaire similaire à pkg-audit pour Arch Linux.
Basé sur les données de https://security.archlinux.org collectées par l'excellente équipe de sécurité Arch.

OPTIONS

-q, --quiet

Afficher uniquement les noms des paquets vulnérables et leurs versions. Définir deux fois pour masquer également les versions

-r, --recursive

Affiche les paquets qui dépendent de paquets vulnérables et sont donc potentiellement vulnérables eux aussi.
Définir deux fois pour afficher TOUS les paquets qui les requièrent

-t, --show-testing

Afficher les paquets qui se trouvent dans les dépôts [testing].
Voir https://wiki.archlinux.org/index.php/Official_repositories#Testing_repositories

-u, --upgradable

Afficher uniquement les paquets qui ont déjà été corrigés

-c, --show-cve

Afficher les numéros CVE

-C, --color [QUAND]

Coloriser la sortie ; QUAND peut être 'auto' (par défaut si omis), 'always', ou 'never'

-b, --dbpath [CHEMINDB]

Définir un emplacement de base de données alternatif. Par défaut, arch-audit utilise /var/lib/pacman

-f, --format [FORMAT]

Spécifier un format pour contrôler la sortie. Les espaces réservés sont :

%n nom du paquet

%c CVEs

%v version corrigée

%t type

%s sévérité

%r requis par (uniquement lorsque -r est également utilisé)

--json

Afficher les résultats sous forme d'objet json.

--proxy [PROXY]

Envoyer les requêtes via un proxy. Le format ressemble à 'socks5://127.0.0.1:9050'.

--no-proxy

Ne pas utiliser de proxy même si l'un est configuré

--source [SOURCE]

Spécifier l'URL ou le chemin du fichier des données json du suivi de sécurité. Par défaut, arch-audit utilise https://security.archlinux.org/all.json

--sort [TRI]...

Spécifier comment trier la sortie. Par défaut, arch-audit utilise 'severity,pkgname'
Les valeurs possibles sont : severity, pkgname, upgradable, reverse

-V, --version

Affiche les informations de version

-h, --help

Affiche les informations d'aide

INFOS

Lire plus sur https://wiki.archlinux.org/index.php/Arch_Security_Team

BOGUES

Les bogues peuvent être signalés sur le traqueur de bogues https://gitlab.archlinux.org/archlinux/arch-audit/-/issues
