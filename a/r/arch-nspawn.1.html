NOM

arch-nspawn - Exécute une commande ou un système d'exploitation dans un conteneur léger de type namespace

SYNOPSIS

arch-nspawn [options] répertoire-de-travail [arguments de systemd-nspawn]

DESCRIPTION

arch-nspawn est un wrapper autour de systemd-nspawn pour exécuter une commande ou un système d'exploitation dans un conteneur de type namespace, comme un répertoire incluant les utilitaires de base d'un système d'exploitation. Il est utilisé pour construire des paquets dans un environnement propre et défini.

OPTIONS

-C <fichier>

Emplacement d'un fichier de configuration pacman

-M <fichier>

Emplacement d'un fichier de configuration makepkg. Des ajouts spécifiques (par exemple, des drapeaux de compilation pour des langues supplémentaires) peuvent être placés dans <fichier>.d/*.conf.

-c <répertoire>

Définit le cache de pacman. Si aucun répertoire n'est spécifié, le cachedir de pacman.conf fourni est utilisé, avec un repli vers /etc/pacman.conf.

-f <src>[:<dst>]

Copie un fichier de l'hôte vers le chroot. Si dst n'est pas fourni, il prend par défaut src à l'intérieur du chroot.

-s

Ne pas exécuter setarch

-h

Afficher ce message d'utilisation
