NOM

Archive::Cpio - module pour la manipulation des archives cpio

SYNOPSIS

use Archive::Cpio;
# exemple simple de suppression de l'entrée "foo"
my $cpio = Archive::Cpio->new;
$cpio->read($file);
$cpio->remove('foo');
$cio->write($file);
 # exemple plus complexe, filtrage à la volée
my $cpio = Archive::Cpio->new;
$cpio->read_with_handler(\*STDIN,
            sub {
                my ($e) = @_;
                if ($e->name ne 'foo') {
                    $cpio->write_one(\*STDOUT, $e);
                }
            });
$cpio->write_trailer(\*STDOUT);

DESCRIPTION

Archive::Cpio fournit quelques fonctions pour lire et écrire des fichiers cpio.

Archive::Cpio->new()

Crée un objet

$cpio->read($filename)

$cpio->read($filehandle)

Lit le fichier cpio

$cpio->write($filename)

$cpio->write($filehandle)

Écrit les entrées et la bande-annonce

$cpio->remove(@filenames)

Supprime toutes les entrées dont les noms correspondent à l'un des noms de fichiers donnés de l'archive en mémoire.

$cpio->get_files([ @filenames ])

Renvoie une liste de "Archive::Cpio::File" (après un "$cpio-"read>)

$cpio->get_file($filename)

Renvoie l'"Archive::Cpio::File" correspondant à "$filename< (après un "$cpio-"read")

$cpio->add_data($filename, $data, $opthashref)

Prend un nom de fichier, une chaîne de données complète et éventuellement une référence à un hachage contenant des options spécifiques.

Ajoute un fichier à l'archive en mémoire, avec le nom $filename et le contenu $data. Les propriétés spécifiques peuvent être définies à l'aide de $opthashref.

$cpio->read_with_handler($filehandle, $coderef)

Appelle la fonction de traitement sur chaque en-tête. Une "Archive::Cpio::File" est passée comme paramètre.

$cpio->write_one($filehandle, $entry)

Écrit une "Archive::Cpio::File" (attention, un cpio valide nécessite une bande-annonce utilisant "write_trailer").

$cpio->write_trailer($filehandle)

Écrit la bande-annonce pour terminer le fichier cpio.
