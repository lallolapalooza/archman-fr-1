ARES_SET_SORTLIST(3) Manuel des fonctions de bibliothèque ARES_SET_SORTLIST(3)

NOM

ares_set_sortlist - Initialise une configuration de sortlist pour ares_channel_t

SYNTAXE

#include <ares.h>
int ares_set_sortlist(ares_channel_t *channel, const char *sortstr)

DESCRIPTION

La fonction ares_set_sortlist(3) initialise une configuration de sortlist d'adresses pour les données du canal identifiées par channel, de manière à ce que les adresses retournées par ares_gethostbyname(3) soient triées conformément à la sortlist. La chaîne sortstr fournie contient une liste d'adresses IP séparées par des espaces et des masques de réseau. Le masque de réseau est optionnel mais suit l'adresse après une barre oblique s'il est présent. Par exemple, "130.155.160.0/255.255.240.0 130.155.0.0".

Cette fonction remplace toute sortlist d'adresses potentiellement configurée précédemment par celles fournies dans la chaîne de configuration.

VALEURS DE RETOUR

ares_set_sortlist(3) peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
La configuration de la sortlist a été initialisée avec succès.
ARES_ENOMEM
La mémoire disponible du processus a été épuisée.
ARES_ENODATA
Les données du canal identifiées par channel étaient invalides.
ARES_ENOTINITIALIZED
L'initialisation de la bibliothèque c-ares n'a pas encore été effectuée.

VOIR AUSSI

ares_init_options(3), ares_dup(3)
