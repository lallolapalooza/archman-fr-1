NOM

ares_inet_ntop - convertir une adresse au format réseau en format de présentation

SYNTAXE

#include <ares.h>
const char *ares_inet_ntop(int af, const void *src, char *dst,
                           ares_socklen_t size);

DESCRIPTION

Il s'agit d'une version portable avec la fonctionnalité identique de inet_ntop couramment disponible.

La fonction ares_inet_ntop() convertit une adresse numérique en une chaîne de texte appropriée pour la présentation. L'argument af spécifie la famille de l'adresse. Il peut s'agir de AF_INET ou AF_INET6. L'argument src pointe vers un tampon contenant une adresse IPv4 si l'argument af est AF_INET, ou une adresse IPv6 si l'argument af est AF_INET6 ; l'adresse doit être en octets réseau. L'argument dst pointe vers un tampon où la fonction stocke la chaîne de texte résultante ; il ne doit pas être NULL. L'argument size spécifie la taille de ce tampon, qui doit être suffisamment grand pour contenir la chaîne de texte (INET_ADDRSTRLEN (16) caractères pour IPv4, INET6_ADDRSTRLEN (46) caractères pour IPv6).

VOIR AUSSI

ares_init(3), ares_inet_pton(3)
