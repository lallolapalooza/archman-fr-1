ARCHIVE_READ_ADD_PASSPHRASE(3) Manuel des fonctions de bibliothèque ARCHIVE_READ_ADD_PASSPHRASE(3)

NOM

archive_read_add_passphrase, archive_read_set_passphrase_callback — fonctions pour la lecture d'archives chiffrées

BIBLIOTHÈQUE

Bibliothèque d'archives en flux (libarchive, -larchive)

SYNTAXE

#include <archive.h>

int
archive_read_add_passphrase(struct archive *, const char *passphrase);

int
archive_read_set_passphrase_callback(struct archive *, void *client_data, archive_passphrase_callback *);

DESCRIPTION

archive_read_add_passphrase()
Enregistre des phrases de passe pour la lecture d'une archive chiffrée. Si passphrase est NULL ou vide, cette fonction ne fera rien et ARCHIVE_FAILED sera retourné. Sinon, ARCHIVE_OK sera retourné.
archive_read_set_passphrase_callback()
Enregistre une fonction de rappel qui sera appelée pour obtenir une phrase de passe pour le déchiffrement après l'échec de toutes les phrases de passe enregistrées par la fonction archive_read_add_passphrase().

VOIR AUSSI

tar(1), archive_read(3), archive_read_set_options(3), libarchive(3)
