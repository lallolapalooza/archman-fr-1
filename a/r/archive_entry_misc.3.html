ARCHIVE_ENTRY_MISC(3) Manuel des fonctions de bibliothèque ARCHIVE_ENTRY_MISC(3)

NOM

archive_entry_symlink_type, archive_entry_set_symlink_type — fonctions diverses pour manipuler les propriétés d'une archive_entry

BIBLIOTHÈQUE

Bibliothèque d'archives en flux (libarchive, -larchive)

SYNOPSIS

#include <archive_entry.h>

int
archive_entry_symlink_type(struct archive_entry *a);

void
archive_entry_set_symlink_type(struct archive_entry *a, int);

DESCRIPTION

La fonction archive_entry_symlink_type() retourne et la fonction archive_entry_set_symlink_type() définit le type du lien symbolique stocké dans une entrée d'archive. Ces fonctions ont une signification particulière sur les systèmes d'exploitation qui prennent en charge plusieurs types de liens symboliques (par exemple, Microsoft Windows).

Les valeurs prises en charge sont :

AE_SYMLINK_TYPE_UNDEFINED
Le type de cible du lien symbolique n'est pas défini (par défaut sur les systèmes Unix)
AE_SYMLINK_TYPE_FILE
Le lien symbolique pointe vers un fichier
AE_SYMLINK_TYPE_DIRECTORY
Le lien symbolique pointe vers un répertoire

VOIR AUSSI
