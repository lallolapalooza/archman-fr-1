NOM

ares_expand_string - Développer une chaîne encodée par sa longueur

SYNOPSIS

#include <ares.h>
int ares_expand_string(const unsigned char *encoded,
                       const unsigned char *abuf, int alen,
                       unsigned char **s, long *enclen)

DESCRIPTION

La fonction ares_expand_string convertit une chaîne encodée par sa longueur en une chaîne C terminée par NUL. L'argument encoded indique le début de la chaîne encodée, et les arguments abuf et alen fournissent le tampon du message contenant (nécessaire pour le traitement des pointeurs d'indirection au sein du nom de domaine encodé). Le résultat est placé dans un tampon alloué et terminé par NUL, dont un pointeur est stocké dans la variable pointée par s. La longueur de la chaîne encodée est stockée dans la variable pointée par enclen afin que l'appelant puisse avancer après la chaîne encodée pour lire d'autres données dans le message.

VALEURS DE RETOUR

ares_expand_string peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
Le développement de la chaîne encodée a réussi.
ARES_EBADSTR
La chaîne encodée était mal formée et n'a pas pu être développée.
ARES_ENOMEM
La mémoire a été épuisée.
