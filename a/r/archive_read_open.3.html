a besoin d'octets bruts de l'archive. Le rappel de lecture doit lire les données dans un tampon, définir l'argument const void **buffer pour qu'il pointe vers les données disponibles, et retourner le nombre d'octets disponibles. La bibliothèque n'impose aucune contrainte sur la taille des blocs de données retournés. À la fin de fichier, le rappel de lecture doit retourner zéro. En cas d'erreur, le rappel de lecture doit appeler archive_set_error() pour enregistrer un code d'erreur et un message, puis retourner -1. Le rappel de saut est invoqué lorsque la bibliothèque souhaite ignorer un bloc de données.

La

valeur de retour est le nombre d'octets réellement ignorés, qui peut différer de la demande. Si le rappel ne peut pas ignorer les données, il doit retourner zéro. Si le rappel de saut n'est pas fourni (le pointeur de fonction est NULL ), la bibliothèque invoquera la fonction de lecture à la place et simplement jettera le résultat. Un rappel de saut peut apporter des gains de performance importants lors de la lecture d'archives non compressées depuis des disques lents ou d'autres supports capables d'ignorer rapidement des données. Le rappel de

fermeture

est invoqué par archive_close lorsque le traitement de l'archive est terminé. Le rappel doit retourner ARCHIVE_OK en cas de succès. En cas d'échec, le rappel doit appeler archive_set_error() pour enregistrer un code d'erreur et un message, puis retourner ARCHIVE_FAT
