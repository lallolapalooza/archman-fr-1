argz_add(3) Manuel des fonctions de bibliothèque argz_add(3)

NOM

argz_add, argz_add_sep, argz_append, argz_count, argz_create, argz_create_sep, argz_delete, argz_extract, argz_insert, argz_next, argz_replace, argz_stringify - fonctions pour gérer une liste argz

BIBLIOTHÈQUE

Bibliothèque C standard (libc,-lc)

SYNOPSIS

#include <argz.h>
error_t argz_add(char **restrict argz, size_t *restrict argz_len,
                const char *restrict str);
error_t argz_add_sep(char **restrict argz, size_t *restrict argz_len,
                const char *restrict str, int delim);
error_t argz_append(char **restrict argz, size_t *restrict argz_len,
                const char *restrict buf, size_t buf_len);
size_t argz_count(const char *argz, size_t argz_len);
error_t argz_create(char *const argv[], char **restrict argz,
                size_t *restrict argz_len);
error_t argz_create_sep(const char *restrict str, int sep,
                char **restrict argz, size_t *restrict argz_len);
void argz_delete(char **restrict argz, size_t *restrict argz_len,
                char *restrict entry);
void argz_extract(const char *restrict argz, size_t argz_len,
                char **restrict argv);
error_t argz_insert(char **restrict argz, size_t *restrict argz_len,
                char *restrict before, const char *restrict entry);
char *argz_next(const char *restrict argz, size_t argz_len,
                const char *restrict entry);
error_t argz_replace(char **restrict argz, size_t *restrict argz_len,
                const char *restrict str, const char *restrict with,
                unsigned int *restrict replace_count);
void argz_stringify(char *argz, size_t len, int sep);

DESCRIPTION

Ces fonctions sont spécifiques à glibc.

Un vecteur argz est un pointeur vers un tampon de caractères accompagné d'une longueur. L'interprétation prévue du tampon de caractères est un tableau de chaînes, où les chaînes sont séparées par des octets nuls ('\0'). Si la longueur est non nulle, le dernier octet du tampon doit être un octet nul.

Ces fonctions servent à manipuler les vecteurs argz. Le couple (NULL,0) est un vecteur argz, et, inversement, les vecteurs argz de longueur 0 doivent avoir un pointeur nul. L'allocation des vecteurs argz non vides est effectuée avec malloc(3), afin que free(3) puisse être utilisé pour les libérer à nouveau.

argz_add() ajoute la chaîne str à la fin du tableau *argz, et met à jour *argz et *argz_len.

argz_add_sep() est similaire, mais découpe la chaîne str en sous-chaînes séparées par le délimiteur delim. Par exemple, on pourrait l'utiliser sur un chemin de recherche UNIX avec le délimiteur ':'.

argz_append() ajoute le vecteur argz (buf,buf_len) après (*argz,*argz_len) et met à jour *argz et *argz_len. (Ainsi, *argz_len sera augmenté de buf_len.)

argz_count() compte le nombre de chaînes, c'est-à-dire le nombre d'octets nuls ('\0'), dans (argz,argz_len).

argz_create() convertit un vecteur d'arguments de style UNIX argv, terminé par (char *) 0, en un vecteur argz (*argz,*argz_len).

argz_create_sep() convertit la chaîne terminée par un octet nul str en un vecteur argz (*argz,*argz_len) en la découpant à chaque occurrence du séparateur sep.

argz_delete() supprime la sous-chaîne pointée par entry du vecteur argz (*argz,*argz_len) et met à jour *argz et *argz_len.

argz_extract() est l'opposé de argz_create(). Elle prend le vecteur argz (argz,argz_len) et remplit le tableau commençant à argv avec des pointeurs vers les sous-chaînes, et un NULL final, créant un vecteur argv de style UNIX. Le tableau argv doit avoir de la place pour argz_count(argz, argz_len) + 1 pointeurs.

argz_insert() est l'opposé de argz_delete(). Elle insère l'argument entry à la position before dans le vecteur argz (*argz,*argz_len) et met à jour *argz et *argz_len. Si before est NULL, alors entry sera inséré à la fin.

argz_next() est une fonction pour parcourir le vecteur argz. Si entry est NULL, la première entrée est retournée. Sinon, l'entrée suivante est retournée. Elle retourne NULL s'il n'y a pas d'entrée suivante.

argz_replace() remplace chaque occurrence de str par with, en réallouant argz si nécessaire. Si replace_count est non NULL, *replace_count sera incrémenté du nombre de remplacements.

argz_stringify() est l'opposé de argz_create_sep(). Elle transforme le vecteur argz en une chaîne normale en remplaçant tous les octets nuls ('\0') sauf le dernier par sep.

VALEUR RENVOYÉE

Toutes les fonctions argz qui effectuent une allocation mémoire ont un type de retour error_t (un type entier), et retournent 0 en cas de succès, et ENOMEM si une erreur d'allocation se produit.

BOGUES

    NOM

    argz_count - compte le nombre de chaînes dans une liste de chaînes argz

    SYNOPIS

    #include <argz.h>

    size_t argz_count(const char *argz);

    DESCRIPTION

    La fonction argz_count renvoie le nombre de chaînes dans la liste de chaînes argz, où le début de la liste est pointé par argz. Une liste de chaînes argz est une séquence de chaînes terminées par un octet nul, suivie d'un octet nul supplémentaire.

    VALEUR DE RETOUR

    La fonction argz_count renvoie le nombre de chaînes dans la liste.

    ATTRIBUTS

    Pour obtenir une explication des termes utilisés dans cette section, voir attributes(7).

    argz_count Versione del kernel non applicabile
