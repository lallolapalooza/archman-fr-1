archive_read_free(3)

Paquet: libarchive

ARCHIVE_READ_FREE(3) Manuel des fonctions de bibliothèque ARCHIVE_READ_FREE(3)

NOM

archive_read_close, archive_read_finish, archive_read_free — fonctions pour la lecture d'archives en flux

BIBLIOTHÈQUE

Bibliothèque d'archives en flux (libarchive, -larchive)

SYNTAXE

#include <archive.h>

int
archive_read_close(struct archive *);

int
archive_read_finish(struct archive *);

int
archive_read_free(struct archive *);

DESCRIPTION

archive_read_close()
Termine l'archive et invoque la fonction de rappel de fermeture.
archive_read_finish()
Ceci est un synonyme obsolète de archive_read_free(). Le nouveau nom a été introduit avec libarchive 3.0. Les applications qui ont besoin de compiler avec libarchive 2 ou libarchive 3 devraient continuer à utiliser le nom archive_read_finish(). Les deux noms seront supportés jusqu'à la sortie de libarchive 4.0, qui n'est pas attendue avant 2013.
archive_read_free()
Invoque archive_read_close() si elle n'a pas été invoquée manuellement, puis libère toutes les ressources. Note : Dans libarchive 1.x, cette fonction était déclarée pour retourner void, ce qui rendait impossible la détection de certaines erreurs lorsque archive_read_close() était invoquée implicitement depuis cette fonction. La déclaration a été corrigée à partir de libarchive 2.0.

VALEURS DE RETOUR

Ces fonctions retournent ARCHIVE_OK en cas de succès, ou ARCHIVE_FATAL.

ERREURS

Les codes d'erreur détaillés et les descriptions textuelles sont disponibles via les fonctions archive_errno() et archive_error_string().
