NOM

ares_set_local_ip6 - Définir l'adresse IPv6 locale pour les requêtes sortantes.

SYNTAXE

#include <ares.h>
void ares_set_local_ip6(ares_channel_t *channel, const unsigned char* local_ip6)

DESCRIPTION

La fonction ares_set_local_ip6 définit l'adresse IPv6 pour les requêtes IPv6 sortantes. Le paramètre local_ip6 est spécifié en ordre des octets réseau (network byte order). Ceci permet aux utilisateurs de spécifier les interfaces sortantes lorsqu'elles sont utilisées sur des systèmes multi-homed. L'argument local_ip6 doit avoir une longueur de 16 octets.
