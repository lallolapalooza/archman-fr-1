NOM

ares_parse_mx_reply - Analyser une réponse à une requête DNS de type MX

SYNTAXE

#include <ares.h>

int ares_parse_mx_reply(const unsigned char* abuf, int alen,
struct ares_mx_reply** mx_out);

DESCRIPTION

La fonction ares_parse_mx_reply analyse la réponse à une requête de type MX en une liste chaînée de struct ares_mx_reply Les paramètres abuf et alen donnent le contenu de la réponse. Le résultat est stocké dans une mémoire allouée et un pointeur vers celle-ci est stocké dans la variable pointée par mx_out. Il incombe à l'appelant de libérer la structure mx_out résultante lorsqu'elle n'est plus nécessaire en utilisant la fonction ares_free_data(3).

La structure ares_mx_reply contient les champs suivants :


struct ares_mx_reply {
    struct ares_mx_reply *next;
    char *host;
    unsigned short priority;
};

VALEURS DE RETOUR

ares_parse_mx_reply peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
La réponse a été analysée avec succès.
ARES_EBADRESP
La réponse était malformée.
ARES_ENODATA
La réponse ne contenait pas de réponse à la requête.
ARES_ENOMEM
La mémoire a été épuisée.

DISPONIBILITÉ

Cette fonction a été introduite pour la première fois dans c-ares version 1.7.2.
