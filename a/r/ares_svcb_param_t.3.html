ARES_DATATYPE_BINP - Officiellement défini comme des données binaires, mais probablement imprimable. Garantit d'avoir un terminateur NULL par commodité (non inclus dans la longueur). Utilisez ares_dns_rr_set_bin(3) pour définir et ares_dns_rr_get_bin(3) pour obtenir.
ARES_DATATYPE_OPT - Tableau d'options. Identifiant sur 16 bits, données binaires. Utilisez ares_dns_rr_set_opt(3) pour définir et ares_dns_rr_get_opt(3) pour obtenir.
ARES_DATATYPE_ABINP - Tableau de données binaires, mais probablement imprimable. Garantit d'avoir un terminateur NULL par commodité (non inclus dans la longueur). Utilisez ares_dns_rr_add_abin(3) pour définir et ares_dns_rr_get_abin(3) pour obtenir. Vous pouvez également utiliser ares_dns_rr_set_bin(3) et ares_dns_rr_get_bin(3) si seules des chaînes concaténées sont souhaitées.

DESCRIPTIO

N

La fonction ares_dns_rec_type_tostr(3) fonction renvoie un type d'enregistrement DNS lisible par l'homme à partir de sa forme numérique passée dans type

.

La fonction ares_dns_class_tostr(3) renvoie une classe DNS lisible par l'homme à partir de sa forme numérique passée dans qclass

.

La fonction ares_dns_opcode_tostr(3) renvoie un opcode DNS lisible par l'homme à partir de sa forme numérique dans opcode

.

La fonction ares_dns_rr_key_tostr(3) renvoie un nom de paramètre d'enregistrement de ressource DNS lisible par l'homme à partir de sa forme numérique dans key

.

La fonction ares_dns_section_tostr(3) renvoie une section de message DNS lisible par l'homme à partir de sa forme numérique dans section

.

La fonction ares_dns_rcode_tostr(3) renvoie un code de réponse DNS lisible par l'homme à partir de sa forme numérique dans rcode

.

La fonction ares_dns_class_fromstr(3) renvoie la classe DNS sous forme numérique à partir de sa représentation textuelle dans str. Le résultat est stocké dans la variable pointée par qclass

.

La fonction ares_dns_rec_type_fromstr(3) renvoie le type d'enregistrement DNS sous forme numérique à partir de sa représentation textuelle dans str. Le résultat est stocké dans la variable pointée par qtype

.

La fonction ares_dns_rr_get_keys(3) récupère une liste de paramètres qui peuvent être définis ou récupérés pour le type fourni. Le nombre de clés retournées est stocké dans la variable pointée par cnt

.

La fonction ares_dns_rr_key_datatype(3) récupère le type de données associé pour un paramètre RR spécifié par key

.

La fonction ares_dns_rr_key_to_rec_type(3) déréférence le paramètre RR fourni spécifié par key pour le type d'enregistrement DNS auquel il

appartient.

La fonction ares_dns_opt_get_datatype(3) est utilisée en association avec ares_dns_rr_set_opt(3) et ares_dns_rr_get_opt(3) pour récupérer le type de données d'un enregistrement d'option contenu dans un RR tel que spécifié dans key si celui-ci est connu. L'identifiant brut de l'enregistrement d'option est fourni par opt

.

La fonction ares_dns_opt_get_name(3) est utilisée en association avec ares_dns_rr_set_opt(3) et ares_dns_rr_get_opt(3) pour récupérer le nom de paramètre lisible par l'homme d'un enregistrement d'option contenu dans un RR tel que spécifié dans key si celui-ci est connu. L'identifiant brut de l'enregistrement d'option est fourni par op

t
.

d'échec.

rs entières respectives,
ou 0 en cas d'échec.
