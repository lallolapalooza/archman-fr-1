DESCRIPTIO

N

"gprof" produit un profil d'exécution des programmes C, Pascal ou Fortran77. L'effet des routines appelées est incorporé dans le profil de chaque appelant. Les données de profil sont issues du fichier de profil du graphe d'appel (gmon.out par défaut) qui est créé par les programmes compilés avec l'option -pg de "cc", "pc" et "f77". L'option -pg lie également les versions des routines de bibliothèque compilées pour le profilage. "Gprof" lit le fichier objet donné (par défaut "a.out") et établit la relation entre sa table de symboles et le graphe d'appel du profil à partir de gmon.out. Si plusieurs fichiers de profil sont spécifiés, la sortie de "gprof" montre la somme des informations de profil des fichiers de profil

donnés.

"Gprof" calcule le temps passé dans chaque routine. Ensuite, ces temps sont propagés le long des arêtes du graphe d'appel. Les cycles sont découverts, et les appels vers un cycle se voient attribuer le temps du

cycle.

Plusieurs formes de sortie sont disponibles à partir de

l'analyse.

Le profil plat montre combien de temps votre programme a passé dans chaque fonction, et combien de fois cette fonction a été appelée. Si vous voulez simplement savoir quelles fonctions consomment le plus de cycles, c'est indiqué ici de manière

concise.

Le graphe d'appel montre, pour chaque fonction, quelles fonctions l'ont appelée, quelles autres fonctions elle a appelées, et combien de fois. Il y a aussi une estimation du temps passé dans les sous-routines de chaque fonction. Cela peut suggérer des endroits où vous pourriez essayer d'éliminer des appels de fonctions qui consomment beaucoup de

temps.

Le listing de source annoté est une copie du code source du programme, étiq

uetée avec le nombre de fois où chaqu
e ligne du programme a été exécutée.

Beaucoup de ces options prennent un symspec optionnel pour spécifier les fonctions à inclure ou à exclure. Ces options peuvent être spécifiées plusieurs fois, avec différents symspecs, pour inclure ou exclure des ensembles de

Spécifier l'une de ces options remplace la valeur par défaut (-p -q), qui imprime un profil plat et une analyse du graphe d'appel pour toutes les
