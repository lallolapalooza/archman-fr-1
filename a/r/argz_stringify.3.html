DESCRIPTIO

N

Ces fonctions sont spécifiques à

glibc.

Un vecteur argz est un pointeur vers un tampon de caractères accompagné d'une longueur. L'interprétation prévue du tampon de caractères est un tableau de chaînes, où les chaînes sont séparées par des octets nuls ('\0'). Si la longueur est non nulle, le dernier octet du tampon doit être un octet

nul.

Ces fonctions servent à manipuler les vecteurs argz. Le couple (NULL,0) est un vecteur argz et, inversement, les vecteurs argz de longueur 0 doivent avoir un pointeur nul. L'allocation de vecteurs argz non vides est effectuée à l'aide de malloc(3), de sorte que free(3) peut être utilisé pour les libérer à

nouveau.

argz_add() ajoute la chaîne str à la fin du tableau *argz, et met à jour *argz et *argz_len

.

argz_add_sep() est similaire, mais divise la chaîne str en sous-chaînes séparées par le délimiteur delim. Par exemple, on peut l'utiliser sur un chemin de recherche UNIX avec le délimiteur ':

'.

argz_append() ajoute le vecteur argz (buf,buf_len) après (*argz,*argz_len) et met à jour *argz et *argz_len. (Ainsi, *argz_len sera augmentée de buf_le

n.)

argz_count() compte le nombre de chaînes, c'est-à-dire le nombre d'octets nuls ('\0'), dans (argz,argz_le

n).

argz_create() convertit un vecteur d'arguments de style UNIX argv, terminé par (char *) 0, en un vecteur argz (*argz,*argz_l

en).

argz_create_sep() convertit la chaîne terminée par un octet nul str en un vecteur argz (*argz,*argz_len) en la divisant à chaque occurrence du séparateur sep

.

argz_delete() supprime la sous-chaîne pointée par entry du vecteur argz (*argz,*argz_len) et met à jour *argz et *argz_len

.

argz_extract() est l'opposé de argz_create(). Elle prend le vecteur argz (argz,argz_len) et remplit le tableau commençant à argv avec des pointeurs vers les sous-chaînes, et un NULL final, créant un vecteur argv de style UNIX. Le tableau argv doit avoir de la place pour argz_count(argz, argz_len) + 1

pointeurs.

argz_insert() est l'opposé de argz_delete(). Elle insère l'argument entry à la position before dans le vecteur argz (*argz,*argz_len) et met à jour *argz et *argz_len. Si before vaut NULL, alors entry sera inséré à la

fin.

argz_next() est une fonction pour parcourir le vecteur argz. Si entry vaut NULL, la première entrée est retournée. Sinon, l'entrée suivante est retournée. Elle retourne NULL s'il n'y a pas d'entrée

suivante.

argz_replace() remplace chaque occurrence de str par with, en réallouant argz si nécessaire. Si replace_count n'est pas NULL, *replace_count sera incrémentée du nombre de

remplacements.

argz_stringify() est l'opposé de argz_create_sep(). Elle transforme le vecteur argz en une chaîne normale en remplaçant tous les octets nuls ('\0') sauf le dernier par se

p
.

    argz_stringify(3)

    argz_stringify, argz_stringify_sep - serialize an argz into a string

    SYNOPSIS

    #include <argz.h>

char *argz_stringify(char *argz, size_t len, int sep);
char *argz_stringify_sep(const char *argz, size_t len, int sep);

    DESCRIPTION

    The argz_stringify and argz_stringify_sep functions serialize the null-terminated argument list specified by argz and len into a single contiguous string, separated by the character sep.

    The resulting string will be null-terminated. The space for this string is allocated using malloc(3) and must be free(3)d by the caller.

    The argz argument is a pointer to the start of the argz list and len is the number of bytes available in the argz list, including the terminating null character.

    argz_stringify modifies the input argz list in place. This is a historical artifact and it is recommended to use argz_stringify_sep instead.

    argz_stringify_sep takes a const pointer to the argz list and does not modify it. The function returns a pointer to the newly allocated string containing the serialized arguments.

    RETURN VALUE

    On success, both functions return a pointer to the newly allocated string. On failure, they return NULL.

    ATTRIBUTES

    For information about the translation of this information to the following attributes, see attributes(7).

    +--------------------+-------------------+
| Attribute          | Value             |
+--------------------+-------------------+
| Interface stability| Committed         |
+--------------------+-------------------+

    STANDARDS

    These functions are GNU extensions to the C library.

    BUGS

    The original argz_stringify function modified the input argz list in place. This is generally undesirable and can lead to unexpected behavior. It is recommended to use argz_stringify_sep instead.

argz_stringify(3)

argz_stringify, argz_stringify_sep - sérialiser un argz en une chaîne

SYNOPSIS

#include <argz.h>

char *argz_stringify(char *argz, size_t len, int sep);
char *argz_stringify_sep(const char *argz, size_t len, int sep);

DESCRIPTION

Les fonctions argz_stringify et argz_stringify_sep sérialisent la liste d'arguments terminée par un caractère nul spécifiée par argz et len en une seule chaîne contiguë, séparée par le caractère sep.

La chaîne résultante sera terminée par un caractère nul. L'espace pour cette chaîne est alloué en utilisant malloc(3) et doit être libéré par l'appelant avec free(3).

L'argument argz est un pointeur vers le début de la liste argz et len est le nombre d'octets disponibles dans la liste argz, y compris le caractère nul de terminaison.

argz_stringify modifie la liste argz d'entrée en place. Il s'agit d'un artefact historique et il est recommandé d'utiliser argz_stringify_sep à la place.

argz_stringify_sep prend un pointeur constant vers la liste argz et ne la modifie pas. La fonction renvoie un pointeur vers la chaîne nouvellement allouée contenant les arguments sérialisés.

VALEUR DE RETOUR

En cas de succès, les deux fonctions renvoient un pointeur vers la chaîne nouvellement allouée. En cas d'échec, elles renvoient NULL.

ATTRIBUTS

Pour plus d'informations sur la traduction de ces informations vers les attributs suivants, voir attributes(7).

+--------------------+-------------------+
| Attribut           | Valeur            |
+--------------------+-------------------+
| Stabilité de l'interface | Engagée           |
+--------------------+-------------------+

NORMES

Ces fonctions sont des extensions GNU de la bibliothèque C.

BOGUES

La fonction originale argz_stringify modifiait la liste argz d'entrée en place. Ceci est généralement indésirable et peut entraîner un comportement inattendu. Il est recommandé d'utiliser argz_stringify_sep à la place.
