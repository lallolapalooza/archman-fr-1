Paquet: net-tools

ARP(8) Manuel d'administration système Linux ARP(8)

NOM

arp - manipuler le cache ARP du système

SYNTAXE

arp [-vn] [-H type] [-i if] [-ae] [nom_hôte]

arp [-v] [-i if] -d nom_hôte [pub]

arp [-v] [-H type] [-i if] -s nom_hôte addr_matériel [temp]

arp [-v] [-H type] [-i if] -s nom_hôte addr_matériel [netmask nm] pub

arp [-v] [-H type] [-i if] -Ds nom_hôte nom_interface [netmask nm] pub

arp [-vnD] [-H type] [-i if] -f [nom_fichier]

DESCRIPTION

Arp manipule ou affiche le cache des voisins IPv4 du noyau. Il peut ajouter des entrées à la table, en supprimer une ou afficher le contenu actuel.

ARP signifie Address Resolution Protocol (Protocole de Résolution d'Adresse), qui est utilisé pour trouver l'adresse MAC (Media Access Control) d'un voisin réseau pour une adresse IPv4 donnée.

MODES

arp sans spécificateur de mode affichera le contenu actuel de la table. Il est possible de limiter le nombre d'entrées affichées en spécifiant un type d'adresse matérielle, un nom d'interface ou une adresse hôte.

arp -d adresse supprimera une entrée du cache ARP. Les privilèges root ou netadmin sont requis pour cela. L'entrée est trouvée par adresse IP. Si un nom d'hôte est donné, il sera résolu avant de rechercher l'entrée dans le cache ARP.

arp -s adresse addr_matériel est utilisé pour configurer une nouvelle entrée dans la table. Le format du paramètre addr_matériel dépend de la classe matérielle, mais pour la plupart des classes, on peut supposer que la présentation habituelle peut être utilisée. Pour la classe Ethernet, il s'agit de 6 octets en hexadécimal, séparés par des deux-points. Lors de l'ajout d'entrées ARP proxy (c'est-à-dire celles avec le drapeau publish activé), un netmask peut être spécifié pour faire du proxy ARP pour des sous-réseaux entiers. Ce n'est pas une bonne pratique, mais c'est supporté par les anciens noyaux car cela peut être utile. Si le drapeau temp n'est pas fourni, les entrées seront stockées de manière permanente dans le cache ARP. Pour simplifier la configuration des entrées pour l'une de vos propres interfaces réseau, vous pouvez utiliser la forme arp -Ds adresse nom_interface. Dans ce cas, l'adresse matérielle est prise de l'interface portant le nom spécifié.

OPTIONS

-v, --verbose
Informe l'utilisateur de ce qui se passe en étant verbeux.
-n, --numeric
affiche les adresses numériques au lieu d'essayer de déterminer les noms symboliques d'hôtes, de ports ou d'utilisateurs.
-H type, --hw-type type, -t type
Lors de la lecture ou de la configuration du cache ARP, ce paramètre optionnel indique à arp quelle classe d'entrées il doit vérifier. La valeur par défaut de ce paramètre est ether (c'est-à-dire le code matériel 0x01 pour IEEE 802.3 10Mbps Ethernet). D'autres valeurs peuvent inclure des technologies réseau telles que ARCnet (arcnet), PROnet (pronet), AX.25 (ax25) et NET/ROM (netrom).
-a
Utilise le format de sortie alternatif de style BSD (sans colonnes fixes).
-e
Utilise le format de sortie par défaut de style Linux (avec colonnes fixes).
-D, --use-device
Au lieu d'une addr_matériel, l'argument donné est le nom d'une interface. arp utilisera l'adresse MAC de cette interface pour l'entrée de table. C'est généralement la meilleure option pour configurer une entrée ARP proxy pour soi-même.
-i If, --device If
Sélectionne une interface. Lors de l'affichage du cache ARP, seules les entrées correspondant à l'interface spécifiée seront imprimées. Lors de la configuration d'une entrée ARP permanente ou temp, cette interface sera associée à l'entrée ; si cette option n'est pas utilisée, le noyau devinera en fonction de la table de routage. Pour les entrées pub, l'interface spécifiée est l'interface sur laquelle les requêtes ARP seront répondus.
NOTE : Cela doit être différent de l'interface vers laquelle les datagrammes IP seront acheminés. NOTE : Depuis le noyau 2.2.0, il n'est plus possible de configurer une entrée ARP pour un sous-réseau entier. Linux effectue désormais un proxy ARP automatique lorsqu'une route existe et qu'il effectue des transferts. Voir arp(7) pour plus de détails. De plus, l'option dontpub, disponible pour les opérations de suppression et de définition, ne peut pas être utilisée avec les noyaux 2.4 et plus récents.
-f nom_fichier, --file nom_fichier
Similaire à l'option -s, seulement cette fois les informations d'adresse sont prises du fichier nom_fichier. Ceci peut être utilisé si des entrées ARP pour un grand nombre d'hôtes doivent être configurées. Le nom du fichier de données est très souvent /etc/ethers, mais ce n'est pas officiel. Si aucun nom de fichier n'est spécifié, /etc/ethers est utilisé par défaut.

Le format du fichier est simple ; il contient seulement des lignes de texte ASCII avec un nom d'hôte et une adresse matérielle séparés par des espaces. De plus, les drapeaux pub, temp et netmask peuvent être utilisés.

Dans tous les endroits où un nom_hôte est attendu, on peut également entrer une adresse IP en notation décimale pointée.

En tant que cas particulier pour la compatibilité, l'ordre du nom d'hôte et de l'adresse matérielle peut être échangé.

Chaque entrée complète dans le cache ARP sera marquée avec le drapeau C. Les entrées permanentes sont marquées avec M et les entrées publiées ont le drapeau P.

EXEMPLES

/usr/sbin/arp -i eth0 -Ds 10.0.0.2 eth1 pub

Ceci répondra aux requêtes ARP pour 10.0.0.2 sur eth0 avec l'adresse MAC de eth1.

/usr/sbin/arp -i eth1 -d 10.0.0.1

Supprime l'entrée du cache ARP pour 10.0.0.1 sur l'interface eth1. Ceci correspondra aux entrées ARP proxy publiées et aux entrées permanentes.

FICHIERS

/etc/networks
/etc/hosts
/etc/ethers

arp(8)

Nom

arp - manipule ou interroge le cache des voisins ARP

Synopsis

arp -n
arp -v
arp -i <interface> -n
arp -i <interface> -v
arp -i <interface> -d <host> [<if>]
arp -i <interface> -s <host> <ether> [<temp>] [<pub>]
arp -i <interface> -Ds <host> <ether> [<temp>] [<pub>]
arp -i <interface> -d -v <host> [<if>]
arp -i <interface> -s -v <host> <ether> [<temp>] [<pub>]
arp -i <interface> -Ds -v <host> <ether> [<temp>] [<pub>]

Description

La commande arp permet de manipuler ou d'afficher le cache du protocole de résolution d'adresses (ARP). Le cache ARP est une table qui stocke les correspondances entre les adresses IP et les adresses MAC sur un réseau local. Lorsque le noyau a besoin d'envoyer un paquet IP à une machine sur le réseau local, il consulte le cache ARP pour trouver l'adresse MAC correspondante. Si l'adresse MAC n'est pas dans le cache, le noyau envoie une requête ARP à toutes les machines du réseau. La machine dont l'adresse IP correspond à celle recherchée répond avec son adresse MAC.

Options

  • -n : N'affiche pas les noms d'hôtes. Si cette option est présente, les adresses IP sont affichées telles quelles au lieu d'être résolues en noms d'hôtes.
  • -v : Mode verbeux. Affiche des informations supplémentaires sur les entrées du cache ARP.
  • -i <interface> : Spécifie l'interface réseau à utiliser. Si aucune interface n'est spécifiée, arp essaiera de deviner celle qui convient.
  • -d <host> : Supprime l'entrée ARP pour l'hôte spécifié.
  • -s <host> <ether> : Ajoute ou met à jour une entrée ARP pour l'hôte spécifié avec l'adresse MAC (ether) correspondante. L'adresse MAC doit être spécifiée au format hexadécimal, par exemple 00:AA:BB:CC:DD:EE.
  • -Ds <host> <ether> : Identique à -s, mais l'adresse MAC est automatiquement déterminée à partir de la requête ARP envoyée (si l'option -t n'est pas utilisée).
  • <temp> : Marque l'entrée comme temporaire. Les entrées temporaires sont supprimées du cache ARP après un certain temps.
  • <pub> : Marque l'entrée comme publique. Les entrées publiques sont envoyées en réponse aux requêtes ARP.

Exemples

arp -n : Affiche le cache ARP sans résoudre les noms d'hôtes.

arp -v : Affiche le cache ARP en mode verbeux.

arp -i eth0 -n : Affiche le cache ARP pour l'interface eth0 sans résoudre les noms d'hôtes.

arp -d 192.168.1.1 : Supprime l'entrée ARP pour l'adresse IP 192.168.1.1.

arp -s 192.168.1.100 00:11:22:33:44:55 : Ajoute une entrée ARP pour l'adresse IP 192.168.1.100 avec l'adresse MAC 00:11:22:33:44:55.

Fichiers

  • /proc/net/arp : Fichier système qui contient le cache ARP.

Voir aussi

ip(8), ping(8), netstat(8)
