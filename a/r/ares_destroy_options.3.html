NOM

ares_destroy_options - Détruire les options initialisées avec ares_save_options

SYNOPSIS

#include <ares.h>
void ares_destroy_options(struct ares_options *options)

DESCRIPTION

La fonction ares_destroy_options(3) détruit la structure d'options identifiée par options, libérant toute mémoire allouée par ares_save_options(3).

VOIR AUSSI

ares_save_options(3), ares_init_options(3)
