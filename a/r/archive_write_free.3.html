archive_write_free(3)

Paquet: libarchive

Licences: BSD-2-Clause

ARCHIVE_WRITE_FREE(3) Manuel des fonctions de bibliothèque ARCHIVE_WRITE_FREE(3)

NOM

archive_write_fail, archive_write_close, archive_write_finish, archive_write_free — fonctions pour créer des archives

BIBLIOTHÈQUE

Bibliothèque d'archives en flux (libarchive, -larchive)

SYNTAXE

#include <archive.h>

int
archive_write_fail(struct archive *);

int
archive_write_close(struct archive *);

int
archive_write_finish(struct archive *);

int
archive_write_free(struct archive *);

DESCRIPTION

archive_write_fail()
Retourne toujours ARCHIVE_FATAL. Cela marque l'objet archive comme inutilisable ; après avoir appelé cette fonction, le seul appel qui peut réussir est archive_write_free() pour libérer les ressources. Ceci peut être utilisé pour accélérer la récupération lorsque la création de l'archive doit être abandonnée. Notez que l'archive créée sera probablement malformée dans ce cas ;
archive_write_close()
Achève l'archive et invoque la fonction de rappel de fermeture.
archive_write_finish()
Ceci est un synonyme obsolète pour archive_write_free().
archive_write_free()
Invoque archive_write_close() si nécessaire, puis libère toutes les ressources. Si vous avez besoin d'informations détaillées sur les échecs de archive_write_close(), vous devez faire attention à l'appeler séparément, car vous ne pouvez pas obtenir d'informations d'erreur après que archive_write_free() ait retourné.

VALEURS DE RETOUR

Ces fonctions retournent ARCHIVE_OK en cas de succès, ou ARCHIVE_FATAL.

ERREURS

Les codes d'erreur détaillés et les descriptions textuelles sont disponibles à partir des fonctions archive_errno() et archive_error_string().

VOIR AUSSI

tar(1), archive_write_set_options(3), libarchive(3), cpio(5), mtree(5), tar(5)
