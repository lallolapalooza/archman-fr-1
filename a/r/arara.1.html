ARARA(1) Manuel des commandes générales ARARA(1)

NOM

arara - un outil d'automatisation TeX basé sur des règles et des directives.

SYNTAXE

arara [options] documents...

DESCRIPTION

arara est un outil d'automatisation TeX basé sur des règles et des directives. Il vous offre un moyen d'améliorer votre expérience TeX. Cet outil vise à fournir un moyen concis d'automatiser le flux de travail TeX quotidien pour les utilisateurs et également pour les auteurs de paquets. Les utilisateurs peuvent écrire leurs propres règles lorsque celles fournies ne suffisent pas.

arara prend une liste de documents en entrée. Ils seront traités conformément à leurs directives. Les options s'appliquent à l'exécution de tous les documents.

OPTIONS

--log
Générer une sortie de journal.
--verbose
Afficher ou supprimer la sortie de la commande.
--dry-run
Effectuer toutes les opérations d'une commande mais sans aucune action réelle.
--safe-run
Exécuter en mode sécurisé et désactiver les fonctionnalités potentiellement dangereuses.
--whole-file
Extraire les directives dans le fichier, pas seulement dans l'en-tête.
--preamble
Définir le préambule du fichier comme nommé en fonction du fichier de configuration.
--timeout
Définit un délai d'exécution pour les processus lancés.
--language
Définir la localisation à la langue spécifiée par le code.
--max-loops
Définit le nombre > 0 de boucles pour les directives de bouclage.
--working-directory
Définit le répertoire de travail pour toute l'exécution.
--call-property
Passe une propriété sous forme de paramètre clé=valeur dans l'application pour être utilisée dans la session.
--generate-completion
Générer un script d'achèvement pour arara.
--version
Afficher la version et quitter.
--help
Afficher un message d'aide et quitter.
