NOM

ares_create_query - Composer un tampon de requête DNS à question unique

SYNOPSIS

#include <ares.h>
int ares_create_query(const char *name,
                      int dnsclass,
                      int type,
                      unsigned short id,
                      int rd,
                      unsigned char **buf,
                      int *buflen,
                      int max_udp_size);

DESCRIPTION

Cette fonction est obsolète depuis c-ares 1.22, utilisez plutôt ares_dns_record_create(3).

La fonction ares_create_query(3) compose une requête DNS avec une seule question. Le paramètre name représente le nom de la requête sous forme d'une chaîne C terminée par NUL, séparée par des points, éventuellement terminée par un point ; les points et les barres obliques inversées dans une étiquette doivent être échappés avec une barre oblique inversée.

Les paramètres dnsclass et type donnent la classe et le type de la requête en utilisant les valeurs définies dans <arpa/nameser.h>.

Le paramètre id donne un identifiant de 16 bits pour la requête.

Le paramètre rd doit être non nul si la récursion est souhaitée, nul sinon.

La requête sera placée dans un tampon alloué, un pointeur vers lequel sera stocké dans la variable pointée par buf, et dont la longueur sera stockée dans la variable pointée par buflen.

Il incombe à l'appelant de libérer ce tampon en utilisant ares_free_string(3) lorsqu'il n'est plus nécessaire. Le paramètre max_udp_size doit être non nul pour activer EDNS. L'utilisation de ares_create_query(3) avec max_udp_size défini à zéro est équivalente à l'utilisation de ares_mkquery(3).

VALEURS DE RETOUR

ares_create_query peut retourner l'une des valeurs suivantes :

ARES_SUCCESS
La construction de la requête DNS a réussi.
ARES_ENOTFOUND
Le nom de requête name fait référence à un nom de domaine .onion. Voir RFC 7686.
ARES_EBADNAME
Le nom de requête name n'a pas pu être encodé en tant que nom de domaine, soit parce qu'il contenait une étiquette de longueur nulle, soit parce qu'il contenait une étiquette de plus de 63 caractères.
ARES_ENOMEM
La mémoire a été épuisée.

DISPONIBILITE

Ajouté dans c-ares 1.10.0

VOIR AUSSI

ares_dns_record(3), ares_expand_name(3), ares_free_string(3), ares_mkquery(3)
