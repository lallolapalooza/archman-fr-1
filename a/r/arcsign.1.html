NOM

arcsign - Script pour signer des messages ARC depuis stdin

VERSION

0.9.2

DESCRIPTION

arcsign est un filtre qui lit un message RFC822 sur l'entrée standard et écrit le même message sur la sortie standard avec des lignes ARC-Signature précédées.

UTILISATION

Les options de signature sont spécifiées sur la ligne de commande :

arcsign sélecteur domaine fichier_clé_privée id_srv

Note : arcsign n'utilisera que les champs d'en-tête des résultats d'authentification avec un id_serveur correspondant à id_srv comme champs d'entrée pour la chaîne ARC.
