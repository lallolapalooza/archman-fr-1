ARECORDMIDI2(1) Manuel des commandes générales ARECORDMIDI2(1)

NOM

arecordmidi2 - enregistrer un fichier MIDI Clip

SYNTAXE

arecordmidi2 [options] midi2file

DESCRIPTION

arecordmidi2 est un utilitaire en ligne de commande qui enregistre un fichier MIDI Clip à partir d'un ou plusieurs ports de séquenceur ALSA.

Pour arrêter l'enregistrement, appuyez sur Ctrl+C.

Lorsque - est passé à l'argument du fichier MIDI Clip, il est enregistré sur la sortie standard. Cela implique également l'option -s.

OPTIONS

-h,--help
Affiche la liste des options.
-V,--version
Affiche la version actuelle.
-p,--port=client:port,...
Définit le(s) port(s) de séquenceur à partir desquel(s) les événements sont enregistrés.

Un client peut être spécifié par son numéro, son nom, ou un préfixe de son nom. Un port est spécifié par son numéro ; pour le port 0 d'un client, la partie ":0" de la spécification du port peut être omise.

arecordmidi2 crée un End-Point UMP contenant le même nombre de Blocs Fonctionnels que spécifié par cette option, chacun étant connecté au port spécifié en tant que source.

Lorsqu'aucun port source n'est spécifié avec l'option -p, arecordmidi2 crée un End-Point UMP avec 16 Blocs Fonctionnels complets et enregistre à partir de ces entrées. L'utilisateur peut connecter librement les ports de séquenceur via aconnect, par exemple. Ce mode peut être utilisé conjointement avec le mode interactif via l'option -r.

-b,--bpm=battements
Définit le tempo musical du fichier MIDI, en battements par minute. La valeur par défaut est 120 BPM.
-t,--ticks=ticks
Définit la résolution des estampilles temporelles (ticks) dans le fichier MIDI, en ticks par battement. La valeur par défaut est 384 ticks/battement.
-i,--timesig=numerateur:denominateur
Définit la mesure du fichier MIDI.

La mesure est spécifiée comme d'habitude avec deux nombres, représentant le numérateur et le dénominateur de la mesure telle qu'elle serait notée. Le dénominateur doit être une puissance de deux. Les deux nombres doivent être séparés par un deux-points. La mesure par défaut est 4:4.

-n,--num-events=evenements
Arrête l'enregistrement après avoir reçu le nombre d'événements donné.
-u,--ump=version
Définit la version du protocole MIDI UMP. Soit 1, soit 2 doit être donné pour le protocole MIDI 1.0 et MIDI 2.0, respectivement. La valeur par défaut est 1.
-r,--interactive
Exécute en mode interactif. arecordmidi2 attend une entrée de la touche RETOUR du terminal pour démarrer l'enregistrement. Après le démarrage, l'enregistrement se termine lorsqu'une autre touche RETOUR est saisie dans le terminal. Les événements reçus avant le début de l'enregistrement sont ignorés.
-s,--silent
Ne pas afficher de messages sur la sortie standard.
-P,--profile=fichier
Lit les données UMP à partir du fichier donné et les place dans la section de configuration de la sortie enregistrée. Le fichier doit contenir uniquement des données UMP valides encodées en big-endian.
--song=texte, --clip=texte, --copyright=texte, --composer=texte, --lyricist=texte, --arranger=texte, --publisher=texte, --performer=texte --accompany=texte, --date=texte, --location=texte
Place le texte de métadonnées donné dans la section de configuration.
