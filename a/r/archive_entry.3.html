ARCHIVE_ENTRY(3) Manuel des fonctions de bibliothèque ARCHIVE_ENTRY(3)

NOM

archive_entry_clear, archive_entry_clone, archive_entry_free, archive_entry_new — fonctions pour la gestion des descriptions d'entrées d'archive

BIBLIOTHÈQUE

Bibliothèque d'archives en flux (libarchive, -larchive)

SYNOPSIS

#include <archive_entry.h>

struct archive_entry *
archive_entry_clear(struct archive_entry *);

struct archive_entry *
archive_entry_clone(struct archive_entry *);

void
archive_entry_free(struct archive_entry *);

struct archive_entry *
archive_entry_new(void);

DESCRIPTION

Ces fonctions créent et manipulent des objets de données qui représentent des entrées dans une archive. Vous pouvez considérer une struct archive_entry comme une version améliorée de struct stat : elle inclut tout de struct stat plus le nom de chemin associé, les noms de groupe et d'utilisateur textuels, etc. Ces objets sont utilisés par libarchive(3) pour représenter les métadonnées associées à une entrée particulière dans une archive.

Création et destruction

Il existe des fonctions pour allouer, détruire, effacer et copier les objets archive_entry :

archive_entry_clear()
Efface l'objet, réinitialisant tous les champs internes au même état qu'un objet nouvellement créé. Ceci est fourni pour vous permettre de recycler rapidement des objets sans surcharger le tas.
archive_entry_clone()
Opération de copie profonde ; tous les champs de texte sont dupliqués.
archive_entry_free()
Libère l'objet struct archive_entry.
archive_entry_new()
Alloue et retourne un objet struct archive_entry vide.

Groupes de fonctions

En raison du grand nombre de fonctions, les fonctions d'accès se trouvent dans des pages de manuel regroupées par objectif.

archive_entry_acl(3)
Manipulation des listes de contrôle d'accès
archive_entry_paths(3)
Manipulation des noms de chemin
archive_entry_perms(3)
Manipulation de l'utilisateur, du groupe et du mode
archive_entry_stat(3)
Fonctions ne faisant pas partie des autres groupes et copie vers/depuis struct stat.
archive_entry_time(3)
Manipulation des champs temporels

La plupart des fonctions définissent ou lisent des entrées dans un objet. Ces fonctions ont l'une des formes suivantes :

archive_entry_set_XXXX()
Stocke les données fournies dans l'objet. En particulier, pour les chaînes, le pointeur est stocké, pas la chaîne référencée.
archive_entry_copy_XXXX()
Comme ci-dessus, sauf que les données référencées sont copiées dans l'objet.
archive_entry_XXXX()
Retourne les données spécifiées. Dans le cas des chaînes, un pointeur qualifié const vers la chaîne est retourné.
Les données de chaîne peuvent être définies ou accédées en tant que chaînes de caractères larges ou chaînes char normales. Les fonctions utilisant des chaînes de caractères larges sont suffixées par _w. Notez qu'il s'agit de représentations différentes des mêmes données : Par exemple, si vous stockez une chaîne étroite et lisez la chaîne large correspondante, l'objet convertira de manière transparente les formats en utilisant la locale actuelle. De même, si vous stockez une chaîne large puis une chaîne étroite pour les mêmes données, la chaîne large précédemment définie sera remplacée par les nouvelles données.
