DESCRIPTIO

N

Ark est un programme pour gérer divers formats de fichiers compressés au sein de KDE. Les archives peuvent être

consultées, extraites, créées et modifiées avec Ark. Le programme peut gérer divers formats tels que tar, gzip,
bzip2, zip, rar (lorsque les bibliothèques ou les programmes en ligne de commande appropriés sont installés).

MODES

D'UTILISATION

Ark peut être utilisé soit comme programme d'interface graphique autonome, soit comme programme en ligne de commande afin d'effectuer certaines tâches

spécifiques.

S'il est invoqué sans les options -b (--batch) ou -c (--add), Ark est démarré comme un programme d'interface graphique

normal.

Lorsque l'option -b (--batch) est utilisée, Ark peut être utilisé pour extraire le contenu d'un ou plusieurs fichiers directement depuis la ligne de commande, sans lancer son interface

graphique.

Lorsque l'option -c (--add) est utilisée, Ark dem

ande les fichiers qui doivent être ajoutés à
une nouvelle archive ou à une archive existante.
