NOM

ares_gethostbyname_file - Rechercher un nom dans le fichier hosts du système

SYNTAXE

#include <ares.h>
int ares_gethostbyname_file(ares_channel_t *channel, const char *name,
                            int family, struct hostent **host)

DESCRIPTION

La fonction ares_gethostbyname_file effectue une recherche d'hôte par nom dans le fichier hosts du système (ou une base de données locale équivalente de noms d'hôtes). Le paramètre channel est requis, mais aucune requête asynchrone n'est effectuée. Au lieu de cela, la recherche est effectuée via le même mécanisme utilisé pour effectuer des recherches 'f' (voir le champ d'options lookups dans ares_init_options(3)). Le paramètre name donne le nom d'hôte sous forme de chaîne C se terminant par NUL, et family donne le type d'adresse désiré pour l'entrée d'hôte résultante.

La valeur de retour indique si la requête a réussi et, sinon, comment elle a échoué. Elle peut avoir l'une des valeurs suivantes :

ARES_SUCCESS
La recherche d'hôte s'est terminée avec succès et host pointe maintenant vers le résultat (et doit être libéré avec ares_free_hostent(3)).
ARES_ENOTFOUND
Le nom d'hôte name n'a pas été trouvé.
ARES_EFILE
Une erreur d'entrée/sortie de fichier s'est produite lors de la recherche.
ARES_ENOMEM
La mémoire a été épuisée.

En cas de succès de la requête, le pointeur pointé par host pointe vers une structure struct hostent contenant l'adresse de l'hôte renvoyée par la recherche. L'utilisateur doit libérer la mémoire pointée par host lorsqu'il a terminé en appelant ares_free_hostent(3). Si la recherche n'a pas abouti, host sera NULL.

DISPONIBILITE

Ajouté dans c-ares 1.5.4
