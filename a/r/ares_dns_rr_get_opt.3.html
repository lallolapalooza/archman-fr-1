DESCRIPTIO

N

La fonction ares_dns_record_rr_cnt(3) renvoie le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section fournie dans le paramètre

sect.

La fonction ares_dns_record_rr_add(3) ajoute une nouvelle entrée d'enregistrement de ressources à l'enregistrement DNS fourni par le paramètre dnsrec. L'enregistrement de ressources résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle appartient l'enregistrement de ressources est spécifiée par le paramètre sect. Le nom de domaine associé à l'enregistrement de ressources est spécifié par le paramètre name, qui ne peut pas être NULL mais peut être une chaîne vide, ou « . ». Le type d'enregistrement de ressources est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le Time To Live (TTL) dans le paramètre

ttl.

Les fonctions ares_dns_record_rr_get(3) et ares_dns_record_rr_get_const(3) sont utilisées pour récupérer le pointeur de l'enregistrement de ressources à partir de l'enregistrement DNS fourni dans le paramètre dnsrec pour la section d'enregistrement de ressources fournie dans le paramètre sect pour l'index spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_rr_cnt(3). La première fonction renvoie un pointeur modifiable vers l'enregistrement de ressources, tandis que la seconde renvoie un pointeur en lecture seule vers l'enregistrement de

ressources.

La fonction ares_dns_record_rr_del(3) est utilisée pour supprimer un enregistrement de ressources de l'enregistrement DNS spécifié dans le paramètre dnsrec. Son utilisation principale est de supprimer un enregistrement ARES_REC_TYPE_OPT lorsqu'il faut réessayer une requête sans support EDNS. La section RR DNS est spécifiée via le paramètre sect, et l'index à supprimer est spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_r

r_cnt(3).

La fonction ares_dns_rr_get_name(3) est utilisée pour récupérer le nom de domaine de l'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr

.

La fonction ares_dns_rr_get_type(3) est utilisée pour récupérer le type d'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr

.

La fonction ares_dns_rr_get_class(3) est utilisée pour récupérer la classe d'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr

.

La fonction ares_dns_rr_get_ttl(3) est utilisée pour récupérer le Time to Live (TTL) de la classe d'enregistrement de ressources à partir du pointeur d'enregistrement de ressources fourni dans le paramètre rr

.

La fonction ares_dns_rr_set_addr(3) est utilisée pour définir une adresse IPv4 pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_INADDR. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre addr

.

La fonction ares_dns_rr_set_addr6(3) est utilisée pour définir une adresse IPv6 pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_INADDR6. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre addr

.

La fonction ares_dns_rr_set_str(3) est utilisée pour définir une chaîne pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_STR ou ARES_DATATYPE_NAME. La plupart des chaînes sont limitées à 255 octets, cependant certains enregistrements, comme un enregistrement TXT, peuvent autoriser des chaînes plus longues car ils sont produites sous forme de chaînes multiples. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val

.

La fonction ares_dns_rr_set_u8(3) est utilisée pour définir une valeur non signée de 8 bits pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_U8. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val

L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val

La fonction ares_dns_rr_set_u32(3) est utilisée pour définir une valeur non signée de 32 bits pour la clé/paramètre d'enregistrement de ressources associé lorsque le type de données est ARES_DATATYPE_U32. L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val

L'enregistrement de ressources à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val. Refer to ares_dns_mapping(3) for enumeration definitions.

DESCRIPTION

These functions provide an interface for manipulating DNS resource records (RR). They allow the user to add, delete, or retrieve specific fields within a DNS resource record.

The ares_dns_record_rr_add function adds an existing resource record to a DNS record structure. The dns_record parameter is the parent DNS record structure, and dns_rr is the resource record to add. This function returns 0 on success, or an error code otherwise.

The ares_dns_record_rr_cnt function returns the number of resource records currently stored within the dns_record structure.

The ares_dns_record_rr_del function deletes a resource record from the DNS record structure. The dns_record parameter is the parent DNS record structure, and dns_rr is the resource record to delete. This function returns 0 on success, or an error code otherwise.

The ares_dns_record_rr_get and ares_dns_record_rr_get_const functions retrieve a resource record from the DNS record structure at the specified index idx. The dns_record parameter is the parent DNS record structure. ares_dns_record_rr_get returns a modifiable pointer to the resource record, while ares_dns_record_rr_get_const returns a constant pointer. Both functions return NULL on failure (e.g., index out of bounds).

The following functions operate on individual resource records:

  • ares_dns_rr_set_u8, ares_dns_rr_set_u16, ares_dns_rr_set_u32, ares_dns_rr_set_addr, ares_dns_rr_set_addr6, ares_dns_rr_set_str, ares_dns_rr_set_bin, and ares_dns_rr_set_opt are used to set specific fields within a resource record. The resource record to modify is passed in dns_rr, and the field to set is identified by key. The value to set is passed in val (for binary types like ARES_DATATYPE_BIN and ARES_DATATYPE_OPT) or directly as arguments (for other types). The length of binary data is passed in val_len.
  • ares_dns_rr_add_abin adds a binary value to an array of binary values within a resource record.
  • ares_dns_rr_del deletes a field identified by key from the resource record. If the field contains multiple values (e.g., an array), the specific value at index idx is removed.
  • ares_dns_rr_del_abin deletes a binary value from an array of binary values within a resource record.
  • ares_dns_rr_del_opt_byid deletes an option/parameter from a resource record of type ARES_DATATYPE_OPT based on its identifier opt.
  • ares_dns_rr_get_addr, ares_dns_rr_get_addr6, ares_dns_rr_get_str, ares_dns_rr_get_u8, ares_dns_rr_get_u16, ares_dns_rr_get_u32, ares_dns_rr_get_bin, ares_dns_rr_get_abin_cnt, ares_dns_rr_get_abin, ares_dns_rr_get_opt_cnt, ares_dns_rr_get_opt, and ares_dns_rr_get_opt_byid are used to retrieve fields from a resource record. The resource record is passed in dns_rr, and the field to retrieve is identified by key. The retrieved value is stored in the pointer provided (e.g., addr, str, val8, etc.). For array types, idx specifies the index to retrieve, and len or val_len stores the length of the retrieved binary data.
  • ares_dns_rr_get_class, ares_dns_rr_get_name, ares_dns_rr_get_ttl, and ares_dns_rr_get_type retrieve metadata about the resource record.

The ares_dns_rr_set_opt(3) function is used to set option/parameter keys and values for the resource record when the datatype is ARES_DATATYPE_OPT. The resource record to be modified is provided in the dns_rr parameter. They key/parameter is provided in the key parameter. The option/parameter value specific to the resource record is provided in the opt parameter, and this is left to the user to determine the appropriate value to use. Some known values may be provided by ares_svcb_param_t and ares_opt_param_t enumerations. The value for the option is always provided in binary form in val with length provided in val_len.

The ares_dns_rr_del_opt_byid(3) function is used to delete option/parameter keys and values for the resource record when the datatype is ARES_DATATYPE_OPT. The resource record to be modified is provided in the dns_rr parameter. They key/parameter is provided in the key parameter. The option/parameter value specific to the resource record is provided in the opt parameter. This function returns ARES_SUCCESS if the record is successfully removed, or ARES_ENOTFOUND if the record could not be found.

The ares_dns_rr_get_addr(3) function is used to retrieve the IPv4 address from the resource record when the datatype is ARES_DATATYPE_INADDR. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_addr6(3) function is used to retrieve the IPv6 address from the resource record when the datatype is ARES_DATATYPE_INADDR6. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_str(3) function is used to retrieve a string from the resource record when the datatype is ARES_DATATYPE_STR or ARES_DATATYPE_NAME. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u8(3) function is used to retrieve an 8bit integer from the resource record when the datatype is ARES_DATATYPE_U8. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u16(3) function is used to retrieve a 16bit integer from the resource record when the datatype is ARES_DATATYPE_U16. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u32(3) function is used to retrieve a 32bit integer from the resource record when the datatype is ARES_DATATYPE_U32. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_bin(3) function is used to retrieve binary data from the resource record when the datatype is ARES_DATATYPE_BIN or ARES_DATATYPE_BINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, and length is stored into the variable pointed to by len.

The ares_dns_rr_get_abin_cnt(3) function is used to retrieve the count of the array of stored binary values from the resource record when the datatype is ARES_DATATYPE_ABINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_abin(3) function is used to retrieve binary data from the resource record array when the datatype is ARES_DATATYPE_ABINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, and the index to retrieve from the array is provided by the idx parameter, and length is stored into the variable pointed to by len.

The ares_dns_rr_get_opt_cnt(3) function is used to retrieve the count of options/parameters associated with the resource record when the datatype is ARES_DATATYPE_OPT. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key.

The ares_dns_rr_get_opt(3) function is used to retrieve binary option data from the resource record when the datatype is ARES_DATATYPE_OPT for the specified index. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, the index to retrieve the option data from is provided in the idx parameter. The value is stored into the variable pointed to by val and length is stored into the variable pointed to by val_len.

The ares_dns_rr_get_opt_byid(3) function is used to retrieve binary option data from the resource record when the datatype is ARES_DATATYPE_OPT for the specified option identifier, if it exists. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, the identifier to retrieve the option data from is provided in the opt parameter. The value is stored into the variable pointed to by val and length is stored into the variable pointed to by val_len.

RETURN VALUES

ares_dns_record_rr_cnt and ares_dns_rr_get_opt_cnt return the respective counts.

ares_dns_record_rr_add, ares_dns_record_rr_del, ares_dns_rr_set_addr, ares_dns_rr_set_addr6, ares_dns_rr_set_str, ares_dns_rr_set_u8, ares_dns_rr_set_u16, ares_dns_rr_set_u32, ares_dns_rr_set_bin, ares_dns_rr_add_abin, ares_dns_rr_del_abin, and ares_dns_rr_set_opt all return an ares_status_t error code. ARES_SUCCESS is returned on success, ARES_ENOMEM is returned on out of memory, ARES_EFORMERR is returned on misuse.

ares_dns_rr_get_name, ares_dns_rr_get_type, ares_dns_rr_get_class, ares_dns_rr_get_ttl, ares_dns_rr_get_addr, ares_dns_rr_get_addr6, ares_dns_rr_get_str, ares_dns_rr_get_u8, ares_dns_rr_get_u16, ares_dns_rr_get_u32, ares_dns_rr_get_bin, ares_dns_rr_get_abin_cnt, ares_dns_rr_get_abin, ares_dns_rr_get_opt all return their prescribed datatype values and in general can't fail except for misuse cases, in which a 0 (or NULL) may be returned, however 0 can also be a valid return value for most of these functions.

ares_dns_record_rr_get and ares_dns_record_rr_get_const will return the requested resource record pointer or NULL on failure (misuse).

ares_dns_rr_get_opt_byid will return ARES_TRUE if the option was found, otherwise ARES_FALSE if not found (or misuse).

AVAILABILITY

These functions were first introduced in c-ares version 1.22.0.
