NOM

ares_set_local_ip4 - Définit l'adresse IP locale pour les requêtes sortantes.

SYNTAXE

#include <ares.h>
void ares_set_local_ip4(ares_channel_t *channel, unsigned int local_ip)

DESCRIPTION

La fonction ares_set_local_ip4 définit l'adresse IP pour les requêtes sortantes. Le paramètre local_ip est spécifié en ordre d'octet hôte. Cela permet aux utilisateurs de spécifier les interfaces sortantes lorsqu'elles sont utilisées sur des systèmes multi-homed.

VOIR AUSSI

ares_set_local_ip6(3)

NOTES

Cette fonction a été ajoutée dans c-ares 1.7.4
