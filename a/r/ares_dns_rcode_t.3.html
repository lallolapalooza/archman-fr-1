ENUMERATIONS

ares_dns_rec_type_t - Types d'enregistrement DNS gérés par c-ares. Certains types d'enregistrement peuvent être valides uniquement sur les requêtes, et d'autres uniquement sur les réponses :

ARES_REC_TYPE_A - Adresse hôte
ARES_REC_TYPE_NS - Serveur faisant autorité
ARES_REC_TYPE_CNAME - Nom canonique
ARES_REC_TYPE_SOA - Début de la zone d'autorité
ARES_REC_TYPE_PTR - Pointeur de nom d'hôte
ARES_REC_TYPE_HINFO - Informations sur l'hôte
ARES_REC_TYPE_MX - Informations de routage du courrier
ARES_REC_TYPE_TXT - Chaînes de texte
ARES_REC_TYPE_SIG - RFC 2535. RFC 2931. Enregistrement SIG
ARES_REC_TYPE_AAAA - RFC 3596. Adresse Ip6
ARES_REC_TYPE_SRV - RFC 2782. Sélection de serveur
ARES_REC_TYPE_NAPTR - RFC 3403. Pointeur d'autorité de nommage
ARES_REC_TYPE_OPT - RFC 6891. Option EDNS0 (méta-RR). Enregistrement pseudo.
ARES_REC_TYPE_TLSA - RFC 6698. Authentification basée sur DNS des entités nommées (DANE) Protocole de sécurité de la couche de transport (TLS) : TLSA
ARES_REC_TYPE_SVCB - RFC 9460. Liaison de service à usage général
ARES_REC_TYPE_HTTPS - - RFC 9460. Type de liaison de service à utiliser avec HTTPS
ARES_REC_TYPE_ANY - Correspondance générique. RR de réponse non valide
ARES_REC_TYPE_URI - RFC 7553. Identificateur de ressource uniforme
ARES_REC_TYPE_CAA - RFC 6844. Autorisation de l'autorité de certification
ARES_REC_TYPE_RAW_RR - Utilisé comme indicateur que l'enregistrement RR n'est pas analysé, mais fourni au format binaire

ares_dns_class_t - Classes DNS pour les requêtes et les réponses :

ARES_CLASS_IN - Internet
ARES_CLASS_CHAOS - CHAOS
ARES_CLASS_HESOID - Hesoid [Dyer 87]
ARES_CLASS_NONE - RFC 2136
ARES_CLASS_ANY - Classe quelconque (requêtes uniquement)

ares_dns_opcode_t - Codes d'opération d'en-tête DNS :

ARES_OPCODE_QUERY - Requête standard
ARES_OPCODE_IQUERY - Requête inverse. Obsolète
ARES_OPCODE_STATUS - Requête d'état du serveur de noms
ARES_OPCODE_NOTIFY - Notification de changement de zone (RFC 1996)
ARES_OPCODE_UPDATE - Message de mise à jour de zone (RFC 2136)

ares_dns_flags_t - Indicateurs d'en-tête DNS :

ARES_FLAG_QR - QR. Si défini, c'est une réponse
ARES_FLAG_AA - Réponse faisant autorité. Si défini, est faisant autorité
ARES_FLAG_TC - Troncature. Si défini, est une réponse tronquée
ARES_FLAG_RD - Récursion souhaitée. Si défini, la récursion est souhaitée
ARES_FLAG_RA - Récursion disponible. Si défini, le serveur prend en charge la récursion
ARES_FLAG_AD - RFC 2065. Le bit Authentic Data indique dans une réponse que les données incluses ont été vérifiées par le serveur qui les fournit
ARES_FLAG_CD - RFC 2065. Le bit Checking Disabled indique dans une requête que les données non vérifiées sont acceptables pour le résolveur envoyant la requête

ares_dns_rcode_t - Codes de réponse DNS du serveur :

ARES_RCODE_NOERROR - Succès
ARES_RCODE_FORMERR - Erreur de format. Le serveur de noms n'a pas pu interpréter la requête
ARES_RCODE_SERVFAIL - Échec du serveur. Le serveur de noms n'a pas pu traiter cette requête en raison d'un problème avec le serveur de noms
ARES_RCODE_NXDOMAIN - Erreur de nom. Significatif uniquement pour les réponses d'un serveur de noms faisant autorité, ce code signifie que le nom de domaine référencé dans la requête n'existe pas.
ARES_RCODE_NOTIMP - Non implémenté. Le serveur de noms ne prend pas en charge le type de requête demandé
ARES_RCODE_REFUSED - Refusé. Le serveur de noms refuse d'effectuer l'opération spécifiée pour des raisons de politique.
ARES_RCODE_YXDOMAIN - RFC 2136. Un nom qui ne devrait pas exister existe
ARES_RCODE_YXRRSET - RFC 2136. Un RRset qui ne devrait pas exister existe
ARES_RCODE_NXRRSET - RFC 2136. Un RRset qui devrait exister, n'existe pas
ARES_RCODE_NOTAUTH - RFC 2136. Le serveur ne fait pas autorité pour la zone nommée dans la section Zone.
ARES_RCODE_NOTZONE - RFC 2136. Un nom utilisé dans la section Prérequis ou Mise à jour n'est pas dans la zone désignée par la section Zone.
ARES_RCODE_DSOTYPEI - RFC 8409. DSO-TYPE Non implémenté
ARES_RCODE_BADSIG - RFC 8945. Échec de la signature TSIG
ARES_RCODE_BADKEY - RFC 8945. Clé non reconnue
ARES_RCODE_BADTIME - RFC 8945. Signature hors de la fenêtre temporelle
ARES_RCODE_BADMODE - RFC 2930. Mauvais mode TKEY
ARES_RCODE_BADNAME - RFC 2930. Nom de clé dupliqué
ARES_RCODE_BADALG - RFC 2930. Algorithme non pris en charge
ARES_RCODE_BADTRUNC - RFC 8945. Mauvaise troncature
ARES_RCODE_BADCOOKIE - RFC 7973. Cookie serveur invalide/manquant

ares_dns_parse_flags_t - Indicateurs pour modifier le comportement d'ares_dns_parse(3) :

ARES_DNS_PARSE_AN_BASE_RAW - Analyse de la section Réponse de RFC 1035 qui permet la compression de noms en tant que type RR BRUT
ARES_DNS_PARSE_NS_BASE_RAW - Analyse de la section Autorité de RFC 1035 qui permet la compression de noms en tant que type RR BRUT
ARES_DNS_PARSE_AR_BASE_RAW - Analyse de la section Supplémentaire de RFC 1035 qui permet la compression de noms en tant que type RR BRUT
ARES_DNS_PARSE_AN_EXT_RAW - Analyse de la section Réponse des RFC ultérieures (pas de compression de noms) en tant que type RR BRUT
ARES_DNS_PARSE_NS_EXT_RAW - Analyse de la section Autorité des RFC ultérieures (pas de compression de noms) en tant que type RR BRUT
ARES_DNS_PARSE_AR_EXT_RAW - Analyse de la section Supplémentaire des RFC ultérieures (pas de compression de noms) en tant que type RR BRUT

DESCRIPTION

La fonction ares_dns_record_destroy(3) détruit la mémoire associée à l'enregistrement DNS créé soit par ares_dns_record_create(3), soit par ares_dns_parse(3) passé via dnsrec.

La fonction ares_dns_parse(3) analyse le tampon fourni dans buf avec la longueur fournie dans buf_len. Le paramètre flags peut être une ou plusieurs valeurs de ares_dns_parse_flags_t, ou zéro si aucun indicateur n'est nécessaire. La structure de données d'enregistrement DNS résultante

est stocké dans la variable pointée par dnsrec et doit être détruit à l'aide de ares_dns_record_de

stroy(3).

La fonction ares_dns_write(3) prend une structure d'enregistrement DNS remplie dans dnsrec et écrit un message DNS au format d'octets dans la variable pointée par buf et écrit la longueur du tampon dans la variable pointée par buf_len. Le tampon doit être détruit à l'aide de ares_free_str

ing(3).

La fonction ares_dns_record_create(3) crée une structure d'enregistrement DNS vide dans la variable pointée par dnsrec. Le paramètre id est l'identifiant du message DNS, cependant, si vous le transmettez à ares_send(3), cet identifiant sera écrasé, il doit donc généralement être 0. Le paramètre flags est un ou plusieurs ares_dns_flags_t. L'opcode est transmis dans le paramètre opcode et devrait généralement être ARES_OPCODE_QUERY. Le code de réponse est principalement destiné aux réponses et est transmis dans le paramètre rcode et est généralement ARES_RCODE_NOERROR

.

La fonction ares_dns_record_duplicate(3) duplique une structure d'enregistrement DNS existante. Cela peut être utile si vous devez enregistrer un résultat tel que récupéré à partir de ares_send_dnsrec(3) ou ares_search_dnsrec(3). La structure à dupliquer est transmise dans le paramètre dnsrec, et la copie dupliquée est retournée, ou NULL en cas d'erreur, par exemple en cas de manque de

mémoire.

La fonction ares_dns_record_get_id(3) est utilisée pour récupérer l'identifiant du message DNS à partir de l'enregistrement DNS fourni dans le paramètre d

nsrec.

La fonction ares_dns_record_set_id(3) est utilisée pour définir l'identifiant du message DNS dans le paramètre id à partir de l'enregistrement DNS fourni dans le paramètre dnsrec. Cet identifiant sera écrasé lorsque l'enregistrement sera transmis à c-ares, il existe donc principalement à des fins

externes.

La fonction ares_dns_record_get_flags(3) est utilisée pour récupérer les drapeaux du message DNS à partir de l'enregistrement DNS fourni dans le paramètre d

nsrec.

La fonction ares_dns_record_get_opcode(3) est utilisée pour récupérer les drapeaux du message DNS à partir de l'enregistrement DNS fourni dans le paramètre d

nsrec.

La fonction ares_dns_record_get_rcode(3) est utilisée pour récupérer le code de réponse du message DNS à partir de l'enregistrement DNS fourni dans le paramètre d

nsrec.

La fonction ares_dns_record_query_add(3) est utilisée pour ajouter une question à l'enregistrement DNS fourni dans le paramètre dnsrec. Le nom de domaine spécifié pour la question est fourni dans le paramètre name, ainsi que le type de question dans le paramètre qtype et la classe de question (généralement ARES_CLASS_IN) dans le paramètre q

class.

La fonction ares_dns_record_query_set_name(3) est utilisée pour modifier le nom de la question dans l'enregistrement DNS fourni dans le paramètre dnsrec. L'index de la requête, qui doit être inférieur à ares_dns_record_query_cnt(3), est fourni dans le paramètre idx. Le nouveau nom de domaine est fourni dans le paramètre name. Une attention particulière doit être portée car cela invalidera tout pointeur name récupéré à partir de ares_dns_Record_query_get(3). Cette fonction est utile si vous envoyez plusieurs requêtes similaires sans recréer l'intégralité de la requête

DNS.

La fonction ares_dns_record_query_set_type(3) est utilisée pour modifier le type de la question dans l'enregistrement DNS fourni dans le paramètre dnsrec. L'index de la requête, qui doit être inférieur à ares_dns_record_query_cnt(3), est fourni dans le paramètre idx. Le nouveau type de requête est fourni dans le paramètre q

type.

La fonction ares_dns_record_query_cnt(3) est utilisée pour récupérer le nombre de questions DNS dans l'enregistrement DNS fourni dans le paramètre d

nsrec.

La fonction ares_dns_record_query_get(3) est utilisée pour récupérer les détails d'une seule question DNS dans le paramètre dnsrec fourni. L'index fourni dans le paramètre idx doit être inférieur à la valeur retournée par ares_dns_record_query_cnt(3). Le nom de la question DNS sera retourné dans la variable pointée par le paramètre name, celui-ci peut être NULL si le nom n'est pas nécessaire. Ce pointeur sera invalidé par tout appel à ares_dns_record_query_set_name(3). Le type de la question DNS sera retourné dans la variable pointée par le paramètre qtype, celui-ci peut être NULL si le type n'est pas nécessaire. La classe de la question DNS sera retournée dans la variable pointée par le paramètre qclass, celui-ci peut être

NULL si la classe n'est pas nécessaire.

VALEURS DE

RETOUR

ares_dns_parse(3), ares_dns_write(3), ares_dns_record_create(3), ares_dns_record_query_add(3) et ares_dns_record_query_get(3) retournent tous un code d'erreur ares_status_t. ARES_SUCCESS est retourné en cas de succès, ARES_ENOMEM est retourné en cas de manque de mémoire, ARES_EFORMERR est retourné en cas d'utilisation

incorrecte.

ares_dns_record_get_id(3), ares_dns_record_set_id(3), ares_dns_record_get_flags(3), ares_dns_record_get_opcode(3), ares_dns_record_get_rcode(3) et ares_dns_record_query_cnt(3) retournent tous leurs valeurs de type de données prescrites et en général ne peuvent pas échouer, sauf en cas d'ut

ilisation incorrecte, où un 0 peut être retourné, cependant 0 peut au
ssi être une valeur de retour valide pour la plupart de ces fonctions.
