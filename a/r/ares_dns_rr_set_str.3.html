DESCRIPTION

La fonction ares_dns_record_rr_cnt(3) retourne le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section fournie dans le paramètre sect.

La fonction ares_dns_record_rr_add(3) ajoute une nouvelle entrée d'enregistrement de ressource à l'enregistrement DNS fourni par le paramètre dnsrec. L'enregistrement de ressource résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle appartient l'enregistrement de ressource est spécifiée par le paramètre sect. Le nom de domaine associé à l'enregistrement de ressource est spécifié par le paramètre name, qui ne peut pas être NULL mais peut être une chaîne vide ou ".". Le type d'enregistrement de ressource est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le temps de vie (TTL) dans le paramètre ttl.

Les fonctions ares_dns_record_rr_get(3) et ares_dns_record_rr_get_const(3) sont utilisées pour récupérer le pointeur de l'enregistrement de ressource à partir de l'enregistrement DNS fourni dans le paramètre dnsrec, pour la section d'enregistrements de ressources fournie dans le paramètre sect, pour l'index spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_rr_cnt(3). La première retourne un pointeur modifiable vers l'enregistrement de ressource, tandis que la seconde retourne un pointeur en lecture seule vers l'enregistrement de ressource.

La fonction ares_dns_record_rr_del(3) est utilisée pour supprimer un enregistrement de ressource de l'enregistrement DNS spécifié dans le paramètre dnsrec. Son utilisation principale est de supprimer un enregistrement ARES_REC_TYPE_OPT lors de la nécessité de réessayer une requête sans support EDNS. La section RR DNS est spécifiée via le paramètre sect, et l'index à supprimer est spécifié dans le paramètre idx. L'index doit être inférieur à ares_dns_record_rr_cnt(3).

La fonction ares_dns_rr_get_name(3) est utilisée pour récupérer le nom de domaine de l'enregistrement de ressource à partir du pointeur d'enregistrement de ressource fourni dans le paramètre rr.

La fonction ares_dns_rr_get_type(3) est utilisée pour récupérer le type d'enregistrement de ressource à partir du pointeur d'enregistrement de ressource fourni dans le paramètre rr.

La fonction ares_dns_rr_get_class(3) est utilisée pour récupérer la classe d'enregistrement de ressource à partir du pointeur d'enregistrement de ressource fourni dans le paramètre rr.

La fonction ares_dns_rr_get_ttl(3) est utilisée pour récupérer le Temps de vie (TTL) de l'enregistrement de ressource à partir du pointeur d'enregistrement de ressource fourni dans le paramètre rr.

La fonction ares_dns_rr_set_addr(3) est utilisée pour définir une adresse IPv4 pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_INADDR. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre addr.

La fonction ares_dns_rr_set_addr6(3) est utilisée pour définir une adresse IPv6 pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_INADDR6. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fourni dans le paramètre key, et la valeur est fournie dans le paramètre addr.

La fonction ares_dns_rr_set_str(3) est utilisée pour définir une chaîne pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_STR ou ARES_DATATYPE_NAME. La plupart des chaînes sont limitées à 255 octets, cependant certains enregistrements, tels qu'un enregistrement TXT, peuvent autoriser une taille plus importante car ils sont renvoyés sous forme de chaînes multiples. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val.

La fonction ares_dns_rr_set_u8(3) est utilisée pour définir une valeur non signée de 8 bits pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_U8. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val.

La fonction ares_dns_rr_set_u16(3) est utilisée pour définir une valeur non signée de 16 bits pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_U16. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val.

La fonction ares_dns_rr_set_u32(3) est utilisée pour définir une valeur non signée de 32 bits pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_U32. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val.

La fonction ares_dns_rr_set_bin(3) est utilisée pour définir une valeur binaire pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_BIN ou ARES_DATATYPE_BINP. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val. Et la longueur de valeur associée est fournie dans le paramètre len.

La fonction ares_dns_rr_add_abin(3) est utilisée pour ajouter une valeur binaire dans le tableau pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val. Et la longueur de valeur associée est fournie dans le paramètre len.

La fonction ares_dns_rr_del_abin(3) est utilisée pour supprimer une valeur binaire dans le tableau pour la clé/paramètre d'enregistrement de ressource associé lorsque le type de données est ARES_DATATYPE_ABINP. L'enregistrement de ressource à modifier est fourni dans le paramètre dns_rr, la clé/paramètre est fournie dans le paramètre key, et la valeur est fournie dans le paramètre val. Et la longueur de valeur associée est fournie dans le paramètre len.

SYNOPSIS

Add a resource record to a DNS record.
ares_dns_record_rr_add(ares_dns_record_t *dns_record, ares_dns_record_rr_t *rr);

Get the count of resource records in a DNS record.
ares_dns_record_rr_cnt(const ares_dns_record_t *dns_record);

Delete a resource record from a DNS record.
ares_dns_record_rr_del(ares_dns_record_t *dns_record, ares_dns_record_rr_t *rr);

Get a resource record from a DNS record.
ares_dns_record_rr_get(ares_dns_record_t *dns_record, size_t idx);

ENUMERATIONS

The key parameter for all functions is typically an integer identifier defined by the specific datatype. For example, for ARES_DATATYPE_INADDR, the key is ARES_ADDR_IPv4. For ARES_DATATYPE_INADDR6, the key is ARES_ADDR_IPv6. For ARES_DATATYPE_OPT, the key can be ARES_OPT_SVCI, ARES_OPT_ECH, etc.

The opt parameter for functions that set options is specific to the option being set. For example, for ARES_OPT_SVCI, the value can be a string representing the service name.

The opt_id parameter for functions that deal with option data is the numerical identifier for the option, as defined by the DNS protocol (e.g., for SVCB/HTTPS records).

DESCRIPTION

These functions provide a programmatic interface to manipulate DNS resource records (RRs) within a DNS message structure. They allow for the creation, modification, retrieval, and deletion of various types of DNS records and their associated data.

The core structure for a DNS record is ares_dns_record_rr_t. A collection of these RRs is managed by ares_dns_record_t.

The ares_dns_record_rr_add(3) function adds an existing resource record structure (rr) to a DNS record structure (dns_record).

The ares_dns_record_rr_cnt(3) function returns the number of resource records currently stored within the dns_record structure.

The ares_dns_record_rr_del(3) function removes a specific resource record structure (rr) from the dns_record structure.

The ares_dns_record_rr_get(3) and ares_dns_record_rr_get_const(3) functions retrieve a pointer to the resource record at the specified index idx within the dns_record structure.

The ares_dns_rr_add_abin(3) function adds an array of binary data to a resource record. The resource record to modify is provided in dns_rr, the binary data is provided in val, and its length in val_len.

The ares_dns_rr_del_abin(3) function deletes an array of binary data from a resource record. The resource record to modify is provided in dns_rr, and the index of the array to delete is provided in idx.

The ares_dns_rr_del_opt_byid(3) function deletes option data from a resource record based on its identifier. The resource record is provided in dns_rr, and the option identifier is provided in opt_id.

The ares_dns_rr_get_addr(3) and ares_dns_rr_get_addr6(3) functions are used to retrieve IPv4 and IPv6 addresses, respectively, from a resource record. The resource record is provided in dns_rr and the key identifying the address type is provided in key.

The ares_dns_rr_get_str(3) function retrieves a string value from a resource record. The resource record is provided in dns_rr and the key identifying the string type is provided in key.

The ares_dns_rr_get_u8(3), ares_dns_rr_get_u16(3), and ares_dns_rr_get_u32(3) functions retrieve 8-bit, 16-bit, and 32-bit unsigned integer values, respectively, from a resource record. The resource record is provided in dns_rr and the key identifying the integer type is provided in key.

The ares_dns_rr_get_bin(3) function retrieves raw binary data from a resource record. The resource record is provided in dns_rr, the key identifying the data is provided in key, and the length of the retrieved data is stored in the variable pointed to by len.

The ares_dns_rr_get_abin_cnt(3) function retrieves the count of binary data arrays stored within a resource record. The resource record is provided in dns_rr and the key identifying the data is provided in key.

The ares_dns_rr_get_abin(3) function retrieves a specific binary data array from a resource record. The resource record is provided in dns_rr, the key identifying the data is provided in key, the index of the array to retrieve is provided in idx, and the length of the retrieved data is stored in the variable pointed to by len.

The ares_dns_rr_get_opt_cnt(3) function retrieves the count of option data entries within a resource record. The resource record is provided in dns_rr and the key identifying the option data is provided in key.

The ares_dns_rr_get_opt(3) function retrieves binary option data from a resource record by its index. The resource record is provided in dns_rr, the key identifying the option data is provided in key, the index of the option data to retrieve is provided in idx. The retrieved data is stored in the variable pointed to by val, and its length is stored in the variable pointed to by val_len.

The ares_dns_rr_get_opt_byid(3) function retrieves binary option data from a resource record by its identifier. The resource record is provided in dns_rr, the key identifying the option data is provided in key, the identifier of the option data to retrieve is provided in opt_id. The retrieved data is stored in the variable pointed to by val, and its length is stored in the variable pointed to by val_len.

The setter functions (e.g., ares_dns_rr_set_addr(3), ares_dns_rr_set_str(3), etc.) are used to set specific data fields within a resource record. The resource record to be modified is provided in dns_rr. The key identifying the field to set is provided in key, and the value to set is provided in the corresponding value parameter (e.g., addr, val).

The ares_dns_rr_set_opt(3) function is used to set option/parameter keys and values for the resource record when the datatype is ARES_DATATYPE_OPT. The resource record to be modified is provided in the dns_rr parameter. The key/parameter is provided in the key parameter. The option/parameter value specific to the resource record is provided in the opt parameter, and this is left to the user to determine the appropriate value to use. Some known values may be provided by ares_svcb_param_t and ares_opt_param_t enumerations. The value for the option is always provided in binary form in val with length provided in val_len.

The ares_dns_rr_del_opt_byid(3) function is used to delete option/parameter keys and values for the resource record when the datatype is ARES_DATATYPE_OPT. The resource record to be modified is provided in the dns_rr parameter. They key/parameter is provided in the key parameter. The option/parameter value specific to the resource record is provided in the opt parameter. This function returns ARES_SUCCESS if the record is successfully removed, or ARES_ENOTFOUND if the record could not be found.

The ares_dns_rr_get_addr(3) function is used to retrieve the IPv4 address from the resource record when the datatype is ARES_DATATYPE_INADDR. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_addr6(3) function is used to retrieve the IPv6 address from the resource record when the datatype is ARES_DATATYPE_INADDR6. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_str(3) function is used to retrieve a string from the resource record when the datatype is ARES_DATATYPE_STR or ARES_DATATYPE_NAME. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u8(3) function is used to retrieve an 8bit integer from the resource record when the datatype is ARES_DATATYPE_U8. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u16(3) function is used to retrieve a 16bit integer from the resource record when the datatype is ARES_DATATYPE_U16. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u32(3) function is used to retrieve a 32bit integer from the resource record when the datatype is ARES_DATATYPE_U32. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_bin(3) function is used to retrieve binary data from the resource record when the datatype is ARES_DATATYPE_BIN or ARES_DATATYPE_BINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, and length is stored into the variable pointed to by len.

The ares_dns_rr_get_abin_cnt(3) function is used to retrieve the count of the array of stored binary values from the resource record when the datatype is ARES_DATATYPE_ABINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_abin(3) function is used to retrieve binary data from the resource record array when the datatype is ARES_DATATYPE_ABINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, and the index to retrieve from the array is provided by the idx parameter, and length is stored into the variable pointed to by len.

The ares_dns_rr_get_opt_cnt(3) function is used to retrieve the count of options/parameters associated with the resource record when the datatype is ARES_DATATYPE_OPT. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key.

The ares_dns_rr_get_opt(3) function is used to retrieve binary option data from the resource record when the datatype is ARES_DATATYPE_OPT for the specified index. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, the index to retrieve the option data from is provided in the idx parameter. The value is stored into the variable pointed to by val and length is stored into the variable pointed to by val_len.

The ares_dns_rr_get_opt_byid(3) function is used to retrieve binary option data from the resource record when the datatype is ARES_DATATYPE_OPT for the specified option identifier, if it exists. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, the identifier to retrieve the option data from is provided in the opt parameter. The value is stored into the variable pointed to by val and length is stored into the variable pointed to by val_len.

RETURN VALUES

ares_dns_record_rr_cnt(3) and ares_dns_rr_get_opt_cnt(3) return the respective counts.

ares_dns_record_rr_add(3), ares_dns_record_rr_del(3), ares_dns_rr_set_addr(3), ares_dns_rr_set_addr6(3), ares_dns_rr_set_str(3), ares_dns_rr_set_u8(3), ares_dns_rr_set_u16(3), ares_dns_rr_set_u32(3), ares_dns_rr_set_bin(3), ares_dns_rr_add_abin(3), ares_dns_rr_del_abin(3), and ares_dns_rr_set_opt(3) all return an ares_status_t error code. ARES_SUCCESS is returned on success, ARES_ENOMEM is returned on out of memory, ARES_EFORMERR is returned on misuse.

ares_dns_rr_get_name(3), ares_dns_rr_get_type(3), ares_dns_rr_get_class(3), ares_dns_rr_get_ttl(3), ares_dns_rr_get_addr(3), ares_dns_rr_get_addr6(3), ares_dns_rr_get_str(3), ares_dns_rr_get_u8(3), ares_dns_rr_get_u16(3), ares_dns_rr_get_u32(3), ares_dns_rr_get_bin(3), ares_dns_rr_get_abin_cnt(3), ares_dns_rr_get_abin(3), ares_dns_rr_get_opt(3) all return their prescribed datatype values and in general can't fail except for misuse cases, in which a 0 (or NULL) may be returned, however 0 can also be a valid return value for most of these functions.

ares_dns_record_rr_get(3) and ares_dns_record_rr_get_const(3) will return the requested resource record pointer or NULL on failure (misuse).

ares_dns_rr_get_opt_byid(3) will return ARES_TRUE if the option was found, otherwise ARES_FALSE if not found (or misuse).

AVAILABILITY

These functions were first introduced in c-ares version 1.22.0.
