NOM

axohelp - programme d'aide pour l'utilisation du paquet LaTeX axohelp2 avec pdflatex.

SYNOPSIS

axohelp [options] [nom_fichier]

DESCRIPTION

Axohelp est un programme utilisé avec axodraw2, qui est un paquet LaTeX pour dessiner des graphes de Feynman (et d'autres graphiques simples) dans des documents LaTeX.

Lorsque le paquet axodraw2 est utilisé avec pdflatex (ou lualatex ou xelatex), il crée un fichier avec l'extension .ax1. Celui-ci contient les spécifications des éléments graphiques. Axohelp convertit ce fichier en un fichier avec l'extension ax2 qui contient le code pdf nécessaire. Le fichier .ax2 est lu par pdflatex (etc.) lors de son exécution suivante, et le contenu du fichier .ax2 est utilisé dans le fichier de sortie .pdf final pour dessiner les graphiques souhaités.

Les fichiers traités sont spécifiés comme suit : Lorsque le nom de fichier sur la ligne de commande est de la forme fichier.ax1, le fichier d'entrée est fichier.ax1 et le fichier de sortie est fichier.ax2. Si le nom de fichier sur la ligne de commande n'a pas l'extension .ax1, cette extension est ajoutée.

OPTIONS

Les options peuvent être introduites par des tirets simples ou doubles. Les options possibles sont :

-h, --help
Donne des informations d'utilisation.
-v, --version
Donne des informations sur la version.
-V
NON IMPLEMENTÉ ACTUELLEMENT : Donne des informations sur chaque fonction utilisée.
