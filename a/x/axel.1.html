Axel est un programme qui télécharge un fichier depuis un serveur FTP ou HTTP via plusieurs connexions. Chaque Contrairement à la plupart des autres programmes, Axel télécharge toutes les données directement dans le fichier de destination. Cela fait gagner du temps à la fin car le programme n'a pas besoin de concaténer toutes Axel prend en charge les protocoles HTTP,
FTPS.

Plusieurs URL de miroirs vers un fichier identique peuvent également être spécifiées et le programme utilisera toutes ces URL pour le téléchargement.

axel(1) — Manuel Linux

NOM

axel — un programme de téléchargement multi-segments

SYNOPIS

axel [OPTIONS] URL...

DESCRIPTION

Axel est un accélérateur de téléchargement en ligne de commande. Il est conçu pour accélérer les téléchargements en téléchargeant un fichier en plusieurs segments simultanément. Il peut également reprendre les téléchargements interrompus. Axel est particulièrement utile lorsque votre connexion Internet est lente ou lorsque le serveur de téléchargement est lent.

OPTIONS

-n , --num-connections=
Spécifie le nombre de connexions simultanées à utiliser pour le téléchargement.
-o , --output=
Spécifie le nom du fichier de sortie.
-a, --alternate
Utilise un affichage alternatif de la progression du téléchargement.
-h, --help
Affiche l'aide et quitte.
-v, --version
Affiche la version et quitte.
-q, --quiet
Mode silencieux, n'affiche pas la progression.
-s , --max-speed=
Définit la vitesse maximale de chaque connexion.
-U , --user-agent=
Définit la chaîne User-Agent.
-S, --secure-to-insecure
Utilise une connexion non sécurisée pour une URL sécurisée.
-k, --keep-session
Conserve la session de téléchargement.
-x, --max-redirect
Définit le nombre maximum de redirections.
-T , --timeout=
Définit le temps de timeout pour la connexion.
-e , --proxy=
Spécifie le proxy à utiliser.
-f , --file=
Télécharge les URLs d'un fichier.

NOTE

Axel est un outil puissant pour accélérer les téléchargements. Cependant, une utilisation excessive du nombre de connexions peut surcharger le serveur et entraîner son blocage.

VALEUR DE RETOUR

Axel renvoie 0 en cas de succès, et une valeur non nulle en cas d'erreur.

EXEMPLES

Télécharger un fichier avec 4 connexions simultanées et spécifier le nom du fichier de sortie :

axel -n 4 -o mon_fichier.zip http://exemple.com/mon_fichier.zip

Télécharger des fichiers à partir d'une liste dans un fichier :

axel -f liste_urls.txt

FICHIERS

~/.axelrc : Fichier de configuration par défaut pour Axel.
