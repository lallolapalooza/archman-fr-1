AXFER-LIST(1) Manuel des commandes générales AXFER-LIST(1)

NOM

axfer-list - exporter les listes de périphériques sonores et de nœuds disponibles pour le transfert de trames de données audio.

SYNTAXE

axfer list direction cible

direction = capture | lecture

cible = device | pcm

DESCRIPTION

La sous-commande list de axfer exporte les listes de nœuds disponibles pour le transfert de trames de données audio. Pour l'instant, la sous-commande est utile uniquement pour le backend libasound de la sous-commande transfer.

OPTIONS

Direction

capture
Fonctionne pour la transmission de capture.
lecture
Fonctionne pour la transmission de lecture.

Cible

device
Exporte une liste de toutes les cartes son et de tous les périphériques audio numériques disponibles dans le backend libasound pour la sous-commande transfer.
pcm
Exporte une liste de tous les nœuds PCM disponibles dans l'espace de configuration alsa-lib dans le backend libasound pour la sous-commande transfer.

COMPATIBILITÉ AVEC APLAY

Les options -l et --list-devices sont traitées comme une opération device. Les options -L et --list-pcms sont traitées comme une opération pcm.

VOIR AUSSI

axfer(1), axfer-transfer(1), alsamixer(1), amixer(1)
