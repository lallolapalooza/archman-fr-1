AFINITFILEFORMAT(3)   AFINITFILEFORMAT(3)

NOM

afInitFileFormat - initialiser le format de fichier d'une configuration de fichier audio

SYNTAXE

#include <audiofile.h>
void afInitFileFormat(AFfilesetup setup, int fileFormat);

PARAMETRES

setup est une configuration de fichier valide créée par afNewFileSetup(3).

fileFormat est une constante entière spécifiant un format de fichier.

DESCRIPTION

Étant donné une structure AFfilesetup créée avec afNewFileSetup(3), afInitFileFormat initialise le format de fichier au format spécifié par fileFormat.

Les formats de fichier suivants sont actuellement pris en charge :

AF_FILE_RAWDATA

données audio brutes

AF_FILE_AIFF

Audio Interchange File Format

AF_FILE_AIFFC

Audio Interchange File Format AIFF-C

AF_FILE_NEXTSND

NeXT .snd/Sun .au

AF_FILE_WAVE

Microsoft RIFF WAVE

AF_FILE_BICSF

Berkeley/IRCAM/CARL Sound File

AF_FILE_AVR

Audio Visual Research

AF_FILE_IFF_8SVX

Amiga IFF/8SVX

AF_FILE_SAMPLEVISION

Sample Vision

AF_FILE_VOC

Creative Voice File

AF_FILE_NIST_SPHERE

NIST SPHERE

AF_FILE_CAF

Core Audio Format

ERREURS

afInitFileFormat peut produire les erreurs suivantes :

AF_BAD_FILESETUP

setup représente une configuration de fichier invalide.

AF_BAD_FILEFMT

fileFormat représente un format de fichier inconnu.

AF_BAD_NOT_IMPLEMENTED

fileFormat représente un format de fichier qui n'est pas actuellement implémenté.
