AFREADMISC(3)   AFREADMISC(3)

NOM

afReadMisc, afWriteMisc, afSeekMisc - accéder aux métadonnées diverses d'un fichier audio

SYNOPSIS

#include <audiofile.h>
int afReadMisc (AFfilehandle file, int miscid, void *buffer, int nbytes);
int afWriteMisc (AFfilehandle file, int miscid, const void *buffer, int nbytes);
int afSeekMisc (AFfilehandle file, int miscid, int offbytes);

DESCRIPTION

afReadMisc lit jusqu'à nbytes depuis le bloc de données divers identifié par miscid dans file.

afWriteMisc écrit jusqu'à nbytes dans le bloc de données divers identifié par miscid dans file.

afSeekMisc change l'offset courant dans le bloc de données divers identifié par miscid à l'offset offbytes.

VALEUR DE RETOUR

afReadMisc retourne le nombre d'octets lus depuis le bloc divers spécifié dans le tampon référencé par buffer.

afWriteMisc retourne le nombre d'octets écrits dans le bloc divers spécifié à partir du tampon référencé par buffer.

afSeekMisc retourne la nouvelle position du pointeur de données logique, mesurée comme un offset en octets depuis le début de la zone de données du bloc divers.

ERREURS

afReadMisc, afWriteMisc et afSeekMisc peuvent produire les codes d'erreur suivants :

• AF_BAD_READ
• AF_BAD_WRITE
• AF_BAD_MISCSEEK
• AF_BAD_MISCID
• AF_BAD_TRACKID
• AF_BAD_FILEHANDLE
