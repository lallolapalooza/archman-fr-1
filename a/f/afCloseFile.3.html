NOM

afCloseFile - ferme un fichier audio ouvert

SYNTAXE

#include <audiofile.h>
int afCloseFile(AFfilehandle file);

PARAMETRES

file est une poignée de fichier valide créée par afOpenFile(3).

DESCRIPTION

afCloseFile ferme le fichier audio file, mettant à jour le fichier s'il a été ouvert en écriture.

VALEUR DE RETOUR

afCloseFile retourne 0 si le fichier a été fermé correctement et -1 si une erreur s'est produite lors de la fermeture du fichier.

ERREURS

afCloseFile peut générer les erreurs possibles suivantes :

• AF_BAD_FILEHANDLE
• AF_BAD_LSEEK
• AF_BAD_WRITE
