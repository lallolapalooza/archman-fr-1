NOM

afew - Documentation afew

afew est un script de marquage initial pour notmuch mail :

  • http://notmuchmail.org/
  • http://notmuchmail.org/initial_tagging/

Sa tâche de base est de fournir un marquage automatique chaque fois que de nouveaux mails sont enregistrés avec notmuch. Dans une configuration classique, vous pourriez l'appeler après notmuch new dans un hook post-synchronisation d'offlineimap ou dans le hook post-new de notmuch.

Il peut effectuer des tâches de base telles que l'ajout de tags basés sur les en-têtes d'e-mails ou les dossiers maildir, la gestion des fils tués et du spam.

FYI : afew fonctionne bien avec alot, une interface graphique pour notmuch mail ;)

•
https://github.com/pazz/alot

DÉMARRAGE RAPIDE

Les étapes pour commencer sont :

  • installer le paquet afew
  • créer les fichiers de configuration
  • ajouter un hook post-new notmuch qui appelle afew

Installation

Les commandes suivantes vous permettront de démarrer sur les systèmes Debian/Ubuntu :

$ sudo aptitude install notmuch python-notmuch dbacl
$ git clone git://github.com/teythoon/afew.git
$ cd afew
$ python setup.py install --prefix=~/.local

Assurez-vous que ~/.local/bin est dans votre PATH. Une façon de faire est d'ajouter ce qui suit à votre ~/.bashrc :

if [ -d ~/.local/bin ]; then
    PATH=$PATH:~/.local/bin
fi

Voir INSTALLATION pour un guide plus détaillé.

Configuration Initiale

Assurez-vous que ~/.notmuch-config contient :

[new]
tags=new

Placez une liste de filtres dans ~/.config/afew/config :

# C'est la chaîne de filtres par défaut
[SpamFilter]
[KillThreadsFilter]
[ListMailsFilter]
[ArchiveSentMailsFilter]
[InboxFilter]

Et créez un hook post-new pour que notmuch appelle afew :

$ notmuchdir=chemin/vers/maildir/.notmuch
$ mkdir -p "$notmuchdir/hooks"
$ printf > "$notmuchdir/hooks/post-new" '#!/usr/bin/env sh
$HOME/.local/bin/afew --tag --new
$ chmod u+x "$notmuchdir/hooks/post-new"

Prochaines Étapes

Vous pouvez :

  • ajouter des Filtres supplémentaires pour un filtrage personnalisé
  • utiliser le Mode Déplacement pour déplacer vos e-mails entre les dossiers
  • exécuter afew sur tous vos anciens mails en lançant afew --tag --all
  • commencer à Étendre afew

INSTALLATION

Prérequis

afew fonctionne avec Python 3.6+, et nécessite notmuch ainsi que ses bindings Python. Sur les systèmes Debian/Ubuntu, vous pouvez les installer en faisant :

$ sudo aptitude install notmuch python-notmuch python-dev python-setuptools

Remarque : si vous installez notmuch avec Homebrew sur macOS, assurez-vous d'exécuter $ brew install --with-python3 notmuch, car la formule brew n'installe pas les bindings python3 de notmuch par défaut.

Installation non privilégiée

Il est recommandé d'installer afew lui-même dans un environnement virtuel en tant qu'utilisateur non privilégié, soit en téléchargeant le code source et en installant via setup.py, soit via pip.

# créer et activer un environnement virtuel
$ python -m venv --system-site-packages .venv
$ source .venv/bin/activate
# installer via pip depuis PyPI :
$ pip install afew
# ou installer depuis la source :
$ python setup.py install --prefix=~/.local

Vous voudrez peut-être créer un lien symbolique de .venv/bin/afew quelque part dans votre PATH (~/bin/ dans ce cas) :

$ ln -snr .venv/bin/afew ~/.bin/afew

Construction de la documentation

La documentation peut être construite dans divers formats en utilisant Sphinx :

# construire les docs dans build/sphinx/{html,man}
$ python setup.py build_sphinx -b html,man

UTILISATION DE LA LIGNE DE COMMANDE

Finalement, afew est un outil en ligne de commande. Vous devez spécifier une action, et s'il faut agir sur tous les messages, ou seulement sur les nouveaux messages. Les actions que vous pouvez choisir sont :

tag
exécute les filtres de tag. Voir Marquage initial.
watch
surveille en continu la boîte aux lettres pour les nouveaux fichiers
move-mails
déplace les fichiers d'e-mails entre les dossiers maildir

Marquage initial

Les tâches de marquage de base ne nécessitent aucune configuration, lancez simplement

$ afew --tag --new
# ou pour marquer *tous* les messages
$ afew --tag --all

Pour faire cela automatiquement, vous pouvez ajouter le hook suivant dans votre ~/.offlineimaprc :

postsynchook = ionice -c 3 chrt --idle 0 /bin/sh -c "notmuch new && afew --tag --new"

Il y a beaucoup plus à dire sur la Configuration générale des filtres et les différents Filtres fournis par afew.

Simulation

L'ajout de --dry-run à toute action --tag ou --sync-tags empêche la modification de la base de données notmuch. Ajoutez quelques options -vv pour voir une simulation.

Mode Déplacement

Pour invoquer afew en mode déplacement, fournissez l'option --move-mails en ligne de commande. Le mode déplacement respectera --dry-run, alors ajoutez --verbose et observez les effets qu'une véritable exécution aurait.

En mode déplacement, afew vérifiera tous les e-mails (ou seulement les récents) dans les dossiers maildir configurés, décidant s'ils doivent être déplacés vers un autre dossier.

La décision est basée sur des règles définies dans votre fichier de configuration. Une règle est liée à un dossier source et spécifie un dossier cible dans lequel un e-mail sera déplacé s'il correspond à une requête associée.

De cette façon, vous pourrez transférer vos principes de tri approximativement vers la structure de dossiers maildir classique comprise par votre serveur de messagerie traditionnel. Marquez vos e-mails avec notmuch, appelez afew --move-mails dans un hook pre-synchronisation d'offlineimap et profitez d'une boîte de réception propre dans votre interface web/client graphique au travail.

Notez qu'en mode déplacement, afew appelle notmuch new après avoir déplacé les e-mails. Vous pouvez utiliser afew -m --notmuch-args=--no-hooks dans un hook pre-new notmuch pour éviter les boucles.

Pour des informations sur la façon de configurer des règles pour le mode déplacement, ce que vous pouvez en faire et ce que vous ne pouvez pas, veuillez vous référer à Mode Déplacement.

afew(1)

NOM

afew - un outil de tri d'e-mails pour Mutt

QUICK START

Créez votre fichier de configuration ~/.config/afew/afew.conf. Le moyen le plus simple est de copier l'exemple dans le répertoire de configuration de Mutt : 

  $ cp /usr/share/doc/afew/afew.conf ~/.config/afew/afew.conf
Ensuite, vous pouvez configurer Mutt pour qu'il appelle afew.

INSTALLATION

afew est disponible dans le dépôt [extra] d'Arch Linux. Vous pouvez l'installer avec pacman : 

  $ pacman -S afew
Si vous n'utilisez pas Arch Linux, vous pouvez trouver les instructions d'installation sur le [site web d'afew].

UTILISATION EN LIGNE DE COMMANDE

La commande de base pour exécuter afew est : 

  $ afew [OPTIONS]
afew lira les e-mails non triés de votre boîte aux lettres (par défaut, ~/Maildir/inbox), appliquera vos filtres et déplacera les e-mails correspondants vers les boîtes aux lettres spécifiées. Certaines options courantes sont :
  • -s, --shell-escape :échappe les caractères spéciaux pour une utilisation dans un shell.
  • -n, --dry-run :ne déplace aucun e-mail, affiche uniquement ce qui serait fait.
  • -v, --verbose :affiche plus d'informations sur ce qui se passe.
  • -h, --help :affiche l'aide et quitte.
  • -c, --config FILE :utilise un fichier de configuration alternatif.
Pour une liste complète des options, voir man afew.

CONFIGURATION

afew utilise un fichier de configuration pour définir comment trier les e-mails. Le fichier de configuration par défaut est ~/.config/afew/afew.conf. Le fichier de configuration est divisé en sections. Chaque section commence par une ligne contenant le nom de la section entre crochets, par exemple : [DEFAULT]. Les lignes commençant par un dièse (#) sont des commentaires. Les lignes vides sont ignorées. Les lignes restantes sont des paires clé-valeur, par exemple : key = value Les valeurs peuvent être des chaînes de caractères, des nombres, des listes (séparées par des virgules) ou des dictionnaires (en utilisant la syntaxe de dictionnaire Python). La section [DEFAULT] contient les paramètres globaux pour afew. Les sections suivantes définissent les filtres. Pour plus de détails sur les options de configuration, voir man afew.conf.

FILTRES

Les filtres sont le cœur d'afew. Ils sont utilisés pour sélectionner les e-mails et décider où les déplacer. Chaque filtre est défini dans sa propre section, commençant par le nom du filtre. Par exemple : [MY_FILTER] Le filtre possède des attributs qui déterminent à quels e-mails il s'applique et quelle action il effectue. Les attributs courants sont :

  • from :une chaîne de caractères ou une expression régulière à faire correspondre à l'en-tête 'From'.
  • to :une chaîne de caractères ou une expression régulière à faire correspondre à l'en-tête 'To'.
  • subject :une chaîne de caractères ou une expression régulière à faire correspondre à l'en-tête 'Subject'.
  • body :une chaîne de caractères ou une expression régulière à faire correspondre au corps de l'e-mail.
  • header :une chaîne de caractères ou une expression régulière à faire correspondre à n'importe quel en-tête d'e-mail.
  • folder :la boîte aux lettres vers laquelle déplacer les e-mails correspondants.
  • mark :un attribut facultatif pour marquer les e-mails avec un drapeau spécifique (par exemple, 'read', 'archive').
Les filtres sont évalués dans l'ordre où ils apparaissent dans le fichier de configuration. Le premier filtre qui correspond à un e-mail sera utilisé. Vous pouvez trouver plus d'exemples dans le fichier de configuration d'exemple.

MODE DÉPLACEMENT

Par défaut, afew déplace les e-mails vers les boîtes aux lettres spécifiées. Cependant, vous pouvez activer le mode déplacement en ajoutant l'attribut move = true à un filtre. Lorsque le mode déplacement est activé, afew ne se contente pas de déplacer les e-mails, il supprime également les messages d'origine. Cela peut être utile pour nettoyer votre boîte de réception de manière permanente.

EXTENSION D'AFEW

afew est écrit en Python, et vous pouvez étendre ses fonctionnalités en écrivant vos propres modules Python. Vous pouvez importer vos modules dans le fichier de configuration en utilisant la directive import. Par exemple, si vous avez un module my_filters.py dans le même répertoire que votre fichier de configuration, vous pouvez l'importer comme suit : import my_filters Vous pouvez ensuite utiliser les fonctions et classes définies dans votre module dans vos filtres. Voir la documentation pour plus de détails.

IMPLÉMENTATION

afew est écrit en Python et utilise la bibliothèque imaplib pour interagir avec les serveurs IMAP. Il utilise également la bibliothèque email pour analyser les messages d'e-mail. La logique de filtrage est implémentée à l'aide d'expressions régulières, ce qui permet une correspondance flexible des en-têtes et du contenu des e-mails.
