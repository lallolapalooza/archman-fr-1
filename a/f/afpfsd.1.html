NOM

afpfsd - Démon pour gérer les sessions AFP pour le client FUSE afpfs-ng.

SYNTAXE

afpfsd [-l|logmethod=méthode [f|--foreground [d|--debug

DESCRIPTION

afpfsd est un démon qui gère les sessions AFP. Les fonctions (comme le montage, l'obtention du statut, etc.) peuvent être effectuées en utilisant l'outil afp_client(1). Ce client communique avec le démon via un pipe nommé.

afpfsd ne démarrera pas si une autre instance est déjà en cours d'exécution. Il doit y avoir une copie d'afpfsd en cours d'exécution par utilisateur.

OPTIONS

-l|--logmethod définit la méthode utilisée pour l'enregistrement des journaux ; les valeurs sont stdout ou syslog

-f|--foreground ne détache pas le démon du processus parent

-f|--debug place le démon au premier plan et affiche les journaux sur la sortie standard

VOIR AUSSI

afp_client(1), mount_afp(1)
