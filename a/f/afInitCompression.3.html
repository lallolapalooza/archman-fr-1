NOM

afInitCompression - initialiser la compression pour une piste dans un fichier audio

SYNTAXE

#include <audiofile.h>
void afInitCompression(AFfilesetup setup, int track, int compression);

PARAMETRES

setup est une configuration de fichier valide renvoyée par afNewFileSetup(3).

track spécifie une piste dans la configuration du fichier audio. track est toujours AF_DEFAULT_TRACK pour tous les formats de fichiers actuellement pris en charge.

compression est un identifiant spécifiant le type de compression (tel que AF_COMPRESSION_G711_ULAW) à utiliser pour les données audio de la piste.

DESCRIPTION

Étant donné une structure AFfilesetup créée avec afNewFileSetup(3) et une piste identifiée par track (AF_DEFAULT_TRACK pour tous les formats de fichiers actuellement pris en charge), afInitCompression initialise la piste à la compression spécifiée.

Les types de compression suivants sont actuellement pris en charge :

AF_COMPRESSION_NONE

aucune compression

AF_COMPRESSION_G711_ULAW

encodage mu-law CCITT G.711

AF_COMPRESSION_G711_ALAW

encodage A-law CCITT G.711

AF_COMPRESSION_IMA

encodage IMA ADPCM

AF_COMPRESSION_MS_ADPCM

encodage MS ADPCM

AF_COMPRESSION_FLAC

FLAC

AF_COMPRESSION_ALAC

Apple Lossless Audio Codec

ERREURS

afInitCompression peut produire les erreurs suivantes :

AF_BAD_FILESETUP

setup représente une configuration de fichier invalide.

AF_BAD_TRACKID

track représente un identifiant de piste invalide.

AF_BAD_COMPTYPE

compression représente un type de compression invalide.

VOIR AUSSI

afNewFileSetup(3), afInitSampleFormat(3)
