NOM

afl-cmin.bash

SYNTAXE

Utilisation : ./afl-cmin.bash [ options ] -- /chemin/vers/application_cible [ ... ]

OPTIONS

Paramètres requis :
  -i dir        - répertoire d'entrée avec le corpus de départ
  -o dir        - répertoire de sortie pour les fichiers minimisés
Paramètres de contrôle d'exécution :
  -T tâches      - nombre de processus parallèles à créer (défaut=1, « all »=nproc)
  -f fichier     - emplacement lu par le programme fuzzé (défaut : stdin)
  -m megs       - limite de mémoire pour le processus enfant (défaut : aucun Mo)
  -t msec       - limite de temps d'exécution pour le processus enfant (défaut : 5000ms)
  -O            - utiliser l'instrumentation binaire uniquement (mode FRIDA)
  -Q            - utiliser l'instrumentation binaire uniquement (mode QEMU)
  -U            - utiliser l'instrumentation basée sur Unicorn (mode Unicorn)
  -X            - utiliser le mode Nyx
Paramètres de minimisation :
  -A            - autoriser les entrées entraînant des plantages et des timeouts
  -C            - conserver les entrées entraînant des plantages, rejeter tout le reste
  -e            - résoudre uniquement la couverture des arêtes, ignorer les décomptes de visites
Pour des conseils supplémentaires, veuillez consulter README.md.
Ce script ne peut pas lire les noms de fichiers se terminant par un espace «  ».
Variables d'environnement utilisées :
AFL_KEEP_TRACES : laisser le répertoire temporaire <out_dir>.traces
AFL_NO_FORKSRV : exécuter la cible via execve au lieu d'utiliser le forkserver
AFL_PATH : emplacement de dernier recours pour trouver le binaire afl-showmap
AFL_SKIP_BIN_CHECK : ignorer la vérification du binaire cible
AFL_CUSTOM_MUTATOR_LIBRARY : bibliothèque de mutateur personnalisé (post_process et send)
AFL_PYTHON_MODULE : bibliothèque de mutateur personnalisé (post_process et send)
