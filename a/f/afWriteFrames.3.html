NOM

afWriteFrames - écrire des trames d'échantillons dans une piste d'un fichier audio

SYNTAXE

#include <audiofile.h>
AFframecount afWriteFrames(AFfilehandle file, int track, const void *data,
    AFframecount count);

DESCRIPTION

afWriteFrames tente d'écrire jusqu'à count trames de données audio à partir du tampon data vers le descripteur de fichier audio file.

PARAMETRES

file est un descripteur de fichier valide retourné par afOpenFile(3).

track est toujours AF_DEFAULT_TRACK pour tous les formats de fichier actuellement supportés.

data est un tampon de trames d'échantillons à écrire dans le fichier.

count est le nombre de trames d'échantillons à écrire.

VALEUR DE RETOUR

afWriteFrames retourne le nombre de trames d'échantillons écrites avec succès dans file.

ERREURS

afWriteFrames peut produire les erreurs suivantes :

AF_BAD_FILEHANDLE

le descripteur de fichier était invalide

AF_BAD_TRACKID

la piste n'est pas AF_DEFAULT_TRACK

AF_BAD_WRITE

l'écriture des données audio dans le fichier a échoué

AF_BAD_LSEEK

la recherche dans le fichier a échoué
