afl-showmap(8) Manuel de l'administrateur système afl-showmap(8)

NOM

afl-showmap

SYNTAXE

afl-showmap [ options ] -- /chemin/vers/l_application_cible [ ... ]

OPTIONS

Paramètres requis :
  -o fichier    - fichier où écrire les données de trace
Paramètres de contrôle d'exécution :
  -t msec    - délai d'attente pour chaque exécution (par défaut : 1000ms)
  -m megs    - limite de mémoire pour le processus enfant (par défaut : aucune)
  -O         - utiliser l'instrumentation binaire uniquement (mode FRIDA)
  -Q         - utiliser l'instrumentation binaire uniquement (mode QEMU)
  -U         - utiliser l'instrumentation basée sur Unicorn (mode Unicorn)
  -W         - utiliser l'instrumentation basée sur qemu avec Wine (mode Wine)
               (Pas nécessaire, ici pour la cohérence avec les autres outils afl-*)
  -X         - utiliser le mode Nyx
Autres paramètres :
  -i dir     - traiter tous les fichiers sous ce répertoire, doit être combiné avec -o.
               Avec -C, -o est un fichier, sans -C c'est un répertoire
               et chaque bitmap sera écrite individuellement.
  -I filelist - alternative à -i, -I est une liste de fichiers
  -C         - collecter la couverture, écrit tous les bords vers -o et donne un résumé
               Doit être combiné avec -i.
  -q         - ignorer la sortie du programme et ne pas afficher les messages
  -e         - afficher uniquement la couverture des bords, ignorer les comptes de touches
  -r         - afficher les valeurs réelles des tuples au lieu des valeurs de filtre AFL
  -s         - ne pas classifier la carte
  -c         - autoriser les vidages de noyau (core dumps)
Cet outil affiche les données brutes de tuples capturées par l'instrumentation AFL.
Pour une aide supplémentaire, consultez docs/README.md.
Si vous utilisez le mode -i/-I, alors la fonctionnalité post_process send send du mutateur personnalisé
est prise en charge.
Variables d'environnement utilisées :
LD_BIND_LAZY: ne pas définir la variable d'environnement LD_BIND_NOW pour la cible
AFL_CMIN_CRASHES_ONLY: (mode cmin) écrire uniquement les tuples pour les entrées qui provoquent des plantages
AFL_CMIN_ALLOW_ANY: (mode cmin) écrire également les tuples pour les entrées qui provoquent des plantages
AFL_CRASH_EXITCODE: code de sortie optionnel de l'enfant à interpréter comme un plantage
AFL_DEBUG: activer la sortie supplémentaire pour les développeurs
AFL_FORKSRV_INIT_TMOUT: temps d'attente pour le serveur de fork au démarrage (en millisecondes)
AFL_KILL_SIGNAL: ID de signal livré aux processus enfants en cas de délai d'attente, etc.
                 (par défaut : SIGKILL)
AFL_FORK_SERVER_KILL_SIGNAL: Signal de mise à mort pour le serveur de fork à la terminaison
                             (par défaut : SIGTERM). S'il n'est pas défini et que AFL_KILL_SIGNAL est
                             défini, cette valeur sera utilisée.
AFL_MAP_SIZE: la taille de la mémoire partagée pour cette cible. doit être >= à la taille pour
              laquelle la cible a été compilée
AFL_PRELOAD: paramètres LD_PRELOAD / DYLD_INSERT_LIBRARIES pour la cible
AFL_PRINT_FILENAMES: affiche l'entrée de la file d'attente actuellement traitée sur la sortie standard
AFL_QUIET: ne pas afficher de sortie informative supplémentaire
AFL_NO_FORKSRV: exécuter la cible via execve au lieu d'utiliser le serveur de fork
