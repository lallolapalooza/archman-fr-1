AFINITSAMPLEFORMAT(3)   AFINITSAMPLEFORMAT(3)

NOM

afInitSampleFormat, afInitByteOrder, afInitChannels, afInitRate - initialise le format des données audio pour une piste dans une configuration de fichier audio

SYNTAXE

#include <audiofile.h>
void afInitSampleFormat(AFfilesetup setup, int track, int sampleFormat,
    int sampleWidth);
void afInitByteOrder(AFfilesetup setup, int track, int byteOrder);
void afInitChannels(AFfilesetup setup, int track, int channels);
void afInitRate(AFfilesetup setup, int track, double rate);

PARAMÈTRES

setup est une configuration de fichier valide retournée par afNewFileSetup(3).

track spécifie une piste dans la configuration du fichier audio. track est toujours AF_DEFAULT_TRACK pour tous les formats de fichiers actuellement pris en charge.

sampleFormat est une constante symbolique spécifiant le format d'échantillon pour les données audio dans la piste. sampleFormat doit être l'une des AF_SAMPFMT_TWOSCOMP, AF_SAMPFMT_UNSIGNED, AF_SAMPFMT_FLOAT, ou AF_SAMPFMT_DOUBLE.

sampleWidth est un entier positif spécifiant le nombre de bits pour chaque échantillon dans la piste.

byteOrder est une constante symbolique spécifiant l'ordre des octets de la piste. byteOrder doit être l'une des AF_BYTEORDER_BIGENDIAN ou AF_BYTEORDER_LITTLEENDIAN.

channels est un entier positif spécifiant le nombre de canaux dans la piste.

rate est un nombre à virgule flottante double précision positif spécifiant la fréquence d'échantillonnage de la piste.

DESCRIPTION

afInitSampleFormat initialise la piste au format d'échantillon et à la largeur d'échantillon spécifiés.

afInitByteOrder initialise la piste à l'ordre des octets spécifié.

afInitChannels initialise la piste au nombre de canaux spécifié.

afInitRate initialise la piste à la fréquence d'échantillonnage spécifiée.

ERREURS

afInitSampleFormat, afInitByteOrder, afInitChannels et afInitRate peuvent produire les erreurs suivantes :

AF_BAD_FILESETUP setup représente une configuration de fichier invalide.
AF_BAD_TRACK track représente un identifiant de piste invalide.

afInitSampleFormat peut également produire les erreurs suivantes :

AF_BAD_SAMPFMT sampleFormat ne représente pas un format d'échantillon valide.
AF_BAD_WIDTH sampleWidth n'est pas une largeur d'échantillon valide.

afInitByteOrder peut également produire l'erreur suivante :

AF_BAD_BYTEORDER byteOrder ne représente pas un ordre d'octets valide.

afInitChannels peut également produire l'erreur suivante :

AF_BAD_CHANNELS channels spécifie un nombre de canaux invalide.

afInitRate peut également produire l'erreur suivante :

AF_BAD_RATE rate spécifie une fréquence d'échantillonnage invalide.
