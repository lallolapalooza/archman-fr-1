afl-tmin(8) Manuel de l'administrateur système afl-tmin(8)

NOM

afl-tmin

SYNTAXE

afl-tmin [ options ] -- /chemin/vers/l_app_cible [ ... ]

OPTIONS

Paramètres requis :
  -i fichier    - cas de test d'entrée à réduire par l'outil
  -o fichier    - emplacement final pour les données minimisées
Paramètres de contrôle d'exécution :
  -f fichier    - fichier d'entrée lu par le programme testé (stdin)
  -t msec       - délai d'attente pour chaque exécution (1000 ms)
  -m megs       - limite de mémoire pour le processus enfant (0 Mo)
  -O            - utiliser l'instrumentation binaire uniquement (mode FRIDA)
  -Q            - utiliser l'instrumentation binaire uniquement (mode QEMU)
  -U            - utiliser l'instrumentation basée sur Unicorn (mode Unicorn)
  -W            - utiliser l'instrumentation basée sur QEMU avec Wine (mode Wine)
                  (Pas nécessaire, ici pour la cohérence avec d'autres outils afl-*)
  -X            - utiliser le mode Nyx
Paramètres de minimisation :
  -e            - résoudre uniquement la couverture des bords, ignorer les comptes de touches
  -l octets      - définir la longueur minimale de suppression de bloc pour accélérer la minimisation
  -x            - traiter les codes de sortie non nuls comme des plantages
  -H            - minimiser un blocage (mode blocage)
Pour des conseils supplémentaires, veuillez consulter docs/README.md.
Variables d'environnement utilisées :
AFL_CRASH_EXITCODE: code de sortie enfant optionnel à interpréter comme un plantage
AFL_FORKSRV_INIT_TMOUT: temps passé à attendre le serveur de fork lors du démarrage (en ms)
AFL_KILL_SIGNAL: ID de signal délivré aux processus enfants lors du délai d'attente, etc.
                 (par défaut : SIGKILL)
AFL_FORK_SERVER_KILL_SIGNAL: signal de terminaison pour le serveur de fork lors de l'arrêt
                             (par défaut : SIGTERM). Si non défini et AFL_KILL_SIGNAL est
                             défini, cette valeur sera utilisée.
AFL_MAP_SIZE: taille de la mémoire partagée pour cette cible. doit être >= la taille
              pour laquelle la cible a été compilée
AFL_PRELOAD:  paramètres LD_PRELOAD / DYLD_INSERT_LIBRARIES pour la cible
AFL_TMIN_EXACT: exiger que les chemins d'exécution correspondent pour les entrées plantées
AFL_NO_FORKSRV: exécuter la cible via execve au lieu d'utiliser le serveur de fork
ASAN_OPTIONS: paramètres personnalisés pour ASAN
              (doit contenir abort_on_error=1 et symbolize=0)
MSAN_OPTIONS: paramètres personnalisés pour MSAN
              (doit contenir exitcode=86 et symbolize=0)
TMPDIR: répertoire à utiliser pour les fichiers d'entrée temporaires
