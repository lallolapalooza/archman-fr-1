afl-cmin(8) Manuel de l'administrateur système afl-cmin(8)

NOM

afl-cmin

SYNTAXE

afl-cmin [ options ] -- /chemin/vers/l_app_cible [ ... ]

OPTIONS

Paramètres requis :
  -i dir        - répertoire d'entrée avec le corpus de départ
  -o dir        - répertoire de sortie pour les fichiers minimisés
Paramètres de contrôle d'exécution :
  -T tasks      - nombre de tâches parallèles à exécuter (défaut : 1, tous=nproc)
  -f file       - emplacement lu par le programme fuzzed (défaut : stdin)
  -m megs       - limite de mémoire pour le processus enfant ( Mo)
  -t msec       - limite de temps d'exécution pour le processus enfant (défaut : 5000)
  -O            - utiliser l'instrumentation binaire uniquement (mode FRIDA)
  -Q            - utiliser l'instrumentation binaire uniquement (mode QEMU)
  -U            - utiliser l'instrumentation basée sur Unicorn (mode unicorn)
  -X            - utiliser le mode Nyx
Paramètres de minimisation :
  -A            - autoriser les plantages et les timeouts (non recommandé)
  -C            - conserver les entrées provoquant des plantages, rejeter tout le reste
  -e            - résoudre uniquement pour la couverture des bords, ignorer les décomptes de visites
Pour des conseils supplémentaires, veuillez consulter README.md
Variables d'environnement utilisées :
AFL_CRASH_EXITCODE: code de sortie facultatif de l'enfant à interpréter comme un plantage
AFL_FORKSRV_INIT_TMOUT: temps d'attente du fuzzer pour que le forkserver démarre
AFL_KEEP_TRACES: laisser le répertoire temporaire <out_dir>/.traces
AFL_KILL_SIGNAL: signal délivré aux processus enfants en cas de timeout (défaut : SIGKILL)
AFL_FORK_SERVER_KILL_SIGNAL: signal délivré aux processus fork server à la
   terminaison (défaut : SIGTERM). Si ce n'est pas défini et qu'AFL_KILL_SIGNAL est
   défini, cette valeur sera la même que celle de AFL_KILL_SIGNAL.
AFL_NO_FORKSRV: exécuter la cible via execve au lieu d'utiliser le forkserver
AFL_CMIN_ALLOW_ANY: écrire également des tuples pour les entrées provoquant des plantages
AFL_PATH: chemin du binaire afl-showmap s'il n'est trouvé nulle part dans PATH
AFL_PRINT_FILENAMES: Si défini, le nom du fichier actuellement traité sera imprimé sur stdout
AFL_SKIP_BIN_CHECK: ignorer les vérifications d'instrumentation afl pour le binaire cible
