NOM

afpcmd - Transférer des fichiers sur le réseau en utilisant le protocole Apple Filing Protocol (AFP)

SYNTAXE

afpcmd [-r [url afp]

DESCRIPTION

afpcmd est un outil en ligne de commande pour aider au transfert de fichiers vers et depuis un serveur utilisant AFP. Il s'agit généralement de Netatalk, Mac OS ou Mac OS X.

Cela peut être fait par un utilisateur non root. Il offre soit une ligne de commande interactive (comme un client FTP traditionnel) soit pour des récupérations par lots.

Ne pas confondre avec les outils de montage FUSE (mount_afp, afpfsd, afp_client), qui offrent la possibilité de monter un système de fichiers entier.

OPTIONS

-r active le drapeau récursif.

url afp utilise le format standard d'URL AFP.

PRISE EN CHARGE DE LA VERSION AFP

Consultez la documentation de afpfs-ng pour plus d'informations sur la compatibilité avec les versions spécifiques d'AFP.

MODE BATCH

Les transferts de fichiers par lots peuvent être effectués de deux manières:

afpcmd -r [url afp vers répertoire]

Cela effectue un transfert récursif de tous les sous-répertoires et fichiers localement.

afpcmd [url afp vers fichier]

Cela transfère uniquement le fichier localement.

Après que l'une de ces opérations soit terminée, la commande se termine.

MODE INTERACTIF

Si une URL est fournie sur la ligne de commande, afpcmd se connecte et entre dans le volume et le répertoire spécifiés.

Les frappes standard de readline sont activées. La complétion de ligne de commande (en utilisant tab) et l'historique (en utilisant les flèches haut et bas) sont fournis. La complétion des noms de fichiers locaux est activée.

Commandes les plus courantes

connect <URL afp>: Se connecter au serveur, changer de volume et de répertoire

cd: Changer de répertoire sur le serveur

get <nom de fichier>: récupérer le fichier

get -r <répertoire>: Récupérer récursivement le répertoire

put <nom de fichier>: Télécharger le fichier

quit: Quitter

Commandes de connexion/déconnexion

disconnect: Se déconnecter du serveur actuel

passwd: Demande un nouveau mot de passe sans l'afficher à l'écran

user <utilisateur>: Définir l'utilisateur

passwd: changer le mot de passe sur le serveur. Ne fonctionne pas.

Commandes de répertoire distant

pwd: Afficher le répertoire courant sur le serveur

mkdir <répertoire>: créer un nouveau répertoire

rmdir <répertoire>: supprimer un répertoire

ls ou dir: afficher les fichiers dans le répertoire courant

Commandes de fichiers distants

mv ou rename ancien_fichier nouveau_fichier: Renommer <ancien fichier> en <nouveau fichier>

touch <nom de fichier>: Créer un fichier vide

view <nom de fichier>: Afficher le fichier

chmod: <fichier> <mode>: Changer le mode d'un fichier sur le serveur

delete ou rm: <fichier>: Supprimer le fichier du serveur

Commandes de statut

status: Afficher le statut de la connexion et les détails. Pour le débogage.

df: Afficher la taille du disque et les blocs disponibles.

Commandes locales

lpwd: Afficher le répertoire local courant

lcd: Changer de répertoire local

Autres commandes

help ou ?: afficher l'aide

testafp: divers tests pour les développeurs

URL AFP

Une utilisation typique d'afpcmd est:

afpcmd afp://nomutilisateur:motdepasse@nomserveur/volume

La syntaxe complète d'une URL est:

afp://nomutilisateur;AUTH=typeauth:motdepasse@serveur:port/volume/chemin

Si un mot de passe de "-" est fourni, l'utilisateur est invité à entrer un mot de passe.

SIGNALEMENT DE BOGUES

Signalez les bogues à la liste de diffusion afpfs-ng-devel@sf.net.
