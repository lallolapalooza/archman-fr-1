afSetVirtualChannels(3)

AFSETVIRTUALSAMPLEFO(3)   AFSETVIRTUALSAMPLEFO(3)

NOM

afSetVirtualByteOrder, afSetVirtualChannels, afSetVirtualPCMMapping, afSetVirtualSampleFormat - définir le format de données virtuel pour une piste dans un fichier audio

SYNTAXE

#include <audiofile.h>
int afSetVirtualByteOrder (AFfilehandle file, int track, int byteOrder);
int afSetVirtualChannels (AFfilehandle file, int track, int channels);
int afSetVirtualSampleFormat (AFfilehandle file, int track,
    int sampleFormat, int sampleWidth);
int afSetVirtualPCMMapping (AFfilehandle file, int track,
    double slope, double intercept, double minclip, double maxclip);

PARAMÈTRES

• file est un descripteur de fichier AF (AFfilehandle) qui fait référence à un fichier audio ouvert et est généralement créé par afOpenFile.
• track est un entier qui identifie une piste particulière dans un fichier audio ouvert. La seule piste valide est AF_DEFAULT_TRACK pour tous les formats de fichiers actuellement pris en charge.
• sampleFormat est un entier qui désigne un format d'échantillon virtuel. Les valeurs valides sont AF_SAMPFMT_TWOSCOMP, AF_SAMPFMT_UNSIGNED, AF_SAMPFMT_FLOAT et AF_SAMPFMT_DOUBLE.
• sampleWidth est un entier positif qui spécifie le nombre de bits dans un échantillon.
• channels est un entier positif qui spécifie le nombre de canaux audio entrelacés dans la piste audio donnée.
• byteOrder est un entier qui spécifie l'ordre des octets virtuel des échantillons dans la piste audio donnée. byteOrder peut être AF_BYTEORDER_BIGENDIAN ou AF_BYTEORDER_LITTLEENDIAN.
• slope et intercept sont des valeurs flottantes double précision qui indiquent la pente des données audio de l'échantillon et la valeur de passage à zéro, respectivement, pour le format d'échantillon donné.
• minclip et maxclip sont des valeurs flottantes double précision qui indiquent les valeurs minimales ou maximales d'échantillon à retourner. Toute valeur inférieure à minclip sera définie à minclip, et toute valeur supérieure à maxclip sera définie à maxclip.

VALEUR DE RETOUR

Ces fonctions retournent 0 en cas de succès et -1 en cas d'échec.
