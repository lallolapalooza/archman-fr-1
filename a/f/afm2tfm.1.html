NOM

afm2tfm - convertir les métriques de polices Adobe en métriques de polices TeX

DESCRIPTION

Les polices PostScript sont (ou devraient être) accompagnées de fichiers de métriques de polices tels que Times-Roman.afm, qui décrivent les caractéristiques de la police appelée Times-Roman. Pour utiliser de telles polices avec TeX, nous avons besoin de fichiers TFM qui contiennent des informations similaires. Ce programme effectue cette conversion.

Pour tous les détails, consultez le manuel de dvips (http://tug.org/dvips).

FICHIERS

psfonts.map dans le répertoire de configuration utilisé par dvips.

VOIR AUSSI

dvips(1), tex(1), vptovf(1), fontinst(1), afm2pl(1), otftotfm(1)

BOGUES

Une option pour ajouter un espacement de lettres à la police virtuelle a été rejetée par Knuth car elle aurait fait casser les ligatures fi et fl du rythme normal.

AUTEURS

Tomas Rokicki et Donald E. Knuth.

Maintenu dans TeX Live ; veuillez envoyer les rapports de bogues ou toute autre correspondance à tex-k@tug.org (http://lists.tug.org/tex-k).
