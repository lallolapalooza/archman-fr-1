AFGETFRAMESIZE(3)   AFGETFRAMESIZE(3)

NOM

afGetFrameSize - calcule la taille d'une trame en octets pour une piste audio

SYNTAXE

#include <audiofile.h>
float afGetFrameSize (AFfilehandle file, int track, int expand3to4);

PARAMETRES

file est un AFfilehandle valide.

track est un entier qui fait référence à une piste audio spécifique dans le fichier. Actuellement, aucun format de fichier audio pris en charge ne permet plus d'une piste audio dans un fichier, donc track doit toujours être AF_DEFAULT_TRACK.

expand3to4 est un entier booléen indiquant si le calcul de la taille de la trame traitera les données de 24 bits comme ayant une taille de 3 octets ou 4 octets.

DESCRIPTION

afGetFrameSize retourne le nombre d'octets dans une trame d'une piste audio donnée.

Une trame d'échantillon consiste en un ou plusieurs échantillons. Pour une piste monaurale, une trame d'échantillon contiendra toujours un échantillon. Pour une piste stéréophonique, une trame d'échantillon contiendra toujours deux échantillons, un pour le canal gauche et un pour le canal droit.

Une valeur non nulle de expand3to4 doit être utilisée lors du calcul de la taille de la trame pour le stockage en mémoire (car les données audio de 24 bits sont présentées en mémoire comme un entier signé de 4 octets), tandis qu'une valeur de zéro doit être utilisée pour le calcul du stockage sur disque où aucun remplissage n'est ajouté. Le paramètre expand3to4 est ignoré sauf si la piste audio spécifiée contient des données audio de 24 bits.
