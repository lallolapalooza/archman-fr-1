NOM

afm2afm - réencoder un fichier afm

SYNTAXE

afm2afm
[-help] [-version] [-encoding=<fichier_encodage>] [-kpx=<fichier_kpx>] [-output=<fichier_sortie>] <fichier_afm>

DESCRIPTION

afm2afm réencode un fichier afm.

Les métriques (y compris les données de crénage) pour les caractères non présents dans l'encodage choisi sont exclus de la sortie, ce qui résulte en des fichiers (potentiellement beaucoup) plus petits.

Des paires de crénage supplémentaires peuvent être ajoutées au fichier de sortie. Si vous ne spécifiez pas de fichier d'encodage, le fichier afm n'est pas réencodé ; cependant, toutes les données inutilisées (non encodées) sont toujours élaguées.

Le programme génère également une entrée pour un fichier de carte de style dvips, mais uniquement si le fichier afm a été réencodé et si la sortie a été écrite dans un fichier (c'est-à-dire si les options -encoding et -output ont toutes deux été spécifiées).

OPTIONS ET ARGUMENTS

-help
Affiche une brève description de la syntaxe.
-version
Affiche le numéro de version et quitte.
-encoding=<fichier_encodage>
Réencoder vers l'encodage dans <fichier_encodage>.
-kpx=<fichier_kpx>
Lire des paires de crénage supplémentaires depuis <fichier_kpx> et les ajouter à la sortie. Cette option ne peut pas être utilisée pour outrepasser les valeurs du fichier afm d'entrée, car afm2afm écrira à la fois les anciennes et les nouvelles valeurs dans la sortie !

Le fichier <fichier_kpx> doit contenir des données de crénage au format afm standard, c'est-à-dire que pour chaque paire de crénage, il doit y avoir une ligne

KPX <glyphe_gauche> <glyphe_droit> <montant>

Toutes les autres lignes du fichier <fichier_kpx> sont ignorées.

-output=<fichier_sortie>
Écrire le résultat dans <fichier_sortie> au lieu de "stdout".
<fichier_afm>
Le fichier afm à réencoder.

Vous pouvez utiliser un ou deux tirets avant les options, et les noms d'options peuvent être abrégés en un préfixe unique.
