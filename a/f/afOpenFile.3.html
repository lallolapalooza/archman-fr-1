AFOPENFILE(3)   AFOPENFILE(3)

NOM

afOpenFile - ouvre un fichier audio et crée une structure de descripteur de fichier utilisée pour les appels ultérieurs à la bibliothèque Audio File.

SYNTAXE

#include <audiofile.h>
AFfilehandle afOpenFile(const char *path, const char *mode,
    AFfilesetup setup);

PARAMÈTRES

path est le chemin du fichier à ouvrir.

mode spécifie un mode d'ouverture du fichier : « r » pour la lecture ou « w » pour l'écriture.

setup est un AFfilesetup créé par afNewFileSetup(3). Cette valeur est ignorée pour les fichiers ouverts en lecture sauf lorsque le format de fichier est AF_FILE_RAWDATA.

VALEUR DE RETOUR

En cas de succès, afOpenFile retourne un AFfilehandle valide qui peut être utilisé dans les appels ultérieurs à la bibliothèque Audio File. En cas d'échec, afOpenFile retourne NULL et génère une erreur.

afCloseFile(3) est utilisé pour fermer le fichier lorsqu'il n'est plus nécessaire.

ERREURS

afOpenFile peut produire les erreurs suivantes :

AF_BAD_OPEN

Un appel à open a échoué.

AF_BAD_READ

Un appel à read a échoué

AF_BAD_WRITE

Un appel à write a échoué.

AF_BAD_LSEEK

Un appel à lseek a échoué.

AF_BAD_MALLOC

L'allocation de mémoire a échoué.

AF_BAD_FILEFMT

setup spécifie un format de fichier non supporté pour le mode.

AF_BAD_SAMPFMT

Le format d'échantillon du fichier n'est pas supporté.

AF_BAD_WIDTH

La largeur d'échantillon du fichier n'est pas supportée.

AF_BAD_RATE

Le taux d'échantillon du fichier n'est pas supporté.

AF_BAD_CHANNELS

Le nombre de canaux dans le fichier n'est pas supporté.

AF_BAD_FILESETUP

setup spécifie une configuration invalide ou non supportée.

VOIR AUSSI

afCloseFile(3), afNewFileSetup(3), afInitFileFormat(3), afInitSampleFormat(3), afReadFrames(3), afWriteFrames(3)
