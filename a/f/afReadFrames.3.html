NOM

afReadFrames - lire des trames d'échantillons depuis un fichier audio

SYNTAXE

#include <audiofile.h>
AFframecount afReadFrames(AFfilehandle file, int track, void *data,
    int count);

DESCRIPTION

afReadFrames tente de lire jusqu'à count trames de données audio depuis le descripteur de fichier audio file dans le tampon situé à data.

PARAMETRES

file est un descripteur de fichier valide retourné par afOpenFile(3).

track est toujours AF_DEFAULT_TRACK pour tous les formats de fichier actuellement supportés.

data est un tampon pour stocker count trames de données d'échantillons audio.

count est le nombre de trames d'échantillons à lire.

VALEUR DE RETOUR

afReadFrames retourne le nombre de trames lues avec succès depuis file.

ERREURS

afReadFrames peut produire les erreurs suivantes :

AF_BAD_FILEHANDLE

le descripteur de fichier était invalide

AF_BAD_TRACKID

le paramètre track n'est pas AF_DEFAULT_TRACK

AF_BAD_READ

la lecture des données audio du fichier a échoué

AF_BAD_LSEEK

la recherche dans le fichier a échoué
