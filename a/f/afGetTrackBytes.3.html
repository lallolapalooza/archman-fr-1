afGetTrackBytes(3)

AFGETFRAMECOUNT(3)   AFGETFRAMECOUNT(3)

NOM

afGetFrameCount, afGetTrackBytes, afGetDataOffset - obtenir le nombre total d'images d'échantillons, la longueur de la piste audio en octets, le décalage de la piste audio pour une piste dans un fichier audio

SYNTAXE

#include <audiofile.h>
AFframecount afGetFrameCount (AFfilehandle file, int track);
AFfileoffset afGetTrackBytes (AFfilehandle file, int track);
AFfileoffset afGetDataOffset (AFfilehandle file, int track);

PARAMETRES

file est un descripteur de fichier audio créé par un appel précédent à afOpenFile(3).

track est un entier qui spécifie une piste audio dans file. Tous les formats de fichiers pris en charge contiennent exactement une piste audio par fichier, donc la constante AF_DEFAULT_TRACK doit toujours être utilisée.

DESCRIPTION

afGetFrameCount renvoie le nombre total d'images d'échantillons contenues dans la piste spécifiée du fichier spécifié.

Chaque image d'échantillons audio consiste en un nombre fixe d'échantillons (égal au nombre de canaux audio dans la piste. Pour les données monaurales, une image d'échantillons consiste en un échantillon audio. Pour les données stéréophoniques, une image d'échantillons consiste en une paire stéréo.

afGetTrackBytes renvoie le nombre total d'octets de données audio brutes (c'est-à-dire avant décompression ou conversion) dans la piste.

afGetDataOffset renvoie le décalage en octets du début des données audio contenues dans la piste spécifiée du fichier spécifié.

VALEUR DE RETOUR

afGetFrameCount renvoie le nombre total d'images d'échantillons dans track.

afGetTrackBytes renvoie le nombre total d'octets de données audio dans track.

afGetDataOffset renvoie le décalage en octets du début des données audio dans track.

Chacune de ces routines renvoie -1 en cas d'erreur.
