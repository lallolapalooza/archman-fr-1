NOM

afInitAESChannelDataTo, afInitAESChannelData - initialiser des données non-audio AES dans une configuration de fichier audio

SYNTAXE

#include <audiofile.h>
void afInitAESChannelDataTo(AFfilesetup setup, int track, int willHaveData);
void afInitAESChannelData(AFfilesetup setup, int track);

PARAMETRES

setup est une configuration de fichier valide retournée par afNewFileSetup(3).

track spécifie une piste dans la configuration du fichier audio. track est toujours AF_DEFAULT_TRACK pour tous les formats de fichiers actuellement supportés.

willHaveData est un entier booléen indiquant si des données non-audio AES seront présentes.

DESCRIPTION

Étant donné une structure AFfilesetup créée avec afNewFileSetup(3) et une piste identifiée par track (AF_DEFAULT_TRACK pour tous les formats de fichiers actuellement supportés), afInitAESChannelDataTo initialise la piste pour contenir ou ne pas contenir de données non-audio AES. afInitAESChannelData se comporte de manière similaire mais initialise toujours la piste pour contenir des données non-audio AES.

Actuellement, seuls les formats de fichiers AIFF et AIFF-C peuvent stocker des données non-audio AES ; ces données sont ignorées dans tous les autres formats de fichiers.

ERREURS

afInitAESChannelDataTo et afInitAESChannelData peuvent produire les erreurs suivantes :

AF_BAD_FILESETUP

setup représente une configuration de fichier invalide.

AF_BAD_TRACKID

track représente un identifiant de piste invalide.
