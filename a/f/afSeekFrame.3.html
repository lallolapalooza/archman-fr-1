AFSEEKFRAME(3)   AFSEEKFRAME(3)

NOM

afSeekFrame, afTellFrame - met à jour ou accède à la position d'échantillon courante pour une piste dans un fichier audio

SYNTAXE

#include <audiofile.h>
AFframecount afSeekFrame(AFfilehandle file, int track,
    AFframecount frameOffset);
AFframecount afTellFrame(AFfilehandle file, int track);

PARAMÈTRES

file est une poignée de fichier audio valide créée par afOpenFile(3).

track identifie une piste audio dans le fichier. track est toujours AF_DEFAULT_TRACK pour tous les formats de fichiers audio actuellement pris en charge.

frameOffset est un décalage d'images d'échantillons. Les décalages d'images d'échantillons valides doivent être supérieurs ou égaux à zéro et strictement inférieurs au nombre d'images d'échantillons contenues dans la piste audio spécifiée. La valeur spéciale -1 est également autorisée.

DESCRIPTION

afSeekFrame déplace la position logique du fichier pour une piste audio spécifiée à un emplacement d'image d'échantillons souhaité. Si frameOffset est -1, afSeekFrame ne modifiera pas le décalage de fichier actuel et retournera plutôt la position de fichier actuelle.

afTellFrame retourne la position de fichier actuelle en images d'échantillons.

VALEUR DE RETOUR

En cas de succès, afSeekFrame et afTellFrame retourneront la position de fichier actuelle mesurée en images d'échantillons depuis le début de la piste audio. En cas d'échec, afSeekFrame et afTellFrame retourneront la valeur -1.

ERREURS

Les erreurs suivantes peuvent être générées par afSeekFrame ou afTellFrame:

AF_BAD_FILEHANDLE

file ne représente pas une poignée de fichier valide.

AF_BAD_TRACK

track n'identifie pas une piste valide.

AF_BAD_LSEEK

Un appel à lseek a échoué.
