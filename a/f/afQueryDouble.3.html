AFQUERY(3)   AFQUERY(3)

NOM

afQuery, afQueryLong, afQueryDouble, afQueryPointer - interroger les capacités de la bibliothèque Audio File Library

SYNTAXE

#include <audiofile.h>
AUpvlist afQuery (int querytype, int arg1, int arg2, int arg3, int arg4);
long afQueryLong (int querytype, int arg1, int arg2, int arg3, int arg4);
double afQueryDouble (int querytype, int arg1, int arg2, int arg3,
    int arg4);
void *afQueryPointer (int querytype, int arg1, int arg2, int arg3,
    int arg4);

PARAMÈTRES

querytype peut être l'un des suivants :

• AF_QUERYTYPE_FILEFMT
• AF_QUERYTYPE_INST
• AF_QUERYTYPE_INSTPARAM
• AF_QUERYTYPE_COMPRESSION
• AF_QUERYTYPE_COMPRESSIONPARAM
• AF_QUERYTYPE_MISC
• AF_QUERYTYPE_MARK
• AF_QUERYTYPE_LOOP

arg1, arg2, arg3 et arg4 sont des sélecteurs entiers dont la signification dépend de querytype.

VALEUR DE RETOUR

En cas de succès, afQuery retournera une valeur AUpvlist non nulle. En cas d'échec, afQuery retournera null tandis que afQueryLong et afQueryDouble retourneront -1 et afQueryPointer retournera null.

Les pointeurs représentant des chaînes de caractères sont la propriété de la bibliothèque Audio File Library et ne doivent pas être libérés ; toutes les autres valeurs de pointeur doivent être libérées par l'appelant.

DESCRIPTION

Pour AF_QUERYTYPE_FILEFMT, les sélecteurs suivants sont des valeurs valides pour arg1 :

AF_QUERY_LABEL

Demande une courte chaîne d'étiquette pour le format (par exemple, "aiff").

AF_QUERY_NAME

Demande un nom court pour le format (par exemple, "MS RIFF WAVE").

AF_QUERY_DESC

Demande un nom descriptif pour le format (par exemple, "Audio Interchange File Format").

AF_QUERY_IMPLEMENTED

Demande une valeur booléenne indiquant si le format est implémenté pour la lecture et l'écriture dans la bibliothèque Audio File Library.

AF_QUERY_ID_COUNT

Demande le nombre total de formats implémentés.

AF_QUERY_IDS

Demande un tableau d'entiers contenant les valeurs de jeton d'ID de tous les formats de fichiers implémentés.

AF_QUERY_COMPRESSION_TYPES

Utilisé avec le sélecteur AF_QUERY_VALUE_COUNT dans arg2, ceci retournera un entier long contenant le nombre de schémas de compression disponibles pour une utilisation dans le format spécifié dans arg3. Utilisé avec le sélecteur AF_QUERY_VALUES, il retourne un pointeur vers un tableau d'entiers contenant les valeurs d'ID de compression des schémas de compression pris en charge par le format spécifié dans arg3.

AF_QUERY_SAMPLE_FORMATS

Utilisé avec le sélecteur AF_QUERY_DEFAULT dans arg2, ceci retournera le format d'échantillon par défaut pour le format de fichier spécifié dans arg3.

AF_QUERY_SAMPLE_SIZES

Utilisé avec le sélecteur AF_QUERY_DEFAULT dans arg2, ceci retournera la largeur d'échantillon par défaut pour le format de fichier spécifié dans arg3.

Pour AF_QUERYTYPE_INST, les sélecteurs suivants sont valides pour arg1 :

AF_QUERY_SUPPORTED

Demande une valeur booléenne indiquant si le format de fichier dans arg2 prend en charge les instruments.

AF_QUERY_MAX_NUMBER

Demande une valeur entière indiquant le nombre maximum d'instruments pris en charge par le format de fichier dans arg2.

Pour AF_QUERYTYPE_INSTPARAM, les sélecteurs suivants sont valides pour arg1 :

AF_QUERY_SUPPORTED

Demande une valeur booléenne indiquant si le format de fichier dans arg2 prend en charge les paramètres d'instrument.

AF_QUERY_ID_COUNT

Demande une valeur entière indiquant le nombre de paramètres d'instrument pris en charge par le format de fichier dans arg2.

AF_QUERY_IDS

Demande un tableau d'entiers contenant les valeurs des paramètres d'instrument pour le format de fichier dans arg2.

AF_QUERY_TYPE

Pour le format de fichier dans arg2, demande le type du paramètre d'instrument dans arg3.

AF_QUERY_NAME

Pour le format de fichier dans arg2, demande le nom du paramètre d'instrument dans arg3.

AF_QUERY_DEFAULT

Pour le format de fichier dans arg2, demande la valeur par défaut du paramètre d'instrument dans arg3.

ERREURS

afQuery peut produire les erreurs suivantes :

AF_BAD_QUERYTYPE

Le type de requête n'est pas pris en charge.

AF_BAD_QUERY

Les arguments de la requête sont incorrects.
