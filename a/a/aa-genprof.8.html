NOM

aa-genprof - utilitaire de génération de profils pour AppArmor

SYNTAXE

aa-genprof <exécutable> [-d /chemin/vers/profils] [-f /chemin/vers/journal]

OPTIONS

-d --dir /chemin/vers/profils

Spécifie où rechercher l'ensemble des profils de sécurité AppArmor.
La valeur par défaut est /etc/apparmor.d.

-f --file /chemin/vers/journal

Spécifie l'emplacement du fichier journal.
Les emplacements par défaut sont lus à partir de F</etc/apparmor/logprof.conf>.
Les valeurs par défaut typiques sont :
         /var/log/audit/audit.log
         /var/log/syslog
         /var/log/messages

DESCRIPTION

Lors de l'exécution de aa-genprof, vous devez spécifier un programme à profiler. Si le programme spécifié n'est pas un chemin d'accès qualifié complet, aa-genprof recherchera dans $PATH afin de trouver le programme.

Si un profil n'existe pas pour le programme, aa-genprof en créera un en utilisant aa-autodep(1).

Genprof effectuera alors les actions suivantes :

- mettra le profil en mode "complain" (plainte)
- écrira une marque dans le journal système
- demandera à l'utilisateur de démarrer l'application à
  profiler dans une autre fenêtre et d'en exercer les fonctionnalités

Il présentera ensuite à l'utilisateur deux options : (E)xaminer le journal système pour trouver les entrées à ajouter au profil et (T)erminer.

Si l'utilisateur sélectionne (E)xaminer ou appuie sur Entrée, aa-genprof analysera les journaux du mode "complain" et parcourra les violations générées en utilisant aa-logprof(1).

Une fois que l'utilisateur a fini de sélectionner les entrées de profil basées sur les violations détectées pendant l'exécution du programme, aa-genprof rechargera les profils mis à jour en mode "complain" et invitera à nouveau l'utilisateur à (E)xaminer et (T)erminer. Ce cycle peut ensuite être répété autant que nécessaire jusqu'à ce que toutes les fonctionnalités de l'application aient été exercées sans générer de violations d'accès.

Lorsque l'utilisateur appuie finalement sur (T)erminer, aa-genprof définira le profil principal, ainsi que tous les autres profils qui ont été générés, en mode "enforce" (application) et quittera.
