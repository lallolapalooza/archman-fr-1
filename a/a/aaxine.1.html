AAXINE(1) Manuel des commandes générales AAXINE(1)

NOM

aaxine - un lecteur vidéo en art ASCII

SYNTAXE

aaxine [options-aalib] [-A<pilote-audio>] [-a<canal-audio>] [-R<reconnaissance-par>] [MRL...]

DESCRIPTION

Ce manuel explique le programme aaxine. Aaxine est une interface basée sur aalib pour libxine, un lecteur vidéo/multimédia polyvalent.

aaxine s'adresse à ceux qui n'ont pas une carte vidéo haut de gamme, mais qui veulent simplement regarder des DVD sur leur bon vieux vt100 ;-)

Comme xine, aaxine lit des flux système MPEG (audio et vidéo), des flux élémentaires mpeg (par exemple, fichiers .mp3 ou .mpv), des fichiers avi (utilisant les codecs win32 ou ffmpeg), des (S)VCD, des DVD et bien plus. En bref, tout ce qui est supporté par xine-lib.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous. Pour une description complète, voir README et FAQ dans /usr/share/doc/xine-ui ou sur la page d'accueil de xine.

-h, --help
Affiche un résumé des options et des pilotes de sortie disponibles (plugins).

Un grand nombre de ces options est fourni par aalib. Veuillez vous reporter à la documentation de votre aalib pour celles-ci !

Les options restantes, étiquetées options AAXINE : lorsqu'elles sont listées avec « aaxine --help », sont expliquées ici.

-A, --audio-driver <drv>
Utilise le pilote audio donné. Les pilotes disponibles peuvent être listés avec « aaxine --help »
-a, --audio-channel <num>
Utilise le canal audio donné. Les canaux sont numérotés séquentiellement à partir de 0 pour la première piste audio.
-R, --recognize-by [option]
Détermine la méthode utilisée pour reconnaître le type de flux. Les options possibles sont :
`default' : par contenu, puis par extension,
`revert' : par extension, puis par contenu,
`content' : uniquement par contenu,
`extension' : uniquement par extension.
Si -R est donné sans option supplémentaire, « revert » est sélectionné.

MRLs

Les MRLs sont similaires aux URLs dans votre navigateur Web. Elles décrivent le média à lire. Les MRLs valides peuvent être des noms de fichiers simples ou l'une des suivantes :
file:<chemin>
fifo:<chemin>
stdin:/
dvd:/<titre>.<partie>
vcd:/<numéro-piste>
tcp://<hôte>:<port>
rtp://<hôte>:<port>
udp://<hôte>:<port>
mms://<hôte>...
http://<hôte>...
cdda://<numéro-piste>

Plusieurs MRLs peuvent être spécifiées afin de lire un certain nombre de flux consécutifs. Des plugins d'entrée supplémentaires fourniront des types de MRL supplémentaires. Ceux listés ci-dessus sont disponibles avec la bibliothèque libxine standard...
Après un délimiteur #, vous pouvez ajouter plusieurs paramètres de flux :

novideo
la vidéo sera ignorée
noaudio
l'audio sera ignoré
nospu
les sous-titres seront ignorés
demux:<nom-demux>
spécifie le plugin demux à utiliser
volume:<niveau>
définit le volume audio
compression:<niveau>
définit la compression dynamique du son
<entrée-config>:<valeur-config>
assigne une nouvelle valeur à n'importe quelle entrée de configuration

TOUCHES DE CONTRÔLE

De nombreuses fonctionnalités peuvent être contrôlées en appuyant sur des touches de contrôle. Les raccourcis clavier sont :

<RETOUR> / R
Lecture
<ESPACE> / P
Pause
0
Sauter au début du flux actuel
1 .. 9
Sauter à 10 %..90 % du flux actuel
<PgUp>
Sauter à la piste précédente dans la liste de lecture
<PgDown>
Sauter à la piste suivante dans la liste de lecture
+
Sélectionner le canal audio suivant (peut prendre quelques secondes pour prendre effet)
-
Sélectionner le canal audio précédent
Q
Quitter.

BOGUES

aucun, bien sûr ;-) Bon, il y en a sûrement quelques-uns. Vous pouvez probablement demander le support (et signaler les bogues) sur notre liste de diffusion à l'adresse <xine-user@lists.sf.net>.
