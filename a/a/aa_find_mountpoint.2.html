aa_find_mountpoint(2)

AA_FIND_MOUNTPOINT(2) AppArmor AA_FIND_MOUNTPOINT(2)

NOM

aa_is_enabled - déterminer si AppArmor est activé

aa_find_mountpoint - trouver où le système de fichiers de l'interface AppArmor est monté

SYNOPSIS

#include <sys/apparmor.h>

int aa_is_enabled(void);

int aa_find_mountpoint(char **mnt);

Liez avec -lapparmor lors de la compilation.

DESCRIPTION

La fonction aa_is_enabled renvoie vrai (1) si AppArmor est activé. Si ce n'est pas le cas, elle définit errno(3) pour refléter la raison pour laquelle il n'est pas activé et renvoie 0.

La fonction aa_find_mountpoint trouve où le système de fichiers AppArmor est monté sur le système, et renvoie une chaîne contenant le chemin de montage. Il incombe à l'appelant de free(3) le chemin renvoyé.

VALEUR RENVOYÉE

aa_is_enabled En cas de succès, 1 est renvoyé. En cas d'erreur, 0 est renvoyé et errno(3) est défini de manière appropriée.

aa_find_mountpoint En cas de succès, zéro est renvoyé. En cas d'erreur, -1 est renvoyé et errno(3) est défini de manière appropriée.

ERREURS

aa_is_enabled

ENOSYS
Les extensions AppArmor pour le système ne sont pas disponibles.
ECANCELED
AppArmor est disponible sur le système mais a été désactivé au démarrage.
EBUSY
AppArmor est disponible mais uniquement via des interfaces privées.
ENOENT
AppArmor est disponible (et peut-être même applique des politiques) mais l'interface n'est pas disponible.
ENOMEM
Mémoire insuffisante disponible.
EPERM
N'avait pas les permissions suffisantes pour déterminer si AppArmor est activé.
EACCES
N'avait pas les permissions suffisantes pour déterminer si AppArmor est activé.
EBUSY
AppArmor est activé mais n'a pas accès aux interfaces partagées, et seules des interfaces privées sont disponibles.

aa_find_mountpoint

ENOMEM
Mémoire insuffisante disponible.
EACCES
L'accès aux chemins requis a été refusé.
ENOENT
Le montage du système de fichiers apparmor n'a pas pu être trouvé
