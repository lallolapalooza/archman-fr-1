NOM

aa-enforce - définir un profil de sécurité AppArmor en mode enforce (application) pour le sortir du mode désactivé ou du mode complain (plainte).

SYNOPIS

aa-enforce <exécutable> [<exécutable> ...] [-d /chemin/vers/profils] [--no-reload]

OPTIONS

-d --dir / chemin/vers/profils

Spécifie où chercher l'ensemble de profils de sécurité AppArmor.
Par défaut : /etc/apparmor.d.

--no-reload
Ne pas recharger le profil après sa modification.

DESCRIPTION

aa-enforce est utilisé pour définir un ou plusieurs profils en mode enforce. Cette commande n'est pertinente qu'en conjonction avec l'utilitaire aa-complain qui définit un profil en mode complain et l'utilitaire aa-disable qui décharge et désactive un profil. Le mode par défaut pour une politique de sécurité est enforce et l'utilitaire aa-complain doit être exécuté pour changer ce comportement.
