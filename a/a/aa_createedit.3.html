aa_createedit(3) Manuel des fonctions de bibliothèque aa_createedit(3)

NOM

aa_createedit - Éditeur de ligne interactif simple fourni comme fonction d'aide.

SYNTAXE

#include <aalib.h>

struct aa_edit *aa_createedit
(
aa_context *c,
int x,
int y,
int size,
char *s,
int maxsize
);

PARAMETRES

aa_context *c
Spécifie le contexte AA-lib sur lequel opérer.
int x
Coordonnée X du texte édité.
int y
Coordonnée Y du texte édité.
int size
Longueur de la fenêtre d'édition.
char *s
Tampon à éditer (contenant la valeur par défaut).
int maxsize
Taille du tampon.

DESCRIPTION

Vous pouvez utiliser cette fonction pour saisir des chaînes de caractères dans les programmes AA-lib. Cette fonction initialise la structure aa_edit utilisée par l'éditeur basé sur les événements. Vous pouvez ensuite appeler la fonction aa_editkey lorsqu'une touche est pressée.

VALEUR DE RETOUR

Pointeur vers le contexte d'édition en cas de succès et NULL en cas d'échec.
