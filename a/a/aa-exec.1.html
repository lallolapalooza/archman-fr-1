DESCRIPTIO

N

aa-exec est utilisé pour lancer un programme confiné par le profil et/ou l'espace de noms spécifié. Si à la fois un profil et un espace de noms sont spécifiés, la commande sera confinée par le profil dans le nouvel espace de noms de politique. Si seul un espace de noms est spécifié, le nom du profil du confinement actuel sera utilisé. Si ni un profil ni un espace de noms ne sont spécifiés, la commande sera exécutée en utilisant l'attachement standard des profils (c'est-à-dire comme si elle était exécutée sans la commande aa-exec)

.

Si les arguments doivent être transmis à la <commande> invoquée par aa-exec, alors -- doit être utilisé pour séparer les arguments de aa-exec de la commande.
aa-exec -

p profile1
-- ls -l

OPTIONS aa-exec accepte les arguments suivants

:
-p PROFIL,
--profile=PROFIL
confine <commande> avec PROFIL. Si le PROFIL n'est pas spécifié, utilise le nom du profil actuel (probablement unconfined)
.
-n ESPACE_DE_NOMS, --namespace=ESPACE_DE_N
OMS
utilise les profils dans ESPACE_DE_NOMS. Cela entraînera le passage du confinement à l'utilisation du nouvel espace de noms de
profils.
-i,
--immediate
passe au PROFIL avant d'exécuter <commande>. Cela soumet l'exécution de <commande> aux règles de transition d'exécution du profil
actuel.
-v,
--verbose
affiche les commandes
effectuées

--debug
affiche les commandes et les codes

-
Signale la fin des options et désactive le traitement ultérieur des options. Tout argument après le -- est traité comme un argument de la commande. Cela est utile lors du passage d'arguments à la <commande> invo
quée
par

RESTRICTION

S

aa-exec utilise aa_change_profile(3) pour changer le confinement de l'application. L'utilisation de aa_change_profile(3) peut être restreinte par la politique de manière à provoquer un échec ou des résultats différents de ceux

attendus.

Même en utilisant aa-exec depuis unconfined, les restrictions dans la politique peuvent provoquer un échec ou faire que le confinement entré soit différent de celui

demandé

Voir la documentation sur la restriction unpriviled unconfined pour plus de détails. https://gitlab.com/apparmor/apparmor/-/wikis/unprivileged_unconfined_restricti

EMPILEMEN

T

aa-exec peut être utilisé pour configurer une pile de profils comme confinement. Lorsqu'une application est confinée par une pile, tous les profils de la pile sont vérifiés comme s'ils étaient le profil confinant l'application. La médiation résultante est l'intersection de ce qui est autorisé par chaque profil de la

pile.

Les profils d'une pile sont traités indépendamment. Chaque profil peut avoir ses propres drapeaux et transitions de profil. Lors d'un exec, chaque profil spécifie sa transition et les résultats sont rassemblés pour former une nouvelle pile

canonisée.

Le séparateur de profil indiquant une pile est la séquence de caractères //&. Ainsi, une pile peut être exprimée en

utilisant 
$ aa-exec -p "unconfined//&firefox" -- bash
$ ps -Z
LABEL                               PID TTY
TIME CMD unconfined 30714 pts/12 00:00:00 bash firefox//&unconfined (u
nconfined) 31160 pts/12 00:00:00 bash firefox//&unconfined (unconfined) 31171 pts/12 00:00:00 ps

ESPACES DE

NOMS

aa-exec peut être utilisé pour entrer dans un confinement dans un autre espace de noms de politique si l'espace de noms de politique existe, est visible et si le profil existe dans l'espace de noms. Notez que les applications lancées dans l'espace de noms ne pourront pas en sortir et peuvent être restreintes par un confinement supplémentaire autour de l'espace de noms. Les fichiers et ressources visibles par le parent qui lance l'application peuvent ne pas être visibles dans l'espace de noms de politique, entraînant des refus

d'accès.

Pour entrer dans un espace de noms de politique, le profil est préfixé avec le nom de l'espace de noms, en utilisant un : en préfixe et en

suffixe.

Ex

. 
$ aa-exec -p :ex1:unconfined -- bash
$ ps -Z
LABEL                               PID TTY          TIME CMD
-                                 30714 pts/12   00:00:00 bash
unconfined                        34372 pts/12   00:00:00 bash
unconfined                        34379 pts/12   00:00:00
ps

Le confinement des processus en dehors de l'espace de noms peut ne pas être visible, auquel cas le confinement sera représenté par un -. Si la politique est empilée, seule une partie du confinement peut être visible. Cependant, le confinement est généralement entièrement visible depuis l'espace de noms de politique

parent.

Ex. le confinement de l'enfant peut être interrogé dans le parent pour

voir 
$ ps -Z 34372
LABEL                               PID TTY      STAT   TIME COMMAND
:ex1:unconfined                   34372 pts/12   S+     0:00
bash

Et dans le cas de l'empilement avec des espaces de

noms 
$ aa-exec -p "unconfined//&:ex1:unconfined" -- bash
$ ps -Z
LABEL                               PID TTY          TIME CMD
-                                 30714 pts/12   00:00:00 bash
unconfined                        36298 pts/12   00:00:00 bash
unconfined                        36305 pts/12   00:00:00
ps

tandis que depuis l'espace de noms parent, le confinement complet peut être

vu 
$ ps -Z 36298
LABEL
PID TTY STAT TIME COMMAND unconfined//&:ex
1:unconfined 36298 pts/12 S+ 0:00 bash
