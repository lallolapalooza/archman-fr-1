NOM

aa_autoinit - fonction d'initialisation simple pour AA-lib.

SYNTAXE

#include <aalib.h>

aa_context *aa_autoinit(const struct aa_hardware_params *params);

PARAMETRES

const struct aa_hardware_params *params
Paramètres matériels souhaités. Utilisez aa_defparams pour les valeurs par défaut.

DESCRIPTION

Tente de trouver un pilote de sortie disponible prenant en charge les paramètres spécifiés. Tente d'abord d'initialiser les pilotes recommandés, puis dans l'ordre les pilotes disponibles dans le tableau aa_drivers (tous les pilotes de sortie réguliers compilés dans AA-lib).

VALEUR DE RETOUR

Pointeur vers la structure de contexte initialisée en cas de succès, ou NULL en cas d'échec.
