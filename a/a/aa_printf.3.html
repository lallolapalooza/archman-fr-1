aa_printf(3)

Paquet: aalib

Licences: LGPL-2.0-or-later

aa_printf(3) Manuel des fonctions de bibliothèque aa_printf(3)

NOM

aa_printf - imprime du texte dans les tampons de sortie AA-lib.

SYNOPSIS

#include <aalib.h>

int aa_printf
(
aa_context *c,
int x,
int y,
enum aa_attribute attr,
const char *fmt,
...
);

PARAMÈTRES

aa_context *c
Spécifie le contexte AA-lib sur lequel opérer.
int x
Coordonnée X du premier caractère.
int y
Coordonnée Y du premier caractère.
enum aa_attribute attr
Attribut à utiliser.

Les valeurs possibles pour un enum aa_attribute sont les suivantes :

AA_NORMAL
Caractères normaux.
AA_DIM
Caractères sombres.
AA_BOLD
Caractères lumineux.
AA_BOLDFONT
Caractères rendus en police grasse.
AA_REVERSE
Caractères inversés (noir sur blanc).
AA_SPECIAL
Rend les caractères d'une manière facilement visible à l'écran. Le rendu exact dépend du pilote, mais ce mode devrait être utilisé pour afficher des textes que vous voulez rendre facilement visibles dans l'image.
const char *fmt
Texte à afficher au format printf standard.
...
Non documenté.

DESCRIPTION

Imprime le texte donné dans les tampons de sortie d'AA-lib. Pour voir l'effet, vous devez également appeler aa_flush.
