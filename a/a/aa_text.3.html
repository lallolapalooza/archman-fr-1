aa_text(3) Manuel des fonctions de bibliothèque aa_text(3)

NOM

aa_text - renvoie un pointeur vers le tampon de sortie texte utilisé par AA-lib.

SYNTAXE

#include <aalib.h>

char *aa_text(aa_context *a);

PARAMÈTRES

aa_context *a
Spécifie le contexte AA-lib sur lequel opérer.

DESCRIPTION

Le tampon de sortie texte est un simple tableau de caractères spécifiant la valeur ASCII des caractères. Le tableau est organisé en `aa_scrheight(a)` lignes de `aa_scrwidth(a)` caractères.

RETOURNE

Pointeur vers le tampon de sortie texte utilisé par AA-lib.
