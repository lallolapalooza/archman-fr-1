aa_policy_cache(3) AppArmor aa_policy_cache(3)

NOM

aa_policy_cache - un objet opaque représentant un cache de politiques AppArmor

aa_policy_cache_new - crée un nouvel objet aa_policy_cache à partir d'un chemin

aa_policy_cache_ref - incrémente le compteur de références d'un objet aa_policy_cache

aa_policy_cache_unref - décrémente le compteur de références et libère l'objet aa_policy_cache lorsque celui-ci atteint 0

aa_policy_cache_remove - supprime tous les fichiers de cache de politiques sous un chemin

aa_policy_cache_replace_all - effectue un remplacement des politiques dans le noyau pour toutes les politiques en cache

aa_policy_cache_dir_path - renvoie le chemin du répertoire aa_policy_cache

aa_policy_cache_dir_path_preview - renvoie un aperçu du chemin du répertoire aa_policy_cache sans objet aa_policy_cache existant

SYNOPSIS

#include <sys/apparmor.h>

typedef struct aa_policy_cache aa_policy_cache;

int aa_policy_cache_new(aa_policy_cache **policy_cache, aa_features *kernel_features, int dirfd, const char *path, uint16_t max_caches);

int aa_policy_cache_add_ro_dir(aa_policy_cache *policy_cache, int dirfd, const char *path);

aa_policy_cache *aa_policy_cache_ref(aa_policy_cache *policy_cache);

void aa_policy_cache_unref(aa_policy_cache *policy_cache);

int aa_policy_cache_remove(int dirfd, const char *path);

int aa_policy_cache_replace_all(aa_policy_cache *policy_cache, aa_kernel_interface *kernel_interface);

char *aa_policy_cache_dir_path(aa_policy_cache *policy_cache, int level);

char *aa_policy_cache_dir_path_preview(aa_features *kernel_features, int dirfd, const char *path);

Lier avec -lapparmor lors de la compilation.

DESCRIPTION

L'objet aa_policy_cache contient des informations sur un ensemble de fichiers de cache de politiques AppArmor. Les fichiers de cache de politiques sont la représentation binaire d'un profil AppArmor lisible par l'humain. La représentation binaire est la forme qui est chargée dans le noyau.

La fonction aa_policy_cache_new() crée un objet aa_policy_cache basé sur un descripteur de fichier de répertoire et un chemin. Voir la page man openat(2) pour des exemples de dirfd et de path. Le chemin doit pointer vers un répertoire et sera utilisé comme base pour l'emplacement des fichiers de cache de politiques. Voir aa_policy_cache_dir_path pour découvrir quel répertoire sera utilisé pour stocker les fichiers de cache de politiques binaires. Si des répertoires de cache superposés supplémentaires sont utilisés (voir aa_policy_cache_add_ro_dir), le répertoire spécifié dans aa_policy_cache_new est le premier répertoire recherché et est la couche superposée inscriptible. Si kernel_features est NULL, alors les fonctionnalités du noyau actuel sont utilisées. Lors de la spécification d'un objet valide kernel_features , celui-ci doit être compatible avec les fonctionnalités du noyau concerné. La valeur de max_caches doit être égale au nombre de caches qui doivent être autorisés avant que les anciens caches ne soient automatiquement purgés. La définition de ce qui est considéré comme un ancien cache est privée à libapparmor. Spécifier 0 signifie qu'aucun nouveau cache ne doit être créé et que seuls les caches existants et valides peuvent être utilisés. Spécifier UINT16_MAX signifie qu'un nouveau cache peut être créé et que le purgeage des anciens caches est désactivé. L'objet aa_policy_cache alloué doit être libéré à l'aide de aa_policy_cache_unref().

La fonction aa_policy_cache_add_ro_dir() ajoute un répertoire de cache existant au cache de politiques, en tant que couche en lecture seule sous le répertoire principal avec lequel le cache a été créé. Lorsque le cache est recherché pour un fichier de cache existant, le répertoire principal sera recherché, puis les répertoires en lecture seule dans l'ordre où ils ont été ajoutés au cache de politiques. Cela permet de pré-remplir le cache de politiques avec des politiques précompilées qui peuvent être mises à jour en superposant le fichier de cache en lecture seule avec un fichier écrit dans le répertoire de cache principal.

aa_policy_cache_ref() incrémente le compteur de références sur l'objet policy_cache .

aa_policy_cache_unref() décrémente le compteur de références sur l'objet policy_cache et libère toutes les ressources correspondantes lorsque le compteur de références atteint zéro.

La fonction aa_policy_cache_remove() supprime tous les fichiers de cache de politiques basés sur un descripteur de fichier de répertoire et un chemin. Le chemin doit pointer vers un répertoire. Voir la page man openat(2) pour des exemples de dirfd et de path.

La fonction aa_policy_cache_replace_all() peut être utilisée pour effectuer un remplacement des politiques pour toutes les politiques du cache dans le répertoire de cache représenté par l'objet policy_cache . Si kernel_interface est NULL, alors l'interface du noyau actuelle est utilisée. Lors de la spécification d'un objet valide kernel_interface , celui-ci doit être l'interface du noyau en cours d'exécution.

La fonction aa_policy_cache_dir_path() fournit le chemin du répertoire de cache pour un objet policy_cache au niveau dans la superposition de répertoires de cache du cache de politiques. Un niveau de 0 sera toujours présent et sera le premier répertoire à rechercher dans une superposition de répertoires de cache, et sera également la couche du répertoire de cache inscriptible. Les fichiers de cache de politiques binaires seront situés dans le répertoire renvoyé par cette fonction.

La fonction aa_policy_cache_dir_levels() fournit un accès au nombre de répertoires qui sont superposés pour créer le cache de politiques.

VALEUR RENVOYÉE

La fonction aa_policy_cache_new() renvoie 0 en cas de succès et *policy_cache pointera vers un objet aa_policy_cache qui doit être libéré par aa_policy_cache_unref(). -1 est renvoyé en cas d'erreur, avec errno défini de manière appropriée, et *policy_cache sera défini à NULL.

aa_policy_cache_ref() renvoie la valeur de policy_cache.

aa_policy_cache_remove() et aa_policy_cache_replace_all() renvoient 0 en cas de succès. -1 est renvoyé en cas d'erreur, avec errno défini de manière appropriée.

aa_policy_cache_dir_path() renvoie une chaîne de chemin qui doit être libérée par l'appelant. NULL est renvoyé en cas d'erreur, avec errno défini de manière appropriée.

aa_policy_cache_dir_levels() renvoie un nombre indiquant le nombre de niveaux de répertoires associés à policy_cache.

aa_policy_cache_dir_path_preview() est identique à aa_policy_cache_dir_path() sauf qu'il ne nécessite pas un objet existant aa_policy_cache . C'est utile si le programme appelant ne peut pas créer un objet aa_policy_cache en raison du manque de privilèges nécessaires pour créer le répertoire de cache.

ERREURS

La valeur errno sera définie en fonction de l'erreur sous-jacente dans la famille de fonctions aa_policy_cache qui renvoient -1 ou NULL en cas d'erreur.

NOTES

Toutes les fonctions aa_policy_cache décrites ci-dessus, à l'exception de aa_policy_cache_dir_path() , ont été ajoutées dans la version 2.13 de libapparmor. Toutes les autres fonctions aa_policy_cache décrites ci-dessus sont présentes dans la version 2.10 de libapparmor.

aa_policy_cache_unref() enregistre la valeur de errno lors de l'appel et restaure errno avant de sortir dans les versions 2.12 et ultérieures de libapparmor.

BOGUES
