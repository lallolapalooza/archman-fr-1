NOM

aa-cleanprof - nettoyer un profil de sécurité AppArmor existant.

SYNTAXE

aa-cleanprof <exécutable> [<exécutable> ...] [-d /chemin/vers/profils] [--no-reload] [-s]

OPTIONS

-d --dir /chemin/vers/profils

Spécifie où rechercher l'ensemble des profils de sécurité AppArmor.
Par défaut : /etc/apparmor.d.

--no-reload
Ne pas recharger le profil après modification.

-s --silent

Écrase silencieusement le profil sans demander à l'utilisateur.

DESCRIPTION

aa-cleanprof est utilisé pour effectuer un nettoyage sur un ou plusieurs profils. L'outil supprime toutes les règles superflues existantes (règles couvertes par une inclusion ou une autre règle), réorganise les règles pour regrouper les règles similaires et supprime tous les commentaires du fichier.

BOGUES

Si vous trouvez des bogues, veuillez les signaler sur https://gitlab.com/apparmor/apparmor/-/issues.

VOIR AUSSI
