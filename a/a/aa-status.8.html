NOM

aa-status - affiche diverses informations sur la politique AppArmor actuelle.

SYNTAXE

aa-status [option]

DESCRIPTION

aa-status rapportera divers aspects de l'état actuel du confinement d'AppArmor. Par défaut, il affiche les mêmes informations que si l'argument --verbose était donné. Un exemple de ce à quoi cela ressemble est :

le module apparmor est chargé.
110 profils sont chargés.
102 profils sont en mode enforce.
8 profils sont en mode complain.
Sur 129 processus en cours d'exécution :
13 processus ont des profils définis.
8 processus ont des profils en mode enforce.
5 processus ont des profils en mode complain.

D'autres options d'arguments sont fournies pour rapporter des aspects individuels, afin de supporter leur utilisation dans des scripts.

OPTIONS

aa-status n'accepte qu'un seul argument à la fois parmi les suivants :

--enabled
retourne une erreur si AppArmor n'est pas activé.
--profiled
affiche le nombre de politiques AppArmor chargées.
--enforced
affiche le nombre de politiques AppArmor en mode enforce chargées.
--complaining
affiche le nombre de politiques AppArmor en mode complain chargées.
--kill
affiche le nombre de politiques AppArmor en mode enforce chargées qui tueront les tâches lors de violations de politique.
--prompt
affiche le nombre de politiques AppArmor en mode enforce chargées, avec un retour à la médiation par l'espace utilisateur.
--special-unconfined
affiche le nombre de politiques AppArmor en mode non-enforce chargées qui sont dans le mode spécial non confiné.
--process-mixed affiche le nombre de processus confinés par des piles de profils avec des profils dans différents modes.
--verbose
affiche plusieurs points de données sur l'ensemble des politiques AppArmor chargées (l'action par défaut si aucun argument n'est donné).
--json
affiche plusieurs points de données sur l'ensemble des politiques AppArmor chargées dans un format JSON, adapté à la consommation par machine.
--pretty-json
identique à --json, formaté pour être lisible par les humains ainsi que par les machines.
--show
sur quels ensembles de données afficher des informations. Actuellement processes, profiles, all pour les processus et les profils. La valeur par défaut est all.
--count
affiche uniquement les décomptes pour les informations sélectionnées.
--filter.mode=filter
Permet de spécifier un filtre d'expression régulière POSIX qui sera appliqué aux processus et aux profils affichés en mode de profil apparmor, réduisant la sortie.
--filter.profiles=filter
Permet de spécifier un filtre d'expression régulière POSIX qui sera appliqué aux profils de confinement des processus et des profils affichés, réduisant la sortie.
--filter.pid=filter
Permet de spécifier un filtre d'expression régulière POSIX qui sera appliqué aux processus affichés, de sorte que seuls les PID des processus correspondant à l'expression seront affichés.
--filter.exe=filter
Permet de spécifier un filtre d'expression régulière POSIX qui sera appliqué aux processus affichés, de sorte que seuls les noms exécutables des processus correspondant à l'expression seront affichés.
--help
affiche une brève description d'utilisation.

STATUT DE SORTIE

À la sortie, aa-status définira son statut de sortie aux valeurs suivantes :

0
si apparmor est activé et la politique est chargée.
1
si apparmor n'est pas activé/chargé.
2
si apparmor est activé mais aucune politique n'est chargée.
3
si les fichiers de contrôle d'apparmor ne sont pas disponibles sous /sys/kernel/security/.
4
si l'utilisateur exécutant le script n'a pas les privilèges suffisants pour lire les fichiers de contrôle d'apparmor.
42
si une erreur interne s'est produite.

BOGUES

aa-status doit être exécuté en tant que root pour lire l'état de la politique chargée à partir du module apparmor. Il utilise le système de fichiers /proc pour déterminer quels processus sont confinés et est donc susceptible aux conditions de concurrence.

Si vous trouvez d'autres bogues, veuillez les signaler sur https://gitlab.com/apparmor/apparmor/-/issues.

VOIR AUSSI

apparmor(7), apparmor.d(5), et https://wiki.apparmor.net.
