DESCRIPTIO

N

objdump affiche les informations concernant un ou plusieurs fichiers objet. Les options permettent de contrôler quelles informations particulières afficher. Ces informations sont principalement utiles aux programmeurs qui travaillent sur les outils de compilation, par opposition aux programmeurs qui veulent simplement que leur programme se compile et

fonctionne.

objfile... sont les fichiers objet à examiner. Lorsque vous spécifiez des archives, objdump affiche les informations sur c

hacun des fichiers
objet membres.

Affiche les entrées de la table des symboles du fichier. C'est similaire aux informations fournies par le programme nm, bien que le format d'affichage soit différent. Le format de la sortie dépend du format du fichier analysé, mais il y a deux types principaux. L'un ressemble à ceci : 
[  4](sec  3)(fl 0x00)(ty   0)(scl   3) (nx 1) 0x00000000 .bss
[  6](sec  1)(fl 0x00)(ty   0)(scl   2) (nx 0) 0x00000000
fred

où le nombre entre crochets est le numéro de l'entrée dans la table des symboles, le numéro sec est le numéro de section, le valeur fl sont les bits de drapeau du symbole, le ty numéro est le type du symbole, le numéro scl est la classe de stockage du symbole et le valeur nx est le nombre d'entrées auxiliaires associées au symbole. Les deux derniers champs sont la valeur du symbole et son

nom.

L'autre format de sortie courant, généralement observé avec les fichiers basés sur ELF, ressemble

à ceci : 
00000000 l    d  .bss   00000000 .bss
00000000 g       .text  00000000
fred

Ici, le premier nombre est la valeur du symbole (parfois appelée son adresse). Le champ suivant est en fait un ensemble de caractères et d'espaces indiquant les bits de drapeau activés sur le symbole. Ces caractères sont décrits ci-dessous. Ensuite vient la section avec laquelle le symbole est associé, ou *ABS* si la section est absolue (c'est-à-dire non liée à aucune section), ou *UND* si la section est référencée dans le fichier analysé, mais pas définie

là.

Après le nom de section vient un autre champ, un nombre, qui pour les symboles communs est l'alignement et pour les autres symboles est la taille. Enfin, le nom du symbole est

affiché.
