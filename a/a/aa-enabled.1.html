NOM

aa-enabled - teste si AppArmor est activé

SYNTAXE

aa-enabled [options]

DESCRIPTION

aa-enabled est utilisé pour déterminer si AppArmor est activé.

OPTIONS

aa-enabled accepte les arguments suivants :

-h, --help
Affiche un bref guide d'utilisation.
-q, --quiet
Ne rien afficher sur la sortie standard. Cette option est destinée à être utilisée par des scripts qui souhaitent simplement utiliser le code de sortie pour déterminer si AppArmor est activé.
-x, --exclusive
Exige qu'AppArmor ait un accès exclusif aux interfaces LSM partagées pour être considéré comme activé.

STATUT DE SORTIE

Lors de sa sortie, aa-enabled définira son statut de sortie aux valeurs suivantes :

0
si AppArmor est activé.
1
si AppArmor n'est pas activé/chargé.
2
intentionnellement non utilisé comme statut de sortie pour aa-enabled.
3
si les fichiers de contrôle AppArmor ne sont pas disponibles sous /sys/kernel/security/.
4
si aa-enabled n'a pas les privilèges suffisants pour lire les fichiers de contrôle apparmor.
10
AppArmor est activé mais n'a pas accès aux interfaces LSM partagées.
64
si une erreur ou une condition inattendue est rencontrée.

BOGUES

Si vous trouvez des bugs, veuillez les signaler sur https://gitlab.com/apparmor/apparmor/-/issues.

VOIR AUSSI

apparmor(7), apparmor.d(5), aa_is_enabled(2), et https://wiki.apparmor.net.
