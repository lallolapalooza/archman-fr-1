NOM

aa-remove-unknown - supprimer les profils AppArmor inconnus

SYNTAXE

aa-remove-unknown [option]

DESCRIPTION

aa-remove-unknown inventorie tous les profils dans /etc/apparmor.d/, compare cette liste aux profils actuellement chargés dans le noyau, puis supprime tous les profils chargés qui n'ont pas été trouvés dans /etc/apparmor.d/. Il affiche également le nom de chaque profil qu'il supprime sur la sortie standard.

OPTIONS

-h, --help
affiche une courte déclaration d'utilisation.
-n
test à blanc ; n'affiche que les noms des profils qui seraient supprimés

EXEMPLES

$ sudo ./aa-remove-unknown -n
Would remove 'test//null-/usr/bin/whoami'
Would remove 'test'
$ sudo ./aa-remove-unknown
Removing 'test//null-/usr/bin/whoami'
Removing 'test'
