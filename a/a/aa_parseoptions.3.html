aa_parseoptions(3) Manuel des fonctions de bibliothèque aa_parseoptions(3)

NOM

aa_parseoptions - analyser les options de ligne de commande standard utilisées par AA-lib.

SYNTAXE

#include <aalib.h>

int aa_parseoptions
(
struct aa_hardware_params *p,
aa_renderparams *r,
int *argc,
char **argv
);

PARAMETRES

struct aa_hardware_params *p
Structure des paramètres matériels à modifier. On s'attend à ce que cette structure, modifiée uniquement des modifications nécessaires, soit utilisée ultérieurement pour initialiser le contexte d'AA-lib.
aa_renderparams *r
Structure des paramètres de rendu à modifier. On s'attend à ce que cette structure, modifiée uniquement des modifications nécessaires, soit utilisée ultérieurement pour le rendu d'images.
int *argc
Pointeur vers le paramètre argc passé à la fonction "main".
char **argv
Pointeur vers le paramètre argv passé à la fonction "main".

DESCRIPTION

Utilisez cette fonction pour analyser les options de ligne de commande standard utilisées par AA-lib. Chaque programme AA-lib devrait appeler cette fonction pour permettre à l'utilisateur de spécifier des paramètres supplémentaires. La fonction modifie les structures aa_hardware_params et aa_renderparams et supprime les options connues des listes argc/argv. Elle analyse également la variable d'environnement AAOPTS. Lors de l'appel avec NULL pour les paramètres argc/argv, elle analyse uniquement AAOPTS. Au moins cet appel devrait être présent dans chaque programme AA-lib.

RETOURNE

1 en cas de succès et 0 en cas d'échec. Le programme peut alors afficher le texte d'aide disponible dans la variable aa_help.
