Empiler des profils ensemble est souhaitable lorsque l'on veut s'assurer que le confinement ne deviendra jamais plus permissif. Lors du changement entre deux profils, comme effectué avec aa_change_profile(2), il y a toujours la possibilité que le nouveau profil soit plus permissif que l'ancien profil, mais cette possibilité est éliminée lors de l'utilisation de aa_stack_profile(). static void read_passwd()
{
        int fd;
        char buf[10];
        if ((fd=open("/etc/passwd", O_RDONLY)) < 0) {
               perror("Failure opening /etc/passwd");
               _exit(1);
        }
        /* Verify that we can read /etc/passwd */
        memset(&buf, 0, 10);
        if (read(fd, &buf, 10) == -1) {
                perror("Failure reading /etc/passwd");
                _exit(1);
        }
        buf[9] = '\0';
        printf("/etc/passwd: %s\n", buf);
        close(fd);
}
