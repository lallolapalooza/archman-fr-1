aa_kernel_interface(3)

Paquet: apparmor

Licences: GPL-2.0-only, LGPL-2.0-only, LGPL-2.1-only

aa_kernel_interface(3) AppArmor aa_kernel_interface(3)

NOM

aa_kernel_interface - un objet opaque représentant l'interface noyau AppArmor pour le chargement, le remplacement et la suppression des politiques

aa_kernel_interface_new - crée un nouvel objet aa_kernel_interface à partir d'un chemin optionnel

aa_kernel_interface_ref - incrémente le compteur de références d'un objet aa_kernel_interface

aa_kernel_interface_unref - décrémente le compteur de références et libère l'objet aa_kernel_interface lorsque celui-ci atteint 0

aa_kernel_interface_load_policy - charge une politique depuis un tampon dans le noyau

aa_kernel_interface_load_policy_from_file - charge une politique depuis un fichier dans le noyau

aa_kernel_interface_load_policy_from_fd - charge une politique depuis un descripteur de fichier dans le noyau

aa_kernel_interface_replace_policy - remplace une politique dans le noyau par une politique issue d'un tampon

aa_kernel_interface_replace_policy_from_file - remplace une politique dans le noyau par une politique issue d'un fichier

aa_kernel_interface_replace_policy_from_fd - remplace une politique dans le noyau par une politique issue d'un descripteur de fichier

aa_kernel_interface_remove_policy - supprime une politique du noyau

aa_kernel_interface_write_policy - écrit une politique dans un descripteur de fichier

SYNTAXE

#include <sys/apparmor.h>

typedef struct aa_kernel_interface aa_kernel_interface;

int aa_kernel_interface_new(aa_kernel_interface **kernel_interface, aa_features *kernel_features, const char *apparmorfs);

aa_kernel_interface *aa_kernel_interface_ref(aa_kernel_interface *kernel_interface);

void aa_kernel_interface_unref(aa_kernel_interface *kernel_interface);

int aa_kernel_interface_load_policy(aa_kernel_interface *kernel_interface, const char *buffer, size_t size);

int aa_kernel_interface_load_policy_from_file(aa_kernel_interface *kernel_interface, int dirfd, const char *path);

int aa_kernel_interface_load_policy_from_fd(aa_kernel_interface *kernel_interface, int fd);

int aa_kernel_interface_replace_policy(aa_kernel_interface *kernel_interface, const char *buffer, size_t size);

int aa_kernel_interface_replace_policy_from_file(aa_kernel_interface *kernel_interface, int dirfd, const char *path);

int aa_kernel_interface_replace_policy_from_fd(aa_kernel_interface *kernel_interface, int fd);

int aa_kernel_interface_remove_policy(aa_kernel_interface *kernel_interface, const char *fqname);

int aa_kernel_interface_write_policy(int fd, const char *buffer, size_t size);

Liez avec -lapparmor lors de la compilation.

DESCRIPTION

L'objet aa_kernel_interface contient des informations sur l'interface noyau AppArmor pour le chargement, le remplacement et la suppression des politiques.

La fonction aa_kernel_interface_new() crée un objet aa_kernel_interface basé sur un objet aa_features optionnel et un chemin optionnel vers le répertoire apparmor de securityfs, généralement trouvé à "/sys/kernel/security/apparmor/". Si kernel_features est NULL, les fonctionnalités du noyau actuel sont utilisées. Lors de la spécification d'un objet kernel_features valide, il doit être compatible avec les fonctionnalités du noyau en cours d'exécution. Si apparmorfs est NULL, l'emplacement par défaut est utilisé. L'objet alloué kernel_interface doit être libéré à l'aide de aa_kernel_interface_unref().

aa_kernel_interface_ref() incrémente le compteur de références de l'objet kernel_interface.

aa_kernel_interface_unref() décrémente le compteur de références de l'objet kernel_interface et libère toutes les ressources correspondantes lorsque le compteur de références atteint zéro.

La famille de fonctions aa_kernel_interface_load() charge une politique dans le noyau. L'opération échouera si une politique du même nom est déjà chargée. Utilisez la famille de fonctions aa_kernel_interface_replace() si vous souhaitez remplacer une politique précédemment chargée par une nouvelle politique du même nom. Les fonctions aa_kernel_interface_replace() peuvent également être utilisées pour charger une politique qui ne correspond pas à une politique précédemment chargée.

Lors du chargement ou du remplacement à partir d'un tampon, le buffer contiendra des données binaires. L'argument size doit spécifier la taille de l'argument buffer.

Lors du chargement ou du remplacement à partir d'un fichier, la combinaison dirfd et path est utilisée pour spécifier l'emplacement du fichier. Voir la page de manuel de openat(2) pour des exemples de dirfd et path.

Il est également possible de charger ou de remplacer à partir d'un descripteur de fichier spécifié par l'argument fd. Le fichier doit être ouvert en lecture et le décalage du fichier doit être correctement défini.

La fonction aa_kernel_interface_remove_policy() peut être utilisée pour décharger une politique précédemment chargée. Le nom complet de la politique doit être spécifié avec l'argument fqname. L'opération échouera si une politique correspondant à fqname n'est pas trouvée.

La fonction aa_kernel_interface_write_policy() permet d'écrire une politique, stockée dans buffer et composée de size octets, dans un descripteur de fichier. Le fd doit être ouvert en écriture et le décalage du fichier doit être correctement défini.

VALEUR DE RETOUR

La fonction aa_kernel_interface_new() retourne 0 en cas de succès et *kernel_interface pointera vers un objet aa_kernel_interface qui doit être libéré par aa_kernel_interface_unref(). -1 est retourné en cas d'erreur, avec errno défini de manière appropriée, et *kernel_interface sera mis à NULL.

aa_kernel_interface_ref() retourne la valeur de kernel_interface.

Les fonctions de la famille aa_kernel_interface_load(), les fonctions de la famille aa_kernel_interface_replace(), aa_kernel_interface_remove() et aa_kernel_interface_write_policy() retournent 0 en cas de succès. -1 est retourné en cas d'erreur, avec errno défini de manière appropriée.

ERREURS

La valeur errno sera définie conformément à l'erreur sous-jacente dans la famille de fonctions aa_kernel_interface qui retournent -1 en cas d'erreur.

NOTES

Toutes les fonctions aa_kernel_interface décrites ci-dessus sont présentes dans libapparmor version 2.10 et plus récentes.

aa_kernel_interface_unref() sauvegarde la valeur de errno lors de son appel et restaure errno avant de se terminer dans libapparmor version 2.12 et plus récentes.

BOGUES

VOIR AUSSI
