DESCRIPTIO

N

« gprof » produit un profil d'exécution des programmes C, Pascal ou Fortran77. L'effet des routines appelées est incorporé dans le profil de chaque appelant. Les données de profil sont prises dans le fichier de profil du graphe d'appels (gmon.out par défaut) qui est créé par les programmes compilés avec l'option -pg de « cc », « pc » et « f77 ». L'option -pg lie également les versions des routines de bibliothèque compilées pour le profilage. « Gprof » lit le fichier objet donné (par défaut « a.out ») et établit la relation entre sa table de symboles et le profil du graphe d'appels à partir de gmon.out. Si plus d'un fichier de profil est spécifié, la sortie de « gprof » affiche la somme des informations de profil des fichiers de profil

donnés.

« Gprof » calcule le temps passé dans chaque routine. Ensuite, ces temps sont propagés le long des arêtes du graphe d'appels. Les cycles sont découverts, et les appels vers un cycle se partagent le temps du

cycle.

Plusieurs formes de sortie sont disponibles à partir de

l'analyse.

Le profil plat montre combien de temps votre programme a passé dans chaque fonction, et combien de fois cette fonction a été appelée. Si vous voulez simplement savoir quelles fonctions consomment la plupart des cycles, c'est indiqué ici de manière

concise.

Le graphe d'appels montre, pour chaque fonction, quelles fonctions l'ont appelée, quelles autres fonctions elle a appelées, et combien de fois. Il y a aussi une estimation du temps passé dans les sous-routines de chaque fonction. Cela peut suggérer des endroits où vous pourriez essayer d'éliminer des appels de fonctions qui consomment beaucoup de

temps.

Le listing de source annoté est une copie du code source du programme, étiq

uetée avec le nombre de fois où chaque
ligne du programme a été exécutée.

OPTION

S

Ces options spécifient lequel des formats de sortie « gprof » doit

produire.

Beaucoup de ces options prennent un symspec optionnel pour spécifier les fonctions à inclure ou à exclure. Ces options peuvent être spécifiées plusieurs fois, avec différents symspecs, pour inclure ou exclure des ensembles de

symboles.

Spécifier l'une de ces options remplace la valeur par défaut (-p -q), qui imprime un profil plat et une analyse du graphe d'appels pour toutes les

fonctions.

] »
« --annotated-source[=symspec
] »

correspondants.

« --brief 
»
Si l'option -b est donnée, « gprof » n'imprime pas les longues explications verboses qui tentent d'expliquer la signification de tous les champs des tableaux. C'est utile si vous prévoyez d'imprimer la sortie, ou si vous en avez assez de voir ces
explications.

Si le fichier de données de profil contient des enregistrements de comptage de blocs de base, spécifier l'option -l, avec -C, fera que les comptages d'exécution

L'option -P fait que « gprof » supprime l'impression d'un profil plat. Si symspec est spécifié, « gprof » imprime un profil plat, mais exclut les symboles

ANOMALIE

S

La granularité de l'échantillonnage est affichée, mais reste statistique au mieux. Nous supposons que le temps pour chaque exécution d'une fonction peut être exprimé par le temps total pour la fonction divisé par le nombre de fois où la fonction est appelée. Ainsi, le temps propagé le long des arcs du graphe d'appels vers les parents de la fonction est directement proportionnel au nombre de fois où cet arc est

parcouru.

Les parents qui ne sont pas eux-mêmes profilés verront le temps de leurs enfants profilés leur être propagé, mais ils apparaîtront comme invoqués spontanément dans la liste du graphe d'appels, et leur temps ne sera pas propagé plus loin. De même, les capteurs de signaux, même profilés, apparaîtront comme spontanés (bien que pour des raisons plus obscures). Tous les enfants profilés des capteurs de signaux devraient voir leurs temps correctement propagés, sauf si le capteur de signal a été invoqué pendant l'exécution de la routine de profilage, auquel cas tout est perdu. Le programme profilé doit appeler "exit"(2) ou retourner normalement pour que les informations de profilage soient enregistrées

dans le
fichier

gmon.

out.
