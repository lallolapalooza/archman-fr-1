App::ClusterSSH::Host(3pm) Documentation Perl fournie par l'utilisateur App::ClusterSSH::Host(3pm)

SYNTAXE

use ClusterSSH::Host;
my $host = ClusterSSH::Host->new({
    hostname => 'nom_hote',
});
my $host = ClusterSSH::Host->parse_host_string('nom_utilisateur@nom_hote:1234');

DESCRIPTION

Représente un hôte. Inclut les détails pour contacter l'hôte tels que le nom d'hôte/l'adresse IP, le nom d'utilisateur et le port.

MÉTHODES

$host=ClusterSSH::Host->new ({ hostname => 'nom_hote' })
Crée un nouvel objet hôte. 'hostname' est un argument requis, 'username' et 'port' sont optionnels. Lève une exception en cas d'erreur.
$host->get_hostname
$host->get_username
$host->get_port
$host->get_master
$host->get_geometry
$host->get_type
Retourne des détails spécifiques sur l'hôte.
$host->set_username
$host->set_port
$host->set_master
$host->set_geometry
$host->set_type
Définit des détails spécifiques sur l'hôte après sa création.
get_realname
Si le nom du serveur fourni n'est pas une adresse IP (IPv4 ou IPv6), tente de le résoudre et retourne les noms découverts.
get_givenname
Alias de get_hostname, à utiliser lorsque " get_realname " pourrait retourner quelque chose de différent.
parse_host_string
Étant donné une chaîne représentant un hôte, retourne un objet hôte. Analyse des hôtes tels que
check_ssh_hostname
Vérifie le nom d'hôte de l'objet pour voir s'il peut être configuré dans le fichier de configuration $HOME/.ssh/config de l'utilisateur.
read_ssh_file
Méthode pour faciliter la lecture des fichiers de configuration ssh. Utilisée pour récupérer les noms d'hôtes pour la validation lorsqu'elle est utilisée dans des clusters.
host
192.168.0.1
user@host
user@192.168.0.1
host:port
[1234:1234:1234::4567]:port
1234:1234:1234::4567

et ainsi de suite. Gère les adresses IPv4 et IPv6 - émet un avertissement si l'adresse IPv6 est ambiguë (c'est-à-dire dans le dernier exemple, la partie 4567 fait-elle partie de l'adresse IPv6 ou d'une définition de port ?) et suppose qu'elle fait partie de l'adresse. Utilise des crochets pour éviter l'avertissement.
