NOM

AppConfig::Getopt - Module Perl5 pour le traitement des arguments de ligne de commande par délégation à Getopt::Long.

SYNOPSIS

use AppConfig::Getopt;
my $state  = AppConfig::State->new(\%cfg);
my $getopt = AppConfig::Getopt->new($state);
$getopt->parse(\@args);            # lire les arguments

APERÇU

AppConfig::Getopt est un module Perl5 qui délègue au module Getopt::Long de Johan Vroman pour analyser les arguments de ligne de commande et mettre à jour les valeurs dans un objet AppConfig::State en conséquence.

AppConfig::Getopt est distribué dans le cadre du bundle AppConfig.

DESCRIPTION

UTILISATION DU MODULE AppConfig::Getopt

Pour importer et utiliser le module AppConfig::Getopt, la ligne suivante doit apparaître dans votre script Perl :

use AppConfig::Getopt;

AppConfig::Getopt est utilisé automatiquement si vous utilisez le module AppConfig et créez un objet AppConfig::Getopt via la méthode getopt().

AppConfig::Getopt est implémenté à l'aide de méthodes orientées objet. Un nouvel objet AppConfig::Getopt est créé et initialisé en utilisant la méthode new(). Celle-ci retourne une référence à un nouvel objet AppConfig::Getopt. Une référence à un objet AppConfig::State doit être passée comme premier paramètre :

my $state  = AppConfig::State->new();
my $getopt = AppConfig::Getopt->new($state);

Ceci créera et retournera une référence à un nouvel objet AppConfig::Getopt.

ANALYSE DES ARGUMENTS DE LIGNE DE COMMANDE

La méthode parse() est utilisée pour lire une liste d'arguments de ligne de commande et mettre à jour l'état en conséquence.

Le(s) premier(s) paramètre(s) (non-référence de liste) peuvent contenir un certain nombre de chaînes de configuration à passer à Getopt::Long::Configure. Une référence à une liste d'arguments peut être passée en plus ou @ARGV est utilisé par défaut.

$getopt->parse();                       # utilise @ARGV
$getopt->parse(\@myargs);
$getopt->parse(qw(auto_abbrev debug));  # utilise @ARGV
$getopt->parse(qw(debug), \@myargs);

Voir Getopt::Long pour les détails des options de configuration disponibles.

Une chaîne de spécification Getopt::Long est construite pour chaque variable définie dans AppConfig::State. Elle se compose du nom, des alias éventuels et de la valeur ARGS pour la variable.

Ces chaînes de spécification sont ensuite passées à Getopt::Long, les arguments sont analysés et les valeurs dans AppConfig::State sont mises à jour.

Voir AppConfig pour des informations sur l'utilisation du module AppConfig::Getopt via la méthode getopt().
