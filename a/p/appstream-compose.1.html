NOM

appstream-compose - Génère les métadonnées AppStream

SYNOPSIS

appstream-compose [OPTION...]

DESCRIPTION

Cette page de manuel documente brièvement la commande appstream-compose.

appstream-compose est une application simple qui prend un préfixe (par défaut /usr) et un ensemble de noms d'applications. Elle recherche les fichiers appdata, metainfo, desktop et icon portant ce nom de base dans $prefix/share/[appdata|metainfo|applications|icons] et génère des fichiers xml appstream et des icônes dans (par défaut) $prefix/share/app-info.
