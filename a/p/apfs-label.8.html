NOM

apfs-label - lister les étiquettes de tous les volumes d'un système de fichiers APFS

SYNTAXE

apfs-label périphérique

DESCRIPTION

apfs-label est un outil simple qui liste l'index et l'étiquette de tous les volumes d'un conteneur APFS, pour aider l'utilisateur à décider lequel monter avec le pilote.

OPTIONS

-v
Afficher le numéro de version de apfs-label et quitter.
