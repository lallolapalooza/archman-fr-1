App::CLI::Command(3) Documentation Perl fournie par l'utilisateur App::CLI::Command(3)

NOM

App::CLI::Command - Classe de base pour les commandes App::CLI

SYNOPSIS

package MyApp::List;
use base qw(App::CLI::Command);
use constant options => (
    'verbose'   => 'verbose',
    'n|name=s'  => 'name',
);
sub run {
    my ( $self, $arg ) = @_;
    print "verbose" if $self->{verbose};
    my $name = $self->{name}; # obtenir l'argument suivant l'option longue --name
    # tout ce que vous voulez que cette commande fasse
}
# Voir App::CLI pour des informations sur la façon d'appeler (sous)commandes.

DESCRIPTION

subcommand()

retourne l'ancienne sous-commande de genre de $self;

cascading()

Retourne l'instance de la sous-commande en cascade appelée si elle était listée dans vos sous-commandes constantes.

cascadable()

Retourne le nom du paquet de la sous-commande si la sous-commande appelée est dans vos sous-commandes constantes, sinon retourne "undef".

app

Retourne l'objet faisant référence à l'application actuelle.

brief_usage ($file)

Affiche une brève utilisation de l'objet commande sur une seule ligne. Optionnellement, un fichier peut être donné pour extraire l'utilisation du POD.

usage ($want_detail)

Affiche l'utilisation. Si $want_detail est vrai, la section "DESCRIPTION" est également affichée.

loc_text $text

Localise le corps du texte (formaté) dans $text et retourne la version localisée.

filename

Retourne le nom du fichier pour le module de commande.

VOIR AUSSI

App::CLI, Getopt::Long
