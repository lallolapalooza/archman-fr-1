NOM

apk manifest - Afficher les sommes de contrôle du contenu des paquets

SYNTAXE

apk manifest [<options>...] paquets...

DESCRIPTION

apk manifest affiche les sommes de contrôle des fichiers dans les paquets listés. Un fichier est affiché par ligne, la somme de contrôle en premier, suivie d'un espace, puis du chemin d'accès au fichier.

La somme de contrôle elle-même est affichée dans le format algorithme:hachage. Les algorithmes pris en charge sont :

  • md5
  • sha1

sha1 est utilisé pour les nouveaux paquets.

OPTIONS

apk manifest ne prend en charge aucune option spécifique. Voir apk(8) pour les options globales.
