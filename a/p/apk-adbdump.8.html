NOM

apk adbdump - vider les fichiers v3 dans leur représentation textuelle

SYNTAXE

apk adbdump [<options>...] fichiers...

DESCRIPTION

apk adbdump videra la partie métadonnées des fichiers spécifiés (paquets, index, base de données installée) vers sa représentation textuelle.

La sortie peut être :

  • yaml avec les annotations en commentaire
  • flux de données json

apk-adbgen(8) peut convertir la représentation textuelle YAML en format binaire avec certaines limitations (les blocs ADB et DATA imbriqués ne sont pas pris en charge).

OPTIONS

--format FORMAT

Spécifie le format de sortie (options : json, yaml)

VOIR AUSSI

apk-adbgen(8), apk-package(5), apk-v3(5)
