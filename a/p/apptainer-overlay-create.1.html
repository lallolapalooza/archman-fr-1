NOM

apptainer-overlay-create - Crée une image de superposition EXT3 inscriptible

SYNTAXE

apptainer overlay create image

DESCRIPTION

La commande apptainer overlay create permet de créer une image de superposition EXT3 inscriptible, soit
sous forme d'image EXT3 unique, soit en l'ajoutant automatiquement à une image SIF existante.

OPTIONS

--create-dir=[] répertoire à créer dans le cadre de la structure de la superposition

-f, --fakeroot[=false] rend la structure de la superposition utilisable par les actions exécutées avec --fakeroot

-h, --help[=false] aide pour create

-s, --size=64 taille de la superposition inscriptible EXT3 en Mio

-S, --sparse[=false] crée une superposition éparse

EXEMPLE

  Pour créer et ajouter une superposition inscriptible à une image SIF existante :
  $ apptainer overlay create --size 1024 /tmp/image.sif
  Pour créer une image de superposition EXT3 inscriptible unique :
  $ apptainer overlay create --size 1024 /tmp/my_overlay.img
  Pour créer une superposition éparse lors de la création d'une nouvelle image de système de fichiers ext3 :
  $ apptainer overlay create --size 1024 --sparse /tmp/ext3_overlay.img
  Pour créer une image de superposition EXT3 inscriptible à utiliser avec les actions --fakeroot :
  $ apptainer overlay create --fakeroot --size 1024 /tmp/my_overlay.img
