SYNOPSIS

DESCRIPTION

Représente la configuration de l'application

METHODS

$cluster=ClusterSSH::Cluster->new();
Crée un nouvel objet. L'objet doit être commun à toutes les invocations.
$cluster->get_cluster_entries($filename);
Lit les fichiers /etc/clusters, $HOME/.clusterssh/clusters et tout autre nom de fichier donné, puis enregistre les étiquettes trouvées.
@external_tags=list_external_clusters()
Appelle un script externe en utilisant "-L" pour lister les étiquettes disponibles
@resolved_tags=get_external_clusters(@tags)
Utilise un script externe pour résoudre les @tags en noms d'hôtes.
$cluster->get_tag_entries($filename);
Lit les fichiers /etc/tags, $HOME/.clusterssh/tags et tout autre nom de fichier donné, puis enregistre les étiquettes trouvées.
$cluster->read_cluster_file($filename);
Lit le fichier cluster donné et enregistre les étiquettes trouvées.
$cluster->expand_filename($filename);
Développe ~ ou $HOME dans un nom de fichier.
$cluster->read_tag_file($filename);
Lit le fichier tag donné et enregistre les étiquettes trouvées.
$cluster->register_tag($tag,@hosts);
Enregistre le nom de l'étiquette donné avec les noms d'hôtes donnés.
$cluster->register_host($host,@tags);
Enregistre l'hôte donné sur les étiquettes fournies.
@entries = $cluster->get_tag('tag');
$entries = $cluster->get_tag('tag');
Récupère toutes les entrées pour l'étiquette donnée. Retourne un tableau d'hôtes ou le nombre d'hôtes dans le tableau selon le contexte.
@tags = $cluster->list_tags();
Retourne un tableau de tous les noms d'étiquettes disponibles.
%tags = $cluster->dump_tags();
Retourne une table de hachage de toutes les données d'étiquettes.
@tags = $cluster->expand_glob( $type, $name, @items );
Utilise l'expansion du shell sur chaque élément de @items, où $type est soit 'node', soit 'tag' et $name est le nom du nœud ou de l'étiquette. Ces attributs sont présentés à l'utilisateur en cas de problème avec l'expansion afin de retrouver la source.
