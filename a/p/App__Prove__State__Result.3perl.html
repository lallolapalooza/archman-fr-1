App::Prove::State::Result(3perl) Guide du programmeur Perl App::Prove::State::Result(3perl)

NOM

App::Prove::State::Result - Résultats individuels des suites de tests.

VERSION

Version 3.50

DESCRIPTION

La commande "prove" prend en charge une option "--state" qui lui demande de stocker un état persistant entre les exécutions. Ce module encapsule les résultats d'une seule exécution de suite de tests.

SYNOPSIS

# Relancer les tests échoués
$ prove --state=failed,save -rbv

MÉTHODES

Méthodes de classe

"new"

my $result = App::Prove::State::Result->new({
    generation => $generation,
    tests      => \%tests,
});

Retourne une nouvelle instance de "App::Prove::State::Result".

"state_version"

Retourne la version actuelle du stockage d'état.

"test_class"

Retourne le nom de la classe utilisée pour suivre les tests individuels. Cette classe doit soit être une sous-classe de "App::Prove::State::Result::Test", soit fournir une interface identique.

"generation"

Accesseur/mutateur pour la « génération » de l'exécution de la suite de tests. La première génération est 1 (un) et les générations suivantes sont 2, 3, etc.

"last_run_time"

Accesseur/mutateur pour l'heure de l'exécution de la suite de tests.

"tests"

Retourne les tests pour une génération donnée. Il s'agit d'un hashref ou d'une hash, selon le contexte d'appel. Les clés de la hash sont les noms des tests individuels et la valeur est un hashref contenant diverses valeurs intéressantes. Chaque paire clé/valeur peut ressembler à ceci :

't/foo.t' => {
   elapsed        => '0.0428488254547119',
   gen            => '7',
   last_pass_time => '1219328376.07815',
   last_result    => '0',
   last_run_time  => '1219328376.07815',
   last_todo      => '0',
   mtime          => '1191708862',
   seq            => '192',
   total_passes   => '6',
 }

"test"

my $test = $result->test('t/customer/create.t');

Retourne une instance individuelle de "App::Prove::State::Result::Test" pour le nom de test donné (généralement le nom du fichier). Retournera une nouvelle instance de "App::Prove::State::Result::Test" si le nom n'est pas trouvé.

"test_names"

Retourne une liste de noms de tests, triés par ordre d'exécution.

"remove"

$result->remove($test_name);            # supprimer le test
my $test = $result->test($test_name);   # erreur fatale

Supprime un test donné des résultats. C'est une opération nulle si le nom du test n'est pas trouvé.

"num_tests"

Retourne le nombre de tests pour un résultat de suite de tests donné.

"raw"

Retourne un hashref de résultats bruts, adapté à la sérialisation par YAML.
