apksigcopier(1) Manuel des commandes générales apksigcopier(1)

NOM

apksigcopier - copier/extraire/patcher les signatures d'APK Android & comparer des APK

SYNTAXE

apksigcopier copy [options] apk_signé apk_non_signé apk_de_sortie

apksigcopier extract [options] apk_signé répertoire_de_sortie

apksigcopier patch [options] répertoire_métadonnées apk_non_signé apk_de_sortie

apksigcopier compare [options] premier_apk second_apk

apksigcopier --version

apksigcopier --help

apksigcopier [commande] --help

DESCRIPTION

Un outil en ligne de commande pour copier les signatures d'APK Android d'un APK signé vers un APK non signé (afin de vérifier les builds reproductibles). Il peut également être utilisé pour comparer deux APK avec des signatures différentes.

COMMANDES

copy

Copier (extraire & patcher) les signatures d'un APK signé vers un APK non signé.

extract

Extraire les signatures d'APK d'un APK signé.

patch

Patcher les signatures d'APK extraites sur un APK non signé.

compare

Comparer deux APK en copiant la signature du premier sur une copie du second et en vérifiant si l'APK résultant est valide.

Cette commande nécessite apksigner(1).

NB : copier depuis un APK signé avec signflinger (v1) vers un APK signé avec apksigner (v2) fonctionne, tandis que l'inverse échoue ; voir la FAQ dans le README.

OPTIONS

copy/extract/patch

--v1-only [no|auto|yes]

Indique s'il faut s'attendre uniquement à une signature v1 : no signifie qu'une signature v2 est également attendue, auto signifie que la présence d'une signature v2 est détectée automatiquement, et yes signifie qu'une signature v2 n'est pas attendue (et ignorée si elle existe). Par défaut : no.

Vous pouvez également définir la variable d'environnement APKSIGCOPIER_V1_ONLY à la place.

compare

--unsigned

Accepter un second_apk non signé.

--min-sdk-version

Passé à apksigner(1) lors de la vérification.

--verify-cmd

Commande (avec arguments) utilisée pour vérifier les APK. Par défaut : apksigner verify.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être définies à 1, yes, ou true pour outrepasser le comportement par défaut.

APKSIGCOPIER_EXCLUDE_ALL_META

Exclure tous les fichiers de métadonnées, pas seulement MANIFEST.MF.

APKSIGCOPIER_COPY_EXTRA_BYTES

Copier les octets supplémentaires après les données (par exemple, une signature v2 existante).

APKSIGCOPIER_SKIP_REALIGNMENT

Ignorer le réalignement des entrées ZIP.

EXEMPLES

extract

$ mkdir meta
$ apksigcopier extract signed.apk meta
$ ls -1 meta
8BEA2A77.RSA
8BEA2A77.SF
APKSigningBlock
APKSigningBlockOffset
MANIFEST.MF

patch

$ apksigcopier patch meta unsigned.apk out.apk

copy

$ apksigcopier copy signed.apk unsigned.apk out.apk

compare

$ apksigcopier compare foo-from-fdroid.apk foo-built-locally.apk
$ apksigcopier compare foo.apk --unsigned foo-unsigned.apk
