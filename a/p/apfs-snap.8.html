NOM

apfs-snap - prendre un instantané d'un système de fichiers APFS

SYNTAXE

apfs-snap point_de_montage nom

DESCRIPTION

apfs-snap est un outil expérimental qui prend un instantané du système de fichiers APFS monté sur le point_de_montage donné. Le nom pour le nouvel instantané doit être spécifié dans nom.

OPTIONS

-v
Affiche le numéro de version de apfs-snap et quitte.

SIGNALEMENT DES BOGUES

Veuillez signaler les bogues par e-mail ou, si vous préférez, ouvrez un ticket github sur https://github.com/eafer/apfsprogs/issues.
