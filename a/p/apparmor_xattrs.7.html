NOM

apparmor_xattrs - Correspondance des attributs étendus (xattr) des profils AppArmor

DESCRIPTION

Les profils AppArmor peuvent faire correspondre conditionnellement des fichiers en fonction de la présence et de la valeur des attributs étendus, en plus du chemin du fichier. Le profil suivant s'applique à tout fichier sous "/usr/bin" où l'attribut étendu "security.apparmor" a la valeur "trusted" :

profile trusted /usr/bin/* xattrs=(security.apparmor="trusted") {
        # ...
}

Notez que "security.apparmor" et "trusted" sont arbitraires, et les profils peuvent correspondre en fonction de la valeur de n'importe quel attribut.

La valeur de xattrs peut également contenir une expression régulière de chemin :

profile trusted /usr/bin/* xattrs=(user.trust="tier/*") {
        # ...
}

Les outils getfattr(1) et setfattr(1) peuvent être utilisés pour visualiser et gérer les valeurs des xattrs :

$ setfattr -n 'security.apparmor' -v 'trusted' /usr/bin/example-tool
$ getfattr --absolute-names -d -m - /usr/bin/example-tool
# file: usr/bin/example-tool
security.apparmor="trusted"

La priorité de chaque profil est déterminée par la longueur du chemin, puis par le nombre de xattrs spécifiés. Un chemin plus spécifique est préféré aux correspondances xattr :

# Priorité la plus élevée, chemin le plus long.
profile example1 /usr/bin/example-tool {
        # ...
}
# Priorité inférieure à celle du chemin le plus long, mais supérieure à une règle
# avec moins de correspondances xattr.
profile example2 /usr/** xattrs=(
        security.apparmor="trusted"
        user.domain="**"
) {
        # ...
}
# Priorité la plus basse. Même longueur de chemin que le deuxième profil, mais avec
# moins de correspondances xattr.
profile example2 /usr/** {
        # ...
}

La correspondance des xattrs nécessite la fonctionnalité noyau suivante :

/sys/kernel/security/apparmor/features/domain/attach_conditions/xattr

PROBLÈMES CONNUS

Les profils AppArmor ne peuvent actuellement pas faire correspondre de manière fiable les attributs étendus avec des valeurs binaires telles que security.evm et security.ima. À l'avenir, AppArmor pourrait acquérir la capacité de faire correspondre en fonction de la présence de certains attributs tout en ignorant leurs valeurs.
