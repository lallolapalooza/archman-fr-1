NOM

apk update - mettre à jour les index des dépôts

SYNTAXE

apk update

DESCRIPTION

apk update force la mise à jour des index de tous les dépôts de paquets configurés. Cette commande n'est pas nécessaire en fonctionnement normal, car tous les applets nécessitant des index rafraîchiront automatiquement ceux-ci après l'expiration du temps de cache.

Voir apk-repositories(5) pour plus d'informations sur la configuration des dépôts de paquets.

OPTIONS

apk update ne supporte aucune option spécifique. Voir apk(8) pour les options globales.
