App::Prove::State(3perl) Guide du programmeur Perl App::Prove::State(3perl)

NOM

App::Prove::State - Stockage d'état pour la commande "prove".

VERSION

Version 3.50

DESCRIPTION

La commande "prove" supporte une option "--state" qui lui demande de stocker un état persistant entre les exécutions. Ce module implémente cet état et les opérations qui peuvent être effectuées dessus.

SYNOPSIS

# Relancer les tests échoués
$ prove --state=failed,save -rbv

MÉTHODES

Méthodes de classe

"new"

Accepte un hashref avec les paires clé/valeur suivantes :

  • "store"

    Le nom du fichier du magasin de données contenant les données que App::Prove::State lit.

  • "extensions" (optionnel)

    Les extensions de noms de tests. Par défaut, ".t".

  • "result_class" (optionnel)

    Le nom de la "result_class". Par défaut, "App::Prove::State::Result".

"result_class"

Accesseur/Mutateur pour le nom de la classe utilisée pour le suivi des résultats des tests. Cette classe doit soit hériter de "App::Prove::State::Result", soit fournir une interface identique.

"extensions"

Obtenir ou définir la liste des extensions que les fichiers doivent avoir pour être considérés comme des tests. Par défaut, ['.t'].

"results"

Obtenir les résultats de la dernière exécution des tests. Renvoie une instance de result_class().

"commit"

Sauvegarder les résultats des tests. Doit être appelé après que tous les tests ont été exécutés.

Méthodes d'instance

"apply_switch"

$self->apply_switch('failed,save');

Appliquer une liste d'options de commutateurs à l'état, mettant à jour l'état interne de l'objet en conséquence. Rien n'est retourné.

Diagnostics :
- "Illegal state option: %s"

"last"
Exécuter dans le même ordre qu'auparavant
"failed"
Exécuter uniquement les tests échoués d'auparavant
"passed"
Exécuter uniquement les tests réussis d'auparavant
"all"
Exécuter tous les tests dans l'ordre normal
"hot"
Exécuter d'abord les tests qui ont échoué le plus récemment
"todo"
Exécuter les tests ordonnés par nombre de todos.
"slow"
Exécuter les tests dans l'ordre du plus lent au plus rapide.
"fast"
Exécuter les tests dans l'ordre du plus rapide au plus lent.
"new"
Exécuter les tests dans l'ordre du plus récent au plus ancien.
"old"
Exécuter les tests dans l'ordre du plus ancien au plus récent.
"save"
Sauvegarder l'état à la sortie.

"get_tests"

Étant donné une liste d'arguments, obtenir les noms des tests qui doivent être exécutés.

"observe_test"

Stocker les résultats d'un test.

"save"

Écrire l'état dans un fichier.

"load"

Charger l'état depuis un fichier.
