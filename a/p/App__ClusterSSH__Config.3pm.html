Paquet: clusterssh

Licences: GPL

App::ClusterSSH::Config(3pm) Documentation Perl fournie par l'utilisateur App::ClusterSSH::Config(3pm)

SYNTAXE

DESCRIPTION

Représente la configuration de l'application.

MÉTHODES

$host=ClusterSSH::Config->new ({ })
Crée un nouvel objet de configuration.
$config->parse_config_file('<nom_fichier>');
Lit la configuration depuis le fichier spécifié.
$config->validate_args();
Valide et applique toute la configuration chargée à ce stade.
$path = $config->search_dirs('<nom>', @répertoires_de_recherche);
Recherche le nom donné dans les répertoires spécifiés. Renvoie undef s'il n'est pas trouvé.
$path = $config->find_binary('<nom>');
Localise l'exécutable <nom> et renvoie le chemin complet. Ne recherche pas uniquement dans $PATH au cas où l'environnement ne serait pas correctement configuré.
$config->load_configs(@supplémentaires);
Charge la configuration à partir d'emplacements connus (met en garde si un fichier .csshrc est trouvé) et charge les fichiers d'options si nécessaire.
$config->write_user_config_file();
Écrit le fichier de configuration par défaut $HOME/.clusterssh/config (avant que les fichiers de configuration d'options ne soient chargés).
$config->dump()
Écrit la configuration actuellement définie sur STDOUT.
