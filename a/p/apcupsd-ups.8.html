NOM

apcupsd-ups - Pilote pour l'accès client apcupsd

SYNOPIS

apcupsd-ups -h

apcupsd-ups -a NOM_ASI [OPTIONS]


Note

Cette page de manuel documente uniquement les fonctionnalités spécifiques du pilote apcupsd-ups. Pour plus d'informations sur le pilote de base, voir nutupsdrv(8).

DESCRIPTION

Ce pilote est un client de apcupsd (un autre projet de surveillance d'ASI).

apcupsd-ups agit comme un client apcupsd, transmettant simplement les données. Cela peut être utile dans les cas où les deux protocoles sont requis sur un réseau, ou dans le cas où la base de code apcupsd possède un mode d'accès à l'ASI manquant dans NUT.

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote prend en charge les paramètres optionnels suivants dans nut.conf(5):

port=<nom_hote>[:<port>]

C'est le nom d'un hôte distant exécutant apcupsd (plus un port optionnel).

Par exemple :

[apcupsd]
        driver = apcupsd-ups
        port = localhost
        desc = "Client apcupsd"

CONTEXTE

Ce pilote a été initialement écrit en une soirée pour permettre l'interopérabilité avec apcupsd.

LIMITATIONS

L'accès à apcupsd est strictement en lecture seule : aucune commande ne peut être émise. Cela découle de la conception d'apcupsd, où les paramètres sont modifiés dans apctest. Pour exécuter apctest, apcupsd doit être arrêté (et c'est apcupsd qui expose l'ASI au réseau et à ce pilote NUT en tant que son client).

NAME

apcupsd-ups — apcupsd UPS monitor

SYNOPSIS

apcupsd [-d level] [-k] [-p port] [-t timeout] [-f configfile] [-l logfile] [-u username] [-g groupname]

DESCRIPTION

apcupsd is a daemon that monitors an American Power Conversion (APC) UPS unit and controls the computer it is attached to. It can execute shell scripts or programs based on events such as power failure, low battery, or battery recharge.

OPTIONS

-d level
Sets the debug level. Higher levels produce more verbose logging.
-k
Kills a running apcupsd process.
-p port
Specifies the serial port to use for communicating with the UPS.
-t timeout
Sets the timeout for communication with the UPS.
-f configfile
Specifies an alternative configuration file.
-l logfile
Specifies an alternative log file.
-u username
Specifies the user to run apcupsd as.
-g groupname
Specifies the group to run apcupsd as.

EVENTS

apcupsd generates events that can trigger actions. These events include:

  • (APCUPSd:32767) COMMBAD Online - Comm error: ...
  • (APCUPSd:32767) COMMOK Online - Comm OK.
  • (APCUPSd:32767) KILLpower - UPS is being turned off.
  • (APCUPSd:32767) ONLINE UPS Name - UPS is online.
  • (APCUPSd:32767) OFFLINE UPS Name - UPS is offline.
  • (APCUPSd:32767) FATAL error - Fatal error.
  • (APCUPSd:32767) START UPS Name - Starting UPS monitor.
  • (APCUPSd:32767) STOP UPS Name - Stopping UPS monitor.
  • (APCUPSd:32767) TIME UPS Name - TIME message.
  • (APCUPSd:32767) LOADxx UPS Name - UPS load is xx%.
  • (APCUPSd:32767) BATTxx UPS Name - UPS battery charge is xx%.
  • (APCUPSd:32767) xxxxxxxx - Unknown message.

BACKGROUND

When apcupsd starts, it reads its configuration file (defaulting to /etc/apcupsd/apcupsd.conf) and attempts to establish communication with the UPS. It then enters a loop, monitoring the UPS status and processing events.

SUPPORTED VARIABLES

The following variables can be configured in /etc/apcupsd/apcupsd.conf:

  • UPSNAME: Name of the UPS.
  • UPSCABLE: Type of cable connecting UPS to computer.
  • UPSTYPE: Type of UPS.
  • DEVICE: Device name for the UPS communication port.
  • POLLTIME: Interval in seconds between UPS status checks.
  • LOCKFILE: Path to the lock file.
  • SCRIPTDIR: Directory for event handling scripts.
  • PWRFAILDIR: Directory for power failure events.
  • REBOOTDIR: Directory for reboot events.
  • ONBATTDIR: Directory for on battery events.
  • OFFBATTDIR: Directory for off battery events.
  • RUNALLSCRIPTS: Set to "yes" to run all scripts for each event.
  • UPSPROG: Path to the main UPS control program.
  • SHUTDOWNPROG: Path to the system shutdown program.
  • HOSTNAME: Hostname to use in event messages.
  • NISIP: IP address of the Network Information Service (NIS) server.
  • NISPORT: Port of the NIS server.
  • MAXLEN: Maximum length of event messages.
  • STATTIME: Interval in seconds between status updates.
  • TIMEOUT: Timeout in seconds for communication with the UPS.
  • LOGGERCMD: Command to use for logging messages.
  • RATING: UPS power rating in VA.
  • BATCHUPS: Set to "yes" to treat the UPS as a battery backup for a computer, not for powering the computer itself.
  • SYSLOG: Set to "yes" to log messages to syslog.
  • FAKEINTERVAL: Interval in seconds for fake UPS events.
  • SLEEPINTERVAL: Interval in seconds to sleep between fake UPS events.
  • OFFDELAY: Delay in seconds before shutting down when on battery.
  • ONDELAY: Delay in seconds before starting up after power is restored.
  • SUBDIRECTORY: Subdirectory for event scripts.
  • EVENTSFILE: File containing event definitions.
  • IBOOT: Set to "yes" to enable inhibit reboot.
  • FINALDELAY: Delay in seconds before the final shutdown command.
  • TRACKING: Set to "yes" to enable tracking of UPS status changes.
  • CHRONOMETRE: Set to "yes" to enable the chronometer feature.
  • AVR: Set to "yes" to enable Automatic Voltage Regulation (AVR).
  • KILLDELAY: Delay in seconds before killing the UPS process.
  • MINONBATT: Minimum time in seconds the UPS must be on battery before certain actions are taken.
  • BUPMON: Set to "yes" to enable battery backup monitoring.
  • MONTIME: Interval in seconds for battery backup monitoring.
  • POWERDOWNFLAG: Flag to indicate power down.
  • USERCMD: Command to execute for user-defined events.
  • USERCMD2: Second user-defined command.
  • USERCMD3: Third user-defined command.
  • USERCMD4: Fourth user-defined command.

LIMITATIONS

apcupsd may not support all features of all APC UPS models. Consult the apcupsd documentation for a list of supported UPS models.

NOM

apcupsd-ups — Moniteur UPS apcupsd

SYNTAXE

apcupsd [-d niveau] [-k] [-p port] [-t délai] [-f fichier_config] [-l fichier_journal] [-u nom_utilisateur] [-g nom_groupe]

DESCRIPTION

apcupsd est un démon qui surveille une unité UPS (Uninterruptible Power Supply) d'American Power Conversion (APC) et contrôle l'ordinateur auquel elle est connectée. Il peut exécuter des scripts shell ou des programmes basés sur des événements tels qu'une panne de courant, une batterie faible ou une recharge de batterie.

OPTIONS

-d niveau
Définit le niveau de débogage. Des niveaux plus élevés produisent des journaux plus verbeux.
-k
Arrête un processus apcupsd en cours d'exécution.
-p port
Spécifie le port série à utiliser pour communiquer avec l'UPS.
-t délai
Définit le délai d'attente pour la communication avec l'UPS.
-f fichier_config
Spécifie un fichier de configuration alternatif.
-l fichier_journal
Spécifie un fichier journal alternatif.
-u nom_utilisateur
Spécifie l'utilisateur sous lequel exécuter apcupsd.
-g nom_groupe
Spécifie le groupe sous lequel exécuter apcupsd.

ÉVÉNEMENTS

apcupsd génère des événements qui peuvent déclencher des actions. Ces événements incluent :

  • (APCUPSd:32767) COMMBAD Online - Erreur de communication : ...
  • (APCUPSd:32767) COMMOK Online - Communication OK.
  • (APCUPSd:32767) KILLpower - L'UPS va s'éteindre.
  • (APCUPSd:32767) ONLINE UPS Name - L'UPS est en ligne.
  • (APCUPSd:32767) OFFLINE UPS Name - L'UPS est hors ligne.
  • (APCUPSd:32767) FATAL error - Erreur fatale.
  • (APCUPSd:32767) START UPS Name - Démarrage du moniteur UPS.
  • (APCUPSd:32767) STOP UPS Name - Arrêt du moniteur UPS.
  • (APCUPSd:32767) TIME UPS Name - Message TIME.
  • (APCUPSd:32767) LOADxx UPS Name - La charge de l'UPS est de xx%.
  • (APCUPSd:32767) BATTxx UPS Name - La charge de la batterie de l'UPS est de xx%.
  • (APCUPSd:32767) xxxxxxxx - Message inconnu.

CONTEXTE

Au démarrage, apcupsd lit son fichier de configuration (par défaut /etc/apcupsd/apcupsd.conf) et tente d'établir la communication avec l'UPS. Il entre ensuite dans une boucle, surveillant l'état de l'UPS et traitant les événements.

VARIABLES PRISES EN CHARGE

Les variables suivantes peuvent être configurées dans /etc/apcupsd/apcupsd.conf :

  • UPSNAME : Nom de l'UPS.
  • UPSCABLE : Type de câble connectant l'UPS à l'ordinateur.
  • UPSTYPE : Type d'UPS.
  • DEVICE : Nom du périphérique pour le port de communication de l'UPS.
  • POLLTIME : Intervalle en secondes entre les vérifications de l'état de l'UPS.
  • LOCKFILE : Chemin vers le fichier de verrouillage.
  • SCRIPTDIR : Répertoire pour les scripts de gestion des événements.
  • PWRFAILDIR : Répertoire pour les événements de panne de courant.
  • REBOOTDIR : Répertoire pour les événements de redémarrage.
  • ONBATTDIR : Répertoire pour les événements sur batterie.
  • OFFBATTDIR : Répertoire pour les événements hors batterie.
  • RUNALLSCRIPTS : Défini sur "yes" pour exécuter tous les scripts pour chaque événement.
  • UPSPROG : Chemin vers le programme de contrôle principal de l'UPS.
  • SHUTDOWNPROG : Chemin vers le programme d'arrêt du système.
  • HOSTNAME : Nom d'hôte à utiliser dans les messages d'événement.
  • NISIP : Adresse IP du serveur NIS (Network Information Service).
  • NISPORT : Port du serveur NIS.
  • MAXLEN : Longueur maximale des messages d'événement.
  • STATTIME : Intervalle en secondes entre les mises à jour de l'état.
  • TIMEOUT : Délai d'attente en secondes pour la communication avec l'UPS.
  • LOGGERCMD : Commande à utiliser pour enregistrer les messages.
  • RATING : Puissance nominale de l'UPS en VA.
  • BATCHUPS : Défini sur "yes" pour considérer l'UPS comme une batterie de secours pour un ordinateur, et non pour alimenter l'ordinateur lui-même.
  • SYSLOG : Défini sur "yes" pour enregistrer les messages dans syslog.
  • FAKEINTERVAL : Intervalle en secondes pour les faux événements UPS.
  • SLEEPINTERVAL : Intervalle en secondes de veille entre les faux événements UPS.
  • OFFDELAY : Délai en secondes avant l'arrêt lorsqu'il est sur batterie.
  • ONDELAY : Délai en secondes avant le démarrage après le rétablissement de l'alimentation.
  • SUBDIRECTORY : Sous-répertoire pour les scripts d'événements.
  • EVENTSFILE : Fichier contenant les définitions d'événements.
  • IBOOT : Défini sur "yes" pour activer l'inhibition du redémarrage.
