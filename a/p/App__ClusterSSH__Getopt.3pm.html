App::ClusterSSH::Getopt(3pm) Documentation Perl fournie par l'utilisateur App::ClusterSSH::Getopt(3pm)

SYNTHAXE

DESCRIPTION

Représente la configuration de l'application

METHODES

$obj=ClusterSSH::Getopts->new ({ })
Crée un nouvel objet.
$obj=ClusterSSH::Getopts->add_option ({ })
Ajoute des options supplémentaires dans l'ensemble autorisé pour l'analyse depuis la ligne de commande
$obj=ClusterSSH::Getopts->add_common_options ({ })
Ajoute des options communes utilisées par la plupart des scripts appelants dans l'ensemble autorisé pour l'analyse depuis la ligne de commande
$obj=ClusterSSH::Getopts->add_common_session_options ({ })
Ajoute des options de session communes utilisées par la plupart des scripts appelants dans l'ensemble autorisé pour l'analyse depuis la ligne de commande
$obj=ClusterSSH::Getopts->add_common_ssh_options ({ })
Ajoute des options ssh communes utilisées par la plupart des scripts appelants dans l'ensemble autorisé pour l'analyse depuis la ligne de commande
$obj->getopts
Fonction à appeler après que toutes les options aient été configurées ; crée des méthodes à appeler pour chaque option sur l'objet, comme $obj->action, ou $obj->username
output(@)
Fonction utilitaire simple pour imprimer des lignes de pod avec des doubles retours

usage
Fonctions pour afficher l'aide et les instructions d'utilisation
