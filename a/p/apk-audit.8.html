apk-audit(8) Manuel de l'administrateur système apk-audit(8)

NOM

apk audit - auditer les répertoires pour détecter des changements

SYNTAXE

apk audit [<options>...] répertoires...

DESCRIPTION

apk audit audite le système ou les répertoires spécifiés pour des changements par rapport à la base de données des paquets.

L'audit peut être effectué sur les fichiers de configuration uniquement (--backup) pour générer une liste des fichiers à stocker dans la surcouche en mode exécution depuis tmp pour la configuration. Alternativement, il peut auditer tous les fichiers installés (--system ou --full) pour, par exemple, détecter des modifications non autorisées de fichiers système.

Par défaut, le format de sortie est un fichier par ligne, pour chaque fichier modifié. Un caractère est imprimé indiquant le type de ligne, suivi d'un espace, puis du chemin affecté ou des détails. Les changements détectés sont :

- Enregistrement de détail de la base de données
+ Enregistrement de détail sur disque
A Fichier ajouté
d Répertoire ajouté
D Répertoire ajouté (avec des fichiers/sous-répertoires non listés)
e une erreur s'est produite pendant l'audit (par exemple, permissions insuffisantes pour lire le fichier)
M Métadonnées de fichier modifiées (uid, gid, ou mode)
m Métadonnées de répertoire modifiées
U Contenu du fichier modifié
X Fichier supprimé
x xattrs modifiés

OPTIONS

--backup

Audite uniquement les fichiers de configuration (par défaut). La liste des fichiers à auditer est générée à partir des masques dans protected_paths.d.

--check-permissions

Vérifie également les permissions des fichiers. Plus précisément, l'uid, le gid et le mode du fichier seront vérifiés en plus du contenu du fichier.

--details

Active le rapport des enregistrements de détails.

--full

Identique à --system, mais rapporte en plus tous les répertoires et fichiers ajoutés. Un remplacement par défaut intégré pour les chemins protégés est utilisé, à moins qu'un --protected-paths ne soit explicitement spécifié.

--ignore-busybox-symlinks

Ignore les liens symboliques dont la cible est le binaire busybox.

--packages

N'imprime que les paquets avec des fichiers modifiés. Au lieu de la sortie complète de chaque modification, l'ensemble des paquets ayant au moins un fichier modifié est imprimé.

Pour réparer tous les paquets avec des fichiers modifiés, on pourrait utiliser :

apk audit --packages -q | xargs apk fix

--protected-paths FICHIER

Utilise le FICHIER donné pour les listes de chemins protégés. Cela fait également en sorte qu'apk ignore les répertoires protected_paths.d réguliers.

--recursive, -r

Descend dans les répertoires et les audite également.

--system

Audite tous les fichiers système. Tous les fichiers fournis par les paquets sont vérifiés pour leur intégrité, à l'exception des fichiers de configuration (listés dans protected_paths.d). Ceci est utile pour détecter des modifications de fichiers non autorisées. Les nouveaux fichiers ou répertoires ne sont pas signalés.
