NOM

appdata2solv - convertit les métadonnées d'application en un fichier solv

SYNTAXE

appdata2solv [OPTIONS]

DESCRIPTION

Le format appdata contient des métadonnées sur les applications. Il peut être disponible à la fois dans les dépôts (pour les applications disponibles) et dans le système installé (pour les applications installées). L'outil appdata2solv lit les métadonnées depuis l'entrée standard et écrit les données analysées sous forme de fichier solv sur la sortie standard. L'analyseur créera des pseudo-paquets application: pour chaque entrée.

-d APPDATADIR

Ne pas lire depuis l'entrée standard, mais scanner le répertoire spécifié pour les entrées appdata. APPDATADIR est normalement défini sur /usr/share/appdata.

-r ROOTDIR

Utiliser ROOTDIR comme répertoire racine.
