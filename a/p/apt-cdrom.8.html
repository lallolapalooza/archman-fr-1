DESCRIPTIO

N

apt-cdrom est utilisé pour ajouter un nouveau CD-ROM à la liste des sources disponibles d'APT. apt-cdrom se charge de déterminer la structure du disque ainsi que de corriger plusieurs erreurs de gravure possibles et de vérifier les fichiers

d'index.

Il est nécessaire d'utiliser apt-cdrom pour ajouter des CD au système APT ; cela ne peut pas être fait manuellement. De plus, chaque disque d'un ensemble multi-CD doit être inséré et analysé séparément afin de prendre en compte les erreurs de gravure

possibles.

Sauf si l'option -h ou --help est donnée, l'une des commandes suivantes doit être

présente.

ad

d
add est utilisé pour ajouter un nouveau disque à la liste des sources. Il démontera le périphérique CD-ROM, demandera l'insertion d'un disque, puis procédera à son analyse et copiera les fichiers d'index. Si le disque ne possède pas de répertoire .disk approprié, un titre descriptif vous sera demandé.

APT utilise un identifiant de CD-ROM pour suivre quel disque se

trouve actuellement dans le lecteur et maintient une base d
e données de ces identifiants dans /var/lib/apt/cdroms.list

OPTION

S

Toutes les options de ligne de commande peuvent être définies à l'aide du fichier de configuration ; les descriptions indiquent l'option de configuration à définir. Pour les options booléennes, vous pouvez annuler le fichier de configuration en utilisant quelque chose comme -f-,--no-f, -f=no ou plusieurs autres

variations.

--no-auto-detect, --cdro

m
Ne pas essayer de détecter automatiquement le chemin du CD-ROM. Généralement combiné avec l'option --cdrom. Élément de configuration : Acquire::cdrom::
AutoDetect.

-d, --cdro

m
Point de montage ; spécifie l'emplacement où monter le CD-ROM. Ce point de montage doit être listé dans /etc/fstab et correctement configuré. Élément de configuration : Acquire::cdrom::
mount.

-r, --renam

e
Renommer un disque ; changer l'étiquette d'un disque ou remplacer l'étiquette donnée au disque. Cette option fera en sorte qu' apt-cdrom demande une nouvelle étiquette. Élément de configuration : APT::CDROM::
Rename.

-m, --no-moun

t
Pas de montage ; empêcher apt-cdrom de monter et démonter le point de montage. Élément de configuration : APT::CDROM::
NoMount.

-f, --fas

t
Copie rapide ; suppose que les fichiers de paquets sont valides et ne vérifie pas chaque paquet. Cette option ne devrait être utilisée que si apt-cdrom a déjà été exécuté sur ce disque et n'a détecté aucune erreur. Élément de configuration : APT::CDROM::
Fast.

-a, --thoroug

h
Analyse approfondie des paquets ; cette option peut être nécessaire avec certains anciens disques Debian 1.1/1.2 qui ont des fichiers Package à des endroits inhabituels. L'analyse du CD prendra beaucoup plus de temps, mais tous les paquets seront
trouvés.

-n, --just-print, --recon, --no-ac

t
Aucune modification ; ne pas modifier le fichier sources.list(5) et ne pas écrire de fichiers d'index. Tout est néanmoins vérifié. Élément de configuration : APT::CDROM::
NoAct.

-h, --hel

p
Afficher un court résumé
d'utilisation.

-v, --versio

n
Afficher la version du
programme.

--audi

t
Afficher les messages d'audit (et de notification). Cela annule l'option quiet, mais uniquement pour les messages de notification, pas pour les messages de
progression.

-c, --config-fil

e
Fichier de configuration ; spécifie un fichier de configuration à utiliser. Le programme lira le fichier de configuration par défaut puis ce fichier de configuration. Si des paramètres de configuration doivent être définis avant l'analyse des fichiers de configuration par défaut, spécifiez un fichier avec la variable d'environnement APT_CONFIG. Voir apt.conf(5) pour des informations sur la
syntaxe.

-o, --optio

n
Définir une option de configuration ; cela définira une option de configuration arbitraire. La syntaxe est -o Foo::Bar=bar. -o et --option peuvent être utilisés plusieurs fois pour définir différentes
options.

--cli-versio

n
Demande une version CLI spécifique. C'est un motif qui prend une version MAJEURE.MINEURE. Vous pouvez omettre la version mineure, auquel cas le niveau mineur le plus récent pris en charge sera utilisé.

Les pistes de version sont présentées comme suit : La version 3.2 a des versions équivalentes 0.32, 1.22 et 2.12, implémentant de nouvelles fonctionnalités pour leurs versions majeures

respectives.

Un cas particulier est le motif de version X.9 : une version comme 2.9 est suivie de 3.0, mais 2.10 suit directement 2.8 ; étant donné que nous utilisons les numéros de version impairs comme séries de développement (2.9 est la série de développement 3.0)

.

Cette fonctionnalité a été introduite dans APT 3.1.10 et remplace la configuration spécifique à chaque binaire. Vous pouvez utiliser APT::Version pour un effet similaire sur les anciens binaires, par exemple, utilisez -o APT::Version=2 pour faire en sorte que apt(8) se comporte comme la série 2.

x.

La valeur par défaut est la version actuelle d'APT pour apt(8) et 0.(10 * majeure + mineure) pour les commandes classiques. La série 0.X est

obsolète de manière douce et les autres comm
andes passeront à la série 2.x à l'avenir.

--no-color, --colo

r
Activer ou désactiver les couleurs. Les couleurs sont activées par défaut sur les terminaux pris en charge pour apt(8) et peuvent également être désactivées à l'aide des variables d'environnement NO_COLOR ou APT_NO_COLOR, ou être davantage configurées par l'option et la portée de configuration APT::Color, voir apt.conf(5) pour des i
nformations
à ce sujet.
