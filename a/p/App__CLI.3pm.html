NOM

App::CLI - Module de distribution pour les programmes d'interface en ligne de commande

SYNTAXE

package MyApp;
use base 'App::CLI';        # le DISTRIBUTEUR de votre App
                            # il n'est pas nécessaire de mettre le distributeur
                            # au niveau supérieur de votre App
package main;
MyApp->dispatch;            # appeler le distributeur où vous voulez
package MyApp::List;
use base qw(App::CLI::Command); # N'importe quelle (SOUS)COMMANDE de votre App
use constant options => (
    "h|help"   => "help",
    "verbose"  => "verbose",
    'n|name=s'  => 'name',
);
use constant subcommands => qw(User Nickname type); # si vous voulez des sous-commandes
                                                    # distribuer automatiquement vers les sous-commandes
                                                    # lors de l'appel $ monapp list [user|nickname|--type]
                                                    # notez que 'type' n'est pas en majuscules
                                                    # c'est une sous-commande dépréciée
sub run {
    my ($self, @args) = @_;
    print "verbose" if $self->{verbose};
    my $name = $self->{name}; # obtenir l'argument suivant l'option longue --name
    if ($self->{help}) {
        # si $ monapp list --help ou $ monapp list -h
        # uniquement afficher les PODs
    } else {
        # faire quelque chose lors de l'appel $ monapp list
        # sans sous-commande et sans --help
    }
}
package MyApp::List::User;
use base qw(App::CLI::Command);
use constant options => (
    "h|help"  =>  "help",
);
sub run {
    my ($self,@args) = @_;
    # code pour lister l'utilisateur
}
pakcage MyApp::List::Nickname;
use base qw(App::CLI::Command);
use constant options => (
    "sort=s"  =>  "sort",
);
sub run {
    my ($self,@args) = @_;
    # code pour lister le pseudonyme
}
package MyApp::List::type;   # ancien genre de sous-commande ne peut pas être en cascade infiniment
use base qw(MyApp::List);    # devrait hériter de la commande de son parent
sub run {
    my ($self, @args);
    # exécuter jusqu'ici lors de l'appel $ monapp list --type
}
package MyApp::Help;
use base 'App::CLI::Command::Help';
use constant options => (
    'verbose' => 'verbose',
);
sub run {
    my ($self, @arg) = @_;
    # faire quelque chose
    $self->SUPER(@_); # App::CLI::Command::Help affichera les PODs de chaque commande
}

DESCRIPTION

"App::CLI" distribue les commandes CLI (interface en ligne de commande) vers des classes de commande. Il prend également en charge les sous-commandes et les options par commande.

Méthodes

get_opt([@config], %opt_map)

Donne une map d'options, traitée par Getopt::Long::Parser.

dispatch(@args)

Interface du distributeur.

cmd_map($cmd)

Trouve le nom du package implémentant la commande demandée.

La commande est d'abord recherchée dans les "alias". Si l'alias existe et pointe vers un nom de package commençant par le signe "+", alors ce nom de package (moins le signe "+") est retourné. Cela permet de mapper des commandes à des packages arbitraires.

Sinon, le package est recherché dans le résultat de l'appel de "commands", et un nom de package est construit en mettant en majuscule le premier caractère du nom de la commande, et en l'ajoutant au nom du package de l'application elle-même.

Si ces deux méthodes échouent, et que la commande ne correspond à aucun nom de package, "undef" est retourné à la place.

get_cmd($cmd, @arg)

Retourne la sous-commande du premier niveau via $ARGV[0].
