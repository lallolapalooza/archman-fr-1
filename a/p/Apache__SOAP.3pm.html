NOM

Apache::SOAP - Serveur SOAP basé sur mod_perl avec configuration minimale

SYNTAXE

httpd.conf (Location), accès basé sur répertoire
<Location /mod_soap>
  SetHandler perl-script
  PerlHandler Apache::SOAP
  PerlSetVar dispatch_to "/Votre/Chemin/Vers/Modules/Déployés, Module::Nom, Module::méthode"
  PerlSetVar options "compress_threshold => 10000"
</Location>
httpd.conf (Fichiers), accès basé sur fichier
<FilesMatch "\.soap$">
  SetHandler perl-script
  PerlHandler Apache::SOAP
  PerlSetVar dispatch_to "/Votre/Chemin/Vers/Modules/Déployés, Module::Nom, Module::méthode"
  PerlSetVar options "compress_threshold => 10000"
</FilesMatch>
.htaccess, accès basé sur répertoire
SetHandler perl-script
PerlHandler Apache::SOAP
PerlSetVar dispatch_to "/Votre/Chemin/Vers/Modules/Déployés, Module::Nom, Module::méthode"
PerlSetVar options "compress_threshold => 10000"

DESCRIPTION

Ce module Perl pour Apache offre la possibilité d'ajouter la prise en charge du protocole SOAP (Simple Object Access Protocol) avec une configuration facile (soit dans un fichier .conf, soit dans un fichier .htaccess). Cette fonctionnalité devrait vous offrir une option légère pour héberger des services SOAP et simplifier grandement les aspects de configuration. Ce module hérite des fonctionnalités du composant SOAP::Transport::HTTP::Apache du module SOAP::Lite.

CONFIGURATION

Le module peut être placé dans les directives <Location>, <Directory>, <Files>, <FilesMatch> dans les zones de configuration principales du serveur ou directement dans un fichier .htaccess.

Tous les paramètres doivent être entre guillemets et peuvent être séparés par des virgules ou des espaces pour les listes ("a, b, c") et par des 'flèches larges' et des virgules pour les paramètres de hachage ("key1 => value1, key2 => value2").

Toutes les options que vous pouvez trouver dans le composant SOAP::Transport::HTTP::Apache sont disponibles pour la configuration. Voici la description des plus importantes.

dispatch_to (LISTE)
Spécifie le chemin vers le répertoire contenant les modules Perl auxquels vous souhaitez donner accès, ou simplement la liste des modules (pour les modules préchargés). 
PerlSetVar dispatch_to "/Votre/Chemin/Vers/Modules/Déployés, Module::Nom, Module::méthode"
options (HASH)
Spécifie la liste des options pour votre module, par exemple le seuil de compression. Les versions futures prendront en charge plus d'options. Voir la documentation de SOAP::Transport::HTTP pour les autres options. 
PerlSetVar options "compress_threshold => 10000"
