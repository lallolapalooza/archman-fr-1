NOM

apk version - comparer les versions de paquets

SYNTAXE

apk version [<options>...] [paquets...]

apk version -c versions...

apk version -t version1 version2

apk version -I

DESCRIPTION

apk version compare les versions des paquets installés avec les versions de paquets disponibles dans les dépôts (voir apk-repositories(5)). Il peut également être utilisé pour valider et comparer des chaînes de versions.

En mode par défaut, si aucun paquet n'est spécifié, tous les paquets installés sont pris en compte. Sinon, la comparaison est limitée aux paquets explicitement listés. Un résumé est imprimé sur stdout, la différence entre les versions des paquets étant représentée par >, =, ou <.

Les options -c, -I et -t sont mutuellement exclusives.

OPTIONS

Ces options ne s'appliquent que lors de la vérification des versions des paquets installés par rapport aux paquets disponibles dans les dépôts (lorsque ni -c, ni -t, ni -I ne sont spécifiés).

--all, -a

Prendre en compte les paquets de toutes les balises de dépôt.

--check, -c

Vérifier la validité des versions. Si une version donnée est invalide, elle est imprimée. Quitte avec le code zéro si toutes les versions sont valides, et non-zéro sinon.

--indexes, -I

Imprimer la version et la description pour l'index de chaque dépôt. Voir apk-repositories(5) pour plus d'informations.

--limit, -l opérande

Limiter aux paquets dont la sortie correspond à l'opérande donné. L'opérande peut être spécifié comme n'importe quelle combinaison de >, = et <.

--test, -t

Comparer deux chaînes de versions. Ne consulte pas la base de données. Imprime l'un des symboles >, =, ou <, si version1 est, respectivement, supérieure, égale ou inférieure à version2.
