NOM

appletviewer - Exécute les applets en dehors d'un navigateur Web.

SYNTAXE

appletviewer [options] url...
options
Les options en ligne de commande séparées par des espaces. Voir Options.
url
L'emplacement des documents ou des ressources à afficher. Vous pouvez spécifier plusieurs URL séparées par des espaces.

DESCRIPTION

La commande appletviewer se connecte aux documents ou aux ressources désignées par urls et affiche chaque applet référencée par les documents dans sa propre fenêtre. Si les documents référencés par les url ne référencent aucune applet avec les balises OBJECT, EMBED ou APPLET, alors la commande appletviewer ne fait rien. Pour plus de détails sur les balises HTML prises en charge par la commande appletviewer, consultez AppletViewer Tags à http://docs.oracle.com/javase/8/docs/technotes/tools/appletviewertags.html

La commande appletviewer nécessite des URL encodées conformément au mécanisme d'échappement défini dans RFC2396. Seules les URL encodées sont prises en charge. Cependant, les noms de fichiers doivent être non encodés, conformément à la spécification RFC2396.

Note : La commande appletviewer est destinée au développement uniquement. Pour plus d'informations, voir About Sample/Test Applications and Code à http://docs.oracle.com/javase/8/docs/technotes/samples/aboutCodeSamples.html

OPTIONS

-debug

Démarre l'Applet Viewer dans le débogueur Java avec la commande jdb pour déboguer les applets du document.
-encoding nom-encodage

Spécifie le nom de l'encodage du fichier HTML d'entrée.
-Joptionjava

Transmet la chaîne optionjava comme un seul argument à l'interpréteur Java, qui exécute l'Applet Viewer. L'argument ne doit pas contenir d'espaces. Les mots multiples de l'argument doivent tous commencer par le préfixe -J. Ceci est utile pour ajuster l'environnement d'exécution du compilateur ou l'utilisation de la mémoire.
