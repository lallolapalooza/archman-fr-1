NOM

App::perlbrew - Gérer les installations perl dans votre "$HOME"

SYNOPSIS

# Installation
curl -L https://install.perlbrew.pl | bash
# Initialisation
perlbrew init
# Voir ce qui est disponible
perlbrew available
# Installer quelques Perls
perlbrew install 5.32.1
perlbrew install perl-5.28.3
perlbrew install perl-5.33.6
# Voir ce qui a été installé
perlbrew list
# Basculer vers une installation et la définir par défaut
perlbrew switch perl-5.32.1
# Utiliser temporairement une autre version uniquement dans le shell courant.
perlbrew use perl-5.28.3
perl -v
# Désactiver et revenir au perl système.
perlbrew off
# Réactiver avec 'switch', ou 'use'
perlbrew switch perl-5.32.1
perlbrew use perl-5.32.1
# Exécuter quelque chose avec tous les perl de perlbrew
perlbrew exec -- perl -E 'say $]'

DESCRIPTION

perlbrew est un programme qui automatise la construction et l'installation de perl de manière simple. Il fournit plusieurs environnements perl isolés, et un mécanisme pour basculer entre eux.

Tout est installé sous "~/perl5/perlbrew". Vous devez ensuite inclure un bashrc/cshrc fourni par perlbrew pour ajuster le PATH pour vous. Vous pouvez ensuite profiter du fait de ne pas avoir à exécuter de commandes "sudo" pour installer des modules cpan car ceux-ci sont également installés dans votre "HOME" .

Pour la documentation de l'utilisation de perlbrew, voir la commande perlbrew sur MetaCPAN https://metacpan.org/, ou en exécutant "perlbrew help", ou en visitant le site web officiel de perlbrew https://perlbrew.pl/. La documentation suivante présente l'API du module "App::perlbrew" , et peut ne pas correspondre à ce que vous souhaitez lire.

INSTALLATION

Le plus simple est d'utiliser l'installateur perlbrew, collez simplement cette instruction dans votre terminal :

curl -L https://install.perlbrew.pl | bash

Ou celle-ci, si vous avez "fetch" (par défaut sur FreeBSD) :

fetch -o- https://install.perlbrew.pl | sh

Après cela, "perlbrew" s'installe dans "~/perl5/perlbrew/bin", et vous devriez suivre les instructions à l'écran pour modifier votre fichier rc de shell afin de l'ajouter à votre PATH.

La commande perlbrew installée est un exécutable autonome qui peut être exécuté avec le perl système. La version minimale requise du perl système est 5.8.0, ce qui devrait suffire pour la plupart des systèmes d'exploitation actuels.

Une version fat-packed de patchperl est également installée dans "~/perl5/perlbrew/bin", ce qui est nécessaire pour construire d'anciens perls.

Le répertoire "~/perl5/perlbrew" contiendra tous les exécutables perl installés, les bibliothèques, la documentation, lib, site_libs. Dans la documentation, ce répertoire est désigné comme "perlbrew root". Si vous devez le définir ailleurs, par exemple parce que votre "HOME" a un quota limité, vous pouvez le faire en définissant la variable d'environnement "PERLBREW_ROOT" avant de lancer l'installateur :

export PERLBREW_ROOT=/opt/perl5
curl -L https://install.perlbrew.pl | bash

Ainsi, différents utilisateurs sur la même machine peuvent partager le même répertoire perlbrew root (bien que seul l'utilisateur d'origine qui a effectué l'installation ait la permission d'effectuer des installations perl.)

Si vous devez installer perlbrew avec un Perl qui n'est ni "/usr/bin/perl" ni "/usr/local/bin/perl", définissez et exportez la variable d'environnement "PERLBREW_SYSTEM_PERL" puis installez comme décrit ci-dessus. Notez que vous ne devez pas utiliser un perl géré par perlbrew.

Vous pouvez également installer perlbrew depuis CPAN :

cpan App::perlbrew

Dans ce cas, la commande perlbrew est installée dans "/usr/bin/perlbrew" ou "/usr/local/bin/perlbrew" ou ailleurs, selon l'emplacement de l'installation de votre perl système.

Veuillez vous assurer de ne pas exécuter cela avec l'un des perls gérés par perlbrew. Il est préférable de désactiver perlbrew avant de le faire, si vous mettez à jour.

perlbrew off
cpan App::perlbrew

Vous devriez toujours utiliser le cpan système (comme /usr/bin/cpan) pour installer "App::perlbrew" car il sera installé sous un PATH système comme "/usr/bin", qui n'est pas affecté par la commande "switch" ou "use" de perlbrew.

La commande "self-upgrade" ne mettra pas à jour le perlbrew installé par la commande cpan, mais il est également facile de mettre à jour perlbrew en exécutant "cpan App::perlbrew" à nouveau.
