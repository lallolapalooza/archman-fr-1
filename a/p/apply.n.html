apply(n) Commandes intégrées Tcl apply(n)

NOM

apply - Appliquer une fonction anonyme

SYNOPSIS

apply func ?arg1 arg2 ...?

DESCRIPTION

La commande apply applique la fonction func aux arguments arg1 arg2 ... et retourne le résultat.

La fonction func est une liste de deux éléments {args corps} ou une liste de trois éléments {args corps espace_nom} (comme si la commande list avait été utilisée). Le premier élément args spécifie les arguments formels de func. La spécification des arguments formels args est partagée avec la commande proc, et est décrite en détail dans la page de manuel correspondante.

Le contenu de corps est exécuté par l'interpréteur Tcl après que les variables locales correspondant aux arguments formels se soient vu attribuer les valeurs des paramètres réels arg1 arg2 .... Lorsque corps est exécuté, les noms de variables font normalement référence à des variables locales, qui sont créées automatiquement lors de leur référencement et supprimées lorsque apply retourne. Une variable locale est créée automatiquement pour chacun des arguments de la fonction. Les variables globales ne peuvent être accédées qu'en invoquant la commande global ou la commande upvar. Les variables d'espace de noms ne peuvent être accédées qu'en invoquant la commande variable ou la commande upvar.

L'invocation de apply ajoute un cadre d'appel à la pile d'évaluation de Tcl (la pile de cadres accessible via uplevel). L'exécution de corps se déroule dans ce cadre d'appel, dans l'espace de noms donné par espace_nom ou dans l'espace de noms global si aucun n'a été spécifié. Si elle est fournie, espace_nom est interprétée par rapport à l'espace de noms global, même si son nom ne commence pas par “::”.

Les sémantiques de apply peuvent également être décrites par :

proc apply {fun args} {
    set len [llength $fun]
    if {($len < 2) || ($len > 3)} {
         error "impossible d'interpréter \"$fun\" comme fonction anonyme"
    }
    lassign $fun argList body ns
    set name ::$ns::[getGloballyUniqueName]
    set body0 {
         rename [lindex [info level 0] 0] {}
    }
    proc $name $argList ${body0}$body
    set code [catch {uplevel 1 $name $args} res opt]
    return -options $opt $res
}

EXEMPLES

Ceci montre comment créer une commande générale simple qui applique une transformation à chaque élément d'une liste.

proc map {lambda list} {
    set result {}
    foreach item $list {
        lappend result [apply $lambda $item]
    }
    return $result
}
map {x {return [string length $x]:$x}} {a bb ccc dddd}
      → 1:a 2:bb 3:ccc 4:dddd
map {x {expr {$x**2 + 3*$x - 2}}} {-4 -3 -2 -1 0 1 2 3 4}
      → 2 -2 -4 -4 -2 2 8 16 26

La commande apply est également utile pour définir des rappel (callbacks) à utiliser dans la commande trace :

set vbl "123abc"
trace add variable vbl write {apply {{v1 v2 op} {
    upvar 1 $v1 v
    puts "variable mise à jour à \"$v\""
}}}
set vbl 123
set vbl abc
