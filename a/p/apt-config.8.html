NOM

apt-config - Programme de requête de configuration APT

SYNTAXE

apt-config [--empty] [--format '%f "%v";%n'] [-o=config_string] [-c=config_file] {shell | dump | {-v | --version} | {-h | --help}}

DESCRIPTION

apt-config est un programme interne utilisé par diverses parties de la suite APT pour fournir une configurabilité cohérente. Il accède au fichier de configuration principal /etc/apt/apt.conf d'une manière facile à utiliser pour les applications scriptées.

Sauf si l'option -h ou --help est donnée, l'une des commandes ci-dessous doit être présente.

shell

shell est utilisé pour accéder aux informations de configuration à partir d'un script shell. Il reçoit des paires d'arguments, la première étant une variable shell et la seconde la valeur de configuration à interroger. En sortie, il liste des commandes d'affectation de variables shell pour chaque valeur présente. Dans un script shell, il doit être utilisé comme suit : 
OPTS="-f"
RES=`apt-config shell OPTS MyApp::options`
eval $RES
Ceci définira la variable d'environnement shell $OPTS à la valeur de MyApp::options avec une valeur par défaut de -f.

L'élément de configuration peut être suffixé par un /[fdbi]. f renvoie les noms de fichiers, d les répertoires, b les valeurs vrai ou faux et i un entier. Chacun des retours est normalisé et vérifié en interne.

dump

Affiche simplement le contenu de l'espace de configuration.

OPTIONS

Toutes les options de ligne de commande peuvent être définies à l'aide du fichier de configuration ; les descriptions indiquent l'option de configuration à définir. Pour les options booléennes, vous pouvez remplacer le fichier de configuration en utilisant quelque chose comme -f-, --no-f, -f=no ou plusieurs autres variations.

--empty

Inclut les options qui ont une valeur vide. C'est le défaut, donc utilisez --no-empty pour les supprimer de la sortie.

--format '%f "%v";%n'

Définit la sortie de chaque option de configuration. %t sera remplacé par son nom individuel, %f par son nom hiérarchique complet et %v par sa valeur. Utilisez des lettres majuscules et des caractères spéciaux dans la valeur pour vous assurer qu'elle puisse, par exemple, être utilisée en toute sécurité dans une chaîne entre guillemets, telle que définie par RFC822. De plus, %n sera remplacé par un saut de ligne, et %N par une tabulation. Un % peut être imprimé en utilisant %%.

-h, --help

Affiche un bref résumé d'utilisation.

-v, --version

Affiche la version du programme.

--audit

Affiche les messages d'audit (et de notification). Ceci remplace l'option silencieuse, mais uniquement pour les messages de notification, pas pour les messages de progression.

-c, --config-file

Fichier de configuration ; Spécifie un fichier de configuration à utiliser. Le programme lira le fichier de configuration par défaut puis ce fichier de configuration. Si des paramètres de configuration doivent être définis avant que les fichiers de configuration par défaut ne soient analysés, spécifiez un fichier avec la variable d'environnement APT_CONFIG. Voir apt.conf(5) pour la syntaxe.

-o, --option

Définir une option de configuration ; Ceci définira une option de configuration arbitraire. La syntaxe est -o Foo::Bar=bar. -o et --option peuvent être utilisés plusieurs fois pour définir différentes options.

--cli-version

Demande une version CLI spécifique. Ceci est un modèle qui prend une version MAJEURE.MINEURE. Vous pouvez omettre la version MINEURE, auquel cas le dernier niveau mineur pris en charge sera utilisé.

Les pistes de version sont présentées comme suit : La version 3.2 a des versions équivalentes 0.32, 1.22 et 2.12, implémentant de nouvelles fonctionnalités pour leurs versions majeures spécifiées.

Un cas spécial est le modèle de version X.9 : une version comme 2.9 est suivie de 3.0, mais 2.10 suit directement 2.8 ; étant donné que nous utilisons des numéros de version impairs comme séries de développement (2.9 est la série de développement 3.0).

Cette fonctionnalité a été introduite dans APT 3.1.10 et remplace la configuration spécifique au binaire. Vous pouvez utiliser APT::Version dans un but similaire sur les binaires plus anciens, par exemple, utilisez -o APT::Version=2 pour que apt(8) se comporte comme la série 2.x.

La valeur par défaut est la version APT actuelle pour apt(8) et 0.(10 * majeur + mineur) pour les commandes classiques. La série 0.X est dépréciée et les autres commandes basculeront vers la série 2.x à l'avenir.

--no-color, --color

Active ou désactive les couleurs. Les couleurs sont activées par défaut sur les terminaux pris en charge pour apt(8) et peuvent également être désactivées à l'aide des variables d'environnement NO_COLOR ou APT_NO_COLOR, ou configurées davantage par l'option de configuration APT::Color et sa portée, voir apt.conf(5) pour des informations à ce sujet.

DIAGNOSTICS

apt-config retourne zéro en cas de fonctionnement normal, 100 décimal en cas d'erreur.

apt-config(8)

APT configuration management

SYNOPSIS

apt-config [-h|--help] [-c=file|-o=option] [--debug] [--format=format] [--format-file=file] [--package=package] [--generate] [--remove] [--save] [--show] [--set] [--sources-list=file] [--system-sources-list=file] [--verbose] [--version] [--no-generate] [--no-remove] [--no-save] [--no-set] [--no-show] [--no-warn-invalid-template] [--no-warn-missing-template] [--no-warn-undefined-variable] [--warn-invalid-template] [--warn-missing-template] [--warn-undefined-variable] [-p=pkg|--package=pkg] [-g|--generate] [-r|--remove] [-s|--save] [-S|--show] [-e=value|--set=value] [-D|--debug] [--format=format] [--format-file=file] [--sources-list=file] [--system-sources-list=file] [--verbose] [--version]

DESCRIPTION

apt-config is a command-line tool that provides an interface to APT's configuration system. It allows users to view, modify, and manage APT configuration files and settings.

OPTIONS

-h, --help
Show help message and exit.
-c=file, -o=option
Specify configuration file or option.
--debug
Enable debug output.
--format=format
Specify output format.
--format-file=file
Specify format file.
--package=package
Specify package name.
--generate
Generate configuration files.
--remove
Remove configuration settings.
--save
Save configuration changes.
--show
Show configuration settings.
--set
Set configuration values.
--sources-list=file
Specify sources list file.
--system-sources-list=file
Specify system sources list file.
--verbose
Enable verbose output.
--version
Show program version and exit.

EXAMPLES

apt-config show apt.conf.d/
Show all configuration settings in apt.conf.d/ directory.

apt-config set APT::Get::AllowUnauthenticated "true"
Set APT::Get::AllowUnauthenticated to "true".

apt-config generate
Generate APT configuration files.
