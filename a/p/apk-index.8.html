apk-index(8) Manuel du gestionnaire système apk-index(8)

NOM

apk index - crée un fichier d'index de dépôt à partir des paquets

SYNTAXE

apk index [<options>...] paquets...

DESCRIPTION

apk index crée un index de dépôt à partir d'une liste de fichiers de paquets. Voir apk-repositories(5) pour plus d'informations sur les index de dépôts.

En général, l'index résultant doit être signé cryptographiquement avant que apk ne l'accepte. Voir abuild-sign(1) pour plus de détails.

OPTIONS

--description, -d TEXTE

Ajoute une description à l'index. En amont (upstream), cela est utilisé pour ajouter des informations de version basées sur le SHA du commit git de la tête de aports au moment de la génération de l'index.

--index, -x INDEX

Lit un index existant à partir de INDEX pour accélérer la création du nouvel index en réutilisant les données lorsque cela est possible.

--merge

Fusionne les paquets dans l'INDEX existant.

--no-warnings

Désactive l'avertissement concernant les dépendances manquantes. Cela se produit lorsque A dépend du paquet B, qui n'a pas de fournisseur dans le dépôt indexé.

--output, -o FICHIER

Écrit l'index généré dans FICHIER.

--prune-origin

Supprime les paquets de l'INDEX existant ayant la même origine que tout nouveau paquet lors de la fusion.

--rewrite-arch ARCH

Définit l'architecture de tous les paquets sur ARCH.

ENVIRONNEMENT

SOURCE_DATE_EPOCH

Utilisé comme date de construction pour les en-têtes de fichiers tar dans APKINDEX.tar.gz.
