RÉSUMÉ

Il n'y a rien dans ce module destiné à un usage public. Voir la documentation de cssh, crsh, ctel, ccon, ou cscp à la place.

DESCRIPTION

C'est le cœur d'App::ClusterSSH. Vous devriez probablement plutôt consulter cssh.
