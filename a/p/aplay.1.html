APLAY(1) Manuel des commandes générales APLAY(1)

NOM

arecord, aplay - enregistreur et lecteur audio en ligne de commande pour le pilote de carte son ALSA

SYNOPSIS

arecord [drapeaux] [nomdefichier]
aplay [drapeaux] [nomdefichier [nomdefichier]] ...

DESCRIPTION

arecord est un enregistreur de fichiers audio en ligne de commande pour le pilote de carte son ALSA. Il prend en charge plusieurs formats de fichiers et plusieurs cartes son avec plusieurs périphériques. Si l'enregistrement se fait en mode entrelacé, le fichier est automatiquement scindé avant la taille de fichier de 2 Go.

aplay est très similaire, il ne fait que lire au lieu d'enregistrer. Pour les formats de fichiers audio pris en charge, la fréquence d'échantillonnage, la profondeur de bits, etc. peuvent être déterminés automatiquement à partir de l'en-tête du fichier audio.

Si le nom de fichier n'est pas spécifié, la sortie ou l'entrée standard est utilisée. La aplay utilitaire accepte plusieurs noms de fichiers.

OPTIONS

-h, --help
Aide : affiche la syntaxe.
--version
Affiche la version actuelle.
-l, --list-devices
Liste toutes les cartes son et tous les périphériques audio numériques
-L, --list-pcms
Liste tous les PCM définis
-D, --device=NOM
Sélectionne le PCM par son nom
-q --quiet
Mode silencieux. Supprime les messages (pas le son :))
-t, --file-type TYPE
Type de fichier (voc, wav, raw ou au). Si ce paramètre est omis, le format WAVE est utilisé.
-c, --channels=#
Le nombre de canaux. Le défaut est un canal. Les valeurs valides vont de 1 à 32.
-f --format=FORMAT
Format d'échantillonnage
Les formats d'échantillonnage reconnus sont : S8 U8 S16_LE S16_BE U16_LE U16_BE S24_LE S24_BE U24_LE U24_BE S32_LE S32_BE U32_LE U32_BE FLOAT_LE FLOAT_BE FLOAT64_LE FLOAT64_BE IEC958_SUBFRAME_LE IEC958_SUBFRAME_BE MU_LAW A_LAW IMA_ADPCM MPEG GSM SPECIAL S24_3LE S24_3BE U24_3LE U24_3BE S20_3LE S20_3BE U20_3LE U20_3BE S18_3LE S18_3BE U18_3LE
Certains de ces formats peuvent ne pas être disponibles sur le matériel sélectionné.
Les raccourcis de format disponibles sont : 
-f cd (16 bits little endian, 44100, stéréo) [-f S16_LE -c2 -r44100]
-f cdr (16 bits big endian, 44100, stéréo) [-f S16_BE -c2 -r44100]
-f dat (16 bits little endian, 48000, stéréo) [-f S16_LE -c2 -r48000]
Si aucun format n'est donné, U8 est utilisé.
-r, --rate=#<Hz>
Fréquence d'échantillonnage en Hertz. La fréquence par défaut est de 8000 Hertz. Si la valeur spécifiée est inférieure à 300, elle est considérée comme la fréquence en kilohertz. Les valeurs valides vont de 2000 à 192000 Hertz.
-d, --duration=#
Interrompt après # secondes. Une valeur de zéro signifie l'infini. La valeur par défaut est zéro, donc si cette option est omise, le processus d'enregistrement/lecture s'exécutera jusqu'à ce qu'il soit tué. Les options '-d' et '-s' sont mutuellement exclusives.
-s, --samples=#
Interrompt après la transmission de # trames PCM. Une valeur de zéro signifie l'infini. La valeur par défaut est zéro, donc si cette option est omise, le processus d'enregistrement/lecture s'exécutera jusqu'à ce qu'il soit tué. Les options '-d' et '-s' sont mutuellement exclusives.
-M, --mmap
Utilise le mode d'E/S mémoire mappée (mmap) pour le flux audio. Si cette option n'est pas définie, le mode d'E/S lecture/écriture sera utilisé.
-N, --nonblock
Ouvre le périphérique audio en mode non bloquant. Si le périphérique est occupé, le programme se terminera immédiatement. Si cette option n'est pas définie, le programme se bloquera jusqu'à ce que le périphérique audio soit de nouveau disponible.
-F, --period-time=#
La distance entre les interruptions est de # microsecondes. Si ni la durée de période ni la taille de période ne sont données, un quart de la durée du tampon est défini.
-B, --buffer-time=#
La durée du tampon est de # microsecondes. Si ni la durée du tampon ni la taille du tampon ne sont données, la durée de tampon maximale autorisée mais pas plus de 500 ms est définie.
--period-size=#
La distance entre les interruptions est de # trames. Si ni la taille de période ni la durée de période ne sont données, un quart de la taille du tampon est défini.
--buffer-size=#
La durée du tampon est de # trames. Si ni la durée du tampon ni la taille du tampon ne sont données, la durée de tampon maximale autorisée mais pas plus de 500 ms est définie.
-A, --avail-min=#
L'espace minimum disponible pour le réveil est de # microsecondes
-R, --start-delay=#
Le délai pour le démarrage automatique du PCM est de # microsecondes (relatif à la taille du tampon si <= 0)
-T, --stop-delay=#
Le délai pour l'arrêt automatique du PCM est de # microsecondes depuis xrun
-v, --verbose
Affiche la structure et la configuration du PCM. Cette option est cumulative. Le VU-mètre est affiché lorsque cette option est donnée deux ou trois fois.
-V, --vumeter=TYPE
Spécifie le type de VU-mètre, soit stereo ou mono. Le VU-mètre stéréo n'est disponible que pour les échantillons stéréo à 2 canaux au format entrelacé.
-I, --separate-channels
Un fichier pour chaque canal. Cette option désactive max-file-time et use-strftime, et ignore SIGUSR1. Le VU-mètre stéréo n'est pas disponible avec des canaux séparés.
-P
Lecture. C'est le comportement par défaut si le programme est invoqué en tapant aplay.
-C
Enregistrement. C'est le comportement par défaut si le programme est invoqué en tapant arecord.
-i, --interactive
Autorise l'opération interactive via stdin. Actuellement, seule la pause/reprise via la touche espace ou entrée est implémentée.
-m, --chmap=ch1,ch2,...
Donne la carte des canaux à remplacer ou à suivre. Passez des chaînes de position de canal comme FL, FR, etc.

Si un périphérique prend en charge le remplacement de la carte des canaux, aplay essaie de passer la carte des canaux donnée. S'il ne prend pas en charge le remplacement de la carte des canaux mais fournit quand même les informations de la carte des canaux, aplay essaie de réorganiser l'ordre des canaux dans le tampon pour qu'il corresponde à la carte des canaux renvoyée par le périphérique.

--disable-resample
Désactive le rééchantillonnage automatique de la fréquence.
--disable-channels
Désactive les conversions automatiques de canaux.
--disable-format
Désactive les conversions automatiques de format.
--disable-softvol
Désactive le contrôle de volume logiciel (softvol).
--test-position
Teste la position du tampon circulaire.
--test-coef=<coef>
Teste le coefficient pour la position du tampon circulaire ; la valeur par défaut est 8. L'expression de validation est : coef * (buffer_size / 2). La valeur minimale est 1.
--test-nowait
N'attend pas le tampon circulaire ‐ consomme tout le CPU.
--max-file-time
Pendant l'enregistrement, lorsque le fichier de sortie a accumulé du son pendant cette durée, le fermez et ouvrez un nouveau fichier de sortie. La valeur par défaut est la taille maximale prise en charge par le format de fichier : 2 Gio pour les fichiers WAV. Cette option n'a aucun effet si --separate-channels est spécifié.
--process-id-file <nomdefichier>
aplay écrit son ID de processus ici, afin que d'autres programmes puissent lui envoyer des signaux.
--use-strftime
Lors de l'enregistrement, interprète les codes %-codes dans le paramètre de nom de fichier en utilisant la fonctionnalité strftimeer le fichier de sortie est ouvert. Les codes strftime importants sont : %Y pour l'année, %m pour le mois, %d pour le jour du mois, %H pour l'heure, %M pour la minute et %S pour la seconde. De plus, %v est le numéro du fichier, commençant à 1. Lorsque cette option est spécifiée, les répertoires intermédiaires pour le fichier de sortie sont créés automatiquement. Cette option n'a aucun effet si --separate-channels est spécifié.
--dump-hw-params
Affiche les paramètres matériels (hw_params) du statut préconfiguré de l'appareil sur stderr. L'affichage liste les capacités de l'appareil sélectionné telles que les formats pris en charge, les fréquences d'échantillonnage, le nombre de canaux, et les octets/tailles/temps de période et de tampon. Pour le périphérique brut hw:X, cette option affiche essentiellement les capacités matérielles de la carte son.
--fatal-errors
Désactive les tentatives de récupération lors d'erreurs (par exemple, xrun) ; le processus aplay se termine immédiatement.

SIGNALS

Lors de l'enregistrement, SIGINT, SIGTERM et SIGABRT fermeront le fichier de sortie et quitteront. SIGUSR1 fermera le fichier de sortie, en ouvrira un nouveau et continuera l'enregistrement. Cependant, SIGUSR1 ne fonctionne pas avec --separate-channels.

EXEMPLES

aplay -c 1 -t raw -r 22050 -f mu_law foobar
jouera le fichier brut « foobar » comme un fichier .au Mu-Law de 22050 Hz, mono, 8 bits.
arecord -d 10 -f cd -t wav -D copy foobar.wav
enregistrera foobar.wav comme un fichier wave de qualité CD de 10 secondes, en utilisant le PCM « copy » (qui pourrait être défini dans le fichier .asoundrc de l'utilisateur comme : 
pcm.copy {
  type plug
  slave {
    pcm hw
  }
  route_policy copy
}
arecord -t wav --max-file-time 30 mon.wav
Enregistre depuis la source audio par défaut en mono, 8 000 échantillons par seconde, 8 bits par échantillon. Commence un nouveau fichier toutes les 30 secondes. Les noms de fichiers sont mon-nn.wav, où nn augmente à partir de 01. Le fichier après mon-99.wav est mon-100.wav.
arecord -f cd -t wav --max-file-time 3600 --use-strftime %Y/%m/%d/listen-%H-%M-%v.wav
Enregistre en stéréo depuis la source audio par défaut. Crée un nouveau fichier toutes les heures. Les fichiers sont placés dans des répertoires basés sur leurs dates de début et ont des noms qui incluent leurs heures de début et leurs numéros de fichier.
