NOM

apfsck - vérifier un système de fichiers APFS

SYNTAXE

apfsck [-cuvw] [-F tier2] périphérique

DESCRIPTION

À moins que vous ne soyez un développeur APFS, vous ne vous intéresserez probablement pas à cet outil. Il est uniquement destiné aux tests et pourrait potentiellement être dangereux s'il est exécuté sur un système de fichiers créé de manière malveillante.

apfsck est un outil expérimental qui vérifie l'intégrité d'un système de fichiers APFS. Lorsqu'un problème est trouvé, il est signalé, mais aucune réparation n'est tentée. Pour cela, vous devriez utiliser les outils officiels fournis par Apple.

OPTIONS

-c
Signaler si le système de fichiers présente des signes d'un crash récent.
-u
Signaler la présence de fonctionnalités inconnues/non prises en charge.
-v
Afficher le numéro de version de apfsck et quitter.
-w
Signaler des incohérences inexpliquées qui peuvent ou non être des corruptions.
-F tier2
Spécifier le périphérique de niveau 2 (tier 2) pour un Fusion Drive.

STATUT DE SORTIE

Le statut de sortie est 0 s'il n'y avait rien à signaler, 1 sinon.

SIGNALEMENT DE BOGUES

Veuillez signaler les bogues par e-mail ou, si vous préférez, créer un ticket sur github à l'adresse https://github.com/eafer/apfsprogs/issues.
