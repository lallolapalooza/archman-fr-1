apk-info(8) Manuel de l'administrateur système apk-info(8)

NOM

apk info - affiche des informations détaillées sur les paquets

SYNTAXE

apk info [<options>...] paquets...

apk info -W fichier

DESCRIPTION

apk info affiche les informations connues sur les paquets listés. Par défaut, il affiche la description, la page web et la taille installée du paquet (équivalent à apk info -dws).

Chaque champ affiché est précédé du nom du paquet et de sa version, puis du champ à afficher, et d'un saut de ligne. Les lignes suivantes affichent les informations appropriées, puis une ligne vide termine ce champ.

apk info -W fichier affiche le paquet qui possède le fichier spécifié.

OPTIONS

En plus des options globales (voir apk(8)), et des options de requête (voir apk-query(8)), les options suivantes sont supportées :

--all, -a

Liste toutes les informations connues sur le paquet.

--contents, -L

Liste les fichiers inclus dans le paquet.

--depends, -R

Liste les dépendances du paquet.

--description, -d

Affiche la description du paquet.

--exists, --installed, -e

Vérifie le statut d'installation du paquet. Pour chaque paquet installé, affiche son nom. Le code de retour est le nombre de paquets donnés non installés. Ainsi, zéro (ou succès) est retourné si tous les paquets nommés sont installés. NOTE : --installed est obsolète et sera supprimé pour permettre le même fonctionnement à l'option du groupe query.

--install-if

Liste la règle install_if du paquet. Lorsque les dépendances dans cette liste sont satisfaites, le paquet sera installé automatiquement.

--license

Affiche l'identifiant de licence SPDX du paquet.

--provides, -P

Liste ce que le paquet fournit.

--rdepends, -r

Liste les dépendances inverses du paquet (tous les autres paquets qui dépendent du paquet).

--replaces

Liste les autres paquets pour lesquels ce paquet est marqué comme remplacement.

--rinstall-if

Liste les autres paquets dont les règles install_if font référence à ce paquet.

--size, -s

Affiche la taille installée du paquet.

--triggers, -t

Affiche les déclencheurs actifs pour le paquet.

--webpage, -w

Affiche l'URL de la page web en amont du paquet.

--who-owns, -W

Affiche le paquet qui possède le fichier spécifié.
