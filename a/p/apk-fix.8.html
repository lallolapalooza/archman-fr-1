apk-fix(8) Manuel du gestionnaire système apk-fix(8)

NOM

apk fix - réparer des paquets ou le système

SYNTAXE

apk fix [<options>...] [paquets...]

DESCRIPTION

apk fix applique des stratégies de réparation pour corriger les erreurs dans l'installation des paquets spécifiés, ou de tous les paquets installés si aucun n'est spécifié.

OPTIONS

apk fix prend en charge les options de commit décrites dans apk(8), ainsi que les options suivantes :

--depends, -d

Répare également les dépendances des paquets spécifiés.

--directory-permissions

Réinitialise toutes les permissions de répertoires.

--reinstall, -r

Réinstalle les paquets (par défaut).

--upgrade, -u

Met à niveau le nom PAQUET si une mise à niveau existe et ne casse pas les dépendances.

--xattr, -x

Répare les paquets avec des xattrs corrompus.
