APPLYGNUPGDEFAULTS(8) GNU Privacy Guard 2.4 APPLYGNUPGDEFAULTS(8)

NOM

applygnupgdefaults - Exécuter gpgconf --apply-defaults pour tous les utilisateurs.

SYNTAXE

applygnupgdefaults

DESCRIPTION

Ceci est un script hérité. Les applications modernes devraient utiliser les fichiers de configuration globaux par composant sous ‘/etc/gnupg/’.

Ce script est un wrapper autour de gpgconf pour l'exécuter avec la commande --apply-defaults pour tous les utilisateurs réels ayant un répertoire d'accueil GnuPG existant. Les administrateurs voudront peut-être utiliser ce script pour mettre à jour les fichiers de configuration GnuPG pour tous les utilisateurs après la modification de ‘/etc/gnupg/gpgconf.conf’. Cela permet d'imposer certaines politiques à tous les utilisateurs. Notez que ce n'est pas une méthode infaillible pour forcer un utilisateur à utiliser certaines options. Un utilisateur peut toujours modifier directement les fichiers de configuration et contourner gpgconf.

applygnupgdefaults est invoqué par root comme suit :

applygnupgdefaults
