DESCRIPTIO

N

Ce script fournit une interface en ligne de commande (pas un shell) à CPAN. Pour le moment, il utilise CPAN.pm pour faire le travail, mais ce n'est pas une commande unique pour CPAN.

pm.

Option

Variables

d'environnement

Il y a plusieurs composants dans CPAN.pm qui utilisent des variables d'environnement. Les outils de construction, ExtUtils::MakeMaker et Module::Build en utilisent certaines, tandis que d'autres sont importantes pour les niveaux au-dessus d'eux. Certaines de ces variables sont spécifiées par le Perl Toolchain Gang

:

Consensus de Lancaster : https://github.com/Perl-Toolchain-Gang/toolchain-site/blob/master/lancaster-consensus.

md

Consensus d'Oslo : https://github.com/Perl-Toolchain-Gang/toolchain-site/blob/master/oslo-consensus.

md
NONINTERACTIVE_TEST
ING
Suppose que personne ne fait attention et ignore les invites pour les distributions qui le font correctement. cpan(1) définit cette variable à 1 sauf si elle a déjà une valeur (même si cette valeur est fausse)
.
PERL_MM_USE_DEFA
ULT
Utilise la réponse par défaut pour les questions avec invite. cpan(1) définit cette variable à 1 sauf si elle a déjà une valeur (même si cette valeur est fausse)
.
CPAN_OP
TS
Comme pour "PERL5OPT", une chaîne d'options cpan(1) supplémentaires à ajouter à celles que vous spécifiez sur la ligne de
commande.
CPANSCRIPT_LOGLE
VEL
Le niveau de journalisation à utiliser, avec le journaliseur intégré minimal ou Log::Log4perl s'il est installé. Les valeurs possibles sont les mêmes que les niveaux de "Log::Log4perl" : "TRACE", "DEBUG", "INFO", "WARN", "ERROR" et "FATAL". La valeur par défaut est "INFO
".

La méthode "run" renvoie 0 en cas de succès et un nombre positif en cas d'échec. Voir la section sur les CODES DE SORTIE pour les détails sur les
