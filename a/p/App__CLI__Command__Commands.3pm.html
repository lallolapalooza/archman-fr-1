NOM

App::CLI::Command::Commands - Affiche une liste de commandes pour votre application

SYNTAXE

package MyApp;
use base qw(App::CLI App::CLI::Command);
# Faire en sorte que votre application obtienne une liste de commandes
use constant alias => (
    commands => '+App::CLI::Command::Commands',
);
1;

DESCRIPTION

Affiche une liste des commandes enregistrées pour votre application ;
