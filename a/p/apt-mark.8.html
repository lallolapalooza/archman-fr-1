DESCRIPTIO

N

apt-mark peut être utilisé comme interface unifiée pour définir divers paramètres pour un paquet, comme marquer un paquet comme étant installé automatiquement/manuellement ou modifier les sélections de dpkg telles que hold, install, deinstall et purge qui sont respectées, par exemple, par apt-get dselect-upgrade ou apti

tud
e.

PAQUETS INSTALLÉS AUTOMATIQUEMENT ET

MANUELLEMENT

Lorsque vous demandez l'installation d'un paquet et qu'en conséquence d'autres paquets sont installés pour satisfaire ses dépendances, les dépendances sont marquées comme étant installées automatiquement, tandis que le paquet que vous avez installé explicitement est marqué comme installé manuellement. Une fois qu'un paquet installé automatiquement n'est plus dépendu par aucun paquet installé manuellement, il est considéré comme n'étant plus nécessaire et, par exemple, apt-get ou aptitude suggéreront au moins de les

supprimer.

aut

o
auto est utilisé pour marquer un paquet comme étant installé automatiquement, ce qui entraînera la suppression du paquet lorsqu'aucun paquet installé manuellement ne dépendra plus de ce
paquet.

manua

l
manual est utilisé pour marquer un paquet comme étant installé manuellement, ce qui empêchera le paquet d'être automatiquement supprimé si aucun autre paquet n'en
dépend.

minimize-manua

l
minimize-manual est utilisé pour marquer les dépendances (transitives) des méta-paquets comme installées automatiquement. Cela peut être utilisé après une installation, par exemple, pour minimiser le nombre de paquets installés manuellement ; ou en continu sur les systèmes gérés par des méta-paquets de configuration
système.

showaut

o
showauto est utilisé pour afficher une liste de paquets installés automatiquement avec chaque paquet sur une nouvelle ligne. Tous les paquets installés automatiquement seront listés si aucun paquet n'est donné. Si des paquets sont donnés, seuls ceux qui sont installés automatiquement seront
affichés.

showmanua

l
showmanual peut être utilisé de la même manière que showauto, sauf qu'il affichera une liste de paquets installés manuellement à la
place.

hold est utilisé pour marquer un paquet comme retenu, ce qui empêchera le paquet d'être automatiquement installé, mis à jour ou
supprimé.

PLANIFIER L'INSTALLATION, LA SUPPRESSION ET LE PURGE DES

PAQUETS

Certaines interfaces comme apt-get dselect-upgrade peuvent être utilisées pour appliquer les modifications précédemment planifiées à l'état d'installation des paquets. De telles modifications peuvent être planifiées avec les install, remove (aussi connu sous le nom de deinstall) et purge commandes. Les paquets avec une sélection spécifique peuvent être affichés avec showinstall, showremove et showpurge respectivement. Plus d'informations sur ces sélections dpkg peuvent être trouvées dans dpkg

(1
).

OPTION

S

-h, --hel

p
Afficher un résumé court de
l'utilisation.

-v, --versio

n
Afficher la version du
programme.

--audi

t
Afficher les messages d'audit (et de notification). Cela remplace l'option quiet, mais seulement pour les messages de notification, pas pour ceux de
progression.

-c, --config-fil

e
Fichier de configuration ; Spécifier un fichier de configuration à utiliser. Le programme lira le fichier de configuration par défaut puis ce fichier de configuration. Si des paramètres de configuration doivent être définis avant que les fichiers de configuration par défaut ne soient analysés, spécifiez un fichier avec la variable d'environnement APT_CONFIG. Voir apt.conf(5) pour les informations de
syntaxe.

-o, --optio

n
Définir un élément de configuration ; Cela définira un élément de configuration arbitraire. La syntaxe est -o Foo::Bar=bar. -o et --option peuvent être utilisés plusieurs fois pour définir différents
éléments.

--cli-versio

n
Demande une version CLI spécifique. Il s'agit d'un motif qui prend une version MAJEUR.MINEUR. Vous pouvez omettre la version MINEUR, auquel cas le niveau mineur le plus récent pris en charge sera utilisé.

Les pistes de version sont présentées comme suit : La version 3.2 a des versions équivalentes 0.32, 1.22 et 2.12, implémentant de nouvelles fonctionnalités pour leurs versions majeures

spécifiées.

Un cas particulier est le motif de version X.9 : Une version comme 2.9 est suivie de 3.0, mais 2.10 suit directement 2.8 ; étant donné que nous utilisons les numéros de version impairs comme séries de développement (2.9 est la série de développement 3.0)

.

Cette fonctionnalité a été introduite dans APT 3.1.10 et remplace la configuration spécifique au binaire. Vous pouvez utiliser APT::Version pour un effet similaire sur les anciens binaires, par exemple, utilisez -o APT::Version=2 pour faire apt(8) se comporter comme la série 2.

x.

La valeur par défaut est la version APT actuelle pour apt(8) et 0.(10 * majeur + mineur) pour les commandes classiques. La série 0.X est o

bsolète de manière douce et les autres command
es passeront à la série 2.x dans le futur.

--no-color, --colo

r
Activer ou désactiver les couleurs. Les couleurs sont activées par défaut sur les terminaux pris en charge pour apt(8) et peuvent aussi être désactivées en utilisant les variables d'environnement NO_COLOR ou APT_NO_COLOR, ou encore configurées par l'élément de configuration et la portée APT::Color, voir apt.conf(5) pour des i
nformations
à ce sujet.
