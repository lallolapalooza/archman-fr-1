NOM

apk convdb - convertir la base de données installée v2 au format v3

SYNTAXE

apk convdb

DESCRIPTION

apk convdb convertit la base de données installée actuelle au format v3 et génère un fichier installed.adb correspondant.

OPTIONS

apk convdb ne prend en charge aucune option spécifique. Voir apk(8) pour les options globales.
