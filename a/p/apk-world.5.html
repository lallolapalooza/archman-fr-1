NOM

/etc/apk/world - liste des contraintes pour la sélection des paquets

DESCRIPTION

Dans /etc/apk/world, apk maintient le monde, c'est-à-dire une liste des contraintes que la sélection des paquets doit satisfaire.

Si vous modifiez ce fichier manuellement, vous devriez exécuter apk-fix(8) pour appliquer les changements.

SPÉCIFICATION DES PAQUETS

C'est un fichier texte brut avec une contrainte par ligne utilisant la notation de dépendance. Chaque ligne a le format : [!]nom{@tag}{[<>~=]version}.

Lors de la modification d'une installation existante, la version installée est préférée à moins qu'une mise à niveau ne soit demandée ou qu'une contrainte du monde ou une dépendance de paquet n'exige une version alternative.

Pour activer la sélection à partir d'un dépôt étiqueté, utilisez le format nom@tag, par exemple busybox@edge. Voir apk-repositories(5) pour plus de détails sur les dépôts de paquets étiquetés. Les dépôts sans étiquette sont également pris en compte pour les contraintes avec une étiquette. L'étiquette est héritée par toutes les dépendances en tant que dépôt autorisé. C'est-à-dire que les dépendances sont sélectionnées à partir du dépôt étiqueté si le nom@tag a une dépendance avec une contrainte de version exigeant une version disponible uniquement à partir du dépôt étiqueté. Si la dépendance peut être satisfaite par un dépôt non étiqueté, elle sera préférée.

Pour contraindre les versions acceptables du paquet, utilisez les opérateurs =, <, >, >=, ~, >~ ou <~. Respectivement, ceux-ci exigent que le paquet soit égal à, inférieur à, supérieur à, supérieur ou égal à, corresponde au préfixe, supérieur ou correspond au préfixe, ou inférieur ou correspond au préfixe à la version spécifiée. L'opérateur ~ limite le paquet à une correspondance de préfixe du numéro de version.

Le ! optionnel devant le nom transforme la contrainte de dépendance en conflit et garantit qu'aucun paquet correspondant à la spécification n'est installé.

busybox

Installe busybox à partir du dépôt non étiqueté à partir duquel il est disponible.

busybox@edge

Autorise l'installation de busybox et de ses dépendances à partir d'un dépôt étiqueté "edge". Les dépôts étiquetés ne seront pas priorisés. Si une version d'un dépôt non étiqueté correspond mieux, elle sera utilisée.

!unwanted

Empêche l'installation de unwanted comme dépendance en créant un conflit.

busybox=1.6.1

Installe la version 1.6.1 de busybox.

busybox>1.6.1

Installe une version de busybox supérieure à 1.6.1.

busybox>=1.6.1

Installe une version de busybox supérieure ou égale à 1.6.1.

busybox<1.6.1

Installe une version de busybox inférieure à 1.6.1.

busybox~1.6

Installe toute version de busybox commençant par 1.6. Exemples de correspondance : 1.6, 1.6.0_pre1, 1.6.0, 1.6.5, 1.6.9_p1.

busybox>~1.6

Installe une version de busybox supérieure ou une correspondance de préfixe de 1.6.

busybox<~1.6

Installe une version de busybox inférieure ou une correspondance de préfixe de 1.6.
