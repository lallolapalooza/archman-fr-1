NOM

apt-sortpkgs - Utilitaires pour trier les fichiers d'index de paquets

SYNTAXE

apt-sortpkgs [-s] [-o=config_string] [-c=config_file] filename... {-v | --version} {-h | --help}

DESCRIPTION

apt-sortpkgs prend un fichier d'index (index source ou index de paquets) et trie les enregistrements afin qu'ils soient ordonnés par le nom du paquet. Il trie également les champs internes de chaque enregistrement selon les règles de tri internes.

Toute la sortie est envoyée sur la sortie standard ; l'entrée doit être un fichier consultable.

OPTIONS

Toutes les options de ligne de commande peuvent être définies à l'aide du fichier de configuration, les descriptions indiquent l'option de configuration à définir. Pour les options booléennes, vous pouvez outrepasser le fichier de configuration en utilisant quelque chose comme -f-,--no-f, -f=no ou plusieurs autres variations.

-s, --source

Utilise l'ordre des champs de l'index source. Élément de configuration : APT::SortPkgs::Source.

-h, --help

Affiche un bref résumé d'utilisation.

-v, --version

Affiche la version du programme.

--audit

Affiche les messages d'audit (et de notification). Ceci outrepasse l'option silencieuse, mais uniquement pour les messages de notification, pas ceux de progression.

-c, --config-file

Fichier de configuration ; Spécifie un fichier de configuration à utiliser. Le programme lira le fichier de configuration par défaut, puis ce fichier de configuration. Si des paramètres de configuration doivent être définis avant que les fichiers de configuration par défaut ne soient analysés, spécifiez un fichier avec la variable d'environnement APT_CONFIG. Voir apt.conf(5) pour la syntaxe.

-o, --option

Définit une option de configuration ; Ceci définira une option de configuration arbitraire. La syntaxe est -o Foo::Bar=bar. -o et --option peuvent être utilisés plusieurs fois pour définir différentes options.

--cli-version

Demande une version CLI spécifique. C'est un modèle qui prend une version MAJEURE.MINEURE. Vous pouvez omettre la version MINEURE, auquel cas le niveau mineur le plus récent pris en charge sera utilisé.

Les pistes de version sont présentées comme suit : La version 3.2 a des versions équivalentes 0.32, 1.22 et 2.12, implémentant de nouvelles fonctionnalités pour leurs versions majeures spécifiées.

Un cas spécial est le modèle de version X.9 : une version comme 2.9 est suivie de 3.0, mais 2.10 suit directement 2.8 ; étant donné que nous utilisons des numéros de version impairs comme séries de développement (2.9 est la série de développement 3.0).

Cette fonctionnalité a été introduite dans APT 3.1.10 et remplace la configuration spécifique aux binaires. Vous pouvez utiliser APT::Version dans un but similaire sur des binaires plus anciens, par exemple, utilisez -o APT::Version=2 pour que apt(8) se comporte comme la série 2.x.

La valeur par défaut est la version APT actuelle pour apt(8) et 0.(10 * majeure + mineure) pour les commandes classiques. La série 0.X est en cours de dépréciation et les autres commandes migreront vers la série 2.x à l'avenir.

--no-color, --color

Active ou désactive les couleurs. Les couleurs sont activées par défaut sur les terminaux pris en charge pour apt(8) et peuvent également être désactivées à l'aide des variables d'environnement NO_COLOR ou APT_NO_COLOR, ou configurées davantage par l'option de configuration APT::Color et sa portée, voir apt.conf(5) pour plus d'informations à ce sujet.

VOIR AUSSI

apt.conf(5)

DIAGNOSTICS

apt-sortpkgs retourne zéro en cas d'opération normale, et 100 décimal en cas d'erreur.

BOGUES

Page des bogues d'APT[1]. Si vous souhaitez signaler un bogue dans APT, veuillez consulter /usr/share/doc/debian/bug-reporting.txt ou la commande reportbug(1).
