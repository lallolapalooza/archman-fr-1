AppConfig::CGI(3) Documentation Perl fournie par l'utilisateur AppConfig::CGI(3)

NOM

AppConfig::CGI - Module Perl5 pour le traitement des paramètres de script CGI.

SYNTAXE

use AppConfig::CGI;
my $state = AppConfig::State->new(\%cfg);
my $cgi   = AppConfig::CGI->new($state);
$cgi->parse($cgi_query);
$cgi->parse();               # recherche la requête CGI dans l'environnement

VUE D'ENSEMBLE

AppConfig::CGI est un module Perl5 qui implémente une interface CGI pour AppConfig. Il examine la variable d'environnement QUERY_STRING, ou une chaîne passée explicitement par paramètre, qui représente les paramètres supplémentaires passés à une requête CGI. Ceci est ensuite utilisé pour mettre à jour les valeurs des variables dans un objet AppConfig::State en conséquence.

AppConfig::CGI est distribué dans le cadre du bundle AppConfig.

DESCRIPTION

UTILISATION DU MODULE AppConfig::CGI

Pour importer et utiliser le module AppConfig::CGI, la ligne suivante doit apparaître dans votre script Perl :

use AppConfig::CGI;

AppConfig::CGI est utilisé automatiquement si vous utilisez le module AppConfig et créez un objet AppConfig::CGI via la méthode cgi(). AppConfig::CGI est implémenté à l'aide de méthodes orientées objet. Un nouvel objet AppConfig::CGI est créé et initialisé à l'aide de la méthode new(). Celle-ci renvoie une référence à un nouvel objet AppConfig::CGI. Une référence à un objet AppConfig::State doit être passée comme premier paramètre :

my $state = AppConfig::State->new();
my $cgi   = AppConfig::CGI->new($state);

Cela créera et renverra une référence à un nouvel objet AppConfig::CGI.

TRAITEMENT DES REQUETES CGI

La méthode parse() est utilisée pour traiter une requête CGI qui peut être spécifiée explicitement, ou est automatiquement extraite de la variable d'environnement CGI "QUERY_STRING". Cela limite actuellement le module à ne supporter que la méthode GET.

Voir AppConfig pour des informations sur l'utilisation du module AppConfig::CGI via la méthode cgi().
