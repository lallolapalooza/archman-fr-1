DESCRIPTIO

N

apparmor_parser est utilisé comme outil général pour compiler et gérer la politique AppArmor, y compris le chargement de nouveaux apparmor.d(5) profils dans le noyau

Linux.

Les profils AppArmor restreignent les opérations disponibles aux

processus.

Les profils sont chargés dans le noyau Linux par le programme apparmor_parser. Les profils peuvent être spécifiés par un nom de fichier ou un nom de répertoire contenant un ensemble de profils. Si un répertoire est spécifié, alors le apparmor_parser essaiera de charger un profil pour chaque fichier du répertoire qui n'est pas un fichier caché, ou explicitement sur liste noire (*.dpkg-new, *.dpkg-old, *.dpkg-dist, *.dpkg-bak, *.dpkg-remove, *.pacsave, *.pacnew, *.rpmnew, *.rpmsave, *.orig, *.rej, *~). Le apparmor_parser prendra l'entrée depuis l'entrée standard si un profil ou un répertoire n'est pas

fourni.

L'entrée fournie à apparmor_parser doit être au format décrit dans apparmo

r.d
(5).

La valeur devrait être légèrement plus grande que la plus grande taille de résident (RSS) rencontrée pour le type de politique

La valeur spécifiée peut inclir un suffixe de KB, MB, GB, pour faciliter l'ajustement de la

FICHIER DE

CONFIGURATION

Un fichier de configuration facultatif /etc/apparmor/parser.conf peut être utilisé pour spécifier les options par défaut de l'analyseur, qui peuvent ensuite être remplacées à l'aide des options de la ligne de

commande.

Le fichier de configuration ignore les espaces en début de ligne et traite les lignes commençant par # comme des commentaires. Les options de configuration sont spécifiées une par ligne en utilisant le même format que les options de ligne de commande longues (sans le -- précédent)

.

Ex.
#commentair

e 
optimize=no-expr-tree
optimize=compress-fas
t

Comme pour la ligne de commande, certaines options s'accumulent et d'autres remplacent, c.-à-d. lorsqu'il y a des versions contradictoires d'un commutateur, la dernière option est celle

choisie.

Ex.
Optimize=no-minimize
Optimize=minimiz

e

donnerait Optimize=minimize comme

résultat.

Les options Include, Dump et Optimize s'accumulent, sauf pour l'option d'inversion (no-X vs. X) et quelques options qui fonctionnent en définissant/effaçant plusieurs options (compress-small). Dans ce cas, l'option remplacera les indicateurs qu'elle définit mais pourra s'accumuler avec

d'autres.

Toutes les autres option

s remplacent les valeur
s précédemment définies.
