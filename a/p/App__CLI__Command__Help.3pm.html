NOM

App::CLI::Command::Help

SYNTAXE

package MyApp::Help;
use base qw(App::CLI::Command::Help);
sub run {
    my $self = shift;
    # prétraitement
    $self->SUPER::run(@_);  # App::CLI::Command::Help afficherait la POD de chaque commande
}

DESCRIPTION

Votre classe de commande doit être capitalisée.

Pour ajouter un message d'aide, ajoutez simplement une POD dans la classe de commande :

package YourApp::Command::Foo;
=head1 NOM
YourApp::Command::Foo - exécuter foo
=head1 DESCRIPTION
blah blah
=head1 UTILISATION
....
=cut
