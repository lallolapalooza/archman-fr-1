NOM

apk search - rechercher des paquets par nom ou description

SYNTAXE

apk search [<options>...] motif...

DESCRIPTION

apk search recherche dans tous les dépôts des paquets correspondant à au moins un motif. Si aucun motif n'est donné, il liste tous les paquets des dépôts configurés (voir apk-repositories(5)). Un motif correspond s'il s'agit d'une sous-chaîne insensible à la casse du nom du paquet.

OPTIONS

En plus des options globales (voir apk(8)), et des options de requête (voir apk-query(8)), les options suivantes sont supportées :

--all, -a

Affiche toutes les versions correspondantes des paquets. Par défaut, apk n'affiche que la dernière version.

--description, -d

Recherche également le motif dans la description du paquet. Par défaut, apk ne recherche pas dans les descriptions de paquets.

--exact, -e, -x

Correspondance exacte des noms de paquets.

--has-origin

Correspondance par origine du paquet. Affiche tous les paquets dont le nom de paquet de base correspond exactement au motif. Implique --all et --exact.

--origin, -o

Affiche le nom de paquet de base.

--rdepends, -r

Affiche les dépendances inverses (autres paquets qui dépendent du paquet).
