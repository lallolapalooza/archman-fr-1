NOM

apachectl - Interface de contrôle du serveur Apache HTTP

SYNTAXE

Lorsqu'il agit en mode de transmission directe, apachectl peut prendre tous les arguments disponibles pour le binaire httpd.

apachectl [ argument-httpd ]

Lorsqu'il agit en mode d'initialisation SysV, apachectl prend des commandes simples d'un seul mot, définies ci-dessous.

apachectl commande

RÉSUMÉ

apachectl est une interface pour le serveur Apache HyperText Transfer Protocol (HTTP). Il est conçu pour aider l'administrateur à contrôler le fonctionnement du démon Apache httpd.

Le script apachectl peut fonctionner dans deux modes. Premièrement, il peut agir comme une simple interface pour la commande httpd qui définit simplement les variables d'environnement nécessaires, puis invoque httpd, transmettant tous les arguments de la ligne de commande. Deuxièmement, apachectl peut agir comme un script d'initialisation SysV, prenant des arguments simples d'un seul mot comme start, restart et stop, et les traduisant en signaux appropriés pour httpd.

Si votre installation Apache utilise des chemins non standard, vous devrez modifier le script apachectl pour définir les chemins appropriés vers le binaire httpd. Vous pouvez également spécifier tous les arguments de ligne de commande httpd nécessaires. Voir les commentaires dans le script pour plus de détails.

Le script apachectl retourne une valeur de sortie de 0 en cas de succès, et >0 en cas d'erreur. Pour plus de détails, consultez les commentaires dans le script.

OPTIONS

Seules les options de style d'initialisation SysV sont définies ici. Les autres arguments sont définis dans la page de manuel de httpd.

start
Démarre le démon Apache httpd. Donne une erreur s'il est déjà en cours d'exécution. Ceci est équivalent à apachectl -k start.
stop
Arrête le démon Apache httpd. Ceci est équivalent à apachectl -k stop.
restart
Redémarre le démon Apache httpd. Si le démon n'est pas en cours d'exécution, il est démarré. Cette commande vérifie automatiquement les fichiers de configuration comme dans configtest avant d'initier le redémarrage pour s'assurer que le démon ne plante pas. Ceci est équivalent à apachectl -k restart.
fullstatus
Affiche un rapport d'état complet de mod_status. Pour que cela fonctionne, vous devez avoir mod_status activé sur votre serveur et un navigateur en mode texte tel que lynx disponible sur votre système. L'URL utilisée pour accéder au rapport d'état peut être définie en modifiant la variable STATUSURL dans le script.
status
Affiche un bref rapport d'état. Similaire à l'option fullstatus, sauf que la liste des requêtes actuellement servies est omise.
graceful
Redémarre gracieusement le démon Apache httpd. Si le démon n'est pas en cours d'exécution, il est démarré. Cela diffère d'un redémarrage normal en ce sens que les connexions ouvertes sont non pas interrompues. Un effet secondaire est que les anciens fichiers de log ne seront pas fermés immédiatement. Cela signifie que si utilisé dans un script de rotation de logs, un délai important peut être nécessaire pour garantir que les anciens fichiers de logs soient fermés avant de les traiter. Cette commande vérifie automatiquement les fichiers de configuration comme dans configtest avant d'initier le redémarrage pour s'assurer qu'Apache ne plante pas. Ceci est équivalent à apachectl -k graceful.
graceful-stop
Arrête gracieusement le démon Apache httpd. Cela diffère d'un arrêt normal en ce sens que les connexions ouvertes ne sont pas interrompues. Un effet secondaire est que les anciens fichiers de log ne seront pas fermés immédiatement. Ceci est équivalent à apachectl -k graceful-stop.
configtest
Exécute un test de syntaxe des fichiers de configuration. Il analyse les fichiers de configuration et signale soit Syntax Ok, soit des informations détaillées sur l'erreur de syntaxe particulière. Ceci est équivalent à apachectl -t.

L'option suivante était disponible dans les versions antérieures mais a été supprimée.

startssl
Pour démarrer httpd avec le support SSL, vous devriez modifier votre fichier de configuration pour inclure les directives pertinentes, puis utiliser le script normal apachectl start.
