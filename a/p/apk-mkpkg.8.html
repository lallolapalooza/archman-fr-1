NOM

apk mkpkg - créer des fichiers de paquet apkv3

SYNTAXE

apk mkpkg [<options>...]

DESCRIPTION

apk mkpkg crée un fichier de paquet à partir des métadonnées et des fichiers de données fournis.

OPTIONS

--compat APK_VERSION

Produit des paquets compatibles avec les versions apk spécifiées. La valeur par défaut est actuellement 3.0.0_pre1.

--files, -F CHEMIN

Spécifie le chemin de la racine de construction à partir duquel les fichiers sont collectés pour être inclus dans le paquet.

--info, -I CLE:VALEUR

Spécifie les métadonnées du paquet. Assigne un champ de métadonnées CLE avec la valeur VALEUR. Référez-vous à apk-package(5) pour la liste des champs de métadonnées APKv3. Ceci peut assigner soit au champ de métadonnées "package info" soit au champ de métadonnées "package".

--output, -o FICHIER

Spécifie le FICHIER comme nom de fichier de sortie. S'il n'est pas spécifié, un nom par défaut sera déduit des champs de métadonnées du paquet.

--rootnode[=BOOL]

Alias obsolète pour définir la version de compatibilité. yes se résout en --compat=3.0.0_pre1 et no en --compat=3.0.0_pre3.

--script, -s TYPE:SCRIPT

Ajoute le SCRIPT spécifié avec le TYPE. Référez-vous à la section MÉTADONNÉES DE PAQUET / scripts de apk-package(5) pour la liste des types de scripts et quand ils sont exécutés.

--stdout

Sort le paquet résultant sur la sortie standard.

--trigger, -t TRIGGER

Ajoute la spécification de chemin du TRIGGER à la liste des triggers qui affectent l'exécution du script trigger.
