NOM

App::Prove::State::Result::Test - Résultats de tests individuels.

VERSION

Version 3.50

DESCRIPTION

La commande "prove" prend en charge une option "--state" qui lui demande de stocker un état persistant entre les exécutions. Ce module encapsule les résultats d'un test unique.

SYNOPSIS

# Relancer les tests échoués
$ prove --state=failed,save -rbv

MÉTHODES

Méthodes de classe

"new"

Méthodes d'instance

"name"

Le nom du test. Généralement un nom de fichier.

"elapsed"

Le temps total écoulé que le test a pris pour s'exécuter, en secondes depuis l'époque..

"generation"

Le numéro de la « génération » de l'exécution du test. La première génération est 1 (un) et les générations suivantes sont 2, 3, etc.

"last_pass_time"

La dernière fois que le programme de test a réussi, en secondes depuis l'époque.

Retourne "undef" si le programme n'a jamais réussi.

"last_fail_time"

La dernière fois que la suite de tests a échoué, en secondes depuis l'époque.

Retourne "undef" si le programme n'a jamais échoué.

"mtime"

Retourne le mtime du test, en secondes depuis l'époque.

"raw"

Retourne un hashref de données brutes de test, adapté à la sérialisation par YAML.

"result"

Actuellement, indique si la suite de tests a réussi sans « problèmes » (comme les TODO réussis).

"run_time"

Le temps total nécessaire à l'exécution du test, en secondes. Si "Time::HiRes" est disponible, il aura une granularité plus fine.

"num_todo"

Le nombre de tests avec des directives TODO.

"sequence"

L'ordre dans lequel ce test a été exécuté pour le résultat de la suite de tests donné.

"total_passes"

Le nombre de fois où le test a réussi.

"total_failures"

Le nombre de fois où le test a échoué.

"parser"

L'objet analyseur sous-jacent. Ceci est utile si vous avez besoin des informations complètes pour le programme de test.
