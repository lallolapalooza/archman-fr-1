APCACCESS(8) Manuel du gestionnaire système APCACCESS(8)

NOM

apcaccess — récupérer les informations d'état de apcupsd(8)

SYNTAXE

apcaccess [-f <fichier-config>] [-h <hôte>[:<port>]] [-p <nom-paramètre>] [-u] [<commande>] [<hôte>[:<port>]]

DESCRIPTION

apcaccess est un programme qui affiche l'état complet de la plupart des onduleurs (UPS) d'American Power Conversion Corp. (APC) à condition que vous ayez le démon apcupsd(8) installé, correctement configuré et en cours d'exécution. Il peut accéder aux informations d'état de n'importe quel UPS APC connecté à la machine locale ou à n'importe quel ordinateur du réseau exécutant apcuspd en mode NIS.

Les options de ligne de commande sont :

-f
fichier de configuration d'apcupsd (le défaut est généralement /etc/apcupsd/apcupsd.conf)
-h
nom d'hôte et port d'apcupsd avec lesquels communiquer. Le nom d'hôte et le port par défaut sont obtenus à partir du fichier de configuration.
-p
Ne rapporter que la valeur du paramètre nommé au lieu de tous les paramètres et valeurs.
-u
Supprimer le champ d'unités pour faciliter l'analyse par des scripts.
<commande>
Une commande optionnelle, sauf si un nom d'hôte est également spécifié. La seule commande implémentée est status, abrégé de status localhost:3551. Ceci produit un affichage complet des informations d'état disponibles pour l'UPS associé.
<hôte>
Un nom d'hôte optionnel qui peut être un nom de machine simple, un nom de domaine entièrement qualifié ou une adresse IP.
:<port>
Un numéro de port optionnel où un argument de nom d'hôte a été spécifié. Le défaut est 3551, le numéro de port officiel attribué par l'IANA pour le serveur NIS d'apcupsd. Le nom d'hôte et le port par défaut sont obtenus à partir du fichier de configuration.

apcaccess utilise le serveur d'informations réseau (NIS) intégré à apcupsd -- sans lien avec le service NIS/YP de Sun -- pour obtenir les informations d'état actuelles de l'UPS sur l'ordinateur local ou distant. Il est donc nécessaire d'avoir les directives de configuration suivantes :


  • NETSERVER on

  • NISPORT 3551

dans le fichier de configuration /etc/apcupsd/apcupsd.conf afin que le serveur d'informations réseau soit accessible. Des règles de pare-feu pour un accès réseau approprié peuvent également être nécessaires.

FORMAT DU RAPPORT D'ÉTAT

Le format de sortie du rapport d'état est une simple chaîne ASCII. Généralement, une seule information se trouve sur chaque ligne de sortie. Le contenu varie en fonction du modèle d'UPS utilisé et, dans certains cas, de la version du micrologiciel.

EXTBATTS
: nombre de batteries externes (pour les modèles XL)
BADBATTS
: nombre de blocs de batteries externes défectueux (pour les modèles XL)
FIRMWARE
: version du micrologiciel de l'UPS
APCMODEL

NOM

apcaccess – obtenir des informations sur le statut de l'onduleur APC

SYNOPIS

apcaccess [ -aFfhHkKpqQSsUVw ] [ -d device ] [ -t timeout ] [ -u user ] [ -P password ] [ -r host ] [ -L logfile ] [ -l logfile ] [ -V value ] [ -i interval ] [ -e events ] [ -o options ] [ host... ]

DESCRIPTION

Le programme apcaccess est une interface en ligne de commande pour le démon apcupsd. Il interroge le démon apcupsd (qui est supposé être en cours d'exécution) et affiche une ou plusieurs des informations de statut disponibles auprès de l'onduleur APC. L'information peut être renvoyée sous forme de liste de paires clé-valeur, ou, si le commutateur -f est utilisé, sous forme de lignes de sortie uniques (une par élément). Si -F est utilisé, il renvoie une liste formatée de toutes les valeurs.

Il est également possible d'obtenir des informations spécifiques en les spécifiant comme argument. Les informations que apcupsd peut renvoyer sont les suivantes :

UPSNAME
: Nom de l'onduleur
CABLE
: Type de câble utilisé (RS232 ou USB)
MODEL
: Modèle de l'onduleur
DEVICE
: Périphérique utilisé par apcupsd
DRIVER
: Pilote utilisé par apcupsd
UPSMODE
: Mode de fonctionnement de l'onduleur (ex. : « Standby+AVR », « Online+DoubleConversion »)
STARTTIME
: Heure de démarrage du démon apcupsd
STATUS
: Statut actuel de l'onduleur : Online, Bushutdown, On Battery, Off, In test, FAIL, Unknown
LINEV
: Tension d'entrée actuelle
LOADPCT
: Pourcentage de la capacité de charge de l'onduleur utilisé tel qu'estimé par l'onduleur
BCHARGE
: Pourcentage de charge actuel de la capacité de la batterie
TIMELEFT
: Temps d'exécution restant sur la batterie tel qu'estimé par l'onduleur
MBATTCHG
: Pourcentage minimum de charge de batterie (BCHARGE) requis pour l'arrêt du système
MINTIMEL
: Temps d'exécution minimum de la batterie (MINUTES) requis pour l'arrêt du système
MAXTIME
: Temps d'exécution maximum de la batterie (TIMEOUT) après lequel le système est arrêté
*OUTPUTV
: Tension de sortie actuelle de l'onduleur
*DWAKE
: Temps d'attente de l'onduleur après une coupure de courant lorsque le courant est rétabli
*DSHUTD
: Délai avant que l'onduleur ne s'éteigne après réception de la commande
LOTRANS
: Tension d'entrée en dessous de laquelle l'onduleur passera sur batterie
HITRANS
: Tension d'entrée au-dessus de laquelle l'onduleur passera sur batterie
*RETPCT
: Pourcentage de charge de batterie requis après une coupure de courant pour rétablir le courant
*ITEMP
: Température interne de l'onduleur en degrés Celsius
ALARMDEL
: Période de délai avant que l'onduleur ne commence à sonner l'alarme
BATTV
: Tension de batterie actuelle
*LINEFREQ
: Fréquence de ligne actuelle en Hertz
*LASTXFER
: Raison du dernier transfert vers la batterie depuis le démarrage d'apcupsd
NUMXFERS
: Nombre de transferts vers la batterie depuis le démarrage d'apcupsd
XONBATT
: Date, heure du dernier transfert vers la batterie depuis le démarrage d'apcupsd
TONBATT
: Secondes actuellement sur batterie
CUMONBATT
: Secondes cumulées sur batterie depuis le démarrage d'apcupsd
XOFFBAT
: Date, heure du dernier transfert hors batterie depuis le démarrage d'apcupsd
SELFTEST
: Date et heure du dernier auto-test depuis le démarrage d'apcupsd
STATFLAG
: Indicateur de statut de l'onduleur en hexadécimal
MANDATE
: Date de fabrication de l'onduleur
SERIALNO
: Numéro de série de l'onduleur
BATTDATE
: Date de remplacement de la batterie (si définie)
NOMBATTV
