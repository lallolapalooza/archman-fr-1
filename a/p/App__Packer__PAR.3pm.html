App::Packer::PAR(3) Documentation Perl fournie par l'utilisateur App::Packer::PAR(3)

NOM

App::Packer::PAR - Empaqueter des applications dans un seul fichier exécutable

DESCRIPTION

Ce module est une version modifiée de App::Packer, temporairement livrée avec PAR jusqu'à ce qu'elle soit intégrée dans les versions plus récentes de App::Packer.

VOIR AUSSI

Voir App::Packer pour l'interface de programmation.
