NOM

aprofutil - Outil de profilage AOT de Mono

SYNTAXE

aprofutil [options] <votre-profil-aot.aotprofile>

DESCRIPTION

L'outil de profilage AOT est un outil pour inspecter les fichiers du profileur AOT.

Il peut être utilisé pour afficher, filtrer et écrire le contenu du fichier de profilage sous forme de texte lisible.

OPTIONS

  -h, --help, -?             Afficher ce message et quitter
  -a, --all                  Afficher les modules, types et méthodes dans le profil
  -d, --modules              Afficher les modules dans le profil
      --filter-method=VALEUR  Filtrer par méthode avec l'expression régulière VALEUR
      --filter-module=VALEUR  Filtrer par module avec l'expression régulière VALEUR
      --filter-type=VALEUR    Filtrer par type avec l'expression régulière VALEUR
  -m, --methods              Afficher les méthodes dans le profil
  -o, --output=VALEUR         Écrire le profil dans le fichier OUTPUT
  -s, --summary              Afficher le résumé du profil
  -t, --types                Afficher les types dans le profil
  -v, --verbose              Afficher des informations sur la progression pendant l'exécution
                               du outil

mono aprofutil.exe -sd startup.aotprofile
