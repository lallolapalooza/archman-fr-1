NOM

appstream-generator - Génère les métadonnées AppStream à partir des dépôts de distribution

SYNTAXE

appstream-generator [COMMANDE]

DESCRIPTION

Cette page de manuel documente brièvement la commande appstream-generator.

appstream-generator génère des métadonnées de catalogue AppStream à partir des dépôts d'une distribution logicielle. Il prend actuellement en charge les formats de dépôts / distributions suivants : Debian, Ubuntu, Arch Linux, RPM-MD (Fedora, Mageia).

Le générateur produira des fichiers de métadonnées de catalogue AppStream au format YAML ou XML AppStream pour être distribués aux utilisateurs, ainsi que des rapports HTML détaillés sur les composants trouvés et des rapports HTML et JSON sur les problèmes rencontrés lors de la compilation des métadonnées. Il lit les fichiers .desktop ainsi que les fichiers metainfo, rend les polices, met à l'échelle les images, met en cache les captures d'écran, etc., pour produire des métadonnées de haute qualité que les logiciels basés sur AppStream et d'autres outils peuvent consommer. Habituellement, appstream-generator est intégré au flux de travail de construction et de livraison de logiciels existant d'une distribution.

L'outil appstream-generator est basé sur la bibliothèque libappstream pour la conversion et l'analyse des métadonnées. Si vous souhaitez simplement intégrer le traitement des métadonnées AppStream dans un autre outil, l'utilisation directe de libappstream est probablement un meilleur choix. L'outil générateur effectue des tâches lourdes comme le rendu des polices et la mise à l'échelle des images, ce qui peut ne pas être nécessaire dans des cas simples.

Pour utiliser appstream-generator, un fichier asgen-config.json est requis. Son format est décrit en détail dans la documentation de asgen-config.json[1].

Le générateur prend en charge un large éventail de fonctionnalités qui peuvent être configurées individuellement pour répondre aux besoins de différents projets et adapter les métadonnées générées à des cas d'utilisation spécifiques. Reportez-vous à la documentation du fichier de configuration pour connaître les options disponibles.

Pour plus d'informations sur le projet AppStream et les autres composants qui en font partie, consultez les pages AppStream sur Freedesktop.org[2].

OPTIONS

run SUITE [SECTION]

Traite les nouvelles métadonnées pour la suite de distribution donnée et les publie.

cleanup

Nettoie les anciens fichiers de métadonnées/médias expirés du cache et des répertoires. Il est recommandé d'exécuter cette commande chaque semaine, ou au moins chaque mois, en fonction du nombre de modifications apportées au dépôt logiciel.

publish SUITE [SECTION]

Exporte toutes les métadonnées et publie les rapports dans les répertoires d'exportation.

Vous ne voudrez généralement pas exécuter cette tâche explicitement, car elle est déjà automatiquement effectuée par la commande run.

remove-found SUITE

Supprime toutes les métadonnées traitées et les indices valides de la suite sélectionnée.

forget PKID

Supprime toutes les informations que nous avons sur cet identifiant de paquet (partiel).

Un identifiant de paquet est un triplet nom/version/architecture. Pour cette commande, la version et l'architecture peuvent être omises pour omettre tous les paquets correspondant à un nom ou à une combinaison nom-version particulière.

info PKID

Affiche les informations associées à cet identifiant de paquet (complet).

Un identifiant de paquet est un triplet nom/version/architecture.

-w|--workspace DIR

Définit l'emplacement de l'espace de travail.

Si cet indicateur est omis et qu'aucun répertoire d'espace de travail n'est indiqué dans le fichier de configuration du générateur, le répertoire courant est supposé comme emplacement de l'espace de travail.

Ce paramètre, s'il est fourni, remplace tout emplacement d'espace de travail défini ailleurs.

-c|--config FICHIER

Définit un fichier de configuration.

Définit explicitement un fichier JSON de configuration du générateur. Si cet indicateur est omis, le fichier asgen-config.json dans le répertoire d'espace de travail courant est utilisé.

Si aucun répertoire d'espace de travail n'est défini dans le fichier de configuration lui-même, le répertoire dans lequel il se trouve est utilisé comme espace de travail. Cela peut être remplacé en définissant explicitement un espace de travail avec -w.

--force

Force la commande.

--verbose

Affiche des informations de débogage supplémentaires.

--version

Affiche le numéro de version de appstream-generator.
