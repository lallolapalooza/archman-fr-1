AppConfig::Sys(3) Documentation Perl fournie par l'utilisateur AppConfig::Sys(3)

NOM

AppConfig::Sys - Module Perl5 définissant les informations et méthodes spécifiques à la plateforme pour d'autres modules AppConfig::*.

SYNTAXE

use AppConfig::Sys;
my $sys = AppConfig::Sys->new();
@fields = $sys->getpwuid($userid);
@fields = $sys->getpwnam($username);

APERÇU

AppConfig::Sys est un module Perl5 fournissant des informations et des opérations spécifiques à la plateforme, nécessaires aux autres modules AppConfig::*.

AppConfig::Sys est distribué dans le cadre du bundle AppConfig.

DESCRIPTION

UTILISATION DU MODULE AppConfig::Sys

Pour importer et utiliser le module AppConfig::Sys, la ligne suivante doit apparaître dans votre script Perl :

use AppConfig::Sys;

AppConfig::Sys est implémenté à l'aide de méthodes orientées objet. Un nouvel objet AppConfig::Sys est créé et initialisé en utilisant la méthode AppConfig::Sys->new(). Celle-ci retourne une référence vers un nouvel objet AppConfig::Sys.

my $sys = AppConfig::Sys->new();

Cela tentera de détecter votre système d'exploitation et créera une référence vers un nouvel objet AppConfig::Sys applicable à votre plateforme. Vous pouvez spécifier explicitement un nom de système d'exploitation pour remplacer cette détection automatique :

$unix_sys = AppConfig::Sys->new("Unix");

Alternativement, la variable de paquet $AppConfig::Sys::OS peut être définie sur un nom de système d'exploitation. Les noms de systèmes d'exploitation valides sont : Win32, VMS, Mac, OS2 et Unix. Ils ne sont pas sensibles à la casse.

MÉTHODES AppConfig::Sys

AppConfig::Sys définit les méthodes suivantes :

getpwnam()
Appelle la fonction système getpwnam() si elle est disponible et retourne le résultat. Retourne undef si elle n'est pas disponible. La méthode can_getpwnam() peut être appelée pour déterminer si cette fonction est disponible.
getpwuid()
Appelle la fonction système getpwuid() si elle est disponible et retourne le résultat. Retourne undef si elle n'est pas disponible. La méthode can_getpwuid() peut être appelée pour déterminer si cette fonction est disponible.
