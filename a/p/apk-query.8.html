apk-query(8) Manuel du gestionnaire système apk-query(8)

NOM

apk query - interroger des informations sur les paquets selon divers critères

SYNTAXE

apk query [<options>...] requête...

apk query [<options>...] --recursive contraintes...

DESCRIPTION

apk query recherche les paquets correspondants parmi les sources sélectionnées.

En mode par défaut, les spécificateurs de requête sont interprétés comme suit :

nom{[<>~=]version}
Sélectionne les paquets par nom et une version correspondante optionnelle.
texte
Sélectionne les paquets dont les champs sélectionnés correspondent au texte.

En mode --recursive, les contraintes spécifient une liste de dépendances à satisfaire et l'algorithme du solveur est utilisé pour déterminer une liste de paquets qui remplissent ces contraintes.

La requête s'exécute selon les étapes suivantes :

1.
Chaque chaîne de requête est exécutée indépendamment pour sélectionner les paquets candidats
2.
Si --all-matches n'est pas spécifié, le meilleur candidat pour l'élément donné est ajouté à la liste des paquets résultants
3.
La liste de paquets résultante est triée

OPTIONS DE REQUÊTE

Les applets prenant en charge les spécificateurs de requête reconnaissent les options suivantes :

--all-matches

Sélectionne tous les paquets correspondants. Par défaut, seul le meilleur match pour chaque élément de requête est sélectionné.

--available

Filtre la sélection aux paquets disponibles.

--fields CHAMPS[:CHAMP_INVERSE]

Une liste de champs séparés par des virgules à inclure dans la sortie. Une spécification optionnelle pour définir le champ à afficher pour les champs synthétiques de dépendances inverses peut être spécifiée (name, package ou origin).

--format FORMATSPEC

Spécifie le format de sortie parmi default, yaml ou json. Le format default est une sortie texte lisible par l'homme.

--from FROMSPEC

Recherche les paquets à partir de : system (toutes les sources système), repositories (exclut la base de données installée), installed (exclut les dépôts normaux) ou none (uniquement les dépôts en ligne de commande).

--installed

Filtre la sélection aux paquets installés.

--match CHAMPS

Une liste de champs séparés par des virgules sur lesquels faire correspondre la requête.

--recursive

Exécute l'algorithme du solveur avec les contraintes données pour sélectionner les paquets.

--summarize CHAMP[:CHAMP_INVERSE]

Produit un résumé du champ spécifié à partir de toutes les correspondances. Le résumé est disponible sur les champs suivants : package, name, origin, depends, provides, replaces, install_if, recommends, reverse-depends, et reverse-install-if.

--upgradable

Filtre la sélection aux paquets susceptibles d'être mis à jour.

--world

Inclut les dépendances de apk-world(5) dans les contraintes. Implique --recursive.

--orphaned

Filtre la sélection aux paquets orphelins.

CHAMPS

Les noms de champs sont tous en minuscules pour les options --match et --fields ainsi que pour la sortie interprétable par machine (json et yaml). Pour le format lisible par l'homme par défaut, les champs sont en majuscules.

Les métadonnées de paquets suivantes sont disponibles : name, version, description, arch, license, origin, maintainer, url, commit, build-time, installed-size, file-size, provider-priority, depends, provides, replaces, install-if, layer, tags, triggers, scripts, et replaces-priority. Voir les sections métadonnées d'informations du paquet et métadonnées du paquet de apk-package(8) pour la description de ces champs.

De plus, les champs suivants sont disponibles :

contents

Noms de fichiers contenus dans un paquet.

download-url

URL complète pour télécharger le paquet.

owner

Recherche le paquet propriétaire pour un nom de chemin donné. (Uniquement --match)

package

L'identifiant du paquet au format nom-version (par exemple, package-1.0-r0).

repositories

Liste des dépôts à partir desquels le paquet est disponible.

status

Statut d'un paquet installé. Liste d'un ou plusieurs des mots-clés suivants :
  • installed
  • broken-files
  • broken-scripts
  • broken-xattr

EXEMPLES

# recherche tous les paquets commençant par apk
apk query "apk*"

# affiche le paquet propriétaire de l'exécutable sensors en json
apk query --format json --match owner /usr/bin/sensors

# affiche apk-tools et ses dépendances en yaml
apk query --format yaml --recursive apk-tools

# imprime les paquets sources pour tous les paquets fournissant cmd:apk
apk query --match name,provides cmd:apk --fields origin

# imprime les paquets sources avec un nom de dépendance spécifique
apk query --match dependency so:libapk.so.2.14.9 --fields origin
