NOM

apt-extracttemplates - Utilitaire pour extraire les fichiers de configuration et les modèles debconf des paquets Debian

SYNOPSIS

apt-extracttemplates [-t=répertoire_temporaire] nom_fichier... {-v | --version} {-h | --help}

DESCRIPTION

apt-extracttemplates prend en entrée un ou plusieurs fichiers de paquets Debian et écrit (dans un répertoire temporaire) tous les scripts de configuration et fichiers de modèles associés. Pour chaque paquet passé en entrée qui contient des scripts de configuration et des modèles, une ligne de sortie sera générée au format :

paquet version fichier_modèle script_configuration

Le fichier de modèle et le script de configuration sont écrits dans le répertoire temporaire spécifié par le répertoire -t ou --tempdir (APT::ExtractTemplates::TempDir), avec des noms de fichiers de la forme paquet.template.XXXXXX et paquet.config.XXXXXX

OPTIONS

Toutes les options de ligne de commande peuvent être définies à l'aide du fichier de configuration ; les descriptions indiquent l'option de configuration à définir. Pour les options booléennes, vous pouvez outrepasser le fichier de configuration en utilisant quelque chose comme -f-,--no-f, -f=no ou plusieurs autres variations.

-t, --tempdir

Répertoire temporaire dans lequel écrire les fichiers de modèles debconf extraits et les scripts de configuration. Élément de configuration : APT::ExtractTemplates::TempDir

-h, --help

Affiche un court résumé d'utilisation.

-v, --version

Affiche la version du programme.

--audit

Affiche les messages d'audit (et de notification). Cela outrepasse l'option silencieux, mais uniquement pour les messages de notification, pas pour ceux de progression.

-c, --config-file

Fichier de configuration ; Spécifie un fichier de configuration à utiliser. Le programme lira le fichier de configuration par défaut puis ce fichier de configuration. Si des paramètres de configuration doivent être définis avant que les fichiers de configuration par défaut ne soient analysés, spécifiez un fichier avec la variable d'environnement APT_CONFIG . Voir apt.conf(5) pour des informations sur la syntaxe.

-o, --option

Définit une option de configuration ; Cela définira une option de configuration arbitraire. La syntaxe est -o Foo::Bar=bar. -o et --option peuvent être utilisés plusieurs fois pour définir différentes options.

--cli-version

Demande une version CLI spécifique. C'est un motif qui prend une version MAJEURE.MINEURE. Vous pouvez omettre la version mineure, auquel cas le niveau mineur le plus récent pris en charge sera utilisé.

Les pistes de version sont présentées comme suit : La version 3.2 a des versions équivalentes 0.32, 1.22 et 2.12, implémentant de nouvelles fonctionnalités pour leurs versions majeures spécifiées.

Un cas particulier est le motif de version X.9 : Une version comme 2.9 est suivie de 3.0, mais 2.10 suit directement 2.8 ; étant donné que nous utilisons les numéros de version impairs comme séries de développement (2.9 est la série de développement 3.0).

Cette fonctionnalité a été introduite dans APT 3.1.10 et remplace la configuration spécifique au binaire. Vous pouvez utiliser APT::Version pour un effet similaire sur les anciens binaires, par exemple, utilisez -o APT::Version=2 pour faire apt(8) se comporter comme la série 2.x.

La valeur par défaut est la version APT actuelle pour apt(8) et 0.(10 * majeure + mineure) pour les commandes classiques. La série 0.X est obsolète de manière douce et les autres commandes passeront à la série 2.x à l'avenir.

--no-color, --color

Active ou désactive les couleurs. Les couleurs sont activées par défaut sur les terminaux pris en charge pour apt(8) et peuvent également être désactivées à l'aide des variables d'environnement NO_COLOR ou APT_NO_COLOR , ou davantage configurées par l'option et la portée de configuration APT::Color , voir apt.conf(5) pour des informations à ce sujet.

VOIR AUSSI

apt.conf(5)

DIAGNOSTICS

apt-extracttemplates renvoie zéro en cas de fonctionnement normal, 100 en décimal en cas d'erreur.

BOGUES

Page des bogues d'APT[1]. Si vous souhaitez signaler un bogue dans APT, veuillez consulter /usr/share/doc/debian/bug-reporting.txt ou la commande reportbug(1) .
