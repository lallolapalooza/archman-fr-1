App::ClusterSSH::Base(3pm) Documentation Perl fournie par l'utilisateur App::ClusterSSH::Base(3pm)

SYNOPSIS

use base qw/ App::ClusterSSH::Base /;
# dans la méthode new de l'objet
sub new {
    ( $class, $arg_ref ) = @_;
    my $self = $class->SUPER::new($arg_ref);
    return $self;
}

DESCRIPTION

Objet de base pour fournir des fonctions utilitaires aux objets - ne doit pas être utilisé directement

MÉTHODES

Ces méthodes supplémentaires sont fournies sur l'objet

$obj = App::ClusterSSH::Base->new({ arg => val, });
Crée l'objet. Aux niveaux de débogage supérieurs, les arguments sont affichés.
$obj->id
Retourne l'identifiant unique de l'objet pour une utilisation dans les sous-classes, telles que 
$info_for{ $self->id } = $info
$obj->debug_level();
Retourne le niveau de débogage actuel
$obj->set_debug_level( n )
Définit le niveau de débogage sur 'n' pour tous les objets enfants.
$obj->debug($level, @text)
Affiche @text sur STDOUT si $level est égal ou inférieur à debug_level
$obj->set_lang
Définit la langue de Locale::Maketext. Par défaut 'en'. Attend que le module App::ClusterSSH/L10N/{lang}.pm existe et contienne toutes les traductions pertinentes, sinon utilise l'anglais par défaut.
$obj->loc('texte à traduire [_1]')
Utilisant le module App::ClusterSSH/L10N/{lang}.pm, convertit le texte donné dans la langue appropriée. Voir App::ClusterSSH::L10N pour plus de détails. Essentiellement un wrapper pour maketext dans Locale::Maketext
$obj->stdout_output(@);
Affiche du texte sur STDOUT.
$obj->parent;
Retourne l'objet qui est le parent de celui-ci, s'il a été défini lors de la création de l'objet
%obj->options;
Accès aux options configurées, si elles sont configurées à ce stade
$obj->exit;
Stub pour permettre au programme de se terminer proprement depuis n'importe quel endroit du code
$config = $obj->config;
Retourne l'objet de configuration qui a été configuré. Croak si set_config n'a pas été appelé
$obj->set_config($config);
Définit la configuration à la valeur donnée - croak si elle a déjà été appelée
$sort = $obj->sort
Référence de code utilisée pour trier les listes ; si configuré (et installé) utilise Sort;:Naturally, sinon utilise le tri de perl
%results = $obj->load_file( filename => '/chemin/vers/fichier', type => '(cluster|config}' )
Charge le fichier spécifié et retourne une hash, analysant le fichier en fonction s'il s'agit d'un fichier de configuration (clé = valeur) ou d'un fichier cluster (clé valeur)
