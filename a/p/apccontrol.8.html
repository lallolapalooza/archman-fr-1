DESCRIPTIO

N

Quand apcupsd(8) détecte des anomalies de l'onduleur surveillé, il déclenche un événement qui entraîne généralement un ou plusieurs appels au script shell apccontrol. Chaque événement amène apccontrol à effectuer une action particulière. Par défaut, ces actions se comportent de manière raisonnable pour tous les événements que apcupsd est susceptible de rencontrer. Cependant, vous pouvez modifier le comportement de chaque

action.

Quand apcupsd détecte un événement, il appelle le script apccontrol avec les quatre arguments suivants

:
eve
nt
Il s'agit de l'événement survenu. Voir la liste des événements possibles
ci-dessous.
ups-na
me
Il s'agit du nom de l'onduleur tel que spécifié dans le fichier de configuration /etc/apcupsd/apcupsd.conf — pas le nom figurant dans l'EEPROM d'un onduleur
intelligent.
connect
ed
Cette valeur vaut 1 si apcupsd est connecté à l'onduleur via un port série ou USB. Dans le cas d'une machine esclave où apcupsd n'est pas directement connecté à l'onduleur, cette valeur sera
0.
power
ed
Cette valeur vaut 1 si l'ordinateur sur lequel apcupsd s'exé
cute est alimenté par l' onduleur et 0 sinon. Ceci n'es
t actuellement pas implémenté et vaut toujours 0 par défaut.

Les événements sont envoyés au journal système et, éventuellement, au fichier d'événements temporaire (/etc/apcupsd/apcupsd.events), et ils génèrent également un appel à apccontrol qui, à son tour, appellera tous les scripts que vous avez placés dans le répertoire /etc/apcupsd

.

PERSONNALISATION DES ACTIONS ÉVÉNEMENTIELLES

Ne modifiez pas apccontrol directement car il serait écrasé lors de la prochaine mise à niveau vers une nouvelle version d'apcupsd.

La méthode recommandée pour personnaliser une action événementielle est simplement de créer un programme exécutable ou un fichier script portant le même nom que l'événement et de placer ce fichier dans le répertoire /etc/apcupsd. Maintenant, lorsque l'événement sélectionné se produit, apccontrol exécutera votre programme ou script.

Si vous souhaitez que apccontrol exécute également son action par défaut pour l'événement sélectionné, votre programme ou script doit se terminer avec un statut de sortie de 0 (zéro).

Si vous ne souhaitez pas que apccontrol exécute également son action par défaut pour l'événement sélectionné, votre programme ou script doit se terminer avec un statut de sortie de 99. Soyez conscient que si vous remplacez complètement l'action par défaut, vous devez vous assurer de l'arrêt correct de votre ordinateur si cela est nécessaire.

Quelques scripts d'exemple (changeme, commfailure, commok, offbattery et onbattery) qui envoient des courriels à root au lieu de diffuser des messages à tous les utilisateurs connectés peuvent être trouvés dans /etc/apcupsd après une installation et également dans le répertoire platforms/etc du code source d'apcupsd.
