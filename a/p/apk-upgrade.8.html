NOM

apk upgrade - mettre à niveau les paquets installés

SYNTAXE

apk upgrade [<options>...] [<paquets>...]

DESCRIPTION

apk upgrade met à niveau les paquets installés vers la dernière version disponible dans les dépôts de paquets configurés (voir apk-repositories(5)). Lorsqu'aucun paquet n'est spécifié, tous les paquets sont mis à niveau si possible. Si une liste de paquets est fournie, seuls ces paquets seront mis à niveau, ainsi que leurs dépendances nécessaires.

Si les dépendances mentionnées dans --preupgrade-depends (voir apk(8)) correspondent à un paquet pouvant être mis à niveau, une étape de pré-mise à niveau est effectuée. Pendant l'étape de pré-mise à niveau, les paquets installés correspondant aux dépendances de pré-mise à niveau sont mis à niveau si possible - leurs dépendances sont appliquées (mais pas mises à niveau à moins qu'elles ne soient requises par les dépendances du nouveau paquet).

Une dépendance de pré-mise à niveau implicite est générée pour le paquet qui possède l'exécutable apk.

OPTIONS

apk upgrade prend en charge les options de commit décrites dans apk(8), ainsi que les options suivantes :

--available, -a

Réinitialise tous les paquets aux versions disponibles dans les dépôts actuels. Cela réinitialise toutes les dépendances versionnées dans le world (voir apk-world(5)). De plus, les paquets sont sélectionnés parmi les dépôts actifs si possible, même si cela implique de remplacer ou de rétrograder le paquet.

Ceci est utile pour réinitialiser le système par rapport à un nouvel ensemble de paquets après la mise à jour des dépôts.

--ignore

Met à niveau tous les paquets à l'exception de ceux listés. Ceci inverse la liste des noms de paquets donnés pour désigner les paquets qui ne doivent pas être mis à niveau.

--latest, -l

Choisit toujours le paquet le plus récent par version. Cependant, les versions considérées sont basées sur le "pinning" des paquets. Principalement, cela remplace l'heuristique par défaut et provoquera l'affichage d'une erreur si toutes les dépendances ne peuvent pas être satisfaites.

--preupgrade[=BOOL]

Si désactivé, désactive l'étape de pré-mise à niveau.

--preupgrade-only

Exécute uniquement la pré-mise à niveau.

--prune

Nettoie le world en supprimant les paquets qui ne sont plus disponibles dans aucun dépôt configuré.
