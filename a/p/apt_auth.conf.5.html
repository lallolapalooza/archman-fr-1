NOM

apt_auth.conf - Fichier de configuration d'authentification pour les sources APT et les proxys

DESCRIPTION

Les fichiers de configuration APT comme sources.list(5) ou apt.conf(5) doivent être accessibles à tous ceux qui utilisent les outils apt sur le système pour avoir accès à toutes les informations liées aux paquets, comme les paquets disponibles dans un dépôt. Les informations de connexion nécessaires pour se connecter à un proxy ou pour télécharger des données depuis un dépôt, d'un autre côté, ne devraient pas toujours être accessibles à tous et ne peuvent donc pas être placées dans un fichier avec des permissions de fichier lisibles par tous.

Le fichier auth.conf d'APT, /etc/apt/auth.conf, et les fichiers .conf dans /etc/apt/auth.conf.d peuvent être utilisés pour stocker les informations de connexion dans un format similaire à netrc avec des permissions de fichier restrictives.

FORMAT SIMILAIRE À NETRC

Le format défini ici est similaire au format du fichier ~/.netrc utilisé par ftp(1) et les programmes similaires interagissant avec les serveurs. C'est un format simple basé sur des jetons (tokens) où les jetons suivants sont reconnus ; les jetons inconnus seront ignorés. Les jetons peuvent être séparés par des espaces, des tabulations ou des sauts de ligne.

machine [protocole://]hôte[:port][/chemin]

Les entrées sont recherchées en trouvant le jeton machine qui correspond au nom d'hôte de l'URI pour lequel apt a besoin d'informations de connexion. Étendant le format netrc, un numéro de port peut être spécifié. Si aucun port n'est donné, le jeton correspond pour tous les ports. De même, le chemin est facultatif et seulement nécessaire et utile si plusieurs dépôts avec des informations de connexion différentes résident sur le même serveur. Un jeton machine avec un chemin correspond si le chemin dans l'URI commence par le chemin donné dans le jeton. Une fois qu'une correspondance est faite, les jetons suivants sont traités, s'arrêtant à la fin du fichier ou lors de la rencontre d'un autre jeton machine.

Si le protocole n'est pas spécifié, l'entrée ne correspond qu'à https et tor+https.

login nom

Le nom d'utilisateur à utiliser.

password chaîne

Le mot de passe à utiliser.

EXEMPLE

Fournir les informations de connexion pour un utilisateur nommé apt avec le mot de passe debian pour l'entrée sources.list(5)

deb https://example.org/debian trixie main

pourrait être fait directement dans l'entrée :

deb https://apt:debian@example.org/debian trixie main

Alternativement, une entrée comme celle qui suit dans le fichier auth.conf pourrait être utilisée :

machine example.org
login apt
password debian

Ou alternativement sur une seule ligne :

machine example.org login apt password debian

Si vous avez besoin d'être plus spécifique, toutes ces lignes s'appliqueront également à l'entrée exemple :

machine example.org/deb login apt password debian
machine example.org/debian login apt password debian
machine example.org/debian/ login apt password debian

En revanche, aucune des lignes suivantes ne s'applique :

machine example.org:443 login apt password debian
machine example.org/deb/ login apt password debian
machine example.org/ubuntu login apt password debian
machine example.orga login apt password debian
machine example.net login apt password debian

NOTES

Le support de base pour cette fonctionnalité est présent depuis la version 0.7.25, mais était non documenté pendant des années. La documentation a été ajoutée dans la version 1.5, modifiant également légèrement l'implémentation. Pour une compatibilité ascendante maximale, vous devriez éviter les jetons machine multiples avec le même nom d'hôte, mais si vous en avez besoin, ils devraient tous avoir un chemin spécifié dans le jeton machine.

Les informations de connexion dans auth.conf sont plus flexibles que celles de sources.list. Par exemple, les informations de connexion peuvent être spécifiées uniquement pour certaines parties d'un dépôt, ou si l'entrée sources.list redirige ailleurs, les informations de connexion pour la destination de redirection peuvent être fournies.
