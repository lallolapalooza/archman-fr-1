APPRES(1) Manuel des commandes générales APPRES(1)

NOM

appres - lister la base de données des ressources des applications X

SYNTAXE

appres [classe [instance]] [-1] [-V] [options_toolkit]

DESCRIPTION

Le programme appres affiche les ressources vues par une application (ou une sous-hiérarchie d'une application) avec les noms de classe et d'instance spécifiés. Il peut être utilisé pour déterminer quelles ressources un programme particulier chargera. Par exemple,


% appres  XTerm

affichera les ressources que tout programme xterm chargera. Si aucune classe d'application n'est spécifiée, la classe -AppResTest- est utilisée.

Pour faire correspondre un nom d'instance particulier, spécifiez un nom d'instance explicitement après le nom de classe, ou utilisez l'option normale du toolkit Xt. Par exemple,


% appres  XTerm  monxterm
ou 
% appres  XTerm  -name  monxterm

Pour lister les ressources correspondant à une sous-hiérarchie d'une application, spécifiez des noms de classe et d'instance hiérarchiques. Le nombre de composants de classe et d'instance doit être égal, et le nom d'instance ne doit pas être spécifié avec une option de toolkit. Par exemple,


% appres  Xman.TopLevelShell.Form  xman.topBox.form

affichera les ressources des widgets de la hiérarchie topBox de xman. Pour lister uniquement les ressources correspondant à un niveau spécifique dans la hiérarchie, utilisez l'option -1. Par exemple,


% appres  XTerm.VT100  xterm.vt100  -1

affichera les ressources correspondant au widget vt100 de xterm.

L'option -V affiche la version de la commande appres et quitte.

VOIR AUSSI

X(7), xrdb(1), listres(1)
