App::ClusterSSH::L10N(3pm) Documentation Perl contribuée par l'utilisateur App::ClusterSSH::L10N(3pm)

SYNOPSIS

use ClusterSSH::L10N;
my $lang = ClusterSSH::L10N->get_handle('en');
$lang->maketext('text to localise with args [_1]', $arg1);

DESCRIPTION

Module de traduction basé sur Locale::Maketext pour ClusterSSH. Voir Locale::Maketext pour plus d'informations et d'utilisation.

NOTE : la langue par défaut de ce module est l'anglais.

METHODS

Voir Locale::Maketext - il n'y a actuellement pas de méthodes supplémentaires dans ce module.
