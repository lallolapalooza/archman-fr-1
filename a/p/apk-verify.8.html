NOM

apk verify - vérifier l'intégrité et la signature des paquets

SYNTAXE

apk verify [<options>...] fichiers...

DESCRIPTION

apk verify vérifie l'intégrité des fichiers de paquets spécifiés, en validant les sommes de contrôle et la signature cryptographique.

apk verify affiche un résumé des résultats sur stdout, et se termine avec le code de sortie zéro si tous les paquets ont été vérifiés avec succès. Si un échec se produit, apk verify se termine avec un code de sortie non nul.

OPTIONS

apk verify ne prend en charge aucune option spécifique. Voir apk(8) pour les options globales.
