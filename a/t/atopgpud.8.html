NOM

atopgpud - démon de statistiques GPU

SYNTAXE

atopgpud [-v]

DESCRIPTION

Le démon atopgpud recueille des informations statistiques de toutes les GPU Nvidia dans le système actuel. Avec une fréquence d'échantillonnage d'une seconde, il maintient les statistiques de chaque GPU, globalement (niveau système) et par processus. Lorsque atopgpud est actif sur le système cible, atop se connecte à ce démon via un socket TCP et obtient toutes les statistiques GPU à chaque intervalle.

L'approche consistant à recueillir toutes les statistiques GPU dans un démon séparé est nécessaire, car le pilote Nvidia n'offre que le pourcentage d'utilisation de la GPU de la dernière seconde. Supposons qu'atop s'exécute avec un intervalle de 10 minutes et qu'il récupère directement le pourcentage d'utilisation de la GPU à partir du pilote Nvidia, il refléterait le pourcentage d'utilisation de la dernière seconde au lieu du pourcentage d'utilisation moyen pendant 600 secondes. Par conséquent, le démon atopgpud récupère le pourcentage d'utilisation de la GPU chaque seconde et l'accumule dans un compteur qui peut être récupéré régulièrement par atop. La même approche s'applique aux autres statistiques GPU.

Lorsque le démon atopgpud s'exécute avec des privilèges root, davantage de compteurs au niveau du processus (c'est-à-dire l'utilisation de la GPU et l'utilisation de la mémoire GPU par processus) sont fournis et ne sont autrement pas applicables.

Notez que certaines statistiques GPU ne sont fournies que pour des types de GPU spécifiques. Pour les GPU plus anciennes ou moins sophistiquées, la valeur -1 est retournée pour les compteurs qui ne sont pas maintenus. Dans la sortie de atop, ces compteurs sont affichés comme 'N/A'.

Si aucune GPU (Nvidia) ne peut être trouvée dans le système cible, atopgpud se termine immédiatement avec le code de sortie 0.

Les messages de journalisation sont écrits via le démon rsyslogd avec la facilité 'daemon'. Avec le drapeau -v (verbeux), atopgpud enregistre également des messages de débogage.

INSTALLATION

Le démon atopgpud est écrit en Python, donc un interpréteur Python doit être installé sur le système cible. Il peut s'agir de Python version 2 ou Python version 3 (le code de atopgpud est écrit de manière générique). Veillez à ce que la première ligne du script atopgpud contienne le nom de commande approprié pour activer un interpréteur Python installé sur le système cible !

Le démon atopgpud dépend du module Python pynvml pour l'interface avec le pilote Nvidia. Ce module peut être installé par la commande pip ou pip3 et est généralement empaqueté sous le nom nvidia-ml-py
Enfin, le module pynvml est un wrapper Python autour de la bibliothèque partagée libnvidia-ml qui doit également être installée.

Après l'installation du paquet atop, le démon atopgpud n'est pas démarré automatiquement, ni le service activé par défaut. Si vous souhaitez activer ce service (de manière permanente), entrez les commandes suivantes (en tant que root) :

  systemctl enable atopgpu
  systemctl start atopgpu

DESCRIPTION DE L'INTERFACE

Les processus clients peuvent se connecter au démon atopgpud sur le port TCP 59123. Par la suite, un tel client peut envoyer une requête de deux octets, composée d'un octet de code de requête suivi d'un octet entier représentant le numéro de version de l'API.
Le code de requête dans le premier octet peut être 'T' pour obtenir des informations sur les types de GPU installés dans ce système (généralement demandé une seule fois).
Le code de requête peut être 'S' pour obtenir toutes les valeurs de compteurs statistiques (demandé pour chaque intervalle).

La réponse du démon commence par un entier de 4 octets. Le premier octet est le numéro de version de l'API qui détermine le format de la réponse tandis que les trois octets suivants indiquent la longueur (ordre big-endian) de la chaîne de réponse qui suit.
Dans les chaînes de réponse, le caractère '@' introduit les informations au niveau du système d'une GPU spécifique et le caractère '#' introduit les informations au niveau du processus liées à cette GPU.
Pour plus de détails sur la signification des compteurs dans une chaîne de réponse, veuillez consulter le code source.
