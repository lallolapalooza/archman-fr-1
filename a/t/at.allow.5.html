NOM

at.allow, at.deny - déterminer qui peut soumettre des jobs via at ou batch

DESCRIPTION

Les fichiers /etc/at.allow et /etc/at.deny déterminent quels utilisateurs peuvent soumettre des commandes pour une exécution ultérieure via at(1) ou batch(1).

Le format des fichiers est une liste de noms d'utilisateurs, un par ligne. Les espaces blancs ne sont pas autorisés.

Si le fichier /etc/at.allow existe, seuls les noms d'utilisateurs mentionnés y sont autorisés à utiliser at.

Si /etc/at.allow n'existe pas, /etc/at.deny est vérifié, et chaque nom d'utilisateur non mentionné dans ce fichier est alors autorisé à utiliser at.

Un /etc/at.deny vide signifie que tous les utilisateurs peuvent utiliser at.

Si aucun des deux n'existe, seul le superutilisateur est autorisé à utiliser at.

VOIR AUSSI

at(1), cron(8), crontab(1), atd(8).
