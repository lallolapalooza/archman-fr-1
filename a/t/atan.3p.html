ATAN(3P) Manuel du programmeur POSIX ATAN(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

atan, atanf, atanl — fonction arc tangente

SYNOPIS

#include <math.h>
double atan(double x);
float atanf(float x);
long double atanl(long double x);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions calculent la valeur principale de l'arc tangente de leur argument x.

Une application souhaitant vérifier les situations d'erreur doit initialiser errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno est différent de zéro ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) est différent de zéro, une erreur s'est produite.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent l'arc tangente de x dans l'intervalle [-π/2,π/2] radians.

Si x est NaN, un NaN est retourné.

Si x est ±0, x est retourné.

Si x est ±Inf, ±π/2 est retourné.

Si x est sous-normal, une erreur de plage peut se produire
et x doit être retourné.

Si x n'est pas retourné, atan(), atanf(), et atanl() retournent une valeur indéfinie par l'implémentation, dont la valeur absolue n'est pas supérieure à DBL_MIN, FLT_MIN, et LDBL_MIN, respectivement.

ERREURS

Ces fonctions peuvent échouer si :

Erreur de plage
La valeur de x est sous-normale.

Si l'expression entière (math_errhandling & MATH_ERRNO) est différente de zéro, alors errno est défini à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est différente de zéro, alors l'exception en virgule flottante de sous-dépassement est déclenchée.

Les sections suivantes sont informatives.

EXEMPLES

UTILISATION PAR L'APPLICATION

En cas d'erreur, les expressions (math_errhandling & MATH_ERRNO) et (math_errhandling & MATH_ERREXCEPT) sont indépendantes l'une de l'autre, mais au moins l'une d'entre elles doit être différente de zéro.
