atexit(3) Manuel des fonctions de bibliothèque atexit(3)

NOM

atexit - enregistrer une fonction à appeler lors de la terminaison normale du processus

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
int atexit(typeof(void (void)) *fonction);

DESCRIPTION

La fonction atexit() enregistre la fonction donnée pour qu'elle soit appelée lors de la terminaison normale du processus, soit via exit(3), soit lors du retour de la fonction main() du programme. Les fonctions ainsi enregistrées sont appelées dans l'ordre inverse de leur enregistrement ; aucun argument ne leur est passé.

La même fonction peut être enregistrée plusieurs fois : elle est appelée une fois pour chaque enregistrement.

POSIX.1 exige qu'une implémentation permette d'enregistrer au moins ATEXIT_MAX (32) fonctions de ce type. La limite réelle supportée par une implémentation peut être obtenue à l'aide de sysconf(3).

Lorsqu'un processus enfant est créé via fork(2), il hérite des copies des enregistrements de son parent. Suite à un appel réussi à l'une des fonctions exec(3), tous les enregistrements sont supprimés.

VALEUR DE RETOUR

La fonction atexit() retourne la valeur 0 en cas de succès ; sinon, elle retourne une valeur non nulle.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
atexit () Sécurité des threads MT-Safe

VERSIONS

POSIX.1 indique que le résultat de l'appel à exit(3) plus d'une fois (c'est-à-dire appeler exit(3) dans une fonction enregistrée à l'aide de atexit()) est indéfini. Sur certains systèmes (mais pas sous Linux), cela peut entraîner une récursion infinie ; les programmes portables ne doivent pas invoquer exit(3) à l'intérieur d'une fonction enregistrée à l'aide de atexit().

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C89, C99, SVr4, 4.3BSD.

NOTES

Les fonctions enregistrées à l'aide de atexit() (et on_exit(3)) ne sont pas appelées si un processus se termine anormalement en raison de la réception d'un signal.

Si l'une des fonctions enregistrées appelle _exit(2), alors les fonctions restantes ne sont pas invoquées, et les autres étapes de terminaison du processus effectuées par exit(3) ne sont pas effectuées.

Les fonctions atexit() et on_exit(3) enregistrent des fonctions sur la même liste : lors de la terminaison normale du processus, les fonctions enregistrées sont invoquées dans l'ordre inverse de leur enregistrement par ces deux fonctions.

Selon POSIX.1, le résultat est indéfini si longjmp(3) est utilisé pour terminer l'exécution de l'une des fonctions enregistrées à l'aide de atexit().

Notes Linux

Depuis glibc 2.2.3, atexit() (et on_exit(3)) peut être utilisé dans une bibliothèque partagée pour établir des fonctions qui sont appelées lorsque la bibliothèque partagée est déchargée.

EXEMPLES

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static void
bye(void)
{
    printf("That was all, folks\n");
}
int
main(void)
{
    long a;
    int i;
    a = sysconf(_SC_ATEXIT_MAX);
    printf("ATEXIT_MAX = %ld\n", a);
    i = atexit(bye);
    if (i != 0) {
        fprintf(stderr, "cannot set exit function\n");
        exit(EXIT_FAILURE);
    }
    exit(EXIT_SUCCESS);
}

VOIR AUSSI

_exit(2), dlopen(3), exit(3), on_exit(3)
