ATMARPD(8) Commandes de maintenance ATMARPD(8)

NOM

atmarpd — démon ATMARP

SYNTAXE

atmarpd [-b] [-d] [-D répertoire] [-l fichier_journal] [-m] [-n]
atmarpd -V

DESCRIPTION

atmarpd implémente le protocole ATMARP tel que spécifié dans les RFC1577 et RFC1755. Les requêtes de résolution d'adresse sont envoyées depuis le noyau (en utilisant un protocole comparablement simple) au démon ATMARP, qui effectue ensuite le dialogue avec le réseau.

atmarpd peut fonctionner comme client ATMARP et comme serveur ATMARP. Il prend également en charge l'utilisation simultanée de plusieurs interfaces IP sur ATM.

atmarpd est configuré depuis la ligne de commande à l'aide du programme atmarp. Sauf si le débogage est activé, la table ATMARP est écrite après chaque modification dans le fichier /var/run/atmarpd.table (ou dans un fichier du même nom dans un répertoire différent, si l'option -D est utilisée).

Notez que atmarpd désactive la prise en charge des SVCs si la signalisation n'est pas disponible au démarrage, c'est-à-dire si atmsigd n'est pas en cours d'exécution.

OPTIONS

-b
S'exécute en arrière-plan (c'est-à-dire dans un processus enfant après initialisation).
-d
Active (beaucoup de) sorties de débogage. Par défaut, atmarpd est relativement discret.
-D répertoire_sauvegarde
Change le répertoire où atmarpd écrit sa table (atmarpd.table). Par défaut, /var/run est utilisé.
-l fichier_journal
Écrit les messages de diagnostic dans le fichier spécifié au lieu de la sortie standard. Le nom spécial syslog est utilisé pour envoyer les diagnostics au journal système.
-m
Active la fusion des appels entrants si l'adresse est connue. Une connexion entrante pour laquelle aucune réponse InARP n'a encore été reçue, mais qui provient d'une adresse ATM pour laquelle une entrée ATMARP existe déjà, est automatiquement ajoutée à cette entrée. Cela suppose qu'il existe une correspondance 1:1 entre les adresses IP et les adresses ATMARP. Par défaut, cette hypothèse n'est pas faite, ce qui entraîne fréquemment la création de connexions dupliquées. Notez que la RFC1577 exige qu'un serveur ATMARP envoie une requête InARP sur une connexion entrante. La fusion peut donc enfreindre la RFC1577 dans ce cas.
-n
Affiche les adresses uniquement au format numérique, c'est-à-dire qu'aucune traduction d'adresse en nom n'est tentée.
-V
Affiche le numéro de version de atmarpd sur la sortie standard et quitte.

FICHIERS

/var/run/atmarpd.table
Table ATMARP
/proc/atm/arp
table des VCs IP sur ATM actuellement actifs

BOGUES

atmarpd supprime les entrées ATMARP de la table du noyau lors de leur rafraîchissement.
