NOM

atomicCompSwap - effectue une opération atomique de comparaison-échange sur une variable

DECLARATION

int atomicCompSwap(inout int mem, uint compare, uint data);

uint atomicCompSwap(inout uint mem, uint compare, uint data);

PARAMETRES

mem

La variable à utiliser comme cible de l'opération.

data

Les données à comparer et potentiellement à échanger avec mem.

DESCRIPTION

atomicCompSwap effectue une comparaison atomique de compare avec le contenu de mem. Si le contenu de mem est égal à compare, alors le contenu de data est écrit dans mem, sinon le contenu de mem reste inchangé. La fonction retourne le contenu original de mem indépendamment du résultat de la comparaison. Les contenus de la mémoire mis à jour par l'opération atomique sont garantis de ne pas être modifiés par une autre affectation ou une autre fonction mémoire atomique dans une invocation de shader entre le moment où la valeur originale est lue et le moment où la nouvelle valeur est écrite.

Les fonctions mémoire atomiques ne sont prises en charge que pour un ensemble limité de variables. Un shader échouera à la compilation si la valeur passée à l'argument mem d'une fonction mémoire atomique ne correspond pas à une variable de type buffer ou shared. Il est acceptable de passer un élément d'un tableau ou un composant unique d'un vecteur à l'argument mem d'une fonction mémoire atomique, à condition que le tableau ou le vecteur sous-jacent soit une variable de type buffer ou shared.
