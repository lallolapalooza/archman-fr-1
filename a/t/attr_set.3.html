attr_set(3)

Paquet: attr

Licences: LGPL

ATTR_SET(3) API de compatibilité XFS ATTR_SET(3)

NOM

attr_set, attr_setf - définir la valeur d'un attribut utilisateur d'un objet de système de fichiers

SYNTAXE

#include <attr/attributes.h>

int attr_set (const char *path, const char *attrname, 
              const char *attrvalue, const int valuelength,
              int flags);
int attr_setf (int fd, const char *attrname, 
               const char *attrvalue, const int valuelength,
               int flags);

DESCRIPTION

Les fonctions attr_set et attr_setf fournissent un moyen de créer des attributs et de définir/modifier leurs valeurs.

Path pointe vers un nom de chemin pour un objet de système de fichiers, et fd fait référence au descripteur de fichier associé à un fichier. Si l'attribut attrname n'existe pas, un attribut avec le nom et la valeur donnés sera créé et associé à cet objet de système de fichiers indiqué. Si un attribut portant ce nom existe déjà sur cet objet de système de fichiers, la valeur existante est remplacée par la nouvelle valeur donnée dans cet appel. La nouvelle valeur d'attribut est copiée du tampon attrvalue pour un total de valuelength octets. L'argument flags peut contenir les symboles suivants combinés par un OU binaire :

ATTR_ROOT
Rechercher attrname dans l'espace d'adressage root, pas dans l'espace d'adressage user. (limité à l'utilisation par le super-utilisateur uniquement)
ATTR_DONTFOLLOW
Ne pas suivre les liens symboliques lors de la résolution d'un path lors d'un appel à la fonction attr_set. Le comportement par défaut est de suivre les liens symboliques.
ATTR_CREATE
Retourner une erreur (EEXIST) si un attribut du nom donné existe déjà sur l'objet de système de fichiers indiqué, sinon créer un attribut avec le nom et la valeur donnés. Ce drapeau est utilisé pour implémenter une opération de création pure, sans ce drapeau attr_set créera l'attribut s'il n'existe pas déjà. Une erreur (EINVAL) sera retournée si ATTR_CREATE et ATTR_REPLACE sont définis dans le même appel.
ATTR_REPLACE
Retourner une erreur (ENOATTR) si un attribut du nom donné n'existe pas déjà sur l'objet de système de fichiers indiqué, sinon remplacer la valeur de l'attribut existant par la valeur donnée. Ce drapeau est utilisé pour implémenter une opération de remplacement pure, sans ce drapeau attr_set créera l'attribut s'il n'existe pas déjà. Une erreur (EINVAL) sera retournée si ATTR_CREATE et ATTR_REPLACE sont définis dans le même appel.

attr_set échouera si une ou plusieurs des conditions suivantes sont vraies :

[ENOATTR]
Le nom d'attribut donné n'est pas associé à l'objet de système de fichiers indiqué et le bit de drapeau ATTR_REPLACE était défini.
[E2BIG]
La valeur de l'attribut donné est trop grande, elle dépasse la taille maximale autorisée pour une valeur d'attribut.
[EEXIST]
Le nom d'attribut donné est déjà associé à l'objet de système de fichiers indiqué et le bit de drapeau ATTR_CREATE était défini.
[ENOENT]
Le fichier nommé n'existe pas.
[EPERM]
L'ID utilisateur effectif ne correspond pas au propriétaire du fichier et l'ID utilisateur effectif n'est pas super-utilisateur.
[ENOTDIR]
Un composant du chemin préfixe n'est pas un répertoire.
[EACCES]
La permission de recherche est refusée sur un composant du chemin préfixe.
[EINVAL]
Un bit était défini dans l'argument flag qui n'est pas défini pour cet appel système, ou les bits de drapeau ATTR_CREATE et ATTR_REPLACE étaient tous deux définis.
[EFAULT]
Path, attrname, ou attrvalue pointe en dehors de l'espace d'adressage alloué du processus.
[ELOOP]
Une recherche de nom de chemin a impliqué trop de liens symboliques.
[ENAMETOOLONG]
La longueur de path dépasse {MAXPATHLEN}, ou un composant de nom de chemin est plus long que {MAXNAMELEN}.

attr_setf échouera si :

[ENOATTR]
Le nom d'attribut donné n'est pas associé à l'objet de système de fichiers indiqué et le bit de drapeau ATTR_REPLACE était défini.
[E2BIG]
La valeur de l'attribut donné est trop grande, elle dépasse la taille maximale autorisée pour une valeur d'attribut.
[EEXIST]
Le nom d'attribut donné est déjà associé à l'objet de système de fichiers indiqué et le bit de drapeau ATTR_CREATE était défini.
[EINVAL]
Un bit était défini dans l'argument flag qui n'est pas défini pour cet appel système, ou les bits de drapeau ATTR_CREATE et ATTR_REPLACE étaient tous deux définis, ou fd fait référence à une socket, pas à un fichier.
[EFAULT]
Attrname, ou attrvalue pointe en dehors de l'espace d'adressage alloué du processus.
[EBADF]
Fd ne fait pas référence à un descripteur valide.

DIAGNOSTICS

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné et errno est défini en conséquence.
