ATMLOOP(8) Commandes de maintenance ATMLOOP(8)

NOM

atmloop - obtenir/définir le mode de bouclage des interfaces ATM

SYNTAXE

atmloop -s [-l niveau] [-r niveau] [itf]
atmloop [itf]
atmloop -q [itf]
atmloop -V

DESCRIPTION

atmloop définit ou affiche les paramètres de bouclage actuels d'une interface ATM, et permet d'interroger les modes de bouclage pris en charge par l'interface.

Certaines cartes ATM peuvent être configurées pour renvoyer les données au pilote (bouclage local) ou au réseau (bouclage distant). Le renvoi peut s'effectuer à plusieurs niveaux différents :

aal
PDU AAL
atm
cellules ATM
numérique
bits envoyés ou reçus de l'interface ligne
analogique
le signal analogique

Les niveaux pris en charge par une interface peuvent être interrogés avec l'option -q. S'il est appelé sans options, atmloop affiche les paramètres de bouclage actuels.

OPTIONS

-s
définit le mode de bouclage. Suivi de -l ou -r, les deux options pour définir le bouclage local et distant en même temps (si pris en charge par le pilote), ou aucune d'elles pour désactiver tout bouclage.
-l niveau
active le bouclage local.
-r niveau
active le bouclage distant.
-q niveau
interroge les niveaux de bouclage pris en charge par l'interface.
-V
affiche le numéro de version de atmloop sur la sortie standard et quitte.
