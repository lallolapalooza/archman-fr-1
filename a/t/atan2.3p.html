ATAN2(3P) Manuel du programmeur POSIX ATAN2(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

atan2, atan2f, atan2l — fonctions arc tangente

SYNTAXE

#include <math.h>
double atan2(double y, double x);
float atan2f(float y, float x);
long double atan2l(long double y, long double x);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions calculent la valeur principale de l'arc tangente de y/x, en utilisant les signes des deux arguments pour déterminer le quadrant de la valeur de retour.

Une application souhaitant vérifier les situations d'erreur doit initialiser errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno est non nul ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) est non nul, une erreur s'est produite.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent l'arc tangente de y/x dans l'intervalle [-π,π] radians.

Si y est ±0 et x est < 0, ±π sera retourné.

Si y est ±0 et x est > 0, ±0 sera retourné.

Si y est < 0 et x est ±0, -π/2 sera retourné.

Si y est > 0 et x est ±0, π/2 sera retourné.

Si x est 0, une erreur de pôle ne se produira pas.

Si x ou y est NaN, un NaN sera retourné.

Si la valeur correcte provoquait un sous-dépassement, une erreur de plage peut se produire, et atan(), atan2f(), et atan2l() retourneront une valeur définie par l'implémentation dont la magnitude n'est pas supérieure à DBL_MIN, FLT_MIN et LDBL_MIN, respectivement.

Si l'option de virgule flottante IEC 60559 est prise en charge, y/x devrait être retourné.

Si y est ±0 et x est -0, ±π sera retourné.

Si y est ±0 et x est +0, ±0 sera retourné.

Pour les valeurs finies de ±y > 0, si x est -Inf, ±π sera retourné.

Pour les valeurs finies de ±y > 0, si x est +Inf, ±0 sera retourné.

Pour les valeurs finies de x, si y est ±Inf, ±π/2 sera retourné.

Si y est ±Inf et x est -Inf, ±3π/4 sera retourné.

Si y est ±Inf et x est +Inf, ±π/4 sera retourné.

Si les deux arguments sont 0, une erreur de domaine ne se produira pas.

ERREURS

Ces fonctions peuvent échouer si :

Erreur de plage
Le résultat sous-dépasse.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno sera défini sur [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de virgule flottante de sous-dépassement sera déclenchée.

Les sections suivantes sont informatives.

EXEMPLES

Conversion des coordonnées cartésiennes vers polaires

La fonction ci-dessous utilise atan2() pour convertir un vecteur 2d exprimé en coordonnées cartésiennes (x,y) en coordonnées polaires (rho,theta). Il existe d'autres moyens de calculer l'angle theta, en utilisant asin(), acos(), ou atan(). Cependant, atan2() présente ici deux avantages :

*
Le quadrant de l'angle est déterminé automatiquement.
*
Les cas singuliers (0,y) sont pris en compte.

Enfin, cet exemple utilise hypot() plutôt que sqrt() car elle est meilleure pour les cas spéciaux ; voir hypot() pour plus d'informations.

#include <math.h>
void
cartesian_to_polar(const double x, const double y,
                   double *rho, double *theta
    )
{
    *rho   = hypot (x,y); /* mieux que sqrt(x*x+y*y) */
    *theta = atan2 (y,x);
}

UTILISATION APPLICATIVE

En cas d'erreur, les expressions (math_errhandling & MATH_ERRNO) et (math_errhandling & MATH_ERREXCEPT) sont indépendantes l'une de l'autre, mais au moins l'une d'entre elles doit être non nulle.
