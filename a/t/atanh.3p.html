ATANH(3P) Manuel du programmeur POSIX ATANH(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

atanh, atanhf, atanhl — fonctions de tangente hyperbolique inverse

SYNTAXE

#include <math.h>
double atanh(double x);
float atanhf(float x);
long double atanhl(long double x);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions doivent calculer la tangente hyperbolique inverse de leur argument x.

Une application souhaitant vérifier les situations d'erreur doit définir errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno est non nul ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) est non nul, une erreur s'est produite.

VALEUR DE RETOUR

En cas de succès, ces fonctions doivent retourner la tangente hyperbolique inverse de leur argument.

Si x est ±1, une erreur de pôle doit se produire, et atanh(), atanhf(), et atanhl() doivent retourner la valeur de la macro HUGE_VAL, HUGE_VALF, et HUGE_VALL, respectivement, avec le même signe que la valeur correcte de la fonction.

Pour |x|>1 fini, une erreur de domaine doit se produire, et un NaN (si pris en charge), ou une valeur définie par l'implémentation doit être retournée.

Si x est NaN, un NaN doit être retourné.

Si x est ±0, x doit être retourné.

Si x est ±Inf, une erreur de domaine doit se produire, et un NaN doit être retourné.

Si x est sous-normal, une erreur de plage peut se produire
et x doit être retourné.

Si x n'est pas retourné, atanh(), atanhf(), et atanhl() doivent retourner une valeur définie par l'implémentation dont la magnitude n'est pas supérieure à DBL_MIN, FLT_MIN, et LDBL_MIN, respectivement.

ERREURS

Ces fonctions doivent échouer si :

Erreur de domaine
L'argument x est fini et non compris dans l'intervalle [-1,1], ou est ±Inf.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno doit être défini à [EDOM]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de virgule flottante invalide doit être levée.

Erreur de pôle
L'argument x est ±1.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno doit être défini à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de division par zéro en virgule flottante doit être levée.

Ces fonctions peuvent échouer si :

Erreur de plage
La valeur de x est sous-normale.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno doit être défini à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de sous-dépassement en virgule flottante doit être levée.

UTILISATION PAR L'APPLICATION
