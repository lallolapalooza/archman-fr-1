attr_get(3)

Paquet: attr

Licences: LGPL

ATTR_GET(3) API de compatibilité XFS ATTR_GET(3)

NOM

attr_get, attr_getf - obtenir la valeur d'un attribut utilisateur d'un objet de système de fichiers

SYNTAXE C

#include <attr/attributes.h>

int attr_get (const char *path, const char *attrname, 
              char *attrvalue, int *valuelength, int flags);
int attr_getf (int fd, const char *attrname, 
               char *attrvalue, int *valuelength, int flags);

DESCRIPTION

Les fonctions attr_get et attr_getf permettent de récupérer la valeur d'un attribut.

Path pointe vers un nom de chemin d'un objet de système de fichiers, et fd fait référence au descripteur de fichier associé à un fichier. Si l'attribut attrname existe, la valeur qui lui est associée sera copiée dans le tampon attrvalue. L'argument valuelength est un argument d'entrée/sortie qui, lors de l'appel à attr_get, doit contenir la taille maximale de la valeur de l'attribut que le processus est prêt à accepter. Au retour, valuelength aura été modifié pour indiquer la taille réelle de la valeur de l'attribut retournée. L'argument flags peut contenir les symboles suivants OR-és bit à bit :

ATTR_ROOT
Rechercher attrname dans l'espace d'adressage root, pas dans l'espace d'adressage user. (réservé à l'usage du super-utilisateur uniquement)
ATTR_DONTFOLLOW
Ne pas suivre les liens symboliques lors de la résolution d'un path lors d'un appel à la fonction attr_get. Le comportement par défaut est de suivre les liens symboliques.

attr_get échouera si une ou plusieurs des conditions suivantes sont vraies :

[ENOATTR]
Le nom de l'attribut donné n'est pas associé à l'objet du système de fichiers indiqué.
[E2BIG]
La valeur de l'attribut donné est trop grande pour tenir dans le tampon. L'entier pointé par l'argument valuelength a été modifié pour indiquer le nombre réel d'octets requis pour stocker la valeur de cet attribut.
[ENOENT]
Le fichier nommé n'existe pas.
[EPERM]
L'identifiant utilisateur effectif ne correspond pas au propriétaire du fichier et l'identifiant utilisateur effectif n'est pas le super-utilisateur.
[ENOTDIR]
Un composant du préfixe du chemin n'est pas un répertoire.
[EACCES]
L'autorisation de recherche est refusée sur un composant du préfixe du chemin.
[EINVAL]
Un bit a été défini dans l'argument flag qui n'est pas défini pour cet appel système.
[EFAULT]
Path, attrname, attrvalue, ou valuelength pointe en dehors de l'espace d'adressage alloué au processus.
[ELOOP]
Une recherche de nom de chemin a impliqué trop de liens symboliques.
[ENAMETOOLONG]
La longueur de path dépasse {MAXPATHLEN}, ou un composant de nom de chemin est plus long que {MAXNAMELEN}.

attr_getf échouera si :

[ENOATTR]
Le nom de l'attribut donné n'est pas associé à l'objet du système de fichiers indiqué.
[E2BIG]
La valeur de l'attribut donné est trop grande pour tenir dans le tampon. L'entier pointé par l'argument valuelength a été modifié pour indiquer le nombre réel d'octets requis pour stocker la valeur de cet attribut.
[EINVAL]
Un bit a été défini dans l'argument flag qui n'est pas défini pour cet appel système, ou fd fait référence à un socket, pas à un fichier.
[EFAULT]
Attrname, attrvalue, ou valuelength pointe en dehors de l'espace d'adressage alloué au processus.
[EBADF]
Fd ne fait pas référence à un descripteur valide.

DIAGNOSTICS

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné et errno est défini de manière appropriée.
