Emplacements atomiques, tels que les champs d'enregistrement.

type 'a t = 'a atomic_loc

Ce module expose un type dédié 'a Atomic.Loc.t pour les emplacements atomiques (stockant une valeur de type 'a ) à l'intérieur d'objets qui ne sont pas nécessairement des références atomiques. Il est utilisé en particulier pour les champs d'enregistrement atomiques : si un enregistrement r a un champ atomique f de type foo , alors [%atomic.loc r.f] a le type foo Atomic.Loc.t .

L'API ci-dessous reflète l'API d'accès à Atomic.Loc.t , voir la documentation ci-dessus pour plus d'informations.
