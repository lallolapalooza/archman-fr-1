NOM

atril-previewer - afficher un aperçu avant impression pour un document

SYNTAXE

atril-previewer [fichier]

DESCRIPTION

atril-previewer est un programme MATE pour afficher la boîte de dialogue d'aperçu avant impression pour les fichiers pris en charge par atril.

OPTIONS

atril-previewer respecte toutes les options normales de la ligne de commande GTK+.

VOIR AUSSI

atril(1), gtk-options(7).
