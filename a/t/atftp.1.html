ATFTP(1) Manuel des commandes générales ATFTP(1)

NOM

atftp - Client TFTP (RFC1350).

SYNTAXE

atftp [options] [hôte [port]]

DESCRIPTION

atftp peut être utilisé de manière interactive ou en mode batch pour récupérer des fichiers depuis des serveurs TFTP. Lorsqu'il est utilisé de manière interactive, un résumé des commandes peut être affiché en tapant 'help'. Ce client TFTP supporte toutes les fonctionnalités de base des RFC1350, RFC2347, RFC2348 et RFC2349. Il supporte également l'implémentation multicast de la RFC2090 et mtftp tels que définis dans la spécification PXE.

OPTIONS

Ce programme supporte à la fois la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets ('--') ainsi que des options courtes. Certaines options sont utilisables uniquement en mode batch, elles n'ont aucune signification lorsque atftp est utilisé de manière interactive. Une description des options est présentée ci-dessous.

-g, --get
Invocation non interactive uniquement. Demande à atftp de récupérer un fichier depuis un serveur tftp.
--mget
Invocation non interactive uniquement. Utilisé pour récupérer un fichier depuis un serveur capable de mtftp.
-p, --put
Invocation non interactive uniquement. Demande à atftp d'envoyer un fichier vers un serveur tftp.
-P, --password
Fournit un mot de passe au serveur tftp. C'est une extension non standard du client atftp nécessaire pour les routeurs Linksys et ne devrait pas être utilisée ailleurs.
-l, --local-file
Invocation non interactive uniquement. Le nom du fichier côté client (local) à lire ou écrire. Doit être utilisé conjointement avec --get ou --put.
-r, --remote-file
Invocation non interactive uniquement. Le nom du fichier côté serveur (distant) à récupérer ou envoyer. Doit être utilisé conjointement avec --get ou --put.
--tftp-timeout <valeur>
Nombre de secondes pour le timeout du client. La valeur par défaut est 5 secondes.
--option <"nom valeur">
Définit l'option « nom » à « valeur ». Cette commande supporte exactement les mêmes arguments que celle en mode interactif. Par exemple, utiliser : --option "blksize 1428" pour configurer la taille des blocs.
Les réglages possibles sont :
--option "blksize disable"
--option "blksize 8"
--option "blksize 65464"
--option "timeout 1"
--option "tsize enable"
--option "tsize disable"
--option "windowsize disable"
--option "windowsize 4"
--option "multicast"
--mtftp <"nom valeur">
Définit les options possibles pour mtftp. Accepte les mêmes options que la commande mtftp en mode interactif. Par exemple, utiliser : --mtftp "client-port 76" pour configurer le port côté client à utiliser.
--no-source-port-checking
Voir la page de manuel de atftpd.
--prevent-sas
Traite la situation du Syndrome du jeune apprenti sorcier comme demandé par la RFC 1350. Cette RFC exige que les réponses répétées à un seul paquet soient rejetées. Ainsi, un bloc ne sera retransmis qu'en cas de timeout. Pour des raisons de compatibilité ascendante, le comportement par défaut reste d'ignorer cette RFC. Les blocs sont donc transmis à chaque requête.
--verbose
Demande à atftp d'être verbeux. Il affichera plus d'informations sur ce qui se passe.
--trace
Ceci est utile à des fins de débogage pour afficher tous les paquets allant vers et venant du réseau.
-V, --version
Affiche la version.
-h, --help
Affiche un résumé des arguments de ligne de commande.
