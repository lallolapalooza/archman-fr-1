ATOPRC(5) Manuel des formats de fichiers ATOPRC(5)

NOM

atoprc - fichier de configuration (rcfile) lié à atop/atopsar

DESCRIPTION

Cette page manuel documente le fichier de configuration (rcfile) des commandes atop et atopsar. Ces commandes peuvent être utilisées pour surveiller le système et la charge des processus sur un système Linux.

Le fichier atoprc contient les paramètres par défaut. Ces paramètres sont lus au démarrage, d'abord à partir du fichier de configuration global /etc/atoprc et ensuite à partir du fichier de configuration spécifique à l'utilisateur ~/.atoprc (les paramètres globaux peuvent donc être remplacés par un utilisateur individuel). Les options dans les deux fichiers de configuration sont identiques.

OPTIONS

Le fichier de configuration contient des paires clé-valeur, une par ligne (les lignes vides et les lignes commençant par un signe # sont ignorées).
Les mots-clés suivants peuvent être spécifiés :

flags
Une liste de drapeaux par défaut pour atop peut être définie ici. Les drapeaux autorisés sont 't', 'B', 'H', 'G', '2' jusqu'à '9', 'g', 'm', 'd', 'n', 'u', 'p', 's', 'c', 'v', 'C', 'M', 'D', 'N', 'A', 'a', 'y', 'Y', 'f', 'F', 'R', '1', 'e', 'E' et 'x'.
twindir
Le chemin absolu par défaut du répertoire temporaire dans lequel le fichier jumeau doit être alloué.
interval
La valeur d'intervalle par défaut en secondes.
linelen
La longueur d'une ligne d'écran lors de l'envoi de la sortie vers un fichier ou un tube (par défaut 80).
username
Expression régulière ou un UID numérique pour sélectionner les utilisateurs pour lesquels les processus (actifs) seront affichés.
procname
L'expression régulière par défaut pour les noms de processus à afficher.
maxlinecpu
Le nombre maximum de CPU actifs qui seront affichés.
maxlinegpu
Le nombre maximum de GPU actifs qui seront affichés.
maxlinelvm
Le nombre maximum de volumes logiques actifs qui seront affichés.
maxlinemdd
Le nombre maximum de périphériques multiples actifs qui seront affichés.
maxlinedisk
Le nombre maximum de disques actifs qui seront affichés.
maxlinenfsm
Le nombre maximum de montages NFS qui seront affichés sur un client NFS.
maxlineintf
Le nombre maximum d'interfaces réseau actives qui seront affichées.
maxlinecont
Le nombre maximum de conteneurs actifs qui seront affichés.
maxlineifb
Le nombre maximum de ports Infiniband qui seront affichés.
maxlinenuma
Le nombre maximum de métriques de nœud NUMA qui seront affichées. Notez que deux lignes sont affichées pour chaque nœud NUMA.
maxlinellc
Le nombre maximum de lignes avec les métriques LLC qui seront affichées.
cpucritperc
Le pourcentage d'occupation considéré comme critique pour un processeur (voir la section COULEURS dans la page man de la commande atop). Ce pourcentage est utilisé pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs en mode texte. Lorsque cette valeur est zéro, aucune coloration de ligne ni tri automatique n'est effectué pour cette ressource.
dskcritperc
Le pourcentage d'occupation considéré comme critique pour un disque (voir la section COULEURS dans la page man de la commande atop). Ce pourcentage est utilisé pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs en mode texte. Lorsque cette valeur est zéro, aucune coloration de ligne ni tri automatique n'est effectué pour cette ressource.
netcritperc
Le pourcentage d'occupation considéré comme critique pour une interface réseau (voir la section COULEURS dans la page man de la commande atop). Ce pourcentage est utilisé pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs en mode texte. Lorsque cette valeur est zéro, aucune coloration de ligne ni tri automatique n'est effectué pour cette ressource.
memcritperc
Le pourcentage considéré comme critique pour l'utilisation de la mémoire (voir la section COULEURS dans la page man de la commande atop). Ce pourcentage est utilisé pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs en mode texte. Lorsque cette valeur est zéro, aucune coloration de ligne ni tri automatique n'est effectué pour cette ressource.
swpcritperc
Le pourcentage d'occupation considéré comme critique pour l'espace d'échange (swap) (voir la section COULEURS dans la page man de la commande atop). Ce pourcentage est utilisé pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs en mode texte. Lorsque cette valeur est zéro, aucune coloration de ligne ni tri automatique n'est effectué pour cette ressource.
swoutcritsec
Le nombre de pages échangées par seconde considéré comme critique pour l'utilisation de la mémoire (voir la section COULEURS dans la page man de la commande atop). Ce seuil est utilisé en combinaison avec 'memcritperc' pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs en mode texte. Lorsque cette valeur est zéro, aucune coloration de ligne ni tri automatique n'est effectué pour cette ressource.
almostcrit
Un pourcentage du pourcentage critique pour déterminer si la ressource est presque critique (voir la section COULEURS dans la page man de la commande atop). Lorsque cette valeur est zéro, aucune coloration pour « presque critique » n'est effectuée.
cpubarwidth
Nombre de colonnes utilisées par barre dans le graphique à barres du processeur. La valeur par défaut est 0, ce qui signifie que la largeur de la barre sera mise à l'échelle automatiquement (plus le terminal est large, plus il y a de colonnes par barre, jusqu'à un maximum de trois). Avec la valeur 1, 2 ou 3, le nombre de barres peut être fixé statiquement à ce nombre de colonnes, avec une colonne d'espace blanc entre les barres.
colorinfo
Définition du nom de couleur pour les messages d'information (par défaut : vert) en mode texte.
Les couleurs autorisées sont : red green yellow blue magenta cyan black white.
colorthread
Définition du nom de couleur pour les lignes spécifiques aux threads lors de l'utilisation de l'option 'y' (par défaut : jaune).
Les couleurs autorisées sont : red green yellow blue magenta cyan black white.
coloralmost
Définition du nom de couleur pour les ressources presque critiques (par défaut : cyan) en mode texte.
Les couleurs autorisées sont : red green yellow blue magenta cyan black white.
colorcritical
Définition du nom de couleur pour les ressources critiques (par défaut : rouge) en mode texte.
Les couleurs autorisées sont : red green yellow blue magenta cyan black white.
atopsarflags
Une liste de drapeaux par défaut pour atopsar peut être définie ici. Les drapeaux autorisés sont 'S', 'x', 'C', 'M', 'H', 'a', 'A' et les drapeaux pour sélectionner un ou plusieurs rapports spécifiques.
perfevents
Définit si le compteur de cycles du CPU doit être récupéré par atop via les compteurs 'perf'. Les valeurs 'auto' (par défaut), 'enable' ou 'disable' peuvent être spécifiées. En cas de 'auto', le compteur de cycles du CPU ne sera pas récupéré sur les machines virtuelles en raison de la surcharge liée à la lecture de ce compteur dans un invité.
pacctdir
Le nom du répertoire supérieur utilisé par la commande

NOM

atoprc - fichier de configuration pour atop

DESCRIPTION

Le fichier de configuration atoprc (qui peut être le fichier global /etc/atoprc ou le fichier spécifique à l'utilisateur ~/.atoprc) permet de spécifier des paramètres d'exécution pour l'outil de surveillance du système atop.

Ce fichier contient des mots-clés suivis de leurs valeurs, un mot-clé par ligne.

OPTIONS

dir
Ce mot-clé spécifie le répertoire où le démon atopacctd écrira les fichiers de comptabilité des processus. Par défaut, ce répertoire est /var/run. Cette option n'a besoin d'être spécifiée que si le démon atopacctd est lancé avec un répertoire différent comme argument en ligne de commande.
Cette option ne peut être spécifiée que dans le fichier /etc/atoprc (au niveau du système) !

Un exemple de fichier /etc/atoprc ou ~/.atoprc:

 

flags         Aaf
interval      5
username
procname
maxlinecpu    4
maxlinedisk   10
maxlineintf   5
cpucritperc   80
almostcrit    90
atopsarflags  CMH
ownprocline   PID:50 VGROW:40 RGROW:45 COMMAND-LINE:50
ownpagline    PAGSCAN:3 BLANKBOX:0 PAGSWIN:3 PAGSWOUT:7

Les mots-clés 'ownprocline' et 'ownpagline' sont expliqués dans la section suivante.

DÉFINITION PERSONNALISÉE DES LIGNES DE SORTIE

Via le fichier rc, il est possible de définir soi-même la mise en page des lignes de sortie. C'est-à-dire que vous pouvez définir la mise en page d'une ligne d'informations sur les processus avec le mot-clé 'ownprocline' (à sélectionner avec la touche 'o' ou le drapeau -o) et vous pouvez redéfinir toutes les lignes d'informations système.

La mise en page d'une ligne de sortie peut être définie comme suit (notez que cela doit être spécifié sur une seule ligne dans le fichier rc) :

   mot-clé   <idcolonne>:<prio> [<idcolonne>:<prio> ...]

L'idcolonne est le nom symbolique d'une colonne qui doit être affichée à cette position dans la ligne de sortie.
La prio est un entier positif qui détermine quelles colonnes ont la priorité lorsque toutes les colonnes spécifiées ne rentrent pas dans la largeur actuelle de l'écran. Plus la valeur est élevée, plus la priorité est élevée.
Les spécifications des colonnes doivent être séparées par un espace. L'ordre dans lequel les colonnes ont été spécifiées est l'ordre dans lequel elles seront affichées, en tenant compte de leur priorité (les colonnes qui ne rentrent pas seront supprimées dynamiquement).

Un idcolonne spécial pour les lignes système est 'BLANKBOX'. Il indique qu'une colonne vide est requise à cette position. Cet idcolonne spécial est également suivi d'une priorité (généralement faible).

La définition suivante peut être spécifiée pour les informations de processus :

ownprocline
Les idcolonnes sont les noms des colonnes affichées dans la sortie normale des lignes relatives aux processus montrées par atop, telles que 'PID', 'CMD', 'S', .... La seule exception est l'idcolonne spécial 'SORTITEM' qui est utilisé pour afficher une des colonnes CPU%/DSK%/MEM%/NET%, en fonction du critère de tri choisi.
Un exemple de ligne de processus définie par l'utilisateur :
 
ownprocline   PID:20 PPID:10 SYSCPU:15 USRCPU:15 VGROW:14 VSIZE:12 RGROW:14 RSIZE:12 ST:8 EXC:7 S:11 SORTITEM:18 CMD:20

Les définitions suivantes sont utilisées en interne par atop comme lignes système par défaut (vous pouvez redéfinir chacune d'elles dans le fichier rc sur une seule ligne) :

ownsysprcline
Redéfinition de la ligne étiquetée 'PRC' :
 
ownsysprcline   PRCSYS:8 PRCUSER:8 BLANKBOX:0 PRCNPROC:7 PRCNZOMBIE:5 PRCCLONES:4 BLANKBOX:0 PRCNNEXIT:6
ownallcpuline
Redéfinition de la ligne étiquetée 'CPU' pour l'utilisation totale du CPU :
 
ownallcpuline   CPUSYS:8 CPUUSER:7 CPUIRQ:4 BLANKBOX:0 CPUIDLE:5 CPUWAIT:6 BLANKBOX:0 CPUSTEAL:1 CPUGUEST:3
ownonecpuline
Redéfinition de la ligne étiquetée 'CPU' pour l'utilisation d'un seul CPU :
 
ownonecpuline   CPUISYS:8 CPUIUSER:7 CPUIIRQ:4 BLANKBOX:0 CPUIIDLE:5 CPUIWAIT:6 BLANKBOX:0 CPUISTEAL:1 CPUIGUEST:3
owncplline
Redéfinition de la ligne étiquetée 'CPL' :
 
owncplline   CPLAVG1:4 CPLAVG5:3 CPLAVG15:2 BLANKBOX:0 CPLCSW:6 CPLINTR:5 BLANKBOX:0 CPLNUMCPU:1
ownmemline
Redéfinition de la ligne étiquetée 'MEM' :
 
ownmemline   MEMTOT:2 MEMFREE:5 MEMCACHE:3 MEMDIRTY:1 MEMBUFFER:3 MEMSLAB:3 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0
ownswpline
Redéfinition de la ligne étiquetée 'SWP' :
 
ownswpline   SWPTOT:3 SWPFREE:4 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 SWPCOMMITTED:5 SWPCOMMITLIM:6
ownpagline
Redéfinition de la ligne étiquetée 'PAG' :
 
ownpagline   PAGSCAN:3 PAGSTALL:1 BLANKBOX:0 PAGSWIN:4 PAGSWOUT:3
owndskline
Redéfinition des lignes étiquetées 'LVM', 'MDD' et 'DSK' :
 
owndskline   DSKNAME:8 DSKBUSY:7 DSKNREAD:6 DSKNWRITE:6 DSKKBPERRD:4 DSKKBPERWR:4 DSKMBPERSECRD:5 DSKMBPERSECWR:5 DSKAVQUEUE:1 DSKAVIO:5
ownnettrline
Redéfinition de la ligne étiquetée 'NET' pour le transport :
 
ownnettrline   NETTRANSPORT:9 NETTCPI:8 NETTCPO:8 NETUDPI:8 NETUDPO:8 NETTCPACTOPEN:6 NETTCPPASVOPEN:5 NETTCPRETRANS:4 NETTCPINERR:3 NETTCPORESET:20 NETUDPNOPORT:1 NETUDPINERR:3
ownnetnetline
Redéfinition de la ligne étiquetée 'NET' pour le réseau :
 
ownnetnetline   NETNETWORK:5 NETIPI:4 NETIPO:4 NETIPFRW:4 NETIPDELIV:4 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 NETICMPIN:1 NETICMPOUT:1
ownnetifline
Redéfinition de la ligne étiquetée 'NET' pour les interfaces :
 
ownnetifline   NETNAME:8 NETPCKI:7 NETPCKO:7 NETSPEEDIN:6 NETSPEEDOUT:6 NETCOLLIS:3 NETMULTICASTIN:2 NETRCVERR:5 NETSNDERR:5 NETRCVDROP:4 NETSNDDROP:4

Les lignes ci-dessus sont affichées dans l'ordre où elles sont affichées par atop en combinaison avec le drapeau -f (dans une fenêtre très large, vous devriez être capable de voir toutes les colonnes).
