ATRIL(1) Manuel des commandes générales ATRIL(1)

NOM

Atril - Le visionneur de documents MATE

SYNTAXE

atril [OPTIONS...] [FICHIERS...]

DESCRIPTION

Atril est le visionneur de documents officiel de l'environnement de bureau MATE, c'est un visionneur de documents simple et multi-pages. Il peut afficher et imprimer des fichiers PostScript (PS), Encapsulated PostScript (EPS), DJVU, DVI, epub, XPS et Portable Document Format (PDF).

Lorsque le document le permet, il permet également de rechercher du texte, de copier du texte dans le presse-papiers, la navigation hypertextuelle et les signets de table des matières.
Cette page de manuel documente brièvement la commande atril.

OPTIONS

nom_de_fichier(s)...
Spécifie le fichier à ouvrir au démarrage de atril. Si ce n'est pas spécifié, atril démarrera avec une fenêtre vide et vous pourrez ouvrir un fichier depuis le menu ou en utilisant le raccourci CTRL+O. Plusieurs fichiers peuvent être chargés s'ils sont séparés par des espaces. atril prend également en charge la gestion des fichiers distants.
-p, --page-label=PAGE
Ici, vous pouvez spécifier une étiquette de page, cette page sera sélectionnée dans le document si elle existe.
-i, --page-index=NUMÉRO
Ici, vous pouvez spécifier un numéro de page, cette page sera sélectionnée dans le document si elle existe.
-f, --fullscreen
Lance atril en mode plein écran. Vous devez spécifier un document pour lancer en mode plein écran.
-s, --presentation
Lance atril en mode présentation. Vous devez spécifier un document pour lancer en mode présentation.
-v, --preview
Lance atril en mode aperçu. Vous devez spécifier un document pour lancer en mode aperçu.
--display=AFFICHAGE
Affichage X à utiliser.
--version
Affiche les informations de version et quitte.
-?, -h, --help
Imprime les options standard de la ligne de commande.
--help-all
Imprime toutes les options de la ligne de commande.

Ce programme accepte également les options GTK standard.

EXEMPLES

atril --preview ~/Bureau/trucs.ps

Ouvre truucs.ps depuis le bureau de l'utilisateur actuel, en mode aperçu.

atril -i 2 -s ./document.pdf

Ouvre document.pdf depuis le répertoire de travail actuel, à la page 2 en mode présentation.
