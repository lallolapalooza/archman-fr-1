ATMADDR(8) Commandes de maintenance ATMADDR(8)

NOM

atmaddr - Lister et maintenir les adresses ATM locales

SYNTAXE

atmaddr [-n] [itf]
atmaddr -r [itf]
atmaddr -a [itf] atm_addr
atmaddr -d [itf] atm_addr
atmaddr -V

DESCRIPTION

atmaddr est utilisé pour lister les adresses locales configurées pour les interfaces ATM et pour modifier manuellement la liste des adresses. Si le numéro d'interface itf est omis, l'interface 0 est utilisée par défaut. L'adresse ATM atm_addr peut être une adresse SVC ATM valide, par exemple une adresse E.164 ou une adresse NSAP de l'ATM Forum.

Si elle est appelée sans options, atmaddr liste les adresses actuellement configurées sur l'interface spécifiée.

Notez que les adresses ATM locales sont normalement maintenues automatiquement par le démon ILMI.

OPTIONS

-a
ajoute l'adresse spécifiée à la fin de la liste.
-d
supprime l'adresse spécifiée de la liste.
-n
sortie d'adresses numériques uniquement. Aucune tentative de traduction d'adresse en nom n'est effectuée.
-r
réinitialise (efface) la liste d'adresses locales de l'interface spécifiée.
-V
affiche le numéro de version de atmaddr sur la sortie standard et quitte.
