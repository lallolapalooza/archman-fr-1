NOM

atmdiag - afficher les diagnostics du pilote de périphérique ATM

SYNTAXE

atmdiag [-z] [interface...]

DESCRIPTION

atmdiag affiche les compteurs statistiques maintenus par les pilotes de périphérique ATM. Si un ou plusieurs numéros d'interface sont spécifiés, seules les statistiques de ces interfaces sont affichées. Sinon, les statistiques de toutes les interfaces sont affichées.

Les compteurs suivants sont affichés pour chaque AAL :

TX_okay
nombre de PDU envoyés avec succès.
TX_err
nombre de PDU non envoyés en raison d'erreurs.
RX_okay
nombre de PDU reçus avec succès.
RX_err
nombre de PDU ignorés en raison d'erreurs.
RX_drop
nombre de PDU ignorés en raison de manque de mémoire.

OPTIONS

-z
remet à zéro tous les compteurs après les avoir affichés.
