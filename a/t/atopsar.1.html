ATOPSAR(1) Manuel des commandes générales ATOPSAR(1)

NOM

atopsar - Rapport d'activité système avancée (lié à atop)

SYNTAXE

atopsar [-options...] [-r fichier|date|- ] [-R nb ] [-b [AAAAMMJJ]hhmm[ss] ] [-e [AAAAMMJJ]hhmm[ss] ]
atopsar [-options...] intervalle [ échantillons ]

DESCRIPTION

Le programme atopsar peut être utilisé pour rapporter des statistiques au niveau système.

Dans la première ligne de syntaxe (aucun intervalle d'échantillonnage spécifié), atopsar extrait les données d'un fichier journal brut qui a été enregistré précédemment par le programme atop (option -w du programme atop).
Vous pouvez spécifier le nom du fichier journal avec l'option -r du programme atopsar. Lorsqu'un fichier journal quotidien d'atop est utilisé, nommé /var/log/atop/atop_AAAAMMJJ (où AAAAMMJJ reflète la date), la date requise sous la forme AAAAMMJJ peut être spécifiée avec l'option -r au lieu du nom de fichier, ou le nom symbolique 'y' peut être utilisé pour le fichier journal quotidien d'hier (cela peut être répété, donc 'yyyy' indique le fichier journal d'il y a quatre jours), ou le nom de fichier '-' peut être utilisé pour lire les données brutes depuis l'entrée standard. Si l'option -r n'est pas spécifiée du tout, le fichier journal quotidien d'aujourd'hui est utilisé par défaut.
L'heure de début et de fin du rapport peuvent être définies en utilisant les options -b et -e suivies d'un argument temporel de la forme [AAAAMMJJ]hhmm[ss].

Dans la seconde ligne de syntaxe, atopsar lit les compteurs d'activité réels du noyau avec l'intervalle spécifié (en secondes) et le nombre spécifié d'*échantillons* (facultatif). Lorsque atopsar est activé de cette manière, il envoie immédiatement la sortie pour chaque rapport demandé à la sortie standard. Si un seul type de rapport est demandé, l'en-tête est imprimé une fois et après chaque *intervalle* secondes, les compteurs statistiques sont affichés pour cette période. Si plusieurs rapports sont demandés, un en-tête est imprimé par échantillon suivi des compteurs statistiques pour cette période.

Certaines options génériques peuvent être spécifiées pour influencer le comportement du programme atopsar :

-S
Par défaut, l'horodatage au début d'une ligne est supprimé si plusieurs lignes sont affichées pour un intervalle donné. Avec cette option, un horodatage est fourni pour chaque ligne de sortie (plus facile pour le post-traitement).
-a
Par défaut, certaines ressources comme les disques et les interfaces réseau ne sont affichées que lorsqu'elles étaient actives pendant l'intervalle. Avec cette option, toutes les ressources d'un type donné sont affichées, même si elles étaient inactives pendant l'intervalle.
-x
Par défaut, atopsar n'utilise les couleurs que si la sortie est dirigée vers un terminal (fenêtre). Ces couleurs peuvent indiquer qu'un pourcentage d'occupation critique a été atteint (rouge) ou presque atteint (cyan) pour une ressource particulière. Voir la page de manuel d'atop pour une description détaillée de cette fonctionnalité (section COLORS).
Avec l'option -x, l'utilisation des couleurs est supprimée inconditionnellement.
-C
Par défaut, atopsar n'utilise les couleurs que si la sortie est dirigée vers un terminal (fenêtre). Ces couleurs peuvent indiquer qu'un pourcentage d'occupation critique a été atteint (rouge) ou presque atteint (cyan) pour une ressource particulière. Voir la page de manuel d'atop pour une description détaillée de cette fonctionnalité (section COLORS).
Avec l'option -C, les couleurs seront toujours utilisées, même si la sortie n'est pas dirigée vers un terminal.
-M
Utiliser des marqueurs à la fin d'une ligne pour indiquer qu'un pourcentage d'occupation critique a été atteint ('*') ou presque atteint ('+') pour des ressources particulières. Le marqueur '*' est similaire à la couleur rouge et le marqueur '+' à la couleur cyan. Voir la page de manuel d'atop pour une description détaillée de ces couleurs (section COLORS).
-H
Répéter la ligne d'en-tête dans un rapport pour chaque N lignes de détail. La valeur de N est déterminée dynamiquement en cas de sortie vers un tty/fenêtre (en fonction du nombre de lignes) ; pour la sortie vers un fichier ou un pipe, cette valeur est de 23.
-R
Synthétiser nb échantillons en un seul échantillon. Si le fichier journal contient, par exemple, des échantillons de 10 minutes, l'utilisation de l'option '-R 6' montre un rapport avec un échantillon par heure.

Rapport sur les 3 processus consommant le plus de capacité processeur. Ce rapport n'est disponible que lors de l'utilisation d'un fichier journal (pas lors de la spécification d'un intervalle).

Rapport sur les 3 processus émettant le plus de transferts de sockets IPv4/IPv6. Ce rapport n'est disponible que lors de l'utilisation d'un fichier journal (pas lors de la spécification d'un intervalle).
