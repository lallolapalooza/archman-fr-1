ATOMICEXCHANGE(3G) [FIXME: manuel] ATOMICEXCHANGE(3G)

NOM

atomicExchange - effectue une opération d'échange atomique sur une variable

DÉCLARATION

int atomicExchange(inout int mem, int data);

uint atomicExchange(inout uint mem, uint data);

PARAMÈTRES

mem

La variable à utiliser comme cible de l'opération.

data

Les données à échanger avec mem.

DESCRIPTION

atomicExchange effectue un échange atomique de data avec le contenu de mem. Le contenu de data est écrit dans mem et le contenu original de mem est retourné. Le contenu de la mémoire mise à jour par l'opération atomique est garanti de ne pas être modifié par une autre affectation ou fonction mémoire atomique dans une autre invocation de shader entre le moment où la valeur originale est lue et le moment où la nouvelle valeur est écrite.

Les fonctions mémoire atomiques ne sont prises en charge que pour un ensemble limité de variables. Un shader échouera à la compilation si la valeur passée à l'argument mem d'une fonction mémoire atomique ne correspond pas à une variable de tampon (buffer) ou partagée (shared). Il est acceptable de passer un élément d'un tableau ou un composant unique d'un vecteur à l'argument mem d'une fonction mémoire atomique, tant que le tableau ou le vecteur sous-jacent est une variable de tampon ou partagée.
