NOM

atac - Arguably a Terminal API Client. Client API de terminal, riche en fonctionnalités, libre, open-source, hors ligne et sans compte.

SYNTAXE

atac [-d|--directory] [--filter] [--tui] [--dry-run] [--no-ansi-log] [-v|--verbose]... [-q|--quiet]... [-h|--help] [-V|--version] [sous-commandes]

DESCRIPTION

ATAC est Arguably a Terminal API Client. Il est basé sur des clients bien connus tels que Postman, Insomnia, ou même Bruno, mais dans votre terminal sans avoir besoin d'un environnement graphique spécifique. La philosophie d'ATAC est d'être libre, sans compte et hors ligne, maintenant et pour toujours.

OPTIONS

-d, --directory=RÉPERTOIRE
Répertoire principal de l'application, contenant les fichiers de collections JSON/YAML, le fichier de configuration atac.toml et le fichier atac.log.
--filter=FILTRE
N'autorise que les fichiers de collection qui correspondent au filtre regex.
--tui
Exécute le TUI après la commande.
--dry-run
Évite de sauvegarder les données dans les fichiers de collection et d'environnement.
--no-ansi-log
Évite d'utiliser le format ANSI pour le fichier journal/la sortie.
-v, --verbose
Augmente la verbosité des journaux.
-q, --quiet
Diminue la verbosité des journaux.
-h, --help
Affiche l'aide (voir un résumé avec '-h').
-V, --version
Affiche la version.

SOUS-COMMANDES
