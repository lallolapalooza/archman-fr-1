ATMARP(8) Commandes de maintenance ATMARP(8)

NOM

atmarp - administrer les connexions IP classiques sur ATM

SYNTAXE

atmarp -a
atmarp -c [[atm]nombre]
atmarp -q addr_ip [qos qos] [sndbuf octets]
atmarp -s addr_ip [itf.]vpi.vci [qos qos] [sndbuf octets] [temp] [pub] [null]
atmarp -s addr_ip addr_atm [qos qos] [sndbuf octets] [temp] [pub] [arpsrv]
atmarp -d addr_ip [arpsrv]
atmarp -V

DESCRIPTION

atmarp est utilisé pour maintenir la table ATMARP du démon ATMARP. La table peut être listée, de nouvelles entrées PVC et SVC peuvent être ajoutées, et les entrées existantes peuvent être supprimées. De plus, atmarp est également utilisé pour créer de nouvelles interfaces IP sur ATM.

Notez que le noyau possède sa propre table ATMARP contenant uniquement les entrées pour les destinations vers lesquelles une connexion existe. La table de atmarpd peut également contenir des entrées actuellement inutilisées.

OPTIONS

-a
liste la table ATMARP actuelle.
-c
crée l'interface IP spécifiée. Si le numéro d'interface est omis, le système d'exploitation attribue le prochain numéro libre et atmarp affiche le nom de l'interface résultant (par exemple, `atm0') sur la sortie standard.
-q
définit le QOS et la taille du tampon d'envoi à utiliser par défaut pour tous les VCs générés pour ce réseau IP (ip_addr doit être l'adresse du réseau).
-s
configure une PVC ou crée une entrée SVC. Les options suivantes sont reconnues :
qos qos
utilise la qualité de service spécifiée (voir qos(7) pour la syntaxe). UBR à la vitesse de la liaison est utilisé par défaut.
sndbuf octets
essaie de définir le tampon d'envoi au nombre d'octets spécifié. Une valeur par défaut du système est utilisée si sndbuf n'est pas spécifié.
temp
ne marque pas l'entrée comme permanente, c'est-à-dire qu'elle expirera et sera ensuite supprimée.
pub
publie l'entrée (uniquement pertinent pour le serveur ATMARP). Les requêtes ATMARP pour les entrées non marquées pour publication génèrent une réponse ATMARP_NAK.
null
utilise l'encapsulation NULL au lieu de l'encapsulation LLC/SNAP sur la PVC. Cette option n'est pas disponible pour les SVC, car l'en-tête LLC/SNAP est requis pour identifier les paquets ATMARP. null implique également que l'entrée est permanente.
arpsrv
identifie l'entrée pointant vers le serveur ATMARP. Notez que le nœud agissant en tant que serveur ATMARP ne doit avoir aucune entrée de serveur ATMARP dans sa table ATMARP.
-d
supprime l'entrée ARP spécifiée. Afin d'empêcher la suppression accidentelle de l'entrée du serveur ATMARP, le drapeau arpsrv doit être spécifié lors de sa suppression.

-V
affiche le numéro de version de atmarp sur la sortie standard et quitte.

FICHIERS

/var/run/atmarpd.table
table ATMARP
