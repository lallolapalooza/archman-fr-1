attr_remove(3)

Paquet: attr

Licences: LGPL

ATTR_REMOVE(3) API de compatibilité XFS ATTR_REMOVE(3)

NOM

attr_remove, attr_removef - supprimer un attribut utilisateur d'un objet de système de fichiers

SYNTAXE C

#include <attr/attributes.h>

int attr_remove (const char *path, const char *attrname, int flags);
int attr_removef (int fd, const char *attrname, int flags);

DESCRIPTION

Les fonctions attr_remove et attr_removef permettent de supprimer des attributs précédemment créés à partir d'objets de système de fichiers.

Path pointe vers un nom de chemin pour un objet de système de fichiers, et fd fait référence au descripteur de fichier associé à un fichier. Si l'attribut attrname existe, le nom et la valeur de l'attribut seront supprimés de l'objet de système de fichiers. L'argument flags peut contenir les symboles suivants, combinés par un OU bit à bit :

ATTR_ROOT
Rechercher attrname dans l'espace d'adressage root, et non dans l'espace d'adressage user. (réservé à l'usage du super-utilisateur uniquement)
ATTR_DONTFOLLOW
Ne pas suivre les liens symboliques lors de la résolution d'un path lors d'un appel à la fonction attr_remove. Par défaut, les liens symboliques sont suivis.

attr_remove échouera si l'une des conditions suivantes est remplie :

[ENOATTR]
Le nom d'attribut donné n'est pas associé à l'objet de système de fichiers indiqué.
[ENOENT]
Le fichier nommé n'existe pas.
[EPERM]
L'ID utilisateur effectif ne correspond pas au propriétaire du fichier et l'ID utilisateur effectif n'est pas le super-utilisateur.
[ENOTDIR]
Un composant du préfixe du chemin n'est pas un répertoire.
[EACCES]
La permission de recherche est refusée sur un composant du préfixe du chemin.
[EINVAL]
Un bit a été défini dans l'argument flag qui n'est pas défini pour cet appel système.
[EFAULT]
Path pointe en dehors de l'espace d'adressage alloué du processus.
[ELOOP]
Une recherche de nom de chemin a impliqué trop de liens symboliques.
[ENAMETOOLONG]
La longueur de path dépasse {MAXPATHLEN}, ou un composant de nom de chemin est plus long que {MAXNAMELEN}.

attr_removef échouera si :

[ENOATTR]
Le nom d'attribut donné n'est pas associé à l'objet de système de fichiers indiqué.
[EINVAL]
Un bit a été défini dans l'argument flag qui n'est pas défini pour cet appel système, ou fd fait référence à une socket, pas à un fichier.
[EFAULT]
Attrname pointe en dehors de l'espace d'adressage alloué du processus.
[EBADF]
Fd ne fait pas référence à un descripteur valide.

DIAGNOSTICS

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné et errno est défini en conséquence.
