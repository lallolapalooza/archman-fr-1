NOM

atool - Un script pour gérer des archives de fichiers de différents types

SYNOPSIS

atool [OPTION]... ARCHIVE [FICHIER]...
aunpack [OPTION]... ARCHIVE [FICHIER]...
apack [OPTION]... ARCHIVE [FICHIER]...
als [OPTION]... ARCHIVE [FICHIER]...
acat [OPTION]... ARCHIVE [FICHIER]...
adiff [OPTION]... ARCHIVE ARCHIVE
arepack [OPTION]... ANCIENNE-ARCHIVE NOUVELLE-ARCHIVE

DESCRIPTION

Cette page de manuel décrit les commandes atool . Ces commandes sont utilisées pour gérer des archives de fichiers de différents types, telles que les archives tar et Zip. Chaque commande peut être exécutée individuellement ou en donnant les options appropriées à atool (voir OPTIONS ci-dessous).

aunpack extrait les fichiers d'une archive. Souvent, on souhaite extraire tous les fichiers d'une archive dans un seul sous-répertoire. Cependant, certaines archives contiennent plusieurs fichiers dans leurs répertoires racines. Le programme aunpack surmonte ce problème en extrayant d'abord les fichiers dans un répertoire (temporaire) unique, puis en déplaçant son contenu en arrière si possible. Cela empêche également les fichiers locaux d'être écrasés par erreur.

apack crée des archives (ou compresse des fichiers). Si aucun argument de fichier n'est spécifié, les noms de fichiers à ajouter sont lus depuis l'entrée standard.

als liste les fichiers d'une archive.

acat extrait les fichiers d'une archive vers la sortie standard.

adiff génère un diff entre deux archives en utilisant diff(1).

arepack recomprime les archives vers un autre format. Il le fait en extrayant d'abord tous les fichiers de l'ancienne archive dans un répertoire temporaire, puis en empaquetant tous les fichiers extraits de ce répertoire dans la nouvelle archive. Utilisez l'option --each (-e) en combinaison avec --format (-F) pour recomprimer plusieurs archives en une seule invocation d'atool. Notez que arepack ne supprimera pas l'ancienne archive.

Sauf si l'option --format (-F) est fournie, le format de l'archive est déterminé par l'extension du fichier d'archive. C'est-à-dire qu'une extension ".tar.gz" ou ".tgz" signifie le format tar+gzip. Notez que les extensions sont vérifiées dans l'ordre listé dans la section TYPES D'ARCHIVES ci-dessous, c'est pourquoi un fichier avec l'extension ".tar.gz" est considéré comme une archive tar+gzip, et non comme un fichier compressé gzip.

OPTIONS

Ces programmes suivent la syntaxe de ligne de commande GNU habituelle, avec les options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-l, --list
Liste les fichiers dans l'archive. Cette option est automatiquement supposée lorsque als est exécuté.
-x, --extract
Extrait les fichiers de l'archive. Cette option est automatiquement supposée lorsque aunpack est exécuté.
-X, --extract-to=CHEMIN
Extrait les fichiers de l'archive vers le répertoire spécifié. Lors de la décompression de fichiers, CHEMIN peut faire référence soit à un nom de fichier, soit à un répertoire existant.
-a, --add
Crée une archive. Cette option est automatiquement supposée lorsque apack est exécuté.
-c, --cat
Extrait un fichier de l'archive vers la sortie standard (l'affichant à l'écran). Cette option est automatiquement supposée lorsque acat est exécuté.
-d, --diff
Extrait deux archives et utilise diff(1) pour générer les différences entre elles. Cette option est automatiquement supposée lorsque adiff est exécuté.
-e, --each
Pour chaque argument, exécute la commande spécifiée. Cela peut être utilisé pour extraire, lister ou créer rapidement plusieurs archives (voir EXEMPLES ci-dessous). Cette option ne peut pas être utilisée avec la commande cat.
-F, --format=EXTENSION
Spécifie manuellement le format de l'archive (voir TYPES D'ARCHIVES ci-dessous).
-S, --simulate
Exécute atool en mode simulation. Aucun changement sur le système de fichiers (c'est-à-dire d'écriture) ne sera fait, et toutes les commandes qui seraient exécutées seront affichées à la place. Cette option ne peut pas être combinée avec --explain (puisqu'elle l'implique déjà).

Notez qu'il n'est pas garanti que les commandes imprimées en mode simulation seront les mêmes que celles exécutées en mode non-simulation. Cela est dû au fait que certaines opérations dépendent des fichiers contenus dans les archives, et atool ne peut à l'heure actuelle le déterminer qu'en extrayant les archives.

-E, --explain
Affiche les commandes exécutées par atool. Cette option ne peut pas être combinée avec --simulate.
-p, --page
Fait passer la sortie à travers un visualiseur (pager), généralement pager sauf si la variable d'environnement PAGER est définie.
-f, --force
Lors de l'extraction depuis des fichiers, autorise l'écrasement des fichiers locaux. Lors de la création d'une archive, autorise l'écrasement du fichier d'archive s'il existe déjà. Notez qu'il est possible d'ajouter des fichiers aux archives RAR et Zip existantes (ce qui n'est pas possible pour de nombreux autres formats).
-D, --subdir
Lors de l'extraction d'archives, crée toujours un nouveau répertoire pour l'archive même si l'archive ne contient qu'un fichier dans son répertoire racine.
-0, --null
Si aucun argument de fichier n'est spécifié lors de la création ou de l'ajout de fichiers aux archives, la liste des fichiers sera lue depuis l'entrée standard. Normalement, ces noms de fichiers sont séparés par un saut de ligne, mais avec cette option, ils sont séparés par des octets nuls. C'est utile avec l'option GNU find -print0.
-q, --quiet
Diminue le niveau de verbosité d'un. Ceci est soustrait du niveau de verbosité par défaut, ou du niveau spécifié avec --verbosity. Cette option peut être spécifiée plus d'une fois pour rendre atool encore moins verbeux.
-v, --verbose
Augmente le niveau de verbosité d'un. Ceci est ajouté au niveau de verbosité par défaut, ou du niveau spécifié avec --verbosity. Cette option peut être spécifiée plus d'une fois pour rendre atool encore plus verbeux.
-V, --verbosity=NIVEAU
Spécifie le niveau de verbosité. Le niveau par défaut est 1, ce qui signifie "verbosité normale" - par exemple, lors de la création et de l'extraction d'archives, les fichiers seront listés.
--config=FICHIER
Charge la configuration depuis le fichier spécifié. Lors de l'utilisation de cette option, les fichiers de configuration globaux et utilisateur ne seront pas chargés. Si le fichier spécifié n'existe pas ou ne peut pas être lu, atool se terminera avec un message d'erreur.
-o, --option=CLE=VALEUR
Remplace une option de configuration. Celles-ci sont appliquées après la lecture des fichiers de configuration.

Vous pouvez spécifier cette option plusieurs fois pour remplacer différentes options.

-O, --format-option=OPTION
Envoie des options supplémentaires à la commande d'archivage. Cela peut être utile lors de la spécification d'options de compression pour certaines archives, par exemple
apack -F7z -O-mx=9 archive.7z dir
Vous pouvez spécifier cette option plusieurs fois pour ajouter différentes options.
--save-outdir=FICHIER
Lors de l'extraction de fichiers, enregistre le nom du répertoire dans lequel l'archive a été extraite dans le fichier spécifié. Si la commande n'était pas `extract', ou si l'archive n'a pas été extraite dans un nouveau répertoire, alors rien ne sera écrit dans le fichier spécifié. Si plusieurs archives ont été spécifiées (avec -e), alors seul le dernier répertoire dans lequel les fichiers ont été extraits sera écrit dans FICHIER.

Cette option est utilisée en interne (voir EXEMPLES ci-dessous).

--help
Affiche un résumé des options.
--version
Affiche les informations de version et quitte.

Sauf si l'option -f (--format) est fournie, le format de l'archive est déterminé par l'extension du fichier d'archive. C'est-à-dire qu'une extension ".tar.gz" ou ".tgz" signifie le format tar+gzip. Notez que les extensions sont vérifiées dans l'ordre listé ci-dessus, c'est pourquoi un fichier avec l'extension ".tar.gz" est considéré comme une archive tar+gzip, et non comme une archive gzip.

CONFIGURATION

Depuis la version 0.8.0, atool peut lire des fichiers de configuration personnalisés. Tout d'abord, les valeurs par défaut codées en dur dans le fichier du programme atool sont évaluées. Ensuite, les valeurs de configuration globales au système sont chargées depuis /etc/atool.conf si ce fichier existe. Enfin, les valeurs de configuration par utilisateur sont chargées depuis .atoolrc dans le répertoire personnel de l'utilisateur courant.

Le format des fichiers de configuration est simple :

variable valeur

Ici variable est une variable listée ci-dessous, et valeur est la valeur à associer à la variable. variable et valeur doivent être séparés par au moins un espace blanc (espace, tabulation etc). Les lignes vides et les lignes commençant par # sont ignorées.

Une valeur de `1' signifie que l'option est activée, et `0' qu'elle est désactivée. Les chaînes de caractères ne doivent pas être entre guillemets, car elles commencent au premier caractère non blanc et se terminent à la fin de la ligne.

Les options sont :

use_tar_bzip2_option (par défaut : 1)
Activez ceci si vous utilisez GNU tar et qu'il supporte l'option --bzip2 pour filtrer les fichiers compressés avec bzip2 via bzip2. Les versions 1.13.6 ou ultérieures de GNU tar supportent --bzip2. Par conséquent, si vous utilisez GNU tar antérieur à 1.13.6, vous devrez désactiver cette option.

Cela s'appelait use_tar_j_option mais utiliser --bzip2 est plus portable.

use_tar_lzip_option (par défaut : 0)
Activez ceci si vous utilisez GNU tar et qu'il supporte l'option --lzip pour filtrer les fichiers compressés avec lzip via lzip. Les versions 1.23 ou ultérieures de GNU tar supportent --lzip. Par conséquent, si vous utilisez GNU tar antérieur à 1.23, vous devrez désactiver cette option.
use_tar_z_option (par défaut : 1)
Activez ceci si vous utilisez GNU tar et qu'il supporte l'option -z pour filtrer les fichiers compressés avec gzip via gzip. Vous devrez désactiver ceci et use_tar_j_option si vous n'utilisez pas GNU tar.

Désactiver ces deux options ne signifie pas qu'atool ne peut pas extraire les fichiers bzip2/gzip. Si désactivées, atool utilise un tube pour envoyer la sortie de bzip2/gzip à tar à la place.

Si possible, ces options devraient être activées car la gestion des erreurs est meilleure lorsque le filtrage est fait par tar.

use_tar_lzma_option (par défaut : 1)
Activez ceci si vous utilisez GNU tar et qu'il supporte l'option --lzma pour filtrer les fichiers compressés avec lzma via lzma. Les versions 1.20 ou ultérieures de GNU tar supportent --lzma.
use_tar_lzop_option (par défaut : 0)
Activez ceci si vous utilisez GNU tar et qu'il supporte l'option --lzop pour filtrer les fichiers compressés avec lzop via lzop. Les versions 1.21 ou ultérieures de GNU tar supportent --lzop.
use_tar_xz_option (par défaut : 0)
Activez ceci si vous utilisez GNU tar et qu'il supporte l'option --xz pour filtrer les fichiers compressés avec xz via xz. Les versions 1.22 ou ultérieures de GNU tar supportent --xz.
use_gzip_for_z (par défaut : 1)
Activez ceci si vous voulez utiliser gzip au lieu de uncompress pour décompresser les fichiers compressés avec compress (fichiers `.Z').
use_rar_for_unpack (par défaut : 0)
Activez ceci si vous voulez toujours utiliser rar au lieu de unrar lorsque c'est possible. Cela fait utiliser à atool la commande rar (path_rar) même pour lister et extraire les fichiers RAR.
use_arc_for_unpack (par défaut : 0)
Activez ceci si vous voulez toujours utiliser arc au lieu de nomarch lorsque c'est possible. Cela fait utiliser à atool la commande arc (path_arc) même pour lister et extraire les fichiers ARC.
use_arj_for_unpack (par défaut : 0)
Activez ceci si vous voulez toujours utiliser arj au lieu de unarj lorsque c'est possible. Cela fait utiliser à atool la commande arj (path_arj) même pour lister et extraire les fichiers ARJ.
use_find_cpio_print0 (par défaut : 1)
Activez ceci si find supporte l'option -print0 et cpio supporte l'option -0. Sans cela, il est impossible/difficile de créer des archives cpio de fichiers dont les noms contiennent des caractères de nouvelle ligne.
extract_deb_control (par défaut : 1)
Les fichiers de paquets .deb de Debian contiennent des informations de contrôle dans un répertoire DEBIAN, en particulier le fichier "control" du paquet. Activez ceci si vous voulez que les informations de contrôle soient extraites pendant l'extraction en plus des fichiers normaux.
strip_unknown_ext (par défaut : 1)
Certains types de fichiers sont en fait des archives, mais leurs extensions ne l'indiquent pas. Des exemples sont les documents Open Office (fichiers Zip) et les documents Gnumeric (fichiers compressés avec gzip). Puisque les extensions de ces noms de fichiers sont inconnues d'atool, elles ne seraient pas supprimées avec cette option réglée à 0. Le fichier de sortie dans ce cas serait quelque chose comme Unpack-XYZW. Régler cette option à 1 fera que l'extension sera supprimée à la place.
use_pbzip2 (par défaut : 0)
Activez ceci si vous voulez utiliser pbzip2 plutôt que bzip2. Veuillez noter que si use_tar_bzip2_option est activé, alors bzip2 sera utilisé par tar indépendamment de l'option use_pbzip2. Donc si vous voulez que tar utilise pbzip2 plutôt que bzip2, réglez use_pbzip2 à 1 et use_tar_bzip2_option à 0.
use_lbzip2 (par défaut : 0)
Activez ceci si vous voulez utiliser lbzip2 plutôt que bzip2. Veuillez noter que si use_tar_bzip2_option est activé, alors bzip2 sera utilisé par tar indépendamment de l'option use_lbzip2. Donc si vous voulez que tar utilise lbzip2 plutôt que bzip2, réglez use_lbzip2 à 1 et use_tar_bzip2_option à 0.
use_pigz (par défaut : 0)
Activez ceci si vous voulez utiliser pigz plutôt que gzip. Veuillez noter que si use_tar_z_option est activé, alors gzip sera utilisé par tar indépendamment de l'option use_pigz. Donc si vous voulez que tar utilise pigz plutôt que gzip, réglez use_pigz à 1 et use_tar_z_option à 0.
use_plzip (par défaut : 0)
<dd>Activez cette option si vous souhaitez utiliser plzip plutôt que lzip. Veuillez noter que si use_tar_lzip_option est activé, lzip sera utilisé par tar quel que soit l'option use_plzip. Donc, si vous souhaitez que tar utilise plzip plutôt que lzip, définissez use_plzip à 1 et use_tar_lzip_option à 0.
use_jar (par défaut : 0)
Activez cette option si vous souhaitez utiliser jar pour gérer les archives jar. Si vous désactivez cette option, zip sera utilisé (ce qui devrait fonctionner tout aussi bien, et probablement plus rapidement aussi).

Cette option est désactivée par défaut car l'extraction de fichiers vers la sortie standard (`cat') n'est pas prise en charge par jar.

use_file (par défaut : 1)
Activez cette option si vous souhaitez qu'atool identifie les types de fichiers à l'aide de file(1) pour les fichiers dont l'extension n'est pas reconnue (ou qui n'en ont pas du tout).
use_file_always (par défaut : 0)
Activez cette option si vous souhaitez qu'atool identifie toujours les archives à l'aide de file(1), quelle que soit l'extension du fichier. Veuillez noter que cela présente actuellement certains inconvénients, comme l'impossibilité d'identifier tous les types d'archives (en particulier les archives tar compressées avec 7zip, lzop, szip, etc.).
tmpdir_name (par défaut : Unpack-%04d)
atool extrait vers un répertoire temporaire créé dans le répertoire courant afin qu'aucun fichier ne soit écrasé. Cette variable contrôle le nom que ce répertoire temporaire doit porter.

La chaîne `%d' dans cette variable sera remplacée par un nombre aléatoire entre 0 et 9999. Il est possible de changer le format de ce nombre en utilisant autre chose que `%d' - voir printf(3).

tmpfile_name (par défaut : Pack-%04d)
Lors de l'utilisation de pbzip2 et de la création d'archives, un fichier temporaire doit être créé. Cette option contrôle le nom de ce fichier. Voir tmpdir_name pour plus de détails sur le format.

args_diff (par défaut : -ru)
Cette variable spécifie les arguments de ligne de commande à passer à la commande diff (telle que spécifiée par path_diff) lors de l'utilisation de adiff. Les caractères d'espace séparent les arguments dans cette chaîne.

(Cette variable ne peut être définie que dans le fichier programme atool.) Cette variable spécifie le répertoire où se trouve le fichier de configuration global au système.

(Cette variable ne peut être définie que dans le fichier programme atool et le fichier de configuration global au système.) Cette variable spécifie l'emplacement du fichier de configuration de l'utilisateur. Notez que si ce nom de fichier est relatif (c'est-à-dire qu'il ne commence pas par `/'), il sera relatif au répertoire personnel de l'utilisateur courant (tel que déterminé par la variable d'environnement HOME).
default_verbosity (par défaut : 1)
Il s'agit du niveau de verbosité par défaut d'atool. En utilisant les options -q et -v, le niveau de verbosité peut être augmenté et diminué. Le niveau 1 signifie « verbosité normale » - par exemple, lors de la création et de l'extraction d'archives, les fichiers seront listés.
show_extracted (par défaut : 1)
Si cette option est définie à 1, la commande aunpack affichera toujours quel fichier ou répertoire a été extrait. Sinon, cela ne sera affiché que si l'archive a été extraite vers un emplacement inattendu (en raison de fichiers locaux déjà existants ou de l'archive contenant plusieurs fichiers dans son répertoire racine).

Cela peut être assez utile en combinaison avec `default_verbosity 0'. Notez que cette option n'aura aucun effet lorsque l'option -X est utilisée avec aunpack, et qu'elle n'a aucun effet sur les fichiers compressés.

keep_compressed (par défaut : 1)
Lors de la compression d'un fichier avec gzip ou bzip2, le fichier original (non compressé) est généralement supprimé une fois qu'il a été compressé. C'est-à-dire que si vous compressez un fichier « test », vous vous retrouverez avec un seul fichier, « test.gz ». Avec cette option définie à 1, vous ferez en sorte qu'atool conserve également le fichier original. Le comportement original est obtenu en définissant cette option à 0.

Cette option a également un effet équivalent lors de la décompression de fichiers compressés. Lorsqu'elle est définie à 1, le fichier original (compressé) sera conservé. Sinon, il sera supprimé.

Notez cependant que cette option n'a aucun effet lors de la compression d'un fichier compressé avec l'option -X (pour spécifier un répertoire ou un fichier de sortie). Dans ce cas, le fichier original est toujours conservé.

decompress_to_cwd (par défaut : 1)
Lors de la décompression d'un fichier avec des commandes telles que gzip ou bzip2, le fichier décompressé est généralement placé dans le même répertoire que le fichier compressé. Avec cette option définie à 1, le fichier décompressé est à la place placé dans le répertoire de travail courant.

Notez que cette option n'a aucun effet lorsque -X est utilisé.

VARIABLES D'ENVIRONNEMENT

PAGER Le visualiseur (pager) par défaut à utiliser lorsque l'option -p/--page est spécifiée.

EXEMPLES

Pour extraire tous les fichiers de l'archive `foobar.tar.gz' vers un sous-répertoire (ou le répertoire courant s'il ne contient qu'un seul fichier) :
aunpack foobar.tar.gz

Pour extraire tous les fichiers de toutes les archives `.tar.gz' du répertoire courant :
aunpack -e *.tar.gz

Pour créer une archive zip contenant deux fichiers `foo' et `bar' :
apack myarchive.zip foo bar

Pour afficher le fichier `baz' de l'archive `myarchive.zip' à travers un visualiseur (pager) :
acat -p myarchive.zip baz

Pour lister le contenu de l'archive rar `stuff.rar' :
als stuff.rar

Pour créer trois archives, `dir1.tar.gz', `dir2.tar.gz' et `dir3.tar.gz', de sorte que la première contienne tous les fichiers de dir1, la deuxième tous ceux de dir2 et la troisième tous ceux de dir3 :
apack -e -F .tar.gz dir1 dir2 dir3

Pour afficher toutes les différences entre les versions 2.4.17 et 2.4.18 du noyau :
adiff linux-2.4.17.tar.gz linux-2.4.18.tar.gz

Pour recompresser toutes les archives .tar.gz du répertoire courant en .tar.7z (l'ancienne archive sera conservée intacte) :
arepack -F.tar.7z -e *.tar.gz>

Voici une fonction shell qui fera en sorte que la commande aunpack se déplace dans le répertoire où les fichiers ont été extraits :
aunpack () {
TMP=`mktemp /tmp/aunpack.XXXXXXXXXX`
atool -x --save-outdir=$TMP "$@"
DIR="`cat $TMP`"
[ "$DIR" != "" -a -d "$DIR" ] && cd "$DIR"
rm $TMP
}
Si vous n'avez pas le programme mktemp, vous pouvez remplacer la deuxième ligne par (notez cependant que ce n'est pas entièrement sûr)
TMP="/tmp/atool_outdir.$$"

BUGS CONNUS

Tenter d'extraire des fichiers gzip et d'autres fichiers compressés sans l'extension .gz (ou .bz2 etc.) ne fonctionnera pas :


aunpack: foo: format not known, identifying using file
aunpack: foo: format is `gzip'
gzip: foo: unknown suffix -- ignored

Cette dernière erreur ci-dessus est générée par gzip -d foo.
