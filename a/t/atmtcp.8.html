    NOM

    atmtcp - Interface pour la couche d'adaptation de la couche de transfert d'atm

    SYNTHÈSE

    atmtcp [options] [commande]

    DESCRIPTION

    atmtcp est un utilitaire qui permet d'interagir avec la couche d'adaptation de la couche de transfert (ATM-TC) du noyau Linux. Il permet de configurer des interfaces ATM, de gérer les connexions et d'envoyer/recevoir des données.

    OPTIONS

    • -i, --interface nom : Spécifie l'interface ATM à utiliser.
    • -s, --server : Lance atmtcp en mode serveur pour écouter les connexions entrantes.
    • -c, --client : Lance atmtcp en mode client pour se connecter à un serveur.
    • -h, --help : Affiche l'aide et quitte.
    • -v, --version : Affiche les informations de version et quitte.

    COMMANDES

    • create : Crée une nouvelle interface ATM.
    • destroy : Détruit une interface ATM existante.
    • connect : Établit une connexion ATM vers un point de service.
    • disconnect : Ferme une connexion ATM.
    • send : Envoie des données sur une connexion ATM.
    • receive : Reçoit des données d'une connexion ATM.
    • status : Affiche l'état des interfaces et des connexions ATM.

    RESTRICTIONS

    Cette commande nécessite des privilèges root pour fonctionner.

    EXEMPLES

    Pour créer une nouvelle interface ATM nommée atm0 :

    # atmtcp create -i atm0

    Pour envoyer 100 octets de données sur la connexion atm0 vers le point de service 1.1.1.1 :

    # echo "hello" | atmtcp -i atm0 connect 1.1.1.1 send
