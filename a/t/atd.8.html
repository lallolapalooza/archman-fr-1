ATD(8) Manuel du gestionnaire système ATD(8)

NOM

atd — exécute les travaux mis en file d'attente pour une exécution ultérieure

SYNOPSIS

atd [-l charge_moy] [-b intervalle_lot] [-d] [-f] [-s]

DESCRIPTION

atd exécute les travaux mis en file d'attente par at(1).

OPTIONS

-l
Spécifie un facteur de charge limite, au-delà duquel les travaux par lots ne doivent pas être exécutés, au lieu du choix à la compilation de 0.8. Pour un système SMP avec n CPU, vous voudrez probablement définir ceci plus haut que n-1.
-b
Spécifie l'intervalle minimum en secondes entre le début de deux travaux par lots (60 par défaut).
-d
Débogage ; affiche les messages d'erreur sur la sortie standard au lieu d'utiliser syslog(3). Cette option implique également -f.
-f
Exécute atd au premier plan.
-s
Traite la file d'attente at/batch une seule fois. Ceci est principalement utile pour la compatibilité avec les anciennes versions de at ; atd -s est équivalent à l'ancienne commande atrun.

AVERTISSEMENT

atd ne fonctionnera pas si son répertoire de mise en file d'attente est monté via NFS, même si no_root_squash est défini.

FICHIERS

/var/spool/atd Le répertoire de stockage des travaux ; celui-ci doit être en mode 700, propriétaire daemon.

/var/spool/atd Le répertoire de stockage de la sortie ; celui-ci doit être en mode 700, propriétaire daemon.

/etc/at.allow, /etc/at.deny déterminent qui peut utiliser le système at.

VOIR AUSSI

at(1), at.deny(5), at.allow(5), cron(8), crontab(1), syslog(3).

BOGUES

La fonctionnalité de atd devrait être fusionnée dans cron(8).
