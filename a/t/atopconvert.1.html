NOM

atopconvert - convertir un fichier journal brut en version plus récente

SYNTAXE

atopconvert [-t version ] fichier_entree_brute [fichier_sortie_brute]

DESCRIPTION

Le programme atopconvert peut être utilisé pour convertir la disposition d'un fichier journal brut vers une version plus récente. L'argument obligatoire est le nom du fichier journal brut d'entrée. Si aucun fichier de sortie n'est spécifié sur la ligne de commande, atopconvert affiche uniquement la version du fichier d'entrée. Lorsque le nom d'un fichier de sortie est spécifié, le fichier d'entrée sera converti vers le fichier de sortie, ou simplement copié si le fichier d'entrée possède déjà la version requise.

Le programme atopconvert convertit le fichier d'entrée (par défaut) au format utilisé par la version la plus récente de atop et écrit dans le fichier de sortie. Avec l'option -t, une version cible alternative peut être spécifiée pour le fichier de sortie (au lieu de la version la plus récente) au format majeur.mineur (exemple : 2.3).
Une fois la conversion terminée, le fichier de sortie peut être lu par une version plus récente de atop ou même étendu par cette version d'atop.

NOTES

Le fichier journal brut d'entrée doit être au moins de version 2.0 !

Les fichiers ne peuvent être mis à niveau que vers une version supérieure, mais pas déclassés.
