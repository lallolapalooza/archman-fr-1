ATRUN(8) Manuel du programmeur Linux ATRUN(8)

NOM

atrun - exécute les tâches mises en file d'attente pour une exécution ultérieure

SYNTAXE

atrun [-l charge_moyenne] [-d]

DESCRIPTION

atrun exécute les tâches mises en file d'attente par at(1). C'est un script shell qui invoque /usr/bin/atd avec l'option -s, et est fourni pour la compatibilité ascendante avec les installations plus anciennes.

VOIR AUSSI

at(1), atd(8).

AUTEUR

At a été principalement écrit par Thomas Koenig.
