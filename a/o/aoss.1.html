NOM

aoss - Script d'encapsulation pour faciliter l'utilisation de la bibliothèque de compatibilité ALSA OSS.

SYNTAXE

aoss commande-oss [arguments]

DESCRIPTION

aoss est un simple script d'encapsulation qui facilite l'utilisation de la bibliothèque de compatibilité ALSA OSS. Il se contente de définir le chemin approprié pour LD_PRELOAD, puis exécute la commande.

Ceci est utile dans les cas où les paramètres de routage (qui peuvent être définis dans votre fichier .asoundrc) doivent être appliqués aux commandes qui utilisent l'API OSS.

Exemples de configuration asoundrc:

pcm.dsp0 { type plug slave.pcm "hw:0,0" }

ou

pcm.dsp0 { type plug slave.pcm "dmix" }

Dans les exemples de configuration ci-dessus, la définition pcm.dsp0 est utilisée pour encapsuler les appels à /dev/dsp0. Vous pouvez également encapsuler l'utilisation de /dev/dsp1, /dev/dsp2, etc. en définissant pcm.dsp1, pcm.dsp2, etc..

Le nom du PCM à ouvrir peut également être donné explicitement via la variable d'environnement ALSA_OSS_PCM_DEVICE. Cela remplace le défaut dsp0, etc.

Note sur mmap : le support mmap de aoss peut être bogué. Vos résultats peuvent varier lorsque vous essayez d'utiliser une application qui utilise le mapping mémoire (mmap'ing) pour accéder aux fichiers de périphériques OSS.

Arguments

commande-oss
Une commande qui utilise l'API OSS
arguments
Les arguments et options appropriés pour la commande OSS.
