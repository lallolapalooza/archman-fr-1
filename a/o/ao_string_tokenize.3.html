NOM

ao_string_tokenize - découpe une chaîne d'entrée en jetons

SYNTAXE

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

token_list_t * ao_string_tokenize(char const * string);

DESCRIPTION

Cette fonction convertira une chaîne d'entrée en une liste de chaînes. La liste de chaînes est dérivée en séparant l'entrée par des espaces blancs. Cependant, si l'entrée contient des caractères de guillemets simples ou doubles, le texte après ce caractère jusqu'à un guillemet correspondant deviendra la chaîne dans la liste.

Le pointeur retourné doit être désalloué avec free(3C) lorsque vous avez terminé d'utiliser les données. Les données sont placées dans un seul bloc de mémoire allouée. Ne désallouez pas les jetons/chaînes individuels.

La structure pointée contiendra au moins ces deux champs :

tkn_ct Le nombre de jetons trouvés dans la chaîne d'entrée.

tok_list Un tableau de tkn_ct + 1 pointeurs vers des sous-chaînes jetons, le dernier pointeur étant mis à NULL.

Il existe deux types de chaînes entre guillemets : les guillemets simples (') et les guillemets doubles ("). Les chaînes entre guillemets simples sont assez brutes dans le sens où les caractères d'échappement (\) sont simplement un autre caractère, sauf lorsqu'ils précèdent les caractères suivants :

    \  les doubles antislashs sont réduits à un
    '   incorpore le guillemet simple dans la chaîne
    0fP  supprime à la fois l'antislash et le caractère de nouvelle ligne

Les chaînes entre guillemets doubles sont formées selon les règles des constantes de chaînes dans les programmes ANSI-C.

string
chaîne à découper en jetons

VALEUR DE RETOUR

pointeur vers une structure qui liste chaque jeton

ERREURS

NULL est retourné et errno sera défini pour indiquer le problème :

EINVAL - Il y avait une chaîne entre guillemets non terminée.

ENOENT - La chaîne d'entrée était vide.

ENOMEM - Il n'y a pas assez de mémoire. @end itemize

EXEMPLES

    #include <stdlib.h>
    int ix;
    token_list_t * ptl = ao_string_tokenize(some_string)
    for (ix = 0; ix < ptl->tkn_ct; ix++)
    do_something_with_tkn(ptl->tkn_list[ix]);
    free(ptl);

Notez que tout est libéré avec le seul appel à free(3C).
