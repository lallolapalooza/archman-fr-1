AHOST(1) Manuel des commandes générales AHOST(1)

NOM

ahost - affiche l'enregistrement A ou AAAA associé à un nom d'hôte ou une adresse IP

SYNOPIS

ahost [OPTION]... HÔTE...

DESCRIPTION

Recherche l'enregistrement DNS A ou AAAA associé à HÔTE (un nom d'hôte ou une adresse IP).

Cet utilitaire est fourni avec la bibliothèque de résolution asynchrone c-ares.

OPTIONS

-d
Affiche des informations de débogage supplémentaires.
-h, -?
Affiche cette aide et quitte.
-t type
Si type est « a », affiche l'enregistrement A. Si type est « aaaa », affiche l'enregistrement AAAA. Si type est « u », recherche les enregistrements AAAA et A (par défaut).
-s serveur
Définit la liste des serveurs à utiliser pour les recherches DNS.
-D domaine
Spécifie le domaine à rechercher au lieu d'utiliser les valeurs par défaut de
/etc/resolv.conf. Cette option n'a d'effet que sur les plateformes qui utilisent
/etc/resolv.conf pour la configuration DNS ; elle n'a aucun effet sur les autres plateformes (comme Win32 ou Android).

SIGNALEMENT DES BOGUES
