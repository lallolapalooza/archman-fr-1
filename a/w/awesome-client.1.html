NOM

awesome-client - Exécution à distance du gestionnaire de fenêtres awesome

SYNTAXE

awesome-client [-h|--help] [commande [commande...]]

DESCRIPTION

awesome-client est une interface en ligne de commande à distance pour awesome. Il communique avec awesome via D-Bus, permettant l'exécution à distance de code Lua.

UTILISATION

awesome-client lit les commandes passées sur la ligne de commande ou provenant de l'entrée standard et les envoie via D-Bus à awesome. Si rlwrap est installé, il sera utilisé pour fournir une interface en ligne de commande readline.

Le module awful.remote doit être chargé pour que cette commande fonctionne.

EXEMPLES

$ awesome-client 'return 1+1, "Bonjour, monde"\
   double 2
   string "Bonjour, monde"
# La commande suivante ne retourne rien sur la ligne de commande,
# mais affichera une notification.
$ awesome-client '
> naughty = require("naughty")
> naughty.notify({
> title="Notification CLI",
> text="Ceci est une notification envoyée depuis la ligne de commande !"})
> '
# Entrer en mode boucle d'évaluation et d'impression (REPL)
# Ce mode enverra chaque ligne à awesome, exactement comme en passant
# plusieurs commandes sur la ligne de commande.
$ awesome-client
awesome# return 1+1
   double 2
awesome# return 1+1, "Bonjour, monde"
   double 2
   string "Bonjour, monde"
awesome#
