NOM

awesome - gestionnaire de fenêtres awesome

SYNTAXE

awesome [-v | --version] [-h | --help] [-c | --config FICHIER] [-k | --check] [--search RÉPERTOIRE] [-a | --no-argb] [-r | *--replace]

DESCRIPTION

awesome est un gestionnaire de fenêtres pour X. Il gère les fenêtres dans différents agencements, comme flottant ou en mosaïque. Tout agencement peut être appliqué dynamiquement, optimisant l'environnement pour l'application utilisée et la tâche en cours.

Dans un agencement en mosaïque, les fenêtres sont gérées dans une zone maître et une zone de superposition. La zone maître contient les fenêtres qui nécessitent actuellement le plus d'attention, tandis que la zone de superposition contient toutes les autres fenêtres. Dans un agencement flottant, les fenêtres peuvent être redimensionnées et déplacées librement. Les fenêtres de dialogue sont toujours gérées comme flottantes, quel que soit l'agencement actuellement appliqué. Les agencements spiral et dwindle sont des cas particuliers de l'agencement en mosaïque où la zone de superposition est arrangée en spirale pour le premier ou comme une fractale rectangulaire pour le second.

Les fenêtres sont regroupées par étiquettes dans awesome. Chaque fenêtre peut être étiquetée avec une ou plusieurs étiquettes. La sélection de certaines étiquettes affiche toutes les fenêtres portant ces étiquettes.

awesome peut contenir de petites wiboxes qui peuvent afficher tout ce que vous voulez : toutes les étiquettes disponibles, l'agencement actuel, le titre des fenêtres visibles, du texte, etc.

OPTIONS

-v, --version

Affiche les informations de version sur la sortie standard, puis quitte.

-h, --help

Affiche l'aide, puis quitte.

-c, --config FICHIER

Utilise un fichier de configuration alternatif au lieu de $XDG_CONFIG_HOME/awesome/rc.lua.

-k, --check

Vérifie la syntaxe du fichier de configuration.

--search

Ajoute un répertoire au chemin de recherche de la bibliothèque.

-a, --no-argb

N'utilise pas les visuels ARGB.

-r, --replace

Remplace un gestionnaire de fenêtres existant.

BINDINGS SOURIS PAR DÉFAUT

Navigation

Bouton1 sur le nom d'une étiquette

Affiche l'étiquette.

Bouton4, Bouton5 sur le nom d'une étiquette

Passe à l'étiquette précédente ou suivante.

Bouton4, Bouton5 sur la fenêtre racine

Passe à l'étiquette précédente ou suivante.

Bouton1, Bouton3, Bouton4, Bouton5 sur le symbole d'agencement

Passe à l'agencement précédent ou suivant.

Modification de l'agencement

Mod4 + Bouton1 sur le nom d'une étiquette

Étiquette le client actuel uniquement avec cette étiquette.

Mod4 + Bouton3 sur le nom d'une étiquette

Active/désactive cette étiquette pour le client.

Bouton3 sur le nom d'une étiquette

Ajoute cette étiquette à la vue actuelle.

Mod4 + Bouton1 sur la fenêtre du client

Déplace la fenêtre.

Mod4 + Bouton3 sur la fenêtre du client

Redimensionne la fenêtre.

BINDINGS CLAVIER PAR DÉFAUT

Aide

Mod4 + s

Affiche les raccourcis clavier actuellement attribués.

Contrôle du gestionnaire de fenêtres

Mod4 + Control + r

Redémarre awesome.

Mod4 + Shift + q

Quitte awesome.

Mod4 + r

Invite de commande d'exécution.

Mod4 + x

Invite de commande pour exécuter du code Lua.

Mod4 + Return

Lance le terminal émulé.

Mod4 + w

Ouvre le menu principal.

Clients

Mod4 + m

Maximise le client.

Mod4 + n

Minimise le client.

Mod4 + Control + n

Restaure le client.

Mod4 + f

Met le client en plein écran.

Mod4 + Shift + c

Ferme le client focalisé.

Mod4 + t

Place le client au premier plan.

Navigation

Mod4 + j

Focalise le client suivant.

Mod4 + k

Focalise le client précédent.

Mod4 + u

Focalise le premier client urgent.

Mod4 + Left

Affiche l'étiquette précédente.

Mod4 + Right

Affiche l'étiquette suivante.

Mod4 + 1-9

Passe à l'étiquette 1-9.

Mod4 + Control + j

Passe à l'écran suivant.

Mod4 + Control + k

Passe à l'écran précédent.

Mod4 + Escape

Focalise le dernier ensemble d'étiquettes sélectionné.

Modification de l'agencement

Mod4 + Shift + j

Échange le client avec le client suivant.

Mod4 + Shift + k

Échange le client avec le client précédent.

Mod4 + o

Envoie le client à l'écran suivant.

Mod4 + h

Diminue le facteur de largeur maître de 5%.

Mod4 + l

Augmente le facteur de largeur maître de 5%.

Mod4 + Shift + h

Augmente le nombre de fenêtres maîtres de 1.

Mod4 + Shift + l

Diminue le nombre de fenêtres maîtres de 1.

Mod4 + Control + h

Augmente le nombre de colonnes pour les fenêtres non maîtresses de 1.

Mod4 + Control + l

Diminue le nombre de colonnes pour les fenêtres non maîtresses de 1.

Mod4 + space

Passe à l'agencement suivant.

Mod4 + Shift + space

Passe à l'agencement précédent.

Mod4 + Control + space

Active/désactive l'état flottant du client.

Mod4 + Control + Return

Échange le client focalisé avec le maître.

Mod4 + Control + 1-9

Active/désactive la vue d'étiquette.

Mod4 + Shift + 1-9

Étiquette le client avec l'étiquette correspondante.

Mod4 + Shift + Control + 1-9

Active/désactive l'étiquette sur le client.

PERSONNALISATION

awesome est personnalisé en créant un fichier $XDG_CONFIG_HOME/awesome/rc.lua personnalisé.

SIGNaux

awesome peut être redémarré en lui envoyant un SIGHUP.

BOGUES

Bien sûr, il n'y a pas de bug dans awesome. Mais il peut y avoir des comportements inattendus.
