NOM

awesomerc - Fichier de configuration pour le gestionnaire de fenêtres awesome

SYNTAXE

awesome recherche un fichier de configuration dans l'ordre suivant :

•$XDG_CONFIG_HOME/awesome/rc.lua
•$HOME/.config/awesome/rc.lua
•$XDG_CONFIG_DIRS/awesome/rc.lua

DESCRIPTION

Le fichier rc.lua contient des informations de configuration pour awesome. Il peut être utilisé pour configurer le comportement et l'apparence d'awesome de diverses manières. Il peut être assimilé à un programme/script Lua exécuté au démarrage par awesome. Par conséquent, il devrait utiliser l'API Lua d'awesome décrite dans la section API. Ce fichier est lu au démarrage.

API LUA AWESOME

La documentation de l'API Lua se trouve dans le répertoire luadoc.

FORMAT DES COULEURS

Le format de couleur dans awesome est soit un nom de couleur X standard (blue, darkblue, lightred, etc.) soit une couleur au format hexadécimal (#rrggbb ou #rrggbbaa). En utilisant le format hexadécimal, vous pouvez également spécifier un canal alpha : cela signifie que #00ff00 dessinera du vert pur, mais #00ff00aa définira le canal alpha sur ‘aa’ et mélangera le vert avec la couleur en dessous.

FORMAT DU TEXTE

Vous pouvez utiliser le balisage Pango dans une chaîne de texte. Cela permet de formater le texte rendu à l'intérieur des widgets. La documentation sur le balisage Pango se trouve dans la documentation Pango à l'adresse http://library.gnome.org/devel/pango/stable/PangoMarkupFormat.html.

Un exemple de balisage Pango : <span weight="bold" foreground="#336699">...</span>.
