AUPARSE_GET_LINE_NUMBER(3) API d'audit Linux AUPARSE_GET_LINE_NUMBER(3)

NOM

auparse_get_line_number - obtenir le numéro de ligne où l'enregistrement a été trouvé

SYNTAXE

#include <auparse.h>

unsigned int auparse_get_line_number(const auparse_state_t *au);"

DESCRIPTION

auparse_get_line_number retournera le numéro de ligne de la source d'entrée pour l'enregistrement courant de l'événement courant. Les numéros de ligne commencent à 1. Si le type de source d'entrée est AUSOURCE_FILE_ARRAY, la numérotation des lignes sera réinitialisée à 1 chaque fois qu'une nouvelle ligne du tableau de fichiers est ouverte.

VALEUR DE RETOUR

Retourne le numéro de ligne. Les numéros de ligne sont basés sur 1 ; une valeur zéro indique que l'information sur le numéro de ligne n'est pas disponible.

VOIR AUSSI

auparse_get_filename(3). auparse_next_record(3).
