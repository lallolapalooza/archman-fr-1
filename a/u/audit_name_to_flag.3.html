AUDIT_NAME_TO_FLAG(3) API d'audit Linux AUDIT_NAME_TO_FLAG(3)

NOM

audit_name_to_flag - Convertit le nom du filtre de correspondance de règle en valeur numérique du filtre de correspondance de règle

SYNTAXE

#include <libaudit.h>
int audit_name_to_flag(const char *flag);

DESCRIPTION

audit_name_to_flag() convertit le nom du filtre de correspondance de règle (« task », « exit », « user », « exclude », « filesystem ») en valeur numérique du filtre de correspondance de règle (AUDIT_FILTER_TASK, AUDIT_FILTER_EXIT, AUDIT_FILTER_USER, AUDIT_FILTER_EXCLUDE, AUDIT_FILTER_FS). flag est le nom du filtre de correspondance de règle.

VALEUR DE RETOUR

Retourne -1 en cas d'erreur ; sinon, la valeur de retour est la valeur numérique du filtre de correspondance de règle.
