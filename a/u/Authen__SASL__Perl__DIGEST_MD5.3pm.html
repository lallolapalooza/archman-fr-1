NOM

Authen::SASL::Perl::DIGEST_MD5 - (DÉPRÉCIÉ) Classe d'authentification Digest MD5

VERSION

version 2.1900

SYNOPSIS

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'DIGEST-MD5',
  callback  => {
    user => $user, 
    pass => $pass,
    serv => $serv
  },
);

DESCRIPTION

Cette méthode implémente les parties client et serveur de l'algorithme SASL DIGEST-MD5, tel que décrit dans la RFC 2831.

Veuillez noter que ce mécanisme a été déplacé dans la section "OBSOLÈTE" du registre des mécanismes https://www.iana.org/assignments/sasl-mechanisms/sasl-mechanisms.xhtml conformément à la RFC6331 https://www.rfc-editor.org/rfc/rfc6331.html.

CALLBACK

Les callbacks utilisés sont :

client

authname
L'identifiant d'autorisation à utiliser après une authentification réussie
user
Le nom d'utilisateur à utiliser dans la réponse
pass
Le mot de passe à utiliser pour calculer la réponse.
serv
Le nom du service lors de l'authentification à un service répliqué
realm
Le domaine d'authentification lors du remplacement du défaut fourni par le serveur. S'il n'est pas donné, la valeur fournie par le serveur est utilisée.

Le callback recevra la liste des domaines que le serveur a fournis dans la réponse initiale.

server

realm
Le domaine par défaut à fournir au client
getsecret(username, realm, authzid)
renvoie le mot de passe associé à "username" et "realm"

PROPRIÉTÉS

Les propriétés utilisées sont :

maxbuf
La taille maximale du tampon pour la réception des données chiffrées
minssf
La valeur minimale de SSF (Security Services Layer) qui doit être fournie par la couche de sécurité SASL. La valeur par défaut est 0.
maxssf
La valeur maximale de SSF qui doit être fournie par la couche de sécurité SASL. La valeur par défaut est 2**31.
externalssf
La valeur SSF fournie par une couche de sécurité externe sous-jacente. La valeur par défaut est 0.
ssf
La valeur SSF réelle fournie par la couche de sécurité SASL après l'achèvement de la phase d'authentification SASL. Cette valeur est en lecture seule et est définie par l'implémentation après l'achèvement de la phase d'authentification SASL.
maxout
La taille maximale du tampon en clair pour l'envoi de données à l'interlocuteur. Cette valeur est définie par l'implémentation après l'achèvement de la phase d'authentification SASL et lorsqu'une couche de sécurité SASL est active.
