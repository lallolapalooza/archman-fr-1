AUDISP-AF_UNIX(8) Utilitaires d'administration système AUDISP-AF_UNIX(8)

NOM

audisp-af_unix - plugin pour envoyer les événements d'audit à un socket af_unix

SYNOPSIS

audisp-af_unix [ OPTIONS ]

DESCRIPTION

audisp-af_unix est un plugin pour le répartiteur d'événements d'audit qui envoie les événements d'audit à un socket af_unix où d'autres applications peuvent lire les événements. La ligne args du fichier af_unix.conf attend trois arguments : le mode d'accès, le chemin du socket et le format de sortie, et facultativement un quatrième argument spécifiant la profondeur de la file d'attente. Le mode d'accès détermine les permissions du socket et est par défaut 0640. Le chemin du socket spécifie où le socket sera créé, l'emplacement par défaut étant /run/audit/audispd_events. Le format de sortie détermine le format dans lequel les événements sont livrés au socket et prend en charge deux options : « string » et « binary ». Le format « string » livre les événements sous une forme lisible par l'homme, tandis que le format « binary » livre les événements dans leur représentation binaire, ce qui est essentiel pour les applications qui doivent traiter les événements en binaire et reconstruire les en-têtes avec précision. Si le format de sortie n'est pas spécifié, le plugin utilise par défaut le format « string ». Si aucune profondeur de file d'attente n'est spécifiée, elle est par défaut à 512.

Le fichier af_unix.conf doit également inclure la ligne format = binary. Ce paramètre spécifie le format d'entrée que le plugin audisp-af_unix attend du répartiteur d'événements d'audit. Il garantit que l'entrée livrée au plugin est au format binaire, permettant au plugin de reconstruire les en-têtes dans leur structure binaire appropriée.

Lorsque le plugin reçoit SIGUSR1, il écrit un rapport d'état dans af_unix.state.

FICHIERS

/etc/audit/plugins/af_unix.conf /run/audit/audispd_events /run/audit/af_unix.state /etc/audit/auditd.conf

VOIR AUSSI

auditd.conf(8), auditd-plugins(5).
