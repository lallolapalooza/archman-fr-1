NOM

auto-multiple-choice-annotate - inscrit les réponses aux questions d'un examen à choix multiples AMC

SYNTAXE

auto-multiple-choice annotate --project dir-projet --names-file eleves.csv [options d'annotation...]

DESCRIPTION

La commande auto-multiple-choice annotate permet d'inscrire les choix pour chaque question et les choix globaux dans des fichiers PDF (un fichier par étudiant ou un fichier unique pour tous les étudiants) qui sont ensuite imprimés.

Options générales

--project dir-projet

Définit le nom du projet ou le répertoire.

--data dir-donnees-projet

Spécifie le répertoire où se trouvent les fichiers de données (la valeur par défaut est dir-projet/data).

--pdf-dir dir-pdf

Définit le répertoire des pdf du projet (la valeur par défaut est dir-projet/cr/corrections/pdf).

--names-file eleves.csv

Spécifie le nom du fichier de la liste des noms des étudiants.

--names-encoding encodage

Choisit l'encodage du fichier eleves.csv (par défaut utf-8).

--association-key cle

Définit la colonne utilisée pour différencier les étudiants (nom de la colonne dans le fichier de liste des noms des étudiants). La valeur actuellement utilisée est stockée dans la base de données, et c'est la valeur par défaut, donc cette option n'a pas besoin d'être utilisée.

--subject sujet.pdf

Spécifie le chemin du fichier de l'énoncé du sujet (par défaut dir-projet/DOC-sujet.pdf).

--compose mode

Utilisée quand on veut recopier les pages des documents sans boîtes à cocher (par exemple, les pages qui précèdent le sujet pour les étudiants) à partir du document sujet. Si mode vaut 1, les pages sont copiées à partir du sujet, les réponses sont annotées de la même manière que les réponses des étudiants, et les mêmes numéros de correction sont inscrits sur les feuilles de réponses. Si mode vaut 2, les pages sont copiées à partir des feuilles de réponses corrigées (donc dupliquées), et les numéros de correction ne sont pas inscrits.

--corrected corrige.pdf

Spécifie le chemin du PDF de la correction de l'ensemble du sujet (par défaut dir-projet/DOC-corrige.pdf. Si ce fichier n'existe pas, il est créé en utilisant les valeurs des options --n-copies, --with, --filter, et --filtered-source).

--darkness-threshold t

Définit la valeur du seuil de noirceur des pixels. La valeur réellement utilisée est stockée dans la base de données, et c'est la valeur par défaut, donc cette option n'a pas besoin d'être utilisée.

--darkness-threshold-up t_sup

Définit la valeur supérieure du seuil de noirceur des pixels. La valeur réellement utilisée est stockée dans la base de données, et c'est la valeur par défaut, donc cette option n'a pas besoin d'être utilisée.

--csv-build-name modele-nom

Définit le modèle pour construire les noms des étudiants à partir du fichier CSV. La valeur par défaut est « (nom|surname) (prenom|name) », auquel cas le nom est le contenu de la colonne nom (ou surname s'il n'y a pas de colonne nom) suivi du contenu de la colonne prenom (ou name s'il n'y a pas de colonne prenom), ce qui fait que le nom du fichier est basé sur la convention française ou anglaise selon le fichier CSV.

--id-file ids.txt

Spécifie le fichier contenant la liste des ID des feuilles de réponse à annoter (numéro d'étudiant pour le mode feuille de réponse par étudiant, ou etudiant:copie pour le mode feuille de réponse par copie). Si le fichier n'est pas spécifié, toutes les feuilles de réponse sont annotées.

--debug fichier.log

Spécifie le fichier où écrire les informations de débogage.

Options de sortie PDF

--n-copies n

Spécifie le nombre de copies à créer pour chaque étudiant (par défaut 1).

--with mode

Définit le mode de génération des copies. mode peut être :
multi
crée une copie par étudiant.
single
crée une seule copie pour tous les étudiants.
d
crée une copie par étudiant avec l'identifiant étudiant en haut de chaque page.
La valeur par défaut est multi.

--filter regex

Spécifie une expression régulière pour filtrer les étudiants à inclure dans la sortie. Par défaut, tous les étudiants sont inclus.

--filtered-source source

Spécifie la source des données des étudiants pour le filtrage. La valeur peut être names (fichier des noms) ou scan (résultats du scan). La valeur par défaut est names.

--pages liste-pages

Spécifie les pages à inclure dans le fichier de sortie. liste-pages est une liste de nombres de pages séparés par des virgules, ou des plages de pages (par exemple, 1,3,5-7).

--first-page n

Spécifie le numéro de la première page à inclure dans la sortie.

--last-page n

Spécifie le numéro de la dernière page à inclure dans la sortie.

Exemple

Pour annoter les copies d'un projet nommé `MonProjet`, en utilisant le fichier `liste_eleves.csv` et en générant une copie par étudiant :

auto-multiple-choice annotate --project MonProjet --names-file liste_eleves.csv --with multi
