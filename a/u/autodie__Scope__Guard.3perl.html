NOM

autodie::Scope::Guard - Classe d'encapsulation pour appeler des subs à la fin de la portée

SYNTAXE

use autodie::Scope::Guard;
$^H{'my-key'} = autodie::Scope::Guard->new(sub {
    print "Hallo world\n";
});

DESCRIPTION

Cette classe est utilisée pour bénir des subs perl afin qu'ils soient invoqués lorsqu'ils sont détruits. C'est surtout utile pour s'assurer que le code est invoqué à la fin de la portée. Ce module ne fait pas partie de l'API publique d'autodie.

Ce module est directement inspiré de l'excellent module Scope::Guard de chocolateboy.

Méthodes

new

my $hook = autodie::Scope::Guard->new(sub {});

Crée un nouveau "autodie::Scope::Guard", qui invoquera la sub donnée une fois qu'elle sortira de sa portée (c'est-à-dire que son gestionnaire DESTROY sera appelé).
