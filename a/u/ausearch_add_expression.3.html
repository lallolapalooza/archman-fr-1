AUSEARCH_ADD_EXPRESSION(3) API d'audit Linux AUSEARCH_ADD_EXPRESSION(3)

NOM

ausearch_add_expression - construire une expression de recherche

SYNTAXE

#include <auparse.h>
int ausearch_add_expression(auparse_state_t *au, const char *expression, char **error, ausearch_rule_t how);"

DESCRIPTION

ausearch_add_item ajoute une expression à l'expression de recherche d'audit actuelle. Les conditions de recherche peuvent ensuite être utilisées pour scanner les journaux, les fichiers ou les tampons pour trouver quelque chose d'intéressant. Le paramètre expression contient une expression, telle que spécifiée dans ausearch-expression(5). Le paramètre how détermine comment cette expression de recherche affectera l'expression de recherche existante, si une est déjà définie. Les valeurs possibles sont :

AUSEARCH_RULE_CLEAR
Efface l'expression de recherche actuelle, le cas échéant, et utilise uniquement cette expression de recherche.
AUSEARCH_RULE_OR
Si une expression de recherche E est déjà configurée, remplacez-la par (E || cette_expression_de_recherche).
AUSEARCH_RULE_AND
Si une expression de recherche E est déjà configurée, remplacez-la par (E && cette_expression_de_recherche).
L'appelant doit libérer le message d'erreur à l'aide de free(3). Si un message d'erreur n'est pas disponible ou ne peut pas être alloué, *error est défini sur NULL.
