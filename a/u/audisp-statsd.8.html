AUDISP-STATSD(8) Utilitaires d'administration système AUDISP-STATSD(8)

NOM

audisp-statsd - plugin pour pousser les métriques d'audit vers un service statsd

SYNTAXE

audisp-statsd [ OPTIONS ]

DESCRIPTION

audisp-statsd est un plugin pour le répartiteur d'événements d'audit qui pousse les métriques d'audit vers un service statsd en utilisant UDP. Il lit le rapport d'état d'auditd à intervalles réguliers et transmet les données. La génération du rapport d'état doit être activée dans auditd.conf.

CONFIGURATION

Le fichier de configuration du plugin est /etc/audit/audisp-statsd.conf. Les paramètres suivants sont reconnus :

adresse
Le nom ou l'adresse du serveur statsd.
port
Le port UDP du service statsd.
intervalle
Intervalle de temps entre la lecture du rapport d'auditd. La valeur est une chaîne de temps telle que 10m, 1h, 2d, ou 6M où le suffixe est s pour secondes, m pour minutes, h pour heures, d pour jours et M pour mois. La valeur par défaut est 15s.

MÉTRIQUES DU RAPPORT

Le plugin collecte les métriques suivantes en tant que jauges :

backlog
nombre d'événements du noyau en attente de transfert vers l'espace utilisateur
perdu
nombre d'événements du noyau supprimés
espace_libre
espace disque libre vu par auditd en MiB
plugin_profondeur_courante
nombre d'événements en attente de transfert vers les plugins dans auditd
plugin_profondeur_max
nombre maximum historique d'événements en attente de transfert vers les plugins
mémoire_totale
mémoire totale actuellement utilisée par glibc en KiB
mémoire_utilisée
combien de la mémoire totale est activement utilisée en KiB
mémoire_libre
quantité de mémoire libre disponible dans les arenas glibc en KiB

Les métriques suivantes sont des compteurs :

compteur_total_événements
nombre total d'événements vus pendant l'intervalle
compteur_total_échecs_événements
nombre total d'événements vus pendant l'intervalle avec un résultat d'échec
compteur_événements_avc
nombre total d'événements AVC vus pendant l'intervalle
compteur_événements_fanotify
nombre total d'événements FANOTIFY vus pendant l'intervalle
compteur_connexions_réussies
nombre total d'événements de connexion réussie vus pendant l'intervalle
compteur_connexions_échouées
nombre total d'événements de connexion échouée vus pendant l'intervalle
compteur_événements_anomalie
nombre total d'événements d'anomalie vus pendant l'intervalle
compteur_réponse_anomalie
nombre total d'événements de réponse à une anomalie vus pendant l'intervalle

FICHIERS

/etc/audit/audisp-statsd.conf /etc/audit/plugins/au-statsd.conf

VOIR AUSSI

auditd.conf(8), auditd-plugins(5).
