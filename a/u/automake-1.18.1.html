NOM

automake - Génère les fichiers Makefile.in pour configure à partir de Makefile.am

SYNOPSIS

automake [OPTION]... [Makefile]...

DESCRIPTION

Génère Makefile.in pour configure à partir de Makefile.am.

Modes d'opération :

--help
affiche cette aide, puis quitte
--version
affiche le numéro de version, puis quitte
-v, --verbose
liste de manière détaillée les fichiers traités
--no-force
ne met à jour que les Makefile.in obsolètes
-W, --warnings=CATÉGORIE
signale les avertissements appartenant à la CATÉGORIE

Suivi des dépendances :

-i, --ignore-deps
désactive le code de suivi des dépendances
--include-deps
active le code de suivi des dépendances

Variantes :

--foreign
définit la sévérité sur foreign
--gnits
définit la sévérité sur gnits
--gnu
définit la sévérité sur gnu

Fichiers de bibliothèque :

-a, --add-missing
ajoute les fichiers standards manquants au paquet
--libdir=RÉP
définit le répertoire stockant les fichiers de bibliothèque
--print-libdir
affiche le répertoire stockant les fichiers de bibliothèque
-c, --copy
avec -a, copie les fichiers manquants (par défaut, un lien symbolique est créé)
-f, --force-missing
force la mise à jour des fichiers standards

Les catégories d'avertissement sont :

cross
problèmes de compilation croisée
gnu
normes de codage GNU (par défaut dans les modes gnu et gnits)
obsolete
fonctionnalités ou constructions obsolètes (par défaut)
override
redéfinitions par l'utilisateur de règles ou de variables Automake
portability
problèmes de portabilité (par défaut dans les modes gnu et gnits)
portability-recursive
variables Make imbriquées (par défaut avec -Wportability)
extra-portability
problèmes de portabilité supplémentaires liés à des outils obscurs
syntax
constructions syntaxiques douteuses (par défaut)
unsupported
fonctionnalités non prises en charge ou incomplètes (par défaut)

-W comprend aussi :

all
active tous les avertissements
none
désactive tous les avertissements
no-CATÉGORIE
désactive les avertissements de la CATÉGORIE
error
traite tous les avertissements activés comme des erreurs
