NOM

authoscope - craqueur d'authentification réseau scriptable

SYNTAXE

authoscope [-nVh] commande

DESCRIPTION

authoscope est un craqueur d'authentification réseau scriptable. Bien que l'espace pour le bruteforce des services courants soit déjà très bien saturé, vous pourriez toujours finir par écrire vos propres scripts python lors du test des identifiants pour des applications web.

La portée d'authoscope est spécifiquement le craquage de services personnalisés. Ceci est fait en écrivant des scripts qui sont chargés dans un runtime lua. Ces scripts représentent un service unique et fournissent une fonction `verify(user, password)` qui renvoie vrai ou faux. La concurrence, l'indication de progression et le rapport sont magiquement fournis par le runtime authoscope.

OPTIONS

-n, --workers <workers>
Le nombre de workers concurrents à exécuter.
-o, --output <output>
Écrit les résultats dans ce fichier.
-v, --verbose
Active la sortie détaillée.
-h, --help
Affiche les informations d'aide.
-V, --version
Affiche les informations de version.

SOUS-COMMANDES

Choisissez l'une des sous-commandes suivantes.

Attaque par dictionnaire

Essaie chaque mot de passe pour chaque utilisateur avec chaque script.

authoscope dict <utilisateurs> <motsdepasse> [scripts]...

Confirmation didentifiants

Charge une liste d'identifiants au format utilisateur:motdepasse et les vérifie avec chaque script.

authoscope creds <identifiants> [scripts]...

Énumération de nom d'utilisateur

Prend une liste de noms d'utilisateur et vérifie s'ils existent sur le système. Ceci exécute toujours la fonction verify avec deux arguments, mais le mot de passe est défini à nil. Vous pouvez écrire un script capable de faire les deux en vérifiant si le mot de passe est nil pour détecter dans quel mode le script est exécuté.

authoscope enum <utilisateurs> [scripts]...

OneShot

Teste une seule combinaison utilisateur-mot de passe en utilisant un script spécifique. Cette commande est également utile lors du développement d'un nouveau script. Si l'argument mot de passe est omis, le script est exécuté en mode d'énumération. Si vous souhaitez utiliser cette commande dans des scripts, définissez -x afin que le code de sortie soit défini à 2 si les identifiants sont invalides.

authoscope oneshot [-x] <script> <utilisateur> [motdepasse]

RÉFÉRENCE RUNTIME

Le runtime authoscope fournit un certain nombre de fonctions qui peuvent être utilisées pour tester des systèmes cibles.

Décode une chaîne base64.

Encode un tableau binaire avec base64.

Efface toutes les erreurs enregistrées pour empêcher une ré-insertion dans la file d'attente.

    return false
else
    return true
end

html_select

Analyse un document html et renvoie le premier élément qui correspond au sélecteur CSS. La valeur de retour est une table avec text étant le texte intérieur et attrs étant une table des attributs de l'élément.

csrf = html_select(html, 'input[name="csrf"]')
token = csrf["attrs"]["value"]

html_select_list

Identique à html_select mais renvoie toutes les correspondances au lieu de la première.

html_select_list(html, 'input[name="csrf"]')

http_basic_auth

Envoie une requête GET avec authentification basique. Renvoie true si aucun en-tête WWW-Authenticate n'est défini et que le code d'état n'est pas 401.

http_basic_auth("https://httpbin.org/basic-auth/foo/buzz", user, password)

http_mksession

Crée un objet de session. Ceci est similaire à requests.Session dans python-requests et garde une trace des cookies.

session = http_mksession()

http_request

Prépare une requête http. Le premier argument est la référence de session et les cookies de cette session sont copiés dans la requête. Une fois la requête envoyée, les cookies de la réponse sont copiés dans la session.

Les arguments suivants sont la méthode, l'url et des options supplémentaires. Veuillez noter que vous devez toujours spécifier un tableau vide {} même si aucune option n'est définie. Les options suivantes

options sont disponibles

:
