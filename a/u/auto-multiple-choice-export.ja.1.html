NOM

auto-multiple-choice-export - Exporter les résultats de notation des examens à choix multiple AMC

SYNOPSIS

auto-multiple-choice export --dataproject-data-dir --modulemodule --fich-nomsstudents-list.csv [--noms-encodagelist-encoding] --ooutput-file

DESCRIPTION

La commande auto-multiple-choice exportexporte les résultats de notation d'un examen à choix multiple AMC.

--data project-data-dir

Spécifie le répertoire contenant les fichiers de données (voirauto-multiple-choice-meptex(1)etc.).

--module module

Sélectionne le module d'exportation. Voir ci-dessous pour les modules fournis avec la distribution standard d'AMC.

--fich-noms students-list.csv

Définit le nom du fichier de la liste des étudiants.

--noms-encodage list-encoding

Sélectionne l'encodage de students-list.csv(par défaut utf-8).

--o output-file

Spécifie le nom du fichier de sortie.

--option-out options

Spécifie des options pour le module sélectionné sous la forme clé=valeur (voir ci-dessous pour les options disponibles pour chaque module). Pour spécifier plusieurs options, utilisez--optionplusieurs fois.

--sort sort-type

Trie les noms des étudiants selonsort-type.Si sort-typevaut l, le tri utilise le numéro de ligne de la liste des étudiants.Si sort-typevaut m, le tri utilise la note (et le nom de l'étudiant en cas d'égalité).Si sort-typevaut i, le tri utilise le numéro d'examen.Si sort-typevaut n, le tri utilise le nom de l'étudiant (et le numéro de ligne de la liste en cas d'égalité).

--useall all

Si allvaut 0 ou est vide, seuls les étudiants ayant un devoir scanné sont inclus dans la sortie.Si allvaut 1, tous les étudiants de la liste sont inclus dans la sortie.

MODULES

OpenDocument

«--module ods» produit un fichier OpenDocument (format utilisé par OpenOffice, LibreOffice, etc.). Les options suivantes sont reconnues :

nom

Spécifie le nom de l'examen affiché en haut de la feuille.

code

Spécifie l'abréviation de l'examen utilisée pour le nom de l'onglet.

columns

Définit la liste des colonnes à ajouter pour chaque étudiant. La valeur par défaut est student.key,student.name.

stats

Si vrai, ajoute un tableau de statistiques des questions.

statsindic

Si vrai, ajoute un tableau de statistiques des questions non notées.

CSV

«--module CSV» produit un fichier CSV. Les options suivantes sont reconnues :

columns

Définit la liste des colonnes à ajouter pour chaque étudiant. La valeur par défaut est student.copy,student.key,student.name.

decimal

Définit le séparateur décimal (par défaut le point).

encodage

Définit l'encodage utilisé pour la sortie (par défaut utf-8).

separateur

Définit le caractère de séparation des colonnes (par défaut la virgule).

entoure

Spécifie le caractère entourant les chaînes (par défaut le guillemet double).

ticked

Si non vide, ajoute des colonnes dont le nom commence par « CHECKED: », indiquant quelles cases sont cochées sur chaque devoir. Cela peut être utilisé par un programme externe pour obtenir des informations sur les cases cochées, par exemple pour une notation plus souple. Si les cases 3 et 4 sont;なる場合、01という値を指定すれば0;0;1;1;0となります。ABという値を指定すればCDとなります。

Liste

「--module Liste」とすると、受験者ごとの得点の一覧がPDFファイルで生成されます。以下のオプションが認識されます:

pagesize

ページサイズです。デフォルト値はa4です。

nom

ページの先頭に表示する試験の名称を指定します。

ncols

カラム数です。デフォルト値は2です。

décimal

小数点（デフォルトはピリオド）を設定します。
