autodie::Util(3perl) Guide de référence du programmeur Perl autodie::Util(3perl)

NOM

autodie::Util - Sous-routines utilitaires internes pour autodie et Fatal

SYNOPIS

# API INTERNE uniquement pour autodie et Fatal !
use autodie::Util qw(on_end_of_compile_scope);
on_end_of_compile_scope(sub { print "Hallo world\n"; });

DESCRIPTION

Utilitaires internes pour autodie et Fatal ! Ce module ne fait pas partie de l'API publique d'autodie.

Ce module contient des sous-routines utilitaires pour abstraire la magie sous-jacente d'autodie et les (ab)utilisations de "%^H" pour appeler des sous à la fin des portées (de compilation).

Notez qu'en raison du fonctionnement de "%^H", certains de ces utilitaires ne sont utiles que pendant la phase de compilation d'un module Perl et reposent sur les détails internes de la façon dont Perl gère les références dans "%^H".

Méthodes

on_end_of_compile_scope

on_end_of_compile_scope(sub { print "Hallo world\n"; });

Invoquera une sous à la fin d'une portée (de compilation). La sous est appelée une fois sans arguments. Peut être appelée plusieurs fois (même dans la même portée de "compilation") pour installer plusieurs sous. Les sous sont appelées dans un ordre "premier entré, dernier sorti" (LIFO ou ordre de "pile").

fill_protos

fill_protos('*$$;$@')

Étant donné un prototype de sous-routine Perl, renvoie une liste de spécifications d'invocation. Chaque spécification est une liste de références, où le premier membre est le nombre (minimum) d'arguments pour cette spécification d'invocation. Les arguments restants sont une représentation sous forme de chaîne de la manière de passer correctement les arguments à une sous avec le prototype donné, lorsqu'elle est appelée avec le nombre d'arguments spécifié.

Les spécifications sont renvoyées dans l'ordre croissant du nombre d'arguments à partir de 0 (par exemple, ';$') ou 1 (par exemple, '$@'). Notez que si le prototype est "slurpy" (par exemple, se termine par un "@"), le nombre d'arguments pour la dernière spécification est un nombre "minimum" plutôt qu'un nombre exact. Cela peut être détecté par le dernier membre de la dernière spécification correspondant à m/[@#]_/.

make_core_trampoline

make_core_trampoline('CORE::open', 'main', prototype('CORE::open'))

Crée un trampoline pour appeler une sous de base. Essentiellement, une petite sous qui détermine comment nous devrions appeler notre sous de base, y insère les arguments de la bonne manière et nous redirige vers celle-ci.

Si nous pouvions utiliser de manière fiable `goto &` sur les builtin de base, nous n'aurions pas besoin de cette sous-routine.

install_subs

install_subs('My::Module', { 'read' => sub { die("Hallo\n"), ... }})

Étant donné un nom de package et une table de hachage associant des noms à une référence de sous-routine (ou "undef"), cette sous-routine installera les sous-routines dites sous leur nom donné dans ce module. Si un nom est mappé à "undef", toute sous-routine portant ce nom dans le module cible sera supprimée (éventuellement en "démasquant" une sous CORE du même nom).
