AUDIT_LOG_USER_COMM_MESSAGE(3) API d'audit Linux AUDIT_LOG_USER_COMM_MESSAGE(3)

NOM

audit_log_user_comm_message - enregistrer un message utilisateur d'une application console

SYNTAXE

#include <libaudit.h>

int audit_log_user_comm_message(intaudit_fd,int"type,constchar*"message,constchar*"comm,constchar*"hostname,constchar*"addr,constchar*"tty,int"result);"

DESCRIPTION

Cette fonction enregistre un message dans le système d'audit en utilisant un format de message prédéfini. Cette fonction doit être utilisée par toutes les applications console non-ELF qui ne manipulent pas les comptes, les groupes, ou qui n'ont pas besoin d'enregistrer l'exécution d'un script. Un exemple serait un script Python enregistrant un événement. Les paramètres de la fonction sont les suivants :

audit_fd - Le descripteur de fichier retourné par audit_open
type - Type de message, par exemple : AUDIT_USYS_CONFIG, AUDIT_USER_LOGIN
message - Le texte du message envoyé
comm - Le nom de la ligne de commande du programme, NULL si inconnu
hostname - Le nom d'hôte si connu, NULL si inconnu
addr - L'adresse réseau de l'utilisateur, NULL si inconnue
tty - Le tty de l'utilisateur, si NULL, la fonction tentera de le déterminer
result - 1 pour "succès" et 0 pour "échec"

VALEUR DE RETOUR

Elle retourne le numéro de séquence qui est > 0 en cas de succès et <= 0 en cas d'erreur.

ERREURS

Cette fonction retourne -1 en cas d'échec. Examinez errno pour plus d'informations.

VOIR AUSSI
