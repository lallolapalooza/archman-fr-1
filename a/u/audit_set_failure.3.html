AUDIT_SET_FAILURE(3) API Audit Linux AUDIT_SET_FAILURE(3)

NOM

audit_set_failure - Définir le drapeau d'échec d'audit

SYNTAXE

#include <libaudit.h>

int audit_set_failure(intfd,uint32_t"failure);"

DESCRIPTION

audit_set_failure définit l'action que le noyau effectuera lorsque la limite du tampon de retour est atteinte ou lorsqu'il rencontre une erreur et ne peut pas continuer. Les valeurs possibles sont :

0 - AUDIT_FAIL_SILENT
Ne rien faire, ne rien signaler, ignorer l'enregistrement et continuer.
1 - AUDIT_FAIL_PRINTK [par défaut]
Enregistrer l'enregistrement d'audit en utilisant printk, ce qui entraînera l'écriture des événements ultérieurs dans syslog.
2 - AUDIT_FAIL_PANIC
Appeler la fonction panic. Ceci serait utilisé pour empêcher l'utilisation de la machine en cas de perte d'événements d'audit.

VALEUR DE RETOUR

La valeur de retour est <= 0 en cas d'erreur, sinon c'est le numéro d'identification de séquence netlink. Cette fonction peut rencontrer toutes les erreurs que sendto pourrait rencontrer.

VOIR AUSSI

audit_set_backlog_limit(3), audit_open(3), auditd(8), auditctl(8).
