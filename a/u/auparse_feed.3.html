AUPARSE_FEED(3) API d'audit Linux AUPARSE_FEED(3)

NOM

auparse_feed - alimenter le parseur avec des données

SYNTAXE

#include <auparse.h>

int auparse_feed(auparse_state_t *au,constchar*"data,size_t"data_len);"
au
L'état du parseur d'audit
data
Un tampon de données à fournir au parseur, d'une longueur de data_len octets. Les données sont copiées dans le parseur ; à son retour, l'appelant peut libérer ou réutiliser le tampon de données.
data_len
Le nombre d'octets dans data

DESCRIPTION

auparse_feed fournit de nouvelles données au parseur pour qu'il les consomme. auparse_init() doit avoir été appelé avec un type de source de AUSOURCE_FEED et un pointeur NULL.

Le parseur consomme autant de données que possible, invoquant une fonction de rappel fournie par l'utilisateur et spécifiée avec auparse_add_callback avec un type d'événement AUPARSE_CB_EVENT_READY chaque fois que le parseur reconnaît un événement complet dans le flux de données. Les données non entièrement analysées persisteront et seront préfixées aux données d'alimentation suivantes. Une fois toutes les données fournies au parseur, auparse_flush_feed doit être appelé pour signaler la fin des données d'entrée et vider toutes les données d'analyse en attente à travers le système d'analyse.

VALEUR DE RETOUR

Retourne -1 si une erreur se produit ; sinon, 0 en cas de succès.

EXEMPLE

void
auparse_callback(auparse_state_t *au, auparse_cb_event_t cb_event_type,
                 void *user_data)
{
    int *event_cnt = (int *)user_data;
    if (cb_event_type == AUPARSE_CB_EVENT_READY) {
        if (auparse_first_record(au) <= 0) return;
        printf("event: %d\n", *event_cnt);
        printf("records:%d\n", auparse_get_num_records(au));
        do {
            printf("fields:%d\n", auparse_get_num_fields(au));
            printf("type=%d ", auparse_get_type(au));
            const au_event_t *e = auparse_get_timestamp(au);
            if (e == NULL) return;
            printf("event time: %lu.%u:%lu\n",
                    (long unsigned)e->sec, e->milli, e->serial);
            auparse_first_field(au);
            do {
                printf("%s=%s (%s)\n", auparse_get_field_name(au),
                       auparse_get_field_str(au),
                       auparse_interpret_field(au));
            } while (auparse_next_field(au) > 0);
            printf("\n");
        } while(auparse_next_record(au) > 0);
        (*event_cnt)++;
    }
}
main(int argc, char **argv)
{
    char *filename = argv[1];
    FILE *fp;
    char buf[256];
    size_t len;
    int *event_cnt = malloc(sizeof(int));
    au = auparse_init(AUSOURCE_FEED, 0);
    auparse_set_eoe_timeout(2);
    *event_cnt = 1;
    auparse_add_callback(au, auparse_callback, event_cnt, free);
    if ((fp = fopen(filename, "r")) == NULL) {
        fprintf(stderr, "could not open '%s', %s\n", filename, strerror(errno));
        return 1;
    }
    while ((len = fread(buf, 1, sizeof(buf), fp))) {
        auparse_feed(au, buf, len);
    }
    auparse_flush_feed(au);
    auparse_destroy(au);
}
