AUDIT_GET_FEATURES(3) API d'audit Linux AUDIT_GET_FEATURES(3)

NOM

audit_get_features, audit_set_feature - interroger ou modifier les fonctionnalités d'audit du noyau

SYNOPSIS

#include <libaudit.h>

uint32_t audit_get_features(void);
int audit_set_feature(int fd, unsigned feature, unsigned value, unsigned lock);"

DESCRIPTION

audit_get_features() retourne une bitmap décrivant quelles fonctionnalités d'audit du noyau sont prises en charge. La bitmap est mise en cache interne et récupérée du noyau lors du premier appel.

audit_set_feature() modifie un bit de fonctionnalité pour le noyau en utilisant le descripteur fd qui doit être un socket netlink d'audit ouvert. feature sélectionne le bit à modifier. Si value est non nul, la fonctionnalité est activée, sinon elle est désactivée. Si lock est non nul, le réglage de la fonctionnalité est verrouillé jusqu'au redémarrage.

Les bits de fonctionnalité actuellement définis sont :

AUDIT_FEATURE_BITMAP_BACKLOG_LIMIT
Le noyau prend en charge la modification de la profondeur de la file d'attente de sauvegarde (backlog).
AUDIT_FEATURE_BITMAP_BACKLOG_WAIT_TIME
Le noyau prend en charge le délai des appels système lorsque la file d'attente est pleine.
AUDIT_FEATURE_BITMAP_EXECUTABLE_PATH
Le noyau inclura le chemin d'accès exécutable dans les enregistrements EXECVE.
AUDIT_FEATURE_BITMAP_EXCLUDE_EXTEND
Les règles d'exclusion peuvent être utilisées avec plus de champs que le seul type de message.
AUDIT_FEATURE_BITMAP_SESSIONID_FILTER
Le filtrage de l'identifiant de session est pris en charge.
AUDIT_FEATURE_BITMAP_LOST_RESET
Permet de réinitialiser le compteur d'événements perdus.
AUDIT_FEATURE_BITMAP_FILTER_FS
Le noyau prend en charge le filtrage des champs du système de fichiers.

VALEUR DE RETOUR

audit_get_features retourne la bitmap des fonctionnalités ou 0 si les requêtes de fonctionnalités ne sont pas prises en charge. audit_set_feature retourne <= 0 en cas d'erreur, sinon c'est l'identifiant de séquence netlink.

VOIR AUSSI

audit_request_features(3), audit_reset_lost(3), audit_open(3).
