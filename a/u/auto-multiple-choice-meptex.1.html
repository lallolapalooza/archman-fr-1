NOM

auto-multiple-choice-meptex - extrait les informations de mise en page du document de travail vers la base de données de mise en page

SYNTAXE

auto-multiple-choice meptex --src calage.xy --data répertoire

DESCRIPTION

La commande auto-multiple-choice meptex extrait les informations de mise en page (positions exactes des cases, des marques, du champ nom sur toutes les pages) d'un document de travail calage.xy et remplit la base de données de mise en page (un fichier SQLite) dans le répertoire de données répertoire.
