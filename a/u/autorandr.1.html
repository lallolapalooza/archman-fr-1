DESCRIPTIO

N

Ce programme détecte automatiquement le matériel d'affichage connecté puis charge une configuration X11 appropriée à l'aide de xrandr. Il prend également en charge l'utilisation de profils d'affichage pour différentes configurations

matérielles.

Autorandr inclut également plusieurs configurations virtuelles, notamment off, common, clone-largest, horizontal et vertical. Consultez la documentati

on pour une explic
ation de chacune.

FICHIER

S

Les fichiers de configuration sont recherchés dans le répertoire autorandr de la liste de chemins séparés par des deux-points dans $XDG_CONFIG_DIRS - ou dans /etc/xdg si cette variable n'est pas définie. Ils sont ensuite recherchés dans ~/.autorandr et si ce répertoire n'existe pas, dans $XDG_CONFIG_HOME/autorandr ou dans ~/.config/autorandr si cette variable n'est pas

définie.

Dans chacun de ces répertoires, il recherche des répertoires contenant config et setup. Il est préférable de gérer ces fichiers à l'aide de l'utilitaire autor

and
r.

OPTIONS PAR

DÉFAUT

Vous pouvez stocker des valeurs par défaut pour n'importe quelle option dans un fichier INI situé à ~/.config/autorandr/settings.ini. Dans une section de configuration, vous pouvez placer des valeurs par défaut sous la forme nom-option=argument-optio

n
.

SCRIPTS DE

RAPPEL

Quatre scripts supplémentaires peuvent être placés dans le répertoire de configuration

:
postswit
ch
Exécuté après qu'un changement de mode a eu lieu. Peut être utilisé pour notifier les gestionnaires de fenêtres ou d'autres applications du
changement.
preswit
ch
Exécuté avant qu'un changement de mode n'ait
lieu.
postsa
ve
Exécuté après qu'un profil a été enregistré ou
modifié.
predete
ct
Exécuté avant qu'a
utorandr n'essaie
d'exécuter xrandr.

Ces scripts doivent être exécutables et peuvent être placés directement dans le répertoire de configuration, où ils seront toujours exécutés, ou dans les sous-répertoires des profils, où ils ne seront exécutés que lors de changements concernant ce profil

spécifique.

À la place (ou en plus) de ces scripts, vous pouvez également placer autant de fichiers exécutables que vous le souhaitez dans des sous-répertoires nommés script_name.d (par exemple postswitch.d)

.

Une partie de l'état d'autorandr est exposée sous forme de variables d'environnement préfixées par AUTORANDR_, telles que : AUTORANDR_CURRENT_PROFILE, AUTORANDR_CURRENT_PROFILES, AUTORANDR_PROFILE_FOLDER et AUTORANDR_MONITORS, dans l'intention qu'elles puissent être utilisées dans les scripts de

rappel.

Le seul détail est que pendant preswitch, AUTORANDR_CURRENT_PROFILE renvoie le profi

l à venir plutôt
que le profil actuel.
