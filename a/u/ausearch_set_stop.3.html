AUSEARCH_SET_STOP(3) API d'audit Linux AUSEARCH_SET_STOP(3)

NOM


ausearch_set_stop - définir la position du curseur

SYNTAXE

#include <auparse.h>

int ausearch_set_stop(auparse_state_t *au,austop_t"où);"

DESCRIPTION

ausearch_set_stop détermine où le curseur interne s'arrêtera lorsqu'une condition de recherche est satisfaite. Les valeurs possibles sont :

AUSEARCH_STOP_EVENT
Celle-ci repositionne les curseurs sur le premier champ du premier enregistrement de l'événement contenant les éléments recherchés.
AUSEARCH_STOP_RECORD
Celle-ci repositionne les curseurs sur le premier champ de l'enregistrement contenant les éléments recherchés.
AUSEARCH_STOP_FIELD
Celle-ci s'arrête simplement sur le champ actuel lorsque l'évaluation des règles devient vraie.

VALEUR DE RETOUR

Retourne -1 en cas d'erreur ; sinon, 0 pour succès.

VOIR AUSSI

ausearch_add_item(3), ausearch_add_regex(3), ausearch_clear(3), ausearch_cur_event(3), ausearch_next_event(3).
