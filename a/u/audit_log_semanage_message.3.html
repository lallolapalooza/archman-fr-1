AUDIT_LOG_SEMANAGE_MESSAGE(3) API d'audit Linux AUDIT_LOG_SEMANAGE_MESSAGE(3)

NOM

audit_log_semanage_message - enregistrer un message semanage

SYNTAXE

#include <libaudit.h>

int audit_log_semanage_message(intaudit_fd,int"type,.Bconstchar*"pgname,constchar*"op,constchar*"name,unsignedint"id,.Bconstchar*"new_seuser,constchar*"new_role,constchar*"new_range,.Bconstchar*"old_seuser,constchar*"old_role,constchar*"old_range,.Bconstchar*"host,constchar*"addr,constchar*"tty,int"result);"

DESCRIPTION

Cette fonction enregistre un message dans le système d'audit en utilisant un format de message prédéfini. Elle doit être utilisée pour toutes les opérations de manipulation d'utilisateurs et de rôles SE Linux. Les paramètres de la fonction sont les suivants :

audit_fd - Le descripteur de fichier retourné par audit_open
type - type de message : AUDIT_ROLE_ASSIGN/REMOVE pour modifier des attributs d'utilisateur ou de rôle SE Linux.
pgname - nom du programme
op  -  opération. "adding-user", "adding-role", "deleting-user", "deleting-role"
name - compte utilisateur. Si non disponible, utiliser NULL.
id  -  uid sur lequel l'opération est effectuée. Ceci est utilisé uniquement lorsque name est NULL.
new_seuser - le nouvel utilisateur selinux que l'utilisateur de connexion obtient
new_role - le nouveau rôle que l'utilisateur de connexion obtient
new_range - la nouvelle plage mls que l'utilisateur de connexion obtient
old_seuser - l'ancien utilisateur selinux que l'utilisateur de connexion avait
old_role - l'ancien rôle que l'utilisateur de connexion avait
old_range - l'ancienne plage mls que l'utilisateur de connexion avait
host - Le nom d'hôte si connu
addr - L'adresse réseau de l'utilisateur
tty  - Le tty de l'utilisateur
result - 1 signifie "succès" et 0 signifie "échec"

VALEUR DE RETOUR

Elle retourne le numéro de séquence qui est > 0 en cas de succès ou <= 0 en cas d'erreur.

ERREURS

Cette fonction retourne -1 en cas d'échec. Examiner errno pour plus d'informations.

VOIR AUSSI
