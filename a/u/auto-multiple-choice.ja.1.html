AUTO-MULTIPLE-CHOI(1) Auto Multiple Choice AUTO-MULTIPLE-CHOI(1)

NOM

auto-multiple-choice - Traitement automatique des questionnaires à choix multiples

SYNOPIS

auto-multiple-choice action [arguments...]

auto-multiple-choice [projet]

DESCRIPTION

La commande auto-multiple-choice passe ses arguments à la commande AMC-action.pl.

Lorsqu'aucun action n'est spécifié, le mode graphique auto-multiple-choice gui est appelé (avec le nom du projet s'il est spécifié).

VOIR AUSSI

Les différentes actions d'AMC : auto-multiple-choice-prepare(1), auto-multiple-choice-imprime(1), auto-multiple-choice-analyse(1), auto-multiple-choice-note(1), auto-multiple-choice-association-auto(1), auto-multiple-choice-export(1), auto-multiple-choice-annotate(1), auto-multiple-choice-regroupe(1)
