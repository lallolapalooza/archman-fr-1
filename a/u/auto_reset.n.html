INTRODUCTIO

N

Tcl inclut une bibliothèque de procédures Tcl pour des fonctions couramment nécessaires. Les procédures définies dans la bibliothèque Tcl sont génériques et conviennent à de nombreuses applications différentes. L'emplacement de la bibliothèque Tcl est renvoyé par la commande info library. En plus de la bibliothèque Tcl, chaque application aura normalement sa propre bibliothèque de procédures de support ; l'emplacement de cette bibliothèque est normalement donné par la valeur de la $app_library variable globale, où app est le nom de l'application. Par exemple, l'emplacement de la bibliothèque Tk est conservé dans la variable tk_library

.

Pour accéder aux procédures de la bibliothèque Tcl, une application devrait charger le fichier init.tcl de la bibliothèque, par exemple avec la commande

Tcl

Détermine s'il existe un fichier exécutable ou une commande interne du shell portant le nom cmd. Si c'est le cas, il renvoie une liste d'arguments à passer à exec pour exécuter le fichier exécutable ou la commande interne du shell nommée par cmd. Sinon, il renvoie une chaîne vide. Cette commande examine les répertoires du chemin de recherche actuel (donné par la variable d'environnement PATH) lors de sa recherche d'un fichier exécutable nommé cmd. Sur les plateformes Windows, la recherche est étendue avec les mêmes répertoires et extensions de fichier que ceux utilisés par exec. Auto_execok se souvient des informations des recherches précédentes dans un tableau nommé auto_execs ; cela évite la recherche de chemin lors des appels ultérieurs pour la même cmd. auto_load cmd Cette commande tente de charger la définition d'une commande Tcl nommée cmd. Pour ce faire, elle recherche un chemin de chargement automatique, qui est une liste d'un ou plusieurs répertoires. Le chemin de chargement automatique est donné par la variable globale auto_path si elle existe. S'il n'y a pas de variable auto_path, alors la variable d'environnement TCLLIBPATH est utilisée, si elle existe. Sinon, le chemin de chargement automatique ne consiste qu'en le répertoire de la bibliothèque Tcl. Dans chaque répertoire du chemin de chargement automatique, il doit y avoir un fichier tclIndex qui décrit une ou plusieurs commandes définies dans ce répertoire et un script à évaluer pour charger chacune des commandes. Le fichier tclIndex devrait être généré avec la commande auto_mkindex. Si cmd est trouvé dans un fichier d'index, alors le script approprié est évalué pour créer la commande. La commande auto_load renvoie 1 si cmd a été créée avec succès. La commande renvoie 0 s'il n'y avait pas d'entrée d'index pour cmd ou si le script n'a pas réellement
