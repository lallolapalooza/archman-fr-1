AUDIT_SET_PID(3) API d'audit Linux AUDIT_SET_PID(3)

NOM

audit_set_pid - Définir l'identifiant du processus du démon d'audit

SYNTAXE

#include <libaudit.h>
int audit_set_pid(int fd, uint32_t pid, rep_wait_t wmode);"

DESCRIPTION

audit_set_pid informe le noyau de l'identifiant du processus (PID) du démon d'audit. L'argument fd est un descripteur ouvert vers le socket netlink d'audit. Lorsque pid est défini à 0, le noyau enregistre tous les événements dans syslog. Sinon, il essaiera d'envoyer les événements à la connexion netlink ayant le même pid que celui donné par cette fonction. Si, pour une raison quelconque, le processus disparaît, le noyau mettra automatiquement la valeur à 0 lui-même. Normalement, cette fonction est appelée par le démon d'audit et non par un programme externe. Si wmode est WAIT_YES, la fonction attendra un accusé de réception (ACK) du noyau.

VALEUR DE RETOUR

La valeur de retour est <= 0 en cas d'erreur, sinon c'est l'identifiant de séquence netlink. Cette fonction peut rencontrer les mêmes erreurs que sendto.

VOIR AUSSI

audit_open(3), auditd(8).
