AUTHVAR(1) Manuel des commandes générales AUTHVAR(1)

NOM

authvar — gère les variables authentifiées pour pesign

SYNTAXE

authvar ⟨-a | -c | -s⟩ -N {guid} -n nom ⟨-v valeur | -f fichier⟩ [-t temps] [-d répertoire] [-S surnom] [-i fichier] [-e fichier]

DESCRIPTION

authvar est un utilitaire en ligne de commande pour la gestion des variables UEFI authentifiées.

OPTIONS

-a | --append
Ajouter à la variable
-c | --clear
Effacer la variable
-s | --set
Définir la variable
-N ⟨{guid} | espace de noms⟩ | --namespace ⟨{guid} | espace de noms⟩
La variable est dans l'espace de noms ou {guid} (par défaut: global)

Utilisez -N help pour lister les espaces de noms.

-n nom | --name nom
Le nom de la variable
-v valeur | --value valeur
Définir ou ajouter la valeur à la variable
-f fichier | --valuefile fichier
Lire la valeur depuis le fichier
-t temps | --timestamp temps
Horodatage pour la variable (par défaut: maintenant)
-d répertoire | --certdir répertoire
Spécifier le répertoire de la base de données de certificats NSS répertoire (par défaut: /etc/pki/pesign)
-S surnom | --sign surnom
Signer la variable avec le certificat de surnom de la base de données NSS
-i fichier | --import fichier
Importer la variable depuis le fichier
-e fichier | --export fichier
Exporter la variable vers le fichier au lieu de la définir dans le firmware

NORMES

B. Kaliski, PKCS #7: Cryptographic Message Syntax v1.5, Internet Engineering Task Force, RFC 2315, https://tools.ietf.org/html/rfc2315 , Mars 1998.

K. Moriarty, M. Nyström, S. Parkinson, A. Rusch, et M. Scott, PKCS #12: Personal Information Exchange Syntax v1.1, Internet Engineering Task Force, RFC 7292, https://tools.ietf.org/html/rfc7292 , Juillet 2014.

PKCS11 Technical Committee, PKCS#11: Cryptographic Token Interface Standard, OASIS, https://www.cryptsoft.com/pkcs11doc/ .

UEFI Specification Working Group, Unified Extensible Firmware Interface (UEFI) Specification Version 2.8, Unified Extensible Firmware Interface Forum, https://uefi.org/specifications , Mars 2019.
