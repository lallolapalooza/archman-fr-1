AUDITD.CRON(5) Utilitaires d'administration système AUDITD.CRON(5)

NOM

auditd.conf - rotation des journaux d'audit basée sur le temps

DESCRIPTION

Par défaut, le démon d'audit (auditd) prend en charge la rotation des journaux basée sur la taille, où les journaux sont pivotés une fois qu'ils atteignent une taille spécifiée, comme configuré dans /etc/audit/auditd.conf. Ce manuel décrit une méthode alternative : la rotation des journaux basée sur le temps à l'aide de cron. En utilisant cette approche, les journaux d'audit peuvent être pivotés à des intervalles spécifiés (horaires, quotidiens, hebdomadaires ou à une date personnalisée), quelle que soit leur taille.

CONFIGURATION

1. Désactiver la rotation basée sur la taille :

Pour activer la rotation des journaux basée sur le temps, désactivez d'abord la rotation intégrée basée sur la taille d'auditd en définissant le paramètre suivant dans /etc/audit/auditd.conf:

max_log_file_action = ignore

2. Configurer la rétention des journaux :

Le paramètre num_logs détermine le nombre de fichiers journaux pivotés à conserver. Pour une rotation quotidienne, la définition de

num_logs = 7

garantit que les journaux des sept derniers jours sont conservés. Cependant, sur les systèmes très actifs, les journaux d'audit peuvent croître rapidement, entraînant potentiellement un manque d'espace disque. Pour éviter cela, assurez-vous que le paramètre space_left_action est configuré pour gérer correctement les situations de manque d'espace disque.

3. Appliquer les modifications de configuration :

Après avoir modifié le fichier de configuration principal d'auditd, rechargez auditd pour appliquer les modifications :

auditctl --signal reload

4. Déployer le script de rotation :

Copiez le script auditd.cron fourni dans le répertoire cron approprié ( cron.daily ou cron.hourly ou cron.weekly , selon votre préférence de rotation). Ensuite, assurez-vous que le fichier possède les bonnes étiquettes SELinux :

cp /usr/share/doc/audit/auditd.cron /etc/cron.daily

VOIR AUSSI

auditd.conf(5), auditd(8), cron(8).
