NOM

auto-multiple-choice-analyse - capture automatique de données à partir de scans pour les examens à choix multiples AMC.

SYNOPSIS

auto-multiple-choice analyse --projet répertoire-projet [--seuil-coche seuil] [--tol-marque tol] [--list-fichiers liste-fichiers.txt | fichiers-scan...]

DESCRIPTION

La commande auto-multiple-choice analyse effectue la capture automatique de données à partir de scans de feuilles de réponses complétées d'un questionnaire à choix multiples AMC. Avant d'appeler auto-multiple-choice analyse, la commande auto-multiple-choice-prepare(1) devrait avoir été appelée pour créer les documents de travail (--mode s) et la mise en page devrait avoir été traitée avec auto-multiple-choice-meptex(1).

--data répertoire-données

spécifie le répertoire où se trouvent les fichiers de données (voir par exemple auto-multiple-choice-meptex(1)). Par défaut, il prend la valeur de répertoire-projet/data.

--cr répertoire-cr-projet

spécifie un répertoire où créer des rapports d'images de la capture de données (zooms sur les cases dans un sous-répertoire zooms, extraction du nom du fichier sous forme de fichier name-*.jpg, et rapport de mise en page sous forme de fichier page-*.jpg).

--projet répertoire-projet

Lorsque cette option est utilisée, si --cr n'est pas utilisé, répertoire-cr-projet sera défini sur répertoire-projet/cr.

Les noms des fichiers de scan à traiter peuvent être donnés de deux manières :

•ces noms peuvent être donnés en arguments,
•ces noms peuvent être écrits dans un fichier texte brut (un nom de fichier par ligne), en utilisant l'option --list-fichiers liste-fichiers.txt pour spécifier le nom de ce fichier.

Certains paramètres pour la capture de données peuvent être définis en utilisant les options suivantes :

--prop proportion

définit la proportion de chaque case qui sera mesurée pour décider si la case est cochée ou non. La valeur par défaut est 0.8.

--bw-threshold seuil

Ce paramètre est utilisé lors de la conversion du fichier de scan en niveaux de gris en noir et blanc. Pour obtenir plus de pixels noirs, utilisez une valeur plus grande. Pour obtenir plus de pixels blancs, utilisez une valeur plus petite. Le seuil doit être compris entre 0 et 1. La valeur par défaut est 0.6.

--ignore-red

Avec cette option, seul le canal rouge sera utilisé à partir des scans en couleur. Ainsi, tout ce qui est écrit en rouge sera ignoré dans le scan. Cela peut être utile lorsque les cases sont imprimées en rouge.

--tol-marque tol

définit la tolérance lors de la détection des quatre marques dans les coins des scans. Ces marques sont détectées en recherchant des composantes connexes noires dont les dimensions sont proches des dimensions cibles cible (dimensions exactes des marques si le processus d'impression/scan était parfaitement précis). Si tol est un nombre réel, les dimensions acceptées sont celles comprises entre (1-tol)*cible et (1+tol)*cible. Si tol est "tinf,tsup" (où tinf et tsup sont des nombres réels), les dimensions acceptées sont celles comprises entre (1-tinf)*cible et (1+tsup)*cible. Une valeur standard est 0.2.

--multiple

Cette option est à utiliser lorsque les scans sont des photocopies de certains sujets (différents étudiants peuvent avoir le même sujet). Dans ce cas, des numéros de copie sont attribués aux étudiants afin que leurs feuilles de réponses, avec le même numéro de sujet, puissent être différenciées.

--pre-allocate id_copie

Cette option peut être utilisée conjointement avec --multiple. Les numéros de copie utilisés pour les scans commenceront à partir de id_copie, dans le même ordre que les scans donnés en arguments.

--try-three | --no-try-three

Utilisez l'une de ces options pour indiquer si le traitement des scans avec seulement trois marques d'angle est autorisé.

--debug fichier.log

spécifie un fichier à remplir avec des informations de débogage.
