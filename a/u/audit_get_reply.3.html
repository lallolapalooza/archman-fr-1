AUDIT_GET_REPLY(3) API du noyau d'audit Linux AUDIT_GET_REPLY(3)

NOM

audit_get_reply - Récupérer la réponse du système d'audit

SYNOPSIS

#include <libaudit.h>
int audit_get_reply(int fd, struct audit_reply *rep, reply_t block, int peek);"

DESCRIPTION

Cette fonction récupère le prochain paquet de données envoyé sur le socket netlink d'audit. Cette fonction est généralement appelée après l'envoi d'une commande au système d'audit. fd doit être un descripteur de fichier ouvert retourné par audit_open. rep doit être une structure de données pour stocker la réponse. block est de type reply_t qui peut être soit : GET_REPLY_BLOCKING, soit GET_REPLY_NONBLOCKING. peek, s'il est différent de zéro, récupère les données sans les retirer du socket netlink.

VALEUR DE RETOUR

Cette fonction retourne -errno en cas d'erreur, 0 si une réponse d'erreur est reçue, et une valeur positive en cas de succès.

VOIR AUSSI

audit_open(3).
