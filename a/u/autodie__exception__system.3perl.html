NOM

autodie::exception::system - Exceptions pour la mort automatique de system().

SYNTAXE

eval {
    use autodie qw(system);
    system($cmd, @args);
};
if (my $E = $@) {
    say "Oups ! ",$E->caller," a eu des problèmes : $@";
}

DESCRIPTION

Ceci est une classe d'exception autodie::exception pour les échecs de la commande "system".

Actuellement, il n'y a aucun moyen d'interroger un objet "autodie::exception::system" pour connaître la commande, le code de retour et d'autres informations que l'on s'attend à ce qu'un tel objet contienne. L'interface sera étendue pour tenir compte de cela à l'avenir.

chaine

Lorsqu'ils sont convertis en chaîne de caractères, les objets "autodie::exception::system" utilisent actuellement le message généré par IPC::System::Simple.
