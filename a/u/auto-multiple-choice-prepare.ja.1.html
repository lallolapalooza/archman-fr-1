NOM

auto-multiple-choice-prepare - Crée des documents à partir d'un fichier source LaTeX.

SYNOPSIS

auto-multiple-choice prepare --mode s --prefix rep-projet fichier-source-qcm

auto-multiple-choice prepare --mode b --data rep-donnees-projet fichier-source-qcm

DESCRIPTION

La commande auto-multiple-choice prepare génère des documents à partir d'un fichier source décrivant un questionnaire à choix multiples. Les informations extraites dépendent de la valeur de l'option --mode. Dans les deux modes, le nom du fichier source est obligatoire.

• Avec --mode s, auto-multiple-choice prepare crée un fichier de sujet d'examen (papier à distribuer aux candidats), un fichier de corrigé (papier avec les réponses correctes marquées) et un fichier d'alignement (fichier contenant des informations sur la position des cases sur le papier). Les options suivantes peuvent être utilisées :

--out-sujet sujet.pdf

Définit le nom du fichier sujet créé.

--out-corrige corrige.pdf

Définit le nom du fichier corrigé créé.

--out-calage calage.xy

Définit le nom du fichier d'alignement créé.

--prefix repertoire

Quand l'un des trois options ci-dessus n'est pas utilisé, ce répertoire devient obligatoire. Les valeurs par défaut seront alors repertoire/sujet.pdf, repertoire/corrige.pdf et repertoire/calage.xy.
• Avec --mode b, auto-multiple-choice prepare extrait des bases de données de correction à partir du fichier source. Dans ce mode, l'option --data (voir ci-dessous) est obligatoire.

Les options suivantes sont utilisables dans les deux modes :

--with moteur-latex

Spécifie le moteur LaTeX (commande) à utiliser. moteur-latex est par exemple pdflatex ou xelatex.

--filter filtre

Spécifie le nom du filtre qui transforme le fichier source QCM en un fichier LaTeX. Les filtres intégrés sont latex (aucune transformation) et plain (source AMC-TXT).

--filtered-source fichier-latex-qcm

Spécifie le nom du fichier LaTeX à créer à partir du fichier source avec le filtre désigné. S'il est omis, le nom de fichier sera dérivé du nom du fichier source en y ajoutant _filtered.tex.

--n-copies n

Spécifie le nombre d'exemplaires du sujet d'examen à générer, et le nombre de copies à surcharger dans le fichier source (premier argument de \onecopy).

--debug fichier.log

Spécifie le fichier dans lequel les informations de débogage seront enregistrées.

--epoch EPOCH

Spécifie une date (secondes écoulées depuis le 1er Janvier 1970) pour que la génération du PDF produise toujours le même résultat.

--data rep-donnees-projet

Spécifie le répertoire où stocker les fichiers de données SQLite.
