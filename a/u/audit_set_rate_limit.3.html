AUDIT_SET_RATE_LIMIT(3) API d'audit Linux AUDIT_SET_RATE_LIMIT(3)

NOM

audit_set_rate_limit - Définir la limite de débit d'audit

SYNTAXE

#include <libaudit.h>
int audit_set_rate_limit(int fd, uint32_t limit);"

DESCRIPTION

audit_set_rate_limit définira le nombre maximum de messages que le noyau enverra par seconde. Ceci peut être utilisé pour limiter le débit si les systèmes deviennent non réactifs. Bien sûr, le compromis est que des événements seront perdus. L'argument limit contrôle combien de messages peuvent être envoyés chaque seconde. La valeur par défaut est 0, ce qui signifie aucune limite.

VALEUR DE RETOUR

La valeur de retour est <= 0 en cas d'erreur, sinon c'est le numéro de séquence netlink. Cette fonction peut avoir n'importe quelle erreur que sendto pourrait rencontrer.

VOIR AUSSI

audit_open(3), auditd(8).
