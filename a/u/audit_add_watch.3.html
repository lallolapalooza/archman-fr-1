AUDIT_ADD_WATCH(3) API d'audit Linux AUDIT_ADD_WATCH(3)

NOM

audit_add_watch - créer une structure de règle pour une surveillance

SYNTAXE

#include <libaudit.h>
int audit_add_watch(struct audit_rule_data **rulep, const char *path);

DESCRIPTION

audit_add_watch créera une règle de surveillance dans le pointeur vers un pointeur rulep. Tout ce que vous avez besoin de lui passer est le path complet vers un fichier et il initialisera la structure audit_rule_data pour une surveillance.

VALEUR DE RETOUR

Retourne -1 en cas d'erreur ; sinon, 0 pour succès.

VOIR AUSSI

audit_add_rule_data(3), audit_delete_rule_data(3).
