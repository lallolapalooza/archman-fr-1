Authen::SASL::Perl::EXTERNAL(3) Documentation Perl fournie par l'utilisateur Authen::SASL::Perl::EXTERNAL(3)

NOM

Authen::SASL::Perl::EXTERNAL - Classe d'authentification externe

VERSION

version 2.1900

SYNTAXE

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'EXTERNAL',
  callback  => {
    user => $user
  },
);

DESCRIPTION

Cette méthode implémente la partie cliente de l'algorithme SASL EXTERNAL, tel que décrit dans la RFC 2222.

RAPPEL

Les rappels utilisés sont :

utilisateur
Le nom d'utilisateur à utiliser pour l'authentification

VOIR AUSSI

Authen::SASL, Authen::SASL::Perl
