NOM

aurpublish - Cadre de gestion de PKGBUILD pour l'Arch User Repository

SYNTAXE

aurpublish [options] PAQUET

aurpublish log [<options>] PAQUET

aurpublish setup

DESCRIPTION

Aurpublish est un utilitaire qui aide les mainteneurs de paquets AUR à soumettre des mises à jour.

COMMENT ÇA MARCHE

Commitez les PKGBUILD dans des sous-répertoires nommés. Exportez-les vers l'AUR avec la commande aurpublish, en utilisant la stratégie de push de sous-arbre. Cela préserve un historique indépendant pour l'hébergement tiers, les pull requests... ;)

COMMANDES

setup

Initialise un nouveau dépôt avec des hooks git.

log <PAQUET>

Affiche le log git d'un sous-arbre de paquet.

OPTIONS

-p <PAQUET>

Au lieu de publier, récupère les changements depuis l'AUR. Peut importer des paquets dans un nouveau sous-arbre.

-s, --speedup <PAQUET>

Accélère les futures publications en enregistrant l'historique du sous-arbre lors d'un push. Cela crée un commit de fusion et une copie secondaire de tous les commits du sous-arbre. Pour plus de détails, voir l'option "--rejoin" dans git-subtree(1).

-u, --url <URL>

Spécifie l'URL du serveur à utiliser pour les opérations git.

-h, --help

Affiche une page d'utilisation.

HOOKS

pre-commit

Avertit des erreurs d'espacement, échoue si les sommes de contrôle ne correspondent pas, et génère automatiquement le .SRCINFO pour tous les PKGBUILD modifiés.

prepare-commit-msg

Pré-remplit le message de commit avec une liste des paquets ajoutés/mis à jour/supprimés + versions (si applicable).

SPÉCIFICATION DE L'URL DU SERVEUR AUR

Vous pouvez utiliser aurpublish pour interagir avec un serveur git autre que le serveur git AUR par défaut (aur.archlinux.org). Cela peut être utile si vous exécutez votre propre serveur AUR.

L'URL du serveur git distant peut être configurée de deux manières. Vous pouvez définir l'URL avec les options -u/--url lors de l'exécution d'aurpublish. Ou vous pouvez configurer le serveur de manière persistante dans git en définissant l'option aurpublish.remoteUrl.

Définir l'URL avec --url

aurpublish --url ssh://moi@example.com monpaquet

Définir l'URL pour le répertoire git actuel avec git config

git config aurpublish.remoteUrl ssh://moi@example.com

Définir l'URL globalement avec git config

git config --global aurpublish.remoteUrl ssh://moi@example.com

Pour plus de détails sur les options git, voir git-config(1).

EXEMPLES

aurpublish setup

Initialise un nouveau dépôt avec des hooks git. Voir la section Hooks pour plus d'informations.

aurpublish -p ansible-core-git

Clone un paquet existant depuis l'AUR et ajoute son URL comme sous-arbre git au dépôt git actuellement existant.

aurpublish ansible-core-git

Pousse un sous-arbre existant vers l'AUR.

aurpublish log

Affiche le log git d'un sous-arbre de paquet.

aurpublish --url ssh://moi@example.com ansible-core-git

Pousse le sous-arbre vers un serveur à ssh://example.com.
