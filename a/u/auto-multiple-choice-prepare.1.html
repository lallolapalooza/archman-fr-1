NAME

auto-multiple-choice-prepare - prépare les documents de travail à partir d'un fichier source LaTeX

SYNOPSIS

auto-multiple-choice prepare --mode s --prefix répertoire-projet fichier-source-qcm

auto-multiple-choice prepare --mode b --data répertoire-données-projet fichier-source-qcm

DESCRIPTION

La commande auto-multiple-choice prepare extrait les documents de travail à partir du fichier source décrivant le questionnaire à choix multiples. Les informations à extraire dépendent de l'argument --mode. Dans tous les modes, le nom du fichier source doit être donné en argument.

•Avec l'option "--mode s", auto-multiple-choice prepare crée le fichier sujet (feuille de réponse à imprimer et à distribuer aux étudiants), la correction (feuille de réponse corrigée unique) et le fichier de positionnement (fichier contenant les informations sur les positions des cases dans les pages). Les arguments suivants peuvent être utilisés :

--out-sujet sujet.pdf

définit le fichier sujet à construire.

--out-corrige corrige.pdf

définit la correction à construire.

--out-calage calage.xy

définit le fichier de positionnement à construire.

--prefix répertoire

ce répertoire n'est nécessaire que si une ou plusieurs des trois options précédentes ne sont pas utilisées : les valeurs par défaut sont alors répertoire/sujet.pdf, répertoire/corrige.pdf et répertoire/calage.xy.
•Avec l'option "--mode b", auto-multiple-choice prepare extrait les données de notation du fichier source. Dans ce mode, l'argument --data doit être utilisé (voir ci-dessous).

Les arguments optionnels suivants peuvent être utilisés dans n'importe quel mode :

--with moteur-latex

donne le moteur LaTeX (commande) à utiliser. moteur-latex peut être pdflatex ou xelatex par exemple.

--filter filtre

définit le nom du filtre pour transformer le fichier source QCM en un fichier LaTeX. Les filtres natifs sont latex (aucun changement) et plain (source est un fichier AMC-TXT).

--filtered-source fichier-latex-qcm

donne le fichier LaTeX à créer à partir du fichier source en utilisant le filtre spécifié. S'il est omis, un nom de fichier dérivé de fichier-source-qcm en ajoutant _filtered.tex est utilisé.

--n-copies n

définit le nombre de copies à produire, remplaçant le nombre donné dans le fichier source LaTeX (premier argument de la commande \onecopy).

--debug fichier.log

donne un fichier à remplir avec des informations de débogage.

--epoch EPOCH

donne une époque (nombre de secondes depuis le 1er janvier 1970) pour obtenir une sortie PDF reproductible.

--data répertoire-données-projet

définit le répertoire où se trouvent les fichiers de données SQLite du projet.
