AUTOHEADER(1) Commandes utilisateur AUTOHEADER(1)

NOM

autoheader — Crée un modèle d'en-tête pour configure

SYNTAXE

autoheader [OPTION]... [FICHIER-MODELE]

DESCRIPTION

Crée un fichier modèle d'instructions C '#define' que 'configure' pourra utiliser. Pour ce faire, analyse le FICHIER-MODELE, ou 'configure.ac' s'il est présent, sinon 'configure.in'.

-h, --help
affiche cette aide, puis quitte
-V, --version
affiche le numéro de version, puis quitte
-v, --verbose
rapport détaillé du traitement
-d, --debug
ne supprime pas les fichiers temporaires
-f, --force
considère tous les fichiers comme obsolètes
-W, --warnings=CATEGORIE
rapporte les avertissements appartenant à CATEGORIE (liste séparée par des virgules acceptée)

Les catégories d’avertissement sont :

cross
problèmes de compilation croisée
gnu
normes de codage GNU (par défaut en modes gnu et gnits)
obsolete
fonctionnalités ou constructions obsolètes (par défaut)
override
redéfinitions par l'utilisateur de règles ou de variables Automake
portability
problèmes de portabilité (par défaut en modes gnu et gnits)
portability-recursive
variables Make imbriquées (par défaut avec -Wportability)
extra-portability
problèmes de portabilité supplémentaires liés à des outils obscurs
syntax
constructions syntaxiques douteuses (par défaut)
unsupported
fonctionnalités non supportées ou incomplètes (par défaut)

-W comprend également :

all
active tous les avertissements
none
désactive tous les avertissements
no-CATEGORIE
désactive les avertissements dans CATEGORIE
error
traite tous les avertissements activés comme des erreurs

Répertoires de bibliothèques :

-B, --prepend-include=RÉPERTOIRE
ajoute le répertoire RÉPERTOIRE au début du chemin de recherche
-I, --include=RÉPERTOIRE
ajoute le répertoire RÉPERTOIRE à la fin du chemin de recherche
