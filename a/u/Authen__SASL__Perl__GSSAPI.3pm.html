Authen::SASL::Perl::GSSAPI(3) Documentation Perl fournie par l'utilisateur Authen::SASL::Perl::GSSAPI(3)

NOM

Authen::SASL::Perl::GSSAPI - Classe d'authentification GSSAPI (Kerberosv5)

VERSION

version 2.1900

SYNOPSIS

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new( mechanism => 'GSSAPI' );
$sasl = Authen::SASL->new( mechanism => 'GSSAPI',
                           callback => { pass => $mycred });
$sasl->client_start( $service, $host );

DESCRIPTION

Cette méthode implémente la partie client de l'algorithme SASL GSSAPI, tel que décrit dans la RFC 2222 section 7.2.1 resp. draft-ietf-sasl-gssapi-XX.txt.

Avec un cache de crédentials Kerberos 5 valide (aussi appelé TGT) elle permet de se connecter à service@host donnés comme deux premiers paramètres à la méthode client_start() d'Authen::SASL. Alternativement, un objet GSSAPI::Cred peut être passé via le hash de rappel d'Authen::SASL en utilisant la clé `pass'.

Veuillez noter que ce module n'implémente actuellement pas de couche de sécurité SASL après authentification. À moins que la connexion ne soit protégée par d'autres moyens, comme TLS, elle sera vulnérable aux attaques de type homme du milieu. Si des couches de sécurité sont requises, alors le module Authen::SASL::XS GSSAPI devrait être utilisé à la place.

CALLBACK

Les rappels utilisés sont :

authname
L'identité d'autorisation à utiliser dans l'échange SASL
gssmech
Le mécanisme GSS à utiliser dans la connexion
pass
Les crédentials GSS à utiliser dans la connexion (optionnel)

EXEMPLE

 #! /usr/bin/perl -w
 use strict;
use warnings;
 use Net::LDAP 0.33;
 use Authen::SASL 2.10;
 # -------- Ajuster à votre environnement --------
 my $adhost      = 'theserver.bla.net';
 my $ldap_base   = 'dc=bla,dc=net';
 my $ldap_filter = '(&(sAMAccountName=BLAAGROL))';
 my $sasl = Authen::SASL->new(mechanism => 'GSSAPI');
 my $ldap;
 eval {
     $ldap = Net::LDAP->new($adhost,
                            onerror => 'die')
       or  die "Impossible de se connecter à l'hôte LDAP '$adhost': '$@'";
     $ldap->bind(sasl => $sasl);
 };
 if ($@) {
     chomp $@;
     die   "\nErreur Bind       : $@",
           "\nErreur SASL détaillée: ", $sasl->error,
           "\nTerminé";
 }
 print "\nLDAP bind() réussi, fonctionnement dans un état authentifié";
 my $mesg = $ldap->search(base   => $ldap_base,
                          filter => $ldap_filter);
 # -------- évaluer $mesg

PROPRIETES

Les propriétés utilisées sont :

maxbuf
La taille maximale du tampon pour la réception du texte chiffré
minssf
La valeur minimale SSF qui devrait être fournie par la couche de sécurité SASL. La valeur par défaut est 0
maxssf
La valeur maximale SSF qui devrait être fournie par la couche de sécurité SASL. La valeur par défaut est 2**31
externalssf
La valeur SSF fournie par une couche de sécurité externe sous-jacente. La valeur par défaut est 0
ssf
La valeur SSF réelle fournie par la couche de sécurité SASL après que la phase d'authentification SASL soit terminée. Cette valeur est en lecture seule et définie par l'implémentation après la fin de la phase d'authentification SASL.
maxout
La taille maximale du tampon de texte clair pour l'envoi de données à l'interlocuteur. Cette valeur est définie par l'implémentation après que la phase d'authentification SASL soit terminée et qu'une couche de sécurité SASL soit en vigueur.
