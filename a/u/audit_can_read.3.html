AUDIT_CAN_CONTROL(3) API d'Audit Linux AUDIT_CAN_CONTROL(3)

NOM

audit_can_control, audit_can_write, audit_can_read - tester les capacités liées à l'audit

SYNTAXE

#include <libaudit.h>

int audit_can_control(void);
int audit_can_write(void);
int audit_can_read(void);

DESCRIPTION

audit_can_control() retourne 1 si le processus appelant possède la capacité CAP_AUDIT_CONTROL, sinon 0. audit_can_write() retourne 1 si CAP_AUDIT_WRITE est disponible. audit_can_read() retourne 1 si CAP_AUDIT_READ est présent. Lorsque le support libcap-ng n'est pas disponible, ces fonctions retournent 1 uniquement lorsque l'UID effectif est 0.

VALEUR DE RETOUR

Ces fonctions retournent 1 lorsque la capacité est présente et 0 sinon.

VOIR AUSSI

audit_open(3).
