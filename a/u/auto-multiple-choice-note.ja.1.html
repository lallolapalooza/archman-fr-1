DESCRIP

TION

La commande auto-multiple-choice note calcule les notes de chaque copie à partir des critères d'évaluation extraits des fichiers source LaTeX parauto-multiple-choice-prepare(1) et des données de reconnaissance de marques créées parauto-multiple-choice-analyse(1)

.

--data project-data-di

r
Spécifie le répertoire contenant les fichiers de données (voirauto-multiple-choice-meptex(1) par exemple)
.

--seuil threshol

d
Spécifie le seuil du ratio de pixels noirs pour déterminer si une case est cochée. Lors de la détermination du statut d'une case,auto-multiple-choice note compare le ratio de pixels noirs (proportion de pixels noirs par rapport au nombre total de pixels) àthreshold (le seuil). Si le ratio de pixels noirs est supérieur àthreshold, la case est déclarée cochée. La valeur standard est généralement de 0.15 pour la disposition standard et d'environ 0.5 pour la disposition de copie séparée (où une lettre est inscrite dans la case et les étudiants sont invités à remplir complètement la case)
.

--seuil-up upper_threshol

d
Spécifie le seuil supérieur au-delà duquel une case est considérée comme non cochée si le ratio de pixels noirs le dépasse. En définissant cette valeur à (par exemple) 0.6, un étudiant peut annuler un marqueur en remplissant complètement la case. Ainsi, si le ratio de pixels noirs est compris entrethreshold etupper_threshold, la case est considérée comme cochée, et si elle dépasseupper_threshold (en étant complètement remplie), elle est considérée comme non cochée. La valeur par défaut est 1.0, ce qui rend cette fonctionnalité
inactive.

--grain granularity --arrondi roundin

g
Arrondit les notes pour qu'elles soient des multiples degranularity.Si rounding est « i », les notes sont tronquées (comme le feraitfloor(3)).Si rounding est « n », les notes sont arrondies au plus proche.Si rounding est « s », les notes sont arrondies vers le haut (comme le feraitceil(3)). Par exemple, avec l'option «--grain 0.25 --arrondi s », une note de 6.285 est arrondie à 6.
5.

--notemin mi

n
Avec cette option, toutes les notes inférieures àmin sont remplacées parmin
.

--notemax ma

x
Spécifie la note maximale attribuée à une copie entièrement correcte. Sans cette option, les notes restent des notes
brutes.

--plafon

d
Avec cette option, toutes les notes supérieures àmax sont remplacées parmax
.

--debug file.

log
Spécifie le fichier dans lequel enregistrer les informations de
débogage.

--postcorrect-student s --postcorrect-copy

c
Indique l'utilisation d'une copie spécifiée par le numéro d'étudiant et le numéro de copie p
our la correction postérieure. En mode de correction postérieure, les réponses correctes so
nt extraites non pas du fichier source LaTeX, mais des réponses spécifiées dans cette copie.
