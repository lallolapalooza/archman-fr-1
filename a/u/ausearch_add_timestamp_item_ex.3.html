ausearch_add_timestamp_item_ex(3)

AUSEARCH_ADD_TIMESTAMP_ITEM_EX(3) API d'audit Linux AUSEARCH_ADD_TIMESTAMP_ITEM_EX(3)

NOM

ausearch_add_timestamp_item_ex - construire une règle de recherche

SYNTAXE

#include <auparse.h>

int ausearch_add_timestamp_item_ex(auparse_state_t *au,constchar*op,time_tsec,unsignedmilli,unsignedserial,ausearch_rule_thow);

DESCRIPTION

ausearch_add_timestamp_item_ex ajoute une condition temporelle d'événement à l'expression de recherche d'audit actuelle. Les conditions de recherche peuvent ensuite être utilisées pour scanner les journaux, les fichiers ou les tampons à la recherche de quelque chose d'intéressant. Le paramètre op spécifie la comparaison souhaitée. Les valeurs légales pour op sont <, <=, >=, > et =. L'opérande de gauche de l'opérateur de comparaison est l'horodatage de l'événement examiné, l'opérande de droite est spécifié par les paramètres sec, milli et serial.

La valeur how détermine comment cette condition de recherche affectera l'expression de recherche existante si une est déjà définie. Les valeurs possibles sont :

AUSEARCH_RULE_CLEAR
Efface l'expression de recherche actuelle, le cas échéant, et utilise uniquement cette condition de recherche.
AUSEARCH_RULE_OR
Si une expression de recherche E est déjà configurée, remplacez-la par (E || cette_condition_de_recherche).
AUSEARCH_RULE_AND
Si une expression de recherche E est déjà configurée, remplacez-la par (E && cette_condition_de_recherche).

VALEUR DE RETOUR

Retourne -1 en cas d'erreur ; sinon, 0 en cas de succès.

USAGE APPLICATIF

Utilisez ausearch_add_item(3) et ausearch_add_interpreted_item(3) pour ajouter des conditions qui vérifient les champs des enregistrements d'audit. Utilisez ausearch_add_expression(3) pour ajouter des expressions de recherche complexes en un seul appel de fonction.

VOIR AUSSI
