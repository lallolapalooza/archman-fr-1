AUDIT_REQUEST_SIGNAL_INFO(3) API d'audit Linux AUDIT_REQUEST_SIGNAL_INFO(3)

NOM

audit_request_signal_info - Demande d'informations de signal pour le système d'audit

SYNTAXE

#include <libaudit.h>

int audit_request_signal_info(intfd);"

DESCRIPTION

audit_request_signal_info demande au noyau d'envoyer des informations sur l'expéditeur d'un signal au démon d'audit. La structure d'informations de signal est la suivante :

struct audit_sig_info {
        uid_t           uid;
        pid_t           pid;
        char            ctx[0];
};

Cette fonction est susceptible d'être utilisée uniquement par les démons d'audit et ne doit pas être appelée par un autre type de programme.

VALEUR DE RETOUR

La valeur de retour est <= 0 en cas d'erreur, sinon c'est le numéro de séquence netlink. Cette fonction peut rencontrer n'importe quelle erreur que sendto pourrait rencontrer.

VOIR AUSSI

audit_open(3), audit_get_reply(3).
