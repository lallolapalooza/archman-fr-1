AUGPARSE(1) Augeas AUGPARSE(1)

NOM

augparse - exécute un module Augeas

SYNTAXE

augparse [OPTIONS] MODULE

DESCRIPTION

Exécute un module Augeas, le plus souvent pour évaluer les tests qu'il contient.

OPTIONS

-I, --include=DIR
Ajoute DIR au chemin de chargement des modules. Peut être donné plusieurs fois. Les répertoires définis ici sont recherchés avant tout répertoire spécifié dans la variable d'environnement AUGEAS_LENS_LIB, et avant le répertoire par défaut /usr/share/augeas/lenses.
-t, --trace
Affiche une trace des modules en cours de chargement.
--nostdinc
Ne recherche aucun des répertoires par défaut pour les modules. Lorsque cette option est définie, seuls les répertoires spécifiés explicitement avec -I ou spécifiés dans AUGEAS_LENS_LIB seront recherchés pour les modules.
--notypecheck
N'effectue pas de vérifications de type de lentilles. Utilisez cette option uniquement pendant le développement de lentilles et assurez-vous de vérifier les types des lentilles une fois que vous avez terminé le développement - vous ne devriez jamais utiliser une lentille qui n'a pas été vérifiée. Cette option est parfois utile lorsque vous travaillez sur des tests unitaires pour une lentille afin d'accélérer le temps nécessaire pour exécuter et corriger les tests de manière répétée.
--version
Affiche les informations de version et quitte.
-h
Affiche cette aide et quitte

EXEMPLES

Pour exécuter les tests dans lenses/tests/test_foo.aug et utiliser des modules du répertoire lenses, exécutez

augparse -I lenses lenses/tests/test_foo.aug

TESTS

Les tests peuvent apparaître comme des formes de niveau supérieur n'importe où dans un module. Généralement, les tests pour un module lenses/foo.aug sont conservés dans un fichier séparé, généralement dans lenses/tests/test_foo.aug.

Il existe deux types de tests qu'Augeas peut exécuter : les tests get et put. La syntaxe pour les tests get est

test LENS get STRING = RESULT

qui applique la direction get de la lentille LENS à STRING et la compare avec le RESULTAT donné. RESULTAT peut être un littéral d'arbre, le symbole ? pour afficher le résultat de l'application de LENS à STRING, ou le symbole * pour indiquer que le test doit produire une exception.

La syntaxe pour les tests put est

test LENS put STRING after COMMANDS = RESULT

qui applique d'abord la direction get de la lentille LENS à STRING, puis applique les COMMANDES données à l'arbre résultant, et enfin transforme l'arbre modifié en une chaîne à l'aide de la direction put de LENS. La chaîne résultante est ensuite comparée à RESULTAT, qui peut être une chaîne, le symbole ? pour afficher le résultat de l'application de LENS à STRING, ou le symbole * pour indiquer que le test doit produire une exception.
