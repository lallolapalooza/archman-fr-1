AUPARSE_INTERPRET_FIELD(3) API d'audit Linux AUPARSE_INTERPRET_FIELD(3)

NOM

auparse_interpret_field, auparse_interpret_realpath,auparse_interpret_sock_family,auparse_interpret_sock_port,auparse_interpret_sock_address - obtenir la valeur interprétée du champ actuel

SYNTAXE

#include <auparse.h>

const char *auparse_interpret_field(const auparse_state_t *au);
const char *auparse_interpret_realpath(const auparse_state_t *au);
const char *auparse_interpret_sock_family(auparse_state_t *au);
const char *auparse_interpret_sock_port(auparse_state_t *au);
const char *auparse_interpret_sock_address(const auparse_state_t *au);

DESCRIPTION

auparse_interpret_field permet d'accéder à la valeur interprétée du champ actuel de l'enregistrement actuel dans l'événement actuel. La chaîne renvoyée est échappée en utilisant la méthode choisie. La valeur renvoyée sera détruite si vous appelez cette fonction à nouveau. Si vous avez besoin d'interpréter un autre champ et de conserver cette valeur, vous devrez la copier pour une utilisation ultérieure.

Les exemples de choses qui peuvent être interprétées sont : les uid, gid, numéros d'appels système, codes de sortie, chemins de fichiers, adresses de sockets, permissions, modes et capacités. Il y en aura probablement d'autres à l'avenir. Si une valeur ne peut pas être interprétée, sa valeur d'origine est renvoyée.

auparse_interpret_realpath est comme auparse_interpret_field, sauf qu'il appliquera realpath aux résultats de la concaténation du cwd et du fichier. Cela implique également qu'il ne peut être appelé que pour le nom de fichier donné dans un enregistrement PATH.

auparse_interpret_sock_family ne renverra que la partie famille de socket d'une adresse de socket.

auparse_interpret_sock_port ne renverra que la partie port d'une adresse de socket. Toutes les familles de sockets n'ont pas de port. Si c'est le cas, vous obtiendrez une valeur NULL, auquel cas votre meilleure option est d'utiliser la fonction d'interprétation normale.

auparse_interpret_sock_address ne renverra que la partie adresse d'une adresse de socket. Toutes les familles de sockets n'ont pas d'adresse IP. Si c'est le cas, vous obtiendrez une valeur NULL, auquel cas votre meilleure option est d'utiliser la fonction d'interprétation normale.

VALEUR RENVOYÉE

Renvoie NULL en cas d'erreur, sinon un pointeur vers la valeur interprétée.

VOIR AUSSI

auparse_get_field_int(3), auparse_get_field_str(3), auparse_set_escape_mode(3).
