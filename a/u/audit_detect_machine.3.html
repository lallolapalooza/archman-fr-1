NOM

audit_detect_machine - Détecte le type de machine actuel

SYNTAXE

#include <libaudit.h>
int audit_detect_machine(void);

DESCRIPTION

audit_detect_machine interroge uname et convertit la chaîne de machine du noyau en une valeur d'énumération définie dans machine_t. Le type de machine est nécessaire pour toute utilisation de la fonction audit_name_to_syscall.

VALEUR DE RETOUR

Retourne -1 en cas d'erreur ; sinon, la valeur de retour est le type de la machine.

VOIR AUSSI

uname(3), audit_name_to_syscall(3).

AUTEUR
