AUDIT_LOG_ACCT_MESSAGE(3) API d'audit Linux AUDIT_LOG_ACCT_MESSAGE(3)

NOM

audit_log_acct_message - enregistrer un message de compte utilisateur

SYNTAXE

#include <libaudit.h>

int audit_log_acct_message(intaudit_fd,int"type,constchar*"pgname,constchar*"op,constchar*"name,unsignedint"id,constchar*"host,constchar*"addr,constchar*"tty,int"result);"

DESCRIPTION

Cette fonction enregistrera un message dans le système d'audit en utilisant un format de message prédéfini. Elle doit être utilisée pour toutes les opérations de manipulation de compte. Les paramètres de la fonction sont les suivants :

audit_fd - Le descripteur de fichier retourné par audit_open
type - type de message : AUDIT_USER_CHAUTHTOK pour la modification de tout attribut de compte.
pgname - nom du programme, si NULL tentera de le déterminer
op - opération. Ex: "adding-user", "changing-finger-info", "deleting-group". Cette valeur doit avoir un tiret ou un underscore entre les mots afin que les analyseurs de rapports les regroupent.
name - nom du compte utilisateur ou du groupe. Si non disponible, utiliser NULL.
id - uid ou gid sur lequel l'opération est effectuée. Si l'utilisateur est inconnu, passer -1 et remplir le paramètre name. Ceci est utilisé uniquement lorsque user est NULL.
host - Le nom d'hôte si connu. Si non disponible, passer NULL.
addr - L'adresse réseau de l'utilisateur. Si non disponible, passer NULL.
tty - Le tty de l'utilisateur, si NULL tentera de le déterminer
result - 1 est "succès" et 0 est "échec"

VALEUR DE RETOUR

Elle retourne le numéro de séquence qui est > 0 en cas de succès ou <= 0 en cas d'erreur.

ERREURS

Cette fonction retourne -1 en cas d'échec. Examiner errno pour plus d'informations.

VOIR AUSSI

audit_log_user_message(3), audit_log_user_comm_message(3), audit_log_user_avc_message(3), audit_log_semanage_message(3).
