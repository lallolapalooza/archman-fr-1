NOM

autom4te - Générer des fichiers et des scripts grâce à M4

SYNOPSIS

autom4te [OPTION]... [FICHIERS]

DESCRIPTION

Exécuter GNU M4 sur les FICHIERS, en évitant les exécutions inutiles. Afficher les traces si le traçage est activé, le fichier figé si la figuration est activée, sinon l'expansion des FICHIERS.

Si certains des FICHIERS sont nommés 'FICHIER.m4f', ils sont considérés comme des fichiers M4 figés de tous les fichiers précédents (qui ne sont donc pas chargés). Si 'FICHIER.m4f' est introuvable, alors 'FICHIER.m4' sera utilisé, avec tous les fichiers précédents.

Certains fichiers peuvent être facultatifs, c'est-à-dire qu'ils ne seront traités que s'ils sont trouvés dans le chemin d'inclusion, mais doivent alors se terminer par '.m4?' ; le point d'interrogation ne fait pas partie du nom réel du fichier.

Modes d'opération :

-h, --help
afficher cette aide, puis quitter
-V, --version
afficher le numéro de version, puis quitter
-v, --verbose
signaler le traitement de manière verbeuse
-d, --debug
ne pas supprimer les fichiers temporaires
-o, --output=FICHIER
enregistrer la sortie dans FICHIER (par défaut '-', stdout)
-f, --force
ne pas se fier aux valeurs en cache
-W, --warnings=CATÉGORIE
signaler les avertissements appartenant à la CATÉGORIE (liste séparée par des virgules acceptée)
-l, --language=LANG
spécifier l'ensemble des macros M4 à utiliser
-C, --cache=RÉPERTOIRE
préserver les résultats pour les exécutions futures dans RÉPERTOIRE
--no-cache
désactiver le cache
-m, --mode=OCTAL
changer le mode du fichier de sortie non tracé (0666)
-M, --melt
ne pas utiliser les fichiers M4 figés

Les langages incluent :

'Autoconf'
créer des scripts de configuration Autoconf
'Autotest'
créer des suites de tests Autotest
'M4sh'
créer des scripts shell M4sh
'M4sugar'
créer une sortie M4sugar

Les catégories d'avertissements sont :

cross
problèmes de compilation croisée
gnu
normes de codage GNU (par défaut dans les modes gnu et gnits)
obsolete
fonctionnalités ou constructions obsolètes (par défaut)
override
redéfinitions par l'utilisateur de règles ou de variables Automake
portability
problèmes de portabilité (par défaut dans les modes gnu et gnits)
portability-recursive
variables Make imbriquées (par défaut avec -Wportability)
extra-portability
problèmes de portabilité supplémentaires liés à des outils obscurs
syntax
constructions syntaxiques douteuses (par défaut)
unsupported
fonctionnalités non prises en charge ou incomplètes (par défaut)

-W comprend aussi :

all
activer tous les avertissements
none
désactiver tous les avertissements
no-CATÉGORIE
désactiver les avertissements de la CATÉGORIE
error
traiter tous les avertissements activés comme des erreurs

Les variables d'environnement 'M4' et 'WARNINGS' sont prises en compte.

Répertoires de bibliothèques :

-B, --prepend-include=RÉP
ajouter le répertoire RÉP au début du chemin de recherche
-I, --include=RÉP
ajouter le répertoire RÉP à la fin du chemin de recherche

Traçage :

-t, --trace=MACRO[:FORMAT]
signaler les invocations de la MACRO
-p, --preselect=MACRO
préparer le traçage de la MACRO pour une exécution future

Figuration :

-F, --freeze
produire un fichier d'état M4 figé pour les FICHIERS

FORMAT vaut par défaut '$f:$l:$n:$%', et peut utiliser les échappements suivants :

$$
$ littéral
$f
fichier où la macro a été appelée
$l
ligne où la macro a été appelée
$d
profondeur d'imbrication de l'appel de macro
$n
nom de la macro
$NUM
argument NUM, sans guillemets et avec les sauts de ligne
$SEP@
tous les arguments, avec les sauts de ligne, entre guillemets, et séparés par SEP
$SEP*
tous les arguments, avec les sauts de ligne, sans guillemets, et séparés par SEP
$SEP%
tous les arguments, sans sauts de ligne, sans guillemets, et séparés par SEP

SEP peut être vide pour la valeur par défaut (virgule pour @ et *, deux-points pour %), un seul caractère pour ce caractère, ou {CHAÎNE} pour utiliser une chaîne.
