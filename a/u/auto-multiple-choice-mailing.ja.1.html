NOM

auto-multiple-choice-mailing - Envoyer par courriel les copies d'examen annotées aux étudiants

SYNOPSIS

auto-multiple-choice mailing [--xmlargsargs.xml] --projectproject-dir --students-liststudents-list.csv [--list-encodingencoding] --email-columncol --sendersender-email --subjectsubject --textemail-body [--text-content-typecontent-type] [--debugfile.log] [arguments de transport...]

DESCRIPTION

auto-multiple-choice mailingenvoie par courriel les copies d'examen annotées aux étudiants. Les adresses courriel sont extraites du fichier de la liste des étudiants.

--project project-dir

Spécifie le répertoire du projet.

--students-list students-list.csv

Définit le nom du fichier de la liste des étudiants.

--list-encoding encoding

Sélectionne l'encodage destudents-list.csv (par défaut utf-8).

--email-column col

Définit, dans le fichier de la liste des étudiants, le nom de la colonne correspondant à l'adresse courriel de l'étudiant.

--sender sender-email

Définit l'adresse de l'expéditeur.

--cc cc-email-address

Définit l'adresse Cc.

--bcc bcc-email-address

Définit l'adresse Bcc.

--subject subject

Définit l'objet du courriel envoyé.

--text email-body

Définit le corps du courriel envoyé.

--text-content-type content-type

Définit le content-type du corps du courriel.content-typeesttext/plainoutext/html.

--attach filename

Joint le fichierfilenameà chaque courriel envoyé. Cette option peut être utilisée plusieurs fois pour joindre plusieurs fichiers.

--transport transport

Définit la méthode de transport. Lestransportvalides sontsendmailouSMTP.

--debug file.log

Spécifie le fichier où enregistrer les informations de débogage.

--delay time

Définit un délai detimesecondes entre chaque envoi.

ARGUMENTS PAR MÉTHODE DE TRANSPORT

En fonction de la valeur detransport , les arguments suivants sont ajoutés :

Transport sendmail

--sendmail-path path

Définit le chemin de la commandesendmail (par défaut /usr/sbin/sendmail).

Transport SMTP

--smtp-host host

Définit le nom d'hôte SMTP (par défautsmtp).

--smtp-port port

Définit le port à utiliser (par défaut 25).

--smtp-ssl mode

Définit le mode de sécurité de la connexion SMTP.L'optionmode est l'une des suivantes : ssl, starttls, 0 (sans chiffrement).

--smtp-user user

Définit le nom d'utilisateur pour l'authentification SMTP.

--smtp-passwd-file file

Spécifie le chemin d'un fichier contenant (sur la première ligne) le mot de passe pour l'authentification SMTP.

ARGUMENTS VIA FICHIER XML

Pour éviter les problèmes d'encodage, vous pouvez placer les arguments dans un fichier XML et utiliser--xmlargs file.xmlcomme premier argument de la commande. Voici un exemple d'un tel fichier :

<?xml version="1.0" encoding="UTF-8"?>
<arguments>
  <arg>--sender</arg><arg>Bienvenue &paamc@passoire.fr&</arg>
  <arg>--text</arg><arg>Voilà votre copie corrigée</arg>
  <arg>--subject</arg><arg>QCM</arg>
</arguments>
