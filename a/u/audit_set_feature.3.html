AUDIT_GET_FEATURES(3) API d'audit Linux AUDIT_GET_FEATURES(3)

NOM

audit_get_features, audit_set_feature - interroger ou modifier les fonctionnalités d'audit du noyau

SYNTAXE

#include <libaudit.h>

uint32_t audit_get_features(void);
int audit_set_feature(int fd, unsigned feature, unsigned value, unsigned lock);"

DESCRIPTION

audit_get_features() renvoie un bitmap décrivant les fonctionnalités d'audit du noyau qui sont supportées. Le bitmap est mis en cache en interne et récupéré du noyau lors du premier appel.

audit_set_feature() modifie un bit de fonctionnalité pour le noyau en utilisant le descripteur fd qui doit être un socket netlink d'audit ouvert. feature sélectionne le bit à modifier. Si value est non nul, la fonctionnalité est activée, sinon elle est désactivée. Si lock est non nul, le paramètre de la fonctionnalité est verrouillé jusqu'au redémarrage.

Les bits de fonctionnalité actuellement définis sont :

AUDIT_FEATURE_BITMAP_BACKLOG_LIMIT
Le noyau supporte la modification de la profondeur de la file d'attente.
AUDIT_FEATURE_BITMAP_BACKLOG_WAIT_TIME
Le noyau supporte le retardement des appels système lorsque la file est pleine.
AUDIT_FEATURE_BITMAP_EXECUTABLE_PATH
Le noyau inclura le chemin de l'exécutable dans les enregistrements EXECVE.
AUDIT_FEATURE_BITMAP_EXCLUDE_EXTEND
Les règles d'exclusion peuvent être utilisées avec plus de champs que le simple type de message.
AUDIT_FEATURE_BITMAP_SESSIONID_FILTER
Le filtrage de l'identifiant de session est supporté.
AUDIT_FEATURE_BITMAP_LOST_RESET
Permet de réinitialiser le compteur d'événements perdus.
AUDIT_FEATURE_BITMAP_FILTER_FS
Le noyau supporte le filtrage par champ de système de fichiers.

VALEUR DE RETOUR

audit_get_features renvoie le bitmap de fonctionnalités ou 0 si les requêtes de fonctionnalités ne sont pas supportées. audit_set_feature renvoie <= 0 en cas d'erreur, sinon c'est le numéro de séquence netlink.

VOIR AUSSI

audit_request_features(3), audit_reset_lost(3), audit_open(3).
