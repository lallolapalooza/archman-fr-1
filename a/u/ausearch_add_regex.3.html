AUSEARCH_ADD_REGEX(3) API d'audit Linux AUSEARCH_ADD_REGEX(3)

NOM

ausearch_add_regex - utilise une règle de recherche par expression régulière

SYNOPSIS

#include <auparse.h>

int ausearch_add_regex(auparse_state_t *au,constchar*"regexp);"

DESCRIPTION

pausearch_add_regex ajoute une condition de recherche basée sur une expression régulière à l'expression de recherche d'audit actuelle. Les conditions de recherche peuvent ensuite être utilisées pour scanner des journaux, des fichiers ou des tampons pour trouver quelque chose d'intéressant. L'expression régulière suit les conventions des expressions régulières étendues POSIX, et est mise en correspondance avec l'enregistrement complet (sans interpréter les valeurs des champs).

Si une expression de recherche E existante est déjà définie, cette fonction la remplace par (E && this_regexp).

VALEUR DE RETOUR

Retourne -1 en cas d'erreur ; sinon, 0 pour succès.

VOIR AUSSI

ausearch_add_expression(3), ausearch_add_item(3), ausearch_clear(3), ausearch_next_event(3), ausearch_cur_event(3), regcomp(3).
