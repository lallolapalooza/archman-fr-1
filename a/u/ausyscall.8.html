AUSYSCALL(8) Utilitaires d'administration système AUSYSCALL(8)

NOM

ausyscall - un programme qui permet de mapper des noms et des numéros d'appels système

SYNTAXE

ausyscall [arch] nom | numéro | --dump | --exact

DESCRIPTION

ausyscall est un programme qui affiche le mappage du nom d'appel système au numéro et inversement pour l'architecture donnée. L'architecture peut être n'importe quoi retourné par « uname -m ». Si l'architecture n'est pas donnée, le programme essaiera de la deviner en fonction de l'image en cours d'exécution. Ou, pour plus de commodité, vous pouvez passer b32 ou b64 pour utiliser l'architecture actuelle mais une ABI spécifique. Vous pouvez donner le nom ou le numéro de l'appel système et il trouvera l'opposé. Vous pouvez également afficher toute la table avec l'option --dump. Par défaut, une recherche de nom d'appel système sera une correspondance partielle, ce qui signifie qu'elle essaiera de faire correspondre toutes les occurrences du nom donné avec les appels système. Ainsi, donner un nom tel que chown correspondra à la fois à fchown et à chown ainsi qu'à tout autre appel système contenant chown dans son nom. Si ce comportement n'est pas souhaité, passez l'indicateur --exact et il effectuera une correspondance de chaîne exacte.

Le programme prend l'architecture spéciale, uring, pour indiquer que vous souhaitez spécifier des opérations io_uring. Dans ce cas, l'architecture doit être fournie car elle détectera autrement le matériel sous-jacent.

Ce programme peut être utilisé pour vérifier les numéros d'appels système sur une plateforme biarch pour l'optimisation des règles. Par exemple, supposez que vous aviez une règle auditctl :

-a always, exit -S open -F exit=-EPERM -k fail-open

Si vous vouliez vérifier que les programmes 32 bits et 64 bits seraient audités, exécutez « ausyscall i386 open » puis « ausyscall x86_64 open ». (Ou utilisez les options b32 et b64.) Regardez les numéros retournés. S'ils sont différents, vous devrez écrire deux règles auditctl pour obtenir une couverture complète.

-a always,exit -F arch=b32 -S open -F exit=-EPERM -k fail-open
-a always,exit -F arch=b64 -S open -F exit=-EPERM -k fail-open

Pour plus d'informations sur un appel système spécifique, utilisez le programme man et passez le numéro 2 comme argument pour vous assurer d'obtenir les informations de l'appel système plutôt qu'un script shell ou un appel de fonction glibc du même nom. Par exemple, si vous vouliez en savoir plus sur l'appel système open, tapez : man 2 open.

OPTIONS

--dump
Imprimer tous les appels système pour l'architecture donnée
--exact
Au lieu de faire une correspondance de mot partiel, faire correspondre exactement le nom de l'appel système donné.

VOIR AUSSI

ausearch(8), auditctl(8).
