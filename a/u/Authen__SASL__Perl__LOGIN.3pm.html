Authen::SASL::Perl::LOGIN(3) Documentation Perl fournie par l'utilisateur Authen::SASL::Perl::LOGIN(3)

NOM

Authen::SASL::Perl::LOGIN - Classe d'authentification Login

VERSION

version 2.1900

SYNTAXE

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'LOGIN',
  callback  => {
    user => $user,
    pass => $pass
  },
);

DESCRIPTION

Cette méthode implémente la partie client et serveur de l'algorithme SASL LOGIN, tel que décrit dans le brouillon IETF draft-murchison-sasl-login-XX.txt.

CALLBACK

Les callbacks utilisés sont :

Client

user
Le nom d'utilisateur à utiliser pour l'authentification
pass
Le mot de passe de l'utilisateur à utiliser pour l'authentification

Serveur

getsecret(username)
retourne le mot de passe associé à "username"
checkpass(username, password)
retourne vrai et faux en fonction de la validité des identifiants passés en arguments.

VOIR AUSSI

Authen::SASL, Authen::SASL::Perl
