NOM

auto-multiple-choice-export - exporte les notes pour les examens à choix multiples d'AMC.

SYNOPIS

auto-multiple-choice export --data répertoire-données-projet --module module --fich-noms liste-élèves.csv [--noms-encodage encodage-liste] --o fichier-sortie

DESCRIPTION

La commande auto-multiple-choice export exporte les notes d'un examen Auto Multiple Choice.

--data répertoire-données-projet

donne le répertoire où se trouvent les fichiers de données (voir par exemple auto-multiple-choice-prepare(1)).

--module module

sélectionne un module pour l'exportation. Voir ci-dessous pour les modules inclus dans la distribution standard d'AMC.

--fich-noms liste-élèves.csv

définit le fichier de liste des élèves.

--noms-encodage encodage-liste

sélectionne un encodage pour le fichier liste-élèves.csv (par défaut utf-8).

--o fichier-sortie

donne le nom du fichier de sortie.

--option-out options

donne une option pour le module sélectionné, sous la forme clé=valeur (voir ci-dessous pour les options possibles pour chaque module). Pour spécifier plusieurs options, utilisez --option plusieurs fois.

--sort type-tri

trie les noms des élèves, en fonction de type-tri. Si type-tri est l, utilisez le numéro de ligne du fichier de liste des élèves pour trier. Si type-tri est m, utilisez la note (et le nom si les notes sont égales) pour trier. Si type-tri est i, utilisez le numéro de l'élève pour trier. Si type-tri est n, utilisez le nom pour trier (ou la ligne du fichier de liste des élèves si égal).

--useall tous

si tous est 0 ou vide, seuls les élèves avec une feuille de réponses numérisée apparaissent dans la sortie. Si tous est 1, tous les élèves de la liste des élèves apparaissent dans la sortie.

MODULES

OpenDocument

Avec "--module ods", un fichier OpenDocument (pour utilisation par OpenOffice ou LibreOffice par exemple) est produit. Les options suivantes sont reconnues :

nom

donne un nom pour l'examen, à écrire au début de la feuille.

code

donne un nom court pour l'examen, à utiliser comme nom d'onglet.

columns

définit la liste des colonnes à ajouter pour chaque élève.

La valeur par défaut est student.key,student.name.

stats

avec une valeur vraie, une table sera ajoutée avec des statistiques pour toutes les questions.

statsindic

avec une valeur vraie, une table sera ajoutée avec des statistiques pour toutes les questions indicatives.

CSV

Avec "--module CSV", un fichier CSV est produit. Les options suivantes sont reconnues :

columns

définit la liste des colonnes à ajouter pour chaque élève.

La valeur par défaut est student.copy,student.key,student.name.

decimal

définit le point décimal (par défaut un point).

encodage

définit l'encodage à utiliser pour la sortie (par défaut utf-8).

separateur

définit le caractère utilisé entre les colonnes (par défaut une virgule).

entoure

définit le caractère utilisé pour entourer les chaînes (par défaut un guillemet double).

ticked

si non vide, des colonnes supplémentaires (avec le préfixe "CHECKED:") sont incluses pour donner toutes les cases cochées sur toutes les feuilles. Ceci peut être utilisé par un programme externe pour récupérer toutes les cases cochées lorsque les notes ne sont pas suffisantes. Utilisez la valeur 01 pour obtenir 0;0;1;1;0 si les cases 3 et 4 sont cochées, et la valeur AB pour obtenir CD si les cases 3 et 4 sont cochées.

List

Avec "--module List", un fichier PDF est produit avec une liste des notes pour tous les élèves. Les options suivantes sont reconnues :

pagesize

La taille de la page. La valeur par défaut est a4.

nom

donne le nom de l'examen, à imprimer en haut de la page.

ncols

Le nombre de colonnes. La valeur par défaut est 2.

decimal

définit le point décimal (par défaut un point).
