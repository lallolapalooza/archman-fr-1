DESCRIPTIO

N

AutoGen est conçu pour générer des fichiers de programme contenant du texte répétitif avec des substitutions variées. Le but est de simplifier la maintenance des programmes contenant de grandes quantités de texte répétitif. Cela est particulièrement utile s'il existe plusieurs blocs de ce type de texte qui doivent être maintenus de manière

synchronisée.

Un exemple courant est le problème de la maintenance du code requis pour le traitement des options de programme. Le traitement des options nécessite qu'un minimum de quatre constructions différentes soient maintenues dans le bon ordre à différents endroits de votre programme. Vous avez besoin d'au moins : le caractère du drapeau dans la chaîne de drapeaux, le code pour traiter le drapeau lorsqu'il est rencontré, une ou deux variables d'état globales, et une ligne dans le texte d'utilisation. Vous aurez besoin de plus de choses que cela si vous choisissez d'implémenter des noms d'options longs, le traitement de fichiers de configuration, des variables d'environnement,

etc.

Tout cela peut être fait mécan

iquement ; avec les modèles a
ppropriés et ce programme.

Cette commande a produit cette page man à partir du fichier de définition d'options AutoGen. Elle remplace le modèle spécifié dans opts.def (normalement options.tpl) et utilise agman-cmd.tpl.
