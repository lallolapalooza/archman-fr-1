AUDIT_REQUEST_STATUS(3) API d'audit Linux AUDIT_REQUEST_STATUS(3)

NOM

audit_request_status - Demande le statut du système d'audit

SYNTAXE

#include <libaudit.h>
int audit_request_status(int fd);"

DESCRIPTION

audit_request_status demande au noyau d'envoyer une structure de statut décrivant divers paramètres sur le descripteur donné dans fd. La structure audit_status est la suivante :

struct audit_status {
   __u32   mask;           /* Masque de bits pour les entrées valides */
   __u32   enabled;        /* 1 = activé, 0 = désactivé */
   __u32   failure;        /* Action en cas d'échec d'enregistrement */
   __u32   pid;            /* pid du processus auditd */
   __u32   rate_limit;     /* limite du taux de messages (par seconde) */
   __u32   backlog_limit;  /* limite des messages en attente */
   __u32   lost;           /* messages perdus */
   __u32   backlog;        /* messages en attente dans la file */
};

VALEUR DE RETOUR

La valeur de retour est <= 0 en cas d'erreur, sinon c'est le numéro de séquence netlink. Cette fonction peut rencontrer les mêmes erreurs que sendto.

VOIR AUSSI

audit_open(3), audit_get_reply(3), auditd(8).
