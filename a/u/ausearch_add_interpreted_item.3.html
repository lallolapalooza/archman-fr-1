ausearch_add_interpreted_item(3)

AUSEARCH_ADD_INTERPRETED_ITEM(3) API Audit Linux AUSEARCH_ADD_INTERPRETED_ITEM(3)

NOM

ausearch_add_interpreted_item - construire une règle de recherche

SYNTAXE

#include <auparse.h>

int ausearch_add_interpreted_item(auparse_state_t *au,constchar*"champ,constchar*"op,constchar*"valeur,ausearch_rule_t"comment);"

DESCRIPTION

ausearch_add_interpreted_item ajoute une condition de recherche à l'expression de recherche d'audit actuelle. Les conditions de recherche peuvent ensuite être utilisées pour scanner des journaux, des fichiers ou des tampons pour trouver quelque chose d'intéressant. La valeur du champ est le nom du champ pour lequel la valeur sera vérifiée. La variable op décrit le type de vérification à effectuer. Les valeurs légales pour op sont :

existe

vérifier simplement que le nom du champ existe
=

localiser le nom du champ et vérifier que la valeur qui lui est associée est égale à la valeur donnée dans cette règle.
!=

localiser le nom du champ et vérifier que la valeur qui lui est associée N'EST PAS égale à la valeur donnée dans cette règle.

Le paramètre valeur est comparé à la valeur interprétée du champ (la valeur qui serait renvoyée par auparse_interpret_field(3)).

La valeur comment détermine comment cette condition de recherche affectera l'expression de recherche existante si elle est déjà définie. Les valeurs possibles sont :

AUSEARCH_RULE_CLEAR
Effacer l'expression de recherche actuelle, le cas échéant, et utiliser uniquement cette condition de recherche.
AUSEARCH_RULE_OR
Si une expression de recherche E est déjà configurée, la remplacer par (E || cette_condition_de_recherche).
AUSEARCH_RULE_AND
Si une expression de recherche E est déjà configurée, la remplacer par (E && cette_condition_de_recherche).

VALEUR DE RETOUR

Retourne -1 en cas d'erreur ; sinon, 0 en cas de succès.
