NOM

auto-multiple-choice-annotate - annotation des copies corrigées après notation pour les examens à choix multiples AMC.

SYNTAXE

auto-multiple-choice annotate --project répertoire-projet --names-file eleves.csv [options-annotation...]

DESCRIPTION

La commande auto-multiple-choice annotate annote les scans des copies avec les notes pour toutes les questions, la note globale et le coefficient, produisant des fichiers PDF (un pour chaque élève, ou un unique fichier).

Options générales

--project répertoire-projet

définit le nom ou le répertoire du projet.

--data répertoire-données-projet

donne le répertoire où se trouvent les fichiers de données (la valeur par défaut est répertoire-projet/data).

--pdf-dir répertoire-pdf

définit le répertoire des PDF du projet, où sortir les copies annotées (la valeur par défaut est répertoire-projet/cr/corrections/pdf).

--names-file liste-élèves.csv

définit le nom du fichier de liste des élèves.

--names-encoding encodage

choisit un encodage pour le fichier liste-élèves.csv (par défaut utf-8).

--association-key clé

définit la clé (nom de colonne dans le fichier de liste des élèves) utilisée pour l'association. La valeur par défaut est stockée dans la base de données à partir de la valeur réellement utilisée pour l'association, donc cette option ne devrait pas être utilisée.

--subject sujet.pdf

définit le chemin vers le fichier PDF du sujet (par défaut répertoire-projet/DOC-sujet.pdf).

--compose mode

utiliser cette option si vous voulez prendre des pages du sujet quand il n'y a pas de cases à cocher sur ces pages (par exemple, les pages de questions avant la feuille de réponses à annoter). Quand mode vaut 1, les pages sont prises du sujet, sont cochées ou non en fonction des réponses de l'élève (comme sur la feuille de réponse), et les mêmes marques de correction sont dessinées que sur la feuille de réponse. Quand le mode vaut 2, les pages sont prises de la feuille de réponse corrigée (donc les réponses cochées sont les bonnes), et aucune marque de correction n'est dessinée.

--corrected corrigé.pdf

définit le chemin vers le PDF du sujet corrigé (par défaut répertoire-projet/DOC-corrigé.pdf). S'il n'est pas présent, ce fichier sera reconstruit en utilisant les valeurs des options --n-copies, --with, --filter et --filtered-source).

--darkness-threshold t

définit le seuil d'obscurité. La valeur par défaut est stockée dans la base de données à partir de la valeur réellement utilisée pour la notation, donc cette option ne devrait pas être utilisée.

--darkness-threshold-up seuil_supérieur_t

définit le seuil d'obscurité supérieur. La valeur par défaut est stockée dans la base de données à partir de la valeur réellement utilisée pour la notation, donc cette option ne devrait pas être utilisée.

--csv-build-name modèle-nom

définit le modèle pour construire les noms des élèves à partir du fichier de liste des élèves. La valeur par défaut est '(nom|surname) (prenom|name)', de sorte que le nom est construit en utilisant le contenu de la colonne nom (ou la colonne surname si la colonne nom n'existe pas), suivi du contenu de la colonne prenom (ou la colonne name), de sorte que le résultat devrait être correct pour des fichiers CSV simples en français ou en anglais.

--id-file ids.txt

donne un nom de fichier où trouver les identifiants des copies à annoter (un par ligne, soit le numéro de l'élève si le mode photocopie est désactivé, soit eleve:copie si le mode photocopie est activé). Si aucun fichier n'est donné, alors toutes les copies seront annotées.

--debug fichier.log

donne un fichier à remplir avec des informations de débogage.

Options de sortie PDF

--single-output

utiliser cette option si vous avez besoin de toutes les copies annotées dans un seul fichier PDF. Le comportement par défaut est de créer un fichier PDF par élève.

--sort s

définit la clé de tri (utile uniquement lorsqu'on utilise --single-output) : utiliser

l

pour conserver les élèves dans le même ordre que dans le fichier de liste des élèves.

m

pour trier les élèves selon leurs notes.

i

pour trier les élèves selon leur identifiant de copie.

n

pour trier les élèves selon leur nom.

--filename-model modèle

définit un modèle de nom de fichier pour les PDF annotés. Dans ce modèle, certaines séquences seront substituées :

(ID)

est remplacé par le nom de l'élève (voir --csv-build-name).

(N)

est remplacé par le numéro de l'élève.

(COL)

est remplacé par la valeur de la colonne COL dans la liste des élèves pour l'élève courant.

La valeur par défaut est '(N)-(ID).pdf'.

Options de fichier source

Ces options sont utilisées lorsque le chemin --corrected pointe vers un fichier inexistant, de sorte que ce fichier puisse être reconstruit.

--src fichier-source-mcq --n-copies n --with moteur-latex --filter nom-filtre --filtered-source fs.tex

voir auto-multiple-choice-prepare(1).

Options pour les scans intégrés

Lorsqu'ils sont présents, les scans sont intégrés dans le fichier PDF annoté. Les options suivantes contrôlent la qualité des scans intégrés, afin de réduire la taille du fichier annoté.

--embedded-max-size taille_max

définit la taille maximale des scans (au format largeurxhauteur, en pixels). La valeur par défaut est la chaîne vide, ce qui signifie qu'il n'y a pas de taille maximale. Les scans plus grands seront réduits avant d'être inclus dans le fichier annoté.

--embedded-format format

définit le format pour l'inclusion des scans : jpeg ou png.

--embedded-jpeg-quality qualité

définit la qualité JPEG (de 1 à 100) pour les scans intégrés en JPEG.

Options d'annotation

Ces options contrôlent le type d'annotations qui vont être dessinées.

--font-size taille_police

définit la taille de la police, en points, pour les annotations.

--text-color couleur

couleur du texte pour les annotations. La valeur par défaut est red.

--verdict en-tête

définit le texte d'en-tête à imprimer sur chaque première page des copies des élèves. Ce texte peut contenir des caractères CR pour des en-têtes multi-lignes. Certaines séquences y sont substituées :

%S

est remplacé par la note totale de l'élève.

%M

est remplacé par la note totale maximale.

%s

est remplacé par le coefficient de l'élève.

%m

est remplacé par le coefficient maximal.

%(ID)

est remplacé par le nom de l'élève.

%(COL)

est remplacé par la valeur de la colonne COL dans la liste des élèves pour l'élève courant.

--position pos

définit la position où les notes des questions doivent être écrites :

marge

les notes seront écrites dans la marge gauche

marges

les notes seront écrites dans la marge la plus proche (gauche ou droite).

case

les notes seront écrites près des cases

none

les notes ne seront pas écrites.

--verdict-question expression-perl

--verdict-question expression-perl

indent">définit le texte à imprimer à côté de toutes les questions, à travers une expression perl à évaluer (si vous avez besoin d'un texte simple, mettez-le simplement entre "). Certaines séquences sont substituées avant l'évaluation :

%S

est remplacé par la note de l'étudiant pour cette question.

%M

est remplacé par la note maximale pour cette question.

%s

est identique à %S, mais arrondi à nc chiffres significatifs (voir l'option --ch-sign).

%m

est identique à %M, mais arrondi à nc chiffres significatifs (voir l'option --ch-sign).

Une valeur standard pour cette option est "\"%s/%m\"". Vous pouvez aussi utiliser des tests (avec la syntaxe perl ( TEST ? SI-OUI : SI-NON )) pour écrire Valide si la note est la note maximale, ou Échoué sinon, en utilisant

--verdict-question "(%S==%M ? \"Valide\" : \"Échoué\")"

--verdict-question-cancelled expression-perl

identique à --verdict-question, mais s'applique aux questions annulées (voir la stratégie de notation allowempty). La valeur par défaut est "X".

--indicatives

utilisez cette option pour demander l'annotation des cases pour les questions indicatives (les notes de ces questions ne seront pas prises en compte lors du calcul de la note globale. Le statut correct/incorrect est souvent sans importance pour ces questions, il n'y a donc pas de raison de corriger les cases correspondantes).

--line-width largeur

définit la largeur de ligne (en points) lors du dessin des symboles de correction des réponses.

--symbols définition-des-symboles

définit la manière dont les cases seront annotées. définition-des-symboles est une liste d'éléments séparés par des virgules de la forme H-A:forme:couleur , où H vaut 0 ou 1 selon que la case doit être cochée ou non, A vaut 0 ou 1 selon que la case est effectivement cochée ou non, forme est l'une de none, circle, mark, box et couleur est une couleur (nom ou #RGB, voir la documentation d'ImageMagick ou GraphicsMagick pour plus de détails).

La valeur par défaut est "0-0:none,0-1:circle:red,1-0:mark:red,1-1:mark:blue".

Longueurs

Les longueurs suivantes peuvent être données avec une unité (in, ft, pt, cm ou mm).

définit la distance depuis les cases (vers la gauche) où écrire les notes des questions lors de l'utilisation de --position case. La valeur par défaut est 1cm.

--dist-margin d

définit la taille de la marge. La valeur par défaut est 5mm.

--dist-margin-global d

définit la taille de la marge pour l'en-tête. La valeur par défaut est 3mm.
