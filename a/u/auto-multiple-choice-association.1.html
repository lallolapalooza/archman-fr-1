NOM

auto-multiple-choice-association - association manuelle entre étudiants et feuilles de réponses pour les examens à choix multiples AMC.

SYNOPIS

auto-multiple-choice association --data répertoire-données-projet --list

auto-multiple-choice association --data répertoire-données-projet --set --student numéro-feuille-étudiant [--copy numéro-copie] --id identifiant-étudiant

DESCRIPTION

La commande auto-multiple-choice association gère les données d'association entre les étudiants et leurs feuilles de réponses.

--data répertoire-données-projet

spécifie le répertoire où se trouvent les fichiers de données (voir par exemple auto-multiple-choice-prepare(1)).

Avec l'option --list, toutes les données d'association sont affichées.

Avec l'option --set, une association manuelle est mise à jour.
