DESCRIPTIO

N

Augeas est un outil d'édition de configuration. Il analyse les fichiers de configuration dans leurs formats natifs et les transforme en arbre. Les modifications de configuration sont effectuées en manipulant cet arbre et en le sauvegardant à nouveau dans les fichiers de configuration

natifs.

augtool fournit une interface en ligne de commande pour l'arbre généré. COMMANDE peut être un

e commande unique comme décrit dans « COMMANDES ». Lorsqu'elle est appelée sans COMMANDE, elle
lit les commandes depuis l'entrée standard jusqu'à ce qu'une fin de fichier soit rencontrée.

COMMANDE

S

En mode interactif, les commandes et les chemins peuvent être complétés en appuyant sur "TAB"

.

Les chemins acceptés comme arguments par les commandes utilisent un petit sous-ensemble des expressions de chemin XPath. Une expression de chemin se compose d'un certain nombre de segments, séparés par "/". Dans chaque segment, le caractère "*" peut être utilisé pour faire correspondre chaque nœud quel que soit son libellé. Les nœuds frères avec des libellés identiques peuvent être distingués en ajoutant "[N]" à leur libellé pour faire correspondre le N-ième frère avec un tel libellé. Le dernier frère avec un libellé spécifique peut être atteint comme "[last()]". Voir « EXEMPLES » pour quelques exemples de

cela.

DIAGNOSTIC

S

Normalement, le code de sortie est 0. Si une ou plusieurs commandes échouent, le code de sortie est défini à une valeur non

nulle.

Notez cependant que l'échec du chargement de certains des fichiers spécifiés par les transformations dans "/augeas/load" n'est pas considéré comme un échec. S'il est important de savoir si tous les fichiers ont été chargés, vous devez émettre un "match /augeas//error" après le chargement pour connaître les dé

tails sur les fichiers qui n'ont pa
s pu être chargés et pourquoi.
