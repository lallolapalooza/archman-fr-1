NOM

autoopts-config - script pour obtenir des informations sur la version installée d'autoopts

SYNTAXE

autoopts-config { <nom-valeur> [...] | tout }

DESCRIPTION

autoopts-config est un outil utilisé par configure pour déterminer les indicateurs de compilation et de liaison qui doivent être utilisés pour compiler et lier des programmes utilisant autoopts. Les noms-valeurs peuvent être précédés d'un ou plusieurs traits d'union. Ils sont ignorés silencieusement.

NOMS DES VALEURS

autogen

Affiche le chemin complet de l'exécutable autogen.
La valeur non configurée est : ${bindir}/autogen${exeext}

bindir

Le répertoire de destination pour les scripts exécutables et les programmes installés par le paquet autogen.
La valeur non configurée est : @bindir@

cflags

Affiche les indicateurs du compilateur nécessaires pour compiler un programme autoopts.
La valeur non configurée est : -I${includedir}

datadir

Le répertoire pour divers répertoires de données.
La valeur non configurée est : @datadir@

datarootdir

Le répertoire racine pour divers répertoires de données. Dans ce cas, il n'y en a qu'un, "datadir".
La valeur non configurée est : @datarootdir@

dotver

Affiche la version actuellement installée d'autoopts, au format pointillé.
La valeur non configurée est : @AO_CURRENT@.@AO_REVISION@.@AO_AGE@

tout

Affiche la liste de tous les noms et valeurs, un par ligne.

exec_prefix

La racine d'installation pour les bibliothèques et les exécutables.
La valeur non configurée est : @exec_prefix@

exeext

L'extension de fichier exécutable utilisée pour l'exécutable autogen.
La valeur non configurée est : @EXEEXT@

includedir

Le répertoire où sont stockés les en-têtes AutoOpts. Ceci n'inclut pas le préfixe "-I" obtenu en spécifiant "cflags".
La valeur non configurée est : @includedir@

ldflags

Affiche les indicateurs de l'éditeur de liens nécessaires pour lier un programme autoopts en mode d'installation par défaut (statique ou dynamique).
La valeur non configurée est : -L${libdir} -lopts

ldopts

Les options de l'éditeur de liens à utiliser lors de la liaison d'un programme à libopts.
La valeur non configurée est : @AG_LDFLAGS@

libdir

Le répertoire d'installation de libopts.
La valeur non configurée est : @libdir@

libs

Une orthographe alternative de "ldflags".
La valeur non configurée est : ${ldflags}

libsrc

Le chemin complet de la bibliothèque source libopts redistribuable, détachable. Ce fichier est au format tarball compressé.
La valeur non configurée est : ${pkgdatadir}/libopts-${dotver}.tar.gz

package

Le nom du paquet qui fournit autoopts. C'est toujours "autogen".
La valeur non configurée est : @PACKAGE@

pkgdatadir

Le répertoire contenant les fichiers de support utilisés par autogen.
La valeur non configurée est : ${datadir}/${package}

prefix

Le préfixe d'installation du paquet autogen.
La valeur non configurée est : @prefix@

static_libs

Le nom de l'archive AR du code objet de libopts.
La valeur non configurée est : ${libdir}/libopts.a

version

Affiche la version actuellement installée d'autoopts.
La valeur non configurée est : @AO_CURRENT@:@AO_REVISION@:@AO_AGE@
