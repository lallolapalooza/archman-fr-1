AUPARSE_ADD_CALLBACK(3) API Audit Linux AUPARSE_ADD_CALLBACK(3)

NOM

auparse_add_callback - ajouter un gestionnaire de rappel pour les notifications

SYNTAXE

#include <auparse.h>

void auparse_add_callback(auparse_state_t *au, auparse_callback_ptr callback, void *user_data, user_destroy user_destroy_func);

DESCRIPTION

auparse_add_callback ajoute une fonction de rappel à l'état d'analyse qui est invoquée pour notifier l'application d'événements d'analyse. Ceci fait partie de l'API de flux d'événements.

La signature du rappel est :

void
auparse_callback(auparse_state_t *au, auparse_cb_event_t cb_event_type,
                 void *user_data);

Lorsque le rappel est invoqué, il reçoit :

au

un pointeur vers l'état d'analyse
cb_event_type
une valeur énumérée indiquant la raison pour laquelle le rappel a été invoqué
user_data
un pointeur vers des données privées fournies par l'utilisateur. Peut être NULL.
user_destroy_func
un pointeur vers une fonction appelée lorsque user_data est détruit. Peut être NULL. La signature est : 
void destroy(void *user_data);

La fonction destroy() doit être préparée à accepter user_data potentiellement NULL.

L'argument cb_event_type indique pourquoi le rappel a été invoqué. Ses valeurs possibles sont :

AUPARSE_CB_EVENT_READY
Un événement complet a été analysé et est prêt à être examiné. Ceci est logiquement équivalent à l'état d'analyse immédiatement après auparse_next_event()

Voir auparse_feed(3) pour un exemple de code complet.

VALEUR DE RETOUR

Aucune.

VOIR AUSSI

auparse_feed(3), auparse_flush_feed(3).
