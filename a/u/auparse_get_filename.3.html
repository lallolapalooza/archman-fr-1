AUPARSE_GET_FILENAME(3) API d'audit Linux AUPARSE_GET_FILENAME(3)

NOM

auparse_get_filename - obtenir le nom du fichier où l'enregistrement a été trouvé

SYNTAXE

#include <auparse.h>

const char * auparse_get_filename(const auparse_state_t *au);"

DESCRIPTION

auparse_get_filename renvoie le nom du fichier source où l'enregistrement a été trouvé si le type de source est AUSOURCE_FILE ou AUSOURCE_FILE_ARRAY. Pour les autres types de sources, la valeur renvoyée sera NULL.

VALEUR RENVOYÉE

Renvoie un pointeur vers un nom de fichier ou NULL si indisponible.

VOIR AUSSI

auparse_get_line_number(3). auparse_next_record(3).
