NOM

autoconf - Générer des scripts de configuration

SYNOPSIS

autoconf [OPTION]... [FICHIER-MODELE]

DESCRIPTION

Génère un script de configuration à partir de FICHIER-MODELE s'il est fourni, ou de 'configure.ac' s'il est présent, ou sinon de 'configure.in'. La sortie est envoyée sur la sortie standard si FICHIER-MODELE est fourni, sinon dans 'configure'.

Modes de fonctionnement :

-h, --help
afficher cette aide, puis quitter
-V, --version
afficher le numéro de version, puis quitter
-v, --verbose
rapporter de manière détaillée le traitement
-d, --debug
ne pas supprimer les fichiers temporaires
-f, --force
considérer tous les fichiers comme obsolètes
-o, --output=FICHIER
sauvegarder la sortie dans FICHIER (stdout par défaut)
-W, --warnings=CATEGORIE
rapporter les avertissements appartenant à CATEGORIE (liste séparée par des virgules acceptée)

Catégories d'avertissement :

cross
problèmes de compilation croisée
gnu
normes de codage GNU (par défaut en mode gnu et gnits)
obsolete
fonctionnalités ou constructions obsolètes (par défaut)
override
redéfinitions par l'utilisateur de règles ou de variables Automake
portability
problèmes de portabilité (par défaut en mode gnu et gnits)
portability-recursive
variables Make imbriquées (par défaut avec -Wportability)
extra-portability
problèmes de portabilité supplémentaires liés à des outils obscurs
syntax
constructions syntaxiques douteuses (par défaut)
unsupported
fonctionnalités non supportées ou incomplètes (par défaut)

-W comprend également :

all
activer tous les avertissements
none
désactiver tous les avertissements
no-CATÉGORIE
désactiver les avertissements dans CATEGORIE
error
traiter tous les avertissements activés comme des erreurs

Répertoires de bibliothèque :

-B, --prepend-include=RÉPERTOIRE
ajouter le répertoire RÉPERTOIRE au début du chemin de recherche
-I, --include=RÉPERTOIRE
ajouter le répertoire RÉPERTOIRE à la fin du chemin de recherche

Traçage :

-t, --trace=MACRO[:FORMAT]
rapporter la liste des appels à MACRO
-i, --initialization
traquer également le processus d'initialisation d'Autoconf

En mode traçage, aucun script de configuration n'est créé. FORMAT vaut par défaut '$f:$l:$n:$%'; voir 'autom4te --help' pour des informations sur FORMAT.
