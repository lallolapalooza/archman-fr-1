AUPARSE_INIT(3) API d'audit Linux AUPARSE_INIT(3)

NOM

auparse_init - initialise une instance de la librairie d'analyse d'audit

SYNTAXE

#include <auparse.h>

auparse_state_t * auparse_init(ausource_tsource,constvoid*"b);"

DESCRIPTION

auparse_init initialise une instance de la librairie d'analyse d'audit. La fonction retourne un pointeur opaque vers l'état interne de l'analyseur. Il est utilisé dans les appels ultérieurs à la librairie. La variable source détermine où la librairie cherche les données. Les valeurs légales peuvent être :

AUSOURCE_LOGS - utiliser les logs d'audit
AUSOURCE_FILE - utiliser un fichier
AUSOURCE_FILE_ARRAY - utiliser plusieurs fichiers
AUSOURCE_BUFFER - utiliser un tampon
AUSOURCE_BUFFER_ARRAY - utiliser un tableau de tampons
AUSOURCE_DESCRIPTOR - utiliser un descripteur particulier
AUSOURCE_FILE_POINTER - utiliser un pointeur FILE stdio
AUSOURCE_FEED - alimenter le parseur avec auparse_feed()

Le pointeur 'b' est utilisé pour définir le nom du fichier, le tableau de noms de fichiers, l'adresse du tampon, ou un tableau de pointeurs vers des tampons, ou le numéro de descripteur en fonction de la source donnée. Lorsque la source de données est un tableau de fichiers ou de tampons, vous créeriez un tableau de pointeurs avec le dernier étant un pointeur NULL. Les tampons doivent être terminés par NUL.

La structure de données retournée par auparse_init n'est pas thread-safe. Si vous avez besoin de l'utiliser dans un programme multithreadé, vous devrez ajouter un verrouillage autour de toute utilisation de la structure de données.

VALEUR DE RETOUR

Retourne un pointeur NULL si une erreur se produit ; sinon, la valeur de retour est un pointeur opaque vers l'état interne de l'analyseur.

VOIR AUSSI

auparse_reset(3), auparse_destroy(3). auparse_feed(3).
