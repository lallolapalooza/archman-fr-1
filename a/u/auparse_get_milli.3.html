AUPARSE_GET_MILLI(3) API d'audit Linux AUPARSE_GET_MILLI(3)

NOM

auparse_get_milli - obtenir la valeur en millisecondes de l'événement

SYNTAXE

#include <auparse.h>

unsigned int auparse_get_milli(const auparse_state_t *au);"

DESCRIPTION

auparse_get_milli récupère la valeur en millisecondes de l'événement actuel.

VALEUR DE RETOUR

Retourne 0 en cas d'erreur ; sinon, la valeur de la partie milliseconde du timestamp.

VOIR AUSSI

auparse_get_timestamp(3), auparse_get_time(3). auparse_get_node(3).
