AUDISP-REMOTE(8) Utilitaires d'administration système AUDISP-REMOTE(8)

NOM

audisp-remote - plugin pour la journalisation à distance

SYNOPSIS

audisp-remote

DESCRIPTION

audisp-remote est un plugin pour le dispatcher d'événements audit qui effectue la journalisation à distance vers un serveur de journalisation agrégé. Lorsque le plugin reçoit SIGUSR1, il écrit un rapport d'état dans remote.state.

CONSEILS

Si vous agrégez plusieurs machines, vous devriez modifier auditd.conf pour définir le nom_format sur quelque chose de significatif et le log_format sur enriched. De cette façon, vous pouvez savoir d'où provient l'événement et faire résoudre le nom d'utilisateur et les groupes localement avant qu'il ne soit envoyé hors de la machine.

SIGNAUX

SIGUSR1
Invite le programme audisp-remote à écrire un rapport d'état dans remote.state dans /run/audit. Le drapeau suspend indique si la journalisation a été suspendue ou non. Le drapeau remote_ended indique si la connexion a été interrompue par le serveur disant qu'il ne peut pas enregistrer les événements. Le drapeau transport_ok indique si la connexion au serveur distant est saine ou non. La queue_length indique le nombre d'enregistrements mis en file d'attente à envoyer au serveur distant. La max_queued_length montre la longueur maximale de la file d'attente depuis le démarrage. Le rapport enregistre également la consommation de mémoire glibc lorsqu'elle est disponible.
SIGUSR2
Invite le programme audisp-remote à reprendre la journalisation si elle a été suspendue en raison d'une erreur.

FICHIERS

/etc/audit/audisp-remote.conf /etc/audit/plugins.d/au-remote.conf /etc/audit/auditd.conf /run/audit/remote.state

VOIR AUSSI

auditd.conf(8), auditd-plugins(5), audisp-remote.conf(5).
