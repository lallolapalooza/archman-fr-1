AUTOSCAN(1) Commandes utilisateur AUTOSCAN(1)

NOM

autoscan - Générer un fichier configure.ac préliminaire

SYNTAXE

autoscan [OPTION]... [SRCDIR]

DESCRIPTION

Examine les fichiers sources dans l'arborescence des répertoires à partir de SRCDIR, ou le répertoire courant si aucun n'est donné. Recherche dans les fichiers sources les problèmes de portabilité courants, vérifie l'incomplétude de 'configure.ac', et crée un fichier 'configure.scan' qui est un 'configure.ac' préliminaire pour ce paquet.

-h, --help
imprimer cette aide, puis quitter
-V, --version
imprimer le numéro de version, puis quitter
-v, --verbose
rapporter verbosement le traitement
-d, --debug
ne pas supprimer les fichiers temporaires

Répertoires de bibliothèque :

-B, --prepend-include=DIR
ajouter le répertoire DIR au début du chemin de recherche
-I, --include=DIR
ajouter le répertoire DIR à la fin du chemin de recherche
