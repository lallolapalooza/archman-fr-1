auto-multiple-choice-imprime —

Imprimer les copies d'examen AMC
pour les distribuer aux candidats

SYNOP

SIS

auto-multiple-choice imprime --sujetsubject.pdf --fich-numsnumbers-file.txt --datadata-dir --methodemethod [arguments-de-localisation-d'impression.

..

DESCRIPTIO

N

La commande auto-multiple-choice imprime imprime les copies d'examen

sélectionnées.

Spécification du contenu à

imprimer

Les arguments suivants permettent de spécifier ce qui doit être imprimé

:

--sujet subject.

pdf
(Définit le fichier d'examen (créé par auto-multiple-choice-prepare(1))
.

--fich-nums numbers-file.

txt
Spécifie un fichier contenant les numéros des copies à imprimer (un par ligne). Si cet argument n'est pas fourni, toutes les copies seront
imprimées.

--data data-di

r
Spécifie le répertoire contenant les fichiers de données (voirauto-multiple-choice-meptex(1), etc.). La base de données de mise en page du répertoire de données est utilisée pour connaître les pages de début et de fin de chaque
copie.

--spli

t
Imprime les feuilles de réponses
séparées.

--answer-firs

t
Trie de sorte que la f
euille de réponses sépa
rée vienne en premier.

Spécification de la méthode

d'impression

Plusieurs méthodes d'impression sont définies

:
•«--methode CUPS » permet à auto-multiple-choice imprime d'imprimer sur une imprimante CUPS. Un job d'impression est envoyé par copie afin de permettre par exemple l'agrafage automatique. Pour cette méthode, utilisez les options suivantes :

--imprimante printe

r
Définit le nom de l'imprimante CUPS à
utiliser.

--options cups-option

s
Spécifie les options CUPS au formatopt1=value1,op
t2=val
ue2,...
•«--methode file » permet àauto-multiple-choice imprime d'écrire les copies dans des fichiers (un par copie).

--output filenam

e
Définit le nom du fichier de sortie. La séquence « %e » sera remplacée par le numéro de copie sur quatre chiffres.Si filename ne contient pas « %e »,
la chaîne « -%e.p
df » sera ajoutée.
•«--methode command » permet àauto-multiple-choice imprime d'utiliser la commande spécifiée pour chaque copie.

--print-command comman

d
Spécifie la commande à utiliser pour l'impression.La chaîne command est divisée en mots aux endroits où se trouvent des caractères d'espacement (même si d
es guillemets sont utilisés). La séquence « %f » se
ra remplacée par le nom du fichier PDF (contenant la
copie à imprimer) et « %e » par le numéro de copie.
