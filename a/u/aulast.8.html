AULAST(8) Utilitaires d'administration système AULAST(8)

NOM

aulast - un programme similaire à last

SYNOPSIS

aulast [ options ]

DESCRIPTION

aulast est un programme qui affiche une liste des derniers utilisateurs connectés, de manière similaire aux programmes last et lastb. Aulast parcourt les journaux d'audit ou le fichier de journal d'audit donné et affiche une liste de tous les utilisateurs connectés (et déconnectés) en fonction de la plage de temps dans les journaux d'audit. Des noms d'utilisateurs et de terminaux peuvent être spécifiés, auquel cas aulast n'affichera que les entrées correspondant aux arguments.

L'utilisateur fantôme reboot se connecte à chaque redémarrage du système. Ainsi, last reboot affichera un journal de tous les redémarrages depuis la création du fichier journal.

La principale différence que remarquera un utilisateur est que aulast affiche les événements du plus ancien au plus récent, tandis que last affiche les enregistrements du plus récent au plus ancien. De plus, le système d'audit n'est pas notifié chaque fois qu'un tty ou pty est alloué, vous pourriez donc ne pas voir autant d'enregistrements indiquant les utilisateurs et leurs tty.

OPTIONS

--bad
Rapporter les mauvaises connexions.
--debug
Afficher les messages de débogage sur stderr.
--extract
Écrire les enregistrements bruts d'audit utilisés pour créer le rapport affiché dans un fichier aulast.log dans le répertoire de travail courant.
-f fichier
Utiliser le fichier au lieu des journaux d'audit pour l'entrée.
--proof
Afficher les numéros de série des événements d'audit utilisés pour déterminer la ligne précédente du rapport. Un numéro de série de 0 est un espace réservé et non un numéro de série d'événement réel. Les numéros de série peuvent être utilisés pour examiner les enregistrements d'audit réels plus en détail. Une requête ausearch est également imprimée qui vous permettra de trouver les enregistrements d'audit associés à cette session.
--stdin
Prendre les enregistrements d'audit depuis stdin. Les événements d'audit doivent être au format brut.
--tty tty
Limiter le rapport à l'activité d'un tty spécifique. Les noms des ttys peuvent être abrégés. Par exemple, 0 est identique à tty0.
--user nom
Limiter le rapport à un utilisateur spécifique.

EXEMPLES

Pour voir les connexions de ce mois-ci
ausearch --start this-month --raw | aulast --stdin

VOIR AUSSI

last(1), lastb(1), ausearch(8), aureport(8).
