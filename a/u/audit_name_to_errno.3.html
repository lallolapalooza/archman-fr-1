AUDIT_NAME_TO_ERRNO(3) API d'audit Linux AUDIT_NAME_TO_ERRNO(3)

NOM

audit_name_to_errno, audit_errno_to_name - Convertir le nom d'errno et la valeur numérique d'errno l'un en l'autre

SYNTAXE

#include <libaudit.h>
int audit_name_to_errno(const char *error);
const char *audit_errno_to_name(int error);

DESCRIPTION

audit_name_to_errno() convertit le nom d'errno ("EPERM", "ENOENT", "ESRCH", etc.) en la valeur numérique d'errno (EPERM, ENOENT, ESRCH, etc.). error est le nom d'errno.

audit_errno_to_name() convertit la valeur numérique d'errno (EPERM, ENOENT, ESRCH, etc.) en le nom d'errno ("EPERM", "ENOENT", "ESRCH", etc.). error est la valeur numérique d'errno.

VALEUR DE RETOUR

audit_name_to_errno() retourne 0 si une erreur se produit ; sinon, la valeur de retour est la valeur numérique d'errno.

audit_errno_to_name() retourne NULL si une erreur se produit ; sinon, la valeur de retour est le nom d'errno.
