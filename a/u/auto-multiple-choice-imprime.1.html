NOM

auto-multiple-choice-imprime - imprime les feuilles de réponses à choix multiples d'AMC à distribuer aux élèves

SYNTAXE

auto-multiple-choice imprime --sujet sujet.pdf --fich-nums fichier-numeros.txt --data rep-data --methode methode [arguments-impression...]

DESCRIPTION

La commande auto-multiple-choice imprime imprime des copies sélectionnées d'une feuille de réponses à choix multiples AMC.

Ce qui doit être imprimé

Les arguments suivants décrivent ce qui doit être imprimé :

--sujet sujet.pdf

définit le fichier sujet (préparé par auto-multiple-choice-prepare(1)).

--fich-nums fichier-numeros.txt

donne un fichier où sont écrits les numéros des copies à imprimer (un numéro par ligne). Si cet argument n'est pas donné, toutes les copies seront imprimées.

--data rep-data

donne le répertoire où se trouvent les fichiers de données (voir par exemple auto-multiple-choice-meptex(1)). La base de données de disposition dans le répertoire de données est utilisée pour savoir à quelle page du fichier sujet chaque copie commence et se termine.

--split

demande d'imprimer les feuilles de réponses séparément.

--answer-first

demande de réordonner les pages de chaque copie pour que la feuille de réponses séparée apparaisse en premier.

Où imprimer

Plusieurs méthodes d'impression sont actuellement définies :

•avec "--methode CUPS", auto-multiple-choice imprime imprime vers une imprimante CUPS. Un travail d'impression est envoyé pour chaque copie, permettant par exemple d'utiliser l'agrafage. Utilisez les options suivantes avec cette méthode :

--imprimante imprimante

définit le nom de l'imprimante CUPS sur laquelle imprimer.

--options options-cups

donne les options CUPS, au format opt1=valeur1,opt2=valeur2,....
•avec "--methode file", auto-multiple-choice imprime génère les feuilles de réponses dans des fichiers (un pour chaque copie).

--output nom-fichier

définit le nom du fichier de sortie. La séquence '%e' sera remplacée par un numéro de copie à 4 chiffres. Si nom-fichier ne contient pas '%e', la chaîne '-%e.pdf' sera ajoutée à sa fin.
•avec "--methode command", auto-multiple-choice imprime utilisera une commande fournie pour chaque copie.

--print-command commande

donne la commande à utiliser pour l'impression. La chaîne commande sera divisée à chaque espace (même en utilisant des guillemets...). La séquence '%f' sera remplacée par un nom de fichier PDF (contenant la copie à imprimer), et '%e' sera remplacé par le numéro de la copie.

Autres options

Autres options disponibles :

--extract-with commande

donne la commande à utiliser pour extraire les pages du sujet PDF. Actuellement, pdftk, gs et qpdf sont disponibles. La valeur par défaut est pdftk, mais qpdf puis gs seront utilisés si la commande pdftk n'est pas installée.
