Authen::SASL::Perl::CRAM_MD5(3) Documentation Perl fournie par l'utilisateur Authen::SASL::Perl::CRAM_MD5(3)

NOM

Authen::SASL::Perl::CRAM_MD5 - (OBSOLÈTE) Classe d'authentification CRAM MD5

VERSION

version 2.1900

SYNOPSIS

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'CRAM-MD5',
  callback  => {
    user => $user,
    pass => $pass
  },
);

DESCRIPTION

Cette méthode implémente la partie client de l'algorithme CRAM-MD5 SASL, tel que décrit dans la RFC 2195 resp. dans le brouillon IETF draft-ietf-sasl-crammd5-XX.txt.

Veuillez noter que ce mécanisme a été déplacé dans la section d'utilisation "LIMITÉE" du registre des mécanismes https://www.iana.org/assignments/sasl-mechanisms/sasl-mechanisms.xhtml et est effectivement obsolète selon la RFC 8314 https://www.rfc-editor.org/rfc/rfc8314.html (voir section 5; considérations de sécurité).

CALLBACK

Les callbacks utilisés sont :

user
Le nom d'utilisateur à utiliser pour l'authentification
pass
Le mot de passe de l'utilisateur à utiliser pour l'authentification

VOIR AUSSI

Authen::SASL, Authen::SASL::Perl
