AUDIT_ENCODE_NV_STRING(3) API d'audit Linux AUDIT_ENCODE_NV_STRING(3)

NOM

audit_encode_nv_string - encode une paire nom/valeur dans une chaîne

SYNOPIS

#include <libaudit.h>
char *audit_encode_nv_string(const char *name, const char *value, unsigned int vlen)"

DESCRIPTION

Cette fonction est utilisée pour encoder une paire nom/valeur. Elle doit être utilisée sur tout champ consigné qui contient potentiellement un espace, un guillemet double ou un caractère de contrôle. Toute valeur contenant ces caractères doit être spécialement encodée pour que la bibliothèque auparse puisse correctement traiter la valeur. La méthode d'encodage est conçue pour empêcher les attaques par injection de journal où des valeurs malveillantes pourraient provoquer des erreurs d'analyse.

Pour utiliser cette fonction, passez la chaîne name et la chaîne value comme arguments respectifs. Si la valeur est susceptible de contenir un octet NUL intégré, vous devrez passer une longueur en octets dans vlen qui indique la taille de la valeur. Sinon, vous pouvez passer 0 pour vlen et la fonction utilisera simplement strlen sur le pointeur value. Soyez également conscient que le nom du champ amènera auparse à effectuer certaines actions lors de l'interprétation de la valeur. Si le nom est uid, une valeur d'identifiant d'utilisateur en décimal est attendue. Assurez-vous que des noms bien connus sont utilisés pour leur objectif prévu ou qu'il n'y a aucune chance de collision de nom avec quelque chose de nouveau.

VALEUR RENVOYÉE

Renvoie une chaîne nouvellement allouée avec malloc que l'appelant doit libérer, ou NULL en cas d'erreur.
