AUPARSE_GET_NODE(3) API Audit Linux AUPARSE_GET_NODE(3)

NOM

auparse_get_node - obtenir le nom du nœud de la machine de l'événement

SYNTAXE

#include <auparse.h>

const char * auparse_get_node(const auparse_state_t *au);"

DESCRIPTION

auparse_get_node récupère le nom du nœud de la machine s'il existe dans l'événement d'audit à partir de la structure de données d'horodatage de l'événement courant. Tous les enregistrements n'ont pas de noms de nœud car il s'agit d'une option configurable par l'administrateur.

VALEUR DE RETOUR

Retourne une copie du nom du nœud ou NULL s'il n'existe pas ou s'il y a eu une erreur. L'appelant doit libérer la chaîne.

VOIR AUSSI

auparse_get_timestamp(3), auparse_get_time(3), auparse_get_milli(3). auparse_get_serial(3).
