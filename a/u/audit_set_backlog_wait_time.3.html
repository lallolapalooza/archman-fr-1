NOM

audit_set_backlog_wait_time - Définir le temps d'attente du tampon d'audit

SYNTAXE

#include <libaudit.h>
int audit_set_backlog_wait_time(int fd, uint32_t bwt);"

DESCRIPTION

audit_set_backlog_wait_time définit le temps que le noyau attendra avant de tenter d'envoyer plus d'événements d'audit sur le descripteur fourni dans fd. Le paramètre bwt spécifie le délai en jiffies avant de tenter de transférer plus d'événements lorsque la limite du tampon est atteinte. Cela donne au démon d'audit une chance de vider la file d'attente du noyau. La valeur par défaut est 60000 ou le réglage 60 * HZ dans le noyau.

VALEUR DE RETOUR

La valeur de retour est <= 0 en cas d'erreur, sinon c'est l'identifiant de séquence netlink. Cette fonction peut rencontrer n'importe quelle erreur que sendto pourrait rencontrer.

VOIR AUSSI

audit_set_backlog_limit(3), audit_open(3), auditd(8), auditctl(8).
