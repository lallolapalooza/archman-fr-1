AUDISP-SYSLOG(8) Utilitaires d'administration système AUDISP-SYSLOG(8)

NOM

audisp-syslog - module pour pousser les événements d'audit vers syslog

SYNOPSIS

audisp-syslog [ OPTIONS ]

DESCRIPTION

audisp-syslog est un module pour le répartiteur d'événements d'audit qui renvoie les événements d'audit vers syslog. Il peut recevoir trois options : une qui est la facilité syslog, une autre qui est le niveau syslog avec lequel tous les événements sont enregistrés, et une troisième qui détermine si les événements doivent être interprétés. Les facilités valides sont LOG_LOCAL0 à 7, LOG_AUTH, LOG_AUTHPRIV, LOG_DAEMON, LOG_SYSLOG et LOG_USER. Les niveaux valides sont LOG_DEBUG à LOG_EMERG. La définition de ces options se fait dans le fichier /etc/audit/syslog.conf sur la ligne args.

Si l'on souhaite que les événements soient interprétés, ajouter le mot interpret sur la ligne args. Cela entraînera l'interprétation de tous les événements. L'inconvénient de cette approche est que les analyseurs naïfs peuvent être trompés par un adversaire qui a la capacité de nommer des fichiers, des processus ou d'autres objets contrôlés par l'utilisateur.

Si vous agrégez plusieurs machines, vous devriez modifier auditd.conf pour définir name_format sur quelque chose de significatif et log_format sur enriched. De cette façon, vous pourrez savoir d'où provient l'événement et faire résoudre le nom d'utilisateur et les groupes localement avant qu'il ne soit envoyé hors de la machine.

FICHIERS

/etc/audit/plugins/syslog.conf /etc/audit/auditd.conf

VOIR AUSSI

auditd.conf(8), auditd-plugins(5), syslog(3).
