AUDIT_NAME_TO_ACTION(3) API d'audit Linux AUDIT_NAME_TO_ACTION(3)

NOM

audit_name_to_action, audit_action_to_name - Convertir le nom d'action en valeur numérique d'action et vice versa

SYNTAXE

#include <libaudit.h>
int audit_name_to_action(const char *action);
const char *audit_action_to_name(int action);

DESCRIPTION

audit_name_to_action() convertit le nom d'action ("never", "possible", "always") en la valeur numérique d'action (AUDIT_NEVER, AUDIT_POSSIBLE, AUDIT_ALWAYS). action est le nom d'action.

audit_action_to_name() convertit la valeur numérique d'action (AUDIT_NEVER, AUDIT_POSSIBLE, AUDIT_ALWAYS) en le nom d'action ("never", "possible", "always"). action est la valeur numérique d'action.

VALEUR DE RETOUR

audit_name_to_action() retourne -1 si une erreur se produit ; sinon, la valeur de retour est la valeur numérique d'action.

audit_action_to_name() retourne NULL si une erreur se produit ; sinon, la valeur de retour est le nom d'action.
