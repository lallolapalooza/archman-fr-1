AUDIT_SET_BACKLOG_LIMIT(3) Manuel des fonctions de bibliothèque AUDIT_SET_BACKLOG_LIMIT(3)

NOM

audit_set_backlog_limit - Définir la limite de la file d'attente d'audit

SYNTAXE

#include <libaudit.h>
int audit_set_backlog_limit(int fd, uint32_t limit);"

DESCRIPTION

audit_set_backlog_limit définit la longueur de la file d'attente pour les événements d'audit en attente de transfert sur le descripteur donné dans fd. L'argument limit spécifie combien d'événements peuvent être mis en file d'attente. La valeur par défaut est 64, ce qui peut potentiellement être dépassé par des rafales d'activité. Lorsque la limite de la file d'attente est atteinte, le noyau consulte le `failure_flag` pour voir quelle action entreprendre.

VALEUR DE RETOUR

La valeur de retour est <= 0 en cas d'erreur, sinon c'est le numéro d'identification de séquence netlink. Cette fonction peut rencontrer n'importe quelle erreur que `sendto` pourrait rencontrer.

VOIR AUSSI

audit_set_failure(3), audit_open(3), auditd(8), auditctl(8).
