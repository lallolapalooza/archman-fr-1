NOM

audit_reset_backlog_wait_time_actual - réinitialiser le compteur réel du temps d'attente de la file d'attente

SYNTAXE

#include <libaudit.h>

int audit_reset_backlog_wait_time_actual(int fd);

DESCRIPTION

audit_reset_backlog_wait_time_actual() réinitialise le total cumulé par le noyau du temps pendant lequel les appels système ont attendu de l'espace dans la file d'attente des événements d'audit. Le paramètre fd doit être un socket netlink d'audit ouvert. Cet appel est utile lorsque les administrateurs activent l'attente de la file d'attente via l'option audit_set_backlog_wait_time(3) pour préserver les événements dans des situations de mémoire restreinte. La réinitialisation périodique du compteur permet de détecter une nouvelle attente de la file d'attente après avoir modifié la taille de la file d'attente ou le temps d'attente. Le noyau doit prendre en charge le champ AUDIT_STATUS_BACKLOG_WAIT_TIME_ACTUAL pour que cet appel réussisse.

VALEUR DE RETOUR

La valeur de retour est <= 0 en cas d'erreur, sinon c'est l'identifiant de séquence netlink.

VOIR AUSSI

audit_set_backlog_wait_time(3), audit_open(3), auditctl(8).
