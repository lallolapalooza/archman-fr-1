Il est préférable que le script ou le processus d'installation qui invoque "AutoSplit" ait créé le chemin complet du répertoire à l'avance. Cet avertissement peut indiquer que le module est divisé dans un chemin incorrect. "AutoSplit" avertira l'utilisateur de toutes les

Des
