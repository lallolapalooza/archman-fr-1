NOM

auto-multiple-choice-note - calcule les notes après capture des données par scan pour les examens à choix multiples AMC.

SYNTAXE

auto-multiple-choice note --data répertoire-données-projet [--seuil seuil] [--grain granularité] [--arrondi arrondi] [--notemin min] [--notemax max] [--no-plafond | --plafond]

DESCRIPTION

La commande auto-multiple-choice note calcule les notes de tous les étudiants à partir de la stratégie de correction extraite du fichier source LaTeX par auto-multiple-choice-prepare(1) et des rapports de capture de données réalisés par auto-multiple-choice-analyse(1).

--data répertoire-données-projet

indique le répertoire où se trouvent les fichiers de données (voir par exemple auto-multiple-choice-meptex(1)).

--seuil seuil

indique le seuil de ratio de noir pour décider si une case est cochée ou non. Pour décider si une case est cochée ou non, auto-multiple-choice note compare le ratio de noir (nombre de pixels noirs sur le nombre total de pixels) à seuil. Si le ratio de noir est supérieur à seuil, la case est déclarée comme cochée. Les valeurs standard peuvent être de 0.15 pour la mise en page standard, ou 0.5 pour une feuille de réponse séparée (dans ce dernier cas, des lettres sont dessinées dans les cases, et les étudiants sont invités à remplir entièrement les cases).

--seuil-up seuil_supérieur

indique le seuil de ratio de noir au-dessus duquel une case est considérée comme non cochée. Vous pouvez fixer cette valeur à (par exemple) 0.6 pour permettre aux étudiants d'annuler une case cochée en la remplissant complètement : si le ratio de noir est compris entre seuil et seuil_supérieur, la case est considérée comme cochée, mais si le ratio de noir est supérieur à seuil_supérieur (par exemple, lorsqu'elle est remplie), la case est considérée comme non cochée. La valeur par défaut est 1.0, de sorte que cette fonctionnalité est désactivée.

--grain granularité --arrondi arrondi

demande que les notes soient arrondies à un multiple de granularité. Si arrondi est 'i', l'arrondi est fait par défaut vers le bas (comme avec floor(3)). Si arrondi est 'n', l'arrondi est fait au multiple le plus proche de granularité. Si arrondi est 's', l'arrondi est fait par défaut vers le haut (comme avec ceil(3)). Par exemple, avec les options "--grain 0.25 --arrondi s", la note 6.285 est arrondie à 6.5.

--notemin min

avec cette option, toutes les notes inférieures à min seront remplacées par min.

--notemax max

indique la note à associer à une copie où toutes les réponses sont correctes. Si elle n'est pas utilisée, les notes ne sont pas mises à l'échelle.

--plafond

avec cette option, toutes les notes supérieures à max seront remplacées par max.

--debug fichier.log

indique un fichier à remplir avec des informations de débogage.

--postcorrect-student e --postcorrect-copy c

demande une post-correction à partir de la feuille de réponses complétée identifiée par les numéros d'étudiant et de copie. En mode post-correction, les réponses correctes ne sont pas extraites du fichier source LaTeX, mais prises à partir des réponses données sur cette feuille.
