AUPARSE_SET_ESCAPE_MODE(3) API d'audit Linux AUPARSE_SET_ESCAPE_MODE(3)

NOM

auparse_set_escape_mode - choisir la méthode d'échappement

SYNTAXE

#include <auparse.h>

void auparse_set_escape_mode(auparse_state_t *au,auparse_esc_t"mode);"

DESCRIPTION

auparse_set_escape_mode est utilisée pour définir la méthode d'échappement qui sera utilisée pour afficher le texte interprété. Les choix pour la variable mode sont :

AUPARSE_ESC_RAW
Aucun échappement de quelque sorte que ce soit n'est effectué.
AUPARSE_ESC_TTY
Les caractères de contrôle TTY sont échappés afin qu'ils soient inoffensifs à afficher sur un terminal. Lorsqu'un caractère de contrôle est trouvé, il est affiché sous forme de nombre octal. C'est le mode par défaut avec lequel la bibliothèque auparse est initialisée.
AUPARSE_ESC_SHELL
En plus d'échapper les caractères de contrôle, cela échappera certains caractères qui peuvent causer des problèmes lorsqu'ils sont utilisés avec des scripts shell. Tous les caractères de contrôle échappés sont affichés sous forme de nombres octaux. Les autres caractères échappés sont précédés d'un antislash. Les caractères supplémentaires qu'il échappe sont : " ' ` $ \
AUPARSE_ESC_SHELL_QUOTE
Similaire à AUPARSE_ESC_SHELL mais étend l'ensemble de caractères pour inclure les opérateurs shell. Tous les caractères de contrôle échappés sont affichés sous forme de nombres octaux. Les autres caractères échappés sont précédés d'un antislash. Les caractères supplémentaires qu'il échappe incluent : ; '  " ` # $ & * ? [ ] < > { } \

VALEUR DE RETOUR

Aucune
