AUBIO(1) Manuel utilisateur aubio AUBIO(1)

NOM

aubio - un outil en ligne de commande pour extraire des informations à partir de fichiers sonores

SYNTAXE

aubio [-h] [-V] <commande> ...

COMMANDES

La syntaxe générale est "aubio <commande> <fichier_sonore> [options]". Les commandes suivantes sont disponibles :

onset
obtenir les temps d'attaque
pitch
extraire la fréquence fondamentale
beat
obtenir les emplacements des temps forts (beats)
tempo
obtenir le tempo général en bpm
notes
obtenir des notes de type midi
mfcc
extraire les coefficients cepstraux de fréquence Mel
melbands
extraire les énergies de fréquence Mel par bande

Pour obtenir la liste des commandes disponibles, utilisez "aubio -h". Pour plus d'informations sur chaque commande, utilisez "aubio <commande> --help".

OPTIONS GÉNÉRALES

Ces options peuvent être utilisées avant qu'une commande ne soit spécifiée.

-h, --help
afficher le message d'aide et quitter
-V, --version
afficher la version

OPTIONS COMMUNES

Les options suivantes peuvent être utilisées avec toutes les commandes :

<uri_source>, -i <uri_source>, --input <uri_source>
fichier sonore d'entrée à analyser (requis)
-r <freq>, --samplerate <freq>
fréquence d'échantillonnage à laquelle le fichier doit être représenté (par défaut : 0, c'est-à-dire la fréquence d'échantillonnage du son d'entrée)
-H <taille>, --hopsize <taille>
taille de saut, nombre d'échantillons entre deux analyses consécutives (par défaut : 256)
-B <taille>, --bufsize <taille>
taille du tampon, nombre d'échantillons utilisés pour chaque analyse (par ex. longueur FFT, par défaut : 512)
-h, --help
afficher le message d'aide et quitter
-T format, --time-format format
sélectionner le format des valeurs temporelles de sortie (échantillons, ms, secondes) (par défaut : secondes)
-v, --verbose
être verbeux (incrémenter la verbosité de 1, par défaut : 1)
-q, --quiet
être silencieux (définir la verbosité à 0)

ONSET

Les options supplémentaires suivantes peuvent être utilisées avec la sous-commande "onset".

-m <méthode>, --method <méthode>
fonction de nouveauté d'attaque <default|energy|hfc|complex|phase|specdiff|kl|mkl|specflux> (par défaut : default)
-t <seuil>, --threshold <seuil>
seuil (par défaut : non défini)
-s <valeur>, --silence <valeur>
seuil de silence, en dB (par défaut : -70)
-M <valeur>, --minioi <valeur>
intervalle inter-attaque minimum (par défaut : 12ms)

PITCH

Les options supplémentaires suivantes peuvent être utilisées avec la sous-commande "pitch".

-m <méthode>, --method <méthode>
méthode de détection de hauteur (pitch) <default|yinfft|yin|mcomb|fcomb|schmitt> (par défaut : default, c'est-à-dire yinfft)
-t <seuil>, --threshold <seuil>
tolérance (par défaut : non défini)
-s <valeur>, --silence <valeur>
seuil de silence, en dB (par défaut : -70)

La taille de tampon par défaut pour l'algorithme de beat est 2048. Le saut par défaut est de 256.

BEAT

La commande "beat" accepte toutes les options communes et aucune option supplémentaire.

La taille de tampon par défaut pour l'algorithme de beat est 1024. Le saut par défaut est de 512.

TEMPO

La commande "tempo" accepte toutes les options communes et aucune option supplémentaire.

La taille de tampon par défaut pour l'algorithme de beat est 1024. Le saut par défaut est de 512.

NOTES

Les options supplémentaires suivantes peuvent être utilisées avec la sous-commande "notes".

-s <valeur>, --silence <valeur>
seuil de silence, en dB (par défaut : -70)
-d <valeur>, --release-drop <valeur>
niveau de chute à la fin (release), en dB. Si le niveau chute plus que ce montant depuis que la dernière note a commencé, la note sera désactivée (par défaut : 10).

MFCC

La commande "mfcc" accepte toutes les options communes et aucune option supplémentaire.

MELBANDS

La commande "melbands" accepte toutes les options communes et aucune option supplémentaire.

EXEMPLES

Extraire les attaques en utilisant un intervalle inter-attaque minimum de 30ms :

    aubio onset /chemin/vers/fichier_entree -M 30ms
Extraire la hauteur avec la méthode "mcomb" et un seuil de silence de -90dB : 
    aubio pitch /chemin/vers/fichier_entree -m mcomb -s -90.0
Extraire les MFCC en utilisant l'implémentation standard de Slaney : 
    aubio mfcc /chemin/vers/fichier_entree -r 44100
