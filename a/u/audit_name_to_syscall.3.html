AUDIT_NAME_TO_SYSCALL(3) API d'audit Linux AUDIT_NAME_TO_SYSCALL(3)

NOM

audit_name_to_syscall - Convertit le nom d'un appel système en sa valeur numérique

SYNTAXE

#include <libaudit.h>
int audit_name_to_syscall(const char *sc, int machine);

DESCRIPTION

audit_name_to_syscall() convertit le nom d'un appel système en sa valeur numérique. sc est le nom de l'appel système. machine est la valeur de l'énumération du type de machine défini dans machine_t. machine peut être obtenu en appelant audit_detect_machine(3).

VALEUR DE RETOUR

Retourne -1 en cas d'erreur ; sinon, la valeur de retour est la valeur numérique de l'appel système.

VOIR AUSSI

audit_syscall_to_name(3), audit_detect_machine(3).
