NOM

auto-multiple-choice-getimages - Prépare les images numérisées pour auto-multiple-choice-analyse(1).

RÉSUMÉ

auto-multiple-choice getimages [--copy-to project-scans-dir] [--vector-density density] --list list-file [scan-files...]

DESCRIPTION

La commande auto-multiple-choice getimages prépare les images numérisées avant de les envoyer à auto-multiple-choice-analyse(1) :

• Les fichiers constitués de plusieurs images sont séparés en fichiers par page.
• Les images vectorielles (PDF, EPS, etc.) sont converties en images matricielles.

Les images d'entrée peuvent être spécifiées comme arguments de la commande auto-multiple-choice getimages, ainsi que comme fichiers contenant les chemins de tous les fichiers de numérisation.

--list list-file

Spécifie le nom d'un fichier contenant les chemins des fichiers de numérisation (un par ligne). Après traitement, le contenu de ce fichier est ignoré et les chemins des fichiers de numérisation sont écrits de telle sorte que le même chemin soit passé à l'option --list-fichiers de auto-multiple-choice analyse.

--copy-to project-scans-dir

Copie tous les fichiers de numérisation dans le répertoire spécifié.

--vector-density density

Définit la résolution lors de la conversion des images vectorielles en images matricielles. La valeur par défaut est 300.
