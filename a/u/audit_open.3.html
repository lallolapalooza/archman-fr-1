AUDIT_OPEN(3) API d'audit Linux AUDIT_OPEN(3)

NOM

audit_open - Ouvre une connexion de socket netlink d'audit

SYNTAXE

#include <libaudit.h>
int audit_open(void);

DESCRIPTION

audit_open crée un socket NETLINK_AUDIT pour la communication avec la partie noyau du sous-système d'audit Linux. Le système d'audit utilise la fonctionnalité ACK de netlink. Cela signifie que chaque message envoyé au noyau retournera un paquet de statut netlink, même si l'opération réussit.

VALEUR DE RETOUR

Retourne -1 en cas d'erreur ; sinon, la valeur de retour est un descripteur référençant le socket.

ERREURS

La fonction audit_open() peut échouer et définir errno pour toutes les erreurs spécifiées pour les routines socket(2) et fcntl(2).

VOIR AUSSI

netlink(7).
