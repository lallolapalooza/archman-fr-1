ausearch_add_item(3)

AUSEARCH_ADD_ITEM(3) API de journalisation Linux AUSEARCH_ADD_ITEM(3)

NOM

ausearch_add_item - construire une règle de recherche

SYNOPSIS

#include <auparse.h>
int ausearch_add_item(auparse_state_t *au, const char *field, const char *op, const char *value, ausearch_rule_t how);"

DESCRIPTION

ausearch_add_item ajoute une condition de recherche à l'expression de recherche d'audit actuelle. Les conditions de recherche peuvent ensuite être utilisées pour parcourir les journaux, les fichiers ou les tampons à la recherche de quelque chose d'intéressant. La valeur de field est le nom du champ pour lequel value sera vérifié. La variable op décrit le type de vérification à effectuer. Les valeurs légales pour op sont :

exists

vérifie simplement que le nom du champ existe
= =

localise le nom du champ et vérifie que la valeur qui lui est associée est égale à la valeur donnée dans cette règle.
!=

localise le nom du champ et vérifie que la valeur qui lui est associée N'EST PAS égale à la valeur donnée dans cette règle.

Le paramètre value est comparé à la valeur du champ non interprétée. Si vous essayez de faire correspondre un champ dont le type est AUPARSE_TYPE_ESCAPED, vous voudrez utiliser la fonction ausearch_add_interpreted_item() à la place.

La valeur how détermine comment cette condition de recherche affectera l'expression de recherche existante si une est déjà définie. Les valeurs possibles sont :

AUSEARCH_RULE_CLEAR
Efface l'expression de recherche actuelle, le cas échéant, et utilise uniquement cette condition de recherche.
AUSEARCH_RULE_OR
Si une expression de recherche E est déjà configurée, remplacez-la par (E || cette_condition_de_recherche).
AUSEARCH_RULE_AND
Si une expression de recherche E est déjà configurée, remplacez-la par (E && cette_condition_de_recherche).

VALEUR DE RETOUR

Retourne -1 en cas d'erreur ; sinon, 0 pour succès.
