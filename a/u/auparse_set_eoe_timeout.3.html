NOM

auparse_set_eoe_timeout - définit la valeur de délai d'attente de fin d'événement

SYNOPSIS

#include <auparse.h>

int auparse_set_eoe_timeout(time_tnew_tmo);"

DESCRIPTION

auparse_set_eoe_timeout est utilisé pour définir la valeur du délai d'attente de fin d'événement (en secondes). La valeur doit être un entier positif. Si cette fonction est appelée, elle remplace tout paramètre dans /etc/auditd.conf. La fonction doit être appelée après l'appel à la fonction auparse_init().

Pour plus de détails sur le délai d'attente, voir la description de l'élément de configuration end_of_event_timeout dans auditd.conf(5).

VALEUR DE RETOUR

Retourne -1 en cas d'erreur ; sinon, 0 en cas de succès.

VOIR AUSSI

auparse_init(3). auditd.conf(8).
