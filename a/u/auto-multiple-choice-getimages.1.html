NOM

auto-multiple-choice-getimages - prépare les images numérisées avant de les envoyer à auto-multiple-choice-analyse(1) pour analyse

SYNOPIS

auto-multiple-choice getimages [--copy-to projet-scans-dir] [--vector-density density] --list liste-fichier [fichiers-scan...]

DESCRIPTION

La commande auto-multiple-choice getimages prépare les fichiers numérisés avant de les envoyer à auto-multiple-choice-analyse(1) :

•les fichiers images multipages sont divisés pour obtenir un fichier par page.
•les images vectorielles (comme PDF, EPS) sont converties en images bitmap.

Les images d'entrée peuvent être fournies soit comme arguments à auto-multiple-choice getimages, soit comme nom d'un fichier contenant tous les chemins des fichiers numérisés.

--list liste-fichier

donne le nom du fichier qui contient éventuellement (un par ligne) les chemins des fichiers numérisés. Ce fichier sera vidé et rempli avec les chemins des fichiers numérisés après traitement, de sorte que le même chemin puisse être passé à auto-multiple-choice analyse comme valeur de l'option --list-fichiers.

--copy-to projet-scans-dir

donne un répertoire où copier tous les fichiers numérisés.

--vector-density densité

définit la densité utilisée pour convertir les scans graphiques vectoriels en fichiers bitmap. La valeur par défaut est 300.
