SYNOPSIS AND DESCRIPTION


These routines are part of the Network Services Remote Procedure Call (RPC) library.
    The RPC model allows a client machine to call procedures on a remote server machine.
    The XDR (External Data Representation) library is used to convert data structures
    into a machine-independent format for transmission across the network.
    The pmap routines interface with the portmapper, which maps RPC
    program numbers to the network addresses where the corresponding services can be found.


The RPC library provides routines for implementing both clients and servers.
    The routines described here are typically used by RPC clients or by RPC servers
    that do not use rpcgen(1) to generate their
    dispatching code.


void auth_destroy(AUTH *auth);



  

  
Destroys the authentication handle.




AUTH *authnone_create(void);



  

  
Creates a null authentication handle. This is used for RPC services that
      do not require authentication.




AUTH *authunix_create(const char *host, uid_t uid, gid_t gid, int len, gid_t *groups);



  

  
Creates an authentication handle for UNIX domain authentication. The
      parameters specify the client host name, user ID, primary group ID, the
      number of supplementary groups, and the supplementary group IDs.

Creates a default UNIX domain authentication handle using the user ID,
      group ID, and supplementary group IDs of the current process.

Creates a client handle for communication with an RPC program identified by
      prog and vers on the specified host using the network
      type specified by nettype. Common network types include
      "tcp" and "udp".




CLIENT *clntraw_create(const char *raddr);



  

  
Creates a raw client handle. This is used for testing RPC services.

Creates a TCP client handle. The parameters are similar to
      clnt_create, with the addition of sockets and buffer
      sizes.

      parameter specifies the timeout for retransmissions.

      for retransmissions.

Calls an RPC procedure proc on the remote server. The arguments are
      encoded using xdr_arg and argp, and the results are decoded using
      xdr_res and resp. The call will block for at most
      wait_time.

      specifies the command, and data provides any associated data.

pmap_getmaps, pmap_getport, pmap_rmtcall, pmap_set, pmap_unset, callrpc, registerrpc




  

  
These routines provide an interface to the portmapper service.
      pmap_getmaps retrieves a list of all registered port
      mappings.
      pmap_getport retrieves the port number for a given
      RPC program and version.
      pmap_rmtcall makes a remote procedure call to an
      unspecified program.
      pmap_set registers an RPC program and version with the
      portmapper.
      pmap_unset unregisters an RPC program and version.
      callrpc is a high-level routine that makes an RPC
      call to a specified host, program, version, and procedure.
      registerrpc is a high-level routine for registering an
      RPC service with the portmapper.
