AUPARSE_GET_TIMESTAMP(3) API d'audit Linux AUPARSE_GET_TIMESTAMP(3)

NOM

auparse_get_timestamp - accéder à l'horodatage de l'événement

SYNTAXE

#include <auparse.h>

const au_event_t * auparse_get_timestamp(const auparse_state_t *au);"

DESCRIPTION

auparse_get_timestamp fournit une fonction d'accès à la structure de données d'horodatage de l'événement. La structure de données est la suivante :

typedef struct
{
        time_t sec;             // Secondes de l'événement
        unsigned int milli;     // millisecondes de l'horodatage
        unsigned long serial;   // Numéro de série de l'événement
        const char *host;       // Nom de nœud de la machine
} au_event_t;

VALEUR RENVOYÉE

Renvoie NULL en cas d'erreur ; sinon, un pointeur valide vers les données.

VOIR AUSSI

auparse_get_time(3), auparse_get_milli(3), auparse_get_serial(3), auparse_get_node(3), auparse_timestamp_compare(3).
