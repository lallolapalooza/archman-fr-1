AUPLUGIN_FGETS(3) API d'audit Linux AUPLUGIN_FGETS(3)

NOM

auplugin_fgets, auplugin_fgets_more, auplugin_fgets_eof, auplugin_fgets_clear, auplugin_setvbuf, auplugin_setvbuf_r - Aide à la lecture en tampon de lignes

SYNTAXE

#include <auplugin.h>

int auplugin_fgets(char *buf, size_t blen, int fd);
int auplugin_fgets_more(size_t blen);
int auplugin_fgets_eof(void);
void auplugin_fgets_clear(void);
int auplugin_setvbuf(void *buf, size_t buff_size, enum auplugin_mem how);
int auplugin_setvbuf_r(auplugin_fgets_state_t *st, void *buf, size_t buff_size, enum auplugin_mem how);

DESCRIPTION

auplugin_fgets lit depuis le descripteur de fichier fd dans buf jusqu'à blen octets ou jusqu'à la prochaine nouvelle ligne. Le texte est accumulé entre les appels dans un tampon interne afin que des lignes complètes puissent être retournées. La chaîne est terminée par un caractère NUL.

auplugin_fgets_more vérifie si le tampon contient une nouvelle ligne ou au moins blen - 1 octets.

auplugin_fgets_eof indique si la fin du fichier a été atteinte sur fd.

auplugin_fgets_clear réinitialise le tampon interne et l'état de fin de fichier, en ignorant tout texte stocké. Lorsque le type de mémoire est MEM_MMAP_FILE, le tampon est rembobiné au début, rendant l'ensemble du fichier à nouveau disponible.

auplugin_setvbuf pointe le tampon interne vers buf et définit la manière dont il sera libéré lorsque auplugin_fgets_destroy sera appelé. Le paramètre how doit être l'une des valeurs suivantes : MEM_SELF_MANAGED, MEM_MALLOC, MEM_MMAP, ou MEM_MMAP_FILE. La valeur par défaut est MEM_SELF_MANAGED, ce qui signifie qu'aucune action n'est effectuée sur le bloc mémoire. Lorsque MEM_MMAP_FILE est utilisé, le tampon est traité comme un tampon pré-chargé (le fichier entier) et aucune lecture ne sera effectuée sur le descripteur fourni à auplugin_fgets_r. La forme réentrante auplugin_setvbuf_r opère sur un handle d'état explicite.

Ces fonctions maintiennent un état statique et ne sont donc pas thread-safe.

VALEUR DE RETOUR

auplugin_fgets retourne -1 en cas d'erreur, 0 lorsqu'aucune donnée n'est disponible, ou le nombre de caractères copiés sinon.

auplugin_fgets_more et auplugin_fgets_eof retournent 1 pour vrai et 0 pour faux.

auplugin_fgets_clear ne retourne aucune valeur.

auplugin_setvbuf retourne 0 en cas de succès et 1 en cas d'échec.

CONTEXTE


La raison pour laquelle cette famille de fonctions a été créée est que, dans les plugins auditd, le flux d'événements est l'entrée standard, qui est le descripteur 0. Un schéma typique consiste à appeler select, poll ou epoll pour attendre l'arrivée d'un enregistrement. Dès qu'il arrive, vous devez le lire. Si vous utilisez fgets, vous rencontrerez de gros problèmes car vous ne pouvez pas mélanger les descripteurs de bas niveau avec des constructions de haut niveau comme la structure FILE. Cette famille de fonctions vous permet de travailler correctement en utilisant uniquement des descripteurs, mais avec la commodité de fgets.
