AUPARSE_GET_NUM_FIELDS(3) API d'audit Linux AUPARSE_GET_NUM_FIELDS(3)

NOM

auparse_get_num_fields - obtenir le nombre de champs

SYNOPSIS

#include <auparse.h>

unsigned int auparse_get_num_fields(const auparse_state_t *au);"

DESCRIPTION

auparse_get_num_fields obtient le nombre de champs dans l'enregistrement actuel de l'événement actuel.

VALEUR DE RETOUR

Retourne 0 en cas d'erreur ; sinon, le nombre de champs.

VOIR AUSSI

auparse_next_record(3).
