varName d>Ceci est une procédure de recherche standard à utiliser par les extensions lors de leur initialisation. Elles appellent cette procédure pour rechercher leur bibliothèque de scripts dans plusieurs répertoires standard. Le dernier composant du nom du répertoire de la bibliothèque est normalement nomdebaseversion (par ex., tk8.0), mais il peut être « library » dans les hiérarchies de compilation. Le fichier initScript sera chargé dans l'interpréteur une fois qu'il est trouvé. Le répertoire dans lequel ce fichier est trouvé est stocké dans la variable globale varName. Si cette variable est déjà définie (par ex., par du code C lors de l'initialisation de l'application), alors aucune recherche n'est effectuée. Sinon, la recherche examine ces répertoires : le répertoire nommé par la variable d'environnement enVarName; par rapport au répertoire de la bibliothèque Tcl ; par rapport au fichier exécutable dans le répertoire bin standard d'installation ou bin/arch ; par rapport au fichier exécutable dans l'arborescence de compilation actuelle ; par rapport au fichier exécutable dans une arborescence de compilation parallèle.

AIDES À LA DÉLIMITATION DES MOTS

Ces procédures sont principalement utilisées en interne par Tk.

tcl_endOfWord str start
Renvoie l'index de la première position de fin de mot qui se trouve après un index de départ start dans la chaîne str. Une position de fin de mot est définie comme le premier caractère non mot suivant le premier caractère mot après le point de départ. Renvoie -1 s'il n'y a plus de positions de fin de mot après le point de départ. Voir la description de tcl_wordchars et tcl_nonwordchars ci-dessous pour plus de détails sur la manière dont Tcl détermine quels caractères sont des caractères mot.
tcl_startOfNextWord str start
Renvoie l'index de la première position de début de mot qui se trouve après un index de départ start dans la chaîne str. Une position de début de mot est définie comme le premier caractère mot suivant un caractère non mot. Renvoie -1 s'il n'y a plus de positions de début de mot après le point de départ.
tcl_startOfPreviousWord str start
Renvoie l'index de la première position de début de mot qui se trouve avant un index de départ start dans la chaîne str. Renvoie -1 s'il n'y a plus de positions de début de mot avant le point de départ.
tcl_wordBreakAfter str start
Renvoie l'index de la première limite de mot après l'index de départ start dans la chaîne str. Renvoie -1 s'il n'y a plus de limites après le point de départ dans la chaîne donnée. L'index renvoyé fait référence au deuxième caractère de la paire qui constitue une limite.
tcl_wordBreakBefore str start
Renvoie l'index de la première limite de mot avant l'index de départ start dans la chaîne str. Renvoie -1 s'il n'y a plus de limites avant le point de départ dans la chaîne donnée. L'index renvoyé fait référence au deuxième caractère de la paire qui constitue une limite.

VARIABLES

Les variables globales suivantes sont définies ou utilisées par les procédures de la bibliothèque Tcl. Elles se répartissent en deux grandes catégories : la gestion des commandes et des paquets inconnus, et la détermination de ce qui constitue un mot.

VARIABLES D'CHARGEMENT AUTOMATIQUE ET DE GESTION DES PAQUETS

auto_execs
Utilisée par auto_execok pour enregistrer des informations sur l'existence ou non de commandes particulières en tant que fichiers exécutables.
auto_index
Utilisée par auto_load pour enregistrer les informations d'index lues depuis le disque.
auto_noexec
Si définie à n'importe quelle valeur, alors unknown n'essaiera pas d'exécuter automatiquement des commandes.
auto_noload
Si définie à n'importe quelle valeur, alors unknown n'essaiera pas de charger automatiquement des commandes.
auto_path
Si définie, elle doit contenir une liste Tcl valide donnant les répertoires à examiner lors des opérations de chargement automatique (y compris pour les fichiers d'index de paquets lors de l'utilisation du gestionnaire par défaut package unknown ). Cette variable est initialisée au démarrage pour contenir, dans l'ordre : les répertoires listés dans la variable d'environnement TCLLIBPATH , le répertoire nommé par la variable globale tcl_library , le répertoire parent de tcl_library, les répertoires listés dans la variable tcl_pkgPath . Les emplacements supplémentaires où chercher des fichiers et des index de paquets doivent normalement être ajoutés à cette variable en utilisant lappend.
env(TCL_LIBRARY)
Si définie, elle spécifie l'emplacement du répertoire contenant les scripts de bibliothèque (la valeur de cette variable sera assignée à la variable tcl_library et donc renvoyée par la commande info library). Si cette variable n'est pas définie, une valeur par défaut est utilisée.
env(TCLLIBPATH)
Si définie, elle doit contenir une liste Tcl valide donnant les répertoires à examiner lors des opérations de chargement automatique. Les répertoires doivent être spécifiés au format Tcl, en utilisant « / » comme séparateur de chemin, quelle que soit la plateforme. Cette variable n'est utilisée que lors de l'initialisation de la variable auto_path .

VARIABLES DE DÉTERMINATION DES LIMITES DES MOTS

Ces variables ne sont utilisées que dans les commandes tcl_endOfWord, tcl_startOfNextWord, tcl_startOfPreviousWord, tcl_wordBreakAfter, et tcl_wordBreakBefore .

tcl_nonwordchars
Cette variable contient une expression régulière utilisée par des routines comme tcl_endOfWord pour identifier si un caractère fait partie d'un mot ou non. Si le motif correspond à un caractère, ce caractère est considéré comme un caractère non mot. Sur les plateformes Windows, les espaces, les tabulations et les sauts de ligne sont considérés comme des caractères non mot. Sous Unix, tout sauf les chiffres, les lettres et les traits de soulignement sont considérés comme des caractères non mot.
tcl_wordchars
Cette variable contient une expression régulière utilisée par des routines comme tcl_endOfWord pour identifier si un caractère fait partie d'un mot ou non. Si le motif correspond à un caractère, ce caractère est considéré comme un caractère mot. Sur les plateformes Windows, les mots sont composés de tout caractère qui n'est pas un espace, une tabulation ou un saut de ligne. Sous Unix, les mots sont composés de chiffres, de lettres ou de traits de soulignement.
