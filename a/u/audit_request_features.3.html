AUDIT_REQUEST_FEATURES(3) API d'audit Linux AUDIT_REQUEST_FEATURES(3)

NOM

audit_request_features - demande un masque de fonctionnalités d'audit

SYNTAXE

#include <libaudit.h>

int audit_request_features(int fd);

DESCRIPTION

audit_request_features() demande au noyau d'envoyer une structure décrivant les fonctionnalités d'audit prises en charge sur le descripteur de fichier fd, qui doit être un socket netlink d'audit ouvert.

VALEUR DE RETOUR

La valeur de retour est <= 0 en cas d'erreur, sinon c'est le numéro de séquence netlink. Cette fonction peut rencontrer n'importe quelle erreur que sendto(2) pourrait rencontrer.

VOIR AUSSI

audit_get_features(3), audit_open(3), auditd(8).
