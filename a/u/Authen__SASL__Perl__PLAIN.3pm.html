Authen::SASL::Perl::PLAIN(3) Documentation Perl Contribuée par les utilisateurs Authen::SASL::Perl::PLAIN(3)

NOM

Authen::SASL::Perl::PLAIN - Classe d'authentification de connexion PLAIN

VERSION

version 2.1900

SYNOPSIS

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'PLAIN',
  callback  => {
    user => $user,
    pass => $pass
  },
);

DESCRIPTION

Cette méthode implémente la partie client et serveur de l'algorithme SASL PLAIN, tel que décrit dans la RFC 2595 et le brouillon IETF draft-ietf-sasl-plain-XX.txt.

CALLBACK

Les callbacks utilisés sont :

Client

authname
L'identifiant d'autorisation à utiliser après une authentification réussie (client).
user
Le nom d'utilisateur à utiliser pour l'authentification (client).
pass
Le mot de passe de l'utilisateur à utiliser pour l'authentification.

Serveur

checkpass(username, password, realm)
renvoie vrai ou faux selon la validité des informations d'identification passées en arguments.

VOIR AUSSI

Authen::SASL, Authen::SASL::Perl
