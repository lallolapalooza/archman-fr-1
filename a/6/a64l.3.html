a64l(3) Manuel des fonctions de bibliothèque a64l(3)

NOM

a64l, l64a — convertir entre long et base-64

BIBLIOTHÉQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
long a64l(const char *str64);
char *l64a(long value);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

a64l(), l64a():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _SVID_SOURCE

DESCRIPTION

Ces fonctions fournissent une conversion entre les entiers longs de 32 bits et les chaînes ASCII en base 64 petit-boutiste (de longueur zéro à six). Si la chaîne utilisée comme argument pour a64l() a une longueur supérieure à six, seuls les six premiers octets sont utilisés. Si le type long a plus de 32 bits, alors l64a() utilise uniquement les 32 bits de poids faible de value, et a64l() étend le signe de son résultat de 32 bits.

Les 64 chiffres du système en base 64 sont:

'.'	représente 0
'/'	représente 1
0-9	représentent  2-11
A-Z	représentent 12-37
a-z	représentent 38-63

Donc 123 = 59*64^0 + 1*64^1 = "v/".

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
l64a () Sécurité des threads MT-Unsafe race:l64a
a64l () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

NOTES

La valeur renvoyée par l64a() peut être un pointeur vers un tampon statique, potentiellement écrasé par des appels ultérieurs.

Le comportement de l64a() est indéfini lorsque value est négatif. Si value est zéro, il renvoie une chaîne vide.

Ces fonctions sont buggées avant glibc 2.2.5 (mettent le chiffre le plus significatif en premier).

Ce n'est pas le codage utilisé par uuencode(1).

VOIR AUSSI

uuencode(1), strtoul(3)
