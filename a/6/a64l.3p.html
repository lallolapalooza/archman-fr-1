A64L(3P) Manuel du programmeur POSIX A64L(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

a64l, l64a — conversion entre un entier 32 bits et une chaîne ASCII radix-64

SYNOPSIS

#include <stdlib.h>
long a64l(const char *s);
char *l64a(long valeur);

DESCRIPTION

Ces fonctions maintiennent des nombres stockés en caractères ASCII radix-64. Il s'agit d'une notation par laquelle les entiers 32 bits peuvent être représentés par jusqu'à six caractères ; chaque caractère représente un chiffre en notation radix-64. Si le type long contient plus de 32 bits, seuls les 32 bits de poids faible seront utilisés pour ces opérations.

Les caractères utilisés pour représenter les chiffres sont '.' (point) pour 0, '/' pour 1, '0' à '9' pour [2,11], 'A' à 'Z' pour [12,37], et 'a' à 'z' pour [38,63].

La fonction a64l() prendra un pointeur vers une représentation radix-64, dans laquelle le premier chiffre est le moins significatif, et retournera la valeur long correspondante. Si la chaîne pointée par s contient plus de six caractères, a64l() utilisera les six premiers. Si les six premiers caractères de la chaîne contiennent un terminateur nul, a64l() n'utilisera que les caractères précédant le terminateur nul. La fonction a64l() analysera la chaîne de caractères de gauche à droite avec le chiffre le moins significatif à gauche, décodant chaque caractère comme un nombre radix-64 à 6 bits. Si le type long contient plus de 32 bits, la valeur résultante est étendue en signe. Le comportement de a64l() n'est pas spécifié si s est un pointeur nul ou si la chaîne pointée par s n'a pas été générée par un appel précédent à l64a().

La fonction l64a() prendra un argument de type long et retournera un pointeur vers la représentation radix-64 correspondante. Le comportement de l64a() n'est pas spécifié si valeur est négative.

La valeur retournée par l64a() peut être un pointeur vers un tampon statique. Les appels ultérieurs à l64a() peuvent écraser le tampon.

La fonction l64a() n'est pas nécessairement thread-safe.

VALEUR DE RETOUR

En cas de succès, a64l() retournera la valeur long résultant de la conversion de la chaîne d'entrée. Si une chaîne pointée par s est une chaîne vide, a64l() retournera 0L.

La fonction l64a() retournera un pointeur vers la représentation radix-64. Si valeur est 0L, l64a() retournera un pointeur vers une chaîne vide.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

Si le type long contient plus de 32 bits, le résultat de a64l(l64a(x)) est x dans les 32 bits de poids faible.

RATIONALE

Ce n'est pas le même encodage que celui utilisé par l'une ou l'autre variante d'encodage de l'utilitaire uuencode.
