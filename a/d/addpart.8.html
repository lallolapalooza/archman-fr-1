ADDPART(8) Administration système ADDPART(8)

NOM

addpart - informer le noyau de l'existence d'une partition

SYNTAXE

addpart périphérique partition début longueur

DESCRIPTION

addpart informe le noyau Linux de l'existence de la partition spécifiée. La commande est un simple wrapper autour de l'appel ioctl « add partition ».

Cette commande ne manipule pas les partitions sur un périphérique bloc.

PARAMÈTRES

périphérique

Le périphérique disque.

partition

Le numéro de partition.

début

Le début de la partition (en secteurs de 512 octets).

longueur

La longueur de la partition (en secteurs de 512 octets).

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

VOIR AUSSI

delpart(8), fdisk(8), parted(8), partprobe(8), partx(8)

SIGNALER LES BOGUES

Pour les rapports de bogues, utilisez le suivi des problèmes https://github.com/util-linux/util-linux/issues.

DISPONIBILITÉ

La commande addpart fait partie du paquet util-linux qui peut être téléchargé depuis le Linux Kernel Archive https://www.kernel.org/pub/linux/utils/util-linux/.
