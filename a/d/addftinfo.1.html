addftinfo(1) Manuel des commandes générales addftinfo(1)

Nom

addftinfo - ajouter des métriques de police à troff pour l'utilisation avec groff

Synopsis

addftinfo [-asc-height n] [-body-depth n] [-body-height n] [-cap-height n] [-comma-depth n] [-desc-depth n] [-fig-height n] [-x-height n] résolution largeur-unité police
addftinfo --help
addftinfo -v
addftinfo --version

Description

addftinfo lit un fichier de description de police AT&T troff police, ajoute des informations de métriques de police supplémentaires requises par GNU troff(1), et écrit le résultat combiné sur la sortie standard. Les informations ajoutées sont dérivées des paramètres existants de la police et des hypothèses sur les noms traditionnels troff pour les caractères. Parmi les métriques de police ajoutées figurent les hauteurs et profondeurs des caractères (à quelle distance chaque caractère s'étend verticalement au-dessus et en dessous de la ligne de base). Les arguments résolution et largeur-unité doivent être les mêmes que les paramètres correspondants dans le fichier DESC. police est le nom du fichier décrivant la police ; si police se termine par “I”, la police est supposée être oblique (ou italique).

Options

--help affiche un message d'utilisation, tandis que -v et --version affichent des informations sur la version ; tous se terminent ensuite.

Toutes les autres options modifient les paramètres utilisés pour dériver les hauteurs et profondeurs. Comme les quantités existantes dans le fichier de description de police, chaque valeur n est en points gradués, pouces/résolution pour une police dont la taille est largeur-unité ; voir groff_font(5).

-asc-height n
hauteur des caractères avec ascendantes, tels que “b”, “d”, ou “l”
-body-depth n
profondeur des caractères tels que les parenthèses
-body-height n
hauteur des caractères tels que les parenthèses
-cap-height n
hauteur des lettres majuscules telles que “A”
-comma-depth n
profondeur d'une virgule
-desc-depth n
profondeur des caractères avec descendantes, tels que “p”, “q”, ou “y”
-fig-height
hauteur des chiffres
-x-height n
hauteur des lettres minuscules sans ascendantes telles que “x”

addftinfo ne tente pas d'utiliser les paramètres spécifiés pour déduire les paramètres non spécifiés. Si un paramètre n'est pas spécifié, la valeur par défaut sera utilisée. Les valeurs par défaut sont choisies pour produire des valeurs raisonnables pour une police Times.

Voir aussi

groff_font(5), groff(1), groff_char(7)
