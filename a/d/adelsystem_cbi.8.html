NOM

adelsystem_cbi - Pilote pour les onduleurs CC ADELSYSTEM CB/CBI

SYNTAXE

adelsystem_cbi -h

adelsystem_cbi -a NOM_PERIPH [OPTIONS]


Note

Cette page de manuel documente uniquement les fonctionnalités spécifiques du pilote adelsystem_cbi. Pour des informations sur le pilote principal, consultez nutupsdrv(8).

MATERIEL SUPPORTÉ

Ceci est le pilote pour les onduleurs CC adelsystem cb/cbi.

Le pilote a été testé avec un CBI2801224A, un onduleur CC tout-en-un 12/24Vcc.

Plus d'informations sur cet onduleur sont disponibles ici :

https://www.adelsystem.com/en/products/dc-ups-/

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote prend en charge les paramètres optionnels suivants dans le fichier ups.conf(5) :

Série :

ser_baud_rate=valeur

Un entier spécifiant le débit en bauds du port série (défaut 9600).

ser_data_bit=valeur

Un entier spécifiant le nombre de bits de données du port série (défaut 8).

ser_parity=valeur

Un caractère spécifiant la parité du port série (défaut N).

ser_stop_bit=valeur

Un entier spécifiant le bit d'arrêt du port série (défaut 1).

Modbus :

dev_slave_id=valeur

Un entier spécifiant l'identifiant esclave Modbus de l'appareil (défaut 1).

CONFIGURATION

Voici un exemple de configuration du pilote adelsystem_cbi dans le fichier ups.conf :

[adelsystem_cbi]
  driver = adelsystem_cbi
  port = /dev/ttyUSB0
  desc = "Pilote d'onduleur CC adelsystem cb/cbi"
  # paramètres série
  ser_baud_rate = 9600
  ser_parity = N
  ser_data_bit = 8
  ser_stop_bit = 1
  # id esclave modbus
  dev_slave_id = 5

COMMANDES INSTANTANÉES

Ce pilote prend en charge les commandes instantanées suivantes :

load.off

exécute "instant poweroff"

INSTALLATION

Ce pilote peut ne pas être compilé par défaut. Vous pouvez le compiler en installant libmodbus et en exécutant configure --with-modbus=yes.

Vous devez également accorder les permissions appropriées sur le fichier du périphérique série local (/dev/ttyUSB0 par exemple) pour permettre à l'utilisateur du pilote NUT d'y accéder.
