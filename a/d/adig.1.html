ADIG(1) Manuel des commandes générales ADIG(1)

NOM

adig - afficher les informations collectées à partir des serveurs du système de noms de domaine (DNS)

SYNTAXE

adig [@serveur] [-c classe] [-p port#] [-q nom] [-t type] [-x addr] [nom] [type] [classe] [opts_requete...]

DESCRIPTION

Envoie des requêtes aux serveurs DNS concernant le nom et affiche les informations reçues, où nom est un nom DNS valide (par ex. www.example.com, 1.2.3.10.in-addr.arpa).

Cet utilitaire est fourni avec la bibliothèque de résolution asynchrone c-ares.

Il est possible de spécifier des arguments par défaut pour adig via ${XDG_CONFIG_HOME}/adigrc.

ARGUMENTS

@serveur
Adresse IP du serveur. Peut être spécifiée sous forme de liste séparée par des virgules. Peut être spécifiée au format URI.
nom
Nom de l'enregistrement de ressource à rechercher.
type
Quel type de requête est requis. Par ex. - A, AAAA, MX, TXT, etc. Si non spécifié, A sera utilisé.
classe
Définit la classe de requête, IN par défaut. Peut également être HS ou CH.

INDICATEURS

-c classe
Définit la classe de requête, IN par défaut. Peut également être HS ou CH.
-h
Affiche l'aide.
-p port
Envoie la requête à un port autre que le 53. Il est souvent recommandé de définir le port via @serveur à la place.
-q nom
Spécifie le nom de domaine à interroger. Utile pour distinguer le nom des autres arguments.
-r
Ignore le traitement de adigrc.
-s
Serveur (alias de la syntaxe @serveur), compatibilité avec l'ancienne ligne de commande.
-t type
Indique le type d'enregistrement de ressource à interroger. Utile pour distinguer le type des autres arguments.
-x addr
Requêtes inversées simplifiées. Définit le type sur PTR et forme une chaîne de requête in-arpa valide.

OPTIONS DE REQUETE

+[no]aaonly
Définit l'indicateur aa dans la requête. Par défaut, il est désactivé.
+[no]aaflag
Alias pour +[no]aaonly.
+[no]additional
Active ou désactive l'affichage de la section supplémentaire. Activé par défaut.
+[no]adflag
Définit le bit ad (données authentiques) dans la requête. Par défaut, il est désactivé.
+[no]aliases
Si le fichier HOSTALIASES doit être pris en compte ou non. Par défaut, il est pris en compte.
+[no]all
Active ou désactive tous les +[no]cmd, +[no]stats, +[no]question, +[no]answer, +[no]authority, +[no]additional, +[no]comments.
+[no]answer
Active ou désactive l'affichage de la réponse. Activé par défaut.
+[no]authority
Active ou désactive l'affichage de l'autorité. Activé par défaut.
+bufsize=#
Taille du paquet UDP EDNS 0 autorisée. Par défaut, 1232.
+[no]cdflag
Définit le bit CD (Checking Disabled) dans la requête. Par défaut, il est désactivé.
+[no]class
Affiche la classe lors de l'impression de l'enregistrement. Activé par défaut.
+[no]cmd
Active ou désactive l'affichage de la commande demandée. Activé par défaut.
+[no]comments
Active ou désactive l'affichage des commentaires. Activé par défaut.
+[no]defname
Alias pour +[no]search.
+domain=somename
Définit la liste de recherche sur un seul domaine.
+[no]dns0x20
Si la randomisation de la casse DNS 0x20 doit être utilisée lors de l'envoi des requêtes. Par défaut, elle est désactivée.
+[no]edns[=#]
Active ou désactive EDNS. N'autorise que la valeur 0 si spécifiée. Par défaut, EDNS est activé.
+[no]ignore
Ignore la troncature sur UDP, par défaut retransmission sur TCP.
+[no]keepopen
Si la connexion au serveur doit être persistante ou non. Par défaut, elle est fermée.
+ndots=#
Définit le nombre de points qui doivent apparaître avant d'être considérés comme absolus. Par défaut, 1.
+[no]primary
Si un seul serveur doit être utilisé lorsqu'il y en a plusieurs de disponibles. Par défaut, tous les serveurs sont utilisés.
+[no]qr
Active ou désactive l'affichage de la requête envoyée. Désactivé par défaut.
+[no]question
Active ou désactive l'affichage de la question. Activé par défaut.
+[no]recurse
Active ou désactive le bit RD (Recursion Desired). Activé par défaut.
+retry=#
Identique à +tries mais n'inclut pas la tentative initiale.
+[no]search
Utiliser ou non la liste de recherche. La liste de recherche n'est pas utilisée par défaut.
+[no]stats
Active ou désactive l'affichage des statistiques. Activé par défaut.
+[no]tcp
Si TCP doit être utilisé lors de l'interrogation des serveurs de noms. Par défaut, UDP est utilisé.
+tries=#
Nombre d'essais de requête. Par défaut, 3.
+[no]ttlid
Affiche le TTL lors de l'impression de l'enregistrement. Activé par défaut.
+[no]vc
Alias pour +[no]tcp.
