DESCRIPTIO

N

amulecmd est un client en console pour contrôler

aMule.
[ -h <host>, --host=<host>

Hôte où aMule est en cours d'exécution (par défaut : localhost). <host> peut être une adresse IP ou un nom

[ -p <port>, --port=<port>

Port d'aMule pour les connexions externes, tel que défini dans Préférences->Contrôle à distance (par défaut : 471

[ -P <password>, --password=<password>

Mot de passe des connexions
externes.
[ -f <path>, --config-file=<path>

Utilise le fichier de configuration donné. Le fichier de configuration par défaut est ~/.aMule/remote.

N'affiche aucune sortie sur

[ -v, --verbose
]
Mode verbeux - affiche également les messages de

[ -l <lang>, --locale=<lang>
]
Définit la locale (langue) du programme. Voir la section NOTES pour la description du paramètre <lang

[ -w, --write-config
]
Écrit les options de la ligne de commande dans le fichier de configuration et
quitte
[ -c <command>, --command=<command>
]
Exécute <command> comme s'il avait été saisi à l'invite de commande de amulecmd et
quitte.
[ --create-config-from=<path>
]
Crée un fichier de configuration basé sur <path>, qui doit pointer vers un fichier de configuration aMule valide, puis
quitte.
[ -v, --version

NOTE

S

Chemin

s

Pour toutes les options qui prennent une valeur <path>, si le chemin ne contient pas de répertoire (c'est-à-dire juste un nom de fichier simple), alors il est considéré comme étant sous le répertoire de configuration d'aMule, ~/.a

Mul
e.

Langue

s

Le paramètre <lang> pour l'option -l a la forme suivante : lang[_LANG][.encoding][@modifier] où lang est la langue principale, LANG est une sous-langue/territoire, encoding est le jeu de caractères à utiliser et modifier permet à l'utilisateur de sélectionner une instance spécifique de données de localisation au sein d'une même

catégorie.

Par exemple, les chaînes suivantes sont valides

:
de
de_DE
de_DE.iso88591
de_DE@euro
de_DE.
iso88591@euro

Bien que toutes les chaînes ci-dessus soient acceptées comme définitions de langue valides, encoding et modifier ne sont pas encore

utilisés.

En plus du format ci-dessus, vous pouvez également spécifier des noms de langue complets en anglais - ainsi -l german est également valide et équivaut à -l de_

DE.

Lorsqu'aucune locale n'est définie, que

ce soit en ligne de commande ou dans l
e fichier de configuration, la lang
ue par défaut du système sera utilisée.
