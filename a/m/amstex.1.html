AMSTEX(1) Manuel des commandes générales AMSTEX(1)

NOM

amstex - formatage et composition de texte structuré

SYNTAXE

amstex [première-ligne]

DESCRIPTION

Cette page de manuel n'a pas pour but d'être exhaustive. La documentation complète pour cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

Le langage AmSTeX est décrit dans le livre The Joy of TeX. AmSTeX est un paquet de macros TeX, pas une modification du programme source TeX, donc toutes les capacités décrites dans tex(1) sont présentes.

Les macros AmSTeX encouragent les auteurs à penser au contenu de leurs documents plutôt qu'à leur forme. L'idéal, pas toujours réalisé, est de ne pas avoir de commandes de formatage (comme « passer en italique » ou « sauter 2 picas ») dans le document du tout ; au lieu de cela, tout est fait par des instructions de balisage spécifiques : « mettre en évidence », « commencer une section ».

Pour les auteurs plus familiers avec LaTeX, un paquet pris en charge par l'AMS appelé amsmath.sty est disponible, entre autres.
