NOM

amuled - le client p2p eMule multiplateforme - version daemonisée

SYNTAXE

amuled [-c <chemin>] [-f] [-p <chemin>] [-e] [-o] [-r] [-w <chemin>] [-d] [-i] [-t <numéro>] [lien_eD2k]

amuled [-v]

amuled [-h]

DESCRIPTION

[ -c <chemin>, --config-dir=<chemin> ]
Lire la configuration depuis <chemin> au lieu du répertoire personnel.
[ -f, --full-daemon ]
Se détache en arrière-plan.
[ -p <chemin>, --pid-file=<chemin> ]
Après le détachement, créer un fichier pid dans le <chemin>. <chemin> doit contenir le nom du fichier.
[ -e, --ec-config ]
Configurer EC (Connexions Externes).
[ -o, --log-stdout ]
Afficher les messages de log sur la sortie standard.
[ -r, --reset-config ]
Réinitialiser la configuration aux valeurs par défaut.
[ -w <chemin>, --use-amuleweb=<chemin> ]
Spécifier l'emplacement du binaire amuleweb à <chemin>.
[ -d, --disable-fatal ]
Ne pas gérer les exceptions fatales.
[ -i, --enable-stdin ]
Ne pas désactiver stdin.
[ -t, --category=<numéro> ]
Définir la catégorie pour les liens eD2k passés à <numéro>.
[ -v, --version ]
Afficher le numéro de version actuel.
[ -h, --help ]
Afficher une brève description de l'utilisation.
[ lien_eD2k ]
Ajoute un lien eD2k au cœur.

Le lien eD2k à ajouter peut être :

  • un lien de fichier (ed2k://|file|...), il sera ajouté à la file d'attente de téléchargement ;
  • un lien serveur (ed2k://|server|...), il sera ajouté à la liste des serveurs ;
  • un lien de liste de serveurs, auquel cas tous les serveurs de la liste seront ajoutés à la liste des serveurs ;
  • un lien magnet.
