NOM

amulegui - programme de contrôle aMule avec interface graphique

SYNTAXE

amulegui [-c <chemin>] [-geometry <geom>] [-o] [-r] [-s] [-t <num>]

amulegui [-v]

amulegui [-h]

DESCRIPTION

amulegui est un programme client, et peut être connecté à amule ou amuled via EC. Vous pouvez gérer votre programme amule avec. Il offre presque les mêmes fonctionnalités que amule, même si le cœur fonctionne sur un autre ordinateur.

[ -c <chemin>, --config-dir=<chemin> ]
Lire la configuration depuis <chemin> au lieu du répertoire personnel
[ -geometry <geom> ]
Définit la géométrie de l'application. <geom> utilise le même format que les applications X11 standard : [=][<largeur>{xX}<hauteur>][{+-}<décalage_x>{+-}<décalage_y>]
[ -o, --log-stdout ]
Imprimer les messages de journalisation sur stdout.
[ -r, --reset-config ]
Réinitialiser la configuration aux valeurs par défaut.
[ -s, --skip ]
Ignorer la boîte de dialogue de connexion.
[ -t, --category=<num> ]
Définir la catégorie pour les liens eD2k passés à <num>
[ -h, --help ]
Afficher une courte description d'utilisation.
[ -v, --version ]
Afficher le numéro de version actuel.
