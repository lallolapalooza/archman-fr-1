NOM

amdgpu - pilote vidéo Xorg pour les GPU AMD RADEON

SYNOPSIS

Section "Device"
  Identifier "devname"
  Driver "amdgpu"
...
EndSection

DESCRIPTION

amdgpu est un pilote Xorg pour les cartes vidéo basées sur AMD RADEON avec les fonctionnalités suivantes :

•
Prise en charge des profondeurs de pixel de 8, 15, 16, 24 et 30 bits ;
•
Prise en charge de RandR jusqu'à la version 1.4 ;
•
Accélération 3D ;

MATÉRIEL PRIS EN CHARGE

Le pilote amdgpu prend en charge les cartes vidéo des familles SI et plus récentes.

DÉTAILS DE CONFIGURATION

Veuillez vous référer à xorg.conf(5) pour les détails de configuration généraux. Cette section ne couvre que les détails de configuration spécifiques à ce pilote.

Les options de pilote suivantes sont prises en charge :

Option "SWcursor" "booléen"
Sélectionne le curseur logiciel.
La valeur par défaut est off.
Option "Accel" "booléen"
Active ou désactive toute l'accélération matérielle.
La valeur par défaut est on.
Option "ZaphodHeads" "chaîne"
Spécifie les sorties RandR à utiliser avec le mode zaphod pour une instance de pilote particulière. Si vous utilisez cette option, vous devez l'utiliser pour toutes les instances du pilote.
Par exemple : Option "ZaphodHeads" "LVDS,VGA-0" assignera les sorties xrandr LVDS et VGA-0 à cette instance du pilote.
Option "DRI" "entier"
Définit le niveau maximal de DRI à activer. Les valeurs valides sont 2 pour DRI2 ou 3 pour DRI3. La valeur par défaut est 3 pour DRI3 si la version de Xorg est >= 1.18.3, sinon 2 pour DRI2.
Option "EnablePageFlip" "booléen"
Active le changement de page (page flipping) DRI2.
La valeur par défaut est on.
Option "TearFree" "booléen"
Définit la valeur par défaut de la propriété 'TearFree' par sortie, qui contrôle la prévention des déchirures à l'aide du mécanisme matériel de changement de page. TearFree est activé pour tout CRTC associé à une ou plusieurs sorties avec TearFree activé. Deux tampons de balayage distincts doivent être alloués pour chaque CRTC avec TearFree activé. Si cette option est définie, la valeur par défaut de la propriété est 'on' ou 'off' en conséquence. Si cette option n'est pas définie, la valeur par défaut de la propriété est auto, ce qui signifie que TearFree est activé pour les sorties pivotées, les sorties avec des transformations RandR appliquées, les sorties secondaires RandR 1.4, et si 'VariableRefresh' est activé, sinon il est désactivé.
Option "VariableRefresh" "booléen"
Active la prise en charge de la variable refresh rate sur les CRTCs de l'écran lorsqu'une application appropriée effectue un changement de page via l'extension Present.
La valeur par défaut est off.
Option "AsyncFlipSecondaries" "booléen"
Utilise des changements de page asynchrones pour les sorties vidéo secondaires sur les configurations multi-affichage. Si un écran a plusieurs affichages connectés et que le changement de page DRI3 est utilisé, alors un seul des affichages aura son changement de page synchronisé au vblank pour une présentation sans déchirure. C'est l'affichage utilisé pour le minutage et l'horodatage de la présentation, généralement celui couvrant la plus grande surface de pixels de l'écran. Tous les autres affichages ("Secondaries") ne synchroniseront pas leurs changements de page. Cela peut causer des déchirures sur ces affichages, mais cela empêche un ralentissement permanent ou périodique ou un saccadage gênant des animations si toutes les sorties vidéo ne sont pas en cours d'exécution de manière synchronisée les unes avec les autres et avec la même fréquence de rafraîchissement. Il n'y a pas de solution parfaite à part des sorties parfaitement synchronisées, mais cette option peut donner des résultats préférables si les affichages dans une configuration multi-affichage se miroitent ou se clonent les uns les autres.
La valeur par défaut est off.
Option "AccelMethod" "chaîne"
Définir cette option sur none désactive l'utilisation de l'architecture d'accélération glamor. Dans ce cas, tout le rendu 2D est effectué par le CPU, mais l'accélération matérielle 3D et vidéo peut toujours fonctionner. C'est principalement utile pour le développement du pilote OpenGL.
La valeur par défaut est d'utiliser glamor.

L'option de pilote suivante est prise en charge pour glamor:

Option "ShadowPrimary" "booléen"
Cette option active un tampon dit "shadow primary" pour un accès rapide du CPU aux données de pixel, et des tampons de balayage séparés pour chaque contrôleur d'affichage (CRTC). Cela peut améliorer les performances pour certaines charges de travail 2D, potentiellement au détriment d'autres charges de travail (par ex. 3D, vidéo). Notez particulièrement que l'activation de cette option désactifie actuellement le changement de page.
La valeur par défaut est off.
