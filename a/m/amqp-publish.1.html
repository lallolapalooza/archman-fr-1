NOM

amqp-publish - Publier un message sur un serveur AMQP

SYNTAXE

amqp-publish [OPTION...]

DESCRIPTION

Publie un message vers un échange sur un serveur AMQP. Les options permettent de spécifier les différentes propriétés du message et les paramètres de la méthode AMQP basic.publish.

Par défaut, le corps du message est lu depuis l'entrée standard. Alternativement, l'option -b permet de fournir le corps du message dans le cadre de la commande.

OPTIONS

-e, --exchange=nom de l'échange

Le nom de l'échange vers lequel publier. Si omis, l'échange par défaut (également appelé échange sans nom) est utilisé.

-r, --routing-key=clé de routage

La clé de routage à utiliser pour la publication. Si omise, une clé de routage vide est supposée. Une clé de routage doit être spécifiée lors de la publication vers l'échange par défaut ; dans ce cas, conformément à la spécification AMQP, la clé de routage correspond au nom d'une file d'attente.

-p, --persistent

Utiliser le mode de livraison persistant. Sans cette option, le mode de livraison non-persistant est utilisé.

-C, --content-type=type MIME

Spécifie la propriété content-type du message. Si omise, la propriété content-type n'est pas définie sur le message.

-E, --content-encoding=encodage du contenu

Spécifie la propriété content-encoding du message. Si omise, la propriété content-encoding n'est pas définie sur le message.

-b, --body=corps du message

Spécifie le corps du message. Si omis, le corps du message est lu depuis l'entrée standard.

-H, --header=en-tête

Spécifie un en-tête optionnel sous la forme "clé : valeur".

EXEMPLES

Envoyer un court message, composé du mot « Hello » à la file d'attente « myqueue » via l'échange par défaut :

$ amqp-publish -r myqueue -b Hello

Envoyer des données XML à partir d'un fichier vers l'échange « events », en mode de livraison persistant, en définissant la propriété content-type du message pour explicitement indiquer le format des données :

$ amqp-publish -e events -p -C text/xml <event.xml
