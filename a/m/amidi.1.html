AMIDI(1) Manuel des commandes générales AMIDI(1)

NOM

amidi - lire et écrire sur les ports ALSA RawMIDI

SYNTAXE

amidi [-p port] [-s fichier | -S données] [-r fichier] [-d] [-t secondes] [-a]

DESCRIPTION

amidi est un utilitaire en ligne de commande qui permet de recevoir et d'envoyer des données SysEx (system exclusive) depuis/vers des périphériques MIDI externes. Il peut également envoyer d'autres commandes MIDI.

amidi ne traite que les fichiers contenant des commandes MIDI brutes, sans informations de timing. amidi ne prend pas en charge les fichiers MIDI standard (.mid), mais aplaymidi(1) et arecordmidi(1) le font.

OPTIONS

Utilisez les options -h, -V, -l, ou -L pour afficher des informations ; ou utilisez au moins l'une des options -s, -r, -S, ou -d pour spécifier les données à envoyer ou recevoir.

-h, --help
Aide : affiche une liste des options.
-V, --version
Affiche la version actuelle.
-l, --list-devices
Affiche la liste de tous les ports MIDI matériels.
-L, --list-rawmidis
Affiche toutes les définitions RawMIDI. (utilisé lors du débogage des fichiers de configuration)
-p, --port=nom
Définit le nom du port ALSA RawMIDI à utiliser. Si cela n'est pas spécifié, amidi utilise le port par défaut défini dans le fichier de configuration (le défaut est le port 0 sur la carte 0, qui peut ne pas exister).
-s, --send=nom_fichier
Envoie le contenu du fichier spécifié au port MIDI. Le fichier doit contenir des commandes MIDI brutes (par exemple un fichier .syx) ; pour les fichiers MIDI standard (.mid), utilisez aplaymidi(1).
-r, --receive=nom_fichier
Écrit les données reçues du port MIDI dans le fichier spécifié. Le fichier conterra des commandes MIDI brutes (comme dans un fichier .syx) ; pour enregistrer un fichier MIDI standard (.mid), utilisez arecordmidi(1).

amidi filtrera les octets Active Sensing et Clock (FEh, F8h), sauf si les options -a ou -c ont été données.

-S, --send-hex="..."
Envoie les octets spécifiés sous forme de nombres hexadécimaux au port MIDI.
-d, --dump
Affiche les données reçues du port MIDI sous forme d'octets hexadécimaux. Les octets Active Sensing et Clock (FEh, F8h) ne seront pas affichés, sauf si les options -a ou -c ont été données.

Cette option est utile pour le débogage.

-t, --timeout=secondes
Arrête la réception des données lorsqu'aucune donnée n'a été reçue pendant la durée spécifiée.

Si cette option n'a pas été donnée, vous devez appuyer sur Ctrl+C (ou tuer amidi) pour arrêter de recevoir des données.

-a, --active-sensing
N'ignore pas les octets Active Sensing (FEh) lors de la sauvegarde ou de l'affichage des commandes MIDI reçues.
-c, --clock
N'ignore pas les octets Clock (F8h) lors de la sauvegarde ou de l'affichage des commandes MIDI reçues.
-i, --sysex-interval=msecondes
Ajoute un délai entre chaque message SysEx envoyé à un périphérique. C'est utile lors de l'envoi de mises à jour de firmware via des messages SysEx à un périphérique distant.

EXEMPLES

amidi -p hw:0 -s mes_parametres.syx
enverra les commandes MIDI dans mes_parametres.syx au port hw:0.
amidi -p hw:1,0,0 -s firmware.syx -i 100
enverra les commandes MIDI dans firmware.syx au port hw:1,0,0 avec un délai de 100 millisecondes entre chaque message SysEx.
amidi -S 'F0 43 10 4C 00 00 7E 00 F7'
envoie un XG Reset au port par défaut.
amidi -p hw:1,2 -S F0411042110C000000000074F7 -r dump.syx -t 1
envoie une « Demande de vidage de paramètres » à un périphérique GS, sauvegarde les données de paramètres reçues dans le fichier dump.syx, et s'arrête une fois que le périphérique a fini d'envoyer les données (lorsqu'aucune donnée n'a été reçue pendant une seconde).
amidi -p virtual -d
crée un port RawMIDI virtuel et affiche toutes les données envoyées à ce port.

FICHIERS

/usr/share/alsa/alsa.conf définitions rawmidi par défaut
/etc/asound.conf définitions rawmidi globales
~/.asoundrc définitions rawmidi spécifiques à l'utilisateur
