NOM

amqp-get - Récupérer un message d'une file d'attente sur un serveur AMQP

SYNTAXE

amqp-get [OPTION...] {-q nom de file}

DESCRIPTION

amqp-get tente de consommer un seul message d'une file d'attente sur un serveur AMQP, puis se termine. Sauf si la file d'attente était vide, le corps du message résultant est envoyé à la sortie standard.

OPTIONS

-q, --queue=nom de file

Le nom de la file d'attente à partir de laquelle consommer les messages.

STATUT DE SORTIE

Si la file d'attente n'est pas vide et qu'un message est récupéré avec succès, le statut de sortie est 0. Si une erreur se produit, le statut de sortie est 1. Si la file d'attente est trouvée vide, le statut de sortie est 2.

EXEMPLES

Récupérer un message de la file d'attente « myqueue » et afficher son corps sur la sortie standard :

$ amqp-get -q myqueue
