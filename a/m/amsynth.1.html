AMSYNTH(1) Commandes utilisateur AMSYNTH(1)

NOM

amsynth - synthétiseur logiciel soustractif à deux oscillateurs

SYNTAXE

amsynth [options]

DESCRIPTION

amsynth est un synthétiseur logiciel facile à utiliser avec une topologie de synthétiseur soustractif classique.

OPTIONS

-h
afficher un message d'aide
-v
afficher les informations de version
-x
exécuter en mode sans interface graphique (sans GUI)
-b <fichier>
utiliser <fichier> comme banque pour stocker les presets
-t <fichier>
utiliser <fichier> comme fichier de réglage
-a <chaîne>
définir le pilote de sortie audio à utiliser [alsa/oss/auto(défaut)]
-r <entier>
définir la fréquence d'échantillonnage à utiliser
-m <chaîne>
définir le pilote MIDI à utiliser [alsa/oss/auto(défaut)]
-c <entier>
définir le canal MIDI auquel répondre (défaut=tous)
-p <entier>
définir la polyphonie (voix actives maximales)
-n <nom>
spécifier le nom du client JACK à utiliser
--jack_autoconnect <vrai|faux>
connecter automatiquement les ports audio JACK aux ports d'E/S matériels. (Défaut : vrai)
--force-device-scale-factor <échelle>
définir le facteur d'échelle à utiliser pour le panneau de contrôle

FICHIERS

$XDG_CONFIG_HOME/amsynth/config
Configuration pour amsynth.
$XDG_DATA_HOME/amsynth/banks/*
Banques de presets utilisateur.

ENVIRONNEMENT

AMSYNTH_NO_GUI
Si AMSYNTH_NO_GUI est défini, amsynth est démarré en mode sans interface graphique (sans GUI).
AMSYNTH_SKIN
Spécifie le répertoire à partir duquel amsynth doit charger son skin.
GDK_SCALE
Spécifie le facteur d'échelle à utiliser pour le panneau de contrôle.

BOGUES & DEMANDES DE FONCTIONNALITÉS

Si vous trouvez un bogue ou si vous souhaitez proposer une nouvelle fonctionnalité, veuillez le signaler sur https://github.com/amsynth/amsynth/issues .
