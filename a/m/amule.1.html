AMULE(1) aMule AMULE(1)

NOM

amule - le client p2p eMule toutes plateformes

SYNTAXE

amule [-c <chemin>] [-geometry <geom>] [-o] [-r] [-w <chemin>] [-d] [-i] [-t <num>] [lien_eD2k]

amule [-v]

amule [-h]

DESCRIPTION

[ -c <chemin>, --config-dir=<chemin> ]
Lire la configuration depuis <chemin> au lieu du répertoire personnel
[ -geometry <geom> ]
Définit la géométrie de l'application. <geom> utilise le même format que les applications X11 standard: [=][<largeur>{xX}<hauteur>][{+-}<xoffset>{+-}<yoffset>]
[ -o, --log-stdout ]
Imprimer les messages de log sur la sortie standard.
[ -r, --reset-config ]
Réinitialise la configuration aux valeurs par défaut.
[ -w <chemin>, --use-amuleweb=<chemin> ]
Spécifie l'emplacement du binaire amuleweb à <chemin>.
[ -d, --disable-fatal ]
Ne gère pas les exceptions fatales.
[ -i, --enable-stdin ]
Ne désactive pas stdin.
[ -t, --category=<num> ]
Définit la catégorie pour les liens eD2k passés à <num>
[ -v, --version ]
Affiche le numéro de version actuel.
[ -h, --help ]
Imprime une brève description de l'utilisation.
[ lien_eD2k ]
Ajoute un lien eD2k au cœur.

Le lien eD2k à ajouter peut être :

  • un lien de fichier (ed2k://|file|...), il sera ajouté à la file d'attente de téléchargement ;
  • un lien de serveur (ed2k://|server|...), il sera ajouté à la liste des serveurs ;
  • un lien de liste de serveurs, auquel cas tous les serveurs de la liste seront ajoutés à la liste des serveurs ;
  • un lien magnet.

NOTES

Chemins

Pour toutes les options qui prennent une valeur <chemin>, si le chemin ne contient aucune partie de répertoire (c'est-à-dire juste un nom de fichier simple), alors il est considéré comme étant sous le répertoire de configuration d'aMule, ~/.aMule.

FICHIERS

~/.aMule/*
