Description détaillée

UNKNOWN_115.

Ces objets stockent un bloc de données contigu contenant les points de restauration, similaire à ce que fait un LogContainer pour les données de journal.

La valeur par défaut de dataLength est 2000, ce qui donne un objectSize de 2048.

Note

Cette classe est basée sur des observations, car aucune documentation publique n'est disponible. Il existe des fonctions API non documentées pour la gestion des RestorePoint. Et cela semble en être une.
