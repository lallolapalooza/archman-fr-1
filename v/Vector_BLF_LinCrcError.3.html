    Vector::BLF::LinCrcError

    NOM

    Vector::BLF::LinCrcError - Représente une erreur de CRC LIN.

    SYNOPIS

    
        package Vector::BLF::LinCrcError;

        use base qw( Error::Tiny );
        ```

    DESCRIPTION

    Cette classe représente une erreur de CRC LIN dans le contexte de la bibliothèque BLF de Vector.

    MÉTHODES

    Aucune méthode spécifique définie dans cette classe, elle hérite de `Error::Tiny`.
