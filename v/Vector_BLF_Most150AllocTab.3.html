std::vector< uint8_t > Vector::BLF::Most150AllocTab::tableData {}

Données de la table d'allocation

La disposition des données tableData dépend du bit 0 de eventModeFlags.

Si le bit 0 de eventModeFlags est effacé, tableData contient length/4 enregistrements avec les champs suivants. (D'autres dispositions de données ne sont pas encore spécifiées.)

  • Bit 0..12 (LabelIdent) : Étiquette de connexion synchrone
  • Bit 12..15 (LabelStatus) :
•
0 : étiquette inchangée
•
4 : étiquette ajoutée (allouée)
•
8 : étiquette supprimée (désallouée) Liste des étiquettes supprimées à la fin du tableau ! La liste des étiquettes supprimées est facultative.
•
Bit 16..31 (LabelWidth) : Largeur de l'étiquette en octets

Disposition des données : if((eventModeFlags & 0x0001) == 0) layout A: SLLLWWWWSLLLWWWWSLLLWWWW... if((eventModeFlags & 0x0001) == 0x0001) layout B: SLLLWWWW< channels >SLLLWWWW< channels >SLLLWWWW< channels >...

•
S : indicateurs d'état
•
0x4 : 1 : nouvelle étiquette (allocation)
•
0x8 : 1 : cette étiquette a été supprimée (désallocation)
  • LLL : numéro d'étiquette
  • WWWW : largeur de l'étiquette
  • < channels > : liste des numéros de canal 16 bits (taille = largeur de l'étiquette)
