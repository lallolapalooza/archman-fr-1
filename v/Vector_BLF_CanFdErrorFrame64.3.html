uint32_t Vector::BLF::CanFdErrorFrame64::btrCfgArb {}

débit binaire utilisé dans la phase d'arbitrage Configuration de chronométrage de bits CAN-FD pour la phase d'arbitrage, peut être 0 si non pris en charge par le matériel/pilote

  • Bit 0-7 : Fréquence du quartz
  • Bit 8-15 : Prétarificateur
  • Bit 16-23 : Cycles BTL
  • Bit 24-31 : Point d'échantillonnage

uint32_t Vector::BLF::CanFdErrorFrame64::btrCfgData {}

débit binaire utilisé dans la phase de données Configuration de chronométrage de bits CAN-FD pour la phase d'arbitrage, peut être 0 si non pris en charge par le matériel/pilote. Voir btrCfgArb.
