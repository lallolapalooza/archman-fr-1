uint8_t Vector::BLF::MostCtrl::ackNack {}

bits d'acquittement AckNack contient l'état de transmission d'un message de contrôle (voir le registre d'état de transmission d'OS8104 pour MOST25).

•
Bit 0: Signification :
•
1 : pas de réponse (NoResp) Restriction :
•
uniquement pour Dir = Tx ou messages d'espionnage
•
Bit 1: Signification :
•
1 : réception valide (Valid) Restriction :
•
uniquement pour Dir = Tx ou messages d'espionnage
•
Bit 2: Signification :
•
1 : erreur CRC (CRCError) Restriction :
•
uniquement pour Dir = Tx ou messages d'espionnage
•
Bit 3: Signification :
•
1 : tampon de réception plein (RxBufFull) Restriction :
•
uniquement pour Dir = Tx ou messages d'espionnage
•
Bit 4: Signification :
•
1 : acquitté (Ack) Restriction :
•
uniquement pour Dir = Tx ou messages d'espionnage (toujours mis à 1 pour les messages Rx en mode nœud)
•
Bit 5: Signification :
•
1 : acquittement négatif (NAck) Restriction :
•
uniquement pour Dir = Tx ou messages d'espionnage

uint8_t Vector::BLF::MostCtrl::state {}

État de transmission MOST25. État de transmission d'un message de contrôle MOST25.

•
Bit 0 : Signification :
•
0 : bus inactif
•
1 : bus actif Restriction :
•
uniquement pour Dir = Rx (MOSTCtrl) ou MOSTSpy
•
Bit 1 : Signification :
•
1 : événement de déverrouillage pendant la transmission (Unl) Restriction :
•
uniquement pour Dir = Rx (MOSTCtrl) ou MOSTSpy
•
Bit 4 : Signification :
•
1 : acquitté (Ack) Restriction :
•
uniquement pour Dir = Tx (toujours défini sur 1 pour les messages Rx en mode nœud)
•
Bit 5 : Signification :
•
1 : non acquitté (NAck) Restriction :
•
uniquement pour Dir = Tx
•
Bit 6 : Signification :
•
Résultat de l'envoi :
•
0 : Erreur de transmission (TxF)
•
1 : OK Restriction :
•
uniquement pour Dir = Tx (MOSTCtrl)
