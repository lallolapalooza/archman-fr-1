uint8_t Vector::BLF::Most50Message::ackNack {}

code d'acquittement ackNack contient l'état de transmission d'un message de contrôle (voir le registre d'état de transmission d'OS8104 pour MOST25).

•
Bit 0 : Signification :
•
1 : pas de réponse (NoResp) Restriction :
•
uniquement pour Dir = Tx ou messages espions
•
Bit 1 : Signification :
•
1 : réception valide (Valid) Restriction :
•
uniquement pour Dir = Tx ou messages espions
•
Bit 2 : Signification :
•
1 : Erreur CRC (CRCError) Restriction :
•
uniquement pour Dir = Tx ou messages espions
•
Bit 3 : Signification :
•
1 : tampon de réception plein (RxBufFull) Restriction :
•
uniquement pour Dir = Tx ou messages espions
•
Bit 4 : Signification :
•
1 : acquitté (Ack) Restriction :
•
uniquement pour Dir = Tx ou messages espions (toujours défini à 1 pour les messages Rx en mode nœud)
•
Bit 5 : Signification :
•
1 : acquittement négatif (NAck) Restriction :
•
uniquement pour Dir = Tx ou messages espions

uint8_t Vector::BLF::Most50Message::state {}

statut de transmission États de transmission des messages et paquets MOST50/150.

•
Bit 0 : Signification :
•
0 : bus inactif
•
1 : bus actif Restriction :
•
uniquement pour Dir = Rx ou mTransferType = Spy
•
Bit 4 : Signification :
•
1 : acquitté (Ack) Restriction
•
uniquement pour mTransferType = Node et Dir = Tx (toujours mis à 1 pour les messages Rx en mode nœud)
•
Bit 5 : Signification :
•
1 : non acquitté (NAck) Restriction :
•
uniquement pour Dir = Tx
•
Bit 6 : Signification : Résultat de l'envoi :
•
0 : Erreur de transmission (TxF)
•
1 : OK Restriction :
•
uniquement pour Dir = Tx
•
uniquement pour mTransferType = Node

uint8_t Vector::BLF::Most50Message::transferType {}

Type de transfert. Les événements de type message peuvent être enregistrés soit via la puce émetteur-récepteur MOST, soit via un espion réseau séparé.

  • 1 : Message rapporté par l'émetteur-récepteur MOST (suite à une réception réussie ou comme acquittement d'une demande de transmission).
  • 2 : Message espion rapporté par l'espion réseau. L'espion voit tous les messages indépendamment de l'adresse de destination.
