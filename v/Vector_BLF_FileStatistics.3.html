uint32_t Vector::BLF::FileStatistics::apiNumber { 4080200 }

Numéro de l'API BL

Ceci comprend le majeur, le mineur, le build et le patch. Il est codé comme suit : majeur * 1000000 + mineur * 1000 + build * 100 + patch. Exemple : 4010608 se décode en 4.1.6.8.

uint8_t Vector::BLF::FileStatistics::compressionLevel {1}

niveau de compression

Note

zlib définit un niveau de compression maximum de 9. Tous les fichiers qui affichent 10 ici, ont en réalité des conteneurs de journaux (LogContainers) avec un niveau de compression de 6, ce qui est le défaut pour Vector BLF.

uint64_t Vector::BLF::FileStatistics::restorePointsOffset {}

Note

Les variables suivantes sont basées sur des observations, car il n'y a pas de documentation publique disponible. Cette variable désigne la position dans le fichier du (premier) LogContainer qui contient les objets RestorePointContainer.

Si les RestorePoints ne sont pas utilisés, cette valeur est par défaut à 0.
