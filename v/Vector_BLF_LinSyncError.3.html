Description détaillée

LIN_SYN_ERROR.

Les erreurs de synchronisation se produisent si le matériel LIN ne parvient pas à se synchroniser avec un Maître externe. Cela peut se produire si le débit binaire réellement utilisé par le Maître dévie de plus de 15 % du débit binaire spécifié par le matériel LIN. Dans ce cas, la valeur du débit binaire doit être modifiée. Cet événement d'erreur peut également se produire si le Maître transmet un champ Sync invalide ou corrompu.
