Description détaillée

MOST_HWMODE.

Cet événement est déclenché lorsqu'un ou plusieurs états matériels changent. Les états matériels sont le bit AllBypass (par exemple, ABY de OS8104), la sélection Maître/Esclave (par exemple, MTR de OS8104), l'espion de contrôle et l'espion asynchrone. L'événement transporte tous les états même si un seul état a changé. hwModeMask indique quel état diffère par rapport à l'événement HW mode précédent.

uint16_t Vector::BLF::MostHwMode::hwMode {}

contournement/maître/esclave/espion

  • Bit 0x01 : Contournement : 0 : ouvert ; 1 : actif
  • Bit 0x02 : Mode de synchronisation : 0 : esclave ; 1 : maître
  • Bit 0x04 : Mode maître : 0 : maître statique ; 1 : maître non statique
  • Bit 0x08 : 0 : Espion Ethernet actif : 1 : bloque le canal 'Espion Ethernet sur MOST'
  • Bit 0x10 : Espion de canal de contrôle : 1 : actif
  • Bit 0x20 : Espion de canal asynchrone : 1 : actif
  • Bit 0x40 : 1 : pas d'événements 'Ethernet sur MOST' (MOST150)
  • Bit 0x80 : 1 : pas d'événements du canal asynchrone
