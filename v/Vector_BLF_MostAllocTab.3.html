std::vector<uint8_t> Vector::BLF::MostAllocTab::tableData {}

Table d'allocation

Le label d'une connexion synchrone peut être réparti sur plusieurs octets dans la Table d'allocation.

Chaque octet de mTableData contient une valeur qui spécifie le numéro d'identification du label auquel il appartient. Si le périphérique est un maître de synchronisation, le MSB de la valeur de l'octet est utilisé pour indiquer si le label est utilisé ou non, sinon le MSB doit être ignoré. Le numéro de label peut donc être déterminé par la valeur de l'octet & 0x7F. Si le numéro de label résultant est 0x70, l'octet n'est utilisé pour aucun label.
