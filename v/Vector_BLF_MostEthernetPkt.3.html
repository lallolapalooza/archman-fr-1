uint8_t Vector::BLF::MostEthernetPkt::state {}

État de transmission États de transmission des messages et paquets MOST50/150.

•
Bit 0 : Signification :
•
0 : bus inactif
•
1 : bus actif Restriction :
•
uniquement pour Dir = Rx ou mTransferType = Spy
•
Bit 4 : Signification :
•
1 : acquitté (Ack) Restriction
•
uniquement pour mTransferType = Node et Dir = Tx (toujours défini à 1 pour les messages Rx en mode nœud)
•
Bit 5 : Signification :
•
1 : non acquitté (NAck) Restriction :
•
uniquement pour Dir = Tx
•
Bit 6 : Signification : Résultat d'envoi :
•
0 : Erreur de transmission (TxF)
•
1 : OK Restriction :
•
uniquement pour Dir = Tx
•
uniquement pour mTransferType = Node

uint8_t Vector::BLF::MostEthernetPkt::transferType {}

Type de transfert. Les événements de type message peuvent être enregistrés soit via la puce émetteur-récepteur MOST, soit via un espion réseau séparé.

  • 1 : Le rapporteur de l'émetteur-récepteur MOST a rapporté le message (soit en raison d'une réception réussie, soit en guise d'acquittement pour une demande d'émission).
  • 2 : Message d'espion signalé par l'espion réseau. L'espion voit tous les messages indépendamment de l'adresse de destination.
