struct FlexRayVFrStartCycle {

Detailed Description

FlexRay VFrStartCycle object. Holds information about the start cycle in a FlexRay frame.

A FlexRay VFrStartCycle object is defined as:

The FlexRay VFrStartCycle object is composed of the following fields:

  • uint16_t version: Version of the data structure.

The possible values for the version field are:

  • 1 = Not defined

  • 2 = Reserved

  • 3 = BUSDOCTOR

  • 4 = Cyclone II

  • 5 = Vector VN interface

  • 6 = VN-Sync-Pulse (only in Status Event, for debugging purposes only)
