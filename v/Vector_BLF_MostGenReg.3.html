Description détaillée

MOST_GENREG.

Cet événement signale le changement d'un registre émetteur-récepteur important comme la position du nœud ou l'adresse du nœud. Il peut survenir spontanément ou à la suite d'une opération de lecture/écriture. Juste après le début de la mesure, les valeurs actuelles des registres spéciaux sont rapportées même si elles n'ont pas changé.

uint16_t Vector::BLF::MostGenReg::regId {}

identifiant de registre Identifiants pour identifier les registres.

  • Empty = 0x0
  • NPR = 0x87 : registre de position de nœud sur 8 bits
  • GA = 0x89 : groupe sur 8 bits (adresse de groupe = 0x0300 + groupe)
  • NA = 0x8A : adresse de nœud sur 16 bits
  • NDR = 0x8F : délai de nœud sur 8 bits (MOST25 uniquement)
  • MPR = 0x90 : nombre de nœuds avec bypass ouvert sur 8 bits
  • MDR = 0x91 : délai maximum sur 8 bits (MOST25 uniquement)
  • SBC = 0x96 : contrôle de bande passante synchrone (SBC) sur 8 bits
•
Bande passante synchrone = 4 x SBC
•
Valeurs maximales pour SBC :
•
MOST25 : 15 (= 60 octets)
•
MOST50 : 29 (= 116 octets)
•
MOST150 : 93 (= 372 octets)
  • APA = 0xE8 : adresse de paquet alternée sur 16 bits (MOST25 uniquement)
  • XTIM = 0xBE : temps de nouvelle tentative de transmission sur 8 bits
  • XRTY = 0xBF : nombre de tentatives d'envoi sur 8 bits
  • MacAdr = 0xFE : adresse MAC sur 48 bits (EUI-48, conforme à la norme IEEE ; MOST150 uniquement)
