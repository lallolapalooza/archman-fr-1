Description détaillée

LIN_CHECKSUM_INFO.

Cet événement d'information se produit lorsque le matériel LIN a correctement détecté le modèle de checksum d'une trame inconnue. Ce modèle de checksum est défini comme le modèle attendu pour cette trame à l'avenir.
