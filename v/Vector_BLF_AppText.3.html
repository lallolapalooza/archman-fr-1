uint32_t Vector::BLF::AppText::source {}

source du texte Définit la source/la sémantique du texte. En fait, deux valeurs différentes sont définies :

0 : Commentaire de mesure

  • réservé n'est pas utilisé
  • texte contient un commentaire de mesure

1 : Informations de canal de base de données

  • réservé contient des informations de canal. Le tableau suivant
  • montre comment les 4 octets sont utilisés :
•
Bits 0-7 : Version des données
•
Bits 8-15 : Numéro du canal
•
Bits 15-23 : Type de bus du canal. Une des valeurs suivantes :
•
1 : BL_BUSTYPE_CAN
•
5 : BL_BUSTYPE_LIN
•
6 : BL_BUSTYPE_MOST
•
7 : BL_BUSTYPE_FLEXRAY
•
9 : BL_BUSTYPE_J1708
•
10 : BL_BUSTYPE_ETHERNET
•
13 : BL_BUSTYPE_WLAN
•
14 : BL_BUSTYPE_AFDX
•
Bit 24 : Indicateur déterminant si le canal est un canal CAN- FD
•
Bits 25-31 : Non utilisés pour le moment
•
texte contient des informations de base de données pour le canal spécifique. Chaque base de données est définie par le chemin de la base de données et le nom du cluster (si disponible). Les bases de données individuelles et le nom du cluster sont séparés par un point-virgule. Exemple : <Path1>;<ClusterName1>;<Path2>;<ClusterName2>;... Si une base de données n'a pas de nom de cluster disponible, une chaîne vide est écrite comme nom de cluster.
