std::array<uint32_t, 4> Vector::BLF::FlexRayVFrError::data {}

flags d'enregistrement Flags du pilote pour usage interne

Type de CC : Cyclone I

•
data[0]: Flags d'erreur de l'API du pilote

Type de CC : Cyclone II

•
data[0]: Flag du paquet d'erreur :
•
0 = Pas d'erreur
•
1 = Dépassement FlexCard
•
2 = Changement de mode d'erreur PCO
•
3 = Images de synchronisation inférieures au minimum
•
4 = Dépassement d'image de synchronisation
•
5 = Échec de correction d'horloge
•
6 = Erreur de parité
•
7 = Dépassement du FIFO de réception
•
8 = Accès FIFO vide
•
9 = Accès au tampon d'entrée illégal
•
10 = Accès au tampon de sortie illégal
•
11 = Erreur de syntaxe
•
12 = Erreur de contenu
•
13 = Violation de limite de slot
•
14 = Transmission hors limite
•
15 = Violation de transmission la plus tardive
•
data[1]: uint32_t la disposition dépend de la valeur du paquet d'erreur (voir ligne précédente)
•
Paquet d'erreur=2 :
•
0 = État inconnu
•
1 = Spécification du protocole FlexRay > CONFIG
•
2 = Spécification du protocole FlexRay > NORMAL_ACTIVE
•
3 = Spécification du protocole FlexRay > NORMAL_PASSIVE
•
4 = Spécification du protocole FlexRay > HALT
•
5 = Spécification du protocole FlexRay > READY
•
6 = Spécification du protocole FlexRay > STARTUP
•
7 = Spécification du protocole FlexRay > WAKEUP
•
Paquet d'erreur = 3 ou 4 :
•
Bits 0..3 > Images de synchronisation paires sur le canal A
•
Bits 4..7 > Images de synchronisation paires sur le canal B
•
Bits 8..11 > Images de synchronisation impaires sur le canal A
•
Bits 12..15 > Images de synchronisation impaires sur le canal B
•
Err or packet = 5:
•
Bit 0 > Correction de débit manquante
•
Bit 1 > Limite de correction de débit atteinte
•
Bit 2 > Limite de correction de décalage atteinte
•
Bit 3 > Correction de décalage manquante
•
Bit 4..7 > Images de synchronisation même sur le canal A
•
Bits 8..11 > Images de synchronisation même sur le canal B
•
Bits 12..15 > Images de synchronisation impaires sur le canal A
•
Bits 16..19 > Images de synchronisation impaires sur le canal B
•
Paquet d'erreur = 11..15:
•
MOT FAIBLE de mData[1] > Canal
•
MOT FORT de mData[1] > Compteur de slots

CC-Type: BUSDOCTOR

•
data[0]: Indicateurs d'erreur de l'API du pilote

CC-Type: VN-Interface

•
data[0]: Étiquette d'erreur:
•
0 = FR_ERROR_POC_MODE
•
1 = FR_ERROR_SYNC_FRAMES_BELOWMIN
•
2 = FR_ERROR_SYNC_FRAMES_OVERLOAD
•
3 = FR_ERROR_CLOCK_CORR_FAILURE
•
4 = FR_ERROR_NIT_FAILURE
•
5 = FR_ERROR_CC_ERROR
•
6 = FR_ERROR_OVERFLOW
•
data[1] et data[2]: la disposition de uint32_t dépend de la valeur de l'étiquette d'erreur (voir la ligne précédente):
•
Étiquette d'erreur = 0:
•
Valeur 0: FR_ERROR_POC_ACTIVE
•
Valeur 1: FR_ERROR_POC_PASSIVE
•
Valeur 2: FR_ERROR_POC_COMM_HALT
•
Étiquette d'erreur = 1 ou 2:
•
Bits 0..3: Images de synchronisation même sur le canal A
•
Bits 4..7: Images de synchronisation même sur le canal B
•
Bits 8..11: Images de synchronisation impaires sur le canal A
•
Bits 12..15: Images de synchronisation impaires sur le canal B
•
Étiquette d'erreur = 3:
•
Bit 0: Correction de débit manquante
•
Bit 1: Limite de correction de débit atteinte
•
Bit 2: Limite de correction de décalage atteinte
•
Bit 3: Correction de décalage manquante
•
Bits 4..19: Compteur d'échec de correction d'horloge
•
Bits 20..23: Images de synchronisation même sur le canal A
•
Bits 24..27: Images de synchronisation même sur le canal B
•
Bits 28..31: Images de synchronisation impaires sur le canal A
•
Bits 32..35: Images de synchronisation impaires sur le canal B
•
Étiquette d'erreur = 4:
•
Valeur 1: FR_ERROR_NIT_SENA
•
Valeur 2: FR_ERROR_NIT_SBNA
•
Valeur 4: FR_ERROR_NIT_SENB
•
Valeur 8: FR_ERROR_NIT_SBNB
•
Étiquette d'erreur = 5:
•
Valeur 0x00000001: Changement du mode POC d'erreur
•
Valeur 0x00000004: Images de synchronisation inférieures au minimum
•
Valeur 0x00000008: Dépassement d'images de synchronisation
•
Valeur 0x00000010: Échec de correction d'horloge
•
Valeur 0x00000040: Erreur de parité, données de MHDS (erreur interne ERay)
•
Valeur 0x00000200: Accès illégal au tampon d'entrée (erreur interne ERay)
•
Valeur 0x00000400: Accès illégal au tampon de sortie (erreur interne ERay)
•
Valeur 0x00000800: Données du drapeau de contraintes du gestionnaire de messages de MHDF (erreur interne ERay)
•
Valeur 0x00010000: Détection d'erreur sur le canal A, données d'ACS
•
Valeur 0x00020000: Dernière violation de transmission sur le canal A
•
Valeur 0x00040000: Transmission au-delà de la limite sur le canal A
•
Valeur 0x01000000: Détection d'erreur sur le canal B, données d'ACS
•
Valeur 0x02000000: Dernière violation de transmission sur le canal B
•
Valeur 0x04000000: Transmission au-delà de la limite sur le canal B

uint32_t Vector::BLF::FlexRayVFrError::tag {}

type de type de contrôleur de communication CC

  • 0 = Indépendant de l'architecture
  • 1 = Type CC invalide (pour usage interne uniquement)
  • 2 = Cyclone I
  • 3 = BUSDOCTOR
  • 4 = Cyclone II
  • 5 = Interface Vector VN
  • 6 = Pulse de synchronisation VN (uniquement dans l'événement de statut, à des fins de débogage uniquement)
