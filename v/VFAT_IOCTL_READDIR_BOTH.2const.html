VFAT_IOCTL_READDIR_BOTH(2const) VFAT_IOCTL_READDIR_BOTH(2const)

NOM

VFAT_IOCTL_READDIR_BOTH, VFAT_IOCTL_READDIR_SHORT - lire les noms de fichiers d'un répertoire dans un système de fichiers FAT

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <linux/msdos_fs.h>  /* Définition des constantes VFAT_* */
#include <sys/ioctl.h>
int ioctl(int fd, VFAT_IOCTL_READDIR_BOTH,
          struct __fat_dirent entry[2]);
int ioctl(int fd, VFAT_IOCTL_READDIR_SHORT,
          struct __fat_dirent entry[2]);

DESCRIPTION

Un fichier ou un répertoire sur un système de fichiers FAT a toujours un nom de fichier court composé de 8 lettres capitales maximum, éventuellement suivi d'un point et de 3 lettres capitales maximum pour l'extension du fichier. Si le nom de fichier réel ne correspond pas à ce schéma, il est stocké sous forme de nom de fichier long de 255 caractères UTF-16 maximum.

Les noms de fichiers courts d'un répertoire peuvent être lus avec VFAT_IOCTL_READDIR_SHORT. VFAT_IOCTL_READDIR_BOTH lit les noms de fichiers courts et longs.

L'argument fd doit être un descripteur de fichier pour un répertoire. Il suffit de créer le descripteur de fichier en appelant open(2) avec le drapeau O_RDONLY. Le descripteur de fichier ne peut être utilisé qu'une seule fois pour parcourir les entrées du répertoire en appelant ioctl(2) de manière répétée.

L'argument entry est un tableau de deux éléments des structures suivantes :


struct __fat_dirent {
    long            d_ino;
    __kernel_off_t  d_off;
    uint32_t short  d_reclen;
    char            d_name[256];
};

La première entrée du tableau concerne le nom de fichier court. La seconde entrée concerne le nom de fichier long.

Les champs d_ino et d_off sont remplis uniquement pour les noms de fichiers longs. Le champ d_ino contient le numéro d'inode du répertoire. Le champ d_off contient le décalage de l'entrée de fichier dans le répertoire. Comme ces valeurs ne sont pas disponibles pour les noms de fichiers courts, le code utilisateur doit simplement les ignorer.

Le champ d_reclen contient la longueur du nom de fichier dans le champ d_name. Pour conserver la compatibilité ascendante, une longueur de 0 pour le nom de fichier court signale que la fin du répertoire a été atteinte. Cependant, la méthode préférée pour détecter la fin du répertoire est de tester la valeur de retour de ioctl(2). S'il n'y a pas de nom de fichier long, le champ d_reclen est mis à 0 et d_name est une chaîne de caractères de longueur 0 pour le nom de fichier long.

VALEUR DE RETOUR

Une valeur de retour de 1 signale qu'une nouvelle entrée de répertoire a été lue et une valeur de retour de 0 signale que la fin du répertoire a été atteinte.

En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

ENOENT
fd fait référence à un répertoire supprimé, mais toujours ouvert.
ENOTDIR
fd ne fait pas référence à un répertoire.

NORMES

Linux.

HISTORIQUE

Linux 2.0.

EXEMPLES

Le programme suivant démontre l'utilisation de ioctl(2) pour lister un répertoire.

Ce qui suit a été enregistré lors de l'application du programme au répertoire /mnt/user :


$ ./fat_dir /mnt/user;
. -> ''
.. -> ''
ALONGF~1.TXT -> 'a long filename.txt'
UPPER.TXT -> ''
LOWER.TXT -> 'lower.txt'

Source du programme

#include <fcntl.h>
#include <linux/msdos_fs.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/ioctl.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int                  fd;
    int                  ret;
    struct __fat_dirent  entry[2];
    if (argc != 2) {
        printf("Usage: %s REPERTOIRE\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /*
     * Ouvre le descripteur de fichier pour le répertoire.
     */
    fd = open(argv[1], O_RDONLY | O_DIRECTORY);
    if (fd == -1) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    for (;;) {
        /*
         * Lit l'entrée de répertoire suivante.
         */
        ret = ioctl(fd, VFAT_IOCTL_READDIR_BOTH, entry);
        /*
         * Si une erreur survient, la valeur de retour est -1.
         * Si la fin de la liste du répertoire a été atteinte,
         * la valeur de retour est 0.
         * Pour la compatibilité ascendante, la fin de la liste du répertoire
         * est également signalée par d_reclen == 0.
         */
        if (ret < 1)
            break;
        /*
         * Affiche le nom court et le nom long.
         */
        printf("%s -> '%s'\n", entry[0].d_name, entry[1].d_name);
    }
    if (ret == -1) {
        perror("VFAT_IOCTL_READDIR_BOTH");
        exit(EXIT_FAILURE);
    }
    /*
     * Ferme le descripteur de fichier.
     */
    close(fd);
    exit(EXIT_SUCCESS);
}
