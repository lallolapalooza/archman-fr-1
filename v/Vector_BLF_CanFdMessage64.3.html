Vector_BLF_CanFdMessage64 - structure for a CAN FD message

SYNOPSIS

struct CanFdMessage64 {

  uint32_t flags;
};

Detailed Description

This structure represents a CAN FD message in the Vector BLF log format.

Member Function Documentation

uint32_t Vector::BLF::CanFdMessage64::flags {}

Flags for the CAN FD message.

  • Bit#=0 (0x0001): Must be 0
  • Bit#=1 (0x0002): Reserved, for internal use
  • Bit#=2 (0x0004): 1=NERR (1=single wire on low speed CAN)
  • Bit#=3 (0x0008): 1=High voltage wake up
  • Bit#=4 (0x0010): 1=Remote frame (only CAN)
  • Bit#=5 (0x0020): Reserved, must be 0
  • Bit#=6 (0x0040): 1=Tx Acknowledge
  • Bit#=7 (0x0080): 1=Tx Request
  • Bit#=8 (0x0100): Reserved, must be 0
  • Bit#=9 (0x0200): SRR (CAN FD)
  • Bit#=10 (0x0400): R0
  • Bit#=11 (0x0800): R1
  • Bit#=12 (0x1000): EDL, 0: CAN frame, 1: CAN FD frame
  • Bit#=13 (0x2000): BRS (CAN FD)
  • Bit#=14 (0x4000): ESI
  • Bit#=15 (0x8000): Reserved, must be 0
  • Bit#=16 (0x10000): Reserved, must be 0
  • Bit#=17 (0x20000): 1=Frame is part of a burst
  • Bit#=18-31: Reserved, must be 0

uint32_t Vector::BLF::CanFdMessage64::flags {}

Indicateurs du message CAN FD.

  • Bit#=0 (0x0001): Doit être 0
  • Bit#=1 (0x0002): Réservé, pour usage interne
  • Bit#=2 (0x0004): 1=NERR (1=fil unique sur CAN basse vitesse)
  • Bit#=3 (0x0008): 1=Réveil haute tension
  • Bit#=4 (0x0010): 1=Trame distante (CAN uniquement)
  • Bit#=5 (0x0020): Réservé, doit être 0
  • Bit#=6 (0x0040): 1=Accusé de réception d'émission
  • Bit#=7 (0x0080): 1=Requête d'émission
  • Bit#=8 (0x0100): Réservé, doit être 0
  • Bit#=9 (0x0200): SRR (CAN FD)
  • Bit#=10 (0x0400): R0
  • Bit#=11 (0x0800): R1
  • Bit#=12 (0x1000): EDL, 0: trame CAN, 1: trame CAN FD
  • Bit#=13 (0x2000): BRS (CAN FD)
  • Bit#=14 (0x4000): ESI
  • Bit#=15 (0x8000): Réservé, doit être 0
  • Bit#=16 (0x10000): Réservé, doit être 0
  • Bit#=17 (0x20000): 1=La trame fait partie d'un burst
  • Bit#=18-31: Réservé, doit être 0
