ioctl_vt(2) Manuel des appels système ioctl_vt(2)

NOM

ioctl_vt - ioctls pour les terminaux console et les consoles virtuelles

SYNTAXE

#include <linux/vt.h>  /* Définition des constantes VT_* */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPTION

Les opérations ioctl(2) suivantes, spécifiques à Linux, sont supportées pour les terminaux console et les consoles virtuelles.

VT_OPENQRY
Retourne la première console disponible (non ouverte). argp pointe vers un int qui est défini comme le numéro de la vt (1 <= *argp <= MAX_NR_CONSOLES).
VT_GETMODE
Obtenir le mode de la vt active. argp pointe vers une

struct vt_mode {
    char  mode;    /* mode vt */
    char  waitv;   /* si défini, attendre lors des écritures si non actif */
    short relsig;  /* signal à élever lors de l'opération de libération */
    short acqsig;  /* signal à élever lors de l'acquisition */
    short frsig;   /* inutilisé (mis à 0) */
};

qui est définie au mode de la vt active. mode est défini comme l'une de ces valeurs :
VT_AUTO commutation automatique de vt
VT_PROCESS le processus contrôle la commutation
VT_ACKACQ accuser réception de la commutation
VT_SETMODE
Définir le mode de la vt active. argp pointe vers une struct vt_mode.
VT_GETSTATE
Obtenir des informations sur l'état global des vt. argp pointe vers une

struct vt_stat {
    unsigned short v_active;  /* vt active */
    unsigned short v_signal;  /* signal à envoyer */
    unsigned short v_state;   /* masque de bits des vt */
};

Pour chaque vt en cours d'utilisation, le bit correspondant dans le membre v_state est défini. (Linux 1.0 à Linux 1.1.92.)
VT_RELDISP
Libérer un écran.
VT_ACTIVATE
Basculer vers la vt argp (1 <= argp <= MAX_NR_CONSOLES).
VT_WAITACTIVE
Attendre que la vt argp ait été activée.
VT_DISALLOCATE
Désallouer la mémoire associée à la vt argp. (Depuis Linux 1.1.54.)
VT_RESIZE
Définir la taille d'écran perçue par le noyau. argp pointe vers une

struct vt_sizes {
    unsigned short v_rows;       /* # lignes */
    unsigned short v_cols;       /* # colonnes */
    unsigned short v_scrollsize; /* n'est plus utilisé */
};

Notez que cela ne modifie pas le mode vidéo. Voir resizecons(8). (Depuis Linux 1.1.54.)
VT_RESIZEX
Définir les divers paramètres d'écran perçus par le noyau. argp pointe vers une

struct vt_consize {
    unsigned short v_rows;  /* nombre de lignes */
    unsigned short v_cols;  /* nombre de colonnes */
    unsigned short v_vlin;  /* nombre de lignes de pixels
                               à l'écran */
    unsigned short v_clin;  /* nombre de lignes de pixels
                               par caractère */
    unsigned short v_vcol;  /* nombre de colonnes de pixels
                               à l'écran */
    unsigned short v_ccol;  /* nombre de colonnes de pixels
                               par caractère */
};

Tout paramètre peut être défini à zéro, indiquant "aucun changement", mais si plusieurs paramètres sont définis, ils doivent être cohérents entre eux. Notez que cela ne modifie pas le mode vidéo. Voir resizecons(8). (Depuis Linux 1.3.3.)
VT_GETCONSIZECSRPOS
Obtenir la taille de la console et la position du curseur. argp pointe vers une

struct vt_consizecsrpos {
    __u16 con_rows;  /* nombre de lignes de la console */
    __u16 con_cols;  /* nombre de colonnes de la console */
    __u16 csr_row;   /* ligne du curseur actuel */
    __u16 csr_col;   /* colonne du curseur actuel */
};

(Depuis Linux 6.16.)

VALEUR RETOUR

En cas de succès, 0 est retourné (sauf indication contraire). En cas d'échec, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
argp est invalide.

NORMES

Linux.

VOIR AUSSI

ioctl(2), ioctl_console(2)
