uint32_t Vector::BLF::CanErrorFrameExt::flags {}

indicateurs étendus de la trame d'erreur CAN Définit quelles informations supplémentaires sont valides. Les valeurs suivantes sont possibles :

  • 1 : L'ECC SJA 1000 est valide (membre ecc)
  • 2 : Le code d'erreur Vector CAN Core est valide.
  • 4 : Position de l'erreur Vector CAN Core
  • 8 : Longueur de trame en ns du Vector CAN Core
