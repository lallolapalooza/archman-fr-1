uint16_t Vector::BLF::AfdxFrame::afdxFlags {}

Indicateurs de statut et d'erreur sous la forme :

  • Bit 0 : Trame provenant de la ligne B
  • Bit 1 : Paquet redondant
  • Bit 2 : Trame fragmentée uniquement
  • Bit 3 : Trame déjà réassemblée
  • Bit 4 : Paquet non valide comme trame AFDX
  • Bit 5 : AFDX-SequenceNo invalide
  • Bit 6 : Délai de redondance dépassé
  • Bit 7 : Erreur de redondance rencontrée
  • Bit 8 : Incompatibilité d'interface A / B
  • Bit 11 : Erreur de fragmentation
