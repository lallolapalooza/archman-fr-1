uint8_t Vector::BLF::Most50Pkt::ackNack {}

code d'acquittement AckNack contient le statut de transmission d'un message de contrôle (voir le registre de statut de transmission de l'OS8104 pour MOST25).

•
Bit 0 : Signification :
•
1 : pas de réponse (NoResp) Restriction :
•
uniquement pour Dir = Tx ou messages espions
•
Bit 1 : Signification :
•
1 : réception valide (Valid) Restriction :
•
uniquement pour Dir = Tx ou messages espions
•
Bit 2 : Signification :
•
1 : Erreur CRC (CRCError) Restriction :
•
uniquement pour Dir = Tx ou messages espions
•
Bit 3 : Signification :
•
1 : tampon de réception plein (RxBufFull) Restriction :
•
uniquement pour Dir = Tx ou messages espions
•
Bit 4 : Signification :
•
1 : acquitté (Ack) Restriction :
•
uniquement pour Dir = Tx ou messages espions (toujours mis à 1 pour les messages Rx en mode nœud)
•
Bit 5 : Signification :
•
1 : acquittement négatif (NAck) Restriction :
•
uniquement pour Dir = Tx ou messages espions

uint8_t Vector::BLF::Most50Pkt::state {}

état de transmission États de transmission des messages et paquets MOST50/150.

•
Bit 0 : Signification :
•
0 : bus inactif
•
1 : bus actif Restriction :
•
uniquement pour Dir = Rx ou mTransferType = Spy
•
Bit 4 : Signification :
•
1 : acquitté (Ack) Restriction
•
uniquement pour mTransferType = Node et Dir = Tx (toujours défini sur 1 pour les messages Rx en mode nœud)
•
Bit 5 : Signification :
•
1 : non acquitté (NAck) Restriction :
•
uniquement pour Dir = Tx
•
Bit 6 : Signification : Résultat de l'envoi :
•
0 : Erreur de transmission (TxF)
•
1 : OK Restriction :
•
uniquement pour Dir = Tx
•
uniquement pour mTransferType = Node

uint8_t Vector::BLF::Most50Pkt::transferType {}

Type de transfert. Les événements de type message peuvent être enregistrés via la puce de transceiver MOST ou via un espion réseau séparé.

  • 1 : Le transceiver MOST du nœud a signalé le message (soit en raison d'une réception réussie, soit comme accusé de réception pour une demande de transmission).
  • 2 : Message espion Le message a été signalé par l'espion réseau. L'espion voit tous les messages indépendamment de l'adresse de destination.
