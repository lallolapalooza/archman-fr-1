Vector_BLF_TestStructure - Structure pour les tests de BLF de Vector.

NAME

Vector_BLF_TestStructure - Structure pour les tests de BLF de Vector.

SYNOPSIS


struct Vector_BLF_TestStructure {
    // Données membres publiques
    uint64_t timestamp;
    uint32_t msg_id;
    uint8_t data[8];
    uint8_t data_len;
};

DESCRIPTION

La structure Vector_BLF_TestStructure est utilisée pour représenter les données d'un message BLF (Binary Logging Format) de Vector, typiquement dans le cadre de tests ou d'émulation.

Elle contient les champs suivants :

  • timestamp : L'horodatage du message en nanosecondes.
  • msg_id : L'identifiant du message.
  • data : Les données du message (jusqu'à 8 octets).
  • data_len : La longueur effective des données dans le champ data.

PUBLIC FUNCTIONS

Cette structure ne définit pas de fonctions membres publiques directement. Les opérations sur cette structure sont généralement effectuées par des fonctions externes ou des méthodes de classes qui l'utilisent.

PUBLIC VARIABLES

Documentation des données membres

  • timestamp

    Type : uint64_t

    Description : L'horodatage du message en nanosecondes depuis une époque de référence (souvent le début de la mesure ou du fichier log).

  • msg_id

    Type : uint32_t

    Description : L'identifiant unique du message CAN ou autre protocole véhiculé.

  • data

    Type : uint8_t[8]

    Description : Un tableau d'octets contenant la charge utile du message. La taille maximale est de 8 octets, correspondant à la taille standard d'une trame CAN.

  • data_len

    Type : uint8_t

    Description : Indique le nombre d'octets valides dans le tableau data. Doit être inférieur ou égal à 8.
