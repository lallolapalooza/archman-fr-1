Vector_BLF_CanDriverErrorExt.3

Nom

Vector_BLF_CanDriverErrorExt - Informations sur les erreurs du pilote CAN BLF

Synopsis

#include <blf/vector_blf.h>

Description

La fonction Vector_BLF_CanDriverErrorExt récupère des informations détaillées sur les erreurs survenues lors de l'utilisation du pilote CAN de Vector BLF. Elle est utile pour le débogage et la gestion des erreurs dans les applications qui utilisent ce pilote.

Syntaxe

int Vector_BLF_CanDriverErrorExt(int errorCode, char *errorBuffer, int bufferSize);

Paramètres

errorCode
Le code d'erreur retourné par une opération précédente du pilote CAN.
errorBuffer
Un pointeur vers un tampon où la description textuelle de l'erreur sera stockée.
bufferSize
La taille du tampon errorBuffer en octets.

Valeur de retour

Retourne 0 en cas de succès, ou un code d'erreur négatif en cas d'échec. Si la description de l'erreur est tronquée car le tampon est trop petit, une valeur d'erreur appropriée est retournée.

Exemple

#include <stdio.h>
#include <blf/vector_blf.h>

int main() {
    int error_code;
    char error_desc[256];

    // Supposons qu'une opération précédente du pilote ait retourné une erreur
    error_code = -101; // Exemple de code d'erreur

    if (Vector_BLF_CanDriverErrorExt(error_code, error_desc, sizeof(error_desc)) == 0) {
        printf("Erreur du pilote CAN BLF (Code: %d): %s\n", error_code, error_desc);
    } else {
        printf("Impossible d'obtenir la description de l'erreur %d\n", error_code);
    }

    return 0;
}
