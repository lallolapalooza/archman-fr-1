int Vector::BLF::File::compressionLevel {1}

niveau de compression

Niveaux de compression zlib :

  • 0 : Z_NO_COMPRESSION
  • 1 : Z_BEST_SPEED
  • 9 : Z_BEST_COMPRESSION

Niveaux de compression Vector BLF :

  • 0 : pas de compression
  • 6 : compression par défaut
  • 10 : compression maximale
