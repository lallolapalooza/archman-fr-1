uint8_t Vector::BLF::MostSpy::ackNack {}

AckNack contient l'état de transmission d'un message de contrôle (voir le Registre d'état de transmission d'OS8104 pour MOST25).

•
Bit 0 : Signification :
•
1 : pas de réponse (NoResp) Restriction :
•
uniquement pour les messages Dir = Tx ou spy
•
Bit 1 : Signification :
•
1 : réception valide (Valid) Restriction :
•
uniquement pour les messages Dir = Tx ou spy
•
Bit 2 : Signification :
•
1 : erreur CRC (CRCError) Restriction :
•
uniquement pour les messages Dir = Tx ou spy
•
Bit 3 : Signification :
•
1 : tampon de réception plein (RxBufFull) Restriction :
•
uniquement pour les messages Dir = Tx ou spy
•
Bit 4 : Signification :
•
1 : acquitté (Ack) Restriction :
•
uniquement pour les messages Dir = Tx ou spy (toujours défini à 1 pour les messages Rx en mode nœud)
•
Bit 5 : Signification :
•
1 : acquittement négatif (NAck) Restriction :
•
uniquement pour les messages Dir = Tx ou spy

uint16_t Vector::BLF::MostSpy::rTyp {}

Sous-type de message de contrôle. Sous-type d'un message de contrôle MOST 25 (voir également la fiche technique de l'OS8104).

  • 0 : Normal
  • 1 : RemoteRead
  • 2 : RemoteWrite
  • 3 : Alloc
  • 4 : Dealloc
  • 5 : GetSource
  • >5 : non utilisé jusqu'à présent

uint8_t Vector::BLF::MostSpy::rTypAdr {}

Mode d'adressage. Mode d'adressage des messages de contrôle MOST25.

  • 0x00 : Périphérique (adresse logique du nœud)
  • 0x10 : Position du nœud
  • 0x20 : Diffusion
  • 0x30 : Multidiffusion
  • 0xFF : Inconnu
