Description détaillée

LIN_SYN_ERROR2.

Les erreurs de synchronisation se produisent si le matériel LIN ne peut pas se synchroniser avec un maître externe. Cela peut se produire si le débit binaire réellement utilisé par le maître dévie de plus de 15 % du débit binaire spécifié par le matériel LIN. Dans ce cas, la valeur du débit binaire doit être modifiée. Cet événement d'erreur peut également se produire si le maître transmet un champ Sync invalide ou corrompu.

nSyncError - Description du fichier d'erreur de nSync

SYNTAXE

~/.config/nSync/nSyncError

DESCRIPTION

Ce fichier contient les messages d'erreur générés par l'application nSync. Il est situé dans le répertoire de configuration de l'utilisateur, sous ~/.config/nSync/.

Le fichier nSyncError est mis à jour à chaque fois qu'une erreur se produit lors de l'exécution de nSync. Les entrées sont généralement horodatées et fournissent des détails sur l'erreur, le contexte dans lequel elle s'est produite, et parfois des suggestions pour résoudre le problème.

OPTIONS

Ce fichier ne prend pas d'options en ligne de commande. Son contenu est généré par le comportement de l'application nSync.
