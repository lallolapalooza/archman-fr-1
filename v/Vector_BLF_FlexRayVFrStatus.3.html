Description détaillée

FR_STATUS.

Le contenu de l'événement de statut FlexRay dépend du type d'interface matérielle. L'événement est généré dans l'une des situations suivantes :

  • Un symbole est reçu
  • L'état POC ou l'état de réveil du CC a changé
  • L'état de la fenêtre de symboles a changé

std::array<uint32_t, 2> Vector::BLF::FlexRayVFrStatus::data {}

indicateurs d'enregistrement Indicateurs de pilote pour usage interne

Type de CC : Cyclone I

  • data[0] : Contenu du registre d'état du protocole (PSR)
  • data[1] : Contenu du registre de configuration du module (MCR0)

Type de CC : BUS DOCTOR

  • MOT FAIBLE de data[0] : Longueur du symbole
  • MOT HAUT de data[0] : Indicateurs : 1 = CAS possible
  • data[1] : Réservé

Type de CC : Interface VN

•
data[0] : État POC du registre E-Ray CCSV. Seulement valide
•
pour les interfaces Vector
•
si l'état de réveil est 0 État POC dans la phase de contrôle opérationnel :
•
0x00 : DEFAULT_CONFIG
•
0x01 : READY
•
0x02 : NORMAL_ACTIVE
•
0x03 : NORMAL_PASSIVE
•
0x04 : HALT
•
0x05 : MONITOR_NODE
•
0x06 : CONFIG État POC dans la phase de réveil :
•
0x10 : WAKEUP_STANDBY
•
0x11 : WAKEUP_LISTEN
•
0x12 : WAKEUP_SEND
•
0x13 : WAKEUP_DETECT État POC dans la phase de démarrage :
•
0x20 : STARTUP_PREPARE
•
0x21 : COLDSTART_LISTEN

0x22 : COLDSTART_COLLISION_RESOLUTION
•
0x23 : COLDSTART_CONSISTENCY_CHECK
•
0x24 : COLDSTART_GAP

•
0x27 : INTEGRATION_LISTEN

0x28 : INTEGRATION_CONSISTENCY_CHECK
•
0x29 : INITIALIZE_SCHEDULE
•
0x30 : ABORT_STARTUP
•
0x31 : STARTUP_SUCCESS Les autres valeurs sont réservées.
•
LOW-WORD de data[1] : Champ de bits indiquant l'état de la fenêtre de symboles du contrôleur et de la source d'événement.
•
1 : SESA (Erreur de syntaxe dans le canal A de la fenêtre de symboles)
•
2 : SBSA (Violation de frontière de slot dans le canal A de la fenêtre de symboles)
•
4 : TCSA (Conflit de transmission dans le canal A de la fenêtre de symboles)
•
8 : SESB (Erreur de syntaxe dans le canal B de la fenêtre de symboles)
•
16 : SBSB (Violation de frontière de slot dans le canal B de la fenêtre de symboles)
•
32 : TCSB (Conflit de transmission dans le canal B de la fenêtre de symboles)
•
64 : L'événement a été généré par un interpréteur de protocole indépendant du contrôleur (Spy).
•
128 : Indicateur POC de l'assistant de démarrage à froid ; s'il est défini, l'événement contient l'état POC de l'assistant de démarrage à froid. Tous les autres bits sont réservés. CANoe/CANalyzer peuvent définir certains de ces bits à 1. D'autres applications doivent les définir à 0.
•
HI-WORD de data[1] : Longueur du symbole en temps de bit. Uniquement valide pour le type de symbole 4 et si la valeur n'est pas zéro.

std::array<uint16_t, 18> Vector::BLF::FlexRayVFrStatus::reservedFlexRayVFrStatus2 {}

réservé reserved[0] : Si cette valeur n'est pas zéro, l'événement contient des informations sur un symbole.

  • 0 = Vide
  • 1 = CAS
  • 2 = MTS
  • 3 = WUS
  • 4 = L'interface réseau ne fournit pas d'interprétation de symbole, par exemple si le mode spy est utilisé ou l'interface BUSDOCTOR. En mode spy, la longueur du symbole est stockée dans le HI-WORD de data[1].

reserved[1..15] : Réservé

uint32_t Vector::BLF::FlexRayVFrStatus::tag {}

type de cc Type de contrôleur de communication

  • 0 = Indépendant de l'architecture
  • 1 = Type CC invalide (pour usage interne uniquement)
  • 2 = Cyclone I
  • 3 = BUSDOCTOR
  • 4 = Cyclone II
  • 5 = Interface Vector VN
  • 6 = VN-Sync-Pulse (uniquement dans l'événement de statut, à des fins de débogage uniquement)
