Description détaillée

Un élément qui représente une série de points.

Une courbe est la représentation d'une série de points en coordonnées polaires. Les points sont connectés à la courbe via l'interface abstraite QwtData.

Énumérateurs

NoCurve
Aucune courbe n'est dessinée. Note : Ceci n'affecte pas les symboles.
Lines
Connecte les points par des lignes droites. Les lignes peuvent être interpolées selon l'attribut 'Fitted'. La courbe peut être configurée avec setCurveFitter().
UserCurve
Les valeurs > 100 sont réservées aux styles de courbes spécifiques à l'utilisateur.

enum QwtPolarCurve::LegendAttribute

Attributs qui définissent comment représenter la courbe dans la légende. Si aucun des flags n'est activé, QwtPlotCurve essaie de trouver une couleur qui représente la courbe et en dessine un rectangle. Dans l'état par défaut, tous les attributs sont désactivés.

Énumérateurs

LegendShowLine
Si le style de courbe n'est pas NoCurve, une ligne est dessinée avec le stylo de la courbe.
LegendShowSymbol
Si la courbe a un symbole valide, il est dessiné.

DESCRIPTION

Cette classe implémente une courbe polaire dans le graphique polaire QwtPolarPlot. La courbe peut être dessinée comme une ligne, avec des bâtons, avec des points, ou pas du tout.

La classe QwtPolarCurve peut afficher des données sous forme de lignes et/ou de symboles. Les deux peuvent être activés simultanément.

Les couleurs et les styles de ligne sont définis par le QPen. Les symboles sont définis par un QwtSymbol.

La classe QwtPolarCurve prend en charge les attributs de légende suivants :

LegendAttribute::Show
Affiche la courbe dans la légende.

Voir aussi : QwtPolarItem::setLegendAttribute(), QwtLegend.

MEMBER ENUMERATION DOCUMENTATION

enum QwtPolarCurve::CurveStyle

Styles de dessin de courbe possibles.

NoCurve
Aucune courbe ne sera dessinée.
Line
La courbe sera dessinée comme une ligne.
Sticks
La courbe sera dessinée avec des bâtons (lignes verticales du rayon de base jusqu'à la valeur).
Dots
La courbe sera dessinée comme une série de points.

Les styles peuvent être combinés à l'aide de l'opérateur OU bit à bit.
