Description détaillée

Échantillon Open-High-Low-Close utilisé dans les graphiques financiers.

Dans les graphiques financiers, le mouvement d'un prix sur un intervalle de temps est souvent représenté par les prix d'ouverture/clôture et les prix les plus bas/plus élevés de cet intervalle.

bool QwtOHLCSample::isValid () const [inline]

Vérifie si un échantillon est valide. Un échantillon est valide lorsque toutes les vérifications suivantes sont vraies :

  • bas <= haut
  • bas <= ouverture <= haut
  • bas <= clôture <= haut

Retourne

True, si l'échantillon est valide
