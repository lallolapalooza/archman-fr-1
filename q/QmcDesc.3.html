QmcDesc(3)

Paquet: pcp

Licences: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

QMCDESC(3) Manuel des fonctions de bibliothèque QMCDESC(3)

NOM

QmcDesc - conteneur pour une description de métrique

SYNTAXE C++

#include <QmcDesc.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPTION

Un objet QmcDesc est un conteneur pour un descripteur de métrique (pmDesc, voir PMAPI(3)) et les unités.

CONSTRUCTEURS & DESTRUCTEUR

~QmcDesc();
Destructeur.
QmcDesc(pmID pmid);
Construit un conteneur pour le descripteur de pmid. Le descripteur est obtenu à partir du contexte PMAPI(3) actuel en utilisant pmLookupDesc(3).

DESCRIPTION

int status() const;
Un statut inférieur à zéro indique que le descripteur n'a pas pu être obtenu, l'erreur PMAPI(3) est codée dans le résultat.
pmID id() const;
Retourne le pmID de ce descripteur.
pmDesc desc() const;
Retourne une copie du descripteur de métrique réel.
const pmDesc *descPtr() const;
Retourne un pointeur vers le descripteur réel pour éviter d'utiliser un pointeur vers une temporaire.

UNITES

const QString &units() const;
La chaîne d'unités complète pour ce descripteur.
const QString &shortUnits() const;
La chaîne d'unités utilisant des abréviations.
bool useScaleUnits() const;
Retourne true si les unités ont été définies par un appel à QmcDesc::setScaleUnits.
const pmUnits &scaleUnits() const;
Retourne les unités de mise à l'échelle pour ce descripteur.
void setScaleUnits(const pmUnits &units);
Définit les unités de mise à l'échelle pour ce descripteur.

DIAGNOSTICS

Les messages d'erreur sont générés en utilisant pmprintf(3) mais ne sont pas vidés. Il est de la responsabilité de l'utilisateur d'appeler pmflush(3) pour afficher les messages.

Des diagnostics supplémentaires peuvent être activés en ajoutant l'option pmc à la spécification de débogage globale, comme décrit dans pmSetDebug(3).

VOIR AUSSI

PMAPI(3), QMC(3), pmflush(3), pmLookupDesc(3) et pmprintf(3).
