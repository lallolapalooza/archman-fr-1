Documentation de l'énumération membre

enum QwtCurveFitter::Mode

Mode préféré de l'algorithme d'ajustement. Même si un QPainterPath peut toujours être créé à partir d'un QPolygonF, le surcoût de la conversion peut être évité en indiquant la préférence de l'implémentation au code applicatif.

Énumérateur

Polygon
L'algorithme d'ajustement crée un polygone - l'implémentation de fitCurvePath() encapsule simplement le polygone dans un chemin.

Voir aussi

QwtWeedingCurveFitter
Path
L'algorithme d'ajustement crée un chemin de peintre - l'implémentation de fitCurve() extrait un polygone du chemin.
