Description Détaillée

QwtPlotZoomer fournit un zoom stylisé pour un widget graphique.

QwtPlotZoomer sélectionne des rectangles à partir des entrées de l'utilisateur (point de souris ou clavier), les traduit en coordonnées graphiques et ajuste les axes en conséquence. La sélection est supportée par une bande élastique et affiche éventuellement les coordonnées du point de souris actuel.

Le zoom peut être répété autant de fois que possible, limité uniquement par maxStackDepth() ou minZoomSize(). Chaque rectangle est placé dans une pile.

Le comportement par défaut pour la sélection de rectangles est un QwtPickerDragRectMachine avec les liaisons suivantes :

  • QwtEventPattern::MouseSelect1
    Le premier point du rectangle de zoom est sélectionné par un clic de souris, le second point est sélectionné à partir de la position où la souris est relâchée.
  • QwtEventPattern::KeySelect1
    La première pression de touche sélectionne le premier point, la seconde pression de touche sélectionne le second point.
  • QwtEventPattern::KeyAbort
    Annule la sélection dans l'état où le premier point est sélectionné.

Pour parcourir la pile de zoom, les liaisons suivantes sont utilisées :

  • QwtEventPattern::MouseSelect3, QwtEventPattern::KeyUndo
    Zoom arrière d'une position dans la pile de zoom.
  • QwtEventPattern::MouseSelect6, QwtEventPattern::KeyRedo
    Zoom avant d'une position dans la pile de zoom.
  • QwtEventPattern::MouseSelect2, QwtEventPattern::KeyHome
    Zoom à la base de zoom.

Les fonctions setKeyPattern() et setMousePattern() peuvent être utilisées pour configurer les actions du zoomer. L'exemple suivant montre comment configurer les touches 'I' et 'O' pour zoomer d'une position dans la pile de zoom. La touche 'Home' est utilisée pour 'dé-zoomer' le graphique.

zoomer = new QwtPlotZoomer( plot );
zoomer->setKeyPattern( QwtEventPattern::KeyRedo, Qt::Key_I, Qt::ShiftModifier );
zoomer->setKeyPattern( QwtEventPattern::KeyUndo, Qt::Key_O, Qt::ShiftModifier );
zoomer->setKeyPattern( QwtEventPattern::KeyHome, Qt::Key_Home );

QwtPlotZoomer est conçu pour les graphiques avec un axe x et un axe y, mais permet d'attacher un autre QwtPlotZoomer (sans bande élastique et traceur) pour les autres axes.

Note

L'exemple en temps réel inclut une classe dérivée de zoomer qui ajoute des barres de défilement à la fenêtre graphique.

QwtPlotZoomer::QwtPlotZoomer (QWidget * canvas, bool doReplot = true) [explicit]

Crée un zoomer pour un canevas de graphique. Le zoomer est configuré avec les axes x et y du graphique parent du canevas. Si les deux axes x sont activés ou aucun ne l'est, le sélecteur est défini sur QwtAxis::XBottom. Si les deux axes y sont activés ou aucun ne l'est, il est défini sur QwtAxis::YLeft.

Le zoomer est initialisé avec un QwtPickerDragRectMachine, le mode de traceur est défini sur QwtPicker::ActiveOnly et la bande élastique est définie sur QwtPicker::RectRubberBand

Paramètres

canvas Canevas de graphique à observer, c'est aussi l'objet parent
doReplot Appelle QwtPlot::replot() pour le graphique associé avant d'initialiser le zoomer avec ses échelles. Cela peut être nécessaire lorsque le graphique est dans un état avec des changements d'échelle en attente.

Voir aussi

QwtPlot::autoReplot(), QwtPlot::replot(), setZoomBase()

void QwtPlotZoomer::setMaxStackDepth (int depth)

Limite le nombre d'opérations de zoom récursives à depth. Une valeur de -1 définit depth à l'infini, 0 désactive le zoom. Si le rectangle de zoom actuel est au-delà de la profondeur, le graphique est dézoomé.

depth Maximum pour la profondeur de la pile
