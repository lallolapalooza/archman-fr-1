Description détaillée

Un dictionnaire pour les éléments de graphique.

QwtPlotDict organise les éléments de graphique par ordre z. Si autoDelete() est actif, tous les éléments attachés seront supprimés dans le destructeur du dictionnaire. QwtPlotDict peut être utilisé pour accéder à tous les QwtPlotItem du graphique, ou à tous les éléments d'un type spécifique.

QwtPlotDict(3)

QwtPlotDict est une classe qui agit comme un dictionnaire pour les objets QwtPlot.

Nom

QwtPlotDict - Dictionnaire pour les objets QwtPlot.

Description

La classe QwtPlotDict fournit une structure de données similaire à un dictionnaire pour stocker et gérer plusieurs objets QwtPlot. Elle permet d'associer des noms (chaînes de caractères) à des instances de QwtPlot, facilitant ainsi l'accès et la manipulation de plusieurs tracés dans une application.

Les principales opérations supportées incluent l'ajout, la suppression et la récupération d'objets QwtPlot par leur nom. Cela est particulièrement utile lorsque vous avez besoin de gérer dynamiquement un ensemble de graphiques.

Constructeur

La classe QwtPlotDict a un constructeur par défaut qui crée un dictionnaire vide.

QwtPlotDict();

Méthodes

  • void insert(const QString &name, QwtPlot *plot) : Insère un objet QwtPlot dans le dictionnaire avec le nom spécifié. Si un objet existe déjà avec ce nom, il sera remplacé.
  • QwtPlot *value(const QString &name) const : Retourne le pointeur vers l'objet QwtPlot associé au nom donné. Retourne nullptr si le nom n'est pas trouvé.
  • bool contains(const QString &name) const : Retourne true si un objet QwtPlot avec le nom donné existe dans le dictionnaire, false sinon.
  • void remove(const QString &name) : Supprime l'objet QwtPlot associé au nom donné du dictionnaire.
  • QStringList keys() const : Retourne une liste de tous les noms (clés) présents dans le dictionnaire.
  • int size() const : Retourne le nombre d'objets QwtPlot stockés dans le dictionnaire.

Exemple d'utilisation


#include <qwt_plot.h>
#include <qwt_plot_dict.h>
#include <QStringList>

int main() {
    QwtPlotDict plotDict;

    // Créer quelques objets QwtPlot
    QwtPlot *plot1 = new QwtPlot();
    QwtPlot *plot2 = new QwtPlot();

    // Insérer les tracés dans le dictionnaire
    plotDict.insert("Graphique Principale", plot1);
    plotDict.insert("Graphique Secondaire", plot2);

    // Vérifier si un tracé existe
    if (plotDict.contains("Graphique Principale")) {
        // Récupérer un tracé
        QwtPlot *mainPlot = plotDict.value("Graphique Principale");
        // Utiliser mainPlot...
    }

    // Obtenir la liste des noms de tracés
    QStringList plotNames = plotDict.keys();
    qDebug() << "Noms des tracés :" << plotNames;

    // Supprimer un tracé
    plotDict.remove("Graphique Secondaire");

    return 0;
}
