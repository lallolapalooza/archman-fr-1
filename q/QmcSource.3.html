QMCSOURCE(3) Manuel des fonctions de bibliothèque QMCSOURCE(3)

NOM

QmcSource - gère les contextes créés par tous les groupes

SYNTAXE C++

#include <QmcSource.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPTION

La classe QmcSource maintient une liste unique de toutes les sources de métriques utilisées afin de minimiser la création de nouveaux contextes (voir pmNewContext(3)) lorsque le contexte aurait pu être dupliqué (voir pmDupContext(3)). Cela réduit également la duplication des descriptions de chaque source.

En général, les utilisateurs de QMC n'auront besoin d'accéder qu'aux méthodes de QmcSource pour obtenir les descriptions de source pour un objet QmcContext(3). Toute création de contexte par l'utilisateur doit être gérée par QmcGroup(3).

DESTRUCTEUR

~QmcSource();
Destructeur.

CONSTRUCTEURS

static QmcSource* getSource(int type, const char* source,
bool matchHosts)

Cette méthode renverra un objet QmcSource qui représente un contexte de type pour source. L'objet QmcSource peut être un nouvel objet si la source n'a pas été précédemment demandée. La gestion de la mémoire des objets QmcSource est gérée par QmcSource. Si tous les QmcContext(3) vers le QmcSource ont été supprimés, l'objet QmcSource sera également supprimé.

Le drapeau matchHosts contrôle l'algorithme utilisé pour faire correspondre les hôtes aux archives. Si matchHosts est égal à false, cette méthode ne tentera pas de faire correspondre un contexte d'hôte à un contexte de source existant. Un objet QmcSource sera toujours renvoyé dans ce cas, bien que la méthode QmcSource::status puisse indiquer qu'une connexion à source a échoué.

Si matchHosts est égal à true, les contextes d'hôtes seront mis en correspondance avec une source d'archives prédéfinie collectée à partir de cette source. Si aucune source d'archives pour la source n'a été spécifiée précédemment, getSource renverra un pointeur NULL.

DIAGNOSTICS

Les messages d'erreur sont générés à l'aide de pmprintf(3) mais ne sont pas vidés. Il incombe à l'utilisateur d'appeler pmflush(3) pour afficher les messages.

Des diagnostics supplémentaires peuvent être activés en ajoutant l'option pmc à la spécification de débogage globale, comme décrit dans pmSetDebug(3).
