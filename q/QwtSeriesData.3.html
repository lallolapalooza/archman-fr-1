Description détaillée

template<typename T>

class QwtSeriesData< T >" Interface abstraite pour l'itération sur les échantillons.

Qwt propose plusieurs implémentations de l'API QwtSeriesData, mais dans les situations où des données au format spécifique à une application doivent être affichées, sans avoir à les copier, il est recommandé d'implémenter un accès aux données individuel.

Une sous-classe de QwtSeriesData<QPointF> doit implémenter :

  • size()
    Doit retourner le nombre de points de données.
  • sample()
    Doit retourner les valeurs x et y de l'échantillon à une position spécifique sous forme d'objet QPointF.
  • boundingRect()
    Doit retourner le rectangle englobant de la série de données. Il est utilisé pour l'autoscaling et peut aider certains algorithmes pour afficher les données. Vous pouvez utiliser qwtBoundingRect() pour une implémentation, mais il est souvent possible d'implémenter un algorithme plus efficace en fonction des caractéristiques de la série. Le membre cachedBoundingRect est destiné à la mise en cache du rectangle calculé.

template<typename T > virtual QRectF QwtSeriesData< T >::boundingRect () const [pure virtual]

Calcule le rectangle englobant de tous les échantillons

Le rectangle englobant est nécessaire pour l'autoscaling et peut être utilisé pour quelques optimisations de dessin.

qwtBoundingRect(...) propose des implémentations lentes itérant sur les échantillons. Pour de grands ensembles, il est recommandé d'implémenter quelque chose de plus rapide, par exemple en mettant en cache le rectangle englobant.
