Detailed Description

This class implements a plot item, that displays samples representing a spectrum. The spectrum is represented by a sequence of points (spectrogram) or by a curve where the value of the third dimension is mapped to a color. The color mapping is done by a QwtColorMap.

The SpectroCurve can be used to display values from different sources like:

* Magnitude spectra

* Color images (when the Z-value represents the intensity)

The curve can be rendered as a sequence of colored lines or dots. The rendering options can be controlled by setPaintAttribute() and setPenWidth().

The color mapping can be adjusted by setColorMap() and setColorRange().
