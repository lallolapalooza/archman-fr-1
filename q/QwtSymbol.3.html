Documentation des énumérations membres

enum QwtSymbol::CachePolicy

En fonction du moteur de rendu et de la complexité de la forme du symbole, il peut être plus rapide de rendre le symbole dans une image pixelisée et de peindre cette image pixelisée.

Exemple : le moteur de rendu logiciel est un rendu purement logiciel, où en mode cache, une opération de dessin se termine généralement par une opération de rastérisation avec le stockage en arrière-plan, qui est généralement plus rapide que les algorithmes de rendu de polygones. Cependant, on peut s'attendre au contraire pour les pipelines de rendu graphique qui peuvent exploiter l'accélération matérielle.

La valeur par défaut est AutoCache.

Voir aussi

setCachePolicy(), cachePolicy()

Note

La politique n'a aucun effet lorsque le symbole est rendu dans un format graphique vectoriel (PDF, SVG).

Avertissement

Depuis Qt 4.8, le raster est le backend par défaut sous X11.

Énumérateur

NoCache
Ne pas utiliser de cache d'image.
Cache
Utiliser toujours un cache d'image.
AutoCache
Utiliser un cache lorsqu'une des conditions suivantes est vraie :
•
Le symbole est rendu avec le moteur de rendu logiciel (QPaintEngine::Raster)

void QwtSymbol::setPath (const QPainterPath & path)

Définir un chemin de pinceau comme symbole. Le symbole est dessiné par un chemin de pinceau, où l'origine (0, 0) du système de coordonnées du chemin est mappée à la position du symbole.

Lorsque le symbole a une taille valide, le chemin de pinceau est mis à l'échelle pour s'adapter à la dimension. Sinon, la taille du symbole dépend du rectangle englobant du chemin.

Exemple

Le code suivant définit un symbole qui dessine une flèche :
#include <qwt_symbol.h>
     QwtSymbol *symbol = new QwtSymbol();
     QPen pen( Qt::black, 2 );
     pen.setJoinStyle( Qt::MiterJoin );
     symbol->setPen( pen );
     symbol->setBrush( Qt::red );
     QPainterPath path;
     path.moveTo( 0, 8 );
     path.lineTo( 0, 5 );
     path.lineTo( -3, 5 );
     path.lineTo( 0, 0 );
     path.lineTo( 3, 5 );
     path.lineTo( 0, 5 );
     QTransform transform;
     transform.rotate( -30.0 );
     path = transform.map( path );
     symbol->setPath( path );
     symbol->setPinPoint( QPointF( 0.0, 0.0 ) );
     setSize( 10, 14 );

Paramètres

path Chemin de pinceau

Note

Le style est implicitement défini sur QwtSymbol::Path

Voir aussi

path(), setSize()

void QwtSymbol::setPinPoint (const QPointF & pos, bool enable = true)

Définir et activer un point d'épingle. La position d'un symbole complexe n'est pas toujours alignée avec son centre (par exemple, une flèche dont la pointe pointe vers une position). Le point d'épingle définit la position dans un pixmap, un graphique, un document SVG ou un chemin de pinceau où le point représenté doit être aligné.
