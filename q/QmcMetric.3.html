QMCMETRIC(3) Manuel des fonctions de bibliothèque QMCMETRIC(3)

NOM

QmcMetric - conteneur pour une métrique et toutes ses valeurs

SYNOPHIS EN C++

#include <pcp/pmc/Metric.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPTION

Un objet QmcMetric est un conteneur pour une métrique unique et toutes ses valeurs.

La structure QmcMetricValue est utilisée pour contenir l'index de l'instance, les valeurs et les erreurs de chaque instance. Dans le cas d'une métrique singulière, un objet QmcMetricValue unique est utilisé.

Un objet QmcMetric se compose d'une liste d'objets QmcMetricValue, d'index vers les descripteurs dans le QmcGroup et le QmcContext de la métrique, et d'indicateurs pour signaler si les instances sont explicites ou implicites, et si seules les métriques actives sont requises après l'appel à QmcMetric::updateIndom.

CONSTRUCTEURS

Les métriques doivent être construites via les méthodes QmcGroup::addMetric car cela garantira que les références au contexte, au descripteur et au domaine d'instance de la métrique sont correctement initialisées.

INSTANCES

Pour les métriques avec un domaine d'instance, il est possible d'ajouter et de supprimer n'importe quelle instance, et également de mettre à jour la liste des instances pour refléter les changements dans un domaine d'instance dynamique.

bool updateIndom();
Met à jour la métrique pour inclure de nouvelles instances. Cette méthode appellera d'abord QmcContext::update pour mettre à jour le domaine d'instance. Si l'indicateur active est défini lors de l'appel à QmcGroup::addMetric, seules les instances exportées par la métrique seront incluses, sinon la métrique exportera toutes les instances listées dans le domaine.

L'ordre des instances peut changer à la suite de cet appel. Les instances qui existaient déjà conserveront leurs valeurs et erreurs actuelles et précédentes, même si elles sont dans un ordre différent.

int addInst(QString const& name);
Ajoute l'instance name à la métrique. Si l'instance n'existe pas dans le domaine d'instance, une erreur PMAPI(3) sera retournée. Cette méthode ignore la valeur de l'indicateur active défini dans le constructeur QmcMetric.
void removeInst(uint_t index);
Supprime l'instance à la position index de la métrique.

DIAGNOSTICS

Les messages d'erreur sont générés à l'aide de pmprintf(3) mais ne sont pas vidés. Il incombe à l'utilisateur d'appeler pmflush(3) pour afficher les messages.

Des diagnostics supplémentaires peuvent être activés en ajoutant l'option pmc à la spécification de débogage globale, comme décrit dans pmSetDebug(3).

VOIR AUSSI

PMAPI(3), QMC(3), QmcContext(3), QmcGroup(3), pmflush(3) et pmprintf(3).
