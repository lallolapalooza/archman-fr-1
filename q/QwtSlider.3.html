Description détaillée

Le widget curseur.

QwtSlider est un widget curseur qui opère sur un intervalle de type double. Sa position est liée à une échelle affichant la valeur actuelle.

Le curseur peut être personnalisé en ayant une gouttière, une rainure - ou les deux.

Detailed Description

Slider widget. The slider can be oriented horizontally or vertically. It can be used as a value slider or a spectrum slider.

The slider is composed of a scale, a trough and a handle. The scale is optional.

The orientation can be changed using QwtAbstractSlider::setOrientation().

The slider has a built-in timer, which can be used for automatic scrolling. When the mouse is pressed inside the slider area, the timer is started and the slider value is changed incrementally. The interval can be set using setUpdateInterval().

The trough can be enabled/disabled using setTrough().

The spacing between the trough and the scale can be changed using setSpacing().

The labels of the scale can be customized by passing a derived QwtScaleDraw object to setScaleDraw().
