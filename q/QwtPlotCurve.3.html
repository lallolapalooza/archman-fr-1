Description détaillée

Un élément de graphique, qui représente une série de points.

Une courbe est la représentation d'une série de points dans le plan x-y. Elle supporte différents styles d'affichage, l'interpolation (par exemple, spline) et des symboles.

Utilisation

a) Attribution des propriétés de la courbe
Lorsqu'une courbe est créée, elle est configurée pour dessiner des lignes noires pleines dans le style QwtPlotCurve::Lines et sans symboles. Vous pouvez modifier cela en appelant setPen(), setStyle() et setSymbol().
b) Connexion/Attribution des données.
QwtPlotCurve obtient ses points en utilisant un objet QwtSeriesData offrant une passerelle vers le stockage réel des points (comme QAbstractItemModel). Il existe plusieurs classes pratiques dérivées de QwtSeriesData, qui stockent également les points à l'intérieur (comme QStandardItemModel). QwtPlotCurve propose également plusieurs variations de setSamples(), qui construisent en interne des objets QwtSeriesData à partir de tableaux.
c) Rattachement de la courbe à un graphique
Voir QwtPlotItem::attach()

Documentation des énumérations des membres

enum QwtPlotCurve::CurveAttribute

Attribut pour le dessin de la courbe

Voir aussi

setCurveAttribute(), testCurveAttribute(), curveFitter()

Énumérateur

Inverted
Pour QwtPlotCurve::Steps uniquement. Dessine une fonction en escalier de la droite vers la gauche.
Fitted
Uniquement en combinaison avec QwtPlotCurve::Lines. Un QwtCurveFitter tente d'interpoler/lisser la courbe avant qu'elle ne soit dessinée.

Note

L'ajustement de courbe nécessite une mémoire temporaire pour calculer les coefficients et les points supplémentaires. Si le dessin en mode QwtPlotCurve::Fitted est lent, il peut être préférable d'ajuster les points avant de les passer à QwtPlotCurve.

enum QwtPlotCurve::CurveStyle

Styles de courbe.

Voir aussi

setStyle(), style()

Énumérateur

NoCurve
Ne dessine pas de courbe. Note : Ceci n'affecte pas les symboles.
Lines
Connecte les points avec des lignes droites. Les lignes peuvent être interpolées en fonction de l'attribut 'Fitted'. L'ajustement de courbe peut être configuré en utilisant setCurveFitter().
Sticks
Dessine des bâtons verticaux ou horizontaux (selon l'orientation()) depuis une ligne de base définie par setBaseline().
Steps
Connecte les points avec une fonction en escalier. La fonction en escalier est dessinée de gauche à droite ou vice versa, en fonction de l'attribut QwtPlotCurve::Inverted.
Dots
Dessine des points aux emplacements des données. Note : Ceci est différent d'une ligne pointillée (voir setPen()), et plus rapide qu'une courbe en style QwtPlotCurve::NoStyle avec un symbole de point.
UserCurve
Les styles >= QwtPlotCurve::UserCurve sont réservés aux classes dérivées de QwtPlotCurve qui surchargent drawCurve() avec des types de courbes supplémentaires spécifiques à l'application.

enum QwtPlotCurve::PaintAttribute

Attributs pour modifier l'algorithme de dessin. Le réglage par défaut active ClipPolygons | FilterPoints

Voir aussi

setPaintAttribute(), testPaintAttribute()

Énumérateur

ClipPolygons
Découpe les polygones avant de les dessiner. Dans les situations où les points sont loin de la zone visible (par exemple, lors d'un zoom profond), cela peut améliorer considérablement les performances de dessin.
FilterPoints
Tente de réduire les données à dessiner en éliminant les doublons ou les points dessinés en dehors de la zone visible. Peut avoir un impact notable sur les courbes avec de nombreux points rapprochés. Seuls quelques algorithmes de filtrage très basiques sont implémentés.
MinimizeMemory
Minimise l'utilisation de la mémoire temporaire nécessaire pour les points traduits avant leur dessin. Cela peut ralentir les performances de dessin.
ImageBuffer
Rend les points dans une image temporaire et dessine l'image. Il s'agit d'une optimisation très spéciale pour le style Dots, lorsqu'il y a un grand nombre de points. Avec un nombre raisonnable de points, QPainter::drawPoints() sera plus rapide.
FilterPointsAggressive
Filtrage de points plus agressif, essayant d'éliminer les points intermédiaires, en acceptant des différences visuelles mineures.

N'a d'effet que lors du dessin de la courbe sur un périphérique de dessin dans des coordonnées entières (par exemple, tous les widgets à l'écran) en utilisant le fait que les points consécutifs sont souvent mappés sur la même coordonnée x ou y. Chaque bloc d'échantillons mappés sur la même coordonnée peut être réduit à 4 points (premier, min, max, dernier).

Dans le pire des cas, le polygone à rendre sera 4 fois plus large que le canevas du graphique.

L'algorithme est très rapide et efficace pour d'énormes jeux de données, et peut être utilisé dans un cycle de replot.

Note

Implémenté uniquement pour QwtPlotCurve::Lines.

Comme cet algorithme remplace de nombreuses petites lignes par une longue, un bug gênant du moteur de dessin raster (Qt 4.8, Qt 5.1 - 5.3) devient plus dominant. Pour ces versions, le bug peut être contourné en activant le mode QwtPainter::polylineSplitting().

void QwtPlotCurve::setBaseline
( double value )

Set the value of the baseline. The baseline is needed for filling the curve with a brush or the Sticks drawing style.

The interpretation of the baseline depends on the orientation(). With Qt::Vertical, the baseline is interpreted as a horizontal line at y = baseline(), with Qt::Horizontal, it is interpreted as a vertical line at x = baseline().

The default value is 0.0.

Parameters

value Value of the baseline

void QwtPlotCurve::setBrush
( const QBrush & brush )

Assign a brush. In case of brush.style() != QBrush::NoBrush and style() != QwtPlotCurve::Sticks the area between the curve and the baseline will be filled.

In case !brush.color().isValid() the area will be filled by pen.color(). The fill algorithm simply connects the first and the last curve point to the baseline. So the curve data has to be sorted (ascending or descending).

void QwtPlotCurve::setCurveFitter
( QwtCurveFitter * curveFitter )

Assign a curve fitter

The curve fitter 'smooths' the curve points, when the Fitted CurveAttribute is set. setCurveFitter(NULL) also disables curve fitting.

The curve fitter operates on the translated points ( = widget coordinates) to be functional for logarithmic scales. Obviously this is less performant for fitting algorithms, that reduce the number of points.

For situations, where curve fitting is used to improve the performance of painting huge series of points it might be better to execute the fitter on the curve points once and to cache the result in the QwtSeriesData object.

Parameters

curveFitter() Curve fitter
