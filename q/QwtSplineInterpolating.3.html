Description détaillée

Classe de base pour une interpolation par spline.

L'interpolation par spline consiste à interpoler un ensemble de points par morceaux avec des polynômes. L'ensemble initial de points est préservé.

QPolygonF QwtSplineInterpolating::equidistantPolygon (const QPolygonF & points, double distance, bool withNodes) const [virtual]

Trouve un polygone interpolé avec des points 'équidistants'. Lorsque withNodes est désactivé, tous les points du polygone résultant seront équidistants selon la paramétrisation.

Lorsque withNodes est activé, le polygone résultant inclura également les points de contrôle et les points interpolés seront toujours alignés sur le point de contrôle précédent ( points[i] + i * distance ).

L'implémentation calcule d'abord les courbes de Bézier, puis calcule les points interpolés dans une seconde passe.

Paramètres

points Nœuds de contrôle de la spline
distance Distance entre 2 points selon la paramétrisation
withNodes Si vrai, ajoute également les nœuds de contrôle ( même s'ils ne sont pas équidistants )

Retour

Polygone d'interpolation

QPainterPath QwtSplineInterpolating::painterPath (const QPolygonF & points) const [override], [virtual]

Interpole une courbe avec des courbes de Bézier. Interpole un polygone par morceaux avec des courbes de Bézier cubiques et les retourne sous forme de QPainterPath.

L'implémentation calcule d'abord les lignes de contrôle de Bézier, puis les convertit en éléments de chemin de peintre dans une boucle supplémentaire.

Paramètres

points Points de contrôle

Retour

Chemin de peintre, qui peut être rendu par QPainter

Note

Les classes de spline dérivées peuvent surcharger painterPath() pour éviter les boucles supplémentaires de conversion des résultats en un QPainterPath

QPolygonF QwtSplineInterpolating::polygon (const QPolygonF & points, double tolerance) const [override], [virtual]

Interpole une courbe par un polygone. Interpole un polygone par morceaux avec des courbes de Bézier en les approximant par des polygones.

L'approximation est basée sur 'Approximation Linéaire par Morceaux de Courbes de Bézier' par Roger Willcocks ( http://www.rops.org )

Paramètres

points Points de contrôle
tolerance Erreur maximale acceptée pour l'approximation

Retour

Polygone approximant les polynômes d'interpolation
