Description détaillée

Classe de base pour les éléments sur le canevas du graphique.

Un élément de graphique est "quelque chose" qui peut être dessiné sur le canevas du graphique, ou qui affecte uniquement les échelles du widget graphique. Ils peuvent être classés comme suit :

•
Représentant
Un "représentant" est un élément qui représente une sorte de données sur le canevas du graphique. Les différentes classes de représentants sont organisées selon les caractéristiques des données :
•
QwtPlotMarker Représente un point ou une coordonnée horizontale/verticale
•
QwtPlotCurve Représente une série de points
•
QwtPlotSpectrogram ( QwtPlotRasterItem ) Représente des données raster
•
...
•
Décorateurs
Un "décorateur" est un élément qui affiche des informations supplémentaires qui ne sont pas liées à des données :
•
QwtPlotGrid
•
QwtPlotScaleItem
•
QwtPlotSvgItem
•
...

Selon les indicateurs QwtPlotItem::ItemAttribute, un élément est inclus dans la mise à l'échelle automatique ou possède une entrée dans la légende.

Avant d'utiliser à mauvais escient les classes d'éléments existantes, il peut être préférable d'implémenter un nouveau type d'élément de graphique (n'implémentez pas un filigrane comme spectrogramme). Dériver un nouveau type de QwtPlotItem signifie principalement implémenter la méthode YourPlotItem::draw().

Voir aussi

L'exemple cpuplot montre l'implémentation d'éléments de graphique supplémentaires.

QwtPlotItem

Header: qwt_plot_item.h

This class is the base class for all plot items.

Plot items are the core elements of a plot. Examples for plot items are QwtPlotCurve, QwtPlotMarker, etc.

The plot items are organized by the plot they belong to. Each plot item is identified by a unique ID. You can assign an arbitrary ID to a plot item, that is useful for searching or accessing items later.

The following attributes can be enabled/disabled for plot items:

Rtti
The item has a valid runtime type information (RTTI).
Legend
The item is represented on the legend.
AutoScale
The boundingRect() of the item is included in the autoscaling calculation as long as its width or height is >= 0.0.
Margins
The item needs extra space to display something outside its bounding rectangle.

void QwtPlotItem::getCanvasMarginHint (const QwtScaleMap & xMap, const QwtScaleMap & yMap, const QRectF & canvasRect, double & left, double & top, double & right, double & bottom) const [virtual]

Calcule un indice pour la marge du canevas. Lorsque le drapeau QwtPlotItem::Margins est activé, l'élément du graphique indique qu'il a besoin de marges sur les bords du canevas. Ceci est par exemple utilisé par les diagrammes en barres pour réserver de l'espace afin d'afficher les barres.

Les marges sont dans les coordonnées du périphérique cible (pixels à l'écran).

Paramètres

xMap Mappe les valeurs x dans les coordonnées pixel.
yMap Mappe les valeurs y dans les coordonnées pixel.
canvasRect Rectangle de contenu du canevas dans les coordonnées du peintre
left Retourne la marge gauche
top Retourne la marge supérieure
right Retourne la marge droite
bottom Retourne la marge inférieure

L'implémentation par défaut retourne 0 pour toutes les marges.

Voir aussi
