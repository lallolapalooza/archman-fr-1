Description détaillée

Classe de base pour toutes les splines.

Une spline est une courbe représentée par une séquence de polynômes. L'approximation par spline est le processus de recherche de polynômes pour un ensemble donné de points. Lorsque l'algorithme conserve les points de départ, on parle d'interpolation.

Les splines peuvent être classées selon les conditions des polynômes qui sont satisfaites aux points de départ et de fin des segments :

•
Continuité géométrique
•
G0 : les polynômes se rejoignent
•
G1 : les dérivées premières sont proportionnelles au point de jonction
•
G2 : les dérivées premières et secondes sont proportionnelles au point de jonction
•
Continuité paramétrique
•
C0 : les courbes se rejoignent
•
C1 : les dérivées premières sont égales
•
C2 : les dérivées premières et secondes sont égales

La continuité géométrique exige que la géométrie soit continue, tandis que la continuité paramétrique exige que la paramétrisation sous-jacente soit continue. La continuité paramétrique d'ordre n implique la continuité géométrique d'ordre n, mais pas l'inverse.

QwtSpline est la classe de base pour les approximations de splines de n'importe quelle continuité.

Detailed Description

This class is an abstract base class for spline interpolation algorithms.

A spline is a function defined piecewise by polynomials. In geometric modeling and computer graphics, splines are often used for drawing smooth curves and surfaces.

Qwt provides several implementations of spline interpolation:

  • QwtSplineCubic: A cubic spline interpolation that calculates polynomials of degree 3. The calculation of the coefficients needs to be done once for all points.
  • QwtSplineBasis: A spline interpolation based on B-splines.
  • QwtSplinePleasing: A spline interpolation that tries to find a visually pleasing curve. The algorithm is described in
  • QwtSplineLocal: A spline interpolation that only uses a local number of points to calculate the polynomials.
  • QwtSplineInterpolating: A spline interpolation that interpolates the given polygon points exactly.

All spline implementations offer different boundary conditions to control the shape of the spline at its endpoints.

The painterPath() function can be used to approximate the spline by a QPainterPath object, that can be rendered by QPainter.

The polygon() function can be used to approximate the spline by a polygon.

uint QwtSpline::locality () const [virtual]

The locality of an spline interpolation identifies how many adjacent polynomials are affected, when changing the position of one point.

A locality of 'n' means, that changing the coordinates of a point has an effect on 'n' leading and 'n' following polynomials. Those polynomials can be calculated from a local subpolygon.

A value of 0 means, that the interpolation is not local and any modification of the polygon requires to recalculate all polynomials ( f.e cubic splines ).

Returns

Order of locality

Reimplemented in QwtSplinePleasing, QwtSplineLocal, QwtSplineCubic, and QwtSplineBasis.

Detailed Description

The class QwtSpline is a container for a series of points and provides methods to interpolate these points. The spline can be drawn to a QPainter.

Member Enumeration Documentation

InterpolationMode

The interpolation mode can be chosen from the following modes:

StraightLine
The points are connected by straight lines.
MonotoneCubic
A cubic spline is used that preserves the monotonicity of the data. This means that if the data is monotonically increasing (decreasing), the spline will also be monotonically increasing (decreasing).
Parabolic
A parabolic spline is used. This spline is continuous and has continuous first derivatives.
Cubic
A cubic spline is used. This is the most common type of spline and provides a smooth interpolation.
