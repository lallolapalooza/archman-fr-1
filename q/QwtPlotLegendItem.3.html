Description détaillée

Une classe qui dessine une légende à l'intérieur du canevas du graphique.

QwtPlotLegendItem peut être utilisé pour dessiner à l'intérieur du canevas du graphique. Il peut être utilisé avec un QwtLegend ou à la place de celui-ci pour avoir plus d'espace pour le canevas du graphique.

Contrairement à QwtLegend, l'élément de légende n'est pas interactif. Pour identifier les clics de souris sur un élément de légende, un filtre d'événements doit être installé pour capturer les événements de souris sur le canevas du graphique. Les géométries des éléments de légende sont disponibles via legendGeometries().

L'élément de légende est aligné sur le canevas du graphique conformément à ses indicateurs d'alignement ( alignment() ). Il peut avoir un arrière-plan pour la légende complète (généralement semi-transparent) ou pour chaque élément de légende.

Note

Un QwtLegend externe avec un arrière-plan transparent par-dessus le canevas du graphique pourrait être une autre option avec un effet similaire.
