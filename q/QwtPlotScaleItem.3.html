Description Détaillée

Un objet qui dessine une échelle à l'intérieur du canvas du graphique.

QwtPlotScaleItem peut être utilisé pour dessiner un axe à l'intérieur du canvas du graphique. Il peut être synchronisé avec l'un des axes du graphique, mais peut également afficher ses propres graduations et étiquettes.

Il est permis de synchroniser l'objet échelle avec un axe désactivé. Dans les graphiques avec des axes d'échelle verticale et horizontale, il peut être nécessaire de supprimer les graduations aux points d'intersection, en surchargeant updateScaleDiv().

L'échelle peut être à une position spécifique (par exemple, 0.0) ou être alignée sur un bord du canvas.

Exemple

L'exemple suivant montre comment remplacer l'axe de gauche, via un objet échelle à la position x 0.0.
QwtPlotScaleItem *scaleItem = new QwtPlotScaleItem( QwtScaleDraw::RightScale, 0.0 );
scaleItem->setFont( plot->axisWidget( QwtAxis::YLeft )->font() );
scaleItem->attach(plot);
plot->setAxisVisible( QwtAxis::YLeft, false );

Detailed Description

A scale item is a scale that can be added to a plot. It acts like a axis, but is not part of the plot's axes system.

The scale item can be aligned relative to the plot canvas or be positioned absolutely. The former is useful for scales that should appear outside the plot area, the latter for scales that should be displayed within the plot area like an axis.

The scale can be attached to a horizontal or vertical plot axis. In case of horizontal scales the position corresponds to QwtPlotItem::yAxis(), otherwise to QwtPlotItem::xAxis().

The scale division can be assigned directly or be synchronized with the corresponding plot axis.

void QwtPlotScaleItem::setAlignment (QwtScaleDraw::Alignment alignment)

Set the alignment of the scale.

Possible alignments:

  • QwtScaleDraw::BottomScale: horizontal, ticks below
  • QwtScaleDraw::TopScale: horizontal, ticks above
  • QwtScaleDraw::LeftScale: vertical, ticks left
  • QwtScaleDraw::RightScale: vertical, ticks right

For horizontal scales the position corresponds to QwtPlotItem::yAxis(), otherwise to QwtPlotItem::xAxis().

void QwtPlotScaleItem::setBorderDistance (int distance)

Align the scale to the canvas. If distance is >= 0 the scale will be aligned to a border of the contents rectangle of the canvas. If alignment() is QwtScaleDraw::LeftScale, the scale will be aligned to the right border, if it is QwtScaleDraw::TopScale it will be aligned to the bottom (and vice versa),

If distance is < 0 the scale will be at the position().

Parameters

distance Number of pixels between the canvas border and the backbone of the scale.
