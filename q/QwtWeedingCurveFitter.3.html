Description détaillée

Un ajusteur de courbe implémentant l'algorithme de Douglas et Peucker.

Le but de l'algorithme de Douglas et Peucker est, étant donné une 'courbe' composée de segments de ligne, de trouver une courbe qui n'est pas trop dissemblable mais qui a moins de points. L'algorithme définit 'trop dissemblable' en fonction de la distance maximale (tolérance) entre la courbe originale et la courbe lissée.

Le temps d'exécution de l'algorithme augmente de manière non linéaire (pire cas O( n*n )) et peut être très lent pour des polygones énormes. Pour éviter les problèmes de performance, il peut être utile de diviser le polygone ( setChunkSize() ) et d'exécuter l'algorithme pour ces parties plus petites. Le désavantage de ne pas avoir d'interpolation aux frontières est, dans la plupart des cas d'utilisation, non pertinent.

La courbe lissée se compose d'un sous-ensemble des points qui ont défini la courbe originale.

Contrairement à QwtSplineCurveFitter, l'algorithme de Douglas et Peucker réduit le nombre de points. En ajustant le paramètre de tolérance en fonction des échelles des axes, QwtSplineCurveFitter peut être utilisé pour implémenter différents niveaux de détail afin d'accélérer le dessin de courbes composées de nombreux points.

                    QwtWeedingCurveFitter ( double threshold = 0.0 )
                    QwtWeedingCurveFitter ( QObject *parent, double threshold = 0.0 )

DESCRIPTION

Un fitter de courbe qui supprime les points redondants. Le fitter est basé sur l'algorithme "Weeding" de William Birch et al. qui supprime les points qui sont trop proches les uns des autres sur les axes X ou Y.

Le paramètre threshold contrôle la distance minimale entre les points consécutifs. Les points sont supprimés si la distance X ou Y est inférieure au seuil.
