Description détaillée

QwtPlotPicker fournit des sélections dans une boîte de graphique.

QwtPlotPicker est un QwtPicker spécialisé pour les sélections dans une boîte de graphique. Il est configuré pour les axes X et Y, et transforme toutes les coordonnées de pixels dans ce système de coordonnées.

Définition en ligne 33 du fichier qwt_plot_picker.h.

QwtPlotPicker::QwtPlotPicker (QWidget * canvas) [explicit]

Crée un sélecteur de graphique. Le sélecteur est configuré pour les axes X et Y du graphique. Si les deux axes ou aucun des axes ne sont activés, il est défini sur QwtAxis::XBottom. Si les deux axes Y ou aucun des axes Y ne sont activés, il est défini sur QwtAxis::YLeft.

Paramètres

canvas Boîte de graphique à observer, également l'objet parent

class QwtPlotPicker : public QwtPicker

This class introduces a picker for QwtPlots.

The QwtPlotPicker introduces a mechanism to select data points or regions from a plot. It maps the selected pixel coordinates into plot coordinates. The selection can be done using the mouse or keyboard.

The picker needs a plot canvas to observe mouse events. It translates the pixel coordinates from the mouse events into plot coordinates and emits signals according to the selection mode.

The following plot item types are supported by QwtPlotPicker:

  • QwtPlotMarker: selects the nearest marker.
  • QwtPlotCurve: selects the curve points that are nearest to the mouse pointer.
  • QwtPlotGrid: doesn't support selection.
  • QwtPlotSpectrogram, QwtPlotHeatmap: The picker can select regions on the canvas.
  • QwtPlot: The picker can select regions on the canvas.

The selection modes are defined by the QwtPickerMachine class. The default state machine is QwtPicker::PointSelection, which is suitable for selecting single points.

The plot picker can be configured with different rubber bands (see QwtPicker documentation) to visualize the selection in progress.

The plot picker can be configured with different selection constraints (see QwtPicker documentation) to limit the selection.

The plot picker can be configured with different tracker modes (see QwtPicker documentation) to display a tooltip with the current cursor position.

The plot picker translates the selection into plot coordinates using the plot's coordinate system. The default setting is to use the coordinate system of the first axis (index 0).

The transformation can be customized by overriding transform() and invTransform().

The selection is always done in the coordinate system of the plot's axes. The translation from pixel coordinates into plot coordinates is done using the axes scale maps.

The selected() signals will emit the selected coordinates in plot coordinates.

The QwtPlotZoomer is a derived class that uses the picker to implement zooming.
