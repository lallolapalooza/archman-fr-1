Description détaillée

Classe de base pour les interpolations de spline fournissant une continuité paramétrique du premier ordre ( C1 ) entre les courbes adjacentes.

Toutes les interpolations avec continuité C1 sont basées sur des règles pour trouver la 1ère dérivée à certains points de contrôle.

Dans le cas des splines non paramétriques, ces points sont les points de la courbe, tandis que pour les splines paramétriques, le calcul est effectué deux fois en utilisant une valeur paramétrique t.

QVector< QwtSplinePolynomial > QwtSplineC1::polynomials (const QPolygonF & points) const [virtual]

Calcule les polynômes d'interpolation pour une spline non paramétrique. Les interpolations de spline C1 sont basées sur la recherche de valeurs pour les dérivées premières aux points de contrôle. Les polynômes d'interpolation peuvent être calculés à partir des dérivées premières à l'aide de QwtSplinePolynomial::fromSlopes().

L'implémentation par défaut est un calcul en deux passes. Dans les classes dérivées, elle peut être surchargée par une implémentation en une passe.

Paramètres

points Points de contrôle

Retour

Polynômes d'interpolation

Note

Les coordonnées x doivent être croissantes ou décroissantes

Réimplémenté dans QwtSplineLocal, QwtSplineCubic et QwtSplineC2.
