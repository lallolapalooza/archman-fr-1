Description détaillée

Un élément de graphique qui affiche une étiquette de texte.

QwtPlotTextLabel affiche une étiquette de texte alignée sur le canevas du graphique.

Contrairement à QwtPlotMarker, la position de l'étiquette est indépendante des coordonnées du graphique.

Comme le dessin d'un texte est une opération coûteuse, l'étiquette est mise en cache dans un pixmap pour accélérer les replots.

Exemple

Le code suivant montre comment ajouter un titre. 
QwtText title("Titre du graphique");
title.setRenderFlags(Qt::AlignHCenter | Qt::AlignTop);
QFont font;
font.setBold(true);
title.setFont(font);
QwtPlotTextLabel *titleItem = new QwtPlotTextLabel();
titleItem->setText(title);
titleItem->attach(plot);
