Description détaillée

Pont entre QwtSeriesStore et QwtPlotSeriesItem.

QwtAbstractSeriesStore est une interface abstraite uniquement pour permettre d'isoler les méthodes basées sur des templates ( QwtSeriesStore ) des méthodes régulières ( QwtPlotSeriesItem ) afin de permettre de dériver de QwtPlotSeriesItem sans aucun problème avec les templates.

Définition à la ligne 24 du fichier qwt_series_store.h.
