Description détaillée

Une aiguille magnétique pour les widgets de boussole.

Une aiguille magnétique pointe vers deux directions opposées indiquant le nord et le sud.

Les couleurs suivantes sont utilisées :

  • QPalette::Light
    Utilisé pour pointer vers le sud
  • QPalette::Dark
    Utilisé pour pointer vers le nord
  • QPalette::Base
    Bouton (ThinStyle seulement)
