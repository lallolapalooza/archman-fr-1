Description détaillée

Un widget pour le dessin de graphiques 2D.

QwtPlot est un widget pour le dessin de graphiques 2D. Un nombre illimité d'éléments de graphique peuvent être affichés sur sa toile. Les éléments de graphique peuvent être des courbes (QwtPlotCurve), des marqueurs (QwtPlotMarker), une grille (QwtPlotGrid), ou toute chose héritant de QwtPlotItem. Un graphique peut avoir jusqu'à quatre axes, chaque élément de graphique étant associé à un axe x et un axe y. Les échelles des axes peuvent être explicitement définies (QwtScaleDiv), ou calculées à partir des éléments de graphique, en utilisant des algorithmes (QwtScaleEngine), qui peuvent être configurés indépendamment pour chaque axe.

L'exemple simpleplot est un bon point de départ pour voir comment configurer un widget de graphique.

Exemple

L'exemple suivant montre (schématiquement) la manière la plus simple d'utiliser QwtPlot. Par défaut, seuls les axes gauche et inférieur sont visibles et leurs échelles sont calculées automatiquement.
#include <qwt_plot.h>
#include <qwt_plot_curve.h>
     QwtPlot *myPlot = new QwtPlot( "Deux Courbes", parent );
     // ajouter des courbes
     QwtPlotCurve *curve1 = new QwtPlotCurve( "Courbe 1" );
     QwtPlotCurve *curve2 = new QwtPlotCurve( "Courbe 2" );
     // connecter ou copier les données aux courbes
     curve1->setData( ... );
     curve2->setData( ... );
     curve1->attach( myPlot );
     curve2->attach( myPlot );
     // enfin, rafraîchir le graphique
     myPlot->replot();

void QwtPlot::insertLegend (QwtAbstractLegend * legend, QwtPlot::LegendPosition pos = QwtPlot::RightLegend, double ratio = -1.0)

Insérer une légende. Si la position de la légende est QwtPlot::LeftLegend ou QwtPlot::RightLegend la légende sera disposée en colonne de haut en bas. Sinon, les éléments de la légende seront distribués dans un tableau avec un nombre de colonnes ajusté au meilleur ajustement de gauche à droite.

insertLegend() définira la fenêtre graphique comme parent de la légende. La légende sera supprimée dans le destructeur de la fenêtre graphique ou lorsqu'une autre légende sera insérée.

Les légendes qui ne sont pas insérées dans la mise en page de la fenêtre graphique doivent être connectées au signal legendDataChanged(). Appeler updateLegend() émet ce signal pour une mise à jour initiale. Lorsque le code de l'application souhaite implémenter sa propre mise en page, il doit également le faire pour le rendu des graphiques (voir QwtPlotRenderer).

Paramètres

legend Légende
pos La position de la légende. Pour les positions haut/gauche, le nombre de colonnes sera limité à 1, sinon il sera défini sur une valeur illimitée.
ratio Rapport entre la légende et le rectangle du titre, de la zone graphique et des axes. La légende sera ajustée si elle a besoin de plus d'espace que celui donné par le rapport. Le rapport est limité à ]0.0 .. 1.0]. Dans le cas de <= 0.0, il sera réinitialisé au rapport par défaut. Le rapport par défaut est 0.33/0.5.

Voir aussi

legend(), QwtPlotLayout::legendPosition(), QwtPlotLayout::setLegendPosition()

void QwtPlot::updateAxes ()

Reconstruit les échelles des axes. En cas d'échelle automatique, les limites d'une échelle sont calculées à partir des boîtes englobantes de tous les éléments de graphique, avec le drapeau QwtPlotItem::AutoScale activé (QwtScaleEngine::autoScale()). Ensuite, une division d'échelle est calculée (QwtScaleEngine::divideScale()) et attribuée au widget d'échelle. Lorsqu'elle est définie avec setAxisScale(), la division d'échelle (QwtScaleEngine::divideScale()) est calculée pour cet intervalle et attribuée au widget d'échelle. Lorsqu'elle est explicitement définie avec setAxisScaleDiv(), le diviseur local est attribué au widget d'échelle. Le widget d'échelle indique les modifications en émettant le signal QwtScaleWidget::scaleDivChanged().

updateAxes() est généralement appelé par replot().

Detailed Description

Clase del gráfico. QwtPlot es un widget que sirve como un contenedor para todos los elementos del gráfico, como ejes, una leyenda, un título, etc. y se utiliza para organizar y mostrar gráficos. El gráfico se compone de las siguientes áreas:

El trazado completo ocupa el espacio del widget. Contiene las siguientes áreas:

Título
El área del título se puede configurar con setTitle.
Zona de leyenda
El área de la leyenda se puede configurar con insertLegend.
Canvas
El lienzo es la región donde se dibujan los elementos del gráfico (curvas, barras, etc.). Se puede configurar con setCanvasBackground, setCanvasPen, setCanvasBorderPen y setCanvasFrameStyle.
Ejes
Hay 4 ejes, que se pueden identificar mediante el identificador de eje: QwtPlot::xBottom, QwtPlot::xTop, QwtPlot::yLeft y QwtPlot::yRight. Cada eje puede tener un título (setAxisTitle), una fuente (setAxisFont), etiquetas rotadas (setAxisLabelRotation) y una escala (setAxisScale, setAxisScaleDiv).
Nota al pie
El área de notas al pie se puede configurar con setFootnote.

Los ejes se componen de una escala y un widget de etiqueta. Los widgets de escala se pueden configurar además con QwtScaleWidget. Se pueden adjuntar widgets adicionales a los ejes (por ejemplo, un control deslizante para cambiar la escala). setAxisContainer.

Un gráfico puede contener varios elementos de gráfico, que se pueden adjuntar y separar mediante attachItem y detachItem. Los elementos se ordenan por su tipo y número de orden.

El diseño del gráfico se calcula automáticamente para adaptar todos los elementos al tamaño del widget. La lógica de diseño puede influir en el espacio para los ejes y la leyenda mediante los indicadores de margen. Los indicadores de margen se pueden obtener para un elemento de gráfico mediante QwtPlotItem::getCanvasMarginHint.

Si se necesita una información de diseño más detallada, se puede implementar plotLayout. Esta función calcula las posiciones y tamaños de todas las áreas del gráfico dentro de un rectángulo dado.

Es posible que los elementos del gráfico necesiten espacio adicional en el lienzo. Este espacio se solicita mediante QwtPlotItem::getCanvasMarginHint y se gestiona internamente en updateCanvasMargins.

La actualización de los elementos del gráfico (por ejemplo, un cambio de escala) se puede activar llamando a replot.
