Description détaillée

Objet peintre essayant de peindre de manière incrémentale.

De nombreuses applications souhaitent afficher des échantillons au fur et à mesure de leur collecte. Lorsqu'il y a trop d'échantillons, des recalculs complets sont nécessaires, ce qui peut être coûteux en cycles de collecte.

QwtPlotDirectPainter fournit une API pour peindre des sous-ensembles (par exemple, tous les points supplémentaires) sans effacer/redessiner le canevas du graphique.

Dans certains environnements, il peut être important de calculer une région de découpage appropriée avant de peindre. Par exemple, sous Qt Embedded, seule la partie du tampon arrière qui a été découpée sera copiée vers un tampon d'écran (probablement non accéléré).

Attention

La peinture incrémentale n'est utile que lorsqu'aucun recalcul n'est déclenché par une autre opération (comme le changement d'échelle) et que rien n'a besoin d'être effacé.

Énumérateurs

AtomicPainter
L'initialisation d'un QPainter est une opération coûteuse en mémoire. Lorsque AtomicPainter est défini, chaque appel à drawSeries() ouvre/ferme un QPainter temporaire. Sinon, QwtPlotDirectPainter essaie d'utiliser le même QPainter pendant une période prolongée.
FullRepaint
Lorsque FullRepaint est défini, le canevas du graphique est explicitement redessiné après le rendu des échantillons.
CopyBackingStore
Lorsque QwtPlotCanvas::BackingStore est activé, le peintre doit peindre vers le tampon arrière et le widget. Dans certains cas/situations/environnements, il peut être plus rapide de peindre uniquement vers le tampon arrière, puis de le copier sur le canevas. Ce drapeau peut également être utile dans les configurations où Qt remplit la zone découpée avec l'arrière-plan du widget.

void QwtPlotDirectPainter::drawSeries (QwtPlotSeriesItem * seriesItem, int from, int to)

Dessine un ensemble de points d'une série. Lorsque l'on observe une mesure en cours d'exécution, les nouveaux points doivent être ajoutés à une série existante. drawSeries() peut être utilisé pour les afficher sans avoir à redessiner tout le canevas.

La configuration plot()->canvas()->setAttribute(Qt::WA_PaintOutsidePaintEvent, true); entraînera un dessin plus rapide, si le moteur de dessin du widget canevas prend en charge cette fonctionnalité.

Paramètres

seriesItem L'élément à dessiner
from L'indice du premier point à dessiner
to L'indice du dernier point à dessiner. Si to < 0, la série sera dessinée jusqu'à son dernier point.
