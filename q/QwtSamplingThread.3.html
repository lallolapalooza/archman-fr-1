Description Détaillée

Un thread collectant des échantillons à intervalles réguliers.

Les signaux continus sont convertis en un signal discret en collectant des échantillons à intervalles réguliers. Un signal discret peut être affiché par un QwtPlotSeriesItem sur un widget QwtPlot.

QwtSamplingThread démarre un thread appelant périodiquement sample(), pour collecter et stocker (ou émettre) un seul échantillon.

virtual void QwtSamplingThread::sample (double elapsed) [protégé], [virtuel pur]

Collecte un échantillon

Paramètres

elapsed Temps écoulé depuis le démarrage du thread en secondes

Note

En raison d'un bug dans une version précédente, elapsed était passé en secondes au lieu de millisecondes. Pour éviter de casser le code existant, nous restons pour l'instant en secondes.
