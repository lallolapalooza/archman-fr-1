Description détaillée

Un élément de graphique qui affiche une zone.

Une zone horizontale met en évidence un intervalle de l'axe y - un intervalle de l'axe x pour une zone verticale - et n'est pas limitée dans la direction opposée. Elle est remplie avec un pinceau et ses lignes de bordure sont affichées optionnellement avec un stylo.

Note

Pour afficher une zone limitée dans les deux directions, utilisez QwtPlotShapeItem

Description

Este tema es usado para resaltar un intervalo de una dirección de ejes en el gráfico.

La zona se dibuja con un cepillo especificado con setBrush(). El borde de la zona se dibuja con un lápiz especificado con setPen().

Si la orientación es horizontal (ver setOrientation()), la zona resalta un intervalo del eje y. Si la orientación es vertical, la zona resalta un intervalo del eje x.

El intervalo se especifica en las unidades del eje correspondiente.

Ver el ejemplo de código zones.
