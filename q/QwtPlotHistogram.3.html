Description détaillée

QwtPlotHistogram représente une série d'échantillons, où un intervalle est associé à une valeur ( $y = f([x1,x2])$ ).

La représentation dépend du style() et d'un symbole optionnel symbol() qui est affiché pour chaque intervalle.

Note

Le terme 'histogramme' est utilisé différemment dans les domaines du traitement d'image et des statistiques. Wikipédia introduit les termes 'histogramme d'image' et 'histogramme de couleur' pour éviter les confusions. Bien que les histogrammes d'image puissent être affichés à l'aide de QwtPlotCurve, il n'existe pas encore d'élément de graphique applicable pour un histogramme de couleur.

Énumération QwtPlotHistogram::HistogramStyle

Styles d'histogramme. Le style par défaut est QwtPlotHistogram::Columns.

Voir aussi

Énumérateur

Outline
Dessine un contour autour de la région, qui est formé par tous les intervalles en utilisant le pen() et rempli avec le brush(). Le style du contour nécessite que les intervalles soient en ordre croissant et ne se chevauchent pas.
Columns
Dessine une colonne pour chaque intervalle. Lorsqu'un symbol() a été défini, le symbole est utilisé à la place de l'affichage d'une boîte rectangulaire commune utilisant le pen() et le brush().
Lines
Dessine une ligne simple en utilisant le pen() pour chaque intervalle.
UserStyle
Les styles >= UserStyle sont réservés aux classes dérivées qui redéfinissent drawSeries() avec des formes d'affichage d'histogramme spécifiques.

Dessine une colonne pour un échantillon dans le style style().

Lorsque symbol() est défini, le symbole est utilisé ; sinon, la colonne est dessinée comme un rectangle plat en utilisant pen() et brush().

Paramètres

rect Rectangle dans lequel la colonne est dessinée dans les coordonnées du périphérique de dessin

Remarque

Dans les applications où il est nécessaire d'afficher des intervalles différents (par exemple, des couleurs différentes ou même des symboles différents), il est recommandé de surcharger drawColumn().

void QwtPlotHistogram::setSymbol (const QwtColumnSymbol * symbol)

Assign a symbol. In Column style an optional symbol can be assigned, that is responsible for displaying the rectangle that is defined by the interval and the distance between baseline() and value. When no symbol has been defined the area is displayed as plain rectangle using pen() and brush().

See also

style(), symbol(), drawColumn(), pen(), brush()

Note

In applications, where different intervals need to be displayed in a different way ( f.e different colors or even using different symbols) it is recommended to overload drawColumn().
