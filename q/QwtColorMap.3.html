Description détaillée

QwtColorMap est utilisé pour mapper des valeurs à des couleurs.

Pour afficher des données 3D sur un plan 2D, la troisième dimension est communément représentée par des couleurs, comme dans un spectrogramme.

Chaque carte de couleur est optimisée pour renvoyer des couleurs pour un seul des formats d'image suivants :

  • QImage::Format_Indexed8
  • QImage::Format_ARGB32

NAME

QwtColorMap - Mapa de colores para un diagrama de Qwt

SYNOPSIS

#include <qwt_color_map.h>

class QwtColorMap

DESCRIPTION

El diseño de un gráfico suele depender de la representación de diferentes valores con diferentes colores. QwtColorMap proporciona una interfaz para buscar los colores de un mapa de colores.

La clase base abstracta QwtColorMap no define ningún mapa de colores. Las subclases como QwtLinearColorMap o QwtThermoMap proporcionan mapas de colores específicos.

Hay dos tipos de mapas de colores:

Los mapas de colores para una intensidad lineal (p. ej., para termogramas o imágenes de nivel de gris) son un caso especial. Para estos mapas de colores, solo es necesario un valor de intensidad para determinar un color. Para optimizar las búsquedas para este caso común, QwtColorMap proporciona una función virtual color1() además de la función virtual color().

El mapa de colores se puede inicializar con un QColor N colores o un número definido de segmentos. En el primer caso, la tabla de colores se construye mediante interpolación lineal entre los colores especificados.

Los colores se pueden solicitar en el rango [0, 255] o [0, 1]. El rango [0, 1] se puede mapear en un rango arbitrario [min, max] utilizando la función transform().

PUBLIC TYPES

ColorMatch
Modo de coincidencia de color.
ColorMatch
ColorMatch es un enum que define los modos de coincidencia de color.
ColorMatch
Fast
No se utiliza ninguna interpolación. El color más cercano se devuelve de una tabla de colores predefinida.
Normal
Se utiliza interpolación lineal. El color se calcula mediante interpolación lineal entre dos colores de la tabla de colores.

NOTES

Un mapa de colores lineal se puede definir fácilmente utilizando QwtLinearColorMap.

QwtLinearColorMap (QRgb rgb1, QRgb rgb2, QwtColorMap::ColorMatch cm = QwtColorMap::Linear)

Esto crea un mapa de colores que va de rgb1 a rgb2.

Los mapas de colores se pueden utilizar para colorear diferentes objetos de Qwt, como QwtPlotRasterItem, QwtThermo o QwtDial.
