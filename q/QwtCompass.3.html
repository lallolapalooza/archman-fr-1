Description détaillée

Un widget boussole.

QwtCompass est un widget pour afficher et saisir des directions. Il se compose d'une échelle, d'une aiguille optionnelle et d'une rose.

Note

L'exemple examples/dials montre comment utiliser QwtCompass.

Documentation du constructeur et du destructeur

QwtCompass::QwtCompass (QWidget * parent = NULL) [explicite]

Constructeur.

Paramètres

parent Widget parent

Crée un widget boussole avec une échelle, aucune aiguille et aucune rose. L'origine par défaut est 270.0 sans valeur valide. Il accepte les entrées de souris et de clavier et n'a pas de pas. Le mode par défaut est QwtDial::RotateNeedle.
