Description détaillée

QwtLinearColorMap construit une carte de couleurs à partir de points de couleur.

Un point de couleur est une couleur à une position spécifique. La plage valide pour les positions est [0.0, 1.0]. Lors du mappage d'une valeur à une couleur, elle est traduite dans cet intervalle selon mode().

QwtLinearColorMap - Linear color map

Detailed Description

A linear color map represents a mapping from values to colors. The colors are calculated by interpolating between a set of color stops. The color stops are defined by value/color pairs.

The interpolation is linear between adjacent stops.

A default map with two color stops is created with the colors black and white.

The map can be used in two modes:

FixedColors
The color is calculated from the color of the next lower color stop. This mode is useful for creating maps like:
    color map for integer values:
    0.0 - 10.0 -> red
    11.0 - 20.0 -> green
    21.0 - 30.0 -> blue

The value `v` is mapped to the color of the stop `s` where `s.value` is the largest value less than or equal to `v`.

ScaledColors
The color is calculated by interpolating the colors of the adjacent stops. This is the default mode.

The value `v` is mapped to the color that is linearly interpolated between the color of the stop `s1` and the color of the stop `s2`, where `s1.value` and `s2.value` are the values of the adjacent stops surrounding `v`.

If the map is used for a value outside the range of the color stops, the color of the nearest end point is used.
