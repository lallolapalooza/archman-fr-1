Description détaillée

Classe de base pour les éléments d'un graphique polaire.

Un QwtPolarItem est quelque chose qui peut être dessiné sur le canevas. Il est connecté au framework QwtPolar via diverses méthodes virtuelles, qui sont implémentées dans les classes dérivées.

QwtPolar offre une implémentation des types d'éléments les plus courants, mais dériver de QwtPolarItem permet d'implémenter facilement de nouveaux types d'éléments.

Detailed Description

Base class for polar items.

A QwtPolarItem is an item that can be added to a QwtPolarPlot. Polar items are organized in layers, but unlike the items in a QwtPlot they are not associated to an axis.

Instead they are associated to the QwtPolarPlot object itself, and can be configured by it.

Polar items are identified by a title. If no title is specified the title of the plot item is empty.

The z-value determines the painting order. Items with higher z-values are painted on top of items with lower z-values. The default z-value is 0.

The base class provides a default implementation for the rendering attributes, but doesn't offer any abstract rendering interface.

The rendering attributes are flags, that can be set/un-set by setItemAttribute/testItemAttribute. A set of default attributes are enabled by default. These attributes are defined in ItemAttribute.

The rendering hints are flags, that can be set/un-set by setRenderHint/testRenderHint. These hints are defined in RenderHint.
