Description détaillée

Une classe abstraite pour dessiner des échelles linéaires ou logarithmiques.

QwtAbstractScaleDraw peut être utilisé pour dessiner des échelles linéaires ou logarithmiques.

Après avoir spécifié une division d'échelle comme objet QwtScaleDiv en utilisant setScaleDiv(), l'échelle peut être dessinée avec la méthode draw().

void QwtAbstractScaleDraw::setMinimumExtent (double minExtent)

Définir une limite inférieure pour la dimension. La dimension est calculée à partir des composants de l'échelle. Dans des situations où les étiquettes changent et où la mise en page dépend de la dimension (par exemple, le décalage d'une échelle), définir une limite supérieure comme dimension minimale évitera des sauts dans la mise en page.

Detailed Description

This is an abstract base class for all scale drawables. It abstracts the common properties of scales like the tick attributes and provides the interface for drawing scales.
