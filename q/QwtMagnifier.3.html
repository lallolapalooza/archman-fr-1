void QwtMagnifier::setWheelFactor (double factor)

Change le facteur de molette. Le facteur de molette définit le rapport entre la plage actuelle du widget parent et la plage zoomée pour chaque pas de la molette.

Utilisez des valeurs > 1 pour le zoom avant (par exemple, 2.0) et des valeurs < 1 pour le zoom arrière (par exemple, 1/2.0 = 0.5). Vous pouvez utiliser cette fonction pour inverser la direction de la molette.

NAME

QwtMagnifier — magnifier item.

SYNOPSIS

#include <qwt_magnifier.h>

class QwtMagnifier;

Detailed Description

This class can be used to magnify a region of a plot.

The magnifier is implemented by overriding the default behavior of mouse events. The events are processed by the eventFilter function.

In normal operation the magnifier uses mouse button 1 (the left button) to zoom in and mouse button 2 (the middle button) to zoom out. The zoom factor can be controlled by the setZoomFactor function.

The QwtMagnifier class offers the following features:

  • Zooming in/out with mouse buttons.

  • Zooming to a specific bounding box by dragging the mouse with button 1 pressed.

  • Zooming to the original plot boundaries by double clicking with button 1.

  • Zooming to the original plot boundaries by clicking with button 2.

The magnifier can be enabled/disabled using the setEnabled function.

QwtMagnifier — élément d'agrandissement.

SYNTAXE

#include <qwt_magnifier.h>

Description détaillée

Cette classe peut être utilisée pour agrandir une région d'un graphique.

L'agrandissement est implémenté en remplaçant le comportement par défaut des événements de souris. Les événements sont traités par la fonction eventFilter.

En fonctionnement normal, l'agrandissement utilise le bouton de la souris 1 (bouton gauche) pour zoomer et le bouton de la souris 2 (bouton du milieu) pour dézoomer. Le facteur de zoom peut être contrôlé par la fonction setZoomFactor.

La classe QwtMagnifier offre les fonctionnalités suivantes :

  • Zoom avant/arrière avec les boutons de la souris.

  • Zoom sur une boîte englobante spécifique en faisant glisser la souris avec le bouton 1 enfoncé.

  • Zoom sur les limites originales du graphique en double-cliquant avec le bouton 1.

  • Zoom sur les limites originales du graphique en cliquant avec le bouton 2.

L'agrandissement peut être activé/désactivé à l'aide de la fonction setEnabled.
