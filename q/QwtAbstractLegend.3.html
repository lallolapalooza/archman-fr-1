Description détaillée

Classe de base abstraite pour les widgets de légende.

Les légendes, qui doivent être sous le contrôle du système de mise en page QwtPlot, doivent être dérivées de QwtAbstractLegend.

Note

D'autres types de légendes peuvent être implémentés en se connectant au signal QwtPlot::legendDataChanged(). Mais comme ces légendes sont inconnues du système de mise en page du graphique, le code de mise en page (à l'écran et pour QwtPlotRenderer) doit être organisé dans le code de l'application.
