Description détaillée

Une surcouche pour un widget.

L'utilisation principale d'un widget de surcouche est d'éviter des opérations de repeinture coûteuses du widget sous-jacent.

Par exemple, combiné avec une toile de graphique, une surcouche évite les repeintures en restaurant le contenu de la toile depuis son stockage de support.

QwtWidgetOverlay est une classe de base abstraite. Les classes dérivées doivent réimplémenter les méthodes suivantes :

  • drawOverlay()
  • maskHint()

Interne QwtPlotPicker utilise des surcouches pour afficher la bordure de sélection et le texte du traceur.

Documentation des énumérations de membres

enum QwtWidgetOverlay::MaskMode

Mode de masque. Lors de l'utilisation de masques, le widget sous-jacent ne reçoit des événements de peinture que pour les régions de la surcouche qui sont masquées. Sinon, Qt effectue des repeintures complètes. Sur les systèmes plus anciens (par exemple, systèmes embarqués) – ou lors de l'utilisation du moteur de rendu raster dans une fenêtre distante – la copie de bits peut être une opération notoirement lente qu'il faut éviter.

Quand et comment masquer dépend de la difficulté de calculer le masque et du nombre de pixels qui peuvent être exclus par le masque.

La valeur par défaut est MaskHint.

Voir aussi

setMaskMode(), maskMode()

Énumérateurs

NoMask
Ne pas utiliser de masque.
MaskHint
Utiliser maskHint() comme masque. Pour de nombreux cas, une approximation rapide suffit et il n'est pas nécessaire de construire un masque plus détaillé (par exemple, le rectangle d'un texte).
AlphaMask
Calculer un masque en vérifiant les valeurs alpha. Parfois, il n'est pas possible de fournir une approximation rapide et le masque doit être calculé en dessinant la surcouche et en testant le résultat.

Lorsqu'un maskHint() valide est disponible, seuls les pixels dans cette approximation sont examinés.

enum QwtWidgetOverlay::RenderMode

Mode de rendu. Pour calculer le masque de la surcouche, celle-ci a déjà été dessinée sur une image temporaire. Au lieu de dessiner la surcouche deux fois, ce tampon peut être copié pour dessiner la surcouche.

Sur les systèmes graphiques utilisant le moteur de rendu raster (QWS, Windows), cela signifie généralement copier uniquement quelques blocs de mémoire. Sur X11, cela entraîne une opération coûteuse et lente, car un pixmap est créé et ce n'est pas recommandé pour des surcouches simples.

Note

Le mode de rendu n'a aucun effet si maskMode() != AlphaMask.

Énumérateurs

AutoRenderMode
Copier le tampon, lorsque le moteur de rendu raster est utilisé.
CopyAlphaMask
Copier toujours le tampon.
DrawOverlay
Ne jamais copier le tampon.

Detailed Description

Overlay widget that can be painted on top of another widget.

The overlay widget can be used to draw additional information on top of an existing widget, without modifying the widget itself. The overlay widget is automatically positioned and sized to match the target widget. The actual drawing is done in the drawOverlay() function, which can be overridden by subclasses.

The overlay can be configured to use a mask to clip the drawing area. The maskMode() function returns the current mask mode, and setMaskMode() can be used to change it.

The render mode can be used to control how the overlay is drawn in relation to the target widget. The renderMode() function returns the current render mode, and setRenderMode() can be used to change it.

The updateOverlay() slot can be used to trigger a repaint of the overlay, for example, after changing its configuration or the target widget's appearance.

Member Enumeration Documentation

MaskMode

Specifies how to calculate the mask for the overlay.

NoMask
No mask is used. The overlay is drawn directly onto the target widget.
InShape
The mask is calculated based on the shape of the target widget. Only the pixels within the shape of the target widget are painted.
FillToShape
The mask is calculated by filling the shape of the target widget. This is useful when the target widget has a complex shape and you want to fill the entire area within that shape.

Description détaillée

Widget de superposition qui peut être dessiné par-dessus un autre widget.

Le widget de superposition peut être utilisé pour dessiner des informations supplémentaires par-dessus un widget existant, sans modifier le widget lui-même. Le widget de superposition est automatiquement positionné et dimensionné pour correspondre au widget cible. Le dessin réel est effectué dans la fonction drawOverlay(), qui peut être substituée par des sous-classes.

La superposition peut être configurée pour utiliser un masque afin de découper la zone de dessin. La fonction maskMode() renvoie le mode de masque actuel, et setMaskMode() peut être utilisée pour le modifier.

Le mode de rendu peut être utilisé pour contrôler comment la superposition est dessinée par rapport au widget cible. La fonction renderMode() renvoie le mode de rendu actuel, et setRenderMode() peut être utilisée pour le modifier.

Le slot updateOverlay() peut être utilisé pour déclencher une nouvelle peinture de la superposition, par exemple, après avoir modifié sa configuration ou l'apparence du widget cible.

Documentation des énumérations des membres

MaskMode

Spécifie comment calculer le masque pour la superposition.

NoMask
Aucun masque n'est utilisé. La superposition est dessinée directement sur le widget cible.
InShape
Le masque est calculé en fonction de la forme du widget cible. Seuls les pixels à l'intérieur de la forme du widget cible sont peints.
FillToShape
Le masque est calculé en remplissant la forme du widget cible. Ceci est utile lorsque le widget cible a une forme complexe et que vous souhaitez remplir toute la zone à l'intérieur de cette forme.
