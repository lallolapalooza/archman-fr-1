Description Détaillée

Un widget de tracé affichant un système de coordonnées polaire.

Un nombre illimité d'éléments de tracé peut être affiché sur sa toile. Les éléments de tracé peuvent être des courbes (QwtPolarCurve), des marqueurs (QwtPolarMarker), la grille (QwtPolarGrid), ou tout autre objet dérivé de QwtPolarItem.

Le système de coordonnées est défini par une échelle radiale et une échelle d'azimut. Les échelles aux axes peuvent être explicitement définies (QwtScaleDiv), ou calculées à partir des éléments de tracé, en utilisant des algorithmes (QwtScaleEngine) qui peuvent être configurés séparément pour chaque axe. La mise à l'échelle automatique est prise en charge pour l'échelle radiale.

Contrairement à QwtPlot, les échelles peuvent être différentes de la vue qui est affichée sur la toile. La vue peut être modifiée par zoom - par exemple en utilisant QwtPolarPanner ou QwtPolarMagnifier.

void QwtPolarPlot::insertLegend (QwtAbstractLegend * legend, QwtPolarPlot::LegendPosition pos = RightLegend, double ratio = -1.0)

Insérer une légende. Si la position de la légende est QwtPolarPlot::LeftLegend ou QwtPolarPlot::RightLegend, la légende sera organisée en une seule colonne de haut en bas. Sinon, les éléments de la légende seront placés dans un tableau avec un nombre de colonnes optimisé de gauche à droite.

Si pos != QwtPolarPlot::ExternalLegend, le widget du graphique deviendra le parent de la légende. Elle sera supprimée lorsque le graphique sera supprimé, ou lorsqu'une autre légende sera définie avec insertLegend().

Paramètres

legend Légende
pos La position de la légende. Pour les positions haut/gauche, le nombre de colonnes sera limité à 1, sinon il sera illimité.
ratio Ratio entre la légende et le rectangle englobant du titre, de la toile et des axes. La légende sera réduite si elle nécessite plus d'espace que le ratio donné. Le ratio est limité à ]0.0 .. 1.0]. Dans le cas de <= 0.0, il sera réinitialisé au ratio par défaut. Le ratio vertical/horizontal par défaut est de 0.33/0.5.

Detailed Description

This is the reference documentation of the public members for class QwtPolarPlot.

A polar plot is a plot where the x-axis is angular and the y-axis is radial. The origin (0,0) is the center of the polar coordinate system.

The polar plot has two scales:

-- Radial scale
Represents the distance from the origin. The scale is displayed as a circle around the origin. The angular scale defines the range of the circle.
-- Angular scale
Represents the angle. The scale is displayed along the border of the polar plot.

The plot has a plot-area, that is the circle defining the range of the radial scale. A plot item can be added to the plot.

The plot needs a map to translate between polar and plot coordinates. QwtPolarPlotMapper is used for this purpose.

Member Enumeration Documentation

enumerations

The enumeration ScaleId is used to identify the different scales of the polar plot.

Qt::PolarAuto = -1
Auto mode for the angular scale.
Qt::PolarRadial = 0
Radial scale.
Qt::PolarAngular = 1
Angular scale.
