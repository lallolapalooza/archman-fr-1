Description détaillée

Un dictionnaire pour les éléments de graphique polaire.

QwtPolarItemDict organise les éléments de graphique polaire par ordre croissant de z. Si autoDelete() est activé, tous les éléments attachés seront supprimés dans le destructeur du dictionnaire.

Voir aussi

QwtPolarItem::attach(), QwtPolarItem::detach(), QwtPolarItem::z()

Une QwtPolarItemList de tous les éléments de graphique attachés.

Retourne

Note

Utilisez la prudence lors de l'itération sur ces listes, car la suppression/détachement d'un élément peut invalider l'itérateur. À la place, vous pouvez placer des pointeurs vers des objets à supprimer dans une liste de suppression, puis parcourir cette liste plus tard.
