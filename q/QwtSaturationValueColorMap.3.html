Description détaillée

QwtSaturationValueColorMap varie la saturation et/ou la valeur pour une teinte donnée dans le modèle de couleur HSV.

La valeur et la saturation sont dans la plage de 0 à 255 tandis que la teinte est dans la plage de 0 à 259.

Descripción detallada

El mapa de color de Qwt tiene un dominio y un rango, ambos especificados en los intervalos [0, 255].

El dominio de las colormaps de Qwt son los valores de intensidad de píxeles que se mapean a los valores de color.

Los valores de color son valores RGB. El dominio y el rango son definidos para cada uno de los canales de color individualmente.

Este mapa de color especial permite construir un mapa de color, que es una interpolación lineal entre dos colores.

El dominio de estos valores de color es también [0, 255].
