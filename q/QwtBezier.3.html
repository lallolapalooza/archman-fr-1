Description détaillée

Implémentation de l'algorithme de Casteljau pour l'interpolation de courbes de Bézier.

Le critère de planéité pour terminer la subdivision est basé sur 'Piecewise Linear Approximation of Bézier Curves' par Roger Willcocks ( http://www.rops.org )

Cet article explique très bien les mathématiques sous-jacentes : https://jeremykun.com/2013/05/11/bezier-curves-and-picasso

void QwtBezier::appendToPolygon (const QPointF & p1, const QPointF & cp1, const QPointF & cp2, const QPointF & p2, QPolygonF & polygon) const

Ajoute à un polygone les points d'une courbe de Bézier interpolée. appendToPolygon() est conçue pour accumuler des points d'une séquence de courbes de Bézier, comme celles créées par une interpolation spline.

Paramètres

cp1 Premier point de contrôle
cp2 Second point de contrôle
p2 Point de fin
polygon Polygone auquel les points interpolés sont ajoutés

Note

Si le dernier point du polygone entrant correspond à p1, il ne sera pas inséré une seconde fois.

void QwtBezier::setTolerance (double tolerance)

Définit la tolérance.

La tolérance est une mesure de la planéité d'une courbe. Une courbe dont la planéité est inférieure à la tolérance est considérée comme plate, terminant ainsi l'algorithme de subdivision.

Lors de l'interpolation d'une courbe de Bézier pour la rendre sous forme d'une séquence de lignes vers un type de grille quelconque (par exemple, l'écran), une valeur de 0.5 de la taille du pixel est une bonne valeur pour la tolérance.

Paramètres

tolerance Critère de terminaison pour la subdivision

Qwt Bezier — Classe de courbe de Bézier Qwt

Date: 2023-10-27

NOM

QwtBezier — Classe de courbe de Bézier Qwt

SYNOPSIS

#include <qwt_bezier.h>

Class QwtBezier

Hérite de QwtSpline.

DESCRIPTION

Cette classe implémente une spline de Bézier. Une courbe de Bézier est définie par une série de points de contrôle. Les propriétés principales d'une courbe de Bézier sont les points de contrôle qui déterminent la forme de la courbe.

La classe QwtBezier dérive de QwtSpline et fournit une implémentation spécifique pour les courbes de Bézier. Elle permet de définir des courbes lisses et continues qui peuvent être utilisées pour dessiner des formes complexes.
