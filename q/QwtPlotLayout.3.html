Description détaillée

Moteur de mise en page pour QwtPlot.

Il est utilisé par le widget QwtPlot pour organiser ses widgets internes ou par QwtPlot::print() pour rendre son contenu sur un périphérique de dessin QPaintDevice comme un QPrinter, QPixmap/QImage ou QSvgRenderer.

void QwtPlotLayout::setAlignCanvasToScale (int axisPos, bool on)

Change le paramètre d'alignement du canevas sur les échelles. Le canevas peut :

  • s'étendre au-delà des extrémités des échelles pour maximiser sa taille,
  • s'aligner sur les extrémités des échelles pour contrôler sa taille.

Le paramètre axisId est quelque peu trompeur car il identifie une bordure du graphique et non les axes qui sont alignés. Par exemple, lorsque QwtAxis::YLeft est défini, l'extrémité gauche des axes X ( QwtAxis::XTop, QwtAxis::XBottom ) est alignée.

Paramètres

axisId Indice de l'axe
on Nouveau paramètre d'alignement du canevas sur les échelles

Voir aussi

setCanvasMargin(), alignCanvasToScale(), setAlignCanvasToScales()

Attention

Dans le cas où on == true, canvasMargin() n'aura aucun effet

void QwtPlotLayout::setCanvasMargin (int margin, int axisPos = -1)

Modifie une marge du canevas. La marge est l'espace au-dessus/en-dessous des graduations de l'échelle. Une marge négative sera mise à -1, excluant les bords des échelles.

Paramètres

margin Nouvelle marge
axisPos L'un des QwtAxis::Position. Spécifie la position de la marge. -1 signifie marge à tous les bords.

Voir aussi

canvasMargin()

Attention

La marge n'aura aucun effet lorsque alignCanvasToScale() est vrai

void QwtPlotLayout::setLegendPosition (QwtPlot::LegendPosition pos, double ratio)

Spécifie la position de la légende.

Paramètres

pos La position de la légende.
ratio Ratio entre la légende et le rectangle englobant du titre, du pied de page, du canevas et des axes. La légende sera réduite si elle nécessite plus d'espace que le ratio donné. Le ratio est limité à ]0.0 .. 1.0]. Dans le cas de <= 0.0, il sera réinitialisé au ratio par défaut. Le ratio vertical/horizontal par défaut est de 0.33/0.5.
