Module Queue
: sig end

Files d'attente premier entré, premier sorti.

Ce module implémente des files d'attente (FIFO), avec modification en place. Voir Queue.examples ci-dessous.

Alerte unsynchronized_access. Les accès non synchronisés aux files d'attente sont une erreur de programmation.

Accès non synchronisés

Les accès non synchronisés à une file d'attente peuvent entraîner un état invalide de la file. Ainsi, les accès concurrents aux files d'attente doivent être synchronisés (par exemple avec un Mutex.t ).

type !'a t

Le type des files d'attente contenant des éléments de type 'a .

exception Empty

Levée lorsque Queue.take ou Queue.peek est appliqué à une file d'attente vide.

val create : unit -> 'a t

Retourne une nouvelle file d'attente, initialement vide.

val add : 'a -> 'a t -> unit

add x q ajoute l'élément x à la fin de la file d'attente q .

val push : 'a -> 'a t -> unit

push est un synonyme de add .

val take : 'a t -> 'a

take q supprime et retourne le premier élément de la file d'attente q , ou lève Queue.Empty si la file d'attente est vide.

val take_opt : 'a t -> 'a option

take_opt q supprime et retourne le premier élément de la file d'attente q , ou retourne None si la file d'attente est vide.

Depuis 4.08

val pop : 'a t -> 'a

pop est un synonyme de take .

val peek : 'a t -> 'a

peek q retourne le premier élément de la file d'attente q , sans le retirer de la file, ou lève Queue.Empty si la file d'attente est vide.

val peek_opt : 'a t -> 'a option

peek_opt q retourne le premier élément de la file d'attente q , sans le retirer de la file, ou retourne None si la file d'attente est vide.

Depuis 4.08

val top : 'a t -> 'a

top est un synonyme de peek .

val drop : 'a t -> unit

drop q supprime le premier élément de la file d'attente q , ou lève Queue.Empty si la file d'attente est vide.

Depuis 5.3

val clear : 'a t -> unit

Supprime tous les éléments d'une file d'attente.

val copy : 'a t -> 'a t

Retourne une copie de la file d'attente donnée.

val is_empty : 'a t -> bool

Retourne true si la file d'attente donnée est vide, false sinon.

val length : 'a t -> int

Retourne le nombre d'éléments dans une file d'attente.

val iter : ('a -> unit) -> 'a t -> unit

iter f q applique f successivement à tous les éléments de q , du moins récent au plus récent. La file d'attente elle-même n'est pas modifiée.

val fold : ('acc -> 'a -> 'acc) -> 'acc -> 'a t -> 'acc

fold f accu q est équivalent à List.fold_left f accu l , où l est la liste des éléments de q . La file d'attente reste inchangée.

val transfer : 'a t -> 'a t -> unit

transfer q1 q2 ajoute tous les éléments de q1 à la fin de la file d'attente q2 , puis vide q1 . C'est équivalent à la séquence iter (fun x -> add x q2) q1; clear q1 , mais s'exécute en temps constant.

Recherche dans un graphe

Pour un exemple plus élaboré, une utilisation classique des files d'attente en algorithmique est l'implémentation d'un parcours en largeur (BFS) dans un graphe.

     type graph = {
       edges: (int, int list) Hashtbl.t
     }
    (* Recherche dans le graphe [g] en utilisant le parcours en largeur (BFS), en partant du nœud [start].
       Retourne le premier nœud qui satisfait [p], ou [None] si
       aucun nœud atteignable depuis [start] ne satisfait [p].
    *)
    let search_for ~(g:graph) ~(start:int) (p:int -> bool) : int option =
      let to_explore = Queue.create() in
      let explored = Hashtbl.create 16 in
      Queue.push start to_explore;
      let rec loop () =
        if Queue.is_empty to_explore then None
        else
          (* nœud à explorer *)
          let node = Queue.pop to_explore in
          explore_node node
      and explore_node node =
        if not (Hashtbl.mem explored node) then (
          if p node then Some node (* trouvé *)
          else (
            Hashtbl.add explored node ();
            let children =
              Hashtbl.find_opt g.edges node
              |> Option.value ~default:[]
            in
            List.iter (fun child -> Queue.push child to_explore) children;
            loop()
          )
        ) else loop()
      in
      loop()
    (* un graphe d'exemple *)
    let my_graph: graph =
      let edges =
        List.to_seq [
          1, [2;3];
          2, [10; 11];
          3, [4;5];
          5, [100];
          11, [0; 20];
        ]
        |> Hashtbl.of_seq
      in {edges}
    # search_for ~g:my_graph ~start:1 (fun x -> x = 30)
    - : int option = None
    # search_for ~g:my_graph ~start:1 (fun x -> x >= 15)
    - : int option = Some 20
    # search_for ~g:my_graph ~start:1 (fun x -> x >= 50)
    - : int option = Some 100

Bienvenue sur Arch Linux

Arch Linux est une distribution Linux autogérée, légère et flexible, conçue pour les développeurs et les utilisateurs expérimentés. Elle suit un modèle de développement continu (rolling release), ce qui signifie que les mises à jour sont publiées fréquemment et que le système est toujours à la pointe de la technologie.

L'un des principes fondamentaux d'Arch Linux est la simplicité. Cela ne signifie pas qu'il est facile à utiliser pour un débutant, mais plutôt qu'il est conçu avec un minimum de modifications et une structure claire. L'utilisateur est responsable de la configuration de son système selon ses propres besoins.

Caractéristiques principales :

  • Simplicité : Pas de configuration inutile, chaque paquet est choisi et configuré par l'utilisateur.
  • Modernité : Les dernières versions stables des logiciels sont disponibles rapidement grâce au modèle de publication continue.
  • Flexibilité : Vous construisez votre système à partir d'une base minimale, en ajoutant uniquement ce dont vous avez besoin.
  • Orienté utilisateur : Les utilisateurs ont le contrôle total sur leur système.
  • Pacman : Un gestionnaire de paquets puissant et simple à utiliser.
  • Arch User Repository (AUR) : Une vaste collection de paquets créés par la communauté.

Installation :

L'installation d'Arch Linux se fait en ligne de commande à l'aide d'un script d'installation interactif. Bien que cela puisse sembler intimidant, le processus est bien documenté dans le Guide d'installation Arch Linux.

Communauté :

Arch Linux dispose d'une communauté active et serviable. Le Arch Wiki est une ressource inestimable contenant une documentation complète sur presque tous les aspects d'Arch Linux.

Tous les logiciels utilisés dans les paquets Arch Linux sont distribués sous leurs licences respectives, qui sont spécifiées dans le paquet Arch Linux correspondant.
