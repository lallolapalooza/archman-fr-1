Description détaillée

Paramétrage de courbe utilisé pour une interpolation spline.

Le paramétrage est le processus de recherche d'une valeur de paramètre pour chaque point de la courbe - généralement liée à une quantité physique (distance, temps ...).

Souvent, l'accumulation de la longueur de la courbe est la manière prévue de paramétrer, mais comme la courbe interpolée n'est pas connue à l'avance, une approximation doit être utilisée.

Les valeurs sont calculées en cumulant des incréments, qui sont fournis par QwtSplineParametrization. Comme les paramètres de la courbe doivent être monotones croissants, chaque incrément doit être positif.

  • t[0] = 0;
  • t[i] = t[i-1] + valueIncrement( point[i-1], p[i] );

QwtSplineParametrization fournit les types de paramétrages les plus couramment utilisés et offre une interface pour injecter des implémentations personnalisées.

Note

Les types de paramétrage les plus pertinents tentent de fournir une approximation de la longueur de la courbe.

Detailed Description

Parametrization for QwtSpline algorithms

When a spline is sampled on a grid, the distance between the sampled points is not constant. The parameterization provides a way to calculate the parameter step for each segment. The parameter is calculated relative to the distance between the control points.

The following parametrizations are available:

  • ParameterX: The parameter step is the difference between the x-coordinates.
  • ParameterY: The parameter step is the difference between the y-coordinates.
  • ParameterUniform: The parameter step is always 1.0.
  • ParameterChordal: The parameter step is the distance between the control points (chordal distance).
  • ParameterCentripetal: The parameter step is the square root of the chordal distance.
  • ParameterManhattan: The parameter step is the Manhattan distance between the control points.

The default parametrization is ParameterChordal.
