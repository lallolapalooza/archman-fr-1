Description détaillée

QwtHueColorMap fait varier la valeur de teinte dans le modèle HSV des couleurs.

QwtHueColorMap peut être utilisé pour définir une palette de couleurs facilement, qui se répète cycliquement à travers toutes les couleurs. Chaque cycle a 360 pas différents.

Les valeurs pour la valeur et la saturation sont dans la plage de 0 à 255 et ne dépendent pas de la valeur de données à mapper.

void QwtHueColorMap::setHueInterval (int hue1, int hue2)

Définit l'intervalle de la coordonnée de teinte
