Description détaillée

Attributs d'une entrée de légende.

QwtLegendData est un conteneur abstrait (similaire à QAbstractModel) pour échanger des attributs, qui ne sont connus qu'entre l'élément du graphique (plot item) et la légende.

En surchargeant QwtPlotItem::legendData(), vous pouvez utiliser toute autre collection d'attributs, qui peuvent être gérés par une implémentation modifiée (ou complètement différente) d'une légende.

Voir aussi QwtLegend, QwtPlotLegendItem

Note : L'exemple stockchart implémente une légende comme un arbre avec des éléments sélectionnables.

QwtLegendData - Legend item data.

QwtLegendData is an abstract base class for legend item data.

Synopsis

#include <qwt_legend_data.h>

Inherits from QwtObject.

Inherited by QwtTextLabel.

Description

The abstract base class QwtLegendData defines the interface for data objects that can be displayed in a legend.

All legend items share a common interface to render themselves. This interface is defined by the abstract base class QwtLegendData.

The QwtLegend class uses these data objects to render the legend items. The legend plugin, that is responsible for the rendering, can query the data object for its representation (e.g. text, pixmap, etc.).

QwtLegendData - Données d'élément de légende.

QwtLegendData est une classe de base abstraite pour les objets de données d'élément de légende.

Synopsis

#include <qwt_legend_data.h>

Hérite de QwtObject.

Hérite de QwtTextLabel.

Description

La classe de base abstraite QwtLegendData définit l'interface des objets de données qui peuvent être affichés dans une légende.

Tous les éléments de légende partagent une interface commune pour se rendre. Cette interface est définie par la classe de base abstraite QwtLegendData.

La classe QwtLegend utilise ces objets de données pour rendre les éléments de légende. Le plugin de légende, responsable du rendu, peut interroger l'objet de données pour sa représentation (par exemple, texte, pixmap, etc.).
