Description détaillée

Un point en coordonnées polaires.

En coordonnées polaires, un point est déterminé par un angle et une distance. Voir http://en.wikipedia.org/wiki/Polar_coordinate_system

QwtPointPolar QwtPointPolar::normalized () const

Normalise le rayon et l'azimut.

Lorsque le rayon est < 0.0, il est défini à 0.0. L'azimut est une valeur >= 0.0 et < 2 * M_PI.

Point normalisé

bool QwtPointPolar::operator!= (const QwtPointPolar & other) const

Compare 2 points.

Deux points sont égaux s'ils ont le même rayon et le même azimut. Les points ne sont pas égaux lorsque l'azimut diffère, mais other.azimuth() est égal à azimuth() % (2 * PI).

Retourne

Vrai si le point est différent de other ; sinon retourne faux.
