Description détaillée

Classe abstraite pour les widgets de curseur avec une échelle.

Un widget de curseur affiche une valeur selon une échelle. La classe est conçue comme une superclasse commune pour les widgets tels que QwtKnob, QwtDial et QwtSlider.

Lorsque le curseur n'est pas en mode lecture seule, sa valeur peut être modifiée par des entrées clavier, souris et molette.

L'échelle du curseur est divisée en un certain nombre de pas, dont la valeur est incrémentée selon les entrées de l'utilisateur. Pour les échelles linéaires uniquement, le nombre de pas correspond à une taille fixe.

void QwtAbstractSlider::keyPressEvent (QKeyEvent * event) [override], [protected], [virtual]

Gère les événements clavier

QwtAbstractSlider gère les touches suivantes :

  • Qt::Key_Left
    Ajoute/Retire singleSteps() en direction de lowerBound() ;
  • Qt::Key_Right
    Ajoute/Retire singleSteps() en direction de upperBound() ;
  • Qt::Key_Down
    Retire singleSteps() lorsque invertedControls() est faux
  • Qt::Key_Up
    Ajoute singleSteps() lorsque invertedControls() est faux
  • Qt::Key_PageDown
    Retire pageSteps() lorsque invertedControls() est faux
  • Qt::Key_PageUp
    Ajoute pageSteps() lorsque invertedControls() est faux
  • Qt::Key_Home
    Définit la valeur sur le minimum()
  • Qt::Key_End
    Définit la valeur sur le maximum()

void QwtAbstractSlider::setInvertedControls (bool on)

Inverse les événements de molette et de clavier

En général, faire défiler la molette de la souris vers le haut augmente la valeur du curseur vers son maximum. Lorsque invertedControls() est actif, la valeur se déplace vers son minimum.

Inverser les contrôles peut être utile pour un curseur vertical avec une échelle inversée (décroissante de haut en bas).

Paramètres

on Inverse les contrôles lorsque vrai

void QwtAbstractSlider::wheelEvent (QWheelEvent * event) [override], [protected], [virtual]

Gestionnaire d'événements de molette

Augmente/diminue la valeur d'un certain nombre de pas. La direction dépend de la propriété invertedControls().

Lorsque le modificateur de contrôle ou de majuscule est enfoncé, le delta de la molette ( divisé par 120 ) est mappé à un incrément selon pageSteps(). Sinon, il est mappé à singleSteps().

Paramètres

event Événement de molette

Redéfini dans QwtDial.
