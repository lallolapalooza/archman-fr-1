Description détaillée

Une horloge analogique.

Exemple

#include <qwt_analog_clock.h>
  QwtAnalogClock *clock = new QwtAnalogClock(...);
  clock->scaleDraw()->setPenWidth(3);
  clock->setLineWidth(6);
  clock->setFrameShadow(QwtDial::Sunken);
  clock->setTime();
  // met à jour l'horloge chaque seconde
  QTimer *timer = new QTimer(clock);
  timer->connect(timer, SIGNAL(timeout()), clock, SLOT(setCurrentTime()));
  timer->start(1000);

Note

L'exemple examples/dials montre comment utiliser QwtAnalogClock.

Detailed Description

This class implements a clock where the time is displayed by pointers. The pointers can be moved programmatically using `setTime()` or `setCurrentTime()`.

The clock is customizable. It is possible to change the color of the background and the pointers, as well as the shape of the pointers.

See also: QwtAbstractScale, QwtClock, QwtScaleWidget.
