Description détaillée

Une machine à états pour les sélections de QwtPicker.

QwtPickerMachine accepte les événements clavier et souris et les traduit en commandes de sélection.

Voir aussi

QwtEventPattern::MousePatternCode, QwtEventPattern::KeyPatternCode

Type d'une sélection.

selectionType()

Énumérateur

NoSelection
La machine à états n'est utilisable pour aucun type de sélection.
PointSelection
La machine à états sert à sélectionner un seul point.
RectSelection
La machine à états sert à sélectionner un rectangle (2 points).
PolygonSelection
La machine à états sert à sélectionner un polygone (plusieurs points).
