QwtPlotRescaler gère les rapports d'aspect fixes pour les échelles de graphique.

QwtPlotRescaler ajuste automatiquement les axes d'un QwtPlot selon des rapports d'aspect fixes.

enum QwtPlotRescaler::RescalePolicy

La politique de redimensionnement définit comment redimensionner l'axe de référence et ses axes dépendants.

Voir aussi

ExpandingDirection, setIntervalHint()

Énumérateur

Fixed
L'intervalle de l'axe de référence reste inchangé lorsque la géométrie du canevas change. Tous les autres axes seront ajustés selon leur rapport d'aspect.
Expanding
L'intervalle de l'axe de référence sera réduit/élargi lorsque la géométrie du canevas change. Tous les autres axes seront ajustés selon leur rapport d'aspect.

L'intervalle représenté par un pixel est fixe.

Fitting
Les intervalles des axes sont calculés de manière à ce que tous les axes incluent leur indice d'intervalle.

Detailed Description

Este escalador de ejes de gráfico ajusta el intervalo de los ejes del gráfico para que encaje en el tamaño actual del lienzo, o para mantener un tamaño de lienzo fijo. El intervalo de los ejes se puede ajustar en relación con sus dimensiones de datos (p. ej., la distancia entre el valor mínimo y el valor máximo de los datos), o en relación con el tamaño del lienzo.

La clase es una subclasificación de QwtPlot para poder acceder a los datos de los ejes del gráfico, y para poder establecer los intervalos de los ejes cuando se produce un cambio en el tamaño del gráfico.

La clase principal para ajustar los intervalos de los ejes es rescale(). Esta función se llama automáticamente cada vez que se cambia el tamaño del lienzo, o cuando se llama explícitamente.

El RescaleStyle determina cómo se ajustan los ejes:

NoRescale
No se realiza ningún ajuste.
Fit
El intervalo de los ejes se ajusta al tamaño del lienzo, manteniendo la relación de aspecto.
KeepSize
El tamaño del lienzo se mantiene fijo. Si el tamaño del lienzo cambia, el intervalo de los ejes se amplía o se contrae en consecuencia.
Horizontal
El eje horizontal se ajusta al tamaño del lienzo.
Vertical
El eje vertical se ajusta al tamaño del lienzo.
Both
Ambos ejes se ajustan al tamaño del lienzo.

Los intervalos de los ejes se pueden ajustar explícitamente llamando a setIntervalData(). Si se llama a esta función, el escalador utilizará el intervalo especificado en lugar de calcular uno nuevo. Esto es útil para establecer límites fijos en los ejes.

Para habilitar el ajuste automático del tamaño, debe conectar la señal QwtPlot::resized() a la ranura QwtPlotRescaler::rescale().

Aquí hay un ejemplo de cómo usar QwtPlotRescaler:

QwtPlot *plot = new QwtPlot( this );
QwtPlotRescaler *rescaler = new QwtPlotRescaler( plot );
rescaler->setRescalePolicy( QwtPlotRescaler::Fit );
plot->connect( plot, &QwtPlot::resized,
    rescaler, &QwtPlotRescaler::rescale );
