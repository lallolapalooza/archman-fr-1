QMCGROUP(3) Manuel des fonctions de bibliothèque QMCGROUP(3)

NOM

QmcGroup - conteneur représentant un groupe de récupération unique de métriques à partir de plusieurs sources

SYNTAXE C++

#include <QmcGroup.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPTION

Un objet QmcGroup est un conteneur pour les contextes et les métriques qui doivent être récupérés en même temps. La classe gère les objets QmcContext(3), les fuseaux horaires et les limites pour chaque contexte créé avec QmcGroup::use et QmcGroup::addMetric.

CONSTRUCTEURS & DESTRUCTEUR

~QmcGroup();
Destructeur qui détruit toutes les métriques et tous les contextes créés par ce groupe.
QmcGroup(bool restrictArchives = false);
Construit un nouveau groupe de récupération. restrictArchives limitera la création de plusieurs contextes d'archives créés à partir du même hôte.

CONTEXTES

Le contexte par défaut du groupe est défini comme le premier contexte créé avec QmcGroup::use avant le premier appel à QmcGroup::addMetric. Si aucun contexte n'est créé avant l'ajout de la première métrique, l'hôte local est utilisé comme contexte par défaut. Par conséquent, si les spécifications de métriques contiennent des sources d'archives, une source d'archives doit avoir été créée avec QmcGroup::use pour éviter une erreur lors du mélange des types de contextes.

uint_t numContexts() const;
Le nombre de contextes valides créés dans ce groupe.
QmcContext const& context(uint_t index) const
Retourne une référence vers un contexte.
QmcContext& context(uint_t index);
Retourne une référence modifiable vers un contexte.
int mode() const;
Retourne le type de contexte, soit PM_CONTEXT_LOCAL, PM_CONTEXT_HOST ou PM_CONTEXT_ARCHIVE.
QmcContext* which() const;
Retourne un pointeur vers le contexte actuel de ce groupe. Cela n'appelle pas pmUseContext(3), donc il pourrait ne pas être le contexte PMAPI(3) actuel.
uint_t contextIndex() const
L'index du contexte de groupe actuel.
int use(int type, char const* source);
Utilise le contexte de type à partir de source. Si un contexte vers cette source existe déjà dans ce groupe, ce contexte deviendra le contexte PMAPI(3) actuel. Sinon, un nouveau contexte sera créé. Le résultat est le handle du contexte PMAPI(3) pour le QmcGroup::context ou un code d'erreur PMAPI(3) si le contexte a échoué.
bool defaultDefined() const;
Retourne true si un contexte par défaut a été déterminé.
int useDefault();
Utilise le contexte par défaut. Si un contexte par défaut n'a pas été créé, une tentative sera faite pour utiliser le contexte de l'hôte local. Un résultat inférieur à zéro indique que la méthode a échoué avec l'erreur PMAPI(3) encodée dans le résultat.
void createLocalContext();
Crée et utilise un contexte vers l'hôte local. Un résultat inférieur à zéro indique que la méthode a échoué avec l'erreur PMAPI(3) encodée dans le résultat.

MÉTRIQUES

Ces méthodes addMetric doivent être utilisées pour créer de nouvelles métriques car les constructeurs de QmcMetric sont privés. Ces méthodes retourneront toujours un pointeur vers un objet QmcMetric, cependant le champ QmcMetric::status() doit être vérifié pour s'assurer que la métrique est valide.

QmcMetric* addMetric(char const* str, double theScale = 0.0,
bool active = false);

Ajoute la métrique str au groupe, avec un facteur d'échelle de scale. Si active est défini, la métrique n'utilisera que les instances actives (voir QmcMetric(3)).

QmcMetric* addMetric(pmMetricSpec* theMetric, double theScale
= 0.0, bool active);

Ajoute la métrique theMetric au groupe, avec un facteur d'échelle de scale. Si active est défini, la métrique n'utilisera que les instances actives (voir QmcMetric(3)).

int fetch(bool update = true);
Récupère toutes les métriques dans tous les contextes de ce groupe. Si update est égal à true, toutes les métriques de compteur seront automatiquement converties en taux (voir QmcMetric(3)).
int setArchiveMode(int mode, const struct timeval *when,
int interval);

Définit le mode et l'heure d'accès à tous les contextes d'archives de ce groupe. Voir pmSetMode(3) pour plus de détails.

FUSEAUX HORAIRES

Ces méthodes assistent dans la gestion de plusieurs fuseaux horaires et aident à contrôler le fuseau horaire actuel.

enum TimeZoneFlag { localTZ, userTZ, groupTZ, unknownTZ };
Énumération utilisée pour décrire l'origine du fuseau horaire par défaut. localTZ, userTZ et groupTZ indiquent que le fuseau horaire a été défini avec QmcGroup::useLocalTZ, QmcGroup::useTZ(QString const&) et QmcGroup::useTZ() respectivement. unknownTZ indique qu'aucun fuseau horaire n'a été défini. userTZ indique que le fuseau horaire a été
int useTZ();
Utilise le fuseau horaire du contexte de groupe actuel comme défaut.
int useTZ(const QString &tz);
Ajoute et utilise tz comme fuseau horaire par défaut de ce groupe.
int useLocalTZ();
Utilise le fuseau horaire de l'hôte local comme défaut pour ce groupe.
void defaultTZ(QString &label, QString &tz);
Retourne le label et la chaîne tz du fuseau horaire par défaut de ce groupe.
TimeZoneFlag defaultTZ() const
Retourne l'origine du fuseau horaire par défaut.
int useDefaultTZ();
Définit le fuseau horaire pour qu'il soit le fuseau horaire par défaut tel que défini dans un appel précédent à QmcGroup::useTZ ou QmcGroup::useLocalTZ.
struct timeval const& logStart() const;
Retourne l'heure de début la plus précoce de toutes les archives de ce groupe. Suppose que QmcGroup::updateBounds a été appelée.
struct timeval const& logEnd() const;
Retourne l'heure de fin la plus tardive de toutes les archives de ce groupe. Suppose que QmcGroup::updateBounds a été appelée.
void updateBounds();
Détermine les heures de début et de fin les plus précoces et les plus tardives de toutes les archives de ce groupe.
