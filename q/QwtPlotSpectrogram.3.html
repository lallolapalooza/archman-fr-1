Description détaillée

Un élément de graphique affichant un spectrogramme.

Un spectrogramme affiche des données tridimensionnelles, où la troisième dimension (la valeur d'intensité) est représentée par des couleurs. Les couleurs sont calculées à l'aide d'une palette de couleurs.

Sur les systèmes multi-cœurs, vous pouvez améliorer les performances de composition d'image en divisant la zone en tuiles - chacune rendue dans un thread différent (voir QwtPlotItem::setRenderThreadCount()).

En mode contour, des lignes de contour sont dessinées pour les niveaux de contour.

Voir aussi

QwtRasterData, QwtColorMap, QwtPlotItem::setRenderThreadCount()

QSize QwtPlotSpectrogram::contourRasterSize (const QRectF & area, const QRect & rect) const [protected], [virtual]

Retourne la grille de pixels à utiliser par l'algorithme de contour CONREC. Une taille plus grande améliore la précision de l'algorithme CONREC, mais ralentit le temps de calcul des lignes.

L'implémentation par défaut retourne rect.size() / 2 limité à la résolution dépendant de la valeur de pixelSize().

Paramètres

area Rectangle dans lequel calculer les lignes de contour
rect Rectangle en coordonnées pixel, où peindre les lignes de contour

Retourne

Grille de pixels à utiliser par l'algorithme de contour CONREC.

Note

La taille sera limitée à rect.size().

void QwtPlotSpectrogram::setColorTableSize (int numColors)

Limite le nombre de couleurs utilisées par la carte de couleurs

Lors de l'utilisation d'une table de couleurs, le mappage de la valeur vers une couleur est généralement plus rapide car il peut être effectué par de simples recherches dans une table de couleurs précalculée.

Définir une taille de table > 0 active l'utilisation d'une table de couleurs, tandis que la définir à 0 la désactive.

La taille par défaut est de 0, et aucune table de couleurs n'est utilisée.

Paramètres

numColors Nombre de couleurs. 0 signifie ne pas utiliser de table de couleurs

Note

La taille de la table de couleurs (colorTableSize) n'a aucun effet lors de l'utilisation d'une table de couleurs de type QwtColorMap::Indexed, où la taille est toujours de 256.

Voir aussi

QwtColorMap::colorTable(), colorTableSize()

Construit et assigne le stylo par défaut pour les lignes de contour
