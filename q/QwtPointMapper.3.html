Description détaillée

Une classe d'aide pour traduire une série de points.

QwtPointMapper est une collection de méthodes et d'optimisations pour traduire une série de points en coordonnées de périphérique de dessin. Il est utilisé par QwtPlotCurve mais pourrait également être utile pour des éléments de graphique similaires affichant une QwtSeriesData<QPointF>.

Documentation des énumérations membres

enum QwtPointMapper::TransformationFlag

Drapeaux affectant le processus de transformation.

Voir aussi

setFlag(), setFlags()

Énumérateur

RoundPoints
Arrondir les points à des valeurs entières.
WeedOutPoints
Essayer de supprimer les points qui sont traduits à la même position.
WeedOutIntermediatePoints
Un algorithme d'élimination encore plus agressif, qui peut être utilisé dans toPolygon().

Un bloc consécutif de points étant mappé à la même coordonnée x est réduit à 4 points :

  • premier point
  • point avec la coordonnée y minimale
  • point avec la coordonnée y maximale
  • dernier point

Dans le pire des cas (les premier et dernier points ne sont jamais parmi les extrêmes), le nombre de points sera 4 fois la largeur.

Comme l'algorithme est rapide, il peut être utilisé dans un cycle de rendu de polyligne.
