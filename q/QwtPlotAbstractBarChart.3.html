Description détaillée

Classe de base abstraite pour les éléments de graphique à barres.

Contrairement à presque tous les autres éléments de graphique, les graphiques à barres ne peuvent pas être affichés à l'intérieur de leur rectangle délimiteur et nécessitent une API spéciale pour calculer la largeur des barres et la manière dont elles affectent la disposition du graphique joint.

Énumération QwtPlotAbstractBarChart::LayoutPolicy

Mode de calcul de la largeur des barres. setLayoutPolicy(), setLayoutHint(), barWidthHint()

Énumérateur

AutoAdjustSamples
La largeur de l'échantillon est calculée en divisant le rectangle délimiteur par le nombre d'échantillons. La valeur de layoutHint() est utilisée comme largeur minimale dans les coordonnées du périphérique de dessin.

void QwtPlotAbstractBarChart::getCanvasMarginHint (const QwtScaleMap & xMap, const QwtScaleMap & yMap, const QRectF & canvasRect, double & left, double & top, double & right, double & bottom) const [override], [virtual]

Calcule une indication pour la marge du canevas. Les graphiques à barres doivent réserver un certain espace pour afficher les barres du premier et du dernier échantillon. L'indication est calculée à partir de layoutHint() en fonction de layoutPolicy().

Les marges sont dans les coordonnées du périphérique cible (pixels à l'écran)

Paramètres

xMap Mappe les valeurs x en coordonnées pixel.
yMap Mappe les valeurs y en coordonnées pixel.
canvasRect Rectangle de contenu du canevas en coordonnées du peintre
left Retourne la marge gauche
top Retourne la marge supérieure
right Retourne la marge droite
bottom Retourne la marge inférieure

Retourne

Marge

void QwtPlotAbstractBarChart::setBaseline (double value)

Définit la ligne de base. La ligne de base est l'origine du graphique. Chaque barre est dessinée à partir de la ligne de base dans la direction de la valeur de l'échantillon. Dans le cas d'une orientation() horizontale, la ligne de base est interprétée comme une valeur en x - sinon comme une valeur en y.

La valeur par défaut pour la ligne de base est 0.

Paramètres

value Valeur pour la ligne de base
