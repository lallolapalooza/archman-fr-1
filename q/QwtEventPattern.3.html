Description détaillée

Une collection de motifs d'événements.

QwtEventPattern introduit un niveau d'indirection pour les entrées souris et clavier. Celles-ci sont représentées par des noms symboliques, de sorte que le code de l'application puisse être configuré par des mappages individuels.

enum QwtEventPattern::MousePatternCode

Codes symboliques d'entrée souris. QwtEventPattern implémente 3 réglages différents pour les souris avec 1, 2 ou 3 boutons qui peuvent être activés en utilisant initMousePattern(). Le réglage par défaut est pour les souris à 3 boutons.

Des réglages individuels peuvent être configurés en utilisant setMousePattern().

Voir aussi

initMousePattern(), setMousePattern(), setKeyPattern()

Énumérateur

MouseSelect1
Le réglage par défaut pour les souris à 1, 2 et 3 boutons est :
  • Qt::LeftButton
  • Qt::LeftButton
  • Qt::LeftButton
MouseSelect2
Le réglage par défaut pour les souris à 1, 2 et 3 boutons est :
  • Qt::LeftButton + Qt::ControlModifier
  • Qt::RightButton
  • Qt::RightButton
MouseSelect3
Le réglage par défaut pour les souris à 1, 2 et 3 boutons est :
  • Qt::LeftButton + Qt::AltModifier
  • Qt::LeftButton + Qt::AltModifier
  • Qt::MidButton
MouseSelect4
Le réglage par défaut pour les souris à 1, 2 et 3 boutons est :
  • Qt::LeftButton + Qt::ShiftModifier
  • Qt::LeftButton + Qt::ShiftModifier
  • Qt::LeftButton + Qt::ShiftModifier
MouseSelect5
Le réglage par défaut pour les souris à 1, 2 et 3 boutons est :
  • Qt::LeftButton + Qt::ControlButton | Qt::ShiftModifier
  • Qt::RightButton + Qt::ShiftModifier
  • Qt::RightButton + Qt::ShiftModifier
MouseSelect6
Le réglage par défaut pour les souris à 1, 2 et 3 boutons est :
  • Qt::LeftButton + Qt::AltModifier + Qt::ShiftModifier
  • Qt::LeftButton + Qt::AltModifier | Qt::ShiftModifier
  • Qt::MidButton + Qt::ShiftModifier
