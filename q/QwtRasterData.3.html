Description Détaillée

QwtRasterData définit une interface pour tout type de données raster.

QwtRasterData est une interface abstraite, utilisée par QwtPlotRasterItem pour trouver les valeurs aux pixels de son raster.

Les espaces à l'intérieur du rectangle englobant des données peuvent être indiqués par des valeurs NaN (si WithoutGaps est désactivé).

Souvent, un élément raster est utilisé pour afficher des valeurs provenant d'une matrice. Dans ce cas, la classe dérivée de données raster doit implémenter une sorte de rééchantillonnage, qui fait correspondre le raster de la matrice au raster demandé de l'élément raster (en fonction de la résolution et des échelles du canevas).

QwtMatrixRasterData implémente des données raster, qui renvoient des valeurs d'une matrice 2D donnée.

Documentation des Énumérations de Membres

enum QwtRasterData::Attribute

Attributs des données raster. Informations supplémentaires utilisées pour améliorer le traitement des données.

Énumérateur

WithoutGaps
Le rectangle englobant des données est couvert par l'intervalle(Qt::XAxis) et l'intervalle(Qt::YAxis).

WithoutGaps indique que les données n'ont pas d'espaces (valeurs inconnues) dans cette zone et que le résultat de value() n'a pas besoin d'être vérifié pour les valeurs NaN.

L'activation de cet indicateur aura un effet positif sur les performances de rendu d'un QwtPlotSpectrogram.

Le réglage par défaut est false.

Note

Les valeurs NaN indiquent une valeur indéfinie

Description détaillée

Interface pour des données raster.

Cette classe abstraite définit l'interface pour des données qui peuvent être représentées sous forme de raster. Des exemples typiques sont des images, des données de terrain, etc.

L'intention est de séparer les algorithmes de rendu de la source des données. Les classes dérivées de QwtRasterData doivent implémenter la méthode virtuelle value().

Documentation des membres de type

enum Attribute

Ensemble d'attributs qui peuvent être spécifiés pour les données raster.

AmbientOccasionalFill
Les données pourraient avoir une valeur constante partout. Par exemple, une image avec une couleur de fond.

OverlayEnabled
Indique que les données sont destinées à être utilisées comme superposition pour un autre jeu de données.

virtual QRectF QwtRasterData::pixelHint(const QRectF &area) const

Indice de pixel. pixelHint() retourne la géométrie d'un pixel, qui peut être utilisée pour calculer la résolution et l'alignement de l'élément de tracé, qui représente les données.

La largeur et la hauteur de l'indice doivent être les distances horizontale et verticale entre 2 points voisins. Le centre de l'indice doit être la position de n'importe quel point ( peu importe lequel ).

Un indice vide indique qu'il y a des valeurs pour n'importe quel niveau de détail.

Limiter la résolution de l'image peut considérablement améliorer les performances et réduire considérablement la quantité de mémoire lors du rendu d'un QImage à partir des données raster.

L'implémentation par défaut retourne un rectangle vide recommandant de rendre à la résolution de l'appareil cible (par exemple, l'écran).

Paramètres

area Dans la plupart des implémentations, la résolution des données ne dépend pas de la zone demandée.

Retourne

Rectangle englobant d'un pixel
