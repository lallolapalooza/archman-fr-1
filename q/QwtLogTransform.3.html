Description détaillée

Transformation logarithmique.

QwtLogTransform modifie les valeurs en utilisant log() et exp().

Note

Dans les calculs de QwtScaleMap, la base de la fonction log n'a aucun effet sur le mappage. Ainsi, QwtLogTransform peut être utilisé pour log2(), log10() ou toute autre échelle logarithmique.
