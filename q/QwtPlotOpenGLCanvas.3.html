Description détaillée

Une toile alternative pour un QwtPlot dérivé de QOpenGLWidget.

Même si QwtPlotOpenGLCanvas n'est pas dérivé de QFrame, il imite son API. Lors de l'utilisation de feuilles de style, il prend en charge le modèle de boîte - en plus des arrière-plans avec des bordures arrondies.

Voir aussi

QwtPlot::setCanvas(), QwtPlotCanvas, QwtPlotCanvas::OpenGLBuffer

Note

Une autre façon d'obtenir des graphiques accélérés par matériel est d'utiliser un tampon hors écran OpenGL ( QwtPlotCanvas::OpenGLBuffer ) avec QwtPlotCanvas. Les performances sont moins bonnes que le rendu direct sur un QOpenGLWidget, mais elles s'intègrent généralement mieux dans une application de bureau.
