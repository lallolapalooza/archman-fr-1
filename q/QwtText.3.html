Description détaillée

Une classe représentant un texte.

Un QwtText est un texte incluant un ensemble d'attributs sur la manière de le rendre.

  • Format
    Un texte peut inclure des séquences de contrôle (par exemple, des balises) décrivant comment le rendre. Chaque format (par exemple, MathML, TeX, Qt Rich Text) a son propre ensemble de séquences de contrôle, qui peuvent être gérées par un QwtTextEngine spécial pour ce format.
  • Arrière-plan
    Un texte peut avoir un arrière-plan, défini par un QPen et un QBrush pour améliorer sa visibilité. Les coins de l'arrière-plan peuvent être arrondis.
  • Police
    Un texte peut avoir une police individuelle.
  • Couleur
    Un texte peut avoir une couleur individuelle.
  • Indicateurs de rendu
    Indicateurs de Qt::AlignmentFlag et Qt::TextFlag utilisés comme dans QPainter::drawText().

enum QwtText::LayoutAttribute

Attributs de disposition. Les attributs de disposition affectent certains aspects de la disposition du texte.

Énumérateur

MinimumLayout
Met en page le texte sans ses marges. Ce mode est utile si un texte doit être aligné avec précision, comme les étiquettes de graduation d'une échelle. Si QwtTextEngine::textMargins n'est pas implémenté pour le format du texte, MinimumLayout n'a aucun effet.

enum QwtText::TextFormat

Format du texte. Le format du texte définit le QwtTextEngine utilisé pour rendre le texte.

Voir aussi

QwtTextEngine, setTextEngine()

Énumérateur

AutoText
Le format du texte est déterminé en utilisant QwtTextEngine::mightRender() pour tous les moteurs de texte disponibles par ordre croissant > PlainText. Si aucun des moteurs de texte ne peut rendre le texte, il est rendu comme QwtText::PlainText.
PlainText
Dessine le texte tel quel, en utilisant un QwtPlainTextEngine.
RichText
Utilise le framework Scribe (Qt Rich Text) pour rendre le texte.
MathMLText
Utilise un moteur de rendu MathML (http://fr.wikipedia.org/wiki/MathML) pour afficher le texte. Dans les versions antérieures de Qwt, un tel moteur était inclus ; depuis Qwt 6.2, il se trouve ici : https://github.com/uwerat/qwt-mml-dev

QwtText::setTextEngine( QwtText::MathMLText, new QwtMathMLTextEngine() );

Documentation des énumérations

QwtText::TextFormat

Les formats de texte possibles.

AutoText
Le format est déterminé par la chaîne de caractères elle-même. Si la chaîne commence par un préfixe reconnu (par exemple, "<html>"), le format correspondant est utilisé, sinon le format plain est utilisé.
PlainText
Texte brut. Pas de balises spéciales ou de séquences de contrôle.
RichText
Texte formaté utilisant un sous-ensemble de HTML. Voir la classe QwtTextHtml pour plus de détails.
MathML
Texte formaté utilisant MathML. (Non implémenté).
SVG
Texte formaté utilisant SVG. (Non implémenté).
Code39
Texte formaté utilisant le code à barres Code 39. (Non implémenté).
OtherFormat
Les formats de texte peuvent être étendus en utilisant `setTextEngine`. Les formats >= QwtText::OtherFormat ne sont pas utilisés par Qwt.

void QwtText::setTextEngine (QwtText::TextFormat format, QwtTextEngine * engine) [static]

Attribuer/Remplacer un moteur de texte pour un format de texte

Avec setTextEngine, il est possible d'étendre Qwt avec d'autres types de formats de texte.

const QwtTextEngine * QwtText::textEngine (const QString & text, QwtText::TextFormat format = AutoText) [static]

Trouver le moteur de texte pour un format de texte

Dans le cas de QwtText::AutoText, le premier moteur de texte (outre QwtPlainTextEngine) est retourné, pour lequel QwtTextEngine::mightRender retourne true. S'il n'y en a pas, QwtPlainTextEngine est retourné.

Si aucun moteur de texte n'est enregistré pour le format, QwtPlainTextEngine est retourné.

Paramètres

text Texte, nécessaire dans le cas d'AutoText
format Format de texte

Retourne

Moteur de texte correspondant
