Description détaillée

Classe de base abstraite pour le rendu de chaînes de texte.

Un moteur de texte est responsable du rendu du texte pour un format de texte spécifique. Ils sont utilisés par QwtText pour rendre le texte.

void QwtTextEngine::textMargins (const QFont & font, const QString & text, double & left, double & right, double & top, double & bottom) const [pure virtual]

Retourne les marges autour du texte

Le textSize peut inclure des marges autour du texte, comme QFontMetrics::descent(). Dans les situations où les textes doivent être alignés en détail, connaître ces marges peut améliorer les calculs d'alignement.

Paramètres

font Police du texte
text Texte à rendre
left Valeur retournée pour la marge gauche
right Valeur retournée pour la marge droite
top Valeur retournée pour la marge supérieure
bottom Valeur retournée pour la marge inférieure
