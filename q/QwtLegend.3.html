DESCRIPTION DETAILLEE

Le widget légende.

Le widget QwtLegend est un arrangement tabulaire d'éléments de légende. Les éléments de légende peuvent être de n'importe quel type de widget, mais en général, ce sera un QwtLegendLabel.

Detailed Description

The QwtLegend class is a legend widget that displays items for different plot items.

The legend consists of a container widget, which can be a scrolling viewport or any other QWidget. The legend items are added to this container widget.

The items are not managed directly by QwtLegend. Instead the plot assigns its items to the legend using the insertLegend() function in QwtPlot. The legend will then notify the plot when the user interacts with an item. The plot can then update the legend by calling updateLegend().

A QwtLegend can be equipped with scrollbars. In this case the contentsWidget() is a QwtScrollDataView which manages the scrolling. The default implementation uses the widget set by setContentsWidget().
