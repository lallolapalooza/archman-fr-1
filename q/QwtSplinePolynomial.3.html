Description détaillée

Un polynôme cubique sans terme constant.

QwtSplinePolynomial est un polynôme de degré 3 de la forme : y = c3 * x³ + c2 * x² + c1 * x;

QwtSplinePolynomial est généralement utilisé en combinaison avec l'interpolation de polygones, où il n'est pas nécessaire de stocker un terme constant ( c0 ), car la translation est connue à partir des points du polygone correspondant.

NAME

QwtSplinePolynomial - Polynomial spline class

SYNOPSIS

#include <qwt_spline_polynomial.h>

class QwtSplinePolynomial : public QwtSpline { ... };

Detailed Description

A polynomial spline is defined by a set of control points.

The spline itself is composed of polynomial segments, where each segment is defined by its start and end points and the corresponding tangents. A polynomial segment is an approximation of the spline between two control points.

SYNTAXE

Description détaillée

Une spline polynomiale est définie par un ensemble de points de contrôle.

La spline elle-même est composée de segments polynomiaux, où chaque segment est défini par ses points de départ et d'arrivée et les tangentes correspondantes. Un segment polynomial est une approximation de la spline entre deux points de contrôle.
