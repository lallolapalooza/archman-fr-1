Description détaillée

Une spline avec continuité C1.

QwtSplineLocal offre plusieurs algorithmes standards pour interpoler une courbe avec des polynômes ayant une continuité C1 aux points de contrôle. Tous les algorithmes sont locaux dans le sens où le changement d'un point de contrôle n'affecte que quelques polynômes.

Documentation des énumérations de membres

Énumérateur QwtSplineLocal::Type

Type d'interpolation de spline. Tous les types d'interpolation de spline sont des algorithmes légers qui calculent les pentes à un point en regardant 1 ou 2 points avant et arrière.

Énumérateur

Cardinal
Une spline cardinale

L'interpolation de spline cardinale est un calcul très économique avec une localité de 1.

ParabolicBlending
L'interpolation par mélange parabolique est un calcul économique avec une localité de 1. Il est parfois également appelé interpolation de Bessel de troisième degré.
Akima
L'algorithme de H.Akima est un calcul avec une localité de 2.
PChip
L'interpolation par polynômes de Hermite quadratiques (PCHIP) est un algorithme populaire car il est proposé par MATLAB.

Il préserve la forme des données et respecte la monotonicité. Il a une localité de 1.

uint QwtSplineLocal::locality () const [override], [virtual]

La localité d'une interpolation de spline identifie combien de polynômes adjacents sont affectés lorsque la position d'un point est modifiée.

Les algorithmes cardinal, mélange parabolique et PChip ont une localité de 1, tandis que l'interpolation Akima a une localité de 2.

Retourne

1 ou 2.
