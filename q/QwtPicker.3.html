Description Détaillée

QwtPicker permet des sélections sur un widget.

QwtPicker filtre tous les événements d'entrée, de sortie, de souris et de clavier d'un widget et les traduit en un tableau de points sélectionnés.

La manière dont les points sont collectés dépend du type de machine d'état connectée au sélecteur. Qwt propose plusieurs machines d'état prédéfinies pour la sélection :

  • Rien
    QwtPickerTrackerMachine
  • Points uniques
    QwtPickerClickPointMachine, QwtPickerDragPointMachine
  • Rectangles
    QwtPickerClickRectMachine, QwtPickerDragRectMachine
  • Polygones
    QwtPickerPolygonMachine

Bien que ces machines d'état couvrent les manières les plus courantes de collecter des points, il est également possible d'implémenter des machines individuelles.

QwtPicker traduit les points sélectionnés en une sélection en utilisant la méthode adjustedPoints(). adjustedPoints() est destiné à être redéfini pour ajuster la sélection conformément aux exigences spécifiques de l'application (par exemple, lorsqu'une application n'accepte que des rectangles avec un rapport d'aspect fixe).

Optionnellement, QwtPicker prend en charge le processus de collecte de points par une bande élastique et un traqueur affichant un texte pour la position actuelle de la souris.

Exemple

#include <qwt_picker.h>
#include <qwt_picker_machine.h>
   QwtPicker *picker = new QwtPicker(widget);
   picker->setStateMachine(new QwtPickerDragRectMachine);
   picker->setTrackerMode(QwtPicker::ActiveOnly);
   picker->setRubberBand(QwtPicker::RectRubberBand);

La machine d'état déclenche les commandes suivantes :

  • begin()
    Active/Initialise la sélection.
  • append()
    Ajoute un nouveau point
  • move()
    Modifie la position du dernier point.
  • remove()
    Supprime le dernier point.
  • end()
    Termine la sélection et appelle accept pour valider les points sélectionnés.

Le sélecteur est actif (isActive()) entre begin() et end(). En état actif, la bande élastique est affichée et le traqueur est visible si trackerMode est ActiveOnly ou AlwaysOn.

Le curseur peut être déplacé à l'aide des touches fléchées. Toutes les sélections peuvent être annulées en utilisant la touche d'abandon (QwtEventPattern::KeyPatternCode).

Attention

Dans le cas de QWidget::NoFocus, la politique de focus du widget observé est définie sur QWidget::WheelFocus et le suivi de la souris sera manipulé pendant que le sélecteur est actif, ou si trackerMode() est AlwayOn.

QPolygon QwtPicker::adjustedPoints (const QPolygon & points) const [protected], [virtual]

Mappe les points pickedPoints() à une selection() et adjustedPoints() mappe les points collectés dans le parentWidget() à une selection(). L'implémentation par défaut renvoie simplement les points sans modification.

La raison pour laquelle une selection() diffère des points sélectionnés dépend des besoins de l'application. Par exemple :

  • Une sélection rectangulaire peut nécessiter un rapport d'aspect spécifique.
  • Une sélection peut n'accepter que des polygones non sécants.
  • ...

L'exemple ci-dessous concerne une sélection rectangulaire, où le premier point est le centre du rectangle sélectionné.

Exemple

QPolygon MyPicker::adjustedPoints( const QPolygon &points ) const
{
    QPolygon adjusted;
    if ( points.size() == 2 )
    {
        const int width = qAbs( points[1].x() - points[0].x() );
        const int height = qAbs( points[1].y() - points[0].y() );
        QRect rect( 0, 0, 2 * width, 2 * height );
        rect.moveCenter( points[0] );
        adjusted += rect.topLeft();
        adjusted += rect.bottomRight();
    }
    return adjusted;
}

Paramètres

points Points sélectionnés

Retourne

Points sélectionnés non modifiés
