Description détaillée

Une classe qui affiche des données raster.

Les données raster sont une grille de valeurs de pixels, qui peuvent être représentées sous forme de QImage. Elles sont utilisées pour de nombreux types d'informations comme les spectrogrammes, les cartogrammes, les cartes géographiques, etc.

Souvent, un graphique contient plusieurs types de données raster organisés en couches. (par exemple, une carte géographique avec des statistiques météorologiques). L'utilisation de setAlpha() permet d'empiler facilement les éléments raster.

QwtPlotRasterItem n'est implémenté que pour les images des formats suivants : QImage::Format_Indexed8, QImage::Format_ARGB32.

Documentation des énumérations de membre

enum QwtPlotRasterItem::CachePolicy

Politique de cache La politique par défaut est NoCache.

Énumérateur

NoCache
renderImage() est appelé à chaque fois que l'élément doit être redessiné.
PaintCache
renderImage() est appelé chaque fois que le cache d'image n'est pas valide, ou que les échelles, ou la taille du canevas ont changé.

Ce type de cache est utile pour améliorer les performances des opérations cacher/afficher ou des manipulations de la valeur alpha. Toutes les autres situations sont gérées par le buffer mémoire du canevas.

setPaintAttribute(), testPaintAttribute()

Énumérateur

PaintInDeviceResolution
Lorsque l'image est rendue selon les pixels de données ( QwtRasterData::pixelHint() ) elle peut être étendue à la résolution du périphérique de dessin avant d'être passée à QPainter. L'algorithme d'extension arrondit les bords des pixels de la même manière que les graduations des axes, ce qui est généralement meilleur que l'algorithme de mise à l'échelle implémenté dans Qt. Désactiver ce drapeau peut avoir du sens pour réduire la taille d'un document/fichier. La possibilité de faire cela pour un format de document dépend de l'implémentation du QPaintEngine spécifique.

Detailed Description

This class is an abstract base class for plot items painting raster data. Raster data is typically organized in a grid and represented by values corresponding to specific X and Y coordinates.

Examples for raster items are:

  • QwtPlotSpectrogram: Plots values from a matrix in different colors.

The core idea of QwtPlotRasterItem is to render the raster data into an image. This image can then be painted onto the plot canvas.

To specify the data to be rendered, derived classes need to implement the pure virtual function renderImage(). The rendering process itself can be optimized using a cache mechanism.

The abstract class also offers ways to control the rendering properties like transparency (alpha) and paint attributes.

QRectF QwtPlotRasterItem::pixelHint (const QRectF & area) const [virtual]

Pixel hint. The geometry of a pixel is used to calculated the resolution and alignment of the rendered image.

Width and height of the hint need to be the horizontal and vertical distances between 2 neighbored points. The center of the hint has to be the position of any point ( it doesn't matter which one ).

Limiting the resolution of the image might significantly improve the performance and heavily reduce the amount of memory when rendering a QImage from the raster data.

The default implementation returns an empty rectangle (QRectF()), meaning, that the image will be rendered in target device ( f.e screen ) resolution.

Parameters

area In most implementations the resolution of the data doesn't depend on the requested area.

Returns

Bounding rectangle of a pixel

void QwtPlotRasterItem::setAlpha (int alpha)

Set an alpha value for the raster data. Often a plot has several types of raster data organized in layers. ( f.e a geographical map, with weather statistics ). Using setAlpha() raster items can be stacked easily.

The alpha value is a value [0, 255] to control the transparency of the image. 0 represents a fully transparent color, while 255 represents a fully opaque color.

Parameters

alpha Alpha value
  • alpha >= 0
    All alpha values of the pixels returned by renderImage() will be set to alpha, beside those with an alpha value of 0 (invalid pixels).
  • alpha < 0 The alpha values returned by renderImage() are not changed.

The default alpha value is -1.
