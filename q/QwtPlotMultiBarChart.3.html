Description Détaillée

QwtPlotMultiBarChart affiche une série d'échantillons composés chacun d'un ensemble de valeurs.

Chaque valeur est affichée sous forme de barre, et les barres de chaque ensemble peuvent être organisées côte à côte ou empilées.

Chaque barre d'un ensemble est rendue avec un QwtColumnSymbol, qui est défini via setSymbol(). Les barres de différents ensembles utilisent les mêmes symboles. Des exceptions peuvent être gérées en surchargeant specialSymbol() ou drawBar().

Selon l'orientation() de la barre, les barres sont affichées horizontalement ou verticalement. Les barres couvrent l'intervalle entre la baseline() et la valeur.

Contrairement à la plupart des autres éléments de graphique, QwtPlotMultiBarChart renvoie plus d'une entrée dans la légende - une pour chaque symbole.

QwtColumnSymbol * QwtPlotMultiBarChart::specialSymbol (int sampleIndex, int valueIndex) const [protected], [virtual]

Créer un symbole pour des valeurs spéciales. En général, les symboles pour dessiner une barre sont définis par setSymbols() et sont communs à tous les ensembles. En surchargeant specialSymbol(), il est possible de créer un symbole temporaire symbol() pour dessiner une valeur spéciale.

Le symbole doit être créé avec new à chaque fois que specialSymbol() est appelée. Une fois le symbole dessiné, il sera supprimé.

Si aucun symbole n'est retourné (NULL), la valeur sera dessinée avec le symbole standard utilisé pour tous les symboles ayant le même index de valeur.

Paramètres

sampleIndex Index de l'échantillon
valueIndex Index de la valeur dans l'ensemble

Retourne

NULL, indiquant que la valeur n'est pas spéciale
