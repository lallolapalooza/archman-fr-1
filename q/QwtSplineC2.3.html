Description détaillée

Classe de base pour les interpolations de splines assurant une continuité paramétrique d'ordre 2 ( C2 ) entre les courbes adjacentes.

Toutes les interpolations avec continuité C2 sont basées sur des règles pour trouver la 2ème dérivée à certains points de contrôle.

Dans le cas des splines non paramétriques, ce sont les points de la courbe, tandis que pour les splines paramétriques, le calcul est effectué deux fois en utilisant une valeur de paramètre t.

Énumérateur

CubicRunout
La seconde dérivée à l'extrémité est liée aux secondes dérivées des 2 voisins : cv[0] := 2.0 * cv[1] - cv[2].

Note

boundaryValue() est ignoré
NotAKnot
La 3ème dérivée à l'extrémité correspond à la 3ème dérivée de ses voisins. Ou en d'autres termes : le premier/dernier segment de courbe prolonge le polynôme de son polynôme voisin

Note

boundaryValue() est ignoré

NAME

QwtSplineC2 — spline curve with C2 continuity

SYNOPSIS

#include <qwt_spline.h>

class QwtSplineC2 : public QwtSplineC1

Inherits from QwtSplineC1.

Detailed Description

This is the base class for splines with C2 continuity. C2 means that the second derivative of the spline curve is continuous.

The default implementation is a 2 pass calculation. In derived classes it might be overloaded by a one pass implementation.

Parameters

points Control points

Returns

Interpolating polynomials

Note

The x coordinates need to be increasing or decreasing

Reimplemented from QwtSplineC1.
