Description détaillée

Une classe de base abstraite pour les widgets ayant une échelle.

L'échelle d'un QwtAbstractScale est déterminée par une définition QwtScaleDiv, qui contient les limites et les graduations de l'échelle. L'échelle est dessinée à l'aide d'un objet QwtScaleDraw.

La division de l'échelle peut être attribuée explicitement - mais généralement elle est calculée à partir des limites à l'aide d'un QwtScaleEngine.

Le moteur d'échelle décide également du type de transformation de l'échelle (linéaire, logarithmique... ).

void QwtAbstractScale::setScaleStepSize (double stepSize)

Définit la taille du pas utilisée pour calculer une division d'échelle. La taille du pas est une indication pour le calcul des intervalles des graduations majeures de l'échelle. Une valeur de 0.0 est interprétée comme aucune indication.
