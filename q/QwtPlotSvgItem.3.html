Description détaillée

Un élément de graphique qui affiche des données au format Scalable Vector Graphics (SVG).

Les images SVG sont souvent utilisées pour afficher des cartes

QwtPlotSvgItem n'est qu'une petite classe enveloppe de commodité pour QwtPlotGraphicItem, qui crée un QwtGraphic à partir de données SVG.
