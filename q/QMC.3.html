QMC(3) Manuel des fonctions de bibliothèque QMC(3)

NOM

QMC - bibliothèque pour la gestion de groupes de métriques Performance Co-Pilot

SYNTAXE C++

#include <qmc.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPTION

La bibliothèque de classes Qt-based Performance Metrics Class (QMC) est une collection de classes C++ pour gérer un large ensemble de métriques de performance provenant de diverses sources. Cette bibliothèque est construite sur PMAPI(3).

DIAGNOSTICS

Les messages d'erreur sont générés à l'aide de pmprintf(3) mais ne sont pas vidés. Il incombe à l'utilisateur d'appeler pmflush(3) pour afficher les messages.

Des diagnostics supplémentaires peuvent être activés en ajoutant l'option pmc à la spécification de débogage globale, comme décrit dans pmSetDebug(3).

VOIR AUSSI

PMAPI(3), QmcContext(3), QmcDesc(3), QmcGroup(3), QmcIndom(3), QmcMetric(3), QmcSource(3), pmflush(3) et pmprintf(3).
