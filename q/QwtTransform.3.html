Description détaillée

Une transformation entre systèmes de coordonnées.

QwtTransform manipule les valeurs lors de leur mappage entre les coordonnées de l'échelle et celles du périphérique de dessin.

Une transformation se compose de 2 méthodes :

  • transform
  • invTransform

où l'une est la fonction inverse de l'autre.

Lorsque p1, p2 sont les limites des coordonnées du périphérique de dessin et s1, s2 les limites de l'échelle, QwtScaleMap utilise les calculs suivants :

  • p = p1 + ( p2 - p1 ) * ( T( s ) - T( s1 ) / ( T( s2 ) - T( s1 ) );
  • s = invT ( T( s1 ) + ( T( s2 ) - T( s1 ) ) * ( p - p1 ) / ( p2 - p1 ) );
