bool QwtPainter::isAligning (const QPainter * painter) [static]

Vérifie si le peintre utilise un moteur de peinture qui aligne les coordonnées sur des entiers. Aujourd'hui, ce sont tous les moteurs de peinture à l'exception de QPaintEngine::Pdf et QPaintEngine::SVG.

Si nous avons un moteur de peinture basé sur des entiers, il est également vérifié si le peintre possède une matrice de transformation qui tourne ou met à l'échelle.

Description détaillée

La classe QwtPainter fournit un objet peintre qui permet de dessiner divers types de graphiques à l'écran. Elle prend en charge les graphiques matriciels et vectoriels, et possède un certain nombre de fonctionnalités pour contrôler le processus de rendu.

void QwtPainter::setPolylineSplitting (bool enable) [static]

Active/désactive la division des polylignes pour le moteur de dessin matriciel. Dans certaines versions de Qt, le moteur de dessin matriciel dessine les polylignes composées de nombreux points beaucoup plus rapidement lorsqu'elles sont divisées en plus petits morceaux : par exemple, toutes les versions de Qt prises en charge supérieures ou égales à Qt 5.0 lors du dessin d'une polyligne antialiassée avec une largeur de trait supérieure ou égale à 2.

void QwtPainter::setRoundingAlignment (bool enable) [static]

Active ou non l'arrondi des coordonnées avant qu'elles ne soient dessinées sur un moteur de dessin qui arrondit à l'entier inférieur. Pour les autres moteurs de dessin (PDF, SVG), ce drapeau n'a aucun effet. QwtPainter stocke uniquement ce drapeau, l'arrondi lui-même est effectué dans le code de dessin (par exemple, les éléments du graphique).
