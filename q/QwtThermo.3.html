Description détaillée

Le widget Thermomètre.

QwtThermo est un widget qui affiche une valeur dans un intervalle. Il supporte :

  • une disposition horizontale ou verticale ;
  • une plage ;
  • une échelle ;
  • un niveau d'alarme.

Les couleurs de remplissage peuvent être calculées à partir d'une carte de couleurs optionnelle. S'il n'y a pas de carte de couleurs assignée, QwtThermo utilise les couleurs/pinceaux suivants de la palette du widget :

  • QPalette::Base Arrière-plan du tuyau
  • QPalette::ButtonText Pinceau de remplissage en dessous du niveau d'alarme
  • QPalette::Highlight Pinceau de remplissage pour les valeurs au-dessus du niveau d'alarme
  • QPalette::WindowText Pour l'axe de l'échelle
  • QPalette::Text Pour les étiquettes de l'échelle

Detailed Description

This widget is a thermometer, that visualizes a value within a given range.

The thermometer is made of a pipe, that is filled according to its current value. The filling can be done either by a solid color or by a color map.

The scale is optional and can be placed above or below the pipe (depending on the orientation).

The alarm level can be indicated by changing the fill color above the threshold.

Exclude/Include min/max values. According to the flags minValue() and maxValue() are included/excluded from the pipe. In case of an excluded value the corresponding tick is painted 1 pixel off of the pipeRect().

F.e. when a minimum of 0.0 has to be displayed as an empty pipe the minValue() needs to be excluded.
