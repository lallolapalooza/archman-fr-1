Description détaillée

QwtPanner fournit le panning d'un widget.

QwtPanner capture le contenu d'un widget, qui peut être glissé dans toutes les directions. Le décalage entre le début et la fin de la position est émis par le signal panned.

QwtPanner capture le contenu du widget dans un pixmap et déplace le pixmap, sans déclencher d'événements de redessin pour le widget. Les zones qui ne font pas partie du contenu ne sont pas peintes pendant le panning. Cela rend le panning suffisamment rapide pour les widgets où les redessins sont trop lents pour les mouvements de souris.

Pour les widgets où les redessins sont très rapides, il peut être préférable d'implémenter le panning manuellement en mappant les événements de souris à des événements de peinture.

QBitmap QwtPanner::contentsMask () const [protected], [virtual]

Calcule un masque pour le contenu du widget panned. Parfois, seule une partie du contenu d'un widget doit être panned. Par exemple, pour un widget avec un fond stylisé aux bords arrondis, seule la zone à l'intérieur des bords doit être panned.

Retourne

Un bitmap vide, indiquant qu'il n'y a pas de masque
