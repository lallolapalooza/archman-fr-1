void QwtPolarRenderer::renderDocument (QwtPolarPlot * plot, const QString & fileName, const QString & format, const QSizeF & sizeMM, int resolution = 85)

Rend un graphique dans un fichier.

Les formats supportés sont :

  • pdf
  • ps
  • svg
  • Tout type de format d'image supporté par Qt, voir QImageWriter::supportedImageFormats()

Paramètres

plot Widget graphique
fileName Chemin du fichier où le document sera stocké
format Format du document
sizeMM Taille du document en millimètres.
