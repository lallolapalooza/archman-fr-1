Description détaillée

Une classe pour dessiner des échelles.

QwtScaleDraw peut être utilisée pour dessiner des échelles linéaires ou logarithmiques. Une échelle a une position, un alignement et une longueur, qui peuvent être spécifiés. Les étiquettes peuvent être tournées et alignées aux graduations en utilisant setLabelRotation() et setLabelAlignment().

Après qu'une division d'échelle ait été spécifiée comme objet QwtScaleDiv en utilisant QwtAbstractScaleDraw::setScaleDiv(const QwtScaleDiv &s), l'échelle peut être dessinée avec le membre QwtAbstractScaleDraw::draw().

Detailed Description

This class is intended to be the base class for all scale-drawing classes. It implements the common interface and provides a default implementation for drawing the scale ticks, labels and the scale backbone.

The orientation of the scale is determined by the derived class. If the orientation is BottomScale or TopScale the scale is horizontal, otherwise it is vertical. LeftScale and RightScale are vertical (Qt::Vertical) scales.

The default alignment is BottomScale.

The length doesn't include the space needed for overlapping labels.

The default label alignment depends on the orientation of the scale:

QwtScaleDraw::TopScale: Qt::AlignHCenter | Qt::AlignTop
QwtScaleDraw::BottomScale: Qt::AlignHCenter | Qt::AlignBottom
QwtScaleDraw::LeftScale: Qt::AlignLeft | Qt::AlignVCenter
QwtScaleDraw::RightScale: Qt::AlignRight | Qt::AlignVCenter

The default label rotation is 0.

void QwtScaleDraw::setLabelAlignment (Qt::Alignment alignment)

Change the label flags. Labels are aligned to the point tick length + spacing away from the backbone.

The alignment is relative to the orientation of the label text. In case of an flags of 0 the label will be aligned depending on the orientation of the scale:

QwtScaleDraw::TopScale: Qt::AlignHCenter | Qt::AlignTop
QwtScaleDraw::BottomScale: Qt::AlignHCenter | Qt::AlignBottom
QwtScaleDraw::LeftScale: Qt::AlignLeft | Qt::AlignVCenter
QwtScaleDraw::RightScale: Qt::AlignRight | Qt::AlignVCenter
Changing the alignment is often necessary for rotated labels.

Parameters

alignment Or'd Qt::AlignmentFlags see <qnamespace.h>

See also

setLabelRotation(), labelRotation(), labelAlignment()

Warning

The various alignments might be confusing. The alignment of the label is not the alignment of the scale and is not the alignment of the flags ( QwtText::flags() ) returned from QwtAbstractScaleDraw::label().
