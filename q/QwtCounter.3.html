Description détaillée

Le widget compteur.

Un compteur possède une étiquette qui affiche un nombre et un ou deux boutons (maximum trois) de chaque côté de l'étiquette qui peuvent être utilisés pour incrémenter ou décrémenter la valeur du compteur.

La plage du compteur est définie par une valeur minimale et une valeur maximale, et une taille de pas. Lorsque la propriété de wrapping est définie, le compteur est circulaire.

Le nombre de pas par lequel un bouton incrémente ou décrémente la valeur peut être spécifié avec setIncSteps(). Le nombre de boutons peut être changé avec setNumButtons().

Exemple :

#include <qwt_counter.h>
  QwtCounter *counter = new QwtCounter(parent);
  counter->setRange(0.0, 100.0);                  // De 0.0 à 100
  counter->setSingleStep( 1.0 );                  // Taille de pas 1.0
  counter->setNumButtons(2);                      // Deux boutons par côté
  counter->setIncSteps(QwtCounter::Button1, 1);   // Bouton 1 incrémente de 1 pas
  counter->setIncSteps(QwtCounter::Button2, 20);  // Bouton 2 incrémente de 20 pas
  connect(counter, SIGNAL(valueChanged(double)), myClass, SLOT(newValue(double)));}

Detailed Description

A widget to edit numerical values.

The counter widget offers a convenient way to edit numerical values. It consists of a line edit and two step buttons. The step buttons can be used to increment or decrement the value with a certain step size.

The step buttons can be enabled or disabled individually. When both buttons are enabled, the default behaviour is to use the left button for decrementing and the right button for incrementing.

The value can be edited directly within the line edit. When the focus leaves the line edit, the entered value is parsed and the counter is updated.

The counter can operate in two modes:

ModeNormal The value is always within the range [minValue, maxValue]. When the value is incremented past maxValue, it stays at maxValue. When it is decremented past minValue, it stays at minValue.

ModeWrap When the value is incremented past maxValue, it wraps around to minValue. When it is decremented past minValue, it wraps around to maxValue.

The counter can optionally be accelerated when the step buttons are pressed. The acceleration is controlled by the system's settings.

The counter can be controlled using the mouse wheel as well. If keyboard tracking is enabled, the mouse wheel events are mapped to the counter value.

The step buttons can be configured to show arrows or plus/minus symbols.

The value is typically stored as a double. For integer values use QwtCounter(QWidget*) and setRange(int, int).
