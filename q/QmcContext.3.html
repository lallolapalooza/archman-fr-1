QMCCONTEXT(3) Manuel des fonctions de bibliothèque QMCCONTEXT(3)

NOM

QmcContext - conteneur pour un contexte PMAPI et ses métriques

SYNTAXE C++

#include <QmcContext.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPTION

Un objet QmcContext est un conteneur pour un seul PMAPI(3). L'objet maintient une liste de tous les descripteurs de métriques (QmcDesc), domaines d'instances (QmcIndom) et métriques (QmcMetric) utilisant le contexte pour minimiser la duplication de ces objets.

CONSTRUCTEURS

Un objet QmcContext doit être construit via l'interface QmcGroup::use.

RECHERCHE DE DESCRIPTEUR

Les descripteurs de métriques et de domaines d'instances sont mis en cache par l'objet QmcContext pour réduire les objets QmcDesc et QmcIndom dupliqués et les appels PMAPI(3) nécessaires pour les créer. Le mappage des noms de métriques aux pmIDs est également maintenu pour éviter les appels à pmLookupName(3).

int lookupDesc(const char *name, pmID& id);
Recherche la métrique name dans la liste des noms et définit id vers le pmID connu. Si non trouvé, utilise pmLookupName(3) pour obtenir le mappage. Si cet appel échoue, le code d'erreur PMAPI(3) sera retourné.
int lookupDesc(const char *name, uint_t& desc, uint_t& indom);
Trouve l'index desc et indom vers l'objet QmcDesc et l'objet QmcIndom pour la métrique name. Les index peuvent alors être utilisés avec QmcContext::desc et QmcContext::indom pour obtenir des références aux objets réels. Les méthodes retourneront un code d'erreur PMAPI(3) si le descripteur de métrique ou le domaine d'instance n'a pas pu être obtenu.
int lookupDesc(pmID pmid, uint_t& desc, uint_t& indom);
Trouve l'index desc et indom vers l'objet QmcDesc et l'objet QmcIndom pour la métrique pmid. Les index peuvent alors être utilisés avec QmcContext::desc et QmcContext::indom pour obtenir des références aux objets réels. Les méthodes retourneront un code d'erreur PMAPI(3) si le descripteur de métrique ou le domaine d'instance n'a pas pu être obtenu.

DIAGNOSTICS

Les messages d'erreur sont générés en utilisant pmprintf(3) mais ne sont pas vidés. Il est de la responsabilité de l'utilisateur d'appeler pmflush(3) pour afficher les messages.

Des diagnostics supplémentaires peuvent être activés en ajoutant les options pmc et/ou optfetch à la spécification de débogage globale, comme décrit dans pmSetDebug(3).

VOIR AUSSI

PMAPI(3), QMC(3), QmcDesc(3), QmcGroup(3), QmcIndom(3), QmcMetric(3), pmflush(3), pmLookupName(3) et pmprintf(3).
