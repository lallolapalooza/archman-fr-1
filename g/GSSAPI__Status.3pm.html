GSSAPI::Status(3) Documentation Perl fournie par l'utilisateur GSSAPI::Status(3)

NOM

GSSAPI::Status - méthodes pour la gestion des statuts GSSAPI

SYNTAXE

use GSSAPI;

$status = GSSAPI::Status->new(GSS_S_COMPLETE, 0);
if (GSS_ERROR($status->major)) {
  die "une mort horrible";
}
if (! $status) {                      # autre façon d'écrire ce qui précède
  die "une mort horrible";
}
$status = $some_GSSAPI->someop($args1, etc);
if ($status) {
  foreach ($status->generic_message, $status->specific_message) {
    print "Erreur GSSAPI: $_\n";
  }
  die "aidez-moi";
}

DESCRIPTION

Les objets "GSSAPI::Status" sont retournés par la plupart des autres opérations GSSAPI. Ces statuts se composent d'un code générique GSSAPI et, pour la plupart des opérations, d'un code spécifique au mécanisme. Ces codes numériques sont accessibles via les méthodes "major" et "minor". Les messages textuels standard associés au statut courant peuvent être obtenus via les méthodes "generic_message" et "specific_message". Chacune de ces méthodes retourne une liste de textes qui devraient présumément être affichés dans l'ordre.

La partie code générique d'un GSSAPI::Status est composée de trois sous-champs accessibles avec les fonctions "GSS_CALLING_ERROR", "GSS_ROUTINE_ERROR" et "GSS_SUPPLEMENTARY_INFO". Les valeurs retournées peuvent être comparées aux constantes dont les noms commencent par "GSS_S_" si votre code souhaite gérer certaines erreurs particulières. La fonction "GSS_ERROR" retourne vrai si et seulement si le code générique donné ne contient ni erreur d'appel ni erreur de routine.

Lorsqu'il est évalué dans un contexte booléen, un objet "GSSAPI::Status" sera vrai si et seulement si le code de statut majeur est "GSS_S_COMPLETE".

Lorsqu'il est évalué dans un contexte de chaîne de caractères, un objet "GSSAPI::Status" retournera les messages génériques et spécifiques joints ensemble par des sauts de ligne. Cela peut ou peut ne pas rendre l'utilisation de "die $status" utile.

BOGUES

Les objets de base sont actuellement implémentés comme une structure C "blessée" contenant les codes de statut majeur et mineur. Il devrait probablement s'agir plutôt d'un tableau ou d'une table de hachage "blessée", réduisant ainsi la quantité de code C impliqué et le rendant plus flexible.
