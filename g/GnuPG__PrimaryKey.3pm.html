NOM

GnuPG::PrimaryKey - Objets de clé primaire GnuPG

SYNTAXE

# suppose un objet GnuPG::Interface dans $gnupg
my @keys = $gnupg->get_public_keys( 'ftobin' );
# ou
my @keys = $gnupg->get_secret_keys( 'ftobin' );
# maintenant, les objets GnuPG::PrimaryKey sont dans @keys

DESCRIPTION

Les objets GnuPG::PrimaryKey sont généralement instanciés en tant qu'objets GnuPG::PublicKey ou GnuPG::SecretKey via diverses méthodes de GnuPG::Interface. Ils incarnent divers aspects d'une clé primaire GnuPG.

Ce paquet hérite des membres de données et des méthodes d'objet de GnuPG::Key, qui ne sont pas décrits ici, mais plutôt dans GnuPG::Key.

MEMBRES DE DONNÉES OBJET

user_ids
Une liste d'objets GnuPG::UserId associés à cette clé.
user_attributes
Une liste d'objets GnuPG::UserAttribute associés à cette clé.
subkeys
Une liste d'objets GnuPG::SubKey associés à cette clé.
local_id
ATTENTION : N'UTILISEZ PAS. Ceci signifiait auparavant l'identifiant local de GnuPG pour la clé, mais les versions modernes de GnuPG ne le produisent pas. Attendez-vous à ce qu'il s'agisse d'une chaîne vide ou de undef.
owner_trust
La valeur scalaire que GnuPG rapporte comme confiance du propriétaire pour cette clé. Voir le fichier DETAILS de GnuPG pour plus de détails.

VOIR AUSSI

GnuPG::Key, GnuPG::UserId, GnuPG::SubKey,
