NOM

Graphics::ColorNames::CSS - Noms de couleurs CSS et valeurs RGB équivalentes

SYNOPSIS

require Graphics::ColorNames::CSS;
$NameTable = Graphics::ColorNames::CSS->NamesRgbTable();
$RgbBlack  = $NameTable->{black};

DESCRIPTION

Ce module définit les noms de couleurs et leurs valeurs RGB associées du brouillon de travail CSS Color Module Level 3 du W3C daté du 2008-07-21.

C'est actuellement un alias pour Graphic::ColorNames::WWW. Cela pourrait changer à l'avenir. Il est recommandé d'utiliser le module WWW, qui implémentera toujours un sur-ensemble de ce module.

Voir la documentation de Graphics::ColorNames pour savoir comment utiliser ce module.

VOIR AUSSI

Graphics::ColorNames::WWW, CSS Color Module Level 3 (http://w3.org/TR/CSS3-color)
