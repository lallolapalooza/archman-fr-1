DESCRIPTIO

N

Ce module encapsule la structure de données nécessaire pour GD::Graph et compagnie. Un objet de cette classe contient une liste de valeurs X, et un certain nombre de listes de valeurs Y correspondantes. Cela n'a vraiment de sens que si les valeurs Y sont numériques, mais vous pouvez essentiellement stocker n'importe quoi. Les valeurs indéfinies ont une signification particulière pour GD::Graph, elles sont donc traitées avec soin lorsqu'elles sont

stockées.

Beaucoup des méthodes de ce module sont destinées à un usage interne par GD::Graph et le module lui-même, et ne seront probablement pas utiles pour vous. Beaucoup ne vous sembleront même pas util

es.
..

S 
use GD::Graph::Data;
use GD::Graph::bars;
my $data = GD::Graph::Data->new();
$data->read(file => '/data/sales.dat', delimiter => ',');
$data = $data->copy(wanted => [2, 4, 5]);
# Ajouter les chiffres plus récents depuis la base de données
use DBI;
# Faire les opérations DBI, comme se connecter à la base de données,
# préparer et exécuter les instructions
while (@row = $sth->fetchrow_array)
{
    $data->add_point(@row);
}
my $chart = GD::Graph::bars->new();
my $gd = $chart->plot($data)
;

ou pour des modifications rapides sur du code

existant 
# Le code existant construit un tableau comme ceci
@data = ( [qw(Jan Feb Mar)], [1, 2, 3], [5, 4, 3], [6, 3, 7] );

$data->read(arguments

)

Lit un ensemble de données depuis un fichier. Cela supprimera les données actuelles. Retourne undef en cas d'échec. Cette méthode utilise le module standard Text::ParseWords pour analyser les lignes. Si vous ne l'avez pas pour une raison quelconque, n'utilisez pas cette méthode, sinon votre programme

Format du fichier de données : Le format de fichier de données par défaut est des données séparées par des tabulations (ce qui peut être modifié avec l'argument delimiter). Les lignes de commentaire sont toutes les lignes qui commencent par un #. Dans l'exemple suivant, j'ai remplacé les tabulations littérales par <tab> pour plus de

clarté

Feb<tab>13<tab>37
# Mars est manquant
Mar<tab><tab>
Apr<tab>9<tab>
18
