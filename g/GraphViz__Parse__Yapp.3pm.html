NOM

GraphViz::Parse::Yapp - Visualiser des grammaires

SYNOPSIS

use GraphViz::Parse::Yapp;
# Passer un fichier généré via yapp -v
my $g = GraphViz::Parse::Yapp->new('Yapp.output');
print $g->as_png;

DESCRIPTION

Ce module permet de visualiser facilement les grammaires Parse::Yapp. Écrire des grammaires Parse::Yapp est déjà difficile, et les grammaires évoluent presque toujours de manière imprévue au départ. Ce module vise à visualiser une grammaire sous forme de graphe afin de rendre la structure claire et d'aider à la compréhension de la grammaire.

Les règles sont représentées comme des nœuds, avec leur nom à gauche du nœud et leurs productions à droite du nœud. Les sous-règles présentes dans les productions sont représentées par des arêtes vers les nœuds de sous-règles.

Ainsi, chaque nœud (règle) doit être connecté au graphe - sinon une règle ne fait pas partie de la grammaire.

Ceci utilise le module GraphViz pour dessiner le graphe. Merci à Damian Conway pour l'idée originale.

MÉTHODES

new

C'est le constructeur. Il prend un argument obligatoire, qui est le nom du fichier de sortie généré en exécutant "yapp -v " sur le fichier de grammaire. Par exemple, si votre fichier de grammaire Parse::Yapp s'appelle "calc.yp", vous exécuterez "yapp -v calc.yp" et passerez "calc.output" comme argument ici. Un objet GraphViz est renvoyé.

# Passer un fichier généré via yapp -v
my $graph = GraphViz::Parse::Yapp->new('Yapp.output');
print $g->as_png;

as_*

La grammaire peut être visualisée dans différents formats graphiques. Les méthodes incluent as_ps, as_hpgl, as_pcl, as_mif, as_pic, as_gd, as_gd2, as_gif, as_jpeg, as_png, as_wbmp, as_ismap, as_imap, as_vrml, as_vtx, as_mp, as_fig, as_svg. Voir la documentation de GraphViz pour plus d'informations. Les deux méthodes les plus courantes sont :

# Afficher un fichier au format PNG
print $g->as_png;
# Afficher un fichier au format PostScript
print $g->as_ps;
