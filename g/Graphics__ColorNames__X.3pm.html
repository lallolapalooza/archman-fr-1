NOM

Graphics::ColorNames::X - Noms de couleurs X-Windows et valeurs RGB équivalentes

VERSION

version v3.5.0

SYNTAXE

require Graphics::ColorNames::X;
$NameTable = Graphics::ColorNames::X->NamesRgbTable();
$RgbBlack  = $NameTable->{black};

DESCRIPTION

Ce module définit les noms de couleurs et leurs valeurs RGB associées utilisées dans X-Windows.

Il est basé sur la version 2014 du fichier rgb.txt, qui inclut les couleurs de CSS4.

VOIR AUSSI

Graphics::ColorNames

Graphics::ColorNames::CSS

rgb.txt https://cgit.freedesktop.org/xorg/app/rgb/plain/rgb.txt
