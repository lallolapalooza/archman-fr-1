Geo::IP::Record(3) Documentation Perl fournie par l'utilisateur Geo::IP::Record(3)

NOM

Geo::IP::Record - Contient des informations de ville pour GeoIP Legacy City Edition

SYNTAXE

use Geo::IP;
my $gi = Geo::IP->open("/usr/local/share/GeoIP/GeoIPCity.dat", GEOIP_STANDARD);
my $record = $gi->record_by_addr('24.24.24.24');
print $record->country_code,
  $record->country_code3,
  $record->country_name,
  $record->region,
  $record->region_name,
  $record->city,
  $record->postal_code,
  $record->latitude,
  $record->longitude,
  $record->time_zone,
  $record->area_code,
  $record->continent_code,
  $record->metro_code;

DESCRIPTION

Geo::IP::Record représente des objets contenant des informations de localisation retournées par la base de données GeoIP Legacy City. Il fonctionne avec les bases de données GeoIP Legacy City commerciales et les bases de données GeoLite Legacy City gratuites.

MÉTHODES D'OBJETS

$code = $record->country_code;
Retourne le code pays ISO 3166 de l'objet de localisation.
$code3 = $record->country_code3;
Retourne le code pays ISO 3166 à 3 lettres de l'objet de localisation.
$name = $record->country_name;
Retourne le nom du pays de l'objet de localisation.
$region = $record->region;
Retourne le code de la région de l'objet de localisation.
$region = $record->region_name;
Retourne le nom de la région de l'objet de localisation.
$city = $record->city;
Retourne la ville de l'objet de localisation.
$postal_code = $record->postal_code;
Retourne le code postal de l'objet de localisation.
$lat = $record->latitude;
Retourne la latitude approximative de la localisation associée à l'adresse IP. Cette valeur n'est pas précise et ne doit pas être utilisée pour identifier une adresse ou un foyer particulier.
$lon = $record->longitude;
Retourne la longitude approximative de la localisation associée à l'adresse IP. Cette valeur n'est pas précise et ne doit pas être utilisée pour identifier une adresse ou un foyer particulier.
$time_zone = $record->time_zone;
Retourne le fuseau horaire de l'objet de localisation.
$area_code = $record->area_code;
Retourne l'indicatif régional de l'objet de localisation (uniquement pour les localisations américaines au niveau de la ville)
$metro_code = $record->metro_code;
Retourne l'indicatif de métro de l'objet de localisation (uniquement pour les localisations américaines au niveau de la ville)
$continent_code = $record->continent_code;
Retourne le code du continent de l'objet de localisation.
Les codes de continent possibles sont AF, AS, EU, NA, OC, SA pour l'Afrique, l'Asie, l'Europe, l'Amérique du Nord, l'Océanie et l'Amérique du Sud.
