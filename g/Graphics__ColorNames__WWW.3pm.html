NOM

Graphics::ColorNames::WWW - Noms de couleur WWW et valeurs RGB équivalentes

SYNOPIS

require Graphics::ColorNames::WWW;
$NameTable = Graphics::ColorNames::WWW->NamesRgbTable();
$RgbBlack  = $NameTable->{black};

DESCRIPTION

Ce module définit les noms de couleur et leurs valeurs RGB associées issues de diverses spécifications WWW, telles que SVG ou CSS, ainsi que des implémentations courantes de navigateurs.

Consultez la documentation de Graphics::ColorNames pour savoir comment utiliser ce module.

Actuellement, SVG et CSS définissent les mêmes mots-clés de couleur et incluent tous les mots-clés de couleur pris en charge par les navigateurs web courants. Par conséquent, les modules Graphics::ColorNames::WWW, Graphics::ColorNames::SVG et Graphics::ColorNames::CSS se comportent de manière identique.

Cela pourrait changer si les spécifications venaient à diverger ; dans ce cas, ce module deviendrait un sur-ensemble de tous les mots-clés de couleur définis par les spécifications du W3C.

Il est recommandé d'utiliser ce module sauf si vous avez besoin d'une compatibilité exacte avec les spécifications CSS et SVG ou des navigateurs spécifiques.

NOTE

Il semblerait que « fuchsia » ait été mal orthographié en « fuscia » dans une spécification HTML non identifiée. Cela semble également être une faute d'orthographe courante, les deux noms sont donc reconnus.

LIMITATIONS

Le mot-clé "transparent" n'est pas pris en charge. Actuellement, Graphics::ColorNames ne permet pas les valeurs RGBA.

De plus, les mots-clés de couleur système ne sont pas assignés à une valeur RGB fixe et ne sont donc pas pris en charge :

"ActiveBorder", "ActiveCaption", "AppWorkspace", "Background", "ButtonFace", "ButtonHighlight", "ButtonShadow", "ButtonText", "CaptionText", "GrayText", "Highlight", "HighlightText", "InactiveBorder", "InactiveCaption", "InactiveCaptionText", "InfoBackground", "InfoText", "Menu", "MenuText", "Scrollbar", "ThreeDDarkShadow", "ThreeDFace", "ThreeDHighlight", "ThreeDLightShadow", "ThreeDShadow", "Window", "WindowFrame", "WindowText" (ceux-ci sont obsolètes en CSS3)

Graphics::ColorNames::HTML, Graphics::ColorNames::CSS, Graphics::ColorNames::SVG
