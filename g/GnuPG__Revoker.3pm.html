GnuPG::Revoker(3) Documentation Perl fournie par l'utilisateur GnuPG::Revoker(3)

NOM

GnuPG::Revoker - Objets révoquant les clés GnuPG

SYNTAXE

# suppose un objet GnuPG::PrimaryKey dans $key
my $revokerfpr = $key->revokers->[0]->fingerprint();

DESCRIPTION

Les objets GnuPG::Revoker ne sont généralement pas instanciés seuls, mais plutôt dans le cadre d'objets GnuPG::Key. Ils représentent une déclaration qu'une autre clé est désignée pour révoquer les certifications faites par la clé en question.

MÉTHODES OBJET

new( %arguments_initialisation )
Cette méthode crée un nouvel objet. Les arguments optionnels sont pour l'initialisation des membres de données.
is_sensitive()
Retourne 0 si les informations du révocateur peuvent être distribuées librement. Si cette valeur est non nulle, les informations doivent être traitées comme "sensibles".

Veuillez consulter http://tools.ietf.org/html/rfc4880#section-5.2.3.15 pour plus d'explications.

compare( $other, $deep )
Retourne une valeur non nulle uniquement lorsque ce révocateur désigné est identique à l'autre GnuPG::Revoker. Si $deep est présent et non nul, les signatures des révocateurs seront également comparées.

MEMBRES DONNÉES OBJET

fingerprint
Un objet GnuPG::Fingerprint indiquant l'empreinte de la clé révocatrice spécifiée. (Notez que ce n'est *pas* l'empreinte de la clé dont les signatures peuvent être révoquées par ce révocateur).
algo_num
L'identifiant numérique de l'algorithme de la clé du révocateur.
signatures
Une liste d'objets GnuPG::Signature qui lient cryptographiquement le révocateur désigné à la clé primaire. Si le matériel a été instancié en utilisant les fonctions *_with_sigs() de GnuPG::Interface, alors une désignation de révocateur valide doit avoir une signature valide associée, provenant de la clé pertinente qui fait la désignation (pas de la clé du révocateur).

Notez que les certifications de révocateur désigné sont elles-mêmes irrévocables, il n'y a donc pas de liste analogue de révocations dans un objet GnuPG::Revoker.

VOIR AUSSI

GnuPG::Interface, GnuPG::Fingerprint, GnuPG::Key, GnuPG::Signature, http://tools.ietf.org/html/rfc4880#section-5.2.3.15
