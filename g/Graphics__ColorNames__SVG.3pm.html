NOM

Graphics::ColorNames::SVG - Noms de couleurs SVG et valeurs RGB équivalentes

SYNTAXE

require Graphics::ColorNames::SVG;
$NameTable = Graphics::ColorNames::SVG->NamesRgbTable();
$RgbBlack  = $NameTable->{black};

DESCRIPTION

Ce module définit les noms de couleurs et leurs valeurs RGB associées selon la spécification SVG 1.2.

Il s'agit actuellement d'un alias pour Graphic::ColorNames::WWW. Cela pourrait changer à l'avenir. Il est recommandé d'utiliser le module WWW, qui implémentera toujours un sur-ensemble de ce module.

Voir la documentation de Graphics::ColorNames pour savoir comment utiliser ce module.

VOIR AUSSI

Graphics::ColorNames::WWW, Spécification Scalable Vector Graphics (SVG) 1.1, Section 4.2 (http://www.w3.org/TR/SVG/types.html#ColorKeywords)
