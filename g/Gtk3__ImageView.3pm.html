Gtk3::ImageView(3) Documentation Perl Contribuée par l'Utilisateur Gtk3::ImageView(3)

NOM

Gtk3::ImageView - Widget de visualisation d'images pour Gtk3

VERSION

9

SYNOPSIS

use Gtk3::ImageView;
Gtk3->init;
$window = Gtk3::Window->new();
$view = Gtk3::ImageView->new;
$view->set_pixbuf($pixbuf, TRUE);
$window->add($view);
$window->show_all;

DESCRIPTION

Le widget Gtk3::ImageView permet à l'utilisateur de zoomer, de déplacer et de sélectionner l'image spécifiée, et fournit des points d'accroche pour permettre la création et l'utilisation d'outils supplémentaires, par exemple un outil de dessin.

Gtk3::ImageView est un portage Gtk3 de Gtk2::ImageView.

Pour discuter de Gtk3::ImageView ou de gtk3-perl, poser des questions et exprimer vos éloges/critiques aux auteurs, rejoignez la liste gtk-perl-list@gnome.org sur lists.gnome.org.

SOUS-ROUTINES/MÉTHODES

$view->set_pixbuf( $pixbuf, $zoom_to_fit )

Définit l'image à visualiser. Le paramètre optionnel zoom_to_fit spécifie si l'image doit être zoomée pour s'adapter ou non.

$view->get_pixbuf

Retourne l'image actuellement visualisée.

$view->get_pixbuf_size

Retourne une table de hachage contenant la taille de l'image actuelle avec les clés width et height.

$view->set_zoom($zoom)

Spécifie le niveau de zoom.

$view->get_zoom

Retourne le niveau de zoom actuel.

$view->set_zoom_to_fit($zoom_to_fit, $limit)

Spécifie si le zoom doit s'adapter ou non. Si limit est défini, un tel zoom automatique n'ira pas au-delà de cette limite. Si la limite est indéfinie, la limite précédemment définie est utilisée, initialement, elle est illimitée.

$view->zoom_to_box( $box, $additional_factor )

Spécifie une boîte à zoomer, incluant un facteur de zoom additionnel.

$view->zoom_to_selection($context_factor)

Zoome sur la sélection actuelle, plus un facteur de zoom additionnel. Raccourci pour

$view->zoom_to_box( $view->get_selection, $context_factor );

$view->get_zoom_to_fit

Retourne si la vue est actuellement en mode zoom pour s'adapter ou non.

$view->zoom_in

Augmente le zoom actuel par le facteur "zoom-step" (par défaut 2).

$view->zoom_out

Diminue le zoom actuel par le facteur "zoom-step" (par défaut 2).

$view->zoom_to_fit

Raccourci pour

$view->set_zoom_to_fit(TRUE);

$view->set_fitting( $value )

Raccourci pour

$view->set_zoom_to_fit($value, 1);

ce qui signifie qu'une petite image ne sera pas étirée pour remplir une grande fenêtre. Fourni (malgré le nom ambigu) pour la compatibilité avec Gtk2::ImageView.

$view->set_offset( $x, $y )

Définit le décalage de vue actuel (c'est-à-dire la position du déplacement).

$view->set_offset

Retourne le décalage de vue actuel (c'est-à-dire la position du déplacement).

$view->get_viewport

Retourne une table de hachage contenant la position et la taille du viewport actuel.

$view->set_tool

Définit l'outil actuel (c'est-à-dire le mode) - un objet d'une sous-classe de "Gtk3::ImageView::Tool".

Voici quelques sous-classes connues de celle-ci :

  • "Gtk3::ImageView::Tool::Dragger" permet de déplacer l'image lorsqu'elle est zoomée.
  • "Gtk3::ImageView::Tool::Selector" permet à l'utilisateur de sélectionner une zone rectangulaire de l'image.
  • "Gtk3::ImageView::Tool::SelectorDragger" sélectionne ou déplace avec différents boutons de souris.

Ne vous fiez pas trop à la manière dont l'outil interagit actuellement avec ImageView.

$view->get_tool

Retourne l'outil actuel (c'est-à-dire le mode).

$view->set_selection($selection)

Définit la sélection actuelle comme une table de hachage de position et de taille.

$view->get_selection

Retourne la sélection actuelle comme une table de hachage de position et de taille.

$view->set_resolution_ratio($ratio)

Définit le rapport des résolutions dans les directions x et y, permettant d'afficher correctement les images avec des pixels non carrés.

$view->get_resolution_ratio

Retourne le rapport de résolution actuel.

$view->set_interpolation

La méthode d'interpolation à utiliser, issue du type "cairo_filter_t" de https://www.cairographics.org/manual/cairo-cairo-pattern-t.html#cairo-filter-t. Les valeurs possibles sont des chaînes en minuscules comme "nearest". Pour utiliser une interpolation différente en fonction du zoom, définissez-la dans le signal "zoom-changed".

$view->get_interpolation

Retourne la méthode d'interpolation actuelle.

INCOMPATIBILITÉS

Portage depuis Gtk2::ImageView

  • set_from_pixbuf() a été renommée en set_pixbuf() et son deuxième argument signifie maintenant zoom_to_fit() au lieu de set_fitting().
  • set_fitting(TRUE) était le comportement par défaut, maintenant vous devez l'appeler explicitement si vous souhaitez ce comportement. Cependant, une fois qu'il est appelé, les nouveaux appels à set_from_pixbuf() ne réinitialiseront pas

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

pour plus de détails, voir set_zoom_to_fit() ..
  • Le glisser-déposer peut maintenant être déclenché en s'abonnant au "dnd-start" signal, et en appelant "$view->drag_begin_with_coordinates()" depuis le gestionnaire. drag_source_set() ne fonctionnera pas.
  • "Gtk2::ImageView::ScrollWin" le remplacement n'est pas encore implémenté.
  • set_transp() est maintenant disponible via CSS https://developer.gnome.org/gtk3/stable/chap-css-overview.html à la place, par exemple via 
    .imageview.transparent {
    background-image: url('checkers.svg');
}
  • set_interpolation() accepte maintenant "cairo_filter_t" https://www.cairographics.org/manual/cairo-cairo-pattern-t.html#cairo-filter-t au lieu de "GdkInterpType" https://developer.gnome.org/gdk-pixbuf/stable/gdk-pixbuf-Scaling.html#GdkInterpType.
