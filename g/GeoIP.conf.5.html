NOM

GeoIP.conf - Fichier de configuration pour geoipupdate

SYNTAXE

Ce fichier vous permet de configurer votre programme geoipupdate pour télécharger les bases de données GeoIP2 et GeoLite2.

DESCRIPTION

Le fichier se compose d'un réglage par ligne. Les lignes commençant par # sont des commentaires et ne seront pas traitées. Tous les mots-clés de réglage sont sensibles à la casse.

Paramètres requis :

AccountID
Votre identifiant de compte MaxMind. Anciennement connu sous le nom de UserId. Peut être remplacé à l'exécution par les variables d'environnement GEOIPUPDATE_ACCOUNT_ID ou GEOIPUPDATE_ACCOUNT_ID_FILE.
LicenseKey
Votre clé de licence MaxMind sensible à la casse. Peut être remplacé à l'exécution par les variables d'environnement GEOIPUPDATE_LICENSE_KEY ou GEOIPUPDATE_LICENSE_KEY_FILE.
EditionIDs
Liste des identifiants d'édition de base de données séparés par des espaces. Les identifiants d'édition peuvent contenir des lettres, des chiffres et des tirets. Par exemple, GeoIP2-City téléchargera la base de données GeoIP2 City (GeoIP2-City). Peut être remplacé à l'exécution par la variable d'environnement GEOIPUPDATE_EDITION_IDS. Note : anciennement appelé ProductIds.

Paramètres optionnels :

DatabaseDirectory
Le répertoire où stocker les fichiers de base de données. S'il n'est pas défini, le défaut est /var/lib/GeoIP. Peut être remplacé à l'exécution par la variable d'environnement GEOIPUPDATE_DB_DIR ou l'argument de ligne de commande -d.
Host
Le nom d'hôte du serveur à utiliser. Le défaut est https://updates.maxmind.com. Peut être remplacé à l'exécution par la variable d'environnement GEOIPUPDATE_HOST.
Proxy
Le nom d'hôte ou l'adresse IP du proxy. Vous pouvez éventuellement spécifier un numéro de port, par exemple, 127.0.0.1:8888. Si aucun numéro de port n'est spécifié, 1080 sera utilisé. Peut être remplacé à l'exécution par la variable d'environnement GEOIPUPDATE_PROXY.
ProxyUserPassword
Le nom d'utilisateur et le mot de passe du proxy, séparés par deux-points. Par exemple, utilisateur:motdepasse. Peut être remplacé à l'exécution par la variable d'environnement GEOIPUPDATE_PROXY_USER_PASSWORD.
PreserveFileTimes
Indique s'il faut conserver les heures de modification des fichiers téléchargés depuis le serveur. Cette option est soit 0 soit 1. Le défaut est 0. Peut être remplacé à l'exécution par la variable d'environnement GEOIPUPDATE_PRESERVE_FILE_TIMES.
LockFile
Le fichier de verrouillage à utiliser. Cela garantit qu'un seul processus geoipupdate peut s'exécuter à la fois. Note : une fois créé, ce fichier de verrouillage n'est pas supprimé du système de fichiers. Le défaut est .geoipupdate.lock sous le DatabaseDirectory. Peut être remplacé à l'exécution par la variable d'environnement GEOIPUPDATE_LOCK_FILE.
RetryFor
La durée pendant laquelle réessayer en cas d'erreurs lors des transactions HTTP. Peut être spécifié comme un nombre décimal (éventuellement fractionnaire) suivi d'un suffixe d'unité. Les unités de temps valides sont ns, us (ou µs), ms, s, m, h. Le défaut est 5m (5 minutes). Peut être remplacé à l'exécution par la variable d'environnement GEOIPUPDATE_RETRY_FOR.
Parallelism
Le nombre maximum de téléchargements de bases de données parallèles. Le défaut est 1, ce qui signifie que les bases de données seront téléchargées séquentiellement. Peut être remplacé à l'exécution par la variable d'environnement GEOIPUPDATE_PARALLELISM ou l'argument de ligne de commande --parallelism.

Paramètres obsolètes :

Les suivants sont obsolètes et seront ignorés s'ils sont présents :

Protocol

SkipPeerVerification

SkipHostnameVerification
