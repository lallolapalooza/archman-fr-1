Glib::BookmarkFile - Analyseur de fichiers de favoris

SYNTAXE

use Glib;
$date .= $_ while (<DATA>);

      $desc  = $b->get_description($uri);
      print "Favori pour `$uri' ($title):\n";

DESCRIPTION

Glib::BookmarkFile vous permet d'analyser, d'éditer ou de créer des fichiers contenant des listes de favoris vers des ressources pointées par des URI, avec des métadonnées associées, en suivant la spécification des favoris de bureau (Desktop Bookmark Specification). La prise en charge des fichiers récents dans GTK+ utilise ce type de fichiers pour stocker la liste des fichiers récemment utilisés.

La syntaxe des fichiers de favoris est décrite en détail dans la spécification des favoris de bureau (Desktop Bookmarks Specification). Voici un résumé rapide : les fichiers de favoris utilisent une sous-classe du format de document XML Bookmark Exchange Language (XBEL), définissant des métadonnées telles que le type MIME de la ressource pointée par un favori, la liste des applications qui ont enregistré le même URI et la visibilité du favori.

MÉTHODES

bookmarkfile = Glib::BookmarkFile->new

$bookmark_file->add_application ($uri, $name, $exec)

  • $uri (chaîne)
  • $name (chaîne ou undef)
  • $exec (chaîne ou undef)

Ajoute l'application avec $name et $exec à la liste des applications qui ont enregistré un favori pour $uri dans $bookmark_file.

Chaque favori à l'intérieur d'un "Glib::BookmarkFile" doit avoir au moins une application enregistrée. Chaque application doit fournir un nom, une ligne de commande utile pour lancer le favori, le nombre de fois où le favori a été enregistré par l'application et la dernière fois que l'application a enregistré ce favori.

Si $name est undef, le nom de l'application sera le même que celui renvoyé par Glib::get_application_name() ; si $exec est undef, la ligne de commande sera une composition du nom du programme tel que renvoyé par Glib::get_prgname() et du modificateur "%u", qui sera développé en URI du favori.

Cette fonction s'occupera automatiquement de mettre à jour le compteur d'enregistrements et l'horodatage au cas où une application avec le même $name aurait déjà enregistré un favori pour $uri dans le fichier de favoris. Si aucun favori pour $uri n'est trouvé, un est créé.

$bookmark_file->add_group ($uri, $group)

  • $uri (chaîne)
  • $group (chaîne)

Ajoute $group à la liste des groupes auxquels appartient le favori pour $uri. Si aucun favori pour $uri n'est trouvé, un est créé.

($exec, $count, $stamp) = $bookmark_file->get_app_info ($uri, $name)

  • $uri (chaîne)
  • $name (chaîne)

Récupère les informations d'enregistrement de $name pour le favori $uri. Voir Glib::BookmarkFile::set_app_info() pour plus d'informations sur les données renvoyées.

Peut échouer avec une Glib::Error dans $@ en cas d'échec.

$bookmark_file->set_app_info ($uri, $name, $exec, $count, $stamp)

  • $uri (chaîne)
  • $name (chaîne)
  • $exec (chaîne)
  • $count (entier)
  • $stamp (horodatage unix)

Définit les métadonnées de l'application $name dans la liste des applications qui ont enregistré un favori pour $uri dans $bookmark_file.

Vous devriez rarement utiliser cette méthode ; utilisez plutôt Glib::BookmarkFile::add_application() et Glib::BookmarkFile::remove_application().

$name peut être n'importe quelle chaîne encodée en UTF-8 utilisée pour identifier une application. $exec peut contenir l'un des deux modificateurs suivants : "%f", qui sera développé comme le nom de fichier local récupéré de l'URI du favori ; "%u", qui sera développé comme l'URI du favori. Le développement est effectué automatiquement lors de la récupération de la ligne de commande stockée à l'aide de la méthode Glib::BookmarkFile::get_app_info(). $count est le nombre de fois où l'application a enregistré le favori ; s'il est inférieur à 0, le nombre d'enregistrements actuel sera augmenté de un, s'il est égal à 0, l'application portant le nom $name sera supprimée de la liste des applications enregistrées. $stamp est l'heure Unix du dernier enregistrement, telle que renvoyée par time() ; s'il est égal à -1, l'heure actuelle sera utilisée.

Si vous essayez de supprimer une application en définissant son compteur d'enregistrement à zéro, et qu'aucun favori pour $uri n'est trouvé, %FALSE est renvoyé et une exception est déclenchée.

Peut échouer avec une Glib::Error dans $@ en cas d'échec.
