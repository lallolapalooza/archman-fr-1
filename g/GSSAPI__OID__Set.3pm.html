Paquet: perl-gssapi

Licences: GPL, PerlArtistic

GSSAPI::OID::Set(3) Documentation Perl fournie par l'utilisateur GSSAPI::OID::Set(3)

NOM

GSSAPI::OID::Set - méthodes pour gérer des ensembles d'OID GSSAPI, et quelques ensembles d'OID constants.

SYNTAXE

use GSSAPI;
$oidset = GSSAPI::OID::Set->new;
$status = $oidset->insert($oid);
$status = $oidset->contains($oid, $isthere);
if ($status && $isthere) {
  # bla bla bla
}

DESCRIPTION

Les objets "GSSAPI::OID::Set" sont des ensembles simples d'OID GSSAPI (évidemment).

BOGUES

Il n'y a aucun moyen de lister les OID dans un ensemble ; vous ne pouvez que vérifier si un OID particulier est présent. C'est réellement un bug dans l'API C, donc toute correction serait spécifique à l'implémentation.
