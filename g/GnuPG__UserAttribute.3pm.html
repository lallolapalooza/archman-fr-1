GnuPG::UserAttribute(3) Documentation Perl fournie par l'utilisateur GnuPG::UserAttribute(3)

NOM

GnuPG::UserAttribute - Objets d'attributs utilisateur GnuPG

SYNOPSIS

# suppose un objet GnuPG::PublicKey dans $publickey
my $jpgs_size = $publickey->user_attributes->[0]->subpacket_total_size();

DESCRIPTION

Les objets GnuPG::UserAttribute ne sont généralement pas instanciés seuls, mais plutôt dans le cadre d'objets GnuPG::PublicKey ou GnuPG::SecretKey.

MÉTHODES OBJET

new( %initialization_args )
Cette méthode crée un nouvel objet. Les arguments optionnels sont l'initialisation des membres de données ;

MEMBRES DE DONNÉES OBJET

validité
Un scalaire contenant la valeur que GnuPG rapporte pour la validité calculée de la liaison entre ce paquet d'attributs utilisateur et sa clé primaire associée. Voir le fichier DETAILS de GnuPG pour plus de détails.
nombre_sous_paquets
Un scalaire contenant le nombre de sous-paquets d'attributs. C'est généralement 1, car la plupart des UAT rencontrés contiennent une seule image au format JPEG.
taille_totale_sous_paquets
Un scalaire contenant le nombre total d'octets de tous les sous-paquets d'attributs.
signatures
Une liste d'objets GnuPG::Signature incarnant les signatures sur cet attribut utilisateur.
révocations
Une liste de révocations associées à cet attribut utilisateur, stockées sous forme d'objets GnuPG::Signature (car les révocations sont aussi un type de certification).

BOGUES

Aucune information utile sur les attributs intégrés n'est fournie pour le moment. Il serait agréable de pouvoir accéder aux données JPEG brutes.

VOIR AUSSI

GnuPG::Signature,
