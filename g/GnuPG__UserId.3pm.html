NOM

GnuPG::UserId - Objets User ID GnuPG

SYNOPSIS

# suppose un objet GnuPG::PublicKey dans $publickey
my $user_id = $publickey->user_ids_ref->[0]->as_string;

DESCRIPTION

Les objets GnuPG::UserId ne sont généralement pas instanciés seuls, mais plutôt dans le cadre d'objets GnuPG::PublicKey ou GnuPG::SecretKey.

MÉTHODES OBJET

new( %args_initialisation )
Cette méthode crée un nouvel objet. Les arguments optionnels sont pour l'initialisation des membres de données ;
compare( $autre, $profond )
Retourne non nul seulement lorsque cet User ID est identique à l'autre GnuPG::UserID. Si $profond est présent et non nul, les signatures et révocations de l'User ID seront également comparées.

MEMBRES DONNÉES OBJET

as_string
Une chaîne représentant l'identifiant utilisateur.
validity
Une scalaire contenant la valeur rapportée par GnuPG pour la confiance en l'authenticité (également appelée) validité d'une clé. Voir le fichier DETAILS de GnuPG pour les détails.
signatures
Une liste d'objets GnuPG::Signature représentant les signatures sur cet identifiant utilisateur.
revocations
Une liste de révocations associées à cet User ID, stockées sous forme d'objets GnuPG::Signature (car les révocations sont aussi un type de certification).
