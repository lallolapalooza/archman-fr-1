GSSAPI::OID(3) Documentation Perl contribuée par l'utilisateur GSSAPI::OID(3)

NOM

GSSAPI::OID - méthodes pour manipuler les OID GSSAPI et quelques OID constants

SYNOP.

use GSSAPI;
#$oid = GSSAPI::OID->new;             # rarement nécessaire ou souhaité
$status = GSSAPI::OID->from_str($oid, "{ 1 2 840 113554 1 2 1 1 }");
#
# pris en charge uniquement sur MIT Kerberos
#
$status = $oid->to_str($str);
#
# pris en charge uniquement sur MIT Kerberos
#
$status = $oid->inquire_names($oidset);
# OID constants fournis :
$oid = gss_nt_user_name;
$oid = gss_nt_machine_uid_name;
$oid = gss_nt_string_uid_name;
$oid = gss_nt_service_name;
$oid = gss_nt_exported_name;
$oid = gss_nt_service_name_v2;
$oid = gss_nt_krb5_name;
$oid = gss_nt_krb5_principal;
$oid = gss_mech_krb5;
$oid = gss_mech_krb5_old;
$oid = gss_mech_krb5_v2;
$oid = gss_mech_spnego;
# si votre implémentation GSSAPI prend en charge
# SPNEGO (Heimdal 0.7 par exemple
# vous pouvez utiliser l'OID de type de mécanisme GSSAPI::OID::gss_mech_spnego.
#
# use GSSAPI::indicate_mechs( $oidset );
# pour obtenir l'ensemble des types de mécanismes pris en charge par votre implémentation
$oid = gss_nt_hostbased_service; # GSS_C_NT_HOSTBASED_SERVICE

DESCRIPTION

"GSSAPI::OID" Les objets sont utilisés comme identifiants/constantes uniques pour les 'mécanismes' -- le protocole et la version particuliers utilisés -- et pour les encodages utilisés pour représenter les noms. Dans de nombreux cas, vous pouvez demander le mécanisme ou l'encodage par défaut pour l'implémentation en utilisant GSS_C_NO_OID. Consultez la description de la routine dans la RFC2743 si vous n'êtes pas sûr.
