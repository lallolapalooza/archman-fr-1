Graphics::Toolkit::Color::Values(3) Documentation Perl contribuée par les utilisateurs Graphics::Toolkit::Color::Values(3)

NOM

Graphics::Toolkit::Color::Value - méthodes de haut niveau liées à une seule couleur

SYNOPSIS

Objet en lecture seule qui contient les valeurs d'une couleur. Il fournit des méthodes pour récupérer les valeurs dans différents formats, pour mesurer la différence avec d'autres couleurs ou pour créer des objets de valeurs de couleurs apparentées.

use Graphics::Toolkit::Color::Value;
my $blue = Graphics::Toolkit::Color::Value->new( 'hsl(220,50,60)' );
my @rgb = $blue->get();
my $purple = $blue->set({red => 220});

DESCRIPTION

L'objet contient les valeurs normalisées de la définition de couleur originale (argument du getter) et le triplet RGB normalisé, si la couleur n'a pas été définie en valeurs RGB. De cette façon, nous évitons autant que possible les erreurs de conversion et d'arrondi.

Ce paquet est une couche de médiation entre Graphics::Toolkit::Color::Space::Hub en dessous, où il s'agit juste de calcul numérique sur des vecteurs de valeurs, et l'API utilisateur au-dessus dans Graphics::Toolkit::Color, où il s'agit principalement de produire des ensembles de couleurs et de gérer les arguments. Ce module n'est pas destiné à être utilisé comme API publique car il offre beaucoup moins de confort que Graphics::Toolkit::Color.

MÉTHODES

new

Le constructeur ne prend qu'un seul argument obligatoire, un scalaire qui définit complètement et numériquement une couleur. À l'intérieur des définitions de couleur, les noms d'espaces de couleur sont insensibles à la casse. Quelques formats possibles sont

[ 1, 2, 3 ]                  # Triplet RGB
[ HSL => 220, 100, 3 ]       # Vecteur HSL nommé
{ h => 220, s =>100, l => 3} # Hash de caractères
{ cyan => 1, magenta => 0.5, yellow => 0} # Hash
'hwb: 20, 60, 30'            # Chaîne
'hwb(20,60,30)'              # css_string
'#2211FF'                    # Chaîne hexadécimale RGB

get

Méthode getter universelle - presque la fonction inverse de new : elle peut retourner les valeurs de la couleur dans tous les espaces de couleur pris en charge (premier argument) (voir : "COLOR-SPACES" dans Graphics::Toolkit::Color::Space::Hub) et dans tous les formats mentionnés ci-dessus (deuxième argument). De plus, un troisième argument peut convertir les valeurs numériques dans différentes plages. L'espace de noms par défaut est RGB, le format par défaut est une liste et chaque espace de couleur a sa plage par défaut.

my @rgb = $val_object->get();
my @cmyk = $val_object->get('CMYK', 'list', 255);
my $YIQ = $val_object->get('YIQ', 'string');

set

Construit un nouvel objet "Graphics::Toolkit::Color::Value" en changeant absolument certaines valeurs de l'objet actuel tout en en conservant d'autres. (add change certaines valeurs relativement.) L'unique argument obligatoire est une HASH référence dont les clés correspondent à un seul des espaces de couleur pris en charge (voir : "COLOR-SPACES" dans Graphics::Toolkit::Color::Space::Hub). Les valeurs en dehors des limites définies seront limitées à une valeur acceptable (ou tournées dans le cas de dimensions circulaires).

my $more_blend_color = $val_object->set( {saturation => 40} );
my $bright_color = $val_object->set( {saturation => 2240} ); #la saturation sera de 100

add

Cette méthode prend également une référence HASH en entrée et produit aussi un objet couleur apparenté comme la méthode setprécédente. La seule différence est : les valeurs du hash seront ajoutées aux valeurs actuelles. Si elles sortent des limites définies, elles seront limitées (ou tournées dans le cas de dimensions circulaires).

my $darker_color = $val_object->set( {lightness => -10} );

blend

Crée un objet de valeur de couleur en mélangeant deux couleurs. Le premier et unique argument obligatoire est le deuxième objet de valeur de couleur. Le deuxième argument est le ratio de mélange. Zéro donnerait la couleur originale et un la deuxième couleur. La valeur par défaut est 0.5 (mélange 1:1). Des valeurs en dehors de la plage 0..1 sont possibles et les valeurs seront limitées si elles dépassent les limites définies de l'espace de couleur requis.

Le troisième argument facultatif est le nom de l'espace de couleur dans lequel le mélange sera calculé - il vaut par défaut 'HSL'.

my $green = Graphics::Toolkit::Color::Values->new( '#00ff00' );
my $cyan = $blue->blend( $green, 0.6, 'YIQ' );

distance

Calcule un nombre réel qui désigne la distance (euclidienne) entre deux points dans un espace de couleur (alias couleurs).

Le premier et unique argument obligatoire est la deuxième couleur sous forme d'objet Graphics::Toolkit::Color::Value . Le deuxième argument facultatif est le nom de l'espace de couleur dans lequel la distance est calculée (par défaut 'HSL'). Le troisième argument est la métrique, qui actuellement est simplement le sous-ensemble de dimensions dans l'espace choisi qui doit être observé. On peut aussi mentionner le nom raccourci d'une dimension plusieurs fois pour augmenter son poids dans le calcul. Le quatrième argument facultatif sont les plages numériques des dimensions. Si aucune n'est donnée, la méthode utilise uniquement des valeurs normalisées (plage : 0..1).

my $blue = Graphics::Toolkit::Color::Values->new( '#0000ff' );
my $green = Graphics::Toolkit::Color::Values->new( '#00ff00' );
my $d = $blue->distance( $green, 'HSV', 's', 255); # 0 : les deux ont la même saturation
