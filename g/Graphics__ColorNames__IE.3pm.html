NOM

Graphics::ColorNames::IE - Noms de couleur de MS Internet Explorer et valeurs RGB équivalentes

SYNOPIS

require Graphics::ColorNames::IE;
$NameTable = Graphics::ColorNames::IE->NamesRgbTable();
$RgbBlack  = $NameTable->{black};

DESCRIPTION

Ce module définit les noms de couleur et leurs valeurs RVB associées reconnus par Microsoft Internet Explorer.

Il s'agit actuellement d'un sous-ensemble des couleurs définies par les spécifications CSS et SVG.

Voir la documentation de Graphics::ColorNames pour savoir comment utiliser ce module.

NOTE

Bien que Microsoft les appelle "noms de couleur X11", certains d'entre eux ne sont pas identiques aux définitions de la spécification X.
