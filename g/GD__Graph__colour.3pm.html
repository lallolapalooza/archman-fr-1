NOM

GD::Graph::colour - Routines de manipulation des couleurs pour utilisation avec GD::Graph

SYNTAXE

use GD::Graph::colour qw(:colours :lists :files :convert);

DESCRIPTION

Le paquet GD::Graph::colour fournit quelques routines pour travailler avec les couleurs. La fonctionnalité de ce paquet est principalement définie par ce qui est nécessaire, maintenant et historiquement, par les modules GD::Graph.

FONCTIONS

colour_list( nombre de couleurs )

Retourne une liste de nombre de couleurs noms de couleurs connus du paquet. Exporté avec la balise :lists.

sorted_colour_list( nombre de couleurs )

Retourne une liste de nombre de couleurs noms de couleurs connus du paquet, triée par luminance ou par teinte. NB. Actuellement, elle trie toujours par luminance. Une option sera ajoutée ultérieurement pour décider de la méthode de tri au moment de l'exécution. Exporté avec la balise :lists.

_rgb( nom de couleur )

Retourne une liste des valeurs RGB de nom de couleur. Si le nom de couleur est une chaîne de caractères de la forme acceptable par la sous-routine hex2rgb, alors la couleur sera ajoutée dynamiquement à la liste. Exporté avec la balise :colours.

_hue( R,V,B )

Retourne la teinte de la couleur avec les valeurs RVB spécifiées. Exporté avec la balise :colours.

_luminance( R,V,B )

Retourne la luminance de la couleur avec les valeurs RVB spécifiées. Exporté avec la balise :colours.

add_colour(nom_couleur => [$r, $g, $b]) ou add_colour('#7fe310')

Auto-explicatif. Exporté avec la balise :colours.

rgb2hex($rouge, $vert, $bleu)

hex2rgb('#7fe310')

Ces fonctions traduisent une liste de valeurs RVB en une chaîne hexadécimale, telle qu'utilisée couramment dans le HTML et l'API Image::Magick, et vice versa. Exporté avec la balise :convert.

read_rgb( nom de fichier )

Lit les couleurs à partir d'un fichier rgb tel qu'utilisé par le système X11.

Faire quelque chose comme :

use GD::Graph::bars;
use GD::Graph::colour;
GD::Graph::colour::read_rgb("rgb.txt") or die "impossible de lire les couleurs";

Vous permettra d'utiliser toutes les couleurs définies dans rgb.txt dans votre graphique. Exporté avec la balise :files.

NOMS DE COULEURS PRÉDÉFINIS

white, lgray, gray, dgray, black, lblue, blue, dblue, gold, lyellow, yellow, dyellow, lgreen, green, dgreen, lred, red, dred, lpurple, purple, dpurple, lorange, orange, pink, dpink, marine, cyan, lbrown, dbrown.
