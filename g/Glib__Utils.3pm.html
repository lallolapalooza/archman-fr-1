NOM

Glib::Utils - Fonctions utilitaires diverses

SYNOPSIS

use Glib;
Glib::set_application_name (Glib::get_real_name."'s Cool Program");
print "app name is ".Glib::get_application_name()."\n";

DESCRIPTION

Voici quelques utilitaires divers et utiles. GLib est une bibliothèque de portabilité, fournissant des fonctions utilitaires portables pour les programmes C. En tant que telles, la plupart de ces fonctions semblent violer le principe de liaison Glib de ne pas dupliquer les fonctionnalités que Perl fournit déjà, mais il y a une distinction pour chacune, je vous le jure. Les fonctions pour traiter les informations utilisateur sont fournies sur toutes les plateformes prises en charge par GLib, pas seulement là où POSIX (qui fournit des informations similaires) est disponible, et fonctionnent même sur des plateformes où %ENV peut ne pas inclure les informations attendues. De plus, le « nom d'application » auquel font référence (set|get)_application_name est un nom lisible par l'humain, distinct du nom réel du programme fourni par le propre $0de Perl.

MÉTHODES

string = Glib::get_application_name

Récupère le nom d'application lisible par l'humain défini par "set_application_name".

Depuis : glib 2.2

Glib::set_application_name ($application_name)

•
$application_name (string)

Définit le nom d'application lisible par l'humain.

Depuis : glib 2.2

string = Glib::get_home_dir

Trouve le répertoire personnel de l'utilisateur courant, par des moyens appropriés/dépendant du système.

list = Glib::get_language_names

Calcule une liste de noms de locales applicables, qui peuvent être utilisés pour par exemple construire des noms de fichiers ou des chemins de recherche dépendant de la locale. La liste retournée est triée du plus souhaitable au moins souhaitable et contient toujours la locale par défaut « C ».

Depuis : glib 2.6

string = Glib::get_prgname

Glib::set_prgname ($prgname)

•
$prgname (string)

string = Glib::get_real_name

Récupère le nom réel de l'utilisateur courant.

string = Glib::strerror ($err)

•
$err (integer)

Retourne une chaîne décrivant la valeur errno donnée, comme « No such file or directory » pour ENOENT. Celle-ci est traduite dans la langue préférée de l'utilisateur et est une chaîne utf8 à caractères larges (contrairement à une chaîne $! (perlvar) ou POSIX::strerror (POSIX) qui sont des octets du codeset de la locale).

string = Glib::strsignal ($signum)

•
$signum (integer)

Retourne une chaîne décrivant le numéro de signal donné, comme « Segmentation violation » pour SIGSEGV. Celle-ci est traduite dans la langue préférée de l'utilisateur et est une chaîne utf8 à caractères larges.

list = Glib::get_system_config_dirs

Retourne une liste ordonnée de répertoires de base dans lesquels accéder aux informations de configuration globales au système.

Depuis : glib 2.6

list = Glib::get_system_data_dirs

Retourne une liste ordonnée de répertoires de base dans lesquels accéder aux données d'application globales au système.

Depuis : glib 2.6

string = Glib::get_tmp_dir

Récupère le répertoire temporaire approprié pour le système courant. Voir la documentation de GLib pour des informations sur son fonctionnement.

string = Glib::get_user_cache_dir

Récupère le répertoire de base dans lequel stocker les données non essentielles en cache spécifiques à un utilisateur particulier.

Depuis : glib 2.6

string = Glib::get_user_config_dir

Récupère le répertoire de base dans lequel stocker les informations de configuration d'application spécifiques à l'utilisateur telles que les préférences et paramètres de l'utilisateur.

Depuis : glib 2.6

string = Glib::get_user_data_dir

Récupère le répertoire de base pour les données d'application telles que les icônes personnalisées pour un utilisateur particulier.

Depuis : glib 2.6

string = Glib::get_user_name

Récupère le nom de l'utilisateur courant par tous les moyens nécessaires dépendant du système.

string = Glib::get_user_special_dir ($directory)

•
$directory (Glib::UserDirectory)

Retourne le chemin complet d'un répertoire spécial en utilisant son identifiant logique.

Depuis : glib 2.14
