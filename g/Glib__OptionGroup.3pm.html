Crée un nouveau groupe d'options à partir des paires clé-valeur fournies. Les clés valides sont name, description, help_description et entries. Les trois premières spécifient des chaînes, tandis que la dernière, entries, spécifie une référence de tableau d'entrées d'options. Exemple

: 
my $group = Glib::OptionGroup->new (
              name => 'urgs',
              description => 'Urgs Urgs Urgs',
              help_description => 'Help with Urgs',
              entries => \@entries)
;

Une entrée d'option est une référence de hachage comme ceci

: 
{ long_name => 'verbose',
  short_name => 'v',
  flags => [qw/reverse hidden in-main/],
  arg_type => 'none',
  arg_value => \$verbose,
  description => 'verbose desc.',
  arg_description => 'verbose arg desc.'
}

Parmi ces clés, seules long_name, arg_type et arg_value sont requises. Ainsi, ceci est aussi une entrée d'option valide

: 
{ long_name => 'package-names',
  arg_type => 'string-array',
  arg_value => \$package_names
}

Par commodité, les entrées d'options peuvent également être spécifiées sous forme de références de tableau contenant long_name, short_name, arg_type et arg_value

: 
[ 'filenames', 'f', 'filename-array', \$filenames
]

Si vous ne souhaitez pas qu'une option ait de nom court, spécifiez undef pour celui-ci

: 
[ 'filenames', und
ef, 'filename-arr
ay', \$filenames ]
