DESCRIPTION

Ce module donne accès aux routines de la bibliothèque GSSAPI, comme décrit dans les RFC2743 et RFC2744 et implémenté par la distribution Kerberos-1.2 de MIT.

Depuis la version 0.14, il compile et fonctionne également avec Heimdal. Les fonctionnalités manquantes pour Heimdal sont gss_release_oid(), gss_str_to_oid() et l'échec de certains tests. Jetez un œil aux tests dans le répertoire t/ pour voir quels tests échouent sur Heimdal (les tests *.t les ignorent pour le moment)

L'API présentée par ce module est une réinterprétation légèrement orientée objet de l'API C, où les structures C opaques sont des objets Perl, mais le style d'appel de fonction a été largement laissé intact. En conséquence, la plupart des routines modifient un ou plusieurs des paramètres qui leur sont passés, reflétant la sémantique C d'appel par référence (ou appel par valeur de retour).

Tous les utilisateurs de ce module sont donc fortement conseillés de localiser toute utilisation de ces routines afin de minimiser les problèmes si et quand l'API change.

UTILISATION

Ce module encapsule les liaisons C GSSAPI. Si vous êtes novice en GSSAPI, il est conseillé de lire les RFC2743 et RFC2744. La documentation suppose que vous êtes familier avec le concept et le jargon de la programmation GSSAPI.

Le répertoire des exemples contient quelques exemples d'utilisation fonctionnels :

getcred_hostbased.pl
obtient un jeton GSSAPI pour un service spécifié en ligne de commande. (comme kgetcred sur Heimdal ou kvno sur MIT)
gss-client.pl
un simple client TCP GSSAPI.
gss-server.pl
un simple serveur TCP GSSAPI. Utilisez les deux comme modèles si vous avez besoin de services TCP GSSAPI rapides à activer GSSAPI.

GSSAPI::Name

Représentation interne GSSAPI d'un nom principal

Méthodes

import( $gssapinameobj, $servicename, $mechnism_oid );
convertit la représentation sous forme de chaîne $servicename du service en un format interne GSSAPI et la stocke dans $gssapiservicename.
entrée
servicename
Valeur scalaire, comme 'HTTP@moerbsen.grolmsnet.lan'.
mechnism_oid
Choisissez l'un des OID de mécanisme prédéfinis de GSSAPI::OID
sortie
$gssapinameobj
Représentation interne GSSAPI du nom de service
valeur de retour
retourne un objet GSSAPI::Status
Exemple :
$statut = GSSAPI::Name->import( $gssapinameobj,
                                'HTTP@moerbsen.grolmsnet.lan',
                                GSSAPI::OID::gss_nt_hostbased_service);
display($tname);
convertit le format interne GSSAPI en une chaîne lisible par l'homme et la stocke dans $tname.
sortie
la chaîne lisible par l'homme sera stockée dans $tname.
valeur de retour
retourne un objet GSSAPI::Status
Exemple :
my $tname;
$statut = $gssapinameobj->display($tname);
die 'hmm, erreur...' if($statut->major != GSS_S_COMPLETE );
print "\n  Le nom est $tname";
compare( nameobj, ret)
Encapsule gss_compare_name().
Entrée
nameobj
le 2ème GSSAPI::Name à comparer
sortie
ret
la valeur est non nulle
les noms font référence à la même entité
la valeur est nulle
les noms font référence à des entités différentes.
valeur de retour
retourne un objet GSSAPI::Status

use GSSAPI qw(:all);
my $oidset;
my $isin = 0;
my $statut = indicate_mechs( $oidset );
$statut->major == GSS_S_COMPLETE || die 'erreur';
$statut = $oidset->contains( gss_mech_krb5_old, $isin );
$statut->major == GSS_S_COMPLETE || die 'erreur';
if ( $isin ) {
  print 'Support du type de mécanisme Kerberos 5 ancien';
} else {
  print 'Pas de support du type de mécanisme Kerberos 5 ancien';
}
