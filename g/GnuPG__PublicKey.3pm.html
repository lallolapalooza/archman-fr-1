NOM

GnuPG::PublicKey - Objets de clé publique GnuPG

SYNTAXE

# suppose un objet GnuPG::Interface dans $gnupg
my @keys = $gnupg->get_public_keys( 'ftobin' );
# maintenant, les objets GnuPG::PublicKey sont dans @keys

DESCRIPTION

Les objets GnuPG::PublicKey sont généralement instanciés via diverses méthodes de GnuPG::Interface. Ils incarnent divers aspects d'une clé publique GnuPG.

Ce paquet hérite des membres de données et des méthodes d'objet de GnuPG::PrimaryKey, qui n'est pas décrit ici, mais plutôt dans GnuPG::PrimaryKey.

Actuellement, ce paquet n'est fonctionnellement pas différent de GnuPG::PrimaryKey.
