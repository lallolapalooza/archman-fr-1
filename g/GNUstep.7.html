BUNDLE

S

Un bundle est une collection de ressources formant un paquet discret pour utilisation. Il existe actuellement trois types de bundles : les applications, les frameworks et les bundles

chargeables.

Un bundle chargeable est une sorte de plug-in. Il y a deux types de bundles chargeables, à savoir les plug-ins et les palettes. Le plug-in est normalement appelé bundle, ce qui peut être un peu déroutant. Un plug-in est un bundle qui peut être chargé par une application pour fournir des fonctionnalités supplémentaires, tandis qu'une palette est un plug-in pour GORM , le constructeur d'interfaces. Une palette est utilisée pour étendre GORM avec des objets d'interface personna

lisés. Les palett
es ont l'extension

.palette . L'ESPACE DE TRAVAIL L'endroit central de l'interface utilisateur
