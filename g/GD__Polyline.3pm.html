GD::Polyline(3) Documentation Perl contribuée par les utilisateurs GD::Polyline(3)

NOM

GD::Polyline - Objet polyline et utilitaires pour polygones (y compris les splines) à utiliser avec GD

SYNOPSIS

use GD;
use GD::Polyline;
# create an image
$image = GD::Image->new (500,300);
$white  = $image->colorAllocate(255,255,255);
$black  = $image->colorAllocate(  0,  0,  0);
$red    = $image->colorAllocate(255,  0,  0);
# create a new polyline
$polyline = GD::Polyline->new;
# add some points
$polyline->addPt(  0,  0);
$polyline->addPt(  0,100);
$polyline->addPt( 50,125);
$polyline->addPt(100,  0);
# polylines can use polygon methods (and vice versa)
$polyline->offset(200,100);
# rotate 60 degrees, about the centroid
$polyline->rotate(3.14159/3, $polyline->centroid());
# scale about the centroid
$polyline->scale(1.5, 2, $polyline->centroid());
# draw the polyline
$image->polydraw($polyline,$black);
# create a spline, which is also a polyine
$spline = $polyline->addControlPoints->toSpline;
$image->polydraw($spline,$red);
# output the png
binmode STDOUT;
print $image->png;

DESCRIPTION

Polyline.pm étend le module GD en vous permettant de créer des polylignes. Considérez une polyligne comme « un polygone ouvert », c'est-à-dire que le dernier sommet n'est pas connecté au premier sommet (sauf si vous ajoutez expressément la même valeur comme les deux points).

Pour le reste de cette documentation, « polyligne » fera référence à un GD::Polyline, « polygone » fera référence à un GD::Polygon qui n'est pas une polyligne, et « polytruc » et « $poly » peuvent être l'un ou l'autre.

La grande fonctionnalité ajoutée à GD par ce module est la possibilité de créer des splines, qui sont des approximations de courbes.

L'objet Polyline

GD::Polyline définit la classe suivante :

« GD::Polyline »
Un objet polyligne, utilisé pour stocker des listes de sommets avant de rendre une polyligne dans une image.
« new »
« GD::Polyline->new » méthode de classe

Crée une polyligne vide sans sommets.

$polyline = GD::Polyline->new;
$polyline->addPt(  0,  0);
$polyline->addPt(  0,100);
$polyline->addPt( 50,100);
$polyline->addPt(100,  0);
$image->polydraw($polyline,$black);

En fait, GD::Polyline est une sous-classe de GD::Polygon, donc toutes les méthodes de polygone (comme offset et transform) peuvent être utilisées sur les polylignes. Quelques nouvelles méthodes ont donc été ajoutées à GD::Polygon (comme rotate) et quelques-unes ont été mises à jour/modifiées/améliorées (comme scale) dans ce module. Voir la section « Nouvelles ou mises à jour des méthodes GD::Polygon » pour plus d'informations.

Notez que ce module est très « jeune » et doit être considéré comme susceptible de changer dans les futures versions, et/ou éventuellement intégré à l'objet polygone existant et/ou au module GD.

Méthodes de polygone mises à jour

Les méthodes suivantes (définies dans GD.pm) sont RÉÉCRITES si vous utilisez ce module.

Tous les efforts ont été faits pour fournir une compatibilité ascendante à 100 %, mais si vous pouvez confirmer que cela n'a pas été atteint, veuillez considérer cela comme un bogue et informer l'auteur de Polyline.pm.

« scale »
« $poly->scale($sx, $sy, $cx, $cy) » méthode objet -- MISE À JOUR de GD::Polygon::scale

Met à l'échelle un polytruc le long de l'axe des x par $sx et le long de l'axe des y par $sy, autour du point central ($cx, $cy).

Le point central ($cx, $cy) est facultatif -- s'il est omis, la fonction mettra à l'échelle autour de l'origine.

Pour retourner un polytruc, utilisez un facteur d'échelle de -1. Par exemple, pour retourner un polytruc de haut en bas autour de la ligne y = 100, utilisez :

$poly->scale(1, -1, 0, 100);

Nouvelles méthodes de polygone

Les méthodes suivantes sont ajoutées à GD::Polygon, et peuvent donc être utilisées par les polygones et les polylignes.

N'oubliez pas : une polyligne est un GD::Polygon, donc les méthodes GD::Polygon comme offset() peuvent être utilisées, et elles peuvent être utilisées dans les méthodes GD::Image comme filledPolygon().

« rotate »
« $poly->rotate($angle, $cx, $cy) » méthode objet

Fait pivoter un polytruc de $angle (dans le sens des aiguilles d'une montre, en radians) autour du point central ($cx, $cy).

Le point central ($cx, $cy) est facultatif -- s'il est omis, la fonction fera pivoter autour de l'origine.

Dans cette fonction et les autres fonctions orientées angle dans GD::Polyline, un $angle positif correspond à une rotation dans le sens des aiguilles d'une montre. C'est l'opposé du sens cartésien habituel, mais c'est parce que le raster est à l'opposé du sens cartésien habituel en ce que l'axe des y va « vers le bas ».

« centroid »
« ($cx, $cy) = $poly->centroid($scale) » méthode objet

Calcule et retourne ($cx, $cy), le centroïde des sommets du polytruc. Par exemple, pour faire pivoter quelque chose de 180 degrés autour de son centroïde :

$poly->rotate(3.14159, $poly->centroid());

$scale est facultatif ; s'il est fourni, $cx et $cy sont multipliés par $scale avant d'être retournés. L'utilisation principale de ceci est de déplacer un polytruc vers l'origine comme ceci :

$poly->offset($poly->centroid(-1));
« segLength »
« @segLengths = $poly->segLength() » méthode objet

Dans un contexte tableau, retourne un tableau des longueurs des segments du polytruc. Le segment n est le segment du sommet n au sommet n+1. Les polygones ont autant de segments que de sommets ; les polylignes en ont un de moins.

Dans un contexte scalaire, retourne la somme du tableau qui aurait été retourné dans le contexte tableau.

« segAngle »
« @segAngles = $poly->segAngle() » méthode objet

Retourne un tableau des angles de chaque segment par rapport à l'axe des x. Le segment n est le segment du sommet n au sommet n+1. Les polygones ont autant de segments que de sommets ; les polylignes en ont un de moins.

Les angles retournés seront dans l'intervalle 0 <= $angle < 2 * pi et les angles augmentent dans le sens des aiguilles d'une montre.

« vertexAngle »
« @vertexAngles = $poly->vertexAngle() » méthode objet

Retourne un tableau des angles entre le segment entrant et sortant de chaque sommet. Pour les polylignes, l'angle au sommet 0 et au dernier sommet ne sont pas définis ; cependant $vertexAngle[0] sera undef afin que $vertexAngle[1] corresponde au sommet 1.

Les angles retournés seront dans l'intervalle 0 <= $angle < 2 * pi et les angles augmentent dans le sens des aiguilles d'une montre.

Notez que ce calcul ne tente pas de déterminer l'angle « intérieur » par rapport à l'« intérieur » ou à l'« extérieur » du polygone, mais plutôt simplement l'angle entre les segments adjacents dans le sens des aiguilles d'une montre. Ainsi, un polygone avec tous les angles droits aura des angles de sommet de pi/2 ou 3*pi/2, selon la manière dont le polygone a été « enroulé ».

« toSpline »
« $poly->toSpline() » méthode objet et méthode usine

Crée un nouveau polytruc qui est une courbe raisonnablement lisse en utilisant des algorithmes de spline cubique, souvent appelés courbes de Bézier. Le polytruc « source » est appelé le « polytruc de contrôle ». S'il s'agit d'une polyligne, la polyligne de contrôle doit avoir 4, 7, 10, ou un nombre quelconque de sommets égal à 3n+1. S'il s'agit d'un polygone, le polygone de contrôle doit avoir 3, 6, 9, ou un nombre quelconque de sommets égal à 3n.

$spline = $poly->toSpline();
$image->polydraw($spline,$red);

En bref, des groupes de quatre points du polytruc de contrôleligne sont considérées comme des « points de contrôle » pour une portion donnée de la spline : la première et la quatrième sont des « points d'ancrage », et la spline passe par elles ; la deuxième et la troisième sont des « points directeurs ». La spline ne passe pas par les points directeurs, cependant la spline est tangente au segment de droite allant du point d'ancrage au point directeur adjacent.

La portion suivante de la spline réutilise le dernier point d'ancrage de la portion précédente. La spline aura un point anguleux (pente non continue) à un point d'ancrage, à moins que les points d'ancrage et son point directeur adjacent ne soient colinéaires.

Dans l'implémentation actuelle, toSpline() renvoie un nombre fixe de segments dans la polyligne retournée par ensemble de quatre points de contrôle. À l'avenir, ceci et d'autres paramètres de l'algorithme pourront être configurables.

"addControlPoints"
"$polyline->addControlPoints()" méthode d'objet et méthode usine

Alors vous dites : « OK. Les splines ont l'air sympas. Mais comment puis-je faire en sorte que mes points d'ancrage et leur point directeur adjacent soient colinéaires afin d'avoir de jolies courbes lisses à partir de ma polyligne ? » Détendez-vous ! Pour les paresseux : addControlPoints() à la rescousse.

addControlPoints() renvoie une polyligne qui peut servir de polyligne de contrôle pour toSpline(), qui renvoie une autre polyligne qui est la spline. Votre tête tourne-t-elle déjà ? Pensez-y ainsi :

+
Si vous avez une polyligne, et que vous avez déjà placé vos points de contrôle où vous le souhaitez, appelez toSpline() directement. Rappelez-vous, seul chaque troisième sommet sera « sur » la spline.

Vous obtenez quelque chose qui ressemble à la spline « inscrite » à l'intérieur de la polyligne de contrôle.

+
Si vous avez une polyligne, et que vous voulez que tous ses sommets soient sur la spline résultante, appelez addControlPoints() puis toSpline(): 
$control = $polyline->addControlPoints();
$spline  = $control->toSpline();
$image->polyline($spline,$red);

Vous obtenez quelque chose qui ressemble à la polyligne de contrôle « inscrite » à l'intérieur de la spline.

Ajouter de « bons » points de contrôle est subjectif ; cet algorithme particulier révèle les goûts de son auteur. À l'avenir, vous pourrez peut-être modifier légèrement ces goûts via des paramètres de l'algorithme. Pour les orgueilleux : merci d'en construire un meilleur !

Et pour les impatients : notez que addControlPoints() renvoie une polyligne, vous pouvez donc enchaîner les appels comme ceci, si vous le souhaitez :

$image->polyline($polyline->addControlPoints()->toSpline(),$mauve);

Nouvelles méthodes de GD::Image

"polyline"
"$image->polyline(polyline,color)" méthode d'objet 
$image->polyline($polyline,$black)

Cela dessine une polyligne avec la couleur spécifiée. À la fois les index de couleur réels et les couleurs spéciales gdBrushed, gdStyled et gdStyledBrushed peuvent être spécifiés.

Ni la méthode polyline() ni la méthode polygon() ne sont très exigeantes : vous pouvez appeler l'une ou l'autre méthode avec soit un GD::Polygon soit un GD::Polyline. La méthode détermine si la forme est « fermée » ou « ouverte » telle qu'elle est dessinée, et non le type d'objet.

"polydraw"
"$image->polydraw(polything,color)" méthode d'objet 
$image->polydraw($poly,$black)

Cette méthode dessine le polything comme prévu (les polygones sont fermés, les polylignes sont ouvertes) en vérifiant simplement le type d'objet et en appelant soit $image->polygon() soit $image->polyline().

Fonctionnalités futures

Sur la planche à dessin se trouvent des fonctionnalités supplémentaires telles que :

- algorithmes de balayage de polygone (pour déterminer si un point est « à l'intérieur » ou « à l'extérieur » du polygone)
- nouveau polygone à partir d'une boîte englobante
- trouver le polygone englobant (le polygone convexe simple ajusté le plus serré pour un ensemble donné de sommets)
- méthode addPts() pour ajouter plusieurs points à la fois
- méthode clone() pour les polygones
- fonctions pour faire interagir GD avec SVG

Merci de fournir des commentaires sur d'autres fonctionnalités possibles que vous aimeriez voir.
