GnuPG::Fingerprint(3) Documentation Perl fournie par l'utilisateur GnuPG::Fingerprint(3)

NOM

GnuPG::Fingerprint - Objets d'empreinte GnuPG

SYNOPSIS

# suppose une clé GnuPG::Key dans $key
my $fingerprint = $key->fingerprint->as_hex_string();

DESCRIPTION

Les objets GnuPG::Fingerprint font généralement partie des objets GnuPG::Key, et ne sont pas créés seuls.

MÉTHODES OBJET

Méthodes d'initialisation

new( %arguments_initialisation )
Cette méthode crée un nouvel objet. Les arguments facultatifs sont pour l'initialisation des membres de données.
hash_init( %args ).
compare( $autre )
Retourne une valeur non nulle uniquement lorsque cette empreinte est identique à l'autre GnuPG::Fingerprint.

MEMBRES DE DONNÉES OBJET

as_hex_string
C'est la valeur hexadécimale de l'empreinte que l'objet incarne, au format chaîne de caractères.
