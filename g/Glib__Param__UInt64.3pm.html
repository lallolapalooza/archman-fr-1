NOM

Glib::Param::UInt64 - Wrapper pour les paramètres uint64 dans GLib

HIERARCHIE

Glib::ParamSpec
+----Glib::Param::UInt64

DESCRIPTION

Cette page documente les accesseurs supplémentaires disponibles pour les paramètres de type entier non signé de 64 bits. Sur les machines 32 bits et même sur certaines machines 64 bits, Perl ne prend en charge que les entiers 32 bits, donc toutes ces méthodes convertissent les valeurs vers et depuis des chaînes Perl si nécessaire.

MÉTHODES

entier non signé 64 bits = $pspec->get_maximum

entier non signé 64 bits = $pspec->get_minimum

VOIR AUSSI
