Glib::Param::Int(3) Documentation Perl fournie par l'utilisateur Glib::Param::Int(3)

NOM

Glib::Param::Int - Paramètres pour les types entiers

HIÉRARCHIE

Glib::ParamSpec
+----Glib::Param::Int
Glib::ParamSpec
+----Glib::Param::Char
Glib::ParamSpec
+----Glib::Param::Long

DESCRIPTION

Cette page documente les accesseurs supplémentaires disponibles pour tous les paramètres de type entier : Char, Int et Long. Perl ne prend réellement en charge que les entiers de taille complète, donc toutes ces méthodes retournent des IV ; la distinction de la taille de l'entier est importante pour la bibliothèque C sous-jacente et détermine également la plage des valeurs de données.

MÉTHODES

entier = $pspec->get_maximum

entier = $pspec->get_minimum

VOIR AUSSI

Glib, Glib::ParamSpec, Glib::ParamSpec
