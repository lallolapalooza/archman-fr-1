Gtk3::SimpleList(3) Documentation Perl contribuée par les utilisateurs Gtk3::SimpleList(3)

NOM

Gtk3::SimpleList - Une interface simple pour le widget de liste MVC complexe de Gtk3

SYNOPSIS

use Glib qw(TRUE FALSE);
use Gtk3 '-init';
use Gtk3::SimpleList;
my $slist = Gtk3::SimpleList->new (
              'Text Field'    => 'text',
              'Markup Field'  => 'markup',
              'Int Field'     => 'int',
              'Double Field'  => 'double',
              'Bool Field'    => 'bool',
              'Scalar Field'  => 'scalar',
              'Pixbuf Field'  => 'pixbuf',
            );
@{$slist->{data}} = (
        [ 'text', 1, 1.1,  TRUE, $var, $pixbuf ],
        [ 'text', 2, 2.2, FALSE, $var, $pixbuf ],
);
# (presque) tout ce que vous pouvez faire avec un tableau, vous pouvez le faire avec
# $slist->{data} qui est une référence de tableau liée au modèle de liste
push @{$slist->{data}}, [ 'text', 3, 3.3, TRUE, $var, $pixbuf ];
# manipuler les sélections
$slist->get_selection->set_mode ('multiple');
$slist->get_selection->unselect_all;
$slist->select (1, 3, 5..9); # sélectionner des lignes par index
$slist->unselect (3, 8); # désélectionner des lignes par index
@sel = $slist->get_selected_indices;
# méthode simple pour rendre les colonnes de texte éditables
$slist->set_column_editable ($col_num, TRUE);
# Gtk3::SimpleList hérite de Gtk3::TreeView, donc toutes les méthodes
# d'une vue d'arbre sont disponibles.
$slist->set_rules_hint (TRUE);
$slist->signal_connect (row_activated => sub {
        my ($sl, $path, $column) = @_;
        my $row_ref = $sl->get_row_data_from_path ($path);
        # $row_ref est maintenant une référence de tableau vers les données de la ligne double-cliquée.
    });
# transformer une TreeView existante en SimpleList ; utile pour
# les interfaces générées par Glade.
$simplelist = Gtk3::SimpleList->new_from_treeview (
                  $glade->get_widget ('treeview'),
                  'Text Field'    => 'text',
                  'Int Field'     => 'int',
                  'Double Field'  => 'double',
               );

RÉSUMÉ

SimpleList est une interface simple pour la combinaison puissante mais complexe de Gtk3::TreeView et Gtk3::ListStore, implémentée à l'aide de tableaux liés pour rendre les choses simples et faciles.

DESCRIPTION

Gtk3 dispose d'un système MVC (Modèle, Vue, Contrôleur) puissant mais complexe utilisé pour implémenter les widgets de liste et d'arbre. Gtk3::SimpleList automatise le travail de configuration complexe et vous permet de traiter le modèle de liste comme une structure de liste de listes plus naturelle.

Après avoir créé un nouvel objet Gtk3::SimpleList avec les colonnes souhaitées, vous pouvez définir les données de la liste avec une simple assignation de tableau Perl. Des lignes peuvent être ajoutées ou supprimées avec toutes les opérations de tableau normales. Vous pouvez traiter le membre "data" de l'objet simplelist comme une référence de tableau et manipuler les données de la liste avec les opérateurs de tableau normaux de Perl.

Un mécanisme a également été mis en place permettant aux colonnes d'être des scalaires Perl. Le scalaire est converti en texte via les mécanismes normaux de Perl puis affiché dans la liste. Ce même mécanisme peut être étendu en définissant de nouveaux types de colonnes arbitraires avant d'appeler la fonction new.

HIÉRARCHIE DES OBJETS

Glib::Object
+--- Gtk3::Object
     +--- Gtk3::Widget
          +--- Gtk3::TreeView
               +--- Gtk3::SimpleList

MÉTHODES

$slist = Gtk3::SimpleList->new ($cname, $ctype, ...)
  • $cname (chaîne)
  • $ctype (chaîne)

Crée un nouvel objet Gtk3::SimpleList avec les colonnes spécifiées. Le paramètre "cname" est le nom de la colonne, ce qui sera affiché dans les en-têtes de liste s'ils sont activés. Le paramètre ctype est le type de colonne, parmi :

text    chaînes de texte normales
markup  chaînes de balisage pango
int     valeurs entières
double  valeurs flottantes en double précision
bool    valeurs booléennes, affichées sous forme de cases à cocher activables
scalar  un scalaire Perl, affiché par défaut comme une chaîne de texte
pixbuf  un Gtk3::Gdk::Pixbuf

ou le nom d'un type personnalisé que vous ajoutez avec "add_column_type". Ceux-ci doivent être fournis par paires selon les colonnes souhaitées pour votre liste.

$slist = Gtk3::SimpleList->new_from_treeview ($treeview, $cname, $ctype, ...)
  • $treeview (Gtk3::TreeView)
  • $cname (chaîne)
  • $ctype (chaîne)

Comme "Gtk3::SimpleList->new()", mais transforme une Gtk3::TreeView existante en Gtk3::SimpleList. C'est principalement destiné à une utilisation avec des outils comme Glade, où le widget est créé pour vous. Cela va créer et attacher un nouveau modèle et supprimer toutes les colonnes existantes de treeview. Renvoie treeview, re-bénie comme un Gtk3::SimpleList.

$slist->set_data_array ($arrayref)
•
$arrayref (référence de tableau)

Définit les données dans la liste à la référence de tableau $arrayref. C'est complètement équivalent à @{$list->{data}} = @{$arrayref} et n'est là que pour la commodité et pour les programmeurs qui n'aiment pas faire de conversion de type et qui ont des données statiques, définies une seule fois.

@indices = $slist->get_selected_indices
Renvoie les indices des lignes sélectionnées dans le ListStore.
$slist->get_row_data_from_path ($path)
•
$path (Gtk3::TreePath) le chemin de la ligne souhaitée

Renvoie une référence de tableau avec les données de la ligne indiquée par $path.

$slist->select ($index, ...);
$slist->unselect ($index, ...);
•
$index (entier)

Sélectionne ou désélectionne des lignes dans la liste par index. Si la liste est configurée pour la sélection multiple, tous les indices de la liste seront définis/annulés ; sinon, seul le premier est utilisé. Si la liste est configurée pour aucune sélection, alors rien ne se passe.

Pour définir le mode de sélection, ou pour sélectionner toutes les lignes ou aucune, utilisez les mécanismes normaux de TreeView/TreeSelection, par exemple $slist->get_selection et les méthodes TreeSelection "get_mode", "set_mode", "select_all", et "unselect_all".

$slist->set_column_editable ($index, $editable)
  • $index (entier)
  • $editable (booléen)
booléen = $slist->get_column_editable ($index)
•
$index (entier)

C'est une interface très simple pour les cellules de colonne de texte éditables de Gtk3::TreeView. Toutes les colonnes qui utilisent l'attribut "text" (basiquement, toute colonne de texte ou de nombre, voir "add_column_type") ont automatiquement des rappels installés pour mettre à jour les données lorsque les cellules sont éditées. Avec "set_column_editable", vous pouvez activer l'édition sur place.

"get_column_editable" vous indique si la colonne index est actuellement éditable.

Gtk3::SimpleList->add_column_type ($type_name, ...)
$type_name (chaîne)

Ajoute un nouveau type de colonne à la liste des types possibles. Initialement, six types sont définis, text, int, double, bool, scalar, et pixbuf. La colonne bool utilise un rendu de cellule à bascule, pixbuf utilise un rendu de cellule pixbuf, et les autres utilisent des rendus de cellule texte. Dans le processus d'ajout d'un nouveau type de colonne, vous pouvez utiliser n'importe quel rendu de cellule de votre choix.

Le premier paramètre est le nom du type de colonne, la liste des six sont des exemples. Il n'y a aucune restriction sur les noms et vous pouvez même écraser les existants si vous le souhaitez. Les paramètres restants sont la définition du type composée de paires clé-valeur. Il y en a trois requis : type, renderer, et attr. La clé type détermine quel type de données réel sera stocké dans la représentation du modèle sous-jacent ; c'est un nom de paquet, par ex. Glib::String, Glib::Int, Glib::Boolean, mais en général si vous voulez une structure de données Perl arbitraire, vous voudrez utiliser 'Glib::Scalar'. La clé renderer doit contenir le nom de la classe du rendu de cellule à créer pour ce type de colonne ; cela peut être n'importe lequel de Gtk3::CellRendererText, Gtk3::CellRendererToggle, Gtk3::CellRendererPixbuf, ou une autre classe de rendu de cellule, éventuellement personnalisée. La clé attr est magique ; elle peut être soit une chaîne, auquel cas elle spécifie l'attribut qui sera défini à partir de la colonne spécifiée (par ex. 'text' pour un rendu texte, 'active' pour un rendu à bascule, etc.), soit une référence à une sous-routine qui sera appelée chaque fois que le rendu a besoin de dessiner les données.

Cette fonction, décrite comme une GtkTreeCellDataFunc dans la référence de l'API, recevra 5 paramètres : $treecol, $cell, $model, $iter, $col_num (quand SimpleList connecte la fonction, il définit le numéro de colonne à passer en tant que données utilisateur). La valeur de données pour la cellule en question est disponible via $model->get ($iter, $col_num); vous pouvez ensuite faire ce que vous avez à faire pour rendre la cellule comme vous le souhaitez. Voici quelques exemples :

# affiche simplement la valeur dans un scalaire tel que
# Perl la convertirait en chaîne
Gtk3::SimpleList->add_column_type( 'a_scalar', 
        type     => 'Glib::Scalar',
        renderer => 'Gtk3::CellRendererText',
        attr     => sub {
             my ($treecol, $cell, $model, $iter, $col_num) = @_;
             my $info = $model->get ($iter, $col_num);
             $cell->set (text => $info);
        }
   );
# additionne les valeurs dans une référence de tableau et affiche
# le résultat dans un rendu texte
Gtk3::SimpleList->add_column_type( 'sum_of_array', 
        type     => 'Glib::Scalar',
        renderer => 'Gtk3::CellRendererText',
        attr     => sub {
             my ($treecol, $cell, $model, $iter, $col_num) = @_;
             my $sum = 0;
             my $info = $model->get ($iter, $col_num);
             foreach (@$info)
             {
                 $sum += $_;
             }
             $cell->set (text => $sum);
        } 
   );

MODIFICATION DES DONNÉES DE LA LISTE

Après la création d'un nouvel objet Gtk3::SimpleList, il y aura un membre appelé "data" qui est un tableau lié. Cela signifie que les données peuvent être traitées comme un tableau, mais en réalité les données résident dans autre chose. Il n'est pas nécessaire de comprendre les détails de cela, cela signifie simplement que vous mettez des données dedans, en prenez, et les modifiez comme n'importe quel autre tableau. Cela inclut l'utilisation d'opérations de tableau comme push, pop, unshift, et shift. Pour ceux d'entre vous très familiers avec perl, cette section s'avérera redondante, mais juste au cas où :

Ajout et suppression de lignes :

  # pousse une ligne à la fin de la liste
  push @{$slist->{data}}, [col1_data, col2_data, ..., coln_data];
  # retire une ligne de la fin de la liste
  $rowref = pop @{$slist->{data}};
  # insère une ligne au début de la liste
  unshift @{$slist->{data}}, [col1_data, col2_data, ..., coln_data];
  # retire une ligne du début de la liste
  $rowref = shift @{$slist->{data}};
  # supprime la ligne à l'index $n, indexé à partir de 0
  splice @{ $slist->{data} }, $n, 1;
  # définit toute la liste comme étant les données d'un tableau
  @{$slist->{data}} = ( [row1, ...], [row2, ...], [row3, ...] );
Accéder aux données dans la liste :

  # obtient une référence de tableau pour toute la nième ligne
  $rowref = $slist->{data}[n];
  # obtient le scalaire dans la mième colonne de la nième ligne, indexé à partir de 0
  $val = $slist->{data}[n][m];
  # définit une référence de tableau pour toute la nième ligne
  $slist->{data}[n] = [col1_data, col2_data, ..., coln_data];
  # définit le scalaire dans la mième colonne de la nième ligne, indexé à partir de 0
  $slist->{data}[n][m] = $rowm_coln_value;
