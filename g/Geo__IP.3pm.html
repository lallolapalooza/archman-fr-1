DESCRIPTIO

N

Ce module utilise la base de données de fichiers GeoIP Legacy. Cette base de données contient simplement des blocs IP comme clés, et des pays comme valeurs. Cette base de données devrait être plus complète et plus précise que les recherches DNS

inversées.

Ce module peut être utilisé pour sélectionner automatiquement le miroir géographiquement le plus pr

oche, pour analyser les journaux de votre serveur web afin de déterminer les pays de vos visiteurs,
pour la détection de fraude par carte de crédit, et pour les contrôles d'exportation de logiciels.

UTILISATION DE LA GÉOLOCALISATION

IP

La géolocalisation IP est intrinsèquement imprécise. Les localisations sont souvent proches

du centre de la population. Toute localisation fournie par une base de données GeoIP ou un
service web ne doit pas être utilisée pour identifier une adresse ou un foyer particulier.

MÉTHODES DE

CLASSE
$gi = Geo::IP->new( $flags
);
Construit un nouvel objet Geo::IP avec la base de données par défaut située dans le datadir de votre système, généralement /usr/local/share/GeoIP/GeoIP.dat.

Les drapeaux peuvent être définis sur GEOIP_STANDARD, ou pour des performances plus rapides (au prix d'une utilisation de plus de mémoire), GEOIP_MEMORY_CACHE. Lorsque vous utilisez le cache mémoire, vous pouvez forcer un rechargement si le fichier est mis à jour en définissant GEOIP_CHECK_CACHE. GEOIP_INDEX_CACHE met en cache la partie d'index la plus fréquemment accédée de la base de données, ce qui entraîne des recherches plus rapides que GEOIP_STANDARD, mais une utilisation mémoire inférieure à GEOIP_MEMORY_CACHE - utile pour les bases de données plus grandes telles que GeoIP Legacy Organization et GeoIP City. Notez que pour les bases de données GeoIP Country, Region et Netspeed, GEOIP_INDEX_CACHE est équivalent à

GEOIP_MEMORY_CACHE.

Avant la version 1.6.3 de geoip-api, la C API laissait fuiter des messages de diagnostic sur stderr inconditionnellement. À partir de Geo::IP v1.44, le drapeau supprimant ce comportement (GEOIP_SILENCE) est implicitement ajouté aux drapeaux passés à new(), open(), et open_typ

e().

Pour combiner des drapeaux, utilisez l'opérateur OU bit à bit, |. Par exemple, pour mettre la base de données en cache en mémoire, mais vérifier un fichier GeoIP.dat mis à jour, utilisez : Geo::IP->new( GEOIP_MEMORY_CACHE | GEOIP_CHECK_CACHE
