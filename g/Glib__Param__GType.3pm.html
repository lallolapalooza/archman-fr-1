NOM

Glib::Param::GType - Enveloppe pour les paramètres de type dans GLib

HIERARCHIE

Glib::ParamSpec
+----Glib::Param::GType

DESCRIPTION

Cet objet décrit un paramètre qui contient le nom d'une classe connue du système de types GLib. Le nom de la classe est considéré comme l'ancêtre commun pour les valeurs valides. Pour créer un paramètre qui autorise tout nom de type, spécifiez "undef" pour le nom du paquet. Faites attention, cependant, bien que nous disions "tout nom de type", cela fait en fait référence à tout type enregistré avec Glib ; les paquets Perl normaux ne fonctionneront pas.

MÉTHODES

string ou undef = $pspec_gtype->get_is_a_type

Si "undef", alors toute classe est autorisée.

Depuis : glib 2.10
