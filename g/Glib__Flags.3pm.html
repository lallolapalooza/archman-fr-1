NOM

Glib::Flags - méthodes et opérateurs surchargés pour les drapeaux

HIERARCHIE

Glib::Flags

DESCRIPTION

Glib mappe les valeurs de drapeaux et d'énumération aux chaînes de surnoms fournies par les bibliothèques C sous-jacentes. Représenter des drapeaux de cette manière en Perl est un problème intéressant, que Glib résout en utilisant des opérateurs surchargés astucieux.

Les fonctions décrites ici effectuent réellement le travail de ces opérateurs surchargés. Voir la description des opérateurs de drapeaux dans la section « This Is Now That » de Glib pour plus d'informations.

MÉTHODES

scalaire = $classe->new ($a)

•
$a (scalaire)

Crée un nouvel objet de drapeaux avec les bits donnés. Ceci est destiné à être utilisé par une sous-classe ; il n'est pas possible de créer un objet "Glib::Flags" en tant que tel. Par exemple :

my $f1 = Glib::ParamFlags->new ('readable');
my $f2 = Glib::ParamFlags->new (['readable','writable']);

Un objet comme celui-ci peut ensuite être utilisé avec les opérateurs surchargés.

scalaire = $a->all ($b, $swap)

  • $b (scalaire)
  • $swap (scalaire)

aref = $f->as_arrayref

Retourne les bits de $f sous forme de référence vers un tableau de chaînes, comme ['flagbit1','flagbit2']. Ceci est la fonction de surcharge pour "@{}", c'est-à-dire l'arrayisation de $f. Vous pouvez également l'appeler directement comme une méthode.

Notez que @$f donne les bits sous forme de liste, mais as_arrayref donne une référence de tableau. Si c'est ce que vous voulez, alors le style de méthode quelquefonction()->as_arrayref peut être plus lisible que [@{quelquefonction()}].

booléen = $f->bool

Retourne 1 si des bits sont définis dans $f, ou 0 s'il n'y en a aucun. Ceci est la surcharge pour $f dans un contexte booléen (comme "if", etc.). Vous pouvez également l'appeler comme méthode pour obtenir directement un vrai/faux.
