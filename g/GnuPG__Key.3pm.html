GnuPG::Key(3) Documentation Perl fournie par l'utilisateur GnuPG::Key(3)

NOM

GnuPG::Key - Objet clé GnuPG

SYNTAXE

# suppose un objet GnuPG::Interface dans $gnupg
my @keys = $gnupg->get_public_keys( 'ftobin' );
# maintenant, des objets GnuPG::PublicKey sont dans @keys

DESCRIPTION

Les objets GnuPG::Key ne sont généralement pas instanciés par eux-mêmes, mais sont plutôt utilisés comme superclasse des objets GnuPG::PublicKey, GnuPG::SecretKey, ou GnuPG::SubKey.

MÉTHODES OBJET

Méthodes d'initialisation

new( %arguments_initialisation )
Cette méthode crée un nouvel objet. Les arguments optionnels sont l'initialisation des membres de données.
hash_init( %args ).
short_hex_id
Ceci retourne l'identifiant hexadécimal court de 8 caractères couramment utilisé de la clé.
compare( $other, $deep )
Retourne une valeur non nulle uniquement lorsque cette Clé est identique à l'autre GnuPG::Key. Si $deep est présent et non nul, les signatures, les révocation et les révocateurs associés à la clé seront également comparés.

MEMBRES DE DONNÉES OBJET

length
Nombre de bits dans la clé.
algo_num
Le numéro de l'algorithme pour lequel la Clé est utilisée.
usage_flags
Les indicateurs d'utilisation de la clé associés à cette clé, représentés par une chaîne de lettres minuscules. Les valeurs possibles incluent : (a) authentifier, (c) certifier, (e) chiffrer et (s) signer.

Une clé peut avoir n'importe quelle combinaison de ceux-ci dans n'importe quel ordre. En plus de ces lettres, la clé primaire a des versions majuscules des lettres pour indiquer les capacités _utilisables_ de la clé entière, et une lettre potentielle 'D' pour indiquer une clé désactivée.

Voir "key capabilities" DETAILS dans les sources GnuPG pour plus de détails.

hex_data
Les données de la clé. ATTENTION : ceci semble n'avoir jamais été instancié et devrait toujours être undef.
pubkey_data
Une liste d'objets Math::BigInt qui correspondent au matériel de la clé publique pour la clé donnée. Ce membre est vide pour les clés secrètes dans GnuPG 1.4. Il est rempli pour les clés secrètes dans GnuPG >= 2.2.0.

Pour les clés DSA, les valeurs sont : premier (p), ordre du groupe (q), générateur du groupe (g), y

Pour les clés RSA, les valeurs sont : modulus (n), exposant (e)

Pour les clés El Gamal, les valeurs sont : premier (p), générateur du groupe (g), y

Pour plus de détails, voir : http://tools.ietf.org/html/rfc4880#page-42

hex_id
L'identifiant hexadécimal long de la clé. Ce n'est ni l'empreinte digitale ni l'identifiant hexadécimal court, qui est de 8 caractères hexadécimaux.
creation_date_string
expiration_date_string
Date formatée de la création et de l'expiration de la clé. Si la clé n'a pas d'expiration, expiration_date_string retournera undef.
creation_date
expiration_date
Date de création et d'expiration de la clé, stockée sous forme de nombre de secondes depuis minuit le 1970-01-01 UTC. Si la clé n'a pas d'expiration, expiration_date retournera undef.
fingerprint
Un objet GnuPG::Fingerprint.
signatures
Une liste d'objets GnuPG::Signature incarnant les signatures sur cette clé. Pour les sous-clés, les signatures sont généralement des signatures de liaison de sous-clé. Pour les clés primaires, les signatures sont des déclarations concernant la clé elle-même.
revocations
Une liste de révocation associées à cette clé, stockées sous forme d'objets GnuPG::Signature (car les révocation sont également un type de certification). Notez qu'une révocation d'une clé primaire a une signification sémantique différente d'une révocation associée à une sous-clé.
revokers
Une liste d'objets GnuPG::Revoker associés à cette clé, indiquant d'autres clés qui sont autorisées à révoquer les certifications faites par cette clé.

VOIR AUSSI

GnuPG::Fingerprint, GnuPG::Signature, GnuPG::Revoker,
