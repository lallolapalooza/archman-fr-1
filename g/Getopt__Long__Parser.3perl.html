Getopt::Long::Parser(3perl) Guide de référence des programmeurs Perl Getopt::Long::Parser(3perl)

NOM

Getopt::Long::Parser - Interface orientée objet pour Getopt::Long

SYNTAXE

use Getopt::Long::Parser;
my $p = Getopt::Long::Parser->new;
$p->configure( %options );
if ( $p->getoptions( @options ) ) { ... }
if ( $p->getoptionsfromarray( \@array, @options ) ) { ... }

Les options de configuration peuvent être passées au constructeur :

my $p = Getopt::Long::Parser->new( config => [ %options ] );

DESCRIPTION

"Getopt::Long::Parser" est une interface orientée objet pour Getopt::Long. Voir sa documentation pour la configuration et l'utilisation.

Notez que "Getopt::Long" et "Getopt::Long::Parser" ne sont pas orientés objet. "Getopt::Long::Parser" émule une interface orientée objet, ce qui devrait convenir à la plupart des usages.

CONSTRUCTEUR

my $p = Getopt::Long::Parser->new( %options );

Le constructeur prend un hachage optionnel avec des paramètres.

config
Une référence de tableau avec des paramètres de configuration. Voir "Configuration de Getopt::Long" dans Getopt::Long pour tous les paramètres possibles.

MÉTHODES

Dans les exemples, $p est supposé être le résultat d'un appel au constructeur.

configure

$p->configure( %settings );

Met à jour les paramètres de configuration actuels. Voir "Configuration de Getopt::Long" dans Getopt::Long pour tous les paramètres possibles.

getoptionsfromarray

my $res = $p->getoptionsfromarray( $aref, @opts );

getoptions

my $res = $p->getoptions( @opts );

Identique à "getoptionsfromarray( \@ARGV, @opts )".
