NOM

Glib::Object - Bindings pour GObject

DESCRIPTION

GObject est la classe objet de base fournie par la bibliothèque gobject. Elle fournit des propriétés d'objet avec un système de notification, et des signaux émettables.

Glib::Object est la classe objet Perl correspondante. Les Glib::Objects sont représentés par des références de hachage bénies, avec une connexion magique à l'objet C sous-jacent.

obtenir et définir

Certaines sous-classes de "Glib::Object" redéfinissent "get" et "set" avec des méthodes plus utiles pour la sous-classe, par exemple "Gtk2::TreeModel" obtenant et définissant le contenu des lignes.

Ceci est généralement fait lorsque la sous-classe n'a pas de propriétés d'objet. Toutes les propriétés d'objet qu'elle ou une sous-classe plus lointaine possède peuvent toujours être accessibles avec "get_property" et "set_property" (avec "find_property" et "list_properties" pour s'en renseigner).

Le code générique pour toute sous-classe d'objet peut utiliser les noms "get_property" et "set_property" pour être sûr d'obtenir les propriétés de l'objet en tant que telles.

Glib::Object

MÉTHODES

objet = $classe->new (...)

•
... (liste) paires clé/valeur, valeurs de propriétés à définir lors de la création

Instancie un Glib::Object de type $classe. Toute paire clé/valeur dans ... est utilisée pour définir les propriétés du nouvel objet ; voir "set". Ceci est conçu pour être hérité par des sous-classes dérivées de Perl (voir Glib::Object::Subclass), mais vous pouvez en fait l'utiliser pour créer n'importe quel type dérivé de GObject.

scalaire = Glib::Object->new_from_pointer ($pointeur, $noinc=FAUX)

  • $pointeur (non signé) un pointeur C sous forme d'entier.
  • $noinc (booléen) si vrai, n'incrémente pas le compteur de références du GObject lors de la création du wrapper Perl. cela signifie généralement que le wrapper Perl possédera l'objet. en général, vous ne voulez pas faire cela, donc la valeur par défaut est fausse.

Crée une référence Perl Glib::Object pour l'objet C pointé par $pointeur. Vous ne devriez en avoir besoin que *très* rarement ; il est destiné à prendre en charge les objets étrangers.

NOTE : la conversion d'un entier arbitraire en GObject peut entraîner un plantage du noyau sans avertissement, car la macro de vérification de type G_OBJECT() tente de déréférencer le pointeur pour trouver une structure GTypeClass, et il n'y a pas de moyen portable de valider le pointeur.

non signé = $objet->get_data ($clé)

•
$clé (chaîne de caractères)

Récupère l'entier stocké sous la clé de données d'objet $clé. Ces valeurs n'ont pas de type ; les conversions de type doivent être effectuées manuellement. Voir "set_data".

$objet->set_data ($clé, $donnée)

  • $clé (chaîne de caractères)
  • $donnée (scalaire)

GObject fournit un mécanisme de données arbitraires qui assigne des entiers non signés à des noms de clés. La fonctionnalité chevauche le hachage utilisé comme instance d'objet Perl, nous recommandons donc fortement d'utiliser des clés de hachage pour stocker vos données. Les valeurs de données GObject ne peuvent pas stocker d'informations de type, elles ne sont donc pas sûres à utiliser pour autre chose que des valeurs entières, et vous devriez vraiment utiliser cette méthode uniquement si vous savez ce que vous faites.

pspec ou undef = $objet_ou_nom_classe->find_property ($nom)

•
$nom (chaîne de caractères)

Trouve la définition de la propriété d'objet $nom pour $objet_ou_nom_classe. Renvoie "undef" s'il n'y a pas de telle propriété. Pour les données retournées, voir Glib::Object::list_properties.

$objet->freeze_notify

Arrête l'émission des signaux "notify" sur $objet. Les signaux sont mis en file d'attente jusqu'à ce que "thaw_notify" soit appelé sur $objet.

$objet->get (...)

•
... (liste) liste de noms de propriétés

Alias pour "get_property" (voir "obtenir et définir" ci-dessus).

$objet->set (clé => $valeur, ...)

•
... (liste) paires clé/valeur

Alias pour "set_property" (voir "obtenir et définir" ci-dessus).

liste = $objet_ou_nom_classe->list_properties

Liste toutes les propriétés de l'objet pour $objet_ou_nom_classe ; les renvoie sous forme de liste de hachages, contenant ces clés :

nom
Le nom de la propriété
type
Le type de la propriété
type_propriétaire
Le type qui possède la propriété
desc
La description de la propriété
flags
Les Glib::ParamFlags de la propriété

$objet->notify ($nom_propriété)

•
$nom_propriété (chaîne de caractères)

Émet un signal "notify" pour la propriété $propriété sur $objet.

pointeur_c = $objet->get_pointer

Complément de "new_from_pointer".

$objet->get_property (...)

Récupère et renvoie les valeurs des propriétés d'objet nommées dans ....

$objet->set_property (clé => $valeur, ...)

Définit les propriétés de l'objet.
