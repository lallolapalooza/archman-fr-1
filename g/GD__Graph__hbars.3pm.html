NOM

GD::Graph::hbars - créer des graphiques à barres avec des barres horizontales

SYNTAXE

use GD::Graph::hbars;

DESCRIPTION

C'est un module wrapper qui est complètement identique à la création d'un objet GD::Graph::bars avec l'attribut "rotate_chart" défini sur une valeur vraie.

VOIR AUSSI

GD::Graph

Remerciements

L'auteur original de la majeure partie du code nécessaire à l'implémentation de ceci était brian d foy, qui m'a envoyé ce module après que je me sois plaint de ne pas avoir le temps d'implémenter des graphiques à barres horizontales. J'ai pris le code qui se trouvait ici et je l'ai distribué dans axestype.pm et bars.pm, pour permettre une meilleure intégration générale. Son code était, à son tour, principalement basé sur une version antérieure de bars.pm et axestype.pm.
