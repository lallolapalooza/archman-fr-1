NOM

GraphicsMagick-config - obtenir des informations sur la version installée de GraphicsMagick

SYNTAXE

GraphicsMagick-config [--cflags] [--cppflags] [--exec-prefix] [--ldflags] [--libs] [--prefix] [--version]

DESCRIPTION

GraphicsMagick-config affiche les options du compilateur et de l'éditeur de liens nécessaires pour compiler et lier des programmes qui utilisent l'interface de programmation d'application (API) de GraphicsMagick.

EXEMPLES

Pour afficher la version de la distribution installée de GraphicsMagick, utilisez :

  GraphicsMagick-config --version

Pour compiler un programme qui appelle l'interface de programmation d'application de GraphicsMagick, utilisez :

  cc `GraphicsMagick-config --cflags --cppflags --ldflags --libs` program.c

OPTIONS

--cflags
Affiche les options du compilateur utilisées pour compiler libMagick.
--cppflags
Affiche les options du préprocesseur nécessaires pour trouver les fichiers d'en-tête C de GraphicsMagick et les définitions afin de garantir que les structures de données de GraphicsMagick correspondent entre votre programme et les bibliothèques installées.
--exec-prefix
Affiche le répertoire sous lequel les binaires et exécutables spécifiques à la cible sont installés.
--ldflags
Affiche les options de l'éditeur de liens nécessaires pour lier la bibliothèque GraphicsMagick.
--libs
Affiche les options de l'éditeur de liens nécessaires pour lier un programme avec libGraphicsMagick.
--version
Affiche la version de la distribution GraphicsMagick sur la sortie standard.
