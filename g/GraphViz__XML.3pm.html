GraphViz::XML(3) Documentation Perl fournie par l'utilisateur GraphViz::XML(3)

NOM

GraphViz::XML - Visualiser XML comme un arbre

SYNOPSIS

use GraphViz::XML;
my $graph = GraphViz::XML->new($xml);
print $g->as_png;

DESCRIPTION

Ce module permet de visualiser facilement le XML sous forme d'arbre. Le XML est difficile à appréhender pour les humains, surtout si le XML est généré par ordinateur. Ce module vise à visualiser le XML sous forme de graphe afin de clarifier sa structure et de faciliter sa compréhension.

Les éléments XML sont représentés par des nœuds en losange, avec des liens vers les éléments qu'ils contiennent. Les données caractères sont représentées dans des nœuds arrondis.

Notez que le module XML::Twig doit être installé.

MÉTHODES

new

C'est le constructeur. Il prend un argument obligatoire, qui est le XML à visualiser. Un objet GraphViz est retourné.

my $graph = GraphViz::XML->new($xml);

as_*

Le XML peut être visualisé dans plusieurs formats graphiques différents. Les méthodes incluent as_ps, as_hpgl, as_pcl, as_mif, as_pic, as_gd, as_gd2, as_gif, as_jpeg, as_png, as_wbmp, as_ismap, as_imap, as_vrml, as_vtx, as_mp, as_fig, as_svg. Voir la documentation de GraphViz pour plus d'informations. Les deux méthodes les plus courantes sont :

# Afficher un fichier au format PNG
print $g->as_png;
# Afficher un fichier au format PostScript
print $g->as_ps;

BOGUES

GraphViz a tendance à réorganiser les nœuds. J'espère trouver bientôt une solution (éventuellement avec des ports).
