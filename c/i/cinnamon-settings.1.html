DESCRIPTIO

N

cinnamon-settings lance l'interface graphique permettant de configurer

Cinnamon.

Elle peut également être utilisée pour lancer l'interface graphique permettant de configurer un module spécifique, d'ajouter des applets à un panneau et de gérer les x

let
s.

MODUL

E

Spécifier un module permet de le configurer directement.
Les modules suivants sont disponibles. Vous pouvez utiliser le nom ou le synonyme.
Les modules avec * ont une interface de configuration avec des onglets. Chaque onglet peut être ouvert directement (voir la section ONGLET ci-dessous).
Les modules avec ** nécessitent les droits root pour ouvrir leur interface de configuration. Ainsi, le seul onglet qui sera toujours ouvert est le

premier.

PANNEAU est le panneau sur lequel l'utilisateur souhaite installer des applets. Le bureau de l'utilisateur peut avoir jusqu'à quatre panneaux.
panel1 est le premier panneau (panneau par défaut).

UUID et

INSTANCE

Les applets, desklets, extensions et thèmes sont les xlets

.

Chaque xlet a un UUID (Universal Unique IDentifier). La structure d'un UUID est nom_du_xlet@auteur, sauf pour les

thèmes.

Il existe deux types de xlets : Système et

Spices.

Les xlets Système se trouvent dans /usr/share/cinnamon/applets/, /usr/share/cinnamon/desklets/ et /usr/share/themes/ ; leur UUID se termine par '@cinnamon.org' sauf pour les thèmes. Il n'y a pas d'extension

système.

Les Spices sont des xlets proposés par des développeurs à l'équipe Cinnamon, qui les évalue et les valide. La description complète de ces Spices peut être trouvée à https://cinnamon-spices.linuxmint.com/.
Les Spices installés par l'utilisateur se trouvent dans ~/.local/share/cinnamon (pour les applets, desklets et extensions) et dans ~/.them

es.

L'argument INSTANCE est réservé aux développeurs. Lorsqu'une applet ou un desklet a plusieurs instan

ces, l'interface de configuration de chacune d'elles peut être ouverte directement par cet argument
INSTANCE. Les utilisateurs n'ont ni la possibilité ni le besoin de connaître la valeur de INSTANCE.
