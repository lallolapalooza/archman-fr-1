DESCRIPTIO

N

Les objets de la classe Cidr peuvent être utilisés pour vérifier si des adresses Internet IP4 appartiennent à des plages d'adresses définies par des spécifications de blocs d'adresses de routage inter-domaine sans classe (CIDR). Les blocs CIDR sont spécifiés sous la forme a.b.c.d/m où a.b.c.d sont les quatre octets d'une spécification d'adresse IP4 en notation pointillée (par ex. 129.125.14.80) et m est une taille de masque (allant de 0 à 32) définissant le nombre de bits de poids fort à conserver tels quels. La spécification CIDR 129.125.14.80/16 définit un réseau de classe B, avec des adresses allant de 129.125.0.0 à 129.125.255.

255.

La taille du masque n'a pas besoin d'être un multiple de 8. Par ex., lorsqu'on spécifie 129.125.14.80/5, seuls les 5 bits de poids fort du premier octet sont fixés, ce qui donne une plage d'adresses allant de 128.0.0.0 à 135.255.255.

255.

Les spécifications CIDR passées à un objet Cidr doivent être de la forme a.b.c.d ou a.b.c.d/m. Si le masque n'est pas spécifié, une taille de masque de 32 est utilisée, définissant effectivement une plage d'adresses d'une seule adresse. Les valeurs de masque de 0 sont ignorées. Les valeurs de masque de 0 sont ignorées par les objets Cidr

.

Lors de la spécification de CIDR sur un flux, les lignes vides et les lignes de commentaire (ayant le caractère dièse (#) comme premier caractère non blanc) sont ignorées. Les lignes non vides doivent commencer par une spécification CIDR, et l'objet Cidr ignorera toutes les informations sur

une ligne suivant un
e spécification CIDR.

EXEMPL

E 
#include <fstream>
#include <iostream>
#include <bobcat/exception>
#ifdef BOBCAT
    #include <bobcat/cidr>
#else
    #include "cidr"
#endif
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    enum Spec
    {
        NONE,
        FILE,
        CIN
    };
    Spec spec = CIN;
    ifstream in;
    if (argc > 1)
    {
        Exception::open(in, argv[1]);       // fichier contenant les spécifications cidr
        spec = FILE;
    }
    while (true)
    {
        string cidrSpec;
        if (spec == CIN)
        {
            cout << "Spécifiez cidr (vide pour quitter) : ";
            if (!getline(cin, cidrSpec) || cidrSpec.empty())
                break;
        }
        try
        {
            Cidr cidr;
            switch (spec)
            {
                case NONE:
                return 0;
                case FILE:
                    cidr.setCidr(in);
                    spec = NONE;
                break;
                case CIN:
                    cidr.setCidr(cidrSpec);
            }
            while (true)
            {
                cout << "Spécifiez l'adresse à tester (vide pour " <<
                    (spec == CIN ? "respec. CIDR" : "quitter") << ") : ";
                string address;
                if (!getline(cin, address) || address.empty())
                    break;
                if (!cidr.match(address))
                {
                    cout << "L'adresse " << address << " n'est pas dans ";
                    if (spec == CIN)
                        cout << cidrSpec << ’\n’;
                    else
                        cout << "les spécifications dans " << argv[1] << ’\n’;
                }
                else
                    cout << "L'adresse " << address << " est dans " << cidr.cidr() <<
                                                                        "\n&quot;
                        "Adresse la plus basse : " << cidr.first() << "\n"
                        "Adresse la plus haute : " << cidr.last() << "\n"
                        "Masque CIDR : " << cidr.mask() << "\n"
                        "Adresse : " << cidr.address() << ’\n’;
            }
        }
        catch (exception const &err)
        {
            cout << "Oups... " << err.what() << "\n"
                    "Réessayez...\n";
        }
    }
}
