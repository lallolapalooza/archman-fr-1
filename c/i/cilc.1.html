NOM

cilc - Générateur de liaisons CIL vers C de Mono

SYNTAXE

cilc [options] assembly target

DESCRIPTION

cilc est le générateur de liaisons CIL vers C de Mono. Il prend en entrée un assembly CIL et génère un répertoire de sources C qui, une fois compilés, fournissent une interface C aux classes contenues dans cet assembly au moyen d'une bibliothèque partagée.

Les sources générées utilisent l'API d'intégration de Mono. Ainsi, un environnement de développement Mono complet doit être disponible sur le système de développement et un environnement d'exécution Mono complet doit être disponible sur les systèmes cibles.
