DESCRIPTION L

a

classe FBB::CinInserter offre une interface de base pour appeler des programmes externes (les dits processus enfants) en lisant leurs flux d'entrée standard. Les flux de sortie standard et d'erreur standard des processus enfants ne sont pas

gérés par défaut par les

objets CinInserter. L'entrée standard de l'enfant est fournie à travers l'objet CinInserter : les informations insérées dans un objet CinInserter sont transmises au flux d'entrée standard du processus enfant. La variable d'environnement PATH n'est pas utilisée lors de l'appel des processus enfants : les programmes des processus enfants doivent être spécifiés à l'aide de chemins. Les objets CinInserter peuvent être utilisés à plusieurs reprises pour exécuter le même ou différents processus enfants. Avant de démarrer le processus enfant suivant, le processus enfant actuel doit avoir terminé. Les arguments passés aux processus enfants peuvent être entourés de guillemets doubles ou simples. Les arguments entourés de guillemets doubles voient leurs guillemets doubles supprimés, tout en interprétant les séquences d'échappement qui peuvent avoir été utilisées à l'intérieur. Les arguments entourés de guillemets simples voient leurs guillemets simples supprimés, tout en acceptant leur contenu tel quel. De plus, des séquences d'échappement non entourées de guillemets peuvent être spécifiées : ces séquences d'échappement sont évaluées et remplacées par les caractères qu'elles représentent (par

exemple,

\100 est converti

en

@). Lorsque des informations de taille ou de structure indéterminées doivent être insérées dans un processus enfant, celui-ci ne peut pas déterminer quand s'arrêter. Cela crée un problème intéressant : le processus enfant démarre, et le processus parent doit attendre que son processus enfant ait fini de traiter son entrée. Mais l'entrée ne peut être transmise au flux d'entrée de l'enfant qu'après le démarrage du processus enfant. Pour résoudre ce problème, InterterFork propose une fonction

membre

execute surchargée, passant les informations au processus enfant via un thread séparé. ESPACE DE NOMS FB

o
Pipe &childInPipe() :
Si les classes dérivées doivent remplacer les membres de redirection, elles ont prob
ablement besoin d'accéder au pipe lu par le processus enfant. Ce membre fournit une

EXEMPL

E 
//#include <bobcat/cininserter>
#include "../cininserter"
#include <iostream>
#include <fstream>
using namespace std;
using namespace FBB;
int main()
{
    CinInserter inserter;
    inserter.execute("/bin/cat");
    ifstream in("build");
    inserter << in.rdbuf();
    cout << "child returns: " << inserter.stop() << ’\n’;
    inserter.execute("/bin/cat");
    in.seekg(0);                    // reset to the beginning
    inserter << in.rdbuf();
    // when immediately followed by another execute, ’stop’ is optional
    inserter.execute("/bin/cat", "a simple text\n");
    inserter.execute("/bin/cat", "a simple text\n");
    bool bret = inserter.execute("/bin/cat", "a simple text\n");
    cout << "direct string insertion: " << bret << ’\n’;
}
