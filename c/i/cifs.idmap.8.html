NOM

cifs.idmap - Aide en espace utilisateur pour le mappage des identifiants pour le système de fichiers Common Internet File System (CIFS)

SYNOPSIS

cifs.idmap [--help|-h] [--timeout|-t] [--version|-v] {identifiant}

DESCRIPTION

Cet outil fait partie de la suite cifs-utils.

cifs.idmap est un programme d'aide en espace utilisateur pour le client du système de fichiers CIFS sous Linux. Il existe un certain nombre d'activités que le noyau ne peut pas facilement effectuer lui-même. Ce programme est un programme d'appel qui effectue ces tâches pour le noyau, puis renvoie le résultat.

cifs.idmap est généralement destiné à être exécuté lorsque le noyau appelle request-key(8) pour un type de clé particulier. Bien qu'il puisse être exécuté directement depuis la ligne de commande, il n'est généralement pas prévu d'être exécuté de cette manière.

Ce programme n'est appelé que si un partage est monté avec l'option de montage cifsacl. Le noyau ne fera l'appel externe que si cette option de montage est spécifiée.

cifs.idmap repose sur un plugin pour gérer le mappage des identifiants. S'il ne trouve pas le plugin, il ne fonctionnera pas correctement. Le plugin (ou un lien symbolique vers celui-ci) doit se trouver dans /etc/cifs-utils/idmap-plugin.

Dans le cas où cifs.idmap ou le plugin ne sont pas disponibles, les objets de fichier dans un partage monté se voient attribuer l'uid et le gid des identifiants du processus qui a monté le partage. Il est fortement recommandé d'utiliser les options de montage uid et gid pour spécifier un uid et gid par défaut afin de mapper les SIDs de propriétaire et les SIDs de groupe dans cette situation.

OPTIONS

--help|-h
Affiche le message d'utilisation et quitte.
--timeout|-t
Définit le minuteur d'expiration, en secondes, de la clé. La valeur par défaut est de 600 secondes (10 minutes). Définir cette valeur à 0 fera que la clé n'expirera jamais.
--version|-v
Affiche le numéro de version et quitte.

CONFIGURATION POUR KEYCTL

cifs.idmap est conçu pour être appelé par le noyau via le programme d'appel request-key. Cela nécessite que request-key soit informé où et comment appeler ce programme. Actuellement, cifs.idmap gère un type de clé de :

cifs.idmap

Ce type de clé sert à mapper un SID à un uid ou un gid.

Pour rendre ce programme utile pour CIFS, vous devrez y ajouter une entrée dans request-key.conf(5). Voici un exemple d'entrée pour ce type de clé :

#OPERATION  TYPE           D C PROGRAM ARG1 ARG2...
#=========  =============  = = ================================
create      cifs.idmap     * * /usr/bin/cifs.idmap %k

Voir request-key.conf(5) pour plus d'informations sur chaque champ.

NOTES

Le support des appels externes vers cifs.idmap a été initialement introduit dans le noyau 3.0.

VOIR AUSSI

request-key.conf(5), mount.cifs(8)
