NOM

cifsiostat - Rapport des statistiques CIFS.

SYNTAXE

cifsiostat [ -h ] [ -k | -m ] [ -t ] [ -U ] [ -V ] [ -y ] [ --dec={ 0 | 1 | 2 } ] [ --human ] [ -o JSON ] [ --pretty ] [ interval [ count ] ]

DESCRIPTION

La commande cifsiostat affiche les statistiques des opérations de lecture et d'écriture sur les systèmes de fichiers CIFS.

Le paramètre interval spécifie le temps en secondes entre chaque rapport. Le premier rapport contient les statistiques depuis le démarrage du système (boot), sauf si l'option -y est utilisée (dans ce cas, le premier rapport est omis). Chaque rapport suivant contient les statistiques collectées pendant l'intervalle depuis le rapport précédent. Un rapport se compose d'une ligne d'en-tête CIFS suivie d'une ligne de statistiques pour chaque système de fichiers CIFS monté. Le paramètre count peut être spécifié conjointement avec le paramètre interval. Si le paramètre count est spécifié, la valeur de count détermine le nombre de rapports générés à interval secondes d'intervalle. Si le paramètre interval est spécifié sans le paramètre count, la commande cifsiostat génère des rapports en continu.

RAPPORT

Le rapport CIFS fournit des statistiques pour chaque système de fichiers CIFS monté. Le rapport affiche les champs suivants :

Système de fichiers:
Cette colonne affiche le point de montage du système de fichiers CIFS.
oB/s (okB/s, oMo/s)
Indique le nombre moyen d'octets (kibioctets, mébioctets) lus par seconde.
eB/s (ekB/s, eMo/s)
Indique le nombre moyen d'octets (kibioctets, mébioctets) écrits par seconde.
rop/s
Indique le nombre d'opérations de "lecture" qui ont été émises vers le système de fichiers par seconde.
wop/s
Indique le nombre d'opérations d' "écriture" qui ont été émises vers le système de fichiers par seconde.
fo/s
Indique le nombre de fichiers ouverts par seconde.
fc/s
Indique le nombre de fichiers fermés par seconde.
fd/s
Indique le nombre de fichiers supprimés par seconde.

OPTIONS

--dec={ 0 | 1 | 2 }
Spécifie le nombre de décimales à utiliser (0 à 2, la valeur par défaut est 2).
-h
Cette option est équivalente à la spécification de --human --pretty.
--human
Affiche les tailles dans un format lisible par l'homme (par exemple 1.0k, 1.2M, etc.). Les unités affichées avec cette option remplacent toutes les autres unités par défaut (par exemple, kibioctets, secteurs...) associées aux métriques.
-k
Affiche les statistiques en kibioctets par seconde.
-m
Affiche les statistiques en mébioctets par seconde.
-o JSON
Affiche les statistiques au format JSON (JavaScript Object Notation). L'ordre des champs de sortie JSON est indéfini et de nouveaux champs pourront être ajoutés à l'avenir.
--pretty
Rend le rapport CIFS plus facile à lire pour un humain.
-t
Affiche l'heure de chaque rapport affiché. Le format de l'horodatage peut dépendre de la valeur de la variable d'environnement S_TIME_FORMAT (voir ci-dessous) et de l'utilisation ou non de l'option -U.
-U
Affiche l'horodatage (UTC - Temps Universel Coordonné) en secondes depuis l'époque.
-V
Affiche le numéro de version puis quitte.
-y
Omet le premier rapport avec les statistiques depuis le démarrage du système, si plusieurs enregistrements sont affichés à l'intervalle donné.

ENVIRONNEMENT

La commande cifsiostat prend en compte les variables d'environnement suivantes :

S_COLORS
Par défaut, les statistiques sont affichées en couleur lorsque la sortie est connectée à un terminal. Utilisez cette variable pour modifier les paramètres. Les valeurs possibles pour cette variable sont never, always ou auto (cette dernière est équivalente aux paramètres par défaut).
Veuillez noter que la couleur (rouge, jaune ou une autre couleur) utilisée pour afficher une valeur n'indique pas un problème, juste différentes plages de valeurs.
S_COLORS_SGR
Spécifie les couleurs et autres attributs utilisés pour afficher les statistiques sur le terminal. Sa valeur est une liste de capacités séparées par des deux-points, par défaut I=32;22:N=34;1:Z=34;22. Les capacités prises en charge sont :
I=
Sous-chaîne SGR pour les noms de système de fichiers.
N=
Sous-chaîne SGR pour les valeurs statistiques non nulles.
Z=
Sous-chaîne SGR pour les valeurs nulles.
S_TIME_FORMAT
Si cette variable existe et que sa valeur est ISO, la locale actuelle sera ignorée lors de l'impression de la date dans l'en-tête du rapport. La commande cifsiostat utilisera plutôt le format ISO 8601 (AAAA-MM-JJ). L'horodatage affiché avec l'option -t sera également conforme au format ISO 8601.

BOGUE

Le système de fichiers /proc doit être monté pour que cifsiostat fonctionne.

Bien que cifsiostat affiche des unités correspondant aux kilo-octets (kB), méga-octets (Mo)..., il utilise en réalité des kibioctets (kiB), mébioctets (MiB)... Un kibioctet est égal à 1024 octets, et un mébioctet est égal à 1024 kibioctets.

FICHIER

/proc/fs/cifs/Stats contient les statistiques CIFS.
