CINNAMON-SCREENSAVER-LOCK-DIALOG(1) Manuel de cinnamon CINNAMON-SCREENSAVER-LOCK-DIALOG(1)

NOM

cinnamon-screensaver-lock-dialog - message pour le dialogue de l'économiseur d'écran cinnamon

SYNTAXE

cinnamon-screensaver-lock-dialog

DESCRIPTION

cinnamon-screensaver-lock-dialog lance l'interface graphique pour définir un message d'absence lors de l'exécution de cinnamon-screensaver.

NOTE

Ce module de dialogue ne fonctionnera que si cinnamon-screensaver est installé. Par conséquent, le bureau Cinnamon n'appellera le dialogue que si ce dernier est effectivement installé.

AUTEUR

cinnamon-screensaver-lock-dialog est écrit par le projet Mint <root@linuxmint.com>.

Cette page de manuel a été écrite par Nicolas Bourdaud <nicolas.bourdaud@gmail.com> pour le projet Debian.
