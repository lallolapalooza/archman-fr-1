CIRCLEQ(3) Manuel des fonctions de bibliothèque CIRCLEQ(3)

NOM

CIRCLEQ_EMPTY, CIRCLEQ_ENTRY, CIRCLEQ_FIRST, CIRCLEQ_FOREACH, CIRCLEQ_FOREACH_REVERSE, CIRCLEQ_HEAD, CIRCLEQ_HEAD_INITIALIZER, CIRCLEQ_INIT, CIRCLEQ_INSERT_AFTER, CIRCLEQ_INSERT_BEFORE, CIRCLEQ_INSERT_HEAD, CIRCLEQ_INSERT_TAIL, CIRCLEQ_LAST, CIRCLEQ_LOOP_NEXT, CIRCLEQ_LOOP_PREV, CIRCLEQ_NEXT, CIRCLEQ_PREV, CIRCLEQ_REMOVE - implémentation d'une file circulaire doublement chaînée

BIBLIOTHÈQUE

Bibliothèque C standard (libc,-lc)

SYNOPSIS

#include <sys/queue.h>
CIRCLEQ_ENTRY(TYPE);
CIRCLEQ_HEAD(HEADNAME, TYPE);
CIRCLEQ_HEAD CIRCLEQ_HEAD_INITIALIZER(CIRCLEQ_HEAD head);
void CIRCLEQ_INIT(CIRCLEQ_HEAD *head);
int CIRCLEQ_EMPTY(CIRCLEQ_HEAD *head);
void CIRCLEQ_INSERT_HEAD(CIRCLEQ_HEAD *head,
                           struct TYPE *elm, CIRCLEQ_ENTRY NAME);
void CIRCLEQ_INSERT_TAIL(CIRCLEQ_HEAD *head,
                           struct TYPE *elm, CIRCLEQ_ENTRY NAME);
void CIRCLEQ_INSERT_BEFORE(CIRCLEQ_HEAD *head, struct TYPE *listelm,
                           struct TYPE *elm, CIRCLEQ_ENTRY NAME);
void CIRCLEQ_INSERT_AFTER(CIRCLEQ_HEAD *head, struct TYPE *listelm,
                           struct TYPE *elm, CIRCLEQ_ENTRY NAME);
struct TYPE *CIRCLEQ_FIRST(CIRCLEQ_HEAD *head);
struct TYPE *CIRCLEQ_LAST(CIRCLEQ_HEAD *head);
struct TYPE *CIRCLEQ_PREV(struct TYPE *elm, CIRCLEQ_ENTRY NAME);
struct TYPE *CIRCLEQ_NEXT(struct TYPE *elm, CIRCLEQ_ENTRY NAME);
struct TYPE *CIRCLEQ_LOOP_PREV(CIRCLEQ_HEAD *head,
                           struct TYPE *elm, CIRCLEQ_ENTRY NAME);
struct TYPE *CIRCLEQ_LOOP_NEXT(CIRCLEQ_HEAD *head,
                           struct TYPE *elm, CIRCLEQ_ENTRY NAME);
CIRCLEQ_FOREACH(struct TYPE *var, CIRCLEQ_HEAD *head,
                           CIRCLEQ_ENTRY NAME);
CIRCLEQ_FOREACH_REVERSE(struct TYPE *var, CIRCLEQ_HEAD *head,
                           CIRCLEQ_ENTRY NAME);
void CIRCLEQ_REMOVE(CIRCLEQ_HEAD *head, struct TYPE *elm,
                           CIRCLEQ_ENTRY NAME);

DESCRIPTION

Ces macros définissent et manipulent des files circulaires doublement chaînées.

Dans les définitions des macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type CIRCLEQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée à l'aide de la macro CIRCLEQ_HEAD().

Création

Une file circulaire est dirigée par une structure définie par la CIRCLEQ_HEAD() macro. Cette structure contient une paire de pointeurs, l'un pointant vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont doublement chaînés afin qu'un élément arbitraire puisse être supprimé sans parcourir la file. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, avant un élément existant, en tête de file, ou en fin de file. Une CIRCLEQ_HEAD structure est déclarée comme suit :


CIRCLEQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à chaîner dans la file. Un pointeur vers la tête de la file peut ensuite être déclaré comme :


struct HEADNAME *headp;

(Les noms head et headp sont choisis par l'utilisateur.)

CIRCLEQ_ENTRY() déclare une structure qui connecte les éléments de la file.

CIRCLEQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file head.

CIRCLEQ_INIT() initialise la file référencée par head.

CIRCLEQ_EMPTY() évalue à vrai s'il n'y a pas d'éléments sur la file.

Insertion

CIRCLEQ_INSERT_HEAD() insère le nouvel élément elm en tête de la file.

CIRCLEQ_INSERT_TAIL() insère le nouvel élément elm en fin de file.

CIRCLEQ_INSERT_BEFORE() insère le nouvel élément elm avant l'élément listelm.

CIRCLEQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

CIRCLEQ_FIRST() renvoie le premier élément de la file.

CIRCLEQ_LAST() renvoie le dernier élément de la file.

CIRCLEQ_PREV() renvoie l'élément précédent de la file, ou &head si cet élément est le premier.

CIRCLEQ_NEXT() renvoie l'élément suivant de la file, ou &head si cet élément est le dernier.

CIRCLEQ_LOOP_PREV() renvoie l'élément précédent de la file. Si elm est le premier élément de la file, le dernier élément est renvoyé.

CIRCLEQ_LOOP_NEXT() renvoie l'élément suivant de la file. Si elm est le dernier élément de la file, le premier élément est renvoyé.

CIRCLEQ_FOREACH() parcourt la file référencée par head dans le sens direct, en assignant chaque élément à tour de rôle à var. var est défini à &head si la boucle se termine normalement, ou s'il n'y avait pas d'éléments.

CIRCLEQ_FOREACH_REVERSE() parcourt la file référencée par head dans le sens inverse, en assignant chaque élément à tour de rôle à var.

Suppression

CIRCLEQ_REMOVE() supprime l'élément elm de la file.

VALEUR RENVOYÉE

CIRCLEQ_EMPTY() renvoie une valeur non nulle si la file est vide, et zéro si la file contient au moins une entrée.

CIRCLEQ_FIRST(), CIRCLEQ_LAST(), CIRCLEQ_LOOP_PREV(), et CIRCLEQ_LOOP_NEXT() renvoient un pointeur vers la structure TYPE première, dernière, précédente ou suivante, respectivement.

CIRCLEQ_PREV(), et CIRCLEQ_NEXT() sont similaires à leurs homologues CIRCLEQ_LOOP_*(), sauf que si l'argument est respectivement le premier ou le dernier élément, elles renvoient &head.

CIRCLEQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la file head.

NORMES

BSD.

ANOMALIES

CIRCLEQ_FOREACH() et CIRCLEQ_FOREACH_REVERSE() ne permettent pas à var d'être supprimé ou libéré à l'intérieur de la boucle, car cela interférerait avec le parcours. CIRCLEQ_FOREACH_SAFE() et CIRCLEQ_FOREACH_REVERSE_SAFE(), qui sont présentes sur les BSD mais ne sont pas présentes dans glibc, corrigent cette limitation en permettant à var d'être supprimé de la liste et libéré de l'intérieur de la boucle sans interférer avec le parcours.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    CIRCLEQ_ENTRY(entry) entries;           /* File */
};
CIRCLEQ_HEAD(circlehead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct circlehead head;                 /* Tête de file */
    int i;
    CIRCLEQ_INIT(&head);                    /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insérer en tête */
    CIRCLEQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insérer en queue */
    CIRCLEQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    CIRCLEQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insérer avant */
    CIRCLEQ_INSERT_BEFORE(&head, n2, n3, entries);
    CIRCLEQ_REMOVE(&head, n2, entries);     /* Suppression */
    free(n2);
                                            /* Traversée en avant */
    i = 0;
    CIRCLEQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Traversée en arrière */
    CIRCLEQ_FOREACH_REVERSE(np, &head, entries)
        printf("%i\n", np->data);
                                            /* Suppression de la file */
    n1 = CIRCLEQ_FIRST(&head);
    while (n1 != (void *)&head) {
        n2 = CIRCLEQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    CIRCLEQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
