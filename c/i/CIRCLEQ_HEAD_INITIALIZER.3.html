DESCRIPTIO

N

Ces macros définissent et manipulent des files circulaires doublement

chaînées.

Dans les définitions des macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type CIRCLEQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée à l'aide de la macro CIRCLEQ_HE

AD().

Créatio

n

Une file circulaire est dirigée par une structure définie par la macro CIRCLEQ_HEAD(). Cette structure contient une paire de pointeurs, l'un pointant vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont doublement chaînés afin qu'un élément arbitraire puisse être supprimé sans parcourir la file. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, avant un élément existant, en tête de file, ou en fin de file. Une structure CIRCLEQ_HEAD est déclarée comme suit

: 


CIRCLEQ_HEAD(HEADNAME, TYPE)
head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à chaîner dans la file. Un pointeur vers la tête de la file peut ensuite être déclaré comme

: 


struct HEADNAME
*headp;

(Les noms head et headp sont choisis par l'utilisateur.

)

CIRCLEQ_ENTRY() déclare une structure qui connecte les éléments de la

file.

CIRCLEQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file head

.

CIRCLEQ_INIT() initialise la file référencée par head

.

CIRCLEQ_EMPTY() évalue à vrai s'il n

'y a pas d'élément
s sur la file.

n

CIRCLEQ_INSERT_HEAD() insère le nouvel élément elm en tête de la

file.

CIRCLEQ_INSERT_TAIL() insère le nouvel élément elm en fin de

file.

CIRCLEQ_INSERT_BEFORE() insère le nouvel élément elm avant l'élément listelm

.

CIRCLEQ_INSERT_AFTER() insère le nouvel élément elm après l'élément list

el

Parcour

s

CIRCLEQ_FIRST() renvoie le premier élément de la

file.

CIRCLEQ_LAST() renvoie le dernier élément de la

file.

CIRCLEQ_PREV() renvoie l'élément précédent de la file, ou &head si cet élément est le

premier.

CIRCLEQ_NEXT() renvoie l'élément suivant de la file, ou &head si cet élément est le

dernier.

CIRCLEQ_LOOP_PREV() renvoie l'élément précédent de la file. Si elm est le premier élément de la file, le dernier élément est

renvoyé.

CIRCLEQ_LOOP_NEXT() renvoie l'élément suivant de la file. Si elm est le dernier élément de la file, le premier élément est

renvoyé.

CIRCLEQ_FOREACH() parcourt la file référencée par head dans le sens direct, en assignant chaque élément à son tour à var. var est défini à &head si la boucle se termine normalement, ou s'il n'y avait pas

d'éléments.

CIRCLEQ_FOREACH_REVERSE() parcourt la file référencée par head dans le sens inverse, en assignant chaque élément à son tour à va

r

RENVOYÉE

CIRCLEQ_EMPTY() renvoie une valeur non nulle si la file est vide, et zéro si la file contient au moins une

entrée.

CIRCLEQ_FIRST(), CIRCLEQ_LAST(), CIRCLEQ_LOOP_PREV(), et CIRCLEQ_LOOP_NEXT() renvoient un pointeur vers la structure TYPE première, dernière, précédente ou suivante,

respectivement.

CIRCLEQ_PREV(), et CIRCLEQ_NEXT() sont similaires à leurs équivalents CIRCLEQ_LOOP_*(), sauf que si l'argument est le premier ou le dernier élément, respectivement, elles renvoient &head

BOGUE

S

CIRCLEQ_FOREACH() et CIRCLEQ_FOREACH_REVERSE() ne permettent pas à var d'être supprimé ou libéré à l'intérieur de la boucle, car cela interférerait avec le parcours. CIRCLEQ_FOREACH_SAFE() et CIRCLEQ_FOREACH_REVERSE_SAFE(), qui sont présentes sur les BSD mais ne sont pas présentes dans glibc, corrigent cette limitation en permettant à var d'être supprimé en toute sécurité de la liste et libéré de

puis l'intérieur de la boucle sans
interférer avec le parcours.

EXEMPLE

S 
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    CIRCLEQ_ENTRY(entry) entries;           /* File */
};
CIRCLEQ_HEAD(circlehead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct circlehead head;                 /* Tête de file */
    int i;
    CIRCLEQ_INIT(&head);                    /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insérer en tête */
    CIRCLEQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insérer en queue */
    CIRCLEQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    CIRCLEQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insérer avant */
    CIRCLEQ_ININSERER_AVANT(&head, n2, n3, entries);
    CIRCLEQ_REMOVE(&head, n2, entries);     /* Suppression */
    free(n2);
                                            /* Traversée en avant */
    i = 0;
    CIRCLEQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Traversée en arrière */
    CIRCLEQ_FOREACH_REVERSE(np, &head, entries)
        printf("%i\n", np->data);
                                            /* Suppression de la file */
    n1 = CIRCLEQ_FIRST(&head);
    while (n1 != (void *)&head) {
        n2 = CIRCLEQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    CIRCLEQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
