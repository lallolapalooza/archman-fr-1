Nom

ciptool - Profil d'accès ISDN commun Bluetooth (CIP)

SYNTAXE

ciptool [OPTIONS] COMMANDES

DESCRIPTION

ciptool(1) est utilisé pour configurer, maintenir et inspecter la configuration CIP du sous-système Bluetooth dans le noyau Linux.

OPTIONS

-i <hciX|BDADDR>
La commande est appliquée au périphérique hciX, qui doit être le nom ou l'adresse d'un périphérique Bluetooth installé.

Si elle n'est pas spécifiée, la commande utilisera le premier périphérique Bluetooth disponible.

-h, --help
Afficher les options d'aide

COMMANDES

show
Afficher les informations sur les périphériques connectés.
search
Rechercher les périphériques Bluetooth et se connecter au premier qui offre le support CIP.
connect <BDADDR> [PSM]
Connecter le périphérique local au périphérique Bluetooth distant sur le numéro PSM spécifié. Si aucun PSM n'est spécifié, SDP sera utilisé pour le récupérer auprès du périphérique distant.
release [BDADDR]
Libérer une connexion vers le périphérique spécifié. Si aucun BDADDR n'est donné et qu'un seul périphérique est connecté, celui-ci sera libéré.
loopback <BDADDR> [PSM]
Créer une connexion vers le périphérique distant pour les tests Bluetooth. Cette commande ne fournira pas de contrôleur CAPI, car elle est uniquement destinée à tester le protocole de transport de messages CAPI.
