GNOME-SESSION(1) Manuel des commandes générales GNOME-SESSION(1)

NOM

cinnamon-session - Lancer l'environnement de bureau GNOME

SYNTAXE

cinnamon-session [-a|--autostart=DIR] [--session=SESSION] [--failsafe|-f] [--debug] [--whale]

DESCRIPTION

Le programme cinnamon-session lance l'environnement de bureau GNOME. Cette commande est généralement exécutée par votre gestionnaire de connexion (mdm, xdm, ou depuis vos scripts de démarrage X). Il chargera soit votre session sauvegardée, soit il fournira une session par défaut pour l'utilisateur telle que définie par l'administrateur système (ou l'installation GNOME par défaut sur votre système).

La session par défaut est définie dans gnome.session, un fichier de type .desktop recherché dans $XDG_CONFIG_HOME/cinnamon-session/sessions, $XDG_CONFIG_DIRS/cinnamon-session/sessions et $XDG_DATA_DIRS/cinnamon-session/sessions.

Lors de la sauvegarde d'une session, cinnamon-session sauvegarde les applications en cours d'exécution dans le répertoire $XDG_CONFIG_HOME/cinnamon-session/saved-session.

cinnamon-session est un gestionnaire de session X11R6. Il peut gérer les applications GNOME ainsi que toute application compatible X11R6 SM.

OPTIONS

Les options suivantes sont supportées :

--autostart=DIR
Lance toutes les applications définies dans DIR, au lieu de lancer les applications définies dans gnome.session, ou via l'option --session. Plusieurs options --autostart peuvent être passées.
--session=SESSION
Utilise les applications définies dans SESSION.session. Si non spécifié, gnome.session sera utilisé.
--failsafe
Exécute en mode de sécurité. Les applications spécifiées par l'utilisateur ne seront pas lancées.
--debug
Active le code de débogage.
--whale
Affiche la baleine de défaillance (fail whale) dans une boîte de dialogue pour le débogage.

DÉFINITION DE SESSION

Les sessions sont définies dans des fichiers .session, qui utilisent un format similaire à .desktop, avec les clés suivantes dans le groupe GNOME Session :

Name
Nom de la session. Peut être localisé.
RequiredComponents
Liste des identifiants de composants (fichiers desktop) requis par la session. Les composants requis seront toujours exécutés dans la session.
RequiredProviders
Liste des fournisseurs de tâches requis par la session. Un fournisseur par défaut pour chaque tâche doit être défini avec une clé DefaultProvider-TASK ; le fournisseur peut être remplacé par les composants requis, la session sauvegardée ou les applications de démarrage automatique. Les fournisseurs de tâches seront toujours exécutés dans la session.
DefaultProvider-TASK
Identifiant (fichier desktop) du fournisseur par défaut pour TASK. Si aucun fournisseur pour TASK n'est trouvé dans les composants requis, la session sauvegardée et les applications de démarrage automatique, le fournisseur par défaut sera lancé.

Voici un exemple de définition de session :


[GNOME Session]
Name=GNOME fallback
RequiredComponents=gnome-panel;metacity;gnome-settings-daemon;
RequiredProviders=notifications;
DefaultProvider-notifications=notification-daemon

Les fichiers .session sont recherchés dans $XDG_CONFIG_HOME/cinnamon-session/sessions, $XDG_CONFIG_DIRS/cinnamon-session/sessions et $XDG_DATA_DIRS/cinnamon-session/sessions.

ENVIRONNEMENT

cinnamon-session définit plusieurs variables d'environnement pour l'utilisation de ses processus enfants :

SESSION_MANAGER

Cette variable est utilisée par les clients conscients du gestionnaire de session pour contacter cinnamon-session.

DISPLAY

Cette variable est définie sur l'affichage X utilisé par cinnamon-session. Notez que si l'option --display est utilisée, cela pourrait être différent du réglage de la variable d'environnement lorsque cinnamon-session est invoqué.

FICHIERS

$XDG_CONFIG_HOME/config/autostart $XDG_CONFIG_DIRS/config/autostart /usr/share/gnome/autostart

Les applications définies dans ces répertoires seront lancées à la connexion. cinnamon-settings(1) peut être utilisé pour les configurer facilement.

$XDG_CONFIG_HOME/cinnamon-session/sessions $XDG_CONFIG_DIRS/cinnamon-session/sessions $XDG_DATA_DIRS/cinnamon-session/sessions

Ces répertoires contiennent les fichiers .session qui peuvent être utilisés avec l'option --session.

$XDG_CONFIG_HOME/cinnamon-session/saved-session

Ce répertoire contient la liste des applications de la session sauvegardée.
