NOM

cb_console_runner - Lanceur de programmes console pour l'IDE Code::Blocks

SYNTAXE

cb_console_runner arguments

DESCRIPTION

cb_console_runner fait partie de l'IDE Code::Blocks. Il est utilisé pour lancer des programmes console et attendre qu'ils se terminent. Lorsque le programme console est terminé, cb_console_runner affiche "Appuyez sur ENTREE pour continuer".

C'est son unique rôle.

OPTIONS

Aucune option.

EXEMPLES

cb_console_runner /home/utilisateur/programme_test --arg1_prog
