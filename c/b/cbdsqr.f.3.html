Documentation de la fonction/sous-routine

subroutine cbdsqr (character uplo, integer n, integer ncvt, integer nru, integer ncc, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( ldvt, * ) vt, integer ldvt, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( ldc, * ) c, integer ldc, real, dimension( * ) rwork, integer info)

CBDSQR

But :

!>
!> CBDSQR calcule les valeurs singulières et, éventuellement, les vecteurs singuliers
!> à droite et/ou à gauche à partir de la décomposition en valeurs singulières (SVD)
!> d'une matrice réelle N-par-N (supérieure ou inférieure) bidiagonale B en utilisant
!> l'algorithme QR implicite à décalage zéro. La SVD de B a la forme
!>
!>    B = Q * S * P**H
!>
!> où S est la matrice diagonale des valeurs singulières, Q est une matrice orthogonale
!> de vecteurs singuliers gauches, et P est une matrice orthogonale de vecteurs
!> singuliers droits. Si des vecteurs singuliers gauches sont demandés, cette sous-routine
!> retourne en fait U*Q au lieu de Q, et, si des vecteurs singuliers droits sont demandés,
!> cette sous-routine retourne P**H*VT au lieu de P**H, pour les matrices d'entrée complexes
!> données U et VT. Lorsque U et VT sont les matrices unitaires qui réduisent une matrice
!> générale A à une forme bidiagonale : A = U*B*VT, comme calculé par CGEBRD, alors
!>
!>    A = (U*Q) * S * (P**H*VT)
!>
!> est la SVD de A. Éventuellement, la sous-routine peut également calculer Q**H*C
!> pour une matrice d'entrée complexe donnée C.
!>
!> Voir  par J. Demmel et W. Kahan,
!> LAPACK Working Note #3 (ou SIAM J. Sci. Statist. Comput. vol. 11,
!> no. 5, pp. 873-912, Sept 1990) et
!>  par
!> B. Parlett et V. Fernando, Technical Report CPAM-554, Mathematics
!> Department, University of California at Berkeley, July 1992
!> pour une description détaillée de l'algorithme.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  B est upper bidiagonale ;
!>          = 'L' :  B est lower bidiagonale.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B.  N >= 0.
!>

NCVT

!>          NCVT est INTEGER
!>          Le nombre de colonnes de la matrice VT. NCVT >= 0.
!>

NRU

!>          NRU est INTEGER
!>          Le nombre de lignes de la matrice U. NRU >= 0.
!>

NCC

!>          NCC est INTEGER
!>          Le nombre de colonnes de la matrice C. NCC >= 0.
!>

D

!>          D est tableau de type REAL, dimension (N)
!>          En entrée, les N éléments diagonaux de la matrice bidiagonale B.
!>          En sortie, si INFO=0, les valeurs singulières de B par ordre décroissant.
!>

E

!>          E est tableau de type REAL, dimension (N-1)
!>          En entrée, les N-1 éléments hors diagonale de la matrice bidiagonale
!>          B.
!>          En sortie, si INFO = 0, E est détruit ; si INFO > 0, D et E
!>          contiendront les éléments diagonaux et superdiagonaux d'une
!>          matrice bidiagonale orthogonalement équivalente à celle donnée
!>          en entrée.
!>

VT

!>          VT est tableau de type COMPLEX, dimension (LDVT, NCVT)
!>          En entrée, une matrice N-par-NCVT VT.
!>          En sortie, VT est écrasé par P**H * VT.
!>          Non référencé si NCVT = 0.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT.
!>          LDVT >= max(1,N) si NCVT > 0 ; LDVT >= 1 si NCVT = 0.
!>

U

!>          U est tableau de type COMPLEX, dimension (LDU, N)
!>          En entrée, une matrice NRU-par-N U.
!>          En sortie, U est écrasé par U * Q.
!>          Non référencé si NRU = 0.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U.  LDU >= max(1,NRU).
!>

C

!>          C est tableau de type COMPLEX, dimension (LDC, NCC)
!>          En entrée, une matrice N-par-NCC C.
!>          En sortie, C est écrasé par Q**H * C.
!>          Non référencé si NCC = 0.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C.
!>          LDC >= max(1,N) si NCC > 0 ; LDC >=1 si NCC = 0.
!>

RWORK

!>          RWORK est tableau de type REAL, dimension (LRWORK)
!>          LRWORK = 4*N, si NCVT = NRU = NCC = 0, et
!>          LRWORK = 4*(N-1), sinon
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  fin réussie
!>          < 0 :  Si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  l'algorithme n'a pas convergé ; D et E contiennent les
!>                éléments d'une matrice bidiagonale orthogonalement similaire
!>                à la matrice d'entrée B ;  si INFO = i, i
!>                éléments de E n'ont pas convergé vers zéro.
!>

Paramètres internes :

!>  TOLMUL  REAL, défaut = max(10,min(100,EPS**(-1/8)))
!>          TOLMUL contrôle le critère de convergence de la boucle QR.
!>          S'il est positif, TOLMUL*EPS est la précision relative
!>             souhaitée dans les valeurs singulières calculées.
!>          S'il est négatif, abs(TOLMUL*EPS*sigma_max) est la
!>             précision absolue souhaitée dans les valeurs singulières
!>             calculées (correspondant à une précision relative
!>             abs(TOLMUL*EPS) dans la plus grande valeur singulière.
!>          abs(TOLMUL) doit être compris entre 1 et 1/EPS, et de préférence
!>             entre 10 (pour une convergence rapide) et .1/EPS
!>             (pour une certaine précision dans les résultats).
!>          Défaut : perdre soit un huitième, soit 2 des
!>             chiffres décimaux disponibles dans chaque valeur singulière
!>             calculée (le plus petit des deux).
!>
!>  MAXITR  INTEGER, défaut = 6
!>          MAXITR contrôle le nombre maximum de passages de l'algorithme
!>          à travers sa boucle interne. L'algorithme s'arrête
!>          (et donc échoue à converger) si le nombre de passages
!>          à travers la boucle interne dépasse MAXITR*N**2.
!>
!>

Note :

!>  Rapport de bug de Cezary Dendek.
!>  Le 3 novembre 2023, la variable entière MAXIT = MAXITR*N**2 est
!>  supprimée car elle peut facilement déborder (pour N supérieur ou égal
!>  à 18 919). Nous utilisons à la place MAXITDIVN = MAXITR*N.
!>
