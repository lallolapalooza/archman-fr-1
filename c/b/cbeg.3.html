!> Programme de test pour les Blas de niveau 2 COMPLEX.

!> Le programme doit être piloté par un court fichier de données. Les 18
!> premiers enregistrements du fichier sont lus à l'aide d'une entrée
!> dirigée par liste, les 17 derniers enregistrements sont lus avec le
!> format ( A6, L2 ). Un exemple annoté d'un fichier de données peut
!> être obtenu en supprimant les 3 premiers caractères des 35 lignes
!> suivantes :
!> 'cblat2.out'      NOM DU FICHIER DE SORTIE DU RÉSUMÉ
!> 6                 NUMÉRO D'UNITÉ DU FICHIER DE RÉSUMÉ
!> 'CBLA2T.SNAP'     NOM DU FICHIER DE SORTIE D'INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER D'INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        DRAPEAU LOGIQUE, T POUR REMBOBINER LE FICHIER D'INSTANTANÉ APRÈS CHAQUE ENREGISTREMENT.
!> F        DRAPEAU LOGIQUE, T POUR S'ARRÊTER EN CAS D'ÉCHECS.
