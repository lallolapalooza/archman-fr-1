CBDT05

Documentation de la fonction/sous-routine

sous-routine cbdt05 (integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) s, integer ns, complex, dimension( * ) u, integer ldu, complex, dimension( ldvt, * ) vt, integer ldvt, complex, dimension( * ) work, real resid)

CBDT05

Objectif :

!>
!> CBDT05 reconstruit une matrice bidiagonale B à partir de sa SVD (partielle) :
!>    S = U' * B * V
!> où U et V sont des matrices orthogonales et S est diagonale.
!>
!> Le ratio de test pour tester la décomposition en valeurs singulières est
!>    RESID = norm( S - U' * B * V ) / ( n * norm(B) * EPS )
!> où VT = V' et EPS est la précision machine.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes des matrices A et U.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes des matrices A et VT.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          La matrice A de taille m par n.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

S

!>          S est un tableau RÉEL, dimension (NS)
!>          Les valeurs singulières de la SVD (partielle) de B, triées par
!>          ordre décroissant.
!>

NS

!>          NS est un ENTIER
!>          Le nombre de valeurs/vecteurs singuliers de la SVD (partielle)
!>          de B.
!>

U

!>          U est un tableau COMPLEXE, dimension (LDU,NS)
!>          La matrice orthogonale U de taille n par ns dans S = U' * B * V.
!>

LDU

!>          LDU est un ENTIER
!>          La dimension principale du tableau U. LDU >= max(1,N)
!>

VT

!>          VT est un tableau COMPLEXE, dimension (LDVT,N)
!>          La matrice orthogonale V de taille n par ns dans S = U' * B * V.
!>

LDVT

!>          LDVT est un ENTIER
!>          La dimension principale du tableau VT.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (M,N)
!>

RESID

!>          RESID est un RÉEL
!>          Le ratio de test :  norm(S - U' * A * V) / ( n * norm(A) * EPS )
!>
