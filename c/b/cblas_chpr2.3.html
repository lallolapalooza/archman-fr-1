NAME


cblas_stbsv - solve a triangular band system of linear equations






SYNOPSIS


                void cblas_stbsv(
                   CBLAS_LAYOUT layout,
                   CBLAS_UPLO Uplo,
                   CBLAS_TRANSPOSE TransA,
                   CBLAS_DIAG Diag,
                   const CBLAS_INT N,
                   const CBLAS_INT K,
                   const float *A,
                   const CBLAS_INT lda,
                   float *X,
                   const CBLAS_INT incX
               );







PURPOSE


cblas_stbsv solves one of the systems of linear equations




A*x = b,


or


A^T*x = b,


or


A^H*x = b,




where A is a triangular band matrix, x and b are vectors, and A^T is the transpose of A and A^H is the conjugate transpose of A.


A band matrix is a special case of a general matrix. The matrix A is assumed to be stored in a way that takes advantage of its band structure. The parameter K specifies the number of super- or sub-diagonals of the matrix A.






ARGUMENTS




 


 Specifies whether matrix storage is row-major or column-major.

 See below.




 


 Specifies whether A is upper or lower triangular.

    

  • CBLAS_UPPER

  • CBLAS_LOWER
    • 





 


 Specifies the form of the system of equations to be solved.

    

  • CBLAS_NO_TRANS

  • CBLAS_TRANS

  • CBLAS_CONJ_TRANS
    • 





 


 Specifies whether A is unit triangular or not.

    

  • CBLAS_UNIT

  • CBLAS_NON_UNIT
    • 





 


 Specifies the order of the triangular band matrix A. N must be at least 0.


 


 Specifies the number of super-diagonals (if Uplo is CBLAS_UPPER) or sub-diagonals (if Uplo is CBLAS_LOWER) of the matrix A. K must be at least 0.


 


 The matrix A. This argument must be a lda*N matrix of real values.


 


 Specifies the leading dimension of the matrix A. lda must be at least K+1.


 


 On entry, the right-hand side vector b. On exit, overwritten by the solution vector x.


 


 Specifies the increment between consecutive elements of X.








layout


Specifies the storage format for the matrix A. This parameter can take the following values:


    

  • CBLAS_ROW_MAJOR: row-major storage
    • 

  • CBLAS_COL_MAJOR: column-major storage
    • 







COMPUTATION


In the case of the row-major layout, A is a matrix of size N x N. The upper K super-diagonals and the main diagonal are stored in rows 0 to K, columns 0 to N-1. The lower K sub-diagonals and the main diagonal are stored in rows 0 to K, columns 0 to N-1.


In the case of the column-major layout, A is a matrix of size N x N. The upper K super-diagonals and the main diagonal are stored in columns 0 to K, rows 0 to N-1. The lower K sub-diagonals and the main diagonal are stored in columns 0 to K, rows 0 to N-1.


The parameter lda must be at least K+1. The parameter N must be at least 0.






EXAMPLE


Consider the following system of equations:


A*x = b


where


A =


1.0  2.0  0.0  0.0
3.0  4.0  5.0  0.0
0.0  6.0  7.0  8.0
0.0  0.0  9.0 10.0



and


b = [1.0, 2.0, 3.0, 4.0]^T



The matrix A is an upper triangular band matrix with K=2. The matrix A is stored as:


A = [ 1.0  2.0  5.0  8.0 ]
    [ 3.0  4.0  7.0 10.0 ]
    [ 0.0  6.0  0.0  0.0 ]



This corresponds to the row-major layout. The leading dimension lda is 3.


The call to solve this system is:


float A[3][4] = { {1.0, 2.0, 5.0, 8.0}, {3.0, 4.0, 7.0, 10.0}, {0.0, 6.0, 0.0, 0.0} };
float b[4] = {1.0, 2.0, 3.0, 4.0};
cblas_stbsv(CBLAS_ROW_MAJOR, CBLAS_UPPER, CBLAS_NO_TRANS, CBLAS_NON_UNIT, 4, 2, A, 3, b, 1);
