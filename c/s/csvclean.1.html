Sorti

csvclean tente d'effectuer les corrections sélectionnées. Ensuite

:
  • Si l'option --omit-error-rows est définie, seules les lignes qui passent les vérifications sélectionnées sont écrites sur la sortie standard. Sinon, toutes les lignes sont écrites sur la sortie
    • standard.
  • Si des vérifications sont activées, les lignes en erreur, avec les numéros de ligne et les de
    • scriptions, sont écrites sur

usage : csvclean [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
                [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-S] [-H]

Corrige les erreurs courantes dans un fichier CSV.
arguments positionnels :
  FILE                  Le fichier CSV sur lequel opérer. S'il est omis, les
                        données d'entrée seront acceptées via STDIN sous forme
de flux pipé. arguments facultatifs : -h, --help affiche ce message d'aide et quitte --length-mismatch signale les lignes de données plus courtes ou plus longues que la ligne d'en-tête. --empty-columns signale les colonnes vides comme erreurs. -a, --enable-all-checks active tous les rapports d'erreurs. --omit-error-rows omet les lignes de données contenant des erreurs de la
sortie standard. --label LABEL ajoute une colonne "label" à la sortie d'erreur standard. Utile dans les flux de travail automatisés. Utilisez "-" pour utiliser par défaut le nom de fichier d'entrée. --header-normalize-space supprime les espaces de début et de fin et remplace les séquences de caractères d'espace par une seule espace
dans l'en-tête. --join-short-rows fusionne les lignes courtes en une seule ligne. --separator SEPARATOR la chaîne utilisée pour joindre les lignes courtes. Par défaut, un saut de ligne. --fill-short-rows remplit les lignes courtes avec les cellules manquantes. --fillvalue FILLVALUE la valeur utilisée pour remplir les lignes courtes. Par défaut, aucune.
