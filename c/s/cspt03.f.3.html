Documentation de la fonction/sous-programme

sous-routine cspt03 (caractère uplo, entier n, complexe, dimension( * ) a, complexe, dimension( * ) ainv, complexe, dimension( ldw, * ) work, entier ldw, réel, dimension( * ) rwork, réel rcond, réel resid)

CSPT03

But:

!>
!> CSPT03 calcule le résidu pour une matrice symétrique complexe empaquetée
!> multipliée par son inverse :
!>    norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique complexe A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est tableau COMPLEX, dimension (N*(N+1)/2)
!>          La matrice symétrique complexe originale A, stockée comme une matrice
!>          triangulaire empaquetée.
!>

AINV

!>          AINV est tableau COMPLEX, dimension (N*(N+1)/2)
!>          L'inverse (symétrique) de la matrice A, stockée comme une matrice
!>          triangulaire empaquetée.
!>

WORK

!>          WORK est tableau COMPLEX, dimension (LDW,N)
!>

LDW

!>          LDW est INTEGER
!>          La dimension principale du tableau WORK.  LDW >= max(1,N).
!>

RWORK

!>          RWORK est tableau REAL, dimension (N)
!>

RCOND

!>          RCOND est REAL
!>          L'inverse du nombre de condition de A, calculé comme
!>          ( 1/norm(A) ) / norm(AINV).
!>

RESID

!>          RESID est REAL
!>          norm(I - A*AINV) / ( N * norm(A) * norm(AINV) * EPS )
!>
