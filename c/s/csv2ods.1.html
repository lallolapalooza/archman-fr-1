CSV2ODS(1) Commandes utilisateur CSV2ODS(1)



NOM
csv2ods - Créer une feuille de calcul OpenDocument à partir de valeurs séparées par des virgules



SYNOPSIS

csv2ods -i fichier.csv -o fichier.ods



DESCRIPTION

Ce programme lit un fichier au format CSV - tableau de colonnes délimitées par des virgules, des tabulations ou tout autre caractère. Il crée ensuite une feuille de calcul. Si une valeur ressemble à un nombre, la cellule est également formatée comme un nombre.



OPTIONS

--version

Afficher le numéro de version du programme et quitter

-h, --help

Afficher le message d'aide et quitter

-i INPUT, --input=INPUT

Fichier d'entrée au format csv.

-o OUTPUT, --output=OUTPUT

Fichier de sortie au format ods.

-d DELIMITER, --delimiter=DELIMITER

Spécifie une chaîne d'un seul caractère à utiliser comme séparateur de champ. La valeur par défaut est ",".

-c ENCODING, --encoding=ENCODING

Spécifie l'encodage du fichier csv. La valeur par défaut est utf-8.

-t TABLENAME, --table=TABLENAME

Le nom de la table dans le fichier de sortie.

-s SKIPINITIALSPACE, --skipinitialspace=SKIPINITIALSPACE

Spécifie comment interpréter les espaces blancs qui suivent immédiatement un délimiteur. La valeur par défaut est Faux, ce qui signifie que les espaces blancs suivant immédiatement un délimiteur font partie du champ suivant.

-l LINETERMINATOR, --lineterminator=LINETERMINATOR

Spécifie la séquence de caractères qui doit terminer les lignes.

-q QUOTING, --quoting=QUOTING

Peut prendre l'une des constantes de module suivantes : 0 = QUOTE_MINIMAL ne fait que lorsque c'est nécessaire, par exemple, lorsqu'un champ contient soit le caractère de citation, soit le délimiteur. 1 = QUOTE_ALL signifie que les guillemets sont toujours placés autour des champs. 2 = QUOTE_NONNUMERIC signifie que les guillemets sont toujours placés autour des champs qui ne peuvent pas être analysés comme des nombres entiers ou à virgule flottante. 3 = QUOTE_NONE signifie que les guillemets ne sont jamais placés autour des champs. La valeur par défaut est QUOTE_MINIMAL.

-e ESCAPECHAR, --escapechar=ESCAPECHAR

Spécifie une chaîne d'un seul caractère utilisée pour échapper le délimiteur lorsque le mode de citation est défini sur QUOTE_NONE.

-r QUOTECHAR, --quotechar=QUOTECHAR

Spécifie une chaîne d'un seul caractère à utiliser comme caractère de citation. La valeur par défaut est ".



EXEMPLE

csv2ods -i /etc/passwd -o accounts.odt -d:
