Documentation de la fonction/sous-routine

sous-routine csrot (integer n, complex, dimension( * ) cx, integer incx, complex, dimension( * ) cy, integer incy, real c, real s)

CSROT

But :

!>
!> CSROT applique une rotation de plan, où le cosinus et le sinus (c et s) sont réels
!> et les vecteurs cx et cy sont complexes.
!> jack dongarra, linpack, 3/11/78.
!>

Paramètres

N 
!>          N est un ENTIER
!>           En entrée, N spécifie l'ordre des vecteurs cx et cy.
!>           N doit être supérieur ou égal à zéro.
!>

CX

!>          CX est un tableau COMPLEXE, de dimension au moins
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Avant l'entrée, le tableau incrémenté CX doit contenir les n
!>           éléments du vecteur cx. En sortie, CX est écrasé par le vecteur
!>           mis à jour cx.
!>

INCX

!>          INCX est un ENTIER
!>           En entrée, INCX spécifie l'incrément pour les éléments de
!>           CX. INCX ne doit pas être nul.
!>

CY

!>          CY est un tableau COMPLEXE, de dimension au moins
!>           ( 1 + ( N - 1 )*abs( INCY ) ).
!>           Avant l'entrée, le tableau incrémenté CY doit contenir les n
!>           éléments du vecteur cy. En sortie, CY est écrasé par le vecteur
!>           mis à jour cy.
!>

INCY

!>          INCY est un ENTIER
!>           En entrée, INCY spécifie l'incrément pour les éléments de
!>           CY. INCY ne doit pas être nul.
!>

C

!>          C est un REEL
!>           En entrée, C spécifie le cosinus, cos.
!>

S

!>          S est un REEL
!>           En entrée, S spécifie le sinus, sin.
!>
