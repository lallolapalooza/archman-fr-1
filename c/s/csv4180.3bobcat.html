DESCRIPTIO

N

Les objets de la classe CSV4180 peuvent être utilisés pour convertir des séries de valeurs séparées par des virgules en les valeurs individuelles séparées (également appelées « champs » ci-dessous). La classe implémente la RFC 4180 (cf. https://www.ietf.org/rfc/rfc4180.txt, section 2)

.

Selon la RFC 4180, les lignes contiennent des valeurs séparées par des virgules : les valeurs séparées par des virgules sur une même ligne sont traitées ensemble, comme une série de valeurs. La dernière valeur séparée par des virgules d'une ligne n'est pas terminée par une

virgule.

Les valeurs séparées par des virgules peuvent être entourées de guillemets doubles. Cependant, elles doivent être entourées de guillemets doubles dans ces cas

:
o
si les valeurs contiennent des virgules
;
o
si les valeurs contiennent des guillemets doubles (auquel cas le guillemet double est « échappé » en le doublant, par ex., "a "" double
quote") ;
o
si les valeurs s'étendent sur plusieurs lignes. Par ex., 
"First
line
second
line"

Les valeurs séparées par des virgules peuvent être vides : la ligne suivante définit trois valeurs séparées par des virgules vides

: 
,,
La première valeur vide commence au début de la ligne et se poursuit jusqu'à la première virgule ; la deuxième valeur vide commence après la première virgule et se poursuit jusqu'à la deuxième virgule ; la troisième valeur vide commence après la deuxième virgule et se poursuit jusqu'à la fin de la ligne. Si la ligne se termine par des caractères d'espace blanc, alors la troisième valeur n'est pas vide, mais contient ces caractères d'espace blanc.

Par défaut, les valeurs sont interprétées comme des chaînes de caractères. La classe CSV4180 offre également des moyens d'ignorer des champs spécifiques, ou de s'assurer qu'ils peuvent être convertis en valeurs entières ou en valeurs en virgule flottante. Le deuxième constructeur (ci-dessous) attend un argument std::string définissant comment interpréter les champs. Les options sont

:
o
I : le champ doit être convertible en une valeur entière
;
o
D : le champ doit être convertible en une valeur en virgule flottante
;
o
S : le champ est une chaîne de caractères : il est utilisé tel
quel ;
o
X : le champ est omis de l'ensemble final des valeurs séparées par des virgules. C'est-à-dire, si une ligne contient trois valeurs séparées par des virgules, et que la spécification "SXS" est utilisée, alors cela résulte en deux valeurs séparées par des virgules : la première et la troisième valeur des trois valeurs séparées par des virgules rencontrées sur les
lignes.
o
- : synonyme de X
.

De plus, les spécifications de champs peuvent contenir des espaces, qui sont

ignorés.

Lors du traitement des valeurs séparées par des virgules, la première ligne peut être considérée comme une ligne d'en-tête. Les spécifications X s'appliquent également aux lignes d'en-tête, mais sinon elles consistent simplement en des champs de type S. De plus, lors du traitement de plusieurs lignes d'entrée, toutes les lignes non en-tête sont rendues disponibles dans un vecteur de vecteurs de champs, tandis que la ligne d'en-tête elle-même peut être accessible via un membre dédié (heade

r()
).

CONSTRUCTEUR

explicit CSV4180(size_t nFields = 0, bool header = false, char fieldSep = ’,’) :
Le premier paramètre spécifie le nombre de champs qui doivent être présents sur les lignes d'entrée. Lors de l'utilisation de la valeur par défaut, le nombre de champs rencontrés sur la première ligne détermine le nombre de champs qui doivent être présents sur les lignes suivantes. Si le deuxième paramètre est true, alors la première ligne est interprétée comme la ligne d'en-tête. Le troisième paramètre spécifie le caractère séparant les champs. Par défaut c'est une virgule, mais parfois (non faisant partie de la RFC) un point-virgule est utilisé. En spécifiant fieldSep, n'importe quel caractère autre qu'une virgule peut être utilisé comme séparateur de
champs.

o
std::istream &operator>>(std::istream &in, CSV4180 &csv) :
Une ligne de texte est extraite de in et traitée par l'objet csv. L'objet csv peut ou non contenir déjà des valeurs séparées par des virgules converties. Lorsqu'il est vide, la première ligne est traitée selon les spécifications fournies à l'objet csv au moment de la construction. Sinon, les valeurs séparées par des virgules sur les lignes extraites doivent correspondre au nombre et aux types des champs, tels que spécifiés par l'objet csv. Lorsque les lignes d'entrée ne correspondent pas à ces spécifications, l'état d'éche
c de i
n est d
éfini.

FONCTIONS

MEMBRES
o
void clear(size_t nFields = 0) :
Les données stockées en interne (référencées par les membres data, header et lastLine) sont effacées. Par défaut, le nombre requis de champs CSV est réinitialisé à 0, mais peut être défini sur une valeur spécifique en spécifiant une valeur pour son paramètre nFields
.
o
std::vector<std::vector<std::string>> const &data() const :
Une référence au vecteur de vecteurs de champs stocké à l'intérieur de l'objet CSV4180 est retournée. Le vecteur retourné par data ne contient pas la ligne d'en-tête. Si une ligne d'en-tête a été demandée, elle peut être récupérée depuis le membre header
().
o
std::vector<std::string> const &header() const :
Si le paramètre header du constructeur a été spécifié comme true, alors ce membre retourne les champs rencontrés sur la première ligne qui a été traitée par le membre read1. Sinon, header retourne une référence à un vecteur
vide.
o
std::string const &lastLine() const :
Une référence à la dernière ligne qui a été extraite avec succès du flux d'entrée par le read1 est retourné. Ainsi, une fois les lignes contenant les valeurs séparées par des virgules traitées, la ligne suivante du flux d'entrée peut être obtenue à partir de ce
membre.
o
size_t nValues() const:
Après avoir appelé read1 pour la première fois, ce membre retourne le nombre requis de valeurs séparées par des virgules qui doivent être rencontrées sur les lignes d'entrée
suivantes.
o
size_t read(std::istream &in, size_t nLines = 0):
Par défaut, toutes les lignes de in sont lues et traitées par le membre read1. En spécifiant une valeur non nulle pour le paramètre nLines, le nombre spécifié de lignes est lu à partir de in. La lecture s'arrête une fois que le statut de in n'est plus good. Quand nLines est spécifié comme zéro, alors les indicateurs de statut de in sont effacés. Le nombre de lignes traitées avec succès est
retourné.
o
std::istream &read1(std::istream &in):
Une ligne est lue à partir de in et analysée pour ses valeurs séparées par des virgules. Si l'analyse échoue, le statut d'échec de in est défini. Après avoir appelé read1 pour la première fois, toutes les lignes suivantes lues par read1 doivent avoir le même nombre de valeurs séparées par des virgules que celui rencontré lors de l'appel à read1 pour la première fois. Les champs analysés sont stockés dans un vecteur d'objets std::string, et ce vecteur est ajouté au vecteur de vecteurs de chaînes retourné par le membre d
ata.
o
std::vector<std::vector<std::string>> release():
Le vecteur de vecteurs de champs stocké à l'intérieur de l'objet CSV4180 est retourné. Après avoir appelé release, le vecteur de champs stocké en interne est vide. Le vecteur retourné par data ne contient pas la ligne d'en-tête. Si une ligne d'en-tête a été demandée, elle peut être récupérée à partir du membre header(). Notez que ce membre ne réinitialise pas le nombre de champs attendus pour les lignes CSV traitées ultérieurement. Si c'est ce que vous voulez, appelez clear après avoir appelé rel
ea
s
e.

EXEMPL

E 
#include <iostream>
#include <bobcat/csv4180>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{ 
    CSV4180 csv;                    // ceci traite
'input' 
    size_t nLines = csv.read(cin);
    cerr << nLines << " lines were read\n";
    if (not csv.header().empty())
    {
        cerr << "header: " << ’\n’;
        for (auto const &field: csv.header())
            cerr << "   `" << field << "’\n";
    }
    cerr << "# CSV values: " << csv.nValues() << ’\n’;
    for (auto const &line: csv.data())
    {
        cerr << "Line:\n";
        for (auto const &entry: line)
            cerr << "   `" << entry << "’\n";
    }
}
