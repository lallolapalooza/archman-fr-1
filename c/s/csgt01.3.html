CSGT01

Documentation de la fonction/sous-routine

sous-routine csgt01 (integer itype, character uplo, integer n, integer m, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldz, * ) z, integer ldz, real, dimension( * ) d, complex, dimension( * ) work, real, dimension( * ) rwork, real, dimension( * ) result)

CSGT01

Objectif :

!>
!> CSGT01 vérifie une décomposition de la forme
!>
!>    A Z   =  B Z D ou
!>    A B Z =  Z D ou
!>    B A Z =  Z D
!>
!> où A est une matrice hermitienne, B est hermitienne définie positive,
!> Z est unitaire et D est diagonale.
!>
!> L'un des rapports de test suivants est calculé :
!>
!> ITYPE = 1:  RESULT(1) = | A Z - B Z D | / ( |A| |Z| n ulp )
!>
!> ITYPE = 2:  RESULT(1) = | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!> ITYPE = 3:  RESULT(1) = | B A Z - Z D | / ( |A| |Z| n ulp )
!>

Paramètres

ITYPE 
!>          ITYPE est INTEGER
!>          La forme du problème généralisé de valeurs propres hermitiennes.
!>          = 1:  A*z = (lambda)*B*z
!>          = 2:  A*B*z = (lambda)*z
!>          = 3:  B*A*z = (lambda)*z
!>

UPLO

!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure des
!>          matrices hermitiennes A et B est stockée.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

M

!>          M est INTEGER
!>          Le nombre de valeurs propres trouvées.  M >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA, N)
!>          La matrice hermitienne d'origine A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX, dimension (LDB, N)
!>          La matrice hermitienne définie positive d'origine B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

Z

!>          Z est un tableau COMPLEX, dimension (LDZ, M)
!>          Les vecteurs propres calculés du problème généralisé de valeurs propres.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= max(1,N).
!>

D

!>          D est un tableau REAL, dimension (M)
!>          Les valeurs propres calculées du problème généralisé de valeurs propres.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (N*N)
!>

RWORK

!>          RWORK est un tableau REAL, dimension (N)
!>

RESULT

!>          RESULT est un tableau REAL, dimension (1)
!>          Le rapport de test tel que décrit ci-dessus.
!>
