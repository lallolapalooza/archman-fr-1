DESCRIPTIO

N

FBB::CSVTable est utilisé pour remplir des tableaux ligne par ligne. Par défaut les éléments du tableau sont séparés par des virgules. Les éléments peuvent contenir tout type de données pouvant également être insérées dans std::ostreams, et peuvent également contenir des lignes horizontales (couvrant éventuellement plusieurs colonnes)

.

Avant d'insérer des éléments dans le tableau, les largeurs, les types d'alignement et les précisions des colonnes du tableau sont définies. Par défaut, les valeurs sont alignées à droite. Lors de l'insertion des éléments du tableau, les types d'alignement et les précisions peuvent être modifiés pour des éléments spécifiques, couvrant éventuellement plusieurs colonnes. Lors de l'insertion de valeurs dont les représentations nécessitent plus de caractères que les largeurs actuelles des colonnes recevant ces valeurs, ces largeurs plus grandes priment sur les largeurs de colonnes

définies.

Contrairement aux tableaux définis par FBB::Table(3bobcat), toutes les données insérées dans CSVTables ne doivent pas être complètement disponibles avant que le tableau ne soit inséré dans une destination std::ostream. Comme les formats de colonnes du tableau sont connus avant la saisie des données, le CSVTable sait quel format utiliser pour quelle colonne. Ces spécifications de format de colonne peuvent être définies de plusieurs manières, par exemple en utilisant des étiquettes de texte et des valeurs. Les objets CSVTable utilisent toujours les spécifications de colonne et les types d'alignement les plus larges qui ont été spécifiés en

dernier.

Lors de l'insertion d'éléments dans CSVTables, les manipulateurs standard C++ IO peuvent également être utilisés. Les lignes du tableau ne se terminent pas automatiquement après que la dernière colonne du tableau a été remplie. Mais lors de l'insertion d'éléments au-delà de la dernière colonne, ils sont insérés tels quels (mais les spécifications de format d'E/S standard peuvent alors toujours être utilisées)

.

Les définitions de colonnes du tableau et les lignes du tableau se terminent à la fin des instructions d'insertion (voir ci-dessous les descriptions des différentes fonctions operator<<). Par

exemple, 
    CSVTable tab;
    ...
    tab << 1 << 2;              // deux éléments dans cette ligne
    tab << "one" << "two" << 3; // trois éléments dans cette
ligne

CSVTable utilise deux classes de support gérant respectivement les définitions des caractéristiques des colonnes du tableau et l'insertion de valeurs dans les éléments du tableau. CSVTabDef gère les définitions de colonnes du tableau, CSVTabIns gère les insertions dans les éléments du tableau. Elles offrent divers opérateurs d'insertion qui sont décrits

ci-dessous.

La construction de tableaux consiste normalement en deux étapes : d'abord les caractéristiques des colonnes sont définies, puis des valeurs sont insérées dans les éléments du tableau. Cette séquence n'est pas imposée par CSVTable : après l'insertion de valeurs dans le tableau, les définitions de colonnes peuvent être mises à jour, après quoi de

s valeurs supplémentaires peuvent être insérées dans le tableau
qui utilisent alors les définitions de colonnes mises à jour.

Une valeur qui est insérée dans le tableau après l'insertion de la valeur de retour de join occupe nCols colonnes, en utilisant le type d'alignement align, et en utilisant facultativement precision lors de l'insertion de valeurs en virgule flottante. La spécification d'alignement doit être FMT::CENTER, FMT::LEFT ou FMT::RIGHT. Exemple : 
            // écrit (en supposant que les colonnes 2 et 3 occupent
// 10 caractères) : // left, mid , righ
t tab << "left" << join(2, FMT::CENTER) << "mid" << "right"";
o
FMT join(FMT::Align align, unsigned precision = ~0U):
Même effet que la fonction join précédente, mais cette fonction occupe toutes les colonnes restantes de la ligne en cours du tableau (cela peut également être accompli en appelant la première fonction join en spécifiant ~0U comme prem
ier arg
ument).

Insertion de lignes horizontales

:

Si un élément de tableau unique doit contenir une ligne horizontale, alors l'insertion simple de Align::HLINE fonctionne bien. Les fonctions hline sont utilisées pour insérer des lignes horizontales s'étendant sur une ou plusieurs colonnes du

tableau.
o
FMT hline(unsigned nCols = ~0U):
Lors de l'insertion de la valeur de retour de cette fonction dans un objet CSVTabIns, une ligne horizontale s'étendant sur nCols colonnes est insérée dans le tableau. Si nécessaire, nCols est réduit pour que la ligne horizontale ne dépasse pas la dernière colonne du tableau. Lors de l'étendue sur plusieurs colonnes, aucun séparateur de colonne n'est utilisé entre les colonnes couvertes : une seule ligne horizontale ininterrompue est insérée. Exemple : 
            // colonnes 1 et 2 : une ligne
horizontale, colonne 3 :
// contient 'hi' (pré
cédée du séparateur de colonne
) tab << hline(2) << "hi";

E 
#include <bobcat/csvtable>
using namespace FBB;
int main()
{
    CSVTable tab;
    tab.fmt() << "case" << right("length", 2) << right("weight", 1) <<
                           right("length", 2) << right("weight", 1);
    tab.sep("  ");
    tab << hline();
    tab << "" << join(4, FMT::CENTER) << "Genre";
    tab << "" << hline();
    tab << "" << join(2, FMT::CENTER) << "Femme" <<
                 join(2, FMT::CENTER) << "Homme";
    tab << "" << hline(2) << hline(2);
    tab << "Cas" << "Longueur" << "Poids" << "Longueur" << "Poids";
    tab << hline();
    tab << 1 << 1.744 << 55.345 << 1.7244 << 64.801;
    tab << 2 << 1.58  << 57.545 << 1.8174 << 81.451;
    tab << 3 << 1.674 << 62.125 << 1.8244 << 80.201;
    tab << hline();
}
