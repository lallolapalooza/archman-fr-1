CSYT03

Objectif :

!>
!> CSYT03 calcule le résidu pour une matrice complexe symétrique multipliée par
!> son inverse :
!>    norme( I - A*AINV ) / ( N * norme(A) * norme(AINV) * EPS )
!> où EPS est le epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice complexe symétrique A est stockée :
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est ENTIER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLExe, dimension (LDA,N)
!>          La matrice complexe symétrique originale A.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N)
!>

AINV

!>          AINV est un tableau COMPLExe, dimension (LDAINV,N)
!>          À l'entrée, l'inverse de la matrice A, stocké comme une matrice symétrique
!>          dans le même format que A.
!>          Dans cette version, AINV est étendue en une matrice complète et
!>          multipliée par A, donc le triangle opposé de AINV sera
!>          modifié ; c'est-à-dire, si la partie triangulaire supérieure de AINV est
!>          stockée, la partie triangulaire inférieure sera utilisée comme espace de travail.
!>

LDAINV

!>          LDAINV est ENTIER
!>          La dimension principale du tableau AINV.  LDAINV >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLExe, dimension (LDWORK,N)
!>

LDWORK

!>          LDWORK est ENTIER
!>          La dimension principale du tableau WORK.  LDWORK >= max(1,N).
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N)
!>

RCOND

!>          RCOND est REEL
!>          L'inverse du nombre de condition de A, calculé comme
!>          RCOND = 1/ (norme(A) * norme(AINV)).
!>

RESID

!>          RESID est REEL
!>          norme(I - A*AINV) / ( N * norme(A) * norme(AINV) * EPS )
!>
