CSVJSON(1) csvkit CSVJSON(1)

NOM

csvjson - Documentation csvjson

DESCRIPTION

Convertit un fichier CSV en JSON ou GeoJSON (selon les indicateurs) :

usage: csvjson [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
               [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
               [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
               [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
               [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [-i INDENT]
               [-k KEY] [--lat LAT] [--lon LON] [--type TYPE]
               [--geometry GEOMETRY] [--crs CRS] [--no-bbox] [--stream]
               [-y SNIFF_LIMIT] [-I]
               [FILE]
Convertit un fichier CSV en JSON (ou GeoJSON).
arguments positionnels :
  FILE                  Le fichier CSV à traiter. S'il est omis, acceptera les
                        données d'entrée via STDIN (entrée standard).
arguments optionnels :
  -h, --help            affiche ce message d'aide et quitte
  -i INDENT, --indent INDENT
                        Indente le JSON de sortie de ce nombre d'espaces. Désactivé
                        par défaut.
  -k KEY, --key KEY     Sortie JSON sous forme d'objet indexé par une colonne donnée,
                        KEY, plutôt que sous forme de tableau. Toutes les valeurs
                        de colonne doivent être uniques. Si --lat et --lon sont spécifiés,
                        cette colonne est utilisée comme ID de Feature GeoJSON.
  --lat LAT             Un index ou un nom de colonne contenant une latitude. La sortie
                        sera GeoJSON au lieu de JSON. Nécessite --lon.
  --lon LON             Un index ou un nom de colonne contenant une longitude. La sortie
                        sera GeoJSON au lieu de JSON. Nécessite --lat.
  --type TYPE           Un index ou un nom de colonne contenant un type GeoJSON.
                        La sortie sera GeoJSON au lieu de JSON. Nécessite --lat
                        et --lon.
  --geometry GEOMETRY   Un index ou un nom de colonne contenant une géométrie GeoJSON.
                        La sortie sera GeoJSON au lieu de JSON. Nécessite --lat
                        et --lon.
  --crs CRS             Une chaîne de système de référence de coordonnées à inclure
                        dans la sortie GeoJSON. Nécessite --lat et --lon.
  --no-bbox             Désactive le calcul d'une boîte englobante.
  --stream              Sortie JSON sous forme de flux d'objets séparés par des
                        nouvelles lignes, plutôt que sous forme de tableau.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        Limite l'analyse du dialecte CSV au nombre d'octets spécifié.
                        Spécifiez « 0 » pour désactiver entièrement l'analyse, ou
                        « -1 » pour analyser le fichier entier.
  -I, --no-inference    Désactive l'inférence de type (et --locale, --date-format,
                        --datetime-format, --no-leading-zeroes) lors de l'analyse
                        de l'entrée.

Voir aussi : Arguments communs à tous les outils.

EXEMPLES

Convertir le jeu de données sur l'éducation des vétérans en JSON indexé par l'abréviation de l'État :

$ csvjson -k "State Abbreviate" -i 4 examples/realdata/FY09_EDU_Recipients_by_State.csv
{
    "AL": {
        "State Name": "ALABAMA",
        "State Abbreviate": "AL",
        "Code": 1.0,
        "Montgomery GI Bill-Active Duty": 6718.0,
        "Montgomery GI Bill- Selective Reserve": 1728.0,
        "Dependents' Educational Assistance": 2703.0,
        "Reserve Educational Assistance Program": 1269.0,
        "Post-Vietnam Era Veteran's Educational Assistance Program": 8.0,
        "TOTAL": 12426.0,
        "j": null
    },
    "...": {
        "...": "..."
    }
}
