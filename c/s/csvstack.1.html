NOM

csvstack - Documentation de csvstack

DESCRIPTION

Empile les lignes de plusieurs fichiers CSV, en ajoutant éventuellement une valeur de regroupement à chaque ligne :

usage: csvstack [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
                [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-S] [-H]
                [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [-g GROUPS]
                [-n GROUP_NAME] [--filenames]
                [FILE [FILE ...]]
Empile les lignes de plusieurs fichiers CSV, en ajoutant éventuellement une valeur de regroupement.
arguments positionnels :
  FILE                  Le(s) fichier(s) CSV à traiter. S'il est omis, les données entrantes seront acceptées via STDIN.
arguments optionnels :
  -h, --help            afficher ce message d'aide et quitter
  -g GROUPS, --groups GROUPS
                        Une liste de valeurs séparées par des virgules à ajouter en tant que "facteurs de regroupement", une par CSV empilé. Celles-ci sont ajoutées à la sortie sous forme de nouvelle colonne. Vous pouvez spécifier un nom pour la nouvelle colonne en utilisant l'indicateur -n.
  -n GROUP_NAME, --group-name GROUP_NAME
                        Un nom pour la colonne de regroupement, par exemple "année". Utilisé uniquement lorsque -g est également spécifié.
  --filenames           Utilise le nom de fichier de chaque fichier d'entrée comme valeur de regroupement. Lorsque spécifié, -g sera ignoré.

Voir aussi : Arguments communs à tous les outils.

ATTENTION :

Si vous redirigez la sortie vers un fichier d'entrée comme csvstack file.csv > file.csv, le fichier s'agrandira indéfiniment.

EXEMPLES

Joindre un ensemble de fichiers pour différentes années :

csvstack -g 2009,2010 examples/realdata/FY09_EDU_Recipients_by_State.csv examples/realdata/Datagov_FY10_EDU_recp_by_State.csv

Ajouter une seule colonne à gauche d'un CSV :

csvstack -n NOUVELLECOL -g "" examples/dummy.csv
