cspctl(1) Manuel des commandes générales cspctl(1)

NOM

cspctl - Programme de contrôle du processeur de signal (CSP) Sound Blaster 16ASP/CSP

SYNTAXE

cspctl commande [-options] <nom_fichier>

DESCRIPTION

cspctl est un programme simple de chargement de microcode CSP pour les cartes son Creative Sound Blaster 16ASP et certaines cartes Sound Blaster AWE32 équipées de la puce Creative Signal Processor (CSP) (CT1748A). cspctl peut également être utilisé comme fonction post-installation pour le module snd-sb16-csp afin de charger le codec par défaut lors de l'installation du module. Si la puce CSP est détectée et initialisée avec succès, elle sera installée comme périphérique dépendant du matériel hwC0D2 dans le répertoire /dev/snd. Actuellement, les codecs suivants peuvent être chargés sur le périphérique CSP :

wfm0001a.csp	Décodeur QSound
wfm0006a.csp	Codec A-law
wfm0007a.csp	Codec u-law
wfm0011a.csp	Codec IMA ADPCM (sortie déformée pour les fichiers IMA de test)
wfm0200a.csp	Codec Creative ADPCM (sonne comme compatible Intel/DVI IMA ADPCM)
wfm0202a.csp	Codec Fast Speech 8
wfm0203a.csp	Codec Fast Speech 10

Ces codecs ne sont pas encore pris en charge par ALSA :

wfm0201a.csp Décodeur Text2Speech

Le fichier de microcode Qsound comporte quatre fonctions, chaque fonction étant un décodeur pour un débit d'échantillonnage différent. Les débits pour les fonctions QSound #1, #2, #3 et #4 sont respectivement de 44100, 22050, 11025 et 8000 Hz. Les codecs IMA ADPCM et FastSpeech sont constitués de deux fonctions, la première est pour la capture et la seconde pour la lecture. Les codecs A-law et u-law n'ont qu'une seule fonction. Pour charger par exemple la fonction #2 du fichier de microcode QSound (décodeur pour 22050Hz), exécutez comme suit :

% cspctl load -f 2 -d QSound wfm0001a.csp

Après un chargement réussi, /proc/asound/SB16/cspD2 affichera :

Creative Signal Processor [v1.0]
State: -x--L
Codec: QSound [func #2]
Sample rates: 22050Hz
QSound decoder disabled

Avec le microcode du décodeur QSound chargé, tous les formats de fichiers PCM simples peuvent être lus avec le positionnement spatial à 180 degrés de QSound appliqué. L'élément QSound est ajouté dynamiquement à la structure du mixeur en tant qu'élément 3DEffect1-space. Il ne s'affichera que si la prise en charge du CSP a été compilée dans les pilotes ALSA, si la puce CSP a été trouvée et si le codec QSound est chargé dans le CSP. Lorsqu'il est activé, la position QSound peut être modifiée dynamiquement par un curseur de mixage, et l'interface de processus doit suivre l'état de la puce CSP et sa position QSound actuelle :

Creative Signal Processor [v1.0]
State: Qx-RL
Codec: QSound [func #2]
Sample rates: 22050Hz
QSound decoder enabled
Processing 16bit mono PCM samples
Qsound position: left = 0x9, right = 0x9

Le pilote prend en charge le chargement automatique des codecs matériels u-Law, A-Law et Ima-ADPCM. Le chargement automatique est actif uniquement lorsqu'aucun microcode n'est chargé dans le CSP et qu'il n'est pas nécessaire de précharger les fichiers *.csp appropriés. Pour décharger un microcode chargé manuellement, vous devez exécuter

% cspctl unload

Si un microcode de codec matériel a été chargé manuellement, le CSP ne prendra en charge que le format PCM chargé et le chargement automatique sera désactivé. Dans ce cas, l'interface de processus affichera les propriétés du codec chargé :

Creative Signal Processor [v1.0]
State: -x--L
Codec: IMA-ADPCM [func #2]
Sample rates: All
PCM format ID: 0x400000 (16bit/-) [mono/stereo] [playback/-]

COMMANDES

load
Charge le microcode depuis le nom de fichier vers le CSP.
unload
Décharge le microcode du CSP.

OPTIONS

-h, --help
Affiche une aide rapide.
-c carte
Sélectionne un numéro de carte. L'option vaut 0 par défaut.
-f fonction
Sélectionne une fonction dans le fichier de microcode. L'option vaut 1 par défaut.
-d description
Chaîne de description facultative du microcode.
