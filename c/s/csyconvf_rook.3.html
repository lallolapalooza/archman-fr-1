e

sous-routine csyconvf_rook (character uplo, character way, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) e, integer, dimension( * ) ipiv, integer

info)

CSYCONVF_ROO

K

But

: 
!> Si le paramètre WAY = 'C' :
!> CSYCONVF_ROOK convertit le format de sortie de la factorisation utilisé dans
!> CSYTRF_ROOK fourni à l'entrée dans le paramètre A en le format de sortie de
!> la factorisation utilisé dans CSYTRF_RK (ou CSYTRF_BK) qui est stocké à la
!> sortie dans les paramètres A et E. Le format IPIV pour CSYTRF_ROOK et
!> CSYTRF_RK (ou CSYTRF_BK) est le même et n'est pas converti.
!>
!> Si le paramètre WAY = 'R' :
!> CSYCONVF_ROOK effectue la conversion dans le sens inverse, c.-à-d.
!> convertit le format de sortie de la factorisation utilisé dans CSYTRF_RK
!> (ou CSYTRF_BK) fourni à l'entrée dans les paramètres A et E en le format de
!> sortie de la factorisation utilisé dans CSYTRF_ROOK qui est stocké à la
!> sortie dans le paramètre A. Le format IPIV pour CSYTRF_ROOK et
!> CSYTRF_RK (ou CSYTRF_BK) est le même et n'est pas converti.
!>
!> CSYCONVF_ROOK peut aussi convertir dans le cas des matrices hermitiennes,
!> c.-à-d. entre les formats utilisés dans CHETRF_ROOK et CHETRF_RK (ou
!> CHETRF_BK).
!
>

Paramètre

s
UPLO 
!>          UPLO est CHARACTER*1
!>          Indique si les détails de la factorisation sont
!>          stockés sous forme de matrice triangulaire supérieure ou
!>          inférieure A.
!>          = 'U' : triangulaire supérieure
!>          = 'L' : triangulaire inférieure
!
>

WA

Y 
!>          WAY est CHARACTER*1
!>          = 'C' : Convertir
!>          = 'R' : Rétablir
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>
!>          1) Si WAY ='C' :
!>
!>          À l'entrée, contient les détails de la factorisation au format
!>          utilisé dans CSYTRF_ROOK :
!>            a) tous les éléments de la matrice diagonale par blocs
!>               symétrique D sur la diagonale de A et sur la
!>               surdiagonale (ou la sous-diagonale) de A, et
!>            b) Si UPLO = 'U' : les multiplicateurs utilisés pour obtenir le
!>               facteur U dans la partie surdiagonale de A.
!>               Si UPLO = 'L' : les multiplicateurs utilisés pour obtenir le
!>               facteur L dans la partie surdiagonale de A.
!>
!>          À la sortie, contient les détails de la factorisation au format
!>          utilisé dans CSYTRF_RK ou CSYTRF_BK :
!>            a) SEULEMENT les éléments diagonaux de la matrice diagonale par
!>               blocs symétrique D sur la diagonale de A, c.-à-d.
!>               D(k,k) = A(k,k) ;
!>               (les éléments surdiagonaux (ou sous-diagonaux) de D
!>                sont stockés à la sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie surdiagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie sous-diagonale de A.
!>
!>          2) Si WAY = 'R' :
!>
!>          À l'entrée, contient les détails de la factorisation au format
!>          utilisé dans CSYTRF_RK ou CSYTRF_BK :
!>            a) SEULEMENT les éléments diagonaux de la matrice diagonale par
!>               blocs symétrique D sur la diagonale de A, c.-à-d.
!>               D(k,k) = A(k,k) ;
!>               (les éléments surdiagonaux (ou sous-diagonaux) de D
!>                sont stockés à la sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie surdiagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie sous-diagonale de A.
!>
!>          À la sortie, contient les détails de la factorisation au format
!>          utilisé dans CSYTRF_ROOK :
!>            a) tous les éléments de la matrice diagonale par blocs
!>               symétrique D sur la diagonale de A et sur la
!>               surdiagonale (ou la sous-diagonale) de A, et
!>            b) Si UPLO = 'U' : les multiplicateurs utilisés pour obtenir le
!>               facteur U dans la partie surdiagonale de A.
!>               Si UPLO = 'L' : les multiplicateurs utilisés pour obtenir le
!>               facteur L dans la partie surdiagonale de A.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!
>

E 
!>          E est un tableau COMPLEX, dimension (N)
!>
!>          1) Si WAY ='C' :
!>
!>          À l'entrée, simplement un espace de travail.
!>
!>          À la sortie, contient les éléments surdiagonaux (ou
!>          sous-diagonaux) de la matrice diagonale par blocs
!>          symétrique D avec des blocs diagonaux 1-par-1 ou 2-par-2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) est mis à 0 ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          2) Si WAY = 'R' :
!>
!>          À l'entrée, contient les éléments surdiagonaux (ou
!>          sous-diagonaux) de la matrice diagonale par blocs
!>          symétrique D avec des blocs diagonaux 1-par-1 ou 2-par-2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i),i=2:N, E(1) non référencé ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i),i=1:N-1, E(N) non référencé.
!>
!>          À la sortie, n'est pas modifié
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (N)
!>          À l'entrée, détails des permutations et de la structure
!>          par blocs de D tels que déterminés :
!>          1) par CSYTRF_ROOK, si WAY ='C' ;
!>          2) par CSYTRF_RK (ou CSYTRF_BK), si WAY ='R'.
!>          Le format IPIV est le même pour toutes ces routines.
!>
!>          À la sortie, n'est pas modifié.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!
>
