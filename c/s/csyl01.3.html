sous-routine csyl01 (real thresh, integer, dimension( 3 ) nfail, real, dimension( 2 ) rmax, integer, dimension( 2 ) ninfo, integer knt)

CSYL01

Objectif :

!>
!> CSYL01 teste CTRSYL et CTRSYL3, des routines pour résoudre l'équation matricielle de Sylvester
!>
!>    op(A)*X + ISGN*X*op(B) = scale*C,
!>
!> où op(A) et op(B) sont tous deux sous forme triangulaire supérieure, op() représente une
!> transposée conjuguée optionnelle, et ISGN peut être -1 ou +1. Scale est une sortie
!> inférieure ou égale à 1, choisie pour éviter le débordement dans X.
!>
!> Le code de test vérifie que le résidu suivant ne dépasse pas
!> le seuil fourni :
!>
!>    norm(op(A)*X + ISGN*X*op(B) - scale*C) /
!>        (EPS*max(norm(A),norm(B))*norm(X))
!>
!> Cette routine complète CGET35 en testant avec des matrices aléatoires plus grandes,
!> dont certaines nécessitent un rééchelonnement de X pour éviter le débordement.
!>
!>

Paramètres

THRESH 
!>          THRESH est REAL
!>          Un test sera comptabilisé comme un échec si le résidu, calculé comme
!>          décrit ci-dessus, dépasse THRESH.
!>

NFAIL

!>          NFAIL est un tableau INTEGER, dimension (3)
!>          NFAIL(1) = Nombre de fois où le résidu CTRSYL dépasse le seuil THRESH
!>          NFAIL(2) = Nombre de fois où le résidu CTRSYL3 dépasse le seuil THRESH
!>          NFAIL(3) = Nombre de fois où CTRSYL3 et CTRSYL divergent
!>

RMAX

!>          RMAX est un tableau DOUBLE PRECISION, dimension (2)
!>          RMAX(1) = Valeur du plus grand rapport de test pour CTRSYL
!>          RMAX(2) = Valeur du plus grand rapport de test pour CTRSYL3
!>

NINFO

!>          NINFO est un tableau INTEGER, dimension (2)
!>          NINFO(1) = Nombre de fois où CTRSYL retourne INFO non nul
!>          NINFO(2) = Nombre de fois où CTRSYL3 retourne INFO non nul
!>

KNT

!>          KNT est INTEGER
!>          Nombre total d'exemples testés.
!>

Définition à la ligne 88 du fichier csyl01.f.
