NOM

csvlook - Documentation de csvlook

DESCRIPTION

Rend un fichier CSV dans la ligne de commande dans un format compatible Markdown, à largeur fixe :

utilisation : csvlook [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
               [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
               [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
               [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
               [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V]
               [--max-rows MAX_ROWS] [--max-columns MAX_COLUMNS]
               [--max-column-width MAX_COLUMN_WIDTH]
               [--max-precision MAX_PRECISION] [--no-number-ellipsis]
               [-y SNIFF_LIMIT] [-I]
               [FICHIER]
Rend un fichier CSV dans la console sous forme de tableau compatible Markdown, à largeur fixe.
arguments positionnels :
  FICHIER               Le fichier CSV à traiter. S'il est omis, les données
                        seront acceptées via l'entrée standard (STDIN).
arguments optionnels :
  -h, --help            afficher ce message d'aide et quitter
  --max-rows MAX_ROWS   Le nombre maximum de lignes à afficher avant de
                        tronquer les données.
  --max-columns MAX_COLUMNS
                        Le nombre maximum de colonnes à afficher avant de
                        tronquer les données.
  --max-column-width MAX_COLUMN_WIDTH
                        Tronquer toutes les colonnes à cette largeur maximale.
                        Le reste sera remplacé par des points de suspension.
  --max-precision MAX_PRECISION
                        Le nombre maximum de décimales à afficher. Le reste
                        sera remplacé par des points de suspension.
  --no-number-ellipsis  Désactiver les points de suspension si --max-precision
                        est dépassé.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        Limiter la détection du dialecte CSV au nombre spécifié
                        d'octets. Spécifier "0" pour désactiver
                        complètement la détection, ou "-1" pour
                        détecter l'ensemble du fichier.
  -I, --no-inference    Désactiver l'inférence de type (et --locale,
                        --date-format, --datetime-format, --no-leading-zeroes)
                        lors de l'analyse de l'entrée.

Si un tableau est trop large pour s'afficher correctement, essayez de rediriger la sortie vers less -S ou de la tronquer avec csvcut.

Si le tableau est trop long, essayez de le filtrer avec grep ou de rediriger la sortie vers less.

Voir aussi : Arguments communs à tous les outils.

NOTE :

La partie fractionnaire d'un nombre décimal est toujours tronquée. Pour contrôler cette troncature, utilisez --no-inference avec --max-column-width.

EXEMPLES

Utilisation de base :

csvlook examples/testfixed_converted.csv

Cet outil est particulièrement utile comme opération finale lors du chaînage avec d'autres outils :

csvcut -c 9,1 examples/realdata/FY09_EDU_Recipients_by_State.csv | csvlook

Si une ligne de données contient plus de cellules que la ligne d'en-tête, csvlook générera une erreur. Utilisez csvclean pour supprimer de telles lignes.

Pour ignorer les cellules supplémentaires, à la place :

csvcut -C "" examples/bad.csv | csvlook

Si ces lignes se trouvent en haut du fichier (par exemple, des avis de droits d'auteur), vous pouvez les ignorer :

csvlook --skip-lines 1 examples/bad.csv

Cette erreur peut également survenir si csvlook déduit incorrectement le format CSV (par "sniffing"). Pour désactiver le sniffing CSV, définissez --snifflimit 0 puis, si nécessaire, définissez vous-même les options --delimiter et --quotechar. Ou, définissez --snifflimit -1 pour utiliser l'ensemble du fichier comme échantillon, au lieu des 1024 premiers octets.
