NOM

csvgrep - Documentation csvgrep

DESCRIPTION

Filtrez les données tabulaires pour ne conserver que les lignes où certaines colonnes contiennent une valeur donnée ou correspondent à une expression régulière :

usage: csvgrep [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
               [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-S] [-H]
               [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [-n] [-c COLUMNS]
               [-m PATTERN] [-r REGEX] [-f MATCHFILE] [-i] [-a]
               [FILE]
Recherche des fichiers CSV. Similaire à la commande Unix "grep", mais pour les
données tabulaires.
arguments positionnels :
  FILE                  Le fichier CSV à traiter. S'il est omis, l'entrée sera
                        acceptée via le flux de données standard (STDIN).
arguments optionnels :
  -h, --help            afficher ce message d'aide et quitter
  -n, --names           Afficher les noms et indices des colonnes du CSV d'entrée
                        et quitter.
  -c COLUMNS, --columns COLUMNS
                        Une liste de nombres d'indices, de noms ou de plages de
                        colonnes séparés par des virgules à rechercher, par
                        exemple "1,id,3-5".
  -m PATTERN, --match PATTERN
                        Une chaîne à rechercher.
  -r REGEX, --regex REGEX
                        Une expression régulière à faire correspondre.
  -f MATCHFILE, --file MATCHFILE
                        Un chemin vers un fichier. Pour chaque ligne, si une ligne
                        du fichier (sans les séparateurs de ligne) correspond
                        exactement à la valeur de la cellule, la ligne
                        correspond.
  -i, --invert-match    Sélectionner les lignes non correspondantes, au lieu des
                        lignes correspondantes.
  -a, --any-match       Sélectionner les lignes où n'importe quelle colonne
                        correspond, au lieu de toutes les colonnes.

Voir aussi : Arguments communs à tous les outils.

NOTE : Même si '-m', '-r' et '-f' sont listés comme arguments "optionnels", vous devez en spécifier un.

EXEMPLES

Rechercher la ligne concernant l'Illinois :

csvgrep -c 1 -m ILLINOIS examples/realdata/FY09_EDU_Recipients_by_State.csv

Rechercher les lignes concernant des états dont le nom commence par la lettre "I" :

csvgrep -c 1 -r "^I" examples/realdata/FY09_EDU_Recipients_by_State.csv

Rechercher les lignes qui ne contiennent pas de cellule d'état vide :

csvgrep -c 1 -r "^$" -i examples/realdata/FY09_EDU_Recipients_by_State.csv

Effectuer une recherche insensible à la casse :

csvgrep -c 1 -r "(?i)illinois" examples/realdata/FY09_EDU_Recipients_by_State.csv

Supprimer les lignes de commentaires :

printf "a,b\n1,2\n# un commentaire\n3,4" | csvgrep --invert-match -c1 -r '^#'

Obtenir les indices des colonnes qui contiennent du texte correspondant (\x1e est le caractère séparateur d'enregistrement (RS)) :

csvgrep -m 22 -a -c 1- examples/realdata/FY09_EDU_Recipients_by_State.csv | csvformat -M $'\x1e' | xargs -d $'\x1e' -n1 sh -c 'echo $0 | csvcut -n' | grep 22

NOTE :

Ce dernier exemple n'est pas performant.
