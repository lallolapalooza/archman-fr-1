NOM

csvpy - Documentation csvpy

DESCRIPTION

Charge un fichier CSV dans un objet agate.csv.Reader puis lance un interpréteur Python afin que l'utilisateur puisse inspecter les données comme bon lui semble :

usage: csvpy [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
             [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
             [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
             [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
             [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [--dict] [--agate]
             [--no-number-ellipsis] [-y SNIFF_LIMIT] [-I]
             [FILE]
Charge un fichier CSV dans un lecteur CSV, puis lance un interpréteur Python.
arguments positionnels :
  FILE                  Le fichier CSV à traiter. S'il est omis, il acceptera
                        les données d'entrée via STDIN.
arguments optionnels :
  -h, --help            affiche ce message d'aide et quitte
  --dict                Charge le fichier CSV dans un DictReader.
  --agate               Charge le fichier CSV dans une table agate.
  --no-number-ellipsis  Désactive les points de suspension si la précision maximale
                        est dépassée.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        Limite le reniflage du dialecte CSV aux octets spécifiés.
                        Spécifiez "0" pour désactiver complètement le reniflage,
                        ou "-1" pour renifler l'intégralité du fichier.
  -I, --no-inference    Désactive l'inférence de type (et --locale, --date-format,
                        --datetime-format, --no-leading-zeroes) lors de l'analyse
                        de l'entrée.

Cet outil utilisera automatiquement l'interpréteur IPython s'il est installé, sinon il utilisera l'interpréteur Python en cours d'exécution.

NOTE :

En raison de limitations de plateforme, csvpy n'accepte pas les données de fichiers comme entrée via STDIN.

Voir aussi : Arguments communs à tous les outils.

EXEMPLES

Utilisation de base :

$ csvpy examples/dummy.csv
Bienvenue ! "examples/dummy.csv" a été chargé dans un objet lecteur nommé "reader". >>> next(reader) ['a', 'b', 'c']

Comme dictionnaire :

$ csvpy --dict examples/dummy.csv
Bienvenue ! "examples/dummy.csv" a été chargé dans un objet DictReader nommé "reader".
>>> next(reader)
{'a': '1', 'c': '3', 'b': '2'}

Comme table agate :

$ csvpy --agate examples/dummy.csv
Bienvenue ! "examples/dummy.csv" a été chargé dans un objet from_csv nommé "reader".
>>> reader.print_table()
|    a | b | c |
| ---- | - | - |
| True | 2 | 3 |
