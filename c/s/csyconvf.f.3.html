Documentation de la fonction/sous-routine

sous-routine csyconvf (character uplo, character way, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) e, integer, dimension( * ) ipiv, integer info)

CSYCONVF

But :

!> Si le paramètre WAY = 'C' :
!> CSYCONVF convertit le format de sortie de la factorisation utilisé dans
!> CSYTRF fourni à l'entrée dans le paramètre A en le format de sortie de
!> la factorisation utilisé dans CSYTRF_RK (ou CSYTRF_BK) qui est stocké
!> à la sortie dans les paramètres A et E. Il convertit également sur place les détails
!> des échanges stockés dans IPIV du format utilisé dans CSYTRF vers
!> le format utilisé dans CSYTRF_RK (ou CSYTRF_BK).
!>
!> Si le paramètre WAY = 'R' :
!> CSYCONVF effectue la conversion dans le sens inverse, c.-à-d.
!> convertit le format de sortie de la factorisation utilisé dans CSYTRF_RK
!> (ou CSYTRF_BK) fourni à l'entrée dans les paramètres A et E en le
!> format de sortie de la factorisation utilisé dans CSYTRF qui est stocké
!> à la sortie dans le paramètre A. Il convertit également sur place les détails
!> des échanges stockés dans IPIV du format utilisé dans CSYTRF_RK
!> (ou CSYTRF_BK) vers le format utilisé dans CSYTRF.
!>
!> CSYCONVF peut également convertir dans le cas des matrices hermitiennes, c.-à-d. entre
!> les formats utilisés dans CHETRF et CHETRF_RK (ou CHETRF_BK).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Indique si les détails de la factorisation sont
!>          stockés sous forme de matrice triangulaire supérieure ou inférieure A.
!>          = 'U' :  Triangulaire supérieure
!>          = 'L' :  Triangulaire inférieure
!>

WAY

!>          WAY est CHARACTER*1
!>          = 'C' : Convertir
!>          = 'R' : Inverser
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>
!>          1) Si WAY ='C' :
!>
!>          À l'entrée, contient les détails de la factorisation dans le format utilisé dans
!>          CSYTRF :
!>            a) tous les éléments de la matrice diagonale par blocs
!>               symétrique D sur la diagonale de A et sur la surdiagonale
!>               (ou la sous-diagonale) de A, et
!>            b) Si UPLO = 'U' : les multiplicateurs utilisés pour obtenir le facteur U
!>               dans la partie sur-diagonale de A.
!>               Si UPLO = 'L' : les multiplicateurs utilisés pour obtenir le facteur L
!>               dans la partie sur-diagonale de A.
!>
!>          À la sortie, contient les détails de la factorisation dans le format utilisé dans
!>          CSYTRF_RK ou CSYTRF_BK :
!>            a) SEULEMENT les éléments diagonaux de la matrice diagonale par blocs
!>               symétrique D sur la diagonale de A, c.-à-d. D(k,k) = A(k,k) ;
!>               (les éléments sur-diagonaux (ou sous-diagonaux) de D
!>                sont stockés à la sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie sur-diagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie sous-diagonale de A.
!>
!>          2) Si WAY = 'R' :
!>
!>          À l'entrée, contient les détails de la factorisation dans le format utilisé dans
!>          CSYTRF_RK ou CSYTRF_BK :
!>            a) SEULEMENT les éléments diagonaux de la matrice diagonale par blocs
!>               symétrique D sur la diagonale de A, c.-à-d. D(k,k) = A(k,k) ;
!>               (les éléments sur-diagonaux (ou sous-diagonaux) de D
!>                sont stockés à la sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie sur-diagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie sous-diagonale de A.
!>
!>          À la sortie, contient les détails de la factorisation dans le format utilisé dans
!>          CSYTRF :
!>            a) tous les éléments de la matrice diagonale par blocs
!>               symétrique D sur la diagonale de A et sur la surdiagonale
!>               (ou la sous-diagonale) de A, et
!>            b) Si UPLO = 'U' : les multiplicateurs utilisés pour obtenir le facteur U
!>               dans la partie sur-diagonale de A.
!>               Si UPLO = 'L' : les multiplicateurs utilisés pour obtenir le facteur L
!>               dans la partie sur-diagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau COMPLEX, dimension (N)
!>
!>          1) Si WAY ='C' :
!>
!>          À l'entrée, simplement un espace de travail.
!>
!>          À la sortie, contient les éléments sur-diagonaux (ou sous-diagonaux)
!>          de la matrice diagonale par blocs symétrique D
!>          avec des blocs diagonaux de taille 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) est mis à 0 ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          2) Si WAY = 'R' :
!>
!>          À l'entrée, contient les éléments sur-diagonaux (ou sous-diagonaux)
!>          de la matrice diagonale par blocs symétrique D
!>          avec des blocs diagonaux de taille 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i),i=2:N, E(1) non référencé ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i),i=1:N-1, E(N) non référencé.
!>
!>          À la sortie, n'est pas modifié
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>
!>          1) Si WAY ='C' :
!>          À l'entrée, détails des échanges et de la structure
!>          par blocs de D dans le format utilisé dans CSYTRF.
!>          À la sortie, détails des échanges et de la structure
!>          par blocs de D dans le format utilisé dans CSYTRF_RK
!>          ( ou CSYTRF_BK).
!>
!>          1) Si WAY ='R' :
!>          À l'entrée, détails des échanges et de la structure
!>          par blocs de D dans le format utilisé dans CSYTRF_RK
!>          ( ou CSYTRF_BK).
!>          À la sortie, détails des échanges et de la structure
!>          par blocs de D dans le format utilisé dans CSYTRF.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>
