NOM

csvsort - Documentation csvsort

DESCRIPTION

Trie les fichiers CSV. Similaire à la commande Unix "sort", mais pour les données tabulaires :

usage: csvsort [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
               [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
               [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
               [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
               [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [-n] [-c COLUMNS]
               [-r] [-i] [-y SNIFF_LIMIT] [-I]
               [FICHIER]
Trie les fichiers CSV. Similaire à la commande Unix "sort", mais pour les données tabulaires.
arguments positionnels :
  FICHIER               Le fichier CSV à traiter. S'il est omis, il acceptera les
                        données d'entrée via STDIN.
arguments optionnels :
  -h, --help            afficher ce message d'aide et quitter
  -n, --names           Affiche les noms et indices des colonnes du CSV d'entrée
                        et quitte.
  -c COLUMNS, --columns COLUMNS
                        Une liste séparée par des virgules d'indices, de noms ou de
                        plages de colonnes pour trier, par exemple "1,id,3-5".
                        Par défaut, toutes les colonnes.
  -r, --reverse         Trier par ordre décroissant.
  -i, --ignore-case     Effectuer un tri insensible à la casse.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        Limite la détection du dialecte CSV au nombre d'octets spécifié.
                        Spécifiez "0" pour désactiver complètement la détection, ou
                        "-1" pour détecter tout le fichier.
  -I, --no-inference    Désactive l'inférence de type (et --locale, --date-format,
                        --datetime-format, --no-leading-zeroes) lors de l'analyse
                        de l'entrée.

Voir aussi : Arguments communs à tous les outils.

NOTE :

Si votre fichier est volumineux, essayez sort -t, fichier.csv à la place.

EXEMPLES

Trier la table des prestations d'éducation des vétérans par la colonne "TOTAL" :

csvsort -c 9 examples/realdata/FY09_EDU_Recipients_by_State.csv

Afficher les cinq États ayant le plus d'individus réclamant des prestations d'éducation des vétérans :

csvcut -c 1,9 examples/realdata/FY09_EDU_Recipients_by_State.csv | csvsort -r -c 2 | head -n 5
