Paquet: csvkit

CSVSTAT(1) csvkit CSVSTAT(1)

NOM

csvstat - Documentation csvstat

DESCRIPTION

Affiche des statistiques descriptives pour toutes les colonnes d'un fichier CSV. Détermine intelligemment le type de chaque colonne, puis affiche des analyses pertinentes pour ce type (plages pour les dates, moyenne et médiane pour les entiers, etc.) :

usage: csvstat [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
               [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
               [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
               [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
               [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [--csv] [--json]
               [-i INDENT] [-n] [-c COLUMNS] [--type] [--nulls] [--non-nulls]
               [--unique] [--min] [--max] [--sum] [--mean] [--median]
               [--stdev] [--len] [--max-precision] [--freq]
               [--freq-count FREQ_COUNT] [--count]
               [--decimal-format DECIMAL_FORMAT] [-G] [-y SNIFF_LIMIT] [-I]
               [FILE]
Affiche des statistiques descriptives pour chaque colonne d'un fichier CSV.
arguments positionnels :
  FILE                  Le fichier CSV à traiter. S'il est omis, acceptera les
                        données entrées via STDIN.
arguments facultatifs :
  -h, --help            afficher ce message d'aide et quitter
  --csv                 Afficher les résultats sous forme de tableau CSV, plutôt
                        que texte brut.
  --json                Afficher les résultats sous forme de texte JSON, plutôt
                        que texte brut.
  -i INDENT, --indent INDENT
                        Indenter la sortie JSON de ce nombre d'espaces. Désactivé
                        par défaut.
  -n, --names           Afficher les noms et indices des colonnes du CSV d'entrée
                        et quitter.
  -c COLUMNS, --columns COLUMNS
                        Une liste séparée par des virgules d'indices de colonnes,
                        de noms ou de plages à examiner, par ex. "1,id,3-5".
                        Par défaut, toutes les colonnes.
  --type                Afficher uniquement le type de données.
  --nulls               Afficher uniquement si les colonnes contiennent des valeurs nulles.
  --non-nulls           Afficher uniquement les comptes de valeurs non nulles.
  --unique              Afficher uniquement les comptes de valeurs uniques.
  --min                 Afficher uniquement les valeurs les plus petites.
  --max                 Afficher uniquement les valeurs les plus grandes.
  --sum                 Afficher uniquement les sommes.
  --mean                Afficher uniquement les moyennes.
  --median              Afficher uniquement les médianes.
  --stdev               Afficher uniquement les écarts-types.
  --len                 Afficher uniquement la longueur des valeurs les plus longues.
  --max-precision       Afficher uniquement le nombre maximal de décimales.
  --freq                Afficher uniquement les listes des valeurs fréquentes.
  --freq-count FREQ_COUNT
                        Le nombre maximal de valeurs fréquentes à afficher.
  --count               Afficher uniquement le nombre total de lignes.
  --decimal-format DECIMAL_FORMAT
                        Spécification de format %- pour l'impression des nombres
                        décimaux. Par défaut, formatage spécifique à la locale
                        avec "%.3f".
  -G, --no-grouping-separator
                        Ne pas utiliser de séparateurs de regroupement dans les
                        nombres décimaux.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        Limiter l'analyse du dialecte CSV au nombre d'octets spécifié.
                        Spécifier "0" pour désactiver complètement l'analyse,
                        ou "-1" pour analyser le fichier entier.
  -I, --no-inference    Désactiver l'inférence de type (et --locale, --date-format,
                        --datetime-format, --no-leading-zeroes) lors de l'analyse
                        de l'entrée.

Voir aussi : Arguments communs à tous les outils.

EXEMPLES

Utilisation de base :

csvstat examples/realdata/FY09_EDU_Recipients_by_State.csv

Lorsqu'un nom de statistique est passé, seule cette statistique sera imprimée :

$ csvstat --min examples/realdata/FY09_EDU_Recipients_by_State.csv
  1. State Name: None
  2. State Abbreviate: None
  3. Code: 1
  4. Montgomery GI Bill-Active Duty: 435
  5. Montgomery GI Bill- Selective Reserve: 48
  6. Dependents' Educational Assistance: 118
  7. Reserve Educational Assistance Program: 60
  8. Post-Vietnam Era Veteran's Educational Assistance Program: 1
  9. TOTAL: 768
 10. j: None

Si une seule statistique et une seule colonne sont demandées, seule une valeur sera retournée :

$ csvstat -c 4 --mean examples/realdata/FY09_EDU_Recipients_by_State.csv
6,263.904
