subroutine cstein (n, d, e, m, w, iblock, isplit, z, ldz, work, iwork, ifail, info)
CSTEIN

Documentation de la fonction/sous-programme

sous-programme cstein (entier n, reel, dimension( * ) d, reel, dimension( * ) e, entier m, reel, dimension( * ) w, entier, dimension( * ) iblock, entier, dimension( * ) isplit, complexe, dimension( ldz, * ) z, entier ldz, reel, dimension( * ) work, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

CSTEIN

Objectif:

!>
!> CSTEIN calcule les vecteurs propres d'une matrice tridiagonale symétrique réelle
!> T correspondant à des valeurs propres spécifiées, en utilisant l'itération inverse.
!>
!> Le nombre maximum d'itérations autorisées pour chaque vecteur propre est
!> spécifié par un paramètre interne MAXITS (actuellement défini à 5).
!>
!> Bien que les vecteurs propres soient réels, ils sont stockés dans un tableau complexe,
!> qui peut être passé à CUNMTR ou CUPMTR pour une rétro-transformation vers les vecteurs propres
!> d'une matrice hermitienne complexe qui a été réduite à une forme tridiagonale.
!>
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice.  N >= 0.
!>

D

!>          D est un tableau RÉEL, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est un tableau RÉEL, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice
!>          T, stockés dans les éléments 1 à N-1.
!>

M

!>          M est un ENTIER
!>          Le nombre de vecteurs propres à calculer.  0 <= M <= N.
!>

W

!>          W est un tableau RÉEL, dimension (N)
!>          Les M premiers éléments de W contiennent les valeurs propres pour
!>          lesquelles les vecteurs propres doivent être calculés.  Les valeurs propres
!>          doivent être regroupées par bloc séparé et ordonnées de la plus petite à la plus grande
!>          au sein du bloc.  ( Le tableau de sortie
!>          W de SSTEBZ avec ORDER = 'B' est attendu ici. )
!>

IBLOCK

!>          IBLOCK est un tableau ENTIER, dimension (N)
!>          Les indices des sous-matrices associés aux valeurs propres correspondantes
!>          dans W ; IBLOCK(i)=1 si la valeur propre W(i) appartient à
!>          la première sous-matrice en partant du haut, =2 si W(i) appartient à
!>          la seconde sous-matrice, etc.  ( Le tableau de sortie IBLOCK
!>          de SSTEBZ est attendu ici. )
!>

ISPLIT

!>          ISPLIT est un tableau ENTIER, dimension (N)
!>          Les points de séparation, où T se décompose en sous-matrices.
!>          La première sous-matrice est constituée des lignes/colonnes 1 à
!>          ISPLIT( 1 ), la seconde des lignes/colonnes ISPLIT( 1 )+1
!>          jusqu'à ISPLIT( 2 ), etc.
!>          ( Le tableau de sortie ISPLIT de SSTEBZ est attendu ici. )
!>

Z

!>          Z est un tableau COMPLEXE, dimension (LDZ, M)
!>          Les vecteurs propres calculés.  Le vecteur propre associé
!>          à la valeur propre W(i) est stocké dans la i-ème colonne de
!>          Z.  Tout vecteur qui ne converge pas est défini à sa valeur itérée actuelle
!>          après MAXITS itérations.
!>          Les parties imaginaires des vecteurs propres sont mises à zéro.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension principale du tableau Z.  LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau RÉEL, dimension (5*N)
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (N)
!>

IFAIL

!>          IFAIL est un tableau ENTIER, dimension (M)
!>          À la sortie normale, tous les éléments de IFAIL sont zéro.
!>          Si un ou plusieurs vecteurs propres ne parviennent pas à converger après
!>          MAXITS itérations, leurs indices sont stockés dans
!>          le tableau IFAIL.
!>

INFO

!>          INFO est un ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0: si INFO = i, alors i vecteurs propres n'ont pas convergé dans
!>               MAXITS itérations. Leurs indices sont stockés dans
!>               le tableau IFAIL.
!>

Paramètres internes:

!>  MAXITS  ENTIER, par défaut = 5
!>          Le nombre maximum d'itérations effectuées.
!>
!>  EXTRA   ENTIER, par défaut = 2
!>          Le nombre d'itérations effectuées après que le critère de croissance de la norme
!>          soit satisfait, doit être au moins 1.
!>
