subroutine cspsvx (character fact, character uplo, integer n, integer nrhs, complex, dimension( * ) ap, complex, dimension( * ) afp, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CSPSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices OTHER

But :

!>
!> CSPSVX utilise la factorisation par pivot diagonal A = U*D*U**T ou
!> A = L*D*L**T pour calculer la solution d'un système d'équations
!> linéaires complexes A * X = B, où A est une matrice symétrique N×N
!> stockée au format compact et où X et B sont des matrices N×NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de condition
!> sont également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la méthode du pivot diagonal est utilisée pour
!>    factoriser A comme
!>       A = U * D * U**T,  si UPLO = 'U', ou
!>       A = L * D * L**T,  si UPLO = 'L',
!>    où U (ou L) est un produit de matrices de permutation et de
!>    matrices triangulaires supérieures (inférieures) unitaires et D
!>    est symétrique et bloc-diagonale avec des blocs diagonaux 1×1 et
!>    2×2.
!>
!> 2. Si certains D(i,i)=0, de sorte que D est exactement singulière,
!>    la routine retourne avec INFO = i. Sinon, la forme factorisée de
!>    A est utilisée pour estimer le conditionnement de la matrice A.
!>    Si le réciproque du conditionnement est inférieur à la précision
!>    machine, INFO = N+1 est retourné comme avertissement, mais la
!>    routine continue néanmoins pour résoudre X et calculer les
!>    bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme
!>    factorisée de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la matrice
!>    de solution calculée et calculer les bornes d'erreur et les
!>    estimations d'erreur arrière pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Indique si la forme factorisée de A a été fournée à
!>          l'entrée.
!>          = 'F' : À l'entrée, AFP et IPIV contiennent la forme
!>                  factorisée de A. AP, AFP et IPIV ne seront pas
!>                  modifiés.
!>          = 'N' : La matrice A sera copiée dans AFP et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEX, dimension (N*(N+1)/2)
!>          Le triangle supérieur ou inférieur de la matrice symétrique
!>          A, compacté colonne par colonne dans un tableau linéaire.
!>          La j-ième colonne de A est stockée dans le tableau AP comme
!>          suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>

AFP

!>          AFP est un tableau COMPLEX, dimension (N*(N+1)/2)
!>          Si FACT = 'F', alors AFP est un argument d'entrée et à
!>          l'entrée contient la matrice bloc-diagonale D et les
!>          multiplicateurs utilisés pour obtenir le facteur U ou L à
!>          partir de la factorisation A = U*D*U**T ou A = L*D*L**T
!>          telle que calculée par CSPTRF, stockée sous forme de
!>          matrice triangulaire compacte dans le même format de
!>          stockage que A.
!>
!>          Si FACT = 'N', alors AFP est un argument de sortie et à la
!>          sortie contient la matrice bloc-diagonale D et les
!>          multiplicateurs utilisés pour obtenir le facteur U ou L à
!>          partir de la factorisation A = U*D*U**T ou A = L*D*L**T
!>          telle que calculée par CSPTRF, stockée sous forme de
!>          matrice triangulaire compacte dans le même format de
!>          stockage que A.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et à
!>          l'entrée contient les détails des échanges et la structure
!>          bloc de D, tels que déterminés par CSPTRF.
!>          Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k)
!>          ont été échangées et D(k,k) est un bloc diagonal 1×1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0, alors les lignes
!>          et colonnes k-1 et -IPIV(k) ont été échangées et
!>          D(k-1:k,k-1:k) est un bloc diagonal 2×2. Si UPLO = 'L' et
!>          IPIV(k) = IPIV(k+1) < 0, alors les lignes et colonnes k+1
!>          et -IPIV(k) ont été échangées et D(k:k+1,k:k+1) est un
!>          bloc diagonal 2×2.
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et à
!>          la sortie contient les détails des échanges et la
!>          structure bloc de D, tels que déterminés par CSPTRF.
!>

B

!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>          La matrice des seconds membres B de dimension N×NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice de solution X de
!>          dimension N×NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>          L'estimation du réciproque du conditionnement de la matrice
!>          A. Si RCOND est inférieur à la précision machine (en
!>          particulier, si RCOND = 0), la matrice est singulière à la
!>          précision de travail. Cette condition est indiquée par un
!>          code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau REAL, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur de
!>          solution X(j) (la j-ième colonne de la matrice de solution
!>          X). Si XTRUE est la solution réelle correspondant à X(j),
!>          FERR(j) est une borne supérieure estimée pour la magnitude
!>          du plus grand élément dans (X(j) - XTRUE) divisée par la
!>          magnitude du plus grand élément dans X(j). L'estimation est
!>          aussi fiable que celle pour RCOND, et est presque toujours
!>          une légère surestimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau REAL, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de
!>          chaque vecteur de solution X(j) (c'est-à-dire le plus
!>          petit changement relatif dans n'importe quel élément de A
!>          ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau REAL, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur
!>                illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : D(i,i) est exactement zéro. La factorisation
!>                       a été complétée mais le facteur D est exactement                       singulière, la solution et les bornes d'erreur n'ont donc
!>                       pas pu être calculées. RCOND = 0 est retourné.
!>                = N+1 : D est non singulier, mais RCOND est inférieur à la
!>                       précision machine, ce qui signifie que la matrice est
!>                       singulière à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car il
!>                       existe un certain nombre de situations où la solution
!>                       calculée peut être plus précise que la valeur de RCOND
!>                       ne le suggérerait.
!>
