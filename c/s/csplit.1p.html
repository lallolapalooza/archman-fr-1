L'expression régulière rexp doit suivre les règles pour les expressions régulières de base décrites dans le volume Définitions de base de POSIX.1‐2017, Section 9.3, Expressions régulières de base. Le décalage optionnel doit être une valeur entière positive ou négative représentant un nombre de lignes. Une valeur entière positive peut être précédée par '+'. Si la sélection de lignes à partir d'une expression de décalage de ce type créerait un fichier avec zéro ligne, ou un fichier avec plus de lignes que celles restant dans le fichier d'entrée, les résultats sont indéfinis. Après la création de la section, la ligne courante doit être définie sur la ligne résultant de l'évaluation de l'expression régulière avec tout décalage appliqué. Si la ligne courante est la première ligne du fichier et qu'une opération d'expression régulière n'a pas encore été effectuée, la correspondance de motif de rexp doit être appliquée de la ligne courante à la fin du fichier.
