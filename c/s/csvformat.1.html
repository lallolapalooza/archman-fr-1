NOM

csvformat - Documentation csvformat

DESCRIPTION

Convertir un fichier CSV dans un format de sortie personnalisé.:

usage: csvformat [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
                 [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING]
                 [-L LOCALE] [-S] [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V]
                 [-E] [-D OUT_DELIMITER] [-T] [-A] [-Q OUT_QUOTECHAR]
                 [-U {0,1,2,3}] [-B] [-P OUT_ESCAPECHAR]
                 [-M OUT_LINETERMINATOR]
                 [FILE]
Convertit un fichier CSV dans un format de sortie personnalisé.
arguments positionnels:
  FILE                  Le fichier CSV à traiter. S'il est omis, acceptera les
                        données d'entrée via STDIN.
arguments optionnels:
  -h, --help            afficher ce message d'aide et quitter
  -E, --skip-header     Ne pas afficher de ligne d'en-tête.
  -D OUT_DELIMITER, --out-delimiter OUT_DELIMITER
                        Caractère délimitant le fichier de sortie.
  -T, --out-tabs        Spécifier que le fichier de sortie est délimité par des tabulations.
                        Remplace "-D".
  -A, --out-asv         Spécifier que le fichier de sortie est délimité par le séparateur d'unité et le séparateur d'enregistrement ASCII. Remplace
                        "-T", "-D" et "-M".
  -Q OUT_QUOTECHAR, --out-quotechar OUT_QUOTECHAR
                        Caractère utilisé pour encadrer les chaînes dans le fichier de sortie.
  -U {0,1,2,3}, --out-quoting {0,1,2,3}
                        Style d'encadrement utilisé dans le fichier de sortie : 0 encadrer minimalement, 1 tout encadrer, 2 encadrer les non-numériques, 3 ne rien encadrer.
  -B, --out-no-doublequote
                        Indique si les guillemets doubles sont doublés dans le fichier de sortie.
  -P OUT_ESCAPECHAR, --out-escapechar OUT_ESCAPECHAR
                        Caractère utilisé pour échapper le délimiteur dans le fichier de sortie si --quoting 3 ("Ne rien encadrer") est spécifié et pour
                        échapper le QUOTECHAR si --out-no-doublequote est spécifié.
  -M OUT_LINETERMINATOR, --out-lineterminator OUT_LINETERMINATOR
                        Caractère utilisé pour terminer les lignes dans le fichier de sortie.

Voir aussi : Arguments communs à tous les outils.

EXEMPLES

Convertir un fichier séparé par des virgules en un fichier délimité par des barres verticales :

csvformat -D "|" examples/dummy.csv

Convertir en fins de ligne retour chariot :

csvformat -M $'\r' examples/dummy.csv

Convertir en fichier délimité par des tabulations (TSV) sans doubler les guillemets :

printf 'key,value\n1,"a ""quoted"" string"' | csvformat -T -Q🐍

Pour éviter d'échapper les caractères de guillemet lors de l'utilisation de --quoting 3, ajoutez --out-quotechar "" :

csvformat -u3 -U3 -Q🐍 examples/optional_quote_characters.csv
