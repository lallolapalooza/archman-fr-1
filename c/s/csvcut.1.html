NOM

csvcut - Documentation csvcut

DESCRIPTION

Filtre et tronque les fichiers CSV. Comme la commande Unix "cut", mais pour les données tabulaires :

usage: csvcut [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
              [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-S] [-H]
              [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [-n] [-c COLUMNS]
              [-C NOT_COLUMNS] [-x]
              [FICHIER]
Filtre et tronque les fichiers CSV. Comme la commande Unix "cut", mais pour les données
tabulaires.
arguments positionnels :
  FICHIER               Le fichier CSV à traiter. S'il est omis, il acceptera les
                        données d'entrée via le flux standard (STDIN).
arguments optionnels :
  -h, --help            afficher ce message d'aide et quitter
  -n, --names           Afficher les noms et indices des colonnes du CSV d'entrée
                        et quitter.
  -c COLUMNS, --columns COLUMNS
                        Une liste de noms, d'indices ou de plages de colonnes à
                        extraire, séparés par des virgules, par exemple
                        "1,id,3-5". Par défaut, toutes les colonnes.
  -C NOT_COLUMNS, --not-columns NOT_COLUMNS
                        Une liste de noms, d'indices ou de plages de colonnes à
                        exclure, séparés par des virgules, par exemple
                        "1,id,3-5". Par défaut, aucune colonne. Ignore les
                        colonnes inconnues.
  -x, --delete-empty-rows
                        Après la découpe, supprime les lignes complètement vides.

Voir aussi : Arguments communs à tous les outils.

REMARQUE :

csvcut n'implémente pas le filtrage des lignes. Pour cela, vous devriez rediriger les données vers csvgrep.

REMARQUE :

Si une ligne de données est plus longue que la ligne d'en-tête, ses colonnes supplémentaires sont tronquées.

EXEMPLES

Afficher les colonnes

Afficher les indices et les noms de toutes les colonnes :

$ csvcut -n examples/realdata/FY09_EDU_Recipients_by_State.csv
  1: State Name
  2: State Abbreviate
  3: Code
  4: Montgomery GI Bill-Active Duty
  5: Montgomery GI Bill- Selective Reserve
  6: Dependents' Educational Assistance
  7: Reserve Educational Assistance Program
  8: Post-Vietnam Era Veteran's Educational Assistance Program
  9: TOTAL
 10:

Afficher uniquement les noms de toutes les colonnes, en supprimant les indices avec la commande cut :

$ csvcut -n examples/realdata/FY09_EDU_Recipients_by_State.csv | cut -c6-
State Name
State Abbreviate
Code
Montgomery GI Bill-Active Duty
Montgomery GI Bill- Selective Reserve
Dependents' Educational Assistance
Reserve Educational Assistance Program
Post-Vietnam Era Veteran's Educational Assistance Program
TOTAL

Extraire des colonnes

Extraire la première et la troisième colonnes :

csvcut -c 1,3 examples/realdata/FY09_EDU_Recipients_by_State.csv

Extraire les colonnes nommées "TOTAL" et "State Name" (dans cet ordre) :

csvcut -c TOTAL,"State Name" examples/realdata/FY09_EDU_Recipients_by_State.csv

Extraire une colonne qui peut ne pas exister dans tous les fichiers :

echo d, | csvjoin examples/dummy.csv - | csvcut -c d
 echo d, | csvjoin examples/join_no_header_row.csv - | csvcut -c d

Autre

Ajouter des numéros de ligne à un fichier, sans faire d'autres modifications :

csvcut -l examples/realdata/FY09_EDU_Recipients_by_State.csv

Afficher les valeurs uniques d'une colonne :

csvcut -c 1 examples/realdata/FY09_EDU_Recipients_by_State.csv | sed 1d | sort | uniq

Ou :

csvcut -c 1 examples/realdata/FY09_EDU_Recipients_by_State.csv | csvsql --query 'SELECT DISTINCT("State Name") FROM stdin'
