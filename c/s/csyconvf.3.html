!> à la sortie dans le paramètre A. Il convertit également sur place les détails

!> (ou CSYTRF_BK) vers le format utilisé dans CSYTRF.
!>

CSYCONVF(3)

NAME

csyconvf - Convert a string to a wide character string.

SYNOPSIS

#include <wchar.h>

wchar_t *csyconvf(const char *s);

DESCRIPTION

The csyconvf() function converts the multibyte character string pointed to by s to a wide character string.

RETURN VALUE

On success, csyconvf() returns a pointer to the converted wide character string. The returned pointer may point to static memory that may be overwritten by subsequent calls to csyconvf().

If the conversion is not possible, csyconvf() returns NULL.
