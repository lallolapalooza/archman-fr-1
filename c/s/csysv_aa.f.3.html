sous-programme csysv_aa (caractère uplo, entier n, entier nrhs, complexe, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, complexe, dimension( ldb, * ) b, entier ldb, complexe, dimension( * ) work, entier lwork, entier info)

CSYSV_AA calcule la solution du système d'équations linéaires A * X = B pour les matrices SY

Objectif :

!>
!> CSYSV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice symétrique N x N et X et B sont des matrices N x NRHS.
!>
!> L'algorithme d'Aasen est utilisé pour factoriser A comme suit :
!>    A = U**T * T * U,  si UPLO = 'U', ou
!>    A = L * T * L**T,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et de matrices triangulaires unitaires supérieures (inférieures), et T est une matrice symétrique tridiagonale. La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire N x N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          triangulaire inférieure de A n'est pas référencée.  Si UPLO = 'L', la
!>          partie inférieure triangulaire N x N de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée.
!>
!>          À la sortie, si INFO = 0, la matrice tridiagonale T et les
!>          multiplicateurs utilisés pour obtenir le facteur U ou L à partir de
!>          la factorisation A = U**T*T*U ou A = L*T*L**T tels que calculés par
!>          CSYTRF.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau ENTIER, de dimension (N)
!>          À la sortie, il contient les détails des échanges, c'est-à-dire
!>          la ligne et la colonne k de A ont été échangées avec la
!>          ligne et la colonne IPIV(k).
!>

B

!>          B est un tableau COMPLEXE, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice des seconds membres N x NRHS B.
!>          À la sortie, si INFO = 0, la matrice solution X de dimension N x NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>          La longueur de WORK.  LWORK >= MAX(2*N, 3*N-2), et pour
!>          les meilleures performances, LWORK >= max(1,N*NB), où NB est
!>          la taille de bloc optimale pour CSYTRF_AA.
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) est exactement zéro.  La factorisation
!>               a été complétée, mais la matrice diagonale par blocs D
!>               est exactement singulière, donc la solution n'a pas pu être calculée.
!>
