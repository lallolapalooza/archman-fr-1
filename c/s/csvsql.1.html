DESCRIPTIO

N

Génère des instructions SQL pour un fichier CSV ou exécute ces instructions directement sur une base de données. Dans ce dernier cas, prend en charge la création de tables et l'insertion de données

: 
utilisation : csvsql [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
              [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
              [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
              [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
              [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V]
              [-i {firebird,mssql,mysql,oracle,postgresql,sqlite,sybase}]
              [--db CONNECTION_STRING] [--query QUERIES] [--insert]
              [--prefix PREFIX] [--before-insert BEFORE_INSERT]
              [--after-insert AFTER_INSERT] [--tables TABLE_NAMES]
              [--no-constraints] [--unique-constraint UNIQUE_CONSTRAINT]
              [--no-create] [--create-if-not-exists] [--overwrite]
              [--db-schema DB_SCHEMA] [-y SNIFF_LIMIT] [-I]
              [--chunk-size CHUNK_SIZE]
              [FILE [FILE ...]]
Génère des instructions SQL pour un ou plusieurs fichiers CSV, ou exécute ces
instructions directement sur une base de données, et exécute une ou plusieurs
requêtes SQL.
arguments positionnels :
  FILE                  Le ou les fichiers CSV sur lesquels opérer. S'ils sont
                        omis, l'entrée sera acceptée sous forme de données
                        pipées via STDIN.
arguments optionnels :
  -h, --help            afficher
ce message d'aide et quitter -i {mssql,mysql,oracle,postgresql,sqlite,duckdb,crate,ingres}, --dialect {mssql,mysql,oracle,postgresql,sqlite,duckdb,crate,ingres} Dialecte SQL à générer. Ne peut pas être utilisé avec --db. --db CONNECTION_STRING S'il est présent, une chaîne de connexion SQLAlchemy à utiliser pour exécuter directement le SQL généré sur une base de données. --engine-option ENGINE_OPTION ENGINE_OPTION Un argument nommé pour create_engine() de SQLAlchemy, sous forme de paire séparée par des espaces. Cette option peut être spécifiée plusieurs fois. Par exemple : thick_mode True --query QUERIES Exécuter une ou plusieurs requêtes SQL délimitées par --sql-delimiter, et afficher le résultat de la dernière requête en CSV. QUERY peut être un nom de fichier. --query peut être spécifié plusieurs fois. --insert Insérer les données dans la table. Nécessite --db. --prefix PREFIX Ajouter une expression suivant le mot-clé INSERT, comme OR IGNORE ou OR REPLACE. --before-insert BEFORE_INSERT
Avant la commande INSERT, exécuter une ou plusieurs requêtes SQL délimitées par --sql-delimiter. Nécessite --insert. --after-insert AFTER_INSERT Après la commande INSERT, exécuter une ou plusieurs requêtes SQL délimitées par --sql-delimiter. Nécessite --insert. --sql-delimiter SQL_DELIMITER Délimiteur séparant les requêtes SQL dans --query, --before-insert et --after-insert. --tables TABLE_NAMES Une liste de noms de tables à créer, séparés par des virgules. Par défaut, les tables seront nommées d'après les noms de fichiers sans extensions ou "stdin". --no-constraints Générer un schéma sans limites de longueur ni vérifications de valeurs nulles. Utile lors de l'échantillonnage de grandes tables. --unique-constraint UNIQUE_CONSTRAINT Une liste de noms de colonnes à inclure dans une contrainte UNIQUE, séparés par des virgules. --no-create Ignorer la création de la table. Nécessite --insert. --create-if-not-exists Créer la table si elle n'existe pas, sinon continuer.
Nécessite --insert. --overwrite Supprimer la table si elle existe déjà. Nécessite --insert. Ne peut pas être utilisé avec --no-create. --db-schema DB_SCHEMA Nom optionnel du schéma de base de données dans lequel créer la ou les tables. -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT Limiter la détection du dialecte CSV au nombre de octets spécifié. Spécifiez "0" pour désactiver complètement la détection, ou "-1" pour détecter sur l'intégralité du fichier. -I, --no-inference Désactiver l'inférence de type (ainsi que --locale, --date-format, --datetime-format, --no-leading-zeroes) lors de l'analyse de l'entrée. --chunk-size CHUNK_SIZE Taille des lots pour l'insertion par lots dans la table. Nécessite --insert. --min-col-len MIN_COL_LEN La longueur minimale des colonnes de texte. --col-len-multiplier COL_LEN_MULTIPLIER Multiplier la longueur maximale de colonne par ce multiplicateur pour accommoder des valeurs plus grandes lors des exécutions suivantes.

Voir aussi : Arguments communs à tous

les outils.

Pour plus d'informations sur les chaînes de connexion et les dialectes pris en charge, consultez la documentation de SQ

LAlchemy.

Si vous préférez ne pas saisir votre mot de passe dans la chaîne de connexion, stockez le mot de passe de manière sécurisée dans un fichier de mot de passe PostgreSQL, un fichier d'options MySQL ou des fichiers similaires pour d'autres

systèmes.

raints :

Interroger et afficher des fichiers CSV en utilisant

SQL

Vous pouvez utiliser csvsql pour interroger « directement » un ou plusieurs fichiers CSV. Veuillez noter que cela créera une base de données SQLite en mémoire, donc ce ne sera pas très rapide

: 
csvsql --query  "SELECT m.usda_id, avg(i.sepal_le
ngth) AS mean_sepal_length FROM iris AS i JOIN ir
ismeta AS m ON (i.species = m.species) GROUP BY m
.species" examples/iris.csv examples/irismeta.csv

Regrouper les lignes par une colonne

: 
csvsql --query "SE
LECT * FROM 'dumm
y3' GROUP BY a" e
xamples/dummy3.csv

Concaténer deux colonnes

: 
csvsql --query "SELE
CT a || b FROM 'dumm
y3'" --no-inference
examples/dummy3.csv

Si une colonne contient des valeurs nulles, vous devez COALESCE la colonne

: 
csvsql --query "SELECT a || COALESCE(b, '') FROM 'sort_ints_nulls'" --no-infe
rence examp
les/sort_int
s_nulls.csv

L'instruction UPDATE SQL ne produit aucune sortie. N'oubliez pas de SELECT les colonnes et les lignes que vous souhaitez

: 
csvsql --query
"UPDATE 'dummy3
' SET a = 'foo'
