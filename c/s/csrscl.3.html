sous-programme csrscl (entier n, réel sa, complexe, dimension( * ) sx, entier incx)

CSRSCL multiplie un vecteur par le scalaire réel réciproque.

Objectif:

!>
!> CSRSCL multiplie un vecteur complexe x de n éléments par le scalaire réel
!> 1/a. Ceci est fait sans dépassement de capacité (overflow) ou sous-dépassement
!> de capacité (underflow) tant que le résultat final x/a ne dépasse pas
!> la capacité ou ne sous-dépasse pas.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de composantes du vecteur x.
!>

SA

!>          SA est un RÉEL
!>          Le scalaire a utilisé pour diviser chaque composante de x.
!>          SA doit être >= 0, sinon le sous-programme divisera par zéro.
!>

SX

!>          SX est un tableau COMPLEXE, dimension
!>                         (1+(N-1)*abs(INCX))
!>          Le vecteur x de n éléments.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les valeurs successives du vecteur SX.
!>          > 0:  SX(1) = X(1) et SX(1+(i-1)*INCX) = x(i),     1< i<= n
!>
