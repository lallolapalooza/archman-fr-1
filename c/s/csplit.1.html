CSPLIT(1) Commandes utilisateur CSPLIT(1)

NOM

csplit - divise un fichier en sections déterminées par des lignes de contexte

SYNTAXE

csplit [OPTION]... FICHIER MOTIF...

DESCRIPTION

Extrait des morceaux de FICHIER séparés par le(s) MOTIF(s) dans les fichiers « xx00 », « xx01 », ..., et affiche le nombre d'octets de chaque morceau sur la sortie standard.

Lit l'entrée standard si FICHIER est -

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-b, --suffix-format=FORMAT
utilise le FORMAT sprintf au lieu de %02d
-f, --prefix=PRÉFIXE
utilise le PRÉFIXE au lieu de « xx »
-k, --keep-files
ne supprime pas les fichiers de sortie en cas d'erreur
--suppress-matched
supprime les lignes correspondant au MOTIF
-n, --digits=CHIFFRES
utilise le nombre spécifié de chiffres au lieu de 2
-s, --quiet, --silent
n'affiche pas les tailles des fichiers de sortie
-z, --elide-empty-files
supprime les fichiers de sortie vides
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

Chaque MOTIF peut être :

ENTIER
copie jusqu'à, mais sans inclure, la ligne spécifiée
/EXPR_RÉGULIÈRE/[DÉCALAGE]
copie jusqu'à, mais sans inclure, une ligne correspondante
%EXPR_RÉGULIÈRE%[DÉCALAGE]
saute jusqu'à, mais sans inclure, une ligne correspondante
{ENTIER}
répète le motif précédent le nombre de fois spécifié
{*}
répète le motif précédent autant de fois que possible

Un DÉCALAGE de ligne est un entier précédé éventuellement de « + » ou « - »
