sous-programme csyrfs (caractère uplo, entier n, entier nrhs, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldaf, * ) af, entier ldaf, entier, dimension( * ) ipiv, complexe, dimension( ldb, * ) b, entier ldb, complexe, dimension( ldx, * ) x, entier ldx, réel, dimension( * ) ferr, réel, dimension( * ) berr, complexe, dimension( * ) work, réel, dimension( * ) rwork, entier info)

CSYRFS

But :

!>
!> CSYRFS améliore la solution calculée pour un système d'équations linéaires
!> lorsque la matrice de coefficients est symétrique indéfinie, et
!> fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  La partie triangulaire supérieure de A est stockée ;
!>          = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          La matrice symétrique A.  Si UPLO = 'U', la partie supérieure N par N
!>          de A contient la partie triangulaire supérieure
!>          de la matrice A, et la partie strictement triangulaire inférieure de A
!>          n'est pas référencée.  Si UPLO = 'L', la partie inférieure N par N
!>          de A contient la partie triangulaire inférieure
!>          de la matrice A, et la partie strictement triangulaire supérieure de A
!>          n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEXE, de dimension (LDAF,N)
!>          La forme factorisée de la matrice A.  AF contient la matrice
!>          diagonale par blocs D et les multiplicateurs utilisés pour obtenir
!>          U ou L à partir de la factorisation A = U*D*U**T ou
!>          A = L*D*L**T calculée par CSYTRF.
!>

LDAF

!>          LDAF est INTEGER
!>          La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Détails des échanges et de la structure de blocs de D
!>          tels que déterminés par CSYTRF.
!>

B

!>          B est un tableau COMPLEXE, de dimension (LDB,NRHS)
!>          La matrice de droite B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEXE, de dimension (LDX,NRHS)
!>          À l'entrée, la matrice solution X, telle que calculée par CSYTRS.
!>          À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

FERR

!>          FERR est un tableau RÉEL, de dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j).  L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          surestimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau RÉEL, de dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau RÉEL, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Paramètres internes :

!>  ITMAX est le nombre maximal d'étapes de raffinement itératif.
!>
