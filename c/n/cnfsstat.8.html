NOM

cnfsstat - Afficher l'utilisation des tampons CNFS

SYNTAXE

cnfsstat [-ahpPsv] [-c classe] [-i secondes] [-l [secondes]] [-m tampon]

DESCRIPTION

cnfsstat lit pathetc/cycbuff.conf et pathetc/storage.conf pour déterminer quels tampons CNFS sont disponibles. Il lit ensuite les tampons cycliques spécifiés et affiche leur état d'utilisation. cnfsstat peut être appelé depuis rc.news si docnfsstat est défini sur true dans inn.conf, et le résultat est écrit dans syslog(3).

OPTIONS

-a
En plus de sa sortie habituelle, cnfsstat affiche l'âge de l'article le plus ancien dans le cycbuff. Vous voudrez peut-être aussi utiliser l'option -v pour voir des vérifications de cohérence étendues.
-c classe
Seules les informations pour la classe spécifiée sont affichées.
-h
Affiche les informations d'utilisation et quitte.
-i secondes
Avec cette option, cnfsstat a une pause initiale de secondes secondes au démarrage. Ceci est utile lorsque cnfsstat est démarré en même temps que INN, afin qu'il puisse attendre un peu avant de commencer à effectuer ses vérifications.
-l [secondes]
Avec cette option, cnfsstat affiche un instantané de statut toutes les secondes secondes, et ne quitte que si une erreur se produit. Lorsque non spécifié, l'intervalle par défaut est de 600 secondes.

À chaque itération, cnfsstat vérifie si les fichiers cycbuff.conf et storage.conf ont été modifiés, et charge la nouvelle configuration si nécessaire.

-m tampon
Affiche des informations sur le tampon spécifié dans un format adapté à MRTG.
-p
Affiche un fichier de configuration MRTG.
-P
Écrit le PID dans pathrun/cnfsstat.pid.
-s
Écrit la sortie dans syslog(3) au lieu de la sortie standard.
-v
Écrit des informations supplémentaires, notamment sur les vérifications de cohérence du stockage des articles et du fichier history.
