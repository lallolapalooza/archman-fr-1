NOM

cntraining - entraînement de normalisation de caractères pour Tesseract

SYNOPSIS

cntraining [-D dir] FICHIER...

DESCRIPTION

cntraining prend une liste de fichiers .tr, à partir desquels il génère le fichier de données normproto (les prototypes de sensibilité de normalisation de caractères).

OPTIONS

-D dir

Répertoire où écrire les fichiers de sortie.

VOIR AUSSI
