!>
!> CCHKGG vérifie les routines du problème aux valeurs propres
!> généralisées non symétriques.
!>                                H          H        H
!> CGGHRD factorise A et B en U H V  et U T V , où   signifie transposé
!> conjugué, H est de Hessenberg, T est triangulaire et U et V sont
!> unitaires.
!>
!>                                 H          H
!> CHGEQZ factorise H et T en  Q S Z  et Q P Z , où P et S sont
!> triangulaires supérieurs et Q et Z sont unitaires.  Il calcule aussi
!> les valeurs propres généralisées (alpha(1),beta(1)),...,(alpha(n),beta(n)),
!> où alpha(j)=S(j,j) et beta(j)=P(j,j) -- ainsi, w(j) = alpha(j)/beta(j)
!> est une racine du problème aux valeurs propres généralisées
!>
!>     det( A - w(j) B ) = 0
!>
!> et m(j) = beta(j)/alpha(j) est une racine du problème essentiellement
!> équivalent
!>
!>     det( m(j) A - B ) = 0
!>
!> CTGEVC calcule la matrice L des vecteurs propres à gauche et la matrice R
!> des vecteurs propres à droite pour la paire de matrices ( S, P ).  Dans la
!> description ci-dessous,  l et r sont les vecteurs propres gauche et droit
!> correspondant aux valeurs propres généralisées (alpha,beta).
!>
!> Lorsque CCHKGG est appelé, un nombre de tailles de matrice  () et un
!> nombre de types de matrice  sont spécifiés.  Pour chaque taille ()
!> et chaque type de matrice, une matrice sera générée et utilisée
!> pour tester les routines non symétriques.  Pour chaque matrice, 13
!> tests seront effectués.  Les douze premiers  devraient être
!> petits -- O(1).  Ils seront comparés au seuil THRESH :
!>
!>                  H
!> (1)   | A - U H V  | / ( |A| n ulp )
!>
!>                  H
!> (2)   | B - U T V  | / ( |B| n ulp )
!>
!>               H
!> (3)   | I - UU  | / ( n ulp )
!>
!>               H
!> (4)   | I - VV  | / ( n ulp )
!>
!>                  H
!> (5)   | H - Q S Z  | / ( |H| n ulp )
!>
!>                  H
!> (6)   | T - Q P Z  | / ( |T| n ulp )
!>
!>               H
!> (7)   | I - QQ  | / ( n ulp )
!>
!>               H
!> (8)   | I - ZZ  | / ( n ulp )
!>
!> (9)   max sur toutes les paires valeur propre/vecteur gauche (beta/alpha,l) de
!>                           H
!>       | (beta A - alpha B) l | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (10)  max sur toutes les paires valeur propre/vecteur gauche (beta/alpha,l') de
!>                           H
!>       | (beta H - alpha T) l' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       où les vecteurs propres l' sont le résultat du passage de Q à
!>       STGEVC et de la transformation inverse (JOB='B').
!>
!> (11)  max sur toutes les paires valeur propre/vecteur droit (beta/alpha,r) de
!>
!>       | (beta A - alpha B) r | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (12)  max sur toutes les paires valeur propre/vecteur droit (beta/alpha,r') de
!>
!>       | (beta H - alpha T) r' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       où les vecteurs propres r' sont le résultat du passage de Z à
!>       STGEVC et de la transformation inverse (JOB='B').
!>
!> Les trois derniers ratios de test seront généralement petits, mais il n'y a
!> aucune exigence mathématique qu'ils le soient.  Ils sont donc
!> comparés à THRESH uniquement si TSTDIF est .TRUE.
!>
!> (13)  | S(Q,Z calculé) - S(Q,Z non calculé) | / ( |S| ulp )
!>
!> (14)  | P(Q,Z calculé) - P(Q,Z non calculé) | / ( |P| ulp )
!>
!> (15)  max( |alpha(Q,Z calculé) - alpha(Q,Z non calculé)|/|S| ,
!>            |beta(Q,Z calculé) - beta(Q,Z non calculé)|/|P| ) / ulp
!>
!> De plus, la normalisation de L et R est vérifiée et comparée
!> au seuil THRSHN.
!>
!> Matrices de test
!> ---- --------
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.
!> Les  sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ; si
!> DOTYPE(j) est .TRUE., alors le type de matrice  sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  ( 0, 0 )         (une paire de matrices nulles)
!>
!> (2)  ( I, 0 )         (une matrice identité et une matrice nulle)
!>
!> (3)  ( 0, I )         (une matrice identité et une matrice nulle)
!>
!> (4)  ( I, I )         (une paire de matrices identité)
!>
!>         t   t
!> (5)  ( J , J  )       (une paire de blocs de Jordan transposés)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         où  X = ( J   0  )  et Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       et I est une identité k x k et J un bloc de Jordan
!>                       (k+1)x(k+1) ; k=(N-1)/2
!>
!> (7)  ( D, I )         où D est P*D1, P est une matrice diagonale unitaire
!>                       aléatoire (c'est-à-dire avec des entrées de
!>                       magnitude 1 aléatoires sur la diagonale),
!>                       et D1=diag( 0, 1,..., N-1 )
!>                       (c'est-à-dire une matrice diagonale avec D1(1,1)=0,
!>                       D1(2,2)=1, ..., D1(N,N)=N-1.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) où  est proche du débordement et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        où D1=P*diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2=Q*diag( 0, N-3, N-4,..., 1, 0, 0 ), et
!>                        P et Q sont des matrices diagonales unitaires aléatoires.
!>           t   t
!> (16) U ( J , J ) V     où U et V sont des matrices unitaires aléatoires.
!>
!> (17) U ( T1, T2 ) V    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des entrées aléatoires O(1) au-dessus de la diagonale
!>                        et des entrées diagonales diag(T1) =gt;                        P*( 0, 0, 1, ..., N-3, 0 ) et diag(T2) =
!>                        Q*( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) U ( T1, T2 ) V    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = précision machine.
!>
!> (19) U ( T1, T2 ) V    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) U ( T1, T2 ) V    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) U ( T1, T2 ) V    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) U ( big*T1, small*T2 ) V   diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) U ( small*T1, big*T2 ) V   diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) U ( small*T1, small*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) U ( big*T1, big*T2 ) V     diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) U ( T1, T2 ) V     où T1 et T2 sont des matrices triangulaires
!>                         supérieures aléatoires.
!
>

Paramètre

s
NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il vaut
!>          zéro, CCHKGG ne fait rien. Il doit être au moins zéro.
!
>

N

N 
!>          NN est un tableau INTEGER de dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les
!>          matrices. Les valeurs nulles seront ignorées. Les valeurs
!>          doivent être au moins zéro.
!
>

NTYPE

S 
!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il vaut zéro,
!>          CCHKGG ne fait rien. Il doit être au moins zéro. S'il vaut
!>          MAXTYP+1 et que NSIZES vaut 1, alors un type
!>          supplémentaire, MAXTYP+1, est défini, qui consiste à
!>          utiliser quelle que soit la matrice dans A. Cela n'est
!>          utile que si DOTYPE(1:MAXTYP) vaut .FALSE. et
!>          DOTYPE(MAXTYP+1) vaut .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE est un tableau LOGICAL de dimension (NTYPES)
!>          Si DOTYPE(j) vaut .TRUE., alors pour chaque taille dans NN,
!>          une matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximal de types défini
!>          (PARAMETER MAXTYP), les types NTYPES+1 à MAXTYP ne seront
!>          pas générés. Si NTYPES est supérieur à MAXTYP,
!>          DOTYPE(MAXTYP+1) à DOTYPE(NTYPES) seront ignorés.
!
>

ISEE

D 
!>          ISEED est un tableau INTEGER de dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de
!>          nombres aléatoires. Les éléments du tableau doivent être
!>          compris entre 0 et 4095 ; sinon, ils seront réduits
!>          modulo 4096. De plus, ISEED(4) doit être impair. Le
!>          générateur de nombres aléatoires utilise une suite
!>          congruentielle linéaire limitée à de petits entiers, et
!>          doit donc produire des nombres aléatoires indépendants de
!>          la machine. Les valeurs de ISEED sont modifiées à la
!>          sortie et peuvent être utilisées dans le prochain appel à
!>          CCHKGG pour continuer la même suite de nombres aléatoires.
!
>

THRES

H 
!>          THRESH est REAL
!>          Un test sera considéré comme un échec si le rapport de
!>          test, calculé comme décrit ci-dessus, dépasse THRESH.
!>          Notez que l'erreur est mise à l'échelle pour être O(1),
!>          donc THRESH devrait être un multiple raisonnablement petit
!>          de 1, p. ex., 10 ou 100. En particulier, il ne devrait
!>          pas dépendre de la précision (simple vs. double) ni de la
!>          taille de la matrice. Il doit être au moins zéro.
!
>

TSTDI

F 
!>          TSTDIF est LOGICAL
!>          Spécifie si les rapports de test 13 à 15 seront calculés
!>          et comparés à THRESH.
!>          = .FALSE. : Seuls les rapports de test 1 à 12 seront
!>                      calculés et testés. Les rapports 13 à 15
!>                      seront mis à zéro.
!>          = .TRUE. :  Tous les rapports de test 1 à 15 seront
!>                      calculés et testés.
!
>

THRSH

N 
!>          THRSHN est REAL
!>          Seuil pour signaler l'erreur de normalisation des
!>          vecteurs propres. Si la normalisation de n'importe quel
!>          vecteur propre diffère de 1 de plus de THRSHN*ulp, alors
!>          un message d'erreur spécial sera affiché. (Cela est
!>          traité séparément des autres tests, car seul un compilateur
!>          ou une erreur de programmation devrait provoquer un
!>          message d'erreur, au moins si THRSHN vaut au moins 5--10.)
!
>

NOUNI

T 
!>          NOUNIT est INTEGER
!>          Le numéro d'unité FORTRAN pour afficher les messages
!>          d'erreur (p. ex., si une routine retourne IINFO différent
!>          de 0.)
!
>

A 
!>          A est un tableau COMPLEX de dimension (LDA, max(NN))
!>          Utilisé pour contenir la matrice A d'origine. Utilisé
!>          uniquement en entrée si NTYPES=MAXTYP+1,
!>          DOTYPE(1:MAXTYP)=.FALSE., et DOTYPE(MAXTYP+1)=.TRUE.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale de A, B, H, T, S1, P1, S2 et P2.
!>          Elle doit être au moins 1 et au moins max( NN ).
!
>

B 
!>          B est un tableau COMPLEX de dimension (LDA, max(NN))
!>          Utilisé pour contenir la matrice B d'origine. Utilisé
!>          uniquement en entrée si NTYPES=MAXTYP+1,

!
>

>

T

>

S

2

!>          calculés.
!
>

1 
!>          P1 est un tableau COMPLEX de dimension (LDA, max(NN))

!>          par CHGEQZ lorsque Q et Z sont également calculés.

>

P

2 
!>          P2 est un tableau COMPLEX de dimension (LDA, max(NN))

U 
!>          U est un tableau COMPLEX de dimension (LDU, max(NN))

>

U
