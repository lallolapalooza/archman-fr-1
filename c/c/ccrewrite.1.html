NOM

ccrewrite - Réécrit les assemblies CLR pour la vérification des contrats d'exécution.

SYNOPSIS

ccrewrite --assembly=<assembly> [options]

DESCRIPTION

Réécrit les assemblies CLR pour convertir les appels dans l'espace de noms System.Diagnostics.Contracts afin d'effectuer la vérification des contrats d'exécution. Cela inclut l'héritage de contrats pour les méthodes virtuelles.

L'assembly doit avoir été construit avec la définition du symbole CONTRACTS_FULL, sinon les appels aux méthodes de contrat auront été supprimés par le compilateur.

Actuellement, seules les pré-conditions sont prises en charge, en utilisant la méthode Contract.Requires(). L'héritage de contrats pour les méthodes virtuelles est pris en charge. Seul un nombre limité d'opérations et de types peuvent être utilisés dans une pré-condition. Un message d'erreur sera affiché si ccrewrite ne parvient pas à traiter l'assembly spécifié.

OPTIONS DE CONFIGURATION

--assembly <nom-assembly>
L'assembly à réécrire. Si aucune option --output n'est spécifiée, ce fichier est écrasé par la version réécrite.
--debug
Utilise les informations de débogage si disponibles pour améliorer l'utilité des messages d'échec de contrat.
--help
Affiche l'aide pour ccrewrite, listant les options de configuration.
--level <niveau> (défaut=4)
Définit quels types de contrats sont présents dans l'assembly réécrit : 0 = Aucun contrat ; 1 = Contrats Requires de publication ; 2 = Contrats Requires ; 3 = Contrats Ensures ; 4 = Invariants ; (Chaque niveau inclut tous les niveaux précédents)
--output <nom-fichier>
Écrit l'assembly réécrit dans le fichier spécifié. S'il n'est pas présent, le fichier d'assembly d'entrée est écrasé par la version réécrite.
--rewrite (défaut=true)
Réécrit l'assembly. Si faux, rien n'est fait.
--throwOnFailure (défaut=false)
Lève une ContractException en cas d'échec de contrat non géré. Le comportement par défaut est d'utiliser Assert.
