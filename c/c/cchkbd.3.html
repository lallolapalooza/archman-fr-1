But

!>
!> CCHKBD vérifie les routines de décomposition en valeurs singulières (SVD).
!>
!> CGEBRD réduit une matrice complexe générale A de dimensions m par n à une forme bidiagonale réelle supérieure ou inférieure par une transformation orthogonale : Q' * A * P = B
!> (ou A = Q * B * P').  La matrice B est bidiagonale supérieure si m >= n
!> et bidiagonale inférieure si m < n.
!>
!> CUNGBR génère les matrices orthogonales Q et P' à partir de CGEBRD.
!> Notez que Q et P ne sont pas nécessairement carrées.
!>
!> CBDSQR calcule la décomposition en valeurs singulières de la matrice
!> bidiagonale B sous la forme B = U S V'.  Elle est appelée trois fois pour calculer
!>    1)  B = U S1 V', où S1 est la matrice diagonale des valeurs
!>        singulières et les colonnes des matrices U et V sont les vecteurs
!>        singuliers gauche et droit de B, respectivement.
!>    2)  Identique à 1), mais les valeurs singulières sont stockées dans S2 et les
!>        vecteurs singuliers ne sont pas calculés.
!>    3)  A = (UQ) S (P'V'), la SVD de la matrice originale A.
!> De plus, CBDSQR dispose d'une option pour appliquer la matrice orthogonale gauche
!> U à une matrice X, utile dans les applications des moindres carrés.
!>
!> Pour chaque paire de dimensions de matrice (M,N) et chaque type de matrice
!> sélectionné, une matrice A de dimensions M par N et une matrice X de dimensions M par NRHS sont générées.
!> Les dimensions du problème sont les suivantes
!>    A:          M x N
!>    Q:          M x min(M,N) (mais M x M si NRHS > 0)
!>    P:          min(M,N) x N
!>    B:          min(M,N) x min(M,N)
!>    U, V:       min(M,N) x min(M,N)
!>    S1, S2      diagonale, ordre min(M,N)
!>    X:          M x NRHS
!>
!> Pour chaque matrice générée, 14 tests sont effectués :
!>
!> Test de CGEBRD et CUNGBR
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp ), PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> Test de CBDSQR sur la matrice bidiagonale B
!>
!> (4)   | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!> (5)   | Y - U Z | / ( |Y| max(min(M,N),k) ulp ), où Y = Q' X
!>                                                  et   Z = U' Y.
!> (6)   | I - U' U | / ( min(M,N) ulp )
!>
!> (7)   | I - VT VT' | / ( min(M,N) ulp )
!>
!> (8)   S1 contient min(M,N) valeurs non négatives en ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (9)   0 si les valeurs singulières réelles de B sont à l'intérieur de THRESH de
!>       celles dans S1.  2*THRESH si elles ne le sont pas.  (Testé en utilisant
!>       SSVDCH)
!>
!> (10)  | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans
!>                                   calculer U et V.
!>
!> Test de CBDSQR sur la matrice A
!>
!> (11)  | A - (QU) S (VT PT) | / ( |A| max(M,N) ulp )
!>
!> (12)  | X - (QU) Z | / ( |X| max(M,k) ulp )
!>
!> (13)  | I - (QU)'(QU) | / ( M ulp )
!>
!> (14)  | I - (VT PT) (PT'VT') | / ( N ulp )
!>
!> Les types de matrices possibles sont
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des éléments espacés uniformément
!>      1, ..., ULP  et des signes aléatoires.
!>      (ULP = (premier nombre plus grand que 1) - 1 )
!> (4)  Une matrice diagonale avec des éléments espacés géométriquement
!>      1, ..., ULP  et des signes aléatoires.
!> (5)  Une matrice diagonale avec des éléments 1, ULP, ..., ULP
!>      et des signes aléatoires.
!>
!> (6)  Identique à (3), mais multipliée par SQRT( seuil de débordement )
!> (7)  Identique à (3), mais multipliée par SQRT( seuil de débordement inférieur )
!>
!> (8)  Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des éléments espacés uniformément 1, ..., ULP avec des signes
!>      aléatoires sur la diagonale.
!>
!> (9)  Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des éléments espacés géométriquement 1, ..., ULP avec des signes
!>      aléatoires sur la diagonale.
!>
!> (10) Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des éléments 1, ULP,..., ULP avec des signes
!>      aléatoires sur la diagonale.
!>
!> (11) Identique à (8), mais multipliée par SQRT( seuil de débordement )
!> (12) Identique à (8), mais multipliée par SQRT( seuil de débordement inférieur )
!>
!> (13) Matrice rectangulaire avec des éléments aléatoires choisis dans (-1,1).
!> (14) Identique à (13), mais multipliée par SQRT( seuil de débordement )
!> (15) Identique à (13), mais multipliée par SQRT( seuil de débordement inférieur )
!>
!> Cas spécial :
!> (16) Une matrice bidiagonale avec des éléments aléatoires choisis selon une
!>      distribution logarithmique sur [ulp^2,ulp^(-2)]  (C'est-à-dire, chaque
!>      élément est  e^x, où x est choisi uniformément sur
!>      [ 2 log(ulp), -2 log(ulp) ] .)  Pour *ce* type :
!>      (a) CGEBRD n'est pas appelé pour la réduire à une forme bidiagonale.
!>      (b) la bidiagonale est  min(M,N) x min(M,N) ; si M<N, la
!>          matrice sera bidiagonale inférieure, sinon supérieure.
!>      (c) seuls les tests 5--8 et 14 sont effectués.
!>
!> Un sous-ensemble de l'ensemble complet des types de matrices peut être sélectionné via
!> le tableau logique DOTYPE.
!
>

NSIZES 
!>          NSIZES est INTEGER

!>          MVAL et NVAL.  Les tailles de matrice sont utilisées par paires (M,N).

NTYPE

S 
!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE.   Si c'est zéro, CCHKBD
!>          ne fait rien.  Il doit être au moins zéro.  Si c'est MAXTYP+1
!>          et que NSIZES est 1, alors un type supplémentaire, MAXTYP+1 est
!>          défini, qui consiste à utiliser quelles que soient les matrices dans A et B.
!>          Cela n'est utile que si DOTYPE(1:MAXTYP) est .FALSE. et
!>          DOTYPE(MAXTYP+1) est .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille (m,n), une matrice
!>          de type j sera générée.  Si NTYPES est plus petit que le
!>          nombre maximal de types défini (PARAMETER MAXTYP), alors
!>          les types NTYPES+1 à MAXTYP ne seront pas générés.  Si
!>          NTYPES est plus grand que MAXTYP, DOTYPE(MAXTYP+1) à
!>          DOTYPE(NTYPES) seront ignorés.
!
>

NRHS/i

> 
!>          NRHS est un entier
!>          Le nombre de colonnes dans les matrices X, Y,
!>          et Z, utilisées pour tester CBDSQR.  Si NRHS = 0, alors les
!>          opérations sur le second membre ne seront pas testées.
!>          NRHS doit être au moins 0.
!
>

ISEE

D 
!>          ISEED est un tableau d'entiers, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de
!>          nombres aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096.  De plus, ISEED(4) doit
!>          être impair.  Les valeurs de ISEED sont modifiées à la sortie, et peuvent
!>          être utilisées dans le prochain appel à CCHKBD pour continuer la même séquence
!>          de nombres aléatoires.
!
>

THRES

H 
!>          THRESH est un réel
!>          La valeur de seuil pour les rapports de test.  Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH.  Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.  Notez que la
!>          valeur attendue des rapports de test est O(1), donc THRESH devrait
!>          être un multiple raisonnablement petit de 1, p. ex., 10 ou 100.
!
>

INF

O 
!>          INFO est un entier
!>          Si 0, alors tout s'est déroulé correctement.
!>           -1: NSIZES < 0
!>           -2: Certains MM(j) < 0
!>           -3: Certains NN(j) < 0
!>           -4: NTYPES < 0
!>           -6: NRHS  < 0
!>           -8: THRESH < 0
!>          -11: LDA < 1 ou LDA < MMAX, où MMAX est max( MM(j) ).
!>          -17: LDB < 1 ou LDB < MMAX.
!>          -21: LDQ < 1 ou LDQ < MMAX.
!>          -23: LDP < 1 ou LDP < MNMAX.
!>          -27: LWORK trop petit.
!>          Si  CLATMR, CLATMS, CGEBRD, CUNGBR, ou CBDSQR
!>              retourne un code d'erreur, la
!>              valeur absolue de celui-ci est retournée.
!>

!>
!>     Quelques variables et paramètres locaux :
!>     ----- ----- --------- --- ----------
!>
!>     ZERO, ONE       Réels 0 et 1.
!>     MAXTYP          Le nombre de types définis.
!>     NTEST           Le nombre de tests effectués, ou qui peuvent
!>                     être effectués jusqu'à présent, pour la matrice courante.
!>     MMAX            La plus grande valeur dans NN.
!>     NMAX            La plus grande valeur dans NN.
!>     MNMIN           min(MM(j), NN(j)) (la dimension de la matrice
!>                     bidiagonale.)
!>     MNMAX           La valeur maximale de MNMIN pour j=1,...,NSIZES.
!>     NFAIL           Le nombre de tests qui ont dépassé THRESH
!>     COND, IMODE     Valeurs à passer aux générateurs de matrices.
!>     ANORM           Norme de A ; passée aux générateurs de matrices.
!>
!>     OVFL, UNFL      Seuils de débordement et de sous-flux.
!>     RTOVFL, RTUNFL  Racines carrées des 2 valeurs précédentes.
!>     ULP, ULPINV     Précision relative la plus fine et son inverse.
!>
!>             Les quatre tableaux suivants décodent JTYPE :
!>     KTYPE(j)        Le type général (1-10) pour le type .
!>     KMODE(j)        La valeur MODE à passer au générateur
!>                     de matrices pour le type .
!>     KMAGN(j)        L'ordre de grandeur ( O(1),
!>                     O(overflow^(1/2) ), O(underflow^(1/2) )
!
