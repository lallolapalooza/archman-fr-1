DESCRIPTIO

N

La commande ouvre une console d'administration et un xterm vers tous les hôtes spécifiés. Tout texte tapé dans la console d'administration est répliqué dans toutes les fenêtres. On peut également taper directement dans toutes les

fenêtres.

Cet outil est destiné (mais pas limité) à l'administration de cluster où la même configuration ou les mêmes commandes doivent être exécutées sur chaque nœud du cluster. L'exécution de ces commandes toutes à la fois via cet outil garantit que tous les nœuds restent

synchronisés.

Les connexions sont ouvertes en utilisant console qui doit être correctement installé et

configuré.

Une prudence particulière doit être prise lors de l'édition de fichiers car les lignes ne sont pas nécessairement dans le même ordre ; supposer que la ligne 5 est identique sur tous les serveurs et la modifier est dangereux. Il est préférable de rechercher la ligne spécifique à modifier et de vérifier que tous les terminaux sont comme attendu avant de valider les

changements.
