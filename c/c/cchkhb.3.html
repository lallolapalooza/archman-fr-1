CCHKHB

But :

!>
!> CCHKHB teste la réduction d'une matrice bande hermitienne en forme tridiagonale,
!> utilisée pour le problème aux valeurs propres hermitien.
!>
!> CHBTRD factorise une matrice bande hermitienne A sous la forme U S U*, où * signifie
!> transposée conjuguée, S est symétrique tridiagonale, et U est unitaire.
!> CHBTRD peut utiliser seulement le triangle inférieur ou seulement le triangle supérieur
!> de A ; CCHKHB vérifie les deux cas.
!>
!> Lorsque CCHKHB est appelée, un certain nombre de tailles de matrices (), un certain
!> nombre de largeurs de bande (), et un certain nombre de types de matrices sont
!> spécifiés. Pour chaque taille (), chaque largeur de bande () inférieure ou égale à ,
!> et chaque type de matrice, une matrice sera générée et utilisée pour tester la routine
!> de réduction des matrices hermitiennes bande. Pour chaque matrice, un certain nombre de
!> tests seront effectués :
!>
!> (1)     | A - V S V* | / ( |A| n ulp )  calculé par CHBTRD avec
!>                                         UPLO='U'
!>
!> (2)     | I - UU* | / ( n ulp )
!>
!> (3)     | A - V S V* | / ( |A| n ulp )  calculé par CHBTRD avec
!>                                         UPLO='L'
!>
!> (4)     | I - UU* | / ( n ulp )
!>
!> Les tailles sont spécifiées par un tableau NN(1:NSIZES) ; la valeur de
!> chaque élément NN(j) spécifie une taille.
!> Les types de matrices sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ;
!> si DOTYPE(j) est .VRAI., alors le type de matrice sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des entrées régulièrement espacées
!>      1, ..., ULP  et des signes aléatoires.
!>      (ULP = (premier nombre supérieur à 1) - 1 )
!> (4)  Une matrice diagonale avec des entrées géométriquement espacées
!>      1, ..., ULP  et des signes aléatoires.
!> (5)  Une matrice diagonale avec des entrées  1, ULP, ..., ULP
!>      et des signes aléatoires.
!>
!> (6)  Identique à (4), mais multiplié par SQRT( seuil de débordement )
!> (7)  Identique à (4), mais multiplié par SQRT( seuil de sous-dépassement )
!>
!> (8)  Une matrice de la forme  U* D U, où U est unitaire et
!>      D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (9)  Une matrice de la forme  U* D U, où U est unitaire et
!>      D a des entrées géométriquement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (10) Une matrice de la forme  U* D U, où U est unitaire et
!>      D a des entrées 1, ULP,..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (11) Identique à (8), mais multiplié par SQRT( seuil de débordement )
!> (12) Identique à (8), mais multiplié par SQRT( seuil de sous-dépassement )
!>
!> (13) Matrice hermitienne avec des entrées aléatoires choisies dans (-1,1).
!> (14) Identique à (13), mais multiplié par SQRT( seuil de débordement )
!> (15) Identique à (13), mais multiplié par SQRT( seuil de sous-dépassement )
!>

Paramètres

NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est zéro,
!>          CCHKHB ne fait rien. Il doit être supérieur ou égal à zéro.
!>

NN

!>          NN est un tableau INTEGER, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées. Les valeurs doivent être supérieures ou égales à zéro.
!>

NWDTHS

!>          NWDTHS est INTEGER
!>          Le nombre de largeurs de bande à utiliser. S'il est zéro,
!>          CCHKHB ne fait rien. Il doit être supérieur ou égal à zéro.
!>

KK

!>          KK est un tableau INTEGER, dimension (NWDTHS)
!>          Un tableau contenant les largeurs de bande à utiliser pour les matrices bande.
!>          Les valeurs doivent être supérieures ou égales à zéro.
!>

NTYPES

!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, CCHKHB
!>          ne fait rien. Il doit être supérieur ou égal à zéro. S'il est MAXTYP+1
!>          et que NSIZES est 1, alors un type supplémentaire, MAXTYP+1 est
!>          défini, qui consiste à utiliser la matrice présente dans A. Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FAUX. et
!>          DOTYPE(MAXTYP+1) est .VRAI. .
!>

DOTYPE

!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) est .VRAI., alors pour chaque taille dans NN une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximum de types
!>          définis (PARAMETER MAXTYP), alors les types NTYPES+1 jusqu'à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruente limitée à de petits entiers, et devrait donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées
!>          lors de l'appel suivant à CCHKHB pour continuer la même séquence de
!>          nombres aléatoires.
!>

THRESH

!>          THRESH est REAL
!>          Un test sera considéré comme dépassant le seuil si la valeur calculée,
!>          comme décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être de l'ordre de 1, donc THRESH devrait être un multiple raisonnablement
!>          petit de 1, par exemple 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. Il doit être supérieur ou égal à zéro.
!>

NOUNIT

!>          NOUNIT est INTEGER
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine renvoie IINFO différent de 0).
!>

A

!>          A est un tableau COMPLEX, dimension
!>                            (LDA, max(NN))
!>          Utilisé pour contenir la matrice dont les valeurs propres doivent être
!>          calculées.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A. Elle doit être au moins 2 (pas 1 !)
!>          et au moins max( KK )+1.
!>

SD

!>          SD est un tableau REAL, dimension (max(NN))
!>          Utilisé pour contenir la diagonale de la matrice tridiagonale calculée
!>          par CHBTRD.
!>

SE

!>          SE est un tableau REAL, dimension (max(NN))
!>          Utilisé pour contenir les sous-diagonales de la matrice tridiagonale
!>          calculée par CHBTRD.
!>

U

!>          U est un tableau COMPLEX, dimension (LDU, max(NN))
!>          Utilisé pour contenir la matrice unitaire calculée par CHBTRD.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale de U. Elle doit être au moins 1
!>          et au moins max( NN ).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (LWORK)
!>          Espace de travail de la routine. La taille requise est calculée
!>          par CHBTRD lors d'un appel avec LWORK= -1.
!>

LWORK

!>          LWORK est INTEGER
!>          La taille du tableau WORK. Elle doit être au moins 1.
!>

RWORK

!>          RWORK est un tableau REAL, dimension (max(NN))
!>          Espace de travail réel de la routine.
!>

RESULT

!>          RESULT est un tableau REAL, dimension (4)
!>          Les quatre valeurs de test calculées par la routine.
!>          RESULT(1) = | A - V S V* | / ( |A| n ulp )
!>          RESULT(2) = | I - UU* | / ( n ulp )
!>          RESULT(3) = | A - V S V* | / ( |A| n ulp )
!>          RESULT(4) = | I - UU* | / ( n ulp )
!>

INFO

!>          INFO est INTEGER
!>          = 0 : échec attendu.
!>          > 0 : nombre d'erreurs détectées.
!>
>

TRAVAI

L 
!>          WORK est un tableau COMPLEX, dimension (LWORK)
!
>

LWOR

K 
!>          LWORK est un INTEGER
!>          Le nombre d'entrées dans WORK.  Cela doit être au moins
!>          max( LDA+1, max(NN)+1 )*max(NN).
!
>

RWOR

K 
!>          RWORK est un tableau REAL
!
>

RESUL

T 
!>          RESULT est un tableau REAL, dimension (4)
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter
!>          le débordement.
!
>

INF

O 
!>          INFO est un INTEGER
!>          Si 0, alors tout s'est déroulé correctement.
!>
!>-----------------------------------------------------------------------
!>
!>       Quelques variables et paramètres locaux :
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Réels 0 et 1.
!>       MAXTYP          Le nombre de types définis.
!>       NTEST           Le nombre de tests effectués, ou qui peuvent
!>                       être effectués jusqu'ici, pour la matrice courante.
!>       NTESTT          Le nombre total de tests effectués jusqu'ici.
!>       NMAX            La plus grande valeur dans NN.
!>       NMATS           Le nombre de matrices générées jusqu'ici.
!>       NERRS           Le nombre de tests qui ont dépassé THRESH

!>       COND, IMODE     Valeurs à passer aux générateurs de matrices.
!>       ANORM           Norme de A ; passée aux générateurs de matrices.
!>
!>       OVFL, UNFL      Seuils de débordement et de sous-flottement.
!>       ULP, ULPINV     Précision relative la plus fine et son inverse.
!>       RTOVFL, RTUNFL  Racines carrées des 2 valeurs précédentes.

!>       KTYPE(j)        Le type général (1-10) pour le type .

!>
