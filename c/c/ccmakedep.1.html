ccmakedep(1) Manuel des commandes générales ccmakedep(1)

NOM

ccmakedep - crée les dépendances dans les makefiles en utilisant un compilateur C

SYNTAXE

ccmakedep [ cpp-flags ] [ -wlargeur ] [ -schaîne-magique ] [ -fmakefile ] [ -osuffixe-objet ] [ -v ] [ -a ] [ -cccompilateur ] [ -- options -- ] fichier-source ...

DESCRIPTION

Le programme ccmakedep appelle un compilateur C pour prétraiter chaque fichier-source, et utilise la sortie pour construire des règles de makefile décrivant leurs dépendances. Ces règles indiquent à make(1) quels fichiers objets doivent être recompilés lorsqu'une dépendance a changé.

Par défaut, ccmakedep place sa sortie dans le fichier nommé makefile s'il existe, sinon Makefile. Un makefile alternatif peut être spécifié avec l'option -f. Il recherche d'abord dans le makefile une ligne commençant par

# DO NOT DELETE

ou celle fournie avec l'option -s, comme délimiteur pour la sortie des dépendances. S'il la trouve, il supprimera tout ce qui suit jusqu'à la fin du makefile et placera la sortie après cette ligne. S'il ne la trouve pas, le programme ajoutera la chaîne au makefile et placera la sortie après.

EXEMPLE

Normalement, ccmakedep sera utilisé dans une cible de makefile afin qu'en tapant 'make depend', les dépendances soient mises à jour pour le makefile. Par exemple,

    SRCS = file1.c file2.c ...
    CFLAGS = -O -DHACK -I../foobar -xyz
    depend:
            ccmakedep -- $(CFLAGS) -- $(SRCS)

OPTIONS

Le programme ignorera toute option qu'il ne comprend pas, vous pouvez donc utiliser les mêmes arguments que ceux que vous utiliseriez pour cc(1), y compris les options -D et -U pour définir et annuler la définition de symboles, et -I pour définir le chemin d'inclusion.

-a
Ajoute les dépendances au fichier au lieu de remplacer les dépendances existantes.
-cccompilateur
Utilise ce compilateur pour générer les dépendances.
-fmakefile
Nom de fichier. Cela vous permet de spécifier un makefile alternatif dans lequel ccmakedep peut placer sa sortie. Spécifier “-” comme nom de fichier (c'est-à-dire -f-) envoie la sortie vers la sortie standard au lieu de modifier un fichier existant.
-schaîne
Délimiteur de chaîne de départ. Cette option permet de spécifier une chaîne différente que ccmakedep recherchera dans le makefile. La valeur par défaut est “# DO NOT DELETE”.
-v
Soyez verbeux : affichez la commande du compilateur C avant de l'exécuter.
-- options --
Si cc makedep rencontre un double trait d'union (--) dans la liste des arguments, alors tous les arguments non reconnus qui le suivent seront ignorés silencieusement. Un second double trait d'union met fin à ce traitement spécial. De cette manière, cc makedep peut ignorer en toute sécurité les arguments ésotériques du compilateur qui pourraient normalement se trouver dans une macro CFLAGS de make (voir la section EXEMPLE ci-dessus). Les options -D, -I et -U appartenant à la paire de doubles traits d'union sont toujours traitées normalement.

VOIR AUSSI

cc(1), make(1), makedepend(1), ccmakedep(1).
