subroutine cchkhb (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) sd, real, dimension( * ) se, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result, integer

CCHKH

B

But

: 
!>
!> CCHKHB teste la réduction d'une matrice hermitienne par bandes en
!> forme tridiagonale, utilisée avec le problème des valeurs propres
!> hermitiennes.
!>
!> CHBTRD factorise une matrice hermitienne par bandes A sous la forme
!> U S U*, où * désigne la transposée conjuguée, S est tridiagonale
!> symétrique, et U est unitaire. CHBTRD peut utiliser soit uniquement
!> le triangle inférieur, soit uniquement le triangle supérieur de A ;
!> CCHKHB vérifie les deux cas.
!>
!> Lorsque CCHKHB est appelé, un nombre de tailles de matrices (),
!> un nombre de largeurs de bande (), et un nombre de types de
!> matrices sont spécifiés. Pour chaque taille (), chaque largeur de
!> bande () inférieure ou égale à , et chaque type de matrice, une
!> matrice sera générée et utilisée pour tester la routine de réduction
!> hermitienne par bandes. Pour chaque matrice, un certain nombre de
!> tests seront effectués :
!>
!> (1)     | A - V S V* | / ( |A| n ulp )  calculé par CHBTRD avec
!>                                         UPLO='U'
!>
!> (2)     | I - UU* | / ( n ulp )
!>
!> (3)     | A - V S V* | / ( |A| n ulp )  calculé par CHBTRD avec
!>                                         UPLO='L'
!>
!> (4)     | I - UU* | / ( n ulp )
!>
!> Les  sont spécifiés par un tableau NN(1:NSIZES) ; la valeur de
!> chaque élément NN(j) spécifie une taille.
!> Les  sont spécifiés par un tableau booléen DOTYPE( 1:NTYPES ) ;
!> si DOTYPE(j) est .TRUE., alors le type de matrice  sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des éléments espacés uniformément
!>      1, ..., ULP  et des signes aléatoires.
!>      (ULP = (premier nombre plus grand que 1) - 1 )
!> (4)  Une matrice diagonale avec des éléments espacés géométriquement
!>      1, ..., ULP  et des signes aléatoires.
!> (5)  Une matrice diagonale avec  éléments 1, ULP, ..., ULP
!>      et des signes aléatoires.
!>
!> (6)  Identique à (4), mais multiplié par SQRT( seuil de débordement )
!> (7)  Identique à (4), mais multiplié par SQRT( seuil de dépassement négatif )
!>
!> (8)  Une matrice de la forme  U* D U, où U est unitaire et
!>      D a des éléments espacés uniformément 1, ..., ULP avec des
!>      signes aléatoires sur la diagonale.
!>
!> (9)  Une matrice de la forme  U* D U, où U est unitaire et
!>      D a des éléments espacés géométriquement 1, ..., ULP avec des
!>      signes aléatoires sur la diagonale.
!>
!> (10) Une matrice de la forme  U* D U, où U est unitaire et
!>      D a  éléments 1, ULP,..., ULP avec des
!>      signes aléatoires sur la diagonale.
!>
!> (11) Identique à (8), mais multiplié par SQRT( seuil de débordement )
!> (12) Identique à (8), mais multiplié par SQRT( seuil de dépassement négatif )
!>
!> (13) Matrice hermitienne avec des éléments aléatoires choisis dans (-1,1).
!> (14) Identique à (13), mais multiplié par SQRT( seuil de débordement )
!> (15) Identique à (13), mais multiplié par SQRT( seuil de dépassement négatif )
!
>

Paramètre

s
NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est
!>          zéro, CCHKHB ne fait rien. Il doit être au moins zéro.
!
>

N

N 
!>          NN est un tableau INTEGER, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les
!>          matrices. Les valeurs nulles seront ignorées. Les valeurs
!>          doivent être au moins zéro.
!
>

NWDTH

S 
!>          NWDTHS est INTEGER
!>          Le nombre de largeurs de bande à utiliser. S'il est zéro,
!>          CCHKHB ne fait rien. Il doit être au moins zéro.
!
>

K

K 
!>          KK est un tableau INTEGER, dimension (NWDTHS)
!>          Un tableau contenant les largeurs de bande à utiliser pour
!>          les matrices par bandes. Les valeurs doivent être au moins
!>          zéro.
!
>

NTYPE

S 
!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, CCHKHB
!>          ne fait rien. Il doit être au moins zéro. S'il vaut
!>          MAXTYP+1 et que NSIZES vaut 1, alors un type supplémentaire,
!>          MAXTYP+1, est défini, qui consiste à utiliser la matrice
!>          quelconque présente dans A. Cela n'est utile que si
!>          DOTYPE(1:MAXTYP) est .FALSE. et DOTYPE(MAXTYP+1) est .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille dans NN
!>          une matrice de cette taille et de type j sera générée.
!>          Si NTYPES est plus petit que le nombre maximal de types
!>          défini (PARAMÈTRE MAXTYP), les types NTYPES+1 à MAXTYP
!>          ne seront pas générés. Si NTYPES est plus grand que
!>          MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!
>

ISEE

D 
!>          ISEED est un tableau INTEGER, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de
!>          nombres aléatoires. Les éléments du tableau doivent être
!>          compris entre 0 et 4095 ; sinon, ils seront réduits modulo
!>          4096. De plus, ISEED(4) doit être impair. Le générateur de
!>          nombres aléatoires utilise une suite congruentielle linéaire
!>          limitée à de petits entiers, et devrait donc produire des
!>          nombres aléatoires indépendants de la machine. Les valeurs
!>          de ISEED sont modifiées à la sortie, et peuvent être
!>          utilisées dans le prochain appel à CCHKHB pour continuer
!>          la même suite de nombres aléatoires.
!
>

THRES

H 
!>          THRESH est REAL
!>          Un test sera considéré comme  si le , calculé comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur est
!>          mise à l'échelle pour être O(1), donc THRESH devrait être
!>          un multiple raisonnablement petit de 1, p. ex., 10 ou 100.
!>          En particulier, il ne devrait pas dépendre de la précision
!>          (simple vs. double) ni de la taille de la matrice. Il doit
!>          être au moins zéro.
!
>

NOUNI

T 
!>          NOUNIT est INTEGER
!>          Le numéro d'unité FORTRAN pour l'affichage des messages
!>          d'erreur (p. ex., si une routine retourne IINFO différent
!>          de 0).
!
>

A 
!>          A est un tableau COMPLEX, dimension
!>                            (LDA, max(NN))
!>          Utilisé pour stocker la matrice dont les valeurs propres
!>          doivent être calculées.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale de A. Elle doit être au moins 2
!>          (pas 1 !) et au moins max( KK )+1.
!
>

S

D 
!>          SD est un tableau REAL, dimension (max(NN))
!>          Utilisé pour stocker la diagonale de la matrice
!>          tridiagonale calculée par CHBTRD.
!
>

S

E 
!>          SE est un tableau REAL, dimension (max(NN))
!>          Utilisé pour stocker la sous-diagonale de la matrice
!>          tridiagonale calculée par CHBTRD.
!
>

U 
!>          U est un tableau COMPLEX, dimension (LDU, max(NN))
!>          Utilisé pour stocker la matrice unitaire calculée par
!>          CHBTRD.
!
>

LD

U 
!>          LDU est INTEGER
!>          La dimension principale de U. Elle doit être au moins 1
!>          et au moins max( NN ).

!
>

WOR

K 
!>          WORK est un tableau COMPLEX de dimension (LWORK)
!
>

LWOR

K 
!>          LWORK est un INTEGER
!>          Le nombre d'entrées dans WORK.  Doit être au moins
!>          max( LDA+1, max(NN)+1 )*max(NN).
!
>

RWOR

K 
!>          RWORK est un tableau REAL
!
>

RESUL

T 
!>          RESULT est un tableau REAL de dimension (4)
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, afin
!>          d'éviter un débordement.
!
>

INF

O 
!>          INFO est un INTEGER
!>          Si 0, tout s'est déroulé correctement.
!>
!>-----------------------------------------------------------------------
!>
!>       Quelques variables et paramètres locaux :
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Réels 0 et 1.
!>       MAXTYP          Le nombre de types définis.
!>       NTEST           Le nombre de tests effectués, ou pouvant être
!>                       effectués jusqu'à présent, pour la matrice courante.
!>       NTESTT          Le nombre total de tests effectués jusqu'à présent.
!>       NMAX            La plus grande valeur dans NN.
!>       NMATS           Le nombre de matrices générées jusqu'à présent.
!>       NERRS           Le nombre de tests qui ont dépassé THRESH
!>                       jusqu'à présent.
!>       COND, IMODE     Valeurs à transmettre aux générateurs de matrices.
!>       ANORM           Norme de A ; transmise aux générateurs de matrices.
!>
!>       OVFL, UNFL      Seuils de débordement et de sous-flux.
!>       ULP, ULPINV     Précision relative la plus fine et son inverse.
!>       RTOVFL, RTUNFL  Racines carrées des 2 valeurs précédentes.
!>               Les quatre tableaux suivants décodent JTYPE :
!>       KTYPE(j)        Le type général (1-10) pour le type .
!>       KMODE(j)        La valeur MODE à transmettre au générateur
!>                       de matrices pour le type .
!>       KMAGN(j)        L'ordre de grandeur ( O(1),
!>                       O(overflow^(1/2) ), O(underflow^(1/2) )
!
