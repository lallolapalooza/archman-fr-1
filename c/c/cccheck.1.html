NOM

cccheck - Effectue la vérification statique des contrats de code pour les assemblages CLR.

SYNTAXE

cccheck --assembly=<assembly> [options]

DESCRIPTION

Effectue la vérification statique des contrats de code pour trouver les bugs et les incohérences entre le code et la spécification. Cela inclut les analyses d'entiers et de non-nullité.

L'assembly doit avoir été compilé avec la définition de symbole CONTRACTS_FULL, sinon les appels aux méthodes de contrat auront été supprimés par le compilateur.

Actuellement, seules les méthodes Contract.Assume() et Contract.Assert() sont prises en charge. Seule l'analyse de non-nullité est prise en charge, les analyses consécutives sont en cours de développement. Un message d'erreur sera affiché si cccheck ne parvient pas à traiter tout ou partie des méthodes de l'assembly spécifié.

OPTIONS DE CONFIGURATION

--assembly <nom-assembly>
L'assembly sur lequel effectuer la vérification statique.
--debug
Affiche des informations de débogage sur le processus de preuve des assertions. Il affiche quatre niveaux d'abstraction : niveau brut, niveau pile, niveau tas et niveau d'expression substituée.
--method=<sous-chaîne-nom-méthode>
Chaîne pour trouver la méthode. Elle filtre toutes les méthodes de l'assembly où le nom de la méthode contient ce paramètre comme sous-chaîne.
--help
Affiche l'aide de cccheck, listant les options de configuration.

EXEMPLES

Supposez que vous ayez une méthode :

void Method() {
object x = null;
int y = 1;
if (y % 2 == 1)
x = new object();
else
x = new string();


Contract.Assert(x != null); }

Après la vérification, l'outil présentera les résultats dans le format suivant : "Assertion à : [Sous-routine : <id> Bloc <idBloc> PC <id>] :
est (vrai|faux|non prouvé|inatteignable)". (PC est un compteur ordinal)
