CCOMPS(1) Manuel des commandes générales CCOMPS(1)

NOM

ccomps - filtre de composantes connexes pour graphes

SYNOPIS

ccomps [ -sxvenzC? ] [ -X[#%]s[-f] ] [ -ofichier_sortie ] [ fichiers ]

DESCRIPTION

ccomps décompose les graphes en leurs composantes connexes, imprimant les composantes sur la sortie standard.

OPTIONS

Les options suivantes sont supportées :

-e
Ne pas induire d'arêtes dans les composantes connexes.
-s
Aucun graphe de sortie n'est imprimé. La valeur de retour peut être utilisée pour vérifier si le graphe est connexe ou non.
-x
Seules les composantes connexes sont imprimées, sous forme de graphes séparés.
-v
Les comptes de nœuds, d'arêtes et de composantes connexes sont imprimés.
-z
Trier les composantes par taille, la plus grande en premier. Ceci n'est effectif que si -x ou -X# est présent. Ainsi, -zX#0 imprimera la plus grande composante.
-C
Utiliser les clusters dans le calcul des composantes en plus de la connectivité normale des arêtes. Essentiellement, cela donne les composantes connexes du graphe dérivé dans lequel les nœuds sont les clusters de haut niveau et les nœuds du graphe original. Cela maintient toute structure de sous-graphe au sein d'une composante, même si un sous-graphe ne contient aucun nœud.
-n
Ne pas projeter la structure des sous-graphes. Normalement, si ccomps produit des composantes sous forme de graphes distincts du graphe d'entrée, il définit des sous-graphes qui sont des projections de sous-graphes du graphe d'entrée sur la composante. (Si la projection est vide, aucun sous-graphe n'est produit.) Si ce drapeau est activé, la composante ne contient que les nœuds et arêtes pertinents.
-X nom_nœud
Imprime uniquement la composante contenant le nœud nom_nœud, s'il existe.
-X# début
-X# début-
-X# début-fin
Imprime uniquement les composantes dans la plage d'indices donnée. Dans la première forme, seule la composante dont l'indice est début, s'il existe, est imprimée. Dans la seconde forme, chaque composante dont l'indice est supérieur ou égal à début est imprimée. Dans la dernière forme, seules les composantes dont les indices sont dans la plage [Idébut,fin] sont imprimées. Ainsi, le drapeau -x est équivalent à -X#0-.
-X% min
-X% min-
-X% min-max
Imprime uniquement les composantes dans la plage de tailles donnée. Dans la première forme, seule une composante dont la taille est min, s'il existe, est imprimée. Dans la seconde forme, chaque composante dont la taille est supérieure ou égale à min est imprimée. Dans la dernière forme, seules les composantes dont les tailles sont dans la plage [Imin,max] sont imprimées.
-o fichier_sortie
Si spécifié, chaque graphe sera écrit dans un fichier différent avec des noms dérivés de fichier_sortie. En particulier, si les drapeaux -o et -x sont utilisés, chaque composante connexe est écrite dans un fichier différent. Si fichier_sortie n'a pas de suffixe, le premier fichier sera nommé fichier_sortie ; puis le suivant fichier_sortie_1, puis le suivant fichier_sortie_2, et ainsi de suite. Si fichier_sortie a un suffixe, c'est-à-dire qu'il a la forme base.sfx, alors les fichiers seront nommés base.sfx, base_1.sfx, base_2.sfx, etc.

Par défaut, chaque graphe d'entrée est imprimé, chaque composante connexe étant donnée comme un sous-graphe dont le nom est une concaténation du nom du graphe d'entrée, de la chaîne "_cc_" et du numéro de la composante.

OPÉRANDES

L'opérande suivant est supporté :

fichiers
Noms des fichiers contenant 1 ou plusieurs graphes au format dot. Si aucun opérande fichiers n'est spécifié, l'entrée standard sera utilisée.

CODES DE RETOUR

Sauf si utilisé pour extraire une seule composante connexe, ccomps retourne 0 si tous les graphes d'entrée sont connexes ; et non nul si un graphe a plusieurs composantes, ou si une erreur s'est produite. Si seule une composante est extraite, ccomps retourne 0 en cas de succès et non nul en cas d'erreur.

BOGUES

Il est possible, bien qu'improbable, que les noms utilisés pour les composantes connexes et leurs sous-graphes entrent en conflit avec des noms de sous-graphes existants.
