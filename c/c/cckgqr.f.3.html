CCKGQR

But :

!>
!> CCKGQR teste
!> CGGQRF: factorisation GQR pour la matrice A de N par M et la matrice B de N par P,
!> CGGRQF: factorisation GRQ pour la matrice A de M par N et la matrice B de P par N.
!>

Paramètres

NM 
!>          NM est un entier
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'entiers, dimension (NM)
!>          Les valeurs de la dimension ligne (colonne) de matrice M.
!>

NP

!>          NP est un entier
!>          Le nombre de valeurs de P contenues dans le vecteur PVAL.
!>

PVAL

!>          PVAL est un tableau d'entiers, dimension (NP)
!>          Les valeurs de la dimension ligne (colonne) de matrice P.
!>

NN

!>          NN est un entier
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'entiers, dimension (NN)
!>          Les valeurs de la dimension colonne (ligne) de matrice N.
!>

NMATS

!>          NMATS est un entier
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrices. Si NMATS >= NTYPES (le nombre maximum
!>          de types de matrices), alors tous les différents types sont
!>          générés pour le test. Si NMATS < NTYPES, une autre ligne d'entrée
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau d'entiers, dimension (4)
!>          En entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          En sortie, la prochaine graine dans la séquence de nombres aléatoires après
!>          la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est un réel
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un entier
!>          La valeur maximale permise pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau complexe, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau complexe, dimension (NMAX*NMAX)
!>

AQ

!>          AQ est un tableau complexe, dimension (NMAX*NMAX)
!>

AR

!>          AR est un tableau complexe, dimension (NMAX*NMAX)
!>

TAUA

!>          TAUA est un tableau complexe, dimension (NMAX)
!>

B

!>          B est un tableau complexe, dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau complexe, dimension (NMAX*NMAX)
!>

BZ

!>          BZ est un tableau complexe, dimension (NMAX*NMAX)
!>

BT

!>          BT est un tableau complexe, dimension (NMAX*NMAX)
!>

BWK

!>          BWK est un tableau complexe, dimension (NMAX*NMAX)
!>

TAUB

!>          TAUB est un tableau complexe, dimension (NMAX)
!>

WORK

!>          WORK est un tableau complexe, dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK est un tableau réel, dimension (NMAX)
!>

NIN

!>          NIN est un entier
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est un entier
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est un entier
!>          = 0 :  sortie réussie
!>          > 0 :  Si CLATMS retourne un code d'erreur, sa valeur absolue est
!>                 retournée.
!>
