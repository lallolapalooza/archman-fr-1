!>
!> CCHKBD vérifie les routines de décomposition en valeurs singulières (SVD).
!>
!> CGEBRD réduit une matrice générale complexe A de dimensions m par n à une forme bidiagonale réelle supérieure ou inférieure par une transformation orthogonale : Q' * A * P = B
!> (ou A = Q * B * P').  La matrice B est bidiagonale supérieure si m >= n
!> et bidiagonale inférieure si m < n.
!>
!> CUNGBR génère les matrices orthogonales Q et P' à partir de CGEBRD.
!> Notez que Q et P ne sont pas nécessairement carrées.
!>
!> CBDSQR calcule la décomposition en valeurs singulières de la matrice
!> bidiagonale B sous la forme B = U S V'.  Elle est appelée trois fois pour calculer
!>    1)  B = U S1 V', où S1 est la matrice diagonale des valeurs
!>        singulières et les colonnes des matrices U et V sont les vecteurs
!>        singuliers gauche et droit, respectivement, de B.
!>    2)  Identique à 1), mais les valeurs singulières sont stockées dans S2 et les
!>        vecteurs singuliers ne sont pas calculés.
!>    3)  A = (UQ) S (P'V'), la SVD de la matrice originale A.
!> De plus, CBDSQR dispose d'une option pour appliquer la matrice orthogonale gauche
!> U à une matrice X, utile dans les applications de moindres carrés.
!>
!> Pour chaque paire de dimensions de matrice (M,N) et chaque type de matrice
!> sélectionné, une matrice A de dimensions M par N et une matrice X de dimensions M par NRHS sont générées.
!> Les dimensions du problème sont les suivantes
!>    A:          M x N
!>    Q:          M x min(M,N) (mais M x M si NRHS > 0)
!>    P:          min(M,N) x N
!>    B:          min(M,N) x min(M,N)
!>    U, V:       min(M,N) x min(M,N)
!>    S1, S2      diagonale, ordre min(M,N)
!>    X:          M x NRHS
!>
!> Pour chaque matrice générée, 14 tests sont effectués :
!>
!> Test de CGEBRD et CUNGBR
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp ), PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> Test de CBDSQR sur la matrice bidiagonale B
!>
!> (4)   | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!> (5)   | Y - U Z | / ( |Y| max(min(M,N),k) ulp ), où Y = Q' X
!>                                                  et   Z = U' Y.
!> (6)   | I - U' U | / ( min(M,N) ulp )
!>
!> (7)   | I - VT VT' | / ( min(M,N) ulp )
!>
!> (8)   S1 contient min(M,N) valeurs non négatives en ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (9)   0 si les vraies valeurs singulières de B sont dans THRESH de
!>       celles de S1.  2*THRESH si elles ne le sont pas.  (Testé avec
!>       SSVDCH)
!>
!> (10)  | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans
!>                                   calculer U et V.
!>
!> Test de CBDSQR sur la matrice A
!>
!> (11)  | A - (QU) S (VT PT) | / ( |A| max(M,N) ulp )
!>
!> (12)  | X - (QU) Z | / ( |X| max(M,k) ulp )
!>
!> (13)  | I - (QU)'(QU) | / ( M ulp )
!>
!> (14)  | I - (VT PT) (PT'VT') | / ( N ulp )
!>
!> Les types de matrices possibles sont
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des entrées espacées uniformément
!>      1, ..., ULP  et des signes aléatoires.
!>      (ULP = (premier nombre plus grand que 1) - 1 )
!> (4)  Une matrice diagonale avec des entrées espacées géométriquement
!>      1, ..., ULP  et des signes aléatoires.
!> (5)  Une matrice diagonale avec des entrées 1, ULP, ..., ULP
!>      et des signes aléatoires.
!>
!> (6)  Identique à (3), mais multiplié par SQRT( seuil de débordement )
!> (7)  Identique à (3), mais multiplié par SQRT( seuil de débordement inférieur )
!>
!> (8)  Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des entrées espacées uniformément 1, ..., ULP avec des signes
!>      aléatoires sur la diagonale.
!>
!> (9)  Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des entrées espacées géométriquement 1, ..., ULP avec des signes
!>      aléatoires sur la diagonale.
!>
!> (10) Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des entrées 1, ULP,..., ULP avec des signes
!>      aléatoires sur la diagonale.
!>
!> (11) Identique à (8), mais multiplié par SQRT( seuil de débordement )
!> (12) Identique à (8), mais multiplié par SQRT( seuil de débordement inférieur )
!>
!> (13) Matrice rectangulaire avec des entrées aléatoires choisies dans (-1,1).
!> (14) Identique à (13), mais multiplié par SQRT( seuil de débordement )
!> (15) Identique à (13), mais multiplié par SQRT( seuil de débordement inférieur )
!>
!> Cas spécial :
!> (16) Une matrice bidiagonale avec des entrées aléatoires choisies selon une
!>      distribution logarithmique sur [ulp^2,ulp^(-2)]  (C'est-à-dire que chaque
!>      entrée est  e^x, où x est choisi uniformément sur
!>      [ 2 log(ulp), -2 log(ulp) ] .)  Pour *ce* type :
!>      (a) CGEBRD n'est pas appelé pour la réduire à une forme bidiagonale.
!>      (b) la bidiagonale est  min(M,N) x min(M,N) ; si M<N, la
!>          matrice sera bidiagonale inférieure, sinon supérieure.
!>      (c) seuls les tests 5--8 et 14 sont effectués.
!>
!> Un sous-ensemble de l'ensemble complet des types de matrices peut être sélectionné via
!> le tableau logique DOTYPE.
!
>

E 
!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille (m,n), une matrice
!>          de type j sera générée.  Si NTYPES est plus petit que le
!>          nombre maximal de types défini (PARAMETER MAXTYP), alors
!>          les types NTYPES+1 à MAXTYP ne seront pas générés.  Si
!>          NTYPES est plus grand que MAXTYP, DOTYPE(MAXTYP+1) à
!>          DOTYPE(NTYPES) seront ignorés.
!

NAME

cchkbd — The general meaning of XXXXX

SYNOPSIS

      SUBROUTINE CCHKSB ( NSIZES, NTYPES, NTEST, KVAL, MVAL, NVAL,
     $                   NRHS, ISEED, THRESH, A, LDA, BD, BE, S1, S2,
     $                   X, LDX, Y, Z, Q, LDQ, PT, LDPT, U, VT, WORK,
     $                   LWORK, RWORK, NOUT, INFO )

Function/Subroutine Documentation

This subroutine tests the driver subroutine CGEBRD, which reduces a general complex matrix to bidiagonal form. (A standard LAPACK routine requires that the matrix A be stored in a bidiagonal format, so that it is diagonal matrix with potentially non-zero sub- and super-diagonals.)

The following array parameters are standard LAPACK arguments:

NSIZES

!>          NSIZES is INTEGER
!>          The number of values specified in the arrays MVAL and NVAL.
!>

NTYPES

!>          NTYPES is INTEGER
!>          The number of matrix types to be tested.
!>

NTEST

!>          NTEST is INTEGER
!>          The number of tests to perform for each matrix type.
!>

KVAL

!>          KVAL is INTEGER array, dimension (NSIZES)
!>          Selects the priority values for the tests.
!>

MVAL

!>          MVAL is INTEGER array, dimension (NSIZES)
!>          The dimensions M of the matrices to be tested.
!>

NVAL

!>          NVAL is INTEGER array, dimension (NSIZES)
!>          The dimensions N of the matrices to be tested.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of columns in the  matrices X, Y,
!>          and Z, used in testing CBDSQR.  If NRHS = 0, then the
!>          operations on the right-hand side will not be tested.
!>          NRHS must be at least 0.
!>

ISEED

!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096.  Also, ISEED(4) must
!>          be odd.  The values of ISEED are changed on exit, and can be
!>          used in the next call to CCHKBD to continue the same random
!>          number sequence.
!>

THRESH

!>          THRESH is REAL
!>          The threshold value for the test ratios.  A result is
!>          included in the output file if RESULT >= THRESH.  To have
!>          every test ratio printed, use THRESH = 0.  Note that the
!>          expected value of the test ratios is O(1), so THRESH should
!>          be a reasonably small multiple of 1, e.g., 10 or 100.
!>

A

!>          A is COMPLEX array, dimension (LDA,NMAX)
!>          where NMAX is the maximum value of N in NVAL.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,MMAX),
!>          where MMAX is the maximum value of M in MVAL.
!>

BD

!>          BD is REAL array, dimension
!>                      (max(min(MVAL(j),NVAL(j))))
!>

BE

!>          BE is REAL array, dimension
!>                      (max(min(MVAL(j),NVAL(j))))
!>

S1

!>          S1 is REAL array, dimension
!>                      (max(min(MVAL(j),NVAL(j))))
!>

S2

!>          S2 is REAL array, dimension
!>                      (max(min(MVAL(j),NVAL(j))))
!>

X

!>          X is COMPLEX array, dimension (LDX,NRHS)
!>

LDX

!>          LDX is INTEGER
!>          The leading dimension of the arrays X, Y, and Z.
!>          LDX >= max(1,MMAX).
!>

Y

!>          Y is COMPLEX array, dimension (LDX,NRHS)
!>

Z

!>          Z is COMPLEX array, dimension (LDX,NRHS)
!>

Q

!>          Q is COMPLEX array, dimension (LDQ,MMAX)
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of the array Q.  LDQ >= max(1,MMAX).
!>

PT

!>          PT is COMPLEX array, dimension (LDPT,NMAX)
!>

LDPT

!>          LDPT is INTEGER
!>          The leading dimension of the arrays PT, U, and V.
!>          LDPT >= max(1, max(min(MVAL(j),NVAL(j)))).
!>

U

!>          U is COMPLEX array, dimension
!>                      (LDPT,max(min(MVAL(j),NVAL(j))))
!>

VT

!>          VT is COMPLEX array, dimension
!>                      (LDPT,max(min(MVAL(j),NVAL(j))))
!>

WORK

!>          WORK is COMPLEX array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          The number of entries in WORK.  This must be at least
!>          3(M+N) and  M(M + max(M,N,k) + 1) + N*min(M,N)  for all
!>          pairs  (M,N)=(MM(j),NN(j))
!>

RWORK

!>          RWORK is REAL array, dimension
!>                      (5*max(min(M,N)))
!>

NOUT

!>          NOUT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)
!>

INFO

!>          INFO is INTEGER
!>          If 0, then everything ran OK.
!>           -1: NSIZES < 0
!>           -2: Some MM(j) < 0
!>           -3: Some NN(j) < 0
!>           -4: NTYPES < 0
!>           -6: NRHS  < 0
!>           -8: THRESH < 0
!>          -11: LDA < 1 or LDA < MMAX, where MMAX is max( MM(j) ).
!>          -17: LDB < 1 or LDB < MMAX.
!>          -21: LDQ < 1 or LDQ < MMAX.
!>          -23: LDP < 1 or LDP < MNMAX.
!>          -27: LWORK too small.
!>          If  CLATMR, CLATMS, CGEBRD, CUNGBR, or CBDSQR,
!>              returns an error code, the
!>              absolute value of it is returned.

!>                     be performed so far, for the current matrix.
!>     MMAX            Largest value in NN.
!>     NMAX            Largest value in NN.
!>     MNMIN           min(MM(j), NN(j)) (the dimension of the bidiagonal
!>                     matrix.)
!>     MNMAX           The maximum value of MNMIN for j=1,...,NSIZES.
!>     NFAIL           The number of tests which have exceeded THRESH
!>     COND, IMODE     Values to be passed to the matrix generators.
!>     ANORM           Norm of A; passed to matrix generators.
!>
!>     OVFL, UNFL      Overflow and underflow thresholds.
!>     RTOVFL, RTUNFL  Square roots of the previous 2 values.

!>             The following four arrays decode JTYPE:
