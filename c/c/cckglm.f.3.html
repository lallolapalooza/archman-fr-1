subroutine cckglm (integer nn, integer, dimension( * ) nval, integer, dimension( * ) mval, integer, dimension( * ) pval, integer nmats, integer, dimension( 4 ) iseed, real thresh, integer nmax, complex, dimension( * ) a, complex, dimension( * ) af, complex, dimension( * ) b, complex, dimension( * ) bf, complex, dimension( * ) x, complex, dimension( * ) work, real, dimension( * ) rwork, integer nin, integer nout, integer info)

CCKGLM

Objectif :

!>
!> CCKGLM teste CGGGLM - sous-routine pour résoudre le problème du modèle linéaire généralisé.
!>

Paramètres

NN 
!>          NN est un ENTIER
!>          Le nombre de valeurs de N, M et P contenues dans les vecteurs
!>          NVAL, MVAL et PVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension N des lignes de la matrice.
!>

MVAL

!>          MVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension M des colonnes de la matrice.
!>

PVAL

!>          PVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension P des colonnes de la matrice.
!>

NMATS

!>          NMATS est un ENTIER
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrices.  Si NMATS >= NTYPES (le nombre maximum
!>          de types de matrices), alors tous les types différents sont
!>          générés pour le test.  Si NMATS < NTYPES, une autre ligne d'entrée
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau d'ENTIERS, dimension (4)
!>          En entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          En sortie, la graine suivante dans la séquence de nombres aléatoires après
!>          la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est un RÉEL
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESID >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau de COMPLEXES, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau de COMPLEXES, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau de COMPLEXES, dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau de COMPLEXES, dimension (NMAX*NMAX)
!>

X

!>          X est un tableau de COMPLEXES, dimension (4*NMAX)
!>

RWORK

!>          RWORK est un tableau de RÉELS, dimension (NMAX)
!>

WORK

!>          WORK est un tableau de COMPLEXES, dimension (NMAX*NMAX)
!>

NIN

!>          NIN est un ENTIER
!>          Le numéro de l'unité pour l'entrée.
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro de l'unité pour la sortie.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : Sortie réussie
!>          > 0 : Si CLATMS renvoie un code d'erreur, sa valeur absolue est
!>                 renvoyée.
!>
