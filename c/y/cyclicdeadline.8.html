NOM

cyclicdeadline - Ce programme est utilisé pour tester le planificateur deadline (SCHED_DEADLINE) à l'aide d'un programme de style cyclictest

SYNOPSIS

cyclicdeadline [-a [CPUSET]] [-D TIME] [-h] [-i INTV] [--json FICHIER] [-s STEP] [-t NUM] [-q]

DESCRIPTION

cyclicdeadline est un programme de style cyclictest pour tester le planificateur deadline

OPTIONS

-a --affinity [CPUSET]
Liste de CPU séparés par des virgules/tirets sur lesquels exécuter les tâches deadline
-D --duration TIME
Spécifie la durée de l'exécution du test. Ajoutez 'm', 'h', ou 'd' pour spécifier les minutes, heures ou jours.
-h --help
Affiche ce menu d'aide
-i --interval INTV
Le délai d'expiration le plus court pour les tâches en microsecondes. (défaut 1000us)
--json=FICHIER
Écrit les résultats finaux dans FICHIER, au format JSON.
-s --step STEP
La quantité à augmenter le délai d'expiration pour chaque tâche en microsecondes. (défaut 500us)
-t --threads NUM
Le nombre de threads à exécuter en tant que deadline (défaut 1)
-q, --quiet
N'affiche qu'un résumé à la sortie. Utile pour les tests automatisés, où seule la sortie du résumé doit être capturée.
-b, --breaktrace=USEC
Envoie une commande break trace lorsque la latence > USEC
--tracemark
Écrit une marque de trace lorsque la latence -b est dépassée.
