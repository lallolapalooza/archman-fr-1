NOM

Class::Data::Inheritable - Données de classe héritables et redéfinissables

SYNOPIS

package Stuff;
use base qw(Class::Data::Inheritable);
# Configure DataFile comme données de classe héritables.
Stuff->mk_classdata('DataFile');
# Déclarer l'emplacement du fichier de données pour cette classe.
Stuff->DataFile('/etc/stuff/data');
# Ou, tout en une seule fois :
Stuff->mk_classdata(DataFile => '/etc/stuff/data');

DESCRIPTION

Class::Data::Inheritable est utilisé pour créer des accesseurs/mutateurs pour les données de classe. C'est-à-dire, si vous voulez stocker quelque chose sur votre classe dans son ensemble (au lieu d'un objet individuel). Ces données sont ensuite héritées par vos sous-classes et peuvent être redéfinies.

Par exemple :

Pere::Ubu->mk_classdata('Suitcase');

générera la méthode Suitcase() dans la classe Pere::Ubu.

Cette nouvelle méthode peut être utilisée pour obtenir et définir une donnée de classe.

Pere::Ubu->Suitcase('Red');
$suitcase = Pere::Ubu->Suitcase;

La partie intéressante se produit lorsqu'une classe hérite de Pere::Ubu :

package Raygun;
use base qw(Pere::Ubu);

# La valise de Raygun est Rouge.
$suitcase = Raygun->Suitcase;

Raygun hérite de ses données de classe Suitcase de Pere::Ubu.

L'héritage des données de classe fonctionne de manière analogue à l'héritage de méthodes. Tant que Raygun ne "redéfinit" pas ses données de classe héritées (en utilisant Suitcase() pour définir une nouvelle valeur), il continuera à utiliser ce qui est défini dans Pere::Ubu et héritera des changements ultérieurs :

# Les valises de Raygun et de Pere::Ubu sont maintenant Bleues
Pere::Ubu->Suitcase('Blue');

Cependant, si Raygun décide de définir son propre Suitcase(), il a maintenant "redéfini" Pere::Ubu et est seul, tout comme s'il avait redéfini une méthode :

# Raygun a une valise orange, celle de Pere::Ubu est toujours Bleue.
Raygun->Suitcase('Orange');

Maintenant que Raygun a redéfini Pere::Ubu, les changements ultérieurs par Pere::Ubu n'affectent plus Raygun.

# Raygun a toujours une valise orange, mais Pere::Ubu utilise Samsonite.
Pere::Ubu->Suitcase('Samsonite');

Méthodes

mk_classdata

Class->mk_classdata($nom_accesseur_donnees);
Class->mk_classdata($nom_accesseur_donnees => $valeur);

C'est une méthode de classe utilisée pour déclarer de nouveaux accesseurs de données de classe. Un nouvel accesseur sera créé dans la classe en utilisant le nom de $nom_accesseur_donnees, et en l'initialisant éventuellement à la valeur donnée.

Pour faciliter la redéfinition, mk_classdata crée un alias vers l'accesseur, _field_accessor(). Ainsi, Suitcase() aurait un alias _Suitcase_accessor() qui fait exactement la même chose que Suitcase(). Ceci est utile si vous souhaitez modifier le comportement d'un seul accesseur tout en bénéficiant de l'héritage des données de classe. Par exemple.

sub Suitcase {
    my($self) = shift;
    warn "Fashion tragedy" if @_ and $_[0] eq 'Plaid';
    $self->_Suitcase_accessor(@_);
}
