sous-programme clags2 (logical upper, real a1, complex a2, real a3, real b1, complex b2, real b3, real csu, complex snu, real csv, complex snv, real csq, complex snq)

CLAGS2

But :

!>
!> CLAGS2 calcule les matrices unitaires 2x2 U, V et Q telles que si ( UPPER ) alors
!>
!>           U**H *A*Q = U**H *( A1 A2 )*Q = ( x  0  )
!>                             ( 0  A3 )     ( x  x  )
!> et
!>           V**H*B*Q = V**H *( B1 B2 )*Q = ( x  0  )
!>                            ( 0  B3 )     ( x  x  )
!>
!> ou si ( .NOT.UPPER ) alors
!>
!>           U**H *A*Q = U**H *( A1 0  )*Q = ( x  x  )
!>                             ( A2 A3 )     ( 0  x  )
!> et
!>           V**H *B*Q = V**H *( B1 0  )*Q = ( x  x  )
!>                             ( B2 B3 )     ( 0  x  )
!> où
!>
!>   U = (   CSU    SNU ), V = (  CSV    SNV ),
!>       ( -SNU**H  CSU )      ( -SNV**H CSV )
!>
!>   Q = (   CSQ    SNQ )
!>       ( -SNQ**H  CSQ )
!>
!> Les lignes des matrices A et B transformées sont parallèles. De plus, si la
!> matrice 2x2 d'entrée A n'est pas nulle, alors l'élément (1,1) transformé
!> de A n'est pas nul. Si les matrices d'entrée A et B ne sont pas toutes deux
!> nulles, alors l'élément (2,2) transformé de B n'est pas nul, sauf lorsque
!> les premières lignes des matrices d'entrée A et B sont parallèles et les
!> secondes lignes sont nulles.
!>

Paramètres

UPPER 
!>          UPPER est LOGICAL
!>          = .TRUE.: les matrices d'entrée A et B sont triangulaires supérieures.
!>          = .FALSE.: les matrices d'entrée A et B sont triangulaires inférieures.
!>

A1

!>          A1 est REAL
!>

A2

!>          A2 est COMPLEX
!>

A3

!>          A3 est REAL
!>          À l'entrée, A1, A2 et A3 sont les éléments de la matrice triangulaire
!>          supérieure (inférieure) 2x2 d'entrée A.
!>

B1

!>          B1 est REAL
!>

B2

!>          B2 est COMPLEX
!>

B3

!>          B3 est REAL
!>          À l'entrée, B1, B2 et B3 sont les éléments de la matrice triangulaire
!>          supérieure (inférieure) 2x2 d'entrée B.
!>

CSU

!>          CSU est REAL
!>

SNU

!>          SNU est COMPLEX
!>          La matrice unitaire souhaitée U.
!>

CSV

!>          CSV est REAL
!>

SNV

!>          SNV est COMPLEX
!>          La matrice unitaire souhaitée V.
!>

CSQ

!>          CSQ est REAL
!>

SNQ

!>          SNQ est COMPLEX
!>          La matrice unitaire souhaitée Q.
!>
