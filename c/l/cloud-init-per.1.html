CLOUD-INIT-PER(1) Manuel des commandes générales CLOUD-INIT-PER(1)

NOM

cloud-init-per - Exécute une commande avec des arguments à une fréquence spécifique

SYNTAXE

cloud-init-per <fréquence> <nom> <cmd> [ arg1 [ arg2 [...]]]

DESCRIPTION

Exécute une commande avec des arguments à une fréquence spécifique.

Cet utilitaire peut faciliter l'utilisation de boothooks ou de bootcmd sur une base "une seule fois" ou "toujours". Par exemple :


- [ cloud-init-per, once, mymkfs, mkfs, /dev/vdb ]

La commande cloud-init-per a remplacé la commande cloud-init-run-module.

OPTIONS

fréquence
Cela peut être l'une des valeurs suivantes :

once : exécuter une seule fois et ne pas réexécuter pour un nouvel identifiant d'instance

instance : exécuter une seule fois pour un identifiant d'instance donné et réexécuter pour un nouvel identifiant d'instance

always : exécuter à chaque démarrage

nom
Un nom donné à la commande à exécuter pour qu'elle apparaisse dans les journaux.
cmd [ arg1 [ arg2 [...]]]
La commande réelle à exécuter suivie de tous les arguments supplémentaires.
