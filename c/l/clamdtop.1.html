NOTE

S

clamdtop utilise des couleurs si le terminal est capable de les afficher. Si vous savez que votre terminal est capable de couleurs, mais que vous n'en voyez aucune, alors vérifiez que votre variable d'environnement TERM est définie correctement. Par exemple, essayez de la définir à TERM=xterm-color si vous êtes dans un environnement de type xterm. La prise en charge de l'IPv6 a été ajoutée. Si vous spécifiez une adresse IPv6, veuillez utiliser les règles d'adressage IPv6 normales. Si vous spécifiez à la fois une adresse IPv6 et une combinaison adresse/port, encapsulez l'adresse IPv6 entre crochets crochets (

par ex. [:
:1]:3410).
