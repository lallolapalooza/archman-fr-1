Documentation de la fonction/sous-programme

sous-routine clattp (entier imat, caractère uplo, caractère trans, caractère diag, entier, dimension( 4 ) iseed, entier n, complexe, dimension( * ) ap, complexe, dimension( * ) b, complexe, dimension( * ) work, réel, dimension( * ) rwork, entier info)

CLATTP

Objectif :

!>
!> CLATTP génère une matrice triangulaire de test en stockage compacté.
!> IMAT et UPLO spécifient de manière unique les propriétés de la matrice de test,
!> qui est retournée dans le tableau AP.
!>

Paramètres

IMAT 
!>          IMAT est un ENTIER
!>          Une clé entière décrivant quelle matrice générer pour ce
!>          chemin.
!>

UPLO

!>          UPLO est CARACTÈRE*1
!>          Spécifie si la matrice A sera triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CARACTÈRE*1
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Transposée conjuguée
!>

DIAG

!>          DIAG est CARACTÈRE*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

ISEED

!>          ISEED est un tableau d'ENTIERS, dimension (4)
!>          Le vecteur initial pour le générateur de nombres aléatoires (utilisé dans
!>          CLATMS). Modifié en sortie.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice à générer.
!>

AP

!>          AP est un tableau de COMPLEXES, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compactée par colonne dans
!>          un tableau linéaire. La j-ème colonne de A est stockée dans le tableau
!>          AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

B

!>          B est un tableau de COMPLEXES, dimension (N)
!>          Le vecteur second membre, si IMAT > 10.
!>

WORK

!>          WORK est un tableau de COMPLEXES, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau de RÉELS, dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  Sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
