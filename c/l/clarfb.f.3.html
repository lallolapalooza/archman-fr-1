sous-routine clarfb (side, trans, direct, storev, m, n, k, v, ldv, t, ldt, c, ldc, work, ldwork)
CLARFB applique un réflecteur de bloc ou sa transposée conjuguée à une matrice rectangulaire générale.

Documentation de la fonction/sous-routine

sous-routine clarfb (character side, character trans, character direct, character storev, integer m, integer n, integer k, complex, dimension( ldv, * ) v, integer ldv, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( ldwork, * ) work, integer ldwork)

CLARFB applique un réflecteur de bloc complexe H ou sa transposée conjuguée H**H à une matrice rectangulaire complexe de taille M par N, C, soit à gauche, soit à droite.

Objectif :

!>
!> CLARFB applique un réflecteur de bloc complexe H ou sa transposée H**H à une
!> matrice complexe C de taille M par N, soit à gauche, soit à droite.
!>

Paramètres

SIDE 
!>          SIDE est de type CHARACTER*1
!>          = 'L': applique H ou H**H à gauche
!>          = 'R': applique H ou H**H à droite
!>

TRANS

!>          TRANS est de type CHARACTER*1
!>          = 'N': applique H (pas de transposée)
!>          = 'C': applique H**H (transposée conjuguée)
!>

DIRECT

!>          DIRECT est de type CHARACTER*1
!>          Indique comment H est formé à partir d'un produit de
!>          réflecteurs élémentaires
!>          = 'F': H = H(1) H(2) . . . H(k) (En avant)
!>          = 'B': H = H(k) . . . H(2) H(1) (En arrière)
!>

STOREV

!>          STOREV est de type CHARACTER*1
!>          Indique comment les vecteurs qui définissent les réflecteurs
!>          élémentaires sont stockés :
!>          = 'C': par colonnes
!>          = 'R': par lignes
!>

M

!>          M est un INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est un INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

K

!>          K est un INTEGER
!>          L'ordre de la matrice T (= le nombre de réflecteurs élémentaires
!>          dont le produit définit le réflecteur de bloc).
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

V

!>          V est un tableau de type COMPLEX, de dimension
!>                                (LDV,K) si STOREV = 'C'
!>                                (LDV,M) si STOREV = 'R' et SIDE = 'L'
!>                                (LDV,N) si STOREV = 'R' et SIDE = 'R'
!>          La matrice V. Voir Détails supplémentaires.
!>

LDV

!>          LDV est un INTEGER
!>          La dimension principale du tableau V.
!>          Si STOREV = 'C' et SIDE = 'L', LDV >= max(1,M);
!>          Si STOREV = 'C' et SIDE = 'R', LDV >= max(1,N);
!>          Si STOREV = 'R', LDV >= K.
!>

T

!>          T est un tableau de type COMPLEX, de dimension (LDT,K)
!>          La matrice triangulaire KxK, T, dans la représentation du
!>          réflecteur de bloc.
!>

LDT

!>          LDT est un INTEGER
!>          La dimension principale du tableau T. LDT >= K.
!>

C

!>          C est un tableau de type COMPLEX, de dimension (LDC,N)
!>          À l'entrée, la matrice C de taille M par N.
!>          À la sortie, C est écrasée par H*C ou H**H*C ou C*H ou C*H**H.
!>

LDC

!>          LDC est un INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de type COMPLEX, de dimension (LDWORK,K)
!>

LDWORK

!>          LDWORK est un INTEGER
!>          La dimension principale du tableau WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N);
!>          Si SIDE = 'R', LDWORK >= max(1,M).
!>

Détails supplémentaires :

!>
!>  La forme de la matrice V et le stockage des vecteurs qui définissent
!>  les H(i) sont mieux illustrés par l'exemple suivant avec n = 5 et
!>  k = 3. La partie triangulaire de V (y compris sa diagonale) n'est pas
!>  référencée.
!>
!>  DIRECT = 'F' et STOREV = 'C':         DIRECT = 'F' et STOREV = 'R':
!>
!>               V = (  1       )                 V = (  1 v1 v1 v1 v1 )
!>                   ( v1  1    )                     (     1 v2 v2 v2 )
!>                   ( v1 v2  1 )                     (        1 v3 v3 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!>  DIRECT = 'B' et STOREV = 'C':         DIRECT = 'B' et STOREV = 'R':
!>
!>               V = ( v1 v2 v3 )                 V = ( v1 v1  1       )
!>                   ( v1 v2 v3 )                     ( v2 v2 v2  1    )
!>                   (  1 v2 v3 )                     ( v3 v3 v3 v3  1 )
!>                   (     1 v3 )
!>                   (        1 )
!>
