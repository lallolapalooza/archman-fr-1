NOM

cleankrf - Nettoyer les fichiers keyrec de DNSSEC-Tools des anciennes données

SYNTAXE

cleankrf [options] <fichiers-keyrec>

DESCRIPTION

cleankrf nettoie les anciennes données des fichiers keyrec de DNSSEC-Tools. Les anciennes données sont les jeux de signature obsolètes, les clés orphelines et les clés obsolètes.

Les jeux de signature obsolètes sont des keyrec de jeu non référencés par un keyrec de zone. Les jeux de signature révoqués sont considérés comme obsolètes par cleankrf.

Les clés orphelines sont des keyrec de clé KSK et ZSK non référencés par un keyrec de jeu.

Les clés obsolètes sont des keyrec de clé avec un keyrec_type de kskobs ou zskobs.

Le code de sortie de cleankrf est le compte des keyrec orphelins et obsolètes trouvés.

OPTIONS

-count
Affiche un décompte final des anciens keyrec trouvés dans les fichiers keyrec. Cette option permet d'afficher le décompte même si l'option -quiet est donnée.
-list
Les keyrec de clé sont vérifiés pour les anciens keyrec, mais ils ne sont pas supprimés du fichier keyrec. Les noms des anciens keyrec sont affichés.
-rm
Supprime les fichiers de clé, à la fois .key et .private, des keyrec orphelins et expirés.
-quiet
N'affiche aucune sortie.
-verbose
Affiche des informations sur les clés référencées et les clés non référencées.
-Version
Affiche les informations de version pour cleankrf et le paquet DNSSEC-Tools.
-help
Affiche un message d'utilisation.
