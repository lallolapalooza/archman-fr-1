sous-routine clavsy (caractère uplo, caractère trans, caractère diag, entier n, entier nrhs, complexe, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, complexe, dimension( ldb, * ) b, entier ldb, entier info)

CLAVSY

But :

!>
!> CLAVSY effectue une des opérations de matrice-vecteur
!>    x := A*x  ou  x := A'*x,
!> où x est un vecteur de N éléments et A est l'un des facteurs
!> de la factorisation de bloc U*D*U' ou L*D*L' calculée par CSYTRF.
!>
!> Si TRANS = 'N', multiplication par U ou U * D (ou L ou L * D)
!> Si TRANS = 'T', multiplication par U' ou D * U' (ou L' ou D * L')
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si le facteur stocké dans A est triangulaire supérieur ou inférieur.
!>          = 'U':  Triangulaire supérieur
!>          = 'L':  Triangulaire inférieur
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération à effectuer :
!>          = 'N':  x := A*x
!>          = 'T':  x := A'*x
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si les blocs diagonaux sont des matrices unitaires ou non.
!>          Si les blocs diagonaux sont supposés unitaires, alors A = U ou A = L, sinon A = U*D ou A = L*D.
!>          = 'U':  Les blocs diagonaux sont supposés être des matrices unitaires.
!>          = 'N':  Les blocs diagonaux sont supposés être des matrices non unitaires.
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de vecteurs
!>          x à multiplier par A. NRHS >= 0.
!>

A

!>          A est tableau de type COMPLEX, dimension (LDA,N)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L tels que calculés par CSYTRF.
!>          Stocké sous forme de matrice triangulaire 2D.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

IPIV

!>          IPIV est tableau de type INTEGER, dimension (N)
!>          Détails des échanges et de la structure de bloc de D,
!>          tels que déterminés par CSYTRF.
!>
!>          Si UPLO = 'U':
!>               Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k)
!>               ont été échangées et D(k,k) est un bloc diagonal 1x1.
!>               (Si IPIV( k ) = k, aucun échange n'a été effectué).
!>
!>               Si IPIV(k) = IPIV(k-1) < 0, alors les lignes et
!>               colonnes k-1 et -IPIV(k) ont été échangées,
!>               D(k-1:k,k-1:k) est un bloc diagonal 2x2.
!>
!>          Si UPLO = 'L':
!>               Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k)
!>               ont été échangées et D(k,k) est un bloc diagonal 1x1.
!>               (Si IPIV( k ) = k, aucun échange n'a été effectué).
!>
!>               Si IPIV(k) = IPIV(k+1) < 0, alors les lignes et
!>               colonnes k+1 et -IPIV(k) ont été échangées,
!>               D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>

B

!>          B est tableau de type COMPLEX, dimension (LDB,NRHS)
!>          À l'entrée, B contient NRHS vecteurs de longueur N.
!>          À la sortie, B est écrasé par le produit A * B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0: succès de l'exécution
!>          < 0: si INFO = -k, le k-ième argument avait une valeur illégale
!>
