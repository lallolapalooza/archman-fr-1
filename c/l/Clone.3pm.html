NOM

Clone - copie récursivement les types de données Perl

SYNOPSIS

use Clone 'clone';
my $data = {
   set => [ 1 .. 50 ],
   foo => {
       answer => 42,
       object => SomeObject->new,
   },
};
my $cloned_data = clone($data);
$cloned_data->{foo}{answer} = 1;
print $cloned_data->{foo}{answer};  # '1'
print $data->{foo}{answer};         # '42'

Vous pouvez également l'ajouter à votre classe :

package Foo;
use parent 'Clone';
sub new { bless {}, shift }
package main;
my $obj = Foo->new;
my $copy = $obj->clone;

DESCRIPTION

Ce module fournit une méthode clone() qui crée des copies récursives de hachages, tableaux, scalaires et références imbriqués, y compris les variables liées et les objets.

clone() prend un argument scalaire et le duplique. Pour dupliquer des listes, des tableaux ou des hachages, passez-les par référence, par exemple :

my $copy = clone (\@array);
# ou
my %copy = %{ clone (\%hash) };

VOIR AUSSI

La méthode dclone() de Storable est une solution flexible pour cloner des variables, bien que plus lente pour des structures de données de taille moyenne. Des benchmarks simples et naïfs montrent que Clone est plus rapide pour les structures de données avec 3 niveaux ou moins, tandis que dclone() peut être plus rapide pour les structures de 4 niveaux ou plus.
