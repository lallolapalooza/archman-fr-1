sous-routine clarfx (side, m, n, v, tau, c, ldc, work)
CLARFX applique un réflecteur élémentaire à une matrice rectangulaire générale, avec déroulement de boucle lorsque le réflecteur est d'ordre ≤ 10.

Documentation de la fonction/sous-routine

sous-routine clarfx (caractère side, entier m, entier n, complexe, dimension( * ) v, complexe tau, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( * ) work)

CLARFX applique un réflecteur élémentaire complexe H à une matrice complexe m par n C, par la gauche ou par la droite. H est représenté sous la forme


       H = I - tau * v * v**H

où tau est un scalaire complexe et v est un vecteur complexe.

Si tau = 0, alors H est considérée comme la matrice unité.

Cette version utilise du code inline si H est d'ordre < 11.

Objectif:

!>
!> CLARFX applique un réflecteur élémentaire complexe H à une matrice complexe
!> m par n C, par la gauche ou par la droite. H est représentée sous la forme
!>
!>       H = I - tau * v * v**H
!>
!> où tau est un scalaire complexe et v est un vecteur complexe.
!>
!> Si tau = 0, alors H est prise comme la matrice unité
!>
!> Cette version utilise du code inline si H a un ordre < 11.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': forme  H * C
!>          = 'R': forme  C * H
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

V

!>          V est un tableau de type COMPLEX, dimension (M) si SIDE = 'L'
!>                                             ou (N) si SIDE = 'R'
!>          Le vecteur v dans la représentation de H.
!>

TAU

!>          TAU est COMPLEX
!>          La valeur tau dans la représentation de H.
!>

C

!>          C est un tableau de type COMPLEX, dimension (LDC,N)
!>          À l'entrée, la matrice m par n C.
!>          À la sortie, C est écrasée par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de type COMPLEX, dimension (N) si SIDE = 'L'
!>                                                ou (M) si SIDE = 'R'
!>          WORK n'est pas référencé si H est d'ordre < 11.
!>
