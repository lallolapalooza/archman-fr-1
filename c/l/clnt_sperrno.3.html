Le transport utilisé pour passer les messages au service est en réalité un tampon dans l'espace d'adressage du processus, donc le serveur RPC correspondant doit se trouver dans le même espace d'adressage ; voir svcraw_create().                 int *sockp, unsigned int sendsz, unsigned int recvsz)
;
Cette routine crée un client RPC pour le programme distant prognum, version versnum ; le client utilise TCP/IP comme transport. Le programme distant est situé à l'adresse Internet *addr. Le paramètre sockp est un socket ; s'il est RPC_ANYSOCK, alors cette routine en ouvre un nouveau et définit sockp. Puisque le RPC basé sur TCP utilise une E/S avec tampon, l'utilisateur peut spécifier la taille des tampons d'envoi et de réception avec les paramètres sendsz et recvsz ; des valeurs de zéro choisissent des valeurs par
