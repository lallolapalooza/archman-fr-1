subroutine cla_syamv (uplo, n, alpha, a, lda, x, incx, beta, y, incy)
CLA_SYAMV calcule le produit matrice-vecteur en utilisant une matrice indéfinie symétrique pour calculer les bornes d'erreur.

Documentation de la fonction/sous-programme

sous-programme cla_syamv (integer uplo, integer n, real alpha, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) x, integer incx, real beta, real, dimension( * ) y, integer incy)

CLA_SYAMV calcule le produit matrice-vecteur en utilisant une matrice indéfinie symétrique pour calculer les bornes d'erreur.

Objectif:

!>
!> CLA_SYAMV  effectue l'opération matrice-vecteur
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>
!> où alpha et beta sont des scalaires, x et y sont des vecteurs et A est une
!> matrice symétrique de taille n par n.
!>
!> Cette fonction est principalement utilisée pour calculer les bornes d'erreur.
!> Pour se protéger contre le sous-dépassement lors de l'évaluation, les
!> composantes du vecteur résultant sont perturbées loin de zéro par (N+1)
!> fois le seuil de sous-dépassement. Pour éviter des erreurs inutilement
!> importantes pour les structures de blocs intégrées dans des matrices générales,
!> les composantes nulles ne sont pas perturbées. Une entrée nulle est
!> considérée si toutes les multiplications impliquées dans le calcul de cette
!> entrée ont au moins un multiplicande nul.
!>

Paramètres

UPLO 
!>          UPLO est de type INTEGER
!>           En entrée, UPLO spécifie si la partie triangulaire supérieure ou
!>           inférieure du tableau A doit être référencée comme suit :
!>
!>              UPLO = BLAS_UPPER   Seule la partie triangulaire supérieure de A
!>                                  est à référencer.
!>
!>              UPLO = BLAS_LOWER   Seule la partie triangulaire inférieure de A
!>                                  est à référencer.
!>
!>           Inchangé en sortie.
!>

N

!>          N est de type INTEGER
!>           En entrée, N spécifie le nombre de colonnes de la matrice A.
!>           N doit être supérieur ou égal à zéro.
!>           Inchangé en sortie.
!>

ALPHA

!>          ALPHA est de type REAL .
!>           En entrée, ALPHA spécifie le scalaire alpha.
!>           Inchangé en sortie.
!>

A

!>          A est un tableau de type COMPLEX, de dimension ( LDA, n ).
!>           Avant l'entrée, la partie principale de taille m par n du tableau A
!>           doit contenir la matrice des coefficients.
!>           Inchangé en sortie.
!>

LDA

!>          LDA est de type INTEGER
!>           En entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant (sous-programme). LDA doit être au moins
!>           max( 1, n ).
!>           Inchangé en sortie.
!>

X

!>          X est un tableau de type COMPLEX, de dimension
!>           ( 1 + ( n - 1 )*abs( INCX ) )
!>           Avant l'entrée, le tableau incrémenté X doit contenir le vecteur x.
!>           Inchangé en sortie.
!>

INCX

!>          INCX est de type INTEGER
!>           En entrée, INCX spécifie l'incrément pour les éléments de X.
!>           INCX ne doit pas être zéro.
!>           Inchangé en sortie.
!>

BETA

!>          BETA est de type REAL .
!>           En entrée, BETA spécifie le scalaire beta. Lorsque BETA est
!>           fourni comme zéro, Y n'a pas besoin d'être défini en entrée.
!>           Inchangé en sortie.
!>

Y

!>          Y est un tableau de type REAL, de dimension
!>           ( 1 + ( n - 1 )*abs( INCY ) )
!>           Avant l'entrée avec BETA non nul, le tableau incrémenté Y doit
!>           contenir le vecteur y. En sortie, Y est écrasé par le vecteur y
!>           mis à jour.
!>

INCY

!>          INCY est de type INTEGER
!>           En entrée, INCY spécifie l'incrément pour les éléments de Y.
!>           INCY ne doit pas être zéro.
!>           Inchangé en sortie.
!>
