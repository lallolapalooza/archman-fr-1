NOM

Class::Accessor::Faster - Accesseurs encore plus rapides, mais moins extensibles

SYNOPSIS

package Foo;
use base qw(Class::Accessor::Faster);

DESCRIPTION

C'est une version plus rapide mais moins extensible de Class::Accessor::Fast.

Les accesseurs générés par Class::Accessor nécessitent deux appels de méthode pour accomplir leur tâche (un pour l'accesseur, un autre pour get() ou set()).

Class::Accessor::Fast élimine l'appel à set()/get() et gère l'accès lui-même, ce qui résulte en un accesseur légèrement plus rapide.

Class::Accessor::Faster utilise une référence de tableau en interne pour être plus rapide.

Lisez la documentation de Class::Accessor pour plus d'informations.
