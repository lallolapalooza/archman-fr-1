CLUSTER(1) Manuel des commandes générales CLUSTER(1)

NOM

cluster - trouver des clusters dans un graphe et augmenter le graphe avec cette information.

SYNTAXE

cluster [-v?] [ -Ck ] [ -ck ] [ -o outfile ] [ fichiers ]

DESCRIPTION

cluster prend en entrée un graphe au format DOT, trouve des clusters de nœuds et augmente le graphe avec cette information. Les clusters sont spécifiés par l'attribut « cluster » attaché aux nœuds ; les valeurs des clusters sont des entiers non négatifs. cluster tente de maximiser la modularité du clustering. Si l'attribut d'arête « weight » est défini, il sera utilisé dans le calcul du clustering.

OPTIONS

Les options suivantes sont prises en charge :

-Ck
spécifie un nombre cible de clusters à générer. Le nombre spécifié k n'est qu'une suggestion et peut ne pas être réalisable. Si k == 0, par défaut, le nombre de clusters qui optimise approximativement la modularité est renvoyé.
-ck
spécifie la méthode de clustering. Si k == 0, par défaut, le clustering par modularité sera utilisé. Si k == 1, la qualité de modularité sera utilisée.
-ooutfile
Spécifie que la sortie doit aller dans le fichier outfile. Par défaut, la sortie standard (stdout) est utilisée.
-v
Mode verbeux.
-?
Affiche l'aide et quitte.

EXEMPLES

Appliquer cluster au graphe suivant,

   graph {
       1--2 [weight=10.]
       2--3 [weight=1]
       3--4 [weight=10.]
       4--5 [weight=10]
       5--6 [weight=10]
       3--6 [weight=0.1]
       4--6 [weight=10.]
      }

donne

   graph {
         node [cluster="-1"];
         1 [cluster=1];
         2 [cluster=1];
         3 [cluster=2];
         4 [cluster=2];
         5 [cluster=2];
         6 [cluster=2];
         1 -- 2 [weight="10."];
         2 -- 3 [weight=1];
         3 -- 4 [weight="10."];
         4 -- 5 [weight=10];
         5 -- 6 [weight=10];
         3 -- 6 [weight="0.1"];
         4 -- 6 [weight="10."];
   }
