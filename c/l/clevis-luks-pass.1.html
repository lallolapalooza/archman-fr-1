NOM

clevis-luks-pass - Extrait la phrase de passe utilisée pour lier un emplacement particulier dans un périphérique LUKS

SYNTAXE

clevis luks pass -d DEV -s SLT

APERÇU

La commande clevis luks pass extrait la phrase de passe utilisée pour lier un emplacement particulier dans un périphérique LUKS. Par exemple :

clevis luks pass -d /dev/sda1 -s 1

OPTIONS

•-d DEV : Le périphérique LUKS sur lequel extraire une phrase de passe
•-s SLT : L'emplacement à utiliser pour l'extraction de la phrase de passe

EXEMPLE

clevis luks pass -d /dev/sda1 -s 1
<phrase de passe ici>

Notez que la sortie de clevis luks pass peut contenir des caractères non imprimables. Dans ce cas, il serait préférable de rediriger sa sortie vers un fichier et de l'utiliser comme fichier clé avec cryptsetup. Par exemple :

clevis luks pass -d /dev/sda1 -s 1 > phrase_de_passe_slot1

Et le fichier phrase_de_passe_slot1 contiendra la phrase de passe associée à l'emplacement n°1 dans /dev/sda1.
