NOM

clevercsv-detect - Détecte le dialecte d'un fichier CSV

SYNTAXE

clevercsv detect [-c | --consistency] [-e ENCODING | --encoding=ENCODING]
                 [-n NUM_CHARS | --num-chars=NUM_CHARS] [ -p | --plain |
                 -j | --json ] [--no-skip] [--add-runtime] <chemin>

DESCRIPTION

Détecte le dialecte d'un fichier CSV.

OPTIONS

-h, --help

Affiche ce message d'aide et quitte

-c, --consistency

Par défaut, le dialecte des fichiers CSV est détecté à l'aide d'un processus en deux étapes. Premièrement, un ensemble strict de vérifications est utilisé pour voir si le fichier adhère à un format très basique (par exemple, lorsque toutes les cellules du fichier sont des entiers). Si aucune de ces vérifications ne réussit, la mesure de cohérence des données de Van den Burg, et al. (2019) est utilisée pour détecter le dialecte. Avec cette option, vous pouvez forcer la détection à toujours utiliser la mesure de cohérence des données. Cela peut être utile à des fins de test ou de recherche, par exemple.

-e, --encoding

Le codage du fichier CSV donné est automatiquement détecté à l'aide de chardet. Bien que chardet soit incroyablement précis, il n'est pas parfait. Dans les rares cas où il fait une erreur dans la détection du codage du fichier, vous pouvez remplacer le codage en le fournissant via ce drapeau. De plus, lorsque vous avez un certain nombre de fichiers CSV avec un codage de fichier connu, vous pouvez utiliser cette option pour accélérer le processus de génération de code.

-n, --num-chars

Sur les gros fichiers CSV, la détection de dialecte peut parfois être un peu lente en raison du grand nombre de dialectes possibles à prendre en compte. Pour atténuer cela, vous pouvez limiter le nombre de caractères à utiliser pour la détection.

Un aspect à garder à l'esprit est que CleverCSV peut avoir besoin de lire un nombre spécifique de caractères pour pouvoir inférer correctement le dialecte. Par exemple, dans le fichier ``imdb.csv`` du dépôt GitHub, le dialecte correct ne peut être trouvé qu'après la lecture d'au moins 66 lignes du fichier. Par conséquent, s'il est possible d'exécuter CleverCSV sur l'ensemble du fichier, cela est généralement recommandé.

-p, --plain

Imprime les composants du dialecte sur des lignes séparées

-j, --json

Imprime le dialecte sur la sortie standard sous la forme d'un objet JSON. Cet objet aura toujours les clés 'delimiter', 'quotechar', 'escapechar' et 'strict'. Si --add-runtime est spécifié, il aura également une clé 'runtime'.

--no-skip

Le score de cohérence des données utilisé pour la détection des dialectes se compose de deux composantes : un score de motif et un score de type. Le score de type est compris entre 0 et 1. Lors du calcul des mesures de cohérence des données pour différents dialectes, nous sautons le calcul du score de type si nous constatons que le score de motif est inférieur au meilleur score de cohérence des données que nous avons vu jusqu'à présent. Cette option peut être utilisée pour désactiver ce comportement et calculer le score de type pour tous les dialectes. Ceci est principalement utile à des fins de débogage et de test.

--add-runtime

Ajoute le temps d'exécution de la détection à la sortie de détection.

<chemin>

Chemin d'accès au fichier CSV
