NOM

clamtk - Interface utilisateur graphique (GUI) pour Clam AntiVirus

SYNTAXE

clamtk
clamtk fichier
clamtk répertoire

DESCRIPTION

clamtk est une interface pour Clam AntiVirus. Il est conçu pour être un scanner antivirus graphique léger et facile à utiliser, à la demande.

clamtk est écrit en utilisant Perl, Python et les bibliothèques Gtk+.

OPTIONS

Il n'y a actuellement pas d'options en ligne de commande, sauf celles notées dans la syntaxe. Il est inutile d'avoir des options en ligne de commande puisqu'on peut utiliser clamscan pour cela. clamtk accepte un fichier ou un répertoire comme argument, de sorte qu'on peut faire un clic droit dessus pour que l'objet soit analysé.

Des plugins existent pour ajouter des fonctionnalités de menu contextuel aux gestionnaires de fichiers tels que Files, Dolphin, Thunar, et autres.

DIAGNOSTICS

Vous devrez peut-être modifier freshclam.conf et clamd.conf avant de tenter des mises à jour de signatures. Consultez la documentation de votre distribution pour plus d'informations.

VOIR AUSSI

clamscan(1), freshclam(1), sigtool(1).
