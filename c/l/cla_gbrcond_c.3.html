CLA_GBRCOND_C calcule le nombre de conditionnement en norme infinie de op(A)*inv(diag(c)) pour les matrices générales bande.

Objectif :

!>
!>    CLA_GBRCOND_C Calcule le nombre de conditionnement en norme infinie de
!>    op(A) * inv(diag(C)) où C est un vecteur REEL.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N' :  A * X = B     (Pas de transposée)
!>       = 'T' :  A**T * X = B  (Transposée)
!>       = 'C' :  A**H * X = B  (Transposée conjuguée = Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est un tableau COMPLEXE, dimension (LDAB,N)
!>     En entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>     La j-ème colonne de A est stockée dans la j-ème colonne du
!>     tableau AB comme suit :
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est un tableau COMPLEXE, dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice bande A, tels que
!>     calculés par CGBTRF.  U est stocké comme une matrice bande triangulaire
!>     supérieure avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1,
!>     et les multiplicateurs utilisés lors de la factorisation sont stockés
!>     dans les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     tels que calculés par CGBTRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

C

!>          C est un tableau REEL, dimension (N)
!>     Le vecteur C dans la formule op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY est LOGICAL
!>     Si .TRUE. alors accéder au vecteur C dans la formule ci-dessus.
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Succès.
!>     i > 0 : Le i-ème argument est invalide.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (2*N).
!>     Espace de travail.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N).
!>     Espace de travail.
!>
