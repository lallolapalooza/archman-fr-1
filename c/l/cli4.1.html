CLI4(1) Manuel des commandes générales CLI4(1)

NOM

cli4 - Accès en ligne de commande à l'API Cloudflare v4

SYNOPSIS

cli4 [-V|--version] [-h|--help] [-v|--verbose] [-q|--quiet] [-j|--json] [-y|--yaml] [-n|--ndjson] [-r|--raw] [-d|--dump] [-p profile-name|--profile profile-name] [item=valeur ...] [item=@nom_fichier ...] [-G|--get] [-P|--patch] [-O|--post] [-U|--put] [-D|--delete] /commande...

DESCRIPTION

cli4 fournit un accès en ligne de commande à l'API Cloudflare v4.

OPTIONS

[-V, --version]
Affiche le numéro de version du programme et quitte.
[-h, --help]
Ces informations (sous forme concise).
[-v, --verbose]
Fournit des informations de débogage du protocole.
[-q, --quiet]
Ne produit aucune réponse JSON/YAML.
[-j, --json]
Produit la réponse au format JSON (par défaut).
[-y, --yaml]
Produit la réponse au format YAML (si le paquet yaml est installé).
[-n, --ndjson]
Produit la réponse au format NDJSON (si le paquet jsonlines est installé).
[-r, --raw]
Produit les résultats JSON en mode brut sans séparer les erreurs et les résultats.
[-d, --dump]
Produit une liste de tous les appels API inclus dans le code.
[-p nom_profil, --profile nom_profil]
Sélectionne un nom_profil dans le fichier de configuration (et donc sélectionne des valeurs personnalisées d'email/token).
--get
Envoie la requête HTTP en tant que GET (par défaut).
--patch
Envoie la requête HTTP en tant que PATCH.
--post
Envoie la requête HTTP en tant que POST.
--put
Envoie la requête HTTP en tant que PUT.
--delete
Envoie la requête HTTP en tant que DELETE.
item=valeur
Définit un paramètre ou une valeur de données à envoyer avec une commande GET, PATCH, POST, PUT ou DELETE. La valeur est envoyée sous forme de chaîne.
item:=valeur
Définit un paramètre ou une valeur de données à envoyer avec une commande GET, PATCH, POST, PUT ou DELETE. La valeur est envoyée sous forme d'entier.
item=@nom_fichier
Définit un paramètre ou une valeur de données à envoyer avec une commande POST ou PUT. La valeur est basée sur le contenu du fichier.
/commande ...
La ou les commandes API à exécuter.

COMMANDE(S)

La chaîne de commande utilise la barre oblique (/) pour séparer les verbes de la même manière que le fait la documentation de l'API Cloudflare v4. Tout verbe commençant par deux-points (:) est converti en zone_id, user_id, organtization_id, ou autre. Tout verbe commençant par deux deux-points (::) est passé tel quel.

RÉSULTATS

La sortie est formatée en JSON ou en YAML.

EXEMPLES

cli4 /zones Liste les informations pour toutes les zones.

cli4 /zones/:example.com Liste les informations spécifiques d'une zone.

cli4 /zones/:example.com/settings Liste les paramètres d'une zone spécifique.

cli4 --delete purge_everything=true /zones/:example.com/purge_cache Purge le cache pour une zone spécifique.

cli4 --delete files='[http://example.com/css/styles.css]' /zones/:example.com/purge_cache Purge le cache pour une zone spécifique.

cli4 --delete files='[http://example.com/css/styles.css,http://example.com/js/script.js] /zones/:example.com/purge_cache Purge le cache pour une zone spécifique.

cli4 --delete tags='[tag1,tag2,tag3]' /zones/:example.com/purge_cache Purge le cache pour une zone spécifique.

cli4 /zones/:example.com/available_plans Liste les plans disponibles pour une zone.

cli4 --patch status=active /zones/:example.com/dnssec Active le DNSSEC pour une zone spécifique.

cli4 /zones/:example.com/dnssec Liste les informations et le statut DNSSEC pour une zone spécifique.

VOIR AUSSI

L'API Cloudflare peut être trouvée sur https://api.cloudflare.com/. Chaque appel API est fourni via une fonction portant un nom similaire au sein de la classe Cloudflare.
