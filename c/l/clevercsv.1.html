NOM

clevercsv - Outil en ligne de commande CleverCSV

SYNTAXE

clevercsv [-h | --help] [-V | --version] [-v | --verbose] <commande ...>

DESCRIPTION

CleverCSV est une bibliothèque Python et un outil en ligne de commande pour traiter les fichiers CSV désordonnés. Il comprend un certain nombre de commandes qui peuvent être utilisées pour analyser, explorer ou standardiser un fichier CSV désordonné.

Une aide et une documentation supplémentaires sont disponibles en ligne sur https://github.com/alan-turing-institute/CleverCSV ou https://clevercsv.readthedocs.io

OPTIONS

-h, --help

afficher ce message d'aide et quitter

-V, --version

Afficher la version et quitter

-v, --verbose

Activer le mode verbeux

COMMANDES

Les commandes suivantes sont disponibles dans CleverCSV :

clevercsv-code(1)

Générer du code Python pour importer un fichier CSV donné

clevercsv-detect(1)

Détecter le dialecte d'un fichier CSV

clevercsv-explore(1)

Inférez le dialecte et ouvrez le fichier dans une session Python interactive

clevercsv-standardize(1)

Convertir un fichier CSV désordonné en un fichier conforme à la RFC-4180

clevercsv-view(1)

Détecter le dialecte et ouvrir le fichier CSV à l'aide de TabView

AUTEURS

Le package CleverCSV a été initialement écrit par Gerrit van den Burg et est issu de recherches scientifiques sur la manipulation de fichiers CSV désordonnés par Gerrit van den Burg, Alfredo Nazabal et Charles Sutton. Cette recherche a été menée et soutenue par The Alan Turing Institute. CleverCSV a depuis bénéficié d'un certain nombre de contributeurs open source sur GitHub.

SIGNALEMENT DE BOGUES

Si vous rencontrez un problème avec CleverCSV, veuillez ouvrir un ticket ou soumettre une demande d'extraction sur https://github.com/alan-turing-institute/CleverCSV. N'hésitez pas, vous aidez à rendre ce projet meilleur pour tout le monde !
