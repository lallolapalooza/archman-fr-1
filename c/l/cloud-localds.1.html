NOM

cloud-localds - créer un disque pour que cloud-init l'utilise en mode nocloud

SYNOPSIS

cloud-localds [options] sortie user-data [meta-data]

DESCRIPTION

cloud-localds crée une image disque avec user-data et/ou meta-data pour cloud-init(1). user-data peut contenir tout ce qui est pris en charge par cloud-init(1).

OPTIONS

-d, --disk_format=FORMATDISQUE
Format du disque à générer. Voir qemu-img(1) pour les formats de disque autorisés. Le format par défaut est raw.
-f, --filesystem=FORMAT
Format du système de fichiers. Les formats autorisés sont vfat et iso. Le format par défaut est iso9660.
-h, --help
Affiche l'aide.
-i, --interfaces
Écrit le fichier d'interfaces réseau dans les métadonnées.
-m, --dsmode=MODE
Ajoute dsmode aux métadonnées. Les modes autorisés sont local ou net. Le mode par défaut dans cloud-init(1) est net.

EXEMPLES

Cet exemple crée une image disque contenant user-data qui peut être utilisée pour démarrer une image cloud compatible avec cloud-init(1).

Créer quelques user-data :
cat > my-user-data <<EOF
password: passw0rd
chpasswd: { expire: False }
ssh_pwauth: True
EOF
Créer l'image disque contenant les user-data :
cloud-localds my-seed.img my-user-data
Démarrer l'image cloud :
qemu -net nic -net user -hda cloud-image.img -hdb my-seed.img -m 512

cloud-image.img est une image compatible avec cloud-init(1) au démarrage.

VOIR AUSSI

cloud-init(1), qemu-img(1), qemu(1)
