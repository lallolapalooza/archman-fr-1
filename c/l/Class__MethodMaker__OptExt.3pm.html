NOM

Class::MethodMaker::OptExt - Constantes pour le mécanisme d'extension d'options de C::MM

SYNOPIS

Cette classe est interne à Class::MethodMaker et ne devrait pas être utilisée par les clients. Elle ne fait **pas** partie de l'API publique.

DESCRIPTION

Cette classe contient les constantes utilisées par Class::MethodMaker pour déterminer les noms de ses méthodes dépendantes des options invoquées.

CONSTANTES DE CLASSE

OPTEXT

OPTEXT est une table de correspondance entre les options implémentées comme extensions de méthode et les paramètres de l'option.

Les clés des paramètres sont :

encode
Numéro de code (pour permettre l'encodage de la combinaison d'options tout en gardant la longueur du nom de la sous-routine à 8 caractères maximum). encode est requis pour toutes les options (pour déterminer l'extension de méthode) et doit être une puissance de deux.
refer
Code pour se référer au stockage (par défaut : '$_[0]->{$name}').
decl
Code pour déclarer le stockage.
postac
Code à exécuter immédiatement après toute vérification d'affectation - par exemple, pour initialiser le stockage si nécessaire.
asgnchk
Code pour vérifier les affectations.
defchk
Code pour la vérification par défaut.
reset
Code à exécuter lors de la réinitialisation d'un élément.
read
Code à exécuter chaque fois qu'une valeur est lue.
store
Code à exécuter chaque fois qu'une valeur est stockée.

COMPOSANTS DE CLASSE

FONCTIONS DE NIVEAU SUPÉRIEUR DE CLASSE

encode

Prend un ensemble d'options, renvoie un code à deux lettres qui représente l'extension à ajouter au nom de la méthode pour incorporer les extensions, et une liste (référence d'tableau) des extensions représentées.

SYNOPIS
my ($ext, $opt) =
  Class::MethodMaker::OptExt->encode([qw( static type foobar )]);
ARGUMENTS
options
Les options à encoder, sous forme de référence d'tableau de noms d'options.
RETOURNE
ext
Un code (chaîne de caractères) à ajouter au nom de la méthode pour représenter les options utilisées.
opts
Les options représentées par l'extension ext. Il s'agit généralement d'un sous-ensemble de celles fournies dans options, car toutes les options générales ne sont pas gérées par un nom de méthode encodé.
