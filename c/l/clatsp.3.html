sous-programme clatsp (caractère uplo, entier n, complexe, dimension( * ) x, entier, dimension( * ) iseed)

CLATSP

But:

!>
!> CLATSP génère une matrice de test spéciale pour la factorisation symétrique
!> complexe (indéfinie) pour les matrices empaquetées. Les blocs de pivot
!> de la matrice générée seront dans l'ordre suivant:
!>    Bloc de pivot 2x2, non diagonalisable
!>    Bloc de pivot 1x1
!>    Bloc de pivot 2x2, diagonalisable
!>    (le cycle se répète)
!> Un échange de lignes est requis pour chaque bloc 2x2 non diagonalisable.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE
!>          Spécifie si la matrice générée doit être triangulaire supérieure ou
!>          inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est ENTIER
!>          La dimension de la matrice à générer.
!>

X

!>          X est un tableau de type COMPLETXE, dimension (N*(N+1)/2)
!>          La matrice générée en format de stockage empaqueté. La matrice
!>          se compose de blocs diagonaux 3x3 et 2x2 qui résultent en la
!>          séquence de pivots donnée ci-dessus. La matrice en dehors de ces
!>          blocs diagonaux est nulle.
!>

ISEED

!>          ISEED est un tableau ENTIER, dimension (4)
!>          À l'entrée, la graine pour le générateur de nombres aléatoires. Le dernier
!>          des quatre entiers doit être impair. (modifié à la sortie)
!>
