sous-routine clattr (entier imat, caractère uplo, caractère trans, caractère diag, entier, dimension( 4 ) iseed, entier n, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( * ) b, complexe, dimension( * ) work, réel, dimension( * ) rwork, entier info)

CLATTR

But :

!>
!> CLATTR génère une matrice de test triangulaire en stockage 2D.
!> IMAT et UPLO spécifient de manière unique les propriétés de la matrice de test,
!> qui est retournée dans le tableau A.
!>

Paramètres

IMAT 
!>          IMAT est un ENTIER
!>          Une clé entière décrivant quelle matrice générer pour ce
!>          chemin.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          Spécifie si la matrice A sera triangulaire supérieure ou inférieure.
!>          = 'U' :  Triangulaire supérieure
!>          = 'L' :  Triangulaire inférieure
!>

TRANS

!>          TRANS est CARACTERE*1
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N' :  Pas de transposée
!>          = 'T' :  Transposée
!>          = 'C' :  Transposée conjuguée
!>

DIAG

!>          DIAG est CARACTERE*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N' :  Triangulaire non unitaire
!>          = 'U' :  Triangulaire unitaire
!>

ISEED

!>          ISEED est un tableau d'ENTIERS, dimension (4)
!>          Le vecteur de graine pour le générateur de nombres aléatoires (utilisé dans
!>          CLATMS).  Modifié à la sortie.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice à générer.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie triangulaire
!>          supérieure N x N du tableau A contient la matrice triangulaire
!>          supérieure, et la partie strictement triangulaire inférieure de
!>          A n'est pas référencée.  Si UPLO = 'L', la partie triangulaire
!>          inférieure N x N du tableau A contient la matrice triangulaire
!>          inférieure et la partie strictement triangulaire supérieure de A n'est
!>          pas référencée.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEXE, dimension (N)
!>          Le vecteur second membre, si IMAT > 10.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 :  Sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument était invalide
!>
