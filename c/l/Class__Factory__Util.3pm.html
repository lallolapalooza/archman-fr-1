Class::Factory::Util(3pm) Documentation Perl fournie par l'utilisateur Class::Factory::Util(3pm)

NOM

Class::Factory::Util - Fournir des méthodes utilitaires pour les classes d'usine

SYNTAXE

package My::Class;
use Class::Factory::Util;
My::Class->subclasses;

DESCRIPTION

Ce module exporte une méthode utile pour les classes d'usine.

UTILISATION

Lorsque ce module est chargé, il crée une méthode dans son appelant nommée subclasses(). Cette méthode retourne une liste des sous-classes disponibles pour le paquet. Elle le fait en recherchant dans @INC ainsi que dans le répertoire contenant l'appelant, et en trouvant tous les modules dans les sous-répertoires immédiats du module appelant.

Ainsi, si vous avez les modules "Foo::Base", "Foo::Base::Bar", et "Foo::Base::Baz", la valeur de retour de "Foo::Base->subclasses()" serait "Bar" et "Baz".
