CLIENT *clntraw_create(unsigned long prognum, unsigned long versnum)
;
Cette routine crée un client RPC fictif pour le programme distant prognum, version versnum. Le transport utilisé pour passer les messages au service est en réalité un tampon dans l'espace d'adressage du processus, de sorte que le serveur RPC correspondant doit se trouver dans le même espace d'adressage ; voir svcraw_create(). Cela permet la simulation de RPC et l'acquisition des surcoûts RPC, comme les tem

CLIENT *clnttcp_create(struct sockaddr_in *addr,
                unsigned long prognum, unsigned long versnum,
                int *sockp, unsigned int sendsz, unsigned int recvsz)
;
Cette routine crée un client RPC pour le programme distant prognum, version versnum ; le client utilise TCP/IP comme transport. Le programme distant est situé à l'adresse Internet *addr. Si addr->sin_port est zéro, alors il est défini sur le port réel sur lequel le programme distant écoute (le service portmap distant est consulté pour obtenir cette information). Le paramètre sockp est un socket ; s'il est RPC_ANYSOCK, alors cette routine en ouvre un nouveau et définit sockp. Puisque le RPC basé sur TCP utilise des E/S tamponnées, l'utilisateur peut spécifier la taille des tampons d'envoi et de réception avec les paramètres sendsz et recvsz ; des valeurs de zéro choisissent des valeurs par déf
aut appropriées. Cette routine
retourne NULL en cas d'échec.

Une fois terminé, xprt->xp_sock est le descripteur de socket du transport, et xprt->xp_port est le numéro de port du transport. Cette routine renvoie NULL en cas d'échec.
