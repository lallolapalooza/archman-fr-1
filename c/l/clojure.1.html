CONFIGURATIO

N

Ce script lit la configuration à partir des fichiers deps.edn. Il vérifiera les fichiers deps.edn à l'emplacement racine du système, dans le répertoire de configuration de l'utilisateur (généralement ~/.clojure) et dans le répertoire local. Les fichiers à chacun de ces emplacements, s'ils existent, sont fusionnés pour former un fichier de configuration co

mbiné. Les options du dernier fichier de configuration spécifié écrasent celles
des fichiers précédents (par ex. les configurations locales ont la priorité).
