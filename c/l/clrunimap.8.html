NOM

clrunimap - Efface la carte unicode actuelle de la console

SYNTAXE

clrunimap [options]

DESCRIPTION

La commande clrunimap efface la carte unicode (également appelée "Screen Font Map") pour la console actuelle.

OPTIONS

-C, --console=DEV
le périphérique console à utiliser.
-V, --version
affiche le numéro de version.
-h, --help
affiche ce message d'utilisation.

NOTES

Si vous n'êtes pas le mainteneur du paquet kbd, il est très peu probable que vous souhaitiez utiliser cette commande. Sur de nombreux noyaux, le résultat sera un écran noir. Sur certains noyaux, un redémarrage sera nécessaire.
Utilisez setfont -u pour charger une carte Unicode pour une console.

VOIR AUSSI

setfont(8).
