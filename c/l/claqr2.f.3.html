subroutine claqr2 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, complex, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, complex, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, complex, dimension( * ) sh, complex, dimension( ldv, * ) v, integer ldv, integer nh, complex, dimension( ldt, * ) t, integer ldt, integer nv, complex, dimension( ldwv, * ) wv, integer ldwv, complex, dimension( * ) work, integer lwork)

CLAQR2 effectue la transformation de similarité unitaire d'une matrice de Hessenberg pour détecter et déflater les valeurs propres entièrement convergées d'une sous-matrice principale traînante (déflation précoce agressive).

But :

!>
!>    CLAQR2 est identique à CLAQR3 sauf qu'il évite
!>    la récursion en appelant CLAHQR au lieu de CLAQR4.
!>
!>    Déflation précoce agressive :
!>
!>    Cette sous-routine accepte en entrée une matrice de Hessenberg
!>    supérieure H et effectue une transformation de similarité unitaire
!>    conçue pour détecter et déflater les valeurs propres entièrement
!>    convergées d'une sous-matrice principale traînante.  En sortie, H a été
!>    écrasée par une nouvelle matrice de Hessenberg qui est une perturbation
!>    d'une transformation de similarité unitaire de H.  On espère
!>    que la version finale de H a de nombreuses entrées sous-diagonales
!>    nulles.
!>

Paramètres

WANTT 
!>          WANTT est de type LOGIQUEL
!>          Si .TRUE., alors la matrice de Hessenberg H est entièrement mise à jour
!>          de sorte que le facteur de Schur triangulaire puisse être
!>          calculé (en coopération avec la sous-routine appelante).
!>          Si .FALSE., alors seule la partie de H nécessaire est mise à jour pour préserver
!>          les valeurs propres.
!>

WANTZ

!>          WANTZ est de type LOGIQUEL
!>          Si .TRUE., alors la matrice unitaire Z est mise à jour
!>          de sorte que le facteur de Schur unitaire puisse être calculé
!>          (en coopération avec la sous-routine appelante).
!>          Si .FALSE., alors Z n'est pas référencée.
!>

N

!>          N est de type ENTIER
!>          L'ordre de la matrice H et (si WANTZ est .TRUE.) l'ordre
!>          de la matrice unitaire Z.
!>

KTOP

!>          KTOP est de type ENTIER
!>          On suppose que soit KTOP = 1, soit H(KTOP,KTOP-1)=0.
!>          KBOT et KTOP déterminent ensemble un bloc isolé
!>          le long de la diagonale de la matrice de Hessenberg.
!>

KBOT

!>          KBOT est de type ENTIER
!>          On suppose sans vérification que soit
!>          KBOT = N, soit H(KBOT+1,KBOT)=0.  KBOT et KTOP déterminent ensemble
!>          un bloc isolé le long de la diagonale de la
!>          matrice de Hessenberg.
!>

NW

!>          NW est de type ENTIER
!>          Taille de la fenêtre de déflation.  1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H est un tableau COMPLEXE, dimension (LDH,N)
!>          À l'entrée, la section initiale N-par-N de H stocke la
!>          matrice de Hessenberg subissant la déflation précoce agressive.
!>          À la sortie, H a été transformée par une transformation de similarité
!>          unitaire, perturbée, puis ramenée
!>          à la forme de Hessenberg qui (on l'espère) a certaines
!>          entrées sous-diagonales nulles.
!>

LDH

!>          LDH est de type ENTIER
!>          Dimension principale de H telle que déclarée dans la sous-routine
!>          appelante.  N <= LDH
!>

ILOZ

!>          ILOZ est de type ENTIER
!>

IHIZ

!>          IHIZ est de type ENTIER
!>          Spécifient les lignes de Z auxquelles les transformations doivent être
!>          appliquées si WANTZ est .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z est un tableau COMPLEXE, dimension (LDZ,N)
!>          SI WANTZ est .TRUE., alors à la sortie, la transformation de similarité
!>          unitaire mentionnée ci-dessus a été
!>          accumulée dans Z(ILOZ:IHIZ,ILOZ:IHIZ) par la droite.
!>          Si WANTZ est .FALSE., alors Z n'est pas référencée.
!>

LDZ

!>          LDZ est de type ENTIER
!>          La dimension principale de Z telle que déclarée dans la
!>          sous-routine appelante.  1 <= LDZ.
!>

NS

!>          NS est de type ENTIER
!>          Le nombre de valeurs propres non convergées (c.-à-d. approximatives)
!>          retournées dans SR et SI qui peuvent être utilisées comme décalages par la
!>          sous-routine appelante.
!>

ND

!>          ND est de type ENTIER
!>          Le nombre de valeurs propres convergées découvertes par cette
!>          sous-routine.
!>

SH

!>          SH est un tableau COMPLEXE, dimension (KBOT)
!>          À la sortie, les valeurs propres approximatives qui peuvent
!>          être utilisées comme décalages sont stockées dans SH(KBOT-ND-NS+1)
!>          jusqu'à SR(KBOT-ND).  Les valeurs propres convergées sont
!>          stockées dans SH(KBOT-ND+1) jusqu'à SH(KBOT).
!>

V

!>          V est un tableau COMPLEXE, dimension (LDV,NW)
!>          Un tableau de travail NW-par-NW.
!>

LDV

!>          LDV est de type ENTIER
!>          La dimension principale de V telle que déclarée dans la
!>          sous-routine appelante.  NW <= LDV
!>

NH

!>          NH est de type ENTIER
!>          Le nombre de colonnes de T.  NH >= NW.
!>

T

!>          T est un tableau COMPLEXE, dimension (LDT,NW)
!>

LDT

!>          LDT est de type ENTIER
!>          La dimension principale de T telle que déclarée dans la
!>          sous-routine appelante.  NW <= LDT
!>

NV

!>          NV est de type ENTIER
!>          Le nombre de lignes du tableau de travail WV disponibles pour
!>          l'espace de travail.  NV >= NW.
!>

WV

!>          WV est un tableau COMPLEXE, dimension (LDWV,NW)
!>

LDWV

!>          LDWV est de type ENTIER
!>          La dimension principale de W telle que déclarée dans la
!>          sous-routine appelante.  NW <= LDV
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (LWORK)
!>          À la sortie, WORK(1) est défini à une estimation de la valeur optimale
!>          de LWORK pour les valeurs données de N, NW, KTOP et KBOT.
!>

LWORK

!>          LWORK est de type ENTIER
!>          La dimension du tableau de travail WORK.  LWORK = 2*NW
!>          suffit, mais une plus grande efficacité peut résulter de valeurs
!>          plus grandes de LWORK.
!>
!>          Si LWORK = -1, alors une interrogation d'espace de travail est supposée ; CLAQR2
!>          estime seulement la taille optimale de l'espace de travail pour les valeurs
!>          données de N, NW, KTOP et KBOT.  L'estimation est retournée
!>          dans WORK(1).  Aucun message d'erreur lié à LWORK n'est émis
!>          par XERBLA.  Ni H ni Z ne sont accédés.
!>
