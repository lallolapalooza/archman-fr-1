sous-routine clarzb (side, trans, direct, storev, m, n, k, l, v, ldv, t, ldt, c, ldc, work, ldwork)
CLARZB applique un réflecteur de bloc ou sa transposée conjuguée à une matrice générale.

Documentation de la fonction/sous-routine

sous-routine clarzb (caractère side, caractère trans, caractère direct, caractère storev, entier m, entier n, entier k, entier l, complexe, dimension( ldv, * ) v, entier ldv, complexe, dimension( ldt, * ) t, entier ldt, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( ldwork, * ) work, entier ldwork)

CLARZB applique un réflecteur de bloc complexe H ou sa transposée conjuguée H**H à une matrice complexe générale C, à gauche ou à droite.

Objectif :

!>
!> CLARZB applique un réflecteur de bloc complexe H ou sa transposée H**H
!> à une matrice complexe distribuée C de taille M par N, à gauche ou à droite.
!>
!> Actuellement, seuls STOREV = 'R' et DIRECT = 'B' sont supportés.
!>

Paramètres

SIDE 
!>          SIDE est de type CHARACTER*1
!>          = 'L' : applique H ou H**H à gauche
!>          = 'R' : applique H ou H**H à droite
!>

TRANS

!>          TRANS est de type CHARACTER*1
!>          = 'N' : applique H (pas de transposée)
!>          = 'C' : applique H**H (transposée conjuguée)
!>

DIRECT

!>          DIRECT est de type CHARACTER*1
!>          Indique comment H est formé à partir d'un produit de réflecteurs
!>          élémentaires.
!>          = 'F' : H = H(1) H(2) . . . H(k) (Avancé, non supporté pour l'instant)
!>          = 'B' : H = H(k) . . . H(2) H(1) (Arrière)
!>

STOREV

!>          STOREV est de type CHARACTER*1
!>          Indique comment les vecteurs qui définissent les réflecteurs
!>          élémentaires sont stockés :
!>          = 'C' : Par colonne (non supporté pour l'instant)
!>          = 'R' : Par ligne
!>

M

!>          M est de type INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est de type INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

K

!>          K est de type INTEGER
!>          L'ordre de la matrice T (= le nombre de réflecteurs
!>          élémentaires dont le produit définit le réflecteur de bloc).
!>

L

!>          L est de type INTEGER
!>          Le nombre de colonnes de la matrice V contenant la partie
!>          significative des réflecteurs de Householder.
!>          Si SIDE = 'L', alors M >= L >= 0 ; si SIDE = 'R', alors N >= L >= 0.
!>

V

!>          V est un tableau de type COMPLEX, de dimension (LDV, NV).
!>          Si STOREV = 'C', alors NV = K ; si STOREV = 'R', alors NV = L.
!>

LDV

!>          LDV est de type INTEGER
!>          La dimension principale du tableau V.
!>          Si STOREV = 'C', alors LDV >= L ; si STOREV = 'R', alors LDV >= K.
!>

T

!>          T est un tableau de type COMPLEX, de dimension (LDT, K)
!>          La matrice triangulaire T de taille K par K dans la représentation du
!>          réflecteur de bloc.
!>

LDT

!>          LDT est de type INTEGER
!>          La dimension principale du tableau T. LDT >= K.
!>

C

!>          C est un tableau de type COMPLEX, de dimension (LDC, N)
!>          À l'entrée, la matrice C de taille M par N.
!>          À la sortie, C est écrasée par H*C ou H**H*C ou C*H ou C*H**H.
!>

LDC

!>          LDC est de type INTEGER
!>          La dimension principale du tableau C. LDC >= max(1, M).
!>

WORK

!>          WORK est un tableau de type COMPLEX, de dimension (LDWORK, K)
!>

LDWORK

!>          LDWORK est de type INTEGER
!>          La dimension principale du tableau WORK.
!>          Si SIDE = 'L', alors LDWORK >= max(1, N) ;
!>          si SIDE = 'R', alors LDWORK >= max(1, M).
!>
