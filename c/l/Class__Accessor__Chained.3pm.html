NOM

Class::Accessor::Chained - créer des accesseurs chaînés

SYNTAXE

package Foo;
use base qw( Class::Accessor::Chained );
__PACKAGE__->mk_accessors(qw( foo bar baz ));
my $foo = Foo->new->foo(1)->bar(2)->baz(4);
print $foo->bar; # affiche 2

DESCRIPTION

Un accesseur chaîné est un accesseur qui retourne toujours l'objet lorsqu'il est appelé avec des paramètres (pour définir) et la valeur du champ lorsqu'il est appelé sans arguments.

Ce module hérite de Class::Accessor afin de fournir la même interface mk_accessors.
