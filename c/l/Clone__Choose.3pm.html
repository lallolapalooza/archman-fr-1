NOM

Clone::Choose - Choisir l'utilitaire de clonage approprié

SYNOPSIS

use Clone::Choose;
my $data = {
    value => 42,
    href  => {
        set   => [ 'foo', 'bar' ],
        value => 'baz',
    },
};
my $cloned_data = clone $data;
# il est aussi possible d'utiliser Clone::Choose et de passer une préférence de clonage
use Clone::Choose qw(:Storable);

DESCRIPTION

"Clone::Choose" vérifie plusieurs modules différents qui fournissent une fonction clone() et en sélectionne un approprié. La préférence par défaut est

Clone
Storable
Clone::PP

Cette liste pourrait évoluer dans le futur. Veuillez voir "EXPORTS" comment choisir un module particulier.

EXPORTS

"Clone::Choose" exporte clone() par défaut.

On peut importer explicitement "clone" en utilisant

use Clone::Choose qw(clone);

ou choisir une implémentation particulière de "clone"

use Clone::Choose qw(:Storable clone);

L'implémentation exportée est résolue dynamiquement, ce qui signifie que tout module utilisateur peut soit s'appuyer sur la préférence du backend par défaut, soit choisir un backend particulier.

Il est également possible de sélectionner un backend "clone" particulier en définissant la variable d'environnement CLONE_CHOOSE_PREFERRED_BACKEND à votre backend préféré.

Cela signifie aussi qu'une importation déjà choisie ne peut pas être modifiée comme ceci :

use Clone::Choose qw(clone :Storable);

Lorsque l'on a vraiment besoin de différentes implémentations de clonage, notre méthode *recommandée* pour les utiliser serait :

use Clone::Choose (); # ne pas importer
my ($xs_clone, $st_clone);
{ local @Clone::Choose::BACKENDS = (Clone => "clone"); $xs_clone = Clone::Choose->can("clone"); }
{ local @Clone::Choose::BACKENDS = (Storable => "dclone"); $st_clone = Clone::Choose->can("clone"); }

Ne méprenez pas *recommandée* - modifier @Clone::Choose::BACKENDS présente de nombreux pièges et n'est pas fiable en dehors de tels exemples simples. N'hésitez pas à ouvrir une requête avec une proposition appropriée pour choisir les implémentations dynamiquement.

L'utilisation de @Clone::Choose::BACKENDS est déconseillée et sera dépréciée dès qu'une meilleure idée sera proposée.

METHODES DU PAQUET

backend

"backend" informe l'appelant du backend choisi dynamiquement :

use Clone::Choose;
say Clone::Choose->backend; # Clone

Cette méthode existe actuellement uniquement à des fins de débogage.

get_backends

"get_backends" renvoie une liste des backends actuellement supportés.
