clock(3) Manuel des fonctions de bibliothèque clock(3)

NOM

clock - déterminer le temps processeur

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <time.h>
clock_t clock(void);

DESCRIPTION

La fonction clock() retourne une approximation du temps processeur utilisé par le programme.

VALEUR DE RETOUR

La valeur retournée est le temps CPU utilisé jusqu'à présent sous forme de clock_t; pour obtenir le nombre de secondes utilisées, divisez par CLOCKS_PER_SEC. Si le temps processeur utilisé n'est pas disponible ou si sa valeur ne peut pas être représentée, la fonction retourne la valeur (clock_t) -1.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
clock () Sécurité des threads MT-Safe

VERSIONS

XSI exige que CLOCKS_PER_SEC soit égal à 1000000 indépendamment de la résolution réelle.

Sur plusieurs autres implémentations, la valeur retournée par clock() inclut également les temps des enfants dont le statut a été collecté via wait(2) (ou un autre appel de type wait). Linux n'inclut pas les temps des enfants attendus dans la valeur retournée par clock(). La fonction times(2), qui retourne explicitement des informations (séparées) sur l'appelant et ses enfants, peut être préférable.

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C89.

Dans glibc 2.17 et antérieur, clock() était implémenté par-dessus times(2). Pour une meilleure précision, depuis glibc 2.18, il est implémenté par-dessus clock_gettime(2) (en utilisant l'horloge CLOCK_PROCESS_CPUTIME_ID).

NOTES

La norme C autorise des valeurs arbitraires au début du programme ; soustraire la valeur retournée par un appel à clock() au début du programme pour une portabilité maximale.

Notez que le temps peut dépasser. Sur un système 32 bits où CLOCKS_PER_SEC est égal à 1000000, cette fonction retournera la même valeur approximativement toutes les 72 minutes.

VOIR AUSSI

clock_gettime(2), getrusage(2), times(2)
