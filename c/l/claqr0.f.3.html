sous-routine claqr0 (wantt, wantz, n, ilo, ihi, h, ldh, w, iloz, ihiz, z, ldz, work, lwork, info)
CLAQR0 calcule les valeurs propres d'une matrice de Hessenberg et, optionnellement, les matrices de la décomposition de Schur.

Documentation de la fonction/sous-routin

e

sous-routine claqr0 (logical wantt, logical wantz, integer n, integer ilo, integer ihi, complex, dimension( ldh, * ) h, integer ldh, complex, dimension( * ) w, integer iloz, integer ihiz, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, integer lwork, integer

info)

CLAQR0 calcule les valeurs propres d'une matrice de Hessenberg et, optionnellement, les matrices de la décomposition de

Schur.

But

: 
!>
!>    CLAQR0 calcule les valeurs propres d'une matrice de Hessenberg H
!>    et, optionnellement, les matrices T et Z de la décomposition de Schur
!>    H = Z T Z**H, où T est une matrice triangulaire supérieure (la
!>    forme de Schur), et Z est la matrice unitaire des vecteurs de Schur.
!>
!>    Optionnellement, Z peut être multipliée à droite par une matrice
!>    unitaire d'entrée Q afin que cette routine puisse fournir la factorisation
!>    de Schur d'une matrice A qui a été réduite à la forme de Hessenberg H
!>    par la matrice unitaire Q :  A = Q*H*Q**H = (QZ)*H*(QZ)**H.
!
>

Paramètre

s
WANTT 
!>          WANTT est de type LOGIQUEL
!>          = .TRUE. : la forme de Schur complète T est requise ;
!>          = .FALSE. : seules les valeurs propres sont requises.
!
>

WANT

Z 
!>          WANTZ est de type LOGIQUEL
!>          = .TRUE. : la matrice des vecteurs de Schur Z est requise ;
!>          = .FALSE. : les vecteurs de Schur ne sont pas requis.
!
>

N 
!>          N est de type INTEGER
!>           L'ordre de la matrice H.  N >= 0.
!
>

IL

O 
!>          ILO est de type INTEGER
!
>

IH

I 
!>          IHI est de type INTEGER
!>           On suppose que H est déjà triangulaire supérieure dans les lignes
!>           et les colonnes 1:ILO-1 et IHI+1:N et, si ILO > 1,
!>           H(ILO,ILO-1) est nul. ILO et IHI sont normalement définis par un
!>           appel précédent à CGEBAL, puis transmis à CGEHRD lorsque la
!>           matrice produite par CGEBAL est réduite à la forme de Hessenberg.
!>           Sinon, ILO et IHI doivent être définis à 1 et N,
!>           respectivement.  Si N > 0, alors 1 <= ILO <= IHI <= N.
!>           Si N = 0, alors ILO = 1 et IHI = 0.
!
>

H 
!>          H est un tableau COMPLEX de dimension (LDH,N)
!>           À l'entrée, la matrice de Hessenberg supérieure H.
!>           À la sortie, si INFO = 0 et WANTT vaut .TRUE., alors H
!>           contient la matrice triangulaire supérieure T issue de la décomposition
!>           de Schur (la forme de Schur). Si INFO = 0 et WANT vaut
!>           .FALSE., alors le contenu de H est indéfini à la sortie.
!>           (La valeur de sortie de H lorsque INFO > 0 est donnée dans la
!>           description de INFO ci-dessous.)
!>
!>           Cette sous-routine peut définir explicitement H(i,j) = 0 pour i > j et
!>           j = 1, 2, ... ILO-1 ou j = IHI+1, IHI+2, ... N.
!
>

LD

H 
!>          LDH est de type INTEGER
!>           La dimension principale du tableau H. LDH >= max(1,N).
!
>

W 
!>          W est un tableau COMPLEX de dimension (N)
!>           Les valeurs propres calculées de H(ILO:IHI,ILO:IHI) sont stockées
!>           dans W(ILO:IHI). Si WANTT vaut .TRUE., alors les valeurs propres sont
!>           stockées dans le même ordre que sur la diagonale de la forme
!>           de Schur retournée dans H, avec W(i) = H(i,i).
!
>

ILO

Z 
!>          ILOZ est de type INTEGER
!
>

IHI

Z 
!>          IHIZ est de type INTEGER
!>           Spécifie les lignes de Z auxquelles les transformations doivent être
!>           appliquées si WANTZ vaut .TRUE..
!>           1 <= ILOZ <= ILO ; IHI <= IHIZ <= N.
!
>

Z 
!>          Z est un tableau COMPLEX de dimension (LDZ,IHI)
!>           Si WANTZ vaut .FALSE., alors Z n'est pas référencé.
!>           Si WANTZ vaut .TRUE., alors Z(ILO:IHI,ILOZ:IHIZ) est
!>           remplacé par Z(ILO:IHI,ILOZ:IHIZ)*U où U est le
!>           facteur de Schur orthogonal de H(ILO:IHI,ILO:IHI).
!>           (La valeur de sortie de Z lorsque INFO > 0 est donnée dans la
!>           description de INFO ci-dessous.)
!
>

LD

Z 
!>          LDZ est de type INTEGER
!>           La dimension principale du tableau Z.  si WANTZ vaut .TRUE.
!>           alors LDZ >= MAX(1,IHIZ).  Sinon, LDZ >= 1.
!
>

WOR

K 
!>          WORK est un tableau COMPLEX de dimension LWORK
!>           À la sortie, si LWORK = -1, WORK(1) renvoie une estimation de
!>           la valeur optimale pour LWORK.
!
>

LWOR

K 
!>          LWORK est de type INTEGER
!>           La dimension du tableau WORK.  LWORK >= max(1,N)
!>           est suffisant, mais LWORK typiquement aussi grand que 6*N peut
!>           être requis pour des performances optimales.  Une interrogation
!>           de l'espace de travail pour déterminer la taille optimale de l'espace de travail est recommandée.
!>
!>           Si LWORK = -1, alors CLAQR0 effectue une interrogation de l'espace de travail.
!>           Dans ce cas, CLAQR0 vérifie les paramètres d'entrée et
!>           estime la taille optimale de l'espace de travail pour les valeurs
!>           données de N, ILO et IHI.  L'estimation est retournée
!>           dans WORK(1).  Aucun message d'erreur lié à LWORK n'est
!>           émis par XERBLA.  Ni H ni Z ne sont accédés.
!
>

INF

O 
!>          INFO est de type INTEGER
!>             = 0 :  sortie réussie
!>             > 0 :  si INFO = i, CLAQR0 n'a pas réussi à calculer toutes
!>                les valeurs propres.  Les éléments 1:ilo-1 et i+1:n de WR
!>                et WI contiennent ces valeurs propres qui ont été
!>                calculées avec succès.  (Les échecs sont rares.)
!>
!>                Si INFO > 0 et WANT vaut .FALSE., alors à la sortie,
!>                les valeurs propres non convergées restantes sont les valeurs
!>                propres de la matrice de Hessenberg supérieure lignes et
!>                colonnes ILO à INFO de la valeur finale, de sortie
!>                de H.
!>
!>                Si INFO > 0 et WANTT vaut .TRUE., alors à la sortie
!>
!>           (*)  (valeur initiale de H)*U  = U*(valeur finale de H)
!>
!>                où U est une matrice unitaire.  La valeur
!>                finale de H est de Hessenberg supérieure et triangulaire dans
!>                les lignes et les colonnes INFO+1 à IHI.
!>
!>                Si INFO > 0 et WANTZ vaut .TRUE., alors à la sortie
!>
!>                  (valeur finale de Z(ILO:IHI,ILOZ:IHIZ)
!>                   =  (valeur initiale de Z(ILO:IHI,ILOZ:IHIZ)*U
!>
!>                où U est la matrice unitaire dans (*) (indépendamment
!>                de la valeur de WANTT.)
!>
!>                Si INFO > 0 et WANTZ vaut .FALSE., alors Z n'est pas
!>                accédé.
!
>
