NOM

cleanarch - Nettoie une archive de clés DNSSEC-Tools des anciennes clés

SYNTAXE

cleanarch [options] <fichier_keyrec | fichier_rollrec>

DESCRIPTION

cleanarch supprime les anciennes clés d'une archive de clés DNSSEC-Tools. L'« âge » des clés et les archives sont déterminés par les options et les arguments.

Les options de ligne de commande et les arguments permettent la sélection des archives, des clés à supprimer, et la quantité de sortie à fournir. Les options sont divisées en trois groupes : sélection d'archive, sélection de clé et format de sortie. Les informations complètes sur les options sont fournies dans la section OPTIONS.

cleanarch prend un seul argument (à distinguer d'une option). Cet argument peut être un fichier keyrec ou un fichier rollrec. Si le fichier est un fichier keyrec, le répertoire d'archive de ses zones keyrecs est ajouté à la liste des archives à nettoyer. Si le fichier est un fichier rollrec, les fichiers keyrec de ses zones sont recherchés pour le répertoire d'archive de ces zones, et ces répertoires sont ajoutés à la liste des archives à nettoyer. Si une zone n'a pas de répertoire d'archive défini explicitement, alors celui par défaut de DNSSEC-Tools sera nettoyé. Les archives spécifiées par cet argument peuvent être modifiées par les options de sélection d'archive.

Les options de sélection d'archive se combinent avec le fichier keyrec ou rollrec pour sélectionner un ensemble de répertoires d'archive à nettoyer. (Certaines options peuvent remplacer l'argument de fichier.)

Les options de sélection de clé permettent à l'ensemble des clés à supprimer de contenir une archive entière, les clés d'une zone particulière, ou toutes les clés antérieures à une certaine date.

Les options de format de sortie définissent la quantité de sortie qui sera fournie. Sans aucune option sélectionnée, les noms des clés seront imprimés au fur et à mesure de leur suppression. Si l'option -verbose est donnée, alors les répertoires sélectionnés pour la recherche et les clés sélectionnées pour la suppression seront imprimés. Si l'option -dirlist est donnée, alors les répertoires sélectionnés pour la recherche seront imprimés et aucune autre action ne sera effectuée. Si l'option -list est donnée, alors les clés sélectionnées pour la suppression seront imprimées et aucune autre action ne sera effectuée.

cleanarch nettoie uniquement les répertoires d'archive ; les fichiers keyrec sont laissés intacts. La commande cleankrf doit être utilisée conjointement avec cleanarch afin d'avoir un environnement cohérent.

OPTIONS

Options de sélection d'archive

Les options suivantes permettent à l'utilisateur de sélectionner les archives à nettoyer.

-archive répertoire
Cette option spécifie un répertoire d'archive à nettoyer.
-defarch
Cette option indique que le répertoire d'archive par défaut (nommé dans le fichier de configuration DNSSEC-Tools) doit être nettoyé.
-zone zone
Cette option indique que zone est la seule zone dont l'archive sera nettoyée. Si le répertoire d'archive est partagé par d'autres zones, leurs clés peuvent également être supprimées.

Options de sélection de clé

Les options suivantes permettent à l'utilisateur de sélectionner les clés à supprimer.

-all
Supprime toutes les clés des archives sélectionnées. Cette option ne peut pas être utilisée avec d'autres options de sélection de clé.
-days jours
Supprime toutes les clés sauf celles dont la date de modification est antérieure de jours jours complets à la date actuelle.
-onezone zone
Seules les clés dont le nom de fichier contient zone sont supprimées. Ceci est destiné à être utilisé pour nettoyer une archive de clés multi-zones.

Cela ne valide pas que zone est une zone réelle. N'importe quelle chaîne peut être utilisée ici. Par exemple, utiliser "private" sélectionnera les anciennes clés privées pour la suppression et utiliser "com" sélectionnera n'importe quel nom de fichier contenant "com".

Options de contrôle de la sortie

Les options suivantes permettent à l'utilisateur de contrôler la sortie de cleanarch.

-dirlist
Cette option liste les répertoires d'archive sélectionnés. Aucune autre action n'est effectuée.
-list
Cette option liste les clés sélectionnées. Aucune autre action n'est effectuée.
-quiet
N'affiche aucune sortie.
-verbose
Affiche une sortie détaillée.
-Version
Affiche les informations de version pour cleanarch et le package DNSSEC-Tools.
-help
Affiche un message d'utilisation et quitte.

AVERTISSEMENTS

L'utilisateur est invité à consacrer un peu de temps à tester cet outil avant de le mettre en production. Une fois qu'une clé est supprimée, elle est perdue. Certains pourraient trouver cela préjudiciable à la santé de leur installation DNSSEC-Tools.
