CLOUD-INIT(1) Manuel des commandes générales CLOUD-INIT(1)

NOM

cloud-init - Initialisation d'instance cloud

SYNTAXE

cloud-init [-h] [-d] [--force] [-v] [SOUS-COMMANDE]

DESCRIPTION

Cloud-init fournit un mécanisme pour l'initialisation d'instance cloud. Ceci est fait en identifiant la plateforme cloud utilisée, en lisant les métadonnées cloud, les données du vendeur et les données utilisateur, puis en initialisant l'instance comme demandé.

OPTIONS

-h, --help
Afficher le message d'aide et quitter.
-v, --version
Afficher le numéro de version du programme et quitter.
--all-stages
INTERNE : Exécuter les phases de cloud-init sous un seul processus en utilisant un protocole de synchronisation. Ceci n'est pas destiné à une utilisation en ligne de commande.

SOUS-COMMANDES

Veuillez consulter l'aide de chaque sous-commande pour des détails supplémentaires, des drapeaux et des sous-commandes.

analyze
Analyser les journaux et les données de cloud-init.
collect-logs
Collecter et compresser toutes les informations de débogage de cloud-init.
clean
Supprimer les journaux et les artefacts afin que cloud-init puisse être réexécuté.
devel
Exécuter des outils de développement. Voir l'aide pour les détails des sous-commandes.
features
Lister les fonctionnalités définies.
query
Interroger les métadonnées standardisées de l'instance depuis la ligne de commande.
schema
Valider les fichiers cloud-config en utilisant jsonschema.
single
Exécuter manuellement un seul module. Utile pour les tests pendant le développement.
status
Rapporter le statut de cloud-init ou attendre sa complétion.

OBSOLÈTE

-d, --debug
Afficher la journalisation supplémentaire avant l'action (par défaut : Faux).
--force
Forcer l'exécution même si aucune source de données n'est trouvée (à utiliser à vos risques et périls).
init
Initialiser cloud-init et exécuter les modules initiaux.
modules
Activer les modules en utilisant une clé de configuration donnée.

ÉTAT DE SORTIE

0 - Succès
1 - Erreur - Cloud-init a échoué.
2 - Erreur récupérable - Cloud-init s'est terminé mais a rencontré des erreurs.
