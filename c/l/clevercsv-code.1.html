NOM

clevercsv-code - Générer du code Python pour importer un fichier CSV

SYNTAXE

clevercsv code [-e ENCODAGE | --encoding=ENCODAGE]
               [-n NOMBRE_CARACTERES | --num-chars=NOMBRE_CARACTERES] [-p | --pandas] <chemin>

DESCRIPTION

Génère du code Python pour importer un fichier CSV donné. C'est particulièrement utile si vous ne voulez pas détecter à plusieurs reprises le dialecte du même fichier. Exécutez simplement :

clevercsv code votre_fichier.csv

et copiez le code généré dans un script Python.

OPTIONS

-h, --help

affiche ce message d'aide et quitte

-e, --encoding

L'encodage du fichier CSV donné est détecté automatiquement à l'aide de chardet. Bien que chardet soit incroyablement précis, il n'est pas parfait. Dans les rares cas où il commet une erreur dans la détection de l'encodage du fichier, vous pouvez remplacer l'encodage en le fournissant via ce drapeau. De plus, lorsque vous avez un certain nombre de fichiers CSV avec un encodage de fichier connu, vous pouvez utiliser cette option pour accélérer le processus de génération de code.

-n, --num-chars

Sur les gros fichiers CSV, la détection de dialecte peut parfois être un peu lente en raison du grand nombre de dialectes possibles à considérer. Pour atténuer cela, vous pouvez limiter le nombre de caractères à utiliser pour la détection.

Un aspect à garder à l'esprit est que CleverCSV peut avoir besoin de lire un certain nombre de caractères pour pouvoir inférer correctement le dialecte. Par exemple, dans le fichier ``imdb.csv`` du dépôt GitHub, le dialecte correct ne peut être trouvé qu'après la lecture d'au moins 66 lignes du fichier. Par conséquent, s'il est possible d'exécuter CleverCSV sur l'ensemble du fichier, cela est généralement recommandé.

-p, --pandas

Par défaut, cette commande écrit un petit script Python pour importer le fichier CSV sous forme de liste de listes. En activant cette option, le script sera écrit de manière à ce que le fichier soit lu comme un DataFrame Pandas à la place.

<chemin>

Chemin d'accès au fichier CSV
