Documentation de la fonction/sous-programme

sous-programme clacn2 (integer n, complex, dimension( * ) v, complex, dimension( * ) x, real est, integer kase, integer, dimension( 3 ) isave)

CLACN2 estime la norme 1 d'une matrice carrée complexe, en utilisant la communication inverse pour évaluer les produits matrice-vecteur.

Objectif :

!>
!> CLACN2 estime la norme 1 d'une matrice carrée complexe A.
!> La communication inverse est utilisée pour évaluer les produits matrice-vecteur.
!>

Paramètres

N 
!>          N est un ENTIER
!>         L'ordre de la matrice.  N >= 1.
!>

V

!>          V est un tableau COMPLEXE, de dimension (N)
!>         Lors du retour final, V = A*W,  où  EST = norm(V)/norm(W)
!>         (W n'est pas retourné).
!>

X

!>          X est un tableau COMPLEXE, de dimension (N)
!>         Lors d'un retour intermédiaire, X doit être écrasé par
!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         où A**H est la transposée conjuguée de A, et CLACN2 doit être
!>         rappelé avec tous les autres paramètres inchangés.
!>

EST

!>          EST est un REEL
!>         À l'entrée avec KASE = 1 ou 2 et ISAVE(1) = 3, EST doit être
!>         inchangé par rapport à l'appel précédent de CLACN2.
!>         À la sortie, EST est une estimation (une borne inférieure) de norm(A).
!>

KASE

!>          KASE est un ENTIER
!>         Lors de l'appel initial à CLACN2, KASE doit être 0.
!>         Lors d'un retour intermédiaire, KASE sera 1 ou 2, indiquant
!>         si X doit être écrasé par A * X  ou A**H * X.
!>         Lors du retour final de CLACN2, KASE sera à nouveau 0.
!>

ISAVE

!>          ISAVE est un tableau ENTIER, de dimension (3)
!>         ISAVE est utilisé pour sauvegarder des variables entre les appels à SLACN2
!>
