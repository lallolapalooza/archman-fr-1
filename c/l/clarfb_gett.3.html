sous-programme clarfb_gett (caractere ident, entier m, entier n, entier k, complexe, dimension( ldt, * ) t, entier ldt, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldb, * ) b, entier ldb, complexe, dimension( ldwork, * ) work, entier ldwork)

CLARFB_GETT

But:

!>
!> CLARFB_GETT applique un bloc de réflecteurs de Householder complexe H
!> à gauche sur une matrice complexe (K+M)-par-N composée de deux matrices
!> blocs: une matrice trapézoïdale supérieure K-par-N stockée dans le
!> tableau A, et une matrice rectangulaire M-par-(N-K), stockée dans le
!> tableau B. Le bloc réflecteur H est stocké dans une représentation
!> compacte de type WY, où les réflecteurs élémentaires sont dans les
!> tableaux A, B et T. Voir la section Détails supplémentaires.
!>

Paramètres

IDENT 
!>          IDENT est CARACTERE*1
!>          Si IDENT = non 'I', ou non 'i', alors V1 est une matrice
!>             unit-triangulaire inférieure et stockée dans le bloc
!>             gauche K-par-K de la matrice d'entrée A,
!>          Si IDENT = 'I' ou 'i', alors V1 est une matrice identité et
!>             non stockée.
!>          Voir la section Détails supplémentaires.
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice B.
!>          M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes des matrices A et B.
!>          N >= 0.
!>

K

!>          K est ENTIER
!>          Le nombre de lignes de la matrice A.
!>          K est aussi l'ordre de la matrice T, c'est-à-dire le nombre
!>          de réflecteurs élémentaires dont le produit définit le bloc
!>          réflecteur. 0 <= K <= N.
!>

T

!>          T est un tableau COMPLExe, dimension (LDT,K)
!>          La matrice triangulaire supérieure K-par-K T dans la
!>          représentation du bloc réflecteur.
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale du tableau T. LDT >= K.
!>

A

!>          A est un tableau COMPLExe, dimension (LDA,N)
!>
!>          À l'entrée:
!>           a) Dans la partie trapézoïdale supérieure K-par-N A: la
!>              matrice d'entrée A.
!>           b) Dans les colonnes sous la diagonale: les colonnes de V1
!>              (les uns ne sont pas stockés sur la diagonale).
!>
!>          À la sortie:
!>            A est écrasé par le produit rectangulaire K-par-N H*A.
!>
!>          Voir la section Détails supplémentaires.
!>

LDA

!>          LDB est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

B

!>          B est un tableau COMPLExe, dimension (LDB,N)
!>
!>          À l'entrée:
!>            a) Dans le bloc droit M-par-(N-K): la matrice d'entrée B.
!>            b) Dans le bloc gauche M-par-N: les colonnes de V2.
!>
!>          À la sortie:
!>            B est écrasé par le produit rectangulaire M-par-N H*B.
!>
!>          Voir la section Détails supplémentaires.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLExe,
!>          dimension (LDWORK,max(K,N-K))
!>

LDWORK

!>          LDWORK est ENTIER
!>          La dimension principale du tableau WORK. LDWORK>=max(1,K).
!>

Détails supplémentaires:

!>
!>    (1) Description de l'opération algébrique.
!>
!>    La matrice A est une matrice K-par-N composée de deux matrices
!>    colonnes blocs, A1, qui est K-par-K, et A2, qui est K-par-(N-K):
!>    A = ( A1, A2 ).
!>    La matrice B est une matrice M-par-N composée de deux matrices
!>    colonnes blocs, B1, qui est M-par-K, et B2, qui est M-par-(N-K):
!>    B = ( B1, B2 ).
!>
!>    Effectue l'opération:
!>
!>       ( A_out ) := H * ( A_in ) = ( I - V * T * V**H ) * ( A_in ) =
!>       ( B_out )        ( B_in )                          ( B_in )
!>                  = ( I - ( V1 ) * T * ( V1**H, V2**H ) ) * ( A_in )
!>                          ( V2 )                            ( B_in )
!>     À l'entrée:
!>
!>    a) ( A_in )  est composé de deux blocs colonnes:
!>       ( B_in )
!>
!>       ( A_in ) = (( A1_in ) ( A2_in )) = (( A1_in ) ( A2_in ))
!>       ( B_in )   (( B1_in ) ( B2_in ))   ((     0 ) ( B2_in )),
!>
!>       où les blocs colonnes sont:
!>
!>       (  A1_in )  est une matrice trapézoïdale supérieure K-par-K stockée
!>                   dans la partie triangulaire supérieure du tableau
!>                   A(1:K,1:K).
!>       (  B1_in )  est une matrice ZERO rectangulaire M-par-K et non
!>                   stockée.
!>
!>       ( A2_in )  est une matrice rectangulaire K-par-(N-K) stockée
!>                  dans le tableau A(1:K,K+1:N).
!>       ( B2_in )  est une matrice rectangulaire M-par-(N-K) stockée
!>                  dans le tableau B(1:M,K+1:N).
!>
!>    b) V = ( V1 )
!>           ( V2 )
!>
!>       où:
!>       1) si IDENT == 'I', V1 est une matrice identité K-par-K, non
!>          stockée;
!>       2) si IDENT != 'I', V1 est une matrice unit-triangulaire
!>          inférieure K-par-K, stockée dans la partie triangulaire
!>          inférieure du tableau A(1:K,1:K) (les uns ne sont pas
!>          stockés),
!>       et V2 est une matrice rectangulaire M-par-K stockée dans le
!>       tableau B(1:M,1:K), (car à l'entrée B1_in est une matrice
!>       zéro rectangulaire qui n'est pas stockée et l'espace est utilisé
!>       pour stocker V2).
!>
!>    c) T est une matrice triangulaire supérieure K-par-K stockée
!>       dans le tableau T(1:K,1:K).
!>
!>    À la sortie:
!>
!>    a) ( A_out ) est composé de deux blocs colonnes:
!>       ( B_out )
!>
!>       ( A_out ) = (( A1_out ) ( A2_out ))
!>       ( B_out )   (( B1_out ) ( B2_out )),
!>
!>       où les blocs colonnes sont:
!>
!>       ( A1_out )  est une matrice carrée K-par-K, ou une matrice
!>                   triangulaire supérieure K-par-K, si V1 est une
!>                   matrice identité. AiOut est stockée dans le
!>                   tableau A(1:K,1:K).
!>       ( B1_out )  est une matrice rectangulaire M-par-K stockée
!>                   dans le tableau B(1:M,K:N).
!>
!>       ( A2_out )  est une matrice rectangulaire K-par-(N-K) stockée
!>                   dans le tableau A(1:K,K+1:N).
!>       ( B2_out )  est une matrice rectangulaire M-par-(N-K) stockée
!>                   dans le tableau B(1:M,K+1:N).
!>
!>
!>    L'opération ci-dessus peut être représentée comme la même opération
!>    sur chaque bloc colonne:
!>
!>       ( A1_out ) := H * ( A1_in ) = ( I - V * T * V**H ) * ( A1_in )
!>       ( B1_out )        (     0 )                          (     0 )
!>
!>       ( A2_out ) := H * ( A2_in ) = ( I - V * T * V**H ) * ( A2_in )
!>       ( B2_out )        ( B2_in )                          ( B2_in )
!>
!>    Si IDENT != 'I':
!>
!>       Le calcul pour le bloc colonne 1:
!>
!>       A1_out: = A1_in - V1*T*(V1**H)*A1_in
!>
!>       B1_out: = - V2*T*(V1**H)*A1_in
!>
!>       Le calcul pour le bloc colonne 2, qui existe si N > K:
!>
!>       A2_out: = A2_in - V1*T*( (V1**H)*A2_in + (V2**H)*B2_in )
!>
!>       B2_out: = B2_in - V2*T*( (V1**H)*A2_in + (V2**H)*B2_in )
!>
!>    Si IDENT == 'I':
!>
!>       L'opération pour le bloc colonne 1:
!>
!>       A1_out: = A1_in - V1*T*A1_in
!>
!>       B1_out: = - V2*T*A1_in
!>
!>       Le calcul pour le bloc colonne 2, qui existe si N > K:
!>
