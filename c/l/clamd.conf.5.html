NOM

clamd.conf - Fichier de configuration pour le démon Clam AntiVirus

DESCRIPTION

clamd.conf configure le démon Clam AntiVirus, clamd(8).

FORMAT DU FICHIER

Le fichier se compose de commentaires et d'options avec des arguments. Chaque ligne commençant par un symbole dièse (#) est ignorée par l'analyseur. Les options et les arguments sont sensibles à la casse et ont la forme Option Argument. Les arguments sont des types suivants :

BOOL
Valeur booléenne (oui/non ou vrai/faux ou 1/0).
CHAINE
Chaîne sans caractères blancs.
TAILLE
Taille en octets. Vous pouvez utiliser les modificateurs 'M' ou 'm' pour les mégaoctets et 'K' ou 'k' pour les kilo-octets. Pour spécifier la taille en octets, n'utilisez pas de modificateurs.
NOMBRE
Entier non signé.

DIRECTIVES

Lorsqu'une option n'est pas utilisée (commentée ou non incluse dans le fichier de configuration), clamd adopte une action par défaut.

Permettre à une correspondance heuristique d'avoir la priorité. Avertissement : désactiver cette limite ou la régler trop haut peut entraîner des dommages graves au système. OnAccessExcludeRootUID
BOOL
Avec cette option, vous pouvez exclure l'UID root (0). Les processus exécutés en tant que root pourront accéder à tous les fichiers sans déclencher d'analyses ni d'événements de permission refusée.
Notez que si clamd ne peut pas vérifier l'uid du processus qui a généré un événement d'analyse à l'accès (par exemple, parce que OnAccessPrevention n'a pas été activé et que le processus s'est déjà terminé), clamd effectuera une analyse. Ainsi, régler OnAccessExcludeRootUID n'est pas garanti pour empêcher chaque accès par l'utilisateur root de déclencher une analyse (sauf si OnAccessPrevention est activé).

no
