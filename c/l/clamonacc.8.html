NOM

clamonacc - démon de scan antivirus à l'accès et client clamd

SYNTAXE

clamonacc [options]

DESCRIPTION

Le démon clamonacc s'enregistre pour recevoir les notifications d'accès aux fichiers du noyau Linux et, en réponse, soumet les scans au démon de scan clamd pour un verdict. L'accès à la demande n'est disponible que sur les systèmes Linux. Sur Linux, l'accès à la demande nécessite une version du noyau >= 3.8. C'est parce qu'il utilise une API du noyau appelée fanotify pour empêcher les processus de tenter d'accéder à des fichiers malveillants. Cette prévention se produit dans l'espace noyau, et offre ainsi une protection plus forte qu'une solution purement en espace utilisateur.

OPTIONS

-h, --help
Affiche les informations d'aide et quitte.
-V, --version
Affiche le numéro de version et quitte.
-v, --verbose
Mode verbeux.
-l FICHIER, --log=FICHIER
Sauvegarde le rapport d'analyse dans FICHIER.
-F, --foreground
Exécuter en premier plan ; ne pas daemonizer.
-W FICHIER, --watch-list=FICHIER
Surveiller les répertoires du FICHIER.
-e FICHIER, --exclude-list=FICHIER
Exclure les répertoires du FICHIER.
-p A[:I], --ping A[:I]
Pinguer clamd jusqu'à [A] fois à un intervalle optionnel [I] jusqu'à ce qu'il réponde.
-w, --wait
Attendre jusqu'à 30 secondes que clamd démarre. Peut être utilisé avec ping pour définir les tentatives [A] et l'intervalle [I] pour vérifier clamd.
--remove
Supprimer les fichiers infectés. Soyez prudent.
--move=DIRECTORY
Déplacer les fichiers infectés dans le RÉPERTOIRE.
--copy=DIRECTORY
Copier les fichiers infectés dans le RÉPERTOIRE.
-c FICHIER, --config-file=FICHIER
Lire la configuration depuis FICHIER.
--allmatch
Continuer l'analyse dans le fichier après avoir trouvé une correspondance.
--fdpass
Transmettre les permissions du descripteur de fichier à clamd. Ceci est utile si clamd s'exécute en tant qu'utilisateur différent car c'est plus rapide que de streamer le fichier à clamd. Uniquement disponible si connecté à clamd via une socket locale (unix).
--stream
Force le streaming de fichiers vers clamd. Ce n'est généralement pas nécessaire car clamdscan détecte automatiquement si le streaming est requis. Cette option existe uniquement à des fins de débogage et de test ; dans tous les autres cas, --fdpass est préférable.

SIGNALS

ClamOnAcc reconnaît les signaux suivants :

SIGHUP
Rouvrir le fichier journal.
SIGUSR2
Recharger les bases de signatures.
SIGTERM
Effectuer une sortie propre.
