sous-routine clqt03 (integer m, integer n, integer k, complex, dimension( lda, * ) af, complex, dimension( lda, * ) c, complex, dimension( lda, * ) cc, complex, dimension( lda, * ) q, integer lda, complex, dimension( * ) tau, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

CLQT03

But :

!>
!> CLQT03 teste CUNMLQ, qui calcule Q*C, Q'*C, C*Q ou C*Q'.
!>
!> CLQT03 compare les résultats d'un appel à CUNMLQ avec les résultats
!> de la formation explicite de Q par un appel à CUNGLQ, puis de la multiplication
!> matricielle par un appel à CGEMM.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes ou de colonnes de la matrice C ; C est n-par-m si
!>          Q est appliquée par la gauche, ou m-par-n si Q est appliquée par la
!>          droite.  M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          L'ordre de la matrice orthogonale Q.  N >= 0.
!>

K

!>          K est un entier (INTEGER)
!>          Le nombre de réflexions élémentaires dont le produit définit la
!>          matrice orthogonale Q.  N >= K >= 0.
!>

AF

!>          AF est un tableau complexe (COMPLEX), de dimension (LDA,N)
!>          Détails de la factorisation LQ d'une matrice m-par-n, comme
!>          retourné par CGELQF. Voir CGELQF pour plus de détails.
!>

C

!>          C est un tableau complexe (COMPLEX), de dimension (LDA,N)
!>

CC

!>          CC est un tableau complexe (COMPLEX), de dimension (LDA,N)
!>

Q

!>          Q est un tableau complexe (COMPLEX), de dimension (LDA,N)
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale des tableaux AF, C, CC et Q.
!>

TAU

!>          TAU est un tableau complexe (COMPLEX), de dimension (min(M,N))
!>          Les facteurs scalaires des réflexions élémentaires correspondant
!>          à la factorisation LQ dans AF.
!>

WORK

!>          WORK est un tableau complexe (COMPLEX), de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La longueur de WORK.  LWORK doit être au moins M, et devrait être
!>          M*NB, où NB est la taille du bloc pour cet environnement.
!>

RWORK

!>          RWORK est un tableau réel (REAL), de dimension (M)
!>

RESULT

!>          RESULT est un tableau réel (REAL), de dimension (4)
!>          Les rapports de test comparent deux techniques pour multiplier une
!>          matrice aléatoire C par une matrice orthogonale Q de taille n-par-n.
!>          RESULT(1) = norm( Q*C - Q*C )  / ( N * norm(C) * EPS )
!>          RESULT(2) = norm( C*Q - C*Q )  / ( N * norm(C) * EPS )
!>          RESULT(3) = norm( Q'*C - Q'*C )/ ( N * norm(C) * EPS )
!>          RESULT(4) = norm( C*Q' - C*Q' )/ ( N * norm(C) * EPS )
!>
