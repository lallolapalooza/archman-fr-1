--heuristic-scan-precedence[=yes/no(*)]
Permet aux correspondances heuristiques de prendre la priorité. Lorsque activé, si une analyse heuristique (telle que phishingScan) détecte un virus/phishing potentiel, elle arrête l'analyse immédiatement. Recommandé, économise du temps CPU d'analyse. Lorsqu'il est désactivé, les virus/phishings détectés par des analyses heuristiques ne sont signalés qu'à la fin d'une analyse. Si une archive contient à la fois un virus/phishing détecté heuristiquement et un vrai malware, le vrai malware sera signalé. Laissez cette option désactivée si vous avez l'intention de traiter les virus "Heuristics.*" différemment des malwares "réels". Si un virus non détecté heuristiquement (basé sur signature) est trouvé en premier, l'analyse est interrompue immédiatement, quelle que soit cette option de configuration.

clamscan(1) — ClamAV 1.5.1

DESCRIPTION

clamscan is a simple virus scanner that can be used to scan files, directories and mail spools for the presence of viruses.

clamscan is part of the ClamAV suite.

Please see the clamscan man page for more information.

--hash-hint
The file hash so that libclamav does not need to calculate it. The type of hash must match the '--hash-alg'.
--log-hash
Print the file hash after each file scanned. The type of hash printed will match the '--hash-alg'.

ENVIRONMENT VARIABLES

clamscan uses the following environment variables:

CVD_CERTS_DIR
Specify a directory containing the root CA cert needed to verify detached CVD digital signatures. If not provided, then clamscan will look in the default directory.
LD_LIBRARY_PATH
May be used on startup to find the libclamunrar_iface shared library module to enable RAR archive support.

EXAMPLES

(0) Scan a single file:

clamscan file

(1) Scan a current working directory:

clamscan

(2) Scan all files (and subdirectories) in /home:

clamscan -r /home

(3) Load database from a file:

clamscan -d /tmp/newclamdb -r /tmp

(4) Scan a data stream:

cat testfile | clamscan -

(5) Scan a mail spool directory:

clamscan -r /var/spool/mail

RETURN CODES

0 : No virus found.

1 : Virus(es) found.
2 : Some error(s) occurred.
