subroutine clarf (side, m, n, v, incv, tau, c, ldc, work)
CLARF applique un réflecteur élémentaire à une matrice rectangulaire générale.

Documentation de la fonction/sous-programme

sous-programme clarf (caractère side, entier m, entier n, complexe, dimension( * ) v, entier incv, complexe tau, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( * ) work)

CLARF applique un réflecteur élémentaire complexe H à une matrice complexe M par N C, soit par la gauche, soit par la droite. H est représenté sous la forme

H = I - tau * v * v**H

où tau est un scalaire complexe et v est un vecteur complexe.

Si tau = 0, alors H est considérée comme la matrice identité.

Pour appliquer H**H (la transposée conjuguée de H), fournissez conjg(tau) à la place de tau.

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': forme  H * C
!>          = 'R': forme  C * H

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.

V

!>          V est un tableau COMPLEX, dimension
!>                     (1 + (M-1)*abs(INCV)) si SIDE = 'L'
!>                  ou (1 + (N-1)*abs(INCV)) si SIDE = 'R'
!>          Le vecteur v dans la représentation de H. V n'est pas utilisé si
!>          TAU = 0.

INCV

!>          INCV est INTEGER
!>          L'incrément entre les éléments de v. INCV <> 0.

TAU

!>          TAU est COMPLEX
!>          La valeur tau dans la représentation de H.

C

!>          C est un tableau COMPLEX, dimension (LDC,N)
!>          À l'entrée, la matrice C de taille M par N.
!>          À la sortie, C est écrasée par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).

WORK

!>          WORK est un tableau COMPLEX, dimension
!>                         (N) si SIDE = 'L'
!>                      ou (M) si SIDE = 'R'
