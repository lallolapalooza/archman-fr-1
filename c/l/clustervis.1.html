CLUSTERVIS(1) Manuel des commandes générales CLUSTERVIS(1)

NOM

clustervis - visualisation des performances CPU et réseau sur un cluster

SYNTAXE

clustervis [-H fichier_nœuds] [-h hôte[,hôte...]] [-a archive[,archive...]] [-m max] [options pmview]

DESCRIPTION

clustervis affiche des graphiques en barres tridimensionnels de l'utilisation du CPU et du trafic réseau pour un ou plusieurs hôtes d'un cluster. Un outil alternatif de surveillance des performances de cluster en deux dimensions est pmgcluster(1). clustervis est conçu pour fournir un aperçu évolutif des performances de grands clusters. D'autres outils tels que pmchart(1) et pmgsys(1) fournissent des détails détaillés sur une base par hôte. Ces outils peuvent être lancés en cliquant sur le plan de base violet d'un hôte particulier, puis en sélectionnant un outil dans le menu lancer de clustervis.

Les arguments -H, -h et -a sont mutuellement exclusifs et ont les sémantiques suivantes ; si aucun des arguments -H, -h ou -a n'est donné, et soit le fichier /etc/nodes ou /etc/ace/nodes existe, soit la variable d'environnement $PCP_CLUSTER_CONFIG est définie, alors utiliser le fichier nommé comme ensemble d'hôtes pour la surveillance en direct. Si le fichier de nœuds par défaut n'existe pas, la variable d'environnement n'est pas définie et aucun des trois drapeaux n'a été donné, une erreur est signalée. Sinon, si -H est donné, alors l'ensemble d'hôtes est donné dans fichier_nœuds.

L'indicateur -h spécifie un ou plusieurs hôtes (séparés par des virgules sans espaces) pour la surveillance en direct et l'indicateur -a spécifie une ou plusieurs archives pour la lecture d'archives (séparées par des virgules).

La hauteur de la pile CPU est proportionnelle à l'utilisation du CPU dans chacun des modes sys (rouge, en cours d'exécution dans le noyau) et user (bleu, en cours d'exécution de code utilisateur). La pile de trafic réseau est affichée pour chaque interface réseau comme le taux de paquets in (bleu clair), out (orange) et errors (rouge). La hauteur de la pile réseau est modulée par l'argument -m, avec une valeur par défaut de 750 paquets/seconde représentant un trafic réseau saturé.

clustervis génère un fichier de configuration pmview(1) et transmet la plupart des options de ligne de commande à pmview(1). Par conséquent, les options de ligne de commande -A, -a, -C, -h, -n, -O, -p, -S, -t, -T, -Z et -z, ainsi que l'interface utilisateur, sont décrites dans la page de manuel de pmview(1).

FICHIERS

$PCP_VAR_DIR/config/pmlogger/config.clustervis
Un fichier de configuration pmlogger(1) pour les métriques clustervis.
/usr/pcp/lib/pmview-args
Procédures shell pour l'analyse des options de ligne de commande de pmview(1).
/etc/nodes
Ensemble par défaut des hôtes dans le cluster.

ENVIRONNEMENT PCP

La variable d'environnement PCP_CLUSTER_CONFIG peut être utilisée pour spécifier le fichier de nœuds par défaut au lieu d'utiliser le drapeau -H. Chaque ligne du fichier est un nom d'hôte (ou un commentaire commençant par #). D'autres variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(4).
