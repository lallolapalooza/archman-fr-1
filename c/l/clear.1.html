clear(1) Commandes utilisateur clear(1)

NOM

clear - effacer l'écran du terminal

SYNTAXE

clear [-x] [-T type-de-terminal]

clear -V

DESCRIPTION

clear efface l'écran de votre terminal et son tampon de défilement, le cas échéant. clear récupère le type de terminal à partir de la variable d'environnement TERM, puis consulte l'entrée de la base de données des capacités de terminaux terminfo pour ce type afin de déterminer comment effectuer ces actions.

Les capacités pour effacer l'écran et le tampon de défilement sont nommées « clear » et « E3 », respectivement. Cette dernière est une capacité définie par l'utilisateur, appliquant un mécanisme d'extension introduit dans ncurses 5.0 (1999).

OPTIONS

clear reconnaît les options suivantes.

-T type
produit des instructions adaptées au terminal de type spécifié. Normalement, cette option est inutile, car le type de terminal est déduit de la variable d'environnement TERM. Si cette option est spécifiée, clear ignore également les variables d'environnement LINES et COLUMNS.
-V
rapporte la version de ncurses associée à ce programme et se termine avec un statut de succès.
-x
empêche clear de tenter d'effacer le tampon de défilement.

PORTABILITÉ

Ni IEEE Std 1003.1/The Open Group Base Specifications Issue 7 (POSIX.1-2008) ni X/Open Curses Issue 7 ne documentent clear.

Ce dernier documente tput, qui pourrait être utilisé pour remplacer cet utilitaire soit via un script shell, soit par un alias (tel qu'un lien symbolique) pour exécuter tput sous le nom clear.

HISTORIQUE

Une commande clear utilisant la base de données et la bibliothèque termcap est apparue dans 2BSD (1979). Eighth Edition Unix (1985) l'a incluse plus tard.

La branche commerciale Unix d'AT&T a adapté un programme BSD différent (tset) pour créer une nouvelle commande, tput, et a remplacé le programme clear par un script shell qui appelait « tput clear ».

/usr/bin/tput ${1:+-T$1} clear 2> /dev/null
exit

En 1989, lorsque Keith Bostic a révisé la commande BSD tput pour la rendre similaire à celle d'AT&T, il a également ajouté un script shell clear.

exec tput clear

Le reste du script dans chaque cas est un avis de droit d'auteur.

En 1995, le clear de ncurses a commencé par adapter la commande originale clear de BSD pour utiliser terminfo. L'extension E3 est venue plus tard.

•
En juin 1999, xterm a fourni une extension à la séquence de contrôle standard pour effacer l'écran. Au lieu d'effacer seulement la partie visible de l'écran en utilisant
printf '\033[2J'
on pouvait également effacer le tampon de défilement en utilisant
printf '\033[3J'
à la place. « XTerm Control Sequences » documente cette fonctionnalité comme provenant d'xterm.
  • Quelques autres émulateurs de terminaux l'ont adoptée, comme PuTTY en 2006.
  • En avril 2011, un développeur de Red Hat a soumis un correctif au noyau Linux, modifiant son pilote de console pour faire de même. La documentation de ce changement, apparaissant dans Linux 3.0, ne mentionnait pas xterm, bien que ce dernier ait été cité dans le rapport de bug Red Hat (#683733) motivant la fonctionnalité.
  • Par la suite, d'autres développeurs de terminaux ont adopté cette fonctionnalité. La prochaine étape pertinente a été de modifier le programme clear de ncurses en 2013 pour intégrer cette extension.
  • En 2013, la capacité E3 n'était pas utilisée par « tput clear ». Cet oubli a été corrigé en 2016 en réorganisant tput pour partager sa logique avec clear et tset.
