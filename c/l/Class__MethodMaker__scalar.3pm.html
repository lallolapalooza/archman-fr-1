Class::MethodMaker::scalar(3) Documentation Perl fournie par l'utilisateur Class::MethodMaker::scalar(3)

NOM

Class::Method::scalar - Crée des méthodes pour gérer une valeur scalaire.

SYNTAXE

package MyClass;
use Class::MethodMaker
  [ scalar => [qw/ a -static s /]];
sub new {
  my $class = shift;
  bless {}, $class;
}
package main;
my $m = MyClass->new;
my $a, $x;
$a = $m->a;       # *undef*
$x = $m->a_isset; # false
$a = $m->a(1);    # 1
$m->a(3);
$x = $m->a_isset; # true
$a = $m->a;       # 3
$a = $m->a(5);     # 5;
$m->a_reset;
$x = $m->a_isset; # false

DESCRIPTION

Crée des méthodes pour gérer des valeurs tableaux dans un objet. Pour un composant nommé "x", crée par défaut les méthodes "x", "x_reset", "x_isset", "x_clear".

Méthodes disponibles :

"*"

$m->a(3);
$a = $m->a;       # 3
$a = $m->a(5);     # 5;

Créée par défaut. Si un argument est fourni, le composant est défini à cette valeur. La méthode retourne la valeur du composant (après affectation à une valeur fournie, si approprié).

*_reset

$m->a_reset;

Créée par défaut. Réinitialise le composant à sa valeur par défaut. Normalement, cela signifie que *_isset retournera faux, et "*" retournera undef. Si "-default" est en vigueur, alors le composant sera défini à la valeur par défaut, et *_isset retournera vrai. Si "-default_ctor" est en vigueur, alors la procédure par défaut sera appelée, et sa valeur de retour sera utilisée pour définir la valeur du composant, et *_isset retournera vrai.

Note avancée : en fait, les valeurs par défaut sont attribuées si nécessaire : typiquement, la prochaine fois que la valeur d'un composant est lue.

*_isset

print $m->a_isset ? "true" : "false";

Créée par défaut. Si le composant est actuellement défini. Ceci est différent d'être défini ; initialement, le composant n'est pas défini (et s'il est lu, il retournera undef) ; il peut être défini à undef (qui est une valeur définie, qui retourne également undef). Après avoir été défini, le seul moyen de dé-définir le composant est avec <*_reset>.

Si une valeur par défaut est en vigueur, alors <*_isset> retournera toujours vrai.

*_clear

$m->a(5);
$a = $m->a;       # 5
$x = $m->a_isset; # true
$m->a_clear;
$a = $m->a;       # *undef*
$x = $m->a_isset; # true

Créée par défaut. Un raccourci pour définir à undef. Notez que le composant sera défini à undef, pas réinitialisé, donc *_isset retournera vrai.

*_get

package MyClass;
use Class::MethodMaker
  [ scalar => [{'*_get' => '*_get'}, 'a'],
    new    => new, ];
package main;
my $m = MyClass->new;
$m->a(3);
$a = $m->a_get;     # 3
$a = $m->a_get(5);  # 3; ignore l'argument
$a = $m->a_get(5);  # 3; inchangé par l'appel précédent

Créée sur demande. Récupère la valeur du composant sans la définir (ignore tous les arguments passés).

*_set

package MyClass;
use Class::MethodMaker
  [ scalar => [{'*_set' => '*_set'}, 'a'],
    new    => new, ];
package main;
my $m = MyClass->new;
$m->a(3);
$a = $m->a_set;     # *undef*
$a = $m->a_set(5);  # *undef*; la valeur est définie mais pas retournée
$a = $m->a;         # 5

Créée sur demande. Définit le composant au premier argument (ou undef si aucun argument n'est fourni). Ne retourne aucune valeur.
