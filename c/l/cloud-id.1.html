CLOUD-ID(1) Manuel des commandes générales CLOUD-ID(1)

NOM

cloud-id - Rapporte l'identifiant cloud canonique pour cette instance

SYNTAXE

cloud-id [-h] [-j] [-l] [-i <DONNÉES_INSTANCE>]

DESCRIPTION

cloud-id est le nom en minuscules de la source de données cloud découverte.

L'identifiant cloud sera 'not run' lorsque le générateur systemd n'a pas encore été exécuté. L'identifiant cloud sera 'disabled' lorsque cloud-init est désactivé ou lorsque ds-identify n'a pas trouvé de source de données valide.

Voir cloud-init status --long pour plus d'informations.

OPTIONS

-h, --help
Affiche le message d'aide et quitte
-j, --json
Rapporte toutes les informations standardisées cloud-id au format json
-l, --long
Rapporte des informations étendues sur cloud-id sous forme de chaîne délimitée par des tabulations
-i <données>, --instance-data <données>
Chemin vers le fichier instance-data.json. Par défaut, c'est /run/cloud-init/instance-data.json

STATUT DE SORTIE

0
En cas de succès
1
En cas d'erreur
2
En raison d'un état désactivé de cloud-init. Voir : cloud-init status --long
3
Le générateur et la découverte de cloud-init n'ont pas encore été exécutés.
