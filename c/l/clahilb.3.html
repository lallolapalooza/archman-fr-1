sous-routine clahilb (integer n, integer nrhs, complex, dimension(lda,n) a, integer lda, complex, dimension(ldx, nrhs) x, integer ldx, complex, dimension(ldb, nrhs) b, integer ldb, real, dimension(n) work, integer info, character*3 path)

CLAHILB

Objectif:

!>
!> CLAHILB génère une matrice de Hilbert N x N mise à l'échelle dans A, ainsi que
!> NRHS membres de droite dans B et des solutions dans X tels que A*X=B.
!>
!> La matrice de Hilbert est mise à l'échelle par M = PPCM(1, 2, ..., 2*N-1) de sorte que toutes
!> les entrées soient des entiers. Les membres de droite sont les NRHS premières
!> colonnes de la matrice identité multipliée par M, et les solutions sont les
!> premières NRHS colonnes de la matrice de Hilbert inverse.
!>
!> Le conditionnement de la matrice de Hilbert croît exponentiellement avec
!> sa taille, approximativement O(e ** (3.5*N)). De plus, les matrices de Hilbert inverses
!> au-delà d'une dimension relativement petite ne peuvent pas être
!> générées exactement sans précision supplémentaire. La précision est épuisée
!> lorsque la plus grande entrée de la matrice de Hilbert inverse est supérieure à
!> 2 puissance du nombre de bits dans la fraction du type de données
!> utilisé plus un, soit 24 pour la simple précision.
!>
!> En simple précision, la solution générée est exacte pour N <= 6 et présente
!> une petite erreur composante pour 7 <= N <= 11.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          La dimension de la matrice A.
!>

NRHS

!>          NRHS est un entier (INTEGER)
!>          Le nombre demandé de membres de droite.
!>

A

!>          A est un tableau de nombres complexes (COMPLEX), dimension (LDA, N)
!>          La matrice de Hilbert mise à l'échelle générée.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= N.
!>

X

!>          X est un tableau de nombres complexes (COMPLEX), dimension (LDX, NRHS)
!>          Les solutions exactes générées. Actuellement, les NRHS premières
!>          colonnes de la matrice de Hilbert inverse.
!>

LDX

!>          LDX est un entier (INTEGER)
!>          La dimension principale du tableau X. LDX >= N.
!>

B

!>          B est un tableau de nombres réels (REAL), dimension (LDB, NRHS)
!>          Les membres de droite générés. Actuellement, les NRHS premières
!>          colonnes de PPCM(1, 2, ..., 2*N-1) multipliées par la matrice identité.
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale du tableau B. LDB >= N.
!>

WORK

!>          WORK est un tableau de nombres réels (REAL), dimension (N)
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0: sortie réussie
!>          = 1: N est trop grand ; les données sont toujours générées mais peuvent ne pas
!>               être exactes.
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>

PATH

!>          PATH est une chaîne de caractères de longueur 3 (CHARACTER*3)
!>          Le nom du chemin LAPACK.
!>
