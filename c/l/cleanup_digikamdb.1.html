NOM

cleanup_digikamdb - Nettoie les bases de données digiKam pour réduire leur taille et augmenter leur vitesse d'accès

SYNTAXE


cleanup_digikamdb
[-t] [-T] [-p] [-h]

OPTIONS

-t
Inclure les bases de données de miniatures.
-T
Nettoyer uniquement les bases de données de miniatures.
-p chemin
Spécifier un chemin de base de données différent. Si cette option n'est pas définie ou si le chemin spécifié est invalide, l'entrée du fichier de configuration sera utilisée.
-h
Afficher les options de la ligne de commande.

DESCRIPTION

cleanup_digikamdb nettoie et optimise le fichier de base de données digiKam. Cela conduira, dans la plupart des cas, à une taille de fichier de base de données plus petite et à une vitesse d'accès accrue, car les éléments inutiles sont supprimés de la base de données et les données sont optimisées.

Le programme s'assurera qu'aucune instance de digiKam n'est en cours d'exécution, car il est plus sûr de ne pas avoir d'accès à la base de données pendant le processus d'optimisation. Il lira ensuite le fichier de configuration de digiKam et déterminera l'emplacement de la base de données. Dans une étape finale, la base de données sera optimisée en invoquant la commande sqlite 'VACUUM;' dessus. Si plus d'une base de données est trouvée à cet emplacement, cleanup_digikamdb optimisera chaque base de données trouvée dans ce chemin et en dessous.

Pour plus d'explications, consultez la description suivante de la commande VACUUM du site web sqlite3 :

Lorsqu'un objet (table, index ou trigger) est supprimé de la base de données, il laisse de l'espace vide. Cet espace vide sera réutilisé la prochaine fois que de nouvelles informations seront ajoutées à la base de données. Mais en attendant, le fichier de base de données peut être plus grand que strictement nécessaire. De plus, les insertions, mises à jour et suppressions fréquentes peuvent entraîner la fragmentation des informations dans la base de données - dispersées dans tout le fichier de base de données plutôt que regroupées en un seul endroit.

La commande VACUUM nettoie la base de données principale en copiant son contenu dans un fichier de base de données temporaire et en rechargeant le fichier de base de données d'origine à partir de la copie. Cela élimine les pages vides, aligne les données des tables pour qu'elles soient contiguës, et nettoie la structure du fichier de base de données.
