NOM

Class::Inspector - Obtenir des informations sur une classe et sa structure

VERSION

version 1.36

RÉSUMÉ

use Class::Inspector;

# Une classe est-elle installée et/ou chargée
Class::Inspector->installed( 'Foo::Class' );
Class::Inspector->loaded( 'Foo::Class' );

# Informations relatives au nom de fichier
Class::Inspector->filename( 'Foo::Class' );
Class::Inspector->resolved_filename( 'Foo::Class' );

# Obtenir des informations relatives aux sous-routines
Class::Inspector->functions( 'Foo::Class' );
Class::Inspector->function_refs( 'Foo::Class' );
Class::Inspector->function_exists( 'Foo::Class', 'bar' );
Class::Inspector->methods( 'Foo::Class', 'full', 'public' );

# Trouver toutes les sous-classes chargées ou autre
Class::Inspector->subclasses( 'Foo::Class' );

DESCRIPTION

Class::Inspector vous permet d'obtenir des informations sur une classe chargée. La plupart, voire la totalité, de ces informations peuvent être trouvées d'autres manières, mais celles-ci ne sont pas toujours très conviviales et impliquent généralement un niveau relativement élevé de magie Perl, ou du code d'apparence étrange et inhabituelle. Class::Inspector tente de fournir une interface plus simple et plus conviviale pour accéder à ces informations.

MÉTHODES

installed

my $bool = Class::Inspector->installed($class);

La "installed" méthode statique essaie de déterminer si une classe est installée sur la machine, ou au moins disponible pour Perl. Elle le fait en enveloppant "resolved_filename".

Renvoie vrai si elle est installée/disponible, faux si la classe n'est pas installée, ou "undef" si le nom de la classe est invalide.

loaded

my $bool = Class::Inspector->loaded($class);

La "loaded" méthode statique essaie de déterminer si une classe est chargée en cherchant des entrées dans la table des symboles.

La méthode qu'elle utilise pour déterminer cela fonctionnera même si la classe n'a pas son propre fichier, mais est contenue dans un seul fichier avec plusieurs classes. Même dans le cas où un type de chargement à l'exécution est utilisé, ceux-ci laissent généralement une trace dans la table des symboles, de sorte qu'une classe basée sur Autoload ou Class::Autouse devrait apparaître correctement comme chargée.

Renvoie vrai si la classe est chargée, faux sinon, ou "undef" si le nom de la classe est invalide.

filename

my $filename = Class::Inspector->filename($class);

Pour une classe donnée, renvoie le nom de fichier de base de la classe. Ceci ne sera PAS un nom de fichier entièrement résolu, seulement la partie du nom de fichier SITUÉE SOUS l'entrée @INC .

print Class->filename( 'Foo::Bar' );
> Foo/Bar.pm

Ce nom de fichier sera renvoyé avec le séparateur approprié pour la plateforme locale, et devrait fonctionner sur toutes les plateformes.

Renvoie le nom de fichier en cas de succès ou "undef" si le nom de la classe est invalide.

resolved_filename

my $filename = Class::Inspector->resolved_filename($class);
my $filename = Class::Inspector->resolved_filename($class, @try_first);

Pour une classe donnée, la "resolved_filename" méthode statique renvoie le nom de fichier entièrement résolu pour une classe. C'est-à-dire, le fichier à partir duquel la classe serait chargée.

Ceci n'est pas nécessairement le fichier à partir duquel la classe A ÉTÉ chargée, car la valeur renvoyée est déterminée à chaque fois qu'elle s'exécute, et le @INC chemin d'inclusion peut changer.

Pour obtenir le fichier réel d'une classe chargée, voir la "loaded_filename" méthode.

Renvoie le nom de fichier pour la classe, ou "undef" si le nom de la classe est invalide.

loaded_filename

my $filename = Class::Inspector->loaded_filename($class);

Pour une classe chargée donnée, la "loaded_filename" méthode statique détermine (via le %INC hachage) le nom du fichier à partir duquel elle a été initialement chargée.

Renvoie un chemin de fichier résolu, ou faux si la classe n'avait pas son propre fichier.

functions

my $arrayref = Class::Inspector->functions($class);

Pour une classe chargée, la "functions" méthode statique renvoie une liste des noms de toutes les fonctions dans l'espace de noms immédiat des classes.

Notez que ce ne sont pas les MÉTHODES de la classe, seulement les fonctions.

Renvoie une référence à un tableau des noms de fonctions en cas de succès, ou "undef" si le nom de la classe est invalide ou si la classe n'est pas chargée.

function_refs

my $arrayref = Class::Inspector->function_refs($class);

Pour une classe chargée, la "function_refs" méthode statique renvoie des références à toutes les fonctions dans l'espace de noms immédiat des classes.

Notez que ce ne sont pas les MÉTHODES de la classe, seulement les fonctions.

Renvoie une référence à un tableau de "CODE" références des fonctions en cas de succès, ou "undef" si la classe n'est pas chargée.

function_exists

my $bool = Class::Inspector->function_exists($class, $functon);

Étant donné un nom de classe et de fonction, la "function_exists" méthode statique vérifiera si la fonction existe dans la classe.

Notez que c'est en tant que fonction, et non en tant que méthode. Pour voir si une méthode existe pour une classe, utilisez la "can" méthode de n'importe quelle classe ou objet.

Renvoie vrai si la fonction existe, faux sinon, ou "undef" si le nom de la classe ou de la fonction est invalide, ou si la classe n'est pas chargée.

methods

my $arrayref = Class::Inspector->methods($class, @options);

Pour un nom de classe donné, la "methods" méthode statique renverra TOUTES les méthodes disponibles pour cette classe. Cela inclut toutes les méthodes disponibles de chaque classe dans l'arbre @ISA de la classe.

Renvoie une référence à un tableau des noms de toutes les méthodes disponibles en cas de succès, ou "undef" si le nom de la classe est invalide ou si la classe n'est pas chargée.

Un certain nombre d'options sont disponibles pour la "methods" méthode qui modifieront les résultats renvoyés. Elles doivent être listées après le nom de la classe, dans n'importe quel ordre.

# Obtenir uniquement les méthodes publiques
my $method = Class::Inspector->methods( 'My::Class', 'public' );
public
L'option "public" renverra uniquement les méthodes 'publiques', telles que définies par la convention Perl de préfixer d'un soulignement les méthodes 'privées'. L'option "public" supprimera effectivement toutes les méthodes qui commencent par un soulignement.
private
L'option "private" renverra uniquement les méthodes 'privées', telles que définies par la convention Perl de préfixer d'un soulignement les méthodes privées. L'option "private" supprimera effectivement les méthodes qui ne commencent pas par un soulignement.

Note : Les options "public" et "private" sont mutuellement exclusives

full
"methods" renvoie normalement seulement le nom de la méthode. En fournissant le « full » option fera retourner les méthodes sous forme de noms complets. C'est-à-dire qu'au lieu de retourner "[ 'method1', 'method2', 'method3' ]", vous obtiendrez plutôt "[ 'Class::method1', 'AnotherClass::method2', 'Class::method3' ]".
expanded
L' « expanded » option fera retourner beaucoup plus d'informations sur les méthodes. Au lieu de simplement le nom de la méthode, vous obtiendrez une référence de tableau contenant le nom de la méthode sous forme de nom combiné unique, à la manière de « full », la classe et la méthode séparément, et une référence CODE vers la fonction réelle (si disponible). Veuillez noter que la référence de la fonction n'est pas garantie d'être disponible. "Class::Inspector" est destiné, à un moment ultérieur, à fonctionner avec des modules qui ont un certain type de chargeur d'exécution commun en place (par ex. « Autoloader » ou "Class::Autouse" par exemple.

La réponse de "methods( 'Class', 'expanded' )" ressemblerait à quelque chose comme ceci.

[
  [ 'Class::method1',   'Class',   'method1', \&Class::method1   ],
  [ 'Another::method2', 'Another', 'method2', \&Another::method2 ],
  [ 'Foo::bar',         'Foo',     'bar',     \&Foo::bar         ],
]

subclasses

my $arrayref = Class::Inspector->subclasses($class);

La « subclasses » méthode statique parcourra l'ensemble du namespace (et donc toutes les classes actuellement chargées ) pour trouver toutes les classes qui sont des sous-classes de la classe fournie en paramètre.

Le test réel sera effectué en appelant "isa" sur la classe en tant que méthode statique. (c.-à-d. "My::Class->isa($class)".

Renvoie une référence vers une liste des classes chargées qui correspondent à la classe fournie, ou faux si aucune ne correspond, ou "undef" si le nom de classe fourni est invalide.
