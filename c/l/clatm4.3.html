Documentation de la fonction/sous-programme

sous-programme clatm4 (integer itype, integer n, integer nz1, integer nz2, logical rsign, real amagn, real rcond, real triang, integer idist, integer, dimension( 4 ) iseed, complex, dimension( lda, * ) a, integer lda)

CLATM4

Objectif :

!>
!> CLATM4 génère des matrices carrées de base, qui pourront ultérieurement
!> être multipliées par d'autres pour produire des matrices de test. Il est
!> principalement destiné à tester les routines de valeurs propres généralisées.
!>
!> Il génère d'abord la diagonale et (éventuellement) la sous-diagonale,
!> en fonction des valeurs de ITYPE, NZ1, NZ2, RSIGN, AMAGN et RCOND.
!> Il remplit ensuite le triangle supérieur avec des nombres aléatoires, si TRIANG
!> est non nul.
!>

Paramètres

ITYPE 
!>          ITYPE est INTEGER
!>          Le type de matrice sur la diagonale et la sous-diagonale.
!>          Si ITYPE < 0, alors le type abs(ITYPE) est généré puis
!>             inversé bout à bout (A(I,J) := A'(N-J,N-I).) Voir aussi
!>             la description de AMAGN et RSIGN.
!>
!>          Types spéciaux :
!>          = 0 : la matrice nulle.
!>          = 1 : l'identité.
!>          = 2 : un bloc de Jordan transposé.
!>          = 3 : Si N est impair, alors un bloc de Jordan transposé k+1 x k+1
!>                suivi d'un bloc identité k x k, où k=(N-1)/2.
!>                Si N est pair, alors k=(N-2)/2, et une entrée diagonale nulle
!>                est ajoutée à la fin.
!>
!>          Types diagonaux. La diagonale est constituée de NZ1 zéros, puis
!>             k=N-NZ1-NZ2 non nuls. La sous-diagonale est nulle. ITYPE
!>             spécifie les entrées diagonales non nulles comme suit :
!>          = 4 : 1, ..., k
!>          = 5 : 1, RCOND, ..., RCOND
!>          = 6 : 1, ..., 1, RCOND
!>          = 7 : 1, a, a^2, ..., a^(k-1)=RCOND
!>          = 8 : 1, 1-d, 1-2*d, ..., 1-(k-1)*d=RCOND
!>          = 9 : nombres aléatoires choisis dans (RCOND,1)
!>          = 10 : nombres aléatoires avec la distribution IDIST (voir CLARND.)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice.
!>

NZ1

!>          NZ1 est INTEGER
!>          Si abs(ITYPE) > 3, alors les NZ1 premières entrées diagonales seront
!>          nulles.
!>

NZ2

!>          NZ2 est INTEGER
!>          Si abs(ITYPE) > 3, alors les NZ2 dernières entrées diagonales seront
!>          nulles.
!>

RSIGN

!>          RSIGN est LOGICAL
!>          = .TRUE. : Les entrées diagonales et sous-diagonales seront
!>                     multipliées par des nombres aléatoires de magnitude 1.
!>          = .FALSE. : Les entrées diagonales et sous-diagonales resteront
!>                     telles quelles (généralement réelles non négatives.)
!>

AMAGN

!>          AMAGN est REAL
!>          Les entrées diagonales et sous-diagonales seront multipliées par
!>          AMAGN.
!>

RCOND

!>          RCOND est REAL
!>          Si abs(ITYPE) > 4, alors la plus petite entrée diagonale sera
!>          RCOND. RCOND doit être compris entre 0 et 1.
!>

TRIANG

!>          TRIANG est REAL
!>          Les entrées au-dessus de la diagonale seront des nombres aléatoires
!>          de magnitude bornée par TRIANG (c'est-à-dire, des nombres aléatoires
!>          multipliés par TRIANG.)
!>

IDIST

!>          IDIST est INTEGER
!>          À l'entrée, DIST spécifie le type de distribution à utiliser
!>          pour générer une matrice aléatoire.
!>          = 1 : parties réelle et imaginaire chacune UNIFORM( 0, 1 )
!>          = 2 : parties réelle et imaginaire chacune UNIFORM( -1, 1 )
!>          = 3 : parties réelle et imaginaire chacune NORMAL( 0, 1 )
!>          = 4 : nombre complexe uniforme dans DISK( 0, 1 )
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les valeurs de ISEED sont modifiées à la sortie, et peuvent
!>          être utilisées dans le prochain appel à CLATM4 pour continuer la même
!>          séquence de nombres aléatoires.
!>          Note : ISEED(4) doit être impair, pour le générateur de nombres
!>          aléatoires actuellement utilisé.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA, N)
!>          Tableau à calculer.
!>

LDA

!>          LDA est INTEGER
!>          Dimension principale de A. Doit être au moins 1 et au moins N.
!>
