fonction réelle cla_hercond_x (caractère uplo, entier n, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldaf, * ) af, entier ldaf, entier, dimension( * ) ipiv, complexe, dimension( * ) x, entier info, complexe, dimension( * ) work, réelle, dimension( * ) rwork)

CLA_HERCOND_X calcule le nombre de conditionnement en norme infini de op(A)*diag(x) pour les matrices hermitiennes indéfinies.

Objectif :

!>
!>    CLA_HERCOND_X calcule le nombre de conditionnement en norme infini de
!>    op(A) * diag(X) où X est un vecteur COMPLEXE.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U' : Le triangle supérieur de A est stocké ;
!>       = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>     En entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEXE, dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L tels que calculés par CHETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Détails des échanges et de la structure par blocs de D
!>     tels que déterminés par CHETRF.
!>

X

!>          X est un tableau COMPLEXE, dimension (N)
!>     Le vecteur X dans la formule op(A) * diag(X).
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie.
!>     i > 0 : Le i-ème argument est invalide.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (2*N).
!>     Espace de travail.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N).
!>     Espace de travail.
!>
