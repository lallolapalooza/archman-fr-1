sous-routine clatrs (uplo, trans, diag, normin, n, a, lda, x, scale, cnorm, info)

CLATRS résout un système triangulaire d'équations avec le facteur d'échelle défini pour éviter le débordement.

Documentation de la fonction/sous-routine

sous-routine clatrs (caractere uplo, caractere trans, caractere diag, caractere normin, entier n, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( * ) x, reel scale, reel, dimension( * ) cnorm, entier info)

CLATRS résout un système triangulaire d'équations avec le facteur d'échelle défini pour éviter le débordement.

Objectif :

!>
!> CLATRS résout l'un des systèmes triangulaires
!>
!>    A * x = s*b,  A**T * x = s*b,  ou  A**H * x = s*b,
!>
!> avec mise à l'échelle pour éviter le débordement. Ici A est une matrice
!> triangulaire supérieure ou inférieure, A**T dénote la transposée de A,
!> A**H dénote la transposée conjuguée de A, x et b sont des vecteurs de n
!> éléments, et s est un facteur d'échelle, généralement inférieur ou égal
!> à 1, choisi de sorte que les composantes de x soient inférieures au
!> seuil de débordement. Si le problème non mis à l'échelle ne cause pas de
!> débordement, la routine BLAS de niveau 2 CTRSV est appelée. Si la matrice A
!> est singulière (A(j,j) = 0 pour un certain j), alors s est mis à 0 et une
!> solution non triviale de A*x = 0 est retournée.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  Résoudre A * x = s*b     (Pas de transposée)
!>          = 'T':  Résoudre A**T * x = s*b  (Transposée)
!>          = 'C':  Résoudre A**H * x = s*b  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N':  Non unitaire triangulaire
!>          = 'U':  Unitaire triangulaire
!>

NORMIN

!>          NORMIN est CHARACTER*1
!>          Spécifie si CNORM a été défini ou non.
!>          = 'Y':  CNORM contient les normes des colonnes à l'entrée
!>          = 'N':  CNORM n'est pas défini à l'entrée. En sortie, les normes
!>                  seront calculées et stockées dans CNORM.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          La matrice triangulaire A. Si UPLO = 'U', la partie triangulaire
!>          supérieure supérieure de n par n du tableau A contient la matrice
!>          triangulaire supérieure, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée. Si UPLO = 'L', la partie
!>          triangulaire inférieure supérieure de n par n du tableau A contient
!>          la matrice triangulaire inférieure, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée. Si DIAG = 'U',
!>          les éléments diagonaux de A ne sont pas non plus référencés et
!>          sont supposés être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max (1,N).
!>

X

!>          X est un tableau COMPLEXE, dimension (N)
!>          À l'entrée, le membre de droite b du système triangulaire.
!>          En sortie, X est écrasé par le vecteur solution x.
!>

SCALE

!>          SCALE est REEL
!>          Le facteur d'échelle s pour le système triangulaire
!>             A * x = s*b,  A**T * x = s*b,  ou  A**H * x = s*b.
!>          Si SCALE = 0, la matrice A est singulière ou mal mise à l'échelle,
!>          et le vecteur x est une solution exacte ou approximative de A*x = 0.
!>

CNORM

!>          CNORM est un tableau REEL, dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM est un argument d'entrée et CNORM(j)
!>          contient la norme de la partie hors diagonale de la j-ième colonne
!>          de A. Si TRANS = 'N', CNORM(j) doit être supérieur ou égal à la
!>          norme infinie, et si TRANS = 'T' ou 'C', CNORM(j) doit être
!>          supérieur ou égal à la norme 1.
!>
!>          Si NORMIN = 'N', CNORM est un argument de sortie et CNORM(j)
!>          retourne la norme 1 de la partie hors diagonale de la j-ième colonne
!>          de A.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -k, le k-ième argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!> Une estimation grossière de x est calculée ; si elle est inférieure au
!> débordement, CTRSV est appelée, sinon, un code spécifique est utilisé qui
!> vérifie les débordements possibles ou les divisions par zéro à chaque
!> opération.
!>
!> Un schéma par colonne est utilisé pour résoudre A*x = b. L'algorithme de
!> base si A est triangulaire inférieure est :
!>
!>       x[1:n] := b[1:n]
!>       pour j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!> Définissons des bornes sur les composantes de x après j itérations de la
!> boucle :
!>     M(j) = borne sur x[1:j]
!>     G(j) = borne sur x[j+1:n]
!> Initialement, posons M(0) = 0 et G(0) = max{x(i), i=1,...,n}.
!>
!> Puis pour l'itération j+1 nous avons
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> où CNORM(j+1) est supérieur ou égal à la norme infinie de la
!> colonne j+1 de A, sans compter la diagonale. Donc
!>
!>     G(j) <= G(0) produit ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> et
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) produit ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> Puisque |x(j)| <= M(j), nous utilisons la routine BLAS de niveau 2 CTRSV si le
!> réciproque du M(j) maximum, j=1,..,n, est supérieur à
!> max(sous-flux, 1/débordement).
!>
!> La borne sur x(j) est également utilisée pour déterminer quand une étape dans
!> la méthode par colonne peut être effectuée sans crainte de débordement. Si
!> la borne calculée est supérieure à une grande constante, x est mis à l'échelle
!> pour éviter le débordement, mais si la borne déborde, x est mis à 0, x(j) à
!> 1, et scale à 0, et une solution non triviale de A*x = 0 est trouvée.
!>
!> De même, un schéma par ligne est utilisé pour résoudre A**T *x = b ou
!> A**H *x = b. L'algorithme de base pour A triangulaire supérieure est :
!>
!>       pour j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       fin
!>
!> Nous calculons simultanément deux bornes
!>       G(j) = borne sur ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = borne sur x(i), 1<=i<=j
!>
!> Les valeurs initiales sont G(0) = 0, M(0) = max{b(i), i=1,..,n}, et nous
!> ajoutons la contrainte G(j) >= G(j-1) et M(j) >= M(j-1) pour j >= 1.
!> Alors la borne sur x(j) est
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * produit ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> et nous pouvons appeler CTRSV en toute sécurité si 1/M(n) et 1/G(n) sont
!> tous deux supérieurs à max(sous-flux, 1/débordement).
!>

Définition à la ligne 237 du fichier clatrs.f.
