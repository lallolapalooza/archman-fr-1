NOM

clients.conf - Configuration client RADIUS

DESCRIPTION

Le fichier clients.conf contient les définitions des clients RADIUS.

Les informations de ce fichier remplacent toutes les informations fournies dans les fichiers obsolètes clients et naslist.

Le format du fichier est le même que celui utilisé pour radiusd.conf. Voir radiusd.conf(5) pour plus de détails.

Chaque entrée client RADIUS a la forme de base suivante :

client <nom-court> {
       <attribut> = <valeur>
 }

Les clients ont de nombreux paramètres de configuration. La plupart sont documentés dans le fichier lui-même sous forme de commentaires. Cette page ne documente que le format du fichier. Veuillez lire le fichier clients.conf lui-même pour plus d'informations.

Le format ancien de la version 1.x est toujours accepté par le serveur, mais cette forme est dépréciée.
