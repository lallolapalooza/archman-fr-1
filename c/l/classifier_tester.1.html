NOM

classifier_tester - pour le moteur *legacy tesseract*.

SYNTAXE

classifier_tester -U fichier_unicharset -F fichier_proprietes_police -X fichier_hauteurs_x -classifier x -lang lang [-output_trainer entraîneur] *.tr

DESCRIPTION

classifier_tester(1) exécute Tesseract dans un mode spécial. Il prend une liste de fichiers .tr et teste un classificateur de caractères sur des données formatées pour l'entraînement, mais cela ne doit pas nécessairement être les mêmes données que celles utilisées pour l'entraînement.

ARGUMENTS ENTRÉE/SORTIE

une liste de fichiers .tr

OPTIONS

-l lang

(Entrée) code de langue à trois caractères ; valeur par défaut eng.

-classifier x

(Entrée) L'un des choix : "pruner", "full".

-U unicharset

(Entrée) L'ensemble des unichars pour la langue.

-F fichier_proprietes_police

(Entrée) Fichier des propriétés des polices, chaque ligne est de la forme suivante, où chaque champ autre que le nom de la police est 0 ou 1 : 
*nom_police* *italique* *gras* *police_fixe* *serif* *fraktur*

-X fichier_hauteurs_x

(Entrée) Fichier des hauteurs x, chaque ligne est de la forme suivante, où la hauteur x est calculée comme la hauteur x en pixels d'un caractère dessiné à 32pt à 300 dpi. [ C'est-à-dire, si hauteur de base x + ascendantes + descendantes = 133, quelle est la hauteur x ? ] 
*nom_police* *hauteur_x*

-output_trainer entraîneur

(Sortie, Facultatif) Nom de fichier pour l'entraîneur de sortie.
