sous-routine claqr4 (wantt, wantz, n, ilo, ihi, h, ldh, w, iloz, ihiz, z, ldz, work, lwork, info)
CLAQR4 calcule les valeurs propres d'une matrice de Hessenberg et, optionnellement, les matrices de la décomposition de Schur.

Documentation de la fonction/de la

sous-routine

sous-routine claqr4 (logical wantt, logical wantz, integer n, integer ilo, integer ihi, complex, dimension( ldh, * ) h, integer ldh, complex, dimension( * ) w, integer iloz, integer ihiz, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, integer lwork, integer

info)

CLAQR4 calcule les valeurs propres d'une matrice de Hessenberg et, optionnellement, les matrices de la décomposition de

Schur.

But

: 
!>
!>    CLAQR4 implémente un niveau de récursion pour CLAQR0.
!>    C'est une implémentation complète de l'algorithme QR multi-décalage
!>    à petite bosse. Elle peut être appelée par CLAQR0 et, pour une
!>    fenêtre de déflation suffisamment grande, elle peut être appelée
!>    par CLAQR3. Cette sous-routine est identique à CLAQR0 sauf qu'elle
!>    appelle CLAQR2 au lieu de CLAQR3.
!>
!>    CLAQR4 calcule les valeurs propres d'une matrice de Hessenberg H
!>    et, optionnellement, les matrices T et Z de la décomposition de Schur
!>    H = Z T Z**H, où T est une matrice triangulaire supérieure (la
!>    forme de Schur), et Z est la matrice unitaire des vecteurs de Schur.
!>
!>    Optionnellement, Z peut être post-multipliée par une matrice
!>    unitaire d'entrée Q afin que cette routine puisse fournir la
!>    factorisation de Schur d'une matrice A qui a été réduite à la
!>    forme de Hessenberg H par la matrice unitaire Q : A = Q*H*Q**H = (QZ)*H*(QZ)**H.
!
>

Paramètre

s
WANTT 
!>          WANTT est de type LOGIQUEL
!>          = .TRUE. : la forme de Schur complète T est requise ;
!>          = .FALSE. : seules les valeurs propres sont requises.
!
>

WANT

Z 
!>          WANTZ est de type LOGIQUEL
!>          = .TRUE. : la matrice des vecteurs de Schur Z est requise ;
!>          = .FALSE. : les vecteurs de Schur ne sont pas requis.
!
>

N 
!>          N est de type ENTIER
!>           L'ordre de la matrice H. N >= 0.
!
>

IL

O 
!>          ILO est de type ENTIER
!
>

IH

I 
!>          IHI est de type ENTIER
!>           On suppose que H est déjà triangulaire supérieure dans les
!>           lignes et colonnes 1:ILO-1 et IHI+1:N et, si ILO > 1,
!>           H(ILO,ILO-1) est nul. ILO et IHI sont normalement définis
!>           par un appel précédent à CGEBAL, puis transmis à CGEHRD
!>           lorsque la matrice produite par CGEBAL est réduite à la
!>           forme de Hessenberg. Sinon, ILO et IHI devraient être
!>           définis à 1 et N, respectivement. Si N > 0, alors
!>           1 <= ILO <= IHI <= N. Si N = 0, alors ILO = 1 et IHI = 0.
!
>

H 
!>          H est un tableau COMPLEXE, dimension (LDH,N)
!>           À l'entrée, la matrice de Hessenberg supérieure H.
!>           À la sortie, si INFO = 0 et WANTT est .TRUE., alors H
!>           contient la matrice triangulaire supérieure T de la
!>           décomposition de Schur (la forme de Schur). Si INFO = 0 et
!>           WANT est .FALSE., alors le contenu de H est indéfini à la
!>           sortie. (La valeur de sortie de H lorsque INFO > 0 est
!>           donnée dans la description de INFO ci-dessous.)
!>
!>           Cette sous-routine peut définir explicitement H(i,j) = 0
!>           pour i > j et j = 1, 2, ... ILO-1 ou j = IHI+1, IHI+2, ... N.
!
>

LD

H 
!>          LDH est de type ENTIER
!>           La dimension principale du tableau H. LDH >= max(1,N).
!
>

W 
!>          W est un tableau COMPLEXE, dimension (N)
!>           Les valeurs propres calculées de H(ILO:IHI,ILO:IHI) sont
!>           stockées dans W(ILO:IHI). Si WANTT est .TRUE., alors les
!>           valeurs propres sont stockées dans le même ordre que sur
!>           la diagonale de la forme de Schur retournée dans H, avec
!>           W(i) = H(i,i).
!
>

ILO

Z 
!>          ILOZ est de type ENTIER
!
>

IHI

Z 
!>          IHIZ est de type ENTIER
!>           Spécifie les lignes de Z auxquelles les transformations
!>           doivent être appliquées si WANTZ est .TRUE..
!>           1 <= ILOZ <= ILO ; IHI <= IHIZ <= N.
!
>

Z 
!>          Z est un tableau COMPLEXE, dimension (LDZ,IHI)
!>           Si WANTZ est .FALSE., alors Z n'est pas référencé.
!>           Si WANTZ est .TRUE., alors Z(ILO:IHI,ILOZ:IHIZ) est
!>           remplacé par Z(ILO:IHI,ILOZ:IHIZ)*U où U est le facteur
!>           de Schur orthogonal de H(ILO:IHI,ILO:IHI).
!>           (La valeur de sortie de Z lorsque INFO > 0 est donnée
!>           dans la description de INFO ci-dessous.)
!
>

LD

Z 
!>          LDZ est de type ENTIER
!>           La dimension principale du tableau Z. Si WANTZ est .TRUE.
!>           alors LDZ >= MAX(1,IHIZ). Sinon, LDZ >= 1.
!
>

WOR

K 
!>          WORK est un tableau COMPLEXE, dimension LWORK
!>           À la sortie, si LWORK = -1, WORK(1) renvoie une estimation
!>           de la valeur optimale pour LWORK.
!
>

LWOR

K 
!>          LWORK est de type ENTIER
!>           La dimension du tableau WORK. LWORK >= max(1,N)
!>           est suffisant, mais LWORK doit généralement être aussi
!>           grand que 6*N pour des performances optimales. Une
!>           interrogation de l'espace de travail pour déterminer la
!>           taille optimale de l'espace de travail est recommandée.
!>
!>           Si LWORK = -1, alors CLAQR4 effectue une interrogation de
!>           l'espace de travail. Dans ce cas, CLAQR4 vérifie les
!>           paramètres d'entrée et estime la taille optimale de
!>           l'espace de travail pour les valeurs données de N, ILO et
!>           IHI. L'estimation est renvoyée dans WORK(1). Aucun
!>           message d'erreur lié à LWORK n'est émis par XERBLA. Ni H
!>           ni Z ne sont accédés.
!
>

INF

O 
!>          INFO est de type ENTIER
!>             = 0 : sortie réussie
!>             > 0 : si INFO = i, CLAQR4 n'a pas réussi à calculer
!>                toutes les valeurs propres. Les éléments 1:ilo-1 et
!>                i+1:n de WR et WI contiennent les valeurs propres qui
!>                ont été calculées avec succès. (Les échecs sont
!>                rares.)
!>
!>                Si INFO > 0 et WANT est .FALSE., alors à la sortie,
!>                les valeurs propres non convergées restantes sont les
!>                valeurs propres de la matrice de Hessenberg supérieure
!>                lignes et colonnes ILO à INFO de la valeur finale de
!>                sortie de H.
!>
!>                Si INFO > 0 et WANTT est .TRUE., alors à la sortie
!>
!>           (*)  (valeur initiale de H)*U  = U*(valeur finale de H)
!>
!>                où U est une matrice unitaire. La valeur finale de
!>                H est de Hessenberg supérieure et triangulaire dans
!>                les lignes et colonnes INFO+1 à IHI.
!>
!>                Si INFO > 0 et WANTZ est .TRUE., alors à la sortie
!>
!>                  (valeur finale de Z(ILO:IHI,ILOZ:IHIZ)
!>                   =  (valeur initiale de Z(ILO:IHI,ILOZ:IHIZ)*U
!>
!>                où U est la matrice unitaire dans (*) (quel que soit
!>                la valeur de WANTT.)
!>
!>                Si INFO > 0 et WANTZ est .FALSE., alors Z n'est pas
!>                accédé.
!
>
