sous-programme claed0 (entier qsiz, entier n, réel, dimension( * ) d, réel, dimension( * ) e, complexe, dimension( ldq, * ) q, entier ldq, complexe, dimension( ldqs, * ) qstore, entier ldqs, réel, dimension( * ) rwork, entier, dimension( * ) iwork, entier info)

CLAED0 utilisé par CSTEDC. Calcule toutes les valeurs propres et les vecteurs propres correspondants d'une matrice tridiagonale symétrique non réduite en utilisant la méthode diviser pour régner.

Objectif :

!>
!> En utilisant la méthode diviser pour régner, CLAED0 calcule toutes les
!> valeurs propres d'une matrice tridiagonale symétrique qui est un bloc
!> diagonal de ceux obtenus en réduisant une matrice hermitienne dense
!> ou bande et les vecteurs propres correspondants de la matrice dense ou bande.
!>

Paramètres

QSIZ 
!>          QSIZ est ENTIER
!>         La dimension de la matrice unitaire utilisée pour réduire
!>         la matrice complète en forme tridiagonale.  QSIZ >= N si ICOMPQ = 1.
!>

N

!>          N est ENTIER
!>         La dimension de la matrice tridiagonale symétrique.  N >= 0.
!>

D

!>          D est tableau RÉEL, dimension (N)
!>         À l'entrée, les éléments diagonaux de la matrice tridiagonale.
!>         À la sortie, les valeurs propres en ordre croissant.
!>

E

!>          E est tableau RÉEL, dimension (N-1)
!>         À l'entrée, les éléments hors diagonale de la matrice tridiagonale.
!>         À la sortie, E a été détruit.
!>

Q

!>          Q est tableau COMPLET, dimension (LDQ,N)
!>         À l'entrée, Q doit contenir une matrice QSIZ x N dont les colonnes
!>         sont orthonormées unitaires. Elle fait partie de la matrice unitaire
!>         qui réduit la matrice hermitienne dense (réductible) en une
!>         matrice tridiagonale symétrique (réductible).
!>

LDQ

!>          LDQ est ENTIER
!>         La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

IWORK

!>          IWORK est tableau ENTIER,
!>         la dimension de IWORK doit être au moins
!>                      6 + 6*N + 5*N*lg N
!>                      ( lg( N ) = plus petit entier k
!>                                  tel que 2^k >= N )
!>

RWORK

!>          RWORK est tableau RÉEL,
!>                               dimension (1 + 3*N + 2*N*lg N + 3*N**2)
!>                        ( lg( N ) = plus petit entier k
!>                                    tel que 2^k >= N )
!>

QSTORE

!>          QSTORE est tableau COMPLET, dimension (LDQS, N)
!>         Utilisé pour stocker des parties de la matrice des vecteurs
!>         propres lorsque les multiplications de matrices de mise à jour
!>         ont lieu.
!>

LDQS

!>          LDQS est ENTIER
!>         La dimension principale du tableau QSTORE.
!>         LDQS >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0:  fin réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  L'algorithme n'a pas réussi à calculer une valeur propre lors
!>                de l'opération sur la sous-matrice située dans les lignes
!>                et colonnes INFO/(N+1) à mod(INFO,N+1).
!>
