Documentation de la fonction/sous-programme

sous-routine claghe (entier n, entier k, reel, dimension( * ) d, complexe, dimension( lda, * ) a, entier lda, entier, dimension( 4 ) iseed, complexe, dimension( * ) work, entier info)

CLAGHE

Objectif :

!>
!> CLAGHE génère une matrice hermitienne complexe A, en pré- et post-
!> multipliant une matrice diagonale réelle D par une matrice unitaire aléatoire :
!> A = U*D*U'. La semi-bande peut ensuite être réduite à k par des transformations unitaires supplémentaires.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de sous-diagonales non nulles dans la bande de A.
!>          0 <= K <= N-1.
!>

D

!>          D est un tableau REEL, dimension (N)
!>          Les éléments diagonaux de la matrice diagonale D.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          La matrice hermitienne n par n générée A (la matrice complète est
!>          stockée).
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= N.
!>

ISEED

!>          ISEED est un tableau ENTIER, dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires ; les éléments
!>          du tableau doivent être compris entre 0 et 4095, et ISEED(4) doit être
!>          impair.
!>          À la sortie, la graine est mise à jour.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (2*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
