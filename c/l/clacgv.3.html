sous-routine clacgv (integer n, complex, dimension( * ) x, integer incx)

CLACGV conjugue un vecteur complexe.

Objectif :

!>
!> CLACGV conjugue un vecteur complexe de longueur N.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          La longueur du vecteur X. N >= 0.
!>

X

!>          X est un tableau complexe (COMPLEX), de dimension
!>                         (1+(N-1)*abs(INCX))
!>          À l'entrée, le vecteur de longueur N à conjuguer.
!>          À la sortie, X est écrasé par conjg(X).
!>

INCX

!>          INCX est un entier (INTEGER)
!>          Le pas entre les éléments successifs de X.
!>
