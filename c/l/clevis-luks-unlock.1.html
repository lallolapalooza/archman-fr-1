NOM

clevis-luks-unlock - Déverrouille un périphérique LUKS lié avec une politique Clevis

SYNTAXE

clevis luks unlock -d DEV [-n NAME] [-t SLT]

APERÇU

La commande clevis luks unlock déverrouille un périphérique LUKS en utilisant sa politique Clevis déjà provisionnée. Par exemple :

$ clevis luks unlock -d /dev/sda

OPTIONS

•-d DEV : Le périphérique LUKS à déverrouiller
•-n NAME : Le nom à donner au nœud de périphérique déverrouillé
•-t SLT : Teste la phrase de passe pour la fente donnée sans déverrouiller le périphérique
•-o PARAMS : Transmet des paramètres arbitraires à cryptsetup ; mettez les paramètres entre guillemets si nécessaire
