CLUTTEX(1) Manuel des commandes générales CLUTTEX(1)

NOM

cluttex — un outil pour traiter les fichiers TeX

SYNOPIS

cluttex -e MOTEUR [options] [--] FICHIER.tex

DESCRIPTION

Traite les fichiers TeX sans encombrer votre répertoire de travail.

Les options suivantes sont acceptées :

-e, --engine=MOTEUR
Spécifie le moteur TeX à utiliser. MOTEUR est l'un des suivants : pdflatex, pdftex, lualatex, luatex, luajittex, xelatex, xetex, latex, etex, tex, platex, eptex, ptex, uplatex, euptex, uptex,
--engine-executable=COMMANDE+OPTIONS
La commande TeX réelle à utiliser. [défaut : MOTEUR]
-o, --output=FICHIER
Le nom du fichier de sortie. [défaut : NOMDUJOB.pdf ou NOMDUJOB.dvi]
--fresh
Nettoie les fichiers intermédiaires avant d'exécuter TeX. Ne peut pas être utilisé avec --output-directory.
--max-iterations=N
Nombre maximum d'exécutions de TeX pour résoudre les références croisées. [défaut : 3]
--start-with-draft
Commence en mode brouillon.
--change-directory, --no-change-directory
Change de répertoire avant d'exécuter TeX. [défaut : non]
--watch[=MOTEUR]
Surveille les fichiers d'entrée pour détecter les changements. Nécessite fswatch ou inotifywait installé. MOTEUR est l'un des ‘fswatch’, ‘inotifywait’ ou ‘auto’. [défaut : auto]
--tex-option=OPTION
Passe OPTION à TeX en tant qu'option unique.
--tex-options=OPTIONS
Passe OPTIONS à TeX en tant qu'options multiples.
--dvipdfmx-option=OPTION, --dvipdfmx-options=OPTIONS
Identique pour dvipdfmx.
--makeindex=COMMANDE+OPTIONS
Commande pour générer l'index, telle que ‘makeindex’ ou ‘mendex’.
--bibtex=COMMANDE+OPTIONS
Commande pour BibTeX, telle que ‘bibtex’ ou ‘pbibtex’.
--biber[=COMMANDE+OPTIONS]
Commande pour Biber.
--makeglossaries[=COMMANDE+OPTIONS]
Commande pour makeglossaries.
-h, --help
Affiche ce message et quitte.
-v, --version
Affiche les informations de version et quitte.
-V, --verbose
Être plus verbeux.
--color[=QUAND]
Rend les messages de ClutTeX plus colorés. QUAND est l'un des ‘toujours’, ‘auto’, ou ‘jamais’. [défaut : ‘auto’ si -color est omis, ‘toujours’ si QUAND est omis]
--includeonly=NOMS
Insère ‘\includeonly{NOMS}’.
--make-depends=FICHIER
Écrit les dépendances sous forme de règle Makefile.
--print-output-directory
Affiche le répertoire de sortie et quitte.
--package-support=PKG1[,PKG2,...]
Active un support spécial pour certains paquets échappant à la console. Actuellement pris en charge : minted, epstopdf.
--check-driver=DRIVER
Vérifie que le bon fichier driver est chargé. DRIVER est l'un des ‘dvipdfmx’, ‘dvips’, ‘dvisvgm’.
--shell-escape, --no-shell-escape
 
--shell-restricted
 
--synctex=NOMBRE
 
--fmt=NOMFMT
 
--file-line-error, --no-file-line-error
[défaut: oui]
--halt-on-error, --no-halt-on-error
[défaut: oui]
--interaction=CHAINE
[défaut: nonstopmode]
--jobname=CHAINE
 
--output-directory=DIR
[défaut: quelque part dans le répertoire temporaire]
--output-format=FORMAT
FORMAT est ‘pdf’ ou ‘dvi’. [défaut: pdf]

STATUT DE SORTIE

L'utilitaire cluttex se termine 0 en cas de succès, et >0 si une erreur se produit.
