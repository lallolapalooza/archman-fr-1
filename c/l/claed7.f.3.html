sous-routine claed7 (entier n, entier cutpnt, entier qsiz, entier tlvls, entier curlvl, entier curpbm, réel, dimension( * ) d, complexe, dimension( ldq, * ) q, entier ldq, réel rho, entier, dimension( * ) indxq, réel, dimension( * ) qstore, entier, dimension( * ) qptr, entier, dimension( * ) prmptr, entier, dimension( * ) perm, entier, dimension( * ) givptr, entier, dimension( 2, * ) givcol, réel, dimension( 2, * ) givnum, complexe, dimension( * ) work, réel, dimension( * ) rwork, entier, dimension( * ) iwork, entier info)

CLAED7 utilisé par CSTEDC. Calcule le système propre mis à jour d'une matrice diagonale après modification par une matrice symétrique de rang un. Utilisé lorsque la matrice d'origine est dense.

Objectif :

!>
!> CLAED7 calcule le système propre mis à jour d'une
!> matrice diagonale après modification par une matrice symétrique de rang un. Cette
!> sous-routine est utilisée uniquement pour le problème propre qui nécessite toutes
!> les valeurs propres et éventuellement les vecteurs propres d'une matrice hermitienne
!> dense ou bande qui a été réduite à une forme tridiagonale.
!>
!>   T = Q(in) ( D(in) + RHO * Z*Z**H ) Q**H(in) = Q(out) * D(out) * Q**H(out)
!>
!>   où Z = Q**Hu, u est un vecteur de longueur N avec des uns dans les
!>   éléments CUTPNT et CUTPNT + 1 et des zéros ailleurs.
!>
!>    Les vecteurs propres de la matrice d'origine sont stockés dans Q, et les
!>    valeurs propres sont dans D. L'algorithme se compose de trois étapes :
!>
!>       La première étape consiste à déflationner la taille du problème
!>       lorsqu'il y a des valeurs propres multiples ou s'il y a un zéro dans
!>       le vecteur Z. Pour chaque occurrence de ce type, la dimension du
!>       problème de l'équation séculaire est réduite de un. Cette étape est
!>       réalisée par la sous-routine SLAED2.
!>
!>       La deuxième étape consiste à calculer les valeurs propres mises à jour.
!>       Ceci est fait en trouvant les racines de l'équation séculaire
!>       via la sous-routine SLAED4 (appelée par SLAED3).
!>       Cette sous-routine calcule également les vecteurs propres du
!>       problème actuel.
!>
!>       La dernière étape consiste à calculer directement les vecteurs propres
!>       mis à jour en utilisant les valeurs propres mises à jour. Les vecteurs
!>       propres du problème actuel sont multipliés par les vecteurs propres
!>       du problème global.
!>

Paramètres

N 
!>          N est ENTIER
!>         La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

CUTPNT

!>          CUTPNT est ENTIER
!>         Contient l'emplacement de la dernière valeur propre dans la sous-matrice
!>         principale. min(1,N) <= CUTPNT <= N.
!>

QSIZ

!>          QSIZ est ENTIER
!>         La dimension de la matrice unitaire utilisée pour réduire
!>         la matrice complète à une forme tridiagonale. QSIZ >= N.
!>

TLVLS

!>          TLVLS est ENTIER
!>         Le nombre total de niveaux de fusion dans l'arbre diviser pour régner global.
!>

CURLVL

!>          CURLVL est ENTIER
!>         Le niveau actuel dans la routine de fusion globale,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM est ENTIER
!>         Le problème actuel au niveau actuel dans la routine de fusion globale
!>         (compté de la gauche vers la droite et du bas vers le haut).
!>

D

!>          D est tableau REEL, dimension (N)
!>         À l'entrée, les valeurs propres de la matrice perturbée de rang 1.
!>         À la sortie, les valeurs propres de la matrice réparée.
!>

Q

!>          Q est tableau COMPLET, dimension (LDQ,N)
!>         À l'entrée, les vecteurs propres de la matrice perturbée de rang 1.
!>         À la sortie, les vecteurs propres de la matrice tridiagonale réparée.
!>

LDQ

!>          LDQ est ENTIER
!>         La dimension principale du tableau Q. LDQ >= max(1,N).
!>

RHO

!>          RHO est REEL
!>         Contient l'élément sous-diagonal utilisé pour créer la modification
!>         de rang 1.
!>

INDXQ

!>          INDXQ est tableau ENTIER, dimension (N)
!>         Ceci contient la permutation qui réintégrera le sous-problème
!>         juste résolu dans l'ordre trié, c'est-à-dire D( INDXQ( I = 1, N ) )
!>         sera dans l'ordre croissant.
!>

IWORK

!>          IWORK est tableau ENTIER, dimension (4*N)
!>

RWORK

!>          RWORK est tableau REEL,
!>                                 dimension (3*N+2*QSIZ*N)
!>

WORK

!>          WORK est tableau COMPLET, dimension (QSIZ*N)
!>

QSTORE

!>          QSTORE est tableau REEL, dimension (N**2+1)
!>         Stocke les vecteurs propres des sous-matrices rencontrées pendant
!>         le diviser pour régner, regroupés. QPTR pointe vers le
!>         début des sous-matrices.
!>

QPTR

!>          QPTR est tableau ENTIER, dimension (N+2)
!>         Liste des indices pointant vers le début des sous-matrices stockées
!>         dans QSTORE. Les sous-matrices sont numérotées à partir du
!>         coin inférieur gauche de l'arbre diviser pour régner, de gauche
!>         à droite et du bas vers le haut.
!>

PRMPTR

!>          PRMPTR est tableau ENTIER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans PERM la
!>         permutation d'un niveau est stockée. PRMPTR(i+1) - PRMPTR(i)
!>         indique la taille de la permutation et également la taille du
!>         problème complet, non déflaté.
!>

PERM

!>          PERM est tableau ENTIER, dimension (N lg N)
!>         Contient les permutations (issues de la déflation et du tri) à
!>         appliquer à chaque bloc propre.
!>

GIVPTR

!>          GIVPTR est tableau ENTIER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans GIVCOL les
!>         rotations de Givens d'un niveau sont stockées. GIVPTR(i+1) - GIVPTR(i)
!>         indique le nombre de rotations de Givens.
!>

GIVCOL

!>          GIVCOL est tableau ENTIER, dimension (2, N lg N)
!>         Chaque paire de nombres indique une paire de colonnes pour effectuer
!>         une rotation de Givens.
!>

GIVNUM

!>          GIVNUM est tableau REEL, dimension (2, N lg N)
!>         Chaque nombre indique la valeur S à utiliser dans la
!>         rotation de Givens correspondante.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur propre n'a pas convergé
!>
