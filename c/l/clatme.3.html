sous-programme clatme (entier n, caractère dist, entier, dimension( 4 ) iseed, complexe, dimension( * ) d, entier mode, réel cond, complexe dmax, caractère rsign, caractère upper, caractère sim, réel, dimension( * ) ds, entier modes, réel conds, entier kl, entier ku, réel anorm, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( * ) work, entier info)

CLATME

But:

!>
!>    CLATME génère des matrices carrées non symétriques aléatoires avec
!>    des valeurs propres spécifiées pour tester les programmes LAPACK.
!>
!>    CLATME opère en appliquant la séquence suivante d'opérations :
!>
!>    1. Fixe la diagonale à D, où D peut être entrée ou
!>         calculée selon MODE, COND, DMAX et RSIGN
!>         comme décrit ci-dessous.
!>
!>    2. Si UPPER='T', le triangle supérieur de A est rempli de valeurs
!>         aléatoires selon la distribution DIST.
!>
!>    3. Si SIM='T', A est multiplié à gauche par une matrice aléatoire
!>         X, dont les valeurs singulières sont spécifiées par DS, MODES et
!>         CONDS, et à droite par X inverse.
!>
!>    4. Si KL < N-1, la bande inférieure est réduite à KL en utilisant
!>         des transformations de Householder. Si KU < N-1, la bande supérieure
!>         est réduite à KU.
!>
!>    5. Si ANORM n'est pas négatif, la matrice est mise à l'échelle pour avoir
!>         la norme de l'élément maximum ANORM.
!>
!>    (Note : comme la matrice ne peut pas être réduite au-delà de la forme de Hessenberg,
!>     aucune option d'empaquetage n'est disponible.)
!>

Paramètres

N 
!>          N est ENTIER
!>           Le nombre de colonnes (ou de lignes) de A. Non modifié.
!>

DIST

!>          DIST est CARACTERE*1
!>           À l'entrée, DIST spécifie le type de distribution à utiliser
!>           pour générer les valeurs propres/singulières aléatoires, et sur le
!>           triangle supérieur (voir UPPER).
!>           'U' => UNIFORME( 0, 1 )  ( 'U' pour uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' pour symétrique )
!>           'N' => NORMALE( 0, 1 )   ( 'N' pour normale )
!>           'D' => uniforme sur le disque complexe |z| < 1.
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau ENTIER, dimension ( 4 )
!>           À l'entrée, ISEED spécifie la graine du générateur de nombres
!>           aléatoires. Ils doivent être compris entre 0 et 4095 inclus,
!>           et ISEED(4) doit être impair. Le générateur de nombres aléatoires
!>           utilise une séquence congruente linéaire limitée à de petits
!>           entiers, et devrait donc produire des nombres aléatoires indépendants
!>           de la machine. Les valeurs de ISEED sont modifiées à la
!>           sortie, et peuvent être utilisées lors du prochain appel à CLATME
!>           pour continuer la même séquence de nombres aléatoires.
!>           Modifié à la sortie.
!>

D

!>          D est un tableau COMPLEXE, dimension ( N )
!>           Ce tableau est utilisé pour spécifier les valeurs propres de A.  Si
!>           MODE=0, alors D est supposé contenir les valeurs propres
!>           sinon elles seront calculées selon MODE, COND,
!>           DMAX et RSIGN et placées dans D.
!>           Modifié si MODE est non nul.
!>

MODE

!>          MODE est ENTIER
!>           À l'entrée, ceci décrit comment les valeurs propres doivent
!>           être spécifiées :
!>           MODE = 0 signifie utiliser D en entrée
!>           MODE = 1 fixe D(1)=1 et D(2:N)=1.0/COND
!>           MODE = 2 fixe D(1:N-1)=1 et D(N)=1.0/COND
!>           MODE = 3 fixe D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 fixe D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 fixe D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    soient uniformément distribués.
!>           MODE = 6 fixe D à des nombres aléatoires provenant de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est entre 1 et 4, D a des entrées allant
!>              de 1 à 1/COND, si entre -1 et -4, D a des entrées
!>              allant de 1/COND à 1,
!>           Non modifié.
!>

COND

!>          COND est RÉEL
!>           À l'entrée, ceci est utilisé comme décrit sous MODE ci-dessus.
!>           S'il est utilisé, il doit être >= 1. Non modifié.
!>

DMAX

!>          DMAX est COMPLEXE
!>           Si MODE n'est ni -6, ni 0, ni 6, le contenu de D, tel que
!>           calculé selon MODE et COND, sera mis à l'échelle par
!>           DMAX / max(abs(D(i))).  Notez que DMAX n'a pas besoin d'être
!>           positif ou réel : si DMAX est négatif ou complexe (ou zéro),
!>           D sera mis à l'échelle par un nombre négatif ou complexe (ou zéro).
!>           Si RSIGN='F', alors la valeur propre la plus grande (en valeur absolue) sera
!>           égale à DMAX.
!>           Non modifié.
!>

RSIGN

!>          RSIGN est CARACTERE*1
!>           Si MODE n'est ni 0, ni 6, ni -6, et que RSIGN='T', alors les
!>           éléments de D, tels que calculés selon MODE et COND, seront
!>           multipliés par un nombre complexe aléatoire du cercle unité
!>           |z| = 1.  Si RSIGN='F', ils ne le seront pas.  RSIGN ne peut
!>           avoir que les valeurs 'T' ou 'F'.
!>           Non modifié.
!>

UPPER

!>          UPPER est CARACTERE*1
!>           Si UPPER='T', alors les éléments de A au-dessus de la diagonale
!>           seront remplis de nombres aléatoires issus de DIST.  Si UPPER='F',
!>           ils ne le seront pas.  UPPER ne peut avoir que les valeurs 'T' ou 'F'.
!>           Non modifié.
!>

SIM

!>          SIM est CARACTERE*1
!>           Si SIM='T', alors A sera transformé par , c'est-à-dire multiplié à gauche par une matrice X et
!>           à droite par X inverse.  X = U S V, où U et V sont
!>           des matrices unitaires aléatoires et S est une matrice (diagonale) de
!>           valeurs singulières spécifiées par DS, MODES et CONDS.  Si
!>           SIM='F', alors A ne sera pas transformé.
!>           Non modifié.
!>

DS

!>          DS est un tableau RÉEL, dimension ( N )
!>           Ce tableau est utilisé pour spécifier les valeurs singulières de X,
!>           de la même manière que D spécifie les valeurs propres de A.
!>           Si MODE=0, DS contient les valeurs singulières, qui
!>           ne peuvent pas être nulles.
!>           Modifié si MODE est non nul.
!>

MODES

!>          MODES est ENTIER
!>

CONDS

!>          CONDS est RÉEL
!>           Similaire à MODE et COND, mais pour spécifier la diagonale
!>           de S.  MODES=-6 et +6 ne sont pas autorisés (car ils
!>           conduiraient à des valeurs propres aléatoirement mal conditionnées.)
!>

KL

!>          KL est ENTIER
!>           Ceci spécifie la bande inférieure de la  matrice.  KL=1
!>           spécifie la forme de Hessenberg supérieure.  Si KL est supérieur ou égal à N-1,
!>           alors A aura une bande inférieure complète.
!>           Non modifié.
!>

KU

!>          KU est ENTIER
!>           Ceci spécifie la bande supérieure de la  matrice.  KU=1
!>           spécifie la forme de Hessenberg inférieure.  Si KU est supérieur ou égal à N-1,
!>           alors A aura une bande supérieure complète ; si KU et KL
!>           sont tous deux supérieurs ou égaux à N-1, alors A sera dense.  Une seule des
!>           deux conditions KU et KL peut être inférieure à N-1.
!>           Non modifié.
!>

ANORM

!>          ANORM est RÉEL
!>

Si ANORM n'est pas négatif, alors A sera mis à l'échelle par un nombre réel non !> négatif afin que la norme de l'élément maximum de A !> soit égale à ANORM. !> Non modifié. !>

A

!>          A est un tableau COMPLEX, de dimension ( LDA, N )
!>           À la sortie, A est la matrice de test souhaitée.
!>           Modifié.
!>

LDA

!>          LDA est INTEGER
!>           LDA spécifie la première dimension de A telle que déclarée dans le
!>           programme appelant. LDA doit être au moins égal à M.
!>           Non modifié.
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension ( 3*N )
!>           Espace de travail.
!>           Modifié.
!>

INFO

!>          INFO est INTEGER
!>           Code d'erreur. À la sortie, INFO sera défini à l'une des
!>           valeurs suivantes :
!>             0 => retour normal
!>            -1 => N négatif
!>            -2 => DIST chaîne illégale
!>            -5 => MODE hors de l'intervalle -6 à 6
!>            -6 => COND inférieur à 1.0, et MODE n'est ni -6, ni 0, ni 6
!>            -9 => RSIGN n'est pas 'T' ou 'F'
!>           -10 => UPPER n'est pas 'T' ou 'F'
!>           -11 => SIM   n'est pas 'T' ou 'F'
!>           -12 => MODES=0 et DS a une valeur singulière nulle.
!>           -13 => MODES n'est pas dans l'intervalle -5 à 5.
!>           -14 => MODES est non nul et CONDS est inférieur à 1.
!>           -15 => KL est inférieur à 1.
!>           -16 => KU est inférieur à 1, ou KL et KU sont tous deux inférieurs à
!>                  N-1.
!>           -19 => LDA est inférieur à M.
!>            1  => Retour d'erreur de CLATM1 (calcul de D)
!>            2  => Impossible de mettre à l'échelle vers DMAX (la valeur propre max. est 0)
!>            3  => Retour d'erreur de SLATM1 (calcul de DS)
!>            4  => Retour d'erreur de CLARGE
!>            5  => Valeur singulière nulle provenant de SLATM1.
!>
