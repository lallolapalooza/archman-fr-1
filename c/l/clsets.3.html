sous-routine clsets (integer m, integer p, integer n, complex, dimension( lda, * ) a, complex, dimension( lda, * ) af, integer lda, complex, dimension( ldb, * ) b, complex, dimension( ldb, * ) bf, integer ldb, complex, dimension( * ) c, complex, dimension( * ) cf, complex, dimension( * ) d, complex, dimension( * ) df, complex, dimension( * ) x, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( 2 ) result)

CLSETS

But :

!>
!> CLSETS teste CGGLSE - une sous-routine pour résoudre le problème des moindres carrés
!> avec contraintes d'égalité (LSE).
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est un ENTIER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          La matrice A de dimensions M x N.
!>

AF

!>          AF est un tableau COMPLEXE, dimension (LDA,N)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et R.
!>          LDA >= max(M,N).
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB,N)
!>          La matrice A de dimensions P x N.
!>

BF

!>          BF est un tableau COMPLEXE, dimension (LDB,N)
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale des tableaux B, BF, V et S.
!>          LDB >= max(P,N).
!>

C

!>          C est un tableau COMPLEXE, dimension( M )
!>          le vecteur C dans le problème LSE.
!>

CF

!>          CF est un tableau COMPLEXE, dimension( M )
!>

D

!>          D est un tableau COMPLEXE, dimension( P )
!>          le vecteur D dans le problème LSE.
!>

DF

!>          DF est un tableau COMPLEXE, dimension( P )
!>

X

!>          X est un tableau COMPLEXE, dimension( N )
!>          vecteur solution X dans le problème LSE.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (M)
!>

RESULT

!>          RESULT est un tableau REEL, dimension (2)
!>          Les ratios de test :
!>            RESULT(1) = norm( A*x - c )/ norm(A)*norm(X)*EPS
!>            RESULT(2) = norm( B*x - d )/ norm(B)*norm(X)*EPS
!>
