clock_getcpuclockid(3) Manuel des fonctions de bibliothèque clock_getcpuclockid(3)

NOM

clock_getcpuclockid - obtenir l'identifiant de l'horloge temps CPU d'un processus

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc), depuis glibc 2.17

Avant glibc 2.17, Bibliothèque temps réel (librt, -lrt)

SYNTAXE

#include <time.h>

int clock_getcpuclockid(pid_t pid, clockid_t *clockid);
Conditions de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

clock_getcpuclockid():

    _POSIX_C_SOURCE >= 200112L

DESCRIPTION

La fonction clock_getcpuclockid() obtient l'identifiant de l'horloge temps CPU du processus dont l'ID est pid, et le retourne dans l'emplacement pointé par clockid. Si pid est zéro, alors l'identifiant de l'horloge temps CPU du processus appelant est retourné.

VALEUR DE RETOUR

En cas de succès, clock_getcpuclockid() retourne 0 ; en cas d'erreur, elle retourne l'un des numéros d'erreur positifs listés dans ERREURS.

ERREURS

ENOSYS
Le noyau ne prend pas en charge l'obtention de l'horloge temps CPU par processus d'un autre processus, et pid ne spécifie pas le processus appelant.
EPERM
L'appelant n'a pas la permission d'accéder à l'horloge temps CPU du processus spécifié par pid. (Spécifié dans POSIX.1-2001 ; ne se produit pas sous Linux à moins que le noyau ne prenne pas en charge l'obtention de l'horloge temps CPU par processus d'un autre processus.)
ESRCH
Il n'existe aucun processus avec l'ID pid.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
clock_getcpuclockid () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.2. POSIX.1-2001.

NOTES

Appeler clock_gettime(2) avec l'identifiant d'horloge obtenu par un appel à clock_getcpuclockid() avec un pid de 0, est équivalent à utiliser l'identifiant d'horloge CLOCK_PROCESS_CPUTIME_ID.

EXEMPLES

Le programme exemple ci-dessous obtient l'ID de l'horloge temps CPU du processus dont l'ID est donné sur la ligne de commande, puis utilise clock_gettime(2) pour obtenir le temps sur cette horloge. Un exemple d'exécution est le suivant :


$ ./a.out 1                 # Afficher l'horloge CPU du processus init
Horloge temps CPU pour PID 1 est 2.213466748 secondes

Source du programme

#define _XOPEN_SOURCE 600
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    clockid_t clockid;
    struct timespec ts;
    if (argc != 2) {
        fprintf(stderr, "%s <process-ID>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    if (clock_getcpuclockid(atoi(argv[1]), &clockid) != 0) {
        perror("clock_getcpuclockid");
        exit(EXIT_FAILURE);
    }
    if (clock_gettime(clockid, &ts) == -1) {
        perror("clock_gettime");
        exit(EXIT_FAILURE);
    }
    printf("CPU-time clock for PID %s is %jd.%09ld seconds\n",
           argv[1], (intmax_t) ts.tv_sec, ts.tv_nsec);
    exit(EXIT_SUCCESS);
}
