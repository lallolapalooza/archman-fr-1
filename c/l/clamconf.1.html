NOM

clamconf - utilitaire de configuration de Clam AntiVirus

SYNTAXE

clamconf [options]

DESCRIPTION

clamconf affiche les valeurs des options de configuration.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche la version du logiciel et quitte.
-c DIR, --config-dir DIR
Recherche les fichiers de configuration clamd.conf et freshclam.conf dans DIR.
-n, --non-default
N'affiche que les paramètres non-défaut.
-g CONFIG_NAME, --generate-config=CONFIG_NAME
Génère un fichier de configuration d'exemple.

CRÉDITS
