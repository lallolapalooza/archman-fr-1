sous-routine clarge (entier n, complexe, dimension( lda, * ) a, entier lda, entier, dimension( 4 ) iseed, complexe, dimension( * ) work, entier info)

CLARGE

But:

!>
!> CLARGE pré- et post-multiplie une matrice complexe générale n par n A
!> par une matrice unitaire aléatoire : A = U*D*U'.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          En entrée, la matrice A originale n par n.
!>          En sortie, A est écrasé par U*A*U' pour une matrice unitaire
!>          aléatoire U.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= N.
!>

ISEED

!>          ISEED est un tableau ENTIER, de dimension (4)
!>          En entrée, la graine du générateur de nombres aléatoires ; les
!>          éléments du tableau doivent être compris entre 0 et 4095, et
!>          ISEED(4) doit être impair.
!>          En sortie, la graine est mise à jour.
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (2*N)
!>

INFO

!>          INFO est ENTIER
!>          = 0: succès
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
