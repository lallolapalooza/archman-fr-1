CLOCK_GETCPUCLOCKID(3P) Manuel du programmeur POSIX CLOCK_GETCPUCLOCKID(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

clock_getcpuclockid — accéder à l'horloge de temps CPU d'un processus (TEMPS RÉEL AVANCÉ)

SYNTAXE

#include <time.h>
int clock_getcpuclockid(pid_t pid, clockid_t *clock_id);

DESCRIPTION

La fonction clock_getcpuclockid() doit retourner l'identifiant d'horloge de l'horloge de temps CPU du processus spécifié par pid. Si le processus décrit par pid existe et que le processus appelant a les permissions nécessaires, l'identifiant d'horloge de cette horloge doit être retourné dans clock_id.

Si pid est zéro, la fonction clock_getcpuclockid() doit retourner l'identifiant d'horloge de l'horloge de temps CPU du processus qui effectue l'appel, dans clock_id.

Les conditions dans lesquelles un processus a la permission d'accéder à l'identifiant d'horloge de temps CPU d'autres processus sont définies par l'implémentation.

VALEUR DE RETOUR

En cas de succès, clock_getcpuclockid() doit retourner zéro ; sinon, un numéro d'erreur doit être retourné pour indiquer l'erreur.

ERREURS

La fonction clock_getcpuclockid() peut échouer si :

EPERM
Le processus demandeur n'a pas la permission d'accéder à l'horloge de temps CPU pour le processus.

La fonction clock_getcpuclockid() peut échouer si :

ESRCH
Aucun processus ne correspond au processus spécifié par pid.
