fonction réelle cla_syrcond_x (caractère uplo, entier n, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldaf, * ) af, entier ldaf, entier, dimension( * ) ipiv, complexe, dimension( * ) x, entier info, complexe, dimension( * ) work, réel, dimension( * ) rwork)

CLA_SYRCOND_X calcule le nombre de condition en norme infinie de op(A)*diag(x) pour les matrices indéfinies symétriques.

Objectif :

!>
!>    CLA_SYRCOND_X Calcule le nombre de condition en norme infinie de
!>    op(A) * diag(X) où X est un vecteur COMPLEXE.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U' : La partie triangulaire supérieure de A est stockée ;
!>       = 'L' : La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N-par-N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEXE, de dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L tels que calculés par CSYTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>     Détails des échanges et de la structure par blocs de D
!>     tels que déterminés par CSYTRF.
!>

X

!>          X est un tableau COMPLEXE, de dimension (N)
!>     Le vecteur X dans la formule op(A) * diag(X).
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Succès de l'exécution.
!>     i > 0 : Le i-ème argument est invalide.
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (2*N).
!>     Espace de travail.
!>

RWORK

!>          RWORK est un tableau RÉEL, de dimension (N).
!>     Espace de travail.
!>
