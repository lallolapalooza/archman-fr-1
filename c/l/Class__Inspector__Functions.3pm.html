Class::Inspector::Functions(3) Documentation Perl fournie par l'utilisateur Class::Inspector::Functions(3)

NOM

Class::Inspector::Functions - Obtenir des informations sur une classe et sa structure

VERSION

version 1.36

SYNOPIS

use Class::Inspector::Functions;
# Class::Inspector fournit une interface non intrusive,
# basée sur des méthodes !

# Une classe est-elle installée et/ou chargée ?
installed( 'Foo::Class' );
loaded( 'Foo::Class' );

# Informations relatives au fichier
filename( 'Foo::Class' );
resolved_filename( 'Foo::Class' );

# Obtenir des informations relatives aux sous-routines
functions( 'Foo::Class' );
function_refs( 'Foo::Class' );
function_exists( 'Foo::Class', 'bar' );
methods( 'Foo::Class', 'full', 'public' );

# Trouver toutes les sous-classes chargées ou quelque chose
subclasses( 'Foo::Class' );

DESCRIPTION

Class::Inspector::Functions est une interface basée sur des fonctions de Class::Inspector. Pour une documentation complète des fonctions disponibles, veuillez consulter le manuel du module principal.

Exportations

Les fonctions suivantes sont exportées par défaut.

installed
loaded
filename
functions
methods
subclasses

Les fonctions suivantes sont exportées uniquement sur demande.

resolved_filename
loaded_filename
function_refs
function_exists

Toutes les fonctions peuvent être importées en utilisant la balise ":ALL".
