subroutine clatsqr (m, n, mb, nb, a, lda, t, ldt, work, lwork, info)
CLATSQR

Documentation de fonction/sous-routine

sous-routine clatsqr (integer m, integer n, integer mb, integer nb, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( * ) work, integer lwork, integer info)

CLATSQR

Objectif:

!>
!> CLATSQR calcule une factorisation QR bloquée Tall-Skinny d'une
!> matrice complexe A de taille M par N pour M >= N :
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> où :
!>
!>    Q est une matrice orthogonale M par M, stockée à la sortie sous forme implicite
!>    dans les éléments sous la diagonale du tableau A et dans
!>    les éléments du tableau T ;
!>
!>    R est une matrice triangulaire supérieure N par N, stockée à la sortie dans
!>    les éléments sur et au-dessus de la diagonale du tableau A.
!>
!>    0 est une matrice nulle (M-N)-par-N, et n'est pas stockée.
!>
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB

!>          MB est INTEGER
!>          La taille de bloc par ligne à utiliser dans la QR bloquée.
!>          MB > N.
!>

NB

!>          NB est INTEGER
!>          La taille de bloc par colonne à utiliser dans la QR bloquée.
!>          N >= NB >= 1.
!>

A

!>          A est tableau de type COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M par N.
!>          À la sortie, les éléments sur et au-dessus de la diagonale
!>          du tableau contiennent la matrice triangulaire supérieure N par N, R ;
!>          les éléments sous la diagonale représentent Q par les colonnes
!>          de V bloqués (voir Détails supplémentaires).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est tableau de type COMPLEX,
!>          dimension (LDT, N * Nombre_de_blocs_lignes)
!>          où Nombre_de_blocs_lignes = CEIL((M-N)/(MB-N))
!>          Les réflecteurs de bloc triangulaires supérieurs stockés sous forme compacte
!>          sous forme d'une séquence de blocs triangulaires supérieurs.
!>          Voir Détails supplémentaires ci-dessous.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T.  LDT >= NB.
!>

WORK

!>          (espace de travail) tableau de type COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK minimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et LWORK >= NB*N sinon.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille minimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  exécution réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!> QR Tall-Skinny (TSQR) effectue une QR par une séquence de transformations orthogonales,
!> représentant Q comme un produit d'autres matrices orthogonales
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> où chaque Q(i) annule les entrées sous-diagonales d'un bloc de MB lignes de A :
!>   Q(1) annule les entrées sous-diagonales des lignes 1:MB de A
!>   Q(2) annule les MB-N lignes inférieures des lignes [1:N,MB+1:2*MB-N] de A
!>   Q(3) annule les MB-N lignes inférieures des lignes [1:N,2*MB-N+1:3*MB-2*N] de A
!>   . . .
!>
!> Q(1) est calculé par GEQRT, qui représente Q(1) par des vecteurs de Householder
!> stockés sous la diagonale des lignes 1:MB de A, et par des réflecteurs de bloc
!> triangulaires supérieurs, stockés dans le tableau T(1:LDT,1:N).
!> Pour plus d'informations, voir Détails supplémentaires dans GEQRT.
!>
!> Q(i) pour i>1 est calculé par TPQRT, qui représente Q(i) par des vecteurs de Householder
!> stockés dans les lignes [(i-1)*(MB-N)+N+1:i*(MB-N)+N] de A, et par des réflecteurs de bloc
!> triangulaires supérieurs, stockés dans le tableau T(1:LDT,(i-1)*N+1:i*N).
!> Le dernier Q(k) peut utiliser moins de lignes.
!> Pour plus d'informations, voir Détails supplémentaires dans TPQRT.
!>
!> Pour plus de détails sur l'algorithme global, voir la description de
!> TSQR Séquentiel à la section 2.2 de [1].
!>
!> [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>
