sous programme claein (logical rightv, logical noinit, integer n, complex, dimension( ldh, * ) h, integer ldh, complex w, complex, dimension( * ) v, complex, dimension( ldb, * ) b, integer ldb, real, dimension( * ) rwork, real eps3, real smlnum, integer info)

CLAEIN calcule un vecteur propre droit ou gauche spécifié d'une matrice de Hessenberg supérieure par itération inverse.

But :

!>
!> CLAEIN utilise l'itération inverse pour trouver un vecteur propre
!> droit ou gauche correspondant à la valeur propre W d'une matrice de
!> Hessenberg supérieure complexe H.
!>

Paramètres

RIGHTV 
!>          RIGHTV est LOGICAL
!>          = .VRAI. : calculer le vecteur propre droit ;
!>          = .FAUX. : calculer le vecteur propre gauche.
!>

NOINIT

!>          NOINIT est LOGICAL
!>          = .VRAI. : aucun vecteur initial n'est fourni dans V
!>          = .FAUX. : le vecteur initial est fourni dans V.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice H.  N >= 0.
!>

H

!>          H est un tableau COMPLEX, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>

LDH

!>          LDH est INTEGER
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

W

!>          W est COMPLEX
!>          La valeur propre de H dont le vecteur propre droit ou gauche
!>          correspondant doit être calculé.
!>

V

!>          V est un tableau COMPLEX, dimension (N)
!>          En entrée, si NOINIT = .FAUX., V doit contenir un vecteur de
!>          démarrage pour l'itération inverse ; sinon, V n'a pas besoin d'être
!>          défini.
!>          En sortie, V contient le vecteur propre calculé, normalisé de telle
!>          sorte que le composant de magnitude la plus grande ait une magnitude
!>          de 1 ; ici, la magnitude d'un nombre complexe (x,y) est prise comme
!>          |x| + |y|.
!>

B

!>          B est un tableau COMPLEX, dimension (LDB,N)
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

RWORK

!>          RWORK est un tableau REAL, dimension (N)
!>

EPS3

!>          EPS3 est REAL
!>          Une petite valeur dépendant de la machine qui est utilisée pour
!>          perturber des valeurs propres proches, et pour remplacer les pivots
!>          nuls.
!>

SMLNUM

!>          SMLNUM est REAL
!>          Une valeur dépendant de la machine proche du seuil de sous-dépassement.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          = 1 : l'itération inverse n'a pas convergé ; V est défini comme la
!>                dernière itération.
!>
