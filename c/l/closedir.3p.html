CLOSEDIR(3P) Manuel du programmeur POSIX CLOSEDIR(3P)

PROLOG

Cette page man fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page man Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

closedir — fermer un flux de répertoire

SYNTAXE

#include <dirent.h>
int closedir(DIR *dirp);

DESCRIPTION

La fonction closedir() ferme le flux de répertoire référencé par l'argument dirp. Au retour, la valeur de dirp peut ne plus pointer vers un objet accessible de type DIR. Si un descripteur de fichier est utilisé pour implémenter le type DIR, ce descripteur de fichier est fermé.

VALEUR DE RETOUR

En cas de succès, closedir() renvoie 0 ; sinon, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

La fonction closedir() peut échouer si :

EBADF
L'argument dirp ne référence pas un flux de répertoire ouvert.
EINTR
La fonction closedir() a été interrompue par un signal.

EXEMPLES

Fermeture d'un flux de répertoire

Le fragment de programme suivant montre comment la fonction closedir() est utilisée.

...
    DIR *dir;
    struct dirent *dp;
...
    if ((dir = opendir (".")) == NULL) {
...
    }
    while ((dp = readdir (dir)) != NULL) {
...
    }
    closedir(dir);
...
