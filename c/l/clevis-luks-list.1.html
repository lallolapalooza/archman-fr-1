NOM

clevis-luks-list - Liste les broches liées à un périphérique LUKS

SYNOPSIS

clevis luks list -d DEV [-s SLT]

APERÇU

La commande clevis luks list liste les broches liées à un périphérique LUKS. Par exemple :

clevis luks list -d /dev/sda1

OPTIONS

•-d DEV : Le périphérique LUKS sur lequel lister les broches liées
•-s SLT : L'emplacement (slot) à utiliser pour lister la broche

EXEMPLES

clevis luks list -d /dev/sda1
1: sss '{"t":1,"pins":{"tang":[{"url":"addr1"},{"url":"addr2"}],"tpm2":[{"hash":"sha256","key":"ecc"}],"sss":{"t":1,"pins":{"tang":[{"url":"addr3"}]}}}}'
2: tang '{"url":"addr"}'
3: tpm2 '{"hash":"sha256","key":"ecc","pcr_bank":"sha1","pcr_ids":"7"}'

Comme nous pouvons le voir dans l'exemple ci-dessus, /dev/sda1 a trois emplacements liés chacun avec une broche différente.

•L'emplacement n°1 est lié avec la broche sss, et utilise également les broches tang et tpm2 dans sa politique.
•L'emplacement n°2 est lié en utilisant la broche tang
•L'emplacement n°3 est lié avec la broche tpm2

Notez que la sortie de clevis luks list peut être utilisée avec la commande clevis luks bind, comme suit :

clevis luks bind -d /dev/sda1 tpm2 '{"hash":"sha256","key":"ecc","pcr_bank":"sha1","pcr_ids":"7"}'

Et nous lierons un autre emplacement avec une politique similaire à celle que nous avons dans l'emplacement n°3. Notez également que si vous êtes intéressé par un emplacement particulier, vous pouvez passer l'argument -s SLT à clevis luks list :

clevis luks list -d /dev/sda1 -s 2
2: tang '{"url":"addr"}'

Dans l'exemple ci-dessus, nous avons listé uniquement la broche liée à l'emplacement n°2.
