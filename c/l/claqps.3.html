Documentation de la fonction/sous-routine

sous-routine claqps (integer m, integer n, integer offset, integer nb, integer kb, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, complex, dimension( * ) tau, real, dimension( * ) vn1, real, dimension( * ) vn2, complex, dimension( * ) auxv, complex, dimension( ldf, * ) f, integer ldf)

CLAQPS calcule une étape de la factorisation QR avec pivotement de colonnes d'une matrice réelle m-par-n A en utilisant BLAS niveau 3.

But :

!>
!> CLAQPS calcule une étape de la factorisation QR avec pivotement
!> d'une matrice complexe M-par-N A en utilisant Blas-3. Il essaie de factoriser
!> NB colonnes de A à partir de la ligne OFFSET+1, et met à jour toute
!> la matrice avec Blas-3 xGEMM.
!>
!> Dans certains cas, en raison d'annulations catastrophiques, il ne peut pas
!> factoriser NB colonnes. Par conséquent, le nombre réel de colonnes factorisées
!> est retourné dans KB.
!>
!> Le bloc A(1:OFFSET,1:N) est correctement pivoté, mais pas factorisé.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0
!>

OFFSET

!>          OFFSET est ENTIER
!>          Le nombre de lignes de A qui ont été factorisées dans
!>          les étapes précédentes.
!>

NB

!>          NB est ENTIER
!>          Le nombre de colonnes à factoriser.
!>

KB

!>          KB est ENTIER
!>          Le nombre de colonnes effectivement factorisées.
!>

A

!>          A est tableau COMPLEXE, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M-par-N.
!>          À la sortie, le bloc A(OFFSET+1:M,1:KB) est le facteur
!>          triangulaire obtenu et le bloc A(1:OFFSET,1:N) a été
!>          correctement pivoté, mais pas factorisé.
!>          Le reste de la matrice, bloc A(OFFSET+1:M,KB+1:N), a été
!>          mis à jour.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

JPVT

!>          JPVT est tableau ENTIER, dimension (N)
!>          JPVT(I) = K <==> La colonne K de la matrice complète A a été
!>          permée à la position I dans AP.
!>

TAU

!>          TAU est tableau COMPLEXE, dimension (KB)
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

VN1

!>          VN1 est tableau RÉEL, dimension (N)
!>          Le vecteur avec les normes partielles des colonnes.
!>

VN2

!>          VN2 est tableau RÉEL, dimension (N)
!>          Le vecteur avec les normes exactes des colonnes.
!>

AUXV

!>          AUXV est tableau COMPLEXE, dimension (NB)
!>          Vecteur auxiliaire.
!>

F

!>          F est tableau COMPLEXE, dimension (LDF,NB)
!>          Matrice F**H = L * Y**H * A.
!>

LDF

!>          LDF est ENTIER
!>          La dimension principale du tableau F. LDF >= max(1,N).
!>
