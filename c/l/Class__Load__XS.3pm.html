NOM

Class::Load::XS - Implémentation XS de parties de Class::Load

VERSION

version 0.10

SYNOPIS

use Class::Load;

DESCRIPTION

Ce module fournit une implémentation XS pour des portions de Class::Load. Voir Class::Load pour les détails de l'API.
