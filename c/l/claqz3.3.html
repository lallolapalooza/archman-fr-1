But :

!>
!> CLAQZ3 Exécute un seul balayage QZ multi-décalages
!>

Paramètres

ILSCHUR 
!>          ILSCHUR est LOGICAL
!>              Détermine si la forme de Schur complète doit être mise à jour ou non
!>

ILQ

!>          ILQ est LOGICAL
!>              Détermine si la matrice Q doit être mise à jour ou non
!>

ILZ

!>          ILZ est LOGICAL
!>              Détermine si la matrice Z doit être mise à jour ou non
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, Q et Z.  N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>

NSHIFTS

!>          NSHIFTS est INTEGER
!>          Le nombre de décalages souhaité à utiliser
!>

NBLOCK_DESIRED

!>          NBLOCK_DESIRED est INTEGER
!>          La taille souhaitée des fenêtres de calcul
!>

ALPHA

!>          ALPHA est un tableau COMPLEXE
!>          contient les parties alpha des décalages à utiliser.
!>

BETA

!>          BETA est un tableau COMPLEXE
!>          contient l'échelle des décalages à utiliser.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA, N)
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max( 1, N ).
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB, N)
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max( 1, N ).
!>

Q

!>          Q est un tableau COMPLEXE, dimension (LDQ, N)
!>

LDQ

!>          LDQ est INTEGER
!>

Z

!>          Z est un tableau COMPLEXE, dimension (LDZ, N)
!>

LDZ

!>          LDZ est INTEGER
!>

QC

!>          QC est un tableau COMPLEXE, dimension (LDQC, NBLOCK_DESIRED)
!>

LDQC

!>          LDQC est INTEGER
!>

ZC

!>          ZC est un tableau COMPLEXE, dimension (LDZC, NBLOCK_DESIRED)
!>

LDZC

!>          LDZ est INTEGER
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO >= 0, WORK(1) contient la taille LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.  LWORK >= max(1,N).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
