NOM

clevis-luks-edit - Modifier une liaison d'un slot clevis dans un périphérique LUKS

SYNTAXE

clevis luks edit [-f] -d DEV -s SLT [-c CONFIG]

APERÇU

La commande clevis luks edit modifie les liaisons clevis d'un périphérique LUKS. Par exemple :

clevis luks edit -d /dev/sda1 -s 1

OPTIONS

•-d DEV : Le périphérique LUKS pour modifier les broches liées par clevis
•-s SLT : Le slot à utiliser lors de la modification de la liaison clevis
•-f : Continuer l'opération de modification même si la configuration n'a pas changé
•-c CONFIG : La configuration mise à jour à utiliser

EXEMPLES

clevis luks list -d /dev/sda1
1: tang '{"url":"addr"}'

Comme nous pouvons le voir dans l'exemple ci-dessus, /dev/sda1 a un slot lié, dans ce cas, à une broche tang.

Nous pouvons modifier cette liaison en lançant la commande suivante :

clevis luks edit -d /dev/sda1 -s 1

Cela ouvrira un éditeur de texte — celui défini dans la variable d'environnement $EDITOR, ou vi, par défaut — avec la configuration actuelle de cette liaison à modifier. Dans ce cas, nous devrions avoir ce qui suit :

{
    "url": "addr"
}

Une fois dans l'éditeur, nous pouvons modifier la configuration de la broche. Pour tang, nous pourrions modifier l' url, par exemple. Après avoir terminé le changement, sauvegardez le fichier et quittez. La configuration mise à jour sera validée pour JSON, et s'il n'y a pas d'erreurs, vous verrez la configuration mise à jour et il vous sera demandé si vous souhaitez continuer.

En continuant, la liaison sera mise à jour. Il pourra être requis de fournir une phrase de passe LUKS valide pour le périphérique.

Dans le deuxième exemple, nous mettrons à jour le même périphérique et le même slot, mais nous fournirons également la configuration mise à jour :

clevis luks edit -d /dev/sda1 -s 1 -c '{"url":"new-addr-here"}'

Dans ce cas, la mise à jour de la liaison se fera en mode non interactif. Notez qu'il pourra également être requis de fournir une phrase de passe LUKS pour le périphérique.
