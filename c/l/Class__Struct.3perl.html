DESCRIPTIO

N

"Class::Struct" exporte une seule fonction, "struct". Étant donné une liste de noms et de types d'éléments, et éventuellement un nom de classe, "struct" crée une classe Perl 5 qui implémente une structure de données de type

"struct".

La nouvelle classe reçoit une méthode constructeur, "new", pour créer des objets

struct.

Chaque élément dans la donnée struct possède une méthode accesseur, qui est utilisée pour assigner à l'élément et pour récupérer sa valeur. L'accesseur par défaut peut être remplacé en déclarant un "sub" du même nom dans le paquet. (Voir l'exemple 2.

)

Le type de chaque élément peut être scalaire, tableau, hash ou

classe.

La fonction

struct()

La fonction "struct" a trois formes de liste de

paramètres. 
struct( CLASS_NAME => [ ELEMENT_LIST ]);
struct( CLASS_NAME => { ELEMENT_LIST });
struct( ELEMENT_LIST )
;

Les première et deuxième formes identifient explicitement le nom de la classe créée. La troisième forme suppose que le nom du paquet courant est le nom de la

classe.

Un objet d'une classe créée par les première et troisième formes est basé sur un tableau, tandis qu'un objet d'une classe créée par la deuxième forme est basé sur un hash. Les formes basées sur un tableau seront quelque peu plus rapides et plus petites ; les formes basées sur un hash sont plus

flexibles.

La classe créée par "struct" ne doit pas être une sous-classe d'une autre classe que "UNIVERSAL"

.

Elle peut cependant être utilisée comme superclasse pour d'autres classes. Pour faciliter cela, la méthode constructeur générée utilise un bénissement à deux arguments. De plus, si la classe est basée sur un hash, la clé de chaque élément est préfixée par le nom de la classe (voir Perl Cookbook, recette 13.12)

.

Une fonction nommée "new" ne doit pas être explicitement définie dans une classe créée par "struct"

.

La ELEMENT_LIST a la

forme 
NAME => TYPE, ..
.

Chaque paire nom-type déclare un élément de la struct. Chaque nom d'élément sera défini comme une méthode accesseur à moins qu'une méthode portant ce nom soit explicitement définie ; dans ce dernier cas, un avertissement est émis si l'indicateur d'avertissement (-w) est

déf
ini.

Création de classe au moment de la

compilation

"Class::Struct" peut créer votre classe au moment de la compilation. La raison principale de le faire est évidente, afin que votre classe se comporte comme toutes les autres classes en Perl. Créer votre classe au moment de la compilation rendra l'ordre des événements similaire à l'utilisation de n'importe quelle autre classe ( ou module Perl )

.

Il n'y a pas de gain de vitesse significatif entre la création de

classe au moment de la compilation et au moment de l'exécution,
il y a simplement un nouvel ordre des événements, plus standard.

Types d'éléments et méthodes

accesseurs

Les quatre types d'éléments -- scalaire, tableau, hash et classe -- sont représentés par des chaînes -- '$', '@', '%', et un nom de classe -- éventuellement précédées d'un '*'

.

La méthode accesseur fournie par "struct" pour un élément dépend du type déclaré de

l'élément.
Scalaire ('$' ou
'*$')
L'élément est un scalaire, et est initialisé par défaut à "undef" (mais voir "Initialisation avec new").

L'argument de l'accesseur, s'il y en a un, est assigné à

l'élément.

Si le type d'élément est '$', la valeur de l'élément (après assignation) est retournée. Si le type d'élément est '*$', une référence vers

l'élément es
t retournée.
Tableau ('@' ou
'*@')
L'élément est un tableau, initialisé par défaut à "()".

Sans argument, l'accesseur retourne une référence vers le tableau entier de l'élément (que l'élément ait été spécifié comme '@' ou '*@'

).

Avec un ou deux arguments, le premier argument est un index spécifiant un élément du tableau ; le second argument, s'il est présent, est assigné à l'élément du tableau. Si le type d'élément est '@', l'accesseur retourne la valeur de l'élément du tableau. Si le type d'élément est '*@', une référence vers l'élément du tableau est

retournée.

Comme cas particulier, lorsque l'accesseur est appelé avec une réfé

rence de tableau comme unique argument, cela provoque l'assignation
de l'élément de tableau entier. La référence d'objet est retournée.
Hash ('%' ou
'*%')
L'élément est un hash, initialisé par défaut à "()".

Sans argument, l'accesseur retourne une référence vers le hash entier de l'élément (que l'élément ait été spécifié comme '%' ou '*%'

).

Avec un ou deux arguments, le premier argument est une clé spécifiant un élément du hash ; le second argument, s'il est présent, est assigné à l'élément du hash. Si le type d'élément est '%', l'accesseur retourne la valeur de l'élément du hash. Si le type d'élément est '*%', une référence vers l'élément du hash est

retournée.

Comme cas particulier, lorsque l'accesseur est appelé avec une ré

férence de hash comme unique argument, cela provoque l'assignation
de l'élément de hash entier. La référence d'objet est retournée.
Classe ('Class_Name' ou
'*Class_Name')
La valeur de l'élément doit être une référence bénie vers la classe nommée ou vers l'une de ses sous-classes. L'élément n'est pas initialisé par défaut.

L'argument de l'accesseur, s'il y en a un, est assigné à l'élément. L'accesseur "croakera" si ce n'est pas une référence d'objet

appropriée.

Si le type d'élément ne commence pas par un '*', l'accesseur retourne la valeur de l'élément (après assignation). Si le type d'élément commence par un '*', une référence

vers l'él
ément lui-
même est r
etournée. ">

Initialisation avec

"new"

"struct" crée toujours un constructeur appelé "new". Ce constructeur peut prendre une liste d'initialisateurs pour les différents éléments de la nouvelle

struct.

Chaque initialisateur est une paire de valeurs : nom de l'élément" => "valeur. La valeur d'initialisation pour un élément scalaire est simplement une valeur scalaire. L'initialisateur pour un élément de tableau est une référence de tableau. L'initialisateur pour un hachage est une référence de

hachage.

L'initialisateur pour un élément de classe est un objet de la classe correspondante, ou de l'une de ses sous-classes, ou une référence à un hachage contenant des arguments nommés à passer au constructeur de

l'élément.

Voir l'exemple 3 ci-dessous pour un exemple

d'initialisatio
n
.

EXEMPLE

S
Exemple
1
Donner à un élément de struct un type de classe qui est lui-même une struct est la façon dont les structs sont imbriquées. Ici, "Timeval" représente un temps (secondes et microsecondes), et "Rusage" a deux éléments, chacun étant de type "Timeval". 
use Class::Struct;
struct( Rusage => {
    ru_utime => 'Timeval',  # user time used
    ru_stime => 'Timeval',  # system time used
});
struct( Timeval => [
    tv_secs  => '$',        # sec
onds tv_usecs => '$', # microseconds ]); # create an object: my $t = Rusage->new(ru_utime=>Timeval->new(), ru_stime=>Timeval->new()); # $t->ru_utime and $t->ru_stime are obje
cts of type Timeval. # set $t->ru_utime to 100.0 sec and $t->ru_stime to 5.0 sec. $t->ru_utime->tv_secs(100); $t->ru_utime->tv_usecs(0); $t->ru_stime->tv_secs(5); $t->ru_stime->tv_usecs(0);
Exemple
2
Une fonction d'accès peut être redéfinie afin de fournir une vérification supplémentaire des valeurs, etc. Ici, nous voulons que l'élément "count" soit toujours non négatif, nous redéfinissons donc l'accès "count" en conséquence. 
package MyObj;
use Class::Struct;
# declare the struct
struct ( 'MyObj', { count => '$', stuff => '%' } );
# override the default accessor method for 'count'
sub count {
    my $self = shift;
    if ( @_ ) {
        die 'count must be non
negative' if $_[0] < 0; $self->{'MyObj::count'} = shift; warn "Too many args to count" if @_; } return $self->{'MyObj::count'}; } package main; $x = new MyObj; print "\$x->count(5) = ", $x->count(5), "\n";
# prints '$x->count(5) = 5' print "\$x->count = ", $x->count, "\n"; # prints '$x->count = 5' print "\$x->count(-5) = ", $x->count(-5), "\n"; # dies due to negative argument!
Exemple
3
Le constructeur d'une classe générée peut recevoir une liste de élément=>paires de valeurs, avec lesquelles initialiser la struct. Si aucun initialisateur n'est spécifié pour un élément particulier, son initialisation par défaut est effectuée à la place. Les initialisateurs pour des éléments inexistants sont silencieusement ignorés.

Notez que l'initialisateur pour une classe imbriquée peut être spécifié comme un objet de cette classe, ou comme une référence à un hachage d'initialisateurs qui sont transmis au constructeur de la struct

imbriquée. 
use Class::Struct;
struct Breed =>
{
    name  => '$',
    cross => '$',
};
struct Cat =>
[
    name     => '$',
    kittens
=> '@', markings => '%', breed => 'Breed', ]; my $cat = Cat->new( name => 'Socks', kittens => ['Mo
nica', 'Kenneth'], markings => { socks=>1, blaze=>"white" }, breed => Breed->new(name=>'short-hair'
, cross=>1), or: breed => {name=>'short-hair', cross=>1}, ); print "Once a cat called ", $cat->
name, "\n"; print "(which was a ", $cat->breed->name, ")\n"; print "had 2 kittens: ", join(' and ', @{$cat->kittens}), "\n";

Auteur et historique des

modifications

Modifié par Damian Conway, 2001-09-10, v0.

62. 
Construction implicite des objets imbriqués modifiée.
Accepte désormais une référence d'objet au lieu d'exiger une référence de hachage.
Initialise également par défaut les attributs d'objet imbriqués à undef, plutôt
que d'appeler le constructeur d'objet sans arguments.
La sur-aide originale était pleine de problèmes :
    * le constructeur de la classe pourrait ne pas s'appeler 'new'
    * la classe pourrait ne pas avoir de constructeur avec des arguments de type hachage
    * la classe pourrait ne pas avoir de constructeur sans argument
    * les structures de données "récursives" ne fonctionnaient pas bien :
              package Person;
              struct { mother => 'Person', father => 'Person'}
;
