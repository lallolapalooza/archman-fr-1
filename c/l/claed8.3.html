sous-routine claed8 (integer k, integer n, integer qsiz, complex, dimension( ldq, * ) q, integer ldq, real, dimension( * ) d, real rho, integer cutpnt, real, dimension( * ) z, real, dimension( * ) dlambda, complex, dimension( ldq2, * ) q2, integer ldq2, real, dimension( * ) w, integer, dimension( * ) indxp, integer, dimension( * ) indx, integer, dimension( * ) indxq, integer, dimension( * ) perm, integer givptr, integer, dimension( 2, * ) givcol, real, dimension( 2, * ) givnum, integer info)

CLAED8 utilisée par CSTEDC. Fusionne les valeurs propres et met en déflation l'équation séculaire. Utilisée lorsque la matrice d'origine est dense.

But :

!>
!> CLAED8 fusionne les deux ensembles de valeurs propres en un ensemble
!> unique trié. Elle essaie ensuite de réduire la taille du problème par
!> déflation. Il existe deux façons dont la déflation peut survenir : lorsque
!> deux valeurs propres ou plus sont proches l'une de l'autre, ou s'il existe
!> un élément minuscule dans le vecteur Z. Pour chaque occurrence de ce type,
!> l'ordre du problème d'équation séculaire associé est réduit d'une unité.
!>

Paramètres

K 
!>          K est INTEGER
!>         Contient le nombre de valeurs propres non déflatées.
!>         C'est l'ordre de l'équation séculaire associée.
!>

N

!>          N est INTEGER
!>         La dimension de la matrice symétrique tridiagonale.  N >= 0.
!>

QSIZ

!>          QSIZ est INTEGER
!>         La dimension de la matrice unitaire utilisée pour réduire
!>         la matrice dense ou bande à une forme tridiagonale.
!>         QSIZ >= N si ICOMPQ = 1.
!>

Q

!>          Q est un tableau COMPLEX, dimension (LDQ,N)
!>         À l'entrée, Q contient les vecteurs propres du système
!>         partiellement résolu qui a été mis à jour lors de
!>         multiplications matricielles avec d'autres systèmes propres
!>         partiellement résolus.
!>         À la sortie, Q contient les (N-K) vecteurs propres mis à jour
!>         restants (ceux qui ont été déflatés) dans ses N-K dernières colonnes.
!>

LDQ

!>          LDQ est INTEGER
!>         La dimension principale du tableau Q.  LDQ >= max( 1, N ).
!>

D

!>          D est un tableau REAL, dimension (N)
!>         À l'entrée, D contient les valeurs propres des deux sous-matrices
!>         à combiner. À la sortie, D contient les (N-K) valeurs propres mises
!>         à jour restantes (celles qui ont été déflatées) triées par ordre
!>         croissant.
!>

RHO

!>          RHO est REAL
!>         Contient l'élément hors diagonale associé à la coupe de rang 1
!>         qui a initialement divisé les deux sous-matrices qui sont
!>         maintenant recombinaison. RHO est modifié pendant le calcul
!>         à la valeur requise par SLAED3.
!>

CUTPNT

!>          CUTPNT est INTEGER
!>         Contient la position de la dernière valeur propre dans la
!>         sous-matrice principale.  MIN(1,N) <= CUTPNT <= N.
!>

Z

!>          Z est un tableau REAL, dimension (N)
!>         En entrée, ce vecteur contient le vecteur de mise à jour (la
!>         dernière ligne de la première matrice de vecteurs propres
!>         partiels et la première ligne de la deuxième matrice de vecteurs
!>         propres partiels). Le contenu de Z est détruit pendant le
!>         processus de mise à jour.
!>

DLAMBDA

!>          DLAMBDA est un tableau REAL, dimension (N)
!>         Contient une copie des K premières valeurs propres qui seront
!>         utilisées par SLAED3 pour former l'équation séculaire.
!>

Q2

!>          Q2 est un tableau COMPLEX, dimension (LDQ2,N)
!>         Si ICOMPQ = 0, Q2 n'est pas référencé. Sinon,
!>         contient une copie des K premiers vecteurs propres qui seront
!>         utilisés par SLAED7 dans une multiplication matricielle (SGEMM)
!>         pour mettre à jour les nouveaux vecteurs propres.
!>

LDQ2

!>          LDQ2 est INTEGER
!>         La dimension principale du tableau Q2.  LDQ2 >= max( 1, N ).
!>

W

!>          W est un tableau REAL, dimension (N)
!>         Cela contiendra les k premières valeurs du vecteur z final
!>         modifié par la déflation et sera transmis à SLAED3.
!>

INDXP

!>          INDXP est un tableau INTEGER, dimension (N)
!>         Cela contiendra la permutation utilisée pour placer les valeurs
!>         déflatées de D à la fin du tableau. En sortie, INDXP(1:K)
!>         pointe vers les valeurs de D non déflatées et INDXP(K+1:N)
!>         pointe vers les valeurs propres déflatées.
!>

INDX

!>          INDX est un tableau INTEGER, dimension (N)
!>         Cela contiendra la permutation utilisée pour trier le contenu
!>         de D par ordre croissant.
!>

INDXQ

!>          INDXQ est un tableau INTEGER, dimension (N)
!>         Cela contient la permutation qui trie séparément les deux
!>         sous-problèmes dans D par ordre croissant. Notez que les éléments
!>         dans la seconde moitié de cette permutation doivent d'abord avoir
!>         CUTPNT ajouté à leurs valeurs afin d'être exacts.
!>

PERM

!>          PERM est un tableau INTEGER, dimension (N)
!>         Contient les permutations (issues de la déflation et du tri) à
!>         appliquer à chaque bloc propre.
!>

GIVPTR

!>          GIVPTR est INTEGER
!>         Contient le nombre de rotations de Givens qui ont eu lieu
!>         dans ce sous-problème.
!>

GIVCOL

!>          GIVCOL est un tableau INTEGER, dimension (2, N)
!>         Chaque paire de nombres indique une paire de colonnes
!>         impliquées dans une rotation de Givens.
!>

GIVNUM

!>          GIVNUM est un tableau REAL, dimension (2, N)
!>         Chaque nombre indique la valeur S à utiliser dans la
!>         rotation de Givens correspondante.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>
