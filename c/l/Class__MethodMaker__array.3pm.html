Class::MethodMaker::array(3) Documentation Perl contribuée par les utilisateurs Class::MethodMaker::array(3)

NOM

Class::Method::array - Créer des méthodes pour gérer une valeur de type tableau.

SYNOPSIS

use Class::MethodMaker
  [ array => [qw/ x /] ];
$instance->x;                # vide
$instance->x(1, 1, 2, 3, 5, 8);
$instance->x_count == 6;     # vrai
$instance->x = (13, 21, 34);
$instance->x_index(1) == 21; # vrai

DESCRIPTION

Crée des méthodes pour gérer des valeurs de tableau dans un objet. Pour un composant nommé "x", crée par défaut les méthodes "x", "x_reset", "x_clear", "x_isset", "x_count", "x_index", "x_push", "x_pop", "x_unshift", "x_shift", "x_splice".

Les méthodes disponibles sont :

"*"

Créée par défaut. Cette méthode renvoie la liste des valeurs stockées dans l'emplacement. Si des arguments sont fournis à cette méthode, ils remplacent le contenu actuel de la liste. Dans un contexte tableau, elle renvoie les valeurs sous forme de tableau, et dans un contexte scalaire sous forme de référence à un tableau. Notez que cette référence n'est plus une référence directe au stockage, contrairement à Class::MethodMaker v1. Cela sert à protéger l'encapsulation. Voir x_ref si vous avez besoin de cette fonctionnalité (et êtes prêt à en assumer le risque associé.) Cette fonction n'auto-déplie plus les références de tableau fournies en arguments, car cela rend difficile la définition de valeurs individuelles à des références de tableau. Voir x_setref pour cette fonctionnalité.

Si une valeur par défaut est en vigueur, cette valeur sera auto-vivifiée (et donc définie) pour chaque valeur non définie (pas not defined) jusqu'au maximum du tableau (les nouveaux éléments ne seront donc pas ajoutés)

*_reset

Créée par défaut. Appelée sans argument, elle réinitialise le composant dans son ensemble ; supprime tout stockage associé et ramène le composant à son état par défaut. Normalement, cela signifie que *_isset renverra faux, et "*" renverra undef. Si "-default" est en vigueur, le composant sera défini à la valeur par défaut, et *_isset renverra vrai. Si "-default_ctor" est en vigueur, la sous-routine par défaut sera invoquée, et sa valeur de retour sera utilisée pour définir la valeur du composant, et *_isset renverra vrai.

Si elle est appelée avec des arguments, ces arguments sont traités comme des index dans le composant, et les éléments individuels ainsi référencés sont réinitialisés (leur stockage est supprimé, de sorte que *_isset(n) renverra faux pour les nappropriés, sauf si "-default" ou "-default_ctor" sont en vigueur, comme ci-dessus). Comme pour les tableaux perl, réinitialiser la valeur définie la plus élevée diminue implicitement le compte (mais x_reset(n) ne désactive jamais l'agrégat lui-même, même si tous les éléments ne sont pas définis).

*_clear

package MyClass;
use Class::MethodMaker
  [ scalar => [{'*_clear' => '*_clear'}, 'a'],
    new    => new, ];
package main;
my $m = MyClass->new;
$m->a(5);
$a = $m->a;       # 5
$x = $m->a_isset; # vrai
$m->a_clear;
$a = $m->a;       # *undef*
$x = $m->a_isset; # vrai

Créée sur demande. Un raccourci pour définir à undef. Notez que le composant sera défini à undef, et non réinitialisé, donc *_isset renverra vrai.

*_isset

Créée par défaut. Indique si le composant est actuellement défini. Cela diffère d'être défini (defined) ; initialement, le composant n'est pas défini (et s'il est lu, renverra undef) ; il peut être défini à undef (ce qui est une valeur définie, qui renvoie également undef). Une fois défini, la seule façon de désactiver le composant est avec <*_reset>.

Si une valeur par défaut est en vigueur, <*_isset> renverra toujours vrai.

*_isset() teste le composant dans son ensemble. *_isset(a) teste l'élément indexé par a. "*_isset(a,b)" teste les éléments indexés par a, b, et renvoie la conjonction logique (et) des tests.

*_count

Créée par défaut. Renvoie le nombre d'éléments dans ce composant. Cela n'est pas affecté par la présence (ou l'absence) d'un "default" (ou "default_ctor"). Renvoie "undef" si le composant entier n'est pas défini (comme pour *_isset).

*_index

Créée par défaut. Prend une liste d'indices, renvoie une liste des valeurs correspondantes.

Si un défaut (ou un constructeur par défaut) est en vigueur, une recherche par index vivifiera et définira à la valeur par défaut les éléments respectifs (et donc la structure de données agrégée aussi, si ce n'est pas déjà le cas).

Attention à un bug dans perl 5.6.1 qui inventera parfois des valeurs dans des emplacements précédemment non définis de tableaux qui contenaient précédemment une valeur. Ainsi, vivifier une valeur (par exemple par x_index(2)) là où x_index(1) était précédemment non défini pourrait causer x_index(1) à être défini à tort. C'est corrigé en 5.8.0.

*_push

Créée par défaut. Pousse un ou plusieurs éléments à la fin de la liste. Pas de valeur de retour.

*_pop

Créée par défaut. Étant donné un nombre, retire ce nombre d'éléments de la fin de la liste et les renvoie (sous forme de référence en contexte scalaire, sous forme de liste en contexte liste). Sans argument, renvoie toujours un seul élément. Étant donné un nombre, les renvoie dans l'ordre du tableau (et non dans l'ordre inverse comme le feraient plusieurs appels à pop).

*_unshift

Créée par défaut. Pousse un ou plusieurs éléments au début de la liste. Pas de valeur de retour.

*_shift

Créée par défaut. Étant donné un nombre, retire ce nombre d'éléments du début de la liste et les renvoie (sous forme de référence en contexte scalaire, sous forme de liste en contexte liste). Sans argument, renvoie toujours un seul élément. Étant donné un nombre, les renvoie dans l'ordre du tableau.

*_splice

Créée par défaut. Arguments comme pour perldoc perlfunc splice. Renvoie une référence de tableau en contexte scalaire (même si un seul élément est extrait), et une liste en contexte liste.

*_get

Créée sur demande. Récupère la valeur du composant sans la définir (ignore tout argument passé).

*_set

@n = $x->a; # (1,2,3)
$x->a_set(1=>4,3=>7);
@n = $x->a; # (1,4,3,7)

Créée par défaut. Prend une liste, traitée comme des paires index => valeur ; chaque index donné est défini à la valeur correspondante. Pas de retour.

Si deux arguments sont donnés, dont le premier est une référence de tableau, alors elle est traitée comme une liste d'indices dont le deuxième argument (qui doit également être une référence de tableau) sont les valeurs correspondantes. Ainsi les deux commandes suivantes sont équivalentes :

$x->a_set(1=>4,3=>7);
$x->a_set([1,3],[4,7]);
