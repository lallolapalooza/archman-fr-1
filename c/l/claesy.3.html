sous-routine claesy (complex a, complex b, complex c, complex rt1, complex rt2, complex evscal, complex cs1, complex sn1)

CLAESY calcule les valeurs propres et les vecteurs propres d'une matrice complexe symétrique de taille 2x2.

Objectif :

!>
!> CLAESY calcule la décomposition en valeurs propres d'une matrice symétrique 2x2
!>    ( ( A, B );( B, C ) )
!> à condition que la norme de la matrice des vecteurs propres soit supérieure
!> à une certaine valeur seuil.
!>
!> RT1 est la valeur propre de plus grande valeur absolue, et RT2 de
!> plus petite valeur absolue.  Si les vecteurs propres sont calculés, alors
!> au retour ( CS1, SN1 ) est le vecteur propre unitaire pour RT1, donc
!>
!> [  CS1     SN1   ] . [ A  B ] . [ CS1    -SN1   ] = [ RT1  0  ]
!> [ -SN1     CS1   ]   [ B  C ]   [ SN1     CS1   ]   [  0  RT2 ]
!>

Paramètres

A 
!>          A est COMPLEX
!>          L'élément ( 1, 1 ) de la matrice d'entrée.
!>

B

!>          B est COMPLEX
!>          L'élément ( 1, 2 ) de la matrice d'entrée.  L'élément ( 2, 1 )
!>          est également donné par B, car la matrice 2x2 est symétrique.
!>

C

!>          C est COMPLEX
!>          L'élément ( 2, 2 ) de la matrice d'entrée.
!>

RT1

!>          RT1 est COMPLEX
!>          La valeur propre de module plus grand.
!>

RT2

!>          RT2 est COMPLEX
!>          La valeur propre de module plus petit.
!>

EVSCAL

!>          EVSCAL est COMPLEX
!>          La valeur complexe par laquelle la matrice des vecteurs propres a été mise à l'échelle
!>          pour la rendre orthonormée.  Si EVSCAL est zéro, les vecteurs propres
!>          n'ont pas été calculés.  Cela signifie deux choses : la matrice 2x2
!>          n'a pas pu être diagonalisée, ou la norme de la matrice
!>          des vecteurs propres avant mise à l'échelle était supérieure à la valeur seuil
!>          THRESH (définie ci-dessous).
!>

CS1

!>          CS1 est COMPLEX
!>

SN1

!>          SN1 est COMPLEX
!>          Si EVSCAL .NE. 0,  ( CS1, SN1 ) est le vecteur propre droit unitaire
!>          pour RT1.
!>
