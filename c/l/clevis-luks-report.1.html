NOM

clevis-luks-report - Signale si un code PIN lié à un volume LUKS1 ou LUKS2 a été pivoté

SYNTAXE

clevis luks report -d DEV -s SLT

APERÇU

La commande clevis luks report vérifie une fente donnée d'un périphérique LUKS et signale si le code PIN qui y est lié — s'il y en a un — a été pivoté.

OPTIONS

•-d DEV : Le périphérique LUKS lié
•-s SLT : Le numéro de la fente ou de la fente de clé à vérifier pour le code PIN
•-q : Mode silencieux. Si utilisé, nous ne demanderons pas si la liaison doit être régénérée avec clevis luks regen
•-r : Régénère les métadonnées LUKS avec clevis luks regen -q -d DEV -s SLT

EXEMPLE

Vérifiez si le code PIN lié à la fente 1 dans /dev/sda1 a été pivoté :
# clevis luks report -d /dev/sda1 -s 1
