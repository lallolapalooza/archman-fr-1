sous-routine claipd (integer n, complex, dimension( * ) a, integer inda, integer vinda)

CLAIPD

Objectif :

!>
!> CLAIPD définit la partie imaginaire des éléments diagonaux d'une matrice complexe
!> A à une valeur élevée. Ceci est utilisé pour tester les routines LAPACK pour les
!> matrices complexes hermitiennes, qui ne sont pas censées accéder ou utiliser
!> les parties imaginaires des diagonales.
!>

Paramètres

N 
!>          N est un entier
!>         Le nombre d'éléments diagonaux de A.
!>

A

!>          A est un tableau de type COMPLEX, dimension
!>                        (1+(N-1)*INDA+(N-2)*VINDA)
!>         À l'entrée, la matrice complexe (hermitienne) A.
!>         À la sortie, les parties imaginaires des éléments diagonaux sont définies
!>         à BIGNUM = EPS / SAFMIN, où EPS est l'epsilon machine et
!>         SAFMIN est le minimum sûr.
!>

INDA

!>          INDA est un entier
!>         L'incrément entre A(1) et le prochain élément diagonal de A.
!>         Les valeurs typiques sont
!>         = LDA+1 : matrices carrées avec une dimension principale LDA
!>         = 2 : matrice triangulaire supérieure compacte, commençant à A(1,1)
!>         = N : matrice triangulaire inférieure compacte, commençant à A(1,1)
!>

VINDA

!>          VINDA est un entier
!>         Le changement dans l'incrément diagonal entre les colonnes de A.
!>         Les valeurs typiques sont
!>         = 0 : pas de changement, les incréments de ligne et de colonne dans A sont fixes
!>         = 1 : matrice triangulaire supérieure compacte
!>         = -1 : matrice triangulaire inférieure compacte
!>
