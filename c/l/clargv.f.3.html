Documentation de la fonction/sous-routine

sous-routine clargv (integer n, complex, dimension( * ) x, integer incx, complex, dimension( * ) y, integer incy, real, dimension( * ) c, integer incc)

CLARGV génère un vecteur de rotations planes avec des cosinus réels et des sinus complexes.

But :

!>
!> CLARGV génère un vecteur de rotations planes complexes avec des cosinus
!> réels, déterminées par des éléments des vecteurs complexes x et y.
!> Pour i = 1,2,...,n
!>
!>    (        c(i)   s(i) ) ( x(i) ) = ( r(i) )
!>    ( -conjg(s(i))  c(i) ) ( y(i) ) = (   0  )
!>
!>    où c(i)**2 + ABS(s(i))**2 = 1
!>
!> Les conventions suivantes sont utilisées (elles sont les mêmes que dans CLARTG,
!> mais diffèrent de la routine BLAS1 CROTG) :
!>    Si y(i)=0, alors c(i)=1 et s(i)=0.
!>    Si x(i)=0, alors c(i)=0 et s(i) est choisi de sorte que r(i) soit réel.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          Le nombre de rotations planes à générer.
!>

X

!>          X est un tableau COMPLEXE, de dimension (1+(N-1)*INCX)
!>          En entrée, le vecteur x.
!>          En sortie, x(i) est écrasé par r(i), pour i = 1,...,n.
!>

INCX

!>          INCX est un entier (INTEGER)
!>          Le pas entre les éléments de X. INCX > 0.
!>

Y

!>          Y est un tableau COMPLEXE, de dimension (1+(N-1)*INCY)
!>          En entrée, le vecteur y.
!>          En sortie, les sinus des rotations planes.
!>

INCY

!>          INCY est un entier (INTEGER)
!>          Le pas entre les éléments de Y. INCY > 0.
!>

C

!>          C est un tableau RÉEL, de dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations planes.
!>

INCC

!>          INCC est un entier (INTEGER)
!>          Le pas entre les éléments de C. INCC > 0.
!>
