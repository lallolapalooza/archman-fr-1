CLOSE(7) Documentation PostgreSQL 18.1 CLOSE(7)

NOM

CLOSE - fermer un curseur

SYNTAXE

CLOSE { nom | ALL }

DESCRIPTION

CLOSE libère les ressources associées à un curseur ouvert. Après la fermeture du curseur, aucune opération ultérieure n'est autorisée sur celui-ci. Un curseur doit être fermé lorsqu'il n'est plus nécessaire.

Tous les curseurs ouverts non conservables sont implicitement fermés lorsqu'une transaction est terminée par COMMIT ou ROLLBACK. Un curseur conservable est implicitement fermé si la transaction qui l'a créé est annulée via ROLLBACK. Si la transaction créatrice est validée avec succès, le curseur conservable reste ouvert jusqu'à ce qu'un CLOSE explicite soit exécuté, ou que le client se déconnecte.

PARAMETRES

nom

Le nom d'un curseur ouvert à fermer.

ALL

Ferme tous les curseurs ouverts.

NOTES

PostgreSQL n'a pas d'instruction explicite OPEN pour les curseurs ; un curseur est considéré comme ouvert lorsqu'il est déclaré. Utilisez l'instruction DECLARE pour déclarer un curseur.

Vous pouvez voir tous les curseurs disponibles en interrogeant la vue système pg_cursors.

Si un curseur est fermé après un point de sauvegarde qui est ensuite annulé, la commande CLOSE n'est pas annulée ; c'est-à-dire que le curseur reste fermé.

EXEMPLES

Fermer le curseur liahona :

CLOSE liahona;

COMPATIBILITE

CLOSE est entièrement conforme à la norme SQL. CLOSE ALL est une extension de PostgreSQL.
