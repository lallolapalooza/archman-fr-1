clock_t(3type) clock_t(3type)

NOM

clock_t - temps système

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <time.h>
typedef /* ... */ clock_t;

DESCRIPTION

Utilisé pour le temps système en ticks d'horloge ou CLOCKS_PER_SEC (défini dans <time.h>). Selon POSIX, c'est un type entier ou un type à virgule flottante.

NORMES

C11, POSIX.1-2024.

HISTORIQUE

C89, POSIX.1-2001.

NOTES

Les en-têtes suivants fournissent également ce type : <sys/types.h> et <sys/times.h>.

VOIR AUSSI

times(2), clock(3)
