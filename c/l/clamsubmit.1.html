NOM

clamsubmit - Utilitaire de soumission de fichiers pour ClamAV

SYNTAXE

clamsubmit [options]

DESCRIPTION

clamsubmit soumet des fichiers à Sourcefire pour une analyse plus approfondie.

OPTIONS

-h, -?
Affiche l'aide sur stderr et quitte.
-e EMAIL
Option requise pour définir l'adresse e-mail pour la soumission.
-n FICHIER
Soumet un fichier qui est rapporté comme une fausse négation (ClamAV signale NETTOYÉ). FICHIER peut être - pour spécifier stdin. Mutuellement exclusif avec -p.
-N NOM
Option requise pour définir le nom de l'expéditeur pour la soumission.
-p FICHIER
Soumet un fichier qui est rapporté comme une fausse positivité (ClamAV signale le fichier comme virus). FICHIER peut être - pour spécifier stdin. Mutuellement exclusif avec -n.
-V VIRUS
Le nom du virus détecté comme fausse positivité. Cette option est requise pour les soumissions de fausses positivité.

VARIABLES D'ENVIRONNEMENT

clamsubmit utilise les variables d'environnement suivantes :

CURL_CA_BUNDLE
(Linux/Unix seulement, sauf macOS) Peut être défini sur le chemin d'un fichier (paquet) contenant un ou plusieurs certificats d'autorité de certification. Cela remplacera le chemin par défaut des certificats openssl.
Notez que la variable d'environnement CURL_CA_BUNDLE est également utilisée par l'outil en ligne de commande curl dans le même but.
