sous-programme claev2 (complexe a, complexe b, complexe c, réel rt1, réel rt2, réel cs1, complexe sn1)

CLAEV2 calcule les valeurs propres et les vecteurs propres d'une matrice hermitienne/symétrique 2x2.

Objectif :

!>
!> CLAEV2 calcule la décomposition en valeurs propres d'une matrice hermitienne 2x2
!>    [  A         B  ]
!>    [  CONJG(B)  C  ].
!> Au retour, RT1 est la valeur propre de valeur absolue plus grande, RT2 est la
!> valeur propre de valeur absolue plus petite, et (CS1,SN1) est le vecteur propre
!> droit unitaire pour RT1, donnant la décomposition
!>
!> [ CS1  CONJG(SN1) ] [    A     B ] [ CS1 -CONJG(SN1) ] = [ RT1  0  ]
!> [-SN1     CS1     ] [ CONJG(B) C ] [ SN1     CS1     ]   [  0  RT2 ].
!>

Paramètres

A 
!>          A est COMPLEX
!>         L'élément (1,1) de la matrice 2x2.
!>

B

!>          B est COMPLEX
!>         L'élément (1,2) et le conjugué de l'élément (2,1) de
!>         la matrice 2x2.
!>

C

!>          C est COMPLEX
!>         L'élément (2,2) de la matrice 2x2.
!>

RT1

!>          RT1 est REAL
!>         La valeur propre de valeur absolue plus grande.
!>

RT2

!>          RT2 est REAL
!>         La valeur propre de valeur absolue plus petite.
!>

CS1

!>          CS1 est REAL
!>

SN1

!>          SN1 est COMPLEX
!>         Le vecteur (CS1, SN1) est un vecteur propre droit unitaire pour RT1.
!>

Détails supplémentaires :

!>
!>  RT1 est précis à quelques ulps près, sauf en cas de dépassement
!>  ou de sous-dépassement.
!>
!>  RT2 peut être imprécis s'il y a une annulation massive dans le
!>  déterminant A*C-B*B ; une précision plus élevée ou une arithmétique
!>  correctement arrondie ou tronquée serait nécessaire pour calculer RT2
!>  avec précision dans tous les cas.
!>
!>  CS1 et SN1 sont précis à quelques ulps près, sauf en cas de dépassement
!>  ou de sous-dépassement.
!>
!>  Le dépassement est possible uniquement si RT1 est à un facteur de 5 du
!>  dépassement. Le sous-dépassement est sans danger si les données d'entrée sont 0
!>  ou dépassent
!>     seuil_de_sous-dépassement / macheps.
!>
