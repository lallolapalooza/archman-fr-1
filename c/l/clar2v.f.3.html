sous-routine clar2v (n, x, y, z, incx, c, s, incc)
CLAR2V applique un vecteur de rotations planes avec cosinus réels et sinus complexes des deux côtés à une séquence de matrices symétriques/hermitiennes de taille 2x2.

Documentation de la fonction/sous-routine

sous-routine clar2v (integer n, complex, dimension( * ) x, complex, dimension( * ) y, complex, dimension( * ) z, integer incx, real, dimension( * ) c, complex, dimension( * ) s, integer incc)

CLAR2V applique un vecteur de rotations planes complexes avec cosinus réels des deux côtés à une séquence de matrices hermitiennes complexes de taille 2x2, définies par les éléments des vecteurs x, y et z. Pour i = 1,2,...,n

( x(i) z(i) ) := ( conjg(z(i)) y(i) )

( c(i) conjg(s(i)) ) ( x(i) z(i) ) ( c(i) -conjg(s(i)) ) ( -s(i) c(i) ) ( conjg(z(i)) y(i) ) ( s(i) c(i) )

Objectif:

!>
!> CLAR2V applique un vecteur de rotations planes complexes avec cosinus réels
!> des deux côtés à une séquence de matrices hermitiennes complexes de taille 2x2,
!> définies par les éléments des vecteurs x, y et z. Pour i = 1,2,...,n
!>
!>    (       x(i)  z(i) ) :=
!>    ( conjg(z(i)) y(i) )
!>
!>      (  c(i) conjg(s(i)) ) (       x(i)  z(i) ) ( c(i) -conjg(s(i)) )
!>      ( -s(i)       c(i)  ) ( conjg(z(i)) y(i) ) ( s(i)        c(i)  )
!>

Paramètres

N 
!>          N est ENTIER
!>          Le nombre de rotations planes à appliquer.
!>

X

!>          X est un tableau COMPLEXE, dimension (1+(N-1)*INCX)
!>          Le vecteur x ; les éléments de x sont supposés réels.
!>

Y

!>          Y est un tableau COMPLEXE, dimension (1+(N-1)*INCX)
!>          Le vecteur y ; les éléments de y sont supposés réels.
!>

Z

!>          Z est un tableau COMPLEXE, dimension (1+(N-1)*INCX)
!>          Le vecteur z.
!>

INCX

!>          INCX est ENTIER
!>          L'incrément entre les éléments de X, Y et Z. INCX > 0.
!>

C

!>          C est un tableau RÉEL, dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations planes.
!>

S

!>          S est un tableau COMPLEXE, dimension (1+(N-1)*INCC)
!>          Les sinus des rotations planes.
!>

INCC

!>          INCC est ENTIER
!>          L'incrément entre les éléments de C et S. INCC > 0.
!>
