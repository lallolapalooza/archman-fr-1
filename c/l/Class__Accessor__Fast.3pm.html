NOM

Class::Accessor::Fast - Accesseurs plus rapides, mais moins extensibles

SYNOPSIS

package Foo;
use base qw(Class::Accessor::Fast);
# Le reste est identique à Class::Accessor mais sans set() et get().

DESCRIPTION

Ceci est une version plus rapide mais moins extensible de Class::Accessor. Les accesseurs générés par Class::Accessor nécessitent deux appels de méthode pour accomplir leur tâche (un pour l'accesseur, un autre pour get() ou set()). Class::Accessor::Fast élimine l'appel de set()/get() et effectue l'accès lui-même, ce qui résulte en un accesseur légèrement plus rapide.

L'inconvénient est que vous ne pouvez pas facilement modifier le comportement de vos accesseurs, ni celui de vos sous-classes. Bien sûr, si vous avez besoin de cela plus tard, vous pouvez toujours remplacer Class::Accessor::Fast par Class::Accessor.

Lisez la documentation de Class::Accessor pour plus d'informations.
