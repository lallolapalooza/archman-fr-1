close_range(2) Manuel des appels système close_range(2)

NOM

close_range - ferme tous les descripteurs de fichiers dans une plage donnée

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <unistd.h>
#include <linux/close_range.h> /* Définition des constantes CLOSE_RANGE_*
                                  */
int close_range(unsigned int first, unsigned int last, int flags);

DESCRIPTION

L'appel système close_range() ferme tous les descripteurs de fichiers ouverts de first à last (inclus).

Les erreurs lors de la fermeture d'un descripteur de fichier donné sont actuellement ignorées.

flags est un masque de bits contenant 0 ou plusieurs des options suivantes :

CLOSE_RANGE_CLOEXEC (depuis Linux 5.11)
Définit le drapeau de fermeture lors de l'exécution (close-on-exec) sur les descripteurs de fichiers spécifiés, plutôt que de les fermer immédiatement.
CLOSE_RANGE_UNSHARE
Détache les descripteurs de fichiers spécifiés des autres processus avant de les fermer, évitant ainsi les courses avec d'autres threads partageant la table des descripteurs de fichiers.

VALEUR DE RETOUR

En cas de succès, close_range() retourne 0. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
flags n'est pas valide, ou first est supérieur à last.

Les erreurs suivantes peuvent survenir avec CLOSE_RANGE_UNSHARE (lors de la construction de la nouvelle table de descripteurs) :

EMFILE
Le nombre de descripteurs de fichiers ouverts dépasse la limite spécifiée dans /proc/sys/fs/nr_open (voir proc(5)). Cette erreur peut survenir dans des situations où cette limite a été abaissée avant un appel à close_range() où le drapeau CLOSE_RANGE_UNSHARE est spécifié.
ENOMEM
La mémoire noyau disponible était insuffisante.

NORMES

Aucune.

HISTORIQUE

FreeBSD. Linux 5.9, glibc 2.34.

NOTES

Fermeture de tous les descripteurs de fichiers ouverts

Pour éviter de fermer aveuglément des descripteurs de fichiers dans la plage de descripteurs de fichiers possibles, cela est parfois implémenté (sur Linux) en listant les descripteurs de fichiers ouverts dans /proc/self/fd/ et en appelant close(2) sur chacun d'eux. close_range() peut s'en charger sans nécessiter /proc et en un seul appel système, ce qui offre des avantages significatifs en termes de performances.

Fermeture des descripteurs de fichiers avant exec

Les descripteurs de fichiers peuvent être fermés en toute sécurité en utilisant


/* nous ne voulons rien après stderr ici */
close_range(3, ~0U, CLOSE_RANGE_UNSHARE);
execve(....);

CLOSE_RANGE_UNSHARE est conceptuellement équivalent à


unshare(CLONE_FILES);
close_range(first, last, 0);

mais peut être plus efficace : si la plage détachée s'étend au-delà du nombre maximum de descripteurs de fichiers actuellement alloués dans la table des descripteurs de fichiers de l'appelant (le cas courant lorsque last est ~0U), le noyau détachera une nouvelle table de descripteurs de fichiers pour l'appelant jusqu'à first, en copiant le moins de descripteurs de fichiers possible. Cela évite complètement les appels close(2) ultérieurs ; toute l'opération est terminée une fois la table détachée.

Fermeture des fichiers lors de exec

Ceci est particulièrement utile dans les cas où plusieurs étapes de configuration avant exec risquent d'entrer en conflit les unes avec les autres. Par exemple, la configuration d'un profil seccomp(2) peut entrer en conflit avec un appel close_range() : si les descripteurs de fichiers sont fermés avant que le profil seccomp(2) ne soit configuré, la configuration du profil ne peut pas les utiliser elle-même, ni contrôler leur fermeture ; si les descripteurs de fichiers sont fermés après, le profil seccomp ne peut pas bloquer l'appel close_range() ou les solutions de repli. L'utilisation de CLOSE_RANGE_CLOEXEC évite cela : les descripteurs peuvent être marqués avant que le profil seccomp(2) ne soit configuré, et le profil peut contrôler l'accès à close_range() sans affecter le processus appelant.

EXEMPLES

Le programme présenté ci-dessous ouvre les fichiers nommés dans ses arguments de ligne de commande, affiche la liste des fichiers qu'il a ouverts (en parcourant les entrées de /proc/PID/fd), utilise close_range() pour fermer tous les descripteurs de fichiers supérieurs ou égaux à 3, puis affiche une fois de plus la liste des fichiers ouverts du processus. L'exemple suivant démontre l'utilisation du programme :


$ touch /tmp/a /tmp/b /tmp/c;
$ ./a.out /tmp/a /tmp/b /tmp/c;
/tmp/a opened as FD 3
/tmp/b opened as FD 4
/tmp/c opened as FD 5
/proc/self/fd/0 ==> /dev/pts/1
/proc/self/fd/1 ==> /dev/pts/1
/proc/self/fd/2 ==> /dev/pts/1
/proc/self/fd/3 ==> /tmp/a
/proc/self/fd/4 ==> /tmp/b
/proc/self/fd/5 ==> /tmp/c
/proc/self/fd/6 ==> /proc/9005/fd
========= About to call close_range() =======
/proc/self/fd/0 ==> /dev/pts/1
/proc/self/fd/1 ==> /dev/pts/1
/proc/self/fd/2 ==> /dev/pts/1
/proc/self/fd/3 ==> /proc/9005/fd

Notez que les lignes montrant le chemin d'accès /proc/9005/fd résultent des appels à opendir(3).

Source du programme

#define _GNU_SOURCE
#include <dirent.h>
#include <fcntl.h>
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>
/* Affiche le contenu des liens symboliques dans /proc/self/fd */
static void
show_fds(void)
{
    DIR            *dirp;
    char           path[PATH_MAX], target[PATH_MAX];
    ssize_t        len;
    struct dirent  *dp;
    dirp = opendir("/proc/self/fd");
    if (dirp  == NULL) {
        perror("opendir");
        exit(EXIT_FAILURE);
    }
    for (;;) {
        dp = readdir(dirp);
        if (dp == NULL)
            break;
        if (dp->d_type == DT_LNK) {
            snprintf(path, sizeof(path), "/proc/self/fd/%s",
                     dp->d_name);
            len = readlink(path, target, sizeof(target));
            printf("%s ==> %.*s\n", path, (int) len, target);
        }
    }
    closedir(dirp);
}
int
main(int argc, char *argv[])
{
    int  fd;
    for (size_t j = 1; j < argc; j++) {
        fd = open(argv[j], O_RDONLY);
        if (fd == -1) {
            perror(argv[j]);
            exit(EXIT_FAILURE);
        }
        printf("%s opened as FD %d\n", argv[j], fd);
    }
    show_fds();
    printf("========= About to call close_range() =======\n");
    if (close_range(3, ~0U, 0) == -1) {
        perror("close_range");
        exit(EXIT_FAILURE);
    }
    show_fds();
    exit(EXIT_FAILURE);
}
