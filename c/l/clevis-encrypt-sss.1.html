NOM

clevis-encrypt-sss - Chiffre à l'aide d'une politique de partage de secrets de Shamir

SYNTAXE

clevis encrypt sss CONFIG [-y] < PT > JWE

APERÇU

La commande clevis encrypt sss chiffre à l'aide d'une politique de partage de secrets de Shamir. Son seul argument est l'objet de configuration JSON.

Le partage de secrets de Shamir (SSS) fournit un moyen de mélanger les broches pour créer des politiques de déverrouillage sophistiquées et de haute disponibilité. SSS est un schéma de seuillage. Il crée une clé et la divise en plusieurs morceaux. Chaque morceau est chiffré à l'aide d'une autre broche (potentiellement même SSS récursivement). De plus, vous définissez le seuil t. Si au moins t morceaux peuvent être déchiffrés, la clé de chiffrement peut être récupérée et le déchiffrement peut réussir.

Par exemple, créons une configuration de haute disponibilité utilisant Tang :

$ cfg='{"t":1,"pins":{"tang":[{"url":...},{"url":...}]}}'
$ clevis encrypt sss "$cfg" < PT > JWE

Dans cette politique, nous déclarons que nous avons un seuil de 1, mais qu'il existe plusieurs fragments de clé chiffrés à l'aide de différents serveurs Tang. Puisque notre seuil est de 1, tant qu'un des serveurs Tang est disponible, le déchiffrement réussira. Comme toujours, le déchiffrement est simplement :

$ clevis decrypt < JWE > PT

CONFIG

Cette commande utilise les propriétés de configuration suivantes :

•t (entier) : Nombre de broches requises pour le déchiffrement (REQUIS)
•pins (objet) : Broches utilisées pour chiffrer les fragments (REQUIS)

Le format de la propriété pins est le suivant :

{PIN:CFG,...} OU {PIN:[CFG,CFG,...],...}

Lorsque la version liste du format est utilisée, plusieurs broches de ce type recevront des fragments de clé.

OPTIONS

•-y : Répond automatiquement oui à toutes les questions. Pour la broche tang, cela ignorera la vérification de confiance de la publicité, ce qui peut être utile dans les déploiements automatisés : 
$ cfg='{"t":1,"pins":{"tang":[{"url":...},{"url":...}]}}'
$ clevis encrypt sss "$cfg" -y < PT > JWE
