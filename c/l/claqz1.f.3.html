sous-routine claqz1 (logique, intent(in) ilq, logique, intent(in) ilz, entier, intent(in) k, entier, intent(in) istartm, entier, intent(in) istopm, entier, intent(in) ihi, complexe, dimension( lda, * ) a, entier, intent(in) lda, complexe, dimension( ldb, * ) b, entier, intent(in) ldb, entier, intent(in) nq, entier, intent(in) qstart, complexe, dimension( ldq, * ) q, entier, intent(in) ldq, entier, intent(in) nz, entier, intent(in) zstart, complexe, dimension( ldz, * ) z, entier, intent(in) ldz)

CLAQZ1

Objectif :

!>
!>      CLAQZ1 poursuit une déformation de décalage 1x1 dans un faisceau de matrices
!>      vers le bas d'une seule position.
!>

Paramètres

ILQ 
!>          ILQ est LOGIQUE
!>              Détermine si la matrice Q doit être mise à jour ou non.
!>

ILZ

!>          ILZ est LOGIQUE
!>              Détermine si la matrice Z doit être mise à jour ou non.
!>

K

!>          K est ENTIER
!>              Indice indiquant la position de la déformation.
!>              À l'entrée, la déformation est située dans
!>              (A(k+1,k),B(k+1,k)).
!>              À la sortie, la déformation est située dans
!>              (A(k+2,k+1),B(k+2,k+1)).
!>

ISTARTM

!>          ISTARTM est ENTIER
!>

ISTOPM

!>          ISTOPM est ENTIER
!>              Les mises à jour de (A,B) sont limitées à
!>              (istartm:k+2,k:istopm). Il est supposé
!>              sans vérification que istartm <= k+1 et
!>              k+2 <= istopm.
!>

IHI

!>          IHI est ENTIER
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>

LDA

!>          LDA est ENTIER
!>              La dimension principale de A telle que déclarée dans
!>              la procédure appelante.
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB,N)
!>

LDB

!>          LDB est ENTIER
!>              La dimension principale de B telle que déclarée dans
!>              la procédure appelante.
!>

NQ

!>          NQ est ENTIER
!>              L'ordre de la matrice Q.
!>

QSTART

!>          QSTART est ENTIER
!>              Indice de début de la matrice Q. Les rotations sont appliquées
!>              aux colonnes k+2-qStart:k+3-qStart de Q.
!>

Q

!>          Q est un tableau COMPLEXE, dimension (LDQ,NQ)
!>

LDQ

!>          LDQ est ENTIER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>

NZ

!>          NZ est ENTIER
!>              L'ordre de la matrice Z.
!>

ZSTART

!>          ZSTART est ENTIER
!>              Indice de début de la matrice Z. Les rotations sont appliquées
!>              aux colonnes k+1-qStart:k+2-qStart de Z.
!>

Z

!>          Z est un tableau COMPLEXE, dimension (LDZ,NZ)
!>

LDZ

!>          LDZ est ENTIER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>
