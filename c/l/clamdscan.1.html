NOM

clamdscan - scanner des fichiers et répertoires à la recherche de virus en utilisant le démon Clam AntiVirus

SYNTAXE

clamdscan [options] [fichier/répertoire]

DESCRIPTION

clamdscan est un client clamd qui peut être utilisé en remplacement de clamscan. Il accepte toutes les options implémentées dans clamscan, mais la plupart d'entre elles seront ignorées car ses capacités de scan dépendent uniquement de clamd.

OPTIONS

-h, --help
Afficher les informations d'aide et quitter.
-V, --version
Afficher le numéro de version et quitter.
-v, --verbose
Être verbeux.
--quiet
Être silencieux - afficher uniquement les messages d'erreur.
--stdout
Écrire tous les messages (sauf la sortie de libclamav) sur la sortie standard (stdout).
-c, --config-file=FICHIER
Lire les paramètres de clamd depuis FICHIER.
-l FICHIER, --log=FICHIER
Sauvegarder le rapport de scan dans FICHIER.
-f FICHIER, --file-list=FICHIER
Scanner les fichiers listés ligne par ligne dans FICHIER.
-p A[:I], --ping A[:I]
Pinger clamd jusqu'à [A] fois à l'intervalle optionnel [I] jusqu'à ce qu'il réponde.
-w, --wait
Attendre jusqu'à 30 secondes que clamd démarre. Peut être utilisé avec ping pour définir le nombre de tentatives [A] et l'intervalle [I] pour vérifier clamd.
-m, --multiscan
En mode multiscan, clamd tentera de scanner le contenu d'un répertoire en parallèle en utilisant les threads disponibles. Cette option est particulièrement utile sur les systèmes multiprocesseurs et multicœurs. Si vous passez plus d'un fichier ou répertoire en ligne de commande, ils sont mis en file d'attente et envoyés à clamd individuellement. Cela signifie que les fichiers uniques sont toujours scannés par un seul thread. De même, clamdscan attendra que clamd termine le scan d'un répertoire (effectué en mode multiscan) avant d'envoyer une requête pour scanner un autre répertoire. Cette option peut être combinée avec --fdpass (voir ci-dessous).
-z, --allmatch
Après une correspondance trouvée, continuer le scan dans le fichier pour d'autres correspondances.
--remove
Supprimer les fichiers infectés. Soyez prudent.
--move=DIRECTORY
Déplacer les fichiers infectés dans le REPERTOIRE.
--copy=DIRECTORY
Copier les fichiers infectés dans le REPERTOIRE.
--no-summary
Ne pas afficher de résumé à la fin du scan.
--reload
Demander à clamd de recharger la base de données des virus.
--allmatch
Continuer le scan dans le fichier après avoir trouvé une correspondance.
-i, --infected
Afficher uniquement les fichiers infectés.
--fdpass
Ouvrir le fichier et passer le descripteur de fichier ouvert à clamd. Ceci est utile si clamd s'exécute en tant qu'utilisateur différent ou si clamd voit un arbre de fichiers différent. C'est plus rapide que de streamer le fichier vers clamd. Uniquement disponible si connecté à clamd via un socket local (unix).
--stream
Forcer le streaming de fichiers vers clamd. Ce n'est généralement pas nécessaire car clamdscan détecte automatiquement si le streaming est requis. Cette option existe uniquement à des fins de débogage et de test, dans tous les autres cas, --fdpass est préférable.

EXEMPLES

(0) Pour scanner un fichier :

clamdscan fichier

(1) Pour scanner le répertoire de travail courant :

clamdscan

(2) Pour scanner tous les fichiers dans /home :

clamdscan /home

(3) Pour scanner un fichier lorsque clamd s'exécute en tant qu'utilisateur différent :

clamdscan --fdpass ~/downloads

(4) Pour scanner depuis l'entrée standard :

clamdscan - < fichier_à_scanner

cat fichier_à_scanner | clamdscan -

CODES DE RETOUR

0 : Aucun virus trouvé.

1 : Virus trouvé(s).
2 : Une erreur s'est produite.
