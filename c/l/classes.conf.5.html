NOM

classes.conf - fichier de configuration des classes pour cups

DESCRIPTION

Le fichier classes.conf définit les classes d'imprimantes locales disponibles. Il est normalement situé dans le répertoire /etc/cups et est géré par le programme cupsd(8). Ce fichier n'est pas destiné à être édité ou géré manuellement.

NOTES

Le nom, l'emplacement et le format de ce fichier sont un détail d'implémentation qui changera dans les futures versions de CUPS.

VOIR AUSSI

cupsd(8), cupsd.conf(5), mime.convs(5), mime.types(5), printers.conf(5), subscriptions.conf(5), Aide en ligne CUPS (http://localhost:631/help)
