sous-routine clarfgp (integer n, complex alpha, complex, dimension( * ) x, integer incx, complex tau)

CLARFGP génère un réflecteur élémentaire (matrice de Householder) complexe avec un bêta non négatif.

Objectif :

!>
!> CLARFGP génère un réflecteur élémentaire complexe H d'ordre n, tel que
!>
!>       H**H * ( alpha ) = ( beta ),   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> où alpha et beta sont des scalaires, beta est réel et non négatif, et
!> x est un vecteur complexe de (n-1) éléments. H est représenté sous la forme
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ,
!>                     ( v )
!>
!> où tau est un scalaire complexe et v est un vecteur complexe de (n-1)
!> éléments. Notez que H n'est pas hermitien.
!>
!> Si les éléments de x sont tous nuls et alpha est réel, alors tau = 0
!> et H est pris comme étant la matrice identité.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre du réflecteur élémentaire.
!>

ALPHA

!>          ALPHA est un NOMBRE COMPLÈXE
!>          En entrée, la valeur alpha.
!>          En sortie, elle est écrasée par la valeur bêta.
!>

X

!>          X est un tableau COMPLÈXE, de dimension
!>                         (1+(N-2)*abs(INCX))
!>          En entrée, le vecteur x.
!>          En sortie, il est écrasé par le vecteur v.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les éléments de X. INCX > 0.
!>

TAU

!>          TAU est un NOMBRE COMPLÈXE
!>          La valeur tau.
!>
