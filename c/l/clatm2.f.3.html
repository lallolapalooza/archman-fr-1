!>
!>    CLATM2 renvoie l'élément (I,J) d'une matrice aléatoire de dimension
!>    (M, N) décrite par les autres paramètres. Elle est appelée par la
!>    routine CLATMR afin de construire des matrices de test aléatoires. Aucune
!>    vérification d'erreur n'est effectuée sur les paramètres, car cette routine est appelée dans
!>    une boucle serrée par CLATMR qui a déjà vérifié les paramètres.
!>
!>    L'utilisation de CLATM2 diffère de CLATM3 dans l'ordre dans lequel le
!>    générateur de nombres aléatoires est appelé pour remplir les éléments de la matrice
!>    aléatoire. Avec CLATM2, le générateur est appelé pour remplir la matrice
!>    pivotée colonne par colonne. Avec CLATM3, le générateur est appelé pour remplir la
!>    matrice colonne par colonne, après quoi elle est pivotée. Ainsi, CLATM3 peut
!>    être utilisé pour construire des matrices aléatoires qui ne diffèrent que par leur
!>    ordre de lignes et/ou de colonnes. CLATM2 est utilisé pour construire des matrices en bande
!>    tout en évitant d'appeler le générateur de nombres aléatoires pour
!>    les éléments en dehors de la bande (et donc de générer des nombres aléatoires
!>
!>    La matrice dont l'élément (I,J) est renvoyé est construite comme
!>    suit (cette routine ne calcule qu'un seul élément) :
!>
!>      Si I est en dehors de (1..M) ou J est en dehors de (1..N), renvoyer zéro
!>         (ce qui est pratique pour générer des matrices au format bande).
!>
!>      Générer une matrice A avec des éléments aléatoires de distribution IDIST.
!>
!>      Définir la diagonale à D.
!>
!>      Étalonner la matrice, si désiré, depuis la gauche (par DL) et/ou
!>         depuis la droite (par DR ou DL) comme spécifié par IGRADE.
!>
!>      Permuter, si désiré, les lignes et/ou les colonnes comme spécifié par
!>         IPVTNG et IWORK.
!>
!>      Mettre la matrice en bande pour avoir une largeur de bande inférieure KL et une largeur
!>         de bande supérieure KU.
!>
!>      Mettre les éléments aléatoires à zéro comme spécifié par SPARSE.
!
>

Paramètre

s

!>          M est INTEGER
!>           Nombre de lignes de la matrice. Non modifié.
!
>

N 
!>          N est INTEGER
!>           Nombre de colonnes de la matrice. Non modifié.
!
>

I 
!>          I est INTEGER
!>           Ligne de l'élément à renvoyer. Non modifié.
!
>

J 
!>          J est INTEGER
!>           Colonne de l'élément à renvoyer. Non modifié.
!
>

K

L 
!>          KL est INTEGER
!>           Largeur de bande inférieure. Non modifié.
!
>

K

U 
!>          KU est INTEGER
!>           Largeur de bande supérieure. Non modifié.
!
>

IDIS

T 
!>          IDIST est INTEGER
!>           À l'entrée, IDIST spécifie le type de distribution à
!>           utiliser pour générer une matrice aléatoire .
!>           1 => parties réelle et imaginaire chacune UNIFORM( 0, 1 )
!>           2 => parties réelle et imaginaire chacune UNIFORM( -1, 1 )
!>           3 => parties réelle et imaginaire chacune NORMAL( 0, 1 )
!>           4 => nombre complexe uniforme dans DISK( 0 , 1 )
!>           Non modifié.
!
>

ISEE

D 
!>          ISEED est un tableau INTEGER de dimension ( 4 )
!>           Graine pour le générateur de nombres aléatoires.
!>           Modifié à la sortie.
!
>

D 
!>          D est un tableau COMPLEX de dimension ( MIN( I , J ) )
!>           Éléments diagonaux de la matrice. Non modifié.
!
>

IGRAD

E 
!>          IGRADE est INTEGER
!>           Spécifie l'étalonnage de la matrice comme suit :
!>           0  => pas d'étalonnage
!>           1  => matrice pré-multipliée par diag( DL )
!>           2  => matrice post-multipliée par diag( DR )
!>           3  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DR )
!>           4  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par inv( diag( DL ) )
!>           5  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( CONJG(DL) )
!>           6  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DL )
!>           Non modifié.
!
>

D

L 
!>          DL est un tableau COMPLEX ( I ou J, selon le cas )
!>           Facteurs d'échelle gauche pour étalonner la matrice.  Non modifié.
!
>

D

R 
!>          DR est un tableau COMPLEX ( I ou J, selon le cas )
!>           Facteurs d'échelle droit pour étalonner la matrice.  Non modifié.
!
>

IPVTN

G 
!>          IPVTNG est INTEGER
!>           À l'entrée, spécifie les permutations de pivotement comme suit :
!>           0 => aucune.
!>           1 => pivotement sur les lignes.
!>           2 => pivotement sur les colonnes.
!>           3 => pivotement complet, c'est-à-dire sur les deux côtés.
!>           Non modifié.
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER ( I ou J, selon le cas )
!>           Ce tableau spécifie la permutation utilisée. La
!>           ligne (ou colonne) en position K était à l'origine en
!>           position IWORK( K ).
!>           Cela diffère de IWORK pour CLATM3. Non modifié.
!
>

SPARS

E 
!>          SPARSE est REAL
!>           Valeur entre 0. et 1.
!>           À l'entrée, spécifie la parcimonie de la matrice
!>           si une matrice parcimonieuse doit être générée.
!>           SPARSE doit être compris entre 0 et 1.
!>           Un nombre aléatoire uniforme ( 0, 1 ) x est généré et
!>           comparé à SPARSE ; si x est plus grand, l'élément de la matrice
!>           est inchangé et si x est plus petit, l'élément est défini
!>           à zéro. Ainsi, en moyenne, une fraction SPARSE des
!>           éléments sera définie à zéro.
!>           Non modifié.
!
>
