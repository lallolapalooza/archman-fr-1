Ceci est le module "Class::Singleton". Un Singleton décrit

une

classe

d'objet qui ne peut avoir qu'une seule instance dans un système donné. Un exemple de Singleton pourrait être un serveur d'impression ou un registre système. Ce module implémente une classe Singleton à partir de laquelle d'autres classes peuvent être dérivées. En soi, le module "Class::Singleton" ne fait pas grand-chose d'autre que gérer l'instanciation d'un seul objet. En dérivant une classe à partir de "Class::Singleton", votre module héritera de la méthode d'instanciation Singleton et pourra implémenter toute fonctionnalité spécifique requise. La
méthode instance() appelle la

la

première et unique fois qu'une nouvelle instance est créée. Tous les paramètres passés à la méthode instance() sont transmis à _new_instance(). Dans la classe de base, la méthode _new_instance() retourne une référence bénie vers un tableau associatif contenant tous les arguments passés soit comme une référence de tableau associatif, soit comme une liste de paramètres nommés. package MyConfig; use base 'Class::

Singleton'; 
sub foo {
    shift->{ foo };
}

sub bar {
    shift->{ bar };
}

package main;

# soit : référence de tableau associatif de paramètres nommés
my $config = MyConfig->instance({ foo => 10, bar => 20 });

# soit : liste de paramètres nommés
my $config = MyConfig->instance( foo => 10, bar => 20 );

print $config->foo();   # 10
print $config->bar();   # 20
