CLQT02

But:

!>
!> CLQT02 teste CUNGLQ, qui génère une matrice m x n, Q, dont les lignes sont
!> orthonormées et qui est définie comme le produit de k réflecteurs élémentaires.
!>
!> Étant donné la factorisation LQ d'une matrice m x n, A, CLQT02 génère
!> la matrice orthogonale Q définie par la factorisation des k premières lignes de A ;
!> elle compare L(1:k,1:m) à A(1:k,1:n)*Q(1:m,1:n)', et vérifie que les lignes de Q
!> sont orthonormées.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q à générer.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q à générer.
!>          N >= M >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          La matrice m x n, A, qui a été factorisée par CLQT01.
!>

AF

!>          AF est un tableau COMPLEXE, de dimension (LDA,N)
!>          Détails de la factorisation LQ de A, tels que retournés par CGELQF.
!>          Voir CGELQF pour plus de détails.
!>

Q

!>          Q est un tableau COMPLEXE, de dimension (LDA,N)
!>

L

!>          L est un tableau COMPLEXE, de dimension (LDA,M)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et L. LDA >= N.
!>

TAU

!>          TAU est un tableau COMPLEXE, de dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires correspondant
!>          à la factorisation LQ dans AF.
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau RÉEL, de dimension (M)
!>

RESULT

!>          RESULT est un tableau RÉEL, de dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norme( L - A*Q' ) / ( N * norme(A) * EPS )
!>          RESULT(2) = norme( I - Q*Q' ) / ( N * EPS )
!>
