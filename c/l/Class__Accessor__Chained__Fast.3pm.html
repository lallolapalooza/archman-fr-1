NOM

Class::Accessor::Chained::Fast - Accesseurs chaînés plus rapides, mais moins extensibles

SYNTAXE

package Foo;
use base qw(Class::Accessor::Chained::Fast);
 # Le reste comme Class::Accessor::Chained sauf pas de set() ni de get().

DESCRIPTION

Par analogie avec Class::Accessor et Class::Accessor::Fast, ce module fournit un générateur d'accesseurs chaînés plus rapide et moins flexible.
