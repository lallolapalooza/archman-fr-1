sous-routine cla_porfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, logical colequ, real, dimension( * ) c, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldy, * ) y, integer ldy, real, dimension( * ) berr_out, integer n_norms, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, complex, dimension( * ) res, real, dimension( * ) ayb, complex, dimension( * ) dy, complex, dimension( * ) y_tail, real rcond, integer ithresh, real rthresh, real dz_ub, logical ignore_cwise, integer info)

CLA_PORFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires pour des matrices symétriques ou hermitiennes définies positives en effectuant un raffinement itératif de précision supplémentaire et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.

But :

!>
!> CLA_PORFSX_EXTENDED améliore la solution calculée d'un système
!> d'équations linéaires en effectuant un raffinement itératif de
!> précision supplémentaire et fournit des bornes d'erreur et des
!> estimations d'erreur arrière pour la solution.
!> Cette sous-routine est appelée par CPORFSX pour effectuer le
!> raffinement itératif.
!> En plus de la borne d'erreur dans la norme, le code fournit une
!> borne d'erreur composante par composante si possible. Voir les
!> commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails
!> des bornes d'erreur. Notez que cette sous-routine est uniquement
!> responsable de la définition des deuxième champs de ERR_BNDS_NORM
!> et ERR_BNDS_COMP.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser pour le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un CHARACTER et P
!>          = 'S':  Simple (Single)
!>          = 'D':  Double
!>          = 'I':  Indigène (Indigenous)
!>          = 'X' ou 'E':  Extra
!>

UPLO

!>          UPLO est CHARACTER*1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de seconds membres, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N par N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T, tel que calculé par CPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .TRUE., un équilibrage par colonne a été effectué sur A avant
!>     d'appeler cette routine. Cela est nécessaire pour calculer la
!>     solution et les bornes d'erreur correctement.
!>

C

!>          C est un tableau REAL, dimension (N)
!>     Les facteurs d'échelle par colonne pour A. Si COLEQU = .FALSE., C
!>     n'est pas accédé. Si C est en entrée, chaque élément de C devrait être une
!>     puissance de la base (radix) pour garantir une solution et des estimations
!>     d'erreur fiables.
!>     La mise à l'échelle par des puissances de la base ne provoque pas
!>     d'erreurs d'arrondi sauf si le résultat déborde ou est sous le seuil
!>     minimal. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente
!>     à la matrice d'entrée, produisant des estimations d'erreur qui peuvent
!>     ne pas être fiables.
!>

B

!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>     La matrice des seconds membres B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

Y

!>          Y est un tableau COMPLEX, dimension (LDY,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par CPOTRS.
!>     À la sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension principale du tableau Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau REAL, dimension (NRHS)
!>     À la sortie, BERR_OUT(j) contient l'erreur arrière relative
!>     composante par composante pour le j-ième second membre donnée par la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la
!>     matrice ou du vecteur Z. Ceci est calculé par CLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur retourner (voir ERR_BNDS_NORM
!>     et ERR_BNDS_COMP).
!>     Si N_NORMS >= 1, retourne les bornes d'erreur dans la norme.
!>     Si N_NORMS >= 2, retourne les bornes d'erreur composante par composante.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau REAL, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative dans la norme, qui est définie comme suit :
!>
!>     Erreur relative dans la norme dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur comme décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois morceaux d'information
!>     retournés.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée, presque
!>              certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque dans la norme estimé. Comparé avec le seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est fiable. Ces nombres de condition réciproquesondition
!>              les nombres sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z correctement mise à l'échelle.
!>              Soit Z = S*A, où S met chaque ligne à l'échelle par une puissance
!>              de la base afin que toutes les sommes absolues de lignes de Z
!>              soient approximativement égales à 1.
!>
!>     Cette sous-routine est uniquement responsable de la définition du deuxième champ
!>     ci-dessus.
!>     Voir Lapack Working Note 165 pour plus de détails et des avertissements
!>     supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau RÉEL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend
!>     l'erreur relative composante par composante), et le type d'information
!>     d'erreur décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations renvoyées pour chaque second membre. Si la précision
!>     composante par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée, qui est
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit être
!>              prise en compte que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque composante par composante estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est ... Ces nombres de condition réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z correctement mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>     second membre courant et S met chaque ligne de
!>     A*diag(x) à l'échelle par une puissance de la base afin que toutes les sommes absolues de lignes de Z soient approximativement égales à 1.
!>
!>     Cette sous-routine est uniquement responsable de la définition du deuxième champ ci-dessus.
!>     Voir Lapack Working Note 165 pour plus de détails et des avertissements supplémentaires.
!>

RES

!>          RES est un tableau COMPLEXE, de dimension (N)
!>     Espace de travail pour contenir le résidu intermédiaire.
!>

AYB

!>          AYB est un tableau RÉEL, de dimension (N)
!>     Espace de travail.
!>

DY

!>          DY est un tableau COMPLEXE, de dimension (N)
!>     Espace de travail pour contenir la solution intermédiaire.
!>

Y_TAIL

!>          Y_TAIL est un tableau COMPLEXE, de dimension (N)
!>     Espace de travail pour contenir les bits de poids faible de la solution intermédiaire.
!>

RCOND

!>          RCOND est RÉEL
!>     Nombre de condition réciproque mis à l'échelle. C'est une estimation du
!>     nombre de condition réciproque de Skeel de la matrice A après
!>     équilibrage (si effectué). Si celui-ci est inférieur à la précision
!>     machine (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut encore être petite même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!>

ITHRESH

!>          ITHRESH est ENTIER
!>     Le nombre maximal de calculs de résidu autorisés pour
!>     l'affinage. La valeur par défaut est 10. Pour 'aggressive', mettre à 100 pour
!>     permettre la convergence en utilisant des factorisations approchées ou
!>     des factorisations autres que LU. Si la factorisation utilise une
!>     technique autre que l'élimination de Gauss, les garanties dans
!>     ERR_BNDS_NORM et ERR_BNDS_COMP peuvent ne plus être dignes de confiance.
!>

RTHRESH

!>          RTHRESH est RÉEL
!>     Détermine quand arrêter l'affinage si l'estimation d'erreur cesse de
!>     diminuer. L'affinage s'arrêtera lorsque la solution suivante ne
!>     satisfait plus norm(dx_{i+1}) < RTHRESH * norm(dx_i) où norm(Z) est
!>     la norme infinie de Z. RTHRESH satisfait 0 < RTHRESH <= 1. La
!>     valeur par défaut est 0.5. Pour 'aggressive', mettre à 0.9 pour permettre
!>     la convergence sur des matrices extrêmement mal conditionnées. Voir LAWN 165
!>     pour plus de détails.
!>

DZ_UB

!>          DZ_UB est RÉEL
!>     Détermine quand commencer à considérer la convergence composante par composante.
!>     La convergence composante par composante n'est considérée qu'après que chaque composante
!>     de la solution Y est stable, ce que nous définissons comme le changement
!>     relatif dans chaque composante étant inférieur à DZ_UB. La valeur par défaut
!>     est 0.25, exigeant que le premier bit soit stable. Voir LAWN 165 pour
!>     plus de détails.
!>

IGNORE_CWISE

!>          IGNORE_CWISE est LOGIQUE
!>     Si .TRUE. alors ignorer la convergence composante par composante. La valeur par défaut
!>     est .FALSE..
!>

INFO

!>          INFO est ENTIER
!>       = 0:  Sortie réussie.
!>       < 0:  si INFO = -i, le i-ème argument de CPOTRS avait une valeur
!>             illégale
!>
