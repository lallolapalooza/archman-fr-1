__extern void * caca_export_canvas_to_memory (caca_canvas_t const * cv, char const * format, size_t * bytes)

Cette fonction exporte un canvas libcaca vers divers formats étrangers tels que l'art ANSI, le HTML, les couleurs IRC, etc. Le pointeur renvoyé doit être passé à free() pour libérer le stockage alloué lorsqu'il n'est plus nécessaire.

Les valeurs valides pour format sont :

  • 'caca' : exporte les fichiers natifs libcaca.
  • 'ansi' : exporte de l'art ANSI (jeu de caractères CP437 avec codes de couleur ANSI).
  • 'html' : exporte une page HTML avec des informations CSS.
  • 'html3' : exporte un tableau HTML qui devrait être compatible avec la plupart des navigateurs, y compris ceux en mode texte.
  • 'irc' : exporte du texte UTF-8 avec les codes de couleur mIRC.
  • 'ps' : exporte un document PostScript.
  • 'svg' : exporte une image vectorielle SVG.
  • 'tga' : exporte une image TGA.
  • 'troff' : exporte une source troff.

Si une erreur se produit, NULL est renvoyé et errno est défini en conséquence :

  • EINVAL Format demandé non pris en charge.
  • ENOMEM Pas assez de mémoire pour allouer le tampon de sortie.

Paramètres

cv Un canvas libcaca
format Une chaîne décrivant le format de sortie demandé.
bytes Un pointeur vers un size_t où le nombre d'octets alloués sera écrit.

Renvoie

Un pointeur vers la zone mémoire exportée, ou NULL en cas d'erreur.

__extern void * caca_export_area_to_memory (caca_canvas_t const * cv, int x, int y, int w, int h, char const * format, size_t * bytes)

Cette fonction exporte une partie d'un libcaca canvas vers divers formats. Pour plus d'informations, voir caca_export_canvas_to_memory().

Si une erreur se produit, NULL est renvoyé et errno est défini en conséquence :

  • EINVAL Format demandé non pris en charge ou coordonnées invalides.
  • ENOMEM Pas assez de mémoire pour allouer le tampon de sortie.

Paramètres

cv Un canvas libcaca
x La coordonnée la plus à gauche de la zone à exporter.
y La coordonnée la plus haute de la zone à exporter.
w La largeur de la zone à exporter.
h La hauteur de la zone à exporter.
format Une chaîne décrivant le format de sortie demandé.
bytes Un pointeur vers un size_t où le nombre d'octets alloués sera écrit.

Renvoie

Un pointeur vers la zone mémoire exportée, ou NULL en cas d'erreur.
