NOM

cache_writeback - réécrit les blocs modifiés vers le périphérique d'origine.

SYNTAXE

cache_writeback [options] --metadata-device {périphérique|fichier} --origin-device {périphérique|fichier} --fast-device {périphérique|fichier}

DESCRIPTION

cache_writeback est un outil hors ligne qui réécrit les données modifiées vers le périphérique de données (l'origine). Destiné à être utilisé dans des scénarios de récupération lorsque le SSD génère des erreurs d'E/S.

Cet outil ne peut pas être exécuté sur un cache actif.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche les informations de version et quitte.
--metadata-device {périphérique|fichier}
Emplacement des métadonnées du cache.
--origin-device {périphérique|fichier}
Périphérique lent mis en cache.
--fast-device {périphérique|fichier}
Périphérique rapide contenant les données qui doivent être réécrites.
--no-metadata-update
Ne met pas à jour les métadonnées pour effacer les drapeaux de modification.
    Vous pourriez vouloir utiliser cet indicateur si vous mettez hors service le cache.
--buffer-size-meg {taille}
Spécifie la taille du cache de données, en mégaoctets.
    Par défaut 64 MiB, une taille plus grande peut améliorer les performances.
--list-failed-blocks
Liste tous les blocs qui ont échoué au processus de réécriture.

VOIR AUSSI

cache_dump(8), cache_check(8), cache_repair(8), cache_restore(8)
