NOM

capng_get_rootid - obtenir l'identifiant racine de l'espace de noms

SYNOPSIS

#include <cap-ng.h>

int capng_get_rootid(void);

DESCRIPTION

capng_get_rootid obtient l'identifiant racine pour les opérations de capacités. Ceci ne s'applique qu'aux opérations du système de fichiers.

VALEUR DE RETOUR

Si le fichier est dans l'espace de noms d'initialisation ou si le noyau ne prend pas en charge les capacités du système de fichiers V3, il retourne CAPNG_UNSET_ROOTID. Sinon, il retourne un entier pour l'identifiant racine de l'espace de noms.

VOIR AUSSI

capng_get_caps_fd(3), capabilities(7)
