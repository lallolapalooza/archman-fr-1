__extern caca_dither_t * caca_create_dither (int bpp, int w, int h, int pitch, uint32_t rmask, uint32_t gmask, uint32_t bmask, uint32_t amask)

Crée une structure de tramage à partir de ses coordonnées (profondeur, largeur, hauteur et pas) et des valeurs des masques de pixels. Si la profondeur est de 8 bits par pixel, les valeurs des masques sont ignorées et la palette de couleurs doit être définie à l'aide de la fonction caca_set_dither_palette(). Pour des profondeurs supérieures à 8 bits par pixel, un masque alpha nul entraîne l'ignorance des valeurs alpha.

En cas d'erreur, NULL est renvoyé et errno est défini en conséquence :

  • EINVAL La valeur demandée pour la largeur, la hauteur, le pas ou les bits par pixel était invalide.
  • ENOMEM Pas assez de mémoire pour allouer la structure de tramage.

Paramètres

bpp Profondeur du bitmap en bits par pixel.
w Largeur du bitmap en pixels.
h Hauteur du bitmap en pixels.
pitch Pas du bitmap en octets.
rmask Masque de bits pour les valeurs rouges.
gmask Masque de bits pour les valeurs vertes.
bmask Masque de bits pour les valeurs bleues.
amask Masque de bits pour les valeurs alpha.

Retour

L'objet de tramage en cas de succès, NULL si une erreur s'est produite.

__extern int caca_set_dither_palette (caca_dither_t * d, uint32_t red[], uint32_t green[], uint32_t blue[], uint32_t alpha[])

Définit la palette d'un bitmap de 8 bits par pixel. Les valeurs doivent être comprises entre 0 et 4095 (0xfff).

En cas d'erreur, -1 est renvoyé et errno est défini en conséquence :

•
EINVAL La valeur des bits par pixel du tramage n'est pas 8, ou l'une des valeurs de pixel était hors de la plage 0 - 4095.

Paramètres

d Objet de tramage.
red Tableau de 256 valeurs rouges.
green Tableau de 256 valeurs vertes.
blue Tableau de 256 valeurs bleues.
alpha Tableau de 256 valeurs alpha.

Retour

0 en cas de succès, -1 si une erreur s'est produite.

__extern int caca_set_dither_antialias (caca_dither_t * d, char const * str)

Indique au moteur de rendu s'il faut lisser le tramage. Le lissage adoucit l'image rendue et évite l'effet d'escalier souvent observé.

  • 'none': pas de lissage.
  • 'prefilter' ou 'default': lissage par pré-filtrage simple. C'est la valeur par défaut.

En cas d'erreur, -1 est retourné et errno est défini conformément :

•
EINVAL Mode de lissage invalide.

Paramètres

d Objet de tramage.
str Une chaîne décrivant la méthode de lissage qui sera utilisée pour le tramage.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

__extern char const *const * caca_get_dither_antialias_list (caca_dither_t const * d)

__extern int caca_set_dither_color (caca_dither_t * d, char const * str)

Indique au moteur de rendu quelles couleurs utiliser pour rendre le bitmap. Les valeurs valides pour str sont :

  • 'mono': utilise du gris clair sur fond noir.
  • 'gray': utilise du blanc et deux nuances de gris sur fond noir.
  • '8': utilise les 8 couleurs ANSI sur fond noir.
  • '16': utilise les 16 couleurs ANSI sur fond noir.
  • 'fullgray': utilise du noir, du blanc et deux nuances de gris pour les caractères et l'arrière-plan.
  • 'full8': utilise les 8 couleurs ANSI pour les caractères et l'arrière-plan.
  • 'full16' ou 'default': utilise les 16 couleurs ANSI pour les caractères et l'arrière-plan. C'est la valeur par défaut.

En cas d'erreur, -1 est retourné et errno est défini conformément :

•
EINVAL Jeu de couleurs invalide.

Paramètres

d Objet de tramage.
str Une chaîne décrivant le jeu de couleurs qui sera utilisé pour le tramage.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

__extern int caca_set_dither_charset (caca_dither_t * d, char const * str)

Indique au moteur de rendu quels caractères utiliser pour rendre le tramage. Les valeurs valides pour str sont :

  • 'ascii' ou 'default': utilise uniquement des caractères ASCII. C'est la valeur par défaut.
  • 'shades': utilise les caractères Unicode 'U+2591 LIGHT SHADE', 'U+2592
    MEDIUM SHADE' et 'U+2593 DARK SHADE'. Ces caractères sont également présents dans la page de code CP437 disponible sur DOS et VGA.
  • 'blocks': utilise des combinaisons de blocs de quart de cellule Unicode. Ces caractères ne se trouvent que dans l'ensemble Unicode.

En cas d'erreur, -1 est retourné et errno est défini conformément :

•
EINVAL Jeu de caractères invalide.

Paramètres

d Objet de tramage.
str Une chaîne décrivant les caractères qui doivent être utilisés pour le tramage.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

__extern int caca_set_dither_algorithm (caca_dither_t * d, char const * str)

Indique au moteur de rendu quel algorithme de tramage doit être utilisé. Le tramage est nécessaire car l'image rendue a généralement beaucoup plus de couleurs que la palette disponible. Les valeurs valides pour str sont :

  • 'none': aucun tramage n'est utilisé, la couleur correspondante la plus proche est utilisée.
  • 'ordered2': utilise une matrice de Bayer 2x2 pour le tramage.
  • 'ordered4': utilise une matrice de Bayer 4x4 pour le tramage.
  • 'ordered8': utilise une matrice de Bayer 8x8 pour le tramage.
  • 'random': utilise un tramage aléatoire.
  • 'fstein': utilise le tramage de Floyd-Steinberg. C'est la valeur par défaut.

En cas d'erreur, -1 est retourné et errno est défini conformément :

•
EINVAL Mode de tramage inconnu.

Paramètres

d Objet de tramage.
str Une chaîne décrivant l'algorithme qui doit être utilisé pour le tramage.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.
