CATGETS(3P) Manuel du programmeur POSIX CATGETS(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

catgets — lire un message de programme

SYNTAXE

#include <nl_types.h>
char *catgets(nl_catd catd, int set_id, int msg_id, const char *s);

DESCRIPTION

La fonction catgets() tente de lire le message msg_id, dans le jeu set_id, du catalogue de messages identifié par catd. L'argument catd est un descripteur de catalogue de messages retourné par un appel antérieur à catopen(). Les résultats ne sont pas définis si catd n'est pas une valeur retournée par catopen() pour un catalogue de messages toujours ouvert dans le processus. L'argument s pointe vers une chaîne de message par défaut qui sera retournée par catgets() s'il ne parvient pas à récupérer le message identifié.

La fonction catgets() n'est pas nécessairement thread-safe.

VALEUR DE RETOUR

Si le message identifié est récupéré avec succès, catgets() retourne un pointeur vers une zone de mémoire tampon interne contenant la chaîne de message terminée par un caractère nul. Si l'appel échoue pour une quelconque raison, s est retourné et errno est défini pour indiquer l'erreur.

ERREURS

La fonction catgets() échoue si :

EINTR
L'opération de lecture a été interrompue en raison de la réception d'un signal, et aucune donnée n'a été transférée.
ENOMSG
Le message identifié par set_id et msg_id n'est pas dans le catalogue de messages.

La fonction catgets() peut échouer si :

EBADF
L'argument catd n'est pas un descripteur de catalogue de messages valide ouvert en lecture.
EBADMSG
Le message identifié par set_id et msg_id dans le catalogue de messages spécifié n'a pas satisfait aux critères de sécurité définis par l'implémentation.
EINVAL
Le catalogue de messages identifié par catd est corrompu.
