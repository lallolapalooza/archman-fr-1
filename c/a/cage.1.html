cage(1) Manuel des commandes générales cage(1)

NOM

cage - un compositeur de kiosque Wayland

SYNTAXE

cage [options...] [--] [application...]

DESCRIPTION

Cage exécute une seule application maximisée. Cage peut exécuter plusieurs applications, mais une seule est visible à la fois. Les interactions utilisateur et les activités en dehors du champ de l'application en cours d'exécution sont empêchées.

OPTIONS

-d

Ne pas dessiner les décorations côté client lorsque possible.

-D

Activer la journalisation de débogage.

-h

Afficher le message d'aide.

-m <mode>

Définir le comportement multi-moniteurs. Les modes supportés sont : last Cage utilise uniquement le dernier moniteur connecté. extend Cage étend l'affichage sur tous les moniteurs connectés.

-s

Autoriser le changement de VT (Terminal Virtuel).

-v

Afficher le numéro de version et quitter.

ENVIRONNEMENT

DISPLAY

Si compilé avec le support Xwayland, sera défini sur le nom de l'affichage X utilisé pour Xwayland. Sinon, sondera le backend X11.

WAYLAND_DISPLAY

Spécifie le nom de l'affichage Wayland sur lequel Cage s'exécute.

XCURSOR_PATH

Répertoire où se trouvent les curseurs.

XCURSOR_SIZE

Spécifie la taille du curseur configurée.

XCURSOR_THEME

Spécifie le thème de curseur configuré.

XKB_DEFAULT_RULES, XKB_DEFAULT_MODEL, XKB_DEFAULT_LAYOUT, XKB_DEFAULT_VARIANT, XKB_DEFAULT_OPTIONS

Configure les paramètres du clavier xkb. Voir xkeyboard-config(7).
