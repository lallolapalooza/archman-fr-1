NOM

cache_dump - dumper les métadonnées du cache depuis un périphérique ou un fichier vers la sortie standard.

SYNTAXE

cache_dump [options] {périphérique|fichier}

DESCRIPTION

cache_dump dverse les métadonnées de cache binaires créées par la cible de cache device-mapper sur un périphérique ou un fichier vers la sortie standard pour analyse ou post-traitement au format XML. Les métadonnées au format XML peuvent être introduites dans cache_restore afin de les remettre sur un périphérique de métadonnées (pour traitement par la cible device-mapper), ou un fichier.

Cet outil ne peut pas être exécuté sur des métadonnées actives.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche les informations sur la version et quitte.
-r, --repair
Répare les métadonnées tout en les dumptant.
-o {fichier xml}
Spécifie un fichier de sortie pour le XML, au lieu de l'afficher sur stdout.

EXEMPLES

Dùmpe les métadonnées du cache sur le volume logique /dev/vg/metadata vers la sortie standard au format XML :

    $ cache_dump /dev/vg/metadata
Dùmpe les métadonnées du cache sur le volume logique /dev/vg/metadata tout en les réparant vers la sortie standard au format XML : 
    $ cache_dump --repair /dev/vg/metadata

DIAGNOSTICS

cache_dump retourne un code de sortie de 0 en cas de succès ou 1 en cas d'erreur.

VOIR AUSSI

cache_check(8), cache_repair(8), cache_restore(8)
