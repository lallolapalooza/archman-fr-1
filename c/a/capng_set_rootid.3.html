CAPNG_SET_ROOTID(3) API Libcap-ng CAPNG_SET_ROOTID(3)

NOM

capng_set_rootid - définir l'identifiant racine de l'espace de noms

SYNOPSIS

#include <cap-ng.h>

int capng_set_rootid(int rootid);

DESCRIPTION

capng_set_rootid définit l'identifiant racine pour les opérations de capacités. Ceci n'est applicable qu'aux opérations du système de fichiers.

VALEUR DE RETOUR

En cas de succès, retourne 0. Retourne -1 en cas d'erreur interne ou si le noyau ne prend pas en charge les capacités du système de fichiers V3.

VOIR AUSSI

capng_set_caps_fd(3), capabilities(7)
