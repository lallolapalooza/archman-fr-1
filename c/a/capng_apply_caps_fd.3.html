NOM

capng_apply_caps_fd - écrire les capacités basées sur les fichiers dans les attributs étendus

SYNTAXE

#include <cap-ng.h>

int capng_apply_caps_fd(int fd);

DESCRIPTION

Cette fonction écrira les capacités basées sur les fichiers dans les attributs étendus du fichier pour lequel le descripteur a été ouvert. L'ensemble de limitation n'est pas inclus dans les opérations de capacités basées sur les fichiers. Notez que cette fonction ne fonctionnera que si elle est compilée sur un noyau qui prend en charge les capacités basées sur les fichiers, comme la version 2.6.26 et ultérieures.

VALEUR DE RETOUR

Cette fonction retourne 0 en cas de succès, -1 si un fichier autre qu'un fichier régulier est passé, et -2 si un identifiant d'espace de noms non root est utilisé pour rootid.

VOIR AUSSI

capng_get_caps_fd(3), capabilities(7)
