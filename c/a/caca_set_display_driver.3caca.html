DESCRIPTION Détaillée

Ces fonctions fournissent les routines de base de libcaca pour l'initialisation de l'affichage, la récupération d'informations système et la configuration.

Documentation des Fonctions

__extern caca_display_t * caca_create_display (caca_canvas_t * cv)

Crée un contexte graphique utilisant des fonctionnalités dépendantes du périphérique (ncurses pour les terminaux, une fenêtre X11, une fenêtre de commande DOS...) qui s'attache à une toile libcaca. Tout ce qui est dessiné dans la toile libcaca peut alors être affiché par le pilote libcaca.

Si aucune toile caca n'est fournie, une nouvelle est créée. Son pointeur peut être récupéré en utilisant caca_get_canvas() et elle est automatiquement détruite lorsque caca_free_display() est appelée.

Notez que, afin d'obtenir une compatibilité Unicode maximale, le code d'initialisation du pilote peut modifier temporairement le locale global LC_CTYPE du programme en utilisant setlocale(). Il est conseillé de ne pas appeler de fonctions dépendantes de LC_CTYPE à partir d'autres threads pendant l'appel à caca_create_display(). Les paramètres de locale sont restaurés au retour de la fonction.

Voir aussi caca_create_display_with_driver().

Si une erreur se produit, NULL est retourné et errno est défini en conséquence :

  • ENOMEM Pas assez de mémoire.
  • ENODEV Périphérique graphique non initialisable.

Paramètres

cv La toile caca ou NULL pour créer une toile automatiquement.

Retourne

Le contexte graphique caca ou NULL si une erreur s'est produite.

Références caca_create_display_with_driver().

__extern caca_display_t * caca_create_display_with_driver (caca_canvas_t * cv, char const * driver)

Crée un contexte graphique utilisant des fonctionnalités dépendantes du périphérique (ncurses pour les terminaux, une fenêtre X11, une fenêtre de commande DOS...) qui s'attache à une toile libcaca. Tout ce qui est dessiné dans la toile libcaca peut alors être affiché par le pilote libcaca.

Si aucune toile caca n'est fournie, une nouvelle est créée. Son pointeur peut être récupéré en utilisant caca_get_canvas() et elle est automatiquement détruite lorsque caca_free_display() est appelée.

Si aucun nom de pilote n'est fourni, libcaca tentera de détecter automatiquement le meilleur pilote de sortie possible.

Voir aussi caca_create_display().

Si une erreur se produit, NULL est retourné et errno est défini en conséquence :

  • ENOMEM Pas assez de mémoire.
  • ENODEV Périphérique graphique non initialisable.

Paramètres

cv La toile caca ou NULL pour créer une toile automatiquement.
driver Une chaîne décrivant le pilote de sortie désiré ou NULL pour choisir automatiquement le meilleur pilote.

Retourne

Le contexte graphique caca ou NULL si une erreur s'est produite.

Références caca_create_canvas(), caca_free_canvas(), caca_manage_canvas(), et caca_unmanage_canvas().

Référencé par caca_create_display().

__extern char const *const * caca_get_display_driver_list (void )

Retourne une liste des pilotes d'affichage disponibles. La liste est un tableau de chaînes de caractères terminées par NULL, intercalant une chaîne contenant la valeur interne pour le pilote d'affichage, et une chaîne contenant la description en langage naturel de ce pilote.

Cette fonction ne peut jamais échouer.

Retourne

Un tableau de chaînes de caractères.

__extern int caca_free_display (caca_display_t * dp)

Détache un contexte graphique de son backend caca et le détruit. La toile libcaca continue d'exister et d'autres contextes graphiques peuvent y être attachés par la suite.

Si la toile caca a été automatiquement créée par caca_create_display(), elle est automatiquement détruite et tout pointeur vers elle devient invalide.

Cette fonction ne peut jamais échouer.

Paramètres

dp Le contexte graphique libcaca.

Retourne

Cette fonction retourne toujours 0.

Références caca_free_canvas(), et caca_unmanage_canvas().
