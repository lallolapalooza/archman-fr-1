NOM

Canto-remote - Une télécommande basique pour canto-daemon

Ceci fournit une certaine capacité pour configurer et interroger canto-daemon sans client complet. Utile pour les scripts ou l'interface avec d'autres programmes.

SYNTAXE DE LA LIGNE DE COMMANDE

canto-remote (options) [commande] (arguments)

OPTIONS

-V
Affiche les informations de version et quitte.
-h/--aide
Affiche l'aide d'utilisation
-D/--rep [répertoire]
Change le répertoire de base pour canto-daemon (défaut : $XDG_CONFIG_HOME/canto)
--sansplugins
Désactive tous les plugins
--activerplugins 'plugin1 plugin2...'
Active ces plugins (remplace --sansplugins)
--desactiverplugins 'plugin1 plugin2...'
Désactive ces plugins
-a/--adresse [IP]
Tente de se connecter à l'adresse au lieu du socket Unix local, par défaut en boucle locale (127.0.0.1)
-p/--port [port]
Utilise le port lors de la connexion avec -a

COMMANDES

Canto-remote prend en charge diverses commandes pour configurer canto-daemon, bien que l'utilisation d'un vrai client soit recommandée.

aide [commande]
Obtenir de l'aide sur une commande spécifique
ajoutflux [URL] (utilisateur=user motdepasse=secret) (nom="Un nom")
S'abonner à un flux, éventuellement avec des arguments spéciaux. Si aucun nom n'est spécifié, le titre du flux sera utilisé.
listflux
Lister tous les flux abonnés
suppflux [nom ou index de listflux]
Se désabonner d'un flux
etat (--tag=tag) (--lu|--total|--tags)
Afficher le nombre d'éléments non lus, éventuellement limité à un tag spécifique, --lu affiche les éléments lus, --total affiche le nombre total d'éléments, --tags affiche la valeur pour tous les tags.

NOTE : Ceci est toujours soumis aux filtres, donc si vous filtrez tous les éléments lus, --lu ne retournera jamais rien d'autre que 0.

mise-a-jour-forcee
Rafraîchir tous les flux, indépendamment des horodatages
config (="valeur")
Changer une variable de configuration
(Vous ne voudrez probablement pas faire cela manuellement, utilisez un client)
une-config (= valeur)
Changer une seule variable de configuration, en supposant que toute la ligne est un seul paramètre.
(Vous ne voudrez probablement pas faire cela manuellement, utilisez un client)
exporter

Écrire une liste de flux au format OPML sur la sortie standard
(par ex. canto-remote exporter > liste-flux.opml)
importer

Importer une liste de flux au format OPML depuis l'entrée standard
(par ex. canto-remote importer < liste-flux.opml)
tuer

Tuer le démon auquel vous vous connectez
script

Exécuter un script (code de test)
NOTE : Les plugins peuvent également ajouter des commandes distantes, comme « sync », qui seront également
listées avec --aide (ou sans arguments).
