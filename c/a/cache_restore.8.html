cache_restore(8) Manuel de l'administrateur système cache_restore(8)

NOM

cache_restore - restaure un fichier de métadonnées de cache sur un périphérique ou un fichier.

SYNTAXE

cache_restore [options] -i {fichier xml} -o {périphérique|fichier}

DESCRIPTION

cache_restore restaure les métadonnées de cache créées par la cible correspondante du device-mapper, sauvegardées dans un fichier au format XML (voir cache_dump(8)), qui peut éventuellement être prétraité avant la restauration sur un autre périphérique ou fichier. Si restauré sur un périphérique de métadonnées, les métadonnées peuvent être traitées par la cible du device-mapper.

Cet outil ne peut pas être exécuté sur des métadonnées actives.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche les informations sur la version et quitte.
-q, --quiet
Ne produit aucune sortie. Vérifiez le code de sortie pour tester le succès.
-i, --input {fichier xml}
Entrée XML.
-o, --output {périphérique|fichier}
Fichier de sortie ou périphérique pour les métadonnées binaires restaurées.
    Si un fichier est utilisé, il doit être pré-alloué et suffisamment grand pour
    contenir les métadonnées.
--metadata-version {1|2}
Choisit une version des métadonnées.

OPTIONS DE BONNAGE

--debug-override-metadata-version {entier}
Remplace la version stockée dans les métadonnées.
--omit-clean-shutdown
Ne définit pas le drapeau d'arrêt propre.

EXEMPLE

Restaure les métadonnées de cache formatées en XML sur le fichier métadonnées vers le volume logique /dev/vg/metadata pour un traitement ultérieur par la cible correspondante du device-mapper :

    $ cache_restore -i metadonnees -o /dev/vg/metadonnees

DIAGNOSTICS

cache_restore retourne un code de sortie de 0 en cas de succès ou 1 en cas d'erreur.

VOIR AUSSI

cache_dump(8), cache_check(8), cache_repair(8)
