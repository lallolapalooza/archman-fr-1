Canto-daemon(1) Manuel des commandes générales Canto-daemon(1)

NOM

Canto-daemon - Un démon d'agrégation RSS extensible.

UTILISATION LIGNE DE COMMANDE

canto-daemon (options)

OPTIONS

-V/--version
Affiche les informations de version et quitte.
-h/--help
Affiche l'aide d'utilisation.
-v
Active la journalisation détaillée (débogage).
-D/--dir [répertoire]
Change le répertoire de base pour canto-daemon (défaut : $XDG_CONFIG_HOME/canto).
-n/--nofetch
Ne récupère pas le nouveau contenu pendant l'exécution (débogage).
--noplugins
Désactive tous les plugins.
--enableplugins 'plugin1 plugin2...'
Active ces plugins (annule --noplugins).
--disableplugins 'plugin1 plugin2...'
Désactive ces plugins.
-a/--address [IP]
Écoute sur l'adresse en plus du socket Unix local. Utiliser "" pour toutes les interfaces. Par défaut, utilise la boucle locale (127.0.0.1).
-p/--port [port]
Utilise le port lors de l'écoute avec -a.

CONFIGURATION

Ce démon gère sa propre configuration et doit être manipulé via canto-remote ou un client, tel que canto-curses.

PLUGINS

Les plugins sont empaquetés dans <prefix>/canto/plugins (c.-à-d. /usr/lib/canto/plugins) et peuvent être activés en les copiant dans votre répertoire de configuration (c.-à-d. $XDG_CONFIG_HOME/canto/plugins). Beaucoup d'entre eux ont leur propre configuration, il est donc conseillé d'ouvrir les fichiers pour apporter des modifications. Voici quelques exemples de plugins inclus avec la source de canto-daemon.

reddit.py
Ajoute du contenu aux éléments reddit. Inclut un tri reddit_score_sort qui ordonne automatiquement les éléments par votes positifs.
sync-rsync.py
Un plugin de synchronisation basé sur rsync. Voir l'en-tête pour la configuration. Peut être utilisé pour synchroniser avec un serveur distant via SSH, ou avec un autre système de fichiers local (pour NFS/sshfs/Dropbox/gdrive etc.).
sync-inoreader.py
Synchronise (la plupart) du contenu avec inoreader.com, un service avec prise en charge de RSS sur le web ainsi que divers appareils mobiles.

FICHIERS

$XDG_CONFIG_HOME/canto/daemon-log

Fichier journal de Canto-daemon.

$XDG_CONFIG_HOME/canto/plugins/

Répertoire des plugins de Canto-daemon.

/usr/lib/canto/plugins
Répertoire des plugins empaquetés par défaut.
