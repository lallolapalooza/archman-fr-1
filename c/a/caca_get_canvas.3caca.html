__extern caca_display_t * caca_create_display (caca_canvas_t *

cv)

Crée un contexte graphique utilisant des fonctionnalités dépendantes de l'appareil (ncurses pour les terminaux, une fenêtre X11, une fenêtre de commande DOS...) qui s'attache à un canevas libcaca. Tout ce qui est dessiné dans le canevas libcaca peut ensuite être affiché par le pilote

libcaca.

Si aucun canevas caca n'est fourni, un nouveau canevas est créé. Son descripteur peut être récupéré en utilisant caca_get_canvas() et il est automatiquement détruit lorsque caca_free_display() est

appelée.

Notez que pour atteindre la compatibilité Unicode maximale, le code d'initialisation du pilote peut temporairement modifier la locale LC_CTYPE globale du programme à l'aide de setlocale(). Il est conseillé de ne pas appeler de fonctions dépendantes de LC_CTYPE depuis d'autres threads pendant l'appel à caca_create_display(). Les paramètres de locale sont restaurés lorsque la fonction

retourne.

Voir aussi caca_create_display_wit

h_driver().

__extern int caca_refresh_display (caca_display_t *

dp)

Exécute toutes les opérations graphiques et les affiche sur le périphérique d'affichage. Rien n'apparaîtra à l'écran tant que cette fonction n'est pas

appelée.

Si caca_set_display_time() a été appelée avec une valeur non nulle, caca_refresh_display() utilisera cette valeur pour obtenir un taux de rafraîchissement constant : si deux appels consécutifs à caca_refresh_display() se produisent dans un intervalle de temps inférieur à la valeur définie avec caca_set_display_time(), le second appel sera retardé avant d'effectuer le rafraîchissement de

l'écran.

jamais.

usec)
