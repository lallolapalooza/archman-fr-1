CARGO-HELP(1) Manuel des commandes générales CARGO-HELP(1)

NOM

cargo-help — Obtenir de l'aide pour une commande Cargo

SYNTAXE

cargo help [sous-commande]

DESCRIPTION

Affiche un message d'aide pour la commande donnée.

EXEMPLES

1. Obtenir de l'aide pour une commande : 
cargo help build
2. L'aide est également disponible avec le drapeau --help : 
cargo build --help
