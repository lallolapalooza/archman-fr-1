NOM

cache_metadata_size - Estimer la taille du périphérique de métadonnées nécessaire pour une configuration donnée.

SYNTAXE

cache_metadata_size [options]

DESCRIPTION

cache_metadata_size estime la taille des métadonnées. Soit --nr-blocks, soit --block-size et --device-size doivent être spécifiés.

OPTIONS

--nr-blocks {naturel}
Spécifie le nombre de blocs de cache.
--block-size {secteurs}
Spécifie la taille de chaque bloc de cache en secteurs de 512 octets.
--device-size {secteurs}
Spécifie la taille totale du périphérique rapide utilisé dans le cache. En secteurs de 512 octets.
--max-hint-width {nb octets}
Spécifie la largeur de l'indice.
    Les politiques de cache utilisent un 'indice' par bloc pour enregistrer des
    informations supplémentaires (par exemple, les compteurs de succès). À
    l'heure actuelle, toutes les politiques utilisent une largeur d'indice de 4
    octets. Si vous souhaitez utiliser une largeur d'indice différente, spécifiez-la
    avec cette option.

EXEMPLE

$ cache_metadata_size --nr-blocks 10240

$ cache_metadata_size --block-size 128 --device-size 1024000

VOIR AUSSI

cache_dump(8), cache_repair(8), cache_restore(8)
