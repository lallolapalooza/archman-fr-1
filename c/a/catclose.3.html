catopen(3) Manuel des fonctions de bibliothèque catopen(3)

NOM

catopen, catclose - ouvrir/fermer un catalogue de messages

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <nl_types.h>
nl_catd catopen(const char *name, int flag);
int catclose(nl_catd catalog);

DESCRIPTION

La fonction catopen() ouvre un catalogue de messages et renvoie un descripteur de catalogue. Le descripteur reste valide jusqu'à ce que catclose() ou execve(2) soit appelé. Si un descripteur de fichier est utilisé pour implémenter les descripteurs de catalogue, alors le drapeau FD_CLOEXEC sera défini.

L'argument name spécifie le nom du catalogue de messages à ouvrir. Si name spécifie un chemin absolu (c'est-à-dire contient un '/'), alors name spécifie un chemin d'accès au catalogue de messages. Sinon, la variable d'environnement NLSPATH est utilisée avec name substitué par %N (voir locale(7)). Il n'est pas spécifié si NLSPATH sera utilisé lorsque le processus a des privilèges root. Si NLSPATH n'existe pas dans l'environnement, ou si un catalogue de messages ne peut être ouvert dans aucun des chemins spécifiés par celui-ci, alors un chemin défini par l'implémentation est utilisé. Ce dernier chemin par défaut peut dépendre du paramètre de locale LC_MESSAGES lorsque l'argument flag est NL_CAT_LOCALE et de la variable d'environnement LANG lorsque l'argument flag est 0. Modifier la partie LC_MESSAGES de la locale peut invalider les descripteurs de catalogue ouverts.

L'argument flag à catopen() est utilisé pour indiquer la source de la langue à utiliser. S'il est défini à NL_CAT_LOCALE, il utilisera le paramètre de locale actuel pour LC_MESSAGES. Sinon, il utilisera la variable d'environnement LANG.

La fonction catclose() ferme le catalogue de messages identifié par catalog. Elle invalide toutes les références ultérieures au catalogue de messages défini par catalog.

VALEUR DE RETOUR

La fonction catopen() renvoie un descripteur de catalogue de messages de type nl_catd en cas de succès. En cas d'échec, elle renvoie (nl_catd) -1 et définit errno pour indiquer l'erreur. Les valeurs d'erreur possibles incluent toutes les valeurs possibles pour l'appel open(2).

La fonction catclose() renvoie 0 en cas de succès, ou -1 en cas d'échec.

ENVIRONNEMENT

LC_MESSAGES
Peut être la source du paramètre de locale LC_MESSAGES, et donc déterminer la langue à utiliser si flag est défini à NL_CAT_LOCALE.
LANG
La langue à utiliser si flag est 0.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
catopen () Sécurité des threads MT-Safe env
catclose () Sécurité des threads MT-Safe

VERSIONS

Ce qui précède est la description POSIX.1. La valeur glibc pour NL_CAT_LOCALE est 1. Le chemin par défaut varie, mais examine généralement un certain nombre d'emplacements sous /usr/share/locale.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

VOIR AUSSI

catgets(3), setlocale(3)
