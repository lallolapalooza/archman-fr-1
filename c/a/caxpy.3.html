Documentation de la fonction/sous-programme

sous-programme caxpy (integer n, complex ca, complex, dimension(*) cx, integer incx, complex, dimension(*) cy, integer incy)

CAXPY

Objectif :

!>
!>    CAXPY une constante multipliée par un vecteur plus un vecteur.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

CA

!>          CA est un nombre complexe (COMPLEX)
!>           À l'entrée, CA spécifie le scalaire alpha.
!>

CX

!>          CX est un tableau complexe (COMPLEX array), dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un entier (INTEGER)
!>         espacement de stockage entre les éléments de CX
!>

CY

!>          CY est un tableau complexe (COMPLEX array), dimension ( 1 + ( N - 1 )*abs( INCY ) )
!>

INCY

!>          INCY est un entier (INTEGER)
!>         espacement de stockage entre les éléments de CY
!>
