NOM

catfish - Outil de recherche de fichiers configurable via la ligne de commande

DESCRIPTION

Catfish est un outil de recherche de fichiers pratique pour Linux et UNIX. L'interface est intentionnellement légère et simple, utilisant uniquement Gtk+3. Vous pouvez la configurer selon vos besoins en utilisant plusieurs options de ligne de commande.

SYNTAXE

catfish [options] chemin requête

OPTIONS

--version
Affiche le numéro de version et quitte
-h, --help
Affiche le message d'aide et quitte
-v, --verbose
Affiche les messages de débogage (-vv déboguera également catfish_lib)
--large-icons
Utilise de grandes icônes
--thumbnails
Utilise des miniatures
--iso-time
Affiche l'heure au format ISO
--path=CHEMIN
Définit le chemin de recherche par défaut
--exact
Effectue une correspondance exacte
--hidden
Inclut les fichiers cachés
--fulltext
Effectue une recherche plein texte
--start
Si le chemin et la requête sont fournis, démarre la recherche lorsque l'application est affichée.
--sort=TRI
Définit une colonne par défaut pour le tri (nom|taille|chemin|date|type),(asc|desc)
