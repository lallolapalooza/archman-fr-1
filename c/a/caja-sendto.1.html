NOM

caja-sendto - application pratique pour envoyer un fichier par e-mail ou messagerie instantanée

SYNTAXE

caja-sendto [OPTIONS | FICHIERS...]

DESCRIPTION

Envoyer FICHIER(s) par e-mail ou messagerie instantanée.

Une fenêtre de dialogue présente un choix d'application de transport et de destinataire pour le(s) fichier(s). Les noms des destinataires peuvent être sélectionnés dans une liste ou complétés automatiquement. L'application sélectionnée est ensuite ouverte avec le(s) fichier(s) et le destinataire prêt pour le transfert.

L'application est destinée à s'intégrer à caja et est écrite pour le bureau graphique MATE.

OPTIONS

-?, --help
Afficher un message d'aide listant toutes les options et leur signification.
