Si les coordonnées sont en dehors des limites du canevas, rien n'est affiché. Si un caractère Unicode de pleine largeur est écrasé, ses parties visibles restantes sont remplacées par des espaces. __extern int caca_put_str (caca_canvas_t * cv, int x, int y, char const * s)

Imprime une chaîne UTF-8 aux coordonnées données, en utilisant les valeurs d'avant-plan et d'arrière-plan par défaut. Les coordonnées peuvent être en dehors des limites du canevas (par exemple une coordonnée Y négative) et la chaîne sera rognée en conséquence si elle est trop longue.

Voir caca_put_char() pour plus d'informations sur la gestion des caractères de pleine largeur lorsqu'ils s'écrasent mutuellement ou aux limites du canevas.

Cette fonction renvoie le nombre de cellules imprimées par la chaîne. Ce n'est pas le nombre de caractères imprimés, car les caractères de pleine largeur occupent deux cellules.

Cette fonction n'échoue jamais.

Paramètres

cv Un descripteur du canevas libcaca.
x Coordonnée X.
y Coordonnée Y.
s La chaîne à imprimer.

Renvoie

Le nombre de cellules imprimées.

Références caca_put_char(), caca_utf32_is_fullwidth(), et caca_utf8_to_utf32().

__extern int caca_blit (caca_canvas_t * dst, int x, int y, caca_canvas_t const * src, caca_canvas_t const * mask)

Blit un canevas sur un autre aux coordonnées données. Un canevas masque optionnel peut être utilisé.

__extern int caca_set_canvas_boundaries (caca_canvas_t * cv, int x, int y, int w, int h)

Définit de nouvelles limites pour un canevas. Cette fonction peut être utilisée pour rogner un canevas, l'étendre, ou pour des combinaisons des deux actions. Toutes les trames sont affectées par cette fonction.

Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence :

  • EINVAL La largeur ou la hauteur spécifiée est invalide.
  • EBUSY Le canevas est en cours d'utilisation par un pilote d'affichage et ne peut pas être redimensionné.
  • ENOMEM Pas assez de mémoire pour la taille de canevas demandée. Si cela se produit, le descripteur du canevas devient invalide et ne devrait pas être utilisé.

Paramètres

cv Le canevas à rogner.
x Coordonnée X du coin supérieur gauche.
y Coordonnée Y du coin supérieur gauche.
w La largeur de la zone rognée.
h La hauteur de la zone rognée.

Renvoie

0 en cas de succès, -1 si une erreur s'est produite.

Références caca_add_dirty_rect(), caca_blit(), caca_create_canvas(), caca_create_frame(), caca_get_frame_count(), et caca_set_frame().

    Nom

    caca_gotoxy — déplace le curseur vers une position donnée

    Synopsis

    void caca_gotoxy(caca_canvas_t *canvas, int x, int y);

    Description

    La fonction caca_gotoxy déplace le curseur du canevas canvas aux coordonnées x et y.

    Paramètres

    • canvas : Un pointeur vers le canevas où déplacer le curseur.
    • x : La nouvelle coordonnée X du curseur.
    • y : La nouvelle coordonnée Y du curseur.

    Exemple

    L'exemple suivant montre comment utiliser caca_gotoxy pour déplacer le curseur en haut à gauche du canevas puis y écrire du texte :

    #include <cacert.h>

int main(void) {
    caca_canvas_t *canvas;
    canvas = caca_create_canvas(80, 24);
    if (canvas == NULL) {
        /* Gérer l'erreur */
        return 1;
    }

    caca_gotoxy(canvas, 0, 0);
    caca_puts(canvas, "Bonjour, monde !");

    /* Afficher le canevas (code omis) */

    caca_free_canvas(canvas);
    return 0;
}
