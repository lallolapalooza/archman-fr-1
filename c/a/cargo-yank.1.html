NOM

cargo-yank - Retire une crate de l'index

SYNTAXE

cargo yank [OPTIONS] <crates>...

DESCRIPTION

Retire une version spécifique d'une crate de l'index des crates.

La crate sera toujours téléchargeable en utilisant la version spécifiée, mais les nouvelles versions ne pourront pas la cibler.

Les options suivantes sont disponibles pour la commande cargo:

--all
Retire toutes les versions de la crate spécifiée.
--vers VERSION
Retire une version spécifique de la crate spécifiée.

Pour plus d'informations sur les options de ligne de commande, voir cargo(1).

OPTIONS

Les options suivantes sont disponibles pour la commande cargo:

-C CHEMIN

Change le répertoire de travail courant avant d'exécuter les opérations spécifiées. Cela affecte par exemple la façon dont cargo recherche par défaut le manifeste du projet (Cargo.toml), ainsi que les répertoires recherchés pour découvrir .cargo/config.toml, par exemple. Cette option doit apparaître avant le nom de la commande, par exemple cargo -C chemin/vers/mon-projet build.

Cette option n'est disponible que sur le canal nightly https://doc.rust-lang.org/book/appendix-07-nightly-rust.html et nécessite le drapeau -Z unstable-options pour être activé (voir #10098 https://github.com/rust-lang/cargo/issues/10098).

-h, --help

Affiche les informations d'aide.

-Z flag

Flags instables (nightly uniquement) pour Cargo. Exécutez cargo -Z help pour plus de détails.

ENVIRONNEMENT

Voir la référence https://doc.rust-lang.org/cargo/reference/environment-variables.html pour les détails sur les variables d'environnement lues par Cargo.

STATUT DE SORTIE

•0: Cargo a réussi.
•101: Cargo n'a pas pu terminer.
