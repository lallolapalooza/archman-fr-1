commande pour Unix.

SYNOPSI

S

DESCRIPTIO

N

cadaver prend en charge le téléversement de fichiers, le téléchargement, l'affichage à l'écran, les opérations d'espace de noms (déplacement et copie), la création et la suppression de collections, ainsi que les opérations de

verrouillage.

Son fonctionnement est similaire à celui du client ftp(1) standard de BSD et du projet Samba smbclient(1). Un utilisateur familier avec ces outils devrait être tout à fait à l'aise avec

cadaver.

cadaver prend en charge la connexion automatique aux serveurs nécessitant une authentification via un fichier .netrc (similaire à ftp(1) - voir la section «

FICHIER .netrc
» ci-dessous).

FICHIER .

netrc

Le fichier ~/.netrc peut être utilisé pour se connecter automatiquement à un serveur nécessitant une authentification. Les jetons suivants (séparés par des espaces, tabulations ou sauts de ligne) peuvent être utilisés

:

machine hos

t
Identifie une machine distante host qui est comparé avec le nom d'hôte donné sur la ligne de commande ou comme argument de la commande open. Tous les jetons suivants jusqu'à la fin du fichier ou jusqu'au prochain machine ou jeton default sont associés à cette
entrée.

defaul

t
C'est l'équivalent du jeton machine mais correspond à n'importe quel nom d'hôte. Un seul jeton default peut être utilisé et il doit être après tous les jetons mac
hine.

login usernam

e
Spécifie le nom d'utilisateur à utiliser lors de la connexion à la machine
distante.

password string
passwd strin

g
Spécifie le mot de passe à utiliser lors de la connexion à la machine
distante.

Tout autre jeton (t

el que décrit dans
ftp(1)) est ignoré.
