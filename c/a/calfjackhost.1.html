calfjackhost(1) Manuel des commandes générales calfjackhost(1)

NOM

calfjackhost - Wrapper JACK pour les plugins Calf

SYNTAXE

calfjackhost [options] plugin[:preset] [!] ...

DESCRIPTION

L'application hôte JACK Calf JACK fournit un moyen d'utiliser les plugins Calf directement, sans avoir besoin d'une application hôte externe. Elle offre également les meilleures fonctionnalités d'interface graphique (utilisant la boîte à outils GTK+ 2), car aucune norme de plugin restrictive ne se trouve entre l'interface graphique et le code de traitement audio.

OPTIONS

-c --client nom
définit le nom du client JACK (le nom que calfjackhost utilise lors de son enregistrement dans JACK)
-i --input nom
préfixe du nom pour les entrées audio
-o --output nom
préfixe du nom pour les sorties audio
-m --midi nom
préfixe du nom pour les entrées MIDI
-c --connect-midi client:port
connecte automatiquement tous les ports MIDI à client:port
-M --connect-midi !n
connecte automatiquement tous les ports MIDI à system:midi_capture_n
-v --version
affiche une chaîne de version (calf some.version.number)
-l --load session
Charge l'état de la session depuis un fichier
-s --state session
Charge l'état de la session depuis un fichier, si un tel fichier existe
-L --list
Liste tous les plug-ins disponibles
-h -? --help
affiche un texte d'aide
-t --no-tray
désactive l'icône de la barre d'état au démarrage

Un point d'exclamation (!) à la place du nom du plugin signifie une connexion automatique. Si "!" est placé avant le nom du premier plugin, le premier plugin a ses entrées connectées à system:capture_1 et system:capture_2. S'il est placé entre les noms de plugins, ces plugins sont connectés entre eux (la sortie du premier plugin est connectée à l'entrée du second plugin). S'il est placé après le nom du dernier plugin, les sorties audio de ce plugin sont connectées à system:playback_1 et system:playback_2 (paire de sortie principale).

BOGUES

Veuillez envoyer les rapports de bugs à <wdev@foltman.com>.

EXEMPLES

Pour démarrer monosynth avec connexion automatique à la première sortie audio système, et sans connexion MIDI automatique, utilisez :


calfjackhost monosynth !

(! signifie "connecter", le dernier "!" signifie "connecter à la sortie")

Autres exemples :


calfjackhost monosynth ! vintagedelay ! flanger ! -M 2

(exécute monosynth dans vintagedelay et vintagedelay dans flanger, puis vers la sortie ; connecte l'entrée MIDI de monosynth à system:midi_capture_2 de JACK)


calfjackhost "monosynth:Fat Bass"

(exécute monosynth avec un preset Fat Bass dans monosynth, ne se connecte pas automatiquement)


calfjackhost ! reverb !

(prend le signal de system:capture_1 et _2, le fait passer par reverb, et l'envoie ensuite à system:playback_1 et _2)

Note : aucune des fonctionnalités de connexion automatique ne fonctionnera si la connexion automatique est désactivée pour la gestion de session.
