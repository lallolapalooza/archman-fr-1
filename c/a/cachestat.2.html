cachestat(2) Manuel des appels système cachestat(2)

NOM

cachestat - interroger les statistiques du cache de pages d'un fichier

SYNTAXE

#include <sys/mman.h>
int cachestat(unsigned int fd, struct cachestat_range *cstat_range,
              struct cachestat *cstat, unsigned int flags);
struct cachestat_range {
    __u64 off;
    __u64 len;
};
struct cachestat {
    __u64 nr_cache;
    __u64 nr_dirty;
    __u64 nr_writeback;
    __u64 nr_evicted;
    __u64 nr_recently_evicted;
};

DESCRIPTION

cachestat() interroge le nombre de pages mises en cache, pages sales, pages marquées pour écriture, pages éjectées et pages récemment éjectées dans la plage d'octets spécifiée par .off et .len dans la structure cachestat_range.

Une page éjectée est une page qui était précédemment dans le cache de pages mais qui a depuis été éjectée. Une page est considérée comme récemment éjectée si sa réinsertion dans le cache indiquerait une utilisation active sous pression mémoire.

Les résultats sont retournés dans une structure cachestat, pointée par l'argument cstat.

Les champs .off et .len doivent être positifs. Si .len > 0, la plage interrogée est [.off, .off+.len]. Si len == 0, la plage s'étend de .off à la fin du fichier.

L'argument flags est réservé pour une utilisation future et doit être mis à 0.

Actuellement, les fichiers hugetlbfs ne sont pas pris en charge.

VALEUR DE RETOUR

En cas de succès, cachestat() renvoie 0. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EFAULT
cstat ou cstat_range pointent vers une adresse invalide.
EINVAL
Valeur flags invalide.
EBADF
Descripteur de fichier invalide.
EOPNOTSUPP
Le descripteur de fichier fait référence à un fichier hugetlbfs, qui n'est pas pris en charge.

NORMES

Linux.

HISTORIQUE

Linux 6.5.

MISE EN GARDE

Notez que l'état d'une page peut changer après que cachestat() l'a récupéré, mais avant que les valeurs ne soient renvoyées à l'application ; par conséquent, les valeurs peuvent être légèrement obsolètes.
