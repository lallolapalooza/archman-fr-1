__extern int caca_put_char (caca_canvas_t * cv, int x, int y, uint32_t

ch)

Affiche un caractère ASCII ou Unicode aux coordonnées données, en utilisant les valeurs par défaut de la couleur de premier plan et

d'arrière-plan.

Si les coordonnées sont en dehors des limites du canvas, rien n'est affiché. Si un caractère Unicode de pleine largeur est écrasé, ses parties visibles restantes sont remplacées par des espaces. Si les limites du canvas devaient diviser le caractère de pleine largeur en deux, un espace est affiché à la

place.

Le comportement lors de l'affichage de caractères non imprimables ou de caractères UTF-32 invalides est indéfini. Pour afficher une séquence d'octets formant un caractère UTF-8 au lieu d'un caractère UTF-32, utilisez la fonction caca_put_s

tr().

Cette fonction renvoie la largeur du caractère affiché. S'il s'agit d'un caractère de pleine largeur, 2 est renvoyé. Sinon, 1 est

renvoyé.

Cette fonction n'échoue

jamais.

cv Un descripteur du canvas libcaca.

afficher.

Retourn

La largeur du caractère affiché : 2 pour un caractère de pleine largeur, 1

__extern uint32_t caca_get_char (caca_canvas_t const * cv, int x, int

Obtient la valeur ASCII ou Unicode du caractère aux coordonnées données. Si la valeur est inférieure ou égale à 127 (0x7f), le caractère peut être affiché en ASCII. Sinon, il doit être traité comme une valeur

UTF-32.

Si les coordonnées sont en dehors des limites du canvas, un espace (0x20) est

renvoyé.

Une exception spéciale est lorsque CACA_MAGIC_FULLWIDTH est renvoyé. Cette valeur est garantie ne pas être un caractère Unicode valide, et indique que le caractère à gauche de celui demandé est un caractère de pleine

largeur.

__extern int caca_put_str (caca_canvas_t * cv, int x, int y, char const * s)

Imprime une chaîne UTF-8 aux coordonnées données, en utilisant les valeurs de premier plan et d'arrière-plan par défaut. Les coordonnées peuvent être en dehors des limites de la toile (par exemple, une coordonnée Y négative) et la chaîne sera recadrée en conséquence si elle est trop longue.

Voir caca_put_char() pour plus d'informations sur la façon dont les caractères pleine chasse sont gérés lorsqu'ils se remplacent mutuellement ou aux limites de la toile.

Cette fonction renvoie le nombre de cellules imprimées par la chaîne. Ce n'est pas le nombre de caractères imprimés, car les caractères pleine chasse comptent pour deux cellules.

Cette fonction ne échoue jamais.

Paramètres

cv Un pointeur vers la toile libcaca.
x Coordonnée X.
y Coordonnée Y.
s La chaîne à imprimer.

Retourne

Le nombre de cellules imprimées.

Références caca_put_char(), caca_utf32_is_fullwidth(), et caca_utf8_to_utf32().

Référencé par caca_vprintf().

__extern int caca_blit (caca_canvas_t * dst, int x, int y, caca_canvas_t const * src, caca_canvas_t const * mask)

Blit une toile sur une autre aux coordonnées données. Une toile de masque optionnelle peut être utilisée.

Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence :

•
EINVAL Un masque a été spécifié mais la taille du masque et la taille de la toile source ne correspondent pas.

Paramètres

dst La toile de destination.
x Coordonnée X.
y Coordonnée Y.
src La toile source.
mask La toile de masque.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

__extern int caca_set_canvas_boundaries (caca_canvas_t * cv, int x, int y, int w, int h)

Définit de nouvelles limites pour une toile. Cette fonction peut être utilisée pour recadrer une toile, l'agrandir ou pour des combinaisons des deux actions. Toutes les images sont affectées par cette fonction.

Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence :

  • EINVAL La largeur ou la hauteur spécifiée est invalide.
  • EBUSY La toile est utilisée par un pilote d'affichage et ne peut pas être redimensionnée.
  • ENOMEM Pas assez de mémoire pour la taille de toile demandée. Si cela se produit, le handle de toile devient invalide et ne doit pas être utilisé.

Paramètres

cv La toile à recadrer.
x Coordonnée X du coin supérieur gauche.
y Coordonnée Y du coin supérieur gauche.
w La largeur de la zone recadrée.
h La hauteur de la zone recadrée.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

Références caca_add_dirty_rect(), caca_blit(), caca_create_canvas(), caca_create_frame(), caca_get_frame_count(), et caca_set_frame().
