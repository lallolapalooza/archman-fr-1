catppt(1) Manuel des commandes générales catppt(1)

NOM

catppt - lit les fichiers MS-PowerPoint et place leur contenu sur la sortie standard

SYNTAXE

catppt [-lV] [-b chaîne ] [-s jeu de caractères ] [-d jeu de caractères ] fichiers

DESCRIPTION

catppt lit les présentations MS-PowerPoint et déverse leur contenu sur stdout.

OPTIONS

-l
liste les jeux de caractères connus et quitte avec succès
-bchaîne
chaîne de séparation des diapositives. Cette chaîne (par défaut, un saut de page) sera affichée à la fin de chaque diapositive.
-djeu de caractères`
- spécifie le nom du jeu de caractères de destination. Le fichier de jeu de caractères a le format décrit dans la section JEUX DE CARACTÈRES de la page de manuel de catdoc(1). Par défaut, le jeu de caractères de la locale actuelle serait utilisé si le support langinfo a été activé lors de la compilation.
-sjeu de caractères
- spécifie le jeu de caractères source. Typiquement, les fichiers PowerPoint utilisent des chaînes UNICODE avec des jeux de caractères connus, mais pour une raison quelconque, vous pourriez souhaiter le remplacer.
-V
affiche le numéro de version
