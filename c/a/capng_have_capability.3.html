NOM

capng_have_capability - vérifier la présence d'une capacité spécifique

SYNTAXE

#include <cap-ng.h>

int capng_have_capability(capng_type_t which, unsigned int capability);

DESCRIPTION

capng_have_capability vérifiera dans l'ensemble des capacités internes spécifié si la capacité spécifiée est définie. Les ensembles de capacités doivent être préalablement configurés par des appels à capng_get_caps_process, capng_get_caps_fd, ou configurés d'une autre manière. Les valeurs pour which doivent être l'une des suivantes : CAPNG_EFFECTIVE, CAPNG_PERMITTED, CAPNG_INHERITABLE, CAPNG_BOUNDING_SET, ou CAPNG_AMBIENT.

VALEUR DE RETOUR

Cette fonction retournera 1 si oui, et 0 sinon.

VOIR AUSSI

capng_get_caps_process(3), capng_get_caps_fd(3), capng_have_capabilities(3), capabilities(7)
