__extern int caca_draw_polyline (caca_canvas_t * cv, int const x[], int const y[], int n, uint32_t ch)

Dessine une polyligne sur la toile en utilisant le caractère et les tableaux de coordonnées donnés. Le premier et le dernier point ne sont pas connectés, donc pour dessiner un polygone, vous devez spécifier le point de départ à la fin de la liste également.

Cette fonction ne peut jamais échouer.

Paramètres

cv Le descripteur de la toile libcaca.
x Tableau des coordonnées X. Doit avoir n + 1 éléments.
y Tableau des coordonnées Y. Doit avoir n + 1 éléments.
n Nombre de lignes à dessiner.
ch Caractère UTF-32 à utiliser pour dessiner les lignes.

Retourne

Cette fonction retourne toujours 0.

__extern int caca_draw_thin_polyline (caca_canvas_t * cv, int const x[], int const y[], int n)

Dessine une polyligne fine sur la toile en utilisant les tableaux de coordonnées donnés et avec de l'art ASCII. Le premier et le dernier point ne sont pas connectés, donc pour dessiner un polygone, vous devez spécifier le point de départ à la fin de la liste également.

Cette fonction ne peut jamais échouer.

Paramètres

cv Le descripteur de la toile libcaca.
x Tableau des coordonnées X. Doit avoir n + 1 éléments.
y Tableau des coordonnées Y. Doit avoir n + 1 éléments.
n Nombre de lignes à dessiner.

Retourne

Cette fonction retourne toujours 0.
