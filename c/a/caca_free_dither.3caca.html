Description détaillée

Ces fonctions fournissent des routines de haut niveau pour l'allocation et le rendu du tramage.

Documentation des fonctions

__extern caca_dither_t * caca_create_dither (int bpp, int w, int h, int pitch, uint32_t rmask, uint32_t gmask, uint32_t bmask, uint32_t amask)

Crée une structure de tramage à partir de ses coordonnées (profondeur, largeur, hauteur et pas) et des valeurs de masques de pixels. Si la profondeur est de 8 bits par pixel, les valeurs de masques sont ignorées et la palette de couleurs doit être définie à l'aide de la fonction caca_set_dither_palette(). Pour les profondeurs supérieures à 8 bits par pixel, un masque alpha nul provoque l'ignorance des valeurs alpha.

Si une erreur se produit, NULL est renvoyé et errno est défini en conséquence :

  • EINVAL La largeur, la hauteur, le pas ou la valeur de bits par pixel demandés étaient invalides.
  • ENOMEM Mémoire insuffisante pour allouer la structure de tramage.

Paramètres

bpp Profondeur du bitmap en bits par pixel.
w Largeur du bitmap en pixels.
h Hauteur du bitmap en pixels.
pitch Pas du bitmap en octets.
rmask Masque de bits pour les valeurs rouges.
gmask Masque de bits pour les valeurs vertes.
bmask Masque de bits pour les valeurs bleues.
amask Masque de bits pour les valeurs alpha.

Renvoie

L'objet de tramage en cas de succès, NULL si une erreur s'est produite.

__extern int caca_set_dither_palette (caca_dither_t * d, uint32_t red[], uint32_t green[], uint32_t blue[], uint32_t alpha[])

Définit la palette d'un bitmap de 8 bits par pixel. Les valeurs doivent être comprises entre 0 et 4095 (0xfff).

Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence :

•
EINVAL La valeur de bits par pixel du tramage n'est pas 8, ou l'une des valeurs de pixel se trouve en dehors de la plage 0 - 4095.

Paramètres

d Objet de tramage.
red Tableau de 256 valeurs rouges.
green Tableau de 256 valeurs vertes.
blue Tableau de 256 valeurs bleues.
alpha Tableau de 256 valeurs alpha.

Renvoie

0 en cas de succès, -1 si une erreur s'est produite.

__extern int caca_dither_bitmap (caca_canvas_t * cv, int x, int y, int w, int h, caca_dither_t const * d, void const * pixels)

Applique le tramage à une image bitmap aux coordonnées données. Le trameur peut être de n'importe quelle taille et sera étiré pour remplir la zone de texte.

Cette fonction n'échoue jamais.

Paramètres

cv Un descripteur du canevas libcaca.
x Coordonnée X du coin supérieur gauche de la zone de dessin.
y Coordonnée Y du coin supérieur gauche de la zone de dessin.
w Largeur de la zone de dessin.
h Hauteur de la zone de dessin.
d Objet trameur à dessiner.
pixels Pixels du bitmap.

Renvoie

Cette fonction renvoie toujours 0.

Références CACA_BLACK, caca_get_attr(), caca_put_char(), caca_set_attr(), et caca_set_color_ansi().
