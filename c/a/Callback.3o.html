Module Callback
: sig end

Enregistrement de valeurs OCaml auprès du runtime C.

Ce module permet d'enregistrer des valeurs OCaml auprès du runtime C sous un nom symbolique, afin que le code C puisse ultérieurement rappeler les fonctions OCaml enregistrées, ou lever les exceptions OCaml enregistrées.

val register : string -> 'a -> unit

Callback.register n v enregistre la valeur v sous le nom n. Le code C peut ultérieurement récupérer une référence à v en appelant caml_named_value(n).

val register_exception : string -> exn -> unit

Callback.register_exception n exn enregistre l'exception contenue dans la valeur d'exception exn sous le nom n. Le code C peut ultérieurement récupérer une référence à l'exception en appelant caml_named_value(n). La valeur d'exception ainsi obtenue est adaptée pour être passée en premier argument à raise_constant ou raise_with_arg.
