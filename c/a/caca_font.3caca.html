Cette fonction charge une police et renvoie un descripteur vers sa structure interne. Ce descripteur peut ensuite être utilisé avec caca_render_canvas() pour une sortie

Les polices internes peuvent également être chargées : si size est défini à 0, data doit être une chaîne contenant le nom de la police

interne.
