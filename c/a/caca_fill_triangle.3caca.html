DESCRIPTION DÉTAILLÉE

Ces fonctions fournissent des routines pour le dessin de primitives, telles que des lignes, des boîtes, des triangles et des ellipses.

__extern int caca_draw_polyline (caca_canvas_t * cv, int const x[], int const y[], int n, uint32_t ch)

Dessine une polyligne sur le tampon en utilisant le caractère et les tableaux de coordonnées donnés. Les premier et dernier points ne sont pas connectés, donc afin de dessiner un polygone, vous devez spécifier le point de départ à la fin de la liste également.

Cette fonction ne échoue jamais.

Paramètres

cv Le handle vers le tampon libcaca.
x Tableau des coordonnées X. Doit contenir n + 1 éléments.
y Tableau des coordonnées Y. Doit contenir n + 1 éléments.
n Nombre de lignes à dessiner.
ch Caractère UTF-32 à utiliser pour dessiner les lignes.

Retourne

Cette fonction retourne toujours 0.

__extern int caca_draw_thin_polyline (caca_canvas_t * cv, int const x[], int const y[], int n)

Dessine une polyligne fine sur le tampon en utilisant les tableaux de coordonnées donnés et avec de l'art ASCII. Les premier et dernier points ne sont pas connectés, donc afin de dessiner un polygone, vous devez spécifier le point de départ à la fin de la liste également.
