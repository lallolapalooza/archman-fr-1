NOM

capng_setpid - définir le PID de travail

SYNTAXE

#include <cap-ng.h>

void capng_setpid(int pid);

DESCRIPTION

capng_pid définit le PID de travail pour les opérations de capacités. Ceci est utile si vous souhaitez obtenir les capacités d'un autre processus.

NOTES

Si votre processus appelle fork , le processus enfant aura toujours le PID du processus parent stocké dans les données internes de libcap-ng. Il est interdit d'effectuer tout type d'opération setcap car vous traverseriez des limites de processus. Pour corriger cela, si votre programme est lié à pthreads, alors libcap-ng utilisera la fonction pthread_atfork (en tant que symbole faible) pour réinitialiser automatiquement les informations de PID au nouveau processus. Vous n'êtes pas obligé de lier contre pthreads. Vous pouvez appeler capng_setpid et ajuster le PID stocké manuellement.

VALEUR DE RETOUR

Aucune.
