NOM

callgrind_annotate - outil de post-traitement pour Callgrind

SYNTAXE

callgrind_annotate [options] [fichier-sortie-callgrind [fichiers-source...]]

DESCRIPTION

callgrind_annotate prend un fichier de sortie produit par l'outil Valgrind Callgrind et affiche les informations sous une forme facile à lire.

OPTIONS

-h --help

Affiche un résumé des options.

--version

Affiche la version de callgrind_annotate.

--show=A,B,C [par défaut : all]

Affiche uniquement les chiffres pour les événements A, B, C.

--threshold=<0--100> [par défaut : 99 %]

Pourcentage des décomptes (de l'événement de tri principal) qui nous intéresse.

callgrind_annotate arrête d'imprimer les fonctions lorsque la somme du pourcentage de coût des fonctions imprimées est supérieure ou égale au pourcentage de seuil donné.

--sort=A,B,C

Trie les colonnes par les événements A, B, C [ordre des colonnes d'événements].

Optionnellement, chaque événement est suivi de : et d'un seuil, pour spécifier des seuils différents selon l'événement.

callgrind_annotate arrête d'imprimer les fonctions lorsque la somme du pourcentage de coût des fonctions imprimées pour tous les événements est supérieure ou égale aux pourcentages de seuils d'événements donnés.

Lorsque un ou plusieurs seuils sont donnés via cette option, la valeur de --threshold est ignorée.

--show-percs=<non|oui> [par défaut : non]

Lorsqu'il est activé, un pourcentage est imprimé à côté de tous les décomptes d'événements. Ceci aide à estimer l'importance relative de chaque fonction et ligne.

--auto=<oui|non> [par défaut : oui]

Annote tous les fichiers source contenant des fonctions qui ont contribué à atteindre le seuil de décompte d'événements.

--context=N [par défaut : 8]

Imprime N lignes de contexte avant et après les lignes annotées.

--inclusive=<oui|non> [par défaut : non]

Ajoute les coûts des sous-programmes aux appels de fonctions.

--tree=<aucun|appelant|appelé|les deux> [par défaut : aucun]

Imprime pour chaque fonction ses appelants, les fonctions appelées ou les deux.

-I, --include=<rép>

Ajoute rép à la liste des répertoires à rechercher pour les fichiers source.

VOIR AUSSI

valgrind(1), $INSTALL/share/doc/valgrind/html/index.html ou http://www.valgrind.org/docs/manual/index.html.
