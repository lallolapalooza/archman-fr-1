NOM

capng_fill - remplir un ensemble de capacités choisi

SYNTAXE

#include <cap-ng.h>

void capng_fill(capng_select_t set);

DESCRIPTION

capng_fill met tous les bits à 1 dans l'ensemble de capacités POSIX sélectionné. Les options sont CAPNG_SELECT_CAPS pour les capacités traditionnelles, CAPNG_SELECT_BOUNDS pour l'ensemble de limites, CAPNG_SELECT_BOTH si le remplissage des deux est désiré, CAPNG_SELECT_AMBIENT si seul l'exploitation des capacités ambiantes est désirée, ou CAPNG_SELECT_ALL si l'effacement de tout est désiré.

VALEUR DE RETOUR

Aucune.

NOTES

Lors de capng_apply, les bits dans l'ensemble de limites ne peuvent qu'être supprimés. Vous ne pouvez pas les définir.

VOIR AUSSI
