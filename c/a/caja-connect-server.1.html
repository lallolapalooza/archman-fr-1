NOM

Caja-connect-server - Dialogue de connexion au serveur pour Caja

SYNOPSIS

caja-connect-server [OPTIONS]

DESCRIPTION

Caja Connect Server est le gestionnaire de connexion pour Caja/MATE. Il est fourni dans le cadre du paquet Caja pour l'environnement de bureau MATE.

Lancer simplement "caja-connection-server" ouvrira un simple dialogue vous permettant de sélectionner le type de serveur et de spécifier l'adresse du serveur, le port et les identifiants de connexion pour le serveur auquel vous souhaitez vous connecter. C'est le même dialogue accessible via le menu "Fichier" de Caja et le menu "Places" de l'environnement de bureau MATE.

Vous pouvez utiliser le gestionnaire de fichiers Caja pour accéder à des serveurs distants tels que les serveurs SSH, FTP et WebDav (HTTP/HTTPS).

Si vous souhaitez monter et accéder à des serveurs distants via des commandes de console, vous devriez utiliser caja directement. Voir : caja(1)

OPTIONS

--display=DISPLAY
Affichage X à utiliser.
-?, -h, --help
Imprimer les options de ligne de commande standard.
--help-all
Imprimer toutes les options de ligne de commande.
