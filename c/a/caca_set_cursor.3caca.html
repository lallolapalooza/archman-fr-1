__extern caca_display_t * caca_create_display (caca_canvas_t *

cv)

Créer un contexte graphique utilisant des fonctionnalités dépendantes de l'appareil (ncurses pour les terminaux, une fenêtre X11, une fenêtre de commande DOS...) qui s'attache à un canevas libcaca. Tout ce qui est dessiné dans le canevas libcaca peut ensuite être affiché par le pilote

libcaca.

Si aucun canevas caca n'est fourni, un nouveau canevas est créé. Son descripteur peut être récupéré en utilisant caca_get_canvas() et il est automatiquement détruit lorsque caca_free_display() est

appelée.

Notez que pour atteindre une compatibilité Unicode maximale, le code d'initialisation du pilote peut temporairement modifier la locale LC_CTYPE globale du programme à l'aide de setlocale(). Il est conseillé de ne pas appeler les fonctions dépendant de LC_CTYPE depuis d'autres threads pendant l'appel à caca_create_display(). Les paramètres de la locale sont restaurés lorsque la fonction se

termine.

h_driver().
