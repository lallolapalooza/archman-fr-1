NOM

callgrind_control - observer et contrôler les programmes exécutés par Callgrind

SYNTAXE

callgrind_control [options] [pid|nom-programme...]

DESCRIPTION

callgrind_control contrôle les programmes exécutés par l'outil Valgrind, Callgrind. Lorsqu'un argument pid/nom-programme n'est pas spécifié, toutes les applications actuellement exécutées par Callgrind sur ce système seront utilisées pour les actions données par les options spécifiées. L'action par défaut est de fournir des informations brèves sur les applications exécutées par Callgrind.

OPTIONS

-h --help

Affiche une courte description, l'utilisation et un résumé des options.

--version

Affiche la version de callgrind_control.

-l --long

Affiche également le répertoire de travail, en plus des informations brèves fournies par défaut.

-s --stat

Affiche des informations statistiques sur les exécutions actives de Callgrind.

-b --back

Affiche les traces de pile/d'appel de chaque thread dans les exécutions actives de Callgrind. Pour chaque fonction active dans la trace de pile, le nombre d'invocations depuis le début du programme (ou depuis le dernier dump) est également affiché. Cette option peut être combinée avec -e pour afficher le coût inclusif des fonctions actives.

-e [A,B,...] (par défaut : tout)

Affiche les valeurs de coût exclusif actuelles par thread pour les compteurs d'événements. Si aucun nom d'événement explicite n'est donné, les chiffres pour tous les types d'événements collectés dans l'exécution Callgrind donnée sont affichés. Sinon, seuls les chiffres pour les types d'événements A, B, ... sont affichés. Si cette option est combinée avec -b, le coût inclusif pour les fonctions de chaque cadre de pile actif est également fourni.

--dump[=<desc>] (par défaut : pas de description)

Demande le vidage des informations de profilage. Optionnellement, une description peut être spécifiée, qui sera écrite dans le vidage comme partie des informations donnant la raison qui a déclenché l'action de vidage. Ceci peut être utilisé pour distinguer plusieurs vidages.

-z --zero

Remet à zéro tous les compteurs d'événements.

-k --kill

Force la terminaison d'une exécution Callgrind.

--instr=<on|off>

Active ou désactive le mode d'instrumentation. Si une exécution Callgrind a l'instrumentation désactivée, aucune simulation n'est effectuée et aucun événement n'est compté. Ceci est utile pour sauter des parties non intéressantes du programme, car le ralentissement est beaucoup moindre (identique à l'outil Valgrind "none"). Voir également l'option Callgrind --instr-atstart.

--vgdb-prefix=<prefix>

Spécifie le préfixe vgdb à utiliser par callgrind_control. callgrind_control utilise en interne vgdb pour trouver et contrôler les exécutions Callgrind actives. Si l'option --vgdb-prefix a été utilisée pour lancer valgrind, alors la même option doit être donnée à callgrind_control.

VOIR AUSSI

valgrind(1), $INSTALL/share/doc/valgrind/html/index.html ou http://www.valgrind.org/docs/manual/index.html.
