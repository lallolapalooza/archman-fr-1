CARDDAV-QUERY(1) Manuel des commandes générales CARDDAV-QUERY(1)

NOM

carddav-query - Interroger un serveur CardDAV pour les noms et adresses e-mail des contacts.

SYNTAXE

carddav-query [-h] [-l <limite>] [-v] [-c <fichier>] [-s <section>] [-k <source_clé>] [-C <cmd_crédentials_clé>] [-s <url_serveur>] [-u <nom_utilisateur>] [-p <mot_de_passe>] <terme> [<terme> ...]

Cet outil a été adapté pour être utilisé comme address-book-cmd dans aerc-config(5).

OPTIONS

-h, --help

afficher ce message d'aide et quitter

-v, --verbose

Afficher les informations de débogage sur stderr.

-l <limite>, --limit <limite>

Nombre maximum de résultats retournés par le serveur. Si le serveur ne prend pas en charge la limitation, cette option sera ignorée.

Par défaut : 10

-c <fichier>, --config-file <fichier>

Fichier de configuration INI à partir duquel lire le point de terminaison de l'URL CardDAV.

Par défaut : ~/.config/aerc/accounts.conf

-S <section>, --config-section <section>

Section de configuration INI où trouver <source_clé> et <cmd_crédentials_clé>. Par défaut, la première section où <source_clé> est trouvée sera utilisée.

-k <source_clé>, --config-key-source <source_clé>

Clé de configuration INI à rechercher dans <section> à partir de <fichier>. La valeur doit respecter le format suivant :
https?://<nom_utilisateur>[:<mot_de_passe>]@<nom_hôte>/<chemin/vers/carnet_adresses>

<nom_utilisateur> et <mot_de_passe> doivent tous deux être encodés en pourcentage. Si <mot_de_passe> est omis, il peut être fourni via --config-key-cred-cmd ou --password.

Par défaut : carddav-source

-C <cmd_crédentials_clé>, --config-key-cred-cmd <cmd_crédentials_clé>

Clé de configuration INI à rechercher dans <section> à partir de <fichier>. La valeur est une commande qui sera exécutée avec sh -c pour déterminer <mot_de_passe> s'il n'est pas présent dans <source_clé>.

Par défaut : carddav-source-cred-cmd

-s <url_serveur>, --server-url <url_serveur>

Point de terminaison de l'URL du serveur CardDAV. Remplace le fichier de configuration.

-u <nom_utilisateur>, --username <nom_utilisateur>

Nom d'utilisateur pour s'authentifier sur le serveur. Remplace le fichier de configuration.

-p <mot_de_passe>, --password <mot_de_passe>

Mot de passe pour l'utilisateur spécifié. Remplace le fichier de configuration.

ARGUMENTS POSITIONNELS

<terme>

Terme de recherche. Sera utilisé pour rechercher des contacts à partir de leurs champs FN (nom formaté), EMAIL, NICKNAME, ORG (entreprise) et TITLE.

EXEMPLES

Ce sont des extraits de ~/.config/aerc/accounts.conf.

Fastmail

[fastmail]
carddav-source = https://janedoe%40fastmail.com@carddav.fastmail.com/dav/addressbooks/user/janedoe@fastmail.com/Default
carddav-source-cred-cmd = pass fastmail.com/janedoe
address-book-cmd = carddav-query -S fastmail %s

Gmail

[gmail]
carddav-source = https://johndoe%40gmail.com@www.googleapis.com/carddav/v1/principals/johndoe@gmail.com/lists/default
carddav-source-cred-cmd = pass gmail.com/johndoe
address-book-cmd = carddav-query -S gmail %s
