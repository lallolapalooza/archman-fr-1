Description détaillée

Ces fonctions permettent de lire et d'écrire des fichiers de manière indépendante de la plateforme.

Documentation des fonctions

__extern caca_file_t * caca_file_open (char const * path, const char * mode)

Crée un descripteur de fichier caca pour un fichier. Si le fichier est zippé, il est décompressé à la volée.

En cas d'erreur, NULL est retourné et errno est défini en conséquence :

  • ENOSTS Fonction non implémentée.
  • EINVAL Fichier non trouvé ou permission refusée.

Paramètres

path Le chemin du fichier
mode Le mode d'ouverture du fichier

Retour

Un descripteur de fichier pour path.

Référencé par caca_import_canvas_from_file().

__extern int caca_file_close (caca_file_t * fp)

Ferme et détruit les ressources associées à un descripteur de fichier caca.

Cette fonction est un wrapper pour fclose() ou, si disponible, gzclose().

Paramètres

fp Le descripteur de fichier

Retour

La valeur de retour de fclose() ou gzclose().

__extern char * caca_file_gets (caca_file_t * fp, char * s, int size)

Lit une ligne de données depuis un descripteur de fichier, jusqu'à un octet de moins que le nombre d'octets donné. Un zéro final est ajouté aux données.

Paramètres

fp Le descripteur de fichier
s Le tampon de destination
size Le nombre maximum d'octets à lire

Retour

Le nombre d'octets lus, y compris le zéro final

__extern int caca_file_eof (caca_file_t * fp)

Retourne le statut de fin de fichier du descripteur de fichier.

Cette fonction est un wrapper pour feof() ou, si disponible, gzeof().

Paramètres

Retour

1 si la fin de fichier a été atteinte, 0 sinon
