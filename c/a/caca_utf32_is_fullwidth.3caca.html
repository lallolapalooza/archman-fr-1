__extern uint32_t caca_utf8_to_utf32 (char const * s, size_t * bytes)

Convertit un caractère UTF-8 lu à partir d'une chaîne et retourne sa valeur dans le jeu de caractères UTF-32. Si le deuxième argument n'est pas nul, le nombre total d'octets lus y est écrit.

Si un octet nul est rencontré avant la fin attendue de la séquence UTF-8, cette fonction retourne zéro et le nombre d'octets lus est mis à zéro.

Cette fonction ne échoue jamais, mais son comportement avec des séquences UTF-8 illégales est indéfini.

Paramètres

s Une chaîne contenant le caractère UTF-8.
bytes Un pointeur vers un size_t pour stocker le nombre d'octets dans le caractère, ou NULL.

Retourne

Le caractère UTF-32 correspondant, ou zéro si le caractère est incomplet.

Référencé par caca_put_str().

__extern size_t caca_utf32_to_utf8 (char * buf, uint32_t ch)

Convertit un caractère UTF-32 lu à partir d'une chaîne et écrit sa valeur dans le jeu de caractères UTF-8 dans le tampon donné.

Cette fonction ne échoue jamais, mais son comportement avec des caractères UTF-32 illégaux est indéfini.

Paramètres

buf Un pointeur vers un tampon de caractères où la séquence UTF-8 sera écrite.
ch Le caractère UTF-32.

Retourne

Le nombre d'octets écrits.

__extern uint8_t caca_utf32_to_cp437 (uint32_t ch)

Convertit un caractère UTF-32 lu à partir d'une chaîne et retourne sa valeur dans le jeu de caractères CP437, ou '?' si le caractère n'a pas d'équivalent.

Cette fonction ne échoue jamais.

Paramètres

ch Le caractère UTF-32.

Retourne

Le caractère CP437 correspondant, ou '?' s'il n'est pas représentable.

__extern uint32_t caca_cp437_to_utf32 (uint8_t ch)

Convertit un caractère CP437 lu à partir d'une chaîne et retourne sa valeur dans le jeu de caractères UTF-32, ou zéro si le caractère est un caractère de contrôle CP437.

Cette fonction ne échoue jamais.

Paramètres

ch Le caractère CP437.

Retourne

Le caractère UTF-32 correspondant, ou zéro s'il n'est pas représentable.

__extern char caca_utf32_to_ascii (uint32_t ch)

Convertit un caractère UTF-32 en caractère ASCII. Lorsqu'aucun équivalent n'existe, un équivalent graphiquement proche est recherché.

Cette fonction ne échoue jamais, mais son comportement avec des caractères UTF-32 illégaux est indéfini.

Paramètres

ch Le caractère UTF-32.

Retourne

Le caractère ASCII correspondant, ou un équivalent graphiquement proche s'il est trouvé, ou '?' s'il n'est pas représentable.

__extern int caca_utf32_is_fullwidth (uint32_t ch)

Vérifie si le caractère UTF-32 donné doit être imprimé avec une largeur double de la normale (caractères pleine largeur). Si le caractère est inconnu ou si son statut ne peut être déterminé, il est traité comme un caractère de largeur standard.

Cette fonction ne échoue jamais.

Paramètres

ch Le caractère UTF-32.

Retourne

1 si le caractère est pleine largeur, 0 sinon.

Référencé par caca_put_char(), et caca_put_str().
