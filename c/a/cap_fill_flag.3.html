NOM

cap_clear, cap_clear_flag, cap_get_flag, cap_set_flag, cap_fill_flag, cap_fill, cap_compare, cap_max_bits - manipulation d'objets de données de capacités

SYNOPSIS

#include <sys/capability.h>
int cap_clear(cap_t cap_p);
int cap_clear_flag(cap_t cap_p, cap_flag_t flag);
int cap_get_flag(cap_t cap_p, cap_value_t cap,
                 cap_flag_t flag, cap_flag_value_t *value_p);
int cap_set_flag(cap_t cap_p, cap_flag_t flag, int ncap,
                 const cap_value_t *caps, cap_flag_value_t value);
int cap_fill_flag(cap_t cap_p, cap_flag_t to,
                  const cap_t ref, cap_flag_t from);
int cap_fill(cap_t cap_p, cap_flag_t to, cap_flag_t from);
int cap_compare(cap_t cap_a, cap_t cap_b);
cap_value_t cap_max_bits();

Liez avec -lcap.

DESCRIPTION

Ces fonctions travaillent sur un état de capacités conservé dans une zone de travail. Une cap_t contient des informations sur les capacités dans chacun des trois indicateurs (flags) : Permis (Permitted), Héritable (Inheritable) et Effectif (Effective). Chaque capacité dans un ensemble peut être effacée (désactivée, 0) ou définie (activée, 1).

Ces fonctions travaillent avec les types de données suivants :

cap_value_t
identifie une capacité, telle que CAP_CHOWN.
cap_flag_t
identifie l'un des trois indicateurs associés à une capacité (c'est-à-dire qu'il identifie l'une des trois dimensions de capacités). Les valeurs valides pour ce type sont CAP_EFFECTIVE, CAP_INHERITABLE ou CAP_PERMITTED.
cap_flag_value_t
identifie le réglage d'un indicateur de capacité particulier (c'est-à-dire la valeur d'une capacité dans un ensemble). Les valeurs valides pour ce type sont CAP_CLEAR (0) ou CAP_SET (1).

cap_clear() initialise l'état de capacités dans la zone de travail identifiée par cap_p afin que tous les indicateurs de capacités soient effacés.

cap_clear_flag() efface toutes les capacités de l'indicateur de capacité spécifié, flag.

cap_get_flag() obtient la valeur actuelle de l'indicateur de capacité, flag, de la capacité, cap, à partir de l'état de capacités identifié par cap_p et la place à l'emplacement pointé par value_p.

cap_set_flag() définit l'indicateur, flag, de chaque capacité dans le tableau caps dans l'état de capacités identifié par cap_p à la valeur value. L'argument, ncap, est utilisé pour spécifier le nombre de capacités dans le tableau, caps.

cap_fill_flag() remplit l'indicateur « to » d'un ensemble de capacités, avec les valeurs de l'indicateur « from » d'un ensemble de capacités de référence.

cap_fill() remplit les valeurs de l'indicateur « to » en copiant toutes les valeurs de l'indicateur « from ».

cap_compare() compare deux ensembles complets de capacités et, dans l'esprit de memcmp(), renvoie zéro si les deux ensembles de capacités sont identiques. Une valeur de retour positive indique qu'il y a une différence entre eux. La valeur retournée transporte des informations supplémentaires sur les différences de cap_flag_t flag. Spécifiquement, la macro CAP_DIFFERS(value, flag) s'évalue à non nul si la value retournée diffère dans ses composantes flag.

cap_max_bits() renvoie le nombre de valeurs de capacité connues du noyau en cours d'exécution. Cela peut différer de la liste de libcap connue au moment de la compilation. Les capacités non nommées au moment de la compilation peuvent être référencées numériquement et libcap les gérera correctement. Notez que le noyau en cours d'exécution a le dernier mot et définit ce que signifie « toutes » les capacités.

VALEUR DE RETOUR

cap_clear(), cap_clear_flag(), cap_get_flag() cap_set_flag() et cap_compare() renvoient zéro en cas de succès, et -1 en cas d'échec. D'autres valeurs de retour pour cap_compare() sont décrites ci-dessus. La fonction cap_max_bits() renvoie une valeur numérique de type cap_value_t qui est supérieure de un à la plus grande valeur réelle connue du noyau en cours d'exécution.

En cas d'échec, errno est défini à EINVAL, indiquant qu'un des arguments est invalide.

CONFORMITE

Ces fonctions sont pour la plupart conformes à la spécification retirée du projet POSIX.1e. Les extensions Linux suivantes sont : cap_fill(), cap_fill_flag(), cap_clear_flag(), cap_compare() et cap_max_bits().
