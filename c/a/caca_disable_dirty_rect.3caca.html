Description détaillée

Ces fonctions manipulent les rectangles sales pour un blitting optimisé.

Documentation des fonctions

__extern int caca_disable_dirty_rect (caca_canvas_t * cv)

Désactiver le traitement des rectangles sales pour tous les appels graphiques libcaca . C'est pratique lorsque l'application appelante doit effectuer des opérations lentes dans une zone connue. Appelez simplement caca_add_dirty_rect() par la suite.

Cette fonction est récursive. Les rectangles sales ne sont réactivés que lorsque caca_enable_dirty_rect() est appelé autant de fois.

Cette fonction n'échoue jamais.

Paramètres

cv Une cavale libcaca.

Retourne

Cette fonction renvoie toujours 0.

__extern int caca_enable_dirty_rect (caca_canvas_t * cv)

Cette fonction ne peut être appelée qu'après que caca_disable_dirty_rect() a été appelée.

Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence :

•
EINVAL Les rectangles sales n'ont pas été désactivés.

Paramètres

cv Une cavale libcaca.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

__extern int caca_get_dirty_rect_count (caca_canvas_t * cv)

Obtenir le nombre de rectangles sales dans une cavale. Les rectangles sales sont des zones contenant des cellules qui ont changé depuis la dernière réinitialisation.

Les rectangles sales sont utilisés en interne par les pilotes d'affichage pour optimiser le rendu en évitant de redessiner tout l'écran. Une fois que le pilote d'affichage a rendu la cavale, il réinitialise la liste des rectangles sales.

Les rectangles sales sont garantis de ne pas se chevaucher.

Cette fonction n'échoue jamais.

Paramètres

cv Une cavale libcaca.

Retourne

Le nombre de rectangles sales dans la cavale donnée.

__extern int caca_get_dirty_rect (caca_canvas_t * cv, int r, int * x, int * y, int * width, int * height)

Obtenir les coordonnées du rectangle sale demandé de la cavale. L'index doit être compris dans le nombre de rectangles sales. Voir caca_get_dirty_rect_count() pour savoir comment calculer ce nombre.

Si une erreur se produit, aucune coordonnée n'est écrite dans les arguments pointeurs, -1 est renvoyé et errno est défini en conséquence :

•
EINVAL L'index du rectangle spécifié est hors limites.

Paramètres

cv Une cavale libcaca.
r L'index du rectangle demandé.
x Un pointeur vers un entier où le bord le plus à gauche du rectangle sale sera stocké.
y Un pointeur vers un entier où le bord le plus haut du rectangle sale sera stocké.
width Un pointeur vers un entier où la largeur du rectangle sale sera stockée.
height Un pointeur vers un entier où la hauteur du rectangle sale sera stockée.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

__extern int caca_add_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

Ajouter une zone d'invalidation à la liste des rectangles sales de la cavale. Pour plus d'informations sur les rectangles sales, voir caca_get_dirty_rect().

Cette fonction peut être utile pour forcer le rafraîchissement d'une zone donnée de la cavale même si le suivi des rectangles sales indique qu'elle est inchangée. Cela peut se produire si le contenu de la cavale a été modifié d'une certaine manière directe.

Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence :

•
EINVAL Les coordonnées du rectangle spécifié sont hors limites.

Paramètres

cv Une cavale libcaca.
x Le bord le plus à gauche du rectangle sale supplémentaire.
y Le bord le plus haut du rectangle sale supplémentaire.
width La largeur du rectangle sale supplémentaire.
height La hauteur du rectangle sale supplémentaire.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

Référencé par caca_blit(), caca_clear_canvas(), caca_fill_box(), caca_flip(), caca_flop(), caca_free_frame(), caca_invert(), caca_put_attr(), caca_put_char(), caca_rotate_180(), caca_rotate_left(), caca_rotate_right(), caca_set_canvas_boundaries(), caca_set_frame(), caca_stretch_left(), et caca_stretch_right().

__extern int caca_remove_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

Marquer une zone de cellules dans la cavale comme non sale. Pour plus d'informations sur les rectangles sales, voir caca_get_dirty_rect().

Des valeurs telles que xmin > xmax ou ymin > ymax indiquent que le rectangle sale est vide. Elles seront ignorées silencieusement.

Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence :

•
EINVAL Les coordonnées du rectangle spécifié sont hors limites.

Paramètres

cv Une cavale libcaca.
x Le bord le plus à gauche du rectangle propre.
y Le bord le plus haut du rectangle propre.
width La largeur du rectangle propre.
height La hauteur du rectangle propre.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

__extern int caca_clear_dirty_rect_list (caca_canvas_t * cv)

Videz la liste des rectangles de mise à jour du canevas.

Cette fonction ne renvoie jamais d'erreur.

Paramètres

cv Un canevas libcaca.

Retour

Cette fonction renvoie toujours 0.
