Description détaillée

Ces fonctions fournissent des routines de gestion de polices bitmap et des rendus de canevas vers bitmap de haute qualité.

Documentation des fonctions

__extern caca_font_t * caca_load_font (void const * data, size_t size)

Cette fonction charge une police et renvoie un descripteur vers sa structure interne. Ce descripteur peut ensuite être utilisé avec caca_render_canvas() pour la sortie bitmap.

Les polices internes peuvent également être chargées : si size est mis à 0, data doit être une chaîne contenant le nom de la police interne.

Si size est non nul, les octets de mémoire de taille à l'adresse data sont chargés comme une police. Cette zone mémoire ne doit pas être libérée par le programme appelant tant que le descripteur de police n'a pas été libéré avec caca_free_font().

En cas d'erreur, NULL est renvoyé et errno est défini en conséquence :

  • ENOENT La police intégrée demandée n'existe pas.
  • EINVAL Données de police invalides dans la zone mémoire.
  • ENOMEM Pas assez de mémoire pour allouer la structure de police.

Paramètres

data La zone mémoire contenant la police ou son nom.
size La taille de la zone mémoire, ou 0 si le nom de la police est donné.

Retour

Un descripteur de police ou NULL en cas d'erreur.

__extern int caca_get_font_width (caca_font_t const * f)

Renvoie la valeur standard pour les glyphes de la police courante. La plupart des glyphes de la police auront cette largeur, à l'exception des caractères pleine chasse.

Cette fonction ne faillit jamais.

Paramètres

f La police, telle que renvoyée par caca_load_font()

Retour

La largeur standard des glyphes.

__extern uint32_t const * caca_get_font_blocks (caca_font_t const * f)

Cette fonction renvoie la liste des blocs Unicode pris en charge par la police donnée. La liste est une liste d'indices terminée par zéro. Voici un exemple :

{
   0x0000, 0x0080,   // Latin de base : A, B, C, a, b, c
   0x0080, 0x0100,   // Supplément Latin-1 : "A, 'e, ^u
   0x0530, 0x0590,   // Arménien
   0x0000, 0x0000,   // FIN
};

Cette fonction ne faillit jamais.

Paramètres

f La police, telle que renvoyée par caca_load_font()

Retour

La liste des blocs Unicode pris en charge par la police.

__extern int caca_render_canvas (caca_canvas_t const * cv, caca_font_t const * f, void * buf, int width, int height, int pitch)

Cette fonction rend le canevas donné sur un tampon d'image en utilisant une police spécifique. Le format de pixel est fixe (ARGB 32 bits, 8 bits pour chaque composant).

La largeur d'image requise peut être calculée en utilisant caca_get_canvas_width() et caca_get_font_width(). La hauteur requise peut être calculée en utilisant caca_get_canvas_height() et caca_get_font_height().

Les glyphes qui ne rentrent pas dans le tampon d'image ne sont actuellement pas rendus du tout. Ils pourraient être rognés à la place dans les futures versions.

En cas d'erreur, -1 est renvoyé et errno est défini en conséquence :

•
EINVAL Largeur, hauteur ou pas invalides spécifiés.

Paramètres

cv Le canevas à rendre
f La police, telle que renvoyée par caca_load_font()
buf Le tampon d'image
width La largeur (en pixels) du tampon d'image
height La hauteur (en pixels) du tampon d'image
pitch Le pas (en octets) d'une ligne du tampon d'image.

Retour

0 en cas de succès, -1 si une erreur s'est produite.

__extern int caca_free_font (caca_font_t * f)

Cette fonction libère toutes les données allouées par caca_load_font(). La structure de police n'est plus utilisable par d'autres fonctions libcaca. Une fois cette fonction terminée, la zone mémoire qui a été fournie à caca_load_font() peut être libérée.

Cette fonction ne faillit jamais.

Paramètres

f La police, telle que renvoyée par caca_load_font()

Retour

Cette fonction renvoie toujours 0.
