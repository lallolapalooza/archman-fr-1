Description détaillée

Ces fonctions fournissent des routines de haut niveau pour l'insertion, la suppression, la copie, etc. d'images de canevas.

Documentation des fonctions

Retourne le nombre d'images du canevas courant.

Cette fonction ne peut jamais échouer.

cv Un canevas libcaca

Retourne

__extern int caca_set_frame (caca_canvas_t * cv, int id)

Définit l'image active du canevas. Toutes les opérations de dessin ultérieures seront effectuées sur cette image. Le contexte de dessin actuel défini par caca_set_attr() est hérité.

Si l'indice de l'image est en dehors de la plage des images du canevas, rien ne se passe.

En cas d'erreur, -1 est retourné et errno est défini conformément :

•
EINVAL L'image demandée est hors plage.

Paramètres

cv Un canevas libcaca
id L'image du canevas à activer

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

__extern char const * caca_get_frame_name (caca_canvas_t const * cv)

Retourne le nom de l'image courante. La chaîne retournée est valide jusqu'à ce que l'image soit supprimée ou que caca_set_frame_name() soit appelée pour changer à nouveau le nom de l'image.

Cette fonction ne peut jamais échouer.

Paramètres

cv Un canevas libcaca.

Retourne

Le nom de l'image courante.

__extern int caca_set_frame_name (caca_canvas_t * cv, char const * name)

Définit le nom de l'image courante. Lors de sa création, une image a un nom par défaut de 'frame#xxxxxxxx' où xxxxxxxx est un numéro hexadécimal auto-incrémenté.

En cas d'erreur, -1 est retourné et errno est défini conformément :

•
ENOMEM Pas assez de mémoire pour allouer la nouvelle image.

Paramètres

cv Un canevas libcaca.
name Le nom à donner à l'image courante.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

__extern int caca_create_frame (caca_canvas_t * cv, int id)

Crée une nouvelle image dans le canevas donné. Son contenu et ses attributs sont copiés de l'image active courante.

L'indice de l'image indique où l'image doit être insérée. Les valeurs valides vont de 0 au nombre actuel d'images du canevas. Si l'indice de l'image est supérieur ou égal au nombre actuel d'images du canevas, la nouvelle image est ajoutée à la fin du canevas. Si l'indice de l'image est inférieur à zéro, la nouvelle image est insérée à l'indice 0.

L'image active ne change pas, mais son indice peut être renuméroté en raison de l'insertion.

En cas d'erreur, -1 est retourné et errno est défini conformément :

•
ENOMEM Pas assez de mémoire pour allouer la nouvelle image.

Paramètres

cv Un canevas libcaca
id L'indice où insérer la nouvelle image

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

Référencé par caca_set_canvas_boundaries().

__extern int caca_free_frame (caca_canvas_t * cv, int id)

Supprime une image d'un canevas donné.

L'indice de l'image indique l'image à supprimer. Les valeurs valides vont de 0 au nombre actuel d'images du canevas moins 1. Si l'indice de l'image est supérieur ou égal au nombre actuel d'images du canevas, la dernière image est supprimée.

Si l'image active est supprimée, l'image 0 devient la nouvelle image active. Sinon, l'image active ne change pas, mais son indice peut être renuméroté en raison de la suppression.

En cas d'erreur, -1 est retourné et errno est défini conformément :

•
EINVAL L'image demandée est hors plage, ou tentative de supprimer la dernière image du canevas.

Paramètres

cv Un canevas libcaca
id L'indice de l'image à supprimer

Retourne

0 en cas de succès, -1 si une erreur s'est produite.
