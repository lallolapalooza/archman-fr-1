__extern int caca_put_char (caca_canvas_t * cv, int x, int y, uint32_t

ch)

Affiche un caractère ASCII ou Unicode aux coordonnées données, en utilisant les valeurs de couleur de premier plan et d'arrière-plan par

défaut.

Si les coordonnées sont en dehors des limites du canvas, rien n'est imprimé. Si un caractère Unicode pleine largeur est écrasé, ses parties visibles restantes sont remplacées par des espaces. Si les limites du canvas devaient diviser le caractère pleine largeur en deux, un espace est imprimé à la

place.

Le comportement lors de l'impression de caractères non imprimables ou de caractères UTF-32 invalides est indéfini. Pour imprimer une séquence d'octets formant un caractère UTF-8 au lieu d'un caractère UTF-32, utilisez la fonction caca_put_str()

.

Cette fonction retourne la largeur du caractère imprimé. S'il s'agit d'un caractère pleine largeur, 2 est retourné. Sinon, 1 est

retourné.

Cette fonction ne échoue

jamais.

    caca_vprintf(3caca)

    Nom

    caca_vprintf - afficher un texte formaté dans une couche Caca

    Syntaxe

    #include <caca.h>

    int caca_vprintf(caca_handle_t *handle, const char *format, va_list args);

    Description

    La fonction caca_vprintf() est l'équivalent de la fonction vprintf(3) de la bibliothèque standard C, mais elle écrit dans la couche d'affichage Caca spécifiée par handle.

    Elle prend un pointeur vers la couche Caca (handle), une chaîne de caractères de format (format) et une liste d'arguments de taille variable (args).

    Le format de chaîne est le même que celui utilisé par printf(3).

    La fonction caca_vprintf() est souvent utilisée pour implémenter des fonctions d'affichage personnalisées qui nécessitent un formatage avancé.

    Les arguments de format sont les suivants :

    • %% : un signe de pourcentage littéral.
    • %c : un caractère.
    • %s : une chaîne de caractères.
    • %d, %i : un entier signé en base 10.
    • %u : un entier non signé en base 10.
    • %x, %X : un entier signé en hexadécimal.
    • %p : un pointeur.

    Des drapeaux et des spécificateurs de largeur/précision peuvent également être utilisés, tels que décrits dans la page de manuel printf(3).

    Valeur retournée

    Au succès, caca_vprintf() retourne le nombre total de caractères écrits. En cas d'erreur, elle retourne un entier négatif.

    Exemple

    
#include <caca.h>
#include <stdarg.h>
#include <stdio.h>

int main(void) {
    caca_handle_t *handle = caca_create_handle();
    caca_canvas_t *canvas = caca_create_canvas(80, 24);
    caca_set_canvas(handle, canvas);

    char *message = "Bonjour le monde !";
    int nombre = 42;

    caca_vprintf(handle, "Ceci est un message : %s et un nombre : %d\n", (va_list){message, nombre});

    caca_free_canvas(canvas);
    caca_free_handle(handle);
    return 0;
}

    Avertissement

    Notez que l'exemple ci-dessus est simplifié. Dans une utilisation réelle, la liste d'arguments args doit être gérée correctement avec les fonctions de la bibliothèque standard C telles que va_start, va_arg et va_end.
