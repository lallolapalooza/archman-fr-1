Diverses Options

-j N, --jobs N

Nombre de tâches parallèles à exécuter. Peut également être spécifié avec la build.jobs valeur de configuration https://doc.rust-lang.org/cargo/reference/config.html. Par défaut, c'est le nombre de CPU logiques. Si négatif, cela définit le nombre maximal de tâches parallèles au nombre de CPU logiques plus la valeur fournie. Si une chaîne default est fournie, cela rétablit la valeur par défaut. Ne doit pas être 0.

--keep-going

Construit autant de crates que possible dans le graphe de dépendances, plutôt que d'interrompre la construction au premier qui échoue.

Par exemple, si le paquet actuel dépend de dépendances fails et works, dont l'une échoue à la construction, cargo rustc -j1 peut ou non construire celle qui réussit (selon laquelle des deux constructions Cargo a choisi d'exécuter en premier), alors que cargo rustc -j1 --keep-going exécuterait définitivement les deux constructions, même si celle exécutée en premier échoue.

--future-incompat-report

Affiche un rapport d'incompatibilité future pour tous les avertissements d'incompatibilité future produits lors de l'exécution de cette commande

Voir cargo-report(1)

EXEMPLES

1.Vérifier si votre paquet (sans compter les dépendances) utilise du code unsafe : 
cargo rustc --lib -- -D unsafe-code
2.Essayer un drapeau expérimental sur le compilateur nightly, comme celui-ci qui affiche la taille de chaque type : 
cargo rustc --lib -- -Z print-type-sizes
3.Surcharger le champ crate-type dans Cargo.toml avec une option en ligne de commande : 
cargo rustc --lib --crate-type lib,cdylib
