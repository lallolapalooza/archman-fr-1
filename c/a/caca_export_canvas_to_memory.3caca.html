Documentation des fonctions __extern ssize_t caca_import_canvas_from_memory ( caca_canvas_t* cv, void const * data, size_t len, char const * format)
Importe un tampon mémoire dans la trame courante du canevas libcaca donné. La trame courante est redimensionnée en conséquence et son contenu est remplacé par les données importées. Les valeurs valides pour format sont :
'' : tente de détecter automatiquement le format du fichier. 'caca' : importe les fichiers natifs libcaca.'text' : importe les fichiers de texte ASCII.
'ansi' : importe les fichiers ANSI. 'utf8' : importe les fichiers UTF-8 avec codes de couleur ANSI. 'bin' : importe les fichiers BIN.Le nombre d'octets lus est renvoyé. Si le format de fichier est valide, mais que les données disponibles étaient insuffisantes, 0 est renvoyé.
Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence :
ENOMEM Mémoire insuffisante pour allouer le canevas.

EOVERFLOW L'importation des données a provoqué un débordement de

valeur.

EINVAL Format demandé invalide.

__extern void * caca_export_canvas_to_memory (caca_canvas_t const * cv, char const * format, size_t * bytes)

Cette fonction exporte une toile libcaca dans divers formats étrangers tels que l'art ANSI, le HTML, les couleurs IRC, etc. Le pointeur retourné doit être passé à free() pour libérer le stockage alloué lorsqu'il n'est plus nécessaire.

Les valeurs valides pour format sont :

  • 'caca': exporte les fichiers natifs libcaca.
  • 'ansi': exporte l'art ANSI (jeu de caractères CP437 avec codes couleur ANSI).
  • 'html': exporte une page HTML avec des informations CSS.
  • 'html3': exporte un tableau HTML qui devrait être compatible avec la plupart des navigateurs, y compris ceux en mode texte.
  • 'irc': exporte du texte UTF-8 avec des codes couleur mIRC.
  • 'ps': exporte un document PostScript.
  • 'svg': exporte une image vectorielle SVG.
  • 'tga': exporte une image TGA.
  • 'troff': exporte une source troff.

Si une erreur se produit, NULL est retourné et errno est défini en conséquence :

  • EINVAL Format non supporté demandé.
  • ENOMEM Pas assez de mémoire pour allouer le tampon de sortie.

Paramètres

cv Une toile libcaca
format Une chaîne décrivant le format de sortie demandé.
bytes Un pointeur vers une size_t où le nombre d'octets alloués sera écrit.

Retourne

Un pointeur vers la zone mémoire exportée, ou NULL en cas d'erreur.

__extern void * caca_export_area_to_memory (caca_canvas_t const * cv, int x, int y, int w, int h, char const * format, size_t * bytes)

Cette fonction exporte une partie d'une toile libcaca dans divers formats. Pour plus d'informations, voir caca_export_canvas_to_memory().

Si une erreur se produit, NULL est retourné et errno est défini en conséquence :

  • EINVAL Format non supporté demandé ou coordonnées invalides.
  • ENOMEM Pas assez de mémoire pour allouer le tampon de sortie.
