NOM

calibrate_lens_gui - Calibration de distorsion d'objectif par identification de caractéristiques linéaires droites

SYNTAXE

calibrate_lens_gui

DESCRIPTION

calibrate_lens_gui est un outil graphique pour la calibration des objectifs.

Cette page de manuel est un brouillon, la documentation complète de l'interface graphique se trouve dans le manuel en ligne disponible dans le menu Aide de Hugin(1).

OPTIONS

calibrate_lens_gui n'a pas d'options ou de paramètres en ligne de commande.
