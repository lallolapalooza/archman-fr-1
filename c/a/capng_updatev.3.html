CAPNG_UPDATEV(3) API Libcap-ng CAPNG_UPDATEV(3)

NOM

capng_updatev - met à jour les paramètres de capacités stockés

SYNTAXE

#include <cap-ng.h>

int capng_updatev(capng_act_t action, capng_type_t type, unsigned int capability, ...);

DESCRIPTION

capng_updatev mettra à jour les paramètres de capacités POSIX internes en fonction des options qui lui sont passées. L'action doit être soit CAPNG_DROP pour définir le bit de capacité à 0, soit CAPNG_ADD pour définir le bit de capacité à 1. L'opération est effectuée sur l'ensemble de capacités spécifié dans le paramètre type. Les valeurs sont : CAPNG_EFFECTIVE, CAPNG_PERMITTED, CAPNG_INHERITABLE, CAPNG_BOUNDING_SET, ou CAPNG_AMBIENT. Les valeurs peuvent être combinées par OR pour effectuer la même opération sur plusieurs ensembles. Le dernier paramètre, capability, est la capacité définie comme donné dans linux/capability.h.

Cette fonction diffère de capng_update en ce qu'elle vous permet de passer une liste de capacités. Cette liste doit être terminée par une valeur -1.

VALEUR DE RETOUR

Retourne 0 en cas de succès et -1 en cas d'échec.

VOIR AUSSI

capng_update(3), capabilities(7)
