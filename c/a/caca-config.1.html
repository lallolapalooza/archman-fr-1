NOM

caca-config - script pour obtenir des informations sur la version installée de libcaca

SYNTAXE

caca-config [ --prefix= DIR] [ --exec-prefix= DIR] [ --version ] [ --libs ] [ --cflags ]

DESCRIPTION

caca-config est un outil utilisé pour configurer et déterminer les indicateurs du compilateur et de l'éditeur de liens qui devraient être utilisés pour compiler et lier des programmes, des bibliothèques et des plugins utilisant libcaca.

L'utilisation de caca-config est dépréciée. L'outil plus générique pkg-config devrait être utilisé à la place.

OPTIONS

--cflags
Affiche les indicateurs du compilateur nécessaires pour compiler un programme ou une bibliothèque utilisant libcaca.
--exec-prefix=DIR
Si spécifié, utilise DIR au lieu du préfixe d'exécution d'installation avec lequel libcaca a été construit lors du calcul de la sortie pour les options --cflags et --libs. Cette option doit être spécifiée avant toute option --cflags et --libs.
--libs
Affiche les indicateurs de l'éditeur de liens nécessaires pour lier un programme ou une bibliothèque utilisant libcaca.
--prefix=DIR
Si spécifié, utilise PREFIX au lieu du préfixe d'installation avec lequel libcaca a été construit lors du calcul de la sortie pour les options --cflags et --libs. Cette option est également utilisée pour le préfixe d'exécution si --exec-prefix n'a pas été spécifié. Cette option doit être spécifiée avant toute option --cflags et --libs.
--version
Affiche la version actuellement installée de libcaca sur la sortie standard.

EXEMPLES

gcc -o main.o $(caca-config --cflags) -c main.c
Est la manière dont vous pourriez utiliser caca-config pour compiler un fichier source C pour un programme exécutable.
gcc -o my_app $(caca-config --libs) main.o util.o
Est la manière dont vous pourriez utiliser caca-config pour lier des objets compilés dans un programme exécutable.
