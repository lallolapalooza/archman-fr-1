carg(3) Manuel des fonctions de bibliothèque carg(3)

NOM

carg, cargf, cargl - calculer l'argument complexe

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <complex.h>
double carg(double complex z);
float cargf(float complex z);
long double cargl(long double complex z);

DESCRIPTION

Ces fonctions calculent l'argument complexe (aussi appelé angle de phase) de z, avec une coupure de branche le long de l'axe réel négatif.

Un nombre complexe peut être décrit par deux coordonnées réelles. On peut utiliser des coordonnées rectangulaires et obtenir


z = x + I * y

où x = creal(z) et y = cimag(z).

Ou on peut utiliser des coordonnées polaires et obtenir


z = r * cexp(I * a)

où r = cabs(z) est le « rayon », le « module », la valeur absolue de z, et a = carg(z) est l'« angle de phase », l'argument de z.

On a :


tan(carg(z)) = cimag(z) / creal(z)

VALEUR DE RETOUR

La valeur de retour est dans l'intervalle [-pi,pi].

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
carg (), cargf (), cargl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE
