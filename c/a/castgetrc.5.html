CASTGETRC(5) Commandes utilisateur CASTGETRC(5)

NOM

castgetrc - fichier de configuration pour castget

DESCRIPTION

Le fichier de configuration .castgetrc doit se trouver dans le répertoire personnel de l'utilisateur. Il définit le comportement du téléchargeur d'enclosures RSS castget, et en particulier la liste des chaînes sur lesquelles il opère.

Le fichier est basé sur un simple format clé-valeur. Il se compose d'une définition de chaîne pour chaque flux RSS que castget doit traiter. Une définition de chaîne commence par une ligne contenant un identifiant de chaîne entre crochets. L'identifiant de chaîne peut être choisi librement par l'utilisateur et est utilisé pour toutes les opérations ultérieures sur la chaîne. Suivent une ou plusieurs paires clé-valeur sous la forme clé=valeur qui définissent le comportement de castget lors de l'opération sur la chaîne. Une définition de chaîne se termine lorsqu'une autre définition de chaîne commence ou à la fin du fichier.

Les lignes commençant par un caractère dièse (`#`) et les lignes vides sont considérées comme des commentaires. Tous les identifiants, clés et valeurs doivent être encodés en UTF-8.

Les paires clé-valeur dans une définition de chaîne définissent le comportement de castget lors du traitement de la chaîne. La définition de chaîne

[fooc]
url=http://downloads.bbc.co.uk/podcasts/radio4/fooc/rss.xml
spool=/home/joe/podcasts

par exemple, demande à castget d'utiliser /home/joe/podcasts comme répertoire de téléchargement lors du traitement de la chaîne fooc.

CLÉS

url
Récupérer le flux RSS de cette URL. Le champ est obligatoire pour toutes les définitions de chaîne.
spool
Télécharger les enclosures dans ce répertoire.
playlist
Écrire les noms de fichiers complets de toutes les enclosures téléchargées dans un fichier playlist de style m3u portant ce nom.
filter
Restreindre l'opération aux enclosures dont les URL correspondent à cette expression régulière.
id3leadartist
Ajouter ou écraser la balise ID3v2 « lead artist » (TPE1) dans les enclosures qui le supportent.
id3contentgroup
Ajouter ou écraser la balise ID3v2 « content group » (TIT1) dans les enclosures qui le supportent.
id3title
Ajouter ou écraser la balise ID3v2 « title » (TIT2) dans les enclosures qui le supportent.
id3album
Ajouter ou écraser la balise ID3v2 « album » (TALB) dans les enclosures qui le supportent.
id3contenttype
Ajouter ou écraser la balise ID3v2 « content type » (TCON) dans les enclosures qui le supportent.
id3year
Ajouter ou écraser la balise ID3v2 « year » (TYER) dans les enclosures qui le supportent.
id3comment
Ajouter ou écraser la balise ID3v2 « comment » (COMM) dans les enclosures qui le supportent.
filename
Enregistrer les téléchargements en utilisant le modèle de nom de fichier donné au lieu de le dériver de l'URL de l'enclosure. Voir MODÈLES DE NOMS DE FICHIER.

CONFIGURATION GLOBALE

Une définition de chaîne avec l'identifiant de chaîne * définira une configuration globale affectant toutes les chaînes. La configuration globale

[*]
id3contenttype=Podcast

par exemple, est équivalente à l'ajout de la paire clé-valeur id3contenttype=Podcast à toutes les autres définitions de chaîne.

Les paires clé-valeur dans les définitions de chaîne remplacent la configuration globale.

MODÈLES DE NOMS DE FICHIER

Les modèles de noms de fichier peuvent contenir des modèles de la forme %(paramètre), qui sont développés pour former un nom de fichier complet. Les modèles sont développés une fois pour chaque téléchargement d'enclosure et peuvent donc être utilisés pour générer des noms de fichier uniques à chaque téléchargement.

Tout ce qui n'est pas un modèle est un littéral qui sera reproduit tel quel (sous réserve de certaines vérifications de bon sens). Le chemin complet d'un téléchargement est déterminé en concaténant le répertoire spool de la chaîne avec le nom de fichier.

Notez que castget refusera d'écraser les fichiers qui existent déjà, sauf lorsqu'il est appelé avec l'option -r pour reprendre les téléchargements. Certains flux RSS réutilisent le même nom de fichier pour toutes les enclosures. Dans de tels cas, l'option -r corrompra les téléchargements existants à moins que vous n'utilisiez des modèles de noms de fichier pour construire des noms de fichier uniques.

Les modèles suivants prennent des informations de l'élément item ou de l'enclosure dans le flux RSS :

  • %(date) : date (par défaut au format AAAA-MM-JJ)
  • %(title) : titre

Les modèles suivants prennent des informations de l'élément channel ou de l'enclosure dans le flux RSS :

•
%(channel_title) : titre de la chaîne

Si une partie des informations requises par un modèle est manquante dans le flux RSS ou est invalide, le modèle sera ignoré et supprimé du nom de fichier résultant.

SUPPRESSION DE CHAÎNE

Si une configuration de chaîne est supprimée, l'état de la chaîne reste le même de sorte que si la chaîne est ajoutée à nouveau par la suite, aucune enclosure marquée comme déjà téléchargée ne sera téléchargée à nouveau.

NOTE

La distribution source inclut un fichier de configuration d'exemple démontrant tous les paramètres pris en charge.
