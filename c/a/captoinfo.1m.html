DESCRIPTIO

N

captoinfo traduit les descriptions de terminaux. Il recherche dans chaque fichier texte donné les entrées termcap et, pour chacune trouvée, écrit une description terminfo équivalente sur le flux de sortie standard. Les capacités tc de termcap sont traduites en capacités terminfo «use »

.

Si aucun fichier n'est spécifié, captoinfo interprète le contenu de la variable d'environnement TERMCAP comme un nom de fichier et n'en extrait que l'entrée pour le terminal nommé dans la variable d'environnement TERM. Si la variable d'environnement TERMCAP n'est pas définie, captoinfo lit /etc/termcap

.

Cette utilitaire est implémentée comme un lien vers tic(1M), avec l' option -I de ce dernier implicite. Vous pouvez utiliser d'autres options de tic telles que -1, -f, -v, -w et -x. L' option -V affiche la version de ncurses associée à ce programme et se termine avec un statut de

succès.
