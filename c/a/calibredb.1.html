calibredb est l'interface en ligne de commande pour la base de données calibre. Elle possède plusieurs sous-commandes, documentées

ci-dessous.

calibredb peut être utilisé pour manipuler soit une base de données calibre spécifiée par un chemin, soit un serveur de contenu calibre fonctionnant sur la machine locale ou sur Internet. Vous pouvez démarrer un serveur de contenu calibre en utilisant soit le programme calibre-server, soit dans le programme principal calibre en cliquant sur Connecter/partager  →  Démarrer le serveur de contenu. Comme calibredb peut modifier vos bibliothèques calibre, vous devez d'abord configurer l'authentification sur le serveur. Il y a deux façons de le faire

:
  • Si vous prévoyez de vous connecter uniquement à un serveur fonctionnant sur le même ordinateur, vous pouvez simplement utiliser l' option --enable-local-write du serveur de contenu, pour permettre à tout programme, y compris calibredb, s'exécutant sur l'ordinateur local, de modifier vos données calibre. Lorsque le serveur est lancé depuis le programme principal calibre, cette option se trouve dans Préférences → Partage sur le
    • réseau → Avancé.
  • Si vous souhaitez permettre l'accès via Internet, vous devriez alors configurer des comptes utilisateur sur le serveur et utiliser les options --username et --password pour calibredb afin de lui donner accès. Vous pouvez configurer l'authentification utilisateur pour calibre-server en utilisant l' option --enable-auth et en utilisant --manage-users pour créer les comptes utilisateur. Si vous
    • lancez le serveur depuis le pr

sur le réseau → Exiger un
nom d'utilisateur/mot de passe.

Pour vous connecter à un serveur de contenu en cours d'exécution, passez l'URL du serveur à l' option --with-library, voir la documentation de cette option pour plus de détails et

d'exemples.
