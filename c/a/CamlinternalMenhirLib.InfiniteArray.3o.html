Module InfiniteArray
: sig end

type 'a t

Ce module implémente des tableaux infinis. *

val make : 'a -> 'a t

make x crée un tableau infini, où chaque emplacement contient x . *

val get : 'a t -> int -> 'a

get a i renvoie l'élément contenu à l'indice i dans le tableau a . Les emplacements sont numérotés à partir de 0. *

val set : 'a t -> int -> 'a -> unit

set a i x définit l'élément contenu à l'indice i dans le tableau a à x . Les emplacements sont numérotés à partir de 0. *

val extent : 'a t -> int

extent a est la longueur d'un segment initial du tableau a qui est suffisamment grand pour contenir toutes les opérations set effectuées. En d'autres termes, tous les éléments au-delà de ce segment ont la valeur par défaut.

val domain : 'a t -> 'a array

domain a est une copie fraîche d'un segment initial du tableau a dont la longueur est extent a .
