Description détaillée

Ces fonctions manipulent les rectangles sales pour des blits optimisés.

Documentation des fonctions

__extern int caca_disable_dirty_rect (caca_canvas_t * cv)

Désactive la gestion des rectangles sales pour tous les appels graphiques de libcaca. Ceci est utile lorsque l'application appelante a besoin d'effectuer des opérations lentes dans une zone connue. Appelez simplement caca_add_dirty_rect() par la suite.

Cette fonction est récursive. Les rectangles sales ne sont réactivés que lorsque caca_enable_dirty_rect() est appelé autant de fois.

Cette fonction ne renvoie jamais d'erreur.

Paramètres

cv Une toile libcaca.

Retourne

Cette fonction retourne toujours 0.

__extern int caca_enable_dirty_rect (caca_canvas_t * cv)

Cette fonction ne peut être appelée qu'après que caca_disable_dirty_rect() a été appelé.

Si une erreur survient, -1 est retourné et errno est défini en conséquence :

•
EINVAL Les rectangles sales n'étaient pas désactivés.

Paramètres

cv Une toile libcaca.

Retourne

0 en cas de succès, -1 si une erreur est survenue.

__extern int caca_get_dirty_rect_count (caca_canvas_t * cv)

Obtient le nombre de rectangles sales dans une toile. Les rectangles sales sont des zones contenant des cellules qui ont changé depuis la dernière réinitialisation.

Les rectangles sales sont utilisés en interne par les pilotes d'affichage pour optimiser le rendu en évitant de redessiner tout l'écran. Une fois que le pilote d'affichage a rendu la toile, il réinitialise la liste des rectangles sales.

Il est garanti que les rectangles sales ne se chevauchent pas.

Cette fonction ne renvoie jamais d'erreur.

Paramètres

cv Une toile libcaca.

Retourne

Le nombre de rectangles sales dans la toile donnée.

__extern int caca_get_dirty_rect (caca_canvas_t * cv, int r, int * x, int * y, int * width, int * height)

Obtient les coordonnées du rectangle sale spécifié de la toile. L'indice doit être inférieur au nombre de rectangles sales. Voir caca_get_dirty_rect_count() pour savoir comment calculer ce nombre.

Si une erreur survient, aucune coordonnée n'est écrite dans les arguments pointeurs, -1 est retourné et errno est défini en conséquence :

•
EINVAL L'indice de rectangle spécifié est hors limites.

Paramètres

cv Une toile libcaca.
r L'indice du rectangle demandé.
x Un pointeur vers un entier où sera stockée la bordure gauche du rectangle sale.
y Un pointeur vers un entier où sera stockée la bordure supérieure du rectangle sale.
width Un pointeur vers un entier où sera stockée la largeur du rectangle sale.
height Un pointeur vers un entier où sera stockée la hauteur du rectangle sale.

Retourne

0 en cas de succès, -1 si une erreur est survenue.

__extern int caca_add_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

Ajoute une zone invalidante à la liste des rectangles sales de la toile. Pour plus d'informations sur les rectangles sales, voir caca_get_dirty_rect().

Cette fonction peut être utile pour forcer le rafraîchissement d'une zone donnée de la toile même si le suivi des rectangles sales indique qu'elle n'a pas changé. Cela peut se produire si le contenu de la toile a été modifié directement.

Si une erreur survient, -1 est retourné et errno est défini en conséquence :

•
EINVAL Les coordonnées du rectangle spécifié sont hors limites.

Paramètres

cv Une toile libcaca.
x Le bord gauche du rectangle sale supplémentaire.
y Le bord supérieur du rectangle sale supplémentaire.
width La largeur du rectangle sale supplémentaire.
height La hauteur du rectangle sale supplémentaire.

Retourne

0 en cas de succès, -1 si une erreur est survenue.

Référencé par caca_blit(), caca_clear_canvas(), caca_fill_box(), caca_flip(), caca_flop(), caca_free_frame(), caca_invert(), caca_put_attr(), caca_put_char(), caca_rotate_180(), caca_rotate_left(), caca_rotate_right(), caca_set_canvas_boundaries(), caca_set_frame(), caca_stretch_left(), et caca_stretch_right().

__extern int caca_remove_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

Marque une zone de cellules dans la toile comme non sale. Pour plus d'informations sur les rectangles sales, voir caca_get_dirty_rect().

Les valeurs telles que xmin > xmax ou ymin > ymax indiquent que le rectangle sale est vide. Elles seront ignorées silencieusement.

Si une erreur survient, -1 est retourné et errno est défini en conséquence :

•
EINVAL Les coordonnées du rectangle spécifié sont hors limites.

Paramètres

cv Une toile libcaca.
x Le bord gauche du rectangle propre.
y Le bord supérieur du rectangle propre.
width La largeur du rectangle propre.
height La hauteur du rectangle propre.

Retourne

0 en cas de succès, -1 si une erreur est survenue.
