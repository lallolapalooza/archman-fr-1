CAPNG_HAVE_CAPABILITIES(3) API Libcap-ng CAPNG_HAVE_CAPABILITIES(3)

NOM

capng_have_capabilities, capng_have_permitted_capabilities - vérifier les capacités

SYNOPSIS

#include <cap-ng.h>

capng_results_t capng_have_capabilities(capng_select_t set); capng_results_t capng_have_permitted_capabilities(void);

DESCRIPTION

capng_have_capabilities vérifiera les ensembles de capacités internes sélectionnés pour voir quel est leur état. Les ensembles de capacités doivent avoir été préalablement configurés avec des appels à capng_get_caps_process, capng_get_caps_fd, ou configurés d'une autre manière. Les options sont CAPNG_SELECT_CAPS pour les capacités traditionnelles, CAPNG_SELECT_BOUNDS pour l'ensemble des limites, CAPNG_SELECT_BOTH si la vérification des deux est souhaitée, CAPNG_SELECT_AMBIENT si seule la vérification des capacités ambiantes est souhaitée, ou CAPNG_SELECT_ALL si la vérification de tous les ensembles est souhaitée. Lorsque les capacités sont vérifiées, cela ne regardera que les capacités effectives.

Si, cependant, la source des capacités provient d'un fichier, alors vous devrez peut-être vérifier en plus les capacités autorisées. C'est pour cette raison que capng_have_permitted_capabilities a été créée. Elle ne prend aucun argument car elle vérifie simplement l'ensemble des autorisations.

VALEUR DE RETOUR

Cette fonction retournera l'une des quatre valeurs suivantes explicites : CAPNG_FAIL, CAPNG_NONE, CAPNG_PARTIAL, CAPNG_FULL.

VOIR AUSSI

capng_get_caps_process(3), capng_get_caps_fd(3), capng_have_capability(3), capabilities(7)
