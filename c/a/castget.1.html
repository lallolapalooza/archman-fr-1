CASTGET(1) Commandes utilisateur CASTGET(1)

NOM

castget - télécharger les pièces jointes RSS

SYNTAXE

castget [OPTION...] [IDENTIFIANT DE CHAÎNE...]

DESCRIPTION

castget télécharge les pièces jointes RSS, par exemple les podcasts, depuis les flux RSS.

Les flux RSS se voient attribuer des identifiants de chaîne dans le fichier de configuration .castgetrc. Les chaînes à traiter par castget sont indiquées en fournissant les identifiants de chaîne en tant qu'arguments. Si aucun identifiant de chaîne n'est fourni, toutes les chaînes disponibles sont traitées.

S'il est exécuté sans aucune option, castget effectuera l'action par défaut sur toutes les chaînes à traiter. L'action par défaut consiste à télécharger toute pièce jointe non encore téléchargée. D'autres actions peuvent être effectuées en fournissant une ou plusieurs options comme arguments.

OPTIONS

Opérations

-c, --catchup
Se mettre à jour avec les chaînes et quitter.
-l, --list
Lister les pièces jointes disponibles qui n'ont pas encore été téléchargées, et quitter.
-h, --help
Afficher l'aide et quitter.
-V, --version
Afficher les informations de version et quitter.

Filtres d'opération

-n, --new-only
Restreindre l'opération aux nouvelles chaînes uniquement, c'est-à-dire aux chaînes qui n'ont jamais été téléchargées ou mises à jour auparavant. Notez que si une chaîne est ajoutée à la configuration puis supprimée, son historique de téléchargement est préservé. Cela signifie qu'une chaîne qui a été retirée du fichier de configuration ne sera pas considérée comme « nouvelle » si elle est ajoutée à nouveau à la configuration ultérieurement.
-1, --first-only
Restreindre l'opération à l'élément le plus récent de chaque chaîne uniquement.
-f motif, --filter=motif
Restreindre l'opération aux pièces jointes dont les URL de téléchargement correspondent à l'expression régulière motif. Notez que cela annulera toute expression régulière de filtre donnée dans le fichier de configuration.

Options globales

-r, --resume
Reprendre les téléchargements interrompus. Assurez-vous de ne pas utiliser cette option si le flux RSS utilise le même nom de fichier pour plusieurs pièces jointes, car cela corromprait les téléchargements existants.
-q, --quiet
Ne rien imprimer sauf les messages d'erreur.
-v, --verbose
Afficher des informations de progression détaillées.
-d, --debug
Afficher (beaucoup d') informations de débogage de connexion.
-p, --progress-bar
Afficher une barre de progression lors du téléchargement des pièces jointes.
-C nom de fichier, --rcfile=nom de fichier
Remplacer le nom de fichier par défaut pour le fichier de configuration.

EXEMPLES

Télécharger toutes les pièces jointes non encore téléchargées :
$ castget
Télécharger toutes les pièces jointes non encore téléchargées de la chaîne foobar et être verbeux :
$ castget -v foobar
Lister toutes les pièces jointes non encore téléchargées :
$ castget -l
Se mettre à jour avec la chaîne foobar :
$ castget -c foobar
Lister la première pièce jointe disponible dans toutes les nouvelles chaînes :
$ castget -1 -n -l
Se mettre à jour avec les éléments correspondant à l'expression régulière Freddies0[67] dans la chaîne frederator :
$ castget -c -f "Freddies0[67]" frederator

PROXY HTTP

Pour utiliser un proxy HTTP, définir la variable d'environnement http_proxy :
http_proxy=http://your.proxy.server:port/ castget
