    cargo-owner

    gestionnaire de paquets Rust

    17 mai 2024

    Cargo

    SYNOPSIS

    cargo owner [OPTIONS] <SUBCOMMAND>

    DESCRIPTION

    Gérer les propriétaires de caisses sur crates.io.

    OPTIONS

    Cette commande n'a pas d'options spécifiques.

    ENVIRONNEMENT

    Cette commande n'utilise pas de variables d'environnement spécifiques.

    STATUT DE SORTIE

    0 si la commande s'est terminée avec succès, non-zéro sinon.

    EXEMPLES

    Ajouter un propriétaire à une caisse :

    cargo owner --add <nom_utilisateur> <nom_caisse>

    Supprimer un propriétaire d'une caisse :

    cargo owner --remove <nom_utilisateur> <nom_caisse>

    Lister les propriétaires d'une caisse :

    cargo owner --list <nom_caisse>
