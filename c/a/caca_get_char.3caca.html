Description détaillée

Ces fonctions fournissent des routines d'impression de caractères de bas niveau et des fonctions graphiques de plus haut niveau.

Documentation des définitions de macros

#define CACA_MAGIC_FULLWIDTH 0x000ffffe

Utilisé pour indiquer que le caractère précédent était un glyphe de pleine largeur.

__extern int caca_gotoxy (caca_canvas_t * cv, int x, int y)

Place le curseur aux coordonnées données. Les fonctions utilisant le curseur utiliseront les nouvelles valeurs. Placer la position du curseur en dehors du canevas est légal, mais le curseur ne sera pas affiché.

Cette fonction ne retourne jamais d'erreur.

Paramètres

cv Un pointeur vers le canevas libcaca.
x Coordonnée X du curseur.
y Coordonnée Y du curseur.

Retourne

Cette fonction retourne toujours 0.

Référencé par caca_conio_cgets(), caca_conio_clrscr(), caca_conio_cprintf(), caca_conio_cputs(), caca_conio_gotoxy(), caca_conio_printf(), et caca_conio_putch().

__extern int caca_put_char (caca_canvas_t * cv, int x, int y, uint32_t ch)

Affiche un caractère ASCII ou Unicode aux coordonnées données, en utilisant les valeurs de couleur de premier plan et d'arrière-plan par défaut.

Si les coordonnées sont en dehors des limites du canevas, rien n'est affiché. Si un caractère Unicode de pleine largeur est écrasé, ses parties visibles restantes sont remplacées par des espaces. Si les limites du canevas coupent le caractère de pleine largeur en deux, un espace est affiché à la place.

Le comportement lors de l'affichage de caractères non imprimables ou de caractères UTF-32 invalides est indéfini. Pour afficher une séquence d'octets formant un caractère UTF-8 au lieu d'un caractère UTF-32, utilisez la fonction caca_put_str().

Cette fonction retourne la largeur du caractère affiché. S'il s'agit d'un caractère de pleine largeur, 2 est retourné. Sinon, 1 est retourné.

Cette fonction ne retourne jamais d'erreur.

Paramètres

cv Un pointeur vers le canevas libcaca.
x Coordonnée X.
y Coordonnée Y.
ch Le caractère à afficher.

Retourne

La largeur du caractère affiché : 2 pour un caractère de pleine largeur, 1 sinon.

Références caca_add_dirty_rect(), CACA_MAGIC_FULLWIDTH, et caca_utf32_is_fullwidth().

Référencé par caca_conio_cgets(), caca_conio_cputs(), caca_conio_putch(), caca_dither_bitmap(), caca_fill_box(), caca_fill_triangle(), caca_flush_figlet(), caca_put_figchar(), et caca_put_str().

__extern uint32_t caca_get_char (caca_canvas_t const * cv, int x, int y)

Obtient la valeur ASCII ou Unicode du caractère aux coordonnées données. Si la valeur est inférieure ou égale à 127 (0x7f), le caractère peut être affiché en ASCII. Sinon, il doit être traité comme une valeur UTF-32.

Si les coordonnées sont en dehors des limites du canevas, un espace (0x20) est retourné.

Une exception spéciale se produit lorsque CACA_MAGIC_FULLWIDTH est renvoyé. Cette valeur n'est garantie d'être aucun caractère Unicode valide, et indique que le caractère à gauche de celui demandé est un caractère de pleine largeur.

Cette fonction ne retourne jamais d'erreur.

Paramètres

cv Un pointeur vers le canevas libcaca.
x Coordonnée X.
y Coordonnée Y.

Retourne

Le caractère Unicode aux coordonnées données.

Référencé par caca_flush_figlet(), et caca_put_figchar().

__extern int caca_put_str (caca_canvas_t * cv, int x, int y, char const * s)

Affiche une chaîne UTF-8 aux coordonnées données, en utilisant les valeurs de premier plan et d'arrière-plan par défaut. Les coordonnées peuvent être en dehors des limites du canevas (par exemple une coordonnée Y négative) et la chaîne sera rognée en conséquence si elle est trop longue.

Voir caca_put_char() pour plus d'informations sur la gestion des caractères pleine largeur lorsqu'ils se superposent ou aux limites du canevas.

Cette fonction renvoie le nombre de cellules imprimées par la chaîne. Ce n'est pas le nombre de caractères imprimés, car les caractères pleine largeur occupent deux cellules.

Cette fonction n'échoue jamais.

Paramètres

cv Un descripteur du canevas libcaca.
x Coordonnée X.
y Coordonnée Y.
s La chaîne à imprimer.

Renvoie

Le nombre de cellules imprimées.

Références caca_put_char(), caca_utf32_is_fullwidth(), et caca_utf8_to_utf32().

Référencé par caca_vprintf().

__extern int caca_blit (caca_canvas_t * dst, int x, int y, caca_canvas_t const * src, caca_canvas_t const * mask)

Effectue un blit d'un canevas sur un autre aux coordonnées données. Un canevas masque optionnel peut être utilisé.

Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence :

•
EINVAL Un masque a été spécifié mais la taille du masque et la taille du canevas source ne correspondent pas.

Paramètres

dst Le canevas de destination.
x Coordonnée X.
y Coordonnée Y.
src Le canevas source.
mask Le canevas masque.

Renvoie

0 en cas de succès, -1 si une erreur s'est produite.

Références caca_add_dirty_rect(), et CACA_MAGIC_FULLWIDTH.

Référencé par caca_conio_movetext(), caca_export_area_to_memory(), caca_import_area_from_file(), caca_import_area_from_memory(), caca_put_figchar(), et caca_set_canvas_boundaries().

__extern int caca_set_canvas_boundaries (caca_canvas_t * cv, int x, int y, int w, int h)

Définit de nouvelles limites pour un canevas. Cette fonction peut être utilisée pour rogner un canevas, l'étendre ou pour des combinaisons des deux actions. Toutes les trames sont affectées par cette fonction.

Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence :

  • EINVAL La largeur ou la hauteur spécifiée est invalide.
  • EBUSY Le canevas est en cours d'utilisation par un pilote d'affichage et ne peut pas être redimensionné.
  • ENOMEM Pas assez de mémoire pour la taille de canevas demandée. Si cela se produit, le descripteur du canevas devient invalide et ne devrait plus être utilisé.

Paramètres

cv Le canevas à rogner.
x Coordonnée X du coin supérieur gauche.
y Coordonnée Y du coin supérieur gauche.
w La largeur de la zone rognée.
h La hauteur de la zone rognée.

Renvoie

0 en cas de succès, -1 si une erreur s'est produite.

Références caca_add_dirty_rect(), caca_blit(), caca_create_canvas(), caca_create_frame(), caca_get_frame_count(), et caca_set_frame().

    Nom

    caca_get_char - obtenir un caractère à partir d'un canevas

    Synopsis

    #include <caca.h>

    char_t caca_get_char(caca_canvas_t *canvas, int x, int y);

    Description

    La fonction caca_get_char() renvoie le caractère représenté par la cellule (x, y) sur le canvas donné.

    Paramètres

    • canvas : Le canevas à interroger.
    • x : La coordonnée X de la cellule.
    • y : La coordonnée Y de la cellule.

    Valeur de retour

    La valeur de retour est un entier de type char_t, qui contient le caractère ainsi que ses attributs de couleur et de style.

    Voir aussi

    caca_put_char(3caca), caca_get_attr(3caca), caca_get_color(3caca)
