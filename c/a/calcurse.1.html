OPTIONS DE

FILTRE

Les options de filtre ont un effet sur les requêtes (-Q et les formes courtes de requête), grep (-G), purge (-P) et export (-x), voir aussi les options dans la section

DESCRIPTION.

Plusieurs options de filtre peuvent être données. Pour qu'un élément soit chargé dans calcurse, il doit correspondre à tous les filtres. En d'autres termes, les filtres sont combinés logiquement par "et". L'option --filter-type a une valeur par défaut qui correspond à n'importe quel élément. Toutes les autres options de filtre n'ont pas de valeur par défaut et ne s'appliquent que lorsqu'elles sont explicitement

définies.

Les options de filtre se répartissent en trois groupes : général, calendrier, tâche. Les filtres généraux s'appliquent à tous les éléments, les filtres de calendrier concernent les heures de début et de fin et ne s'appliquent qu'aux rendez-vous et événements, et les filtres de tâche concernent la priorité et l'état d'achèvement et ne s'appliquent qu'aux

TODO.

En dehors des trois groupes se trouve le filtre

d'inversion.

Filtres de

calendrier

Pour les options de filtre se terminant par -from, -to, -after, -before et -range, l'heure de début ou de fin est le critère de

filtre.

Un événement est un rendez-vous d'une journée entière pour lequel aucune heure n'est affichée. L'heure de début d'un événement est le début de la journée de l'événement (minuit), l'heure de fin est la fin de la journée de l'événement (une seconde avant le prochain minuit)

.

Les options -start- se terminant par -from, -after et -range font référence au même critère de filtre et ne peuvent pas être utilisées ensemble. Il en va de même pour les options se terminant par -to, -before et -range. Des restrictions similaires s'appliquent aux options -end-

.

Les heures de début et de fin d'un élément récurrent font référence à la toute première occurrence, et non à celles de l'une des répétitions. Si un élément récurrent satisfait le critère, toutes les répétitions sont affichées dans les requêtes, même si elles ne satisfont pas le critère. Si elles sont indésirables, elles peuvent être supprimées de la sortie avec les options de plage de jours, bien que cela supprime également d'autres éléments dans cette

plage.

$XDG_DATA_HOME a pour valeur par défaut $HOME/.local/share et $XDG_CONFIG_HOME a pour valeur par défaut $HOME/.

config.

Les fichiers sont de deux types différents : données et configuration. Les fichiers de données constituent la base de données de calcurse et sont indépendants de la version de calcurse ; les fichiers de configuration dépendent de la version de calcurse bien que la rétrocompatibilité soit toujours

visée.

Fichiers de

données

Le fichier de calendrier apts contient tous les rendez-vous et événements de l'utilisateur, et le fichier todo contient la liste de tâches. Le sous-répertoire notes contient les notes qui sont attachées aux rendez-vous, événements ou tâches. Un fichier texte est créé par note, dont le nom est l'empreinte de message SHA1 de la note

elle-même.

Les fichiers de verrouillage (cachés) des programmes calcurse (.calcurse.pid) et daemon (.daemon.log) sont présents lorsqu'ils sont en cours d'exécution. Si l'activité du journal du daemon a été activée dans le menu de configuration des notifications, le fichier daemon.log est

présent.

Un fichier de calendrier alternatif peut être spécifié avec l'option -c

.

Fichiers de

configuration

Le fichier conf contient la configuration de l'utilisateur et le fich

ier keys les raccourcis clavier définis par l'utilisateur. Le réperto
ire hooks contient des scripts fournis par l'utilisateur, voir Hooks.

Configuration du

répertoire

Un répertoire alternatif pour à la fois les fichiers de configuration et le répertoire de données peut être spécifié avec l' option

-D.

Un répertoire alternatif pour les fichiers de configuration uniquement peut être spécifié avec l'option -C ; dans ce cas, les fichiers de données sont soit dans le répertoire par défaut, soit dans le répertoire spécifié par -D. Si à la fois -D et -C sont présents, les fichiers de configuration dans le répertoire de données, s'il y en a, sont

ignorés.

configuration.
