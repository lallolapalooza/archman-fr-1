CARGO-LOGOUT(1) Manuel des commandes générales CARGO-LOGOUT(1)

NOM

cargo-logout — Supprimer localement un jeton API du registre

SYNTAXE

cargo logout [options]

DESCRIPTION

Cette commande exécutera un fournisseur d'identifiants pour supprimer un jeton enregistré.

Pour le fournisseur d'identifiants par défaut cargo:token, les identifiants sont stockés dans $CARGO_HOME/credentials.toml où $CARGO_HOME vaut par défaut .cargo dans votre répertoire personnel.

Si un registre a un fournisseur d'identifiants spécifié, il sera utilisé. Sinon, les fournisseurs de la valeur de configuration registry.global-credential-providers seront tentés, en commençant par la fin de la liste.

Si --registry n'est pas spécifié, alors les identifiants pour le registre par défaut seront supprimés (configuré par registry.default https://doc.rust-lang.org/cargo/reference/config.html#registrydefault, qui vaut par défaut https://crates.io/).

Cela ne révoquera pas le jeton sur le serveur. Si vous avez besoin de révoquer le jeton, visitez le site web du registre et suivez ses instructions (voir https://crates.io/me pour révoquer le jeton pour https://crates.io/).

OPTIONS

Options de déconnexion

--registry registry

Nom du registre à utiliser. Les noms de registre sont définis dans les fichiers de configuration de Cargo https://doc.rust-lang.org/cargo/reference/config.html. S'il n'est pas spécifié, le registre par défaut est utilisé, défini par la clé de configuration registry.default qui vaut par défaut crates-io.

Options d'affichage

-v, --verbose

Utilise une sortie verbeuse. Peut être spécifié deux fois pour une sortie « très verbeuse » qui inclut des sorties supplémentaires comme les avertissements de dépendance et la sortie des scripts de compilation. Peut également être spécifié avec la valeur de configuration config value https://doc.rust-lang.org/cargo/reference/config.html term.verbose.

-q, --quiet

Ne pas afficher les messages de journalisation de Cargo. Peut également être spécifié avec la valeur de configuration config value https://doc.rust-lang.org/cargo/reference/config.html term.quiet.

--color when

Contrôle quand la sortie colorée est utilisée. Valeurs valides :
•auto (par défaut) : Détecte automatiquement si la prise en charge des couleurs est disponible sur le terminal.
•always : Affiche toujours les couleurs.
•never : N'affiche jamais les couleurs.

Peut également être spécifié avec la valeur de configuration config value https://doc.rust-lang.org/cargo/reference/config.html term.color.

Options communes

+toolchain

Si Cargo a été installé avec rustup, et que le premier argument de cargo commence par +, il sera interprété comme un nom de toolchain rustup (tel que +stable ou +nightly). Voir la documentation de rustup https://rust-lang.github.io/rustup/overrides.html pour plus d'informations sur le fonctionnement des substitutions de toolchain.

--config KEY=VALUE ou PATH

Remplace une valeur de configuration Cargo. L'argument doit être au format TOML KEY=VALUE, ou être fourni en tant que chemin vers un fichier de configuration supplémentaire. Ce drapeau peut être spécifié plusieurs fois. Voir la section sur les remplacements en ligne de commande https://doc.rust-lang.org/cargo/reference/config.html#command-line-overrides pour plus d'informations.

-C PATH

Change le répertoire de travail courant avant d'exécuter toute opération spécifiée. Cela affecte où Cargo recherche par défaut le manifeste du projet (Cargo.toml), ainsi que les répertoires recherchés pour découvrir .cargo/config.toml, par exemple. Cette option doit apparaître avant le nom de la commande, par exemple cargo -C chemin/vers/mon-projet build.

Cette option n'est disponible que sur la channel nightly https://doc.rust-lang.org/book/appendix-07-nightly-rust.html et nécessite l'activation du drapeau -Z unstable-options (voir #10098 https://github.com/rust-lang/cargo/issues/10098).

-h, --help

Affiche les informations d'aide.

-Z flag

Drapeaux instables (réservés à la nightly) pour Cargo. Exécutez cargo -Z help pour les détails.

ENVIRONNEMENT

Voir la référence https://doc.rust-lang.org/cargo/reference/environment-variables.html pour les détails sur les variables d'environnement que Cargo lit.

STATUT DE SORTIE

•0 : Cargo a réussi.
•101 : Cargo n'a pas pu être complété.

EXEMPLES

1. Supprimer le jeton du registre par défaut : 
cargo logout
2. Supprimer le jeton pour un registre spécifique : 
cargo logout --registry my-registry

VOIR AUSSI
