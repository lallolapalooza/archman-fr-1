NOM

capng_update - mettre à jour les paramètres de capacités stockés

SYNTAXE

#include <cap-ng.h>

int capng_update(capng_act_t action, capng_type_t type,unsigned int capability);

DESCRIPTION

capng_update mettra à jour les paramètres internes de capacités POSIX en fonction des options qui lui sont passées. L'action doit être soit CAPNG_DROP pour définir le bit de capacité à 0, soit CAPNG_ADD pour définir le bit de capacité à 1. L'opération est effectuée sur l'ensemble de capacités spécifié dans le paramètre type. Les valeurs sont : CAPNG_EFFECTIVE, CAPNG_PERMITTED, CAPNG_INHERITABLE, CAPNG_BOUNDING_SET, ou CAPNG_AMBIENT. Les valeurs peuvent être combinées par un OU logique (OR) pour effectuer la même opération sur plusieurs ensembles. Le dernier paramètre, capability, est la définition de capacité telle que donnée dans linux/capability.h.

VALEUR DE RETOUR

Retourne 0 en cas de succès et -1 en cas d'échec.

VOIR AUSSI

capng_updatev(3), capabilities(7)
