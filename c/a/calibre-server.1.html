calibre-server - calibre-server

calibre-server [options] [chemin vers le dossier de la bibliothèque...]

Démarre le serveur de contenu calibre. Le serveur de contenu calibre expose vos bibliothèques calibre sur Internet. Vous pouvez spécifier le chemin vers les dossiers de la bibliothèque comme arguments pour calibre-server. Si vous ne spécifiez aucun chemin, toutes les bibliothèques que le programme calibre principal connaît seront utilisées.

Chaque fois que vous passez des arguments à calibre-server qui contiennent des espaces, entourez les arguments de guillemets. Par exemple : "/chemin/quelconque/avec des espaces"

[OPTIONS]

--access-log
Chemin vers le fichier journal d'accès. Ce journal contient des informations sur les clients se connectant au serveur et effectuant des requêtes. Par défaut, aucun journal d'accès n'est effectué.
--ajax-timeout
Temps (en secondes) d'attente d'une réponse du serveur lors des requêtes.
--auth-mode
Choisir le type d'authentification utilisé. Définit le mode d'authentification HTTP utilisé par le serveur. Réglez sur "basic" si vous placez ce serveur derrière un proxy SSL. Sinon, laissez-le sur "auto", ce qui utilisera "basic" si SSL est configuré, sinon il utilisera "digest".
--auto-reload
Recharger automatiquement le serveur lorsque le code source change. Utile pour le développement. Vous devriez également spécifier une petite valeur pour le délai d'extinction.
--ban-after
Nombre d'échecs de connexion pour bannir. Le nombre d'échecs de connexion après lequel une adresse IP est bannie.
--ban-for
Bannir les adresses IP qui ont des échecs de connexion répétés. Bannit temporairement l'accès pour les adresses IP qui ont des échecs de connexion répétés pendant le nombre spécifié de minutes. Utile pour empêcher les tentatives de devinettes de mots de passe. Si défini sur zéro, aucun bannissement n'est effectué.
--book-list-mode
Choisir le mode de liste de livres par défaut. Définit le mode de liste de livres par défaut qui sera utilisé pour les nouveaux utilisateurs. Les utilisateurs individuels peuvent remplacer le défaut dans leurs propres paramètres. Le défaut est d'utiliser une grille de couvertures.
--compress-min-size
Taille minimale pour laquelle les réponses utilisent la compression de données (en octets).
--custom-list-template
Chemin vers un fichier JSON contenant un modèle pour le mode de liste de livres personnalisée. La manière la plus simple de créer un tel fichier modèle est d'aller dans Préférences -> Partage sur le net -> Modèle de liste de livres dans calibre, de créer le modèle et de l'exporter.
--daemonize
Exécuter le processus en arrière-plan en tant que démon (Linux uniquement).
--displayed-fields
Restreindre les champs personnalisés affichés. Liste séparée par des virgules de champs de métadonnées définis par l'utilisateur qui seront affichés par le serveur de contenu dans les vues /opds et /mobile. Si vous spécifiez cette option, tous les champs ne figurant pas dans cette liste ne seront pas affichés. Par exemple : ma_notation,mes_étiquettes
--enable-allow-socket-preallocation, --disable-allow-socket-preallocation
Pré-allocation de socket, par exemple, avec l'activation de socket systemd. Par défaut, cette option est activée.
--enable-auth, --disable-auth
Authentification basée sur un mot de passe pour accéder au serveur. Normalement, le serveur n'est pas restreint, permettant à quiconque d'y accéder. Vous pouvez restreindre l'accès aux utilisateurs prédéfinis avec cette option. Par défaut, cette option est désactivée.
--enable-fallback-to-detected-interface, --disable-fallback-to-detected-interface
Retour au retour à l'interface détectée automatiquement. Si pour une raison quelconque le serveur ne parvient pas à se lier à l'interface spécifiée dans l'option listen_on, il essaiera alors de détecter une interface qui se connecte à l'extérieur et de s'y lier. Par défaut, cette option est activée.
--enable-local-write, --disable-local-write
Autoriser les connexions locales non authentifiées
tions de faire des modifications. Normalement, si vous n'activez pas l'authentification, le serveur fonctionne en mode lecture seule, afin de ne pas permettre aux utilisateurs anonymes de faire des modifications à vos bibliothèques calibre. Cette option permet à toute personne se connectant depuis le même ordinateur que celui sur lequel le serveur s'exécute de faire des modifications. C'est utile si vous voulez exécuter le serveur sans authentification mais utiliser quand même calibredb pour faire des modifications à vos bibliothèques calibre. Notez que l'activation de cette option signifie que tout programme s'exécutant sur l'ordinateur peut faire des modifications à vos bibliothèques calibre. Par défaut, cette option est désactivée.

Utilisez cette option pour la désactiver. Par défaut, cette option est activée.

basées sur OPDS puissent détecter et se connecter automati

vous rencontrez des transferts de fichiers corrompus, désactivez-le. Par défaut, cette option est activée.
