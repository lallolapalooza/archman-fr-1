CAPNG_SAVE_STATE(3) API Libcap-ng CAPNG_SAVE_STATE(3)

NOM

capng_save_state - obtenir l'état interne de la bibliothèque

SYNTAXE

#include <cap-ng.h>

void *capng_save_state(void);

DESCRIPTION

capng_save_state est une fonction qui retourne un pointeur vers l'état interne de la bibliothèque libcap-ng. Il doit être considéré comme opaque et ne doit pas être modifié directement. Cette fonction doit être utilisée lorsque vous suspectez qu'une bibliothèque tierce utilise également libcap-ng et que vous souhaitez vous assurer qu'elle ne modifie pas quelque chose d'important. Cette fonction n'est pas disponible dans les bindings Python.

VALEUR DE RETOUR

Cette fonction retourne NULL en cas d'échec et un pointeur non-NULL sinon.

NOTES

La structure retournée par capng_save_state est allouée par malloc ; elle doit être libérée si elle n'est pas utilisée.

VOIR AUSSI
