Module LexerUtil
: sig end

val init : string -> Lexing.lexbuf -> Lexing.lexbuf

init nomfichier tamponlex initialise le tampon de lexing tamponlex afin que les positions qui en seront lues ultérieurement se réfèrent au fichier nomfichier . Il retourne tamponlex .

val read : string -> string * Lexing.lexbuf

read nomfichier lit le contenu entier du fichier nomfichier et retourne une paire constituée de ce contenu (une chaîne de caractères) et d'un tampon de lexing qui a été initialisé à partir de cette chaîne.

val newline : Lexing.lexbuf -> unit

newline tamponlex incrémente le compteur de lignes stocké dans tamponlex . Il doit être appelé par le lexer lui-même chaque fois qu'un caractère de nouvelle ligne est consommé. Ceci permet de maintenir le numéro de ligne actuel dans tamponlex .

val range : Lexing.position * Lexing.position -> string

range (posdebut, posfin) affiche une description textuelle de l'intervalle délimité par les positions de début et de fin posdebut et posfin . Cette description est longue d'une ligne et se termine par un caractère de nouvelle ligne. Cette description mentionne le nom du fichier, le numéro de ligne, et un intervalle de caractères sur cette ligne. Le numéro de ligne n'est correct que si newline a été utilisé correctement, comme décrit ci-dessus.

val tabulate : ('a -> bool) -> (unit -> 'a) -> unit -> 'a

tabulate est_eof lexer tabule le lexer lexer : c'est-à-dire qu'il exécute ce lexer immédiatement jusqu'à ce qu'un jeton EOF soit trouvé, stocke les jetons dans un tableau en mémoire, et retourne un nouveau lexer qui (lorsqu'il est appelé) lit les jetons à partir de ce tableau. La fonction lexer n'est pas autorisée à lever une exception et doit produire un flux fini de jetons : c'est-à-dire qu'après un nombre fini d'invocations, elle doit retourner un jeton qui est identifié par la fonction est_eof comme un jeton EOF.

Le lexer existant lexer et le nouveau lexer retourné par
tabulate est_eof lexer sont des fonctions de type unit -> 'a , où le type 'a sera probablement instancié avec un triple d'un jeton et de deux positions, conformément à l'API de lexer révisée décrite dans le module CamlinternalMenhirLib.Convert .
