CARGO-UNINSTALL(1) Manuel des commandes générales CARGO-UNINSTALL(1)

NOM

cargo-uninstall — Supprimer une binaire Rust

SYNTAXE

cargo uninstall [options] [spéc•]

DESCRIPTION

Cette commande supprime un paquet installé avec cargo-install(1). L'argument spéc est une spécification d'ID de paquet du paquet à supprimer (voir cargo-pkgid(1)).

Par défaut, toutes les binaires sont supprimées pour une caisse, mais les indicateurs --bin et --example peuvent être utilisés pour ne supprimer que des binaires particulières.

La racine d'installation est déterminée, par ordre de priorité :

•Option --root
•Variable d'environnement CARGO_INSTALL_ROOT
•Valeur de configuration install.root de Cargo https://doc.rust-lang.org/cargo/reference/config.html
•Variable d'environnement CARGO_HOME
•$HOME/.cargo

OPTIONS

Options de désinstallation

-p, --package spéc•

Paquet à désinstaller.

--bin nom•

Ne désinstaller que la binaire nom.

--root rép

Répertoire à partir duquel désinstaller les paquets.

Options d'affichage

-v, --verbose

Utiliser une sortie verbeuse. Peut être spécifié deux fois pour une sortie « très verbeuse » qui inclut des informations supplémentaires telles que des avertissements de dépendance et la sortie des scripts de build. Peut également être spécifié avec la valeur de configuration term.verbose https://doc.rust-lang.org/cargo/reference/config.html.

-q, --quiet

Ne pas imprimer les messages de log de Cargo. Peut également être spécifié avec la valeur de configuration term.quiet https://doc.rust-lang.org/cargo/reference/config.html.

--color quand

Contrôle quand la sortie colorée est utilisée. Valeurs valides :
•auto (par défaut) : Détecte automatiquement si le support couleur est disponible sur le terminal.
•always : Affiche toujours les couleurs.
•never : N'affiche jamais de couleurs.

Peut également être spécifié avec la valeur de configuration term.color https://doc.rust-lang.org/cargo/reference/config.html.

Options communes

+toolchain

Si Cargo a été installé avec rustup, et que le premier argument de cargo commence par +, il sera interprété comme un nom de toolchain rustup (tel que +stable ou +nightly). Voir la documentation rustup https://rust-lang.github.io/rustup/overrides.html pour plus d'informations sur le fonctionnement des remplacements de toolchain.

--config CLÉ=VALEUR ou CHEMIN

Remplace une valeur de configuration Cargo. L'argument doit être en syntaxe TOML de CLÉ=VALEUR, ou fourni comme chemin vers un fichier de configuration supplémentaire. Cet indicateur peut être spécifié plusieurs fois. Voir la section sur les remplacements en ligne de commande https://doc.rust-lang.org/cargo/reference/config.html#command-line-overrides pour plus d'informations.

-C CHEMIN

Change le répertoire de travail actuel avant d'exécuter toute opération spécifiée. Cela affecte par exemple l'endroit où cargo recherche par défaut le manifeste du projet (Cargo.toml), ainsi que les répertoires dans lesquels rechercher pour découvrir .cargo/config.toml, par exemple. Cet option doit apparaître avant le nom de la commande, par exemple cargo -C chemin/vers/mon-projet build.

Cette option n'est disponible que sur le canal nightly https://doc.rust-lang.org/book/appendix-07-nightly-rust.html et nécessite l'indicateur -Z unstable-options pour être activé (voir #10098 https://github.com/rust-lang/cargo/issues/10098).

-h, --help

Affiche les informations d'aide.

-Z indicateur

Indicateurs instables (réservés à nightly) pour Cargo. Exécutez cargo -Z help pour les détails.

ENVIRONNEMENT

Voir la référence https://doc.rust-lang.org/cargo/reference/environment-variables.html pour les détails sur les variables d'environnement que Cargo lit.

CODE DE SORTIE

•0 : Cargo a réussi.
•101 : Cargo n'a pas pu être terminé.

EXEMPLES

1. Désinstaller un paquet précédemment installé. 
cargo uninstall ripgrep
