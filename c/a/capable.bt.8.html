NOM

capable.bt - Trace les vérifications de capacités de sécurité (cap_capable()).

SYNTAXE

capable.bt

DESCRIPTION

Cela trace les vérifications de capacités de sécurité dans le noyau et affiche les détails de chaque appel. Ceci peut être utile pour le débogage général, ainsi que pour l'application de la sécurité : déterminer une liste blanche des capacités dont une application a besoin.

Étant donné que cela utilise BPF, seul l'utilisateur root peut utiliser cet outil.

PRÉREQUIS

CONFIG_BPF, bpftrace.

EXEMPLES

Tracer toutes les vérifications de capacités dans tout le système :
# capable.bt

CHAMPS

HEURE(s)
Heure de la vérification de capacité : HH:MM:SS.
UID
Identifiant utilisateur.
PID
Identifiant du processus.
COMM
Nom du processus. CAP Numéro de capacité. NOM Nom de la capacité. Voir capabilities(7) pour les descriptions.
AUDIT
Si cet événement était un événement d'audit.

SURCHARGE

Cela ajoute une instrumentation à faible surcharge aux vérifications de capacités, qui sont censées être de faible fréquence, bien que cela dépende de l'application. Testez dans un environnement de laboratoire avant utilisation.

SOURCE

Ceci vient de bpftrace.

https://github.com/bpftrace/bpftrace

Consultez également la distribution bpftrace pour un fichier _examples.txt compagnon contenant des exemples d'utilisation, de sortie et des commentaires pour cet outil.

Il s'agit d'une version bpftrace de l'outil bcc du même nom. L'outil bcc offre des options pour personnaliser la sortie.

https://github.com/iovisor/bcc
