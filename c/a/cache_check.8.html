NOM

cache_check - valide les métadonnées du cache sur un périphérique ou un fichier.

SYNTAXE

cache_check [options] {périphérique|fichier}

DESCRIPTION

cache_check vérifie les métadonnées de cache créées par la cible de mise en cache du device-mapper sur un périphérique ou un fichier.

Cet outil ne peut pas être exécuté sur des métadonnées actives.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche les informations de version et quitte.
-q, --quiet
Supprime les messages de sortie, renvoie uniquement le code de sortie.
--super-block-only
Vérifie uniquement le super bloc.
--skip-hints
Ignore la vérification des métadonnées des valeurs d'indices de politique.
--skip-discards
Ignore la vérification des bits de défausse dans les métadonnées.
--clear-needs-check-flag
Efface l'indicateur « needs_check » dans le super bloc.
    Le noyau peut définir un indicateur pour forcer la vérification du pool avant sa prochaine
    activation. Définissez ce commutateur pour effacer l'indicateur si la vérification réussit.
    Si la vérification des métadonnées a échoué, l'indicateur n'est pas effacé et une exécution de
    cache_repair est nécessaire pour corriger tout problème. Une fois que cache_repair a réussi,
    vous pouvez exécuter à nouveau cache_check.

EXEMPLE

Analyse et répare les métadonnées de cache sur le volume logique /dev/vg/metadata :

    $ cache_check /dev/vg/metadata
Le périphérique ne doit pas être activement utilisé par la cible lors de l'exécution.

DIAGNOSTICS

cache_check renvoie un code de sortie de 0 en cas de succès ou 1 en cas d'erreur.

VOIR AUSSI

cache_dump(8), cache_repair(8), cache_restore(8)
