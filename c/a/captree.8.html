NOM

captree - affiche l'arbre des capacités des processus

SYNTAXE

captree [OPTIONS] [(pid|nom-globale) ...]

DESCRIPTION

captree affiche les capacités sur les processus mentionnés indiqués par les valeurs pid ou nom-globale fournies sur la ligne de commande. Si aucune valeur pid, etc. n'est fournie, pid=1 est implicite. Une valeur pid de 0 affiche tous les processus connus du noyau.

Les capacités POSIX.1e sont affichées entre guillemets au format cap_from_text(3). Le tuple IAB des capacités est affiché entre crochets au format texte décrit dans cap_iab(3). Ces deux formats texte sont décrits dans cap_text_formats(7). Notez que le texte du tuple IAB est omis s'il contient des composantes A et B vides. Ceci est dû au fait que le texte POSIX.1e régulier contient déjà des informations sur le drapeau d'héritage. Ce comportement peut être outrepassé avec l'argument de ligne de commande --verbose.

Arguments optionnels (qui doivent précéder la liste des valeurs pid|nom-globale) :

--help
Affiche les informations d'utilisation et quitte. Notez que les runtimes Go modernes sortent avec le statut 0 dans ce cas, mais les runtimes plus anciens sortent avec le statut 2.
--verbose
Affiche les ensembles de capacités et les tuples IAB même lorsqu'ils sont vides ou redondants.
--depth=n
Affiche l'arbre des processus jusqu'à une profondeur de n. Notez que la valeur par défaut pour ce paramètre est 0, ce qui implique une profondeur infinie.
--colo[u]r=false
Colo[u]re les PID cibles, si la sortie standard est un TTY, en rouge. Cette option est activée par défaut lorsqu'elle est exécutée via un TTY. L'argument --color=false supprimera cette couleur. Le passage de la sortie à un autre programme supprimera également l'utilisation de la colo[u]r.

STATUT DE SORTIE

Si la cible fournie ne peut être trouvée, le statut de sortie est 1. Si une option non reconnue est fournie, le statut de sortie est 2. Sinon, captree se termine avec le statut 0.
