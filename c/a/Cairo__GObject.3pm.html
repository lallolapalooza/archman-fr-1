NOM

Cairo::GObject - Intégrer Cairo dans le système de types Glib

SYNOPSIS

use Cairo::GObject;
# Cairo et Glib sont maintenant chargés et les types Cairo sont enregistrés auprès
# des mécanismes de types de Glib. Cela vous permet d'utiliser correctement les types Cairo
# dans les signaux et les propriétés.

RÉSUMÉ

Cairo::GObject enregistre les types de Cairo ("Cairo::Context", "Cairo::Surface", etc.) auprès des systèmes de types de Glib afin qu'ils puissent être utilisés normalement dans les signaux et les propriétés. Si vous avez rencontré une erreur similaire à celle-ci :

GType CairoContext (15497280) n'est pas enregistré avec gperl

-- alors vous devez utiliser Cairo::GObject.
