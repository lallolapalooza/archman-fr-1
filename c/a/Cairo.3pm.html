RÉSUM

É

Cairo fournit des liaisons Perl pour la bibliothèque de graphiques vect

oriels cairo. Elle prend en charge plusieurs cibles de sortie, y compris
PNG, PDF et SVG. Cairo produit une sortie identique sur toutes ces cibles.

Chemins -- Création de chemins et manipulation des données de

chemin 
$path = [
  { type => "move-to", points => [[1, 2]] },
  { type => "line-to", points => [[3, 4]] },
  { type => "curve-to", points => [[5, 6], [7, 8], [9, 10]] },
  ...
  { type => "close-path", points => [] },
]
;

Cairo::Path est une structure de données servant à contenir un chemin. Cette structure de données sert de valeur de retour pour "$cr->copy_path" et "$cr->copy_path_flat" ainsi que de valeur d'entrée pour "$cr->append_

path".

Cairo::Path est représenté comme une référence de tableau qui contient des éléments de chemin, représentés par des références de hachage avec deux clés : type et points. La valeur pour type peut être l'une des suivantes

:
"move-t
o"
"line-t
o"
"curve-t
o"
"close-pat
h"

La valeur pour points est une référence de tableau qui contient zéro point ou plus. Les points sont représentés comme des références de tableau contenant deux doubles : x et y. Le nombre de points nécessaires dépend du type de l'élément de chemin

:
"move-to" : 1
point
"line_to" : 1
point
"curve-to" : 3
points
"close-path" : 0
point

La sémantique et l'ordre des valeurs de coordonnées sont cohérents avec "$cr->move_to", "$cr->line_to", "$cr->curve_to" et "$cr->close_

path".

Notez que les chemins retournés par Cairo sont implémentés comme des références de tableau liées qui ne prennent pas en charge l'ajout, la suppression ou le mélange de segments de chemin. Pour ces opérations, vous devez d'abord faire une copie superficielle

: 
my @path_clone = @{$path};
# maintenant vous pouvez modifier @path_clone comme vous le
souhaitez

Les points d'un seul élément de chemin peuvent être modifiés directement, cependant, sans avoir besoin d'une copie superficielle

: 
$path->[$i]{points} = [[3, 4], [5, 6], [7, 8]]
