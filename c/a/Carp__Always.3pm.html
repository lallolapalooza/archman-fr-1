NOM

Carp::Always - Avertit et meurt bruyamment avec des traces de pile

SYNTAXE

use Carp::Always;

Souvent utilisé en ligne de commande :

perl -MCarp::Always script.pl

DESCRIPTION

Ce module est destiné à être une aide au débogage. Il peut être utilisé pour faire en sorte qu'un script se plaigne bruyamment avec des traces de pile lors de l'appel de warn() ou de die().

Voici à quoi ressemblent les traces de pile produites par ce module :

# cela fonctionne pour les die et warn explicites
$ perl -MCarp::Always -e 'sub f { die "arghh" }; sub g { f }; g'
arghh at -e line 1
        main::f() called at -e line 1
        main::g() called at -e line 1
# cela fonctionne pour les erreurs déclenchées par l'interpréteur
$ perl -MCarp::Always -w -e 'sub f { $a = shift; @a = @$a };' \
                         -e 'sub g { f(undef) }; g'
Use of uninitialized value in array dereference at -e line 1
        main::f('undef') called at -e line 2
        main::g() called at -e line 2

Dans l'implémentation, le module Carp fait le gros du travail, via longmess(). L'implémentation réelle définit les hooks de signal $SIG{__WARN__} et $SIG{__DIE__} pour émettre les traces de pile.

De plus, toutes les utilisations de "carp" et "croak" sont rendues verbeuses, se comportant comme "cluck" et "confess".

MÉTHODES

Carp::Always implémente les méthodes suivantes.

import

Carp::Always->import()

Active Carp::Always. Également déclenché par des instructions comme

use Carp::Always;
use Carp::Always 0.14;

mais pas par

use Carp::Always ();    # n'invoque pas import()

unimport

Carp::Always->unimport();

Désactive Carp::Always. Également déclenché avec

no Carp::Always;

REMERCIEMENTS

Ce module est né en réaction à une publication d'Acme::JavaTrace par Sébastien Aperghis-Tramoni. Sébastien a également un module plus récent appelé Devel::SimpleTrace avec le même code et moins de commentaires flame sur la documentation. L'élagage de la documentation inutilement longue de ce module a été encouragé par Michael Schwern.

Schwern et d'autres m'ont dit "le nom du module était pourri" - il s'appelait "Carp::Indeed". Après avoir longuement réfléchi et n'aboutir à rien, j'ai suivi la suggestion de nuffin et maintenant il s'appelle "Carp::Always".

BOGUES

  • Ce module ne fonctionne pas bien avec d'autres modules qui manipulent "warn", "die", $SIG{__WARN__}, $SIG{__DIE__}.
  • Les scripts de test sont bons. Je devrais en écrire plus.

Veuillez signaler les bogues via GitHub https://github.com/aferreira/cpan-Carp-Always/issues
