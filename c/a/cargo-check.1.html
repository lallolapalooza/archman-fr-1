DESCRIPTIO

N

Vérifie un paquet local et toutes ses dépendances pour détecter des erreurs. Cela compile essentiellement les paquets sans effectuer la dernière étape de génération de code, ce qui est plus rapide que d'exécuter cargo build. Le compilateur enregistre des fichiers de métadonnées sur le disque afin que les exécutions futures puissent les réutiliser si la source n'a pas été modifiée. Certains diagnostics et erreurs ne sont émis que lors de la génération de code, ils ne seront donc pas signalés avec cargo

che
ck.

NAME

cargo-check

check a local package for errors

SYNOPSIS

cargo check [OPTIONS] [SPEC…]

DESCRIPTION

This command checks a local package for errors.

By default, it checks the main package in the current directory.

It compiles the code, but does not produce executables or libraries.

The primary purpose of cargo check is to run the compiler in a way that is fast, and provides quick feedback on whether the code compiles, and with what errors. It can be used as a quicker alternative to cargo build when you only care about whether the code compiles.

The command will build all dependencies, but will skip building the crate itself if it can determine that it hasn't changed since the last build. It also skips tests and examples, and does not produce any output artifacts.

OPTIONS

Cargo supports many options, here are a few of the most common ones:

--all-features
Enable all features of the package.
--no-default-features
Disable the default features of the package.
--features <FEATURES>
Comma-separated list of features to enable.
--target <TRIPLE>
Check for the given target triple.
--release
Check with optimizations enabled.
--profile <PROFILE>
Check with all the settings from the specified profile.
--workspace
Check all packages in the workspace.
--all
Check all packages in the crate.
--tests
Check all tests.
--doc
Check documentation.
--no-deps
Don't check dependency crates.
--timings
Output information about the time spent in the compiler.
--future-incompat-report
Displays a future-incompat report for any future-incompatible warnings produced during execution of this command

See cargo-report(1)

ENVIRONMENT

See the reference https://doc.rust-lang.org/cargo/reference/environment-variables.html for details on environment variables that Cargo reads.

EXIT STATUS

•0: Cargo succeeded.
•101: Cargo failed to complete.

EXAMPLES

1.Check the local package for errors: 
cargo check
2.Check all targets, including unit tests: 
cargo check --all-targets --profile=test
