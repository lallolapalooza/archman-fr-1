format)

Importe un tampon mémoire dans la trame courante du canevas libcaca donné. La trame courante est redimensionnée en conséquence et son contenu est remplacé par les données

importées.

Les valeurs valides pour format sont

:
  • '' : tente de détecter automatiquement le format du
    • fichier.
  • 'caca' : importe les fichiers libcaca
    • natifs.
  • 'text' : importe les fichiers texte
    • ASCII.
  • 'ansi' : importe les fichiers
    • ANSI.
  • 'utf8' : importe les fichiers UTF-8 avec codes de couleur
    • ANSI.
  • 'bin' : imp
    • orte les fi
chiers BIN.

Le nombre d'octets lus est renvoyé. Si le format de fichier est valide, mais que les données disponibles étaient insuffisantes, 0 est

renvoyé.

Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence

:
  • ENOMEM Mémoire insuffisante pour allouer le
    • canevas.
  • EOVERFLOW L'importation des données a provoqué un débordement de
    • valeur.
  • EINVAL For
    • mat demandé
invalide.

Cette fonction exporte un canvas libcaca vers divers formats externes tels que l'art ANSI, HTML, les couleurs IRC, etc. Le pointeur retourné doit être passé à free() pour libérer le stockage alloué lorsqu'il n'est plus

nécessaire.

Les valeurs valides pour format sont

:
  • 'caca' : exporte les fichiers natifs
    • libcaca.
  • 'ansi' : exporte de l'art ANSI (jeu de caractères CP437 avec codes de couleur
    • ANSI).
  • 'html' : exporte une page HTML avec informations
    • CSS.
  • 'html3' : exporte un tableau HTML qui devrait être compatible avec la plupart des navigateurs, y compris ceux en mode
    • texte.
  • 'irc' : exporte du texte UTF-8 avec les codes de couleur
    • mIRC.
  • 'ps' : exporte un document
    • PostScript.
  • 'svg' : exporte une image vectorielle
    • SVG.
  • 'tga' : exporte une image
    • TGA.
  • 'troff' : ex
    • porte une s
ource troff.

    • charge.
