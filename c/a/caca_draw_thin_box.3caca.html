DESCRIPTION Détaillée

Ces fonctions fournissent des routines de dessin de primitives, telles que des lignes, des boîtes, des triangles et des ellipses.

Paramètres

x1 Coordonnée X du premier point.
y1 Coordonnée Y du premier point.
x2 Coordonnée X du second point.
y2 Coordonnée Y du second point.

__extern int caca_draw_polyline (caca_canvas_t * cv, int const x[], int const y[], int n, uint32_t ch)

Dessine une polyligne sur le canevas en utilisant le caractère et les tableaux de coordonnées donnés. Le premier et le dernier point ne sont pas reliés, donc pour dessiner un polygone, vous devez également spécifier le point de départ à la fin de la liste.

Cette fonction ne renvoie jamais d'erreur.

Paramètres

cv Le handle vers le canevas libcaca.
x Tableau des coordonnées X. Doit avoir n + 1 éléments.
y Tableau des coordonnées Y. Doit avoir n + 1 éléments.
n Nombre de lignes à dessiner.
ch Caractère UTF-32 à utiliser pour dessiner les lignes.

Retour

Cette fonction renvoie toujours 0.

__extern int caca_draw_thin_polyline (caca_canvas_t * cv, int const x[], int const y[], int n)

Dessine une polyligne fine sur le canevas en utilisant les tableaux de coordonnées donnés et avec de l'art ASCII. Le premier et le dernier point ne sont pas reliés, donc pour dessiner un polygone, vous devez également spécifier le point de départ à la fin de la liste.

Cette fonction ne renvoie jamais d'erreur.

Paramètres

cv Le handle vers le canevas libcaca.
x Tableau des coordonnées X. Doit avoir n + 1 éléments.
y Tableau des coordonnées Y. Doit avoir n + 1 éléments.
n Nombre de lignes à dessiner.

Retour

Cette fonction renvoie toujours 0.
