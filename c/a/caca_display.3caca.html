Description détaillée

Ces fonctions fournissent les routines de base de libcaca pour l'initialisation de l'affichage, la récupération d'informations système et la configuration.

Documentation des fonctions

__extern caca_display_t * caca_create_display (caca_canvas_t * cv)

Crée un contexte graphique utilisant des fonctionnalités dépendantes du périphérique (ncurses pour les terminaux, une fenêtre X11, une invite de commande DOS...) qui s'attache à une toile libcaca. Tout ce qui est dessiné dans la toile libcaca peut alors être affiché par le pilote libcaca.

Si aucune toile caca n'est fournie, une nouvelle est créée. Son handle peut être récupéré en utilisant caca_get_canvas() et elle est automatiquement détruite lorsque caca_free_display() est appelée.

Notez que pour obtenir une compatibilité Unicode maximale, le code d'initialisation du pilote peut modifier temporairement la locale globale LC_CTYPE du programme en utilisant setlocale(). Il est conseillé de ne pas appeler de fonctions dépendantes de LC_CTYPE depuis d'autres threads pendant l'appel à caca_create_display(). Les paramètres de locale sont restaurés lorsque la fonction retourne.

Voir aussi caca_create_display_with_driver().

Si une erreur se produit, NULL est retourné et errno est défini en conséquence :

  • ENOMEM Pas assez de mémoire.
  • ENODEV Périphérique graphique non initialisé.

Paramètres

cv La toile caca ou NULL pour créer une toile automatiquement.

Retourne

Le contexte graphique caca ou NULL si une erreur s'est produite.

Références caca_create_display_with_driver().

__extern caca_display_t * caca_create_display_with_driver (caca_canvas_t * cv, char const * driver)

Crée un contexte graphique utilisant des fonctionnalités dépendantes du périphérique (ncurses pour les terminaux, une fenêtre X11, une invite de commande DOS...) qui s'attache à une toile libcaca. Tout ce qui est dessiné dans la toile libcaca peut alors être affiché par le pilote libcaca.

Si aucune toile caca n'est fournie, une nouvelle est créée. Son handle peut être récupéré en utilisant caca_get_canvas() et elle est automatiquement détruite lorsque caca_free_display() est appelée.

Si aucun nom de pilote n'est fourni, libcaca tentera de détecter automatiquement le meilleur pilote de sortie possible.

Voir aussi caca_create_display().

Si une erreur se produit, NULL est retourné et errno est défini en conséquence :

  • ENOMEM Pas assez de mémoire.
  • ENODEV Périphérique graphique non initialisé.

Paramètres

cv La toile caca ou NULL pour créer une toile automatiquement.
driver Une chaîne décrivant le pilote de sortie désiré ou NULL pour choisir le meilleur pilote automatiquement.

Retourne

Le contexte graphique caca ou NULL si une erreur s'est produite.

Références caca_create_canvas(), caca_free_canvas(), caca_manage_canvas(), et caca_unmanage_canvas().

Réfèrencé par caca_create_display().

__extern char const *const * caca_get_display_driver_list (void )

Retourne une liste des pilotes d'affichage disponibles. La liste est un tableau de chaînes de caractères terminé par NULL, entrelant une chaîne contenant la valeur interne du pilote d'affichage, et une chaîne contenant la description en langage naturel de ce pilote.

Cette fonction ne échoue jamais.

Retourne

Un tableau de chaînes de caractères.

__extern int caca_free_display (caca_display_t * dp)

Détache un contexte graphique de son backend caca et le détruit. La toile libcaca continue d'exister et d'autres contextes graphiques peuvent y être attachés par la suite.

Si la toile caca a été créée automatiquement par caca_create_display(), elle est automatiquement détruite et tout handle la concernant devient invalide.

Cette fonction ne échoue jamais.

Paramètres

dp Le contexte graphique libcaca.

Retourne

Cette fonction retourne toujours 0.

Références caca_free_canvas(), et caca_unmanage_canvas().

__extern int caca_refresh_display (caca_display_t * dp)

Vide toutes les opérations graphiques et les imprime sur le périphérique d'affichage. Rien ne s'affichera à l'écran tant que cette fonction n'est pas appelée.

Si caca_set_display_time() a été appelée avec une valeur non nulle, caca_refresh_display() utilisera cette valeur pour obtenir une fréquence d'images constante : si deux appels consécutifs à caca_refresh_display() sont dans un intervalle de temps inférieur à la valeur définie avec caca_set_display_time(), le second appel sera retardé avant d'effectuer l'actualisation de l'écran.

Cette fonction ne échoue jamais.

Paramètres

dp Le contexte d'affichage libcaca.

Retourne

Cette fonction retourne toujours 0.

Références caca_clear_dirty_rect_list().

__extern int caca_set_display_time (caca_display_t * dp, int usec)

Définit le délai de rafraîchissement en microsecondes. Le délai de rafraîchissement est utilisé par caca_refresh_display() pour obtenir une fréquence d'images constante. Voir la documentation de caca_refresh_display() pour plus de détails.

Si l'argument est zéro, la fréquence d'images constante est désactivée. C'est le comportement par défaut.

En cas d'erreur, -1 est retourné et errno est défini en conséquence :

•
EINVAL La valeur du délai de rafraîchissement est invalide.

Paramètres

dp Le contexte d'affichage libcaca.
usec Le délai de rafraîchissement en microsecondes.

Retourne

0 en cas de succès, -1 en cas d'erreur.

__extern int caca_get_display_time (caca_display_t const * dp)

Obtient le temps de rendu moyen, qui est le temps moyen mesuré entre deux appels à caca_refresh_display(), en microsecondes. Si la fréquence d'images constante a été activée en appelant caca_set_display_time(), le temps de rendu moyen sera proche du délai demandé même si le temps de rendu réel était plus court.

Cette fonction ne échoue jamais.

Paramètres

dp Le contexte d'affichage libcaca.

Retourne

Le temps de rendu en microsecondes.

__extern int caca_get_display_width (caca_display_t const * dp)

Si libcaca s'exécute dans une fenêtre, obtient la largeur utilisable de la fenêtre. Cette valeur peut être utilisée pour le calcul du rapport d'aspect. Si libcaca ne s'exécute pas dans une fenêtre ou s'il n'y a aucun moyen de connaître la taille de la police, la plupart des pilotes supposeront qu'une police de 6x10 est utilisée. Notez que les unités ne sont pas nécessairement des pixels.

Cette fonction ne échoue jamais.

Paramètres

dp Le contexte d'affichage libcaca.

Retourne

La largeur d'affichage.

__extern int caca_get_display_height (caca_display_t const * dp)

Si libcaca s'exécute dans une fenêtre, obtient la hauteur utilisable de la fenêtre. Cette valeur peut être utilisée pour le calcul du rapport d'aspect. Si libcaca ne s'exécute pas dans une fenêtre ou s'il n'y a aucun moyen de connaître la taille de la police, suppose qu'une police de 6x10 est utilisée. Notez que les unités ne sont pas nécessairement des pixels.

Cette fonction ne échoue jamais.

Paramètres

dp Le contexte d'affichage libcaca.

Retourne

La hauteur d'affichage.

__extern int caca_set_display_title (caca_display_t * dp, char const * title)

Si libcaca s'exécute dans une fenêtre, essaie de changer son titre. Cela fonctionne avec les pilotes ncurses, S-Lang, OpenGL, X11 et Win32.

En cas d'erreur, -1 est retourné et errno est défini en conséquence :

•
ENOSYS Le pilote d'affichage ne prend pas en charge la définition du titre de la fenêtre.

Paramètres

dp Le contexte d'affichage libcaca.
title Le titre d'affichage souhaité.

Retourne

0 en cas de succès, -1 en cas d'erreur.

__extern int caca_set_mouse (caca_display_t * dp, int flag)

Affiche ou masque le pointeur de la souris. Cette fonction fonctionne avec les pilotes ncurses, S-Lang et X11.

En cas d'erreur, -1 est retourné et errno est défini en conséquence :

•
ENOSYS Le pilote d'affichage ne prend pas en charge le masquage du pointeur de la souris.

Paramètres

dp Le contexte d'affichage libcaca.
flag 0 masque le pointeur, 1 affiche le pointeur par défaut du système (généralement une flèche). Les autres valeurs sont réservées pour une utilisation future.

Retourne

0 en cas de succès, -1 en cas d'erreur.

__extern int caca_set_cursor (caca_display_t * dp, int flag)

Affiche ou masque le curseur, pour les périphériques qui prennent en charge cette fonctionnalité.

En cas d'erreur, -1 est retourné et errno est défini en conséquence :

•
ENOSYS Le pilote d'affichage ne prend pas en charge l'affichage du curseur.

Paramètres

dp Le contexte d'affichage libcaca.
flag 0 masque le curseur, 1 affiche le curseur par défaut du système (généralement un rectangle blanc). Les autres valeurs sont réservées pour une utilisation future.

Retourne

0 en cas de succès, -1 en cas d'erreur.
