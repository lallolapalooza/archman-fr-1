NOM

Caja-file-management-properties - Préférences de gestion de fichiers de Caja

SYNTAXE

caja-file-management-properties

DESCRIPTION

Caja File Management Properties est distribué dans le cadre du paquet caja et est utilisé pour configurer les préférences de Caja. Il est généralement accessible via le menu "Édition" dans les fenêtres du navigateur Caja, ou en appuyant sur "ALT+E" puis "N" une fois le menu ouvert.

Les Préférences de gestion de fichiers permettent à l'utilisateur de configurer le comportement de caja.

Vous pouvez spécifier les préférences d'apparence pour la Vue par défaut ; et les valeurs par défaut pour la Vue Icônes, Compacte, Liste et Arborescence ; et sélectionner les options de tri et d'affichage. Vous pouvez configurer Caja pour reconnaître une seule ou double clic comme entrée ; ainsi que d'inclure une commande Supprimer et une option de menu qui contourne la Corbeille. Caja File Management Properties (caja-file-management-properties) vous permet également d'indiquer à Caja comment gérer certains fichiers ; s'il faut Afficher ou Exécuter les fichiers texte exécutables ; Afficher ou Lire automatiquement les médias comme les CD, DVD ou photos, et quelles applications utiliser lors de ces tâches. Entre autres options, cette boîte de dialogue vous permet également d'ajuster les paramètres d'aperçu de fichiers et les paramètres des plugins installés, s'ils existent.
