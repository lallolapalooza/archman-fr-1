CARGO-LOCATE-PROJECT(1) Manuel des commandes générales CARGO-LOCATE-PROJECT(1)

NOM

cargo-locate-project — Imprime une représentation JSON du fichier Cargo.toml et de son emplacement

SYNOPIS

cargo locate-project [options]

DESCRIPTION

Cette commande imprime un objet JSON sur la sortie standard avec le chemin complet du manifeste. Le manifeste est trouvé en cherchant vers le haut un fichier nommé Cargo.toml à partir du répertoire de travail courant.

Si le projet fait partie d'un espace de travail (workspace), le manifeste du projet, plutôt que la racine de l'espace de travail, est affiché. Ceci peut être remplacé par l'indicateur --workspace. La racine de l'espace de travail est trouvée en remontant plus haut ou en utilisant le champ package.workspace après avoir localisé le manifeste d'un membre de l'espace de travail.

OPTIONS

--workspace

Localise le Cargo.toml à la racine de l'espace de travail, par opposition au membre de l'espace de travail courant.

Options d'affichage

--message-format fmt

La représentation dans laquelle imprimer l'emplacement du projet. Valeurs valides :
•json (par défaut) : Objet JSON avec le chemin sous la clé « root ».
•plain : Juste le chemin.

-v, --verbose

Utilise une sortie verbeuse. Peut être spécifié deux fois pour une sortie « très verbeuse » qui inclut des informations supplémentaires telles que des avertissements de dépendance et la sortie des scripts de construction. Peut également être spécifié avec la valeur de configuration term.verbose https://doc.rust-lang.org/cargo/reference/config.html.

-q, --quiet

Ne pas afficher les messages de journalisation de cargo. Peut également être spécifié avec la valeur de configuration term.quiet https://doc.rust-lang.org/cargo/reference/config.html.

--color quand

Contrôle quand la sortie colorée est utilisée. Valeurs valides :
•auto (par défaut) : Détecte automatiquement si le support des couleurs est disponible sur le terminal.
•always : Affiche toujours les couleurs.
•never : N'affiche jamais les couleurs.

Peut également être spécifié avec la valeur de configuration term.color https://doc.rust-lang.org/cargo/reference/config.html.

Options de manifeste

--manifest-path chemin

Chemin vers le fichier Cargo.toml. Par défaut, Cargo recherche le fichier Cargo.toml dans le répertoire courant ou dans tout répertoire parent.

Options communes

+toolchain

Si Cargo a été installé avec rustup, et que le premier argument de cargo commence par +, il sera interprété comme un nom de toolchain rustup (tel que +stable ou +nightly). Voir la documentation de rustup https://rust-lang.github.io/rustup/overrides.html pour plus d'informations sur le fonctionnement des remplacements de toolchain.

--config CLE=VALEUR ou CHEMIN

Remplace une valeur de configuration Cargo. L'argument doit être dans la syntaxe TOML de CLE=VALEUR, ou fourni comme chemin vers un fichier de configuration supplémentaire. Cet indicateur peut être spécifié plusieurs fois. Voir la section sur les remplacements en ligne de commande https://doc.rust-lang.org/cargo/reference/config.html#command-line-overrides pour plus d'informations.

-C CHEMIN

Change le répertoire de travail courant avant d'exécuter les opérations spécifiées. Cela affecte notamment les endroits où cargo recherche par défaut le manifeste du projet (Cargo.toml), ainsi que les répertoires recherchés pour découvrir .cargo/config.toml, par exemple. Cette option doit apparaître avant le nom de la commande, par exemple cargo -C chemin/vers/mon-projet build.

Cette option n'est disponible que sur le canal nightly https://doc.rust-lang.org/book/appendix-07-nightly-rust.html et nécessite l'indicateur -Z unstable-options pour être activé (voir #10098 https://github.com/rust-lang/cargo/issues/10098).

-h, --help

Imprime les informations d'aide.

-Z flag

Indicateurs instables (réservés à la nightly) pour Cargo. Exécutez cargo -Z help pour les détails.

ENVIRONNEMENT

Voir la référence https://doc.rust-lang.org/cargo/reference/environment-variables.html pour les détails sur les variables d'environnement que Cargo lit.

STATUT DE SORTIE

•0 : Cargo a réussi.
•101 : Cargo n'a pas pu terminer.

EXEMPLES

1. Affiche le chemin du manifeste en fonction du répertoire courant : 
cargo locate-project
