NOM

cardos-tool - affiche des informations sur les jetons de sécurité basés sur Card OS ou les formate

SYNTAXE

cardos-tool [OPTIONS]

DESCRIPTION

L'utilitaire cardos-tool est utilisé pour afficher des informations sur les cartes à puce et les jetons de sécurité similaires basés sur Siemens Card/OS M4.

OPTIONS

--format, -f

Formate la carte ou le jeton.

--help, -h

Affiche le message d'aide à l'écran.

--info, -i

Affiche des informations sur la carte ou le jeton.

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est un ATR, le lecteur avec une carte correspondante sera choisi.

--startkey arg, -s arg

Spécifie la clé de départ pour le formatage.

--change-startkey arg, -S arg

Change la clé de départ avec la commande APDU donnée.

--verbose, -v

Rend cardos-tool plus verbeux. Spécifiez cet indicateur plusieurs fois pour activer la sortie de débogage dans la bibliothèque opensc.

--wait, -w

Fait attendre cardos-tool l'insertion du jeton dans le lecteur.

AUTEURS
