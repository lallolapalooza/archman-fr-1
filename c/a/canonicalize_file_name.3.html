canonicalize_file_name(3) Manuel des fonctions de bibliothèque canonicalize_file_name(3)

NOM

canonicalize_file_name - renvoie le chemin canonisé absolu

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <stdlib.h>
char *canonicalize_file_name(const char *path);

DESCRIPTION

La fonction canonicalize_file_name() renvoie une chaîne terminée par un caractère nul contenant le chemin absolu canonisé correspondant à path. Dans la chaîne renvoyée, les liens symboliques sont résolus, tout comme les composants de chemin . et ... Les caractères slash (/) consécutifs sont remplacés par un seul slash.

La chaîne renvoyée est allouée dynamiquement par canonicalize_file_name() et l'appelant doit la désallouer avec free(3) lorsqu'elle n'est plus nécessaire.

L'appel canonicalize_file_name(path) est équivalent à l'appel :


realpath(path, NULL);

VALEUR DE RETOUR

En cas de succès, canonicalize_file_name() renvoie une chaîne terminée par un caractère nul. En cas d'erreur (par exemple, un composant de chemin est illisible ou n'existe pas), canonicalize_file_name() renvoie NULL et définit errno pour indiquer l'erreur.

ERREURS

Voir realpath(3).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur

NORMES

GNU.

VOIR AUSSI
