CAPTEST:(8) Utilitaires d'administration système CAPTEST:(8)

NOM

captest - un programme pour démontrer les capacités

SYNTAXE

captest [ --ambient --drop-all | --drop-caps | --id ] [ --init-grp ] [ --lock ] [ --text ]

DESCRIPTION

captest est un programme qui démontre et affiche les capacités du processus actuel. Chaque option affiche le même rapport. Il affichera les capacités actuelles. Ensuite, il tentera d'accéder directement à /etc/shadow pour montrer si cela est possible. Il crée ensuite un processus enfant qui tente de lire /etc/shadow et affiche les résultats. Ensuite, il affiche les capacités qu'un processus enfant aurait.

Vous pouvez également appliquer des capacités du système de fichiers à ce programme pour étudier leur fonctionnement. Par exemple, utilisez `filecap /usr/bin/captest chown`. Ensuite, exécutez `captest` en tant qu'utilisateur normal. Un autre test intéressant consiste à rendre `captest` suid root afin que vous puissiez voir l'interaction entre les identifiants de root et les capacités. Par exemple, utilisez `chmod 4755 /usr/bin/captest`. Lorsque le programme est exécuté par un utilisateur normal, il vérifiera si une élévation de privilèges est possible. Mais ne laissez pas cette application en setuid root après avoir terminé les tests, afin qu'un attaquant ne puisse pas en profiter.

OPTIONS

--ambient
Tente d'ajouter la capacité ambiante CAP_CHOWN.
--drop-all
Supprime toutes les capacités, y compris les capacités ambiantes, et efface l'ensemble des bornes.
--drop-caps
Supprime uniquement les capacités traditionnelles.
--id
Change l'uid et le gid en 99, supprime les groupes supplémentaires et efface l'ensemble des bornes.
--init-grp
Change l'uid et le gid en 99, puis ajoute tous les groupes supplémentaires associés à ce compte. Vous devrez les ajouter avant le test car, par défaut, il n'y a pas de groupes supplémentaires pour le compte 99.
--text
Cette option affiche les capacités effectives en texte plutôt qu'en numérique.
--lock
Empêche les processus enfants de retrouver leurs privilèges si l'uid est 0.

VOIR AUSSI

filecap(8), capabilities(7)
