CARGO-SEARCH(1) Manuel des commandes générales CARGO-SEARCH(1)

NOM

cargo-search — Recherche des paquets dans le registre. Le registre par défaut est crates.io

SYNOPIS

cargo search [options] [requête…]

DESCRIPTION

Effectue une recherche textuelle de crates sur https://crates.io. Les crates correspondants seront affichés avec leur description au format TOML, prêts à être copiés dans un fichier manifeste Cargo.toml.

OPTIONS

Options de recherche

--limit limite

Limite le nombre de résultats (par défaut : 10, maximum : 100).

--index index

L'URL de l'index du registre à utiliser.

--registry registry

Nom du registre à utiliser. Les noms de registres sont définis dans les fichiers de configuration de Cargo https://doc.rust-lang.org/cargo/reference/config.html. S'il n'est pas spécifié, le registre par défaut est utilisé, défini par la clé de configuration registry.default qui vaut par défaut crates-io.

Options d'affichage

-v, --verbose

Utilise une sortie détaillée. Peut être spécifié deux fois pour une sortie « très détaillée » qui inclut des informations supplémentaires telles que des avertissements de dépendance et la sortie des scripts de construction. Peut également être spécifié avec la valeur de configuration term.verbose https://doc.rust-lang.org/cargo/reference/config.html.

-q, --quiet

Ne pas afficher les messages de log de cargo. Peut également être spécifié avec la valeur de configuration term.quiet https://doc.rust-lang.org/cargo/reference/config.html.

--color quand

Contrôle quand la sortie colorisée est utilisée. Valeurs valides :
•auto (par défaut) : Détecte automatiquement si le support des couleurs est disponible sur le terminal.
•always : Affiche toujours les couleurs.
•never : N'affiche jamais les couleurs.

Peut également être spécifié avec la valeur de configuration term.color https://doc.rust-lang.org/cargo/reference/config.html.

Options communes

+toolchain

Si Cargo a été installé avec rustup, et que le premier argument de cargo commence par +, il sera interprété comme un nom de toolchain rustup (tel que +stable ou +nightly). Voir la documentation rustup https://rust-lang.github.io/rustup/overrides.html pour plus d'informations sur le fonctionnement des remplacements de toolchain.

--config CLÉ=VALEUR ou CHEMIN

Remplace une valeur de configuration de Cargo. L'argument doit être en syntaxe TOML de CLÉ=VALEUR, ou fourni comme chemin vers un fichier de configuration supplémentaire. Cet indicateur peut être spécifié plusieurs fois. Voir la section sur les remplacements en ligne de commande https://doc.rust-lang.org/cargo/reference/config.html#command-line-overrides pour plus d'informations.

-C CHEMIN

Change le répertoire de travail courant avant d'exécuter toute opération spécifiée. Cela affecte par exemple où cargo recherche par défaut le manifeste du projet (Cargo.toml), ainsi que les répertoires explorés pour découvrir .cargo/config.toml, par exemple. Cette option doit apparaître avant le nom de la commande, par exemple cargo -C path/to/my-project build.

Cette option n'est disponible que sur le canal nightly https://doc.rust-lang.org/book/appendix-07-nightly-rust.html et nécessite l'indicateur -Z unstable-options pour être activé (voir #10098 https://github.com/rust-lang/cargo/issues/10098).

-h, --help

Affiche l'aide.

-Z flag

Indicateurs instables (uniquement pour nightly) pour Cargo. Exécutez cargo -Z help pour les détails.

ENVIRONNEMENT

Voir la référence https://doc.rust-lang.org/cargo/reference/environment-variables.html pour les détails sur les variables d'environnement que Cargo lit.

STATUT DE SORTIE

•0 : Cargo a réussi.
•101 : Cargo n'a pas pu s'achever.

EXEMPLES

1. Rechercher un paquet depuis crates.io : 
cargo search serde
