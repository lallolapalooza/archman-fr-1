Le drapeau --locked peut être utilisé pour forcer Cargo à utiliser le fichier Cargo.lock empaqueté s'il est disponible. Cela peut être utile pour garantir des constructions reproductibles, afin d'utiliser exactement le même ensemble de dépendances qui étaient disponibles lorsque le paquet a été publié. Cela peut également être utile si une version plus récente d'une dépendance est publiée et ne se construit plus sur votre système, ou a d'autres problèmes. L'inconvénient de l'utilisation de --locked est que vous ne recevrez aucune correction ni mise à jour d'une dépendance. Notez que Cargo n'a pas commencé à publier les fichiers Cargo. lock avant la version 1.37, ce qui signifie que les paquets publiés avec des versions antérieures n'auront pas de fichier Cargo.lock disponible.
