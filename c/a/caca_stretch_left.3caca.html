__extern int caca_rotate_left (caca_canvas_t * cv)

Appliquer une transformation de 90 degrés à un canevas, en choisissant des caractères qui ressemblent à la version pivotée lorsque c'est possible. Les cellules de caractères sont pivotées deux par deux. Certains caractères resteront inchangés par le processus, d'autres seront remplacés par des équivalents proches. Les caractères de pleine largeur aux coordonnées horizontales impaires seront perdus. L'opération n'est pas garantie réversible.

Notez que la largeur du canevas est divisée par deux et devient la nouvelle hauteur. La hauteur est multipliée par deux et devient la nouvelle largeur. Si la largeur originale est un nombre impair, la division est arrondie vers le haut.

Si une erreur se produit, -1 est renvoyé et errno est défini en conséquence :

  • EBUSY Le canevas est en cours d'utilisation par un pilote d'affichage et ne peut pas être pivoté.
  • ENOMEM Pas assez de mémoire pour allouer la nouvelle taille du canevas. Si cela se produit, le descripteur de canevas précédent est toujours valide.

Paramètres

cv Le canevas à faire pivoter vers la gauche.

Renvoie

0 en cas de succès, -1 si une erreur s'est produite.

Références caca_add_dirty_rect().

NAME

caca_stretch_right

apply a 270-degree transformation to a canvas

SYNOPSIS

#include <caca.h>

__extern int caca_stretch_right (caca_canvas_t * cv)

Detailed Description

Apply a 270-degree transformation to a canvas, choosing characters that look like the rotated version wherever possible. Some characters will stay unchanged by the process, some others will be replaced by close equivalents. Fullwidth characters will be lost. The operation is not guaranteed to be reversible at all.

Note that the width and height of the canvas are swapped, causing its aspect ratio to look stretched.

If an error occurs, -1 is returned and errno is set accordingly:

  • EBUSY The canvas is in use by a display driver and cannot be rotated.
  • ENOMEM Not enough memory to allocate the new canvas size. If this happens, the previous canvas handle is still valid.

Function Documentation

caca_stretch_right

Parameters

cv The canvas to rotate right.

Returns

0 in case of success, -1 if an error occurred.
