__extern caca_dither_t * caca_create_dither (int bpp, int w, int h, int pitch, uint32_t rmask, uint32_t gmask, uint32_t bmask, uint32_t

amask)

Crée une structure de tramage à partir de ses coordonnées (profondeur, largeur, hauteur et pas) et des valeurs de masques de pixels. Si la profondeur est de 8 bits par pixel, les valeurs de masques sont ignorées et la palette de couleurs doit être définie à l'aide de la fonction caca_set_dither_palette(). Pour les profondeurs supérieures à 8 bits par pixel, un masque alpha nul provoque l'ignorance des valeurs

alpha.

Si une erreur se produit, NULL est renvoyé et errno est défini en conséquence

:
  • EINVAL La largeur, la hauteur, le pas ou la valeur de bits par pixel demandés étaient
    • invalides.
  • ENOMEM Mémoire insuffi
    • sante pour allouer la
structure de tramage.

Paramètre

s

w Largeur du bitmap en pixels.

pitch Pas du bitmap en octets.

gmask Masque binaire pour les valeurs de vert.
bmask Masque binaire pour les valeurs de bleu.

    • tramage.
  • 'ordered8' : utiliser une matrice de Bayer 8x8 pour le
    • tramage.

    • aléatoire.
