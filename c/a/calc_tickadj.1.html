calc_tickadj(1calc_tickadjman) Commandes utilisateur calc_tickadj(1calc_tickadjman)

NOM

calc_tickadj - Calcule la valeur optimale pour tick étant donné le fichier de dérive ntp.

SYNTAXE

calc_tickadj [-indicateurs] [-indicateur [valeur]] [--nom-option[[=| ]valeur]]

Tous les arguments doivent être des options.

DESCRIPTION

Le script calc_tickadj utilise le fichier de dérive ntp fourni pour générer la valeur de tick optimale. Généralement, ntpd peut faire un meilleur travail si la valeur de dérive est la plus petite possible.

L'exemple de sortie de 

$ ./calc_tickadj
81.699 (drift)
9999 usec; 9999779 nsec
$ cat /etc/ntp/drift
-23.159

signifie ce qui suit. Si le tick sur cette machine est 10 000, en mettant la valeur à 9999, nous décalerons la machine de sa dérive actuelle de -23.159 à une dérive de 81.699, et ce faisant, nous accélérerons un peu l'horloge chaque seconde au lieu de la ralentir.

Si le 'tick' sur cette machine est 10 000 000, alors en le réglant à 9999779, la valeur de dérive sera d'environ 0.0.

calc_tickadj essaie de déterminer la valeur de tick en utilisant le programme tickadj du paquet ntp. Si cela ne fonctionne pas, vous pouvez spécifier le tick actuel manuellement sur la ligne de commande.

OPTIONS

-d chaîne, --drift-file=chaîne

Fichier de dérive Ntp à utiliser. La chaîne par défaut pour cette option est :
/etc/ntp/drift

Utilise le fichier de dérive spécifié pour les calculs.

-t nombre, --tick=nombre

Valeur de tick de cet hôte. Cette option prend un nombre entier comme argument.

Le tick actuel pour lequel le réglage sera calculé.

-?, --help

Affiche les informations d'utilisation et quitte.
-!, --more-help

Transmet les informations d'utilisation étendues à un paginateur.
-v [{v|c|n --version [{v|c|n}]}]

Affiche la version du programme et quitte. Le mode par défaut est `v', une version simple. Le mode `c' affichera les informations de copyright et `n' affichera l'avis de copyright complet.
