EXEMPLES

1. Récupérer la spécification du paquet pour le paquet foo : 
cargo pkgid foo
2. Récupérer la spécification du paquet pour la version 1.0.0 de foo : 
cargo pkgid foo@1.0.0
3. Récupérer la spécification du paquet pour foo depuis crates.io : 
cargo pkgid https://github.com/rust-lang/crates.io-index#foo
4. Récupérer la spécification du paquet pour foo depuis un paquet local : 
cargo pkgid file:///path/to/local/package#foo
