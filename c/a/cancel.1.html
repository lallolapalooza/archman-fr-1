NOM

cancel - annuler des tâches

SYNTAXE

cancel [ -h nom_hote[:port] ] [ -E ] [ -U nom_utilisateur ] [ -a ] [ -u nom_utilisateur ] [ -x ] [ id ] [ destination ] [ id-destination ]

DESCRIPTION

La commande cancel annule des tâches d'impression. Si aucune destination ou id n'est spécifié, la tâche en cours d'impression sur la destination par défaut est annulée.

OPTIONS

Les options suivantes sont reconnues par cancel :

-a
Annule toutes les tâches sur la destination nommée, ou toutes les tâches sur toutes les destinations si aucune n'est fournie.
-E
Force le chiffrement lors de la connexion au serveur.
-h nom_hote[:port]
Spécifie un serveur alternatif. Note : cette option doit précéder toutes les autres.
-U nom_utilisateur
Spécifie le nom d'utilisateur à utiliser lors de la connexion au serveur.
-u nom_utilisateur
Annule les tâches appartenant à nom_utilisateur.
-x
Supprime les fichiers de données de tâche en plus de l'annulation.

CONFORMIT

Contrairement au système d'impression System V, CUPS permet aux noms d'imprimante de contenir n'importe quel caractère imprimable à l'exception de l'espace, de la tabulation, de "/" ou de "#". De plus, les noms d'imprimante et de classe ne sont pas sensibles à la casse.

EXEMPLES

Annuler la tâche d'impression en cours :

    cancel

Annuler la tâche « myprinter-42 » :

    cancel myprinter-42

Annuler toutes les tâches :

    cancel -a

NOTES

Les administrateurs souhaitant empêcher l'annulation non autorisée de tâches via l'option -u devraient exiger l'authentification pour les opérations Cancel-Jobs dans cupsd.conf(5).
