NOM

cache_repair - réparer les métadonnées binaires du cache d'un périphérique/fichier vers un périphérique/fichier.

SYNTAXE

cache_repair [options] -i {périphérique|fichier} -o {périphérique|fichier}

DESCRIPTION

cache_repair lit les métadonnées binaires du cache créées par la cible respective du device-mapper depuis un périphérique ou un fichier, les répare et les écrit vers un autre périphérique ou fichier. Si elles sont écrites sur un périphérique de métadonnées, les métadonnées peuvent être traitées par la cible du device-mapper.

Cet outil ne peut pas être exécuté sur des métadonnées actives.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche les informations de version et quitte.
-i, --input {périphérique|fichier}
Fichier ou périphérique d'entrée contenant les métadonnées binaires.
-o, --output {périphérique|fichier}
Fichier ou périphérique de sortie pour les métadonnées binaires réparées.
    Si c'est un fichier, il doit être pré-alloué et suffisamment grand pour contenir
    les métadonnées.

EXEMPLE

Lit les métadonnées binaires du cache depuis le fichier metadata, les répare et les écrit vers le volume logique /dev/vg/metadata pour un traitement ultérieur par la cible respective du device-mapper :

    $ cache_repair -i metadata -o /dev/vg/metadata

DIAGNOSTICS

cache_repair retourne un code de sortie de 0 en cas de succès ou 1 en cas d'erreur.

VOIR AUSSI

cache_dump(8), cache_check(8), cache_restore(8)
