__extern ssize_t caca_import_canvas_from_memory (caca_canvas_t * cv, void const * data, size_t len, char const * format)

Importe un tampon mémoire dans la trame actuelle du canevas libcaca donné. La trame actuelle est redimensionnée en conséquence et son contenu est remplacé par les données importées.

Les valeurs valides pour format sont :

  • '': tente de détecter automatiquement le format du fichier.
  • 'caca': importe les fichiers natifs libcaca.
  • 'text': importe les fichiers texte ASCII.
  • 'ansi': importe les fichiers ANSI.
  • 'utf8': importe les fichiers UTF-8 avec des codes couleur ANSI.
  • 'bin': importe les fichiers BIN.

Le nombre d'octets lus est retourné. Si le format de fichier est valide, mais qu'il n'y avait pas assez de données disponibles, 0 est retourné.

En cas d'erreur, -1 est retourné et errno est défini en conséquence :

  • ENOMEM Pas assez de mémoire pour allouer le canevas.
  • EOVERFLOW L'importation des données a provoqué un dépassement de valeur.
  • EINVAL Format demandé invalide.

Paramètres

cv Un canevas libcaca dans lequel importer le fichier.
data Une zone mémoire contenant les données à charger dans le canevas.
len La taille en octets de la zone mémoire.
format Une chaîne décrivant le format d'entrée.

Retourne

Le nombre d'octets lus, ou 0 s'il n'y avait pas assez de données, ou -1 si une erreur s'est produite.

Réfèrencé par caca_import_area_from_memory(), et caca_import_canvas_from_file().

  • '': tente de détecter automatiquement le format du fichier.

__extern void * caca_export_canvas_to_memory (caca_canvas_t const * cv, char const * format, size_t * bytes)

Cette fonction exporte une toile libcaca dans divers formats étrangers tels que l'art ANSI, le HTML, les couleurs IRC, etc. Le pointeur retourné doit être passé à free() pour libérer le stockage alloué lorsqu'il n'est plus nécessaire.

Les valeurs valides pour le format sont :

  • 'caca': exporte les fichiers natifs libcaca.
  • 'ansi': exporte l'art ANSI (jeu de caractères CP437 avec codes couleur ANSI).
  • 'html': exporte une page HTML avec des informations CSS.
  • 'html3': exporte un tableau HTML qui devrait être compatible avec la plupart des navigateurs, y compris ceux en mode texte.
  • 'irc': exporte du texte UTF-8 avec des codes couleur mIRC.
  • 'ps': exporte un document PostScript.
  • 'svg': exporte une image vectorielle SVG.
  • 'tga': exporte une image TGA.
  • 'troff': exporte une source troff.

Si une erreur se produit, NULL est retourné et errno est défini en conséquence :

  • EINVAL Format non supporté demandé.
  • ENOMEM Pas assez de mémoire pour allouer le tampon de sortie.

Paramètres

cv Une toile libcaca
format Une chaîne décrivant le format de sortie demandé.
bytes Un pointeur vers une taille_t où le nombre d'octets alloués sera écrit.

Retourne

Un pointeur vers la zone mémoire exportée, ou NULL en cas d'erreur.

Référencé par caca_export_area_to_memory().
