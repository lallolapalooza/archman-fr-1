NAME

cargo-doc - Génère la documentation pour les paquets Rust.

SYNOPSIS

cargo doc [OPTIONS] [-- RUSTFLAGS...]

DESCRIPTION

Génère la documentation pour le paquet actuel ou pour les dépendances du paquet actuel.

Par défaut, cargo doc génère la documentation pour le paquet actuel. Si l'option --all est spécifiée, la documentation sera générée pour tous les membres du workspace.

La documentation sera écrite dans le répertoire target/doc.

OPTIONS

  • --all : Génère la documentation pour tous les membres du workspace.
  • --no-deps : Ne génère pas la documentation pour les dépendances.
  • --open ou -o : Ouvre la documentation générée dans le navigateur web.
  • --document-private-items ou --doc-private : Documente les éléments privés.
  • --target TARGET : Génère la documentation pour un fichier cible spécifique.
  • --release : Génère la documentation pour une version optimisée.

ENVIRONMENT

  • RUSTFLAGS : Options supplémentaires passées au compilateur Rust.

EXIT STATUS

Renvoie 0 en cas de succès, une valeur non nulle en cas d'échec.

EXAMPLES

Générer la documentation pour le paquet actuel :

cargo doc

Générer la documentation pour tous les membres du workspace et ouvrir dans le navigateur :

cargo doc --all --open

Générer la documentation pour le paquet actuel sans inclure les dépendances :

cargo doc --no-deps
