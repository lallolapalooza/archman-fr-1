NOM

cas - statistiques c aMule

SYNTAXE

cas [-o] [-p] [-c <chemin>]

cas [-h]

DESCRIPTION

cas est un programme permettant d'afficher le contenu de votre fichier de signature en ligne aMule sur la console (sous une forme lisible). Pour que cela fonctionne, vous devez activer l'option "Signature en ligne" dans les préférences d'aMule.

[ -o, --picture, -P ]
Écrit l'image de la signature en ligne. Vous pouvez éventuellement ajouter =<CHEMIN> à cette option pour spécifier l'emplacement où elle doit être écrite.
[ -p, --html, -H ]
Page HTML avec les statistiques et l'image. Vous pouvez éventuellement ajouter =<CHEMIN> à cette option pour spécifier l'emplacement où elle doit être écrite.
[ -c <chemin>, --config-dir=<chemin> ]
Lit la configuration depuis <chemin> au lieu du répertoire personnel.
[ -h, --help ]
Imprime une brève description de l'utilisation.

Sans aucune option, il imprime les données de la signature en ligne sur la sortie standard.
