NOM

Canary::Stability - un canari pour vérifier la compatibilité perl des modules de schmorp

SYNTAXE

# dans Makefile.PL
use Canary::Stability DISTNAME => 2001, MINIMUM_PERL_VERSION;

DESCRIPTION

Ce module est utilisé par les modules de Schmorp lors de la phase de configuration pour tester la perl installée pour la compatibilité avec ses modules.

Il n'est pas, à ce stade, destiné à être un outil pour d'autres auteurs de modules, bien qu'en principe rien ne les empêche de souscrire aux mêmes idées.

Voir le Makefile.PL dans Coro ou AnyEvent pour des exemples d'utilisation.

VARIABLES D'ENVIRONNEMENT

"PERL_CANARY_STABILITY_NOPROMPT=1"
Ne pas interroger l'utilisateur sur les messages d'alerte.
"PERL_CANARY_STABILITY_COLOUR=0"
Désactiver l'utilisation des couleurs.
"PERL_CANARY_STABILITY_COLOUR=1"
Forcer l'utilisation des couleurs.
"PERL_CANARY_STABILITY_DISABLE=1"
Désactiver complètement la fonctionnalité de ce module.
"AUTOMATED_TESTING=1"
Lorsque cette variable est définie sur une valeur vraie et que la version minimale requise de perl n'est pas satisfaite, le module se terminera, ce qui devrait permettre de sauter les tests dans les environnements de test automatisés.

Ceci est fait pour éviter des rapports d'échec ou de succès erronés lorsque les chances de succès sont déjà faibles et que les échecs ne sont pas pris en charge par l'auteur.
