NOM

cxl-set-alert-config - définit le seuil d'alerte d'avertissement sur un memdev CXL

SYNOPSIS

cxl set-alert-config <mem0> [<mem1>..<memN>] [<options>]

DESCRIPTION

Le périphérique CXL déclenche une alerte lorsque son état de santé change. Une alerte critique sera automatiquement configurée par le périphérique après un redémarrage du périphérique. Si pris en charge, les seuils d'alerte d'avertissement programmables seront également initialisés aux valeurs par défaut recommandées par le fournisseur, puis pourront être configurés par l'utilisateur.

Utilisez cette commande pour configurer les seuils d'alerte d'avertissement d'un périphérique. Après avoir émis cette commande, les nouveaux seuils d'alerte d'avertissement demandés remplaceront les seuils d'alerte d'avertissement précédemment programmés.

Pour activer l'alerte d'avertissement, définissez à la fois threshold=valeur et alert=on. Pour désactiver l'alerte d'avertissement, définissez uniquement alert=off. D'autres cas entraîneront des erreurs.

Utilisez "cxl list -m <memdev> -A" pour examiner les capacités de seuil d'alerte d'avertissement programmable d'un périphérique.

OPTIONS

<mémoire(s) de périphérique(s)>

Un nom de périphérique memX, ou un numéro d'ID de memdev. Restreint l'opération aux memdev spécifiés. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction.

-S, --serial

Plutôt qu'un numéro d'ID de memdev, interpréter l'argument <memdev> comme une liste de numéros de série.

-L, --life-used-threshold=

Définit la <valeur> pour le seuil d'alerte d'avertissement de durée de vie utilisée.

--life-used-alert=

Active ou désactive l'alerte d'avertissement de durée de vie utilisée. Les options sont on ou off.

-O, --over-temperature-threshold=

Définit la <valeur> pour le seuil d'alerte d'avertissement de surchauffe du périphérique.

--over-temperature-alert=

Active ou désactive l'alerte d'avertissement de surchauffe du périphérique. Les options sont on ou off.

-U, --under-temperature-threshold=

Définit la <valeur> pour le seuil d'alerte d'avertissement de sous-température du périphérique.

--under-temperature-alert=

Active ou désactive l'alerte d'avertissement de sous-température du périphérique. Les options sont on ou off.

-V, --volatile-mem-err-threshold=

Définit la <valeur> pour le seuil d'alerte d'avertissement d'erreurs de mémoire volatile corrigées.

--volatile-mem-err-alert=

Active ou désactive l'alerte d'avertissement d'erreurs de mémoire volatile corrigées. Les options sont on ou off.

-P, --pmem-err-threshold=

Définit la <valeur> pour le seuil d'alerte d'avertissement d'erreurs de mémoire persistante corrigées.

--pmem-err-alert=

Active ou désactive l'alerte d'avertissement d'erreurs de mémoire persistante corrigées. Les options sont on ou off.

-v, --verbose

Active les messages de débogage détaillés dans la bibliothèque (si libcxl a été compilé avec la journalisation et le débogage activés).
