NOM

cxl-zero-labels - efface les étiquettes sur un ensemble de memdevs

SYNTAXE

cxl zero-labels <mem0> [<mem1>..<memN>] [<options>]

DESCRIPTION

La zone d'étiquettes de région est une petite partition persistante de capacité disponible sur certains périphériques mémoire CXL. La zone d'étiquettes est utilisée pour configurer ou déterminer l'ensemble des périphériques mémoire participant à différents ensembles d'entrelacement. Cette commande réinitialise le périphérique à son état par défaut en supprimant toutes les étiquettes.

OPTIONS

<périphérique(s) mémoire>

Un nom de périphérique memX, ou un numéro d'identifiant de memdev. Restreint l'opération aux memdev spécifiés. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction.

-S, --serial

Plutôt qu'un numéro d'identifiant de memdev, interprète l'argument <memdev> comme une liste de numéros de série.

-s, --size=

Limite l'opération au nombre d'octets donné. Une taille de 0 indique d'opérer sur toute la capacité d'étiquetage.

-O, --offset=

Commence l'opération au décalage donné dans la zone d'étiquettes.

-v

Active les messages de débogage verbeux dans la bibliothèque (si libcxl a été compilée avec la journalisation et le débogage activés).
