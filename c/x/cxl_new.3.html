CXL_NEW(3) Manuel libcxl CXL_NEW(3)

NOM

cxl_new - Créer un nouvel objet de contexte de bibliothèque qui sert de point d'accès pour toutes les opérations de la bibliothèque

SYNTAXE

#include <cxl/libcxl.h>
int cxl_new(struct cxl_ctx **ctx);

DESCRIPTION

Instancie un nouveau contexte de bibliothèque et stocke un pointeur opaque dans ctx. Le contexte est libéré par linklibcxl:cxl_unref[3], c'est-à-dire que cxl_new(3) implique un linklibcxl:cxl_ref[3] interne.

VALEUR DE RETOUR

Retourne 0 en cas de succès, et un errno négatif en cas d'échec. Les codes d'erreur possibles sont :

•-ENOMEM
•-ENXIO

EXEMPLE

Voir l'exemple d'utilisation dans test/libcxl.c
