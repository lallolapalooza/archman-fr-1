CXPM(1) Manuel des commandes générales CXPM(1)

NOM

cxpm - Vérifie un fichier XPM (X PixMap), versions XPM 1, 2 ou 3.

SYNTAXE

cxpm [nom_fichier]

DESCRIPTION

Le programme cxpm peut être utilisé pour vérifier le format de tout fichier XPM (version 1, 2 ou 3). En cas d'erreur, contrairement à sxpm, cxpm affiche un message d'erreur indiquant où l'analyseur a échoué. Cela devrait aider à identifier ce qui ne va pas dans un fichier XPM, mais ne vous attendez pas à trop non plus. Ce n'est pas du tout un programme de type lint pour XPM. Premièrement, il s'arrête à la première erreur rencontrée - ainsi plusieurs cycles de correction et de réessai peuvent être nécessaires pour que votre fichier soit analysé avec succès. Deuxièmement, cxpm ne se soucie que du format. Si, par exemple, votre pixmap utilise trop de couleurs pour votre système, vous pourriez encore rencontrer des difficultés à l'afficher. Soyez averti.

Lorsqu'aucun nom_fichier n'est donné, cxpm lit depuis l'entrée standard.
