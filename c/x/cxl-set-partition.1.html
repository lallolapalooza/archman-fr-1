NOM

cxl-set-partition - définit le partitionnement entre capacité volatile et persistante sur un périphérique CXL

SYNOPSIS

cxl set-partition <mem0> [ [<mem1>..<memN>] [<options>]

DESCRIPTION

Les périphériques CXL peuvent prendre en charge la mémoire volatile et persistante. La quantité de capacité du périphérique réservée à chaque type est généralement établie en usine, mais certains périphériques permettent également un re-partitionnement dynamique.

Utilisez cette commande pour partitionner un périphérique en capacité volatile et persistante. Le changement de partitionnement devient la configuration « suivante », qui sera active lors du prochain réinitialisation du périphérique.

Utilisez « cxl list -m <memdev> -I » pour examiner les capacités de partitionnement d'un périphérique. Une valeur de partition_alignment_size égale à zéro signifie qu'il n'y a pas de capacité disponible et donc que les partitions ne peuvent pas être modifiées.

L'utilisation de cette commande pour modifier la taille de la capacité persistante entraînera la perte des données stockées.

OPTIONS

<périphérique(s) mémoire>

Un nom de périphérique memX, ou un numéro d'ID de périphérique mémoire. Restreint l'opération aux périphériques mémoire spécifiés. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction.

-S, --serial

Plutôt qu'un numéro d'ID de périphérique mémoire, interprète les arguments <memdev> comme une liste de numéros de série.

-b, --bus=

Restreint l'opération au bus spécifié.

-t, --type=

Type de partition, pmem ou ram (volatile), à modifier. Par défaut : pmem

-s, --size=

Taille de la partition <type> en octets. La taille doit être alignée sur l'exigence d'alignement du périphérique. Utilisez cxl list -m <memdev> -I pour trouver partition_alignment_size, ou utilisez l'option --align. Par défaut : toute la capacité disponible est attribuée à <type>.

-a, --align

Sélectionnez cette option pour permettre l'alignement automatique de --size afin de répondre aux exigences d'alignement du périphérique. Lorsque vous utilisez cette option, spécifiez la taille minimale --size de la partition --type requise. Lorsque cette option est omise, la commande échoue si --size n'est pas correctement alignée. Utilisez cxl list -m <memdev> -I pour examiner la partition_alignment_size.

-v

Active les messages de débogage verbeux dans la bibliothèque (si libcxl a été compilé avec la journalisation et le débogage activés).
