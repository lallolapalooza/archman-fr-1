DESCRIPTIO

N

L'utilitaire cxref doit analyser une collection de fichiers en langage C et tenter de construire une table de référence croisée. Les informations provenant des lignes #define doivent être incluses dans la table des symboles. Une liste triée doit être écrite sur la sortie standard de tous les symboles (auto, statiques et globaux) dans chaque fichier séparément, ou, avec l'option -c, en combinaison. STDOU

T

La sortie standard doit être utilisée pour la liste de référence croisée, sauf si l'option -o est utilisée pour sélectionner un fichier de sortie

différent.

Le format de la sortie standard n'est pas spécifié, sauf que les informations suivantes doivent être incluses

:
*
Si l'option -c n'est pas spécifiée, chaque partie de la liste doit commencer par le nom du fichier d'entrée sur une ligne
séparée.
*
La ligne de nom doit être suivie d'une liste triée de symboles, chacun avec son chemin d'accès de localisation associé, le nom de la fonction dans laquelle il apparaît (s'il ne s'agit pas d'un nom de fonction lui-même), et des références de numéros de
ligne.
*
Chaque numéro de ligne peut être précédé d'un drapeau <astérisque> ('*'), signifiant qu'il s'agit de la référence de déclaration. D'autre
s drapeaux d'un seul caractère,
