Nom

ctags-lang-markdown - Notes diverses sur le marquage de code source Markdown avec Universal Ctags

SYNTAXE

ctags ... --languages=+Markdown ...
ctags ... --language-force=Markdown ...
ctags ... --map-Markdown=+.md ...

DESCRIPTION

Cette page de manuel rassemble des notes diverses sur le marquage de documents Markdown [XSYNTAX].
