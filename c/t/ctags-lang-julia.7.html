Pourquoi X1 et X2 ont-ils le rôle « namespace », alors que X3 a le rôle « imported » ? C'est parce que le symbole a dans le module X1, et b dans le module X2 sont amenés dans la portée courante, mais X1 et X2 eux-mêmes ne le sont pas. Nous utilisons le rôle « namespace » pour de tels

modules.

X3 est différent. Le symbole X3, ainsi que tous les symboles exportés dans X3, est amené dans la portée courante. Pour de tels modules, nous utilisons le rôle « imported » ou « used » selon qu'ils sont chargés par import ou using

.
