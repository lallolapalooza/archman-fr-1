CTRLALTDEL(8) Administration système CTRLALTDEL(8)

NOM

ctrlaltdel - définit la fonction de la combinaison Ctrl-Alt-Suppr

SYNTAXE

ctrlaltdel hard|soft

DESCRIPTION

D'après l'examen du code linux/kernel/reboot.c, il est clair que la séquence <Ctrl-Alt-Suppr> peut effectuer deux fonctions.

hard

Redémarre immédiatement l'ordinateur sans appeler sync(2) et sans aucune autre préparation. C'est le comportement par défaut.

soft

Fait en sorte que le noyau envoie le signal SIGINT (interruption) au processus init (c'est toujours le processus avec PID 1). Si cette option est utilisée, le programme init(8) doit prendre en charge cette fonctionnalité. Comme il existe maintenant plusieurs programmes init(8) dans la communauté Linux, veuillez consulter la documentation de la version que vous utilisez actuellement.

Lorsque la commande est exécutée sans argument, elle affiche le paramètre actuel.

La fonction de ctrlaltdel est généralement définie dans le fichier /etc/rc.local.

OPTIONS

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

FICHIERS

/etc/rc.local
