Nom

ctags-lang-javascript - Notes diverses sur l'indexation du code source JavaScript avec Universal Ctags

SYNOPSIS

ctags ... --languages=+JavaScript ...
ctags ... --language-force=JavaScript ...
ctags ... --map-JavaScript=+.js ...

DESCRIPTION

Cette page de manuel rassemble des notes diverses sur l'indexation du code source JavaScript.

CLASSES

ES6 a introduit le mot-clé class, mais il existe toujours la méthode originale consistant à définir une fonction et à y attacher un prototype. ctags suit la convention selon laquelle les noms de fonctions commençant par une lettre majuscule sont des constructeurs de classe.

Changement depuis "0.0"

Nouveau rôle foreigndecl pour le type function
