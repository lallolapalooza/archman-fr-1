sous-routine ctpqrt (integer m, integer n, integer l, integer nb, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( * ) work, integer info)

CTPQRT

But :

!>
!> CTPQRT calcule une factorisation QR bloquée d'une matrice complexe
!>  C, qui est composée d'un bloc triangulaire A et d'un bloc pentagonal B,
!>  en utilisant la représentation WY compacte pour Q.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice B.
!>          M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice B, et l'ordre de la
!>          matrice triangulaire A.
!>          N >= 0.
!>

L

!>          L est un entier (INTEGER)
!>          Le nombre de lignes de la partie trapézoïdale supérieure de B.
!>          MIN(M,N) >= L >= 0. Voir Détails supplémentaires.
!>

NB

!>          NB est un entier (INTEGER)
!>          La taille de bloc à utiliser pour la QR bloquée.  N >= NB >= 1.
!>

A

!>          A est un tableau de type COMPLEX, de dimension (LDA,N)
!>          À l'entrée, la matrice triangulaire supérieure A de N x N.
!>          À la sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice triangulaire supérieure R.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau de type COMPLEX, de dimension (LDB,N)
!>          À l'entrée, la matrice pentagonale B de M x N. Les M-L premières lignes
!>          sont rectangulaires, et les L dernières lignes sont trapézoïdales supérieures.
!>          À la sortie, B contient la matrice pentagonale V. Voir Détails supplémentaires.
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>

T

!>          T est un tableau de type COMPLEX, de dimension (LDT,N)
!>          Les réflecteurs de bloc triangulaires supérieurs stockés sous forme compacte
!>          sous forme d'une séquence de blocs triangulaires supérieurs. Voir Détails supplémentaires.
!>

LDT

!>          LDT est un entier (INTEGER)
!>          La dimension principale du tableau T.  LDT >= NB.
!>

WORK

!>          WORK est un tableau de type COMPLEX, de dimension (NB*N)
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0:  succès de l'exécution
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  La matrice d'entrée C est une matrice de (N+M) x N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!>  où A est une matrice triangulaire supérieure N x N, et B est une matrice
!>  pentagonale M x N composée d'une matrice rectangulaire (M-L) x N, B1, en haut
!>  d'une matrice trapézoïdale supérieure L x N, B2 :
!>
!>               B = [ B1 ]  <- (M-L) x N rectangulaire
!>                   [ B2 ]  <-     L x N trapézoïdale supérieure.
!>
!>  La matrice trapézoïdale supérieure B2 est composée des L premières lignes d'une
!>  matrice triangulaire supérieure N x N, où 0 <= L <= MIN(M,N).  Si L=0,
!>  B est rectangulaire M x N ; si M=L=N, B est triangulaire supérieure.
!>
!>  La matrice W stocke les réflecteurs élémentaires H(i) dans la i-ème colonne
!>  sous la diagonale (de A) dans la matrice d'entrée C de (N+M) x N
!>
!>               C = [ A ]  <- N x N triangulaire supérieure
!>                   [ B ]  <- M x N pentagonale
!>
!>  de sorte que W puisse être représentée comme
!>
!>               W = [ I ]  <- identité, N x N
!>                   [ V ]  <- M x N, même forme que B.
!>
!>  Ainsi, toutes les informations nécessaires pour W sont contenues à la sortie dans B,
!>  que nous appelons V ci-dessus. Notez que V a la même forme que B ; c'est-à-dire,
!>
!>               V = [ V1 ] <- (M-L) x N rectangulaire
!>                   [ V2 ] <-     L x N trapézoïdale supérieure.
!>
!>  Les colonnes de V représentent les vecteurs qui définissent les H(i).
!>
!>  Le nombre de blocs est B = ceiling(N/NB), où chaque
!>  bloc est de taille NB sauf le dernier bloc, qui est de taille
!>  IB = N - (B-1)*NB. Pour chacun des B blocs, un facteur de réflecteur
!>  de bloc triangulaire supérieur est calculé : T1, T2, ..., TB. Les T de taille
!>  NB x NB (et IB x IB pour le dernier bloc) sont stockés dans la matrice T
!>  de NB x N comme
!>
!>               T = [T1 T2 ... TB].
!>
