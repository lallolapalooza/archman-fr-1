NOM

ctan-o-mat - Valider et téléverser un paquet pour CTAN

SYNTAXE

ctan-o-mat [options] [<configuration du paquet>]

DESCRIPTION

Ce programme peut être utilisé pour automatiser le téléversement d'un paquet sur le Comprehensive TeX Archive Network (https://www.ctan.org). La description du paquet est extraite d'un fichier de configuration. Ainsi, il peut être mis à jour facilement sans avoir à remplir un formulaire Web avec les mêmes vieilles informations encore et encore.

Les informations fournies sont validées dans tous les cas. Si la validation réussit et que seule la validation est demandée, alors l'archive fournie est placée dans la zone d'arrivée de CTAN pour un traitement ultérieur par l'équipe CTAN.

Dans tous les cas, toute découverte lors de la validation est rapportée à la fin du traitement. Notez que la validation est la valeur par défaut et qu'une soumission officielle doit être demandée par une option de ligne de commande appropriée.

ctan-o-mat nécessite une connexion Internet au serveur CTAN. Même la validation récupère les attributs connus et les contraintes de base du serveur.

CONFIGURATION

La configuration par défaut est lue à partir d'un fichier portant le même nom que le répertoire courant et l'extension .pkg. Ce nom de fichier peut être écrasé sur la ligne de commande.

La configuration dépend des fonctionnalités actuellement prises en charge par le serveur CTAN. Comme ces fonctionnalités peuvent changer avec le temps, la configuration n'est pas codée en dur dans ctan-o-mat. Vous pouvez demander un modèle vide de la configuration via le paramètre de ligne de commande "--init".

OPTIONS

-h
--help
Affiche ce court résumé de l'utilisation et quitte le programme.
-i
--init
Crée un modèle vide pour une configuration.
--list licenses
Liste les licences connues de CTAN sur le flux de sortie standard. Chaque licence est représentée sur une ligne. La ligne contient les champs clé, nom, indicateur de gratuité. Ces champs sont séparés par des tabulations. Ensuite, le programme se termine sans traiter d'autres arguments.
--config <configuration du paquet>
--pkg <configuration du paquet>
--package <configuration du paquet>
Définit le fichier de configuration du paquet.
-s
--submit
Téléverse la soumission, la valide et la soumet officiellement à CTAN si la validation réussit.
-v
--verbose
Affiche plus d'informations pendant le traitement (mode verbeux).
--version
Affiche le numéro de version de ce programme et quitte.
--validate
-n
--noaction
N'effectue pas le téléversement final. Le paquet est validé et les messages résultants sont affichés.
<paquet>
Ce paramètre est le nom d'une configuration de paquet (voir section CONFIGURATION) contenue dans un fichier. S'il n'est pas défini autrement, la configuration du paquet prend par défaut le nom du répertoire courant avec ".pkg" ajouté.

ENVIRONNEMENT

Les variables d'environnement suivantes sont reconnues par ctan-o-mat.

CTAN_O_MAT_URL
La valeur est le préfixe de l'URL du serveur CTAN à contacter. La valeur par défaut est "https://ctan.org/submit". L'URL complète est construite en ajoutant "validate", "upload", ou "fields" pour utiliser les API REST CTAN respectives.

CONNEXION VIA PROXIES

Si vous avez besoin de vous connecter à Internet via un proxy, cela peut être réalisé en définissant certaines variables d'environnement avant d'exécuter ctan-o-mat. Pour rediriger la requête via le proxy, définissez simplement une variable d'environnement "http_proxy" pour pointer vers l'hôte proxy -- y compris le protocole et le port si nécessaire. Notez que le nom de la variable d'environnement est censé être en **minuscules**.
