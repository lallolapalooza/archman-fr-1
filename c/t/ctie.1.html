CTIE(1) Manuel des commandes générales CTIE(1)

NOM

ctie - fusionne ou applique des fichiers de modification CWEB

SYNTAXE

ctie -c|-m fichierSortie fichierMaître fichierModification...

DESCRIPTION

Le programme ctie est utilisé pour traiter plusieurs fichiers de modification utilisés avec le système CWEB pour la programmation lettrée. Les programmes CWEB permettent d'appliquer des correctifs à un fichier source (le fichierMaître) au moyen d'un seul fichier de modification. ctie peut être utilisé pour soit fusionner jusqu'à 32 fichiers de modification en un seul, soit pour appliquer les modifications au fichierMaître afin de créer un nouveau fichier maître. La sortie du nouveau fichier de modification ou du fichier maître corrigé va dans fichierSortie. Tous les fichiers inclus (indiqués à l'aide de la commande CWEB @i) sont entièrement développés pendant le traitement par ctie, ce qui signifie que les fichiers de modification peuvent modifier le contenu de tous les fichiers inclus.

OPTIONS

-c
Crée un seul fichier de modification à partir des fichiersModification donnés.
-m
Crée un nouveau fichier maître en appliquant les fichiersModification donnés.

ENVIRONNEMENT

La variable d'environnement CWEBINPUTS est utilisée pour rechercher les fichiers d'entrée, ou la valeur par défaut du système si CWEBINPUTS n'est pas définie. Voir tex(1) pour les détails de la recherche. Pour éviter les conflits avec d'autres programmes qui utilisent également l'environnement CWEBINPUTS, vous pouvez être plus spécifique et utiliser CWEBINPUTS_ctie pour des exigences spécifiques dans CTIE.
