Nom

ctags-lang-ldscript - Notes diverses sur le marquage du code source LdScript avec Universal Ctags

Syntaxe

ctags ... --languages=+LdScript ...
ctags ... --language-force=LdScript ...
ctags ... --map-LdScript=+.lds ...
ctags ... --map-LdScript=+.lds.S ...

Description

Cette page de manuel rassemble des notes diverses sur le marquage du code source LdScript.
