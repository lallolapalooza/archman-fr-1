CTGSJ

A

But

: 
!>
!> CTGSJA calcule la décomposition en valeurs singulières généralisée (GSVD)
!> de deux matrices triangulaires supérieures (ou trapézoïdales) complexes A et B.
!>
!> À l'entrée, on suppose que les matrices A et B ont les formes
!> suivantes, qui peuvent être obtenues par la sous-routine de prétraitement CGGSVP
!> à partir d'une matrice A de dimensions M×N et d'une matrice B de dimensions P×N :
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> où la matrice A12 de dimensions K×K et la matrice B13 de dimensions L×L sont non singulières
!> et triangulaires supérieures ; A23 est triangulaire supérieure de dimensions L×L si M-K-L >= 0,
!> sinon A23 est trapézoïdale supérieure de dimensions (M-K)×L.
!>
!> À la sortie :
!>
!>        U**H *A*Q = D1*( 0 R ),    V**H *B*Q = D2*( 0 R ),
!>
!> où U, V et Q sont des matrices unitaires.
!> R est une matrice triangulaire supérieure non singulière, et D1
!> et D2 sont des matrices « diagonales », qui ont les structures
!> suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                    K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stockée dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> où
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) est stockée dans A(1:M, N-K-L+1:N) et R33 est stockée
!>     (  0  R22 R23 )
!> dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> Le calcul des matrices de transformation unitaires U, V ou Q
!> est facultatif. Ces matrices peuvent soit être formées explicitement, soit
!> être multipliées à droite par les matrices d'entrée U1, V1 ou Q1.
!
>

Paramètre

!>          = 'U' :  U doit contenir une matrice unitaire U1 à l'entrée, et

!>          = 'I' :  U est initialisée à la matrice identité, et la

!>                  le produit V1*V est renvoyé ;
!>          = 'I' :  V est initialisée à la matrice identité, et la
!>                  matrice unitaire V est renvoyée ;
!>          = 'N' :  V n'est pas calculée.
!
>

JOB

Q 
!>          JOBQ est de type CHARACTER*1
!>          = 'Q' :  Q doit contenir une matrice unitaire Q1 à l'entrée, et
!>                  le produit Q1*Q est renvoyé ;
!>          = 'I' :  Q est initialisée à la matrice identité, et la
!>                  matrice unitaire Q est renvoyée ;
!>          = 'N' :  Q n'est pas calculée.
!
>

M 
!>          M est de type INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!
>

P 
!>          P est de type INTEGER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!
>

N 
!>          N est de type INTEGER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!
>

K 
!>          K est de type INTEGER
!
>

L 
!>          L est de type INTEGER
!>
!>          K et L spécifient les sous-blocs dans les matrices d'entrée A et B :
!>          A23 = A(K+1:MIN(K+L,M),N-L+1:N) et B13 = B(1:L,,N-L+1:N)
!>          de A et B, dont la GSVD va être calculée par CTGSJA.
!>          Voir Détails supplémentaires.
!
>

A 
!>          A est un tableau COMPLEX, de dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M×N.
!>          À la sortie, A(N-K+1:N,1:MIN(K+L,M) ) contient la matrice
!>          triangulaire R ou une partie de R.  Voir But pour plus de détails.
!
>

A

>

B

>

B

>

!>          TOLB est de type REAL
!>
!>          TOLA et TOLB sont les critères de convergence pour la procédure
!>          d'itération de Jacobi-Kogbetliantz. Généralement, ils sont les
!>          mêmes que ceux utilisés dans l'étape de prétraitement, par exemple
!>              TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>              TOLB = MAX(P,N)*norm(B)*MACHEPS.
!
>

ALPH

A 
!>          ALPHA est un tableau REAL, de dimension (N)
!
>

BET

A 
!>          BETA est un tableau REAL, de dimension (N)
!>
!>          À la sortie, ALPHA et BETA contiennent les paires de valeurs
!>          singulières généralisées de A et B ;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          et si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = diag(C),
!>            BETA(K+1:K+L)  = diag(S),
!>          ou si M-K-L < 0,
!>            ALPHA(K+1:M)= C, ALPHA(M+1:K+L)= 0
!>            BETA(K+1:M) = S, BETA(M+1:K+L) = 1.
!>          De plus, si K+L < N,
!>            ALPHA(K+L+1:N) = 0
!>            BETA(K+L+1:N)  = 0.
!
>

U 
!>          U est un tableau COMPLEX, de dimension (LDU,M)
!>          À l'entrée, si JOBU = 'U', U doit contenir une matrice U1 (généralement
!>          la matrice unitaire renvoyée par CGGSVP).
!>          À la sortie,
!>          si JOBU = 'I', U contient la matrice unitaire U ;
!>          si JOBU = 'U', U contient le produit U1*U.
!>          Si JOBU = 'N', U n'est pas référencée.
!
>

U

!>          la matrice unitaire retournée par CGGSVP).
!>          À la sortie,
!>          si JOBV = 'I', V contient la matrice unitaire V ;
!>          si JOBV = 'V', V contient le produit V1*V.
!>          Si JOBV = 'N', V n'est pas référencé.

Détails supplémentaires

: 
!>
!>  CTGSJA utilise essentiellement une variante de l'algorithme de Kogbetliantz pour réduire
!>  la matrice A23 triangulaire (ou trapézoïdale) min(L,M-K)-par-L et la matrice B13
!>  L-par-L à la forme :
!>
!>           U1**H *A13*Q1 = C1*R1; V1**H *B13*Q1 = S1*R1,
!>
!>  où U1, V1 et Q1 sont des matrices unitaires.
!>  C1 et S1 sont des matrices diagonales satisfaisant
!>
!>                C1**2 + S1**2 = I,
!>
!>  et R1 est une matrice triangulaire supérieure non singulière L-par-L.
!
>
