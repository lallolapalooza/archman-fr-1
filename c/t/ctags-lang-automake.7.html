Nom

ctags-lang-automake - Notes diverses sur le marquage du code source Automake (Makefile.am) avec Universal Ctags

Syntaxe

ctags ... --language-force=Automake ...
ctags ... --map-Automake=+.am ...

Description

Cette page de manuel rassemble des notes diverses sur le marquage du code source Automake (Makefile.am).
