Nom

ctags-lang-rmarkdown - Notes diverses sur l'étiquetage du code source R Markdown avec Universal Ctags

SYNTAXE

ctags ...--extras=+{subparser}{guest} --languages=+RMarkdown ...
ctags ...--extras=+{subparser}{guest} --language-force=RMarkdown ...
ctags ...--extras=+{subparser}{guest} --map-RMarkdown=+.rmd ...

DESCRIPTION

Le parseur RMarkdown est un sous-parseur exclusif empilé sur le parseur Markdown. Il fonctionne lorsque :

  • le parseur Markdown est activé,
  • l'option subparser est activée, et
  • le parseur RMarkdown lui-même est activé.

Le parseur RMarkdown étend la manière de détecter les blocs de code à partir du parseur Markdown. Cette extension sert à exécuter des parseurs invités sur les morceaux de code.

Le parseur Markdown s'attend à ce que la syntaxe suivante représente les blocs de code :

```nom-du-langage
        ...
```

Par exemple :

```r
        ...
```

Le parseur RMarkdown accepte la syntaxe suivante pour les morceaux de code :

```{nom-du-langage nom-du-morceau, ...}
        ...
```

Par exemple :

```{r precalc fig.height=4}
        ...
```

Donnez l'option --extras=+{guest} pour activer le parseur invité sur la ligne de commande si vous souhaitez exécuter les parseurs appropriés sur les lignes à l'intérieur des morceaux de code.

Le parseur extrait les étiquettes de morceau qui suivent nom-du-langage en tant qu'objets de type chunklabel. Dans l'exemple, le parseur RMarkdown extrait precalc en tant qu'objet de type chunklabel. Le type chunklabel est activé par défaut.

EXEMPLES

"input.rmd"

# Section 1
```{r mon_morceau}
        zero_fun <- function () {
                return 0
        }
```
# Section 2

"output.tags" avec "--options=NONE --extras=+{guest} --fields=+KZln -o - input.rmd"

Section 1       input.rmd       /^# Section 1$/;"       chapter line:1  language:Markdown
Section 2       input.rmd       /^# Section 2$/;"       chapter line:9  language:Markdown
mon_morceau input.rmd       /^```{r mon_morceau}$/;"    chunklabel      line:3  language:RMarkdown
zero_fun        input.rmd       /^      zero_fun <- function () {$/;"   function        line:4  language:R
