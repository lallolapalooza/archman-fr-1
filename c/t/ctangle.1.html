CWEB(1) Manuel des commandes générales CWEB(1)

NOM

ctangle, cweave - traduire CWEB en C/C++ et/ou TeX

SYNTAXE

ctangle [options] fichier web[.w] [{fichier de changement[.ch]|-} [fichier de sortie[.c]]]

cweave [options] fichier web[.w] [{fichier de changement[.ch]|-} [fichier de sortie[.tex]]]

DESCRIPTION

Le programme ctangle convertit un document source CWEB en un programme C/C++ qui peut être compilé de la manière habituelle. Le fichier de sortie inclut des spécifications #line afin que le débogage puisse être effectué en référence au fichier source CWEB.

Le programme cweave convertit le même fichier CWEB en un fichier TeX qui peut être formaté et imprimé de la manière habituelle. Il prend en charge les détails typographiques tels que la mise en page des pages et l'utilisation d'indentations, d'*italiques*, de **gras**, etc., et il fournit des informations complètes d'index croisé qu'il collecte automatiquement.

CWEB vous permet de préparer un document unique contenant toutes les informations nécessaires à la fois pour produire un programme C/C++ compilable et pour produire un document bien formaté décrivant le programme avec autant de détails que le rédacteur peut le souhaiter. L'utilisateur de CWEB doit être familier avec TeX ainsi qu'avec C/C++.

UTILISATION

La ligne de commande doit comporter un, deux ou trois noms. Le premier est considéré comme le fichier d'entrée CWEB (et .w est ajouté s'il n'y a pas d'extension). S'il y a un second nom, il s'agit d'un fichier de changement (et .ch est ajouté s'il n'y a pas d'extension). Le fichier de changement remplace des parties du fichier CWEB, comme décrit dans la documentation. S'il y a un troisième nom, il remplace le nom par défaut du fichier de sortie, qui est ordinairement le même que le nom du fichier d'entrée (mais dans le répertoire courant) avec l'extension .tex. Si vous voulez simplement changer le nom du fichier de sortie, mais que vous n'avez pas de fichier de changement à appliquer, vous pouvez utiliser `-' comme deuxième argument.

DIFFÉRENCES PAR RAPPORT AU CWEB ORIGINAL

CWEBbin essaie d'être un remplacement transparent pour CWEB, donc en général, vous ne devriez pas remarquer de différences dans l'invocation des programmes ni dans la sortie résultante. Il y a cependant quelques différences qui méritent d'être notées :

•
Les options --help, --quiet, --verbose, --version, et les drapeaux +c, -i, -o, +u, et +lX sont nouveaux dans CWEBbin et TeX Live.
•
L'option +lX est accompagnée de plusieurs fichiers d'enveloppement pour cwebmac.tex avec des légendes traduites pour l'allemand (+ld), le français (+lf) et l'italien (+li).
•
CWEB dans TeX Live fonctionne silencieusement par défaut (depuis 2019) ; utilisez l'option --verbose pour obtenir le comportement original.
•
La recherche de fichiers avec la variable d'environnement CWEBINPUTS est étendue pour permettre plusieurs chemins séparés par des deux-points ; voir ENVIRONNEMENT ci-dessous.
•
Si correctement configurés, les programmes principaux ctangle et cweave sont localisés avec les « utilitaires GNU gettext ».

OPTIONS

Les options sur la ligne de commande peuvent être désactivées avec `-' (si elles sont activées par défaut) ou activées avec `+' (si elles sont désactivées par défaut). En fait, les options sont traitées de gauche à droite, donc une séquence comme --verbose -h ne montrera que la ligne de bannière (+b) et le rapport de progression (+p), mais omettra le message de succès (-h).

Le premier lot d'options est commun à ctangle et cweave :

•
+b : affiche la ligne de bannière sur le terminal
•
+h : affiche un message de succès à l'achèvement
•
+p : affiche des messages de rapport de progression
•
+q/-q : raccourci pour -bhp ; aussi --quiet (par défaut)
•
+v/-v : raccourci pour +bhp ; aussi --verbose
•
+c : vérifie les changements dans la sortie temporaire
•
+s : affiche les statistiques d'utilisation
•
--help : affiche le message d'aide et quitte
•
--version : affiche les informations de version et quitte

Il y a une autre option applicable uniquement à ctangle :

•
+k : conserve les séparateurs dans les littéraux numériques dans la sortie
•
+u : translittère les caractères UTF-8 dans le code C

Il existe sept autres options applicables uniquement à cweave :

•
-e : n'enveloppe pas le matériel C/C++ dans \PB{...}
•
-f : ne force pas un saut de ligne après chaque instruction C/C++ dans la sortie
•
-i : supprime l'indentation des déclarations de paramètres
•
-o : supprime la séparation des déclarations et des instructions
•
-x : omet les index, les noms de section, la table des matières
•
+lX/-lX : utilise les macros pour la langue X comme de Xcwebmac.tex
•
+t : traite typename dans un modèle comme typedef

ENVIRONNEMENT

La variable d'environnement CWEBINPUTS est utilisée pour rechercher les fichiers d'entrée, ou le défaut du système si CWEBINPUTS n'est pas définie. Voir tex(1) pour les détails de la recherche. Pour éviter les conflits avec d'autres programmes qui utilisent également l'environnement CWEBINPUTS, vous pouvez être plus spécifique et utiliser CWEBINPUTS_cweb pour des exigences spéciales dans CWEB.

Si préparé pour le support NLS, ctangle et cweave utilisent la variable d'environnement TEXMFLOCALEDIR pour configurer le répertoire parent où les « utilitaires GNU gettext » recherchent les catalogues de traduction.

Ces variables sont préconfigurées dans texmf.cnf de TeX Live.

FICHIERS

L'emplacement des fichiers mentionnés ci-dessous varie d'un système à l'autre. Utilisez l'utilitaire kpsewhich pour trouver leurs emplacements.

•
cwebmac.tex : Les macros TeX par défaut \input dans la première ligne du fichier de sortie cweave.
•
cwebman.tex : Le manuel utilisateur de CWEB, disponible en PDF depuis CTAN (https://ctan.org/pkg/cweb).
