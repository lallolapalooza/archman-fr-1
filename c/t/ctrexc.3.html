Documentation de la fonction/sous-routine

sous-routine ctrexc (caractère compq, entier n, complexe, dimension( ldt, * ) t, entier ldt, complexe, dimension( ldq, * ) q, entier ldq, entier ifst, entier ilst, entier info)

CTREXC

Objectif :

!>
!> CTREXC réorganise la factorisation de Schur d'une matrice complexe
!> A = Q*T*Q**H, de sorte que l'élément diagonal de T avec l'indice de ligne IFST
!> soit déplacé à la ligne ILST.
!>
!> La forme de Schur T est réorganisée par une transformation unitaire de similarité
!> Z**H*T*Z, et éventuellement la matrice Q des vecteurs de Schur est mise à jour par
!> post-multiplication avec Z.
!>

Paramètres

COMPQ 
!>          COMPQ est CHARACTER*1
!>          = 'V':  met à jour la matrice Q des vecteurs de Schur ;
!>          = 'N':  ne met pas à jour Q.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice T. N >= 0.
!>          Si N == 0, les arguments ILST et IFST peuvent avoir n'importe quelle valeur.
!>

T

!>          T est un tableau COMPLEX, dimension (LDT,N)
!>          À l'entrée, la matrice triangulaire supérieure T.
!>          À la sortie, la matrice triangulaire supérieure réorganisée.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

Q

!>          Q est un tableau COMPLEX, dimension (LDQ,N)
!>          À l'entrée, si COMPQ = 'V', la matrice Q des vecteurs de Schur.
!>          À la sortie, si COMPQ = 'V', Q a été post-multiplié par la
!>          matrice de transformation unitaire Z qui réorganise T.
!>          Si COMPQ = 'N', Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= 1, et si
!>          COMPQ = 'V', LDQ >= max(1,N).
!>

IFST

!>          IFST est INTEGER
!>

ILST

!>          ILST est INTEGER
!>
!>          Spécifient la réorganisation des éléments diagonaux de T :
!>          L'élément avec l'indice de ligne IFST est déplacé à la ligne ILST par une
!>          séquence de transpositions entre éléments adjacents.
!>          1 <= IFST <= N ; 1 <= ILST <= N.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  fin réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
