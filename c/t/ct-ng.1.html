crosstool-NG(1) Commandes utilisateur crosstool-NG(1)

NOM

ct-ng, crosstool-NG - Construire des chaînes d'outils croisées

SYNOPSIS

ct-ng ACTION

DESCRIPTION

Construire une chaîne d'outils croisée peut être un vrai casse-tête.

crosstool-NG facilite la construction de chaînes d'outils croisées, et vous permet de tirer le meilleur parti de votre cible en configurant les différents composants de la chaîne d'outils selon le processeur ciblé.

ACTIONS

Voici les actions les plus couramment utilisées. Pour les autres actions, veuillez consulter la documentation dans /usr/share/doc/crosstool-ng

help
Affiche un bref texte d'aide.
menuconfig
Configure crosstool-NG en utilisant un menu de configuration très similaire à celui du noyau Linux.
oldconfig
Applique les options trouvées dans un fichier .config existant et demande les options plus récentes s'il y en a.
saveconfig
Sauvegarde la configuration actuelle de crosstool-NG, ainsi que les fichiers de configuration des composants associés, dans un échantillon. Les échantillons sont sauvegardés dans leur propre sous-répertoire, nommé d'après le tuple de la cible, dans le sous-répertoire samples du répertoire courant. Les échantillons peuvent être rappelés plus tard en appelant ct-ng avec le tuple de la cible qu'ils représentent.
savedefconfig
Sauvegarde la configuration actuelle dans un fichier mini-defconfig, qui ne contient que les symboles strictement nécessaires pour reproduire la configuration. Les fichiers defconfig sont beaucoup plus petits qu'un .config complet, il est donc facile de les envoyer par mail. Comme seuls les symboles non par défaut sont présents dans un defconfig, il est facile de repérer les valeurs significatives. De plus, il est facile d'utiliser des fichiers defconfig avec des versions plus récentes de crosstool-NG. Par défaut, le mini-defconfig est sauvegardé dans un fichier nommé defconfig, sauf si la variable $DEFCONFIG est définie, auquel cas le mini-defconfig sera sauvegardé dans le fichier référencé par $DEFCONFIG.

Note : seul le fichier .config de crosstool-NG est sauvegardé. Les fichiers de configuration des composants ne sont pas sauvegardés. Utilisez saveconfig pour cela.

defconfig
Configure crosstool-NG en utilisant un fichier mini-defconfig (précédemment sauvegardé avec savedefconfig ou édité manuellement). Le mini-defconfig par défaut est lu depuis le fichier defconfig, sauf si la variable $DEFCONFIG est définie, auquel cas le mini-defconfig sera lu depuis le fichier référencé par $DEFCONFIG.
build
Construit la chaîne d'outils configurée.
clean
Supprime les fichiers générés par crosstool-NG pour lui-même (il s'agit principalement des binaires des configurateurs).
distclean
Identique à clean, mais supprime également le répertoire de construction de la chaîne d'outils, les fichiers téléchargés et le fichier de configuration .config. La chaîne d'outils générée n'est pas touchée, ni les échantillons qui ne sont pas supprimés.
updatetools
Met à jour les scripts config.guess et config.sub. Ces scripts sont utilisés par crosstool-NG pour canonicaliser les noms des machines (hôtes, construction et cibles).

ENVIRONNEMENT

STOP, RESTART
Arrête et redémarre respectivement la construction juste avant cette étape. Pour redémarrer une étape, une construction précédente doit avoir atteint au moins cette étape, ou plus loin.

La liste des étapes est consultable avec l'action list-steps.

VALEUR DE RETOUR

Le frontend ct-ng est en fait un script make(1). Consultez la page de manuel de make(1) pour connaître la signification des valeurs de retour.

SÉCURITÉ

Ne pas exécuter en tant que root ! De grandes précautions ont été prises pour éviter les erreurs, mais il n'existe pas de programmes sans bugs. Pendant le fonctionnement normal, crosstool-NG supprime des répertoires entiers. Si vous exécutez en tant que root, et qu'il y a un bug ou que vous avez mal configuré crosstool-NG, des répertoires importants entiers pourraient être supprimés (par ex. /usr), bien que crosstool-NG refuse d'installer des chaînes d'outils dans certains répertoires critiques bien connus.
