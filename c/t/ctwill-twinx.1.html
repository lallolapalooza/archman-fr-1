NOM

ctwill, ctwill-refsort, ctwill-twinx - convertir CWEB en TeX avec mini-index

SYNOPSIS

ctwill [options] webfile[.w] [{changefile[.ch]|-} [outfile[.tex]]]

ctwill-refsort < indexfile.ref > indexfile.sref

ctwill-twinx outfile.tex [outfile.tex ...] > index.tex

DESCRIPTION

Le ctwill programme convertit un document source CWEB en un fichier TeX qui peut être mis en forme et imprimé de la manière habituelle. Il prend soin des détails typographiques tels que la disposition de la page et l'utilisation de l'indentation, l'italique, le gras, etc., et fournit des informations d'index croisé étendues qu'il collecte automatiquement.

CWEB vous permet de préparer un seul document contenant toutes les informations nécessaires à la fois pour produire un programme C/C++ compilable et pour produire un document bien formaté décrivant le programme aussi en détail que l'auteur le désire. L'utilisateur de CWEB devrait être familier avec TeX ainsi qu'avec C/C++.

UTILISATION

La ligne de commande devrait contenir un, deux ou trois noms. Le premier est considéré comme le fichier d'entrée CWEB (et .w est ajouté s'il n'y a pas d'extension). S'il y a un deuxième nom, c'est un fichier de modification (et .ch est ajouté s'il n'y a pas d'extension). Le fichier de modification remplace des parties du fichier CWEB, comme décrit dans la documentation. S'il y a un troisième nom, il remplace le nom par défaut du fichier de sortie, qui est habituellement le même que le nom du fichier d'entrée (mais dans le répertoire courant) avec l'extension .tex. Si vous voulez simplement changer le nom du fichier de sortie, mais que vous n'avez pas de fichier de modification à appliquer, vous pouvez utiliser `-' comme deuxième argument.

ctwill est exactement comme cweave sauf qu'il produit une bien meilleure documentation, pour laquelle vous devez travailler beaucoup plus dur. Vous devriez exécuter ctwill deux fois, une fois pour amorcer la pompe et une fois pour obtenir des résultats décents. De plus, vous devez exécuter la sortie deux fois à travers TeX.

Après tex foo vous aurez une sortie qui ressemble à des pages finales sauf que les entrées des mini-index ne seront pas alphabetisées. La première exécution produit un fichier étrange appelé foo.ref. Dites ctwill-refsort < foo.ref > foo.sref et ensuite une autre tex foo produira une sortie alphabetisée.

Le ctwill-twinx programme compile un index maître pour un ensemble de programmes liés qui ont été traités par ctwill (non par cweave, notez-le bien !). Les programmes individuels devraient définir leurs noms avec une ligne de la forme \def\title{NAME}. Pour votre commodité, ctwill-twinx prend le premier « mot » dans \title et le transforme en forme majuscule. Vous devriez adapter le fichier twinx-startup.tex pour la première page de l'index maître.

Les mini-index listent les identifiants qui sont utilisés mais non définis sur chaque double page. À la fin de chaque section, ctwill donne à TeX une liste des identifiants utilisés dans cette section et des informations sur l'endroit où ils sont définis.

La signification actuelle de chaque identifiant est initialement \uninitialized. Ensuite ctwill lit le .aux fichier pour votre travail, s'il y en a un.

Avant de lire le .aux fichier, ctwill cherche en fait un fichier appelé system.bux, qui sera lu s'il est présent. Et après foo.aux, une troisième possibilité est foo.bux. La convention générale est de mettre les définitions des procédures système telles que printf dans system.bux, et de mettre les définitions trouvées dans les fichiers d'en-tête spécifiquement foo dans foo.bux. Comme les .aux fichiers, .bux fichiers devraient contenir seulement @$ spécifications.

La signification spécifiée par @$...@> a généralement quatre composantes : un identifiant (suivi d'un espace), un nom de programme (entre accolades), un numéro de section (suivi d'un espace), et une partie TeX.

Un mode spécial proofmode est fourni pour que vous puissiez vérifier ctwill's conclusions sur les références croisées. Exécutez ctwill avec le drapeau +P, et TeX produira un document spécialement formaté (sans mini-index) dans lequel vous pouvez vérifier que vos spécifications sont correctes.

Plus de détails sur la façon d'utiliser ctwill peuvent être trouvés dans les premières sections de son code source, respectivement le fichier de modification cweav-twill.ch applicable à la cweave.w source. Un exemple complet avec toutes les options est décrit dans Mini-Indexes for Literate Programs, pages 225–245 de Knuth's Digital Typography.

DIFFÉRENCES PAR RAPPORT À CTWILL ORIGINAL

La présente incarnation de ctwill et de ses utilitaires essaie d'être un remplacement direct pour le paquet original. Il y a cependant quelques différences à noter :

•
Cette version est basée sur la version la plus récente de CWEB (4.8).
•
Dans TeX Live les programmes utilitaires sont préfixés avec ctwill- et les fichiers de macro avec ct pour des raisons techniques.
•
Les options --help, --quiet, --verbose, --version, et les drapeaux +c, -i, -o, et +lX sont nouveaux dans CWEBbin et TeX Live.
•
L'option +lX est accompagnée de fichiers wrapper d'exemple pour ctwimac.tex et ctproofmac.tex avec des légendes traduites pour l'allemand (+ld).
•
L'option +lX est également accompagnée d'un pdfctwimac.tex étendu pour la production de sortie PDF avec hyperliens actifs (+lpdf).
•
ctwill dans TeX Live fonctionne silencieusement par défaut ; utilisez l' --verbose option pour obtenir le comportement original.
•
La recherche de fichier avec la variable d'environnement CWEBINPUTS est étendue pour permettre plusieurs chemins séparés par des deux-points ; voir ENVIRONNEMENT ci-dessous.
•
Si correctement configuré, le programme principal ctwill est localisé avec les « utilitaires GNU gettext ».

OPTIONS

Les options sur la ligne de commande peuvent être désactivées avec `-' (si elles sont activées par défaut) ou activées avec `+' (si elles sont désactivées par défaut). En fait, les options sont traitées de gauche à droite, donc une séquence comme --verbose -h n'affichera que la ligne de bannière (+b) et le rapport de progression (+p), mais laissera de côté le message de succès (-h).

•
+b: imprimer la ligne de bannière sur le terminal
•
+h: imprimer le message de succès à la fin
•
+p: imprimer les messages de rapport de progression
•
+q/-q: raccourci pour -bhp; aussi --quiet (par défaut)
•
+v/-v: raccourci pour +bhp; aussi --verbose
•
+c: vérifier les changements dans la sortie temporaire
•
-e: ne pas envelopper le matériel C/C++ dans \PB{...}
•
-f: ne pas forcer un saut de ligne après chaque déclaration C/C++ dans la sortie
•
-i: supprimer l'indentation des déclarations de paramètres
•
-o: supprimer la séparation des déclarations et des instructions
•
-x: omettre les index, les noms de sections, la table des matières
•
+P: \input ctproofmac.tex au lieu de ctwimac.tex
•
+lX/-lX: utiliser les macros pour la langue X telles que définies dans X{ctwimac|ctproofmac}.tex
•
+s: imprimer les statistiques d'utilisation
•
+t: traiter typename dans un template comme typedef
•
--help: afficher le message d'aide et quitter
•
--version: afficher les informations de version et quitter

ENVIRONNEMENT

La variable d'environnement CWEBINPUTS est utilisée pour rechercher les fichiers d'entrée, ou la valeur par défaut du système si CWEBINPUTS n'est pas défini. Voir tex(1) pour les détails de la recherche. Pour éviter les conflits avec d'autres programmes qui utilisent aussi l'environnement CWEBINPUTS, vous pouvez être plus précis et utiliser CWEBINPUTS_cweb pour des besoins spécifiques dans CWEB.

NAME

ctwill — A variant of cweave

SYNOPSIS

ctwill [ -lX ] [ -p ] [ -P ] [ -w ] [ -W ] [ -C ] [ -d ] [ -v ] [ -x ] [ -h ] [ -? ] [ file.w ... ]

DESCRIPTION

ctwill is a variant of cweave. The cweave utility is a CWEB program that is used to format C source code files into TeX files. ctwill is a version of cweave that has been modified for the use of the ctangle program.

The CWEB system consists of two programs: ctangle and cweave. ctangle produces a C source file from a WEB file (a file with a .w extension), and cweave produces a TeX file from a WEB file.

The CWEB system was originally written by Donald E. Knuth and Silvio Levy. ctwill is a variant of cweave that has been modified for the use of the ctangle program. The modifications are mostly to the output format to make it easier to integrate with other tools.

The ctwill program is part of the CWEB package. The CWEB package can be obtained from the Comprehensive TeX Archive Network (CTAN).

USAGE

The ctwill program is typically used to process C source code files that are written in the WEB format. The WEB format is a literate programming format that allows you to intersperse C code with TeX documentation. The ctwill program takes one or more WEB files as input and produces a TeX file as output.

The TeX file produced by ctwill can then be processed by the TeX typesetting system to produce a formatted document. The C code embedded in the WEB file can be extracted by the ctangle program.

DIFFERENCES TO ORIGINAL CTWILL

The version of ctwill provided with TeX Live has been modified to be compatible with the TeX Live distribution. The main difference is in the way that translation catalogs are handled. The original ctwill program used the GETTEXT package to internationalize the program. This version uses a simpler mechanism that is specific to TeX Live.

OPTIONS

-lX
Requests that the output file be prefixed with the TeX command \\input X. For example, -ld will prepend \\input dctwimac.tex to the output file. The special option -lpdf will prepend \\input pdfctwimac.tex, which is used for producing PDF output with active hyperlinks.
-p
Requests that the output file be prefixed with the TeX command \\input ctproofmac.tex. This option is used when generating proof copies of the documentation.
-P
This option is similar to -p, but it also enables the generation of proof-related information in the output file.
-w
Suppresses the generation of the TeX file. Only the C source file will be produced.
-W
Suppresses the generation of the C source file. Only the TeX file will be produced.
-C
Enables C-style comments in the output TeX file. This can be useful for documenting C code that uses C-style comments.
-d
Enables debugging output. This can be useful for troubleshooting problems with the ctwill program.
-v
Prints the version number of ctwill and exits.
-x
Extracts the C source code from the WEB file without processing the documentation. This is equivalent to running ctangle on the input file.
-h
-?
Prints a help message and exits.

ENVIRONMENT

ctwill like ctangle and cweave uses the environment variable TEXMFLOCALEDIR to configure the parent directory where the “GNU gettext utilities” search for translation catalogs.

These variables are preconfigured in TeX Live’s texmf.cnf.

FILES

The location of the files mentioned below varies from system to system. Use the kpsewhich utility to find their locations.

•
ctwimac.tex: The default TeX macros \input in the first line of the output file.
•
ctproofmac.tex: If ctwill is invoked with the +P option, it will change the first line of the output file to \input ctproofmac.tex.

In both cases you can request some prefix X with the +lX option, e.g., +ld will \input dctwimac.tex and +Pld will \input dctproofmac.tex. A special application is the use of option +lpdf that will \input pdfctwimac.tex for production of PDF output with active hyperlinks.

•
webfile.bux: Reference definitions to resolve from other modules.
•
system.bux: Reference definitions to resolve from C/C++ standard library header files like <stdio.h>.

Other auxiliary files with references are created automatically by ctwill and the actual index files are created by TeX.

•
cwebman.tex: The CWEB user manual, available in PDF from CTAN (https://ctan.org/pkg/cweb).
