Nom

ctags-lang-terraform - Notes diverses sur l'indexation des fichiers Terraform avec Universal Ctags

SYNOPSIS

ctags ... --languages=+Terraform ...
ctags ... --language-force=Terraform ...
ctags ... --map-Terraform=+.tf ...
ctags ... --extras=+{reference} --languages=+TerraformVariables ...
ctags ... --extras=+{reference} --language-force=TerraformVariables ...
ctags ... --extras=+{reference} --map-Terraform=+.tfvars ...

DESCRIPTION

Cette page de manuel rassemble des notes diverses sur l'indexation des fichiers Terraform.

ASTUCES

Extraction des variables assignées dans les définitions de variables

Spécifiez --extras=+{reference} et --languages=+TerraformVariables pour extraire les variables assignées dans les définitions de variables (*.tfvars). L'analyseur TerraformVariables extrait les variables dans les fichiers *.tfvars avec le type variable et le rôle assigned du langage Terraform.
