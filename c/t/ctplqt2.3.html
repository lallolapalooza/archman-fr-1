Documentation de la fonction/sous-routine

sous-routine ctplqt2 (integer m, integer n, integer l, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldt, * ) t, integer ldt, integer info)

CTPLQT2

But:

!>
!> CTPLQT2 calcule une factorisation LQ d'une matrice complexe C, composée
!> d'une matrice triangulaire A et d'une matrice pentagonale B,
!> en utilisant la représentation WY compacte pour Q.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre total de lignes de la matrice B.
!>          M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice B, et l'ordre de
!>          la matrice triangulaire A.
!>          N >= 0.
!>

L

!>          L est un ENTIER
!>          Le nombre de lignes de la partie trapézoïdale inférieure de B.
!>          MIN(M,N) >= L >= 0. Voir Détails supplémentaires.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,M)
!>          À l'entrée, la matrice triangulaire inférieure A de taille M-par-M.
!>          À la sortie, les éléments sur et sous la diagonale du tableau
!>          contiennent la matrice triangulaire inférieure L.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEXE, de dimension (LDB,N)
!>          À l'entrée, la matrice pentagonale B de taille M-par-N. Les N-L premières colonnes
!>          sont rectangulaires, et les L dernières colonnes sont trapézoïdales inférieures.
!>          À la sortie, B contient la matrice pentagonale V. Voir Détails supplémentaires.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,M).
!>

T

!>          T est un tableau COMPLEXE, de dimension (LDT,M)
!>          Le facteur triangulaire supérieur T de taille N-par-N du réflecteur de bloc.
!>          Voir Détails supplémentaires.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,M)
!>

INFO

!>          INFO est un ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!>
!>  La matrice d'entrée C est une matrice de taille M-par-(M+N)
!>
!>               C = [ A ][ B ]
!>
!>
!>  où A est une matrice triangulaire inférieure M-par-M, et B est une matrice pentagonale M-par-N
!>  composée d'une matrice rectangulaire M-par-(N-L) B1 à gauche et d'une matrice
!>  trapézoïdale inférieure M-par-L B2 :
!>
!>               B = [ B1 ][ B2 ]
!>                   [ B1 ]  <-     M-par-(N-L) rectangulaire
!>                   [ B2 ]  <-     M-par-L trapézoïdale inférieure.
!>
!>  La matrice trapézoïdale inférieure B2 est composée des L premières colonnes d'une
!>  matrice triangulaire inférieure N-par-N, où 0 <= L <= MIN(M,N). Si L=0,
!>  B est rectangulaire M-par-N ; si M=L=N, B est triangulaire inférieure.
!>
!>  La matrice W stocke les réflecteurs élémentaires H(i) dans la i-ème ligne
!>  au-dessus de la diagonale (de A) dans la matrice d'entrée C de taille M-par-(M+N)
!>
!>               C = [ A ][ B ]
!>                   [ A ]  <- triangulaire inférieure M-par-M
!>                   [ B ]  <- pentagonale M-par-N
!>
!>  de telle sorte que W puisse être représentée comme
!>
!>               W = [ I ][ V ]
!>                   [ I ]  <- identité, M-par-M
!>                   [ V ]  <- M-par-N, même forme que B.
!>
!>  Ainsi, toutes les informations nécessaires pour W sont contenues à la sortie dans B,
!>  que nous appelons V ci-dessus. Notez que V a la même forme que B ; c'est-à-dire,
!>
!>               W = [ V1 ][ V2 ]
!>                   [ V1 ] <-     M-par-(N-L) rectangulaire
!>                   [ V2 ] <-     M-par-L trapézoïdale inférieure.
!>
!>  Les lignes de V représentent les vecteurs qui définissent les H(i).
!>  Le réflecteur de bloc H de taille (M+N)-par-(M+N) est alors donné par
!>
!>               H = I - W**T * T * W
!>
!>  où W^H est la transposée conjuguée de W et T est le facteur triangulaire supérieur
!>  du réflecteur de bloc.
!>
