NOM

ctanbib - récupérer des informations bibliographiques pour les paquets hébergés sur CTAN.

SYNTAXE

ctanbib <options> [nom du paquet]

DESCRIPTION

Cette commande peut récupérer des informations bibliographiques pour les paquets TeX hébergés sur CTAN au format BibTeX.

Recherche l'entrée du Catalogue pour chaque NOMDUPAQ sur CTAN (à l'adresse https://ctan.org/xml/2.0/pkg/NOMDUPAQ), et convertit les informations pertinentes en une entrée BibTeX.

Par défaut, le champ url de l'entrée de sortie est la valeur du champ home du paquet s'il est spécifié dans l'entrée du Catalogue ; sinon, https://ctan.org/pkg/NOMDUPAQ est utilisé.

OPTIONS

-c,--ctan
Utilise toujours l'URL CTAN /pkg/ au lieu de la page d'accueil du paquet
-C,--CTAN
Utilise le chemin CTAN du paquet comme url (par ex. : /support/ctanbib)
-e,--entrytype
(défaut : manual) Change le type d'entrée
-h,--help
imprime le message d'aide.
-p,--pkgname
Encapsule le nom du paquet dans une commande tanbibpkgname. Cette commande peut être redéfinie dans le document pour le formatage désiré.
-v,--version
imprime les informations de version.

EXEMPLES

$ ctanbib latex

Cette invocation imprimera des données au format BibLaTeX sur la sortie standard :

@manual{latex,
  title = {Le paquet Latex},
  subtitle = {Un paquet de macros TeX qui définit LaTeX},
  author = {Lamport, Leslie et L'équipe LaTeX},
  url = {http://www.latex-project.org/},
  urldate = {2018-08-23}, 
  date = {2018-04-01},
  version = {PL 5}
}

L'option --ctan :

$ ctanbib -c hyperref

Ceci produit un enregistrement bib avec le type @ctan :

@ctan{hyperref,
title = {Le paquet Hyperref},
subtitle = {Support étendu pour l'hypertexte en LaTeX},
author = {Rahtz, Sebastian et Oberdiek, Heiko},
url = {/macros/latex/contrib/hyperref},
urldate = {2018-08-27}, 
date = {},
version = {6.86b}
}
