ct_run(1) Commandes utilisateur ct_run(1)

NOM

ct_run - Programme utilisé pour démarrer Common Test depuis la ligne de commande du système d'exploitation

DESCRIPTION

Le programme ct_run est automatiquement installé avec Erlang/OTP et l'application Common Test (pour plus d'informations, voir la section Installation du Guide de l'utilisateur). Le programme accepte différents indicateurs de démarrage. Certains indicateurs déclenchent le démarrage de Common Test par ct_run et lui transmettent des données. Certains indicateurs démarrent un nœud Erlang préparé pour exécuter Common Test dans un mode particulier.

La fonction d'interface ct:run_test/1, correspondant au programme ct_run, est utilisée pour démarrer Common Test depuis le shell Erlang (ou un programme Erlang). Pour plus de détails, voir la page de manuel ct.

ct_run accepte également les indicateurs de l'émulateur Erlang. Ceux-ci sont utilisés lorsque ct_run appelle erl pour démarrer le nœud Erlang (cela permet d'ajouter des répertoires au chemin du serveur de code, de changer le cookie sur le nœud, de démarrer plus d'applications, etc.).

Avec l'indicateur optionnel -erl_args, les options de la ligne de commande ct_run peuvent être divisées en deux groupes :

•Un groupe que Common Test doit traiter (ceux précédant -erl_args).
•Un groupe que Common Test doit ignorer et transmettre directement à l'émulateur (ceux suivant -erl_args).

Les options précédant -erl_args que Common Test ne reconnaît pas sont également transmises à l'émulateur sans modification. Par -erl_args, l'utilisateur peut spécifier des indicateurs portant le même nom, mais avec des destinations différentes, sur la ligne de commande ct_run.

Si les indicateurs -pa ou -pz sont spécifiés dans le groupe d'options de Common Test (précédant -erl_args), les répertoires relatifs sont convertis en absolus et réinsérés dans le chemin du code par Common Test. Ceci afin d'éviter des problèmes lors du chargement des modules utilisateur lorsque Common Test change le répertoire de travail pendant l'exécution des tests. Cependant, Common Test ignore les indicateurs -pa et -pz suivant -erl_args sur la ligne de commande. Ces répertoires sont ajoutés au chemin du code normalement (c'est-à-dire, sous la forme spécifiée).

Le statut de sortie est défini avant la fin du programme. La valeur 0 indique un résultat de test réussi, 1 indique un ou plusieurs cas de test échoués ou auto-ignorés, et 2 indique un échec d'exécution du test.

Si ct_run est appelé avec l'option -help, il affiche tous les indicateurs de démarrage valides sur stdout.

Exécuter les tests depuis la ligne de commande

 ct_run -dir TestDir1 TestDir2 .. TestDirN |
  [-dir TestDir] -suite Suite1 Suite2 .. SuiteN
  [-group Groups1 Groups2 .. GroupsN] [-case Case1 Case2 .. CaseN]
  [-step [config | keep_inactive]]
  [-config ConfigFile1 ConfigFile2 .. ConfigFileN]
  [-userconfig CallbackModule1 ConfigString1 and CallbackModule2
   ConfigString2 and .. CallbackModuleN ConfigStringN]
  [-decrypt_key Key] | [-decrypt_file KeyFile]
  [-label Label]
  [-logdir LogDir]
  [-logopts LogOpts]
  [-verbosity GenVLevel | [Category1 VLevel1 and
   Category2 VLevel2 and .. CategoryN VLevelN]]
  [-silent_connections [ConnType1 ConnType2 .. ConnTypeN]]
  [-stylesheet CSSFile]
  [-cover CoverCfgFile]
  [-cover_stop Bool]
  [-event_handler EvHandler1 EvHandler2 .. EvHandlerN] |
  [-event_handler_init EvHandler1 InitArg1 and
   EvHandler2 InitArg2 and .. EvHandlerN InitArgN]
  [-include InclDir1 InclDir2 .. InclDirN]
  [-no_auto_compile]
  [-abort_if_missing_suites]
  [-multiply_timetraps Multiplier]
  [-scale_timetraps]
  [-create_priv_dir auto_per_run | auto_per_tc | manual_per_tc]
  [-repeat N] |
  [-duration HHMMSS [-force_stop [skip_rest]]] |
  [-until [YYMoMoDD]HHMMSS [-force_stop [skip_rest]]]
  [-basic_html]
  [-no_esc_chars]
  [-keep_logs all | NLogs]
  [-ct_hooks CTHModule1 CTHOpts1 and CTHModule2 CTHOpts2 and ..
   CTHModuleN CTHOptsN]
  [-ct_hooks_order test | config]
  [-exit_status ignore_config]
  [-help]

Exécuter les tests en utilisant une spécification de test

 ct_run -spec TestSpec1 TestSpec2 .. TestSpecN
  [-join_specs]
  [-config ConfigFile1 ConfigFile2 .. ConfigFileN]
  [-userconfig CallbackModule1 ConfigString1 and CallbackModule2
   ConfigString2 and .. and CallbackModuleN ConfigStringN]
  [-decrypt_key Key] | [-decrypt_file KeyFile]
  [-label Label]
  [-logdir LogDir]
  [-logopts LogOpts]
  [-verbosity GenVLevel | [Category1 VLevel1 and
   Category2 VLevel2 and .. CategoryN VLevelN]]
  [-allow_user_terms]
  [-silent_connections [ConnType1 ConnType2 .. ConnTypeN]]
  [-stylesheet CSSFile]
  [-cover CoverCfgFile]
  [-cover_stop Bool]
  [-event_handler EvHandler1 EvHandler2 .. EvHandlerN] |
  [-event_handler_init EvHandler1 InitArg1 and
   EvHandler2 InitArg2 and .. EvHandlerN InitArgN]
  [-include InclDir1 InclDir2 .. InclDirN]
  [-no_auto_compile]
  [-abort_if_missing_suites]
  [-multiply_timetraps Multiplier]
  [-scale_timetraps]
  [-create_priv_dir auto_per_run | auto_per_tc | manual_per_tc]
  [-repeat N] |
  [-duration HHMMSS [-force_stop [skip_rest]]] |
  [-until [YYMoMoDD]HHMMSS [-force_stop [skip_rest]]]
  [-basic_html]
  [-no_esc_chars]
  [-keep_logs all | NLogs]
  [-ct_hooks CTHModule1 CTHOpts1 and CTHModule2 CTHOpts2 and ..
   CTHModuleN CTHOptsN]
  [-ct_hooks_order test | config]
  [-exit_status ignore_config]

Rafraîchir les fichiers d'index HTML

 ct_run -refresh_logs [-logdir LogDir] [-basic_html]
  [-keep_logs all | NLogs]

Exécuter Common Test en mode interactif

 ct_run -shell
  [-config ConfigFile1 ConfigFile2 ... ConfigFileN]
  [-userconfig CallbackModule1 ConfigString1 and CallbackModule2
   ConfigString2 and .. and CallbackModuleN ConfigStringN]
  [-decrypt_key Key] | [-decrypt_file KeyFile]

Démarrer un nœud maître Common Test

 ct_run -ctmaster
