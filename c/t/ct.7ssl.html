NOM

ct - Certificate Transparency

SYNTAXE

#include <openssl/ct.h>

DESCRIPTION

Cette bibliothèque implémente la vérification de la Certificate Transparency (CT) pour les clients TLS, telle que définie dans la RFC 6962. Cette vérification peut fournir une certaine confiance qu'un certificat a été enregistré publiquement dans un ensemble de journaux CT.

Par défaut, ces vérifications sont désactivées. Elles peuvent être activées en utilisant SSL_CTX_enable_ct(3) ou SSL_enable_ct(3).

Cette bibliothèque peut également être utilisée pour analyser et examiner les structures de données CT, telles que les Signed Certificate Timestamps (SCTs), ou pour lire une liste de journaux CT. Il existe des fonctions pour : - décoder et encoder les SCTs aux formats DER et TLS. - afficher les SCTs. - vérifier l'authenticité des SCTs. - charger une liste de journaux CT à partir d'un fichier CONF.
