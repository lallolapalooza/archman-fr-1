Documentation de la fonction/sous-routine

sous-routine ctrcon (caractère norm, caractère uplo, caractère diag, entier n, complexe, dimension( lda, * ) a, entier lda, réel rcond, complexe, dimension( * ) work, réel, dimension( * ) rwork, entier info)

CTRCON

But:

!>
!> CTRCON estime la réciproque du nombre de condition d'une matrice
!> triangulaire A, en norme 1 ou en norme infini.
!>
!> La norme de A est calculée et une estimation de norm(inv(A)) est
!> obtenue, puis la réciproque du nombre de condition est calculée comme
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infini est requis:
!>          = '1' ou 'O':  Norme 1;
!>          = 'I':         Norme infini.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  A est triangulaire supérieure;
!>          = 'L':  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N':  A est triangulaire non-unitaire;
!>          = 'U':  A est triangulaire unitaire.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de type COMPLEX, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure
!>          triangulaire N-par-N du tableau A contient la matrice
!>          triangulaire supérieure, et la partie strictement inférieure
!>          triangulaire de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          inférieure triangulaire N-par-N du tableau A contient la matrice
!>          triangulaire inférieure, et la partie strictement supérieure
!>          triangulaire de A n'est pas référencée.  Si DIAG = 'U', les
!>          éléments diagonaux de A ne sont pas non plus référencés et sont
!>          supposés être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>          La réciproque du nombre de condition de la matrice A,
!>          calculée comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est un tableau de type COMPLEX, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau de type REAL, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
