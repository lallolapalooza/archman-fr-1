NOM

CTLOG_STORE_get0_log_by_id - Obtenir un journal de Certificate Transparency d'un CTLOG_STORE

SYNTAXE

#include <openssl/ct.h>
const CTLOG *CTLOG_STORE_get0_log_by_id(const CTLOG_STORE *store,
                                        const uint8_t *log_id,
                                        size_t log_id_len);

DESCRIPTION

Un Signed Certificate Timestamp (SCT) identifie le journal de Certificate Transparency (CT) qui l'a émis en utilisant le LogID du journal (voir RFC 6962, Section 3.2). Par conséquent, il est utile de pouvoir récupérer plus d'informations sur un journal (par exemple, sa clé publique) en utilisant ce LogID.

CTLOG_STORE_get0_log_by_id() fournit un moyen de le faire. Elle trouvera un CTLOG dans un CTLOG_STORE qui possède un LogID donné.

VALEURS DE RETOUR

CTLOG_STORE_get0_log_by_id retourne un CTLOG avec le LogID donné, s'il existe dans le CTLOG_STORE donné, sinon elle retourne NULL.

VOIR AUSSI

ct(7), CTLOG_STORE_new(3)

HISTORIQUE

La fonction CTLOG_STORE_get0_log_by_id() a été ajoutée dans OpenSSL 1.1.0.
