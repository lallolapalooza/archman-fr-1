Nom

ctags-lang-iPythonCell - La page man de l'analyseur iPythonCell pour Universal Ctags

Syntaxe

ctags ... --extras=+{sous-analyseur} --languages=+iPythonCell,Python \
[--extras-IPythonCell=+{doubleSharps}] \
[--regex-IPythonCell=/<MOTIF>/\n/c/] ...

Description

L'analyseur iPythonCell est un sous-analyseur empilé par-dessus l'analyseur Python. Il fonctionne lorsque :

  • l'analyseur Python est activé,
  • l'option subparser (sous-analyseur) est activée, et
  • l'analyseur iPythonCell lui-même est activé.

L'analyseur iPythonCell extrait les cellules telles qu'expliquées dans vim-ipython-cell (https://github.com/hanschen/vim-ipython-cell/blob/master/README.md).

Type(S)

L'analyseur iPythonCell ne définit qu'un type : cell.

Options supplémentaires(s)

L'étiquetage des cellules commençant par ##... est désactivé par défaut car le motif est trop générique ; avec ce motif, des étiquettes indésirables peuvent être extraites.

Activez l'option supplémentaire spécifique au langage doubleSharps pour étiqueter les cellules commençant par ##....

Personnalisation

Si votre motif de cellule préféré n'est pas pris en charge par l'analyseur, vous pouvez définir le motif dans votre fichier .ctagd.d/your.ctags ou sur la ligne de commande. Voici un exemple pour prendre en charge "# CTAGS: ..." :

"input.py"

x=1
# CTAGS: DEFINE F
def F():
        # CTAGS: DO NOTING
        pass

"output.tags" avec "--options=NONE --sort=no --extras=+{sous-analyseur} --regex-IPythonCell=/[ t]*# CTAGS:[ ]?(.*)$/1/c/ -o - input.py"

x    input.py        /^x=1$/;"       v
DEFINE F     input.py        /^# CTAGS: DEFINE F$/;" c
F    input.py        /^def F():$/;"  f
DO NOTING    input.py        /^      # CTAGS: DO NOTING$/;"  c

Vous pouvez mettre "--regex-IPythonCell=/[ \t]*# CTAGS:[ ]?(.*)$/\1/c/" dans your.ctags pour éviter de spécifier le motif de manière répétée.
