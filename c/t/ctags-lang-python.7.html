Si une variable ("id") sans indice de type est initialisée avec une expression lambda, ctags attribue le type fonction pour la balise de

"id".

Si une variable ("id_t") avec un indice de type est initialisée avec une expression lambda, ctags attribue le type variable pour la balise de "id_t" avec typeref: et nameref:. ctags remplit le champ typeref: avec la valeur de l'indice de type. La manière de remplir nameref: est un peu

compliquée.

Pour l'expression lambda utilisée pour initialiser la variable avec indice de type, ctags crée une balise extra anonyme ("anonFunc84011d2c0101"). ctags remplit le champ nameref: de "id_t" avec le nom de la balise extra anonyme : "nameref:function:anonFunc84011d2c0101"
