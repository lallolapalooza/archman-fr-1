sous-routine ctrsen (character job, character compq, logical, dimension( * ) select, integer n, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( * ) w, integer m, real s, real sep, complex, dimension( * ) work, integer lwork, integer

CTRSE

N

But

: 
!>
!> CTRSEN réordonne la factorisation de Schur d'une matrice complexe
!> A = Q*T*Q**H, de sorte qu'un groupe d'eigenvalues sélectionné apparaisse
!> aux positions de tête sur la diagonale de la matrice triangulaire
!> supérieure T, et que les colonnes de tête de Q forment une base
!> orthonormale du sous-espace invariant droit correspondant.
!>
!> En option, la routine calcule les nombres de conditionnement réciproques du
!> groupe d'eigenvalues et/ou du sous-espace invariant.
!
>

Paramètre

s
JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si des nombres de conditionnement sont requis pour le
!>          groupe d'eigenvalues (S) ou le sous-espace invariant (SEP) :
!>          = 'N' : aucun ;
!>          = 'E' : pour les eigenvalues uniquement (S) ;
!>          = 'V' : pour le sous-espace invariant uniquement (SEP) ;
!>          = 'B' : pour les eigenvalues et le sous-espace invariant (S et
!>                 SEP).
!
>

COMP

Q 
!>          COMPQ est CHARACTER*1
!>          = 'V' : met à jour la matrice Q des vecteurs de Schur ;
!>          = 'N' : ne met pas à jour Q.
!
>

SELEC

T 
!>          SELECT est un tableau LOGICAL, dimension (N)
!>          SELECT spécifie les eigenvalues dans le groupe sélectionné. Pour
!>          sélectionner la j-ième eigenvalue, SELECT(j) doit être défini à .TRUE..
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice T. N >= 0.
!
>

T 
!>          T est un tableau COMPLEX, dimension (LDT,N)
!>          À l'entrée, la matrice triangulaire supérieure T.
!>          À la sortie, T est écrasée par la matrice T réordonnée, avec les
!>          eigenvalues sélectionnées comme éléments diagonaux de tête.
!
>

LD

T 
!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!
>

Q 
!>          Q est un tableau COMPLEX, dimension (LDQ,N)
!>          À l'entrée, si COMPQ = 'V', la matrice Q des vecteurs de Schur.
!>          À la sortie, si COMPQ = 'V', Q a été post-multipliée par la
!>          matrice de transformation unitaire qui réordonne T ; les M
!>          colonnes de tête de Q forment une base orthonormale pour le
!>          sous-espace invariant spécifié.
!>          Si COMPQ = 'N', Q n'est pas référencée.
!
>

LD

Q 
!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.
!>          LDQ >= 1 ; et si COMPQ = 'V', LDQ >= N.
!
>

W 
!>          W est un tableau COMPLEX, dimension (N)
!>          Les eigenvalues réordonnées de T, dans le même ordre qu'elles
!>          apparaissent sur la diagonale de T.
!
>

M 
!>          M est INTEGER
!>          La dimension du sous-espace invariant spécifié.
!>          0 <= M <= N.
!
>

S 
!>          S est REAL
!>          Si JOB = 'E' ou 'B', S est une borne inférieure sur le nombre de
!>          conditionnement réciproque pour le groupe d'eigenvalues sélectionné.
!>          S ne peut pas sous-estimer le vrai nombre de conditionnement
!>          réciproque d'un facteur supérieur à sqrt(N). Si M = 0 ou N, S = 1.
!>          Si JOB = 'N' ou 'V', S n'est pas référencée.
!
>

SE

P 
!>          SEP est REAL
!>          Si JOB = 'V' ou 'B', SEP est le nombre de conditionnement
!>          réciproque estimé du sous-espace invariant spécifié. Si
!>          M = 0 ou N, SEP = norm(T).
!>          Si JOB = 'N' ou 'E', SEP n'est pas référencée.
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si JOB = 'N', LWORK >= 1 ;
!>          si JOB = 'E', LWORK = max(1,M*(N-M)) ;
!>          si JOB = 'V' ou 'B', LWORK >= max(1,2*M*(N-M)).
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          ne calcule que la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!
>

Détails supplémentaires

: 
!>
!>  CTRSEN rassemble d'abord les eigenvalues sélectionnées en calculant une transformation
!>  unitaire Z pour les déplacer dans le coin supérieur gauche de T. En d'autres
!>  termes, les eigenvalues sélectionnées sont les eigenvalues de T11 dans :
!>
!>          Z**H * T * Z = ( T11 T12 ) n1
!>                         (  0  T22 ) n2
!>                            n1  n2
!>
!>  où N = n1+n2. Les premières
!>  n1 colonnes de Z couvrent le sous-espace invariant spécifié de T.
!>
!>  Si T a été obtenue à partir de la factorisation de Schur d'une matrice
!>  A = Q*T*Q**H, alors la factorisation de Schur réordonnée de A est donnée par
!>  A = (Q*Z)*(Z**H*T*Z)*(Q*Z)**H, et les premières n1 colonnes de Q*Z couvrent le
!>  sous-espace invariant correspondant de A.
!>
!>  Le nombre de conditionnement réciproque de la moyenne des eigenvalues de
!>  T11 peut être renvoyé dans S. S est compris entre 0 (très mal conditionné)
!>  et 1 (très bien conditionné). Il est calculé comme suit. D'abord, nous
!>  calculons R de sorte que
!>
!>                         P = ( I  R ) n1
!>                             ( 0  0 ) n2
!>                               n1 n2
!>
!>  soit le projecteur sur le sous-espace invariant associé à T11.
!>  R est la solution de l'équation de Sylvester :
!>
!>                        T11*R - R*T22 = T12.
!>
!>  Soit F-norm(M) la norme de Frobenius de M et 2-norm(M) la
!>  2-norme de M. Alors S est calculée comme la borne inférieure
!>
!>                      (1 + F-norm(R)**2)**(-1/2)
!>
!>  sur le réciproque de 2-norm(P), le vrai nombre de conditionnement réciproque.
!>  S ne peut pas sous-estimer 1 / 2-norm(P) d'un facteur
!>  supérieur à sqrt(N).
!>
!>  Une borne d'erreur approchée pour la moyenne calculée des
!>  eigenvalues de T11 est
!>
!>                         EPS * norm(T) / S
!>
!>  où EPS est la précision machine.
!>
!>  Le nombre de conditionnement réciproque du sous-espace invariant droit
!>  couvert par les premières n1 colonnes de Z (ou de Q*Z) est renvoyé dans SEP.
!>  SEP est définie comme la séparation de T11 et T22 :
!>
!>                     sep( T11, T22 ) = sigma-min( C )
!>
!>  où sigma-min(C) est la plus petite valeur singulière de la
!>  matrice n1*n2-par-n1*n2
!>
!>     C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )
!>
!>  I(m) est une matrice identité m par m, et kprod désigne le produit de
!>  Kronecker. Nous estimons sigma-min(C) par le réciproque d'une estimation de
!>  la 1-norme de inverse(C). Le vrai réciproque de la 1-norme de inverse(C)
!>  ne peut pas différer de sigma-min(C) d'un facteur supérieur à sqrt(n1*n2).
!>
!>  Quand SEP est petit, de petits changements dans T peuvent causer de grands changements dans
!>  le sous-espace invariant. Une borne approchée sur l'erreur angulaire
!>  maximale dans le sous-espace invariant droit calculé est
!>
!>                      EPS * norm(T) / SEP
!
>
