Nom

ctags-lang-lisp - Notes diverses sur l'indexation du code source Lisp avec Universal Ctags

SYNOPSIS

ctags ... --languages=+Lisp ...
ctags ... --language-force=Lisp ...
ctags ... --map-Lisp=+.cl ...
ctags ... --map-Lisp=+.clisp ...
ctags ... --map-Lisp=+.l ...
ctags ... --map-Lisp=+.lisp ...
ctags ... --map-Lisp=+.lsp ...

DESCRIPTION

Cette page de manuel rassemble des notes diverses sur l'indexation du code source Lisp.
