A

But

: 
!>
!> CTGSJA calcule la décomposition en valeurs singulières généralisées (GSVD)
!> de deux matrices triangulaires supérieures (ou trapézoïdales) complexes A et B.
!>
!> À l'entrée, on suppose que les matrices A et B ont les formes
!> suivantes, qui peuvent être obtenues par la sous-routine de prétraitement CGGSVP
!> à partir d'une matrice A de dimensions M par N et d'une matrice B de dimensions P par N :
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> où la matrice A12 de dimensions K par K et la matrice B13 de dimensions L par L sont non singulières
!> et triangulaires supérieures ; A23 est triangulaire supérieure de dimensions L par L si M-K-L >= 0,
!> sinon A23 est trapézoïdale supérieure de dimensions (M-K) par L.
!>
!> À la sortie,
!>
!>        U**H *A*Q = D1*( 0 R ),    V**H *B*Q = D2*( 0 R ),
!>
!> où U, V et Q sont des matrices unitaires.
!> R est une matrice triangulaire supérieure non singulière, et D1
!> et D2 sont des matrices « diagonales », qui ont les structures
!> suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                    K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> où
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N) et R33 est stocké
!>     (  0  R22 R23 )
!> dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> Le calcul des matrices de transformation unitaires U, V ou Q
!> est facultatif. Ces matrices peuvent soit être formées explicitement, soit
!> être multipliées à droite par les matrices d'entrée U1, V1 ou Q1.
!
>

NAME


ctgsja - CTGSJA computes the Schur decomposition of a matrix pair (A, B)






SYNOPSIS


    SUBROUTINE CTGSJA(
         JOBU, JOBV, JOBQ, M, N, K, A, LDA, B, LDB, ALPHA, BETA, U, LDU, V, LDV,
         Q, LDQ, WORK, NCYCLE, INFO
    )

        CHARACTER          *          JOBU, JOBV, JOBQ
        INTEGER                      M, N, K, LDA, LDB, LDU, LDV, LDQ, NCYCLE, INFO
        REAL                         ALPHA, BETA
        COMPLEX, DIMENSION( LDA, * ) A
        COMPLEX, DIMENSION( LDB, * ) B
        COMPLEX, DIMENSION( LDU, * ) U
        COMPLEX, DIMENSION( LDV, * ) V
        COMPLEX, DIMENSION( LDQ, * ) Q

Function/Subroutine Documentation


CTGSJA computes the generalized Schur decomposition of a
    matrix pair (A, B) which are rectangular matrices.


CTGSJA is a subroutine of the DGELSD type. It is used
    among others by CGGHRD and CGEQRF.

Further Details:




!>
!>  CTGSJA essentially uses a variant of Kogbetliantz algorithm to reduce
!>  min(L,M-K)-by-L triangular (or trapezoidal) matrix A23 and L-by-L
!>  matrix B13 to the form:
!>
!>           U1**H *A13*Q1 = C1*R1; V1**H *B13*Q1 = S1*R1,
!>
!>  where U1, V1 and Q1 are unitary matrix.
!>  C1 and S1 are diagonal matrices satisfying
!>
!>                C1**2 + S1**2 = I,
!>
!>  and R1 is an L-by-L nonsingular upper triangular matrix.
!>
