Nom

ctags-lang-sql - La page de manuel de l'analyseur SQL pour Universal Ctags

SYNTAXE

ctags ... [--extras={guest}] --languages=+SQL ...

DESCRIPTION

L'analyseur SQL prend en charge divers dialectes SQL. PostgreSQL en fait partie.

PostgreSQL permet à des fonctions définies par l'utilisateur d'être écrites dans d'autres langages (langages procéduraux) que SQL et C [PL].

L'analyseur SQL crée des balises pour les objets de langage dans les fonctions définies par l'utilisateur écrites dans les langages procéduraux si l'extension guest est activée.

L'analyseur SQL recherche un jeton qui suit le mot-clé LANGUAGE dans le code source pour choisir un analyseur invité approprié.

... LANGUAGE plpythonu AS '... fonction définie par l'utilisateur ' ...
... AS $$ fonction définie par l'utilisateur $$ LANGUAGE plv8 ...

Dans les exemples ci-dessus, plpythonu et plv8 sont les noms de langages procéduraux. L'analyseur SQL supprime pl au début et u à la fin du nom avant de trouver un analyseur ctags. Pour plpythonu et plv8, l'analyseur SQL extrait python et v8 comme candidats analyseurs invités.

Pour plpythonu, ctags peut exécuter son analyseur Python. ctags n'a pas d'analyseur nommé v8. Cependant, l'analyseur JavaScript dans ctags a v8 comme alias. Ainsi, ctags peut exécuter l'analyseur JavaScript comme analyseur invité pour plv8.

EXEMPLES

Taguer du code incluant une fonction définie par l'utilisateur dans une chaîne de caractères [GH3006]:

"input.sql"

CREATE OR REPLACE FUNCTION fun1() RETURNS VARCHAR AS '
DECLARE
        test1_var1 VARCHAR(64) := $$ABC$$;
        test1_var2 VARCHAR(64) := $xyz$XYZ$xyz$;
        test1_var3     INTEGER := 1;
BEGIN
        RETURN  TO_CHAR(test_var3, ''000'') || test1_var1 || test1_var2;
END;
' LANGUAGE plpgsql;

"output.tags" avec "--options=NONE -o - --sort=no --extras=+{guest} input.sql"

fun1    input.sql       /^CREATE OR REPLACE FUNCTION fun1() RETURNS VARCHAR AS '$/;"    f       typeref:typename:VARCHAR
test1_var1      input.sql       /^      test1_var1 VARCHAR(64) := $$ABC$$;$/;"  v
test1_var2      input.sql       /^      test1_var2 VARCHAR(64) := $xyz$XYZ$xyz$;$/;"    v
test1_var3      input.sql       /^      test1_var3     INTEGER := 1;$/;"        v

Taguer du code incluant une fonction définie par l'utilisateur dans une quote dollar [GH3006]:

"input.sql"

CREATE OR REPLACE FUNCTION fun2() RETURNS VARCHAR LANGUAGE plpgsql AS $$
DECLARE
        test2_var1 VARCHAR(64) := 'ABC2';
        test2_var2 VARCHAR(64) := 'XYZ2';
        test2_var3        INTEGER := 2;
BEGIN
        RETURN  TO_CHAR(test2_var3, '000') || test2_var1 || test2_var2;
END;
$$;

"output.tags" avec "--options=NONE -o - --sort=no --extras=+{guest} input.sql"

fun2    input.sql       /^CREATE OR REPLACE FUNCTION fun2() RETURNS VARCHAR LANGUAGE plpgsql AS $\$$/;" f       typeref:typename:VARCHAR
test2_var1      input.sql       /^      test2_var1 VARCHAR(64) := 'ABC2';$/;"   v
test2_var2      input.sql       /^      test2_var2 VARCHAR(64) := 'XYZ2';$/;"   v
test2_var3      input.sql       /^      test2_var3        INTEGER := 2;$/;"     v

Taguer du code écrit en JavaScript:

-- Tiré de https://github.com/plv8/plv8/blob/r3.0alpha/sql/plv8.sql
CREATE FUNCTION test(keys text[], vals text[]) RETURNS text AS
$$
        var o = {};
        for (var i = 0; i < keys.length; i++)
                o[keys[i]] = vals[i];
        return JSON.stringify(o);
$$
LANGUAGE plv8 IMMUTABLE STRICT;

"output.tags" avec "--options=NONE -o - --sort=no --extras=+{guest} input.sql"

test    input.sql       /^CREATE FUNCTION test(keys text[], vals text[]) RETURNS text AS$/;"    f
o       input.sql       /^      var o = {};$/;" v

BOGUES CONNUES

Les séquences d'échappement ('') dans une chaîne de caractères peuvent perturber un analyseur invité.
