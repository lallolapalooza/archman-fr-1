Documentation de la fonction/sous-routine

subroutine ctgsen (integer ijob, logical wantq, logical wantz, logical, dimension( * ) select, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) alpha, complex, dimension( * ) beta, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( ldz, * ) z, integer ldz, integer m, real pl, real pr, real, dimension( * ) dif, complex, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

CTGSEN

But :

!>
!> CTGSEN réordonne la décomposition de Schur généralisée d'une paire
!> de matrices complexes (A, B) (en termes d'une transformation
!> d'équivalence unitaire Q**H * (A, B) * Z), de sorte qu'un cluster
!> sélectionné d valeurs propres apparaît dans les blocs diagoniques
!> principaux de la paire (A,B). Les colonnes principales de Q et Z
!> forment des bases unitaires des sous-espaces propres gauche et
!> droit correspondants (sous-espaces déflationnaires). (A, B) doit
!> être sous forme canonique de Schur généralisée, c'est-à-dire que A
!> et B sont tous deux triangulaires supérieurs.
!>
!> CTGSEN calcule également les valeurs propres généralisées
!>
!>          w(j)= ALPHA(j) / BETA(j)
!>
!> de la paire de matrices réordonnée (A, B).
!>
!> En option, la routine calcule des estimations des nombres de
!> condition réciproques pour les valeurs propres et les sous-espaces
!> propres. Ce sont Difu[(A11,B11), (A22,B22)] et Difl[(A11,B11),
!> (A22,B22)], c'est-à-dire la(s) séparation(s) entre les paires de
!> matrices (A11, B11) et (A22,B22) qui correspondent respectivement
!> au cluster sélectionné et aux valeurs propres hors du cluster, et
!> les normes de  sur les sous-espaces propres gauche et droit par
!> rapport au cluster sélectionné dans le bloc (1,1).
!>
!>

Paramètres

IJOB 
!>          IJOB est INTEGER
!>          Spécifie si les nombres de condition sont requis pour le
!>          cluster de valeurs propres (PL et PR) ou les sous-espaces
!>          déflationnaires (Difu et Difl) :
!>           =0 : Réordonner uniquement par rapport à SELECT. Pas
!>                d'extras.
!>           =1 : Réciproque des normes de  sur les sous-espaces
!>               propres gauche et droit par rapport au cluster
!>               sélectionné (PL et PR).
!>           =2 : Bornes supérieures sur Difu et Difl. Estimation basée
!>               sur la norme F (DIF(1:2)).
!>           =3 : Estimation de Difu et Difl. Estimation basée sur la
!>               norme 1 (DIF(1:2)).
!>               Environ 5 fois plus coûteux que IJOB = 2.
!>           =4 : Calculer PL, PR et DIF (c'est-à-dire 0, 1 et 2
!>               ci-dessus) : version économique pour tout obtenir.
!>           =5 : Calculer PL, PR et DIF (c'est-à-dire 0, 1 et 3
!>               ci-dessus)
!>

WANTQ

!>          WANTQ est LOGICAL
!>          .TRUE. : mettre à jour la matrice de transformation gauche Q ;
!>          .FALSE. : ne pas mettre à jour Q.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          .TRUE. : mettre à jour la matrice de transformation droite Z ;
!>          .FALSE. : ne pas mettre à jour Z.
!>

SELECT

!>          SELECT est un tableau LOGICAL, dimension (N)
!>          SELECT spécifie les valeurs propres dans le cluster
!>          sélectionné. Pour sélectionner une valeur propre w(j),
!>          SELECT(j) doit être défini à .TRUE..
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B. N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension(LDA,N)
!>          À l'entrée, la matrice triangulaire supérieure A, sous
!>          forme canonique de Schur généralisée.
!>          À la sortie, A est écrasée par la matrice A réordonnée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX, dimension(LDB,N)
!>          À l'entrée, la matrice triangulaire supérieure B, sous
!>          forme canonique de Schur généralisée.
!>          À la sortie, B est écrasée par la matrice B réordonnée.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

ALPHA

!>          ALPHA est un tableau COMPLEX, dimension (N)
!>

BETA

!>          BETA est un tableau COMPLEX, dimension (N)
!>
!>          Les éléments diagonaux de A et B, respectivement,
!>          lorsque la paire (A,B) a été réduite à la forme de Schur
!>          généralisée. ALPHA(i)/BETA(i) i=1,...,N sont les valeurs
!>          propres généralisées.
!>

Q

!>          Q est un tableau COMPLEX, dimension (LDQ,N)
!>          À l'entrée, si WANTQ = .TRUE., Q est une matrice N par N.
!>          À la sortie, Q a été post-multipliée par la matrice de
!>          transformation unitaire gauche qui réordonne (A, B) ; Les
!>          M colonnes principales de Q forment des bases
!>          orthonormales pour la paire spécifiée de sous-espaces
!>          propres gauche (sous-espaces déflationnaires).
!>          Si WANTQ = .FALSE., Q n'est pas référencée.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= 1.
!>          Si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z est un tableau COMPLEX, dimension (LDZ,N)
!>          À l'entrée, si WANTZ = .TRUE., Z est une matrice N par N.
!>          À la sortie, Z a été post-multipliée par la matrice de
!>          transformation unitaire gauche qui réordonne (A, B) ; Les
!>          M colonnes principales de Z forment des bases
!>          orthonormales pour la paire spécifiée de sous-espaces
!>          propres gauche (sous-espaces déflationnaires).
!>          Si WANTZ = .FALSE., Z n'est pas référencée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1.
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

M

!>          M est INTEGER
!>          La dimension de la paire spécifiée de sous-espaces propres
!>          gauche et droit (sous-espaces déflationnaires) 0 <= M <= N.
!>

PL

!>          PL est REAL
!>

PR

!>          PR est REAL
!>
!>          Si IJOB = 1, 4 ou 5, PL, PR sont des bornes inférieures
!>          sur le réciproque de la norme de  sur les sous-espaces
!>          propres gauche et droit par rapport au cluster sélectionné.
!>          0 < PL, PR <= 1.
!>          Si M = 0 ou M = N, PL = PR  = 1.
!>          Si IJOB = 0, 2 ou 3 PL, PR ne sont pas référencés.
!>

DIF

!>          DIF est un tableau REAL, dimension (2).
!>          Si IJOB >= 2, DIF(1:2) stockent les estimations de Difu et
!>          Difl. Si IJOB = 2 ou 4, DIF(1:2) sont des bornes
!>          supérieures basées sur la norme F pour Difu et Difl. Si
!>          IJOB = 3 ou 5, DIF(1:2) sont des estimations basées sur la
!>          norme 1 de Difu et Difl, calculées en utilisant la
!>          communication inversée avec CLACN2.
!>          Si M = 0 ou N, DIF(1:2) = F-norm([A, B]).
!>          Si IJOB = 0 ou 1, DIF n'est pas référencé.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >=  1
!>          Si IJOB = 1, 2 ou 4, LWORK >=  2*M*(N-M)
!>          Si IJOB = 3 ou 5, LWORK >=  4*M*(N-M)
!>
!>          Si LWORK = -1, alors une interrogation d'espace de travail
!>          est supposée ; la routine          ne calcule que la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun
!>          message d'erreur lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) renvoie la valeur optimale de LIWORK.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK. LIWORK >= 1.
!>          Si IJOB = 1, 2 ou 4, LIWORK >=  N+2;
!>          Si IJOB = 3 ou 5, LIWORK >= MAX(N+2, 2*M*(N-M));
!>
!>          Si LIWORK = -1, alors une interrogation d'espace de travail est supposée ; la
!>          routine ne calcule que la taille optimale du tableau IWORK,
!>          renvoie cette valeur comme première entrée du tableau IWORK, et
!>          aucun message d'erreur lié à LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>            =0: Sortie réussie.
!>            <0: Si INFO = -i, le i-ème argument avait une valeur illégale.
!>            =1: Le réordonnancement de (A, B) a échoué parce que la paire
!>                de matrices transformée (A, B) serait trop éloignée de la forme
!>                de Schur généralisée ; le problème est très mal conditionné.
!>                (A, B) peut avoir été partiellement réordonné.
!>                Si demandé, 0 est renvoyé dans DIF(*), PL et PR.
!>

Détails supplémentaires :

!>
!>  CTGSEN collecte d'abord les valeurs propres sélectionnées en calculant les matrices
!>  unitaires U et W qui les déplacent dans le coin supérieur gauche de (A, B). En
!>  d'autres termes, les valeurs propres sélectionnées sont les valeurs propres de (A11, B11) dans
!>
!>              U**H*(A, B)*W = (A11 A12) (B11 B12) n1
!>                              ( 0  A22),( 0  B22) n2
!>                                n1  n2    n1  n2
!>
!>  où N = n1+n2 et U**H désigne la transposée conjuguée de U. Les premières
!>  n1 colonnes de U et W engendrent la paire spécifiée de sous-espaces propres
!>  gauches et droits (sous-espaces défléchissants) de (A, B).
!>
!>  Si (A, B) a été obtenu à partir de la décomposition de Schur réelle généralisée
!>  d'une paire de matrices (C, D) = Q*(A, B)*Z', alors la
!>  forme de Schur généralisée réordonnée de (C, D) est donnée par
!>
!>           (C, D) = (Q*U)*(U**H *(A, B)*W)*(Z*W)**H,
!>
!>  et les premières n1 colonnes de Q*U et Z*W engendrent les
!>  sous-espaces défléchissants correspondants de (C, D) (Q et Z stockent Q*U et Z*W, resp.).
!>
!>  Notez que si la valeur propre sélectionnée est suffisamment mal conditionnée,
!>  alors sa valeur peut différer significativement de sa valeur avant
!>  réordonnancement.
!>
!>  Les nombres de condition réciproques des sous-espaces propres gauches et droits
!>  engendrés par les premières n1 colonnes de U et W (ou Q*U et Z*W) peuvent
!>  être renvoyés dans DIF(1:2), correspondant à Difu et Difl, resp.
!>
!>  Difu et Difl sont définis comme suit :
!>
!>       Difu[(A11, B11), (A22, B22)] = sigma-min( Zu )
!>  et
!>       Difl[(A11, B11), (A22, B22)] = Difu[(A22, B22), (A11, B11)],
!>
!>  où sigma-min(Zu) est la plus petite valeur singulière de la
!>  matrice (2*n1*n2)-par-(2*n1*n2)
!>
!>       Zu = [ kron(In2, A11)  -kron(A22**H, In1) ]
!>            [ kron(In2, B11)  -kron(B22**H, In1) ].
!>
!>  Ici, Inx est la matrice identité de taille nx et A22**H est la
!>  transposée conjuguée de A22. kron(X, Y) est le produit de Kronecker entre
!>  les matrices X et Y.
!>
!>  Lorsque DIF(2) est petit, de petites modifications de (A, B) peuvent causer de grands changements
!>  dans le sous-espace défléchissant. Une borne (asymptotique) approchée sur
!>  l'erreur angulaire maximale dans les sous-espaces défléchissants calculés est
!>
!>       EPS * norm((A, B)) / DIF(2),
!>
!>  où EPS est la précision machine.
!>
!>  La norme réciproque des projecteurs sur les sous-espaces propres
!>  gauches et droits associés à (A11, B11) peut être renvoyée dans PL et PR.
!>  Elles sont calculées comme suit. D'abord, nous calculons L et R de sorte que
!>  P*(A, B)*Q soit diagonale par blocs, où
!>
!>       P = ( I -L ) n1           Q = ( I R ) n1
!>           ( 0  I ) n2    et        ( 0 I ) n2
!>             n1 n2                    n1 n2
!>
!>  et (L, R) est la solution de l'équation de Sylvester généralisée
!>
!>       A11*R - L*A22 = -A12
!>       B11*R - L*B22 = -B12
!>
!>  Ensuite PL = (F-norm(L)**2+1)**(-1/2) et PR = (F-norm(R)**2+1)**(-1/2).
!>  Une borne (asymptotique) approchée sur l'erreur absolue moyenne des
!>  valeurs propres sélectionnées est
!>
!>       EPS * norm((A, B)) / PL.
!>
!>  Il existe également des bornes d'erreur globales qui sont valables pour des perturbations jusqu'à
!>  une certaine restriction :  Une borne inférieure (x) sur la plus petite
!>  F-norm(E,F) pour laquelle une valeur propre de (A11, B11) peut se déplacer et
!>  coalescer avec une valeur propre de (A22, B22) sous la perturbation (E,F),
!>  (c'est-à-dire (A + E, B + F), est
!>
!>   x = min(Difu,Difl)/((1/(PL*PL)+1/(PR*PR))**(1/2)+2*max(1/PL,1/PR)).
!>
!>  Une borne approchée sur x peut être calculée à partir de DIF(1:2), PL et PR.
!>
!>  Si y = ( F-norm(E,F) / x) <= 1, les angles entre les sous-espaces défléchissants
!>  gauches et droits perturbés (L', R') et non perturbés (L, R)
!>  associés au cluster sélectionné dans les blocs (1,1) peuvent
!>  être bornés comme
!>
!>   max-angle(L, L') <= arctan( y * PL / (1 - y * (1 - PL * PL)**(1/2))
!>   max-angle(R, R') <= arctan( y * PR / (1 - y * (1 - PR * PR)**(1/2))
!>
!>  Voir la section 4.11 du Guide de l'utilisateur LAPACK ou les références
!>  suivantes pour plus d'informations.
!>
!>  Notez que si la méthode par défaut pour calculer l'estimation DIF basée sur la norme de Frobenius
!>  n'est pas souhaitée (voir CLATDF), alors le paramètre
!>  IDIFJB (voir ci-dessous) devrait être changé de 3 à 4 (la routine CLATDF
!>  (IJOB = 2 sera utilisée)). Voir CTGSYL pour plus de détails.
!>
