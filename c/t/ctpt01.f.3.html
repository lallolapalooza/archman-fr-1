Documentation de la fonction/sous-routine

sous-routine ctpt01 (caractère uplo, caractère diag, entier n, complexe, dimension( * ) ap, complexe, dimension( * ) ainvp, réel rcond, réel, dimension( * ) rwork, réel resid)

CTPT01

Objectif :

!>
!> CTPT01 calcule le résidu pour une matrice triangulaire A multipliée par son
!> inverse lorsque A est stockée dans un format compact :
!>    RESID = norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Non unitaire
!>          = 'U':  Unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure d'origine A, compactée
!>          colonne par colonne dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

AINVP

!>          AINVP est un tableau COMPLEX, dimension (N*(N+1)/2)
!>          À l'entrée, l'inverse (triangulaire) de la matrice A, compactée
!>          colonne par colonne dans un tableau linéaire comme dans AP.
!>          À la sortie, le contenu de AINVP est détruit.
!>

RCOND

!>          RCOND est REAL
!>          Le conditionnement réciproque de A, calculé comme
!>          1/(norm(A) * norm(AINV)).
!>

RWORK

!>          RWORK est un tableau REAL, dimension (N)
!>

RESID

!>          RESID est REAL
!>          norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS )
!>
