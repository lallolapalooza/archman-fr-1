sous-routine ctgsna (character job, character howmny, logical, dimension( * ) select, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldvl, * ) vl, integer ldvl, complex, dimension( ldvr, * ) vr, integer ldvr, real, dimension( * ) s, real, dimension( * ) dif, integer mm, integer m, complex, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer

CTGSN

A

Objectif

: 
!>
!> CTGSNA estime les nombres de condition réciproques pour les
!> valeurs propres et/ou vecteurs propres spécifiés d'une paire de
!> matrices (A, B).
!>
!> (A, B) doit être sous forme canonique de Schur généralisée, c'est-à-dire
!> que A et B sont tous deux triangulaires supérieurs.
!
>

Paramètre

s
JOB 
!>          JOB est CHARACTER*1
!>          Indique si les nombres de condition sont requis pour les
!>          valeurs propres (S) ou les vecteurs propres (DIF) :
!>          = 'E' : pour les valeurs propres uniquement (S) ;
!>          = 'V' : pour les vecteurs propres uniquement (DIF) ;
!>          = 'B' : pour les valeurs propres et les vecteurs propres (S et DIF).
!
>

HOWMN

Y 
!>          HOWMNY est CHARACTER*1
!>          = 'A' : calculer les nombres de condition pour toutes les paires
!>                  propres ;
!>          = 'S' : calculer les nombres de condition pour les paires
!>                  propres sélectionnées spécifiées par le tableau SELECT.
!
>

SELEC

T 
!>          SELECT est un tableau LOGICAL, dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les paires propres pour lesquelles
!>          les nombres de condition sont requis. Pour sélectionner les nombres
!>          de condition de la j-ième valeur propre et/ou vecteur propre
!>          correspondant, SELECT(j) doit être défini à .TRUE..
!>          Si HOWMNY = 'A', SELECT n'est pas référencé.
!
>

N 
!>          N est INTEGER
!>          L'ordre de la paire de matrices carrées (A, B). N >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          La matrice triangulaire supérieure A dans la paire (A,B).
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!
>

B 
!>          B est un tableau COMPLEX, dimension (LDB,N)
!>          La matrice triangulaire supérieure B dans la paire (A, B).
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!
>

V

L 
!>          VL est un tableau COMPLEX, dimension (LDVL,M)
!>          Si JOB = 'E' ou 'B', VL doit contenir les vecteurs propres à gauche
!>          de (A, B), correspondant aux paires propres spécifiées par HOWMNY
!>          et SELECT. Les vecteurs propres doivent être stockés dans des
!>          colonnes consécutives de VL, tels que renvoyés par CTGEVC.
!>          Si JOB = 'V', VL n'est pas référencé.
!
>

LDV

L 
!>          LDVL est INTEGER
!>          La dimension principale du tableau VL. LDVL >= 1 ; et
!>          Si JOB = 'E' ou 'B', LDVL >= N.
!
>

V

R 
!>          VR est un tableau COMPLEX, dimension (LDVR,M)
!>          Si JOB = 'E' ou 'B', VR doit contenir les vecteurs propres à droite
!>          de (A, B), correspondant aux paires propres spécifiées par HOWMNY
!>          et SELECT. Les vecteurs propres doivent être stockés dans des
!>          colonnes consécutives de VR, tels que renvoyés par CTGEVC.
!>          Si JOB = 'V', VR n'est pas référencé.
!
>

LDV

R 
!>          LDVR est INTEGER
!>          La dimension principale du tableau VR. LDVR >= 1 ;
!>          Si JOB = 'E' ou 'B', LDVR >= N.
!
>

S 
!>          S est un tableau REAL, dimension (MM)
!>          Si JOB = 'E' ou 'B', les nombres de condition réciproques des
!>          valeurs propres sélectionnées, stockés dans des éléments
!>          consécutifs du tableau.
!>          Si JOB = 'V', S n'est pas référencé.
!
>

DI

F 
!>          DIF est un tableau REAL, dimension (MM)
!>          Si JOB = 'V' ou 'B', les nombres de condition réciproques estimés
!>          des vecteurs propres sélectionnés, stockés dans des éléments
!>          consécutifs du tableau.
!>          Si les valeurs propres ne peuvent pas être réordonnées pour
!>          calculer DIF(j), DIF(j) est défini à 0 ; cela ne peut se produire
!>          que lorsque la valeur réelle serait de toute façon très petite.
!>          Pour chaque valeur propre/vecteur spécifié par SELECT, DIF stocke
!>          une estimation basée sur la norme de Frobenius de Difl.
!>          Si JOB = 'E', DIF n'est pas référencé.
!
>

M

M 
!>          MM est INTEGER
!>          Le nombre d'éléments dans les tableaux S et DIF. MM >= M.
!
>

M 
!>          M est INTEGER
!>          Le nombre d'éléments des tableaux S et DIF utilisés pour stocker
!>          les nombres de condition spécifiés ; pour chaque valeur propre
!>          sélectionnée, un élément est utilisé. Si HOWMNY = 'A', M est défini à N.
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>          Si JOB = 'V' ou 'B', LWORK >= max(1,2*N*N).
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (N+2)
!>          Si JOB = 'E', IWORK n'est pas référencé.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!
>

Détails supplémentaires

: 
!>
!>  L'inverse du nombre de condition de la i-ème valeur propre
!>  généralisée w = (a, b) est défini comme
!>
!>          S(I) = (|v**HAu|**2 + |v**HBu|**2)**(1/2) / (norm(u)*norm(v))
!>
!>  où u et v sont les vecteurs propres à droite et à gauche de (A, B)
!>  correspondant à w ; |z| désigne la valeur absolue du nombre
!>  complexe, et norm(u) désigne la 2-norme du vecteur u. La paire
!>  (a, b) correspond à une valeur propre w = a/b (= v**HAu/v**HBu) de la
!>  paire de matrices (A, B). Si a et b valent tous deux zéro, alors (A,B) est
!>  singulière et S(I) = -1 est renvoyé.
!>
!>  Une borne d'erreur approchée sur la distance cordeale entre la i-ème
!>  valeur propre généralisée w calculée et la valeur propre exacte
!>  lambda correspondante est
!>
!>          chord(w, lambda) <=   EPS * norm(A, B) / S(I),
!>
!>  où EPS est la précision machine.
!>
!>  L'inverse du nombre de condition du vecteur propre à droite u
!>  et du vecteur propre à gauche v correspondant à la valeur propre
!>  généralisée w est défini comme suit. Supposons
!>
!>                   (A, B) = ( a   *  ) ( b  *  )  1
!>                            ( 0  A22 ),( 0 B22 )  n-1
!>                              1  n-1     1 n-1
!>
!>  Alors le nombre de condition réciproque DIF(I) est
!>
!>          Difl[(a, b), (A22, B22)]  = sigma-min( Zl )
!>
!>  où sigma-min(Zl) désigne la plus petite valeur singulière de
!>
!>         Zl = [ kron(a, In-1) -kron(1, A22) ]
!>              [ kron(b, In-1) -kron(1, B22) ].
!>
!>  Ici In-1 est la matrice identité de taille n-1 et X**H est la transposée
!>  conjuguée de X. kron(X, Y) est la Kronecker product entre les
!>  matrices X et Y.
!>
!>  Nous approchons la plus petite valeur singulière de Zl par une
!>  borne supérieure. Cela est effectué par CLATDF.
!>
!>  Une borne d'erreur approchée pour un vecteur propre calculé VL(i) ou
!>  VR(i) est donnée par
!>
!>                      EPS * norm(A, B) / DIF(i).
!>
!>  Voir la réf. [2-3] pour plus de détails et d'autres références.
!
>
