sous-routine ctzrqf (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, integer info)

CTZRQF

But:

!>
!> Cette routine est obsolète et a été remplacée par la routine CTZRZF.
!>
!> CTZRQF réduit la matrice trapézoïdale supérieure M-par-N ( M<=N ) complexe A
!> en forme triangulaire supérieure par des transformations unitaires.
!>
!> La matrice trapézoïdale supérieure A est factorisée comme suit :
!>
!>    A = ( R  0 ) * Z,
!>
!> où Z est une matrice unitaire N-par-N et R est une matrice triangulaire
!> supérieure M-par-M.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= M.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          À l'entrée, la partie supérieure trapézoïdale M-par-N de tête du
!>          tableau A doit contenir la matrice à factoriser.
!>          À la sortie, la partie triangulaire supérieure M-par-M de tête de A
!>          contient la matrice triangulaire supérieure R, et les éléments M+1 à
!>          N des M premières lignes de A, avec le tableau TAU, représentent la
!>          matrice unitaire Z comme un produit de M réflecteurs élémentaires.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension de tête du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEXE, dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

INFO

!>          INFO est un ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!>
!> La factorisation est obtenue par la méthode de Householder. La k-ième
!> matrice de transformation, Z( k ), dont la transposée conjuguée est utilisée
!> pour introduire des zéros dans la (m - k + 1)-ième ligne de A, est donnée sous la
!> forme :
!>
!>     Z( k ) = ( I     0   ),
!>              ( 0  T( k ) )
!>
!> où
!>
!>     T( k ) = I - tau*u( k )*u( k )**H,   u( k ) = (   1    ),
!>                                                   (   0    )
!>                                                   ( z( k ) )
!>
!> tau est un scalaire et z( k ) est un vecteur de ( n - m ) éléments.
!> tau et z( k ) sont choisis pour annihiler les éléments de la k-ième ligne
!> de X.
!>
!> tau est retourné dans le k-ième élément de TAU et le vecteur
!> u( k ) dans la k-ième ligne de A, tels que les éléments de z( k )
!> sont dans a( k, m + 1 ), ..., a( k, n ). Les éléments de R sont retournés
!> dans la partie triangulaire supérieure de A.
!>
!> Z est donné par :
!>
!>     Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>
