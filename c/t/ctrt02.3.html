CTRT02

But:

!>
!> CTRT02 calcule le résidu pour la solution calculée d'un système
!> d'équations linéaires triangulaires op(A)*X = B, où A est une matrice
!> triangulaire. Le rapport de test est le maximum sur
!>    norme(b - op(A)*x) / ( ||op(A)||_1 * norme(x) * EPS ),
!> où op(A) = A, A**T, ou A**H, b est la colonne de B, x est le
!> vecteur solution, et EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CARACTERE*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  A    * X = B  (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CARACTERE*1
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices X et B.  NRHS >= 0.
!>

A

!>          A est tableau COMPLEXE, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure
!>          triangulaire principale de dimension n x n du tableau A contient
!>          la matrice triangulaire supérieure, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée.  Si UPLO = 'L',
!>          la partie inférieure triangulaire principale de dimension n x n
!>          du tableau A contient la matrice triangulaire inférieure, et la partie
!>          strictement supérieure triangulaire de A n'est pas référencée.
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas non plus
!>          référencés et sont supposés valoir 1.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

X

!>          X est tableau COMPLEXE, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est tableau COMPLEXE, dimension (LDB,NRHS)
!>          Les vecteurs du côté droit pour le système d'équations linéaires.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est tableau COMPLEXE, dimension (N)
!>

RWORK

!>          RWORK est tableau REEL, dimension (N)
!>

RESID

!>          RESID est REEL
!>          Le maximum sur le nombre de côtés droits de
!>          norme(op(A)*X - B) / ( norme(op(A)) * norme(X) * EPS ).
!>
