DESCRIPTIO

N

Cette page man décrit l'analyseur SystemVerilog/Verilog pour Universal Ctags. L'analyseur SystemVerilog prend en charge les mots-clés de la norme IEEE 1800-2017. L'analyseur Verilog prend en charge les mots-clés de la norme IEEE

1364-2005.

champ para

meter

Si le champ parameter est activé, un champ parameter: est ajouté sur un paramètre dont la valeur peut être remplacée sur un module, une interface ou un programme instancié. Cela est utile pour un plugin ou une extension d'éditeur permettant l'auto-instanciation de modules avec des paramètres qui peuvent être

remplacés. 
$ ctags ... --fields-Verilog=+{parameter} ...
$ ctags ... --fields-SystemVerilog=+{parameter}

L'analyseur extrait les noms des modules utilisés dans les déclarations d'instances en tant que balises de référence. decl est le rôle des balises. Voir la section "TAG ENTRIES" de ctags(1) pour les balises de référence et les

rôles.
