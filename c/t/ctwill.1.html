La variable d'environnement CWEBINPUTS est utilisée pour rechercher les fichiers d'entrée, ou la valeur par défaut du système si CWEBINPUTS n'est pas défini. Voir tex(1) pour les détails de la recherche. Pour éviter les conflits avec d'autres programmes qui utilisent également l'environnement CWEBINPUTS, vous pouvez être plus précis et utiliser CWEBINPUTS_cweb pour des besoins spécifiques à

CONFIGURATION DE LANGAGE

Comme ctangle et cweave, utilise la variable d'environnement TEXMFLOCALEDIR pour configurer le répertoire parent où les utilitaires « GNU gettext » recherchent les catalogues de traduction.

Ces variables sont préconfigurées dans le fichier texmf.cnf de TeX Live.

FICHIERS

L'emplacement des fichiers mentionnés ci-dessous varie d'un système à l'autre. Utilisez l'utilitaire kpsewhich pour trouver leurs emplacements.

•
ctwimac.tex : Les macros TeX par défaut \input dans la première ligne du fichier de sortie.
•
ctproofmac.tex : Si ctwill est appelé avec l'option +P, il modifiera la première ligne du fichier de sortie en \input ctproofmac.tex.

Dans les deux cas, vous pouvez demander un préfixe X avec l'option +lX, par exemple +ld produira \input dctwimac.tex et +Pld produira \input dctproofmac.tex. Une application spéciale est l'utilisation de l'option +lpdf qui produira \input pdfctwimac.tex pour la génération de sortie PDF avec des hyperliens actifs.

•
webfile.bux : Définitions de référence à résoudre à partir d'autres modules.
•
system.bux : Définitions de référence à résoudre à partir des fichiers d'en-tête de la bibliothèque standard C/C++ comme <stdio.h>.

D'autres fichiers auxiliaires contenant des références sont créés automatiquement par ctwill et les fichiers d'index réels sont créés par TeX.

•
cwebman.tex : Le manuel utilisateur CWEB, disponible en PDF sur CTAN (https://ctan.org/pkg/cweb).
