Nom

ctags-lang-c - Notes diverses sur l'étiquetage du code source C avec Universal Ctags

SYNTAXE

ctags ... --languages=+C ...
ctags ... --language-force=C ...
ctags ... --map-C=+.c ...

DESCRIPTION

Cette page de manuel rassemble des notes diverses sur l'étiquetage du code source C.

VERSIONS
