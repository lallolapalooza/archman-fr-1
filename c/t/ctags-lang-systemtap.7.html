Nom

ctags-lang-systemtap - Notes diverses sur l'étiquetage du code source SystemTap avec Universal Ctags

SYNOPSIS

ctags ... --languages=+SystemTap ...
ctags ... --language-force=SystemTap ...
ctags ... --map-SystemTap=+.stp ...

DESCRIPTION

Cette page de manuel rassemble des notes diverses sur l'étiquetage des scripts SystemTap.

Invités

L'analyseur SystemTap exécute CPreProcessor comme analyseur invité sur les zones entourées par %{ et %}.

"input.stp"

%{
#define X 1
%}

"output.tags" avec "--options=NONE -o - --sort=no --extras=+{guest} input.stp"

X       input.stp       /^#define X /;" d       file:
