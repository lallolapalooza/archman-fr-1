Documentation de la fonction/de la sous-routine

sous-routine ctgsyl (character trans, integer ijob, integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( ldd, * ) d, integer ldd, complex, dimension( lde, * ) e, integer lde, complex, dimension( ldf, * ) f, integer ldf, real scale, real dif, complex, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

CTGSYL

But :

!>
!> CTGSYL résout l'équation de Sylvester généralisée :
!>
!>             A * R - L * B = scale * C            (1)
!>             D * R - L * E = scale * F
!>
!> où R et L sont des matrices inconnues de dimension m par n, (A, D), (B, E) et
!> (C, F) sont des paires de matrices données de dimensions m par m, n par n et m par n,
!> respectivement, avec des entrées complexes. A, B, D et E sont
!> triangulaires supérieurs (c'est-à-dire que (A,D) et (B,E) sont
!> sous forme de Schur généralisée).
!>
!> La solution (R, L) écrase (C, F). 0 <= SCALE <= 1
!> est un facteur de mise à l'échelle de sortie choisi pour éviter le débordement.
!>
!> En notation matricielle, (1) est équivalente à résoudre Zx = scale*b, où Z
!> est définie comme
!>
!>        Z = [ kron(In, A)  -kron(B**H, Im) ]        (2)
!>            [ kron(In, D)  -kron(E**H, Im) ],
!>
!> Ici Ix est la matrice identité de taille x et X**H est la transposée
!> conjuguée de X. Kron(X, Y) est le produit de Kronecker entre les
!> matrices X et Y.
!>
!> Si TRANS = 'C', y dans le système conjugué transposé Z**H *y = scale*b
!> est résolu, ce qui est équivalent à résoudre pour R et L dans
!>
!>             A**H * R + D**H * L = scale * C           (3)
!>             R * B**H + L * E**H = scale * -F
!>
!> Ce cas (TRANS = 'C') est utilisé pour calculer une estimation basée sur la norme un
!> de Dif[(A,D), (B,E)], la séparation entre les paires de matrices (A,D)
!> et (B,E), en utilisant CLACON.
!>
!> Si IJOB >= 1, CTGSYL calcule une estimation basée sur la norme de Frobenius de
!> Dif[(A,D),(B,E)]. C'est-à-dire le réciproque d'une borne inférieure sur le
!> réciproque de la plus petite valeur singulière de Z.
!>
!> Il s'agit d'un algorithme BLAS de niveau 3.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : résout l'équation de Sylvester généralisée (1).
!>          = 'C' : résout le système (3).
!>

IJOB

!>          IJOB est INTEGER
!>          Spécifie le type de fonctionnalité à effectuer.
!>          =0 : résout (1) uniquement.
!>          =1 : La fonctionnalité de 0 et 3.
!>          =2 : La fonctionnalité de 0 et 4.
!>          =3 : Seule une estimation de Dif[(A,D), (B,E)] est calculée.
!>              (la stratégie de look ahead est utilisée).
!>          =4 : Seule une estimation de Dif[(A,D), (B,E)] est calculée.
!>              (CGECON sur les sous-systèmes est utilisé).
!>          Non référencé si TRANS = 'C'.
!>

M

!>          M est INTEGER
!>          L'ordre des matrices A et D, et la dimension des lignes des
!>          matrices C, F, R et L.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices B et E, et la dimension des colonnes
!>          des matrices C, F, R et L.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA, M)
!>          La matrice triangulaire supérieure A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1, M).
!>

B

!>          B est un tableau COMPLEX, dimension (LDB, N)
!>          La matrice triangulaire supérieure B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1, N).
!>

C

!>          C est un tableau COMPLEX, dimension (LDC, N)
!>          À l'entrée, C contient le membre de droite de la première équation
!>          matricielle dans (1) ou (3).
!>          À la sortie, si IJOB = 0, 1 ou 2, C a été écrasée par
!>          la solution R. Si IJOB = 3 ou 4 et TRANS = 'N', C contient R,
!>          la solution obtenue lors du calcul de
!>          l'estimation de Dif.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1, M).
!>

D

!>          D est un tableau COMPLEX, dimension (LDD, M)
!>          La matrice triangulaire supérieure D.
!>

LDD

!>          LDD est INTEGER
!>          La dimension principale du tableau D. LDD >= max(1, M).
!>

E

!>          E est un tableau COMPLEX, dimension (LDE, N)
!>          La matrice triangulaire supérieure E.
!>

LDE

!>          LDE est INTEGER
!>          La dimension principale du tableau E. LDE >= max(1, N).
!>

F

!>          F est un tableau COMPLEX, dimension (LDF, N)
!>          À l'entrée, F contient le membre de droite de la deuxième équation
!>          matricielle dans (1) ou (3).
!>          À la sortie, si IJOB = 0, 1 ou 2, F a été écrasée par
!>          la solution L. Si IJOB = 3 ou 4 et TRANS = 'N', F contient L,
!>          la solution obtenue lors du calcul de
!>          l'estimation de Dif.
!>

LDF

!>          LDF est INTEGER
!>          La dimension principale du tableau F. LDF >= max(1, M).
!>

DIF

!>          DIF est REAL
!>          À la sortie, DIF est le réciproque d'une borne inférieure du
!>          réciproque de la fonction Dif, c'est-à-dire que DIF est une borne supérieure de
!>          Dif[(A,D), (B,E)] = sigma-min(Z), où Z est comme dans (2).
!>          SI IJOB = 0 ou TRANS = 'C', DIF n'est pas référencé.
!>

SCALE

!>          SCALE est REAL
!>          À la sortie, SCALE est le facteur de mise à l'échelle dans (1) ou (3).
!>          Si 0 < SCALE < 1, C et F contiennent les solutions R et L, respectivement,
!>          pour un système légèrement perturbé mais les matrices d'entrée A, B,
!>          D et E n'ont pas été modifiées. Si SCALE = 0, R et L
!>          contiendront les solutions du système homogène avec C = F = 0.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si IJOB = 1 ou 2 et TRANS = 'N', LWORK >= max(1,2*M*N).
!>
!>          Si LWORK = -1, une interrogation de l'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (M+N+2)
!>

INFO

!>          INFO est INTEGER
!>            =0 : sortie réussie
!>            <0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>            >0 : (A, D) et (B, E) ont des valeurs propres communes ou très proches.
!>
