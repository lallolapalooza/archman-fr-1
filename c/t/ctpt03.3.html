sous-routine ctpt03 (caractere uplo, caractere trans, caractere diag, entier n, entier nrhs, complexe, dimension( * ) ap, reel scale, reel, dimension( * ) cnorm, reel tscal, complexe, dimension( ldx, * ) x, entier ldx, complexe, dimension( ldb, * ) b, entier ldb, complexe, dimension( * ) work, reel resid)

CTPT03

Objectif :

!>
!> CTPT03 calcule le résidu de la solution d'un système triangulaire
!> d'équations mis à l'échelle A*x = s*b,  A**T *x = s*b,  ou  A**H *x = s*b,
!> lorsque la matrice triangulaire A est stockée au format compacté.  Ici A**T
!> désigne la transposée de A, A**H désigne la transposée conjuguée de
!> A, s est un scalaire, et x et b sont des matrices de N par NRHS.  Le ratio
!> de test est le maximum sur le nombre de seconds membres de
!>    norm(s*b - op(A)*x) / ( norm(op(A)) * norm(x) * EPS ),
!> où op(A) désigne A, A**T, ou A**H, et EPS est le epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N' : A *x = s*b     (Pas de transposée)
!>          = 'T' : A**T *x = s*b  (Transposée)
!>          = 'C' : A**H *x = s*b  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N' : Non-unitaire triangulaire
!>          = 'U' : Unitaire triangulaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices X et B.  NRHS >= 0.
!>

AP

!>          AP est tableau COMPLEX, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compactée
!>          par colonne dans un tableau linéaire.  La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

SCALE

!>          SCALE est REAL
!>          Le facteur d'échelle s utilisé pour résoudre le système
!>          triangulaire.
!>

CNORM

!>          CNORM est tableau REAL, dimension (N)
!>          Les normes 1 des colonnes de A, sans compter la diagonale.
!>

TSCAL

!>          TSCAL est REAL
!>          Le facteur d'échelle utilisé pour calculer les normes 1 dans CNORM.
!>          CNORM contient en fait les normes des colonnes de TSCAL*A.
!>

X

!>          X est tableau COMPLEX, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est tableau COMPLEX, dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est tableau COMPLEX, dimension (N)
!>

RESID

!>          RESID est REAL
!>          Le maximum sur le nombre de seconds membres de
!>          norm(op(A)*x - s*b) / ( norm(op(A)) * norm(x) * EPS ).
!>
