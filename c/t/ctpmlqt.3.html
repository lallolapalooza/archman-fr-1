sous-programme ctpmlqt (caractère side, caractère trans, entier m, entier n, entier k, entier l, entier mb, complexe, dimension( ldv, * ) v, entier ldv, complexe, dimension( ldt, * ) t, entier ldt, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldb, * ) b, entier ldb, complexe, dimension( * ) work, entier info)

CTPMLQT

Objectif:

!>
!> CTPMLQT applique une matrice unitaire complexe Q obtenue à partir d'un
!>  réflecteur bloc complexe H à une matrice complexe générale
!> C, qui consiste en deux blocs A et B.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H à Gauche ;
!>          = 'R': appliquer Q ou Q**H à Droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, appliquer Q ;
!>          = 'C':  Transposée conjuguée, appliquer Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice B. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice B. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>

L

!>          L est INTEGER
!>          L'ordre de la partie trapézoïdale de V.
!>          K >= L >= 0.  Voir Détails supplémentaires.
!>

MB

!>          MB est INTEGER
!>          La taille du bloc utilisée pour le stockage de T.  K >= MB >= 1.
!>          Cette valeur de MB doit être la même que celle utilisée pour générer T
!>          dans CTPLQT.
!>

V

!>          V est un tableau COMPLEXE, de dimension (LDV,K)
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CTPLQT dans B.  Voir Détails supplémentaires.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V. LDV >= K.
!>

T

!>          T est un tableau COMPLEXE, de dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs de bloc
!>          tels que retournés par CTPLQT, stockés sous forme de matrice MB par K.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T.  LDT >= MB.
!>

A

!>          A est un tableau COMPLEXE, de dimension
!>          (LDA,N) si SIDE = 'L' ou
!>          (LDA,K) si SIDE = 'R'
!>          À l'entrée, la matrice A de K lignes par N colonnes ou M lignes par K colonnes.
!>          À la sortie, A est écrasé par le bloc correspondant de
!>          Q*C ou Q**H*C ou C*Q ou C*Q**H.  Voir Détails supplémentaires.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,K) ;
!>          Si SIDE = 'R', LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEXE, de dimension (LDB,N)
!>          À l'entrée, la matrice B de M lignes par N colonnes.
!>          À la sortie, B est écrasé par le bloc correspondant de
!>          Q*C ou Q**H*C ou C*Q ou C*Q**H.  Voir Détails supplémentaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEXE. La dimension de WORK est
!>           N*MB si SIDE = 'L', ou  M*MB si SIDE = 'R'.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  exécution réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!>
!>  Les colonnes de la matrice pentagonale V contiennent les réflecteurs
!>  élémentaires H(1), H(2), ..., H(K) ; V est composée d'un bloc rectangulaire V1 et d'un
!>  bloc trapézoïdal V2 :
!>
!>        V = [V1] [V2].
!>
!>
!>  La taille du bloc trapézoïdal V2 est déterminée par le paramètre L,
!>  où 0 <= L <= K ; V2 est trapézoïdal inférieur, composé des L premières
!>  lignes d'une matrice triangulaire supérieure K par K.  Si L=K, V2 est triangulaire inférieure ;
!>  si L=0, il n'y a pas de bloc trapézoïdal, donc V = V1 est rectangulaire.
!>
!>  Si SIDE = 'L':  C = [A]  où A est K par N,  B est M par N et V est K par M.
!>                      [B]
!>
!>  Si SIDE = 'R':  C = [A B]  où A est M par K, B est M par N et V est K par N.
!>
!>  La matrice unitaire complexe Q est formée à partir de V et T.
!>
!>  Si TRANS='N' et SIDE='L', C est remplacé à la sortie par Q * C.
!>
!>  Si TRANS='C' et SIDE='L', C est remplacé à la sortie par Q**H * C.
!>
!>  Si TRANS='N' et SIDE='R', C est remplacé à la sortie par C * Q.
!>
!>  Si TRANS='C' et SIDE='R', C est remplacé à la sortie par C * Q**H.
!>
