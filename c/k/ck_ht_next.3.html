CK_HT_NEXT(3) Manuel des fonctions de bibliothèque CK_HT_NEXT(3)

NOM

ck_ht_next — itérer vers la prochaine entrée de table de hachage

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_ht.h>

bool
ck_ht_next(ck_ht_t *ht, ck_ht_iterator_t *iterator, ck_ht_entry_t **entry);

DESCRIPTION

La fonction ck_ht_next() incrémentera l'objet itérateur pointé par iterator pour pointer vers la prochaine entrée de table de hachage non vide. Si ck_ht_next() renvoie true, alors le pointeur pointé par entry sera initialisé à l'entrée de table de hachage actuelle pointée par l'objet iterator.

Il est attendu que iterator ait été initialisé en utilisant la fonction ck_ht_iterator_init(3) ou initialisé statiquement en utilisant CK_HT_ITERATOR_INITIALIZER.

VALEURS DE RETOUR

Si ck_ht_next() renvoie true, alors l'objet pointé par entry pointe vers une entrée de table de hachage valide. Si ck_ht_next() renvoie false, alors la valeur de l'objet pointé par entry est indéfinie.

ERREURS

Le comportement est indéfini si iterator ou ht ne sont pas initialisés.
