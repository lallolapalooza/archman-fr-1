CK_BITMAP_BUFFER(3) Manuel des fonctions de bibliothèque CK_BITMAP_BUFFER(3)

NOM

ck_bitmap_buffer — retourne le pointeur vers le tableau de bits

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_bitmap.h>

void *
ck_bitmap_buffer(ck_bitmap_t *bitmap);

DESCRIPTION

La fonction ck_bitmap_buffer() retourne un pointeur vers le tableau de bits réel. Pour les pointeurs ck_bitmap, le tableau de bits est de type CK_BITMAP_WORD[] et se compose de ck_bitmap_base(bitmap) / sizeof(CK_BITMAP_WORD) éléments. Sur les plates-formes 64 bits actuellement prises en charge, CK_BITMAP_WORD est uint64_t. Sur les plates-formes 32 bits actuellement prises en charge, CK_BITMAP_WORD est uint32_t.

VALEURS DE RETOUR

Cette fonction retourne une valeur non NULL.
