NOM

CK_COHORT_INSTANCE — déclarer une instance d'un type de cohorte

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_cohort.h>

CK_COHORT_INSTANCE(NOM_COHORTE nom_cohorte);

DESCRIPTION

L'utilisateur doit utiliser cette macro pour déclarer des instances des types de cohortes qu'ils ont définis. Par exemple, s'ils ont utilisé la macro CK_COHORT_PROTOTYPE pour définir un type de cohorte nommé foo, ils créeraient une instance de ce type comme suit :
CK_COHORT_INSTANCE(foo) cohorte;

Cette macro doit également être utilisée lors de l'allocation de mémoire pour les cohortes. Par exemple, pour allouer un bloc de 4 cohortes :
CK_COHORT_INSTANCE(foo) *cohortes = malloc(4 * sizeof(CK_COHORT_INSTANCE(foo)));
