CK_RHS_RESET(3) Manuel des fonctions de bibliothèque CK_RHS_RESET(3)

NOM

ck_rhs_reset — supprimer toutes les clés d'un ensemble de hachage

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_rhs.h>

bool
ck_rhs_reset(ck_rhs_t *hs);

DESCRIPTION

La fonction ck_rhs_reset(3) supprime toutes les clés stockées dans l'ensemble de hachage pointé par l'argument hs.

VALEUR DE RETOUR

En cas de succès, ck_rhs_reset(3) retourne vrai, sinon elle retourne faux en cas d'échec. Cette fonction échouera uniquement si un ensemble de hachage de remplacement ne peut pas être alloué en interne.

ERREURS

Le comportement est indéfini si hs n'est pas initialisé. Le comportement est indéfini si cette fonction est appelée par un thread qui n'est pas un écrivain.
