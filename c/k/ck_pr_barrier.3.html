NOM

ck_pr_barrier — barrière d'optimisation du compilateur

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_pr.h>

void
ck_pr_barrier(void);

DESCRIPTION

La fonction ck_pr_barrier(3) est utilisée pour désactiver le déplacement d'optimisation du code au-delà de l'invocation de la fonction.
