ck_pr_load(3) Manuel des fonctions de bibliothèque ck_pr_load(3)

NOM

ck_pr_load_ptr, ck_pr_load_double, ck_pr_load_uint, ck_pr_load_int, ck_pr_load_char, ck_pr_load_64, ck_pr_load_32, ck_pr_load_16, ck_pr_load_8 — opérations de chargement volatile atomiques

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPIS

#include <ck_pr.h>

void *
ck_pr_load_ptr(const void *cible);

double
ck_pr_load_double(const double *cible);

unsigned int
ck_pr_load_uint(const unsigned int *cible);

int
ck_pr_load_int(const int *cible);

char
ck_pr_load_char(const char *cible);

uint64_t
ck_pr_load_64(const uint64_t *cible);

uint32_t
ck_pr_load_32(const uint32_t *cible);

uint16_t
ck_pr_load_16(const uint16_t *cible);

uint8_t
ck_pr_load_8(const uint8_t *cible);

DESCRIPTION

La famille de fonctions ck_pr_load(3) charge atomiquement la valeur pointée par cible et la retourne. Cette famille de fonctions sert toujours de barrière implicite au compilateur et n'est pas susceptible d'être réordonnée par le compilateur.

VALEURS DE RETOUR

Cette famille de fonctions retourne la valeur contenue dans l'emplacement pointé par le premier argument.
