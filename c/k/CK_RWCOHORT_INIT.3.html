NOM

CK_RWCOHORT_INIT — initialise une instance d'un type de verrou de lecteur-rédacteur basé sur des cohortes

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_rwcohort.h>

CK_RWCOHORT_NEUTRAL_INIT(nom_cohorte cohort_name, verrou *lock);

CK_RWCOHORT_RP_INIT(nom_cohorte cohort_name, verrou *lock, unsigned int limite_attente);

CK_RWCOHORT_WP_INIT(nom_cohorte cohort_name, verrou *lock, unsigned int limite_attente);

DESCRIPTION

Cette macro initialise l'instance de verrou pointée par l'argument lock. Tant qu'une instance de verrou n'est pas initialisée à l'aide de la macro CK_RWCOHORT_INIT, toute opération impliquant celle-ci aura un comportement indéfini. Notez que l'argument limite_attente ne doit être utilisé qu'avec les verrous de préférence lecteur ou de préférence rédacteur. Pour les verrous neutres, cet argument doit être omis. Si vous n'êtes pas sûr de la valeur à utiliser pour l'argument limite_attente, vous devriez utiliser CK_RWCOHORT_STRATEGY_DEFAULT_LOCAL_WAIT_LIMIT.
