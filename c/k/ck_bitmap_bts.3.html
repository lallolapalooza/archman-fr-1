NOM

ck_bitmap_bts — définir le bit à l'index spécifié et récupérer sa valeur originale

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_bitmap.h>

bool
ck_bitmap_bts(ck_bitmap_t *bitmap, unsigned int n);

DESCRIPTION

ck_bitmap_bts() définit le bit à l'index spécifié par l'argument n à 1 et récupère sa valeur originale.

VALEURS DE RETOUR

Cette fonction renvoie la valeur originale du bit à l'index n dans bitmap.
