ck_rhs_set(3)

Paquet: libck

Licences: BSD, Apache, Custom

CK_RHS_SET(3) Manuel des fonctions de bibliothèque CK_RHS_SET(3)

NOM

ck_rhs_set — stocker une clé dans un ensemble de hachage

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_rhs.h>

bool
ck_rhs_set(ck_rhs_t *hs, unsigned long hash, const void *key, void **previous);

DESCRIPTION

La fonction ck_rhs_set(3) stockera la clé spécifiée par l'argument key dans l'ensemble de hachage pointé par l'argument hs. La clé spécifiée par key est attendue pour avoir la valeur de hachage spécifiée par l'argument hash (qui a été précédemment générée en utilisant la macro CK_RHS_HASH(3)).

Si l'appel à ck_rhs_set(3) a réussi, alors la clé spécifiée par key a été stockée avec succès dans l'ensemble de hachage pointé par hs. Si la clé existe déjà dans l'ensemble de hachage, elle est remplacée par key et la valeur précédente est stockée dans le pointeur void pointé par l'argument previous. Si previous est défini à NULL, alors key n'était pas un remplacement pour une entrée existante dans l'ensemble de hachage.

VALEURS DE RETOUR

En cas de succès, ck_rhs_set(3) retourne vrai, sinon elle retourne faux en cas d'échec.

ERREURS

Le comportement est indéfini si key ou hs ne sont pas initialisés. La fonction retournera également faux si l'ensemble de hachage n'a pas pu être agrandi pour accueillir l'insertion de la clé.
