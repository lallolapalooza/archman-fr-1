CK_HS_HASH(3) Manuel des fonctions de bibliothèque CK_HS_HASH(3)

NOM

CK_HS_HASH — invoquer la fonction de hachage avec la graine de l'ensemble de hachage

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_hs.h>

unsigned long
CK_HS_HASH(ck_hs_t *hs, ck_hs_hash_cb_t *hf, const void *key);

DESCRIPTION

La macro CK_HS_HASH(3) invoquera la fonction de hachage pointée par l'argument hf avec la valeur de graine associée à hs et le pointeur de clé spécifié par l'argument key.

VALEURS DE RETOUR

Cette fonction retournera la valeur retournée par la fonction hf.

ERREURS

Il est attendu que hs ait été précédemment initialisé via ck_hs_init(3).
