ck_hs_set(3)

Paquet: libck

CK_HS_SET(3) Manuel des fonctions de bibliothèque CK_HS_SET(3)

NOM

ck_hs_set — stocke une clé dans un ensemble de hachage

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_hs.h>

bool
ck_hs_set(ck_hs_t *hs, unsigned long hash, const void *key, void **previous);

DESCRIPTION

La fonction ck_hs_set(3) stockera la clé spécifiée par l'argument key dans l'ensemble de hachage pointé par l'argument hs. La clé spécifiée par key est censée avoir la valeur de hachage spécifiée par l'argument hash (qui a été précédemment générée à l'aide de la macro CK_HS_HASH(3)).

Si l'appel à ck_hs_set(3) a réussi, alors la clé spécifiée par key a été stockée avec succès dans l'ensemble de hachage pointé par hs. Si la clé existe déjà dans l'ensemble de hachage, elle est remplacée par key et la valeur précédente est stockée dans le pointeur void pointé par l'argument previous. Si previous est défini sur NULL, alors key n'était pas un remplacement pour une entrée existante dans l'ensemble de hachage.

VALEURS DE RETOUR

En cas de succès, ck_hs_set(3) retourne vrai et sinon retourne faux en cas d'échec.

ERREURS

Le comportement est indéfini si key ou hs ne sont pas initialisés. La fonction retournera également faux si l'ensemble de hachage n'a pas pu être agrandi pour accueillir l'insertion de la clé.
