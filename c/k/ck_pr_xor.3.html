ck_pr_xor(3) Manuel des fonctions de bibliothèque ck_pr_xor(3)

NOM

ck_pr_xor_ptr, ck_pr_xor_char, ck_pr_xor_uint, ck_pr_xor_int, ck_pr_xor_64, ck_pr_xor_32, ck_pr_xor_16, ck_pr_xor_8 — opérations xor bit-à-bit atomiques

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_pr.h>

void
ck_pr_xor_ptr(void *cible, uintptr_t delta);

void
ck_pr_xor_char(char *cible, char delta);

void
ck_pr_xor_uint(unsigned int *cible, unsigned int delta);

void
ck_pr_xor_int(int *cible, int delta);

void
ck_pr_xor_64(uint64_t *cible, uint64_t delta);

void
ck_pr_xor_32(uint32_t *cible, uint32_t delta);

void
ck_pr_xor_16(uint16_t *cible, uint16_t delta);

void
ck_pr_xor_8(uint8_t *cible, uint8_t delta);

DESCRIPTION

La famille de fonctions ck_pr_xor(3) calcule et stocke de manière atomique le résultat d'une opération xor bit-à-bit entre la valeur pointée par cible et delta dans la valeur pointée par cible.

VALEURS DE RETOUR

Cette famille de fonctions n'a pas de valeur de retour.
