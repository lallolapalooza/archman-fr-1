NOM

ck_pr_cas - Compare-and-swap atomiques des primitives de chargement

BIBLIOTHEQUE

Bibliothèque de synchronisation de Concurrency Kit.

#include <ck_pr.h>

SYNTAXE

bool ck_pr_cas(unsigned long long *target,
               unsigned long long new_value,
               unsigned long long *previous_value);
bool ck_pr_cas_32(unsigned int *target,
                  unsigned int new_value,
                  unsigned int *previous_value);
bool ck_pr_cas_16(unsigned short *target,
                  unsigned short new_value,
                  unsigned short *previous_value);
bool ck_pr_cas_8(unsigned char *target,
                 unsigned char new_value,
                 unsigned char *previous_value);
bool ck_pr_cas_value(unsigned long long *target,
                     unsigned long long new_value,
                     unsigned long long *previous_value,
                     unsigned long long *original_value);
bool ck_pr_cas_32_value(unsigned int *target,
                        unsigned int new_value,
                        unsigned int *previous_value,
                        unsigned int *original_value);
bool ck_pr_cas_16_value(unsigned short *target,
                        unsigned short new_value,
                        unsigned short *previous_value,
                        unsigned short *original_value);
bool ck_pr_cas_8_value(unsigned char *target,
                       unsigned char new_value,
                       unsigned char *previous_value,
                       unsigned char *original_value);

DESCRIPTION

Les primitives ck_pr_cas_* fournissent une opération atomique compare-and-swap. Elles comparent la valeur pointée par target avec la valeur pointée par previous_value. Si les valeurs sont égales, alors la valeur pointée par target est mise à jour avec la valeur spécifiée par new_value. Si la valeur dans target n'était pas égale à la valeur spécifiée par previous_value, alors aucune modification n'est apportée à la valeur dans target. La forme *_value de ces fonctions met inconditionnellement à jour original_value.

VALEURS DE RETOUR

Cette famille de fonctions renvoie true si la valeur dans target a été modifiée à la suite de l'opération. Sinon, elles renvoient false.
