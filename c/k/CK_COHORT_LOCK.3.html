NOM

CK_COHORT_LOCK — acquérir le verrou de cohorte

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_cohort.h>

CK_COHORT_LOCK(COHORT_NAME nom_cohorte, COHORT *cohorte, void *contexte_global, void *contexte_local);

DESCRIPTION

Cet appel tente d'acquérir les verrous local et global (si nécessaire) de cohorte. L'appel sera bloqué jusqu'à ce que les deux verrous soient acquis. contexte_global sera passé comme second argument à la fonction qui a été fournie comme argument global_lock_method à CK_COHORT_PROTOTYPE si cette méthode est appelée, et contexte_local sera passé à la fonction spécifiée par local_lock_method
