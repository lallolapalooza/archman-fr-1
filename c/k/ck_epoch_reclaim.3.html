CK_EPOCH_RECLAIM(3) Manuel des fonctions de bibliothèque CK_EPOCH_RECLAIM(3)

NOM

ck_epoch_reclaim — exécute immédiatement tous les rappels différés

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_epoch.h>

void
ck_epoch_reclaim(ck_epoch_record_t *record);

DESCRIPTION

La fonction ck_epoch_reclaim(3) exécutera sans condition tous les rappels qui ont été différés avec ck_epoch_call(3).

EXEMPLE

#include <ck_epoch.h>
#include <ck_stack.h>
#include <stdlib.h>

/*
 * epoch a été préalablement initialisé avec ck_epoch_init.
 */
ck_epoch_t *epoch;

void
function(void)
{
	ck_epoch_record_t *record;

	logically_delete(object);
	ck_epoch_call(epoch, record, &object->epoch_entry, destructor);

	/*
	 * Attendre qu'aucun thread ne puisse avoir de référence à l'objet
	 * que nous venons de supprimer.
	 */
	ck_epoch_synchronize(epoch, record);

	/*
	 * Exécuter tous les rappels différés.
	 */
	ck_epoch_reclaim(record);

	return;
}

VALEURS DE RETOUR

Cette fonction n'a pas de valeur de retour.
