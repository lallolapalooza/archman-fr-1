NOM

ck_pr_fas_ptr, ck_pr_fas_double, ck_pr_fas_char, ck_pr_fas_uint, ck_pr_fas_int, ck_pr_fas_64, ck_pr_fas_32, ck_pr_fas_16, ck_pr_fas_8 — opérations d'échange atomiques

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_pr.h>

void *
ck_pr_fas_ptr(void *target, void *new_value);

double
ck_pr_fas_double(double *target, double new_value);

ck_pr_fas_char(char *target, char new_value);

unsigned int
ck_pr_fas_uint(unsigned int *target, unsigned int new_value);

ck_pr_fas_32(uint32_t *target, uint32_t new_value);

uint16_t
ck_pr_fas_16(uint16_t *target, uint16_t new_value);

uint8_t
ck_pr_fas_8(uint8_t *target, uint8_t new_value);

DESCRIPTION

La famille de fonctions ck_pr_fas(3) récupère atomiquement la valeur pointée par target et remplace la valeur pointée par target par la valeur spécifiée par new_value.

VALEURS DE RETOUR

Cette fonction renvoie la valeur pointée par target au moment de l'invocation de l'opération, avant qu'elle ne soit atomiquement remplacée par new_value.
