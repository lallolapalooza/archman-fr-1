NOM

ck_ring_dequeue_spsc — retire un pointeur d'une FIFO bornée

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_ring.h>

bool
ck_ring_dequeue_spsc(ck_ring_t *ring, ck_ring_buffer_t *buffer, void *result);

DESCRIPTION

La fonction ck_ring_dequeue_spsc(3) retire un pointeur du tampon borné pointé par ring en mode FIFO. Le pointeur est stocké dans le pointeur pointé par result. Le tampon pointé par buffer doit être unique à ring et pointer vers un tableau de ck_ring_buffer_t de longueur suffisante (selon la puissance de 2 des éléments dans le tampon). Le découplage de l'anneau par rapport au tampon sert à traiter des cas d'utilisation impliquant plusieurs espaces d'adressage et le DMA, entre autres. Si vous êtes sur des plateformes non-POSIX ou si vous souhaitez une stricte conformité avec C, il est recommandé de passer un pointeur de type void ** pour result. Cette fonction peut être appelée sans verrouillage pour une invocation concurrente de ck_ring_dequeue_spsc(3) et jusqu'à une invocation concurrente de ck_ring_enqueue_spsc(3). Cette fonction offre des garanties de progression sans attente.

EXEMPLE

#include <ck_ring.h>

/* Cet anneau a été précédemment initialisé avec ck_ring_init. */
ck_ring_t ring;

/* L'anneau a été initialisé pour 1023 éléments. */
ck_ring_buffer_t buffer[1024];

void
dequeue(void)
{
	void *result;

	/* Retirer de l'anneau jusqu'à ce qu'il soit vide. */
	while (ck_ring_dequeue_spsc(&ring, &buffer, &result) == true) {
		/*
		 * result contient le plus ancien pointeur dans ring
		 * puisque l'opération de retrait a retourné true.
		 */
		operation(result);
	}

	/* Un anneau vide a été rencontré, quitter. */
	return;
}

VALEURS DE RETOUR

La fonction retourne vrai si le tampon n'était pas vide. Le résultat de l'opération de retrait est stocké dans la valeur pointée par result. La fonction retournera faux si le tampon était vide et la valeur dans result sera indéfinie.
