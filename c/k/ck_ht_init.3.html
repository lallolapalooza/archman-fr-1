DESCRIPTIO

N

La fonction ck_ht_init() initialise la table de hachage pointée par le pointeur ht

.

L'argument mode spécifie le type de paires clé-valeur à stocker dans la table de hachage. La valeur de mode peut être l'une des suivantes

:
CK_HT_MODE_BYTESTR
ING
La table de hachage est destinée à stocker des pointeurs clé-valeur où la clé est une région de mémoire d'une longueur maximale de 65536 octets. Ce pointeur sera déréférencé lors des opérations sur la table de hachage pour la comparaison des clés. Les entrées de cette table de hachage doivent être manipulées à l'aide des fonctions ck_ht_entry_empty(3), ck_ht_entry_key(3), ck_ht_entry_key_length(3), ck_ht_entry_value(3), et ck_ht_entry_set(3). Tenter une opération sur la table de hachage avec une clé de valeur NULL ou (void *)UINTPTR_MAX entraînera un comportement
indéfini.
CK_HT_MODE_DIR
ECT
La table de hachage est destinée à stocker des pointeurs clé-valeur où la clé est un champ de largeur fixe compatible avec le type uintptr_t. La clé sera directement comparée aux autres clés pour l'égalité. Les entrées de cette table de hachage doivent être manipulées à l'aide des fonctions ck_ht_entry_empty(3), ck_ht_entry_key_direct(3), ck_ht_entry_value_direct(3) et ck_ht_entry_set_direct(3). Tenter une opération sur la table de hachage av
ec une clé de valeur 0 ou UINTPTR_
MAX entraînera un comportement indéfini.

En plus de cela, l'utilisateur peut combiner par bits le drapeau mode avec CK_HT_WORKLOAD_DELETE pour indiquer que la table de hachage devra gérer une charge de travail lourde en suppressions, auquel cas des bornes plus strictes sur la latence peuvent être fournies au prix d'une utilisation mémoire d'environ 13 % plus élevée. L'argument hash_function est un pointeur vers une fonction de hachage spécifiée par l'utilisateur. Elle est facultative, si NULL est spécifié, alors l'implémentation par défaut de la fonction de hachage sera utilisée ( ck_ht_hash(3) ). Une fonction de hachage spécifiée par l'utilisateur prend quatre arguments. L'argument h est un pointeur vers un objet valeur de hachage. La fonction de hachage doit mettre à jour la valeur de l'objet de type uint64_t contenue dans l'objet pointé par h. L'argument key est un pointeur vers une clé, l'argument key_length est la longueur de la clé et l'argument seed est la graine initiale associée à la table de hachage. Cette graine initiale est spécifiée par l'utilisateur dans ck_ht_ini

t(3).

L'argument allocator est un pointeur vers une structure contenant les pointeurs de fonction malloc et free qui définissent respectivement les fonctions d'allocation et de destruction mémoire à utiliser par la table de hachage en cours d'initialisation

.

L'argument capacity représente le nombre initial de paires clé-valeur que la table de hachage est censée contenir. Cet argument est simplement un indice et l'implémentation sous-jacente est libre d'allouer plus ou moins de mémoire que nécessaire pour contenir le nombre d'entrées spécifié par

capacity.

L'argument seed spécifie la graine initiale utilisée par la fonction de hachage sous-jacente. L'utilisateur est libre de choisir une valeur de son

choix.

La table de hachage peut être accédée en toute sécurité par plu

sieurs lecteurs en présence d'un écrivain concurrent. Le com
portement est indéfini en présence d'écrivains concurrents.

RETOURNÉES

En cas de succès ck_ht_init() renvoie la valeur true et renvoie sinon la valeur false pour indiq

uer une
erreur.

ERREUR

S

Le comportement de ck_ht_init() est indéfini si ht n'est pas un pointeur vers un objet ck_

ht_t.
