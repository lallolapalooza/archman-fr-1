CK_EPOCH_SYNCHRONIZE(3) Manuel des fonctions de bibliothèque CK_EPOCH_SYNCHRONIZE(3)

NOM

ck_epoch_synchronize — bloquer jusqu'à ce qu'une période de grâce soit détectée

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_epoch.h>

void
ck_epoch_synchronize(ck_epoch_record_t *record);

DESCRIPTION

La fonction ck_epoch_synchronize(3) bloquera l'appelant jusqu'à ce qu'une période de grâce soit détectée, selon la sémantique de la récupération d'époque. Il n'est pas sûr d'appeler cette fonction sur un enregistrement qui se trouve dans une section active. Tous les objets nécessitant une récupération de mémoire sûre qui sont logiquement supprimés sont sûrs pour une suppression physique suite à un appel à ck_epoch_synchronize(3). Si vous avez besoin que tous les rappels soient distribués, il est suggéré d'utiliser ck_epoch_barrier(3) à la place ou de suivre un appel à ck_epoch_synchronize(3) avec ck_epoch_reclaim(3).

EXEMPLE

#include <ck_epoch.h>
#include <ck_stack.h>
#include <stdlib.h>

/*
 * epoch a été préalablement initialisé avec ck_epoch_init.
 * stack a été préalablement initialisé avec ck_stack_init.
 */
ck_epoch_t *epoch;
ck_stack_t *stack;

void
function(void)
{
	ck_epoch_record_t *record;
	ck_stack_entry_t *s;

	record = malloc(sizeof *record);
	ck_epoch_register(&epoch, record, NULL);

	/*
	 * Nous utilisons une section d'époque ici pour garantir qu'aucun
	 * nœud dans la pile ne soit supprimé pendant que nous y accédons.
	 * Ceci est nécessaire ici car il y a plusieurs écrivains.
	 * S'il n'y avait qu'un seul thread dépilant cette pile,
	 * il n'y aurait pas besoin de ck_epoch_begin/ck_epoch_end.
	 */
	ck_epoch_begin(record);

	/* Supprimer logiquement un objet. */
	s = ck_stack_pop_upmc(stack);

	ck_epoch_end(record);

	/*
	 * Attendre jusqu'à ce qu'aucun thread ne puisse potentiellement avoir une référence à
	 * l'objet que nous venons de dépiler (supposer que tous les threads exécutent simplement
	 * ck_stack_pop_upmc).
	 */
	ck_epoch_synchronize(record);

	/* Il est maintenant sûr de supprimer physiquement l'objet. */
	free(s);
	return;
}

VALEURS DE RETOUR

Cette fonction n'a pas de valeur de retour.

ERREURS

L'objet pointé par .Fa record doit avoir été préalablement enregistré via ck_epoch_register(3).
