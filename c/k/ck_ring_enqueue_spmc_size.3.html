CK_RING_ENQUEUE_SPMC_SIZE(3) Manuel des fonctions de bibliothèque CK_RING_ENQUEUE_SPMC_SIZE(3)

NOM

ck_ring_enqueue_spmc_size — met en file d'attente un pointeur dans un FIFO borné et renvoie la taille du tampon

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_ring.h>

bool
ck_ring_enqueue_spmc_size(ck_ring_t *ring, ck_ring_buffer_t *buffer, void *entry, unsigned int *length);

DESCRIPTION

La fonction ck_ring_enqueue_spmc(3) met en file d'attente le pointeur entry dans le tampon borné pointé par ring selon le mode FIFO. Le tampon pointé par buffer doit être unique à ring et pointer vers un tableau de ck_ring_buffer_t de longueur suffisante (selon la puissance de 2 des éléments dans le tampon). Le découplage de l'anneau du tampon sert à répondre à des cas d'utilisation impliquant plusieurs espaces d'adressage et le DMA, entre autres. Si vous êtes sur des plateformes non-POSIX ou si vous souhaitez une conformité stricte avec C, il est recommandé de passer un pointeur de type void ** pour entry. Cette fonction peut être appelée sans verrouillage pour UINT_MAX invocations concurrentes de ck_ring_dequeue_spmc(3) ou ck_ring_trydequeue_spmc(3). Cette fonction fournit des garanties de progression sans attente pour une invocation active.

EXEMPLE

#include <ck_ring.h>

/* Cet anneau a été précédemment initialisé avec ck_ring_init. */
ck_ring_t ring;

/* L'anneau a été initialisé pour 1023 éléments. */
ck_ring_buffer_t buffer[1024];

void
enqueue(void)
{
	void *entry = some_object;
	unsigned int length;

	/* Tenter de mettre en file d'attente le pointeur vers some_object dans buffer. */
	if (ck_ring_enqueue_spmc_size(&ring, &buffer, &entry, &length) == false) {
		/*
		 * Le tampon était plein et l'opération de mise en file d'attente
		 * a échoué.
		 */
		return;
	}

	/*
	 * Si entry était le 101ème pointeur ou plus dans le tampon,
	 * faire quelque chose.
	 */
	if (length > 100) {
		do_something;
	}

	return;
}

VALEURS DE RETOUR

La fonction renvoie true si la valeur de entry a été mise en file d'attente avec succès dans ring. La fonction renvoie false si la valeur de entry n'a pas pu être mise en file d'attente, ce qui n'arrive que si ring était plein. Le nombre d'éléments dans le tampon par rapport au moment où entry est mis en file d'attente est stocké dans l'entier pointé par length.
