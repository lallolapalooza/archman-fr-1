CK_EPOCH_UNREGISTER(3) Manuel des fonctions de bibliothèque CK_EPOCH_UNREGISTER(3)

NOM

ck_epoch_unregister — désenregistrer un thread pour la récupération d'époque

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_epoch.h>

void
ck_epoch_unregister(ck_epoch_record_t *record);

DESCRIPTION

La fonction ck_epoch_unregister(3) permet au enregistrement pointé par le pointeur record d'être utilisé comme valeur de retour par la fonction ck_epoch_recycle(3). Cet enregistrement peut maintenant être utilisé par un autre thread d'exécution. Le comportement est indéfini si l'objet pointé par record est modifié d'une quelconque manière, même après un appel à la fonction ck_epoch_unregister(3).

VALEURS DE RETOUR

Cette fonction n'a pas de valeur de retour.
