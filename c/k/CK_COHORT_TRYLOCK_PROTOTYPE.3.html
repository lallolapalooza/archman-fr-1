CK_COHORT_TRYLOCK_PROTOTYPE(3) Manuel des fonctions de bibliothèque CK_COHORT_TRYLOCK_PROTOTYPE(3)

NOM

CK_COHORT_TRYLOCK_PROTOTYPE — définir un type de cohorte avec des types de verrou spécifiés

BIBLIOTHÉQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_cohort.h>

CK_COHORT_TRYLOCK_PROTOTYPE(COHORT_NAME nom_cohorte, LOCK_FXN methode_verrou_global, LOCK_FXN methode_deverrou_global, BOOL_LOCK_FXN methode_global_verrouillee, BOOL_LOCK_FXN methode_verrou_global_essai, LOCK_FXN methode_verrou_local, LOCK_FXN methode_deverrou_local, BOOL_LOCK_FXN methode_locale_verrouillee, BOOL_LOCK_FXN methode_verrou_local_essai);

DESCRIPTION

Le fichier d'en-tête ck_cohort.h ne définit aucun type de cohorte. Au lieu de cela, l'utilisateur doit utiliser les macros CK_COHORT_PROTOTYPE ou CK_COHORT_TRYLOCK_PROTOTYPE pour définir les types qu'il souhaite utiliser. Il doit utiliser CK_COHORT_TRYLOCK_PROTOTYPE s'il souhaite que son type de cohorte prenne en charge les opérations de trylock. La macro CK_COHORT_TRYLOCK_PROTOTYPE prend les arguments suivants :

nom_cohorte : Un identifiant utilisé pour ce type de cohorte. Il devra être passé à chacune des autres macros CK_COHORT.
methode_verrou_global : La méthode qui doit être appelée pour acquérir le verrou global.
methode_deverrou_global : La méthode qui doit être appelée pour relâcher le verrou global.
methode_global_verrouillee : Cette méthode doit retourner vrai si le verrou global est acquis par un thread.
methode_verrou_global_essai : La méthode qui doit être appelée pour tenter d'acquérir le verrou global. Elle ne doit pas bloquer et retourner vrai si le verrou a été acquis avec succès.
methode_verrou_local : La méthode qui doit être appelée pour acquérir le verrou local.
methode_deverrou_local : La méthode qui doit être appelée pour relâcher le verrou local.
methode_locale_verrouillee : Cette méthode doit retourner vrai si le verrou local est acquis par un thread.
methode_verrou_local_essai : La méthode qui doit être appelée pour tenter d'acquérir le verrou local. Elle ne doit pas bloquer et retourner vrai si le verrou a été acquis avec succès.

Les instances du type de cohorte défini peuvent être déclarées comme suit :
CK_COHORT_INSTANCE(nom_cohorte) cohorte;
