CK_PR_FENCE_LOAD_STORE(3) Manuel des fonctions de bibliothèque CK_PR_FENCE_LOAD_STORE(3)

NOM

ck_pr_fence_load_store — force l'ordonnancement des opérations de lecture par rapport aux opérations d'écriture

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_pr.h>

void
ck_pr_fence_load_store(void);

void
ck_pr_fence_strict_load_store(void);

DESCRIPTION

Cette fonction force l'ordonnancement des opérations de lecture et des opérations de ck_pr_load(3) par rapport aux opérations d'écriture qui les précèdent ou les suivent. Les opérations d'écriture qui ont été validées sur des processeurs distants et reçues par le processeur appelant avant l'invocation de ck_pr_fence_load_store() ne seront également visibles qu'après un appel à la famille de fonctions ck_pr_fence_load. Cette fonction sert toujours de barrière implicite du compilateur. Sur les architectures avec CK_MD_TSO ou CK_MD_PSO spécifié (ordonnancement total des écritures et ordonnancement partiel des écritures respectivement), cette opération sert uniquement de barrière du compilateur et aucune instruction de clôture ne sera émise. Pour forcer l'émission inconditionnelle d'une clôture de lecture, utilisez ck_pr_fence_strict_load_store(). Les architectures implémentant CK_MD_RMO émettent toujours une clôture.

EXEMPLE

#include <ck_pr.h>

static unsigned int a;
static unsigned int b;

void
function(void)
{
	unsigned int snapshot_a;

	snapshot_a = ck_pr_load_uint(&a);

	/*
	 * Garantir que la lecture de "a" est terminée
	 * avant l'écriture dans "b".
	 */
	ck_pr_fence_load_store();
	ck_pr_store_uint(&b, 1);

	return;
}

VALEUR DE RETOUR

Cette fonction n'a pas de valeur de retour.
