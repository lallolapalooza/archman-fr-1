CK_HT_GET_SPMC(3) Manuel des fonctions de bibliothèque CK_HT_GET_SPMC(3)

NOM

ck_ht_get_spmc — charger une paire clé-valeur d'une table de hachage

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_ht.h>

bool
ck_ht_get_spmc(ck_ht_t *ht, ck_ht_hash_t h, ck_ht_entry_t *entry);

DESCRIPTION

La fonction ck_ht_get_spmc() renverra la valeur associée à la clé spécifiée dans l'argument entry dans la table de hachage pointée par l'argument ht. La clé spécifiée dans entry est censée avoir la valeur de hachage spécifiée par l'argument h.

Si ht a été créé avec CK_HT_MODE_BYTESTRING, alors entry doit avoir été initialisé avec les fonctions ck_ht_entry_set_key(3) ou ck_ht_entry_set(3). Si ht a été créé avec CK_HT_MODE_DIRECT, alors entry doit avoir été initialisé avec les fonctions ck_ht_entry_key_set_direct(3) ou ck_ht_entry_set_direct(3).

Il est attendu que h ait été initialisé avec ck_ht_hash(3) si ht a été créé avec CK_HT_MODE_BYTESTRING. Si ht a été initialisé avec CK_HT_MODE_DIRECT, alors il est attendu que h ait été initialisé avec la fonction ck_ht_hash_direct(3).

Si l'appel à ck_ht_get_spmc() a réussi, alors la paire clé-valeur dans entry a été trouvée avec succès dans la table de hachage pointée par h et échouera si la clé spécifiée dans entry n'existe pas dans la table de hachage. En cas de succès, entry contiendra la paire clé-valeur trouvée dans la table de hachage pointée par l'argument ht.

Si ht a été initialisé avec CK_HT_MODE_BYTESTRING, alors la paire clé/valeur dans entry peut être extraite en utilisant les fonctions ck_ht_entry_key(3) et ck_ht_entry_value(3). La longueur de la clé peut être extraite en utilisant la fonction ck_ht_entry_key_length(3).

Si ht a été initialisé avec CK_HT_MODE_DIRECT, alors la paire clé/valeur dans entry peut être extraite en utilisant les fonctions ck_ht_entry_key_direct(3) et ck_ht_entry_value_direct(3).

Cette fonction peut être appelée en toute sécurité en présence d'un écrivain concurrent.

VALEURS DE RETOUR

En cas de succès, ck_ht_get_spmc() renvoie true. En cas de succès, entry contiendra la paire clé/valeur telle que trouvée dans la table de hachage. Sinon, la fonction renvoie false en cas d'échec.

ERREURS

Le comportement est indéfini si entry ou ht ne sont pas initialisés. La fonction renverra false si la clé spécifiée dans entry n'a pas été trouvée dans la table de hachage.
