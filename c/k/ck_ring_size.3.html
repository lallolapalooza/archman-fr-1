CK_RING_SIZE(3) Manuel des fonctions de bibliothèque CK_RING_SIZE(3)

NOM

ck_ring_size — retourne le nombre de pointeurs mis en file d'attente dans un anneau FIFO borné

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_ring.h>

unsigned int
ck_ring_size(ck_ring_t *ring);

DESCRIPTION

La fonction ck_ring_size(3) retourne le nombre de pointeurs actuellement mis en file d'attente dans le tampon pointé par ring.

VOIR AUSSI
