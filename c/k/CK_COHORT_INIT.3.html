CK_COHORT_INIT(3) Manuel des fonctions de bibliothèque CK_COHORT_INIT(3)

NOM

CK_COHORT_INIT — initialise une instance d'un type de cohorte

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_cohort.h>

CK_COHORT_INIT(COHORT_NAME nom_cohorte, COHORT *cohorte, void *verrou_global, void *verrou_local, unsigned int limite_passage);

DESCRIPTION

Jusqu'à ce qu'une instance de cohorte soit initialisée à l'aide de la macro CK_COHORT_INIT, toute opération impliquant celle-ci aura un comportement indéfini. Après l'appel de cette macro, la cohorte pointée par l'argument cohorte utilisera le verrou pointé par verrou_global comme son verrou global et le verrou pointé par verrou_local comme son verrou local.

La cohorte abandonnera son verrou global après limite_passage acquisitions consécutives de son verrou local, même si d'autres threads attendent. Si vous n'êtes pas sûr de la valeur à utiliser pour l'argument limite_passage, vous devriez utiliser CK_COHORT_DEFAULT_LOCAL_PASS_LIMIT.
