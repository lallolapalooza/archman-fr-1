ck_hs_move(3)

Paquet: libck

Licences: BSD, Apache, Custom

CK_HS_MOVE(3) Manuel des fonctions de bibliothèque CK_HS_MOVE(3)

NOM

ck_hs_move — déplacer un ensemble de hachage vers un autre

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_hs.h>

bool
ck_hs_move(ck_hs_t *destination, ck_hs_t *source, ck_hs_hash_cb_t *hash_cb, ck_hs_compare_cb_t *compare_cb, struct ck_malloc *m);

DESCRIPTION

La fonction ck_hs_move(3) initialisera source à partir de destination. La fonction de hachage sera définie sur hash_cb, la fonction de comparaison sur compare_cb et les rappels d'allocateur sur m. Les modifications ultérieures apportées à source entraîneront un comportement indéfini. Les opérations concurrente ck_hs_get(3) et ck_hs_fas(3) sur source sont autorisées jusqu'à la prochaine opération d'écriture sur destination.

Cette opération déplace la propriété d'un objet d'ensemble de hachage à un autre et réaffecte les fonctions de rappel à des valeurs spécifiées par le développeur. Cela permet une configuration dynamique des rappels d'allocation et est nécessaire pour les cas d'utilisation impliquant du code exécutable qui peut être démappé sous l'ensemble de hachage.

VALEURS DE RETOUR

En cas de succès, ck_hs_move(3) retourne vrai, sinon elle retourne faux pour indiquer une erreur.
