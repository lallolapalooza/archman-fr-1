ck_pr_stall(3) Manuel des fonctions de bibliothèque ck_pr_stall(3)

NOM

ck_pr_stall — primitive d'attente active

BIBLIOTHÉQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_pr.h>

void
ck_pr_stall(void);

DESCRIPTION

La fonction ck_pr_stall(3) doit être utilisée à l'intérieur des chemins de nouvelle tentative des boucles d'attente active. Elle sert non seulement de barrière compilateur, mais sur certaines architectures, elle émet des instructions qui économisent des cycles.

EXEMPLE

#include <ck_pr.h>

static int ready = 0;

void
function(void)
{

	/* Attendre activement jusqu'à ce que ready soit différent de zéro. */
	while (ck_pr_load_int(&ready) == 0)
		ck_pr_stall();

	return;
}
