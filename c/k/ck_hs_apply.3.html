CK_HS_APPLY(3) Manuel des fonctions de bibliothèque CK_HS_APPLY(3)

NOM

ck_hs_apply — appliquer une fonction à une valeur d'ensemble de hachage

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_hs.h>

void *
ck_hs_apply_fn_t(void *key, void *closure);

bool
ck_hs_apply(ck_hs_t *hs, unsigned long hash, const void *key, ck_hs_apply_fn_t *function, void *argument);

DESCRIPTION

La fonction ck_hs_apply(3) recherchera l'emplacement de l'ensemble de hachage associé à key et le transmettra à la fonction pointée par function pour une action ultérieure. Ce rappel peut supprimer ou remplacer la valeur en retournant respectivement NULL ou un pointeur vers un autre objet avec une clé identique. Le premier argument passé à function est un pointeur vers l'objet trouvé dans l'ensemble de hachage et le second argument est le pointeur argument passé à ck_hs_apply(3). Si le pointeur retourné par function est équivalent au premier argument, aucune modification n'est apportée à l'ensemble de hachage.

VALEURS DE RETOUR

En cas de succès, ck_hs_apply(3) retourne vrai et sinon retourne faux en cas d'échec.
