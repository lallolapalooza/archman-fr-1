CK_RING_ENQUEUE_SPSC(3) Manuel des fonctions de bibliothèque CK_RING_ENQUEUE_SPSC(3)

NOM

ck_ring_enqueue_spsc — enfile un pointeur dans une FIFO bornée

BIBLIOTHEQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_ring.h>

bool
ck_ring_enqueue_spsc(ck_ring_t *ring, ck_ring_buffer_t *buffer, void *entry);

DESCRIPTION

La fonction ck_ring_enqueue_spsc(3) enfile le pointeur entry dans le tampon borné pointé par ring selon le mode FIFO (Premier entré, Premier sorti). Le tampon pointé par buffer doit être unique pour ring et pointer vers un tableau de `ck_ring_buffer_t` de longueur suffisante (selon la puissance de 2 des éléments dans le tampon). Le découplage de l'anneau (`ring`) du tampon (`buffer`) sert à traiter des cas d'utilisation impliquant plusieurs espaces d'adressage et le DMA, entre autres. Si vous êtes sur des plateformes non-POSIX ou si vous souhaitez une conformité stricte avec C, il est recommandé de passer un pointeur de type `void **` pour entry. Cette fonction peut être appelée sans verrouillage pour une invocation concurrente jusqu'à une invocation de ck_ring_dequeue_spsc(3). Cette fonction fournit des garanties de progression sans attente (wait-free).

EXEMPLE

#include <ck_ring.h>

/* Cet anneau a été précédemment initialisé avec ck_ring_init. */
ck_ring_t ring;

/* L'anneau a été initialisé pour 1023 éléments. */
ck_ring_buffer_t buffer[1024];

void
enqueue(void)
{
	void *entry = some_object;

	/* Tentative d'enfiler le pointeur vers some_object dans le tampon. */
	if (ck_ring_enqueue_spsc(&ring, &buffer, &entry) == false) {
		/*
		 * Le tampon était plein et l'opération d'enfilement
		 * a échoué.
		 */
		return;
	}

	/* L'opération d'enfilement s'est terminée avec succès. */
	return;
}

VALEURS DE RETOUR

La fonction retourne `true` si la valeur de entry a été enfilée avec succès dans ring. La fonction retournera `false` si la valeur de entry n'a pas pu être enfilée, ce qui ne se produit que si ring était plein.
