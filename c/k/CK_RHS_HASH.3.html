CK_RHS_HASH(3) Manuel des fonctions de bibliothèque CK_RHS_HASH(3)

NOM

CK_RHS_HASH — invoque la fonction de hachage avec la graine de l'ensemble de hachage

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_rhs.h>

unsigned long
CK_RHS_HASH(ck_rhs_t *hs, ck_rhs_hash_cb_t *hf, const void *key);

DESCRIPTION

La macro CK_RHS_HASH(3) invoquera la fonction de hachage pointée par l'argument hf avec la valeur de graine associée à hs et le pointeur de clé spécifié par l'argument key.

VALEURS DE RETOUR

Cette fonction retournera la valeur retournée par la fonction hf.

ERREURS

Il est attendu que hs ait été précédemment initialisé via ck_rhs_init(3).

VOIR AUSSI
