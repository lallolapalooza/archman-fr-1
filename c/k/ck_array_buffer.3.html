CK_ARRAY_BUFFER(3) Manuel des fonctions de bibliothèque CK_ARRAY_BUFFER(3)

NOM

ck_array_buffer — retourne la longueur et le pointeur d'un tableau de pointeurs visibles par le lecteur

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_array.h>

void *
ck_array_buffer(ck_array_t *array, unsigned int *length);

DESCRIPTION

La fonction ck_array_buffer(3) retourne un pointeur vers le tableau de pointeurs actuellement visibles par les lecteurs après la dernière opération de validation dans array. L'entier non signé pointé par length est mis à jour pour refléter la longueur du tableau.

VALEURS DE RETOUR

Cette fonction retourne un pointeur vers un tableau de pointeurs.

VOIR AUSSI

ck_array_commit(3), ck_array_put(3), ck_array_put_unique(3), ck_array_remove(3), ck_array_init(3) ck_array_deinit(3), ck_array_length(3), ck_array_initialized(3), CK_ARRAY_FOREACH(3)
