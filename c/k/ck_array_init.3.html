CK_ARRAY_INIT(3) Manuel des fonctions de bibliothèque CK_ARRAY_INIT(3)

NOM

ck_array_init — initialiser un tableau de pointeurs

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_array.h>

bool
ck_array_init(ck_array_t *array, unsigned int mode, struct ck_malloc *allocator, unsigned int initial_length);

DESCRIPTION

La fonction ck_array_init(3) initialise le tableau pointé par l'argument array. La valeur du mode doit être CK_ARRAY_MODE_SPMC. L'argument allocator doit pointer vers une structure de données ck_malloc avec des pointeurs de fonction valides et non NULL initialisés pour malloc, free et realloc. initial_length spécifie la longueur initiale du tableau. La valeur de initial_length doit être supérieure ou égale à 2. Un tableau permet une opération de mise en place ou de suppression concurrente en présence d'un nombre quelconque d'opérations CK_ARRAY_FOREACH concurrentes.

VALEURS DE RETOUR

Cette fonction renvoie vrai si le tableau a été créé avec succès. Elle renvoie faux si la création a échoué. L'échec peut survenir en raison d'échecs d'allocation de mémoire interne ou d'arguments invalides.
