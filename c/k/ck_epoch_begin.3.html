CK_EPOCH_BEGIN(3) Manuel des fonctions de bibliothèque CK_EPOCH_BEGIN(3)

NOM

ck_epoch_begin — débuter un segment d'exécution protégé par époque

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_epoch.h>

void
ck_epoch_begin(ck_epoch_record_t *record, ck_epoch_section_t *section);

DESCRIPTION

La fonction ck_epoch_begin(3) marque le début d'une section de code protégée par époque. Une section de code protégée par époque est délimitée par un appel à la fonction ck_epoch_end(3). Bien que la récursion soit autorisée pour les sections protégées par époque, les appels récursifs seront associés à l'ck_epoch_begin(3) qui se trouve en haut de la pile d'appels. Si une section est passée, alors la récursion sur un enregistrement entraînera le rafraîchissement de l'époque à l'entrée de chaque section protégée.

VALEUR DE RETOUR

Cette fonction n'a pas de valeur de retour.

ERREURS

L'objet pointé par epoch doit avoir été préalablement initialisé via ck_epoch_init(3). L'objet pointé par record doit avoir été préalablement enregistré via ck_epoch_register(3).
