CK_BITMAP_RESET(3) Manuel des fonctions de bibliothèque CK_BITMAP_RESET(3)

NOM

ck_bitmap_reset — réinitialise le bit à l'index spécifié

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_bitmap.h>

void
ck_bitmap_reset(ck_bitmap_t *bitmap, unsigned int n);

DESCRIPTION

La fonction ck_bitmap_reset() réinitialise le bit à l'offset spécifié par l'argument n à 0.

VALEUR DE RETOUR

Cette fonction n'a pas de valeur de retour.
