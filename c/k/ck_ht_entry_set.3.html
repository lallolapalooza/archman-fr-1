CK_HT_ENTRY_SET(3) Manuel des fonctions de bibliothèque CK_HT_ENTRY_SET(3)

NOM

ck_ht_entry_set — initialiser une paire clé-valeur

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_ht.h>

void
ck_ht_entry_set(ck_ht_entry_t *entry, ck_ht_hash_t h, const void *key, uint16_t key_length, const void *value);

DESCRIPTION

La fonction ck_ht_entry_set() initialisera l'objet pointé par entry avec une clé pointée par l'argument key et une valeur pointée par l'argument value. La longueur de la clé est spécifiée par key_length. La valeur maximale de key_length est définie par la macro CK_HT_KEY_LENGTH. Cette fonction est généralement utilisée pour initialiser une entrée pour les opérations ck_ht_set_spmc(3) et ck_ht_put_spmc(3). Il est attendu que l'entrée soit associée à une table de hachage initialisée avec CK_HT_MODE_BYTESTRING (voir ck_ht_init(3) pour plus d'informations).

VALEURS DE RETOUR

ck_ht_entry_set() ne retourne aucune valeur.

ERREURS

Cette fonction ne produira jamais d'échec.
