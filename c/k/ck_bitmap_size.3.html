CK_BITMAP_SIZE(3) Manuel des fonctions de bibliothèque CK_BITMAP_SIZE(3)

NOM

ck_bitmap_size — retourne le nombre d'octets nécessaires pour un bitmap

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_bitmap.h>

unsigned int
ck_bitmap_size(unsigned int n_bits);

DESCRIPTION

La fonction ck_bitmap_size() retourne le nombre d'octets nécessaires pour allouer un bitmap qui contiendra le nombre de bits spécifiés par n_bits.

Cette fonction est utilisée pour déterminer le nombre d'octets à allouer pour les objets bitmap créés dynamiquement. L'objet alloué doit toujours être initialisé à l'aide de ck_bitmap_init(3).

VALEURS DE RETOUR

Cette fonction retourne une valeur non nulle.
