NOM

ck_epoch_end — termine un segment d'exécution protégé par époque

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_epoch.h>

void
ck_epoch_end(ck_epoch_record_t *record, ck_epoch_section_t *section);

DESCRIPTION

La fonction ck_epoch_end(3) marque la fin d'une section de code protégée par époque. section doit pointer vers un objet de section initialisé précédemment avec ck_epoch_begin(3).

VALEURS DE RETOUR

Cette fonction n'a pas de valeur de retour.

ERREURS

L'objet pointé par record doit avoir été précédemment enregistré via ck_epoch_register(3).
