NOM

ck_array_deinit — détruit et désinitialise un tableau de pointeurs

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_array.h>

void
ck_array_deinit(ck_array_t *array, bool defer);

DESCRIPTION

La fonction ck_array_deinit(3) détruit la mémoire associée au tableau pointé par array. L'argument defer est vrai si l'allocateur doit détruire la mémoire en utilisant une récupération de mémoire sûre, ou faux si l'allocateur peut détruire cette mémoire immédiatement.

VALEURS DE RETOUR

Cette fonction n'a pas de valeur de retour.
