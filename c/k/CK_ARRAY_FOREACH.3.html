CK_ARRAY_FOREACH(3) Manuel des fonctions de bibliothèque CK_ARRAY_FOREACH(3)

NOM

CK_ARRAY_FOREACH — parcourir un tableau

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_array.h>

bool
CK_ARRAY_FOREACH(ck_array_t *array, ck_array_iterator_t *iterator, void **b);

DESCRIPTION

La macro CK_ARRAY_FOREACH(3) parcourt le tableau pointé par array. Un pointeur vers un objet itérateur doit être spécifié par iterator et b doit pointer vers un pointeur void.

EXEMPLE

#include <ck_array.h>

/* Supposons que ceci ait déjà été initialisé. */
ck_array_t array;

void
example(void)
{
	ck_array_iterator_t iterator;
	void *pointer;

	CK_ARRAY_FOREACH(&array, &iterator, &pointer) {
		do_something(pointer);
	}
}

VALEURS DE RETOUR

Cette macro n'a pas de valeur de retour.
