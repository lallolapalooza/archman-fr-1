DESCRIPTION

Voir la page de manuel de votre système pour queue pour des informations supplémentaires. ck_queue est une implémentation compatible avec queue.h de nombreuses queues multiples lecteurs/un seul écrivain. Elle permet une itération simultanée sûre, un coup d'œil et un accès en lecture en présence d'un seul écrivain simultané, sans aucune utilisation de verrous. Dans de nombreux cas, l'adoption de ck_queue nécessitera simplement de préfixer toutes les opérations de queue avec CK_.
