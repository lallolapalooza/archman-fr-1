DESCRIPTION

Ceci est un verrou de lecteur-rédacteur centralisé privilégiant l'écriture. Il nécessite très peu d'espace supplémentaire et offre un chemin d'accès rapide à faible latence. La récursion côté écriture nécessite l'utilisation de ck_rwlock_recursive. La récursion côté lecture est interdite. La fonction ck_rwlock_write_downgrade() dégrade l'acquisition côté écriture de l'appelant en une acquisition côté lecture sans perdre la section critique actuelle.

EXEMPLE

#include <ck_rwlock.h>

static ck_rwlock_t lock = CK_RWLOCK_INITIALIZER;

static void
reader(void)
{

	for (;;) {
		ck_rwlock_read_lock(&lock);
		/* Section critique côté lecture. */
		ck_rwlock_read_unlock(&lock);

		if (ck_rwlock_read_trylock(&lock) == true) {
			/* Section critique côté lecture. */
			ck_rwlock_read_unlock(&lock);
		}
	}

	return;
}

static void
writer(void)
{

	for (;;) {
		ck_rwlock_write_lock(&lock);
		/* Section critique côté écriture. */
		ck_rwlock_write_unlock(&lock);

		if (ck_rwlock_write_trylock(&lock, 1) == true) {
			/* Section critique côté écriture. */
			ck_rwlock_write_unlock(&lock);
		}
	}

	return;
}
