CK_RING_TRYDEQUEUE_SPMC(3) Manuel des fonctions de bibliothèque CK_RING_TRYDEQUEUE_SPMC(3)

NOM

ck_ring_trydequeue_spmc — retirer d'une FIFO bornée en autorisant un échec spécieux

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_ring.h>

bool
ck_ring_trydequeue_spmc(ck_ring_t *ring, ck_ring_buffer_t *buffer, void *result);

DESCRIPTION

La fonction ck_ring_trydequeue_spmc(3) tente de retirer un pointeur du tampon borné pointé par ring en mode FIFO. Le pointeur est stocké dans le pointeur pointé par result. Le tampon pointé par buffer doit être unique à ring et pointer vers un tableau de ck_ring_buffer_t de longueur suffisante (conformément à la puissance de 2 des éléments dans le tampon). Le découplage de l'anneau du tampon sert à traiter les cas d'utilisation impliquant plusieurs espaces d'adressage et le DMA, entre autres. Si vous êtes sur des plateformes non-POSIX ou si vous souhaitez une stricte conformité avec C, il est recommandé de passer un pointeur de type void ** pour result. Cette fonction peut être appelée sans verrouillage pour UINT_MAX invocations concurrentes de ck_ring_dequeue_spmc(3) ou ck_ring_trydequeue_spmc(3) et jusqu'à une invocation concurrente de ck_ring_enqueue_spmc(3) ou ck_ring_tryenqueue_spmc(3). Cette opération s'achèvera toujours en un nombre borné d'étapes. Il est possible que la fonction retourne false même si ring n'est pas vide. Ceci

EXEMPLE

#include <ck_ring.h>

/* Cet anneau a été précédemment initialisé avec ck_ring_init. */
ck_ring_t ring;

/* L'anneau a été initialisé pour 1023 éléments. */
ck_ring_buffer_t buffer[1024];

void
dequeue(void)
{
	void *result;

	/* Retirer de l'anneau jusqu'à ce que la contention soit activement observée. */
	while (ck_ring_trydequeue_spmc(&ring, &buffer, &result) == true) {
		/*
		 * result contient le pointeur le plus ancien dans l'anneau
		 * depuis que l'opération de retrait a renvoyé true.
		 */
		operation(result);
	}

	/* Un anneau vide a été rencontré, quitter. */
	return;
}

VALEURS DE RETOUR

La fonction renvoie true si l'opération de retrait s'est achevée avec succès en un nombre borné d'étapes. Le résultat de l'opération de retrait est stocké dans la valeur pointée par result. Sinon, la fonction renverra false si le tampon était vide ou si l'opération n'a pas pu être achevée en un nombre borné d'étapes. Si la fonction renvoie false, alors le contenu de result est indéfini.
