CK_RHS_GROW(3) Manuel des fonctions de bibliothèque CK_RHS_GROW(3)

NOM

ck_rhs_grow — agrandir la capacité d'un ensemble de hachage

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_rhs.h>

bool
ck_rhs_grow(ck_rhs_t *hs, unsigned long capacity);

DESCRIPTION

La fonction ck_rhs_grow(3) redimensionnera l'ensemble de hachage afin de pouvoir stocker au moins le nombre d'entrées spécifié par capacity à un facteur de chargement de un. Le facteur de chargement par défaut de l'ensemble de hachage est de 0.5. Si vous souhaitez minimiser la probabilité d'allocations mémoire pour un ensemble de hachage destiné à stocker n entrées, spécifiez une capacity de 2n. Le comportement par défaut de ck_rhs est d'arrondir capacity à la prochaine puissance de deux si elle n'est pas déjà une puissance de deux.

VALEURS DE RETOUR

En cas de succès, ck_rhs_grow(3) renvoie true, sinon elle renvoie false en cas d'échec.

ERREURS

Le comportement est indéfini si hs n'est pas initialisé. Cette fonction ne renverra false qu'en cas d'échecs internes d'allocation mémoire.
