NOM

ck_array_initialized — indique si un tableau a été récemment initialisé ou désinitialisé

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_array.h>

bool
ck_array_initialized(ck_array_t *array);

DESCRIPTION

La fonction ck_array_initialized(3) peut être utilisée pour déterminer si un tableau a été récemment initialisé avec ck_array_init(3) ou désinitialisé avec ck_array_deinit(3). Le comportement est indéfini si un utilisateur alloue des données d'allocateur internes par d'autres moyens.

VALEURS DE RETOUR

Cette fonction retourne vrai si le tableau est initialisé, et faux sinon.
