ck_pr_fence_load_atomic(3)

Paquet: libck

CK_PR_FENCE_LOAD_ATOMIC(3) Manuel des fonctions de bibliothèque CK_PR_FENCE_LOAD_ATOMIC(3)

NOM

ck_pr_fence_load_atomic — impose l'ordre des opérations de chargement aux opérations atomiques de lecture-modification-écriture

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_pr.h>

void
ck_pr_fence_load_atomic(void);

void
ck_pr_fence_strict_load_atomic(void);

DESCRIPTION

Cette fonction impose l'ordre des opérations de chargement mémoire et des opérations ck_pr_load(3) par rapport aux opérations de stockage avant l'invocation de la fonction. Tout opération de stockage qui a été validée sur des processeurs distants et reçue par le processeur appelant avant l'invocation de ck_pr_fence_load_atomic() sera également rendue visible uniquement après un appel à la famille de fonctions ck_pr_fence_load. Cette fonction sert toujours de barrière compilateur implicite. Sur les architectures avec CK_MD_TSO ou CK_MD_PSO spécifié (ordre total des stockages et ordre partiel des stockages respectivement), cette opération sert uniquement de barrière compilateur et aucune instruction de clôture ne sera émise. Pour forcer l'émission inconditionnelle d'une clôture de chargement, utilisez ck_pr_fence_strict_load_atomic(). Les architectures implémentant CK_MD_RMO émettent toujours une clôture.

EXEMPLE

#include <ck_pr.h>

static unsigned int a;
static unsigned int b;

void
function(void)
{
	unsigned int snapshot_a, snapshot_b;

	snapshot_a = ck_pr_load_uint(&a);

	/*
	 * Garantir que le chargement depuis "a" se termine
	 * avant la mise à jour de "b".
	 */
	ck_pr_fence_load_atomic();
	ck_pr_fas_uint(&b, 1);

	return;
}

VALEURS DE RETOUR

Cette fonction ne retourne aucune valeur.
