NOM

ck_epoch_poll — sonde non bloquante de l'objet epoch pour les cycles de dispatch

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_epoch.h>

bool
ck_epoch_poll(ck_epoch_record_t *record);

DESCRIPTION

La fonction ck_epoch_poll(3) tente de distribuer toutes les fonctions associées à l'objet pointé par epoch via ck_epoch_call(3) si cela est jugé sûr. Cette fonction est conçue pour être utilisée dans les cas où le coût de récupération de l'epoch doit être amorti dans le temps d'une manière qui n'affecte pas la progression de l'appelant.

VALEURS DE RETOUR

Cette fonction retourne false si les conditions suivantes sont remplies : aucune mémoire n'a été récupérée, les enregistrements ne sont pas dans une période de grâce et aucun progrès n'a été réalisé.

ERREURS

Le comportement est indéfini si l'objet pointé par record n'a pas été précédemment enregistré via ck_epoch_register(3).
