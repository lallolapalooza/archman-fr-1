CK_RHS_ITERATOR_INIT(3) Manuel des fonctions de bibliothèque CK_RHS_ITERATOR_INIT(3)

NOM

ck_rhs_iterator_init — initialiser l'itérateur de l'ensemble de hachage

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_rhs.h>

ck_rhs_iterator_t iterator = CK_RHS_ITERATOR_INITIALIZER


void
ck_rhs_iterator_init(ck_rhs_iterator_t *iterator);

DESCRIPTION

La fonction ck_rhs_iterator_init(3) initialisera l'objet pointé par l'argument iterator. Alternativement, un itérateur peut être initialisé statiquement en lui assignant la valeur CK_RHS_ITERATOR_INITIALIZER.

Un itérateur est utilisé pour parcourir les entrées de l'ensemble de hachage avec la fonction ck_rhs_next(3).

VALEURS DE RETOUR

ck_rhs_iterator_init(3) n'a pas de valeur de retour.

ERREURS

Cette fonction ne peut pas échouer.
