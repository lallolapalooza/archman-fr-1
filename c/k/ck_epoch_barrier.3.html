Paquet: libck

CK_EPOCH_BARRIER(3) Manuel des fonctions de bibliothèque CK_EPOCH_BARRIER(3)

NOM

ck_epoch_barrier — bloquer jusqu'à une période de grâce et l'envoi de tous les rappels

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_epoch.h>

void
ck_epoch_barrier(ck_epoch_record_t *record);

DESCRIPTION

La fonction ck_epoch_barrier(3) bloquera l'appelant jusqu'à ce qu'une période de grâce soit détectée, conformément à la sémantique de la récupération d'époque. Tous les objets nécessitant une récupération de mémoire sûre qui sont logiquement supprimés peuvent être physiquement supprimés en toute sécurité après un appel à ck_epoch_barrier(3). Cette fonction enverra également tous les rappels associés à l'époque qui ont été précédemment planifiés via ck_epoch_call(3).

EXEMPLE

#include <ck_epoch.h>
#include <ck_stack.h>
#include <stdlib.h>

/*
 * epoch a été précédemment initialisé avec ck_epoch_init.
 * stack a été précédemment initialisé avec ck_stack_init.
 */
ck_epoch_t *epoch;
ck_stack_t *stack;

void
function(void)
{
	ck_epoch_record_t *record;
	ck_stack_entry_t *s;

	record = malloc(sizeof *record);
	ck_epoch_register(&epoch, record, NULL);

	/*
	 * Nous utilisons ici une section d'époque pour garantir qu'aucun
	 * nœud de la pile n'est supprimé pendant que nous y accédons.
	 * Ceci est nécessaire ici car il y a plusieurs rédacteurs.
	 * S'il n'y avait qu'un seul thread retirant de cette pile,
	 * alors il n'y aurait pas besoin de ck_epoch_begin/ck_epoch_end.
	 */
	ck_epoch_begin(record);

	/* Supprime logiquement un objet. */
	s = ck_stack_pop_upmc(stack);

	ck_epoch_end(record);

	/*
	 * Attendez jusqu'à ce qu'aucun thread ne puisse avoir de référence à l'objet
	 * que nous venons de retirer (supposez que tous les threads exécutent
	 * simplement ck_stack_pop_upmc).
	 */
	ck_epoch_barrier(record);

	/* Il est maintenant sûr de supprimer physiquement l'objet. */
	free(s);
	return;
}

VALEURS DE RETOUR

Cette fonction n'a pas de valeur de retour.

ERREURS

Le comportement est indéfini si l'objet pointé par epoch n'est pas un objet d'époque valide. L'objet pointé par record doit avoir été précédemment enregistré via ck_epoch_register(3).
