ck_pr_rtm(3) Manuel des fonctions de bibliothèque ck_pr_rtm(3)

NOM

ck_pr_rtm_begin, ck_pr_rtm_end, ck_pr_rtm_abort, ck_pr_rtm_test — mémoire transactionnelle restreinte

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_pr.h>

unsigned int
ck_pr_rtm_begin(void);

void
ck_pr_rtm_end(void);

void
ck_pr_rtm_abort(const unsigned int status);

bool
ck_pr_rtm_test(void);

DESCRIPTION

Cette famille de fonctions implémente le support de la mémoire transactionnelle restreinte, si elle est disponible sur la plateforme sous-jacente. Actuellement, le support n'est fourni que pour les microarchitectures x86 Intel Haswell et plus récentes qui disposent de la fonctionnalité TSX-NI.

La fonction ck_pr_rtm_begin() renvoie CK_PR_RTM_STARTED si une transaction a été démarrée avec succès. En cas d'abandon, qu'il soit interne (via un ck_pr_rtm_abort) ou externe, le flux du programme reprendra au point où la fonction a été appelée, sauf que la valeur de retour consistera en un masque de bits avec un ou plusieurs des bits suivants définis :

CK_PR_RTM_EXPLICIT
Défini si la transaction a été explicitement abandonnée via ck_pr_rtm_abort().
CK_PR_RTM_RETRY
Défini si la transaction a échoué mais peut encore réussir si elle est retentée.
CK_PR_RTM_CONFLICT
La transaction a échoué en raison d'un conflit sur l'une des adresses mémoire qui font partie de l'ensemble de travail de la transaction.
CK_PR_RTM_CAPACITY
Défini si la limite de taille de transaction définie par l'architecture a été dépassée.
CK_PR_RTM_DEBUG
Défini si un point d'arrêt matériel a été déclenché.
CK_PR_RTM_NESTED
Défini si une transaction imbriquée a échoué.

L'utilisateur peut également spécifier un octet de statut d'abandon en appelant ck_pr_rtm_abort(). Cet octet de statut peut être extrait en appelant la fonction CK_PR_RTM_CODE() avec la valeur de retour de ck_pr_rtm_begin() comme argument. La valeur de retour de CK_PR_RTM_CODE() sera la valeur de cet octet de statut. Pour plus d'informations, veuillez consulter les manuels de jeux d'instructions Intel.
