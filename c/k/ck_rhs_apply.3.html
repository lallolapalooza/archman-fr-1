ck_rhs_apply(3)

Paquet: libck

Licences: BSD, Apache, Custom

CK_RHS_APPLY(3) Manuel des fonctions de bibliothèque CK_RHS_APPLY(3)

NOM

ck_rhs_apply — appliquer une fonction à une valeur d'ensemble de hachage

BIBLIOTHèQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_rhs.h>

void *
ck_rhs_apply_fn_t(void *key, void *closure);

bool
ck_rhs_apply(ck_rhs_t *hs, unsigned long hash, const void *key, ck_rhs_apply_fn_t *function, void *argument);

DESCRIPTION

La fonction ck_rhs_apply(3) recherchera l'emplacement de l'ensemble de hachage associé à key et le passera à la fonction pointée par function pour une action supplémentaire. Ce rappel peut supprimer ou remplacer la valeur en retournant respectivement NULL ou un pointeur vers un autre objet avec une clé identique. Le premier argument passé à function est un pointeur vers l'objet trouvé dans l'ensemble de hachage et le second argument est le pointeur argument passé à ck_rhs_apply(3). Si le pointeur retourné par function est équivalent au premier argument, aucune modification n'est apportée à l'ensemble de hachage.

VALEURS DE RETOUR

En cas de succès, ck_rhs_apply(3) retourne true et sinon retourne false en cas d'échec.
