CK_HS_GROW(3) Manuel des fonctions de bibliothèque CK_HS_GROW(3)

NOM

ck_hs_grow — agrandir la capacité d'une table de hachage

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_hs.h>

bool
ck_hs_grow(ck_hs_t *hs, unsigned long capacity);

DESCRIPTION

La fonction ck_hs_grow(3) redimensionnera la table de hachage afin de pouvoir stocker au moins le nombre d'entrées spécifié par capacity avec un facteur de charge de un. Le facteur de charge par défaut de la table de hachage est de 0,5. Si vous souhaitez minimiser la probabilité d'allocations mémoire pour une table de hachage destinée à stocker n entrées, spécifiez une capacity de 2n. Le comportement par défaut de ck_hs est d'arrondir capacity à la prochaine puissance de deux si elle n'est pas déjà une puissance de deux.

VALEURS DE RETOUR

En cas de succès, ck_hs_grow(3) renvoie true, sinon elle renvoie false en cas d'échec.

ERREURS

Le comportement est indéfini si hs est non initialisé. Cette fonction ne renverra false qu'en cas d'échec d'allocation mémoire interne.
