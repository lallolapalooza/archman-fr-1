CK_EPOCH_CALL(3) Manuel des fonctions de bibliothèque CK_EPOCH_CALL(3)

NOM

ck_epoch_call — différer l'exécution d'une fonction jusqu'à une période de grâce

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNOPSIS

#include <ck_epoch.h> typedef struct ck_epoch_entry ck_epoch_entry_t;
typedef void ck_epoch_cb_t(ck_epoch_entry_t *);
void
ck_epoch_call(ck_epoch_record_t *record, ck_epoch_entry_t *entry, ck_epoch_cb_t *function);

DESCRIPTION

La fonction ck_epoch_call(3) différera l'exécution de la fonction pointée par function jusqu'à ce qu'une période de grâce soit détectée dans epoch. La fonction recevra le pointeur spécifié par entry. La fonction s'exécutera à un moment donné dans le futur via des appels à ck_epoch_reclaim(3), ck_epoch_barrier(3) ou ck_epoch_poll(3).

EXEMPLE

#include <ck_epoch.h>
#include <ck_stack.h>
#include <stdlib.h>

/*
 * epoch a été initialisé précédemment avec ck_epoch_init.
 */
ck_epoch_t *epoch;

struct object {
	int value;
	ck_epoch_entry_t epoch_entry;
};
static struct object *global;

CK_EPOCH_CONTAINER(struct object, epoch_entry, object_container)

void
destroy_object(ck_epoch_entry_t *e)
{
	struct object *o = object_container(e);

	free(o);
	return;
}

void
function(void)
{
	ck_epoch_record_t *record;
	struct object *n;

	record = malloc(sizeof *record);
	ck_epoch_register(&epoch, record, NULL);

	n = malloc(sizeof *n);
	if (n == NULL)
		return;

	n->value = 1;

	/*
	 * Nous utilisons une section d'époque ici car il y a plusieurs
	 * écrivains. Il est également possible d'utiliser d'autres formes de
	 * synchronisation du côté écriture, tels que les mutex.
	 */
	ck_epoch_begin(record);
	n = ck_pr_fas_ptr(&global, n);
	ck_epoch_end(record);

	/* Différer la destruction de l'objet précédent. */
	ck_epoch_call(record, &n->epoch_entry, destroy_object);

	/* Sonder le sous-système d'époque de manière non bloquante. */
	ck_epoch_poll(record);
	return;
}

VALEURS DE RETOUR

Cette fonction n'a pas de valeur de retour.

ERREURS

L'objet pointé par record doit avoir été enregistré précédemment via ck_epoch_register(3).
