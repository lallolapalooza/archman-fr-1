CK_HT_GROW_SPMC(3) Manuel des fonctions de bibliothèque CK_HT_GROW_SPMC(3)

NOM

ck_ht_grow_spmc — redimensionner une table de hachage si nécessaire

BIBLIOTHÈQUE

Concurrency Kit (libck, -lck)

SYNTAXE

#include <ck_ht.h>

bool
ck_ht_grow_spmc(ck_ht_t *ht, uint64_t capacity);

DESCRIPTION

La fonction ck_ht_grow_spmc() redimensionnera la table de hachage afin de pouvoir stocker au moins le nombre d'entrées spécifié par capacity avec un facteur de charge de un. Le facteur de charge par défaut de la table de hachage est de 0.5. Si vous souhaitez minimiser la probabilité d'allocations mémoire pour une table de hachage destinée à stocker n entrées, spécifiez une capacité de 2n. Le comportement par défaut de ck_ht est d'arrondir capacity à la prochaine puissance de deux disponible si ce n'est pas déjà une puissance de deux.

Cette fonction peut être appelée en présence d'opérations concurrentes ck_ht_get_spmc(3).

VALEURS DE RETOUR

En cas de succès, ck_ht_grow_spmc() retourne true, sinon elle retourne une valeur false.

ERREURS

Le comportement n'est pas défini si ht n'est pas initialisé. La fonction ne retournera false qu'en cas d'échec d'allocation mémoire interne.
