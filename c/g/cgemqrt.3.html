sous-programme cgemqrt (caractere side, caractere trans, entier m, entier n, entier k, entier nb, complexe, dimension( ldv, * ) v, entier ldv, complexe, dimension( ldt, * ) t, entier ldt, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( * ) work, entier info)

CGEMQRT

But:

!>
!> CGEMQRT écrase la matrice complexe générale M par N de C avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q C            C Q
!> TRANS = 'C':    Q**H C            C Q**H
!>
!> où Q est une matrice orthogonale complexe définie comme le produit de K
!> réflecteurs élémentaires:
!>
!>       Q = H(1) H(2) . . . H(K) = I - V T V**H
!>
!> générée en utilisant la représentation WY compacte telle que renvoyée par CGEQRT.
!>
!> Q est d'ordre M si SIDE = 'L' et d'ordre N si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': applique Q ou Q**H depuis la Gauche;
!>          = 'R': applique Q ou Q**H depuis la Droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': Pas de transposition, applique Q;
!>          = 'C': Transposée conjuguée, applique Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

NB

!>          NB est INTEGER
!>          La taille du bloc utilisée pour le stockage de T. K >= NB >= 1.
!>          Cela doit être la même valeur de NB utilisée pour générer T
!>          dans CGEQRT.
!>

V

!>          V est tableau COMPLEX, dimension (LDV,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que renvoyé par
!>          CGEQRT dans les K premières colonnes de son argument tableau A.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T est tableau COMPLEX, dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs de bloc
!>          tels que renvoyés par CGEQRT, stockés comme une matrice NB par N.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= NB.
!>

C

!>          C est tableau COMPLEX, dimension (LDC,N)
!>          À l'entrée, la matrice C de M par N.
!>          À la sortie, C est écrasée par Q C, Q**H C, C Q**H ou C Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est tableau COMPLEX. La dimension de WORK est
!>           N*NB si SIDE = 'L', ou M*NB si SIDE = 'R'.
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
