subroutine cgglse (integer m, integer n, integer p, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) c, complex, dimension( * ) d, complex, dimension( * ) x, complex, dimension( * ) work, integer lwork, integer info)

CGGLSE résout des systèmes surdéterminés ou sousdéterminés pour d'AUTRES matrices

Objectif:

!>
!> CGGLSE résout le problème des moindres carrés avec contraintes d'égalité (LSE)
!> linéaire :
!>
!>         minimiser || c - A*x ||_2   sous contrainte   B*x = d
!>
!> où A est une matrice M par N, B est une matrice P par N, c est un vecteur M donné
!> et d est un vecteur P donné. On suppose que
!> P <= N <= M+P, et
!>
!>          rank(B) = P et  rank( (A) ) = N.
!>                               ( (B) )
!>
!> Ces conditions garantissent que le problème LSE a une solution unique,
!> obtenue en utilisant une factorisation RQ généralisée des matrices
!> (B, A) donnée par
!>
!>    B = (0 R)*Q,   A = Z*T*Q.
!>
!> Les appelants de cette sous-routine doivent noter que les vérifications de
!> singularité/déficience de rang implémentées dans cette sous-routine sont rudimentaires.
!> La sous-routine CTRTRS appelée par cette sous-routine ne signale un échec dû à la
!> singularité que si le problème est exactement singulier.
!>
!> Il est concevable que l'un (ou plusieurs) des facteurs impliqués dans la factorisation
!> RQ généralisée de la paire (B, A) soit subnormalement proche de la singularité sans que
!> cette sous-routine ne signale d'erreur. Les solutions calculées pour de tels problèmes
!> presque de rang déficient peuvent être moins précises en raison d'une perte de précision
!> numérique.
!>
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B. N >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B. 0 <= P <= N <= M+P.
!>

A

!>          A est tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M par N.
!>          À la sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapézoïdale supérieure T de taille min(M,N) par N.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est tableau COMPLEX, dimension (LDB,N)
!>          À l'entrée, la matrice B de taille P par N.
!>          À la sortie, le triangle supérieur de la sous-matrice B(1:P,N-P+1:N)
!>          contient la matrice triangulaire supérieure R de taille P par P.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!>

C

!>          C est tableau COMPLEX, dimension (M)
!>          À l'entrée, C contient le membre de droite du problème des moindres carrés LSE.
!>          À la sortie, la somme des carrés des résidus pour la solution
!>          est donnée par la somme des carrés des éléments N-P+1 à M du
!>          vecteur C.
!>

D

!>          D est tableau COMPLEX, dimension (P)
!>          À l'entrée, D contient le membre de droite de l'équation contrainte.
!>          À la sortie, D est détruit.
!>

X

!>          X est tableau COMPLEX, dimension (N)
!>          À la sortie, X est la solution du problème LSE.
!>

WORK

!>          WORK est tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,M+N+P).
!>          Pour des performances optimales LWORK >= P+min(M,N)+max(M,N)*NB,
!>          où NB est une borne supérieure pour les tailles de blocs optimales pour
!>          CGEQRF, CGERQF, CUNMQR et CUNMRQ.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument était invalide.
!>          = 1:  le facteur triangulaire supérieur R associé à B dans la
!>                factorisation RQ généralisée de la paire (B, A) est exactement
!>                singulier, de sorte que rank(B) < P ; le moindres carrés
!>                la solution n'a pas pu être calculée.
!>          = 2:  la partie (N-P) par (N-P) du facteur trapézoïdal supérieur
!>                T associé à A dans la factorisation RQ généralisée
!>                de la paire (B, A) est exactement singulière, de sorte que
!>                rank( (A) ) < N ; les moindres carrés
!>                    ( (B) )
!>                la solution n'a pas pu être calculée.
!>
