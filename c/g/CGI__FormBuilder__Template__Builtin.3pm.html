NOM

CGI::FormBuilder::Template::Builtin - Rendu HTML intégré

SYNOPSIS

my $form = CGI::FormBuilder->new;
$form->render;

DESCRIPTION

Ce module fournit le rendu par défaut pour FormBuilder. Il est appelé automatiquement par la méthode render() de FormBuilder si aucun modèle externe n'est spécifié. Voir la documentation de CGI::FormBuilder pour plus de détails.

VOIR AUSSI

CGI::FormBuilder, CGI::FormBuilder::Template::HTML, CGI::FormBuilder::Template::Text, CGI::FormBuilder::Template::TT2, CGI::FormBuilder::Template::Fast, CGI::FormBuilder::Template::CGI_SSI
