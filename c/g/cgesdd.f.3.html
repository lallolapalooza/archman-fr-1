sous-routine cgesdd (character jobz, integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) s, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( ldvt, * ) vt, integer ldvt, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer

CGESD

D

But

: 
!>
!> CGESDD calcule la décomposition en valeurs singulières (SVD) d'une
!> matrice complexe A de dimensions M par N, en calculant éventuellement
!> les vecteurs singuliers gauche et/ou droit, en utilisant la méthode
!> de diviser pour régner. La SVD est écrite
!>
!>      A = U * SIGMA * conjugate-transpose(V)
!>
!> où SIGMA est une matrice M par N qui est nulle sauf pour ses
!> min(m,n) éléments diagonaux, U est une matrice unitaire M par M, et
!> V est une matrice unitaire N par N. Les éléments diagonaux de SIGMA
!> sont les valeurs singulières de A ; elles sont réelles et non
!> négatives, et sont retournées en ordre décroissant. Les premières
!> min(m,n) colonnes de U et V sont les vecteurs singuliers gauche et
!> droit de A.
!>
!> Notez que la routine retourne VT = V**H, et non V.
!>
!
>

Paramètre

s
JOBZ 
!>          JOBZ est CHARACTER*1
!>          Spécifie les options pour le calcul de toute ou partie de la matrice U :
!>          = 'A' :  toutes les M colonnes de U et toutes les N lignes de V**H sont
!>                  retournées dans les tableaux U et VT ;
!>          = 'S' :  les premières min(M,N) colonnes de U et les premières
!>                  min(M,N) lignes de V**H sont retournées dans les tableaux U
!>                  et VT ;
!>          = 'O' :  Si M >= N, les premières N colonnes de U sont écrasées
!>                  dans le tableau A et toutes les lignes de V**H sont retournées
!>                  dans le tableau VT ;
!>                  sinon, toutes les colonnes de U sont retournées dans le
!>                  tableau U et les premières M lignes de V**H sont écrasées
!>                  dans le tableau A ;
!>          = 'N' :  aucune colonne de U ni ligne de V**H n'est calculée.
!
>

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.  N >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M par N.
!>          À la sortie,
!>          si JOBZ = 'O',  A est écrasée avec les premières N colonnes
!>                          de U (les vecteurs singuliers gauche, stockés
!>                          par colonnes) si M >= N ;
!>                          A est écrasée avec les premières M lignes
!>                          de V**H (les vecteurs singuliers droits, stockés
!>                          par lignes) sinon.
!>          si JOBZ .ne. 'O', le contenu de A est détruit.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!
>

S 
!>          S est un tableau REAL, dimension (min(M,N))
!>          Les valeurs singulières de A, triées de sorte que S(i) >= S(i+1).
!
>

U 
!>          U est un tableau COMPLEX, dimension (LDU,UCOL)
!>          UCOL = M si JOBZ = 'A' ou JOBZ = 'O' et M < N ;
!>          UCOL = min(M,N) si JOBZ = 'S'.
!>          Si JOBZ = 'A' ou JOBZ = 'O' et M < N, U contient la matrice
!>          unitaire U de dimensions M par M ;
!>          si JOBZ = 'S', U contient les premières min(M,N) colonnes de U
!>          (les vecteurs singuliers gauche, stockés par colonnes) ;
!>          si JOBZ = 'O' et M >= N, ou JOBZ = 'N', U n'est pas référencée.
!
>

LD

U 
!>          LDU est INTEGER
!>          La dimension principale du tableau U.  LDU >= 1 ;
!>          si JOBZ = 'S' ou 'A' ou JOBZ = 'O' et M < N, LDU >= M.
!
>

V

T 
!>          VT est un tableau COMPLEX, dimension (LDVT,N)
!>          Si JOBZ = 'A' ou JOBZ = 'O' et M >= N, VT contient la
!>          matrice unitaire V**H de dimensions N par N ;
!>          si JOBZ = 'S', VT contient les premières min(M,N) lignes de
!>          V**H (les vecteurs singuliers droits, stockés par lignes) ;
!>          si JOBZ = 'O' et M < N, ou JOBZ = 'N', VT n'est pas référencée.
!
>

LDV

T 
!>          LDVT est INTEGER
!>          La dimension principale du tableau VT.  LDVT >= 1 ;
!>          si JOBZ = 'A' ou JOBZ = 'O' et M >= N, LDVT >= N ;
!>          si JOBZ = 'S', LDVT >= min(M,N).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne la valeur optimale de LWORK.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée. La taille
!>          optimale du tableau WORK est calculée et stockée dans WORK(1),
!>          et aucun autre travail n'est effectué en dehors de la vérification des arguments.
!>
!>          Soit mx = max(M,N) et mn = min(M,N).
!>          Si JOBZ = 'N', LWORK >= 2*mn + mx.
!>          Si JOBZ = 'O', LWORK >= 2*mn*mn + 2*mn + mx.
!>          Si JOBZ = 'S', LWORK >=   mn*mn + 3*mn.
!>          Si JOBZ = 'A', LWORK >=   mn*mn + 2*mn + mx.
!>          Ce ne sont pas des minima stricts dans tous les cas ; voir les commentaires dans le code.
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand ;
!>          une interrogation est recommandée.
!
>

RWOR

K 
!>          RWORK est un tableau REAL, dimension (MAX(1,LRWORK))
!>          Soit mx = max(M,N) et mn = min(M,N).
!>          Si JOBZ = 'N',    LRWORK >= 5*mn (LAPACK <= 3.6 nécessite 7*mn) ;
!>          sinon si mx >> mn, LRWORK >= 5*mn*mn + 5*mn ;
!>          sinon              LRWORK >= max( 5*mn*mn + 5*mn,
!>                                           2*mx*mn + 2*mn*mn + mn ).
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (8*min(M,N))
!
>

INF

O 
!>          INFO est INTEGER
!>          <  0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          = -4 :  si A avait une entrée NAN.
!>          >  0 :  Le processus de mise à jour de SBDSDC n'a pas convergé.
!>          =  0 :  sortie réussie.
!
>
