sous-routine cgels (trans, m, n, nrhs, a, lda, b, ldb, work, lwork, info)
CGELS résout des systèmes surdéterminés ou sous-déterminés pour les matrices GE

sous-routine

sous-routine cgels (character trans, integer m, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) work, integer lwork, integer

info)

CGELS résout des systèmes surdéterminés ou sous-déterminés pour les matrices

GE

But

: 
!>
!> CGELS résout des systèmes linéaires complexes surdéterminés ou
!> sous-déterminés impliquant une matrice A de dimensions M par N, ou sa
!> transposée conjuguée, en utilisant une factorisation QR ou LQ de A.
!>
!> On suppose que A est de rang complet, et seule une protection élémentaire
!> est fournie contre les matrices de rang déficient. Cette sous-routine ne
!> détecte que le rang déficient exact, c'est-à-dire lorsqu'un élément
!> diagonal du facteur triangulaire de A est exactement nul.
!>
!> Il est concevable qu'un ou plusieurs des éléments diagonaux du facteur
!> triangulaire de A soient des nombres subnormalement infimes sans que cette
!> sous-routine signale une erreur. Les solutions calculées pour de telles
!> matrices presque de rang déficient peuvent être moins précises en raison
!> d'une perte de précision numérique.
!>
!> Les options suivantes sont fournies :
!>
!> 1. Si TRANS = 'N' et m >= n : trouver la solution des moindres carrés d'un
!>    système surdéterminé, c'est-à-dire résoudre le problème des moindres
!>    carrés
!>                 minimiser || B - A*X ||.
!>
!> 2. Si TRANS = 'N' et m < n : trouver la solution de norme minimale d'un
!>    système sous-déterminé A * X = B.
!>
!> 3. Si TRANS = 'C' et m >= n : trouver la solution de norme minimale d'un
!>    système sous-déterminé A**H * X = B.
!>
!> 4. Si TRANS = 'C' et m < n : trouver la solution des moindres carrés d'un
!>    système surdéterminé, c'est-à-dire résoudre le problème des moindres
!>    carrés
!>                 minimiser || B - A**H * X ||.
!>
!> Plusieurs vecteurs de second membre b et vecteurs de solution x peuvent
!> être traités dans un seul appel ; ils sont stockés en tant que colonnes de
!> la matrice de second membre B de dimensions M par NRHS et de la matrice de
!> solution X de dimensions N par NRHS.
!
>

Paramètre

s
TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : le système linéaire implique A ;
!>          = 'C' : le système linéaire implique A**H.
!
>

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M par N.
!>            si M >= N, A est écrasée par les détails de sa
!>                       factorisation QR tels que renvoyés par CGEQRF ;
!>            si M <  N, A est écrasée par les détails de sa
!>                       factorisation LQ tels que renvoyés par CGELQF.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!
>

B 
!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>          À l'entrée, la matrice B des vecteurs de second membre, stockée
!>          par colonnes ; B est de dimensions M par NRHS si TRANS = 'N', ou
!>          N par NRHS si TRANS = 'C'.
!>          À la sortie, si INFO = 0, B est écrasée par les vecteurs de
!>          solution, stockés par colonnes :
!>          si TRANS = 'N' et m >= n, les lignes 1 à n de B contiennent les
!>          vecteurs de solution des moindres carrés ; la somme des carrés des
!>          résidus pour la solution dans chaque colonne est donnée par la
!>          somme des carrés du module des éléments N+1 à M dans cette
!>          colonne ;
!>          si TRANS = 'N' et m < n, les lignes 1 à N de B contiennent les
!>          vecteurs de solution de norme minimale ;
!>          si TRANS = 'C' et m >= n, les lignes 1 à M de B contiennent les
!>          vecteurs de solution de norme minimale ;
!>          si TRANS = 'C' et m < n, les lignes 1 à M de B contiennent les
!>          vecteurs de solution des moindres carrés ; la somme des carrés des
!>          résidus pour la solution dans chaque colonne est donnée par la
!>          somme des carrés du module des éléments M+1 à N dans cette
!>          colonne.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= MAX(1,M,N).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= max( 1, MN + max( MN, NRHS ) ).
!>          Pour des performances optimales,
!>          LWORK >= max( 1, MN + max( MN, NRHS )*NB ).
!>          où MN = min(M,N) et NB est la taille de bloc optimale.
!>
!>          Si LWORK = -1, une interrogation de l'espace de travail est
!>          supposée ; la routine calcule uniquement la taille optimale du
!>          tableau WORK, renvoie cette valeur comme première entrée du
!>          tableau WORK, et aucun message d'erreur lié à LWORK n'est émis
!>          par XERBLA.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  si INFO =  i, le i-ème élément diagonal du facteur
!>                triangulaire de A est exactement nul, de sorte que A n'a pas
!>                de rang complet ; la solution des moindres carrés n'a pas pu
!>                être calculée.
!
>
