CGGSVD3 calcule la décomposition en valeurs singulières généralisée (GSVD) de la matrice complexe M par N A et de la matrice complexe P par N B :

Objectif :

!>
!> CGGSVD3 calcule la décomposition en valeurs singulières généralisée (GSVD)
!> d'une matrice complexe A de taille M par N et d'une matrice complexe B de taille P par N :
!>
!>       U**H*A*Q = D1*( 0 R ),    V**H*B*Q = D2*( 0 R )
!>
!> où U, V et Q sont des matrices unitaires.
!> Soit K+L = le rang numérique effectif de la
!> matrice (A**H,B**H)**H, alors R est une matrice triangulaire supérieure non singulière de taille (K+L)-par-(K+L), D1 et D2 sont des matrices de taille M-par-(K+L) et P-par-(K+L) 
!> et de structures suivantes, respectivement :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N), et R33 est stocké
!!>   ( 0  R22 R23 )
!>   dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> La routine calcule C, S, R, et éventuellement les matrices de transformation
!> unitaires U, V et Q.
!>
!> En particulier, si B est une matrice non singulière de taille N par N, alors la GSVD de
!> A et B donne implicitement la SVD de A*inv(B) :
!>                      A*inv(B) = U*(D1*inv(D2))*V**H.
!> Si ( A**H,B**H)**H a des colonnes orthonormées, alors la GSVD de A et B est aussi
!> égale à la décomposition CS de A et B. De plus, la GSVD peut
!> être utilisée pour dériver la solution du problème aux valeurs propres :
!>                      A**H*A x = lambda* B**H*B x.
!> Dans certaines littératures, la GSVD de A et B est présentée sous la forme
!>                  U**H*A*X = ( 0 D1 ),   V**H*B*X = ( 0 D2 )
!> où U et V sont orthogonales et X est non singulière, et D1 et D2 sont
!> ``diagonales''.  La forme GSVD précédente peut être convertie en la forme
!> latérale en prenant la matrice non singulière X comme
!>
!>                       X = Q*(  I   0    )
!>                             (  0 inv(R) )
!>

Nom


CGGSVD3 - La sous-routine CGGSVD3 calcule la décomposition généralisée des valeurs singulières de deux matrices.






Synopsis


SUBROUTINE CGGSVD3( JOBU, JOBV, JOBQ, M, N, P, A, LDA, B, LDB, ALPHA, BETA, U, LDU, V, LDV, Q, LDQ, WORK, LWORK, IWORK, INFO )




    Arguments





JOBU




CHARACTER*1



Spécifie quelles unités de vecteurs sont calculées:


    

  •  JOBU = 'U' : Les LDU vecteurs colonnes unitaires de U sont calculés.
    • 

  •  JOBU = 'N' : Aucune unité de vecteurs n'est calculée.
    • 



JOBV




CHARACTER*1



Spécifie quelles unités de vecteurs sont calculées:


    

  •  JOBV = 'V' : Les LDV vecteurs colonnes unitaires de V sont calculés.
    • 

  •  JOBV = 'N' : Aucune unité de vecteurs n'est calculée.
    • 



JOBQ




CHARACTER*1



Spécifie quelles unités de vecteurs sont calculées:


    

  •  JOBQ = 'Q' : Les LDQ vecteurs colonnes unitaires de Q sont calculés.
    • 

  •  JOBQ = 'N' : Aucune unité de vecteurs n'est calculée.
    • 



M




INTEGER



Le nombre de lignes de la matrice A.


N




INTEGER



Le nombre de colonnes des matrices A et B.


P




INTEGER



Le nombre de lignes de la matrice B.


A




COMPLEX*16 array, dimension (LDA, N)



La matrice A de taille M-by-N.


LDA




INTEGER



La taille de la première dimension de A; LDA >= max(1, M).


B




COMPLEX*16 array, dimension (LDB, N)



La matrice B de taille P-by-N.


LDB




INTEGER



La taille de la première dimension de B; LDB >= max(1, P).


ALPHA




DOUBLE PRECISION array, dimension (N)



Sur la sortie, les valeurs non négatives représentant les numérateurs des rapports des valeurs singulières généralisées.


BETA




DOUBLE PRECISION array, dimension (N)



Sur la sortie, les valeurs non négatives représentant les dénominateurs des rapports des valeurs singulières généralisées.


U




COMPLEX*16 array, dimension (LDU, M)



Sur la sortie, la matrice unitaire M-by-M de vecteurs singuliers gauches.


LDU




INTEGER



La taille de la première dimension de U; LDU >= max(1, M).


V




COMPLEX*16 array, dimension (LDV, N)



Sur la sortie, la matrice unitaire N-by-N de vecteurs singuliers gauches.


LDV




INTEGER



La taille de la première dimension de V; LDV >= max(1, N).


Q




COMPLEX*16 array, dimension (LDQ, P)



Sur la sortie, la matrice unitaire P-by-P de vecteurs singuliers droits.


LDQ




INTEGER



La taille de la première dimension de Q; LDQ >= max(1, P).


WORK




COMPLEX*16 array, dimension (LWORK)



Tableau de travail.


LWORK




INTEGER



La dimension du tableau WORK. LWORK >= 1.


Si LWORK = -1, alors une requête d'espace de travail est supposée; la routine calcule seulement la taille optimale du tableau WORK, retourne cette valeur comme première entrée du tableau WORK, et aucun message d'erreur lié à LWORK n'est émis par XERBLA.


IWORK




INTEGER array, dimension (N)



Sur la sortie, IWORK stocke les informations de tri. Plus précisément, la boucle suivante trie ALPHA


for I = K+1, min(M,K+L)
    swap ALPHA(I) and ALPHA(IWORK(I))
endfor



afin que ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).


INFO




INTEGER





    

  • 0: sortie réussie.
    • 

  • < 0: si INFO = -i, alors le i-ème argument avait une valeur illégale.
    • 

  • > 0: si INFO = 1, la procédure de type Jacobi n'a pas convergé. Pour plus de détails, voir la sous-routine CTGSJA.
    • 











Paramètres internes :
TOLA    REAL
TOLB    REAL
        TOLA et TOLB sont les seuils pour déterminer le rang effectif de (A**H,B**H)**H. Généralement, ils sont définis à
                   TOLA = MAX(M,N)*norm(A)*MACHEPS,
                   TOLB = MAX(P,N)*norm(B)*MACHEPS.
        La taille de TOLA et TOLB peut affecter la taille des erreurs inverses de la décomposition.
