DESCRIPTIO

N

Ce moteur adapte FormBuilder pour utiliser "Template Toolkit". Pour ce faire, spécifiez l'option "template" sous forme de référence de hachage incluant l'option "type" définie à "TT2" et l'option "template" définie au nom du modèle que vous souhaitez traiter. Vous pouvez également ajouter "variable" comme option (entre autres) pour indiquer le nom de la variable à laquelle vous souhaitez que les données du formulaire soient référencées

: 
my $form = CGI::FormBuilder->new(
                fields => \@fields,
                template => {
                    type => 'TT2',
                    template => 'userinfo.tmpl',
                    variable => 'form',
                }
           )
;

Les méthodes suivantes sont fournies (généralement utilisées uniquement en interne)

MODÈLE

S

Le modèle pourrait ressembler à quelque chose comme ceci

: 
<html>
<head>
  <title>[% form.title %]</title>
  [% form.jshead %]
</head>
<body>
  [% form.start %]
  <table>
    [% FOREACH field = form.fields %]
    <tr valign="top">
      <td>
        [% field.required
              ? "<b>$field.label</b>"
              : field.label
        %]
      </td>
      <td>
        [% IF field.invalid %]
        Entrée manquante ou invalide, veuillez réessayer.
    <br/>
    [% END %]
    [% field.field %]
  </td>
</tr>
    [% END %]
    <tr>
      <td colspan="2" align="center">
        [% form.submit %] [% form.reset %]
      </td>
    </tr>
  </table>
  [% form.end %]
</body>
</html>

Par défaut, Template Toolkit rend toutes les informations de formulaire et de champ accessibles via de simples

variables. 
[% jshead %]  -  JavaScript à insérer dans <head>
[% title  %]  -  Le <title> du formulaire HTML
[% start  %]  -  Balise <form> d'ouverture et champs internes
[% submit %]  -  Le(s) bouton(s) de soumission
[% reset  %]  -  Le bouton de réinitialisation
[% end    %]  -  Balise </form> de fermeture
[% fields %]  -  Liste des champs
[% field  %]  -  Hachage des champs (pour recherche par
nom)

Vous pouvez spécifier l'option "variable" pour rendre toutes ces variables accessibles sous un certain espace de noms. Par exemple

: 
my $form = CGI::FormBuilder->new(
    fields => \@fields,
    template => {
         type => 'TT2',
         template => 'form.tmpl',
         variable => 'form'
    },
)
;

Avec "variable" définie à "form", les variables sont accessibles comme

: 
[% form.jshead %]
[% form.start  %]
etc.

Vous pouvez accéder à des champs individuels via la variable "field"

. 
Pour un champ nommé...  Les données du champ sont dans...
--------------------  -----------------------
job                   [% form.field.job   %]
size                  [% form.field.size  %]
email                 [% form.field.email
%]

Chaque champ contient divers éléments. Par exemple

: 
[% myfield = form.field.email %]
[% myfield.label    %]  # étiquette de texte
[% myfield.field    %]  # balise de saisie du champ
[% myfield.value    %]  # première valeur
[% myfield.values   %]  # liste de toutes les valeurs
[% myfield.option   %]  # première valeur
[% myfield.options  %]  # liste de toutes les valeurs
[% myfield.required %]  # indicateur requis
[% myfield.invalid  %]  # indicateur
invalide

La variable "fields" contient une liste de tous les champs du formulaire. Pour parcourir tous les champs dans l'ordre, vous pourriez faire quelque chose comme ceci

: 
[% FOREACH field = form.fields %]
<tr>
 <td>[% field.label %]</td> <td>[% field.field %]</td>
</tr>
[% END
%]

Si vous souhaitez personnaliser l'une des options de Template Toolkit, vous pouvez définir l'option "engine" pour contenir une référence à un objet "Template" existant ou une référence de hachage d'options qui sont passées au constructeur "Template". Vous pouvez également définir l'élément "data" pour définir des variables supplémentaires que vous souhaitez accessibles lorsque le modèle est

traité. 
my $form = CGI::FormBuilder->new(
    fields => \@fields,
    template => {
         type => 'TT2',
         template => 'form.tmpl',
         variable => 'form',
         engine   => {
              INCLUDE_PATH => '/usr/local/tt2/templates',
         },
         data => {
              version => 1.23,
              author  => 'Fred Smith',
         },
    },
)
;

Pour plus de détails sur l'utilisation de Template Toolkit, voir "Template" ou http://www

.template-t
oolkit.org
