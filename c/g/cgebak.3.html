Documentation de la fonction/sous-routine

sous-routine cgebak (caractere job, caractere side, entier n, entier ilo, entier ihi, reel, dimension( * ) scale, entier m, complexe, dimension( ldv, * ) v, entier ldv, entier info)

CGEBAK

Objectif :

!>
!> CGEBAK forme les vecteurs propres droits ou gauches d'une matrice générale
!> complexe en effectuant une transformation arrière sur les vecteurs propres
!> calculés de la matrice équilibrée produite par CGEBAL.
!>

Paramètres

JOB 
!>          JOB est CARACTERE*1
!>          Spécifie le type de transformation arrière requise :
!>          = 'N' : ne rien faire, retourner immédiatement ;
!>          = 'P' : effectuer la transformation arrière pour la permutation uniquement ;
!>          = 'S' : effectuer la transformation arrière pour la mise à l'échelle uniquement ;
!>          = 'B' : effectuer les transformations arrière pour la permutation et la
!>                 mise à l'échelle.
!>          JOB doit être identique à l'argument JOB fourni à CGEBAL.
!>

SIDE

!>          SIDE est CARACTERE*1
!>          = 'R' : V contient les vecteurs propres droits ;
!>          = 'L' : V contient les vecteurs propres gauches.
!>

N

!>          N est ENTIER
!>          Le nombre de lignes de la matrice V. N >= 0.
!>

ILO

!>          ILO est ENTIER
!>

IHI

!>          IHI est ENTIER
!>          Les entiers ILO et IHI déterminés par CGEBAL.
!>          1 <= ILO <= IHI <= N, si N > 0 ; ILO=1 et IHI=0, si N=0.
!>

SCALE

!>          SCALE est un tableau REEL, de dimension (N)
!>          Détails de la permutation et des facteurs de mise à l'échelle, tels
!>          que retournés par CGEBAL.
!>

M

!>          M est ENTIER
!>          Le nombre de colonnes de la matrice V. M >= 0.
!>

V

!>          V est un tableau COMPLEXE, de dimension (LDV,M)
!>          À l'entrée, la matrice des vecteurs propres droits ou gauches à
!>          transformer, telle que retournée par CHSEIN ou CTREVC.
!>          À la sortie, V est écrasé par les vecteurs propres transformés.
!>

LDV

!>          LDV est ENTIER
!>          La dimension principale du tableau V. LDV >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale.
!>
