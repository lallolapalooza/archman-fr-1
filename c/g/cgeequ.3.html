subroutine cgeequ (m, n, a, lda, r, c, rowcnd, colcnd, amax, info)
CGEEQU

Documentation de la fonction/sous-programme

sous-programme cgeequ (integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) r, real, dimension( * ) c, real rowcnd, real colcnd, real amax, integer info)

CGEEQU

Objectif :

!>
!> CGEEQU calcule les échelles de lignes et de colonnes destinées à équilibrer une
!> matrice A de taille M par N et à réduire son nombre de condition. R renvoie les
!> facteurs d'échelle de ligne et C les facteurs d'échelle de colonne, choisis pour
!> tenter de faire en sorte que l'élément le plus grand de chaque ligne et colonne
!> de la matrice B dont les éléments sont B(i,j)=R(i)*A(i,j)*C(j) ait une valeur
!> absolue de 1.
!>
!> R(i) et C(j) sont limités à être entre SMLNUM = le plus petit nombre sûr
!> et BIGNUM = le plus grand nombre sûr. L'utilisation de ces facteurs d'échelle
!> n'est pas garantie de réduire le nombre de condition de A mais fonctionne bien
!> en pratique.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          La matrice M par N dont les facteurs d'équilibrage doivent
!>          être calculés.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

R

!>          R est un tableau REAL, dimension (M)
!>          Si INFO = 0 ou INFO > M, R contient les facteurs d'échelle de ligne
!>          pour A.
!>

C

!>          C est un tableau REAL, dimension (N)
!>          Si INFO = 0,  C contient les facteurs d'échelle de colonne pour A.
!>

ROWCND

!>          ROWCND est REAL
!>          Si INFO = 0 ou INFO > M, ROWCND contient le rapport du
!>          plus petit R(i) au plus grand R(i).  Si ROWCND >= 0.1 et
!>          AMAX n'est ni trop grand ni trop petit, il n'est pas utile
!>          de mettre à l'échelle avec R.
!>

COLCND

!>          COLCND est REAL
!>          Si INFO = 0, COLCND contient le rapport du plus petit
!>          C(i) au plus grand C(i).  Si COLCND >= 0.1, il n'est pas
!>          utile de mettre à l'échelle avec C.
!>

AMAX

!>          AMAX est REAL
!>          Valeur absolue de l'élément matriciel le plus grand.  Si AMAX est très
!>          proche du dépassement de capacité ou très proche du sous-dépassement,
!>          la matrice doit être mise à l'échelle.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i,  et i est
!>                <= M :  la i-ème ligne de A est exactement nulle
!>                >  M :  la (i-M)-ème colonne de A est exactement nulle
!>
