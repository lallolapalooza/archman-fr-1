sous-programme cgbrfsx (caractère trans, caractère equed, entier n, entier kl, entier ku, entier nrhs, complexe, dimension( ldab, * ) ab, entier ldab, complexe, dimension( ldafb, * ) afb, entier ldafb, entier, dimension( * ) ipiv, réel, dimension( * ) r, réel, dimension( * ) c, complexe, dimension( ldb, * ) b, entier ldb, complexe, dimension( ldx , * ) x, entier ldx, réel rcond, réel, dimension( * ) berr, entier n_err_bnds, réel, dimension( nrhs, * ) err_bnds_norm, réel, dimension( nrhs, * ) err_bnds_comp, entier nparams, réel, dimension( * ) params, complexe, dimension( * ) work, réel, dimension( * ) rwork, entier info)

CGBRFSX

But :

!>
!>    CGBRFSX améliore la solution calculée d'un système d'équations linéaires
!>    et fournit des bornes d'erreur et des estimations d'erreur à rebours
!>    pour la solution. En plus de la borne d'erreur normée, le code
!>    fournit une borne d'erreur composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires original peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED, R
!>    et C ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système non équilibré original.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Conjuguée transposée)
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibration qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     la solution et les bornes d'erreur correctement.
!>       = 'N':  Pas d'équilibration
!>       = 'R':  Équilibration par ligne, c'est-à-dire que A a été multipliée par
!>               diag(R).
!>       = 'C':  Équilibration par colonne, c'est-à-dire que A a été multipliée par
!>               diag(C).
!>       = 'B':  Équilibration par ligne et par colonne, c'est-à-dire que A a été
!>               remplacée par diag(R) * A * diag(C).
!>               Le membre de droite B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est tableau COMPLEX, dimension (LDAB,N)
!>     La matrice de bande originale A, stockée dans les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne du
!>     tableau AB comme suit :
!>     AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est tableau COMPLEX, dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice de bande A, tels que
!>     calculés par CGBTRF.  U est stockée comme une matrice triangulaire supérieure de bande
!>     avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1, et
!>     les multiplicateurs utilisés lors de la factorisation sont stockés dans
!>     les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB.  LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV est tableau INTEGER, dimension (N)
!>     Les indices de pivot de CGETRF ; pour 1<=i<=N, la ligne i de la
!>     matrice a été échangée avec la ligne IPIV(i).
!>

R

!>          R est tableau RÉEL, dimension (N)
!>     Les facteurs d'échelle de ligne pour A.  Si EQUED = 'R' ou 'B', A est
!>     multipliée à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé.  R est un argument d'entrée si FACT = 'F' ;
!>     sinon, R est un argument de sortie.  Si FACT = 'F' et
!>     EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>     Si R est une sortie, chaque élément de R est une puissance du radix.
!>     Si R est une entrée, chaque élément de R doit être une puissance du radix
!>     pour assurer une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances du radix ne provoque pas d'erreurs d'arrondi sauf si le
!>     résultat sous-dépasse ou dépasse les limites. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est tableau RÉEL, dimension (N)
!>     Les facteurs d'échelle de colonne pour A.  Si EQUED = 'C' ou 'B', A est
!>     multipliée à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé.  C est un argument d'entrée si FACT = 'F' ;
!>     sinon, C est un argument de sortie.  Si FACT = 'F' et
!>     EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>     Si C est une sortie, chaque élément de C est une puissance du radix.
!>     Si C est une entrée, chaque élément de C doit être une puissance du radix
!>     pour assurer une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances du radix ne provoque pas d'erreurs d'arrondi sauf si le
!>     résultat sous-dépasse ou dépasse les limites. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est tableau COMPLEX, dimension (LDB,NRHS)
!>     La matrice du membre de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est tableau COMPLEX, dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par CGETRS.
!>     À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est RÉEL
!>     Conditionnement inverse mis à l'échelle. Ceci est une estimation du
!>     nombre de conditionnement de Skeel inverse de la matrice A après
!>     équilibration (si effectuée). Si ceci est inférieur à la précision de la machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut encore
be small even !> si ce nombre est très petit et que la matrice semble mal !> conditionnée. !>

BERR

!>          BERR est un tableau REAL, de dimension (NRHS)
!>     Erreur résiduelle relative par composante. C'est l'erreur résiduelle
!>     relative par composante de chaque vecteur solution X(j) (c'est-à-dire
!>     le plus petit changement relatif dans un élément de A ou B qui rend X(j)
!>     une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est un entier
!>     Nombre de bornes d'erreur à retourner pour chaque second membre
!>     et chaque type (normale ou par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau REAL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à l'erreur
!>     relative normale, qui est définie comme suit :
!>
!>     Erreur relative normale dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur comme décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_NORM(:,err) contient les trois champs
!>     suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque normal estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              de l'erreur est . Ces nombres de condition réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriément mise à l'échelle.
!>              Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance
!>              de la base de manière à ce que toutes les sommes de lignes
!>              absolues de Z soient approximativement 1.
!>
!>     Voir la note de travail Lapack 165 pour plus de détails et des mises en
!>     garde supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau REAL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à l'erreur
!>     relative par composante, qui est définie comme suit :
!>
!>     Erreur relative par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend l'erreur relative
!>     par composante), et le type d'information d'erreur comme décrit ci-dessous.
!>     Il y a actuellement jusqu'à trois informations retournées pour chaque
!>     second membre. Si la précision par composante n'est pas demandée (PARAMS(3) = 0.0),
!>     alors ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus les
!>     premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_COMP(:,err) contient les trois champs
!>     suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque par composante estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              de l'erreur est . Ces nombres de condition réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriément mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance de la base de manière à ce que toutes
!>              les sommes de lignes absolues de Z soient approximativement 1.
!>
!>     Voir la note de travail Lapack 165 pour plus de détails et des mises en
!>     garde supplémentaires.
!>

NPARAMS

!>          NPARAMS est un entier
!>     Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0, le
!>     tableau PARAMS n'est jamais référencé et les valeurs par défaut sont
!>     utilisées.
!>

PARAMS

!>          PARAMS est un tableau REAL, de dimension NPARAMS
!>     Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre. Seules les positions jusqu'à NPARAMS sont accédées ; les
!>     valeurs par défaut sont utilisées pour les paramètres de rang supérieur.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Indique s'il faut effectuer un
!>            raffinage itératif ou non.
!>         Défaut : 1.0
!>            = 0.0 : Aucun raffinement n'est effectué, et aucune borne d'erreur
!>                    n'est calculée.
!>            = 1.0 : Utilise l'algorithme de raffinement en double précision,
!>                    éventuellement avec des calculs en simple précision doublée si
!>                    l'environnement de compilation ne supporte pas la DOUBLE
!>                    PRECISION.
!>              (d'autres valeurs sont réservées à un usage futur)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximum de calculs de résiduels
!>            autorisés pour le raffinement.
!>         Défaut : 10
!>         Agressif : Défini à 100 pour permettre la convergence en utilisant
!>                     des factorisations approximatives ou des factorisations autres
!>                     que LU. Si la factorisation utilise une technique autre que
!>                     l'élimination gaussienne, les garanties dans
!>                     err_bnds_norm et err_bnds_comp peuvent ne plus être
!>                     fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicateur déterminant si le code
!>            tentera de trouver une solution avec une petite erreur relative par
!>            composante dans l'algorithme de double précision. Positif
!>            signifie vrai, 0.0 signifie faux.
!>         Défaut : 1.0 (tenter la convergence par composante)
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau REAL, de dimension (2*N)
!>

INFO

!>          INFO est un entier
!>       = 0 : Sortie réussie. La solution pour chaque second membre est
!>         garantie.
!>       < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>       > 0 et <= N : U(INFO,INFO) est exactement zéro. La factorisation
!>         a été complétée, mais le facteur U est exactement singulier, donc
!>         la solution et les bornes d'erreur n'ont pas pu être calculées. RCOND = 0
!>         est retourné.
!>       = N+J : La solution correspondant au J-ème second membre n'est pas
!>         garantie. Les solutions correspondant aux autres seconds membres K avec K > J
!>         peuvent également ne pas être garanties, mais seul le premier second membre
!>         de ce type est rapporté. Si une erreur par composante petite n'est pas
!>         demandée (PARAMS(3) = 0.0), alors le J-ème second membre est le premier
!>         avec une borne d'erreur normale qui n'est pas garantie (le plus petit J tel
!>         que ERR_BNDS_NORM(J,1) = 0.0). Par défaut (PARAMS(3) = 1.0), le J-ème
!>         second membre est le premier avec une borne d'erreur normale ou par composante
!>         qui n'est pas garantie (le plus petit J tel que ERR_BNDS_NORM(J,1) = 0.0 ou
!>         ERR_BNDS_COMP(J,1) = 0.0). Voir la définition de
!>         ERR_BNDS_NORM(:,1) et ERR_BNDS_COMP(:,1). Pour obtenir des informations
!>         sur tous les seconds membres, vérifiez ERR_BNDS_NORM ou
!>         ERR_BNDS_COMP.
!>
