DESCRIPTIO

N

Ce module gère la localisation pour FormBuilder. Il est invoqué en spécifiant l'option « messages » à la méthode new() de FormBuilder. Actuellement, FormBuilder est livré avec plusieurs locales différentes 

: 
Anglais (par défaut)   en_US
Danois                da_DK
Allemand/Deutsch      de_DE
Espagnol/Espanol      es_ES
Japonais              ja_JP
Norvégien/Norvegian   no_NO
Turc                  tr_TR
Russe
ru_RU

Pour activer la localisation automatique qui détectera la locale du client et utilisera l'une de ces locales incluses, activez simplement les messages « auto » : « auto » 

: 
my $form = CGI::FormBuilder->new(messages => 'auto')
;

Ou, pour utiliser une locale spécifique, spécifiez-la sous la forme « :locale 

» 
# Forcer les messages en danois
my $form = CGI::FormBuilder->new(messages => ':da_DK')
;

En plus de ces locales incluses, vous pouvez entièrement personnaliser vos propres messages. Chaque message que FormBuilder produit est associé à une clé unique. Vous pouvez remplacer sélectivement les messages de FormBuilder en spécifiant une chaîne de message différente pour une clé de message

donnée.

Pour ce faire, créez d'abord un fichier et donnez-lui un nom unique. Dans cet exemple, nous utiliserons une locale abrégée comme suffixe 

: 
# messages.en
# Messages FormBuilder pour la locale "en"
js_invalid_start      %s erreur(s) ont été trouvées dans votre formulaire :\n
js_invalid_end        Corrigez ces champs et réessayez !
js_invalid_select     - Vous devez choisir une option pour le champ « %s »
\n

Ensuite, spécifiez ce fichier à new(

). 
my $form = CGI::FormBuilder->new(messages => 'messages.en')
;

Alternativement, vous pouvez le spécifier directement sous forme de référence de hachage 

: 
my $form = CGI::FormBuilder->new(
      messages => {
          js_invalid_start  => '%s erreur(s) ont été trouvées dans votre formulaire :\n',
          js_invalid_end    => 'Corrigez ces champs et réessayez !',
          js_invalid_select => '- Choisissez une option dans la liste « %s »\n',
      }
   )
;

Bien qu'en pratique ceci soit rarement utile, sauf si vous voulez juste ajuster une ou deux

choses.

Ce système est simple, et il existe de très nombreux messages pouvant être personnalisés. Voici une liste de messages, avec leurs valeurs par défaut 

: 
form_invalid_input          Entrée invalide
form_invalid_checkbox       Cochez une ou plusieurs options
form_invalid_file           Nom de fichier invalide
form_invalid_password       Entrée invalide
form_invalid_radio          Choisissez une option
form_invalid_select         Sélectionnez une option dans cette liste
form_invalid_textarea       Veuillez remplir ce champ
form_invalid_default        Entrée invalide
form_invalid_text           %s erreur(s) ont été rencontrées avec votre soumission.
                            Veuillez corriger les champs %smis en évidence%s ci-dessous.
form_required_text          Les champs %smis en évidence%s sont obligatoires.
form_confirm_text           Succès ! Votre soumission a été reçue %s.
form_select_default         -sélectionner-
form_grow_default           %s supplémentaire(s)
form_other_default          Autre :
form_reset_default          Réinitialiser
form_submit_default         Soumettre
js_noscript                 Veuillez activer JavaScript ou utiliser un navigateur plus récent.
js_invalid_start            %s erreur(s) ont été rencontrées avec votre soumission :
js_invalid_end              Veuillez corriger ces champs et réessayer.
js_invalid_checkbox         - Cochez une ou plusieurs des options « %s »
js_invalid_default          - Entrée invalide pour le champ « %s »
js_invalid_file             - Nom de fichier invalide pour le champ « %s »
js_invalid_input            - Entrée invalide pour le champ « %s »
js_invalid_multiple         - Sélectionnez une ou plusieurs options dans la liste « %s »
js_invalid_password         - Entrée invalide pour le champ « %s »
js_invalid_radio            - Choisissez l'une des options « %s »
js_invalid_select           - Sélectionnez une option dans la liste « %s »
js_invalid_textarea         - Veuillez remplir le champ « %s »
mail_confirm_subject        Confirmation de soumission %s
mail_confirm_text           Votre soumission a été reçue %s et sera traitée sous peu.
mail_results_subject        Résultats de la soumission
%s

Les balises « js_ » sont utilisées dans les alertes JavaScript, tandis que les balises « form_ » sont utilisées dans le HTML et les modèles gérés par

FormBuilder.

Dans certains messages, vous remarquerez un %s de format « printf ». C'est parce que ces messages incluront certains détails pour vous. Par exemple, la balise « js_invalid_start » affichera le nombre d'erreurs si vous incluez la balise de format %s. Bien sûr, ceci est facultatif, et vous pouvez

l'omettre.

La meilleure façon de comprendre le fonctionn

ement de ceci est d'expérimenter un peu.
Cela devrait devenir évident très rapidement.
