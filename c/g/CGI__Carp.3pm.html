Pour activer cette fonctionnalité, exportez la nouvelle sous-routine "warningsToBrowser". Comme l'envoi des avertissements au navigateur avant que les en-têtes HTTP aient été envoyés causerait une erreur, les avertissements sont stockés dans un tampon interne jusqu'à ce que vous appeliez la sous-routine warningsToBrowser() avec un argument vrai

REMPLACER LE NOM DU

PROGRAMME

CGI::Carp inclut le nom du programme qui a généré l'erreur ou l'avertissement dans les messages écrits dans le journal et la fenêtre du navigateur. Parfois, Perl peut se confondre quant au nom réel du programme exécuté. Dans ces cas, vous pouvez remplacer le nom du programme que CGI::Carp utilisera pour tous les

messages.

La manière rapide de le faire est d'indiquer à CGI::Carp le nom du programme dans sa directive use. Vous pouvez le faire en ajoutant "name=cgi_carp_log_name" à votre directive "use". Par exemple

: 
use CGI::Carp qw(name=cgi_carp_log_name)
;

. Si vous souhaitez changer le nom du programme en cours d'exécution, vous pouvez utiliser la fonction set_progname() à la place. Elle n'est pas exportée par défaut, vous devez l'importer explicitement en

écrivant 
use CGI::Carp qw(set_progname)
;

Une fois que vous avez fait cela, vous pouvez changer le nom du programme journalisé à tout moment en

appelant 
set_progname(nom_du_programme)
;

Vous pouvez remettre le programme par défaut en

appelant 
set_progname(undef)
;

Notez que ce remplacement n'a pas lieu avant la fin de la compi

lation du programme, de sorte que toute erreur de compilatio
n apparaîtra toujours avec le nom de programme non remplacé
