NOM

CGI::Session::Driver::DBI - Classe de base pour les pilotes CGI::Session natifs liés à DBI

SYNOPSIS

require CGI::Session::Driver::DBI;
@ISA = qw( CGI::Session::Driver::DBI );

DESCRIPTION

Dans la plupart des cas, vous pouvez créer un nouveau pilote CGI::Session basé sur DBI en créant simplement un fichier de pilote vide qui hérite de CGI::Session::Driver::DBI. C'est exactement ce que fait sqlite. La seule raison pour laquelle cette classe ne convient pas à un pilote valide est que son nom n'est pas en minuscules. Je suis sérieux !

NOTES

CGI::Session::Driver::DBI définit la méthode init(), qui rend le handle DBI disponible pour les pilotes dans l'attribut d'objet Handle, indépendamment de ce que "\%dsn_args" a été utilisé dans la création de l'objet session. Si votre pilote nécessite une initialisation non standard, vous devez redéfinir la méthode init() dans votre fichier .pm, mais assurez-vous de définir l'attribut d'objet 'Handle' au handle de base de données (renvoyé par DBI->connect(...)) si vous souhaitez hériter de certaines méthodes de CGI::Session::Driver::DBI.

STOCKAGE

Avant de pouvoir utiliser des pilotes de session basés sur DBI, vous devez vous assurer qu'une table de base de données compatible est créée pour que CGI::Session fonctionne. La commande suivante produira les exigences minimales dans la plupart des bases de données SQL :

CREATE TABLE sessions (
    id CHAR(32) NOT NULL PRIMARY KEY,
    a_session TEXT NOT NULL
);

Votre table de session peut définir des colonnes supplémentaires, mais les deux ci-dessus sont requises. Le nom de la table de session est attendu être sessions par défaut. Vous pouvez utiliser un nom différent si vous le souhaitez. Pour ce faire, vous devez passer TableName dans le cadre de vos " \%dsn_args " :

$s = CGI::Session->new('driver:sqlite', undef, {TableName=>'my_sessions'});
$s = CGI::Session->new('driver:mysql', undef,
{
    TableName=>'my_sessions',
    DataSource=>'dbi:mysql:shopping_cart'.
});

Pour utiliser des noms de colonnes différents, modifiez l'instruction 'create table', puis faites simplement ceci :

$s = CGI::Session->new('driver:pg', undef,
{
    TableName=>'session',
    IdColName=>'my_id',
    DataColName=>'my_data',
    DataSource=>'dbi:pg:dbname=project',
});

ou

$s = CGI::Session->new('driver:pg', undef,
{
    TableName=>'session',
    IdColName=>'my_id',
    DataColName=>'my_data',
    Handle=>$dbh,
});

ARGUMENTS DU PILOTE

Les arguments de pilote suivants sont pris en charge :

DataSource
Premier argument à passer à DBI->connect(). Si le pilote établit la connexion à la base de données lui-même, il se déconnectera également explicitement de la base de données lorsque l'objet pilote sera DÉTRUIT.
User
Utilisateur privilégié pour se connecter à la base de données définie dans "DataSource".
Password
Mot de passe de l'User privilégié pour se connecter à la base de données définie dans "DataSource"
Handle
Un objet handle de base de données DBI existant. Le handle peut être créé à la demande en fournissant une référence de code comme argument, telle que "<sub{DBI-"connect}>>. De cette façon, la connexion à la base de données n'est créée que si elle est réellement nécessaire. Cela peut être utile en combinaison avec un plugin de framework comme CGI::Application::Plugin::Session, qui crée également un objet CGI::Session à la demande.

"Handle" remplacera tous les arguments ci-dessus, s'il y en a.

TableName
Nom de la table dans laquelle les données de session seront stockées.
