NOM

CGI::Session::ID::incr - Driver d'ID CGI::Session

SYNOPSIS

use CGI::Session;
$session = CGI::Session->new("id:Incr", undef, {
                            Directory   => '/tmp',
                            IDFile      => '/tmp/cgisession.id',
                            IDInit      => 1000,
                            IDIncr      => 2 });

DESCRIPTION

CGI::Session::ID::incr est utilisé pour générer des ID de session auto-incrémentés. Comparez-le à CGI::Session::ID::md5, où les ID de session sont des chaînes de caractères aléatoires de 32 caractères de long. CGI::Session::ID::incr attend les arguments suivants passés à CGI::Session->new() comme troisième argument.

IDFile
Emplacement où sont stockés les ID auto-incrémentés. Cet attribut est requis.
IDInit
Valeur initiale de l'ID si c'est le premier ID à être généré. Par exemple, si vous voulez que les numéros d'ID commencent par 1000 au lieu de 0, c'est là que vous devez définir votre valeur. La valeur par défaut est 0.
IDIncr
De combien de chiffres chaque nombre doit-il s'incrémenter. Par exemple, si vous voulez que le premier ID généré commence par 1000, et que chaque ID subséquent s'incrémente de 10, définissez IDIncr à 10 et IDInit à 1000. La valeur par défaut est 1.
