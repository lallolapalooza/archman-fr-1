NOM

CGI::FormBuilder::Multi - Créer des formulaires FormBuilder multi-pages

SYNOPSIS

use CGI::FormBuilder::Multi;
use CGI::Session;   # ou quelque chose de similaire
# "Méta-formulaire" de haut niveau
my $multi = CGI::FormBuilder::Multi->new(
    # options du formulaire 1
    { fields   => [qw(name email daytime_phone evening_phone)],
      title    => 'Basic Info',
      template => 'page1.tmpl',
      validate => { name => 'NAME', email => 'EMAIL' },
      required => [qw(name email daytime_phone)],
    },
    # options du formulaire 2
    { fields   => [qw(billing_name billing_card billing_exp
                      billing_address billing_city billing_state
                      billing_zip billing_phone)],
      title    => 'Billing',
      template => 'page2.tmpl',
      required => 'ALL',
    },
    # options du formulaire 3
    { fields   => [qw(same_as_billing shipping_address
                      shipping_city shipping_state shipping_zip)],
      title    => 'Shipping',
      template => 'page3.tmpl',
      required => 'ALL',
    },
    # quelques options spécifiques à ce module
    navbar => 1,
    # options restantes (pas dans des références de hachage) s'appliquent à tous les formulaires
    header => 1,
    method => 'POST',
    submit => 'Continue',
    values => $dbi_hashref_query,
);
# Obtenir le formulaire de la page courante
my $form = $multi->form;
if ($form->submitted && $form->validate) {
    # Récupérer l'identifiant de session
    my $sid = $form->sessionid;
    # Initialiser la session
    my $session = CGI::Session->new("driver:File", $sid, {Directory=>'/tmp'});
    # Stocker automatiquement les données mises à jour dans la session
    $session->save_param($form);
    # dernière page ?
    if ($multi->page == $multi->pages) {
        print $form->confirm;
        exit;
    }
    # Toujours ici, passer à la page suivante
    $multi->page++;
    # Et récupérer à nouveau le formulaire (pas de "my" sur $form !)
    $form = $multi->form;
    # S'assurer qu'il a le bon sessionid
    $form->sessionid($session->id);
    # à la page 3, nous avons un traitement spécial des champs
    if ($multi->page == 3) {
        $form->field(name    => 'same_as_billing',
                     type    => 'checkbox',
                     options => 'Yes',
                     jsclick => 'this.form.submit()');
    }
}
# Continuer et afficher le formulaire de la page suivante
print $form->render;

DESCRIPTION

Ce module fonctionne avec "CGI::FormBuilder" pour créer des formulaires multi-pages. Chaque formulaire est spécifié en utilisant les mêmes options que vous passeriez directement à FormBuilder. Voir CGI::FormBuilder pour une liste de ces options.

Le "méta-formulaire" multi-pages est un composite des formulaires individuels que vous spécifiez, liés ensemble via le paramètre CGI spécial "_page" . Le formulaire courant est disponible via la méthode form() , et la page courante est disponible via page(). C'est à vous de naviguer de manière appropriée :

my $multi = CGI::FormBuilder::Multi->new(...);
# formulaire courant
my $form  = $multi->form;
$multi->page++;         # page suivante
$multi->page--;         # et précédente
$multi->page = $multi->pages;   # aller à la dernière page
# formulaire courant
$form = $multi->form;

Pour que les choses soient aussi fluides que possible, vous devriez donner un titre à chacun de vos formulaires, même si vous utilisez un modèle. Cela permettra à "::Multi" de créer des liens croisés par nom au lieu de simplement "Page 2".

MÉTHODES

Les méthodes suivantes sont fournies :

new(\%form1, \%form2, opt => val)

Cela crée un nouvel objet "CGI::FormBuilder::Multi" . Les formulaires sont spécifiés comme des références de hachage d'options, dans l'ordre séquentiel, de manière similaire à la spécification des champs. L'ordre des formulaires est l'ordre dans lequel les pages seront parcourues.

En plus d'une référence de hachage, les formulaires peuvent être directement spécifiés comme un objet $form qui a déjà été créé. Pour les objets existants, ce qui suit ne s'applique pas.

Lorsque le premier argument non-référence est rencontré, tous les arguments restants sont considérés comme des options communes qui s'appliquent à tous les formulaires. De cette façon, vous pouvez spécifier des paramètres globaux pour des choses comme "method" ou "header" (qui seront probablement les mêmes), puis remplacer des paramètres individuels comme "fields" et "validate" au niveau de chaque formulaire.

Si vous ne souhaitez spécifier aucune option pour vos formulaires, vous pouvez à la place simplement spécifier l'option "pages" , par exemple :

my $multi = CGI::FormBuilder::Multi->new(pages => 3);

Avec cette approche, vous devrez assembler dynamiquement chaque page au fur et à mesure que vous les atteignez. La liste de diffusion peut aider.

Le "SYNOPSIS" ci-dessus est très représentatif d'une utilisation typique.

form()

Cela retourne le formulaire de la page courante, comme un objet créé directement par "CGI::FormBuilder->new". Toutes les méthodes et options FormBuilder valides fonctionnent sur le formulaire. Pour changer le formulaire retourné, utilisez page().

page($num)

Cela définit et retourne la page courante. Elle peut accepter un numéro de page soit comme argument, soit directement comme affectation :

$multi->page(1);    # page 1
$multi->page = 1;   # même chose
$multi->page++;     # page suivante
$multi->page--;     # reculer d'une page
if ($multi->page == $multi->pages) {
    # dernière page
}

Astuce : En général, vous ne devriez changer de page qu'une fois que vous avez validé le formulaire de la page courante de manière appropriée.

pages()

Cela retourne le nombre total de pages. En fait, ce qu'il retourne est un tableau de tous les formulaires (et il a donc l'alias forms()), qui se trouve juste devenir la longueur dans un contexte scalaire, comme partout ailleurs en Perl.

navbar($onoff)

Cela retourne une barre de navigation qui permet à l'utilisateur de sauter entre les pages du formulaire. C'est utile si vous voulez permettre à une personne de remplir différentes pages hors de l'ordre. Dans la plupart des cas, vous ne voulez pas cela, donc c'est désactivé par défaut.

Pour l'utiliser, la meilleure façon est de définir "navbar => 1" dans new(). Cependant, vous pouvez aussi l'obtenir vous-même pour rendre votre propre HTML :

my $html = $multi->navbar;      # HTML scalaire
my @link = $multi->navbar;      # tableau de liens

C'est utile dans quelque chose comme ceci :

my $nav = $multi->navbar;
$form = $multi->form;
$form->tmpl_param(navbar => $navbar);

La barre de navigation aura deux classes de style : "fb_multi_page" pour le lien de la page courante, et "fb_multi_link" pour les autres.
