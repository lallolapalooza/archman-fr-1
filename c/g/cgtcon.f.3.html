sous-routine cgtcon (caractère norm, entier n, complexe, dimension( * ) dl, complexe, dimension( * ) d, complexe, dimension( * ) du, complexe, dimension( * ) du2, entier, dimension( * ) ipiv, réel anorm, réel rcond, complexe, dimension( * ) work, entier info)

CGTCON

But :

!>
!> CGTCON estime la réciproque du nombre de condition d'une matrice complexe
!> tridiagonale A, en utilisant la factorisation LU calculée par
!> CGTTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et la réciproque du
!> nombre de condition est calculée comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou la norme
!>          de l'infini est requis :
!>          = '1' ou 'O' : norme 1 ;
!>          = 'I' : norme de l'infini.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

DL

!>          DL est tableau COMPLEX, dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L de la
!>          factorisation LU de A, tels que calculés par CGTTRF.
!>

D

!>          D est tableau COMPLEX, dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U
!>          provenant de la factorisation LU de A.
!>

DU

!>          DU est tableau COMPLEX, dimension (N-1)
!>          Les (n-1) éléments de la première superdiagonale de U.
!>

DU2

!>          DU2 est tableau COMPLEX, dimension (N-2)
!>          Les (n-2) éléments de la deuxième superdiagonale de U.
!>

IPIV

!>          IPIV est tableau INTEGER, dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice
!>          a été échangée avec la ligne IPIV(i).  IPIV(i) sera toujours égal
!>          à i ou i+1 ; IPIV(i) = i indique qu'un échange de ligne
!>          n'était pas requis.
!>

ANORM

!>          ANORM est REAL
!>          Si NORM = '1' ou 'O', la norme 1 de la matrice originale A.
!>          Si NORM = 'I', la norme de l'infini de la matrice originale A.
!>

RCOND

!>          RCOND est REAL
!>          La réciproque du nombre de condition de la matrice A,
!>          calculée comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est tableau COMPLEX, dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
