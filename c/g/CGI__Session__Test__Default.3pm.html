CGI::Session::Test::Default(3) Documentation Perl fournie par l'utilisateur CGI::Session::Test::Default(3)

NOM

CGI::Session::Test::Default - Exécute une suite de tests pour un pilote CGI::Session donné

new()

my $t = CGI::Session::Test::Default->new(
    # Ce sont toutes des valeurs optionnelles, avec les valeurs par défaut suivantes :
    dsn   => "driver:file",
    args  => undef,
    tests => 77,
);

Crée un nouvel objet de test, remplaçant éventuellement certains défauts.

number_of_tests()

my $new_num = $t->number_of_tests($new_num);

Une méthode d'accesseur/mutateur pour modifier le nombre de tests à exécuter, après l'appel de new() et avant run().

run()

$t->run();

Exécute la suite de tests. Voir new() pour définir les options associées.
