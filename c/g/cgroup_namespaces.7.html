cgroup_namespaces(7)

NAME

cgroup_namespaces - control groups namespaces

DESCRIPTION

A namespace is a feature of the Linux kernel that isolates a system resource by associating certain process trees with a set of resource control trees. Namespaces allow for a system resource (such as the network stack or the mount table) to have different attributes and values for processes inside the namespace than for processes outside the namespace.

The cgroup namespace isolates the view of the control group hierarchy. When a process is started in a new cgroup namespace, it sees a new, isolated view of the control group hierarchy. The process can then manipulate its own view of the control group hierarchy, but it cannot affect the control group hierarchy seen by other processes that are not in the same cgroup namespace.

The primary effect of the cgroup namespace is to change the apparent location of the root control group (/) within the hierarchy. In a new cgroup namespace, the process sees its own root control group as /, regardless of its actual location in the host's control group hierarchy.

This allows for a more isolated and secure execution environment, where processes within the namespace cannot interfere with or observe the control group configurations of other processes outside the namespace.

STANDARDS

This is a Linux kernel feature and is not standardized by any formal standards body.

NOTES

The cgroup namespace is typically used in conjunction with other namespaces (such as the PID, network, and mount namespaces) to create fully isolated containers or virtual environments. For example, a container might have its own PID namespace, its own network namespace, and its own cgroup namespace, providing a high degree of isolation from the host system and other containers.

To create a new cgroup namespace, you can use the unshare command with the --cgroup` option:

unshare --cgroup command

Alternatively, you can use the clone system call with the CLONE_NEWCGROUP flag.

namespaces(7), unshare(1), clone(2)

cgroup_namespaces(7)

NOM

cgroup_namespaces - espaces de noms de groupes de contrôle

DESCRIPTION

Un espace de noms est une fonctionnalité du noyau Linux qui isole une ressource système en associant certains arbres de processus à un ensemble d'arbres de contrôle de ressources. Les espaces de noms permettent à une ressource système (telle que la pile réseau ou la table des montages) d'avoir des attributs et des valeurs différents pour les processus à l'intérieur de l'espace de noms par rapport aux processus à l'extérieur de l'espace de noms.

L'espace de noms cgroup isole la vue de la hiérarchie des groupes de contrôle. Lorsqu'un processus est lancé dans un nouvel espace de noms cgroup, il voit une nouvelle vue isolée de la hiérarchie des groupes de contrôle. Le processus peut alors manipuler sa propre vue de la hiérarchie des groupes de contrôle, mais il ne peut pas affecter la hiérarchie des groupes de contrôle vue par d'autres processus qui ne sont pas dans le même espace de noms cgroup.

L'effet principal de l'espace de noms cgroup est de changer l'emplacement apparent du groupe de contrôle racine (/) dans la hiérarchie. Dans un nouvel espace de noms cgroup, le processus voit son propre groupe de contrôle racine comme /, quelle que soit sa position réelle dans la hiérarchie des groupes de contrôle de l'hôte.

Cela permet un environnement d'exécution plus isolé et plus sécurisé, où les processus à l'intérieur de l'espace de noms ne peuvent pas interférer avec ou observer les configurations de groupes de contrôle des autres processus à l'extérieur de l'espace de noms.

NORMES

Il s'agit d'une fonctionnalité du noyau Linux et elle n'est standardisée par aucun organisme de normalisation formel.

NOTES

L'espace de noms cgroup est généralement utilisé en conjonction avec d'autres espaces de noms (tels que les espaces de noms PID, réseau et montage) pour créer des conteneurs ou des environnements virtuels entièrement isolés. Par exemple, un conteneur peut avoir son propre espace de noms PID, son propre espace de noms réseau et son propre espace de noms cgroup, offrant un haut degré d'isolation par rapport au système hôte et aux autres conteneurs.

Pour créer un nouvel espace de noms cgroup, vous pouvez utiliser la commande unshare avec l'option --cgroup :

unshare --cgroup commande

Alternativement, vous pouvez utiliser l'appel système clone avec l'indicateur CLONE_NEWCGROUP.

namespaces(7), unshare(1), clone(2)
