Documentation de la fonction/sous-programme

sous-programme cgehd2 (integer n, integer ilo, integer ihi, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer info)

CGEHD2 réduit une matrice carrée générale complexe à la forme de Hessenberg supérieure à l'aide d'un algorithme non bloqué.

Objectif :

!>
!> CGEHD2 réduit une matrice générale complexe A à la forme de Hessenberg
!> supérieure H par une transformation unitaire de similarité :  Q**H * A * Q = H .
!>

Paramètres

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>
!>          On suppose que A est déjà triangulaire supérieure en lignes
!>          et colonnes 1:ILO-1 et IHI+1:N. ILO et IHI sont normalement
!>          définis par un appel précédent à CGEBAL ; sinon, ils devraient
!>          être définis à 1 et N respectivement. Voir Détails supplémentaires.
!>          1 <= ILO <= IHI <= max(1,N).
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA,N)
!>          À l'entrée, la matrice générale carrée n par n à réduire.
!>          À la sortie, le triangle supérieur et la première sous-diagonale
!>          de A sont écrasés par la matrice de Hessenberg supérieure H,
!>          et les éléments sous la première sous-diagonale, avec le
!>          tableau TAU, représentent la matrice unitaire Q comme un
!>          produit de réflecteurs élémentaires. Voir Détails supplémentaires.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau COMPLEX, de dimension (N-1)
!>          Les facteurs scalaires des réflecteurs élémentaires (voir
!>          Détails supplémentaires).
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

!>
!>  La matrice Q est représentée par un produit de (ihi-ilo) réflecteurs
!>  élémentaires
!>
!>     Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i) = 0, v(i+1) = 1 et v(ihi+1:n) = 0 ; v(i+2:ihi) est stocké à la
!>  sortie dans A(i+2:ihi,i), et tau dans TAU(i).
!>
!>  Le contenu de A est illustré par l'exemple suivant, avec
!>  n = 7, ilo = 2 et ihi = 6 :
!>
!>  à l'entrée,                       à la sortie,
!>
!>  ( a   a   a   a   a   a   a )    (  a   a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      h   h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  v4  h   h   h )
!>  (                         a )    (                          a )
!>
!>  où a dénote un élément de la matrice originale A, h dénote un
!>  élément modifié de la matrice de Hessenberg supérieure H, et vi dénote
!>  un élément du vecteur définissant H(i).
!>
