CGGSV

P

Objectif

: 
!>
!> Cette routine est obsolète et a été remplacée par la routine CGGSVP3.
!>
!> CGGSVP calcule les matrices unitaires U, V et Q telles que
!>
!>                    N-K-L  K    L
!>  U**H*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**H*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> où la matrice A12 de dimension K par K et la matrice B13 de dimension L
!> par L sont non singulières et triangulaires supérieures ; A23 est
!> triangulaire supérieure de dimension L par L si M-K-L >= 0, sinon A23
!> est trapézoïdale supérieure de dimension (M-K) par L. K+L = le rang
!> numérique effectif de la matrice (A**H,B**H)**H de dimension (M+P) par N.
!>
!> Cette décomposition est l'étape de prétraitement pour le calcul de la
!> Décomposition en Valeurs Singulières Généralisées (GSVD), voir la
!> sous-routine CGGSVD.
!
>

>

!>          section Objectif.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!
>

TOL

!>          TOLA est REAL
!
>

TOL

B 
!>          TOLB est REAL
!>
!>          TOLA et TOLB sont les seuils pour déterminer le rang numérique
!>          effectif de la matrice B et d'un sous-bloc de A. Généralement,
!>          ils sont définis à
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          La taille de TOLA et TOLB peut affecter la taille des erreurs
!>          arrière de la décomposition.
!
>

!
>

L

!>
!>          À la sortie, K et L spécifient la dimension des sous-blocs

!>          K + L = rang numérique effectif de (A**H,B**H)**H.
!
>

U 
!>          U est un tableau COMPLEX, dimension (LDU,M)
!>          Si JOBU = 'U', U contient la matrice unitaire U.
!>          Si JOBU = 'N', U n'est pas référencée.
