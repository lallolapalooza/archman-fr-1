sous-programme cgels (trans, m, n, nrhs, a, lda, b, ldb, work, lwork, info)
CGELS résout les systèmes surdéterminés ou sousdéterminés pour les matrices GE

Documentation de la fonction/sous-programme

sous-programme cgels (caractère trans, entier m, entier n, entier nrhs, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldb, * ) b, entier ldb, complexe, dimension( * ) work, entier lwork, entier info)

CGELS résout les systèmes linéaires complexes surdéterminés ou sousdéterminés impliquant une matrice A de taille M par N, ou sa transposée conjuguée, en utilisant une factorisation QR ou LQ de A.

Objectif :

!>
!> CGELS résout les systèmes linéaires complexes surdéterminés ou sousdéterminés
!> impliquant une matrice A de taille M par N, ou sa transposée conjuguée,
!> en utilisant une factorisation QR ou LQ de A.
!>
!> On suppose que A a un rang complet, et seule une protection rudimentaire
!> contre les matrices de rang déficient est fournie. Ce sous-programme ne détecte
!> que la déficience de rang exacte, où un élément diagonal du facteur triangulaire
!> de A est exactement zéro.
!>
!> Il est possible que l'un (ou plusieurs) des éléments diagonaux du facteur triangulaire
!> de A soient des nombres anormalement petits sans que ce sous-programme ne signale
!> d'erreur. Les solutions calculées pour de telles matrices quasi-déficientes en rang peuvent
!> être moins précises en raison d'une perte de précision numérique.
!>
!> Les options suivantes sont fournies :
!>
!> 1. Si TRANS = 'N' et m >= n : trouver la solution aux moindres carrés d'un
!>    système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>                 minimiser || B - A*X ||.
!>
!> 2. Si TRANS = 'N' et m < n : trouver la solution de norme minimale d'un
!>    système sousdéterminé A * X = B.
!>
!> 3. Si TRANS = 'C' et m >= n : trouver la solution de norme minimale d'un
!>    système sousdéterminé A**H * X = B.
!>
!> 4. Si TRANS = 'C' et m < n : trouver la solution aux moindres carrés d'un
!>    système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>                 minimiser || B - A**H * X ||.
!>
!> Plusieurs vecteurs de second membre b et vecteurs solution x peuvent être
!> traités en un seul appel ; ils sont stockés comme colonnes de la
!> matrice B de second membre de taille M par NRHS et de la matrice solution X
!> de taille N par NRHS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : le système linéaire implique A ;
!>          = 'C' : le système linéaire implique A**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >= 0.
!>

A

!>          A est tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M par N.
!>            si M >= N, A est écrasée par les détails de sa factorisation QR
!>                       renvoyée par CGEQRF ;
!>            si M <  N, A est écrasée par les détails de sa factorisation LQ
!>                       renvoyée par CGELQF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est tableau COMPLEX, dimension (LDB,NRHS)
!>          À l'entrée, la matrice B des vecteurs de second membre, stockée
!>          par colonne ; B est de taille M par NRHS si TRANS = 'N', ou de taille N par NRHS
!>          si TRANS = 'C'.
!>          À la sortie, si INFO = 0, B est écrasée par les vecteurs solution,
!>          stockés par colonne :
!>          si TRANS = 'N' et m >= n, les lignes 1 à n de B contiennent les vecteurs
!>          solution aux moindres carrés ; la somme des carrés résiduelle pour
!>          la solution dans chaque colonne est donnée par la somme des carrés
!>          des modules des éléments n+1 à m dans cette colonne ;
!>          si TRANS = 'N' et m < n, les lignes 1 à N de B contiennent les
!>          vecteurs solution de norme minimale ;
!>          si TRANS = 'C' et m >= n, les lignes 1 à M de B contiennent les
!>          vecteurs solution de norme minimale ;
!>          si TRANS = 'C' et m < n, les lignes 1 à M de B contiennent les
!>          vecteurs solution aux moindres carrés ; la somme des carrés résiduelle
!>          pour la solution dans chaque colonne est donnée par la somme des
!>          carrés des modules des éléments m+1 à N dans cette colonne.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= MAX(1,M,N).
!>

WORK

!>          WORK est tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= max( 1, MN + max( MN, NRHS ) ).
!>          Pour des performances optimales,
!>          LWORK >= max( 1, MN + max( MN, NRHS )*NB ).
!>          où MN = min(M,N) et NB est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO =  i, le i-ème élément diagonal du
!>                facteur triangulaire de A est exactement zéro, de sorte que A n'a pas
!>                de rang complet ; la solution aux moindres carrés n'a pas pu être
!>                calculée.
!>
