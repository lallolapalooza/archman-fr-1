Documentation de la fonction/sous-routine

sous-routine cgelsx (integer m, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, integer, dimension( * ) jpvt, real rcond, integer rank, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CGELSX résout des systèmes surdéterminés ou sous-déterminés pour les matrices GE

Objectif :

!>
!> Cette routine est obsolète et a été remplacée par la routine CGELSY.
!>
!> CGELSX calcule la solution de norme minimale d'un problème aux moindres carrés
!> complexes :
!>     minimiser || A * X - B ||
!> en utilisant une factorisation orthogonale complète de A. A est une matrice M x N
!> qui peut être de rang défectueux.
!>
!> Plusieurs vecteurs de membre droit b et vecteurs solution x peuvent être
!> gérés en un seul appel ; ils sont stockés comme colonnes de la matrice
!> B de membre droit M x NRHS et de la matrice solution X de dimension N x NRHS.
!>
!> La routine calcule d'abord une factorisation QR avec pivot de colonnes :
!>     A * P = Q * [ R11 R12 ]
!>                 [  0  R22 ]
!> avec R11 défini comme la plus grande sous-matrice principale dont le numéro de
!> conditionnement estimé est inférieur à 1/RCOND. L'ordre de R11, RANK,
!> est le rang effectif de A.
!>
!> Ensuite, R22 est considéré comme négligeable, et R12 est annihilé
!> par des transformations unitaires de la droite, arrivant à la
!> factorisation orthogonale complète :
!>    A * P = Q * [ T11 0 ] * Z
!>                [  0  0 ]
!> La solution de norme minimale est alors
!>    X = P * Z**H [ inv(T11)*Q1**H*B ]
!>                 [        0         ]
!> où Q1 comprend les RANK premières colonnes de Q.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres droits, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >= 0.
!>

A

!>          A est tableau COMPLEX, dimension (LDA,N)
!>          En entrée, la matrice A de dimension M x N.
!>          En sortie, A a été écrasée par les détails de sa
!>          factorisation orthogonale complète.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est tableau COMPLEX, dimension (LDB,NRHS)
!>          En entrée, la matrice B de membre droit M x NRHS.
!>          En sortie, la matrice solution X de dimension N x NRHS.
!>          Si m >= n et RANK = n, la somme des carrés des résidus
!>          pour la solution dans la i-ème colonne est donnée par la somme des
!>          carrés des éléments N+1:M de cette colonne.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,M,N).
!>

JPVT

!>          JPVT est tableau INTEGER, dimension (N)
!>          En entrée, si JPVT(i) .ne. 0, la i-ème colonne de A est une
!>          colonne initiale, sinon c'est une colonne libre. Avant
!>          la factorisation QR de A, toutes les colonnes initiales sont
!>          permutées vers les positions principales ; seules les colonnes
!>          libres restantes sont déplacées suite au pivotement de colonnes
!>          pendant la factorisation.
!>          En sortie, si JPVT(i) = k, alors la i-ème colonne de A*P
!>          était la k-ème colonne de A.
!>

RCOND

!>          RCOND est REAL
!>          RCOND est utilisé pour déterminer le rang effectif de A, qui
!>          est défini comme l'ordre de la plus grande sous-matrice triangulaire
!>          principale R11 dans la factorisation QR avec pivotement de A,
!>          dont le numéro de conditionnement estimé est < 1/RCOND.
!>

RANK

!>          RANK est INTEGER
!>          Le rang effectif de A, c'est-à-dire l'ordre de la sous-matrice
!>          R11.  C'est le même que l'ordre de la sous-matrice T11
!>          dans la factorisation orthogonale complète de A.
!>

WORK

!>          WORK est tableau COMPLEX, dimension
!>                      (min(M,N) + max( N, 2*min(M,N)+NRHS )),
!>

RWORK

!>          RWORK est tableau REAL, dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
