!>
!>    CGET24 vérifie le pilote expert de problème de valeurs propres non symétriques
!>    (forme de Schur) CGEESX.
!>
!>    Si COMP = .FALSE., les 13 premiers des tests suivants seront
!>    effectués sur la matrice d'entrée A, ainsi que les tests 14 et 15
!>    si LWORK est suffisamment grand.
!>    Si COMP = .TRUE., les 17 tests seront effectués.
!>
!>    (1)     0 si T est sous forme de Schur, 1/ulp sinon
!>           (pas de tri des valeurs propres)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Ici VS est la matrice des vecteurs propres de Schur, et T est sous forme de
!>      Schur (pas de tri des valeurs propres).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (pas de tri des valeurs propres).
!>
!>    (4)     0     si W sont les valeurs propres de T
!>            1/ulp sinon
!>            (pas de tri des valeurs propres)
!>
!>    (5)     0     si T(avec VS) = T(sans VS),
!>            1/ulp sinon
!>            (pas de tri des valeurs propres)
!>
!>    (6)     0     si eigenvalues(avec VS) = eigenvalues(sans VS),
!>            1/ulp sinon
!>            (pas de tri des valeurs propres)
!>
!>    (7)     0 si T est sous forme de Schur, 1/ulp sinon
!>            (avec tri des valeurs propres)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Ici VS est la matrice des vecteurs propres de Schur, et T est sous forme de
!>      Schur (avec tri des valeurs propres).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (avec tri des valeurs propres).
!>
!>    (10)    0     si W sont les valeurs propres de T
!>            1/ulp sinon
!>            Si l'espace de travail est suffisant, comparer également W avec et
!>            sans nombres de condition réciproques
!>            (avec tri des valeurs propres)
!>
!>    (11)    0     si T(avec VS) = T(sans VS),
!>            1/ulp sinon
!>            Si l'espace de travail est suffisant, comparer également T avec et sans
!>            nombres de condition réciproques
!>            (avec tri des valeurs propres)
!>
!>    (12)    0     si eigenvalues(avec VS) = eigenvalues(sans VS),
!>            1/ulp sinon
!>            Si l'espace de travail est suffisant, comparer également VS avec et sans
!>            nombres de condition réciproques
!>            (avec tri des valeurs propres)
!>
!>    (13)    si le tri a fonctionné et SDIM est le nombre de
!>            valeurs propres qui ont été SÉLECTIONNÉES
!>            Si l'espace de travail est suffisant, comparer également SDIM avec et
!>            sans nombres de condition réciproques
!>
!>    (14)    si RCONDE est le même, que VS et/ou RCONDV soient calculés ou non
!>
!>    (15)    si RCONDV est le même, que VS et/ou RCONDE soient calculés ou non
!>
!>    (16)  |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>       RCONDE est le nombre de condition moyen réciproque des valeurs propres
!>       calculé par CGEESX et RCDEIN (la valeur vraie pré-calculée)
!>       est fournie en entrée. cond(RCONDE) est le nombre de condition
!>       de RCONDE, et tient compte des erreurs dans le calcul de RCONDE,
!>       de sorte que la quantité résultante doit être O(ULP). cond(RCONDE)
!>       est essentiellement donné par norm(A)/RCONDV.
!>
!>    (17)  |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>       RCONDV est le nombre de condition réciproque du sous-espace invariant droit
!>       calculé par CGEESX et RCDVIN (la valeur vraie pré-calculée)
!>       est fournie en entrée. cond(RCONDV) est le nombre de condition
!>       de RCONDV, et tient compte des erreurs dans le calcul de RCONDV,
!>       de sorte que la quantité résultante doit être O(ULP).
!>       cond(RCONDV) est essentiellement donné par norm(A)/RCONDE.
!>

Paramètres

COMP 
!>          COMP est LOGICAL
!>          COMP décrit quels tests d'entrée effectuer :
!>            = .FALSE. si les nombres de condition calculés ne doivent pas
!>                      être testés par rapport à RCDVIN et RCDEIN
!>            = .TRUE.  s'ils doivent être comparés
!>

JTYPE

!>          JTYPE est INTEGER
!>          Type de matrice d'entrée. Utilisé pour étiqueter la sortie en cas d'erreur.
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension (4)
!>          Si COMP = .FALSE., la graine du générateur de nombres aléatoires
!>          utilisée pour produire la matrice.
!>          Si COMP = .TRUE., ISEED(1) = le numéro de l'exemple.
!>          Utilisé pour étiqueter la sortie en cas d'erreur.
!>

THRESH

!>          THRESH est REAL
!>          Un test sera considéré comme une erreur si la quantité calculée,
!>          comme décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être O(1), donc THRESH devrait être un multiple raisonnablement
!>          petit de 1, par exemple 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. Il doit être au moins zéro.
!>

NOUNIT

!>          NOUNIT est INTEGER
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine renvoie INFO différent de 0).
!>

N

!>          N est INTEGER
!>          La dimension de A. N doit être au moins 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA, N)
!>          Utilisé pour contenir la matrice dont les valeurs propres doivent être
!>          calculées.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A et H. LDA doit être au
!>          moins 1 et au moins N.
!>

H

!>          H est un tableau COMPLEX, dimension (LDA, N)
!>          Une autre copie de la matrice de test A, modifiée par CGEESX.
!>

HT

!>          HT est un tableau COMPLEX, dimension (LDA, N)
!>          Encore une autre copie de la matrice de test A, modifiée par CGEESX.
!>

W

!>          W est un tableau COMPLEX, dimension (N)
!>          Les valeurs propres calculées de A.
!>

WT

!>          WT est un tableau COMPLEX, dimension (N)
!>          Comme W, ce tableau contient les valeurs propres de A,
!>          mais celles calculées lorsque CGEESX ne calcule qu'une décomposition
!>          en valeurs propres partielle, c'est-à-dire pas de vecteurs de Schur.
!>

WTMP

!>          WTMP est un tableau COMPLEX, dimension (N)
!>          Comme W, ce tableau contient les valeurs propres de A,
!>          mais triées par partie réelle ou imaginaire croissante.
!>

VS

!>          VS est un tableau COMPLEX, dimension (LDVS, N)
!>          VS contient les vecteurs de Schur calculés.
!>

NAME

cget24 - computes the Schur vectors and reciprocal condition numbers for selected eigenvalues and Schur vectors of a general complex matrix.

SYNOPSIS

SUBROUTINE CGET24( COMP, SELECT, N, T, LDT, S, LDS, VS, LDVS, RCDEIN,
&                  RCDVIN, NSLCT, ISLCT, ISRT, RESULT, WORK, LWORK,
&                  RWORK, BWORK, INFO )




INTEGER            INFO
COMPLEX*16         RCDEIN
COMPLEX*16         RCDVIN
COMPLEX*16         S( LDS, * )
COMPLEX*16         T( LDT, * )
COMPLEX*16         VS( LDVS, * )
COMPLEX*16         WORK( * )
LOGICAL            BWORK( * )
LOGICAL            SELECT( * )
REAL*8             RESULT( * )
REAL*8             RWORK( * )
INTEGER            ISLCT( * )
INTEGER            LD LDT
INTEGER            LDVS
INTEGER            LDS
INTEGER            N
INTEGER            NSLCT
INTEGER            ISRT

Function/Subroutine Documentation

COMP

!>          COMP is LOGICAL
!>          = .TRUE.: Schur vectors are computed.
!>          = .FALSE.: Schur vectors are not computed.

SELECT

!>          SELECT is LOGICAL array, dimension (N)
!>          On entry, the SELECT array specifies which eigenvalues are
!>          to be selected. To select the j-th eigenvalue,
!>          SELECT(j) must be set to .TRUE..
!>          On exit, SELECT is unchanged.

N

!>          N is INTEGER
!>          The order of the matrix T. N >= 0.

T

!>          T is COMPLEX array, dimension (LDT, N)
!>          On entry, T contains the upper triangular matrix of the
!>          Schur decomposition.
!>          On exit, if COMP = .TRUE., T is overwritten by the
!>          reordered upper triangular matrix.
!>          If COMP = .FALSE., T is unchanged.

LDT

!>          LDT is INTEGER
!>          Leading dimension of T. LDT >= max(1,N).

S

!>          S is COMPLEX array, dimension (LDS, N)
!>          On entry, S contains the eigenvectors of the matrix T
!>          corresponding to the eigenvalues selected by SELECT.
!>          On exit, if COMP = .TRUE., S is overwritten by the
!>          reordered Schur vectors.
!>          If COMP = .FALSE., S is unchanged.

LDS

!>          LDS is INTEGER
!>          Leading dimension of S. LDS >= max(1,N).

VS

!>          VS is COMPLEX array, dimension (LDVS, N)
!>          On entry, VS contains the Schur vectors of the original
!>          matrix A.
!>          On exit, if COMP = .TRUE., VS is overwritten by the
!>          reordered Schur vectors.
!>          If COMP = .FALSE., VS is unchanged.

LDVS

!>          LDVS is INTEGER
!>          Leading dimension of VS. Must be at least max(1, N).

VS1

!>          VS1 is COMPLEX array, dimension (LDVS, N)
!>          VS1 holds another copy of the computed Schur vectors.

RCDEIN

!>          RCDEIN is REAL
!>          When COMP = .TRUE. RCDEIN holds the precomputed reciprocal
!>          condition number for the average of selected eigenvalues.

RCDVIN

!>          RCDVIN is REAL
!>          When COMP = .TRUE. RCDVIN holds the precomputed reciprocal
!>          condition number for the selected right invariant subspace.

NSLCT

!>          NSLCT is INTEGER
!>          When COMP = .TRUE. the number of selected eigenvalues
!>          corresponding to the precomputed values RCDEIN and RCDVIN.

ISLCT

!>          ISLCT is INTEGER array, dimension (NSLCT)
!>          When COMP = .TRUE. ISLCT selects the eigenvalues of the
!>          input matrix corresponding to the precomputed values RCDEIN
!>          and RCDVIN. For I=1, ... ,NSLCT, if ISLCT(I) = J, then the
!>          eigenvalue with the J-th largest real or imaginary part is
!>          selected. The real part is used if ISRT = 0, and the
!>          imaginary part if ISRT = 1.
!>          Not referenced if COMP = .FALSE.

ISRT

!>          ISRT is INTEGER
!>          When COMP = .TRUE., ISRT describes how ISLCT is used to
!>          choose a subset of the spectrum.
!>          Not referenced if COMP = .FALSE.

RESULT

!>          RESULT is REAL array, dimension (17)
!>          The values computed by the 17 tests described above.
!>          The values are currently limited to 1/ulp, to avoid
!>          overflow.

WORK

!>          WORK is COMPLEX array, dimension (2*N*N)

LWORK

!>          LWORK is INTEGER
!>          The number of entries in WORK to be passed to CGEESX. This
!>          must be at least 2*N, and N*(N+1)/2 if tests 14--16 are to
!>          be performed.

RWORK

!>          RWORK is REAL array, dimension (N)

BWORK

!>          BWORK is LOGICAL array, dimension (N)

INFO

!>          INFO is INTEGER
!>          If 0,  successful exit.
!>          If <0, input parameter -INFO had an incorrect value.
!>          If >0, CGEESX returned an error code, the absolute
!>                 value of which is returned.
