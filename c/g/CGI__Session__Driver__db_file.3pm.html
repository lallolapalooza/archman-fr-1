NOM

CGI::Session::Driver::db_file - Pilote CGI::Session pour BerkeleyDB utilisant DB_File

SYNOPSIS

$s = CGI::Session->new("driver:db_file", $sid);
$s = CGI::Session->new("driver:db_file", $sid, {FileName=>'/tmp/cgisessions.db'});

DESCRIPTION

db_file stocke les données de session dans un fichier BerkelyDB en utilisant DB_File - module Perl. Toutes les sessions seront stockées dans un seul fichier, spécifié dans l'argument du pilote FileName comme dans l'exemple ci-dessus. Si FileName n'est pas donné, la valeur par défaut est /tmp/cgisess.db, ou son équivalent sur un système non-UNIX.

Si la hiérarchie de répertoires menant au fichier n'existe pas, elle sera créée pour vous.

Ce module prend une option UMask qui sera utilisée si DB_File doit créer le fichier de base de données pour vous. Par défaut, le masque est 0660.
