NOM

cg_annotate - outil de post-traitement pour Cachegrind

SYNTAXE

cg_annotate [options] fichier-de-sortie-cachegrind [fichiers-source...]

DESCRIPTION

cg_annotate prend un ou plusieurs fichiers de sortie Cachegrind et affiche des données sur le programme profilé sous une forme facile à lire.

OPTIONS

-h --help

Affiche le message d'aide.

--version

Affiche le numéro de version.

--diff

Compare deux fichiers de sortie Cachegrind.

--mod-filename <regex> [par défaut : aucun]

Spécifie une expression de recherche et remplacement s/ancien/nouveau/ qui est appliquée à tous les noms de fichiers. Utile pour comparer, afin de supprimer les différences mineures dans les chemins entre deux versions différentes d'un programme situées dans des répertoires différents. Un suffixe i rend l'expression régulière insensible à la casse, et un suffixe g la fait correspondre plusieurs fois.

--mod-funcname <regex> [par défaut : aucun]

Comme --mod-filename, mais pour les noms de fichiers. Utile pour supprimer les différences mineures dans les noms aléatoires de fonctions auto-générées par certains compilateurs.

--show=A,B,C [par défaut : tous, en utilisant l'ordre dans le fichier de sortie Cachegrind]

Spécifie quels événements afficher (et l'ordre des colonnes). Par défaut, utilise tous les événements présents dans le fichier de sortie Cachegrind (et utilise l'ordre dans le fichier). Mieux utilisé en conjonction avec --sort.

--sort=A,B,C [par défaut : ordre dans le fichier de sortie Cachegrind]

Spécifie les événements sur lesquels le tri des entrées fichier:fonction et fonction:fichier sera basé.

--threshold=X [par défaut : 0,1 %]

Définit le seuil de signification pour les sections fichier:fonction et fonction:fichier. Un fichier ou une fonction est affiché s'il représente plus de X % des comptages pour l'événement de tri principal. Si on annote des fichiers source, cela affecte également les fichiers qui sont annotés.

--show-percs, --no-show-percs, --show-percs=<non|oui> [par défaut : oui]

Lorsque activé, un pourcentage est imprimé à côté de tous les comptages d'événements. Cela aide à évaluer l'importance relative de chaque fonction et ligne.

--annotate, --no-annotate, --auto=<non|oui> [par défaut : oui]

Active ou désactive l'annotation des fichiers source.

--context=N [par défaut : 8]

Le nombre de lignes de contexte à afficher avant et après chaque ligne annotée. Utilisez un nombre important (par exemple, 100000) pour afficher toutes les lignes source.

VOIR AUSSI

valgrind(1), $INSTALL/share/doc/valgrind/html/index.html ou http://www.valgrind.org/docs/manual/index.html.
