CGESVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices GE

But :

!>
!>    CGESVXX utilise la factorisation LU pour calculer la solution d'un
!>    système d'équations linéaires complexes  A * X = B,  où A est une
!>    matrice N×N et X et B sont des matrices N×NRHS.
!>
!>    Si cela est demandé, les bornes d'erreur à la fois dans la norme et
!>    maximales composante par composante sont renvoyées. CGESVXX renverra
!>    une solution avec une erreur garantie minime
!>    (O(eps) où eps est la précision machine de travail)
!>    sauf si la matrice est très mal conditionnée, auquel cas
!>    un avertissement est renvoyé. Les nombres de condition pertinents sont également
!>    calculés et renvoyés.
!>
!>    CGESVXX accepte les factorisations et les facteurs d'équilibrage
!>    fournis par l'utilisateur ; voir les définitions des options FACT et EQUED.
!>    La résolution avec raffinement et l'utilisation d'une factorisation provenant d'un appel
!>    CGESVXX précédent produira également une solution avec soit des erreurs O(eps)
!>    soit des avertissements, mais nous ne pouvons pas faire cette affirmation pour des factorisations
!>    et des facteurs d'équilibrage généraux fournis par l'utilisateur s'ils
!>    diffèrent de ce que CGESVXX produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>
!>      TRANS = 'N' :  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T' : (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C' : (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Que le système soit équilibré ou non dépend de
!>    l'échelle de la matrice A, mais si l'équilibrage est utilisé, A est
!>    écrasée par diag(R)*A*diag(C) et B par diag(R)*B (si TRANS='N')
!>    ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') comme
!>
!>      A = P * L * U,
!>
!>    où P est une matrice de permutation, L est une matrice triangulaire inférieure
!>    unitaire, et U est triangulaire supérieure.
!>
!>    3. Si certains U(i,i)=0, de sorte que U est exactement singulière, alors la
!>    routine se termine avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de condition de la matrice A (voir
!>    l'argument RCOND). Si l'inverse du nombre de condition est inférieur
!>    à la précision machine, la routine continue néanmoins à résoudre X
!>    et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    la routine utilisera le raffinement itératif pour essayer d'obtenir une petite
!>    erreur et de petites bornes d'erreur.  Le raffinement calcule le résidu à
!>    au moins deux fois la précision de travail.
!>
!>    6. Si l'équilibrage a été utilisé, la matrice X est multipliée à gauche par
!>    diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de sorte
!>    qu'elle résout le système original avant équilibrage.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS.  Ces
!>     paramètres déterminent la manière dont le raffinement est effectué, mais souvent
!>     les valeurs par défaut sont acceptables.  Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>     Indique si la forme factorisée de la matrice A est
!>     fournée à l'entrée, et si ce n'est pas le cas, si la matrice A doit être
!>     équilibrée avant d'être factorisée.
!>       = 'F' :  À l'entrée, AF et IPIV contiennent la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été
!>               équilibrée avec les facteurs d'échelle donnés par R et C.
!>               A, AF et IPIV ne sont pas modifiés.
!>       = 'N' :  La matrice A sera copiée dans AF et factorisée.
!>       = 'E' :  La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>     Indique la forme du système d'équations :
!>       = 'N' :  A * X = B     (Pas de transposition)
!>       = 'T' :  A**T * X = B  (Transposition)
!>       = 'C' :  A**H * X = B  (Transposition conjuguée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>     À l'entrée, la matrice A de dimension N×N.  Si FACT = 'F' et EQUED
!>     n'est pas 'N', alors A a dû être équilibrée par les facteurs
!>     d'échelle dans R et/ou C.  A n'est pas modifiée si FACT = 'F' ou
!>     'N', ou si FACT = 'E' et EQUED = 'N' à la sortie.
!>
!>     À la sortie, si EQUED .ne. 'N', A est mise à l'échelle comme suit :
!>     EQUED = 'R' :  A := diag(R) * A
!>     EQUED = 'C' :  A := A * diag(C)
!>     EQUED = 'B' :  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX, dimension (LDAF,N)
!>     Si FACT = 'F', alors AF est un argument d'entrée et à l'entrée
!>     contient les facteurs L et U de la factorisation
!>     A = P*L*U telle que calculée par CGETRF.  Si EQUED .ne. 'N', alors
!>     AF est la forme factorisée de la matrice équilibrée A.
!>
!>     Si FACT = 'N', alors AF est un argument de sortie et à la sortie
!>     renvoie les facteurs L et U de la factorisation A = P*L*U
!>     de la matrice originale A.
!>
!>     Si FACT = 'E', alors AF est un argument de sortie et à la sortie
!>     renvoie les facteurs L et U de la factorisation A = P*L*U
!>     de la matrice équilibrée A (voir la description de A pour
!>     la forme de la matrice équilibrée).
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Si FACT = 'F', alors IPIV est un argument d'entrée et à l'entrée
!>     contient lest indices from the factorization A = P*L*U
!>     as computed by CGETRF; row i of the matrix was interchanged
!>     with row IPIV(i).
!>
!>     If FACT = 'N', then IPIV is an output argument and on exit
!>     contains the pivot indices from the factorization A = P*L*U
!>     of the original matrix A.
!>
!>     If FACT = 'E', then IPIV is an output argument and on exit
!>     contains the pivot indices from the factorization A = P*L*U
!>     of the equilibrated matrix A.
!>

EQUED

!>          EQUED is CHARACTER*1
!>     Specifies the form of equilibration that was done.
!>       = 'N':  No equilibration (always true if FACT = 'N').
!>       = 'R':  Row equilibration, i.e., A has been premultiplied by
!>               diag(R).
!>       = 'C':  Column equilibration, i.e., A has been postmultiplied
!>               by diag(C).
!>       = 'B':  Both row and column equilibration, i.e., A has been
!>               replaced by diag(R) * A * diag(C).
!>     EQUED is an input argument if FACT = 'F'; otherwise, it is an
!>     output argument.
!>

R

!>          R is REAL array, dimension (N)
!>     The row scale factors for A.  If EQUED = 'R' or 'B', A is
!>     multiplied on the left by diag(R); if EQUED = 'N' or 'C', R
!>     is not accessed.  R is an input argument if FACT = 'F';
!>     otherwise, R is an output argument.  If FACT = 'F' and
!>     EQUED = 'R' or 'B', each element of R must be positive.
!>     If R is output, each element of R is a power of the radix.
!>     If R is input, each element of R should be a power of the radix
!>     to ensure a reliable solution and error estimates. Scaling by
!>     powers of the radix does not cause rounding errors unless the
!>     result underflows or overflows. Rounding errors during scaling
!>     lead to refining with a matrix that is not equivalent to the
!>     input matrix, producing error estimates that may not be
!>     reliable.
!>

C

!>          C is REAL array, dimension (N)
!>     The column scale factors for A.  If EQUED = 'C' or 'B', A is
!>     multiplied on the right by diag(C); if EQUED = 'N' or 'R', C
!>     is not accessed.  C is an input argument if FACT = 'F';
!>     otherwise, C is an output argument.  If FACT = 'F' and
!>     EQUED = 'C' or 'B', each element of C must be positive.
!>     If C is output, each element of C is a power of the radix.
!>     If C is input, each element of C should be a power of the radix
!>     to ensure a reliable solution and error estimates. Scaling by
!>     powers of the radix does not cause rounding errors unless the
!>     result underflows or overflows. Rounding errors during scaling
!>     lead to refining with a matrix that is not equivalent to the
!>     input matrix, producing error estimates that may not be
!>     reliable.
!>

B

!>          B is COMPLEX array, dimension (LDB,NRHS)
!>     On entry, the N-by-NRHS right hand side matrix B.
!>     On exit,
!>     if EQUED = 'N', B is not modified;
!>     if TRANS = 'N' and EQUED = 'R' or 'B', B is overwritten by
!>        diag(R)*B;
!>     if TRANS = 'T' or 'C' and EQUED = 'C' or 'B', B is
!>        overwritten by diag(C)*B.
!>

LDB

!>          LDB is INTEGER
!>     The leading dimension of the array B.  LDB >= max(1,N).
!>

X

!>          X is COMPLEX array, dimension (LDX,NRHS)
!>     If INFO = 0, the N-by-NRHS solution matrix X to the original
!>     system of equations.  Note that A and B are modified on exit
!>     if EQUED .ne. 'N', and the solution to the equilibrated system is
!>     inv(diag(C))*X if TRANS = 'N' and EQUED = 'C' or 'B', or
!>     inv(diag(R))*X if TRANS = 'T' or 'C' and EQUED = 'R' or 'B'.
!>

LDX

!>          LDX is INTEGER
!>     The leading dimension of the array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND is REAL
!>     Reciprocal scaled condition number.  This is an estimate of the
!>     reciprocal Skeel condition number of the matrix A after
!>     equilibration (if done).  If this is less than the machine
!>     precision (in particular, if it is zero), the matrix is singular
!>     to working precision.  Note that the error may still be small even
!>     if this number is very small and the matrix appears ill-
!>     conditioned.
!>

RPVGRW

!>          RPVGRW is REAL
!>     Reciprocal pivot growth.  On exit, this contains the reciprocal
!>     pivot growth factor norm(A)/norm(U). The 
!>     norm is used.  If this is much less than 1, then the stability of
!>     the LU factorization of the (equilibrated) matrix A could be poor.
!>     This also means that the solution X, estimated condition numbers,
!>     and error bounds could be unreliable. If factorization fails with
!>     0<INFO<=N, then this contains the reciprocal pivot growth factor
!>     for the leading INFO columns of A.  In CGESVX, this quantity is
!>     returned in WORK(1).
!>

BERR

!>          BERR is REAL array, dimension (NRHS)
!>     Componentwise relative backward error.  This is the
!>     componentwise relative backward error of each solution vector X(j)
!>     (i.e., the smallest relative change in any element of A or B that
!>     makes X(j) an exact solution).
!>

N_ERR_BNDS

!>          N_ERR_BNDS is INTEGER
!>     Number of error bounds to return for each right hand side
!>     and each type (normwise or componentwise).  See ERR_BNDS_NORM and
!>     ERR_BNDS_COMP below.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is REAL array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     normwise relative error, which is defined as follows:
!>
!>     Normwise relative error in the ith solution vector:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     The array is indexed by the type of error information as described
!>     below. There currently are up to three pieces of information
!>     returned.
!>
!>     The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_NORM(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated normwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*A, where S scales each row by a power of the
!>              radix so all absolute row sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is REAL array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right-hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!>              sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

NPARAMS

!>          NPARAMS is INTEGER
!>     Specifies the number of parameters set in PARAMS.  If <= 0, the
!>     PARAMS array is never referenced and default values are used.
!>

PARAMS

!>          PARAMS is REAL array, dimension NPARAMS
!>     Specifies algorithm parameters.  If an entry is < 0.0, then
!>     that entry will be filled with default value used for that
!>     parameter.  Only positions up to NPARAMS are accessed; defaults
!>     are used for higher-numbered parameters.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
!>            refinement or not.
!>         Default: 1.0
!>            = 0.0:  No refinement is performed, and no error bounds are
!>                    computed.
!>            = 1.0:  Use the double-precision refinement algorithm,
!>                    possibly with doubled-single computations if the
!>                    compilation environment does not support DOUBLE
!>                    PRECISION.
!>              (other values are reserved for future use)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
!>            computations allowed for refinement.

NAME


cgesvxx - computes the solution to a complex system of linear
    equations AX = B, with optimal pivoting and error bounding.

Function/Subroutine
    Documentation


CGESVXX


    Purpose
    =======
    CGESVXX computes the solution to a complex system of linear equations
    of the form
        A * X = B
    or
        A**T * X = B
    or
        A**H * X = B
    where A is an N-by-N matrix, X and B are N-by-NRHS matrices, T denotes the
    transpose, and H denotes the conjugate transpose.

    Before calling CGESVXX, the routine may use iterative refinement to
    improve the computed solution and error bounds.

    CGESVXX uses the partial pivoting LU factorization of A to compute the
    solution vectors X and the error bounds for the solutions of the
    corresponding system of linear equations.

    Arguments
    =========
    FACT       (input) CHARACTER*1
               Specifies the form of the system of equations:
               = 'N': None of the forms below is required. Solution is computed.
               = 'E': The option for iterative refinement is selected.
               = 'F': Factorize. The factorization of A is done, but not
                      explicitly given.
               = 'R': Recompute the solution. The solution is recomputed from
                      the factorization on fact.

    TRANSPOSE  (input) CHARACTER*1
               Specifies the form of the system of equations:
               = 'N': None of the forms below is required. Solution is computed.
               = 'T': A^T*X = B is computed.
               = 'C': A^H*X = B is computed.

    N          (input) INTEGER
               The number of linear equations, i.e., the dimension of the
               matrix A. N >= 0.

    NRHS       (input) INTEGER
               The number of right hand sides, i.e., the number of columns of
               the matrix B. NRHS >= 0.

    A          (input) COMPLEX array, dimension (LDA, N)
               On entry, the N-by-N coefficient matrix A.
               On exit, if FACT = 'F', the factors are stored in A.

    LDA        (input) INTEGER
               The leading dimension of the array A. LDA >= max(1, N).

    IPIVOT     (output) INTEGER array, dimension (N)
               The pivot indices of the factorization of A. PIVOT[i] stores
               the row index that was swapped with row i.

    EQUIL      (output) INTEGER
               An indicator of whether or not the matrix A was equilibrated
               before performing the partial LU factorization.
               = 0: No equilibration was performed, due to condition number
                    estimates.
               = 1: Equilibration was performed, and matrix A has been
                    updated.
               = 2: Equilibration was not performed, and matrix A has not
                    been updated.

    B          (input) COMPLEX array, dimension (LDB, NRHS)
               On entry, the N-by-NRHS right-hand side matrix B.
               On exit, the solution matrix X.

    LDB        (input) INTEGER
               The leading dimension of the array B. LDB >= max(1, N).

    EQUIL_B    (output) INTEGER
               This is an output parameter and it has the same meaning as
               EQUIL.

    EQUIL_C    (output) INTEGER
               This is an output parameter and it has the same meaning as
               EQUIL.

    RCOND      (output) REAL
               Estimate of the reciprocal condition number of the matrix A.
               RCOND is computed for the matrix A, however, if equilibration
               was performed, RCOND is an estimate for the equilibrated
               matrix. RCOND is returned as >= 0.

    ERR_BNDS_NORM (output) REAL array, dimension (NRHS)
               Error bounds for the infinity-norm of the solutions X.
               ERR_BNDS_NORM(J) = norm(X(J) - X(J)_true)
               where X(J) is the computed solution for the Jth column of B.
               The bounds are computed for the infinity-norm.

    ERR_BNDS_COMP (output) REAL array, dimension (NRHS)
               Error bounds for the componentwise relative error of the
               solutions X.
               ERR_BNDS_COMP(J) = max(|X(J) - X(J)_true| / (|X(J)|*ULP(X(J)) + |X(J)_true|*ULP(X(J)_true)))
               where ULP(x) is the unit roundoff in the machine, computed for
               the infinity-norm.

    FERROUT    (output) REAL array, dimension (NRHS)
               This is an output parameter and it has the same meaning as
               ERR_BNDS_NORM. It is computed for the componentwise relative
               error.

    INFO       (output) INTEGER
               = 0: Successful exit. The solution to every right-hand side is
