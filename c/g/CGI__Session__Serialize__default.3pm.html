NOM

CGI::Session::Serialize::default - Sérialiseur CGI::Session par défaut

DESCRIPTION

Cette bibliothèque est utilisée par le pilote CGI::Session pour sérialiser les données de session avant de les stocker sur disque.

Toutes les méthodes sont appelées en tant que méthodes de classe.

MÉTHODES

freeze($class, \%hash)
Reçoit deux arguments. Le premier est le nom de la classe, le second sont les données à sérialiser. Doit retourner une chaîne sérialisée en cas de succès, undef en cas d'échec. Le message d'erreur doit être défini à l'aide de "set_error()|CGI::Session::ErrorHandler/"set_error()""
thaw($class, $string)
Reçoit deux arguments. Le premier est le nom de la classe, le second est la chaîne de données *gelées*. Doit retourner une structure de données dégelée en cas de succès, undef en cas d'échec. Le message d'erreur doit être défini à l'aide de "set_error()|CGI::Session::ErrorHandler/"set_error()""

LICENCE

Pour le support et la licence, voir CGI::Session
