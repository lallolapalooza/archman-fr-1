!>
!> CGGSVD3 calcule la décomposition en valeurs singulières généralisées (GSVD)
!> d'une matrice complexe A de dimensions M×N et d'une matrice complexe B de dimensions P×N :
!>
!>       U**H*A*Q = D1*( 0 R ),    V**H*B*Q = D2*( 0 R )
!>
!> où U, V et Q sont des matrices unitaires.
!> Soit K+L = le rang numérique effectif de la
!> matrice (A**H,B**H)**H, alors R est une matrice triangulaire supérieure
!> non singulière de dimensions (K+L)×(K+L), D1 et D2 sont des matrices de dimensions
!> M×(K+L) et P×(K+L) respectivement, de structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N), et R33 est stocké
!>   ( 0  R22 R23 )
!>   dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> La routine calcule C, S, R, et éventuellement les matrices de
!> transformation unitaires U, V et Q.
!>
!> En particulier, si B est une matrice non singulière de dimensions N×N, alors la GSVD de
!> A et B donne implicitement la SVD de A*inv(B) :
!>                      A*inv(B) = U*(D1*inv(D2))*V**H.
!> Si ( A**H,B**H)**H a des colonnes orthonormales, alors la GSVD de A et B est aussi
!> égale à la décomposition CS de A et B. De plus, la GSVD peut
!> être utilisée pour dériver la solution du problème des valeurs propres :
!>                      A**H*A x = lambda* B**H*B x.
!> Dans certaines littératures, la GSVD de A et B est présentée sous la forme
!>                  U**H*A*X = ( 0 D1 ),   V**H*B*X = ( 0 D2 )
!> où U et V sont orthogonales et X est non singulière, et D1 et D2 sont
!> « diagonales ». La première forme de GSVD peut être convertie en la seconde
!> forme en prenant la matrice non singulière X comme
!>
!>                       X = Q*(  I   0    )
!>                             (  0 inv(R) )
!
>

NAME


CGGSVD3 — Singular value decomposition of a general matrix pair







SYNOPSIS


SUBROUTINE CGGSVD3( JOBU, JOBV, JOBQ, M, N, P, A, LDA, B, LDB, TOL,
                        K, L, ALPHA, BETA, U, LDU, V, LDV, Q, LDQ, WORK,
                        LWORK, IWORK, INFO )
INTEGER M, N, P, LDA, LDB, K, L, LDU, LDV, LDQ, LWORK, INFO
REAL TOL
COMPLEX A(LDA, *), B(LDB, *), U(LDU, *), V(LDV, *), Q(LDQ, *)
COMPLEX WORK( * )
INTEGER IWORK( * )
CHARACTER JOBU, JOBV, JOBQ








Function/Subroutine Documentation


CGGSVD3 computes the singular value decomposition (SVD)
    of a general matrix pair (A,B) of the same dimension N, where A and B
    are complex matrices of size M-by-N and P-by-N respectively.


    It is assumed that M >= N and P >= N.



The singular value decomposition is
    A = U * S1 * T
    B = V * S2 * T


where S1, S2, T are N-by-N matrices, and U, V are unitary matrices.
    The matrices S1 and S2 are upper triangular matrices of the form:


    S1 = [ SIGMA | 0 ]
         [ ----- | - ]
         [   0   | 0 ]

    S2 = [   0   | 0 ]
         [ ----- | - ]
         [   0   | 0 ]



where SIGMA is a K+L-by-K+L diagonal matrix with positive
    entries, and K+L is the effective rank of the matrix pair (A,B).


This subroutine is the blocked version of CGGSVD. It replaces
    the deprecated subroutine CGGSVD.


Input Parameters:




JOBU    (CHARACTER*1)
        Specifies whether to compute the matrices U and T.
        JOBU = 'U': The unitary matrix U is computed.
        JOBU = 'N': U and T are not computed.

JOBV    (CHARACTER*1)
        Specifies whether to compute the matrices V and T.
        JOBV = 'V': The unitary matrix V is computed.
        JOBV = 'N': V and T are not computed.

JOBQ    (CHARACTER*1)
        Specifies whether to compute the matrix Q.
        JOBQ = 'Q': The unitary matrix Q is computed.
        JOBQ = 'N': Q is not computed.

M       (INTEGER)
        The number of rows of A. M >= 0.

N       (INTEGER)
        The number of columns of A and B. N >= 0.

P       (INTEGER)
        The number of rows of B. P >= 0.

A       (COMPLEX array, dimension (LDA, N))
        The M-by-N matrix A.

LDA     (INTEGER)
        The leading dimension of the array A. LDA >= max(1, M).

B       (COMPLEX array, dimension (LDB, N))
        The P-by-N matrix B.

LDB     (INTEGER)
        The leading dimension of the array B. LDB >= max(1, P).

TOL     (REAL)
        The threshold to determine the effective rank of (A,B).
        Generally, it is set to max(M,N)*norm(A)*MACHEPS.
        It may affect the size of backward errors of the decomposition.

WORK    (COMPLEX array, dimension (LWORK))
        On exit, WORK(1) returns the optimal LWORK.





LWORK


        LWORK is INTEGER
        The dimension of the array WORK. LWORK >= 1.

        If LWORK = -1, then a workspace query is assumed; the routine
        only calculates the optimal size of the WORK array, returns
        this value as the first entry of the WORK array, and no error
        message related to LWORK is issued by XERBLA.



RWORK


        RWORK is REAL array, dimension (2*N)



IWORK


        IWORK is INTEGER array, dimension (N)
        On exit, IWORK stores the sorting information. More
        precisely, the following loop will sort ALPHA
           for I = K+1, min(M,K+L)
               swap ALPHA(I) and ALPHA(IWORK(I))
           endfor
        such that ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).



INFO


        INFO is INTEGER
        = 0:  successful exit.
        < 0:  if INFO = -i, the i-th argument had an illegal value.
        > 0:  if INFO = 1, the Jacobi-type procedure failed to
              converge.  For further details, see subroutine CTGSJA.

Paramètres Internes :

 TOLA    REAL
 TOLB    REAL
         TOLA et TOLB sont les seuils pour déterminer le rang effectif
         de (A**H,B**H)**H. Généralement, ils sont définis à
                  TOLA = MAX(M,N)*norm(A)*MACHEPS,
                  TOLB = MAX(P,N)*norm(B)*MACHEPS.
         La taille de TOLA et TOLB peut affecter la taille des erreurs
         rétrospectives de la décomposition.
