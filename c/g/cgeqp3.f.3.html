Documentation de la fonction/sous-programme

sous-programme cgeqp3 (entier m, entier n, complexe, dimension( lda, * ) a, entier lda, entier, dimension( * ) jpvt, complexe, dimension( * ) tau, complexe, dimension( * ) work, entier lwork, réel, dimension( * ) rwork, entier info)

CGEQP3

But :

!>
!> CGEQP3 calcule une factorisation QR avec pivot de colonnes d'une
!> matrice A :  A*P = Q*R  en utilisant les BLAS de niveau 3.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de type COMPLEXE, de dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M-par-N.
!>          À la sortie, le triangle supérieur du tableau contient la
!>          matrice trapézoïdale supérieure R de taille min(M,N)-par-N ; les éléments sous
!>          la diagonale, ainsi que le tableau TAU, représentent la
!>          matrice unitaire Q comme un produit de min(M,N) réflecteurs élémentaires.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

JPVT

!>          JPVT est un tableau de type ENTIER, de dimension (N)
!>          À l'entrée, si JPVT(J).ne.0, la J-ème colonne de A est permutée
!>          à l'avant de A*P (une colonne principale) ; si JPVT(J)=0,
!>          la J-ème colonne de A est une colonne libre.
!>          À la sortie, si JPVT(J)=K, alors la J-ème colonne de A*P était la
!>          la K-ème colonne de A.
!>

TAU

!>          TAU est un tableau de type COMPLEXE, de dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

WORK

!>          WORK est un tableau de type COMPLEXE, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO=0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= N+1.
!>          Pour des performances optimales LWORK >= ( N+1 )*NB, où NB
!>          est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête de mémoire de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau de type RÉEL, de dimension (2*N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur réel/complexe
!>  avec v(1:i-1) = 0 et v(i) = 1 ; v(i+1:m) est stocké à la sortie dans
!>  A(i+1:m,i), et tau dans TAU(i).
!>
