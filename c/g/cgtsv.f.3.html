Documentation de la fonction/sous-programme

sous-programme cgtsv (integer n, integer nrhs, complex, dimension( * ) dl, complex, dimension( * ) d, complex, dimension( * ) du, complex, dimension( ldb, * ) b, integer ldb, integer info)

CGTSV calcule la solution du système d'équations linéaires A * X = B pour les matrices GT

But :

!>
!> CGTSV  résout l'équation
!>
!>    A*X = B,
!>
!> où A est une matrice tridiagonale de taille N x N, par élimination gaussienne
!> avec pivotage partiel.
!>
!> Notez que l'équation  A**T *X = B  peut être résolue en échangeant l'ordre
!> des arguments DU et DL.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un entier (INTEGER)
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est un tableau de nombres complexes (COMPLEX array), de
!>          dimension (N-1).
!>          À l'entrée, DL doit contenir les (N-1) éléments sous-diagonaux
!>          de A.
!>          À la sortie, DL est écrasé par les (N-2) éléments de la
!>          deuxième superdiagonale de la matrice triangulaire supérieure U
!>          de la factorisation LU de A, dans DL(1), ..., DL(N-2).
!>

D

!>          D est un tableau de nombres complexes (COMPLEX array), de
!>          dimension (N).
!>          À l'entrée, D doit contenir les éléments diagonaux de A.
!>          À la sortie, D est écrasé par les N éléments diagonaux de U.
!>

DU

!>          DU est un tableau de nombres complexes (COMPLEX array), de
!>          dimension (N-1).
!>          À l'entrée, DU doit contenir les (N-1) éléments superdiagonaux
!>          de A.
!>          À la sortie, DU est écrasé par les (N-1) éléments de la première
!>          superdiagonale de U.
!>

B

!>          B est un tableau de nombres complexes (COMPLEX array), de
!>          dimension (LDB,NRHS).
!>          À l'entrée, la matrice B de membres de droite de taille N x NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, U(i,i) est exactement zéro, et la solution
!>                n'a pas été calculée. La factorisation n'a pas été
!>                achevée sauf si i = N.
!>
