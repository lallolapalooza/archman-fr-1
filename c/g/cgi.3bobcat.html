DESCRIPTIO

N

La classe CGI offre une interface pour les données soumises par des formulaires web. Les données sont envoyées à un script traitant les données en utilisant une balise <form action="/chemin/vers/script/formulaire">. Très souvent, il s'agit effectivement d'un script, comme un script Perl, mais il n'est pas nécessaire d'utiliser un langage de script. La classe CGI permet aux programmeurs C++ de traiter le formulaire par un exécutable, ce qui donne généralement un traitement plus rapide et des avantages en temps de construction grâce à la sécurité de type offerte par C++. La classe CGI gère automatiquement les données soumises en utilisant la méthode GET ainsi que les données soumises en utilisant la méthode POST

.

Par défaut, le constructeur de la classe écrit les lignes d'en-tête habituelles Content-type sur le flux de sortie standard. La sortie (html) supplémentaire d'une page de réponse doit être fournie par d'autres code. Par conséquent, un programme traitant un formulaire téléchargé aura une organisation comparable à la configuration de base suivante

: 
    // supposer que les includes et namespace std/FBB sont définis
    int main()
    {
        CGI cgi;
        cout << "<html><body>\n";
        if (parametersOK(cgi))
        {
            process(cgi);
            generateReplyPage();
        }
        else
            generateErrorPage();
        cout << "</body></html>\n;
}

Lorsque des erreurs sont détectées dans les données du formulaire reçues, un message d'erreur est écrit sur le flux de sortie standard et une exception FBB::Excepti

on est
levée.

CONSTRUCTEUR

S
o
CGI(bool defaultEscape = true, char const *header = "Content-type: text/html", std::ostream &out = std::cout) :
Le constructeur par défaut écrit l'en-tête de type de contenu standard sur le flux de sortie standard et utilisera std::cout pour la sortie. Spécifier 0 comme en-tête supprime la sortie de la ligne Content-type. Sinon, la ligne de type de contenu est également suivie de deux combinaisons de caractères \r\n. Par défaut, tous les caractères dans les variables de formulaire récupérées sont échappés. Les opérateurs d'insertion surchargés (voir ci-dessous) peuvent être utilisés pour modifier l'ensemble par défaut des caractères à échapper. La barre oblique inverse est utilisée comme caractère d'échappement. Le préfixe d'échappement n'est pas utilisé si la valeur defaultEscape est spécifiée comme false et si aucune insertion dans l'objet CGI n'a été
effe
ctuée.

Les constructeurs de copie et de

déplacement (et les opérateurs
d'affectation) sont disponibles.

Remarque : les trois opérateurs d'insertion suivants, qui définissent des ensembles de caractères devant être échappés, ne peuvent être utilisés qu'avant d'appeler l'un des membres param, begin ou end. Dès qu'un de ces trois derniers membres a été appelé, l'ensemble des caractères à échapper est fixé et toute tentative de modifier cet ensemble est ignorée silencieusement

.
o
char const *operator[](std::string const &key) const :
L'opérateur d'indexation retourne la valeur de la variable d'environnement spécifiée comme index. 0 est retourné si la variable spécifiée dans key n'est pas
définie.
o
CGI &operator<<(std::string const &accept) :
Les actions de ce membre sont supprimées une fois que param, begin ou end (voir ci-dessous) a été
appelé.
L'opérateur d'insertion peut être utilisé pour ajuster finement l'ensemble des caractères échappés dans les chaînes retournées par param (voir ci-dessous). Selon la valeur du paramètre defaultEscape du constructeur, les caractères insérés dans l'objet CGI seront ou ne seront pas échappés par une barre oblique
inverse.
Si le paramètre defaultEscape du constructeur a été spécifié comme true, alors l'opérateur d'insertion peut être utilisé pour définir un ensemble de caractères qui ne sont pas échap
pés.
Si defaultEscape a été spécifié comme false, alors l'opérateur d'insertion définira un ensemble de caractères qui seront écha
ppés.
La barre oblique inverse elle-même est toujours échappée et une demande de l'utiliser non échappée est ignorée
silencieusement.
La chaîne accept peut être spécifiée comme un ensemble de caractères d'expression régulière, sans les crochets carrés habituels. Par exemple, une insertion comme cgi << "-a-z0-9" définit l'ensemble composé du tiret, des lettres minuscules et des
chiffres.
Des caractères individuels, des plages de caractères (utilisant le tiret pour spécifier une plage) et toutes les classes de caractères standard ([:alnum:], [:alpha:], [:cntrl:], [:digit:], [:graph:], [:lower:], [:print:], [:punct:], [:space:], [:upper:] et [:xdigit:]) peuvent être utilisés pour spécifier un ensemble de caractères. En plus de ces classes de caractères standard, la classe [:cgi:] peut être utilisée pour définir l'ensemble composé des caractères " ’ ` ; et \
.
Notez que les classes de caractères standard et [:cgi:] nécessitent des crochets
carrés.
Lorsqu'une série d'insertions est effectuée, l'union des ensembles définis par ces insertions est
utilisée.
Remarque : l'utilisation de guillemets simples non échappés, de guillemets doubles, de caractères de backtick et de points-virgules dans des programmes CGI peut être risqué et n'est pas
conseillé.

Les actions de ce membre sont supprimées une fois que param, begin ou end (voir ci-dessous) a été
appelé.
Cet opérateur d'insertion est utilisé pour modifier le traitement d'échappement par défaut d'un seul caractère c. Le paramètre int est converti en interne en cha
r.
o
CGI &operator<<(std::pair<char, char> range) :
Les actions de ce membre sont supprimées une fois que param, begin ou end (voir ci-dessous) a été
appelé.
Cet opérateur d'insertion peut être utilisé pour modifier le traitement d'échappement par défaut d'une plage de caractères. Le deuxièmer doit être égal ou supérieur à la position du premier caractère de la paire dans la séquence de classement ASCII, sinon le membre n'aura aucun

EXEMPL

E 
#include "main.ih"
void showParam(CGI::MapStringVector::value_type const &mapValue)
{
    cout << "Param: " << mapValue.first << ’\n’;
    for (auto &str: mapValue.second)
        cout << "    " << CGI::dos2unix(str) << "\n"
            "    ";
    cout << ’\n’;
}
int main(int argc, char **argv)
try
{
    Arg &arg = Arg::initialize("evhm:", argc, argv);
    // usage and version are in the source archive in .../cgi/driver
    // arg.versionHelp(usage, version, 2);
    ifstream in(arg[0]);
    string line;
    while (getline(in, line))
    {
        size_t pos = line.find(’=’);
        if (pos == string::npos)
            continue;
                            // set environment vars simulating
                            // a GET form
        if (setenv(line.substr(0, pos).c_str(),
               line.substr(pos + 1).c_str(), true) == 0)
        {
            if (arg.option(’e’))
                cout << line.substr(0, pos).c_str() << ’=’ <<
                       line.substr(pos + 1).c_str() << ’\n’;
        }
        else
            cout << "FAILED: setenv " << line << ’\n’;
    }
    CGI cgi(false);             // chars are not escaped
    cgi << arg[1];
    if (arg.option(&line, ’m’))
        cgi.setMaxUploadSize(stoul(line), *line.rbegin());
    cout << "Max upload size (b): " << cgi.maxUploadSize() << ’\n’;
    CGI::Method method = cgi.method();
    cout << "To escape:\n" <<
            cgi << "\n"
            "Method: " << (method == CGI::GET ? "GET" : "POST") <<
            ’\n’;
    cout << "Query string: " << cgi.query() << ’\n’;
    cout << "Submit string: `" << cgi.param1("submit") << "’\n";
    for (auto &mapElement: cgi)
        showParam(mapElement);
    cout << "END OF PROGRAM\n";
}
catch (exception const &err)
{
    cout << err.what() << ’\n’;
    return 1;
}
catch (...)
{
    return 1;
}
