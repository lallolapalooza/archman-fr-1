CGGSVD calcule la décomposition en valeurs singulières (SVD) pour les matrices

OTHER

But

: 
!>
!> Cette routine est obsolète et a été remplacée par la routine CGGSVD3.
!>
!> CGGSVD calcule la décomposition en valeurs singulières généralisées (GSVD)
!> d'une matrice complexe A de dimension M par N et d'une matrice complexe B de dimension P par N :
!>
!>       U**H*A*Q = D1*( 0 R ),    V**H*B*Q = D2*( 0 R )
!>
!> où U, V et Q sont des matrices unitaires.
!> Soit K+L le rang numérique effectif de la
!> matrice (A**H,B**H)**H, alors R est une matrice triangulaire supérieure
!> non singulière de dimension (K+L)-par-(K+L), D1 et D2 sont des matrices
!> de dimension M-par-(K+L) et P-par-(K+L)
!> respectivement, de structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N), et R33 est stocké
!>   ( 0  R22 R23 )
!>   dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> La routine calcule C, S, R, et éventuellement les matrices de
!> transformation unitaires U, V et Q.
!>
!> En particulier, si B est une matrice non singulière de dimension N par N, alors la GSVD de
!> A et B donne implicitement la SVD de A*inv(B) :
!>                      A*inv(B) = U*(D1*inv(D2))*V**H.
!> Si ( A**H,B**H)**H a des colonnes orthonormales, alors la GSVD de A et B est aussi
!> égale à la décomposition CS de A et B. De plus, la GSVD peut
!> être utilisée pour dériver la solution du problème de valeurs propres :
!>                      A**H*A x = lambda* B**H*B x.
!> Dans certaines littératures, la GSVD de A et B est présentée sous la forme
!>                  U**H*A*X = ( 0 D1 ),   V**H*B*X = ( 0 D2 )
!> où U et V sont orthogonales et X est non singulière, et D1 et D2 sont
!> « diagonales ». La première forme de GSVD peut être convertie en la seconde
!> forme en prenant la matrice non singulière X comme
!>
!>                       X = Q*(  I   0    )
!>                             (  0 inv(R) )
!
>
