Regardons un dernier exemple. Ici, nous voulons un groupe de boutons radio qui permet à une personne de se retirer d'une liste de diffusion. Voici notre gabarit

Voulez-vous être sur notre liste de diffusion ?

</tmpl_loop>

Ensuite, nous allons modifier notre "mailopt" champ via field():

Enfin, vous pouvez également parcourir chaque champ en utilisant la boucle de premier niveau "fields" dans votre modèle. Cela vous permet de réutiliser le même modèle même si vos paramètres changent. Le code de modèle suivant parcourrait chaque champ, créant une ligne de tableau pour chacun :

<table>
<tmpl_loop fields>
<tr>
<td class="small"><tmpl_if required><b><tmpl_var label></b><tmpl_else><tmpl_var label></tmpl_if></td>
<td><tmpl_var field></td>
</tr>
</tmpl_loop>
</table>

Chaque boucle aura un "label", "field", "value", etc., comme ci-dessus.
