Documentation de la fonction/sous-routine

sous-routine cget10 (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) work, real, dimension( * ) rwork, real result)

CGET10

Objectif:

!>
!> CGET10 compare deux matrices A et B et calcule le rapport
!> RESULT = norm( A - B ) / ( norm(A) * M * EPS )
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes des matrices A et B.
!>

N

!>          N est un entier
!>          Le nombre de colonnes des matrices A et B.
!>

A

!>          A est un tableau de type COMPLEX, dimension (LDA,N)
!>          La matrice A de dimensions m x n.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est un tableau de type COMPLEX, dimension (LDB,N)
!>          La matrice B de dimensions m x n.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau de type COMPLEX, dimension (M)
!>

RWORK

!>          RWORK est un tableau de type COMPLEX, dimension (M)
!>

RESULT

!>          RESULT est un nombre REEL
!>          RESULT = norm( A - B ) / ( norm(A) * M * EPS )
!>
