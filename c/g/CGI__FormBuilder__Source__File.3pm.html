NOM

CGI::FormBuilder::Source::File - Initialiser FormBuilder à partir d'un fichier externe

SYNOPSIS

# utiliser le module principal
use CGI::FormBuilder;
my $form = CGI::FormBuilder->new(source => 'form.conf');
my $lname = $form->field('lname');  # comme d'habitude

DESCRIPTION

Ce module analyse un fichier contenant des options de configuration de FormBuilder et renvoie un hachage adapté à la création d'un nouvel objet $form . En général, vous ne devriez pas l'utiliser directement, mais plutôt passer un $filename à "CGI::FormBuilder", qui appelle ce module.

Le format de configuration emprunte à Python (aïe !) qui est sensible à l'indentation et aux sauts de ligne. Cela vous fait gagner du travail à long terme. Voici un formulaire complet :

    # bases du formulaire
    method: POST
    header: 1
    title:  Account Information
    # définir les champs
    fields:
        fname:
            label:   First Name
            size:    40
        minit:
            label:   Middle Initial
            size:    1
        lname:
            label:   Last Name
            size:    60
        email:
            size:    80
        phone:
            label:    Home Phone
            comment:  (optional)
            required: 0
        sex:
            label:   Gender
            options: M=Male, F=Female
            jsclick: javascript:alert('Change your mind??')
        # options personnalisées et sous-routine de tri
        state:
            options:  \&getstates
            sortopts: \&sortstates
        datafile:
            label:   Upload Survey Data
            type:    file
            growable:   1
    # valider nos champs ci-dessus
    validate:
        email:  EMAIL
        phone:  /^1?-?\d{3}-?\d{3}-?\d{4}$/
    required: ALL
    # créer deux boutons de soumission et ignorer la validation pour "Cancel"
    submit:  Update, Cancel
    jsfunc:  <<EOJS
  // ignorer la validation
  if (this._submit.value == 'Cancel') return true;
EOJS
    # CSS
    styleclass: acctInfoForm
    stylesheet: /style/acct.css

Toute option que FormBuilder accepte est prise en charge par ce fichier de configuration. Fondamentalement, chaque fois que vous placeriez une nouvelle accolade pour créer une structure de données imbriquée dans FormBuilder, vous mettez un saut de ligne et une indentation à la place.

Les options multiples DOIVENT être séparées par des virgules. Toute espace blanc est préservé intact, alors ne soyez pas confus et ne faites pas quelque chose comme ceci :

fields:
    send_me_emails:
        options: Yes No

Ce qui donnera une seule option "Yes No". Vous voulez :

fields:
    send_me_emails:
        options: Yes, No

Ou encore mieux :

fields:
    send_me_emails:
        options: 1=Yes, 0=No

Ou peut-être le mieux de tous :

fields:
    send_me_emails:
        options: 1=Yes Please, 0=No Thanks

Si vous êtes confus, rejoignez la liste de diffusion :

fbusers-subscribe@formbuilder.org

Nous pourrons vous aider.

MÉTHODES

new()

Cette méthode crée un nouvel objet "CGI::FormBuilder::Source::File" .

my $source = CGI::FormBuilder::Source::File->new;

Tous les arguments spécifiés sont considérés comme des valeurs par défaut, que le fichier surcharge ensuite. Par exemple, pour toujours désactiver "javascript" (afin que vous n'ayez pas à le faire dans tous vos fichiers de configuration), utilisez :

my $source = CGI::FormBuilder::Source::File->new(
                  javascript => 0
             );

Ensuite, chaque fichier analysé par $source aura la valeur "javascript => 0" sauf si ce fichier a lui-même un paramètre "javascript:" .

parse($source)

Cette méthode analyse la source spécifiée, qui est soit un $file, "\$string", ou "\@array", et renvoie un hachage qui peut être passé directement à "CGI::FormBuilder":

my %conf = $source->parse('myform.conf');
my $form = CGI::FormBuilder->new(%conf);

write_module($modname)

Cette méthode écrit réellement un module dans le répertoire courant que vous pouvez ensuite utiliser dans des scripts ultérieurs pour obtenir le même formulaire :

$source->parse('myform.conf');
$source->write_module('MyForm');    # écrire MyForm.pm
# puis dans votre code Perl
use MyForm;
my $form = MyForm->new;

Vous pouvez également surcharger les paramètres de "MyForm" de la même manière que vous le feriez dans FormBuilder":

my $form = MyForm->new(
                header => 1,
                submit => ['Save Changes', 'Abort']
           );

Cela accélérera les choses, car vous n'aurez pas à réanalyser le fichier à chaque fois. Bonne idée Peter.

NOTES

Ce module a été entièrement inspiré par "Text::FormBuilder" de Peter Eichman , bien que la syntaxe soit différente..

Rappelez-vous que pour obtenir un nouveau niveau dans une référence de hachage, vous devez ajouter un saut de ligne et une indentation. Ainsi, pour obtenir quelque chose comme ceci :

table => {cellpadding => 1, cellspacing => 4},
td    => {align => 'center', bgcolor => 'gray'},
font  => {face => 'arial,helvetica', size => '+1'},

Vous devez écrire :

table:
    cellpadding: 1
    cellspacing: 4
td:
    align: center
    bgcolor: gray
font:
    face: arial,helvetica
    size: +1

Vous avez compris l'idée...
