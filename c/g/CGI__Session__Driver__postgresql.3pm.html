CGI::Session::Driver::postgresql(3) Documentation Perl fournie par l'utilisateur CGI::Session::Driver::postgresql(3)

NOM

CGI::Session::Driver::postgresql - Driver PostgreSQL pour CGI::Session

SYNTAXE

use CGI::Session;
$session = CGI::Session->new("driver:PostgreSQL", undef, {Handle=>$dbh});

DESCRIPTION

CGI::Session::PostgreSQL est un driver CGI::Session pour stocker les données de session dans une table PostgreSQL.

STOCKAGE

Avant de pouvoir utiliser les drivers de session basés sur DBI, vous devez vous assurer qu'une table de base de données compatible est créée pour que CGI::Session fonctionne. La commande suivante produira les exigences minimales dans la plupart des bases de données SQL :

CREATE TABLE sessions (
    id CHAR(32) NOT NULL PRIMARY KEY,
    a_session BYTEA NOT NULL
);

et dans votre code, utilisez :

use CGI::Session;
$session = CGI::Session->new("driver:PostgreSQL", undef, {Handle=>$dbh, ColumnType=>"binary"});

Notez l'argument ColumnType. Le type texte de PostgreSQL a des problèmes lorsqu'il essaie de contenir un caractère nul. (Connu sous le nom de "\0" en Perl, à ne pas confondre avec le NULL SQL). Si vous savez qu'il n'y a aucune chance qu'un caractère nul apparaisse jamais dans les données sérialisées, vous pouvez omettre l'attribut ColumnType. L'utilisation d'un type de colonne BYTEA et de "ColumnType => 'binary'" est recommandée lors de l'utilisation de Storable comme sérialiseur ou s'il existe une possibilité qu'une valeur nulle apparaisse dans toutes les données sérialisées.

Pour utiliser des noms de colonnes différents, modifiez l'instruction 'create table', puis faites simplement ceci :

$s = CGI::Session->new('driver:pg', undef,
{
    TableName=>'session',
    IdColName=>'my_id',
    DataColName=>'my_data',
    DataSource=>'dbi:pg:dbname=project',
});

ou

$s = CGI::Session->new('driver:pg', undef,
{
    TableName=>'session',
    IdColName=>'my_id',
    DataColName=>'my_data',
    Handle=>$dbh,
});

Pour plus de détails, voir CGI::Session::Driver::DBI, la classe parente.

Voir également le driver sqlite, qui utilise une méthode différente pour traiter les données binaires.
