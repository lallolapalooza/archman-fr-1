sous-routine cgesvd (jobu, jobvt, m, n, a, lda, s, u, ldu, vt, ldvt, work, lwork, rwork, info)
CGESVD calcule la décomposition en valeurs singulières (SVD) des matrices GE

sous-routine cgesvd (character jobu, character jobvt, integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) s, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( ldvt, * ) vt, integer ldvt, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer

CGESVD calcule la décomposition en valeurs singulières (SVD) des matrices

GE

But

: 
!>
!> CGESVD calcule la décomposition en valeurs singulières (SVD) d'une matrice
!> complexe A de dimensions M par N, en calculant éventuellement les vecteurs
!> singuliers gauche et/ou droit. La SVD est écrite
!>
!>      A = U * SIGMA * conjugate-transpose(V)
!>
!> où SIGMA est une matrice de dimensions M par N qui est nulle sauf pour ses
!> min(m,n) éléments diagonaux, U est une matrice unitaire de dimensions M par M,
!> et V est une matrice unitaire de dimensions N par N. Les éléments diagonaux de
!> SIGMA sont les valeurs singulières de A ; elles sont réelles et non négatives,
!> et sont renvoyées en ordre décroissant. Les premières min(m,n) colonnes de
!> U et V sont les vecteurs singuliers gauche et droit de A.
!>
!> Notez que la routine renvoie V**H, et non V.
!
>

Paramètre

s
JOBU 
!>          JOBU est CHARACTER*1
!>          Spécifie les options pour calculer toute ou partie de la matrice U :
!>          = 'A' :  les M colonnes de U sont renvoyées dans le tableau U ;
!>          = 'S' :  les premières min(m,n) colonnes de U (les vecteurs singuliers
!>                   gauche) sont renvoyées dans le tableau U ;
!>          = 'O' :  les premières min(m,n) colonnes de U (les vecteurs singuliers
!>                   gauche) sont écrasées dans le tableau A ;
!>          = 'N' :  aucune colonne de U (aucun vecteur singulier gauche) n'est
!>                   calculée.
!
>

JOBV

T 
!>          JOBVT est CHARACTER*1
!>          Spécifie les options pour calculer toute ou partie de la matrice
!>          V**H :
!>          = 'A' :  les N lignes de V**H sont renvoyées dans le tableau VT ;
!>          = 'S' :  les premières min(m,n) lignes de V**H (les vecteurs singuliers
!>                   droit) sont renvoyées dans le tableau VT ;
!>          = 'O' :  les premières min(m,n) lignes de V**H (les vecteurs singuliers
!>                   droit) sont écrasées dans le tableau A ;
!>          = 'N' :  aucune ligne de V**H (aucun vecteur singulier droit) n'est
!>                   calculée.
!>
!>          JOBVT et JOBU ne peuvent pas être tous les deux 'O'.
!
>

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A. N >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M par N.
!>          À la sortie,
!>          si JOBU = 'O',  A est écrasée avec les premières min(m,n)
!>                          colonnes de U (les vecteurs singuliers gauche,
!>                          stockés par colonnes) ;
!>          si JOBVT = 'O', A est écrasée avec les premières min(m,n)
!>                          lignes de V**H (les vecteurs singuliers droit,
!>                          stockés par lignes) ;
!>          si JOBU .ne. 'O' et JOBVT .ne. 'O', le contenu de A
!>                          est détruit.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!
>

S 
!>          S est un tableau REAL, dimension (min(M,N))
!>          Les valeurs singulières de A, triées de sorte que S(i) >= S(i+1).
!
>

U 
!>          U est un tableau COMPLEX, dimension (LDU,UCOL)
!>          (LDU,M) si JOBU = 'A' ou (LDU,min(M,N)) si JOBU = 'S'.
!>          Si JOBU = 'A', U contient la matrice unitaire U de dimensions M par M ;
!>          si JOBU = 'S', U contient les premières min(m,n) colonnes de U
!>          (les vecteurs singuliers gauche, stockés par colonnes) ;
!>          si JOBU = 'N' ou 'O', U n'est pas référencée.
!
>

LD

U 
!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= 1 ; si
!>          JOBU = 'S' ou 'A', LDU >= M.
!
>

V

T 
!>          VT est un tableau COMPLEX, dimension (LDVT,N)
!>          Si JOBVT = 'A', VT contient la matrice unitaire V**H de dimensions
!>          N par N ;
!>          si JOBVT = 'S', VT contient les premières min(m,n) lignes de
!>          V**H (les vecteurs singuliers droit, stockés par lignes) ;
!>          si JOBVT = 'N' ou 'O', VT n'est pas référencée.
!
>

LDV

T 
!>          LDVT est INTEGER
!>          La dimension principale du tableau VT. LDVT >= 1 ; si
!>          JOBVT = 'A', LDVT >= N ; si JOBVT = 'S', LDVT >= min(M,N).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >=  MAX(1,2*MIN(M,N)+MAX(M,N)).
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, une interrogation de l'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!
>

RWOR

K 
!>          RWORK est un tableau REAL, dimension (5*min(M,N))
!>          À la sortie, si INFO > 0, RWORK(1:MIN(M,N)-1) contient les
!>          éléments superdiagonaux non convergés d'une matrice bidiagonale supérieure
!>          B dont la diagonale est dans S (pas nécessairement triée).
!>          B satisfait A = U * B * VT, elle a donc les mêmes valeurs
!>          singulières que A, et des vecteurs singuliers liés par U et VT.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 :  si CBDSQR n'a pas convergé, INFO indique combien de
!>                 superdiagonales d'une forme bidiagonale intermédiaire B
!>                 n'ont pas convergé vers zéro. Voir la description de RWORK
!>                 ci-dessus pour plus de détails.
!
>
