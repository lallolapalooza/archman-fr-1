sous-programme cggsvp3 (character jobu, character jobv, character jobq, integer m, integer p, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, real tola, real tolb, integer k, integer l, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( ldv, * ) v, integer ldv, complex, dimension( ldq, * ) q, integer ldq, integer, dimension( * ) iwork, real, dimension( * ) rwork, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CGGSVP3

Objectif :

!>
!> CGGSVP3 calcule les matrices unitaires U, V et Q telles que
!>
!>                    N-K-L  K    L
!>  U**H*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**H*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> où la matrice KxK A12 et la matrice LxL B13 sont des matrices triangulaires
!> supérieures non singulières ; A23 est triangulaire supérieure LxL si M-K-L >= 0,
!> sinon A23 est trapézoïdale supérieure (M-K)xL. K+L = le rang numérique effectif
!> de la matrice (M+P)xN (A**H,B**H)**H.
!>
!> Cette décomposition est l'étape de pré-traitement pour le calcul de la
!> décomposition en valeurs singulières généralisées (GSVD), voir le sous-programme
!> CGGSVD3.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          = 'U' : la matrice unitaire U est calculée ;
!>          = 'N' : U n'est pas calculée.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          = 'V' : la matrice unitaire V est calculée ;
!>          = 'N' : V n'est pas calculée.
!>

JOBQ

!>          JOBQ est CHARACTER*1
!>          = 'Q' : la matrice unitaire Q est calculée ;
!>          = 'N' : Q n'est pas calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B. P >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B. N >= 0.
!>

A

!>          A est tableau de type COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice AxN A.
!>          À la sortie, A contient la matrice triangulaire (ou trapézoïdale)
!>          décrite dans la section Objectif.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est tableau de type COMPLEX, dimension (LDB,N)
!>          À l'entrée, la matrice PxN B.
!>          À la sortie, B contient la matrice triangulaire décrite dans
!>          la section Objectif.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!>

TOLA

!>          TOLA est REAL
!>

TOLB

!>          TOLB est REAL
!>
!>          TOLA et TOLB sont les seuils pour déterminer le rang numérique effectif
!>          de la matrice B et d'un sous-bloc de A. Généralement,
!>          ils sont définis par
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          La taille de TOLA et TOLB peut affecter les erreurs inverses
!>          de la décomposition.
!>

K

!>          K est INTEGER
!>

L

!>          L est INTEGER
!>
!>          À la sortie, K et L spécifient la dimension des sous-blocs
!>          décrits dans la section Objectif.
!>          K + L = rang numérique effectif de (A**H,B**H)**H.
!>

U

!>          U est tableau de type COMPLEX, dimension (LDU,M)
!>          Si JOBU = 'U', U contient la matrice unitaire U.
!>          Si JOBU = 'N', U n'est pas référencé.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,M) si
!>          JOBU = 'U' ; LDU >= 1 sinon.
!>

V

!>          V est tableau de type COMPLEX, dimension (LDV,P)
!>          Si JOBV = 'V', V contient la matrice unitaire V.
!>          Si JOBV = 'N', V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V. LDV >= max(1,P) si
!>          JOBV = 'V' ; LDV >= 1 sinon.
!>

Q

!>          Q est tableau de type COMPLEX, dimension (LDQ,N)
!>          Si JOBQ = 'Q', Q contient la matrice unitaire Q.
!>          Si JOBQ = 'N', Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q' ; LDQ >= 1 sinon.
!>

IWORK

!>          IWORK est tableau de type INTEGER, dimension (N)
!>

RWORK

!>          RWORK est tableau de type REAL, dimension (2*N)
!>

TAU

!>          TAU est tableau de type COMPLEX, dimension (N)
!>

WORK

!>          WORK est tableau de type COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK,
!>          renvoie cette valeur comme première entrée du tableau WORK, et aucun
!>          message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
