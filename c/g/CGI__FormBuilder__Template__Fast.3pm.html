CGI::FormBuilder::Template::Fast(3) Documentation Perl fournie par l'utilisateur CGI::FormBuilder::Template::Fast(3)

NOM

CGI::FormBuilder::Template::Fast - Interface FormBuilder pour CGI::FastTemplate

SYNTAXE

 my $form = CGI::FormBuilder->new(
     fields   => \@whatever,
     template => {
         type => 'Fast',
         root => '/chemin/vers/templates',
         # utiliser des fichiers externes
         define => {
             form           => 'form.txt',
             field          => 'field.txt',
             invalid_field  => 'invalid_field.txt',
         },
         # ou définir en ligne
         define_nofile => {
             form => '<html><head></head><body>$DEBUT_FORM
                      <table>$CHAMPS</table>$SOUMETTRE $FIN_FORM</body></html>',
             # etc.
         },
     },
);

DESCRIPTION

Ce moteur adapte FormBuilder pour utiliser "CGI::FastTemplate". Veuillez lire attentivement cette documentation, car son utilisation diffère de manière importante des autres adaptateurs de template.

Vous devrez définir trois templates : "form", "field" et "invalid_field". Vous pouvez utiliser "define" pour pointer vers des fichiers externes (ce qui est le style recommandé de "CGI::FastTemplate"), ou "define_nofile"/ "define_raw" pour les définir en ligne. Les templates dans "define_nofile" ont la priorité sur "define_raw", et ces deux-là ont la priorité sur "define".

my $form = CGI::FormBuilder->new(
    # ...
    template => {
        type => 'FastTemplate',
        root => '/chemin/vers/templates',
        define => {
            form           => 'form.txt',
            field          => 'field.txt',
            invalid_field  => 'invalid_field.txt',
        },
        # ou, vous pouvez définir les templates directement
        define_nofile => {
            form => '<html><head></head><body>$DEBUT_FORM<table>'
                    '$CHAMPS</table>$SOUMETTRE $FIN_FORM</body></html>',
            # etc.
        },
    },
    # ...
);

Si vous utilisez "define" avec des templates externes, vous voudrez probablement aussi définir votre répertoire racine de templates avec le paramètre "root".

Dans chacun des templates de champ, les variables suivantes sont disponibles :

$NOM         # $field->name
$CHAMP       # $field->tag   (balise input HTML)
$VALEUR      # $field->value (première valeur seulement !)
$LIBELLE     # $field->label
$COMMENTAIRE # $field->comment
$ERREUR      # $field->error
$REQUIS      # $field->required ? 'required' : 'optional'

Tous les champs sont traités en séquence ; les champs valides utilisent le template "field", et les champs invalides le template "invalid_field". Le résultat de chacun de ces derniers est ajouté à la variable $CHAMPS, que vous devriez utiliser dans votre template "form". Dans le template "form", vous avez également accès aux variables suivantes :

$TITRE        # titre du formulaire
$DEBUT_FORM   # balise ouvrante du formulaire
$SOUMETTRE    # le bouton de soumission
$REINITIALISER # le bouton de réinitialisation
$FIN_FORM     # balise fermante du formulaire
$JS_ENTETE    # JavaScript de validation

Notez que puisque "CGI::FastTemplate" n'utilise rien d'autre que des variables scalaires simples, il n'y a pas de variables correspondant aux listes que d'autres moteurs ont (par exemple, les listes "fields" ou "options" dans "TT2" ou "Text::Template").

CGI::FormBuilder, CGI::FormBuilder::Template, CGI::FastTemplate
