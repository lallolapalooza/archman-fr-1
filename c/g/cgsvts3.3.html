!>
!> CGSVTS3 teste CGGSVD3, qui calcule la GSVD d'une matrice A de dimensions M par N
!> et d'une matrice B de dimensions P par N :
!>              U'*A*Q = D1*R et V'*B*Q = D2*R.
!
>

Paramètre

s
M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!
>

P 
!>          P est INTEGER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,M)
!>          La matrice A de dimensions M par N.
!
>

A

F 
!>          AF est un tableau COMPLEX, dimension (LDA,N)
!>          Détails de la GSVD de A et B, tels que renvoyés par CGGSVD3,
!>          voir CGGSVD3 pour plus de détails.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale des tableaux A et AF.
!>          LDA >= max( 1,M ).
!
>

B 
!>          B est un tableau COMPLEX, dimension (LDB,P)
!>          À l'entrée, la matrice B de dimensions P par N.
!
>

B

F 
!>          BF est un tableau COMPLEX, dimension (LDB,N)

>

>

>

V

!
>

Q

>

!>          RESULT est un tableau REAL, dimension (6)
!>          Les rapports de test :
!>          RESULT(1) = norm( U'*A*Q - D1*R ) / ( MAX(M,N)*norm(A)*ULP)

!>          RESULT(3) = norm( I - U'*U ) / ( M*ULP )
!>          RESULT(4) = norm( I - V'*V ) / ( P*ULP )
!>          RESULT(5) = norm( I - Q'*Q ) / ( N*ULP )
