sous-routine cggev (character jobvl, character jobvr, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) alpha, complex, dimension( * ) beta, complex, dimension( ldvl, * ) vl, integer ldvl, complex, dimension( ldvr, * ) vr, integer ldvr, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CGGEV calcule les valeurs propres et, optionnellement, les vecteurs propres gauche et/ou droit pour les matrices GE

But :

!>
!> CGGEV calcule pour une paire de matrices complexes non symétriques
!> N par N (A,B), les valeurs propres généralisées, et optionnellement,
!> les vecteurs propres généralisés gauche et/ou droit.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un
!> scalaire lambda ou un rapport alpha/beta = lambda, tel que A - lambda*B
!> est singulière. Elle est généralement représentée sous la forme de la
!> paire (alpha,beta), car il existe une interprétation raisonnable pour
!> beta=0, et même lorsque les deux sont nuls.
!>
!> Le vecteur propre généralisé droit v(j) correspondant à la
!> valeur propre généralisée lambda(j) de (A,B) satisfait
!>
!>              A * v(j) = lambda(j) * B * v(j).
!>
!> Le vecteur propre généralisé gauche u(j) correspondant à la
!> valeur propre généralisée lambda(j) de (A,B) satisfait
!>
!>              u(j)**H * A = lambda(j) * u(j)**H * B
!>
!> où u(j)**H est le conjugué-transposé de u(j).
!>

Paramètres

JOBVL 
!>          JOBVL est CHARACTER*1
!>          = 'N' :  ne pas calculer les vecteurs propres généralisés gauches ;
!>          = 'V' :  calculer les vecteurs propres généralisés gauches.
!>

JOBVR

!>          JOBVR est CHARACTER*1
!>          = 'N' :  ne pas calculer les vecteurs propres généralisés droits ;
!>          = 'V' :  calculer les vecteurs propres généralisés droits.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, VL et VR.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA, N)
!>          À l'entrée, la matrice A de la paire (A,B).
!>          À la sortie, A a été écrasée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX, dimension (LDB, N)
!>          À l'entrée, la matrice B de la paire (A,B).
!>          À la sortie, B a été écrasée.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA est un tableau COMPLEX, dimension (N)
!>

BETA

!>          BETA est un tableau COMPLEX, dimension (N)
!>          À la sortie, ALPHA(j)/BETA(j), j=1,...,N, seraient les
!>          valeurs propres généralisées.
!>
!>          Remarque : les quotients ALPHA(j)/BETA(j) peuvent facilement
!>          déborder ou être trop petits, et BETA(j) peut même être nul.
!>          Ainsi, l'utilisateur devrait éviter de calculer naïvement le
!>          rapport alpha/beta.
!>          Cependant, ALPHA sera toujours inférieur et généralement
!>          comparable en magnitude à norm(A), et BETA toujours inférieur
!>          et généralement comparable à norm(B).
!>

VL

!>          VL est un tableau COMPLEX, dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres généralisés gauches u(j) sont
!>          stockés les uns après les autres dans les colonnes de VL, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre est mis à l'échelle de sorte que la plus grande
!>          composante ait abs(partie réelle) + abs(partie imag.) = 1.
!>          Non référencé si JOBVL = 'N'.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale de la matrice VL. LDVL >= 1, et
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX, dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres généralisés droits v(j) sont
!>          stockés les uns après les autres dans les colonnes de VR, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre est mis à l'échelle de sorte que la plus grande
!>          composante ait abs(partie réelle) + abs(partie imag.) = 1.
!>          Non référencé si JOBVR = 'N'.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale de la matrice VR. LDVR >= 1, et
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.  LWORK >= max(1,2*N).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; la
!>          routine calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau REAL, dimension (8*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          =1,...,N :
!>                L'itération QZ a échoué.  Aucun vecteur propre n'a été
!>                calculé, mais ALPHA(j) et BETA(j) devraient être
!>                corrects pour j=INFO+1,...,N.
!>          > N :  =N+1 : autre échec que l'itération QZ dans CHGEQZ,
!>                =N+2 : retour d'erreur de CTGEVC.
!>
