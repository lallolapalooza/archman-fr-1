sous-routine cgtts2 (integer itrans, integer n, integer nrhs, complex, dimension( * ) dl, complex, dimension( * ) d, complex, dimension( * ) du, complex, dimension( * ) du2, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb)

CGTTS2 résout un système d'équations linéaires avec une matrice tridiagonale en utilisant la factorisation LU calculée par CGTTRF.

Objectif :

!>
!> CGTTS2 résout l'un des systèmes d'équations
!>    A * X = B,  A**T * X = B,  ou  A**H * X = B,
!> avec une matrice tridiagonale A en utilisant la factorisation LU calculée
!> par CGTTRF.
!>

Paramètres

ITRANS 
!>          ITRANS est INTEGER
!>          Spécifie la forme du système d'équations.
!>          = 0 :  A * X = B     (Pas de transposée)
!>          = 1 :  A**T * X = B  (Transposée)
!>          = 2 :  A**H * X = B  (Transposée conjuguée)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est un tableau COMPLEX de dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L de la
!>          factorisation LU de A.
!>

D

!>          D est un tableau COMPLEX de dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U de
!>          la factorisation LU de A.
!>

DU

!>          DU est un tableau COMPLEX de dimension (N-1)
!>          Les (n-1) éléments de la première super-diagonale de U.
!>

DU2

!>          DU2 est un tableau COMPLEX de dimension (N-2)
!>          Les (n-2) éléments de la deuxième super-diagonale de U.
!>

IPIV

!>          IPIV est un tableau INTEGER de dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).  IPIV(i) sera toujours soit
!>          i soit i+1 ; IPIV(i) = i indique qu'un échange de ligne n'était pas
!>          nécessaire.
!>

B

!>          B est un tableau COMPLEX de dimension (LDB,NRHS)
!>          À l'entrée, la matrice des vecteurs de membre de droite B.
!>          À la sortie, B est remplacé par les vecteurs solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>
