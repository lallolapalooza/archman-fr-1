NOM

cgal_create_cmake_script - créer un script cmake pour des applications utilisant CGAL

SYNTAXE

cgal_create_cmake_script [exemple|démo|test]

DESCRIPTION

Le script cgal_create_cmake_script permet la création simple de scripts cmake pour des applications qui utilisent la bibliothèque CGAL. Le paramètre sélectionne l'un des trois types de scripts, le type par défaut est exemple.

OPTIONS

exemple
Crée un script cmake pour plusieurs applications simples. Chaque fichier C et cpp dans le répertoire courant contenant une fonction main() est compilé et lié en tant qu'exécutable séparé.
démo
Crée un script cmake pour une seule application. Tous les fichiers C et cpp dans le répertoire courant sont compilés et liés en un seul exécutable.
test
Crée un script cmake adapté à la suite de tests utilisée par les développeurs de CGAL.

AUTEUR

Le projet CGAL (https://www.cgal.org/).

SIGNALER BOGUES

Signalez les bogues à <cgal-discuss@inria.fr> (voir https://www.cgal.org/ pour plus d'instructions).

VOIR AUSSI

La documentation complète de CGAL est disponible sur https://www.cgal.org/ au format PDF et HTML.
