sous-programme cgtt01 (entier n, complexe, dimension( * ) dl, complexe, dimension( * ) d, complexe, dimension( * ) du, complexe, dimension( * ) dlf, complexe, dimension( * ) df, complexe, dimension( * ) duf, complexe, dimension( * ) du2, entier, dimension( * ) ipiv, complexe, dimension( ldwork, * ) work, entier ldwork, reel, dimension( * ) rwork, reel resid)

CGTT01

But :

!>
!> CGTT01 reconstruit une matrice tridiagonale A à partir de sa factorisation LU
!> et calcule le résidu
!>    norm(L*U - A) / ( norm(A) * EPS ),
!> où EPS est le epsilon machine.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

DL

!>          DL est un tableau COMPLEXE, dimension (N-1)
!>          Les (n-1) sous-diagonales de A.
!>

D

!>          D est un tableau COMPLEXE, dimension (N)
!>          Les éléments diagonaux de A.
!>

DU

!>          DU est un tableau COMPLEXE, dimension (N-1)
!>          Les (n-1) super-diagonales de A.
!>

DLF

!>          DLF est un tableau COMPLEXE, dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L à partir de la
!>          factorisation LU de A.
!>

DF

!>          DF est un tableau COMPLEXE, dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U de la
!>          factorisation LU de A.
!>

DUF

!>          DUF est un tableau COMPLEXE, dimension (N-1)
!>          Les (n-1) éléments de la première super-diagonale de U.
!>

DU2

!>          DU2 est un tableau COMPLEXE, dimension (N-2)
!>          Les (n-2) éléments de la deuxième super-diagonale de U.
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).  IPIV(i) sera toujours soit
!>          i, soit i+1 ; IPIV(i) = i indique qu'un échange de ligne n'était pas
!>          nécessaire.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (LDWORK,N)
!>

LDWORK

!>          LDWORK est un ENTIER
!>          La dimension principale du tableau WORK.  LDWORK >= max(1,N).
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N)
!>

RESID

!>          RESID est un REEL
!>          Le résidu normalisé :  norm(L*U - A) / (norm(A) * EPS)
!>
