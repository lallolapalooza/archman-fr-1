CGSVTS3

Objectif :

!>
!> CGSVTS3 teste CGGSVD3, qui calcule le GSVD d'une matrice A de taille M par N
!> et d'une matrice B de taille P par N :
!>              U'*A*Q = D1*R et V'*B*Q = D2*R.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est un ENTIER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,M)
!>          La matrice A de taille M par N.
!>

AF

!>          AF est un tableau COMPLEXE, de dimension (LDA,N)
!>          Détails du GSVD de A et B, tels que retournés par CGGSVD3,
!>          voir CGGSVD3 pour plus de détails.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension de tête des tableaux A et AF.
!>          LDA >= max( 1,M ).
!>

B

!>          B est un tableau COMPLEXE, de dimension (LDB,P)
!>          À l'entrée, la matrice B de taille P par N.
!>

BF

!>          BF est un tableau COMPLEXE, de dimension (LDB,N)
!>          Détails du GSVD de A et B, tels que retournés par CGGSVD3,
!>          voir CGGSVD3 pour plus de détails.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension de tête des tableaux B et BF.
!>          LDB >= max(1,P).
!>

U

!>          U est un tableau COMPLEXE, de dimension(LDU,M)
!>          La matrice unitaire U de taille M par M.
!>

LDU

!>          LDU est un ENTIER
!>          La dimension de tête du tableau U. LDU >= max(1,M).
!>

V

!>          V est un tableau COMPLEXE, de dimension(LDV,M)
!>          La matrice unitaire V de taille P par P.
!>

LDV

!>          LDV est un ENTIER
!>          La dimension de tête du tableau V. LDV >= max(1,P).
!>

Q

!>          Q est un tableau COMPLEXE, de dimension(LDQ,N)
!>          La matrice unitaire Q de taille N par N.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension de tête du tableau Q. LDQ >= max(1,N).
!>

ALPHA

!>          ALPHA est un tableau REEL, de dimension (N)
!>

BETA

!>          BETA est un tableau REEL, de dimension (N)
!>
!>          Les paires de valeurs singulières généralisées de A et B, les
!>          matrices "diagonales" D1 et D2 sont construites à partir de
!>          ALPHA et BETA, voir le sous-programme CGGSVD3 pour les détails.
!>

R

!>          R est un tableau COMPLEXE, de dimension(LDQ,N)
!>          La matrice triangulaire supérieure R.
!>

LDR

!>          LDR est un ENTIER
!>          La dimension de tête du tableau R. LDR >= max(1,N).
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (N)
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK,
!>          LWORK >= max(M,P,N)*max(M,P,N).
!>

RWORK

!>          RWORK est un tableau REEL, de dimension (max(M,P,N))
!>

RESULT

!>          RESULT est un tableau REEL, de dimension (6)
!>          Les rapports de test :
!>          RESULT(1) = norm( U'*A*Q - D1*R ) / ( MAX(M,N)*norm(A)*ULP)
!>          RESULT(2) = norm( V'*B*Q - D2*R ) / ( MAX(P,N)*norm(B)*ULP)
!>          RESULT(3) = norm( I - U'*U ) / ( M*ULP )
!>          RESULT(4) = norm( I - V'*V ) / ( P*ULP )
!>          RESULT(5) = norm( I - Q'*Q ) / ( N*ULP )
!>          RESULT(6) = 0        si ALPHA est en ordre décroissant ;
!>                    = ULPINV   sinon.
!>
