Documentation de la fonction/sous-routine

sous-routine cgelsx (integer m, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, integer, dimension( * ) jpvt, real rcond, integer rank, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CGELSX résout des systèmes surdéterminés ou sous-déterminés pour des matrices GE

But :

!>
!> Cette routine est dépréciée et a été remplacée par la routine CGELSY.
!>
!> CGELSX calcule la solution de norme minimale d'un problème des moindres carrés
!> linéaires complexes :
!>     minimiser || A * X - B ||
!> en utilisant une factorisation orthogonale complète de A. A est une matrice
!> M-par-N qui peut être de rang-défectueux.
!>
!> Plusieurs vecteurs de second membre b et vecteurs solution x peuvent être
!> traités en un seul appel ; ils sont stockés comme colonnes de la matrice
!> de second membre B (M-par-NRHS) et de la matrice solution X (N-par-NRHS).
!>
!> La routine calcule d'abord une factorisation QR avec pivot de colonnes :
!>     A * P = Q * [ R11 R12 ]
!>                 [  0  R22 ]
!> avec R11 défini comme la plus grande sous-matrice principale dont le numéro
!> de condition estimé est inférieur à 1/RCOND. L'ordre de R11, RANK,
!> est le rang effectif de A.
!>
!> Ensuite, R22 est considéré comme négligeable, et R12 est annihilé
!> par des transformations unitaires depuis la droite, aboutissant à la
!> factorisation orthogonale complète :
!>    A * P = Q * [ T11 0 ] * Z
!>                [  0  0 ]
!> La solution de norme minimale est alors
!>    X = P * Z**H [ inv(T11)*Q1**H*B ]
!>                 [        0         ]
!> où Q1 comprend les RANK premières colonnes de Q.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un entier (INTEGER)
!>          Le nombre de seconds membres, c'est-à-dire le nombre
!>          de colonnes des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau de complexes (COMPLEX), dimension (LDA,N)
!>          En entrée, la matrice A de taille M-par-N.
!>          En sortie, A contient des détails de sa factorisation orthogonale complète.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est un tableau de complexes (COMPLEX), dimension (LDB,NRHS)
!>          En entrée, la matrice de second membre B de taille M-par-NRHS.
!>          En sortie, la matrice solution X de taille N-par-NRHS.
!>          Si m >= n et RANK = n, la somme des carrés résiduels pour
!>          la solution dans la i-ème colonne est donnée par la somme des
!>          carrés des éléments N+1:M dans cette colonne.
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale du tableau B. LDB >= max(1,M,N).
!>

JPVT

!>          JPVT est un tableau d'entiers (INTEGER), dimension (N)
!>          En entrée, si JPVT(i) .ne. 0, la i-ème colonne de A est une colonne
!>          initiale, sinon c'est une colonne libre. Avant
!>          la factorisation QR de A, toutes les colonnes initiales sont
!>          permutées vers les positions principales ; seules les colonnes
!>          libres restantes sont déplacées suite au pivotement de colonnes
!>          pendant la factorisation.
!>          En sortie, si JPVT(i) = k, alors la i-ème colonne de A*P
!>          était la k-ème colonne de A.
!>

RCOND

!>          RCOND est un réel (REAL)
!>          RCOND est utilisé pour déterminer le rang effectif de A, qui
!>          est défini comme l'ordre de la plus grande sous-matrice triangulaire
!>          principale R11 dans la factorisation QR avec pivotement de A,
!>          dont le numéro de condition estimé est < 1/RCOND.
!>

RANK

!>          RANK est un entier (INTEGER)
!>          Le rang effectif de A, c'est-à-dire l'ordre de la sous-matrice
!>          R11. C'est le même que l'ordre de la sous-matrice T11
!>          dans la factorisation orthogonale complète de A.
!>

WORK

!>          WORK est un tableau de complexes (COMPLEX), dimension
!>                      (min(M,N) + max( N, 2*min(M,N)+NRHS )),
!>

RWORK

!>          RWORK est un tableau de réels (REAL), dimension (2*N)
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
