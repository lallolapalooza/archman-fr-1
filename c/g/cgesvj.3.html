sous-routine cgesvj (character*1 joba, character*1 jobu, character*1 jobv, integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( n ) sva, integer mv, complex, dimension( ldv, * ) v, integer ldv, complex, dimension( lwork ) cwork, integer lwork, real, dimension( lrwork ) rwork, integer lrwork, integer

info)

CGESV

J

But

: 
!>
!> CGESVJ calcule la décomposition en valeurs singulières (SVD) d'une matrice
!> complexe A de dimensions M par N, où M >= N. La SVD de A est écrite comme
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> où SIGMA est une matrice diagonale de dimensions N par N, U est une matrice
!> orthonormale de dimensions M par N, et V est une matrice unitaire de
!> dimensions N par N. Les éléments diagonaux de SIGMA sont les valeurs
!> singulières de A. Les colonnes de U et de V sont les vecteurs singuliers
!> gauche et droit de A, respectivement.
!
>

Paramètre

s
JOBA 
!>          JOBA est CHARACTER*1
!>          Spécifie la structure de A.
!>          = 'L' : la matrice d'entrée A est triangulaire inférieure ;
!>          = 'U' : la matrice d'entrée A est triangulaire supérieure ;
!>          = 'G' : la matrice d'entrée A est une matrice générale de
!>          dimensions M par N, M >= N.
!
>

JOB

U 
!>          JOBU est CHARACTER*1
!>          Spécifie s'il faut calculer les vecteurs singuliers gauche
!>          (les colonnes de U) :
!>          = 'U' ou 'F' : les vecteurs singuliers gauche correspondant aux
!>                 valeurs singulières non nulles sont calculés et renvoyés
!>                 dans les colonnes dominantes de A. Voir plus de détails
!>                 dans la description de A.
!>                 Le seuil d'orthogonalité numérique par défaut est défini
!>                 à environ TOL=CTOL*EPS, CTOL=SQRT(M), EPS=SLAMCH('E').
!>          = 'C' : analogue à JOBU='U', sauf que l'utilisateur peut
!>                 contrôler le niveau d'orthogonalité numérique des vecteurs
!>                 singuliers gauche calculés. TOL peut être défini à
!>                 TOL = CTOL*EPS, où CTOL est donné en entrée dans le
!>                 tableau WORK.
!>                 Aucun CTOL inférieur à ONE n'est autorisé. Un CTOL
!>                 supérieur à 1 / EPS est sans signification. L'option 'C'
!>                 peut être utilisée si M*EPS est une orthogonalité
!>                 satisfaisante pour les vecteurs singuliers gauche calculés,
!>                 de sorte que CTOL=M pourrait économiser quelques balayages
!>                 de rotations de Jacobi.
!>                 Voir les descriptions de A et WORK(1).
!>          = 'N' : la matrice U n'est pas calculée. Cependant, voir la
!>                 description de A.
!
>

JOB

V 
!>          JOBV est CHARACTER*1
!>          Spécifie s'il faut calculer les vecteurs singuliers droit, c'est-à-
!>          dire la matrice V :
!>          = 'V' ou 'J' : la matrice V est calculée et renvoyée dans le
!>          tableau V
!>          = 'A' :  les rotations de Jacobi sont appliquées au tableau V de
!>                  dimensions MV par N. En d'autres termes, la matrice de
!>                  vecteurs singuliers droit V n'est pas calculée
!>                  explicitement ; au lieu de cela, elle est appliquée à une
!>                  matrice de dimensions MV par N initialement stockée dans
!>                  les MV premières lignes de V.
!>          = 'N' :  la matrice V n'est pas calculée et le tableau V n'est pas
!>                  référencé
!
>

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. 1/SLAMCH('E') > M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M par N.
!>          À la sortie,
!>          Si JOBU = 'U' .OR. JOBU = 'C' :
!>                 Si INFO = 0 :
!>                 RANKA colonnes orthonormales de U sont renvoyées dans les
!>                 RANKA colonnes dominantes du tableau A. Ici RANKA <= N
!>                 est le nombre de valeurs singulières de A calculées qui sont
!>                 au-dessus du seuil de débordement négatif SLAMCH('S'). Les
!>                 vecteurs singuliers correspondant aux valeurs singulières
!>                 sous le seuil ou nulles ne sont pas calculés. La valeur de
!>                 RANKA est renvoyée dans le tableau RWORK sous la forme
!>                 RANKA=NINT(RWORK(2)). Voir aussi les descriptions de SVA
!>                 et RWORK. Les colonnes calculées de U sont numériquement
!>                 orthogonales entre elles jusqu'à environ
!>                 TOL=SQRT(M)*EPS (par défaut) ; ou TOL=CTOL*EPS
!>                 (JOBU = 'C'), voir la description de JOBU.
!>                 Si INFO > 0,
!>                 la procédure CGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (balayages). Dans ce cas, les colonnes
!>                 calculées de U peuvent ne pas être orthogonales jusqu'à
!>                 TOL. La sortie U (stockée dans A), SIGMA (donnée par les
!>                 valeurs singulières calculées dans SVA(1:N)) et V reste une
!>                 décomposition de la matrice d'entrée A dans le sens où le
!>                 résidu
!>                 || A - SCALE * U * SIGMA * V^* ||_2 / ||A||_2 est petit.
!>          Si JOBU = 'N' :
!>                 Si INFO = 0 :
!>                 Notez que les vecteurs singuliers gauche sont « gratuits »
!>                 dans l'algorithme de SVD de Jacobi unilatéral. Cependant,
!>                 si seules les valeurs singulières sont nécessaires, le
!>                 niveau d'orthogonalité numérique de U n'est pas un problème
!>                 et les itérations s'arrêtent lorsque les colonnes de la
!>                 matrice itérée sont numériquement orthogonales jusqu'à
!>                 environ M*EPS. Ainsi, à la sortie, A contient les colonnes
!>                 de U mises à l'échelle avec les valeurs singulières
!>                 correspondantes.
!>                 Si INFO > 0 :
!>                 la procédure CGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (balayages).
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension dominante du tableau A.  LDA >= max(1,M).
!
>

SV

A 
!>          SVA est un tableau REAL, dimension (N)
!>          À la sortie,
!>          Si INFO = 0 :
!>          selon la valeur SCALE = RWORK(1), nous avons :
!>                 Si SCALE = ONE :
!>                 SVA(1:N) contient les valeurs singulières calculées de A.
!>                 Pendant le calcul, SVA contient les normes euclidiennes des
!>                 colonnes des matrices itérées dans le tableau A.
!>                 Si SCALE .NE. ONE :
!>                 Les valeurs singulières de A sont SCALE*SVA(1:N), et cette
!>                 représentation factorisée est due au fait que certaines des
!>                 valeurs singulières de A pourraient déborder en dessous ou
!>                 en dessus.
!>
!>          Si INFO > 0 :
!>          la procédure CGESVJ n'a pas convergé dans le nombre donné
!>          d'itérations (balayages) et SCALE*SVA(1:N) peut ne pas être
!>          précis.
!
>

M

V 
!>          MV est INTEGER
!>          Si JOBV = 'A', alors le produit des rotations de Jacobi dans
!>          CGESVJ est appliqué aux MV premières lignes de V. Voir la
!>          description de JOBV.
!
>

V 
!>          V est un tableau COMPLEX, dimension (LDV,N)
!>          Si JOBV = 'V', alors V contient à la sortie la matrice de
!>                         dimensions N par N des vecteurs singuliers droit ;
!>          Si JOBV = 'A', alors V contient le produit de la matrice de
!>                         vecteurs singuliers droit calculée et de la matrice
!>                         initiale dans le tableau V.
!>          Si JOBV = 'N', alors V n'est pas référencé.
!
>

LD

V 
!>          LDV est INTEGER
!>          La dimension dominante du tableau V, LDV >= 1.
!>          Si JOBV = 'V', alors LDV >= max(1,N).
!>          Si JOBV = 'A', alors LDV >= max(1,MV) .
!
>

CWOR

K 
!>          CWORK est un tableau COMPLEX, dimension (max(1,LWORK))
!>          Utilisé comme espace de travail.
!
>

LWOR

K 
!>          LWORK est INTEGER.
!>          Longueur de CWORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et LWORK >= M+N, sinon.
!>
!>          Si à l'entrée LWORK = -1, alors une interrogation d'espace de
!>          travail est supposée et aucun calcul n'est effectué ;
!>          CWORK(1) est défini à la longueur minimale (et optimale)
!>          de CWORK.
!
>

RWOR

K 
!>          RWORK est un tableau REAL, dimension (max(6,LRWORK))
!>          À l'entrée,
!>          Si JOBU = 'C' :
!>          RWORK(1) = CTOL, où CTOL définit le seuil de convergence.
!>                    Le processus s'arrête si toutes les colonnes de A sont
!>                    mutuellement orthogonales jusqu'à CTOL*EPS,
!>                    EPS=SLAMCH('E').
!>                    Il est requis que CTOL >= ONE, c'est-à-dire qu'il n'est
!>                    pas permis de forcer la routine à obtenir l'orthogonalité
!>                    en dessous d'EPSILON.
!>          À la sortie,
!>          RWORK(1) = SCALE est le facteur d'échelle tel que SCALE*SVA(1:N)
!>                    sont les valeurs singulières calculées de A.
!>                    (Voir la description de SVA().)
!>          RWORK(2) = NINT(RWORK(2)) est le nombre de valeurs singulières
!>                    non nulles calculées.
!>          RWORK(3) = NINT(RWORK(3)) est le nombre de valeurs singulières
!>                    calculées qui sont plus grandes que le seuil de
!>                    débordement (underflow).
!>          RWORK(4) = NINT(RWORK(4)) est le nombre de balayages de
!>                    rotations Jacobi nécessaires pour la convergence
!>                    numérique.
!>          RWORK(5) = max_{i.NE.j} |COS(A(:,i),A(:,j))| dans le dernier
!>                    balayage.
!>                    Ceci est une information utile dans les cas où CGESVJ
!>                    n'a pas convergé, car elle peut être utilisée pour
!>                    estimer si la sortie est encore utile et pour une
!>                    analyse a posteriori.
!>          RWORK(6) = la plus grande valeur absolue de tous les sinus des
!>                    angles de rotation Jacobi dans le dernier balayage.
!>                    Elle peut être utile pour une analyse a posteriori.
!
>

LRWOR

K 
!>         LRWORK est INTEGER
!>         Longueur de RWORK.
!>         LRWORK >= 1, si MIN(M,N) = 0, et LRWORK >= MAX(6,N), sinon
!>
!>         Si à l'entrée LRWORK = -1, alors une interrogation d'espace de
!>         travail est supposée et aucun calcul n'est effectué ;
!>         RWORK(1) est défini à la longueur minimale (et optimale)
!>         de RWORK.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, alors le i-ème argument avait une valeur
!>                illégale
!>          > 0:  CGESVJ n'a pas convergé dans le nombre maximal autorisé
!>                (NSWEEP=30) de balayages. La sortie peut encore être utile.
!>                Voir la description de RWORK.
!
>

Détails supplémentaires

: 
!>
!> La matrice orthogonale N par N V est obtenue comme un produit de
!> rotations de plan Jacobi. Dans le cas du débordement (underflow) de la
!> tangente de l'angle Jacobi, une transformation Jacobi modifiée de
!> Drmac [3] est utilisée. La stratégie de pivotement utilise des
!> permutations de colonnes de de Rijk [1]. La précision relative des
!> valeurs singulières calculées et la précision des vecteurs singuliers
!> calculés (en métrique d'angle) est garantie par la théorie de Demmel
!> et Veselic [2]. Le nombre de condition qui détermine la précision dans
!> le cas de rang complet est essentiellement min_{D=diag} kappa(A*D),
!> où kappa(.) est le nombre de condition spectral. Les meilleures
!> performances de cette procédure SVD Jacobi sont obtenues si elle est
!> utilisée dans une version accélérée de Drmac et Veselic [4,5], et
!> c'est la routine noyau dans la bibliothèque SIGMA [6].
!> Certains paramètres de réglage (marqués avec [TP]) sont disponibles
!> pour l'implémenteur.
!> L'intervalle de calcul pour les valeurs singulières non nulles est
!> l'intervalle de nombres machine ( UNDERFLOW , OVERFLOW ). Dans les cas
!> extrêmes, même des valeurs singulières dénormalisées peuvent être
!> calculées avec la perte correspondante de chiffres significatifs
!> graduelle.
!
>
