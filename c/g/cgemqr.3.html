Documentation de la fonction/sous-routine

sous-routine cgemqr (caractère side, caractère trans, entier m, entier n, entier k, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( * ) t, entier tsize, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( * ) work, entier lwork, entier info)

CGEMQR

Objectif :

!>
!> CGEMQR écrase la matrice réelle générale M par N, C, avec
!>
!>                      SIDE = 'L'     SIDE = 'R'
!>      TRANS = 'N':      Q * C          C * Q
!>      TRANS = 'T':      Q**H * C       C * Q**H
!>
!> où Q est une matrice unitaire complexe définie comme le produit
!> de réflecteurs élémentaires calculés par la factorisation QR en blocs
!> (CGEQR).
!>
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H à Gauche ;
!>          = 'R': appliquer Q ou Q**H à Droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': Pas de transposée, appliquer Q ;
!>          = 'C': Transposée conjuguée, appliquer Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >=0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,K)
!>          Partie de la structure de données représentant Q, retournée par CGEQR.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T est un tableau COMPLEXE, de dimension (MAX(5,TSIZE)).
!>          Partie de la structure de données représentant Q, retournée par CGEQR.
!>

TSIZE

!>          TSIZE est INTEGER
!>          La dimension du tableau T. TSIZE >= 5.
!>

C

!>          C est un tableau COMPLEXE, de dimension (LDC,N)
!>          En entrée, la matrice M par N, C.
!>          En sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          (espace de travail) tableau COMPLEXE, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient le LWORK minimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée. La routine
!>          calcule seulement la taille du tableau WORK, retourne cette
!>          valeur dans WORK(1), et aucun message d'erreur lié à WORK
!>          n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0: succès
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
