NOM

CGI::Session::Driver::sqlite - Pilote CGI::Session pour SQLite

SYNTAXE

$s = CGI::Session->new("driver:sqlite", $sid, {DataSource=>'/mon/dossier/sessions.sqlt'});
$s = CGI::Session->new("driver:sqlite", $sid, {Handle=>$dbh});

ou

$s = CGI::Session->new('driver:sqlite', undef,
{
    TableName=>'session',
    IdColName=>'mon_id',
    DataColName=>'mes_donnees',
    Handle=>$dbh,
});

DESCRIPTION

Le pilote sqlite stocke les données de session dans des fichiers SQLite en utilisant le pilote DBI DBD::SQLite. Pour plus de détails, voir CGI::Session::Driver::DBI, sa classe parente.

ARGUMENTS DU PILOTE

Les arguments de pilote pris en charge sont DataSource et Handle. **Un seul** de ces arguments peut être défini lors de la création de l'objet de session.

DataSource doit être sous la forme "dbi:SQLite:dbname=/chemin/vers/db.sqlt". Si "dbi:SQLite:" est manquant, il sera préfixé pour vous. Si Handle est présent, il doit s'agir du descripteur de base de données ($dbh) retourné par DBI::connect().

Depuis la version 1.7 de ce pilote, le troisième argument n'est **PAS** facultatif. L'utilisation d'une base de données par défaut dans le répertoire temporaire constitue un risque de sécurité car toute personne sur la machine peut créer et/ou lire vos données de session. Si vous comprenez ces risques et souhaitez toujours l'ancien comportement, vous pouvez définir l'option "DataSource" à '/tmp/sessions.sqlt'.

BOGUES ET LIMITATIONS

Aucun connu.

LICENCE

Pour le support et la licence, voir CGI::Session
