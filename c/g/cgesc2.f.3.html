Documentation de la fonction/sous-routine

sous-routine cgesc2 (integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) rhs, integer, dimension( * ) ipiv, integer, dimension( * ) jpiv, real scale)

CGESC2 résout un système d'équations linéaires en utilisant la factorisation LU avec pivotement complet calculé par sgetc2.

Objectif :

!>
!> CGESC2 résout un système d'équations linéaires
!>
!>           A * X = scale* RHS
!>
!> avec une matrice générale N-par-N A en utilisant la factorisation LU avec
!> pivotement complet calculée par CGETC2.
!>
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA, N)
!>          À l'entrée, la partie LU de la factorisation de la matrice N-par-N
!>          A calculée par CGETC2 :  A = P * L * U * Q
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1, N).
!>

RHS

!>          RHS est un tableau COMPLEXE, dimension N.
!>          À l'entrée, le vecteur membre de droite b.
!>          À la sortie, le vecteur solution X.
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N).
!>          Les indices de pivot ; pour 1 <= i <= N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

JPIV

!>          JPIV est un tableau ENTIER, dimension (N).
!>          Les indices de pivot ; pour 1 <= j <= N, la colonne j de la
!>          matrice a été échangée avec la colonne JPIV(j).
!>

SCALE

!>          SCALE est un RÉEL
!>           À la sortie, SCALE contient le facteur d'échelle. SCALE est choisi
!>           tel que 0 <= SCALE <= 1 pour éviter le débordement dans la solution.
!>
