CGESVDX calcule la décomposition en valeurs singulières (SVD) pour les matrices GE

Documentation de la fonction/sous-routine

sous-routine cgesvdx (character jobu, character jobvt, character range, integer m, integer n, complex, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, integer ns, real, dimension( * ) s, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( ldvt, * ) vt, integer ldvt, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

CGESVDX calcule la décomposition en valeurs singulières (SVD) pour les matrices GE

But :

!>
!>  CGESVDX calcule la décomposition en valeurs singulières (SVD) d'une matrice
!>  complexe M par N A, en calculant éventuellement les vecteurs singuliers
!>  gauche et/ou droit. La SVD est écrite
!>
!>      A = U * SIGMA * transpose(V)
!>
!>  où SIGMA est une matrice M par N qui est nulle sauf pour ses
!>  min(m,n) éléments diagonaux, U est une matrice unitaire M par M, et
!>  V est une matrice unitaire N par N. Les éléments diagonaux de SIGMA
!>  sont les valeurs singulières de A ; elles sont réelles et non négatives, et
!>  sont retournées par ordre décroissant. Les premières min(m,n) colonnes de
!>  U et V sont les vecteurs singuliers gauche et droit de A.
!>
!>  CGESVDX utilise un problème de valeurs propres pour obtenir la SVD, ce qui
!>  permet le calcul d'un sous-ensemble de valeurs singulières et
!>  de vecteurs. Voir SBDSVDX pour plus de détails.
!>
!>  Notez que la routine retourne V**T, et non V.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          Spécifie les options pour calculer toute ou partie de la matrice U :
!>          = 'V' : les premières min(m,n) colonnes de U (les vecteurs
!>                  singuliers gauche) ou tel que spécifié par RANGE sont
!>                  retournées dans le tableau U ;
!>          = 'N' : aucune colonne de U (aucun vecteur singulier gauche) n'est
!>                  calculée.
!>

JOBVT

!>          JOBVT est CHARACTER*1
!>           Spécifie les options pour calculer toute ou partie de la matrice
!>           V**T :
!>           = 'V' : les premières min(m,n) lignes de V**T (les vecteurs
!>                   singuliers droit) ou tel que spécifié par RANGE sont
!>                   retournées dans le tableau VT ;
!>           = 'N' : aucune ligne de V**T (aucun vecteur singulier droit) n'est
!>                   calculée.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs singulières seront trouvées.
!>          = 'V' : toutes les valeurs singulières dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs singulières de la i-ème à la IU-ème seront trouvées.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A. N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice M par N A.
!>          À la sortie, le contenu de A est détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle dans
!>          lequel rechercher les valeurs singulières. VU > VL.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle dans
!>          lequel rechercher les valeurs singulières. VU > VL.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur singulière à retourner.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur singulière à retourner.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

NS

!>          NS est INTEGER
!>          Le nombre total de valeurs singulières trouvées,
!>          0 <= NS <= min(M,N).
!>          Si RANGE = 'A', NS = min(M,N) ; si RANGE = 'I', NS = IU-IL+1.
!>

S

!>          S est un tableau REAL, dimension (min(M,N))
!>          Les valeurs singulières de A, triées de sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau COMPLEX, dimension (LDU,UCOL)
!>          Si JOBU = 'V', U contient les colonnes de U (les vecteurs
!>          singuliers gauche, stockés par colonnes) tel que spécifié par RANGE ; si
!>          JOBU = 'N', U n'est pas référencé.
!>          Note : L'utilisateur doit s'assurer que UCOL >= NS ; si RANGE = 'V',
!>          la valeur exacte de NS n'est pas connue à l'avance et une borne
!>          supérieure doit être utilisée.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= 1 ; si
!>          JOBU = 'V', LDU >= M.
!>

VT

!>          VT est un tableau COMPLEX, dimension (LDVT,N)
!>          Si JOBVT = 'V', VT contient les lignes de V**T (les vecteurs
!>          singuliers droit, stockés par lignes) tel que spécifié par RANGE ; si JOBVT = 'N',
!>          VT n'est pas référencé.
!>          Note : L'utilisateur doit s'assurer que LDVT >= NS ; si RANGE = 'V',
!>          la valeur exacte de NS n'est pas connue à l'avance et une borne
!>          supérieure doit être utilisée.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT. LDVT >= 1 ; si
!>          JOBVT = 'V', LDVT >= NS (voir ci-dessus).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= MAX(1,MIN(M,N)*(MIN(M,N)+4)) pour les chemins (voir
!>          les commentaires dans le code) :
!>             - CHEMIN 1  (M beaucoup plus grand que N)
!>             - CHEMIN 1t (N beaucoup plus grand que M)
!>          LWORK >= MAX(1,MIN(M,N)*2+MAX(M,N)) pour les autres chemins.
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, une interrogation de l'espace de travail est supposée ; la routine
!>          ne calcule que la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau REAL, dimension (MAX(1,LRWORK))
!>          LRWORK >= MIN(M,N)*(MIN(M,N)*2+15*MIN(M,N)).
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (12*MIN(M,N))
!>          Si INFO = 0, les NS premiers éléments de IWORK sont nuls. Si INFO > 0,
!>          alors IWORK contient les indices des vecteurs propres qui n'ont pas
!>          convergé dans SBDSVDX/SSTEVX.
!>

INFO

!>     INFO est INTEGER
!>           = 0 :  sortie réussie
!>           < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>           > 0 :  si INFO = i, alors i vecteurs propres n'ont pas convergé
!>                 dans SBDSVDX/SSTEVX.
!>                 si INFO = N*2 + 1, une erreur interne est survenue dans
!>                 SBDSVDX
!
>
